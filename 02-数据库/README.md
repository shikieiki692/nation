# 数据库（筛选/浏览/监控层）

> 本目录是知识库的**筛选/浏览/监控层**，不是真实源。
> 真实内容存放在各业务目录（03-知识点、04-题库、04-专题与题型等），此处只做聚合索引。

## 与 10-索引与统计 的区别

| | 02-数据库 | 10-索引与统计 |
|---|---|---|
| 作用 | 筛选/浏览/监控（Dataview 查询、看板） | 纯索引 + 统计报表 |
| 内容 | `.base` 文件 + `数据库-*.md` 索引页 | 知识点总索引、统计汇总 |
| 更新频率 | 高（随库存变化实时更新） | 中（随库存变化更新） |
| 受众 | 学习者/教师（浏览筛选） | 维护者/开发者（全局统计） |
