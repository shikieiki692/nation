# KB-Token-Saver · Token节约执行器

## 用途

在操作 `04-题库/` 下任何文件前，**自动执行**以下步骤，确保 token 消耗最小化：

1. 读取格式速查文件（4KB）→ 替代读取多个示例文件（~3KB/文件）
2. 读取章节摘要文件（20KB）→ 替代读取完整OCR（775KB）
3. 禁止全读OCR源文件

**核心价值**：
- 单题审计：~50K tokens → <5K tokens（节省90%）
- 批量审计(10题)：~500K tokens → <30K tokens（节省94%）
- 创建新题：~100K tokens → <10K tokens（节省90%）

---

## 强制执行步骤

### Step 1: 读取速查文件（~2K tokens）

**操作**：`kb_read` 读取以下文件

```
04-题库/教材习题/结构化学基础/题库格式速查.md
```

**包含内容**：
- YAML frontmatter 模板
- 文件命名规范
- 内容结构模板
- 常见错误示例

### Step 2: 读取章节摘要（~8K tokens）

**操作**：`kb_read` 读取以下文件

```
07-资料提炼/习题提炼/结构化学基础-习题章节摘要.md
```

**包含内容**：
- 308题的题目索引
- 每题的关键数据和核心概念
- 章节概览和题号范围

### Step 3: 禁止全读OCR

**绝对禁止**：
- ❌ 读取完整OCR源文件（775KB，~3.1M tokens）
- ❌ 读取整个章节的OCR内容

**允许**：
- ✅ 读取OCR的特定行（用 `limit` 限制，如 `limit=50`）
- ✅ 读取OCR的特定章节（先定位行号再读取）

## 执行检查清单

操作题库前，agent 必须确认：

- [ ] 已读取 `题库格式速查.md`
- [ ] 已读取 `结构化学基础-习题章节摘要.md`
- [ ] 未读取完整OCR源文件（775KB）
- [ ] Read调用已添加 `limit` 参数
- [ ] 小修改使用 Edit 而非 Read+Write

## 与kb-audit的配合

当触发 `kb-audit` skill 时，本skill 会先执行，确保：
1. 审计清单已加载
2. 格式规范已确认
3. 摘要文件已读取

然后 `kb-audit` 可以直接使用这些数据进行审计。
