# 真题库（按题型分类）

> 本目录将真题按**知识模块/题型**重新组织，与 `04-题库/真题/`（按届次/年份组织）形成互补。
> 共 **58 个题型文件**。

## 与04-题库/真题/ 的关系

| 维度 | 04-题库/真题/ | 05-真题库/ |
|------|-------------|-----------|
| 组织方式 | 按届次（第25届初赛、第36届决赛…） | 按题型/知识模块（分析-滴定、结构-晶胞…） |
| 用途 | 查找某届真题的完整试卷 | 查找某类题型的所有真题 |
| 文件数 | ~854题 | 58题（持续扩展中） |
| frontmatter | knowledge_points 字段 | aliases 字段含届次信息 |

## 目录结构

| 模块 | 文件数 | 示例 |
|------|--------|------|
| 分析化学 | 8 | 滴定(3)、沉淀滴定、络合滴定、氧化还原滴定(2)、误差 |
| 结构化学 | 5 | 晶胞计算、Bragg方程、钙钛矿、离子半径比、晶体结构 |
| 无机化学 | 13 | 18电子规则、对角线规则、反位效应、过渡金属(4)、Born-Haber、Jahn-Teller |
| 有机化学 | 17 | Diels-Alder、Grignard、Aldol、SN1、SN2、E2、Friedel-Crafts等 |
| 物理化学 | 7 | 动力学(2)、热力学(2)、电化学(2)、相平衡 |
| 化学原理 | 2 | 酸碱理论、氧化还原、配合物 |
| 化学动力学 | 1 | 速率方程相关 |
| 自由基 | 3 | 链式机理、开环环化、KIE合成应用 |

## 使用方式

- 要找某届真题 → 去 `04-题库/真题/第XX届初赛/`
- 要找某类题型的所有真题 → 在本目录按文件名搜索
- 每个文件的 `aliases` 字段包含原始届次信息，可反向定位到04-题库/
