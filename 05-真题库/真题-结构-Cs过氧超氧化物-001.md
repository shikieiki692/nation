# Cs 过氧/超氧化物相变中的电荷有序——Cs₄(O₂⁻)₂(O₂²⁻)

## 题目

Cs 的超氧化合物在一定温度（或压力）作用下，可由电荷无序（charge-disordered）的**立方相**转变为电荷有序（charge ordered）的**四方相**。

立方相：只有一种 O–O 键长；双氧阴离子 $\mathrm{O_2^{n-}}$ 有三种对称性等价的取向，分别平行于三条晶轴；X 射线衍射分析给出其晶胞含 4 个 Cs⁺ 和 3 个双氧阴离子。

四方相：$\mathrm{O_2^-}$ 与 $\mathrm{O_2^{2-}}$ 有序排列，晶体中出现两种 O–O 键长，实测约为 133 pm 和 149 pm，其中平行于 c 轴取向的双氧离子取较长键长。

(1) 写出立方相晶体结构中双氧阴离子的氧化数；写出四方相的化学式（须能表示出超氧与过氧两种组分）。

(2) 指出四方相中平行于 c 轴的 $\mathrm{O_2^{n-}}$ 是 $\mathrm{O_2^-}$ 还是 $\mathrm{O_2^{2-}}$，并说明理由。

## 参考答案

**答案**：

(1) 立方相双氧阴离子氧化数为 **−4/3**；四方相化学式为 **$\mathrm{Cs_4(O_2^-)_2(O_2^{2-})}$**（即 $\mathrm{Cs_4O_6}$）

(2) 平行于 c 轴的是 **$\mathrm{O_2^{2-}}$（过氧离子）**

**详细推导**：

**(1) 立方相氧化数。** 晶胞内 4 个 Cs⁺ 共 +4 电荷，由 3 个等价的双氧阴离子分摊：

$$
3n = -4 \Rightarrow n = -\frac{4}{3}
$$

氧化数为分数正是"电荷无序"的体现——每个双氧位点是 $\mathrm{O_2^-}$ 与 $\mathrm{O_2^{2-}}$ 的统计平均，故只有一种平均的 O–O 键长。

**(2) 四方相化学式。** 电荷有序不改变组成：晶胞仍含 4 Cs 与 3 个双氧单元。设 $\mathrm{O_2^-}$ 有 x 个、$\mathrm{O_2^{2-}}$ 有 y 个：

$$
x + y = 3 \qquad x + 2y = 4
$$

解得 x = 2、y = 1，化学式 $\mathrm{Cs_4(O_2^-)_2(O_2^{2-})}$。验证电荷：2×(−1) + 1×(−2) = −4，与 4 个 Cs⁺ 平衡 ✓

**(3) 判别平行 c 轴的型体。** 由分子轨道（见本库 [[真题-结构-超氧离子分子轨道-001]]）：

| 型体 | π* 电子数 | 键级 | 典型 O–O 键长 |
|---|---|---|---|
| $\mathrm{O_2^-}$ | 3 | 1.5 | ≈ 133 pm |
| $\mathrm{O_2^{2-}}$ | 4 | 1.0 | ≈ 149 pm |

平行于 c 轴的双氧离子 O–O 键长较长（149 pm）→ 键级低 → 为 $\mathrm{O_2^{2-}}$（过氧离子）；另两个取向（133 pm）为 $\mathrm{O_2^-}$（超氧离子）。

**易错点**：

- 电荷守恒联立时把"3 个双氧单元"写成 4 个（x + y = 4 与 x + 2y = 4 无正整数解）——单元数由立方相晶胞内容（4 Cs ∶ 3 O₂）继承而来，须先读出
- 认为分数氧化数"不存在"或化整为 −1——混合价态统计平均正是 −4/3 的物理含义
- 键长-键级关系记反：反键 π* 电子越多键级越低、键越长，O₂²⁻ 比 O₂⁻ 键长
- 写化学式时只写 Cs₄O₆——题目要求"表示出超氧与过氧两种组分"，必须写成 $\mathrm{Cs_4(O_2^-)_2(O_2^{2-})}$
