## 逐题讲评

**7-1（C）Diels-Alder 活性：s-cis 构象可及性**

- DA 反应的速控步要求二烯取 **s-cis（顺式）构象**——只有折叠构象下 C1、C4 两端才能同时接近亲双烯体的 π 体系。
- 三选项为 2,4-己二烯骨架的几何/构象异构体（见图）：延展（s-trans 型）排布的优势构象需翻转越过构象能垒才能进入 s-cis，反应慢；双键几何使骨架天然处于或最易翻越至 s-cis 的异构体，活化代价最小。
- C 的骨架排布最利于 s-cis 构象的达成 → 与丙烯腈反应最快。
- **易错**：只比取代基电子效应而忽略构象要求；E/Z 是构型（不可翻转），s-cis/s-trans 是构象（可翻转），二者不可混淆。

**7-2（A）内酰胺碱性水解：N-取代基电子效应**

- A 为 N-苯基-2-哌啶酮：N 的孤对部分离域进入苯环（N-芳基交叉共轭），**削弱 N→C=O 共振给电子**，羰基碳亲电性升高 → $\mathrm{OH^-}$ 亲核加成快 → 碱性水解快。
- B 中酰胺 N 为烷基型、酰胺共振正常，羰基缺电子程度低 → 水解慢。
- 一般规律：酰胺碱性水解速率随羰基亲电性增大而加快；凡削弱酰胺共振的因素（N-芳基化、N-酰基化、酰胺键扭曲等）均使水解加快。
- **易错**：把"内酰胺"一律当"共振强、稳定"；忽略 N 上取代基电子性质的差异。

**7-3（B）柠檬烯型二烯的选择性环氧化**

- 底物有两个双键：环内三取代双键（带甲基）与环外异丙烯基端叉双键。
- mCPBA 亲电且体积大，区域选择由电子与位阻共同决定：环外异丙烯基双键**暴露、位阻小**，过酸经螺状过渡态接近顺利；环内双键贴于环架，受环上 1-位甲基与 4-位异丙烯基的位阻屏蔽。
- 主要产物为**环外双键环氧化的产物**（选项 B，其结构即题面组合图右半所示）；A（环内环氧化）为次要产物。
- **易错**：只按"三取代双键更富电子"机械推断而忽略位阻项；把题面组合图右半误当作底物的一部分。

**7-4（C）Cram（Felkin–Anh）非螯合控制**

- 底物 (S)-2-苯基丙醛：α-手性碳上三个大小不等的基团 L = Ph、M = Me、S = H，α 位**无杂原子**，格氏加成受 Cram（Felkin–Anh）模型控制而非螯合控制。
- 构象取羰基与最小基团 H 重叠；乙基从小基团 H 一侧沿 Bürgi–Dunitz 轨迹接近羰基（避开大基团 Ph）→ 主产物为 Cram 产物。
- 四个选项为两对非对映体的 Fischer 投影（见图），与 Felkin–Anh 预测一致者为 C。
- **易错**：把 α-苯基当"可螯合基团"而走 chelation 模型（底物 α 位无杂原子，无可螯合位点）；忽略非对映面选择性，误以为格氏加成只给消旋产物。

**7-5（A）极性反转合成 α-羟基酮：二噻烷与二硫杂环戊烷之别**

- 两法同为 Corey–Seebach 型极性反转：醛 → 缩硫醛 → 强碱去质子成双硫稳定碳负离子 → 与 $\mathrm{R^2CHO}$ 加成 → $\mathrm{Hg^{2+}}$/水脱保护得 α-羟基酮。
- 分水岭在**去质子步**：方法 A 用 1,3-丙二硫醇得**六元 1,3-二噻烷**，椅式构象下碳负离子 p 轨道可与两个 C–S 键的 $\sigma^*$ 高效负超共轭（pKa ≈ 31），n-BuLi 可稳定去质子；方法 B 用乙二硫醇得**五元 1,3-二硫杂环戊烷**，环构象受限、上述稳定化显著减弱，C2–H 酸性不足，n-BuLi 一步不可行。
- 故方法 A 全程可行，方法 B 断裂在去质子步。
- **易错**：认为"两个缩硫醛只差一个 $\mathrm{CH_2}$、性质近似"；忽略环大小对碳负离子稳定化的决定性影响。

**7-6（B）Cope [3,3] 重排：手性中心的迁移**

- 底物 $\mathrm{CH_2{=}CH{-}C(Me)(Ph){-}CH_2{-}CH{=}CH{-}CH_3}$（手性碳为带 Me/Ph 的季碳），经**椅式六元环状过渡态**：σ 键（C3–C4）断裂、新 σ 键（C1–C6）生成，两个 π 键移位。
- 原子映射（本题核心考点——**手性中心"搬家"**）：原手性碳 C3 变为产物烯键碳（新双键 C2=C3，Me/Ph 上双键）；原右端双键碳 C6 变为产物的新手性碳（带 H、CH₃ 与两条链）。
- 产物骨架：$\mathrm{CH_2{=}CH{-}CH(CH_3){-}CH_2{-}CH{=}C(Ph)(CH_3)}$。椅式过渡态中大基团取 pseudo-equatorial，决定新手性中心的构型与产物三取代双键的 E/Z——四个选项恰为两者的 2×2 组合（见图），答案 B。
- **易错**：按"取代基原地不动"错误追踪原子（Cope 是 σ 键迁移、端基原子对调）；忽略椅式过渡态的构象偏好而随机挑构型。

**7-7（A）芳香性判据比较"碳氢酸"酸性**

- 判据：比较去质子后**共轭碱的稳定化**——负电荷若落入可芳香化的环系（环戊二烯负离子型 6π，或更大的 4n+2 整体离域体系），酸性强。
- 两化合物为稠合方式不同的稠环多烯同分异构体（见图）：A 中 sp³ CH 去质子后，负电荷所在环与相邻不饱和环系形成整体芳香离域，稳定化强；B 的稠合方式使去质子后的负电荷缺乏同等程度的芳香稳定化。
- 故 A 酸性较强。
- **易错**：只按"环戊二烯 CH"字面套 pKa ≈ 16，忽略稠合环境对共轭碱芳香性的修饰。
