# 赖氨酸的等电点与四种形态分布计算——三元酸模型与分布分数

## 题目

赖氨酸又名 2,6-二氨基己酸（简写 Lys，$\mathrm{C_6H_{14}N_2O_2}$），是一种人体必需氨基酸。它在水溶液中有 4 种分布形式，用 $\mathrm{H_2A^{2+}}$、$\mathrm{HA^{+}}$、A 和 $\mathrm{A^-}$ 表示（A 代表赖氨酸分子骨架，三级解离依次为—COOH、$\alpha$-$\mathrm{NH_3^+}$、$\varepsilon$-$\mathrm{NH_3^+}$）。

已知其三级解离常数：

$$
\mathrm{p}K_{\mathrm{a1}} = 2.18, \quad \mathrm{p}K_{\mathrm{a2}} = 8.95, \quad \mathrm{p}K_{\mathrm{a3}} = 10.50
$$

现配制赖氨酸水溶液，分析浓度 $c = 0.345\ \mathrm{mol \cdot L^{-1}}$。

(1) 计算赖氨酸的等电点 pI；

(2) 计算 pH = 9.60 时赖氨酸 4 种分布形式的平衡浓度。

## 参考答案

**答案**：

- pI = 9.72
- pH = 9.60 时：$[\mathrm{H_2A^{2+}}] \approx 0$，$[\mathrm{HA^{+}}] = 0.057\ \mathrm{mol/L}$，$[\mathrm{A}] = 0.256\ \mathrm{mol/L}$，$[\mathrm{A^-}] = 0.032\ \mathrm{mol/L}$

**详细推导**：

**第一步：确定等电点公式。** 净电荷为 0 的形态是 A（$\alpha$-$\mathrm{NH_3^+}$ 与—COO⁻ 成两性离子、$\varepsilon$-$\mathrm{NH_2}$ 未质子化），它分布在 $\mathrm{p}K_{\mathrm{a2}}$ 与 $\mathrm{p}K_{\mathrm{a3}}$ 之间，故赖氨酸（碱性氨基酸）的等电点：

$$
\mathrm{pI} = \frac{1}{2}\left(\mathrm{p}K_{\mathrm{a2}} + \mathrm{p}K_{\mathrm{a3}}\right) = \frac{1}{2}(8.95 + 10.50) = 9.72
$$

**第二步：写出 pH = 9.60 时的逐级比例。** $[\mathrm{H^+}] = 10^{-9.60}$：

$$
\frac{[\mathrm{A}]}{[\mathrm{HA^{+}}]} = \frac{K_{\mathrm{a2}}}{[\mathrm{H^+}]} = 10^{9.60 - 8.95} = 4.47, \qquad
\frac{[\mathrm{A^-}]}{[\mathrm{A}]} = \frac{K_{\mathrm{a3}}}{[\mathrm{H^+}]} = 10^{9.60 - 10.50} = 0.126
$$

$$
\frac{[\mathrm{H_2A^{2+}}]}{[\mathrm{HA^{+}}]} = \frac{[\mathrm{H^+}]}{K_{\mathrm{a1}}} = 10^{2.18 - 9.60} \approx 3.8 \times 10^{-8} \Rightarrow \delta(\mathrm{H_2A^{2+}}) \approx 0
$$

**第三步：按物料平衡解出各形态浓度。** 设 $[\mathrm{A}] = x$，则 $[\mathrm{HA^{+}}] = x/4.47$，$[\mathrm{A^-}] = 0.126x$：

$$
x\left(1 + \frac{1}{4.47} + 0.126\right) = 1.350x = 0.345 \Rightarrow x = 0.256
$$

即 $[\mathrm{A}] = 0.256$，$[\mathrm{HA^{+}}] = 0.0572$，$[\mathrm{A^-}] = 0.0322\ \mathrm{mol/L}$（分布分数 $\delta(\mathrm{A}) = 0.741$，$\delta(\mathrm{HA^{+}}) = 0.166$，$\delta(\mathrm{A^-}) = 0.093$）。

**第四步：电荷自洽校验。** pH = 9.60 略低于 pI = 9.72，平均净电荷应为小正值：

$$
\bar{z} = (+1) \times 0.166 + (-1) \times 0.093 = +0.073 > 0 \ ✓
$$

**易错点**：

- 等电点公式用错：$\frac{1}{2}(\mathrm{p}K_{\mathrm{a1}} + \mathrm{p}K_{\mathrm{a2}}) = 5.57$ 是两性形态 $\mathrm{HA^{+}}$ 的两性点，净电荷为 0 的形态是 A，赖氨酸的 pI 必须取 $\frac{1}{2}(\mathrm{p}K_{\mathrm{a2}} + \mathrm{p}K_{\mathrm{a3}})$
- 分布分数是比例，各形态浓度必须再乘分析浓度 $c$
- $\mathrm{H_2A^{2+}}$ 能否忽略要有依据：由 $[\mathrm{H_2A^{2+}}]/[\mathrm{HA^{+}}] = [\mathrm{H^+}]/K_{\mathrm{a1}} \approx 10^{-7.4}$ 直接说明

**评注（校勘注）**：源卷答案给 $[\mathrm{HA^{+}}] = 0.059\ \mathrm{mol/L}$，系将其分布分数粗化为 0.17 所致；精确计算 $\delta(\mathrm{HA^{+}}) = 0.166$，对应 0.057 mol/L（源卷 $[\mathrm{A}] = 0.26$、$[\mathrm{A^-}] = 0.032$ 与精确值一致）。本稿按精确值给出。
