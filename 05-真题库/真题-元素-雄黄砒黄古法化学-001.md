# 雄黄砒黄古法化学——砷硫化物推断与方程式书写

> **讲评定位**：以中国古代炼丹/冶金文献为情境的元素化学推断题。考查点不难，但**矿物别名→化学式**的转换和**合金组成的分数处理**是两个易错点，适合作为初赛元素化学的讲评开场题（5-8 分钟）。

## 题目

雄黄为 $\mathrm{As_4S_4}$，雌黄为 $\mathrm{As_2S_3}$，砒黄为 $\mathrm{As_2O_3}$，硫黄为硫单质。

**1.1.1** 写出雄黄"变"铁的反应方程式。

**1.1.2** 写出在木炭存在下，砒黄"变"铜的反应方程式（提示：含砷 5% 的砷铜合金是黄色的）。

---

## 解析

### 讲评思路（板书顺序）

1. **矿物别名破译**（学生常卡在这里）：雄黄 = $\mathrm{As_4S_4}$、砒黄 = $\mathrm{As_2O_3}$——建议先在黑板上列"古名-化学式"对照表
2. **1.1.1 关键**：铁的硫化物中呈"金色"的是 $\mathrm{FeS_2}$（黄铁矿，愚人金）——这是题目的隐含提示；As 被还原为单质
3. **1.1.2 关键**：① 木炭高温还原产物是 CO 不是 CO₂；② "变"铜 = As 溶入铜形成**合金**，不是生成砷化铜
4. **合金组成计算**：由 $\omega(\mathrm{As})=5\%$ 反推 $x$——训练"实验式→最简整数比"的基本功

### 参考答案

**1.1.1**
$$\mathrm{As_4S_4} + 2\mathrm{Fe} \longrightarrow 4\mathrm{As} + 2\mathrm{FeS_2}$$

**1.1.2**
$$\mathrm{As_2O_3} + 2x\mathrm{Cu} + 3\mathrm{C} \longrightarrow 2\mathrm{Cu}_x\mathrm{As} + 3\mathrm{CO}$$
由 $\omega(\mathrm{As}) = \dfrac{74.92}{74.92 + 63.55x} = 5\%$ 解得 $x \approx 22.4$，最简整数比：
$$5\mathrm{As_2O_3} + 224\mathrm{Cu} + 15\mathrm{C} \longrightarrow 2\mathrm{Cu_{112}As_5} + 15\mathrm{CO}$$

### 易错警示

| 易错点 | 纠正 |
|:--|:--|
| 雄黄写成 AsS | 原题明确给出 $\mathrm{As_4S_4}$ |
| 1.1.2 生成砷单质 | 提示已说明形成**砷铜合金** |
| C 的氧化产物写 CO₂ | 高温过量碳条件下产物为 CO |
