# 第34届决赛——CO2与磷镓化合物的 FLP 型 1:1 加成产物推断

## 题目

第 2 题 第(5)小问（2 分）

二氧化碳和如下图所示的化合物（Ar = 2,6-iPr₂C₆H₃）在甲苯中发生 1:1 加成反应；较之反应物，产物内的磷-磷键长变短而磷-镓键长变长。画出该产物的结构式。

![[97b21cadc3ea4eb52c5ab8d20c3cd54df6c0e2bb647cdc0d297a277382b32fb2.jpg]]

（底物结构：N(Ar)CH₂CH₂N(Ar) 五元环内的二氨基磷 P₁ 以 P–P 单键连 P₂，P₂ 与 Ga(nacnac)（β-二亚胺型配体）以 P₂=Ga 双键相连）

## 参考答案

**答案**（原卷评分标准答案图，2 分）：

![[8b452fcb149958048d19ee41e05f629b891ec660137507f963cbd68e34af87c7.jpg]]

产物为四元环加合物：CO₂ 以「C 端接 P₂、一个 O 端接 Ga」的方式插入，环序为 **P₂–C–O–Ga**（环上碳保留一个 C=O，闭合边为原有的 P₂–Ga 键）；同时 P₁–P₂ 升级为 **P₁=P₂ 双键**（变短），原 P₂=Ga 双键退化为 **P₂–Ga 单键**（变长）。

## 讲评

**底物：分子内「受阻 Lewis 酸碱对（FLP）」式的极性链**

- 骨架 P₁–P₂=Ga（P₁ 为五元环内二氨基磷）：P₂=Ga 键强极化——P 端富电子（δ⁻）、Ga 端缺电子（δ⁺，nacnac 配体稳定 Ga(III) 中心）。
- 于是同一分子内背靠背地埋着**亲核的磷端**与**亲电的镓端**，两者又被骨架「锁住」不能彼此完全淬灭——正是 FLP（frustrated Lewis pair，受阻 Lewis 酸碱对）活化小分子的经典构型。

**CO₂ 的 1:1 加成：电子会计**

1. CO₂ 的 C 是亲电中心：P₂ 端孤对进攻 C → 生成 **P₂–C 键**；CO₂ 的一个 π 电子对移向氧，氧端电子密度升高，随即配位到缺电子的 Ga 上 → 生成 **O–Ga 键**。P₂–C 与 O–Ga 连同环内原有的 P₂–Ga 闭合成**四元环 P₂–C–O–Ga**，环上碳保留一个 **C=O 双键**。
2. 与此同时，原 **P₂=Ga 双键的 π 电子对转移至 P₁–P₂ 之间**（与 P₁ 的孤对汇合），构成 **P₁=P₂ 双键**；P₂=Ga 双键退化为**单键**。
3. 净结果与题干两条键长信息严格互锁：
   - **P–P 键变短**：P₁–P₂ 由单键（σ）升级为双键（σ+π），键级 1 → 2；
   - **P–Ga 键变长**：P₂=Ga 由双键退化为单键，键级 2 → 1。

**易错**

- 把产物画成开链 P₂–C–O–Ga 而丢掉四元环闭合边 P₂–Ga——题干说「磷-镓键长**变长**」而非「断裂」，P–Ga 键必须保留；
- 漏掉 P₁=P₂ 双键升级——「P–P 键**变短**」是另一条硬约束，两条键长信息共同唯一锁定产物；
- 把 CO₂ 的两个 C=O 都打开——本题是 1:1 加成，碳上保留一个 C=O；
- 接反极性方向——亲核的磷端接 C、亲电的镓端接 O，不可颠倒。
