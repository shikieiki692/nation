# 海水中溶解 CO₂ 平衡浓度——电荷平衡与多平衡联立

## 题目

某 $CO_2$ 传感器的微液池内含 50.0 μmol·L⁻¹ 溴百里酚蓝指示剂（用 NaHIn 表示）和 42.0 μmol·L⁻¹ NaOH 溶液。海水中溶解的 $CO_2$ 透过选择性膜进入微池并达到解离平衡。已知（单位均为 mol·L⁻¹）：碳酸 $K_1 = 3.0\times10^{-7}$，$K_2 = 3.0\times10^{-11}$；指示剂 $K_{In} = 2.0\times10^{-7}$；$K_w = 6.7\times10^{-15}$。H₂In 与 H₂CO₃ 型体浓度均可忽略。

平衡时测得溶液 pH = 6.99（即 $[H^+] = 1.0\times10^{-7}$ mol·L⁻¹）。计算微池内海水中溶解的 $CO_2$ 的平衡浓度 $[CO_2(aq)]$。

## 参考答案

**答案**：$[CO_2(aq)] = 3.0\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$

**详细推导**：

**第一步：由 pH 分配指示剂型体（分布系数法）。**

$$
[HIn^-] = \frac{[H^+]}{[H^+] + K_{In}}\times c_{In} = \frac{1.0\times10^{-7}}{3.0\times10^{-7}}\times 50.0\ \mu mol\cdot L^{-1} = 17\ \mu mol\cdot L^{-1}
$$

$$
[In^{2-}] = \frac{K_{In}}{[H^+] + K_{In}}\times c_{In} = \frac{2.0\times10^{-7}}{3.0\times10^{-7}}\times 50.0\ \mu mol\cdot L^{-1} = 33\ \mu mol\cdot L^{-1}
$$

**第二步：把碳酸各型体用 $[CO_2(aq)]$ 表达。** 由一级、二级解离平衡：

$$
[HCO_3^-] = \frac{K_1[CO_2(aq)]}{[H^+]} = \frac{3.0\times10^{-7}}{1.0\times10^{-7}}\,[CO_2(aq)] = 3.0\,[CO_2(aq)]
$$

$$
[CO_3^{2-}] = \frac{K_1K_2[CO_2(aq)]}{[H^+]^2} = \frac{3.0\times10^{-7}\times 3.0\times10^{-11}}{1.0\times10^{-14}}\,[CO_2(aq)] = 9.0\times10^{-4}\,[CO_2(aq)]
$$

$$
[OH^-] = \frac{K_w}{[H^+]} = 6.7\times10^{-8}\ \mathrm{mol\cdot L^{-1}}
$$

**第三步：代入电荷平衡方程求解。**（$[Na^+] = 92.0\ \mu mol\cdot L^{-1}$，浓度统一为 mol·L⁻¹）

$$
92.0\times10^{-6} + 1.0\times10^{-7} = 3.0\,[CO_2] + 2(9.0\times10^{-4})[CO_2] + 17\times10^{-6} + 2(33\times10^{-6}) + 6.7\times10^{-8}
$$

$$
[CO_2(aq)] = \frac{(92.0 - 17 - 66)\times10^{-6} + 1.0\times10^{-7} - 6.7\times10^{-8}}{3.0018} \approx \frac{9.0\times10^{-6}}{3.0} = 3.0\times10^{-6}\ \mathrm{mol\cdot L^{-1}}
$$

**易错点**：

- 型体分配方向搞反：HIn⁻ 的分布系数分子是 $[H^+]$，In²⁻ 的是 $K_{In}$，两者之和才等于 $c_{In}$
- 电荷平衡中 33 μmol·L⁻¹ 的 In²⁻ 忘乘 2
- 把 H₂CO₃ 写进电荷平衡（中性分子不进）
- 分子分母单位不一致：μmol·L⁻¹ 与 mol·L⁻¹ 混算——建议先全部换算成 mol·L⁻¹
- 结果精度：CO₃²⁻ 项（2×9.0×10⁻⁴[CO₂]）相对 3.0[CO₂] 可忽略，说明结果对 $K_2$ 的取值不敏感；即使取 $K_2$ 有一成偏差，$[CO_2]$ 三位有效数字不变

**校勘注**：源卷解析中 $K_2$ 代入值（3.3×10⁻¹¹）与题给常数（3.0×10⁻¹¹）不一致，本稿统一按题给 $K_2 = 3.0\times10^{-11}$ 计算，结论不变。
