# LiO₂ 正当晶胞参数——密度公式与几何关系联立

## 题目

LiO₂ 晶体属正交晶系，密度为 2.217 g·cm⁻³。其结构中 Li⁺ 与双氧离子 O₂⁻（按离子质心计）交替排列：沿 b 轴方向 Li⁺ 与相邻 O₂⁻ 质心共线相接，Li–O₂ 间距为 239 pm；在 ac 平面内，Li⁺ 与最近的斜向 O₂⁻ 的位移分量为 $(a/2,\ c/2)$，距离为 252 pm。已知正当晶胞参数满足 $b > a > c$，且 $a$、$c$ 均小于 420 pm。

求 LiO₂ 晶体正当晶胞参数 $a$、$b$、$c$，并写出晶胞中 LiO₂ 单元数 $Z$。

## 参考答案

**答案**：a = 403 pm，b = 478 pm，c = 303 pm，Z = 2

**详细推导**：

**第一步：由密度求晶胞体积。** $M(\mathrm{LiO_2}) = 6.94 + 2\times16.00 = 38.94\ \mathrm{g\cdot mol^{-1}}$，由 $\rho = ZM/(N_A V)$：

$$
V = \frac{Z\times38.94}{6.022\times10^{23}\times 2.217}\ \mathrm{cm^3} = Z\times2.917\times10^{-23}\ \mathrm{cm^3} = Z\times2.917\times10^{7}\ \mathrm{pm^3}
$$

（1 cm = 10¹⁰ pm，1 cm³ = 10³⁰ pm³。）

**第二步：由几何关系表示 b 与 ac。** 沿 b 轴 Li⁺ 与 O₂⁻ 质心交替共线，相邻间距 239 pm，即

$$
b = 2\times239 = 478\ \mathrm{pm}
$$

ac 面内斜向接触给出

$$
\left(\frac{a}{2}\right)^2 + \left(\frac{c}{2}\right)^2 = 252^2 \;\Rightarrow\; a^2 + c^2 = 4\times252^2 = 254016\ \mathrm{pm^2}
$$

**第三步：用约束条件定 Z。** 晶胞体积还应满足 $abc = V$，即 $ac = V/b = Z\times2.917\times10^7/478 = Z\times6.10\times10^4\ \mathrm{pm^2}$。

- 若 Z = 1：$ac = 6.10\times10^4$，与 $a^2+c^2 = 254016$ 联立解得 a ≈ 488 pm、c ≈ 125 pm。此时 a > b = 478，违反 $b > a$ 且 a > 420，**舍去**。
- 若 Z = 2：$ac = 1.220\times10^5\ \mathrm{pm^2}$，联立

$$
(a+c)^2 = 254016 + 244060 = 498076 \Rightarrow a+c = 705.7
$$

$$
(a-c)^2 = 254016 - 244060 = 9956 \Rightarrow a-c = 99.8
$$

解得 **a = 402.8 ≈ 403 pm，c = 302.9 ≈ 303 pm**。检验：b(478) > a(403) > c(303)，且 a、c < 420 pm，全部约束满足 ✓

**易错点**：

- 不加验证地取 Z = 1——Z 必须用几何与密度联立后以题面约束（b > a > c、a < 420）检验定出
- 单位换算：1 cm³ = 10³⁰ pm³，把 2.917×10⁻²³ cm³ 误写成 2.917×10⁴ pm³（差 10³ 倍）会导致 ac 偏小一半以上，只能靠错数硬凑
- 把 Li–O₂ 距离直接当晶胞参数（b = 239 或 252）——距离与参数之间隔着结构几何（共线 2 倍、面对角位移）
- 平方关系记错：252 pm 是对角位移长度，等式是 $(a/2)^2+(c/2)^2 = 252^2$，展开后别丢系数 4

**校勘注**：源卷解析按"Z = 1、V = 2.917×10⁴ pm³"推演，数值与单位均有误（该假设解出的 a、c 违反题面约束），但最终答案数字与正确解一致。本稿按 Z = 2 重新推演，过程自洽。
