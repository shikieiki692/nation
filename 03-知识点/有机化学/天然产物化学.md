# 天然产物化学

## 一、定位

天然产物化学关注**自然界来源的复杂有机分子**：它们的生物合成来源、碳骨架特征、官能团/手性布局，以及"如何得到它们"（提取、全合成、半合成、仿生合成）。对竞赛而言，天然产物是**综合应用题的最佳载体**——一个分子同时考家族识别（萜/生物碱/聚酮…）、官能团化学（过氧桥、内酯、烯胺…）、立体化学（多手性中心）、生源逻辑（异戊二烯/乙酸/莽草酸途径）与逆合成分析。约 50% 上市药物直接或间接源自天然产物（青蒿素、紫杉醇、吗啡），学习它的价值远超"背几个分子"。

## 二、学习重点

- 从**骨架与生源单元**识别天然产物家族（数 C5 单元辨萜类、找含氮杂环辨生物碱、看羰基交替辨聚酮）。
- 关注**构型、官能团密度与后期修饰**（手性中心数目、药效团、代谢位点）。
- 与 [[天然产物合成]]、[[逆合成分析]] 的策略题结合：天然产物题常以"给结构→设计合成"收尾。

## 三、核心原理

### 3.1 天然产物家族分类（先背这张表）

| 家族 | 生源单元 | 碳骨架/结构特征 | 代表 |
|:---|:---|:---|:---|
| 萜类 | 异戊二烯单元（C5，头尾相连） | 骨架碳数常为 5 的倍数（单萜 C10、倍半萜 C15、二萜 C20、三萜 C30）；可环化 | 樟脑、青蒿素（倍半萜内酯）、β-胡萝卜素（四萜 C40） |
| 生物碱 | 氨基酸（鸟氨酸/赖氨酸/苯丙氨酸等） | 含碱性氮、常为含氮杂环 | 吗啡、奎宁、咖啡因、毒芹碱 |
| 聚酮 | 乙酸/丙酸单元（Claisen 缩合延伸） | 羰基/羟基交替排列（–C–C(=O)–C–C(=O)– 模式） | 红霉素、四环素、他汀类 |
| 苯丙素/木脂素 | 苯丙氨酸/桂皮酸 | C6–C3 骨架；香豆素/木质素 | 肉桂酸、香豆素、鬼臼毒素 |
| 甾体/三萜 | 异戊二烯（角鲨烯环化） | 四环稠环（环戊烷并多氢菲） | 胆固醇、性激素、地塞米松 |
| 脂肪酸衍生物 | 乙酰 CoA | 长链羧酸、前列腺素型环戊烷 | 前列腺素、白三烯 |

### 3.2 生源逻辑：天然产物结构不是随机

- **萜类**：异戊二烯规则（C5 头尾连接）→ 单萜/倍半萜…再经阳离子环化（如角鲨烯 → 羊毛甾醇）生成多环骨架——"数异戊二烯单元"是判断萜类的第一步。
- **生物碱**：由氨基酸脱羧/转氨得含氮骨架，再经 Mannich/ Pictet–Spengler 等缩合关环（[[莽草酸途径]] 供芳香氨基酸前体）。
- **聚酮**：乙酸/丙二酸单元经 Claisen 型延伸与还原/脱水/环化，得聚-β-羰基链 → 大环内酯/芳香聚酮。
- 生源逻辑价值：逆合成时"仿生切断"（找异戊二烯单元/乙酸单元/氨基酸残基）常给出最简洁的合成思路。

### 3.3 结构特征三高

- **手性中心多**：紫杉醇 11 个、青蒿素 7 个——全合成的立体控制是核心难题（不对称催化试金石）。
- **官能团密度高**：同一分子含酯/醚/醇/过氧/烯烃等，要求化学选择性（保护基策略）。
- **环系复杂**：桥环（樟脑）、螺环、稠环（甾体）、过氧桥（青蒿素）——合成难点常在"成环方式"。

### 3.4 获取策略四类

1. **提取分离**：天然来源直接提取（青蒿素传统工艺）；依赖来源充足。
2. **全合成**：从简单原料按逆合成构建——价值在来源不足时供药（紫杉醇全合成里程碑：Nicolaou/Holton）与检验新反应。
3. **半合成**：以天然产物为原料做结构修饰/改造——工业常用（青蒿酸 → 青蒿素/衍生物，紫杉醇侧链改造）。
4. **仿生合成**：模拟生源路径（阳离子环化、聚酮链组装、生物碱缩合）——高效且启发新策略。

### 3.5 结构与活性（药效团思维）

- 活性常集中在少数关键基团：青蒿素的**过氧桥**（抗疟药效团）、紫杉醇的侧链与环系（微管稳定）、青霉素的 β-内酰胺。
- 药物化学思路 = 识别药效团 → 修饰外围（增溶解/代谢稳定）→ 半合成/全合成供给——天然产物题与药物化学在此交汇。

## 四、关键结论

- 家族识别三问：骨架碳数是不是 5 的倍数？（萜）；含不含碱性氮？（生物碱）；有没有羰基-羟基交替？（聚酮）。
- 生源单元（C5 异戊二烯、C2 乙酸、氨基酸）是结构与逆合成的"路标"。
- 三高特征（多手性/高官能团密度/复杂环系）决定合成策略与考点分布。
- 四条获取路线（提取/全合成/半合成/仿生）按来源与目的选择。
- 活性看药效团，修饰看药物化学——天然产物是"结构→活性→合成"的完整叙事。

## 五、常见分类或情形

- **按家族**：萜类、生物碱、聚酮、苯丙素、甾体、脂肪酸类（见 3.1 表）。
- **按题型**：家族判断、生源切断（逆合成）、结构-活性分析、路线设计（全合成/半合成/仿生）。
- **按难度梯度**：初赛（家族识别+简单转化）、决赛（完整逆合成/多步设计、真题如 Clayden 35/42 素材）。
- **按代表分子**：青蒿素（倍半萜内酯+过氧桥）、紫杉醇（二萜类+复杂环系）、吗啡/奎宁（生物碱）、红霉素（大环内酯聚酮）、胆固醇（甾体）。

## 六、适用条件与限制

- 家族判断需先确认生源：分子式含 N 不一定是生物碱（酰胺/硝基也含 N）——看碱性氮与杂环。
- 骨架碳数为 5 的倍数不绝对（重排/降解会偏离）——萜类判断要结合异戊二烯亚结构。
- 天然产物题信息量大：先画骨架/标官能团再动笔，防止漏手性中心或官能团。
- 全合成路线设计无唯一答案：评分看切断合理性、官能团兼容与步骤经济性。
- 药效团分析需文献背景：题内会提示关键基团，勿自行臆断活性来源。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 含氮 = 生物碱 | 生物碱是"碱性含氮天然产物"（杂环胺）；酰胺/硝基/季铵盐类不算——看氮的碱性 |
| 萜类只看 C 数倍数 | 还需找异戊二烯亚结构（C5 头尾）并考虑重排/降解；角鲨烯 C30 是三萜前体而非单萜×6 直链 |
| 聚酮 vs 脂肪酸 | 都源于乙酸单元，但聚酮保留羰基-羟基交替并高度环化/芳构化（红霉素）；脂肪酸是还原饱和的长链 |
| 全合成 vs 半合成 | 全合成从简单原料构建全部骨架；半合成从天然产物出发修饰——紫杉醇用半合成（10-DAB 前体）更现实 |
| 仿生 vs 仿制 | 仿生合成=按生源反应（阳离子环化/聚酮组装）模拟酶逻辑设计路线，是"借自然的策略"不是简单复制结构 |

## 九、典型题型

- **家族判断**：给结构判断萜/生物碱/聚酮并说明依据（数 C5/找碱性氮/看羰基交替）。
- **生源切断**：用异戊二烯单元/乙酸单元"仿生"地切断复杂分子，简化逆合成。
- **路线设计**：青蒿素/紫杉醇类——比较全合成/半合成/仿生可行性并写关键步。
- **结构-活性**：识别药效团（过氧桥等）与可修饰位点。
- **真题综合**：Clayden 42 章生命化学与历届决赛天然产物合成题（骨架识别+机理+合成混合）。

## 十、例题

**例题 1**：青蒿素（Artemisinin）属于哪类天然产物？结构中有什么关键官能团？为何它是"半合成"的代表？

**解答**：青蒿素是**倍半萜内酯**（sesquiterpene lactone，15 个碳 = 3 个异戊二烯单元，含 δ-内酯）。最特殊的官能团是**过氧桥（–O–O–）**——抗疟药效团。全合成步骤多、总产率低；工业采用**半合成**：从青蒿提取青蒿酸（artemisinic acid）再经化学转化引入过氧桥制青蒿素或其衍生物，兼顾来源与成本——这就是"半合成解决天然来源不足"的典型。

**例题 2**：判断下列分子家族：①含 20 个碳、骨架可拆成 4 个 C5 片段；②含哌啶环与碱性 N、生源来自赖氨酸；③链上羰基与羟基交替并已关大环内酯。

**解答**：①二萜类（20 = 4×5，异戊二烯单元头尾相连）；②生物碱（哌啶类生物碱，如毒芹碱/胡椒碱类，氨基酸生源）；③聚酮大环内酯（乙酸/丙酸单元 Claisen 延伸后还原/关环——红霉素型）。识别依据分别对应 C5 计数、碱性氮杂环、羰基交替三大特征。

**例题 3**：给一个复杂天然产物目标，说明逆合成设计的总体思路（以萜类为例）。

**解答**：①先家族识别与生源分析：萜类按 C5 单元找异戊二烯亚结构，考虑可能的阳离子环化切断；②切"战略键"：优先切可由 Diels-Alder、Cope/Claisen、Aldol/Michael、偶联等可靠反应构建的键；③官能团化逻辑：把复杂官能团还原为简单前体（内酯←羟基酸、过氧桥←H₂O₂ 引入）；④对照生源途径找仿生路线（环化顺序与酶逻辑一致常最短）；⑤最后评估手性来源（天然手性池/不对称催化/拆分）。全合成题按此框架逐层展开即可得大部分分数。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 见氮就说生物碱 | 生物碱的 N 须是**碱性**并常在杂环中；酰胺氮（青霉素）、硝基不具碱性 | 反例：青蒿素无氮是萜；含 –CONH– 的分子不一定是生物碱——先测 N 的碱性环境 |
| 只数碳就定萜类 | 骨架碳 15/20 且可拆 C5 才算萜；重排/降解/含氧取代会"破环"简单倍数 | 判别：找异戊二烯亚结构（借位的甲基与双键模式），不只看总数 |
| 忽略官能团与立体 | 天然产物题漏数手性中心或漏标官能团（内酯/过氧/烯醚）导致后续全错 | 自检：先圈出所有官能团与手性碳再作答；路线设计要照顾每个官能团 |
| 全合成与半合成混用 | 全合成=从简单原料全部搭建；半合成=天然产物修饰——紫杉醇工艺是半合成 | 判别：题给"以天然来源 X 为原料修饰"→半合成；"从苯/简单原料构建"→全合成 |
| 药效团乱猜 | 活性基团（如过氧桥）由题/文献给定；不看提示自造"关键基团"易错 | 判别：结构-活性题先找题内提示（"研究表明 X 基团是活性必需"）再分析 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
天然产物化学应在掌握各类官能团反应与基本合成策略之后学习。建议先背熟家族分类表（萜/生物碱/聚酮/苯丙素/甾体），再学异戊二烯规则等生源逻辑，然后用"给结构→家族判断→关键官能团→逆合成设计"的流程练综合题，最后以青蒿素/紫杉醇案例建立药物与半合成视角。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为天然产物就是"复杂的有机分子" | 天然产物有规律可循：萜类来自异戊二烯单元、生物碱含碱性氮杂环、聚酮来自乙酸单元 |
| 忽略天然产物的生物合成逻辑 | 结构反映酶催化逻辑（Mannich/Claisen/阳离子环化），理解生源可简化结构分析 |
| 认为天然产物合成只是"模仿自然" | 全合成/半合成解决天然来源不足并支撑新药（紫杉醇、青蒿素衍生物）——有明确的药学价值 |
| 含氮即生物碱 | 须看氮的碱性/杂环环境，酰胺/硝基不算 |

### 12.3 入门级例题
**题目**：青蒿素属于哪类天然产物？其结构中有什么特殊官能团？

**解答**：青蒿素属于倍半萜内酯。最特殊的是过氧桥（–O–O–），这是抗疟活性的关键药效团。青蒿素含 7 个手性中心，全合成复杂，工业用半合成（青蒿酸转化）实现。

### 12.4 与现实世界的联系
- **药物发现**：约 50% 上市药物直接或间接源于天然产物（青蒿素抗疟、紫杉醇抗癌、吗啡镇痛）。
- **食品工业**：薄荷醇、香兰素、甜菊糖苷、类胡萝卜素等香料/甜味剂/色素均为天然产物。
- **农药开发**：除虫菊酯启发拟除虫菊酯类农药；天然产物仍是新农药先导的重要来源。
