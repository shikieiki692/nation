# 有机合成

## 一、定义

**有机合成**是从可得原料出发，通过一系列反应构建目标分子（TM）的过程。设计合成路线的系统方法是 **逆合成分析（retrosynthetic analysis）**：由 E.J. Corey 提出，**从目标分子出发逆向分析，直到可购买的起始原料**——因为产物是固定不可改变的，正向拼凑容易走弯路。

逆合成使用**双线开尾箭头 ⇏**，读作"可由……制得"，表示一个真实反应的逆过程。

## 二、考纲对应

- 对应考纲条目：50-有机合成
- 所属模块：基础要求-有机化学
- 作用：有机合成是有机化学的综合应用层——初赛考路线设计与中间体推断，决赛考多步全合成策略。逆合成分析是所有合成题的统一思维框架。

## 三、核心原理

### 3.1 术语体系（Clayden §28）

| 术语 | 定义 |
|:---|:---|
| 目标分子（TM） | 待合成的分子 |
| 切断（disconnection） | 想象的键断裂，对应一个真实反应的逆过程；用波浪线标出位点 |
| 合成子（synthon） | 切断得到的理想化碎片，带 "+" / "−" 极性标记 |
| 合成等价物 | 对应合成子的实际试剂（如酰基合成子 MeCO⁺ 的等价物是酰氯或酸酐） |
| FGI（官能团互变） | 不断键，把一个官能团转化为另一个的逆合成操作（氧化、还原、取代三类） |

### 3.2 切断五准则

1. **切断必须对应已知、可靠的反应**——最重要的准则；每个切断都要有一个产率良好的正向反应撑腰。
2. **两个片段通过杂原子相连的化合物，在杂原子旁切断**（酯、酰胺、醚、胺、缩醛、硫醚都适用，都对应取代反应）。
3. **避免化学选择性问题**——比较可替代的切断方式；通常把活泼基团的引入放在合成后期。
4. **尽可能用双官能团切断**——比单官能团切断更有效地简化分子；两个官能团的 1,2-/1,3-/1,5-关系决定可用策略。
5. **先转化为氧基官能团再做 C-C 切断**——醇/醛/酮/酯/酸之间极易通过氧化还原或取代互变；遇到陌生官能团，先 FGI 成相同氧化程度的氧基形态。

### 3.3 C-X 切断要点

- **醚**：在 C–O 的烷基一侧切断（芳基侧亲核取代不可靠）。合成子 = 烷氧负离子 + 卤代烷。
- **胺**：直接烷基化有多烷基化危险，两条 FGI 路线——①胺 → 酰胺 → 切断 C–N → 酰氯 + 胺 → 还原；②还原胺化：胺 → 亚胺 → 醛/酮 + 胺 → NaCNBH₃ 或催化氢化还原。
- **酯**：切断羰基 C–O 键 → 羧酸（或酰氯/酸酐）+ 醇。
- **硫醚**：S–C(烷基) 侧切断，对应硫醇盐对卤代烷的 SN2。

### 3.4 C-C 切断要点

- **炔烃旁切断**：炔负离子烷基化是可靠反应；炔还是烯烃的"中转站"（Lindlar 顺式 / Na/NH₃ 反式还原）——含孤立双键的 TM 常先 FGI 为炔。
- **1,2 C-C 切断**（羰基 α 位成键）：烯醇盐 + 卤代烷；丙二酸酯/乙酰乙酸酯合成法（先烷基化再脱羧）。
- **1,1 C-C 切断**：格氏试剂对羰基加成；含两个相同基团的叔醇用 2 当量格氏 + 酯。**注意格氏对酮会继续加成，酮的 1,1-切断通常不可靠。**

### 3.5 双官能团切断速查表（核心！）

| TM 中官能团关系 | 想到的反应 | 合成子组合 |
|:---|:---|:---|
| 1,3-二氧（β-羟基羰基、α,β-不饱和羰基） | **羟醛反应（Aldol）** | d² + a¹ |
| 1,3-二酮 | **Claisen 酯缩合** | d² + a¹（酯氧化程度） |
| 1,3-氨基酮/醇 | **Mannich 反应**（或腈的羟醛 + 还原） | — |
| 1,5-二羰基 | **Michael 加成** | d² + a³ |
| 1,2-双官能化 | 环氧作 a² 合成子；烯烃双羟基化/环氧化 | — |
| 1,4-双官能化 | **需极性反转**（d¹ 或 a⁴ 策略）；苯 + 环状酸酐 F-C 酰基化可规避 | d¹+a¹ / a¹+a⁴ |

**编号规则**：数字表示位点与官能团的相对位置；受体 a 用奇数（a¹, a², a³），给体 d 用偶数（d², d³）。**d¹ 和 a² 是"非天然"反应性**，需极性反转试剂实现。

### 3.6 极性反转（Umpolung）

羰基化合物的自然反应性沿碳链交替（a¹-d²-a³…）。**极性反转**把天然反应性颠倒，是 1,2- 和 1,4-双官能化化合物合成的关键：

- **d¹ 合成子**（酰基碳变亲核）：CN⁻、二噻烷、硫缩醛
- **a² 合成子**（α-碳变亲电）：α-卤代羰基化合物、环氧
- **a⁴ 合成子**：α-溴代羰基化合物

### 3.7 起始原料经验法则

> 至多含 **6 个碳原子 + 1 个官能团**（醇、醛、酮、酸、胺、双键或卤代烃）的化合物通常是可购买的；直链化合物可到约 8 个碳。常用双官能团起始原料：丙二酸酯、乙酰乙酸酯、1,3-二羰基化合物。

逆合成分析给出的是**多条候选路线**，最后靠文献检索和实验逐条削减——"最好的路线不能被精确预测"（Clayden）。

## 四、关键结论

1. 逆合成 = 从 TM 倒推到可买原料；正向拼凑易走弯路。
2. 每个切断必须对应可靠正向反应——切断是"逆向想象"，可行性由正向保证。
3. 双官能团关系是路线的"指纹"：见 1,3 想羟醛/Claisen/Mannich，见 1,5 想 Michael。
4. FGI（氧化/还原/取代）与切断交替使用；陌生官能团先换成氧基形态。
5. 1,2-、1,4-关系需要极性反转思维（Umpolung）。
6. 好路线兼顾步骤数、产率、选择性与可放大性；产率 80% 的 3 步优于产率 30% 的 2 步。

## 五、常见比较与易混点

| 易混点 | 辨析 |
|:---|:---|
| 逆合成箭头 vs 普通反应箭头 | ⇏ 表示"可由……制得"（逻辑逆向）；→ 表示实际反应方向，不可混用 |
| 合成子 vs 试剂 | 合成子是理想碎片（如 MeCO⁺），试剂是它的等价物（酰氯/酸酐），写合成路线最终要落到试剂 |
| FGI vs 切断 | FGI 不断键只换官能团；切断断键拆骨架。两者交替使用 |
| 酮的格氏 1,1-切断 | 格氏对酮加成不停，要制叔醇应对酯用 2 当量格氏 |
| 1,4-关系用普通烯醇盐切断 | 1,4-是"非天然"极性组合，必须极性反转试剂 |

## 八、例题

### 例题 1（逆合成入门）

**题目**：用逆合成分析设计从苯合成苯甲酸的路线。

**解答**：苯甲酸 C₆H₅COOH ⇏（羧基由烷基氧化而来，FGI）甲苯 C₆H₅CH₃ ⇏（Friedel-Crafts 烷基化切断）苯 + CH₃Cl。正向：苯 + CH₃Cl/AlCl₃ → 甲苯 → KMnO₄ 氧化 → 苯甲酸。

**反思**：芳香酸的逆合成通式是"先切断侧链到烷基苯"，羧基本身不是切断出来的，是氧化 FGI 出来的。

### 例题 2（1,3-关系识别）

**题目**：目标分子为 α,β-不饱和酮 PhCH=CHCOCH₃，如何逆合成？

**解答**：α,β-不饱和羰基 ⇏（FGI 加水回到 β-羟基羰基）PhCH(OH)CH₂COCH₃ ⇏（**1,3-二氧切断 → 羟醛反应**，d² + a¹）CH₃COCH₃ 的烯醇盐 + PhCHO。正向：苯甲醛 + 丙酮在碱催化下羟醛缩合并脱水即得。

## 九、易错点

1. **切断不对应真实反应**：想象中的断键必须有正向反应支撑，否则路线不可行。
2. **忽略多烷基化**：胺的直接烷基化几乎必失控，须走酰胺或还原胺化 FGI。
3. **在芳环侧切断 C–O**：芳香亲核取代不可靠，醚一律在烷基侧切断。
4. **见到 1,4-关系硬用羟醛**：1,4-需要极性反转（如 α-溴代羰基、CN⁻、二噻烷）。
5. **忘查原料可得性**：路线终点必须落在可购买的起始原料（≤6C + 1 官能团经验法则）。

## 十、🎯 教学视角

### 10.1 学习路径建议

有机合成应在掌握各类官能团反应和反应机理之后学习，是有机化学的综合应用。先学逆合成的术语与箭头语言（TM、⇏、切断、合成子、FGI），再背熟双官能团关系速查表（1,3→羟醛/Claisen/Mannich，1,5→Michael），然后通过药物中间体案例（普萘洛尔、多匹可明等）体会五准则，最后过渡到多步合成练习。

### 10.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为合成就是"正向拼凑" | 逆合成分析（从产物倒推原料）是设计合成路线的正确思维方式，正向思维容易走弯路 |
| 忽略保护基策略 | 多官能团分子的合成需要选择性保护不需要反应的官能团，否则会得到复杂混合物 |
| 只追求步骤少不考虑可行性 | 好的合成路线需要兼顾步骤数、产率、选择性和可放大性 |
| 切断位置随便选 | 切断必须对应已知可靠反应，且优先考虑双官能团切断和杂原子旁切断 |

### 10.3 入门级例题

**题目**：乙酸乙酯 CH₃COOCH₂CH₃ 如何逆合成？正向是什么反应？

**解答**：酯是两个片段经氧原子相连 → 准则 2 在杂原子旁切断 → CH₃CO⁺（酰基合成子，等价物乙酰氯/乙酸）+ ⁻OCH₂CH₃（乙醇）。正向：乙酸 + 乙醇酸催化酯化（或乙酰氯 + 乙醇）。

**引导提问**：学生掌握后追问"如果是苯甲酸乙酯，切断位置变不变？为什么？"（不变，仍在 C(=O)–O 键；但若是苯基醚 Ph–O–R，就要切烷基侧了。）

### 10.4 与现实世界的联系

- **药物全合成**：紫杉醇、青蒿素等天然产物的全合成是有机合成的巅峰挑战，推动了新反应和新策略的发展
- **工业制药**：从简单原料到药物分子的工业路线设计，每一步都体现逆合成思想
- **Corey 的贡献**：逆合成分析获 1990 年诺贝尔化学奖，是现代合成化学的通用语言
