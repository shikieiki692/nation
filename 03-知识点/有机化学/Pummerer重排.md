# Pummerer重排

## 一、反应概述

Pummerer重排（1909年）是亚砜（R-SO-R'）在酸性酐或酰氯作用下，α-碳上失去一个质子，重排生成α-酰氧基硫醚的反应。

**一句话记忆**：亚砜在酸酐作用下，氧走了，α-碳上多了个酰氧基。

## 二、反应通式

$$\ce{R-SO-CH2-R' ->[Ac2O] R-S-CH(OAc)-R'}$$

**典型条件**：Ac₂O（乙酸酐）或 TFAA（三氟乙酸酐）加热

## 三、机理要点

### 3.1 经典机理（三步）

1. **活化**：亚砜氧进攻酸酐羰基，形成硫鎓中间体
2. **去质子化**：α-氢被邻近正电荷硫活化，失去α-H形成硫叶立德（或硫鎓叶立德）
3. **[2,3]-σ迁移重排**：乙酸根从硫迁移到α-碳，同时S-O键断裂

$$\ce{R-S^{+}(OAc)-CH2-R' ->[-H^{+}] R-S^{+}=CH-R' <=> R-S-CH^{-}-R'}$$
$$\ce{->[2,3-重排] R-S-CH(OAc)-R'}$$

### 3.2 关键中间体

- **硫鎓离子**（R-S⁺-OAc）：氧被酰化后离去
- **硫叶立德**（R-S=CH-R'）：α-碳具有亲核性
- **[2,3]-σ迁移**：同步的协同过程，立体化学保持

### 3.3 变体

| 变体 | 条件 | 产物 |
|:---|:---|:---|
| 经典Pummerer | Ac₂O | α-酰氧基硫醚 |
| Modified Pummerer | TFAA + 吡啶 | α-三氟甲基硫醚 |
| Pummerer-type | NCS/NBS | α-卤代硫醚 |
| Pummerer/串联 | 分子内捕获 | 环化产物 |

## 四、竞赛要点

### 4.1 与Swern氧化的关系

Pummerer重排与Swern氧化共享中间体——**氯化亚砜鎓离子**（R-S⁺-Cl）和**硫叶立德**。理解了Pummerer重排的机理，就能理解Swern氧化为什么会生成醛/酮（而非停留在α-酰氧基硫醚阶段）。

**关键区别**：
- Swern氧化：硫叶立德被DMSO中的氧捕获 → 醛/酮
- Pummerer重排：硫叶立德被酸酐/卤素捕获 → α-取代硫醚

### 4.2 竞赛中出现的场景

1. **多步合成中的硫化学步骤**：涉及亚砜作为中间体
2. **机理推断题**：给出亚砜→α-取代硫醚的转化，要求写出机理
3. **与[2,3]-σ迁移的关联**：Pummerer重排是[2,3]-σ迁移的经典实例

### 4.3 逆合成应用

在逆合成分析中，Pummerer重排可用于：
- 在α-位引入官能化（OAc、卤素等）
- 构建含硫杂环（分子内Pummerer）

## 五、易错点

1. **不是[1,2]-迁移**：Pummerer重排是**[2,3]-σ迁移**，不是1,2-迁移
2. **α-氢是必须的**：没有α-氢的亚砜不发生Pummerer重排
3. **酸酐不能省略**：单纯的加热不能引发Pummerer，需要酸酐/酰氯活化
4. **立体化学**：[2,3]-迁移是协同过程，保留立体化学

## 六、教学视角

**核心教学价值**：Pummerer重排是含硫有机化学的核心反应之一，展示了硫的特殊化学性质（可极化性、d轨道参与、叶立德化学）。

**与其他KP的关联**：
- 与 [[Swern氧化]] 共享硫叶立德中间体
- 与 [[1,2-迁移与重排]] 中[2,3]-σ迁移类型对应
- 与 [[含硫化合物]] 中亚砜/硫醚的化学性质关联

### §8.1 Pummerer重排竞赛相关真题与应用

**竞赛考查角度**：
1. **基础机理书写**：写出亚砜→α-酰氧基硫醚的完整Pummerer重排机理（19届决赛）
2. **产物预测**：给定亚砜结构，预测Pummerer重排产物（35-37届初赛相关变体）
3. **Tandem反应设计**：Pummerer/Mannich串联反应构建含氮杂环（IChO训练题）

**Modified Pummerer（TFAA条件）竞赛应用**：

经典Pummerer使用Ac₂O，而Modified Pummerer使用TFAA（三氟乙酸酐），显著提高反应活性：

| 条件 | 亲电试剂 | 活性 | 竞赛应用 |
|:---|:---|:---:|:---|
| 经典Pummerer | Ac₂O | ★★ | 亚砜→α-酰氧基硫醚 |
| Modified Pummerer | TFAA | ★★★★ | 亚砜→α-三氟乙酰氧基硫醚，可进一步水解 |
| Pummerer/Mannich串联 | TFAA + 胺 | ★★★ | 合成α-氨基硫醚，天然产物全合成关键步骤 |
| Pummerer/aldol串联 | TFAA + 醛 | ★★★ | 构建1,3-含氧化合物 |

**关键考点**：TFAA条件下的Modified Pummerer因CF₃CO离去能力更强，可在更低温度下进行，且中间体硫鎓离子更活泼，有利于与弱亲核体反应（如吲哚C3位进攻），这在竞赛全合成题中常作为关键步骤出现。
