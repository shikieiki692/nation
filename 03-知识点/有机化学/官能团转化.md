# 官能团转化

## 一、定位

官能团转化是有机合成的基本动作，核心是把当前官能团变成“下一步更有用”的官能团。

## 二、学习重点
- 明确每种官能团最常见的进出路径
- 先看兼容性，再看步数与选择性
- 结合逆合成去判断哪一步最值得先做

## 🎯 教学视角

### 学习路径建议

官能团转化（FGI）应在掌握各类官能团基本反应之后学习，是逆合成分析的核心工具。建议先建立"官能团转化网络图"，将醇、醛酮、羧酸、胺、卤代烃之间的常见转化路径可视化，再通过合成练习强化应用能力。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为任何官能团都可以直接互相转化 | 许多转化需要多步（如羧酸→醛需先还原为醇再温和氧化），不能一步到位 |
| 忽略官能团转化中的选择性问题 | 同一分子中有多个官能团时，需考虑化学选择性（哪个官能团先反应）和保护基策略 |
| 只看正向合成不看逆合成 | 逆合成分析（从目标分子倒推）是设计合成路线的正确思维方式，正向思维容易走弯路 |

### 入门级例题

**题目**：设计一条从苯酚到水杨酸（邻羟基苯甲酸）的合成路线。

**解答**：苯酚 → 邻羟基苯甲醛（Reimer-Tiemann反应：CHCl₃/NaOH）→ 水杨酸（氧化：KMnO₄ 或 Ag₂O）。关键步骤是引入醛基（官能团转化：-OH → -CHO），再氧化为羧酸（-CHO → -COOH）。

### 与现实世界的联系

- **全合成设计**：紫杉醇、青蒿素等天然产物的全合成核心就是官能团转化的精巧安排
- **工业制药**：从简单原料到药物分子的工业路线设计，每一步都是官能团转化的实际应用
- **生物合成**：生物体内的代谢通路（如糖酵解）本质上也是一系列酶催化的官能团转化
