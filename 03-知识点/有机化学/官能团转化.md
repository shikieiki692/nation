# 官能团转化

## 一、定位

官能团转化是有机合成的基本动作，核心是把当前官能团变成“下一步更有用”的官能团。

## 二、学习重点
- 明确每种官能团最常见的进出路径
- 先看兼容性，再看步数与选择性
- 结合逆合成去判断哪一步最值得先做

## 三、核心原理

### 3.1 官能团转化网络

下表汇总了有机合成中最常见的官能团转化路径及对应试剂。掌握这张"地图"是合成设计的基本功：每条箭头都是一个已知反应，合成路线就是把这些箭头串联起来。

| 起始官能团 | 目标官能团 | 常用试剂/条件 | 备注 |
|:---|:---|:---|:---|
| 醇 R-OH | 醛 R-CHO | PCC（吡啶氯铬酸盐）；Swern 氧化（DMSO/(COCl)₂, Et₃N）；Dess-Martin 高碘烷 | PCC 在 CH₂Cl₂ 中反应，停在醛阶段，不继续氧化为酸；Dess-Martin 条件温和，对敏感底物友好 |
| 醇 R-OH | 酮 R₂C=O | Jones 试剂（CrO₃/H₂SO₄）；Swern 氧化；Dess-Martin | 仲醇氧化只能得到酮 |
| 醛 R-CHO | 醇 R-CH₂OH | NaBH₄（甲醇/乙醇溶剂）；LiAlH₄（无水乙醚，后处理酸性淬灭） | NaBH₄ 是实验室最常用的温和还原剂，选择性好（见3.4）；LiAlH₄ 还原性更强，能还原酯、羧酸、酰胺 |
| 酮 R₂C=O | 醇 R₂CHOH | NaBH₄；LiAlH₄ | 产物为仲醇；若需手性醇可用 CBS 催化剂或酶催化不对称还原 |
| 醇 R-OH | 卤代烃 R-X | HX（X = Br, I）；SOCl₂（氯化亚砜）；PBr₃ | SOCl₂ 适用于从醇制氯代烃（SNi 机理，构型保持）；PBr₃ 适用于制溴代烃（构型翻转） |
| 醛 R-CHO | 羧酸 R-COOH | KMnO₄（碱性/酸性）；Tollens 试剂（Ag₂O/NH₃·H₂O）；Jones 试剂 | Tollens 试剂选择性氧化醛基，不氧化醇；KMnO₄ 氧化性强，需注意其他官能团的兼容性 |
| 酮 R₂C=O | 羧酸（断裂 C-C） | Baeyer-Villiger 氧化（mCPBA）→ 酯水解 | 酮的 C-C 键断裂通常需要先 Baeyer-Villiger 插氧成酯，再水解 |
| 羧酸 R-COOH | 酯 R-COOR' | Fischer 酯化（ROH, H⁺催化）；DCC 缩合 | 酯化是可逆反应，常用 Dean-Stark 除水推动平衡 |
| 羧酸 R-COOH | 酰氯 R-COCl | SOCl₂（氯化亚砜）；(COCl)₂（草酰氯） | 酰氯是最活泼的羧酸衍生物，是合成其他衍生物的枢纽 |
| 羧酸 R-COOH | 酸酐 (RCO)₂O | 酸酐交换法；脱水剂（如 DCC） | 酸酐活性低于酰氯，高于酯 |
| 卤代烃 R-X | 胺 R-NH₂ | Gabriel 合成（邻苯二甲酰亚胺钾盐，再肼解）；叠氮化钠 NaN₃ + 还原 | Gabriel 合成避免了多烷基化问题，产伯胺纯净 |
| 卤代烃 R-X | 腈 R-CN | NaCN（DMF 溶剂）；KCN | 腈水解得羧酸，还原得胺——一个官能团两种后续方向 |
| 卤代烃 R-X | 醇 R-OH | NaOH/H₂O（水解）；NaOAc + 水解 | SN2 条件下需注意构型翻转 |
| 腈 R-CN | 羧酸 R-COOH | 酸性水解（H₃O⁺, Δ）；碱性水解（NaOH/H₂O, Δ） | 水解经酰胺中间体，完全水解得到羧酸（或羧酸盐） |
| 腈 R-CN | 酰胺 R-CONH₂ | 部分水解（温和条件：碱性/酸性控制 pH） | 控制反应程度可停留在酰胺阶段 |

> **教学提示**：上表不是要求死记硬背，而是要建立"官能团空间"的概念——醇、醛酮、羧酸、胺、卤代烃、腈构成一个网络，每条边对应一类反应。做合成题时，先在脑中画出这个网络，再找从起始物到目标分子的路径。

### 3.2 逆合成中的 FGI 策略

FGI（Functional Group Interconversion，官能团互变）是逆合成分析中的核心操作之一。其定义为：**在逆合成步骤中，将目标分子的官能团变换为另一种官能团，从而暴露出原本无法进行的键断裂（disconnection）**。

Clayden（第28章）指出：*"FGI changes the functional group to allow a disconnection that was not previously possible."* 也就是说，FGI 本身不是一个合成反应，而是一个逆合成思维工具——它告诉你："如果目标分子的这个官能团能变成另一个官能团，那么断键就变得可行了。"

#### FGI 的典型操作

| 当前官能团 | FGI 变换为 | 原因/动机 |
|:---|:---|:---|
| 醇 R-OH | 卤代烃 R-X | 卤代烃可以与亲核试剂（CN⁻, RO⁻, R₂CuLi 等）反应，实现碳链构建；醇的 C-O 键较难断裂 |
| 酮 R₂C=O | 醇 R₂CHOH | 醇可以断 C-C 键（如 Grignard 加成的逆操作），酮的 C-C 键直接断开较困难 |
| 酯 R-COOR' | 羧酸 R-COOH | 羧酸可以脱羧，或酯经水解后更容易与其他试剂反应 |
| 酰胺 R-CONH₂ | 羧酸 R-COOH | 类似酯→酸的逻辑，酰胺水解为酸后再做其他转化 |
| 胺 R-NH₂ | 卤代烃 R-X | 卤代烃可通过 SN2 引入氮；胺也可以 FGI 为腈再还原 |
| 硝基 Ar-NO₂ | 胺 Ar-NH₂ | 芳香胺可通过重氮盐实现多种官能团化（Sandmeyer 反应等） |

#### FGI 在逆合成中的运用步骤

1. **识别目标分子的官能团**：列出所有官能团，判断哪些键可以直接断开（disconnection）。
2. **尝试直接断键**：如果某条键可以直接断开（如 C-C 键可通过 Grignard 断开），则优先使用。
3. **若直接断键不可行，使用 FGI**：将官能团变换成另一种，使断键变得可能。
4. **继续倒推**：对新得到的前体重复上述过程，直到到达可购买的起始原料。

> **教学提示**：FGI 的难点在于"什么时候用"。经验法则是：当目标分子的某个官能团使你想断开的键变得惰性（如 C-OH 键不易断裂），或使前体分子不稳定时，就考虑 FGI。多做逆合成练习（Clayden Ch28 的习题是很好的训练材料），逐渐培养直觉。

### 3.3 化学选择性与保护基

在实际合成中，分子往往含有多个官能团。此时核心问题变成：**哪个官能团先反应？** 这就是化学选择性（chemoselectivity）的问题。

#### 化学选择性的两种控制方式

- **动力学控制（kinetic control）**：反应在较低温度、较短时间内进行，反应速率更快的官能团优先反应。例如，NaBH₄ 在低温下优先还原醛基而非酮基（醛的羰基碳更缺电子，反应更快）。
- **热力学控制（thermodynamic control）**：反应在较高温度、较长时间下进行，产物为更稳定的异构体。例如，烯醇化反应中，取代更多的烯醇在热力学上更稳定。

当化学选择性无法通过试剂本身的选择性来实现时，就需要**保护基策略**（protecting group strategy）。

#### 保护基策略的核心逻辑

Clayden（第23章）将保护基策略概括为三步：

1. **保护（protection）**：用保护基将不需要反应的官能团"临时封住"。
2. **反应（reaction）**：在保护基的保护下，对目标官能团进行所需反应。
3. **脱保护（deprotection）**：反应完成后，选择性地去除保护基，恢复原始官能团。

一个好的保护基应满足：
- 安装和脱除条件温和、产率高
- 对其他官能团惰性（不影响反应）
- 脱除条件不破坏已构建的分子骨架

#### 常见保护基一览表

| 需保护的官能团 | 保护基 | 安装条件 | 脱除条件 | 特点 |
|:---|:---|:---|:---|:---|
| 醛/酮 -CHO / >C=O | 缩醛/缩酮（acetal/ketal），常用 1,3-二氧戊环 | HOCH₂CH₂OH, H⁺催化 | 稀酸水溶液（H₃O⁺） | 对碱和亲核试剂稳定，酸性条件下脱保护 |
| 醇 R-OH | TBDMS（叔丁基二甲基硅基） | TBDMS-Cl, Et₃N（或咪唑） | TBAF（四丁基氟化铵，F⁻） | 硅基保护基的代表，F⁻选择性脱除，不影响缩醛 |
| 醇 R-OH | 苄基（Bn） | BnBr, NaH | H₂/Pd-C（催化氢解） | 脱保护条件与 TBDMS 正交（正交性概念见下） |
| 胺 R-NH₂ | Boc（叔丁氧羰基） | (Boc)₂O, Et₃N | TFA（三氟乙酸）或 HCl/二氧六环 | 酸性脱保护，不影响 Cbz |
| 胺 R-NH₂ | Cbz（苄氧羰基） | Cbz-Cl, NaOH/H₂O | H₂/Pd-C（氢解） | 与 Boc 正交——Boc 条件不脱 Cbz，Cbz 条件不脱 Boc |
| 胺 R-NH₂ | Fmoc（芴甲氧羰基） | Fmoc-Cl, 碱性条件 | 哌啶/DMF（碱性β-消除） | 固相肽合成（SPPS）中常用，与 Boc/Cbz 正交 |

#### 正交保护（Orthogonal Protection）

正交保护是指：**两种保护基可以在完全不同的条件下分别脱除，互不干扰**。例如 Boc（酸脱）和 Cbz（氢解脱）是正交的——可以在酸性条件下脱 Boc 而保留 Cbz，也可以氢解脱 Cbz 而保留 Boc。正交保护在多官能团分子的合成中至关重要，是高级有机合成的必备技能。

> **教学提示**：保护基是"必要之恶"——它们增加了合成步骤，但在化学选择性无法解决时是唯一选择。教学中应引导学生思考："这个反应是否真的需要保护？有没有更选择性的试剂可以省去保护步骤？" 最好的合成路线是保护步骤最少的路线。

### 3.4 官能团兼容性判断

合成路线设计中，每一步反应都必须考虑试剂对分子中其他官能团的影响。以下是常见试剂的兼容性速查：

| 试剂 | 能反应的官能团 | 不兼容（会被破坏或干扰）的官能团 | 典型解决方案 |
|:---|:---|:---|:---|
| Grignard 试剂 RMgX / 有机锂 RLi | 醛/酮的 C=O（亲核加成）；环氧化物；CO₂ | **-OH, -NH, -COOH, -CHO（活泼氢）**；酯（会发生加成-消除） | 先保护活泼氢（如 TBDMS 保护 -OH，Boc 保护 -NH₂）；或将醛/酮先保护为缩醛 |
| NaBH₄ | 醛 R-CHO；酮 R₂C=O | **酯 R-COOR'（不反应）**；羧酸（不反应）；酰胺（不反应） | NaBH₄ 选择性好，醛酮共存时醛先还原（动力学控制）；若需还原酯，换用 LiAlH₄ |
| LiAlH₄ | 醛、酮、酯、羧酸、酰胺、环氧化物、硝基 | **-OH, -NH（活泼氢会消耗 LiAlH₄）**；卤代烃（可能被还原） | 先处理活泼氢（加水或酸淬灭前，确保无游离 -OH/-NH）；严格无水操作 |
| 催化氢化 H₂/Pd-C | C=C；C≡C；C=O（醛酮）；硝基 -NO₂；苄基 -OBn/-NHBn | **卤代烃（可能脱卤）**；烯丙基位置可能被还原；苯环（需高压/高温） | 选择性可通过催化剂调节：Pd/C 活性最高，PtO₂ 适中，Lindlar 催化剂（Pd/CaCO₃/Pb）停在烯烃 |
| PCC（氧化） | 仲醇 → 酮；伯醇 → **醛**（停在醛） | 其他醇（仲醇也被氧化）；对 C=C 无影响 | PCC 是温和氧化剂，兼容性好；但 Cr(VI) 有毒，实验室逐渐被 Dess-Martin 或 Swern 取代 |
| KMnO₄（氧化） | 醇 → 醛 → 羧酸（强氧化，一路到底）；C=C 断裂（稀冷条件：顺式二醇；浓热条件：断裂为酸/酮） | **几乎不兼容任何还原性官能团**（醛、胺、硫醚等都会被氧化） | 需要选择性氧化时，避免 KMnO₄，改用温和氧化剂（PCC, Dess-Martin, Ag₂O） |
| SOCl₂ / PBr₃ | 醇 → 卤代烃 | **羧酸（SOCl₂ 可将 -COOH 转为 -COCl）**；胺（可能被磺酰化） | 若需选择性将 -OH 转为 -X 而不影响 -COOH，需保护 -COOH（如酯化） |
| mCPBA（间氯过氧苯甲酸） | C=C → 环氧化物；酮 → 酯（Baeyer-Villiger） | 醇（可能被氧化）；胺（可能被氧化） | mCPBA 是常用的亲电氧化剂，对 C=C 和酮有良好选择性 |

> **教学提示**：兼容性判断是合成设计中最容易出错的环节。建议学生养成习惯：在写每个合成步骤时，先列出分子中所有官能团，再逐一检查试剂是否与之兼容。这个习惯一旦养成，合成正确率会显著提升。

## 五、典型题型与解题策略

### 题型一：设计合成路线（正向合成与 FGI）

**题目特征**：给出起始原料和目标分子，要求设计合成路线。

**解题策略**：

1. **逆合成优先**：从目标分子出发，用 FGI 和键断裂倒推，直到到达起始原料。
2. **标记官能团**：比较起始原料和目标分子的官能团差异，确定需要做哪些官能团转化。
3. **选择最优路径**：考虑步数最少、产率最高、兼容性最好的路线。
4. **正向验证**：从起始原料正向走一遍，检查每一步的兼容性和产率。

**示例**：从环己醇合成环己基甲胺。

**分析**：
- 逆合成：环己基甲胺 ← 环己基腈水解还原 ← 环己基腈 ← 环己基溴 + NaCN ← 环己醇 + HBr
- 正向：环己醇 →(HBr)→ 溴代环己烷 →(NaCN)→ 环己基腈 →(LiAlH₄ 还原)→ 环己基甲胺
- 每一步兼容性检查：HBr 不影响环；NaCN 与溴代烃发生 SN2；LiAlH₄ 将腈还原为伯胺。

### 题型二：逆合成分析（含 FGI 操作）

**题目特征**：要求对目标分子进行逆合成分析，写出断键位置和 FGI 操作。

**解题策略**：

1. **列出所有官能团**：标注每个官能团的类型和位置。
2. **尝试直接断键**：优先断开可由 Grignard、Aldol、Diels-Alder 等经典反应形成的键。
3. **引入 FGI**：若直接断键不可行，将官能团变换为更易断键的形式。
4. **重复倒推**：直到所有前体都是可购买的简单分子。

**示例**：对 2-甲基-3-羟基丁醛进行逆合成分析。

**分析**：
- 目标分子含有醛基和羟基，且处于 β 位 → 这是 Aldol 加成产物的典型结构。
- 断键：β-羟基醛 → FGI（醛基还原为 -CH₂OH）→ 1,3-二醇 → Aldol 断键 → 两分子乙醛。
- 或直接断键：β-羟基醛的 C2-C3 键是 Aldol 产物，可直接断开 → 两分子乙醛。

### 题型三：化学选择性预测

**题目特征**：给出含多个官能团的分子和特定试剂，问哪个官能团先反应/是否需要保护。

**解题策略**：

1. **列出所有官能团**：标记每个官能团的反应活性等级。
2. **查阅试剂的选择性**：对照 3.4 的兼容性速查表。
3. **判断动力学 vs 热力学控制**：考虑温度、时间等条件。
4. **若无选择性，设计保护基方案**：选用正交保护基，写出保护→反应→脱保护三步。

**示例**：4-羟基丁醛（HO-CH₂CH₂CH₂CHO）与 NaBH₄ 反应，产物是什么？

**分析**：
- 分子中含有 -OH 和 -CHO 两个官能团。
- NaBH₄ 选择性还原醛/酮，不与醇反应 → 产物为 1,4-丁二醇（HO-CH₂CH₂CH₂CH₂OH）。
- 无需保护，NaBH₄ 本身的化学选择性即可解决问题。

## 🎯 教学视角

### 学习路径建议

官能团转化（FGI）应在掌握各类官能团基本反应之后学习，是逆合成分析的核心工具。建议先建立"官能团转化网络图"，将醇、醛酮、羧酸、胺、卤代烃之间的常见转化路径可视化，再通过合成练习强化应用能力。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为任何官能团都可以直接互相转化 | 许多转化需要多步（如羧酸→醛需先还原为醇再温和氧化），不能一步到位 |
| 忽略官能团转化中的选择性问题 | 同一分子中有多个官能团时，需考虑化学选择性（哪个官能团先反应）和保护基策略 |
| 只看正向合成不看逆合成 | 逆合成分析（从目标分子倒推）是设计合成路线的正确思维方式，正向思维容易走弯路 |

### 入门级例题

**题目**：设计一条从苯酚到水杨酸（邻羟基苯甲酸）的合成路线。

**解答**：苯酚 → 邻羟基苯甲醛（Reimer-Tiemann反应：CHCl₃/NaOH）→ 水杨酸（氧化：KMnO₄ 或 Ag₂O）。关键步骤是引入醛基（官能团转化：-OH → -CHO），再氧化为羧酸（-CHO → -COOH）。

### 与现实世界的联系

- **全合成设计**：紫杉醇、青蒿素等天然产物的全合成核心就是官能团转化的精巧安排
- **工业制药**：从简单原料到药物分子的工业路线设计，每一步都是官能团转化的实际应用
- **生物合成**：生物体内的代谢通路（如糖酵解）本质上也是一系列酶催化的官能团转化
