# Cope重排

## 一、定义

Cope 重排（1940 年 A. C. Cope）指 **1,5-二烯在加热条件下经六元环状过渡态发生的 [3,3]-σ 迁移重排**：分子中一个"3 原子片段"（含一根 σ 键）与另一个"3 原子片段"（含两根 π 键的共轭二烯部分）协同交换，σ 键由 C1–C6 之间断裂并在 C3–C4（新位置）重新形成，产物仍是 1,5-二烯。它是**协同的周环反应**，不经过碳正离子/自由基中间体，具有高度立体专一性，是构建复杂碳骨架与转移立体化学信息的重要工具。最简单的 1,5-己二烯发生 Cope 重排时因产物与原料相同而称**简并重排**（degenerate），需用同位素标记才能观察到。

## 二、考纲对应

本页属周环反应-σ 迁移分支，对应"[3,3]-σ 迁移与 Cope/Claisen 重排"：能识别 1,5-二烯骨架、写出重排产物（含取代基转移后的位置），理解椅式过渡态对立体化学的控制（立体专一），并与 Claisen 重排（含氧 [3,3]）区分。决赛理论与人名反应综合题常见，初赛偶尔以信息题形式给出。

## 三、核心原理

### 3.1 周环机理：协同的 [3,3]-σ 迁移

- 旧 σ 键（C1–C6）断裂与两个新 π 键变一个新 σ 键（C3–C4 区）**同步进行**，单步协同、无中间体——因此不受溶剂极性、自由基引发剂影响，也**不发生碳正离子重排**。
- 依据 Woodward–Hoffmann 规则，加热条件下 [3,3]-σ 迁移经**同面–同面**方式允许；[1,3] 等迁移热允许条件不同，故 Cope 反应热力学上温和可行。
- 命名要点：σ 键两端各沿 π 体系数到新键位置，两端序号均为 3 → [3,3]；方括号数字之和 = 过渡态环原子数（3+3 = 六元环）。

### 3.2 椅式过渡态与立体专一性

- 六元环过渡态可取**椅式或船式构象**；椅式能量低，是主要反应通道。
- 立体专一性来源：迁移过程中各参与碳的构型被"锁"在椅式过渡态的几何里。对 3,4-二取代-1,5-己二烯类底物，**取代基的直立/平伏取向决定产物双键的 E/Z**——(E,E)/(Z,Z) 构型的底物经椅式过渡态给出立体专一的产物，反应结果可预测（常与 Claisen 并列考察"用椅式画产物"）。
- 手性信息传递：若 1,5-二烯的 C3/C4（新 σ 键两端）带手性中心，重排可通过椅式过渡态把立体化学传递给产物，实现"无试剂参与"的立体化学转移。

### 3.3 简并性与热力学驱动

- 1,5-己二烯本身重排回到自身（简并），需加热（约 200 °C 以上）才能越过能垒，观察靠同位素（¹³C/²H 标记）在两端互换。
- 要使重排有用，需打破简并：**取代基电子效应**是主要杠杆——C2（或 C5）连吸电子基（如酯基、氰基）或 C1（C6）连供电子基时，新形成的烯醇/烯胺型片段更稳定，反应被驱动向一侧（如"氧-Cope"或杂原子加速的 Cope）。
- 也可用环张力释放驱动：环状 1,5-二烯开环重排（逆向环化）或用于扩环/收缩。

### 3.4 与 Claisen 重排的家族关系

Cope 是 [3,3]-σ 迁移的"烃基母体"；**Claisen 重排 = 烯丙基乙烯基醚的 [3,3]-σ 迁移**（一个 C–C–C 片段换成 C–O–C，产物为 γ,δ-不饱和羰基化合物，经烯醇互变异构）。两者过渡态类型、立体专一性逻辑完全一致，区别只在含氧片段——学 Cope 是理解整个 [3,3] 家族的钥匙。

## 四、关键结论

- Cope 重排：1,5-二烯加热经**六元环椅式过渡态**的协同 [3,3]-σ 迁移；产物仍是 1,5-二烯。
- 协同无中间体：不是碳正离子/自由基机理，不受极性/自由基引发影响。
- 立体专一：椅式过渡态决定产物双键几何与手性传递，可用构象分析预测。
- 简并重排（1,5-己二烯）需同位素标记观察；取代基电子效应打破简并、提供热力学驱动。
- Claisen 是其含氧版本；[3,3] 家族是 σ 迁移中最常用的成键工具。

## 五、常见分类或情形

- **按底物**：开链 1,5-二烯（简并或取代驱动）；环状 1,5-二烯（开环/扩环）；杂原子加速型（氧-Cope、氮-Cope，降低温度）。
- **按驱动**：电子效应驱动（吸电子在 C2/C5、供电子在 C1/C6）、张力释放驱动（小环开环）。
- **按立体控制**：椅式 vs 船式过渡态；1,2-二取代底物的 (E,E)/(Z,Z) 选择性传递。
- **相关反应家族**：Claisen（含氧）、Carroll（β-酮酯的 [3,3] 变体）、[2,3]-Wittig 等。

## 六、适用条件与限制

- **需加热**：简单 1,5-二烯能垒高（200 °C 量级）；降温手段靠杂原子/取代基加速（氧-Cope 可室温）。
- **简并底物无合成价值**：无取代基的对称二烯重排"白转一圈"，须设计电子效应或环系驱动。
- **竞争副反应**：高温下可能伴随 [1,3] 迁移或电环化、逆 Diels-Alder 等周环旁路；强热对敏感官能团不友好。
- **立体化学依赖构象可达性**：若底物无法采取椅式过渡态（位阻过大/构象锁定），反应变慢或改走船式（产物 E/Z 改变）——读题先检查椅式是否可行。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Cope vs 碳正离子重排 | Cope 是协同周环（六元环过渡态、无中间体）；碳正离子重排（如 Wagner-Meerwein）经正离子中间体、受溶剂极性影响——Cope 不受影响且可同位素标记证协同 |
| Cope vs Claisen | 同为 [3,3]-σ 迁移；Cope 底物是 1,5-二烯（产物 1,5-二烯），Claisen 底物是烯丙基乙烯基醚（产物 γ,δ-不饱和羰基化合物，经烯醇互变）——看骨架含不含氧 |
| 简并 vs 无反应 | 1,5-己二烯 Cope 是简并重排（产物=原料，反应发生但不可观察），不是不反应；用 ²H 标记两端可证明互换 |
| [3,3] vs [1,3] 迁移 | [3,3] 热允许走同面-同面、六元环过渡态；[1,3] 氢迁移等热条件下机理与允许性不同——σ 迁移命名先数对新键两端序号 |
| 椅式 vs 船式产物 | 椅式过渡态主导；船式只在椅式受阻时出现且改变 E/Z——画产物先排椅式 |

## 九、典型题型

- **产物书写**：给取代 1,5-二烯，画 [3,3] 重排产物（标新 σ 键位置与双键 E/Z）。
- **立体化学预测**：给 (E,E)/(Z,Z)-3,4-二取代底物，用椅式过渡态推产物构型。
- **机理辨析**：判断某重排是协同 [3,3] 还是碳正离子（用同位素/溶剂效应证据）。
- **简并识别**：判断底物是否简并、如何设计取代基打破简并。
- **合成应用**：逆合成中找 1,5-二烯关系，用 Cope/Claisen 反推原料。

## 十、例题

**例题 1**：写出 1,5-己二烯在 250 °C 下的反应并说明如何证明它发生了反应。

**解答**：1,5-己二烯发生 Cope 重排，产物仍是 1,5-己二烯（简并重排，原料与产物相同），宏观无变化。证明方法：用 ²H（或 ¹³C）标记 C1 与 C6 两端，加热后标记原子出现在另一端（C6/C1 互换）——说明 C1–C6 σ 键断裂并在新位置重建，反应确实发生。

**例题 2**：(E,E)-3,4-二甲基-1,5-己二烯发生 Cope 重排，用椅式过渡态判断产物的立体化学。

**解答**：椅式过渡态要求参与迁移的六个原子近似共面排布。对 (E,E)-3,4-二甲基底物，两个甲基在椅式过渡态中可取双平伏（diequatorial）最稳定构象，此构象对应的产物为 (E,E)-3,4-二甲基-1,5-己二烯（重排回到同一构型，简并但保留 E,E）——若底物为 (Z,Z) 则只能经甲基有直立取向的椅式（或船式）过渡态，得到不同的 E/Z 结果。读题时先确定取代基在椅式中的取向，再"平移"画产物。

**例题 3**：某 1,5-二烯在 C2 位连有酯基（吸电子），重排平衡偏向哪一侧？为什么？

**解答**：偏向酯基随 [3,3] 迁移"走到"新形成的 C=C 端成为烯醇酯类稳定片段的一侧——吸电子基连在 C2（原 π 体系 2 位）会使产物中相应双键与酯基共轭（或形成更稳定的烯醇/烯醇衍生物），热力学上稳定产物侧。故设计"供电子在 C1/C6、吸电子在 C2/C5"可把简并反应变为正向合成工具（氧-Cope 加速同理：C1 接 O 使产物为烯醇醚更稳）。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为 Cope 重排是"碳正离子重排" | Cope 是协同周环反应，经六元环过渡态一步完成，无碳正离子/自由基中间体 | 反例：Cope 不受溶剂极性影响、无重排副产物；同位素标记两端互换是协同的直接证据——与 Wagner-Meerwein 类离子重排本质不同 |
| 混淆 Cope 与 Claisen | Cope 是 1,5-二烯的 [3,3]-σ 迁移；Claisen 是烯丙基乙烯基醚的 [3,3]-σ 迁移，产物含氧（γ,δ-不饱和羰基） | 判别：骨架含 C–O–C 且产物有羰基/烯醇 → Claisen；纯碳骨架 1,5-二烯 → Cope |
| 忽略过渡态构象要求 | Cope 过渡态是椅式六元环，取代基直立/平伏决定产物 E/Z；不看构象直接画必错 | 判别：先排取代基取向最稳的椅式（大基团平伏），再按"旧 σ 键两端互换"平移画产物双键 |
| 把简并当"不发生" | 1,5-己二烯重排产物=原料（简并），反应发生了但宏观无变化 | 反例：²H 标记 C1/C6 后加热，标记原子互换——证明 σ 键断裂重建；简并≠不反应 |
| [3,3] 与 [1,3]/[1,5] 迁移混用 | 不同 σ 迁移的热允许性与过渡态不同；[3,3] 走六元环椅式，[1,3] 烷基迁移热条件常禁阻或需特殊机理 | 判别：命名先数"新 σ 键两端沿 π 骨架的序号"再定过渡态环大小（3+3=6）；题中写"1,3 迁移六元环"即错 |
| 忽视电子效应对平衡的驱动 | 无取代基的对称二烯是简并的，没有合成意义；驱动靠吸/供电子基或杂原子 | 反例：C2 连酯基后平衡显著偏向酯共轭一侧；氧-Cope 可室温进行——"加热就完事"漏了取代基设计意图 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
Cope 重排应在掌握周环反应与 σ 迁移概念（命名、热允许同面-同面）之后学习。建议先理解 [3,3]-σ 迁移的协同本质与六元环椅式过渡态，再学取代基电子效应如何打破简并，接着与 Claisen 对比建立 [3,3] 家族观，最后用天然产物合成中的 Cope 关键步建立应用感（注意：Cope 消除是另一反应，勿混入本页学习路径）。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为 Cope 重排是"碳正离子重排" | Cope 重排是协同周环反应，通过六元环过渡态进行，不涉及碳正离子中间体 |
| 混淆 Cope 重排和 Claisen 重排 | Cope 重排是 1,5-二烯的 [3,3]-σ 迁移；Claisen 重排是烯丙基乙烯基醚的 [3,3]-σ 迁移，产物含氧 |
| 忽略过渡态的构象要求 | Cope 重排的过渡态为椅式构象，取代基的直立/平伏位置影响立体化学结果 |
| 把简并重排当成"没反应" | 对称二烯重排产物与原料相同但反应确实发生（同位素标记可证） |

### 12.3 入门级例题
**题目**：写出 1,5-己二烯在加热条件下的 Cope 重排结果。

**解答**：1,5-己二烯经 [3,3]-σ 迁移重排，生成新的 1,5-己二烯。由于分子对称，产物与原料相同（简并重排）；若引入不同取代基（如 C2 酯基）则平衡偏向取代基共轭一侧，可得到结构不同的产物。

### 12.4 与现实世界的联系
- **天然产物全合成**：Cope/Claisen 重排用于构建复杂碳骨架，如维生素 D 前体与多烯环化路线。
- **药物合成**：某些药物分子合成以 Cope 重排引入特定立体化学（椅式过渡态传递构型）。
- **高分子化学**：热响应性聚合物的设计利用加热引发的结构重排（含 Cope 型单元）。
