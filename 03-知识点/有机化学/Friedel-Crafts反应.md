# Friedel-Crafts反应

## 一、定义

Friedel-Crafts（傅-克）反应是芳香亲电取代（SEAr）家族中最重要的一对碳-碳成键反应，在 Lewis 酸（AlCl₃、FeCl₃、BF₃ 等）催化下把**烷基或酰基引入芳环**：

- **FC 烷基化**：Ar–H + R–X（或烯烃/醇）→ Ar–R + HX，亲电体为烷基碳正离子（或极化络合物）。
- **FC 酰基化**：Ar–H + RCOCl（或酸酐）→ Ar–COR + HCl，亲电体为酰基正离子（或酰氯–Lewis 酸络合物）。

两者机理同为"生成亲电体 → σ 络合物 → 脱质子"，但合成行为差异极大：**酰基化不重排、可停在一取代、适用更广**，是合成芳酮的主力；**烷基化易碳正离子重排、多取代、可逆**，用途受限。石油化工中乙苯（→苯乙烯）、异丙苯（→苯酚+丙酮）的工业制备即 FC 烷基化，是芳环官能团化最经典的人名反应之一。

## 二、考纲对应

本页属芳香亲电取代-人名反应核心考点，对应"Friedel-Crafts 烷基化/酰基化"：能写 AlCl₃ 催化下两类反应的机理（亲电体生成、σ 络合物、脱质子）；理解烷基化碳正离子**重排**与多取代问题、酰基化需**化学计量 AlCl₃** 的原因；掌握"先酰化后还原"绕开重排的合成策略；并能判断强钝化芳环（硝基苯、苯胺盐）不反应。初赛决赛均高频，常与定位规则联合出题。

## 三、核心原理

### 3.1 共性机理：亲电体 → σ 络合物 → 脱质子

两类反应共用 SEAr 三步框架（详见 [[SEAr定位规则]] 与 σ 络合物中间体 [[σ络合物]]）：

1. **生成亲电体**：Lewis 酸活化亲电试剂——烷基化时 R–X + AlCl₃ → R⁺(AlCl₄⁻)（或极化物种）；酰化时 RCOCl + AlCl₃ → RCO⁺(AlCl₄⁻)（酰基正离子）。
2. **亲电进攻**：亲电体加到芳环，形成带正电的**σ 络合物（芳基正离子/环己二烯正离子）**——决速步，正电荷在邻/对位共振离域。
3. **脱质子**：碱（AlCl₄⁻、Cl⁻）从 sp³ 碳上拔 H⁺，恢复芳香性得产物，Lewis 酸再生（烷基化）或与产物络合（酰化，见 3.3）。

### 3.2 FC 烷基化：重排、多取代与可逆三大问题

- **碳正离子重排**：伯卤代烃生成的伯碳正离子立即重排为更稳定的仲/叔碳正离子——正丙基氯得**异丙基苯**而非正丙苯；新戊基体系发生烷基迁移。
- **多取代与活性升高**：烷基是供电子基，一取代后芳环**更活泼**，继续烷基化（引入多个烷基）；过量芳环+低温+缓慢加试剂只能缓解，无法根治。
- **可逆与异构化**：烷基化可逆（质子酸可脱烷基），长时间/高温下发生烷基转移（异丙苯歧化）等副反应。
- **烯烃/醇也可作烷基化剂**（质子酸催化，经质子化烯烃/碳正离子），工业乙苯/异丙苯即烯烃烷基化。
- 适用环范围：需活化或中等活性芳环；**强钝化环（硝基苯）不反应**。

### 3.3 FC 酰基化：为何要化学计量 AlCl₃

- 酰基化不可逆、不发生碳正离子重排（酰基正离子共振稳定，无重排倾向），且**酰基是钝化基**，一取代后芳环不再反应 → 天然单酰化、可作定位"阻断/导向"。
- 关键条件差异：产物芳酮的羰基氧与 AlCl₃ 强配位（形成 1:1 络合物），Lewis 酸被"扣留"——故酰化需 **≥1 当量（常 1.1–2 当量）AlCl₃**，后处理加水破坏络合物才释放酮；而烷基化只需催化量 AlCl₃。
- 酰化后 Clemmensen/Wolff-Kishner 还原（见 [[Clemmensen还原]]）得烷基苯——"**先酰化再还原**"是绕开烷基化重排/多取代的标准策略（如由苯制正丙苯：丙酰氯酰化→还原）。

### 3.4 区域选择性与适用边界

- 区域选择性由环上已有取代基决定：活化基（供电子）导向邻/对位；中等钝化基（卤素）仍邻/对位但活性低；强钝化基（NO₂、NR₃⁺、CF₃）使环几乎不反应（题-038-9 语境：致钝邻对位定位基上的 FC 不进行）。
- 氨基芳环（苯胺）在 Lewis 酸下成盐失活，需先 N-酰化保护再做 FC。
- 杂环适用性：富电子杂环（吡咯、呋喃、噻吩）可反应但条件更温和（避免聚合/开环）；缺电子杂环（吡啶）不反应。
- 分子内 FC 酰化可关环得环酮（靛酮类合成）；FC 反应也见于 Fries 重排（酚酯 → 邻/对羟基酮，见 [[Fries重排]]）的同类 Lewis 酸化学。

## 四、关键结论

- FC = SEAr 型 C–C 成键：亲电体生成 → σ 络合物 → 脱质子；Lewis 酸活化卤代烃/酰氯。
- **烷基化三坑**：重排（伯→仲/叔）、多取代（产物更活）、可逆；只适用于活化/中等芳环。
- **酰基化两优**：不重排、单取代可控；代价是**化学计量 AlCl₃**（与酮配位）+ 后处理水解。
- 绕坑策略：需要正丙基类烷基 → 用"酰化 + 还原"两步而非直接烷基化。
- 强钝化环（硝基苯等）两者都不反应；苯胺需保护氨基。

## 五、常见分类或情形

- **烷基化剂**：卤代烃（RX）、烯烃/醇（质子酸催化）、环氧化物（开环引入羟烷基）。
- **酰基化剂**：酰氯（最常用，需 Lewis 酸）、酸酐（可用 BF₃/质子酸）、羧酸（高温脱水条件，少用）。
- **Lewis 酸**：AlCl₃（酰化首选，强）、FeCl₃、BF₃、SnCl₄、ZnCl₂；烷基化也可用质子酸（HF、H₂SO₄、H₃PO₄ 催化烯烃）。
- **分子内 FC**：关环合成茚酮/四氢萘酮类；**与 Fries 重排、Clemmensen 还原**构成酰基化学组合拳。

## 六、适用条件与限制

- 芳环活性门槛：至少"中等"（卤苯勉强）；强钝化（NO₂、CN、COR、SO₃H、NR₃⁺）不反应——不可用于含这些基团的底物。
- 烷基化重排无法完全避免（即使低温）；要直线烷基只能走酰化-还原。
- 苯胺/酚等富电子底物对 Lewis 酸敏感（酚可 FC 但易氧化/聚合），吡咯等需极温和条件。
- 酰化 AlCl₃ 用量大 → 原子经济差、废液多；工业上追求固体酸/沸石替代。
- 空间位阻：邻位大取代基阻碍反应；叔烷基易脱烷基。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| FC 烷基化 vs 酰基化"都是引入烃基" | 烷基化直接连烷基（产物更活、可重排多取代）；酰基化连酰基（钝化、单取代、不重排）——合成芳基烷烃优先酰化+还原 |
| AlCl₃ 用量"催化 vs 化学计量" | 烷基化催化量即可（AlCl₃ 再生）；酰化需 ≥1 当量（产物酮与 AlCl₃ 配位扣留）——题目给"1.5 当量 AlCl₃"就是在做酰化 |
| 苯胺能否直接 FC | 不能：氨基与 Lewis 酸成盐使环强钝化——先 N-酰化（或做成乙酰胺）再 FC，后水解 |
| 硝基苯 vs 卤苯的 FC 活性 | 都低但机制不同：卤素弱钝化仍邻对位可反应（慢）；硝基强钝化完全不反应 |
| FC 烷基化 vs 自由基烷基化 | FC 是离子型 SEAr（碳正离子、需 Lewis 酸）；自由基途径（如 Mn(OAc)₃）机理完全不同、适用缺电子杂环 |

## 九、典型题型

- **机理书写**：苯 + 叔丁基氯/AlCl₃ 或苯 + 乙酰氯/AlCl₃ 的完整机理（亲电体、σ 络合物、脱质子）。
- **重排预测**：正丙基氯/新戊基氯烷基化主产物（碳正离子重排后结构）。
- **合成设计**：由苯合成正丙苯、对叔丁基苯乙酮、邻/间位取代芳酮（酰化定位+阻断）。
- **条件判断**：解释酰化需过量 AlCl₃、为何硝基苯不反应、苯胺要先保护。
- **信息题应用**：C60 全合成类路线中识别 FC 步（题-025决-7）。

## 十、例题

**例题 1**：写出苯与正丙基氯在 AlCl₃ 催化下的主产物并解释。

**解答**：正丙基氯与 AlCl₃ 生成正丙基碳正离子，但伯碳正离子不稳定，立即经 1,2-氢迁移重排为更稳定的仲碳正离子（异丙基），再进攻苯环 → 主产物**异丙苯**（不是正丙苯）。这正是 FC 烷基化的经典重排问题；若要正丙苯，须改用丙酰氯酰化得苯丙酮再 Clemmensen 还原。

**例题 2**：设计由苯合成对-叔丁基苯乙酮（两步，指出每步条件与选择性来源）。

**解答**：第一步 FC 烷基化：苯 + 叔丁基氯/AlCl₃ → 叔丁苯（叔丁基无重排问题，一取代后仍较活，用过量苯抑制二取代）；第二步 FC 酰化：叔丁苯 + 乙酰氯/AlCl₃（≥1 当量）→ 酰基进入叔丁基的**对位**（叔丁基是邻对位定位基，邻位受阻，主得对位产物）。若次序颠倒（先乙酰化再叔丁基化）则乙酰基钝化环、无法再烷基化——顺序决定成败。

**例题 3**：苯胺直接做 FC 酰化几乎不反应，如何解决？写出方案思路。

**解答**：苯胺的氨基是强 Lewis 碱，先与 AlCl₃ 成盐使环强烈钝化（且消耗催化剂），故不反应。方案：先用乙酸酐把 –NH₂ 酰化成 –NHCOCH₃（酰胺，邻对位定位且不再碱性成盐），再做 FC 酰化（得邻/对位酰基产物），最后水解酰胺恢复氨基。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 以为 FC 烷基化能引入任意烷基 | 伯碳正离子立即重排成仲/叔；新戊基等还发生烷基迁移 | 反例：正丙基氯 + 苯 → 异丙苯（非正丙苯）——需要直线烷基时用"酰化+还原"，见题目提示"正丙基/直链"即警惕重排 |
| 混淆两种反应的 AlCl₃ 用量 | 酰化产物酮与 AlCl₃ 配位，Lewis 酸被扣留，必须 ≥1 当量；烷基化只需催化量 | 判别：条件给"1.2–2 当量 AlCl₃"+酰氯/酸酐 → 酰化；给"催化量 AlCl₃"+卤代烃 → 烷基化 |
| 忽略烷基化后的多取代 | 烷基是活化基，一取代后环更活，继续烷基化 | 反例：苯 + 过量氯甲烷 → 甲苯/二甲苯/三甲苯混合物——控制靠过量苯+低温+慢加，但无法根治 |
| 认为强钝化环也能 FC | 硝基苯、苯铵盐、腈/酮/磺酸取代环的亲电位点活性极低，不反应 | 判别：看环上是否已有 NO₂/NR₃⁺/CF₃ 等强钝化基 → FC 停摆；卤苯虽慢仍可反应（弱钝化） |
| 苯胺/酚直接套用标准条件 | 苯胺成盐失活；酚在 AlCl₃ 下易氧化副反应，富电子杂环（吡咯）易聚合 | 反例：苯胺直接 FC 几乎无产物——需 N-酰化保护；吡咯/呋喃要温和 Lewis 酸低温 |
| 把 FC 酰化当成可逆/多取代 | 酰基钝化使反应不可逆且停在一取代——这正是它优于烷基化的点，别用烷基化的思维套 | 判别：酰化产物无法再 FC；"酰基化会像烷基化那样多取代"是错的 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
Friedel-Crafts 反应应在掌握芳香亲电取代机理与 Lewis 酸概念之后学习。建议先对比烷基化/酰基化的"机理同、行为异"，再抓三大差异（重排/用量/可逆），然后用"由苯制正丙苯""酰化定位"两个合成题把知识串成策略。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为 FC 烷基化可以引入任意烷基 | 伯烷基可能发生碳正离子重排，得到非预期产物（正丙基→异丙基） |
| 混淆酰基化和烷基化的适用范围 | 酰化适用于更广芳环且不重排、单取代；烷基化只适用于活化/中等活性芳环且有多取代问题 |
| 忽略 AlCl₃ 的用量差异 | 酰基化需化学计量 AlCl₃（与产物酮络合），烷基化只需催化量 |
| 拿硝基苯直接做 FC | 强钝化环不反应；要用先还原成氨基再保护等间接路线 |

### 12.3 入门级例题
**题目**：为什么 FC 烷基化中用正丙基氯主要得到异丙基苯？

**解答**：正丙基氯在 AlCl₃ 催化下先生成正丙基碳正离子，伯碳正离子不稳定，经 1,2-氢迁移重排为更稳定的仲碳正离子（异丙基碳正离子）后再进攻苯环，故主产物为异丙苯。

### 12.4 与现实世界的联系
- **石油化工**：FC 烷基化生产乙苯（苯乙烯前体）、异丙苯（苯酚/丙酮前体），工业上多用固体酸催化烯烃烷基化。
- **药物合成**：FC 酰化在芳环引入酰基，是芳酮类中间体的重要来源。
- **精细化工**：萘、蒽醌类染料/颜料中间体的合成大量使用 FC 酰化。
