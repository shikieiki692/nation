# 卤代烃

## 核心概念

卤代烃是烃分子中的氢原子被卤素原子（F、Cl、Br、I）取代后生成的化合物，是有机合成中重要的中间体，可发生亲核取代（SN1/SN2）和消除（E1/E2）等反应。

## 核心原理

### 3.1 亲核取代反应：SN1 vs SN2

| 特征 | SN1 | SN2 |
|:---|:---|:---|
| 动力学 | 一级（速率仅取决于底物浓度） | 二级（速率 = k[底物][亲核体]） |
| 底物活性 | 3° > 2° > 1°（碳正离子越稳定越有利） | 1° > 2° > 3°（空间位阻越小越有利） |
| 亲核体 | 弱亲核体即可（如 H₂O、ROH） | 需要强亲核体（如 OH⁻、CN⁻、RS⁻） |
| 溶剂 | 极性质子溶剂（H₂O、MeOH）——溶剂化稳定碳正离子 | 极性非质子溶剂（DMF、DMSO、丙酮）——裸露亲核体 |
| 立体化学 | 外消旋化（碳正离子平面结构，两面等概率进攻） | 构型翻转（Walden 反转，背面进攻） |
| 中间体 | 碳正离子（分步反应，先离去再进攻） | 无中间体（协同过渡态，五配位碳） |
| 重排 | 可能发生碳正离子重排（1,2-H 或 1,2-CH₃ 迁移） | 不发生重排 |

**机理要点**：

- **SN1**：分两步——① C–LG 键异裂生成碳正离子（决速步）；② 亲核体进攻碳正离子。因碳正离子为 sp² 杂化平面结构，亲核体从两面进攻概率相等，导致外消旋化（若手性中心）。叔碳正离子的超共轭和诱导效应使其稳定，故 3° 底物最利于 SN1。
- **SN2**：一步协同——亲核体从离去基团背面进攻碳中心，经过五配位过渡态（Walden 反转）。空间位阻是决定性因素，1° 碳最易发生，3° 碳几乎不发生 SN2。极性非质子溶剂（如 DMSO、DMF）不与亲核体形成氢键，保持其强亲核性。

### 3.2 消除反应：E1 vs E2

| 特征 | E1 | E2 |
|:---|:---|:---|
| 动力学 | 一级（决速步仅涉及底物） | 二级（碱与底物均参与决速步） |
| 底物活性 | 3° > 2° > 1° | 3° > 2° > 1°（但受位阻和构象限制） |
| 碱的要求 | 弱碱即可（溶剂或弱碱均可） | 需要强碱（如 t-BuO⁻、EtO⁻、OH⁻） |
| 溶剂 | 极性质子溶剂（有利于碳正离子中间体稳定） | 极性非质子溶剂更佳（裸露碱，碱性更强） |
| 区域选择性 | Saytzeff 产物（多取代烯烃，热力学更稳定） | 小碱 → Saytzeff 产物；大位阻碱（如 t-BuOK）→ Hofmann 产物（少取代烯烃） |
| 立体化学 | 无特定要求（碳正离子平面，β-H 任意方向） | 反式共平面消除（anti-periplanar，H 与 LG 在反式位置） |
| 中间体 | 碳正离子（与 SN1 共享同一中间体） | 无中间体（一步协同，C–H 断裂与 C=C 形成同步） |

**机理要点**：

- **E1**：与 SN1 前两步相同——先离去生成碳正离子，再由碱夺取 β-H。因经碳正离子中间体，可能发生重排。
- **E2**：一步协同——碱进攻 β-H，同时 C–H 键断裂、C=C 双键形成、离去基团离开。**立体化学要求严格**：β-H 与离去基团必须处于 anti-periplanar（反式共平面，二面角 180°）构象。这在环己烷体系中意味着 H 与 LG 必须同时处于 a 键（轴向），是解题的关键。
- **Saytzeff vs Hofmann**：小碱（OH⁻、EtO⁻）倾向于夺取多取代碳上的 β-H，生成热力学更稳定的多取代烯烃（Saytzeff 产物）；大位阻碱（t-BuOK）难以接近多取代碳上的 β-H，转而夺取空间上更易接近的 β-H，生成少取代烯烃（Hofmann 产物）。

### 3.3 SN1/E1、SN2/E2 的竞争

四种反应并非独立存在，而是在同一反应体系中竞争。决定因素如下：

- **底物结构是第一判据**：
  - 3° 卤代烃：碳正离子稳定 → **E1/SN1**（或 E2，若碱强）；空间位阻大 → SN2 极难
  - 1° 卤代烃：无稳定碳正离子 → **SN2**；E2 需强碱（如 t-BuOK）
  - 2° 卤代烃：四种机理均可，**条件决定产物**
- **碱的强度与浓度**：
  - 高浓度 + 强碱（t-BuOK、NaOEt）→ **E2 或 SN2**（碱直接参与反应）
  - 低浓度 + 弱碱/弱亲核体 → **E1 或 SN1**（溶剂辅助解离）
- **温度效应**：**高温有利于消除**（消除产物熵增更大，ΔG = ΔH − TΔS，高温下 TΔS 项贡献增大）；低温有利于取代。
- **溶剂效应**：极性质子溶剂（如 H₂O、MeOH）→ 有利于 SN1/E1（稳定碳正离子中间体）；极性非质子溶剂（如 DMSO、DMF）→ 有利于 SN2/E2（裸露亲核体/碱）。

### 3.4 卤代烃的制备与应用

**制备方法**：

| 方法 | 试剂 | 适用底物 | 特点 |
|:---|:---|:---|:---|
| 醇 + HX | HCl / HBr / HI | 1°/2°/3° 醇 | 需催化量 ZnCl₂（Lucas 试剂）或加热；3° 醇按 SN1 机理 |
| 醇 + SOCl₂ | SOCl₂（吡啶） | 1°/2° 醇 | 副产物 SO₂ + HCl 气体逸出，**构型翻转** |
| 醇 + PBr₃ | PBr₃ | 1°/2° 醇 | 温和条件，**构型翻转** |
| 烯烃 + HX | HBr（过氧化物 → 反 Markovnikov） | 烯烃 | Markovnikov 加成（普通 HBr）或反 Markovnikov（HBr/ROOR 自由基机理） |
| 烯烃 + X₂ | Br₂、Cl₂ | 烯烃 | 1,2-二卤代烃（反式加成） |

**合成应用**：
- **Grignard 试剂制备**：R–X + Mg → RMgX（无水乙醚中），是构建 C–C 键的核心方法
- **偶联反应底物**：卤代烃参与 Suzuki、Heck、Sonogashira 等钯催化偶联反应，是现代有机合成的支柱
- **消除制烯烃**：强碱（t-BuOK）处理卤代烃，高效构建双键

## 与其他知识点的关系

1. **与醇的互变**：醇可通过 HX/SOCl₂/PBr₃ 转化为卤代烃，卤代烃也可水解回醇（SN1/SN2）。这是有机合成中醇-卤-醇转化的核心循环。
2. **与烯烃的互变**：卤代烃消除（E2）生成烯烃，烯烃加成 HX 生成卤代烃。两者互为前体/产物，构成"取代-消除-加成"反应网络。
3. **与碳正离子化学的联系**：SN1/E1 经碳正离子中间体，涉及重排（1,2-迁移），与烯烃加成（Markovnikov 规则）、醇脱水等共享碳正离子化学。
4. **与有机金属试剂的联系**：卤代烃是制备 Grignard 试剂（RMgX）和有机锂试剂（RLi）的原料，这两类试剂是构建 C–C 键的核心工具。
5. **与立体化学的联系**：SN2 的 Walden 反转、E2 的 anti-periplanar 要求、环己烷构象分析均在此交汇，是理解有机反应立体化学控制的最佳范例。

## 典型题型

**题型一：反应机理判断与产物预测**
- 给定底物 + 试剂 + 条件，判断主要按 SN1/SN2/E1/E2 哪种机理进行，并预测主要产物
- 关键：先判断底物级数（1°/2°/3°），再看碱/亲核体强度、溶剂类型、温度

**题型二：立体化学分析**
- 已知手性卤代烃的构型，预测 SN1/SN2 反应产物的构型（外消旋化 vs 翻转）
- 已知环己烷取代基位置，判断 E2 消除能否发生（anti-periplanar 构象要求）

**题型三：合成路线设计**
- 以卤代烃为中间体，设计从 A 到 B 的合成路线（如：醇 → 卤代烃 → Grignard → 加成产物）
- 选择性控制：如何通过条件选择实现取代 vs 消除、Saytzeff vs Hofmann 产物



## 🎯 教学视角

### 学习路径建议

卤代烃是有机化学的核心枢纽，应在掌握烷烃命名和基本结构之后立即学习。它是连接"结构"与"反应"的桥梁——卤代烃可发生SN1/SN2取代和E1/E2消除四大反应，是理解有机反应机理的最佳起点。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为卤代烃的反应只是"取代或消除" | SN1/SN2/E1/E2是竞争反应，产物分布取决于底物结构、碱强度、溶剂和温度 |
| 混淆SN1和SN2的条件 | SN1：3°>2°底物、极性质子溶剂、弱亲核试剂；SN2：1°>2°底物、极性非质子溶剂、强亲核试剂 |
| 忽略离去基团的影响 | 离去能力：I⁻>Br⁻>Cl⁻>>F⁻，碘代烃反应活性远高于氟代烃 |

### 入门级例题

**题目**：判断以下反应主要按SN1还是SN2机理进行：(CH₃)₃CBr + NaOH → ?

**解答**：底物为叔卤代烃（3°），空间位阻大，不利于SN2背面进攻；同时叔碳正离子稳定，有利于SN1。但NaOH是强碱，也可能促进E2消除。实际产物以E2消除为主（异丁烯），少量SN1取代产物（叔丁醇）。

### 与现实世界的联系

- **药物合成**：卤代烃是药物合成中最常见的中间体，约30%的药物合成步骤涉及卤代烃的取代反应
- **高分子工业**：氯乙烯（CH₂=CHCl）聚合生成PVC塑料，是世界第三大通用塑料
- **生物化学**：自然界中的卤代物（如氯霉素）具有抗菌活性，海洋生物也产生大量卤代天然产物
