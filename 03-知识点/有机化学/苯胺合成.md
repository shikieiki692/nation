# 苯胺合成

## 一、定义

苯胺（C₆H₅NH₂，aniline）是最重要的芳香伯胺，其合成是芳胺化学的入口。核心问题：**如何在苯环上直接装上 –NH₂**？苯环亲电取代无法直接引入氨基（–NH₂ 太强的给电子/碱性，且 NH₂⁺ 型亲电体不存在），故工业与实验室走"**间接引入**"路线——主要四类：①硝基苯还原（最经典：先硝化再还原）；②卤苯的氨解/金属催化胺化（C–N 偶联）；③苯酚的高温氨解（工业气相）与酚类 Bucherer 反应（限萘系）；④酰胺的 Hofmann 降解（苯甲酰胺 → 苯胺，少一个碳）等重排/降解路线。选择哪条取决于底物上的其他官能团与位点要求（还原法最常用但怕还原敏感基团，偶联法位置灵活）。苯胺是染料（偶氮）、药物（磺胺/扑热息痛）、聚氨酯（MDI）与橡胶助剂的核心原料。

## 二、考纲对应

本页属芳胺合成方法学，对应"苯胺及取代苯胺的制备"：能写出硝基苯还原（Fe/HCl、Sn/HCl、催化氢化）的试剂与条件并说明官能团兼容性；掌握卤苯的金属催化胺化（Buchwald–Hartwig/Cu）与 SNAr 氨解路线；理解苯酚氨解与 Bucherer 反应的适用范围（Bucherer 主用于萘酚类）；会结合定位规则设计"由苯合成取代苯胺"（先引入再还原/先偶联再修饰）。初赛以路线设计与试剂选择出现，决赛（34 届铁催化合成苯胺语境）深入机理。

## 三、核心原理

### 3.1 路线总览：先硝化后还原（经典主线）

- 苯 + HNO₃/H₂SO₄ → 硝基苯 → **还原** → 苯胺。这是工业与实验室的主干。
- 还原剂分两类：
  - **化学还原**：Fe/HCl（或 Fe/H⁺，Béchamp 法，工业曾用）、Sn/HCl、Zn/酸——酸性条件；产物需碱化游离出苯胺。
  - **催化氢化**：H₂/Pd-C（或 Raney Ni）——干净、无金属盐废料，工业主流；对 C=C、C≡C、羰基等可还原基团不兼容（选择性差）。
  - 其他：水合肼/Raney Ni（转移氢化）、Na₂S/硫化物（**选择性还原多硝基中的一个硝基**——连二亚硫酸钠/硫化钠可还原多硝基化合物中一个硝基，如间二硝基苯 → 间硝基苯胺）。
- 关键注意：**氨基是强给电子邻对位定位基**，故"先硝化再还原"引入的 NH₂ 位置由硝化前底物决定——合成对位/邻位取代苯胺常从相应取代苯硝化再还原；也可先做目标取代再硝化还原。

### 3.2 卤苯的 C–N 偶联：现代柔性路线

- **Buchwald–Hartwig 胺化**（Pd 催化，见 [[偶联反应]]）：Ar–X + H₂NR + 碱 → Ar–NR₂；适用于带各种官能团的芳卤，位置由 C–X 决定（可放在合成后期）。
- **Ullmann 型铜催化**：Ar–X + 氨/胺 + Cu（配体）→ Ar–NH₂；条件较 Pd 温和粗放、成本低。
- **SNAr 氨解**：活化芳卤（硝基邻/对位）直接与氨/胺反应（见 [[SN2Ar反应]]）——无金属，但要求 EWG 活化。
- 无活化氯苯的经典氨解（Cu 催化、高温高压、工业）已多数被 Pd/Cu 催化取代。

### 3.3 酚类路线：苯酚氨解与 Bucherer 反应（注意适用范围）

- **苯酚气相氨解**（工业）：苯酚 + NH₃，Al₂O₃ 等催化、高温（约 350 °C）→ 苯胺 + H₂O。
- **Bucherer 反应**：酚类 + NH₃/NaHSO₃（亚硫酸氢盐）→ 芳胺。**关键：主要适用于萘酚类**（1-萘酚 → 1-萘胺、2-萘酚 → 2-萘胺）——亚硫酸氢盐先与萘环 1,2-位发生可逆 1,4-加成活化，苯酚因无法形成稳定加成中间体在该条件下基本不反应。**把 Bucherer 写成"苯酚→苯胺的通用法"是常见错误**；苯酚制苯胺走高温氨解或间接路线。
- 酚还可经磺化/活化或先转卤/OTf 再偶联。

### 3.4 其他路线：降解与重排

- **Hofmann 降解（重排）**：苯甲酰胺 + Br₂/NaOH → 苯胺（少一个碳，经异氰酸酯中间体）——由羧酸同系物"降级"制苯胺/取代苯胺。
- **Curtius/Schmidt**：苯甲酰叠氮/苯甲酸在叠氮酸条件下 → 苯胺（同族）。
- **Gabriel 法**（脂肪胺经典）对芳胺不适用；芳胺不走 Gabriel。
- 这些路线在"由羧酸侧链制备芳胺/降一个碳"的合成题中有价值。

### 3.5 取代苯胺的定位与保护逻辑

- –NH₂ 是强活化邻对位定位基：直接再取代苯胺得邻/对位产物，且易氧化（苯胺在空气中变棕）。
- 合成对位取代苯胺常用"**先酰化保护（–NHCOCH₃）→ 取代（对位为主）→ 水解**"——乙酰氨基仍是邻对位定位但活性适中、防氧化、防过度取代。
- 需要间位取代苯胺时：先由苯做间位取代（用钝化基 CN/NO₂/COR 定位）再还原/降解成 NH₂（如硝基苯 → 间位再引入 → 还原）。

## 四、关键结论

- 苯环不能直接亲电引入 NH₂ → 间接路线：硝化+还原、卤苯偶联/氨解、苯酚氨解、酰胺降级。
- 还原法（Fe/HCl、H₂/Pd-C）最经典；注意酸性介质与碱化游离、多硝基可选硫化物部分还原。
- Buchwald–Hartwig/Cu 偶联位置灵活、官能团兼容好（现代首选之一）。
- **Bucherer 限于萘酚类**（亚硫酸氢盐加成活化），苯酚制苯胺走高温氨解——勿泛化。
- 取代苯胺合成记住"酰化保护再取代、水解恢复"与"间位需求先钝化定位"两条策略。

## 五、常见分类或情形

- **按 C–N 键构建方式**：硝基还原（N 来自 NO₂）、氨解/胺化（N 来自 NH₃/胺）、酚置换（N 来自 NH₃ 置换 OH）、降级（N 来自酰胺原有 N，C 减一个）。
- **按催化剂**：无金属（化学还原、SNAr）、Fe/Sn（化学还原）、Pd（氢化、B-H 胺化）、Cu（Ullmann 型、SNAr 助催化）。
- **按底物**：苯→苯胺（主线）、取代苯（邻/间/对位）、萘系（Bucherer）、杂环胺。
- **按工业/实验室**：工业（催化氢化、气相氨解、Béchamp 铁粉）、实验室（小量 Pd/C、Hofmann 降级）。

## 六、适用条件与限制

- 还原法怕还原敏感基团：含 C=C、C≡C、–CHO、–CO–、–NO₂（多硝基需选择性）时催化氢化会误伤——用化学还原（Fe/HCl）或先保护。
- 酸性还原产物是苯胺盐，需碱化游离；苯胺沸点 184 °C，水蒸气蒸馏可分离。
- 卤苯胺化需活化/催化剂：无活化氯苯+NH₃ 直接反应条件苛刻（>200 °C、高压）；B-H 需 Pd 与配体、除氧。
- 苯胺易氧化（空气变棕）、碱性（pKb≈9.4）可与酸成盐——储存与后处理注意。
- Bucherer 对苯酚无效（适用萘酚）；苯酚氨解需高温气相设备。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Bucherer 反应对象 | Bucherer 是**萘酚→萘胺**（NaHSO₃ 加成活化萘环）；把它写成"苯酚→苯胺"即错——苯酚制苯胺用高温氨解或间接法 |
| Fe/HCl 还原 vs 催化氢化 | 化学还原对 C=C/羰基较温和（硝基优先）；H₂/Pd-C 会把 C=C、C=O 一并还原——看底物其他官能团选还原剂 |
| 多硝基还原选择性 | Na₂S/(NH₄)₂S 可只还原其中一个硝基（得硝基苯胺）；Fe/H₂ 会全部还原——"部分还原"用硫化物 |
| 苯胺的定位与保护 | –NH₂ 邻对位强活化且易氧化——做对位取代先 N-乙酰化（防多取代/氧化）再水解 |
| 亲电取代无法直接引氨基 | 没有 NH₂⁺ 型可用亲电体；必须经 NO₂ 还原或 C–N 偶联等"间接"路线——"苯+NH₃ 亲电取代"不存在 |

## 九、典型题型

- **路线设计**：由苯（或指定取代苯）合成苯胺/对甲苯胺/间硝基苯胺——选硝化还原 vs 偶联并解释定位。
- **还原剂选择**：底物含 C=C 时选 Fe/HCl 还是 H₂/Pd-C？含两个硝基如何部分还原？
- **试剂书写**：硝基苯还原（Fe/HCl）、B-H 胺化条件、Hofmann 降解的完整条件。
- **鉴别/性质**：苯胺的碱性成盐、与酰氯/酸酐反应（保护）、重氮化后用途。
- **机理题**：34 届铁催化合成苯胺（题-34决理-1-6-1）——金属还原的电子转移/中间体。

## 十、例题

**例题 1**：设计由苯合成对-硝基苯胺（两步以内思路，注明关键控制）。

**解答**：直接路线：苯 → 硝基苯（HNO₃/H₂SO₄）→ 对-硝基苯胺？——不行：硝基苯还原得苯胺（–NO₂ 全还原），得不到对-硝基苯胺。正确设计：苯 → 乙酰苯胺？先苯硝化得硝基苯后无位点控制。实用方案：苯 → 对-硝基氯苯思路复杂；最简：苯 → 硝基苯 →（Fe/HCl 还原）苯胺 → 乙酰化（–NHCOCH₃）→ 硝化（主要对位）→ 水解 → 对-硝基苯胺。要点：乙酰氨基是邻对位定位且活性适中，硝化主对位；若需邻位异构体可低温/其他控制分离。

**例题 2**：某底物 4-硝基氯苯要转化为 4-氨基苯甲醚（对氨基苯甲醚）。选哪条路线并说明理由。

**解答**：4-硝基氯苯的 Cl 被硝基（对位）活化 → 可与甲醇钠发生 **SNAr** 得 4-硝基苯甲醚（Cl 被 OCH₃ 取代，位置专一）；再还原硝基（Fe/HCl 或 H₂/Pd-C）→ 4-氨基苯甲醚。这条"先 SNAr 后还原"路线温和、位点确定；若先还原硝基得 4-氯苯胺，氨基会使环富电子、SNAr 变难且 Cl 邻位 H 问题多——顺序决定成败。

**例题 3**：苯甲酰胺如何转化为苯胺？与"苯→苯胺"路线比有什么特点？

**解答**：苯甲酰胺 + Br₂/NaOH（Hofmann 降解）：C₆H₅CONH₂ → 异氰酸酯中间体 → C₆H₅NH₂（少一个碳，放出 CO₂/碳酸盐）。特点：原料是羧酸衍生物，路线"降碳"——适合由苯甲酸类同系物制备芳胺（碳链缩短一个）；而硝基还原路线保持碳数。合成题中若给苯甲酸/酰胺骨架且目标芳胺少一个碳，优先想 Hofmann。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 把 Bucherer 写成苯酚→苯胺 | Bucherer（NH₃/NaHSO₃）靠亚硫酸氢盐对**萘环**的 1,4-加成活化，苯酚无法形成该中间体基本不反应 | 判别：题目对象是萘酚/萘系 → Bucherer；是苯酚 → 高温氨解或间接（硝化还原/偶联） |
| 忽略还原选择性 | H₂/Pd-C 会把 C=C/C=O 也还原；含其他可还原基团时须用 Fe/HCl 或先保护 | 反例：对-硝基苯乙烯用 H₂/Pd-C 会连双键一起还原——"还原硝基"先看底物里还有啥 |
| 以为多硝基能一次全还原或不分 | 硫化物（Na₂S 等）可选择还原一个硝基得硝基苯胺；Fe/H₂ 全还原——"部分还原"是考点 | 判别：目标含残留 NO₂ → 用 Na₂S 类；目标全胺 → 强还原 |
| 直接对苯胺做亲电取代设计 | –NH₂ 强活化易多取代/氧化——对位取代苯胺应先 N-乙酰化再取代后水解 | 反例：苯胺直接硝化会氧化+多取代；乙酰苯胺硝化主对位——"先保护"是标准答案 |
| 还原产物处理忘了游离 | 酸性还原得苯胺盐（C₆H₅NH₃⁺Cl⁻），须加碱才得游离苯胺——写"过滤即得苯胺"不完整 | 自检：Fe/HCl 体系产物行要含"碱化（NaOH）→ 游离苯胺" |

## 十二、🎯 教学视角

### 12.1 学习路径建议
苯胺合成应在掌握胺的基本性质与硝基化合物还原之后学习。先掌握"苯环不能直接亲电引 NH₂"这一根本约束，再按四类路线（硝化还原/偶联氨解/酚氨解/Bucherer/降级）逐个学并比较适用范围，最后用"由苯合成 X 取代苯胺"的路线设计题串起定位、保护与还原选择性。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为苯胺只能由硝基苯还原制得 | 苯胺还可经卤苯金属催化胺化（B-H）、苯酚氨解、酰胺 Hofmann 降解等路线；Bucherer 仅限萘系 |
| 混淆苯胺与苯酚的酸碱性 | 苯胺是弱碱（pKb≈9.4）可与强酸成盐；苯酚是弱酸——性质相反 |
| 把 Bucherer 泛化到苯酚 | Bucherer（NH₃/NaHSO₃）主要适用于萘酚类，苯酚在该条件下不反应 |
| 忽略还原选择性 | 有 C=C/羰基的底物不能用 H₂/Pd-C 还原硝基；多硝基部分还原用硫化物 |

### 12.3 入门级例题
**题目**：如何由苯出发合成苯胺？写出至少两种方法。

**解答**：方法一：苯 → 硝基苯（HNO₃/H₂SO₄）→ 苯胺（Fe/HCl 或催化氢化还原）。方法二：苯 → 氯苯（Cl₂/FeCl₃）→ 苯胺（Cu 催化氨解或 Pd 催化 Buchwald–Hartwig 胺化）。方法三（工业）：苯 → 苯酚 → 高温氨解 → 苯胺。

### 12.4 与现实世界的联系
- **药物合成**：苯胺是磺胺类、对乙酰氨基酚（扑热息痛）等药物的关键中间体。
- **染料工业**：苯胺是偶氮染料核心原料——1856 年"苯胺紫"（mauveine）开启合成染料时代。
- **聚合物材料**：聚苯胺（PANI）是导电高分子，用于防腐涂层、传感器与柔性电子。
