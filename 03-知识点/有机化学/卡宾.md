# 卡宾

## 核心概念

卡宾（carbene，$:CR_2$）是**只具有六个价电子的二价碳中性活性中间体**。它与碳正离子（carbenium ion，如 $^+CH_3$）同为六电子缺电子物种，但卡宾**不带电荷**——这决定了它既有孤对电子又有空轨道，是强亲电试剂且选择性低（可与孤对电子、C=C、甚至 C-H 反应）。卡宾太不稳定，必须在反应底物存在下现场生成。

### 单线态与三线态卡宾

- **单线态（singlet）**：两个非键电子自旋配对（↑↓），填入同一 sp² 轨道，p 轨道空置。键角较小（约 100-110°），不能被 ESR 观察到。典型代表：:CCl₂、:CHCl、N-杂环卡宾。
- **三线态（triplet）**：两个非键电子分占 sp² 和 p 两个轨道，自旋平行（↑↑，洪特规则）。键角较大（约 130-150°），可被 ESR 观察。典型代表：:CH₂、:CPh₂。

![[media/arrowpushing-carbene-triplet-singlet.jpg]]

**两条关键规则**：

1. **自旋态由前体决定**：由所有电子成对的前体（如 α 消除、重氮化合物热解）形成的卡宾必为**单线态**——即使三线态在能量上更稳定；大多数卡宾反应太快，来不及自旋翻转。
2. **取代基效应**：邻位有孤对电子的给电子取代基（Cl、OR、NR₂）通过孤对电子与空 p 轨道相互作用**稳定单线态**（:CCl₂ 是单线态基态）；无此作用的卡宾（:CH₂）三线态为基态。

## 制备方法

| 方法 | 底物与条件 | 说明 |
|:---|:---|:---|
| 重氮化合物脱 N₂ | 重氮甲烷/重氮羰基化合物，光解或热解（或 Cu/Rh 催化） | N₂ 离去的能量补偿卡宾的不稳定；重氮羰基化合物更稳定实用 |
| Bamford-Stevens 反应 | 对甲苯磺酰腙 + 碱 | 先消除 Ts⁻ 得重氮化合物再分解，安全性好 |
| α-消除 | CHCl₃ + 强碱（→:CCl₂）；三氯乙酸钠加热脱羧 | 碱夺质子→碳负离子→失 Cl⁻；脱羧法避免强碱 |
| 咪唑鎓去质子 | 咪唑鎓盐 + NaH | 得 **N-杂环卡宾（NHC）**——可分离的稳定卡宾，Grubbs 催化剂关键配体 |
| 金属卡宾体 | 重氮羰基 + Cu/Rh 催化；W/Cr 羰基体系 | 得金属键合的卡宾体（carbenoid）或可分离的 **Fischer 卡宾** |

## 特征反应

### 1. 环丙烷化（对烯烃加成）——最重要

- **单线态卡宾**：协同 [1+2] 环加成（周环反应，侧向接近烯烃），**立体专一**——烯烃的 Z/E 几何完整保留到环丙烷产物。
- **三线态卡宾**：分步自由基机理（加成→双自由基→自旋翻转→成键），中间体自由旋转 → **非立体专一**（顺反混合物）。
- 判据：加成缺乏立体专一性 → 必为三线态；有立体专一性 → 多为单线态（但不绝对，因三线态也可能来不及翻转）。

**Simmons-Smith 反应**：Zn/Cu + CH₂I₂ 生成锌类卡宾，**不释放游离卡宾**，表现为单线态行为（立体专一 + 立体选择）。烯丙醇的羟基与锌配位**螯合导向**，亚甲基加到羟基同面，速率提高 >100 倍。

### 2. 插入反应

- **C-H 插入**：分子内优先，单线态协同插入、构型保持；铑催化可选择性插入特定位点 C-H 成环——在未官能化碳上建键的合成利器。
- **O-H / N-H 插入**：卡宾先进攻杂原子孤对电子形成叶立德（内盐），再质子转移得中性产物；Rh 催化 N-H 插入用于碳青霉烯类抗生素合成。

### 3. 重排

- **1,2-氢迁移**：有 β-H 的卡宾极快重排为烯烃。
- **Wolff 重排**：α-重氮酮 → 卡宾 → 烷基 1,2-迁移 → **烯酮** → 水解得羧酸。**Arndt-Eistert 同系化**（羧酸→酰氯→重氮酮→Wolff 重排）是羧酸碳链增加一个 CH₂ 的标准方法。

### 4. 氮类似物与金属卡宾（拓展）

- **氮宾**（nitrene，R-N:）：卡宾的氮类似物，Curtius 重排、Hofmann 重排的中间体（→ 异氰酸酯 → 少一碳的胺）。
- **烯烃复分解**：Grubbs Ru-卡宾催化剂经 [2+2]/逆 [2+2]（金属代环丁烷）交换烯烃；2005 年诺贝尔化学奖（Chauvin、Schrock、Grubbs）。

## 易错点

| 易错点 | 正确理解 |
|:---|:---|
| 认为卡宾是"缺电子的碳正离子" | 卡宾是中性二价碳，兼有孤对电子和空轨道，可发生协同反应，与碳正离子不同 |
| 混淆单/三线态的反应性 | 单线态协同加成（立体专一）；三线态分步自由基机理（非立体专一） |
| 认为卡宾只能由重氮化合物产生 | α-消除（氯仿+碱）、Bamford-Stevens、咪唑鎓去质子（NHC）、金属卡宾体均可 |
| 认为三线态基态的卡宾一定按三线态反应 | 由全成对前体形成的卡宾必为单线态，且反应常快于自旋翻转 |
| 忽略 Simmons-Smith 不产生游离卡宾 | 它是锌类卡宾的金属→烯烃卡宾转移，螯合导向决定立体选择性 |

## 🎯 教学视角

### 学习路径建议

卡宾应在掌握碳正离子、碳负离子、自由基等活性中间体之后学习。建议先理解单线态和三线态的电子结构差异，再学习卡宾的产生方法（重氮化合物分解、α-消除），最后掌握其特征反应（环丙烷化、C-H插入）。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为卡宾是"缺电子的碳正离子" | 卡宾是二价碳，有孤对电子和空轨道，反应性与碳正离子不同，可发生协同反应 |
| 混淆单线态和三线态的反应性 | 单线态卡宾可协同加成（顺式加成），三线态卡宾按自由基机理反应（可能得顺反混合物） |
| 认为卡宾只能由重氮化合物产生 | 还可通过α-消除（如氯仿+碱生成:CCl₂）、光解酮等方法产生 |

### 入门级例题

**题目**：解释为什么二氯卡宾（:CCl₂）主要以单线态存在，而亚甲基（:CH₂）主要以三线态存在。

**解答**：二氯卡宾中Cl的孤对电子可向碳的空p轨道给电子（p-π共轭），稳定单线态。亚甲基无此稳定化作用，且两个非键电子分占两个轨道（三线态）时电子排斥更小，故三线态更稳定。

### 与现实世界的联系

- **药物合成**：环丙烷结构广泛存在于药物中（如抗疟药环丙沙星），Simmons-Smith反应是构建环丙烷的经典方法
- **材料科学**：卡宾可插入C-H键进行表面功能化，用于修饰碳纳米管和石墨烯
- **N-杂环卡宾（NHC）**：NHC是重要的有机催化剂和配体，2005年诺贝尔化学奖涉及其在烯烃复分解中的应用
