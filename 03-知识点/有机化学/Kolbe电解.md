# Kolbe电解

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 上位框架：[[电化学]] · [[自由基]] · [[偶联反应]]
- 同位比较：[[Wurtz偶联]]

## 一、定义

**Kolbe电解**（Kolbe electrolysis，又称 Kolbe 合成）指**羧酸盐的水/醇溶液在阳极发生氧化脱羧**，生成的烃基自由基两两偶联成烷烃的反应：

$$\mathrm{2\,RCOO^- \xrightarrow[\text{Pt 阳极}]{\text{电解}} R{-}R + 2\,CO_2\uparrow + 2e^-}$$

它以电化学方式实现了"羧酸 → 少一个碳的烷烃二聚体"，是**少数能直接把两个碳骨架拼接起来的经典方法**之一。

## 二、电极反应

以羧酸钠 $\mathrm{RCOONa}$ 水溶液、惰性（Pt）电极为例：

**阳极（氧化，核心反应）**：

$$\mathrm{RCOO^- - e^- \longrightarrow RCOO\cdot \longrightarrow R\cdot + CO_2\uparrow}$$

$$\mathrm{2\,R\cdot \longrightarrow R{-}R}$$

**阴极（还原）**：

$$\mathrm{2\,H_2O + 2e^- \longrightarrow H_2\uparrow + 2\,OH^-}$$

**总反应**：

$$\mathrm{2\,RCOONa + 2\,H_2O \xrightarrow{\text{电解}} R{-}R + 2\,CO_2\uparrow + H_2\uparrow + 2\,NaOH}$$

注意阴极放出 $\mathrm{H_2}$、溶液逐渐变碱——Kolbe 电解**不是"电解水顺便脱羧"，两个电极各贡献一半反应**，写总方程式必须两半都配平。

> 相关题：[[题-032-4-1-双膜电解阳极半反应]]（第 32 届初赛 4.2：双离子交换膜电解槽中 Kolbe 型阳极氧化，要求写阳极半反应）

## 三、反应机理

### 3.1 阳极侧四步

1. **羧酸根迁移至阳极并放电**（单电子转移，SET）：
   $$\mathrm{RCOO^- \xrightarrow{-e^-} RCOO\cdot}$$
2. **脱羧**：羧酸自由基极不稳定，立即放出一分子 $\mathrm{CO_2}$：
   $$\mathrm{RCOO\cdot \longrightarrow R\cdot + CO_2}$$
3. **自由基在电极表面高浓度富集**：这是偶联能发生的关键——阳极附近自由基局部浓度远高于溶液本体。
4. **二聚**：
   $$\mathrm{R\cdot + R\cdot \longrightarrow R{-}R}$$

### 3.2 为什么烃基自由基会"二聚"而不是乱反应

自由基的命运取决于**浓度与竞争速率**。Kolbe 电解的设计正是为了让二聚占优：

- 阳极表面自由基生成速率极快 → 局部浓度极高 → 二聚（二级反应，对 [R·] 二次依赖）被显著加速
- 副反应（夺氢、歧化）多为一级或依赖溶剂，在此条件下被压制
- 因此**高电流密度**是 Kolbe 电解的必要条件，不只是"快一点"

自由基的一般行为与稳定性规律见 [[自由基]]。

### 3.3 驱动力

脱羧的不可逆性来自 $\mathrm{CO_2}$ **气体逸出体系**，使平衡单向移动；同时断裂的是较弱的 $\mathrm{C{-}C(=O)}$ 键，并生成稳定的 $\mathrm{CO_2}$。

## 四、适用范围

| 底物 | 结果 |
|:---|:---|
| 一级羧酸盐 $\mathrm{RCOO^-}$（R 为直链一级） | ✅ 最佳，产率高 |
| 二级羧酸盐 | 尚可，副反应增多 |
| 三级羧酸盐 | ❌ 生成的三级自由基易歧化/消除 |
| $\alpha$ 位有杂原子或芳基的羧酸盐 | ⚠ 易走 Hofer–Moest 途径（见 §五） |
| 二元羧酸**单酯**（$\mathrm{^-OOC{-}(CH_2)_n{-}COOR}$） | ✅ **最有用的合成应用** |
| 芳基羧酸盐 | ❌ 芳基自由基活性过高，难控制 |

### 4.1 最有价值的合成应用：二元羧酸单酯的偶联

$$\mathrm{2\,ROOC{-}(CH_2)_n{-}COO^- \xrightarrow{\text{电解}} ROOC{-}(CH_2)_{2n}{-}COOR + 2\,CO_2}$$

两个单酯分子各脱掉一个 $\mathrm{CO_2}$，剩下的两段碳链首尾相接，**碳链长度翻倍**且两端仍保留酯基。这是制备长链二元羧酸酯（如麝香酮、环十五酮前体）的经典路线——比逐步增长碳链的常规方法高效得多。

半酯的酸性被保留（一端是 $\mathrm{-COO^-Na^+}$，可被阳极氧化），另一端酯基不参与电解，因此**偶联位置是选择性的**。

## 五、主要副反应

| 副反应 | 条件 | 产物 |
|:---|:---|:---|
| **Hofer–Moest 反应** | 自由基被**进一步氧化**为碳正离子（高电流密度、非水/混合溶剂） | 醇 $\mathrm{ROH}$、醚 $\mathrm{ROMe}$、烯烃 |
| 歧化 | 两个自由基间夺氢 | 烷烃 $\mathrm{RH}$ + 烯烃 |
| $\beta$-消除 | 自由基 $\beta$ 位有 H | 烯烃 |
| 与溶剂夺氢 | 自由基浓度不足 | 烷烃 $\mathrm{RH}$（相当于"还原性脱羧"） |

**Hofer–Moest 是 Kolbe 最主要的竞争通道**：关键在于 $\mathrm{R\cdot}$ 是被**另一个**自由基捕获（→ 偶联），还是在阳极**再失一个电子**变成 $\mathrm{R^+}$（→ 醇/醚）。电流密度越高、溶剂给质子能力越强、R 越能稳定正电荷（苄基、三级），越偏向 Hofer–Moest。

## 六、交叉 Kolbe 与分子内 Kolbe

- **交叉（混合）Kolbe**：两种不同羧酸盐混合电解，得 $\mathrm{R^1{-}R^1}$、$\mathrm{R^1{-}R^2}$、$\mathrm{R^2{-}R^2}$ 的**统计混合物**，分离困难 —— 除非其中一种**大幅过量**，才可能以交叉产物为主。合成价值有限。
- **分子内 Kolbe**：同一分子两端各带一个羧酸根时，脱羧后两个自由基**首尾自偶联关环**，是构筑中环/大环的途径之一。

## 七、与 Wurtz 偶联的比较

两者都是"两个烃基片段拼起来"，但**起始原料与机理完全不同**：

| | **Kolbe 电解** | **Wurtz 偶联** |
|:---|:---|:---|
| 原料 | **羧酸盐** $\mathrm{RCOO^-}$ | **卤代烷** $\mathrm{R{-}X}$ |
| 电子来源 | **电极**（外加电压） | **碱金属 Na**（化学还原） |
| 中间体 | 烃基**自由基** | 烃基**自由基**（或有机钠，尚有争议） |
| 碳数变化 | **减少 1 个碳**（脱羧） | **不变** |
| 驱动力 | $\mathrm{CO_2}$ 逸出 | $\mathrm{NaX}$ 生成 |
| 条件 | 电解槽、高电流密度、Pt 电极 | 无水乙醚、金属钠 |
| 主要副反应 | Hofer–Moest、歧化 | 消除成烯、重排 |
| 适用 | 一级羧酸盐最佳 | 一级卤代烷最佳 |

**记忆要点**：Kolbe 丢一个碳（脱羧），Wurtz 不丢碳；Kolbe 用电，Wurtz 用钠。

更完整的偶联反应体系见 [[偶联反应]]、[[Wurtz偶联]]；电极过程的热力学框架见 [[电极电势]]。

## 八、解题要点

遇到"羧酸盐电解"类问题，按序判断：

1. **认出阳极事件**：羧酸根 $-\mathrm{e^-}$ → 脱 $\mathrm{CO_2}$ → 烃基自由基（**碳数减一**）
2. **认出阴极事件**：水（或 $\mathrm{H^+}$）还原放 $\mathrm{H_2}$，**溶液变碱**
3. **写总反应**：两半反应配平后相加，别忘了 $\mathrm{NaOH}$（或对应碱）在产物侧
4. **判主产物**：一级自由基 → 偶联 $\mathrm{R{-}R}$；能稳定正电荷的 → Hofer–Moest 得醇
5. **若底物是二元羧酸单酯** → 偶联后碳链翻倍、两端保留酯基

## 九、常见误区

| 误区 | 纠正 |
|:---|:---|
| 认为产物碳数不变 | 脱掉了 $\mathrm{CO_2}$，**每个片段少一个碳** |
| 只写阳极半反应就算完 | 总方程式必须配平阴极（$\mathrm{H_2}$）与碱的生成 |
| 认为电解的是水 | 阳极是**羧酸根**放电，不是 $\mathrm{OH^-}$ |
| 认为任何羧酸盐都能偶联 | 一级最佳；三级、芳基走副反应 |
| 把 Kolbe 与 Wurtz 混为一谈 | 一个脱羧用电、一个不脱羧用钠 |
| 认为电流密度无关紧要 | 高电流密度是压制夺氢副反应、保证二聚的关键 |
| 认为混合羧酸盐电解可得纯交叉产物 | 得统计混合物，需某一组分大幅过量 |
