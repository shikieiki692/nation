# Haworth式 (Haworth Projection)

## 定义

Haworth式（哈沃斯投影式）是英国化学家Walter Haworth提出的一种表示糖类环状结构的平面投影方法。它将单糖的环状结构画成一个垂直于纸面的平面环（通常为五元环或六元环），用粗线表示朝向观察者的一侧，能够清晰地展示环上各取代基的空间取向。

## 核心原理

### 1. 基本绘制规则
- **六元环（吡喃糖）**：环平面垂直于纸面，氧原子通常位于右上角
- **五元环（呋喃糖）**：氧原子位于上方
- **粗线表示**：环中靠近观察者的键用粗线表示
- **取代基方向**：环平面下方的取代基向下（垂直），上方的取代基向上（垂直）

### 2. D/L构型与Haworth式的关系
- **D-型糖**：Haworth式中 $CH_2OH$ 基团位于环平面上方（C5位）
- **L-型糖**：Haworth式中 $CH_2OH$ 基团位于环平面下方

### 3. Fischer式转换为Haworth式的规则
- **D-型糖**：
  - Fischer式中右侧的羟基在Haworth式中向下
  - Fischer式中左侧的羟基在Haworth式中向上
- **C5羟基与醛基/酮基反应**形成半缩醛/半缩酮环

### 4. $\alpha$ 和 $\beta$ 异头物的表示
- **$\alpha$-异头物**：异头碳上的半缩醛羟基与 $CH_2OH$ 基团位于环的异侧（D-糖中向下）
- **$\beta$-异头物**：异头碳上的半缩醛羟基与 $CH_2OH$ 基团位于环的同侧（D-糖中向上）

## 与其他知识点的联系

- **Fischer投影式**: Haworth式由Fischer式转换而来，两者是糖类立体化学表达的两种重要方式
- **单糖**: 单糖的环状结构是Haworth式表达的对象
- **糖的构型与变旋**: Haworth式能直观展示 $\alpha$/$\beta$ 异头物的区别，是理解变旋现象的基础
- **糖苷**: 糖苷键的形成和构型在Haworth式中可以清晰表达

**Fischer → Haworth 转换规则**（以 D-葡萄糖为例）：

1. Fischer 投影式向右写的 -OH → Haworth 式中在环平面**下方**
2. Fischer 投影式向左写的 -OH → Haworth 式中在环平面**上方**
3. D-糖的 CH₂OH 在环平面**上方**
4. 异头碳 -OH：α 型在环平面下方（D-糖），β 型在上方

**口诀**："右下左上，D 上 α 下"。即 Fischer 中右侧的基团在 Haworth 中向下，左侧向上；D-糖的 CH₂OH 向上，α-异头碳 OH 向下。

**Haworth式与椅式构象的关系**：
- Haworth 式是平面表示，实际吡喃糖以椅式构象存在
- 转换时：Haworth 式中向上的取代基在椅式构象中为**直立键(axial)**或**平伏键(equatorial)**，取决于取代基位置
- β-D-葡萄糖的所有大基团（OH, CH₂OH）均处于平伏键 → 最稳定 → 在平衡中占 64%

**常见单糖 Haworth 式**：
- D-吡喃葡萄糖：α 型 C1-OH 向下，β 型 C1-OH 向上
- D-呋喃果糖：五元环，C2 为异头碳
- D-吡喃半乳糖：C4-OH 向上（与葡萄糖的差异仅在 C4）

**Haworth式的局限性**：
1. 是平面表示，不能反映真实构象（椅式更准确）
2. 不能显示环的扭曲和张力
3. 对呋喃糖（五元环）的表示不够直观（信封式/扭船式构象）
4. 不能反映取代基的轴/赤道关系（需转换为椅式构象）
5. 竞赛中常用 Haworth 式判断 α/β 构型和糖苷键类型，但分析稳定性时需用椅式

**Haworth式的局限性和使用注意事项**：
1. Haworth式将糖环画成平面正多边形，但实际吡喃糖以椅式构象存在（¹C₄或⁴C₁），呋喃糖为信封式或扭船式——Haworth式无法体现构象差异
2. Haworth式中取代基的"上/下"仅表示相对立体化学（α/β），不反映实际键角和空间位阻
3. 无法体现异头效应（anomeric effect）——axial vs equatorial偏好在Haworth式中不可见
4. 多糖链的柔性（构象翻转、糖苷键旋转角φ/ψ）在Haworth式中无法表示
5. 大环糖（如环糊精）的Haworth式极难画准，建议用椅式或3D模型

**使用建议**：
- 初赛常用Haworth式判断α/β构型和糖苷键位置——足够
- 决赛涉及构象分析时，必须转化为椅式构象讨论
- 需要讨论稳定性（如α vs β葡萄糖比例）时，应引入异头效应和椅式构象
