# 有机化学基础

> 本页是有机化学模块的**总览地图**：不展开任何具体反应的机理细节，而是给出官能团体系、结构语言、电子效应、反应类型四条主线的框架，并指向各具体 KP。细节请沿链接下钻。

## 一、定位

这一页作为"有机起步框架"入口，用来收拢官能团、结构表示、酸碱观与反应分类这些最基础的公共语言。学完本页，学生应能回答三个问题：**这个分子属于哪类（官能团）？它的电子往哪流（电子效应）？它能发生哪类反应（反应类型）？**

## 三、结构与表示主线

### 3.1 碳的成键与杂化

- 碳四价：sp³（四面体，109.5°）、sp²（平面三角，120°）、sp（直线，180°）。
- **杂化直接决定性质**：s 成分越高电子越靠近核——C–H 酸性 sp > sp² > sp³（乙炔 pKa ≈ 25，乙烯 ≈ 44，乙烷 ≈ 50）；键长 sp < sp² < sp³。
- 相关 KP：[[诱导效应]]、[[Bent规则]]（张力环杂化修正）

### 3.2 结构式语言

- Lewis 式 / Kekulé 式（键线式）/ 楔形式 / 锯架式 / 纽曼投影式 / Fischer 投影式。
- 有机 Lewis 式惯例：不标孤对电子，但**必须标形式电荷**（八隅律成键数 +1 → 正电荷，−1 → 负电荷）。
- 共振论：真实结构是共振式的叠加，判断主共振式看电荷分布与八隅体完整性。相关 KP：[[Lewis式]]、[[共振论]]、[[构象异构]]

### 3.3 官能团体系（识别是审题第一步）

| 类别 | 代表官能团 | 代表化合物类 | 下钻 KP |
|:---|:---|:---|:---|
| 烃 | C=C、C≡C、芳环 | 烯、炔、芳烃 | [[加成反应]]、[[芳香亲电取代反应]] |
| 含卤 | C–X | 卤代烃 | [[SN1反应]]、[[SN2反应]]、[[E2反应]] |
| 含氧（单键） | –OH、C–O–C | 醇、醚、环氧化合物 | [[有机氧化反应]]、[[有机还原反应]] |
| 含氧（羰基） | C=O 及衍生物 | 醛酮、羧酸、酯、酰胺、酰卤、酸酐 | [[羰基亲核加成]]、[[Aldol缩合]] |
| 含氮 | –NH₂、–NO₂、–C≡N | 胺、硝基化合物、腈 | （还原胺化见 [[有机合成]]） |

系统清单见 [[官能团]]。

## 四、电子效应与酸碱主线

有机化学的"统一货币"是**电子流向**：90% 的有机反应是离子型的，本质是富电子位点（电子源）进攻缺电子位点（电子穴）。

1. **诱导效应**：σ 链传递的静电作用，用取代乙酸 pKa 标度量化（CH₃COOH 4.74 → ClCH₂COOH 2.86 → O₂NCH₂COOH 1.68）。→ [[诱导效应]]
2. **共轭效应**：π 轨道重叠传递，沿共轭链呈 "−+−+…" 交替极化。→ [[共轭效应]]
3. **超共轭效应**：σ 键 → 反键/空 p 轨道的给体-受体相互作用，是烷基稳定碳正离子、多取代双键更稳定等事实的统一解释。→ [[超共轭效应]]、[[给体-受体相互作用]]
4. **有机酸碱观**：Lewis 酸 = 亲电试剂，Lewis 碱 = 亲核试剂；pKa 是比较一切酸性的标尺；共轭酸 pKa < 10 一般是好离去基。→ [[有机酸碱性]]、[[离去基与pKa]]、[[亲核体与亲电体]]

## 五、反应类型主线

### 5.1 按电子转移方式分（ABOC 四大类）

| 类别 | 特征 | 典型 |
|:---|:---|:---|
| 离子型反应 | 电子对成对转移（双钩箭头） | SN1/SN2、亲电加成、羰基亲核加成 |
| 自由基反应 | 单电子转移（鱼钩箭头），链式 | 烷烃卤代、NBS 烯丙位溴代、过氧化物效应 |
| 周环反应 | 环状过渡态、协同 | Diels-Alder、电环化、[3,3]σ 重排 |
| 过渡金属催化 | 金属参与成键重组 | 偶联反应、复分解（决赛/信息题高频） |

### 5.2 按结果分（竞赛常用分类）

- **取代**：[[SN1反应]]、[[SN2反应]]、[[芳香亲电取代反应]]、[[芳香亲核取代]]
- **加成**：[[亲电加成]]（马氏规则）、[[亲核加成]]、[[直接加成与共轭加成]]（1,2 vs 1,4）
- **消除**：[[E1反应]]、[[E2反应]]（反式共平面）、[[Grob碎裂化反应]]
- **重排**：[[1,2-迁移与重排]]（Wagner-Meerwein）
- **氧化还原**：[[有机氧化反应]]、[[有机还原反应]]

### 5.3 活性中间体（机理题的四个主角）

[[碳正离子]]（6 电子，亲电）、[[碳负离子]]（8 电子，亲核）、[[自由基]]（单电子）、[[卡宾]]（中性缺电子）——判断"谁更稳定、下一步往哪走"是所有机理推断的固定动作。→ [[中间体]]

### 5.4 从反应到合成

单个反应学完后汇入 [[有机合成]]：逆合成分析（⇏、切断、合成子、FGI）是把零散反应组织成路线的框架，核心速查：1,3-关系→羟醛/Claisen/Mannich，1,5-关系→Michael。→ [[逆合成分析]]

## 六、建议学习顺序

1. **先认结构与官能团**：杂化、结构式、官能团识别（§三）
2. **再看电子效应与酸碱观**：诱导 → 共轭 → 超共轭，pKa 标尺（§四）
3. **进入基本反应类型**：取代/加成/消除 + 四大中间体（§五）
4. **最后综合**：机理书写（[[反应机理表示法]]、[[Grossman规则]]）→ 逆合成（[[有机合成]]）

## 八、🎯 教学视角

### 8.1 学习路径建议

有机化学基础是整个有机化学学习的起点，建议按照"结构→电子→反应"的逻辑推进。先掌握碳的杂化和官能团识别，再理解电子效应（诱导、共轭）和酸碱理论，最后进入取代、加成、消除等基本反应类型。每学一条主线都要"下钻"到对应 KP 完成细节，再回本页复盘框架。

### 8.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为有机化学就是"背反应方程式" | 有机化学的核心是理解电子流动和反应机理，掌握规律后可以推导产物 |
| 忽略杂化方式对性质的影响 | sp³、sp²、sp 杂化直接决定键角、键长、酸碱性和反应性，是结构分析的基础 |
| 混淆有机化学和无机化学的学习方法 | 有机化学更强调"结构决定性质"的逻辑推理，而非记忆周期表规律 |
| 把官能团当标签背 | 官能团的价值在于预测反应性：看到 C=O 就该想到亲核加成，看到 C–X 就该想到取代与消除 |

### 8.3 入门级例题

**题目**：为什么乙炔（HC≡CH）的酸性比乙烯（H₂C=CH₂）强？

**解答**：乙炔中碳为 sp 杂化（50% s 成分），乙烯中碳为 sp² 杂化（33% s 成分）。s 成分越高，电子越靠近原子核，碳负离子越稳定，共轭酸的酸性越强。因此乙炔 pKa ≈ 25，乙烯 pKa ≈ 44。

### 8.4 与现实世界的联系

- **生命科学**：生物大分子（蛋白质、核酸、糖类、脂质）都是有机分子，有机化学是理解生命的基础
- **材料科学**：塑料、橡胶、纤维、液晶等材料的性质由其有机结构决定
- **医药工业**：90% 以上的药物是有机分子，有机化学是药物发现和制造的核心学科
