# 乙酰乙酸乙酯合成法

## 一、定义

**乙酰乙酸乙酯合成法** 是以乙酰乙酸乙酯（CH₃COCH₂COOEt）为底物，利用其活泼 α-氢的酸性和亲核取代能力，经 **烷基化/酰基化 → 水解脱羧** 两步构建取代酮的经典合成方法。

- **核心原理**：乙酰乙酸乙酯中两个羰基之间的亚甲基（—CH₂—）的 pKa ≈ 11，可被乙醇钠等弱碱去质子化生成稳定的烯醇负离子
- **与丙二酸二乙酯合成法并列**为有机合成两大"β-二羰基合成策略"

## 二、反应流程

### 2.1 标准步骤

```
步骤 1：去质子化
  CH₃COCH₂COOEt + NaOEt → CH₃COCH⁻COOEt Na⁺ + EtOH

步骤 2：烷基化
  CH₃COCH⁻COOEt + R-X → CH₃COCHRCOOEt + X⁻

步骤 3：水解脱羧
  CH₃COCHRCOOEt → (1) OH⁻/H₂O, Δ → (2) H⁺ → CH₃COCH₂R + CO₂ + EtOH
```

**三步总结果**：R-X 将 R 基引入乙酰乙酸乙酯的 α-位 → 水解脱羧后得 **取代丙酮**（RCH₂COCH₃）

### 2.2 变体

| 变体 | 步骤 2 试剂 | 产物 |
|:-----|:-----------|:-----|
| 烷基化 | R-X (伯卤代烃) | 单取代丙酮 RCH₂COCH₃ |
| 二烷基化 | R-X 两次 | 二取代丙酮 R₂CHCOCH₃ |
| 酰基化 | R-COCl 或 R-COOR' | β-二酮 RCOCH₂COCH₃ |
| 烯丙基化 | CH₂=CHCH₂-X | 不饱和酮 |

## 四、教学常见节点

- **两步选择性**：先烷基化再脱羧 vs 先脱羧再烷基化——不能先脱羧
- **卤代烃限制**：必须用伯卤代烃或甲基卤（Sₙ2 要求）
- **与丙二酸酯对比**：乙酰乙酸乙酯→取代酮；丙二酸二乙酯→取代羧酸
- **二烷基化**：可连续两次引入不同 R 基（第一步单取代，第二步再取代）
- **分子烷基化**：二卤代物可得环酮（Dieckmann 缩合的先驱）

## 五、竞赛拓展

- **不对称合成中的应用**：手性相转移催化下的不对称烷基化
- **Michael 加成串联**：可与 α,β-不饱和羰基发生 Michael 加成
- **与丙二酸酯互补选择**：合成酮 vs 合成酸的路线选择判断
- **Carroll 重排**：β-酮酸烯丙基酯的 [3,3]-σ 迁移脱羧

## §12 教学视角

### 学生常见认知误区
- **误区1：「可以先脱羧再烷基化」** → 这是最致命的操作错误。脱羧后变成丙酮，丙酮的 α-H 虽可去质子化但形成的烯醇负离子不如乙酰乙酸乙酯稳定，且烷基化产率极低 → **口诀：先烷后脱是正路，先脱后烷无退路**
- **误区2：「仲卤代烃和叔卤代烃也能用」** → SN2 烷基化要求底物为伯卤代烃或甲基卤。仲卤代烃会发生消除竞争，叔卤代烃完全不反应 → **口诀：烷基化要伯碳，仲碳消除叔碳废**
- **误区3：「乙酰乙酸乙酯和丙二酸二乙酯产物相同」** → 乙酰乙酸乙酯水解脱羧得取代酮（RCH₂COCH₃），丙二酸二乙酯水解脱羧得取代乙酸（RCH₂COOH）→ **口诀：乙酰出酮，丙二出酸，一字之差产物远**
- **误区4：「二烷基化时两个 R 基相同更简单」** → 两步烷基化可引入不同 R 基，但第二步由于空间位阻增大，产率通常低于第一步 → **口诀：两次烷基化，先小后大是上策**

### 入门级例题
**题目**: 用乙酰乙酸乙酯合成法，设计从 BrCH₂CH₂Br 和 CH₃I 合成 2-甲基环戊酮的路线。
**分析**: 目标是环戊酮（五元环酮）。逆合成分析：环戊酮可由 1,5-二溴戊烷的分子内烷基化（Dieckmann 型）得到，但本题给的是 BrCH₂CH₂Br（二溴乙烷），需要两个乙酰乙酸乙酯单元分别烷基化后偶联。
**解答**: 步骤 1：NaOEt 去质子化乙酰乙酸乙酯；步骤 2：与 BrCH₂CH₂Br 双烷基化（两个乙酰乙酸乙酯分别接在溴乙烷两端）；步骤 3：碱性水解 + 酸化脱羧；步骤 4：分子内 Aldol 缩合成环。总结果得环戊酮衍生物。
**反思**: 分子内烷基化是构建环酮的重要策略。二卤代物 + 两当量 β-二羰基化合物 → 环化产物，这是 Dieckmann 缩合的延伸思路。

### 与现实/直觉的连接
- **乙酰乙酸乙酯合成法如同「积木组装」**：乙酰乙酸乙酯是「底座」，R-X 是「积木块」，去质子化→烷基化→脱羧三步就像「拆掉底座露出积木」
- **与丙二酸酯的互补关系**：如同「锤子和螺丝刀」——合成酮用乙酰乙酸乙酯，合成酸用丙二酸酯，工具选对事半功倍
- **工业应用**：许多药物中间体（如布洛芬前体）的合成都用到 β-二羰基策略

### 教学建议
1. **先讲 Claisen 缩合再讲本反应**：乙酰乙酸乙酯本身就是 Claisen 缩合的产物，理解其来源有助于理解为什么 α-H 酸性如此之强
2. **用「保护-活化」策略解释**：两个羰基「保护」了中间的亚甲基，使其 pH ≈ 11 可被弱碱去质子化，这是整个方法的核心
3. **与丙二酸酯对比教学**：同一天讲两个反应，画对照表——底物、碱、产物、应用范围的异同，帮助学生建立「工具箱」思维
4. **强调 SN2 底物限制**：用具体例子展示仲卤代烃的消除竞争（如异丙基溴 → 丙烯为主产物），让学生「看到失败」才记住限制
5. **设计综合合成题**：给一个目标酮分子，让学生判断该用乙酰乙酸乙酯还是丙二酸酯路线，训练逆合成分析能力
