# 环烷烃

## 核心概念

环烷烃是碳原子形成环状结构的饱和烃。小环（三元环、四元环）存在显著的角张力和扭转张力，稳定性较差；五元环和六元环最为稳定；七元环以上的中环和大环存在跨环张力。

**一句话本质**：环烷烃的全部化学性质都可以从"**环张力**"这一条主线推导——张力来自成键几何被迫偏离理想值（sp³ 的 109.5°）与空间拥挤；张力越大，分子能量越高、越易开环反应。环己烷通过椅式构象几乎完全消除张力，因此成为"参考零点"：凡与无张力参照的偏差，就是该环的张力能。

**三类张力**（区分清楚是解张力题的第一步）：
1. **角张力（Baeyer 张力）**：环小迫使 C–C–C 键角偏离 109.5°（环丙烷 60°、环丁烷约 90°）→ 键的弯曲使轨道重叠变差
2. **扭转张力（Pitzer 张力）**：相邻 C–H/C–C 键被迫处于重叠式（环丙烷全重叠、环丁烷近重叠），无交叉式缓解
3. **跨环张力（van der Waals 张力）**：中环（8~11 元）环内相对的两个 H 距离小于范德华接触距离，互相排斥——这是中环反而不如大环稳定的原因

## 环的大小与稳定性（燃烧热证据）

张力能最经典的证据是**每个 CH₂ 的燃烧热**（无张力参考值 ≈ 659 kJ/mol，即直链烷烃的每 CH₂ 值）：

| 环 | 每 CH₂ 燃烧热 / kJ·mol⁻¹ | 与无张力的差 | 总张力能（近似） |
|---|---|---|---|
| 环丙烷 C₃H₆ | ≈ 697 | +38 | ≈ 115 kJ/mol |
| 环丁烷 C₄H₈ | ≈ 686 | +27 | ≈ 110 kJ/mol |
| 环戊烷 C₅H₁₀ | ≈ 664 | +5 | ≈ 27 kJ/mol |
| 环己烷 C₆H₁₂ | ≈ 659 | 0 | ≈ 0（无张力） |
| 环庚烷及以上 | 662~664 | 略正 | 中环有跨环张力 |

**读表结论**：环己烷与直链烷烃的每 CH₂ 燃烧热相同 → **环己烷无张力**（椅式构象完美解决角与扭转张力）；环丙烷/环丁烷张力最大（各约 110 kJ/mol，相当于一根键的 1/3）；环戊烷张力很小（信封式构象缓解扭转张力，仅余轻微角张力）。

**Baeyer 张力学说的局限**：Baeyer 假设环是**平面**的，据此推出"环越大越稳定"——对三元到六元环成立，但无法解释中环（8~11 元）反而张力回升、大环（>12 元）又变稳定。现代解释：中环的跨环张力来自环内 H–H 拥挤，大环因可采取非平面折叠构象而重新稳定。**"平面假设"是 Baeyer 学说的唯一错误**，竞赛判断题常考这一点。

## 构象：为什么六元环最舒服

- **环己烷椅式**：所有 C–C–C 角 ≈ 111°（接近 109.5°）、所有相邻键均为交叉式 → 角张力与扭转张力双双为零；有 a 键（直立）与 e 键（平伏）之分，大取代基占 e 键最稳（见 [[构象分析]]）
- **环戊烷信封式**：一个碳翘出平面，牺牲少量角张力换取扭转张力大幅降低
- **环丁烷蝴蝶式**：折叠以降低扭转张力（代价是角张力略升）
- **环丙烷**：必须平面（三点定面），角张力 + 全重叠扭转张力都无解 → 张力最大

**推论（高频考点）**：环丙烷的 C–C 键是"弯曲键"（香蕉键），轨道重叠差、键能低、表现出**类似烯烃的反应性**（可加氢、加 Br₂、加 HX 开环），而环戊烷/环己烷只发生自由基取代——"小环像烯、大环像烷"。

## 反应性（由张力决定）

| 环大小 | 典型反应 | 说明 |
|---|---|---|
| 环丙烷 | H₂/Ni 开环成丙烷；Br₂ 开环得 1,3-二溴丙烷；HX 开环（马氏规则） | 三元环最活泼，**开环而非加成后保留环** |
| 环丁烷 | 需较剧烈条件才开环（H₂ 高温） | 张力次之 |
| 环戊/环己烷 | 光照卤代（自由基取代），不易开环 | 与烷烃无异 |
| 环丙烷衍生物 | 开环位置有选择性（取代多的键先断） | 碳正离子稳定性导向 |

**注意**：环丙烷与 Br₂/CCl₄ 反应使其褪色（似烯），但**不能使 KMnO₄ 褪色**（不被氧化）——这是区分"环丙烷"与"烯烃"的经典实验判据。

## 立体化学：环上的顺反与取代

- 环限制旋转 → 环上两个取代基有**顺反异构**（同侧 cis / 异侧 trans），与链状烷烃不同
- 环己烷二取代：1,2-、1,3-、1,4- 各有 cis/trans；trans-1,2- 可为 (e,e) 或 (a,a)，(e,e) 更稳
- 稠环：**十氢化萘**有顺/反稠合（反式更稳，两个环己烷椅式刚性连接）
- 桥环与笼状：**金刚烷**（adamantane，C₁₀H₁₆）是椅式环己烷的完美三维延伸——高度对称、几乎无张力，是"金刚石结构的最小分子片段"（本页 aliases 含金刚烷）

## 命名与典型分子

- **单环**：环 + 碳原子数 + 烷（环丙烷/环丁烷/环戊烷/环己烷）；取代基编号取最小，有官能团时环作取代基
- **螺环**：两环共用一个碳（螺[2.4]庚烷——方括号内为两环除螺原子外的碳数，从小到大）
- **桥环/稠环**：共用两个及以上碳（二环[2.2.1]庚烷 = 降冰片烷；十氢化萘 = 二环[4.4.0]癸烷）
- **笼状**：金刚烷 C₁₀H₁₆（高度对称、mp 高、几乎无张力）、立方烷 C₈H₈（张力极大，人工合成里程碑）

**通式与不饱和度**：单环环烷烃 CₙH₂ₙ（与单烯烃同分异构！）——每多一个环，Ω 多 1：Ω = 环数 + 双键数（不计三键另计）。竞赛给分子式判结构时，"C₆H₁₂ 可能是环己烷也可能是己烯"是标准陷阱。

## 谱学特征（鉴别环丙烷的钥匙）

- **¹H NMR**：环丙烷的 CH₂ 质子出现在 **δ ≈ 0.2**（异常高场，远低于普通烷烃的 1.2~1.5）——原因：三元环的环电流产生屏蔽区（类似芳环但方向相反），使环上质子显著高场位移。**看到 δ 0.2 附近的 CH₂ 信号，先想环丙烷。**
- **¹³C NMR**：环丙烷碳 δ ≈ 3~10（同样异常高场）
- **IR**：与烷烃近似（无特征官能团峰），环丙烷的 C–H 伸缩略偏高（≈3050 cm⁻¹，因 s 成分较高）
- **MS**：环烷烃分子离子峰较明显（环不易碎），常见 M−28（失 C₂H₄）碎片

## 工业与来源

- **石油组分**：环烷烃是石油（尤其环烷基原油）的主要组分之一
- **催化重整**：环己烷/甲基环戊烷在 Pt/Al₂O₃ 上脱氢芳构化 → 苯/甲苯（提高汽油辛烷值 + 提供芳烃原料）——"环烷烃 → 芳烃"是炼厂的核心反应之一
- **开环聚合**：环己内酰胺开环聚合 → 尼龙-6；环氧化物（三元环）开环聚合 → 聚醚——小环张力是聚合的热力学驱动力

## 完整算例（张力能估算）

**题目**：环丙烷与环己烷的燃烧热分别为 −2091 与 −3952 kJ/mol。估算两者每个 CH₂ 的燃烧热差，并说明化学含义。

**解答**：
- 环丙烷每 CH₂ = 2091/3 = 697 kJ/mol
- 环己烷每 CH₂ = 3952/6 = 659 kJ/mol
- 差 38 kJ/mol × 3 个 CH₂ = **约 114 kJ/mol**——即环丙烷比"三个无张力 CH₂"高出约 115 kJ/mol 的张力能

**含义**：这 115 kJ/mol 就是环丙烷易开环的热力学驱动力——开环后张力释放，故反应放热且活化能低。数量级感：约相当于两根 C–C 键键能的 1/3，足以让环丙烷在温和条件下与 Br₂/HX 反应。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 环越小越不稳定（线性外推） | 丙烷最不稳，但**中环（8~11）有跨环张力**反而回升，大环又变稳 | 稳定性：3 < 4 < 5 ≈ 7+ < 6（六元最稳），非线性 |
| 环己烷是平面正六边形 | 椅式构象，碳不在同一平面，键角 ≈111° | 平面环己烷会有角张力 120° + 全重叠——不可能 |
| 所有环烷烃 C–C–C 键角 109.5° | 小环被迫偏离（环丙烷 60°） | 只有环己烷椅式接近理想角 |
| 环丙烷与烯烃性质完全相同 | 都能使 Br₂ 褪色，但环丙烷**不使 KMnO₄ 褪色**（抗氧化） | 用 KMnO₄ 区分环丙烷与丙烯 |
| Baeyer 平面假设当正确 | 中环/大环非平面，故其"越大越稳"预言在中环失效 | 现代判据：角张力 + 扭转张力 + 跨环张力三项加和 |
| 环上取代无顺反 | 环阻碍旋转 → 有 cis/trans 异构 | 1,2-二甲基环己烷有顺反两种（链状烷烃无） |

## 🎯 教学视角

### 学习路径建议
环烷烃应在学习烷烃结构和构象分析之后引入。先理解环状结构带来的张力概念（角张力、扭转张力、跨环张力），再通过Baeyer张力学说和构象分析理解不同环大小的稳定性差异。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 环越小越不稳定 | 环丙烷最不稳定，但环丁烷也不稳定，五元环和六元环最稳定 |
| 环己烷是平面正六边形 | 环己烷采取椅式构象，碳原子不在同一平面上 |
| 所有环烷烃的C-C-C键角都是109.5° | 小环中键角被迫偏离sp³的理想角度，产生角张力 |

### 入门级例题
**题目**：为什么环丙烷比环己烷活泼得多？
**解答**：环丙烷的C-C-C键角被迫压缩到60°（远小于sp³理想的109.5°），存在巨大的角张力。同时相邻C-H键处于重叠式构象，有扭转张力。这些张力使环丙烷容易开环反应，而环己烷通过椅式构象消除了一切张力。

### 与现实世界的联系
1. **药物化学**：环丙烷基团常用于药物设计中增强代谢稳定性和结合力
2. **石油化工**：环烷烃是石油的重要组分，催化重整可将环烷烃转化为芳烃
3. **高分子材料**：环状单体（如环己内酰胺）开环聚合生产尼龙等材料

> **记忆锚**：张力三兄弟——角张力（小环）、扭转张力（重叠式）、跨环张力（中环）；六元椅式零张力是标尺；"小环像烯能开环、大环像烷只取代"；KMnO₄ 不褪色 = 环丙烷非烯。

## 竞赛考察要点

1. **稳定性排序**：给几个环按张力/燃烧热排序（六元最稳、三元最不稳、中环回升）。
2. **Baeyer 学说评价**：指出平面假设的错误与中环反常。
3. **反应性判断**：环丙烷/环丁烷开环条件与产物（HX 开环的马氏取向）。
4. **构象与取代**：环己烷 a/e 键、顺反二取代稳定性（联动 [[构象分析]]）。
5. **鉴别题**：环丙烷 vs 烯烃（Br₂ 都褪色、KMnO₄ 只烯褪色）。
6. **结构推断**：稠环/桥环/金刚烷的对称性与分子式（CₙH₂ₙ 通式与不饱和度 Ω = 1 对应一个环）。

## 关键结论速记

- 张力三源：角张力（几何偏离）+ 扭转张力（重叠式）+ 跨环张力（中环 H–H 拥挤）。
- 稳定性：环己烷（零张力）> 环戊烷 ≈ 大环 > 环丁烷 > 环丙烷；中环 8~11 元反常回升。
- 证据：每 CH₂ 燃烧热（无张力 659；环丙烷 697、环丁烷 686、环己烷 659）。
- 反应性：小环（3、4）开环似烯，五/六元环只取代似烷；环丙烷不耐氧化（KMnO₄ 不褪色）。
- 构象：环己烷椅式（a/e）、环戊烷信封式、环丁烷蝴蝶式、环丙烷必平面。
- 立体：环阻碍旋转 → 有 cis/trans；金刚烷是椅式环己烷的三维延伸。
- 收尾自检：能按张力排序、能用燃烧热算张力能、能区分环丙烷与烯烃——本页达标。
- 命名锚：螺[n.m]（共用 1 碳）、二环[a.b.c]（桥碳数降序）、金刚烷 C₁₀H₁₆ / 立方烷 C₈H₈。
- 谱学锚：¹H NMR δ ≈ 0.2 的 CH₂ ⇒ 环丙烷（环电流屏蔽），¹³C δ 3~10 同证。
- 通式锚：单环 CₙH₂ₙ 与单烯同分异构——给分子式判结构时别漏"环"这个选项（Ω = 环 + 双键）。
- 反应锚：环丙烷 + HX 开环遵循马氏规则（H 加到含 H 多的碳），断键发生在取代较多的 C–C 上（碳正离子稳定性导向）。
- 构象锚：十氢化萘反式稠合（两椅刚性）比顺式稳定；甾体骨架由三个稠合六元环 + 一个五元环构成，全反式稠合最稳。
- 数值锚：环丙烷键角 60°、张力能约 115 kJ/mol；环己烷椅式键角约 111°、张力能约 0。
- 易混锚：环丙烷与 Br₂ 反应是**开环加成**（得 1,3-二溴丙烷），不是取代——写产物别写成溴代环丙烷。
- 复习联动：本页讲"环的大小-张力-反应性"主线，构象细节（a/e 键、翻转能垒、A 值）看 [[构象分析]]，开环机理看 [[三元环开环]]，张力定量看 [[环张力]]——四页合读构成脂环烃完整图景。
- 一句话收束：环烷烃的所有"反常"（小环像烯、中环不稳、六元最舒服）都来自同一个词——张力；把张力的三个来源和六元环的零张力标尺记住，本页全部结论都能自己推出来。
