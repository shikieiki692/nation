# 有机金属试剂

## 一、定位

有机金属试剂是碳负性合成子的重要来源，常用于成键、加成和官能团转化。

## 二、学习重点
- 识别“强亲核 / 强碱”双重属性
- 区分 Grignard、RLi 与有机铜试剂的反应性
- 先判断兼容官能团，再决定是否可用

## 三、核心原理

### 3.1 碳-金属键的极性与反应性

有机金属试剂中碳-金属键（C–M）的极化方向由电负性差决定。碳的电负性（2.5）高于常见金属：Mg（1.2）、Li（1.0）、Cu（1.9）。因此 C–M 键中碳带部分负电荷（δ⁻），金属带部分正电荷（δ⁺），使碳具有亲核性和碱性。

电负性比较：C(2.5) > Cu(1.9) > Mg(1.2) > Li(1.0)

电负性差越大，键极化程度越强，碱性通常也越强。

### 3.2 常用有机金属试剂对比表

| 试剂 | 制备 | 碱性 | 亲核性 | 1,2-加成 | 1,4-加成 | 兼容性 |
|:---|:---|:---|:---|:---|:---|:---|
| RMgBr | RBr + Mg / Et₂O | 强 | 中等 | ✓ 主 | 少 | 不耐酸性 H |
| RLi | RBr + 2Li | 更强 | 强 | ✓ | 少 | 更不耐 |
| R₂CuLi | 2RLi + CuI | 弱 | 中等 | 少 | ✓ 主 | 较好 |
| RZnX | RBr + Zn | 中等 | 中等 | ✓ | 取决于条件 | 较好 |

关键规律：碱性越强 → 兼容性越差（更不耐活泼氢）；有机铜试剂因碱性弱而兼容性较好，且具有独特的共轭加成选择性。

### 3.3 核心反应

**Grignard 加成**（1,2-加成）

R'MgBr + R₂C=O → R₂R'C–OMgBr →（H₃O⁺）→ R₂R'C–OH

- 醛 → 仲醇
- 酮 → 叔醇
- CO₂ → 羧酸（R'MgBr + CO₂ → R'COOH）

**有机铜共轭加成**（1,4-加成）

R₂CuLi + α,β-不饱和酮 → 1,4-加成产物（β-位引入 R 基团）

有机铜试剂对共轭体系的 1,4-加成具有高度选择性，是构建β-取代羰基化合物的重要方法。

**有机锂去质子**

RLi + 末端炔烃 → 炔化锂（acetylide）

有机锂的强碱性使其可定量去质子化末端炔烃（pKa ≈ 25），生成的炔化锂是重要的亲核试剂。

### 3.4 合成应用

- **C–C 键构建**：Grignard 反应是有机合成中最重要的 C–C 键构建方法之一，碳负性合成子与各类亲电体反应可高效构建碳骨架。
- **兼容性问题**：Grignard 试剂和有机锂试剂不耐以下官能团中的酸性氢（活泼氢）：–OH、–NH、–COOH、–CHO。合成设计时必须先判断目标分子中的官能团兼容性，必要时使用保护基策略。
- **选择性控制**：通过选择不同有机金属试剂可控制反应选择性——需要 1,2-加成选 Grignard 或 RLi，需要 1,4-加成选有机铜试剂。

## 四、与其他知识点的关系

- **羰基化学**：Grignard 试剂与醛酮的加成是羰基亲核加成的典型应用，需结合羰基亲电性理解反应机理。
- **亲核取代**：有机金属试剂的制备（RBr + Mg → RMgBr）涉及金属对碳-卤键的氧化加成，与 SN2 机理相关。
- **烯醇与烯醇盐**：有机锂试剂可用于烯醇盐的制备（去质子化），与烯醇化学直接关联。
- **保护基策略**：因 Grignard 试剂不耐活泼氢，当分子中存在 –OH、–COOH 等基团时需使用保护基，与保护基策略知识联动。
- **金属有机化学深化**：有机金属试剂是过渡金属催化交叉偶联反应（Suzuki、Negishi 等）的基础，为后续学习铺路。

## 五、典型题型

**题型一：官能团兼容性判断**

给出含多种官能团的分子，判断能否直接使用 Grignard 试剂进行反应。需识别分子中的酸性氢（–OH、–NH、–COOH、–CHO），若存在则不可直接使用，需先保护。

**题型二：Grignard 合成设计**

给定目标醇（仲醇或叔醇），设计合理的 Grignard 合成路线：选择合适的羰基底物和 Grignard 试剂组合，写出反应方程式。

**题型三：试剂选择与反应选择性**

给定 α,β-不饱和羰基化合物，判断使用 Grignard 试剂与有机铜试剂分别得到什么产物（1,2-加成 vs 1,4-加成），并解释选择性原因。

## 🎯 教学视角

### 学习路径建议

有机金属试剂应在掌握亲核取代和羰基化学之后学习。建议先理解碳-金属键的极性（碳带部分负电荷，具有亲核性），再学习Grignard试剂、有机锂试剂和有机铜试剂的制备与反应性差异，最后掌握它们在合成中的应用。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为所有有机金属试剂反应性相同 | Grignard试剂（强碱、中等亲核性）、有机锂（更强碱）、有机铜（共轭加成选择性）各有特点 |
| 忽略有机金属试剂的水敏感性 | Grignard试剂和有机锂遇水分解，必须在无水无氧条件下操作 |
| 混淆1,2-加成和1,4-加成 | Grignard试剂主要1,2-加成到羰基，有机铜试剂主要1,4-加成到α,β-不饱和羰基 |

### 入门级例题

**题目**：如何用Grignard试剂从环己酮合成1-甲基环己醇？

**解答**：环己酮 + CH₃MgBr（甲基Grignard试剂）→ 1-甲基环己醇。Grignard试剂的甲基碳（亲核体）进攻环己酮的羰基碳（亲电体），生成叔醇。

### 与现实世界的联系

- **药物合成**：Grignard反应是构建C-C键的经典方法，广泛用于药物中间体的合成
- **工业催化**：Ziegler-Natta催化剂（有机铝+TiCl₄）是聚乙烯和聚丙烯工业的核心催化剂
- **材料科学**：有机金属化学气相沉积（MOCVD）使用有机金属前体制备半导体薄膜
