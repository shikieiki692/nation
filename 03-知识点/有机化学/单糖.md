# 单糖 (Monosaccharide)

## 定义

单糖是最简单的糖类，是不能再水解为更小糖分子的多羟基醛或多羟基酮。根据官能团不同分为醛糖（含醛基）和酮糖（含酮基）；根据碳原子数可分为丙糖、丁糖、戊糖、己糖等。

## 考纲对应

- **考纲编号**: 53
- **所属模块**: 糖类

## 核心原理

### 1. 结构特征
- 多羟基醛或多羟基酮
- 含有多个手性碳原子，存在大量立体异构体
- 最常见的单糖为己糖（如葡萄糖、果糖）和戊糖（如核糖）

### 2. 环状结构
- 单糖在水溶液中主要以环状半缩醛/半缩酮形式存在
- 形成吡喃糖（六元环）或呋喃糖（五元环）结构
- 产生新的手性中心（异头碳），形成 $\alpha$ 和 $\beta$ 异头物

### 3. 变旋现象
- 由于环状结构的打开与闭合，单糖在水溶液中会发生旋光度的变化
- 最终达到 $\alpha$ 和 $\beta$ 异头物的平衡混合物

## 与其他知识点的联系

- **糖类**: 单糖是糖类的基本组成单元
- **醛酮结构**: 单糖的化学性质源于醛基/酮基和羟基的共同作用
- **二糖与多糖**: 单糖通过糖苷键连接形成更复杂的糖类
- **还原糖**: 单糖通常具有还原性，是重要的还原糖
- **糖苷**: 单糖的半缩醛羟基参与形成糖苷键
- **Haworth式**: 用于表达单糖的环状结构
- **糖的构型与变旋**: 单糖是研究糖构型和变旋现象的核心对象

## 典型例题

**例题1**：判断下列单糖的构型（D/L 和 R/S）

D-葡萄糖的 Fischer 投影式中，最远手性碳（C5）的-OH 在右侧 → D 构型。
D/L 构型仅看最远手性碳，R/S 需用 CIP 规则逐个判断。

**例题2**：为什么 D-葡萄糖在水溶液中的比旋光度从 +112° 变为 +52.7°？

因为变旋现象：α-D-葡萄糖 ([α] = +112°) 和 β-D-葡萄糖 ([α] = +18.7°) 通过开链结构互变，达到平衡混合物（约 36% α, 64% β），[α] = +52.7°。

**化学性质**：

1. **氧化反应**：
   - 醛基氧化 → 糖酸（gluconic acid）：稀 HNO₃ 氧化
   - 伯醇氧化 → 糖醛酸（glucuronic acid）：选择性氧化 C6-OH
   - 醛基 + 伯醇均氧化 → 糖二酸（glucaric acid）

2. **还原反应**：
   - 醛基还原 → 糖醇（glucitol/sorbitol）：NaBH₄ 还原
   - 果糖还原 → 山梨糖醇 + 甘露糖醇（两种产物，因 C2 成新手性中心）

3. **成脎反应**：
   - 与过量苯肼反应生成糖脎（osazone）
   - C1 和 C2 都被苯肼氧化，因此 D-葡萄糖、D-果糖、D-甘露糖生成相同的脎
   - 糖脎为黄色结晶，可用于鉴别糖类

**Fischer → Haworth 转换规则**：

1. Fischer 投影式向右写 → Haworth 式中，右侧的 -OH 在环平面下方
2. Fischer 投影式向左写 → Haworth 式中，左侧的 -OH 在环平面之上
3. D-型糖的 CH₂OH 在环平面上方
4. 异头碳 -OH：α 型在环平面下方（D-型），β 型在环平面上方（D-型）

**D/L 与 R/S 构型对应**：

D/L 是相对构型（以甘油醛为标准），R/S 是绝对构型（CIP 规则）。
- D-甘油醛 = (R)-甘油醛（-OH 在 Fischer 投影式右侧 → 最远手性碳为 R）
- D-葡萄糖所有手性碳的 R/S 依次为：C2(R), C3(S), C4(R), C5(R)
- D/L 只看最远手性碳，R/S 需对每个手性碳分别判断

## 易错点

1. **D/L 不等于 R/S**：D-果糖的 C2 是 S 构型（酮糖），但仍是 D 型
2. **变旋不等于外消旋**：变旋是 α/β 异头物的平衡，不是对映体混合物
3. **果糖的脎与葡萄糖相同**：成脎反应只改变 C1 和 C2，C3-C5 不变
4. **吡喃糖 vs 呋喃糖**：葡萄糖主要以吡喃糖（六元环）存在，果糖在溶液中呋喃糖比例较高

## 教学视角

- 从 Fischer 投影式入手，先理解开链结构，再引出环状结构
- 变旋现象是理解糖化学的关键实验事实
- 成脎反应是竞赛高频考点，需理解其反应机理和鉴别意义

**D/L构型与R/S构型的对应关系**：

D/L 是相对构型标记（以甘油醛为参照），R/S 是绝对构型标记（CIP规则）。两者无简单一一对应，但对常见单糖有固定关系：

| 单糖 | Fischer投影最远手性C | D/L | R/S | 说明 |
|:---|:---|:---|:---|:---|
| D-甘油醛 | C2 | D | R | D = R 的基准 |
| L-甘油醛 | C2 | L | S | L = S 的基准 |
| D-葡萄糖 | C5 | D | R | D系糖最高编号手性C多为R |
| D-半乳糖 | C5 | D | R | 同上 |
| D-果糖 | C5 | D | R | 酮糖也以C5判定D/L |
| D-苏氨酸 | — | — | 2S,3R | 氨基酸中 D/L 与 R/S 关系更复杂 |

**规律**：对糖类，D/L 仅取决于 Fischer 投影中距羰基最远的手性碳（对醛糖为 C5，对酮糖为 C5 或编号最大手性碳）上 -OH 的方向（右=D，左=L）。该碳的 R/S 通常为 R（D）或 S（L），但这不是必然规律——其他手性碳的 R/S 与 D/L 无直接关系。
