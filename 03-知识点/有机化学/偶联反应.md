# 偶联反应

## 一、定义

偶联反应指两个有机片段在金属（通常为催化量的 Pd、Ni、Cu）参与下形成新共价键（以 C–C 键为主，也可构建 C–N、C–O 等键）的一类反应的总称。现代意义上的交叉偶联（cross-coupling）指**亲电体（通常为芳基/烯基卤化物 Ar–X）与亲核体（有机金属试剂 R–M）**在过渡金属催化循环中连接：Ar–X + R–M → Ar–R + M–X。经典代表有 2010 年诺贝尔化学奖的 Heck、Suzuki、Negishi 反应。区别于无选择性的古典 Wurtz 偶联（两分子卤代烃化学计量 Na 偶联），催化偶联通过配位球内的分步反应实现了**位点可控、官能团兼容**的成键，是有机合成中构建碳骨架最核心的工具。

## 二、考纲对应

本页属金属有机化学前沿，对应"过渡金属催化的偶联反应"：能识别 Suzuki/Stille/Negishi/Heck/Sonogashira 等反应类型，写出氧化加成–转金属–还原消除催化循环并标出金属氧化态变化，比较各偶联反应的底物、碱与官能团兼容性，并能读懂信息题给出的陌生催化循环（补缺步、判中间体氧化态、写总反应）。初赛信息题与决赛理论均高频出现。

## 三、核心原理

### 3.1 催化循环三要素：氧化加成–转金属–还原消除

绝大多数 C(sp²)–X 型交叉偶联共用同一骨架循环（以 Pd 为例）：

1. **氧化加成（OA）**：Pd(0) 插入 Ar–X 的 C–X 键 → Ar–Pd(II)–X。金属氧化态升高 2（+0 → +2），配位数增加 2，构型由近似直线二配位变为顺式平面四方形。
2. **转金属（TM）**：亲核体 R–M 把 R 转移给 Pd，同时 M 与 X 结合（R–M + Ar–Pd–X → Ar–Pd–R + M–X）。这一步**不改变 Pd 氧化态**，只是配体交换。
3. **还原消除（RE）**：Ar 与 R 从 Pd(II) 顺式偶合为 Ar–R 重新释放 Pd(0)（氧化态降 2）。还原消除要求两基团处于**顺式**，故转金属后常伴随异构化把基团摆到顺位。

净结果：Ar–X + R–M → Ar–R + M–X，Pd 循环再生不被消耗。**判循环守恒的快速检查：OA 氧化态 +2、RE 氧化态 −2，中间任何写"Pd 变价两次以上"的步骤都应警惕。**

### 3.2 亲电体活性与配体效应

- 氧化加成速率随 C–X 键强度下降而增大：**I > Br ≫ Cl**；Ar–OTf（三氟甲磺酸酯）等同价于 Br 级活性，Ar–Cl 通常需富电子大位阻配体（SPhos、XPhos、NHC）才能温和加成。
- 富电子膦/卡宾配体使 Pd(0) 电子密度更高、更易氧化加成；大位阻配体促进还原消除（两基团被"挤"到顺式）。
- 芳基碘代物活性最高但昂贵，工业与全合成常用溴代物/三氟甲磺酸酯平衡成本与活性。

### 3.3 转金属细节：碱的角色

- **Suzuki（硼）**：有机硼烷本身亲核性弱，需碱（如 K₂CO₃、K₃PO₄、NaOH）先与硼配位形成**四价硼酸根**（或转成硼"ate"配合物）才发生转金属——这是 Suzuki 必须加碱的机理根源。
- **Stille（锡）、Negishi（锌）**：有机锡/有机锌亲核性足够，**不需要额外碱**即可转金属。
- **Kumada（镁）**：格氏试剂亲核性太强，转金属快但对羰基等官能团不耐受，应用受限。
- 转金属的驱动力常与"金属–卤素/氧键生成"有关：生成 M–X 或 M–O 越强，转金属越彻底。

### 3.4 Heck 反应的特例地位

Heck 反应没有转金属步骤：氧化加成得 Ar–Pd–X 后，烯烃**配位–迁移插入**（syn 加成，Pd 与 Ar 同面加到双键）→ 中间体经 **β-H 消除**得取代烯烃产物，Pd–H 中间体被碱中和（HX）再生 Pd(0)。因终止步是 β-H 消除而非还原消除，**Heck 产物保留双键**，且双键位置取决于 β-H 消除方向。这是"偶联反应"家族中机理最不同的一个，切勿与 Suzuki 混为一谈。

### 3.5 铜与双催化体系

- **Sonogashira**：Pd 循环（氧化加成、还原消除）与 Cu 循环（末端炔的铜化、转金属）**双催化**偶联芳基卤与末端炔，构建芳基炔。
- **Cu 单独催化**：如 Glaser 类自身偶联（末端炔 + Cu/O₂ → 联炔）；Ullmann 型 C–N/C–O 偶联（芳基卤 + Cu）。
- **Ni 催化**：Ni(0)/Ni(II) 循环与 Pd 平行，Ni 廉价且对 Ar–Cl 更活泼，近年 Ni 催化 Suzuki/还原偶联发展迅速；Ni 易发生单电子路径，机理常比 Pd 复杂。

## 四、关键结论

常用交叉偶联速查表（都基于 C(sp²)–X 亲电体）：

| 反应 | 亲核体 R–M | 催化剂 | 需碱？ | 特点与注意 |
|---|---|:---:|:---:|---|
| Suzuki | 硼酸/硼酸酯 | Pd | 是 | 试剂低毒稳定，工业首选；碱活化硼酸盐 |
| Stille | 有机锡 | Pd | 否 | 官能团兼容最好，但锡试剂高毒 |
| Negishi | 有机锌 | Pd/Ni | 否 | 活性与兼容性平衡好 |
| Kumada | 格氏试剂 | Ni/Pd | 否 | 活性高但对羰基不耐受 |
| Heck | 烯烃（无 R–M） | Pd | 是 | 无转金属；产物含双键（β-H 消除） |
| Sonogashira | 末端炔（+Cu） | Pd/Cu | 常加胺碱 | 双催化；构建 Ar–C≡C–R |

- 电子守恒检查：OA +2 / RE −2；催化循环中金属只作"渡船"，不被消耗。
- 立体化学：还原消除保持构型（Ar–Pd 键断裂不涉及手性中心翻转），Suzuki/Negishi 常可实现手性保持的立体专一偶联。
- "偶联"不等于任意成键：亲电体需可氧化加成的 C–X，亲核体需可转金属的 C–M；两者缺一不可。

## 五、常见分类或情形

- **交叉偶联（cross-coupling）**：两种不同片段成键（上述 Suzuki 等均属此类），是现代偶联主体。
- **自身偶联（homocoupling）**：同种片段偶联，如 Wurtz（Na 化学计量）、Yamamoto（Ni 催化 Ar–X 自身偶联）、Glaser（末端炔自身氧化偶联）。
- **Heck 型烯基化**：亲电体 + 烯烃，不经有机金属亲核体。
- **C–N/C–O 偶联**：Buchwald–Hartwig 胺化（Ar–X + 胺 → Ar–NR₂）、Ullmann 型醚化——把偶联概念从 C–C 推广到 C–杂。
- **无亲电卤素的偶联**：C–H 直接芳基化属 C–H活化 与偶联的交叉领域（见"八"链接）。

## 六、适用条件与限制

- 亲电体范围：芳基/烯基/炔基卤（或类卤 OTf）最成熟；烷基卤氧化加成慢且易 β-H 消除，烷基–烷基偶联至今是难点（需特殊配体或 Ni/光催化）。
- 亲核体兼容性：有机硼/锌兼容羰基、酯、酰胺等大多数官能团；格氏试剂与强碱敏感基团不兼容。
- 空气与水分：Pd(0) 与富电子配体对氧敏感，反应常需惰性气氛；Suzuki 的水相/两相体系是例外。
- 催化剂与配体成本：Pd 昂贵，放大生产关注残留金属与配体专利；配体选择常决定反应成败（不是"Pd 就行"）。
- 碱与温度：Suzuki 需碱且常加热（80–100 °C）；部分体系可用微波加速。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Heck vs Suzuki "都是 Pd 偶联所以机理一样" | Heck 无转金属、终止步是 β-H 消除（产物有双键）；Suzuki 经转金属+还原消除（产物是 σ 键饱和骨架） |
| Stille vs Suzuki 都要碱 | Stille 不需碱（锡试剂亲核性足够）；"要碱"是 Suzuki 硼酸根活化的特征 |
| Kumada vs Suzuki 官能团耐受 | 格氏试剂碱性/亲核性强，对羰基等不耐受；硼试剂温和得多 |
| 亲电体与亲核体谁是谁 | Ar–X 是**亲电体**（被氧化加成，碳上连着卤素）；R–M 是**亲核体**（带着金属去转金属）——写反则循环无法闭合 |
| 古典 Wurtz vs 催化偶联 | Wurtz 化学计量 Na、自由基路径、易自身偶联；催化偶联分步可控、化学计量试剂是两种底物 |

## 九、典型题型

- **反应识别**：给底物与条件判断属于哪种偶联（看亲核体：硼→Suzuki，锡→Stille，锌→Negishi，炔+Cu→Sonogashira，烯烃→Heck）。
- **循环补全**：信息题给陌生配体/金属的催化循环，缺转金属或还原消除一步，要求补写并标 Pd 氧化态。
- **试剂选择**：多步合成中某步需引入芳基，比较 Suzuki/Stille/Negishi 选最优（兼顾活性、毒性、官能团）。
- **总反应书写**：Ar–X + R–M → Ar–R + M–X 的计量与副产物判断。

## 十、例题

**例题 1**：判断下列反应类型并写出其与"还原消除"的关系：(a) PhI + PhB(OH)₂（Pd 催化、加碱）；(b) PhI + CH₂=CH–CO₂Et（Pd 催化、加碱）。

**解答**：(a) Suzuki 偶联——循环为氧化加成→碱活化硼酸根后的转金属→还原消除，产物联苯由还原消除生成。(b) Heck 反应——氧化加成后烯烃迁移插入，终止步是 β-H 消除生成肉桂酸酯类产物，**没有还原消除生成 C–C 键的步骤**；碱用于中和 Pd–H 释放的 HX 使 Pd(0) 再生。

**例题 2**：Suzuki 偶联为何必须加碱？Stille 偶联为何通常不需要？

**解答**：中性硼酸/硼酸酯的亲核性不足以发生转金属；碱（OH⁻、CO₃²⁻ 等）与硼配位形成带负电的四价硼酸根（如 [ArB(OH)₃]⁻），显著增强对 Pd 上 X 的置换能力，转金属才顺利进行。有机锡试剂中 C–Sn 键极化明显、锡易与卤素结合（生成 Sn–X 键的驱动力强），无需碱即可转金属——这也是两种反应条件差异的机理来源。

**例题 3**：信息题给出一循环：Pd(0)L₂ + PhBr → A →（加 PhB(OH)₂/碱）→ B → 联苯 + Pd(0)L₂。写出 A、B 及 Pd 的氧化态。

**解答**：A = Ph–Pd(II)–Br（氧化加成产物，Pd 为 +2）；B = Ph–Pd(II)–Ph（转金属后中间体，Pd 仍为 +2）；还原消除释放联苯并回到 Pd(0)。氧化态轨迹为 0 → +2 → +2 → 0，符合"只有 OA 和 RE 改变氧化态"的判据。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 把 Heck 与 Suzuki 机理混为一谈 | Heck 无转金属、无还原消除成键，靠 β-H 消除出双键；Suzuki 靠还原消除出 σ 键 | 判据：产物是否含新双键——Heck 产物 Ar–CH=CH–R 必带双键；Suzuki 产物是联苯/芳基烷烃类 σ 骨架 |
| 氧化态变化写反或重复升降 | OA 是金属失电子（+0→+2）、RE 得电子（+2→+0）；把"转金属"也写成变价 | 守恒自检：一个循环氧化态回到起点；只有 OA(+2) 与 RE(−2) 两次变化，转金属/配体交换/异构化均不变价 |
| 把催化剂量当化学计量 | 偶联 Pd 用量常 1–5 mol%，Pd 循环再生；写"消耗 1 当量 Pd"即错 | 反例：总反应中 Pd 不在产物与副产物里；配平总反应只写两种底物与 M–X 副产物 |
| 亲电体/亲核体搞反 | Ar–X 中 C 带部分正电性（连卤素）是亲电体；R–M 的 C 带负电性才是亲核体 | 判别：被"氧化加成"插入的是 C–X 键；被"转金属"送上 Pd 的是 R–M 的 R |
| 忽视卤素活性序 | 芳基氯直接套用溴代条件常不反应 | Ar–Cl 需富电子大位阻配体（XPhos 类）或 Ni 催化；活性序 I > Br ≫ Cl，先看亲电体再选条件 |
| 以为所有偶联都需碱/都耐受水氧 | 碱只对需活化的体系必要（Suzuki 硼酸根、Heck 中和 HX）；Stille/Negishi 无需碱 | 判别：看亲核体是否需要"活化"——硼/硅需碱（或氟源），锡/锌直接转金属；对水氧敏感的是 Pd(0) 催化剂本身 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
先掌握催化循环三基元（氧化加成–转金属–还原消除）与氧化态判据，再逐个学 Suzuki → Stille/Negishi → Heck → Sonogashira，每个反应抓住"亲核体+碱+终止步"三个特征记忆，最后用对比表横向串讲。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为所有偶联反应可以互换使用 | 不同偶联对底物要求不同：Suzuki 需碱，Stille 锡试剂高毒，Heck 需烯烃且产物带双键 |
| 忽略有机金属试剂的毒性 | Stille 的有机锡高毒、残留难除，工业更倾向低毒的 Suzuki |
| 认为偶联反应只"连接两个碳" | 偶联可构建 C–C、C–N、C–O 等多种键（Buchwald–Hartwig 胺化即 C–N 偶联） |
| 把催化剂当"万能的" | 配体决定活性与选择性，没有合适的配体，Pd 盐本身常不反应 |

### 12.3 入门级例题
**题目**：比较 Suzuki 偶联与 Stille 偶联的优缺点，工业上倾向选哪个？

**解答**：Suzuki 优点是有机硼试剂低毒、稳定、可商业化大量供应；缺点是需要碱、个别官能团受限。Stille 优点是锡试剂活性高、官能团兼容性好；缺点是锡试剂高毒且副产物有机锡残留难分离。工业上优先选择 Suzuki。

### 12.4 与现实世界的联系
- **药物合成**：约 25% 的药物合成涉及偶联反应，如抗癌药伊马替尼（格列卫）关键步即 Suzuki 偶联。
- **有机电子材料**：共轭聚合物（聚芴、聚噻吩类）依赖 Suzuki 或 Yamamoto 偶联，用于 OLED 与有机太阳能电池。
- **农药化学**：许多含杂环农药（三唑类杀菌剂等）通过偶联构建关键碳–碳键。
