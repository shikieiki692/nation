# Aldol缩合（羟醛缩合）

- 上位框架：[[缩合反应]] · [[烯醇与烯醇盐]] · [[醛酮]]
- 逆过程：[[逆羟醛缩合]]（同一平衡的另一端，合成上作切断策略）

> **说明**：本页为**正向** Aldol（羟醛缩合）；逆反应（β-羟基羰基断裂为两个羰基化合物）见 [[逆羟醛缩合]]。两页互为正逆，学习时建议先掌握本页正向，再学逆过程。

---

## 一、定义

**Aldol 缩合（羟醛缩合，aldol addition / aldol condensation）**：醛或酮在酸或碱催化下，一个分子的 **α-碳**（以烯醇 / 烯醇负离子形式）对**另一分子羰基碳**进行亲核加成，先生成 **β-羟基醛或 β-羟基酮**（aldol addition）；若进一步加热或在碱性条件下脱水，则得到 **α,β-不饱和羰基化合物**（aldol condensation）。

名称来源：产物同时含 **al**dehyde（醛基）与 **alcoh**ol（醇羟基）→ "aldol"。

乙醛自缩合（碱催化）：

$$2\,\mathrm{CH_3CHO} \xrightarrow{\mathrm{OH^-}} \mathrm{CH_3CH(OH)CH_2CHO} \xrightarrow{-\mathrm{H_2O}} \mathrm{CH_3CH{=}CHCHO}$$

先得 3-羟基丁醛（aldol 加成产物），再脱水得巴豆醛（2-丁烯醛，α,β-不饱和醛）。

---

## 二、机理

### 2.1 碱催化

1. 碱（$\mathrm{OH^-}$）夺取 α-氢 → 生成**烯醇负离子**（亲核体）
2. 烯醇负离子进攻另一分子醛 / 酮的羰基碳 → 烷氧负离子
3. 质子化 → **β-羟基羰基**（aldol 加成产物）

控制要点：

- 醛的 α-氢酸性较强，烯醇化容易；酮的 α-氢酸性较弱，自缩合平衡偏左，常需强碱（如 LDA）先定量生成烯醇负离子，或靠脱水推动平衡。
- 一旦产物脱水形成共轭的 α,β-不饱和羰基，平衡被"拉向"缩合一侧（近乎不可逆）。

### 2.2 酸催化

1. 羰基质子化 → 亲电性增强
2. 另一分子的**烯醇**（酸催化下由羰基互变异构生成）进攻质子化羰基
3. 去质子化得 aldol 产物；酸性下同样可脱水生成 α,β-不饱和羰基

酸、碱催化殊途同归——关键都在**先形成烯醇物种、再发生 C–C 加成**。

### 2.3 加成 vs 缩合

| 条件 | 主导产物 |
|:---|:---|
| 低温、不脱水 | β-羟基羰基（aldol addition） |
| 加热 / 碱性可脱水 | α,β-不饱和羰基（aldol condensation） |

> 竞赛中 "Aldol 缩合" 有时特指**脱水后的缩合产物**；但多数语境把"加成"与"缩合"统称 Aldol 反应。本文以"先 β-羟基羰基、后可脱水为 α,β-不饱和羰基"两步描述。

---

## 三、交叉 Aldol 与定向控制

自缩合（如乙醛 + 乙醛）选择性好；但**两种不同的醛 / 酮**混合时可能产生 4 种产物，选择性差。常用控制策略：

1. **一方无 α-氢**：如甲醛、苯甲醛不含 α-氢，只能作亲电体，与含 α-氢的醛 / 酮缩合 → 高选择性（如 **Claisen–Schmidt 缩合**：醛 + 芳醛 → α,β-不饱和酮）。
2. **定向 Aldol（directed aldol）**：用 LDA 等强、非亲核碱在低温下定量生成**动力学烯醇负离子**（或烯醇硅醚），再与醛反应；其立体化学可由 **Zimmerman–Traxler 六元环过渡态模型**预测（见 [[MukaiyamaAldol]] 与 [[反应机理]]）。
3. **烯醇硅醚路线（Mukaiyama Aldol）**：烯醇硅醚作亲核体、Lewis 酸活化羰基，在温和条件下高立体选择性构建 β-羟基羰基（详见 [[MukaiyamaAldol]]）。

---

## 四、与逆羟醛缩合的关系

正向 Aldol 与逆向 retro-Aldol 共存于同一平衡，**方向由条件决定**（详细见 [[逆羟醛缩合]]）：

- 低温、浓碱、醛为底物 → 正向（Aldol 加成 / 缩合）
- 高温、稀碱、体系有水 → 逆向（retro-Aldol）
- 产物能脱水成共轭体系 → 正向被"锁死"（脱水不可逆地拉走平衡）

合成上：正向 Aldol 是**构建 C–C 键、增长碳链**的核心手段；逆向 retro-Aldol 是**切断策略**（从复杂分子倒推简单原料）。两者是同一平衡的两端。

---

## 五、合成意义

- **碳链增长**：醛 / 酮 α-碳连到另一个羰基碳上，净增 2–3 个碳。
- **构建 β-羟基羰基 / α,β-不饱和羰基骨架**：后者广泛存在于天然产物（大环内酯、麝香酮前体）与药物骨架。
- **Robinson 增环**：Aldol + Michael 串联构建六元环，是甾体骨架的经典路线。

---

## 六、现实与竞赛中的 Aldol

- **生物化学**：醛缩酶（aldolase）催化果糖-1,6-二磷酸的**逆**羟醛缩合裂解（正向在糖异生中构建 C–C 键）。
- **工业**：羟醛缩合是生产 2-乙基己醇（增塑剂醇）、季戊四醇等的关键步骤。
- **竞赛考点**：交叉 Aldol 选择性判断、脱水产物 E/Z 构型、定向 Aldol 立体化学（syn / anti 产物预测）、Robinson 增环。

## 七、教学视角

### 学习路径建议

1. 先掌握 [[醛酮]] 的亲核加成与 α-氢酸性
2. 理解 [[烯醇与烯醇盐]] 的生成与亲核性
3. 学正向 Aldol（本页）→ 再学其逆过程 [[逆羟醛缩合]]
4. 进阶：定向 Aldol 与 [[MukaiyamaAldol]]、Robinson 增环

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 醛与酮都易自缩合 | 酮 α-氢酸性弱，自缩合平衡偏左；常用强碱 / 脱水推动 |
| "缩合"一定脱水 | Aldol 加成先给 β-羟基羰基，脱水是后续、条件依赖的步骤 |
| 交叉 Aldol 产物唯一 | 两不同羰基混合可生成 4 种产物，需定向控制 |
| 正向与逆向是两回事 | 两者是同一平衡的两端，方向由条件与产物移除决定 |

### 入门级例题

**题目**：写出乙醛在稀碱中加热的主要产物。

**解答**：乙醛先 aldol 加成得 3-羟基丁醛，加热脱水得 α,β-不饱和醛——巴豆醛（$\mathrm{CH_3CH{=}CHCHO}$）。
