# Michael加成

## 一、定义

Michael 加成（1887 年 A. Michael）指**亲核试剂对 α,β-不饱和羰基化合物（Michael 受体）β-碳的 1,4-共轭加成**：亲核体（Michael 给体，常为丙二酸酯/β-酮酯/硝基烷等稳定碳负离子前体，也可是胺、硫醇等杂原子亲核体）进攻 C=C–C=O 的 β 位，负电荷离域到羰基氧上，质子化后得到"给体片段 + 受体饱和链"的加成产物。它是构建 C–C 键最可靠的方法之一，也是 Robinson 增环（Michael 加成 + 分子内 Aldol）的第一步，在萜类、甾体与生物碱全合成中无处不在。

## 二、考纲对应

本页属羰基化学-共轭加成核心考点，对应"Michael 加成与 Robinson 增环"：能写出稳定碳负离子对 α,β-不饱和酮/酯/腈的 1,4-加成机理与产物；会用 HSAB 软硬思想判断 1,2- vs 1,4-加成倾向；掌握丙二酸酯/乙酰乙酸酯合成法中 Michael 步的用法，并能串联 Robinson 增环完成环己烯酮骨架构建。初赛决赛均为高频考点。

## 三、核心原理

### 3.1 两个亲电中心：1,2- vs 1,4-加成

α,β-不饱和羰基化合物有**两个亲电位点**：羰基碳（1,2-位，直接加成）与 β-碳（1,4-位，共轭加成）：

- 羰基碳上发生普通的亲核加成（如 Grignard、有机锂、NaBH₄/CeCl₃ 体系可选择性 1,2-还原）。
- β-碳发生 Michael 加成：亲核体先加到 β-碳，形成**烯醇负离子**中间体（负电荷在 α-碳与羰基氧间离域），质子化后烯醇互变为羰基——净结果是亲核体连到 β-碳、双键消失。
- 选择 1,2 还是 1,4，主看**亲核体软硬**与试剂：硬亲核体（RMgX、RLi、H⁻）倾向 1,2-直接加成；软亲核体（稳定碳负离子如丙二酸酯负离子、硫醇、胺、有机铜锂）倾向 1,4-共轭加成——HSAB 的"软亲电中心在 β-碳"。

### 3.2 Michael 给体：稳定碳负离子

- 常见给体：丙二酸二乙酯、乙酰乙酸乙酯、硝基烷、丙二腈、β-二酮等（α-H 的 pKa 约 9–16，可被烷氧负/胺碱拔取）。
- 给体的 pKa 与受体活性要匹配：弱碱（如 Et₃N、K₂CO₃）配活性高的受体（硝基烯 > 烯酮 > 烯酯）。
- 催化模式：碱催化（拔 α-H 生成亲核负离子）或 Lewis 酸活化受体；不对称 Michael 用手性胺/手性 Lewis 酸（如脯氨酸衍生物催化，含 GIL 类有机小分子催化——见相关题目 25 届决赛题）。
- 杂原子给体：硫醇（硫-Michael，点击化学常用）、胺（氮-Michael，aza-Michael）无需强碱即可进行。

### 3.3 区域与立体化学要点

- 区域专一：亲核体总是加到 **β-碳**（与受体共轭端一致），α-位保留给质子化后的烯醇。
- 新生成的手性中心在 β-碳（与给体相连处）；无手性诱导时得外消旋体，不对称催化可控制 β-位构型。
- 可逆性：Michael 加成在强碱下可逆（retro-Michael），弱碱/低温常保不可逆——设计合成时注意碱性条件匹配。

### 3.4 Robinson 增环：Michael + 分子内 Aldol

Robinson 增环 = 环己酮 + 甲基乙烯基酮（MVK）类受体先做 Michael 加成，再对产物中残留的羰基做**分子内 Aldol 缩合**闭环，得到 6/5 元环烯酮骨架。它是"一锅法构建环己烯酮"的经典串联，也是萜类/甾体全合成的核心步——解题时看到"环己烯酮 + 1,3-二羰基化合物"要立刻想到 Robinson。

### 3.5 串联与级联：Michael 的合成放大效应

Michael 加成产生的烯醇负离子中间体**还可继续反应**，构成一锅串联：Michael 后接分子内 Aldol 即 Robinson 增环；接 Dieckmann/Claisen 闭环得双环酮；受体含双 Michael 位点时一次加成后再分子内关环（如多烯环化生源模拟）。解题遇到"给体连受体后产物还能闭环"的线索，先想中间体烯醇负离子能否再亲电进攻——这是 Michael 从单步反应升级为复杂骨架构建工具的钥匙。

## 四、关键结论

- Michael 加成 = 亲核体对 α,β-不饱和羰基 **β-碳的 1,4-共轭加成**；中间体为烯醇负离子。
- 选择性判据：硬亲核体 1,2-、软亲核体 1,4-（HSAB）；稳定碳负离子/硫醇/胺走 Michael。
- 受体活性序（大致）：硝基烯 > 烯酮/烯醛 > 烯酯/烯腈 > 烯酰胺。
- Michael 给体：α-H pKa 足够低的 CH 酸（丙二酸酯/β-酮酯/硝基烷/丙二腈）。
- Robinson 增环 = Michael + 分子内 Aldol，构建环己烯酮骨架的黄金串联。

## 五、常见分类或情形

- **按给体**：碳亲核体（丙二酸酯、β-酮酯、硝基烷、氰基乙酸酯等 CH 酸）；杂原子亲核体（硫醇硫-Michael、胺 aza-Michael、膦/亚膦酸酯）。
- **按受体**：α,β-不饱和酮/醛/酯/腈/硝基烯/砜/酰胺；双 Michael 受体（用于串联与聚合物交联）。
- **按催化**：碱催化、Lewis 酸催化、有机小分子不对称催化（脯氨酸类/金鸡纳碱类/GIL 类）。
- **按用途**：Robinson 增环第一步、丙二酸酯/乙酰乙酸酯合成法中的碳链延长与 α-烷基化前体、共轭加成串联环化（多烯环化）。

## 六、适用条件与限制

- **碱强度与可逆性**：强碱下 Michael 可逆，产物可被"吃回去"；对可逆体系用弱碱+低温或质子源控制。
- **给体 pKa 匹配**：给体太弱（α-H 不够酸）需更强碱，但强碱又可能与受体/产物反应——需平衡。
- **受体聚合倾向**：活泼受体（甲基乙烯基酮、丙烯醛）易自身聚合，常需缓慢滴加与阻聚剂。
- **立体选择性默认无**：β-位新手性中心无诱导时外消旋；需要手性配体/催化剂才可控。
- **1,2 副反应**：含羰基强亲核体（Grignard/RLi）对多数受体直接 1,2-加成而非 Michael——选给体时要避开。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Michael 加成 vs 普通羰基加成 | Michael 是 β-碳的 1,4-共轭加成（产物羰基保留、双键消失）；普通加成是羰基碳 1,2-加成（羰基变醇） |
| Michael 加成 vs Aldol 缩合 | Aldol 是烯醇负离子对**羰基碳**的 1,2-加成（β-羟基羰基/烯酮）；Michael 是同一烯醇负离子对**β-碳**的 1,4-加成——受体含 C=C 才可能 Michael |
| 硬 vs 软亲核体的去向 | 硬（RMgX、RLi、H⁻）→ 1,2-；软（稳定碳负离子、RS⁻、胺、有机铜）→ 1,4-——Grignard 加 CuI 转成有机铜后才走 Michael |
| Michael 给体 vs 受体谁是谁 | 给体 = 提供亲核碳的 CH 酸（丙二酸酯等，α-H 可被拔）；受体 = 接受加成的 α,β-不饱和羰基——写反机理即错 |
| 丙二酸酯合成法 vs Michael | 丙二酸酯合成法是"丙二酸酯烷基化+水解脱羧"三步序列；Michael 是其中烷基化可用"对受体共轭加成"替代的变体——两条都是给体 α-位的官能团化 |

## 八、与其他知识点的联系

- [[Aldol缩合]] / [[Claisen缩合]]：烯醇负离子化学的三兄弟（1,2 加成/1,4 加成/酯缩合），机理共用烯醇/烯醇负离子。
- [[Robinson环化]]：Michael + 分子内 Aldol 的串联闭环（本页直接上游概念）。
- 丙二酸酯/乙酰乙酸乙酯合成法（见对应合成页）：给体 CH 酸的经典应用。
- [[共轭加成]] 概念通论见 [[Aldol缩合]] 的烯醇化学与软硬酸碱框架（本库无独立共轭加成页，1,4-加成的总纲即本页）。
- 羰基化学与 HSAB：软硬酸碱理论决定 1,2/1,4 走向（可链软硬酸碱/亲核体亲电体页）。

## 九、典型题型

- **产物书写**：丙二酸二乙酯/乙酰乙酸乙酯 + 查尔酮/丙烯酸甲酯/甲基乙烯基酮 → Michael 产物。
- **1,2 vs 1,4 判断**：同受体分别与 RMgX、R₂CuLi、丙二酸酯负离子反应的主产物。
- **Robinson 增环**：给环己酮+MVK，写 Michael 中间体与分子内 Aldol 闭环产物（环己烯酮）。
- **不对称 Michael**：25 届决赛 GIL 催化题——识别催化剂角色与立体控制来源。
- **合成设计**：逆合成中切 Michael 键（给体 α-C 与受体 β-C 之间）。

## 十、例题

**例题 1**：丙二酸二乙酯与丙烯酸甲酯在 NaOEt 中反应，主产物是什么？机理如何？

**解答**：NaOEt 拔丙二酸二乙酯的 α-H 得稳定碳负离子（软亲核体）；丙烯酸甲酯是 α,β-不饱和酯，β-碳是软亲电位点 → 发生 1,4-共轭加成：负离子加 β-C，烯醇负离子中间体质子化后互变，得 CH(CO₂Et)₂–CH₂CH₂CO₂Me 的 Michael 加成产物（1,3,3-三酯）。后续碱水解-脱羧可转成己二酸衍生物——这是"Michael 版"的碳链二碳延长。

**例题 2**：解释为什么环己酮的烯醇负离子与甲基乙烯基酮（MVK）反应得 1,4-加成产物，而与苯甲醛反应却得 Aldol 产物。

**解答**：MVK 是 α,β-不饱和酮，其 β-碳（软亲电中心）接受软烯醇负离子的共轭加成 → Michael 产物（2-取代环己酮连 CH₂CH₂COCH₃ 侧链）；苯甲醛只有孤立羰基（无共轭 C=C），只能发生 1,2-羰基加成 → Aldol（β-羟基酮，可脱水成烯酮）。**受体是否有 C=C–C=O 共轭结构是决定走 Michael 还是 Aldol 的第一判据**——这正是 Robinson 增环第一步（环己酮+MVK 先 Michael 再分子内 Aldol）的设计基础。

**例题 3**：设计由环己酮与丙烯酸甲酯经 Michael+Dieckmann 思路合成双环骨架的逆合成思路。

**解答**：环己酮先经 LDA 生成烯醇负离子（或烯胺）对丙烯酸甲酯 β-碳 Michael 加成，得 2-(2-甲氧羰基乙基)环己酮；其侧链酯与环上 α-H 可做分子内 Claisen（Dieckmann）闭环成双环 β-酮酯，水解脱羧得双环酮。Michael 步的 β-碳与给体 α-碳成键是逆合成切点——与 Robinson 增环（Aldol 闭环）互为"酯/酮闭环"两个版本。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为亲核试剂总是进攻羰基碳 | 只有孤立羰基才 1,2-；α,β-不饱和体系里软亲核体（稳定碳负离子、硫醇、有机铜）优先 1,4-进攻 β-碳 | 反例：丙二酸酯负离子 + 丙烯酸甲酯 → Michael 产物（β 位成键）；RMgX 不加 CuI 才走 1,2——先看亲核体软硬与受体有无共轭 C=C |
| 忽略 α,β-不饱和羰基的两个亲电中心 | 羰基碳（1,2）与 β-碳（1,4）都是亲电位点，选择性取决于试剂 | 判别：硬亲核体/还原剂 → 1,2；软亲核体 → 1,4；题目问"哪个碳被进攻"先标出 C=C–C=O 两端 |
| 混淆 Michael 加成与 Aldol 缩合 | Aldol 是烯醇对羰基碳的 1,2-加成（无 C=C 受体也可发生）；Michael 必须受体含 C=C–C=O 共轭且走 β-碳 | 反例：环己酮+苯甲醛 = Aldol；环己酮烯醇+MVK = Michael——看受体是不是 α,β-不饱和 |
| 亲核体/受体角色颠倒 | 给体是"被拔 α-H 的 CH 酸"（丙二酸酯等，带可离去 H 的碳负离子前体）；受体是"含共轭 C=C 的缺电子烯烃" | 判别：写机理时负电荷从给体 α-C 流向受体 β-C；把丙烯酸酯当给体、丙二酸酯当受体即错 |
| 忽视碱性条件下的可逆性 | Michael 在强碱下可逆（retro-Michael），过量强碱会把产物拉回原料；不是所有 Michael 都不可逆 | 反例：丙二酸酯对硝基烯的加成在强碱下可逆；工业/合成上常控碱强度与温度保正向——产物稳定性（新负离子的 pKa）决定平衡位置 |
| 忽略 1,2 副反应与聚合 | 活泼受体（MVK、丙烯醛）易自身 Michael 聚合；Grignard 直接加会走 1,2 | 判别：活泼受体缓慢滴加；欲走 Michael 的格氏试剂先转有机铜（R₂CuLi）——条件提示"加 CuI"就是在告诉你走 1,4 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
Michael 加成应在掌握羰基亲核加成、烯醇/烯醇负离子化学与 Aldol 缩合之后学习。建议先理解 1,2- vs 1,4-加成的两亲电中心框架（HSAB 软硬），再学给体 CH 酸与受体活性匹配，然后掌握 Robinson 增环串联，最后用不对称 Michael（GIL 等）与真题收尾。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为亲核试剂总是进攻羰基碳 | 软亲核体（如烯醇负离子、硫醇）倾向于 1,4-加成（Michael 加成），而不是 1,2-加成 |
| 忽略 α,β-不饱和羰基的两个亲电中心 | 羰基碳（1,2-位）和 β-碳（1,4-位）都是亲电中心，亲核体的选择性取决于软硬度 |
| 混淆 Michael 加成和 Aldol 缩合 | Michael 加成是 1,4-共轭加成；Aldol 缩合是 1,2-加成到羰基 |
| 忘记 Robinson 增环的分步逻辑 | Robinson = 先 Michael（链上挂受体）再分子内 Aldol（闭环），两步同一碳负离子化学 |

### 12.3 入门级例题
**题目**：解释为什么丙二酸二乙酯与丙烯酸甲酯反应主要得到 1,4-加成产物。

**解答**：丙二酸二乙酯的烯醇负离子是软亲核体，丙烯酸甲酯的 β-碳是软亲电中心。根据 HSAB 理论，软-软相互作用有利，因此发生 1,4-共轭加成（Michael 加成），而不是 1,2-加成到羰基碳。

### 12.4 与现实世界的联系
- **天然产物全合成**：Michael 加成与 Robinson 增环是萜类、甾体、生物碱骨架构建的核心手段。
- **药物合成**：许多药物分子的碳骨架（含手性 β-位）通过（不对称）Michael 加成构建。
- **高分子化学**：Michael 加成用于制备功能性聚合物（含 Michael 受体的交联剂、硫-Michael 点击化学）。
