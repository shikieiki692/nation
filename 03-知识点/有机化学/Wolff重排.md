# Wolff重排

## 一、定义

Wolff 重排（沃尔夫重排）指 **α-重氮酮在加热、光照或过渡金属催化（Ag₂O、Cu 等）下失去氮气、经酰基卡宾中间体发生 1,2-迁移生成烯酮** 的重排反应：

- 通式：R–CO–CHN₂ →（−N₂）→ R–CO–CH:（酰基卡宾）→ R–CH=C=O（烯酮）。
- 本质：不是简单"放氮气"的分解，而是**卡宾生成 + 1,2-酰基（R 或 H）迁移扩链**——产物烯酮（RCH=C=O）是高活性亲电中间体。
- 最大应用：**Arndt–Eistert 同系化**——羧酸经酰氯 → 重氮酮 → Wolff 重排 → 烯酮，加水/醇/胺捕获得**多一个碳**的羧酸/酯/酰胺（RCOOH → RCH₂COOH），是羧酸"延长一个碳"的标准方法。竞赛中与卡宾化学、重氮化合物、Curtius 重排（异氰酸酯同族）一起考查机理辨认与产物书写。

## 二、考纲对应

本页属重排反应-卡宾化学考点，对应"α-重氮酮的 Wolff 重排与 Arndt–Eistert 同系化"：能识别 α-重氮酮底物并写失 N₂ → 卡宾 → 1,2-迁移 → 烯酮机理；掌握烯酮被 H₂O/ROH/R₂NH 捕获的产物（酸/酯/酰胺，碳数 +1）；理解与 Curtius/Hofmann（异氰酸酯家族）的对比（本页产物是烯酮而非异氰酸酯）；能在合成设计中用 Arndt–Eistert 完成羧酸同系化。初赛决赛均以机理与产物题出现。

## 三、核心原理

### 3.1 底物制备：α-重氮酮从哪来

- 最常用：酰氯 + 重氮甲烷（CH₂N₂）→ α-重氮酮 RCOCHN₂ + HCl（Arndt–Eistert 前步）。
- 其他：羧酸活化酯与重氮甲烷、或由 α-氨基酮重氮化（少用）。重氮甲烷剧毒易爆（黄色气体），实验室常用其乙醚溶液或替代试剂（TMSCHN₂）。

### 3.2 机理：失氮 → 酰基卡宾 → 1,2-迁移

1. **失 N₂**：α-重氮酮受热/光照/Ag⁺ 催化失去 N₂，生成**酰基卡宾**（RCO–CH:，或以其重氮鎓-烯醇共振形式）。
2. **1,2-迁移**：与卡宾相邻的 R 基（或 H）带着电子对迁移到卡宾碳，同时原羰基与卡宾碳之间成键 → **烯酮 R–CH=C=O**（迁移基团与 C=O 的相对构型决定 E/Z）。
3. 迁移倾向：H > 芳基 > 烷基（H 最易迁移，形成末端烯酮）；手性 R 迁移**保持构型**（迁移发生在卡宾碳的同一面）。
- 机理要点：迁移与失氮协同或经卡宾分步（Ag₂O 催化下常经银-卡宾络合物），立体专一；产物烯酮**不在反应条件下分离**（太活泼），立即被亲核体捕获。

### 3.3 烯酮捕获：Arndt–Eistert 同系化的完成

- 烯酮 RCH=C=O 是强亲电体（累积双键，中心 C 缺电子）：
  - + H₂O → RCH₂COOH（羧酸，**碳数 +1**——Arndt–Eistert 的目标产物）；
  - + R'OH → RCH₂CO₂R'（酯）；
  - + R'₂NH → RCH₂CONR'₂（酰胺）；
  - + 羧酸 → 混合酸酐（可继续转化）。
- 净效果：RCOOH → RCOCl → RCOCHN₂ →（Wolff）RCH=C=O → RCH₂COOH：**同系化（增加一个 CH₂）**，且手性保持（α-手性碳的构型保留）。
- 应用场景：把氨基酸/手性酸延长一个碳而不消旋；合成 β-氨基酸、环扩张（重氮酮环化得扩环酮，经 Wolff 的变体）等。

### 3.4 与异氰酸酯家族对比（Curtius/Hofmann/Schmidt）

- Wolff 产物是**烯酮**（C=C=O，亲电碳）：底物是 α-重氮酮，失 N₂。
- Curtius 产物是**异氰酸酯**（R–N=C=O）：底物是酰基叠氮 RCON₃，失 N₂，R 迁移到 N。
- Hofmann（酰胺+Br₂/NaOH）、Schmidt（羧酸+HN₃）同样经异氰酸酯 → 胺/少碳产物。
- 记忆："重氮酮 → 烯酮（碳扩）" vs "酰基叠氮/酰胺 → 异氰酸酯（氮扩/降碳）"——**Wolff 保持并增加碳，Curtius 类降一个碳得胺**，方向相反别混。

### 3.5 反应条件与变体

- 热（>100 °C）、光（紫外）、金属催化（Ag₂O、Rh₂(OAc)₄ 等）三种引发方式均可行；光/银催化更温和。
- 醇/水作溶剂兼捕获剂直接得酯/酸；胺存在得酰胺——"一锅同系化"。
- 环状 α-重氮酮（如 2-重氮环己酮）Wolff 后可扩环（环扩张成更大的环酮，经烯酮重排/缩环竞争需控条件）。
- 相关变体：重氮酯（diazo ester）的 Wolff 型也偶见（Arndt 中间体）。

## 四、关键结论

- Wolff 重排 = α-重氮酮失 N₂ → 酰基卡宾 → 1,2-迁移 → 烯酮；不是单纯分解。
- 烯酮必须被亲核体（H₂O/ROH/胺）现场捕获：得酸/酯/酰胺。
- Arndt–Eistert 同系化 = 羧酸 → 酰氯 → 重氮酮 → Wolff → +1 碳的羧酸；手性保持。
- 迁移倾向 H > 芳基 > 烷基；产物烯酮中心碳亲电。
- 家族定位：Wolff（→烯酮，碳链 +1）vs Curtius/Hofmann/Schmidt（→异氰酸酯，得胺、降碳）。

## 五、常见分类或情形

- **按引发**：热 Wolff、光 Wolff（光化学经典）、金属催化（Ag₂O/Rh）。
- **按捕获亲核体**：水（酸）、醇（酯）、胺（酰胺）、硫醇（硫酯）。
- **按底物**：开链 α-重氮酮（同系化主线）、环状重氮酮（扩环/缩环）、α-重氮酯（较少）。
- **按合成用途**：Arndt–Eistert 羧酸同系化、氨基酸链延长、环扩张、天然产物/药物中间体。

## 六、适用条件与限制

- 重氮化合物**危险**（CH₂N₂ 剧毒易爆）：需专业防护与稀释操作；实验室常改用 TMSCHN₂ 等安全替代。
- 烯酮不能分离：须在亲核捕获剂存在下进行（无捕获剂则聚合/与底物副反应）。
- 环状底物的区域/环大小竞争：扩环 vs 缩环产物需控条件（Ag⁺ 常利于扩环、热利于缩环）。
- 底物官能团耐受：强酸/强氧化条件避免；活泼酮（β-二羰基）副反应需评估。
- 光引发可能伴随其他光反应（如顺反异构）——重氮酮需在低温与适当波长下进行。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Wolff vs 简单失氮分解 | Wolff 是失 N₂ 后**卡宾 1,2-迁移重排**得烯酮——写成"只放氮气留下卡宾就不管"即漏了迁移产物 |
| Wolff vs Curtius | 底物不同（重氮酮 vs 酰基叠氮）、产物不同（烯酮 vs 异氰酸酯）——Wolff 碳链 +1、Curtius 得胺降碳，方向相反 |
| Wolff vs Arndt–Eistert | Arndt–Eistert 是**整条同系化流程**（酰氯+CH₂N₂ → 重氮酮 → Wolff → 水解）；Wolff 重排只是其中重排一步——题说"Arndt–Eistert 同系化"要写全流程 |
| 迁移基团顺序 | 迁移倾向 H > 芳基 > 烷基；说"烷基总是先迁移"即错 |
| 烯酮与酮烯醇 | 烯酮（RCH=C=O）累积双键高活性亲电体，非普通烯醇；捕获产物是羧酸衍生物而非 β-羟基酮 |

## 九、典型题型

- **产物书写**：α-重氮酮（热/光/Ag₂O）在 H₂O、CH₃OH、胺中分别的产物（注意碳数 +1）。
- **机理推断**：补全失 N₂ → 卡宾 → 迁移 → 烯酮的箭头；判断迁移基团。
- **合成设计**：RCOOH → RCH₂COOH（Arndt–Eistert 三步）或氨基酸延长一个 CH₂ 且保持手性。
- **家族辨析**：给定底物判断走 Wolff（重氮酮）还是 Curtius（叠氮）还是 Hofmann（酰胺）。
- **真题**：30 届生物碱互变中间体（题-030-10）——识别 Wolff/重氮酮中间体。

## 十、例题

**例题 1**：写出 α-重氮苯乙酮 PhCOCHN₂ 在（a）光照、（b）Ag₂O/甲醇中的产物与机理。

**解答**：（a）光照失 N₂ 生成酰基卡宾 PhCOCH:，苯基 1,2-迁移 → 苯基烯酮 PhCH=C=O（在无水无捕获剂时聚合/需谨慎表述）；（b）Ag₂O/甲醇中同样先生成烯酮，立即被 CH₃OH 捕获 → 苯乙酸甲酯 PhCH₂CO₂CH₃（碳数 +1）。机理三步：失 N₂（卡宾）→ 1,2-苯基迁移（烯酮）→ 醇捕获（酯）。注意迁移基团是 Ph（迁移倾向 H>Ar>烷基，此处无 H 可迁故 Ar 迁）。

**例题 2**：设计由苯乙酸（PhCH₂COOH）制备 3-苯基丙酸（PhCH₂CH₂COOH）的同系化路线并指出关键控制。

**解答**：Arndt–Eistert：①苯乙酸 → 苯乙酰氯（SOCl₂ 或 PCl₃）；②酰氯 + CH₂N₂ → 重氮酮 PhCH₂COCHN₂；③重氮酮在 Ag₂O/水（或醇→酯再水解）中 Wolff 重排 → 烯酮 PhCH₂CH=C=O → 加水得 PhCH₂CH₂COOH（3-苯基丙酸，碳数 +1）。关键：重氮甲烷安全操作；Wolff 步需捕获剂在场；若原料 α-碳有手性则全程保持构型（协同迁移）。

**例题 3**：区分下列底物的主产物途径：PhCOCHN₂、PhCON₃、PhCONH₂（各给条件）。

**解答**：PhCOCHN₂（α-重氮酮，热/光/Ag₂O）→ Wolff → 烯酮 → 加水得 PhCH₂COOH（苯乙酸，碳 +1）。PhCON₃（酰基叠氮，热）→ Curtius → 异氰酸酯 PhN=C=O → 水解得 PhNH₂（苯胺，降碳）。PhCONH₂ + Br₂/NaOH（Hofmann）→ 异氰酸酯 → PhNH₂（苯胺）。归纳：重氮酮走烯酮扩碳；叠氮/酰胺走异氰酸酯得胺——底物官能团直接决定家族。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为 Wolff 只是"失去 N₂ 分解" | 失 N₂ 后还有卡宾 1,2-迁移生成烯酮——产物是烯酮/捕获产物而非"卡宾留在那" | 判别：产物书写必须含迁移结果（R–CH=C=O + 捕获物）；只写失氮即漏重排 |
| 混淆 Wolff 与 Curtius/Hofmann | Wolff 底物 α-重氮酮、产物烯酮（碳链 +1）；Curtius/Hofmann 底物叠氮/酰胺、产物异氰酸酯→胺（降碳） | 判别：看底物——重氮酮→Wolff；酰基叠氮→Curtius；酰胺+Br₂/NaOH→Hofmann；三者失 N₂ 或重排对象不同 |
| 烯酮捕获产物写错 | 烯酮 + H₂O → 羧酸（+1 碳）；写成 β-羟基酮或原样保留烯酮即错 | 自检：RCH=C=O + H₂O → RCH₂COOH——计数碳数 +1；溶剂是 CH₃OH 则得酯 |
| 迁移基团顺序记反 | 迁移倾向 H > 芳基 > 烷基；分子有 H 可迁时优先得末端烯酮 | 反例：RCH₂COCHN₂ 类优先 H 迁移；PhCOCHN₂ 无 α-H 时 Ph 迁移——先找可迁基团再写产物 |
| 忽略重氮化合物危险性 | CH₂N₂ 剧毒易爆，需防护/稀释/替代试剂（TMSCHN₂）——"实验室随便制备使用"观念错误 | 判别：涉及 CH₂N₂ 的合成叙述应含安全提示或替代试剂 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
Wolff 重排应在掌握卡宾化学与重氮化合物之后学习。先理解 α-重氮酮的生成（酰氯+CH₂N₂），再写"失 N₂→卡宾→1,2-迁移→烯酮"机理，接着用 Arndt–Eistert 同系化串联应用（捕获剂决定酸/酯/酰胺），最后与 Curtius/Hofmann 三方对比锁死家族边界。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为 Wolff 重排只是"失去 N₂" | Wolff 涉及卡宾中间体的 1,2-酰基/氢迁移生成烯酮，是重排而非单纯分解 |
| 忽略烯酮中间体的反应性 | Wolff 生成的烯酮（RCH=C=O）是高活性亲电体，须被水/醇/胺等当场捕获 |
| 混淆 Wolff 与 Curtius | Wolff 是 α-重氮酮 → 烯酮（碳 +1）；Curtius 是酰基叠氮 → 异氰酸酯（得胺降碳） |
| 迁移基团顺序搞混 | H > 芳基 > 烷基；无 H 时才迁移芳基/烷基 |

### 12.3 入门级例题
**题目**：写出 α-重氮苯乙酮在光照条件下的 Wolff 重排产物（水为捕获剂）。

**解答**：PhCOCHN₂ 光照失 N₂ → 酰基卡宾 PhCOCH: → 苯基 1,2-迁移 → 烯酮 PhCH=C=O → 加水得苯乙酸 PhCH₂COOH。

### 12.4 与现实世界的联系
- **有机合成**：Arndt–Eistert 同系化把羧酸延长一个碳（药物侧链修饰、氨基酸同系物）。
- **天然产物合成**：Wolff/烯酮化学用于构建复杂碳骨架与环扩张。
- **光化学**：Wolff 是光引发重排的教科书案例（光响应合成策略）。
