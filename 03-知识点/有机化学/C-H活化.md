# C-H活化

## 一、定义

C–H 活化指在过渡金属催化下**直接断裂惰性 C–H 键并就地引入官能团**的反应（C–H + R–X → C–R + HX 类转化）。传统交叉偶联需要预官能团化的底物（先做卤代或硼化），C–H 活化省去这步"预活化"，原料即天然分子中最丰富的 C–H 键，因此被称为原子经济性最高、步骤最省的官能团化策略，是 21 世纪金属有机化学与合成方法学的核心前沿（多位学者因 C–H 活化获诺贝尔奖级荣誉，如 2005 年 Grubbs/肖万/施罗克之外，2021 年前后导向 C–H 活化成为方法学热点）。**现阶段 C–H 活化的核心矛盾不是"能不能断键"，而是选择性**——分子中有许多 C–H 键，如何只活化目标的那一根。

## 二、考纲对应

本页属前沿方法学，对应"过渡金属催化"在信息题中的延伸：能识别导向基（directing group）并判断其控制的活化位点；能区分 CMD、氧化加成、σ-键复分解等活化机理；理解 C–H 官能团化在药物后期修饰（late-stage functionalization）与全合成中的应用价值。化学竞赛初赛信息题与决赛方法学题均可能给陌生 C–H 活化循环要求读图作答。

## 三、核心原理

### 3.1 为什么 C–H 键"惰性"而难以直接活化

- 烷烃/芳烃 C–H 键键能高（约 100 kcal/mol 量级，芳烃 C–H 约 110 kcal/mol），且 σ 轨道低能深埋、极性小，普通试剂无法接近。
- 传统断 C–H 靠强亲电/自由基试剂，但选择性差（笼统拔氢）。
- 过渡金属解决之道：先把金属"锚定"在 C–H 键附近（导向基或底物配位），再经**低能垒的金属–碳成键路径**选择性断键——本质是"金属靠近 + 轨道匹配"，而非"试剂强力"。

### 3.2 导向基策略：选择性的第一来源

- **导向基**：分子中已有的、含孤对电子的官能团（吡啶 N、酰胺、羧酸、肟醚、亚胺等），通过与金属配位形成环金属中间体，把金属"拉"到邻近的 C–H 键上。
- 配位–环金属化通常给出**五元或六元环**过渡态，活化发生在导向基的**邻位（ortho）**——这是区域选择性的最可靠来源。
- 弱导向基（酯、酮、酰胺）需更强条件；强导向基（吡啶、8-氨基喹啉酰胺等）可在温和条件下活化远程 C(sp³)–H。
- 导向基可分"安装–活化–脱除"三步使用，也可利用底物自带的羧基/酰胺（内源导向）实现无痕策略。

### 3.3 主要活化机理类型

1. **CMD（协同金属化–去质子化）**：金属与 C–H 的碳配位的同时，由碱（羧酸根、碳酸根）拔走 H，两者协同一步完成，不经过独立的 Wheland 型正离子中间体。Pd(II)、Ru(II) 催化的芳烃 C–H 活化多走此路径；**富电子芳环更易 CMD**。
2. **氧化加成型**：金属直接插入 C–H 键（M + C–H → M(H)(C)），氧化态升高 2。多见于 Pd(II)→Pd(IV)（高价钯，配体/氧化剂辅助）与部分 Rh、Ir 体系；富电子金属（低位 d 轨道）有利。
3. **σ-键复分解 / σ-CAM**：金属–烷基（或 M–H）键与 C–H 键经四中心过渡态互换，金属氧化态不变。Ru/Rh/Ir 活化烷烃 C(sp³)–H 的常见途径，也是烷烃脱氢、氢化硅烷化的机理基础。
4. **亲电金属化**（早期/特殊）：Hg(II)、Pt(II) 等直接亲电进攻富电子芳环（Shilov 化学的 Pt 活化即属此类，机理尚有争议但常归入亲电路径）。

### 3.4 官能团化终止步：活化之后做什么

C–H 活化产物是"金属–碳"中间体（Ar–M 或 R–M），后续官能团化决定合成价值：

- **芳基化/烯基化**：与芳基卤或烯烃偶联（桥接 [[偶联反应]] 的还原消除步）。
- **卤化/硼化**：与 NBS、B₂pin₂ 等反应得芳基卤/硼酸酯——硼化产物可直接接力 Suzuki 偶联。
- **胺化/氧合**：C–N、C–O 键构建，用于药物后期修饰。
- 终止步常需**氧化剂**（Cu(II)、Ag 盐、空气/O₂）把 Pd(0) 或低价中间体重新氧化回活性价态——这是 C–H 活化与"氧化还原中性"的交叉偶联在条件上的重要区别。

### 3.5 后期官能团化（LSF）理念

药物分子已含多个官能团，传统全合成需重新搭建骨架才能换取代基；C–H 活化允许在**合成的最后阶段**直接在骨架上引入（如引入芳基、氟、甲基），加速构效关系（SAR）研究——这是 C–H 活化最打动制药工业的应用点。

## 四、关键结论

- 活化三要素：**导向基（定位）＋金属（断键）＋氧化剂/碱（再生与终止）**，缺一不可。
- 选择性层级：导向基邻位 > 电子效应（富电子位点）> 位阻效应（避开拥挤位点）。
- 机理判据速查：CMD 不变价（Pd(II) 全程）、OA 变价（Pd(II)→Pd(IV)）、σ-复分解不变价且多用于烷烃。
- "直接活化 C–H" ≠ "随便活化任意 C–H"：没有导向基或精细设计的底物，目前无法实现任意位点选择。
- 与交叉偶联的关系：C–H 活化省去"预官能团化"这步，但终止官能团化常仍借偶联/硼化的还原消除逻辑。

## 五、常见分类或情形

- **按机理**：CMD / 氧化加成 / σ-键复分解 / 亲电金属化。
- **按底物 C–H 类型**：芳烃 C(sp²)–H（最成熟）；烯烃 C(sp²)–H；烷基 C(sp³)–H（最难、最前沿，需强导向基）。
- **按引入官能团**：C–H 芳基化 / 烯基化 / 烷基化 / 卤化 / 硼化 / 胺化 / 羰基化。
- **按催化金属**：Pd、Ru、Rh、Ir（贵金属主流）；Ni、Co、Fe、Mn（廉价金属，近年爆发式发展）。

## 六、适用条件与限制

- **选择性依赖导向基**：目前大多数实用体系仍"一个导向基管一个位点"；无导向的远程/非活化位点选择是开放难题。
- **氧化剂化学计量**：Pd(II)/Pd(0) 循环需外部氧化剂再生（Cu(II)、Ag(I)、O₂），原子经济性打了折扣；Ru 等高价态体系可减少氧化剂需求。
- **底物当量与耐受性**：弱导向基常需底物过量；强酸/强碱、易配位杂质会毒化催化剂。
- **高温与时间**：C–H 键惰性，活化步活化能高，多数体系需 100 °C 以上与较长时间。
- **区域选择性叠加**：导向基邻位仍可能有多个不等价 C–H（如不对称邻位），需配体/位阻进一步区分。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| C–H 活化 vs 传统交叉偶联 | 偶联需预官能团化底物（Ar–X、Ar–B）；C–H 活化直接断 C–H 免预活化，但终止步常仍含偶联逻辑 |
| CMD vs 亲电芳香取代（SEAr） | CMD 是金属协助下碱拔氢的协同过程（富电子环有利、无芳正离子中间体）；SEAr 是亲电试剂进攻的离子机理（也是富电子环有利）——判据看"是否有独立亲电位点/是否经过 Wheland 型中间体"，CMD 更多依赖碱与金属配位 |
| 氧化加成活化 vs CMD 的价态 | OA 型金属氧化态 +2（Pd(II)→Pd(IV)）；CMD 全程 Pd(II) 不变价——信息题看循环中金属价态是否跳变即可区分 |
| "直接" = "无选择性随便活化" | 恰恰相反：正因 C–H 太多，才必须用导向基把反应"锁"在唯一/少数位点 |
| 芳烃 C–H 活化 vs 芳香亲电取代的区域选择来源 | SEAr 看电子效应（间/对位由取代基决定）；导向 C–H 活化看配位几何（几乎总在导向基邻位）——两套逻辑不要混用 |

## 八、与其他知识点的联系

- [[偶联反应]]：C–H 活化的官能团化终止步（芳基化/烯基化）复用其还原消除逻辑；芳基 C–H 直接芳基化是两者交叉点。
- [[过渡金属催化]]：氧化加成、迁移插入、还原消除等基元步骤的母概念。
- [[氧化加成与还原消除]]：OA 型 C–H 活化（Pd(II)→Pd(IV)）的机理本质。
- [[有机金属试剂]]：活化产物 M–C 键的化学与转金属背景。
- [[小分子活化]]：无机侧"活化惰性小分子（N₂、CO₂、CH₄）"与本页"活化 C–H 键"同属金属–惰性键活化思想，可对照学习。
- [[催化循环入门]]（决赛深化）：读信息题循环的方法论延伸。

## 九、典型题型

- **位点判断**：给一个含酰胺/吡啶底物，问 Pd 催化下哪个 C–H 被活化（答：导向基邻位，并画五元环金属环）。
- **机理识别**：信息题循环含"金属插入 C–H 且价态 +2"或"碱拔氢协同"步骤，判断是 OA 还是 CMD。
- **补全催化循环**：C–H 芳基化循环中缺氧化剂再生步，要求补写并说明 Cu(II)/Ag 盐的作用。
- **合成应用评价**：比较"传统 Suzuki 路线"与"C–H 直接芳基化路线"的步骤数与原子经济性（LSF 背景题）。

## 十、例题

**例题 1**：2-苯基吡啶在 Pd(OAc)₂ 催化下与 ArI 反应只得到 2-(2-芳基苯基)吡啶（单芳基化）。解释区域选择性的来源。

**解答**：吡啶氮是强导向基，其孤对电子与 Pd(II) 配位，使 Pd 靠近苯环邻位 C–H，经 CMD（碱协助）形成五元环 Pd 金属环中间体；后续与 ArI 氧化加成、还原消除完成芳基化。由于金属环只可能在吡啶的邻位闭合，另一个邻位被芳基占据后再活化困难，故选择性地只发生在吡啶邻位——选择性来自导向基的配位几何而非电子效应。

**例题 2**：某信息题循环中，Pd(II) 与芳烃 C–H 作用后仍为 Pd(II)，随后与 PhB(OH)₂ 反应再生 Pd(II) 并放出联苯。该活化属于哪类机理？中间体是什么？

**解答**：活化过程 Pd 价态未变（Pd(II)→Pd(II)），且需碱协助，属于 CMD（协同金属化–去质子化），中间体为芳基–Pd(II) 金属环/芳基钯物种；与硼酸酯的转金属–还原消除生成联苯，Pd(II) 由氧化剂再生。价态不变是 CMD 区别于"氧化加成型活化"（Pd(II)→Pd(IV)）的关键判据。

**例题 3**：某药物分子拟在芳环上引入一个芳基以改善活性。方案 A：先溴化再 Suzuki；方案 B：利用分子内已有的酰胺导向 C–H 芳基化。评价两者。

**解答**：方案 A 需两步（溴化+偶联）且溴化选择性依赖电子效应，可能在多个位置溴化；方案 B 一步完成且选择性锁定在酰胺邻位（若该位点正是目标位点则最优），步骤与原子经济性更高——这正是后期官能团化（LSF）思想：借助已有官能团导向，直接在骨架上修饰。代价是 B 需专门的催化条件与氧化剂。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 以为 C–H 活化可以"随意活化任意 C–H 键" | 现阶段选择性几乎全靠导向基/底物设计；无导向时 Pd 等难以区分多个 C–H | 反例：2-苯基吡啶只活化吡啶邻位；同一分子中的间/对位 C–H 不动——"直接"指的是免预官能团化，不是"任意" |
| 把 CMD 与 SEAr 混为一谈 | CMD 是金属配位+碱协同拔氢（不变价、无芳正离子中间体）；SEAr 是亲电试剂进攻的离子机理 | 判据：CMD 需碱与金属、对富电子环有利且无独立亲电位点；信息题若活化步前后金属价态不变且需羧酸根/碳酸根，倾向 CMD |
| 忽略氧化剂再生的化学计量 | Pd(II) 活化后变 Pd(0)（或 Pd 中间体失活），没有氧化剂循环无法持续；把 C–H 活化当"无副产物" | 反例：Pd(II)/Pd(0) 体系需 Cu(II)/Ag/空气再生，副产物含还原态氧化剂；Ru 高价体系才接近氧化还原中性 |
| 认为活化位点由电子效应决定 | 导向 C–H 活化的主控因素是配位几何（导向基邻位），电子效应只是次级调节 | 判别：有强导向基时先画金属环（五/六元）定位；电子效应只在无导向或弱导向时主导（富电子位优先） |
| 混淆 sp² 与 sp³ C–H 的难度 | 烷基 C(sp³)–H 键无 π 体系协助、位阻大，活化难度远高于芳烃；把"任何 C–H"当同一难度 | 反例：芳烃 C–H 活化早已成熟，无强导向基的末端甲基 C–H 官能团化至今是研究前沿——题中遇烷基 C–H 必配强导向基与苛刻条件 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
C–H 活化应在掌握过渡金属催化基本概念（氧化加成/还原消除/配位）之后学习。建议先理解"直接官能团化 C–H 键"的优势（原子经济性高、无需预官能团化），再学导向基策略与区域选择性控制，最后学 CMD/OA/σ-复分解三类机理的区别判据，并以药物后期修饰（LSF）收尾建立应用感。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为 C–H 活化可以"随意活化任意 C–H 键" | C–H 活化需要导向基团或底物电子效应控制区域选择性，目前还无法做到完全随机的 C–H 官能团化 |
| 忽略 C–H 活化的选择性问题 | 分子中可能存在多种 C–H 键，实现化学选择性 C–H 活化是该领域的核心挑战 |
| 认为 C–H 活化只是"学术游戏" | C–H 活化已在药物合成中应用，如简化药物分子的后期官能团化（LSF） |

### 12.3 入门级例题
**题目**：解释为什么钯催化的 C–H 芳基化反应中，导向基团可以控制区域选择性。

**解答**：导向基团（如吡啶、酰胺）通过与 Pd 配位形成环金属中间体，将 Pd 催化剂"拉"到特定 C–H 键附近，使该 C–H 键优先被活化（通常为邻位）。没有导向基团时，Pd 只能依赖电子效应（如富电子 C–H 键更活泼），选择性较差。

### 12.4 与现实世界的联系
- **药物后期修饰（LSF）**：直接在药物分子骨架上引入新官能团，无需从头合成，加速药物优化。
- **天然产物全合成**：C–H 活化简化合成路线、减少步骤，被用于紫杉醇类等复杂分子的简化合成。
- **材料科学**：C–H 活化用于共轭聚合物的直接官能团化，制备新型有机电子材料。
