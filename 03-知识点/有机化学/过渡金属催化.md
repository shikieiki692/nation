# 过渡金属催化

## 一、定义

过渡金属催化指利用 d 区金属（Pd、Ni、Cu、Ru、Rh、Ir、Co、Fe 等）的配合物作为**催化剂**，通过一系列基元步骤（氧化加成、迁移插入、β-H 消除、还原消除、配体交换等）循环往复地转化有机底物的反应模式。催化剂只改变反应途径与速率、不被消耗，用量通常为底物的 1–5 mol%。典型应用包括偶联（Suzuki/Heck/Negishi）、氢化、烯烃复分解、Wacker 氧化、羰基化等——现代有机合成约 25% 的药物制造步骤依赖过渡金属催化。与"化学计量金属试剂"（如化学计量 Grignard 反应）不同，**催化循环**是这一领域的核心心智模型。

本页属金属有机化学基础，对应"过渡金属催化的基本概念与催化循环阅读"：能辨认氧化加成/迁移插入/β-H 消除/还原消除四类基元步骤，跟踪循环中金属的氧化态与配位数变化，写出催化循环的总反应，并能读懂信息题给出的陌生催化循环（含补缺步、判断中间体）。初赛信息题高频、决赛理论常考循环机理细节（后者见决赛深化页，本页为入门框架）。

## 三、核心原理

### 3.1 为什么是"过渡金属"：催化的结构基础

- 过渡金属有部分填充的 d 轨道，可呈现多种稳定氧化态（如 Pd(0)/Pd(II)、Rh(I)/Rh(III)），从而在循环中"先被氧化、后被还原"而不被破坏。
- 金属配合物有配位不饱和位点，能可逆地结合底物（烯烃、CO、卤化物、C–H 键等），把底物"拉进配位球"活化。
- 通过更换**配体**（膦、卡宾、胺）可精细调节金属的电子密度与空间位阻，进而控制活性与选择性——配体设计是过渡金属催化的"旋钮"。

### 3.2 四类核心基元步骤（以 Pd 为例）

1. **氧化加成（OA）**：金属插入极性键（Ar–X 等），氧化态 +2、配位数 +2（Pd(0) → Pd(II)）。C–X 活性 I > Br ≫ Cl。
2. **迁移插入（MI）**：配位的不饱和底物（烯烃/CO）插入金属–碳键，如 Pd–Ar 对配位烯烃的顺式加成；氧化态不变。
3. **β-H 消除**：金属–烷基物种经 syn 四中心过渡态脱去 β-H 得 M–H 与烯烃，是迁移插入的逆过程，也是 Heck/Wacker 等反应的关键步。
4. **还原消除（RE）**：两个顺式基团偶合离去，氧化态 −2、配位数 −2（Pd(II) → Pd(0)），催化循环的"产品释放步"。

偶联类循环 = OA → 转金属（配体交换，不变价）→ RE；Heck/Wacker 类循环 = OA → 迁移插入 → β-H 消除 → 再生。**守恒判据：循环中只有 OA（+2）与 RE（−2）改变金属氧化态。**

### 3.3 催化循环的读法（信息题核心技能）

给一个陌生循环图，按固定顺序读：

1. **找金属进出**：每个箭头旁标物种，跟踪同一金属中心（如 Pd）转了一圈，回到起点 = 循环闭合；金属不进入产物。
2. **标氧化态**：依据配体（X 型阴离子配体计 −1，如 Br⁻、OAc⁻；L 型中性配体不计，如膦、烯烃）与 d 电子习惯判断每一步氧化态变化；OA/RE 是唯二变价步。
3. **分类基元步**：把每步归入 OA/MI/β-H 消除/RE/转金属/配体交换。
4. **写总反应**：把所有进入循环的试剂相加、把所有离开循环的产物相加，消去催化剂与中间体，即得净反应（循环图的"外圈"）。

### 3.4 金属–反应类型速查

| 金属 | 常见氧化态对 | 代表反应 |
|---|---|---|
| Pd | 0/II（可到 IV） | Suzuki/Heck/Negishi/Stille 偶联、Wacker 氧化、C–H 官能团化 |
| Ni | 0/II | 偶联（对 Ar–Cl 更活泼）、还原偶联 |
| Cu | I/II（可到 III） | Sonogashira 共催化、Click 反应、氧化偶联（Glaser）、Ullmann 型 C–N/C–O |
| Rh、Ir | I/III | 不对称氢化（BINAP-Rh）、氢甲酰化（Co/Rh） |
| Ru | II/III 等 | 烯烃复分解（Grubbs）、氢化转移 |
| Co | I/III | 氢甲酰化（HCo(CO)₄）、近年 C–H 活化 |

### 3.5 配体与碱的角色

- **配体**：膦（PPh₃、BINAP、XPhos）与 NHC 卡宾最常见；富电子大位阻配体加速氧化加成并促进还原消除；手性配体（BINAP、Josiphos）是不对称催化的关键。
- **碱**：Suzuki 中活化硼酸根、Heck 中中和 HX、C–H 活化中协助去质子化——碱的"任务"因循环而异，读题时注意。
- **氧化剂/还原剂**：当循环需从低价金属再生时补氧化剂（如 Wacker 中 CuCl₂/O₂ 再氧化 Pd(0)→Pd(II)）。

## 四、关键结论

- 催化循环闭环：金属不被消耗；总反应 = 底物之和 − 产物之和。
- 变价只发生在 OA（+2）与 RE（−2）；其余步骤（配位、迁移插入、转金属、β-H 消除）不变价。
- 过渡金属的催化能力来自"可变价态 + 配位不饱和 + 配体可调"三者叠加。
- 同一种金属可催化多种反应（Pd 既偶联又 Wacker 氧化），识别反应类型靠底物与试剂而非金属本身。
- "催化"与"化学计量"的区别：金属用量小且循环再生；写总反应时不出现金属物种。

## 五、常见分类或情形

- **按基元逻辑**：氧化还原中性型（偶联类：OA→TM→RE，无净氧化还原）；氧化型（Wacker：需外部氧化剂再生）；还原型（氢化：H₂ 参与）。
- **按成键类型**：C–C 偶联（Suzuki/Heck/Negishi/复分解）、C–H 官能团化、C–杂键构建（胺化/醚化）、加氢/脱氢、羰基插入。
- **按催化剂量**：均相催化（可溶性配合物，选择性好、机理清晰）vs 多相催化（金属负载于载体，工业大规模，机理研究难）。
- **名人名反应载体**：Heck/Suzuki/Negishi（2010 诺奖）、烯烃复分解（2005 诺奖）、不对称氢化（2001 诺奖）、Wacker 氧化、氢甲酰化。

## 六、适用条件与限制

- **底物边界**：催化循环依赖特定基元步，烷基卤的氧化加成慢且易 β-H 消除，故烷基–烷基偶联长期困难。
- **催化剂失活**：Pd(0) 对氧敏感、易析出钯黑；强配位杂质（硫、磷化物）会毒化催化剂。
- **氧化剂化学计量**：需再生高价金属的体系（Wacker、多数 C–H 活化）氧化剂本身构成副产物来源，原子经济性打折。
- **配体依赖**：没有合适配体时反应常不进行或选择性差；配体成本与专利是工业放大的现实约束。
- **残留金属**：药物合成对 Pd 残留有严格限度，需额外除金属步骤。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 催化 vs 化学计量金属试剂 | 催化剂循环再生、用量 mol%、不进入产物；化学计量试剂（Na、Mg、Li 试剂）被消耗、以当量计 |
| 氧化加成与还原消除方向 | OA：M⁰ → M²⁺（失电子被氧化、配位数增）；RE：M²⁺ → M⁰（得电子被还原、配位数减）——"氧化加成"指金属被氧化 |
| 迁移插入与 β-H 消除的关系 | 互为逆过程（烯烃插入 M–C vs M–C 中 β-H 消除出烯烃），都是 syn 四中心机理、不变价 |
| 均相 vs 多相催化 | 均相：金属溶于反应液、机理基元步可研究、选择性高；多相：金属固载、易分离回收但机理黑箱 |
| "偶联是过渡金属催化的全部" | 氢化、复分解、氧化、羰基化、C–H 活化都是过渡金属催化；偶联只是 C–C 键构建分支 |

## 九、典型题型

- **基元步识别**：给循环图各步标名称（OA/MI/β-H 消除/RE/转金属）。
- **氧化态跟踪**：问某中间体金属的氧化态与配位数（用 X/L 配体计数法）。
- **总反应书写**：由循环图"外圈"写出净反应与副产物。
- **条件解释**：为何 Suzuki 加碱、Wacker 加 CuCl₂/O₂、Heck 碱中和 HX——联系基元步的功能。
- **陌生催化循环补全**（初赛信息题/决赛）：缺一步试剂或中间体，要求补写并说明理由。

## 十、例题

**例题 1**：某催化循环含以下步骤：Pd(0) + PhBr → A；A + 碱活化硼酸酯 → B；B → 联苯 + Pd(0)。标出各步名称与 Pd 氧化态。

**解答**：第一步氧化加成：A = Ph–Pd(II)–Br（Pd 0 → +2）；第二步转金属：B = Ph–Pd(II)–Ph（Pd 仍 +2，碱的作用是把硼酸酯活化为可转金属的硼酸根）；第三步还原消除：释放联苯、Pd 回到 0。总反应 PhBr + PhB(OR)₂ → Ph–Ph，副产物为硼酸酯残基与碱式盐。

**例题 2**：Wacker 氧化 CH₂=CH₂ 制乙醛的循环含 Pd(II)→Pd(0) 的还原步。工业上为何要加 CuCl₂ 与 O₂？Pd 若直接以当量使用行不行？

**解答**：Wacker 循环中 Pd(II) 使烯烃氧化后被还原为 Pd(0)，需再生为 Pd(II) 才能继续催化；CuCl₂ 把 Pd(0) 氧化回 Pd(II)（自身变 Cu(I)），O₂ 再把 Cu(I) 氧化回 Cu(II)——两级再氧化使 O₂（廉价空气）作终端氧化剂。若 Pd 以当量使用，既不经济又难分离回收，违背"催化量循环再生"的原则。

**例题 3**：信息题给出 Ni 催化还原偶联循环，金属在 Ni(0) 与 Ni(II) 间穿梭，每步试剂分别为 ArCl 与 Ar'Br。写出使循环闭合所缺的那类基元步（氧化加成 or 还原消除）出现几次。

**解答**：两次氧化加成（Ni(0)→Ni(II) 分别插入 ArCl、Ar'Br 后经转金属/自身偶联路径）、一次还原消除（Ni(II)→Ni(0) 放出 Ar–Ar'）。判据：氧化态回到 0 且每圈 Ni 净不消耗；若题中只画了一次 OA 一次 RE，则核对是否漏了第二次 OA 的试剂箭头。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 混淆氧化加成与还原消除的方向 | OA 是金属**失电子**（被氧化）M⁰→M²⁺；把"金属插入 C–X"误记为金属被还原 | 反例：Pd(0)+PhBr→Pd(II)，Pd 给出电子插键，氧化态升——"氧化加成"的名字就暗示金属被氧化；配位数同增 2 可作第二判据 |
| 把催化剂量写成化学计量 | 循环再生意味着 Pd 用量 mol%；写"消耗 1 当量 Pd"或总反应含 Pd 即错 | 自检：总反应只含底物与副产物；催化剂在循环图中只绕圈不消失 |
| 忽视配体的决定作用 | 以为"有 Pd 就行"，实为配体决定活性/选择性；无合适配体 Pd 盐常不反应或析钯黑 | 反例：Ar–Cl 的 Suzuki 需 XPhos 类大位阻富电子配体，PPh₃ 体系几乎不反应 |
| 不认识 β-H 消除的 syn 特征 | 把 β-H 消除写成反式消除 | 反例：金属–烷基的 β-H 消除经 syn 四中心过渡态，要求 C–M 与 C–H 共面同侧；这是它与 E2（反式）机理的本质区别 |
| 循环"外圈"总反应写错 | 把循环内中间体当试剂/产物写进总反应 | 判别：只在循环外圈出现、且被消耗/生成的物种才进总反应；金属与配体在内外圈都不出现 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
过渡金属催化应在掌握基础有机反应（取代、加成、消除）与金属有机基本概念之后学习。建议先理解氧化加成/还原消除/插入/β-H 消除四个基元步骤，再学具体偶联反应（Suzuki、Heck、Negishi 等）的循环画法，最后掌握"读循环图→写总反应"的信息题技能；决赛向内容再进 [[过渡金属催化基础]]。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为过渡金属催化只是"高级有机化学" | 过渡金属催化已是现代有机合成常规工具，Suzuki 偶联等反应在药物工业大量使用 |
| 混淆氧化加成和还原消除的方向 | 氧化加成：M⁰ → M²⁺（金属氧化态升高，配位数增加）；还原消除：M²⁺ → M⁰（相反过程） |
| 认为所有偶联反应机理相同 | 不同偶联的催化循环不同：Suzuki 需碱活化硼酸，Heck 是烯烃插入+β-H 消除，Negishi 用有机锌试剂 |

### 12.3 入门级例题
**题目**：画出 Suzuki 偶联反应（PhBr + PhB(OH)₂ → Ph–Ph）的催化循环。

**解答**：Pd(0) 对 PhBr 氧化加成 → Ph–Pd(II)–Br；碱活化硼酸生成 Ph–B(OH)₃⁻ 后转金属 → Ph–Pd(II)–Ph；还原消除 → Ph–Ph + Pd(0) 再生。关键步骤：氧化加成（Pd 进入）、转金属（有机基团交换）、还原消除（产物释放）。

### 12.4 与现实世界的联系
- **药物合成**：约 25% 的药物合成步骤涉及过渡金属催化，如抗癌药伊马替尼（格列卫）用 Suzuki 偶联。
- **有机电子材料**：共轭聚合物（聚噻吩等）依赖 Suzuki/Stille 偶联，用于柔性屏与太阳能电池。
- **绿色化学**：催化减少步骤、提高原子经济性、以空气作终端氧化剂（Wacker 型）是绿色合成的核心技术。
