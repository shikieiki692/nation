# 甲酸

## 一、定义

甲酸（HCOOH，蚁酸）是最简单的羧酸，结构上 R = H：既含 **羧基（–COOH）** 又含**类醛基的 C–H**（COOH 中的 H 直接连在羰基碳上），因此是唯一**同时具有羧酸酸性与醛的还原性**的羧酸。物理上为无色有刺激性气味的液体（bp 101 °C，mp 8.4 °C，可与水混溶），因蚂蚁分泌物得名"蚁酸"。化学上三大特征：①酸性在饱和一元羧酸中最强（pKa ≈ 3.75，因无烷基推电子）；②可被温和氧化剂氧化为 CO₂（Tollens 试剂产生银镜、KMnO₄ 褪色）——这是它区别于其他羧酸的鉴定反应；③受热脱水可分解（HCOOH → CO + H₂O，浓硫酸催化）或歧化。它还是一碳单位（C1）化学的母体（甲酸酯/甲酰胺/甲酸盐），工业上是重要的还原剂与皮革/纺织助剂。

## 二、考纲对应

本页属羧酸化学-结构特殊性考点，对应"甲酸的结构、酸性、还原性与鉴定"：能解释甲酸为何是饱和一元羧酸中最强酸（诱导/无推电子烷基）；掌握其还原性（Tollens/Fehling 银镜、使 KMnO₄ 褪色）并用于与乙酸等区分；理解其热分解（脱水成 CO、脱氢成 CO₂）与甲酸盐/酯的反应；并能识别"含醛基的羧酸"这一结构特征在推断题中的信号（第 30 届真题语境）。初赛以鉴别与性质推断出现。

## 三、核心原理

### 3.1 为什么甲酸酸性最强：没有"推电子"的烷基

- 饱和一元羧酸酸性：HCOOH (pKa 3.75) < CH₃COOH (4.76) < 更长烷基酸（约 4.8–5）。
- 根源：烷基是给电子基，通过诱导效应"推"电子使羧酸根负电荷更分散不利？——正相反：给电子基使 O–H 更难解离（负电荷更集中），酸性下降。甲酸 R=H 无推电子烷基，羧基氧的负电荷相对最稳定 → 酸性最强。
- 取代乙酸系列：吸电子基（Cl、NO₂）增大酸性（ClCH₂COOH pKa 2.86），给电子基降低酸性——甲酸是最简参照点。
- 也因 C–H 无超共轭稳定（比较：乙酸的 α-H 超共轭使羧基 C=O 电子密度略增），酸性差异虽小但考题常问"为何甲酸最强"。

### 3.2 结构特殊性：羧基碳上的 H = 潜在"醛氢"

- HCOOH 的 H–C(=O)–OH：与醛 R–CHO 一样有 **C–H 键连在羰基碳**上，故可被氧化——羧酸的"α 碳"上无 H 的普通羧酸不能。
- 氧化产物是 CO₂（C 从 +2 → +4，失 2e⁻）：HCOOH + [O] → CO₂ + H₂O。
- Tollens 试剂：HCOOH + 2[Ag(NH₃)₂]⁺ + 2OH⁻ → CO₂ + 2Ag↓ + 2NH₄⁺ + 2NH₃（银镜）；乙酸无此反应 → **甲酸 vs 乙酸的经典鉴别**。
- 高锰酸钾：甲酸使酸性 KMnO₄ 褪色（被氧化为 CO₂）；乙酸不褪。

### 3.3 热分解与还原性应用

- **浓硫酸脱水**：HCOOH →(H₂SO₄, Δ) CO + H₂O——实验室制 CO 的方法（CO 有毒性，注意通风）。
- **脱氢（催化/加热）**：HCOOH → CO₂ + H₂O（歧化分解）或 H₂ + CO₂（催化脱氢，甲酸作储氢介质）。
- **还原剂角色**：甲酸/甲酸盐可还原 Pd/C 类（催化转移氢化）；甲酸铵可作氢源。
- 与 NaHCO₃ 反应放 CO₂（羧酸通性）；成酯（甲酸酯 R–O–CHO，具还原性且香味，如甲酸甲酯）。

### 3.4 一碳（C1）化学地位

- 甲酸是 C1 池的重要成员：甲酸 → 甲酰胺/甲酸酯 → 异腈（甲酰胺脱水）；与 CO/H₂ 转化相关。
- 生物化学：叶酸循环中甲酸/甲酰基是一碳单位载体（嘌呤合成）。
- 工业：甲酸（皮革鞣制脱毛、纺织染整、饲料防腐、融雪剂甲酸盐）与甲酸燃料电池（直接甲酸燃料电池 DFAFC：HCOOH → CO₂ + 2H⁺ + 2e⁻）。

### 3.5 鉴定与区分实验汇总

| 试剂 | 甲酸 | 乙酸 | 乙二酸（草酸） |
|---|---|---|---|
| Tollens 银镜 | ✓（氧化为 CO₂） | ✗ | ✓（也还原） |
| 酸性 KMnO₄ | 褪色 | 不褪 | 褪色 |
| 加热脱水 | CO（浓 H₂SO₄） | 不分解 | CO+CO₂ |
| 与 Ca²⁺ | 可溶 | 可溶 | CaC₂O₄ 沉淀 |

## 四、关键结论

- 甲酸 = R=H 的最简羧酸：酸性最强（无推电子烷基）+ 有还原性（羰基 C–H 可被氧化为 CO₂）。
- 酸性排序：HCOOH > CH₃COOH > 长链烷酸；吸电子取代增大、给电子减小。
- 还原性是"类醛"信号：Tollens 银镜/KMnO₄ 褪色专用于甲酸（及草酸）区别于普通羧酸。
- 热分解：浓硫酸脱水得 CO；歧化/催化得 CO₂/H₂。
- C1 化学与工业应用（制革、DFAFC 燃料）。

## 五、常见分类或情形

- **按性质**：酸性（pKa 3.75 最强一元羧酸）、还原性（Tollens 阳性）、热分解（CO/CO₂）。
- **按衍生物**：甲酸盐（HCOO⁻，如甲酸钠、甲酸铵）、甲酸酯（HCOOR，具还原性的酯）、甲酰胺（HCONH₂，脱水得异腈）。
- **按制备**：甲酸钠 + 硫酸（CO + NaOH 高温高压制甲酸钠再酸化）、甲醇羰基化（工业主流：CH₃OH + CO → HCOOCH₃ 水解）、甲醛氧化（历史法）。
- **按鉴别对象**：甲酸 vs 乙酸、甲酸 vs 甲醛、甲酸 vs 草酸（区分实验矩阵）。

## 六、适用条件与限制

- 银镜/褪色反应的"还原性"只对含羰基 C–H 或邻二羟基物种成立——普通羧酸（乙酸及以上）无此性质，勿推广。
- 甲酸有腐蚀性（强于乙酸）与还原性，储存避免与氧化剂混放；加热分解产生剧毒 CO。
- Tollens 试剂需现配现用（久置生成爆炸性雷酸银）；氨性条件 pH 需控制。
- 甲酸与甲醛都能使 Tollens 阳性，区分看：甲醛无酸性（不与 NaHCO₃ 放气），甲酸有羧酸通性。
- 乙二酸（草酸）也具还原性（被氧化为 CO₂），鉴别甲酸 vs 草酸要靠成盐/沉淀（Ca²⁺）或沸点/气味。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 甲酸 vs 乙酸 | 甲酸 pKa 3.75 更强且 Tollens 阳性（可氧化为 CO₂）；乙酸 pKa 4.76、无还原性——银镜/高锰酸钾是分水岭 |
| 甲酸 vs 甲醛 | 都能银镜；但甲酸是羧酸（与 NaHCO₃ 放 CO₂、pKa≈4），甲醛无酸性——看酸碱行为 |
| "最简单的羧酸" ≠ 无特殊性 | 甲酸的 C–H 使其兼有醛的还原性——"最简"反而最特殊 |
| 甲酸酸性强的原因 | 无给电子烷基（R=H），羧酸根负电荷最"不被打扰"——不是"甲酸分子小所以酸强" |
| 草酸 vs 甲酸 | 都还原 Tollens、都使 KMnO₄ 褪色；草酸加热分解 CO+CO₂、与 Ca²⁺ 沉淀，甲酸不沉淀——用沉淀/分解区分 |

## 八、与其他知识点的联系

- 羧酸化学总论（酸性规律、成酯、脱羧）：甲酸是"边界案例"。
- 醛的还原性（Tollens/Fehling）：甲酸的类醛行为共用此逻辑。
- 一碳化学：甲酸→甲酰胺→异腈（与 [[重氮化合物]]/异腈化学相连）。
- 电化学能源：DFAFC（直接甲酸燃料电池）——还原性+清洁燃烧的应用。
- 推断题语境：见 [[题-030-8-化合物A到F结构简式]]（多步推断中甲酸/甲酸盐信号）。

## 九、典型题型

- **鉴别设计**：给甲酸/乙酸/甲醛/草酸混合物，设计化学鉴别流程（银镜→酸性→沉淀）。
- **性质解释**：为何甲酸是饱和一元羧酸中最强酸？为何它能发生银镜而乙酸不能？
- **方程式书写**：甲酸与 Tollens、与 NaHCO₃、浓硫酸脱水、与醇成酯。
- **推断题**：化合物能银镜又能与 NaHCO₃ 放气 → 锁定含甲酸/甲酸酯片段（第 30 届语境）。
- **热分解/储氢**：甲酸分解产物的判断（CO vs CO₂ vs H₂）。

## 十、例题

**例题 1**：如何用化学方法区分甲酸和乙酸？写出关键反应。

**解答**：取两支试管加 Tollens 试剂（银氨溶液）微热：甲酸产生银镜（HCOOH 被氧化为 CO₂，Ag⁺ 还原为 Ag），乙酸无银镜。或用酸性 KMnO₄：甲酸使紫色褪去，乙酸不褪。反应：HCOOH + 2[Ag(NH₃)₂]⁺ + 2OH⁻ → CO₂ + 2Ag↓ + 2NH₄⁺ + 2NH₃（或 HCOOH + [O] → CO₂ + H₂O）。

**例题 2**：解释为什么甲酸（pKa≈3.75）的酸性强于乙酸（pKa≈4.76）。

**解答**：羧酸酸性取决于羧酸根负离子 RCOO⁻ 的稳定性。烷基是给电子基，R 为烷基时通过诱导效应向羧酸根"推"电子，使负电荷更集中、稳定性下降、酸性减弱；甲酸 R=H，无推电子烷基，HCOO⁻ 的负电荷相对最稳定，解离最易 → 酸性最强。同理 ClCH₂COOH（pKa≈2.9）因吸电子氯更强酸——取代基电子效应是核心。

**例题 3**：某有机物分子式 CH₂O₂，能与 NaHCO₃ 反应放 CO₂，又能发生银镜反应；加热脱水（浓 H₂SO₄）产生有毒气体。确定结构并写出三个反应。

**解答**：分子式 CH₂O₂ 即甲酸 HCOOH（唯一满足：1 个 C、羧基酸性、羰基 C–H 还原性）。反应：①与 NaHCO₃：HCOOH + NaHCO₃ → HCOONa + CO₂↑ + H₂O；②银镜：HCOOH 氧化为 CO₂（见上）；③浓硫酸加热：HCOOH → CO↑ + H₂O（CO 有毒）。三特征（酸性+还原性+脱水产 CO）共同锁定甲酸。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为甲酸只是"最简单的羧酸"无特殊性 | 甲酸的羰基碳上连 H（类醛），使它同时有还原性——全库唯一能银镜的羧酸 | 判别：含 H–C(=O)–OH 片段才可被氧化为 CO₂；乙酸以上无此 C–H |
| 酸性与甲醇类比错位 | 甲酸 pKa≈3.75（羧酸）、甲醇 pKa≈15.5（醇）——"醇≠酸"不要拿来比羧酸排序 | 判别：同类比（羧酸系列内）才有效；HCOOH > CH₃COOH 因无推电子烷基 |
| 忽略还原性反应方程式 | 银镜反应中甲酸被氧化为 CO₂（C +2→+4）——写成生成甲醇/甲醛即错 | 自检：产物 CO₂ + 水的物料守恒；草酸也如此但甲酸无草酸的 Ca²⁺ 沉淀 |
| 热分解产物记错 | 浓硫酸脱水 → CO；不是 CO₂ 也不是 H₂ | 判别：实验室制 CO 用甲酸+浓硫酸；歧化/催化才出 CO₂/H₂——看条件提示 |
| 用甲醛性质套甲酸 | 都银镜，但甲醛无酸性（不放 CO₂）且甲醛氧化成甲酸而非 CO₂（在氨性中才到 CO₂） | 判别：先加 NaHCO₃ 试酸性区分甲酸/甲醛，再谈银镜 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
甲酸应在学习羧酸通性之后作为"结构特殊性"案例学习：先理解 R=H 带来的两个推论（酸性最强、有还原性），再练鉴别设计（vs 乙酸/甲醛/草酸），最后用热分解与 C1 化学收尾——把"最简羧酸"讲成"最特殊的羧酸"。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为甲酸只是"最简单的羧酸" | 甲酸的特殊性在于羰基碳上连 H（类醛），可发生 Tollens/Fehling 反应，其他羧酸不能 |
| 混淆甲酸的酸性与醇的酸性 | 甲酸 pKa≈3.75（较强酸），甲醇 pKa≈15.5（极弱酸），相差约 10¹² 倍——但别用醇与酸比 |
| 忽略甲酸的还原性 | 甲酸可被 KMnO₄、Tollens 试剂等氧化为 CO₂，是鉴定甲酸的重要反应 |
| 热分解产物搞混 | 浓硫酸脱水得 CO；加热歧化/催化才得 CO₂ 或 H₂ |

### 12.3 入门级例题
**题目**：如何用化学方法区分甲酸和乙酸？

**解答**：加 Tollens 试剂：甲酸产生银镜（被氧化为 CO₂），乙酸无反应；或加酸性 KMnO₄，甲酸使其褪色而乙酸不褪。

### 12.4 与现实世界的联系
- **电化学能源**：直接甲酸燃料电池（DFAFC）把 HCOOH 氧化为 CO₂ 供电，是便携氢能替代方案。
- **皮革工业**：甲酸用于皮革鞣制和脱毛；也作饲料防腐剂与纺织助剂。
- **生物代谢**：甲酸是一碳单位代谢中间体，参与叶酸循环与嘌呤合成。
