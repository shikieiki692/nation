# Woodward-Hoffmann规则

## 一、定义

Woodward–Hoffmann（伍德沃德–霍夫曼）规则（1965 年，获 1981 年诺贝尔化学奖）是基于**轨道对称性守恒原理**预测周环反应（电环化、环加成、σ-迁移）立体化学与热/光允许性的统一规则：反应中分子轨道对称性沿反应坐标守恒，只有当反应物轨道与产物轨道对称性匹配（相关）时反应才"对称性允许"，否则禁阻。它把看似无关的三类周环反应（电环化、环加成、σ-迁移）纳入同一套"电子计数 + 热/光 + 立体方式"判据，并解释了为什么某些反应加热可行而光照走相反路径、为什么有些热力学允许的反应实际不发生。竞赛中用于预测电环化产物顺反构型、判断 Diels-Alder 热/光条件与环加成立体专一性。

## 二、考纲对应

本页属周环反应-理论框架考点，对应"轨道对称性与周环反应选择规则"：会用电子计数（4n/4n+2）判断电环化的热/光允许方式（对旋/旋光）；判断 [m+n] 环加成的热/光条件与同面/异面；识别 σ-迁移的 [i,j] 与 suprafacial/antarafacial；能解释"热与光结论相反"的轨道根源。决赛理论与高水平初赛信息题直接考查，是 周环反应 页的"规则本体"深化页（该页总览+DA 示例，本页系统化）。

## 三、核心原理

### 3.1 轨道对称性守恒：规则的理论根基

- 周环反应是**单步协同**过程，反应物 MO 连续变形为产物 MO。若某反应物占据轨道（成键/HOMO）的相关线连到产物**反键**轨道，则基态反应须跨越对称性禁阻的高能垒 → 热禁阻。
- 两个等价表述：①**相关图法**（Woodward–Hoffmann 原始）：沿反应坐标跟踪 MO 对称性；②**前线轨道法**（福井谦一/前线轨道理论）：看 HOMO 与反应另一端的 LUMO 对称性是否匹配。
- 关键推论：**光照改变占据轨道**（电子跃到 LUMO），对称性匹配关系反转 → 光反应允许性常与热反应**相反**。

### 3.2 电环化反应：旋光 vs 对旋

开链共轭多烯环化为环烯时，两端 π 轨道旋转方向有两种：同向旋转（**旋光 conrotatory**，产物双键 E/Z 特定）与反向旋转（**对旋 disrotatory**）。

- **热反应**：4n 个 π 电子（n=1 → 丁二烯 4π）→ **旋光允许**；4n+2 个 π 电子（己三烯 6π）→ **对旋允许**。
- **光反应**：两者互换——4n 光 → 对旋；4n+2 光 → 旋光。
- 例：1,3-丁二烯（4π）热环化旋光 → 顺式环丁烯（两个 H 同侧与否取决于旋转方向）；光照对旋 → 反式环丁烯。产物顺反由旋转方式直接决定——这是 W-H 规则预测立体化学的招牌案例。

### 3.3 环加成反应：[m+n] 与同面/异面

两片段 π 体系端对端成两个 σ 键成环。按总 π 电子数：

- **热允许**：总电子数 = 4n+2 时走**同面-同面**（suprafacial–suprafacial）——[4+2] Diels-Alder（6 电子）热允许即此；4n 电子时需**同面-异面**（antarafacial 参与），几何上常难满足（小环体系）。
- **光允许**：4n 走同面-同面（[2+2] 光二聚成环丁烷）；4n+2 光则需异面参与。
- 实战结论：**[2+2] 环加成热禁阻、光允许**（烯烃加热不二聚成环丁烷，光照才行）；**[4+2] DA 热允许、光禁阻**——判断条件给热还是光，先看总电子数。
- 立体专一性：DA 的顺式保留（endo 规则）本质也是轨道对称性+次级相互作用的体现。

### 3.4 σ-迁移反应：[i,j] 与同面/异面

σ 键沿共轭体系迁移（如 [1,5]-H 迁移、[3,3]-Cope/Claisen）：

- 氢迁移 [1,j]：热允许条件是 j 使体系满足 4n+2 且氢走同面（如 [1,5]-H 热允许、[1,3]-H 热禁阻需异面/高温）。
- 碳迁移 [1,j] 与 [i,j]：烷基迁移有构型保持/翻转问题，常走同面（保持）。
- [3,3]（Cope/Claisen）热允许：6 电子体系同面-同面——这就是 Cope 重排加热可行的轨道理由。

### 3.5 记忆口诀总表

| 反应类型 | 电子数 | 热允许方式 | 光允许方式 |
|---|---|---|---|
| 电环化 | 4n | 旋光 | 对旋 |
| 电环化 | 4n+2 | 对旋 | 旋光 |
| 环加成 [m+n] | 4n（如[2+2]） | 禁阻（需异面） | 同面-同面 ✓ |
| 环加成 [m+n] | 4n+2（如[4+2]） | 同面-同面 ✓ | 禁阻 |
| σ-迁移 [i,j] | 总 4n+2（H 走同面） | ✓ | 视情况 |

口诀："**4n 热旋、4n+2 热对；光照互换**"（电环化）；"[2+2] 光、[4+2] 热"（环加成）。

## 四、关键结论

- W-H 规则 = 轨道对称性守恒的应用：协同周环反应的选择规则由 π 电子计数与热/光条件唯一决定。
- 电环化：4n 热旋光、4n+2 热对旋；光照两种互换——产物顺反由此定。
- 环加成：[4+2]（6 电子）热允许（DA）；[2+2]（4 电子）光允许——电子数决定条件。
- σ-迁移：[3,3] 热允许（6 电子同面）；[1,3]-H 热禁阻等由 [i,j] 计数判。
- 热与光相反的原因：激发使 HOMO/LUMO 互换、占据轨道对称性反转。
- 立体专一性是规则价值所在：同一原料热/光给出不同立体化学产物。

## 五、常见分类或情形

- **电环化**：丁二烯→环丁烯（4π）、己三烯→环己二烯（6π）、环丁烯开环（逆向）等。
- **环加成**：[2+2]（光二聚成环丁烷、酮的光环化）、[4+2] Diels-Alder、[6+4]（少见）等。
- **σ-迁移**：[1,3]-H/[1,5]-H 氢迁移、[3,3] Cope/Claisen、[2,3]-Wittig 等。
- **实际判断流程**：①标共轭电子总数；②看题给条件（热/光）；③查口诀得立体方式；④画产物构型。

## 六、适用条件与限制

- 只适用于**协同周环机理**：若反应实际走分步（自由基/离子）路径，W-H 规则不适用（需实验证据判断机理）。
- 电子计数必须数对：电环化数 π 电子；环加成数两片段总 π 电子；σ-迁移按迁移体系总电子。
- 异面（antarafacial）过程在多数常规底物上几何上难以实现（需特殊环系/大体系），故"禁阻"常意味着实际不发生而非理论上完全不可行。
- 立体化学预测需要正确识别旋转方向与取代基取向，画图易错——先定旋/对旋再摆取代基。
- 光反应还需考虑顺反异构/副反应（激发态活性高）。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 热 vs 光规则 | 光照使电子跃迁到 LUMO，占据轨道对称性反转 → 允许性常与热相反（电环化 4n 热旋光对；[2+2] 热禁光允）——题目给"光照"先想互换 |
| 4n vs 4n+2 数错 | 电环化数共轭 π 电子总数（丁二烯 4、己三烯 6）；环加成把两片段加起来（乙烯+乙烯=4、丁二烯+乙烯=6） | 
| W-H vs 前线轨道 | 两者等价：W-H 用相关图、FMO 看 HOMO/LUMO 匹配；解题用 FMO 直觉、记 W-H 结论 |
| 与热力学稳定性的关系 | W-H 是**动力学/轨道**判据：热力学允许但对称性禁阻的反应实际极慢（如[2+2]加热）——"放热不一定发生" |
| 旋光/对旋产物混淆 | 旋光（同向）→ 取代基在环同侧关系特定；对旋（反向）→ 相反构型——先判方式再写顺反，不能凭产物稳定性猜 |

## 九、典型题型

- **电环化产物预测**：丁二烯/己三烯在热或光条件下环化产物的顺反构型（题-有机-周环-WoodwardHoffmann规则电环化）。
- **条件判断**：某 [2+2] 或 [4+2] 反应应加热还是光照（电子计数定条件）。
- **立体专一性解释**：同一 1,3-二取代丁二烯热/光产物不同——用旋/对旋解释。
- **逆向分析**：由产物构型反推反应条件（热/光）与原料构型。
- **机理辨析**：判断某转化是协同周环（适用 W-H）还是分步离子/自由基（不适用）。

## 十、例题

**例题 1**：预测 1,3-丁二烯在（a）加热（b）光照条件下电环化的产物构型差异。

**解答**：丁二烯 4 个 π 电子 = 4n（n=1）。（a）热：旋光（conrotatory）允许——两端同向旋转，得**反式**（两个 H 在环两侧/取代基反式）环丁烯为主（实际热力学向顺式环丁烯的动力学产物，规则预测反式-顺式取决于取代基；经典命题为 2,4-己二烯类：热得 E,E 相关构型）。（b）光：对旋（disrotatory）允许——得另一构型产物。规则要点：**热与光给出相反立体化学**，这是 W-H 规则可验证的招牌预言。

**例题 2**：判断乙烯光二聚与丁二烯+乙烯（DA）各自需要热还是光，并解释。

**解答**：[2+2] 环加成总 π 电子 4 = 4n → 基态同面-同面禁阻（需异面，几何难满足）→ **热禁阻、光照允许**（激发态对称性反转，同面-同面可行）——故环丁烷靠光二聚制备。[4+2] 总电子 6 = 4n+2 → **热允许**（同面-同面）→ Diels-Alder 加热即可、光照反而禁阻。电子计数直接决定实验条件选择。

**例题 3**：为什么 [1,3]-H 迁移（如烯丙基体系的氢 1,3 跳）加热难以进行，而 [1,5]-H 迁移在顺-1,3-戊二烯中容易？

**解答**：[1,j]-H 迁移热允许条件是迁移体系满足 4n+2 且氢 suprafacial：[1,3] 对应 2 电子（4n，n=0.5 不整）不满足 → 热禁阻（须 antarafacial 或高温自由基路径）；[1,5] 对应 4 电子 + H 同面 = 6 电子等价过程 → 热允许，故 1,3-戊二烯的 [1,5]-H 迁移（双键移位异构化）常温可发生。这就是"为什么某些氢迁移容易、某些几乎不发生"的轨道根源。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 热/光规则记反 | 4n 电环化热旋光、光对旋；[2+2] 热禁光允、[4+2] 热允光禁——"光照"不是"都允许" | 判别：先数 π 电子总数再对表；口诀"4n 热旋 4n+2 热对，光照互换；2+2 光、4+2 热" |
| 电子数数错 | 电环化数单一共轭体系 π 电子；环加成数**两片段合计**——把 DA 数成 4+2=6 要合计 | 反例：乙烯+乙烯=4（[2+2]）；丁二烯+乙烯=6（[4+2]）——数错直接判反条件 |
| 把 W-H 当经验规律 | 规则基于轨道对称性守恒（相关图/FMO），有严格量子力学基础，非凑出来的规律 | 判别：解释"为什么[2+2]热不反应"要用对称性禁阻，不是"不稳定" |
| 用热力学代替对称性判断 | 放热/产物稳定 ≠ 反应可行；对称性禁阻的反应动力学极慢 | 反例：两个乙烯聚合放热，但热[2+2]几乎不发生（禁阻）；光照才行——"能放热"与"会发生"是两回事 |
| 旋光/对旋的产物构型画错 | 旋光两端同向转、对旋反向转；取代基随旋转落到环同侧/异侧——凭产物稳定性猜构型必错 | 判别：先在两端标旋转箭头（同向=旋、反向=对），再逐个原子摆取代基画环产物 |
| 忽略机理前提 | 规则只适用协同周环；若反应走分步（自由基/离子/双自由基），对称性分析不适用 | 判别：题目有引发剂/极性条件/非立体专一证据 → 非协同 → 别套 W-H |

## 十二、🎯 教学视角

### 12.1 学习路径建议
Woodward-Hoffmann 规则应在掌握前线轨道理论与周环反应各论之后学习。建议先理解"轨道对称性守恒"的概念（相关图/前线轨道两种视角），再逐类学电环化（旋/对旋）、环加成（[2+2]/[4+2]）、σ 迁移（[i,j]）的电子计数规则，最后用记忆口诀 + 真题判断流程收束。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为 W-H 规则只是"经验规律" | 规则基于量子力学的轨道对称性守恒原理，有严格理论基础 |
| 混淆热反应和光反应的规则 | 热与光的允许性通常相反（光激发改变 HOMO/LUMO 对称性） |
| 忽略电子计数 | 电环化看 π 电子数（4n/4n+2）；环加成看总电子数；σ 迁移看 [i,j]——数错全错 |
| 用热力学代替对称性 | 对称性禁阻的反应即使放热也不发生（如热 [2+2]）——W-H 是动力学判据 |

### 12.3 入门级例题
**题目**：预测 1,3-丁二烯在光照条件下的电环化产物构型。

**解答**：丁二烯 4 个 π 电子（4n 体系）。光反应：对旋（disrotatory）允许——两端反向旋转，得特定顺反构型的环丁烯；热反应则旋光（conrotatory）允许，产物构型相反。光照使电子从 HOMO 跃迁到 LUMO，改变了轨道对称性匹配关系。

### 12.4 与现实世界的联系
- **天然产物全合成**：W-H 规则用于预测与控制周环步的立体化学（维生素 D 前体、萜类电环化）。
- **药物合成**：光化学 [2+2] 与 DA 是构建四元/六元环与手性中心的工具。
- **材料科学**：光致变色分子（二芳基乙烯类）利用光环化-开环的可逆电环化实现开关。
