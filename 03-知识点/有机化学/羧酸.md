# 羧酸 (Carboxylic Acids)

## 一、定义

**羧酸** 是含有 **羧基（—COOH）** 的有机化合物，通式为 **R—COOH**。羧基由羰基（C=O）和羟基（—OH）直接相连而成，是含氧官能团中酸性最强的。

- 羧基中的 **羟基** 因羰基的吸电子效应而具有明显酸性（pKa ≈ 4~5）
- 羧酸是有机合成中最常见的起始物料之一

## 二、分类

### 2.1 按碳骨架
| 类型 | 实例 |
|:---|:---|
| **饱和一元羧酸** | 乙酸、丙酸、丁酸 |
| **不饱和羧酸** | 丙烯酸、巴豆酸 |
| **芳香羧酸** | 苯甲酸、邻苯二甲酸 |
| **二元羧酸** | 草酸、丙二酸、丁二酸 |
| **取代羧酸** | 卤代酸、羟基酸、氨基酸 |

## 四、教学常见节点

- **酸性比较**：HCOOH > PhCOOH > CH₃COOH > 取代乙酸（吸电子基增强酸性）
- **取代基对酸性的影响**：FCH₂COOH > ClCH₂COOH > BrCH₂COOH > CH₃COOH
- **二元羧酸**：加热脱水成酸酐（丁二酸 → 丁二酸酐）
- **脱羧**：β-酮酸受热易脱羧；丙二酸加热脱羧得乙酸
- **试剂**：DCC 常用于羧酸与胺/醇的缩合

## §12 教学视角

### 学生常见认知误区

- **误区1：「羧基中的 -OH 和醇中的 -OH 性质一样」** → 学生看到都有 -OH 就以为反应性相同。实际上羧基中 -OH 因羰基的吸电子共轭效应，O-H 键极性增强，酸性远强于醇（羧酸 pKa ≈ 4~5，醇 pKa ≈ 16）。而且羧基 -OH 可被亲核试剂取代（生成酯、酰氯等），醇 -OH 则不能。 → **口诀：羧基 -OH 是「叛变的 -OH」——酸性翻了十亿倍，还能被取代。**

- **误区2：「羧酸的酸性不如硫酸所以不重要」** → 学生轻视有机弱酸。实际上羧酸的 pKa（4~5）比碳酸（pKa₁ ≈ 6.4）强，所以羧酸能与碳酸钠反应放出 CO₂——这是实验室鉴别羧酸的经典方法。 → **正确认知：羧酸比碳酸强，可以与 NaHCO₃ 反应。这是鉴别羧酸和酚（酚比碳酸弱）的关键实验。**

- **误区3：「脱羧反应只有丙二酸和 β-酮酸才会发生」** → 学生只记住了特殊例子，但忽略了普适规律。脱羧的关键是产物稳定性：丙二酸脱羧得酮式乙酸（稳定），β-酮酸脱羧得烯醇式酮（互变异构稳定）。一般羧酸加热不脱羧。 → **口诀：脱羧要有「稳定退路」——产物能稳定才脱得掉。**

- **误区4：「Fischer 酯化是加成反应」** → Fischer 酯化（羧酸 + 醇 → 酯 + 水）是**取代反应**（酰基碳上的 -OH 被 -OR' 取代），不是加成。虽然机理中有亲核加成步骤，但整体是取代。 → **方法：看净结果——酸 + 醇 = 酯 + 水，有小分子脱出，是缩合/取代。**

- **误区5：「羧酸衍生物的反应活性顺序是固定的」** → 学生记住「酰氯 > 酸酐 > 酯 > 酰胺」但不知道为什么。本质是离去基团的碱性越弱（离去能力越强），酰基碳越容易被亲核进攻。 → **口诀：离去基团越「懒」（碱性越弱），酰基碳越「勤快」（越容易反应）。**

### 入门级例题

**题目**：某化合物 A（分子式 $\ce{C4H8O2}$）不与 NaHCO₃ 反应，但能与 Na 反应放出 H₂。A 经酸性水解得到 B 和 C，其中 B 可被 Tollens 试剂氧化。写出 A 的结构并解释为何 A 不与 NaHCO₃ 反应。

**分析**
- $\ce{C4H8O2}$，不饱和度 = 1
- 不与 NaHCO₃ 反应 → 不是羧酸（羧酸比碳酸强，会反应）
- 能与 Na 反应 → 含活泼 H（-OH 或 -NH）
- 酸性水解得 B 和 C → A 是酯
- B 被 Tollens 试剂氧化 → B 是醛（被氧化为酸）

**解答**

A 是甲酸丙酯 $\ce{HCOOCH2CH2CH3}$（或甲酸异丙酯 $\ce{HCOOCH(CH3)2}$）。

酸性水解：$\ce{HCOOR + H2O ->[H+] HCOOH + ROH}$
- B = 甲酸（HCOOH），可被 Tollens 试剂氧化（醛基 H）
- C = 丙醇（或异丙醇）

A 不与 NaHCO₃ 反应，因为酯的酸性极弱（pKa ≈ 25），远弱于碳酸，不能提供质子给 $\ce{HCO3-}$。

**反思**
- NaHCO₃ 反应是鉴别羧酸和酯的经典方法：羧酸有气泡（CO₂），酯没有
- 酯的水解是可逆反应，需要酸或碱催化；碱性水解（皂化）不可逆
- Tollens 试剂（银镜反应）可以区分醛和酮，也可以区分甲酸酯（含醛基 H）和普通酯

### 与现实/直觉的连接

**类比：羧酸是一个「两面派」**
- **酸性面**：-OH 部分可以给出 H⁺，表现出酸的性质（与碱反应、使石蕊变红）
- **羰基面**：C=O 部分可以被亲核进攻，表现出羰基化合物的性质（加成-取代）
- 两个面的「分裂」来自共轭：O=C-OH 中，孤对电子从 -OH 氧向羰基共轭，使得 -OH 的氧带有部分正电荷，O-H 更容易断裂

**实际应用**
- **醋（乙酸）**：日常食用醋含 4-8% 乙酸，其酸性足以溶解水垢（碳酸钙）：$\ce{2CH3COOH + CaCO3 -> (CH3COO)2Ca + H2O + CO2}$
- **阿司匹林（乙酰水杨酸）**：含羧基，所以有酸味。它的合成是水杨酸（酚酸）的酚 -OH 的 Fischer 酯化。
- **尼龙和涤纶**：尼龙是二元酸 + 二元胺缩合（酰胺键），涤纶是二元酸 + 二元醇缩合（酯键）——都是羧酸衍生物的缩合聚合。
- **柠檬酸循环（TCA 循环）**：生物体内能量代谢的核心通路，全部中间体都是羧酸或酮酸。

### 教学建议

1. **酸性比较是入门第一关**：建议用 pKa 表让学生排序常见有机酸（羧酸、酚、醇、水），建立「酸性阶梯」。核心规则：吸电子基增强酸性，给电子基减弱酸性。
2. **取代基效应用定量数据说话**：不要只说「F 增强酸性」，而是给出具体 pKa（FCH₂COOH pKa = 2.66 vs CH₃COOH pKa = 4.76），让学生感受效应的大小。
3. **脱羧反应关联代谢**：丙二酸脱羧和 β-酮酸脱羧在生物体内（脂肪酸合成、柠檬酸循环）反复出现。将有机反应和生物化学连接能极大增强学生兴趣。
4. **羧酸衍生物的反应活性是合成设计的基础**：酰氯最活泼（容易合成酯、酰胺），酰胺最稳定（不容易被水解）。这个活性序列是设计多步合成时选择保护基和反应顺序的核心依据。
5. **用「酰基碳的亲电性」统一所有反应**：酯化、水解、醇解、氨解——本质都是亲核试剂进攻酰基碳。理解了这一点，学生就不需要死记每个反应，而是能推导。
