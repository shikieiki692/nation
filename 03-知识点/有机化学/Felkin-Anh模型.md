# Felkin-Anh模型

## 一、定位

Felkin-Anh 模型用于预测亲核试剂对手性羰基化合物进攻时的立体选择性，是羰基加成题中的经典判断框架。

## 二、学习重点
- 先识别羰基 α 位取代基大小
- 再判断亲核体优先从哪一侧进攻
- 与螯合控制模型形成对照

## 三、关联页
- [[立体选择性]]
- [[不对称合成]]

## 四、核心原理

### 4.1 模型核心思想

Felkin-Anh模型的核心是将空间效应和电子效应统一在同一个构象分析框架中：

- **构象要求**：羰基α-碳上最大基团(L)垂直于羰基平面（即L-C键与C=O键呈约90°夹角），使L基团远离羰基氧
- **进攻方向**：亲核试剂从位阻最小的方向进攻羰基碳——即从小基团(S)一侧接近
- **电子效应**：α-碳上C-L键的σ\*反键轨道与羰基π\*轨道存在超共轭相互作用（σ\*\_{C-L}→π\*\_{C=O}），当L垂直于羰基平面时这种超共轭最强，进一步降低了亲核试剂从S侧进攻时的过渡态能量

> **一句话总结**：大基团垂直于羰基平面既满足空间位阻最小化，也满足电子效应最优化，两个因素协同指向同一进攻面。

### 4.2 构象分析与预测

使用Newman投影式进行预测的标准步骤：

1. **画Newman投影式**：沿α-碳—羰基碳键观察，大基团(L)置于垂直位置（上方或下方）
2. **排布其余基团**：中基团(M)和小基团(S)分布在平面内，分别位于L的两侧
3. **确定进攻方向**：亲核试剂从S一侧进攻（位阻最小面）
4. **推断产物构型**：根据进攻方向确定新生成手性中心的构型

**应用示例**：

对于α-手性醛 R\*-CH(L)(M)(S)-CHO：
- L = 大基团（如 Ph、t-Bu）
- M = 中基团（如 Me、Et）
- S = 小基团（如 H、Me）

亲核试剂Nu⁻从S侧进攻→得到的主产物中Nu与S处于同侧关系（Fischer投影中同侧）。

### 4.3 螯合控制例外

当α-碳上连接有可螯合基团（如-OH、-OMe、-NR₂等）时，反应可能偏离Felkin-Anh预测：

- **螯合条件**：α-位有含孤对电子的杂原子取代基，且存在合适的Lewis酸金属离子（如Mg²⁺、Ti⁴⁺、Zn²⁺、Sn⁴⁺）
- **螯合机理**：金属离子同时配位羰基氧和α-取代基的杂原子，形成五元环螯合中间体，刚性锁定构象
- **进攻方向改变**：亲核试剂从螯合环的对面进攻（"螯合面"），可能导致与Felkin-Anh模型完全相反的立体选择性

**Cram螯合模型 vs Felkin-Anh模型**：

| 特征 | Felkin-Anh模型 | Cram螯合模型 |
|:---|:---|:---|
| 构象 | 大基团垂直于羰基平面 | 螯合环刚性锁定构象 |
| 进攻面 | 从小基团(S)一侧进攻 | 从螯合环对面进攻 |
| 适用条件 | 无螯合基团或非Lewis酸条件 | α-位有可螯合基团 + Lewis酸存在 |
| 预测结果 | 取决于L/M/S大小排序 | 常给出与Felkin-Anh相反的产物 |

> **实战要点**：Grignard试剂中Mg²⁺可参与螯合，而NaBH₄还原通常不涉及金属螯合。反应条件（Lewis酸种类、溶剂极性）决定走哪条路径。

## 六、典型题型

### 题型一：根据反应物预测主产物立体化学

给出含α-手性中心的醛/酮和特定亲核试剂，要求用Felkin-Anh模型画出优势构象并预测主要产物的构型。这类题目需要：
1. 正确判断α-碳上各基团的L/M/S大小
2. 画出正确的Newman投影式
3. 确定亲核试剂的进攻方向
4. 推断产物的相对构型（syn/anti或R/S）

### 题型二：判断反应条件对立体选择性的影响

给出同一个底物在不同条件下反应，要求解释为什么得到不同立体化学产物。例如：无Lewis酸条件下得到Felkin-Anh产物，加入TiCl₄后得到螯合控制产物。需要结合螯合控制例外进行分析。

## 🎯 教学视角

### 学习路径建议

Felkin-Anh模型应在掌握立体化学基础和羰基亲核加成之后学习。建议先理解"大基团垂直于羰基平面"的构象要求，再学习亲核试剂从位阻最小面进攻的规则，最后与螯合控制模型对比（当α-位有可螯合基团时）。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为亲核试剂总是从位阻小的一面进攻 | Felkin-Anh模型考虑了电子效应和空间效应的综合影响，大基团垂直于羰基平面时电子效应也起作用 |
| 混淆Felkin-Anh模型和Cram规则 | Felkin-Anh模型是Cram规则的改进版，考虑了σ*轨道的电子效应，更准确 |
| 忽略螯合控制的例外 | 当α-位有OH、OMe等可螯合基团时，亲核试剂可能从"螯合面"进攻，违反Felkin-Anh预测 |

### 入门级例题

**题目**：用Felkin-Anh模型预测(R)-2-苯基丙醛与CH₃MgBr反应的主要产物。

**解答**：(R)-2-苯基丙醛的α-碳连接H（小）、CH₃（中）、Ph（大）。按Felkin-Anh模型，Ph垂直于羰基平面，CH₃和H在平面内。亲核试剂（CH₃⁻）从位阻最小的H一侧进攻，主要产物为(2S,3R)-3-苯基-2-丁醇。

### 与现实世界的联系

- **药物合成**：Felkin-Anh模型用于预测和控制药物分子中手性中心的构型，提高对映选择性
- **天然产物全合成**：许多天然产物的立体化学由Felkin-Anh模型控制的羰基加成反应决定
- **不对称催化**：手性催化剂的设计需要理解Felkin-Anh模型，以实现高非对映选择性
