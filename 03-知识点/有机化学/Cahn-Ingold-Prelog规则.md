# Cahn-Ingold-Prelog规则

> [!note] 核心概念
> 用于确定手性中心R/S构型和双键Z/E构型的优先级排序规则。

## 优先级排序全规则（按序执行）

### 第一层：原子序数（最大头）

- 直接相连原子序数大者优先：I(53) > Br(35) > Cl(17) > S(16) > O(8) > N(7) > C(6) > H(1)
- 同位素：质量数大者优先（D > H；¹⁴C > ¹²C）
- **优先级由原子序数唯一决定，与电负性无关**——O > N > C 排序中 O 优先是因为序数而非电负性（虽然恰好一致）；S > O 则纯靠序数（电负性 S < O 但 S 仍优先！）——这是新手最大误区

### 第二层：平局时向"下一层原子"延伸

- 直接相连原子相同（如两个碳）→ 比较各自连的其余 3 个原子，按序数降序逐位比较
- 例：-CH₂OH vs -CH₂CH₃：第一层都 C；第二层 -CH₂OH 的 C 连 (O, H, H)，-CH₂CH₃ 的 C 连 (C, H, H)；比较最高位 O(8) vs C(6) → -CH₂OH 优先
- 递归：第二层还平局（都连 C）→ 向第三层延伸（把"复制"的 C 展开），直到分出胜负

### 第三层：多重键按"展开"处理

**双键/三键视作连接 2 个/3 个相同的"虚拟原子"**：

- C=O 的 C 视作连 (O, O, —)；C≡N 的 C 视作连 (N, N, N)；苯环 C 视作连 (C, C, —) 类
- 例：-CHO（醛基，C 连 O,O,H）> -CH₂OH（C 连 O,H,H）——醛基碳"虚拟两个 O"故优先
- 例：-C≡CH（C 连 C,C,C 虚拟三重）> -CH=CH₂（C 连 C,C,H）> -CH₂CH₃（C 连 C,H,H）——炔 > 烯 > 烷

## R/S构型判定（四步法）

1. 对四个取代基按 CIP 排序：1 > 2 > 3 > 4
2. 视线沿 C–4 键（最低优先级基团朝远离观察者/或先把 4 转到纸面后方）
3. 看 1 → 2 → 3 的旋转方向：**顺时针 = R（rectus，右）**，**逆时针 = S（sinister，左）**
4. 若 4 正好朝向观察者（纸面外），先旋转纸面或记住"看反了 → 结果取反"

**费歇尔投影快捷法**：若 4（通常 H）在水平线上 → 直接读 1→2→3：顺时针为 R？——投影里水平键朝前（纸外），规则：**H 在横线时，1→2→3 顺时针为 S、逆时针为 R**（与 H 在竖线时相反）。记口诀："横 H 反着读"。最稳做法仍是把 4 转到后方再判，投影题可先任意置换两次把 4 放竖线（每次交换翻转构型，交换偶数次不变）。

## Z/E构型判定（双键）

1. 对双键**两端各**做 CIP 排序（每端两基团分 1、2）
2. 两端高优先级基团（各端 1 号）同侧 = **Z**（zusammen，一起）；异侧 = **E**（entgegen，相对）
3. 与 cis/trans 的关系：**多数一致但不总是**——当两端有相同基团无法用 cis/trans 表达时必须用 Z/E；两对基团不同时 cis = Z、trans = E 恰好吻合，但（如 1-氯-1-溴-2-碘-2-氟乙烯）只能靠 CIP 判 Z/E

**易混提醒**：Z ≠ cis、E ≠ trans 是绝对化错误；cis/trans 看"相同或最大基团同侧与否"，Z/E 看"各自端的高优先级基团同侧与否"——两者在基团各不相同时等价，有交叉比较时可能背离。

## 含杂原子/手性面/轴手性（扩展）

- **含 P/S 手性**：亚砜 R¹S(O)R²（S 手性中心，孤对算"第四基团"按最低处理）、手性膦 PR¹R²R³——同法排序，孤对优先级 0（最低）
- **轴手性**（联苯/丙二烯）：不能旋转的轴产生手性——联苯邻位大基团阻碍旋转（阻转异构），丙二烯两端面互相垂直
- **面手性**（环芳烃/取代环烯）：罕见但决赛可出
- **R/S 标记的前提**：必须先确认分子是手性的（有且仅有一个手性中心时为 R/S；多手性中心逐个标，注意内消旋体抵消）

## 判定速练（含解析）

**练 1**：乳酸 CH₃CH(OH)COOH 手性碳四基团排序 → -OH(1, O) > -COOH(2, C 连 O,O,O 虚拟) > -CH₃(3, C 连 H,H,H) > -H(4)。H 放后方，1→2→3 逆时针 → S。题-乳酸天然异构体为 S-(+)-乳酸？实际 L-乳酸（(S)-(+)-乳酸）✓——R/S 与旋光 +/- 无关，须实验测。

**练 2**：判断 CH₃CH=CHCl 的 Z/E——C1 端 CH₃(H,H,H) vs H：CH₃ 优先(1)；C2 端 Cl 优先(1)、H(2)。两端 1 号（CH₃ 与 Cl）同侧为 Z（顺-1-氯丙烯）✓。

**练 3**（投影陷阱）：费歇尔投影中 H 在横线，1→2→3 顺时针——因横线键朝前，实际为 S（反着读）——先练熟"置换法"保底。

## 费歇尔投影速判法（考场不翻车）

费歇尔投影中：竖线键朝纸后、横线键朝纸前。判 R/S 的可靠流程：

**置换法（推荐，永不翻车）**：
1. 若 H（4 号）在竖线上 → 已就位：直接看 1→2→3，顺 R 逆 S
2. 若 H 在横线上 → 与任一基团交换一次（交换改变构型），把 H 换到竖线 → 按 1 判向 → **结果取反**（因为做过一次交换）

**规则背记（熟练者用）**：
- H 在竖线：1→2→3 顺时针 = R
- H 在横线：1→2→3 顺时针 = S（"横 H 反着读"）

**多手性中心**：每个中心独立判向（2ⁿ 个立体异构体上限），逐个标 (2R,3S) 式；判完用对称性检查是否内消旋（有对称面 → 整体无旋光）。

## 完整判定流程图（含分子式识别）

1. 分子有无手性中心？（C 连 4 个不同基团 / P、S 类似 / 轴-面手性）——无则 R/S 不适用
2. 有 → 四基团排序：第一层序数 → 平局第二层 → 多重键展开 → 同位素 →（仍有平局则结构对称，实际不可能有 4 基团全平）
3. 视图操作：4 号朝后（旋转分子或置换）
4. 判向：1→2→3 顺时针 R / 逆时针 S
5. 双键另判 Z/E：两端各排序 → 同侧 Z 异侧 E
6. 复核：命名后检查是否有内消旋抵消、是否与已知旋光数据矛盾

**六步走完，CIP 题零失分**——绝大多数错误发生在第 2 步（排序）与第 3 步（视图），排序表与"横 H 反读"各花 30 秒即可根治。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| R/S 与旋光 +/- 挂钩 | R/S 是构型（空间排列），旋光方向需实验（+/- 与 R/S 无固定对应） | (S)-乳酸可左旋或右旋视具体化合物；沙利度胺 R 与 S 旋光都可能 |
| 优先级看电负性 | 看原子序数：S(16) > O(8)——电负性 O > S 但 CIP 里 S 优先 | 含 S 取代基常误判：-SH > -OH 在 CIP 规则下成立 |
| 平局不向第二层延伸 | 第一层相同必须比第二层（逐位比较） | -CH₂OH > -CH₂CH₃ 靠第二层 O vs C |
| 多重键不展开 | C=O 不展开则误判为 C 连 (O,单键,无) | -CHO 连 O,O（双键拆 2 个虚拟 O）> -CH₂OH 连 O,H |
| H 方向看反 | 4 朝前时直接读会 R/S 颠倒 | H 在横线反着读；或置换两次把 H 转竖线 |
| Z/E 与 cis/trans 强制等价 | 基团各不相同时等价，含交叉/相同基团时可能背离 | 1-氯-1-溴-2-碘-2-氟乙烯只能 Z/E 表达 |
| 忘了先验手性 | 内消旋/无手性中心标 R/S 无意义 | 2,3-二溴丁烷的 (2R,3S) 是内消旋（无旋光）——标了也要识别抵消 |

## 🎯 教学视角

### 学习路径建议

CIP规则应在掌握手性概念和立体化学基础之后学习。建议先理解"优先级排序"的逻辑（原子序数→同位素→下一层原子），再练习R/S和Z/E的判定方法，最后通过大量练习建立快速判断能力。

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为R/S构型等同于"右旋/左旋" | R/S是构型标记（空间排列），旋光方向（+/-）需实验测定，两者无直接对应关系 |
| 忽略双键/三键的特殊处理 | 双键碳视为连接两个相同原子（如C=O视为C连接两个O），三键视为连接三个 |
| 混淆Z/E和cis/trans | Z/E是CIP规则定义的（基于优先级），cis/trans基于基团相对位置，两者可能不同 |

### 入门级例题

**题目**：判断乳酸（CH₃CH(OH)COOH）中手性碳的R/S构型。

**解答**：手性碳连接四个基团：-OH（O，原子序数8）、-COOH（C连接O,O,O）、-CH₃（C连接H,H,H）、-H（H）。按CIP规则排序：-OH（1）> -COOH（2）> -CH₃（3）> -H（4）。将H置于远离位置，从1→2→3画弧线：逆时针→S构型。

### 与现实世界的联系

- **药物手性**：许多药物的R和S异构体活性不同（如沙利度胺），CIP规则是命名手性药物的基础
- **不对称合成**：手性催化剂的设计需要明确目标产物的R/S构型
- **天然产物结构鉴定**：天然产物的绝对构型确定依赖CIP规则和旋光测定

> **记忆锚**：排序三问——原子序数？同位素？下一层？多重键展开成"多个假原子"；判向一眼——4 放后、1→2→3，顺 R 逆 S；横 H 反读防翻车。

## 竞赛考察要点

1. **排序题**：含 S/O/卤素混合基团排序（考序数非电负性）。
2. **R/S 判定**：楔形/费歇尔/纽曼三种画法下快速判向。
3. **Z/E 判定**：交叉基团烯烃（cis/trans 失效场景）。
4. **含 P/S 手性**：亚砜、手性膦的 R/S（孤对最低）。
5. **轴手性/阻转异构**：联苯邻位大基团与丙二烯。
6. **合成与命名联动**：产物构型保持/翻转的 R/S 变化判断（SN2 翻转 → R/S 反转的识别）。

## 关键结论速记

- 优先级 = 原子序数（非电负性）→ 同位素 → 第二层逐位 → 多重键展开（=O 当两个 O）。
- R/S：4 朝后，1→2→3 顺时针 R；投影横 H 反着读。
- Z/E：每端各排序，两端 1 号同侧 Z、异侧 E；≠ cis/trans 的绝对化。
- 手性中心标 R/S 前先确认手性（内消旋识别）。
- 收尾自检：能给含 S 基团排序、判乳酸 R/S、判 1-氯-1-溴-2-碘-2-氟乙烯 Z/E——本页达标。
- 常用排序速查：-I > -Br > -Cl > -SO₃H > -SH > -OH > -NH₂ > -COOH > -CHO > -CH₂OH > -C≡CH > -CH=CH₂ > -CH₃ > -H——把这条链背下来能秒解 90% 排序题。
- SN2 翻转联动：R 构型底物 SN2 后必为 S（Walden 翻转）——机理题靠"R/S 反转"验证 SN2 路径，与立体电子/构象分析联动读。

## Z/E 判定补充示例（cis/trans 失效场景）

**例**：1-氯-1-溴-2-碘-2-氟乙烯（ClBrC=CIF）。cis/trans 无法表达（两端基团无对应关系），必须 Z/E：
- 左端 C1：Br(35) > Cl(17) → Br 是 1 号
- 右端 C2：I(53) > F(9) → I 是 1 号
- Br 与 I 同侧 → **Z 型**；异侧 → E 型

**区分口诀**："cis/trans 管'一样大的基团'，Z/E 管'每端最大的基团'"——两套语言在基团全不同时给出相同答案，遇到 1,2-二取代但两端基团不对称（如 ClCH=CHBr）就只用 Z/E。

**含氮/磷配位视角**：手性膦（P 连三个不同基团 + 孤对）与亚砜（S=O + 两个不同基团 + 孤对）的 R/S 判定中，孤对一律按"第 4 号最低优先级"处理——排序其余三基团后正常判向。
