# 红外光谱

## 一、定义

红外光谱（IR）是分子吸收红外区电磁辐射后，由**化学键的振动**（伸缩与弯曲）能级跃迁产生的吸收光谱。它回答的核心问题是"**这个分子里有什么官能团**"：不同化学键（O–H、C=O、C=C、C≡C、C–H 等）各有特征吸收频率（以波数 cm⁻¹ 表示），如同分子的"功能团指纹"。通常把 **4000–1500 cm⁻¹ 称为官能团区**（用于识别官能团），**1500–400 cm⁻¹ 称为指纹区**（对分子整体结构极其敏感，用于与标准谱比对确认结构）。IR 是波谱分析三件套（MS 定分子量、IR 定官能团、NMR 定连接方式）中"最快、最便宜、最灵敏"的一环，常作为 NMR 之前的第一道筛选。

## 二、考纲对应

本页属波谱分析基础，对应"红外光谱判断官能团"：能由特征波数识别 O–H/N–H/C=O/C≡C/苯环等官能团；掌握 C–H 伸缩振动的 **3000 cm⁻¹ 分界线**（sp³ < 3000、sp²/sp > 3000）判断杂化方式；会用 Hooke 定律的约化质量思想比较不同键（C–H vs C–D、C–C vs C≡C）的波数高低；并知道 IR 与 NMR 在结构解析中的互补分工。初赛决赛均有直接波数排序与官能团判断题。

## 三、核心原理

### 3.1 振动模型：Hooke 定律与约化质量

化学键近似为弹簧连接两原子，振动频率由键的"刚性"（力常数 k）与约化质量 μ 决定：

- 波数大致正比于 √(k/μ)：**键越强，波数越高**（C≡C 约 2150 > C=C 约 1650 > C–C 约 1200 区域）。
- **约化质量 μ = m₁m₂/(m₁+m₂) 越大，波数越低**：C–H 约 3000，C–D 降到约 2200（D 比 H 重一倍，波数约下降 √2 倍）——这是氘代位移的根源，也是"比较 C–H 与 C–D 波数"题的答案依据。
- 同族比较：C–H 比 C–C 高（μ 小得多）；O–H 与 N–H 伸缩都在 3200–3600 高区（μ 小 + 键较强）。

### 3.2 振动方式：伸缩 vs 弯曲

- **伸缩振动（stretching）**：键长周期性变化，频率高（一般 1500 cm⁻¹ 以上），是官能团识别的主力峰。
- **弯曲振动（bending）**：键角周期性变化，频率低（多在 1500 cm⁻¹ 以下指纹区），如 CH₂ 的剪式（约 1465）、面外弯曲等。
- 同一键的伸缩频率**总高于**弯曲频率（伸缩需克服的恢复力更大）；题目说"某键弯曲振动出现在更高波数"即错。

### 3.3 3000 cm⁻¹ 分界线：C–H 杂化的快速判据

- sp³ 碳的 C–H：约 **2850–2960 cm⁻¹（< 3000）**——饱和烷烃。
- sp² 碳的 C–H（烯/芳）：约 **3000–3100 cm⁻¹（> 3000）**，芳环 C–H 常在 3030 附近并有 1600/1500 骨架峰与 690–900 面外弯曲区。
- sp 碳的 C–H（末端炔）：约 **3300 cm⁻¹**（尖峰）。
- 实战口诀：**"有没有 >3000 的峰"决定分子是否含不饱和碳上的氢**；醛基的 C–H 特殊地出现在 ~2720/2820（费米共振双峰），是醛的特征。

### 3.4 官能团区关键峰速记

| 官能团 | 波数（cm⁻¹） | 峰形特征 |
|---|---|---|
| O–H（醇/酚，缔合） | 3200–3550 | **宽而强**（氢键），"又胖又壮" |
| O–H（游离，稀溶液） | 约 3600 | 尖峰 |
| N–H | 3300–3500 | 伯胺**双峰**、仲胺单峰 |
| ≡C–H | 约 3300 | 尖峰（末端炔） |
| C–H（sp²/sp³/sp） | 见 3.3 | 3000 分界 |
| C≡N（腈） | 约 2250 | 中强尖峰 |
| C≡C | 约 2150 | 弱（对称炔常无） |
| C=O | 1680–1750 | **强峰**（酮 1715、醛 1725、酯 1735、羧酸 1710 且伴宽 OH） |
| C=C | 1620–1680 | 中弱；芳环 1600/1500 双峰 |
| C–O | 1000–1300 | 强（酯/醚/醇区分靠此区+羰基位置） |

### 3.5 影响波数的因素：共轭与环张力

- **共轭使 C=O/C=C 波数降低**（π 离域削弱双键）：如 α,β-不饱和酮 C=O 约 1685、酰胺 C=O 约 1650（N 的孤对离域强）。
- **环张力升高波数**：环酮 C=O 随环变小升高（环己酮 1715 → 环丙酮 1815 附近）。
- 诱导效应拔电子使 C=O 略升（酰氯 ~1800）。波数判断题的"排序"逻辑基本就是这三条（键强/共轭/张力）加约化质量。

## 四、关键结论

- IR 回答"**有什么官能团**"，不能独立确定完整结构——完整结构靠 MS（分子式）+ IR（官能团）+ NMR（连接方式）+ 不饱和度协同。
- 官能团区（>1500）定官能团，指纹区（<1500）比对整体结构。
- 3000 cm⁻¹ 是 C–H 杂化的分水岭：sp³ < 3000 ≤ sp²，sp 约 3300。
- 强峰优先：C=O（约 1700 强）、O–H（>3000 宽）、C≡N（2250 尖）三峰几乎可"秒判"醛酮/醇/腈。
- 波数高低三因素：键强（k↑ 波数↑）、约化质量（μ↑ 波数↓）、共轭/张力（离域↓波数、张力↑波数）。

## 五、常见分类或情形

- **按振动**：伸缩（高波数）与弯曲（低波数）；对称/不对称伸缩（如 CH₂、CO₂）。
- **按官能团区**：X–H 区（>2500：O–H、N–H、C–H）、叁键区（2000–2500：C≡C、C≡N）、双键区（1500–1900：C=O、C=C、芳环）、指纹区（<1500）。
- **按应用**：纯化合物官能团鉴定、反应监控（羰基峰出现/消失）、聚合物与药物鉴别（与标准谱比对）、环境气体检测（CO₂、CH₄ 特征吸收）。

## 六、适用条件与限制

- **只能定性判断官能团类型**，难以精确定量与完整定结构；对称分子中无偶极矩变化的振动红外不吸收（如 N≡N、对称取代炔 C≡C 弱/无）。
- **水与玻璃干扰**：水在 3300/1640 强吸收，样品须除水；盐窗（NaCl）怕水。
- **氢键浓度依赖**：OH/NH 峰位置随浓度变（缔合移低变宽），读图须注明状态。
- 同分异构体、相似官能团（酮 vs 酯）需结合峰位置细微差（1715 vs 1735）与 C–O 区，必要时上 NMR 终判。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 伸缩 vs 弯曲谁频率高 | 伸缩总是高于同键弯曲；弯曲多在指纹区 |
| C–H 波数 <3000 还是 >3000 | sp³ < 3000（烷烃 2850–2960）；sp²/sp > 3000（烯/芳 3000–3100、炔约 3300）——3000 是分界 |
| C–H vs C–D 谁高 | C–H 高：D 质量约 2 倍 → 波数约 ×(1/√2) ≈ 0.7，3000 → 约 2200（约化质量题标准答案） |
| 酮 vs 醛的 C=O | 酮 1715、醛 1725（醛另有 2720/2820 双峰）；酯 1735、羧酸 1710+宽 OH、酰胺约 1650（共轭+诱导综合） |
| 共轭使 C=O 升高还是降低 | **降低**（π 离域削弱 C=O）；环张力升高；诱导吸电子升高——排序题先分清作用方向 |

## 八、与其他知识点的联系

- [[¹H NMR]] / [[有机波谱分析]]：波谱联用——IR 定官能团后，NMR 定氢环境与连接，MS 定分子式。
- [[质谱分析]]：分子量/分子式的互补手段（IR 不提供）。
- [[红外活性]] 相关概念：振动需伴随偶极矩变化才有 IR 吸收（对称非极性振动 IR 禁阻）。
- 官能团化学（醇/酚/醛酮/羧酸/腈/炔）：特征峰对应各章官能团性质，反向"看图识官能团"。

## 九、典型题型

- **波数排序**：比较 C–H/C–D、C–C/C=C/C≡C、不同杂化 C–H 的波数（Hooke + 约化质量 + 键级）。
- **官能团判断**：给谱图关键峰（1700 强/3300 宽/2250 尖/2720 双峰）判醛酮醇腈。
- **3000 分界应用**：由 C–H 吸收是否 >3000 判断分子含烯/芳（不饱和）还是纯饱和。
- **联合解析**：MS 给分子式 → 不饱和度 → IR 给官能团 → NMR 给连接，推导结构（如 Zchem 溴苯乙烷案例）。
- **共轭/张力影响**：比较酮、烯酮、环酮的 C=O 波数并解释。

## 十、例题

**例题 1**：某化合物分子式 C₃H₆O，IR 在 1720 cm⁻¹ 有强峰、2700–2800 cm⁻¹ 有两个弱峰。推断结构。

**解答**：1720 强峰 → C=O；2700–2800 双峰是醛基 C–H 的费米共振特征（醛专属）。C₃H₆O 不饱和度 = (2×3+2−6)/2 = 1，恰为羰基。若为酮则无 2700 双峰且 C=O 约 1715；此处双峰锁定醛 → 丙醛 CH₃CH₂CHO。

**例题 2**：比较下列 C–H 伸缩波数高低并解释：(a) 乙烷 C–H；(b) 乙烯 C–H；(c) 乙炔 C–H；(d) 乙烷的 C–D（全氘）。

**解答**：波数高低 (c) 约 3300 > (b) 约 3050 > (a) 约 2950 > (d) 约 2200。理由：s 成分越多、C–H 键越强则波数越高（sp > sp² > sp³）；C–D 中 D 质量约为 H 两倍，约化质量增大使波数约降为 C–H 的 1/√2 ≈ 0.71 倍（2950×0.71 ≈ 2100–2200）——键强与约化质量共同决定波数。

**例题 3**：某未知物 IR 显示 3300 cm⁻¹ 宽强峰、1710 cm⁻¹ 强峰、指纹区 1200 附近强峰。最可能是哪类化合物？

**解答**：3300 宽强 = 缔合 O–H（羧酸或醇）；1710 C=O 偏低更像羧酸（醇无 C=O）；羧酸还有 C–O 约 1200 强峰与 2500–3300 的超宽 OH。若 1710 移到 1735 且无宽 OH 则是酯。综合判为羧酸；可用"羧酸 OH 特宽（可延至 2500）"与"酯无 OH"鉴别。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为红外可以确定完整结构 | IR 只答"有什么官能团"，同分异构/连接方式靠 NMR/MS | 反例：C₃H₆O 的丙酮与丙醛 IR 都有 C=O，靠 2720 醛双峰区分后仍须 NMR 佐证——完整结构是波谱联用结果 |
| 混淆伸缩与弯曲频率 | 同键弯曲频率低于伸缩（1500 以下 vs 1500 以上） | 判别：CH₂ 剪式 1465 属弯曲；C=O 1700 属伸缩；题目给"弯曲振动在高波数"即反 |
| 3000 cm⁻¹ 分界记反 | sp³ C–H 在 2850–2960（**低于**3000）；高于 3000 的 C–H 才对应 sp²/sp 不饱和碳 | 反例：环己烷只在 2900 附近有峰（无 >3000），而苯环在 3030 有峰——"有没有 >3000 的 C–H"判不饱和 |
| 氢键方向记反 | 氢键使 O–H/N–H 峰**移低变宽**（缔合 3200–3550 宽），不是升高 | 反例：游离 OH 3600 尖峰 vs 浓溶液/固态 3300 宽峰；出现 3300"又胖又壮"先想羟基或羧酸 |
| 共轭对 C=O 的影响方向写反 | 共轭（如 α,β-不饱和酮、酰胺）使 C=O **降低**（约 1685/1650）；升高的是环张力与吸电子诱导 | 判别：酰胺 C=O 1650 < 酮 1715 < 酯 1735 < 酰氯 1800——按离域/诱导排序列出再答题 |
| 忽视 IR 的选择定则 | 振动须伴随偶极矩变化才吸收；对称非极性振动（N≡N、对称 C≡C）IR 弱或无 | 反例：N₂ 无 IR 吸收、对称二取代炔 C≡C 常不见峰——"有该键就必有该峰"不成立 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
红外光谱应在掌握分子振动基本概念（伸缩/弯曲、Hooke 定律约化质量）与官能团知识之后学习。建议先记熟"三大峰"（O–H 宽 >3000、C=O 约 1700 强、C≡N 2250 尖）与 3000 分界线，再逐个学 X–H/叁键/双键区，最后用"MS→IR→NMR"联合解析例题（如溴苯乙烷）建立实战流程。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 认为红外光谱可以确定完整结构 | 红外主要鉴定官能团类型，完整结构需结合 NMR、MS 等其他谱学手段 |
| 混淆伸缩振动和弯曲振动的频率 | 伸缩振动频率通常高于弯曲振动，且与键强度和原子质量相关（Hooke 定律） |
| 忽略氢键对 O–H 峰的影响 | 游离 O–H 在 3600 cm⁻¹ 附近尖锐峰，氢键使峰移至 3200–3500 cm⁻¹ 且变宽 |
| 认为 IR 昂贵费时 | IR 灵敏、快捷、便宜——这正是"做 NMR 前先跑 IR"的理由 |

### 12.3 入门级例题
**题目**：一化合物 IR 只在 2900 cm⁻¹ 有吸收（无 >3000 峰、无 1700 峰）。说明它含有什么类型的氢？可能是什么类化合物？

**解答**：只有 <3000 的 C–H 伸缩峰 → 全部氢都在 sp³ 碳上（无烯/芳 C–H）；无 C=O 峰 → 非醛酮酸酯酰胺。结合分子式可判为饱和烃/醇/醚等无羰基饱和化合物（若含 OH 应在 3300 附近另有宽峰）。

### 12.4 与现实世界的联系
- **药物质量控制**：红外是药典规定鉴别方法之一，与标准谱比对确认药物身份。
- **环境监测**：便携式红外光谱仪现场检测 CO₂、CH₄ 等温室气体。
- **食品分析**：红外快速检测脂肪/蛋白/水分含量，无需化学前处理。
