# 官能团

## 一、定位

官能团是有机化学里最重要的"识别标签"：它决定分子的主要反应类型、典型鉴别方法和常见转化路径。有机题的破题顺序几乎都是——**先认官能团，再定反应类型，最后写产物**。

本页是总览地图：不展开任何具体反应机理（那是各反应 KP 的任务），只解决三件事——**认结构、记典型性质、挂钩反应类型**。

## 二、官能团地图

### 含氧官能团

| 官能团 | 结构 | 典型反应类型 | 特征鉴别 |
|:---|:---|:---|:---|
| 羟基（醇） | R-OH | 取代、消除（脱水）、氧化、酯化 | Lucas 试剂（浑浊速度分伯仲叔） |
| 酚 | Ar-OH | 芳环亲电取代（活化）、酸性、成醚 | FeCl₃ 显紫色；使溴水褪色（白色沉淀） |
| 醚 | R-O-R′ | 相对稳定，强酸下断裂 | —（常作溶剂识别项） |
| 醛基 | R-CHO | 亲核加成、氧化、Aldol 缩合 | Tollens 银镜、Fehling 砖红色沉淀 |
| 酮羰基 | R-CO-R′ | 亲核加成、α-H 反应、还原 | 不与 Tollens 反应（与醛区分）；碘仿反应（甲基酮） |
| 羧基 | R-COOH | 酸性、酯化、脱羧 | NaHCO₃ 放出 CO₂ |
| 酯基 | R-COO-R′ | 水解（皂化）、醇解、氨解、Claisen 缩合 | — |
| 酰卤/酸酐/酰胺 | R-CO-X / (RCO)₂O / R-CONR₂ | 羰基亲核取代（活性依次递减） | 酰卤遇水剧烈水解 |

### 含氮与其他官能团

| 官能团 | 结构 | 典型反应类型 | 备注 |
|:---|:---|:---|:---|
| 氨基 | R-NH₂ | 碱性、烷基化/酰基化、重氮化（芳伯胺） | 芳胺重氮盐是 Sandmeyer 等转化的枢纽 |
| 硝基 | R-NO₂ | 还原为氨基（芳硝基最重要） | 强吸电子、间位定位 |
| 腈基 | R-C≡N | 水解为羧酸、还原为胺 | 相当于"羧酸前体" |
| 卤素 | R-X | 亲核取代、消除、生成格氏试剂 | 乙烯式/芳卤不活泼 |
| 碳碳双键 | C=C | 亲电加成、氧化（臭氧化/KMnO₄）、聚合 | 使溴水、KMnO₄ 褪色 |
| 碳碳三键 | C≡C | 亲电加成、端炔酸性（生成炔钠/炔银） | 端炔与银氨溶液生成白色沉淀 |

## 三、三个核心规则

1. **官能团决定反应类型**：看到羰基想亲核加成与 α-H 反应，看到羟基想取代/消除/氧化，看到双键想亲电加成。合成题逆推时优先围绕官能团转化做断点。
2. **多官能团有优先级**：命名与编号时按 羧酸 > 磺酸 > 酯 > 酰卤 > 酰胺 > 腈 > 醛 > 酮 > 醇/酚 > 胺 的顺序确定主官能团，其余作取代基。
3. **相似官能团靠鉴别反应区分**：醛 vs 酮（Tollens）、醇 vs 酚（FeCl₃、溴水）、伯仲叔醇（Lucas）、端炔 vs 内炔（银氨沉淀）——鉴别题本质是官能团化学性质的差异。

## 四、学习路径：把官能团挂进反应地图

附录B 的 16 区自查清单给出了一条自然的进阶顺序，每个区都对应若干官能团的反应：

```
电子效应（理论基础）
  → 羰基亲核加成 / 亲核取代（醛酮羧酸衍生物——主干道）
    → 饱和碳亲核取代与消除（卤代烃、醇）
      → 亲电加成与烯醇化（烯炔、羰基 α 位）
        → 芳香亲电取代（芳环官能团的电子效应应用）
          → 缩合反应（羰基化合物的多步串联）
            → 杂原子 / 杂环 / 周环 / 重排（决赛区分层）
```

按此顺序逐区自检：不熟悉的反应名称 → 回到对应 KP 补。官能团识别能力应在学习任何具体反应之前建立，建议按 含氧 → 含氮 → 含卤 的顺序系统过一遍。

## 官能团转化总表（合成路线主干）

**氧化还原梯（含氧主链）**：

| 转化 | 试剂/条件 | 备注 |
|---|---|---|
| 伯醇 → 醛 | PCC / 温和氧化 | 强氧化剂直接到酸 |
| 醛 → 羧酸 | Tollens/Fehling/酸性 KMnO₄ | 鉴别+氧化同步 |
| 伯醇 → 羧酸 | 酸性 KMnO₄/K₂Cr₂O₇ | 两步过醛中间体 |
| 酮 → 醇 | NaBH₄/LiAlH₄ 还原 | 仲醇 |
| 羧酸 → 酯 | 醇+酸催化酯化 | 可逆，除水推动 |
| 酯 → 醇 | LiAlH₄（到伯醇） | 不同于水解 |
| 酰胺 → 胺 | LiAlH₄ 还原 | 比水解更常用（制胺） |
| 腈 → 胺 | LiAlH₄ / H₂ 催化 | 扩链法 |

**碳链变换**：
- **延长 1C**：醛/酮 + HCN → 氰醇 → 水解（α-羟基酸）/还原（β-羟基胺）
- **延长 2C**：格氏试剂 + CO₂ → 羧酸（+1C）；与环氧乙烷 → 伯醇（+2C）
- **延长 nC**：卤代烃 + NaCN → 腈（+1C 后水解成酸）；Wittig/HWE 烯化（定点 C=C）
- **缩短 1C**：羧酸 → 脱羧（Hunsdiecker/Kolbe）；酰胺 → Hofmann 降级（少 1C 胺）

**还原方向口诀**："醛酮酸酯一条线，LiAlH₄ 通杀到醇；酰胺腈硝基到胺，NaBH₄ 只管醛酮。"

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 把官能团只当"命名标签" | 官能团决定反应类型、活性和合成策略，是有机分析的核心工具 | 银镜反应不是"分子有醛基"的充分条件？——是；但甲酸酯也银镜（伪醛基陷阱） |
| 混淆醛和酮的性质 | 都含羰基，但醛可被弱氧化剂（Tollens、Fehling）氧化，酮不能 | 果糖（酮糖）能银镜——碱性下烯醇化异构为醛，别当反例惊讶 |
| 忽略官能团优先级 | 多官能团分子命名和反应预测需按优先级排序（羧酸 > 酯 > 醛 > 酮 > 醇 > 胺） | 羟基+羧基：COOH 作主官能团，OH 作取代基（羟基酸命名） |
| 认为同一官能团在任何环境活性相同 | 电子效应调制活性：对硝基苯酚酸性远强于苯酚，酯羰基比酮羰基更难亲核加成 | 共轭/诱导使活性跨数量级——"看官能团还要看环境" |
| 混淆醇/酚/酸的酸性层次 | 酸性：羧酸 > 酚 > 醇（pKa 约 5/10/16） | NaHCO₃ 只溶羧酸；NaOH 溶羧酸+酚；Na 全反应（醇最慢） |
| 漏判"隐藏官能团" | 有些分子官能团需先转化才显反应性（缩醛=保护醛、烯醇醚、氰醇） | 缩醛在酸性水溶液水解回醛后才银镜——保护基陷阱 |

## 🎯 教学视角

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为官能团只是"命名标签" | 官能团决定了分子的反应类型、反应活性和合成策略，是有机化学的核心分析工具 |
| 混淆相似官能团的性质 | 醛和酮虽都含羰基，但醛可被弱氧化剂氧化（如 Tollens 试剂），酮不能；这是区分两者的关键 |
| 忽略官能团的优先级 | 多官能团分子命名和反应预测时，需要按优先级排序（羧酸>酯>醛>酮>醇>胺） |

### 入门级例题

**题目**：某化合物分子式为 C₄H₈O，能发生银镜反应但不能使溴水褪色。推断其结构。

**解答**：能发生银镜反应 → 含醛基（-CHO）。不能使溴水褪色 → 无碳碳双键。分子式 C₄H₈O，不饱和度 = 1（醛基提供）。结构为丁醛（CH₃CH₂CH₂CHO）或 2-甲基丙醛（(CH₃)₂CHCHO）。

### 与现实世界的联系

- **药物化学**：药物分子的药效团（pharmacophore）本质就是特定官能团的空间排列，如 β-内酰胺抗生素的 β-内酰胺环
- **高分子材料**：单体的官能团决定了聚合方式（缩聚 vs 加聚），如尼龙由胺基和羧基缩聚而成
- **生物化学**：氨基酸的氨基和羧基、糖的羟基和醛/酮基、核酸的磷酸基和碱基——生命分子的化学本质就是官能团的组合

## 官能团的红外指纹（谱学识别补充）

| 官能团 | 特征吸收峰（cm⁻¹） | 备注 |
|---|---|---|
| 羟基 O-H（醇/酚） | 3200~3600 宽强 | 氢键缔合变宽；游离出现 3600 尖峰 |
| 羧酸 O-H | 2500~3300 极宽 | 与 C=O ~1710 同现，双证 |
| 胺 N-H | 3300~3500（伯胺双峰） | 与 OH 区分：胺无氢键宽化 |
| 醛 C-H | ~2720 特征双峰 | 醛的"身份证" |
| 羰基 C=O | 1650~1750 | 频率排序：酰卤 > 酸 > 酯 > 醛 > 酮 > 酰胺（共轭下降） |
| 烯 C=C | 1620~1680（弱） | 对称烯偶极小常难见 |
| 炔 C≡C | 2100~2260 | 端炔 ~3300 C-H 另证 |
| 硝基 N=O | 1520/1350 双峰 | 强吸电特征 |
| 醚 C-O | 1050~1150 | 酯的 C-O 在 1230 附近可辨 |

**记忆锚**："OH 三千宽、C=O 十七、醛氢二七二、端炔三三"——四个锚点秒判含氧官能团类型。

## 竞赛考察要点

1. **破题顺序**：认官能团 → 定反应类型 → 写产物（本页地图即为此服务）。
2. **性质差异鉴别**：醛 vs 酮、醇 vs 酚 vs 酸、伯仲叔醇、端炔 vs 内炔——记忆每种"鉴别试剂+现象"。
3. **官能团优先级命名**：多官能团主次排序（羧酸 > 醛 > 酮 > 醇 > 胺 常用段）。
4. **转化总表应用**：逆合成时沿"氧化还原梯/碳链变换"切断（本页转化总表）。
5. **谱学联合**：IR 指纹 + NMR 化学位移反推官能团组合。
6. **多官能团交互**：一个分子多个官能团的反应选择性（先反应哪个——醛先于酮、酚羟基活化芳环）。

## 关键结论速记

- 破题三拍：认官能团 → 定反应类型 → 写产物；多官能团按优先级排主次。
- 三核心规则：官能团决定反应 / 优先级定命名 / 鉴别反应分相似团。
- 鉴别五对：醛(Tollens/Fehling 银镜砖红)、酚(FeCl₃ 紫)、伯仲叔醇(Lucas 浑浊)、端炔(银氨白沉)、烯(KMnO₄ 褪色)。
- 酸性谱：羧酸(~5) > 酚(~10) > 醇(~16)——NaHCO₃/NaOH/Na 三档筛。
- 转化主干：氧化还原梯（醇↔醛↔酸、酯/酰胺/腈→醇或胺）+ 碳链变换（CN 扩 1C、格氏+CO₂ 羧化、Hofmann 降 1C）。
- IR 锚：OH 3300 宽、C=O 1700 区、醛 H 2720、端炔 3300+2100。
- 收尾自检：给陌生分子能排主次官能团、能选鉴别试剂、能规划一条转化路线——本页达标。
