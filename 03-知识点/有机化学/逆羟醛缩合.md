## 一、定义

**逆羟醛缩合（retro-Aldol）** 是 [[Aldol缩合]] 的逆反应：β-羟基醛/酮在碱或酸催化下，**在 α-碳与 β-碳之间断裂**，生成两个较小的羰基化合物。

$$\mathrm{RCH_2{-}CH(OH){-}CH(R'){-}CHO \longrightarrow RCH_2{-}CHO + R'CH_2{-}CHO}$$

通式上看，它把一根 **C–C 键**换成两根 **C=O 键**——断裂处在 β-羟基的邻位。

## 二、机理

两条路径的关键差别在于**先活化哪一端**。

### 2.1 碱催化

1. $\mathrm{OH^-}$ 夺取羟基的质子 → 烷氧负离子
2. 烷氧负离子的电子对回落成 $\mathrm{C{=}O}$，**同时** C–C 键断裂，推出一个**烯醇负离子**
3. 烯醇负离子从溶剂夺质子 → 第二个羰基化合物

$$\mathrm{RCH_2{-}CH(O^-){-}CH(R'){-}CHO \longrightarrow RCH_2{-}CHO + ^-CH(R'){-}CHO}$$

> 碱催化的推动力：产物之一是稳定的**烯醇负离子**（离去基团以烯醇盐形式离去）。

### 2.2 酸催化

1. 羟基**质子化** → 变成好的离去基团 $\mathrm{H_2O}$
2. 脱水生成 α,β-不饱和羰基（共轭体系）
3. 水对共轭体系**逆 Michael 加成**，C–C 键断裂

$$\mathrm{RCH_2{-}CH(OH){-}CH(R'){-}CHO \xrightarrow{H^+} RCH_2{-}CH{=}C(R'){-}CHO \xrightarrow{H_2O} RCH_2{-}CHO + R'CH_2{-}CHO}$$

> 酸催化的推动力：先脱水形成**共轭的 α,β-不饱和羰基**，再由水逆加成分解。

### 2.3 与正向反应的关系

正向 Aldol 与逆向 retro-Aldol 共存于同一平衡，**方向由条件决定**：

| 条件 | 主导方向 |
|:---|:---|
| 低温、浓碱、醛为底物 | **正向**（Aldol 加成/缩合） |
| 高温、稀碱、体系有水 | **逆向**（retro-Aldol） |
| 产物能脱水成共轭体系 | 正向被"锁死"（脱水不可逆地拉走平衡） |
| 产物能作为气体/沉淀移出 | 依具体体系而定 |

判据：**凡是能把平衡产物"拿走"的因素（脱水成共轭、沉淀、挥发），就把反应锁在那个方向。**

## 三、合成意义：切断策略

逆羟醛缩合在合成上的价值**不在于做反应，而在于做分析**——它是逆合成分析的经典**切断（disconnection）**手段：

- 看到目标分子中有 **β-羟基羰基** 或 **α,β-不饱和羰基** 片段
- → 在该片段的 **α–β 键**处画切断线
- → 拆成一个**烯醇负离子等价体**（提供 α-碳）与一个**羰基亲电体**（提供羰基碳）
- → 正向写回去就是一步 Aldol

**示例**：用逆羟醛缩合分析 2-甲基-3-羟基丁醛的合成前体

1. 认出它是 Aldol 加成产物（β-羟基醛）
2. 在 β-羟基与 α-碳之间切断
3. 得 **丙醛**（亲核体，提供 α-碳）+ **乙醛**（亲电体，提供羰基碳）
4. 正向合成：丙醛在碱催化下与乙醛发生 Aldol 加成

切断的通用规则见 [[反应机理]] 与 [[缩合反应]]。

## 四、现实中的逆羟醛缩合

- **生物化学（最经典的实例）**：糖酵解中的**醛缩酶（aldolase）**催化果糖-1,6-二磷酸发生逆羟醛缩合，裂解为两个三碳糖（磷酸二羟丙酮 + 甘油醛-3-磷酸）。这是逆羟醛缩合在自然界中最重要的场合。
- **天然产物全合成**：大环内酯类抗生素（如红霉素）等复杂分子的合成路线设计中，逆羟醛缩合是构建碳骨架的关键切断策略。
- **工业化学**：用于回收缩合反应的副产物，提高原子经济性。

## 五、教学视角

### 学习路径建议

逆羟醛缩合应在**掌握 Aldol 缩合正向反应之后**学习。建议顺序：

1. 先理解 Aldol 缩合的正向反应（醛/酮的 α-碳对另一羰基加成）—— 见 [[Aldol缩合]]
2. 再学其逆过程（β-羟基醛/酮断裂为两个羰基化合物）
3. 最后掌握在合成中的应用（切断策略）

### 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 认为逆羟醛缩合只是"反向 Aldol" | 它在合成中是**独立的切断策略**，用于从复杂分子倒推简单原料 |
| 混淆碱催化和酸催化的机理 | 碱催化：先去质子化生成烯醇负离子，再断裂 C–C 键；酸催化：先质子化羟基脱水，再断裂 |
| 认为逆反应无实际用途 | 醛缩酶催化的糖酵解裂解就是逆羟醛缩合，是生命代谢的核心步骤之一 |
| 忽略与正向反应的平衡关系 | 两者共存于同一平衡，**产物能否被"拿走"（脱水/沉淀/挥发）决定方向** |
