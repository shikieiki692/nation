# 醇 (Alcohols)

## 一、定义

**醇**是羟基（—OH）连在饱和碳原子上的有机化合物，通式为 **R—OH**。醇是含氧官能团中最基础的类型，也是有机合成中重要的原料和中间体。

- 羟基连在 **sp³ 杂化** 的碳原子上（区别于酚，酚的 —OH 连在芳环上）
- 醇羟基具有 **弱酸性**（pKa ≈ 15~18）和 **氢键供体/受体** 双重性质

## 二、分类

### 2.1 按碳骨架分类
| 类型 | 特征 | 实例 |
|:---|:---|:---|
| **伯醇 (1°)** | RCH₂OH | 乙醇、正丙醇 |
| **仲醇 (2°)** | R₂CHOH | 异丙醇、环己醇 |
| **叔醇 (3°)** | R₃COH | 叔丁醇 |

### 2.2 按羟基数目
| 类型 | 特征 | 实例 |
|:---|:---|:---|
| **一元醇** | 一个 —OH | 甲醇、乙醇 |
| **二元醇/二醇** | 两个 —OH | 乙二醇、丙二醇 |
| **多元醇** | 多个 —OH | 甘油、山梨醇 |

## 四、醇的反应

> 醇是有机合成中最核心的官能团之一，其制备、转化（卤代、氧化、消除）构成了合成化学的基础工具箱。

### 4.1 醇的制备

#### 格氏试剂法

$$\ce{RMgX + R'CHO -> R-CH(R')-OMgX ->[H3O+] R-CH(R')-OH}$$

- 格氏试剂与醛反应得 2°醇，与酮反应得 3°醇
- 与甲醛反应得 1°醇（多一个碳）
- 与酯反应得 3°醇（两分子格氏试剂加成）
- **限制**：格氏试剂对水、CO₂、活泼氢敏感

#### 硼氢化-氧化反应

$$\ce{R-CH=CH2 + BH3 -> (R-CH2-CH2)3B ->[H2O2/OH-] R-CH2-CH2-OH}$$

- **反马氏规则**：羟基加在取代较少的碳上
- **顺式加成**：H 和 OH 从同侧加成
- **立体选择性**：硼从位阻较小面进攻

#### 其他制备方法

| 方法 | 试剂/条件 | 产物 | 特点 |
|:---|:---|:---|:---|
| **烯烃水合** | H₂O/H⁺ 或 Hg(OAc)₂/NaBH₄ | 醇 | 马氏规则 |
| **卤代烷水解** | NaOH/H₂O | 醇 | SN2（1°）或 SN1（3°）|
| **醛/酮还原** | NaBH₄ 或 LiAlH₄ | 1°/2°醇 | 选择性还原 |
| **环氧开环** | 酸或碱催化 | 邻二醇 | 酸/碱催化位向不同 |
| **羟汞化-去汞** | Hg(OAc)₂/H₂O → NaBH₄ | 醇 | 马氏规则，不重排 |

### 4.2 醇的取代反应

#### 醇 → 卤代烷（四种经典方法）

| 试剂 | 条件 | 立体化学 | 适用范围 | 特点 |
|:---|:---|:---:|:---|:---|
| **SOCl₂** | 碱（吡啶/Et₃N）| **inversion** | 1°/2°醇 | 副产物 SO₂ + HCl（气体，易除）|
| **PBr₃** | 中性 | **inversion** | 1°/2°醇 | 副产物 H₃PO₃ |
| **Appel（CBr₄/PPh₃）** | 中性 | **inversion** | 1°/2°醇 | 温和，官能团耐受性好 |
| **DAST** | 低温 | 有时 **retention** | 1°/2°/3°醇 | 氟代首选，也可氯代 |

**机理**：SOCl₂/碱 → 氯亚硫酸酯 → SN2 → inversion；PBr₃ → 亚磷酸酯 → SN2 → inversion；DAST → 特殊机理（有时 retention）

#### Mitsunobu 反应

$$\ce{ROH + R'COOH + DIAD + PPh3 -> R'COOR（构型翻转）+ Ph3P=O + DIAD-H2}$$

- 醇的 **inversion**，形成酯
- 本质：PPh₃ 活化醇 → 氧鎓中间体 → 羧酸根背面进攻
- P=O 键的形成是反应驱动力

### 4.3 醇的消除反应

#### 酸催化脱水（E1 机理）

$$\ce{R3C-OH + H+ -> R3C-OH2+ -> R3C+ -> 烯烃 + H+}$$

- 3°醇 > 2°醇 > 1°醇（碳正离子稳定性）
- 遵循 **Zaitsev 规则**：多取代烯烃为主
- 可能伴随重排（碳正离子中间体）

#### E2 消除

$$\ce{R-CH2-CH2-OH + POCl3 ->[吡啶] R-CH=CH2}$$

- **反式共平面（anti-periplanar）**要求
- 用 Newman 投影式分析构象
- 环己烷衍生物需画椅式构象判断可行性

#### E1 vs E2 vs E1cb 对比

| | **E1** | **E2** | **E1cb** |
|:---|:---|:---|:---|
| **步骤** | 两步 | 一步协同 | 两步 |
| **决速步** | 离去基团离去 | C-H 断裂 + LG 离去同步 | C-H 断裂（去质子）|
| **碳正离子** | 有 | 无 | 无 |
| **碱的要求** | 弱碱即可 | 需要强碱 | 需要极强碱 |
| **底物** | 3° > 2° > 1° | 无限制（但位阻影响）| 需稳定碳负离子 |
| **立体化学** | 无特定 | **反式共平面** | 无特定 |
| **区域选择性** | Zaitsev | Zaitsev 或 Hofmann | Hofmann |

#### Zaitsev vs Hofmann 规则

- **Zaitsev（热力学产物）**：多取代烯烃为主（高温/弱碱）
- **Hofmann（动力学产物）**：少取代烯烃为主（大位阻碱）
- 离去基团差（如 F）→ Hofmann（E1cb 特征）

### 4.4 醇的氧化

#### 氧化试剂选择性光谱

| 试剂 | 氧化强度 | 1°醇产物 | 2°醇产物 | 特点 |
|:---|:---:|:---:|:---:|:---|
| **PCC/PDC** | 温和 | **醛** | 酮 | 不进一步氧化醛 |
| **Swern** | 温和 | **醛** | 酮 | 低温，无金属 |
| **Dess-Martin** | 温和 | **醛** | 酮 | 高选择性，贵 |
| **Jones（CrO₃/H₂SO₄）** | 强 | **羧酸** | 酮 | 酸性，副反应多 |
| **Oppenauer** | 温和 | — | 酮 | 可逆，MPV 逆反应 |

**核心思维**：氧化试剂的选择性——"想停在哪就停在哪"。

#### Swern 氧化机理

$$\ce{DMSO + (COCl)2 -> [Cl2S+(CH3)2] ->[ROH] 烷氧基锍盐 ->[Et3N] RCHO + (CH3)2S}$$

1. DMSO 与草酰氯形成氯锍盐
2. 醇进攻 → 烷氧基锍盐
3. Et₃N 去质子 → 消除 → 醛/酮 + 二甲硫醚

#### 其他氧化方法

| 试剂 | 特点 | 适用范围 |
|:---|:---|:---|
| **Collins 试剂** | CrO₃·吡啶复合物 | 1°醇 → 醛 |
| **Corey-Kim** | NCS/DMS + 醇 → 氧化 | 温和氧化 |
| **Ley-Griffith（TPAP/NMO）** | 高价钌催化 | 不饱和醇的选择性氧化 |
| **TEMPO/NaOCl** | 有机催化 | 1°醇 → 醛 |

### 4.5 醇的反应性排序

| 反应类型 | 反应性顺序 | 原因 |
|:---|:---|:---|
| 亲核取代（SN1）| 3° > 2° > 1° | 碳正离子稳定性 |
| 亲核取代（SN2）| 1° > 2° > 3° | 位阻 |
| 消除（E1）| 3° > 2° > 1° | 碳正离子稳定性 |
| 消除（E2）| 3° > 2°（强碱）| 烯烃稳定性 + 位阻 |
| 氧化 | 1°/2°可氧化，3°不氧化 | 无 α-H |

### 4.6 氧化试剂选择决策树

```
目标产物是醛？
  ├─ 是 → PCC、Swern、Dess-Martin、Collins
  └─ 否 → 目标产物是羧酸？
           ├─ 是 → Jones、KMnO₄
           └─ 否 → 目标产物是酮？
                    ├─ 是 → PCC、Swern、Dess-Martin、Jones
                    └─ 否 → 3°醇不可氧化
```

### 4.7 卤代试剂选择

| 目标 | 首选试剂 | 注意 |
|:---|:---|:---|
| 1°醇 → 氯代烷 | SOCl₂/吡啶 | inversion |
| 1°醇 → 溴代烷 | PBr₃ 或 Appel | inversion |
| 1°/2°/3°醇 → 氟代烷 | DAST | 有时 retention |
| 构型翻转（2°醇）| Mitsunobu | 先成酯，再水解 |

### 4.8 取代/消除竞争

| 条件 | 主要产物 | 原因 |
|:---|:---|:---|
| 低温、弱碱、稀溶液 | 取代 | SN2 有利 |
| 高温、强碱、浓溶液 | 消除 | E2 有利 |
| 3°醇 + 酸 | 消除（E1）| 碳正离子易形成 |
| 1°醇 + 强亲核试剂 | 取代（SN2）| 位阻小 |

### 4.9 常见比较与易混点

| 对比项 | SN1 | SN2 |
|:---|:---|:---|
| 底物 | 3° > 2° | 1° > 2° |
| 立体化学 | 外消旋化 | 构型翻转 |
| 重排 | 可能 | 不可能 |
| 溶剂 | 极性质子有利 | 极性非质子有利 |

| 对比项 | Zaitsev 规则 | Hofmann 规则 |
|:---|:---|:---|
| 产物 | 多取代烯烃 | 少取代烯烃 |
| 控制因素 | 热力学（稳定性）| 动力学（位阻）|
| 典型条件 | 高温、弱碱 | 大位阻碱 |

| 对比项 | PCC | Jones |
|:---|:---|:---|
| 1°醇产物 | 醛 | 羧酸 |
| 条件 | 温和（CH₂Cl₂）| 强酸（H₂SO₄）|
| 选择性 | 高 | 低 |

### 4.10 醇的反应易错点

1. **"PCC 氧化 1°醇得羧酸"**：错误，PCC 停在醛；Jones 才氧化到羧酸
2. **"E2 总是 Zaitsev"**：错误，大位阻碱 → Hofmann 产物
3. **"所有醇卤代都 inversion"**：错误，DAST 有时 retention
4. **"3°醇可被氧化"**：错误，3°醇无 α-H，不能被常规氧化剂氧化
5. **"Swern 氧化需要高温"**：错误，Swern 需低温（-78°C 开始）

### 4.11 例题

**例题 1：氧化试剂选择**
如何将 1-丁醇转化为丁醛？ → PCC/Swern/Dess-Martin（不可用 Jones）

**例题 2：E2 消除构象分析**
E2 消除要求 H 和离去基团 anti-periplanar（二面角 180°），只有直立-直立（ax-ax）关系满足此几何要求。

**例题 3：醇的制备**
由丙烯制备 1-丙醇（反马氏：硼氢化-氧化）和 2-丙醇（马氏：酸催化水合或羟汞化-去汞）。

### 4.12 醇的反应竞赛拓展

1. **Sharpless 不对称双羟基化**：烯烃 → 邻二醇，对映选择性控制
2. **Woodward/Prevost 双羟基化**：碘/羧酸银法，不同立体化学
3. **Tishchenko 反应**：醛的歧化生成酯
4. **Meerwein-Ponndorf-Verley 还原**：Oppenauer 的逆反应，酮 → 醇
5. **Ley-Griffith 氧化**：TPAP/NMO 体系，温和高效

## 五、教学常见节点

- **醇的酸性比较**：CH₃OH > ROH > 酚 < 羧酸（pKa 序列）
- **醇的脱水**：分子内（140°C，H₂SO₄）→ 烯；分子间（140°C）→ 醚
- **醇的氧化分级**：1° → 醛 → 羧酸；2° → 酮；3° 不氧化
- **醇的鉴别**：Lucas 试剂（ZnCl₂/HCl）区分 1°/2°/3° 醇
- **卤代反应**：PBr₃、SOCl₂、HI 等转化
- **关键合成应用**：Grignard 反应制醇、还原（NaBH₄/LiAlH₄）醛酮制醇

## 六、竞赛拓展

- **邻二醇的氧化裂解**：HIO₄（高碘酸）氧化
- **频哪醇重排**：邻二醇在酸催化下的重排反应
- **不对称醇的合成**：手性催化剂下不对称还原酮

## §12 教学视角

### 学生常见认知误区

- **误区1：「醇和酚都是含 -OH 的，所以性质差不多」** → 学生看到都有 -OH 就认为化学性质类似。实际上酚的 -OH 直接连在芳环上，受共振稳定，酸性远强于醇（酚 pKa ≈ 10，醇 pKa ≈ 16）。酚能与 NaOH 反应，醇不能。 → **口诀：酚酸醇中性，芳环是分界。**

- **误区2：「PCC 氧化 1° 醇得到羧酸」** → 这是竞赛中最常见的有机错误之一。PCC/PDC 是温和氧化剂，将 1° 醇停在醛；Jones 氧化才到羧酸。 → **口诀：PCC 停醛，Jones 到酸——温和停，强烈冲。**

- **误区3：「E2 消除一定是 Zaitsev 产物」** → 学生背了 Zaitsev 规则就到处用。实际上大位阻碱（如 t-BuOK）倾向于生成 Hofmann 产物（少取代烯烃）。 → **口诀：小碱热力学（Zaitsev），大碱动力学（Hofmann）。**

- **误区4：「3° 醇也能被氧化」** → 3° 醇的碳上没有 $\alpha$-H（即与 -OH 相连的碳上没有氢），常规氧化剂无法作用。 → **正确认知：氧化需要 $\alpha$-H，3° 醇无此结构，故不被氧化。**

- **误区5：「硼氢化-氧化是马氏规则加成」** → 硼氢化-氧化的区域选择性恰好**反马氏**：-OH 加在取代较少的碳上。学生经常和酸催化水合搞混。 → **口诀：硼氢化反马，酸催化正马——记一个就够了。**

- **误区6：「SOCl₂ 醇→氯代烷一定 inversion」** → 在碱（吡啶）存在下确实 inversion（SN2 机理），但在无碱条件下可能通过 SNi 机理得到 retention。竞赛题若无特殊说明，通常默认有碱→inversion。 → **方法：看到 SOCl₂ 先看有无碱，再判断立体化学。**

### 入门级例题

**题目**：化合物 A（分子式 $\ce{C5H12O}$）是一种手性醇，经 PCC 氧化后得到酮 B（分子式 $\ce{C5H10O}$）。B 经 $\ce{NaBH4}$ 还原又得到 A。写出 A 的可能结构并解释为何 B 的还原必须用 $\ce{NaBH4}$ 而非 $\ce{LiAlH4}$（假设 A 中含有酯基）。

**分析**
- 分子式 $\ce{C5H12O}$，不饱和度 = 0，是饱和醇
- PCC 氧化得酮 → A 是 2° 醇（仲醇）
- 手性 → A 有一个手性碳
- A 经 PCC 得 B（酮），B 经 $\ce{NaBH4}$ 还原得 A（手性 2° 醇）
- 需要保护酯基：$\ce{LiAlH4}$ 会还原酯基，$\ce{NaBH4}$ 不会

**解答**

A 的可能结构为 2-戊醇（$\ce{CH3CH(OH)CH2CH2CH3}$）或其手性异构体。由于 PCC 氧化只断开 $\alpha$-C 上的 C-H 键，不改变碳骨架。

若分子中同时含有酯基：$\ce{NaBH4}$ 只还原醛/酮，不还原酯基；$\ce{LiAlH4}$ 还原一切羰基（醛、酮、酯、酰胺），会破坏酯基。

**反思**
- 竞赛中「选择性还原」是高频考点：$\ce{NaBH4}$ 是温和还原剂，只还原醛/酮；$\ce{LiAlH4}$ 是强还原剂，还原几乎所有羰基化合物
- 手性醇的合成需要考虑对映选择性，基础竞赛可先忽略，高级竞赛需掌握 Sharpless 不对称环氧化等

### 与现实/直觉的连接

**类比：氧化试剂是一把可调温的熨斗**
- 温和氧化剂（PCC、Swern）= 低温熨斗：轻轻烫平，不烧坏衣服（停在醛）
- 强氧化剂（Jones、KMnO₄）= 高温熨斗：用力烫，直接烫到头（到羧酸）
- 你的任务是选择「刚够用」的温度——这就是合成设计的核心思想

**实际应用**
- **乙醇的工业氧化**：工业上用铜催化剂将乙醇氧化为乙醛（类似 PCC 的效果），乙醛进一步氧化为乙酸（类似 Jones）。
- **药物合成中的醇氧化**：紫杉醇等药物合成中，需要在分子多个 -OH 中选择性氧化某一个，这时 PCC 和 Swern 的温和性至关重要。
- **生物体内的醇代谢**：乙醇在体内被乙醇脱氢酶（ADH）氧化为乙醛（类似 2° 醇→酮），乙醛再被乙醛脱氢酶（ALDH）氧化为乙酸。喝酒脸红是因为 ALDH 活性低，乙醛积累。

### 教学建议

1. **先建立「官能团转化网络」**：醇的教学核心是「它从哪来，到哪去」。建议先画一张转化图：烯→醇（水合/硼氢化）→卤代烷/醛/酮/羧酸，让学生有全局观。
2. **氧化试剂选择用决策树**：不要让学生死记硬背，而是用「想停在哪就停在哪」的思维。给出目标产物→选择合适试剂。本文件中的决策树可以直接用于教学。
3. **立体化学是竞赛的拉分点**：基础学生只需掌握 SN2 = inversion；竞赛学生需要掌握 SOCl₂/PBr₃/DAST 的立体化学差异。分层教学。
4. **用 Newman 投影式讲 E2 消除**：E2 要求 anti-periplanar 几何构型，这必须用 Newman 投影式才能直观理解。环己烷体系则需要椅式构象。建议用分子模型辅助。
5. **关联生物化学**：醇的氧化（乙醇→乙醛→乙酸）是学生最熟悉的生活化学，可以用这个例子串联氧化试剂选择、酶催化和代谢通路，增强记忆。
