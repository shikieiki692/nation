# 有机化学

> 本目录涵盖中国化学奥林匹克**基础要求**中的有机化学模块，共 **322 个知识点文件**。
> 所有文件平铺在根目录，无子文件夹。是03-知识点/中最大的模块。

## 知识模块分布

| 模块 | 核心KP |
|------|--------|
| **反应类型** | SN1/SN2/SNAr/E1/E2/E1cb、亲核/亲电加成、亲核/亲电取代、自由基取代、周环反应 |
| **人名反应**（~100+） | Diels-Alder、Wittig、Grignard、Heck、Suzuki、Friedel-Crafts、Claisen、Aldol、Beckmann、Cope重排等 |

| **官能团** | 醇、醛酮、羧酸、羧酸衍生物、胺、卤代烃、烯烃、炔烃、苯酚、杂环 |
| **电子效应** | 诱导/共轭/超共轭效应、共振论、芳香性、Hückel规则 |
| **合成** | 逆合成分析、全合成、官能团转化、保护基、不对称合成 |
| **波谱** | NMR、IR、UV-Vis、质谱 |
| **生物分子** | 氨基酸、糖化学、多肽、脂肪酸、生物碱 |
| **高分子** | 缩聚/加聚反应、重复单元 |
