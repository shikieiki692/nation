# 金属与金属材料

## 课标要求

1. 了解金属的物理性质（导电性、导热性、延展性等）
2. 理解合金的概念和常见合金的特性
3. 掌握金属的化学性质（与O₂、酸、盐溶液反应）
4. 理解金属活动性顺序及其应用
5. 了解金属资源的利用和保护

## 核心概念

### 1. 金属的物理性质

**共同性质**：金属光泽、导电性、导热性、延展性

| 金属 | 特性 |
|------|------|
| 铁 | 银白色，有磁性，导电性良好 |
| 铜 | 紫红色，导电性仅次于银 |
| 铝 | 银白色，密度小，导电性良好 |
| 金 | 黄色，延展性最好，化学性质稳定 |
| 银 | 导电性、导热性最好的金属 |
| 钨 | 熔点最高的金属（3414°C） |
| 汞 | 常温下唯一的液态金属 |
| 锂 | 密度最小的金属 |

**性质决定用途**：但用途还需考虑价格、资源、美观、耐腐蚀性等因素。

### 2. 合金

**定义**：在纯金属中加热熔合某些金属或非金属而制得的具有金属特性的物质。

**合金的优点**（相对于纯金属）：
- 硬度一般更大
- 熔点一般更低
- 抗腐蚀性能更好
- 用途更广泛

**常见合金**：

| 合金 | 主要成分 | 特性 | 用途 |
|------|---------|------|------|
| 生铁 | Fe + C(2%~4.3%) | 硬而脆 | 铁锅、暖气片 |
| 钢 | Fe + C(0.03%~2%) | 硬度大，韧性好 | 刀具、桥梁、建筑 |
| 不锈钢 | Fe + Cr + Ni | 抗腐蚀性强 | 餐具、医疗器械 |
| 黄铜 | Cu + Zn | 硬度大，耐腐蚀 | 仪器、装饰品 |
| 青铜 | Cu + Sn | 耐磨，铸造性好 | 轴承、雕塑 |
| 焊锡 | Sn + Pb | 熔点低 | 焊接金属 |
| 钛合金 | Ti + Al + V | 密度小，强度高，耐腐蚀 | 航空航天、医疗 |

### 3. 金属的化学性质

**（1）与氧气反应**

| 金属 | 反应条件 | 产物 | 现象 |
|------|---------|------|------|
| 镁 | 常温 | MgO | 银白色金属逐渐变暗 |
| 铝 | 常温 | Al₂O₃（致密薄膜） | 保护内部不再被氧化 |
| 铁 | 点燃 | Fe₃O₄ | 剧烈燃烧，火星四射 |
| 铜 | 加热 | CuO | 红色固体变黑色 |
| 金 | 任何条件 | 不反应 | "真金不怕火炼" |

**（2）与稀盐酸/稀硫酸反应**

| 金属 | 反应现象 | 化学方程式 |
|------|---------|-----------|
| 镁 | 剧烈反应，产生大量气泡 | Mg + 2HCl = MgCl₂ + H₂↑ |
| 锌 | 反应较快，产生气泡 | Zn + 2HCl = ZnCl₂ + H₂↑ |
| 铁 | 反应较慢，产生气泡，溶液变浅绿色 | Fe + 2HCl = FeCl₂ + H₂↑ |
| 铜 | 不反应 | — |

**置换反应**：一种单质与一种化合物反应，生成另一种单质和另一种化合物的反应。

**（3）与盐溶液反应**

| 实验 | 现象 | 化学方程式 |
|------|------|-----------|
| 铁放入硫酸铜溶液 | 铁丝表面覆盖红色物质，溶液变浅绿色 | Fe + CuSO₄ = FeSO₄ + Cu |
| 铜放入硝酸银溶液 | 铜丝表面覆盖银白色物质，溶液变蓝色 | Cu + 2AgNO₃ = Cu(NO₃)₂ + 2Ag |
| 铜放入硫酸铝溶液 | 不反应 | — |

### 4. 金属活动性顺序

$$
\text{K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au}
$$

金属活动性由强逐渐减弱

**三大应用规则**：
1. 金属位置越靠前，活动性越强
2. 位于氢前面的金属能置换出稀盐酸、稀硫酸中的氢
3. 位于前面的金属能把位于后面的金属从其化合物溶液中置换出来

**判断反应能否发生**：
- 活动性强的金属 + 活动性弱的金属的化合物 → 反应能发生
- 活动性弱的金属 + 活动性强的金属的化合物 → 反应不能发生

### 5. 金属资源的利用和保护

**铁的冶炼**（高炉炼铁）：
- 原料：铁矿石、焦炭、石灰石、空气
- 原理：Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂

**金属资源保护**：
- 防止金属腐蚀（涂油、镀层、制成合金）
- 回收利用废旧金属
- 合理开采金属矿物
- 寻找金属替代品

## 知识拓展
- **金属活动性顺序的理论解释（电极电位）**：金属活动性顺序的本质是金属失去电子的难易程度，高中化学用电极电位来定量描述。电极电位越负（如K为-2.93V），越容易失去电子，活动性越强；电极电位越正（如Au为+1.50V），越不容易失去电子，活动性越弱。这解释了为什么"真金不怕火炼"——金的化学性质极其稳定。
- **合金的性能优势**：合金中不同大小的原子混合在一起，破坏了纯金属规则的晶体结构，使位错运动受阻，因此硬度显著增大。例如，纯铝很软，但铝铜合金（硬铝）的强度接近钢材。形状记忆合金（如镍钛合金）能在变形后通过加热恢复原始形状，广泛用于医疗支架和航天天线。
- **稀土金属的战略价值**：稀土元素（17种）被称为"工业维生素"，虽然用量少但不可或缺。钕铁硼永磁材料用于电动汽车电机和风力发电机；铕用于LED荧光粉；镧用于储氢材料和石油催化裂化。中国拥有全球最大的稀土储量和生产能力，稀土已成为重要的战略资源。

## 竞赛衔接

1. **金属活动性顺序的验证实验设计**：常用"三取中"法验证三种金属的活动性顺序
2. **铝的钝化**：常温下铝与氧气反应生成致密氧化膜，阻止内部铝继续被氧化
3. **湿法炼铜**：Fe + CuSO₄ = FeSO₄ + Cu，我国古代就已应用
4. **合金的微观结构**：合金中不同原子的大小差异会改变金属原子的排列，从而改变性能
5. **金属与酸反应的速率**：除金属活动性外，还与酸的浓度、温度、金属表面积有关

## 常见易错

| 易错点 | 正确理解 |
|--------|---------|
| "合金是化合物" | 错误。合金是混合物，具有金属特性 |
| "铁与稀盐酸反应生成FeCl₃" | 错误。生成FeCl₂（亚铁盐），溶液呈浅绿色 |
| "铜能与稀硫酸反应" | 错误。铜在金属活动性顺序中位于氢后面，不能置换酸中的氢 |
| "铝的抗腐蚀性差" | 错误。铝表面生成致密Al₂O₃薄膜，抗腐蚀性很好 |
| "地壳中含量最高的金属是铁" | 错误。是铝（Al） |
| "钢是很纯的铁" | 错误。钢是铁碳合金，含碳量0.03%~2% |

## 教学视角

本单元是初中化学"元素化合物"部分的重要内容，体现了"结构决定性质，性质决定用途"的基本化学观念：

1. **实验探究**：金属活动性的探究是初中化学最重要的探究实验之一
2. **分类思想**：通过金属与O₂、酸、盐反应的规律，建立金属化学性质的分类认识
3. **守恒观念**：置换反应中元素种类不变，为质量守恒定律提供实例
4. **社会价值**：金属资源保护与可持续发展，培养学生环保意识
5. **实际应用**：从日常生活用品到航空航天材料，体现金属材料的广泛应用
