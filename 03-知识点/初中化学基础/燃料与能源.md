# 燃料与能源

## 课标要求

1. 理解燃烧的条件和灭火的原理
2. 了解化石燃料（煤、石油、天然气）的组成和合理利用
3. 认识化石燃料使用对环境的影响
4. 了解新能源（氢能、太阳能等）的开发与应用
5. 理解化学反应中的能量变化

## 核心概念

### 1. 燃烧的条件

燃烧是可燃物与氧气发生的一种发光、放热的剧烈氧化反应。

**燃烧三要素**（缺一不可）：
1. 可燃物（物质本身具有可燃性）
2. 氧气或空气
3. 达到着火点（燃烧所需的最低温度）

| 物质 | 着火点/°C |
|------|----------|
| 白磷 | 40 |
| 红磷 | 260 |
| 木材 | 240~270 |
| 木炭 | 320~400 |
| 无烟煤 | 600~700 |

**关键点**：着火点是物质固有属性，不能降低着火点。

### 2. 灭火的原理和方法

灭火就是破坏燃烧的条件，只需破坏其中一个即可：

| 灭火方法 | 破坏的条件 | 实例 |
|---------|-----------|------|
| 隔离可燃物 | 移走或隔离可燃物 | 关闭燃气阀门 |
| 隔绝氧气 | 用覆盖物隔绝空气 | 油锅着火用锅盖盖灭 |
| 降低温度 | 使温度降到着火点以下 | 用水浇灭 |

### 3. 化石燃料

**三大化石燃料**：

| 燃料 | 主要成分 | 主要用途 |
|------|---------|---------|
| 煤 | 有机物和无机物的复杂混合物 | 发电、取暖、化工原料 |
| 石油 | 多种碳氢化合物的混合物 | 汽油、柴油、润滑油等 |
| 天然气 | 主要成分是甲烷（CH₄） | 燃料、化工原料 |

**甲烷燃烧**：CH₄ + 2O₂ →(点燃) CO₂ + 2H₂O

**特点**：化石燃料不可再生，储量有限

### 4. 化石燃料对环境的影响

| 污染物 | 来源 | 危害 |
|--------|------|------|
| SO₂ | 煤燃烧 | 形成酸雨 |
| NOx | 汽车尾气 | 形成酸雨、光化学烟雾 |
| CO | 不完全燃烧 | 有毒，污染空气 |
| CO₂ | 完全燃烧 | 温室效应加剧 |
| 烟尘 | 不完全燃烧 | 降低空气质量 |

### 5. 新能源

| 新能源 | 优点 | 目前应用 |
|--------|------|---------|
| 氢能 | 燃烧产物是水，无污染；热值高 | 航天、燃料电池汽车 |
| 太阳能 | 清洁可再生，取之不尽 | 光伏发电、热水器 |
| 风能 | 清洁可再生 | 风力发电 |
| 核能 | 能量密度极高 | 核电站 |
| 地热能 | 稳定可靠 | 发电、供暖 |

## 知识拓展
- **氢能源的前景与挑战**：氢能被称为"终极清洁能源"，因为其燃烧产物只有水，且热值是汽油的3倍以上。然而，目前面临三大挑战：制氢成本高（电解水需大量电能）、储运困难（氢气易泄漏且高压储存有安全隐患）、加氢基础设施不足。科学家正在探索光催化分解水制氢，若突破将彻底改变能源格局。
- **可燃冰（天然气水合物）**：可燃冰是在高压低温条件下，甲烷分子被水分子笼状结构包裹形成的冰状固体。1立方米可燃冰可释放约164立方米天然气。全球可燃冰储量估计是已知化石燃料总量的2倍以上。2017年中国在南海成功试采可燃冰，标志着这一领域的技术突破。但开采中需防止甲烷泄漏（甲烷的温室效应是CO₂的25倍）。
- **核能与太阳能的化学原理**：核裂变（重核分裂为轻核）和核聚变（轻核结合为重核）都遵循爱因斯坦质能方程E=mc²，虽然不属于化学反应，但其能量释放机制对能源研究至关重要。太阳能电池的核心是半导体硅——硅原子吸收光子后，外层电子被激发产生电流，这一"光生伏特效应"将光能直接转化为电能，是物理化学的精彩应用。

## 竞赛衔接

1. **控制变量法**：燃烧条件探究是控制变量法的经典应用
2. **能量守恒**：化学反应中的能量变化遵循能量守恒定律
3. **可燃冰**：甲烷水合物（CH₄·nH₂O），储量巨大但开发需谨慎
4. **乙醇作为生物质能源**：C₂H₅OH + 3O₂ →(点燃) 2CO₂ + 3H₂O，燃烧放热29.7 kJ/g

## 常见易错

| 易错点 | 正确理解 |
|--------|---------|
| "着火点可以降低" | 错误。着火点是物质固有属性，只能降低温度，不能降低着火点 |
| "燃烧一定需要O₂" | 通常情况需要，但某些物质可在Cl₂中燃烧（如H₂在Cl₂中燃烧） |
| "CO₂是温室气体，所以CO₂有害" | CO₂无毒，是植物光合作用原料；过量排放才导致温室效应 |
| "氢能源已经广泛应用" | 目前因制取和储运成本高，尚未广泛应用 |
| "煤是纯净物" | 煤是复杂的混合物 |
| "化学反应只能放热" | 有些反应吸热（如C + CO₂ → 2CO） |

## 教学视角

本单元将化学知识与能源、环境紧密结合，体现化学的社会价值：

1. **实验探究**：燃烧条件的探究是控制变量法的典型应用，培养学生科学探究能力
2. **辩证思维**：化石燃料的使用既有贡献也有危害，培养学生辩证分析能力
3. **社会责任**：了解能源危机和环境问题，增强节能减排意识
4. **能量观念**：建立化学反应伴随能量变化的观念，为高中热化学学习奠基
5. **实际应用**：从灭火方法选择到新能源开发，体现化学知识的实用价值
