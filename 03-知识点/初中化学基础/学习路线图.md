# 初中化学KP学习路线图

> 12个KP文件的前置依赖关系与推荐学习顺序。
> 从零基础到高中衔接的完整路径。

---

## 学习阶段总览

```
阶段1：化学入门（上册 Ch1）
    │
    ├── 物质的变化与性质 ──── 无前置（入门文件）
    └── 化学实验基础 ──────── 物质的变化与性质
    │
阶段2：身边的化学物质（上册 Ch2-4）
    │
    ├── 空气与氧气 ←──── 物质的变化与性质、化学实验基础
    ├── 分子原子与元素 ←── 空气与氧气（O₂的微观解释）
    └── 水与水资源 ←──── 分子原子与元素（分子→水的组成）
    │
阶段3：化学反应原理（上册 Ch5-7）
    │
    ├── 质量守恒与化学方程式 ←── 分子原子与元素、水与水资源
    ├── 碳及其氧化物 ←──── 质量守恒与化学方程式（方程式应用）
    └── 燃料与能源 ←──── 碳及其氧化物（燃烧反应）
    │
阶段4：元素化学深化（下册 Ch8-10）
    │
    ├── 金属与金属材料 ←──── 质量守恒与化学方程式（金属反应方程式）
    ├── 溶液 ←──── 水与水资源（水的溶解能力）
    └── 酸碱盐 ←──── 溶液（溶液中的反应）、金属与金属材料（金属与酸反应）
    │
阶段5：综合应用（下册 Ch11）
    │
    └── 化学与社会 ←── 所有前置KP（综合应用）
```

## 推荐学习路径（按目标分层）

### 🎯 初中毕业备考路径
```
物质的变化与性质 → 化学实验基础
→ 空气与氧气 → 分子原子与元素 → 水与水资源
→ 质量守恒与化学方程式
→ 碳及其氧化物 → 燃料与能源
→ 金属与金属材料 → 溶液 → 酸碱盐
→ 化学与社会
```

### 🎯 初中→高中衔接路径（重点补充）
```
完成初中全路径后，重点强化：
→ 分子原子与元素（为原子结构打基础）
→ 质量守恒与化学方程式（为化学计量打基础）
→ 酸碱盐（为离子反应打基础）
→ 溶液（为溶液化学打基础）
```
