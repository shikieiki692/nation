# 质量守恒与化学方程式

## 课标要求

1. 认识质量守恒定律，能从微观角度解释质量守恒的原因
2. 能正确书写简单的化学方程式
3. 掌握化学方程式的配平方法（最小公倍数法）
4. 能根据化学方程式进行简单的计算

## 核心概念

### 一、质量守恒定律

**定律内容**：参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和。

**关键词解读**：
- "参加反应"：未反应的物质质量不能计入
- "各物质"：包括所有反应物和所有生成物
- "质量总和"：不能遗漏任何一种物质

**微观解释**：化学反应的过程就是原子重新组合的过程。

| 微观粒子 | 反应前后变化 | 质量是否改变 |
|----------|-------------|-------------|
| 原子种类 | 不变 | 不变 |
| 原子数目 | 不变 | 不变 |
| 原子质量 | 不变 | 不变 |
| 分子种类 | 改变（生成新分子） | — |
| 分子数目 | 可能改变 | — |
| 元素种类 | 不变 | 不变 |

**"六个不变、两个一定变、一个可能变"**：
- 六个不变：原子种类、原子数目、原子质量、元素种类、元素质量、反应前后总质量
- 两个一定变：物质种类、分子种类
- 一个可能变：分子数目

### 二、验证质量守恒定律的实验设计

**实验设计原则**：
1. 有气体参与或生成的反应，必须在**密闭容器**中进行
2. 天平称量前要调零
3. 反应前后都要称量，比较数据

**典型实验**：

| 实验 | 反应 | 装置要求 | 现象与结论 |
|------|------|----------|-----------|
| 铜粉加热 | 2Cu + O₂ → 2CuO | 密闭（气球） | 反应前后质量不变 |
| 铁与硫酸铜 | Fe + CuSO₄ → Cu + FeSO₄ | 可敞口 | 反应前后质量不变 |
| 盐酸与碳酸钠 | Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ | 敞口（不适用） | 质量减少（CO₂逸出） |
| 镁条燃烧 | 2Mg + O₂ → 2MgO | 敞口（不适用） | 质量变化（O₂参与或MgO烟雾逸出） |

> **注意**：盐酸与碳酸钠、镁条燃烧的实验中，天平读数变化是因为有气体参与或逸出，**并不违反**质量守恒定律。验证该定律时，有气体参与的反应必须在密闭容器中进行。

### 三、化学方程式

**定义**：用化学式来表示化学反应的式子。

**化学方程式的意义**：

| 意义层面 | 具体含义 | 示例（以 2H₂ + O₂ → 2H₂O 为例） |
|----------|----------|--------------------------------|
| 定性 | 反应物、生成物、反应条件 | 氢气在氧气中燃烧生成水 |
| 定量 | 各物质的质量比 | H₂:O₂:H₂O = 4:32:36 = 1:8:9 |
| 微观 | 分子个数比 | 2个氢分子 + 1个氧分子 → 2个水分子 |

**化学方程式的书写原则**：
1. 以客观事实为基础（不能凭空臆造）
2. 遵守质量守恒定律（等号两边原子种类和数目相等）

### 四、化学方程式的书写步骤

以磷在氧气中燃烧为例：

**步骤1**：写出反应物和生成物的化学式，注明条件

$$\text{P} + \text{O}_2 \xrightarrow{\text{点燃}} \text{P}_2\text{O}_5$$

**步骤2**：配平（最小公倍数法）

- 左边O原子数=2，右边O原子数=5，最小公倍数=10
- 在 O₂ 前配5，在 P₂O₅ 前配2
- 再调整P：左边配4

$$4\text{P} + 5\text{O}_2 \xlongequal{\text{点燃}} 2\text{P}_2\text{O}_5$$

**步骤3**：检查等号两边各原子种类和数目是否相等

**符号标注规则**：

| 情况 | 标注 | 示例 |
|------|------|------|
| 生成物中有气体（反应物无气体） | 气体化学式后加"↑" | 2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑ |
| 生成物中有固体沉淀（反应物无固体） | 固体化学式后加"↓" | CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄ |
| 反应物和生成物都有气体 | 气体不标"↑" | S + O₂ → SO₂ |

### 五、化学方程式的配平方法

**最小公倍数法**（最常用）：
1. 找出化学式中原子数目不等的元素
2. 求该元素原子数的最小公倍数
3. 确定各化学式的化学计量数
4. 调整其他原子的数目
5. 检查所有原子是否平衡

**常用配平技巧**：
- **观察法**：适用于简单反应，直接观察调整
- **奇偶法**：某元素在一边是奇数、另一边是偶数时，先在奇数项前配2
- **定一法**：将最复杂化学式的系数定为1，再推导其他

**配平练习示例**：

| 反应 | 配平后的方程式 |
|------|---------------|
| C₂H₄ + O₂ → CO₂ + H₂O | C₂H₄ + 3O₂ → 2CO₂ + 2H₂O |
| Fe₂O₃ + CO → Fe + CO₂ | Fe₂O₃ + 3CO → 2Fe + 3CO₂ |
| WO₃ + H₂ → W + H₂O | WO₃ + 3H₂ → W + 3H₂O |

### 六、根据化学方程式的简单计算

**计算步骤（五步法）**：

1. **设**未知量
2. **写**出化学方程式
3. **找**出已知量和未知量的关系（相对分子质量与化学计量数的乘积之比）
4. **列**比例式求解
5. **答**简明写出答案

**例题1**：加热分解 7.9 g 高锰酸钾，可得到氧气的质量是多少？

$$2\text{KMnO}_4 \xrightarrow{\triangle} \text{K}_2\text{MnO}_4 + \text{MnO}_2 + \text{O}_2\uparrow$$

$$2 \times 158 \quad\quad\quad\quad\quad\quad\quad\quad 32$$

$$7.9\text{g} \quad\quad\quad\quad\quad\quad\quad\quad\quad x$$

$$\frac{2 \times 158}{32} = \frac{7.9\text{g}}{x}$$

$$x = \frac{32 \times 7.9\text{g}}{2 \times 158} = 0.8\text{g}$$

**答**：可得到 0.8 g 氧气。

**例题2**：工业上制取 5.6 t 氧化钙，需要碳酸钙的质量是多少？

$$\text{CaCO}_3 \xrightarrow{\text{高温}} \text{CaO} + \text{CO}_2\uparrow$$

$$100 \quad\quad\quad 56$$

$$x \quad\quad\quad 5.6\text{t}$$

$$\frac{100}{56} = \frac{x}{5.6\text{t}}$$

$$x = 10\text{t}$$

**答**：需要碳酸钙 10 t。

## 关键实验

### 实验1：铜粉在密闭容器中加热
- **装置**：锥形瓶底部铺铜粉，瓶口塞单孔橡胶塞，插入系有气球的玻璃导管
- **操作**：称量装置总质量 → 加热 → 冷却后再称量
- **现象**：铜粉变黑（生成CuO），气球先膨胀后缩小
- **结论**：反应前后总质量不变，验证质量守恒定律

### 实验2：铁与硫酸铜溶液反应
- **操作**：铁丝与硫酸铜溶液在密闭装置中反应
- **现象**：铁丝表面出现红色固体，溶液由蓝色变为浅绿色
- **结论**：反应前后总质量不变

### 实验3：红磷燃烧验证质量守恒
- **装置**：锥形瓶内放红磷，用酒精灯加热玻璃导管引燃
- **关键**：小气球的作用是平衡气压，防止瓶塞弹出
- **现象**：红磷燃烧产生白烟，天平保持平衡

## 知识拓展
- **质量守恒定律的发现历史**：1756年，俄国科学家罗蒙诺索夫最先通过实验发现化学反应中质量守恒，但未引起广泛关注。1774年，拉瓦锡用更精确的定量实验独立证实了这一规律并赋予了清晰的理论解释，使质量守恒定律被科学界广泛接受。这一段科学史告诉我们，科学发现往往需要精确实验和理论阐述的双重支撑。
- **化学计量学的工业应用**：化工生产中，化学方程式配平不仅是课堂练习，更是工厂计算原料投入量和产品产量的基础。例如，合成氨工业（N₂ + 3H₂ → 2NH₃）中，工程师需要精确计算氮气和氢气的最佳投料比，这直接影响生产效率和成本控制。化学计量学是连接实验室与工厂的关键纽带。
- **催化剂的奥秘**：催化剂能改变化学反应速率但不参与反应，其本质是提供了一条活化能更低的反应路径。生命体中的酶是天然催化剂，效率可达普通催化剂的百万倍以上。催化剂研究是当代化学的核心前沿之一——2001年诺贝尔化学奖即授予了在手性催化反应方面做出开创性贡献的三位科学家。

## 竞赛衔接

### 从质量守恒到能量守恒（链接：[[反应热与盖斯定律]]）

**初中知识的延伸方向**：
1. 初中质量守恒定律只涉及"质量"，高中将扩展到**能量守恒**——化学反应中能量不会凭空产生或消失
2. 初中配平是"凑数"，高中将从**氧化还原反应**的角度理解配平的本质（电子转移守恒）
3. 初中计算是简单的质量比例，高中将引入**物质的量**进行更精确的计算
4. 初中只涉及简单反应，高中将学习**可逆反应**、**化学平衡**等概念

### 思维进阶

质量守恒定律的本质是**原子的守恒**：
- 原子是化学变化中的最小粒子，在反应中不会被创造或消灭
- 原子只是重新排列组合，形成新的分子或物质
- 因此，反应前后原子的种类、数目、质量都不变，总质量自然不变

这一思想在高中化学中将推广为：
- **元素守恒**：反应前后元素种类不变
- **电子守恒**：氧化还原反应中得失电子总数相等
- **电荷守恒**：离子反应中正负电荷总数相等
- **能量守恒**：反应热的计算基础

## 常见易错

| 易错点 | 正确理解 |
|--------|----------|
| "质量守恒定律适用于所有变化" | 仅适用于**化学变化**，不适用于物理变化 |
| "反应前后分子数目一定不变" | 分子数目**可能**改变，如 2H₂ + O₂ → 2H₂O（3→2） |
| "化学方程式中"↑"和"↓"可加可不加" | 生成物中气体/沉淀必须标注（当反应物中没有气体/沉淀时） |
| "配平可以改变化学式" | 配平只能改变化学计量数（系数），**不能**改变化学式（如下标） |
| "参加反应的质量比等于相对分子质量之比" | 应该是相对分子质量与化学计量数的**乘积**之比 |
| "敞口容器中反应质量减少就违反了质量守恒" | 质量减少是因为有气体逸出或参与，**并不违反**定律 |
