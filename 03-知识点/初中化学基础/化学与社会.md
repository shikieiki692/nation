# 化学与社会

## 课标要求
- 了解人体中的元素及其作用，知道合理膳食的重要性
- 认识常见的化学合成材料，了解新材料的发展
- 了解化学与环境保护的关系，树立绿色化学理念
- 理解化学在可持续发展中的作用

## 核心概念

### 化学与人体健康
**人体中的元素**：
- **常量元素**：含量超过0.01%的元素（如O、C、H、N、Ca等），占人体质量的99%以上
- **微量元素**：含量在0.01%以下的元素（如Fe、Zn、F、I等），维持人体正常生命活动

**部分元素对人体健康的影响**：
| 元素 | 主要作用 | 缺乏症 | 过量危害 |
|-----|---------|-------|---------|
| 钙（Ca） | 构成骨骼和牙齿 | 佝偻病、骨质疏松 | 肾结石 |
| 铁（Fe） | 血红蛋白的重要成分 | 贫血 | 肝脏损伤 |
| 碘（I） | 甲状腺激素的成分 | 甲状腺肿大 | 甲状腺肿大 |
| 氟（F） | 构成骨骼和牙齿 | 龋齿 | 氟斑牙、氟骨症 |

**人体需要的营养素**：
1. **糖类**：主要供能物质（如葡萄糖C₆H₁₂O₆）
2. **蛋白质**：构成细胞的基本物质，提供能量
3. **油脂**：重要的备用能源
4. **维生素**：调节新陈代谢，预防疾病
5. **无机盐**：构成人体组织，维持生理功能
6. **水**：人体含量最多的物质，参与各种生理活动

**合理膳食**：我国制定了"中国居民平衡膳食宝塔"，指导人们合理搭配食物，保证营养均衡。

### 食品安全与化学
**食品添加剂**：为改善食品品质和延长保存期而加入的化学合成物质，必须按照国家标准使用。

**食品安全问题**：
- **农药残留**：不合理使用农药导致农产品中农药残留超标
- **重金属污染**：工业废水排放导致土壤和水源重金属污染
- **食品腐败**：微生物作用导致食品变质，产生有害物质

**食品保存方法**：
- **腌制法**：用食盐腌渍蔬菜、鱼、肉等，抑制微生物生长
- **冷藏法**：低温抑制微生物繁殖
- **真空包装法**：隔绝氧气，防止食品氧化和好氧菌生长
- **干燥法**：减少水分，抑制微生物生长

### 化学与环境保护
**水污染**：
- **来源**：工业废水、生活污水、农业面源污染
- **危害**：破坏水生生态系统，危害人体健康
- **防治**：工业废水处理达标排放，生活污水集中处理

**大气污染**：
- **主要污染物**：SO₂、CO、NO₂、可吸入颗粒物
- **酸雨**：pH<5.6的降雨，由SO₂、NO₂等酸性气体导致
- **防治**：使用清洁能源，安装尾气净化装置

**土壤污染**：
- **来源**：工业废渣、农药化肥不合理使用、生活垃圾分类不当
- **危害**：影响农作物生长，污染物通过食物链进入人体
- **防治**：合理使用农药化肥，垃圾分类回收

### 常见的化学合成材料
**三大合成材料**：
1. **塑料**：密度小、耐腐蚀、易加工，如聚乙烯、聚丙烯
2. **合成纤维**：强度高、弹性好、耐磨，如涤纶、腈纶
3. **合成橡胶**：弹性和绝缘性好，如顺丁橡胶、丁苯橡胶

**合成材料的优点**：
- 性能优异，可满足特殊需求
- 便于大规模工业化生产
- 成本较低，产量稳定

**合成材料的环境问题**：
- **白色污染**：塑料制品难以降解，造成环境污染
- **资源消耗**：生产合成材料需要消耗石油等化石资源
- **回收利用**：建立完善的回收体系，实现资源循环利用

**区分纤维的方法**：
- **燃烧法**：棉纤维燃烧有烧纸味，羊毛纤维燃烧有烧焦羽毛味，涤纶燃烧有特殊气味且熔化成球

### 新材料
**复合材料**：将几种材料复合起来，综合各组分性能的优点，如碳纤维复合材料、玻璃纤维增强塑料（玻璃钢）。

**功能材料**：具有光、电、磁等特殊性质的材料，广泛应用于信息技术、航空航天等领域。

**新型材料的发展**：
- 纳米材料：具有特殊性能的超细颗粒材料
- 生物材料：与人体组织相容性好的材料
- 智能材料：能感知环境变化并作出响应的材料

### 绿色化学理念
**绿色化学**：从源头上减少或消除化学生产过程中的污染，实现化学与环境的和谐发展。

**绿色化学的核心原则**：
1. **预防污染**：优于污染治理
2. **原子经济性**：使反应物中的原子尽可能多地转化为产物
3. **低毒合成**：使用无毒或低毒的原料和溶剂
4. **节能降耗**：降低能源消耗，提高资源利用率

**可持续发展**：在满足当代人需求的同时，不损害后代人满足其需求的能力。化学在资源开发、能源利用、环境保护等方面发挥着重要作用。

## 关键实验
1. **营养素的检验**：用碘液检验淀粉，用双缩脲试剂检验蛋白质
2. **合成纤维的区分**：通过燃烧现象区分棉纤维、羊毛纤维和涤纶
3. **塑料制品的鉴别**：通过外观、手感、燃烧现象区分不同塑料

## 知识拓展
- **绿色化学12原则**：1998年，美国化学家阿纳斯塔斯和沃纳提出了绿色化学12原则，核心思想包括：防止废物产生优于事后处理、设计更安全的化学反应、使用可再生原料、设计可降解产品等。绿色化学不是禁止使用化学品，而是从分子设计层面让化学反应本身变得更加环保。
- **化学在新能源中的角色**：锂电池是当今最重要的储能技术——锂离子在正极和负极之间迁移实现充放电，这一过程完全依赖化学反应。新型钙钛矿太阳能电池的光电转换效率已超过26%，其关键材料的合成和性能优化都是化学研究的前沿。氢能的规模化也需要化学突破催化剂和储氢材料。
- **新材料的发展趋势**：生物可降解材料（如聚乳酸PLA）正在逐步替代传统塑料；碳纤维复合材料使飞机重量减轻20%~40%；自修复材料能在受损后自动修复裂纹；气凝胶是密度最低的固体材料（99.8%是空气），隔热性能极佳。材料科学的每一次突破，往往都源于化学合成与结构设计的创新。

## 竞赛衔接
- **元素与健康**：人体必需元素的生理功能和缺乏症

- **环境监测**：水质、空气质量的监测指标和方法

## 常见易错
| 易错点 | 正确理解 |
|-------|---------|
| 人体所需元素都从食物中获取 | 人体所需元素主要从食物中获取，但水和空气也提供部分元素 |
| 所有食品添加剂都是有害的 | 合理使用的食品添加剂是安全的，过量或滥用才有害 |
| 合成材料一定比天然材料好 | 各有优缺点，应根据用途选择合适材料 |
| 绿色化学就是不使用化学物质 | 绿色化学是合理使用化学物质，从源头减少污染 |
| 塑料都是白色污染 | 可降解塑料和回收利用的塑料不是白色污染 |
| 任何垃圾都可以填埋处理 | 有害垃圾需特殊处理，可回收垃圾应分类回收 |
