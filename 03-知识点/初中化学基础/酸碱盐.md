# 酸碱盐

## 课标要求
- 了解酸碱指示剂的作用，会使用pH试纸测定溶液酸碱度
- 掌握常见酸（HCl、H₂SO₄）和碱（NaOH、Ca(OH)₂）的性质
- 理解中和反应的概念和应用
- 了解常见盐的性质，掌握复分解反应发生的条件

## 核心概念

### 溶液的酸碱性
**酸碱指示剂**是能检验溶液酸碱性的物质，常见的有紫色石蕊溶液和无色酚酞溶液。

| 指示剂 | 酸性溶液 | 中性溶液 | 碱性溶液 |
|-------|---------|---------|---------|
| 紫色石蕊溶液 | 红色 | 紫色 | 蓝色 |
| 无色酚酞溶液 | 无色 | 无色 | 红色 |

**使用注意**：
- 指示剂只能检验溶液的酸碱性，不能测定酸碱度
- 酸碱指示剂本身是有机弱酸或弱碱，在不同pH环境下结构变化导致颜色变化

### pH的概念和测定
**pH**是表示溶液酸碱度的数值，范围通常为0~14：
- pH < 7：酸性溶液（pH越小，酸性越强）
- pH = 7：中性溶液
- pH > 7：碱性溶液（pH越大，碱性越强）

**pH试纸使用方法**：
1. 在白瓷板或玻璃片上放一小片pH试纸
2. 用干燥、洁净的玻璃棒蘸取待测溶液点到pH试纸上
3. 把试纸显示的颜色与标准比色卡对照，读出pH

**注意**：不能将pH试纸直接浸入待测溶液中，否则会污染试剂。

### 常见的酸
**盐酸（HCl）**：无色液体，有刺激性气味，能与多种物质反应。

**硫酸（H₂SO₄）**：无色黏稠液体，有吸水性，浓硫酸有强腐蚀性。

**酸的化学性质**：
1. **与指示剂反应**：酸溶液能使紫色石蕊溶液变红
2. **与活泼金属反应**：生成盐和氢气（如Mg + 2HCl = MgCl₂ + H₂↑）
3. **与金属氧化物反应**：生成盐和水（如Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O）
4. **与碱反应**：发生中和反应生成盐和水

**浓硫酸的稀释**：一定要将浓硫酸沿容器内壁慢慢注入水中，并不断搅拌。切不可将水倒入浓硫酸中，否则会导致酸液飞溅。

### 常见的碱
**氢氧化钠（NaOH）**：白色固体，易潮解，有强烈腐蚀性，俗称苛性钠、火碱或烧碱。

**氢氧化钙（Ca(OH)₂）**：白色粉末，微溶于水，水溶液俗称石灰水，对皮肤、衣服有腐蚀作用。

**碱的化学性质**：
1. **与指示剂反应**：碱溶液能使紫色石蕊溶液变蓝，使无色酚酞溶液变红
2. **与非金属氧化物反应**：生成盐和水（如CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O）
3. **与酸反应**：发生中和反应生成盐和水

**酸和碱的共性**：
- 酸溶液中都含有H⁺，所以酸有相似的化学性质
- 碱溶液中都含有OH⁻，所以碱有相似的化学性质

### 酸碱中和反应
**中和反应**是酸与碱作用生成盐和水的反应：
$$
\text{酸} + \text{碱} = \text{盐} + \text{水}
$$

**典型反应**：
- NaOH + HCl = NaCl + H₂O（氢氧化钠与盐酸反应）
- Ca(OH)₂ + 2HCl = CaCl₂ + 2H₂O（氢氧化钙与盐酸反应）
- 2NaOH + H₂SO₄ = Na₂SO₄ + 2H₂O（氢氧化钠与硫酸反应）

**中和反应的应用**：
1. **医药**：服用含Al(OH)₃的药物治疗胃酸过多
2. **农业**：用熟石灰中和酸性土壤
3. **工业**：处理工厂排放的酸性或碱性废水

### 常见的盐
**氯化钠（NaCl）**：食盐的主要成分，维持人体正常生理活动所必需。

**碳酸钠（Na₂CO₃）**：俗称纯碱、苏打，是重要的工业原料。

**碳酸氢钠（NaHCO₃）**：俗称小苏打，是制作面点发酵粉的主要成分，可治疗胃酸过多。

**碳酸钙（CaCO₃）**：石灰石、大理石的主要成分，可用作建筑材料和补钙剂。

**碳酸盐的检验**：组成里含有碳酸根离子或碳酸氢根离子的盐都能与盐酸反应，生成二氧化碳气体（能使澄清石灰水变浑浊）。

### 复分解反应的条件
**复分解反应**是两种化合物互相交换成分，生成另外两种化合物的反应。

**发生条件**：反应物都可溶，生成物中必须有**沉淀**、**气体**或**水**之一。

**常见沉淀**：
- 碳酸盐沉淀：CaCO₃、BaCO₃等（能与酸反应生成CO₂）
- 硫酸盐沉淀：BaSO₄（不溶于酸）
- 氯化物沉淀：AgCl（不溶于酸）
- 碱：Cu(OH)₂、Fe(OH)₃等（能与酸反应）

## 关键实验
1. **酸碱指示剂实验**：验证石蕊和酚酞在酸碱溶液中的颜色变化
2. **pH试纸测定**：学习正确使用pH试纸测定溶液的酸碱度
3. **浓硫酸稀释**：掌握浓硫酸稀释的正确操作方法，理解安全注意事项
4. **中和反应实验**：用酚酞作指示剂，验证氢氧化钠与盐酸的反应
5. **碳酸盐与酸反应**：检验碳酸根离子的存在

## 知识拓展
- **酸碱理论的演变**：酸碱理论经历了三次飞跃——阿伦尼乌斯理论（酸电离出H⁺，碱电离出OH⁻）适用于水溶液体系；布朗斯特-劳里理论将酸碱定义扩展为质子的给予者和接受者，解释了NH₃在水中显碱性等现象；路易斯理论进一步扩展为电子对的接受者和给予者，解释了AlCl₃、BF₃等不含氢的"酸"。这一演变过程展示了化学理论从特殊到一般的发展轨迹。
- **pH在生活中的应用**：人体血液的pH维持在7.35~7.45之间，偏离这个范围会危及生命。胃液pH约为1.5~2.0（强酸性，帮助消化蛋白质），皮肤表面pH约为5.5（弱酸性，抑制细菌），洗发水的pH通常控制在5~7之间以保护头皮。了解pH有助于科学选择日用品。
- **缓冲溶液的概念**：缓冲溶液是能抵抗少量酸或碱的加入而保持pH基本不变的溶液，通常由弱酸及其盐（如CH₃COOH/CH₃COONa）或弱碱及其盐组成。人体血液中的碳酸/碳酸氢根缓冲体系（H₂CO₃/HCO₃⁻）是维持血液pH稳定的关键。缓冲作用的原理将在高中化学"弱电解质的电离平衡"中详细学习。

## 竞赛衔接
- **酸碱强弱比较**：强酸强碱与弱酸弱碱的区分
- **离子共存问题**：判断离子在溶液中能否大量共存
- **复分解反应方程式书写**：正确书写化学方程式，标注沉淀和气体符号
- **中和滴定**：酸碱中和反应的定量分析

## 常见易错
| 易错点 | 正确理解 |
|-------|---------|
| 酸溶液显酸性，显酸性的溶液一定是酸 | 酸溶液一定显酸性，但显酸性的溶液不一定是酸（如NH₄Cl溶液） |
| 碱溶液显碱性，显碱性的溶液一定是碱 | 碱溶液一定显碱性，但显碱性的溶液不一定是碱（如Na₂CO₃溶液） |
| 中和反应一定是酸和碱的反应 | 中和反应特指酸与碱反应生成盐和水，酸与金属氧化物反应生成盐和水不是中和反应 |
| 所有盐都含有金属离子 | 铵盐（如NH₄Cl）不含金属离子，含有铵根离子 |
| pH试纸使用前需润湿 | 测定溶液pH时，pH试纸不能润湿，否则会稀释待测液，导致测量不准确 |
| 浓硫酸稀释时将水倒入浓硫酸中 | 一定要将浓硫酸沿容器内壁慢慢注入水中，并不断搅拌 |

## 教学视角
- **概念建构**：从宏观现象（指示剂变色）到微观解释（H⁺和OH⁻的作用）
- **分类思想**：从物质类别认识酸、碱、盐的性质，建立物质分类观
- **实验探究**：通过对比实验探究酸碱的化学性质
- **实际应用**：联系生活实际（胃药、土壤改良、废水处理）理解化学价值
- **安全意识**：强调实验安全，特别是浓硫酸的腐蚀性和中和反应的放热
