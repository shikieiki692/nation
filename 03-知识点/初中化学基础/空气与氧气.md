# 空气与氧气

## 课标要求

1. 了解空气的主要成分，认识空气是混合物
2. 了解氧气的物理性质和化学性质
3. 掌握氧气的实验室制取方法
4. 了解空气污染与防治，增强环保意识

## 核心概念

### 一、空气的组成

空气是由多种气体组成的混合物。按体积计算，空气的成分大约为：

| 成分 | 体积分数 | 主要性质 |
|------|---------|---------|
| 氮气（N₂） | 78% | 无色无味，化学性质不活泼 |
| 氧气（O₂） | 21% | 无色无味，化学性质比较活泼 |
| 稀有气体 | 0.94% | 无色无味，化学性质很不活泼 |
| 二氧化碳（CO₂） | 0.03% | 无色无味，不能燃烧也不支持燃烧 |
| 其他气体和杂质 | 0.03% | 含量极少 |

![空气成分示意图](人教版初中化学教材/义务教育教科书·化学九年级上册_images/f9d2ed73aed60b8a6f3ee92cba241c8634af828ac5464433bf375fa220f40132.jpg)

**拉瓦锡测定空气组成**：
法国化学家拉瓦锡通过汞与氧气的反应，首次科学测定了空气的组成。他将汞放在密闭容器中加热12天，发现一部分汞变成红色粉末，同时空气体积减小。证明了空气由氧气和氮气组成。

### 二、氧气的性质

**物理性质**：
- 无色、无味的气体
- 密度比空气略大（标准状况下1.429 g/L，空气1.293 g/L）
- 不易溶于水（1L水约溶解30mL氧气）
- 低温高压下可变为淡蓝色液体或固体

**化学性质**：氧气的化学性质比较活泼，能与许多物质发生反应。

| 物质 | 在空气中燃烧现象 | 在氧气中燃烧现象 | 反应文字表达式 |
|------|-----------------|-----------------|---------------|
| 木炭 | 红热 | 发出白光，放热 | 碳 + 氧气 → 二氧化碳 |
| 硫 | 淡蓝色火焰 | 蓝紫色火焰，放热 | 硫 + 氧气 → 二氧化硫 |
| 铁丝 | 红热，不能燃烧 | 剧烈燃烧，火星四射，生成黑色固体 | 铁 + 氧气 → 四氧化三铁 |

**氧化反应与化合反应**：
- **氧化反应**：物质与氧气发生的反应
- **化合反应**：由两种或两种以上物质生成另一种物质的反应（多变一）
- 缓慢氧化：进行得很慢，不易被察觉的氧化反应（如食物腐烂、呼吸作用）

### 三、氧气的实验室制取

**高锰酸钾制取氧气**：
- 反应原理：高锰酸钾 → 锰酸钾 + 二氧化锰 + 氧气
- 装置：加热固体制气体
- 收集方法：排水法或向上排空气法
- 注意事项：试管口放棉花，防止高锰酸钾粉末进入导管

**过氧化氢制取氧气**：
- 反应原理：过氧化氢 → 水 + 氧气
- 装置：固液不加热型
- 催化剂：二氧化锰（加快反应速率，本身质量和化学性质不变）
- 优点：操作简便，安全

**工业制取氧气**：
- 原理：分离液态空气法（利用液态氮和液态氧沸点不同）
- 过程：空气 → 加压降温 → 液态空气 → 升温 → 氮气先蒸发 → 剩余主要是液态氧

### 四、催化剂

**定义**：在化学反应里能改变其他物质的化学反应速率，而本身的质量和化学性质在反应前后都没有发生变化的物质。

**催化剂的特点（一变二不变）**：
1. 改变化学反应速率（加快或减慢）
2. 反应前后质量不变
3. 反应前后化学性质不变

**注意**：
- 催化剂只改变化学反应速率，不影响生成物的质量
- 催化剂在反应前后的化学性质相同
- 催化剂具有选择性，不同反应使用不同催化剂

### 五、空气污染与防治

**空气污染的主要来源**：
- 工业废气排放
- 汽车尾气排放
- 化石燃料燃烧
- 建筑扬尘

**主要污染物**：
- 二氧化硫（SO₂）：形成酸雨
- 一氧化碳（CO）：有毒
- 二氧化氮（NO₂）：形成酸雨和光化学烟雾
- 可吸入颗粒物（PM10、PM2.5）
- 臭氧（O₃）

**防治措施**：
1. 使用清洁能源（太阳能、风能等）
2. 加强空气质量监测
3. 植树造林
4. 工业废气处理后排放
5. 减少汽车尾气排放

## 关键实验

### 实验2-1：氧气的检验

**实验目的**：验证氧气能支持燃烧

**实验步骤**：
将带有火星的木条插入盛有氧气的集气瓶中

**实验现象**：
木条复燃

![氧气可以使带有火星的木条复燃](人教版初中化学教材/义务教育教科书·化学九年级上册_images/9e5392e8573731fe3b6b604a1cf87594506ca04dab46e71a01097a292c8dcc4e.jpg)

**结论**：
氧气能支持燃烧，具有助燃性

### 实验2-2：木炭在氧气中燃烧

**实验目的**：观察木炭在氧气中燃烧的现象

**实验步骤**：
1. 用坩埚钳夹取木炭在酒精灯上加热至红热
2. 插入盛有氧气的集气瓶中

**实验现象**：
木炭在氧气中发出白光，放出热量

**操作要点**：
- 由瓶口向下缓慢插入，使木炭与氧气充分反应

### 实验2-4：铁丝在氧气中燃烧

**实验目的**：观察铁丝在氧气中燃烧的现象

**实验步骤**：
1. 将铁丝盘成螺旋状
2. 在下端系一根火柴
3. 点燃火柴，待快燃尽时插入氧气瓶中

**实验现象**：
铁丝剧烈燃烧，火星四射，生成黑色固体

**操作要点**：
- 集气瓶底部预先放少量水或细沙，防止高温熔融物炸裂瓶底

## 知识拓展
- **拉瓦锡发现空气组成的历史**：1774年，拉瓦锡用精密天平将汞在密闭容器中加热12天，发现约1/5的空气被消耗，生成红色氧化汞粉末。他还将氧化汞加热分解，成功回收了氧气。这个实验彻底推翻了空气是单一元素的旧观念，开启了现代化学的大门。
- **臭氧层与紫外线**：平流层中的臭氧（O₃）能吸收太阳紫外线，保护地球生物。臭氧层空洞主要由氟利昂（CFCs）分解产生氯原子催化O₃分解所致。一个氯原子可破坏约10万个臭氧分子，这说明了催化剂在大气化学中的巨大影响力。
- **氧气在工业中的应用**：炼钢工业中，向高温铁水中吹入纯氧可去除碳、硫、磷等杂质，大幅提高钢的质量。氧炔焰（乙炔在纯氧中燃烧，温度可达3000°C以上）广泛用于金属切割和焊接。工业制氧主要采用深冷分离液态空气法，日产氧气可达数百吨。

## 常见易错

| 易错点 | 错误理解 | 正确理解 |
|-------|---------|---------|
| 空气中含量最多的是氧气 | 氧气含量最多（21%） | 氮气含量最多（78%） |
| 铁丝在空气中能燃烧 | 铁丝在空气中可以燃烧 | 铁丝在空气中只能红热，不能燃烧 |
| 催化剂能增加生成物质量 | 催化剂使生成物增多 | 催化剂只改变反应速率，不影响生成物质量 |

## 教学视角

### 教学重点
1. 理解空气是混合物，认识各成分的性质和用途
2. 掌握氧气的化学性质和实验室制取方法
3. 建立"性质决定用途"的化学观念

### 教学路径
1. 从空气组成入手，认识混合物概念
2. 通过实验探究氧气的性质
3. 学习氧气的制取方法，掌握实验技能
4. 了解空气污染，培养环保意识

### 与现实联系
- **日常生活**：呼吸作用需要氧气，空气污染影响健康
- **工业生产**：氧气用于炼钢、焊接，氮气用于食品防腐
- **环境保护**：空气质量监测，减少污染物排放

### 教学建议
1. 通过对比实验（如木炭在空气和氧气中燃烧）加深理解
2. 强调实验安全，特别是铁丝燃烧实验的操作规范
3. 结合生活实例讲解空气污染与防治
4. 培养学生的环保意识和社会责任感
