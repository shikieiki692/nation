# 碳及其氧化物

## 课标要求

1. 了解金刚石、石墨、C₆₀等碳单质的结构和性质差异，认识物质的多样性
2. 掌握二氧化碳的物理性质和化学性质（与水反应、与碱反应）
3. 掌握二氧化碳的实验室制取原理和装置
4. 了解一氧化碳的可燃性、还原性和毒性
5. 了解碳循环与温室效应

## 核心概念

### 1. 碳单质的多样性

同一种碳元素可以组成不同的单质：

| 碳单质 | 结构特点 | 主要性质 | 主要用途 |
|--------|---------|---------|---------|
| 金刚石 | 碳原子呈立体网状排列 | 硬度最大，无色透明，不导电 | 钻石、钻头、切割玻璃 |
| 石墨 | 碳原子呈层状排列 | 质软，灰黑色，导电性好，熔点高 | 铅笔芯、电极、润滑剂 |
| C₆₀ | 60个碳原子构成足球状分子 | 有特殊的物理和化学性质 | 超导、催化、能源、医学 |
| 活性炭 | 疏松多孔结构 | 吸附性强 | 防毒面具、净水、除臭 |

**关键点**：金刚石和石墨物理性质差异巨大的原因是**碳原子的排列方式不同**，而非组成原子不同。

### 2. 碳单质的化学性质

**常温下稳定**：碳单质受日光照射或与空气、水接触都不易变化，古代字画能长期保存不变色。

**高温下活泼**：
- 与氧气反应：
  - 充分燃烧：C + O₂ →(点燃) CO₂
  - 不充分燃烧：2C + O₂ →(点燃) 2CO
- 还原性（还原金属氧化物）：
  - 2CuO + C →(高温) 2Cu + CO₂↑
  - 2Fe₂O₃ + 3C →(高温) 4Fe + 3CO₂↑
- 高温下与CO₂反应：CO₂ + C →(高温) 2CO

### 3. 二氧化碳（CO₂）的性质

**物理性质**：
- 无色无味气体，密度比空气大（相对分子质量44 > 29）
- 能溶于水（1体积水约溶解1体积CO₂）
- 固态CO₂叫"干冰"，升华吸热

**化学性质**：
- 不燃烧、不支持燃烧
- 与水反应：CO₂ + H₂O = H₂CO₃（碳酸使石蕊变红）
- 碳酸不稳定：H₂CO₃ = CO₂↑ + H₂O
- 与石灰水反应：CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O（检验CO₂）

### 4. 二氧化碳的实验室制取

**原理**：大理石/石灰石（CaCO₃）+ 稀盐酸

$$
CaCO_3 + 2HCl = CaCl_2 + H_2O + CO_2↑
$$

**装置**：固液不加热型（长颈漏斗+锥形瓶/试管）

**收集**：向上排空气法（CO₂密度比空气大）

**验满**：将燃着的木条放在集气瓶口，木条熄灭则集满

**检验**：通入澄清石灰水，变浑浊则为CO₂

### 5. 一氧化碳（CO）的性质

| 性质 | 说明 |
|------|------|
| 物理性质 | 无色无味气体，难溶于水，密度略小于空气 |
| 可燃性 | 2CO + O₂ →(点燃) 2CO₂（蓝色火焰） |
| 还原性 | CO + CuO →(加热) Cu + CO₂；4CO + Fe₃O₄ →(高温) 4CO₂ + 3Fe |
| 毒性 | 与血红蛋白结合，使人体缺氧 |
| 相互转化 | 2CO + O₂ →(点燃) 2CO₂；CO₂ + C →(高温) 2CO |

## 关键实验

### 实验1：倾倒CO₂灭火
将CO₂慢慢倒入烧杯，观察到下层蜡烛先熄灭，上层后熄灭。证明CO₂密度比空气大，不燃烧、不支持燃烧。

### 实验2：CO₂与水反应
用石蕊染成紫色的干燥纸花分别做四组实验（喷水、放入CO₂、喷水后放入CO₂、吹干），证明CO₂与水反应生成碳酸。

![[人教版初中化学教材/义务教育教科书·化学九年级上册_images/f89269c294d47b4324767e028873bbe42e10e4014eb0ff4e7105849114a6f212.jpg]]

### 实验3：木炭还原氧化铜
木炭粉末与氧化铜粉末混合加热，黑色粉末变红色，澄清石灰水变浑浊，证明碳具有还原性。

## 知识拓展
- **碳纳米管与石墨烯**：碳纳米管是由石墨层卷曲而成的中空管状结构，其强度是钢的100倍而密度仅为钢的1/6。石墨烯是单层碳原子组成的二维蜂窝状材料，2004年由英国科学家首次分离成功（2010年诺贝尔物理学奖），它是目前最薄、导电性最好的材料，未来可能引发电子技术革命。
- **CO₂与温室效应**：CO₂分子能吸收地球辐射的红外线，使大气保温增强，这就是温室效应。适度的温室效应使地球平均温度维持在15°C左右（否则约-18°C），但人类大量燃烧化石燃料导致CO₂浓度从工业革命前的280 ppm升至如今超过420 ppm，引发全球变暖。科学家正在研究碳捕获与封存技术（CCS）来应对这一挑战。
- **一氧化碳的工业用途**：CO是重要的工业还原剂和化工原料。在高炉炼铁中，CO还原铁矿石：Fe₂O₃ + 3CO → 2Fe + 3CO₂。CO还是合成甲醇、醋酸等化工产品的重要原料。在半导体工业中，高纯CO用于化学气相沉积。值得注意的是，CO的工业价值与其毒性并存，安全生产至关重要。

## 竞赛衔接

1. **碳的同素异形体**：除金刚石、石墨、C₆₀外，还有碳纳米管、石墨烯等新成员，石墨烯是目前最薄的材料（厚度仅0.335nm）
2. **CO₂与NaOH反应**：CO₂ + 2NaOH = Na₂CO₃ + H₂O（吸收CO₂，无明显现象）
3. **温室效应增强因素**：CO₂、CH₄、O₃等都是温室气体
4. **碳循环**：光合作用吸收CO₂，呼吸作用和燃料燃烧释放CO₂

## 常见易错

| 易错点 | 正确理解 |
|--------|---------|
| "金刚石和石墨由不同原子构成" | 错误。都是碳原子构成，只是排列方式不同 |
| "CO₂能使石蕊变红" | 不准确。是CO₂与水反应生成的H₂CO₃使石蕊变红 |
| "CO₂有毒" | CO₂无毒，但不能供给呼吸；有毒的是CO |
| "干冰是冰" | 干冰是固态CO₂，不是水的固态 |
| "碳在氧气中只生成CO₂" | 氧气不充足时生成CO |
| "CO₂和CO可以相互转化" | 正确。2CO+O₂→2CO₂；CO₂+C→2CO（高温） |

## 教学视角

本单元是初中化学"元素化合物"部分的核心内容，体现了"物质的性质决定用途"这一基本化学观念。教学中应注重：

1. **对比思想**：通过CO与CO₂分子组成仅差一个氧原子却性质迥异，理解结构决定性质
2. **实验探究**：CO₂与水反应的实验设计体现了控制变量的科学方法
3. **转化关系**：C、CO、CO₂之间的相互转化是理解碳循环的基础
4. **实际应用**：从灭火、制碳酸饮料到冶金工业，体现化学知识的实用价值
