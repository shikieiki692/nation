# 合成氨

## 一、定义

合成氨（Haber–Bosch 工艺，1909 年 Haber 实验室合成、Bosch 工业化，二人分获 1918/1931 年诺贝尔奖）指由氮气与氢气在**高温高压与铁基催化剂**下直接化合生成氨的工业过程：

- 主反应：N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，ΔH° = −92.4 kJ/mol（放热、气体分子数减少）。
- 净反应零碳问题：工业 H₂ 主要来自天然气重整（CH₄ + H₂O → CO + 3H₂，再水煤气变换），故传统合成氨是重要碳排源；"绿氨"（电解水绿氢 + 空气氮）是当下热点。
- 意义：全球约一半人口的食物依赖合成氨氮肥；氨也是化工（硝酸/炸药/尼龙）与未来能源载体（易液化储氢）。竞赛价值：**热力学（平衡移动）×动力学（催化活化 N≡N）×工程（条件折中、循环分离）**三要素综合分析的教科书案例，34 届决赛 2-5 系列大题以此为舞台。

## 二、考纲对应

本页属化学平衡/热力学/动力学综合应用，对应"合成氨的平衡分析与条件选择"：能用 Le Châtelier 原理与 [[van't Hoff方程]] 分析温度、压力对平衡转化率的影响；解释为何工业取 400–500 °C、200–300 atm 的折中；理解催化剂（Fe₃O₄ 还原成 Fe + K₂O/Al₂O₃ 助剂）只加速不移动平衡；能结合反应物循环与产物分离提高总转化率。决赛 2-5 系列（热力学/平衡组成/催化剂/电化学合成）直接考查。

## 三、核心原理

### 3.1 热力学画像：放热 + 体积减小 → 条件方向明确

- ΔH° = −92.4 kJ/mol（放热）：低温有利平衡（van't Hoff：K 随温度降低而增大）。
- Δn = 2 − (1+3) = −2（气体分子数减少）：高压有利平衡（Kp 表达式含 p² 分母与 p⁴ 分子之比，p 升高向分子数少的一侧移动）。
- 故**热力学指向"低温高压"**：500 K 附近 K 仍可观（约 0.1–1 atm⁻² 量级），而室温 K 很大但速率极低——平衡与速率的矛盾由此展开。

### 3.2 动力学瓶颈：N≡N 键的活化

- N₂ 的 N≡N 键能约 945 kJ/mol，是已知最稳定的双原子分子之一——必须靠催化剂把 N₂ 活化解离。
- 铁催化剂机理（简）：N₂ 与 H₂ 在 Fe 表面化学吸附 → N≡N 逐步解离（N₂ 解离是决速步）→ 表面 N 原子被 H 逐步加氢 → NH₃ 脱附。助剂 K₂O（给电子、促进 N₂ 解离）与 Al₂O₃（结构性载体、防 Fe 烧结）。
- **催化剂只降低活化能、加速到达平衡，不改变平衡位置**——转化率仍由热力学决定。

### 3.3 条件选择的权衡逻辑（答题主框架）

- **温度**：低温利平衡但速率慢 → 工业取 **400–500 °C**（铁催化剂在此温度活性足够、平衡损失可接受）；再低则速率不可行。用 van't Hoff 可量化各温度的 K 与平衡转化率（题-2-5-2）。
- **压力**：高压利平衡但设备与能耗剧增 → 传统 **150–300 atm**（200 atm 附近经济最优）；现代低压工艺（如 100 atm 下改进催化剂）趋势。
- **浓度/循环**：单程转化率仅约 15–25%（受平衡限制）→ 反应后**冷却分离液氨**，未反应的 N₂/H₂ 循环回反应器，使总转化率接近化学计量——"循环+分离"是工程补平衡的关键。
- **催化剂**：提高到达平衡的速率（题-2-5-4：催化剂与电化学语境）。

### 3.4 定量分析工具

- 平衡组成计算：设 N₂/H₂ 投料比 1:3（最优化学计量），Kp = p(NH₃)²/[p(N₂)·p(H₂)³]，联立总压与转化率解 x(NH₃)（题-2-5-3）。
- 温度影响：ln(K₂/K₁) = −(ΔH°/R)(1/T₂ − 1/T₁)（ΔH°<0 → 升温 K 降）——合成氨是 van't Hoff 方程最标准的应用场景。
- 热力学可行性再评估：ΔG° = −RT lnK 判断各温度下反应是否"能进行到可观程度"。

### 3.5 现代方向：绿氨与电化学合成

- **绿氨**：可再生电力电解水制 H₂ + 空分 N₂，全程低碳；氨作氢载体（含氢 17.6 wt%）储运。
- **电化学合成氨**（题-2-5-6）：常温常压电解池中 N₂ 在阴极还原（氮还原反应 NRR），挑战是 N≡N 活化与析氢副反应竞争——Li 介导、熔盐体系等路线；竞赛题常给循环/能垒要求分析。

## 四、关键结论

- 合成氨主反应：放热（−92.4 kJ/mol）+ 分子数减少 → 热力学要低温高压。
- 速率瓶颈是 N≡N 解离：铁催化剂（+K₂O/Al₂O₃ 助剂）解决动力学，不改变平衡。
- 工业条件 = 权衡产物：400–500 °C（平衡 vs 速率）+ 150–300 atm（平衡 vs 成本）+ 循环分离（补单程转化率）。
- 定量：Kp 联立 + van't Hoff 温变 + 投料比 1:3。
- 现代：绿氨（电解水氢）与电化学合成（常温常压 NRR）是低碳方向。

## 五、常见分类或情形

- **按工艺条件**：传统高压 Haber-Bosch（150–300 atm、400–500 °C、Fe 催化）；中低压工艺（改进催化剂，100 atm 上下）。
- **按氢源**：天然气重整（灰氨/蓝氨，CO₂ 排放或捕集）、电解水（绿氨）。
- **按反应器/分离**：单程通过 + 冷却液化分离 + 循环（主流）；膜反应器/电化学（前沿）。
- **按题目语境**：热力学平衡分析（温压对 K/转化率）、动力学（催化剂机理/活化能）、工程经济（条件取舍）、电化学合成（NRR 半反应）。

## 六、适用条件与限制

- 平衡计算默认理想气体与纯组分；高压下实际气体偏离（需逸度修正，竞赛一般忽略）。
- 催化剂有适用温区：低于约 350 °C 铁催化剂活性骤降，故"降到室温最大化平衡"不现实。
- 原料气需脱硫脱毒（CO、硫化物毒化催化剂），否则催化剂失活。
- 单程转化率受平衡限制（约 15–25%），不循环分离则总转化率很低——流程设计是考核点之一。
- 电化学 NRR 目前法拉第效率低、析氢竞争严重，属前沿非成熟工艺。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| "高温有利于合成氨" | 高温加快速率但**降低平衡产率**（放热）；400–500 °C 是速率-平衡折中，不是"高温更有利" |
| "高压无上限有利" | 平衡上高压有利，但设备/压缩成本随压力剧增；工业 150–300 atm 是经济折中 |
| "催化剂提高产率" | 催化剂只加速到达平衡、不移动平衡；产率上限仍由温度压力决定 |
| 反应物循环的目的 | 循环是为了**利用未反应原料提高总转化率**（分离液氨后循环 N₂/H₂），不是改变 K |
| 合成氨 vs 氨氧化 | 合成氨：N₂ + H₂ → NH₃（还原 N 到 −3）；氨氧化：4NH₃ + 5O₂ → 4NO + 6H₂O（氧化 N 到 +2，制硝酸第一步）——方向相反，勿混 |

## 九、典型题型

- **条件判断**：说明为何选 400–500 °C/200 atm/循环分离（三问综合）。
- **K 与温变**：给两温度 K 求 ΔH° 或给 ΔH° 求新温度 K（van't Hoff 应用）。
- **平衡组成**：投料 1:3、总压、Kp → 求平衡转化率与 NH₃ 摩尔分数。
- **催化剂分析**：解释 Fe 催化剂 + 助剂作用、为何催化剂不提高平衡转化率。
- **电化学/前沿**：氮还原半反应书写、与析氢竞争的分析（2-5-6）。

## 十、例题

**例题 1**：N₂ + 3H₂ ⇌ 2NH₃，ΔH° = −92.4 kJ/mol。解释工业为何不用"极低温+极高压力"来最大化平衡转化率。

**解答**：热力学上低温高压确实使平衡转化率最大（放热+分子数减少）；但①铁催化剂在约 350 °C 以下活性急剧下降，低温下到达平衡极慢、无法工业化；②压力超过约 300 atm 后设备（厚壁反应器、压缩机）与能耗成本陡增，收益递减。工业 400–500 °C、150–300 atm 是"平衡产率 × 反应速率 × 工程成本"三者的最优折中——用 van't Hoff 可算出各温度的 K 再结合动力学判断。

**例题 2**：某合成氨体系总压 200 atm、投料比 N₂:H₂ = 1:3，500 °C 时 Kp = 0.027 atm⁻²。设平衡时 NH₃ 分压为 x，写出 Kp 表达式并说明如何求转化率。

**解答**：设 N₂ 分压 p、H₂ 分压 3p、NH₃ 分压 2a 初值经转化：平衡时 N₂: P−a、H₂: 3(P−a)、NH₃: 2a（a 为反应的 N₂ 分压降），总压 P = 4(P−a) + 2a = 4P − 2a → a = 1.5P − 0.5P总？更稳妥用摩尔分数：Kp = x(NH₃)²·P² / [x(N₂)·x(H₂)³·P⁴] = x(NH₃)²/[x(N₂)x(H₂)³·P²]；把 x 用转化率 α 表示（1−α、3(1−α)、2α，总量 4−2α）代入解方程即得 α——实操中 34 届 2-5-3 正是此类：先写 Kp 与总压关系、再数值求解平衡组成。

**例题 3**：比较传统热 Haber 工艺与电化学合成氨（NRR）在"活化 N₂"上的差异。

**解答**：热工艺靠高温 + Fe 催化剂表面使 N≡N 解离（决速步活化能约 100+ kJ/mol 被催化降低）；电化学 NRR 希望在常温常压下用阴极电子+质子直接把 N₂ 还原为 NH₃（N₂ + 6H⁺ + 6e⁻ → 2NH₃），绕过高温——挑战是 N₂ 惰性导致的动力学缓慢，以及水还原析氢（2H⁺ + 2e⁻ → H₂）的竞争，故当前选择性/法拉第效率低。两者殊途同归：都是"活化 N≡N"这一化学难题的不同供能方式（热/电）。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为高温对合成氨有利 | 反应放热，升温使 K 与平衡转化率**下降**；高温只为速率 | 反例：500 °C 转化率低于 400 °C——题目问"为何不更低温度"要答催化剂活性与速率，不是"低温不利平衡" |
| 忽略压力成本说"压力越高越好" | 平衡上高压有利，但工程成本非线性增长；工业值约 200 atm 为经济点 | 判别：谈"工业实际条件"必带成本维度；纯热力学题才可无限加压 |
| 以为催化剂提高转化率 | 催化剂不改变 K 与平衡位置，只加快到达平衡 | 反例：加催化剂前后平衡转化率相同——"催化剂提高产率"是经典误区 |
| 单程转化率低就认为工艺差 | 循环分离使总转化率接近化学计量；单程 15–25% 是平衡限制下的常态 | 判别：看到"冷却分离+循环"流程即知总转化率高——单程 vs 全程要分清 |
| Kp 表达式的量纲/投料比搞错 | Kp = x(NH₃)²/[x(N₂)x(H₂)³·P²]（用分压则无 P 因子）；投料 1:3 最优——系数代错全错 | 自检：先写分压式再换摩尔分数；Δn=−2 使 Kp 有 atm⁻² 量纲，别丢掉 P 项 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
合成氨是热力学与动力学综合应用的经典案例，应在学习化学平衡和 Le Châtelier 原理之后引入。先分析反应的热力学特征（放热、体积减小），再讨论温度和压强对平衡的影响（定量用 van't Hoff），然后理解催化剂的作用与活化 N≡N 的动力学瓶颈，最后用 34 届 2-5 系列题把"条件选择+平衡计算+前沿电化学"串起来。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 高温有利于合成氨 | 高温虽加快速率但降低平衡产率（放热反应），工业温度是平衡-速率折中 |
| 高压总是有利的 | 高压利于平衡但设备成本剧增，工业一般用 150–300 atm 的经济折中 |
| 催化剂能提高平衡产率 | 催化剂只加快到达平衡的速率，不改变平衡位置与 K |
| 单程转化率低 = 工艺不经济 | 靠冷却分离 + 循环未反应气，总转化率可接近化学计量 |

### 12.3 入门级例题
**题目**：N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，ΔH° = −92.4 kJ/mol。为什么工业采用高压与中温并加入铁催化剂？

**解答**：高压使平衡右移（分子数减少）；中温（400–500 °C）是"低温利平衡但速率慢"的折中；铁催化剂降低 N≡N 解离活化能、加快到达平衡，但不改变平衡位置。三者分别对应平衡、速率与工程三把尺子。

### 12.4 与现实世界的联系
1. **粮食生产**：合成氨氮肥养活了全球约一半人口（Haber–Bosch 被称为"养活世界人口的反应"）。
2. **清洁能源**：绿氢+绿氨被视为未来的储氢/能源载体（氨含氢 17.6 wt%、易液化）。
3. **航天燃料**：液氨/氨分解氢可作推进剂氢源；氨也是硝酸、炸药的工业源头。
