# 酸碱强度

## 核心概念

酸碱强度用于衡量酸或碱在溶液中给出或接受质子的能力，通常用pKa、pKb或pH值来量化比较。

**三组概念的边界**（第一关辨析）：
- **酸强度**：由 Ka（或 pKa = −log Ka）表征，是**热力学固有属性**，与浓度无关——0.1 mol/L 与 0.0001 mol/L 盐酸的"酸强度"相同（都是强酸、Ka 都极大），只是 pH 不同。
- **酸量/浓度**：溶液中酸的总量（mol/L），可高可低。
- **pH**：溶液中实际的 [H⁺] 负对数，由"强度 × 浓度 + 其它平衡"共同决定。

"强度"回答"这个酸分子多想给出质子"，"浓度"回答"有多少酸分子"，"pH"回答"溶液最终多酸"——三把尺子别混。

**量化链**：Ka 越大 → pKa 越小 → 酸越强。共轭碱的强度反比：酸越强共轭碱越弱。水溶液中 Ka·Kb = Kw = 1.0×10⁻¹⁴（25°C），故 pKa + pKb = 14——酸强度与共轭碱强度在数值上被水"锁死"互补。

## 强度分档与参照

| 档次 | pKa 范围 | 典型代表 |
|---|---|---|
| 强酸 | < 0（水中完全电离） | HClO₄、HI、HBr、HCl、H₂SO₄（一级）、HNO₃ |
| 中强酸 | 0~5 | H₃PO₄(2.1)、HF(3.2)、HNO₂(3.3)、HCOOH(3.75) |
| 弱酸 | 5~10 | HAc(4.76)、H₂CO₃(6.4)、H₂S(7.0)、HClO(7.5)、HCN(9.2) |
| 极弱酸 | > 10 | 苯酚(10)、水(14)、乙醇(16)、NH₃(约 33 气相/水中间接) |
| 强碱 | pKb < 0 | NaOH、KOH、Ca(OH)₂ |
| 弱碱 | pKb > 0 | NH₃(4.75)、甲胺(3.4)、吡啶(8.8) |

**记忆锚 pKa 序列**：HClO₄(−10) < HI(−9) < HBr(−9) < HCl(−7) < H₂SO₄(−3) < HNO₃(−1.3) < H₃O⁺(0) < H₃PO₄(2.1) < HF(3.2) < HAc(4.76) < H₂CO₃(6.4) < H₂S(7) < HClO(7.5) < HCN(9.2) < 苯酚(10) < H₂O(14)——这一段是含氧酸/氢化物酸强度比较的标尺。

## 影响强度的结构因素

**通用判据：看共轭碱 A⁻ 的稳定性——A⁻ 越稳定，HA 酸性越强。**

| 因素 | 机制 | 示例（pKa 递减=酸性增） |
|---|---|---|
| 电负性（同周期氢化物） | 吸电子使 H 更易脱 | CH₄(~50) > NH₃(33) > H₂O(14) > HF(3.2) |
| 键能/半径（同族氢化物） | 键长增长键易断、A⁻ 分散 | HF(3.2) < HCl(−7) < HBr(−9) < HI(−9)：**同族看键能不看电负性** |
| 诱导效应 | 吸电子基稳定共轭碱 | Cl₃CCOOH(0.7) < ClCH₂COOH(2.9) < CH₃COOH(4.76) |
| 共振/离域 | 负电荷离域稳定 A⁻ | 苯酚(10) < 乙醇(16)；羧酸(4.8) < 醇(16) |
| 杂化 s 成分 | s 成分高、电负性大 | 炔烃(25) < 烯烃(44) < 烷烃(50)——sp > sp² > sp³ |
| 溶剂化 | 溶剂稳定离子 | 气相酸性顺序与水中可能反转（水中 HF 弱因 F⁻ 强水合？实际 HF 弱因 H—F 键强） |

**两条铁律防翻车**：① 同周期比电负性（HF > H₂O > NH₃）；② 同族比键长/半径（HI > HBr > HCl > HF——"HF 是弱酸"是这条的著名例外产物）。**卤素氢化物酸性与电负性顺序相反**是最高频陷阱。

## 拉平效应与区分效应

**拉平效应**：在强质子溶剂（如水）中，比 H₃O⁺ 强的酸全部"拉平"到 H₃O⁺ 水平——HClO₄、HI、HBr、HCl 在水中都是 100% 电离，**测不出强弱差异**。同理比 OH⁻ 强的碱被拉平到 OH⁻。强酸强弱只能"看 pKa 理论值"，水中无法实验区分。

**区分效应**：改用**碱性更弱/无质子溶剂**可区分强酸：
- 冰醋酸（碱性弱于水）中 HClO₄ > HBr > HCl 强弱分明（电导法可测）
- 液氨中甚至可区分 NaOH 与 KOH 的碱强度
- 气相酸度（质子亲和能）给出"无溶剂"的本征顺序

**竞赛考法**：① 解释"为什么 HClO₄ 与 HCl 在水中酸性无法比较"（拉平）；② 选溶剂区分强酸（冰醋酸）；③ 判断某碱在液氨/醋酸中的强度变化。拉平效应别名被本页承接，相关内容见本节与 [[酸碱理论]]。

## pKa 预测反应方向（酸强碱弱规则）

**规则**：质子转移方向总是"强酸 + 强碱 → 弱酸 + 弱碱"，即平衡偏向 pKa 较大（较弱酸）一侧。

例：HAc (pKa 4.76) + NaHCO₃ → H₂CO₃ (6.4) 分解 CO₂——HAc 强于 H₂CO₃，反应可行（食醋除水垢）。反例：苯酚 (10) 与 NaHCO₃ 不反应（苯酚弱于 H₂CO₃），但与 NaOH 反应（14 > 10）——**"苯酚溶 NaOH 不溶 NaHCO₃"是酸强度判断的经典应用**。

一般规则：RCOOH + R'OH ⇌ RCOOR' 的平衡、胺的质子化程度、缓冲 pH 区间的选择，统统由比较 pKa 完成——**pKa 差 5 个单位约对应平衡常数差 10⁵**。

## 强度 vs 浓度的混淆陷阱（数值例）

**题目**：比较 0.01 mol/L HCl 与 1.0 mol/L HAc 的"酸性"。

**解答**：若指**强度**——HCl 是强酸（完全电离）远强于 HAc（弱酸），与浓度无关；若指 [H⁺]/pH——HCl: [H⁺] = 0.01，pH = 2；HAc: [H⁺] = √(1.8×10⁻⁵×1.0) = 4.2×10⁻³，pH = 2.37——**浓弱酸的实际 [H⁺] 仍低于稀强酸**（强度差异 > 浓度补偿）。

**结论**：任何浓度下强酸 [H⁺] 贡献能力都碾压弱酸——除非弱酸浓度高到天文数字。题目若说"浓醋酸比稀盐酸酸"必错。

## pKa 应用速查表（去质子试剂选择）

| 目标底物 | 需拔的 H（pKa） | 适用试剂 |
|---|---|---|
| 末端炔烃 | sp C—H（~25） | NaNH₂、LDA（不能用 NaOH/NaOR） |
| 醇 | O—H（16~18） | NaH、Na（强碱且不给亲核竞争） |
| 水 | O—H（14） | NaOH 即可 |
| β-二羰基 | α-H（~11~13） | 乙醇钠/NaH |
| 苯酚 | O—H（10） | NaOH（但不用 NaHCO₃） |
| 羧酸 | O—H（~5） | NaHCO₃（弱碱即可，选择性拔羧酸 H） |
| 胺盐 | N—H（~9~10） | NaOH 中和 |

**规则**：试剂共轭碱的 pKa 须比底物 pKa 大 ~3 以上才"拔得动"（平衡 >99%）。NaHCO₃ 只拔羧酸不碰苯酚、NaNH₂ 才拔得动炔氢——**有机合成中酸强度表就是试剂选择的说明书**。

## 判断速练

1. **排序**：HCl、HF、HAc、H₂O、NH₃ 的酸性 → HCl(−7) > HF(3.2) > HAc(4.76) > H₂O(14) > NH₃(33)——注意 HF 强于 HAc（氢键/键能讨论）但远弱于 HCl。
2. **解释**：为什么对硝基苯酚（pKa 7.2）强于苯酚（10）？——NO₂ 吸电子共轭+诱导稳定苯氧负离子；对甲氧基苯酚（10.2）更弱——OCH₃ 给电子 destabilize 负电荷。
3. **选碱**：要把 CH₃COCH₃ 的 α-H（pKa ~20）拔掉——用 LDA（pKa ~36）而非乙醇钠（pKa ~16，不够）。
4. **判方向**：苯酚钠 + 通 CO₂ → 苯酚析出？（H₂CO₃ pKa1 6.4 < 苯酚 10，成立——工业制苯酚原理）。苯酚 + NaHCO₃ 不反应同理。

四题对应四种考法：排序、电子效应解释、试剂选择、平衡方向判断。

**考前回看清单**：① pKa 方向别反（小=强）；② 同族氢化物例外（HF 最弱）；③ 水中强酸拉平；④ 共轭碱稳定则酸强；⑤ 强度/浓度/pH 三概念分离——五项过一遍即可上考场。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| pKa 越小酸性越弱 | pKa = −logKa，pKa 小 = Ka 大 = 强 | HAc pKa 4.76 强于 HCN 9.21（4.76 < 9.21） |
| 强酸 = 浓度大的酸 | 强度是 Ka 属性与浓度无关 | 浓 HAc 仍是弱酸；稀 HCl 仍是强酸 |
| 同族氢化物酸性按电负性排 | 同族 H—X 键长/键能主导，与电负性相反 | HF 弱酸而 HI 强酸（F 电负性最大却酸性最弱） |
| 忽略共轭碱稳定性判据 | 一切结构因素最终作用于 A⁻ 稳定度 | 羧酸 > 醇因为羧酸根共振；苯酚 > 醇因为苯氧负离子离域 |
| 水中比较强酸强弱 | 拉平效应使 HClO₄/HCl 水中无差异 | 用冰醋酸/气相区分；水中只分"强/非强"两档 |
| 判断反应方向用浓度不用 pKa | 平衡方向由热力学（pKa 差）定，浓度只移位置 | 苯酚 + NaHCO₃ 不反应与浓度无关——pKa 10 > 6.4 |

## 🎯 教学视角

### 学习路径建议
酸碱强度应在学习Brønsted酸碱理论之后引入。先理解pKa的定义和物理意义，再学习影响酸碱强度的结构因素（电负性、共振效应、诱导效应等），最后通过pKa值预测酸碱反应方向。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| pKa越小酸性越弱 | pKa越小酸性越强（pKa = -log Ka） |
| 强酸就是浓度大的酸 | 酸的强度（Ka）与浓度无关，浓盐酸和稀盐酸的酸强度相同 |
| 同一元素最高氧化态的含氧酸酸性最强 | 不一定，如HClO（+1）的酸性弱于HClO₄（+7） |

### 入门级例题
**题目**：比较HF（pKa=3.17）和HAc（pKa=4.76）的酸性强弱。
**解答**：HF的pKa更小，说明Ka更大，酸性更强。虽然F⁻的电负性高于CH₃COO⁻，但HF的酸性仍强于HAc。

### 与现实世界的联系
1. **药物设计**：药物分子的pKa影响其在体内的吸收和分布
2. **食品工业**：酸度调节剂的选择依赖于其pKa值
3. **环境科学**：酸雨的pH（~4.2）与H₂SO₄和HNO₃的pKa有关

> **记忆锚**：强度看 pKa 不看浓度；共轭碱稳则酸强；同族氢化物酸性与电负性反着走（HF 最弱）；水中强酸全拉平，区分要用冰醋酸。

## 竞赛考察要点与命题角度

1. **排序题**：给一组酸按 pKa 排序（含氧酸/氢化物/羧酸混合）——先分家族再套因素。
2. **解释题**："为何 HF 酸性弱于 HCl？""为何邻硝基苯酚强于苯酚？"——落到共轭碱稳定性。
3. **拉平/区分**：选溶剂区分 HClO₄ 与 HCl——冰醋酸；判断"水中无法比较"。
4. **反应方向**：用 pKa 表判断某质子转移是否发生（酸强碱弱规则）。
5. **有机酸强度**：Cl₃CCOOH/苯酚/乙醇/炔烃的 pKa 数量级与去质子试剂选择（LDA 拔炔氢等）。

## 溶剂对强度的影响（进阶）

1. **溶剂化稳定离子**：质子溶剂（水、醇）通过氢键稳定 A⁻ 与 H⁺——电离被促进；非质子溶剂中离子对不稳定，酸的电离显著减弱（HAc 在苯中几乎不电离）。
2. **拉平/区分（前文）**：溶剂碱性决定"强酸上限"——水中上限 H₃O⁺（pKa 0），液氨中上限 NH₄⁺，冰醋酸中上限为 CH₃COOH₂⁺（碱性极弱，故可区分强酸）。
3. **气相酸度**：无溶剂时酸性顺序回归本征（气相中 HF 强于 HCl 也是可能的——质子亲和能排序与溶液不同），说明溶剂可翻转相对强度。
4. **同离子/盐效应**：高离子强度下活度系数变化使表观 Ka 偏移（离子强度对 Ka 的影响是活度层面的次级修正）。

**考试落点**：解释"同一对酸碱在不同溶剂中强弱互换"时，回答模板 = "溶剂化能力差异 + 拉平/区分效应"。
