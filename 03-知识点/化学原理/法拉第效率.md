# 法拉第效率

## 核心概念

法拉第效率（电流效率）是电极上实际产物所需电量与总通过电量之比，反映电化学反应的选择性。

**定义式**（两个等价算法）：

法拉第效率 FE = 实际用于目标产物的电量 / 总通过电量 = 目标产物实际量 / 目标产物理论量（按法拉第定律由电量算得）

- 用于**单一目标产物**：η = m_实际/m_理论 = Q_有效/Q_总
- 用于**多产物体系**（如 CO₂ 还原同时得 CO、HCOOH、H₂）：每个产物的分效率 FEᵢ = 该产物消耗的电子数占总电子的比例，各 FEᵢ 之和 < 100%——差额是被未检出副反应/非电子途径（如析氢之外的寄生反应）消耗的部分

**物理意义**：FE = 100% 意味着每一个电子都"干正事"；FE 低说明电流被副反应分流（析氢、析氧、溶剂分解、电极腐蚀等）或传质受限。

## 法拉第定律基础（前置公式）

Q = n·F = I·t

- Q：通过电量（C）；n：发生电极反应的电子摩尔数（mol e⁻）
- F = 96485 C/mol（法拉第常数）
- 产物物质的量 = Q/(zF) = It/(zF)，z 为生成 1 mol 产物所需电子数（如 Cu²⁺ + 2e⁻ → Cu，z = 2）

法拉第效率把"电流—时间"（实验直接可测）与"产物量"（称量/色谱/气相检测）联系起来，是电化学定量分析的核心桥梁。

## 计算流程

1. **算理论产量**：m_理论 = It/(zF) × M
2. **测实际产量**：称量（沉积金属）、气体体积（排水集气）、色谱定量
3. **求效率**：η = m_实际/m_理论 × 100%（或按电子数：η = z·n_产物·F/(It)）

## 与能量效率的区分（高频混淆点）

| 指标 | 定义 | 关注点 |
|---|---|---|
| 法拉第效率（电流效率） | 有效电子占比 | 选择性 |
| 电压效率 | 理论分解电压/实际槽压 | 过电位与欧姆损耗 |
| 能量效率 | FE × 电压效率 | 综合能耗 |

高 FE 不等于低能耗：即使所有电子都用于目标产物，若槽压因过电位高达 3 V（理论 1.23 V），能量效率仍只有约 40%。题目问"为什么 FE 高但能耗高"——答过电位与欧姆降。

## 副反应与传质的影响

- **竞争副反应**：水溶液中阴极析氢（HER）几乎总是与目标还原竞争——催化剂要抑制 HER 提高 FE；阳极析氧（OER）同理。
- **传质限制**：电流密度过大时，反应物来不及扩散到电极表面（极限电流），多余电流只能走副反应 → FE 随电流密度升高而下降。
- **电极结构与电解液**：气体扩散层、pH、缓冲剂、CO₂ 溶解度都影响 CO₂ 还原的 FE。
- **再氧化/交叉**：目标产物在电极附近被再氧化或迁移到对极消耗，也会降低表观 FE。

## 完整算例（含气体体积换算）

**题目**：碱性电解水，以 5.00 A 电解 1.00 h，阴极收集到 H₂ 在 298 K、1 atm 下体积 1.95 L。求阴极析氢的法拉第效率。

**解答**：
- 总电量 Q = 5.00×3600 = 18000 C
- H₂ 理论量（2H₂O + 2e⁻ → H₂ + 2OH⁻，z = 2）：n_理论 = Q/(2F) = 18000/(2×96485) = 0.0933 mol
- V_理论 = nRT/P = 0.0933×8.314×298/101325 = 2.28 L
- η = 1.95/2.28 × 100% = **85.5%**（约 14.5% 电流被阳极氧渗透/膜电阻/副反应等消耗）

**要点**：气体产物用理想气体方程换算体积，注意温度压力条件；z 按电极半反应配平取。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 法拉第效率与能量效率混为一谈 | 一个看电子选择性，一个看综合能耗（FE × 电压效率） | FE = 100% 而槽压 3 V → 能量效率仅约 40% |
| 多产物时各 FE 相加超过 100% | 各产物 FEᵢ 按其消耗电子计，总和应 ≤ 100% | CO₂ 还原 FE(CO) + FE(HCOOH) + FE(H₂) ≤ 100%，余量为未检出副反应 |
| z 取错（电子数） | z 是生成 1 mol 产物的电子数，按半反应配平取 | Cu²⁺→Cu 的 z = 2；O₂ 的 z = 4（4OH⁻ − 4e⁻ → O₂ + 2H₂O） |
| 直接用质量当理论产量 | 理论产量必须先由 It/(zF)×M 算，不是随便一个数 | 上例若用 18000 C 直接折算会漏 F 与 z |
| 忽略副反应只算单一产物 | 实际电解几乎总有竞争反应 | 水溶液阴极 FE < 100% 大概率是析氢分流 |
| 认为 FE 随电流密度恒不变 | 超极限电流密度后 FE 骤降 | 电镀/电解都要在极限电流以下工作 |

## 🎯 教学视角

### 学习路径建议
法拉第效率应在学习[[电解池]]（法拉第电解定律）之后引入，重点理解"电流效率"的物理意义。先掌握法拉第定律计算理论产量，再学习实际产量与理论产量的比值即为法拉第效率，最后分析副反应和传质限制对效率的影响。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 法拉第效率100%是不可能的 | 理想情况下可以达到100%，实际因副反应和传质限制而降低 |
| 电流效率只与电极材料有关 | 还与电解液组成、温度、电流密度、电极结构等多因素有关 |
| 法拉第效率高就意味着能耗低 | 高电流效率不等于低能耗，还需考虑过电位和欧姆损耗 |

### 入门级例题
**题目**：电解CuSO₄溶液，通入2.00 A电流30分钟，阴极实际析出铜0.350 g，求法拉第效率。（M(Cu) = 63.55 g/mol）
**解答**：理论产量 = (2.00×1800)/(2×96485)×63.55 = 1.186 g。效率 = 0.350/1.186 × 100% = 29.5%（效率较低，说明有大量副反应如析氢）。

### 与现实世界的联系
1. **电镀工业**：高法拉第效率意味着更少的电能浪费和更好的镀层质量
2. **电解水制氢**：阳极析氧效率直接影响电解槽的能耗和经济性
3. **电化学CO₂还原**：提高目标产物的法拉第效率是该领域的核心挑战

## 多产物电流分配算例（CO₂ 还原）

**题目**：CO₂ 饱和的 KHCO₃ 溶液中，以 20 mA 恒流电解 1.00 h，阴极气相产物经气相色谱定量：CO 0.150 mmol、H₂ 0.100 mmol（液相甲酸可忽略）。求 FE(CO)、FE(H₂) 与"未解释电流"占比。（CO₂ + 2H⁺ + 2e⁻ → CO + H₂O，z = 2；2H₂O + 2e⁻ → H₂ + 2OH⁻，z = 2）

**解答**：
- 总电量 Q = 0.020×3600 = 72 C → 总电子 n_e = 72/96485 = 7.46×10⁻⁴ mol
- CO 耗电子 = 2×0.150×10⁻³ = 3.00×10⁻⁴ mol → FE(CO) = 3.00/7.46 = **40.2%**
- H₂ 耗电子 = 2×0.100×10⁻³ = 2.00×10⁻⁴ mol → FE(H₂) = 2.00/7.46 = **26.8%**
- 未解释 = 1 − 0.402 − 0.268 = **33.0%**（膜渗透损失、液相产物甲酸、还原后再氧化等）

**要点**：电流守恒是这类题的隐藏条件——Σ(各产物 FE) 与 100% 的差额本身就是题眼，常用来反推被忽略的副产物。

## 常见体系 FE 量级（自检参考）

| 体系 | 典型 FE | 说明 |
|---|---|---|
| 电镀铜/镍（工业） | 95~100% | 成熟工艺，副反应极少 |
| 电解水制氢（碱性） | 95~99% | 高纯体系接近定量 |
| 氯碱工业 | >95% | 隔膜/离子膜抑制副反应 |
| CO₂ 电还原（研究态） | 单产物 20~90% | 催化剂与电位敏感，析氢是主要竞争者 |
| 有机电合成 | 60~90% | 副反应多，需控电位/电流密度 |
| 镁/铝电解 | 85~95% | 高温熔盐体系，电流效率受回溶影响 |

**由 FE 反推经济性**：FE 每降 10 个百分点，单位产品电耗约升 11%——所以工业电解都追求在"极限电流密度以下、副反应拐点以上"的窗口运行。

## 竞赛考察要点与命题角度

1. **基础计算**：It/(zF) 算理论量 → 与实际量比 → FE——套公式两步走。
2. **多产物定量**：给电解产气组成（CO/H₂ 比例），由总电量与各产物物质的量反推各 FE 与电流分配——联立电子守恒。
3. **CO₂ 还原语境（39 届决赛）**：Cu/Ag 催化剂上 CO₂ → CO 与 HER 竞争，给电流密度-电位曲线求某电位下的 FE。
4. **与能量效率辨析**：给出槽压、理论分解电压与 FE，求能量效率 = FE × (E理论/E实际)。
5. **工业参数分析**：电流密度升高 FE 下降的原因（传质极限）——答"极限电流密度"。

> **记忆锚**：法拉第效率问"电子干正事没"，能量效率问"电费花得值不值"；多产物先分 FE 再求和，总和不过百。

## 关键结论速记

- FE = 实际用于目标产物的电量/总电量 = 实际产量/理论产量（It/(zF) 算理论量）。
- 多产物：每产物按"消耗电子数占比"算 FE，ΣFE ≤ 100%，差额指向未检出副反应。
- FE 高 ≠ 能耗低：能量效率 = FE × 电压效率（E理论/E实际），过电位是隐藏扣分项。
- 电流密度超过极限电流 → 传质跟不上 → FE 骤降；催化剂的核心任务是压 HER/OER 提选择性。
- 气体产物算 FE 要过理想气体方程换算体积，别忘了标温度压力。
- 相关题：[[题-39决理-4-电化学CO₂还原]]（39 届决赛）——CO₂ 还原多产物 FE 分配的标准真题。
- 单位自检：Q(C) = I(A)×t(s)；n_e = Q/F；产物体积先算 mol 再过 PV = nRT——三道换算任何一处漏单位，答案差 10³。
- 判定"电子守恒"是否闭合：把 FE 反算回各产物电子数相加，应与 It/F 严格相等——不闭合必有隐藏副产物。
- 读题先标 z：每个电极半反应配平后数电子，Cu 2e⁻、Ag 1e⁻、O₂ 4e⁻、H₂ 2e⁻、CO（CO₂ 还原）2e⁻、CO₂ → CH₄ 8e⁻——电子数错了全题皆错。
- 遇到"恒流电解 + 分时段取样"题：每时段电量独立算，产物累计核对总 FE——时段间 FE 漂移常被用来考"催化剂失活/浓度变化"。
- 复习自检：能独立写出"5 A 电解 2 h 求铜析出量与 FE 反推实际量"的完整过程，本页即达标。

## 术语对照速查（阅读文献/题干用）

| 术语 | 含义 | 与 FE 的关系 |
|---|---|---|
| Faradaic efficiency (FE) | 目标产物电子占比 | 本页主题 |
| Overpotential 过电位 | 实际电位超出平衡电位的部分 | 越大能量效率越低，与 FE 正交 |
| Limiting current 极限电流 | 传质决定的最大电流 | 超过后 FE 下降 |
| Partial current density 分电流密度 | 某产物对应的电流密度 jᵢ | FEᵢ = jᵢ/j总 |
| Selectivity 选择性 | 目标产物相对副产物的优势度 | FE 的另一种表述 |
| Turnover frequency (TOF) | 单位活性位单位时间转化数 | 活性指标，与 FE 互补 |
| Mass transport 传质 | 反应物向电极的扩散/对流 | 受限 → FE 与 j 脱钩 |

**进阶关系**：FE 与 TOF 双高才是好催化剂——FE 高但 TOF 低（电流全走目标产物但总电流小）只说明"选择性好、活性差"。电催化评价三件套：FE、过电位（或 onset 电位）、稳定性。
