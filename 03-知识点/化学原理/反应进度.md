# 反应进度

## 核心概念

- **定义**：$\xi = \frac{\Delta n_B}{\nu_B}$，单位：mol
- **$\nu_B$**：配平方程式中物质B的计量系数（产物为正，反应物为负）
- 同一反应中所有物质的反应进度相同
- 与方程式写法有关（系数不同则 $\xi$ 不同）

**物理图像**：反应进度是描述"反应走了多远"的一把统一标尺。不管盯住哪个物质，用它的物质的量变化除以自己的计量系数，得到的都是同一个数 ξ——这把"各物质变化量不一致"的混乱归一成"一个反应进行了多少 mol"。

**过程量属性**：ξ 描述的是过程的推进程度，不是体系某时刻的固有性质——它随反应进行而增长，是可变量（过程量），这与 U、H 等状态函数不同。

## 关键公式/方程式

### 基本定义
$$\xi = \frac{n_B - n_{B,0}}{\nu_B}$$

### 标准摩尔反应焓
$$\Delta_r H_m^{\theta} = \frac{\Delta H}{\xi}$$

（"m"指反应进度变化1mol）

### 恒容与恒压的关系
$$\Delta_r H_m = \Delta_r U_m + RT \Delta \nu_{\text{gas}}$$

### 反应进度作为一切摩尔反应量的基准

以 ξ = 1 mol 为"一份反应"：

ΔrXm = ΔX/ξ（X = H、U、S、G……）

- 平衡常数 ΔrGm⁰ = −RT·lnK 中的"m"同样是"反应进度 1 mol"；
- 动力学速率定义 r = (1/V)·dξ/dt 也建立在 ξ 上——热力学与动力学共用同一把标尺。

## 典型应用

- 计算反应的热效应（弹式量热计测量 $\Delta U$，需换算为 $\Delta H$）
- 竞赛中注意方程式写法对 $\xi$ 的影响
- 固体不参与 $\Delta n_{\text{gas}}$ 计算

## 完整算例：弹式量热计的 ΔU → ΔH

**题目**：0.500 g 苯甲酸（C₇H₆O₂，M = 122）在弹式量热计中完全燃烧，放热 13.18 kJ。量热计中水与弹体的总热容 C = 8.65 kJ/K。（a）求恒容燃烧热 ΔcU（kJ/mol）；（b）已知燃烧反应 C₇H₆O₂(s) + 7.5O₂(g) → 7CO₂(g) + 3H₂O(l)，Δνgas = 7 − 7.5 = −0.5，求 ΔcH。

**解答**：
（a）n = 0.500/122 = 4.098×10⁻³ mol；ΔcU = −13.18/4.098×10⁻³ = −3216 kJ/mol（负号：放热）。

（b）ΔcH = ΔcU + RT·Δνgas = −3216000 + 8.314×298×(−0.5) = −3216000 − 1239 ≈ **−3217 kJ/mol**。

**要点**：RTΔνgas 项通常只有 1~2 kJ/mol（气体计量差 1 时 ≈ 2.5 kJ），对燃烧焓（千焦量级）是修正项而非主项；但题若问精确值或反应气体计量差大（如 CO 燃烧 Δνgas = −0.5）必须计入。反应进度在这里的作用：把"0.5 g 苯甲酸放热 13.18 kJ"换算成"1 mol 反应（ξ = 1 mol）的热效应"。

## 反应进度与转化率/产率

设反应 aA + bB → cC，A 的初始量 nA0，平衡时消耗 x mol A（ξ = x/a）：

- A 的转化率 αA = x/nA0 = a·ξ/nA0
- C 的物质的量 nC = c·ξ（从 0 开始）
- 平衡组成表（ICE 表）的核心就是"各物质变化 = νB·ξ"——ξ 与 ICE 表是同一件事的两种写法

**竞赛提示**：给出平衡总压/平均摩尔质量求 ξ 是常见题型——先设 ξ，用 νB·ξ 表达各物质的平衡量，再代入理想气体状态方程/分压定律闭合求解。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 反应进度与方程式写法无关 | 同一反应写成 2 倍系数，同样实际进程的 ξ 减半 | N₂+3H₂→2NH₃ 消耗 0.3 mol N₂ 时 ξ = 0.3；写成 ½ 系数则 ξ = 0.6 |
| 把 ξ 当成某物质的物质的量 | ξ 是所有物质共用的"反应程度"，不是任一种物质的量 | 单位虽都是 mol，但 ξ = Δn_B/ν_B 已按系数归一 |
| 恒压 Δngas 计算漏固体/液体 | 只有气态计量系数差计入 Δνgas | CaCO₃(s) → CaO(s)+CO₂(g)：Δνgas = +1 只看气体 |
| 弹式量热直接当 ΔH | 弹式恒容测得 ΔU，须加 RTΔνgas 才是 ΔH | 上例 ΔcH − ΔcU ≈ −1.2 kJ/mol；量热计题几乎必考此换算 |
| 化学计量数符号用反 | ν_B：反应物为负、产物为正 | ξ 恒正：Δn(反应物) < 0 除以负系数才得正 ξ |
| 动力学速率公式忘记除以体积 | r = (1/V)dξ/dt，均相反应 r 有浓度量纲 | 给 V、dξ/dt 求 r 时要除 V；异相反应按面积定义时不同 |

## 竞赛考察要点与命题角度

1. **换算基准题**：给"某物质消耗/生成量"求反应进度，或反求其他物质变化量——νB·ξ 一步到位。
2. **热效应摩尔化**：给非 1 mol 反应的实际放热，用 ξ 归一到 ΔrHm。
3. **ICE 表进阶**：设 ξ 解平衡组成（含分压、Kp 计算），平衡题的标准骨架。
4. **动力学衔接**：速率 = dξ/dt 的归一化定义，比较不同物质"消耗速率"要用计量系数折算（v(N₂):v(H₂):v(NH₃) = 1:3:2）。
5. **多反应体系（决赛）**：同时平衡时引入多个独立 ξ（每反应一个），独立反应数 = 物种数 − 元素数——用 ξ 向量表达总变化。

## 六、🎯 教学视角

### 6.1 学习路径建议
反应进度是热力学计算的基础工具，应在学习化学计量之后引入。先理解"进度"的概念——所有物质按同一比例反应，再掌握反应进度与方程式系数的关系，最后学习如何用反应进度表达摩尔反应焓等热力学量。

### 6.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 反应进度与方程式写法无关 | 同一反应写法不同（系数加倍），反应进度减半 |
| 反应进度的单位是mol就等于物质的量 | 反应进度描述的是反应进行的程度，不是某种物质的量 |
| 固体和液体不影响Δngas | 恒压反应中只有气体的计量系数差参与Δngas计算 |

### 6.3 入门级例题
**题目**：反应 N₂(g) + 3H₂(g) → 2NH₃(g)，当消耗了0.3 mol N₂时，反应进度是多少？
**解答**：ξ = Δn(N₂)/ν(N₂) = (-0.3)/(-1) = 0.3 mol。

### 6.4 与现实世界的联系
1. **化工生产**：反应进度用于计算工业反应器的转化率和产率
2. **电池设计**：锂电池的容量计算依赖于电极反应的进度
3. **环境监测**：大气中污染物的化学转化程度用反应进度描述

## 关键结论速记

- ξ = ΔnB/νB：一反应共用一个 ξ，写式子的写法决定 ξ 数值——先写配平式再谈 ξ。
- "摩尔反应量"（ΔrHm、ΔrGm、ΔrSm）统统指 ξ = 1 mol，与"1 mol 某物质"是两回事。
- 恒压热效应 ΔrHm 与恒容 ΔrUm 换算：ΔrHm = ΔrUm + RTΔνgas（只数气体）。
- ICE 表 = 各物质平衡量 nB0 + νB·ξ：设 ξ 列平衡组成是平衡计算的标准动作。
- 速率折算：不同物质的消耗/生成速率之比 = 计量系数之比（ν 取绝对值）。
- 检查单位习惯：ξ 单位 mol；涉及"每摩尔反应"的热力学量，答案单位一定是 kJ/mol（每 mol 反应）而非 kJ。

## 进阶：多反应体系的反应进度（决赛视角）

体系同时发生 R 个独立反应时，第 i 个反应有自己的进度 ξᵢ，物种 B 的总变化量：

ΔnB = Σᵢ νBᵢ·ξᵢ

独立反应数 R = 物种数 N − 独立元素约束数。例：C(s)、CO(g)、CO₂(g) 体系 N = 3、元素 1 → R = 2（C + CO₂ → 2CO 与 C + ½O₂ → CO 等只能取两个独立组合）。用"每反应一个 ξ"列物料守恒解平衡，是决赛多重平衡题的标准方法。

## 平衡组成数值示例（设 ξ 解平衡）

**题目**：2.0 mol SO₂ 与 1.0 mol O₂ 在恒温恒容下反应 2SO₂ + O₂ → 2SO₃，平衡时测得 SO₂ 转化率 60%。求平衡时各物质的量与总压（体积 10 L，300 K）。

**解答**：设反应进度 ξ（SO₂ 的 ν = −2）：

- 消耗 SO₂ = 2ξ = 2.0×0.60 = 1.2 mol → ξ = 0.6
- n(SO₂) = 2.0 − 1.2 = 0.8；n(O₂) = 1.0 − 0.6 = 0.4；n(SO₃) = 2ξ = 1.2
- 总量 n总 = 0.8 + 0.4 + 1.2 = 2.4 mol
- P = nRT/V = 2.4×8.314×300/0.010 = 5.99×10⁵ Pa ≈ 5.99 bar

**要点**：用"消耗 = |νB|·ξ"从任一物质的转化率一步求 ξ，其余物质的变化量随之而定——比逐物质列 ICE 更不易错。由 ξ 还能直接写 Kp = p(SO₃)²/(p(SO₂)²·p(O₂)) 的分压比。
