# 化学原理

> 本目录涵盖中国化学奥林匹克**基础要求**中的化学原理模块，共 **176 个知识点文件**。
> 所有文件平铺在根目录，无子文件夹。

## 知识模块分布

| 模块 | 核心KP |
|------|--------|
| **热力学** | 焓、熵、Gibbs自由能、热力学第一/第二定律、盖斯定律、标准生成焓、热力学循环 |
| **化学平衡** | 化学平衡、平衡常数、反应商、等温方程、Le Chatelier原理、平衡计算 |
| **化学动力学** | 反应速率、反应级数、速率方程、活化能、Arrhenius方程、半衰期、催化、酶动力学 |
| **溶液与酸碱** | 溶液浓度、溶解度、溶度积、依数性、缓冲溶液、酸碱理论（Brønsted/Lewis） |
| **电化学** | 电化学、原电池、电解池、标准电极电势、Nernst方程、Frost/Latimer/Pourbaix图 |
| **原子结构** | 原子结构、原子轨道、电子排布、量子数、杂化轨道、原子光谱、电负性、电离能 |
| **化学键** | 共价键、离子键、金属键、VSEPR、键参数、范德华力、氢键、离域π键 |
| **配合物** | 配合物命名、异构、几何构型、晶体场理论、高/低自旋、软硬酸碱 |
| **其他** | 核反应、方程式书写、有效数字、密度公式 |
