# 平衡常数

## 一、定义

对于反应 $m\mathrm{A} + n\mathrm{B} \rightleftharpoons p\mathrm{C} + q\mathrm{D}$，在温度 $T$ 下达平衡时，各物质平衡浓度之间恒有：

$$K_c = \frac{[\mathrm{C}]^p[\mathrm{D}]^q}{[\mathrm{A}]^m[\mathrm{B}]^n}$$

$K$ 称为该反应在温度 $T$ 时的**平衡常数**，是表明化学反应**限度**的特征值：

- 由实验直接测定的叫**经验平衡常数（实验平衡常数）** $K$；由 $\Delta_r G_m^{\theta}(T)$ 间接求算的叫**标准平衡常数** $K^{\theta}$。
- 用浓度表示的为 $K_c$；气相反应中用分压表示的为 $K_p$。
- **$K$ 只与温度有关**，与起始浓度、压强、催化剂无关。一个反应在指定温度下只有一个特征平衡常数，但不同起始状态下的转化率可以不同。

## 二、考纲对应

- 对应考纲条目：07-化学平衡
- 所属模块：基础要求-化学原理
- 作用：平衡常数是化学平衡全部定量计算（平衡组成、转化率、平衡移动、酸碱/沉淀/配位/氧化还原各类平衡）的共同语言，是初赛计算题的核心工具。

## 三、核心原理

### 3.1 平衡常数的实验测定（为什么是常数）

**N₂O₄–NO₂ 体系（373 K）**：三组不同起始投料（纯 N₂O₄、纯 NO₂、两者混合），达到平衡后平衡浓度各不相同，但 $[\mathrm{NO_2}]^2/[\mathrm{N_2O_4}]$ 均为 0.36，即

$$K = \frac{[\mathrm{NO_2}]^2}{[\mathrm{N_2O_4}]} = 0.36 \quad (373\ \mathrm{K})$$

**醋酸电离（293 K）**：4 种不同起始浓度的 HAc 溶液，电离度 $\alpha$ 各不相同，但 $K(\mathrm{HAc}) = \dfrac{[\mathrm{H_3O^+}][\mathrm{Ac^-}]}{[\mathrm{HAc}]} = 1.8\times10^{-5}$ 恒定。

**乙醇+醋酸酯化（373 K）**：$K = 4.0$ 不变，但改变投料比时两者转化率此消彼长——乙酸过量可提高乙醇转化率。**平衡常数表征的是"限度"，转化率表征的是"某次具体投料下的实现程度"**，这是两个必须分清的概念。

### 3.2 $K_c$ 与 $K_p$ 的换算

若各气体可视为理想气体（$p = cRT$），则对任意气相反应：

$$K_p = K_c(RT)^{\Delta n}$$

其中 $\Delta n$ = 生成物气体计量系数之和 − 反应物气体计量系数之和；$R$ 的取值单位由分压单位决定（分压用 bar 时 $R = 0.0831\ \mathrm{dm^3\cdot bar\cdot mol^{-1}\cdot K^{-1}}$）。

**例**：$2\mathrm{SO_2}(g) + \mathrm{O_2}(g) \rightleftharpoons 2\mathrm{SO_3}(g)$，$K_p^{\mathrm{bar}}(1000\ \mathrm{K}) = 3.46$，$\Delta n = 2-3 = -1$，则 $K_c = K_p(RT)^{-\Delta n} = 3.46\times(0.0831\times1000)^1 = 288$。

### 3.3 平衡常数的书写规则

1. **表达式与化学方程式一一对应，并注明温度**。同一平衡体系方程式写法不同，$K$ 值不同但含义等价：
   - $\mathrm{N_2O_4}(g) \rightleftharpoons 2\mathrm{NO_2}(g)$，$K = 0.36$（373 K）
   - $\frac{1}{2}\mathrm{N_2O_4}(g) \rightleftharpoons \mathrm{NO_2}(g)$，$K' = \sqrt{0.36} = 0.60$
   - $2\mathrm{NO_2}(g) \rightleftharpoons \mathrm{N_2O_4}(g)$，$K'' = 1/0.36 = 2.8$
2. **纯固体、纯液体（及稀溶液中近似不变的溶剂水）不写入表达式**，其"浓度"归并入常数项。多相平衡实例：
   - $\mathrm{CaCO_3}(s) \rightleftharpoons \mathrm{CaO}(s) + \mathrm{CO_2}(g)$，$K_p = p(\mathrm{CO_2})$
   - $\mathrm{Fe_2O_3}(s) + 3\mathrm{CO}(g) \rightleftharpoons 2\mathrm{Fe}(s) + 3\mathrm{CO_2}(g)$，$K_p = p^3(\mathrm{CO_2})/p^3(\mathrm{CO})$
   - $\mathrm{AgCl}(s) \rightleftharpoons \mathrm{Ag^+}(aq) + \mathrm{Cl^-}(aq)$，$K_c = [\mathrm{Ag^+}][\mathrm{Cl^-}]$（即 [[溶度积]] $K_{sp}$）
3. 醋酸电离、AgCl 沉淀等水溶液反应的 $K$ 在室温附近随温度变化很小，应用时可不注明温度；气相反应的 $K$ 受温度影响大，必须注明（如上述 N₂O₄ 体系 373 K 时 $K=0.36$，423 K 时为 3.2）。

### 3.4 平衡常数与反应方向（$Q$ 与 $K$）

任意时刻的**反应商** $Q$ 与 $K$ 形式相同但用即时浓度/分压代入：

| 关系 | 含义 |
|:---|:---|
| $Q < K$ | 反应正向进行 |
| $Q = K$ | 体系处于平衡 |
| $Q > K$ | 反应逆向进行 |

平衡常数的大小表明反应进行的限度：$K$ 越大，平衡时产物越占优（经验上 $K^{\theta} > 10^6$ 可认为反应进行得很彻底）。

## 四、关键结论

1. $K$ 是温度函数，只随温度改变；浓度、压强、催化剂都不改变 $K$。
2. $K$ 表"限度"，转化率表"实现程度"；$K$ 不变时改变投料可重新分配各反应物的转化率。
3. $K_p = K_c(RT)^{\Delta n}$，只有 $\Delta n = 0$ 时两者数值相等。
4. 方程式系数翻倍则 $K$ 变平方，方程式倒写则 $K$ 取倒数。
5. 纯固/液相不写入表达式；多相平衡中 $K$ 的"不完整"是正常写法。
6. 平衡常数可实验测定（测平衡组成），也可由热力学数据（$\Delta_r G_m^{\theta} = -RT\ln K^{\theta}$）求算。

## 五、适用条件与限制

| 内容 | 适用条件 | 限制 |
|:---|:---|:---|
| $K_c$、$K_p$（经验平衡常数） | 恒温、达平衡 | 有量纲时通常省略不写；数值依赖方程式写法 |
| $K_p = K_c(RT)^{\Delta n}$ | 各气体近似理想气体 | 高压下偏离理想气体需用逸度（决赛内容，见 [[非理想气体]]） |
| 纯固/液不写入 | 固/液相即自身标准态 | 溶液中的水在浓溶液或水参与主反应时不能随意省略 |
| $Q$–$K$ 判据 | 任意时刻 | 只判方向与限度，不涉及速率 |

## 六、常见比较与易混点

| 易混点 | 辨析 |
|:---|:---|
| $K$ 大 = 反应快 | $K$ 描述平衡位置（热力学），速率由动力学决定；合成氨 $K$ 不小但常温速率极慢 |
| 增大浓度使 $K$ 变大 | 平衡移动改变的是组成，$K$ 只随温度变 |
| $K_c$ 与 $K_p$ 数值相同 | 仅 $\Delta n=0$ 时相等，否则差 $(RT)^{\Delta n}$ 因子 |
| 转化率大 = $K$ 大 | 转化率随投料比变化；同一 $K$ 下不同投料转化率可大不相同（酯化反应例） |
| 所有物质都写进表达式 | 纯固体、纯液体、稀溶液中的水不写入 |

## 八、典型题型

1. 由平衡组成求 $K$（实验测定型）
2. 由 $K$ 求平衡浓度/转化率（ICE 表，见 [[化学平衡计算]]）
3. $K_c$ 与 $K_p$ 换算
4. $Q$–$K$ 比较判断反应方向
5. 方程式变形（系数、倒写、叠加）后 $K$ 的换算

## 九、例题

### 例题 1（$Q$–$K$ 判方向）

**题目**：25°C 时反应 N₂O₄(g) ⇌ 2NO₂(g) 的 $K_p = 0.148\ \mathrm{atm}$，若 N₂O₄ 和 NO₂ 的分压均为 0.50 atm，反应向哪个方向进行？

**解答**：$Q_p = \dfrac{(0.50)^2}{0.50} = 0.50 > K_p = 0.148$，$Q > K$，反应**逆向**进行（向生成 N₂O₄ 方向）。

### 例题 2（$K_p$→$K_c$ 换算，普化原理例 6.1）

**题目**：已知 $2\mathrm{SO_2}(g) + \mathrm{O_2}(g) \rightleftharpoons 2\mathrm{SO_3}(g)$ 在 1000 K 时 $K_p^{\mathrm{bar}} = 3.46$，求同温度下的 $K_c$。

**解答**：$\Delta n = -1$，$K_c = K_p(RT)^{-\Delta n} = 3.46 \times (0.0831\times 1000)^{1} = 288$。

**反思**：换算时先算 $\Delta n$ 的符号再定 $(RT)$ 的指数方向，是最常见的出错点。

## 十、易错点

1. **把转化率当作平衡常数**：$K$ 与投料无关，转化率与投料有关。
2. **方程式写法改变后沿用原 $K$ 值**：系数减半要开方，逆反应要取倒数。
3. **把纯固体/纯液体写入表达式**。
4. **$\Delta n$ 数错**：只数气体物质的计量系数，固/液体不计。
5. **认为催化剂能改变 $K$**：催化剂只改变达到平衡的速率。

## 十一、🎯 教学视角

### 11.1 学习路径建议

平衡常数是化学平衡的核心概念，应在学习化学反应可逆性之后引入。先用 N₂O₄/NO₂ 颜色实验建立"平衡是动态的、组成服从固定比值"的直觉，再给出 $K$ 的定义与测定，然后掌握 $K_c$/$K_p$ 的区别与换算，最后学习用 $Q$–$K$ 判断方向和用 ICE 表计算平衡组成（过渡到 [[化学平衡计算]]）。

### 11.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| K 值大说明反应速率快 | K 只描述平衡位置，与反应速率无关 |
| 增加浓度会增大 K | K 仅与温度有关，浓度和压强变化不改变 K |
| K 的表达式中包含所有物质 | 纯固体和纯液体不写入平衡常数表达式 |
| 平衡就是"反应停止了" | 平衡是正逆反应速率相等的动态状态，宏观上浓度不再变化 |

### 11.3 入门级例题

**题目**：373 K 时向 1 dm³ 容器中充入 0.100 mol N₂O₄，平衡时 [N₂O₄] = 0.040 mol·dm⁻³，求该温度下 N₂O₄ ⇌ 2NO₂ 的 $K_c$。

**解答**：分解的 N₂O₄ = 0.060 mol·dm⁻³，生成 [NO₂] = 0.120 mol·dm⁻³。$K_c = \dfrac{(0.120)^2}{0.040} = 0.36$。引导学生注意：换一组投料（如充入 0.100 mol NO₂）算出的 $K$ 仍是 0.36——这正是"常数"二字的含义。

### 11.4 与现实世界的联系

1. **工业合成**：平衡常数指导合成氨、硫酸工业条件的选择以提高产率
2. **环境化学**：大气中 NO₂/N₂O₄ 平衡影响光化学烟雾的形成
3. **生命体系**：肌红蛋白结合氧的平衡常数决定氧的运输与释放（28 届初赛真题情境）
