# 摩尔电导率 (Molar Conductivity)

## 一、定义

**摩尔电导率（Λₘ）** 是衡量电解质溶液导电能力的量，定义为 **溶液的电导率（κ）除以电解质浓度（c）**：

$$ \Lambda_m = \frac{\kappa}{c} $$

- 单位：S·m²·mol⁻¹
- 物理意义：1 mol 电解质在给定条件下所有离子贡献的电导之和
- **极限摩尔电导率（Λ₀）**：无限稀释时的摩尔电导率（离子间相互作用消失）

## 二、核心规律

### 2.1 Kohlrausch 定律
$$\Lambda_m = \Lambda_0 - A\sqrt{c}$$

- 适用于 **强电解质** 稀溶液
- A 为与溶剂、温度、电荷数相关的常数
- 外推至 c → 0 可得 Λ₀

### 2.2 Kohlrausch 离子独立迁移定律（无限稀释）
$$\Lambda_0 = \nu_+\lambda_+^0 + \nu_-\lambda_-^0$$

- λ⁰₊、λ⁰₋：阳离子和阴离子的极限摩尔电导率
- ν₊、ν₋：化学式中的离子计量数
- 可用于计算弱电解质的 Λ₀（无法直接测量）

### 2.3 弱电解质
- 不满足 Kohlrausch 平方根定律
- Λ₀ 通过离子独立迁移定律间接求得
- 解离度 α = Λₘ/Λ₀（Ostwald 稀释定律基础）

## 四、教学常见节点

- **Λₘ 随浓度变化**：强电解质缓慢下降（离子缩合），弱电解质快速下降（解离度降低）
- **应用：求弱酸的 Ka**：测 Λₘ → Λ₀(Kohlrausch) → α → Ka
- **应用：电导滴定**：酸碱中和过程中 Λₘ 突变点即为终点
- **水的电导**：纯水 Λ₀ = λ⁰(H⁺) + λ⁰(OH⁻) ≈ 5.5 × 10⁻⁶ S·m²·mol⁻¹
- **竞赛考查**：从 Λₘ 与 √c 图判断强弱电解质、用离子独立迁移定律计算

## 五、竞赛拓展

- **Walden 规则**：Λ₀η = 常数（η 为溶剂粘度）
- **Λ₀ 的温度系数**：温度升高，Λ₀ 增大（离子迁移率增加）
- **电导法测溶解度**：难溶盐饱和溶液的电导率 → 溶解度

## §12 教学视角

### 学生常见认知误区
- **误区1：「电导率越大，摩尔电导率越大」** → 混淆了 κ（溶液整体导电能力）和 Λₘ = κ/c（归一化到 1 mol 的导电能力）。稀释溶液时 κ 降低但 Λₘ 反而升高，因为离子间相互作用减弱。 → **口诀：κ 看总量，Λₘ 看个体；越稀 Λₘ 越大，离子跑得更自由**
- **误区2：「弱电解质也满足 Λₘ = Λ₀ − A√c」** → Kohlrausch 平方根定律仅适用于强电解质稀溶液（Debye-Hückel-Onsager 理论基础）。弱电解质随稀释解离度急剧增大，Λₘ 变化远超线性√c 关系。 → **口诀：强电解质走直线（√c），弱电解质靠拼凑（离子加和）**
- **误区3：「弱电解质的 Λ₀ 无法获得」** → 虽然弱电解质的 Λ₀ 不能直接外推测量，但 Kohlrausch 离子独立迁移定律允许用强电解质的 λ⁰ 数据间接计算：Λ₀ = ν₊λ⁰₊ + ν₋λ⁰₋。 → **口诀：强的直接推，弱的拆开算**

### 入门级例题
**题目**（初赛难度）：已知 25°C 时下列极限摩尔电导率数据：λ⁰(H⁺) = 349.8 S·cm²·mol⁻¹，λ⁰(OH⁻) = 198.3 S·cm²·mol⁻¹，λ⁰(Na⁺) = 50.1 S·cm²·mol⁻¹，λ⁰(CH₃COO⁻) = 40.9 S·cm²·mol⁻¹。试利用 Kohlrausch 离子独立迁移定律求 CH₃COOH 的 Λ₀，并估算 0.10 mol·dm⁻³ 醋酸溶液的解离度 α。

**分析**：醋酸是弱电解质，Λ₀ 无法直接外推。但 CH₃COOH 可看作 CH₃COONa + HCl − NaCl 的"离子组合"，因此 Λ₀(CH₃COOH) = λ⁰(H⁺) + λ⁰(CH₃COO⁻)。

**解答**：

$$\Lambda_0(\mathrm{CH_3COOH}) = \lambda^0(\mathrm{H^+}) + \lambda^0(\mathrm{CH_3COO^-}) = 349.8 + 40.9 = 390.7\ \mathrm{S \cdot cm^2 \cdot mol^{-1}}$$

若实验测得 0.10 mol·dm⁻³ 醋酸的 Λₘ ≈ 5.2 S·cm²·mol⁻¹，则：

$$\alpha = \frac{\Lambda_m}{\Lambda_0} = \frac{5.2}{390.7} \approx 1.33\%$$

**反思**：弱电解质的解离度极低（0.1 M 醋酸仅约 1.3% 解离），这解释了为什么其电导率远低于同浓度强电解质。Kohlrausch 离子独立迁移定律是连接强电解质数据与弱电解质性质的关键桥梁。

### 与现实/直觉的连接
想象一个拥挤的地铁站（高浓度）：人挤人时每个人走得慢（离子间相互作用强，Λₘ 低）。清空到几乎没人时（无限稀释），每个人都能自由奔跑（Λ₀，离子迁移不受干扰）。摩尔电导率就是"归一化到每一个人的通行效率"——浓度越低，人与人之间的阻碍越少，效率越高。这就是为什么 Λₘ 随稀释而增大，而非 κ（总通行量）随稀释而减小。

### 教学建议
1. **先画 Λₘ vs √c 图**：在黑板上同时画强电解质（KCl，缓慢线性下降）和弱电解质（CH₃COOH，急剧下降）的曲线，让学生直观感受两者差异
2. **用"拆积木"类比离子独立迁移定律**：把 Λ₀ 比作积木的单块价值，强电解质的 Λ₀ = 各离子贡献之和，就像总价等于各积木单价之和
3. **强调单位陷阱**：Λₘ 的单位 S·m²·mol⁻¹ 容易与 κ 的单位 S·m⁻¹ 混淆，建议让学生做一次完整的单位推导
4. **关联实验**：电导滴定是 Λₘ 最直观的应用，可以让学生思考"为什么滴定终点处电导会突变"
5. **对比 Walden 规则**：Λ₀η = 常数，可以让学生思考"为什么换溶剂后电导会变化"，建立溶剂粘度与离子迁移率的直觉
