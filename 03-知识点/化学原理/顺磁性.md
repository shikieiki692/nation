# 顺磁性

## 一、定义

顺磁性（paramagnetism）指物质含**未成对电子**、在**外磁场中被吸引**（磁化率 χ > 0 且很小）的性质。微观根源是未成对电子的自旋磁矩在磁场中取向排列；无外场时这些磁矩随机取向、宏观不显磁性。与之相对：**抗磁性**（所有电子成对，χ < 0，被外场排斥——一切物质都有抗磁本底）与**铁磁性**（磁矩长程有序，χ 大且可被磁铁吸引）。化学上，顺磁性的最大价值是**反推电子结构**：测出磁矩 → 算未成对电子数 n → 判断 d 电子排布与配合物高低自旋（O₂、NO 的顺磁也直接证明分子轨道理论）。竞赛中以"由磁矩求 n"与"判断高低自旋"两类题最常见。

## 二、考纲对应

本页属原子/分子结构与性质桥梁，对应"磁性判断与磁矩计算"：能判断物种是否含未成对电子（顺磁/抗磁）；会用自旋磁矩公式 μ = √(n(n+2)) BM 由实验磁矩反推未成对电子数 n；结合 [[晶体场理论]] 判断八面体配合物高低自旋并解释磁矩差异；知道 O₂、NO 等简单分子的顺磁性来源。初赛决赛均直接出题（Wilkinson 催化剂、d 区离子构型推断语境）。

## 三、核心原理

### 3.1 磁性三分类：从电子成对与否出发

- **抗磁性（diamagnetic）**：所有电子成对（自旋相消），无永久磁矩；外场诱导出相反磁矩被排斥（χ < 0）。一切物质都有抗磁本底，纯抗磁如 H₂O、NaCl、Zn²⁺(d¹⁰)、Cu⁺(d¹⁰)、[Fe(CN)₆]⁴⁻（低自旋 d⁶ 全成对）。
- **顺磁性**：存在未成对电子；外场使其自旋磁矩部分取向，被吸引（χ > 0，室温约 10⁻³–10⁻⁵ 量级，弱）。O₂、NO、过渡金属离子及高低自旋配合物的大多数。
- **铁磁性/反铁磁性/亚铁磁性**：固体中磁矩长程有序（χ 大、有剩磁/转变温度），属凝聚态物理范畴——竞赛仅需知道"铁磁可被磁铁吸住，顺磁太弱吸不动"。
- 判别速记：**凡有未成对电子 → 顺磁；全成对 → 抗磁**；O₂ 顺磁（两个未成对 π* 电子）是反直觉经典。

### 3.2 磁矩来源：自旋为主、轨道为辅

- 磁矩 μ 主要来自电子自旋；对第一过渡系配合物常近似只算自旋贡献（轨道贡献被配体场"猝灭"或部分保留）。
- 自旋-only 公式：μ = √(n(n+2)) BM（BM = 玻尔磁子 ≈ 9.27×10⁻²⁴ J/T），n = 未成对电子数。
- 典型值速记：n=1 → 1.73；n=2 → 2.83；n=3 → 3.87；n=4 → 4.90；n=5 → 5.92 BM（高自旋 d⁵ 的 Mn²⁺/Fe³⁺ 约 5.9）。
- 当实验值明显大于自旋-only 预测（如某些 Co(II) 配合物 μ≈4.7 vs n=3 预测 3.87），说明有轨道贡献/自旋-轨道耦合——竞赛题通常提示按自旋-only 处理。

### 3.3 由磁矩反推电子结构（解题主流程）

1. 已知离子/配合物的 d 电子数（如 Fe³⁺ = d⁵）。
2. 由实验 μ 求 n（μ = √(n(n+2))，解出 n 后四舍五入取整）。
3. 对照排布判断自旋态：八面体场中 d⁴–d⁷ 有高低自旋之分——高自旋 n 大、低自旋 n 小（Δo 与配对能 P 比较：Δo > P 低自旋，Δo < P 高自旋）。
4. 例：Ti³⁺(d¹) μ=1.73 → n=1；Fe(CN)₆³⁻ 低自旋 d⁵ → n=1 → μ≈1.73（实验约 2.0 含轨道贡献）；[Fe(H₂O)₆]²⁺ 高自旋 d⁶ → n=4 → μ≈4.9。

### 3.4 磁矩的温度依赖与测量

- 顺磁磁化率随温度升高而减小（居里定律 χ ∝ 1/T）：热运动打乱取向。反铁磁在 Néel 温度以下有序、铁磁在 Curie 温度以下有序。
- 测量方法：Gouy 天平（样品受磁场力称重）、NMR Evans 法（化学位移差）、SQUID（精密）。竞赛不考仪器细节，考"μ_eff 与 n 的换算"。

### 3.5 分子顺磁性：O₂、NO 的启示

- O₂：MO 排布 (σ2s)²(σ*2s)²(σ2p)²(π2p)⁴(π*2p)²——两个 π* 电子分占不同轨道且自旋平行（Hund），故**三重基态、顺磁**——这是 MO 理论胜过 Lewis 结构（O=O 无未成对）的直接证据。
- NO：11 个价电子，π* 上有 1 个未成对电子 → 顺磁；NO₂ 也有未成对（角形，N 上 1 个单电子）。
- 竞赛题常以"实测某分子顺磁 → 反推其必须含未成对电子 → 选择相应键级/结构模型"的方式出现。

## 四、关键结论

- 顺磁 ⇔ 有未成对电子；抗磁 ⇔ 全成对；强弱上顺磁远弱于铁磁。
- 自旋-only 公式 μ = √(n(n+2)) BM；常用值 n=1:1.73、n=2:2.83、n=3:3.87、n=4:4.90、n=5:5.92。
- 由 μ 求 n → 判 d 电子自旋态（八面体高低自旋看 Δo 与 P）。
- O₂ 顺磁是 MO 理论经典证据；d¹⁰/d⁰ 离子（Zn²⁺、Cu⁺、Sc³⁺）必抗磁。
- 轨道贡献会使 μ_eff 偏离自旋-only 值；竞赛默认按自旋-only 处理（有提示除外）。

## 五、常见分类或情形

- **按电子结构**：d⁰/d¹⁰（抗磁）；d¹–d⁹（多数顺磁，除低自旋全成对如 [Fe(CN)₆]⁴⁻ 低自旋 d⁶ 抗磁）。
- **按物质类型**：原子/离子（过渡金属离子）、小分子（O₂、NO、NO₂）、配合物（高/低自旋判断）、金属与合金（铁磁等有序态）。
- **按测量用途**：结构推断（n → 构型/自旋态）、纯度/价态验证（如判断催化剂中金属氧化态——Wilkinson 催化剂语境）。
- **高低自旋判据**：八面体 d⁴–d⁷ 的 Δo 与配对能 P 比较；强场配体（CN⁻、CO）低自旋、弱场配体（H₂O、F⁻）高自旋。

## 六、适用条件与限制

- 自旋-only 公式是**近似**：含重元素/低对称场时轨道贡献显著（如 Co(II)、某些 Ni(II)），μ_eff 偏大——题中未提示精确处理时按自旋-only。
- 温度影响：高温 χ 小，低温 χ 大；固体有序化（铁磁/反铁磁）后磁矩规律改变，公式只适用顺磁区。
- 抗磁本底需扣除：精密测量要校正配体/溶剂的抗磁贡献（竞赛题一般给已校正值）。
- 高低自旋仅对 d⁴–d⁷ 有意义：d¹–d³ 与 d⁸–d⁹ 八面体场中电子排布唯一（无高低之分），d⁸ 平面四方（如 Ni²⁺ 配合物）又另论。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 顺磁 vs 铁磁 | 顺磁无外场时磁矩无序、χ 极小、吸不动；铁磁磁矩有序、可被磁铁吸住——"有未成对电子"只是顺磁，不等于铁磁 |
| 磁矩大 ⇔ 电子多 | 磁矩只由**未成对**电子贡献（μ=√(n(n+2))）；d¹⁰ 电子多但 n=0 抗磁 | 
| 含金属就顺磁 | 满壳层离子（Zn²⁺ d¹⁰、Cu⁺ d¹⁰、Ti⁴⁺ d⁰）抗磁；顺磁取决于未成对电子而非含不含金属 |
| 高自旋一定顺磁 | 高自旋必顺磁，但低自旋也可能顺磁（d⁵ 低自旋 n=1）；只有全成对才抗磁 |
| O₂ 的键模型 | O₂ 顺磁 → Lewis O=O 模型失败；MO 的 (π*)² 分占自旋平行解释之——"O=O 双键应抗磁"是 MO 优越性的反面教材 |

- [[抗磁性]]：全成对情形（对照页）。

## 九、典型题型

- **μ 求 n**：给实验磁矩 5.92 BM，问未成对电子数与可能离子（答 n=5，如 Mn²⁺/Fe³⁺ 高自旋 d⁵）。
- **高低自旋判断**：比较 [Fe(CN)₆]³⁻ 与 [FeF₆]³⁻ 的磁矩大小并解释（强场低自旋 n=1 约 2.0 vs 弱场高自旋 n=5 约 5.9）。
- **分子磁性判断**：判断 O₂、N₂、NO、CO 谁顺磁并说明 MO 依据。
- **价态/结构推断**：Wilkinson 催化剂（Rh 配合物）等体系由磁矩/电子构型判断 d 电子数与氧化态（题-025-5）。
- **构型反推**：配合物磁矩给定 → 判八面体/四面体/平面四方与自旋态。

## 十、例题

**例题 1**：Ti³⁺ 的磁矩测量值约 1.73 BM，推断其电子构型与未成对电子数。

**解答**：μ = √(n(n+2)) = 1.73 → n(n+2) ≈ 3 → n = 1。Ti³⁺ 为 [Ar]3d¹，d 轨道仅 1 个电子，无论八面体/四面体场都只有 1 个未成对电子，与实验一致。d¹–d³ 无高低自旋之分，n 由 d 电子数直接确定。

**例题 2**：比较 [Fe(CN)₆]³⁻ 与 [FeF₆]³⁻ 的磁矩（自旋-only）并解释差异。

**解答**：两者 Fe 均为 +3 → d⁵。CN⁻ 是强场配体，Δo > P → 低自旋：t₂g⁵ 一个轨道先填满两电子后，第 5 个电子进 t₂g 另一轨道 → n = 1 → μ = √3 ≈ 1.73 BM。F⁻ 是弱场配体，Δo < P → 高自旋：五个轨道各 1 电子（Hund）→ n = 5 → μ = √35 ≈ 5.92 BM。磁矩差近 4.2 BM，实验可清晰区分两配合物的自旋态——"测磁矩判高低自旋"的标准题。

**例题 3**：解释 O₂ 的顺磁性，并指出它与 Lewis 结构模型的矛盾。

**解答**：O₂ 共 16 个价电子，MO 填充后 (π2p)⁴ 成键满、(π*2p)² 两个电子按 Hund 规则分占两个反键轨道且自旋平行 → 2 个未成对电子 → 顺磁（三重态基态）。Lewis 结构 O=O（全成对）预测抗磁，与实验矛盾——只有 MO 理论能解释 O₂ 的顺磁性与 O–O 键长（键级 2）之间的自洽。同理 NO（π* 1 电子）顺磁。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 所有含金属物质都顺磁 | Zn²⁺(d¹⁰)、Cu⁺(d¹⁰)、Sc³⁺/Ti⁴⁺(d⁰) 全成对抗磁 | 反例：ZnCl₂ 抗磁——判据是"有无未成对电子"不是"含不含金属" |
| 磁矩与总电子数挂钩 | μ = √(n(n+2)) 中 n 是**未成对**电子数；d¹⁰ 电子多但 n=0 → μ=0 | 判别：先写 d 电子排布数未成对电子，再代公式；n 最大 5（高自旋 d⁵）对应 μ 5.92 封顶 |
| 高低自旋不会判 | 强场（CN⁻/CO）Δo > P → 低自旋 n 小；弱场（H₂O/F⁻）→ 高自旋 n 大——d⁴–d⁷ 才有选择 | 反例：[Fe(CN)₆]³⁻ n=1 vs [FeF₆]³⁻ n=5；d¹–d³/d⁸–d⁹ 八面体无高低之分，别硬分 |
| 顺磁=铁磁=能被磁铁吸 | 顺磁磁矩极弱（10⁻³ 量级）吸不动；能被吸住的是铁磁体 | 判别：题目问"能否被磁铁吸引"——O₂ 顺磁但液态氧才见宏观吸引；粉末配合物顺磁≠铁磁 |
| 轨道贡献忘了 | 自旋-only 只近似；Co(II) 等 μ_eff 明显大于 √(n(n+2)) 预测 | 判别：题给 μ=4.7 且 n 应=3（3.87）时说明有轨道贡献/自旋轨道耦合——按题意自旋-only 处理或说明偏差来源 |
| O₂ 用 Lewis 判断磁性 | O=O 双键全成对 → 错判抗磁；必须用 MO（π* 2 个未成对） | 判别：凡涉及 O₂ 磁性一律 MO；顺磁是"O=O 双键"模型的直接反例 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
顺磁性应在学习电子排布之后引入，是电子排布与宏观性质的桥梁。先理解未成对电子产生顺磁的物理本质（自旋磁矩），再掌握磁矩公式 μ = √(n(n+2)) BM 的计算与典型值，接着用八面体晶体场判高低自旋，最后用 O₂/MO、Wilkinson 催化剂真题收尾。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 所有含金属的物质都是顺磁性的 | Zn²⁺(d¹⁰)、Cu⁺(d¹⁰) 等满壳层离子是抗磁性的 |
| 磁矩越大说明电子越多 | 磁矩公式 μ = √(n(n+2)) BM，n 是未成对电子数，不是总电子数 |
| 顺磁性物质一定会被磁铁吸引 | 弱顺磁性物质的吸引力很弱，需要用精密仪器测量 |
| 顺磁与铁磁不分 | 铁磁才有长程有序与强吸引；顺磁是极弱的场致取向 |

### 12.3 入门级例题
**题目**：Ti³⁺ 的磁矩测量值为 1.73 BM，推断其电子构型。

**解答**：由 μ = √(n(n+2)) = 1.73 解得 n = 1。Ti³⁺ 为 3d¹ 构型，有 1 个未成对电子，与实验一致。

### 12.4 与现实世界的联系
1. **MRI 造影剂**：顺磁性 Gd³⁺ 配合物缩短组织弛豫时间，增强图像对比度。
2. **氧气检测**：O₂ 的顺磁性（磁化率随氧浓度变化）被用于气体分析仪测氧。
3. **磁性材料基础**：理解顺磁是通向铁磁/反铁磁与自旋电子学的起点。
