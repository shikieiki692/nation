# Stokes-Einstein方程

> [!note] 核心概念
> 描述 Brown 运动中扩散系数与粒子半径、温度、溶剂粘度之间的关系。

## 公式

$$D = \frac{k_B T}{6\pi\eta r}$$

其中：
- $D$：扩散系数（m²/s）
- $k_B$：Boltzmann常数
- $T$：绝对温度（K）
- $\eta$：溶剂粘度（Pa·s）
- $r$：粒子半径（m）

## 两条物理线的合成

Stokes-Einstein 方程是**两个独立物理定律的乘积**：

1. **Einstein 关系（涨落-耗散）**：D = μ·k_B·T——扩散系数 = 迁移率 μ × 热涨落强度 k_BT。布朗粒子虽被分子无规则撞击，但统计上仍服从宏观迁移规律；μ 是"单位力下的漂移速度"。
2. **Stokes 定律（流体力学阻力）**：球形粒子在粘性介质中以速度 v 运动受阻力 F = 6πηrv——μ = v/F = 1/(6πηr)。

两式相乘消去 μ 即得 D = k_BT/(6πηr)。**物理图像**：热运动（k_BT）驱动扩散，粘度与粒子半径（6πηr）构成阻力——温度越高扩散越快，介质越粘、粒子越大扩散越慢。

## 量纲与数量级自检

D 的单位：k_BT/(6πηr) = (J/K·K)/(Pa·s·m) = J/(Pa·s·m) = (N·m)/(N·m⁻²·s·m) = m²/s ✓

- 小分子（水、离子，r ≈ 0.1~0.3 nm）在水中 D ≈ 1~2×10⁻⁹ m²/s
- 蛋白质（r ≈ 2~5 nm）D ≈ 10⁻¹¹~10⁻¹⁰ m²/s
- 胶体粒子（r ≈ 50~500 nm）D ≈ 10⁻¹²~10⁻¹³ m²/s

**逆用求 r 是主要考法**：测 D → r = k_BT/(6πηD)，从而得到分子/粒子水合半径（含溶剂化层），是判断"分子是紧凑球还是伸展链"的工具。

## 应用

- 通过扩散系数测定分子/胶体粒子大小（水合半径）
- 与 Nernst-Einstein 方程联用求电导率（离子迁移）
- 动态光散射（DLS）的理论基础
- 凝胶电泳/色谱中分子迁移速率的解释
- 药物控释：纳米载体扩散出凝胶的速率估算

**Nernst-Einstein 衔接**：对离子，迁移率 μ = zFD/(RT)（或摩尔电导 Λm = z²F²D/(RT)）——把扩散系数与电导率挂钩；再由 Stokes-Einstein 又得到 Λm 与离子半径/粘度的关系（Stokes 半径）。测定电解质摩尔电导 → 反推离子扩散系数与水合半径，是物化实验常考逻辑链。

## 数值算例

**题目**：25°C时某蛋白质在水中的扩散系数D = 6.9×10⁻¹¹ m²/s，水的粘度η = 8.9×10⁻⁴ Pa·s。估算该蛋白质的半径。
**解答**：r = kBT/(6πηD) = 1.38×10⁻²³×298/(6π×8.9×10⁻⁴×6.9×10⁻¹¹) = 4.1×10⁻⁹ m = 4.1 nm。

**扩展问**：若该蛋白质摩尔质量约 66 kDa、比体积 0.73 cm³/g，求未水合的"裸球"半径并比较。
**解答**：V = M·v̄/N_A = 66000×0.73×10⁻⁶/6.02×10²³ = 8.0×10⁻²⁶ m³ → r_裸 = (3V/4π)^(1/3) ≈ 2.7 nm。实测水合半径 4.1 nm > 2.7 nm——差值反映水化层厚度与形状偏离球形的程度。

## 适用条件与局限

- **球形粒子**：非球（棒状、线团）需修正（摩擦比 f/f₀ > 1）
- **连续介质**：粒子尺寸须远大于溶剂分子（小分子扩散、气体中扩散不适用）
- **稀溶液**：粒子间不相互作用
- **Stokes 定律的滑移/粘附边界**：微观粒子常介于"粘附边界"与"滑移边界"之间，系数 6π 可能变为 4π（滑移）——竞赛按 6π 标准式处理即可
- **高温/低粘假设**：DLS 测大分子时温度粘度必须精确控制

## 竞赛考察要点与命题角度

1. **直接求 r**：给 D、η、T 求水合半径（37 届初赛语境）——套公式、盯单位。
2. **比例判断**：D 与 T 成正比、与 η、r 成反比——升温/换溶剂/换大分子三方向定性判断。
3. **DLS 原理**：动态光散射测的是散射光强涨落的衰减时间 → 由衰减时间得 D → Stokes-Einstein 得 r——"为什么 DLS 能测纳米颗粒尺寸"的完整链条。
4. **电导衔接**：离子摩尔电导 Λm → D → r（Stokes 半径）三段式，考察 Nernst-Einstein 与 Stokes-Einstein 的接力。
5. **摩擦比**：给 f/f₀ > 1 判断分子形状偏离球形的程度（f₀ 为同体积球摩擦系数）。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 温度越高扩散越慢 | D ∝ T：热运动加剧扩散加快 | 加热使墨水扩散更快；D(50°C) > D(25°C) |
| 粒子越大扩散越快 | D ∝ 1/r：大粒子阻力大、扩散慢 | 蛋白质 D ≈ 10⁻¹¹ ≪ 小分子 D ≈ 10⁻⁹ m²/s |
| 单位混用（nm 与 m、cP 与 Pa·s） | r 常给 nm、η 常给 cP（1 cP = 10⁻³ Pa·s） | 先统一到 m 与 Pa·s 再代入；1 nm = 10⁻⁹ m |
| 用 D 直接判断摩尔质量大小 | D 测的是水合半径，非球形/柔性分子会误导 | 柔性链的表观半径比同质量球大（f/f₀ 偏离 1） |
| 该方程适用于所有体系 | 仅球形粒子 + 连续介质 + 稀溶液 | 气体扩散、小分子在微孔中扩散均不适用 |
| 混淆 D 的单位量级 | 忘记 D 是 m²/s（不是 m/s） | 小分子水相 D ~ 10⁻⁹ m²/s；10⁻⁵ m²/s 是气体量级 |

## 动态光散射（DLS）原理链

DLS 测粒径的四步逻辑（竞赛简述题标准答案）：

1. 激光照胶体溶液，颗粒 Brown 运动使散射光强度随时间**涨落**；
2. 用自相关函数分析涨落衰减——衰减快慢由颗粒扩散快慢决定；
3. 由衰减时间常数得扩散系数 D；
4. D 代入 Stokes-Einstein 方程 → 水合半径 r（粒径分布）。

**为什么用光散射而不用显微镜**：纳米颗粒远小于可见光波长，静态成像无法分辨；散射光涨落携带的动力学信息却可以。DLS 测得的是"强度加权平均直径"，多分散样品会偏大——报告结果时需注明分布类型。

## 沉降与扩散的竞争（胶体稳定性）

胶体颗粒受重力沉降（沉降速度 v = 2r²(ρ−ρ₀)g/(9η)，Stokes 沉降定律），同时 Brown 扩散使它趋于均匀。两者竞争由 Boltzmann 分布刻画：n(h) = n₀·exp(−m_eff·g·h/(k_BT))。当热能 k_BT 远大于重力势能差时（小颗粒），胶体稳定悬浮；颗粒增大或密度差增大 → 沉降占优。

**衔接题**：已知颗粒半径与密度差，问"多小的颗粒可稳定悬浮"——令 k_BT ≳ (4/3)πr³Δρ·g·h 反解 r 上限，或用 Stokes 沉降速度低于某阈值作判据。此题把 Stokes 沉降（重力）与 Brown 扩散（热涨落）两个 Stokes 家族定律串在一起，是胶体化学综合题常客。

## 与相关概念的辨析

| 概念 | 关系 |
|---|---|
| Brown 运动 | 现象（粒子无规运动），Stokes-Einstein 是其定量描述 |
| 扩散系数 D | 本方程输出量，Fick 定律的比例常数 |
| 迁移率 μ | Einstein 关系 D = μkT 的中间量 |
| Stokes 半径 | 由 D 反推的等效球半径（含溶剂化层） |
| 水合半径 | 与 Stokes 半径近似同义，强调水化层 |
| 摩擦系数 f | f = 6πηr（球）；f/f₀ 指示形状偏离 |

## 🎯 教学视角

### 学习路径建议
Stokes-Einstein方程应在学习Brown运动和扩散现象之后引入。先理解方程的物理意义（扩散系数与粒子大小、温度、粘度的关系），再学习如何通过扩散系数测定分子或胶体粒子的大小。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 温度越高扩散越慢 | 温度越高分子热运动越剧烈，扩散越快（D∝T） |
| 粒子越大扩散越快 | 粒子越大阻力越大，扩散越慢（D∝1/r） |
| 该方程适用于所有体系 | 仅适用于球形粒子在连续介质中的扩散 |

### 入门级例题
**题目**：25°C时某蛋白质在水中的扩散系数D = 6.9×10⁻¹¹ m²/s，水的粘度η = 8.9×10⁻⁴ Pa·s。估算该蛋白质的半径。
**解答**：r = kBT/(6πηD) = 1.38×10⁻²³×298/(6π×8.9×10⁻⁴×6.9×10⁻¹¹) = 4.1×10⁻⁹ m = 4.1 nm。

### 与现实世界的联系
1. **药物递送**：纳米药物载体的尺寸影响其在体内的扩散和分布
2. **血液检测**：动态光散射（DLS）利用Stokes-Einstein方程测定蛋白质和纳米颗粒的尺寸
3. **地下水污染**：污染物在地下水中的扩散速率与粒子大小和水的粘度有关

> **记忆锚**：D = kT/6πηr——分子热运动推着走（kT），粘度半径拉着停（6πηr）；升温快、变粘慢、粒子大更慢；测 D 反推水合半径是标准考法。

## 关键结论速记

- D = k_BT/(6πηr)：T↑D↑，η↑D↓，r↑D↓——三方向定性必考。
- 小分子 D ~ 10⁻⁹、蛋白 ~10⁻¹¹、胶体 ~10⁻¹² m²/s——量级自检。
- 逆用 r = k_BT/(6πηD) 求水合半径；与裸球半径比 → 水化层与形状信息。
- DLS：光强涨落 → D → r；离子电导：Λm → D → r（Nernst-Einstein 接力）。
- 单位先统一：r 用 m、η 用 Pa·s（1 cP = 10⁻³ Pa·s）、D 用 m²/s。
- 同一温度粘度下比较两种粒子：D₁/D₂ = r₂/r₁——扩散系数反比半径，无需查常数。
- 温度修正典型题：η 随温度按 Arrhenius 型下降（水 25°C→60°C 粘度约减半），D 变化要同时计入 T 升与 η 降两个因素。
- 见到"由扩散测分子量"的表述要警惕：Stokes-Einstein 直接给的是**半径**，分子量须经比体积/形状模型换算——题面不给模型时只能答半径。

## 数值感受（培养量感）

- 25°C 水中：O₂ 分子 D ≈ 2.1×10⁻⁹ m²/s（1 s 扩散距离 ~√(2Dt) ≈ 65 μm）；
- 葡萄糖（r ≈ 0.36 nm）D ≈ 6.7×10⁻¹⁰ m²/s；IgG 抗体（r ≈ 5.5 nm）D ≈ 4×10⁻¹¹ m²/s；
- 甘油（η ≈ 1.4 Pa·s，比水粘 1500 倍）中同粒子 D 缩小约 1500 倍——换溶剂题按比例秒答。

**量感口诀**：水中小分子"每秒走几十微米"、蛋白"每秒走几微米"、胶体"每秒走亚微米"——差一个数量级对应半径差一个数量级（D ∝ 1/r）。
