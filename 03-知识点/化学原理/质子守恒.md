# 质子守恒

## 一、定位

质子守恒用于酸碱平衡计算，核心是“体系中失去的 H+ 数等于得到的 H+ 数”。

## 二、与其他守恒的分工
- [[物料守恒]] 负责元素总量不变
- [[电荷守恒]] 负责体系总电荷平衡
- 质子守恒负责酸碱转移关系的约束

## 三、常见使用场景
- 多元弱酸 / 多元弱碱溶液
- 缓冲体系
- 容量分析中的终点附近近似处理

## 🎯 教学视角

### 学习路径建议
质子守恒应在学习物料守恒和电荷守恒之后引入，是三种守恒中最具技巧性的一种。先理解"质子转移"的核心思想，再通过具体例子（如NaHCO₃溶液）练习书写质子守恒式，最后与物料守恒和电荷守恒联立求解。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 质子守恒就是[H⁺]=[OH⁻] | 只有纯水中才是这样，溶液中还需考虑质子给体和受体 |
| 质子守恒式中只写H⁺和OH⁻ | 还需写入获得或失去质子的共轭酸碱对 |
| 质子守恒和电荷守恒是一回事 | 电荷守恒关注总电荷为零，质子守恒关注质子转移的守恒 |

### 入门级例题
**题目**：写出NaHCO₃溶液的质子守恒式。
**解答**：质子守恒：[H⁺] + [H₂CO₃] = [OH⁻] + [CO₃²⁻]。左边是获得质子的产物（H⁺和H₂CO₃），右边是失去质子的产物（OH⁻和CO₃²⁻）。

### 与现实世界的联系
1. **酸碱滴定**：质子守恒用于估算滴定终点的pH
2. **缓冲溶液设计**：利用质子守恒计算缓冲溶液的组成
3. **环境化学**：天然水体的酸碱平衡可以用质子守恒描述
