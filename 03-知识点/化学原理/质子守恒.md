# 质子守恒

## 一、定位

质子守恒用于酸碱平衡计算，核心是“体系中失去的 H+ 数等于得到的 H+ 数”。

## 二、与其他守恒的分工
- [[物料守恒]] 负责元素总量不变
- [[电荷守恒]] 负责体系总电荷平衡
- 质子守恒负责酸碱转移关系的约束

## 三、常见使用场景
- 多元弱酸 / 多元弱碱溶液
- 缓冲体系
- 容量分析中的终点附近近似处理

## 四、核心原理

### 4.1 质子守恒的书写方法

**核心思想**：在酸碱反应中，质子（H⁺）的转移是守恒的——得质子产物的总量等于失质子产物的总量。

$$\sum(\text{得质子产物的浓度} \times \text{得质子数}) = \sum(\text{失质子产物的浓度} \times \text{失质子数})$$

**零水准法**（推荐）：选择溶液中大量存在的物种作为零水准（参考点），以此为基准判断哪些物种得到了质子、哪些失去了质子。

**书写步骤**：
1. **确定零水准**：选择溶液中初始大量存在且可作为质子给体/受体的物种（通常是溶剂分子和加入的盐的阴/阳离子）
2. **写出得质子产物**：零水准获得 H⁺ 后生成的物种（写在等式左边）
3. **写出失质子产物**：零水准失去 H⁺ 后生成的物种（写在等式右边）
4. **令两边相等**：每个产物乘以其得/失质子的个数，建立等式

> **注意**：零水准本身不出现在等式中，因为它既没有得质子也没有失质子。

### 4.2 典型体系的质子守恒式

以下均以零水准法推导：

| 体系 | 零水准 | 质子守恒式 |
|:---|:---|:---|
| 纯水 | H₂O | $[\text{H}^+] = [\text{OH}^-]$ |
| NaAc 溶液 | H₂O, Ac⁻ | $[\text{H}^+] + [\text{HAc}] = [\text{OH}^-]$ |
| NH₃·H₂O 溶液 | H₂O, NH₃ | $[\text{H}^+] = [\text{OH}^-] + [\text{NH}_4^+]$ |
| NaHCO₃ 溶液 | H₂O, HCO₃⁻ | $[\text{H}^+] + [\text{H}_2\text{CO}_3] = [\text{OH}^-] + [\text{CO}_3^{2-}]$ |
| Na₂CO₃ 溶液 | H₂O, CO₃²⁻ | $[\text{H}^+] + [\text{HCO}_3^-] + 2[\text{H}_2\text{CO}_3] = [\text{OH}^-]$ |
| NaH₂PO₄ 溶液 | H₂O, H₂PO₄⁻ | $[\text{H}^+] + [\text{H}_3\text{PO}_4] = [\text{OH}^-] + [\text{HPO}_4^{2-}] + 2[\text{PO}_4^{3-}]$ |

**推导示范（NaAc 溶液）**：
- 零水准：H₂O 和 Ac⁻
- 得质子产物：H₃O⁺（即 H⁺），以及 Ac⁻ + H⁺ → HAc
- 失质子产物：OH⁻（H₂O 失去 H⁺）
- 质子守恒式：$[\text{H}^+] + [\text{HAc}] = [\text{OH}^-]$

### 4.3 三种守恒的联立求解

三种守恒从不同角度约束同一溶液体系：

| 守恒 | 核心约束 | 表达式形式 |
|:---|:---|:---|
| [[物料守恒]] | 某元素在溶液中的总浓度不变 | 含该元素的所有物种浓度之和 = 初始浓度 |
| [[电荷守恒]] | 溶液整体电中性 | $\sum c_i z_i = 0$（所有离子浓度×电荷数之和为零） |
| 质子守恒 | 质子转移守恒 | 得质子产物总量 = 失质子产物总量 |

**关键关系**：质子守恒式可由物料守恒和电荷守恒联立消元得到，三者数学上等价。实际解题时选择最方便的一个使用即可：
- 若体系物种简单，直接用质子守恒最简洁
- 若需精确求解多个离子浓度，联立物料守恒+电荷守恒更系统
- 质子守恒特别适合快速判断[H⁺]与其他离子浓度的关系

### 4.4 多元酸/碱体系的特殊处理

**多元酸各级电离常数差异大时的近似处理**：

当 $K_{a1} \gg K_{a2}$ 时（如 H₃PO₄ 的 $K_{a1}=7.1\times10^{-3}$，$K_{a2}=6.3\times10^{-8}$），第一级电离远强于第二级，可近似认为 H₂PO₄⁻ 的浓度近似等于初始浓度。

**两性物质的 [H⁺] 近似公式**：

对于 NaHCO₃、NaH₂PO₄ 等两性物质（既能给质子又能受质子），其质子守恒式联立可得近似公式：

$$[\text{H}^+] \approx \sqrt{K_{a1} \cdot K_{a2}}$$

> **适用条件**：$c \gg K_{a1}$ 且 $c \gg K_w / K_{a2}$（即浓度不太稀，且两级电离常数相差足够大）。

**推导思路**：以 NaHCO₃ 为例，质子守恒 $[\text{H}^+] + [\text{H}_2\text{CO}_3] = [\text{OH}^-] + [\text{CO}_3^{2-}]$，在 $c$ 较大时近似有 $[\text{H}_2\text{CO}_3] \approx c$，$[\text{CO}_3^{2-}] \approx K_{a2} \cdot c / [\text{H}^+]$，代入整理即得 $[\text{H}^+] \approx \sqrt{K_{a1} \cdot K_{a2}}$。

**混合酸碱体系**：

当溶液中存在多种酸或碱时（如 HAc + NaAc 缓冲体系），质子守恒式的零水准需同时包含所有主要物种，得质子和失质子的产物也会相应增多。此时电荷守恒+物料守恒联立求解通常更方便。

## 五、与其他知识点的关系

1. **[[物料守恒]]**：质子守恒可由物料守恒与电荷守恒联立推导，二者数学等价但适用场景不同。物料守恒更直观，质子守恒更简洁。
2. **[[电荷守恒]]**：质子守恒与电荷守恒互为补充。电荷守恒是溶液电中性的必然要求，质子守恒是质子转移的守恒约束。联立二者可消去中间变量求解目标浓度。
3. **[[酸碱理论]]**：质子守恒是 Brønsted-Lowry 酸碱理论的直接应用——酸是质子给体，碱是质子受体，质子守恒正是对这一转移过程的定量描述。
4. **[[缓冲溶液]]**：缓冲溶液的 pH 计算本质上就是利用质子守恒（或其近似形式）求解 [H⁺]。Henderson-Hasselbalch 方程可视为质子守恒在缓冲体系中的简化形式。
5. **[[水的电离]]**：质子守恒的零水准通常包含 H₂O，H₂O 的自电离平衡（$K_w = [\text{H}^+][\text{OH}^-]$）是质子守恒式中 [H⁺] 和 [OH⁻] 的来源。

## 六、典型题型与解题策略

### 题型一：书写指定体系的质子守恒式

**解题策略**：
1. 找准零水准——溶液中初始大量存在的物种
2. 列出所有得质子产物（写在左边）和失质子产物（写在右边）
3. 注意得/失质子的个数（如 CO₃²⁻ 得两个 H⁺ 生成 H₂CO₃，系数为 2）
4. 写完后用电荷守恒或物料守恒交叉验证

**例题**：写出 Na₃PO₄ 溶液的质子守恒式。

**解析**：零水准为 H₂O 和 PO₄³⁻。得质子产物：H⁺、HPO₄²⁻（得1个H⁺）、H₂PO₄⁻（得2个H⁺，系数2）、H₃PO₄（得3个H⁺，系数3）。失质子产物：OH⁻。

$$[\text{H}^+] + [\text{HPO}_4^{2-}] + 2[\text{H}_2\text{PO}_4^-] + 3[\text{H}_3\text{PO}_4] = [\text{OH}^-]$$

### 题型二：三种守恒联立求解离子浓度

**解题策略**：
1. 分别写出物料守恒、电荷守恒、质子守恒（任选两个即可）
2. 联立方程，消去不需要的中间变量
3. 代入已知的 $K_a$、$K_b$、$K_w$ 和浓度数据求解
4. 注意近似条件：当 $c/K_a > 100$ 时可忽略酸的电离对浓度的影响

**例题**：0.1 mol/L NaAc 溶液中，求各离子浓度关系。

**解析**：
- 物料守恒：$[\text{HAc}] + [\text{Ac}^-] = 0.1$
- 电荷守恒：$[\text{Na}^+] + [\text{H}^+] = [\text{Ac}^-] + [\text{OH}^-]$
- 质子守恒：$[\text{H}^+] + [\text{HAc}] = [\text{OH}^-]$

由质子守恒直接得 $[\text{H}^+] = [\text{OH}^-] - [\text{HAc}]$，可知 $[\text{OH}^-] > [\text{H}^+]$，溶液呈碱性（NaAc 为强碱弱酸盐）。

### 题型三：两性物质 pH 近似计算

**解题策略**：
1. 判断物质是否为两性物质（既能给质子又能受质子）
2. 验证近似条件：$c \gg K_{a1}$ 且 $c \gg K_w/K_{a2}$
3. 直接套用 $[\text{H}^+] \approx \sqrt{K_{a1} \cdot K_{a2}}$ 计算
4. 若条件不满足，需回到质子守恒精确求解

**例题**：计算 0.1 mol/L NaHCO₃ 溶液的 pH（已知 $K_{a1}=4.3\times10^{-7}$，$K_{a2}=5.6\times10^{-11}$）。

**解析**：
$$[\text{H}^+] \approx \sqrt{K_{a1} \cdot K_{a2}} = \sqrt{4.3\times10^{-7} \times 5.6\times10^{-11}} = \sqrt{2.4\times10^{-17}} \approx 4.9\times10^{-9}$$
$$\text{pH} \approx 8.31$$

溶液呈弱碱性，与 NaHCO₃ 作为两性物质的预期一致。

## 🎯 教学视角

### 学习路径建议
质子守恒应在学习物料守恒和电荷守恒之后引入，是三种守恒中最具技巧性的一种。先理解"质子转移"的核心思想，再通过具体例子（如NaHCO₃溶液）练习书写质子守恒式，最后与物料守恒和电荷守恒联立求解。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 质子守恒就是[H⁺]=[OH⁻] | 只有纯水中才是这样，溶液中还需考虑质子给体和受体 |
| 质子守恒式中只写H⁺和OH⁻ | 还需写入获得或失去质子的共轭酸碱对 |
| 质子守恒和电荷守恒是一回事 | 电荷守恒关注总电荷为零，质子守恒关注质子转移的守恒 |

### 入门级例题
**题目**：写出NaHCO₃溶液的质子守恒式。
**解答**：质子守恒：[H⁺] + [H₂CO₃] = [OH⁻] + [CO₃²⁻]。左边是获得质子的产物（H⁺和H₂CO₃），右边是失去质子的产物（OH⁻和CO₃²⁻）。

### 与现实世界的联系
1. **酸碱滴定**：质子守恒用于估算滴定终点的pH
2. **缓冲溶液设计**：利用质子守恒计算缓冲溶液的组成
3. **环境化学**：天然水体的酸碱平衡可以用质子守恒描述
