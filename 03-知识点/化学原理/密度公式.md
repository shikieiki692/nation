# 密度公式

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 关联笔记：[[理想气体状态方程]], [[化学计量]], [[摩尔质量]]

## 一、定义

密度（$\rho$）是单位体积物质的质量。在化学竞赛中，密度计算广泛应用于气体摩尔质量测定、溶液浓度换算、晶体结构分析等领域。

## 二、考纲对应

- 属于化学计量模块（考纲编号 01），是化竞初赛基础计算题的高频工具
- 密度公式本身不单独设考点，但贯穿气体定律、溶液浓度、晶体结构三大板块
- 掌握密度公式可直接解决相对密度求分子量、溶液浓度互转、晶胞参数计算等竞赛核心题型

## 三、核心原理

### 3.1 基本公式

$$\rho = \frac{m}{V}$$

### 3.2 气体密度与摩尔质量

由理想气体状态方程 $PV = nRT = \frac{m}{M}RT$，可得：
$$\rho = \frac{PM}{RT}$$

其中 $M$ 为摩尔质量（g/mol），$P$ 为压强（Pa），$T$ 为温度（K），$R = 8.314 \text{ J/(mol·K)}$。

**标准状况（STP, 0°C, 101.325 kPa）**：
$$\rho_0 = \frac{M}{22.4} \quad (\text{g/L})$$

### 3.3 相对密度（$D$）

某气体对氢气的相对密度：
$$D_{H_2} = \frac{\rho}{\rho_{H_2}} = \frac{M}{M_{H_2}} = \frac{M}{2}$$

对空气的相对密度：
$$D_{\text{air}} = \frac{M}{M_{\text{air}}} = \frac{M}{29}$$

### 3.4 溶液密度与质量分数

物质的量浓度与质量分数的换算：
$$c = \frac{1000 \rho w}{M}$$

其中 $\rho$ 为溶液密度（g/cm³），$w$ 为质量分数，$M$ 为溶质摩尔质量。

### 3.5 晶体密度

$$\rho = \frac{Z \cdot M}{N_A \cdot V_{\text{晶胞}}}$$

其中 $Z$ 为晶胞中分子/原子团个数，$V_{\text{晶胞}}$ 为晶胞体积。

## 四、关键结论

1. **气体密度与摩尔质量的桥梁公式**：rho = PM/RT 是连接宏观可测物理量（rho, P, T）与微观量（M）的核心关系，标准状况下简化为 rho0 = M/22.4（g/L）
2. **相对密度法快速求 M**：M = 2D_H2 = 29D_air，竞赛中只需测一种相对密度即可锁定分子量，进而确定分子式
3. **晶胞密度公式是竞赛结构题的万能钥匙**：rho = ZM/(NA * V_晶胞)，可正向算密度，也可反向由密度推 M、Z 或 a，是初赛/决赛晶体结构题的核心公式

## 五、常见分类或情形

| 应用场景 | 核心公式 | 典型用途 |
|------|------|------|
| 气体密度法 | rho = PM/RT | 由实验测定的 rho, P, T 求 M |
| 相对密度法 | M = 2D_H2 = 29D_air | 快速估算气体分子量 |
| 溶液浓度互转 | c = 1000 rho w/M | 质量分数与物质的量浓度互转 |
| 晶胞密度法 | rho = ZM/(NA * V_晶胞) | 晶体结构计算（求 M、Z 或 a）|
| 非理想气体修正 | rho = PM/(ZRT) | 高压/低温条件下的密度修正 |

## 六、适用条件与限制

1. **理想气体公式 rho = PM/RT 仅在低压高温下准确**：高压或低温时分子间力不可忽略，需用压缩因子 Z 修正
2. **标准状况 22.4 L/mol 仅在 STP（0C, 101.325 kPa）下成立**：IUPAC 新标准（100 kPa）下为 22.7 L/mol，竞赛中需注意题目给定条件
3. **晶胞密度公式要求已知晶体结构类型**：若未知 Z 或晶胞形状，则无法直接计算，需结合衍射数据或其他条件

## 七、常见比较与易混点

- **密度 rho vs 摩尔质量 M**：rho 是宏观量（g/cm3 或 g/L），M 是微观量（g/mol）；对气体两者通过 rho = PM/RT 关联
- **相对密度 D_H2 vs D_air**：D_H2 = M/2，D_air = M/29，分母不同，计算时务必确认参考气体
- **溶液密度 rho（g/cm3）vs 气体密度 rho（g/L）**：单位不同，换算时注意 1 g/cm3 = 1000 g/L
- **晶胞密度公式中 Z 的含义**：Z 是每个晶胞中结构单元（分子或化学式单元）的个数，不是原子总数。如 NaCl 中 Z=4（指 4 个 NaCl 单元，共 8 个离子）

## 八、与其他知识点的联系

- 前置知识：[[理想气体状态方程]]、[[摩尔质量]]
- 相关知识：[[化学计量]]、[[晶体结构]]（晶胞密度）、[[溶液浓度]]
- 应用知识：[[气体分子量测定]]、[[晶胞参数]]、Bragg 方程

## 九、典型题型

1. **由相对密度求摩尔质量**：$M = 2D_{H_2} = 29D_{\text{air}}$
2. **气体定律综合计算**：温度/压强变化后的密度换算
3. **溶液浓度换算**：由密度和质量分数求物质的量浓度
4. **晶胞密度计算**：结合晶胞参数和晶体结构求密度

## 十、例题

**题目**：某金属 M 的面心立方晶体，晶胞参数 a = 361 pm，密度 rho = 8.90 g/cm3。求 M 的摩尔质量并判断是什么金属。

**解答**：
1. FCC 晶胞 Z = 4，rho = 4M/(NA * a3)
2. a3 = (361e-10 cm)3 = 4.70e-23 cm3
3. M = rho * NA * a3 / 4 = 8.90 x 6.022e23 x 4.70e-23 / 4 约等于 63.4 g/mol
4. 查周期表，该金属为 Cu（铜，M = 63.5 g/mol）

## 十一、易错点

1. **气体密度与温度的关系**：温度升高，体积膨胀，密度降低；rho = PM/RT 中 T 在分母，易记反
2. **c = 1000 rho w/M 中 1000 的来源**：1000 是 mL 到 L 的精确换算因子，不是约数
3. **晶胞密度中 Z 的理解**：Z 是结构单元数不是原子数，NaCl 中 Z=4 代表 4 个 NaCl 单元
4. **相对密度的参考气体**：D_H2 = M/2，D_air = M/29，选错参考气体会导致 M 计算错误

## 十二、🎯 教学视角

### 12.1 学习路径建议

**前置知识**：摩尔质量、理想气体状态方程、物质的量浓度概念。

**推荐教学顺序**：
1. 回顾 ρ = m/V 基本公式 → 引出"密度是连接宏观与微观的桥梁"
2. 气体密度 → 摩尔质量测定（M = ρRT/p）→ 相对密度法
3. 溶液密度 → 质量分数与浓度互转（c = 1000ρw/M）→ 分析化学的日常工具
4. 晶胞密度 → ρ = ZM/(Nₐ·V) → 竞赛核心公式，联系 Bragg 方程
5. 综合练习：同一公式在不同物态中的变形应用

**课时建议**：0.5–1 学时（作为工具性知识点穿插在各章节中复习）

### 12.2 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| 气体密度与温度无关 | 温度升高→体积膨胀→密度降低；ρ = PM/RT 中 T 在分母 | "热胀冷缩，密度让座" |
| 溶液 c = 1000ρw/M 中的 1000 是"约数" | 1000 是单位换算：mL→L 的精确换算因子，不是近似 | "千是升毫升的桥" |
| 晶胞密度公式中 Z 就是原子数 | Z 是"每个晶胞中的结构单元数"，如 NaCl 中 Z=4（指4个 NaCl 单元，共8个离子） | "Z 数单元不数离子" |
| 相对密度 D = M₁/M₂ 只能对空气用 | 相对密度可以对任意参考气体，D_H₂ = M/2，D_air = M/29 | "对谁比就除谁的 M" |

### 12.3 入门级例题

**例题**：某金属 M 的面心立方晶体，晶胞参数 a = 361 pm，密度 ρ = 8.90 g/cm³。求 M 的摩尔质量并判断是什么金属。

**引导思路**：
1. FCC 晶胞 Z = 4 → ρ = 4M/(Nₐ·a³)
2. a³ = (361×10⁻¹⁰ cm)³ = 4.70×10⁻²³ cm³
3. M = ρ·Nₐ·a³/4 = 8.90 × 6.022×10²³ × 4.70×10⁻²³ / 4 ≈ 63.4 g/mol
4. 查表 → Cu（铜，M = 63.5 g/mol）✓

**教师引导**：让学生先猜"密度8.9的金属"，建立直觉（铜是紫红色的！），再用计算验证。

### 12.4 与真实世界的联系

- **气体密度与安检**：机场安全气囊检测利用气体密度差异判断包裹中是否藏有异常物质
- **溶液密度与酿酒**：酒度计（酒精密度计）本质就是 c = 1000ρw/M 的应用——酒精浓度越高，密度越低
- **晶胞密度与材料鉴定**：X射线衍射测出晶胞参数后，密度计算是验证"合成产物是否为目标相"的第一步

## 十三、竞赛拓展

1. **晶胞密度公式的"反向"应用——从密度反推未知量**：$\rho = \dfrac{Z \cdot M}{N_A \cdot V}$ 是竞赛晶体结构计算的核心公式，但最常考的题型不是"已知 Z 求 ρ"，而是：① 已知 ρ 和晶体结构 → 反推原子量 M（若 M 非整数 → 同位素混合或合金）；② 已知 ρ 和 M → 反推 Z（→ 修正结构模型）；③ 已知 ρ、M、Z → 反推晶胞参数 a（→ 联系 Bragg 方程的跨知识考点）。例如第 29 届初赛：由密度推算未知金属的原子量 → 查周期表对号入座。

2. **气体相对密度法在竞赛中的进阶应用**：气体对空气的相对密度 $D_{air} = M/29$ 可用于判断气体是否发生**缔合或解离**。例如 NO₂ 在低温下二聚为 N₂O₄——实测分子量为 46（对应 NO₂）→ 但气体密度异常高 → 说明部分以 N₂O₄（M=92）存在 → 可进一步计算二聚度 $\alpha$。竞赛中给"实测蒸气压密度"数据 → 第一步判断分子是否缔合（乙酸蒸气中二聚体占主导），这是质量作用定律和化学平衡的经典联结点。

3. **非理想气体密度修正——压缩因子 Z 的竞赛计算**：真实气体 $pV = ZnRT$ → $\rho = \dfrac{pM}{ZRT}$。竞赛信息题可能给不同 p 下的 Z 数据，要求：① 计算该 p 下的真实密度；② 用 van der Waals 方程估算 Z（$Z = 1 + \dfrac{1}{RT}\left(b - \dfrac{a}{RT}\right)p$ 展开到一阶）；③ 判断 Z > 1（排斥主导，密度偏低）还是 Z < 1（吸引主导，密度偏高）。Boyle 温度 $T_B = a/(Rb)$ 时 Z → 1（低压极限）。
