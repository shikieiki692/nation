# 恒压热与恒容热

## 核心概念

恒压热（$Q_P$）和恒容热（$Q_V$）是两种不同实验条件下测量的反应热效应，分别对应焓变 $\Delta H$ 和内能变化 $\Delta U$。

## 关键公式

### 恒压热效应

$$Q_P = \Delta H$$

- 适用于开放体系（常压下的化学反应）
- 通过咖啡杯量热计等恒压装置测量

### 恒容热效应

$$Q_V = \Delta U$$

- 适用于密闭体系（弹式量热计）
- 测量更精确，但需校正为 $Q_P$

### 两者转换关系

$$Q_P = Q_V + RT\Delta n$$

或

$$\Delta H = \Delta U + RT\Delta n$$

其中 $\Delta n$ 为气态产物与气态反应物的化学计量数之差。

### 特殊情况

| 条件 | 关系 |
|------|------|
| 无气体参与 | $\Delta(PV) \approx 0$，$Q_P \approx Q_V$ |
| $\Delta n = 0$ | $Q_P = Q_V$（如 $H_2 + Cl_2 \rightarrow 2HCl$） |
| $\Delta n > 0$ | $Q_P > Q_V$（气体增多，体系对外做功） |
| $\Delta n < 0$ | $Q_P < Q_V$（气体减少，环境对体系做功） |

### 数值估算

$RT$ 在 298K 时约为 $2.48\ \text{kJ/mol}$，通常 $RT\Delta n$ 项相对于化学键能量（几十到几百 kJ/mol）可忽略。

## 典型应用

1. **弹式量热计数据处理**：将实验测得的 $Q_V$ 转换为 $\Delta H$
2. **燃烧热测定**：有机物燃烧热通常通过弹式量热计测量
3. **反应热比较**：判断不同条件下反应热的差异

## 易错点

1. **符号规定**：放热反应 $Q < 0$，$\Delta H < 0$；吸热反应 $Q > 0$，$\Delta H > 0$
2. **水的状态**：298K 标准状态下水为液态，1000K 时水为气态，$\Delta n$ 的计算需注意
3. **仅考虑气态物质**：$\Delta n$ 只计算气态反应物和产物，液体和固体不计入
4. **$R$ 的单位**：$R = 8.314\ \text{J/(mol·K)}$，计算 $RT\Delta n$ 时需注意与 kJ 的换算
