# 非理想气体

## 一、定义

非理想气体（真实气体）指**偏离理想气体状态方程 pV = nRT 行为**的气体。理想气体假设"分子无体积、分子间无作用力"，只在**低压高温**下近似成立；高压、低温、大分子/强极性气体（CO₂、NH₃、SO₂、重烃）明显偏离。描述与修正工具：①**van der Waals 方程**（体积修正 b + 压力修正 a，定性/半定量最优）；②**压缩因子 Z**（Z = pV/nRT，Z ≠ 1 即偏离，Z < 1 引力主导、Z > 1 斥力/体积主导）；③**逸度（fugacity）**（把非理想压力"折算"成等效理想压力，使热力学公式继续成立，用于化学平衡/电化学的严格计算）。竞赛中它连接"气体定律→状态方程→热力学修正"，34 届决赛（非理想气体与平衡常数）与 30 届（N₂O₄ 分压）真题语境。

## 二、考纲对应

本页属气体-热力学基础，对应"真实气体的偏离与修正"：能用 van der Waals 方程解释 a、b 两项的物理意义并做简单计算；会用压缩因子 Z 判断偏离方向（Z<1 引力、Z>1 斥力）；理解逸度的概念与"p → 逸度"的替换逻辑（平衡常数、化学势计算）；知道临界温度以下可液化、超临界流体的概念。初赛以 Z/状态方程判断题、决赛（34 届）以逸度与 K 计算出现。

## 三、核心原理

### 3.1 理想气体假设的两处"失真"

- **分子有体积**：理想气体把分子当质点；真实分子占体积 → 高压下可压缩空间减小，实际 pV 偏大（Z > 1）。
- **分子间有作用力**：理想气体忽略分子间引力；真实气体中内层分子受整体引力牵拉，撞击器壁压力减小 → 实际 p 偏小（Z < 1，低温/高压明显）。
- 两种效应竞争：低压高温下引力项为主（Z 常 < 1）；极高压力下体积项为主（Z > 1）；某温度（Boyle 温度）附近二者抵消、Z ≈ 1。

### 3.2 van der Waals 方程：两项修正

- 方程：(p + a·n²/V²)(V − nb) = nRT（或对 1 mol：(p + a/Vm²)(Vm − b) = RT）。
- **a（分子间引力参数）**：越大分子间引力越强（CO₂/NH₃/H₂O 大，He/H₂ 近 0）；压力修正项 a/Vm² 反映"内压"。
- **b（分子体积参数，排除体积）**：约等于分子本身体积的 4 倍（每摩尔）；体积修正 Vm − b。
- 适用范围：比理想气体好得多，覆盖气液两相与临界点；但仍是**近似**（更高精度用 Redlich-Kwong、Peng-Robinson 等）。
- 竞赛考法：给 a、b 判断两气体谁更"非理想"（a、b 大者）；或定性解释高压下为何用 V−nb、低压下为何加 a/V²。

### 3.3 压缩因子 Z：偏离的"体检指标"

- Z = pV/(nRT) = pVm/(RT)。理想气体 Z = 1；Z < 1 → 实际体积小于理想（引力主导，如 CO₂ 50 atm、298 K 时 Z ≈ 0.85）；Z > 1 → 体积大于理想（分子本身体积/斥力主导，极高压力）。
- Z 随压力变化有特征形状：先降（引力区）后升（体积区），在某压力取最小；不同温度曲线不同。
- 对应态原理（进阶）：用对比压力/温度，多数气体的 Z–p_r 曲线近似重合——可用普适压缩因子图近似求 Z（竞赛偶尔引入）。

### 3.4 液化与临界现象

- 气体能否加压液化取决于温度是否低于**临界温度 Tc**：T < Tc 加压可液化（出现气液共存与临界乳光）；T > Tc 无论多高压都是气体（超临界流体）。
- 临界点：Tc、pc、Vc 处气液性质合一；van der Waals 方程给出 Tc = 8a/(27Rb)、pc = a/(27b²) 等（可由 a、b 估算 Tc）。
- 超临界 CO₂（T > 31 °C、p > 73 atm）兼具气体扩散与液体溶解力——萃取应用。
- 判定：室温下 CO₂（Tc = 31 °C）可被加压液化（钢瓶液态 CO₂）；H₂/He（Tc 极低）室温永为气态。

### 3.5 逸度：热力学公式的"续命修正"

- 化学势/平衡常数严格应写 μ = μ° + RT·ln(f/p°) 而非用压力 p——**用逸度 f 代替压力 p**（f = γ·p，γ 为逸度系数）。
- γ < 1（引力主导，低压/中压常见）、γ > 1（高压体积主导）；低压极限 f → p（γ → 1）。
- 平衡常数严格版：K° 用逸度比计算——34 届"非理想气体与平衡常数"即考把 Kp 换成 K_f（或给逸度系数修正）。
- 竞赛定位：理解"为什么高压反应/真实气体的平衡计算要引入逸度"与简单代换即可，深算见物理化学深化页。

## 四、关键结论

- 理想气体是"低压高温"极限；真实气体在高压/低温/大分子下偏离（分子体积 + 分子间力）。
- van der Waals：(p + a/Vm²)(Vm − b) = RT——a 管引力、b 管体积，两修正各司其职。
- Z = pVm/RT：Z<1 引力主导、Z>1 体积主导、Z=1 理想（或 Boyle 温度抵消）。
- T < Tc 可液化；超临界流体在 Tc、pc 之上。
- 严格热力学用逸度 f 替压力 p（f = γp）；低压极限 f → p。

## 五、常见分类或情形

- **按偏离来源**：引力主导（Z<1：低温/中高压 CO₂、NH₃）、体积主导（Z>1：极高压力）、近理想（He/H₂ 高温）。
- **按修正工具**：van der Waals（状态方程）、压缩因子（判偏离）、逸度（热力学代换）、维里展开（进阶精确）。
- **按温度区间**：T < Tc（可液化）、T > Tc（超临界）。
- **按考法**：a/b 物理意义、Z 判断、气液液化判断、逸度与平衡常数（34 届）、实际气体分压（30 届 N₂O₄）。

## 六、适用条件与限制

- van der Waals 是半定量修正：临界区/高密度时误差大，需高阶方程。
- Z 需指定温度压力才唯一；"Z = 0.85"必须带条件（否则无意义）。
- 逸度系数 γ 依赖温度压力与组分（混合气体用路易斯规则近似）——深算超出初赛，决赛按题目给值处理。
- 理想气体假设在多数竞赛计算题仍被默认（题目不说非理想就按理想）——别过度修正。
- 分压定律（Dalton）对真实气体也有偏差（分子间力使分压非线性）——精确混气用逸度。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 高压 = 一定偏离 | 偏离取决于温度与气体种类：He 在高压仍接近理想；CO₂ 中压已偏离——看 Z 而非只看压力 |
| van der Waals 是精确方程 | 只是两参数半定量修正；精确需更高阶状态方程（RK/PR/维里） |
| 逸度就是修正后的压力 | 逸度是"等效理想压力"（使 μ 公式成立）；γ 是修正系数，f 不是直接测的压力 |
| Z<1 与 Z>1 的物理原因 | Z<1 引力（内压使 p 小）；Z>1 分子体积（可压缩空间小）——同一气体不同压力可先后出现两区 |
| 临界温度与沸点 | Tc 是"加压液化上限温度"（物性常数）；沸点是 1 atm 下气液平衡温度——别混 |

## 九、典型题型

- **Z 判断**：给 Z 值/条件判断引力还是体积主导；给 p-T 条件判断接近理想与否。
- **van der Waals 计算**：用 a、b 估 Vm（迭代）或由临界参数求 a、b。
- **液化判断**：室温能否把某气体加压液化（比较 Tc）。
- **逸度代换**：非理想气体的 K（K_f）与 Kp 换算（34 届题-2-5-5）。
- **实际气体分压**：N₂O₄ ⇌ 2NO₂ 的平衡分压计算（30 届语境，注意理想假设何时失效）。

## 十、例题

**例题 1**：CO₂ 在 298 K、50 atm 时 Z = 0.85。说明其偏离方向与主导因素。

**解答**：Z = pVm/RT = 0.85 < 1 → 实际摩尔体积小于理想气体预测（同压下"更挤"）——分子间引力主导：内层 CO₂ 分子受整体引力牵拉，撞击器壁的有效压力减小，表现为体积偏小。CO₂ 是较大、可极化的分子（a 参数大），中高压下引力效应显著；若加压到数百 atm，体积排斥项将反超、Z 回升 >1。

**例题 2**：判断下列气体在 25 °C 能否用单纯加压液化：CO₂（Tc = 31 °C）、N₂（Tc = −147 °C）、NH₃（Tc = 132 °C）。

**解答**：加压液化的条件是 T < Tc。25 °C = 298 K：CO₂（Tc 304 K > 298 K）→ 可液化（钢瓶液态 CO₂）；NH₃（Tc 405 K）→ 可液化（液氨）；N₂（Tc 126 K < 298 K）→ **不可液化**，25 °C 下 N₂ 无论多高压都是超临界/气态（工业靠深冷液化）。判据：比较操作温度与临界温度。

**例题 3**：某真实气体反应在高压下进行，用 Kp（压力商）计算与用逸度计算哪个更正确？为什么？

**解答**：严格的热力学平衡常数应用**逸度**：K° = Π(f_i/p°)ᵛⁱ（或对气体 K_f = Πfᵛⁱ），因为化学势 μ = μ° + RT ln(f/p°) 才严格成立。高压下 γ ≠ 1（f ≠ p），Kp 会随压力"漂移"（表观变化），而 K_f 是真正常数——34 届真题即考"非理想气体平衡常数"要用逸度修正。低压极限 γ→1、K_f→Kp，两种处理一致。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 认为高压气体必然强偏离 | 偏离由 Z 决定：He/H₂ 高压仍近理想（a、b 极小）；CO₂ 中压已偏——"高压=偏离"是粗略印象 | 判别：看气体种类与温度（a、b 大小、与 Tc 距离），别只看压力数字 |
| van der Waals 当精确解 | 两参数方程是半定量近似；临界区误差大，工业用 RK/PR 等 | 判别：题问"精确计算"要用给定高阶方程；vdW 用于解释与估算 |
| 逸度与压力混为一谈 | 逸度是等效理想压力（γ 修正后），不是实测压力；γ<1 时 f<p | 判别：μ 公式与 K° 一律用 f；只有 γ=1（低压）才可代 p |
| Z 的方向与原因颠倒 | Z<1 = 引力（p 被"拉小"）；Z>1 = 分子体积（空间被"占"）——同气体先 Z<1 后 Z>1 | 判别：记住 CO₂ 50 atm Z≈0.85（引力）；几百 atm 后 Z>1（体积）——两区都要会解释 |
| 忽略"题设是否理想" | 多数竞赛计算默认理想气体；题目特意给 a/b、γ、Z 或说"高压/真实气体"才需修正 | 判别：先读题设——给 Z/逸度系数就要修正，否则按理想 pV=nRT |

## 十二、🎯 教学视角

### 12.1 学习路径建议
非理想气体应在理想气体状态方程与 van der Waals 方程之后学习。先理解理想假设的两处失真（分子体积/分子间力），再学 vdW 两项修正与 Z 判偏离，接着用 Tc 判液化/超临界，最后引入逸度完成热力学衔接（决赛用）。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 高压下所有气体都偏离理想行为 | 偏离程度取决于温度与气体种类（He 高压仍近理想）——看 Z |
| van der Waals 方程能精确描述所有气体 | 它是两参数半定量修正；精确描述需高阶状态方程 |
| 逸度就是修正后的压力 | 逸度是等效压力（使热力学公式成立），γ 为修正系数 |
| Z<1/Z>1 原因 | Z<1 引力主导、Z>1 分子体积主导——同一气体不同压力可先后出现 |

### 12.3 入门级例题
**题目**：CO₂ 在 298 K、50 atm 时压缩因子 Z = 0.85，说明什么？

**解答**：Z < 1 说明实际气体体积小于理想气体预测，分子间引力占主导——CO₂ 在该条件下偏离理想行为。

### 12.4 与现实世界的联系
1. **深海潜水**：高压呼吸气体（氦氧混合）的非理想行为影响供气安全与减压计划。
2. **天然气管道**：长距离输送需用真实气体状态方程算压降与流量。
3. **超临界流体**：超临界 CO₂ 萃取利用临界点附近的特殊溶解/扩散性质（食品/制药）。
