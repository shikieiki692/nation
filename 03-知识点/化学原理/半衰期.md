# 半衰期

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[07-化学平衡]]

## 一、定义
**半衰期** $t_{1/2}$ 指反应物浓度降为初始值一半所需的时间。

它是描述反应快慢的一个非常直观的量，特别常用于一级反应和放射性衰变。

## 二、考纲对应
- [[07-化学平衡]]：反应级数、积分速率方程、半衰期规律

## 三、核心原理

### 一级反应
若 $v = k[A]$，则：

$$t_{1/2} = \frac{\ln 2}{k} = \frac{0.693}{k}$$

这是最重要的结论，因为**一级反应的半衰期与初始浓度无关**。

### 二级反应
若 $v = k[A]^2$，则：

$$t_{1/2} = \frac{1}{k[A]_0}$$

二级反应的半衰期与初始浓度成反比。

### 零级反应
若 $v = k$，则：

$$t_{1/2} = \frac{[A]_0}{2k}$$

零级反应的半衰期与初始浓度成正比。

## 四、关键结论

1. **一级反应最特殊**：半衰期恒定，不随起始浓度改变。
2. **半衰期可反推速率常数**：一级反应中 $k = 0.693/t_{1/2}$。
3. **半衰期常用于作图和定性判级**：
   - 若不同初始浓度下 $t_{1/2}$ 不变，常提示一级反应
   - 若 $t_{1/2}$ 随 $[A]_0$ 增大而减小，常提示二级反应

## 五、常见分类或情形

### 1. 一级反应与放射性衰变
放射性核衰变通常服从一级规律，因此常直接用半衰期表示衰变快慢，例如 $^{14}\mathrm{C}$ 测年。

### 2. 动力学判级
题目若给出不同起始浓度下的半衰期，可快速判断反应级数。

### 3. 寿命估算
药物代谢、材料老化、污染物降解等问题中，半衰期常被用来估算“剩余一半需要多久”。

## 六、适用条件与限制
- 必须建立在对应级数的速率方程成立的前提下
- 对复杂多步反应，半衰期可能只是经验量，不一定能直接套简单公式
- 使用时要先确认级数，再选公式

## 七、常见错误
- 把一级反应的 $t_{1/2} = 0.693/k$ 误用于所有反应
- 忘记二级反应公式中含有 $[A]_0$
- 用半衰期判断级数时忽略实验误差

## 八、与其他知识点的连接
- 与 [[反应级数]]：半衰期规律是判别级数的重要抓手
- 与 [[反应速率]]：半衰期是速率快慢的另一种表达
- 与 [[速率方程]]：不同速率方程对应不同半衰期公式

## 九、一句话记忆
**半衰期是”浓度减半要多久”，而一级反应最关键的特征是它与初始浓度无关。**

## §12 教学视角

### 学生常见认知误区
- **误区1：「所有反应的半衰期都是 t₁/₂ = 0.693/k」** → 这只适用于一级反应。二级反应 t₁/₂ = 1/(k[A]₀)，零级反应 t₁/₂ = [A]₀/(2k)，公式完全不同。 → **口诀：0.693 只属一级，二级除以浓度，零级乘以浓度；公式选错全白费**
- **误区2：「半衰期越短说明反应越快」** → 同级数比较时成立，但跨级数比较时不可靠。一级反应半衰期与 [A]₀ 无关，二级反应半衰期与 [A]₀ 成反比，不同级数的半衰期受浓度影响的方式不同。 → **口诀：同级比 k 值，跨级看级数；半衰期不是万能尺**
- **误区3：「放射性衰变的半衰期可以通过改变条件来改变」** → 放射性衰变是一级过程，其速率常数 k 由核内部结构决定，温度、压力、化学环境等均无法改变其半衰期。 → **口诀：核衰变看核不看外，温度压力都无奈**

### 入门级例题
**题目**（初赛难度）：某反应在不同初始浓度下的半衰期实验数据如下：[A]₀ = 0.10 mol·L⁻¹ 时 t₁/₂ = 50 s；[A]₀ = 0.20 mol·L⁻¹ 时 t₁/₂ = 25 s；[A]₀ = 0.40 mol·L⁻¹ 时 t₁/₂ = 12.5 s。(a) 判断反应级数；(b) 求速率常数 k。

**分析**：观察半衰期与初始浓度的关系。[A]₀ 加倍时 t₁/₂ 减半，说明 t₁/₂ ∝ 1/[A]₀，符合二级反应特征。

**解答**：

(a) 由数据：[A]₀ 从 0.10 → 0.20（×2），t₁/₂ 从 50 → 25（÷2），即 t₁/₂ ∝ [A]₀⁻¹。这与二级反应的 t₁/₂ = 1/(k[A]₀) 一致，因此反应为**二级反应**。

(b) 代入二级反应公式：

$$k = \frac{1}{t_{1/2} \cdot [A]_0} = \frac{1}{50 \times 0.10} = 0.20\ \mathrm{L \cdot mol^{-1} \cdot s^{-1}}$$

验证：k = 1/(25 × 0.20) = 0.20 L·mol⁻¹·s⁻¹，一致。

**反思**：判级的核心是看 t₁/₂ 对 [A]₀ 的依赖关系：恒定→一级，反比→二级，正比→零级。竞赛中常以实验数据表格形式出题，需快速识别规律。

### 与现实/直觉的连接
半衰期就像”沙漏翻转的时间”——每翻转一次，剩余的沙子减半。对于一级反应（如放射性衰变），沙漏的速度是恒定的，无论沙子多少，每次翻转时间相同。对于二级反应，沙子越多翻转越快（分子碰撞概率高），沙子越少翻转越慢——就像两个人要在茫茫人海中找到对方，人越多越容易碰面，剩的人越少越难找。零级反应则像是固定速率的传送带，不管有多少货物都以相同速度搬运。

### 教学建议
1. **先建”三级对比表”**：在黑板上并排写出零级、一级、二级的速率方程、积分式、半衰期公式，让学生一目了然
2. **用”判级练习”巩固**：给出多组 [A]₀ vs t₁/₂ 数据，让学生先判断级数再选公式计算 k
3. **强调”先确认级数再选公式”**：这是竞赛中最常见的错误模式——学生直接套用 t₁/₂ = 0.693/k 而不判断级数
4. **关联放射性衰变**：¹⁴C 测年是一级反应半衰期的经典应用，可以让学生计算”经过 n 个半衰期后剩余多少”
5. **区分”半衰期”与”寿命”**：平均寿命 τ = 1/k（一级反应），τ = t₁/₂/ln2，两者容易混淆
