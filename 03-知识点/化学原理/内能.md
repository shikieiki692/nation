# 内能

![[zhao_dg_w_relation_91524757.jpg]]

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[06-热力学初步]]

## 一、定义
**内能** $U$ 是体系内部各种微观能量的总和，包括分子运动能、相互作用势能等。

## 二、考纲对应
- [[06-热力学初步]]：热、功、内能与焓的关系

## 三、核心原理
- 内能是**状态函数**
- 绝对值通常不直接使用，解题中更关注 $\Delta U$
- 根据 [[热力学第一定律]]：

$$\Delta U = Q + W$$

## 四、关键结论
1. 在等容且不做非体积功时，$\Delta U = Q_V$。
2. 对很多化学反应，$\Delta U$ 与 [[焓]] 关系密切：

$$\Delta H = \Delta U + \Delta nRT$$

3. 多数常压化学问题更常直接使用焓，但内能是更基础的起点。

## 五、常见分类或情形
- **等容过程**：直接对应内能变化
- **理想气体反应**：常与气体物质的量变化一起出现

## 六、常见错误
- 把内能当成“热量”
- 混淆 $\Delta U$ 与 $\Delta H$

## 七、一句话记忆
**内能是体系内部能量账本，第一定律描述的正是这本账如何因热和功而改变。**

## §12 教学视角

### 学生常见认知误区
- **误区1：「内能就是热量」** → 日常说“加热增加内能”让学生把 Q 和 U 混淆 → **口诀：热量是过程量（不带 Δ），内能是状态量（只看 ΔU）；内能变化 = 热 + 功，不是只有热**
- **误区2：「等容过程没有功」** → 忘记等容只意味着体积功 W_V = 0，但可能还有非体积功 → **口诀：等容 W_V=0，不等于 W=0；除非题目说“不做非体积功”**
- **误区3：「ΔH 永远等于 ΔU」** → 忽略 ΔH = ΔU + ΔnRT 中 Δn 项 → **口诀：气态物质的量不变时 ΔH = ΔU，有气体摩尔数变化时必须修正**

### 入门级例题
**题目**: 在恒容弹式量热计中燃烧 0.100 mol 苯 C₆H₆(l)，温度升高 2.56 K，量热计热容 C_V = 15.2 kJ/K。求 Δ_rU。
**分析**: 恒容条件下 ΔU = Q_V，Q_V = C_V · ΔT。
**解答**:
$$
Q_V = 15.2 × 2.56 = 38.9 kJ
$$
$$
Δ_rU = Q_V / n = -38.9 / 0.100 = -389 kJ/mol
$$
**反思**: 弹式量热计测的是 ΔU 而非 ΔH；如需 ΔH，还需用 ΔH = ΔU + Δn_g RT 修正。

### 与现实/直觉的连接
内能是体系的“能量总账”——体系内部所有分子的动能和势能之和。你无法知道这本账的绝对余额，但可以精确记录每一笔收支（ΔU）。第一定律就是“收支平衡表”：热 + 功 = 内能变化。

### 教学建议
1. **强调状态函数 vs 过程量**：画 U 的“台阶图”，ΔU 只取决于起点和终点
2. **符号约定统一**：明确教材采用 IUPAC 约定，不同教材符号不同是学生最大困惑来源
3. **ΔU vs ΔH 的使用场景**：等容用 ΔU，等压用 ΔH
4. **先做简单数值练习**：Q = nC_VΔT、Q = nC_pΔT 的计算让学生建立信心
5. **连接理想气体内能只与温度有关**：这一结论在后续热力学循环中反复使用
