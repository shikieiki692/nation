# 电子排布规则

## 核心概念

电子排布规则是描述原子中电子如何填充原子轨道的三条基本原则，由构造原理（Aufbau principle）、泡利不相容原理（Pauli exclusion principle）和洪特规则（Hund's rule）组成。

## 关键公式

### 轨道能量顺序（构造原理）

$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d < 7p$$

**记忆口诀**：按周期表排列，注意 $4s$ 在 $3d$ 之前，$6s$ 在 $4f$ 和 $5d$ 之前。

### 三条基本规则

**1. 能量最低原理（Aufbau Principle）**
- 电子优先填入能量最低的可用轨道
- 新电子依次填入：$1s \to 2s \to 2p \to 3s \to 3p \to 4s \to 3d \to ...$

**2. 泡利不相容原理（Pauli Exclusion Principle）**
- 一个原子轨道最多容纳2个电子，且自旋必须相反
- 四个量子数（$n, l, m_l, m_s$）不能完全相同的两个电子不能共存

**3. 洪特规则（Hund's Rule）**
- 在简并轨道（如3个 $p$ 轨道、5个 $d$ 轨道）上，电子优先以平行自旋方式单独占据不同轨道
- 使未成对电子数最大化，降低电子间排斥能

### 半满/全满修正规则

- $d^5$（半满）和 $d^{10}$（全满）状态具有额外稳定性
- 典型特例：
  - Cr: $[Ar] 4s^1 3d^5$（而非 $4s^2 3d^4$）
  - Cu: $[Ar] 4s^1 3d^{10}$（而非 $4s^2 3d^9$）

### 电子排布简写

使用稀有气体原子实表示：$[Ne] 3s^1$ 表示 Na，$[Ar] 4s^2 3d^{10} 4p^5$ 表示 Br

## 典型应用

1. **元素性质预测**：通过电子排布判断元素的化学性质、化合价、磁性
2. **过渡金属特例**：解释 Cr、Cu 等元素的异常电子排布
3. **离子电子排布**：先失去最外层电子（$4s$ 先于 $3d$ 失去）
4. **光谱项推导**：电子排布是推导原子光谱项的基础

## 易错点

1. **$4s$ 与 $3d$ 的填充顺序**：填充时 $4s$ 先于 $3d$，但失去电子时 $4s$ 也先于 $3d$ 失去
2. **书写顺序差异**：国际教材按填充顺序写（$4s^2 3d^1$），国内高考要求按主量子数排序（$3d^1 4s^2$），竞赛中两种均可
3. **半满全满规则的适用范围**：仅当外层轨道能量接近时适用（如 $3d$ 与 $4s$），对 $s$-$p$ 能量差较大的情况不适用（如 Si 保持 $3s^2 3p^2$ 而非 $3s^1 3p^3$）
4. **洪特规则的自旋平行**：单独占据不同轨道的电子自旋必须平行（同向）
5. **原子实的选择**：原子实对应最接近的稀有气体，如 K 用 $[Ar]$ 而非 $[Ne]$
