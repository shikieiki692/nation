# 量热法

## 核心概念

量热法（Calorimetry）是通过测量温度变化来确定化学反应热效应的实验方法。根据实验条件分为恒压量热和恒容量热两种。

## 关键公式

### 恒压量热（咖啡杯量热计）

$$q_p = m \cdot c \cdot \Delta T = \Delta H$$

- $m$：溶液质量（g）
- $c$：比热容，水溶液通常取 $4.18\ \text{J/(g·°C)}$
- $\Delta T = T_{\text{终}} - T_{\text{始}}$

### 恒容量热（弹式量热计）

$$q_v = -C_{\text{cal}} \cdot \Delta T = \Delta U$$

- $C_{\text{cal}}$：量热计总热容（kJ/K 或 J/K）
- 负号表示放热反应中体系内能降低

### 两种量热的转换

$$\Delta H = \Delta U + RT\Delta n$$

或

$$q_p = q_v + RT\Delta n$$

其中 $\Delta n$ 为气态物质的化学计量数变化。

### 热容的概念

$$C = \frac{q}{\Delta T}$$

- $C$（热容）：体系温度升高1K所需吸收的热量，单位 J/K 或 kJ/K
- $c$（比热容）：单位质量物质的热容，单位 J/(g·K)

## 典型应用

1. **燃烧热测定**：用弹式量热计测量有机物的恒容燃烧热
2. **溶解热测定**：用咖啡杯量热计测量盐类溶解的热效应
3. **生成焓推导**：通过燃烧热数据结合盖斯定律计算标准生成焓
4. **键能计算**：从实验焓变反推化学键的键能

## 易错点

1. **符号规定**：温度升高 $\Delta T > 0$，放热反应 $\Delta H < 0$，两者符号相反
2. **弹式量热计测的是 $\Delta U$ 而非 $\Delta H$**：需通过 $RT\Delta n$ 校正
3. **热容单位**：$C_{\text{cal}}$ 的单位是 J/K 或 kJ/K，注意与比热容 J/(g·K) 区分
4. **有效数字**：量热实验中温度测量精度通常为 ±0.01K，限制了最终结果的有效数字
5. **绝热假设**：实际量热计与环境有热交换，需进行散热校正

## 九、🎯 教学视角

### 9.1 学习路径建议
量热法应在学习热力学第一定律之后引入，是将理论与实验结合的桥梁。先理解恒压和恒容量热的物理区别，再掌握两种量热计的使用原理和数据处理方法，最后学习如何从量热数据推导其他热力学量。

### 9.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 咖啡杯量热计和弹式量热计测量结果相同 | 咖啡杯量热计测Qp=ΔH，弹式量热计测Qv=ΔU，两者不同 |
| 量热实验不需要散热校正 | 实际量热计与环境有热交换，精密测量需要散热校正 |
| 比热容和热容是同一个概念 | 热容是体系的属性（J/K），比热容是单位质量的热容（J/(g·K)） |

### 9.3 入门级例题
**题目**：在咖啡杯量热计中，将50.0 mL 1.00 mol/L HCl与50.0 mL 1.00 mol/L NaOH混合，温度从25.00°C升至31.67°C。求中和热。（溶液密度1.00 g/mL，比热容4.18 J/(g·K)）
**解答**：q = mcΔT = 100.0×4.18×6.67 = 2788 J = 2.79 kJ。n(H₂O) = 0.050 mol，ΔH = -2.79/0.050 = -55.8 kJ/mol。

### 9.4 与现实世界的联系
1. **食品工业**：弹式量热计用于测定食品热量，营养标签数据来源于此
2. **建筑材料**：量热法测定水泥水化热，指导大体积混凝土施工
3. **药物研发**：微量量热法用于研究药物与蛋白质的结合热
