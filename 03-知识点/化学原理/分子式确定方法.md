# 分子式确定方法

## 核心概念

分子式确定是通过元素分析数据和分子量信息来确定化合物化学式的方法。分为两步：先确定实验式（经验式），再确定分子式。

**三步主干**：① 元素分析 → 各元素质量分数；② 质量分数 ÷ 原子量 → 物质的量比 → 取最简整数比 = 实验式；③ 实验式量 × n = 分子量 → 分子式。第③步的 n 若无分子量信息，可借助质谱（分子离子峰）或不饱和度约束推断。

**"实验式 ≠ 分子式"是第一原则**：CH₂O 既是甲醛（M = 30）也是乙酸甲酯等一切 (CH₂O)ₙ 的实验式——只有结合分子量才能定 n。乙炔 C₂H₂ 与苯 C₆H₆ 实验式同为 CH，是另一个经典例子。

## 关键公式

### 从质量分数确定原子个数比

$$n_X = \frac{M \times w\%_X}{A_{r,X}}$$

- $M$：化合物摩尔质量（g/mol）
- $w\%_X$：元素 X 的质量分数
- $A_{r,X}$：元素 X 的相对原子质量

（实际计算中 M 可约去，直接用 w%_X/A_r,X 之比取最简整数比。）

### 从原子个数比确定实验式

将各元素原子个数比取整数比（或最简整数比）即为实验式。

### 从实验式确定分子式

$$\text{分子式} = (\text{实验式})_n$$

其中 $n = \frac{M_{\text{分子量}}}{M_{\text{实验式量}}}$

### 不饱和度（验证/约束分子式）

Ω = (2C + 2 + N − H − X)/2（X 为卤素）

- Ω = 0 饱和链烷/醇/醚；Ω = 1 一个双键或一个环；Ω = 2 一个三键或两个双键……
- **用途 1**：分子式写完后用 Ω 核对合理性（如 C₇H₁₀ 的 Ω = (14+2−10)/2 = 3——若题说无环无双键则矛盾，必为结构推断错误）
- **用途 2**：质谱/元素分析只给实验式时，用 Ω ≥ 0 且为整数的约束尝试 n

## 计算步骤（完整流程）

1. **确定各元素的质量分数**（题目给出或通过燃烧分析计算：CO₂ 质量 → C%；H₂O 质量 → H%；N 用凯氏定氮或气体体积；O 用差减法 = 100% − 其余）
2. **计算各元素的物质的量之比**：$n_X = w\%_X / A_{r,X}$
3. **取整数比得到实验式**（各项 ÷ 最小值；若得 1.5/2.5 类分数 ×2；×3……直到全整数）
4. **结合分子量确定分子式**：$n = M_{\text{分子量}} / M_{\text{实验式量}}$
5. **验证**：算不饱和度 Ω 检查合理性 + 核对总质量分数 = 100%

## 燃烧分析的完整推导

**题目型数据**：某有机物仅含 C、H、O，取 0.300 g 完全燃烧，得 CO₂ 0.660 g、H₂O 0.270 g。求实验式。

**推导**：
- n(C) = 0.660/44 = 0.0150 mol → m(C) = 0.180 g
- n(H) = 2×0.270/18 = 0.0300 mol → m(H) = 0.030 g（注意 H 的物质的量要乘 2！）
- m(O) = 0.300 − 0.180 − 0.030 = 0.090 g → n(O) = 0.005625 mol
- n(C):n(H):n(O) = 0.0150:0.0300:0.005625 = 2.67:5.33:1 = 8:16:3 → **实验式 C₈H₁₆O₃**

**要点**：① 水的物质的量 ×2 才是 H 的物质的量（每分子水含 2 个 H）——漏乘 2 是最高频失误；② O 用差减法得质量再除原子量（不是直接减物质的量）；③ 比例出现 .67/.33 时整体 ×3。

## 典型应用

1. **有机物分子式推断**：竞赛中经典考点，结合燃烧分析数据
2. **无机化合物鉴定**：通过元素分析确定组成
3. **水合物化学式**：通过失重分析确定结晶水数目（加热失水：Δm/M(H₂O) 得结晶水数）

## 质谱辅助（分子量判定）

- **分子离子峰 M⁺**：最高质量峰（注意同位素峰 M+1 会干扰，看相对强度判断：含 Cl/Br 有特征同位素簇）
- **氮规则**：含偶数个 N 的分子（无 N 视为 0 个偶数）分子量为偶数，含奇数个 N 分子量为奇数——写分子式后快速自检（如 M = 73 却写了无 N 式，必错：奇数质量必须含奇数 N）
- **高分辨质谱**：精确质量（如 180.0634）直接匹配唯一分子式（C₆H₁₂O₆ 的精确质量 180.0634）——竞赛常给 4 位小数反推元素组成
- **M+1/M 峰比**：估算 C 数（¹³C 天然丰度 1.1%，每 100 个 C 贡献 ~1.1 个 M+1）——进阶判断 C 数

## 水合物失重算例

**题目**：2.50 g CuSO₄·xH₂O 加热至恒重得 1.60 g 无水 CuSO₄。求 x。

**解答**：失水 0.90 g → n(H₂O) = 0.90/18 = 0.050 mol；n(CuSO₄) = 1.60/160 = 0.010 mol；x = 0.050/0.010 = **5** → CuSO₄·5H₂O。

**要点**：失重分析的本质是"测水含量确定结晶水数"，原理与元素分析相同——由组分质量反推化学式计量比。

## 质谱定分子量的正确姿势

1. **M⁺ 归属**：分子离子峰是最高质量处符合氮规则的同位素簇起点；含 Cl/Br 时先认同位素簇（Cl：M 与 M+2 约 3:1；Br：约 1:1）再定 M⁺。
2. **氮规则**：M 为偶数 ⟺ 含偶数个 N（0、2、4…）；M 为奇数 ⟺ 含奇数个 N（1、3…）——写完分子式立即核验。
3. **精确质量匹配**：高分辨 MS 给到小数点后 3~4 位（如 180.0634），与候选分子式的精确质量比对，唯一确定组成。
4. **M+1 同位素比估算 C 数**：¹³C 丰度 1.1%，(M+1)/M ≈ 1.1%×n(C) + 0.37%（¹⁵N 贡献，若含 N）——可反推碳数范围。

**常见错误模式**：把碎片峰或含同位素峰误当 M⁺ → 分子量错 → 全链错。判据是"最高质量 + 符合氮规则 + 与元素分析相容"三者同时满足。

## 常见比例陷阱速查

| 原子比形态 | 正确取整 | 典型化合物 |
|---|---|---|
| 1:1 | ×1 | CH（苯/乙炔的实验式） |
| 1:1.5 | ×2 → 2:3 | C₂H₃（丙烯基类） |
| 1:2.5 | ×2 → 2:5 | C₂H₅（乙基） |
| 2.67:5.33:1 | ×3 → 8:16:3 | 多羟基/醚类 |
| 1:2:0.5 | ×2 → 2:4:1 | 含氧有机物常见 |

**判别**：先全部除以最小者，出现 x.33/x.67 试 ×3，出现 x.5 试 ×2，出现 x.25/x.75 试 ×4——直到全整数且数值合理（H 数不超 2C+2+N 等化学约束）。
- 若含卤素：卤素按 H 位置计入 Ω 公式（X 视同 H）；含 O 不影响 Ω——先定分子式再算 Ω 才不会把卤素漏掉。
- 含 S/P 的分子式：S 与 O 同族位置处理（Ω 公式不含 S），质量分数路径照常，只是原子量表别查错。
- 收尾自检：拿到任一组质量分数，能闭眼走完"摩尔比 → 实验式 → 分子量定 n → 氮规则 + Ω 双验证"，本页掌握达标。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 实验式当分子式 | 实验式只给最简比，缺分子量无法定 n | CH₂O 可能是甲醛(30)、乙酸(60)、葡萄糖(180) |
| H 的物质的量忘乘 2 | 每 mol H₂O 含 2 mol H | 0.270 g 水 = 0.015 mol → n(H) = 0.030 不是 0.015 |
| 差减法算 O 用物质的量减 | 质量守恒：m(O) = m总 − m(C) − m(H)，先减质量再除原子量 | 0.300−0.180−0.030 = 0.090 g，不能拿 mol 直接减 |
| 整数比处理不当 | 1.5/2.5/3.33 需整体 ×2/×3，不能四舍五入 | 2.67:5.33:1 ×3 → 8:16:3；四舍五入会错成 3:5:1 |
| 忽略氮规则/Ω 验证 | 分子式可能违反奇偶或 Ω 非整数 | M = 73 必须含奇数 N；C₇H₁₀ Ω = 3 与"饱和"描述冲突 |
| 元素分析总和强行凑 100% | 实验有误差，O 用差减、其余允许 ~±0.3% 漂移 | C 40.1%/H 6.7% 时 O 取 53.2% 而非硬凑 53.3% 的假精确 |

## 七、🎯 教学视角

### 7.1 学习路径建议
分子式确定方法应在学习化学计量和摩尔概念之后引入。先掌握从元素分析数据计算实验式的方法，再学习如何利用分子量信息从实验式推导分子式，最后结合不饱和度等辅助手段验证结果。

### 7.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 实验式就是分子式 | 实验式只给出最简原子比，分子式可能是实验式的整数倍 |
| 元素分析数据总和必须恰好等于100% | 实验数据有误差，总和可能偏离100%，需合理处理 |
| 含C、H、O的化合物氧必须通过减法求得 | 当已知C和H的质量分数时，剩余部分假设为O |

### 7.3 入门级例题
**题目**：某有机物含C 40.0%、H 6.7%、O 53.3%，分子量为180，确定分子式。
**解答**：n(C):n(H):n(O) = 40.0/12 : 6.7/1 : 53.3/16 = 3.33:6.7:3.33 ≈ 1:2:1，实验式为CH₂O。实验式量=30，n=180/30=6，分子式为C₆H₁₂O₆（葡萄糖）。

### 7.4 与现实世界的联系
1. **药物研发**：新药合成后首先通过元素分析确认分子式
2. **法医鉴定**：未知粉末的元素分析可快速缩小嫌疑人范围
3. **食品检测**：检测食品添加剂的分子组成以确认真伪

> **记忆锚**：质量分数除原子量得摩尔比 → 取整成实验式 → 分子量除实验式量得 n → Ω 与氮规则双验证——五步走完分子式到手。

## 竞赛考察要点与命题角度

1. **燃烧分析 + 分子量**：C/H/O 有机物的标准推断（上例流程）。
2. **含 N/卤素**：氮规则奇偶校验、卤素的 AgX 沉淀定量（X% 由 AgCl/AgBr 质量反推）。
3. **质谱综合**：给 MS 谱图（分子离子峰 M⁺、M+1 同位素比）求分子式——高分辨质量匹配。
4. **Ω 反推结构线索**：先定分子式 → Ω 排除结构（双键/环/三键数）→ 结合波谱断结构——从"式"到"结构"的桥。
5. **多步反应产物推断**：中间产物分子式由元素分析定，再经反应推最终结构——分子式确定嵌入全合成推断题。
