# 基尔霍夫定律

## 核心概念

- 反应热随温度变化的定量关系
- 本质是汉斯定律（Hess's law）的特例：把"反应物在 T₁ → 反应物在 T₂"与"产物在 T₂ → 产物在 T₁"的升温/降温焓变补进循环，就得到不同温度反应焓的换算
- 适用于反应物不变但温度变化的情况；是 298 K 标准数据推广到任意温度的标准工具

**物理图像**：ΔrH(T₂) 与 ΔrH(T₁) 之差，等于把反应物从 T₁ 加热到 T₂ 所需热量减去把产物从 T₁ 加热到 T₂ 所需热量——差值为正是因产物热容小于反应物热容（温度升高时"少吸收"的热量体现为反应焓增大）。

## 关键公式/方程式

### 积分形式
$$\Delta_r H_m^{\theta}(T_2) = \Delta_r H_m^{\theta}(T_1) + \int_{T_1}^{T_2} \Delta C_P \, dT$$

### 热容差
$$\Delta C_P = \sum \nu_i C_{P,m,i}$$
（产物系数为正，反应物系数为负）

### 简化形式（$\Delta C_P$ 为常数）
$$\Delta_r H_m^{\theta}(T_2) = \Delta_r H_m^{\theta}(T_1) + \Delta C_P (T_2 - T_1)$$

### 温度区间跨相变时的分段处理

若 T₁→T₂ 之间某组分发生相变（如 H₂O 在 100°C 汽化、金属在中间温度熔化），**热容不连续**，不能直接套简化式，必须分段：

ΔrH(T₂) = ΔrH(T₁) + ∫(T₁→T相变)ΔCp·dT + Δ相变H(按化学计量) + ∫(T相变→T₂)ΔCp'·dT

漏掉相变焓或把相变前后热容当同一段积分，是变温计算最常见的失分点。

### 恒容对应形式

标准形式是恒压关系；恒容过程用 ΔCv = ΣνiCv,m,i 修正 ΔrU：

ΔrU(T₂) = ΔrU(T₁) + ΔCv(T₂ − T₁)

## 规律与趋势

- 以 $T_1$ 为基态，积分从 $T_1$ 到 $T_2$ 更易记
- 热容通常是温度的函数：$C_P = a + bT + cT^2 + \cdots$
- 考试通常保留到一次项
- ΔCp 的符号决定反应焓随温度变化的方向：ΔCp < 0（产物热容小）→ 温度升高 ΔrH 减小（放热反应放得更多）；气体分子数减少的反应常因产物热容小而呈此趋势
- 温度区间不大（<100 K）且无相变时，ΔrH 随温度变化通常 <5%，可近似不变——初赛多数题可忽略，但题面若强调"精确计算/高温"则必须用基尔霍夫修正

## 典型应用

- 由298K的热力学数据计算其他温度下的反应焓
- 计算绝热反应的最高温度（如甲烷爆炸温度）
- 竞赛中变温条件下的热力学计算
- 与 van't Hoff 方程衔接：平衡常数随温度的变化 lnK 对 1/T 作图斜率 = −ΔrH/R，而 ΔrH 本身若随温度显著变化，需先用基尔霍夫修正再积分（决赛层考察）

## 完整算例

**题目**：298 K 时 N₂(g) + 3H₂(g) → 2NH₃(g)，ΔrH⁰ = −92.2 kJ/mol。Cp,m：N₂ 29.1、H₂ 28.8、NH₃ 35.1 J/(mol·K)（视为常数）。求 500 K 的反应焓。

**解答**：ΔCp = 2×35.1 − (29.1 + 3×28.8) = 70.2 − 115.5 = −45.3 J/(mol·K)。

ΔrH⁰(500 K) = −92200 + (−45.3)×(500−298) = −92200 − 9151 = **−101.4 kJ/mol**

（放热更多：产物热容小，升温后体系"少吸收"的热量转成额外放热。若不修正按 −92.2 kJ/mol 计，高温热力学题会整体偏错。）

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 认为反应焓与温度无关 | ΔrH 是温度函数，基尔霍夫定律给出定量修正 | 高温燃烧/绝热火焰温度题必须修正；ΔCp ≠ 0 即随温度变 |
| ΔCp 算错符号 | 产物系数为正、反应物系数为负，漏乘化学计量数 | 3H₂ 的系数 3 易漏：ΔCp = Σν(产物)Cp − Σν(反应物)Cp |
| 单位混用（kJ 与 J） | ΔrH 常用 kJ，Cp 是 J/(mol·K)，乘积后单位错一个 10³ | 先统一：−92.2 kJ = −92200 J 再运算；结果再换回 kJ |
| 温度区间跨相变仍用一段积分 | 相变点热容不连续且有相变焓，直接积分全错 | 见题中是否有 H₂O 汽化/金属熔化；分段 + 加 Δ相变H |
| 恒压恒容不分 | 标准式是 ΔCp（恒压），恒容反应/ΔrU 要用 ΔCv | 题目给 Cv 或要求 ΔrU 时改用 ΔCv 形式 |
| 把 Cp 当常数却忽略温度区间过大 | 区间 >300 K 时 Cp 随温度变化不可忽略 | 用 Cp = a + bT + cT² 积分（至少到一次项 bT） |

## 一步一查清单（考场自查）

1. **写 ΔCp**：产物减反应物、乘系数、单位 J/(mol·K)——先单独算出再代入。
2. **写 T 差**：T₂ − T₁ 用开尔文（摄氏温差数值相同，但绝对温度代入积分上下限必须是 K）。
3. **查相变**：扫描题面每种物质的相态标注（s/l/g）在 T₁、T₂ 是否一致。
4. **查产物化学计量**：有水生成的反应，液态水 Cp 与气态水 Cp 差约 37 J/(mol·K)，跨 100°C 时此项主导。
5. **结果合理性**：修正量通常 2~10 kJ/mol 量级；若算出几十上百 kJ 的"修正"，几乎必然是 ΔCp 或系数错。

## 竞赛考察要点与命题角度

1. **简单套公式**：给 298 K 反应焓与各物质 Cp，求 T₂ 反应焓——两步（ΔCp → ΔrH(T₂)），注意单位与系数。
2. **绝热火焰温度/最高温度**：燃烧放热全部用于加热产物，ΔrH(T_点火) = ∫Cp(产物)dT 解 T——基尔霍夫与能量守恒联用，答案常是"点火温度下反应焓 + 产物升温焓闭合"。
3. **分段积分**：题面把产物设成含液态水，从 298 K 到 500 K 跨 100°C——必须先算 298→373 K（液态 Cp）再汽化再 373→500 K（气态 Cp）。
4. **与平衡常数挂钩（决赛）**：ln(K₂/K₁) = −ΔrH/R·(1/T₂ − 1/T₁)，若 ΔrH 依赖温度则用基尔霍夫修正后的 ΔrH(T) 再积分——两道公式的"接力"是决赛热力学计算题的标准骨架。
5. **定性判断**：不给数据问"升温使放热反应放得更多还是更少"——只需 ΔCp 符号：ΔCp<0（产物热容小）则升温 ΔrH 更负（放更多）。

## 精确积分示例（Cp 随温度变化）

**题目**：某反应 298 K 时 ΔrH⁰ = −50.0 kJ/mol，ΔCp = 10.0 + 0.02T (J/(mol·K))。求 600 K 的反应焓。

**解答**：ΔrH(600) = ΔrH(298) + ∫₂₉₈⁶⁰⁰ (10.0 + 0.02T)dT

= −50000 + [10.0×(600−298) + 0.01×(600²−298²)]

= −50000 + [3020 + 0.01×(360000−88804)] = −50000 + 3020 + 2712 = **−44268 J/mol ≈ −44.3 kJ/mol**

**对比**：若按 ΔCp(298) ≈ 10.0+5.96 ≈ 16.0 当常数，得 −50000+16×302 = −45168，偏差约 900 J——题面要求精确时须保留 bT 项。

## 三方程温度依赖辨析（防混淆）

| 方程 | 回答的问题 | 输入 → 输出 |
|---|---|---|
| 基尔霍夫定律 | 反应焓 ΔrH 随 T 怎么变 | ΔrH(T₁) + Cp 数据 → ΔrH(T₂) |
| van't Hoff 方程 | 平衡常数 K 随 T 怎么变 | ΔrH（常视为常数或经基尔霍夫修正）+ K(T₁) → K(T₂) |
| 吉布斯-亥姆霍兹方程 | ΔrG 随 T 怎么变（ΔH、ΔS 定温） | ΔrG(T₁) → ΔrG(T₂)，或由 ΔH/ΔS 求任意 T 的 ΔG |

记忆锚点：**基尔霍夫管"焓的温度修正"，是另外两个方程的上游数据源**——van't Hoff 严格版要把 ΔrH(T) 先做基尔霍夫修正再积分；决赛题中"给 Cp 求不同温度 K"就是两者接力。

## 关键结论速记

- ΔrH(T₂) = ΔrH(T₁) + ∫ΔCp·dT：ΔCp 按"产物 − 反应物（乘系数）"取。
- ΔCp < 0（常见于气体分子数减少的反应）→ 升温使放热反应放得更多。
- 跨相变必分段并加相变焓；恒容用 ΔCv 版本。
- 初赛小温区可忽略温度修正；高温/精确题才动用基尔霍夫。
- 常见 ΔCp 数量级：气体分子数变化 ±1 的反应，ΔCp 约 ±10~30 J/(mol·K)，温度差 200 K 时修正量约 2~6 kJ/mol——相对反应焓常 <5%，但足以改变符号判断的边界题（如 ΔrH 很小时的平衡温度计算）必须计入。
- 复习锚点：能徒手推一遍"298 K 数据 → 500 K 反应焓"的完整流程（ΔCp → 代入 → 单位换算），本页即算掌握。

## 六、🎯 教学视角

### 6.1 学习路径建议
基尔霍夫定律应在掌握盖斯定律和热容概念之后引入，解决"反应焓随温度变化"的问题。先理解其本质是盖斯定律的特例（构造温度变化的热力学循环），再学习积分形式和简化形式的应用。

### 6.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 反应焓在所有温度下都相同 | 反应焓随温度变化，基尔霍夫定律给出了定量关系 |
| ΔCp通常很大，不能忽略 | 对于许多反应ΔCp较小，在温度变化不大时可近似认为ΔH不变 |
| 基尔霍夫定律只适用于恒压过程 | 标准形式是恒压下的关系，恒容下有对应的修正形式 |

### 6.3 入门级例题
**题目**：已知298K时N₂(g)+3H₂(g)→2NH₃(g)的ΔHθ=-92.2 kJ/mol，Cp(N₂)=29.1, Cp(H₂)=28.8, Cp(NH₃)=35.1 J/(mol·K)，求500K时的ΔHθ。
**解答**：ΔCp = 2×35.1 - (29.1+3×28.8) = 70.2 - 115.5 = -45.3 J/(mol·K)。ΔHθ(500K) = -92200 + (-45.3)×(500-298) = -92200 - 9151 = -101.4 kJ/mol。

### 6.4 与现实世界的联系
1. **发动机设计**：内燃机中燃烧温度远高于298K，需要用基尔霍夫定律修正反应焓
2. **火箭推进**：高温燃烧产物的热力学性质需要温度修正
3. **地球科学**：地幔深处的化学反应需要计算高温下的反应焓

> **最小可用清单**：写基尔霍夫题先问三件事——① 单位统一了吗（kJ vs J）？② 系数乘全了吗（ΣνCp）？③ 区间里有相变吗（分段）？三问过完再代入积分，可避开九成失分。
