# 熵

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[06-热力学初步]]

## 一、定义
熵是热力学状态函数，记作 $S$，用于度量体系可实现的微观状态数多少。

统计意义上有：

$$
S = k \ln \Omega
$$

热力学定义上有：

$$
\mathrm{d}S = \frac{\delta q_{\mathrm{rev}}}{T}
$$

课堂上可以先压成一句话：  
**熵不是“乱”这个词本身，而是体系可取微观状态数多少的量度。**

## 二、考纲对应
- 要求层级：理解熵的物理意义、熵变的定性判断、标准熵变计算及与自发性的关系
- 课堂定位：是 [[Gibbs自由能]]、[[热力学第二定律]]、[[化学势]] 的上游基础页

## 三、核心原理

### 3.1 熵为什么是状态函数
熵变只取决于始态和终态，与真实路径无关。  
因此哪怕实际过程不可逆，也可以通过设计一条可逆路径来计算 $\Delta S$。

### 3.2 第二定律中的熵判据
对孤立体系：

$$
\Delta S_{\text{孤立}} = \Delta S_{\text{体系}} + \Delta S_{\text{环境}} \ge 0
$$

- 可逆过程：$=0$
- 不可逆过程：$>0$

这就是“熵增原理”的严格表达。

### 3.3 第三定律与标准摩尔熵
理想晶体在 $0\ \mathrm{K}$ 时熵为零，因此可以建立物质的绝对熵标尺。  
标准摩尔熵记作 $S^{\theta}$，表示 1 mol 物质在标准态下的熵值。

### 3.4 熵的三种主要来源
- **位置熵**：粒子可占据空间越多，熵越大
- **热熵**：温度越高，可及能级越多，熵越大
- **构型熵**：分子越复杂、对称性越低、内部排列可能性越多，熵越大

## 四、关键结论
- 熵是状态函数，可以走可逆路径算不可逆过程的熵变
- 气体、升温、混合、溶解、解离、粒子数增多通常有利于熵增
- 固体生成、气体物质的量减少、体系更有序通常有利于熵减
- 熵增有利于自发，但**不能单独判定自发性**，还要结合 [[焓]] 与 [[Gibbs自由能]]

## 五、常见分类或情形

### 5.1 标准摩尔熵的高频规律
| 情形 | 课堂结论 |
|------|------|
| 同一物质不同聚集态 | $S^{\theta}(\mathrm{g}) > S^{\theta}(\mathrm{l}) > S^{\theta}(\mathrm{s})$ |
| 同类物质摩尔质量增大 | 通常 $S^{\theta}$ 增大 |
| 多原子分子 vs 单原子分子 | 通常前者更大 |
| 对称性降低、结构更复杂 | 通常 $S^{\theta}$ 增大 |
| 温度升高 | 熵增大 |
| 压力升高（气体） | 熵减小 |

### 5.2 反应熵变计算

$$
\Delta_{\mathrm{r}} S^{\theta} = \sum \nu S^{\theta}(\text{产物}) - \sum \nu S^{\theta}(\text{反应物})
$$

高频判断抓手：
- 气体物质的量明显增加，往往 $\Delta S^{\theta} > 0$
- 气体物质的量明显减少，往往 $\Delta S^{\theta} < 0$
- 若 $\Delta n_{\mathrm g}=0$，则要继续看相态、复杂度与溶解解离情况

### 5.3 相变熵
在相变温度下的可逆相变：

$$
\Delta S_{\text{相变}} = \frac{\Delta H_{\text{相变}}}{T_{\text{相变}}}
$$

这解释了为什么熔化、汽化通常伴随熵增。

### 5.4 典型数据直觉
- $\mathrm{H_2O(l)}$ 的 $S^{\theta}$ 明显小于 $\mathrm{H_2O(g)}$
- $\mathrm{F_2 < Cl_2 < Br_2 < I_2}$ 的标准摩尔熵通常依次增大
- 乙醇和二甲醚这类同分异构体中，对称性更低者通常熵更大

## 六、适用条件与限制
- $\mathrm{d}S = \dfrac{\delta q_{\mathrm{rev}}}{T}$ 中必须使用**可逆热**
- $\Delta S_{\text{相变}} = \dfrac{\Delta H_{\text{相变}}}{T_{\text{相变}}}$ 只适用于相变点的可逆相变
- 标准熵变公式默认建立在标准态数据上，物态、温度、计量系数不能写错
- 熵变常能判断趋势，但单看 $\Delta S$ 不能判断常温是否自发

## 七、常见比较与易混点
- **熵不等于“混乱”这个口号**：精确定义是微观状态数的量度
- **$\Delta S > 0$ 不等于一定自发**：还要看 $\Delta H - T\Delta S$
- **标准摩尔熵 $S^{\theta}$ 和标准反应熵变 $\Delta_{\mathrm r}S^{\theta}$ 不是一回事**
- **固体熵不等于零**：只有理想晶体在 $0\ \mathrm K$ 时熵取零

## 十、例题
- **例题 1**：判断 $\mathrm{H_2O(l) \to H_2O(g)}$、$\mathrm{NaCl(s) \to Na^+(aq)+Cl^-(aq)}$、$\mathrm{N_2(g)+3H_2(g)\to 2NH_3(g)}$ 的 $\Delta S^{\theta}$ 正负。  
  **答案要点**：蒸发熵增，溶解解离通常熵增，4 mol 气体变 2 mol 气体则熵减。
- **例题 2**：已知 $\mathrm{N_2(g)+3H_2(g)\to 2NH_3(g)}$ 的 $\Delta S^{\theta} < 0$，为什么工业上仍可进行？  
  **答案要点**：该反应放热，低温时焓项有利；真正判据是 $\Delta G = \Delta H - T\Delta S$，而且工业还要兼顾速率与平衡。

## 十一、易错点
- 把“熵增原理”机械理解成“凡熵增都能自发进行”
- 只看 $\Delta n_{\mathrm g}$，忽略溶解、解离、聚集态变化
- 标准熵表查值时不写物态
- 把 $S^{\theta}$、$\Delta S^{\theta}$、$\Delta G$ 混成一个量

## 十二、🎯 教学视角
- 第一轮最该讲清的是：`熵是状态数，不只是“乱”`
- 课堂推进最好按 `微观图景 -> 定性判断 -> 查表计算 -> 与自由能联立` 这条线走
- 最稳的课堂抓手不是抽象定义，而是三类过程：相变、混合/溶解、气体计量数变化

## 十三、🧰 备课可抽料资产

### 13.1 主干结论
- 熵刻画微观状态数多少，第二定律用总熵增给出方向判据
- 标准摩尔熵有一套稳定可记的比较规律
- 反应熵变与自由能判据是热力学课堂的核心桥梁

### 13.2 机制 / 推导资产
- 可直接复用的课堂链：微观状态数 -> 熵定义 -> 第二定律 -> 标准熵变 -> $\Delta G$
- 可直接复用的桥句：“熵先告诉你体系更愿意往哪边排布，自由能再告诉你这件事能不能在当前温度下发生”

### 13.3 误区 / 纠偏资产
- “熵不是单纯的混乱口号”
- “自发性不能只看熵”
- “$S^{\theta}$ 是家底，$\Delta_{\mathrm r}S^{\theta}$ 是变化”

### 13.4 题型 / 例题资产
- 建议题链：相变判断 -> 气体计量数判断 -> 查表算 $\Delta_{\mathrm r}S^{\theta}$ -> 联立 $\Delta H,\Delta S$ 判断温度效应

## 十六、标准摩尔熵与 Trouton 规则

### 标准摩尔熵比较表（298.15 K，数据来源：CRC Handbook）

| 物质 | Sθ (J·mol⁻¹·K⁻¹) | 说明 |
|------|:---:|------|
| C（金刚石） | 2.4 | 最有序的固体之一 |
| C（石墨） | 5.7 | 层状结构，比金刚石稍高 |
| NaCl（s） | 72.1 | 离子晶体 |
| Fe（s） | 27.3 | 金属晶体 |
| H₂O（s，冰） | 48.0 | 氢键有序排列 |
| H₂O（l） | 69.9 | 液态熵显著高于固态 |
| H₂O（g） | 188.8 | 气态熵远高于液态 |
| H₂（g） | 130.7 | 双原子气体 |
| O₂（g） | 205.2 | 双原子气体 |
| N₂（g） | 191.6 | 双原子气体 |
| CO₂（g） | 213.8 | 三原子气体 |
| CH₄（g） | 186.3 | 五原子气体 |
| C₂H₆（g） | 229.2 | 重分子气体 |
| He（g） | 126.2 | 单原子气体 |
| Ar（g） | 154.8 | 单原子气体 |

**规律总结**：
1. 气态 > 液态 > 固态（同种物质）
2. 分子越复杂（原子数越多），Sθ 越大（振动模式更多）
3. 重分子 > 轻分子（同相态）
4. 混合物 > 纯物质（混合熵增）

### Trouton 规则

**内容**：大多数非极性液体的摩尔蒸发熵近似为常数：
$$\Delta S_{vap} = \frac{\Delta H_{vap}}{T_b} \approx 85\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$$

**验证**：
| 液体 | Tb (K) | ΔHvap (kJ/mol) | ΔSvap (J·mol⁻¹·K⁻¹) |
|------|:---:|:---:|:---:|
| C₆H₆ | 353 | 30.7 | 87.0 |
| CCl₄ | 350 | 30.0 | 85.7 |
| C₆H₁₄ | 342 | 28.9 | 84.5 |
| CS₂ | 319 | 26.7 | 83.7 |

**例外**：
- H₂O（ΔSvap ≈ 109）：液态有氢键，额外有序 → 蒸发时破坏氢键，熵增更大
- HF（ΔSvap ≈ 86）：虽有氢键但形成环状缔合体，影响较小
- 低沸点气体（H₂, He）：量子效应显著，偏离 Trouton 规则
