# 热力学第二定律

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[06-热力学初步]]

## 一、定义
**热力学第二定律**给出自发过程的方向判据。对孤立体系而言：

$$\Delta S_{\text{孤立}} \ge 0$$

即自发过程总朝着总熵不减的方向进行。

## 二、考纲对应
- [[06-热力学初步]]：熵、自发过程、Gibbs自由能判据

## 三、核心原理
- 第一类问题：为什么有些过程能发生，有些不能
- 第二定律回答的是**方向性**，不是守恒性
- 熵 $S$ 是刻画混乱度或可及微观状态数多少的量

## 四、关键结论
1. 孤立体系中，自发过程满足 $\Delta S_{\text{总}} > 0$，平衡时 $\Delta S_{\text{总}} = 0$。
2. 在恒温恒压且不做非体积功条件下，可进一步转化为 [[Gibbs自由能]] 判据：$\Delta G < 0$。
3. 第二定律解释了“吸热反应也可能自发”“放热反应也可能不自发”。

## 五、常见分类或情形
- **相变**：通常从固到液、液到气熵增
- **混合与溶解**：多数情况下熵增
- **气体分子数变化**：常作为定性判断反应熵变的重要线索

## 六、适用条件与限制
- 最根本形式是总熵判据
- 实际解题中常转用 $\Delta G$，但要注意恒温恒压条件

## 七、常见错误
- 误认为“放热就一定自发”
- 只看体系熵，不看体系与环境总熵
- 在不满足条件时机械套用 $\Delta G < 0$

## 八、与其他知识点的连接
- 与 [[熵]]：第二定律的核心语言
- 与 [[Gibbs自由能]]：第一轮最常用的化学判据
- 与 [[热力学第一定律]]：第一定律管守恒，第二定律管方向

## 九、一句话记忆
**第二定律说明自发过程有方向，而这个方向由总熵增加来刻画。**

## 表述史与统计本质（概念深化）

**两种等价表述**：
- **Kelvin 表述**：不可能从单一热源吸热全部转化为功而不留下任何影响（第二类永动机不存在）
- **Clausius 表述**：热不能自发地从低温物体传到高温物体

两者等价——都刻画"**方向性**"：第一定律告诉你"能量守恒（能不能）"，第二定律告诉你"自发方向（会不会自己发生）"，第三定律给你熵的绝对零点。

**熵的统计定义（Boltzmann）**：S = k·ln W——W 是体系可及的微观状态数。"孤立体系 ΔS ≥ 0"的微观图像：体系自发展向**可及微观状态数更大**（概率更大）的宏观态。所以：
- 气体自由膨胀 ΔS > 0：W 增大（分子可占体积加倍）
- 冰融化 ΔS > 0：W 增大（液态分子排布方式远多于晶格）
- **"熵增 = 走向概率更大状态"** 比"混乱度"更精确——蛋白质折叠熵减仍自发是因为**溶剂水**的熵大增补偿（总熵仍增）

## 判据层级表（防混用）

| 条件 | 判据 | 说明 |
|---|---|---|
| 孤立体系（任何过程） | ΔS_total ≥ 0 | 最根本、最普适 |
| 恒温恒压、不做非体积功 | ΔG ≤ 0 | 化学最常见的等价形式 |
| 恒温恒容、不做非体积功 | ΔA ≤ 0（亥姆霍兹） | 恒容反应/相变用 |
| 恒熵恒压 / 恒熵恒容 | ΔH ≤ 0 / ΔU ≤ 0 | 绝热不可逆过程等特殊场景 |

**主路径**：凡化学题默认恒温恒压 → 用 ΔG；只有明确"孤立体系/宇宙熵变"问法才直接算 ΔS_total。**ΔG = ΔH − TΔS 只是把环境熵并入体系的语言**：ΔS_surr = −ΔH/T（恒压），故 ΔS_total = ΔS_sys + ΔS_surr = ΔS − ΔH/T，两边乘 −T 得 −TΔS_total = ΔH − TΔS = ΔG。**记牢这个推导，就永远不会把三个判据当三个孤立定律。**

## 完整算例：-10°C 时冰会融化吗？（总熵判据数值演示）

**题目**：已知 0°C 时冰的 ΔH_fus = +6.01 kJ/mol（相变熵 ΔS_fus = 6010/273 = 22.0 J·K⁻¹·mol⁻¹）。用总熵判据判断 −10°C 与 +10°C 时融化是否自发（近似取 ΔH、ΔS_sys 不随温度变）。

**解答（−10°C，T = 263 K）**：
- ΔS_sys ≈ 22.0 J·K⁻¹·mol⁻¹（冰融化本身熵增，近似不变）
- ΔS_surr = −ΔH/T = −6010/263 = **−22.9 J·K⁻¹·mol⁻¹**（环境吸热熵减）
- ΔS_total = 22.0 − 22.9 = **−0.9 J·K⁻¹·mol⁻¹ < 0 → 不自发**（-10°C 冰不融化 ✓）

**解答（+10°C，T = 283 K）**：
- ΔS_surr = −6010/283 = −21.2；ΔS_total = 22.0 − 21.2 = **+0.8 J·K⁻¹·mol⁻¹ > 0 → 自发** ✓

**验证（0°C 平衡点）**：T = 273 K → ΔS_surr = −6010/273 = −22.0 = −ΔS_sys → ΔS_total = 0（相变平衡）✓

**结论与要点**：① 融化是**吸热**（ΔH > 0）却在 0°C 以上自发——自发性来自体系熵增（22.0）超过环境熵减；② 温度越低环境熵减越重（分母小），故低温下吸热过程不自发——这就是"ΔG = ΔH − TΔS 中 T 的杠杆作用"的数值图像；③ 相变点 ΔS_total = 0 是对称性的自检锚。

## ΔH 与 ΔS 竞争（自发性四组合表）

| ΔH | ΔS | 温度影响 | 典型过程 |
|---|---|---|---|
| −（放热） | +（熵增） | **任意 T 自发**（ΔG 恒负） | 燃烧、酸碱中和、活泼金属溶酸 |
| +（吸热） | +（熵增） | **高温自发**（T 增大使 −TΔS 胜出） | 冰融化（>0°C）、CaCO₃ 分解、NH₄Cl 溶解 |
| −（放热） | −（熵减） | **低温自发** | 2NO₂→N₂O₄、NH₃+HCl→NH₄Cl（气体凝集） |
| +（吸热） | −（熵减） | **任意 T 不自发**（ΔG 恒正） | 逆方向的凝集分解（除非耦合） |

**记忆**：ΔH 是"能量倾向"（放热偏向自发）、ΔS 是"混乱倾向"（熵增偏向自发）——两者方向一致则任何温度都一致地自发/不自发；方向相反时**温度当裁判**（T 放大 ΔS 的贡献）。竞赛常考"某吸热反应为何高温自发"——标准答案：ΔG = ΔH − TΔS，高温使 −TΔS 项主导。

## §12 教学视角

### 学生常见认知误区
- **误区1：「放热反应一定自发」** → 许多学生将 ΔH < 0 等同于自发，但冰在 -10°C 融化是吸热自发的（ΔS > 0 驱动），而常温下 2H₂ + O₂ → 2H₂O 虽放热但没有催化剂时不反应（动力学限制）→ **口诀：ΔH 管能量，ΔS 管混乱，ΔG 才是判官**
- **误区2：「熵增就一定自发」** → 只看体系熵变 ΔS_sys 不够，必须看总熵 ΔS_total = ΔS_sys + ΔS_surr。NaCl 溶于水熵增自发，但蛋白质折叠熵减也自发（因为水的熵增大补偿）→ **口诀：体系熵增不保险，总熵增加才算数**
- **误区3：「ΔG < 0 可以在任何条件下使用」** → Gibbs 自由能判据 ΔG < 0 仅在恒温恒压且不做非体积功的条件下成立。在恒温恒容或非标准态条件下需用其他判据 → **口诀：ΔG 有前提，恒温恒压记心间**

### 入门级例题
**题目**: 判断 25°C 时以下过程是否自发：(a) H₂O(l) → H₂O(g) 在 1 atm 下；(b) H₂O(g) → H₂O(l) 在 1 atm 下。已知 25°C 时水的蒸气压为 23.8 mmHg。
**分析**: 关键在于理解「自发」与「标准态」的区别。在 1 atm 下，水的蒸气压 < 1 atm（外压），所以蒸发不是自发的（ΔG > 0）。但在真空或蒸气压低于平衡蒸气压时，蒸发是自发的。
**解答**: (a) 在 1 atm 下，水的蒸气压 23.8 mmHg < 760 mmHg，蒸发不自发（ΔG > 0）。需加热到 100°C 才自发。(b) 在 1 atm 下，凝结自发（ΔG < 0），因为外压 > 蒸气压。
**反思**: 自发性取决于条件！判断 ΔG 必须明确温度、压力等条件，不能笼统说「水在常温蒸发」就是自发的。

### 与现实/直觉的连接
- **墨水在水中扩散**：从高浓度到低浓度自发扩散，这是熵增驱动的经典例子——分子从有序（集中在一端）到无序（均匀分布）
- **冰融化**：零度以上，虽然需要吸热（ΔH > 0），但水分子自由度增大带来的熵增（ΔS > 0）使 ΔG < 0，所以自发融化
- **铁生锈**：Fe → Fe₂O₃ 虽然熵减（固体更有序），但巨大的放热（ΔH << 0）使 ΔG < 0，所以常温自发

### 教学建议
1. **用「竞争」的比喻讲 ΔH 与 ΔS**：把焓变比作「能量倾向」，熵变比作「混乱倾向」，两者竞争决定 ΔG 的正负
2. **先讲总熵判据再讲 ΔG**：让学生理解 ΔG 是恒温恒压条件下总熵判据的等价形式，而非独立判据
3. **用相变实例建立直觉**：水的三态变化是学生最熟悉的相变，用它讲解「条件改变可翻转自发性方向」
4. **强调条件的重要性**：每次讨论 ΔG 时都明确「在什么温度、什么压力下」，养成条件意识
5. **设计矛盾性问题挑战误区**：如「CaCO₃ 分解是吸热的，为什么高温下自发？」——让学生用 ΔG = ΔH - TΔS 自行解释

## 竞赛考察要点

1. **表述辨析**：Kelvin/Clausius 表述、第二类永动机、"热不能全转功"判断。
2. **总熵 vs ΔG 判据**：给条件选判据（孤立体系→ΔS_total；恒温恒压→ΔG）并说明推导关系。
3. **吸热自发题**：冰融化/CaCO₃ 分解等——"ΔS_sys 增 > ΔS_surr 减"的标准解答模板。
4. **四组合判断**：给 ΔH、ΔS 符号判"任意温/高低温自发"（本页表格直接套）。
5. **ΔG = ΔH − TΔS 温度杠杆**：求转变温度 T = ΔH/ΔS（相变/分解温度）。
6. **熵统计图像**：S = k ln W、气体膨胀/混合熵增的微观解释（与统计热力学衔接）。

## 关键结论速记

- 第二定律管方向：孤立体系 ΔS_total ≥ 0；Kelvin（热不全转功）/Clausius（热不自发上流）等价表述。
- 熵 = k ln W——自发展向可及微观状态数更大的宏观态（"概率大者自发"）。
- ΔG 是恒温恒压总熵判据的等价形（ΔG = −TΔS_total 推导）；ΔA 是恒容版。
- 吸热可自发（ΔS_sys 胜出：冰 >0°C 融化）、放热可不自发（ΔS 减：需低温）。
- 四组合：同向恒自发/恒不自发；反向由 T 裁判（高温放大 −TΔS）。
- 转变温度 T = ΔH/ΔS（两相平衡或 ΔG = 0）。
- 相变点锚：0°C 融化 ΔS_total = 0；−10°C 总熵 −0.9（不自发）、+10°C +0.8（自发）J·K⁻¹·mol⁻¹。
- 收尾自检：能讲 ΔG 与 ΔS_total 的推导、能算吸热过程转变温度、能判四组合自发性——本页达标。
