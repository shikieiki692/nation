# 热力学第二定律

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[06-热力学初步]]

## 一、定义
**热力学第二定律**给出自发过程的方向判据。对孤立体系而言：

$$\Delta S_{\text{孤立}} \ge 0$$

即自发过程总朝着总熵不减的方向进行。

## 二、考纲对应
- [[06-热力学初步]]：熵、自发过程、Gibbs自由能判据

## 三、核心原理
- 第一类问题：为什么有些过程能发生，有些不能
- 第二定律回答的是**方向性**，不是守恒性
- 熵 $S$ 是刻画混乱度或可及微观状态数多少的量

## 四、关键结论
1. 孤立体系中，自发过程满足 $\Delta S_{\text{总}} > 0$，平衡时 $\Delta S_{\text{总}} = 0$。
2. 在恒温恒压且不做非体积功条件下，可进一步转化为 [[Gibbs自由能]] 判据：$\Delta G < 0$。
3. 第二定律解释了“吸热反应也可能自发”“放热反应也可能不自发”。

## 五、常见分类或情形
- **相变**：通常从固到液、液到气熵增
- **混合与溶解**：多数情况下熵增
- **气体分子数变化**：常作为定性判断反应熵变的重要线索

## 六、适用条件与限制
- 最根本形式是总熵判据
- 实际解题中常转用 $\Delta G$，但要注意恒温恒压条件

## 七、常见错误
- 误认为“放热就一定自发”
- 只看体系熵，不看体系与环境总熵
- 在不满足条件时机械套用 $\Delta G < 0$

## 八、与其他知识点的连接
- 与 [[熵]]：第二定律的核心语言
- 与 [[Gibbs自由能]]：第一轮最常用的化学判据
- 与 [[热力学第一定律]]：第一定律管守恒，第二定律管方向

## 九、一句话记忆
**第二定律说明自发过程有方向，而这个方向由总熵增加来刻画。**

## §12 教学视角

### 学生常见认知误区
- **误区1：「放热反应一定自发」** → 许多学生将 ΔH < 0 等同于自发，但冰在 -10°C 融化是吸热自发的（ΔS > 0 驱动），而常温下 2H₂ + O₂ → 2H₂O 虽放热但没有催化剂时不反应（动力学限制）→ **口诀：ΔH 管能量，ΔS 管混乱，ΔG 才是判官**
- **误区2：「熵增就一定自发」** → 只看体系熵变 ΔS_sys 不够，必须看总熵 ΔS_total = ΔS_sys + ΔS_surr。NaCl 溶于水熵增自发，但蛋白质折叠熵减也自发（因为水的熵增大补偿）→ **口诀：体系熵增不保险，总熵增加才算数**
- **误区3：「ΔG < 0 可以在任何条件下使用」** → Gibbs 自由能判据 ΔG < 0 仅在恒温恒压且不做非体积功的条件下成立。在恒温恒容或非标准态条件下需用其他判据 → **口诀：ΔG 有前提，恒温恒压记心间**

### 入门级例题
**题目**: 判断 25°C 时以下过程是否自发：(a) H₂O(l) → H₂O(g) 在 1 atm 下；(b) H₂O(g) → H₂O(l) 在 1 atm 下。已知 25°C 时水的蒸气压为 23.8 mmHg。
**分析**: 关键在于理解「自发」与「标准态」的区别。在 1 atm 下，水的蒸气压 < 1 atm（外压），所以蒸发不是自发的（ΔG > 0）。但在真空或蒸气压低于平衡蒸气压时，蒸发是自发的。
**解答**: (a) 在 1 atm 下，水的蒸气压 23.8 mmHg < 760 mmHg，蒸发不自发（ΔG > 0）。需加热到 100°C 才自发。(b) 在 1 atm 下，凝结自发（ΔG < 0），因为外压 > 蒸气压。
**反思**: 自发性取决于条件！判断 ΔG 必须明确温度、压力等条件，不能笼统说「水在常温蒸发」就是自发的。

### 与现实/直觉的连接
- **墨水在水中扩散**：从高浓度到低浓度自发扩散，这是熵增驱动的经典例子——分子从有序（集中在一端）到无序（均匀分布）
- **冰融化**：零度以上，虽然需要吸热（ΔH > 0），但水分子自由度增大带来的熵增（ΔS > 0）使 ΔG < 0，所以自发融化
- **铁生锈**：Fe → Fe₂O₃ 虽然熵减（固体更有序），但巨大的放热（ΔH << 0）使 ΔG < 0，所以常温自发

### 教学建议
1. **用「竞争」的比喻讲 ΔH 与 ΔS**：把焓变比作「能量倾向」，熵变比作「混乱倾向」，两者竞争决定 ΔG 的正负
2. **先讲总熵判据再讲 ΔG**：让学生理解 ΔG 是恒温恒压条件下总熵判据的等价形式，而非独立判据
3. **用相变实例建立直觉**：水的三态变化是学生最熟悉的相变，用它讲解「条件改变可翻转自发性方向」
4. **强调条件的重要性**：每次讨论 ΔG 时都明确「在什么温度、什么压力下」，养成条件意识
5. **设计矛盾性问题挑战误区**：如「CaCO₃ 分解是吸热的，为什么高温下自发？」——让学生用 ΔG = ΔH - TΔS 自行解释
