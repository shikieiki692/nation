# 弱酸

## 核心概念

弱酸是指在水溶液中仅部分电离的酸，其电离平衡常数Ka远小于1。常见弱酸包括醋酸（CH₃COOH）、碳酸（H₂CO₃）、氢氟酸（HF）等。

**判定标准**：Ka < 1（实际竞赛常以 Ka < 10⁻² 为"弱"、10⁻²~10⁰ 为"中强"经验分界；"弱酸"是定量概念而非性质标签）。弱酸溶液中存在**未电离分子 ⇌ 离子**的动态平衡，pH 由 Ka 与浓度共同决定，而不是由酸浓度直接给出。

**与强酸的本质差异**：强酸完全电离（溶液中无 HA 分子），弱酸部分电离（HA、A⁻、H⁺、OH⁻ 共存）。因此 0.1 mol/L HAc 的 [H⁺] ≈ 1.3×10⁻³ 而非 0.1——"弱酸不能按浓度直接算 pH"是第一考点。

## 电离平衡与计算

HA ⇌ H⁺ + A⁻，Ka = [H⁺][A⁻]/[HA]

**近似条件**（初赛必考判定）：c/Ka ≥ 500（等价于电离度 α ≤ 5%）时，可用近似式：

[H⁺] = √(Ka·c)，pH = ½(pKa − log c)

不满足时解二次方程：[H⁺]² + Ka[H⁺] − Ka·c = 0。

**极稀/极弱修正**：当 [H⁺] 低至 ~10⁻⁶ 量级（c 很小或 Ka 很小）时，水的自电离不可忽略，须用质子条件 [H⁺] = [A⁻] + [OH⁻] 精确解——初赛以 c ≥ 10⁻⁴、Ka ≥ 10⁻⁸ 为界判断是否需要修正。

**电离度**：α = [H⁺]/c（一元弱酸）= √(Ka/c)（稀溶液近似）。**稀释时 α 增大但 [H⁺] 减小**——两个方向相反的变化常被拿来设问。

## 多元弱酸的分步电离

H₂CO₃：Ka1 = 4.3×10⁻⁷，Ka2 = 5.6×10⁻¹¹——**Ka1 ≫ Ka2（通常差 10⁴~10⁵ 倍）**。

- 二元弱酸溶液中 [H⁺] 主要由第一步决定：[H⁺] ≈ √(Ka1·c)
- 酸根浓度有简洁式：**[A²⁻] ≈ Ka2**（与总浓度无关！推导：由两级平衡与物料守恒在 Ka1≫Ka2 下得 [A²⁻] ≈ Ka2）
- [HA⁻] ≈ [H⁺]（一级电离为主时）
- 磷酸 H₃PO₄ 三级：Ka1 = 7.6×10⁻³、Ka2 = 6.3×10⁻⁸、Ka3 = 4.4×10⁻¹³——pH 由第一级主导，[PO₄³⁻] ≈ Ka1·Ka2·Ka3/[H⁺]³ 类公式按需展开

**竞赛要点**：H₂S、H₂CO₃、H₃PO₄ 的逐级电离与沉淀/配合平衡联动题（如通 H₂S 沉硫化物时 [S²⁻] ≈ Ka1Ka2[H₂S]/[H⁺]²）是高频综合题骨架。

## 影响弱酸强度的因素

| 因素 | 规律 | 示例 |
|---|---|---|
| 电负性 | 同周期 A—H 键，电负性大者酸性强 | HF 酸性 < HCl < HBr < HI（键能主导，同族看键长） |
| 诱导效应 | 吸电子基使羧酸酸性增强 | Cl₃CCOOH (pKa 0.7) ≫ CH₃COOH (4.76)；FCH₂COOH > CH₃COOH |
| 共轭碱稳定化 | 负电荷越分散（离域/溶剂化）酸性越强 | 苯酚 (10) vs 乙醇 (16)：苯氧负离子共振稳定 |
| 溶剂 | 质子溶剂稳定离子，酸碱性随溶剂迁移 | 同一酸在水中 vs 醋酸中的 pKa 不同 |

## 常见弱酸 Ka 速查（数量级记忆）

| 弱酸 | Ka | pKa | 备注 |
|---|---|---|---|
| HAc（乙酸） | 1.8×10⁻⁵ | 4.76 | 标准参照物 |
| HF | 6.8×10⁻⁴ | 3.17 | 弱酸中的"强手"；F⁻ 强水合 |
| HCN | 6.2×10⁻¹⁰ | 9.21 | 极弱 |
| HClO | 2.9×10⁻⁸ | 7.54 | 弱酸，氧化性强 |
| H₂CO₃ Ka1 | 4.3×10⁻⁷ | 6.37 | 二元 |
| H₂S Ka1 | 9.1×10⁻⁸ | 7.04 | 二元 |
| H₃PO₄ Ka1 | 7.6×10⁻³ | 2.12 | 三元，中强 |
| NH₄⁺（共轭酸） | 5.6×10⁻¹⁰ | 9.25 | 与 NH₃ Kb 配套 |

**判断酸强弱不靠"含几个 H"**：H₃PO₄ 是中强酸、H₂CO₃ 是弱酸——看的是可电离 H 的 O—H 键极化（含氧酸规律见 [[含氧酸]]）。

## 完整算例（近似 + 精确对照）

**题目**：（a）0.10 mol/L HAc（Ka = 1.8×10⁻⁵）的 pH？（b）若 c = 1.0×10⁻⁴ mol/L，能否仍用近似式？

**解答**：
（a）c/Ka = 0.10/1.8×10⁻⁵ = 5556 ≥ 500 → 近似：[H⁺] = √(1.8×10⁻⁵×0.10) = 1.34×10⁻³，pH = 2.87。

（b）c/Ka = 1.0×10⁻⁴/1.8×10⁻⁵ = 5.6 < 500 → 近似失效。解二次方程 [H⁺]² + Ka[H⁺] − Ka·c = 0：[H⁺] = 3.4×10⁻⁵，pH = 4.47（近似式会给出 √(1.8×10⁻⁹) = 4.2×10⁻⁵、pH 4.37——差 0.1 个 pH 单位，误差已不可接受）。

**要点**：先算 c/Ka 再决定用哪个公式；近似条件不满足时硬套近似式是失分重灾区。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 弱酸 = 不溶于水的酸 | 溶解性与电离度无关 | 醋酸易溶却是弱酸；BaSO₄ 难溶却是"强电解质盐"（溶解部分全电离） |
| Ka 越小酸性越强 | Ka 越大电离程度越大酸性越强 | pKa = −logKa：pKa 小者酸强（HAc 4.76 < HCN 9.21 → HAc 强） |
| 用酸总浓度直接算 [H⁺] | 弱酸仅部分电离，[H⁺] ≪ c | 0.1 mol/L HAc 的 [H⁺] = 1.3×10⁻³ 而非 0.1 |
| 忘了近似条件 c/Ka ≥ 500 | 极稀/Ka 大时近似式误差不可忽略 | c/Ka < 500 必须解二次方程或质子条件 |
| 多元弱酸把两级 H⁺ 相加 | Ka1 ≫ Ka2，H⁺ 由第一级主导，第二级几乎不贡献 | H₂CO₃ pH 只由 Ka1 决定；把 Ka2 也算进去会重复计数 |
| 认为 [A²⁻] 随浓度变 | 二元弱酸 [A²⁻] ≈ Ka2（稀溶液）与总浓度无关 | H₂CO₃ 稀释时 [CO₃²⁻] 基本不变（≈ Ka2 = 5.6×10⁻¹¹）——常被当压轴判断 |
| 混淆 Ka 与电离度 α | Ka 是常数（只随温度），α 随浓度变 | 稀释时 α↑ 而 Ka 不变：α = √(Ka/c) 变、Ka 恒 |

## 🎯 教学视角

### 学习路径建议
弱酸应在学习酸碱理论和电离平衡之后引入。先理解弱酸的部分电离特征，再掌握Ka的表达式和pH计算方法，最后学习多元弱酸的分步电离和缓冲溶液的概念。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 弱酸就是不溶于水的酸 | 弱酸可溶于水但仅部分电离，如醋酸易溶但是弱酸 |
| Ka越小酸性越强 | Ka越小说明电离程度越小，酸性越弱 |
| 弱酸溶液中H⁺浓度等于酸的浓度 | 弱酸仅部分电离，[H⁺]远小于酸的总浓度 |

### 入门级例题
**题目**：0.10 mol/L HAc溶液的pH是多少？（Ka = 1.8×10⁻⁵）
**解答**：设[H⁺] = x，则x²/0.10 = 1.8×10⁻⁵，x = 1.34×10⁻³ mol/L。pH = 2.87。

### 与现实世界的联系
1. **食品调味**：醋酸（乙酸）是食醋的主要成分，赋予酸味
2. **碳酸饮料**：CO₂溶于水形成碳酸（H₂CO₃），产生气泡和酸味
3. **制药工业**：阿司匹林（乙酰水杨酸）是弱酸，其吸收受胃液pH影响

> **记忆锚**：弱酸算 pH 三步——先看 c/Ka 够不够 500，够就 √(Ka·c)，不够就解二次方程；多元弱酸 H⁺ 只看第一级，酸根近似等于 Ka2。

## 竞赛考察要点与命题角度

1. **pH 计算**：近似式/精确式判定 + 计算——初赛必考。
2. **稀释题**：加水稀释 10 倍 pH 变化 <1（弱酸越稀越电离补偿）——与强酸稀释 pH 恰升 1 对比。
3. **混合体系**：弱酸 + 强酸/弱碱/盐的同离子效应（[[同离子效应]]）——先定体系再算。
4. **与沉淀联动**：H₂S 饱和溶液 [S²⁻] = Ka1Ka2[H₂S]/[H⁺]² 驱动硫化物分步沉淀。
5. **分布分数**（进阶）：某 pH 下 HA/A⁻ 各占比例 δ = [HA]/([HA]+[A⁻]) = [H⁺]/([H⁺]+Ka)——滴定曲线与缓冲区的定量基础。

## 弱酸 vs 强酸 vs 中强酸对比表

| 性质 | 强酸（HCl） | 中强酸（H₃PO₄） | 弱酸（HAc） |
|---|---|---|---|
| 电离程度 | 完全（无分子） | 部分但可观（α ~30%） | 很小（α ~1%） |
| Ka | —（极大） | 10⁻²~10⁻³ | <10⁻³ |
| 0.1 mol/L 的 pH | 1.0 | ~1.6（一级） | 2.87 |
| 稀释 10 倍 pH 变化 | +1.0 | <+1.0 | <+1.0（电离度补偿） |
| 同离子效应敏感性 | 无 | 弱 | 强（加 NaAc pH 显著上升） |
| 溶液主要物种 | H⁺、A⁻ | H⁺、H₂PO₄⁻、H₃PO₄ | HAc 分子为主 + 少量离子 |

**关键判别**：电解质强弱看**电离度**（熔融/水中是否全电离），不看溶解度、不看 Ka 之外的任何直觉——这是"电解质"与"溶解性"两个维度的经典混淆点。

## 稀释算例（补偿效应）

**题目**：将 0.10 mol/L HAc 稀释 100 倍，pH 变化多少？（对比强酸）

**解答**：稀释后 c = 1.0×10⁻³，c/Ka = 55.6 < 500 → 解二次方程：[H⁺] = 1.3×10⁻⁴（近似 √(Ka·c) = 1.34×10⁻⁴ 尚可），pH = 3.87。原 pH 2.87 → 稀释 100 倍 pH 只升 1.0。

**对比**：强酸 HCl 0.1→1.0×10⁻³ mol/L，pH 从 1 升到 3（+2.0）。弱酸 pH 变化（+1.0）小于强酸（+2.0）——因为稀释使电离度 α 从 1.3% 升到 13%，部分补偿了浓度下降。**"弱酸稀释 pH 变化慢于强酸"是判断弱酸与否的实验依据之一**（配合电导法）。

## 进阶：质子条件与精确解（决赛衔接）

对浓度为 c 的一元弱酸，质子条件（PBE）：[H⁺] = [A⁻] + [OH⁻]。代入平衡关系 [A⁻] = Ka·c/([H⁺]+Ka)、[OH⁻] = Kw/[H⁺]：

[H⁺] = Ka·c/([H⁺]+Ka) + Kw/[H⁺]

- 忽略 [OH⁻]（c 不太稀）→ 二次方程（前文）；
- 再忽略分母中的 [H⁺]（c/Ka ≥ 500）→ [H⁺] = √(Ka·c)（近似式）。

**三档递进是同一个方程的三次化简**——记忆"先判断、再选式"的底气来自这里。决赛涉及极稀弱酸（c ~ 10⁻⁷）、纯水加微量酸、混合酸时，回到 PBE 精确式最稳。

**自检题**：0.10 mol/L NH₄Cl（NH₃ 的 Kb = 1.8×10⁻⁵）的 pH？——NH₄⁺ 是弱酸（Ka = Kw/Kb = 5.6×10⁻¹⁰），c/Ka 远超 500，[H⁺] = √(5.6×10⁻¹⁰×0.10) = 7.5×10⁻⁶，pH ≈ 5.13。盐类水解的 pH 计算与弱酸同构，只是先由 Kw/Kb 换出 Ka。
- 收尾自查：能说出"为什么弱酸稀释 pH 变化小于强酸"（电离度补偿）并算对一道 c/Ka 恰在 500 附近的题，本页掌握达标。
