# 弱酸

## 核心概念

弱酸是指在水溶液中仅部分电离的酸，其电离平衡常数Ka远小于1。常见弱酸包括醋酸（CH₃COOH）、碳酸（H₂CO₃）、氢氟酸（HF）等。

## 🎯 教学视角

### 学习路径建议
弱酸应在学习酸碱理论和电离平衡之后引入。先理解弱酸的部分电离特征，再掌握Ka的表达式和pH计算方法，最后学习多元弱酸的分步电离和缓冲溶液的概念。

### 学生易踩的认知误区
| 误区 | 正解理解 |
|:---|:---|
| 弱酸就是不溶于水的酸 | 弱酸可溶于水但仅部分电离，如醋酸易溶但是弱酸 |
| Ka越小酸性越强 | Ka越小说明电离程度越小，酸性越弱 |
| 弱酸溶液中H⁺浓度等于酸的浓度 | 弱酸仅部分电离，[H⁺]远小于酸的总浓度 |

### 入门级例题
**题目**：0.10 mol/L HAc溶液的pH是多少？（Ka = 1.8×10⁻⁵）
**解答**：设[H⁺] = x，则x²/0.10 = 1.8×10⁻⁵，x = 1.34×10⁻³ mol/L。pH = 2.87。

### 与现实世界的联系
1. **食品调味**：醋酸（乙酸）是食醋的主要成分，赋予酸味
2. **碳酸饮料**：CO₂溶于水形成碳酸（H₂CO₃），产生气泡和酸味
3. **制药工业**：阿司匹林（乙酰水杨酸）是弱酸，其吸收受胃液pH影响
