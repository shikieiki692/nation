# 弱碱

## 核心概念

弱碱是指在水溶液中仅部分电离的碱，其电离平衡常数Kb远小于1。常见弱碱包括氨水（NH₃·H₂O）、甲胺（CH₃NH₂）等。

**Brønsted 定义落地**：弱碱是"接受质子能力有限"的物种——NH₃ 只有孤对电子上的部分"拉力"能夺走水中 H⁺。平衡写作：

NH₃ + H₂O ⇌ NH₄⁺ + OH⁻，Kb = [NH₄⁺][OH⁻]/[NH₃] = 1.8×10⁻⁵（25°C）

**两类弱碱形态**：① 分子碱（NH₃、RNH₂、吡啶——靠 N 孤对）；② 阴离子碱（Ac⁻、CO₃²⁻、S²⁻、PO₄³⁻——共轭碱，即"弱酸盐的水解"）。两者共用同一套 Kb 计算框架，只是来源不同（后者 Kb = Kw/Ka(共轭酸)）。

## 电离平衡与计算（与弱酸镜像对称）

**近似条件同款**：c/Kb ≥ 500 时 [OH⁻] = √(Kb·c)，pOH = ½(pKb − log c)，pH = 14 − pOH；不满足解二次方程 [OH⁻]² + Kb[OH⁻] − Kb·c = 0。

**共轭桥**：Ka(NH₄⁺)·Kb(NH₃) = Kw，pKa(NH₄⁺) + pKb(NH₃) = 14。查表常见只给 Ka（如 NH₄⁺ 的 Ka = 5.6×10⁻¹⁰），要算氨水碱度先 Kb = Kw/Ka 换算——**"给酸查碱、给碱查酸"是标准动作**。

**盐类水解的归属**：NH₄Cl 溶液显酸性（NH₄⁺ 是弱酸）、NaAc 显碱性（Ac⁻ 是弱碱）——"谁强显谁性"即比较盐离子的 Ka 与 Kb（或对应酸/碱强度）。强碱弱酸盐的 pH 计算本质就是阴离子弱碱的 Kb 计算。

## 碱强度排序与结构因素

| 碱 | Kb | pKb | 说明 |
|---|---|---|---|
| NaOH | — | <0 | 强碱（完全解离出 OH⁻） |
| 甲胺 CH₃NH₂ | 4.4×10⁻⁴ | 3.36 | 烷基给电子 → 强于氨 |
| 氨 NH₃ | 1.8×10⁻⁵ | 4.75 | 基准 |
| 苯胺 C₆H₅NH₂ | 4.3×10⁻¹⁰ | 9.37 | 苯环共轭吸走 N 孤对 → 大弱 |
| 吡啶 | 1.5×10⁻⁹ | 8.82 | 弱于氨（sp² N） |
| Ac⁻ | 5.6×10⁻¹⁰ | 9.25 | 对应 HAc Ka 1.8×10⁻⁵ |
| CO₃²⁻ | 2.1×10⁻⁴(Kb1) | 3.67 | 二元碱（对应 HCO₃⁻ 的 Ka2 = 5.6×10⁻¹¹） |

**规律**：① 烷基给电子 → 脂肪胺碱性强于氨（MeNH₂ > NH₃）；② 苯环/羰基吸电子（共轭分散孤对）→ 苯胺、酰胺碱性大减（酰胺几乎中性）；③ 杂化影响：N 的 s 成分越高碱性越弱（sp³ 胺 > sp² 吡啶 > sp 腈）；④ 阴离子碱的强度反比于共轭酸强度（Ac⁻ < CO₃²⁻ < S²⁻——对应 HAc > HCO₃⁻ > HS⁻）。

**氢氧化物 vs 胺碱的区分**：NaOH 在水中直接给出 OH⁻；NH₃ 是"夺取水中质子生成 OH⁻"——前者强碱解离、后者弱碱水解，但产物都有 OH⁻，计算统一用 [OH⁻] 语言。

## 多元弱碱（阴离子）的分步水解

CO₃²⁻ 在水中的两级"电离"实为两级水解：

CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻（Kb1 = Kw/Ka2 = 10⁻¹⁴/5.6×10⁻¹¹ = 1.8×10⁻⁴）
HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻（Kb2 = Kw/Ka1 = 10⁻¹⁴/4.3×10⁻⁷ = 2.3×10⁻⁸）

**Kb1 ≫ Kb2**（对应 Ka1 ≪ Ka2 的倒数关系）——[OH⁻] 由第一级主导。Na₂CO₃ 溶液 pH ≈ 11.6（0.1 mol/L），显著强碱性；NaHCO₃ 因 HCO₃⁻ 本身两性呈弱碱（见 [[两性物质]] √(Ka1Ka2) 公式）。

**S²⁻、PO₄³⁻ 同理**：Na₂S 溶液强碱性（Kb1 = Kw/Ka2(HS⁻ 的 Ka 1.1×10⁻¹²) ≈ 0.009），Na₃PO₄ 也强碱——"弱酸强碱盐水解显碱性"的定量都走 Kb = Kw/Ka。

## 完整算例（两级水解 pH）

**题目**：求 0.10 mol/L Na₂CO₃ 溶液的 pH（H₂CO₃：Ka1 = 4.3×10⁻⁷、Ka2 = 5.6×10⁻¹¹）。

**解答**：Kb1 = Kw/Ka2 = 1.0×10⁻¹⁴/5.6×10⁻¹¹ = 1.8×10⁻⁴。c/Kb1 = 0.10/1.8×10⁻⁴ = 556 ≥ 500 → [OH⁻] = √(1.8×10⁻⁴×0.10) = 4.2×10⁻³，pOH = 2.37，**pH = 11.63**。

**验证**：第二级 Kb2 = 2.3×10⁻⁸ 产生的 OH⁻ 可忽略（<1%）；若用 NaHCO₃（两性）则 pH = ½(pKa1+pKa2) = 8.35——同为碳酸钠家族，Na₂CO₃ 与 NaHCO₃ 的 pH 差 3 个多单位，是"阴离子碱 vs 两性物"的绝佳对比题。

## 三类碱的形态对照

| 类别 | 代表 | "给出碱性的方式" | 强度尺度 |
|---|---|---|---|
| 氢氧化物强碱 | NaOH、KOH | 直接解离出 OH⁻ | 无 Kb（完全） |
| 分子弱碱 | NH₃、RNH₂、吡啶 | 夺水中 H⁺ 生成 OH⁻ | Kb（10⁻³~10⁻¹⁰） |
| 阴离子弱碱 | Ac⁻、CO₃²⁻、S²⁻、PO₄³⁻ | 水解（夺 H⁺ 生成 OH⁻） | Kb = Kw/Ka(共轭酸) |

**统一视角**：三类碱最终都使 [OH⁻] > [H⁺]——"碱"的 Brønsted 定义（接受质子）把氢氧化物之外的物种也纳入，而计算上强碱直接给 [OH⁻]、弱碱走 Kb 平衡。**判别题常见陷阱**：NaHCO₃ 既含 Na⁺（强碱阳离子）又含 HCO₃⁻（两性阴离子）——碱性来自 HCO₃⁻ 的水解主导，属第三类且很弱。

## 缓冲算例（弱碱/共轭酸体系）

**题目**：含 0.20 mol/L NH₃ 与 0.30 mol/L NH₄Cl 的缓冲溶液，pH 多少？（NH₃ Kb = 1.8×10⁻⁵）

**解答**：方法一（Kb 视角）：[OH⁻] = Kb·[NH₃]/[NH₄⁺] = 1.8×10⁻⁵×0.20/0.30 = 1.2×10⁻⁵，pOH = 4.92，pH = 9.08。

方法二（Henderson-Hasselbalch）：pKa(NH₄⁺) = 14 − pKb(NH₃) = 9.25；pH = pKa + log([NH₃]/[NH₄⁺]) = 9.25 + log(0.20/0.30) = 9.25 − 0.18 = 9.07 ✓（两法一致）。

**要点**：碱性缓冲区的 H-H 公式里 pKa 用的是**共轭酸的 pKa**（9.25），不是氨的 pKb——"缓冲对写共轭酸、公式套 pKa"是高频错点；加少量强酸/强碱时 pH 变化 <0.1（缓冲容量内）。

## 判断速练

1. **排序碱性**：NaOH、CH₃NH₂、NH₃、C₆H₅NH₂、吡啶 → NaOH > CH₃NH₂ > NH₃ > 吡啶 > 苯胺（给电子/杂化/共轭三因素）。
2. **选试剂**：要制备几乎不含 NH₃ 的 NH₄Cl 浓溶液？——加 HCl 至酸性（NH₃ 全转 NH₄⁺）；反之要"无 NH₄⁺ 的氨水"不存在（共轭平衡）。
3. **判 pH**：0.1 mol/L NaAc 与 0.1 mol/L NH₄Cl 谁更"偏离中性"？——NaAc: Kb = 5.6×10⁻¹⁰，pH ≈ 8.87；NH₄Cl: Ka = 5.6×10⁻¹⁰，pH ≈ 5.13——对称偏离，同数量级。
4. **陷阱**：Mg(OH)₂ 是强碱吗？——不是，微溶但溶解部分全电离（"强电解质"），其悬浊液碱性弱源于溶解度而非强度——强度与溶解度再次分离。

## 同离子效应与稀释（弱碱专属表现）

**加共轭酸（NH₄⁺）**：向氨水加 NH₄Cl，同离子 NH₄⁺ 抑制电离平衡左移：[OH⁻] 下降、pH 下降——这就是 [[同离子效应]] 与缓冲的同一枚硬币两面（缓冲 = 适量共轭酸共存；同离子 = 过量抑制）。

**稀释补偿**：氨水稀释 10 倍，电离度 α 从 1.3% 升到约 4%，[OH⁻] 只降约 3 倍（√10 关系）而非 10 倍——pH 降约 0.5 而非 1.0（对比强碱 NaOH 稀释 10 倍 pH 恰降 1）。**"弱碱稀释 pH 变化慢"与弱酸同源**，同受"稀释促电离"补偿。

**加无关盐（离子强度）**：高浓度 NaCl 使活度系数下降，表观电离度略升（盐效应）——初赛不考定量，只需知道"同离子抑制、盐效应微弱促进"的方向。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 弱碱 = 不溶于水的碱 | 溶解性与碱强度无关 | NH₃ 极易溶却是弱碱；Ca(OH)₂ 微溶却是强碱（溶解部分全电离） |
| Kb 越大碱性越弱 | Kb 大 = 电离程度大 = 碱强 | MeNH₂（Kb 4.4×10⁻⁴）碱性强于 NH₃（1.8×10⁻⁵） |
| 弱碱溶液只有 OH⁻ 和碱分子 | 还有 H⁺（水电离）与共轭酸 | 0.1 mol/L 氨水 [OH⁻] = 1.3×10⁻³ 时 [H⁺] = 7.7×10⁻¹²——中性水也有 10⁻⁷ |
| 算 [OH⁻] 忘了 14 − pOH | 得到 pOH 直接当 pH | pH = 14 − pOH：氨水 pOH 2.87 → pH 11.13 |
| 阴离子碱的 Kb 直接查表 | 常只给共轭酸 Ka，须 Kb = Kw/Ka | Ac⁻ 的 Kb = 10⁻¹⁴/1.8×10⁻⁵ = 5.6×10⁻¹⁰ |
| 多元碱水解只算一级就算完 | 第二级虽小但影响 [CO₃²⁻] 等物种分布 | pH 由 Kb1 定，但 [HCO₃⁻]/[CO₃²⁻] 分布要两级联立 |

## 🎯 教学视角

### 学习路径建议
弱碱应在学习酸碱理论和电离平衡之后引入。先理解弱碱的部分电离特征，再掌握Kb的表达式和计算方法，最后学习共轭酸碱对的关系（Kw = Ka × Kb）。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 弱碱就是不溶于水的碱 | 弱碱可溶于水但仅部分电离，如NH₃·H₂O是弱碱但易溶 |
| Kb越大碱性越弱 | Kb越大说明电离程度越大，碱性越强 |
| 弱碱溶液中只有OH⁻和碱分子 | 溶液中同时存在OH⁻、H⁺和未电离的碱分子 |

### 入门级例题
**题目**：0.10 mol/L NH₃·H₂O的pH是多少？（Kb = 1.8×10⁻⁵）
**解答**：设[OH⁻] = x，则x²/0.10 = 1.8×10⁻⁵，x = 1.34×10⁻³ mol/L。pOH = 2.87，pH = 11.13。

### 与现实世界的联系
1. **清洁剂**：氨水是常见的家用清洁剂，利用其弱碱性去除油污
2. **食品工业**：碳酸氢铵作为膨松剂用于烘焙
3. **生物缓冲**：血液中的NH₄⁺/NH₃缓冲对参与酸碱平衡调节

> **记忆锚**：弱碱镜像弱酸——Kb 换 Ka、[OH⁻] 换 [H⁺]、pOH 再转 pH；查表先过 Ka·Kb = Kw 桥；阴离子碱（水解）与分子碱同框架。

## 常用 Kb 数量级速查

| 碱 | Kb | 用途锚点 |
|---|---|---|
| CH₃NH₂ | 4.4×10⁻⁴ | 脂肪胺代表（强于氨） |
| NH₃ | 1.8×10⁻⁵ | 基准（pKb 4.75） |
| CO₃²⁻ | 1.8×10⁻⁴ | Na₂CO₃ 水解一级 |
| Ac⁻ | 5.6×10⁻¹⁰ | 对应 HAc（pKb 9.25） |
| 吡啶 | 1.5×10⁻⁹ | 芳香氮碱 |
| 苯胺 | 4.3×10⁻¹⁰ | 共轭吸电子大弱 |
| S²⁻ | ≈ 9×10⁻³（Kb1） | Na₂S 强碱性 |

**对照记忆**：pKb = 14 − pKa(共轭酸)——只要记住共轭酸 pKa（NH₄⁺ 9.25、HAc 4.76、HCO₃⁻ 10.33、HS⁻ 12），Kb 立即心算。

## 竞赛考察要点与命题角度

1. **pH 计算**：氨水/胺/弱酸盐——对称三步（条件判断 → √(Kb·c) → pH = 14 − pOH）。
2. **碱强度排序**：脂肪胺 > NH₃ > 吡啶 > 苯胺 > 酰胺——给电子/吸电子/杂化三因素。
3. **共轭换算**：给 Ka(NH₄⁺) 求氨水 Kb、给 Kb 求盐溶液 pH——Kw 桥必考。
4. **缓冲体系**：NH₃/NH₄Cl 缓冲对的 pKa = 9.25（即 NH₄⁺ 的 pKa）——碱性缓冲区的 Henderson-Hasselbalch 用 pKa 而非 pKb 表达（pH = pKa + log[碱]/[酸]）。
5. **多元弱碱盐**：Na₂CO₃/Na₃PO₄/Na₂S 的强碱性（Kb1 = Kw/Ka2）与沉淀/气体联动（CO₃²⁻ 遇酸放 CO₂）。
