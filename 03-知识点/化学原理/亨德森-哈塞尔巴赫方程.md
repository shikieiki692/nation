## 核心概念

Henderson-Hasselbalch方程：pH = pKa + log([A⁻]/[HA])，用于计算缓冲溶液的pH值。

## 🎯 教学视角

### 学习路径建议
Henderson-Hasselbalch方程应在学习酸碱平衡和缓冲溶液之后引入。先理解缓冲溶液的工作原理，再推导pH = pKa + log([A⁻]/[HA])公式，最后通过实际计算掌握其应用，注意适用条件（浓度不能太稀）。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| Henderson-Hasselbalch方程适用于所有酸碱溶液 | 仅适用于缓冲溶液，即弱酸/共轭碱或弱碱/共轭酸体系 |
| pH一定等于pKa时缓冲能力最强 | 缓冲能力最强时[A⁻]/[HA]=1，此时pH=pKa，但缓冲范围是pKa±1 |
| 加水稀释不会改变pH | 稀释会改变[A⁻]/[HA]的比值（因为活度系数变化），pH会有微小变化 |

### 入门级例题
**题目**：0.10 mol/L HAc和0.050 mol/L NaAc混合溶液的pH是多少？（pKa = 4.76）
**解答**：pH = pKa + log([A⁻]/[HA]) = 4.76 + log(0.050/0.10) = 4.76 + log(0.5) = 4.76 - 0.30 = 4.46。

### 与现实世界的联系
1. **血液缓冲**：血液中HCO₃⁻/H₂CO₃缓冲对维持pH在7.35-7.45
2. **细胞培养**：生物缓冲液（如PBS）的配制依赖Henderson-Hasselbalch方程
3. **药物制剂**：药物的溶解度和吸收率常受pH影响，需用缓冲体系控制
