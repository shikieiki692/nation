# 洪特规则

## 一、定义

洪特规则（Hund 规则，1925 年 F. Hund）是电子排布三规则之一（另两条：构造原理/Aufbau、泡利不相容原理），内容两条：**①在能量简并（等价）的轨道上排布电子时，电子优先分占不同轨道且自旋平行（尽可能多取平行自旋）；②等价轨道全满、半满或全空时体系较稳定**（半满/全满的"额外稳定性"是规则推论，用于解释 Cr、Cu 等反常排布）。物理本质：平行自旋的电子因交换作用（费米子统计）在空间上趋于分离、库仑排斥更小，故体系能量更低。洪特规则直接决定原子的**未成对电子数**，进而决定磁性（顺磁/抗磁）与光谱项——是"电子排布 → 磁矩/性质"推理链的关键一环。

## 二、考纲对应

本页属原子结构-电子排布考点，对应"洪特规则与未成对电子数判断"：会用洪特规则写 p/d/f 简并轨道的电子分布并数未成对电子；掌握半满/全满稳定性对 Cr（3d⁵4s¹）、Cu（3d¹⁰4s¹）、Mo、Ag 等反常排布的解释；能由电子排布判断原子/离子的磁性与磁矩（衔接 [[顺磁性]]/[[磁矩]]）。初赛直接考排布书写与未成对电子计数，决赛配位化学（Wilkinson 催化剂 d 电子数）依赖此基础。

## 三、核心原理

### 3.1 规则一：简并轨道分占 + 自旋平行

- 同亚层（如 3 个 2p、5 个 3d、7 个 4f）轨道能量相同（简并）。放电子时：
  - 先每个轨道放 1 个电子（**自旋相同**，全平行）；
  - 轨道数不够时才在同一轨道**成对**（第二电子自旋相反）。
- 例：N（1s²2s²2p³）的三个 2p 电子分占三个 p 轨道且自旋全平行 → 3 个未成对；O（2p⁴）第四个电子才与某个配对 → 2 个未成对。
- 为什么平行更稳：两个**自旋平行**的电子因交换能（同自旋费米子反对称波函数）空间分离 → 库仑排斥小于"反平行共占"；自旋平行电子数越多，交换稳定化越大。

### 3.2 规则二：半满/全满的额外稳定性（含 Cr/Cu 反常）

- 等价轨道**全空、半满、全满**是较稳定构型（交换能最大/电子分布最对称、屏蔽均匀）。
- 由此出现 d⁴/d⁵、d⁹/d¹⁰ 的排布"竞争"：3d⁴ 若排 4s² 则 d 轨道 3 单 1 对；改为 3d⁵4s¹ 可获半满 d 的稳定化——**Cr: [Ar]3d⁵4s¹**（不是 3d⁴4s²）。
- 同理 **Cu: [Ar]3d¹⁰4s¹**（全满 d）；Mo（4d⁵5s¹）、Ag（4d¹⁰5s¹）同型；Nb、Ru、Rh、Pd 等也受类似效应。
- 边界：半满/全满优势只在**能量相近**的亚层间显著（3d–4s 差小）；能量差大（如 2p–3s）时不适用——"所有元素都要让 4s 给 d 让路"是错的（如 Zn 正常 [Ar]3d¹⁰4s²）。

### 3.3 数未成对电子：规则一的应用主场景

| 组态 | 排布 | 未成对数 n |
|---|---|---|
| p³（N） | 3 轨道各 1 | 3 |
| d⁵（Mn²⁺/Fe³⁺ 高自旋） | 5 轨道各 1 | 5 |
| d⁶（Fe²⁺ 高自旋） | 4 单 + 1 对 | 4 |
| d⁷（Co²⁺ 高自旋） | 3 单 + 2 对 | 3 |
| f⁷（Gd³⁺） | 7 轨道各 1 | 7 |

- 记忆法：n ≤ 5 时 n = 电子数；n > 5 时未成对 = 10 − n（d 亚层）或 14 − n（f 亚层）。
- 由 n 可接磁矩（μ = √(n(n+2)) BM，见 [[顺磁性]]/[[磁矩]]）——把排布规则接到磁性判断。

### 3.4 在分子/配合物中的延伸

- 洪特规则同样适用于分子轨道中的简并轨道：O₂ 的 (π*)² 分占两轨道且平行 → 三线态/顺磁（MO 理论应用）。
- 配合物高低自旋（八面体场）本质是"洪特（分占）vs 配对能 P"的竞争：Δo < P 时电子分占（高自旋，符合洪特）；Δo > P 时成对（低自旋，违背洪特但总能量更低）——"洪特规则不是绝对铁律，场强可压倒它"。
- 卡宾（CH₂）的 singlet/triplet 也由该逻辑理解（Clayden 38 语境）。

### 3.5 与其他排布规则的关系

- 顺序：先 **Aufbau**（按能级填充 1s→2s→2p→3s→3p→4s→3d…）→ 再 **泡利**（每轨道 ≤2 且自旋相反）→ 最后 **洪特**（简并轨道怎么分）。三规则合力给出基态排布。
- 洪特是"给定轨道集合内如何放电子"的规则；Aufbau 决定"放进哪个集合"——Cr 的"反常"其实是两条规则的竞争结果。

## 四、关键结论

- 洪特规则：简并轨道分占且平行（规则一）+ 半满/全满稳定（规则二）。
- 根源是交换作用/库仑排斥：平行自旋电子空间分离更省能。
- 应用主线：数未成对电子 n → 磁性判断/磁矩计算。
- Cr/Cu 型反常 = 半满/全满竞争 4s 电子（仅能量相近时成立）。
- 配合物高/低自旋是洪特与配对能的竞争；O₂ 顺磁是分子轨道版的洪特。

## 五、常见分类或情形

- **按轨道**：p 轨道（N/O/F）、d 轨道（过渡金属离子）、f 轨道（镧系 Gd³⁺ 等）。
- **按反常排布**：Cr/Mo（半满 d⁵）、Cu/Ag/Au（全满 d¹⁰）、Nb/Ru/Rh/Pd（中间型）。
- **按应用**：未成对计数（基础）、磁性判断（顺磁 n>0）、配合物自旋态、MO 简并轨道（O₂）。
- **按考法**：写排布数 n、解释 Cr/Cu、判断高/低自旋的 n、接磁矩计算。

## 六、适用条件与限制

- 半满/全满"稳定化"是近似经验规律：能量差小时才主导（3d–4s）；重元素相对论效应使 6s/5d 关系更复杂（Au 型）。
- 洪特规则描述**基态**；激发态/离子化后可偏离。
- 规则一只在简并轨道间生效：不同能级轨道（2s vs 2p）不存在"分占"选择。
- 配体场强可压倒规则二（低自旋配合物）——配合物语境别死套"洪特优先分占"。
- 光谱项（LS 耦合）层面洪特另有三条（最大 S、最大 L、J 规则）——竞赛一般不深入到 Russell-Saunders。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 洪特只适用 d 轨道 | 适用于一切简并轨道（p/d/f）；p³（N）就是最常例子 |
| "先填满再成对"理解错 | 规则一是"简并轨道先各 1 个且平行"，不是"把外层先填满"——配对永远最后 |
| 半满/全满绝对稳定 | 只在能量相近亚层间显著（3d/4s）；4s 与 3d 差大或重元素时不总适用（Zn 正常 3d¹⁰4s²） |
| 高自旋一定更稳 | 配合物中 Δo > P 时低自旋更稳（CN⁻ 强场）——洪特让位于配体场 |
| 把 Aufbau 与洪特混为一谈 | Aufbau 决定填充顺序（能级）；洪特决定简并轨道内分布——Cr 反常是两者竞争而非某一规则错 |

## 九、典型题型

- **排布与计数**：写 Fe/N/Mn²⁺/Co²⁺ 排布并数未成对电子（Fe：3d⁶ 高自旋 n=4）。
- **反常解释**：为何 Cr 是 3d⁵4s¹、Cu 是 3d¹⁰4s¹？（半满/全满稳定化）。
- **磁性衔接**：由 n 求磁矩 μ = √(n(n+2))（25 届 Wilkinson 催化剂语境）。
- **高低自旋**：八面体 d⁶（Fe²⁺）高自旋 n=4 vs 低自旋 n=0——判断条件与磁矩差。
- **周期表规律**：同族（Cr/Mo/W）或同周期反常排布对比。

## 十、例题

**例题 1**：写出 Fe 原子（Z=26）基态电子排布并数未成对电子。

**解答**：Fe：[Ar]3d⁶4s²。3d 有 5 个简并轨道，前 5 个 d 电子按洪特规则各占一轨道且自旋平行，第 6 个电子只能与其中一个配对（自旋反平行）→ 4 个单电子轨道 → **未成对电子 n = 4**（高自旋 d⁶；若在强场配体下低自旋则 n = 0）。磁矩自旋-only μ = √(4×6) ≈ 4.90 BM。

**例题 2**：解释 Cr（Z=24）的电子排布为何是 [Ar]3d⁵4s¹ 而非 [Ar]3d⁴4s²。

**解答**：3d⁵（半满，5 个电子分占 5 个轨道且平行）获得最大交换能稳定化；把 4s 的一个电子"降"到 3d 使 d 达到半满所获稳定化超过 4s→3d 的能量差（3d 与 4s 能量相近），故基态取 3d⁵4s¹。Cu 同理取 3d¹⁰4s¹（全满）。注意此逻辑要求亚层能量差足够小；对 Zn（3d¹⁰4s²，d 已全满无需让电子）与轻元素不适用。

**例题 3**：[Fe(CN)₆]³⁻ 与 [Fe(H₂O)₆]³⁺ 的未成对电子数各为多少？洪特规则在哪一个被"违反"？

**解答**：两者 Fe 均为 +3 = d⁵。[Fe(CN)₆]³⁻：CN⁻ 强场 Δo > P → 低自旋 t₂g⁵（先填满 t₂g 一对，再单占一个）→ n = 1；[Fe(H₂O)₆]³⁺：H₂O 弱场 → 高自旋五轨道各 1 → n = 5。低自旋 d⁵ 中电子"成对优先于分占"，形式上违背洪特规则一，但总能量（晶体场稳定化）更低——说明**洪特规则是在"无外场竞争"时的基态规则，配体场可压倒它**。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 洪特只适用于 d 轨道 | p、f 简并轨道同样适用——N（2p³）n=3 是基础例子 | 判别：凡"同亚层多电子"都先分占平行；不限 d |
| 先成对后分占 | 规则一要求**先分占（平行）再配对**；把第 2 个电子立刻填入同一轨道即错 | 反例：O 2p⁴ = 3 单 1 对（n=2），不是 2 对（n=0）——画轨道箱逐个填 |
| 半满/全满绝对化 | 只在能量相近的亚层（3d/4s）显著；说"所有 d⁴/d⁹ 都反常"即错（Pd 等重元素另论、能量差大不适用） | 反例：Zn 正常 3d¹⁰4s²；Cr/Mo 才 3d⁵4s¹——看具体元素与能差 |
| 配合物也硬套"洪特优先分占" | 强场（CN⁻/CO）Δo>P 时低自旋（成对）更稳——分占不是无条件最优 | 判别：先看配体强弱；弱场高自旋（洪特）、强场低自旋（配对） |
| 未成对计数 n>5 出错 | d 亚层 n>5 时未成对 = 10−n（d⁶→4、d⁷→3）；写成 n=电子数即错 | 自检：d⁶ 高自旋 n=4（4 单 1 对）；d¹⁰ n=0 抗磁 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
洪特规则应在学习构造原理和泡利原理之后引入，是电子排布三规则的最后一条。先理解"简并轨道优先单独占据且平行"的物理本质（交换能/降低排斥），再掌握半满/全满修正（Cr/Cu），最后把未成对电子数接到磁矩与配合物自旋态（高/低自旋）形成完整链条。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 洪特规则只适用于 d 轨道 | 同样适用于 p、f 等一切简并轨道（N 的 2p³ 即经典例子） |
| 电子必须先填满低轨道再分占 | 简并轨道内先各占 1 个（自旋平行），配对标在最后 |
| 半满全满稳定性是绝对的 | 只在能量相近轨道间显著（3d/4s）；能量差大时（如 2p/3s）不适用 |
| 配合物无条件分占 | 强场配体（CN⁻）使 Δo>P，低自旋成对更稳——洪特让位于配体场 |

### 12.3 入门级例题
**题目**：写出 Fe 原子（Z=26）的基态电子排布，并说明有几个未成对电子。

**解答**：Fe 为 [Ar]3d⁶4s²。3d⁶ 中 5 个轨道先各填 1 个电子（洪特规则），第 6 个电子成对填入 → 4 个未成对电子。

### 12.4 与现实世界的联系
1. **MRI 造影剂**：顺磁性 Gd³⁺（4f⁷ 半满，n=7）缩短弛豫增强对比——半满的洪特后果。
2. **磁性存储**：硬盘/磁性材料的磁性源于 d 电子平行排列（铁磁交换）。
3. **EPR/ESR 检测**：利用未成对电子探测自由基与过渡金属配合物。
