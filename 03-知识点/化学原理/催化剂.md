# 催化剂

## 一、定位

催化剂通过改变反应路径、降低有效活化能来加快速率，但不改变化学平衡常数。

## 二、学习重点
- 区分”加快速率”和”改变平衡”是两件事
- 理解均相催化、异相催化与酶催化的共性
- 会从能量图角度描述催化作用

## 🎯 教学视角

### 学习路径建议
催化剂应在学习反应速率和活化能之后引入，重点理解”降低活化能但不改变平衡”这一核心原则。先从能量图角度理解催化作用的物理图像，再分别学习均相催化、异相催化和酶催化的特点。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 催化剂能改变平衡常数 | 催化剂只改变达到平衡的速率，不改变平衡位置 |
| 催化剂参与反应就会被消耗 | 催化剂在反应循环中再生，理论上可以无限使用 |
| 催化剂能使不反应的物质发生反应 | 催化剂只能加速热力学上可行的反应，不能改变反应的热力学可行性 |

### 入门级例题
**题目**：某反应无催化剂时活化能为100 kJ/mol，加入催化剂后活化能降至60 kJ/mol。在300K时，催化反应速率大约是无催化反应的多少倍？（假设指前因子不变）
**解答**：k_cat/k_uncat = exp[(Ea,uncat - Ea,cat)/(RT)] = exp[(100000-60000)/(8.314×300)] = exp[16.04] ≈ 9.3×10⁶倍。

### 与现实世界的联系
1. **汽车尾气净化**：铂-铑催化剂将CO和NOₓ转化为无害气体
2. **工业合成氨**：铁基催化剂使N₂和H₂在温和条件下反应
3. **生物酶催化**：人体内数千种酶催化生化反应，如碳酸酐酶催化CO₂水合
