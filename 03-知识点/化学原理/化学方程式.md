# 化学方程式

## 一、定义

化学方程式是用化学式表示化学反应**质量关系**的式子，反映三件事：①哪些物质参与（反应物/产物与状态）；②计量关系（配平系数）；③反应条件。其根基是两条守恒：**质量守恒**（原子种类与数目不变）与**电荷守恒**（离子反应中净电荷不变，适用于氧化还原与电解质溶液反应）。在竞赛语境中，"化学方程式"往往是信息题的**最后落点**——给陌生反应物/产物（或只给反应物）要求书写并配平完整方程式，是初赛大题的高频形态（第 27/28/35 届真题语境）。常见变体包括：分子方程式、离子方程式、热化学方程式（含 ΔH）、电极反应式。

## 二、考纲对应

本页属化学基础工具，对应"正确书写与配平化学方程式（含离子方程式）"：掌握质量守恒与电荷守恒；会用氧化数法、离子-电子半反应法配平氧化还原方程（酸性/碱性/中性介质）；能写陌生反应（信息题）的方程式并补缺项（H₂O、H⁺、OH⁻）；区分分子方程式与离子方程式。该能力贯穿全部模块——配平错误直接失分，是竞赛的"保底技能"。

## 三、核心原理

### 3.1 配平的第一性原理：守恒

- **原子守恒**：方程式两侧每种原子个数相等——一切配平方法的最终检验标准。
- **电荷守恒**：离子方程式两侧净电荷相等；对氧化还原反应，电子转移数相等即电荷自动平衡。
- 配平完成后的自检顺序：①原子数 ②电荷（离子式）③系数最简整数比 ④状态与条件标注。

### 3.2 配平方法一：氧化数法（化合价升降法）

适用：氧化还原分子方程式。步骤：

1. 标出变化的元素氧化态（未变化的不参与配平基数）。
2. 求升降总数并取最小公倍数 → 得氧化剂/还原剂系数（升价元素总数 = 降价元素总数）。
3. 用观察法配平其余原子；若方程式含离子，最后用电荷校验。

要点：同一元素一分子内多原子变化要乘原子数（如 FeS₂ 中 S 为 −1，2 个 S 共升 2×7=14）；歧化/归中反应先按"两个半反应"分别算。

### 3.3 配平方法二：离子-电子法（半反应法）

适用：离子型氧化还原（酸性/碱性/中性介质），是竞赛最稳妥的方法：

1. 拆成氧化半反应与还原半反应，各写成"物种 + H⁺/OH⁻ + e⁻ ⇌ 物种"。
2. **介质补平规则**（记忆核心）：酸性介质用 H⁺ 与 H₂O；碱性介质用 OH⁻ 与 H₂O；中性介质原则上也可用 H⁺/H₂O（视题目指定）。
   - 氧不平衡：酸性中每多 1 个 O 加 2H⁺ 生成 1 个 H₂O（少 1 个 O 加 1 个 H₂O 生成 2H⁺）；碱性中每多 1 个 O 加 1 个 H₂O 生成 2OH⁻（少 1 个 O 加 2OH⁻ 生成 1 个 H₂O）。
3. 电荷配平：两侧电荷差用电子的数目补齐。
4. 两半反应乘最小公倍数相加，消去电子；合并同类项得最终离子方程式。

### 3.4 缺项配平与陌生反应书写

信息题高频形态：

- **缺项配平**：给"反应物 → 部分产物 + 缺项"，由守恒反推缺项（通常补 H₂O、H⁺ 或 OH⁻；少数补 O₂、H₂ 等）。判据：先数原子，缺什么补什么，再验电荷。
- **陌生反应产物预测**：先确定元素的氧化态变化（找氧化剂/还原剂），按"升价产物/降价产物 + 介质"推产物（如碱性中 MnO₄⁻ → MnO₂、酸性中 → Mn²⁺）；配平后用两条守恒验证。
- **多步/中间体**：题给若干分步反应，总反应 = 分步相加（消中间体）——与热化学循环同理。

### 3.5 分子式 vs 离子式：书写规范

- 分子方程式：所有物种写化学式，用于计量与工业反应。
- 离子方程式：**强电解质（强酸/强碱/可溶盐）拆成离子；弱电解质（弱酸/弱碱/水）、沉淀、气体、单质、氧化物保留分子式**；微溶物视状态（浊液不拆、澄清拆）。
- 氧化还原离子方程式中单质（如 Cl₂、Fe、Na）不拆；配平后可"还原"回分子方程式（若题要求）。

## 四、关键结论

- 配平本质 = 原子守恒 + 电荷守恒；两条自检永远最后做。
- 氧化数法快但易错于"同分子多原子同变价"；半反应法稳但须记介质补平规则——介质看题目（酸/碱/中性）。
- 系数必须最简整数比；电子不写进最终方程式（只在半反应中）。
- 缺项配平：先原子后电荷，缺项通常是 H₂O/H⁺/OH⁻。
- 离子方程：强拆弱留、单质沉淀气体不拆。

## 五、常见分类或情形

- **按是否氧化还原**：非氧化还原（复分解/化合/分解——原子守恒即可）；氧化还原（需电子守恒）。
- **按介质**：酸性 / 碱性 / 中性 / 熔融（如电解 Al₂O₃）；熔融体系无 H⁺/OH⁻ 参与。
- **按形态**：分子方程式、离子方程式、热化学方程式（带 ΔH 与状态）、电极反应式（正负极/阴阳极）。
- **按来源**：教材反应（背诵型）、信息题陌生反应（推理型）、实验现象型（由观察反推产物）。

## 六、适用条件与限制

- 信息题产物不确定时**不可硬配**——先判断反应类型（氧化还原？酸碱？沉淀？）再推产物；乱猜产物配平无意义。
- 介质词要看清：酸性（H⁺）、碱性（OH⁻）、中性（可加 H₂O）——用错介质整式全错。
- 歧化（同一元素既升又降）与归中（不同价态同元素变中间价）需分半反应处理，不能只用一个氧化数差。
- 有机物参与（燃烧/氧化）配平易乱：可先配 C/H 后配 O（有机物常把 C 总数先定）。
- 电极反应式注意：燃料电池中 O₂ 在碱性介质生成 OH⁻、酸性生成 H₂O——介质决定产物。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 分子式 vs 离子式 | 离子式必须拆强电解质；弱酸/弱碱/沉淀/气体/单质不拆——"所有离子都写出"与"全不拆"都是错 |
| 酸性 vs 碱性介质产物 | 同氧化剂介质不同产物不同：MnO₄⁻ 酸性→Mn²⁺、中性/弱碱→MnO₂、强碱→MnO₄²⁻——先定介质再写产物 |
| 歧化 vs 归中 | 歧化：同一价态分向高/低两价；归中：高低两价汇到中间价——都拆两个半反应处理 |
| 配平系数可否约分 | 必须最简整数比（如 2:4 → 1:2）；但半反应内部可先不约，合并时再约 |
| 电子写在方程里 | 最终方程式不含电子；电子只在半反应法中间步骤出现——把 e⁻ 留在终式即错 |

## 八、与其他知识点的联系

- [[氧化数]]：氧化数法是配平氧化还原的第一工具（升降值计算基础）。
- [[电化学]]：电极反应式是"介质限定版"的离子方程式，正负极半反应相加即电池总反应。
- [[化学计量]]：方程式系数的计量学意义（摩尔比、限量试剂计算）。
- 氧化还原反应概念（电子转移、氧化剂/还原剂）：本页配平的对象背景。
- 热化学（焓变）与 [[化学平衡]]：方程式书写在能量与平衡计算中的前置地位。

## 九、典型题型

- **直接配平**：给分子式/离子式配平（氧化数法或半反应法）。
- **介质指定**：同一反应分别在酸性/碱性条件下写出不同产物与配平。
- **缺项补全**：MnO₄⁻ + SO₃²⁻ + ___ → Mn²⁺ + SO₄²⁻ + ___（补 H⁺ 与 H₂O）。
- **陌生反应书写**：信息题给原料与描述，预测产物并写方程（如碱金属/碱土金属章节、真题语境）。
- **电极反应**：给电池体系写两极反应与总反应。

## 十、例题

**例题 1**：配平（酸性介质）：MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺。

**解答**：还原半反应 MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O（Mn +7→+2 得 5e⁻，O 多 4 用 8H⁺ 生成 4H₂O）；氧化半反应 Fe²⁺ → Fe³⁺ + e⁻。电子最小公倍数 5：MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O。自检：Mn 1=1、Fe 5=5、H 8=8、O 4=4；电荷左侧 −1+10+8=+17、右侧 +2+15=+17 ✓。

**例题 2**：配平（碱性介质）：MnO₄⁻ + SO₃²⁻ → MnO₂ + SO₄²⁻。

**解答**：MnO₄⁻ → MnO₂：Mn +7→+4 得 3e⁻；氧多 2 → 加 2H₂O 生成 4OH⁻（碱性规则：每多 1 O 加 1 H₂O 生成 2OH⁻，多 2 个 O 加 2H₂O 得 4OH⁻）→ MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻。SO₃²⁻ → SO₄²⁻：S +4→+6 失 2e⁻；多 1 个 O → 加 2OH⁻ 生成 H₂O → SO₃²⁻ + 2OH⁻ → SO₄²⁻ + H₂O + 2e⁻。电子公倍数 6：2MnO₄⁻ + 3SO₃²⁻ + H₂O → 2MnO₂ + 3SO₄²⁻ + 2OH⁻。自检：电荷左 −2−6=−8、右 −6−2=−8 ✓；O 左 8+9+1=18、右 4+12+2=18 ✓。

**例题 3**：信息题——酸性条件下 H₂O₂ 与 Fe²⁺ 反应，写离子方程式。

**解答**：H₂O₂ 中 O 为 −1，被还原为 −2（H₂O，得 2e⁻），Fe²⁺ 被氧化为 Fe³⁺（失 1e⁻）。半反应：H₂O₂ + 2H⁺ + 2e⁻ → 2H₂O；Fe²⁺ → Fe³⁺ + e⁻。公倍数 2：H₂O₂ + 2Fe²⁺ + 2H⁺ → 2Fe³⁺ + 2H₂O。自检：H 2+2=4 右 4 ✓、O 2=2 ✓、电荷左 0+4+2=+6 右 +6 ✓。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 配平后系数约分 | 化学方程式系数必须是最简整数比，但"约过头"如把 2:4:2 写成 1:2:1 是**正确**的；真正的问题是忘了约到最简（保留 2:4:2） | 自检：所有系数有公因数即未约净；半反应内部系数先不约，合并后统一约 |
| 离子方程乱拆 | 强电解质拆、弱电解质/沉淀/气体/单质/氧化物不拆；把 CH₃COOH、BaSO₄、Cl₂ 拆成离子即错 | 反例：BaSO₄ 沉淀不拆；弱酸写分子式——"可溶即拆"只对强电解质成立 |
| 介质选错/产物写错 | 同氧化剂在不同介质产物不同：酸性 MnO₄⁻→Mn²⁺、碱性→MnO₄²⁻/MnO₂；题目写"碱性"却按酸性补 H⁺ 即整式错 | 判别：先看题面介质词（酸/碱/中性/熔融），再决定补 H⁺ 还是 OH⁻ 与产物价态 |
| 只数原子不验电荷 | 氧化还原离子方程若电荷不等则电子数配错 | 自检：两侧净电荷相等是硬条件；配完先数电荷再数原子 |
| 电子写进最终方程 | e⁻ 只在半反应中间步骤出现，合并后必须消去 | 反例：终式里出现 e⁻ 即未合并完——两半反应相加时电子相互抵消 |
| 歧化/归中当普通反应配 | 同元素既升又降或高低归中时，一个氧化数差算不平 | 反例：Cl₂ + OH⁻ → Cl⁻ + ClO⁻（歧化）须拆两个半反应；Fe³⁺ + Fe → Fe²⁺（归中）同理——先识别再选方法 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
化学方程式是化学学习的基础工具，应在学习化学计量之前掌握。先理解质量守恒和电荷守恒，再学氧化数法配平氧化还原，接着掌握半反应法的介质补平规则，最后用缺项配平与信息题陌生反应书写收束——配平速度靠练习，正确率靠守恒自检。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 配平后系数可以约分 | 化学方程式的系数必须是最简整数比（约分是必须的，不是可选项） |
| 离子方程式中所有离子都要写出 | 强电解质拆成离子；弱电解质、沉淀、气体保留分子式 |
| 方程式配平与条件无关 | 同一反应在不同条件下（酸性/碱性）产物与配平都可能不同 |
| 电子写在最终方程式里 | 电子只在半反应中出现，合并后必须消去 |

### 12.3 入门级例题
**题目**：配平离子方程式（酸性条件）：MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺。

**解答**：还原半反应 MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O，氧化半反应 Fe²⁺ → Fe³⁺ + e⁻；电子公倍数 5 后相加：MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O。

### 12.4 与现实世界的联系
1. **工业生产**：化工厂物料衡算依赖准确的化学方程式。
2. **环境治理**：污水氧化还原处理需精确配平以控制药剂用量。
3. **电池设计**：电极反应配平决定电池理论容量与介质选择（燃料电池酸/碱介质产物不同）。
