# van't Hoff方程

## 一、定义

van't Hoff 方程（范特霍夫方程）是**平衡常数 K 随温度变化**的定量关系，微分形式与积分形式分别为：

- 微分式：d(lnK)/dT = ΔH°/(RT²)（ΔH° 为标准摩尔反应焓，恒压）
- 积分式（ΔH° 视为常数时）：ln(K₂/K₁) = −(ΔH°/R)·(1/T₂ − 1/T₁)

它把"化学平衡"与"热力学"两座山连成一座：只要知道某温度下的 K 与反应焓，就能预测另一温度下的 K；反过来，由多个温度的 K（或 lnK–1/T 直线的斜率）可实验测定 ΔH°。它是 Le Châtelier 原理"升温向吸热方向移动"的**定量表达**，也是合成氨等工业选择反应温度的理论基础。

## 二、考纲对应

本页属化学平衡-热力学交叉考点，对应"平衡常数与温度的关系"：能写出 van't Hoff 方程两种形式并说明各量含义；会由 ΔH° 与一个温度的 K 求另一温度的 K；能由 lnK–1/T 图求 ΔH°（斜率 = −ΔH°/R）与 ΔS°（截距）；理解 ΔH° 随温度变化需用 [[基尔霍夫定律]] 修正。初赛与决赛（合成氨热力学、CO₂ 捕集平衡等真题语境）均直接考查。

## 三、核心原理

### 3.1 从 Gibbs 能量关系推导（知道来处才记得住）

平衡时 ΔG° = −RT·lnK。把 ΔG° = ΔH° − T·ΔS° 代入并移项：lnK = −ΔH°/(RT) + ΔS°/R。对 T 求导（假定 ΔH°、ΔS° 不随 T 变）：

- d(lnK)/dT = ΔH°/(RT²)——即 van't Hoff 微分式。
- 若 ΔH° > 0（吸热），lnK 随 T 增大而增大 → 升温 K 增大；若 ΔH° < 0（放热），升温 K 减小——与 Le Châtelier 原理完全一致，只是给出了定量大小。

### 3.2 积分式与"两温度求 K"操作

对微分式从 T₁ 到 T₂ 积分（ΔH° 常数假设）：

- ln(K₂/K₁) = −(ΔH°/R)·(1/T₂ − 1/T₁)。

解题标准流程：①写反应与 ΔH°（注意符号与单位 kJ→J）；②代 T₁、K₁、T₂；③算 ln(K₂/K₁)；④开指数得 K₂。放热反应（ΔH°<0）时若 T₂ > T₁，指数为负 → K₂ < K₁，数值上可自洽检查。

### 3.3 lnK–1/T 直线：同时求 ΔH° 与 ΔS°

把积分式改写成 y = mx + b 形式：lnK = (−ΔH°/R)·(1/T) + ΔS°/R。以 lnK 对 1/T 作图得直线：

- 斜率 = −ΔH°/R → ΔH° = −斜率×R。
- 截距 = ΔS°/R → ΔS° = 截距×R。

此法用一组不同温度的 K 实验值即可同时得到焓变与熵变（题库/真题"给三个温度的 K 求 ΔH°"即此类）。注意横轴必须是 **1/T（开尔文）**，用摄氏温度作图不是直线。

### 3.4 适用前提与修正

- 积分式成立的前提是**ΔH° 在 T₁–T₂ 区间近似常数**；区间很大时须先按 [[基尔霍夫定律]] 修正（ΔH°(T) = ΔH°(T₀) + ∫ΔCₚ dT）再积分，否则误差随温差增大。
- K 必须用**标准平衡常数**（无量纲，活度/逸度表达）；用 Kc/Kp 时若反应前后气体分子数变化，温度还通过 Kc–Kp 换算关系影响数值。
- 方程适用于一切化学平衡（气相、液相、溶液、复相），不限于气体反应。
- ΔS° 随温度变化通常比 ΔH° 小，粗略处理时常一并忽略；精密题目会提示 ΔCₚ。

### 3.5 定性联系：与 Le Châtelier 原理、工业温度选择

- 升温方向：吸热反应 K 升（平衡右移），放热反应 K 降——合成氨（放热）高压低温有利平衡，但低温速率慢，工业取折中温度并用催化剂。
- 生物/环境应用：碳酸钙分解、CO₂ 胺吸收（题-038-7-1 语境）等平衡的温度敏感性均由 van't Hoff 方程量化。

## 四、关键结论

- 微分式 d(lnK)/dT = ΔH°/(RT²)：吸热 ΔH°>0 升温 K 增；放热反之。
- 积分式 ln(K₂/K₁) = −(ΔH°/R)(1/T₂ − 1/T₁)：两温度 K 互求的万能公式。
- lnK 对 1/T 作图：斜率 −ΔH°/R、截距 ΔS°/R——实验求热力学量。
- ΔH° 视作常数是近似；大温差用基尔霍夫修正。
- 与 Le Châtelier 原理是同一规律的定性与定量两面。

## 五、常见分类或情形

- **按用途**：已知 K₁、ΔH° 求 K₂（最常见）；由多温度 K 求 ΔH°/ΔS°（作图/两点式）；判断升温平衡移动方向（定性与半定量）。
- **按反应类型**：气相反应（Kp/Kc 注意 Δn）、溶液反应（活度/浓度 K）、复相反应（纯固体活度为 1）。
- **按数据形态**：题目给"两个温度的两个 K"、"三个温度三个 K"（线性回归）或"lnK–1/T 图"（读斜率截距）。

## 六、适用条件与限制

- ΔH° 恒定的近似在温差 <50–100 K 时常足够；大温差必须基尔霍夫修正。
- K 的定义必须统一（标准态）；比较不同来源数据前先核对 K 是否同为压力/浓度基准。
- 只给"升温平衡移动方向"时定性用 Le Châtelier 即可；定量必用 van't Hoff。
- 对 Δn ≠ 0 的气相反应，若题目给 Kc，温度还隐含 Kc–Kp = Kc(RT)^Δn 的换算，别只套 ln 式。
- 方程描述的是**平衡位置**随温度变化，与反应速率（Arrhenius）无关——两条曲线不要混。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| van't Hoff vs Le Châtelier | 前者定量（ΔH° 与 T 决定 K 变化量）；后者只定性（"向吸热方向"）——两者方向判断永远一致 |
| van't Hoff vs Arrhenius | van't Hoff 管平衡常数 K 随温度；Arrhenius 管速率常数 k 随温度（k = Ae^(−Ea/RT)）——一个是平衡、一个是速率 |
| lnK 对 1/T 的斜率符号 | 斜率 = −ΔH°/R：吸热反应斜率负、放热反应斜率正——把斜率直接当 ΔH°/R 即错符号 |
| ΔH° 是否随温度变 | 严格随 T 变（ΔCₚ 修正）；考题若温差大且给 ΔCₚ，须先算 ΔH°(T) 再积分 |
| Kc vs Kp vs K° | 只有无量纲标准平衡常数 K° 直接进 ln 式；Kc/Kp 需统一标准态与 Δn 换算 |

## 九、典型题型

- **两温度求 K**：298 K 时 K 已知 + ΔH° → 求 350 K（或某工业温度）的 K。
- **作图求热力学量**：给 3–4 个温度的 K，作 lnK–1/T 直线求 ΔH°、ΔS°。
- **方向判断+定量**：问升温对某放热反应 K 的影响并计算 K 变为几倍。
- **合成氨热力学**：34 届决赛语境——由 van't Hoff 分析高压低温与速率折中（题-34决理-2-5）。
- **真实体系**：CO₂ 捕集胺吸收/碳酸盐分解的平衡温度敏感性（题-038-7-1）。

## 十、例题

**例题 1**：某反应 A ⇌ B 的 ΔH° = −20 kJ/mol，298 K 时 K = 10。求 350 K 时的 K，并判断方向是否与 Le Châtelier 一致。

**解答**：ln(K₂/10) = −(−20000/8.314)·(1/350 − 1/298) = 2406×(1/350 − 1/298) ≈ 2406×(−4.98×10⁻⁴) ≈ −1.20 → K₂ = 10×e^(−1.20) ≈ 3.0。放热反应升温 K 由 10 降到约 3，与"升温向吸热方向（逆向）移动"一致——定量结果验证定性判断。

**例题 2**：测得某平衡在 T = 300/333/400 K 时 lnK = 2.0/1.2/−0.5。求该反应的 ΔH° 与 ΔS°（R = 8.314 J·mol⁻¹·K⁻¹）。

**解答**：以 lnK 对 1/T 线性回归：斜率 = (2.0−(−0.5))/(1/300−1/400) = 2.5/(3.333×10⁻³−2.5×10⁻³) = 2.5/8.333×10⁻⁴ ≈ 3000 K → ΔH° = −斜率×R = −3000×8.314 ≈ −25 kJ/mol（放热，斜率正）。截距 = lnK − 斜率×(1/T)：取 300 K 点 = 2.0 − 3000/300 = 2.0 − 10 = −8 → ΔS° = 截距×R ≈ −66.5 J·mol⁻¹·K⁻¹（反应分子数减少/熵减，与放热组合合理）。

**例题 3**：合成氨 N₂ + 3H₂ ⇌ 2NH₃ 为放热反应（ΔH° < 0）。工业为何不把温度降到极低来最大化平衡转化率？

**解答**：van't Hoff 方程表明降温确实使 K 增大、平衡转化率升高；但低温下反应速率指数下降（Arrhenius），到达平衡极慢，工厂无法接受。工业折中：约 400–500 °C + 铁基催化剂（保速率），同时用高压（反应分子数减少，加压提高转化率）与循环分离补偿平衡限制——平衡（van't Hoff）与速率（Arrhenius）两把尺子要同时用。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| ΔH° 符号带错导致方向反转 | 吸热 ΔH°>0 升温 K 增；放热升温 K 减；ln 式里 ΔH° 前还有负号，双重负号易错 | 自检：算完用 Le Châtelier 复核——若算出的移动方向与"向吸热方向"矛盾则符号错 |
| 把 1/T 写成 T 或混用摄氏温度 | 积分式是 (1/T₂−1/T₁) 且 T 必须开尔文；作图横轴也必须是 1/K | 反例：298→350 K 若误用 ℃ 数值差一个 273 偏移，结果完全错误——先换 K 再算 |
| 把 van't Hoff 当速率公式 | 它管平衡常数 K 的温变，与速率常数 k（Arrhenius）无关；升温放热反应 K 降但速率仍升 | 判别：题目问"转化率/平衡移动"用 van't Hoff；问"反应快慢/活化能"用 Arrhenius |
| 忽略 ΔH° 随温度变化 | 大温差下 ΔH° 不是常数，直接套常数积分式误差大 | 反例：给 ΔCₚ 的题必须先基尔霍夫修正 ΔH°(T) 再积分——"ΔH° 恒为常数"只在窄温区成立 |
| K 与 Kc/Kp 混用 | ln 式中 K 须是无量纲标准平衡常数；气相 Δn≠0 时 Kc 与 Kp 还差 (RT)^Δn 因子 | 判别：题目给 Kc 且反应分子数变化，先换算统一基准再代入；纯固体/液体活度 1 不写进 K |
| 把 ΔS° 当斜率相关量搞混 | lnK–1/T 直线斜率只含 ΔH°（−ΔH°/R），ΔS° 在截距——斜率读出来的是焓不是熵 | 反例：由斜率直接乘 R 得 ΔH°；要 ΔS° 用截距×R——两个量别串位 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
van't Hoff 方程应在学习化学平衡和热力学（Gibbs 自由能、焓熵）之后引入。建议先理解方程的物理意义（lnK 与 1/T 的线性关系），再掌握积分形式的应用（已知一个温度的 K 求另一温度的 K），最后学习如何通过 lnK–1/T 图求反应焓与熵。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| van't Hoff 方程只适用于气相反应 | 适用于所有化学平衡，包括溶液中的平衡与复相平衡 |
| 升温一定使 K 增大 | 吸热反应 K 随温度升高而增大，放热反应则减小——方向由 ΔH° 符号决定 |
| van't Hoff 方程中的 ΔH° 是常数 | 在温度变化范围大时需要考虑 ΔH° 随温度的变化（基尔霍夫定律） |
| 把 lnK–1/T 图的斜率记反 | 斜率 = −ΔH°/R（吸热为负、放热为正），ΔS° 在截距 |

### 12.3 入门级例题
**题目**：反应 A ⇌ B 的 ΔH° = −20 kJ/mol，298 K 时 K = 10。求 350 K 时的 K。

**解答**：ln(K₂/K₁) = −(ΔH°/R)(1/T₂ − 1/T₁) = −(−20000/8.314)(1/350 − 1/298) ≈ −1.20，K₂ = 10×e^(−1.20) ≈ 3.0。放热反应升温 K 减小，方向与 Le Châtelier 原理一致。

### 12.4 与现实世界的联系
1. **工业合成**：van't Hoff 方程指导合成氨等工业反应的温度选择（平衡与速率的折中）。
2. **药物稳定性**：预测药物在不同储存温度下降解平衡与货架期。
3. **地质过程**：地幔矿物相变、碳酸盐沉积的平衡条件随深度（温度）变化。
