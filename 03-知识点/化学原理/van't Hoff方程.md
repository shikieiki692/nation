# van't Hoff方程

## 核心概念

van't Hoff方程描述平衡常数随温度的变化：dlnK/dT = ΔH°/(RT²)，积分形式可计算不同温度下的平衡常数。

## 🎯 教学视角

### 学习路径建议
van't Hoff方程应在学习化学平衡和热力学之后引入，描述平衡常数随温度的定量变化。先理解方程的物理意义（lnK与1/T的线性关系），再掌握积分形式的应用（已知一个温度的K求另一温度的K），最后学习如何通过lnK vs 1/T图求反应焓。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| van't Hoff方程只适用于气相反应 | 适用于所有化学平衡，包括溶液中的平衡 |
| 升温一定使K增大 | 吸热反应K随温度升高而增大，放热反应则减小 |
| van't Hoff方程中的ΔH°是常数 | 在温度变化范围大时需要考虑ΔH°随温度的变化（基尔霍夫定律） |

### 入门级例题
**题目**：反应A ⇌ B的ΔH° = -20 kJ/mol，298K时K = 10。求350K时的K。
**解答**：ln(K₂/K₁) = -(ΔH°/R)(1/T₂ - 1/T₁) = -(-20000/8.314)(1/350 - 1/298) = 2406×(-4.98×10⁻⁴) = -1.20。K₂ = 10×e⁻¹·²⁰ = 3.01（放热反应，升温K减小）。

### 与现实世界的联系
1. **工业合成**：van't Hoff方程指导合成氨等工业反应的温度选择
2. **药物稳定性**：预测药物在不同储存温度下的降解平衡
3. **地质过程**：地幔中矿物相变的平衡条件随深度（温度）变化
