# 焓变计算

## 核心概念

焓变（ΔH）是化学反应中最重要的热力学量之一，有三种主要计算方法：

1. **盖斯定律法**：通过已知反应焓变的代数组合推导目标反应焓变
2. **标准生成焓法**：利用各物质的标准摩尔生成焓查表计算
3. **键能估算法**：通过断键吸热与成键放热的差值估算

**一句话本质**：ΔH 只取决于**始态与终态**（H 是状态函数），与路径无关——这是三种方法共同的理论基石。盖斯定律与生成焓法都是"状态函数 + 已知数据"的精确路径（误差来自数据本身）；键能法是"轨道层面估算"（把分子拆成键的平均能量），天然带系统性偏差。**考场选法原则：有生成焓表数据用方法二；给了若干已知反应式用方法一；什么都没有只有结构式时用方法三（并知道它是估算）。**

## 关键公式

### 方法一：盖斯定律

$$\Delta_r H_m^{\theta} = \sum n_i \cdot \Delta_r H_m^{\theta}(\text{已知反应}_i)$$

将已知反应式进行适当倍数的乘除和正逆变换，组合得到目标反应式，对应焓变做相同运算。

**操作要点**：目标反应式两边各有若干物种——把"只出现在一个已知反应中且不在目标式中的物质"（中间物）作为消元对象：凡在目标式**左边**的物质，其已知反应要**正写**；在**右边**的**反写**；倍数由消元后的系数守恒定。写完所有已知反应相加，检查左右各物质系数与目标一致后再加焓变。

### 方法二：标准生成焓法

$$\Delta_r H_m^{\theta} = \sum n_i \cdot \Delta_f H_m^{\theta}(\text{产物}) - \sum n_j \cdot \Delta_f H_m^{\theta}(\text{反应物})$$

- $\Delta_f H_m^{\theta}$：标准摩尔生成焓（从最稳定单质生成1mol化合物的焓变）
- 最稳定单质的 $\Delta_f H_m^{\theta} = 0$（如 C(石墨)、O₂(g)、H₂(g)）

**参考态三陷阱**：① 碳必须用石墨（金刚石 +1.9 kJ/mol ≠ 0）；② 相态必须写——H₂O(l) −285.8 vs H₂O(g) −241.8（差 44 = 蒸发热）；③ 磷用红磷（白磷 +17.6 kJ/mol 是参考态陷阱的经典出题点）。**"产物之和减反应物之和"记成反是最高频失误**。

### 方法三：键能估算法

$$\Delta_r H \approx \sum BE(\text{反应物}) - \sum BE(\text{产物})$$

- 断键吸热（+），成键放热（-）
- 键能数据为统计平均值，计算结果为估算值

**估算的系统偏差来源**：① 键能是"该键在所有分子中的平均值"——共振/离域（苯）、环张力、杂化状态都会使实际键强偏离平均值（苯的 C=C 键能实际介于单双键之间）；② 忽略分子间作用与相变贡献；③ 对 ΔH 小而键能大的反应（如异构化），相对误差被放大。**估算值只用于数量级与方向判断，精确值一律走前两法**。

### 焓变与内能变化的关系

$$\Delta H = \Delta U + \Delta(PV) = \Delta U + RT\Delta n$$

其中 $\Delta n$ 为气态物质的化学计量数变化。

**何时必用此式**：弹式量热计直接测得的是 ΔU（恒容），需换算成 ΔH 才与热化学数据可比（见 [[反应进度]] 弹式量热节）；只数**气体**的 Δn（固体液体 Δ(PV) 可忽略）：C(s)+O₂(g)→CO₂(g)，Δn=0 → ΔH=ΔU；而 C(s)+½O₂→CO(g)，Δn=+0.5 → ΔH = ΔU + 0.5RT。

## 完整算例：一题三法互证（推荐记住的模板）

**题目**：计算 C₂H₄(g) + H₂(g) → C₂H₆(g) 在 298 K 的 Δ_rH°。已知常用数据：ΔfH°：C₂H₄(g) +52.3、C₂H₆(g) −84.7 kJ/mol；ΔcH°：C₂H₄ −1411、C₂H₆ −1560、H₂ −286 kJ/mol；键能 BE：C=C 612、C–C 348、C–H 413、H–H 436 kJ/mol。

**解答（方法二·生成焓）**：ΔH = ΔfH°(C₂H₆) − [ΔfH°(C₂H₄) + ΔfH°(H₂)] = (−84.7) − (+52.3 + 0) = **−137.0 kJ/mol**

**验证（方法一·盖斯，用燃烧焓）**：目标式"反应物燃烧 − 产物燃烧"：

ΔH = [ΔcH°(C₂H₄) + ΔcH°(H₂)] − ΔcH°(C₂H₆) = (−1411 − 286) − (−1560) = **−137 kJ/mol ✓**（与生成焓法一致）

**估测（方法三·键能）**：

断键：C=C(612) + 4×C–H(4×413=1652) + H–H(436) = 2700 kJ/mol
成键：C–C(348) + 6×C–H(6×413=2478) = 2826 kJ/mol
ΔH ≈ 2700 − 2826 = **−126 kJ/mol**（与 −137 差 11 kJ，偏差 ~8%，来自键能平均化——量级与方向正确，作估算可用）

**要点**：① 同一反应用三种方法应自洽（−137 = −137），做题时两法互验能抓住查表错误；② 键能法写断键时**每个键逐一数**（C₂H₄ 含 1 个 C=C + 4 个 C–H，别漏 C–H）；③ 生成焓法里单质（H₂）直接是 0，别当"缺数据"。

## 典型应用

1. **燃料热值比较**：通过燃烧焓计算单位质量燃料释放的能量（kJ/g）
2. **反应可行性判断**：结合吉布斯自由能判断反应方向
3. **工业过程设计**：计算反应器的热量需求或散热设计
4. **键能反推**：已知生成焓反推特定化学键的键能（如用 ΔfH°(苯) 与"C₆H₆ 假想的 3 C=C + 3 C–C"差值估离域能）

## 方法选择决策表（考场 30 秒）

| 题干给什么 | 首选方法 | 理由 |
|---|---|---|
| 若干已知反应式 + 焓变 | 盖斯（加减消元） | 中间物消去即得 |
| 各物质的生成焓表 | 生成焓法（产物减反应物） | 一步到位，最不易错 |
| 只有结构式/键能表 | 键能估算 | 唯一可行，标注"估算" |
| 问 ΔH 与 ΔU 关系 | 恒容数据 + RTΔn 换算 | 弹式量热场景 |

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 生成焓法把加减写反 | 必须是产物之和 − 反应物之和 | C₂H₄ 加氢 ΔH<0（放热）：写反会得 +137（错） |
| 系数调整漏乘焓变 | 反应式乘 n 或反写，焓变同步乘 n / 变号 | 把已知反应 ×2 时 ΔH 也 ×2 |
| 参考态用错（金刚石/白磷） | 最稳定单质才是 0 | C 用石墨（金刚石 +1.9）；P 用红磷（白磷 +17.6） |
| 状态不写（l/g 混用） | 相态不同生成焓差一个相变焓 | H₂O(l) −285.8 vs H₂O(g) −241.8，差 44 kJ/mol |
| 键能法当精确值 | 键能是统计平均，共振/张力/杂化均会偏离 | 苯环/环丙烷用键能估算必然偏——只说数量级 |
| ΔH = ΔU 恒成立 | 只有 Δn(气) = 0 才相等 | 有气体摩尔数变化时差 RTΔn（C+½O₂→CO：+0.5RT） |
| 键能法漏数键/把断成键符号颠倒 | 断键吸热为 +、成键放热为 −；产物成键要算 | ΔH ≈ ΣBE(反应物) − ΣBE(产物)，别背反 |

## 九、🎯 教学视角

### 9.1 学习路径建议
焓变计算是热力学的核心计算技能，应在掌握盖斯定律和标准生成焓概念后系统学习。先分别掌握三种方法（盖斯定律法、生成焓法、键能法），再通过大量练习熟练运用，最后了解不同方法的适用范围和精度差异。

### 9.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 键能法计算结果与生成焓法完全一致 | 键能法使用统计平均值，结果是估算值，可能有较大偏差 |
| 盖斯定律只能用两个已知反应组合 | 可以用任意多个已知反应，关键是组合后能消去中间产物 |
| 生成焓法不需要考虑物质状态 | 同一物质不同状态（如H₂O(l)和H₂O(g)）的生成焓相差很大 |

### 9.3 入门级例题
**题目**：利用盖斯定律，由以下已知反应计算C(石墨) + ½O₂(g) → CO(g)的焓变：
① C(石墨) + O₂(g) → CO₂(g) ΔH₁ = -393.5 kJ/mol
② CO(g) + ½O₂(g) → CO₂(g) ΔH₂ = -283.0 kJ/mol
**解答**：目标反应 = ① - ②，ΔH = -393.5 - (-283.0) = -110.5 kJ/mol。

### 9.4 与现实世界的联系
1. **燃料选择**：通过燃烧焓比较不同燃料的能量密度
2. **火箭推进剂**：计算推进剂组合的总放热量以评估性能
3. **碳捕获**：利用反应焓设计CO₂捕获和封存过程的能量平衡

> **记忆锚**：状态函数走捷径（盖斯拼图、生成焓产物减反应物）；键能是估算是最后手段；ΔH 与 ΔU 差一口气体的 RTΔn；参考态石墨/红磷/相态三陷阱。

## 进阶：由生成焓反推键能/离域能（三法联动的考法）

**键能反推**：已知 ΔfH° 可倒推分子内某键的键能——例如由乙烷生成焓 −84.7、石墨升华焓 +717 与 H₂ 解离焓 +436 反推 C–C 键能 ≈ 348 kJ/mol。做法是把"单质 → 气态原子"（原子化）与"原子 → 分子"（成键）两步拆开，差值即键能。

**离域能测定（经典）**：苯的实测生成焓比"假设 3 个孤立 C=C（612×3）+ 3 个 C–C（348×3）+ 6 个 C–H（413×6）键能加和"的估算放热量**少放热约 150 kJ/mol**——即苯因离域比"假想环己三烯"稳定约 150 kJ/mol（离域能/共振能）。**"键能估算与实测之差 = 离域能"**是把方法三从"估"变"测"的关键跳板，也是竞赛唯一爱考键能法的场景。

**温度修正**：298 K 的数据用于其它温度需用 [[基尔霍夫定律]] 修正——ΔH(T₂) = ΔH(T₁) + ∫ΔC_p dT。初赛通常只要求定性：ΔC_p > 0（产物热容大）时升温 ΔH 增大；对气体反应 ΔC_p 常很小可忽略。**"298 K 数据直接用于 400 K"只在题目明示近似时成立**，否则要提基尔霍夫修正。

## 关键结论速记

- 三法三用：有生成焓用减法、有已知反应用拼图、只有结构用键能（估算）。
- 两法互证是检查手段（C₂H₄ 加氢：生成焓法 −137 = 燃烧焓盖斯 −137）。
- 参考态三陷阱：石墨（非金刚石）、红磷（非白磷）、相态必写。
- 键能法：断键 +、成键 −；苯/环丙烷等体系必然偏离平均值。
- ΔH = ΔU + RTΔn（只数气体）；弹式量热给 ΔU 要先换算。
- 数值锚：H₂O 相变 44 kJ/mol；C₂H₄ 加氢 −137；C+½O₂→CO −110.5（两套互证数据背熟）。
- 收尾自检：给同一反应能用两法独立算并核对一致、能挑出参考态陷阱、能换算 ΔU→ΔH——本页达标。
- 快速复核技巧：放热反应 ΔH 必为负（燃烧/中和/加氢都是放热）——算出正号先自查"是不是把产物减反应物写反或盖斯方向拼反"。
- 数据自洽锚：C₂H₄ 加氢 −137（两法互证）、C+½O₂→CO −110.5、H₂O 相变 +44——三组数能当"临时校验器"使用（手头结果若差一个数量级必是单位或参考态错）。
- 单位纪律：生成焓 kJ/mol（每摩尔反应式进度）；键能 kJ/mol（每摩尔键）——把"每摩尔键"直接乘化学计量数再相减是常见错误源，先数键再乘。
- 考场快排：先看题干给不给各物质 ΔfH° 表（给→方法二秒杀）；不给表只给反应式（→盖斯拼图）；只给结构（→键能并声明估算）。
- 反例自查：若答案 ΔH 为正而反应显然放热（燃烧/中和/加氢），第一嫌疑是"产物减反应物写反"或"盖斯方向拼反"——不是数据错。
- 多步组合题：分步反应加和时中间物系数须对消干净（如某物质同时在两个已知反应同侧出现需先合并再消），对消后逐项核对再求和。
