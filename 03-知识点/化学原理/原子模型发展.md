# 原子模型发展

## 核心概念

原子结构模型经历了从宏观到微观、从经典到量子的发展历程，每个模型都是对实验事实的合理化解释，同时也存在局限性。

## 模型发展时间线

### 1. 道尔顿模型（1803年）
- **核心观点**：分子由原子组成，化学反应是原子的重新排列
- **贡献**：首次明确提出原子概念，发现质量守恒定律
- **局限**：未涉及原子内部结构

### 2. 汤姆孙模型（1904年）
- **核心观点**：原子是带正电的"云"中嵌着电子（葡萄干布丁模型）
- **实验基础**：阴极射线在电场中偏转，发现电子
- **贡献**：首次发现电子并证明其普遍存在于各种物质中

### 3. 卢瑟福模型（1911年）
- **核心观点**：原子质量集中在带正电的极小原子核，电子在核外广阔空间运动
- **实验基础**：α粒子散射实验（$He^{2+}$ 轰击金箔）
  - 绝大多数α粒子直接穿过
  - 极少数发生大角度偏转
- **贡献**：证明原子核存在，原子核体积仅占原子的万亿分之一

### 4. 波尔模型（1913年）
- **核心观点**：电子在特定量子化轨道上运动，能级分立
- **实验基础**：氢原子光谱（不连续的特征谱线）
- **贡献**：首次将量子概念引入原子结构
- **局限**：仅适用于氢原子，违反测不准原理

### 5. 量子力学模型（1926年至今）
- **核心方程**：薛定谔方程 $\hat{H}\psi = E\psi$
- **核心概念**：波函数 $\psi$、原子轨道、概率密度 $|\psi|^2$
- **贡献**：成功解释多电子原子的光谱和化学性质

## 关键公式

### 薛定谔方程

$$\hat{H}\psi = E\psi$$

- $\hat{H}$：哈密顿算符
- $\psi$：波函数
- $E$：体系总能量

### 波函数的物理意义

- $|\psi|^2$：电子在空间某处出现的概率密度
- 特定解对应原子轨道（s, p, d, f）

## 易错点

1. **模型的局限性**：每个模型都有其适用范围，不能将某一模型绝对化
2. **波尔模型的地位**：尽管有缺陷，但它是量子力学发展的重要桥梁
3. **α粒子散射实验**：证明了原子核的存在，而非证明了电子的存在
4. **波粒二象性**：电子既有粒子性（$E = mc^2$）又有波动性（$E = h\nu$），与测不准原理是不同概念
