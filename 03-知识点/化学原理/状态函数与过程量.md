# 状态函数与过程量

## 核心概念

- **状态函数**：给定体系状态时有确定值，变化量仅取决于始态和终态（如 $U, H, S, G, A, T, P, V$）
- **过程量**：与过程路径有关（如 $q, w$）
- **状态函数微分**：用 $d$ 表示（如 $dU$）
- **过程量微分**：用 $\delta$ 表示（如 $\delta q, \delta w$）

**一句话本质**：状态函数描述"体系此刻是什么"，过程量描述"体系经历了什么"。同一始态到同一终态，无论走哪条路径，状态函数的变化量完全相同；而沿途吸的热、做的功随路径而变（等温可逆 vs 一步恒外压膨胀吸热做功完全不同）。

## 状态函数的三条判据

| 判据 | 检验方法 | 举例 |
|---|---|---|
| ① 循环积分判据 | 经历任意循环回到原态，变化量必须为零（∮dX = 0） | ∮dU = 0，但 ∮δq ≠ 0 |
| ② 路径无关判据 | 两态间变化量与路径无关 | 理想气体等温膨胀：ΔU 恒为 0 |
| ③ 全微分判据 | dX 是全微分（恰性条件：二阶混合偏导相等） | dU 全微分；δq、δw 非全微分 |

三者等价：满足其一即为状态函数。竞赛题常用"循环后变化量为零/非零"来考你区分（如"理想气体经循环 ΔU = 0 而 w ≠ 0"）。

## 关键公式/方程式

### 广度量与强度量
- 广度量：具有加和性（$V, m, S, H, U, G$）
- 强度量：无加和性（$T, P, \rho, C_{m}$）
- 转换关系：广度量/物质的量 = 强度量

### 状态方程
$$T = f(P, V, n_1, n_2, \ldots)$$

理想气体：$PV = nRT$（三个变量中两个独立）

### 全微分
$$dT = \left(\frac{\partial T}{\partial P}\right)_V dP + \left(\frac{\partial T}{\partial V}\right)_P dV$$

**热力学量分类总表**（记忆锚，考场上秒分类）：

| 物理量 | 状态函数？ | 广延/强度 | 备注 |
|---|---|---|---|
| T、P、ρ、摩尔量 | 是 | 强度 | 无加和性 |
| V、m、n | 是 | 广延 | 直接加和 |
| U、H、S、G、A | 是 | 广延 | 核心热力学势 |
| q（热） | **否** | 广延 | 过程量，δq |
| w（功） | **否** | 广延 | 过程量，δw（体积功 δw = −P外dV） |
| ΔH 的"Δ"本身 | 是（差值） | — | 路径无关是它的全部价值 |
| 反应进度 ξ | 否 | 广延 | 过程量（描述"走了多远"） |

## 规律与趋势

- 状态函数的循环变化为零：$\oint dU = 0$
- 状态相同则状态函数值相同
- 过程量（$q, w$）的循环积分不为零
- 广延量是强度的函数乘以物质的量；判别式：把体系一分为二，值翻倍的是广延量，不变的是强度量
- 全微分与偏导关系是后面 Maxwell 关系式、热力学基本方程的数学地基——"dU = TdS − PdV"能成立正是因为 U(S,V) 是全微分

## 典型应用

- 判断物理量是否为状态函数
- 竞赛中利用状态函数特性简化计算（如循环过程直接写 ΔU = 0、ΔH = 0）
- 理解热力学基本关系式的数学基础
- 弹式量热计测 ΔU 后换算 ΔH（ΔH = ΔU + Δ(PV)）——靠的正是 H = U + PV 是状态函数组合

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 把热 q、功 w 当状态函数 | q、w 是过程量，用 δ 记微分；同样两态间可有无数个 q | 等温可逆膨胀 w 最大、一步恒外压膨胀 w 最小——ΔU 相同而 w 不同 |
| 分不清广延/强度 | 靠"是否随量变"直觉而非"加和性"定义 | T、P 是强度：半杯水与整杯水同温同压；V、S 是广延：半杯水 V 减半 |
| 温度压力记成广延量 | T、P 不具加和性 | 两杯 50°C 水倒一起仍是 50°C 不是 100°C |
| 以为 ΔH = q 恒成立 | ΔH = q 只在恒压且无非体积功时成立；恒容时 q = ΔU | 弹式量热计（恒容）直接测得 ΔU，须加 Δ(PV) 才是 ΔH |
| 忽略"状态相同"前提 | 状态函数值取决于完整状态（T、P、n 等），只报一个变量不构成状态 | "1 mol 理想气体"要加上 T、P 才能定 U；单变量相同 ≠ 状态相同 |
| 循环积分概念混淆 | ∮dX = 0 只对状态函数成立，过程量的循环和 ≠ 0 | 卡诺循环：ΔU = 0 但 w = −q ≠ 0——能量守恒不矛盾 |

## 竞赛考察要点与命题角度

1. **分类题**：给一串物理量（U、H、q、w、S、G、T、P、V、ξ、ΔH）要求分出状态函数/过程量、广延/强度——按上表直接秒答。
2. **循环题**：任意循环后 ΔU = ΔH = 0，但 w 与 q 不一定为零且 w = −q——结合第一定律出题。
3. **路径题**：理想气体从 (P₁,V₁) 到 (P₂,V₂)，比较等温可逆/恒外压/自由膨胀三种路径的 w、q、ΔU——ΔU 全同（理想气体 U 只随 T），w、q 各异。
4. **数学题**：判断某微分形式是否全微分（检查二阶混合偏导）——为 Maxwell 关系埋伏笔。
5. **新概念迁移**：给一个没见过的量（如"热力学概率 Ω 的对数"）判断是否状态函数——落在"能否由状态唯一确定"这一本质。

## 完整算例：同始末态三种路径（理想气体等温）

**题目**：1 mol 理想气体，300 K 下从 1.0 L 等温膨胀到 2.0 L。分别计算：(a) 向真空自由膨胀；(b) 恒外压 0 至中间分两步（先对 0.5 atm 外压、后对 0 外压，此处简化为一次恒外压 P外 = P₂/2 的近似，学生可自行分多步）；(c) 可逆膨胀。比较各路径的 w、q、ΔU。

**解答**（等温理想气体 ΔU = 0，故每路径 q = −w）：

| 路径 | w（对外做功，J） | q（吸热，J） | ΔU |
|---|---|---|---|
| (a) 自由膨胀（真空） | 0 | 0 | 0 |
| (b) 一步恒外压至终压 | P外(V₂−V₁)，取 P外 = P₂ = nRT/V₂ ≈ 1247 | ≈ 1247 | 0 |
| (c) 可逆膨胀 | nRT·ln(V₂/V₁) = 8.314×300×ln2 ≈ 1729 | ≈ 1729 | 0 |

**要点**：ΔU 三者全为 0（状态函数，路径无关）；w、q 各不相同（过程量，路径有关）；可逆膨胀做最大功、吸最大热。此结论正是"可逆过程效率最高"的微观来源，也是熵判据（ΔS_隔离 ≥ 0）导出的起点。

## 全微分判据速用

函数 X(x, y) 的微分 dX = Mdx + Ndy 是全微分的充要条件：∂M/∂y = ∂N/∂x。

- 例：dU = TdS − PdV 中，(∂T/∂V)_S = −(∂P/∂S)_V 即为一条 Maxwell 关系式——热力学势能写成恰当变量组合后，"二阶混合偏导相等"自动产出可测关系。
- 竞赛不要求推导 Maxwell，但"δq 不是全微分、除以 T 后 δq/T 却是（熵的定义）"这一跃迁是理解熵的钥匙：**克劳修斯正是发现 1/T 是 δq 的积分因子，才定义了状态函数 S**。

## 七、🎯 教学视角

### 7.1 学习路径建议
状态函数与过程量应在学习热力学第一定律之前引入，是理解热力学数学框架的基础。先区分状态函数（只与始末态有关）和过程量（与路径有关），再理解广度量与强度量的区别，最后掌握全微分的物理意义。

### 7.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 热q是状态函数 | q是过程量，其值取决于具体路径，用δ表示 |
| 状态函数的变化量与路径无关 | 这正是状态函数的定义特征，循环积分为零 |
| 温度和压力都是广度量 | T和P是强度量，V和S是广度量 |

### 7.3 入门级例题
**题目**：判断以下物理量哪些是状态函数：内能U、热q、体积V、功w。
**解答**：状态函数：U（内能）、V（体积）。过程量：q（热）、w（功）。判断依据：状态函数的循环积分为零。

### 7.4 与现实世界的联系
1. **工程热力学**：发动机循环分析依赖于状态函数的特性
2. **气象学**：大气状态用温度、压力等状态函数描述
3. **化学工程**：反应器设计需要区分状态函数和过程量

> **记忆口诀**：函数看"态"（到点即定值、绕圈归零），过程看"路"（q、w 随路径走）；广延随量增，强度恒不变。

## 关键结论速记

- 状态函数：Δ 只看出没；过程量：q、w 看路线——同一始末态，ΔU 相同、q/w 可千差万别。
- 三判据（循环为零/路径无关/全微分恰性）等价，考场最常用"循环后归零"快速判定。
- 广延量加和、强度量不加和：T、P、ρ、摩尔量为强度，其余常见热力学量多为广延。
- δq 非全微分，δq/T = dS 是全微分——熵的存在性本身是第二定律的数学内容。
- 理想气体 U、H 只随 T：等温过程 ΔU = ΔH = 0（无论路径），这是最常调用的简化。
- 看到 ΔH 与 q 混用先问条件：恒压无非体积功才 ΔH = q；恒容 q = ΔU。
- 相变过程是"恒 T 恒 P 状态函数大变"的典型：ΔvapH ≠ 0 但 T 不变——焓变与温度变化无关，别用 ΔH = CpΔT 套相变。
- 考场快速分：U、H、S、G、T、P、V 是"态"；q、w、ξ、路程是"路"——先分类再动笔。
- 恒温恒容下的自发判据用 Helmholtz 能 A、恒温恒压用 Gibbs 能 G——判据选择也依赖"状态函数 + 约束条件"的配对。
