# 配合物命名

## 一、命名总则

### 1.1 配合物的结构

配合物由**内界**（配位单元）和**外界**（抗衡离子）组成：

```
[Co(NH₃)₆]Cl₃
 ─┬──  ─┬─  ─┬─
  │     │    └── 外界（Cl⁻）
  │     └── 配体（NH₃）
  └── 中心原子（Co³⁺）
```

### 1.2 基本命名顺序

**内界命名顺序：**
1. 配体名称（先无机后有机，先阴离子后中性）
2. "合"字
3. 中心原子名称

**外界命名：**
- 外界阳离子在前，外界阴离子在后
- 阴离子配合物作外界时，命名类似普通盐

### 1.3 氧化态标注

中心原子的氧化态用**罗马数字**标注在名称后括号内：
- [Co(NH₃)₆]Cl₃ → 六氨合钴(III)氯化物
- [Fe(CN)₆]⁴⁻ → 六氰合铁(II)酸根离子

- **NO⁺（亚硝酰阳离子）：** 作为配体时视为中性3电子给体
- **O₂（分子氧）：** 作为配体时称为超氧(peroxo)或过氧(dioxygen)
- **PR₃（膦配体）：** 按有机配体命名

## 三、配体排序规则

### 3.1 IUPAC推荐顺序

配体按以下优先级从高到低排列：

1. **简单无机阴离子**（CN⁻, Cl⁻, F⁻, OH⁻等）
2. **复杂无机阴离子**（SCN⁻, NO₂⁻等）
3. **中性无机分子**（H₂O, NH₃等）
4. **有机阴离子**（acac⁻, C₂O₄²⁻等）
5. **中性有机分子**（en, phen等）

### 3.2 同类配体内部排序

- **无机配体：** 按配体原子的**元素符号字母序**（英文名首字母）
  - Br⁻ (bromo) > Cl⁻ (chloro) > F⁻ (fluoro) > I⁻ (iodo)
- **有机配体：** 按配体名称的字母序

### 3.3 注意事项

- 中文命名中，排序规则与英文略有不同
- 实际考试中，配体顺序错误通常不扣分，但建议养成规范习惯

## 四、数字前缀

### 4.1 简单配体

| 配体数 | 前缀 |
|--------|------|
| 1 | mono-（通常省略） |
| 2 | di- |
| 3 | tri- |
| 4 | tetra- |
| 5 | penta- |
| 6 | hexa- |

### 4.2 复杂配体

当配体名称本身包含数字前缀（如"二"、"三"）或为多齿配体时，使用：

| 配体数 | 前缀 |
|--------|------|
| 2 | bis- |
| 3 | tris- |
| 4 | tetrakis- |
| 5 | pentakis- |

### 4.3 使用规则

**使用bis-/tris-/tetrakis-的条件：**
- 配体名称中已包含"di-"、"tri-"等前缀
- 配体为复杂有机分子（名称较长）
- 配体名称包含数字（如"1,10-菲啰啉"）

**示例：**
- [Co(en)₃]³⁺ → tris(ethylenediamine)cobalt(III)
- [Fe(phen)₃]²⁺ → tris(1,10-phenanthroline)iron(II)

**括号使用：** bis-/tris-/tetrakis-后配体名称需加圆括号。

## 五、中心原子氧化态标注

### 5.1 罗马数字标注

- 氧化态用罗马数字写在中心原子名称后的圆括号内
- 罗马数字后不加任何符号

| 氧化态 | 罗马数字 |
|--------|---------|
| +1 | I |
| +2 | II |
| +3 | III |
| +4 | IV |
| +5 | V |
| +6 | VI |
| +7 | VII |

### 5.2 氧化态计算方法

配合物整体电荷为零时：
$$\text{中心原子氧化态} + \sum(\text{配体电荷}) = \text{配合物总电荷}$$

**示例：**
- [Co(NH₃)₆]Cl₃：Co氧化态 = 0 - 6×0 = +3（外界3个Cl⁻平衡）
- K₃[Fe(CN)₆]：Fe氧化态 = -3 - 6×(-1) = +3

## 六、桥联配合物命名

### 6.1 桥联前缀μ-

当配体同时连接两个或多个中心原子时，该配体称为**桥联配体**，命名时加前缀 **μ-**。

### 6.2 命名规则

- 桥联配体名称前加 μ-
- 若有多个桥联配体，加 μ₂-, μ₃- 等表示桥联的中心原子数
- 桥联配体在名称中放在普通配体之后

### 6.3 示例

- **[Co₂(CO)₈]：** 八羰基二钴
  - 实际结构中有2个桥联CO和6个端基CO
  - 命名：2,4-μ-二羰基六羰基二钴(0)

- **[Al₂(OH)₄(H₂O)₈]⁴⁺：** 八水合-μ-四羟基二铝(III)离子

- **[(NH₃)₅Cr–OH–Cr(NH₃)₅]⁵⁺：** μ-羟基-十氨合二铬(III)离子

## 七、特殊命名

### 7.1 顺反异构

- **顺式（cis-）：** 相同配体在相邻位置（夹角90°）
- **反式（trans-）：** 相同配体在相对位置（夹角180°）

示例：
- 顺-二氯二氨合铂(II)：cis-[PtCl₂(NH₃)₂]
- 反-二氯二氨合铂(II)：trans-[PtCl₂(NH₃)₂]

### 7.2 旋光异构

- **Δ（delta）：** 右旋异构体
- **Λ（lambda）：** 左旋异构体

示例：
- Δ-[Co(en)₃]³⁺：Δ-三(乙二胺)合钴(III)
- Λ-[Co(en)₃]³⁺：Λ-三(乙二胺)合钴(III)

### 7.3 面式/经式

对于MA₃B₃型八面体配合物：

- **面式（fac-）：** 三个相同配体占据八面体的一个三角面
- **经式（mer-）：** 三个相同配体占据八面体的一个子午面

示例：
- 面-三氯三氨合钴(III)：fac-[CoCl₃(NH₃)₃]
- 经-三氯三氨合钴(III)：mer-[CoCl₃(NH₃)₃]

## 八、命名实例

### 练习1（基础）

**[Co(NH₃)₆]Cl₃**
- 配体：6个NH₃ → 六氨
- 中心原子：Co → 钴
- 氧化态：+3 → (III)
- 外界：3个Cl⁻ → 三氯化物
- **完整名称：三氯化六氨合钴(III)**

### 练习2（基础）

**[Cr(H₂O)₄Cl₂]Cl**
- 内界配体：4个H₂O + 2个Cl⁻ → 四水·二氯
- 中心原子：Cr → 铬
- 氧化态：+3 → (III)
- 外界：1个Cl⁻ → 氯化物
- **完整名称：氯化二氯四水合铬(III)**

### 练习3（含桥联）

**[Co₂(CO)₈]**
- 无外界
- 8个CO → 八羰基
- 2个Co → 二钴
- 氧化态：0 → (0)
- **完整名称：八羰基二钴(0)**

### 练习4（含有机配体）

**[Fe(phen)₃]Cl₂**
- 配体：3个phen → 三(1,10-菲啰啉)
- 中心原子：Fe → 铁
- 氧化态：+2 → (II)
- 外界：2个Cl⁻ → 二氯化物
- **完整名称：二氯化三(1,10-菲啰啉)合铁(II)**

### 练习5（阴离子配合物作外界）

**K₄[Fe(CN)₆]**
- 外界阳离子：4个K⁺ → 四钾
- 内界配体：6个CN⁻ → 六氰
- 中心原子：Fe → 铁
- 氧化态：+2 → (II)
- 内界总电荷：-4 → "酸根"后缀
- **完整名称：六氰合铁(II)酸钾**

### 练习6（含桥联）

**[Al₂(OH)₂(H₂O)₈]⁴⁺**
- 普通配体：8个H₂O → 八水
- 桥联配体：2个OH⁻ → μ-二羟基
- 中心原子：2个Al → 二铝
- 氧化态：+3 → (III)
- **完整名称：八水-μ-二羟基二铝(III)离子**

### 练习7（含异构）

**[PtCl₂(NH₃)₂]（顺式）**
- 配体：2个Cl⁻ + 2个NH₃ → 二氯·二氨
- 中心原子：Pt → 铂
- 氧化态：+2 → (II)
- 构型：顺式
- **完整名称：顺-二氯·二氨合铂(II)**

### 练习8（含多齿配体）

**[Co(en)₂Cl₂]⁺**
- 配体：2个en + 2个Cl⁻ → 二(乙二胺)·二氯
- 中心原子：Co → 钴
- 氧化态：+3 → (III)
- 内界总电荷：+1
- **完整名称：二氯·二(乙二胺)合钴(III)离子**

### 练习9（含特殊配体）

**[Fe(CO)₅]**
- 配体：5个CO → 五羰基
- 中心原子：Fe → 铁
- 氧化态：0 → (0)
- **完整名称：五羰基铁(0)**

### 练习10（复杂）

**[Cr(NH₃)₅(NCS)](NO₃)₂**
- 内界配体：5个NH₃ + 1个NCS⁻ → 五氨·异硫氰酸根
- 中心原子：Cr → 铬
- 氧化态：+3 → (III)
- 外界：2个NO₃⁻ → 二硝酸盐
- **完整名称：二硝酸盐·异硫氰酸根·五氨合铬(III)**

## 九、易错点

### 9.1 配体名称拼写

| 错误 | 正确 |
|------|------|
| 氨（amine） | 氨（ammine），注意双m |
| 氰（cyano）写成"氰根" | 氰（cyano） |
| 水（aqua）写成"水合" | 水（aqua） |

### 9.2 数字前缀使用

- 简单配体（H₂O, NH₃, CN⁻）：用 di-, tri-, tetra-
- 复杂配体（en, phen）：用 bis-, tris-, tetrakis-
- **错误示例：** tris(aqua) → 应为 triaqua

### 9.3 桥联配体位置

- 桥联配体在名称中放在普通配体之后
- **错误示例：** μ-二羟基·八水二铝(III) → 应为 八水-μ-二羟基二铝(III)

### 9.4 氧化态计算

- 必须先配平电荷再命名
- CN⁻电荷为-1，不是-2
- en为中性配体

### 9.5 配体排序

- 英文命名中按配体原子字母序
- 中文命名中无机配体在前，有机在后
- **注意：** 不同教材的排序规则可能略有差异

## 十、竞赛拓展

### 10.1 价键理论中的配体命名

在价键理论中，配体名称有时会注明杂化方式：
- [Co(NH₃)₆]³⁺：六氨合钴(III)，d²sp³杂化，内轨型
- [CoF₆]³⁻：六氟合钴(III)，sp³d²杂化，外轨型

### 10.2 命名中的立体化学标记

高级命名中，还需要注明：
- **旋光异构：** Δ-, Λ-
- **几何异构：** cis-, trans-, fac-, mer-
- **绝对构型：** R-, S-（手性配体）

### 10.3 特殊配合物命名

- **簇合物：** 如 [Mo₆Cl₈]⁴⁺ → 八氯合六钼(II)簇离子
- **夹心配合物：** 如 Fe(C₅H₅)₂ → 二茂铁
- **大环配合物：** 如 [Ni(cyclam)]²⁺ → (1,4,8,11-四氮杂环十四烷)合镍(II)

### 10.4 IUPAC 2005规则

最新IUPAC规则中，配体命名有一些更新：
- SCN⁻命名为thiocyanato-κS（强调硫原子配位）
- NO₂⁻命名为nitrito-κN（强调氮原子配位）
- 使用"κ"表示配位原子

## §12 教学视角

### 常见误解

| 误解 | 正确理解 |
|------|----------|
| "配体数直接用数字前缀" | 简单配体用di/tri/tetra，复杂配体用bis/tris/tetrakis |
| "命名只需按配体数排列" | 必须按IUPAC顺序：无机阴离子→复杂阴离子→中性无机→有机阴离子→中性有机 |
| "氧化态可写可不写" | 氧化态是配合物命名的必要组成部分，必须标注 |
| "桥联配体名称在最前面" | 桥联配体在名称中放在普通配体之后，用μ-前缀标记 |

### 典型例题（教学版）

**题目：** 命名以下配合物：
(a) [Co(NH₃)₄Cl₂]Cl
(b) K₃[Fe(CN)₆]

**教学解析：**

**(a) [Co(NH₃)₄Cl₂]Cl**
- 步骤1：识别外界和内界 → 外界Cl⁻，内界[Co(NH₃)₄Cl₂]⁺
- 步骤2：确定配体种类 → NH₃（中性，ammine）和Cl⁻（阴离子，chloro）
- 步骤3：排序 → 阴离子配体Cl⁻在前，中性配体NH₃在后
- 步骤4：确定氧化态 → Co + 4×0 + 2×(-1) = +1 → Co(III)
- 步骤5：组合命名 → 二氯·四氨合钴(III)氯化物

**(b) K₃[Fe(CN)₆]**
- 步骤1：识别外界和内界 → 外界3个K⁺，内界[Fe(CN)₆]³⁻
- 步骤2：确定配体种类 → CN⁻（阴离子，cyano）
- 步骤3：确定氧化态 → Fe + 6×(-1) = -3 → Fe(III)
- 步骤4：组合命名 → 六氰合铁(III)酸钾

**类比：** 配合物命名就像"快递包装"——外界是"外包装箱"（写在最外层），内界是"内包装"（详细描述内容物）。配体是"物品"，中心原子是"收件人"。这个类比帮助学生理解命名的层次结构。

### 教学建议

1. **先建立结构框架：** 用[Co(NH₃)₆]Cl₃作为第一个例子，让学生理解外界/内界/配体/中心原子的概念
2. **配体记忆技巧：** 让学生先记住最常见的10种配体（H₂O, NH₃, CN⁻, Cl⁻, OH⁻, CO, en, phen, acac, NO₂⁻），再逐步扩展
3. **氧化态计算练习：** 用简单的配合物（如[Co(NH₃)₆]³⁺）让学生反复计算氧化态
4. **桥联配合物的特殊处理：** 用[Al₂(OH)₂(H₂O)₈]⁴⁺作为例子，展示μ-前缀的使用
5. **异构体命名：** 用顺/反、面/经作为例子，让学生理解立体化学标记
