# 化学平衡计算

## 核心概念

化学平衡计算是利用平衡常数 $K$ 和初始条件，求算平衡时各物质浓度的过程。常用 ICE 表（Initial-Change-Equilibrium）方法系统处理。

## 关键公式

### 平衡常数表达式

对于反应 $aA + bB \rightleftharpoons cC + dD$：

$$K_c = \frac{[C]^c[D]^d}{[A]^a[B]^b}$$

$$K_p = \frac{P_C^c \cdot P_D^d}{P_A^a \cdot P_B^b}$$

### $K_p$ 与 $K_c$ 的关系

$$K_p = K_c(RT)^{\Delta n}$$

其中 $\Delta n = (c+d) - (a+b)$（气态物质的化学计量数变化）

### ICE 表方法

| | A | B | C | D |
|---|---|---|---|---|
| 初始 | $[A]_0$ | $[B]_0$ | 0 | 0 |
| 变化 | $-ax$ | $-bx$ | $+cx$ | $+dx$ |
| 平衡 | $[A]_0 - ax$ | $[B]_0 - bx$ | $cx$ | $dx$ |

将平衡浓度代入 $K_c$ 表达式求解 $x$。

### 反应商 $Q$ 与平衡常数 $K$ 的比较

| 条件 | 反应方向 |
|------|---------|
| $Q < K$ | 正向进行 |
| $Q = K$ | 平衡状态 |
| $Q > K$ | 逆向进行 |

## 典型应用

1. **平衡浓度计算**：已知初始浓度和 $K$，求平衡浓度
2. **转化率计算**：$\alpha = \frac{\text{已反应量}}{\text{初始量}} \times 100\%$
3. **平衡移动预测**：通过 $Q$ 与 $K$ 的比较判断反应方向
4. **分压计算**：利用 $K_p$ 和分压关系求算

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| $K_c$ 与 $K_p$ 混用不换算 | $K_c$ 用浓度、$K_p$ 用分压，仅 Δn=0 时数值相等 | $K_p = K_c(RT)^{Δn}$；注意 Δn 只数气体，单位用 atm 时 R=0.0821 |
| 把纯固体/纯液体写进平衡式 | 表达式只含气相与溶液相浓度（活度恒 1 不写） | CaCO₃(s) ⇌ CaO(s)+CO₂(g) → K_p = P(CO₂) |
| 近似无条件使用（x 可能不小） | 近似成立须验证：x/[A]₀ < 5% | N₂O₄ 例近似解误差 ~5% 恰在边界——先算后验，超限回退二次方程 |
| 二次方程两根不取舍 | 浓度不能为负，x 必须使所有平衡浓度 > 0 | x = [−b±√Δ]/2a 中取使 [A]₀−ax>0 的根 |
| 温度变化仍用原 K | K 只随温度变（van't Hoff 方程），浓度/压强/催化剂不改 K | 升温 K 变不变看吸放热：ΔH>0 升温 K 增大 |
| 反应商 Q 与 K 判断用错方向 | Q<K 正向（产物生成）、Q>K 逆向 | 代入当前浓度算 Q 再比较；不是看哪个方向"缺产物" |
| 恒容 vs 恒压的 Δn 处理混 | 恒容用浓度；恒压且气体摩尔数变则总压/体积随反应变 | 恒压反应体积变 → 用分压或总压守恒（P_total = ΣP_i），勿当恒容算 |
| 多重平衡叠加忘乘除 K | 反应相加 K 相乘、相减 K 相除、反写取倒数 | A+B⇌C (K₁) 与 C⇌D (K₂) → A+B⇌D 的 K = K₁K₂ |

## 完整算例：N₂O₄ 分解的"近似-验证-精确"三步（升级版）

**题目**：25°C 时 N₂O₄(g) ⇌ 2NO₂(g) 的 $K_c = 4.61×10^{-3}$。初始 [N₂O₄] = 0.100 mol/L（恒容），求平衡组成与分解率 α。

**解答**：

**（1）ICE 表**：设 N₂O₄ 分解 x mol/L → 平衡 [N₂O₄] = 0.100−x、[NO₂] = 2x。

$$K_c = \frac{(2x)^2}{0.100-x} = 4.61\times10^{-3}$$

**（2）近似尝试 + 5% 判据验证**：假设 x ≪ 0.100 → 4x² ≈ 4.61×10⁻⁴ → x ≈ 0.0107。验证：x/[A]₀ = 0.0107/0.100 = **10.7% > 5%**——近似不成立，必须解二次方程。

**（3）精确解**：4x² = 4.61×10⁻³(0.100−x) → 4x² + 4.61×10⁻³x − 4.61×10⁻⁴ = 0

$$x = \frac{-4.61\times10^{-3} + \sqrt{(4.61\times10^{-3})^2 + 4\times4\times4.61\times10^{-4}}}{8} = 0.0102\ \text{mol/L}$$

平衡：[N₂O₄] = 0.0898、[NO₂] = 0.0204 mol/L；**α = 0.0102/0.100 = 10.2%**

**回代验证**：K = (0.0204)²/0.0898 = 4.16×10⁻⁴/0.0898 = 4.63×10⁻³ ≈ K_c ✓

**要点**：① 近似必须验 5% 判据——本例 K=4.6×10⁻³ 不算足够小（教材常说 K<10⁻⁴ 才安全）；② 精确解取正根（另一根为负无物理意义）；③ α 的 10.7%（错近似）与 10.2%（精确）差 5% 相对——填空题要精确值时别用近似。

## 常见考法与套路

1. **转化率-平衡常数联动**：给 α 求 K 或给 K 求 α——"设初始为 1 mol"归一化最省事。
2. **总压/平均摩尔质量法**：恒容给平衡总压或混合气平均摩尔质量（相对密度）→ 反推 n 总 → 求 x。平均摩尔质量 M̄ = m/n 总 = (初始质量)/n 总 是经典桥。
3. **解离度与分压**：分解反应（PCl₅、N₂O₄）给总压 P 与解离度 α → K_p = 4α²P/(1−α²) 型公式——背型不背死，由分压守恒现推。
4. **多重平衡叠加**：反应相加减 K 相乘除（见易错点末行）。
5. **等效平衡/极限法**：把"一边倒"极值算出判断范围（工业投料比优化）。

## 九、🎯 教学视角

### 9.1 学习路径建议
化学平衡计算应在学习平衡常数概念之后系统训练。先掌握ICE表方法的规范使用，再学习Kc与Kp的转换，最后通过近似处理和二次方程求解处理不同难度的平衡计算问题。

### 9.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| Kc和Kp数值相同 | 只有Δn=0时两者才相等，否则需通过Kp=Kc(RT)^Δn转换 |
| 增加反应物浓度会增大K | K仅与温度有关，浓度和压强变化不改变K |
| K很大就说明反应进行完全 | K大只说明平衡时产物占优，但反应速率可能很慢 |

### 9.3 入门级例题
**题目**：25°C时N₂O₄(g) ⇌ 2NO₂(g)的Kc = 4.61×10⁻³。若初始[N₂O₄] = 0.100 mol/L，求平衡浓度。
**解答**：设分解量为x，则Kc = (2x)²/(0.100-x) = 4.61×10⁻³。因K较小，假设x<<0.100，则4x² ≈ 4.61×10⁻⁴，x ≈ 0.0107 mol/L。平衡时[N₂O₄] = 0.0893 mol/L，[NO₂] = 0.0214 mol/L。

### 9.4 与现实世界的联系
1. **化工优化**：通过平衡计算确定最佳反应条件以提高产率
2. **环境监测**：大气中NO₂/N₂O₄平衡影响光化学烟雾的形成
3. **药物代谢**：药物在体内的酸碱平衡影响其吸收和分布
4. **合成氨工业**：N₂+3H₂ 平衡 + 勒夏特列权衡——高压高温催化剂的选择本质是"平衡产率 × 速率 × 成本"三重优化（温度升高 K 减小但速率加快，故取 ~450°C 折中）
5. **血液 CO₂ 缓冲**：CO₂/HCO₃⁻/H₂CO₃ 多平衡体系的 K 值维持血液 pH 7.4——体内"多重平衡"的活教材

## 竞赛考察要点

1. **ICE 表基本功**：任意体系套表——初始/变化/平衡三行，变化行按计量系数成比例。
2. **Kc-Kp 转换**：气体反应 Δn ≠ 0 时必考一次（R 单位与分压单位匹配）。
3. **近似与精确**：5% 判据、二次方程取正根——压轴小问常逼你"先近似后证伪"。
4. **归一化技巧**：转化率题设初始 1 mol；分解题用 1−α 与 2α 型未知量。
5. **平均摩尔质量/总压桥**：平衡气相分析数据的标准推 K 路径。
6. **多重平衡**：K 的乘除/倒数运算 + 目标反应拆分。

## 关键结论速记

- ICE 三行法通吃；变化行严格按计量系数。
- $K_p = K_c(RT)^{Δn}$（Δn 只数气体）；纯固/液不进表达式。
- 近似判据 5%：x/[A]₀ < 5% 可用，否则二次方程（取正根）。
- 温度是 K 的唯一变量；Q vs K 判方向。
- 多重平衡：相加乘、相减除、反写倒数。
- 分解反应总压题：K_p = 4α²P/(1−α²)（PCl₅ 型，自己会推）。
- 数值锚：N₂O₄ 0.1M 分解 α=10.2%（精确）vs 10.7%（近似超限）。
- 复盘自测：① K=4.6e-3 的近似为何不成立？② 平均摩尔质量怎么当桥？③ 反应相加 K 怎么算？——答 5% 判据超限 / M̄=m/n总 反推 n总 / K 相乘。
- 陷阱自查：算出两根先验正负与可行性；K 单位常写"无单位"（标准态浓度比）但计算时必须同单位体系——浓度全用 mol/L 或全用分压，别混。
- 边界情形：K 极大（>10⁴）→ 反应近乎完全，反向近似（设产物少）处理；K 极小 → 正向近似——"接近哪边就从哪边设小量"。
- 单位纪律：气体反应若题目给 K_p 与分压（atm），R=0.0821 L·atm·mol⁻¹·K⁻¹；给 K_c 用浓度——两套别混（R=8.314 只在 J/能量语境）。
- 收尾复核：本页算例 N₂O₄ 精确 α=10.2% 与入门例题近似解 0.0107 之差就是"5% 判据"的活演示——遇到 K 在 10⁻³~10⁻⁴ 量级必须走精确解。
- 收尾自检：能给任意反应列 ICE、能验证近似、能由 α 或总压求 K——本页达标。
