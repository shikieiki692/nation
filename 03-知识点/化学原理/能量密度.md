# 能量密度

## 核心概念

能量密度（Energy Density）是指单位质量燃料完全燃烧所释放的能量，是评价燃料性能的重要指标，单位为 kJ/g 或 MJ/kg。

## 关键公式

$$\text{能量密度} = \frac{|\Delta_r H_m^{\ominus}|}{M}$$

- $\Delta_r H_m^{\ominus}$：标准摩尔燃烧焓（kJ/mol）
- $M$：燃料的摩尔质量（g/mol）

### 计算步骤

1. 写出完全燃烧反应方程式
2. 查表获取各物质的标准生成焓
3. 计算反应的标准焓变：$\Delta_r H^{\ominus} = \sum \Delta_f H^{\ominus}(\text{产物}) - \sum \Delta_f H^{\ominus}(\text{反应物})$
4. 除以燃料的摩尔质量得到能量密度

## 典型应用

1. **燃料选择**：比较不同燃料的单位质量能量输出
2. **航天推进剂**：轻量化设计要求高能量密度燃料
3. **电池技术**：电化学能量密度（Wh/kg）与化学能量密度的对比
4. **生物质能源**：评估生物质燃料的经济性

## 典型数据

| 燃料 | 能量密度 (kJ/g) |
|------|----------------|
| 氢气 H₂ | ~142 |
| 辛烷 C₈H₁₈ | ~47.7 |
| 甲醇 CH₃OH | ~22.7 |
| 甲烷 CH₄ | ~55.5 |

## 易错点

1. **完全燃烧**：必须是完全燃烧反应（C→CO₂，H→H₂O(l)），不完全燃烧的焓变不同
2. **水的状态**：燃烧产物中水为液态时释放更多能量（包含蒸发热）
3. **能量密度 vs 能量体积密度**：前者按质量计算，后者按体积计算，氢气能量密度高但体积密度很低
4. **正负号**：燃烧焓为负值（放热），能量密度取绝对值比较

## 七、🎯 教学视角

### 7.1 学习路径建议
能量密度应在学习燃烧焓和盖斯定律之后引入，是热力学在能源领域的直接应用。先理解能量密度的定义和计算方法，再比较不同燃料的能量密度，最后讨论能量密度与实际应用的关系。

### 7.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 氢气是最好的燃料 | 氢气质量能量密度最高，但体积能量密度很低，储存困难 |
| 能量密度越高的燃料越好 | 还需考虑安全性、成本、环境影响等因素 |
| 燃烧热越大能量密度越高 | 能量密度还与摩尔质量有关，小分子燃料通常能量密度更高 |

### 7.3 入门级例题
**题目**：计算甲烷（CH₄）的能量密度。已知ΔfH⊖(CH₄,g) = -74.8 kJ/mol，ΔfH⊖(CO₂,g) = -393.5 kJ/mol，ΔfH⊖(H₂O,l) = -285.8 kJ/mol。
**解答**：CH₄ + 2O₂ → CO₂ + 2H₂O，ΔrH⊖ = -393.5 + 2×(-285.8) - (-74.8) = -890.3 kJ/mol。能量密度 = 890.3/16 = 55.6 kJ/g。

### 7.4 与现实世界的联系
1. **电动汽车vs燃油车**：锂电池的能量密度（~0.5 MJ/kg）远低于汽油（~46 MJ/kg），这是续航焦虑的根源
2. **航天燃料**：液氢能量密度最高但密度极低，需要超低温储存
3. **生物质能源**：纤维素的能量密度（~17 MJ/kg）较低，限制了生物燃料的大规模应用
