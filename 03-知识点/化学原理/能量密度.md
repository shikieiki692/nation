# 能量密度

## 核心概念

能量密度（Energy Density）是指单位质量燃料完全燃烧所释放的能量，是评价燃料性能的重要指标，单位为 kJ/g 或 MJ/kg。

## 关键公式

$$\text{能量密度} = \frac{|\Delta_r H_m^\circ|}{M}$$

- $\Delta_r H_m^\circ$：标准摩尔燃烧焓（kJ/mol）
- $M$：燃料的摩尔质量（g/mol）

### 计算步骤

1. 写出完全燃烧反应方程式
2. 查表获取各物质的标准生成焓
3. 计算反应的标准焓变：$\Delta_r H^\circ = \sum \Delta_f H^\circ(\text{产物}) - \sum \Delta_f H^\circ(\text{反应物})$
4. 除以燃料的摩尔质量得到能量密度

## 典型应用

1. **燃料选择**：比较不同燃料的单位质量能量输出
2. **航天推进剂**：轻量化设计要求高能量密度燃料
3. **电池技术**：电化学能量密度（Wh/kg）与化学能量密度的对比
4. **生物质能源**：评估生物质燃料的经济性

## 典型数据

| 燃料 | 能量密度 (kJ/g) |
|------|----------------|
| 氢气 H₂ | ~142 |
| 辛烷 C₈H₁₈ | ~47.7 |
| 甲醇 CH₃OH | ~22.7 |
| 甲烷 CH₄ | ~55.5 |

## 易错点

1. **完全燃烧**：必须是完全燃烧反应（C→CO₂，H→H₂O(l)），不完全燃烧的焓变不同
2. **水的状态**：燃烧产物中水为液态时释放更多能量（包含蒸发热）
3. **能量密度 vs 能量体积密度**：前者按质量计算，后者按体积计算，氢气能量密度高但体积密度很低
4. **正负号**：燃烧焓为负值（放热），能量密度取绝对值比较
