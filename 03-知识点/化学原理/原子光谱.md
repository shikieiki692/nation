# 原子光谱

## 一、氢原子光谱实验事实

### 1.1 线状光谱

氢原子在激发态下会发射**线状光谱**（而非连续光谱）。这一事实表明：氢原子的能量是**量子化**的，电子只能存在于特定的能级上。

### 1.2 频率规律

氢原子光谱的谱线频率满足以下经验规律：

$$\nu = c \cdot \tilde{\nu} = c \cdot R_H \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$$

其中：
- $\nu$ 为频率（Hz）
- $\tilde{\nu}$ 为波数（cm⁻¹）
- $R_H$ 为Rydberg常数（氢原子：109677.6 cm⁻¹）
- $n_1 < n_2$ 为正整数

### 1.3 Balmer经验公式

1885年，Balmer发现氢原子可见光区谱线满足：

$$\frac{1}{\lambda} = R_H \left(\frac{1}{2^2} - \frac{1}{n^2}\right) \quad (n = 3, 4, 5, \ldots)$$

可见光区主要谱线：
- $n = 3 \rightarrow 2$：Hα（656.3 nm，红色）
- $n = 4 \rightarrow 2$：Hβ（486.1 nm，青色）
- $n = 5 \rightarrow 2$：Hγ（434.0 nm，蓝色）
- $n = 6 \rightarrow 2$：Hδ（410.2 nm，紫色）

## 二、Rydberg公式

### 2.1 一般形式

Rydberg公式统一描述氢原子所有光谱系：

$$\frac{1}{\lambda} = R_H \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$$

其中 $R_H = 1.09678 \times 10^7 \text{ m}^{-1}$（氢原子）

### 2.2 主要光谱系

| 光谱系 | $n_1$ | $n_2$ | 波长范围 | 发现年份 |
|--------|-------|-------|----------|----------|
| Lyman系 | 1 | 2, 3, 4, ... | 91.2–121.6 nm（紫外） | 1906 |
| Balmer系 | 2 | 3, 4, 5, ... | 364.6–656.3 nm（可见光） | 1885 |
| Paschen系 | 3 | 4, 5, 6, ... | 820.4–1875 nm（近红外） | 1908 |
| Brackett系 | 4 | 5, 6, 7, ... | 1458–4051 nm（红外） | 1922 |
| Pfund系 | 5 | 6, 7, 8, ... | 2279–7460 nm（远红外） | 1924 |

### 2.3 谱线间距规律

- 随着 $n_2$ 增大，相邻谱线间距**减小**（趋于收敛极限）
- 收敛极限对应 $n_2 = \infty$，即电离能

### 2.4 精细结构

高分辨率下，每条谱线实际上是由多条非常接近的谱线组成的**精细结构**。这是由于：
- 电子自旋-轨道耦合
- 相对论效应

## 三、Bohr理论解释

### 3.1 三条基本假设

1. **定态假设（Stationary States）：** 电子在原子核周围只能处于一系列不连续的稳定轨道上，处于定态的电子不辐射能量。

2. **频率条件（Frequency Condition）：** 电子从一个定态跃迁到另一个定态时，辐射或吸收光子的能量等于两定态的能量差：

$$h\nu = |E_{n_2} - E_{n_1}|$$

3. **角动量量子化（Angular Momentum Quantization）：** 电子轨道角动量只能取$h/2\pi$的整数倍：

$$L = mvr = n\hbar \quad (n = 1, 2, 3, \ldots)$$

### 3.2 能级公式

结合库仑力和角动量量子化条件，Bohr推导出氢原子能级：

$$E_n = -\frac{13.6 \text{ eV}}{n^2} = -\frac{R_H hc}{n^2}$$

其中：
- $n = 1, 2, 3, \ldots$（主量子数）
- 基态能量 $E_1 = -13.6$ eV
- 电离能 $IE = E_\infty - E_1 = 0 - (-13.6) = 13.6$ eV

### 3.3 光谱频率的解释

从 $n_2$ 跃迁到 $n_1$ 时发射光子的频率：

$$\nu = \frac{E_{n_2} - E_{n_1}}{h} = \frac{13.6 \text{ eV}}{h} \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$$

这与Rydberg公式完全一致，且给出Rydberg常数的理论值：

$$R_H = \frac{me^4}{8\varepsilon_0^2 h^3 c} = 1.097 \times 10^7 \text{ m}^{-1}$$

与实验值高度吻合（误差约0.05%）。

## 四、Bohr理论的成功与局限

### 4.1 成功之处

1. **定量解释了氢原子光谱：** 成功推导出Rydberg公式，给出Rydberg常数的理论值
2. **解释了电离能：** 给出13.6 eV的理论值，与实验一致
3. **提出了量子化概念：** 开创了原子物理学的新时代
4. **解释了类氢离子光谱：** He⁺, Li²⁺等类氢离子的光谱也可以用类似公式描述

### 4.2 局限性

| 局限 | 说明 |
|------|------|
| 无法解释精细结构 | 高分辨率下谱线有精细分裂 |
| 无法解释Zeeman效应 | 外磁场下谱线分裂 |
| 无法解释多电子原子 | 无法处理电子间排斥 |
| 违反经典电动力学 | 加速电荷应辐射能量，但定态电子不辐射 |
| 人为引入量子化条件 | 角动量量子化是假设，缺乏理论基础 |
| 无法解释谱线强度 | 不能预测谱线的相对强度 |

## 五、量子力学模型的修正

### 5.1 波函数与轨道

量子力学用**波函数** $\psi(r, \theta, \phi)$ 描述电子状态：

- 波函数本身无物理意义
- $|\psi|^2$ 代表**概率密度**（电子在某点出现的概率/体积）
- 轨道 = 波函数 = 电子的量子力学状态

### 5.2 概念区别

| 概念 | 含义 |
|------|------|
| 轨道（orbital） | 电子的量子力学状态，用波函数描述 |
| 轨迹（orbit） | 经典力学中物体运动的路径（Bohr假设） |
| 原子轨道 | 波函数的空间分布图像 |

### 5.3 径向分布函数

径向分布函数 $D(r) = 4\pi r^2 |\psi|^2$ 表示在半径 $r$ 处**单位厚度球壳内**找到电子的概率。

**关键结论：**
- 氢原子基态（1s）最可几半径 = $a_0 = 52.9$ pm（Bohr半径）
- 概率密度最大处（$|\psi|^2$最大）在核处
- 径向分布函数最大处（$D(r)$最大）在 $r = a_0$

### 5.4 量子数总结

| 量子数 | 符号 | 取值范围 | 物理意义 |
|--------|------|----------|----------|
| 主量子数 | $n$ | 1, 2, 3, ... | 能级大小、电子层 |
| 角量子数 | $l$ | 0, 1, 2, ..., n-1 | 轨道形状 |
| 磁量子数 | $m_l$ | -l, ..., 0, ..., +l | 轨道空间取向 |
| 自旋量子数 | $m_s$ | +1/2, -1/2 | 电子自旋方向 |

## 六、多电子原子光谱简介

### 6.1 能级分裂

多电子原子中，由于：
- **屏蔽效应（Screening Effect）：** 内层电子屏蔽了核电荷
- **钻穿效应（Penetration Effect）：** 外层电子可钻入内层

导致能级不仅与 $n$ 有关，还与 $l$ 有关：

$$E_{n,l} = E_n + \Delta E_{n,l}$$

### 6.2 能级顺序

多电子原子能级顺序（构造原理）：

$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d < 7p$$

### 6.3 选律（Selection Rules）

并非所有跃迁都是允许的。量子力学给出**选律**：

- $\Delta l = \pm 1$（角量子数变化±1）
- $\Delta m_l = 0, \pm 1$（磁量子数变化0或±1）
- $\Delta m_s = 0$（自旋不变）

### 6.4 谱线强度

谱线强度与：
- **跃迁概率**（Einstein系数）成正比
- **上能级布居数**（Boltzmann分布）成正比
- **频率的三次方**成正比

## 七、例题与应用

### 例题1：Rydberg公式计算

**题目：** 计算氢原子Lyman系第一条谱线的波长。

**解答：**
Lyman系：$n_1 = 1$，第一条谱线对应 $n_2 = 2$

$$\frac{1}{\lambda} = R_H \left(\frac{1}{1^2} - \frac{1}{2^2}\right) = 1.097 \times 10^7 \times \frac{3}{4} = 8.228 \times 10^6 \text{ m}^{-1}$$

$$\lambda = \frac{1}{8.228 \times 10^6} = 1.215 \times 10^{-7} \text{ m} = 121.5 \text{ nm}$$

（紫外区，Lyman-α线）

### 例题2：电离能计算

**题目：** 计算氢原子的电离能（单位：kJ/mol）。

**解答：**
$$IE = E_\infty - E_1 = 0 - (-13.6 \text{ eV}) = 13.6 \text{ eV}$$

换算为kJ/mol：
$$IE = 13.6 \times 96.485 = 1312 \text{ kJ/mol}$$

### 例题3：类氢离子

**题目：** 计算He⁺的电离能。

**解答：**
类氢离子的能级公式：
$$E_n = -\frac{Z^2 \times 13.6 \text{ eV}}{n^2}$$

He⁺的 $Z = 2$：
$$IE = \frac{2^2 \times 13.6}{1^2} = 54.4 \text{ eV}$$

## 八、易错点

1. **谱线是"线"而非"带"：** 氢原子光谱是线状光谱，表明能量是量子化的。分子光谱才是带状光谱。

2. **Lyman系在紫外区：** 不是可见光！可见光区只有Balmer系。

3. **Bohr半径是"最可几半径"：** $a_0 = 52.9$ pm是径向分布函数的最大值位置，不是电子轨道的"半径"。

4. **概率密度 vs 径向分布函数：** 核处概率密度最大，但径向分布函数在核处为零（因为球壳体积为零）。

5. **选律的适用条件：** 选律 $\Delta l = \pm 1$ 只对电偶极跃迁成立。磁偶极跃迁、电四极跃迁等违反此选律。

## 九、竞赛拓展

### 9.1 同位素效应

不同氢同位素（H, D, T）的Rydberg常数不同：

$$R_M = \frac{R_\infty}{1 + m_e/M}$$

因此D的谱线比H的谱线频率略高（约0.02%）。

### 9.2 Lamb位移

2p₁/₂和2s₁/₂能级在量子电动力学（QED）修正下并非简并，存在约1057 MHz的能级差。这是验证QED理论的重要实验。

### 9.3 超精细结构

由于电子自旋与核自旋的相互作用，氢原子基态分裂为两个超精细能级，对应21 cm谱线（1420 MHz）。这是射电天文学的重要谱线。

### 9.4 多电子原子光谱项

对于多电子原子，需要用**光谱项** $^{2S+1}L_J$ 描述原子状态。这涉及到：
- 总自旋量子数 $S$
- 总轨道角动量量子数 $L$
- 总角动量量子数 $J$

## §12 教学视角

### 常见误解

| 误解 | 正确理解 |
|------|----------|
| "Bohr模型的电子在圆形轨道上运动" | Bohr模型是半经典模型，电子不是真的在"轨道"上运动。量子力学用波函数描述电子状态 |
| "谱线是电子在轨道间'跳跃'产生的" | 跃迁是量子力学过程，电子不经过中间状态。经典类比（跳跃）仅帮助理解 |
| "Lyman系在可见光区" | Lyman系在紫外区，可见光区只有Balmer系 |
| "Bohr半径是原子的大小" | Bohr半径是最可几半径，电子在核外有概率分布，没有明确的"边界" |

### 典型例题（教学版）

**题目：** 氢原子从 $n = 4$ 跃迁到 $n = 2$ 和从 $n = 2$ 跃迁到 $n = 1$，哪条谱线的频率更高？

**教学解析：**
- 跃迁1：$n = 4 \rightarrow 2$
$$\Delta E_1 = 13.6 \times \left(\frac{1}{4} - \frac{1}{16}\right) = 13.6 \times \frac{3}{16} = 2.55 \text{ eV}$$

- 跃迁2：$n = 2 \rightarrow 1$
$$\Delta E_2 = 13.6 \times \left(1 - \frac{1}{4}\right) = 13.6 \times \frac{3}{4} = 10.2 \text{ eV}$$

因为 $\Delta E_2 > \Delta E_1$，所以 $n = 2 \rightarrow 1$ 的频率更高。

**类比：** 原子光谱就像"原子指纹"——每种元素有自己独特的光谱线。这就像人的指纹一样，可以用来识别元素。天文学家就是通过分析恒星的光谱来确定其化学组成的。

### 教学建议

1. **从实验事实出发：** 先展示氢原子光谱的实验照片，让学生观察线状光谱的特点
2. **强调Bohr理论的成功：** 让学生理解理论与实验的定量吻合
3. **用能级图解释跃迁：** 画出能级图，用箭头表示跃迁，帮助学生直观理解
4. **区分"轨道"和"轨道"：** 强调orbital（量子力学）与orbit（Bohr模型）的区别
5. **引入选律概念：** 解释为什么不是所有跃迁都能发生，为后续学习做铺垫
