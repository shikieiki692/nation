# 电解池

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-化学原理]]
- 对应考纲条目：[[氧化还原电化学]]

## 一、定义

**电解池（Electrolytic Cell）**：利用外加电流驱动**非自发**氧化还原反应（ΔG > 0）的装置，实现电能 → 化学能。与自发产生电流的 [[原电池]] 能量转化方向正好相反。

## 二、考纲对应

- 对应考纲条目：[[氧化还原电化学]]（电解原理、电解产物判断、法拉第定律）
- 所属模块：化学原理—电化学
- 本知识点在考纲中的作用：**电解产物判断与电量计算是初赛计算题核心类型**；超电势概念是区分考生深度的重要考点。

## 三、核心原理

### 3.1 电解池的组成

- 外加直流电源、两个电极、电解质溶液（或熔融电解质）
- **阳极（anode）**：连电源正极，发生**氧化**反应
- **阴极（cathode）**：连电源负极，发生**还原**反应
- 电子流向：电源负极 → 阴极，阳极 → 电源正极（外电路）；离子在溶液中定向迁移导电

### 3.2 阴阳极与电极反应判断

- 口诀 **"阳氧阴还"**：阳极氧化、阴极还原，适用于所有电化学体系
- **惰性电极**（Pt、石墨）：电极本身不参与反应，只有溶液中离子放电
- **活性电极**（Cu、Zn 等）：阳极自身可能溶解（M → Mⁿ⁺ + ne⁻），如铜的精炼

### 3.3 电解产物判断规律

**阴极（还原）——阳离子 + H₂O 竞争**，比较还原电极电势（结合超电势取实际较高者）：
- Ag、Cu 等不活泼金属离子优先放电
- H⁺ 处于中等电位，与 Zn²⁺、Fe²⁺、Cu²⁺ 竞争（需考虑超电势）
- 活泼金属离子（Na⁺、K⁺、Ca²⁺、Mg²⁺、Al³⁺）几乎不放电，水被还原析 H₂

**阳极（氧化）——阴离子 + H₂O 竞争 + 电极材料**：
- 惰性电极放电次序：S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根（SO₄²⁻、NO₃⁻ 等不放电）
- 活性电极：电极自身溶解优先于阴离子放电

**超电势修正**：H₂、O₂、Cl₂ 在多数电极上有显著超电势，可能**改变实际析出顺序**。例：电解 ZnSO₄ 溶液，H₂ 在 Zn 电极上超电势大，实际析出 Zn 而非 H₂。

### 3.4 法拉第定律与法拉第效率

**法拉第第一定律**：电极上析出/溶解物质的质量与通过电量成正比
$$ m = \frac{M}{zeF}Q = \frac{M}{zeF}It $$
其中 Q = It，z 为电极反应转移电子数，F = 96485 C·mol⁻¹。

**法拉第效率（电流效率）**：实际产量 / 理论产量 × 100%，反映电解选择性（见 [[法拉第效率]]）。

### 3.5 分解电压与超电势

- **理论分解电压**：由热力学（ΔGθ = −nFEθ）算得的最低电解电压
- **实际分解电压**：电解实际进行所需电压，因极化/超电势高于理论值
- **超电势**：η = E实际 − E理论；气体析出（H₂、O₂、Cl₂）超电势显著

## 四、关键结论

1. 电解池：电能 → 化学能，驱动非自发反应；原电池相反
2. 阳极氧化、阴极还原（"阳氧阴还"）；电源正极接阳极、负极接阴极
3. 产物判断：阴极比还原电势、阳极比氧化电势，均需超电势修正
4. 惰性 vs 活性电极：活性阳极自身溶解（电解精炼原理）
5. 法拉第定律 m = (M/zeF)·It 连接电量与产量；实际产量受电流效率修正

## 五、常见分类或情形

| 类型 | 说明 | 实例 |
|:---|:---|:---|
| 熔融电解 | 无水，直接电解熔融盐 | 电解熔融 NaCl 制 Na、Al₂O₃ 制 Al |
| 溶液电解 | 水溶液中 H₂O 参与竞争 | 电解饱和食盐水制 Cl₂（氯碱工业） |
| 惰性电极 | Pt/石墨，离子放电 | 电解 CuSO₄ 溶液 |
| 活性阳极 | 阳极自身溶解 | 电解精炼铜（粗铜作阳极） |

## 六、适用条件与限制

1. 法拉第定律适用于恒流电解；电流效率 < 100% 时存在副反应
2. 产物判断须考虑超电势、浓度、酸度（[[Nernst方程]] 修正电极电势）
3. 活性阳极不适用"阴离子放电"规则

## 七、常见比较与易混点

| 易混表述 | 正确认识 |
|:---|:---|
| "原电池正极 = 电解池正极" | 原电池用正/负极，电解池用阴/阳极；两者发生还原的电极均可类比，但命名不同 |
| "电解池也有正负极" | 电解池用阴/阳极；连电源正极的是阳极 |
| "按标准电势直接判断产物" | H₂/O₂ 超电势大，可能反转析出顺序 |
| "阳极发生还原" | 阳极恒为氧化（"阳氧阴还"），无论原电池还是电解池 |

## 十、例题

### 例题 1（惰性电极电解 CuSO₄）
**题目**：用惰性电极电解 CuSO₄ 溶液，写出阴阳极反应与总反应。
**解答**：
- 阴极：Cu²⁺ + 2e⁻ → Cu（Eθ = +0.34 V > 水还原）
- 阳极：2H₂O → O₂ + 4H⁺ + 4e⁻（SO₄²⁻ 不放电，水氧化）
- 总反应：2Cu²⁺ + 2H₂O → 2Cu + O₂↑ + 4H⁺

### 例题 2（氯碱工业）
**题目**：电解饱和 NaCl 溶液，判断阴阳极产物。
**解答**：
- 阴极：Na⁺ 还原极难（Eθ = −2.71 V），水优先还原 → H₂↑ + OH⁻
- 阳极：Cl⁻ 优先于 OH⁻（Cl₂ 在石墨上超电势低于 O₂）→ Cl₂↑
- 总反应：2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑

### 例题 3（法拉第定律计算）
**题目**：2.00 A 电流电解 CuSO₄ 溶液 30 min，电流效率 100%，求阴极析铜质量。
**解答**：m = (M/zeF)·It = (63.55 / 2×96485) × 2.00 × 1800 ≈ **1.186 g**。

## 十一、易错点

1. 电解池称"正负极" → 应为阴阳极（电源正极接阳极）
2. 直接按标准电势判断产物，忽略超电势（H₂ 在 Zn 上高 η 使 Zn 先析出）
3. 把活性阳极当惰性处理（铜精炼中粗铜溶解）
4. 法拉第定律漏除转移电子数 z

### 12.3 入门级例题
**题目**：电解 NaCl 水溶液，阴极产物是什么？
**预期解答路径**：判断阳离子放电顺序 → Na⁺ vs H⁺ → 水的还原电位更高 → 析 H₂。
**老师引导**：卡壳时问"Na 能从水溶液里析出吗？金属钠遇水会怎样？"

### 12.4 与现实/直觉的连接
- 电解水制氢、氯碱工业、电解精炼铜、电镀——电解池是工业电化学核心
- 类比：电解池像"电水泵"——原电池靠反应自发"放水"，电解池靠外加电"泵水上山"（强制非自发反应）
