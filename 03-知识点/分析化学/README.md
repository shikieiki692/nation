> 本目录涵盖中国化学奥林匹克**基础要求**中的分析化学模块，共 **38 个知识点文件**。

## 知识模块分布

| 模块 | 核心KP |
|------|--------|
| **容量分析** | 酸碱滴定、氧化还原滴定、络合滴定、沉淀滴定、碘量法、EDTA滴定、滴定曲线、指示剂 |
| **仪器分析** | Lambert-Beer定律、分光光度法、NMR谱学、热重分析、元素分析 |
| **数据处理** | 误差、偏差、精密度、准确度、Q检验法 |
| **平衡理论** | 分布分数、副反应系数、条件稳定常数、林邦公式 |
| **分离** | 萃取、重量分析 |
