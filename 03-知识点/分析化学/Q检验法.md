# Q检验法

## 一、定义

Q 检验法（Q-test，Dixon 检验）是**判断一组平行测量数据中"可疑值"（离群值/异常值）是否应舍弃**的统计学方法。步骤：把数据按大小排列，计算可疑值与最近邻值之差的绝对值除以极差得统计量 **Q = |x_可疑 − x_邻| / (x_max − x_min)**，与给定置信度（常用 90%/95%）下的**临界值 Q_crit**（查表，随测定次数 n 变化）比较：**Q ≥ Q_crit → 该值应舍弃；Q < Q_crit → 保留**（差异属随机波动）。意义：测量中出现"明显偏离"的数据时，不能凭感觉删数据，必须用统计检验给出依据——Q 检验是 n 较小（3–10 次）时最简便的异常值判别法。竞赛（误差与数据处理章节）考计算步骤、查表比较与"为何要检验"的概念。

## 二、考纲对应

本页属分析化学-误差与数据处理考点，对应"异常值的统计检验（Q 检验法）"：能按步骤计算 Q 值并与临界值比较作出舍弃/保留判断；理解 Q 检验的适用条件（正态分布、小样本 n ≤ 10、一次检验一个可疑值）；了解 Grubbs（Grubbs）检验作为更大样本/更严格方法的对照。初赛决赛以计算判断与概念题出现。

## 三、核心原理

### 3.1 为什么需要"异常值检验"

- 平行测定中个别数据明显偏离（可能来自操作失误、仪器漂移、样品不均），若保留会扭曲平均值与精密度；若随意删除又引入主观性。
- 统计检验提供客观判据：假设数据来自同一正态总体，若某值"离谱"到在给定置信度下几乎不可能出现（超出随机波动），才可舍弃。
- 原则：**舍弃要有统计依据**；可疑值一般只对"最偏离的一个"检验一次，不能反复剔除直到"满意"。

### 3.2 Q 检验的步骤（考试标准流程）

1. 数据升序排列：x₁ ≤ x₂ ≤ … ≤ x_n。
2. 确定可疑值（通常是最小或最大值）。
3. 计算极差 R = x_max − x_min（用全部数据，含可疑值）。
4. 计算 Q = |x_可疑 − x_最近邻| / R。
5. 查 Q 临界值表（表列：n 与置信度 90%/95%/99% 对应的 Q_crit）。
6. 比较：Q ≥ Q_crit → 舍弃可疑值（重新算平均/精密度）；Q < Q_crit → 保留。

注意：若最小与最大都可疑，先检验偏离更远的那个；舍弃后一般不再对剩余数据重复 Q 检验（避免多重检验膨胀错误）。

### 3.3 Q 临界值表的量级感觉（95%）

| n | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|--:|--:|--:|--:|--:|--:|--:|
| Q(95%) | 0.97 | 0.83 | 0.71 | 0.63 | 0.57 | 0.52 | 0.47 | 0.44 |

- n 越小 Q_crit 越大（数据少时"离群"更常见，更难舍弃）；n=3 几乎任何最大值都通不过（Q_crit≈0.97）——提醒：3 次测定不足以用 Q 检验剔除数据。
- 90% 的 Q_crit 略小于 95%；99% 的更大（更保守，更难舍弃）。

### 3.4 Grubbs 检验（对照与替代）

- Grubbs 统计量：G = |x_可疑 − x̄|/s（用平均值与标准偏差，而非极差）——利用了全部数据信息，比 Q 更灵敏；适用于稍大样本与更严格场合。
- 判据同型：G ≥ G_crit(α, n) 舍弃。考题若给 s 与 x̄ 常用 Grubbs；给排序数据常用 Q。
- 两种检验结论一般一致；样本小（n ≤ 10）且只查一个值时 Q 简便常用（教材主线）。

### 3.5 检验之后：报告与再统计

- 舍弃后：用剩余 n−1 个数据重算平均值 x̄、标准偏差 s、置信区间——**注意自由度变化**（t 分布查表用 n−1）。
- 保留时：把可疑值当作正常随机波动纳入统计（不剔除）。
- 报告习惯：注明检验方法、置信度与舍弃依据（"经 Q 检验（95%）x 值被舍弃，剩余数据平均值…"）。

## 四、关键结论

- Q = |x_可疑 − x_邻| / 极差；与 Q_crit(n, 置信度) 比较判舍弃/保留。
- 适用：小样本（n ≈ 3–10）、正态分布、一次检验一个可疑值。
- Q_crit 随 n 减小而增大——数据越少越难合法舍弃。
- Grubbs（用 x̄、s）是大样本/更严格替代法。
- 检验后重算平均值与精密度（注意自由度变化）。

## 五、常见分类或情形

- **按方法**：Q 检验（Dixon，极差型）、Grubbs 检验（标准偏差型）、(Chauvenet/拉依达 3σ 等：3σ 准则用于大样本)。
- **按数据规模**：n ≤ 10 常用 Q/Grubbs；大样本用 3σ 或 Grubbs。
- **按可疑值位置**：最小值、最大值（或两端同时可疑时先查更偏离者）。
- **按置信度**：90%（较宽松）、95%（常用）、99%（严格）——题目指定则按其查表。

## 六、适用条件与限制

- 小样本且近似正态：n < 3 无法检验；明显偏态数据慎用 Q。
- 一次只剔除一个可疑值：剔除后不得再对剩余数据连续 Q 检验（多重检验失真）——若仍有可疑，换 Grubbs 或增加测定。
- Q 用极差，对两端数据敏感但未利用中间数据分布信息（n 大时不如 Grubbs）。
- 临界值表随置信度与 n 变化：查错表/用错置信度即判错。
- 异常值若来自系统误差（方法本身问题），检验剔除治标不治本——应找原因。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| Q 与 Grubbs 用谁 | Q 用极差（排序数据即算）；Grubbs 用 x̄、s（给平均值与标准偏差时用）——题目给什么统计量就选对应方法 |
| Q 值大 = 该保留？ | Q 值大表示可疑值偏离越远，**越应舍弃**（Q ≥ Q_crit 舍弃）——方向别记反 |
| 置信度越高越易舍弃？ | 置信度越高（99%）Q_crit 越大、**越难舍弃**（更保守）——95% 比 99% 更容易剔除 |
| 反复剔除直到"顺眼" | 一次检验只剔一个；反复 Q 检验会放大错误（把正常数据也剔掉） |
| 3 次测定就能剔数据 | n=3 时 Q_crit≈0.97（95%），几乎不可能舍弃——样本太少时检验无意义 |

## 九、典型题型

- **计算判断**：给 n 次数据，用 Q 检验（95%）判断最大值/最小值是否舍弃（题-误差-02 同型）。
- **概念辨析**：Q 检验适用条件、为什么不能反复剔、置信度与 Q_crit 关系。
- **方法选择**：给 x̄、s 用 Grubbs；给排序数据用 Q。
- **检验后统计**：舍弃后重算平均值与精密度（n−1）。

## 十、例题

**例题 1**：某实验测得 5 次数据：20.02、20.04、20.06、20.08、20.50。用 Q 检验法（95%）判断 20.50 是否应舍弃。

**解答**：排序不变，可疑值 20.50，最近邻 20.08；极差 R = 20.50 − 20.02 = 0.48；Q = |20.50 − 20.08|/0.48 = 0.42/0.48 = **0.875**。查表 n=5、95%：Q_crit = 0.71。0.875 > 0.71 → **20.50 应舍弃**（在 95% 置信度下该值超出随机波动范围）。舍弃后余 4 个数据重算：x̄ = (20.02+20.04+20.06+20.08)/4 = 20.05。

**例题 2**：3 次平行测定得 0.1012、0.1014、0.1035。能否用 Q 检验（95%）舍弃 0.1035？

**解答**：n=3，可疑 0.1035，最近邻 0.1014；R = 0.1035−0.1012 = 0.0023；Q = (0.1035−0.1014)/0.0023 = 0.0021/0.0023 ≈ 0.913。查表 n=3、95%：Q_crit = 0.97。0.913 < 0.97 → **不能舍弃**（保留）。启示：只有 3 次数据时 Q_crit 接近 1，几乎任何可疑值都"合法保留"——样本太少无法统计剔除，应补做平行测定。

**例题 3**：对比 Q 检验与 Grubbs 检验在"数据 2.5、2.7、2.8、3.1"（x̄ = 2.775、s ≈ 0.25）判断最大值 3.1 时的差别。

**解答**：Q 法：R = 3.1−2.5 = 0.6，Q = (3.1−2.8)/0.6 ≈ 0.50；n=4、95% Q_crit = 0.83 → 0.50 < 0.83 保留。Grubbs：G = (3.1−2.775)/0.25 ≈ 1.30；n=4、95% G_crit ≈ 1.481 → 1.30 < 1.48 保留。两种方法结论一致（保留）；注意 Grubbs 利用全部数据、对中间分布更敏感，n 增大后比 Q 更有分辨力。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| Q 值大小方向记反 | Q 越大偏离越远 → **越应舍弃**；"Q 值大所以可靠"是错的 | 判别：判据是 Q ≥ Q_crit 舍弃——大 Q 进舍弃区 |
| 极差/邻近值取错 | 极差用全数据最大−最小（含可疑值）；邻值是与可疑值**最近**的那个数据 | 反例：20.50 的邻值是 20.08（不是 20.02）——排序后取紧邻 |
| 置信度与 Q_crit 关系搞反 | 95% < 99% 的 Q_crit（99% 更难舍弃）；用 90% 表判 95% 题即错 | 自检：先看题给置信度再选表列；保守度 90 < 95 < 99 |
| 反复剔除数据 | 一次检验只能考虑剔除一个最可疑值；剔除后不得再对剩余连续 Q 检验 | 判别：若剔除后仍觉异常，应增测或换 Grubbs，而非循环 Q |
| n 太小强行检验 | n=3 时 Q_crit≈0.97，几乎不可能舍弃——样本不足时检验无统计意义 | 反例：3 次数据 0.913<0.97 保留——"数据少时更该多测，不是更该删" |

## 十二、🎯 教学视角

### 12.1 学习路径建议
建议先理解异常值（可疑值）的来源与"舍弃必须有统计依据"的原则，再学 Q 检验的完整计算步骤（排序→极差→Q→查表→判断），用 2–3 个例题熟练"舍弃/保留"判定，最后对照 Grubbs 检验理解方法选择与局限。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| Q 值越大越可靠 | Q 值越大说明偏离越远、越应舍弃；Q ≥ Q_crit 才舍弃 |
| 任何异常值都能用 Q 检验舍弃 | Q 检验适用于正态分布小样本（n≤10），且一次只能考虑剔除一个 |
| Q 检验可以反复使用 | 剔除一个后不应再对剩余数据连续 Q 检验（可换 Grubbs 或增测） |
| 置信度越高越易删 | 置信度越高 Q_crit 越大、越保守（越难舍弃） |

### 12.3 入门级例题
**题目**：5 次数据 20.02、20.04、20.06、20.08、20.50，用 Q 检验（95%）判断 20.50 是否舍弃。

**解答**：Q = |20.50−20.08|/(20.50−20.02) = 0.42/0.48 = 0.875；n=5、95% Q_crit = 0.71；0.875 > 0.71 → 舍弃。

### 12.4 与现实世界的联系
- **质量控制**：工业质检用 Q/Grubbs 判断产品数据异常，避免坏数据进入统计。
- **科学实验**：处理平行实验数据、提高结果可靠性（发表数据需注明异常值处理）。
- **临床检验**：医学检测筛除异常值防误诊，同时警惕真阳性被误删（统计与医学判断结合）。
