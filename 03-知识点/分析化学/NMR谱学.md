# NMR 谱学（Nuclear Magnetic Resonance Spectroscopy）

## 一、定义

核磁共振（NMR）是化学竞赛决赛中的**核心表征手段**，广泛用于确定分子结构、研究动态过程和测定物理化学参数。NMR 基于具有核自旋的原子核在外磁场中的能级分裂和射频辐射诱导的共振跃迁。

## 二、考纲对应

| 考纲条目 | 具体要求 |
|---------|---------|
| 波谱分析 | 掌握NMR的基本原理（核自旋、共振条件） |
| 结构表征 | 能用化学位移、偶合常数、积分推断有机物结构 |
| 动态过程 | 理解变温NMR研究化学交换和构象翻转 |

## 三、核心原理

### 3.1 核自旋与磁矩
- **核自旋量子数 I**：奇质量数或奇质子数的核具有半整数自旋（I = 1/2, 3/2...）
- **磁矩**：μ = γ · I · ħ，γ 为磁旋比
- **I = 1/2 核**：¹H、¹³C、¹⁹F、³¹P 等，NMR 信号尖锐，最常用

### 3.2 共振条件
$$
\Delta E = h\nu = \gamma \hbar B_0 \quad \Rightarrow \quad \nu = \frac{\gamma B_0}{2\pi}
$$
- B₀：外磁场强度
- 磁场越强，分辨率越高（化学位移差值以 Hz 计增大）

## 四、关键结论

### 化学位移（δ）

**定义**：
$$
\delta = \frac{\nu_{\text{sample}} - \nu_{\text{TMS}}}{\nu_{\text{spectrometer}}} \times 10^6 \quad (\text{ppm})
$$

**影响化学位移的因素**：

| 因素 | 效应 | 趋势 |
|:---|:---|:---|
| 电负性 | 诱导效应 | 邻位电负性基团↑ → δ↑ |
| 磁各向异性 | 环电流效应 | 苯环下屏蔽，平面外去屏蔽 |
| 氢键 | 电子云密度降低 | 氢键使 δ↑（如 –OH 可变化）|
| 溶剂效应 | 溶剂极化 | 极性溶剂通常 δ 增大 |

**常见化学位移范围（¹H NMR）**：
- TMS：0 ppm
- 烷基 CH₃：0.9–1.5 ppm
- 烯烃 =CH–：4.5–6.5 ppm
- 芳香 ArH：6.5–8.5 ppm
- 醛基 CHO：9–10 ppm
- 羧酸 COOH：10–13 ppm
- 可交换质子（–OH / –NH₂）：1–5 ppm（可变）

### 自旋-自旋偶合

**n+1 规则**：
- 与 n 个等价相邻质子偶合 → 裂分为 n+1 重峰
- 强度比符合 Pascal 三角

**偶合常数 J**：
- **²J（同碳偶合）**：10–15 Hz
- **³J（邻位偶合，vicinal）**：6–8 Hz（反式 > 顺式），取决于二面角（Karplus 关系）
- **⁴J（远程偶合，W-型）**：0–3 Hz，特殊几何才可观

**磁不等价质子**：
- 同一个 CH₂ 上的两个 H 可能不等价（如手性中心邻位的 CH₂、环己烷的 a/e 键）
- 表现为 AB 体系（而不是简单的双峰）

### 积分与结构推求

- **积分面积**与质子数成正比（积分比 = 质子数比，不是绝对数量）
- **结构推求逻辑链**：分子式 → 不饱和度 → 特征峰（δ）→ 裂分模式 → 拼接结构

## 五、常见分类或情形

### 动态 NMR

**时间尺度**：
- NMR 时间尺度：τ ≈ 1/Δν（通常 ms 量级）
- **慢交换**：观测到两组独立信号
- **快交换**：观测到平均化后的单一信号

**典型应用**：
- **构象翻转**：环己烷的椅式翻转（低温下可区分直立/平伏氢）
- **配位交换**：Be(C₅H₅)₂ 中 η¹ 与 η⁵ 的快速交换
- **质子转移**：可交换氢（–OH, –NH）在 D₂O 中消失

### NOE（核 Overhauser 效应）

- 空间接近（< 5 Å）的质子之间产生信号增强
- 用于判断**立体化学**（顺式/反式、endo/exo）

## 六、适用条件与限制

- NMR仅适用于具有核自旋（I≠0）的原子核（如¹H、¹³C、¹⁹F、³¹P）
- 化学位移受溶剂、温度、浓度影响，不能孤立使用
- n+1规则仅适用于一级近似（弱偶合），强偶合需用二级分析
- 可交换质子（–OH、–NH）的化学位移不可靠，需D₂O交换验证

## 七、常见比较与易混点

| 对比维度 | 正确理解 | 常见误区 |
|:---|:---|:---|
| 化学位移方向 | δ增大=去屏蔽（电子云密度降低） | 认为δ增大是屏蔽增强 |
| 等价质子 | 需同时满足化学等价和磁等价 | 仅凭化学环境相同就认为等价 |
| n+1规则 | 仅适用于相邻质子磁等价的情况 | 对所有裂分都用n+1规则 |
| 积分面积 | 比值=质子数比，不是绝对数 | 认为积分面积就是质子数 |

## 八、与其他知识点的联系

- [[有机波谱分析]]：NMR 是有机波谱三兄弟（UV/MS/NMR）中最精细的结构表征手段
- [[立体化学]]：NOE 和偶合常数是判断立体化学的核心工具
- 动态过程：变温 NMR 研究化学交换、构象翻转
- [[配位化学]]：配位交换的动力学 NMR 研究

## 九、典型题型

1. **结构推求题**：给出分子式 + ¹H NMR 数据（化学位移、积分、裂分）+ 偶合常数 → 推断结构并标注立体化学
2. **动态过程分析**：变温 NMR 数据 → 计算活化能、判断交换机制（快交换/慢交换）
3. **立体化学判断**：利用偶合常数 J 判断顺反异构（如 J = 15 Hz 反式，J = 10 Hz 顺式）；利用 NOE 增强判断空间接近
4. **磁不等价质子识别**：判断 CH₂ 上两个 H 是否磁不等价，预测裂分模式（AB 体系 vs 简单峰）
5. **可交换质子鉴定**：通过 D₂O 交换实验确认 –OH、–NH 等可交换质子

## 十、例题

**例1**（基础结构推求）某化合物分子式为 C₄H₈O，¹H NMR 显示：δ 9.8 (1H, t, J = 2 Hz), δ 2.4 (2H, m), δ 1.0 (3H, t, J = 7 Hz)。推断结构。

**解析**：δ 9.8 的醛基质子（三重峰，与 CH₂ 偶合），δ 2.4 的 CH₂（与醛基 H 和 CH₃ 偶合），δ 1.0 的 CH₃（三重峰，与 CH₂ 偶合）。结构为 CH₃CH₂CHO（丙醛）。

**例2**（立体化学判断）某化合物分子式为 C₄H₆O₂，¹H NMR 显示：δ 7.2 (1H, dd, J = 15.5, 1.0 Hz), δ 5.8 (1H, dd, J = 15.5, 6.5 Hz), δ 4.2 (1H, m), δ 1.3 (3H, d, J = 6.5 Hz), δ 1.2 (3H, t, J = 7.0 Hz)。推断结构并判断双键构型。

**解析**：δ 7.2 和 5.8 的两个烯烃质子，偶合常数 J = 15.5 Hz 提示反式双键。δ 4.2 的 CH 与 δ 1.3 的 CH₃ 偶合（J = 6.5 Hz），δ 1.2 的 CH₃ 与 CH₂ 偶合（J = 7.0 Hz）。结构为 (E)-CH₃CH=CHCOOCH₂CH₃（反式巴豆酸乙酯）。

## 十一、易错点

1. **化学位移方向混淆**：δ 增大表示去屏蔽（电子云密度降低），而非屏蔽增强
2. **等价质子判断错误**：仅满足化学等价不够，还需磁等价才能应用 n+1 规则
3. **n+1 规则误用**：相邻质子磁不等价时（如手性中心邻位 CH₂），裂分不符合 n+1 规则
4. **积分面积误解**：积分比等于质子数比，而非绝对质子数
5. **可交换质子位置误判**：–OH、–NH 的化学位移随浓度、温度、溶剂显著变化，不能作为可靠结构依据
6. **动力学 NMR 忽略协同过程**：如 Be(C₅H₅)₂ 的交换需同时考虑 1,5-σ 迁移和环翻转

## 十二、🎯 教学视角

### 学生常见认知误区
1. **误区**：化学位移 δ 越大表示屏蔽越强。
   - **原因**："位移"一词容易联想到物理位移。
   - **正确认知**：δ 越大表示**去屏蔽**越强，电子云密度越低。
   - **记忆法**：δ=0（TMS）是屏蔽最强的参考点，δ 增大=远离参考点=去屏蔽。

2. **误区**：n+1 规则适用于所有裂分情况。
   - **原因**：教材强调 n+1 规则，学生过度泛化。
   - **正确认知**：n+1 规则仅适用于相邻质子**磁等价**的情况。
   - **反例**：手性中心邻位 CH₂ 的两个 H 磁不等价，出现 AB 体系而非简单双峰。

### 入门级例题（教师引导提问）
**题目**：某化合物分子式 C₃H₆O，¹H NMR 显示：δ 9.8 (1H, t), δ 2.4 (2H, m), δ 1.0 (3H, t)。推断结构。

**预期解答路径**：
- δ 9.8 提示醛基（-CHO）
- 1H 三重峰 → 与 CH₂ 偶合（n=2, 2+1=3）
- 3H 三重峰 → 与 CH₂ 偶合（n=2, 2+1=3）
- 2H 多重峰 → 与两侧各 1 个 H 偶合
- **核心结论**：结构为 CH₃CH₂CHO（丙醛）。

### 与现实/直觉的连接
- **类比**：NMR 像"原子核的收音机"——调谐到特定频率（磁场），不同化学环境的核发出不同"声音"（化学位移）。
- **生活实例**：MRI（磁共振成像）就是 NMR 的医学应用，利用人体内水分子中氢核的共振信号成像。

## 十三、竞赛拓展

- **¹³C NMR**：化学位移范围更广（0–220 ppm），无偶合（去耦谱）或保留偶合信息
- **二维 NMR**（COSY、HSQC）：超纲但有助于理解复杂结构
- **高分辨 NMR**：区分化学等价但磁不等价的质子

## 十六、¹³C NMR 化学位移表与二维 NMR

### ¹³C NMR 化学位移速查表

| 碳类型 | δ (ppm) | 典型例子 |
|------|:---:|------|
| 烷基 C（-CH₃, -CH₂-） | 0–50 | CH₄(-2.3), C₂H₆(5.7) |
| C-X（X=Cl, Br, O, N） | 30–80 | CH₃Cl(25), CH₃OH(50) |
| 炔碳 C≡C | 65–90 | CH≡CH(71.9) |
| 烯碳 C=C | 100–150 | CH₂=CH₂(123.3) |
| 芳碳 C（苯环） | 110–160 | C₆H₆(128.5) |
| 羰基 C=O（醛） | 190–205 | CH₃CHO(200) |
| 羰基 C=O（酮） | 195–220 | CH₃COCH₃(206) |
| 羰基 C=O（羧酸） | 170–185 | CH₃COOH(178) |
| 羰基 C=O（酯） | 165–180 | CH₃COOCH₃(171) |

规律：δ 值随碳原子周围电子密度降低而增大。sp³ C < sp C < sp² C < 羰基 C。

### 二维 NMR 基础概念

| 技术 | 提供信息 | 竞赛应用 |
|------|------|------|
| COSY | ¹H-¹H 偶合关系（相邻 H） | 确定碳骨架连接 |
| HSQC | ¹H-¹³C 直接相连 | 确定哪个 H 连在哪个 C 上 |
| HMBC | ¹H-¹³C 远程偶合（2-3 键） | 跨越杂原子连接 |
| NOESY | 空间距离近的 H | 立体化学判断 |

竞赛考查方式：决赛/IChO 中给出 COSY 和 HSQC 谱图推导未知物结构。
