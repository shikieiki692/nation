# 有机化合物基础

> **课标要求**：认识有机化合物的一般方法，了解甲烷、乙烯、苯、乙醇、乙酸等典型有机物的结构特点和主要性质，建立"碳骨架+官能团"的有机物分析框架。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能辨识常见有机化合物分子中的碳骨架和官能团，概括其分子中碳原子的成键类型。能描述甲烷、乙烯、乙炔的分子结构特征，并能搭建甲烷和乙烷的立体模型，能写出丁烷和戊烷的同分异构体。
2. 能描述乙烯、乙醇、乙酸的主要化学性质及相应性质实验的现象，能书写相关的化学方程式，能利用这些物质的主要性质进行鉴别。能预测简单有机化合物的某些性质，并进行实验验证。
3. 能列举合成高分子、油脂、糖类、蛋白质等有机化合物在生产、生活中的重要应用，并结合这些物质的主要性质进行简单说明。
4. 能列举事实说明有机化学在生产、生活中的应用价值及其对推动社会发展的贡献。从有机化合物及其性质的角度对有关能源、材料、饮食、健康、环境等实际问题进行分析、讨论和评价。能从材料组成的角度对生活中常见的材料进行分类，根据需求选择和使用适当的材料，解释使用注意事项。能妥善保存、科学合理地使用常见有机化学品。

## 核心概念

### 1. 有机化合物概述

**定义：** 含碳化合物（CO、CO₂、碳酸盐、碳化物等除外）。

**碳的成键特点：**
- 每个碳原子形成4个共价键
- C-C之间可形成单键、双键、三键
- 碳链可以是直链、支链或环状
- 同一分子中可含多种官能团

**有机物一般性质：**
- 熔沸点较低（分子间作用力为主）
- 多数难溶于水，易溶于有机溶剂
- 多数可燃烧
- 反应速率较慢，常需催化剂和加热

### 2. 甲烷（CH₄）与烷烃

#### 甲烷

| 项目 | 内容 |
|------|------|
| 结构 | 正四面体，键角109°28'，4个C-H键完全等同 |

![甲烷的正四面体结构模型](人教版高中化学课本/【2】人教版·化学必修第二册_images/0d7ee1f5bfcfea166fa111f27083ec046460cc21d7cdd4b0caf4c92745ca0a85.jpg)

| 物理性质 | 无色无味气体，密度小于空气，难溶于水 |
| 化学性质 | 常温下稳定（不与酸、碱、KMnO₄反应） |

**关键反应：**

| 反应类型 | 方程式 | 条件 |
|----------|--------|------|
| 燃烧 | CH₄ + 2O₂ → CO₂ + 2H₂O | 点燃 |
| **取代反应** | CH₄ + Cl₂ $\xrightarrow{\text{光照}}$ CH₃Cl + HCl | 光照 |

> **取代反应**：有机物分子中的原子或原子团被其他原子或原子团所替代的反应。

**实验7-1**：CH₄与Cl₂混合光照：
- 气体颜色变浅（Cl₂被消耗）
- 瓶壁出现油状液滴（CH₂Cl₂、CHCl₃、CCl₄）
- 液面上升（气体体积减小）
- 有白雾（HCl遇水蒸气）

#### 烷烃

| 项目 | 内容 |
|------|------|
| 通式 | CₙH₂ₙ₊₂（n≥1） |
| 结构特征 | 全部C-C单键，碳原子sp³杂化 |
| 物理规律 | 碳数↑→熔沸点↑、密度↑；C₁-C₄气态，C₅-C₁₆液态，C₁₇+固态 |
| 化学性质 | 稳定（取代反应需光照）、可燃 |

**同系物：** 结构相似，分子组成上相差一个或多个CH₂原子团的化合物。

**同分异构体：** 分子式相同而结构不同的化合物。

![三种戊烷的分子结构模型](人教版高中化学课本/【5】人教版·化学选择性必修3有机化学基础_images/2914fdb2d9ba443a0506cea2bcc40d4ca6f579048529824291b4396e594d7c37.jpg)

| 碳数 | 异构体数目 |
|------|-----------|
| C₄H₁₀ | 2（正丁烷、异丁烷） |
| C₅H₁₂ | 3（正戊烷、异戊烷、新戊烷） |
| C₆H₁₄ | 5 |
| C₁₀H₂₂ | 75 |

### 3. 乙烯（C₂H₄）与有机高分子材料

#### 乙烯

| 项目 | 内容 |
|------|------|
| 结构 | CH₂=CH₂，平面结构，键角~120° |
| C=C双键 | 1个σ键 + 1个π键（π键易断裂→加成反应） |
| 物理性质 | 无色稍有甜味气体，密度略小于空气 |

**关键反应：**

| 反应类型 | 方程式 | 说明 |
|----------|--------|------|
| 燃烧 | C₂H₄ + 3O₂ → 2CO₂ + 2H₂O | 火焰明亮有黑烟 |
| **加成反应** | CH₂=CH₂ + Br₂ → CH₂BrCH₂Br | 溴的CCl₄溶液褪色 |
| | CH₂=CH₂ + H₂ $\xrightarrow{\text{催化剂}}$ CH₃CH₃ | |
| | CH₂=CH₂ + H₂O $\xrightarrow{\text{催化剂}}$ CH₃CH₂OH | 工业制乙醇 |
| 氧化 | 被酸性KMnO₄溶液氧化→褪色 | 可区分烷烃和烯烃 |
| **加聚反应** | nCH₂=CH₂ $\xrightarrow{\text{催化剂}}$ [—CH₂—CH₂—]ₙ | 生成聚乙烯（PE） |

> **加成反应**：不饱和碳原子与其他原子或原子团直接结合的反应。双键中π键断裂，两端各连新原子/基团。

> **加聚反应**：许多含有双键的单体通过加成反应聚合成高分子的反应。[—CH₂—CH₂—]ₙ中的重复单元叫**链节**，n叫**聚合度**。

#### 烃的分类

```
烃
├── 饱和烃（烷烃）：只含C-C单键
└── 不饱和烃
    ├── 烯烃（C=C双键）
    ├── 炔烃（C≡C三键）
    └── 芳香烃（苯环）
```

#### 苯（C₆H₆）简介

| 项目 | 内容 |
|------|------|
| 结构 | 平面正六边形，所有C-C键等长（139 pm，介于单双键之间） |
| 特殊键 | 离域π键（6个C的p轨道侧面重叠形成大π键） |
| 关键特征 | **不能**使酸性KMnO₄溶液褪色（不同于烯烃） |
| 关键特征 | **不能**使溴的CCl₄溶液褪色（不同于烯烃） |

**苯的典型反应（以取代为主）：**
- 燃烧：C₆H₆ + 3O₂ → 6CO₂ + 3H₂O（浓烈黑烟）
- 硝化：C₆H₆ + HNO₃ $\xrightarrow{\text{浓H₂SO₄, 50-60°C}}$ C₆H₅NO₂ + H₂O
- 加成：C₆H₆ + 3H₂ $\xrightarrow{\text{Ni, 加热}}$ C₆H₁₂（环己烷）

### 4. 乙醇（C₂H₅OH）与乙酸（CH₃COOH）

#### 乙醇

| 项目 | 内容 |
|------|------|
| 结构 | CH₃CH₂**OH**，官能团为羟基（—OH） |
| 物理性质 | 无色特殊气味液体，密度0.789 g/cm³，bp 78.5°C，与水混溶 |

**关键反应：**

| 反应 | 方程式 | 说明 |
|------|--------|------|
| 与Na反应 | 2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑ | 比水与Na反应温和（O-H极性弱于水） |
| 燃烧 | CH₃CH₂OH + 3O₂ → 2CO₂ + 3H₂O | |
| **催化氧化** | 2CH₃CH₂OH + O₂ $\xrightarrow{\text{Cu/Ag, Δ}}$ 2CH₃CHO + 2H₂O | 铜丝加热后插入乙醇→反复变黑变亮 |
| 消去反应 | CH₃CH₂OH $\xrightarrow{\text{浓H₂SO₄, 170°C}}$ CH₂=CH₂↑ + H₂O | 分子内脱水 |

> **催化氧化机理**：Cu先被氧化为CuO（变黑），CuO再氧化乙醇为乙醛同时CuO还原为Cu（变亮），如此循环。

#### 乙酸

| 项目 | 内容 |
|------|------|
| 结构 | CH₃**COOH**，官能团为羧基（—COOH） |
| 物理性质 | 无色刺激性液体，mp 16.6°C（冰醋酸），bp 118°C |
| 酸性 | 弱酸，能使石蕊变红，能与碳酸盐反应（强于碳酸） |

**核心反应——酯化反应：**
$$\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \xrightleftharpoons{\text{浓H}_2\text{SO}_4, \Delta} \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}$$

> **酯化反应**：酸和醇反应生成酯和水。属于取代反应（羧酸脱-OH，醇脱-H）。浓H₂SO₄作催化剂和吸水剂。

> **实验7-6**：乙醇+乙酸+浓H₂SO₄加热→产物导入饱和Na₂CO₃溶液上方→可闻到水果香味（乙酸乙酯）。

#### 官能团与有机物分类

| 官能团 | 名称 | 代表物 | 有机物类别 |
|--------|------|--------|-----------|
| —OH | 羟基 | 乙醇 | 醇 |
| —COOH | 羧基 | 乙酸 | 羧酸 |
| —CHO | 醛基 | 乙醛 | 醛 |
| C=C | 碳碳双键 | 乙烯 | 烯烃 |
| C≡C | 碳碳三键 | 乙炔 | 炔烃 |
| —X（卤素） | 卤原子 | 氯乙烷 | 卤代烃 |
| —NH₂ | 氨基 | 甲胺 | 胺 |
| —COO— | 酯基 | 乙酸乙酯 | 酯 |

### 5. 基本营养物质

#### 糖类

| 类别 | 代表物 | 分子式 | 特征 |
|------|--------|--------|------|
| 单糖 | 葡萄糖 | C₆H₁₂O₆ | 还原糖（银镜反应/Cu(OH)₂砖红色） |
| 单糖 | 果糖 | C₆H₁₂O₆ | 与葡萄糖互为同分异构体 |
| 二糖 | 蔗糖 | C₁₂H₂₂O₁₁ | 非还原糖 |
| 二糖 | 麦芽糖 | C₁₂H₂₂O₁₁ | 还原糖 |
| 多糖 | 淀粉 | (C₆H₁₀O₅)ₙ | 遇碘变蓝，非还原糖 |
| 多糖 | 纤维素 | (C₆H₁₀O₅)ₙ | n值与淀粉不同，不互为同分异构体 |

**关键反应：**
- 淀粉水解：(C₆H₁₀O₅)ₙ + nH₂O $\xrightarrow{\text{酸/酶}}$ nC₆H₁₂O₆（葡萄糖）
- 葡萄糖氧化：C₆H₁₂O₆ + 6O₂ $\xrightarrow{\text{酶}}$ 6CO₂ + 6H₂O（生命活动能量来源）
- 葡萄糖发酵：C₆H₁₂O₆ $\xrightarrow{\text{酶}}$ 2C₂H₅OH + 2CO₂↑

#### 蛋白质

| 性质 | 说明 |
|------|------|
| 组成 | C、H、O、N、S等元素 |
| 水解产物 | 氨基酸 |
| **变性** | 重金属盐、强酸碱、加热、紫外线等→蛋白质失去活性（不可逆） |
| **颜色反应** | 含苯环蛋白质 + 浓HNO₃加热→黄色（黄色反应） |
| **灼烧气味** | 烧焦羽毛味（含N） |

> 中国成就：1965年，中国科学家首次人工合成具有生物活性的结晶牛胰岛素（蛋白质）。

#### 油脂

| 项目 | 内容 |
|------|------|
| 本质 | 高级脂肪酸与甘油形成的酯（酯类） |
| 植物油 | 含不饱和脂肪酸甘油酯较多，室温液态 |
| 动物脂肪 | 含饱和脂肪酸甘油酯较多，室温固态 |
| 氢化 | 植物油 + H₂ $\xrightarrow{\text{催化剂}}$ 人造脂肪（硬化油/人造黄油） |
| 皂化反应 | 油脂 + NaOH → 甘油 + 脂肪酸钠（肥皂） |

## 知识拓展

### 人们对甲烷分子结构的认识过程

甲烷是最简单的有机化合物，人类认识其分子结构花了上百年时间：1808年道尔顿用图式表示甲烷（受当时分析方法限制）；凯库勒提出碳原子是四价、碳原子本身可以互相连接的观点；布特列洛夫提出化学结构理论——分子的化学性质取决于组成单元的性质、数量和化学结构，原子间能相互影响。1874年范托夫和勒贝尔各自提出碳原子具有**四面体结构**的假说，开辟了立体化学的新篇章，X射线衍射进一步证明甲烷的正四面体结构。

### 乙醇的工业制法

**(1) 发酵法**：淀粉经水解为葡萄糖，再经酵母菌发酵得乙醇。发酵液含乙醇6%~10%，精馏后得95%工业乙醇。
$$2(\mathrm{C}_{6}\mathrm{H}_{10}\mathrm{O}_{5})_{n} \xrightarrow{\mathrm{H}_{2}\mathrm{O}} n\mathrm{C}_{12}\mathrm{H}_{22}\mathrm{O}_{11} \xrightarrow{\mathrm{H}_{2}\mathrm{O}} 2n\mathrm{C}_{6}\mathrm{H}_{12}\mathrm{O}_{6}$$
$$\mathrm{C}_{6}\mathrm{H}_{12}\mathrm{O}_{6} \xrightarrow{\text{酶}} 2\mathrm{CH}_{3}\mathrm{CH}_{2}\mathrm{OH} + 2\mathrm{CO}_{2}\uparrow$$

**(2) 乙烯水合法（工业主流）**：磷酸/硅藻土催化剂，260~290°C，约7 MPa，乙烯单程转化率仅5%左右，大量乙烯需循环。
$$\mathrm{CH}_{2}=\mathrm{CH}_{2} + \mathrm{H}_{2}\mathrm{O} \xrightarrow[\triangle]{\text{催化剂}} \mathrm{CH}_{3}\mathrm{CH}_{2}\mathrm{OH}$$

### 乙醇的生理作用

乙醇不需消化直接扩散进入血液。代谢过程主要在肝脏：乙醇 →（乙醇脱氢酶）→ 乙醛（有害）→（乙醛脱氢酶）→ 乙酸（唯一有营养价值的代谢产物）。代谢速率有限，饮酒速率超过代谢速率时器官中积蓄导致中毒。

### 淀粉和碘的显色机理

直链淀粉遇碘呈蓝色，支链淀粉遇碘呈紫红色。机理：碘分子嵌入淀粉螺旋体的轴心部位形成**包合物**。颜色与聚合度有关——聚合度200~980时呈蓝色，支链上平均聚合度20~28时呈紫色。加热蓝色消失是解吸作用。

## 竞赛衔接

- **有机物命名法**（IUPAC系统命名法）
- **有机反应机理初步**：自由基取代（CH₄ + Cl₂）、亲电加成（烯烃 + HX）

## 常见易错

1. ❌ "有机物都难溶于水" → ✅ 乙醇、乙酸、葡萄糖等小分子有机物可与水混溶
2. ❌ "苯含有碳碳双键" → ✅ 苯中6个C-C键完全等同（键长139 pm），是离域π键，不是交替的单双键
3. ❌ "乙烯使KMnO₄褪色是加成反应" → ✅ 是氧化反应（KMnO₄氧化乙烯）
4. ❌ "乙醇与Na反应比水剧烈" → ✅ 水与Na反应更剧烈（O-H极性：水 > 乙醇）
5. ❌ "淀粉和纤维素是同分异构体" → ✅ 虽然分子式都写为(C₆H₁₀O₅)ₙ，但n值不同，不是同分异构体
6. ❌ "酯化反应中浓H₂SO₄只作催化剂" → ✅ 同时作催化剂和吸水剂（吸水促进平衡正移）

## 🎯 教学视角

### 教学重点与难点
- **重点**：建立"碳骨架+官能团"的分析框架；掌握典型有机物（甲烷→乙烯→苯→乙醇→乙酸）的结构与性质关系；理解四种基本有机反应类型（取代、加成、氧化、消去）。
- **难点**：苯的特殊结构（离域π键，不是交替单双键）的理解；官能团与有机物性质的关系（"结构决定性质"的观念建立）；同分异构现象的初步认识。

### 建议教学路径
- 模型拼插法（螺旋上升式活动串）：活动1（1个C）→活动2（2个C）→活动3（3~4个C），逐步建立碳原子成键特点的认知
- 结构分析路径：分子结构→化学键→官能团→性质，以乙醇为例建立"结构决定性质"的分析模型
- 对比教学：烷烃（稳定，取代反应）vs烯烃（活泼，加成反应）vs苯（特殊，取代为主），突出结构差异导致性质差异
- 实验驱动：甲烷与Cl₂光照（取代反应特征）、乙烯使溴水褪色（加成反应）、乙醇催化氧化（Cu丝变色现象）等实验增强感性认识

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 有机物都难溶于水 | 乙醇、乙酸、葡萄糖等小分子有机物可与水混溶 | 从分子极性和氢键角度解释溶解性规律 |
| 苯含有碳碳双键 | 苯中6个C-C键完全等同（键长139 pm），是离域π键，不是交替的单双键 | 对比苯与烯烃的化学性质差异（苯不能使KMnO₄褪色） |
| 乙烯使KMnO₄褪色是加成反应 | 是氧化反应（KMnO₄氧化乙烯） | 强调KMnO₄的强氧化性，褪色≠加成 |
| 乙醇与Na反应比水剧烈 | 水与Na反应更剧烈（O-H极性：水>乙醇） | 从O-H键极性角度对比 |
| 淀粉和纤维素是同分异构体 | 虽然分子式都写为(C₆H₁₀O₅)ₙ，但n值不同，不是同分异构体 | 强调同分异构体要求分子式完全相同 |
| 酯化反应中浓H₂SO₄只作催化剂 | 同时作催化剂和吸水剂（吸水促进平衡正移） | 从化学平衡移动角度理解浓硫酸的双重作用 |

### 与现实世界的联系
- 能源与燃料：甲烷（天然气主要成分）、乙醇（生物燃料）是重要的能源物质
- 材料与工业：聚乙烯（PE）等高分子材料广泛应用于包装、建筑、医疗等领域
- 食品与健康：糖类（能量来源）、蛋白质（生命基础）、油脂（储能物质）是人体必需的营养物质
- 生活化学品：食醋（乙酸）、酒精（乙醇）、肥皂（油脂皂化产物）与日常生活密切相关
- 中国科学成就：1965年首次人工合成结晶牛胰岛素，体现有机化学在生命科学中的重要地位
