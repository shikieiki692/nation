# 配合物基础

## 课标要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能说出配位键的特征；能运用配位键解释配合物的某些典型性质；能举例说明配合物在生物、化学等领域的广泛应用。

## 核心概念

### 配合物的组成

配合物（络合物）由**中心离子（原子）**和**配体**组成。

- **中心离子（原子）**：通常是过渡金属离子（如Cu²⁺、Fe³⁺、Ag⁺等），提供空轨道
- **配体**：提供孤对电子的分子或离子（如NH₃、H₂O、Cl⁻、CN⁻、SCN⁻等）
- **配位数**：与中心离子直接成键的配位原子个数（不是配体个数）
- **配位键**：中心离子的空轨道接受配体提供的孤对电子形成

配合物的命名：先配体后中心离子。如[Cu(NH₃)₄]SO₄命名为硫酸四氨合铜(II)。

### 常见配合物实例

**[Cu(NH₃)₄]²⁺（铜氨配合物）**：

Cu²⁺ + 4NH₃ → [Cu(NH₃)₄]²⁺

现象：向CuSO₄溶液中加入过量浓氨水，先产生Cu(OH)₂蓝色沉淀，继续加氨水沉淀溶解，生成深蓝色的[Cu(NH₃)₄]²⁺。

配位数：4（4个NH₃分子各提供1对孤对电子）

**[Fe(SCN)ₙ]³⁻ⁿ（铁硫氰酸配合物）**：

Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ

现象：Fe³⁺与SCN⁻反应生成血红色配合物。这是检验Fe³⁺最灵敏的方法。配位数通常为1~6，具体取决于SCN⁻浓度。

**[Ag(NH₃)₂]⁺（银氨配合物）**：

Ag⁺ + 2NH₃ → [Ag(NH₃)₂]⁺

用于银镜反应（检验醛基）和溶解AgCl/AgBr（拍照底片定影时用Na₂S₂O₃而非银氨）。

### 配位键的本质

配位键的本质是**孤对电子→空轨道**的给予-接受作用：

- 中心离子通常有空的d、s、p轨道可以接受电子
- 配体中配位原子（如N、O、S、Cl等）有未共用的孤对电子
- 形成配位键后，与普通共价键没有区别

配位数的影响因素：

- 中心离子的电荷和半径：电荷高、半径大→配位数大
- 配体的性质：配体体积小→配位数大
- 反应条件：温度、浓度等

### 配合物的稳定性

配合物的稳定性用稳定常数K稳表示：

[M + nL ⇌ MLₙ]，K稳 = [MLₙ] / ([M][L]ⁿ)

K稳越大，配合物越稳定。影响稳定性的因素：

- **中心离子**：过渡金属离子配合物通常较稳定（晶体场稳定化能的贡献）
- **配体**：多齿配体（如EDTA）形成的配合物比单齿配体内协效应更强
- **螯合效应**：含有两个或以上配位原子的配体（螯合剂）形成的配合物特别稳定

### 内轨型与外轨型配合物

根据中心离子d轨道参与杂化的情况：

- **内轨型配合物**：中心离子使用内层(n-1)d轨道参与杂化（如dsp²、d²sp³），配合物较稳定，通常为低自旋
- **外轨型配合物**：中心离子使用外层nd轨道参与杂化（如sp³d、sp³d²），配合物稳定性较低，通常为高自旋

判断依据：配体的场强。强场配体（如CN⁻、CO）倾向于形成内轨型；弱场配体（如F⁻、H₂O）倾向于形成外轨型。

## 知识拓展

### 配合物与超分子

- **配位键**：一方提供孤电子对，另一方提供空轨道形成的共价键。
- **配合物**：中心原子（离子）与配体通过配位键结合形成的化合物。
- **超分子**：两个或多个分子通过分子间作用力（包括氢键、范德华力等）形成的复杂聚集体。教材通过典型例子阐述超分子的重要特征——分子识别。
- **配合物在生物中的应用**：血红蛋白中的Fe²⁺与O₂的配位、叶绿素中的Mg²⁺、维生素B₁₂中的Co³⁺等。
- **分子识别**：超分子的核心特征，如冠醚识别碱金属离子——冠醚空腔大小与金属离子半径匹配时结合最稳定。

## 竞赛衔接

- 配合物的命名和组成是竞赛基础技能，需熟练掌握
- 配合物的稳定性（稳定常数）计算是竞赛常见题型
- 内轨型/外轨型配合物的判断与晶体场理论在竞赛中有深入考察

## 常见易错

1. **配位数不等于配体个数**：如[Co(NH₃)₄Cl₂]⁺中配位数是6（4个N + 2个Cl），不是4
2. **配体不一定是电中性的**：NH₃、H₂O是中性配体，但Cl⁻、CN⁻、OH⁻是阴离子配体，会改变中心离子的表观电荷
3. **EDTA是六齿配体**：EDTA（乙二胺四乙酸）有6个配位原子（2个N + 4个O），能与一个金属离子形成非常稳定的螯合物

## 关键实验

### 实验活动：简单配合物的形成（CuSO₄ + NH₃）
- **目的**：通过CuSO₄溶液中加入氨水的实验，直观展示配位键的形成过程和配合物的特征颜色
- **关键操作**：
  - 向CuSO₄溶液中逐滴加入浓氨水并摇匀
  - 先观察蓝色沉淀生成，继续滴加氨水至沉淀溶解
  - 记录沉淀生成和溶解两个阶段的颜色变化
- **预期现象**：
  - 第一阶段：Cu²⁺ + 2OH⁻ → Cu(OH)₂↓（蓝色絮状沉淀）
  - 第二阶段：Cu(OH)₂ + 4NH₃ → [Cu(NH₃)₄]²⁺ + 2OH⁻（沉淀溶解，溶液变为深蓝色）
  - 深蓝色的[Cu(NH₃)₄]²⁺是铜氨配合物的特征颜色
- **注意事项**：
  - 氨水要逐滴加入并摇匀，先观察沉淀生成再观察沉淀溶解，两个阶段缺一不可
  - 浓氨水有刺激性气味，操作应在通风橱中进行
  - 该实验直观展示配位键形成过程：Cu²⁺提供空轨道，NH₃中N提供孤对电子
  - 可延伸讨论：血红蛋白中Fe²⁺与卟啉环的配位、叶绿素中Mg²⁺的配位等生物实例

## 🎯 教学视角

### 教学重点与难点

**重点**：
- 配合物的组成：中心离子（提供空轨道）+ 配体（提供孤对电子）+ 配位数
- 配位键的本质：孤对电子→空轨道的给予-接受作用，形成后与普通共价键完全等价
- 常见配合物实例：[Cu(NH₃)₄]²⁺（铜氨）、[Fe(SCN)ₙ]³⁻ⁿ（检验Fe³⁺）、[Ag(NH₃)₂]⁺（银氨）

**难点**：
- 配位数≠配体个数：多齿配体（如EDTA）一个配体贡献多个配位原子，配位数是直接与中心离子成键的配位原子个数
- 内轨型与外轨型配合物的判断：强场配体（CN⁻、CO）→内轨型（低自旋）；弱场配体（F⁻、H₂O）→外轨型（高自旋）
- 配合物稳定性的影响因素：中心离子电荷/半径、配体性质、螯合效应

### 建议教学路径

1. **前置知识**：先掌握 [[化学键基础]] 中配位键的概念（孤对电子→空轨道）
2. **配合物组成**：从CuSO₄溶液中加氨水的实验引入——先产生Cu(OH)₂蓝色沉淀，继续加氨沉淀溶解生成深蓝色[Cu(NH₃)₄]²⁺，直观展示配位键的形成
3. **配位数教学**：用[Co(NH₃)₄Cl₂]⁺等例子强调配位数是"配位原子个数"而非"配体个数"
4. **稳定性与应用**：用稳定常数K稳定量描述配合物稳定性，结合血红蛋白（Fe²⁺-卟啉）、叶绿素（Mg²⁺）、维生素B₁₂（Co³⁺）等生物实例说明配合物的重要性

### 常见认知误区

| 误区 | 正确理解 |
|:---|:---|
| 配位数等于配体个数 | 配位数是直接与中心离子成键的配位原子个数，多齿配体（如EDTA）一个配体贡献多个配位原子 |
| 配合物中的配位键比普通共价键弱 | 配位键一旦形成就与普通共价键完全等价，强度没有本质区别 |
| 只有过渡金属才能形成配合物 | 过渡金属最常见，但主族元素（如Al³⁺、Mg²⁺）也能形成配合物 |

### 与现实世界的联系

1. 血红蛋白中Fe²⁺与卟啉环形成配合物，负责在血液中运输O₂，是生物体内最重要的配合物之一。
2. 叶绿素中的Mg²⁺配合物是光合作用的核心，维生素B₁₂中的Co³⁺配合物参与DNA合成。
3. 摄影工业中，定影液利用Na₂S₂O₃与未曝光的AgBr形成配合物[Ag(S₂O₃)₂]³⁻来溶解多余的AgBr。
4. EDTA作为六齿螯合剂，广泛用于水质软化、重金属解毒和分析化学中的络合滴定。
