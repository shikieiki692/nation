# 生物大分子与合成高分子

> **课标要求**：了解糖类、蛋白质、核酸的组成与性质，掌握高分子的两种基本合成方法（加聚与缩聚），了解常见高分子材料的种类与应用。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

### 生物大分子（第四章）

1. 能说明单糖的组成和结构特点，能综合运用相关知识分析单糖的主要化学性质。
2. 能说明二糖和多糖的组成和结构特点，能综合运用相关知识分析二糖和多糖的主要化学性质。
3. 能辨识氨基酸中的氨基和羧基，能说明氨基酸的主要化学性质，能写出氨基酸之间发生缩合反应的化学方程式。
4. 能辨识蛋白质中的肽键，能说明蛋白质的主要结构特点和化学性质。
5. 能说明核酸的组成和结构特点，能说出核酸的生物功能。

### 合成高分子（第五章）

6. 能对单体和高分子进行相互推断，写出典型的加聚反应和缩聚反应的化学方程式。能综合应用有关知识分析和设计高分子的合成路线。
7. 能举例说明塑料、合成纤维、合成橡胶的组成和结构特点。能列举重要的合成高分子，说明它们在材料领域中的应用。
8. 能参与材料的选择与使用、环境保护等社会性议题的讨论，并作出有科学依据的判断、评价和决策。

## 第一部分：生物大分子

### 1. 糖类

#### 组成与分类

**通式** 不是所有糖都符合Cₘ(H₂O)ₙ（如脱氧核糖C₅H₁₀O₄不符合），也不能仅凭该式判断（如乙酸C₂H₄O₂符合但不是糖）。

**结构定义**：多羟基醛、多羟基酮及其缩合产物。

| 类别 | 代表物 | 分子式 | 能否水解 |
|------|--------|--------|---------|
| **单糖** | 葡萄糖、果糖 | C₆H₁₂O₆ | 不能 |
| **二糖** | 蔗糖、麦芽糖 | C₁₂H₂₂O₁₁ | 能→2 mol单糖 |
| **多糖** | 淀粉、纤维素 | (C₆H₁₀O₅)ₙ | 能→n mol葡萄糖 |

#### 单糖

**葡萄糖（C₆H₁₂O₆）：**
- 多羟基醛：CH₂OH-CHOH-CHOH-CHOH-CHOH-CHO（含1个-CHO + 5个-OH）
- **还原糖**：能发生银镜反应、能与Cu(OH)₂反应（砖红色沉淀）
- 在溶液中主要以环状结构存在
- 氧化：C₆H₁₂O₆ + 6O₂ $\xrightarrow{\text{酶}}$ 6CO₂ + 6H₂O（生命活动能量来源）

**果糖（C₆H₁₂O₆）：**
- 与葡萄糖互为同分异构体
- 多羟基酮（酮糖）
- 比蔗糖更甜

**核糖（C₅H₁₀O₅）与脱氧核糖（C₅H₁₀O₄）**：
- 核糖→RNA的组成成分
- 脱氧核糖→DNA的组成成分

#### 二糖

| 二糖 | 分子式 | 还原性 | 水解产物 |
|------|--------|--------|---------|
| 蔗糖 | C₁₂H₂₂O₁₁ | **非还原糖** | 葡萄糖 + 果糖 |
| 麦芽糖 | C₁₂H₂₂O₁₁ | **还原糖** | 2分子葡萄糖 |

#### 多糖

**淀粉 (C₆H₁₀O₅)ₙ：**
- 白色粉末，无甜味，不溶于冷水
- **特征反应**：遇碘变蓝（碘进入淀粉螺旋结构中）
- **非还原糖**（无游离醛基/酮基）
- 水解：(C₆H₁₀O₅)ₙ + nH₂O $\xrightarrow{\text{酸/酶}}$ nC₆H₁₂O₆
- 应用：食品、发酵工业（乙醇、醋酸、氨基酸等）

**纤维素 (C₆H₁₀O₅)ₙ：**
- 白色纤维状物质，不溶于水和一般有机溶剂
- **非还原糖**
- n值与淀粉不同→与淀粉**不是**同分异构体
- 水解比淀粉更困难（需浓酸和高温）
- 应用：纺织（棉/麻）、造纸、硝化纤维（火药/涂料）、粘胶纤维（人造丝）

**纤维素制燃料乙醇**：秸秆→预处理→纤维素水解→葡萄糖→发酵→蒸馏→乙醇

#### 糖类水解方程式汇总

```
蔗糖 + H₂O → 葡萄糖 + 果糖         （稀H₂SO₄/酶催化）
麦芽糖 + H₂O → 2葡萄糖            （稀H₂SO₄/酶催化）
(淀粉)ₙ + nH₂O → n葡萄糖           （稀H₂SO₄/酶催化）
(纤维素)ₙ + nH₂O → n葡萄糖          （浓H₂SO₄/酶催化）
```

### 2. 蛋白质

#### 氨基酸

**结构**：R-CH(NH₂)-COOH（α-氨基酸是蛋白质的构建单元）

**化学性质：**

| 性质 | 说明 |
|------|------|
| **两性** | 含-NH₂（碱性）和-COOH（酸性），可与酸碱反应 |
| **成肽反应** | 2个氨基酸脱水缩合→二肽 + H₂O |
| | —COOH + —NH₂ → —CO—NH—（肽键）+ H₂O |
| **手性碳** | 除甘氨酸外，所有氨基酸都有手性碳→旋光异构 |

- 21种氨基酸构成人体蛋白质，其中8种为必需氨基酸（需从食物获取）

#### 蛋白质结构层次

| 层次 | 内容 | 决定因素 |
|------|------|----------|
| **一级结构** | 氨基酸序列 | 基因决定 |

![[4e9ed9f89404e239a6bf019946466839453f843cbd254de958ec4ee7ada7e8e5.jpg|蛋白质一级结构]]
*图：蛋白质一级结构示意图——氨基酸通过肽键(-CO-NH-)连接成多肽链*
| **二级结构** | α-螺旋、β-折叠（氢键维持） | 肽键间氢键 |
| **三级结构** | 二级结构进一步折叠 | 多种弱相互作用 |
| **四级结构** | 多条肽链组装 | 非共价相互作用 |

> **经典案例**：血红蛋白中一个氨基酸突变（Glu→Val）→镰刀型细胞贫血症。说明一级结构决定高级结构。

#### 蛋白质的性质

| 性质 | 条件 | 是否可逆 | 应用 |
|------|------|---------|------|
| **水解** | 酸/碱/酶催化 | — | 蛋白质→多肽→氨基酸 |
| **盐析** | 加入高浓度(NH₄)₂SO₄/Na₂SO₄ | **可逆**（加水重新溶解） | 蛋白质纯化 |
| **变性** | 加热、强酸碱、重金属盐、乙醇、紫外线 | **不可逆** | 消毒灭菌、烹饪 |
| **颜色反应** | 浓HNO₃ + 含苯环蛋白质→加热→黄色 | — | 蛋白质检验 |
| **灼烧** | 烧焦羽毛味 | — | 鉴别蛋白质纤维 |

> **盐析 vs 变性的区别**：盐析是物理变化（可逆），变性是化学变化（不可逆，空间结构被破坏）。

**中国成就**：1965年，中国科学家首次人工合成具有生物活性的结晶牛胰岛素（A链21氨基酸 + B链30氨基酸，通过二硫键连接）。

#### 酶

- 生物催化剂，绝大多数是蛋白质
- 催化效率极高（比普通催化剂快约10⁷倍）
- 条件温和（体温、中性pH）
- 高度专一性（一种酶催化一种反应）

### 3. 核酸

#### 组成

水解层次：核酸 → 核苷酸 → 核苷 + 磷酸 → 戊糖 + 碱基

![[355ca2bbb00bf910c13d84ffde5d80a59287fa1f669780b4b19ad35dc7f640a2.jpg|核酸水解产物]]
*图：核酸的水解产物示意图——核酸逐步水解得到磷酸、戊糖（核糖/脱氧核糖）和五种碱基(A, G, C, T, U)*

| 组分 | DNA | RNA |
|------|-----|-----|
| **戊糖** | 脱氧核糖 | 核糖 |
| **碱基** | A(腺嘌呤)、G(鸟嘌呤)、C(胞嘧啶)、**T(胸腺嘧啶)** | A、G、C、**U(尿嘧啶)** |
| **单体** | 脱氧核苷酸 | 核苷酸 |

#### DNA双螺旋结构

- 两条多核苷酸链反向平行，围绕同一轴螺旋
- 糖-磷酸骨架在外侧，碱基在内侧
- **碱基互补配对**：A-T（2个氢键）、G-C（3个氢键）
- 遗传信息编码在碱基序列中

#### ATP（腺苷三磷酸）

$$\text{A-P~P~P} \xrightleftharpoons{} \text{A-P~P} + \text{Pi} + \text{能量}$$
- ~ 代表高能磷酸键
- ATP是细胞生命活动的直接能量来源
- ATP-ADP循环：光合作用合成ATP → 生命活动消耗ATP → ADP + Pi

#### PCR（聚合酶链反应）

- 体外DNA扩增技术，可将微量DNA放大数百万倍
- 应用：疾病诊断、法医鉴定、考古学

## 第二部分：合成高分子

### 4. 基本概念

| 概念 | 定义 |
|------|------|
| **高分子** | Mr > 10⁴的分子（平均分子量，非单一值） |
| **单体** | 聚合反应的起始小分子 |
| **链节（重复单元）** | 高分子链中重复的结构单元 |
| **聚合度（n）** | 链节的重复次数 |
| **平均分子量** | = 链节分子量 × n |

### 5. 两种聚合方法

| 比较项 | 加聚反应 | 缩聚反应 |
|--------|---------|---------|
| 单体要求 | 含C=C双键（乙烯基型） | 含两个以上官能团（双官能团/多官能团） |
| 反应特点 | 单体直接加成，不脱去小分子 | 单体间脱去小分子（H₂O等） |
| 链节端基 | 一般不写出 | **必须写出**端基 |
| 可逆性 | 通常不可逆 | 一般可逆（移除小分子促进正向） |
| 小分子量 | 无 | 单一单体→(n-1)H₂O；两种单体→(2n-1)H₂O |
| 典型产物 | PE、PVC、PP、PS | 涤纶、锦纶、酚醛树脂 |

**加聚反应示例：**
- nCH₂=CHCl → [—CH₂—CHCl—]ₙ（PVC）
- nCH₂=CH₂ → [—CH₂—CH₂—]ₙ（PE）
- nCH≡CH → [—CH=CH—]ₙ（聚乙炔，导电高分子）

**缩聚反应示例：**
- 己二酸 + 己二胺 → [—CO(CH₂)₄CO—NH(CH₂)₆NH—]ₙ + nH₂O（尼龙66）
- 对苯二甲酸 + 乙二醇 → [—CO—C₆H₄—CO—O—CH₂CH₂—O—]ₙ + nH₂O（涤纶PET）

### 6. 高分子材料

#### 塑料

| 类型 | 结构特征 | 代表物 | 加工特点 |
|------|----------|--------|---------|
| **热塑性** | 线型/支链结构 | PE、PVC、PP、PS | 可反复加热熔化成型 |
| **热固性** | 网状/交联结构 | 酚醛树脂、环氧树脂 | 一次成型，不可再熔 |

**聚乙烯PE：**
| 类型 | 制备条件 | 密度 | 用途 |
|------|----------|------|------|
| LDPE（低密度） | 高压法（150-300 MPa） | 0.91-0.93 | 食品袋、薄膜 |
| HDPE（高密度） | 低压法（0.1-2 MPa） | 0.94-0.97 | 瓶、桶、管 |
| UHMWPE（超高分子量） | 特殊催化剂 | — | 防弹衣、绳索 |

**酚醛树脂（电木）：**
- 苯酚 + 甲醛 $\xrightarrow{\text{酸催化}}$ **线型**酚醛树脂
- 苯酚 + 甲醛 $\xrightarrow{\text{碱催化}}$ **体型（网状）**酚醛树脂（不可熔）
- 应用：电绝缘材料、电路板、航天器隔热瓦

#### 合成纤维

| 名称 | 化学名 | 单体 | 特点 |
|------|--------|------|------|
| **涤纶** | 聚对苯二甲酸乙二醇酯(PET) | 对苯二甲酸 + 乙二醇 | 产量最大的合成纤维 |
| **锦纶** | 聚酰胺(PA66) | 己二酸 + 己二胺 | 耐磨、强度高 |
| **腈纶** | 聚丙烯腈(PAN) | 丙烯腈 | 似羊毛，保暖 |
| **芳纶** | 聚对苯二甲酰对苯二胺(Kevlar) | 对苯二甲酰氯 + 对苯二胺 | 超高强度，防弹 |

#### 合成橡胶

| 名称 | 单体 | 特点 |
|------|------|------|
| 顺丁橡胶 | 1,3-丁二烯 | 耐磨，用于轮胎 |
| 丁苯橡胶 | 丁二烯 + 苯乙烯 | 综合性能好 |
| 氯丁橡胶 | 氯丁二烯 | 耐油、耐老化 |
| 硅橡胶 | 二甲基硅氧烷 | 耐高温、生物相容 |

**硫化**：线型橡胶 + S $\xrightarrow{\Delta}$ 交联网络（-S-S-键连接）→弹性和强度显著提高

**天然橡胶**：顺式-1,4-聚异戊二烯（来自橡胶树乳胶）

### 7. 功能高分子与可降解高分子

| 类型 | 示例 | 应用 |
|------|------|------|
| 分离膜 | 反渗透膜、离子交换膜 | 海水淡化、污水处理 |
| 导电高分子 | 聚乙炔（掺杂后） | 有机电子器件 |
| 医用高分子 | 聚乳酸(PLA)、聚乙二醇(PEG) | 手术缝线、药物载体 |
| 可降解高分子 | PLA、聚己内酯(PCL) | 可降解包装、环保材料 |

> **可降解高分子的意义**：传统塑料（PE/PP/PS）自然降解需数百年→白色污染。可降解高分子在微生物/光/水作用下分解为无害小分子。

## 知识拓展

### 葡萄糖的环状结构

D-葡萄糖在水溶液中存在变旋现象：
- α-D-吡喃葡萄糖（36.4%，比旋光度+112°→平衡）
- β-D-吡喃葡萄糖（63.6%，比旋光度+18.7°→平衡）
- 链状葡萄糖含量极少
- 平衡比旋光度+52.7°

开链→环状：第5号C上的-OH与醛基发生分子内半缩醛反应，醛基碳由sp²→sp³杂化，由非手性→手性碳。新生成的半缩醛羟基（苷羟基）在空间两种取向→α型和β型（差向异构体）。

霍沃思透视式写法：六元环氧原子在后方，左侧基团写上方，右侧写下方；D型羟甲基在上方，α型苷羟基与羟甲基异侧，β型同侧。

### 蛋白质的显色反应

1. **双缩脲反应**：蛋白质+碱+少量CuSO₄→紫红色配合物。多肽中肽键（-CO-NH-）与双缩脲结构相似，肽键越多颜色越深。
2. **黄色蛋白反应**：某些蛋白质+浓HNO₃→黄色（含苯环的蛋白质），加氨→橙色。
3. **茚三酮反应**：蛋白质+茚三酮→蓝/紫/紫红色。可用于氨基酸和蛋白质的层析及定量测定。

### 核酸的性质

- 糖苷键和磷酯键在酸性条件或酶催化下水解
- 含磷酸基→酸性；含氮杂环→可结合质子
- 碱基中共轭双键强烈吸收紫外光→可用紫外分光光度法定性定量
- DNA变性（氢键断裂）→复性（链重新缔合）→性质恢复
- 戊糖单元可发生显色反应

### 聚合反应的深入分类

**按反应机理分类**：

**链式聚合反应（连锁聚合）**：
- 单体均为含不饱和键的化合物
- 反应一旦引发，迅速以链式反应得到聚合物
- 经历链引发→链增长→链终止
- 产物除聚合物外无小分子副产物
- 链节组成与单体相同
- 相对分子质量瞬间增长，与反应时间几乎无关

链式聚合的引发方式：
- **自由基聚合**：过氧化苯甲酰、偶氮二异丁腈等引发剂→自由基→引发单体
- **阳离子聚合**：质子酸（H₂SO₄、HCl）或路易斯酸（AlCl₃、TiCl₄、BF₃）催化
- **阴离子聚合**：氨基钠（NaNH₂）、烷基锂（RLi）等碱性试剂催化
- **配位聚合**：齐格勒-纳塔催化剂（如TiCl₄-AlR₃）→高密度聚乙烯、导电聚乙炔

**逐步聚合反应**：
- 单体有两个或以上官能团（二羧酸、二醇、羟基酸、二胺、氨基酸等）
- 可逆反应，伴随小分子（H₂O、HX、NH₃、ROH）生成
- 相对分子质量随时间缓慢增长，达到一定值后难再增长
- 一般缩聚物相对分子质量比加聚物小

### 功能高分子

在传统高分子基础上赋予特定功能（化学活性、光/电/磁特性、催化活性、生物相容性等）。

**主要类别**：
1. 选择分离功能高分子：离子交换树脂、高分子分离膜
2. 高分子试剂：固相合成法，可重复使用
3. 催化功能高分子：模拟酶、高分子金属催化剂
4. 光活性高分子：感光树脂、光致变色高分子
5. 电学功能高分子：聚乙炔（导电高分子）、聚苯胺、聚噻吩
6. 生物医学高分子：医用材料、高分子药物
7. 形状记忆高分子：热敏型，加热恢复原形
8. 生物降解高分子：聚乳酸、淀粉基可降解材料

### 尼龙的发明

卡罗瑟斯（杜邦公司）：1928年开始研究双官能团分子缩聚反应→发现聚酯熔融物可纺丝→但100°C以下熔化、易溶于有机溶剂→转而研究聚酰胺→选择己二胺+己二酸→聚己二酰己二胺（尼龙66），1939年工业化。

合成路线：H₂N(CH₂)₆NH₂ + HOOC(CH₂)₄COOH → 盐 →[缩聚] H-[NH(CH₂)₆NHCO(CH₂)₄CO]ₙ-OH

## 竞赛衔接

- **蛋白质二级结构的氢键模型**：α-螺旋中每圈3.6个氨基酸残基，螺距0.54 nm
- **DNA杂交与变性**：温度升高→双链解开（Tm值）→冷却→可复性
- **开环聚合**：环状单体开环聚合（如己内酰胺→尼龙6）
- **活性聚合**：可控分子量和分子量分布的聚合方法（ATRP、RAFT）
- **生物可降解材料**的酶催化降解机理

## 常见易错

1. ❌ "淀粉和纤维素分子式相同，所以是同分异构体" → ✅ n值不同，分子式实际不同，不是同分异构体
2. ❌ "蔗糖是非还原糖所以不能水解" → ✅ 能水解（水解后产物有还原糖）
3. ❌ "蛋白质变性后加水可以恢复活性" → ✅ 变性不可逆，加水不能恢复
4. ❌ "加聚反应和缩聚反应都会脱去小分子" → ✅ 只有缩聚反应脱去小分子
5. ❌ "高分子的n值是固定的" → ✅ n是平均值，高分子是不同n值的混合物
6. ❌ "热塑性塑料和热固性塑料都可以反复加热成型" → ✅ 只有热塑性的可以

## 🎯 教学视角

### 教学重点与难点

| 维度 | 内容 |
|------|------|
| **重点** | 糖类/蛋白质/核酸的基本组成单元和特征反应（银镜反应、碘反应、双缩脲反应等）；加聚反应与缩聚反应的本质区别（单体要求、小分子脱去、端基处理）；蛋白质盐析与变性的可逆性差异 |
| **难点** | 淀粉与纤维素“n值不同故不是同分异构体”的理解；氨基酸两性及成肽反应的书写；单体与高分子的正向/逆向推断；热塑性塑料与热固性塑料的结构差异 |

### 建议教学路径

1. **糖类**：从“通式Cₘ(H₂O)ₙ”的局限性切入（脱氧核糖不符合、乙酸符合但不是糖）→结构定义（多羟基醛/酮）→通过银镜反应和Cu(OH)₂实验验证还原糖→淀粉遇碘变蓝→纤维素水解条件对比
2. **蛋白质**：氨基酸结构（同时含-NH₂和-COOH→两性）→成肽反应（肽键形成）→蛋白质四级结构→盐析（可逆）与变性（不可逆）的对比实验→1965年人工合成牛胰岛素的科学史
3. **核酸**：水解法逐层拆解（核酸→核苷酸→核苷→戊糖+碱基）→DNA双螺旋（碱基互补配对：A-T 2个氢键，G-C 3个氢键）→遗传信息编码
4. **高分子**：从断键成键角度建立加聚（π键断裂→新σ键，无小分子）和缩聚（官能团间脱水/脱HX）的认知模型→口罩材料（聚丙烯）引入→单体↔高分子双向推断练习→线型vs网状结构决定热塑/热固性

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| “淀粉和纤维素分子式相同所以是同分异构体” | n值不同，分子式实际不同，不是同分异构体 |
| “蔗糖是非还原糖所以不能水解” | 能水解（水解后产物有还原糖），非还原糖仅指不能发生银镜反应 |
| “蛋白质变性后加水可以恢复活性” | 变性不可逆，空间结构被永久破坏 |
| “加聚和缩聚都会脱去小分子” | 只有缩聚反应脱去小分子，加聚反应无小分子副产物 |
| “高分子的n值是固定的” | n是平均值，高分子是不同n值的混合物（多分散性） |
| “热塑性和热固性塑料都可以反复加热成型” | 只有热塑性的可以（线型结构），热固性一次成型不可再熔（网状结构） |

### 与现实世界的联系

- **食品与健康**：葡萄糖是生命活动能量来源（C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O），淀粉/纤维素是膳食中最重要的碳水化合物，纤维素制燃料乙醇是生物质能源的重要方向
- **生物技术**：PCR（聚合酶链反应）用于疾病诊断、法医鉴定、考古学；DNA双螺旋结构是分子生物学的基石
- **材料应用**：医用口罩过滤层（聚丙烯熔喷布）、防弹衣（芳纶Kevlar）、轮胎（顺丁橡胶）均为高分子材料；可降解高分子（聚乳酸PLA）是解决白色污染的关键方向
- **化学工业**：涤纶（PET）是产量最大的合成纤维，酚醛树脂（电木）是最早的人工合成塑料（1907年）
- **中国成就**：1965年人工合成结晶牛胰岛素，是世界上第一个人工合成的具有生物活性的蛋白质
