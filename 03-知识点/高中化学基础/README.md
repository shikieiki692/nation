# 高中化学基础

> 本模块是竞赛知识体系的入门层，为只有初中化学基础的学生提供衔接。
> 每个知识点都链接到对应的竞赛级KP，学完本模块后应能顺利进入竞赛学习。

## 学习路径

```
物质分类与离子反应 → 氧化还原基础 → 元素化学基础（钠氯铁）
    → 物质的量计算 → 原子结构基础 → 元素周期律 → 化学键
    → 分子结构基础 → 晶体结构基础 → 配合物基础
```
