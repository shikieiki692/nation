# 高中化学基础

> 本模块是竞赛知识体系的入门层，为只有初中化学基础的学生提供衔接。
> 每个知识点都链接到对应的竞赛级KP，学完本模块后应能顺利进入竞赛学习。
> **覆盖范围**：人教版高中化学必修一（4章）+ 必修二（4章）+ 选择性必修1·化学反应原理（4章）+ 选择性必修2·物质结构与性质（3章）+ 选择性必修3·有机化学基础（5章），共 **32个KP文件**。

## 学习路径

```
─── 基础概念 ───────────────────────────────────────
物质分类与离子反应 → 氧化还原基础
    → 物质的量计算

─── 元素化学 ───────────────────────────────────────
钠及其化合物 → 氯及其化合物 → 铁及其化合物 → 金属材料
    → 硫及其化合物 → 氮及其化合物 → 无机非金属材料

─── 物质结构 ───────────────────────────────────────
原子结构基础 → 电离能与电负性 → 元素周期律基础
    → 化学键基础 → 分子空间结构与杂化
    → 分子极性与分子间作用力
    → 晶体结构基础 → 配合物基础 → 超分子基础

─── 化学反应原理 ─────────────────────────────────
化学反应与能量基础 → 反应热与盖斯定律
    → 化学反应速率与平衡 → 水溶液中的离子平衡
    → 电化学基础

─── 有机化学 ───────────────────────────────────────
有机化合物基础 → 有机化合物分类与研究方法
    → 烃与烃的衍生物
    → 生物大分子与合成高分子
```
