# 烃与烃的衍生物

> **课标要求**：系统掌握烷烃、烯烃、炔烃、芳香烃的结构与性质，深入学习卤代烃、醇酚、醛酮、羧酸与酯的性质与转化，理解有机合成路线设计的基本方法。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

### 烃（第二章）

1. 能写出简单烷烃的结构简式和名称，能依据甲烷的结构特点、性质和取代反应规律说出烷烃的结构特点和性质，并推测烷烃发生卤代反应的产物。
2. 能依据同系物的概念写出烷烃、烯烃、炔烃和苯的同系物的通式，认识同系物主要物理性质的变化规律。
3. 能依据同分异构体的概念写出烷烃的碳架异构体，写出烯烃的碳架异构体、位置异构体和立体异构体，写出炔烃的碳架异构体和位置异构体，写出芳香烃的碳架异构体。
4. 能写出简单烯烃的结构简式，能依据乙烯的结构特点和性质说出烯烃的结构特点和性质，能依据碳碳双键官能团的加成反应、加聚反应规律写出烯烃发生加成反应、加聚反应的化学方程式。
5. 能基于官能团和共价键的类型认识乙炔的结构特点，能依据结构特点，结合实验探究认识乙炔的化学性质，能写出乙炔的燃烧、加成和加聚反应的化学方程式，能写出简单炔烃的结构简式。
6. 能基于苯环的大π键认识苯的结构特点，能说出苯的取代反应和加成反应的规律，并能将反应规律与苯的结构特点相联系，写出相应反应的化学方程式。
7. 能写出简单的苯的同系物的结构简式，能基于苯与甲苯的化学性质，通过对比认识苯的同系物分子中基团的相互作用。

### 烃的衍生物（第三章）

8. 能辨识卤代烃中的碳卤键，能从官能团和化学键的角度认识卤代烃的取代反应（水解反应、醇解反应）和消去反应，能写出相应的化学方程式。
9. 能辨识醇和酚中的羟基，能从分子结构的角度认识醇、酚化学性质的异同，能说出醇、酚的主要用途。
10. 能辨识醛基和酮羰基，能从官能团和化学键的角度认识醛、酮的加成反应和氧化反应，能说出醛、酮的主要用途。
11. 能辨识羧基和酯基，能从官能团和化学键的角度认识羧酸、酯的主要化学性质，能说出羧酸、酯的主要用途。
12. 能基于官能团的转化和化学键的断裂与形成，设计简单的有机合成路线。

## 第一部分：烃

### 1. 烷烃

**通式** CₙH₂ₙ₊₂，全部sp³杂化，全部σ键。

**IUPAC系统命名法：**
1. 选最长碳链为主链
2. 从离支链最近的一端开始编号
3. 写出支链位置和名称
4. 相同支链用中文数字合并

**示例：** CH₃-CH(CH₃)-CH₂-CH₃ → 2-甲基丁烷

**同系物性质递变规律：**

| 性质 | 变化趋势 |
|------|----------|
| 熔沸点 | 随碳数增加而升高（分子间作用力增大） |
| 密度 | 随碳数增加而增大（趋近0.8 g/cm³） |
| 溶解性 | 均不溶于水，溶于有机溶剂 |
| 状态 | C₁-C₄气态→C₅-C₁₆液态→C₁₇+固态 |

### 2. 烯烃与炔烃

#### 烯烃（C=C双键）

**结构特征：** sp²杂化，平面结构，键角~120°。C=C中含1σ + 1π键。

![乙烯分子结构](人教版高中化学课本/【5】人教版·化学选择性必修3有机化学基础_images/8c46e0a4e4791f536a3acc56a4b90b2c2c7622299923bf27c5d0ab396a18fcb0.jpg)
*图：乙烯分子结构示意图——C=C双键由1个σ键和1个π键组成，键角120°*

**核心反应：**

| 反应类型 | 方程式示例 | 条件 |
|----------|-----------|------|
| **加成反应** | CH₂=CH₂ + Br₂ → CH₂BrCH₂Br | 溴的CCl₄溶液褪色 |
| | CH₂=CH₂ + HCl → CH₃CH₂Cl | 催化剂 |
| | CH₂=CH₂ + H₂O → CH₃CH₂OH | 催化剂,加热加压 |
| | CH₂=CH₂ + H₂ → CH₃CH₃ | Ni催化剂,加热 |
| **加聚反应** | nCH₂=CH₂ → [—CH₂—CH₂—]ₙ | 催化剂 |
| **氧化反应** | 被酸性KMnO₄氧化→褪色 | 用于鉴别 |

**马尔科夫尼科夫规则（Markovnikov规则）：**
不对称烯烃与HX加成时，H加在含H较多的碳上，X加在含H较少的碳上。
$$\text{CH}_3\text{CH=CH}_2 + \text{HBr} \rightarrow \text{CH}_3\text{CHBrCH}_3 \text{（主产物，2-溴丙烷）}$$

**顺反异构（几何异构）：**
产生条件：C=C双键两端碳各连接两个不同的基团。
- 顺式（cis）：相同基团在同侧
- 反式（trans）：相同基团在异侧
- 例：顺-2-丁烯（mp -138.9°C，bp 3.7°C）vs 反-2-丁烯（mp -105.5°C，bp 0.9°C）

**共轭二烯（1,3-丁二烯）：**
- **1,2-加成**：加在其中一个双键上
- **1,4-加成**：加在共轭体系两端（中间形成新双键）
- 两种产物为竞争产物

#### 炔烃（C≡C三键）

**结构特征：** sp杂化，直线形，键角180°。C≡C中含1σ + 2π键。

**乙炔实验室制法：**
$$\text{CaC}_2 + 2\text{H}_2\text{O} \rightarrow \text{Ca(OH)}_2 + \text{C}_2\text{H}_2\uparrow$$
- 用饱和NaCl溶液代替水→减缓反应速率
- 气体通过CuSO₄溶液→除去H₂S等杂质

**乙炔的加成（可逐步加成）：**
```
C₂H₂ + Br₂ → CHBr=CHBr  (第一步加成，生成1,2-二溴乙烯)
CHBr=CHBr + Br₂ → CHBr₂-CHBr₂  (第二步加成，生成1,1,2,2-四溴乙烷)

C₂H₂ + H₂O → CH₃CHO  (水合加成，产物为乙醛)
```

**炔烃的燃烧：** 含碳量高→火焰明亮有浓烟（如乙炔C₂H₂含碳92.3%）

### 3. 芳香烃

#### 苯（C₆H₆）

**结构核心：**
- 平面正六边形，6个C均为sp²杂化
- 6个C-C键完全等同（键长139 pm，介于单键154 pm和双键134 pm之间）
- 离域大π键（6个p轨道侧面重叠形成）

**关键实验：**
- **实验2-1**：苯 + 酸性KMnO₄ → **不褪色**（与烯烃不同）
- 苯 + 溴水 → **不反应**（无催化剂时不发生加成）

> **苯的化学性质特征：** 以**取代反应**为主，不易发生加成反应（因大π键稳定，破坏需大量能量）。

**苯的取代反应：**

| 反应 | 方程式 | 条件 |
|------|--------|------|
| 卤代 | C₆H₆ + Br₂ $\xrightarrow{\text{FeBr}_3}$ C₆H₅Br + HBr | FeBr₃催化 |
| 硝化 | C₆H₆ + HNO₃ $\xrightarrow{\text{浓H}_2\text{SO}_4, 50\text{-}60°\text{C}}$ C₆H₅NO₂ + H₂O | 水浴加热 |
| 磺化 | C₆H₆ + H₂SO₄ $\xrightarrow{70\text{-}80°\text{C}}$ C₆H₅SO₃H + H₂O | |

**苯的加成反应：**
$$\text{C}_6\text{H}_6 + 3\text{H}_2 \xrightarrow{\text{Ni, 加热}} \text{C}_6\text{H}_{12}\text{（环己烷）}$$

#### 甲苯及苯的同系物

**通式** CₙH₂ₙ₋₆（n≥6）

**苯环与侧链的互活效应：**
- **甲基活化苯环**→甲苯比苯更容易发生取代反应（邻/对位定位）
- **苯环活化甲基**→甲苯的甲基比乙烷的甲基更活泼

**实验2-2**：甲苯使酸性KMnO₄褪色（苯不能）→甲基被氧化为-COOH

**TNT合成：**
$$\text{C}_6\text{H}_5\text{CH}_3 + 3\text{HNO}_3 \xrightarrow{\text{浓H}_2\text{SO}_4} \text{2,4,6-三硝基甲苯(TNT)} + 3\text{H}_2\text{O}$$

## 第二部分：烃的衍生物

### 4. 卤代烃

**性质：** 不溶于水，溶于有机溶剂。密度比相应烃大。

**溴乙烷的两类反应：**

![溴乙烷分子模型](人教版高中化学课本/【5】人教版·化学选择性必修3有机化学基础_images/a50188501e82bb815db3cb2da58bc111fb543e30558f56f0a7104810ba86969b.jpg)
*图：溴乙烷(CH₃CH₂Br)分子球棍模型——红色为Br原子*

| 反应类型 | 条件 | 方程式 | 产物特征 |
|----------|------|--------|----------|
| **取代（水解）** | NaOH水溶液, 加热 | CH₃CH₂Br + NaOH → CH₃CH₂OH + NaBr | 生成醇 |
| **消去** | NaOH醇溶液, 加热 | CH₃CH₂Br + NaOH → CH₂=CH₂↑ + NaBr + H₂O | 生成烯 |

> **⚠️ 关键区别**：NaOH水溶液→取代（水解）；NaOH醇溶液→消去。条件不同，产物完全不同。

**消去反应定义：** 有机物分子中脱去小分子（H₂O、HX等），生成不饱和化合物的反应。

**Br⁻的检验：** 先加NaOH水溶液加热水解→加HNO₃酸化→加AgNO₃→浅黄色AgBr沉淀

### 5. 醇与酚

#### 醇（以乙醇为例）

**物理性质：** 无色液体，bp 78.5°C，与水混溶（氢键作用）。

**核心反应：**

| 反应 | 方程式 | 断键位置 |
|------|--------|---------|
| 与Na | 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑ | O-H键断裂 |
| 催化氧化 | 2C₂H₅OH + O₂ $\xrightarrow{\text{Cu}}$ 2CH₃CHO + 2H₂O | O-H键和α-C-H键断裂 |
| 消去（分子内脱水） | C₂H₅OH $\xrightarrow{\text{浓H}_2\text{SO}_4, 170°\text{C}}$ CH₂=CH₂ + H₂O | C-O键和β-C-H键断裂 |
| 分子间脱水 | 2C₂H₅OH $\xrightarrow{\text{浓H}_2\text{SO}_4, 140°\text{C}}$ C₂H₅OC₂H₅ + H₂O | C-O键和O-H键断裂 |
| 与HBr取代 | C₂H₅OH + HBr $\xrightarrow{\Delta}$ C₂H₅Br + H₂O | C-O键断裂 |

> **实验3-2**：乙醇消去制乙烯——浓H₂SO₄与乙醇加热到170°C→气体通过NaOH溶液（除SO₂）→通入KMnO₄/溴水→褪色。

#### 酚（以苯酚为例）

| 性质 | 说明 |
|------|------|
| 弱酸性 | C₆H₅OH + NaOH → C₆H₅ONa + H₂O（但酸性弱于H₂CO₃） |
| 溴代反应 | C₆H₅OH + 3Br₂ → 2,4,6-三溴苯酚↓(白) + 3HBr（极灵敏） |
| FeCl₃显色 | C₆H₅OH + FeCl₃ → 紫色（酚类特征反应） |

> **基团互活效应**：苯环使O-H极性增大（酚比醇酸性强）；-OH活化苯环（酚比苯更容易发生取代反应）。

### 6. 醛与酮

#### 醛（以乙醛为例）

| 反应 | 方程式 | 说明 |
|------|--------|------|
| **银镜反应** | CH₃CHO + 2[Ag(NH₃)₂]OH $\xrightarrow{\Delta}$ CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O | 检验醛基 |
| **与Cu(OH)₂** | CH₃CHO + 2Cu(OH)₂ + NaOH $\xrightarrow{\Delta}$ CH₃COONa + Cu₂O↓(砖红) + 3H₂O | 检验醛基 |
| 催化加氢 | CH₃CHO + H₂ $\xrightarrow{\text{Ni}}$ CH₃CH₂OH | 还原（醛→醇） |
| 空气氧化 | 2CH₃CHO + O₂ $\xrightarrow{\text{催化剂}}$ 2CH₃COOH | 氧化（醛→酸） |

> **醛的特征**：既能被氧化（→羧酸）又能被还原（→醇），处于氧化态中间。

#### 酮（以丙酮为例）

- CH₃COCH₃，bp 56.2°C，与水混溶
- **酮不能发生银镜反应**（不能被弱氧化剂氧化）→ 与醛的关键区别
- 可催化加氢：CH₃COCH₃ + H₂ → CH₃CH(OH)CH₃（仲醇）

### 7. 羧酸与酯

#### 羧酸

| 性质 | 说明 |
|------|------|
| 弱酸性 | 能与Na、NaOH、Na₂CO₃、NaHCO₃反应 |
| 酸性排序 | CH₃COOH > H₂CO₃ > C₆H₅OH |

**甲酸（HCOOH）的特殊性：** 结构中同时含-COOH和-CHO→既有酸性又能发生银镜反应。

#### 酯化反应

$$\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \xrightleftharpoons{\text{浓H}_2\text{SO}_4, \Delta} \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}$$

**¹⁸O同位素示踪机理：** 酸脱-OH，醇脱-H（形成H₂¹⁸O）。

#### 酯的水解

| 条件 | 方程式 | 特点 |
|------|--------|------|
| 酸性 | CH₃COOC₂H₅ + H₂O $\xrightleftharpoons{\text{H}^+}$ CH₃COOH + C₂H₅OH | 可逆 |
| 碱性 | CH₃COOC₂H₅ + NaOH → CH₃COONa + C₂H₅OH | 不可逆（皂化反应） |

#### 油脂（高级脂肪酸甘油酯）

- **皂化反应**：油脂 + NaOH → 甘油 + 脂肪酸钠（肥皂）
- **硬化（氢化）**：液态植物油 + H₂ → 固态脂肪（人造黄油）

### 8. 有机合成路线设计

#### 核心思路

| 方法 | 说明 |
|------|------|
| **正向分析** | 从原料出发→逐步构建碳骨架→引入官能团→目标产物 |
| **逆合成分析** | 从目标产物出发→断键识别前体→逐步倒推→到简单原料 |

**逆合成符号**：用双线箭头"⇒"表示逆向步骤。

#### 碳骨架构建

| 策略 | 方法 | 示例 |
|------|------|------|
| 碳链增长 | 炔烃/醛 + HCN → 水解得酸或还原得胺 | 增加1个碳 |
| | 羟醛缩合（含α-H的醛→β-羟基醛→α,β-不饱和醛） | 增加碳链 |
| 碳链缩短 | 酸性KMnO₄氧化烯/炔/芳烃侧链 | C=C→断裂为羧酸 |
| 成环 | Diels-Alder反应（共轭二烯 + 烯亲体→环状产物） | 构建六元环 |

#### 官能团保护

当分子中有多个官能团时，反应可能影响非目标官能团→先将非目标基团"保护"（如-OH→醚）→反应→再去保护。

## 知识拓展

### 苯的结构与反应机理

**芳香亲电取代反应机理**（以硝化为例）：
1. 硝酸在浓硫酸作用下产生硝基正离子（NO₂⁺）：HONO₂ + 2H₂SO₄ ⇌ H₃O⁺ + NO₂⁺ + 2HSO₄⁻
2. NO₂⁺进攻苯环形成中间体碳正离子（σ配合物）
3. 质子转移：中间体碳正离子将质子转给HSO₄⁻，恢复芳香性，生成硝基苯

**取代基定位效应**：
- 邻、对位定位基（致活）：-OH、-NH₂、-OR、-CH₃、-CR₃等（给电子效应）
- 邻、对位定位基（致钝）：-F、-Cl、-Br、-I（吸电子诱导 > 给电子共轭）
- 间位定位基（致钝）：-COR、-CHO、-COOH、-COOR、-CN、-NO₂、-SO₃H等（吸电子效应）

### 自由基取代反应机理

甲烷氯代反应（自由基型）：
- 链引发：Cl₂ →[光照] 2Cl·（共价键均裂）
- 链转移：Cl· + CH₄ → ·CH₃ + HCl；·CH₃ + Cl₂ → CH₃Cl + Cl·（循环）
- 链终止：自由基碰撞结合，反应物浓度减小后反应结束

碳自由基稳定性：R₃C· > R₂CH· > RCH₂· > CH₃·

### 烯烃加成反应机理

**离子型亲电加成**（与氢卤酸）：
1. HX → H⁺ + X⁻（共价键异裂）
2. CH₂=CH₂ + H⁺ → CH₃CH₂⁺（慢，速率控制步骤）
3. CH₃CH₂⁺ + X⁻ → CH₃CH₂X（快）

**马尔可夫尼可夫规则**：不对称烯烃与HX加成时，卤原子加到含氢较少的碳原子上（形成更稳定的碳正离子）。碳正离子稳定性：R₃C⁺ > R₂CH⁺ > RCH₂⁺ > CH₃⁺

**反马氏规则**：在过氧化物存在下，丙烯与HBr发生自由基加成，主要产物为1-溴丙烷（因2°碳自由基更稳定）。

### 卤代烃与AgNO₃反应的机理

溴乙烷中C-Br为极性键（Cᵟ⁺-Brᵟ⁻），Ag⁺与Br结合生成AgBr沉淀，促进亲核取代：

- **Sₙ2机理**（双分子亲核取代）：水直接进攻碳原子，同步断裂C-Br
- **Sₙ1机理**（单分子亲核取代）：Ag⁺使C-Br断裂形成碳正离子，NO₃⁻进攻

加入Ag⁺后取代产物主要是硝酸乙酯（CH₃CH₂ONO₂），而非乙醇。叔丁基溴与AgNO₃主要发生Sₙ1反应，溴乙烷水解几乎都是Sₙ2反应。

### 酯化反应机理（加成-消除机理）

1. 羰基氧原子质子化
2. 醇羟基氧原子亲核进攻质子化羰基碳
3. 质子转移后失水生成酯

同位素标记实验：用CH₃CO¹⁸OH标记，¹⁸O可留在酯中也可能不在（因中间体两个羟基等价）→需用CH₃C(=O)¹⁸OH标记醇才能验证"酸脱羟基醇脱氢"。

### 醛基C=O不与Br₂加成的原因

碳氧双键发生**亲核加成**，碳碳双键发生**亲电加成**。Br₂是强亲电试剂，易与烯烃加成，不能与醛加成。乙醛使溴水褪色是**氧化反应**：CH₃CHO + Br₂ + H₂O → CH₃COOH + 2HBr

## 竞赛衔接

- **亲核取代SN1 vs SN2**：SN1（碳正离子机理，叔卤代烃）vs SN2（背面进攻，伯卤代烃）
- **消除E1 vs E2**：单分子消除 vs 双分子消除
- **Markovnikov规则的本质**：碳正离子稳定性（叔 > 仲 > 伯）
- **Diels-Alder反应**的区域选择性和立体选择性
- **Woodward合成**、**Corey逆合成分析**的经典案例

## 常见易错

1. ❌ "苯可以使溴水褪色" → ✅ 苯能萃取溴水中的Br₂（物理变化，上层橙红色），但不能化学反应褪色
2. ❌ "乙醇消去制乙烯只需加热即可" → ✅ 必须控制170°C（140°C生成乙醚）
3. ❌ "卤代烃的水解和消去可以同时进行" → ✅ 条件不同：水溶液→水解，醇溶液→消去
4. ❌ "酯化反应中浓H₂SO₄只催化不参与" → ✅ 浓H₂SO₄同时作催化剂和吸水剂
5. ❌ "银镜反应后直接倒掉废液" → ✅ 银是贵金属，应回收
6. ❌ "酚和醇的-OH性质相同" → ✅ 酸性差异很大（酚能与NaOH反应，醇不能）

## 🎯 教学视角

### 教学重点与难点

| 维度 | 内容 |
|------|------|
| **重点** | “结构决定性质”的有机化学核心思想；烃→卤代烃→醇→醛→羧酸→酯的官能团转化链；各类烃（烷/烯/炔/芳香）的结构特征与反应性差异；卤代烃水解与消去的条件控制 |
| **难点** | Markovnikov规则的理解与应用；苯环取代反应的条件差异（FeBr3催化卤代 vs 浓H2SO4/浓HNO3硝化）；酯化反应“酸脱羟基醇脱氢”的机理；逆合成分析的思维逻辑 |

### 建议教学路径

1. **烃类**：以甲烷为模型认识烷烃（结构相似→性质相似）→迁移到烯烃/炔烃（从官能团C=C/C≡C和化学键类型出发）→芳香烃（大π键→取代为主，基团互活效应）
2. **卤代烃**：作为连接烃和烃的衍生物的桥梁，对比NaOH水溶液（水解→醇）和NaOH醇溶液（消去→烯），强调条件控制对产物的决定性影响
3. **醇酚醛酮羧酸酯**：以“官能团转化链”为主线，从-OH极性分析预测反应→构建“醇→醛→酸→酯”转化关系模型→用银镜反应、酯化反应等实验验证
4. **有机合成**：从正向分析（原料→目标产物）和逆合成分析（目标产物→前体）两条路径理解合成路线设计

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| “苯可以使溴水褪色” | 苯只能萃取Br₂（物理变化），不能化学反应褪色；需Br₂蒸气+FeBr₃催化剂才能反应 |
| “乙醇消去制乙烯只需加热” | 必须控制170°C（140°C生成乙醚），温度决定产物 |
| “卤代烃的水解和消去可以同时进行” | 条件完全不同：水溶液→水解，醇溶液→消去 |
| “酯化反应中浓H₂SO₄只作催化剂” | 同时作催化剂和吸水剂（促进平衡正移） |
| “酚和醇的-OH性质相同” | 酸性差异极大（酚能与NaOH反应，醇不能），源于苯环的p-π共轭效应 |
| “银镜反应后直接倒掉废液” | 银是贵金属，应回收 |

### 与现实世界的联系

- **石化工业**：乙烯是石油化工产量最大的基础原料，烷烃裂解获得三烯（乙烯、丙烯、丁二烯）、三苯（苯、甲苯、二甲苯）等基本化工原料
- **日用化学品**：乙酸乙酯用作溶剂和香精，肥皂是油脂皂化的产物（脂肪酸钠+甘油）
- **食品工业**：食用酒精的蒸馏提纯、食品级乙酸乙酯的制备、真假酒鉴别（甲醇检测）
- **安全常识**：乙炔爆炸极限3%~81%，液态乙炔震动即分解爆炸，需丙酮溶解后储存在钢瓶中
