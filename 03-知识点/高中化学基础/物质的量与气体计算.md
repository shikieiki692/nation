# 物质的量与气体计算

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

5. 能认识物质的量在化学定量研究中的重要作用，能运用物质的量、摩尔质量、气体摩尔体积、物质的量浓度之间的相互关系进行简单计算。

## 核心概念

### 物质的量（n）

物质的量是国际单位制中七个基本物理量之一，单位为**摩尔（mol）**。1 mol任何粒子的集合体所含的粒子数等于阿伏加德罗常数 Nₐ ≈ 6.022 × 10²³ mol⁻¹。

*图：1 mol不同物质的质量——虽然质量不同，但所含粒子数均为6.02×10²³*

核心关系式：

n = N / Nₐ = m / M

- N：粒子数
- m：质量（g）
- M：摩尔质量（g/mol），数值上等于相对分子质量或相对原子质量

### 气体摩尔体积

在**标准状况（STP，0°C，101.3 kPa）**下，1 mol任何气体的体积约为22.4 L。即：

Vₘ = V / n = 22.4 L/mol（标准状况）

使用条件：

1. 必须是气体（标准状况下水是液体，不能用22.4 L/mol）
2. 必须在标准状况下（常温常压下22.4 L/mol不成立）
3. 混合气体同样适用（只要总物质的量正确）

### 物质的量浓度（c）

物质的量浓度定义为单位体积溶液中所含溶质的物质的量：

c = n / V

- c的单位：mol/L
- V是**溶液体积**（不是溶剂体积）
- n是溶质的物质的量（不是溶剂）

### 稀释公式

稀释前后溶质的物质的量不变：

c₁V₁ = c₂V₂

此公式适用于将浓溶液稀释为稀溶液的计算。

### 质量分数与物质的量浓度的换算

c = 1000ρω / M

- ρ：溶液密度（g/mL）
- ρ：溶液密度（g/cm³）
- ω：质量分数（小数形式）
- M：溶质摩尔质量（g/mol）
- 系数1000用于单位换算

### 理想气体状态方程基础

对于气体，物质的量与温度、压强、体积之间的关系：

PV = nRT

- P：压强（Pa或atm）
- V：体积（L或m³）
- n：物质的量（mol）
- R：理想气体常数，R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K)
- T：热力学温度（K），T(K) = t(°C) + 273.15

标准状况下：P = 101.3 kPa，T = 273.15 K，代入可得Vₘ = 22.4 L/mol。

利用PV = nRT可以进行非标准状况下的气体计算，比仅用22.4 L/mol更灵活。

### 阿伏加德罗定律

同温同压下，相同体积的任何气体含有相同数目的分子。

推论：

- 同T同P：V₁/V₂ = n₁/n₂
- 同T同V：P₁/P₂ = n₁/n₂
- 同T同P：ρ₁/ρ₂ = M₁/M₂

## 关键实验

### 实验活动1：配制一定物质的量浓度的溶液
- **目的**：学会配制一定物质的量浓度的溶液，理解物质的量浓度的概念，掌握容量瓶的使用方法
- **关键操作**：计算所需溶质质量 → 用电子天平称量 → 在烧杯中加适量蒸馏水溶解 → 冷却至室温 → 用玻璃棒引流转移至容量瓶 → 洗涤烧杯和玻璃棒2~3次，洗涤液转入容量瓶 → 加蒸馏水至刻度线附近 → 改用胶头滴管逐滴加至凹液面最低处与刻度线相切 → 摇匀
- **预期现象**：配制得到的溶液浓度与目标浓度一致（可通过其他方法验证）
- **注意事项**：
  - 溶解放热的物质（如NaOH）必须冷却至室温后再转移（热胀冷缩影响体积精度）
  - 转移时用玻璃棒引流，洗涤液必须全部转入容量瓶（保证溶质全部转移）
  - 定容时视线应与凹液面最低处相切（仰视偏低、俯视偏高）
  - 摇匀后液面略有下降属正常现象（部分溶液润湿瓶塞和瓶颈），不需要再加水
  - 容量瓶使用前需检漏：加水→塞紧瓶塞→倒转→观察是否漏水→旋转瓶塞180°→再倒转检查

## 知识拓展

### 摩尔定义的演变

**1971年：** 第14届国际计量大会（CGPM）将"摩尔"列为国际单位制（SI）第七个基本物理量，定义为：摩尔是一系统的物质的量，该系统中所含的基本单元数与0.012 kg碳-12的原子数目相等。此时阿伏加德罗常数Nₐ是一个需要实验测定的量。

**2018年：** 第26届CGPM通过了SI基本单位的重新定义，摩尔的定义修改为：摩尔是物质的量的单位，所含基本单元数恰好为6.02214076×10²³个。这是SI单位历史上首次通过**固定基本常数**（而非物质参考标准）来定义单位。

**新定义的核心变化：**
- 阿伏加德罗常数被固定为精确值：Nₐ = 6.02214076×10²³ mol⁻¹
- 不再依赖碳-12的质量标准
- 摩尔质量的数值不再精确等于相对分子质量（但差值极小，日常使用可忽略）
- 使SI七个基本单位全部建立在物理常数基础上，更加普适和稳定

**新旧对比：**

| | 1971年定义 | 2018年定义 |
|---|---|---|
| 基准 | 0.012 kg ¹²C含有的原子数 | 固定Nₐ = 6.02214076×10²³ mol⁻¹ |
| Nₐ | 需实验测定 | 精确固定值 |
| 日常计算 | 无影响 | 无影响 |
| 高精度计量 | 存在不确定性 | 无不确定性 |

## 竞赛衔接

- PV = nRT的灵活应用是竞赛气体计算的基础，包括混合气体、分压定律等
- 竞赛中常考非标准状况下气体体积的计算
- 阿伏加德罗定律的推论在确定气体分子式中有重要应用

## 常见易错

1. **22.4 L/mol只能用于标准状况下的气体**：常温常压（25°C, 101.3 kPa）下1 mol气体体积约24.5 L，不能用22.4 L/mol
2. **物质的量浓度中的V是溶液体积**：配制100 mL 1 mol/L NaCl溶液，取5.85 g NaCl加水至100 mL，不是加100 mL水
3. **SO₃在标准状况下不是气体**：SO₃熔点16.8°C，沸点44.8°C，标准状况下是固体，不能用22.4 L/mol计算

## 🎯 教学视角

### 教学重点与难点
- **重点**：物质的量、摩尔质量、气体摩尔体积、物质的量浓度的概念与相互关系；22.4 L/mol的适用条件；物质的量浓度溶液的配制操作
- **难点**：标准状况与常温常压下气体体积的区分；浓度c=n/V中V是溶液体积而非溶剂体积；质量分数与物质的量浓度的换算

### 建议教学路径
- 为分散学习难点，教材将物质的量安排在钠和氯的学习之后，引导学生从定量角度再认识物质性质和化学反应
- 注重宏观与微观相结合，建立可称量的宏观物质与不可称量的微观粒子间的联系（n=N/Nₐ=m/M）
- 通过容量瓶的创造性设计教学，让学生从实验需求出发自主设计仪器，体会仪器设计的巧妙
- 以化学方程式计算应用为载体，从宏观（质量关系）和微观（微粒数目）两个角度引入，但把握要求，不要过度强化计算

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 22.4 L/mol在任何条件下都适用 | 只在标准状况（0°C，101.3 kPa）下适用于气体，常温常压下1 mol气体约24.5 L | 强调使用22.4 L/mol的三个前提：标准状况、气体、1 mol |
| 浓度c = n/V中的V是溶剂体积 | V必须是溶液体积，配制溶液时是加水至指定体积，而非加入指定体积的水 | 通过容量瓶操作演示：加水至刻度线，而非量取一定体积的水 |
| SO₃在标准状况下是气体 | SO₃熔点16.8°C，标准状况下是固体，不能用22.4 L/mol计算 | 记忆常见物质在标准状况下的状态，SO₃、H₂O、己烷等常温下非气态的物质需特别注意 |

### 与现实世界的联系
- 医院输液中各种药物的浓度精确到小数点后，物质的量浓度计算是药剂师的基本功
- 汽车安全气囊中叠氮化钠（NaN₃）的分解产生N₂气体，通过PV=nRT计算所需NaN₃的质量以充满气囊
- 环境监测中气体污染物（如SO₂、NOₓ）的浓度检测和排放标准制定，都依赖物质的量浓度的精确计算
- 工业生产中原料配比、产品纯度控制等都以物质的量为基础进行定量分析
