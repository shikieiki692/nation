# 物质的量与气体计算

## 核心概念

### 物质的量（n）

物质的量是国际单位制中七个基本物理量之一，单位为**摩尔（mol）**。1 mol任何粒子的集合体所含的粒子数等于阿伏加德罗常数 Nₐ ≈ 6.022 × 10²³ mol⁻¹。

核心关系式：

n = N / Nₐ = m / M

- N：粒子数
- m：质量（g）
- M：摩尔质量（g/mol），数值上等于相对分子质量或相对原子质量

### 气体摩尔体积

在**标准状况（STP，0°C，101.3 kPa）**下，1 mol任何气体的体积约为22.4 L。即：

Vₘ = V / n = 22.4 L/mol（标准状况）

使用条件：

1. 必须是气体（标准状况下水是液体，不能用22.4 L/mol）
2. 必须在标准状况下（常温常压下22.4 L/mol不成立）
3. 混合气体同样适用（只要总物质的量正确）

### 物质的量浓度（c）

物质的量浓度定义为单位体积溶液中所含溶质的物质的量：

c = n / V

- c的单位：mol/L
- V是**溶液体积**（不是溶剂体积）
- n是溶质的物质的量（不是溶剂）

### 稀释公式

稀释前后溶质的物质的量不变：

c₁V₁ = c₂V₂

此公式适用于将浓溶液稀释为稀溶液的计算。

### 质量分数与物质的量浓度的换算

c = 1000ρω / M

- ρ：溶液密度（g/mL）
- ρ：溶液密度（g/cm³）
- ω：质量分数（小数形式）
- M：溶质摩尔质量（g/mol）
- 系数1000用于单位换算

### 理想气体状态方程基础

对于气体，物质的量与温度、压强、体积之间的关系：

PV = nRT

- P：压强（Pa或atm）
- V：体积（L或m³）
- n：物质的量（mol）
- R：理想气体常数，R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K)
- T：热力学温度（K），T(K) = t(°C) + 273.15

标准状况下：P = 101.3 kPa，T = 273.15 K，代入可得Vₘ = 22.4 L/mol。

利用PV = nRT可以进行非标准状况下的气体计算，比仅用22.4 L/mol更灵活。

### 阿伏加德罗定律

同温同压下，相同体积的任何气体含有相同数目的分子。

推论：

- 同T同P：V₁/V₂ = n₁/n₂
- 同T同V：P₁/P₂ = n₁/n₂
- 同T同P：ρ₁/ρ₂ = M₁/M₂

## 竞赛衔接

- PV = nRT的灵活应用是竞赛气体计算的基础，包括混合气体、分压定律等
- 竞赛中常考非标准状况下气体体积的计算
- 阿伏加德罗定律的推论在确定气体分子式中有重要应用

## 常见易错

1. **22.4 L/mol只能用于标准状况下的气体**：常温常压（25°C, 101.3 kPa）下1 mol气体体积约24.5 L，不能用22.4 L/mol
2. **物质的量浓度中的V是溶液体积**：配制100 mL 1 mol/L NaCl溶液，取5.85 g NaCl加水至100 mL，不是加100 mL水
3. **SO₃在标准状况下不是气体**：SO₃熔点16.8°C，沸点44.8°C，标准状况下是固体，不能用22.4 L/mol计算
