# 反应热与盖斯定律

> **课标要求**：理解反应热、焓变的概念，掌握热化学方程式的书写规则，理解燃烧热和中和热的定义，掌握盖斯定律及其应用。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能从体系和环境的角度认识反应热的概念。
2. 能利用简易量热计测定中和反应的反应热。
3. 能从体系内能变化的角度认识反应热。
4. 能从化学键断裂和形成时的能量变化认识反应热的微观实质。
5. 能用热化学方程式表示反应热。
6. 能根据热化学方程式、盖斯定律等计算反应热。
7. 能结合燃烧热、反应热的计算等体会研究反应热的价值。

## 核心概念

### 1. 焓与焓变

#### 基本概念

| 概念 | 定义 |
|------|------|
| **体系** | 反应物、生成物和反应本身构成的整体 |
| **环境** | 体系以外的一切（容器、空气等） |
| **内能（U）** | 体系中所有物质的总能量 |
| **焓（H）** | H = U + pV，等压条件下反应热等于焓变 |
| **焓变（ΔH）** | ΔH = H(产物) - H(反应物)，单位 kJ/mol |

#### 符号约定

| ΔH | 类型 | 微观解释 |
|-----|------|----------|
| ΔH < 0 | 放热反应 | 成键释放能量 > 断键吸收能量 |
| ΔH > 0 | 吸热反应 | 断键吸收能量 > 成键释放能量 |

**微观本质（键能法）：**
$$\Delta H = \sum E(\text{反应物键能}) - \sum E(\text{产物键能})$$

**经典计算——H₂(g) + Cl₂(g) = 2HCl(g)：**
- 断键吸收：E(H-H) + E(Cl-Cl) = 436 + 243 = 679 kJ
- 成键释放：2 × E(H-Cl) = 2 × 431 = 862 kJ
- ΔH = 679 - 862 = **-183 kJ/mol**（与实验值-184.6 kJ/mol接近）

![H₂+Cl₂反应能量变化示意图：断键吸收436+243 kJ，成键释放2×431 kJ](../人教版高中化学课本/【3】人教版·化学选择性必修1化学反应原理_images/b714266f244a75bc3d7de09acdd3d83b62ed5e8538b6bc69a5a9cea830417ffc.jpg)
*图：H₂ + Cl₂ → 2HCl的能量变化——断键吸收679 kJ，成键释放862 kJ*

> **竞赛衔接**：精确值与键能法计算的偏差来源于键能是气态平均值，且忽略了分子间作用力和零点能。

### 2. 热化学方程式

**定义：** 标明反应热的化学方程式。

**书写规则（6条）：**

1. **注明温度和压强**（默认25°C、101 kPa可不标）
2. **标明所有物质的聚集状态**：(g)气态、(l)液态、(s)固态、(aq)水溶液
3. **化学计量数可以是整数或分数**
4. **ΔH必须与方程式一一对应**（计量数加倍，ΔH也加倍）
5. **ΔH写在方程式右侧**，放热"-"，吸热"+"
6. **单位为kJ/mol**（"每摩尔反应"）

**示例对比：**

```
H₂(g) + ½O₂(g) = H₂O(l)    ΔH = -285.8 kJ/mol
2H₂(g) + O₂(g) = 2H₂O(l)   ΔH = -571.6 kJ/mol   ← ΔH也×2
H₂(g) + ½O₂(g) = H₂O(g)    ΔH = -241.8 kJ/mol   ← 气态水ΔH不同
```

> **⚠️ 关键**：H₂O(g)与H₂O(l)的ΔH相差约44 kJ/mol（水的汽化热）。聚集状态写错会导致ΔH错误。

### 3. 燃烧热

**定义：** 在101 kPa下，**1 mol**物质**完全燃烧**生成**指定产物**时放出的热量。

**指定产物（必须记住）：**
- C → **CO₂(g)**
- H → **H₂O(l)**（不是气态！）
- S → **SO₂(g)**
- N → **N₂(g)**

**常见燃烧热数据（25°C, 101 kPa）：**

| 物质 | ΔH (kJ/mol) | 注意 |
|------|-------------|------|
| H₂(g) | -285.8 | 产物H₂O(l) |
| C(s,石墨) | -393.5 | 产物CO₂(g) |
| CO(g) | -283.0 | |
| CH₄(g) | -890.3 | |
| C₂H₅OH(l) | -1366.8 | |
| C₈H₁₈(l) | -5518 | 汽油主要成分 |

> **⚠️ 易错**：燃烧热中H₂O必须是(l)态，若写成(g)态则ΔH数值偏小（放出热量少44 kJ）。

### 4. 中和反应反应热

**定义：** 在稀溶液中，强酸与强碱反应生成**1 mol H₂O**时放出的热量。

**标准值：** ΔH = -57.3 kJ/mol（25°C, 101 kPa）

**测定实验（简易量热计）：**

![简易量热计示意图：内筒、隔热层、外壳、温度计、玻璃搅拌器、杯盖](../人教版高中化学课本/【3】人教版·化学选择性必修1化学反应原理_images/58b520b5caf445691a7d17f80cc929b59c6212713c5c976887639248ae19451c.jpg)
*图：简易量热计——隔热层减少热量散失，搅拌器保证温度均匀*

| 步骤 | 操作 |
|------|------|
| 1 | 量取50 mL 0.50 mol/L HCl和50 mL 0.55 mol/L NaOH |
| 2 | 分别测量初始温度t₁ |
| 3 | 迅速混合并搅拌，记录最高温度t₂ |
| 4 | 计算：Q = (m₁ + m₂) × c × (t₂ - t₁)，c = 4.18 J/(g·°C) |
| 5 | ΔH = -Q / n(H₂O) |

**注意事项：**
- NaOH稍过量（确保HCl完全反应）
- 使用环形玻璃搅拌棒（不能用金属棒，导热）
- 装置保温（减少热量散失）
- 重复3次取平均值

> **⚠️ 易错**：弱酸或弱碱的中和热绝对值 < 57.3 kJ/mol（因为弱电解质电离需要吸热）。

### 5. 盖斯定律

**内容：** 一个化学反应的反应热只与始态和终态有关，与反应途径无关。

**核心思想：** 若一个总反应可以表示为若干步反应之和，则总反应的ΔH等于各步反应ΔH之和。

#### 基本运算规则

| 规则 | 操作 |
|------|------|
| 方程式相加 | ΔH相加 |
| 方程式相减 | ΔH相减 |
| 方程式反写 | ΔH变号（正→负） |
| 方程式乘系数n | ΔH也乘n |

#### 经典应用——求不可测反应热

**问题：** 求 C(s) + ½O₂(g) = CO(g) 的ΔH

**已知：**
- ① C(s) + O₂(g) = CO₂(g)，ΔH₁ = -393.5 kJ/mol
- ② CO(g) + ½O₂(g) = CO₂(g)，ΔH₂ = -283.0 kJ/mol

**解法：** 目标 = ① - ②
$$\Delta H = \Delta H_1 - \Delta H_2 = -393.5 - (-283.0) = \mathbf{-110.5 \text{ kJ/mol}}$$

**更多例题：**

**例2**：求 CH₄(g) = C(s) + 2H₂(g) 的ΔH

已知：
- ① CH₄(g) + 2O₂(g) = CO₂(g) + 2H₂O(l)，ΔH₁ = -890.3 kJ/mol
- ② C(s) + O₂(g) = CO₂(g)，ΔH₂ = -393.5 kJ/mol
- ③ H₂(g) + ½O₂(g) = H₂O(l)，ΔH₃ = -285.8 kJ/mol

目标 = ① - ② - 2×③
$$\Delta H = -890.3 - (-393.5) - 2(-285.8) = -890.3 + 393.5 + 571.6 = \mathbf{+74.8 \text{ kJ/mol}}$$

## 知识拓展

### 反应进度（extent of reaction, ξ）

反应进度ξ是描述化学反应进行程度的物理量，定义为：

$$\xi = \frac{\Delta n_i}{\nu_i}$$

其中Δnᵢ是物质i的物质的量变化量，νᵢ是物质i的化学计量数（产物取正值，反应物取负值）。单位：mol。

**重要含义：**
- ξ = 1 mol 称为"1 mol的反应进度"，指按方程式的化学计量数比恰好反应了1 mol的"反应单元"
- ΔH的单位kJ/mol中的"mol"即指ξ = 1 mol，**不是指某具体物质的1 mol**
- 因此ΔH与方程式的写法直接相关：

```
2H₂(g) + O₂(g) = 2H₂O(l)    ΔH = -571.6 kJ/mol    ← ξ=1 mol对应2 mol H₂燃烧
H₂(g) + ½O₂(g) = H₂O(l)    ΔH = -285.8 kJ/mol    ← ξ=1 mol对应1 mol H₂燃烧
```

两个方程描述同一反应，但ΔH相差2倍，因为"1 mol反应进度"对应的物质的量不同。

### 标准生成焓补充

**标准摩尔生成焓（ΔfHθm）**：在标准状态（100 kPa）下，由最稳定的单质生成1 mol化合物时的焓变。

**规定：** 最稳定单质的ΔfHθm = 0（基准点）。

如：ΔfHθm(H₂,g) = 0，ΔfHθm(O₂,g) = 0，ΔfHθm(C,石墨) = 0，ΔfHθm(O₃,g) ≠ 0（臭氧不是最稳定单质）。

**用生成焓计算反应焓：**

$$\Delta_r H^\theta_m = \sum \nu_i \cdot \Delta_f H^\theta_m(\text{产物}) - \sum \nu_i \cdot \Delta_f H^\theta_m(\text{反应物})$$

**示例：** 计算 H₂(g) + ½O₂(g) = H₂O(l) 的ΔrHθm

已知：ΔfHθm(H₂O,l) = −285.8 kJ/mol，ΔfHθm(H₂,g) = 0，ΔfHθm(O₂,g) = 0

$$\Delta_r H^\theta_m = 1 \times (-285.8) - [1 \times 0 + \tfrac{1}{2} \times 0] = -285.8 \text{ kJ/mol}$$

> **竞赛衔接**：标准生成焓数据表是热力学计算的核心工具，类似电化学中的标准电极电位表。通过生成焓可计算任意反应的ΔH，也可反推键能、晶格能等。

## 竞赛衔接

- **标准生成焓（ΔfHθ）**：最稳定单质生成1 mol化合物的焓变。任意反应的ΔH = ΣΔfHθ(产物) - ΣΔfHθ(反应物)
- **键焓法vs生成焓法**：键焓法更粗略（忽略了气态分子的平动/转动/振动能差异）
- **Hess定律的图解法**：用Born-Haber循环计算晶格能
- **热化学中的Kirchhoff方程**：ΔH(T₂) = ΔH(T₁) + ∫ΔCp dT

## 常见易错

1. ❌ "ΔH的单位是kJ" → ✅ 是kJ/mol（每摩尔反应进度）
2. ❌ "热化学方程式中H₂O写(g)和(l)不影响ΔH" → ✅ 影响很大（相差~44 kJ/mol）
3. ❌ "燃烧热中H₂O可以是气态" → ✅ 燃烧热要求H₂O为液态(l)
4. ❌ "弱酸中和热等于-57.3 kJ/mol" → ✅ 绝对值偏小（弱酸电离吸热）
5. ❌ "盖斯定律说明反应热与反应条件无关" → ✅ 与条件（温度、压强）有关，盖斯定律说的是与途径无关

## 🎯 教学视角

### 教学重点与难点

**重点：**
1. **热化学方程式的规范书写**——聚集状态(g)(l)(s)(aq)必须标注、ΔH与计量数一一对应、单位kJ/mol的含义（每摩尔反应进度而非每摩尔物质）
2. **盖斯定律的"方程式加减法"**——方程式反写ΔH变号、乘系数ΔH也乘、多步叠加求不可测反应热
3. **从宏观和微观双视角认识反应热**——宏观：反应前后物质内能不同导致能量变化；微观：旧键断裂吸能与新键形成放能的综合结果

**难点：**
- **ΔH单位的理解**：kJ/mol中"mol⁻¹"指反应进度为1 mol，因此计量数不同时ΔH数值不同（如H₂燃烧与2H₂燃烧的ΔH差2倍）
- **焓的抽象性**：焓H = U + pV没有确切物理意义，但ΔH = Qₚ（等压条件）具有实用价值；内能绝对值无法测定但变化值可测
- **盖斯定律的图解思维**：将反应路径类比为登山（势能变化与路径无关），帮助学生从"状态函数"角度理解

### 建议教学路径

1. **第一课时：从定性和定量两个角度感受反应热**
   - 利用"研究与实践"栏目：课前布置学生查阅火箭推进剂成分与反应原理
   - 通过中和反应反应热的测定实验，从定量角度感受反应热
   - 引导学生区分"吸热"和"放热"的宏观现象

2. **第二课时：从宏观和微观角度分析原因，建立模型**
   - 选取具体反应（天然气、肼、乙醇燃烧）分析能量变化原因
   - 宏观视角：反应物与生成物内能不同 → 能量变化
   - 微观视角：旧键断裂吸能 + 新键形成放能 → 综合结果决定吸放热
   - 可补充键能数据让学生练习计算反应热

3. **第三课时：符号表征——热化学方程式与燃烧热**
   - 核心问题驱动：ΔH与温度和压强有关吗？化学计量数不同时意义有何不同？
   - 对比H₂O(g)与H₂O(l)的ΔH差异（相差约44 kJ/mol，水的汽化热）
   - 介绍燃烧热概念：1 mol物质完全燃烧生成指定产物（C→CO₂, H→H₂O(l), S→SO₂）

4. **第四课时：盖斯定律的发现与应用**
   - 问题引入：2C(s)+O₂(g)=2CO(g)的ΔH能否直接测定？能否设计路径？
   - 用登山类比（势能变化与路径无关）引出盖斯定律
   - 练习：利用已知反应热组合求未知反应热（如求C不完全燃烧的ΔH）
   - 结合含硫物质热化学循环案例（太阳能转化与存储），说明盖斯定律在调控能量中的作用

5. **第五课时：应用与复习**
   - 以火箭推进剂为主题：写出热化学方程式 → 计算ΔH → 从物质变化和能量变化两个视角分析
   - 建构思维导图，从宏观现象、微观实质和符号表征三个维度总结

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| "ΔH的单位是kJ" | 单位是kJ/mol（每摩尔反应进度），不同计量数的方程式ΔH不同 |
| "热化学方程式中H₂O写(g)和(l)不影响ΔH" | 影响很大，相差约44 kJ/mol（水的汽化热） |
| "燃烧热中H₂O可以是气态" | 燃烧热要求H₂O为液态(l)，写成(g)会导致ΔH数值偏小 |
| "弱酸中和热等于-57.3 kJ/mol" | 绝对值偏小（弱酸电离需吸热），如HF+NaOH为-67.7 kJ/mol（HF电离放热，特殊情况） |
| "盖斯定律说明反应热与反应条件无关" | 盖斯定律说的是与途径无关；ΔH仍与温度、压强有关 |
| "焓的绝对值可以测定" | 焓的绝对值无法确定，但变化值可通过Qₚ计算 |

### 与现实世界的联系

- **火箭推进剂**：液氢+液氧（ΔH = -285.8 kJ/mol）、肼类推进剂的选择需综合考虑反应热、产物环保性和储存安全性
- **食品与营养**：葡萄糖和脂肪的氧化放热比较——单位质量脂肪放热约38 kJ/g（葡萄糖约17 kJ/g），解释了脂肪作为高效储能物质的生理功能
- **燃料变迁与能源战略**：从柴薪→煤炭→石油→天然气→氢能，每次变迁都是物质变化和能量变化两个视角的综合考量
- **太阳能转化与存储**：利用含硫物质的热化学循环，将太阳能转化为化学能储存，体现了盖斯定律在新能源技术中的应用

### 竞赛衔接

- 标准生成焓表的使用（类似电极电位表）
- Born-Haber循环计算离子晶体晶格能
- 热力学第一定律在化学反应中的应用
- 热容与温度对ΔH的影响（Kirchhoff方程）
