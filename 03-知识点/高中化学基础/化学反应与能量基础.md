# 化学反应与能量基础

> **课标要求**：理解化学反应中能量变化的本质（键能角度），了解吸热反应和放热反应，认识原电池的工作原理，了解化学电源的种类与应用。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能从化学反应中能量变化的角度认识化学反应，了解吸热反应和放热反应。
2. 能理解化学能与热能、化学能与电能之间的转化关系。
3. 能设计简单的原电池装置，理解原电池的工作原理和形成条件。
4. 能从化学反应速率的角度认识化学反应的快慢，了解影响化学反应速率的因素。
5. 能理解化学反应的限度，知道可逆反应在一定条件下能达到化学平衡状态。
6. 能运用化学反应速率和化学平衡的知识解释简单的实际问题。

## 核心概念

### 1. 化学反应与热能

#### 放热反应与吸热反应

| 类型 | 特征 | 典型例子 |
|------|------|----------|
| **放热反应** | 反应释放热量，体系温度升高 | Mg + HCl、C/H₂/CH₄燃烧、H₂ + Cl₂、酸碱中和 |
| **吸热反应** | 反应吸收热量，体系温度降低 | Ba(OH)₂·8H₂O + NH₄Cl、C + CO₂ $\xrightarrow{\text{高温}}$ 2CO、CaCO₃分解 |

#### 微观解释（键能角度）

**核心公式：**
$$\Delta H = \text{断键吸收的能量} - \text{成键释放的能量}$$

| ΔH符号 | 含义 |
|--------|------|
| ΔH < 0 | 放热反应（成键释放 > 断键吸收） |
| ΔH > 0 | 吸热反应（断键吸收 > 成键释放） |

**经典例题——H₂ + Cl₂ → 2HCl的能量分析：**

| 步骤 | 键 | 能量 |
|------|------|------|
| 断键（吸热） | 1 mol H-H | +436 kJ |
| 断键（吸热） | 1 mol Cl-Cl | +243 kJ |
| **断键总计** | | **+679 kJ** |
| 成键（放热） | 2 mol H-Cl | -862 kJ |
| **成键总计** | | **-862 kJ** |
| **净变化** | | **ΔH = -183 kJ/mol**（放热） |

#### 能量图（反应进程图）

```
        能量
         ↑    ···活化能Eₐ
         |   /
         |  / ← 活化络合物
反应物 ──┤·
         |     \
         |      \
         |       ·── 产物
         |        ← 放出能量（|ΔH|）
         └──────────────→ 反应进程
         
  放热反应：反应物能量 > 产物能量
  吸热反应：反应物能量 < 产物能量
```

![化学反应与能量变化的关系示意图，放热反应与吸热反应对比](../人教版高中化学课本/【2】人教版·化学必修第二册_images/adec99f60c28e92183026ff0b2f2ffb9c6239fe53095cc18529c70d6323ee597.jpg)
*图：吸热反应——生成物总能量高于反应物总能量，需从环境吸收能量*

> **竞赛衔接**：ΔH ≈ Σ(反应物键能) - Σ(产物键能)。注意键能表中给出的是断键吸收的能量（正值）。

**实验验证：**
- **实验6-1**：Mg + 2 mol/L HCl → 温度升高（放热）
- **实验6-2**：Ba(OH)₂·8H₂O + 2NH₄Cl → 温度急剧下降，烧杯底部水结冰（吸热）

### 2. 化学反应与电能

#### 原电池初步

**定义：** 将化学能直接转化为电能的装置。

**Zn-Cu原电池（稀H₂SO₄介质）：**

```
      电子流动方向 →
    ┌──────────────────┐
    │     导线         │
    │  ┌────┐ ┌────┐  │
    │  │ Zn │ │ Cu │  │
    │  │(-) │ │(+) │  │
    │  └──┬─┘ └─┬──┘  │
    │     │  稀H₂SO₄  │
    │     └────────┘  │
    └──────────────────┘
```

| 电极 | 反应 | 类型 |
|------|------|------|
| **负极（Zn）** | Zn - 2e⁻ = Zn²⁺ | 氧化反应（失电子） |
| **正极（Cu）** | 2H⁺ + 2e⁻ = H₂↑ | 还原反应（得电子） |
| **总反应** | Zn + 2H⁺ = Zn²⁺ + H₂↑ | |

![Zn-Cu原电池原理示意图，电子从Zn经外电路流向Cu，溶液中H⁺在Cu片上得电子析出H₂](../人教版高中化学课本/【2】人教版·化学必修第二册_images/785042046fbefb8fac4afde47b817456b8a6a3cdd73e40539814eab8cbb85052.jpg)
*图：Zn-Cu原电池原理——Zn失电子（负极），H⁺得电子析出H₂（正极）*

**构成原电池的条件：**
1. 两种活泼性不同的电极（或一个金属一个碳棒）
2. 电解质溶液
3. 形成闭合回路（导线连接）
4. 自发的氧化还原反应

> **实验6-3**：Zn片和Cu片分别插入稀H₂SO₄→用导线连接→电流计偏转→有电流产生。

#### 化学电源

**一次电池（不可充电）：**

锌锰干电池：
- 负极（Zn壳）：Zn - 2e⁻ = Zn²⁺
- 正极（碳棒）：2MnO₂ + 2NH₄⁺ + 2e⁻ = Mn₂O₃ + 2NH₃ + H₂O

**二次电池（可充电）：**

铅蓄电池：
- 负极（Pb）：Pb + SO₄²⁻ - 2e⁻ = PbSO₄
- 正极（PbO₂）：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O
- 总反应：Pb + PbO₂ + 2H₂SO₄ $\xrightleftharpoons[\text{充电}]{\text{放电}}$ 2PbSO₄ + 2H₂O

**燃料电池：**
- H₂-O₂燃料电池（酸性电解质）：
  - 负极：H₂ - 2e⁻ = 2H⁺
  - 正极：½O₂ + 2H⁺ + 2e⁻ = H₂O
  - 能量转换效率 > 80%（远高于热电厂的~30%）

> **竞赛衔接**：原电池中电子从负极经外电路流向正极；溶液中阳离子向正极移动，阴离子向负极移动（内电路）。

### 3. 化学反应速率初步

**定义：** 单位时间内反应物或生成物浓度的变化量。

$$v = \frac{|\Delta c|}{\Delta t}$$

**影响因素：**
- 浓度：增大反应物浓度→速率增大
- 温度：升高温度→速率增大（约每升高10°C速率增大2-4倍）
- 催化剂：改变反应路径→降低活化能→速率增大
- 固体表面积：颗粒越细→表面积越大→速率越大
- 气体压强：增大压强→气体浓度增大→速率增大

### 4. 化学平衡初步

**可逆反应：** 在同一条件下既能正向又能逆向进行的反应。

**化学平衡状态：** 可逆反应中，正反应速率等于逆反应速率，各物质浓度不再改变的状态。

**平衡特征：**
- **动**：动态平衡（v正 = v逆 ≠ 0）
- **定**：各物质浓度（或百分含量）保持不变
- **变**：改变条件可使平衡移动

**工业应用——合成氨：**
$$\text{N}_2 + 3\text{H}_2 \xrightleftharpoons[\text{高温高压}]{\text{催化剂}} 2\text{NH}_3, \quad \Delta H = -92.4 \text{ kJ/mol}$$

| 条件选择 | 原因 |
|----------|------|
| 温度 400-500°C | 折中：低温有利平衡产率，但低温反应速率太慢 |
| 压强 10-30 MPa | 高压有利平衡（气体分子数减少方向） |
| 铁基催化剂 | 降低活化能，加速达到平衡（不改变平衡位置） |

## 教材例题/习题

1. **判断放热/吸热**：根据反应物和产物总能量比较判断
2. **键能计算ΔH**：利用ΔH = 断键能之和 - 成键能之和
3. **原电池正负极判断**：活泼金属为负极（失电子），不活泼金属/碳棒为正极（得电子）
4. **平衡移动判断**：改变条件→比较Q与K→判断移动方向

## 知识拓展

### 电池的发展历程

- 18世纪晚期：伽伐尼发现蛙腿痉挛现象（生物电）；伏特证明两种金属片间以电解质间隔即可产生电流，发明**伏打电池**
- 1859年：普兰特发明**铅酸蓄电池**（产量最大、应用最广的二次电池）
- 1865年：勒克朗谢发明**锌锰电池**（氯化铵水溶液为电解质），后发展为碱性锌锰电池、无汞电池
- 1899年：荣格发明**镉镍电池**（循环寿命长，但有记忆效应）
- 20世纪70年代：**镍氢电池**研制成功，记忆效应小，能量密度大，可快速充放电
- 20世纪80~90年代：**锂离子电池**研究和迅速发展，广泛应用于医疗、电子、通信、航空和军事领域
- 20世纪90年代末：**聚合物锂离子电池**实现商业化，安全、易加工、比能量高
- 1889年：蒙德和兰格提出**燃料电池**概念；1959年培根研制成功氢氧燃料电池；20世纪60年代应用于"阿波罗"号飞船

电池分为**化学电池**（原电池、蓄电池、储备电池、燃料电池）和**物理电池**（太阳能电池、温差电池）。

### 蓄电池爆炸的原因

三个主要方面：（1）电池材料安全隐患——有机溶剂易挥发燃烧爆炸，金属锂与水或空气反应易爆炸；（2）电池制造工艺缺陷——两极间金属粉尘或杂物穿破隔膜造成短路，短路大量发热导致电解质溶剂汽化，甚至电池爆炸；（3）电池过充电——过充电引发电镀效应导致过度放热，大电流充放电也可能导致安全隐患。

### 衡量电池性能的五项指标

| 指标 | 含义 |
|------|------|
| **电压** | 包括理论充放电电压、工作电压、充电电压、终止电压 |
| **容量** | 电池放电到终止电压时输出的电量，分理论容量和实际容量 |
| **能量** | 电池对外做功输出的电能，比能量（能量密度）= 单位质量/体积输出的能量 |
| **功率** | 单位时间内输出的电能，比功率 = 单位质量/体积输出的功率 |
| **循环寿命** | 电池可重复充放电的次数 |

### 汽车用新型电池

**(1) 锂离子电池**：三大类正极材料——磷酸铁锂、锰酸锂、镍钴铝酸锂三元体系。充电时间从6~8 h缩短至1 h以下。存在问题：能量密度有限（150~200 W·h/kg），安全性（自燃、爆炸事故），需改善隔膜耐热性。

**(2) 燃料电池**：氢燃料电池以铂催化剂使H₂+O₂产生电能和水，效率40%~60%，利用余热可达85%。日本已有量产车上市，续航约480 km。甲醇燃料电池直接以甲醇为燃料，可小型化、轻量化。

**(3) 金属-空气电池**：铝-空气电池已达350 W·h/kg，相当于磷酸铁锂电池的2.3倍，理论能量密度极高。

## 竞赛衔接

- **标准生成焓（ΔfHθ）**：由最稳定单质生成1 mol化合物的焓变，用于计算任意反应的ΔH
- **Hess定律的应用**：间接计算难以直接测量的反应热
- **Tafel方程**：电极电位与电流密度的关系
- **Butler-Volmer方程**：描述电极过程动力学

## 常见易错

1. ❌ "放热反应不需要加热就能发生" → ✅ 放热反应也可能需要加热引发（如C燃烧需要点燃），放热/吸热描述的是反应本身的能量变化
2. ❌ "原电池中正极发生氧化反应" → ✅ 正极发生还原反应（得电子），负极发生氧化反应（失电子）
3. ❌ "催化剂改变平衡位置" → ✅ 催化剂只改变反应速率（同等加速正逆反应），不改变平衡位置
4. ❌ "增大压强一定加快反应速率" → ✅ 只对有气体参与的反应有效，且需要通过减小体积来增大压强
5. ❌ "平衡常数K很大的反应就没有反应物剩余" → ✅ K大说明正向程度大，但不意味着100%转化

## 🎯 教学视角

### 教学重点与难点
- **重点**：键能法理解反应热的微观本质（ΔH = 断键吸收的能量 - 成键释放的能量）；原电池的构成条件和电极反应（负极氧化、正极还原）；平衡状态的判断与特征（动、定、变）。
- **难点**：放热/吸热反应与反应条件的关系（放热反应也可能需要加热引发）；原电池工作原理中电子流向与离子迁移的理解；化学平衡的动态本质（v正=v逆≠0）。

### 建议教学路径
- 情境引入：用"没有电的生活"引入，火力发电中化学能经多步转化效率仅30%~40%，提出能否将化学能直接转化为电能的问题
- 原电池设计思路：从电流实质（带电粒子定向移动）→氧化还原反应中电子转移→氧化还原反应最有可能设计成原电池
- 探究式教学流程：提出假设→实验证实或证伪→发现新问题→提出新假设→得出结论
- 数据驱动：通过SO₂与O₂反应的浓度-时间数据，让学生完成"数形转换"（画浓度-时间图和速率-时间图），建立化学平衡概念

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 放热反应不需要加热就能发生 | 放热反应也可能需要加热引发（如C燃烧需要点燃），放热/吸热描述的是反应本身的能量变化 | 区分"反应条件"与"反应热效应"两个不同概念 |
| 原电池中正极发生氧化反应 | 正极发生还原反应（得电子），负极发生氧化反应（失电子） | 强调"负氧正还"的口诀，结合电子流向理解 |
| 催化剂改变平衡位置 | 催化剂只改变反应速率（同等加速正逆反应），不改变平衡位置 | 从活化能角度解释催化剂的作用机制 |
| 增大压强一定加快反应速率 | 只对有气体参与的反应有效，且需要通过减小体积来增大压强 | 强调压强影响的是气体浓度 |
| 平衡常数K很大的反应就没有反应物剩余 | K大说明正向程度大，但不意味着100%转化 | 用具体数据说明平衡时反应物仍有剩余 |

### 与现实世界的联系
- 电池技术发展：从伏打电池到锂离子电池、燃料电池，化学能与电能的转化支撑现代便携电子设备和电动汽车
- 化工生产中的平衡应用：合成氨工业（哈伯法）中温度、压强、催化剂的选择体现了化学平衡与反应速率的综合考量
- 新能源技术：氢燃料电池（效率40%~60%，利用余热可达85%）是未来清洁能源的重要方向
- 生活中的能量变化：燃烧反应（放热）与光合作用（吸热）是自然界最基本的化学能转化
