# 氮及其化合物

> **课标要求**：了解氮气的结构与性质，掌握氮氧化物、氨及铵盐、硝酸的性质与转化，理解氮的固定概念，认识氮循环的生态意义。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据物质类别和元素价态分别列举含硫元素、氮元素的典型代表物质。
2. 能从物质类别和元素价态的角度，依据氧化还原反应原理，预测硫及其化合物、氮及其化合物的化学性质和变化。
3. 能从物质类别和元素价态变化的角度，设计含硫物质、含氮物质的转化路径。
4. 能根据实验目的和假设设计实验方案，选择适当的实验试剂，探究不同价态含硫物质的转化；能观察并如实记录实验现象和数据，进行分析和推理，得出合理的结论。
5. 能利用二氧化硫、氨、硫酸根和铵根的性质和反应，选择适当的实验试剂，设计检验二氧化硫、检验溶液中硫酸根和铵根等离子及实验室制取氨的实验方案。
6. 能根据硫酸、硝酸和氨的性质，分析实验室、工业生产及环境保护中的某些常见问题。
7. 能说明硫及其化合物、氮及其化合物（如二氧化硫、氨等）的应用对社会发展的价值和对环境的影响，能有意识地运用所学的知识或寻求相关证据参与社会性议题（如酸雨及防治）的讨论。

## 核心概念

### 1. 氮气（N₂）

| 项目 | 内容 |
|------|------|
| 位置 | 第二周期第ⅤA族，最外层5个电子 |
| 结构 | N≡N三键，键能 946 kJ/mol（极高） |
| 物理性质 | 无色无味气体，mp -210°C，bp -196°C，密度 1.25 g/L |
| 化学性质 | 常温下极不活泼（"惰性"），因三键极难断裂 |

**反应条件——必须高温/高压/放电/催化剂：**
- N₂ + 3Mg $\xrightarrow{\text{点燃}}$ Mg₃N₂（与活泼金属直接化合）
- N₂ + O₂ $\xrightarrow{\text{放电}}$ 2NO（闪电固氮）
- N₂ + 3H₂ $\xrightleftharpoons[\text{高温高压}]{\text{催化剂}}$ 2NH₃（工业合成氨，哈伯法）

> **氮的固定**：将大气中游离态N₂转化为化合态氮（氮化物/氨/硝酸盐等）的过程。
> - 自然固氮：闪电将N₂转化为NO→NO₂→HNO₃→硝酸盐进入土壤
> - 生物固氮：豆科植物根瘤菌将N₂→NH₃
> - 人工固氮：合成氨工业（哈伯-博施法）

### 2. 氮氧化物

#### 一氧化氮（NO）

| 性质 | 内容 |
|------|------|
| 外观 | 无色气体，有毒 |
| 溶解性 | 不溶于水 |
| 化学性质 | 极易与O₂反应：2NO + O₂ = 2NO₂ |
| 生物功能 | 信号分子，调节血压、免疫（1998年诺贝尔生理学/医学奖） |

#### 二氧化氮（NO₂）

| 性质 | 内容 |
|------|------|
| 外观 | 红棕色、有刺激性气味的有毒气体 |
| 密度 | 大于空气 |
| 溶解性 | 可溶于水 |

**NO₂与水反应（工业制硝酸基础）：**
$$3\text{NO}_2 + \text{H}_2\text{O} = 2\text{HNO}_3 + \text{NO}$$

> **⚠️ 关键**：此反应中NO₂既是氧化剂又是还原剂（歧化反应），N从+4价分别变为+5（HNO₃）和+2（NO）。

**实验5-5**：注射器实验——NO与水、空气的连续反应：
1. 注射器充NO，注入水→NO不溶于水
2. 再抽入空气→NO遇O₂变为红棕色NO₂
3. NO₂溶于水→红棕色消失，水面上升

*图：注射器实验装置——观察NO→NO₂→HNO₃的连续转化*

### 3. 氨（NH₃）

**物理性质：**
- 无色、有刺激性气味的气体
- 密度小于空气（可用向下排空气法收集）
- **极易溶于水**：室温下1体积水溶解约700体积NH₃
- 液氨气化吸热→用作制冷剂

**化学性质：**

| 反应类型 | 方程式 | 说明 |
|----------|--------|------|
| 与水反应（碱性） | NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻ | 溶液呈弱碱性 |
| 与酸反应 | NH₃ + HCl = NH₄Cl（白烟） | 可用于检验NH₃或HCl气体 |
| 催化氧化 | 4NH₃ + 5O₂ $\xrightarrow{\text{Pt},\Delta}$ 4NO + 6H₂O | 工业制硝酸第一步 |
| 与Cl₂反应 | 8NH₃ + 3Cl₂ = 6NH₄Cl + N₂ | 过量NH₃时的反应 |

**关键实验：**
- **实验5-6 喷泉实验**：充满NH₃的圆底烧瓶→滴入酚酞的水→形成红色喷泉。证明NH₃极易溶于水且水溶液呈碱性。

![氨的喷泉实验](人教版高中化学课本/【2】人教版·化学必修第二册_images/4eabc74ad55bad095342fef506642a66df8432e09d8cb1f235f8ad5ac9578a4a.jpg)
*图：氨的喷泉实验——圆底烧瓶内形成红色喷泉，证明NH₃极易溶于水且溶液呈碱性*
- **实验5-7 NH₄⁺检验**：加NaOH溶液并加热→用湿润红色石蕊试纸检验→试纸变蓝（NH₃逸出）

### 4. 铵盐

**共性：**
- 一般都溶于水
- 受热易分解（非氧化还原）
- 与碱反应释放NH₃

**典型反应：**
- NH₄Cl $\xrightarrow{\Delta}$ NH₃↑ + HCl↑（冷却又结合：管口白烟）
- NH₄HCO₃ $\xrightarrow{\Delta}$ NH₃↑ + H₂O + CO₂↑
- 2NH₄Cl + Ca(OH)₂ $\xrightarrow{\Delta}$ CaCl₂ + 2H₂O + 2NH₃↑（实验室制NH₃）

> **竞赛衔接**：NH₄⁺的酸性来源于质子水合：NH₄⁺的pKa = 9.25。

### 5. 硝酸（HNO₃）

**物理性质：** 无色、有刺激性气味的挥发性液体。

**不稳定性：**
$$4\text{HNO}_3 \xrightarrow{\text{光/热}} 4\text{NO}_2\uparrow + \text{O}_2\uparrow + 2\text{H}_2\text{O}$$
→ 必须保存在棕色瓶中，置于阴凉处。

**强氧化性（与H₂SO₄对比）：**

| 反应 | 方程式 | 说明 |
|------|--------|------|
| 浓HNO₃ + Cu | Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O | 生成红棕色NO₂ |
| 稀HNO₃ + Cu | 3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O | 生成无色NO |
| 浓HNO₃ + C | C + 4HNO₃(浓) $\xrightarrow{\Delta}$ CO₂↑ + 4NO₂↑ + 2H₂O | |
| 浓HNO₃ + Fe/Al | 常温钝化（表面致密氧化膜） | 同浓H₂SO₄ |

**王水**（浓HNO₃ : 浓HCl = 1:3，体积比）：
- 能溶解Au和Pt（单独的浓HNO₃或浓HCl都不能）
- 配制后立即使用（放置后分解）

> **⚠️ 易错点**：浓HNO₃的还原产物是NO₂，稀HNO₃的还原产物是NO。浓度越高，还原产物中N的化合价越高（+4 > +2）。

### 6. 酸雨

| 项目 | 内容 |
|------|------|
| 正常雨水 | pH ≈ 5.6（溶解了大气CO₂） |
| 酸雨定义 | pH < 5.6 的降水 |
| 主要来源 | 煤/石油中含S→燃烧生成SO₂；汽车/电厂高温→N₂+O₂→NOₓ |
| 形成机理 | SO₂ → SO₃ → H₂SO₄；NOₓ → HNO₃ |
| 危害 | 腐蚀建筑、酸化土壤和水体、破坏森林 |
| 防治 | 工业废气脱硫脱硝（碱液吸收、催化还原等） |

## 教材例题/习题

1. **工业制硝酸三步法**：合成NH₃→催化氧化制NO→NO氧化为NO₂→NO₂溶于水制HNO₃
2. **NO₂的二聚**：2NO₂ ⇌ N₂O₄（可逆，低温平衡右移）
3. **氮的转化链**：N₂→NH₃→NO→NO₂→HNO₃→硝酸盐

## 知识拓展

### 神奇的一氧化氮分子

NO分子1992年被《科学》杂志评选为"明星分子"。N和O之间的三键由一个双电子σ键、一个双电子π键和一个三电子π键组成。NO是顺磁性、单自由基分子，微溶于水但不与水反应，具有脂溶性，可快速扩散通过生物膜，生物半衰期仅3~5 s。作为内皮细胞源性血管舒张因子（EDRF），NO能使血管平滑肌松弛，细胞依靠一氧化氮合成酶以L-精氨酸和分子氧为底物生成NO。NO有时还承担神经系统递质的作用。

### 合成氨工业的奠基人——哈伯

弗里茨·哈伯（Fritz Haber），德国化学家，1909年7月在600°C、约20 MPa和锇（或铀）催化剂条件下合成氨成功，1918年获诺贝尔化学奖。博施（Carl Bosch）负责将哈伯的成果工业化，经上万次试验选定含碱金属化合物的铁催化剂，将合成塔衬以软铁解决氢腐蚀问题，1913年建立世界第一个合成氨工厂，年产量约7000 t。博施和柏吉斯（Alfried Bergius）获1931年诺贝尔化学奖。一项技术成果使三人获诺贝尔奖。

### 硝酸与金属反应的一般规律

（1）H后金属（Cu、Hg、Ag）：浓硝酸主要得NO₂，稀硝酸主要得NO。
（2）Fe、Co、Ni、Al等在浓硝酸中发生"钝化"（致密氧化膜）。与稀硝酸主要生成N₂O，与更稀的硝酸生成氨。
（3）Mg、Zn等与不同浓度硝酸可得不同还原产物：
$$4\mathrm{Zn} + 10\mathrm{HNO}_{3} = 4\mathrm{Zn}(\mathrm{NO}_{3})_{2} + \mathrm{N}_{2}\mathrm{O}\uparrow + 5\mathrm{H}_{2}\mathrm{O}$$
$$4\mathrm{Zn} + 10\mathrm{HNO}_{3} = 4\mathrm{Zn}(\mathrm{NO}_{3})_{2} + \mathrm{NH}_{4}\mathrm{NO}_{3} + 3\mathrm{H}_{2}\mathrm{O}$$
（4）Au、Pt等不与硝酸反应。

### 氮肥知识

氮是形成蛋白质、核酸和叶绿素的重要元素。氮肥分铵态氮肥、硝态氮肥和酰胺态氮肥三类：

| 类型 | 名称 | 化学式 | 含氮量 | 施用要点 |
|------|------|--------|--------|----------|
| 铵态 | 硫酸铵 | $(NH_{4})_{2}SO_{4}$ | 20%~21% | 长期施用会使土壤板结 |
| 铵态 | 碳酸氢铵 | $NH_{4}HCO_{3}$ | 16%~17% | 不稳定，需深施覆土 |
| 铵态 | 硝酸铵 | $NH_{4}NO_{3}$ | 34%~35% | 含硝态和铵态氮 |
| 铵态 | 氨水 | $NH_{3} \cdot H_{2}O$ | 16%~17% | 易挥发，不能接触种子 |
| 硝态 | 硝酸钾 | $KNO_{3}$ | 14% | 较稳定 |
| 酰胺态 | 尿素 | $CO(NH_{2})_{2}$ | 42%~46% | 含氮量最高，较稳定 |

## 竞赛衔接

- **氮的氧化态谱**：-3（NH₃）、0（N₂）、+1（N₂O）、+2（NO）、+3（HNO₂/N₂O₃）、+4（NO₂/N₂O₄）、+5（HNO₃/N₂O₅）
- **亚硝酸（HNO₂）**：弱酸（Ka = 4.6×10⁻⁴），不稳定，既可作氧化剂又可作还原剂
- **叠氮化物（N₃⁻）**：含N-N-N线性结构，NaN₃用于汽车安全气囊
- **联氨（N₂H₄）**：火箭推进剂，强还原性

## 常见易错

1. ❌ "NO₂是硝酸的酸酐" → ✅ N₂O₅才是硝酸的酸酐（N₂O₅ + H₂O = 2HNO₃）；NO₂与水反应不是简单的酸性氧化物反应
2. ❌ "NH₃能使干燥的红色石蕊试纸变蓝" → ✅ 必须是湿润的（NH₃溶于水后才显碱性）
3. ❌ "浓HNO₃氧化性比稀HNO₃强，所以还原产物中N的化合价更低" → ✅ 相反：浓HNO₃→NO₂（+4），稀HNO₃→NO（+2）
4. ❌ "实验室用NH₄NO₃加热制NH₃" → ✅ NH₄NO₃受热可能爆炸，应使用NH₄Cl + Ca(OH)₂
5. ❌ "NO₂溶于水后溶液呈酸性" → ✅ 正确（生成HNO₃），但反应同时产生NO气体

## 🎯 教学视角

### 教学重点与难点
- **重点**：氮的化合价变化链（-3→0→+2→+4→+5）是贯穿本节的主线；含氮物质分5类（单质、氢化物、氧化物、含氧酸、含氧酸盐），与硫元素对应物质进行性质异同比较。
- **难点**：浓硝酸与浓硫酸分别与铜反应的对比（常温vs加热、NO₂vsSO₂）；NO₂与水反应的歧化本质；"氮三角"转化关系的整合。

### 建议教学路径
- 以非金属元素学习模式为参照：含氮物质分5类，与硫元素对应物质进行性质异同比较，建立类比学习框架
- 情境素材："雷雨发庄稼"引入氮的固定；酸雨危害引入环境问题；工业合成氨和工业制硝酸为背景
- 浓硝酸强氧化性突破难点：通过浓硝酸与浓硫酸分别与铜反应的对比表加深理解——常温vs加热；NO₂vsSO₂
- "氮三角"结构化：整合N₂、NH₃、NO、NO₂、HNO₃、Cu(NO₃)₂间转化关系，以化合价变化为主线串联

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| NO₂是硝酸的酸酐 | N₂O₅才是硝酸的酸酐（N₂O₅+H₂O=2HNO₃）；NO₂与水反应不是简单的酸性氧化物反应 | 对比酸性氧化物的定义与NO₂歧化反应的本质区别 |
| NH₃能使干燥的红色石蕊试纸变蓝 | 必须是湿润的（NH₃溶于水后才显碱性） | 强调NH₃本身不电离OH⁻，溶于水才形成NH₃·H₂O电离出OH⁻ |
| 浓HNO₃氧化性比稀HNO₃强，还原产物中N的化合价更低 | 相反：浓HNO₃→NO₂（+4），稀HNO₃→NO（+2） | 从浓度对还原产物的影响规律理解：浓度越高，还原产物中N的化合价越高 |
| 实验室用NH₄NO₃加热制NH₃ | NH₄NO₃受热可能爆炸，应使用NH₄Cl+Ca(OH)₂ | 从安全性角度强调NH₄NO₃的热不稳定性 |

### 与现实世界的联系
- 氮的固定与农业：哈伯-博施法合成氨是20世纪最重要的化学发明，支撑全球粮食生产
- 酸雨的形成与防治：NOₓ排放→硝酸型酸雨，与SO₂共同造成酸雨危害，需要脱硫脱硝处理
- 氮氧化物的环境化学：汽车尾气处理中的催化还原技术（NOₓ→N₂+H₂O）
- 生物信号分子：NO是血管舒张因子（EDRF），1998年诺贝尔生理学/医学奖相关研究
- 氮肥知识：铵态氮肥、硝态氮肥、酰胺态氮肥的特点与合理施用
