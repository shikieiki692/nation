# 铁及其化合物

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据物质类别和元素价态列举铁元素的典型代表物。能利用离子反应、氧化还原反应等概念对铁及其化合物的相关反应进行分类和分析说明。
2. 能列举、描述、辨识铁及其化合物重要的物理、化学性质及实验现象。能用化学方程式、离子方程式正确表示铁及其化合物的主要化学性质。
3. 能从物质类别、元素价态的角度，依据复分解反应和氧化还原反应原理，预测铁及其化合物的化学性质和变化，设计实验进行初步验证，并能分析、解释有关实验现象。
4. 能利用铁及其化合物的性质和反应，设计常见含铁物质制备、分离、提纯、检验等简单任务的方案。能从物质类别和元素价态变化的视角说明物质的转化路径。

## 核心概念

### 铁的基本性质

铁（Fe）是第四周期第VIII族过渡金属，常见化合价为+2和+3。

**铁与非金属反应**：
- 与Cl₂：2Fe + 3Cl₂ →点燃 2FeCl₃（生成+3价铁）
- 与S：Fe + S →△ FeS（生成+2价铁，S氧化性较弱）
- 与O₂：3Fe + 2O₂ →点燃 Fe₃O₄（含+2和+3两种价态）

**铁与水蒸气反应**：

3Fe + 4H₂O(g) →高温 Fe₃O₄ + 4H₂

这是铁在高温下与水蒸气反应生成Fe₃O₄和H₂，体现了铁的还原性。该反应需要红热条件，是教材明确要求掌握的核心反应。

**铁与酸反应**：
- 与稀HCl/稀H₂SO₄：Fe + 2H⁺ → Fe²⁺ + H₂↑（生成+2价铁）
- 与浓H₂SO₄（常温钝化）：表面形成致密氧化膜，阻止进一步反应
- 与稀HNO₃：Fe + 4HNO₃(稀) → Fe(NO₃)₃ + NO↑ + 2H₂O（Fe过量时：3Fe + 8HNO₃(稀) → 3Fe(NO₃)₂ + 2NO↑ + 4H₂O）

**铁与盐溶液反应**：Fe + Cu²⁺ → Fe²⁺ + Cu

### Fe²⁺与Fe³⁺的性质对比

| 性质 | Fe²⁺ | Fe³⁺ |
|------|------|------|
| 颜色 | 浅绿色 | 棕黄色 |
| 氧化还原性 | 既有氧化性又有还原性 | 以氧化性为主 |
| 与NaOH | Fe²⁺ + 2OH⁻ → Fe(OH)₂↓（白色→灰绿→红棕） | Fe³⁺ + 3OH⁻ → Fe(OH)₃↓（红棕色） |
| 与KSCN | 无明显现象 | Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ（血红色） |
| 与Cl₂ | 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ | 不反应 |

### Fe²⁺与Fe³⁺的相互转化

**Fe²⁺ → Fe³⁺**（氧化）：加入氧化剂

- 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻
- 5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O

**Fe³⁺ → Fe²⁺**（还原）：加入还原剂

- 2Fe³⁺ + Fe → 3Fe²⁺
- 2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺
- 2Fe³⁺ + S²⁻ → 2Fe²⁺ + S↓

### Fe(OH)₂的制备

Fe(OH)₂极易被空气中O₂氧化为Fe(OH)₃：

4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃

现象：白色沉淀迅速变为灰绿色，最终变为红棕色。

![[30674c0e865f15f163b52665ae43477c5cff2f86b7c32946518ee1f1ea64cfbf.jpg|Fe(OH)₂和Fe(OH)₃的生成实验]]

**防氧化操作要点**：

1. 将NaOH溶液煮沸（除去溶解的O₂）
2. 将胶头滴管伸入液面以下（隔绝空气）
3. 在液面上覆盖一层苯或植物油（隔绝空气）

### Fe³⁺的检验

- **KSCN法**：加入KSCN溶液，溶液变为血红色（最灵敏）

![[324a84073885aedf5908c636bc8aeeed5e2690e9346b5bd6feea9cd85aa463d1.jpg|Fe³⁺的检验实验]]

- **NaOH法**：加入NaOH溶液，生成红棕色沉淀

### 铁的冶炼基础

**高炉炼铁原理**（以赤铁矿Fe₂O₃为例）：

- 还原剂：CO（由C和CO₂反应生成）
- 主反应：Fe₂O₃ + 3CO →高温 2Fe + 3CO₂
- 造渣反应：CaCO₃ →高温 CaO + CO₂，CaO + SiO₂ →高温 CaSiO₃

## 知识拓展

### 铁的发现与冶炼史

公元前2500年人类已发现和使用铁（陨铁），古埃及人称铁为"天石"。约公元前2000年发明铁矿石冶炼。我国在公元前7世纪至前6世纪的春秋时代已发明冶炼生铁技术，春秋末期已出现炼钢技术。铁的拉丁语是 ferrum，元素符号 Fe。

### 铁的存在与性质

铁是地壳中最丰富的元素之一，含量4.75%，在金属中仅次于铝。常见化合价为+2和+3。纯铁较软，有良好延展性和导热性，能导电，能被磁化又可去磁。

铁的重要化学性质：
- 纯铁在空气中不易起变化，含杂质的铁在潮湿空气里逐渐生锈
- 铁红热时能与水反应生成氢气
- 铁易溶于稀酸，但在浓硫酸或浓硝酸中因钝化而不能溶解
- 铁加热时能与卤素、硫、磷、硅等非金属反应，但不与氮直接反应
- 铁是生命过程必需元素，是血红蛋白的主要成分

## 关键实验

### 实验活动2：铁及其化合物的性质
- **目的**：认识铁及其化合物的重要化学性质，理解Fe²⁺/Fe³⁺的检验与相互转化
- **关键操作与预期现象**：
  - **Fe(OH)₃的制备**：向FeCl₃溶液中滴入NaOH溶液 → 生成红褐色沉淀
  - **Fe(OH)₂的制备**：向FeSO₄溶液中滴入NaOH溶液 → 白色絮状沉淀迅速变灰绿色，最终变红褐色（4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃）
  - **Fe³⁺的检验**：向FeCl₃溶液滴入KSCN溶液 → 溶液呈血红色；向FeCl₂溶液滴入KSCN溶液 → 无明显变化
  - **Fe²⁺/Fe³⁺的转化**：向FeCl₃溶液加入铁粉 → 黄色变浅绿色，KSCN无变化；再滴入氯水 → 变红色
- **注意事项**：
  - 制备Fe(OH)₂时需隔绝空气：新制FeSO₄溶液中加少量铁粉、NaOH溶液煮沸除氧、胶头滴管伸入液面以下操作
  - FeCl₂溶液必须用新配制的，并加铁粉还原
  - 氯水不宜过量（否则会氧化SCN⁻使红色褪去）

## 竞赛衔接

- Fe²⁺/Fe³⁺相互转化涉及的氧化还原反应是竞赛中配平练习的重要素材
- 铁的配合物（如K₃[Fe(CN)₆]检验Fe²⁺）在竞赛中有深入考察
- Fe(OH)₂的制备实验操作是竞赛实验考试的常见考点

## 常见易错

1. **铁与稀HNO₃反应产物取决于用量**：Fe少量生成Fe³⁺，Fe过量生成Fe²⁺。不能一概而论
2. **Fe与Cl₂反应无论Fe是否过量都生成FeCl₃**：Cl₂氧化性强，能将Fe直接氧化到+3价。这与Fe和稀HNO₃反应不同
3. **Fe₃O₄不是FeO·Fe₂O₃**：虽然可以这样简写，但Fe₃O₄是反尖晶石结构的纯净物，不是混合物

## 🎯 教学视角

### 教学重点与难点
- **重点**：铁的+2和+3价态及其转化关系（“铁三角”模型）；Fe²⁺与Fe³⁺的检验方法（KSCN法、NaOH法）；Fe(OH)₂的制备操作
- **难点**：铁与不同氧化剂反应产物价态的判断（弱氧化剂→Fe²⁺，强氧化剂→Fe³⁺）；Fe(OH)₂极易被氧化的实验操作控制

### 建议教学路径
- 教材按照“铁单质→铁的氧化物→铁的氢氧化物→铁盐和亚铁盐”的顺序编排，教学核心是从氧化还原反应和离子反应的视角构建“铁三角”模型
- 以补铁剂为真实情境引入：阅读硫酸亚铁片说明书获取信息，预测性质，设计实验验证（维生素C与Fe²⁺同服有利于吸收）
- 通过实验呈现Fe(OH)₂白色沉淀迅速变灰绿色最终变红褐色的事实，引导学生提出假设——Fe²⁺具有还原性
- 以黑木耳中铁元素含量测定为综合案例：从定性检验到定量测定，建立“特性→检验、性质→转化、守恒→定量测定”的方法论

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 铁与稀硝酸反应一定生成Fe³⁺ | 取决于铁的用量：Fe少量生成Fe³⁺，Fe过量生成Fe²⁺（过量Fe会还原Fe³⁺） | 分步分析：先写Fe与稀HNO₃生成Fe³⁺的反应，再写过量Fe还原Fe³⁺的反应 |
| Fe(OH)₂是稳定化合物 | Fe(OH)₂极易被空气中O₂氧化为Fe(OH)₃，制备时必须隔绝空气 | 强调三个防氧化措施：煮沸NaOH溶液、胶头滴管伸入液面下、液面覆盖植物油 |
| Fe₃O₄是FeO和Fe₂O₃的混合物 | Fe₃O₄是纯净物（反尖晶石结构），可以写成FeO·Fe₂O₃但不是混合物 | 从晶体结构角度解释：Fe₃O₄中Fe²⁺和Fe³⁺有序排列，是单一化合物 |

### 与现实世界的联系
- 钢铁腐蚀（生锈）的本质是Fe被O₂和H₂O氧化为Fe₂O₃·xH₂O，每年造成巨大经济损失，是材料科学的核心课题
- 普鲁士蓝（Fe₄[Fe(CN)₆]₃）是最早的合成颜料之一，也是治疗铊和铯中毒的药物，体现了铁配合物在医药中的应用
- 补铁剂（硫酸亚铁片）中添加维生素C是为了防止Fe²⁺被氧化为Fe³⁺，提高铁的吸收率
- 高炉炼铁利用CO还原Fe₂O₃，是从矿物中提取金属的经典氧化还原过程
