# 铁及其化合物

## 核心概念

### 铁的基本性质

铁（Fe）是第四周期第VIII族过渡金属，常见化合价为+2和+3。

**铁与非金属反应**：
- 与Cl₂：2Fe + 3Cl₂ →点燃 2FeCl₃（生成+3价铁）
- 与S：Fe + S →△ FeS（生成+2价铁，S氧化性较弱）
- 与O₂：3Fe + 2O₂ →点燃 Fe₃O₄（含+2和+3两种价态）

**铁与酸反应**：
- 与稀HCl/稀H₂SO₄：Fe + 2H⁺ → Fe²⁺ + H₂↑（生成+2价铁）
- 与浓H₂SO₄（常温钝化）：表面形成致密氧化膜，阻止进一步反应
- 与稀HNO₃：Fe + 4HNO₃(稀) → Fe(NO₃)₃ + NO↑ + 2H₂O（Fe过量时：3Fe + 8HNO₃(稀) → 3Fe(NO₃)₂ + 2NO↑ + 4H₂O）

**铁与盐溶液反应**：Fe + Cu²⁺ → Fe²⁺ + Cu

### Fe²⁺与Fe³⁺的性质对比

| 性质 | Fe²⁺ | Fe³⁺ |
|------|------|------|
| 颜色 | 浅绿色 | 棕黄色 |
| 氧化还原性 | 既有氧化性又有还原性 | 以氧化性为主 |
| 与NaOH | Fe²⁺ + 2OH⁻ → Fe(OH)₂↓（白色→灰绿→红棕） | Fe³⁺ + 3OH⁻ → Fe(OH)₃↓（红棕色） |
| 与KSCN | 无明显现象 | Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ（血红色） |
| 与Cl₂ | 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ | 不反应 |

### Fe²⁺与Fe³⁺的相互转化

**Fe²⁺ → Fe³⁺**（氧化）：加入氧化剂

- 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻
- 5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O

**Fe³⁺ → Fe²⁺**（还原）：加入还原剂

- 2Fe³⁺ + Fe → 3Fe²⁺
- 2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺
- 2Fe³⁺ + S²⁻ → 2Fe²⁺ + S↓

### Fe(OH)₂的制备

Fe(OH)₂极易被空气中O₂氧化为Fe(OH)₃：

4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃

现象：白色沉淀迅速变为灰绿色，最终变为红棕色。

**防氧化操作要点**：

1. 将NaOH溶液煮沸（除去溶解的O₂）
2. 将胶头滴管伸入液面以下（隔绝空气）
3. 在液面上覆盖一层苯或植物油（隔绝空气）

### Fe³⁺的检验

- **KSCN法**：加入KSCN溶液，溶液变为血红色（最灵敏）
- **NaOH法**：加入NaOH溶液，生成红棕色沉淀

### 铁的冶炼基础

**高炉炼铁原理**（以赤铁矿Fe₂O₃为例）：

- 还原剂：CO（由C和CO₂反应生成）
- 主反应：Fe₂O₃ + 3CO →高温 2Fe + 3CO₂
- 造渣反应：CaCO₃ →高温 CaO + CO₂，CaO + SiO₂ →高温 CaSiO₃

## 竞赛衔接

- Fe²⁺/Fe³⁺相互转化涉及的氧化还原反应是竞赛中配平练习的重要素材
- 铁的配合物（如K₃[Fe(CN)₆]检验Fe²⁺）在竞赛中有深入考察
- Fe(OH)₂的制备实验操作是竞赛实验考试的常见考点

## 常见易错

1. **铁与稀HNO₃反应产物取决于用量**：Fe少量生成Fe³⁺，Fe过量生成Fe²⁺。不能一概而论
2. **Fe与Cl₂反应无论Fe是否过量都生成FeCl₃**：Cl₂氧化性强，能将Fe直接氧化到+3价。这与Fe和稀HNO₃反应不同
3. **Fe₃O₄不是FeO·Fe₂O₃**：虽然可以这样简写，但Fe₃O₄是反尖晶石结构的纯净物，不是混合物

## 🎯 教学视角

### 学习路径建议
先掌握 [[氧化还原反应基础]] 中氧化数变化和电子转移的概念。铁的+2和+3价态转化是理解过渡金属变价行为的典型案例，建议结合 [[配合物基础]] 学习铁的配合物化学。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 铁与稀硝酸反应一定生成Fe³⁺ | 取决于铁的用量：Fe少量生成Fe³⁺，Fe过量生成Fe²⁺（过量Fe会还原Fe³⁺） |
| Fe(OH)₂是稳定化合物 | Fe(OH)₂极易被空气中O₂氧化为Fe(OH)₃，制备时必须隔绝空气 |
| Fe₃O₄是FeO和Fe₂O₃的混合物 | Fe₃O₄是纯净物（反尖晶石结构），可以写成FeO·Fe₂O₃但不是混合物 |

### 入门级例题
**题目**：如何鉴别FeCl₂溶液和FeCl₃溶液？
**解答**：取少量两种溶液，分别滴加KSCN溶液。变血红色的是FeCl₃（Fe³⁺ + nSCN⁻ → 血红色配合物），不变色的是FeCl₂。

### 与现实世界的联系
1. 钢铁腐蚀（生锈）的本质是Fe被O₂和H₂O氧化为Fe₂O₃·xH₂O，每年造成巨大经济损失，是材料科学的核心课题。
2. 普鲁士蓝（Fe₄[Fe(CN)₆]₃）是最早的合成颜料之一，也是治疗铊和铯中毒的药物，体现了铁配合物在医药中的应用。
