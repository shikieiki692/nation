# 水溶液中的离子平衡

> **课标要求**：理解弱电解质的电离平衡与电离常数，掌握水的离子积和pH的计算，理解盐类水解的原理与应用，掌握沉淀溶解平衡与溶度积。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能认识弱电解质在水溶液中存在电离平衡，了解电离平衡常数的含义。
2. 能理解水的离子积常数，会进行简单溶液 pH 的计算。
3. 能认识盐类水解的原理，能解释盐类水解在生产生活中的应用。
4. 能认识沉淀溶解平衡，能利用溶度积常数进行简单计算和判断。
5. 能设计实验方案进行中和滴定，掌握滴定操作的基本技能。

## 核心概念

### 1. 弱电解质的电离平衡

#### 强电解质与弱电解质

| 比较项 | 强电解质 | 弱电解质 |
|--------|----------|----------|
| 电离程度 | 完全电离 | 部分电离（存在电离平衡） |
| 代表物 | 强酸（HCl, H₂SO₄, HNO₃）、强碱（NaOH, KOH）、大部分盐 | 弱酸（CH₃COOH, H₂CO₃, H₂S, HCN）、弱碱（NH₃·H₂O） |
| 溶液中粒子 | 完全是离子 | 分子和离子共存 |
| 导电性 | 同浓度下较强 | 同浓度下较弱 |

#### 电离平衡常数

**弱酸 Ka：**
$$\text{CH}_3\text{COOH} \rightleftharpoons \text{CH}_3\text{COO}^- + \text{H}^+$$
$$K_a = \frac{[\text{CH}_3\text{COO}^-][\text{H}^+]}{[\text{CH}_3\text{COOH}]}$$

**弱碱 Kb：**
$$\text{NH}_3\cdot\text{H}_2\text{O} \rightleftharpoons \text{NH}_4^+ + \text{OH}^-$$
$$K_b = \frac{[\text{NH}_4^+][\text{OH}^-]}{[\text{NH}_3\cdot\text{H}_2\text{O}]}$$

**常见弱酸Ka值（25°C）：**

| 弱酸 | Ka | 强度排序 |
|------|-----|---------|
| CH₃COOH | 1.75 × 10⁻⁵ | |
| H₂CO₃ | Ka₁ = 4.5 × 10⁻⁷ | |
| H₂CO₃ | Ka₂ = 4.7 × 10⁻¹¹ | |
| HCN | 6.2 × 10⁻¹⁰ | |

> **多元弱酸分步电离**：H₂CO₃的Ka₁ >> Ka₂（相差约10⁴倍），第一步电离占主导。第二步电离受到第一步产生的H⁺的抑制。

**Ka的应用：**
- Ka越大→酸性越强
- 比较酸性强弱：Ka(CH₃COOH) > Ka₁(H₂CO₃) > Ka(HCN) > Ka₂(H₂CO₃)
- 利用"强酸制弱酸"原理：CH₃COOH + Na₂CO₃ → CH₃COONa + CO₂↑ + H₂O（Ka(CH₃COOH) > Ka₁(H₂CO₃)）

### 2. 水的电离与pH

#### 水的自偶电离

$$\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-$$
$$K_w = [\text{H}^+][\text{OH}^-] = 1.0 \times 10^{-14} \quad (25°\text{C})$$

![水分子电离过程：两个水分子间质子转移，形成H₃O⁺和OH⁻](人教版高中化学课本/【3】人教版·化学选择性必修1化学反应原理_images/8fc65de89a9554fdf26d5edf09014939523a3958fc873c3af9a5fe98203a5b35.jpg)

**Kw的温度依赖性：**

| 温度 | Kw |
|------|-----|
| 0°C | 0.115 × 10⁻¹⁴ |
| 25°C | 1.00 × 10⁻¹⁴ |
| 100°C | 54.5 × 10⁻¹⁴ |

> **⚠️ 关键**：Kw随温度升高而增大（水的电离是吸热过程）。100°C时中性水的pH ≈ 6.28（不是7！）。

![HCl在水中完全电离：HCl分子全部解离为H⁺和Cl⁻（强电解质）](人教版高中化学课本/【3】人教版·化学选择性必修1化学反应原理_images/5e9c0f81c20483ce96a274f063d8591e78881a9598543e767f8742d1cd76c693.jpg)

#### 溶液的pH

$$\text{pH} = -\lg[\text{H}^+]$$

| 溶液类型 | [H⁺]与[OH⁻]关系 | pH（25°C） |
|----------|-----------------|-----------|
| 酸性 | [H⁺] > [OH⁻] | pH < 7 |
| 中性 | [H⁺] = [OH⁻] | pH = 7 |
| 碱性 | [H⁺] < [OH⁻] | pH > 7 |

**pH计算示例：**
- 0.01 mol/L HCl：[H⁺] = 0.01 → pH = 2
- 0.01 mol/L NaOH：[OH⁻] = 0.01 → [H⁺] = 10⁻¹² → pH = 12
- 0.01 mol/L CH₃COOH（Ka = 1.75×10⁻⁵）：[H⁺] ≈ √(Ka·c) = √(1.75×10⁻⁷) ≈ 4.2×10⁻⁴ → pH ≈ 3.4

> **⚠️ 易错**：强酸稀释100倍→pH增大2；弱酸稀释100倍→pH增大小于2（因为电离度增大，[H⁺]下降不到100倍）。

**pH测定：**
- **pH试纸**：精度约1个单位，使用时不能湿润
- **pH计（酸度计）**：精度高，可达0.01

*图：广泛pH试纸和精密pH试纸——不同pH范围的试纸用于快速测定溶液酸碱性*

#### 血液的酸碱缓冲

血液pH = 7.35-7.45，由H₂CO₃/HCO₃⁻缓冲体系维持：
$$\text{H}^+ + \text{HCO}_3^- \rightleftharpoons \text{H}_2\text{CO}_3 \rightleftharpoons \text{CO}_2\uparrow + \text{H}_2\text{O}$$

### 3. 酸碱中和滴定

**原理：** 用已知浓度的酸（或碱）来确定未知浓度的碱（或酸）的浓度。

**操作要点：**

| 项目 | 内容 |
|------|------|
| 仪器 | 酸式滴定管（装酸）、碱式滴定管（装碱）、锥形瓶 |
| 指示剂选择 | 强酸滴强碱→甲基橙（变色范围3.1-4.4）；强碱滴强酸→酚酞（变色范围8.2-10.0） |

| 滴定终点 | 滴入最后一滴标准液→溶液颜色发生突变→半分钟内不恢复 |
| 计算公式 | c(酸)·V(酸) = c(碱)·V(碱)（一元酸碱） |
| 误差分析 | 重复3次取平均值；平视读数（仰视偏大，俯视偏小） |

### 4. 盐类的水解

#### 水解规律

| 盐的类型 | 实例 | 溶液pH | 水解方程式 |
|----------|------|--------|-----------|
| 强酸+强碱 | NaCl, KNO₃ | = 7 | 不水解 |
| 强酸+弱碱 | NH₄Cl, (NH₄)₂SO₄ | < 7 | NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺ |
| 强碱+弱酸 | CH₃COONa, Na₂CO₃ | > 7 | CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻ |

**口诀：** "谁弱谁水解，谁强显谁性"（强酸弱碱→酸性；强碱弱酸→碱性）

**Na₂CO₃分步水解：**
- 第一步：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻（主要）
- 第二步：HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻（程度极小）

#### 影响水解的因素

| 因素 | 影响 |
|------|------|
| 盐的本性 | 弱酸/弱碱越弱，水解程度越大 |
| 温度 | 升温促进水解（水解是吸热反应） |
| 浓度 | 稀释促进水解 |
| 酸碱 | 加酸抑制阳离子水解，加碱抑制阴离子水解 |

#### 水解常数

$$K_h = \frac{K_w}{K_a} \quad \text{（强碱弱酸盐）}$$
$$K_h = \frac{K_w}{K_b} \quad \text{（强酸弱碱盐）}$$

#### 水解的应用

| 应用 | 原理 |
|------|------|
| 热碱水去油污 | 加热促进CO₃²⁻水解→[OH⁻]增大→促进油脂皂化 |
| FeCl₃溶液配制 | 加入浓盐酸抑制Fe³⁺水解 |
| 明矾净水 | Al³⁺水解→Al(OH)₃胶体→吸附悬浮物 |
| 泡打粉 | NaHCO₃与有机酸反应产生CO₂ |

### 5. 三大守恒

| 守恒类型 | 表达式 | 示例（Na₂CO₃溶液） |
|----------|--------|-------------------|
| **电荷守恒** | 阳离子总电荷 = 阴离子总电荷 | [Na⁺] + [H⁺] = [OH⁻] + [HCO₃⁻] + 2[CO₃²⁻] |
| **物料守恒** | 某元素的总浓度 = 初始浓度 | [Na⁺] = 2{[CO₃²⁻] + [HCO₃⁻] + [H₂CO₃]} |
| **质子守恒** | 水电离出的H⁺ = 水电离出的OH⁻ | [H⁺] + [HCO₃⁻] + 2[H₂CO₃] = [OH⁻] |

### 6. 沉淀溶解平衡

#### 溶度积（Ksp）

以AgCl为例：
$$\text{AgCl(s)} \rightleftharpoons \text{Ag}^+\text{(aq)} + \text{Cl}^-\text{(aq)}$$
$$K_{sp} = [\text{Ag}^+][\text{Cl}^-] = 1.8 \times 10^{-10} \quad (25°\text{C})$$

**Q与Ksp的比较：**

| 条件 | 结果 |
|------|------|
| Q > Ksp | 有沉淀析出 |
| Q = Ksp | 饱和溶液（平衡） |
| Q < Ksp | 沉淀溶解（不饱和） |

**常见Ksp值（25°C）：**

| 物质 | Ksp | 难溶程度 |
|------|-----|---------|
| AgCl | 1.8 × 10⁻¹⁰ | 微溶 |
| AgI | 8.5 × 10⁻¹⁷ | 难溶 |
| Ag₂S | 6.3 × 10⁻⁵⁰ | 极难溶 |
| BaSO₄ | 1.1 × 10⁻¹⁰ | 微溶 |
| CaCO₃ | 2.8 × 10⁻⁹ | 微溶 |

#### 沉淀溶解平衡的应用

**(a) 沉淀的生成：** 向含Cu²⁺、Hg²⁺的废水中加Na₂S→生成极难溶的CuS、HgS→去除重金属

**(b) 沉淀的溶解：** CaCO₃加HCl→CO₃²⁻与H⁺结合→Q < Ksp→沉淀溶解

**(c) 沉淀的转化：**
$$\text{AgCl} \xrightarrow{\text{I}^-} \text{AgI} \xrightarrow{\text{S}^{2-}} \text{Ag}_2\text{S}$$
原理：Ksp越小的沉淀越容易生成。锅炉除垢：CaSO₄ + Na₂CO₃ → CaCO₃ + Na₂SO₄，再用酸溶解CaCO₃。

#### 含氟牙膏原理

| 物质 | Ksp |
|------|-----|
| Ca₅(PO₄)₃OH（羟基磷灰石） | 较大 |
| Ca₅(PO₄)₃F（氟磷灰石） | 更小 |

F⁻将羟基磷灰石转化为更难溶的氟磷灰石→更耐酸腐蚀→预防龋齿。

## 知识拓展

### 酸碱质子理论

布朗斯特-劳里酸碱质子理论（1923年）突破了阿伦尼乌斯酸碱电离理论的局限：

**核心定义：**
- **酸：** 能给出质子的分子或离子（质子给体）
- **碱：** 能与质子结合的分子或离子（质子受体）

**共轭酸碱对：** 酸给出质子后余下的是共轭碱，碱接受质子后成为共轭酸，彼此联系在一起叫共轭酸碱对。共轭酸碱对的半反应不能单独存在。

**两性电解质：** $\mathrm{H_2O}$、$\mathrm{HSO_3^-}$、$\mathrm{HCO_3^-}$、$\mathrm{HS^-}$ 等既能给出质子也能接受质子。例如 $\mathrm{HCO_3^-}$ 作酸：$\mathrm{HCO_3^- + H_2O \rightleftharpoons H_3O^+ + CO_3^{2-}}$；作碱：$\mathrm{HCO_3^- + H_2O \rightleftharpoons OH^- + H_2CO_3}$。水溶液呈酸性还是碱性取决于两个反应向右进行倾向性的大小。

### 决定电解质强弱的因素

1. **键型：** 典型离子化合物和强极性共价化合物（HCl、$\mathrm{H_2SO_4}$）为强电解质；弱极性键共价化合物（$\mathrm{CH_3COOH}$、HCN）为弱电解质。但仅从键型区分不全面，HF虽为强极性却是弱电解质。
2. **键能：** HF、HCl、HBr、HI 键能依次减小。HF键能最大且分子间形成氢键有缔合作用，1 mol/L HF溶液中 $\mathrm{F^-}$ 仅占 1%。
3. **溶解度：** $\mathrm{BaSO_4}$、$\mathrm{CaF_2}$ 等溶于水时全部电离（强电解质），但溶解度很小，水溶液导电能力弱。
4. **浓度：** 溶液越稀电离程度越大。10 mol/L 盐酸中溶质有 0.3% 是共价分子，可视为弱电解质。
5. **溶剂介电常数：** 水的 $\varepsilon = 81$，LiCl等在水中易电离；乙醇 $\varepsilon = 27$，苯 $\varepsilon = 2$，离子化合物在其中难电离。

**结论：** 弱电解质和强电解质不是物质本质上的分类，而是电解质在溶剂等不同条件下造成的区别，彼此之间没有明显界限。

### 少数盐是弱电解质

大多数盐为强电解质，但少数盐如 $\mathrm{HgCl_2}$、$\mathrm{CdI_2}$ 由于阳离子（$\mathrm{Hg^{2+}}$、$\mathrm{Cd^{2+}}$）容易被阴离子极化，电子云产生较大变形，改变了键的性质。$\mathrm{HgCl_2}$ 水溶液几乎不导电，电离度不超过 0.5%，在溶液中主要以分子形式存在。

### 影响电离平衡的因素

**同离子效应：** 在弱电解质溶液中加入含有相同离子的强电解质时，弱电解质的电离平衡向左移动，电离度减小。例如向氨水中加入 $\mathrm{CH_3COONH_4}$，$\mathrm{NH_4^+}$ 浓度增大，平衡左移。

**盐效应：** 在弱电解质溶液中加入其他强电解质盐时，电离度增大。例如 0.1 mol/L $\mathrm{CH_3COOH}$ 中加入 0.1 mol/L NaCl，$c(\mathrm{H^+})$ 从 $1.33 \times 10^{-3}$ 增至 $1.68 \times 10^{-3}$ mol/L。但盐效应不改变数量级，同离子效应影响大得多。

### 溶度积规则

对于难溶电解质 $A_nB_m$：$Q = c^n(\mathrm{A^{m+}}) \cdot c^m(\mathrm{B^{n-}})$

- $Q > K_{sp}$：平衡左移，沉淀析出
- $Q = K_{sp}$：饱和溶液，沉淀与溶解平衡
- $Q < K_{sp}$：不饱和溶液，无沉淀；若有沉淀则溶解

### 沉淀的配位溶解

难溶电解质在配位剂作用下生成配离子而溶解：

$$\mathrm{AgCl(s) + 2NH_3(aq) \rightleftharpoons [Ag(NH_3)_2]^+(aq) + Cl^-(aq)}$$

$$\mathrm{AgBr(s) + 2S_2O_3^{2-}(aq) \rightleftharpoons [Ag(S_2O_3)_2]^{3-}(aq) + Br^-(aq)}$$

两性金属氢氧化物（$\mathrm{Al(OH)_3}$、$\mathrm{Zn(OH)_2}$ 等）既能溶于酸也能溶于强碱，分别生成羟基配合物。

## 竞赛衔接

- **缓冲溶液**：pH = pKa ± 1范围内有缓冲能力， Henderson-Hasselbalch方程：pH = pKa + lg([A⁻]/[HA])
- **分布系数（δ）**：多元弱酸各存在形式的分数随pH变化的曲线
- **溶解度（S）与Ksp的换算**：如AB型：S = √Ksp；A₂B型：S = ∛(Ksp/4)
- **同离子效应与盐效应**：加入共同离子→显著降低溶解度；加入无关电解质→略有增加
- **沉淀完全的标准**：残余离子浓度 < 10⁻⁵ mol/L

## 常见易错

1. ❌ "弱酸溶液稀释10倍pH增大1" → ✅ 实际增大小于1（稀释促进电离）
2. ❌ "Na₂CO₃溶液呈碱性说明CO₃²⁻发生了电离" → ✅ 是水解（与水反应），不是电离
3. ❌ "盐类水解程度很小所以可以忽略" → ✅ 虽然程度小但在某些应用中很重要（如FeCl₃净水、热碱去油污）
4. ❌ "Ksp大的物质一定比Ksp小的易溶" → ✅ 只有同类型（如都是AB型）才可直接比较Ksp
5. ❌ "中和滴定终点=等当点" → ✅ 终点是指示剂变色点，等当点是酸碱恰好完全反应的点，两者应尽量接近但不完全等同

## 🎯 教学视角

### 教学重点与难点

**重点：**
1. **四大平衡体系的统一理解**——电离平衡、水的电离、盐类水解、沉淀溶解平衡都是化学平衡理论在水溶液中的具体应用，核心都是勒夏特列原理
2. **弱电解质电离平衡**——电离平衡常数Ka/Kb的含义与应用；多元弱酸分步电离（Ka₁ >> Ka₂）；"强酸制弱酸"原理的判断
3. **盐类水解的原理与应用**——"谁弱谁水解，谁强显谁性"的规律；水解是吸热反应，加热促进水解；配制易水解盐溶液时需加酸抑制水解
4. **沉淀溶解平衡与Ksp**——Q与Ksp的比较判断沉淀生成/溶解/饱和；沉淀转化的方向（Ksp小的优先生成）

**难点：**
- **同离子效应与盐效应的区别**：同离子效应使电离度显著减小（可改变数量级），盐效应使电离度略有增大（不改变数量级）——前者影响远大于后者
- **水的电离的特殊地位**：Kw = [H⁺][OH⁻] = 1.0×10⁻¹⁴（25°C），100°C时Kw增大到54.5×10⁻¹⁴，此时中性水的pH ≈ 6.28（不是7！）
- **三大守恒的综合运用**：电荷守恒、物料守恒、质子守恒在复杂溶液中的列式与求解
- **分步沉淀的条件**：只有同类难溶电解质且被沉淀离子浓度相近时，Ksp小的先析出；浓度差异大时次序可能改变

### 建议教学路径

1. **第一课时：弱电解质的电离平衡**
   - 从实验对比入手：0.1 mol/L HCl vs CH₃COOH（pH、导电性、与Mg反应速率）
   - 建立电离平衡常数Ka/Kb的概念，强调只与温度有关
   - 利用常见弱酸Ka值表比较酸性强弱
   - 说明多元弱酸Ka₁ >> Ka₂的原因（第一步电离产生的H⁺抑制第二步）

2. **第二课时：水的电离与pH**
   - 从水的自偶电离引入Kw的概念
   - Kw的温度依赖性：100°C时中性pH ≈ 6.28
   - pH的定义与计算：强酸、强碱、弱酸的pH计算示例
   - 强调：弱酸稀释100倍pH增大小于2（稀释促进电离）

3. **第三课时：酸碱中和滴定**
   - 原理讲解：用已知浓度的酸（或碱）确定未知浓度的碱（或酸）
   - 操作要点：仪器选择、指示剂选择（甲基橙vs酚酞）、终点判断
   - 误差分析训练：仰视/俯视读数的影响、操作失误的偏高/偏低判断

4. **第四课时：盐类的水解**
   - 从"谁弱谁水解，谁强显谁性"引入
   - Na₂CO₃分步水解的分析
   - 影响水解的因素：温度、浓度、酸碱
   - 应用实例：热碱水去油污、FeCl₃溶液配制加盐酸、明矾净水

5. **第五课时：沉淀溶解平衡**
   - 从AgCl的溶解平衡引入Ksp概念
   - Q与Ksp的比较判断沉淀生成/溶解
   - 沉淀转化实验：AgCl → AgI → Ag₂S（颜色变化：白→黄→黑）
   - 应用：含氟牙膏原理、锅炉除垢、重金属废水处理

6. **第六课时：三大守恒与综合应用**
   - 电荷守恒、物料守恒、质子守恒的列式方法
   - 以Na₂CO₃溶液为例练习三大守恒的综合运用

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| "弱酸溶液稀释10倍pH增大1" | 实际增大小于1（稀释促进电离，[H⁺]下降不到10倍） |
| "Na₂CO₃溶液呈碱性说明CO₃²⁻发生了电离" | 是水解（CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻），不是电离 |
| "盐类水解程度很小所以可以忽略" | 程度虽小但应用很重要（FeCl₃净水、热碱去油污、配制易水解盐需加酸） |
| "Ksp大的物质一定比Ksp小的易溶" | 只有同类型（如都是AB型）才可直接比较Ksp |
| "中和滴定终点=等当点" | 终点是指示剂变色点，等当点是酸碱恰好完全反应的点，两者应尽量接近但不完全等同 |
| "100°C时pH=7的水才是中性" | 100°C时Kw增大，中性水的pH ≈ 6.28 |
| "加入NaCl使AgCl溶解度增大是因为盐效应" | 主要是同离子效应（Cl⁻浓度增大使平衡左移），盐效应影响较小 |

### 与现实世界的联系

- **血液酸碱平衡**：血液pH = 7.35-7.45，由H₂CO₃/HCO₃⁻缓冲体系维持。pH偏离正常范围会导致酸中毒或碱中毒，危及生命
- **含氟牙膏**：F⁻将牙齿表面的羟基磷灰石Ca₅(PO₄)₃OH转化为更难溶的氟磷灰石Ca₅(PO₄)₃F（Ksp更小），更耐酸腐蚀，预防龋齿
- **热碱水去油污**：加热促进CO₃²⁻水解 → [OH⁻]增大 → 促进油脂皂化反应，这是日常清洁的化学原理
- **明矾净水**：Al³⁺水解生成Al(OH)₃胶体 → 吸附水中悬浮杂质 → 沉降净水，是水处理的经典方法
- **工业废水处理**：向含Cu²⁺、Hg²⁺的废水中加Na₂S → 生成极难溶的CuS、HgS → 去除重金属离子
- **中和滴定在工业中的应用**：酸碱浓度的精确测定是化工生产质量控制的基本手段
