# 原子结构基础

## 核心概念

### 原子核的组成

原子由原子核和核外电子组成。原子核带正电，由质子和中子构成（普通氢原子¹H除外，只有1个质子，没有中子）。

核心关系式：

**质量数（A）= 质子数（Z）+ 中子数（N）**

原子序数 = 核电荷数 = 质子数 = 核外电子数（对中性原子）

同位素：质子数相同但中子数不同的原子互称同位素，如¹H、²H（D）、³H（T）；¹²C、¹³C、¹⁴C。

### 核外电子排布

**能层（电子层）**：K（n=1）、L（n=2）、M（n=3）、N（n=4）……每层最多容纳2n²个电子。

**能级（亚层）**：同一能层中能量略有不同的电子状态，分为s、p、d、f能级：

- s能级：1个轨道，最多容纳2个电子
- p能级：3个轨道，最多容纳6个电子
- d能级：5个轨道，最多容纳10个电子
- f能级：7个轨道，最多容纳14个电子

能级能量顺序：1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d < 7p

可用"构造原理"助记：按能级图从低到高依次填充。

### 构造原理与电子排布式

构造原理：电子按能量由低到高的顺序依次填入轨道。

以铁（Fe，Z=26）为例：

1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s² 或简写为 [Ar]3d⁶ 4s²

注意：书写时按能层顺序排列（3d在4s前面），但填充时4s先于3d。

### 泡利不相容原理

在一个原子中，不可能有两个电子具有完全相同的四个量子数。即每个轨道最多容纳2个自旋方向相反的电子。

### 洪特规则

**洪特规则**：电子在同一能级的不同轨道上排布时，优先以自旋相同的方式分占不同轨道。

**洪特规则特例**：当d能级或f能级处于全满（d¹⁰）、半满（d⁵）或全空（d⁰）状态时，原子能量较低，更加稳定。

例如：Cr（Z=24）的电子排布为 [Ar]3d⁵4s¹ 而非 [Ar]3d⁴4s²（半满更稳定）；Cu（Z=29）为 [Ar]3d¹⁰4s¹ 而非 [Ar]3d⁹4s²（全满更稳定）。

### 基态与激发态

- **基态**：原子中电子处于能量最低的状态
- **激发态**：电子吸收能量后跃迁到较高能级的状态

激发态的电子不稳定，会回到较低能级，以光的形式释放能量，产生**原子光谱**。不同元素的原子光谱不同（特征谱线），可用于元素鉴定。

## 竞赛衔接

- 电子排布式书写是竞赛基础技能，需熟练掌握1-36号元素
- 洪特规则特例（Cr、Cu等）是竞赛选择题的常见考点
- 竞赛中会考察激发态电子跃迁产生的光谱线数目的计算

## 常见易错

1. **4s先于3d填充但后于3d失去**：过渡金属失去电子时先失去4s电子，如Fe²⁺为 [Ar]3d⁶ 而非 [Ar]3d⁴4s²
2. **N（Z=7）的电子排布为1s²2s²2p³而非1s²2s²2p²3s¹**：p能级有3个轨道，电子优先分占不同轨道（洪特规则），不会先填入3s
3. **书写电子排布式时按能层顺序**：虽然填充顺序是4s先于3d，但书写时应按能层排列，写作3d⁶4s²
