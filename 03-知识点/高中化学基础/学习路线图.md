## 推荐学习路径（按目标分层）

### 🎯 高考备考路径
```
物质分类与离子反应 → 氧化还原反应基础 → 钠/氯/铁/物质的量
→ 原子结构 → 元素周期律 → 化学键
→ 硫/氮/无机非金属
→ 化学反应与能量基础
→ 有机化合物基础
→ 化学品使用与绿色化学
```

### 🎯 竞赛入门路径（在高考基础上扩展）
```
在高考路径完成后，按顺序补充：
→ 反应热与盖斯定律 → 化学反应速率与平衡 → 水溶液中的离子平衡 → 电化学基础
→ 有机化合物分类与研究方法 → 烃与烃的衍生物 → 生物大分子与合成高分子
→ 分子结构基础 → 分子空间结构与杂化 → 晶体结构基础 → 配合物基础 → 超分子基础
→ 碱金属 → 卤素 → 过渡金属通性
```

### 🎯 有机化学专项路径
```
化学键基础 → 分子空间结构与杂化
→ 有机化合物基础
→ 有机化合物分类与研究方法
→ 烃与烃的衍生物
→ 生物大分子与合成高分子
```
