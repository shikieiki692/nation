# 化学反应速率与平衡

> **课标要求**：理解化学反应速率的概念与表达，掌握影响反应速率的因素，理解活化能与碰撞理论，掌握化学平衡状态的判断与平衡常数，理解勒夏特列原理及其应用，了解反应方向的判据。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能从浓度、温度等角度认识化学反应速率及其影响因素。
2. 能用碰撞理论解释浓度、温度、催化剂对反应速率的影响。
3. 能判断可逆反应是否达到化学平衡状态，理解平衡常数的含义。
4. 能运用勒夏特列原理分析条件改变对化学平衡的影响。
5. 能利用 ΔG = ΔH - TΔS 判断化学反应的方向。
6. 能从反应速率和化学平衡角度认识化学反应的调控在生产生活中的应用。

## 核心概念

### 1. 化学反应速率

#### 定义与表达

$$v = \frac{|\Delta c|}{\Delta t} \quad \text{单位：mol/(L·s) 或 mol/(L·min)}$$

**速率比与计量数比的关系：**
对于反应 mA + nB ⇌ pC + qD：
$$\frac{v(A)}{m} = \frac{v(B)}{n} = \frac{v(C)}{p} = \frac{v(D)}{q}$$

**示例：** N₂ + 3H₂ ⇌ 2NH₃，若v(N₂) = 0.02 mol/(L·min)，则：
- v(H₂) = 3 × 0.02 = 0.06 mol/(L·min)
- v(NH₃) = 2 × 0.02 = 0.04 mol/(L·min)

> **注意**：速率v总是取正值。

### 2. 影响反应速率的因素

| 因素 | 影响规律 | 微观解释（碰撞理论） |
|------|----------|----------------------|
| **浓度** | 增大反应物浓度→速率增大 | 单位体积内活化分子数增多→有效碰撞频率增大 |
| **温度** | 升高温度→速率增大（约2-4倍/10°C） | 更多分子获得足够能量成为活化分子→有效碰撞比例增大 |
| **催化剂** | 改变（通常增大）反应速率 | 降低活化能→更多分子成为活化分子 |
| **压强** | 增大压强→气体浓度增大→速率增大 | 本质是浓度效应 |
| **固体表面积** | 颗粒越细→表面积越大→速率增大 | 接触面积增大 |

> **催化剂的本质**：改变反应路径，降低活化能Eₐ，但不改变ΔH。催化剂同时加速正反应和逆反应。

#### 活化能与碰撞理论

| 概念 | 定义 |
|------|------|
| **有效碰撞** | 能导致化学反应发生的碰撞（需同时满足能量和方向要求） |
| **活化分子** | 具有足够能量（≥活化能）的分子 |
| **活化能（Eₐ）** | 活化分子平均能量与全部反应物分子平均能量之差 |
| **反应机理** | 反应经历的各步基元反应的总和 |

**能量图关系：**

$$\Delta H = E_{a(\text{正})} - E_{a(\text{逆})}$$

```
        能量
         ↑
         |     ·活化络合物
         |    /\

         └──────────────→ 反应进程
```

### 3. 化学平衡状态

#### 可逆反应与平衡

**可逆反应：** 在同一条件下正向和逆向都能进行的反应（用 ⇌ 表示）。

**化学平衡状态定义：**
正反应速率 = 逆反应速率，各物质浓度不再改变。

**平衡的特征——"动、定、变"：**
- **动**：动态平衡（v正 = v逆 ≠ 0，反应并未停止）
- **定**：各物质浓度（或百分含量）保持不变
- **变**：改变条件可使平衡移动

#### 平衡状态的判断标志

**直接标志（等价判断）：**

| 判断依据 | 平衡时的状态 |
|----------|-------------|
| 速率关系 | v正(A) = v逆(A)（同一物质的正逆速率相等） |
| 浓度 | 各物质浓度不再变化 |
| 百分含量 | 各物质的物质的量分数/体积分数不再变化 |

**间接标志（需结合反应特点）：**

| 反应特点 | 判断标志 |
|----------|----------|
| 气体不等计量数反应 | 总压强不再变化、总物质的量不再变化、混合气体平均摩尔质量不再变化 |
| 有色物质参与 | 颜色不再变化 |
| 所有物质均为气体且计量数相等 | 上述间接标志均**不能**作为判断依据 |

### 4. 化学平衡常数

#### 浓度商Q与平衡常数K

对于反应 mA + nB ⇌ pC + qD：

**浓度商：**
$$Q_c = \frac{[C]^p \cdot [D]^q}{[A]^m \cdot [B]^n}$$

**平衡常数：** 当反应达到平衡时，Q_c = K

**K的特征：**
- K只与**温度**有关，与浓度、压强无关
- 固体和纯液体不写入表达式
- K >> 1：反应正向进行程度大（产物为主）
- K << 1：反应正向进行程度小（反应物为主）

**K与ΔH的关系：**
- 放热反应（ΔH < 0）：升温→K减小
- 吸热反应（ΔH > 0）：升温→K增大

### 5. 勒夏特列原理（平衡移动）

**原理：** 如果改变影响平衡的一个条件（浓度、压强或温度），平衡就向能够减弱这种改变的方向移动。

| 改变条件 | 平衡移动方向 | K值变化 |
|----------|-------------|---------|
| 增大反应物浓度 | 正向移动（消耗反应物） | 不变 |
| 减小产物浓度 | 正向移动（补充产物） | 不变 |
| 增大压强（缩小体积） | 向气体分子数减少的方向移动 | 不变 |
| 升高温度 | 向吸热方向移动 | **改变** |
| 加入催化剂 | **不移动**（等同加速正逆反应） | 不变 |

> **⚠️ 关键理解**：
> - 浓度和压强改变不改变K，只改变Q→Q≠K→平衡移动→重新达到Q=K
> - 温度改变K本身→原来的平衡不再平衡→移动到新的K值

#### 合成氨工业条件选择

反应：N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，ΔH = -92.4 kJ/mol

| 条件 | 理论最优 | 工业实际 | 原因 |
|------|----------|----------|------|
| 温度 | 低温（放热反应） | 400-500°C | 低温速率太慢，需折中 |
| 压强 | 高压（分子数减少） | 10-30 MPa | 过高压设备成本太高 |
| 催化剂 | — | 铁基催化剂（含K₂O、Al₂O₃助催化剂） | 加速达到平衡 |
| 浓度 | — | 及时分离NH₃、N₂和H₂循环利用 | 持续正移提高产率 |

### 6. 化学反应的方向

#### 自发过程的判据

| 判据 | 条件 |
|------|------|
| **焓判据** | ΔH < 0（放热）→倾向于自发 |
| **熵判据** | ΔS > 0（混乱度增加）→倾向于自发 |

#### 吉布斯自由能（综合判据）

$$\Delta G = \Delta H - T\Delta S$$

| ΔG | 反应方向 |
|-----|---------|
| ΔG < 0 | 反应自发（正向自发） |
| ΔG = 0 | 平衡状态 |
| ΔG > 0 | 反应非自发（逆向自发） |

**四种组合：**

| ΔH | ΔS | ΔG = ΔH - TΔS | 自发性 |
|-----|-----|---------------|--------|
| < 0 | > 0 | 总是 < 0 | 任何温度自发 |
| > 0 | < 0 | 总是 > 0 | 任何温度非自发 |
| < 0 | < 0 | 低温 < 0，高温 > 0 | 低温自发 |
| > 0 | > 0 | 低温 > 0，高温 < 0 | 高温自发 |

> **典型例子**：
> - NH₄NO₃溶于水（ΔH > 0, ΔS > 0）→低温非自发，高温自发（常温下自发是因为T足够大）
> - 冰在室温下融化（ΔH > 0, ΔS > 0）→273K以上自发

## 知识拓展

### 活化能与碰撞理论

**活化分子与临界能：** 只有碰撞分子的能量等于或超过临界能 $E_c$ 时，才可能发生有效碰撞。活化分子具有的平均能量与反应物分子平均能量之差叫活化能 $E_a$。

**阿伦尼乌斯方程：** 升高温度使活化分子百分数增大，反应速率增大：

$$k = A e^{-\frac{E_a}{RT}}$$

**有效碰撞的两个条件：**
1. **能量因素：** 反应物分子能量达到某一临界数值
2. **空间因素：** 反应物分子必须按一定方向碰撞

以 $\mathrm{NO_2 + CO = NO + CO_2}$ 为例：$\mathrm{N-O}$ 和 $\mathrm{C-O}$ 必须在一条直线上碰撞才能发生反应。即使两个活化分子，不在特定位置碰撞也不能反应。

### 过渡状态理论

20世纪30年代提出的过渡状态理论认为：反应物相互接近时经过中间过渡状态（活化络合物），再转化成产物：

$$A + BC \rightarrow A\cdots B\cdots C \rightarrow AB + C$$

过渡态位能高于始态和终态，形成能垒。活化能即过渡态与始态的位能差 $E_0$。以基元反应 $\mathrm{HI + HI \rightarrow H_2 + 2I\cdot}$ 为例：$E_0$ 约为 180 kJ/mol，远小于 2 个 HI 分子的键能 596 kJ/mol。反应总是能垒低的途径优先。

### 催化剂加速反应的原理

**均相催化：** 反应物与催化剂先生成中间产物，再分解为产物，总活化能比直接反应小得多。例如乙醛碘催化分解：无催化剂 $E_a = 190$ kJ/mol，碘催化后总 $E_a = 136$ kJ/mol，速率增大约 1 万倍。

**多相催化三种理论：**
1. **活性中心理论：** 催化作用发生在催化剂表面活性中心（棱角、凸起、缺陷部位），只占总表面积很小部分（如合成氨铁催化剂活性中心仅占 0.1%）
2. **活化络合物理论：** 反应物被活性中心吸附后形成活化络合物，化学键松弛，活化能大大降低
3. **多位理论：** 活性中心分布具有几何规整性，只有活性中心结构与反应物分子结构成几何对应时，才能形成多位活化络合物

### 反应机理与速率方程

**基元反应：** 一步完成的反应，速率方程可直接按化学计量数写出。例如：

$$\mathrm{CO + NO_2 = CO_2 + NO} \quad v = k \cdot c(\mathrm{CO}) \cdot c(\mathrm{NO_2})$$

**非基元反应：** 速率方程由实验测定反应级数后才能确定。

基元反应的正逆反应速率常数之比等于平衡常数：$K = k_{\text{正}} / k_{\text{逆}}$

### 化学平衡常数的深入理解

**标准平衡常数 $K^\ominus$：** 量纲为一，$K^\ominus = \exp\left(-\frac{\Delta_r G_m^\ominus}{RT}\right)$。**经验平衡常数 $K_p$ 或 $K_c$：** 量纲取决于表达式。当反应物与生成物化学计量数之和相等时，经验平衡常数无量纲，与标准平衡常数相等；否则有量纲，数值与单位有关。

### 化学反应方向的判据

用吉布斯自由能变化 $\Delta G$ 判断等温等压下反应的自发性：$\Delta G = \Delta H - T\Delta S$

| 类型 | $\Delta H$ | $\Delta S$ | $\Delta G$ | 反应方向 |
|------|-----------|-----------|-----------|----------|
| 1 | - 焓减 | + 熵增 | - | 任何温度均自发 |
| 2 | + 焓增 | - 熵减 | + | 任何温度均不自发 |
| 3 | + 焓增 | + 熵增 | 取决于 $T$ | 常温不自发，高温自发 |
| 4 | - 焓减 | - 熵减 | 取决于 $T$ | 常温自发，高温不自发 |

**典型例题：** 氨与氯化氢反应 $\mathrm{NH_3(g) + HCl(g) = NH_4Cl(s)}$ $\Delta H = -176$ kJ/mol。虽为熵减过程，但放热使环境熵增，总熵变 $\Delta S_{\text{总}} > 0$，故自发进行。

### 熵的生物学意义

生命体是开放系统，与环境交换物质、能量和熵。机体摄入高分子物质（低熵），排泄小分子产物（高熵），使环境熵增。薛定谔在《生命是什么》中指出："新陈代谢最基本的内容是有机体成功地使自身释放出它活着时不得不产生的全部熵。"

## 竞赛衔接

- **速率方程**：v = k[A]^m[B]^n（m、n由实验确定，不一定等于计量数）
- **阿伦尼乌斯方程**：k = A·e^(-Eₐ/RT)，ln(k₂/k₁) = Eₐ/R × (1/T₁ - 1/T₂)
- **van't Hoff等温式**：ΔG = ΔG° + RT·lnQ
- **Kp与Kc的转换**：Kp = Kc(RT)^Δn（Δn为气态产物与反应物计量数之差）
- **多重平衡规则**：多个平衡反应相加，总K = 各K之积

## 常见易错

1. ❌ "平衡常数K大的反应速率一定快" → ✅ K描述的是平衡位置（热力学），速率描述的是快慢（动力学），两者无必然联系
2. ❌ "催化剂使平衡正向移动" → ✅ 催化剂不改变平衡位置，只加速达到平衡
3. ❌ "增大压强平衡一定正向移动" → ✅ 只有气体计量数不等时才成立；计量数相等则不移动
4. ❌ "平衡不移动说明反应停止了" → ✅ 动态平衡，正逆反应仍在进行
5. ❌ "升温使放热反应产率降低，所以升温总是不利于反应" → ✅ 升温虽然降低产率但能显著提高速率，工业上需综合考虑
6. ❌ "ΔG > 0的反应永远不会发生" → ✅ 只是正向非自发，局部或短时间尺度内仍可能观察到反应

## 🎯 教学视角

### 教学重点与难点

**重点：**
1. **平衡状态的判断**——直接标志（v正=v逆、浓度不变）和间接标志（总压强不变、颜色不变等需结合反应特点判断）；特别强调"动、定、变"三个特征
2. **勒夏特列原理的定性分析**——浓度、压强、温度改变时平衡移动方向的判断；关键理解：浓度/压强改变K不变只改变Q，温度改变K本身
3. **平衡常数K的计算与影响因素**——K只与温度有关；K与ΔH的关系（放热反应升温K减小，吸热反应升温K增大）
4. **活化能与碰撞理论**——有效碰撞需同时满足能量和空间两个条件；催化剂降低活化能但不改变ΔH和平衡

**难点：**
- **平均速率与即时速率的区分**：教材计算的是平均速率v = Δc/Δt，即时速率用微分表示dc/dt，但速率大小关系仍相同
- **平衡常数K的深层理解**：标准平衡常数K°量纲为一，经验平衡常数Kp或Kc的量纲取决于表达式；只有当气态反应物与生成物计量数之和相等时两者数值相等
- **反应方向的综合判据**：ΔG = ΔH - TΔS的四种组合需要结合具体温度分析，不能仅凭ΔH或ΔS单一因素判断

### 建议教学路径

1. **第一课时：化学反应速率的概念与影响因素**
   - 从实验现象入手：Na₂S₂O₃ + H₂SO₄（硫沉淀计时）、H₂O₂分解（FeCl₃催化）
   - 建立速率表达式v = |Δc|/Δt，强调速率比 = 计量数比
   - 用碰撞理论解释浓度、温度、催化剂对速率的影响
   - 通过分子能量分布曲线图直观展示：温度升高使活化分子百分数增大

2. **第二课时：化学平衡状态的判断**
   - 从可逆反应入手：N₂ + 3H₂ ⇌ 2NH₃，分析反应进程中各物质浓度的变化趋势
   - 建立平衡的"动、定、变"三特征
   - 重点训练平衡状态的等价判断（同一物质v正=v逆）和间接判断（需结合反应特点）
   - 通过Fe³⁺ + SCN⁻平衡体系的实验演示浓度和温度对平衡的影响

3. **第三课时：化学平衡常数与勒夏特列原理**
   - 从浓度商Q引入平衡常数K的定义，强调K只与温度有关
   - 用合成氨工业条件选择为例，综合分析温度、压强、催化剂、浓度的工业选择逻辑
   - 核心问题：为什么合成氨不用低温？（速率太慢，需折中）

4. **第四课时：化学反应的方向**
   - 从自发过程的焓判据和熵判据引入
   - 建立吉布斯自由能ΔG = ΔH - TΔS的综合判据
   - 通过四种组合分析：如NH₄NO₃溶于水（ΔH>0, ΔS>0，常温自发）

5. **第五课时：复习与综合应用**
   - 建构思维导图：速率 → 平衡 → 方向 → 调控的逻辑链
   - 工业实例分析：合成氨、SO₃转化等

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| "平衡常数K大的反应速率一定快" | K描述的是平衡位置（热力学），速率描述的是快慢（动力学），两者无必然联系 |
| "催化剂使平衡正向移动" | 催化剂同等加速正逆反应，不改变平衡位置，只加速达到平衡 |
| "增大压强平衡一定正向移动" | 只有气体计量数不等时才成立；计量数相等则不移动 |
| "平衡不移动说明反应停止了" | 动态平衡，v正=v逆≠0，正逆反应仍在进行 |
| "升温使放热反应产率降低，所以升温总是不利于反应" | 升温虽然降低产率但能显著提高速率，工业上需综合考虑速率与产率的平衡 |
| "ΔG>0的反应永远不会发生" | 只是正向非自发，局部或短时间尺度内仍可能观察到反应 |
| "同一反应中不同物质表示的速率数值不同，说明速率不同" | 速率比 = 计量数比，本质是同一反应的速率，只是表达方式不同 |

### 与现实世界的联系

- **合成氨工业**：哈伯-博施法——在400-500°C、10-30 MPa、铁基催化剂条件下合成NH₃，是20世纪最重要的化学发明之一，使全球粮食产量翻倍
- **生物酶催化**：酶是高效的生物催化剂，降低活化能的同时具有高度选择性，理解酶的作用需要活化能和碰撞理论的知识
- **汽车尾气催化转化**：Pt/Pd/Rh三元催化剂同时催化CO氧化、HC氧化和NOx还原，是催化剂选择性加速特定反应的经典应用
- **食品保存**：低温保存（减缓反应速率）、真空包装（隔绝O₂）、添加抗氧化剂（抑制氧化反应），都是反应速率理论的实际应用
