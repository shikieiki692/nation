# 金属材料

> **对应教材**：人教版必修一第三章第二节（pp.73-84）

## 课标要求

- 以金属材料的发展为例，认识化学在促进社会发展中的重要作用，体会科学、技术、社会之间的相互关系
- 对不同类型合金的性能和用途的认识，强化"性能决定用途"的观念

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据物质类别和元素价态列举铁元素的典型代表物。能利用离子反应、氧化还原反应等概念对铁及其化合物的相关反应进行分类和分析说明。
2. 能列举、描述、辨识铁及其化合物重要的物理、化学性质及实验现象。能用化学方程式、离子方程式正确表示铁及其化合物的主要化学性质。
3. 能从物质类别、元素价态的角度，依据复分解反应和氧化还原反应原理，预测铁及其化合物的化学性质和变化，设计实验进行初步验证，并能分析、解释有关实验现象。
4. 能利用铁及其化合物的性质和反应，设计常见含铁物质制备、分离、提纯、检验等简单任务的方案。能从物质类别和元素价态变化的视角说明物质的转化路径。
5. 能说明常见金属材料对社会发展的价值及对环境的影响。能有意识地运用所学知识或寻求相关证据参与有关金属材料的社会性议题的讨论。

## 核心概念

### 一、合金的概念与本质

**合金**是由一种金属跟其他金属（或非金属）熔合而成的具有金属特性的物质。日常使用的金属材料大多数属于合金。

**合金的性能特征**：
- 合金的硬度一般比其成分金属的**大**
- 合金的熔点一般比其成分金属的**低**
- 合金的抗腐蚀性一般比其成分金属的**好**
- 合金的性能可以通过所添加的合金元素的种类、含量和生成合金的条件等来加以调节

*图："蛟龙"号深海潜水器——钛合金因其高强度、耐腐蚀性被用于制造耐压球壳*

**合金硬度增大的微观解释**：纯金属内所有原子大小和形状相同，排列十分规整，原子层之间容易相对滑动。加入其他元素的原子后（大小不同），改变了金属原子有规则的层状排列，使原子层之间的相对滑动变得困难，导致合金硬度变大。

> **竞赛衔接**：合金的"性能调控"思想在材料化学中非常重要。竞赛中可能考察合金组分对晶体结构和性能的影响。

### 二、铁合金

铁合金是含碳量不同的铁碳合金，分为**生铁**和**钢**两大类。

| 合金 | 含碳量 | 性能特点 | 主要用途 |
|:---|:---:|:---|:---|
| 生铁 | 2%~4.3% | 硬度大、抗压，性脆 | 机座、管道 |
| 钢 | 0.03%~2% | 延展性好，机械性能好 | 机械、交通工具 |

**钢的分类**：

**碳素钢**（按含碳量分）：
- **低碳钢**（含碳<0.3%）：韧性好，可塑性好 → 钢管、钢丝、钢板
- **中碳钢**（含碳0.3%~0.6%）：强度较高 → 齿轮、轴、连杆
- **高碳钢**（含碳0.6%~2%）：硬度大 → 弹簧、刀具、模具

**合金钢**（特种钢）：在碳素钢中加入合金元素获得特殊性能

**不锈钢**：最常见合金钢，含Cr 18%、Ni 8%（或Cr 17%~19%，Ni 8%~13%）
- 在大气中比较稳定，不容易生锈，抗腐蚀能力强
- 用途：医疗器材、厨房用具、餐具、地铁车体

**钢中合金元素的主要作用**：

| 合金元素 | 主要作用 |
|:---|:---|
| 铬(Cr) | 增强耐磨性和抗氧化性；增强高温强度 |
| 锰(Mn) | 防止硫引起的脆性；增强钢的强度和韧性 |
| 钼(Mo) | 降低脆性；增强高温强度 |
| 钨(W) | 提高高温时的强度和硬度 |
| 钴(Co) | 提高红热时的硬度和耐磨性 |
| 镍(Ni) | 增强低温时的韧性；改变高铬钢内部结构 |
| 硅(Si) | 提高强度和硬度；增强高温抗氧化性 |

### 三、铝和铝合金

**铝的化学性质**：
- 铝是地壳中含量**最多**的金属元素
- 常温下与O₂反应生成致密Al₂O₃薄膜（保护膜）
- 铝是活泼金属，既能与酸反应，也能与强碱反应

**铝与酸反应**：
```
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O   （先溶解氧化膜）
2Al + 6HCl → 2AlCl₃ + 3H₂↑       （然后铝与酸反应）
```

**铝与碱反应**：
```
2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑
Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O
```

> **重要概念**：**两性氧化物** — 既能与酸反应生成盐和水，又能与碱反应生成盐和水的氧化物。Al₂O₃是典型的两性氧化物。

**实验现象**：
- 未打磨铝片放入NaOH溶液：开始无气泡（先溶解Al₂O₃膜），一段时间后产生气泡
- 打磨过铝片放入NaOH溶液：立即产生气泡

**重要结论**：由于Al和Al₂O₃均能与酸、碱反应，铝制餐具**不宜**用来蒸煮或长时间存放酸性或碱性食物。

**铝合金**：
- 纯铝硬度和强度较小，不适合制造机器零件
- 向铝中加入Cu、Mg、Si、Mn、Zn及稀土元素等制成铝合金
- **硬铝**（含Cu 4%、Mg 0.5%、Mn 0.5%、Si 0.7%）：密度小、强度高、抗腐蚀能力强 → 制造飞机和宇宙飞船的理想材料

> **竞赛衔接**：Al的两性性质是元素化学中的核心考点。竞赛中会考察Al(OH)₃的酸碱电离平衡：H⁺ + AlO₂⁻ + H₂O ⇌ Al(OH)₃ ⇌ Al³⁺ + 3OH⁻

### 四、新型合金

**储氢合金**：
- 能大量吸收H₂，与H₂结合成金属氢化物
- 要求：储氢量大，氢化物易形成、易分解，室温下吸放氢速率快
- 典型：Ti-Fe合金、La-Ni合金
- 应用前景：氢能汽车的安全储存和运输

**其他新型合金**：
- **钛合金**：高强度、低密度、耐腐蚀 → "蛟龙"号载人潜水器耐压球壳
- **耐热合金**：能承受高温 → 喷气式飞机发动机叶片（镍钴合金，耐1100℃）
- **形状记忆合金**：受力变形后加热可恢复原状 → 航空航天、生物工程

### 五、稀土金属

- 17种元素：镧系15种（原子序数57~71）+ 钪 + 钇
- 被誉为"冶金工业的维生素"（在合金中加入少量稀土可大幅改善性能）
- 我国稀土储量、产量、用量、出口量均居世界**第一**
- 应用：冶金、石油化工、电子材料、永磁材料、超导材料、催化剂等

## 知识拓展

### 铁的合金——生铁与钢

**生铁：** 含碳量2%~4.3%，还含硅、锰及少量硫、磷，可铸不可锻。
- 炼钢生铁（白口铁）：碳以碳化铁形态存在，质硬而脆
- 铸造生铁（灰口铁）：碳以片状石墨形态存在，有良好切削、耐磨和铸造性能
- 球墨铸铁：石墨从片状变为球状，某些性能接近钢

**钢：** 含碳量0.03%~2%，坚硬有韧性，可锻打、压延、铸造。
- 碳素钢：含碳量 < 0.3%（低碳钢）、0.3%~0.6%（中碳钢）、> 0.6%（高碳钢）
- 合金钢（特种钢）：钨钢、锰钢（硬度大）；锰硅钢（韧性好）；钼钢（抗高温）；镍铬钢（不锈钢，抗腐蚀）

**超级钢：** 2017年我国成功研制的超级钢，强度远超普通钢材。

### 铝及铝合金

铝是地壳中含量最高的金属元素（接近8%），密度只有钢铁的1/3。超音速飞机约70%由铝及其合金构成。

铝的两性特征：铝既能与稀酸（盐酸或硫酸）反应，也能与强碱溶液反应生成盐和氢气。放入冷的浓硝酸或浓硫酸中会被钝化。

## 关键实验

### 实验3-4：铝与盐酸反应
- 向试管中加入5mL盐酸，放入铝片
- 现象：先无明显现象（溶解Al₂O₃膜），后产生气泡
- 放出的可燃性气体为H₂

### 实验3-5：铝与NaOH溶液反应
- 向NaOH溶液中分别放入打磨和未打磨的铝片
- 打磨的铝片：立即产生气泡（H₂）
- 未打磨的铝片：先无气泡（Al₂O₃先与NaOH反应），后产生气泡

## 教材例题与练习

**例题**：把5.4g Al放入足量NaOH溶液中完全反应，计算生成H₂的体积（标准状况）。

**解答**：
n(Al) = 5.4g / 27g/mol = 0.2mol
由 2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑
n(H₂) = 0.2 × (3/2) = 0.3mol
V(H₂) = 0.3 × 22.4 = 6.72L

**精选练习**：相同质量的两份铝，分别放入足量的盐酸和NaOH溶液中，放出H₂在同温同压下体积之比为**1:1**（因为两个反应中Al均从0价升到+3价，转移电子数相同）。

## 竞赛衔接

- **Al的两性**：竞赛中Al(OH)₃的酸碱两性电离是核心考点，需掌握Al(OH)₃的Ka和Kb
- **合金的晶体学**：固溶体概念（间隙固溶体vs置换固溶体）、相图基础
- **储氢合金**：金属氢化物的热力学和动力学
- **硬铝的成分**：需记忆典型合金的组分和性能

## 常见易错

1. **合金一定是混合物**：合金中各成分金属保持各自的化学性质，不是化合物
2. **合金的熔点不一定低于所有成分金属**：一般是低于成分金属中熔点较高的那种，但不一定低于最低的
3. **铝不活泼是错误认识**：铝实际上是很活泼的金属（在金属活动性顺序中排在前面），只是因为表面致密氧化膜使其表现出"不活泼"的假象
4. **Al与NaOH反应不是置换反应**：2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑，反应物中有三种物质，不属于四种基本反应类型中的任何一种
5. **铝制餐具不能盛放酸性或碱性食物**：因为Al和Al₂O₃均能与酸和碱反应

## 🎯 教学视角

### 教学重点与难点
- **重点**：合金的概念与性能特征（硬度大、熔点低、耐腐蚀）；铁合金的分类（生铁与钢的含碳量与性能）；铝的两性性质（既能与酸反应又能与碱反应）；“性能决定用途”的观念
- **难点**：铝的两性本质（Al和Al₂O₃均能与酸、碱反应）；合金性能调控的微观解释；从物质类别和元素价态视角理解金属材料的选择与应用

### 建议教学路径
- 以“身边的金属材料”为主题开展社会调查，从日常用品（不锈钢餐具、铝合金门窗、易拉罐）引入，建立“性能→用途”的思维链
- 通过对比实验（打磨vs未打磨铝片放入NaOH溶液）直观展示Al₂O₃保护膜的作用，解释“铝其实很活泼但表现不活泼”的矛盾
- 以“金属材料能否被新型材料替代”为话题组织课堂辩论，引导学生从社会发展角度认识金属材料的价值
- 以“我国稀土金属资源的开发与利用”为主题撰写科技小论文，培养社会参与意识

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 铝不与酸反应 | 铝先溶解表面Al₂O₃膜，然后与酸剧烈反应放出H₂ | 设计对比实验：未打磨铝片放入盐酸，先无气泡后剧烈反应 |
| 不锈钢就是不会生锈的钢 | 不锈钢只是“不容易”生锈，在某些条件下仍会腐蚀 | 强调“不锈”是相对概念，Cl⁻环境（如海水）仍可能腐蚀不锈钢 |
| 合金是化合物 | 合金是混合物，各成分金属保持各自化学性质 | 从微观角度解释：合金中原子排列不如纯金属规整，但未形成化学键结合 |
| 铝比铁不活泼 | 铝实际上比铁活泼得多，铝制品耐用是因为表面氧化膜的保护 | 对比金属活动性顺序中Al和Fe的位置，解释氧化膜的保护作用 |

### 与现实世界的联系
- **日常用品**：不锈钢餐具、铝合金门窗、易拉罐（铝合金）——合金通过调整成分获得所需性能
- **航空航天**：飞机用硬铝（密度小、强度高）、潜水器用钛合金（高强度、耐腐蚀）——极端环境对材料的特殊要求
- **新能源**：储氢合金为氢能汽车提供安全储氢方案——Ti-Fe合金、La-Ni合金能大量吸收和释放H₂
- **信息技术**：稀土永磁材料用于硬盘驱动器、电动汽车电机——我国稀土储量居世界第一，是战略资源优势
- **材料发展史**：石器时代→青铜器时代→铁器时代，材料进步推动了人类文明的发展
