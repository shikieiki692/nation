# 氧化还原反应基础

## 核心概念

### 氧化数的概念

氧化数（也叫氧化态）是人为规定的形式电荷数，用于判断氧化还原。基本规则：

- 单质中元素氧化数为0
- 化合物中各元素氧化数代数和为0
- 单原子离子的氧化数等于电荷数
- H通常为+1（金属氢化物中为-1），O通常为-2（过氧化物中为-1，OF₂中为+2）

### 氧化还原的核心关系

口诀"**升失氧降得还**"：

- 某元素氧化数**升**高 → 该物质**失**电子 → 被**氧**化 → 作**还**原剂
- 某元素氧化数**降**低 → 该物质**得**电子 → 被**还**原 → 作**氧**化剂

记忆方法：还原剂被氧化（升失氧），氧化剂被还原（降得还）。

### 氧化还原与四大反应类型

- **置换反应**一定是氧化还原反应（有单质参与和生成）
- **复分解反应**一定不是氧化还原反应
- **化合反应**和**分解反应**不一定是氧化还原反应，取决于是否有元素化合价变化

### 电子转移表示法

**双线桥法**：在方程式上方用箭头从反应物中某元素指向产物中同种元素，标明"失去/得到 × e⁻"。

例如：Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

- Cu：0 → +2，失去2e⁻（被氧化，作还原剂）
- N：+5 → +4，得到1e⁻（被还原，作氧化剂），共2个N原子各得1e⁻

### 常见氧化剂与还原剂

**常见氧化剂**（得电子，氧化数降低）：

- KMnO₄（Mn：+7→+2，酸性条件下）
- 浓H₂SO₄（S：+6→+4，生成SO₂）
- HNO₃（N：+5→+4或+2）
- Cl₂、Br₂、FeCl₃、H₂O₂

**常见还原剂**（失电子，氧化数升高）：

- 活泼金属：Na、Fe、Al、Zn
- C、CO、H₂（冶金常用还原剂）
- Fe²⁺、S²⁻、I⁻、SO₃²⁻

### 歧化反应与归中反应

- **歧化反应**：同一元素既被氧化又被还原。如Cl₂ + 2NaOH → NaCl + NaClO + H₂O，Cl₂中Cl（0价）一部分升为+1（NaClO），一部分降为-1（NaCl）
- **归中反应**：不同价态的同种元素反应后归为同一中间价态。如Na₂S + Na₂SO₃ + 6HCl → 6NaCl + 3S↓ + 3H₂O，S²⁻（-2）和SO₃²⁻（+4）归为S（0价）。注意归中反应遵循"只靠拢不交叉"原则。

## 竞赛衔接

- 竞赛中氧化还原方程式配平是基本功，需熟练掌握化合价升降法和半反应法
- 竞赛常考陌生氧化还原方程式的配平和电子转移数计算
- 歧化反应和归中反应在元素化学中频繁出现，如Cl₂、S、N的化合物反应

## 常见易错

1. **有单质参与的反应不一定是氧化还原反应**：如石墨转化为金刚石（同素异形体转变），虽然有单质但无化合价变化
2. **Fe³⁺与Cu的反应中，氧化剂是Fe³⁺不是FeCl₃**：写离子方程式时要注意真正起氧化作用的粒子
3. **浓HNO₃的还原产物不一定是NO₂**：稀HNO₃还原产物为NO，极稀时可能生成N₂O甚至NH₄NO₃，还原产物与浓度有关
