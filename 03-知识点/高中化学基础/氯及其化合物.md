# 氯及其化合物

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据钠及其化合物、氯及其化合物的物质类别和元素的化合价列举相应的典型代表物。能利用电离、离子反应、氧化还原反应等概念对含钠元素和氯元素物质的常见反应进行分类。
2. 能够列举、描述、辨识钠及其化合物、氯及其化合物的重要物理、化学性质及实验现象。能用化学方程式、离子方程式正确表示这些典型物质的主要化学性质。
3. 能从物质类别、元素价态的角度，依据复分解反应和氧化还原反应原理，预测钠及其化合物、氯及其化合物的化学性质和变化，设计实验进行初步验证，并能分析、解释有关实验现象。
4. 能利用钠及其化合物、氯及其化合物的性质和反应，设计含钠元素和氯元素物质制备、分离、提纯、检验等简单任务的方案。能从物质类别和元素价态变化的视角说明物质的转化路径。

## 核心概念

### 氯气的制备

**实验室制法**：用MnO₂氧化浓盐酸

![实验室制取氯气装置](06-外部资料导入/高中化学必修一/高中化学必修第一册人民教育出版社课程教材研究所化学课程教材研究开发中心z-library.sk,1lib.sk,z-lib.sk_images/dc2990e4949ff3afa6522c626d3d21f862025de83f299e14422bcaf8bc500901.jpg)

MnO₂ + 4HCl(浓) →△ MnCl₂ + Cl₂↑ + 2H₂O

也可用KMnO₄与浓盐酸反应（无需加热）：

2KMnO₄ + 16HCl(浓) → 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O

**工业制法**：电解饱和食盐水（氯碱工业）

2NaCl + 2H₂O →通电 2NaOH + H₂↑ + Cl₂↑

**尾气处理**：Cl₂有毒，用NaOH溶液吸收

Cl₂ + 2NaOH → NaCl + NaClO + H₂O

### 氯气的性质

- 黄绿色气体，有刺激性气味，密度比空气大，能溶于水（1:2）
- **与金属反应**：2Na + Cl₂ →点燃 2NaCl；2Fe + 3Cl₂ →点燃 2FeCl₃（注意：Fe与Cl₂反应只能生成+3价铁）；Cu + Cl₂ →点燃 CuCl₂
- **与非金属反应**：H₂ + Cl₂ →点燃 2HCl（苍白色火焰）

![H2在Cl2中燃烧实验](06-外部资料导入/高中化学必修一/高中化学必修第一册人民教育出版社课程教材研究所化学课程教材研究开发中心z-library.sk,1lib.sk,z-lib.sk_images/7ee8e8e52adb7cd0e1a28c6e26f779ab6ac896a79d76c7f5dd1276e7a3b684c9.jpg)
- **与水反应**：Cl₂ + H₂O ⇌ HCl + HClO
- **与碱反应**：Cl₂ + 2NaOH → NaCl + NaClO + H₂O

### 氯水的成分

新制氯水中存在三种分子和三种离子：

- **分子**：Cl₂、HClO、H₂O
- **离子**：H⁺、Cl⁻、ClO⁻（少量OH⁻）

久置氯水由于HClO见光分解（2HClO →光照 2HCl + O₂↑），最终变为稀盐酸。

### HClO的漂白原理

HClO具有强氧化性，能氧化有色物质使其褪色。这种漂白是**永久性**的（不可逆），与SO₂的漂白（可逆）不同。

注意：干燥的Cl₂不能漂白干燥的有色布条，因为漂白需要HClO参与。

### 卤素单质性质递变

从F₂到I₂，卤素单质呈现规律性变化：

| 性质 | F₂ | Cl₂ | Br₂ | I₂ |
|------|-----|------|------|-----|
| 颜色 | 淡黄绿 | 黄绿 | 深红棕 | 紫黑 |
| 状态 | 气 | 气 | 液 | 固 |
| 氧化性 | → 依次减弱 | | | |
| 与H₂反应 | 冷暗处爆炸 | 光照爆炸 | 加热反应 | 持续加热可逆 |

### 卤素离子检验

用AgNO₃溶液检验，再加稀HNO₃：

- Cl⁻：生成白色沉淀AgCl（不溶于稀HNO₃）
- Br⁻：生成淡黄色沉淀AgBr（不溶于稀HNO₃）
- I⁻：生成黄色沉淀AgI（不溶于稀HNO₃）

检验Cl⁻也可用**湿润的淀粉KI试纸**：Cl₂ + 2KI → 2KCl + I₂，I₂使淀粉变蓝。但此法不能区分Cl₂和Br₂蒸气。

## 知识拓展

### 氯气毒性机理

Cl₂本身毒性有限，其致毒机理主要依赖于与黏膜表面水分的反应：

Cl₂ + H₂O → HCl + HClO

**双重损伤机制：**
- **HCl（盐酸）**：造成腐蚀性损伤，酸蚀黏膜组织，引起炎症反应
- **HClO（次氯酸）**：造成氧化性损伤，强氧化性破坏细胞膜蛋白质和酶系统，导致细胞坏死

**致死浓度**：空气中Cl₂浓度达0.1%（体积分数，约1000 ppm）时，短时间暴露即可致死。浓度3~5 ppm时可明显感觉到刺激性气味，浓度超过10 ppm时引起剧烈咳嗽和呼吸困难。

**中毒急救**：立即脱离污染区，吸氧，用2%碳酸氢钠溶液洗眼和漱口。

### 漂白粉制备与有效氯

**制备原理：**

2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O

工业上将氯气通入消石灰（Ca(OH)₂粉末）中制得。产品为Ca(ClO)₂和CaCl₂的混合物，有效成分为Ca(ClO)₂。

**有效氯的概念：**

"有效氯"是指漂白粉的氧化能力用等质量Cl₂的氧化能力来表示。其定义为：漂白粉的氧化能力相当于多少质量分数的Cl₂。

计算依据：Ca(ClO)₂ → Cl₂，1 mol Ca(ClO)₂可产生2 mol Cl₂（酸性条件下）。

- 理论有效氯：Ca(ClO)₂分子量143，对应2 mol Cl₂（71 g），理论有效氯 = 71/143 ≈ **49%**
- 商业漂白粉实际有效氯：约**35%**（因含有CaCl₂、Ca(OH)₂等杂质）

**储存要求：**

漂白粉必须密封、干燥储存。暴露在空气中会发生：

Ca(ClO)₂ + CO₂ + H₂O → CaCO₃ + 2HClO

生成的HClO见光分解（2HClO →光照 2HCl + O₂↑），导致有效氯逐渐降低，漂白粉失效。这也是漂白粉不能与"84消毒液"（NaClO溶液）混合使用的原因——二者混合后Ca²⁺与CO₃²⁻/SO₄²⁻可能反应，且酸碱环境改变不利于有效氯保持。

## 竞赛衔接

- 卤素的氧化性/还原性递变及置换反应是竞赛元素化学的基础内容
- 氯气与碱反应（歧化反应）的温度效应（热碱中产物不同）需要掌握
- 氟的特殊性（无正氧化态、HF弱酸、F₂与水反应等）是竞赛常考知识点

## 常见易错

1. **Fe与Cl₂反应只生成FeCl₃**：无论Fe过量与否，Cl₂都能将Fe氧化到+3价。这与Fe与稀盐酸反应（生成FeCl₂）不同
2. **制备Cl₂时必须用浓盐酸**：稀盐酸还原性不够，不能与MnO₂反应。随着反应进行盐酸变稀，反应会自动停止
3. **漂白粉的有效成分是Ca(ClO)₂而非CaCl₂**：漂白粉是Ca(ClO)₂和CaCl₂的混合物，其中起漂白作用的是Ca(ClO)₂

## 🎯 教学视角

### 教学重点与难点
- **重点**：氯气的化学性质（与金属、非金属、水、碱反应）；氯水的成分分析；HClO的漂白原理；Cl⁻的检验方法
- **难点**：Cl₂与H₂O可逆反应的理解；氯水中多种粒子共存的分析；干燥Cl₂与湿润Cl₂漂白性差异的本质

### 建议教学路径
- 从钠及其化合物的知识迁移：先复习钠的研究思路（分类→单质→化合物→性质→用途），再引入氯气的学习
- 采用任务驱动突破难点：预测Cl₂+H₂O的生成物→设计实验证明→书写方程式→对比氯气与水和碱的反应
- 矿泉水瓶对比实验效果显著：先注水振荡（瓶变瘪、颜色变浅），再注NaOH溶液振荡（黄绿色褪去），直观证明反应发生
- 以化学史创设情境：从舍勒发现氯气到戴维确认，让学生体会科学研究精神；以"84消毒液与洁厕灵"的日常安全问题培养社会参与意识

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| Fe与Cl₂反应可能生成FeCl₂ | 无论Fe是否过量，Cl₂都能将Fe氧化到+3价，产物始终是FeCl₃ | 对比Cl₂与稀HCl的氧化性差异：Cl₂强氧化性→Fe³⁺，H⁺弱氧化性→Fe²⁺ |
| 干燥Cl₂能漂白有色布条 | 漂白需要HClO参与，干燥Cl₂不含HClO，不能漂白干燥的有色布条 | 设计对比实验：干燥布条+干燥Cl₂ vs 湿润布条+干燥Cl₂ |
| 氯水的有效成分是Cl₂ | 新制氯水中起漂白作用的是HClO而非Cl₂，久置氯水因HClO分解变为稀盐酸 | 分析氯水成分：Cl₂、HClO、H₂O三种分子共存，强调HClO的强氧化性 |

### 与现实世界的联系
- 自来水消毒使用Cl₂或ClO₂，利用氯的氧化性杀灭水中细菌和病毒
- 84消毒液（NaClO溶液）和漂白粉（Ca(ClO)₂）是日常生活中利用次氯酸盐氧化性进行消毒和漂白的典型产品
- 漂白粉的"有效氯"指标反映漂白能力，工业品漂白粉一般含有效氯35%
- ClO₂消毒能力是等质量Cl₂的2.63倍，且不生成致癌致畸物质，是饮用水消毒的发展方向
