# 钠及其化合物

## 核心概念

### 金属钠的性质

钠是活泼金属，质软（可用刀切），密度0.97 g/cm³（比水小，比煤油大），熔点低（97.8°C）。

**与O₂反应**：
- 常温：4Na + O₂ → 2Na₂O（白色固体）
- 点燃：2Na + O₂ →点燃 Na₂O₂（淡黄色固体）

**与H₂O反应**（现象：浮、熔、游、响、红）：

2Na + 2H₂O → 2NaOH + H₂↑

- 浮：钠密度比水小，浮在水面
- 熔：反应放热使钠熔化成小球
- 游：产生H₂推动钠在水面游动
- 响：发出嘶嘶声
- 红：若加酚酞，溶液变红（生成NaOH）

保存方法：钠保存在煤油或石蜡油中，隔绝空气和水。

### Na₂O与Na₂O₂的区别

| 性质 | Na₂O（氧化钠） | Na₂O₂（过氧化钠） |
|------|----------------|-------------------|
| 颜色 | 白色 | 淡黄色 |
| 氧化数 | O为-2 | O为-1（过氧根O₂²⁻） |
| 与H₂O | Na₂O + H₂O → 2NaOH | 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ |
| 与CO₂ | Na₂O + CO₂ → Na₂CO₃ | 2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂ |
| 用途 | — | 呼吸面具供氧剂、漂白剂 |

Na₂O₂的特殊性：既是氧化剂又是还原剂（O从-1变为-2和0），与H₂O和CO₂反应都能放出O₂。

### NaOH的性质

- 强碱，白色固体，极易溶于水（放热），易潮解
- 与酸反应、与酸性氧化物反应、与两性物质反应
- 不能干燥酸性气体（如CO₂、SO₂、HCl）

### Na₂CO₃与NaHCO₃的比较

| 性质 | Na₂CO₃（纯碱） | NaHCO₃（小苏打） |
|------|----------------|------------------|
| 溶解度 | 较大 | 较小 |
| 热稳定性 | 稳定 | 加热分解：2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑ |
| 与酸反应 | Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ | NaHCO₃ + HCl → NaCl + H₂O + CO₂↑（更快） |
| 与NaOH | 不反应 | NaHCO₃ + NaOH → Na₂CO₃ + H₂O |

**转化关系**：Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃，NaHCO₃ + NaOH → Na₂CO₃ + H₂O

### 焰色反应

某些金属及其化合物在火焰中呈现特征颜色：

- Na：黄色
- K：紫色（透过蓝色钴玻璃观察，滤去Na的黄光）
- Ca：砖红色
- Cu：绿色
- Ba：黄绿色

焰色反应是**物理变化**，不是化学变化。用铂丝或铁丝蘸取样品在火焰上灼烧。

## 常见易错

1. **钠在空气中燃烧生成Na₂O₂而非Na₂O**：常温下缓慢氧化才生成Na₂O，点燃或加热生成Na₂O₂
2. **Na₂O₂与H₂O反应不是简单的置换反应**：O₂²⁻中O为-1价，反应中一部分降到-2（NaOH），一部分升到0（O₂），属于歧化反应
3. **焰色反应不是钠的化合物特有**：所有含钠物质（包括单质Na）焰色都呈黄色，与阴离子无关

## 🎯 教学视角

### 学习路径建议
先掌握 [[氧化还原反应基础]] 中金属活动性顺序和氧化数的概念。钠是碱金属的代表元素，其化学性质（强还原性）是理解其他碱金属的基础。Na₂O₂的歧化反应是氧化还原分析的经典案例。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 钠在空气中燃烧生成Na₂O | 常温缓慢氧化生成Na₂O（白色），点燃或加热生成Na₂O₂（淡黄色），条件不同产物不同 |
| Na₂O₂与H₂O反应是置换反应 | 这是歧化反应：O₂²⁻中O从-1价变为-2（NaOH中）和0（O₂中），Na₂O₂既是氧化剂又是还原剂 |
| Na₂CO₃和NaHCO₃的溶液都呈碱性所以一样 | 虽然都呈碱性，但NaHCO₃碱性更弱，且NaHCO₃能与NaOH反应而Na₂CO₃不能 |

### 入门级例题
**题目**：7.8 g Na₂O₂与足量水反应，能生成多少升O₂（标准状况）？
**解答**：n(Na₂O₂) = 7.8/78 = 0.1 mol。由 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑，n(O₂) = 0.05 mol，V = 0.05×22.4 = 1.12 L。

### 与现实世界的联系
1. 潜水艇和呼吸面具中使用Na₂O₂作为供氧剂，利用其与CO₂和水蒸气反应放出O₂的特性。
2. 焰色反应用于烟花制造：不同金属盐产生不同颜色（Na黄色、K紫色、Cu绿色），是节日烟花五彩缤纷的原因。
