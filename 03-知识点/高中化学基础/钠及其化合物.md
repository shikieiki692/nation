# 钠及其化合物

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据钠及其化合物、氯及其化合物的物质类别和元素的化合价列举相应的典型代表物。能利用电离、离子反应、氧化还原反应等概念对含钠元素和氯元素物质的常见反应进行分类。
2. 能够列举、描述、辨识钠及其化合物、氯及其化合物的重要物理、化学性质及实验现象。能用化学方程式、离子方程式正确表示这些典型物质的主要化学性质。
3. 能从物质类别、元素价态的角度，依据复分解反应和氧化还原反应原理，预测钠及其化合物、氯及其化合物的化学性质和变化，设计实验进行初步验证，并能分析、解释有关实验现象。
4. 能利用钠及其化合物、氯及其化合物的性质和反应，设计含钠元素和氯元素物质制备、分离、提纯、检验等简单任务的方案。能从物质类别和元素价态变化的视角说明物质的转化路径。

## 核心概念

### 金属钠的性质

钠是活泼金属，质软（可用刀切），密度0.97 g/cm³（比水小，比煤油大），熔点低（97.8°C）。

**与O₂反应**：
- 常温：4Na + O₂ → 2Na₂O（白色固体）
- 点燃：2Na + O₂ →点燃 Na₂O₂（淡黄色固体）

**与H₂O反应**（现象：浮、熔、游、响、红）：

![钠与水反应实验](06-外部资料导入/高中化学必修一/高中化学必修第一册人民教育出版社课程教材研究所化学课程教材研究开发中心z-library.sk,1lib.sk,z-lib.sk_images/d732237a7c6b61dd08a83171084711e26c460ce8d91b8b7efb5b4f86d736fc42.jpg)

2Na + 2H₂O → 2NaOH + H₂↑

- 浮：钠密度比水小，浮在水面
- 熔：反应放热使钠熔化成小球
- 游：产生H₂推动钠在水面游动
- 响：发出嘶嘶声
- 红：若加酚酞，溶液变红（生成NaOH）

保存方法：钠保存在煤油或石蜡油中，隔绝空气和水。

### Na₂O与Na₂O₂的区别

| 性质 | Na₂O（氧化钠） | Na₂O₂（过氧化钠） |
|------|----------------|-------------------|
| 颜色 | 白色 | 淡黄色 |
| 氧化数 | O为-2 | O为-1（过氧根O₂²⁻） |
| 与H₂O | Na₂O + H₂O → 2NaOH | 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ |
| 与CO₂ | Na₂O + CO₂ → Na₂CO₃ | 2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂ |
| 用途 | — | 呼吸面具供氧剂、漂白剂 |

Na₂O₂的特殊性：既是氧化剂又是还原剂（O从-1变为-2和0），与H₂O和CO₂反应都能放出O₂。

### NaOH的性质

- 强碱，白色固体，极易溶于水（放热），易潮解
- 与酸反应、与酸性氧化物反应、与两性物质反应
- 不能干燥酸性气体（如CO₂、SO₂、HCl）

### Na₂CO₃与NaHCO₃的比较

| 性质 | Na₂CO₃（纯碱） | NaHCO₃（小苏打） |
|------|----------------|------------------|
| 溶解度 | 较大 | 较小 |
| 热稳定性 | 稳定 | 加热分解：2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑ |
| 与酸反应 | Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ | NaHCO₃ + HCl → NaCl + H₂O + CO₂↑（更快） |
| 与NaOH | 不反应 | NaHCO₃ + NaOH → Na₂CO₃ + H₂O |

**转化关系**：Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃，NaHCO₃ + NaOH → Na₂CO₃ + H₂O

### 焰色反应

某些金属及其化合物在火焰中呈现特征颜色：

- Na：黄色
- K：紫色（透过蓝色钴玻璃观察，滤去Na的黄光）
- Ca：砖红色
- Cu：绿色
- Ba：黄绿色

焰色反应是**物理变化**，不是化学变化。用铂丝或铁丝蘸取样品在火焰上灼烧。

## 知识拓展

### 钠的化学性质补全

**与CO₂反应（灭火相关）：**

4Na + 3CO₂ → 2Na₂CO₃ + C

这一反应在火灾中具有重要警示意义：钠着火时**不能用CO₂灭火器扑救**，因为钠能与CO₂反应，反而加剧燃烧。正确做法是用干燥沙土覆盖。

**工业制备方法：**

工业上通过电解**熔融NaCl**制备金属钠。纯NaCl熔点高达801°C，能耗极大。工业上加入CaCl₂形成共晶混合物，可将熔点降至约600°C，显著降低能耗：

2NaCl(熔融) →通电 2Na + Cl₂↑

**钠的保存：**

钠必须隔绝空气和水保存。常用煤油（密度0.8 g/cm³，钠密度0.97 g/cm³，钠沉于煤油底部）或石蜡油。钠**不能**保存在CCl₄中，因为CCl₄密度（1.59 g/cm³）大于钠，钠会浮在表面而无法完全浸没。

### Na⁺/K⁺/Mg²⁺/Ca²⁺的生理作用

**血浆离子浓度：**

| 离子 | 血浆浓度 | 细胞内浓度 |
|------|----------|------------|
| Na⁺ | 145 mmol/L | 10 mmol/L |
| K⁺ | 4.5 mmol/L | 150 mmol/L |
| Mg²⁺ | 1 mmol/L | 0.5 mmol/L |
| Ca²⁺ | 2.5 mmol/L | <0.001 mmol/L |

注意Na⁺主要在细胞外液（血浆），K⁺主要在细胞内液——这种分布差异由钠钾泵（Na⁺/K⁺-ATPase）主动维持，每消耗1分子ATP排出3个Na⁺、泵入2个K⁺。

**胚胎-海洋起源联系**：人体血浆的离子组成与海水非常相似，这被认为是生命起源于海洋的证据之一。

**生理功能与饮食：**
- Na⁺：维持细胞外液渗透压和酸碱平衡，参与神经信号传递。缺钠导致肌肉痉挛、低血压。主要来源：食盐（NaCl）
- K⁺：维持细胞内液渗透压，参与心肌活动调节。缺钾导致心律失常、肌肉无力。主要来源：香蕉、橙子、土豆、菠菜
- Mg²⁺：300多种酶的辅因子，参与ATP代谢。缺镁导致肌肉震颤、心律失常。主要来源：绿叶蔬菜、坚果
- Ca²⁺：骨骼和牙齿的主要成分，参与血液凝固和肌肉收缩。缺钙导致骨质疏松、抽搐。主要来源：牛奶、豆制品

### 过氧化钠深层知识

**离子化合物本质：**

Na₂O₂是由Na⁺和过氧根离子O₂²⁻组成的离子化合物，而非分子化合物。O-O键为非极性共价键（键长149 pm），两个氧原子共用一对电子，每个氧氧化数为-1。

**强氧化性：**

Na₂O₂具有极强的氧化性，能将Cr³⁺（绿色）氧化为Cr₆⁺（黄色）：

Cr₂(SO₄)₃ + 3Na₂O₂ + 4H₂O → 2Na₂CrO₄ + 3Na₂SO₄ + 4H₂O

这一性质可用于检验Cr³⁺离子。

**危险性：**

Na₂O₂与棉花、活性炭、铝粉等可燃物接触可引发剧烈燃烧甚至爆炸。实验操作中切勿将Na₂O₂撒落在可燃物上。Na₂O₂属于**遇湿易燃物品**和**氧化剂**，运输和储存需严格管控。

**供氧系统原理：**

在潜艇、航天器等密闭环境中，Na₂O₂用于生命保障系统，通过与人呼出的CO₂和水蒸气反应产生O₂：

2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂
2Na₂O₂ + 2H₂O → 4NaOH + O₂↑

### 碳酸钠/碳酸氢钠稳定性规律

**热稳定性序列：**

H₂CO₃ < NaHCO₃ < Na₂CO₃

- H₂CO₃：室温即分解
- NaHCO₃：约50°C开始分解，270°C完全分解：2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑
- Na₂CO₃：851°C熔化而不分解

**碱金属碳酸氢盐稳定性递变：**

LiHCO₃ < NaHCO₃ < KHCO₃

规律：阳离子半径越小，极化能力越强，对HCO₃⁻中O-H键的极化作用越大，越容易促使HCO₃⁻分解。Li⁺半径最小（76 pm），极化能力最强，因此LiHCO₃甚至不存在固体（只能存在于溶液中），加热即分解。Na⁺半径102 pm，KH⁺半径138 pm，极化能力依次减弱，热稳定性依次增强。

这个规律也解释了为什么Li₂CO₃加热也能分解（Li₂CO₃ →△ Li₂O + CO₂↑），而Na₂CO₃不能——小阳离子的高电荷密度使碳酸盐热稳定性降低。

## 常见易错

1. **钠在空气中燃烧生成Na₂O₂而非Na₂O**：常温下缓慢氧化才生成Na₂O，点燃或加热生成Na₂O₂
2. **Na₂O₂与H₂O反应不是简单的置换反应**：O₂²⁻中O为-1价，反应中一部分降到-2（NaOH），一部分升到0（O₂），属于歧化反应
3. **焰色反应不是钠的化合物特有**：所有含钠物质（包括单质Na）焰色都呈黄色，与阴离子无关

## 🎯 教学视角

### 教学重点与难点
- **重点**：钠与水、氧气反应的产物判断；Na₂O与Na₂O₂的性质对比；Na₂CO₃与NaHCO₃的鉴别与相互转化；焰色反应的操作
- **难点**：Na₂O₂与H₂O/CO₂反应中的歧化反应分析（电子转移）；碳酸钠与碳酸氢钠热稳定性差异的微观解释

### 建议教学路径
- 钠的原子结构简单（最外层仅1个电子），可由结构推导性质，降低学习难度；教学贯彻分类思想，从单质到化合物，从物理性质到化学性质再到用途
- 采用对比教学法：Na₂O与Na₂O₂对比（颜色、O的价态、与H₂O/CO₂反应差异），Na₂CO₃与NaHCO₃对比（溶解度、热稳定性、与酸反应速率）
- 以生活情境引入："84消毒液与洁厕灵能否混合使用？"引导学生从氧化还原角度分析
- Na₂O₂的歧化反应是氧化还原分析的经典案例，可结合电子转移图帮助学生理解

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 钠在空气中燃烧生成Na₂O | 常温缓慢氧化生成Na₂O（白色），点燃或加热生成Na₂O₂（淡黄色），条件不同产物不同 | 强调温度区间：160°C以下主要产物Na₂O，250~300°C生成Na₂O₂ |
| Na₂O₂与H₂O反应是置换反应 | 这是歧化反应：O₂²⁻中O从-1价变为-2（NaOH中）和0（O₂中），Na₂O₂既是氧化剂又是还原剂 | 画出电子转移图，让学生看到O₂²⁻中两个O原子"一升一降" |
| Na₂CO₃和NaHCO₃的溶液都呈碱性所以一样 | 虽然都呈碱性，但NaHCO₃碱性更弱，且NaHCO₃能与NaOH反应而Na₂CO₃不能 | 用pH试纸或酚酞对比同浓度溶液的碱性强弱 |

### 与现实世界的联系
- 潜水艇和呼吸面具中使用Na₂O₂作为供氧剂，利用其与CO₂和水蒸气反应放出O₂的特性
- 焰色反应用于烟花制造：不同金属盐产生不同颜色（Na黄色、K紫色、Cu绿色），是节日烟花五彩缤纷的原因
- NaHCO₃（小苏打）在食品工业中用作膨松剂，Na₂CO₃（纯碱）用于玻璃制造和洗涤剂生产
- 电解熔融NaCl制备金属钠，是工业上获取活泼金属的重要方法

### 侯德榜与侯氏制碱法

侯德榜（1890—1974）是中国著名化学家，他将氨碱法（索尔维法）改进为联合制碱法（侯氏制碱法），大幅提高了NaCl的利用率，同时副产NH₄Cl化肥。

**核心反应**：

第一步：向饱和NaCl溶液中先通入NH₃，再通入CO₂，析出NaHCO₃沉淀：

NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl

第二步：加热NaHCO₃使其分解，得到Na₂CO₃：

2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑

**侯氏制碱法的优势**：索尔维法中NaCl利用率仅约70%，副产的CaCl₂几乎无用；侯氏制碱法将NaCl利用率提高到96%以上，副产的NH₄Cl可直接用作氮肥，同时避免了大量CaCl₂废渣的产生。
