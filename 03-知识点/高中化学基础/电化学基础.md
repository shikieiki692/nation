# 电化学基础

> **课标要求**：理解原电池和电解池的工作原理，掌握化学电源的种类与电极反应，理解电解原理及其应用，了解金属腐蚀的类型与防护方法。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能从氧化还原反应的角度认识原电池和电解池的工作原理。
2. 能书写简单的电极反应式和总反应方程式。
3. 能说明常见化学电源的工作原理，体会化学能与电能转化的应用价值。
4. 能运用电解原理说明氯碱工业、电镀等生产中的应用。
5. 能分析金属腐蚀的原因，了解金属防护的常用方法。

## 核心概念

### 1. 原电池

#### 工作原理

**定义：** 将化学能直接转化为电能的装置。本质是自发的氧化还原反应。

**锌铜原电池（含盐桥）：**

![[e550b11528a7165264c9525828826c8d9a5c15d8dc8a1741b3f32a1fe6fa16bc.jpg|Zn-Cu原电池示意图：Zn在ZnSO₄溶液中，Cu在CuSO₄溶液中，通过盐桥连接]]
*图：含盐桥的Zn-Cu原电池——盐桥维持两半电池电荷平衡*

```
     外电路：电子从Zn流向Cu
    ┌────────────────────────┐
    │         导线           │
    │    ┌────┐    ┌────┐   │
    │    │ Zn │    │ Cu │   │
    │    │(-) │    │(+) │   │
    │    └──┬─┘    └─┬──┘   │
    │  ZnSO₄│   盐桥   │CuSO₄│
    │    └──┴─────────┴──┘   │
    └────────────────────────┘
```

| 电极 | 反应 | 类型 |
|------|------|------|
| **负极（Zn）** | Zn - 2e⁻ = Zn²⁺ | 氧化反应 |
| **正极（Cu）** | Cu²⁺ + 2e⁻ = Cu | 还原反应 |
| **总反应** | Zn + Cu²⁺ = Zn²⁺ + Cu | |

**盐桥的作用：**
- 含KCl（或KNO₃）的琼脂凝胶
- K⁺向CuSO₄溶液（正极区）迁移，Cl⁻向ZnSO₄溶液（负极区）迁移
- 维持两半电池的电荷平衡→使电流持续产生

**原电池构成条件：**
1. 两种活泼性不同的电极（或金属+碳棒）
2. 电解质溶液
3. 形成闭合回路
4. 自发的氧化还原反应

**电子与离子流向：**
- 外电路：电子从负极→导线→正极
- 内电路：阳离子向正极迁移，阴离子向负极迁移

### 2. 化学电源

#### 一次电池（不可充电）

**碱性锌锰电池：**

![[d32ce62e1e0ce515ff955e68fd8527caa8dc79be57487f7411c371c11500cbd4.jpg|碱性锌锰电池构造]]

| 电极 | 反应 |
|------|------|
| 负极（Zn） | Zn + 2OH⁻ - 2e⁻ = Zn(OH)₂ |
| 正极（MnO₂） | MnO₂ + H₂O + e⁻ = MnO(OH) + OH⁻ |
| 总反应 | Zn + 2MnO₂ + 2H₂O = 2MnO(OH) + Zn(OH)₂ |

#### 二次电池（可充电）

**铅蓄电池：**
| 状态 | 电极 | 反应 |
|------|------|------|
| 放电（原电池） | 负极（Pb） | Pb + SO₄²⁻ - 2e⁻ = PbSO₄ |
| | 正极（PbO₂） | PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O |
| 充电（电解池） | 阴极（接负极） | PbSO₄ + 2e⁻ = Pb + SO₄²⁻ |
| | 阳极（接正极） | PbSO₄ + 2H₂O - 2e⁻ = PbO₂ + 4H⁺ + SO₄²⁻ |
| **总反应** | | Pb + PbO₂ + 2H₂SO₄ ⇌ 2PbSO₄ + 2H₂O |

**锂离子电池：**
- 负极：LixCy - xe⁻ = xLi⁺ + Cy
- 正极：Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ = LiCoO₂
- 特点：Li⁺在充放电过程中在两极间往返嵌入/脱出（"摇椅电池"）

#### 燃料电池

**H₂-O₂燃料电池（酸性电解质）：**
| 电极 | 反应 |
|------|------|
| 负极 | H₂ - 2e⁻ = 2H⁺ |
| 正极 | ½O₂ + 2H⁺ + 2e⁻ = H₂O |
| 总反应 | H₂ + ½O₂ = H₂O |

**特点：**
- 能量转换效率 > 80%（热电厂~30%）
- 燃料和氧化剂连续供给，不储存在电池内
- 可用H₂、CH₃OH、N₂H₄等作燃料

![[4d2951312500b6811a67284f98b22714243ff66aa60fa95e91c5a65d82e39221.jpg|氢氧燃料电池工作原理：H₂在负极氧化，O₂在正极还原，质子交换膜传递H⁺]]

> **竞赛衔接**：碱性燃料电池（KOH电解质）的正极反应为：O₂ + 2H₂O + 4e⁻ = 4OH⁻

### 3. 电解池

#### 电解原理

**定义：** 通电使非自发氧化还原反应发生的装置。将电能转化为化学能。

| 对比项 | 原电池 | 电解池 |
|--------|--------|--------|
| 能量转化 | 化学能→电能 | 电能→化学能 |
| 反应类型 | 自发反应 | 非自发反应（外加电能驱动） |
| 电极名称 | 负极（氧化）、正极（还原） | 阴极（还原）、阳极（氧化） |

**CuCl₂溶液电解：**
| 电极 | 反应 | 现象 |
|------|------|------|
| 阳极（接正极） | 2Cl⁻ - 2e⁻ = Cl₂↑ | 黄绿色刺激性气体 |
| 阴极（接负极） | Cu²⁺ + 2e⁻ = Cu | 红色固体析出 |
| 总反应 | CuCl₂ $\xrightarrow{\text{电解}}$ Cu + Cl₂↑ | |

#### 电解原理的应用

**(a) 氯碱工业（电解饱和食盐水）：**
| 电极 | 反应 |
|------|------|
| 阳极 | 2Cl⁻ - 2e⁻ = Cl₂↑ |
| 阴极 | 2H₂O + 2e⁻ = H₂↑ + 2OH⁻ |
| 总反应 | 2NaCl + 2H₂O $\xrightarrow{\text{电解}}$ Cl₂↑ + H₂↑ + 2NaOH |

- 使用离子交换膜电解槽
- 产品：NaOH（烧碱）、Cl₂、H₂

**(b) 电镀：**
- 镀件作阴极，镀层金属作阳极
- 电解质溶液含镀层金属离子
- 例：在铁上镀铜→Fe为阴极，Cu为阳极，CuSO₄溶液为电解质

**(c) 铜的电解精炼：**
- 粗铜作阳极（溶解，杂质形成"阳极泥"，其中含Au、Ag等贵金属）
- 纯铜作阴极（Cu²⁺还原析出纯铜）
- CuSO₄溶液为电解质

**(d) 电冶金（冶炼活泼金属）：**
- 电解熔融NaCl：2NaCl(熔融) $\xrightarrow{\text{电解}}$ 2Na + Cl₂↑
- 电解熔融Al₂O₃（加冰晶石Na₃AlF₆作助熔剂降低熔点）：2Al₂O₃ $\xrightarrow{\text{电解}}$ 4Al + 3O₂↑

### 4. 金属的腐蚀与防护

#### 金属腐蚀的类型

| 类型 | 原理 | 条件 |
|------|------|------|
| **化学腐蚀** | 金属与O₂、Cl₂、SO₂等直接反应 | 高温或接触腐蚀性气体 |
| **电化学腐蚀** | 不纯金属与电解质形成微电池 | 更常见、危害更大 |

#### 电化学腐蚀（重点）

**(a) 析氢腐蚀（酸性环境）：**
| 电极 | 反应 |
|------|------|
| 负极（Fe） | Fe - 2e⁻ = Fe²⁺ |
| 正极（C） | 2H⁺ + 2e⁻ = H₂↑ |
| 总反应 | Fe + 2H⁺ = Fe²⁺ + H₂↑ |

**(b) 吸氧腐蚀（弱酸性/中性，最常见）：**
| 电极 | 反应 |
|------|------|
| 负极（Fe） | Fe - 2e⁻ = Fe²⁺ |
| 正极（C） | 2H₂O + O₂ + 4e⁻ = 4OH⁻ |
| 总反应 | 2Fe + O₂ + 2H₂O = 2Fe(OH)₂ |

后续变化：Fe(OH)₂ →（O₂/H₂O）→ Fe(OH)₃ → Fe₂O₃·xH₂O（铁锈）

> **实验4-3**：铁钉吸氧腐蚀——将铁钉放入NaCl溶液中，连接一根细管→管内水面上升（O₂被消耗，气压降低）

#### 金属的防护方法

| 方法 | 原理 | 示例 |
|------|------|------|
| **改变材料组成** | 合金化提高耐蚀性 | 不锈钢（加Cr、Ni） |
| **表面覆盖保护层** | 隔绝腐蚀介质 | 涂漆、涂油脂、电镀、化学钝化（Fe₃O₄膜）、阳极氧化（Al₂O₃膜） |
| **牺牲阳极法** | 接更活泼金属→优先腐蚀 | 船体焊锌块、地下管道接镁块 |
| **外加电流法** | 被保护金属接电源负极→阴极保护 | 大型储罐、海底管道 |

**牺牲阳极法详解：**
- 将比Fe更活泼的金属（Mg或Zn）与钢铁连接
- 活泼金属成为负极（优先被腐蚀）
- 钢铁成为正极（被保护）
- **实验4-4**：Fe-Zn在NaCl溶液中→K₃[Fe(CN)₆]检验→无蓝色沉淀（Fe²⁺未生成，Fe被保护）

**外加电流法详解：**
- 被保护金属接直流电源负极（阴极）
- 辅助电极（惰性电极）接正极
- 强制电子流向被保护金属→消除腐蚀电流

## 知识拓展

### 电化学简史

- **1789年** 伽伐尼发现青蛙腿痉挛现象，提出生物电假说
- **1799年** 伏打研制能维持一定电流的电堆；同年卡里斯尔和尼科尔森用电堆电解水得到 $\mathrm{H_2}$ 和 $\mathrm{O_2}$
- **1807年** 戴维利用伏打电堆电解制得钾和钠
- **1833年** 法拉第发表电解定律
- **1839年** 格罗夫发明燃料电池（利用 $\mathrm{H_2}$ 和 $\mathrm{O_2}$ 获得电能）
- **1889年** 能斯特提出计算电极电势的热力学方程
- **1905年** 塔费尔发现超电势与电流密度对数的线性关系

### 电极类型与电极反应

**第一类：金属电极和气体电极**
- 金属电极：$\mathrm{M | M^{n+}}$，电极反应 $\mathrm{M \rightleftharpoons M^{n+} + ne^-}$
- 氢电极：$\mathrm{2H^+ + 2e^- \rightleftharpoons H_2}$（酸性）或 $\mathrm{2H_2O + 2e^- \rightleftharpoons H_2 + 2OH^-}$（碱性）
- 氧电极：$\mathrm{O_2 + 2H_2O + 4e^- \rightleftharpoons 4OH^-}$

**第二类：难溶性盐电极和难溶性氧化物电极**
- 甘汞电极：$\mathrm{Hg_2Cl_2 + 2e^- \rightleftharpoons 2Hg + 2Cl^-}$
- 银-氯化银电极：$\mathrm{AgCl + e^- \rightleftharpoons Ag + Cl^-}$
- 这类电极不与金属离子可逆，而与难溶盐的阴离子可逆，大大扩展了电化学研究范围

**第三类：氧化还原电极**
- 具有不同氧化态的同种元素相互转化构成
- 例如 $\mathrm{Fe^{3+} + e^- \rightleftharpoons Fe^{2+}}$

### 电极电势的测定

**标准氢电极：** 铂片上镀蓬松铂黑，放入 $c(\mathrm{H^+}) = 1$ mol/kg 硫酸中，25°C 通入 100 kPa 纯 $\mathrm{H_2}$。被 $\mathrm{H_2}$ 饱和的铂片与硫酸间的电势差规定为零。

**双电层形成：** 金属放入盐溶液时，金属离子进入溶液（或溶液中离子沉积到金属上），最终达到平衡，形成双电层，产生电势差。金属越活泼，越易失去电子，离子进入溶液的倾向越大。

**标准电极电势表（部分关键数据）：**

| 电极 | $\varphi^\theta$/V | 性质 |
|------|---------------------|------|
| $\mathrm{Li^+/Li}$ | -3.045 | 最强还原剂 |
| $\mathrm{Zn^{2+}/Zn}$ | -0.763 | 常见还原剂 |
| $\mathrm{H^+/H_2}$ | 0.00 | 参考标准 |
| $\mathrm{Cu^{2+}/Cu}$ | +0.340 | |
| $\mathrm{Ag^+/Ag}$ | +0.800 | |
| $\mathrm{F_2/F^-}$ | +2.87 | 最强氧化剂 |

### 燃料电池及其效率

传统能源转化途径：化学能 $\rightarrow$ 热能 $\rightarrow$ 机械能 $\rightarrow$ 电能，能量利用率不超过 35%（受热机限制）。**燃料电池**使化学能直接转化为电能，效率极高（80%~98%）。

标态 25°C 时氢氧燃料电池理论效率：$\eta = \frac{-nEF}{\Delta_r H_m} = \frac{-237.16}{-285.84} \times 100\% = 83\%$

| 燃料电池反应 | $\Delta_r H_m^\theta$/(kJ·mol⁻¹) | $E^\theta$/V | $\eta$/% |
|-------------|-----------------------------------|--------------|--------|
| $\mathrm{H_2 + \frac{1}{2}O_2 \rightarrow H_2O(l)}$ | -285.84 | 1.229 | 83 |
| $\mathrm{CH_4 + 2O_2 \rightarrow CO_2 + 2H_2O(l)}$ | -890.36 | 1.060 | 92 |
| $\mathrm{CH_3OH + \frac{3}{2}O_2 \rightarrow CO_2 + 2H_2O(l)}$ | -719.23 | 1.207 | 97 |
| $\mathrm{N_2H_4(aq) + O_2 \rightarrow N_2 + 2H_2O(l)}$ | -605.84 | 1.559 | 99 |

### 分解电压与电极极化

**分解电压：** 使电解顺利进行的最低电压。电解 0.100 mol/L $\mathrm{Na_2SO_4}$ 溶液时，理论分解电压 1.23 V，实际分解电压 1.7 V。

**电极极化两种情况：**
1. **浓差极化：** 离子扩散速率慢导致电极附近浓度与溶液中间不同，可通过搅拌和升温消除
2. **电化学极化：** 电解产物析出过程中某一步骤反应速率迟缓导致电极电势偏离可逆电势，搅拌不能消除

**超电势：** $\eta = |\varphi_{\text{实}} - \varphi_{\text{理}}|$，超电压 $E_{\text{超}} = \eta_{\text{阴}} + \eta_{\text{阳}}$。影响因素：电解产物（金属小，气体大）、电极材料和表面状态、电流密度。

**应用实例：** 铁板上电镀锌时，若无超电势 $\varphi(\mathrm{H^+/H_2}) > \varphi(\mathrm{Zn^{2+}/Zn})$，阴极应析出 $\mathrm{H_2}$。但控制条件使氢超电势变大，即可析出金属锌。

### 金属腐蚀的几种情况

1. **尘粒/水滴腐蚀：** 尘粒覆盖的中心部位供氧少，边缘供氧多，金属在中心溶解
2. **裂缝腐蚀：** 裂缝外部被导电氧化物覆盖处发生 $\mathrm{O_2}$ 还原，内部无保护层处腐蚀
3. **涂层下腐蚀：** 涂层擦伤或裂缝使腐蚀发生在涂层里面
4. **土壤腐蚀：** 通过不同土壤时，供氧量不同形成腐蚀电池（如黏土 vs 沙土）
5. **白铁皮 vs 镀锡铁皮：** 镀锌铁（白铁皮）锌为阳极先腐蚀保护铁；镀锡铁锡为阳极时铁被腐蚀

## 教材例题/习题

1. **原电池正负极判断**：活泼金属为负极，不活泼金属/碳棒为正极
2. **电极反应式书写**：先判断氧化/还原，再写半反应，最后加电子
3. **电解产物判断**：先确定阳极（氧化）和阴极（还原）→看溶液中什么离子放电
4. **腐蚀类型判断**：酸性强→析氢腐蚀；中性/弱酸→吸氧腐蚀

## 竞赛衔接

- **标准电极电位（Eθ）**：定量判断氧化还原反应方向和原电池电动势
- **Nernst方程**：非标准状态下的电极电位计算
- **法拉第电解定律**：m = MIt/(nF)，电极上析出物质质量与电量的关系
- **电化学腐蚀的定量分析**：腐蚀速率与溶液pH、O₂浓度的关系
- **电有机合成**：己二腈的电化学合成（丙烯腈电还原偶联）

## 常见易错

1. ❌ "原电池中正极发生氧化反应" → ✅ 正极发生**还原**反应（得电子）
2. ❌ "电解池中阳极发生还原反应" → ✅ 阳极发生**氧化**反应（失电子）
3. ❌ "盐桥中的离子不参与电极反应" → ✅ 正确，盐桥只传导离子维持电荷平衡
4. ❌ "电解NaCl溶液得到Na和Cl₂" → ✅ 是电解饱和食盐水得到NaOH、Cl₂和H₂（不是电解熔融NaCl）
5. ❌ "Fe在干燥空气中不会被腐蚀" → ✅ 化学腐蚀仍可发生（高温下与O₂反应），只是速率较慢
6. ❌ "牺牲阳极法和外加电流法原理相同" → ✅ 不同：牺牲阳极法是利用原电池原理（活泼金属作负极优先腐蚀），外加电流法是利用电解池原理（外接电源强制被保护金属作阴极）

## 🎯 教学视角

### 教学重点与难点

**重点：**
1. **原电池和电解池的对比**——能量转化方向相反（化学能→电能 vs 电能→化学能）；电极名称和反应类型的对应关系（原电池：负极氧化/正极还原；电解池：阳极氧化/阴极还原）
2. **电极反应式的书写**——先判断氧化/还原，再写半反应，最后加电子；注意碱性/酸性介质中电极反应式的书写差异
3. **电化学腐蚀的两种类型**——析氢腐蚀（酸性环境）和吸氧腐蚀（弱酸性/中性，更常见）；判断依据是溶液pH
4. **金属防护方法的原理**——牺牲阳极法（原电池原理）vs 外加电流法（电解池原理）的本质区别

**难点：**
- **盐桥的作用机制**：盐桥中的K⁺和Cl⁻不参与电极反应，只通过离子迁移维持两半电池的电荷平衡，使电流持续产生
- **电解产物的判断**：阳极优先放电顺序（活泼金属电极自身溶解 > S²⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根）；阴极优先放电顺序（Ag⁺ > Cu²⁺ > H⁺ > Fe²⁺ > Zn²⁺ > Na⁺）
- **牺牲阳极法与外加电流法的原理区分**：前者利用原电池原理（活泼金属作负极优先腐蚀），后者利用电解池原理（外接电源强制被保护金属作阴极）

### 建议教学路径

1. **第一课时：原电池的工作原理**
   - 从锌铜原电池（含盐桥）实验入手，观察电流计偏转和电极现象
   - 建立原电池的四个构成条件
   - 分析电子与离子的流向：外电路电子从负极→正极，内电路阳离子向正极迁移、阴离子向负极迁移
   - 引导学生从氧化还原反应角度理解：负极失电子（氧化），正极得电子（还原）

2. **第二课时：化学电源**
   - 一次电池：碱性锌锰电池的电极反应
   - 二次电池：铅蓄电池的放电（原电池）和充电（电解池）过程对比
   - 燃料电池：H₂-O₂燃料电池的电极反应，强调能量转换效率>80%（远高于热电厂~30%）
   - 锂离子电池："摇椅电池"的工作原理

3. **第三课时：电解池的工作原理**
   - 从CuCl₂溶液电解实验入手，观察阳极产生Cl₂（黄绿色气体）、阴极析出Cu（红色固体）
   - 建立电解池的电极命名和反应类型
   - 对比原电池与电解池：能量转化方向相反，但电化学本质都是氧化反应和还原反应
   - 讲解放电顺序，用于判断电解产物

4. **第四课时：电解原理的应用**
   - 氯碱工业：电解饱和食盐水，使用离子交换膜电解槽
   - 电镀：镀件作阴极，镀层金属作阳极
   - 铜的电解精炼：粗铜作阳极（杂质形成"阳极泥"），纯铜作阴极
   - 电冶金：电解熔融NaCl制Na、电解熔融Al₂O₃（加冰晶石助熔）制Al

5. **第五课时：金属的腐蚀与防护**
   - 化学腐蚀 vs 电化学腐蚀的区别
   - 析氢腐蚀（酸性环境）和吸氧腐蚀（中性/弱酸性）的电极反应
   - 实验演示：铁钉吸氧腐蚀（侧管水面上升证明O₂被消耗）
   - 四种防护方法：改变材料组成、表面覆盖保护层、牺牲阳极法、外加电流法

6. **第六课时：综合复习与实验**
   - 电镀实验（Cu镀Fe）和燃料电池制作实验
   - 原电池与电解池的综合判断练习

### 常见认知误区

| 误区 | 纠正 |
|------|------|
| "原电池中正极发生氧化反应" | 正极发生**还原**反应（得电子），负极发生氧化反应（失电子） |
| "电解池中阳极发生还原反应" | 阳极发生**氧化**反应（失电子），阴极发生还原反应（得电子） |
| "盐桥中的离子参与电极反应" | 盐桥只传导离子维持电荷平衡，K⁺和Cl⁻不参与电极反应 |
| "电解NaCl溶液得到Na和Cl₂" | 是电解饱和食盐水得到NaOH、Cl₂和H₂（电解熔融NaCl才能得到Na） |
| "Fe在干燥空气中不会被腐蚀" | 化学腐蚀仍可发生（高温下与O₂反应），只是速率较慢 |
| "牺牲阳极法和外加电流法原理相同" | 不同：牺牲阳极法利用原电池原理（活泼金属作负极优先腐蚀），外加电流法利用电解池原理（外接电源强制被保护金属作阴极） |
| "燃料电池的能量转换效率与热电厂相同" | 燃料电池效率>80%（化学能直接转化为电能），热电厂仅~30%（受热机卡诺循环限制） |

### 与现实世界的联系

- **电动汽车与储能**：锂离子电池是电动汽车和手机的核心，理解充放电过程的电极反应有助于认识电池容量衰减和安全问题
- **氯碱工业**：电解饱和食盐水生产NaOH、Cl₂和H₂，是化学工业的基础，产品广泛用于造纸、纺织、水处理
- **金属防腐工程**：船舶焊锌块（牺牲阳极法）、海底管道外加电流保护，每年可减少数千亿元的金属腐蚀损失
- **燃料电池与新能源**：氢燃料电池效率>80%，是未来清洁能源的重要方向；甲醇燃料电池、肼燃料电池也在航天和潜艇中应用
- **生物电化学**：细胞膜电位（静息电位约-70 mV）和动作电位的产生本质是离子的选择性透过和浓度差，是神经传导的电化学基础
- **电镀与表面处理**：装饰性电镀（Cr、Ni）、防腐电镀（Zn、Cd）、功能性电镀（硬铬）广泛应用于汽车、电子、航空航天行业
