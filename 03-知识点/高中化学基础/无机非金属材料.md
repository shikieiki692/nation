# 无机非金属材料

> **课标要求**：了解传统硅酸盐材料和新型无机非金属材料的组成、性质与应用，认识硅及含硅化合物在信息、能源等领域的重要作用，了解自然资源的开发利用。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能从材料组成的角度对生活中常见的无机非金属材料进行分析，能根据使用需求选择适当的材料，能解释其使用注意事项，并能科学合理地使用。

## 核心概念

### 1. 传统硅酸盐材料

**硅酸盐结构基础：**
- 基本结构单元：SiO₄四面体（每个Si与4个O形成共价键）
- 四面体通过共用顶角O原子连接→形成链状、层状或三维骨架结构
- 这种结构赋予硅酸盐材料：高硬度、不溶于水、耐高温、耐腐蚀

![SiO₄硅氧四面体结构示意图，Si位于中心，4个O位于四面体顶角](../人教版高中化学课本/【2】人教版·化学必修第二册_images/184bc74e98966101fa6707b463864387e261244a81b4444fa702b9001bf07f56.jpg)
*图：SiO₄硅氧四面体——硅酸盐的基本结构单元*

#### 陶瓷

| 项目 | 内容 |
|------|------|
| 原料 | 黏土（含水硅酸铝） |
| 工艺 | 成型→高温烧结 |
| 特性 | 耐高温、绝缘、耐腐蚀 |
| 应用 | 建筑材料、绝缘器皿、古代瓷器 |

#### 玻璃

| 项目 | 内容 |
|------|------|
| 主要成分 | Na₂SiO₃、CaSiO₃、SiO₂ |
| 原料 | 纯碱Na₂CO₃ + 石灰石CaCO₃ + 石英砂SiO₂ |
| 反应 | Na₂CO₃ + SiO₂ $\xrightarrow{\text{高温}}$ Na₂SiO₃ + CO₂↑；CaCO₃ + SiO₂ $\xrightarrow{\text{高温}}$ CaSiO₃ + CO₂↑ |
| 类型 | 普通玻璃、光学玻璃（含PbO）、硼硅玻璃（耐热耐化学）、有色玻璃（金属氧化物着色） |

> **⚠️ 注意**：玻璃是非晶体（无固定熔点），属于混合物。

#### 水泥

| 项目 | 内容 |
|------|------|
| 原料 | 黏土 + 石灰石 |
| 工艺 | 回转窑高温煅烧→熟料→加石膏调节凝固速度 |
| 应用 | 砂浆（水泥+沙+水）、混凝土（水泥+沙+碎石+水） |

### 2. 硅（Si）与二氧化硅（SiO₂）

#### 硅单质

| 项目 | 内容 |
|------|------|
| 位置 | 第三周期第ⅣA族 |
| 性质 | 灰黑色、有金属光泽的固体 |
| 导电性 | **半导体**（介于导体和绝缘体之间） |
| 应用 | 计算机芯片、太阳能电池 |

**工业制硅：**
$$\text{SiO}_2 + 2\text{C} \xrightarrow{\text{高温}} \text{Si(粗)} + 2\text{CO}\uparrow$$
$$\text{Si(粗)} + 3\text{HCl} \xrightarrow{300°\text{C}} \text{SiHCl}_3 + \text{H}_2$$
$$\text{SiHCl}_3 + \text{H}_2 \xrightarrow{1100°\text{C}} \text{Si(纯)} + 3\text{HCl}$$

#### 二氧化硅（SiO₂）

| 性质 | 内容 |
|------|------|
| 结构 | 原子晶体，每个Si与4个O成键，每个O桥接2个Si |
| 熔点 | 极高（1723°C） |
| 硬度 | 大（硬度7） |

**关键化学反应：**

| 反应 | 方程式 | 说明 |
|------|--------|------|
| 与HF反应 | SiO₂ + 4HF = SiF₄↑ + 2H₂O | HF可蚀刻玻璃（唯一能与SiO₂反应的酸） |
| 与NaOH反应 | SiO₂ + 2NaOH = Na₂SiO₃ + H₂O | 因此不能用玻璃瓶装NaOH |
| 与Na₂CO₃高温反应 | SiO₂ + Na₂CO₃ $\xrightarrow{\text{高温}}$ Na₂SiO₃ + CO₂↑ | 高温下非挥发性酸酐置换挥发性酸酐 |

> **竞赛衔接**：SiO₂是原子晶体（共价网络），每个Si-O键能约452 kJ/mol。石英玻璃是SiO₂的非晶态。

**SiO₂的重要用途：**
- 光导纤维（光通信，传输容量大、抗干扰、衰减低）
- 石英晶体（压电效应，用于钟表和电子振荡器）
- 光学镜片（紫外到红外透过率高）

### 3. 新型无机非金属材料

#### 碳化硅（SiC，金刚砂）

| 项目 | 内容 |
|------|------|
| 结构 | 类似金刚石的原子晶体，Si和C交替排列 |
| 硬度 | 极高（接近金刚石） |
| 耐温 | 1600°C以上仍保持强度 |
| 应用 | 磨料、切削工具、高温结构材料、耐火材料 |

#### 其他新型陶瓷

| 类型 | 特性 | 应用 |
|------|------|------|
| 氮化硅(Si₃N₄)陶瓷 | 熔点高（约1900°C）、硬度大（仅次于金刚石和碳化硅）、电绝缘性好、化学性质稳定、耐腐蚀 | 发动机部件（涡轮增压器转子）、切削刀具、轴承、高温结构件 |
| 高温结构陶瓷 | 耐高温、高强度 | 发动机部件、航天器 |
| 压电陶瓷 | 受压产生电信号 | 传感器、打火机点火 |
| 透明陶瓷 | 光学透明 | 高压钠灯灯管 |
| 超导陶瓷 | 低温零电阻 | 磁悬浮、输电 |

> **氮化硅(Si₃N₄)**：是一种重要的结构陶瓷材料，属于共价键化合物。其制备方法包括反应烧结法和热压烧结法。Si₃N₄的高硬度、耐高温和自润滑特性使其成为替代金属制造发动机高温部件的理想材料，可大幅减轻发动机重量并提高工作温度，从而提升热效率。

### 4. 碳纳米材料

| 材料 | 结构 | 特性 | 应用 |
|------|------|------|------|
| **C₆₀（富勒烯）** | 球形笼状，60个C构成五元环和六元环 | 可溶于有机溶剂、超导掺杂 | 材料科学、医学 |
| **碳纳米管** | 石墨片卷成的管状结构 | 比表面积大、强度极高、导电性好 | 复合材料、电池、传感器 |
| **石墨烯** | 单层石墨（一层碳原子） | 电阻率极低、导热性极好、强度极高 | 光电子器件、超级电容器、电池 |

> **竞赛衔接**：石墨烯是2010年诺贝尔物理学奖（Geim & Novoselov）。C₆₀是1996年诺贝尔化学奖（Kroto, Curl, Smalley）。

### 5. 自然资源的开发利用

#### 金属冶炼

| 方法 | 适用金属 | 示例 |
|------|----------|------|
| 热分解法 | 不活泼金属（Hg, Ag） | 2HgO $\xrightarrow{\Delta}$ 2Hg + O₂↑ |
| 热还原法（C/CO/H₂） | 中等活泼金属 | Fe₂O₃ + 3CO $\xrightarrow{\text{高温}}$ 2Fe + 3CO₂ |
| 铝热反应 | 难熔金属 | Fe₂O₃ + 2Al $\xrightarrow{\text{点燃}}$ 2Fe + Al₂O₃ |
| 电解法 | 活泼金属（Na, Ca, Mg, Al） | 2Al₂O₃(熔融) $\xrightarrow{\text{电解}}$ 4Al + 3O₂↑ |

> **铝热反应**：2Al + Fe₂O₃ $\xrightarrow{\text{点燃}}$ Al₂O₃ + 2Fe，ΔH = -851.5 kJ/mol，放出大量热使Fe呈液态。可用于野外焊接铁轨。

#### 海水资源

| 资源 | 提取方法 |
|------|----------|
| NaCl | 蒸发结晶（"盐田法"） |
| Br₂ | "空气吹出法"：Cl₂氧化Br⁻→空气吹出→SO₂吸收→再氧化→蒸馏 |
| Mg | 加石灰乳沉淀Mg(OH)₂→加HCl→电解熔融MgCl₂ |
| 淡水 | 蒸馏法、反渗透法、电渗析法 |

#### 煤和石油

| 加工方式 | 原理 | 产品 |
|----------|------|------|
| 煤的干馏（焦化） | 隔绝空气加强热 | 焦炭、煤焦油、焦炉气、粗苯 |
| 煤的气化 | C + H₂O(g) $\xrightarrow{\text{高温}}$ CO + H₂ | 水煤气（合成气） |
| 煤的液化 | 直接加氢或间接合成 | 液体燃料 |
| 石油分馏 | 利用沸点不同分离 | 汽油、煤油、柴油等 |
| 石油裂化 | 大分子断裂为小分子 | 提高汽油产量 |
| 石油裂解 | 深度裂化（>800°C） | 乙烯、丙烯等化工原料 |

## 知识拓展

### 纳米陶瓷与先进陶瓷

陶瓷材料按制造工艺和性能可分为三个层次：

| 类型 | 代表材料 | 特征 | 典型应用 |
|------|----------|------|----------|
| **传统陶瓷** | 黏土砖、瓷器 | 天然原料，烧结温度较低，性能有限 | 建筑材料、日用器皿 |
| **先进陶瓷（精细陶瓷）** | Al₂O₃、Si₃N₄、SiC、ZrO₂ | 人工合成高纯粉体，高温烧结，强度高、耐温、耐腐蚀 | 切削工具、发动机部件、人工关节 |
| **纳米陶瓷** | 晶粒尺寸<100 nm的陶瓷 | 超塑性（可像金属一样加工变形），高强度、高韧性 | 航天热障涂层、生物医学植入体、微型传感器 |

先进陶瓷的优异性能源于其均匀的微观结构和高纯度原料；纳米陶瓷则因晶粒极细而消除了传统陶瓷的脆性缺陷。

### Si与碱的反应

硅虽为非金属，却能与强碱溶液反应：

$$\text{Si} + 2\text{NaOH} + \text{H}_2\text{O} \rightarrow \text{Na}_2\text{SiO}_3 + 2\text{H}_2\uparrow$$

这一性质说明：
- **Si耐酸但不耐碱**：Si不与HF以外的酸反应（HF蚀刻硅片而非用碱），但可被强碱溶解
- **半导体工艺关联**：硅片清洗常用稀HF（去除SiO₂），而KOH溶液用于硅的各向异性湿法刻蚀（制作微机电结构）
- 与SiO₂对比：SiO₂只与HF和碱反应（酸性氧化物），Si只与碱和HF反应——二者互为补充

> **竞赛衔接**：Si + 4HF → SiF₄↑ + 2H₂↑，此反应同时涉及氧化还原和配位（F⁻与SiF₄形成SiF₆²⁻），是半导体工业刻蚀硅片的基础反应。

## 竞赛衔接

- **硅酸盐的矿物学**：长石、云母、高岭土等都是天然硅酸盐矿物
- **分子筛**：人工合成的铝硅酸盐，具有均匀微孔结构，用于催化和分离
- **光导纤维原理**：利用SiO₂的全反射传导光信号
- **半导体化学**：Si的掺杂（P型/N型）是集成电路的基础

## 常见易错

1. ❌ "玻璃是晶体" → ✅ 玻璃是非晶体（无固定熔点），石英水晶才是SiO₂的晶体形态
2. ❌ "SiO₂是酸性氧化物所以能溶于所有酸" → ✅ SiO₂只与HF反应，不溶于其他酸
3. ❌ "用玻璃瓶装NaOH溶液没问题" → ✅ SiO₂与NaOH反应生成Na₂SiO₃（会使瓶塞与瓶口粘连），应用橡胶塞的塑料瓶
4. ❌ "煤的干馏是物理变化" → ✅ 是化学变化（隔绝空气加强热产生新物质）
5. ❌ "石油分馏是化学变化" → ✅ 是物理变化（利用沸点不同进行分离）

## 🎯 教学视角

### 教学重点与难点
- **重点**：传统硅酸盐材料（陶瓷、玻璃、水泥）的工业应用与性能特点；Si和SiO₂的化学性质（尤其是与HF和NaOH的反应）；碳纳米材料的前沿应用。
- **难点**：玻璃是非晶体（无固定熔点）的理解；SiO₂"是酸性氧化物但只与HF反应"的特殊性；区分煤的干馏（化学变化）与石油分馏（物理变化）。

### 建议教学路径
- 课前布置自学，课堂以讲授与讨论结合归纳整合，重点了解性能和用途，不深入化学反应原理
- 情境素材创设：三峡工程水泥、航天器耐高温陶瓷、计算机芯片高纯硅、石墨烯等前沿应用引入学习兴趣
- 对比教学：传统材料（陶瓷/玻璃/水泥）vs新型材料（碳化硅/碳纳米管/石墨烯），突出材料科学的发展脉络
- 联系生活实际：从日用品（玻璃杯、瓷砖）到高科技（光导纤维、半导体芯片），建立材料与生活的联系

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| 玻璃是晶体 | 玻璃是非晶体（无固定熔点），石英水晶才是SiO₂的晶体形态 | 对比晶体（有固定熔点）与非晶体（无固定熔点）的本质区别 |
| SiO₂是酸性氧化物所以能溶于所有酸 | SiO₂只与HF反应，不溶于其他酸 | 强调"酸性氧化物"的定义是与碱反应，不是与酸反应 |
| 用玻璃瓶装NaOH溶液没问题 | SiO₂与NaOH反应生成Na₂SiO₃（会使瓶塞与瓶口粘连），应用橡胶塞的塑料瓶 | 联系实验室实际操作规范 |
| 煤的干馏是物理变化 | 是化学变化（隔绝空气加强热产生新物质） | 对比干馏（化学变化）与分馏（物理变化）的本质区别 |
| 石油分馏是化学变化 | 是物理变化（利用沸点不同进行分离） | 强调分馏只是物理分离过程 |

### 与现实世界的联系
- 传统材料的工业应用：陶瓷（建筑材料、绝缘器皿）、玻璃（光学镜片、建筑）、水泥（基础设施建设的核心材料）
- 信息技术基础：高纯硅是计算机芯片和太阳能电池的核心材料，光导纤维（SiO₂）支撑现代通信网络
- 新材料前沿：石墨烯（2010年诺贝尔物理学奖）、碳纳米管、C₆₀（1996年诺贝尔化学奖）在能源、电子、医疗等领域的应用
- 自然资源开发：金属冶炼方法的选择（热分解法、热还原法、铝热反应、电解法）与金属活动性的关系
