# 硫及其化合物

> **课标要求**：了解硫单质及其化合物的性质与应用，认识含硫物质在自然界中的转化，理解浓硫酸的强氧化性，掌握SO₄²⁻的检验方法。

## 学业要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能依据物质类别和元素价态分别列举含硫元素、氮元素的典型代表物质。
2. 能从物质类别和元素价态的角度，依据氧化还原反应原理，预测硫及其化合物、氮及其化合物的化学性质和变化。
3. 能从物质类别和元素价态变化的角度，设计含硫物质、含氮物质的转化路径。
4. 能根据实验目的和假设设计实验方案，选择适当的实验试剂，探究不同价态含硫物质的转化；能观察并如实记录实验现象和数据，进行分析和推理，得出合理的结论。
5. 能利用二氧化硫、氨、硫酸根和铵根的性质和反应，选择适当的实验试剂，设计检验二氧化硫、检验溶液中硫酸根和铵根等离子及实验室制取氨的实验方案。
6. 能根据硫酸、硝酸和氨的性质，分析实验室、工业生产及环境保护中的某些常见问题。
7. 能说明硫及其化合物、氮及其化合物（如二氧化硫、氨等）的应用对社会发展的价值和对环境的影响，能有意识地运用所学的知识或寻求相关证据参与社会性议题（如酸雨及防治）的讨论。

## 核心概念

### 1. 硫单质（S）

| 项目 | 内容 |
|------|------|
| 位置 | 第三周期第ⅥA族，最外层6个电子 |
| 物理性质 | 黄色晶体，质脆，不溶于水，微溶于酒精，易溶于CS₂ |

![硫粉实物](人教版高中化学课本/【2】人教版·化学必修第二册_images/8b67c0b0579e3e9344978ba3a173d25e644456961f6d428f41025fa0e39baf8f.jpg)
*图：硫粉——黄色晶体，质脆，不溶于水*
| 熔沸点 | mp 113°C，bp 445°C，密度 2.06 g/cm³ |
| 氧化态 | 得2个电子→-2价（如H₂S），也可失电子→+4、+6价 |

**关键化学反应：**

- S + Fe $\xrightarrow{\Delta}$ FeS（硫的氧化性较弱，只能将Fe氧化到+2价）
- S + 2Cu $\xrightarrow{\Delta}$ Cu₂S（同理，Cu→+1价）
- S + H₂ $\xrightarrow{\Delta}$ H₂S
- S + O₂ $\xrightarrow{\text{点燃}}$ SO₂

> **竞赛衔接**：硫的氧化性弱于O₂和Cl₂，故产物为低价态金属硫化物（FeS而非Fe₂S₃，Cu₂S而非CuS）。

### 2. 二氧化硫（SO₂）

**物理性质：**
- 无色、有刺激性气味的有毒气体，密度大于空气
- 1体积水溶解约40体积SO₂

**化学性质（三重身份）：**

| 性质 | 反应 | 说明 |
|------|------|------|
| **酸性氧化物** | SO₂ + H₂O ⇌ H₂SO₃ | 可逆反应，亚硫酸为弱酸 |
| **还原性** | 2SO₂ + O₂ $\xrightarrow{\text{催化剂},\Delta}$ 2SO₃ | 工业制硫酸关键步骤 |
| **氧化性** | SO₂ + 2H₂S = 3S↓ + 2H₂O | 与H₂S反应体现氧化性 |
| **漂白性** | 与品红溶液反应生成无色物质 | 加热后恢复红色（不稳定漂白） |

> **⚠️ 易错点**：SO₂的漂白是与有机色素结合生成无色化合物（非氧化还原），加热可逆；而Cl₂的漂白是永久性氧化漂白。

**关键实验：**
- 实验5-1：SO₂溶于水，用pH试纸测酸性
- 实验5-2：SO₂使品红褪色，加热恢复红色

![SO₂溶于水实验](人教版高中化学课本/【2】人教版·化学必修第二册_images/601a52093fd1cfaad41b99d2da1682a119041d7d73bf2e0699684d5466eda404.jpg)
*图：SO₂溶于水实验——试管倒立于水中，液面上升证明SO₂可溶于水*

### 3. 硫酸（H₂SO₄）

**浓H₂SO₄三大特性：**

| 特性 | 说明 | 典型实验 |
|------|------|----------|
| **吸水性** | 吸收游离水分子，作干燥剂 | 干燥H₂、O₂、CO₂等（不能干燥NH₃、H₂S） |
| **脱水性** | 将有机物中H、O按2:1比例脱去 | 蔗糖变黑膨胀（"黑面包"实验） |
| **强氧化性** | 热浓H₂SO₄能氧化大多数金属和部分非金属 | Cu + 浓H₂SO₄、C + 浓H₂SO₄ |

**核心反应方程式：**

- Cu + 2H₂SO₄(浓) $\xrightarrow{\Delta}$ CuSO₄ + SO₂↑ + 2H₂O
- C + 2H₂SO₄(浓) $\xrightarrow{\Delta}$ CO₂↑ + 2SO₂↑ + 2H₂O

![铜与浓硫酸反应实验](人教版高中化学课本/【2】人教版·化学必修第二册_images/3afe15f73902be37f96814c5cb68fde41bf43bebe86ae0fd88bfb6be3fa2b79a.jpg)
*图：铜与浓硫酸反应实验装置——产生的SO₂通入品红溶液验证漂白性*

> **钝化现象**：常温下，Fe和Al遇浓H₂SO₄（或浓HNO₃）表面生成致密氧化膜，阻止反应继续。这是化学变化，不是不反应。工业可用铁罐车运输浓硫酸。

### 4. 硫酸根离子（SO₄²⁻）的检验

**标准方法：**
$$\text{先加稀HCl酸化（排除CO₃²⁻、SO₃²⁻、Ag⁺干扰），再加BaCl₂溶液，若产生白色沉淀则含SO₄²⁻}$$

- Ba²⁺ + SO₄²⁻ = BaSO₄↓（白色，不溶于稀酸）

> **⚠️ 易错点**：不能先加BaCl₂再加稀HCl，因为若溶液含Ag⁺会生成不溶于酸的AgCl白色沉淀，造成误判。

### 5. 含硫化合物的化合价体系

| 化合价 | 代表物 | 性质倾向 |
|--------|--------|----------|
| -2 | H₂S, Na₂S | 还原性（可被O₂、Cl₂、浓H₂SO₄、KMnO₄等氧化） |
| 0 | S单质 | 既有氧化性又有还原性 |
| +4 | SO₂, H₂SO₃, Na₂SO₃ | 还原性为主（可被O₂、Cl₂、H₂O₂等氧化） |
| +6 | SO₃, H₂SO₄, SO₄²⁻ | 氧化性（热浓H₂SO₄） |

**转化关系图：**
```
  氧化剂              氧化剂             氧化剂
H₂S  ───→  S  ───→  SO₂  ───→  SO₃/H₂SO₄
 ↑               ↑               ↑
 还原剂           还原剂           还原剂
（金属、H₂）    （H₂S）        （C、Cu等）
```

### 6. 重要含硫盐类

| 物质 | 化学式 | 用途 |
|------|--------|------|
| 石膏 | CaSO₄·2H₂O | 建筑材料、医用石膏 |
| 熟石膏 | 2CaSO₄·H₂O | 模具、绷带 |
| 重晶石 | BaSO₄ | 钡餐（X射线不能穿透）、白色颜料 |
| 胆矾/蓝矾 | CuSO₄·5H₂O | 波尔多液（与石灰乳混合）、检验水的存在 |
| 无水硫酸铜 | CuSO₄（白色） | 遇水变蓝，检验水的存在 |

| 实验编号 | 内容 | 考点 |
|----------|------|------|
| 实验5-1 | SO₂溶于水测pH | 酸性氧化物性质 |

## 教材例题/习题

1. **SO₂与CO₂的鉴别**：用品红溶液（SO₂使之褪色，CO₂不能）
2. **浓H₂SO₄稀释**：必须将浓H₂SO₄沿容器壁缓慢加入水中，并不断搅拌（类似浓HNO₃操作）
3. **比较漂白性**：SO₂（可逆）vs Cl₂（永久）vs H₂O₂（氧化）vs 活性炭（吸附）

## 知识拓展

### 硫的S₈分子结构与温度-黏度关系

硫的常见同素异形体S₈为8元环冠状结构（8个S原子交替位于环平面上下）。不同温度下硫的形态和黏度变化显著：

| 温度范围 | 存在形态 | 说明 |
|----------|----------|------|
| < 119°C | 黄色固体（S₈环） | 常温下的稳定形态 |
| 119–444°C | 黏稠液体 | S₈环断裂开环，形成线性聚合链（—S—S—S—…），黏度在~160°C达到峰值；温度继续升高，链断裂变短，黏度反而下降 |
| > 750°C | S₂分子（气体） | S₂的键合方式类似O₂（双键），为气态 |

黏度变化的本质：S₈环→开环聚合→链状高分子（高黏度）→高温断链→小分子S₂（低黏度），反映了环状与链状结构之间的平衡。

### SO₂漂白性微观原理

SO₂的漂白作用并非氧化还原过程，而是SO₂与有机色素分子中的**发色团**（chromophore）发生加成反应，生成无色的加合物。具体特点：

- **非氧化还原**：与Cl₂、O₃、H₂O₂等氧化性漂白剂不同，SO₂的漂白不改变色素分子的氧化态
- **可逆性**：生成的无色加合物不稳定，受热分解后色素恢复原有颜色。这就是为什么SO₂漂白过的丝绸、草帽等会随时间（或受热）逐渐恢复原色
- **选择性**：SO₂主要漂白某些有机色素（如品红），对指示剂（如石蕊）不能使其褪色（只能使其变红，因为SO₂溶于水显酸性）

> 与Cl₂漂白的本质对比：Cl₂（或HClO）的漂白是不可逆的氧化漂白（永久性），SO₂的漂白是可逆的加合漂白。

### 浓硫酸的吸水作用与脱水作用

浓硫酸具有**吸水性**和**脱水性**两个本质不同的概念：

| 对比项 | 吸水性 | 脱水性 |
|--------|--------|--------|
| **对象** | 游离态的水分子（H₂O） | 有机化合物中的H和O（按2:1比例结合为H₂O脱去） |
| **本质** | 物理吸附+化学水合 | 化学反应（C—H键和C—O键断裂） |
| **结果** | 形成H₂SO₄·nH₂O水合物（n=1–5） | 有机物炭化（如蔗糖变黑） |
| **典型现象** | 浓硫酸暴露在空气中变稀 | 蔗糖遇浓硫酸→黑色膨胀（"黑面包"实验） |

**经典脱水反应实例：**
- HCOOH $\xrightarrow{\text{浓H}_2\text{SO}_4}$ CO↑ + H₂O（甲酸脱水）
- C₂H₅OH $\xrightarrow[170°\text{C}]{\text{浓H}_2\text{SO}_4}$ C₂H₄↑ + H₂O（乙醇脱水制乙烯）
- C₁₂H₂₂O₁₁（蔗糖）$\xrightarrow{\text{浓H}_2\text{SO}_4}$ 12C + 11H₂O（炭化）

### 浓、稀硫酸氧化作用差异

浓硫酸和稀硫酸的氧化性来源截然不同：

| 对比项 | 稀硫酸 | 浓硫酸 |
|--------|--------|--------|
| **氧化剂** | H⁺（只能氧化活泼金属） | S(+6)（能氧化大多数金属和部分非金属） |
| **氧化能力** | 较弱 | 强（热浓） |
| **产物** | 金属硫酸盐 + H₂↑ | 金属硫酸盐 + SO₂↑（或S↓、H₂S↑，取决于浓度和金属用量） |

**Zn与不同浓度H₂SO₄的反应（浓度依赖产物）：**
- Zn + H₂SO₄(稀) → ZnSO₄ + H₂↑
- Zn + 2H₂SO₄(浓) $\xrightarrow{\Delta}$ ZnSO₄ + SO₂↑ + 2H₂O
- 3Zn + 4H₂SO₄(浓，过量Zn) $\xrightarrow{\Delta}$ 3ZnSO₄ + S↓ + 4H₂O
- 4Zn + 5H₂SO₄(极浓，过量Zn) $\xrightarrow{\Delta}$ 4ZnSO₄ + H₂S↑ + 4H₂O

随着浓度降低和金属用量增加，H₂SO₄中S(+6)被还原的程度加深：SO₂(S:+4) → S(S:0) → H₂S(S:−2)。

## 竞赛衔接

- **硫代硫酸钠**（Na₂S₂O₃）：与酸反应生成S和SO₂，用于碘量法滴定
- **多硫化物**（Na₂Sₓ）：含硫链结构，常见于矿物
- **SO₂的配位化学**：可作为配体与过渡金属配位
- **硫的含氧酸**：亚硫酸（H₂SO₃，不稳定）、焦硫酸（H₂S₂O₇）、过硫酸（H₂S₂O₈）
- **硫氮化合物**：S₄N₄（篮状/笼状八元环，8π 电子假芳香性，撞击易爆）、S₂N₂（不稳定的四元环，室温聚合为 (SN)ₓ 一维导电聚合物）——竞赛级趣味拓展，结构判断常用共振式 + 休克尔规则

## 常见易错

1. ❌ "SO₂能使品红褪色是因为SO₂有强氧化性" → ✅ 是与有机色素化合，非氧化还原
2. ❌ "SO₂和CO₂都能使澄清石灰水变浑浊，所以不能区分" → ✅ 可用品红溶液或KMnO₄溶液区分
3. ❌ "常温下Fe遇浓H₂SO₄不反应" → ✅ 是钝化（表面氧化膜阻止），加热后仍剧烈反应
4. ❌ "浓H₂SO₄有强氧化性所以能干燥H₂S" → ✅ 浓H₂SO₄会氧化H₂S，不能用于干燥还原性气体
5. ❌ "BaCl₂溶液加入某溶液产生白色沉淀说明含SO₄²⁻" → ✅ 须先加稀HCl酸化排除干扰

## 🎯 教学视角

### 教学重点与难点
- **重点**：SO₂的多重性质（酸性氧化物+还原性+氧化性+漂白性）是本节核心，可通过"一条线索（硫的化合价变化）"串联所有反应；建立"硫三角"（H₂S—S—SO₂—SO₃—H₂SO₄）转化关系图。
- **难点**：SO₂的漂白性原理（不要求书写化学方程式）；浓硫酸钝化现象的理解（不写化学方程式）；可逆反应概念的引入（控制深广度，不补充额外例子）。

### 建议教学路径
- 以元素周期律为指导建构知识体系：比较硫与氧、氯的原子结构，得出硫单质氧化性比O₂、Cl₂弱，解释硫只能把铁、铜氧化为较低价态；比较硫酸与盐酸的酸性异同，感受"同类物质的共性与个性的辩证关系"
- 情境素材创设：火山喷发视频引入硫的学习；酸雨图片引入SO₂；硫酸工业生产视频或浓硫酸与蔗糖的"黑面包"实验引入硫酸
- 知识结构化：建立"硫三角"转化关系图，以化合价变化为主线串联H₂S、S、SO₂、SO₃、H₂SO₄的相互转化
- 实验驱动：通过SO₂漂白品红（可逆）、Cu与浓H₂SO₄加热等实验，让学生直观感受性质差异

### 常见认知误区
| 误区 | 正确认识 | 突破策略 |
|------|----------|----------|
| SO₂能使品红褪色是因为SO₂有强氧化性 | 是与有机色素化合生成无色化合物（非氧化还原），加热可逆 | 对比Cl₂漂白（永久性氧化漂白）的本质区别 |
| 常温下Fe遇浓H₂SO₄不反应 | 是钝化（表面致密氧化膜阻止），加热后仍剧烈反应 | 结合工业铁罐车运输浓硫酸的实例理解 |
| 浓H₂SO₄有强氧化性所以能干燥H₂S | 浓H₂SO₄会氧化H₂S，不能用于干燥还原性气体 | 从氧化还原角度分析浓硫酸的"双重身份" |
| BaCl₂产生白色沉淀即含SO₄²⁻ | 须先加稀HCl酸化排除CO₃²⁻、SO₃²⁻、Ag⁺干扰 | 强调操作顺序的逻辑：先除干扰，再检验目标 |

### 与现实世界的联系
- 酸雨的形成与防治：SO₂排放→硫酸型酸雨→腐蚀建筑、酸化土壤和水体，工业烟气脱硫技术
- 硫酸工业生产：接触法制硫酸（SO₂催化氧化→SO₃→H₂SO₄）是重要的化工流程
- 含硫化合物的生活应用：石膏（建筑材料）、CuSO₄·5H₂O（波尔多液农药）、BaSO₄（钡餐造影）
- 环境保护：含硫燃料的脱硫处理，减少SO₂排放的社会性议题

### SO₂在食品工业中的应用

SO₂在食品工业中有三方面重要作用：

1. **杀菌消毒**：SO₂溶于水生成H₂SO₃，能抑制微生物生长，广泛用于果酒、果汁等食品的防腐保鲜
2. **抗氧化剂**：SO₂能与食品中的氧化性物质反应，防止食品氧化变色变质（如防止水果褐变）
3. **漂白**：SO₂可使食品色泽更白更亮（如漂白糖类、干果等）

**葡萄酒中的应用**：在葡萄酒酿制过程中，添加适量SO₂可以杀死葡萄汁中的杂菌，防止异常发酵，同时作为抗氧化剂防止葡萄酒成分被氧化，保持天然果香味。

**残留量限制**：我国《食品安全国家标准 食品添加剂使用标准》（GB 2760）规定了SO₂在各类食品中的最大使用量。例如，葡萄酒中SO₂的最大残留量为0.25 g/L。使用不当导致SO₂残留超标会对人体健康造成不利影响。
