# 分子极性与分子间作用力

> **对应教材**：人教版选修二第二章第三节（pp.52-64）

## 课标要求

> 以下为《普通高中化学课程标准》对应的学业要求，摘自教师教学用书。

1. 能利用电负性判断共价键的极性，能根据共价分子的结构特点说明简单分子的某些性质；能说明分子间作用力（含氢键）对物质熔点、沸点等性质的影响，能列举含有氢键的物质及其性质特点，知道氢键对于生命的重大意义。
2. 能根据键的极性和分子结构特点来判断分子的极性，并据此对分子的一些典型性质及其应用作出解释。

## 核心概念

### 一、共价键的极性

**极性共价键**：不同原子之间形成的共价键，共用电子对偏向电负性较大的原子。
- 例如：H-Cl中，共用电子对偏向Cl，Cl端带部分负电荷(δ⁻)，H端带部分正电荷(δ⁺)
- 键的极性大小取决于两原子电负性差值Δχ：差值越大，极性越强

**非极性共价键**：相同原子之间形成的共价键，共用电子对不偏向任何一方。
- 例如：H-H、Cl-Cl、C-C
- Δχ = 0

**键的极性与电负性的关系**：
| 电负性差Δχ | 键型 | 举例 |
|:---|:---|:---|
| 0 | 非极性共价键 | H-H, Cl-Cl |
| 0~0.4 | 弱极性共价键 | C-H (Δχ=0.4) |
| 0.4~1.7 | 极性共价键 | H-Cl (Δχ=0.9), H-O (Δχ=1.4) |
| >1.7 | 离子键 | NaCl (Δχ=2.1) |

### 二、分子的极性

**极性分子**：正电中心和负电中心不重合的分子，具有偶极矩。
**非极性分子**：正电中心和负电中心重合的分子，偶极矩为零。

**判断方法**：分子的极性取决于两个因素——**键的极性**和**分子的空间构型**。

**从键的极性到分子的极性**：

情况1：分子中只有非极性键 → 一定是非极性分子
- 例：H₂、O₂、N₂、Cl₂

情况2：分子中只有极性键 → 看空间构型是否对称
- 构型对称 → 非极性分子（极性键的偶极矩矢量和为零）
- 构型不对称 → 极性分子

情况3：分子中同时有极性键和非极性键 → 同样看构型对称性

**典型例子**：

| 分子 | 键的极性 | 空间构型 | 分子极性 | 偶极矩(D) |
|:---|:---|:---|:---|:---:|
| CO₂ | 极性键(C=O) | 直线形(对称) | **非极性** | 0 |
| H₂O | 极性键(O-H) | V形(不对称) | **极性** | 1.85 |
| CH₄ | 极性键(C-H) | 正四面体(对称) | **非极性** | 0 |
| NH₃ | 极性键(N-H) | 三角锥(不对称) | **极性** | 1.47 |
| CCl₄ | 极性键(C-Cl) | 正四面体(对称) | **非极性** | 0 |
| CHCl₃ | 极性键 | 四面体(不对称) | **极性** | 1.04 |
| BF₃ | 极性键(B-F) | 平面三角形(对称) | **非极性** | 0 |
| HCl | 极性键 | 双原子(不对称) | **极性** | 1.08 |

**关键规律**：
- 直线形且两端原子相同的分子（如CO₂、CS₂）→ 非极性
- V形分子（如H₂O、H₂S）→ 一定极性
- 正四面体且四个顶点相同的分子（如CH₄、CCl₄）→ 非极性
- 三角锥形分子（如NH₃、PCl₃）→ 一定极性

> **竞赛衔接**：偶极矩的测量和计算是竞赛中分子结构分析的重要工具。偶极矩为零可以反推分子构型的对称性。

### 三、分子间作用力（范德华力）

**定义**：分子之间存在的弱相互作用力，比化学键弱得多（约为化学键的1/100~1/10）。

**范德华力的三个组成部分**：

1. **取向力**（Keesom力）：极性分子之间，永久偶极-永久偶极的静电相互作用
2. **诱导力**（Debye力）：极性分子的永久偶极诱导邻近分子产生诱导偶极
3. **色散力**（London力）：所有分子之间都存在，由瞬时偶极的相互吸引产生

> **色散力是最普遍存在的分子间作用力**，即使是非极性分子之间也有色散力。对于大多数分子，色散力是范德华力的主要贡献。

**范德华力对物质物理性质的影响**：

**对熔点和沸点的影响**：
- 范德华力越大 → 熔沸点越高
- 影响范德华力大小的因素：
  - **相对分子质量**：越大 → 色散力越大 → 熔沸点越高（同族氢化物从上到下熔沸点升高）
  - **分子的极性**：极性越大 → 取向力和诱导力越大 → 熔沸点越高

**典型比较**：
| 物质 | 相对分子质量 | 分子极性 | 沸点 |
|:---|:---:|:---|:---:|
| He | 4 | 非极性 | -269℃ |
| Ne | 20 | 非极性 | -246℃ |
| Ar | 40 | 非极性 | -186℃ |
| N₂ | 28 | 非极性 | -196℃ |
| CO | 28 | 极性 | -192℃ |
| HCl | 36.5 | 极性 | -85℃ |
| HBr | 81 | 极性 | -67℃ |
| HI | 128 | 极性 | -35℃ |

**注意**：CO和N₂相对分子质量相同，但CO是极性分子有额外的取向力，所以沸点略高。

### 四、氢键

**定义**：氢键是一种特殊的分子间作用力，当H与电负性很大、半径很小的原子（主要是**F、O、N**）以共价键结合时，H原子可以与另一个电负性很大的原子之间形成的弱相互作用。

**表示方法**：X-H···Y（X和Y为F、O、N等电负性大且有孤对电子的原子）

**氢键的本质**：
- 不是化学键，是分子间作用力的一种特殊形式
- 强度：比范德华力强得多，但比化学键弱
  - 化学键：100~400 kJ/mol
  - 氢键：5~30 kJ/mol
  - 范德华力：0.5~5 kJ/mol

**形成条件**：
1. 分子中必须有H与F、O、N以共价键结合（提供"供体"H）
2. 另一个分子中必须有F、O、N原子且有孤对电子（提供"受体"）

**氢键对物质物理性质的影响**：

**对沸点的影响**：
- H₂O的沸点远高于H₂S（水分子间有氢键，H₂S分子间只有范德华力）
- HF的沸点高于HCl（HF分子间有氢键）
- NH₃的沸点高于PH₃（NH₃分子间有氢键）

**反常现象**：第ⅥA族氢化物中，H₂O的沸点远高于H₂S、H₂Se、H₂Te（正常趋势应该是从上到下递增），就是因为H₂O分子间存在氢键。

**对水的特殊性质的解释**：
- 水的高沸点（100℃，远高于同族氢化物的预期值约-60℃）
- 冰的密度小于液态水（冰中氢键使水分子按四面体排列，形成较疏松的结构）
- 水的高比热容（氢键的形成和断裂需要额外能量）
- 水的高表面张力



**氢键的类型**：X—H…Y（X、Y为N、O、F），“—”为共价键，“…”为氢键。氢键不仅存在于分子之间（如水），也存在于分子内（如邻羟基苯甲醛）。


*图：冰的氢键网络——每个水分子与4个相邻水分子形成氢键，冰融化后空隙减小导致密度增大*

**氢键的类型**：
- **分子间氢键**：不同分子之间（如水分子间、HF分子间）→ 提高熔沸点
- **分子内氢键**：同一分子内部（如邻硝基苯酚）→ 通常降低熔沸点（减弱了分子间氢键）

> **竞赛衔接**：氢键在生物化学中极为重要——DNA双螺旋结构中碱基对之间靠氢键配对（A-T两个氢键，G-C三个氢键）；蛋白质的二级结构（α螺旋、β折叠）也靠氢键维持。

## 关键规律总结

### 判断分子极性的快速方法
1. 找出所有键的偶极矩方向（从正到负）
2. 用矢量合成法判断是否相互抵消
3. 对称中心/对称面存在 → 非极性；不存在 → 极性

### 物质沸点排序的一般思路
1. 先看是否有氢键（有氢键的物质沸点显著偏高）
2. 若无氢键差异，看分子极性（极性 > 非极性）
3. 若极性相近，看相对分子质量（越大沸点越高）

## 教材例题与练习

**典型题1**：判断下列分子中哪些是极性分子：H₂O, CO₂, NH₃, BF₃, CHCl₃, CCl₄

**解答**：极性分子有H₂O（V形）、NH₃（三角锥）、CHCl₃（不对称四面体）。
非极性分子有CO₂（直线对称）、BF₃（平面对称）、CCl₄（正四面对称）。

**典型题2**：解释为什么HF、H₂O、NH₃的沸点分别高于HCl、H₂S、PH₃。

**解答**：HF、H₂O、NH₃分子间存在氢键，而HCl、H₂S、PH₃分子间只有范德华力。氢键强度远大于范德华力，需要更多能量克服分子间作用力，因此沸点更高。

## 知识拓展

### 分子间作用力的三种本质

- **取向力**：极性分子之间，偶极取向后异极相吸。
- **诱导力**：极性分子的电场使非极性分子电子云变形产生诱导偶极。
- **色散力**：非极性分子中电子运动产生瞬时偶极，诱导邻近分子产生瞬时偶极。**对大多数分子，色散力是主要的**。
- 数据示例：H₂O中取向力36.38 kJ/mol（占主导），而Ar中仅有色散力8.49 kJ/mol。

### 氢键的本质与影响

- **本质**：X-H…Y中，X-H基本是共价键，H…Y是带有部分负电荷的Y原子与极性很强的X-H之间的静电吸引。
- **能量**：一般不超过40 kJ/mol，比化学键弱，比范德华力强。
- **饱和性**：一个H原子只能形成一个氢键。
- **方向性**：X-H…Y尽量在同一直线上（氢键方向与Y的孤电子对对称轴一致时最强）。
- **分子内氢键**：如邻硝基苯酚，X-H…Y不在同一直线上（约150°），使分子钳环化。分子内氢键降低熔沸点，分子间氢键升高熔沸点。
- **对酸性的影响**：邻羟基苯甲酸电离常数为苯甲酸的15.9倍（邻位OH与苯甲酸根形成氢键稳定阴离子）。

## 竞赛衔接

- **偶极矩与分子构型**：通过测量偶极矩可以反推分子的空间构型
- **氢键的类型与强度**：F-H···F > O-H···O > N-H···N（电负性越大氢键越强）
- **生物大分子中的氢键**：DNA碱基配对、蛋白质二级结构
- **冰的结构**：冰Ih中每个水分子与4个相邻水分子形成氢键，呈六方晶系

## 常见易错

1. **有极性键的分子不一定是极性分子**：CO₂有极性键但因对称结构是非极性分子
2. **氢键不是化学键**：氢键是分子间作用力的特殊形式，强度远小于化学键
3. **所有分子间都存在色散力**：即使是非极性分子（如He、N₂）之间也有色散力
4. **水的密度反常不是因为氢键更强**：冰中氢键形成的四面体排列比液态水更疏松，所以冰密度更小
5. **分子内氢键和分子间氢键的影响相反**：分子内氢键会削弱分子间氢键，导致熔沸点降低

## 🎯 教学视角

### 教学重点与难点

**重点**：
- 键的极性与分子极性的关系：极性键是必要条件，分子构型对称性决定最终极性
- 范德华力的三个组成部分：取向力（极性-极性）、诱导力（极性-非极性）、色散力（所有分子间都存在）
- 氢键的形成条件（H与F/O/N成键 + 另一F/O/N原子有孤对）及其对沸点、密度等性质的影响

**难点**：
- 分子极性的矢量判断法：画出各极性键的偶极矩方向，用矢量合成法判断向量和是否为零
- 氢键的本质：X-H…Y中X-H基本是共价键，H…Y是带有部分负电荷的Y原子与极性很强的X-H之间的静电吸引，具有饱和性和方向性
- 分子内氢键与分子间氢键的相反影响：分子内氢键（如邻硝基苯酚）降低熔沸点，分子间氢键升高熔沸点

### 建议教学路径

1. **前置知识**：先掌握 [[分子空间结构与杂化]] 中VSEPR理论判断分子构型
2. **键的极性**：从电负性差值出发，回顾极性键与非极性键的判据
3. **分子极性判断**：用矢量分析法——画出分子中各极性键的极性向量，判断向量和是否为零。分类归纳：只含非极性键→一定非极性分子；含极性键+对称结构→非极性分子；含极性键+不对称结构→极性分子
4. **分子间作用力**：先用实验数据比较同族氢化物沸点（ⅣA族正常递增 vs ⅥA族H₂O"反常"最高），用"反常"现象引出氢键概念
5. **综合应用**：将微观结构与宏观性质（沸点、溶解性、密度）联系起来

### 常见认知误区

| 误区 | 正确理解 |
|:---|:---|
| 极性键→极性分子 | 不一定。CO₂、CH₄有极性键但因构型对称是非极性分子 |
| 氢键是化学键 | 氢键是分子间作用力，比化学键弱得多（化学键100~400 kJ/mol，氢键5~30 kJ/mol） |
| 范德华力只存在于非极性分子间 | 所有分子间都有色散力，极性分子间还有取向力和诱导力 |
| HF沸点高于HCl是因为HF分子量大 | 恰恰相反，HCl分子量更大，但HF有氢键所以沸点更高 |
| 水的密度反常是因为液态水氢键更强 | 冰中氢键形成的四面体排列比液态水更疏松，所以冰密度更小 |

### 与现实世界的联系

1. **水的特殊性**：地球上的生命依赖于水的高比热容、高沸点和密度反常——这些都源于氢键。
2. **药物设计**：药物分子与靶点蛋白的结合常涉及氢键和范德华力，是药物-受体相互作用的基础。
3. **材料科学**：利用分子间作用力设计自组装材料。
4. **DNA双螺旋**：碱基对之间的氢键配对（A-T两个、G-C三个）是遗传信息存储的分子基础。

## 关键实验

### 实验：碘在水与四氯化碳中的溶解性对比（相似相溶验证）
- **目的**：验证"相似相溶"规律——极性分子易溶于极性溶剂，非极性分子易溶于非极性溶剂
- **关键操作**：取少量碘（I₂）分别加入水和CCl₄中，振荡后观察溶解情况和颜色
- **预期现象**：
  - 碘在CCl₄中：溶解性好，溶液呈紫红色（I₂和CCl₄均为非极性分子）
  - 碘在水中：溶解性差，溶液呈棕黄色或几乎无色（I₂为非极性分子，H₂O为极性分子）
- **注意事项**：碘有挥发性，CCl₄有毒，操作应在通风橱中进行，避免皮肤接触

### 实验活动：手性分子模型制作
- **目的**：通过搭建手性分子的球棍模型，直观理解"手性"概念和对映异构现象
- **关键操作**：
  - 先搭建CH₂ClBr的球棍模型（两种结构可完全重叠→同种分子，无手性）
  - 再搭建CHFClBr的球棍模型（两种结构不能重叠→互为镜像→手性异构体）
  - 让学生体验左右手的镜像关系，理解"手性"概念
- **预期现象**：CHFClBr的两种镜像模型无论如何旋转都无法完全重合，如同左手和右手
- **注意事项**：
  - 可用不同颜色的橡皮泥或球棍模型套件中的不同颜色球代表不同原子
  - 强调20种氨基酸中除甘氨酸外均有手性，手性药物的两个对映体生物活性可能完全不同
  - 2001年诺贝尔化学奖授予不对称催化合成领域
