# Born-Haber循环

## 核心概念

Born-Haber循环是**用热力学数据通过 Hess 定律构造的闭合能量循环**，用于计算难以直接测定的离子晶体**晶格能 U**（气态阳离子与气态阴离子结合成 1 mol 离子晶体释放的能量）。它是"实验量 + 理论量互相印证"的经典框架：只要循环中其余各项可测（升华焓、电离能、电子亲和能、键解离能），未知项即可作为"差额"求出。

Born-Haber循环也是判断"某化合物能否稳定存在"的热力学工具——若按循环算出的晶格能不足以抵消电离能等吸热项（净生成焓为正），该离子化合物便不稳定或根本不能形成。

## 循环构建（以 NaCl 为例）

按"单质 → 气态原子 → 气态离子 → 离子晶体"的路径逐级拆解：

| 步骤 | 过程 | 能量项 | 符号 |
|---|---|---|---|
| ① 升华 | Na(s) → Na(g) | 升华焓 ΔsubH | + |
| ② 电离 | Na(g) → Na⁺(g) + e⁻ | 第一电离能 I₁ | + |
| ③ 解离 | ½Cl₂(g) → Cl(g) | ½ 键解离能 ½D | + |
| ④ 得电子 | Cl(g) + e⁻ → Cl⁻(g) | 电子亲和能 EA | + 或 −（见符号约定） |
| ⑤ 成晶 | Na⁺(g) + Cl⁻(g) → NaCl(s) | 晶格能 −U | − |

总方程：**ΔfH⁰(NaCl, s) = ΔsubH(Na) + I₁(Na) + ½D(Cl₂) + EA(Cl) − U**

其中 U 取正值（放热取正），故方程中写作 −U。把除 U 外各项的实验数据代入，即可解出晶格能；此计算值与理论静电模型（Born–Lande 方程）的偏差可揭示键的离子性程度。

## 关键公式与符号约定

**晶格能的理论表达式（Born–Lande 方程）**：

U = (Nₐ·A·|z₊z₋|·e²/4πε₀r₀)·(1 − 1/n)

- A：Madelung 常数（NaCl 型 1.748，CsCl 型 1.763，闪锌矿 1.638），只取决于晶格几何
- r₀：平衡核间距；n：Born 指数（由压缩性实验定，通常 5–12）

**电子亲和能两种符号约定（高频陷阱）**：教材常用"放热为负"（Cl 的 EA ≈ −349 kJ/mol，代入后总方程中 +EA 为负贡献）；部分竞赛书用"放热为正"（EA ≈ +349，方程中写作 −EA）。**解题前必须先看题目约定，混用会整体差一个 EA 的符号**。

## 晶格能的趋势规律

- **电荷乘积主导**：U ∝ z₊·z₋——MgO（2×2）晶格能远大于 NaCl（1×1），故 MgO 熔点 ≈ 2852°C 而 NaCl 仅 801°C。
- **半径效应**：U ∝ 1/(r₊+r₋)——同电荷时半径小者晶格能大：LiF > NaF > KF > RbF。
- **推论链**：晶格能越大 → 熔点/硬度越高、热稳定性越强（碳酸盐分解温度 MgCO₃ < CaCO₃ < SrCO₃ < BaCO₃ 的经典解释：阳离子半径增大使晶格能下降速率快于碳酸根极化效应，但竞赛通常只需定性：半径增大 → 晶格能减小 → 分解温度上升的方向判断需具体分析）。

## 典型应用

1. **求晶格能**：循环中唯一难测项，差额法解出，并与理论值互证。
2. **反推电子亲和能**：EA 极难直接测定，用实验 ΔfH + U 理论值反推（如 O 的第二电子亲和能 EA₂ 为正值、只能如此获得）。
3. **判断化合物稳定性与歧化方向**：CuCl 的 ΔfH 为吸热（U 不足以补偿 I₂+EA₂）→ 潮湿下歧化 CuCl → Cu + CuCl₂；卤化银生成焓负值源于高晶格能。
4. **解释热稳定性差异**：NaHCO₃ 受热分解而 Na₂CO₃ 稳定，可借产物晶格能（碳酸盐 vs 氧化物/碳酸氢盐的 U 比较）定性理解。

## 完整计算示例

**题目**：已知 ΔsubH(Mg) = 148 kJ/mol，I₁+I₂(Mg) = 2189 kJ/mol，½D(O₂) = 249 kJ/mol，EA₁+EA₂(O) = +703 kJ/mol（放热为正约定，故代入作 −703），ΔfH(MgO, s) = −602 kJ/mol。求 MgO 的晶格能。

**解答**：按 ΔfH = ΔsubH + (I₁+I₂) + ½D − (EA₁+EA₂) − U 整理：

U = 148 + 2189 + 249 − 703 − (−602) = 2485 kJ/mol

（注：若题目用"放热为负"约定，EA 写作 −703 kJ/mol，则方程中 +EA 即 −703，结果相同——两种约定殊途同归，关键是符号与方程的写法要配套。）

**要点**：MgO 的 U ≈ 2485 kJ/mol 远高于 NaCl 的 787 kJ/mol——差值的 2/3 来自电荷乘积（1×1 → 2×2），1/3 来自半径减小，这解释了 MgO 的高熔点与高硬度。

## 与理论值的互证：离子性判断

把 Born-Haber 循环"实测"U 与 Born–Lande 理论 U 比较：
- 两者接近（偏差 <5%）→ 该晶体以离子键为主（NaCl、KBr 等）；
- 理论值明显高于实测 → 实际成键含显著共价成分（如 AgCl、ZnS、CuCl——极化作用使电子云变形、键长缩短但键的离子性下降），偏差大小本身可作"离子性程度"的半定量标尺。

此互证思路是竞赛推断题的高频落点：给出实验 U 与理论 U，要求判断键型或解释偏差来源（极化、部分共价）。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 忽略电子亲和能的符号约定 | 不同教材 EA 正负约定相反，混用使结果差 2×EA | 见题目是否给"放出能量 349 kJ"字样；解出 U 后与已知 NaCl 实测值（≈787 kJ/mol）比对自检 |
| 忘记循环路径任意性 | 误以为必须先电离再解离或必须可逆 | Hess 定律下路径无关——先气化 Cl₂ 还是先生成 Na 离子都行，只要始态终态一致 |
| 键解离能用整键能而非 ½ | Cl₂ 的 D 是全键解离能，方程中只有 ½ mol Cl₂ | 化学计量数乘 D：½D(Cl₂)；写错则差 121 kJ |
| 升华焓与原子化焓混淆 | 金刚石、Si 等原子晶体无"升华"，用原子化焓 | C(石墨)→C(g) 的原子化焓 ≈ 717 kJ/mol，不是升华焓 |
| 单位换算遗漏 | I、EA 常用 kJ/mol，电子伏特 (eV) 需 ×96.485 | 1 eV ≈ 96.5 kJ/mol；对不上数量级先查单位 |
| 把 U 符号方向写反 | 成晶放热，U 取正代入带负号；有人把 U 当吸热项 | 生成焓为负的稳定离子晶体，右边吸热项之和必小于 U |

## 竞赛考察要点与命题角度

1. **数值反推型**：给 4 个数据求第 5 个（最常见）。写全循环各步再列总方程，逐项代入，注意 ½D 与化学计量数。
2. **符号辨析型**：故意混用 EA 约定 / 给出 "Cl(g) + e⁻ → Cl⁻(g) 放出 349 kJ" 这类描述，考你往方程里代 +349 还是 −349。对策：先写明约定再动笔。
3. **定性比较型**：不计算，比较两种晶体的 U/熔点/分解温度（电荷、半径、极化三个因素按序比较）。
4. **与电子亲和能结合**：第二电子亲和能必为正（O⁻ 再得电子需输入能量），只能经循环反推——注意这类"无法直接测量"的设问。
5. **理论值偏差解释型**：给实验 U 与 Born–Lande 理论 U 偏差，要求归因于极化/共价成分——回答要落到"电子云变形使实际键能高于点电荷模型预期（实测偏高）或离子性下降（实测偏低）"的具体方向。

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解Hess定律和热力学循环的概念，再学习Born-Haber循环的构建方法，最后掌握晶格能的计算和应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| Born-Haber循环只能计算晶格能 | 该循环可用于计算任何难以直接测量的热力学量 |
| 循环中各步骤必须可逆 | 热力学是状态函数，路径可逆与否不影响结果 |
| 电子亲和能总是负值 | 有些元素的电子亲和能是正值（如N、Ne） |

### 15.3 入门级例题

**题目**：利用Born-Haber循环计算NaCl的晶格能。

**解答**：Na(s) → Na(g)（升华能）→ Na⁺(g) + e⁻（电离能）→ Cl(g)（解离能）→ Cl⁻(g)（电子亲和能）→ NaCl(s)（晶格能）。根据Hess定律，各步骤能量之和等于生成焓。

### 15.4 与现实世界的联系

1. **材料科学**：晶格能数据用于预测离子晶体的稳定性和性质
2. **地球化学**：理解矿物形成和转化的热力学过程
3. **电池技术**：离子晶体的热力学性质影响电池材料的选择

## 关键结论速记

- Born-Haber循环 = Hess 定律在离子晶体上的应用：**ΔfH = Σ(单质→气态离子各步) − U**。
- U 是"差额"，符号与 EA 约定是两大失分点；解出后与同族已知值比对自检。
- U ∝ z₊z₋/(r₊+r₋)：电荷翻倍 U 约翻 4 倍（趋势主导因素），半径只线性影响。
- 实验 U 与理论 U 的偏差大小 = 离子性/共价性的半定量标尺（极化使键偏离纯离子模型）。
