# 六价铬

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述
- 六价铬是铬最重要的高价态体系，常见形态包括 CrO₃、CrO₄²⁻、Cr₂O₇²⁻
- 在基础层，核心是"强氧化性 + pH 依赖转化"

**元素定位**：Cr(VI) 是 d⁰ 构型（3d⁰），无 d-d 颜色——黄/橙来自 O→Cr 的 LMCT（电荷转移跃迁）；四面体含氧阴离子（CrO₄²⁻/Cr₂O₇²⁻ 均为 Cr 四配位）是它的稳定形态。强氧化性（酸性 E⁰(Cr₂O₇²⁻/Cr³⁺) = +1.33 V）使其成为分析化学与有机氧化的常客，同时 Cr(VI) 致癌（强氧化损伤 DNA）——"有用但危险"的双面元素。

## 二、核心要点

### 2.1 铬酸根-重铬酸根平衡（pH 变色核心）

2CrO₄²⁻（黄）+ 2H⁺ ⇌ Cr₂O₇²⁻（橙）+ H₂O

- 酸性（pH < ~4）：以 Cr₂O₇²⁻ 为主（橙色）
- 碱性：以 CrO₄²⁻ 为主（黄色）
- 稀释影响：平衡左移（放水方向），稀释使 Cr₂O₇²⁻ 解聚变黄——"酸橙碱黄、稀释变黄"

**本质**：这是**同多酸缩合**的最简案例（聚合度 2）——与 [[钒的多酸]] 同源（酸致缩合），只是 Cr 只到二聚；与 [[三价铬水解]] 的 +3 水解线构成铬的两条 pH 主线。

### 2.2 强氧化性（酸性介质）

Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O，E⁰ = +1.33 V

- 典型反应（分析化学招牌）：
  - 滴定 Fe²⁺：Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O（重铬酸钾法测铁，二苯胺磺酸钠指示）
  - 氧化醇：酸性 K₂Cr₂O₇ 使伯醇 → 羧酸、仲醇 → 酮（颜色橙 → 绿 Cr³⁺，酒精检测仪原理）
- **氧化性依赖 pH**：酸性强氧化、碱性弱得多（E⁰ 降约 0.6 V）——"酸性橙水是氧化剂，碱性黄水近乎温和"

### 2.3 CrO₃ 与铬酰化合物

- CrO₃（铬酐）：暗红色固体，强氧化性（遇乙醇自燃），溶于水成铬酸 H₂CrO₄/重铬酸 H₂Cr₂O₇
- CrO₂Cl₂（铬酰氯）：红色液体，Cr(VI) 四面体含端基氧 + 两个 Cl——易水解回 CrO₄²⁻
- 制取：K₂Cr₂O₇ + 浓 H₂SO₄（重铬酸盐的"硫酸变红"：析出 CrO₃ 或生成铬酰）

### 2.4 CrO₅ 过氧配合物（高频易错点）

- 酸性 Cr(VI) + H₂O₂ → 蓝色 CrO₅（实为 CrO(O₂)₂ 或 CrO₅·配体加合物），乙醚萃取呈蓝色
- **Cr 仍为 +6**（两个 O₂²⁻ 过氧配体 + 一个端基氧）——不是 +5！
- 检验 H₂O₂ / Cr(VI) 的经典显色反应（蓝色乙醚层）

### 2.5 六价铬的制备与还原治理

- 制备：铬铁矿 FeCr₂O₄ + Na₂CO₃ + O₂ 焙烧（1100°C）→ Na₂CrO₄（黄）→ 酸化 → Na₂Cr₂O₇ → 结晶
- 废水治理：还原为 Cr³⁺（FeSO₄/NaHSO₃/亚铁）→ 碱沉 Cr(OH)₃——"六价还原成三价，三价沉淀出体系"
- Cr(VI) 检测：二苯碳酰二肼显色（紫红）——环境监测标准法

## 四、pH-形态-颜色速查表

| pH | 主要物种 | 颜色 | 氧化性 |
|---|---|---|---|
| < 1（强酸） | Cr₂O₇²⁻ / HCrO₄⁻ | 橙 | 最强（+1.33 V 体系） |
| 2~6 | Cr₂O₇²⁻ 为主 | 橙 | 强 |
| 7~10 | CrO₄²⁻ 为主（HCrO₄⁻ 渐消） | 黄 | 明显减弱 |
| > 10（强碱） | CrO₄²⁻ | 黄 | 弱（E⁰ ≈ +0.7 V 碱性体系） |

**分布图像**（原页附分布系数-pH 图，此处文字化）：pH ≈ 6~7 为 CrO₄²⁻/Cr₂O₇²⁻ 各半的转变区；强酸性下 HCrO₄⁻/Cr₂O₇²⁻ 并存。记住"转变区在 pH~6"即可定性判断任意给定 pH 的主物种。

## 五、完整算例（重铬酸钾滴定铁）

**题目**：0.02000 mol/L K₂Cr₂O₇ 滴定 25.00 mL Fe²⁺ 溶液，消耗 20.00 mL。求 Fe²⁺ 浓度。

**解答**：n(Cr₂O₇²⁻) = 0.02000×0.02000 = 4.000×10⁻⁴ mol；计量关系 Cr₂O₇²⁻ : Fe²⁺ = 1:6 → n(Fe²⁺) = 6×4.000×10⁻⁴ = 2.400×10⁻³ mol；c(Fe²⁺) = 2.400×10⁻³/0.02500 = **0.09600 mol/L**。

**要点**：① 计量比 1:6 是本题灵魂（数电子：Cr +6→+3 得 3e⁻×2 = 6e⁻，Fe +2→+3 失 1e⁻×6）；② K₂Cr₂O₇ 可作基准物质（易纯化、稳定），这是它优于 KMnO₄ 之处。

## 六、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| CrO₄²⁻ 与 Cr₂O₇²⁻ 当不同元素化合物 | 同一 Cr(VI) 的 pH 依赖形态，平衡互转 | 加酸橙、加碱黄——2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O |
| CrO₅ 当五价铬 | CrO₅ = CrO(O₂)₂，Cr 仍 +6，含过氧配体 | 蓝色乙醚层检验 H₂O₂——价态没变，是 O₂²⁻ 不是 O²⁻ |
| 碱性 CrO₄²⁻ 当强氧化剂 | 氧化性依赖 pH，碱性下 E⁰ 低得多 | 只有酸性 Cr₂O₇²⁻ 才是 +1.33 V 的强氧化剂 |
| 六价铬只有氧化性 | 碱性 CrO₄²⁻ 可被更强氧化剂（如过氧）再氧化 | CrO₅ 的生成就是"Cr(VI) 被 O₂²⁻ 配位氧化"的例子 |
| 滴定计量比记错 | Cr₂O₇²⁻/Fe²⁺ = 1:6 不是 1:3 | 数电子守恒：6e⁻ vs 1e⁻ → 1:6 |
| 重铬酸钾氧化性恒强于高锰酸钾 | 介质不同各有强弱；KMnO₄ 酸性 E⁰ = +1.51 V 更高 | 重铬酸钾的优势是稳定可基准化，不是氧化性更强 |

## §12 教学视角

### 学生常见认知误区
- **误区1：「CrO₄²⁻ 和 Cr₂O₇²⁻ 是不同物质」** → 它们是同一元素在不同 pH 下的存在形式，通过平衡互相转化 → **口诀：酸性橙（Cr₂O₇²⁻），碱性黄（CrO₄²⁻），加酸变橙、加碱变黄**
- **误区2：「CrO₅ 是稳定的五价铬化合物」** → CrO₅ 是过氧配合物 CrO(O₂)₂，Cr 仍为 +6 价，只是含有过氧基团 → **口诀：CrO₅ 中 Cr 仍是 +6 价，O₂²⁻ 是过氧配体不是 O²⁻**
- **误区3：「六价铬只有氧化性」** → 在碱性条件下 CrO₄²⁻ 可被强氧化剂氧化为更高价态（如 CrO₅ 中的过氧配位） → **口诀：酸性 Cr₂O₇²⁻ 只做氧化剂，碱性 CrO₄²⁻ 既可做氧化剂也可做还原剂**

### 入门级例题
**题目**: 向黄色 CrO₄²⁻ 溶液中逐滴加入稀 H₂SO₄，观察到溶液变橙色。写出平衡方程式，并解释颜色变化原因。
**分析**: CrO₄²⁻ 在碱性条件下稳定（黄色），加酸后平衡向 Cr₂O₇²⁻ 方向移动（橙色）。
**解答**: 2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O。加酸使 [H⁺] 增大，平衡右移，Cr₂O₇²⁻ 浓度增大，溶液由黄变橙。
**反思**: 这个平衡是铬化学的核心，也是 pH 指示剂变色的原理之一。

### 与现实/直觉的连接
六价铬的 pH 依赖变色就像一个天然的 pH 指示剂。工业上电镀铬时，镀液的 pH 控制直接决定了 Cr₂O₇²⁻ 的浓度，进而影响镀层质量。六价铬也是著名的致癌物，其毒性与强氧化性密切相关——能氧化 DNA 中的碱基。

### 教学建议
1. **现场变色实验**：向 K₂CrO₄ 溶液中加酸变橙、加碱变黄，直观感受平衡移动
2. **画平衡图**：用浓度-pH 图展示 CrO₄²⁻/Cr₂O₇²⁻ 的分布曲线（转变区 pH ≈ 6）
3. **CrO₅ 过氧检验**：讲解蓝色 CrO₅（乙醚萃取层显蓝色）是检验 H₂O₂ 的经典反应
4. **联系环保**：六价铬废水处理（还原为 Cr³⁺ 后沉淀）是实际应用场景
5. **与同族对比**：Mo(VI) 和 W(VI) 也能形成类似的含氧阴离子，但缩合倾向更强（形成多酸）

> **记忆锚**：六价铬四句——"酸橙碱黄是缩合，不是换价；CrO₅ 蓝色仍是 +6；要氧化先加酸；想治理先还原再沉淀。"

## 七、竞赛考察要点

1. **平衡移动题**：加酸/加碱/稀释对 CrO₄²⁻/Cr₂O₇²⁻ 的影响与颜色判断。
2. **氧化还原配平**：Cr₂O₇²⁻ 氧化 Fe²⁺/醇/SO₂——酸性介质、产物 Cr³⁺。
3. **滴定计算**：重铬酸钾法测铁（1:6 计量）——基准物质稳定性考点。
4. **过氧显色**：CrO₅ 蓝色乙醚层检验 H₂O₂；与 Ti 过氧橙色并列。
5. **工业流程**：铬铁矿焙烧 → Na₂CrO₄ → Na₂Cr₂O₇ → CrO₃/还原——制备与治理闭环。
6. **价态辨析**：CrO₅ 中 Cr 的价态计算（设 Cr 为 x：x + 2×(−1)×2 + (−2) = 0 → x = +6）。

## 八、关键结论速记

- 2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O：酸橙碱黄、稀释变黄——Cr(VI) 的第一方程。
- 酸性 Cr₂O₇²⁻ 是 +1.33 V 强氧化剂（Fe²⁺ 1:6）；碱性 CrO₄²⁻ 温和。
- CrO₅ 蓝色 = Cr(VI) + 过氧配体，不是 +5——检验 H₂O₂ 招牌反应。
- 黄色 CrO₄²⁻ 与橙色 Cr₂O₇²⁻ 颜色均来自 LMCT（d⁰ 无 d-d）。
- 治理闭环：Cr(VI) 还原 → Cr³⁺ → 碱沉 Cr(OH)₃；检测用二苯碳酰二肼紫红。
- 收尾自检：能写平衡式、1:6 滴定、CrO₅ 价态计算、酸碱性氧化差异——本页达标。
- 最后一题：为什么 K₂Cr₂O₇ 能作基准物而 KMnO₄ 不能？——易纯化、不吸湿、溶液稳定、氧化还原当量明确；KMnO₄ 需标定（自身会缓慢分解）。
