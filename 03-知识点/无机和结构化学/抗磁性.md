# 抗磁性

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 关联笔记：[[顺磁性]], [[配合物]], [[晶体场理论]]

## 一、定义

抗磁性（Diamagnetism）是指物质中所有电子均成对，在外加磁场作用下产生与外磁场方向相反的微弱磁矩，从而被磁场排斥的性质。抗磁性是所有物质的普遍属性，但在没有未成对电子的物质中表现得最为明显。

## 二、核心原理

### 2.1 产生机理

- **电子成对**：抗磁性物质中所有电子都成对填充在原子轨道或分子轨道中，净自旋 $S = 0$
- **感应磁矩**：外加磁场改变电子轨道运动，产生与外磁场方向相反的感应磁矩（楞次定律的微观表现）
- **磁化率**：$\chi < 0$，数量级约 $-10^{-6}$ ~ $-10^{-5}$，与温度无关

### 2.2 与顺磁性的对比

| 性质 | 抗磁性 | 顺磁性 |
|------|--------|--------|
| **电子结构** | 全部成对 | 有未成对电子 |
| **磁矩来源** | 感应磁矩（轨道运动改变） | 永久磁矩（自旋+轨道） |
| **磁化率符号** | $\chi < 0$ | $\chi > 0$ |
| **温度依赖性** | 基本与温度无关 | 服从居里定律，随温度升高而减弱 |
| **典型物质** | H₂O、N₂、NaCl、Zn²⁺（d¹⁰） | O₂、Fe³⁺（d⁵）、Cu²⁺（d⁹） |

### 2.3 竞赛中的判断要点

1. **过渡金属离子**：d⁰（Sc³⁺、Ti⁴⁺）和 d¹⁰（Zn²⁺、Cu⁺）构型通常为抗磁性
2. **强场配体 vs 弱场配体**：弱场下可能高自旋（顺磁），强场下可能低自旋甚至配对完全（抗磁）
3. **双原子分子**：$N_2$（抗磁）vs $O_2$（顺磁，有两个未成对电子）是经典对比

## 四、关键结论
- 抗磁性是所有物质的普遍属性，但在无未成对电子的物质中表现最明显
- 抗磁性磁化率 $\chi < 0$，数量级 $-10^{-6}$ ~ $-10^{-5}$，与温度无关
- $d^0$、$d^{10}$ 构型的过渡金属离子和所有主族闭壳层离子为抗磁性

## 五、常见分类或情形
| 典型抗磁性物质 | 电子构型特征 |
|:---|:---|
| $N_2$、$H_2O$、NaCl | 闭壳层分子/离子晶体 |
| $Zn^{2+}$（$d^{10}$）、$Cu^{+}$（$d^{10}$）| 全充满d轨道 |
| $Sc^{3+}$（$d^0$）、$Ti^{4+}$（$d^0$）| 空d轨道 |
| $[Fe(CN)_6]^{4-}$（低自旋 $d^6$）| 强场导致全部配对 |

## 六、适用条件与限制
- 抗磁性效应很弱，通常被顺磁性掩盖；只有在无未成对电子时才能单独观察到
- 超导体表现为完全抗磁性（迈斯纳效应，$\chi = -1$），但这与普通抗磁性的微观机制不同
- 抗磁性校正：在计算配合物有效磁矩时，需从摩尔磁化率中扣除抗磁贡献（Pascal常数）

## 七、常见比较与易混点
1. **抗磁性 vs 反磁性**：二者是同一概念的不同译名，英文均为 diamagnetism
2. **$N_2$ 抗磁 vs $O_2$ 顺磁**：$N_2$ 所有电子配对（MO中无未成对电子），$O_2$ 有两个未成对电子，这是MO理论的经典验证
3. **磁矩为零 ≠ 一定是抗磁性**：严格来说 $\chi < 0$ 才是抗磁，但化学中通常将 $\mu = 0$ 的物质统称为抗磁性

## 八、与其他知识点的联系
- [[顺磁性]]：抗磁性与顺磁性是磁性的两种基本类型，判断配合物磁性是竞赛核心技能
- [[配合物]]：配合物的磁性判断需要综合考虑金属电子构型和配体场强弱
- [[晶体场理论]]：晶体场分裂能与成对能的大小关系决定了配合物的磁性
- [[分子轨道理论]]：$N_2$ 与 $O_2$ 的磁性差异可通过MO理论完美解释

## 九、典型题型

1. **判断离子/配合物的磁性**：根据电子构型和配体场强判断抗磁或顺磁
2. **解释磁性差异**：如 $[\text{Fe(CN)}_6]^{4-}$（低自旋 d⁶，抗磁）vs $[\text{Fe(H}_2\text{O)}_6]^{2+}$（高自旋 d⁶，顺磁）
3. **MO理论解释**：$N_2$ 抗磁性与键级关系的解释

## 十、例题
**题目**：已知 $[Ni(CN)_4]^{2-}$ 为抗磁性，$[NiCl_4]^{2-}$ 为顺磁性（$\mu \approx 2.83\ \mu_B$）。Ni 为 +2 价（$d^8$），判断两种配合物的几何构型并说明理由。

**解答**：
- $[Ni(CN)_4]^{2-}$：抗磁性，$n=0$，$d^8$ 全部配对 → 平面正方形构型（$dsp^2$ 杂化，$dx^2-y^2$ 空轨道）。CN⁻为强场配体，促使形成平面正方形
- $[NiCl_4]^{2-}$：$\mu = 2.83\ \mu_B$，$\sqrt{n(n+2)} = 2.83$，$n=2$ → 四面体构型（$sp^3$ 杂化）。Cl⁻为弱场配体，$\Delta_t$ 较小，保持高自旋

## 十一、易错点
1. **$d^{10}$ 离子不一定是抗磁性的**：需确认氧化态正确，如 $Cu^{2+}$ 是 $d^9$（顺磁），$Cu^{+}$ 才是 $d^{10}$（抗磁）
2. **抗磁性校正不可忽略**：在精确磁矩计算中，配体的抗磁贡献（Pascal常数）需从总磁化率中扣除
3. **超导体的完全抗磁性 ≠ 普通抗磁性**：迈斯纳效应是宏观量子现象，机制完全不同

## 十二、🎯 教学视角
**学习路径**：从分子磁性的两种基本类型（抗磁/顺磁）出发 → 理解抗磁性的微观来源（楞次定律的量子版）→ 学习判断抗磁性的快速方法（电子是否全部配对）→ 结合晶体场理论讨论配合物的磁性

| 常见误区 | 正确理解 |
|:---|:---|
| "抗磁性只有少数物质才有" | 抗磁性是所有物质的普遍属性，只是通常被更强的顺磁性掩盖 |
| "$O_2$ 是抗磁性的因为稳定" | $O_2$ 有两个未成对电子，是顺磁性的；$N_2$ 才是抗磁性的 |

## 十三、竞赛拓展
- 磁化率的测量方法：古埃（Gouy）法、法拉第（Faraday）法和SQUID超导量子干涉仪
- Pascal加和规则：分子的摩尔抗磁磁化率可由原子和结构单元的抗磁磁化率加和估算
- 超导体的迈斯纳效应：$\chi = -1$（完全排斥磁场），是超导态的判据之一
