# 氰化法

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述
- 氰化法是金、银湿法冶金中的经典提取路线（全球约 75% 黄金产量依赖它）
- 它的本质是"稳定配离子形成 + 氧化还原推动"共同作用——**单独靠 CN⁻ 或单独靠 O₂ 都溶不动金，两者协同才行**

**元素速查**：Au 的惰性根源是 d¹⁰ 全满 + 高电离能 + 弱水合——标准电位 Au³⁺/Au = +1.50 V、Au⁺/Au = +1.68 V，常规酸/碱/单一试剂都无法氧化它；只有**配位剂把 Au⁺ 浓度拉到极低**，使 Au/Au(I) 电位大幅下移，空气（O₂）才有能力氧化。这是氰化法的全部化学秘密。

## 二、核心要点

### 2.1 核心反应与半反应拆分

总反应：4Au + 8CN⁻ + O₂ + 2H₂O → 4[Au(CN)₂]⁻ + 4OH⁻

半反应（碱性介质）：
- 阳极（Au 被氧化）：Au + 2CN⁻ − e⁻ → [Au(CN)₂]⁻，E⁰ ≈ −0.6 V
- 阴极（O₂ 被还原）：O₂ + 2H₂O + 4e⁻ → 4OH⁻，E⁰ = +0.40 V（碱性）

**E⁰ 分析**：裸 Au 的 Au⁺/Au = +1.68 V（无法被 O₂ 氧化，因为 1.68 > 0.40）；但配位后 [Au(CN)₂]⁻/Au 降到 ≈ −0.6 V < 0.40 V——**配位使金的氧化变得热力学可行**。稳定常数 K_f([Au(CN)₂]⁻) ≈ 10³⁸（极大）是电位大幅下移的根源。

银同理：4Ag + 8CN⁻ + O₂ + 2H₂O → 4[Ag(CN)₂]⁻ + 4OH⁻。

### 2.2 为什么 CN⁻ 是"两职"试剂

- **配体职**：与 Au⁺/Ag⁺ 络合成 [Au(CN)₂]⁻/[Ag(CN)₂]⁻（直线型，CN⁻ 的 σ 给电子 + π 接受稳定 Au(I)）
- **碱职**：CN⁻ 是弱酸 HCN（pKa 9.2）的共轭碱——浸出液 pH 须保持在 ~10 以上，使 CN⁻ 主要以游离形式存在（pH < 9 时大量变 HCN 逸出，剧毒且失效）

**作业条件**：石灰调 pH 10~11；充气（O₂ 是氧化剂）；NaCN 浓度约 0.03~0.3%。

### 2.3 工艺流程

1. **浸出**：矿石细磨 + NaCN 溶液 + 鼓空气，Au 溶解入液（数小时~数天）
2. **固液分离**：含金贵液与尾渣分离
3. **回收**：三选一——
   - 锌粉置换（经典）：Zn + 2[Au(CN)₂]⁻ → [Zn(CN)₄]²⁻ + 2Au↓（活泼金属置换，氧化还原非沉淀）
   - 活性炭吸附（CIP/CIL 工艺）：金氰配合物吸附到活性炭，再解吸电解
   - 离子交换/树脂法
4. **精炼**：粗金熔炼 → 电解精炼（金阳极泥）得高纯金

### 2.4 环保与替代（CN⁻ 剧毒）

- 尾矿中 CN⁻ 必须处理：碱性氯化法（Cl₂/次氯酸盐氧化 CN⁻ → CNO⁻ → CO₂/N₂）、SO₂-空气（Inco 法）、H₂O₂ 氧化、生物降解法
- 替代浸出剂：硫脲（酸性介质，Au 溶速快但耗量大）、硫代硫酸盐（碱性，对杂质不敏感）、王水只用于精炼不用于矿石
- 环保事故（尾矿库泄漏）使"无氰提金"成为研究热点

## 四、典型计算（电位法判断可行性）

**题目**：已知 Au⁺/Au 的 E⁰ = +1.68 V，[Au(CN)₂]⁻ 的 K_f = 10³⁸，CN⁻ 浓度 0.1 mol/L（[Au(CN)₂]⁻ 取 10⁻⁴ mol/L 近似）。求配位后 Au(I)/Au 的实际电位，判断 O₂（碱性 E⁰ = +0.40 V）能否氧化 Au。

**解答**：E = E⁰(Au⁺/Au) + 0.059·log[Au⁺]；由 K_f：K_f = [Au(CN)₂]⁻/([Au⁺][CN⁻]²) → [Au⁺] = 10⁻⁴/(10³⁸×0.01) = 10⁻⁴⁰。

E = 1.68 + 0.059×log(10⁻⁴⁰) = 1.68 − 2.36 = **−0.68 V < 0.40 V** → O₂ 氧化 Au 热力学可行 ✓。

**要点**：配位剂把游离 Au⁺ 浓度压到 10⁻⁴⁰ 量级，电位下移约 2.4 V——这正是"惰性金能被空气溶解"的定量解释。此类"由 K_f 算电位变化"是竞赛计算题标准型。

## 五、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| CN⁻ 只是络合剂 | CN⁻ 还当碱控制 pH——酸性下变 HCN 逸出失效且剧毒 | 浸出液必须石灰调 pH > 10；pH < 9 大量 CN⁻ 变 HCN |
| 氰化法只能提金 | 银同样适用（4Ag + 8CN⁻ + O₂ + 2H₂O → 4[Ag(CN)₂]⁻ + 4OH⁻） | "金银通吃"；铜锌杂质也会耗 CN⁻（需预处理） |
| 锌粉置换当沉淀反应 | 置换是氧化还原：Zn 还原 Au(I) 为 Au 单质 | 产物是 [Zn(CN)₄]²⁻ 配离子而非 Zn²⁺ 游离——写 [Zn(CN)₄]²⁻ 才完整 |
| 以为裸金能被 O₂ 氧化 | 裸 Au 电位 +1.68 V 高于 O₂ 的 +0.40 V——热力学禁止 | 配位后电位 −0.6 V 才可行；"先配位后氧化"是顺序关键 |
| 忽视 K_f 的量级意义 | K_f ≈ 10³⁸ 不是普通稳定，是"把电位拉下 2 V+"的级别 | 换弱配体（Cl⁻）达不到此效果——王水靠 Cl⁻ 络合 + 强氧化双管 |
| 浸出条件只写 NaCN 不写 pH/空气 | 缺 O₂ 无氧化动力、缺碱 CN⁻ 逸失——三个条件缺一不可 | 标准答案三件套：NaCN + 空气/O₂ + 碱性（pH~10-11） |

## 六、🎯 教学视角（补充）

### 学习路径建议

**前置知识**：配位化学、氧化还原电位、溶度积概念。

**推荐教学顺序**：
1. 从"为什么金这么惰性却能被溶解？"出发 → 引出氰化法的核心思想
2. 核心反应：4Au + 8CN⁻ + O₂ + 2H₂O → 4[Au(CN)₂]⁻ + 4OH⁻
3. 三个驱动力：CN⁻ 与 Au⁺ 形成稳定配离子（K_f ≈ 10³⁸）、O₂ 提供氧化动力、水提供质子
4. 工艺流程：浸出 → 锌粉置换 → 熔炼 → 电解精炼
5. 环保问题：CN⁻ 剧毒 → 尾矿处理和替代工艺（硫脲法、硫代硫酸盐法）

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "CN⁻ 只是络合剂" | CN⁻ 同时是配体（与 Au⁺ 络合）和碱（与 H⁺ 反应控制 pH） | "CN 一身两职" |
| "氰化法只能提金" | 氰化法也能提银：4Ag + 8CN⁻ + O₂ + 2H₂O → 4[Ag(CN)₂]⁻ + 4OH⁻ | "金银通吃" |
| "锌粉置换是沉淀反应" | 锌粉置换是氧化还原反应：Zn + 2[Au(CN)₂]⁻ → [Zn(CN)₄]²⁻ + 2Au | "置换靠氧化还原" |

### 与真实世界的联系

- **黄金开采**：全球约 75% 的金产量通过氰化法提取 → 理解工业化学的重要窗口
- **环境保护**：氰化法的环境风险（尾矿库泄漏）推动了"绿色提金"技术的发展
- **法医化学**：CN⁻ 是经典的毒物 → 与氰化法的联系让学生理解"毒物也是工具"

> **记忆锚**：氰化提金四句——"金太惰要配位帮，K_f 十的三十八方；空气供氧碱调 pH，锌粉换金 CN 走四方。"

## 七、竞赛考察要点与命题角度

1. **方程式**：写总反应或半反应（注意碱性介质 OH⁻ 配平）。
2. **电位计算**：由 K_f 与 E⁰ 算配位后电位，判断可行性（四节算例型）。
3. **流程题**：浸出条件（pH/O₂/浓度）与回收方法（锌置换 vs 炭吸附）选择理由。
4. **环保**：CN⁻ 处理原理（碱性氯化等氧化为 CNO⁻/N₂）。
5. **对比**：氰化法 vs 硫脲/硫代硫酸盐法优缺点——"毒性 vs 效率 vs 成本"三维比较。

## 八、工业数据速查（写论述/流程题用）

| 参数 | 典型值 | 说明 |
|---|---|---|
| NaCN 浓度 | 0.03~0.3%（约 0.006~0.06 mol/L） | 越高浸出越快但耗量/毒性↑ |
| 浸出 pH | 10~11（石灰调） | 防 HCN 逸出（pKa 9.2） |
| 溶金速率 | 与 [CN⁻]、[O₂] 都有关 | 两者任一不足都限速——"双限速"模型 |
| 锌粉置换 E⁰ | Zn²⁺/Zn = −0.76 V 远低于 [Au(CN)₂]⁻/Au ≈ −0.6 V | 热力学驱动力充足 |
| K_f[Au(CN)₂]⁻ | ≈ 10³⁸ | 直线型 [NC–Au–CN]⁻ |
| K_f[Ag(CN)₂]⁻ | ≈ 10²¹ | 银氰配离子同型 |
| 尾矿 CN⁻ 排放标准 | < 0.5 mg/L（中国） | 处理到 CNO⁻/N₂ 才可排放 |

**双限速模型要点**：浸出速率 ∝ [CN⁻]·[O₂] 的联合控制——工业上用"充气 + 适度 CN⁻ 浓度"平衡，单纯加 CN⁻ 不加氧不提速（反之亦然）。此模型是流程优化问答题的标准答案。

## 九、关键结论速记

- 氰化法 = 配位（K_f 10³⁸ 压电位）+ 氧化（O₂）+ 控 pH（CN⁻ 不逸）三要素协同。
- 配位使 Au 氧化电位 +1.68 V → −0.6 V——"惰性金被空气溶解"的定量解释。
- 回收 Zn 置换是氧化还原（产物 [Zn(CN)₄]²⁻）；现代主流是活性炭吸附。
- CN⁻ 剧毒：处理走氧化（Cl₂/H₂O₂/SO₂-空气）；替代走硫脲/硫代硫酸盐。
- 银同法（K_f 10²¹）；杂质 Cu/Zn 耗 CN⁻ 需预处理或加保护碱。
- 收尾自检：能写总反应与半反应、由 K_f 算电位变化、说出锌置换的氧化还原本质——本页达标。
