# 配体取代机理

## 核心概念

配合物配体取代反应有解离(D)、缔合(A)和交换(I/I_a/I_d)三种机理，取决于中心金属和配体性质。

**一句话本质**：取代反应 M–L(旧) + Y(新) → M–Y + L 只有一条原则——**旧键先断还是新键先来**。按"键的断裂与形成的先后与协同程度"，反应谱系从纯粹的 D（旧键先断、配位数降低）连续过渡到纯粹的 A（新键先成、配位数升高），中间是各种"交换"（I）：新键与旧键同步但程度不同。机理判断的硬证据来自**速率定律与配位数变化**，不是结构式直觉。

## 三种机理对比（主干）

| 机理 | 步骤 | 配位数变化 | 速率定律 | 中间体/过渡态 | 证据 |
|---|---|---|---|---|---|
| **D（解离）** | 旧配体先离开 → 低配位中间体 → 新配体结合 | 先降后升 | rate = k[配合物]（**与 Y 无关**） | 真实低配位中间体（可捕获） | 速率与 Y 浓度/亲核性无关；中间体可分离 |
| **A（缔合）** | 新配体先结合 → 高配位中间体 → 旧配体离开 | 先升后降 | rate = k[配合物][Y]（二级） | 真实高配位中间体 | 二级动力学；中间体可捕获（18e 规则） |
| **I（交换）** | 新键形成与旧键断裂同步，无中间体 | 不变 | 二级（I_a）或一级（I_d） | 过渡态（无中间体） | 速率与 Y 亲核性相关（I_a 强相关） |

**I_a 与 I_d 的区分**：I_a（缔合活化）中 Y 的进入程度大——速率对 Y 的**亲核性**敏感（如 Co(III)/Cr(III) 体系）；I_d（解离活化）中 L 的离去程度大——速率几乎只与 L 的离去能力相关、对 Y 不敏感。二者是"同一过渡态的两种偏向"，不是不同机理。

## 机理选择的决定因素

1. **中心金属的 d 电子数**：d⁸（Pt(II)、Ni(II)、Pd(II)）平面四方偏好 A（轴向空位可接受新配体）；八面体 d³/d⁶（Cr(III)、Co(III)）配位饱和且 CFSE 大，偏好 I_d/D
2. **中心金属大小与电荷**：半径大、电荷低 → 不易缔合（位阻小利于 A 但静电弱）
3. **配体体积（位阻）**：Y 或剩余配体庞大 → 抑制 A，逼向 D/I_d；拥挤的配合物取代慢（如含叔膦的配合物）
4. **配体离去能力（labilizing 效应）**：易极化、可稳定低配位中间体的配体离去快
5. **溶剂**：配位溶剂（H₂O、CH₃CN）可充当"陪衬配体"参与交换——溶剂协助路径

**经验排序**：八面体 Co(III)/Cr(III) 惰性（I_d）、八面体 V(II)/Fe(II)/Ni(II) 活性、平面四方 d⁸ 走 A 且 Ni ≫ Pd ≫ Pt（速率差可达 10⁵~10⁶ 倍）、d⁰/d¹⁰（Ti(IV)、Zn(II)）通常快交换。

## 活性/惰性判据（Taube）

- **活性（labile）**：25℃ 约 1 min 内完成取代；**惰性（inert）**：更慢。动力学概念，与热力学稳定/不稳定正交。
- 反例对：Co(NH₃)₆³⁺ 动力学惰性但热力学不稳定（酸解 K≈10²⁵）；Ni(CN)₄²⁻ 热力学稳定（K≈10⁻²²）但 CN⁻ 交换极快。

**判据口诀**：看 d 电子在**强场八面体**中的排布——CFSE 大的构型（d³、低自旋 d⁶）因取代要经过 CFSE 损失的过渡态而惰性；d⁰/d⁵(高自旋)/d¹⁰ 无 CFSE 损失 → 活性。**"d³、低自旋 d⁶ 惰性，其余多活性"**是最快的考场判断。

## CFAE 晶体场活化能（定量惰性判据）

- 定义：八面体→四方锥（D 机理）或→五角双锥（A 机理）的 CFSE 变化，对活化能的贡献。
- **CFAE>0 → 惰性；CFAE<0 → 活性**。
- 关键数据（表 4.2/4.3）：解离机理强场 d³/d⁶/d⁸ = +0.20/+0.40/+0.20 Δ₀；缔合机理强场 d⁶ = +0.852 Δ₀（最大）。
- d⁴(Cr²⁺)/d⁹(Cu²⁺) 因 JT 效应 + CFAE 双重贡献，水交换最快。

**CFAE 的物理图像**：取代反应必经配位几何畸变——八面体→四方锥（走 D）或→五角双锥（走 A）。畸变使 d 轨道能级分裂改变，若电子排布在新分裂下能量上升（CFAE > 0），该路径被抬高 → 惰性；若能量下降（JT 活性的 Cr²⁺/Cu²⁺ 走 D 反而稳定）→ 活性。

## 水交换速率的周期规律（读图要点）

| 位置 | 典型离子 | 水交换速率 / s⁻¹ | 原因 |
|---|---|---|---|
| d⁰ | Ca²⁺、Ti⁴⁺ | 10⁷~10⁸ | 无 CFSE |
| d³ | Cr³⁺ | ~10⁻⁶ | CFAE +0.40 Δ₀ → 最惰性 |
| 低自旋 d⁶ | Co³⁺（低自旋） | ~10⁻⁴ | CFAE +0.40 Δ₀（同 Cr³⁺ 量级） |
| d⁴/d⁹ | Cr²⁺、Cu²⁺ | 10⁸~10⁹ | JT 畸变 + CFAE 负贡献 |
| d⁵ 高自旋 | Mn²⁺、Fe³⁺ | 10⁶~10⁷ | 无 CFSE（高自旋） |
| d¹⁰ | Zn²⁺、Cd²⁺、Hg²⁺ | 10⁷~10⁹ | 无 CFSE |

**对照记忆**：周期表上"Cr³⁺ 和低自旋 Co³⁺ 最慢（10⁻⁴~10⁻⁶），两侧（d⁰/d⁵/d¹⁰）都快（10⁶⁺），Cr²⁺/Cu²⁺ 因 JT 甚至超过 d⁰"——图 4.6 的"双峰"即 Cr²⁺/Cu²⁺ 两个尖峰。

## SN1 CB 碱水解机理

- 碱水解不直接由 OH⁻ 进攻：先快平衡去质子生成共轭碱 Co(NH₃)₄(NH₂)X⁺，再决速步解离 X⁻。
- 速率：rate = k_b[Co(NH₃)₅X²⁺][OH⁻]（k_b'≈k_b 因 K≈K_w）。

**为什么叫 SN1 CB**：SN1（先解离）+ CB（conjugate base，共轭碱参与）——OH⁻ 的角色是**夺质子**而非直接进攻中心（否则无法解释为何对强场 Co(III) 这种"惰性中心"碱水解却快）。竞争证据：反应速率与 OH⁻ 浓度一级相关（符合先平衡），但配体 X 的离去顺序（I⁻ > Br⁻ > Cl⁻）符合解离控制。**共轭碱 NH₂⁻ 是更强给电子体 → 削弱 trans 位 X 键 → 促进解离**。

## 平面四方缔合机理与亲核性标度

- d⁸ 金属平面四方取代走缔合（SN2）机理，五配位三角双锥 18e 中间体；速率 Ni≫Pd≫Pt。
- 亲核反应活性常数 n⁰(Pt) = lg(k_Y/k_s⁰)，同族配位原子：F⁻≪Cl⁻<Br⁻<I⁻，O≪S<Se，N≪As<P。
- 亲核性 ≠ 碱性：PPh₃ n⁰=8.93 但 pK_a=2.61。

**反式效应联动**：平面四方取代中，**反位配体的 labilizing 效应**决定取代发生位置（见 [[反式效应]]）——强反式效应配体（CO、CN⁻、烯烃）使对位键变弱，亲核试剂优先从反位配体对面进攻。合成上"先放反式效应弱的、后放强的"可定向取代。

## 易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 所有取代都是解离（SN1 式） | 机理取决于 d 电子/几何/位阻——平面四方 d⁸ 走缔合 | Pt(II) 取代是 SN2 型（五配位中间体），二级动力学 |
| 速率与配体浓度无关就定成 D | I_d 也表现一级（对 Y 不敏感）——要区分"中间体可捕获"与"过渡态" | D 有可分离低配位中间体；I_d 无。速率数据只是必要非充分证据 |
| 活性=热力学不稳定 | 活性是动力学（1 min 内取代），与稳定性正交 | Co(NH₃)₆³⁺ 惰性但不稳定；Ni(CN)₄²⁻ 稳定但活性 |
| 碱水解= OH⁻ 直接进攻 | 碱水解走 SN1 CB：OH⁻ 夺质子生成共轭碱，决速步是解离 | 对强场惰性 Co(III) 仍快的原因就在"先脱质子活化" |
| 亲核性 = 碱性 | PPh₃ 强亲核（n⁰=8.93）但弱碱（pKa 2.61） | 亲核性管对金属进攻，碱性管对质子进攻——软硬不同对象 |
| 忽视 d 电子对速率的决定作用 | d³/低自旋 d⁶ 因 CFAE 惰性，d⁰/d⁵(HS)/d¹⁰ 活性 | Cr³⁺ 水交换 10⁻⁶ vs Cr²⁺ 10⁹——一个 d 电子的量级差异 |
| 以为取代必经过高配位数中间体 | D/I_d 机理配位数不升——配位数变化是机理判据之一 | 低自旋 d⁶ 八面体饱和且位阻大时宁愿解离 |

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解配体取代的三种基本机理（解离、缔合、交换），再学习影响机理选择的因素，最后掌握不同机理的动力学特征。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 所有配体取代都通过解离机理 | 机理取决于中心金属和配体的性质 |
| 解离机理中配体先离开 | 解离机理中旧配体先离开形成中间体 |
| 缔合机理中配体同时进出 | 缔合机理中新配体先结合形成中间体 |

### 15.3 入门级例题

**题目**：[Pt(NH₃)₄]²⁺中Cl⁻取代NH₃的反应属于什么机理？

**解答**：Pt(II)是d⁸构型，形成平面四边形配合物，配体取代通常通过缔合机理进行。新配体Cl⁻先与Pt²⁺结合形成五配位中间体，然后NH₃离开。

### 15.4 与现实世界的联系

1. **药物设计**：顺铂的抗癌作用涉及Cl⁻配体被水分子取代（水合后 DNA 配位）
2. **催化反应**：催化循环中配体的取代和活化（配体解离创造空配位）
3. **生物体系**：金属酶中的底物结合和产物释放（如碳酸酐酶的 Zn²⁺ 快交换）

> **记忆锚**：机理问三件事——旧键先断（D/配位降）还是新键先来（A/配位升）还是同步（I）；活性看 CFAE（d³、低自旋 d⁶ 惰性，Cr²⁺/Cu²⁺ 因 JT 最快）；d⁸ 平面四方走 SN2 + 反式效应定向。

## 竞赛考察要点

1. **机理判据**：给动力学数据（级数/对 Y 的敏感性）判 D/A/I。
2. **Taube 判据**：说清活性/惰性与热力学稳定性的正交关系（反例对）。
3. **CFAE 计算**：d³/d⁶/d⁸ 的 CFAE 值及对惰性的解释。
4. **水交换图读**：双峰（Cr²⁺/Cu²⁺）与谷（Cr³⁺/低自旋 Co³⁺）的位置与原因。
5. **SN1 CB 机理**：碱水解的共轭碱步骤与速率定律。
6. **反式效应/立体化学**：平面四方取代的产物构型（联动 [[反式效应]]）。

## 关键结论速记

- 机理谱系 D–I_d–I_a–A：旧键先断 ↔ 新键先来；中间体可捕获才是 D/A 的铁证。
- Taube：活性=1 min 内完成（动力学），与热力学稳定正交。
- CFAE：强场 d³/低自旋 d⁶ 取代必经高能过渡态 → 惰性；高自旋 d⁵/d⁰/d¹⁰ 无 CFSE 损失 → 活性。
- 水交换速率最慢 Cr³⁺、低自旋 Co³⁺（10⁻⁴~10⁻⁶），最快 Cr²⁺、Cu²⁺（JT，10⁸⁺）。
- d⁸ 平面四方（Pt/Pd/Ni）走缔合 SN2，速率 Ni ≫ Pd ≫ Pt，反式效应决定取代位。
- 碱水解 SN1 CB：OH⁻ 夺质子（共轭碱）→ 决速步解离——不是直接进攻。
- 亲核性 ≠ 碱性（PPh₃ 例）；n⁰(Pt) 标度 F⁻≪Cl⁻<Br⁻<I⁻。
- 收尾自检：能给动力学数据判机理、能背 Taube 反例对、能解释 Cr³⁺ vs Cr²⁺ 速率差 15 个数量级——本页达标。
