# CO2固定

## 核心概念

CO₂固定是指将CO₂转化为有用的化学品或材料的过程，可通过金属配合物催化插入反应实现。

## 核心原理

### CO₂的化学特性

- 线性分子(O=C=O)，碳为中心正电性
- 热力学稳定: $\Delta_fG^{\ominus} = -394$ kJ/mol
- 作为C1源(一碳单元)参与合成反应

### CO₂活化方式

**1. 金属配合物插入**
$$\text{M-R} + \text{CO}_2 \rightarrow \text{M-O-C(=O)-R}$$
- M-R键(金属-碳)极化，R⁻进攻CO₂的碳正中心
- 常见: Ni(0)、Pd(0)、Ti(IV)配合物

**2. Lewis酸活化**
- Lewis酸(如AlR₃)与CO₂的氧配位
- 使碳更缺电子，易受亲核进攻

**3. 碱活化**
- 强碱(如n-BuLi)直接进攻CO₂
- 形成羧酸盐中间体

### 金属催化CO₂插入机理

$$\text{M-L} + \text{CO}_2 \rightarrow \text{M}(\eta^2\text{-CO}_2) \rightarrow \text{M-O-C(=O)-L}$$

- L = 烷基、芳基、胺基、氢等
- CO₂先以η²模式配位，再插入M-L键
- 例: Ni(0)配合物 + CO₂ → η²-CO₂配合物 → 羧酸镍

### 热力学驱动力

- M-C键断裂 + C-O键形成 → 净能量变化
- M-O键通常较强(驱动反应正向进行)
- 需要合适的金属中心和配体设计

### 应用

| 应用 | 反应 | 产物 |
|:---|:---|:---|
| 聚碳酸酯 | CO₂ + 环氧化物 → | 聚碳酸酯 |
| 甲醇合成 | CO₂ + 3H₂ → | CH₃OH + H₂O |
| 羧化反应 | R-M + CO₂ → | RCOOH |
| 环状碳酸酯 | CO₂ + 环氧化物 → | 环状碳酸酯 |

## 与相关知识点的关系

### 与金属有机化学的联系
- CO₂插入是金属有机化学的经典反应类型
- 涉及氧化加成、还原消除、迁移插入等基元步骤
- 金属中心的电子密度和空间位阻影响反应活性

### 与配位化学的联系
- CO₂可作为σ配体或π配体与金属配位
- η¹-CO₂(单齿)和η²-CO₂(双齿)配位模式
- 配体设计调控金属中心的CO₂活化能力

### 与绿色化学的联系
- CO₂是温室气体，固定CO₂实现碳循环利用
- 替代光气(COCl₂)等剧毒C1源
- CO₂是可再生C1原料(来自生物质或大气)

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解CO2的化学性质和反应活性，再学习金属配合物催化CO2固定的机理，最后掌握CO2固定的应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| CO2是惰性气体 | CO2可以参与多种化学反应，如与格氏试剂反应 |
| 只有植物能固定CO2 | 许多金属配合物也能催化CO2的转化 |
| CO2固定只能生成有机物 | CO2也可以转化为无机物如碳酸盐 |

### 15.3 入门级例题

**题目**：解释为什么CO2能与格氏试剂反应而不能与水反应。

**解答**：格氏试剂RMgX中的C-Mg键极性大，碳带部分负电荷，可以进攻CO2中的碳正中心。而水分子中的O-H键极性方向相反，无法有效进攻CO2。

### 15.4 与现实世界的联系

1. **气候变化**：CO2固定是减少温室气体的重要途径
2. **绿色化学**：将CO2转化为有用化学品实现碳循环利用
3. **能源储存**：CO2电解还原制备燃料
