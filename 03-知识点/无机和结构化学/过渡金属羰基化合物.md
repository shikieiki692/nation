# 过渡金属羰基化合物

## 核心概念

过渡金属羰基化合物中CO作为π-酸配体，通过σ给予和π反馈键与金属结合，常遵循18电子规则。

### A. 单核与双核羰基典型结构

| 类别 | 化合物 | 构型 | 电子数 | 备注 |
|------|--------|------|--------|------|
| 单核 | V(CO)₆ | Oₕ | 17e | 顺磁，18e 规则例外 |
| 单核 | Cr/Mo/W(CO)₆ | Oₕ | 18e | |
| 单核 | Fe/Ru/Os(CO)₅ | D₃ₕ | 18e | |
| 单核 | Ni(CO)₄ | T₄ | 18e | |
| 双核 | Mn₂(CO)₁₀ | D₄ₕ | 每 Mn 18e | Mn—Mn 293 pm，无桥 |
| 双核 | Fe₂(CO)₉ | 三桥 | | 3 个 μ2-CO |
| 双核 | Co₂(CO)₈ | 两桥 | | 2 个 μ2-CO |

### B. CO 的五种配位方式

- **端基 μ1-CO**：M—C≡O 直线，最常见。
- **边桥 μ2-CO**：桥连两个金属中心。
- **半桥**：不对称桥（一短一长）。
- **面桥 μ3-CO**：桥连三个金属中心（三帽）。
- **侧基 η²-CO**：C、O 均参与配位，富电子金属，少见。

### C. σ-π 协同配键（synergic）

- CO 以 5σ（C 端孤对）→ M 做 σ 给予；M dπ → CO π* 做反馈。
- **协同效应**：σ 给予增强反馈，反馈增强 CO 的 σ 接受能力。
- 共振式：M—C≡O⁺ ↔ M=C=O；CO 键级由 3 降至 ~2.4-2.8。

> 📷 **图 6.5 M—CO σ-π 协同配键示意**（σ 给予 + dπ→π* 反馈，《中级无机化学》Ch6 教材原图）
> ![[媒体仓库/zjwx_ch6_co_sigma_pi_bonding.jpg]]

### D. νCO 谱学——反馈键强度的直接证据

- 自由 CO：2143 cm⁻¹。
- **等电子体系列**（金属形式负电荷↑ → dπ 反馈↑ → νCO↓）：
  Ni(CO)₄ 2066 → [Co(CO)₄]⁻ 1890 → [Fe(CO)₄]²⁻ 1790 → [Mn(CO)₄]³⁻ 1670 → [Cr(CO)₄]⁴⁻ 1462。
- **非经典羰基阳离子**（σ 为主、无反馈 → νCO 反升 > 2143）：[Au(CO)₂]⁺ 2235、[Pt(CO)₄]²⁺ 2261、[Ir(CO)₆]³⁺ 2295。
- **桥基 vs 端基**：Co₂(CO)₈ 端基 2050、桥基 1858 cm⁻¹。

### E. 制备 4 法

1. 金属 + CO 直接化合（Ni 25℃/常压；Fe 150℃/10 MPa）。
2. 还原法（CO 还原金属盐/氧化物，如 OsO₄ + CO → Os(CO)₅）。
3. 羰基阴离子（M(CO)₆ + 碱/还原剂）。
4. 羰基阳离子（Lewis 酸如 AlCl₃ 夺 CO）。

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解CO的电子结构和配位方式，再学习金属羰基化合物的成键特点，最后掌握18电子规则的应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| CO通过氧原子与金属配位 | CO总是通过碳原子与金属配位，因为碳的电负性较低 |
| 18电子规则是绝对的 | 18电子规则是经验规则，有些稳定化合物不满足该规则 |
| 金属羰基化合物都是单核的 | 金属羰基化合物可以是单核、双核或多核的 |

### 15.3 入门级例题

**题目**：Ni(CO)₄是18电子规则的典型例子，请验证。

**解答**：Ni的价电子数为10，4个CO各提供2个电子，总电子数 = 10 + 4×2 = 18，符合18电子规则。

### 15.4 与现实世界的联系

1. **有机合成**：金属羰基化合物用作有机合成的催化剂
2. **材料制备**：金属羰基化合物热分解可制备高纯金属粉末
3. **环境监测**：CO检测器利用金属羰基化合物的形成与分解
