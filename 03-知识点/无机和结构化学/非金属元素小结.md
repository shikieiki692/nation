# 非金属元素小结

> 本知识点综合总结氮、磷、硼、碳、硅五大非金属元素的竞赛核心内容，涵盖制备、结构、性质和典型反应。

---

## 一、氮元素化合物

### 1. 亚硝酸 (HNO₂)

#### 制备方法
- **气相合成法**：NO + NO₂ + H₂O → 2HNO₂
- **复分解法**：Ba(NO₂)₂ + 2HCl → 2HNO₂ + BaCl₂（低温）
- 亚硝酸不稳定，无法制得纯品，会发生歧化：3HNO₂ → 2NO + HNO₃ + H₂O

#### 核心性质
| 性质 | 数值/描述 |
|------|-----------|
| pKa | 3.3（中等强度酸） |
| 稳定性 | 不稳定，歧化分解 |
| 氧化性 | 通过 NO⁺ 实现 |
| 还原性 | 可被 KMnO₄、H₂O₂ 氧化 |

#### 氧化性反应（通过 NO⁺ 机理）
- 2I⁻ + 2NO⁺ → I₂ + 2NO
- Fe²⁺ + NO⁺ → Fe³⁺ + NO
- SO₂ + 2NO⁺ → SO₄²⁻ + 2NO
- HN₃ + NO⁺ → N₂O + H₂O + N₂

#### 还原性反应
- MnO₄⁻ + HNO₂ → Mn²⁺ + NO₃⁻（酸性高锰酸钾氧化）
- H₂O₂ + HNO₂ → H₂O + HNO₃

#### 与羟胺反应（同位素标记验证机理）
- **中性条件**：先形成肼衍生物（顺/反异构体），脱水后氮位置不固定
- **酸性条件**：直接形成 NH₂ONO 中间体，脱水后氮固定位于中间

#### 亚硝酸盐
- **稳定存在的盐**：碱金属（除Li）、碱土金属、Zn、Cd、Hg(I)、Ag(I)
- **LiNO₂特殊性**：锂离子强极化，性质类似镁盐
- **硝酸盐热分解制备**：
  - NaNO₃ → NaNO₂ + O₂（典型碱金属）
  - LiNO₃ → Li₂O + NO₂ + O₂（锂/镁系）
- **分解特性**：碱金属亚硝酸盐先熔融后分解；其他直接分解为氧化物

### 2. 联氨/肼 (N₂H₄)

#### 制备方法（Raschig反应）
- **总反应**：2NH₃ + NaClO → N₂H₄ + NaCl + H₂O
- **机理**：
  1. NH₃ + ClO⁻ → NH₂Cl + OH⁻（亲核进攻）
  2. NH₂Cl + NH₃ → N₂H₅⁺ + Cl⁻（SN2反应）
  3. OH⁻ + N₂H₅⁺ → N₂H₄ + H₂O
- **副反应**：联氨与氯胺反应生成N₂和NH₄Cl（强碱中写NH₃）

#### 结构与性质
- **结构**：两个N-H键平面呈C₂点群对称，"牛角"状空间构型
- **物理性质**：室温无水发烟液体
- **强还原性**：N₂H₄ + O₂ → N₂ + 2H₂O（火箭推进剂）
- **配位能力**：可作单齿或双齿配体

### 3. 叠氮酸 (HN₃)

#### 制备方法
- NaNH₂ + N₂O → NaN₃ + H₂O
- 2NaN₃ + Pb(NO₃)₂ → Pb(N₃)₂ + 2NaNO₃
- 叠氮盐酸化得HN₃

#### 核心性质
| 性质 | 数值/描述 |
|------|-----------|
| Ka | 1.8×10⁻⁵（与醋酸相当） |
| 结构 | N₃⁻与CO₂为等电子体，直线型 |
| 还原性 | 与HNO₂反应生成N₂O和N₂ |

#### 与金属反应的特殊性
- Zn + HN₃ → Zn(N₃)₂ + NH₃ + N₂（区别于普通酸生成H₂）

#### 配位模式
- **端基配位**：保持直线型与金属配位
- **桥联配位**：μ₂-η¹（单原子桥联）和 μ₂-η²（双原子桥联）
- **结构特征**：八元环配合物呈非平面构型

### 4. 硝基与亚硝酸根配合物

| 配位类型 | 配位原子 | 特点 |
|----------|----------|------|
| 硝基配合物 | N（η¹） | 仅氮配位，单齿 |
| 亚硝酸根配合物 | O或N | 可双齿配位（η²） |
| 桥式配合物 | N和O | 金属-配体-金属键角约112° |

## 二、磷元素化合物

### 1. 单质磷

#### 制备方法
- **工业法**：Ca₃(PO₄)₂ + 5C + SiO₂ → 3CaSiO₃ + P₂ + 5CO
- **SiO₂作用**：偶合剂，形成高晶格能硅酸钙，使反应热力学更有利

#### 同素异形体
| 形态 | 结构特征 | 性质 |
|------|----------|------|
| 白磷 | P₄正四面体，Td对称 | 剧毒、自燃，60°键角"香蕉键" |
| 红磷 | 无定型，可能含链状/层状结构 | 较稳定 |
| 黑磷 | 层状结构，三种晶型（菱形、正交、立方） | 最稳定 |

#### 白磷的特殊成键
- 键角60°，电子云偏离键轴形成"香蕉键"
- 解释：sp³杂化但键角压缩，或p-d²杂化（d轨道参与成键）

#### 化学反应
- **碱液歧化**：P₄ + 3KOH + 3H₂O → PH₃↑ + 3KH₂PO₂
- **还原性**：可将CuSO₄还原为Cu、Cu₃P等多种产物
- **配位规律**：
  - 3配位：P₄、PH₃、PCl₃、P₄O₆
  - 4配位：磷酸盐、P₄O₁₀（最稳定）
  - 5配位：PF₅、PCl₅
  - 6配位：特殊配合物（罕见）

### 2. 磷化氢 (PH₃)

#### 制备方法
- Ca₃P₂水解、AlP水解
- 白磷加碱
- H₃PO₃热分解：H₃PO₄ + PH₃
- PCl₃与LiAlH₄反应

#### 结构特点
- 键角93.6°（远小于NH₃的107.5°）
- 接近纯p轨道的90°，说明杂化作用弱，孤电子对s成分高
- 体现第二周期与第三周期元素的差异

#### 化学性质
| 性质 | 描述 |
|------|------|
| 热分解 | 478-483K分解为P₄和H₂ |
| 燃烧 | Cl₂中呈浅绿色火焰，生成PCl₃和PCl₅ |
| 还原性 | 还原KMnO₄、CuSO₄、AgNO₃、H₂O₂ |
| 酸性 | pKa≈27（比NH₃的pKa=34更强） |
| 路易斯碱性 | 可与BF₃、B₂H₆、AlCl₃形成加合物 |

#### 与甲醛反应（竞赛考点）
- PH₃ + HCHO → [P(CH₂OH)₄]⁺Cl⁻
- 产物中正负离子均为正四面体构型

### 3. 三卤化磷 (PX₃)

#### 键角规律
- 电负性越大，键电子离P越远，键角越小
- 键角排序：PF₃ < PCl₃ < PBr₃ < PI₃

#### 水解反应
- 浓碱：PF₃生成H₂PO₃⁻和F⁻
- 稀碱：生成含氟亚磷酸盐
- 常规：PCl₃ + 3H₂O → H₃PO₃ + 3HCl

#### PF₃的特殊性
- 弱路易斯碱，但强π酸配体（吸电子使d轨道能量降低）
- **π酸配体强度排序**：NO⁺ > PF₃ > CO > PCl₃ > P(OR)₃ > PR₃
- **中毒机理**：与CO类似，可与血红蛋白中的铁结合

### 4. 五氟化磷 (PF₅)
- 理论三角双锥构型，但五个F实际等同
- 通过四方锥中间体快速翻转实现氟等价
- 分子快速重排的典型案例

### 5. 磷的氧化物

#### P₄O₆（六氧化四磷）
- Td点群，四面体骨架，棱上插入O原子
- 只含P-O键，不含P-P键
- 重要反应：5P₄O₆ + 8I₂ → 4P₂I₄ + 3P₄O₁₀

#### P₄O₁₀（十氧化四磷）
- 结构演变：P₄O₆(Td) → P₄O₇(C₃ᵥ) → P₄O₈(C₂ᵥ) → P₄O₉(C₃ᵥ) → P₄O₁₀(Td)
- 强脱水剂

### 6. 磷的硫化物
- **P₄S₃**：三元环结构，只含五元环和三元环，无六元环
- **P₄S₁₀**：4Fe₂P + 18S → 2P₄S₁₀ + 8FeS
- **热稳定性规律**：含硫量越少越稳定

### 7. 磷的含氧酸

| 酸名 | 化学式 | 特点 |
|------|--------|------|
| 次磷酸 | H₃PO₂ | 一元酸，pKa=1.1，P-H有强还原性 |
| 亚磷酸 | H₃PO₃ | 二元酸，Ka=5.1×10⁻² |
| 连二磷酸 | H₄P₂O₆ | K₁≈6×10⁻³，K₂≈1.5×10⁻³ |
| 正磷酸 | H₃PO₄ | 自偶电离：2H₃PO₄ ⇌ P(OH)₄⁺ + H₂PO₄⁻ |
| 焦磷酸 | H₄P₂O₇ | K₁=0.14，K₂=0.011 |
| 偏磷酸 | (HPO₃)ₙ | 环状结构，区别于多聚磷酸（线性） |

#### 磷酸盐分解规律
- 同族阳离子半径越大，碳酸盐越稳定
- 非闭壳层（过渡金属）比闭壳层更不稳定
- 极化作用越强（半径小、电荷高），越易分解

## 三、硼元素化合物

### 1. 单质硼

#### 制备方法
- Mg还原B₂O₃得无定形棕色硼
- Na还原BCl₃得无定形硼
- Zn还原BCl₃得晶体硼
- H₂还原BBr₃得高纯度硼

#### 晶体结构
- **基本单元**：B₁₂正三角二十面体（Ih群）
- **α-菱形硼**：近似CCP堆积，但角度偏差（58.06°而非60°）形成三方晶系
- **成键方式**：硼原子间通过3c-2e键连接

### 2. 硼烷

#### 特殊键型
- 3c-2e氢桥键（B-H-B）
- 3c-2e硼桥键（B-B-B）
- 正常2c-2e B-B键和B-H键

#### Styx规则
- **s**：B-H-B三中心键数
- **t**：B-B-B三中心键数
- **y**：B-B二中心键数
- **x**：额外B-H键（BH₂基团）数

**方程组**：
- 电子守恒：s + 2t + 2y + x = 2p
- 轨道守恒：2s + 3t + 2y + x = 3p
- 氢原子守恒：s + x = q

**负电荷处理**：负电荷视为骨架额外电子，2p变为2p+1

#### Wade规则
- **b**（骨架成键电子对数）= q/2
- **n**（骨架原子数）= p
- 闭式：b = n + 1（q = 2）
- 巢式：b = n + 2（q = 4）
- 网式：b = n + 3（q = 6）

**示例**：B₂H₆ → STYX=[2,0,0,2]，b=4，n=2，巢式

### 3. 硼烷反应

#### 加合反应
- B₂H₆ + 2L → 2BH₃·L（直接加合）
- B₂H₆ + 2L → [L₂BH₂]⁺[BH₄]⁻（离子型加合）

#### 取代反应
- B-H键可被有机基团取代
- NH₃取代时，适量NH₃生成氨基硼烷，过量生成无配位氨基硼烷

#### 硼氢化反应
- 3RCH=CH₂ + ½B₂H₆ → (RCH₂CH₂)₃B
- 通过配位→断键→形成三烷基硼机理

#### 作为还原剂
- RCN → RCH₂NH₂（腈还原为伯胺）
- RR'C=NOH → RR'CHNH₂（肟还原为仲胺）

#### 燃烧反应
- B₂H₆ + 3O₂ → B₂O₃ + 3H₂O（放出大量热）

### 4. 硼酸 (H₃BO₃)

#### 电离特性
- 分子式B(OH)₃，C₃h点群
- 特殊电离：B(OH)₃ + H₂O ⇌ [B(OH)₄]⁻ + H⁺
- pKa = 9.25（弱酸）
- 浓溶液中三聚体形成增强酸性：3B(OH)₃ ⇌ B₃O₃(OH)₃ + 3H₂O

#### 增强酸性的方法
- 加甘油：与硼酸根形成络合物，释放质子
- 解决滴定困难问题

#### 硼酸酯
- B₂O₃ + 6ROH → 2B(OR)₃ + 3H₂O
- 燃烧产生绿色火焰（重要考点）
- 热分解：B(OR)₃ → B(OH)₃ + ROH

### 5. 硼酸盐结构

#### 基本结构单元
- 三角形：BO₃³⁻
- 四面体：BO₄⁵⁻
- 仅通过顶点连接，无边或面共享

#### 构建规则
- 仅允许完全/部分质子化形式
- 氧通常连接1-2个硼原子
- 氢只连氧且氧仅连1个硼
- 形成B₃O₃六元环需满足特定化学计量比

#### 典型化合物
- [B₅O₆(OH)₄]⁻：双六元环螺环结构，sp³杂化

### 6. 硼卤化物

#### 制备方法
- 浓H₂SO₄处理银砂与B₂O₃制BF₃
- B₂O₃ + 3C + 3Cl₂ → 2BCl₃ + 3CO
- 无水HF处理硼砂得Na₂O·4BF₃加合物

#### 路易斯酸性（反常规律）
- 排序：BBr₃ > BCl₃ > BF₃ ≈ AlCl₃
- 原因：π反馈键强度随电负性增大而增强，导致路易斯酸性反而减弱

#### 水解差异
- BCl₃、BBr₃、BI₃：剧烈水解生成H₃BO₃和HX
- BF₃：B-F键强度极高（582 kJ/mol），不水解，形成加合物

#### 醇解反应差异
- BCl₃ + 3ROH → B(OR)₃ + 3HCl
- BF₃ + ROH → BF₃·ROH（不断裂B-F键）

## 四、碳元素化合物

### 1. 碳化物分类

#### 离子型碳化物
- **C⁴⁻型**：Al₄C₃（水解得CH₄）
- **C₂²⁻型**：CaC₂（水解得C₂H₂）
- **C₃⁴⁻型**：Mg₄C₃（等电子体CO₂，水解得丙二烯）
- CaC₂结构：类似NaCl但对称性降低为四方体心
- CaC₂ + N₂ → CaCN₂ + C（2008年国初考点）

#### 间隙型碳化物
- 第4-6族过渡金属（除Cr），如TiC、WC
- 金属原子立方最密堆积，碳填八面体空隙
- 超高熔点（TiC: 3683K）、极高硬度（莫氏8-9级）

#### 共价碳化物
- SiC（金刚砂）：类似闪锌矿的金刚石型结构

### 2. 一氧化碳 (CO)

#### 制备与纯化
- 甲酸脱水法：HCOOH → H₂SO₄ → CO + H₂O
- 纯化：加热分解镍羰基配合物（470K）

#### 核心性质
| 性质 | 描述 |
|------|------|
| 偶极矩 | 0.112D（很小） |
| 电荷分布 | C端负，O端正（与常见误解相反） |
| 配位特性 | 总是通过C原子配位 |
| π酸性 | 强π酸配体 |

#### 典型反应
- 还原PdCl₂为金属Pd
- 与Fe₂O₅反应
- 6-8atm、390-400K下与NaOH反应生成甲酸钠
- 与S反应生成COS
- 与硼烷在NaCN存在下发生路易斯酸碱加合

### 3. 二氧化碳 (CO₂)

#### 干冰结构
- 分子晶体，CCP堆积但取向不同
- 简单立方晶胞，Pa3空间群
- 具有沿体对角线的四个C₃旋转轴

### 4. 碳酸盐分解规律

#### 稳定性规律
- 同族阳离子半径越大，碳酸盐越稳定
- 非闭壳层比闭壳层更不稳定
- 极化作用越强（半径小、电荷高），越易分解

#### 计算理解
- 分解倾向取决于氧化物与碳酸盐的点阵能差值
- 半径大的金属更易保持碳酸盐形态

#### 典型示例
- Li₂CO₃比Cs₂CO₃更易分解

### 5. 碳酸根晶体结构
- 自由态：D₃h对称性
- 晶体中：受阳离子或氢键影响，对称性降低
- **方解石**：三方晶系，R3̄c空间群，低温低压稳定
- **文石**：正交晶系，Pmcn空间群，高压低温稳定

### 6. 碳酸氢盐
- 稳定性几乎都低于对应碳酸盐
- 原因：H⁺极化作用强于任何金属离子
- NH₄HCO₃比(NH₄)₂CO₃更稳定（三维网状氢键结构）

### 7. 四卤化碳

#### 物理状态
- CF₄：无色气体
- CCl₄：无色液体
- CBr₄：黄色固体
- CI₄：亮红色固体

#### 制备方法
- CF₄：AgOF + CCl₄ 或 SiC + F₂/XeF₂
- CCl₄：CS₂ + 3Cl₂ → CCl₄ + S₂Cl₂（路易斯酸催化）
- CBr₄：CH₄ + Br₂ 或 CCl₄ + AlBr₃
- CI₄：CCl₄ + C₂H₅I

## 五、硅元素化合物

### 1. 单质硅

#### 结构与性质
- a4型（金刚石型）堆积，灰黑色金属光泽
- 半导体：掺B/Al/Ga为p型，掺P/As为n型

#### 溶解性
- 不溶于纯HF
- 溶于NaOH：Si + 4OH⁻ → SiO₄⁴⁻ + 2H₂↑
- 溶于HF+浓HNO₃：生成H₂SiF₆和NO
- 非纯硅可溶于HF生成SiF₄

#### 制备方法
- SiO₂ + C → SiCl₄/SiHCl₃（高温）
- H₂还原SiCl₄或SiHCl₃得高纯硅

### 2. 硅烷

#### 制备方法
- LiAlH₄还原硅卤化物：SiCl₄ → SiH₄，Si₂Cl₆ → Si₂H₆
- 替代还原剂：Li/LiH/NaH

#### 化学性质
| 性质 | 描述 |
|------|------|
| 自燃性 | 空气中可自燃，放出大量热 |
| 电负性 | Si(1.8) vs H(2.1)，H显负电性 |
| 还原性 | 强还原剂 |

#### 典型反应
- SiH₄ + MeOH → SiH₃(OMe) + H₂ → Si(OMe)₄ + H₂
- SiH₄ + 2H₂O → SiO₂·xH₂O + 4H₂↑

## 六、氰化物

### 1. 氰 (CN)₂ 制备
- CuSO₄ + 2KCN → CuCN↓ + K₂SO₄ + (CN)₂↑
- 氧化性介于I₂和Br₂之间

### 2. 氰化氢 (HCN) 制备
- HCONH₄ → P₄O₁₀ → HCN + 2H₂O
- Hg(CN)₂ + ZnS → HgS↓ + 2HCN↑
- CaCN₂水解（2008年国初考点）

### 3. 氰根配位特性
- **双齿配位**：C端（软）配二价金属，N端（硬）配三价金属
- **结构类型**：有限结构、无限链状、层状、三维结构

### 4. 卤化氰
- FCN、ClCN、BrCN、ICN均可稳定存在
- 可三聚形成环状结构：3XCN → (XCN)₃

### 5. 普鲁士蓝结构
- 立方晶系，八个小立方体组成完整晶胞
- Fe²⁺与CN⁻碳端配位，Fe³⁺与CN⁻氮端配位
- K⁺填入四个交错立方体空隙
- 完全氧化形式为柏林绿：Fe[Fe(CN)₆]₃

## 七、典型应用与竞赛考点

### 1. 结构判断
- 白磷P₄的Td对称性和"香蕉键"
- 干冰的Pa3空间群和C₃轴
- α-菱形硼的三方晶系（角度偏差58.06°）
- 普鲁士蓝的立方晶系和配位规律

### 2. 反应机理
- 亚硝酸与羟胺反应的同位素标记验证
- Raschig反应制联氨的SN2机理
- 硼氢化反应的配位→断键→形成机理
- Wade规则和Styx规则的应用

### 3. 特殊性质
- LiNO₂性质类似镁盐（极化作用）
- PF₃的π酸性和中毒机理
- BF₃路易斯酸性的反常规律
- 碳酸盐分解的点阵能分析
- NH₄HCO₃比(NH₄)₂CO₃更稳定（氢键网络）

### 4. 配位化学
- 硝基/亚硝酸根配合物的配位模式
- CN⁻的双齿配位和软硬酸碱
- 硼烷的加合反应和配位数变化
