# 外层电子转移


## 核心概念

外层电子转移机理（Outer-sphere mechanism）不经过桥联配体，电子直接在两个配合物之间转移。

## §二 核心原理

### 机理特点

外层电子转移的两个配合物各自保持完整的配位层，电子通过空间直接隧穿转移，不涉及配体桥联。

### 适用条件

| 条件 | 说明 |
|:---|:---|
| 惰性配体层 | 两个配合物都有惰性配体（如 [Fe(CN)₆]³⁻/⁴⁻） |
| 配体不易桥联 | 配体空间位阻大或电子结构不利于桥联 |
| 结构相似 | 氧化态和还原态结构差异小 |

### Franck-Condon原理与重组能

电子转移瞬间核构型不变，因此需要**重组能 λ** 来补偿核构型差异：

$$\lambda = \lambda_{\text{内层}} + \lambda_{\text{外层}}$$

| 重组能组成 | 来源 |
|:---|:---|
| 内层重组能 $\lambda_{\text{内层}}$ | 键长/键角变化 |
| 外层重组能 $\lambda_{\text{外层}}$ | 溶剂分子重排/极化 |

### 自交换反应速率差异

不同体系的自交换反应速率差异巨大：

| 自交换反应 | 速率常数 k |
|:---|:---|
| [Fe(H₂O)₆]³⁺/²⁺ | ~4 |
| [Ru(bpy)₃]³⁺/²⁺ | ~4×10⁸ |

### 速率影响因素

| 因素 | 影响 |
|:---|:---|
| σ\*轨道转移 | 速率较慢（如Cr³⁺/²⁺） |
| π轨道转移 | 速率较快（如Fe³⁺/²⁺） |
| 大体积配体屏蔽 | 降低电子耦合，减慢速率 |

## §二.5 本书补充（中级无机化学 Ch4）

> 来源：[[07-资料提炼/书籍提炼/提炼-中级无机化学-第4章-配合物反应机理]]

### Franck-Condon 限制的根源（半径差）

Fe²⁺(74 pm) 与 Fe³⁺(64 pm) 半径差使相应轨道能量不匹配；须靠核运动（≈10⁻¹³ s，比电子运动 10⁻¹⁵ s 慢约 2 个数量级）先使轨道能量相等，电子转移瞬间核近似"冻结"。

### 外界机理活化能三组成

1. 克服相同电荷离子排斥的静电能
2. 扭曲两个配离子配位层的能量
3. 改变两个配离子周围溶剂排布的能量

Fe(H₂O)₆²⁺/³⁺ 自交换 E_a≈32 kJ·mol⁻¹。

### 自交换与交叉反应速率（表 4.11 关键数据）

| 反应 | k/(dm³·mol⁻¹·s⁻¹) |
|:---|:---|
| Cr(H₂O)₆²⁺/³⁺ | 5.1×10⁻¹⁰ |
| Co(NH₃)₆²⁺/³⁺ | <10⁻⁹ |
| Fe(H₂O)₆²⁺/³⁺ | 4 |
| Fe(CN)₆⁴⁻/³⁻ | 7.4×10² |
| Ru(NH₃)₆²⁺/³⁺ | 8×10² |
| IrCl₆³⁻/²⁻ | 2.3×10⁵ |
| Cr(bipy)₃²⁺/Fe(H₂O)₆³⁺ | 1.4×10⁹ |

规律：**含净化学变化的交叉反应快于自交换**（如 Cr(H₂O)₆²⁺-Fe(H₂O)₆³⁺ k=2.3×10³ vs 两者自交换 5.1×10⁻¹⁰ 与 4）；惰性配合物电子转移速率仍可极快（Fe(CN)₆⁴⁻-IrCl₆²⁻ k=3.8×10⁵，两者配体取代 t₁/₂>1 min）。

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解外层电子转移的基本特点，再学习影响反应速率的因素，最后掌握判断反应机理的方法。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 所有电子转移都通过内层机理 | 外层机理不需要桥联配体，适用于某些特定体系 |
| 外层电子转移速率一定比内层快 | 电子转移速率取决于具体体系和反应条件 |
| 外层电子转移不涉及配体 | 配体环境会影响电子转移速率 |

### 15.3 入门级例题

**题目**：[Fe(H₂O)₆]²⁺和[Fe(H₂O)₆]³⁺之间的电子转移属于什么机理？

**解答**：这是外层电子转移机理。两个配合物结构相似，不需要桥联配体，电子可以直接在两个Fe离子之间转移。

### 15.4 与现实世界的联系

1. **生物体系**：细胞色素c中的电子传递涉及外层电子转移
2. **电池技术**：电池充放电过程涉及电极材料中的电子转移
3. **催化反应**：许多催化循环涉及金属中心的氧化还原和电子转移
