# 金刚石型结构

![[mineru/03-教材书籍/无机化学第6版Weller/无机化学第6版Weller/无机化学第6版主族364-564_images/4eef2f5667ede1df13bd746adfe1a69ee77a18b816ee289ef2f9ecefad77102d.jpg]]

> Weller 图 14.1 的立方金刚石结构图，既能展示层状投影，也便于承接“两个互穿 fcc 子晶格”的结构描述。

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[17-常见晶体结构]]

## 一、结构描述
- C 原子：fcc 位置 + 1/2 四面体空隙交错填充
- 每个 C：sp³ 杂化，正四面体配位 4 个 C
- = 两套 fcc 子格子沿体对角线偏移 1/4

## 二、参数
- 晶胞含：8 个 C 原子
- 空间利用率：34%（很低，因共价键有方向性）
- C—C 键长：154 pm

## 三、类似结构
- Si, Ge, α-Sn（灰锡）
- 立方 BN（闪锌矿型，B+N 替代 C+C）

## 四、关键结论
### 晶胞参数
- 金刚石属面心立方晶胞，含 **8 个 C 原子**（4 个 fcc + 4 个 Td 交替填充）
- 空间利用率仅 **34%**（共价键方向性导致，远低于金属最密堆积的 74%）
- C—C 键长 **154 pm**，配位数 **4**（sp³ 正四面体）

### 性质（§13.4.4）
- 自然界中**硬度最大**的晶体之一
- 精密机械中每年消耗**几百万克拉**（1 克拉 = 200 mg）
- 用做金属表面磨料、石油勘探钻头

### 共价晶体特征
金刚石是共价晶体（原子晶体）的典型代表——低配位数（4）、低空间利用率（34%）、高熔点、高硬度、不导电、整个晶体是一个巨大分子。

## 五、常见分类或情形
与立方 ZnS 型的关系（§13.4.2）：
- **立方 ZnS 型** = S²⁻ fcc + Zn²⁺ 在 1/2 Td
- **金刚石型** = C fcc + C 在 1/2 Td（**两套 fcc 子格子沿体对角线偏移 1/4**）
- 立方 BN（闪锌矿型）= B + N 替代 C + C

### 其他金刚石型晶体
Si、Ge、$\alpha$-Sn（灰锡）均为金刚石型结构，但禁带较窄，属于半导体。

## 六、适用条件与限制
- 更适用于方向性极强的共价晶体，不适合简单离子球模型解释
- 结构相似不等于物性相同，Si、Ge、C 的禁带和硬度差异仍很大

## 七、常见比较与易混点
- 金刚石型可视为“同种原子的立方 ZnS 型”，但成键本质是共价键而非离子键
- 低空间利用率并不代表结构松散，方向性共价键会显著提高硬度

- 前置知识：[[立方ZnS型结构]]、[[原子晶体]]
- 对比知识：[[石墨结构]]、立方BN结构

## 十、例题

**例题**：金刚石晶胞中含 8 个 C 原子，晶胞参数 a = 356.7 pm。计算金刚石的 C—C 键长和空间利用率。

**解**：
1. C—C 键长 = (√3/4) × a = 0.433 × 356.7 pm ≈ 154 pm
2. 晶胞中 8 个 C 原子总体积 = 8 × (4/3)π(77 pm)³ = 8 × 1.912 × 10⁶ pm³ = 15.30 × 10⁶ pm³
3. 晶胞体积 = a³ = (356.7)³ = 45.38 × 10⁶ pm³
4. 空间利用率 = 15.30 / 45.38 ≈ 33.7% ≈ 34%

**关键**：金刚石中 C—C 键长 = (√3/4)a，来源于体对角线 1/4 偏移的几何关系。

## 十一、易错点

1. **晶胞中原子计数**：不要只算 fcc 的 4 个原子——金刚石有两套子格子，共 8 个原子
2. **C—C 键长 ≠ a/2**：键长沿体对角线方向，为 (√3/4)a，不是面对角线或棱长的一半
3. **空间利用率低 ≠ 结构松散**：34% 是共价键方向性的结果，但正因如此金刚石硬度极高
4. **金刚石 vs 石墨**：两者都是碳的同素异形体，但金刚石是 sp³ 原子晶体（不导电），石墨是 sp² 层状结构（导电）

## 十二、🎯 教学视角

### 12.1 学习路径

1. 从立方 ZnS 型结构出发 → 理解两套 fcc 子格子的偏移关系
2. 用手模型或球棍模型演示 sp³ 四面体配位
3. 计算晶胞参数（键长、空间利用率）→ 掌握几何推导
4. 对比金刚石、石墨、C₆₀ → 理解碳的多种成键方式

### 12.2 学生易踩的认知误区

| 常见误区 | 正确理解 |
|:---|:---|
| "金刚石空间利用率只有 34%，所以结构不稳定" | 低填充率恰恰是共价键方向性的体现，金刚石硬度极高 |
| "金刚石型和立方 ZnS 型完全不同" | 金刚石可视为"同种原子的立方 ZnS 型"，只是成键由离子键变为共价键 |
| "Si 和金刚石结构一样所以性质也一样" | 结构相同但禁带宽度不同，Si 是半导体而金刚石是绝缘体 |
