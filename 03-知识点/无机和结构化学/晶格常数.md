# 晶格常数

## 一、定义
晶胞的六个参数：a, b, c（棱长）和 α, β, γ（棱间夹角）。

### 七大晶系的晶格常数特征
| 晶系 | 边长 | 夹角 |
|------|------|------|
| 立方 | a = b = c | α = β = γ = 90° |
| 四方 | a = b ≠ c | α = β = γ = 90° |
| 正交 | a ≠ b ≠ c | α = β = γ = 90° |
| 六方 | a = b ≠ c | α = β = 90°, γ = 120° |
| 三方 | a = b = c | α = β = γ ≠ 90° |
| 单斜 | a ≠ b ≠ c | α = γ = 90°, β ≠ 90° |
| 三斜 | a ≠ b ≠ c | α ≠ β ≠ γ ≠ 90° |

## 二、考纲对应
- [[16-晶体基本概念]]：晶胞参数的物理含义与测定

## 三、核心原理
### 晶胞参数的完整描述（§13.2）
六面体晶胞由六个参数完全确定：
- **边长** $a, b, c$：三个周期方向的重复距离
- **夹角**：$\alpha = b \wedge c$（$b$ 轴与 $c$ 轴的夹角），$\beta = c \wedge a$（$c$ 轴与 $a$ 轴的夹角），$\gamma = a \wedge b$（$a$ 轴与 $b$ 轴的夹角）

### X 射线衍射测定晶格常数——Bragg 方程
晶面间距 $d$ 与晶格常数直接相关。Bragg 方程：

$$2d\sin\theta = n\lambda$$

- $\theta$：衍射角（由实验测得）
- $\lambda$：X 射线波长（已知）
- $n$：衍射级数（整数）
- $d$：晶面间距（可由此推导 $a, b, c$）

### 实例数据
- Cu（面心立方）：$a=b=c=0.356\,\mathrm{nm}=356\,\mathrm{pm}$
- Na（体心立方）：由 $r=(\sqrt{3}/4)a$ 关系测定
- Po（简单立方）：$a=2r$

## 四、关键结论
- 晶格常数不仅决定晶胞大小，还与**原子/离子半径**直接关联
- 对于立方晶系，$a$ 和 $r$ 的关系：
  - 简单立方：$a=2r$
  - 体心立方：$r=\sqrt{3}a/4\qquad a=4r/\sqrt{3}$
  - 面心立方：$a=2\sqrt{2}r\qquad r=\sqrt{2}a/4$
- 三方晶系有两种取法：简单三方（$a=b\neq c,\gamma=120^\circ$）和菱面体（$a=b=c,\alpha=\beta=\gamma\neq90^\circ$），两者等价
- 六方密堆积的理想轴比：$c/a = \sqrt{8/3} \approx 1.633$（实际金属常偏离此值）

## 六、适用条件与限制
- 晶胞参数的选取必须符合对称性要求（如表 13.1 所列）
- 单凭 $a=b=c,\ \alpha=\beta=\gamma=90^\circ$ 不足以判定立方晶系——必须检查是否存在 4 个沿体对角线的三重轴
- X 射线波长 $\lambda$ 的数量级应与待测晶面间距 $d$ 相当（$10^{-10}\,\mathrm{m}$ 量级）

## 七、常见比较与易混点
- **晶胞参数 vs 原子间距**：晶胞参数是重复周期（宏观），原子间距是两相邻原子核间距离的一半（原子半径定义）
- **三方晶系的两种表述**等价——仅取法不同
- 七大晶系的"对称性要求"是高于"几何关系"的判据——先看对称元素，再看几何参数

## 十二、🎯 教学视角

### 学习路径建议

**前置知识**：晶体基本概念、七大晶系、X射线衍射基础。

**推荐教学顺序**：
1. 回顾晶胞参数（a, b, c, α, β, γ）→ 引出"晶格常数就是晶胞的尺寸和角度"
2. 七大晶系的参数特征表 → 记忆口诀："三斜最自由，立方最规矩"
3. Bragg 方程 2d sinθ = nλ → 晶格常数如何通过衍射实验测定
4. a 与原子半径 r 的关系：sc(a=2r), bcc(a=4r/√3), fcc(a=4r/√2) → 竞赛高频考点
5. 六方最密堆积的 c/a 理想值 1.633 → 实际偏差反映层间作用力

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "a, b, c 就是三个边长" | a, b, c 是晶胞基矢的长度，不一定相互垂直（只有立方晶系才两两垂直） | "矢量长度非边长，角度说了才算数" |
| "Bragg 方程中的 d 是晶胞边长" | d 是晶面间距，与晶胞参数和 Miller 指数有关（立方晶系：d = a/√(h²+k²+l²)） | "d 是面间距，a 是边长，别搞混" |
| "hcp 的 c/a 一定是 1.633" | 1.633 是理想值，实际金属常偏离（如 Cd 的 c/a = 1.886，说明沿 c 轴拉长了） | "理想1.633，实际常偏离" |

### 入门级例题

**例题**：铜的 fcc 晶胞参数 a = 361.5 pm。(1) 求 Cu 的原子半径；(2) 求(111)面间距。

**引导思路**：
1. FCC 中 a = 4r/√2 → r = a√2/4 = 361.5 × 1.414 / 4 = 127.8 pm
2. 立方晶系 d(hkl) = a/√(h²+k²+l²) → d(111) = 361.5/√3 = 208.7 pm

### 与真实世界的联系

- **宝石鉴定**：钻石的晶格常数 a = 356.7 pm 是鉴定天然 vs 合成钻石的参数之一
- **半导体工业**：硅的晶格常数 a = 543.1 pm 决定了芯片上能刻多细的线 → 摩尔定律的物理极限之一
- **热膨胀监测**：晶格常数随温度变化（热膨胀），高精度衍射可测量 pm 级的长度变化
- 主要来源：[[提炼-普化原理-第13章-晶体与晶体结构]]（《普通化学原理 第4版》第 13 章），§13.2 表 13.1
- Bragg 方程及推导：§13.2 图 13.4 及公式 $2d\sin\theta=n\lambda$
- 金属 Cu 晶胞参数实例：§13.4.1 例 13.1（$a=0.356\,\mathrm{nm}$）
