# 碱金属和碱土金属

## 核心概念

### 碱金属通性（Li, Na, K, Rb, Cs）
- **原子半径**：沿Li→Cs顺序递增
- **熔沸点**：沿Li→Cs顺序递减，Li最高
- **密度**：Li<Na<K出现反常（Li=0.57g/cm³为最小固体密度），原因：体积增大效应在K处超过原子量增大效应
- **硬度**：沿Li→Cs顺序递减
- **电极电势**：E⊖(M⁺/M)均为负值，Li最负（-3.04V），因水合焓异常大补偿了高升华焓和电离能
- **晶体结构**：均为体心立方(bcp/bcc)，配位数8，空间利用率68%

### 锂的特殊性（"锂的罪状"）
- 硝酸盐分解生成Li₂O（其他碱金属生成MNO₂）
- 燃烧生成Li₂O（Na生成Na₂O₂，K/Rb/Cs生成MO₂超氧化物）
- 室温下与N₂反应生成Li₃N，不能用N₂作保护气
- 易形成共价键（有机锂试剂如丁基锂）
- 难溶盐：LiF、Li₂CO₃、Li₃PO₄
- LiOH为弱碱（pKb≈0.2），其他MOH为强碱
- 性质与IIA族Mg更相似（对角线规则）

### 碱土金属通性（Be, Mg, Ca, Sr, Ba）
- **原子半径**：沿Be→Ba顺序递增
- **熔沸点**：Be显著高于其他（非典型金属键）
- **密度**：Ca为碱土金属中最小
- **电离能**：第一电离能按Be→Ba递减
- **焰色**：Be/Mg无焰色，Ca砖红色，Sr鲜红色，Ba黄绿色
- **晶体结构**：Mg为hcp，Ca/Sr为fcc，Ba为bcc

### 铍的特殊性（对角线规则-与Al相似）
- Be²⁺半径极小，电荷密度极大
- 空气中不活泼（氧化膜保护），与热水不反应，与酸反应缓慢，可溶于碱
- 氧化物和氢氧化物呈两性（碱土金属中唯一）
- 碳化物水解生成甲烷（类似Al₄C₃）
- 缺电子化合物，易形成共价键和配合物

## 关键反应

### 碱金属反应
- 锂与水：Li + H₂O → LiOH + H₂↑（温和反应，因熔点高不易熔化）
- 锂的氧化链：Li → Li₂O → LiOH → LiOH·H₂O → Li₂CO₃
- 钠与钾制备：
  - Na：电解NaCl-CaCl₂(40%:60%)混合熔融物
  - K：Na还原熔融KCl（利用沸点差异，NaCl晶格能更高）
- 氢化物还原性：
  - 9NaH + TiCl₄ →[400℃] NaCl + Ti + H₂↑
  - 6NaH + 2BF₃ →[200℃] B₂H₆ + 6NaF
  - 2NaH + 2SO₂ → Na₂S₂O₄ + H₂↑
- 叠氮化物：RCOCl + NaN₃ → RCON₃ → RNCO（Wolff重排）
- 锂离子鉴定：Fe(OH)₃ + KIO₄ → [Fe(IO₆)]³⁻ + Li⁺ → Li₃[Fe(IO₆)]↓（黄色）

### 碱土金属反应
- 氢化铍制备：
  - BeCl₂ + 2NaBHEt₃ → Be(BH₄)₂ →[分解] BeH₂
- 氯化铍水解：BeCl₂ + H₂O → Be(OH)₂ + HCl（极易水解）
- 氧化铍：两性氧化物，既溶于酸也溶于碱
- 镁与氮气：3Mg + N₂ →[800℃] Mg₃N₂
- 钙/锶/钡与水：M + 2H₂O → M(OH)₂ + H₂↑
- 氢化钙应用：CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂↑（野外制氢）
- 铝热法制备：3CaO + 2Al → 3Ca + Al₂O₃

## 规律与趋势

### 周期律
- 碱金属：原子半径↑，电离能↓，电负性↓，金属性↑
- 碱土金属：原子半径↑，电离能↓，金属性↑
- 电极电势：整体趋势越来越负（还原性增强）

### 对角线规则
- Li-Mg、Be-Al、B-Si性质相似
- Be与Al：两性氧化物/氢氧化物，碳化物水解生成甲烷

### 溶解度规律
- 碱土金属硫酸盐：Ca²⁺ > Sr²⁺ > Ba²⁺（例外：氢氧化物Ba(OH)₂ > Ca(OH)₂）
- 温度效应：Mg(OH)₂和Ca(OH)₂溶解度随温度升高而降低

### 氢化物稳定性
- 碱金属：LiH最稳定（可在700-800℃保持稳定）
- 碱土金属：CaH₂ > SrH₂ > BaH₂

## 典型应用

### 竞赛重点
1. **锂的特殊性判断**：燃烧产物、与N₂反应、难溶盐识别
2. **电极电势异常**：Li最负因水合焓补偿（热力学循环分析）
3. **铍的对角线规则**：与Al的相似性（两性、共价性、碳化物水解）
4. **石墨插层化合物**：KC₈结构（一层石墨一层钾交替，四种K层a/b/c/d）
5. **离子鉴定**：Na⁺用六硝基合钴(III)酸钠，K⁺用六硝基合钴(III)酸钾
6. **氢化物应用**：CaH₂野外制氢，LiH分离Na/K

### 工业应用
- 氯碱工业：电解食盐水生产NaOH和Cl₂
- 碱金属制备：Na电解法，K钠还原法
- 锂提取：硫酸盐转化法、氧化物烧结法
