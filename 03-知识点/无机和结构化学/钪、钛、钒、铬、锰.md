# 铜族与锌族元素化学

> **说明**：笔记原始文件名为"钪、钛、钒、铬、锰"，但实际内容覆盖铜族（Cu、Ag、Au）、锌族（Zn、Cd、Hg）及钪（Sc）简介。本知识点按实际内容整理。

---

## 一、铜族元素（IB族：Cu、Ag、Au）

### 1. 铜的化合物

#### 1.1 氢氧化铜 Cu(OH)₂

**制备**（避免直接强碱与 Cu²⁺ 反应，防止多聚离子或碱式盐）：
- 标准法：先用氨水生成 $[\text{Cu(NH}_3)_4]^{2+}$，再加强碱得纯净 Cu(OH)₂ 沉淀
- 替代法：硫酸铜氨水溶液中加少量酸除氨

**性质**：
- 碱性氢氧化物，$K_{sp} = 5 \times 10^{-19}$
- 两性：可溶于极浓 KOH/NaOH（>6M），加热促进溶解
- 特殊溶剂：氨水（铜氨配合物）、甘油/水杨酸/酒石酸

**斐林试剂**：Cu²⁺ 与酒石酸根配位形成深蓝色配合物 $[\text{Cu(C}_4\text{H}_2\text{O}_6)]^{2-}$

**波尔多液**：CuSO₄ : Ca(OH)₂ = 1:1（质量比），有效成分为未反应的 CuSO₄ 和 Cu(OH)₂ 悬浮颗粒

#### 1.2 氧化铜 CuO

- 碱性氧化物，易溶于酸，可溶于浓碱
- 制备：铜在空气中加热至 800-1000°C
- 天然存在：黑铜矿

#### 1.3 硫化铜 CuS

- 黑色晶体，$K_{sp} = 10^{-36}$（极难溶）
- 制备：$\text{Cu}^{2+} + \text{H}_2\text{S} \rightarrow \text{CuS} \downarrow + 2\text{H}^+$
- 天然矿物：铜蓝（covellite），纯品黑色，天然蓝色（杂质致色）

**特殊结构**（重要考点）：
- 表观式 CuS 中 Cu²⁺ 与 S²⁻ 存在氧化还原倾向
- 实际结构含 S₂²⁻ 多硫离子稳定体系
- 真实化学式：$\text{Cu}_4^{(1)}\text{Cu}_2^{(2)}(\text{S}_2)_2\text{S}_2$
- 1/3 铜为三角平面配位（sp²），2/3 铜为四面体配位（sp³）
- 硫：四配位（二硫键）或五配位（单硫）

**溶解性**：
- 不溶于水和非氧化性酸
- 氧化剂存在时可溶（如 FeCl₃）
- 配位剂存在时可溶：$2\text{CuS} + 10\text{CN}^- \rightarrow 2[\text{Cu(CN)}_4]^{3-} + 2\text{S}^{2-} + (\text{CN})_2$

#### 1.4 碳酸铜化合物

- 纯 CuCO₃ **尚未制备出**，实际以碱式碳酸铜形式存在
- **孔雀石**（铜绿）：CuCO₃·Cu(OH)₂，亮绿色
- **石青**：2CuCO₃·Cu(OH)₂，蓝色
- 石青制备：$3\text{CuSO}_4 + 2\text{CaCO}_3 + \text{H}_2\text{O} \rightarrow \text{Cu}_3(\text{CO}_3)_2(\text{OH})_2 + 3\text{CaSO}_4 + \text{CO}_2$

#### 1.5 醋酸铜

- 一水合醋酸铜为二聚体结构
- 每个铜八配位，醋酸根为桥连配体（linker）
- Cu-Cu 键距 264 pm（金属铜中 255 pm），存在较强 Cu-Cu 相互作用
- 本质应理解为配合物

### 2. 铜的配合物

#### 2.1 二价铜配合物

- 电子构型：Cu²⁺ 为 d⁹
- 四配位：dsp² 杂化 → 平面四边形（与一价铜 d¹⁰ 四面体显著不同）
- 六配位：姜-泰勒畸变 → dsp² + 两个远距离配体

**典型配合物**：
- 单齿氮配体：$[\text{Cu(NH}_3)_4]^{2+}$（四氨合铜）
- 双齿氮配体：$[\text{Cu(en)}_2]^{2+}$（平面四边形）、$[\text{Cu(en)}_3]^{2+}$（八面体）
- 联吡啶(bipy)：五配位三角双锥

#### 2.2 空间位阻效应

- 氮配体带甲基取代基时，立体阻碍迫使平面四边形 → 四面体转化

#### 2.3 多核配合物

- 乙二胺衍生物可通过氧桥形成二聚体 $[\text{Cu}_2(\text{OH})_2(\text{en})_2]^{2+}$
- 五配位结构在铜配合物中较常见

## 二、银的性质

### 1. 银的矿物与制备

**矿物**：
- 辉银矿 Ag₂S、硒化银 Ag₂Se、硫铜银矿 CuAgS、角银矿 AgCl
- 名称含"辉"字的矿物必定含硫

**氰化法提取**（考试热点）：
- $\text{Ag}_2\text{S} / \text{AgCl} \xrightarrow{\text{NaCN}} [\text{Ag(CN)}_2]^-$（直线型）
- 锌粉还原：$[\text{Ag(CN)}_2]^- + \text{Zn} \rightarrow \text{Ag} + [\text{Zn(CN)}_4]^{2-}$
- 硫化银是所有银盐中溶解度最小的，需高浓度氰根离子才能溶解
- 涉及氧化还原平衡与配位平衡的耦合计算（2010 决赛真题）

### 2. 银单质性质

- 晶体结构：立方最密堆积（CCP）
- 导电性、导热性在所有金属中最强
- 室温不与 O₂ 反应；加热可被 O₃ 氧化：$\text{Ag} + \text{O}_3 \rightarrow \text{AgO}$

**亲硫特性**：比与氧反应更容易
- 加热直接与硫化合
- 室温含 O₂ 的 H₂S 溶液中生成 Ag₂S

**酸溶解**：
- 不溶于水和弱酸
- 浓 H₂SO₄（热）：生成 Ag₂SO₄
- 浓 HNO₃：生成 NO₂ + AgNO₃
- 稀 HNO₃：生成 NO + AgNO₃

### 3. 银的化合物

**价态稳定性**：Ag⁺ 比 Ag²⁺ 稳定（与铜相反）
- 原因：银原子半径大于铜，二价银水合能不足

**可溶盐**：AgNO₃、AgClO₃、AgClO₄
**难溶盐**：Ag₂SO₄、AgCH₃COO、卤化银（除 AgF 外）

#### 氧化银 Ag₂O

- 制备：AgNO₃ + NaOH → 棕黑色 Ag₂O
- 催化 H₂O₂ 分解：$\text{Ag}_2\text{O} + \text{H}_2\text{O}_2 \rightarrow \text{O}_2 + \text{Ag}$
- 可溶于碳酸铵（形成 $[\text{Ag(NH}_3)_2]^+$）、氰化钾（形成 $[\text{Ag(CN)}_2]^-$）

#### 氢氧化银 AgOH

- 需低于 -45°C 低温制备（90% 酒精溶液 NaOH + AgNO₃）
- 常温立即失水转化为 Ag₂O
- 两性：碱性悬浮于水；可溶于浓强碱形成银酸盐

#### 硫化银 Ag₂S

- 制备：$4\text{Ag}_2\text{O} + 4\text{S} \rightarrow 3\text{Ag}_2\text{S} + \text{Ag}_2\text{SO}_4$
- 硫代硫酸银分解：$\text{Ag}_2\text{O} + \text{S}_2\text{O}_3^{2-} \rightarrow \text{Ag}_2\text{S} + \text{SO}_4^{2-}$
- 可溶于硝酸或王水（氧化溶解）、浓氰化物（配位溶解）

#### 草酸银 Ag₂C₂O₄

- 分解直接生成 Ag + CO₂（不同于多数草酸盐）
- 链状聚合物结构（sp 杂化二配位）
- **具有爆炸性**（重要考点）

#### 二价银化合物

- AgO 实际为 Ag₂O 和 Ag₂O₃ 混合物（混合价态，非纯二价）
- 抗磁性证明非纯二价（纯 d⁹ 应顺磁性）
- 催化机理：Ag⁺ → Ag²⁺ → Ag⁺ 构成催化循环

### 4. 银的配合物

**配位数与杂化**：
- 二配位：sp 杂化（线性）
- 三配位：sp² 杂化（平面三角形）
- 四配位：sp³ 杂化（四面体）

**硫脲配合物**（提取银、金的重要方法）：
- 1:1 型、1:2 型（sp² 平面三角形）、1:3 型（sp³ 四面体）
- 硫脲中仅 S 原子参与配位

## 三、金的性质

### 1. 矿物与制备

- 天然金矿、碲金矿（AuTe₂），常与 Te 伴生
- 氰化法提取（同银）
- 替代：硫脲法（毒性低，对 Cu、Ag、Au 均有效）

### 2. 金单质性质

- 金黄色（颜色命名标准）
- 化学惰性极强，仅溶于：王水、有氧 NaCN、有氧硫脲、热浓硒酸
- 常见价态：+3 最稳定，+1 存在但不常见
- Au⁺ 可歧化为 Au⁰ 和 Au³⁺（类似 Cu⁺）

### 3. 金的化合物

#### 三氟化金 AuF₃

- 热稳定性差，500°C 分解
- 结构：四配位平面正方形通过 F 桥连形成无限螺旋链，六方晶系
- 强氟化剂和氧化剂，良好氟受体（路易斯酸）

#### 三氯化金 AuCl₃

- 红色结晶，共价化合物 Au₂Cl₆
- 所有原子共平面，两种 Au-Cl 键长
- 溶于盐酸或王水生成 $[\text{AuCl}_4]^-$
- dsp² 杂化，四配位平面正方形

### 4. 金的配合物

**一价金**：
- 二配位：直线型（sp 杂化）
- 四配位：平面正方形（dsp²），空间位阻大时可为四面体

**三价金**：
- 四配位：平面正方形
- 六配位：d²sp³ 杂化
- 存在五配位化合物（变形三角双锥）

## 四、锌族元素（IIB族：Zn、Cd、Hg）

### 1. 锌的性质

#### 矿物
- 菱锌矿 ZnCO₃、闪锌矿 β-ZnS（立方）、纤锌矿 α-ZnS（六方）
- 硅锌矿 Zn₂SiO₄、红锌矿 ZnO

#### 制备
- 焙烧转化为 ZnO，再用焦炭或 CO 还原：$\text{ZnO} + \text{C} \rightarrow \text{Zn} + \text{CO}$

#### 单质性质
- hcp 结构，c/a = 1.856（存在畸变）
- 干燥空气中 200°C 以上被氧化
- 潮湿含 CO₂ 空气中形成碱式碳酸锌保护膜
- **两性特征**：
  - 溶于碱：$\text{Zn} + 2\text{OH}^- + 2\text{H}_2\text{O} \rightarrow [\text{Zn(OH)}_4]^{2-} + \text{H}_2\uparrow$
  - 溶于氨水：$\text{Zn} + 4\text{NH}_3 + 2\text{H}_2\text{O} \rightarrow [\text{Zn(NH}_3)_4]^{2+} + \text{H}_2\uparrow + 2\text{OH}^-$

#### 锌的定性分析

**Fe³⁺/I⁻ 体系**：
- $\text{Fe}^{3+} + \text{I}^- \rightleftharpoons \text{Fe}^{2+} + \frac{1}{2}\text{I}_2$，pH=10 附近为主反应
- 配位平衡影响：$[\text{Fe(CN)}_6]^{3-}$ 使 Fe³⁺/Fe²⁺ 电位降低，氧化能力反转
- 沉淀平衡影响：Zn(OH)₂ 沉淀使平衡右移

**锌的检验**：
- 赤血盐反应：黄色赤血盐 + Zn²⁺ → 白色沉淀（Zn₃[Fe(CN)₆]₂ 或 Zn₂Fe(CN)₆）
- 硫氰酸汞反应：蓝色/紫色配合物

#### 锌的化合物

**二卤化锌**：
- ZnF₂：金红石型离子晶体，其他卤化物共价性明显
- 仅 ZnF₂ 能形成水合物（具荧光特性）
- ZnF₂ + H₂O → Zn(OH)F → ZnO

**氯化锌 ZnCl₂**：
- 固态共价性盐，熔融自偶电离：$2\text{ZnCl}_2 \rightleftharpoons \text{Zn}^{2+} + \text{ZnCl}_3^- + \text{ZnCl}_4^{2-}$
- 稀溶液（<1M）完全电离；浓溶液存在未解离 ZnCl₂ 和 ZnCl₃⁻
- 6M 溶液 pH≈1，所有盐类中溶解度最高
- 工业应用：除锈、干燥剂

**氧化锌 ZnO**：
- 室温白色（"锌白"），加热变黄（荷移跃迁吸收光谱带移至紫色区），可逆
- 半导体特性，颜色变化与能带结构相关
- 两性：酸溶/碱溶/氨溶
- 锌酸根可能为三配位或四配位，具体结构未完全确定
- 固体：NaZn(OH)₃·3H₂O、Na₂Zn(OH)₄、Ba₂[Zn(OH)₆]

**硫化锌 ZnS**：
- 闪锌矿和纤锌矿两种结构（结构化学重要范例）
- 难溶于水，可溶于稀酸
- 立德粉/锌钡白：ZnS + BaSO₄ 混合物，白色颜料
- 铁酸锌 ZnFe₂O₄：尖晶石结构，Zn²⁺ 占四面体空隙，Fe³⁺ 占八面体空隙

**锌有机化合物**：
- 二甲基锌：直线型分子，sp 杂化
- 乙酰丙酮锌：三聚体，含 5 配位和 6 配位锌原子混合结构

### 2. 锌族元素通性

- 金属性显著弱于碱土金属（ns² 电子构型相似）
- 共价键趋势强（极化率 > Mg、Ca）
- 通常形成 +2 价化合物
- Hg 可形成 +1 价化合物（Hg₂²⁺ 形式）

### 3. 镉的性质

- 银白色金属，hcp 结构
- 潮湿空气中缓慢氧化为棕色 CdO
- **不与 NaOH 反应**（区别于锌）
- 二价镉化合物**毒性极强**，实验废液需专门回收

#### 镉的化合物

**卤化物**：
- CdF₂：标准萤石结构
- CdCl₂：层状化合物（类似 MgCl₂）
- CdI₂：hcp 结构，共价性较强的层状化合物

**氢氧化物**：碱性氢氧化物（碱性强于 Zn(OH)₂），不具两性

**硫化物 CdS**：
- 比 ZnS 更难溶，仅溶于浓盐酸
- 镉盐 + S²⁻ → 柠檬黄色；长时间 → 橙黄色

### 4. 汞的性质

> 详细内容见 [[汞]] 知识点，以下仅补充笔记中的关键要点。

#### 单质性质

- 常温唯一液态金属（m.p. = -38.7°C）
- 6s² 惰性电子对效应显著，第一电离能居所有金属之首
- 与 H₂SO₄（中等浓度以上）反应生成 Hg₂²⁺ 和 H₂
- 350°C 与 O₂ 生成 HgO，400°C 以上分解

#### 汞的价态

- Hg₂²⁺（亚汞离子）：含 Hg-Hg 键，直线型结构
- Hg²⁺（二价汞）：稳定价态
- 锌镉汞中**唯一常见 +1 价**的元素

#### 甘汞 Hg₂Cl₂

- 气态：直线型 Cl-Hg-Hg-Cl（sp 杂化）
- 固态：链状单元通过次级键形成畸变八面体配位
- 链内 Hg-Cl 键长 252 pm，链间 318 pm
- 光解：$\text{Hg}_2\text{Cl}_2 \xrightarrow{h\nu} \text{Hg} + \text{HgCl}_2$
- 制备：$2\text{HgCl}_2 + \text{SO}_2 + 2\text{H}_2\text{O} \rightarrow \text{Hg}_2\text{Cl}_2\downarrow + \text{H}_2\text{SO}_4 + 2\text{HCl}$

#### 二价汞化合物

**Hg²⁺ 离子特性**：
- 半径 93 pm，极化能力显著强于 Ca²⁺（106 pm）
- 仅与高电负性基团（F⁻、NO₃⁻、ClO₄⁻）形成偏离子性化合物
- HgCl₂ 溶于水时 99% 以上以分子形式存在

**氯化汞 HgCl₂**（升汞）：
- 制备：汞与卤素直接化合、HCl + HgO、300°C 以下盐类卤代
- 强共价化合物，有机溶剂溶解性好
- 与碱反应：过量碱生成 HgO；少量碱生成 Hg(OH)Cl
- 与 NH₃ 反应产物多样：HgCl₂·NH₃、Hg(NH₂)Cl、Hg₂NCl·H₂O

**氧化汞 HgO**：
- 黄色和红色两种形态（与晶型有关）
- 强氧化性：氧化 SO₂ → SO₃、H₃PO₃ → H₃PO₄、As₂O₃ → As₂O₅

**硫化汞 HgS**：
- $K_{sp} = 10^{-54}$（极难溶）
- 仅溶于王水、浓 HBr、浓 HI、硫化物溶液
- 王水溶解原理：Cl⁻ 形成 $[\text{HgCl}_4]^{2-}$ + 强氧化性打破平衡
- 红色朱砂（稳定相）：畸变 NaCl 型晶格，立方晶系
- 黑色变体（亚稳态）：Hg²⁺ 与 S²⁻ 直接反应生成

#### 汞的有机化合物

- 二甲基汞 HgMe₂：直线型，sp 杂化
- 甲基化试剂，羟汞化反应
- **剧毒性**，实验室需严格防护

## 五、钪（Sc）简介

- 命名来源：斯堪的纳维亚半岛（Scandinavia）
- 主要存在形式：Sc₂O₃
- 钇钪矿：(Sc,Y,RE)₂Si₂O₇，含 Sc₂O₃ 约 33.8%-42.3%
- 水磷钪矿：ScPO₄·2H₂O
- 钪呈 +3 价，自然界分布较少

## 六、规律与趋势

### IIB 族趋势（Zn → Cd → Hg）

| 性质 | Zn | Cd | Hg |
|------|----|----|-----|
| 熔点 | 419.5°C | 321.1°C | -38.7°C |
| 金属性 | 最强 | 中等 | 最弱 |
| 与稀酸 | 反应 | 较不活泼 | 不反应 |
| 与 NaOH | 反应 | **不反应** | 不反应 |
| 氢氧化物碱性 | 较弱 | **较强** | — |
| 硫化物 Ksp | 较大 | 中等 | **10⁻⁵⁴** |

### IB 族趋势（Cu → Ag → Au）

| 性质 | Cu | Ag | Au |
|------|-----|-----|-----|
| 稳定价态 | +2 | **+1** | **+3** |
| 导电性 | 强 | **最强** | 次于 Cu |
| 化学惰性 | 中等 | 较强 | **最强** |
| 配合物稳定性 | 强 | 较弱 | 强 |

### 惰性电子对效应

- Hg 的 6s² 电子对极稳定（相对论效应 + 镧系收缩）
- 导致 Hg 常温液态、高电离能、低金属性
- Au 的 6s² 也较稳定，使 +3 价成为最稳定价态

## 七、典型应用

### 竞赛中的典型应用

1. **CuS 的结构分析**：理解非常规价态组合和 S₂²⁻ 多硫离子的稳定作用
2. **氰化法提取金银**：氧化还原平衡与配位平衡的耦合计算
3. **姜-泰勒效应**：Cu²⁺ 配合物的 J-T 畸变分析

## 九、易错点

1. CuS 中并非简单的 Cu²⁺S²⁻，实际含 Cu⁺、Cu²⁺ 和 S₂²⁻
2. Ag⁺ 比 Ag²⁺ 稳定（与 Cu 相反），不可混淆
3. AgO 不是纯二价银化合物，而是 Ag₂O 和 Ag₂O₃ 的混合物
4. Cd(OH)₂ 碱性 > Zn(OH)₂，但 Cd 金属性 < Zn（看似矛盾）
5. Hg₂²⁺ 含 Hg-Hg 共价键，不是简单的 2Hg⁺
6. HgS 仅溶于王水，单独 HCl 不足以溶解（Kf 不足）
7. 草酸银具有爆炸性，分解直接生成 Ag + CO₂
8. CuCO₃ 无法单独制备，实际以碱式碳酸铜形式存在

### 15.3 入门级例题

**题目**：解释为什么Cu²⁺的配合物常呈蓝色。

**解答**：Cu²⁺是d⁹构型，在八面体场中发生Jahn-Teller畸变，d-d跃迁吸收橙色光，因此呈现互补色蓝色。

3. **电池技术**：锌是干电池的重要材料
