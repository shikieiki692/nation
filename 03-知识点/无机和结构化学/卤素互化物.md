# 卤素互化物

## 一、定义与分类

### 1.1 定义

卤素互化物（Interhalogen compounds）是由**两种不同卤素原子**形成的化合物，通式为 **XYₙ**，其中 X 是电负性较小的卤素（中心原子），Y 是电负性较大的卤素（配体原子）。

### 1.2 分类

| 类型 | 通式 | 配位数 | 几何构型 | 示例 |
|------|------|--------|----------|------|
| 二原子 | XY | 1 | 直线形 | ClF, BrF, ICl, IBr |
| 四原子 | XY₃ | 3 | T形 | ClF₃, BrF₃, IF₃ |
| 六原子 | XY₅ | 5 | 四方锥 | ClF₅, BrF₅, IF₅ |
| 八原子 | XY₇ | 7 | 五方双锥 | IF₇ |

### 1.3 稳定性规律

- **中心原子越大越稳定：** I的化合物最稳定，F的化合物最不稳定
- **配体越多越不稳定：** XY > XY₃ > XY₅ > XY₇（热力学稳定性递减）
- **原因：** 配体越多，空间位阻越大，Y–X–Y排斥越强

---

## 二、命名规则

### 2.1 基本规则

- 电负性小的卤素（中心原子）在前，电负性大的卤素（配体）在后
- 命名格式："某化某"或"一某化某"

### 2.2 具体命名

| 化学式 | 中文名 | 英文名 |
|--------|--------|--------|
| ClF | 一氟化氯 | Chlorine monofluoride |
| ClF₃ | 三氟化氯 | Chlorine trifluoride |
| BrF₅ | 五氟化溴 | Bromine pentafluoride |
| IF₇ | 七氟化碘 | Iodine heptafluoride |
| ICl | 一氯化碘 | Iodine monochloride |
| ICl₃ | 三氯化碘 | Iodine trichloride |

### 2.3 注意事项

- ICl而非ClI：碘电负性(2.66) < 氯(3.16)，碘为中心原子
- IBr而非BrI：碘电负性(2.66) < 溴(2.96)，碘为中心原子

## 三、VSEPR构型预测

### 3.1 价层电子对计算

对于XYₙ型卤素互化物：
- 中心原子X的价电子数：7（VIIA族）
- 配体Y提供的电子数：n × 1（每个Y提供1个电子成键）
- 总价层电子数：7 + n
- 成键电子对数：n
- 孤对电子数：(7 + n)/2 - n = (7 - n)/2

### 3.2 各类型VSEPR构型

**XY型（ClF, BrF, ICl, IBr）：**
- 电子对数：2（1个成键对 + 1个孤对？不对）
- 实际：XY是直线形，因为只有一个σ键，没有孤对电子在中心原子上
- 但严格说，XY是双原子分子，没有键角概念

**XY₃型（ClF₃, BrF₃, IF₃）：**
- 中心原子X：7个价电子
- 3个Y提供3个电子
- 总电子数：10，5对电子
- 成键对：3，孤对：2
- VSEPR模型：三角双锥
- 孤对占据赤道位（排斥最小）
- **构型：T形**（键角略小于90°）

**XY₅型（ClF₅, BrF₅, IF₅）：**
- 中心原子X：7个价电子
- 5个Y提供5个电子
- 总电子数：12，6对电子
- 成键对：5，孤对：1
- VSEPR模型：正八面体
- 孤对占据一个顶点
- **构型：四方锥**（键角略小于90°）

**XY₇型（IF₇）：**
- 中心原子I：7个价电子
- 7个F提供7个电子
- 总电子数：14，7对电子
- 成键对：7，孤对：0
- VSEPR模型：五方双锥
- **构型：五方双锥**

## 四、典型化合物详解

### 4.1 ClF（一氟化氯）

- **分子式：** ClF
- **构型：** 直线形
- **键长：** Cl–F = 163 pm
- **键能：** Cl–F = 253 kJ/mol
- **性质：** 无色气体，活泼，是强氟化剂
- **制备：** Cl₂ + F₂ → 2ClF（控制条件）

### 4.2 BrF₃（三氟化溴）

- **分子式：** BrF₃
- **构型：** T形
- **键长：** Br–F = 170 pm（赤道位），181 pm（轴向位）
- **键角：** F(ax)–Br–F(ax) = 172°（略小于180°）
- **性质：** 无色至淡黄色液体，强氟化剂
- **自偶电离：** 2BrF₃ ⇌ BrF₂⁺ + BrF₄⁻
- **应用：** 用于铀浓缩（铀六氟化物的制备）

### 4.3 IF₅（五氟化碘）

- **分子式：** IF₅
- **构型：** 四方锥
- **键长：** I–F = 187 pm（赤道位），184 pm（轴向位）
- **键角：** F(ax)–I–F(eq) = 81.9°
- **性质：** 无色液体，与水剧烈反应
- **水解：** IF₅ + 3H₂O → HIO₃ + 5HF

### 4.4 IF₇（七氟化碘）

- **分子式：** IF₇
- **构型：** 五方双锥
- **键长：** I–F = 180–190 pm
- **性质：** 无色气体，不稳定
- **热稳定性：** 在室温下缓慢分解
- **特殊性：** 最高配位数的卤素互化物

## 五、ICl₃二聚体

### 5.1 结构特点

ICl₃在固态下以**二聚体I₂Cl₆**形式存在：

```
    Cl       Cl
     \     /
      I---I
     /     \
    Cl       Cl
```

- 两个ICl₃单元通过**桥联氯**连接
- 每个I原子与4个Cl原子成键（2个端基Cl，2个桥联Cl）
- I的配位数：4
- 构型：平面四边形（扭曲）

### 5.2 键参数

- I–Cl（端基）：238 pm
- I–Cl（桥联）：268 pm
- 桥联I–Cl–I键角：约83°

### 5.3 形成原因

- ICl₃单体中I的配位数为3，还有空余轨道
- 桥联形成可以降低体系能量
- 固态下以二聚体形式存在更稳定

---

## 六、多卤阴离子

### 6.1 三碘离子I₃⁻

- **构型：** 直线形（VSEPR：5对电子，3个成键对+2个孤对）
- **键长：** I–I = 290 pm（比I₂的267 pm长）
- **键级：** 约0.5（每个I–I键级）
- **稳定性：** I₂ + I⁻ ⇌ I₃⁻（平衡常数K ≈ 700）
- **应用：** 碘量法滴定中使用KI溶液溶解I₂

### 6.2 其他多卤阴离子

| 阴离子 | 构型 | 中心原子配位数 |
|--------|------|---------------|
| ClF₂⁻ | 直线形 | 2 |
| BrF₂⁻ | 直线形 | 2 |
| IF₂⁻ | 直线形 | 2 |
| ClF₄⁻ | 平面四方形 | 4 |
| BrF₄⁻ | 平面四方形 | 4 |
| IF₄⁻ | 平面四方形 | 4 |
| IF₆⁻ | 正八面体 | 6 |

### 6.3 形成规律

多卤阴离子的形成遵循Lewis酸碱理论：
- 卤素互化物XYₙ作为**Lewis酸**（接受电子对）
- 卤素离子Y⁻作为**Lewis碱**（提供电子对）
- 形成配位数增加的阴离子

$$XY_n + Y^- \rightarrow XY_{n+1}^-$$

---

## 七、多卤阳离子

### 7.1 常见多卤阳离子

| 阳离子 | 构型 | 说明 |
|--------|------|------|
| Cl₃⁺ | V形 | 最简单的多卤阳离子 |
| Br₃⁺ | V形 | 类似Cl₃⁺ |
| I₃⁺ | V形 | 类似Cl₃⁺ |
| ClF₂⁺ | V形 | ClF与F⁻受体反应 |
| BrF₂⁺ | V形 | BrF₃自偶电离产物 |
| IF₄⁺ | 变形四面体 | IF₅自偶电离产物 |

### 7.2 形成机制

多卤阳离子通常通过以下方式形成：
1. **自偶电离：** 如 2BrF₃ ⇌ BrF₂⁺ + BrF₄⁻
2. **与Lewis酸反应：** 如 ClF + SbF₅ → ClF₂⁺SbF₆⁻
3. **与强质子酸反应：** 如 IF₅ + 2HF → IF₆⁻ + H₂F⁺

### 7.3 稳定性

- 多卤阳离子通常在**强Lewis酸**存在下稳定
- 需要**弱配位阴离子**（如SbF₆⁻, AsF₆⁻）作为抗衡离子
- 在水溶液中不稳定，会水解

---

## 八、Lewis酸碱行为

### 8.1 作为Lewis酸

卤素互化物可以接受电子对，作为Lewis酸：

$$IF_5 + F^- \rightarrow IF_6^-$$

- IF₅中I的配位数：5
- IF₆⁻中I的配位数：6
- I的氧化态保持+5

### 8.2 作为Lewis碱

卤素互化物也可以提供电子对，作为Lewis碱：

$$BrF_3 + SbF_5 \rightarrow BrF_2^+ + SbF_6^-$$

- BrF₃中Br的孤对电子提供给SbF₅
- 形成BrF₂⁺阳离子

### 8.3 自偶电离

某些卤素互化物可以发生自偶电离：

$$2BrF_3 \rightleftharpoons BrF_2^+ + BrF_4^-$$

$$2IF_5 \rightleftharpoons IF_4^+ + IF_6^-$$

这种自偶电离类似于水的自偶电离，使得这些化合物可以作为离子溶剂。

## 九、制备方法

### 9.1 直接合成

最简单的方法是让两种卤素直接反应：

$$X_2 + nY_2 \rightarrow 2XY_n$$

**示例：**
- Cl₂ + F₂ → 2ClF（控制F₂过量）
- Cl₂ + 3F₂ → 2ClF₃（F₂过量）
- Br₂ + 5F₂ → 2BrF₅（F₂过量）

### 9.2 卤素间的转化

$$XY_n + Y_2 \rightarrow XY_{n+2}$$

**示例：**
- ClF + F₂ → ClF₃
- BrF₃ + F₂ → BrF₅

### 9.3 注意事项

- 反应条件（温度、压力、比例）影响产物
- F₂过量有利于生成高配位数产物
- 需要特殊设备（因产物腐蚀性强）

## 十、例题与应用

### 例题1：VSEPR构型预测

**题目：** 预测BrF₃的分子构型和键角。

**解答：**
- Br的价电子数：7
- 3个F提供3个电子
- 总电子数：10，5对电子
- 成键对：3，孤对：2
- VSEPR模型：三角双锥
- 孤对占据赤道位（排斥最小）
- **构型：T形**
- **键角：** F(ax)–Br–F(ax) ≈ 172°（略小于180°）

### 例题2：Lewis酸碱反应

**题目：** 写出IF₅与F⁻反应的方程式，并解释产物的构型。

**解答：**
$$IF_5 + F^- \rightarrow IF_6^-$$

- IF₅中I的配位数：5（四方锥）
- IF₆⁻中I的配位数：6（正八面体）
- I的氧化态保持+5
- 反应是Lewis酸碱加成

### 例题3：自偶电离

**题目：** 解释BrF₃的自偶电离，并说明其作为离子溶剂的应用。

**解答：**
$$2BrF_3 \rightleftharpoons BrF_2^+ + BrF_4^-$$

- BrF₂⁺：V形阳离子（Br的配位数2）
- BrF₄⁻：平面四方形阴离子（Br的配位数4）
- 类似于水的自偶电离：2H₂O ⇌ H₃O⁺ + OH⁻
- BrF₃可以溶解离子化合物，用于研究无水体系中的离子反应

## 十一、易错点

1. **命名顺序错误：** 电负性小的卤素在前，不是任意顺序。ICl而非ClI。

2. **构型预测错误：** XY₃不是平面三角形，而是T形（因为有2对孤对电子）。

3. **键角理解错误：** T形分子中，轴向F–X–F键角略小于180°，不是恰好180°。

4. **ICl₃的结构：** 固态下以二聚体I₂Cl₆形式存在，不是单体ICl₃。

5. **多卤阴离子的形成：** 需要Lewis酸碱理论解释，不是简单的"加成"。

## 十二、竞赛拓展

### 12.1 超价分子的成键

卤素互化物是超价分子的典型例子。传统价键理论需要引入d轨道参与成键，但现代计算化学表明，d轨道的贡献很小，主要靠多中心键和离子性解释。

### 12.2 卤素互化物的反应性

- **氟化反应：** 卤素互化物是强氟化剂，可以将金属转化为氟化物
- **氧化反应：** 可以氧化有机物，用于有机合成
- **水解反应：** 与水剧烈反应，生成含氧酸和HF

### 12.3 实际应用

- **铀浓缩：** BrF₃用于制备UF₆（气体扩散法）
- **半导体工业：** 用于刻蚀和清洗
- **有机合成：** 作为氟化试剂

### 12.4 结构化学意义

卤素互化物是理解VSEPR理论、超价分子成键、Lewis酸碱理论的重要模型体系。它们的结构多样性（从直线形到五方双锥）展示了主族元素成键的丰富性。

## §12 教学视角

### 常见误解

| 误解 | 正确理解 |
|------|----------|
| "XY₃是平面三角形" | XY₃是T形（有2对孤对电子占据赤道位） |
| "ICl₃是单体" | 固态下以二聚体I₂Cl₆形式存在 |
| "多卤阴离子是简单的加合物" | 需要用Lewis酸碱理论解释，中心原子氧化态不变 |
| "卤素互化物很稳定" | 稳定性随配位数增加而降低，IF₇在室温下分解 |

### 典型例题（教学版）

**题目：** 预测ClF₃的分子构型，并解释为什么键角不是恰好90°和180°。

**教学解析：**
1. **VSEPR分析：**
   - Cl的价电子数：7
   - 3个F提供3个电子
   - 总电子数：10，5对电子
   - 成键对：3，孤对：2
   - VSEPR模型：三角双锥

2. **孤对电子排布：**
   - 孤对占据赤道位（排斥最小）
   - 2个孤对在赤道位，1个成键对在赤道位
   - 2个成键对在轴向位

3. **键角解释：**
   - 轴向F–Cl–F：理论180°，实际172°（被赤道孤对电子压缩）
   - 赤道F–Cl–轴向F：理论90°，实际87.5°（被孤对电子排斥）

**类比：** 卤素互化物就像"变形金刚"——虽然看起来是"超价"的（中心原子价电子数超过8），但实际上可以通过VSEPR理论预测其结构。这个类比帮助学生理解"超价"分子并不神秘。

### 教学建议

1. **从VSEPR理论出发：** 先复习VSEPR理论的基本规则，再应用于卤素互化物。

2. **用具体例子教学：** 用ClF₃作为典型例子，详细分析其VSEPR构型和键角。

3. **强调命名规则：** 让学生记住"电负性小的在前"的规则，避免命名错误。

4. **引入Lewis酸碱概念：** 用卤素互化物的反应展示Lewis酸碱理论的应用。

5. **讨论实际应用：** 介绍卤素互化物在工业和科研中的应用，激发学生兴趣。
