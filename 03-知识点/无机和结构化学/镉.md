# 镉

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]

## 一、概述

- 镉（Cd，Z = 48）位于锌副族（IIB）中部，**最常见且几乎唯一的氧化态是 +2**
- 在基础层，镉主要通过 Zn → Cd → Hg 纵向递变出现——三元素构成 ds 区"d¹⁰s²"家族的完整链条

**元素速查**：相对原子质量 112.4；电子构型 [Kr]4d¹⁰5s²（d 轨道全满，故化学上更像主族金属而非典型过渡金属）；常见价态 +2（+1 仅在 Cd₂²⁺ 等少数簇中存在且不稳定）；电负性 1.69；第一电离能 868 kJ/mol。

**"不像过渡金属"的原因**：d¹⁰ 全满 + s² 电子对使 Cd 无法利用 d 电子成键——无变价（只有 +2）、无 d-d 颜色（Cd²⁺ 无色）、无磁性（反磁）、配合物以四面体 [CdX₄]²⁻ 与八面体 [CdX₆]⁴⁺ 为主。这是"ds 区三兄弟"（Zn/Cd/Hg）的共同性格，也是把它们与典型过渡金属（Cu/Fe/Cr）区分开的第一判据。

## 二、核心要点

### 2.1 单质与结构

- 单质：银白带蓝灰光泽的软金属，**hcp（六方最密堆积）结构**（与 Zn 同型，但 c/a 比偏离理想值更明显——层间距略大）
- 熔点 321°C、沸点 767°C——低熔沸点是 ds 区金属共性（Hg 常温液态、Cd/Zn 低熔）
- 表面在空气中缓慢氧化成 CdO 保护膜；加热燃烧生成棕褐色 CdO
- 不溶于碱（与 Zn 不同——Zn 因两性可溶强碱，**Cd 的两性极弱**，这是 Zn/Cd 的关键差别之一）

### 2.2 主要化合物

| 化合物 | 性质 | 用途/考点 |
|---|---|---|
| CdO | 棕褐色，碱性氧化物（不显两性） | 颜料、电极材料 |
| **CdS（镉黄）** | 柠檬黄→橙黄，Ksp 极小（~10⁻²⁸） | 经典黄色颜料；**定性分析中 H₂S 在酸性中沉淀的黄色硫化物** |
| CdSe / CdTe | 半导体，带隙随尺寸可调（量子点） | 量子点发光、CdTe 薄膜太阳能电池 |
| Cd(OH)₂ | 白色，弱两性（偏碱） | 溶于酸；浓强碱可溶生成 [Cd(OH)₄]²⁻ |
| CdCl₂ | 层状结构（CdI₂ 型），共价性明显 | 配位化学载体 |
| Cd(CN)₂ / [Cd(CN)₄]²⁻ | 剧毒配合物 | 电镀液组分 |

**CdS 的颜色机理（高频考点）**：Cd²⁺ 的极化能力强于 Zn²⁺（半径大、变形性大），使 S²⁻ 的电子云被显著极化 → 电子从 S²⁻ 到 Cd²⁺ 的**电荷转移跃迁（LMCT）能量降低**，吸收边从紫外移入可见光蓝紫区 → 呈黄色。ZnS 的 Zn²⁺ 极化弱、带隙宽（3.6 eV，吸收在紫外）→ 白色。**这条"极化→带隙→颜色"链条同时解释了 CdS/CdSe/CdTe 颜色逐渐加深（Se、Te 更易极化）**。

### 2.3 配位化学

- Cd²⁺ 是 d¹⁰，无晶体场稳定化能（CFSE = 0）→ **配位数灵活**（4、5、6 皆常见），几何由配体体积与静电决定
- 常见配离子：[Cd(NH₃)₄]²⁺（四面体）、[Cd(CN)₄]²⁻（四面体，K_f 大）、[CdI₄]²⁻、[Cd(OH)₄]²⁻
- 与卤素形成 [CdX₄]²⁻ 的趋势：I⁻ > Br⁻ > Cl⁻（软酸 Cd²⁺ 与软碱 I⁻ 匹配，见软硬酸碱理论思路）
- **与 Zn²⁺ 的区别**：Zn²⁺ 配位数以 4 为主且两性明显；Cd²⁺ 更容易达到 6 配位且碱性氧化物为主

## 三、Zn → Cd → Hg 递变（本页图即此对比）

| 性质 | Zn | Cd | Hg |
|---|---|---|---|
| 电子构型 | 3d¹⁰4s² | 4d¹⁰5s² | 5d¹⁰6s² |
| 第一电离能 | 906 | 868 | 1007 kJ/mol（Hg 反常高：相对论效应收缩 6s） |
| M²⁺ 半径 | 74 | 95 | 102 pm |
| E⁰(M²⁺/M) | −0.76 | −0.40 | +0.85 V（Hg 是唯一"不活泼"的） |
| 硫化物 | ZnS 白 | CdS 黄 | HgS 红/黑（极难溶） |
| 硫化物带隙 | 3.6 eV | 2.4 eV | ~2 eV（HgS 窄） |
| 毒性 | 必需微量元素 | **高毒** | **高毒** |

**读图规律**：沿族向下半径增大、金属性增强（E⁰ 升高意味着还原性减弱——Zn 最活泼、Hg 最惰性）；Hg 因相对论效应（6s 收缩、5d  destabilize）出现多处反常（常温液态、+1 价以 Hg₂²⁺ 二聚存在、E⁰ 为正）。Cd 处于"中间但更靠近 Zn"的位置——它像 Zn 一样以 +2 为主、能形成配合物，但因半径大、极化强而在颜色/溶解度上不同。

## 四、毒性与环境（重要现实维度）

- **毒性机制**：Cd²⁺ 与 Zn²⁺ 半径/配位习性相近 → 在体内**冒充 Zn²⁺ 占据金属酶活性位**（如碱性磷酸酶、碳酸酐酶），但 d¹⁰ 的 Cd²⁺ 无法完成催化 → 酶失活；同时 Cd 干扰 Ca 代谢导致骨软化
- **痛痛病（Itai-itai disease）**：日本富山县神通川流域因镉矿废水污染稻米，导致居民肾小管功能障碍 + 骨软化骨折——环境化学经典案例
- **蓄积性**：生物半衰期长达 10~30 年，主要蓄积于肾皮质
- **治理**：硫化物沉淀法处理含镉废水（CdS 溶解度极低）；禁止镉用于食品容器与玩具；欧盟 RoHS 限制
- **处置纪律**：含镉废液单独收集，不可与一般重金属废液混合；CdS 等难溶物也应按危废处理

## 五、应用

1. **镍镉电池（Ni-Cd）**：负极为 Cd，可循环充电但有"记忆效应"且 Cd 污染严重 → 已被 Ni-MH/Li-ion 大量替代
2. **颜料**：镉黄（CdS）、镉红（CdS·CdSe 固溶体）——色彩鲜艳稳定，但因毒性受限用于艺术颜料与特种塑料
3. **半导体与量子点**：CdSe 量子点（尺寸调色）、CdTe 薄膜太阳能电池（转换效率 ~22%）
4. **电镀与防腐**：镉镀层耐海水腐蚀（航空/船舶），但受环保限制
5. **合金**：低熔点合金（Wood 合金含 Cd）、轴承合金；银-镉-铟控制棒（核反应堆，Cd 中子吸收截面大）

## 六、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 镉与锌性质相同 | Cd 半径大、极化强：CdS 黄而 ZnS 白；Cd(OH)₂ 两性极弱而 Zn(OH)₂ 两性明显 | "Zn 白 Cd 黄"是最直观的区分 |
| 镉化物无毒 | Cd²⁺ 高毒、蓄积于肾、致骨软化（痛痛病） | 与 Zn（必需元素）形成鲜明对照 |
| 镉只有 +2 | 主价 +2，但存在 +1（Cd₂²⁺ 二聚阳离子，类似 Hg₂²⁺，极不稳定） | 与 Hg 的 +1 稳定性对比：Hg₂²⁺ 稳定、Cd₂²⁺ 罕见 |
| Cd(OH)₂ 明显两性 | 偏碱性，只溶于浓强碱 | Zn(OH)₂ 两性典型、Cd(OH)₂ 勉强、Hg(OH)₂ 不存在（直接分解为 HgO） |
| 认为 Cd 是典型过渡金属 | d¹⁰ 全满 → 无变价、无色、反磁 | 与 Fe/Cu/Cr 等 d 区元素区分 |
| 忽略 CdS 在定性分析中的作用 | 酸性通 H₂S 得黄色 CdS 是第二组阳离子鉴定标准现象 | 与 CuS(黑)、HgS(黑)、As₂S₃(黄) 需靠其他试剂区分 |

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解镉在周期表中的位置和基本性质，再学习镉的常见化合物，最后掌握镉的化学反应和应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 镉和锌性质完全相同 | 镉的金属性比锌弱，化合物更稳定 |
| 镉化物都是无毒的 | 镉化物毒性很强，需要特殊处理 |
| 镉只有+2价 | 镉主要形成+2价化合物，但也有+1价化合物 |

### 15.3 入门级例题

**题目**：解释为什么CdS是柠檬黄色而ZnS是白色。

**解答**：Cd²⁺的极化能力强于Zn²⁺，导致CdS的吸收带移向可见光区域，呈现黄色。而ZnS的吸收带在紫外区，因此呈白色。

### 15.4 与现实世界的联系

1. **半导体材料**：CdS和CdSe是重要的半导体材料
2. **电池技术**：镉镍电池曾广泛使用
3. **颜料工业**：镉颜料具有鲜艳的颜色和良好的稳定性

> **记忆锚**：镉三件事——d¹⁰ 无变价（只有 +2）、CdS 黄（极化→带隙→颜色）、高毒蓄积（冒充 Zn²⁺ 占位）。与 Zn 的差别：黄 vs 白、碱性 vs 两性、有毒 vs 必需。

## 七、竞赛考察要点

1. **递变题**：Zn/Cd/Hg 的电离能、E⁰、硫化物颜色与溶解度排序（Hg 反常须记住）。
2. **颜色解释**：CdS 黄、ZnS 白、HgS 红/黑——极化能力递增强度 → 带隙递减 → 吸收红移。
3. **两性对比**：Zn(OH)₂ 两性 > Cd(OH)₂ 弱两性 > HgO 无两性。
4. **定性分析**：酸性 H₂S 沉淀组（CuS 黑、CdS 黄、HgS 黑、As₂S₃ 黄）的区分流程。
5. **环境化学**：痛痛病案例 + 硫化物沉淀法处理含镉废水。
6. **结构题**：Cd 的 hcp 金属结构、CdCl₂ 层状结构（CdI₂ 型）。

## 八、关键结论速记

- Cd = d¹⁰s²，只有 +2 稳定，无色反磁，hcp 金属，低熔点 321°C。
- 与 Zn 三差别：CdS 黄 vs ZnS 白；Cd(OH)₂ 弱两性 vs Zn(OH)₂ 两性；Cd 高毒 vs Zn 必需。
- 颜色根源：极化能力 Cd²⁺ > Zn²⁺ → 带隙窄 → LMCT 吸收红移入可见。
- Hg 反常（相对论效应）：常温液态、+1 以 Hg₂²⁺ 存在、E⁰ = +0.85 V（惰性）。
- 毒性机制：冒充 Zn²⁺ 占酶位；痛痛病是经典环境案例；废水用硫化物沉淀。
- 收尾自检：能解释 CdS 颜色、能排 Zn/Cd/Hg 递变、能说清镉毒性机制——本页达标。
- 数值锚：Cd 原子量 112.4、熔点 321°C、CdS 带隙约 2.4 eV（ZnS 3.6 eV）——三数串起"位置-物理-颜色"三条线。
- 定性分析锚：酸性 H₂S 中 CdS 为黄色沉淀，可溶于浓 HCl？——不溶（CdS 需氧化性酸如浓 HNO₃ 才溶），与 Sb₂S₃（溶浓 HCl）形成对照。
- 结构锚：Cd 金属 hcp；CdS 有闪锌矿（立方）与纤锌矿（六方）两种晶型；CdCl₂ 取 CdI₂ 型层状结构（与 Cd(OH)₂ 层状同理）。
- 一句话收束：镉在竞赛里不承担复杂反应，它的考点是"对比"——与 Zn 比两性/颜色/毒性，与 Hg 比反常/价态，与典型过渡金属比 d¹⁰ 的"无变价"性格。
