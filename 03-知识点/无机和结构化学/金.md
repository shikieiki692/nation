# 金

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述
- [Xe]4f¹⁴5d¹⁰6s¹（强相对论效应 → 6s 收缩 → 化学惰性 + 金色外观）
- 氧化态：+1（配合物中稳定），+3（最常见）
- **王水**才能溶解：Au + 4HCl + HNO₃ → HAuCl₄ + NO + 2H₂O

**元素定位**：金是 IB 族（铜族）最重成员，也是"最不活泼金属"竞赛题的标准答案。理解金的一切反常（金色、惰性、+3 主氧化态、Au⁺ 歧化、纳米红）都可以归因于一个词——**相对论效应**：6s 轨道被相对论性收缩、与 5d 靠近，改变了电离能、键合与光学行为。

## 二、重要反应
- Au(III) 配合物均为平面正方形（dsp²，d⁸）
- HAuCl₄（氯金酸）：黄色晶体
- Au 纳米粒子：表面等离子体共振 → 红色（非 bulk 金色）
- 溶解体系三档（对比记忆）：Cu 溶于 HNO₃、Ag 溶于 HNO₃、**Au 仅王水**——"氧化性酸 + 络合配体"双缺一不可
- [Au(CN)₂]⁻ 线性配合物是氰化法提金的核心（见 [[氰化法]]）

## 三、核心原理

### 3.1 金与王水的反应
金是化学性质最稳定的金属之一。只有王水能溶解金：
$$\mathrm{Au} + 4\mathrm{HCl} + \mathrm{HNO}_3 \longrightarrow \mathrm{HAuCl}_4 + \mathrm{NO} + 2\mathrm{H}_2\mathrm{O}$$
王水既有硝酸的氧化性又有盐酸的络合性（提供 $\mathrm{Cl}^{-}$ 配体生成稳定的 $\mathrm{AuCl}_4^{-}$）。

**为什么单独 HNO₃ 不行**：Au 的 E°(Au³⁺/Au) ≈ +1.50 V（酸性）高于 HNO₃ 的 +0.96 V——氧化性不够；但 Cl⁻ 把 Au³⁺ 络合为 AuCl₄⁻（K_f 巨大）后，**有效电极电势被大幅拉低**，HNO₃ 就能氧化了。**"氧化剂 + 隐蔽剂（配体）协同"是王水的机理本质**，可迁移到其它贵金属（Pt 同理）与生物浸金（CN⁻ 络合 + O₂ 氧化）。

### 3.2 金的氧化态与相对论效应
Au 的价电子构型为 $5\mathrm{d}^{10} 6\mathrm{s}^1$。常见的稳定氧化态为 $+3$（如 $\mathrm{AuCl}_3$、$\mathrm{Au}_2\mathrm{O}_3$）。强相对论效应使 6s 收缩，化学惰性，同时呈现金色外观。Au 也可以形成 $+1$ 氧化态，但在水溶液中容易歧化。

**相对论效应三连锁**：
1. **6s 收缩 → 6s 电子难失**：Au 第一电离能（890 kJ/mol）反常高于 Ag（731），E°(Au⁺/Au) = +1.68 V 极高 → 金属极惰性；
2. **5d 轨道因屏蔽减弱而扩张 → 5d-6s 能隙缩小**：可见光蓝紫段（~2.3 eV）被 d→s 带间吸收 → 反射光谱呈金色（Ag 无此吸收故银白）；
3. **亲金相互作用（aurophilicity）**：Au(I) 之间出现 ~3.0 Å 的弱吸引（相对论收缩使外层电子云可极化）——解释 Au 簇合物构型。

**氧化态地图**：Au(I) 只以**线性二配位**存在（[Au(CN)₂]⁻、[AuCl₂]⁻，sp 杂化）；Au(III) 平面正方形 d⁸（AuCl₄⁻、AuCl₃ 二聚体）。水溶液中 Au⁺ 歧化：3Au⁺ ⇌ Au³⁺ + 2Au（K ~ 10¹⁰，E°：Au⁺ + e⁻ → Au +1.68 vs Au³⁺ + 2e⁻ → Au⁺ +1.29 → 2×1.68 > 1.29? 判据：歧化须 E°(右) > E°(左)——Au⁺ 歧化与否由 E°(Au³⁺/Au⁺) = 1.29 与 E°(Au⁺/Au) = 1.68 比较：**1.29 < 1.68 → 逆歧化？** 歧化条件：E°(氧化产物/中间) < E°(中间/还原产物)？标准判据：若 E°(X⁺/X) > E°(X³⁺/X⁺) 则 X⁺ 歧化自发。1.68 > 1.29 → Au⁺ 不歧化？但教科书说 Au⁺ 水溶液歧化 3Au⁺→Au³⁺+2Au！

   计算歧化反应 3Au⁺ → Au³⁺ + 2Au 的 E：半反应 Au⁺ + e⁻ → Au（E₁=+1.68）；Au³⁺ + 2e⁻ → Au⁺（E₂=+1.29）。歧化电池：阳极 Au⁺ → Au³⁺ + 2e⁻（−E₂=−1.29）；阴极 Au⁺ + e⁻ → Au（E₁=1.68）。电池反应 3Au⁺ → Au³⁺+2Au，E = E₁ − E₂？不对，两个半反应电势不能直接减（电子数不同），要算 ΔG：歧化 3Au⁺→Au³⁺+2Au：拆成 Au⁺→Au³⁺（失 2e，ΔG₁=−2F×1.29… 符号乱。

   简化正确推理：Au⁺ + e⁻ → Au E°=+1.68；Au³⁺ + 3e⁻ → Au E°=+1.50。由这两式推 Au³⁺ + 2e⁻ → Au⁺：ΔG：Au³⁺+3e⁻→Au：ΔG₃ = −3F×1.50；Au⁺+e⁻→Au：ΔG₁ = −1F×1.68。相减得 Au³⁺ + 2e⁻ → Au⁺：ΔG₂ = ΔG₃ − ΔG₁ = −3F×1.50 + 1F×1.68 = −2.82F → E₂ = −ΔG₂/2F = 1.41 V。
   歧化 Au⁺：半反应 ①Au⁺→Au（还原 +1.68）②Au⁺→Au³⁺（氧化，逆反应 E₂=1.41 → 氧化电势 −1.41）。歧化电动势 = E(还原) − E(氧化) = 1.68 − 1.41 = +0.27 V > 0 → **Au⁺ 歧化自发** ✓（K≈10⁹ 与教材"易歧化"一致）。
   
   所以歧化成立（我用初赛 E°：Au⁺/Au +1.68、Au³⁺/Au +1.50——常见表值）。正文别写复杂推导，结论"3Au⁺ → Au³⁺ + 2Au 歧化（由 E° 计算 K~10⁹）"。

### 3.3 铂系元素
VIII 族第五、六周期的 Ru、Rh、Pd 和 Os、Ir、Pt 6 种元素被称为铂系元素，都是比较惰性的贵金属。Pt 和 Pd 离子可以与 $\mathrm{Cl}^{-}$ 和 $\mathrm{NH}_3$ 等形成配合物。$\mathrm{PtCl}_2(\mathrm{NH}_3)_2$ 有两种几何异构体，顺式异构体（"顺铂"）有抗癌性能。$\mathrm{PtF}_6$ 是最强的氧化剂之一，甚至可将 $\mathrm{O}_2$ 氧化成 $\mathrm{O}_2^{+}[\mathrm{PtF}_6]^{-}$，也可与稀有气体 Xe 反应得到第一个稀有气体化合物 $\mathrm{Xe}^{+}[\mathrm{PtF}_6]^{-}$。

### 3.4 铂系金属的化学稳定性
铂系金属化学性质很稳定，其中只有 Pd 可溶于浓 $\mathrm{HNO}_3$ 或王水，Pt 可溶于王水，其他几种金属块状时都不溶于任何强酸。利用其化学稳定性，可制作精密仪器零件及器皿。国际标准米尺是用 Pt-Ir 合金制成的。

## 四、关键结论
- Au 的常见氧化态为 $+3$（$\mathrm{HAuCl}_4$、$\mathrm{AuCl}_3$、$\mathrm{Au}_2\mathrm{O}_3$）
- Au 只能溶于王水（氧化性 + 络合性协同作用）
- $\mathrm{Au(OH)}_3$ 为两性（以酸性为主）
- 铂系元素中 Ru 和 Os 可以有 $+8$ 氧化态（$\mathrm{OsO}_4$ 是稳定氧化物）
- Pt-Pt-Rh 热电偶常用于高温测量（约 $1300^{\circ}\mathrm{C}$）
- 三元催化剂（Pt-Rh-Pd）用于汽车尾气净化

## 五、常见分类或情形
- **Au(III) 化合物**：$\mathrm{HAuCl}_4$（氯金酸）、$\mathrm{AuCl}_3$、$\mathrm{Au}_2\mathrm{O}_3$
- **Au(I) 化合物**：$\mathrm{AuCl}$、$\mathrm{[Au(CN)}_2]^{-}$（氰化物提金法）
- **铂系配合物**：$\mathrm{PtCl}_2(\mathrm{NH}_3)_2$（顺铂/反铂）、$\mathrm{PtF}_6$（最强氧化剂之一）
- **贵金属催化剂**：汽车尾气三元催化剂（Pt-Rh-Pd）
- **金簇与纳米金**：Au 纳米粒子 SPR 红色（粒径 ~20 nm）；纳米金/负载 Au 是低温 CO 氧化、炔烃活化的高效催化剂（"惰性块金 vs 活泼纳米金"反差题）

## 六、适用条件与限制
- Au 极不活泼，自然界有单质存在
- 王水溶解 Au 时需加热
- 铂系金属块状在高温也不能和 $\mathrm{Cl}_2$、$\mathrm{O}_2$ 等反应
- $\mathrm{OsO}_4$ 有毒且易挥发

## 七、常见比较与易混点
| IB 族 | Cu | Ag | Au |
|------|------|------|------|
| 常见氧化态 | +2 | +1 | +3 |
| 与 $\mathrm{O}_2$ | CuO | 不反应 | 不反应 |
| 与酸 | 氧化性酸 | $\mathrm{HNO}_3$ | 仅王水 |
| $E^{\theta}(\mathrm{M}^{+}/\mathrm{M})$ | $+0.521$ | $+0.799$ | $+1.68$ V |

**IB 族递变规律（与主族相反！）**：Cu(+2) → Ag(+1) → Au(+3)——同族向下氧化态先降后升的"反常"，根源是**惰性对效应 + 相对论效应**：Ag 的 4d¹⁰ 全满稳定故 +1 最稳；Au 因 6s 强烈收缩，+1 态 6s 电子难失的同时 5d 电子（因 6s 收缩屏蔽减弱而扩张）反而相对易失 → +3（5d⁸）经平面正方形配体场稳定而成为主氧化态。**"IB 族主氧化态：Cu²⁺/Ag⁺/Au³⁺"** 与 IIB 族（Zn²⁺/Cd²⁺/Hg²⁺ 全 +2）形成对照。

- 王水溶解 Au/Pt 的原理：$\mathrm{HNO}_3$ 氧化 + HCl 络合（生成稳定 $\mathrm{Cl}^{-}$ 配合物）
- 金纳米粒子的红色（表面等离子体共振）vs 块状金的黄色

## 八、与其他知识点的联系

- [[铜]] / [[银]]：IB 族递变对照（氧化态/与酸反应/E°）
- [[氰化法]]：Au + CN⁻ + O₂ 的提金化学（含 K_f 与 E° 联动）
- [[稀有气体化合物]]：PtF₆ 氧化 Xe 的历史联系（1962 Bartlett）
- [[配位化学]]：Au(I) 线性 / Au(III) 平面正方形的配位化学依据
- 相对论效应：与本库 [[汞]]（液态/惰性）同源——"Hg 与 Au 是相对论效应双星"

## 九、典型题型

1. **"哪种酸能溶 Au"辨析**：HNO₃（氧化性够吗→不够）、浓 H₂SO₄、王水（氧化+络合）——E° 与配位协同。
2. **氧化态推断**：给配合物化学式定 Au 价态（AuCl₄⁻ = +3、[Au(CN)₂]⁻ = +1）。
3. **歧化判断**：Au⁺ 水溶液歧化（3Au⁺ → Au³⁺ + 2Au）与稳定 Au(I) 的配体（CN⁻ 络合后 E° 反转，[Au(CN)₂]⁻ 不歧化）。
4. **氰化法流程**：4Au + 8CN⁻ + O₂ + 2H₂O → 4[Au(CN)₂]⁻ + 4OH⁻（氧化剂是 O₂ 不是酸）。
5. **顺铂/反铂**：PtCl₂(NH₃)₂ 的顺反异构与抗癌活性（配位化学 + 医药应用）。

## 十、例题

**题目**：解释为何 Au 不溶于浓 HNO₃ 而溶于王水；氰化法提金中 Au 的氧化剂是什么？

**解答**：HNO₃ 的氧化电势（NO₃⁻/NO ≈ +0.96 V）低于 Au³⁺/Au 的 +1.50 V，单独无法氧化 Au；王水中 Cl⁻ 与 Au³⁺ 生成稳定 AuCl₄⁻，使 Au(III)/Au 电对的**有效电势大幅降低**，HNO₃ 遂可氧化。氰化法以 O₂ 为氧化剂：4Au + 8CN⁻ + 2H₂O + O₂ → 4[Au(CN)₂]⁻ + 4OH⁻——同样借 [Au(CN)₂]⁻ 的强络合（K_f ~ 10³⁸）拉低 Au⁺/Au 电势使 O₂ 能氧化。**两法机理同构："氧化 + 络合"双管齐下**。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| Au 与 Ag 一样溶于硝酸 | Ag 溶（生成 AgNO₃）、**Au 不溶**（E° 太高） | 王水才行：HNO₃ 氧化 + Cl⁻ 络合协同 |
| Au 只有 +1 或"像 Ag 一样 +1 主" | Au 主氧化态是 **+3**（HAuCl₄/AuCl₃/Au₂O₃）；Ag 才是 +1 主 | IB 族主氧化态 Cu²⁺/Ag⁺/Au³⁺ |
| Au⁺ 在水溶液中稳定 | Au⁺ 歧化 3Au⁺ → Au³⁺ + 2Au | 用 CN⁻ 等配体络合成 [Au(CN)₂]⁻ 才稳定（防歧化） |
| 把金色当"金属光泽通性" | 金色是相对论效应 d-s 带间吸收蓝紫光的特异反射 | Ag 同样"金属光泽"却银白——只有 Au 金 |
| 纳米金 = 小金块（金色） | 纳米金 SPR 呈红/紫色（粒径相关） | 惰性块金 vs 催化活性纳米金（低温 CO 氧化） |
| Au(I) 配位数 4 | Au(I) 是 **d¹⁰ 线性二配位**（sp）——Au(III) 才平面正方形 | [Au(CN)₂]⁻ 线性、AuCl₄⁻ 平面正方形 |
| 顺铂对位异构体也有抗癌性 | 反铂（trans）无抗癌活性——顺式才有效 | 配位化学立体化学 + 医药考点 |

## 十二、🎯 教学视角

### 学习路径建议
金应在学完 IB 族（铜/银）与配合物基础后引入。先掌握"相对论效应 → 惰性 + 金色"这条主线，再对比 Cu/Ag/Au 的氧化态递变，最后落到王水与氰化法两个"氧化+络合协同"的应用机理上。铂系元素作为姊妹体系顺带横向对照。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| Au 是"最稳定"就什么都不反应 | Au 惰性但仍可被氧化（王水/CN⁻+O₂/卤素），且纳米 Au 是活性催化剂 |
| Cu/Ag/Au 递变与主族一致 | IB 族氧化态 2/1/3 非单调——相对论 + 惰性对效应所致 |
| 王水只是"更强酸" | 王水不是靠酸性，是靠"氧化 + 络合"协同（盐酸提供 Cl⁻ 配体） |

### 与现实世界的联系
1. **货币与电子**：Au 导电优、耐腐蚀——金合金触点/键合丝
2. **抗癌药顺铂**：Pt(II) 平面方形配合物的顺式异构体（机制见例题/[[配位化学]]）
3. **催化**：负载纳米 Au（Au/TiO₂）低温 CO 氧化、乙炔氢氯化——"惰性金属的纳米活化"
4. **首饰鉴定**：K 金（24K=纯金）——"K"来自 Karat

> **记忆锚**：金三问——为什么惰性（6s 收缩 E°+1.68）？为什么金色（5d-6s 带间吸收）？为什么 +3 主（5d 扩张 + 平面方形 d⁸ 稳定）？三问都是相对论效应。

## 竞赛考察要点

1. **溶解性判断**：Au 与各酸/王水——E° 对比 + 配位协同解释。
2. **氧化态与构型**：Au(I) 线性（[Au(CN)₂]⁻）、Au(III) 平面正方形（AuCl₄⁻）→ 由配位数反推 d 电子。
3. **歧化计算**：Au⁺ 歧化方向（E° 或 K 判断）+ CN⁻ 稳定化原理。
4. **氰化法配平**：4Au + 8CN⁻ + O₂ + 2H₂O → 4[Au(CN)₂]⁻ + 4OH⁻（电荷/氧守恒）。
5. **相对论效应**：6s 收缩 → 惰性/金色/亲金性；与 Hg 液态同源对比。
6. **顺铂化学**：PtCl₂(NH₃)₂ 顺反异构、PtF₆ 氧化 Xe（稀有气体化学史）。

## 关键结论速记

- 相对论效应三连锁：6s 收缩（惰性 E°=+1.68）→ 5d-6s 靠近（金色）→ 亲金作用（簇）。
- 氧化态：Au(I) 线性 d¹⁰（配 CN⁻ 才稳）/ Au(III) 平面方形 d⁸（主氧化态）；Au⁺ 水相歧化。
- 溶解：王水 = HNO₃ 氧化 + HCl 络合（有效电势拉低）；氰化法同构（O₂ 氧化 + CN⁻ 络合，K_f 10³⁸）。
- IB 族递变：Cu²⁺/Ag⁺/Au³⁺——"向下氧化态不单调"的反常范例。
- 纳米 Au：SPR 红/紫色、低温 CO 氧化催化——"块金惰性、纳米活泼"。
- 铂系对照：Pd 溶 HNO₃、Pt 溶王水、其余更惰；OsO₄（+8）稳定氧化物；顺铂抗癌。
- 收尾自检：能讲王水/氰化法的"氧化+络合"机理、能排 Cu-Ag-Au 递变、能由配合物定 Au 价态——本页达标。
