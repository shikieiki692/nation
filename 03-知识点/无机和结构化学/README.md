# 无机和结构化学

> 本目录涵盖中国化学奥林匹克**基础要求**中的无机和结构化学模块，共 **215 个知识点文件**。
> 绝大多数文件平铺在根目录，`元素化学/` 子目录仅1个文件。

## 知识模块分布

| 模块 | 核心KP |
|------|--------|
| **晶体结构** | 晶胞、晶格常数、点阵类型、密堆积（立方/六方）、NaCl/CsCl/CaF2/ZnS/金红石/钙钛矿/尖晶石等结构、Bragg方程、原子坐标 |
| **元素化学** | 逐元素KP（Na/Ca/Fe/Cu/Zn/Cr/Mn/Co/Ni/Ti/V/Al/B/Si/P等）+ 族总览（碱金属/碱土/卤素/氮族/氧族/碳族/硼族/稀有气体/过渡元素） |
| **对称性** | 对称元素、旋转轴、镜面、对称中心、反轴、点群、群论基础 |
| **配位化学** | 配位数、配体交换、八面体配位、光谱化学序列、角重叠模型、EAN/18电子规则、金属-金属键 |
| **化学键理论** | 共价半径、离子半径、离子极化、有效核电荷、屏蔽效应、镧系收缩、相对论效应、能带理论、Pauling规则 |
| **材料与前沿** | MOF材料、二维材料、储氢材料、非化学计量化合物、高压化学 |
