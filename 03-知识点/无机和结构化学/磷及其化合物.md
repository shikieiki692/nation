# 磷及其化合物（Phosphorus and Its Compounds）

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、定义

**磷（P）**：Z = 15，价层构型 3s²3p³，VA 族第二周期下方元素。以**白磷、红磷、黑磷**三种同素异形体为主，化合物体系极其丰富：氢化物（PH₃）、氧化物（P₄O₆、P₄O₁₀）、含氧酸（H₃PO₄、H₃PO₃、H₃PO₂、H₄P₂O₇、HPO₃ 等）、卤化物（PCl₃、PCl₅）、硫化物（P₄S₃~P₄S₁₀）。

**核心矛盾**：P 是第三周期元素，**不能用 2p 轨道**与 O 形成强的 p-p π 键，成键靠 sp³ 杂化 σ 键 + 空的 3d 轨道参与 π 反馈——这决定了磷含氧酸的结构、酸性与氧化还原特性的独特面貌。

## 二、考纲对应

- 对应考纲条目：[[13-元素化学]]（氮族元素：磷及其化合物）
- 所属模块：[[基础要求-无机和结构化学]]
- 本知识点在考纲中的作用：磷化学是氮族元素的「非金属化合物体系」核心，含氧酸体系（一元/二元/三元）与酸性次序是竞赛高频考点，也是从原子结构解释宏观性质的标准范本。

## 三、核心原理

### 3.1 单质磷：同素异形体

| 同素异形体 | 结构 | 关键性质 |
|:---|:---|:---|
| **白磷 P₄** | 正四面体，**60° 键角**（张角最小、张力极大） | 燃点仅 40℃、空气中自燃（暗处磷光）、剧毒、溶于 CS₂ |
| **红磷** | 白磷断一根键后**链状/层状聚合**（无张力） | 较稳定、燃点 ~260℃、安全火柴原料、无毒 |
| **黑磷** | 层状结构（类石墨） | 最稳定、不燃、有导电性、半导体材料 |

**制备**：白磷由磷灰石 `Ca₃(PO₄)₂ + SiO₂ + C` 在电弧炉高温还原：
`2Ca₃(PO₄)₂ + 6SiO₂ + 10C → 6CaSiO₃ + 10CO↑ + P₄↑`

**白磷的化学性质**（碱性歧化是高中到竞赛的经典）：
`P₄ + 3NaOH + 3H₂O → 3NaH₂PO₂ + PH₃↑`（黄磷与碱共沸制 H₃PO₂ 与 PH₃）

### 3.2 磷化氢 PH₃

- **制备**：① 磷化钙水解 `Ca₃P₂ + 6H₂O → 3Ca(OH)₂ + 2PH₃↑`；② 碘化膦与碱 `PH₄I + NaOH → NaI + PH₃↑ + H₂O`；③ 白磷热碱歧化（见上）。
- **结构**：三角锥形，键角 **93.3°**（比 NH₃ 的 107.3° 小，因 P 半径大、成键轨道更分散）。
- **性质**：大蒜味剧毒气体；**碱性极弱**（PH₄⁺ 极不稳定，K_b ≈ 10⁻²⁸）；**强还原剂**（能被 Cu²⁺/Ag⁺ 等氧化，可用于定性与回收贵金属）；空气中自燃。
- **配位悖论**：对 H⁺，**NH₃ > PH₃**（N 电负性大、孤对定域）；对过渡金属，**PH₃ ≫ NH₃**（P 有空的 3d 轨道接受金属 d 电子 → **反馈π键**）。这是「配位能力方向与质子亲和方向相反」的经典案例。

### 3.3 磷的含氧酸体系（重点）

| 酸 | P 氧化态 | 元数 | 结构要点 | 代表性质 |
|:---|:---|:---|:---|:---|
| **H₃PO₂**（次磷酸） | +1 | **一元** | 2 个 P—H | 强还原剂，化学镀镍还原剂 |
| **H₃PO₃**（亚磷酸） | +3 | **二元** | 1 个 P—H | 强还原剂，可被卤素氧化 |
| **H₃PO₄**（磷酸） | +5 | **三元** | 无 P—H | 氧化性极弱，非氧化性酸 |
| **H₄P₂O₇**（焦磷酸） | +5 | 四元 | 双磷酸缩合 | 酸强于 H₃PO₄ |
| **(HPO₃)ₙ**（偏磷酸） | +5 | — | 链/环状 | 强酸 |

**结构核心**：P sp³ 杂化；P=O 双键由 **σ 配键 + d-p π 配键** 组成（P 的 3d 与 O 的 2p 形成反馈π键）。P—H 键中的 H **不能电离**（电负性 P ≈ H），故含 P—H 的酸是低价酸（少一个可电离 H）。

**酸性强弱次序**（必背）：
`(HPO₃)ₙ > H₄P₂O₇ > H₃PO₂ > H₃PO₃ > H₃PO₄`
（缩合酸 > 简单酸；低价酸因 P—H 增多、负电荷分散更差反而酸性更强——但 H₃PO₄ 的 Kₐ₁ = 7.6×10⁻³ 仍为三元酸中较强的一级）

**磷酸三级电离**：Kₐ₁ = 7.6×10⁻³，Kₐ₂ = 6.3×10⁻⁸，Kₐ₃ = 4.4×10⁻¹³。

### 3.4 磷酸及其盐

- **制备**：磷灰石 + H₂SO₄ `Ca₅(PO₄)₃F + 5H₂SO₄ → 5CaSO₄ + 3H₃PO₄ + HF↑`；也可 P₄O₁₀ + H₂O。
- **溶解性规律**：**磷酸二氢盐全溶**；磷酸一氢盐微溶；**正盐（磷酸盐）除钠、钾、铵盐外均难溶**。→ 沉淀法：`3Ag⁺ + PO₄³⁻ → Ag₃PO₄↓`（黄色）。
- **鉴定反应**：① Ag₃PO₄ 黄色沉淀；② 磷钼酸铵（黄色晶形沉淀，经典定性）：`PO₄³⁻ + 12MoO₄²⁻ + 3NH₄⁺ + 24H⁺ → (NH₄)₃[P(Mo₃O₁₀)₄]·6H₂O↓ + 6H₂O`；③ 镁铵混合试剂：`Mg²⁺ + NH₄⁺ + PO₄³⁻ → MgNH₄PO₄↓`（白色，灼烧转焦磷酸镁）。
- **多磷酸盐**：Na₅P₃O₁₀（三聚磷酸钠）是**软水剂**（螯合 Ca²⁺/Mg²⁺）、洗涤剂助剂；六偏磷酸钠用于水处理。

### 3.5 磷的氧化物

- **P₄O₆**（三氧化二磷，P 为 +3）：由白磷在**限氧**下燃烧制得；是**亚磷酸（H₃PO₃）的酸酐**（注意 +3 是亚磷酸盐酐，不是偏磷酸酐）；还原性。
- **P₄O₁₀**（五氧化二磷，P 为 +5）：白磷在**充足氧气**中燃烧；P₄O₆ 六个桥氧键中再插入 4 个 O（加在 P 上）成 P₄O₁₀；是磷酸/焦磷酸的酸酐；**最强的固体干燥剂之一**（对水的亲和力极大，吸水放热）。

### 3.6 磷的卤化物与硫化物

- **PCl₃**：液态，无色，**遇水剧烈水解**生成亚磷酸与 HCl：`PCl₃ + 3H₂O → H₃PO₃ + 3HCl`。
- **PCl₅**：固态，**离子型化合物** `[PCl₄]⁺[PCl₆]⁻`（注意不是简单分子晶体！PCl₄⁺ 四面体、PCl₆⁻ 八面体）；水解分两步：`PCl₅ + 4H₂O → H₃PO₄ + 5HCl`（直接完全水解）；气态时以共价 PCl₅ 分子存在（三角双锥）。
- **P₄S₃ ~ P₄S₁₀**：磷与硫的化合物系列；P₄S₃ 用于安全火柴；硫化磷水解产生 H₃PO₄、H₂S。

## 四、关键结论

| 主题 | 结论 |
|:---|:---|
| 白磷结构 | P₄ 正四面体，60° 键角，张力大 → 易燃、剧毒、歧化反应 |
| PH₃ 配位 | 对 H⁺：NH₃>PH₃；对过渡金属：PH₃≫NH₃（反馈π键） |
| 含氧酸元数 | 按可电离 H 数定：H₃PO₂ 一元、H₃PO₃ 二元、H₃PO₄ 三元 |
| 酸性次序 | (HPO₃)ₙ > H₄P₂O₇ > H₃PO₂ > H₃PO₃ > H₃PO₄ |
| P=O 本质 | σ 配键 + d-p π 配键（P 的 3d 参与） |
| 磷酸盐溶解性 | 二氢盐全溶 > 一氢盐微溶 > 正盐（Na/K/NH₄ 除外）难溶 |
| 鉴定 | Ag₃PO₄ 黄；磷钼酸铵黄；MgNH₄PO₄ 白 |

## 五、常见分类或情形

- **同素异形体**：白磷（P₄ 张力）、红磷（链状）、黑磷（层状）
- **氢化物**：PH₃（弱碱、强还原、配位悖论）
- **氧化物/含氧酸**：P₄O₆→H₃PO₃；P₄O₁₀→H₃PO₄/H₄P₂O₇/(HPO₃)ₙ
- **卤化物**：PCl₃（共价液态）、PCl₅（固态 [PCl₄]⁺[PCl₆]⁻）
- **硫化物**：P₄S₃~P₄S₁₀（安全火柴）
- **含氧酸盐**：磷酸盐（三组溶解性）、多磷酸盐（软水剂）、磷钼酸铵（鉴定）

## 六、适用条件与限制

- **PH₃ 配位悖论不适用于所有场合**：只在对过渡金属 vs 对 H⁺ 的方向对比中成立；对一般主族 Lewis 酸仍是 NH₃ 强。
- **酸式盐溶解性规律只适用于磷酸体系**：不要泛化到硫酸/碳酸（机理不同）。
- **PCl₅ 固态离子结构的判断**依赖晶体证据；气态是共价分子，状态不同结构表述不同。
- **含氧酸氧化性**：H₃PO₄ 是非氧化性酸（+5 稳定），但 H₃PO₃、H₃PO₂ 是强还原剂——低价态是还原性的根源。

## 七、常见比较与易混点

| 易混点 | 区分 |
|:---|:---|
| H₃PO₃ 是「三元酸」还是「二元酸」 | **二元**——1 个 P—H 上的 H 不电离；结构上 P 只有 3 个羟基配位位 |
| 酸性次序（H₃PO₂ vs H₃PO₄） | 低价酸酸性反而强：`(HPO₃)ₙ > H₄P₂O₇ > H₃PO₂ > H₃PO₃ > H₃PO₄` |
| PH₃ 配位能力 | 对 H⁺ 弱、对过渡金属强（反馈π键）——与直觉相反 |
| P₄O₆ vs P₄O₁₀ | P₄O₆ 是 H₃PO₃ 酸酐（+3）；P₄O₁₀ 是 H₃PO₄ 酸酐（+5） |
| PCl₅ 固态 vs 气态 | 固态 [PCl₄]⁺[PCl₆]⁻ 离子晶体；气态共价分子三角双锥 |
| 白磷 vs 红磷 | 白磷张力大易燃毒；红磷链状较稳定无毒 |

## 十、例题

### 例题 1（基础 · 含氧酸元数与酸性）

**题目**：判断 H₃PO₂、H₃PO₃、H₃PO₄ 的元数并解释理由。

**解答**：
- H₃PO₂：**一元**。结构 `H₂P(=O)OH`，只有 1 个 —OH，P—H 上的 H 不电离。
- H₃PO₃：**二元**。结构 `HP(=O)(OH)₂`，2 个 —OH，1 个 P—H 不电离。
- H₃PO₄：**三元**。结构 `OP(OH)₃`，3 个 —OH 均可电离。
- 判断原则：**元数 = 结构中 —OH 的个数**（可电离 H 数），而非化学式 H 总数。

### 例题 2（提高 · PH₃ 配位悖论）

**题目**：为什么 NH₃ 的碱性比 PH₃ 强，但 PH₃ 与过渡金属形成的配合物往往比 NH₃ 更稳定？

**解答**：
- 对质子：N 电负性大，孤对电子定域、易给出 → NH₃ 碱性强（K_b(NH₃)≈1.8×10⁻⁵ vs PH₃≈10⁻²⁸）。
- 对过渡金属：P 电负性小，且有**空的 3d 轨道**，金属的 d 电子可以反馈到 P 的空 3d 轨道形成 **d-p 反馈π键**，增强 M—P 键（σ+π 协同）；N 没有空的价轨道接受反馈 → 只靠 σ 配位。
- 结论：**质子亲和力与过渡金属配位能力方向相反**——用「反馈π键」解释。

### 例题 3（竞赛 · 磷的含氧酸鉴定与多聚）

**题目**：某无色溶液含 PO₄³⁻，写出两种可行的定性鉴定反应，并说明正磷酸盐的溶解性规律。

**解答**：
- ① `3Ag⁺ + PO₄³⁻ → Ag₃PO₄↓`（黄色沉淀，溶稀 HNO₃）；
- ② 磷钼酸铵法：`PO₄³⁻ + 12MoO₄²⁻ + 3NH₄⁺ + 24H⁺ → (NH₄)₃[P(Mo₃O₁₀)₄]·6H₂O↓ + 6H₂O`（黄色晶形沉淀）。
- 溶解性：**磷酸二氢盐全溶**（如 NaH₂PO₄）；**磷酸一氢盐微溶**；**正磷酸盐（除 Na⁺/K⁺/NH₄⁺ 外）难溶**（如 Ca₃(PO₄)₂、Ag₃PO₄）。多磷酸盐（如 Na₅P₃O₁₀）可螯合 Ca²⁺/Mg²⁺ 用于软水。

## 十一、易错点

| 易错点 | 学生为什么会这么想 | 正确认识 | 口诀 |
|:---|:---|:---|:---|
| "H₃PO₃ 是三元酸" | 化学式有 3 个 H | P—H 上 H 不电离，H₃PO₃ 是**二元**酸 | "亚磷酸只有一个 H 摸鱼——P—H 键的 H 不是酸 H" |
| "H₃PO₄ 酸性最强" | 三元酸=强酸直觉 | (HPO₃)ₙ > H₄P₂O₇ > H₃PO₂ > H₃PO₃ > H₃PO₄ | "缩合强、低价酸也强，磷酸排最后" |
| "PH₃ 和 NH₃ 一样是弱碱配体" | 同族类比 | PH₃ 对过渡金属是强 σ+π 配体 | "对 H⁺ 怂，对金属猛——3d 轨道开外挂" |
| "PCl₅ 是共价分子晶体" | 与 PCl₃ 类比 | 固态是 `[PCl₄]⁺[PCl₆]⁻` 离子晶体 | "固态是盐，气态才是分子" |
| "白磷稳定/安全" | 磷在火柴里 | P₄ 60° 键角张力大 → 易燃剧毒 | "白磷是张力的囚徒，见光就着火" |

## 十二、🎯 教学视角

### 12.1 讲授主线

1. **单质磷**：三种同素异形体结构 → 张力解释白磷活性
2. **PH₃**：结构 + 弱碱 + 配位悖论（反馈π键）
3. **含氧酸体系**：按 P 氧化态从 +1 到 +5 串成一条线（H₃PO₂→H₃PO₃→H₃PO₄），用「P—H 不电离」解释元数
4. **氧化物/卤化物/盐**：P₄O₆/P₄O₁₀ 酸酐对应、PCl₅ 固态离子、磷酸盐溶解性

### 12.2 学生典型认知误区

| 误区 | 教学干预 |
|:---|:---|
| "三元酸=酸强" | 对比 H₃PO₄ 与 (HPO₃)ₙ、H₃PO₂ 酸性，用「结构决定酸性」讲清楚 |
| "PH₃ 弱碱所以弱配体" | 用过渡金属配合物（如 Ni(PCl₃)₄）实例说明反馈π键 |
| "白磷红磷只是颜色不同" | 用 60° 键角张力解释白磷活性、红磷稳定 |

## 十三、竞赛拓展

1. **Wade 规则与磷簇**：P₄ 是 closo 型簇的简单例；白磷在高压下可转成多种多面体簇。
2. **磷的富氧化合物与 d-p π 键**：P=O 的 d-p π 配键是第三周期含氧酸「同周期酸更强」的结构基础（与第二周期 N=O 的 p-p π 键对比）。
3. **多聚磷酸盐的工业意义**：三聚磷酸钠（STPP）软水剂、六偏磷酸钠水处理、ATP/磷酸酯的生化意义。
4. **同族延伸**：As/Sb/Bi 的硫代酸盐（As₂S₃、As₂S₅ 溶于碱金属硫化物）、马氏试砷法/古氏试砷法（AsH₃ 加热分解成砷镜）。
5. **磷与生命**：DNA 磷酸骨架、ATP 高能磷酸键——从竞赛到生化。
