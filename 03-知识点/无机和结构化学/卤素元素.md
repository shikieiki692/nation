# 卤素元素

## 核心概念

### 1. 卤素氧化物
- **三氧化二氯 (Cl₂O₃)**：极不稳定，含罕见Cl-Cl键，是ClO₂光解产物，为亚氯酸(HClO₂)的酸酐
- **二氧化氯 (ClO₂)**：19电子体系，Cl-O键强于单键(dp-π键)，三种共振结构，碱性条件下歧化为ClO₃⁻和ClO₂⁻
- **高氯酸氯 (ClO₃Cl)**：实际结构为Cl-O-ClO₃，比ClO₂更不稳定，室温分解为Cl₂、O₂和Cl₂O₆
- **六氧化二氯 (Cl₂O₆)**：气相以ClO₃·自由基存在，凝聚相为二聚体，有Cl-Cl键和ClO₂⁺ClO₄⁻两种争议结构
- **七氧化二氯 (Cl₂O₇)**：两个ClO₄四面体共顶点连接，C₂对称性(非C₂ᵥ)，热分解经ClO₃和ClO₄
- **二氧化溴 (BrO₂)**：需<-40℃稳定，碱性歧化为BrO₃⁻和Br₂，亚溴酸根(BrO₂⁻)不稳定
- **五氧化二碘 (I₂O₅)**：300℃才分解，与CO定量反应生成I₂和CO₂(定量分析应用)

### 2. 卤素含氧酸

| 含氧酸 | 酸性强度 | 氧化性(热力学) | 氧化性(动力学) |
|--------|----------|----------------|----------------|
| HClO < HClO₂ < HClO₃ < HClO₄ | 逐增 | 逐减 | - |
| HClO₃ > HBrO₃ > HIO₃ | 逐减 | BrO₃⁻ > ClO₃⁻ > IO₃⁻ | IO₃⁻ > BrO₃⁻ > ClO₃⁻ |
| HClO₄ < HBrO₄ < HIO₄ | 逐增 | HBrO₄ > HClO₄ > HIO₄ | HIO₄ >> HBrO₄ > HClO₄ |

### 3. 卤素互化物
- **通式**：XYₙ，X为电负性较小的卤素
- **稳定形式**：XY、XY₃、XY₅、XY₇
- **稳定性规律**：Y电负性越大越稳定(F>Cl>Br>I)；X电负性越小越稳定(I>Br>Cl>F)；n越小越稳定
- **结构**：可用VSEPR理论解释，固体中存在四极键

### 4. 拟卤素
- **主要类型**：氧氰(OCN)₂、硫氰(SCN)₂、氰(CN)₂、硒氰(SeCN)₂
- **氧化性排序**：F₂ > (OCN)₂ > Cl₂ > Br₂ > (SCN)₂ > I₂ > (CN)₂ > (SeCN)₂
- **特点**：氧氰无单质形态，仅存在于水溶液中

## 关键反应

### 氯的氧化物制备
```
Cl₂O₃：2ClO₂ → Cl₂O₃ + O₃ (光解)
ClO₂：2NaClO₂ + Cl₂ → 2ClO₂ + 2NaCl
ClO₂：4H⁺ + C₂O₄²⁻ + 2ClO₃⁻ → 2ClO₂ + 2CO₂ + 2H₂O
Cl₂O₆：2ClO₂ + 2O₃ → Cl₂O₆ + 2O₂
Cl₂O₇：2HClO₄ → Cl₂O₇ + H₂O (浓H₃PO₄脱水，-10℃)
```

### 碘的氧化物制备
```
I₂O₅：I₂ + 10HNO₃(浓) → 2HIO₃ + 10NO₂ + 4H₂O
I₂O₅ + 5CO → I₂ + 5CO₂ (定量反应)
```

### 卤素互化物制备
```
单质化合：I₂ + 3F₂ → 2IF₃
归中反应：ClF₃ + Cl₂ → 3ClF
氧化还原：KI + 4F₂ → KF + IF₇
```

### 拟卤素反应
```
(CN)₂ + O₂ → 2CO + N₂ (火焰温度达5000K)
```

## 规律与趋势

### 1. 卤氧键特性
- 键长：随氧化态升高，卤氧键键长变短
- 原因：d-pπ键数量增加，电荷分离程度增大

### 2. 含氧酸酸性规律
- **同种元素**：低氧化态→高氧化态，酸性增强
- **同族元素**：F→I，相同氧化态的含氧酸酸性减弱

### 3. 含氧酸氧化性规律
- **热力学氧化性(电极电势)**：同种元素氧化态越低氧化性越强；同族从上到下氧化性增强
- **动力学氧化性(反应速率)**：IO₃⁻ > BrO₃⁻ > ClO₃⁻；HIO₄ >> HBrO₄ > HClO₄

### 4. 卤素阳离子稳定性
- 稳定性顺序：I₃⁺ > I₂⁺ > Br₃⁺ > Br₂⁺ > Cl₂⁺ > Cl⁺
- 碘最易形成阳离子，氟最难

### 5. 卤素互化物熔沸点
- 虽然IF₇分子量>ICl，但ICl存在四极键使熔沸点更高

## 典型应用

### 1. 定量分析
- **I₂O₅与CO反应**：用于CO含量分析
- **ClO₃F与I⁻反应**：酸性条件下定量生成F⁻和I₂

### 2. 氧化还原滴定
- **BrO₃⁻氧化S₂O₃²⁻**：快速反应生成SO₄²⁻
- **IO₃⁻氧化还原反应**：动力学速率最快

### 3. 配合物形成
- **高碘酸配合物**：[Mn(IO₆)₃]¹¹⁻、[Cu(IO₆)₂]⁷⁻
- **四价金属配合物**：M⁴⁺(IO₃)₆²⁻型，如Mn、Ti、Pb

### 4. 火箭推进剂
- **KClO₄、NH₄ClO₄**：用作火箭推进剂
- **ClF₃与NH₃反应**：2ClF₃ + 2NH₃ → N₂ + 6HF + Cl₂

### 5. 干燥剂
- **Mg(ClO₄)₂**：高效干燥剂，可用于制备无水HClO₄

### 6. 氟化试剂
- **BrF₃**：兼具氧化、氟化和氟给体性质
- **IF₅**：温和氟化试剂，水解生成HIO₃和HF
