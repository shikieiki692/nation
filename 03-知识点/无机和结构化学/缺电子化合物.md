# 缺电子化合物（Electron-Deficient Compound）

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]、[[09-原子结构]]

## 一、定义

**缺电子化合物**：分子中**价电子总数不足以使所有原子都达到稳定的二中心二电子键（2c-2e）配置**的化合物。核心判据是「**价电子数 < 价轨道数**」——中心原子有空着的价轨道（如 B：3 个价电子 4 个价轨道；Al：3 个价电子 4 个价轨道）。

缺电子不是「不稳定」，而是一种**结构特征**，化学上通过三种途径补偿：
1. **形成多中心键**（3c-2e 氢桥、3c-4e 卤桥）
2. **接受电子对**（Lewis 酸性，如 BF₃ + :NH₃）
3. **形成大π键**（如 BX₃ 的 Π₄⁶）或**聚合**（二聚/簇合）减少缺电子

典型代表：B₂H₆、BF₃、H₃BO₃、AlCl₃、Al₂(CH₃)₆、NaBH₄ 中的 [BH₄]⁻。

## 三、核心原理

### 3.1 缺电子的本质

- B 原子电子构型 2s²2p¹，只有 **3 个价电子却有 4 个价轨道**（2s + 2pₓ + 2pᵧ + 2p𝓏）。
- 若形成 BH₃，B 周围只有 6 个电子（3 对），缺一对电子达到八隅体 → BH₃ 不能稳定存在。
- 解决途径：**两个 BH₃ 二聚成 B₂H₆**，用 2 个电子同时为 3 个原子服务。

### 3.2 三中心二电子键（3c-2e）—— B₂H₆

- B₂H₆ 价电子总数 = 2×3 + 6×1 = **12 e⁻**。
- 4 个端位 B—H：正常 2c-2e σ 键，用去 8 e⁻。
- 2 个桥位 B—H—B：剩下 4 e⁻ 分给 2 个桥键，每个桥 = **3c-2e**（3 个原子共用 2 个电子）。
- 成键细节：每个 B sp³ 不等性杂化（3 条单电子轨道 + 1 条空轨道），桥 H 的 1s 与两侧 B 的空轨道重叠，两平面互相垂直。
- 结论：**B—H 端键是正常的，B—H—B 桥键是多中心的**。

```
        H       H
         \     /
          B---B
         /     \
        H   H   H    （俯视示意：端 H 与 B 共面，桥 H 在面上/下）
```

- **B₁₀H₁₄（癸硼烷）**含 5 种键型：B—H、B—B（经典 2c-2e）+ 氢桥键 + 开式硼桥键 + 闭式硼桥键（均为 3c-2e 变体）；骨架为缺两个相邻顶点的正二十面体。

### 3.3 三中心四电子键（3c-4e）—— Al₂Cl₆

- AlCl₃ 与 BF₃ 不同：Al、Cl 半径大，**不能像 B—F 那样形成大π键** → 靠**二聚**解决缺电子。
- Al₂Cl₆ 中桥 Cl 提供 **3 个电子**（1 个单电子 + 1 个孤对电子），与两侧 Al 形成 **3c-4e 氯桥键**。
- Al 是 sp³ 杂化，有 1 条空轨道接受桥 Cl 的孤对；Al₂Cl₆ 中每个 Al 配位数 4（四面体）。
- 遇 Lewis 碱：二聚体解离，单分子作 Lewis 酸（AlCl₃·O(C₂H₅)₂）。
- 类似物：三甲基铝 Al₂(CH₃)₆（甲基桥 3c-4e）。

### 3.4 大π键补偿（BX₃ 的 Π₄⁶）

- BX₃ 中 B 为 sp² 三角形，空 2p 轨道与三个 X 的满 p 轨道侧面重叠 → **Π₄⁶ 大π键**（4 个原子 6 个电子）。
- 解释 B—F 键长实测（130 pm）比单键半径和小——部分双键性质。
- **Lewis 酸性次序反常**：一般 **BI₃ > BBr₃ > BCl₃ > BF₃**（大π键越易形成，B 越「不饿」，Lewis 酸性越弱；F 的 2p 与 B 2p 重叠最好，Π₄⁶ 最强）。
- 但对**弱碱**（如 CO）时次序反转：**BF₃ > BCl₃ > BBr₃ > BI₃** → **Lewis 酸性顺序随碱而变**（必考点）。

### 3.5 缺电子与 Lewis 酸性（H₃BO₃ 一元弱酸本质）

- H₃BO₃ 中 B 为 sp² 平面三角形，有空的 2p 轨道。
- 溶于水时**接受 OH⁻ 的孤对电子**生成 [B(OH)₄]⁻（sp³ 正四面体），破坏水的解离 → 显酸性：
  `H₃BO₃ + H₂O ⇌ [B(OH)₄]⁻ + H⁺`，Kₐ = 5.81×10⁻¹⁰。
- **加多元醇（乙二醇/甘油）酸性增强**：生成稳定硼酸酯，平衡右移（Kₐ 增大上万倍）——硼酸定量滴定的依据。
- 这是「缺电子化合物的酸性可能不是给出 H⁺，而是接受电子对」的第一课。

### 3.6 硼烷的制备、性质与用途

- 制备：① Mg₃B₂ + H₃PO₄；② BCl₃ + H₂ 无声放电；③ `3LiAlH₄ + 4BCl₃（乙醚中）→ 2B₂H₆`（不能有水）。
- 性质：还原性极强、空气中自燃（ΔrH = −2167.3 kJ/mol）；**极易水解** `B₂H₆ + 6H₂O → 2H₃BO₃ + 6H₂↑`；剧毒。
- [BH₄]⁻（NaBH₄/LiBH₄）：B 有 4 个价轨道，形成 4 根 2c-2e 键后恰好「饱和」→ 比 BH₃ 稳定得多；重要还原剂（`NaBH₄ + 4H₂O → Na[B(OH)₄] + 4H₂↑`）。

## 四、关键结论

| 物种 | 缺电子特征 | 补偿方式 |
|:----|:----|:----|
| B₂H₆ | 12 价电子 < 14（烷烃标准） | 桥 B—H—B **3c-2e** 键 |
| BF₃ | B 空 2p 轨道 | **Π₄⁶ 大π键** + 接受电子对（Lewis 酸） |
| H₃BO₃ | B 空 2p 轨道 | 接受 OH⁻ → [B(OH)₄]⁻（一元弱酸） |
| AlCl₃ | Al 空轨道 | 二聚 → **3c-4e 氯桥** |
| [BH₄]⁻ | （饱和） | 4 根 2c-2e，稳定 |

## 五、常见分类或情形

- **缺电子氢化物**：乙硼烷 B₂H₆、B₄H₁₀、B₅H₉、B₁₀H₁₄ 等硼烷系
- **缺电子卤化物**：BF₃、BCl₃、AlCl₃、AlBr₃
- **缺电子含氧酸**：H₃BO₃（B(OH)₃）
- **配位氢化物**：NaBH₄、LiAlH₄
- **缺电子金属有机**：Al₂(CH₃)₆、Al(C₂H₅)₃（Ziegler-Natta 催化剂组分）
- **无机苯/氮化硼（等电子补偿）**：B₃N₃H₆、BN

## 六、适用条件与限制

- 判据：**价电子总数与价轨道数的关系**，而非「缺氢」「缺氧」。
- 3c-2e（桥 H：B₂H₆）vs 3c-4e（桥 Cl：Al₂Cl₆）：桥原子提供电子数不同（H 1 个、Cl 3 个）。
- 大π键能否形成取决于**轨道半径/重叠**：B—F 小半径可成 Π₄⁶；Al—Cl 大半径不能 → 走二聚路线。
- 缺电子≠不稳定：B₂H₆ 动力学活泼（水解/自燃），但 [BH₄]⁻、硼酸盐热力学稳定。

## 七、常见比较与易混点

| 易混点 | 区分 |
|:----|:----|
| BH₃ vs B₂H₆ | BH₃ 不存在（缺电子，6 电子）；B₂H₆ 靠 3c-2e 桥键稳定 |
| 3c-2e vs 3c-4e | B₂H₆ 氢桥（2 e⁻/3 原子）；Al₂Cl₆ 氯桥（4 e⁻/3 原子） |
| BF₃ vs AlCl₃ | BF₃ 单聚靠大π键；AlCl₃ 不能成π键 → 二聚 |
| H₃BO₃（一元）vs H₃PO₃（二元） | H₃BO₃ 缺电子 Lewis 酸接受 OH⁻；H₃PO₃ 是 P—H 上 H 不电离 |
| 缺电子 vs 等电子体 | 缺电子是「电子不足」；等电子体是「价电子数相同」——B₃N₃H₆ 与 C₆H₆ 等电子但 B/N 各有缺电子/富电子 |

- **题型-缺电子化合物结构判断**：B₂H₆ 的 3c-2e 桥键、BF₃ 的 Lewis 酸性、Al₂Cl₆ 的二聚结构

## 十、例题

### 例题 1（基础 · B₂H₆ 的三中心二电子键）

**题目**：乙硼烷 B₂H₆ 中共有多少个价电子？画出桥式结构，说明桥 B—H—B 的成键方式，并写出 B₂H₆ 与 LiH 的反应。

**解答**：
（1）价电子总数 = 2×3(B) + 6×1(H) = **12 e⁻**。
（2）4 个端 B—H（2c-2e）用 8 e⁻；2 个桥 B—H—B 各用 2 e⁻ → 每个桥为 **3c-2e 键**（3 个原子共用 2 个电子）。每个 B 以 sp³ 不等性杂化参与成键，4 端 H 与 2 B 共面，2 桥 H 位于平面上下。
（3）`B₂H₆ + 2LiH → 2Li[BH₄]`。B 杂化保持 sp³，但成键全部转为 2c-2e σ 键——[BH₄]⁻ 配位数 4 恰好饱和。

### 例题 2（提高 · BF₃ 单聚 vs AlCl₃ 二聚）

**题目**：为什么 BF₃ 以单分子存在，而 AlCl₃ 在气相以 Al₂Cl₆ 二聚体存在？

**解答**：
- BF₃：B 的空 2p 轨道与三个 F 的 2p 轨道形成 **Π₄⁶ 大π键**，B 周围电子密度得到部分补偿 → 单聚稳定。
- AlCl₃：Al、Cl 半径大，p 轨道重叠差，**无法形成大π键** → 通过氯桥二聚（3c-4e）解决缺电子。
- 本质：能否形成大π键决定缺电子补偿路径（π 键 vs 桥键）。

### 例题 3（竞赛 · 硼酸加甘油酸性增强）

**题目**：硼酸 H₃BO₃ 化学式上有 3 个 H，却是一元弱酸。解释原因，并说明为什么加入甘油后酸性显著增强。

**解答**：
（1）H₃BO₃ 的酸性来自 B 的**空 2p 轨道接受 OH⁻**生成 [B(OH)₄]⁻，破坏水的解离：`H₃BO₃ + H₂O ⇌ [B(OH)₄]⁻ + H⁺`（Kₐ = 5.81×10⁻¹⁰）。不是直接电离出 H⁺，因此是**一元** Lewis 酸。
（2）甘油的两个相邻 OH 与 B 螯合生成稳定硼酸酯，平衡大幅右移，c(H⁺) 增大（Kₐ 增大上万倍）——可用于酸碱滴定定量测定硼酸。

## 十一、易错点

| 易错点 | 学生为什么会这么想 | 正确认识 | 口诀 |
|:---|:---|:---|:---|
| "BH₃ 就是硼烷" | 把最简式当存在形式 | BH₃ 缺电子不能单独存在；实际是 B₂H₆（3c-2e 桥键） | "BH₃ 不存在——缺电子逼它找邻居借电子" |
| "H₃BO₃ 有三个 H，是三元酸" | 中学「写几个 H 就是几元酸」的简化 | 一元弱酸：B 空轨道接受 OH⁻ 而非自身电离 H⁺ | "硼酸只有一个氢在干活——另外两个是围观群众" |
| "BX₃ 酸性 BF₃ 最强" | 电负性 F 最大 | 一般次序 BI₃>BBr₃>BCl₃>BF₃（大π键补偿）；对弱碱反转 | "氟把硼喂饱了，就懒得吃外来的了" |
| "缺电子 = 不稳定 = 不重要" | 直觉把"缺"当缺陷 | 缺电子产生独特化学（多中心键、Lewis 酸、聚合），是特征不是缺陷 | "拼图少一块，别人来补——补出的是新玩法" |
| "Al(OH)₃ 溶于过量氨水" | 把两性泛化 | Al(OH)₃ 只溶强酸强碱，不溶氨水（鉴别点） | "氨水太弱，撬不动氢氧化铝" |

## 十二、🎯 教学视角

### 12.1 讲授主线

1. **缺电子的判据**：价电子数 vs 价轨道数 → B/Al 的「3 电子 4 轨道」
2. **多中心键**：B₂H₆ 的 3c-2e（氢桥）→ Al₂Cl₆ 的 3c-4e（氯桥）→ 对比电子数
3. **Lewis 酸性**：BF₃ → H₃BO₃（接受 OH⁻）→ 缺电子如何变成「酸」
4. **饱和产物**：[BH₄]⁻、[BF₄]⁻ 恰好 8 电子 → 稳定还原剂

### 12.2 学生典型认知误区

| 误区 | 教学干预 |
|:---|:---|
| "缺电子 = 缺稳定性" | 用 [BH₄]⁻（稳定还原剂）与 BH₃（不存在）对比 |
| "H₃BO₃ 是三元酸" | 投影 H₃BO₃ vs H₃PO₃ 结构，找「哪个 H 能电离」 |
| "BF₃ 和 BCl₃ 水解一样" | BF₃ 水解不完全（F 强、生成 HBF₄）；BCl₃ 水解彻底 |

## 十三、竞赛拓展

1. **Wade 规则与硼烷簇合物**：closo（n+1 电子对）、nido（n+2）、arachno（n+3）。如 [B₁₂H₁₂]²⁻ 闭合二十面体；B₅H₉ 四方锥（nido）。碳硼烷是 C 取代衍生物。
2. **超酸化学**：BF₃ + HF → H[BF₄]（强酸）；SbF₅ + HF → HSbF₆、与 HSO₃F 成魔酸（Magic Acid）。Lewis 酸强度 SbF₅ > BF₃ > AlCl₃。
3. **无机苯的芳香性**：B₃N₃H₆ 与 C₆H₆ 等电子，但 B—N 极性使亲电取代活性不同；H 加到 N、Cl 加到 B（电负性控制）——有机规则迁移到无机的经典交叉。
4. **Ziegler-Natta 催化**：Al(C₂H₅)₃ 等缺电子烷基铝是烯烃聚合催化剂的重要组分——缺电子化学的工业应用。
