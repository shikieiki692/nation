# 非整比化合物

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[17-常见晶体结构]]

## 一、定义

非整比化合物指组成中各元素原子个数比不能用简单小整数严格表示的晶体化合物，常写成 A₁₋ₓB、AB₁₋ₓ 或 AₓB_y。

**一句话本质**：非整比不是"比例写错了"，而是**晶体的本征缺陷在组成上的表现**——骨架（结构框架）依然是确定的，只是部分格位被空位占据、或被间隙原子填充、或由变价离子混合占位，使表观原子比偏离理想整比。**"结构有序、组成可变"**八个字是非整比化合物区别于"杂质污染"的核心。

## 二、成因

- 点缺陷导致某类原子或离子出现空位（Schottky / Frenkel 缺陷及变体）
- 变价元素通过不同价态共存来维持电中性（如 Fe²⁺/Fe³⁺ 混占）
- 过渡金属化合物中，金属-金属作用和局部配位环境允许偏离理想整比（d 电子成键补偿——见 NbO）

**热力学根源**：完美晶体只在 0 K 存在；任意 T > 0 时缺陷的构型熵（ΔS_defect > 0）使"含一定浓度缺陷的晶体"比"完美晶体"自由能更低——所以**非整比是热力学必然**，x 随温度升高而增大。"整比是理想极限，非整比是常态"（高温更甚）。

## 三、典型体系速查

| 体系 | 写法 | 缺陷类型 | 价态补偿 | 实际意义 |
|---|---|---|---|---|
| 方铁矿 | Fe₁₋ₓO（x≈0.05~0.12） | Fe 位空位 | Fe²⁺ → Fe³⁺（每空位关联 2 个 Fe³⁺） | 钢铁冶炼中间物；缺陷催化 |
| 磁黄铁矿 | Fe₁₋ₓS（NiAs 型衍生） | Fe 位空位 | Fe³⁺ 混入 | 经典 NiAs 缺位变体（见 [[NiAs型结构]]） |
| 氢化钛/钯 | TiHₓ、PdHₓ（x<2） | H 入隙（八面体/四面体隙） | —（金属储氢） | 储氢材料、燃料电池 |
| 嵌入型锂氧化物 | Li₁₋ₓCoO₂、LiₓFePO₄ | Li 脱嵌 | Co³⁺/Co⁴⁺ | 锂电池正极（容量=可脱嵌 x） |
| 缺氧氧化物 | TiO₂₋ₓ、WO₃₋ₓ、CeO₂₋ₓ | O 空位 | 阳离子部分还原 | 催化（CeO₂ 储放氧）、变色材料 |
| 间隙碳/氮化物 | TiCₓ、Fe₄N 类 | C/N 入隙 | — | 硬质合金、磁性材料 |

**读表要点**：金属侧空位 → 靠变价补偿（Fe₁₋ₓO、Fe₁₋ₓS）；非金属侧空位 → 靠阳离子还原补偿（TiO₂₋ₓ）；间隙/嵌入 → 宿主价态调节或金属储氢/储锂——三种"组成可变"各有电荷平衡机制，做题时**写电荷守恒是关键动作**。

## 四、课堂要点

- 非整比不等于"随便写比例"，本质上仍是有确定结构框架的缺陷晶体
- 做题时常结合电荷守恒、平均氧化数、晶胞占位率一起判断
- 要和[[混合价态]]区分：二者相关但不完全等同

**与混合价态的分工**：非整比管"**原子数比**不整"（Fe₁₋ₓS 的 Fe:S ≠ 1:1）；混合价态管"**同一元素多种价态**"（Fe²⁺ 与 Fe³⁺ 共存）。两者常常**同时出现**（Fe₁₋ₓO 里 Fe³⁺/Fe²⁺ 混占），但概念正交——一个非整比体系必然伴随变价补偿，但混合价态也可出现在整比化合物（如 Fe₃O₄ = FeO·Fe₂O₃，整比但混价）。

## 五、定量计算（电荷守恒定平均氧化态）

**例题**：Fe₁₋ₓS 中 x = 0.125（S²⁻ 为 −2），求 Fe 的平均氧化态。
**解**：化学式 Fe₀.₈₇₅S → 电荷守恒：0.875 × v + 1 × (−2) = 0 → v = 2/0.875 = **+2.29**
**含义**：平均氧化态介于 +2 与 +3 之间 → 说明 Fe²⁺ 与 Fe³⁺ 共存（设 Fe³⁺ 占比 y：2(1−y)+3y = 2.29 → y ≈ 0.29，即约 29% 的 Fe 为 +3）。

**进阶（由密度反推 x）**：测得晶体密度 ρ 与晶胞参数 a（已知结构），由"晶胞实际质量 = ρ·a³/N_A"反推**实际占位原子数**，与理想结构占位数之差即空位浓度 x——"密度亏缺 = 空位证据"是 XRD+密度联合测 x 的标准方法。

## 六、与 NbO 型有序缺位的对照（防混）

| | Fe₁₋ₓO（无序缺位） | NbO（有序缺位） |
|---|---|---|
| 缺位分布 | 随机（固溶体式） | 有序（超结构） |
| 化学式 | 非整比（x 可连续变） | 恒 1:1（缺位成对保持整比） |
| 补偿机制 | Fe³⁺ 电荷补偿 | Nb–Nb 金属键（Nb₆ 簇） |
| 归属 | **非整比化合物**（本页主题） | **有序缺位新结构**（[[NbO型结构]]） |

**关键区分**：非整比 ≠ 一切"有缺陷的结构"——NbO 缺位有序且成对（3 Nb + 3 O/晶胞），化学式仍是整比的 NbO，属**新结构类型**而非非整比固溶体；Fe₁₋ₓO 缺位随机、x 连续可调，才是"非整比"的正宗。**"缺位有序且化学式整比 → 新结构；缺位无序且 x 可调 → 非整比"**是考场判据。

## 易错点（补充判据）

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 非整比化合物是"不纯/混合物" | 非整比是纯净物的本征缺陷，单相均一 | 缺陷浓度由热力学决定（T 的函数），非杂质引入 |
| FeS 与 Fe₁₋ₓS 当两种物质 | Fe₁₋ₓS 是 FeS 结构的缺位变体，x 是空位量尺 | 同一 NiAs 骨架，x 连续可变 → 固溶体系列 |
| 所有化合物都整比 | 高温/变价体系普遍非整比 | 整比是 0 K 理想，Fe₁₋ₓO 室温 x≈0.05 已是常态 |
| 非整比 = 混合价态 | 非整比管原子数比、混价管价态种类，二者可独立 | Fe₃O₄ 整比但混价；Fe₁₋ₓS 非整比且混价——概念正交 |
| 一切缺陷结构都叫非整比 | 有序缺位（NbO/TiO）化学式整比是新结构 | 缺位有序+整比 → 新结构；缺位无序+x 可调 → 非整比 |
| x 任意大/负（过度外推） | x 受结构稳定性与电荷平衡约束有范围 | Fe₁₋ₓO 的 x 只在 ~0.05-0.12 区间稳定，超出即分相 |
| 忽略电荷补偿直接写式 | 每个空位/间隙都须电荷平衡（变价/间隙离子） | 写 Fe₁₋ₓO 后必须问"谁补电荷"——Fe³⁺ 占比可算 |

## 🎯 教学视角（补充）

### 学习路径建议

**前置知识**：化学计量化合物概念、离子晶体结构、混合价态。

**推荐教学顺序**：
1. 从"为什么 Fe₁₋ₓS 不是 FeS？"出发 → 引出点缺陷概念
2. 非整比的本质：晶体中存在空位或间隙原子 → 原子比例偏离简单整数比
3. 与混合价态的区别：混合价态是"同一元素不同氧化态"，非整比是"原子数比例不整"
4. 典型例子：Fe₁₋ₓS（磁黄铁矿）→ NiAs 结构中部分 Fe 位空缺
5. 实际意义：非整比化合物在催化、电池、半导体中的应用

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "非整比化合物是不纯的" | 非整比化合物是纯净物，不是混合物——缺陷是晶体结构的本征特征 | "缺陷是天生的，不是杂质" |
| "FeS 和 Fe₁₋ₓS 是两种物质" | Fe₁₋ₓS 是 FeS 的非整比变体，化学式中 x 反映了空位浓度 | "x 是空位的量尺" |
| "所有化合物都是整比的" | 实际上大多数固态化合物在高温下都有一定程度的非整比性（热力学平衡缺陷） | "整比是理想，非整比是常态" |

### 入门级例题

**例题**：Fe₁₋ₓS 中，当 x = 0.125 时，S²⁻ 的氧化态为 -2。求 Fe 的平均氧化态。

**引导思路**：
1. 化学式：Fe₀.₈₇₅S → 电荷平衡：0.875 × (Fe 氧化态) + 1 × (-2) = 0
2. Fe 平均氧化态 = 2/0.875 = +2.286
3. 说明部分 Fe³⁺ 存在 → 非整比 + 混合价态共存

### 与真实世界的联系

- **锂电池正极材料**：Li₁₋ₓCoO₂ 是典型的非整比化合物 → 锂的脱嵌量 x 决定电池容量
- **颜色宝石**：蓝宝石（Al₂O₃ 中掺微量 Fe²⁺/Ti⁴⁺）的颜色来自非整比缺陷
- **催化剂**：Fe₁₋ₓO 的缺陷位是 CO₂ 加氢催化活性位

> **记忆锚**：非整比四问——谁的格位空了（金属/非金属）？谁补电荷（变价/间隙）？x 范围多大（受稳定约束）？有序还是无序（新结构 vs 固溶体）？四问答完即得分。

## 竞赛考察要点

1. **化学式推导**：给 Fe₁₋ₓS 求平均氧化态 / Fe³⁺ 占比（电荷守恒）。
2. **密度反推 x**：ρ、a、结构已知 → 反推空位浓度（五节进阶）。
3. **概念辨析**：非整比 vs 混合价态 vs 有序缺位（NbO）三连辨。
4. **体系归类**：Fe₁₋ₓO（无序+变价补偿）、TiO₂₋ₓ（氧空位）、PdHₓ（间隙）、Li₁₋ₓCoO₂（嵌入）。
5. **NiAs 衍生**：磁黄铁矿 Fe₁₋ₓS 的空位位置与 NiAs 结构的关系（联动 [[NiAs型结构]]）。
6. **热力学解释**：缺陷构型熵 → 任意 T>0 都非完美晶体 → 非整比必然。

## 九、关键结论速记

- 非整比 = 本征点缺陷在组成上的表现："结构有序、组成可变"。
- 三种电荷补偿：金属空位→变价；非金属空位→阳离子还原；间隙/嵌入→宿主价态或储氢储锂。
- 与混价正交：非整比管原子比、混价管价态；Fe₃O₄ 整比但混价、Fe₁₋ₓS 两者都有。
- 与有序缺位（NbO）分界：无序+x 可调 → 非整比；有序+整比 → 新结构。
- 数值方法：电荷守恒求平均氧化态；ρ·a³/N_A 反推 x。
- 热力学：缺陷构型熵使非整比成为 T>0 的常态（x 随 T 增）。
- 收尾自检：能由 x 求平均氧化态与 Fe³⁺ 占比、能辨非整比/混价/NbO 三概念、能举六个体系——本页达标。
