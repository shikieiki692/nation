# 三价铬水解

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述
- Cr³⁺ 在水溶液中不是简单静止的单一粒子，而会发生连续水解和聚合
- 这是铬化学中最常见也最容易被简化过头的一条主线

**一句话本质**：Cr³⁺ 的高电荷（+3）+ 中等半径使其水合离子 [Cr(H₂O)₆]³⁺ 呈强酸性（pKa₁ ≈ 4），水配体逐个失去质子变成羟基配体（水解），相邻羟合单元再脱 H₂O 成羟桥/氧桥（聚合）——"水解-羟合-聚合"三级联动，产物随 pH 与时间演化。

**与 Al³⁺ 的对比**：Al³⁺ 也水解聚合，但 Al 是 d⁰、配体交换快（动态平衡瞬间建立）；Cr³⁺ 是 d³、配体交换**慢**（动力学惰性）——所以 Cr 的水解产物"冻得住"、可分离，也正因慢，放置几天颜色还在变（老化）。"Al 快 Cr 慢"是两元素水解行为差异的总开关。

## 二、核心要点

### 2.1 水解阶梯（逐步脱质子）

[Cr(H₂O)₆]³⁺（紫色）→ 逐级水解：

[Cr(H₂O)₆]³⁺ + H₂O ⇌ [Cr(H₂O)₅(OH)]²⁺ + H₃O⁺（pKa₁ ≈ 4）
[Cr(H₂O)₅(OH)]²⁺ ⇌ [Cr(H₂O)₄(OH)₂]⁺ + H₃O⁺（pKa₂ ≈ 6.5）
…… → Cr(OH)₃·nH₂O（灰绿胶状沉淀）

**pH 依赖**：pH < 3 时 Cr³⁺ 基本以 [Cr(H₂O)₆]³⁺ 存在（紫）；pH 3-6 水解成羟合阳离子（绿）；pH ~6-12 沉淀 Cr(OH)₃（灰绿）；pH > 12 溶解为 [Cr(OH)₄]⁻（亮绿——**Cr(OH)₃ 两性**）；浓强碱/长时间可得 [Cr(OH)₆]³⁻。

### 2.2 聚合（olation 羟桥 → oxolation 氧桥）

水解到一定程度，羟合单元间脱 H₂O 形成**羟桥（–OH–）**双聚/多聚：

2[Cr(H₂O)₅(OH)]²⁺ ⇌ [(H₂O)₄Cr(μ-OH)₂Cr(H₂O)₄]⁴⁺ + 2H₂O（羟桥二聚）

继续失 H⁺/老化，羟桥可转**氧桥（–O–）**（oxolation）。聚合使溶液"变稠/变绿/变浑"，是铬鞣（皮革）的原理——胶原蛋白羧基与 Cr 多聚体交联。

### 2.3 配体竞争与颜色

- [Cr(H₂O)₆]³⁺ 紫、[Cr(H₂O)₅Cl]²⁺/[Cr(H₂O)₄Cl₂]⁺ 绿——**CrCl₃·6H₂O 有紫/绿异构体**（水合异构）即源于配体场不同
- 强配体（acac⁻、草酸根、EDTA）能"抢走"水解产物的配位位并抑制聚合：[Cr(acac)₃] 中性螯合物稳定、草酸根形成 [Cr(C₂O₄)₃]³⁻
- 加氨水：先沉淀 Cr(OH)₃，过量氨水不像对 Zn 那样溶解（不形成稳定氨配合物）——与 Al³⁺ 一致、与 Zn²⁺/Cu²⁺ 相反

### 2.4 阴离子渗透（浓碱下的深化）

Cr(OH)₃ 溶于过量强碱：Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻（亮绿，亚铬酸根 CrO₂⁻ 是脱水写法）

浓 NaOH + 加热可进一步形成 [Cr(OH)₆]³⁻——"阴离子渗透"指 OH⁻ 进入配位层逐步取代水/羟基的过程；实际以 [Cr(OH)₄]⁻ 为常见终点（相当于 CrO₂⁻·2H₂O）。

## 四、现象-过程对照表（写现象题用）

| 操作 | 现象 | 主导过程 |
|---|---|---|
| CrCl₃ 溶于水 | 紫→绿（放置） | [Cr(H₂O)₆]³⁺ 水解成羟合阳离子 |
| 加热 Cr³⁺ 溶液 | 加快变绿 | 水解吸热？实际加热加速配体交换与聚合（动力学） |
| 逐滴加 NaOH 至过量 | 灰绿↓ → 溶解亮绿 | 沉淀 Cr(OH)₃ → 两性溶解 [Cr(OH)₄]⁻ |
| 加 NH₃·H₂O（过量） | 灰绿↓ 不溶 | 不形成氨配合物（同 Al，异 Zn） |
| 加草酸/EDTA | 溶液转紫红/稳定 | 配体取代竞争，抑制水解聚合 |
| 久置（数天） | 绿加深、可能出沉淀 | 老化：羟桥 → 氧桥聚合（动力学惰性慢过程） |

## 五、典型计算与辨析

**例 1**：0.1 mol/L CrCl₃ 溶液 pH 约多少？（pKa₁ ≈ 4）
**解**：近似 c/Ka = 0.1/10⁻⁴ = 1000 ≥ 500 → [H⁺] = √(10⁻⁴×0.1) = 3.2×10⁻³ → pH ≈ 2.5。**要点**：Cr³⁺ 溶液明显酸性（不靠加酸自己就 pH ~2-3），配制高浓度溶液需先酸化防聚合。

**例 2（两性判断）**：Cr(OH)₃ 与 Al(OH)₃ 的两性有何异同？
**答**：都溶强碱成 [M(OH)₄]⁻；差别在动力学——Al 瞬间平衡，Cr 慢且需要加热/放置；Cr(OH)₃ 灰绿、Al(OH)₃ 白；Cr(OH)₃ 不溶氨水、Al(OH)₃ 也不溶——鉴别 Al³⁺/Cr³⁺ 不能靠氨水，要靠 Cr 的颜色与氧化（碱性 H₂O₂ 氧化 Cr(III) → CrO₄²⁻ 黄色）。

## 六、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| Cr³⁺ 在水中就是 [Cr(H₂O)₆]³⁺ | 那是低 pH 极限；实际连续水解成羟合/聚合体 | pH > 3 就以羟合阳离子为主；"动态过程非静止离子" |
| 水解 = 分解 | 水解是配体交换（H₂O → OH⁻），中心离子不变 | 配平只动 H₂O/OH⁻/H⁺，Cr 始终 +3 |
| 加碱必得 Cr(OH)₃ 沉淀 | 过量强碱溶解沉淀（两性） | 适量碱沉淀、过量碱 [Cr(OH)₄]⁻ 亮绿溶解 |
| Cr³⁺ 水解像 Al³⁺ 一样快 | Cr³⁺ d³ 惰性、配体交换慢——水解聚合需时间 | 溶液放置变绿/老化；Al 是 d⁰ 快交换 |
| 氨水能溶 Cr(OH)₃ | Cr 不形成稳定氨配合物（不像 Zn/Cu） | 氨水只沉淀不溶解——用氨水区分 Cr³⁺ 与 Zn²⁺ |
| 把水解产物颜色当 Cr 价态色 | 紫/绿/灰绿都是 +3 不同配体场/聚合态 | 要变价须氧化还原：Cr³⁺ 绿 + H₂O₂/碱性 → CrO₄²⁻ 黄 |

## §12 教学视角

### 学生常见认知误区
- **误区1：「Cr³⁺ 在水中就是 [Cr(H₂O)₆]³⁺」** → 实际上 Cr³⁺ 会发生连续水解，产物随 pH、温度和放置时间变化 → **口诀：Cr³⁺ 在水中是"动态过程"，不是静止的单一离子**
- **误区2：「水解就是分解」** → 水解是配体交换（H₂O → OH⁻），不是化学键断裂分解 → **口诀：水解 = 水配体失去质子变成羟基配体，中心离子不变**
- **误区3：「加碱就能得到 Cr(OH)₃ 沉淀」** → 过量强碱会溶解 Cr(OH)₃ 生成 [Cr(OH)₄]⁻ → **口诀：Cr(OH)₃ 两性，过碱溶解，适量碱才沉淀**

### 入门级例题
**题目**: 向 0.1 mol/L CrCl₃ 溶液中逐滴加入 NaOH 溶液，描述现象并写出各阶段反应。
**分析**: Cr³⁺ 先水解，加碱后生成 Cr(OH)₃ 沉淀，过量碱溶解沉淀。
**解答**: 
- 初始：[Cr(H₂O)₆]³⁺ 呈紫色，放置后水解变绿
- 加少量碱：[Cr(H₂O)₅(OH)]²⁺ → [Cr(H₂O)₄(OH)₂]⁺ → Cr(OH)₃↓（灰绿色沉淀）
- 加过量碱：Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻（沉淀溶解，绿色溶液）
**反思**: Cr(III) 的水解系列是"先逐步脱质子，再沉淀，过碱溶解"的完整过程。

### 与现实/直觉的连接
Cr³⁺ 的水解就像一个"逐步变色的调色盘"——随着 pH 升高，从紫色（[Cr(H₂O)₆]³⁺）→绿色（水解产物）→灰绿沉淀（Cr(OH)₃）→绿色溶液（[Cr(OH)₄]⁻）。这个连续变化在实验室中非常直观，也是理解配位化学中配体场强度的绝佳案例。

### 教学建议
1. **现场实验演示**：向 CrCl₃ 溶液中滴加 NaOH，观察颜色从紫→绿→沉淀→溶解的全过程
2. **画水解阶梯图**：用"阶梯"图展示逐步脱质子过程，每一步对应一个颜色变化
3. **强调 Cr(III) 的惰性**：Cr(III) 是 d³ 构型，配体交换速率很慢，水解需要时间
4. **对比 Al³⁺**：Al(OH)₃ 也两性，但 Al³⁺ 无色（d⁰），Cr³⁺ 有色（d³），对比教学加深理解
5. **联系电镀与鞣革**：Cr(III) 水解产物在鞣革工业中有重要应用

> **记忆锚**：Cr³⁺ 五步曲——紫（水合）→绿（水解）→灰绿（沉淀）→亮绿（过碱溶）；Al 快 Cr 慢、d³ 惰性冻住中间态；想见黄，加碱氧化（CrO₄²⁻）。

## 应用与工业（水解化学的用武之地）

- **铬鞣（皮革）**：碱式硫酸铬 Cr(OH)SO₄ 水解聚合的多核 Cr(III) 与皮胶原羧基交联——"铬鞣革"占全球皮革 85%；废鞣液 Cr(III) 回收是环保重点。
- **镀铬前处理**：镀硬铬/装饰铬的镀液含 Cr(III) 体系（环保替代 Cr(VI) 镀液）；Cr³⁺ 水解控制镀液 pH 稳定。
- **绿色化学**：Cr(VI)（致癌）→ Cr(III) 还原治理——酸性 FeSO₄/亚硫酸盐把 CrO₄²⁻ 还原成 Cr³⁺ 再碱沉 Cr(OH)₃。
- **分析化学**：Cr³⁺ 在碱性 H₂O₂ 中氧化为 CrO₄²⁻ 后光度法定量——依赖水解-氧化两步衔接。
- **颜料**：Cr₂O₃（铬绿）由重铬酸铵热分解制得——(NH₄)₂Cr₂O₇ 加热"火山喷发"实验产物即 Cr₂O₃。

**工业主线记忆**：铬铁矿 → Na₂CrO₄ → Cr₂O₇²⁻（氧化/酸化）→ 还原 Cr³⁺ → 碱沉/鞣革——六价管氧化与颜料、三价管鞣革与镀液，水解化学嵌在"三价"这一站。

## 七、竞赛考察要点
1. **现象描述题**：给操作写颜色/沉淀序列（四节对照表）。
2. **两性方程式**：Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻；与酸反应成 Cr³⁺。
3. **氧化衔接**：碱性 H₂O₂ 氧化 Cr(III) → CrO₄²⁻（黄）——检验 Cr 的关键步骤（母页 [[铬]] 展开）。
4. **鉴别题**：Al³⁺/Cr³⁺ 区分（氨水都不溶 → 用 NaOH+H₂O₂ 看黄 vs 无）。
5. **水解 pH 计算**：由 pKa₁ 估算 Cr³⁺ 溶液酸度（五节例 1）。
6. **配体竞争**：草酸/EDTA/acac⁻ 抑制水解聚合的配位化学解释。

## 八、关键结论速记

- Cr³⁺ = 高电荷 + d³ 惰性 → 水解（逐步脱质子）+ 聚合（羟桥→氧桥）+ 两性（过碱溶）。
- 颜色线：紫 [Cr(H₂O)₆]³⁺ → 绿羟合 → 灰绿 Cr(OH)₃ → 亮绿 [Cr(OH)₄]⁻（全是 +3）。
- 与 Al 三异：Al 白 Cr 灰绿、Al 快 Cr 慢、Al 无 Cr 有色——鉴别靠氧化出 CrO₄²⁻ 黄色。
- 氨水只沉不溶（无氨配合物）——区分 Cr³⁺/Zn²⁺ 的钥匙。
- 收尾自检：能写水解阶梯四步、两性两方程、说清"为什么 Cr 水解产物放几天还在变"——本页达标。
- 颜色双查：紫 ↔ 绿变化先问"pH 还是配体"——稀释/加热变绿多为水解聚合，加 Cl⁻/配体变绿是配体场替换——两条路殊途同"绿"，机理不同。
- 与 Cr(VI) 分界：本页一切现象都在 +3 内打转；要出黄/橙（CrO₄²⁻/Cr₂O₇²⁻）必须有氧化剂——答题先圈价态再选机理。
- 老化工记忆：新配 CrCl₃ 紫、放久绿、煮沸更绿——"新紫老绿"四字可用于判断溶液年龄（老化 = 聚合推进）。
- 最后一题自测：给 CrCl₃ 溶液 ①加氨水 ②加过量 NaOH ③加 NaOH+H₂O₂，分别写现象——①灰绿沉淀不溶 ②沉淀溶亮绿 ③氧化成黄色 CrO₄²⁻；③是 Cr³⁺ 鉴定招牌反应。
- 若题给 Cr(OH)₃ 与 Al(OH)₃ 混合沉淀要分离——加过量 NaOH：Al 溶 [Al(OH)₄]⁻、Cr 溶 [Cr(OH)₄]⁻ 都溶（不行）；须先碱性 H₂O₂ 把 Cr 氧化成 CrO₄²⁻ 再加 Ba²⁺ 沉 BaCrO₄ 或酸化分步——两性相似时的分离要借价态差异。
