# 三价铬水解

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述
- `Cr3+` 在水溶液中不是简单静止的单一粒子，而会发生连续水解和聚合
- 这是铬化学中最常见也最容易被简化过头的一条主线

## 二、核心要点
- 常见教学口径可概括为：水合 → 水解 → 羟合 → 氧合 → 阴离子渗透
- 溶液颜色会随放置、配体和酸度变化而改变
- 强配体如 `acac-`、草酸根可与水解竞争，改变最终产物

## §12 教学视角

### 学生常见认知误区
- **误区1：「Cr³⁺ 在水中就是 [Cr(H₂O)₆]³⁺」** → 实际上 Cr³⁺ 会发生连续水解，产物随 pH、温度和放置时间变化 → **口诀：Cr³⁺ 在水中是“动态过程”，不是静止的单一离子**
- **误区2：「水解就是分解」** → 水解是配体交换（H₂O → OH⁻），不是化学键断裂分解 → **口诀：水解 = 水配体失去质子变成羟基配体，中心离子不变**
- **误区3：「加碱就能得到 Cr(OH)₃ 沉淀」** → 过量强碱会溶解 Cr(OH)₃ 生成 [Cr(OH)₄]⁻ → **口诀：Cr(OH)₃ 两性，过碱溶解，适量碱才沉淀**

### 入门级例题
**题目**: 向 0.1 mol/L CrCl₃ 溶液中逐滴加入 NaOH 溶液，描述现象并写出各阶段反应。
**分析**: Cr³⁺ 先水解，加碱后生成 Cr(OH)₃ 沉淀，过量碱溶解沉淀。
**解答**: 
- 初始：[Cr(H₂O)₆]³⁺ 呈紫色，放置后水解变绿
- 加少量碱：[Cr(H₂O)₅(OH)]²⁺ → [Cr(H₂O)₄(OH)₂]⁺ → Cr(OH)₃↓（灰绿色沉淀）
- 加过量碱：Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻（沉淀溶解，绿色溶液）
**反思**: Cr(III) 的水解系列是“先逐步脱质子，再沉淀，过碱溶解”的完整过程。

### 与现实/直觉的连接
Cr³⁺ 的水解就像一个“逐步变色的调色盘”——随着 pH 升高，从紫色（[Cr(H₂O)₆]³⁺）→绿色（水解产物）→灰绿沉淀（Cr(OH)₃）→绿色溶液（[Cr(OH)₄]⁻）。这个连续变化在实验室中非常直观，也是理解配位化学中配体场强度的绝佳案例。

### 教学建议
1. **现场实验演示**：向 CrCl₃ 溶液中滴加 NaOH，观察颜色从紫→绿→沉淀→溶解的全过程
2. **画水解阶梯图**：用“阶梯”图展示逐步脱质子过程，每一步对应一个颜色变化
3. **强调 Cr(III) 的惰性**：Cr(III) 是 d³ 构型，配体交换速率很慢，水解需要时间
4. **对比 Al³⁺**：Al(OH)₃ 也两性，但 Al³⁺ 无色（d⁰），Cr³⁺ 有色（d³），对比教学加深理解
5. **联系电镀与鞣革**：Cr(III) 水解产物在鞣革工业中有重要应用
