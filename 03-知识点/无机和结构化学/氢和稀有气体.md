# 氢和稀有气体

## 核心概念

### 氢气部分

**氢的基本特征**
- 氢是自然界中最简单的原子，仅含1个质子和1个电子，电子排布为 $1s^1$
- 氢气（H₂）是最简单的分子，是理解化学键的基础模型
- 氢在周期表中的位置存在争议：第1族（失电子形成H⁺）、第17族（得电子形成H⁻）、第14族（s¹半满构型）
- IUPAC建议将其归为第1族元素

**氢的丰度**
- 宇宙丰度：占宇宙总质量的76%，是含量最丰富的元素
- 地壳分布：质量分数仅1%，但原子比例达15.4%
- 自然界中主要以化合态存在（H₂O、石油、天然气等有机物）

**氢同位素性质**
- H₂、D₂、T₂的熔点依次升高：13.96K < 18.73K < 20.63K
- 键能依次增强：436 < 443 < 447 kJ/mol
- 影响因素：中子效应（核间斥力减弱）、分子变形性（范德华力增强）、量子效应（零点能）

### 稀有气体部分

**稀有气体基本性质**
- 18族元素，常温常压下为单原子分子气体
- 历史突破：1962年Bartlett首次发现稀有气体化合物

**第一例稀有气体化合物的发现**
- 研究背景：1960年发现PtF₆的氧化性强于F₂
- 反应路径：Pt + F₂ → PtF₆；PtF₆ + O₂ → O₂⁺PtF₆⁻
- 关键实验：I(O₂) > I(Xe)，尝试 Xe + PtF₆ → Xe⁺PtF₆⁻
- 产物特征：室温下得到橙黄色固体，不溶于CCl₄，证明是离子化合物

## 关键反应

### 氢气制备反应

**实验室制备**
- 活泼金属+水：$Ca + 2H_2O → Ca(OH)_2 + H_2↑$
- 活泼金属+酸：$Fe + H_2SO_4 → FeSO_4 + H_2↑$
- 两性金属+碱：$2Al + 2NaOH + 2H_2O → 2NaAlO_2 + 3H_2↑$
- 活泼金属氢化物+水：$LiH + H_2O → LiOH + H_2↑$
- 氢化铝锂：$LiAlH_4 + 4H_2O → LiOH + Al(OH)_3 + 4H_2↑$

**工业大规模生产**
- 水的电解：$2H_2O \xrightarrow{电解} 2H_2↑ + O_2↑$
- 天然气转化：$CH_4(g) + H_2O(g) → CO + 3H_2$（1100℃）
- 水煤气法：$C(s) + H_2O(g) \xrightarrow{1000℃} CO(g) + H_2(g)$

### 氢气化学反应

**与非金属反应**
- 与氟：-250℃即可剧烈反应（所有非金属中活性最高）
- 与氧/氯：点燃或光照引发剧烈反应，有爆炸风险
- 与溴：需加热至400℃
- 与氮：需>500℃高温或电弧条件，通常需要催化剂

**与金属反应**
- 碱金属/碱土金属：形成离子型氢化物（如 $Ca + H_2 → CaH_2$）
- 过渡金属：形成共价型或间隙型氢化物

**与氧化物反应**
- 还原成单质：$MnO + H_2 → Mn + H_2O$（500℃以下）
- 得到氢化物：$La_2O_3 + 6H_2 → 2LaH_3 + 3H_2O$

**与卤化物反应**
- 检测应用：1% PdCl₂溶液遇H₂立即生成Pd黑
- 还原成单质：Pt、Rh、Pd、Fe、Ir、Ag等卤化物在100-200℃反应

### 稀有气体化合物反应

**氟化氙制备**
- 三级平衡体系：
  - $Xe + F_2 ⇌ XeF_2$
  - $XeF_2 + F_2 ⇌ XeF_4$
  - $XeF_4 + F_2 ⇌ XeF_6$
- 反应条件：>250℃，温度、压力、投料比影响产物分布

**氟化氙水解**
- XeF₂：直接氧化还原 $XeF_2 + H_2O → Xe + \frac{1}{2}O_2 + 2HF$
- XeF₄：歧化+氧化还原 $6XeF_4 + 12H_2O → 2XeO_3 + 4Xe + 3O_2 + 24HF$
- XeF₆：分步水解且价态不变

## 规律与趋势

### 氢气成键特点

**七种成键形式**
1. **共价单键**：H₂、HCl、H₂O、NH₃、CH₄（σ键，键能400-500 kJ/mol）
2. **离子键**：
   - 作为质子（H⁺）：电离能ΔH = 1312 kJ/mol，存在于H₃O⁺、NH₄⁺等
   - 作为氢负离子（H⁻）：电子亲和能ΔH = -72.8 kJ/mol
3. **金属键**：250 GPa高压+27K低温下形成
4. **氢键**：
   - 常规氢键：X-H···Y（X,Y=O,N,F），键能20-30 kJ/mol
   - 特殊案例：[F-H-F]⁻对称氢键（键能212 kJ/mol）
5. **二氢键**：X-H···H-E（E=B,M），使熔点异常升高
6. **多中心桥键**：三中心两电子键（如B-H-B）
7. **负氢配位键**：H⁻→M⁺共价σ配位键

### 氟化氙性质规律

**物理性质异常**
- 熔点：XeF₂(117℃) < XeF₄(129℃) > XeF₆(49.5℃)
- 键能：XeF₂ > XeF₄ > XeF₆
- 键长：XeF₂ > XeF₄ > XeF₆（通常键长与键能呈反比，此处为特例）

**溶解性质**
- XeF₂：可溶于HF但不电离
- XeF₄：难溶于HF
- XeF₆：可溶且发生电离：$XeF_6 + HF ⇌ XeF_5^+ + HF_2^-$

**化学性质**
- 氧化能力：XeF₆ > XeF₄ > XeF₂
- 氟给予体能力：XeF₆ > XeF₂ > XeF₄
- 氟接受体：仅XeF₆可作受体

## 典型应用

### 竞赛中的典型应用

**氢气检测**
- 1% PdCl₂溶液遇H₂立即生成Pd黑，可用于氢气检测

**氢化铝锂的特殊应用**
- 野外制氢：定量产氢且纯度高，1mol产生4mol H₂
- 还原性调节：通过醇解反应可控制还原程度
- 氨解反应：与氨气反应生成四氨基铝锂，取代程度可调

**氟化氙的氟化剂应用**
- 苯氟化：$C_6H_6 + XeF_2 \xrightarrow{CCl_4} C_6H_5F + Xe$（产率约68%）
- 选择性：易氟化Si-Cl键，不易氟化Si-C或Si-H键

**高氙酸盐的分析应用**
- 稳定形式：Na₄XeO₆·6H₂O（加热至500℃才分解）
- 检测对象：Mn²⁺、Fe²⁺、Cr³⁺
- 检测方法：
  - 锰：直接显色（高锰酸根）
  - 铁：加邻菲罗啉显色
  - 铬：加二苯卡巴肼显色

**超纯氢气制备**
- 通过U + 3H₂ ⇌ UH₃可逆反应制备
- 用途：半导体、光伏等需要超高纯氢气的领域

### 关键结构特征

**氢化物结构**
- 碱金属氢化物（NaH等）：NaCl型结构
- 碱土金属氢化物（CaH₂、SrH₂、BaH₂）：变形PbCl₂结构
- 例外：MgH₂（金红石结构）、BeH₂（共价化合物）

**氟化氙分子构型**
- XeF₂：直线型（VSEPR：三角双锥，10电子）
- XeF₄：平面四边形（VSEPR：AX₄E₂型）
- XeF₆：变形八面体

**高氙酸盐结构**
- 高氙酸根（XeO₆⁴⁻）：严格对称的正八面体构型

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解氢和稀有气体的通性，再学习它们的重要化合物，最后掌握它们的特殊性质和应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 氢只能形成+1价化合物 | 氢也能形成-1价的氢化物（如NaH） |
| 稀有气体都不能形成化合物 | 重稀有气体（Kr、Xe、Rn）可以形成化合物 |
| 氢的化合物都很稳定 | 氢化物的稳定性差异很大 |

### 15.3 入门级例题

**题目**：解释为什么Xe能形成化合物而He不能。

**解答**：Xe的原子半径大，电离能低，价电子容易被激发参与成键。而He的原子半径小，电离能高，价电子很难参与成键。

### 15.4 与现实世界的联系

1. **核工业**：氢的同位素用于核聚变
2. **照明技术**：稀有气体用于制造霓虹灯
3. **医疗领域**：氙气用作麻醉剂
