# 配体场理论

## 核心概念

- 从轨道相互作用角度将配体分为三类
- 配体场强度决定分裂能大小，影响配合物的颜色和磁性
- 轨道作用顺序：先形成σ键再形成π键

## 配体分类

### 1. 仅σ给体（sigma donor only）
- 典型例子：H₂O, NH₃
- 只提供σ电子对给金属
- 中等分裂能

### 2. σ给体 + π受体（π酸配体）
- 典型例子：CO, CN⁻, NO, PR₃
- 既提供σ电子，又接受金属d电子进入π*轨道
- 强分裂能（光谱化学序列中位于高端）

### 3. 强σ给体 + π给体
- 典型例子：F⁻, Cl⁻, Br⁻, I⁻
- 提供σ电子的同时，也向金属提供π电子
- 弱分裂能（光谱化学序列中位于低端）

## 规律与趋势

### 光谱化学序列
$$I^- < Br^- < Cl^- < F^- < OH^- < H_2O < NH_3 < en < NO_2^- < CN^- < CO$$

### 轨道能量比较
- Cl的σ轨道能量 > F（因Cl用3p轨道，F用2p轨道）
- 同族卤素从上到下π给体能力增强，分裂能减小

### 分裂能影响因素
| 因素 | 影响 |
|------|------|
| 配体场强度 | 强场→大分裂能 |
| 金属氧化态 | 高氧化态→大分裂能 |
| 金属周期 | 4d > 3d, 5d > 4d |

## 典型应用

- 解释配合物颜色（d-d跃迁）
- 预测配合物高自旋/低自旋态
- 竞赛中分析配合物的光谱和磁性
