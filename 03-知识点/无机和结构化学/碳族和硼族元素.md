# 碳族和硼族元素

## 核心概念

### 碳族元素（第14族）
- **元素**：碳(C)、硅(Si)、锗(Ge)、锡(Sn)、铅(Pb)
- **价电子构型**：ns²np²
- **氧化态**：+4、+2（惰性电子对效应：重元素+2态更稳定）
- **成键特点**：碳可形成p-pπ键，硅及以下元素难以形成稳定的p-pπ键

### 硼族元素（第13族）
- **元素**：硼(B)、铝(Al)、镓(Ga)、铟(In)、铊(Tl)
- **价电子构型**：ns²np²
- **氧化态**：+3（惰性电子对效应：铊+1态更稳定）
- **缺电子性**：硼和铝的化合物常为缺电子化合物，易形成配合物

## 关键反应

### 碳的反应
```
CaC₂ + N₂ → CaCN₂ + C （碳化钙与氮气反应）
2C + O₂ → 2CO （不完全燃烧）
C + CO₂ → 2CO （高温下）
C + 2H₂O → CO₂ + 2H₂ （水煤气反应）
```

### 硅的反应
```
Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑
SiO₂ + 2C → Si + 2CO↑ （工业制粗硅）
SiO₂ + 4HF → SiF₄↑ + 2H₂O （氢氟酸腐蚀玻璃）
```

### 硼的反应
```
2B + 3H₂ → 2BH₃ （硼烷合成）
B₂O₃ + 3Mg → 2B + 3MgO （硼的还原）
B₂H₆ + 3O₂ → B₂O₃ + 3H₂O （硼烷燃烧）
```

### 铝的反应
```
2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O
AlCl₃ + 3H₂O → Al(OH)₃ + 3HCl （水解）
```

## 规律与趋势

### 碳族元素周期律
1. **原子半径**：从上到下逐渐增大
2. **电负性**：从上到下逐渐减小（C:2.55, Si:1.90, Ge:2.01, Sn:1.96, Pb:2.33）
3. **金属性**：从上到下金属性增强（碳为非金属，硅为半金属，锗、锡、铅为金属）
4. **氧化物酸碱性**：从上到下氧化物酸性减弱，碱性增强
   - CO₂、SiO₂为酸性氧化物
   - GeO₂为两性氧化物
   - SnO₂、PbO₂为两性偏酸性氧化物

### 硼族元素周期律
1. **原子半径**：从上到下逐渐增大
2. **电负性**：从上到下逐渐减小（B:2.04, Al:1.61, Ga:1.81, In:1.78, Tl:2.04）
3. **金属性**：从上到下金属性增强（硼为非金属，铝及以下为金属）
4. **氧化物酸碱性**：从上到下氧化物酸性减弱，碱性增强
   - B₂O₃为酸性氧化物
   - Al₂O₃为两性氧化物
   - Ga₂O₃、In₂O₃、Tl₂O₃为碱性氧化物

### 惰性电子对效应
- **碳族**：+2氧化态稳定性从上到下增加（Pb²⁺比Pb⁴⁺更稳定）
- **硼族**：+1氧化态稳定性从上到下增加（Tl⁺比Tl³⁺更稳定）
- **解释**：6s²电子对不易参与成键（相对论效应）

## 典型应用

### 碳的应用
1. **有机化学基础**：所有有机化合物都含碳
2. **材料科学**：石墨、金刚石、石墨烯、碳纳米管
3. **能源领域**：化石燃料、碳基电池
4. **催化领域**：活性炭吸附、碳催化剂

### 硅的应用
1. **半导体材料**：硅芯片、太阳能电池
2. **硅酸盐工业**：玻璃、水泥、陶瓷
3. **有机硅材料**：硅橡胶、硅油、硅树脂
4. **光纤通信**：高纯度二氧化硅光纤

### 硼的应用
1. **硼玻璃**：耐热玻璃、硼硅酸盐玻璃
2. **硼肥**：农业微量元素肥料
3. **核反应堆控制棒**：硼-10吸收中子
4. **硼烷燃料**：高能火箭燃料

### 铝的应用
1. **轻质合金**：航空、汽车材料
2. **铝热剂**：焊接铁轨（Al + Fe₂O₃）
3. **电解铝**：霍尔-埃鲁法
4. **催化剂**：氧化铝催化剂载体
