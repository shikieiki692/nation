# 氧族元素

## 核心概念

### 氧（O）

- 氧族元素包括 O、S、Se、Te、Po，位于周期表第 16 列（VIA 族）
- O₂ 分子基态为**三线态**（¹Δ_g），电子排布为 $(\sigma_{2p_z})^2(\pi_{2p_x})^2(\pi_{2p_y})^2(\pi^*_{2p_x})^1(\pi^*_{2p_y})^1$，净键级 = 2
- O₂ 激发态为**单线态**（¹Δ_g），两个 π\* 电子占据同一轨道，比基态高 95 kJ/mol，更活泼
- O₂ 具有顺磁性（存在未成对电子）
- 固态氧有三种晶型：α-O₂（单斜，C2/m）、β-O₂（三方，R3m）、γ-O₂（立方，Pm3n）

### 硫（S）

- 硫在自然界以单质硫、硫化物矿物、硫酸盐矿物三种形式存在
- 常见硫化物矿物：黄铁矿 FeS₂、黄铜矿 CuFeS₂、方铅矿 PbS、闪锌矿 ZnS、辰砂 HgS、辉铜矿 Cu₂S、斑铜矿 Cu₅FeS₄
- 硫的同素异形体：S₈（皇冠型，D₄d 对称，最稳定）、S₆（三方晶体，不稳定）、弹性硫 Sₙ（螺旋链结构）
- SO₂ 与 O₃ 互为等电子体

### 硫的氧化物

- S₂O：无色气体，77K 时为橙红色液体，与 SO₂ 等电子体但无 π₃⁴ 键
- SO₂：V 型分子，键角 119.5°，极易溶于水，既有氧化性又有还原性
- SO₃：γ 型为三聚体（SP³ 杂化），β 型为螺旋链状；强氧化性

### 硫的氟化物

- SF₆：正八面体构型，化学惰性，熔点 222.4K，不溶于水
- S₂F₁₀：D₄d 对称，剧毒，熔点 220.5K，沸点 303K（无色液体）
- SF₄：跷跷板型结构，配位不饱和，易水解，极毒
- S₂F₂：结构类似过氧化氢，存在两种异构体

## 关键反应

### 氧的制备

| 方法 | 反应方程式 | 特点 |
|------|-----------|------|
| 分馏液态空气 | 物理方法 | 工业主要方法，成本低 |
| 电解水 | 2H₂O → 2H₂↑ + O₂↑ | 实验室小规模 |
| KClO₃ 分解 | 2KClO₃ --MnO₂→ 2KCl + 3O₂↑ | 需 MnO₂ 催化 |
| KMnO₄ 分解 | 4KMnO₄ → 4MnO₂ + 2K₂O + 3O₂↑ | 经典实验 |
| Brin 法 | 2BaO + O₂ ⇌ 2BaO₂（873K）；2BaO₂ → 2BaO + O₂↑（1173K） | 工业级纯度 |

### 过氧化氢制备

| 方法 | 反应方程式 | 特点 |
|------|-----------|------|
| BaO₂ + HCl | BaO₂ + 2HCl → BaCl₂ + H₂O₂ | 首次发现方法 |
| Na₂O₂ + NaH₂PO₄ | Na₂O₂ + 2NaH₂PO₄ → 2Na₂HPO₄ + H₂O₂ | 冷饱和溶液 |
| 电解法 | 2H₂O → H₂O₂ + H₂ | 硫酸氢盐作媒介 |
| 蒽醌法 | H₂ + O₂ → H₂O₂（蒽醌循环） | 工业方法 |

### 过氧化氢的氧化还原反应

**作为氧化剂（酸性条件）：**

- H₂O₂ + 2I⁻ + 2H⁺ → I₂ + 2H₂O
- H₂O₂ + 2Fe²⁺ + 2H⁺ → 2Fe³⁺ + 2H₂O
- H₂O₂ + PbS（黑色）→ PbSO₄（白色）+ H₂O（油画漂白）

**作为还原剂：**

- 2MnO₄⁻ + 5H₂O₂ + 6H⁺ → 2Mn²⁺ + 5O₂↑ + 8H₂O
- H₂O₂ + Cl₂ → 2HCl + O₂

**Fenton 试剂：**

- Fe²⁺ + H₂O₂ → Fe³⁺ + OH· + OH⁻
- OH· 自由基氧化电位 Eθ = 2.77V，极强

### 臭氧反应

- O₃ + 2Ag → Ag₂O + O₂
- 2I₂ + 3O₃ → I(IO₃)₃（碘酸碘）
- O₃ + SO₂ → SO₃（完全化合，无 O₂ 放出）
- O₃ + CN⁻ → OCN⁻ + O₂；OCN⁻ + O₃ → CO₃²⁻ + N₂ + O₂（处理含氰废水）

### 硫的反应

| 反应 | 方程式 |
|------|--------|
| 与 Cl₂ 反应 | S + Cl₂ → S₂Cl₂ |
| 燃烧 | S + O₂ → SO₂（蓝色火焰） |
| 与浓 HNO₃ | S + 6HNO₃ → H₂SO₄ + 6NO₂ + 2H₂O |
| 与 NaOH | 3S + 6NaOH → Na₂SO₃ + 2Na₂S + 3H₂O |
| 与浓 H₂SO₄ | S + 2H₂SO₄ → 3SO₂ + 2H₂O |
| 与发烟硫酸 | S₈ + 3SbF₅ --HF→ [S₈²⁺][SbF₆]₂⁻ + SbF₃ |

### 硫化氢制备

- 实验室：FeS + H₂SO₄ → H₂S↑ + FeSO₄
- 替代法：CH₃CSNH₂ + H₂O → CH₃COONH₄ + H₂S

### SO₂ 反应

- 氧化性：SO₂ + 2CO → S + 2CO₂
- 还原性：SO₂ + Cl₂ + 2H₂O → H₂SO₄ + 2HCl
- 工业制备：4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂

### SF₄ 制备与水解

- 制备：3SCl₂ + 4NaF --MeCN→ SF₄ + S₂Cl₂ + 4NaCl
- 水解：SF₄ + 2H₂O → SO₂ + 4HF

### 亚硫酸特性

- H₂SO₃ 实际不存在，溶液中以 SO₂·H₂O 形式存在
- 平衡体系：SO₂ + H₂O ⇌ H⁺ + HSO₃⁻
- 酸式盐存在互变异构：氢连氧形式 ⇌ 氢连硫形式

## 规律与趋势

### 氧化物分类规律

| 类型 | 特征 | 典型实例 |
|------|------|---------|
| 离子型氧化物 | 金属氧化物 | Na₂O、MgO、Al₂O₃ |
| 共价型氧化物 | 18 电子构型 | Ag₂O、Cu₂O |
| 两性氧化物 | 既与酸又与碱反应 | ZnO、Al₂O₃ |
| 酸性氧化物 | 非金属氧化物 | SO₃、P₄O₁₀、SiO₂ |

### 颜色规律

- 短周期氧化物均无色：K₂O、CaO、Sc₂O₃、TiO₂ 均白色
- 长周期出现颜色：CrO₃ 橙色、V₂O₅ 紫绿色、Mn₂O₇ 暗红色
- 规律：极化能力↑ → 跃迁能↓ → 吸收波长↑ → 颜色深

### 熔沸点规律

- 离子键越强 → 熔沸点越高
- 共价型氧化物通常熔沸点较低

### 硫含氧酸氧化态系列

- 次硫酸（H₂SO₂）→ 亚硫酸（H₂SO₃）→ 硫酸（H₂SO₄）→ 过硫酸（H₂S₂O₈）
- 还原性：H₂SO₂ > H₂SO₃ > H₂SO₄

### 硫氟化物结构趋势

- SF₆：正八面体，配位饱和，惰性
- SF₄：跷跷板型，配位不饱和，易水解
- S₂F₂：类似过氧化氢，存在异构体

### 过氧化氢电极电势判断

- 酸性条件（A）：Eθ(H₂O₂/H₂O) = 1.776V，Eθ(O₂/H₂O₂) = 0.682V
- 碱性条件（B）：Eθ(HO₂⁻/OH⁻) = 0.87V，Eθ(O₂/HO₂⁻) = -0.076V
- 判断规则：Eθ > 1.776V 时 H₂O₂ 作还原剂；Eθ < 0.682V 时作氧化剂

## 典型应用

### 氧气相关

- 工业制氧：分馏液态空气法（成本低、效率高）
- 液氧特性：极活泼，可使棉花等有机物剧烈燃烧爆炸
- 单线态氧应用：光动力治疗、有机合成中的氧化反应

### 过氧化氢相关

- Fenton 试剂处理难降解有机废水
- 油画漂白：H₂O₂ 氧化 PbS 为 PbSO₄
- 有机氧化：DMS→DMSO，HCHO→HCOOH

### 臭氧相关

- 含氰废水处理：O₃ 将 CN⁻ 氧化为 CO₃²⁻ + N₂
- 消毒杀菌：利用强氧化性

### 硫相关

- S₂Cl₂ 与乙烯反应生成芥子气（二战生化武器）
- SF₆ 用作高压电气设备绝缘气体
- 雕白粉（NaHSO₂·HCHO·2H₂O）用作还原性漂白剂
- SO₂ 用作溶剂（SO₂ 溶剂合物如 KI·4SO₂）

## 十五、🎯 教学视角

### 15.1 学习路径建议

先理解氧族元素的通性，再学习氧和硫的重要化合物，最后掌握它们的氧化还原性质和应用。

### 15.2 学生易踩的认知误区

| 误区 | 正确理解 |
|:---|:---|
| 氧的非金属性最强 | 氟的非金属性比氧强 |
| 过氧化氢只有氧化性 | 过氧化氢既有氧化性又有还原性 |
| 硫的氧化物都是酸性氧化物 | SO₂和SO₃都是酸性氧化物，但S₂O不是 |

### 15.3 入门级例题

**题目**：解释为什么H₂O₂可以作氧化剂也可以作还原剂。

**解答**：H₂O₂中氧的氧化态为-1，处于中间价态。当遇到更强的氧化剂时，H₂O₂作还原剂被氧化为O₂；当遇到还原剂时，H₂O₂作氧化剂被还原为H₂O。

### 15.4 与现实世界的联系

1. **环保领域**：H₂O₂用于废水处理和漂白
2. **医疗领域**：H₂O₂用作消毒剂
3. **能源领域**：H₂O₂用作火箭推进剂的氧化剂
