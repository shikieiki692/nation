# 锑

## 一、概述
- 锑（Sb）位于氮族元素中部，常见氧化态为 `+3` 和 `+5`
- 在基础教学中，锑最常作为 `砷 → 锑 → 铋` 纵向递变链条中的中间节点

## 二、核心要点
- `SbH3` 键角更接近 `90°`，体现重主族氢化物杂化减弱
- `Sb2S3` 可溶于浓盐酸，常与 `As2S3` 的溶解性差异一起考
- `SbCl3` 易分步水解生成 `SbOCl`
- `Sb2O3` 两性较明显，较 `As2O3` 更偏碱性

## 🎯 教学视角（补充）

### 学习路径建议

**前置知识**：氮族元素趋势、惰性对效应、砷的化学。

**推荐教学顺序**：
1. 从 N → P → As → Sb 的递变出发 → Sb 处于"两性转折点"
2. SbH₃：键角接近 90°（sp³ 杂化减弱），有毒，不稳定 → 与 PH₃ 类比
3. Sb 的卤化物：SbCl₃ 水解生成 SbOCl（氯氧化锑）→ 与 BiCl₃ 类似
4. Sb₂O₃：两性氧化物（比 As₂O₃ 更偏碱性）→ 可溶于酸和碱
5. 与 As 的对比：Sb₂S₃ 可溶于浓盐酸，As₂S₃ 不溶 → 分离依据

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "Sb 和 As 性质完全一样" | Sb 比 As 更偏碱性：Sb₂O₃ 更易溶于酸，Sb₂S₃ 可溶于浓 HCl 而 As₂S₃ 不溶 | "锑比砷碱，硫化锑能溶" |
| "SbCl₃ 在水中稳定" | SbCl₃ 遇水水解：SbCl₃ + H₂O → SbOCl↓ + 2HCl | "锑盐怕水" |
| "Sb 只有 +3 和 +5" | Sb 还有 0 和 -3 氧化态（SbH₃），但 +3 最稳定 | "锑的+3最安逸" |

### 与真实世界的联系

- **阻燃剂**：三氧化二锑（Sb₂O₃）是最重要的阻燃协效剂 → 与卤素化合物配合使用
- **半导体**：锑化铟（InSb）是重要的红外探测器材料
- **铅酸电池**：锑加入铅合金栅极 → 提高机械强度和耐腐蚀性
