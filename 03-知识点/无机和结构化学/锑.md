# 锑

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述

- 锑（Sb，Z = 51）位于氮族元素中部（第五周期），常见氧化态为 +3 和 +5
- 在基础教学中，锑最常作为 砷 → 锑 → 铋 纵向递变链条中的中间节点——**"两性转折点"**：As 偏酸、Sb 两性、Bi 偏碱
- 单质为准金属（类金属）：有金属光泽但导电性差，存在同素异形体

**元素速查**：相对原子质量 121.8；电子构型 [Kr]4d¹⁰5s²5p³；常见价态 +3（稳定）、+5（存在但氧化性强）、−3（SbH₃）；电负性 2.05；单质锑有灰锑（稳定，层状菱方结构）、黄锑、黑锑等同素异形体，工业品以辉锑矿 Sb₂S₃ 为源。

## 二、核心要点

### 2.1 氢化物与键角

- SbH₃（锑化氢）：剧毒、极不稳定（室温缓慢分解，加热爆炸性分解），还原性强——沿族向下氢化物稳定性骤降（NH₃ > PH₃ > AsH₃ > SbH₃ > BiH₃）
- **键角更接近 90°**（SbH₃ 约 91°）：重主族氢化物 sp³ 杂化减弱、趋向用近纯 p 轨道成键——同族键角 NH₃ 107° → PH₃ 94° → AsH₃ 92° → SbH₃ 91°
- 碱性极弱（几乎不质子化）——与 NH₃ 的碱性形成鲜明对比

### 2.2 卤化物与水解

- SbCl₃ 是重要试剂：共价性显著（低熔点固体，可升华），**遇水强烈水解**：
  SbCl₃ + H₂O ⇌ SbOCl↓（氧氯化锑/氯氧化锑，白色）+ 2HCl
- SbOCl 继续水解得 Sb₂O₃·xH₂O；配制 SbCl₃ 溶液须加盐酸抑制水解（同 BiCl₃ 操作）
- SbCl₅ 存在（+5 卤化物比 Bi 稳）但氧化性强，可作氯化剂
- 硫化物 Sb₂S₃（橙红）：**溶于浓盐酸**（生成 SbCl₃ + H₂S）——与 As₂S₃（不溶浓 HCl）构成分离依据

### 2.3 氧化物与酸碱性

- Sb₂O₃（锑白）：**两性氧化物**——溶于强酸（生成 Sb³⁺ 盐）也溶于强碱（生成亚锑酸盐 [Sb(OH)₄]⁻ 或 SbO₂⁻）；比 As₂O₃ 更偏碱性
- Sb₂O₅：+5 氧化物，酸性强于 Sb₂O₃；对应水合物锑酸 H[Sb(OH)₆]（可写成 HSb(OH)₆，六羟基合锑酸）——+5 锑在水溶液中以 Sb(OH)₆⁻ 形式存在，不是简单 SbO₄³⁻
- 锑酸盐：如 Na[Sb(OH)₆]——钠的锑酸盐溶解度小，曾用于 Na⁺ 鉴定（焦锑酸氢钠 Na₂H₂Sb₂O₇ 沉淀法）

### 2.4 硫代酸盐

- Sb₂S₃ 溶于碱金属硫化物生成**硫代亚锑酸盐**：Sb₂S₃ + 3Na₂S → 2Na₃SbS₃（硫代亚锑酸钠）
- 同理 As₂S₃ 溶 Na₂S 得 Na₃AsS₃——硫代酸盐的形成是砷锑砷族硫化物区别于大多数金属硫化物的特征（"硫化物溶于硫化钠"的定性分组依据）

### 2.5 单质与应用

- 灰锑为层状结构（类砷），脆性大不能锻造
- 阻燃协效：Sb₂O₃ 与卤系阻燃剂配合（生成 SbX₃ 气相捕获自由基）
- 铅酸电池栅极合金含 Sb（提高强度抗腐蚀）；InSb 红外探测器；半导体掺杂

## 四、As/Sb 硫化物分离逻辑（经典考点）

| 步骤 | 操作 | 现象/原理 |
|---|---|---|
| ① 酸化 | 硫代酸盐溶液加 HCl | 重新析出硫化物沉淀（Sb₂S₃↓ + H₂S） |
| ② 盐酸溶解性差异 | As₂S₃ 与 Sb₂S₃ 混合 + 浓 HCl | **Sb₂S₃ 溶（SbCl₃ + H₂S），As₂S₃ 不溶**——分离 |
| ③ 确认 | 滤液稀释 | SbCl₃ 水解出 SbOCl 白浊 |

**记忆锚**：第五周期锑开始"金属性显现"——硫化物能被盐酸溶解、氯化物易水解、氧化物呈两性，三步都指向 As→Sb 的金属性跃迁。

## 五、周期递变速查（As → Sb → Bi）

| 性质 | As | Sb | Bi |
|---|---|---|---|
| 单质类型 | 准金属 | 准金属 | 金属 |
| 氧化物酸碱性 | H₃AsO₃ 弱酸 | Sb₂O₃ 两性 | Bi₂O₃ 碱式 |
| 氯化物水解 | — | SbOCl | BiOCl |
| +5 稳定性 | 常见 | 存在（SbCl₅） | 仅 BiF₅ |
| 氢化物稳定性 | AsH₃ 剧毒 | SbH₃ 很不稳 | BiH₃ 极不稳 |
| 硫化物 + 浓 HCl | As₂S₃ 不溶 | Sb₂S₃ 溶 | Bi₂S₃ 溶 |

## 六、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| Sb 与 As 性质"完全一样" | Sb 金属性强一档：氧化物两性、硫化物溶浓 HCl | Sb₂O₃ 溶酸也溶碱、Sb₂S₃ + 浓 HCl 溶而 As₂S₃ 不溶——分离题就考这一差 |
| SbCl₃ 水溶液稳定澄清 | SbCl₃ 遇水即水解出 SbOCl 白浊 | 配液加 HCl；稀释观察白浊是 Sb³⁺ 鉴别 |
| 锑只有 +3/+5 | 还有 0（单质）与 −3（SbH₃） | SbH₃ 虽极不稳定但确实存在（还原性极强） |
| SbH₃ 键角仍按 ~107° 想 | 重氢化物近 90°（p 轨道成键为主） | 键角序列 NH₃ 107 > PH₃ 94 > AsH₃ 92 > SbH₃ 91 |
| 以为 +5 锑酸根是 SbO₄³⁻ | 水溶液中 +5 锑是 Sb(OH)₆⁻（六羟基合锑酸根） | 锑酸写作 H[Sb(OH)₆]；与磷酸 PO₄³⁻ 不同——大半径中心无法形成四面体含氧酸根 |
| Sb₂S₃ 当作"普通不溶硫化物" | 它溶于 Na₂S/浓 HCl——砷分族硫化物特征 | 硫代酸盐形成 + 浓 HCl 溶解 = Sb 的定性分组手段 |

## 七、🎯 教学视角（补充）

### 学习路径建议

**前置知识**：氮族元素趋势、惰性对效应、砷的化学。

**推荐教学顺序**：
1. 从 N → P → As → Sb 的递变出发 → Sb 处于"两性转折点"
2. SbH₃：键角接近 90°（sp³ 杂化减弱），有毒，不稳定 → 与 PH₃ 类比
3. Sb 的卤化物：SbCl₃ 水解生成 SbOCl（氯氧化锑）→ 与 BiCl₃ 类似
4. Sb₂O₃：两性氧化物（比 As₂O₃ 更偏碱性）→ 可溶于酸和碱
5. 与 As 的对比：Sb₂S₃ 可溶于浓盐酸，As₂S₃ 不溶 → 分离依据

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "Sb 和 As 性质完全一样" | Sb 比 As 更偏碱性：Sb₂O₃ 更易溶于酸，Sb₂S₃ 可溶于浓 HCl 而 As₂S₃ 不溶 | "锑比砷碱，硫化锑能溶" |
| "SbCl₃ 在水中稳定" | SbCl₃ 遇水水解：SbCl₃ + H₂O → SbOCl↓ + 2HCl | "锑盐怕水" |
| "Sb 只有 +3 和 +5" | Sb 还有 0 和 -3 氧化态（SbH₃），但 +3 最稳定 | "锑的+3最安逸" |

### 与真实世界的联系

- **阻燃剂**：三氧化二锑（Sb₂O₃）是最重要的阻燃协效剂 → 与卤素化合物配合使用
- **半导体**：锑化铟（InSb）是重要的红外探测器材料
- **铅酸电池**：锑加入铅合金栅极 → 提高机械强度和耐腐蚀性

> **记忆锚**：Sb 是氮族"金属性开关"——氢化物近 90°、氯化物怕水（SbOCl）、氧化物两性、硫化物吃浓盐酸也吃 Na₂S。

## 八、竞赛考察要点

1. **递变题**：As/Sb/Bi 的氧化物酸碱性、氢化物稳定性与键角排序。
2. **水解与配液**：SbCl₃ 稀释变浊；如何配澄清 SbCl₃ 溶液（加 HCl）。
3. **分离题**：As₂S₃ 与 Sb₂S₃ 混合分离（浓 HCl 溶 Sb 不溶 As）——硫化物分组。
4. **硫代酸盐**：Sb₂S₃ + Na₂S 的反应与加酸逆沉淀。
5. **+5 结构**：锑酸 H[Sb(OH)₆] 的书写与 Sb(OH)₆⁻ 配位结构（六配位，不同于 PO₄³⁻ 四面体）。
6. **键角解释**：SbH₃ 键角近 90° 的原因（重 p 区杂化弱、近纯 p 成键）。

## 九、关键结论速记

- 位置：氮族第五周期，金属性转折点——As 酸、Sb 两、Bi 碱。
- 水解链条：SbCl₃ → SbOCl（白）→ Sb₂O₃·xH₂O；Bi 同款（BiOCl）。
- 硫化物个性：Sb₂S₃ 溶浓 HCl、溶 Na₂S（硫代酸盐）——As₂S₃ 都不行。
- +5 形态：SbCl₅ 存在但氧化性强；水溶液中 +5 是 Sb(OH)₆⁻。
- SbH₃：键角 91°、剧毒、极不稳定、强还原——重氢化物共有的"快崩"脾气。
- 收尾自检：能写 SbCl₃ 水解与硫代酸盐两方程、说清 As₂S₃/Sb₂S₃ 分离原理，本页达标。
- 数值锚点：Sb 原子量 121.8、SbH₃ 键角 ~91°、Sb₂O₃ 两性（溶酸溶碱）——记住位置、键角、两性三件事即可串起全部考法。
- 相关元素横向：同周期相邻的 Sn（+2/+4 惰性对）、Te（氧化性含氧酸）常与 Sb 编入同一道递变题——比较时统一用"价态稳定性 + 氧化物酸碱性"两轴。
- 工业线索：辉锑矿 Sb₂S₃ 为源，火法（还原熔炼）得粗锑；粗锑精炼借 Sb₂O₃ 挥发/碱性精炼除 As——"矿 → 氧化物 → 还原"三步是主族金属冶炼通用模板。
- 最后提醒：Sb 的化合物大多有毒（SbH₃ 尤甚），题面出现"通风橱/毒气"提示时先想 SbH₃/AsH₃——氢化物毒性与不稳定性绑定记忆。
- 收尾复核：本页速记 6 条 + 锚点 3 个（121.8 / 91° / 两性）能默写，锑页即完成——与 [[砷]]、[[铋]] 两页合读可得氮族下半段完整图景。
- 判断题自测：① Sb₂O₃ 是酸性氧化物？——错，两性；② SbCl₃ 溶液久置变澄清？——错，水解出 SbOCl 白浊；③ Sb₂S₃ 不溶于浓盐酸？——错，溶（As₂S₃ 才不溶）。三问全对，本页达标。
- 附：Sb 在周期表中与 Te、Sn 相邻，元素推断题若给"第五周期 VA 族 + 两性 + 硫化物溶盐酸"三线索，直接锁定 Sb。
