# 石墨结构

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[17-常见晶体结构]]

## 一、结构描述
- **六方晶系**（hexagonal P）
- 层内：C sp² 杂化 + 离域 πₙ 键（类苯环），C—C 142 pm
- 层间：范德华力，间距 335 pm（远大于层内键长）

## 二、堆垛方式
- ABAB...（Bernal 石墨，最稳定）：一半 C 正对下层环心，一半正对下层 C
- ABCABC...（菱形石墨）

## 三、性质
- 导电（沿层面）：离域 π 电子
- 润滑性：层间滑移
- C—C 键比金刚石还短（π 键强化）

## 四、关键结论
### 混合键型晶体（§13.5.1，图 13.16）
石墨是**典型的混合键型晶体**，含有三种类型的相互作用：
1. **层内 C—C**：sp² 杂化 $\sigma$ 键，键长 $142\,\mathrm{pm}$（比金刚石的 154 pm 还短，因 $\pi$ 键强化）
2. **层内 $\pi$ 键**：各 C 的 p 轨道垂直于平面，相互重叠组成**离域大 $\pi$ 键**，$\pi$ 电子可在整层自由活动 → 类金属导电性
3. **层间**：**范德华力**，C 原子间距 $340\,\mathrm{pm}$（远大于层内 142 pm）→ 层间易滑动，具有润滑性

### 性质
- **导电性**（沿层面）：$\pi$ 电子自由移动，是优良电极材料
- **润滑性**：层间范德华力弱，工业上用做固体润滑剂
- C—C 键比金刚石**更强**（键长更短）

## 五、常见分类或情形
- 六方石墨（Bernal 石墨，ABAB...）：最稳定，一半 C 正对下层环心，一半正对下层 C
- 菱形石墨（ABCABC...）：亚稳相

## 七、常见比较与易混点
- **石墨 vs 金刚石**：同素异形体。石墨导电、软、润滑；金刚石不导电、极硬
- **石墨键型 vs 金刚石键型**：石墨为混合键型（共价 + 金属 + 分子间力），金刚石为纯共价
- **层内键长 142 pm < 金刚石 C—C 154 pm**：$\pi$ 键使层内键更强更短

## 六、适用条件与限制
- 石墨导电仅沿层面方向（各向异性），垂直层面方向不导电
- 石墨的层间作用力弱，高温高压下可转化为金刚石
- 石墨在空气中高温下会被氧化为 CO₂

## 八、与其他知识点的联系
- [[金刚石型结构]]：石墨与金刚石互为同素异形体，键型不同导致性质迥异
- [[离域π键]]：石墨层内的离域大 π 键是其导电性的根本原因
- [[金属晶体]]：石墨的导电性源于 π 电子自由移动，类似于金属中的自由电子气
- [[原子晶体]]：金刚石是纯共价晶体，石墨是混合键型晶体

## 九、典型题型
- **类型1：键型分析**：分析石墨中三种相互作用（σ 键、π 键、范德华力）的特点
- **类型2：各向异性解释**：解释石墨导电性和力学性质的各向异性
- **类型3：同素异形体比较**：比较石墨与金刚石的结构和性质差异
- **类型4：堆垛方式判断**：区分六方石墨（ABAB）和菱形石墨（ABCABC）

## 十、例题
**例题1**：解释为什么石墨可以导电而金刚石不能导电。

**解答**：
- 石墨：层内 C 以 sp² 杂化形成 σ 键，每个 C 剩余一个 p 轨道垂直于层面，相互重叠形成离域大 π 键 → π 电子可在整层自由移动 → 导电
- 金刚石：每个 C 以 sp³ 杂化与 4 个 C 形成 σ 键，所有电子都定域在共价键中 → 无自由电子 → 不导电

**例题2**：比较石墨层内 C—C 键长（142 pm）与金刚石 C—C 键长（154 pm），解释为什么石墨的键更短。

**解答**：
石墨层内 C 为 sp² 杂化，σ 键 + 离域 π 键的叠加使键级约为 1.33，键能更大 → 键长更短。金刚石中 C 为 sp³ 杂化，纯 σ 键（键级 = 1）→ 键长更长。

## 十一、易错点
- **误认为石墨是原子晶体**：石墨是混合键型晶体（共价 + 金属性 + 分子间力），不是纯共价晶体
- **误认为石墨层间是共价键**：层间是范德华力，间距 340 pm 远大于层内 142 pm
- **忽略石墨的各向异性**：石墨沿层面导电、垂直层面不导电，性质各向异性
- **混淆六方石墨和菱形石墨**：六方石墨（ABAB...）是最稳定的天然石墨，菱形石墨（ABCABC...）是亚稳相

## 十二、🎯 教学视角

### 学习路径建议
1. 从石墨的宏观性质（软、导电、润滑）出发 → 引出微观结构的特殊性
2. 三层相互作用：层内 σ 键 + 离域 π 键 + 层间范德华力
3. 与金刚石对比 → 同素异形体，键型不同导致性质迥异
4. 各向异性 → 沿层面 vs 垂直层面的性质差异

### 学生易踩的认知误区
| 误区 | 正确理解 |
|------|---------|
| "石墨是原子晶体" | 石墨是混合键型晶体，不是纯共价晶体 |
| "石墨层间是化学键" | 层间是范德华力，不是化学键 |
| "石墨导电是因为有金属键" | 石墨导电是因为离域 π 电子，不是金属键 |
