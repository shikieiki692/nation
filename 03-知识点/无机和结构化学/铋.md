# 铋

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[基础要求-无机和结构化学]]
- 对应考纲条目：[[13-元素化学]]

## 一、概述

- 铋（Bi，Z = 83）是氮族（VA 族）最重的稳定元素，+3 远比 +5 稳定——**惰性对效应的终端展示**（6s² 电子对惰性在第六周期达到最大）
- 单质为银白色带浅红光泽的脆性金属，熔点低（271°C），是"低熔点金属"家族（Ga、In、Sn、Bi、Pb）成员
- 它是讲解惰性对效应的代表元素之一

**元素速查**：相对原子质量 209.0（无稳定同位素前的最后稳定核素 ²⁰⁹Bi 几乎不衰变）；电子构型 [Xe]4f¹⁴5d¹⁰6s²6p³；常见价态 +3（主）、+5（需强配位）、−3（BiH₃ 少见）；电负性 2.02（氮族中最大，金属性最强）。

## 二、核心要点

### 2.1 惰性对效应下的氧化态

- 6s² 惰性电子对使 Bi 的 +5 极不稳定——**仅 BiF₅ 能稳定存在**（F 的强电负性 + 小半径稳定高氧化态）；BiCl₅ 室温分解，Bi₂O₅ 不存在
- +3 是最常见氧化态：Bi₂O₃（碱式氧化物为主）、BiCl₃、Bi(NO₃)₃ 等
- 对比同族：N(+5) 稳定（HNO₃）、P(+5) 稳定（H₃PO₄）、As(+5) 常见、Sb(+5) 存在但氧化性强、**Bi(+5) 几乎只能靠 F/O 稳住**——惰性对效应沿族向下增强的完整链条

### 2.2 Bi³⁺ 的水解与氧铋离子

- Bi³⁺ 电荷高、半径大 → 强烈水解，溶液中不存在游离 Bi³⁺ 水合离子：
  Bi³⁺ + Cl⁻ + H₂O ⇌ BiOCl↓（白色）+ 2H⁺
- **BiO⁺（氧铋离子）**是 Bi³⁺ 水解的稳定归宿；加酸抑制水解可回 Bi³⁺
- 经典操作：BiCl₃ 溶液加水稀释即析出白色 BiOCl 沉淀（"铋盐遇水变浑浊"）——鉴别 Bi³⁺ 的简便方法

### 2.3 铋的含氧酸盐与强氧化性

- **铋酸钠 NaBiO₃**：最强的固体氧化剂之一——酸性介质中能把 Mn²⁺ 氧化成 MnO₄⁻（紫红色）：
  2Mn²⁺ + 5NaBiO₃ + 14H⁺ → 2MnO₄⁻ + 5Bi³⁺ + 5Na⁺ + 7H₂O
  这是检验 Mn²⁺ 的特征反应（NaBiO₃ 中 Bi 为 +5，靠 O²⁻ 配位稳定）
- 铋酸盐在分析化学中的地位类似 PbO₂（同为 +4/+5 高价固体氧化剂）

### 2.4 低价多核簇离子

- 铋能形成**金属-金属键的多核簇离子**（Zintl 离子）：Bi₃³⁻、Bi₄²⁻、Bi₅³⁺、Bi₈²⁺ 等
- 这些簇存在于熔盐/液氨介质，结构多为闭式多面体——竞赛结构推断题素材（如 Bi₈²⁺ 为四方反棱柱）
- 与铅、锡的低价簇类比：重 p 区金属"低价成簇"是普遍现象

### 2.5 单质与合金

- 单质铋有**热缩冷胀**性质（液态密度 > 固态，类似水/镓/锑），结晶时膨胀
- 低熔点合金：Wood 合金（Bi 50%、Pb 25%、Sn 12.5%、Cd 12.5%，熔点约 70°C）用于保险丝/消防喷淋
- 铋晶体可长成阶梯状"彩虹晶体"（氧化膜干涉色）

## 四、周期递变速查（As → Sb → Bi）

| 性质 | As | Sb | Bi |
|---|---|---|---|
| +5 稳定性 | 常见（H₃AsO₄） | 有（Sb₂O₅、SbF₅） | 极差（仅 BiF₅/NaBiO₃） |
| +3 性质 | 两性偏酸 | 两性 | 碱性（Bi₂O₃ 溶于酸不溶于强碱） |
| 氧化物酸碱性 | H₃AsO₃ 弱酸 | Sb₂O₃ 两性 | Bi₂O₃ 碱式 |
| 氢化物 | AsH₃（剧毒） | SbH₃（很不稳） | BiH₃（极不稳定，几乎无实际存在） |
| 水解产物 | — | SbOCl | BiOCl |
| 金属性 | 准金属 | 准金属 | 金属 |

**口诀**：As 酸、Sb 两、Bi 碱；五价沿族往下塌（惰性对），氢化物沿族往下崩。

## 五、检测与应用

- **Bi³⁺ 检测**：加水稀释析白 BiOCl；或与 Na₂SnO₂（亚锡酸钠碱性液）反应析出黑色 Bi 微粒（Bi³⁺ 被还原）
- **胃药**：碱式水杨酸铋 / 碱式硝酸铋（收敛、保护胃黏膜，治疗腹泻）
- **珠光颜料**：BiOCl 晶体高折射率，用于化妆品/塑料珠光效果
- **超导与热电**：Bi-Sr-Ca-Cu-O 高温超导、Bi₂Te₃ 热电材料
- **核医学**：²¹³Bi 用于靶向 α 治疗

## 六、易错点

| 常见错误 | 错在哪里 | 反例/判别要点 |
|---|---|---|
| 认为 Bi 与 N 一样 +5 稳定 | 惰性对效应使第六周期 +5 几乎不存在 | 仅 BiF₅/NaBiO₃；BiCl₅ 不存在——"氮五稳、铋五险" |
| BiCl₃ 溶液当"澄清酸性盐溶液" | Bi³⁺ 强水解生成 BiOCl 白浊 | 稀释即浑浊：BiCl₃ + H₂O ⇌ BiOCl↓ + 2HCl；要澄清须加盐酸 |
| 低估 NaBiO₃ 氧化性 | 它是固体氧化剂天花板，能把 Mn²⁺ 拉到 MnO₄⁻ | Mn²⁺ + NaBiO₃（酸性）→ 紫色 MnO₄⁻——检验 Mn²⁺ 特征反应 |
| 把 Bi₂O₃ 当两性氧化物 | Bi 的氧化物已偏碱性（氮族最低） | Bi₂O₃ 溶于酸、不溶于强碱——与 Al₂O₃ 完全不同 |
| 忽略低价簇的存在 | 重 p 区金属低价以 M–M 键成簇 | Bi₅³⁺/Bi₈²⁺ 等多面体簇是竞赛结构题素材 |
| 把 209 当"有放射性"的暗示 | ²⁰⁹Bi 是稳定核素（极长半衰期） | 铋是最后一个"无放射性"天然元素，勿误判 |

## 七、🎯 教学视角（补充）

### 学习路径建议

**前置知识**：氮族元素趋势、惰性对效应、氧化态概念。

**推荐教学顺序**：
1. 从 N → P → As → Sb → Bi 的元素性质递变出发 → 引出铋的位置
2. 惰性对效应：Bi 的 +5 氧化态极不稳定（仅 BiF₅ 稳定），+3 是最常见氧化态
3. Bi³⁺ 的化学：易形成 BiO⁺（氧铋离子）→ 盐类大多水解
4. 与 Sb 的对比：同族但性质差异（Bi 更偏碱性，Sb 两性）
5. 铋的特殊化合物：铋酸钠 NaBiO₃（强氧化剂，可氧化 Mn²⁺ 为 MnO₄⁻）

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "Bi 和 N 一样有 +5 价" | N 的 +5 很稳定（HNO₃），Bi 的 +5 极不稳定（仅 BiF₅），这就是惰性对效应 | "氮的五价稳，铋的五价险" |
| "BiCl₃ 溶液是酸性的" | BiCl₃ 在水中强烈水解：BiCl₃ + H₂O → BiOCl↓ + 2HCl，所以溶液显酸性且有白色沉淀 | "铋盐遇水变浑浊" |
| "NaBiO₃ 是弱氧化剂" | NaBiO₃ 是最强的固体氧化剂之一，可在酸性条件下将 Mn²⁺ 氧化为紫色的 MnO₄⁻ | "铋酸钠氧化王" |

### 与真实世界的联系

- **胃药**：碱式水杨酸铋（Pepto-Bismol）利用 Bi³⁺ 的收敛和抗菌作用治疗胃肠道疾病
- **化妆品**：铋的化合物（如氧氯化铋）用作珠光颜料，赋予化妆品闪亮光泽
- **超导体**：Bi-Sr-Ca-Cu-O 系列是重要的高温超导材料

> **记忆锚**：铋三件事——五价只剩 F 和 O 撑（惰性对）、三价遇水就变浊（BiOCl）、铋酸钠能把 Mn²⁺ 拉成 MnO₄⁻（固体氧化王）。

## 八、竞赛考察要点

1. **氧化态题**："Bi 有哪些稳定氧化态？BiCl₅ 存在吗？"——答 +3 稳定、+5 仅 BiF₅/铋酸盐。
2. **水解题**：BiCl₃ 稀释为何浑浊？如何配澄清液？——加 HCl 抑制水解。
3. **氧化还原题**：NaBiO₃ 氧化 Mn²⁺（酸性）——写配平、判现象（紫色）。
4. **递变题**：As/Sb/Bi 氧化物酸碱性、氢化物稳定性排序。
5. **结构题**：Bi 簇离子（Bi₅³⁺、Bi₈²⁺）的多面体几何。

## 九、关键结论速记

- 惰性对终端：+3 稳、+5 仅 BiF₅/NaBiO₃——写 Bi 的化合物先问价态能不能活。
- Bi³⁺ 强水解：稀释出 BiOCl 白浊；配澄清液加盐酸。
- NaBiO₃ 是固体氧化剂天花板（酸性下 Mn²⁺ → MnO₄⁻）。
- 氧化物偏碱性（As 酸 → Sb 两 → Bi 碱），与 Al 的两性划清界限。
- 单质热缩冷胀、低熔点（271°C）；Wood 合金做保险丝。
- 低价簇 Bi₅³⁺/Bi₈²⁺ 是结构推断素材——重 p 区金属"低价成簇"。
- 收尾自检：能写 BiCl₃ 水解方程、NaBiO₃ 氧化 Mn²⁺ 配平、排序 As/Sb/Bi 氧化物酸碱性，本页达标。
- 数值锚点：熔点 271°C、²⁰⁹Bi 稳定、Bi₂O₃ 只溶于酸——三数一性记住 Bi。
