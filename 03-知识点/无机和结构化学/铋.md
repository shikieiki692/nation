# 铋

- 总览：[[中国化学奥林匹克基本要求-总览]]

## 一、概述
- 铋（Bi）是氮族较重元素，`+3` 远比 `+5` 稳定
- 它是讲解 `惰性对效应` 的代表元素之一

## 二、核心要点
- `Bi5+` 很不稳定，常用“仅 `BiF5` 稳定存在”来建立直觉
- `Bi3+` 稳定，易形成 `BiO+` 等含氧阳离子
- 铋还能形成低价多核簇离子，如 `Bi3+`、`Bi5+`、`Bi8^2+`
- 相关推断常和 `惰性对效应`、簇合物结构、氧化还原能力相连

## 🎯 教学视角（补充）

### 学习路径建议

**前置知识**：氮族元素趋势、惰性对效应、氧化态概念。

**推荐教学顺序**：
1. 从 N → P → As → Sb → Bi 的元素性质递变出发 → 引出铋的位置
2. 惰性对效应：Bi 的 +5 氧化态极不稳定（仅 BiF₅ 稳定），+3 是最常见氧化态
3. Bi³⁺ 的化学：易形成 BiO⁺（氧铋离子）→ 盐类大多水解
4. 与 Sb 的对比：同族但性质差异（Bi 更偏碱性，Sb 两性）
5. 铋的特殊化合物：铋酸钠 NaBiO₃（强氧化剂，可氧化 Mn²⁺ 为 MnO₄⁻）

### 学生易踩的认知误区

| 误区 | 正确理解 | 记忆口诀 |
|------|---------|----------|
| "Bi 和 N 一样有 +5 价" | N 的 +5 很稳定（HNO₃），Bi 的 +5 极不稳定（仅 BiF₅），这就是惰性对效应 | "氮的五价稳，铋的五价险" |
| "BiCl₃ 溶液是酸性的" | BiCl₃ 在水中强烈水解：BiCl₃ + H₂O → BiOCl↓ + 2HCl，所以溶液显酸性且有白色沉淀 | "铋盐遇水变浑浊" |
| "NaBiO₃ 是弱氧化剂" | NaBiO₃ 是最强的固体氧化剂之一，可在酸性条件下将 Mn²⁺ 氧化为紫色的 MnO₄⁻ | "铋酸钠氧化王" |

### 与真实世界的联系

- **胃药**：碱式水杨酸铋（Pepto-Bismol）利用 Bi³⁺ 的收敛和抗菌作用治疗胃肠道疾病
- **化妆品**：铋的化合物（如氧氯化铋）用作珠光颜料，赋予化妆品闪亮光泽
- **超导体**：Bi-Sr-Ca-Cu-O 系列是重要的高温超导材料
