# 储氢材料

## 一、定义

储氢材料指能**可逆地吸附/吸收并释放氢气**的固态或液态体系，是氢能"制-储-运-用"链条中"储运"环节的核心。氢气密度极低（标况 0.0899 g/L），储存方式分三类：①高压气态储氢（钢瓶/碳纤维瓶，35–70 MPa）；②低温液态储氢（−253 °C 液化，体积密度高但能耗大）；③**材料储氢**——靠材料与 H₂ 的物理吸附（比表面大：MOF、碳材料、分子筛）或化学键合（金属氢化物、配位氢化物、氨基化物）把氢"装进"材料。材料储氢的追求指标：**高质量储氢密度（wt%，氢质量分数）、高体积密度、适中的吸放氢温度/压力、快动力学、长循环寿命、安全廉价**。竞赛常考储氢容量计算（质量分数）、金属氢化物反应（LaNi₅H₆、MgH₂、LiNH₂ 体系）与储氢方式比较（25/27/36/39 届真题语境）。

## 二、考纲对应

本页属材料化学-氢能考点，对应"储氢材料类型与储氢容量计算"：能区分物理吸附（MOF/碳）与化学储氢（金属氢化物/配位氢化物）；掌握储氢容量 wt% 的定义与计算（如 LaNi₅H₆、LiNH₂、MgH₂）；会写储氢合金吸放氢的可逆反应式并分析温度/压力条件（van't Hoff 式平台压）；了解高压/液氢/材料三种方式优劣比较。初赛决赛以计算题与材料分析题出现。

## 三、核心原理

### 3.1 储氢的三种方式与比较

| 方式 | 原理 | 优点 | 局限 |
|---|---|---|---|
| 高压气态 | 压缩装瓶（35–70 MPa） | 技术成熟、成本低 | 体积密度仍低、需高压容器/安全 |
| 低温液态 | 液化（−253 °C，20 K） | 体积密度高（70 g/L 级） | 液化能耗大（约占氢能 30%）、蒸发损失 |
| 材料储氢 | 物理吸附或化学键合 | 体积/质量密度潜力高、常温可行 | 储氢量/放氢温度/循环寿命仍需优化 |

材料储氢又分：**物理吸附型**（H₂ 分子弱吸附在孔表面：MOF、活性炭、碳纳米管——低温高压有利，室温容量低）与**化学储氢型**（H 以原子/离子形式成键：金属氢化物、配位氢化物、氨基/硼氢化物——放氢需热能，常高温）。

### 3.2 储氢容量计算（考试核心技能）

- 定义：**质量储氢密度 wt% = m(H)/[m(材料) + m(H)] × 100%**（吸氢后总质量计）。
- 例：LaNi₅ + 3H₂ ⇌ LaNi₅H₆——M(LaNi₅) = 138.9 + 5×58.7 = 432.4；6 个 H = 6.0；wt% = 6.0/(432.4+6.0) ≈ 1.4%。
- 常用材料 wt% 参考：LaNi₅H₆ ≈ 1.4%、MgH₂ ≈ 7.6%、LiH ≈ 12.7%（但 LiH 放氢温度极高）、NH₃BH₃（氨硼烷）≈ 19.6%、LiBH₄ ≈ 18.5%、MOF-5 低温 ≈ 数 wt%。**"高容量"常伴高放氢温度/不可逆——考题爱考 wt% 与实用性的权衡**。
- 注意：wt% 计算分母含氢（吸氢后）；体积储氢密度另算（g/L 或 kg/m³）。

### 3.3 金属氢化物与平台压（热力学）

- 储氢合金可逆反应：M + (x/2)H₂ ⇌ MHₓ（放氢是吸热，ΔH > 0）。
- **平台压**：恒温下吸放氢存在一个平台压力 p_plat，与温度满足 van't Hoff 关系：ln(p_plat) ∝ −ΔH/(RT) + ΔS/R——**升高温度平台压指数上升**（放氢需加热）。
- 典型体系：LaNi₅（室温附近平台 ~0.2–0.3 MPa，易活化——镍氢电池负极）、Mg/MgH₂（7.6 wt% 但需 >300 °C）、TiFe、AB₂ 型（ZrMn₂ 类）、V 基固溶体。
- 实际应用折中：LaNi₅ 容量低但条件温和（电池/低温应用）；MgH₂ 容量高需高温（车用研究）。

### 3.4 轻质配位/氨基氢化物（高容量方向）

- **LiNH₂–LiH 体系**（25 届真题）：LiNH₂ + 2LiH ⇌ Li₂NH + LiH + H₂? 常用表述：2LiNH₂ + LiH ⇌ Li₂NH + LiNH₂? 标准反应：LiNH₂ + LiH ⇌ Li₂NH + H₂（可逆储氢约 6.5 wt%）——"锂氮氢化物储氢"。
- **硼氢化物/氨硼烷**：LiBH₄（18.5 wt%）、NaBH₄、NH₃BH₃（19.6 wt%）——容量高但放氢路径复杂（杂质气体、可逆性差），需催化剂/纳米化改善。
- **金属氨基硼烷/复合氢化物**：研究热点；放氢温度随体系优化可降到 100–200 °C。
- 化学储氢的另一思路：有机物液体储氢（LOHC：N-乙基咔唑等加氢/脱氢循环）。

### 3.5 物理吸附储氢与孔材料

- MOF/COF/多孔碳：靠 H₂ 与孔壁的弱范德华作用——**低温（77 K）高压**容量可观（MOF-5 等 >5 wt%@77K），室温低。
- 碳纳米管早期宣称的高容量未获严格证实——考题若出现，以"物理吸附、低温有利、可逆快"作答。
- 评价指标：BET 比表面、孔体积、等量吸附热（最佳 ~15–25 kJ/mol 平衡吸附/脱附）。

## 四、关键结论

- 储氢三方式：高压、液氢、材料（材料 = 物理吸附 + 化学储氢两类）。
- wt% 计算：m(H)/m(总)×100%，分母含氢；LaNi₅H₆ ≈ 1.4%、MgH₂ ≈ 7.6%、NH₃BH₃ ≈ 19.6%。
- 金属氢化物：M + x/2 H₂ ⇌ MHₓ，平台压随温度指数上升（van't Hoff）——放氢要加热。
- 高容量（轻质氢化物）普遍伴随高放氢温度/可逆性差——综合性能才决定实用。
- 氢能链：制（电解/重整）–储运（材料/高压/液氢）–用（燃料电池）。

## 五、常见分类或情形

- **按结合方式**：物理吸附（MOF/碳/分子筛）、化学储氢（金属氢化物/配位氢化物/氨基化物）。
- **按金属**：AB₅（LaNi₅）、AB₂（ZrMn₂ 型）、AB（TiFe）、A₂B（Mg₂Ni）、BCC 固溶体（V 基）。
- **按轻质体系**：MgH₂、LiH、LiNH₂–LiH、NaAlH₄、LiBH₄、NH₃BH₃。
- **按应用**：镍氢电池负极（LaNi₅ 型储氢合金）、车载储氢罐、便携储氢、固定式储运。
- **按考法**：容量计算、吸放氢反应式、平台压与温度关系、方式比较、材料选择。

## 六、适用条件与限制

- 单一指标陷阱：wt% 高 ≠ 好用——放氢温度、可逆性、循环衰减、杂质气体（B₂H₆/NH₃）都要考虑。
- 金属氢化物吸氢放热（ΔH < 0 吸氢放热？注意：M + H₂ → MHₓ 是放热，放氢吸热）——放氢需供热，车用发动机余热可能不足。
- 氢脆/粉化：储氢合金反复吸放氢体积膨胀易粉化（LaNi₅ 需活化与结构稳定化）。
- 安全：氢气爆炸极限宽（4–75%）、易泄漏——材料储氢安全性是其卖点之一。
- 物理吸附容量随温度敏感：室温容量低是 MOF/碳实用化的主要瓶颈。

## 七、常见比较与易混点

| 易混点 | 正确辨析 |
|:---|:---|
| 物理吸附 vs 化学储氢 | 物理吸附靠范德华力（H₂ 分子、低温高压、快可逆）；化学储氢成 M–H 键（原子/离子 H、需热/压、容量高）——看是否"断键/成键" |
| 储氢合金吸放氢是物理还是化学 | 化学过程（M–H 键形成/断裂）；不是"把氢气装进合金空隙"这么简单（虽与空隙有关） |
| wt% 分子分母 | wt% = 氢质量/吸氢后总质量——分母含氢；用"材料质量"作分母会高估 |
| 放氢方向热效应 | 吸氢放热、放氢吸热（可逆金属氢化物）；说"放氢放热"即错（除非是水解产氢等放热反应，别混） |
| 高压/液氢 vs 材料 | 高压/液氢是"装氢"（物理容器）；材料储氢是"与材料作用"（吸附/键合）——用途都可但原理不同 |

## 八、与其他知识点的联系

- [[氢键]]/氢化物化学：离子氢化物（LiH/NaH）、共价氢化物与金属氢化物的分类。
- 热力学（van't Hoff/平台压）：吸放氢平衡与温度关系（化学原理衔接）。
- 晶体结构（LaNi₅ 型 CaCu₅ 结构）：储氢合金的晶胞与空隙（结构-性能关联）。
- 电化学（镍氢电池）：储氢合金负极与电池反应。
- 能源化学/材料前沿：MOF、氨硼烷等（与 反钙钛矿/能带材料 同属材料视野）。

## 九、典型题型

- **容量计算**：LaNi₅H₆/MgH₂/LiNH₂ 体系的 wt% 计算（给摩尔质量）。
- **反应式**：写储氢合金可逆吸放氢反应并说明温度/压力如何移动平衡。
- **材料选择**：车载（需常温放氢）vs 固定储能（可高温）选材料并说明理由。
- **方式比较**：高压/液氢/材料三方式优缺点（39 届题-039-6 语境）。
- **前沿分析**：MOF 低温高容量 vs 室温低；氨硼烷高容量但放氢难——综合权衡。

## 十、例题

**例题 1**：LaNi₅ 合金吸氢形成 LaNi₅H₆。计算其质量储氢容量，并与 MgH₂ 比较。

**解答**：M(LaNi₅) = 138.91 + 5×58.69 = 432.36 g/mol；6 个 H 为 6×1.008 = 6.05。wt%(LaNi₅H₆) = 6.05/(432.36+6.05) ×100% ≈ **1.38%**。MgH₂：M = 24.31+2×1.008 = 26.32，wt% = 2.02/26.32 ≈ **7.7%**。比较：MgH₂ 容量高约 5.5 倍，但放氢需约 300 °C+；LaNi₅ 容量低却可在室温附近可逆吸放氢——工程上按应用温度选材。

**例题 2**：某储氢合金在 25 °C 吸氢平台压约 0.3 MPa，加热到 100 °C 平台压约升至 3 MPa。解释该现象并判断吸氢是放热还是吸热。

**解答**：平台压与温度满足 van't Hoff 关系（ln p ∝ −ΔH/RT）：温度升高平台压指数上升——该合金 25→100 °C 平台压 0.3→3 MPa 正符合。由斜率可求放氢焓 ΔH > 0（放氢吸热），故**吸氢放热**（M + H₂ → MHₓ + 热）。实际应用即利用此性质：加压低温吸氢、降压/加热放氢。

**例题 3**：比较 MOF-5（77 K 吸附约 5 wt%）、LaNi₅H₆（约 1.4 wt%）、NH₃BH₃（约 19.6 wt%）在"车载燃料电池供氢"场景的适用性。

**解答**：车载要求：体积/质量密度高 + 放氢温度温和（80–200 °C 可用发动机/电池余热）+ 快速可逆 + 安全。MOF-5 需 77 K 液氮温区，车载不可行（低温能耗巨大）——适用固定深冷场景；LaNi₅H₆ 放氢条件温和但容量低（1.4 wt%）→ 增重明显，早期镍氢电池可、现代车载勉强；NH₃BH₃ 容量极高但放氢温度高（>100 °C 起始、完全放氢更高）且伴随 NH₃/B₂H₆ 杂质、不可逆（一次性）——需催化/纳米化改善，或用于"一次性/再生式"场景。综合：暂无完美车载材料，方向是"中温可逆轻质氢化物 + 纳米/催化调控"。

## 十一、易错点

| 常见错误 | 错在哪里 | 反例 / 判别要点 |
|:---|:---|:---|
| 储氢材料只是"装氢容器" | 材料靠吸附/键合储氢（物理吸附或化学 M–H 键），不是普通容器 | 判别：金属氢化物成键（化学）、MOF 孔吸附（物理）——都"与材料作用" |
| 金属氢化物储氢当物理过程 | LaNi₅ 等吸氢形成 MHₓ 是**化学过程**（M–H 键） | 反例：LaNi₅ + 3H₂ → LaNi₅H₆ 有新键生成——化学储氢 |
| wt% 分母写错 | 分母是吸氢后总质量（材料+氢）；用材料质量算会高估 | 自检：LaNi₅H₆ 应为 6.05/438.4；写成 6.05/432.4（1.40% vs 1.38%）数值不同 |
| 热效应方向搞反 | 可逆金属氢化物：吸氢放热、放氢吸热；把"放氢放热"当普遍规律即错 | 判别：平台压随 T 升 = 放氢吸热 ΔH>0（van't Hoff）；水解制氢（NaH+H₂O）是另一类放热反应勿混 |
| 只看 wt% 定优劣 | 容量高常伴随放氢温度高/可逆差/杂质——LaNi₅ 容量低仍被镍氢电池采用 | 判别：评价材料至少看 容量×温度×可逆×循环×成本 五维 |

## 十二、🎯 教学视角

### 12.1 学习路径建议
先理解氢气储存的基本原理（物理吸附 vs 化学键合），再学金属氢化物（LaNi₅/MgH₂）的吸放氢反应与平台压，接着练 wt% 容量计算，最后用"车载/固定场景选材"综合题把 容量-温度-可逆 权衡串起来。

### 12.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 储氢材料就是能装氢气的容器 | 储氢材料通过物理吸附（MOF/碳）或化学键合（金属氢化物）方式储存氢气 |
| 金属氢化物储氢是物理过程 | 金属氢化物储氢是化学过程（形成 M–H 键） |
| 储氢容量越高越好 | 还需考虑可逆性、放氢温度、动力学、循环寿命与安全等综合性能 |
| 放氢是放热 | 可逆金属氢化物放氢吸热（需加热），吸氢放热 |

### 12.3 入门级例题
**题目**：LaNi₅ 合金吸收氢气形成 LaNi₅H₆，计算其储氢容量（质量分数）。

**解答**：M(LaNi₅) = 138.91 + 5×58.69 = 432.36 g/mol；6 个 H ≈ 6.05 g/mol。储氢容量 = 6.05/(432.36+6.05)×100% ≈ 1.38%。

### 12.4 与现实世界的联系
1. **新能源汽车**：氢燃料电池车使用高压/低温储氢罐，车载储氢合金与 LOHC 在研究。
2. **航空航天**：液氢是火箭/航天器推进剂（液氢储罐技术成熟）。
3. **便携与固定电源**：镍氢电池负极用 LaNi₅ 型储氢合金；电网储能探索 MgH₂ 等高温体系。
