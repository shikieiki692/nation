# 铝、锗和锑分族

## 核心概念

### p区金属元素概述
- p区金属包括：铝(Al)、镓(Ga)、铟(In)、锗(Ge)、锡(Sn)、铅(Pb)等
- 主要氧化态：+3（Al、Ga）、+2/+4（Ge、Sn、Pb）
- 稀散元素：镓(Ga)、铟(In)、锗(Ge)、硒(Se)等在自然界中分布分散，很少形成独立矿床

### 铝的化学
- **地壳丰度**：仅次于Si和O，居第三位（8.8%）
- **矿石类型**：铝土矿（Al₂O₃）、水合铝石（Al(OH)₃）、刚玉（α-Al₂O₃）
- **其他含铝矿物**：伊利石、高岭石（中国特有）、蒙脱石（层状硅酸盐）
- **提取方法**：电解熔融Al₂O₃（使用冰晶石Na₃AlF₆降低熔点）

### 镓的化学
- **稀散元素**：常与锌、铝、锗等伴生
- **制备**：从铝土矿残渣中回收，利用Ga³⁺和Al³⁺氢氧化物沉淀pH差异分离
- **单质特性**：熔点极低但沸点高，两性金属

### 锗的化学
- **半导体材料**：GeAs（立方ZnS结构），带宽大于硅
- **提取**：从ZnS矿中富集GeS₂/GeS，通过盐酸处理和氢气还原获得高纯锗

### 锡的化学
- **同素异形体**：α-Sn（灰锡，金刚石型，<18℃）和β-Sn（白锡，四方晶系，>18℃）
- **锡瘟现象**：白锡降温至18℃以下时，需灰锡晶核引发快速转化

### 铅的化学
- **矿物**：方铅矿（PbS）、白铅矿（PbCO₃）、磷氯铅矿等
- **制备**：矿石焙烧→PbO/PbSO₄→焦炭还原得粗铅
- **晶体结构**：立方最密堆积(CCP)，空间群Fm3m

## 关键反应

### 铝的反应
```
铝热反应：2Al + Fe₂O₃ → Al₂O₃ + 2Fe（ΔG < 0，可还原多种金属氧化物）
电解制铝：2Al₂O₃(熔融) → 4Al + 3O₂↑（冰晶石作助熔剂）
铝与碱：2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
```

### 铝的化合物制备
```
AlF₃：2Al + 6HF → 2AlF₃ + 3H₂↑
      Al₂O₃ + 6HF → 2AlF₃ + 3H₂O
      2Na₃AlF₆ + Al₂(SO₄)₃ → 4AlF₃ + 3Na₂SO₄（固相法）
AlCl₃：2Al + 3Cl₂ → 2AlCl₃
       3C + 2Al₂O₃ + 6Cl₂ → 4AlCl₃ + 3CO₂
```

### 镓的反应
```
氢化镓制备：3LiAlH₄ + GaCl₃ → Ga₂H₆ + 3LiCl
GaCl₃的Lewis酸反应：GaCl₃·L → [LGaCl₂]⁺[GaCl₄]⁻（1:1加合物）
                    GaCl₃·2L → [L₂GaCl₂]⁺[GaCl₄]⁻（1:2加合物）
```

### 锗的反应
```
氢化锗制备：GeHCl₃ + 3Na → 3NaCl + GeH（遇空气爆炸，强还原性）
氧化还原：Ge₂O₃ + 4Ge → 3Ge₂O（500℃真空条件）
半导体制备：4GeO + As₄(g) → 4GeAs + GeCl₃
```

### 锡的反应
```
与稀硝酸：4Sn + 10HNO₃ → NH₄NO₃ + 4Sn(NO₃)₂ + 3H₂O
与热浓碱：Sn + 2NaOH + 2H₂O → Na₂SnO₃ + 2H₂↑
二氯化锡水解：SnCl₂ + H₂O → Sn₃O₂·H₂O + HCl（实际产物为簇状结构）
```

### 铅的反应
```
与SO₂反应：Pb + SO₂ → PbSO₄（300℃左右）
制备PbCl₂：2PbO + Cl₂ → 2PbCl₂ + O₂
            PbO + 2HCl(g) → PbCl₂ + H₂O
碱式碳酸铅：Pb(OAc)₂ + CO₂ → 2PbCO₃·Pb(OH)₂（铅白）
```

## 规律与趋势

### p区金属的周期性
| 性质 | Al | Ga | Ge | Sn | Pb |
|------|-----|-----|-----|-----|-----|
| 主要氧化态 | +3 | +3 | +2,+4 | +2,+4 | +2,+4 |
| 熔点/℃ | 660 | 30 | 938 | 232 | 327 |
| 金属性 | 两性 | 两性 | 准金属 | 金属 | 金属 |
| Lewis酸性 | 中等 | 强 | - | - | - |

### 卤化物的结构变化
- **AlF₃**：离子化合物，[AlF₆]³⁻变形八面体，固态六配位，气态sp²平面三角形
- **AlCl₃**：固态层状六配位，气态二聚体Al₂Cl₆（四配位），高温解离为单体
- **GaCl₃**：常温液态二聚体Ga₂Cl₆，Lewis酸性强于AlCl₃

### 氧化物的晶型与稳定性
- **Al(OH)₃**：OH⁻呈hcp排列，Al³⁺填入1/3八面体空隙，层状结构
- **α-Al₂O₃（刚玉）**：O²⁻呈hcp排列，Al³⁺填入2/3八面体空隙，R3c空间群
- **GeO₂**：五种晶型（α, β, γ, δ, ω），β型最稳定，仅溶于熔融碱
- **Sn(OH)₂**：实际为H₄Sn₆O₈或Sn₆O₄(OH)₄簇状结构

### 半导体材料特性
- **GaAs**：立方ZnS结构，带宽大于Si，可制备n型和p型半导体
- **PbS**：NaCl型结构，半导体特性，可被O₃氧化漂白

## 典型应用

### 竞赛考点
1. **铝热反应的热力学计算**：通过ΔG-T图判断反应可行性
2. **AlCl₃的结构分析**：固态vs气态配位数变化（6→4→3），点群判断（D₂h）
3. **GaCl₃的Lewis酸性**：1:1和1:2加合物的形成与检测
4. **Sn(OH)₂的真实结构**：簇状结构H₄Sn₆O₈的形成机理
5. **锡的同素异形体**：α-Sn和β-Sn的转化条件与锡瘟现象
6. **Pb的配位化学**：PbCl₂的九配位结构（三帽三棱柱）

### 工业应用
- **铝的提取**：电解法（冰晶石助熔）
- **GaAs半导体**：MOCVD法制备（GaMe₃ + AsH₃ → GaAs + 3CH₄）
- **铅蓄电池**：PbO₂ + Pb + 2H₂SO₄ → 2PbSO₄ + 2H₂O
- **碱式碳酸铅**：颜料（铅白），涂料工业

### 实验室制备
- **高纯Ge**：GeCl₄水解控制pH=5.3最佳
- **SnCl₂脱水**：真空或干燥HCl气流中加热，或用乙酸酐快速脱水
- **PbCl₂**：热溶液中易溶，冷却后析出晶体
