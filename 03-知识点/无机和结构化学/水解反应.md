# 水解反应

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 上位框架：[[酸碱理论]] · [[化学平衡]]
- 易混辨析：[[水合物]]（水合 ≠ 水解）

## 一、定义

**水解反应（hydrolysis）** 指化合物与水作用而发生的分解或取代反应：水分子拆开为 $\mathrm{H^+}$ 与 $\mathrm{OH^-}$（或 $\mathrm{H}$ 与 $\mathrm{OH}$）两部分，分别加到原分子的两个片段上，**旧键断裂、生成两个新产物**。

统一的形式化写法：

$$\mathrm{A{-}B + H_2O \longrightarrow A{-}OH + H{-}B}$$

按被水解的对象，竞赛中分三大类，机理完全不同，必须分开处理：

| 类别 | 典型对象 | 驱动力 | 所在节 |
|:---|:---|:---|:---|
| **离子型水解** | 弱酸阴离子 / 弱碱阳离子（盐类） | 酸碱质子转移平衡 | §二 |
| **共价型水解** | 卤化物、氮化物、碳化物、氢化物 | 配位/亲核进攻 + 断键 | §三 |
| **有机物水解** | 卤代烃、酯、酰胺、酰卤、腈、缩醛 | 亲核取代/加成-消除 | §四 |

> **关键区分：水解 ≠ 水合。** 水合是水加成上去、不丢原子（$\mathrm{C{=}O \to C(OH)_2}$，见 [[水合物]]）；水解是水参与并**把分子拆成两块**。二者常在同一体系中竞争。

## 二、离子型水解：盐类水解

### 2.1 本质

盐类水解是**酸碱中和的逆反应**。弱酸的共轭碱（$\mathrm{A^-}$）或弱碱的共轭酸（$\mathrm{BH^+}$）与水发生质子转移：

- 弱酸强碱盐：$\mathrm{A^- + H_2O \rightleftharpoons HA + OH^-}$ → 溶液显**碱性**
- 强酸弱碱盐：$\mathrm{BH^+ + H_2O \rightleftharpoons B + H_3O^+}$ → 溶液显**酸性**
- 弱酸弱碱盐：双方同时水解，pH 由 $K_a$ 与 $K_b$ 的相对大小决定

强酸强碱盐（$\mathrm{NaCl}$、$\mathrm{KNO_3}$ 等）**不水解**：共轭碱/酸太弱，无法从水夺质子。

### 2.2 水解常数与计算

| 盐的类型 | 水解常数 | 近似 [H⁺] 或 [OH⁻] |
|:---|:---|:---|
| 弱酸强碱盐 NaA | $K_h = \dfrac{K_w}{K_a}$ | $[\mathrm{OH^-}] \approx \sqrt{K_h c}$ |
| 强酸弱碱盐 BHCl | $K_h = \dfrac{K_w}{K_b}$ | $[\mathrm{H^+}] \approx \sqrt{K_h c}$ |
| 弱酸弱碱盐 BA | $K_h = \dfrac{K_w}{K_a K_b}$ | 需联立，不可简单开方 |

**水解度** $h$（已水解的分数）在 $h \ll 1$ 时：

$$h \approx \sqrt{\frac{K_h}{c}}$$

两条直接推论，竞赛高频考：

1. **稀释促进水解**：$c \downarrow \Rightarrow h \uparrow$（同 Le Chatelier）
2. **升温促进水解**：中和放热 → 水解**吸热** → $T \uparrow \Rightarrow K_h \uparrow$

完整推导与缓冲体系对照见 [[酸碱理论]]。

### 2.3 双水解

弱酸弱碱盐中阴阳离子**互相促进**水解，若产物为难溶物或气体（脱离体系），水解可**进行到底**：

$$\mathrm{Al^{3+} + 3HCO_3^- \longrightarrow Al(OH)_3\downarrow + 3CO_2\uparrow}$$

$$\mathrm{2Al^{3+} + 3S^{2-} + 6H_2O \longrightarrow 2Al(OH)_3\downarrow + 3H_2S\uparrow}$$

判据：产物之一**难溶**（见 [[溶度积]]）或**挥发**，则平衡被彻底拉向右方，反应不可逆。这类离子不能共存于溶液。

## 三、共价型水解：无机物的水解

### 3.1 机理通式

无机共价化合物（多为卤化物、氢化物、氮化物、碳化物）的水解，本质是**水分子的亲核进攻 + 离去基团带走质子**：

1. 中心原子接受 $\mathrm{H_2O}$ 的孤对电子 → 配位（超价中间体）
2. $\mathrm{H^+}$ 转移到离去基团 $\mathrm{X}$ 上
3. $\mathrm{M{-}X}$ 断裂，$\mathrm{X}$ 以 $\mathrm{HX}$ 形式离去
4. 重复直至所有可离去基团换完

$$\mathrm{MX_n + n\,H_2O \longrightarrow M(OH)_n + n\,HX}$$

### 3.2 为什么有的水解、有的不水解？

**核心判据是中心原子的极化能力（[[离子极化]]）与是否有可接受孤对电子的空轨道。**

| 中心原子特征 | 水解倾向 | 例子 |
|:---|:---|:---|
| 高电荷、小半径（极化力强） | 强 | $\mathrm{PCl_5}$、$\mathrm{SiCl_4}$、$\mathrm{AlCl_3}$ |
| 有低能空 d 轨道 / 可超价 | 强 | $\mathrm{SiCl_4}$、$\mathrm{PCl_5}$、$\mathrm{SF_4}$ |
| 第二周期、无空 d 轨道、满配位 | 极难 | $\mathrm{CCl_4}$、$\mathrm{NF_3}$、$\mathrm{CF_4}$ |

$\mathrm{CCl_4}$ 与 $\mathrm{SiCl_4}$ 的对比是最经典的考点：同为四氯化物，$\mathrm{SiCl_4}$ 遇水剧烈发烟水解，$\mathrm{CCl_4}$ 却完全不水解。原因是 C 为第二周期元素、**无空 d 轨道**、四个 Cl 已把配位层塞满，水分子无处进攻；Si 有 3d 空轨道且半径大，可接受水的孤对电子形成五配位中间体。

### 3.3 水解产物的判断规则

**规则：水解时各元素氧化数不变**（水解不是 [[氧化还原反应]]），产物按"正负价组合"推定。

| 类别 | 通式 | 实例 |
|:---|:---|:---|
| 离子型氢化物 | $\mathrm{MH + H_2O \to MOH + H_2\uparrow}$ | $\mathrm{CaH_2 + 2H_2O \to Ca(OH)_2 + 2H_2\uparrow}$ |
| 离子型氮化物 | $\mathrm{M_3N + 3H_2O \to 3MOH + NH_3\uparrow}$ | $\mathrm{Mg_3N_2 + 6H_2O \to 3Mg(OH)_2 + 2NH_3\uparrow}$ |
| 离子型碳化物 | 按碳负离子形态定产物 | $\mathrm{CaC_2 + 2H_2O \to Ca(OH)_2 + C_2H_2\uparrow}$；$\mathrm{Al_4C_3 + 12H_2O \to 4Al(OH)_3 + 3CH_4\uparrow}$ |
| 磷的卤化物 | 逐步水解 | $\mathrm{PCl_3 + 3H_2O \to H_3PO_3 + 3HCl}$；$\mathrm{PCl_5 \xrightarrow{少量水} POCl_3 + 2HCl \xrightarrow{过量水} H_3PO_4 + HCl}$ |
| 硅的卤化物 | 完全水解成硅酸 | $\mathrm{SiCl_4 + 4H_2O \to H_4SiO_4\ (或\ SiO_2\cdot xH_2O) + 4HCl}$ |

**注意特例 $\mathrm{NCl_3}$**：N 与 Cl 电负性接近（N 3.04，Cl 3.16，Cl 略大），但 N **无空 d 轨道**，水只能进攻 Cl 一侧，因此产物是 $\mathrm{NH_3 + 3HOCl}$ 而非 $\mathrm{HNO_3 + 3HCl}$：

$$\mathrm{NCl_3 + 3H_2O \longrightarrow NH_3 + 3HOCl}$$

**判断口诀：水电离成 H⁺ 与 OH⁻ 后，谁被哪个原子拿走，取决于中心原子与配位原子谁的"空位"更可进攻、以及它们各自形成的含氧酸/氢化物哪个更稳定。**

> 相关题：[[题-027-5-反钙钛矿M摩尔质量]]、[[题-030-1-离子化合物A2B化学式推断]]
> 高价金属氟化物的特殊水解行为见 [[高价金属氟化物水解]]；$\mathrm{Cr^{3+}}$ 的水解-聚合平衡见 [[三价铬水解]]。

## 四、有机物的水解

机理上是**亲核取代（饱和碳）**或**加成-消除（羰基碳）**，水/氢氧根作亲核体。活性顺序与离去基团能力直接相关（见 [[离去基与pKa]]、[[亲核取代]]）。

| 底物 | 条件 | 产物 | 可逆性 |
|:---|:---|:---|:---|
| 卤代烃 | 水/OH⁻ | 醇 | 可逆但可推动 |
| 酰氯 | 水（常温即剧烈） | 羧酸 + HCl | 不可逆 |
| 酸酐 | 水 | 2 羧酸 | 不可逆 |
| 酯 | 酸催化（可逆）或碱催化（**皂化**，不可逆） | 羧酸（或羧酸盐）+ 醇 | 见上 |
| 酰胺 | 强酸/强碱 + 长时间加热 | 羧酸（或羧酸盐）+ 胺/氨 | 需强制条件 |
| 腈 | 酸/碱催化，分步 | 酰胺 → 羧酸 | 分步 |
| 缩醛 | 稀酸 | 醛/酮 + 醇 | 可逆（脱保护手段） |

**活性递变的结构理由**：离去基团越易离去（$\mathrm{Cl^- > RCOO^- > OR^- > NR_2^-}$），羰基碳越缺电子，水解越快。详细排序与四面体中间体分析见 [[羧酸衍生物]]。

**酯的碱催化水解为何不可逆**：产物羧酸被碱中和成羧酸盐，$\mathrm{RCOO^-}$ 失去亲电性、无法被醇进攻，平衡被单向锁死——这是"皂化"与"酸性水解"的根本区别。

## 五、解题判断流程

遇到"某物质水解产物是什么"或"水解程度如何比较"，按序过一遍：

1. **定类型**：盐类（离子型）还是共价化合物还是有机物？三类走不同规则。
2. **盐类** → 算 $K_h$，判断酸碱性；检查是否双水解且产物脱离体系（沉淀/气体）。
3. **共价无机** → ①先看中心原子能否接受孤对电子（空轨道/超价能力）；②氧化数不变，按正负价组合推产物；③注意 $\mathrm{NCl_3}$、$\mathrm{CCl_4}$ 这类"进攻位点反常"的特例。
4. **有机** → 看离去基团能力与羰基亲电性；碱性条件注意产物被中和导致的不可逆。
5. **检查守恒**：原子守恒 + 电荷守恒 + **氧化数不变**。

## 六、常见误区

| 误区 | 纠正 |
|:---|:---|
| 认为所有盐都水解 | 强酸强碱盐不水解；共轭酸/碱越弱越不水解 |
| 把水解当氧化还原 | 水解中**各元素氧化数不变** |
| 认为 $\mathrm{CCl_4}$ 与 $\mathrm{SiCl_4}$ 水解行为相同 | C 无空 d 轨道且满配位，$\mathrm{CCl_4}$ 不水解 |
| 认为稀释抑制水解 | 稀释**促进**水解，$h \approx \sqrt{K_h/c}$ |
| 认为水解一定吸热/放热 | 水解是中和的逆反应，**吸热**，升温促进 |
| 混淆"水合"与"水解" | 水合加成不拆分，水解拆成两块（见 [[水合物]]） |
