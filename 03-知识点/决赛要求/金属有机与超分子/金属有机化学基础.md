# 金属有机化学基础

## 核心概念

- **定义**：含有至少一根金属-碳键的配位化合物
- **学科交叉**：50%无机化学 + 50%有机化学
- **研究视角**：无机关注结构（Structure），有机关注反应性（Reactivity）

## 关键概念

### 学科演变
- 早期：作为配位化学的子集（无机化学家研究）
- 现代：发展为与配位化学并列的交叉学科

### 核心反应类型
- 氧化加成（Oxidative Addition）
- 还原消除（Reductive Elimination）
- 迁移插入（Migratory Insertion）
- β-氢消除（β-Hydride Elimination）

### 18电子规则
- 过渡金属配合物倾向于达到18电子构型（满壳层）
- 16电子配合物也常见（特别是Pt(II)、Pd(II)）

## 典型应用

- 催化循环：如Suzuki偶联、Heck反应
- Grubbs催化剂（烯烃复分解反应，诺贝尔奖）
- Wilkinson催化剂（均相加氢）

## 五、🎯 教学视角

### 5.1 学习路径建议
建议先掌握配位化学基础（晶体场理论、18电子规则），再学习金属有机化学的核心反应类型（氧化加成、还原消除、迁移插入、β-氢消除）。理解这些基元反应是分析催化循环的前提，最后通过具体催化体系（如Suzuki偶联）建立整体认识。

### 5.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 所有金属有机化合物都遵循18电子规则 | 16电子配合物也很常见，特别是Pt(II)、Pd(II)等d⁸构型金属 |
| 氧化加成一定增加金属氧化态 | 氧化加成使金属氧化态+2、配位数+2，但需注意协同机理与SN2机理的区别 |
| 催化循环中每步反应都必须经过 | 催化循环是理想化模型，实际反应可能存在副反应和竞争路径 |

### 5.3 入门级例题
**题目**：Wilkinson催化剂RhCl(PPh₃)₃催化烯烃加氢，请写出一个催化循环中可能涉及的基元反应步骤。
**解答**：可能涉及的步骤包括：(1)配体解离：RhCl(PPh₃)₃ → RhCl(PPh₃)₂ + PPh₃（产生空配位点）；(2)烯烃配位：RhCl(PPh₃)₂ + CH₂=CH₂ → RhCl(PPh₃)₂(CH₂=CH₂)；(3)氧化加成：H₂ + Rh(I) → Rh(III)-H₂；(4)迁移插入：Rh-H + C=C → Rh-C-C-H；(5)还原消除：Rh-C-C-H → Rh(I) + 烷烃。

### 5.4 与现实世界的联系
- **药物合成**：Suzuki偶联反应广泛用于药物分子中碳-碳键的构建，如抗癌药物Imatinib的合成
- **高分子工业**：Ziegler-Natta催化剂用于聚烯烃的大规模工业生产
- **绿色化学**：Grubbs催化剂的烯烃复分解反应为有机合成提供了原子经济性高的新路径
