# 热力学四大基本方程

## 核心概念

- 从热力学第一、第二定律联立推导出的四个微分方程
- 是所有热力学关系式的基础
- 适用于封闭体系、不做非体积功的条件

## 关键公式/方程式

### 四大基本方程
$$dU = TdS - pdV$$
$$dH = TdS + Vdp$$
$$dA = -SdT - pdV$$
$$dG = -SdT + Vdp$$

### 约束条件
- 封闭体系（非开放体系）
- 不做非体积功（$w' = 0$）
- 不要求理想气体，适用于任何体系

### 记忆要点
- 每个公式都包含熵变项（$TdS$ 或 $-SdT$）和功变项（$-pdV$ 或 $Vdp$）
- 只需熟记 $dU$ 表达式，其余可通过定义式代换推导

## 推导关系

$$dU = TdS - pdV$$
$$\xrightarrow{H = U + pV} dH = dU + pdV + Vdp = TdS + Vdp$$
$$\xrightarrow{A = U - TS} dA = dU - TdS - SdT = -SdT - pdV$$
$$\xrightarrow{G = H - TS} dG = dH - TdS - SdT = -SdT + Vdp$$

## 典型应用

- 推导麦克斯韦关系式
- 推导各种热力学偏导数关系
- 竞赛中作为热力学推导的起点

## 五、🎯 教学视角

### 5.1 学习路径建议
建议先熟练掌握热力学第一定律（内能变化）和第二定律（熵变）的基本概念，再学习焓、亥姆霍兹自由能、吉布斯自由能的定义，最后通过定义式代换推导出四大基本方程。掌握一个公式后，其余可通过H=U+pV、A=U-TS、G=H-TS的关系式依次推导。

### 5.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 四大基本方程只适用于理想气体 | 四大基本方程适用于任何封闭体系，不要求理想气体条件 |
| dG=-SdT+Vdp中G只随T、p变化 | 这是全微分形式，G是T和p的函数，但在有非体积功时还需考虑其他变量 |
| 记住四个公式就够了 | 更重要的是理解推导过程，竞赛中常要求从dU出发推导其他热力学量的关系 |

### 5.3 入门级例题
**题目**：从dU=TdS-pdV出发，推导出dG的表达式。
**解答**：由G=H-TS=U+pV-TS，取全微分：dG=dU+pdV+Vdp-TdS-SdT。代入dU=TdS-pdV：dG=(TdS-pdV)+pdV+Vdp-TdS-SdT=-SdT+Vdp。这就是吉布斯自由能的基本方程。

### 5.4 与现实世界的联系
- **化学平衡计算**：dG=-SdT+Vdp是推导范特霍夫方程和判断反应自发性的基础
- **材料相变**：通过dG=0条件可推导克拉佩隆方程，预测相变温度与压力的关系
- **电化学**：dG=-nFE将热力学与电化学联系起来，是计算电池电动势的理论基础
