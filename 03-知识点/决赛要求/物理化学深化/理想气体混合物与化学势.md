# 理想气体混合物与化学势

## 核心概念

- **化学势**：物质B的吉布斯自由能对物质的量的偏导数
- 化学势差是化学反应和相变过程的驱动力
- 平衡条件：各组分化学势相等

## 关键公式/方程式

### 化学势定义
$$\mu_B = \left(\frac{\partial G}{\partial n_B}\right)_{T, P, n_{C(\neq B)}}$$

### 理想气体化学势
$$\mu_B(T, P) = \mu_B^{\theta}(T) + RT \ln \frac{P_B}{P^{\theta}}$$

### 理想液体混合物化学势
$$\mu_B(T, P) = \mu_B^{\theta}(T) + RT \ln x_B$$

### 多组分热力学基本方程
$$dG = -SdT + Vdp + \sum_B \mu_B dn_B$$

### 偏摩尔量
$$V_B = \left(\frac{\partial V}{\partial n_B}\right)_{T, P, n_{C(\neq B)}}$$
$$\left(\frac{\partial \mu_B}{\partial P}\right)_{T, n} = V_B$$
$$\left(\frac{\partial \mu_B}{\partial T}\right)_{P, n} = -S_B$$

## 规律与趋势

- 理想气体混合：$\Delta H_{\text{mix}} = 0$，$\Delta V = 0$，$\Delta S > 0$，$\Delta G < 0$
- 物质总是从化学势高的状态向化学势低的状态转移
- 理想体系的偏摩尔体积等于纯组分摩尔体积

## 典型应用

- 推导范特霍夫等温式
- 理解化学平衡的微观本质
- 竞赛中分析多组分体系的热力学行为
