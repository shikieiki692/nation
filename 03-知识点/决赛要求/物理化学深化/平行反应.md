# 平行反应

## 核心概念

- 反应物同时通过两条或多条路径生成不同产物
- 总速率常数等于各路径速率常数之和
- 表观活化能需用阿伦尼乌斯公式微分形式推导

## 关键公式/方程式

### 一级平行反应
$$A \xrightarrow{k_1} B, \quad A \xrightarrow{k_2} C$$

### 总速率常数
$$k = k_1 + k_2$$

### 转化时间
$$t = \frac{1}{k} \ln \frac{a_0}{a_t}$$

### 表观活化能（正确公式）
$$E_a(k_1 + k_2) = E_{a1} k_1 + E_{a2} k_2$$

$$E_a = \frac{E_{a1} k_1 + E_{a2} k_2}{k_1 + k_2}$$

### 常见错误
错误假设A相同直接求和：$E_a = -RT \ln(e^{-E_{a1}/RT} + e^{-E_{a2}/RT})$（错误！）

## 规律与趋势

- 速率常数单位 $s^{-1}$ 表明为一级反应
- 表观活化能是各路径活化能的加权平均
- 权重为各路径的速率常数（高温时高活化能路径贡献增大）

## 典型应用

- 乙烷热分解反应机理分析
- 竞赛中判断反应机理的合理性
- 计算不同产物的比例

## 🎯 教学视角

### 学习路径建议
先掌握 [[Arrhenius方程]] 中速率常数与活化能的关系，再理解单通道反应的动力学行为。平行反应是多通道竞争的推广，关键在于速率常数相加而非活化能相加。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 表观活化能是各路径活化能的算术平均 | 表观活化能是加权平均，权重为各路径的速率常数 $k_i$，高温时高活化能路径权重增大 |
| 产物比例取决于活化能之差 | 产物比例由 $k_1/k_2$ 决定，取决于两条路径的活化能和指前因子之比 |
| 总反应级数等于各平行反应级数之和 | 对一级平行反应，总反应仍为一级，$k_{\text{总}} = k_1 + k_2$ |

### 入门级例题
**题目**：某一级平行反应的两条路径活化能分别为 $E_{a1} = 80\,\text{kJ/mol}$，$E_{a2} = 120\,\text{kJ/mol}$，在某温度下 $k_1 = 3k_2$，求表观活化能。
**解答**：$E_a = \frac{E_{a1} k_1 + E_{a2} k_2}{k_1 + k_2} = \frac{80 \times 3 + 120 \times 1}{3 + 1} = \frac{360}{4} = 90\,\text{kJ/mol}$。

### 与现实世界的联系
1. 石油裂解中烃类同时发生多种分解路径，通过平行反应模型优化温度以控制产物分布（如乙烯 vs 丙烯比例）。
2. 药物代谢中药物分子在肝脏中通过多种酶同时降解，平行反应动力学用于预测药物半衰期。
