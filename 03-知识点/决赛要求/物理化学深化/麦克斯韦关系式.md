# 麦克斯韦关系式

## 核心概念

- 从热力学四大基本方程出发，利用全微分的数学对称性推导
- 将不可直接测量的量转化为可实验测量的 p-T 关系

## 关键公式/方程式

### 四大基本方程
$$dU = TdS - pdV$$
$$dH = TdS + Vdp$$
$$dA = -SdT - pdV$$
$$dG = -SdT + Vdp$$

### 四个麦克斯韦关系
$$\left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial p}{\partial S}\right)_V$$

$$\left(\frac{\partial T}{\partial p}\right)_S = \left(\frac{\partial V}{\partial S}\right)_p$$

$$\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V$$

$$\left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p$$

### 数学基础
若 $dz = Mdx + Ndy$，则 $\left(\frac{\partial M}{\partial y}\right)_x = \left(\frac{\partial N}{\partial x}\right)_y$

## 规律与趋势

- 记忆技巧：只需记住 $dU = TdS - pdV$，其余可通过勒让德变换推导
- 考试技巧：先推导数学对称关系，再套用四大基本公式
- 注意吉布斯自由能关系式中存在负号（易错点）

## 典型应用

- 推导内能随体积变化：$\left(\frac{\partial U}{\partial V}\right)_T = T\left(\frac{\partial p}{\partial T}\right)_V - p$
- 推导焓随压强变化：$\left(\frac{\partial H}{\partial p}\right)_T = V - T\left(\frac{\partial V}{\partial T}\right)_p$
- 将热力学势函数的变化转化为实验可测参数
