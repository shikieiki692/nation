# 麦克斯韦关系式

## 核心概念

- 从热力学四大基本方程出发，利用全微分的数学对称性推导
- 将不可直接测量的量转化为可实验测量的 p-T 关系

## 关键公式/方程式

### 四大基本方程
$$dU = TdS - pdV$$
$$dH = TdS + Vdp$$
$$dA = -SdT - pdV$$
$$dG = -SdT + Vdp$$

### 四个麦克斯韦关系
$$\left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial p}{\partial S}\right)_V$$

$$\left(\frac{\partial T}{\partial p}\right)_S = \left(\frac{\partial V}{\partial S}\right)_p$$

$$\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V$$

$$\left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p$$

### 数学基础
若 $dz = Mdx + Ndy$，则 $\left(\frac{\partial M}{\partial y}\right)_x = \left(\frac{\partial N}{\partial x}\right)_y$

## 规律与趋势

- 记忆技巧：只需记住 $dU = TdS - pdV$，其余可通过勒让德变换推导
- 考试技巧：先推导数学对称关系，再套用四大基本公式
- 注意吉布斯自由能关系式中存在负号（易错点）

## 典型应用

- 推导内能随体积变化：$\left(\frac{\partial U}{\partial V}\right)_T = T\left(\frac{\partial p}{\partial T}\right)_V - p$
- 推导焓随压强变化：$\left(\frac{\partial H}{\partial p}\right)_T = V - T\left(\frac{\partial V}{\partial T}\right)_p$
- 将热力学势函数的变化转化为实验可测参数

## 🎯 教学视角

### 学习路径建议
先熟练掌握四大热力学基本方程（$dU, dH, dA, dG$），再理解全微分的数学性质 $dz = Mdx + Ndy \Rightarrow (\partial M/\partial y)_x = (\partial N/\partial x)_y$。麦克斯韦关系式是数学技巧与物理直觉的结合。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 四个关系式都要死记硬背 | 只需记住 $dU = TdS - pdV$，其余三个通过勒让德变换（替换变量）即可推出 |
| 麦克斯韦关系式可以直接实验验证 | 它们是恒等式，价值在于将不可测量（如 $\partial S/\partial V$）转化为可测量（如 $\partial p/\partial T$） |
| 所有偏导数都是正的 | $G$ 关系式中存在负号：$(\partial S/\partial p)_T = -(\partial V/\partial T)_p$，负号容易遗漏 |

### 入门级例题
**题目**：利用麦克斯韦关系式，推导理想气体的 $(\partial U/\partial V)_T$。
**解答**：由 $dU = TdS - pdV$，在恒温下 $(\partial U/\partial V)_T = T(\partial S/\partial V)_T - p$。利用第三麦克斯韦关系 $(\partial S/\partial V)_T = (\partial p/\partial T)_V = nR/V$，得 $(\partial U/\partial V)_T = T \cdot nR/V - p = p - p = 0$。

### 与现实世界的联系
1. 材料科学中利用麦克斯韦关系式从膨胀系数和压缩系数计算热力学性质，指导新材料设计。
2. 地球科学中通过岩石的状态方程数据，用麦克斯韦关系式推算地幔深部的热力学状态。
