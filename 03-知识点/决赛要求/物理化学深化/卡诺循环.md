# 卡诺循环

## 核心概念

- **卡诺循环**：由四个可逆过程组成的理想热机循环
- **卡诺定理**：所有工作于同温热源和同温冷源之间的热机，以可逆热机效率最高
- **第二类永动机**：效率100%的热机，不可能存在

## 关键公式/方程式

### 四个可逆过程
1. 恒温可逆膨胀（$T_h$）：$w_1 = -nRT_h \ln(V_2/V_1)$
2. 绝热可逆膨胀：$q = 0$，温度从 $T_h \to T_c$
3. 恒温可逆压缩（$T_c$）：$w_3 = -nRT_c \ln(V_3/V_4)$
4. 绝热可逆压缩：$q = 0$，温度从 $T_c \to T_h$

### 热机效率
$$\eta = \frac{w}{Q_h} = 1 - \frac{T_c}{T_h} < 1$$

### 制冷系数
$$\beta = \frac{Q_c}{w} \leq \frac{T_c}{T_h - T_c}$$

### 关键推导
$$\frac{V_2}{V_1} = \frac{V_3}{V_4}$$

## 规律与趋势

- 效率仅取决于两热源温度比，与工作物质无关
- 温差越大，热机效率越高
- 实际热机效率必然低于卡诺效率
- 温度必须使用开尔文温标

## 典型应用

- 计算热机效率的理论上限
- 判断实际热机的效率是否合理
- 制冷设备的最小电功计算
- 竞赛中结合熵变计算进行热力学分析

## 🎯 教学视角

### 学习路径建议
先掌握 [[可逆过程与最大功]] 和 [[绝热可逆过程]]，理解恒温可逆和绝热可逆两个基本过程。卡诺循环是这两个过程的组合，建议同时学习 [[熵]] 的概念以理解效率公式的深层含义。

### 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 热机效率可以接近 100% | 卡诺效率 $\eta = 1 - T_c/T_h$ 是理论上限，实际热机效率必然低于此值，永远不可能等于 1 |
| 效率公式中温度可以用摄氏度 | 公式中 $T_c$ 和 $T_h$ 必须使用开尔文温标，摄氏度会导致计算错误 |
| 制冷系数越大说明越耗电 | 制冷系数 $\beta = Q_c/w$，越大说明每单位电功转移的热量越多，制冷效率越高 |

### 入门级例题
**题目**：一台卡诺热机工作在 600 K 和 300 K 之间，求其效率。若从高温热源吸收 1000 J 热量，能做多少功？
**解答**：$\eta = 1 - 300/600 = 0.5$（50%），做功 $w = \eta Q_h = 0.5 \times 1000 = 500\,\text{J}$。

### 与现实世界的联系
1. 火力发电厂的热效率受卡诺效率限制，提高蒸汽温度或降低冷凝温度是提升效率的基本方向。
2. 空调和冰箱的制冷系数决定了能耗等级，理解卡诺循环有助于选购高能效家电。
