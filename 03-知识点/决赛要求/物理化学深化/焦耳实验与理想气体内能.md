# 焦耳实验与理想气体内能

## 核心概念

- **焦耳实验**：理想气体向真空自由膨胀，观测温度变化
- **实验结论**：$\Delta T = 0$，说明理想气体内能仅是温度的函数
- **理想气体定义**：分子间相互作用力为零 + 分子体积忽略不计

## 关键公式/方程式

### 理想气体内能特性
$$\left(\frac{\partial U}{\partial V}\right)_T = 0, \quad \left(\frac{\partial U}{\partial P}\right)_T = 0$$

### 理想气体焓特性
$$\left(\frac{\partial H}{\partial V}\right)_T = 0, \quad \left(\frac{\partial H}{\partial P}\right)_T = 0$$

### 关键结论
$$U = U(T), \quad H = H(T)$$

### 内能微观组成
$$U = \underbrace{U_{\text{kinetic}}(T)}_{\text{动能项}} + \underbrace{U_{\text{potential}}(V)}_{\text{势能项}}$$

- 理想气体势能项为零（无分子间作用力），故 $U$ 仅由动能决定

## 规律与趋势

- 自由膨胀过程：$Q = 0, W = 0, \Delta U = 0, \Delta H = 0$
- 真空膨胀是绝热不可逆的自发过程
- 实际气体 $\left(\frac{\partial U}{\partial V}\right)_T \neq 0$（van der Waals气体存在分子间引力）

## 典型应用

- 判断理想气体各过程的 $\Delta U$ 和 $\Delta H$
- 竞赛中区分理想气体与实际气体的行为差异
- 理解焦汤系数 $\mu_{JT}$ 的物理基础
