# 晶体场分裂与磁性

![[crystal-field-splitting.jpg]]

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：[[决赛要求-结构与配位深化]]
- 对应考纲条目：[[决赛03-配合物深化]]
- 关联笔记：[[配合物稳定性]], [[Jahn-Teller效应]]

## 一、定义

在配合物中，中心金属离子的d轨道由于配体静电场的作用发生能级分裂（晶体场分裂）。d电子在分裂后的轨道中的排布方式决定了配合物的磁性和光谱性质。

## 二、核心原理

### 2.1 d轨道在八面体场中的分裂

八面体场中，5个简并d轨道分裂为两组：

- **$e_g$ 轨道**（高能）：$d_{z^2}$、$d_{x^2-y^2}$，直接指向配体
- **$t_{2g}$ 轨道**（低能）：$d_{xy}$、$d_{xz}$、$d_{yz}$，位于配体之间

**分裂能**：$\Delta_o = E(e_g) - E(t_{2g})$

### 2.2 电子排布：高自旋 vs 低自旋

对于 $d^4$–$d^7$ 组态（尤其是第一过渡系）：

| 条件 | 电子排布 | 自旋状态 | 典型例子 |
|------|---------|---------|---------|
| $\Delta_o > P$（强场）| $t_{2g}^n e_g^m$ 优先配对 | 低自旋 | $[\text{Fe(CN)}_6]^{3-}$（$d^5$，$t_{2g}^5$）|
| $\Delta_o < P$（弱场）| 优先单电子占据 | 高自旋 | $[\text{FeF}_6]^{3-}$（$d^5$，$t_{2g}^3 e_g^2$）|

其中 $P$ 为电子成对能。

### 2.3 磁性判断

- **顺磁性**：有未成对电子，磁矩 $\mu = \sqrt{n(n+2)}\,\mu_B$（$n$ 为未成对电子数）
- **反磁性**：所有电子成对，$\mu = 0$

**竞赛常考点**：通过磁性实验判断配合物是高自旋还是低自旋，进而推断配体场强弱。

### 2.4 其他配位场的分裂

| 配位场 | 分裂方式 | 分裂能大小 |
|--------|---------|-----------|
| 四面体 | $e$（低）+ $t_2$（高）| $\Delta_t \approx \frac{4}{9}\Delta_o$ |
| 平面四方 | 四组能级 | 通常最大 |
| 八面体 | $t_{2g}$（低）+ $e_g$（高）| 基准 |

### 2.5 LFSE 与热力学性质

配位场稳定化能（LFSE）是 d 电子进入分裂后轨道获得的总稳定化能（单位：−Δo）：

| dⁿ | 弱场（高自旋） | 强场（低自旋） |
|:---:|:---:|:---:|
| d¹ | −0.40 | −0.40 |
| d² | −0.80 | −0.80 |
| d³ | −1.20 | −1.20 |
| d⁴ | −0.60 | −1.60 |
| d⁵ | 0 | −2.00 |
| d⁶ | −0.40 | **−2.40（最大）** |
| d⁷ | −0.80 | −1.80 |
| d⁸ | −1.20 | −1.20 |
| d⁹ | −0.60 | −0.60 |
| d¹⁰ | 0 | 0 |

**水合焓双峰曲线**：若不考虑 LFSE，水合焓应随 d 电子数增加单调上升；实测 d⁰→d¹⁰ 呈**双峰**（峰值在 d³ 与 d⁸），恰与弱场 LFSE 的双峰变化一致 → 直接证明配位场效应对热力学性质的贡献。2 价金属卤化物晶格能同理呈双峰。

### 2.6 磁性定量公式

- **自旋磁矩**：$\mu_s = \sqrt{n(n+2)}\,\mu_B$（n = 未成对电子数）
- **Curie 定律**：$\chi_M = C/T$（C 为 Curie 常数）
- **Curie-Weiss 定律**：$\chi_M = C/(T-\theta)$（θ 为 Weiss 常数，反映磁交换作用）

**常见磁矩数据（中级无机化学 表3.5）**：Mn²⁺ 5.92、Fe³⁺ 5.92、Cr³⁺ 3.87、Ni²⁺ 2.83、Cu²⁺ 1.73（单位 μ_B）。

## 五、常见分类或情形

| 分裂类型 | 几何构型 | 轨道分裂 | 磁性特征 |
|:---|:---|:---|:---|
| 八面体 | Oh | t₂g(低) + eg(高) | d⁴-d⁷可有高/低自旋 |
| 四面体 | Td | e(低) + t₂(高) | 几乎总是高自旋（Δt小） |
| 平面四方 | D4h | 四组能级 | 通常最大分裂 |
| 线性 | D∞h | 特殊分裂 | 少见 |

## 六、适用条件与限制

- 晶体场理论假设纯静电作用，忽略了共价键贡献（配体场理论更完整）
- 高/低自旋判断仅对d⁴-d⁷构型有意义，d¹-d³和d⁸-d¹⁰只有一种排布
- 四面体场分裂能太小（Δt≈4/9Δo），通常不出现低自旋态
- 磁矩公式μ=√(n(n+2))是近似值，实际值受轨道角动量贡献影响

## 七、常见比较与易混点

| 对比维度 | 正确理解 | 常见误区 |
|:---|:---|:---|
| 高自旋 vs 低自旋 | 高自旋=弱场(Δ<P)，低自旋=强场(Δ>P) | 记反了场强与自旋态的对应 |
| 八面体 vs 四面体 | 四面体分裂能仅为八面体的4/9 | 认为四面体也能出现低自旋 |
| 磁矩计算 | μ=√(n(n+2))仅考虑自旋贡献 | 忽略轨道角动量的贡献 |
| Jahn-Teller效应 | eg轨道不对称占据才显著 | 认为t₂g不对称也会畸变 |

## 八、与其他知识点的联系

- 配体类型与电子给受性质 → π给体/π受体对Δ的影响

## 九、典型题型

1. **高自旋/低自旋判断**：给定金属离子和配体，判断配合物是高自旋还是低自旋
2. **未成对电子数计算**：根据d电子构型和晶体场分裂情况计算未成对电子数
3. **磁矩计算与磁性判断**：用公式 $\mu = \sqrt{n(n+2)}\,\mu_B$ 计算磁矩，判断顺磁/反磁性
4. **晶体场分裂能比较**：根据光谱化学序列比较不同配体的场强
5. **Jahn-Teller效应判断**：判断哪些d电子构型会发生Jahn-Teller畸变

## 十、例题

### 例题1

**题目**：判断 $[\mathrm{Fe(H_2O)_6}]^{3+}$ 和 $[\mathrm{Fe(CN)_6}]^{3-}$ 分别是高自旋还是低自旋配合物，并计算它们的磁矩。

**解题思路**：
- Fe³⁺的d电子构型为 $d^5$
- $\mathrm{H_2O}$ 是弱场配体，$\Delta_o < P$（成对能），电子优先单电子占据
- $\mathrm{CN^-}$ 是强场配体，$\Delta_o > P$，电子优先配对

**答案**：

$[\mathrm{Fe(H_2O)_6}]^{3+}$：
- 弱场，高自旋
- 电子排布：$t_{2g}^3 e_g^2$，5个未成对电子
- 磁矩：$\mu = \sqrt{5(5+2)} = \sqrt{35} \approx 5.92\,\mu_B$

$[\mathrm{Fe(CN)_6}]^{3-}$：
- 强场，低自旋
- 电子排布：$t_{2g}^5$，1个未成对电子
- 磁矩：$\mu = \sqrt{1(1+2)} = \sqrt{3} \approx 1.73\,\mu_B$

### 例题2

**题目**：解释为什么 $[\mathrm{CoF_6}]^{3-}$ 是高自旋配合物而 $[\mathrm{Co(NH_3)_6}]^{3+}$ 是低自旋配合物。

**解题思路**：
- Co³⁺的d电子构型为 $d^6$
- 根据光谱化学序列：$\mathrm{F^-} < H_2O < NH_3 < CN^-$
- $\mathrm{F^-}$ 是弱场配体，$\mathrm{NH_3}$ 是较强场配体

**答案**：

$[\mathrm{CoF_6}]^{3-}$：
- $\mathrm{F^-}$ 是弱场配体，$\Delta_o$ 较小
- $\Delta_o < P$，电子优先单电子占据
- 高自旋：$t_{2g}^4 e_g^2$，4个未成对电子

$[\mathrm{Co(NH_3)_6}]^{3+}$：
- $\mathrm{NH_3}$ 是较强场配体，$\Delta_o$ 较大
- $\Delta_o > P$，电子优先配对
- 低自旋：$t_{2g}^6$，0个未成对电子（反磁性）

## 十一、易错点

1. **高自旋/低自旋判断条件混淆**：高自旋对应弱场（$\Delta_o < P$），低自旋对应强场（$\Delta_o > P$），不要记反
2. **未成对电子数计算错误**：特别是 $d^4$-$d^7$ 构型，要根据场强决定电子排布，而不是简单地按照Hund规则填充
3. **四面体场的特殊情况**：四面体场的分裂能 $\Delta_t \approx \frac{4}{9}\Delta_o$，通常较小，几乎都是高自旋

### 12.2 认知误区

**误区1："晶体场理论是完全正确的"**
- 纠正：晶体场理论假设纯静电作用，忽略了共价键贡献；配体场理论（MO）更完整

**误区2："所有d⁴-d⁷配合物都有高/低自旋两种可能"**
- 纠正：四面体场分裂能太小，几乎总是高自旋

**误区3："顺磁性一定意味着有未成对电子"**
- 纠正：顺磁性的主要来源是未成对电子的自旋磁矩，但轨道磁矩也有贡献

### 12.3 入门例题

**入门题**：判断[CoF₆]³⁻和[Co(NH₃)₆]³⁺分别是高自旋还是低自旋。

**解答**：Co³⁺为d⁶。F⁻是弱场配体（Δ小），[CoF₆]³⁻为高自旋t₂g⁴eg²，4个未成对电子。NH₃是较强场配体（Δ大），[Co(NH₃)₆]³⁺为低自旋t₂g⁶，0个未成对电子（反磁性）。

### 12.4 真实世界联系

- **颜料化学**：Cu²⁺配合物的蓝色来自d-d跃迁（d⁹构型，Jahn-Teller畸变）
- **血红蛋白**：Fe²⁺在卟啉配体场中为低自旋态，与O₂结合后变为高自旋态
- **磁性材料**：配合物的磁性可用于分子磁体和信息存储材料设计

## 十三、竞赛拓展

- **光谱化学序列的定量参数化**：Jorgensen引入f和g参数，将Δ表达为f·g，可半定量预测未知配合物的Δ
- **Nephelauxetic效应**：配体与金属的共价作用使电子云膨胀，降低电子间排斥参数β，反映配体的共价贡献
- **高自旋-低自旋交叉（Spin Crossover）**：某些d⁴-d⁷配合物在温度/压力/光照下可发生自旋态转变，应用于分子开关和传感器
- **轨道角动量贡献**：在某些配合物（如[Ti(H₂O)₆]³⁺）中，轨道角动量未完全猝灭，对磁矩有显著贡献
