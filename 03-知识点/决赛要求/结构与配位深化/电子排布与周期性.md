## 一、定义

**电子排布与周期性**研究多电子原子中电子在轨道上的填充规律（Aufbau原理、Pauli原理、Hund规则），以及由此产生的元素性质周期性变化。决赛阶段要求不仅掌握"怎么排"，更要理解"为什么这么排"——即钻穿效应、屏蔽效应、交换能等因素如何共同决定能级顺序和电子构型。

## 三、核心原理

### 3.1 决定电子排布的三个原理

**Pauli不相容原理**：同一原子中不能有两个电子具有完全相同的四个量子数。一个轨道最多容纳2个自旋相反的电子。

**Aufbau原理（构造原理）**：按能量从低到高的顺序填充轨道。实际顺序由[[钻穿效应]]和[[屏蔽效应]]共同决定：

$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f approx 5d < 6p$$

**Hund规则**：
1. 电子优先以平行自旋占据不同的简并轨道（最大S）
2. 在S相同的情况下，L最大的态能量最低
3. 半满前J最小的态最低；半满后J最大的态最低

### 3.2 反常排布的物理解释

| 元素 | 反常排布 | 原因 |
|-----|---------|------|
| Cr | $[Ar]3d^54s^1$ 而非 $3d^44s^2$ | 半满d层（$d^5$）有额外交换能稳定化 |
| Cu | $[Ar]3d^{10}4s^1$ 而非 $3d^94s^2$ | 全满d层（$d^{10}$）有额外稳定化 |
| Mo | $[Kr]4d^55s^1$ | 同Cr，半满d层稳定 |
| Pd | $[Kr]4d^{10}$ | 全满d层极稳定，甚至不填5s |

**交换能**（Hund规则第一条的能量根源）：平行自旋电子间的交换作用使能量降低。平行自旋对数越多，交换能越低。

### 3.3 周期性的电子结构根源

| 周期性 | 电子结构根源 |
|-------|------------|
| 周期数 = 最外层主量子数 | 每填满一层开始新周期 |
| 主族元素 | s/p区，价电子在最外层 |
| 过渡元素 | d区，(n-1)d电子逐步填充 |
| 镧系/锕系 | f区，(n-2)f电子逐步填充 |
| 原子半径递减 | 同周期$Z_{eff}$增加 |
| 电离能增大 | 同周期$Z_{eff}$增加 |
| 电负性增大 | 同周期$Z_{eff}$增加 |

## 四、关键结论

1. **电子排布不是死记**，而是理解钻穿→能级→填充→稳定化的逻辑链
2. **半满和全满有额外稳定化**：交换能 + 对称性
3. **离子排布≠原子排布**：失去电子时总是先失最外层（n最大），即使先填时4s先于3d
4. **镧系收缩**：4f电子屏蔽极差，导致后续过渡元素半径异常小

## 五、典型竞赛题型

### 题型1：书写基态电子排布

**例**：写出Ag（Z=47）的基态电子排布。

**答**：$[Kr]4d^{10}5s^1$。类似Cu，全满d层有额外稳定化。

### 题型2：解释反常排布

**例**：为什么Cr是$3d^54s^1$而不是$3d^44s^2$？

**答**：$d^5$为半满构型，有6对平行自旋（$C_5^2=10$对？不对，重新算：5个电子各占一个d轨道，平行自旋，交换对数为$C_5^2=10$）。而$d^4$只有$C_4^2=6$对交换。额外的交换能使$3d^54s^1$更稳定。此外，半满构型的电子云分布更对称，也贡献稳定性。

## 七、常见比较与易混点

| 对比维度 | 正确理解 | 常见误区 |
|:---|:---|:---|
| 填充顺序 vs 电离顺序 | 填充时先4s后3d，电离时先失4s | 认为先填的电子一定后失 |
| 全满 vs 半满稳定 | Cr是d⁵半满（而非d⁴），Cu是d¹⁰全满（而非d⁹） | 记混Cr和Cu的反常排布 |
| Mg > Al 电离能反常 | Mg的3s²全满稳定，Al的3p¹易失 | 与N > O的半满稳定混淆 |
| 离子排布书写 | 离子排布按n整理，Fe²⁺写作[Ar]3d⁶ | 把4s写在3d前面（填充顺序） |

## 九、典型题型

1. **书写基态电子排布式**：给定元素（包括特殊排布的Cr、Cu、Mo、Pd等），写出完整的基态电子排布式
2. **由电子排布推断元素**：根据给定的电子排布特征（如3d排布、未成对电子数等）推断元素种类及其在周期表中的位置
3. **解释反常电子排布**：解释Cr、Cu、Mo、Ag、Pd等元素为什么不遵循常规构造原理，涉及半满/全满稳定化与交换能
4. **利用逐级电离能推断元素**：根据连续电离能数据的跃变位置判断价电子数和元素种类
5. **电离能反常的电子构型解释**：解释同周期中电离能的"反常"（如Mg>Al、P>S、N>O等）

## 十、例题

### 例题1：由电子排布推断元素

**题目**：已知某离子 $M^{2+}$ 的3d轨道中有5个电子。(1) 写出M原子的电子排布；(2) 写出M的元素名称和符号；(3) 说明M在周期表中的位置。

**解题思路**：
- $M^{2+}$ 有 $3d^5$，形成 $M^{2+}$ 时先失去4s电子（无论先填后失规则），所以M原子应为 $3d^54s^2$ 或 $3d^64s^2$ 或 $3d^74s^2$
- 最可能是Mn（$[Ar]3d^54s^2$）→失去2个4s电子→$[Ar]3d^5$
- Mn位于第四周期、VIIB族（5+2=7）

**答案**：(1) $[Ar]3d^54s^2$；(2) 锰Mn；(3) 第四周期VIIB族。

### 例题2：解释反常排布与逐级电离能

**题目**：(a) 写出Cr和Cu基态原子的电子排布，解释其反常原因。(b) 已知某元素A的逐级电离能（kJ/mol）：$I_1 = 738$，$I_2 = 1451$，$I_3 = 7733$，$I_4 = 10540$。推断A是什么元素。

**解题思路**：
- (a) Cr：$[Ar]3d^54s^1$（而非 $3d^44s^2$），因 $d^5$ 半满有额外交换能稳定化（$C_5^2 = 10$ 对平行自旋交换）；Cu：$[Ar]3d^{10}4s^1$（而非 $3d^94s^2$），因 $d^{10}$ 全满有额外稳定化
- (b) $I_3 \gg I_2$（7733 vs 1451），说明该元素有2个价电子，为IIA族。$I_1 = 738$ 接近Mg（738 kJ/mol），故A = Mg

**答案**：(a) Cr为 $3d^54s^1$（半满稳定），Cu为 $3d^{10}4s^1$（全满稳定）；(b) A为Mg。

## 十一、易错点

1. **电子排布书写错误**：过渡金属离子化时总是先失最外层（n最大的）电子，即使填充时4s先于3d——例如Fe为 $3d^64s^2$，但Fe²⁺为 $3d^6$（先失4s）
2. **反常排布记忆混乱**：Cr是 $3d^54s^1$（半满）而非 $3d^44s^2$，Cu是 $3d^{10}4s^1$（全满）而非 $3d^94s^2$，Pd是最极端的例外——$4d^{10}5s^0$（完全不填5s）
3. **电离能反常原因混淆**：Mg > Al是因为Mg的 $3s^2$ 全满稳定，而N > O是因为N的 $2p^3$ 半满稳定——两者稳定化的物理根源不同（全满 vs 半满），不能混为一谈

### 12.2 认知误区

**误区1："电子排布就是背规则"**
- 纠正：理解钻穿→能级→填充→稳定化的逻辑链比死记硬背更有效

**误区2："离子化总是先失最后填入的电子"**
- 纠正：电离时失去的是离子中能量最高的电子，不一定与填充顺序一致

**误区3："半满和全满的稳定性是绝对的"**
- 纠正：半满/全满稳定化需要与其他因素（如配体场、相对论效应）竞争

### 12.3 入门例题

**入门题**：写出Fe²⁺的电子排布，并解释为什么不是[Ar]3d⁴4s²。

**解答**：Fe原子为[Ar]3d⁶4s²。电离时先失去4s电子（4s能量在离子中高于3d），所以Fe²⁺为[Ar]3d⁶。

### 12.4 真实世界联系

- **过渡金属颜色**：d电子排布决定d-d跃迁能量，从而决定配合物颜色
- **磁性材料**：未成对电子数决定材料的磁性（如Fe₃O₄的铁磁性）
- **催化活性**：d电子构型影响金属中心的氧化还原电位和催化活性

## 十三、竞赛拓展

- **相对论性效应与6s惰性电子对**：重元素中6s电子因相对论性收缩而能量降低，导致Pb²⁺比Pb⁴⁺稳定、Tl⁺比Tl³⁺稳定
- **Cotton原子轨道能级图**：展示不同元素的原子轨道能量随原子序数变化的详细关系，是理解电子排布的可视化工具
- **Hund规则的能量根源——交换能**：平行自旋电子间的量子力学交换相互作用使能量降低，交换对数越多（如d⁵有C₅²=10对），稳定化越大
- **镧系收缩的电子结构根源**：4f电子钻穿能力极弱（径向节点数=0），屏蔽不完全，导致有效核电荷持续增加
