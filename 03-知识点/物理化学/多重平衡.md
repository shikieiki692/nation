# 多重平衡

## 核心概念

多重平衡是指在同一体系中同时存在多个化学平衡的过程，各平衡之间通过共享物种相互关联。多重平衡规则（Hess定律在平衡常数中的应用）允许通过已知平衡常数组合计算未知平衡常数。

## 二、核心原理

### 2.1 多重平衡规则

多重平衡规则是Hess定律在化学平衡中的直接应用，其核心依据是状态函数的广度性质：

| 操作 | 方程式变化 | K值变化 | 理论依据 |
|:---|:---|:---|:---|
| 方程式相加 | 反应①+反应② | $K = K_1 \cdot K_2$ | $\Delta G^{\theta}$是广度量状态函数，可按热化学定律组合；$\Delta G^{\theta} = -2.30RT \cdot \lg K$ |
| 方程式相减 | 反应①-反应② | $K = K_1 / K_2$ | 同上 |
| 方程式乘系数n | 反应×n | $K = K^n$ | $\Delta G^{\theta}$与化学计量数成正比 |

**理论依据**：由于$\Delta G^{\theta}$是状态函数且为广度量，可按热化学定律组合。由$\Delta G^{\theta} = -2.30RT \cdot \lg K$可知，平衡常数K与$\Delta G^{\theta}$的对数关系使得方程式的加减对应K的乘除。

### 2.2 典型多重平衡体系

**例1：SO₂/SO₃/NO/NO₂/O₂体系**

已知：
- 反应①：$2SO_2(g) + O_2(g) \rightleftharpoons 2SO_3(g)$，平衡常数$K_{p1}$
- 反应②：$2NO(g) + O_2(g) \rightleftharpoons 2NO_2(g)$，平衡常数$K_{p2}$
- 反应③：$SO_2(g) + NO_2(g) \rightleftharpoons SO_3(g) + NO(g)$，平衡常数$K_{p3}$

由于反应③ = (反应① - 反应②)/2，故：$K_{p3} = \sqrt{K_{p1}/K_{p2}}$

**例2：CoO还原平衡（普化原理例6.4）**

已知：
- 反应①：$CoO(s) + H_2(g) \rightleftharpoons Co(s) + H_2O(g)$，$K_{p1}$
- 反应②：$H_2(g) + CO_2(g) \rightleftharpoons H_2O(g) + CO(g)$，$K_{p2}$
- 目标反应：$CoO(s) + CO(g) \rightleftharpoons Co(s) + CO_2(g)$，$K_{p3}$

由于目标反应 = 反应① - 反应②，故：$K_{p3} = K_{p1} / K_{p2}$

若$K_{p2} = 67$，$K_{p1} = 0.14$，则$K_{p3} = 0.14 / 67 = 4.8 \times 10^{-3}$（注意：此处根据平衡常数表达式推导，实际计算需谨慎）

### 2.3 竞赛常见多重平衡耦合

| 耦合类型 | 典型反应 | K计算公式 | 说明 |
|:---|:---|:---|:---|
| 沉淀溶解+酸碱 | $Mg(OH)_2 + 2H^+ \rightleftharpoons Mg^{2+} + 2H_2O$ | $K = K_{sp} / K_w^2 = 5.61 \times 10^{16}$ | $K_{sp}(Mg(OH)_2) = 5.61 \times 10^{-12}$ |
| 沉淀溶解+配位 | $AgCl$溶于$NH_3$：$AgCl + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+ + Cl^-$ | $K = K_{sp} \cdot K_{稳}$ | 配合物稳定常数与溶度积的组合 |
| 配位+氧化还原 | 氰化法提银：$Ag_2S + 4CN^- + \frac{1}{2}O_2 \rightarrow 2[Ag(CH)_2]^- + S$ | 多步平衡组合 | 涉及沉淀溶解、配合、氧化还原的复杂耦合 |
| 酸溶判断 | $MnS + 2H^+ \rightleftharpoons Mn^{2+} + H_2S$ | $K = K_{sp} / K_{a1}K_{a2} > 10^7$（自发） | $CuS$酸溶$K < 10^{-7}$（不溶） |

**关键判据**：酸溶反应的平衡常数$K = K_{sp} / (K_{a1} \cdot K_{a2})$，其中$K_{a1}$、$K_{a2}$为$H_2S$的分级电离常数。当$K > 10^7$时反应自发向右，$K < 10^{-7}$时反应几乎不发生。

### 2.4 解题策略

**核心原则**：多重平衡题先抓最大贡献，不先做"全展开"

1. **识别主平衡**：先看哪一个主平衡最强（K值最大）
2. **简化处理**：抓住主导平衡，忽略次要平衡的微小贡献
3. **逐步推导**：从已知平衡出发，通过多重平衡规则推导目标平衡

**特别提示**：萃取题本质上也是多重平衡题，涉及分配平衡、络合平衡等多种平衡的耦合。

## 三、与相关知识点的关系

### 3.1 与化学平衡基础的关系

多重平衡是化学平衡的延伸和深化，建立在以下基础之上：
- **平衡常数表达式**：$K = \prod [产物]^{\nu_i} / \prod [反应物]^{\nu_i}$
- **Le Chatelier原理**：多重平衡体系中，改变某一条件会影响所有相关平衡
- **反应商Q与K的关系**：判断多重平衡体系的移动方向

### 3.2 与热力学函数的关系

多重平衡规则的热力学本质：
- $\Delta G^{\theta} = \sum \nu_i \Delta G_f^{\theta}(产物) - \sum \nu_i \Delta G_f^{\theta}(反应物)$
- $\Delta G^{\theta} = -RT \ln K$，故$\ln K = -\Delta G^{\theta} / RT$
- 状态函数的加和性决定了K的乘除关系

### 3.3 与电化学的关系

多重平衡在电化学中的应用：
- **电极电势的组合**：$E^{\theta}_{cell} = E^{\theta}_{cathode} - E^{\theta}_{anode}$
- **Nernst方程**：$E = E^{\theta} - \frac{RT}{nF} \ln Q$，其中Q为反应商
- **标准电极电势与平衡常数**：$\ln K = nFE^{\theta} / RT$

### 3.4 与酸碱平衡、沉淀平衡、氧化还原平衡的关系

多重平衡是连接各类平衡的桥梁：
- **酸碱平衡**：弱酸的$K_a$可通过多重平衡计算（如醋酸与氢氧根反应）
- **沉淀溶解平衡**：$K_{sp}$的测定和应用常涉及多重平衡
- **氧化还原平衡**：电极电势的比较和电池电动势的计算基于多重平衡
- **配合物平衡**：稳定常数$K_{稳}$的测定常通过多重平衡设计实验

### 3.5 在竞赛中的地位

多重平衡是化学竞赛的核心工具之一：
- **计算复杂平衡常数**：通过多重平衡组合难以直接测定的平衡常数
- **设计实验方案**：利用多重平衡原理设计实验测定未知常数
- **分析复杂体系**：环境化学、生物化学中的多平衡耦合体系分析
- **解题技巧**：竞赛中多重平衡题常作为综合题出现，考查多知识点融合能力

## 三、🎯 教学视角

### 3.1 学习路径建议
建议先掌握单一化学平衡的基本概念和平衡常数表达式，再学习多重平衡规则（Hess定律在平衡常数中的应用）。理解"方程式相加则K相乘、方程式相减则K相除"的规则是核心，需要通过大量练习培养识别共享物种和组合平衡的能力。

### 3.2 学生易踩的认知误区
| 误区 | 正确理解 |
|:---|:---|
| 多重平衡就是多个反应同时进行 | 多重平衡的关键是各平衡通过共享物种相互关联，可以组合计算未知K |
| 平衡常数可以直接相加 | 方程式相加时K相乘，方程式乘以系数n时K变为Kⁿ，不能直接相加 |
| 多重平衡只在理论上有用 | 多重平衡广泛用于计算难直接测定的平衡常数，如弱酸的Ka、难溶盐的Ksp |

### 3.3 入门级例题
**题目**：已知以下平衡常数：(1) CH₃COOH ⇌ CH₃COO⁻ + H⁺, Ka=1.8×10⁻⁵；(2) H₂O ⇌ H⁺ + OH⁻, Kw=1.0×10⁻¹⁴。求反应 CH₃COOH + OH⁻ ⇌ CH₃COO⁻ + H₂O 的平衡常数K。
**解答**：目标反应 = 反应(1) - 反应(2)，因此K = Ka/Kw = (1.8×10⁻⁵)/(1.0×10⁻¹⁴) = 1.8×10⁹。这是醋酸与氢氧根反应的平衡常数，数值很大说明反应几乎完全进行。

### 3.4 与现实世界的联系
- **缓冲溶液设计**：利用多重平衡规则可同时计算弱酸Ka和缓冲溶液pH
- **沉淀溶解平衡**：通过组合溶度积和络合平衡常数，计算沉淀在络合剂中的溶解度
- **环境化学**：多重平衡用于分析水体中金属离子在不同配体和pH条件下的形态分布
