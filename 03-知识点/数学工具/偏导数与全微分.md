# 偏导数与全微分

## 一句话

多元函数里**固定其他变量、只看一个变量怎么变**；全微分把所有变量的贡献线性叠加起来。它是 Maxwell 关系与误差传递的共同基础。

## 核心公式

**记号**：$\left(\dfrac{\partial G}{\partial p}\right)_T$ 读「定温下 $G$ 对 $p$ 的偏导」，下标是被固定的量。

**全微分**：$df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy$

**混合偏导相等**（Clairaut 定理）：$\dfrac{\partial^2 f}{\partial x\partial y} = \dfrac{\partial^2 f}{\partial y\partial x}$

**链式法则**（换中间变量）：$\left(\dfrac{\partial U}{\partial T}\right)_p = \left(\dfrac{\partial U}{\partial T}\right)_V + \left(\dfrac{\partial U}{\partial V}\right)_T\left(\dfrac{\partial V}{\partial T}\right)_p$

**恰当微分判据**：$Mdx+Ndy$ 恰当 ⇔ $\dfrac{\partial M}{\partial y}=\dfrac{\partial N}{\partial x}$ ⇔ 它对应一个状态函数。

## 误差传递（最常用）

$R=R(A,B,\ldots)$ 时：

```
ΔR ≈ |∂R/∂A|·ΔA + |∂R/∂B|·ΔB + …              （最坏情形）
σ_R = sqrt( (∂R/∂A)²σ_A² + (∂R/∂B)²σ_B² + … )  （方和根）
```

特例：

- $R=A+B$：$\Delta R = \Delta A+\Delta B$（绝对误差相加）
- $R=AB$ 或 $A/B$：$\dfrac{\Delta R}{R}=\dfrac{\Delta A}{A}+\dfrac{\Delta B}{B}$（**相对**误差相加）
- $R=A^n$：$\dfrac{\Delta R}{R}=n\dfrac{\Delta A}{A}$
- 因为 $d\ln x = dx/x$，**对数的微分就是相对误差**

例：$M=\rho RT/p$，相对误差 $=\dfrac{\Delta\rho}{\rho}+\dfrac{\Delta T}{T}+\dfrac{\Delta p}{p}$；若 $\rho$ 贡献 0.4%、$T$ 与 $p$ 合计不到 0.2%，则**该改进的是密度测量**，换更准的温度计是浪费。

## 化学落点

| 场景 | 式子 |
|:--|:--|
| 热膨胀系数 | $\alpha = \dfrac1V\left(\dfrac{\partial V}{\partial T}\right)_p$ |
| 压缩系数 | $\kappa = -\dfrac1V\left(\dfrac{\partial V}{\partial p}\right)_T$ |
| 内压 | $\pi_T = \left(\dfrac{\partial U}{\partial V}\right)_T$ |
| 焦耳-汤姆逊系数 | $\mu_{JT} = -\dfrac1{C_p}\left(\dfrac{\partial H}{\partial p}\right)_T$ |
| 化学势 | $\mu = \left(\dfrac{\partial G}{\partial n}\right)_{T,p}$ |

## 易错点

1. **下标漏写或写错**——$(\partial p/\partial T)_p$ 无意义；下标对不上说明中间变量选错了。
2. $\Delta$（有限变化）与 $d$（无限小）混用；非状态函数用 $\delta$（$\delta Q$、$\delta W$）因为它们的积分与路径有关。
3. 误差传递中**乘除加相对误差、加减加绝对误差**，别反了。
4. 判断「是不是状态函数」要用混合偏导相等，不能凭直觉。
