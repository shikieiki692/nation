# 对数与指数运算

## 一句话

$\ln$ 是化学里出现频率最高的函数——**把乘除变加减、把指数变系数**。它为什么无处不在，答案就在 $\ln(e^{ax})=ax$。

## 核心公式

```
ln(xy) = ln x + ln y      ln(x/y) = ln x − ln y      ln(x^n) = n ln x
ln N = 2.303 lg N         lg N = ln N / 2.303        e^{ln x} = 10^{lg x} = x
```

换底因子来自 $\ln 10 = 2.3026\ldots \approx 2.303$。

**必背值**（其余都能拼出来）：

| 值 | 数值 | 顺带推出 |
|:--|:--|:--|
| $\lg 2$ | `0.3010` | $\lg 4=0.602$、$\lg 8=0.903$、$\lg 5=0.699$ |
| $\lg 3$ | `0.4771` | $\lg 6=0.778$、$\lg 9=0.954$ |
| $\lg 7$ | `0.8451` | $\lg 3.5=\lg7-\lg2=0.544$ |
| $\ln 2$ | `0.6931` | $\ln 4=1.386$、$\ln 8=2.079$ |
| $\ln 10$ | `2.3026` | |

**常用近似**（$\lvert x\rvert \ll 1$）：

```
ln(1+x) ≈ x − x²/2        e^x ≈ 1 + x        (1+x)^n ≈ 1 + nx
```

一阶近似 $\ln(1+x)\approx x$ 的**误差约为 $x/2$**：$x=0.1$ 时约 5%，$x=0.01$ 时约 0.5%。

## 心算流程

$\lg(m\times10^n) = n + \lg m$。例：$\lg(6.0\times10^{-4}) = -4+0.778 = -3.222$（**不是** `-4.778`）。

## 化学落点

| 式子 | 出处 |
|:--|:--|
| $\ln[\mathrm{A}] = \ln[\mathrm{A}]_0 - kt$ | 一级反应积分式 |
| $\Delta G^\circ = -RT\ln K = -2.303RT\lg K$ | 平衡 |
| $E = E^\circ - \dfrac{RT}{nF}\ln Q = E^\circ - \dfrac{0.0592}{n}\lg Q$ | Nernst（298 K） |
| $\mathrm{pH} = -\lg[\mathrm{H}^+]$ | 酸碱（**注意是 $\lg$ 不是 $\ln$**） |
| $\ln\dfrac{p_2}{p_1} = -\dfrac{\Delta H_{\text{vap}}}{R}\left(\dfrac1{T_2}-\dfrac1{T_1}\right)$ | Clausius-Clapeyron |

## 易错点

1. **$\mathrm{pH}$ 用 $\lg$，热力学公式用 $\ln$**——差 2.303 倍，混用必错。
2. $\Delta G^\circ=-RT\ln K$ 与 $-2.303RT\lg K$ 是**同一个式子**，2.303 只能乘一次。
3. $\ln(1+x)\approx x$ 只在 $\lvert x\rvert\ll1$ 成立；转化率超过约 5% 就必须用精确式 $-\ln(1-\alpha)$。
4. 对数里不能放带单位的量（严格写法见 [[量纲分析与数量级估算]]）。
