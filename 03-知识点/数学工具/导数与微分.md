# 导数与微分

## 一句话

导数是**瞬时变化率**（区间缩到极限），微分 $dy$ 是「用切线代替曲线」的线性近似——$dy = f'(x)\,dx$。

## 核心公式

```
(cu)' = c u'                (u+v)' = u' + v'
(uv)' = u'v + uv'           (u/v)' = (u'v − uv')/v²
链式：[f(g(x))]' = f'(g(x))·g'(x)
```

常用导数表：$x^n\to nx^{n-1}$、$e^x\to e^x$、$a^x\to a^x\ln a$、$\ln x\to 1/x$、$\log_ax\to 1/(x\ln a)$、$\sin x\to\cos x$、$\cos x\to-\sin x$。

**微分与线性近似**：

$dy = f'(x)\,dx\qquad f(x+\Delta x)\approx f(x)+f'(x)\Delta x$

**极值判据**：$f'(x_0)=0$；$f''(x_0)>0$ 为极小，$f''(x_0)<0$ 为极大。

## 怎么用

- **由曲线读速率**：$c$–$t$ 图上某点的切线斜率即 $-\dfrac{d[\mathrm{A}]}{dt}$。
- **稳态近似**：令中间体浓度的时间导数为零，$d[\mathrm{I}]/dt = 0$。
- **误差估算**：$d\ln x = dx/x$——**对数的微分就是相对误差**（见 [[偏导数与全微分]]）。
- **极值问题**：连串反应中间体浓度最大时刻、$y$ 关于某变量的最优值。

## 化学落点

| 场景 | 写法 |
|:--|:--|
| 反应速率定义 | $v = -\dfrac{1}{\nu_A}\dfrac{d[\mathrm{A}]}{dt}$（$\nu_A$ 为计量系数，取正） |
| 一级反应瞬时速率 | $-\dfrac{d[\mathrm{A}]}{dt} = k[\mathrm{A}]$ |
| 由 $\ln K$ 求 $\Delta H^\circ$ | $\dfrac{d\ln K}{dT} = \dfrac{\Delta H^\circ}{RT^2}$（van't Hoff） |
| 由 $\ln k$ 求 $E_a$ | $\dfrac{d\ln k}{dT} = \dfrac{E_a}{RT^2}$（Arrhenius 微分式） |
| Arrhenius 作图 | $\ln k$ 对 $1/T$ 作图，斜率 $= -E_a/R$ |

## 易错点

1. **用长时间平均速率代替瞬时速率**会严重失真：一级反应在 $t=0$ 附近用 0→20 min 的平均速率估算，相对误差可达 37%。
2. 统一速率 $v$ 要除以计量系数：$2\mathrm{A}+\mathrm{B}\to3\mathrm{C}$ 中 $v = -\frac12\dfrac{d[\mathrm{A}]}{dt} = -\dfrac{d[\mathrm{B}]}{dt} = \frac13\dfrac{d[\mathrm{C}]}{dt}$。
3. Arrhenius 图横轴是 $1/T$ 不是 $T$；误取 $T$ 得到的是曲线，其斜率为 $\dfrac{E_a}{RT^2}$ 而非 $-E_a/R$。
4. $d$ 与 $\Delta$ 别混：$d$ 是无限小，$\Delta$ 是有限变化量；非状态函数（$Q$、$W$）用 $\delta$。
