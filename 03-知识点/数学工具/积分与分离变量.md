# 积分与分离变量

## 一句话

积分是导数的逆运算；**分离变量**是把「变化率方程」改写成「浓度–时间关系」的通用手法——零/一/二级速率方程全部由它推出。

## 8 条够用积分表

| 被积函数 | 原函数 |
|:--|:--|
| $x^n\ (n\neq-1)$ | $\dfrac{x^{n+1}}{n+1}$ |
| $\dfrac1x$ | $\ln\lvert x\rvert$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x/\ln a$ |
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\dfrac1{x+a}$ | $\ln\lvert x+a\rvert$ |
| $\dfrac1{(x+a)^2}$ | $-\dfrac1{x+a}$ |

定积分 $\displaystyle\int_a^b f(x)dx = F(b)-F(a)$；平均值 $\langle f\rangle = \dfrac1{b-a}\displaystyle\int_a^b f(x)dx$。

## 分离变量三步

以一级反应 $-\dfrac{d[\mathrm{A}]}{dt}=k[\mathrm{A}]$ 为例：

1. **分**：$\dfrac{d[\mathrm{A}]}{[\mathrm{A}]} = -k\,dt$
2. **积**（两侧各配自己的上下限）：$\displaystyle\int_{[\mathrm{A}]_0}^{[\mathrm{A}]}\dfrac{d[\mathrm{A}]'}{[\mathrm{A}]'} = -k\int_0^t dt'$
3. **整**：$\ln\dfrac{[\mathrm{A}]}{[\mathrm{A}]_0} = -kt$

## 三个结果（应能现推，不是背）

| 级数 | 速率方程 | 积分式 | 直线关系 | 半衰期 |
|:--|:--|:--|:--|:--|
| 0 | $v=k$ | $[\mathrm{A}]=[\mathrm{A}]_0-kt$ | $[\mathrm{A}]$–$t$ | $[\mathrm{A}]_0/(2k)$ |
| 1 | $v=k[\mathrm{A}]$ | $\ln[\mathrm{A}]=\ln[\mathrm{A}]_0-kt$ | $\ln[\mathrm{A}]$–$t$ | $0.693/k$ |
| 2 | $v=k[\mathrm{A}]^2$ | $\dfrac1{[\mathrm{A}]}=\dfrac1{[\mathrm{A}]_0}+kt$ | $1/[\mathrm{A}]$–$t$ | $1/(k[\mathrm{A}]_0)$ |

## 化学落点

- 体积功：$w=-\displaystyle\int p\,dV$，等温可逆理想气体得 $w=-nRT\ln(V_2/V_1)$。
- Gibbs-Helmholtz 积分式：$\dfrac{\Delta G_2}{T_2}-\dfrac{\Delta G_1}{T_1} = \Delta H\left(\dfrac1{T_2}-\dfrac1{T_1}\right)$。
- Arrhenius 两点式：$\ln\dfrac{k_2}{k_1}=\dfrac{E_a}{R}\left(\dfrac1{T_1}-\dfrac1{T_2}\right)$。
- 平行反应的产物比：$\dfrac{[\mathrm{B}]}{[\mathrm{C}]}=\dfrac{k_1}{k_2}$（同一个积分 $\int[\mathrm{A}]dt$ 相消）。

## 易错点

1. **二级反应的 $1/[\mathrm{A}]$–$t$ 图斜率是 $+k$**（不是 $-k$）——负号已在 $\int x^{-2}dx=-x^{-1}$ 中抵消。
2. 积分忘常数 $C$（不定积分）；定积分上下限要与变量配对（左限 $[\mathrm{A}]_0$ 对应 $t=0$）。
3. $k$ 的定义看清楚是对 $-\dfrac{d[\mathrm{A}]}{dt}$ 还是对统一速率 $v$——对 $2\mathrm{A}\to\mathrm{P}$ 两者差 2 倍。
4. 零级模型在 $[\mathrm{A}]$ 耗尽后失效（会给出负浓度），物理上无意义。
