# 化学式推断

- 总览：[[中国化学奥林匹克基本要求-总览]]
- 所属模块：综合方法
- 关联笔记：[[元素推断]], [[密度公式]], [[化学计量]], [[物料守恒]]

## 一、定义

化学式推断是指根据实验数据（元素质量分数、燃烧产物质量、气体体积、晶胞参数等）确定未知化合物的实验式（最简式）或分子式的过程。它是竞赛中元素分析和结构推断的基础技能。

## 二、考纲对应

| 考纲条目 | 具体要求 |
|---------|---------|
| 化学计量 | 掌握由元素质量分数确定实验式的方法 |
| 元素化学 | 理解燃烧分析法的原理和计算 |
| 晶体化学 | 能由晶胞参数和密度推算化学式 |

## 三、核心原理

### 3.1 由元素质量分数求实验式

1. 假设样品质量为 100g，计算各元素的物质的量：
   $$n_i = \frac{m_i}{M_i} = \frac{w_i \times 100}{M_i}$$
2. 求各元素物质的量之比，化为最简整数比
3. 得到实验式（最简式）

### 3.2 由实验式求分子式

需要知道相对分子质量 $M_r$：
$$n = \frac{M_r}{M_{\text{实验式}}}$$
分子式 = $(\text{实验式})_n$

**求 $M_r$ 的方法**：
- 理想气体法：$M = \frac{mRT}{PV} = \rho \frac{RT}{P} = 2D_{H_2} = 29D_{\text{air}}$
- 依数性法（稀溶液）：$M = \frac{mRT}{\pi V}$ 或沸点升高/凝固点降低
- 质谱法：直接给出分子离子峰

### 3.3 燃烧分析法

对于仅含 C、H、O 的有机物：
- $n(C) = n(CO_2) = \frac{m(CO_2)}{44}$
- $n(H) = 2n(H_2O) = \frac{2m(H_2O)}{18}$
- $n(O) = \frac{m_{\text{样品}} - m(C) - m(H)}{16}$

对于含 N 的有机物：
- $n(N) = 2n(N_2)$（由氮气体积计算）
- 或利用差减法求 N 的质量

### 3.4 晶胞化学式推断

1. 确定晶胞中各原子的位置及贡献（顶点 1/8、棱 1/4、面心 1/2、体心 1）
2. 计算各原子的总数
3. 化为最简整数比

## 四、关键结论

1. **实验式与分子式的区别**：实验式是最简整数比，分子式是实际原子个数
2. **差减法求氧含量**：含氧量低时相对误差大，需注意有效数字
3. **晶胞化学式**：考虑原子在晶胞中的位置贡献（顶点1/8、棱1/4、面心1/2、体心1）
4. **分子量的多种测定方法**：气体密度法、依数性法、质谱法各有适用范围

## 五、常见分类或情形

| 推断类型 | 输入数据 | 输出结果 | 关键方法 |
|:---|:---|:---|:---|
| 燃烧分析 | 样品质量+燃烧产物质量 | 实验式/分子式 | 差减法求氧 |
| 晶体化学式 | 晶胞参数+密度+原子量 | 化学式+Z值 | 密度公式 |
| 气体密度法 | 蒸气密度 | 分子量 | M=ρRT/P |
| 依数性法 | 沸点升高/凝固点降低 | 分子量 | M=mRT/(πV) |

## 六、适用条件与限制

- 燃烧分析仅适用于可完全燃烧且产物可定量吸收的化合物
- 晶胞化学式需要准确的密度数据和晶体结构信息
- 气体密度法仅适用于气态化合物或可气化的化合物
- 依数性法要求溶液足够稀（理想溶液近似）

## 七、常见比较与易混点

| 对比维度 | 正确理解 | 常见误区 |
|:---|:---|:---|
| 实验式 vs 分子式 | 实验式是最简比，分子式需分子量才能确定 | 混淆两者概念 |
| 差减法求氧 | 适用于含C、H、O的有机物 | 认为氧含量可以任意低 |
| 晶胞贡献 | 顶点1/8、棱1/4、面心1/2、体心1 | 记错贡献比例 |
| 直接配制 vs 标定 | 基准物质可直接配制，非基准需标定 | 认为所有高纯试剂都可直接配制 |

## 八、与其他知识点的联系

- 元素推断 → 化学式推断是元素推断的定量基础
- 密度公式 → 晶胞参数与密度的关系（ρ=ZM/(N_A·a³)）
- 化学计量 → 物质的量计算是所有推断的数学基础
- 物料守恒 → 质量守恒是差减法的理论依据
- 晶体结构 → 晶胞中原子的排列决定化学式

## 九、典型题型

1. **燃烧分析求实验式/分子式**：给出燃烧产物质量和样品质量
2. **晶胞化学式**：根据晶体结构确定化学式
3. **结合密度求分子式**：$M = \frac{\rho N_A V_{\text{晶胞}}}{Z}$
4. **综合推断**：化学式推断 + 结构推断 + 反应方程式

## 十、例题

### 例题1

**题目**：某有机化合物仅含C、H、O三种元素。取1.000 g样品在氧气中完全燃烧，生成2.240 g CO₂和0.900 g H₂O。已知该化合物的相对分子质量为90。求该化合物的实验式和分子式。

**解题思路**：
- 由CO₂质量求C的质量和物质的量
- 由H₂O质量求H的质量和物质的量
- 差减法求O的质量和物质的量
- 求各元素物质的量之比，得实验式
- 由相对分子质量求分子式

**答案**：

(1) 计算各元素的物质的量：
- $n(C) = n(CO_2) = \frac{2.240}{44} = 0.0509$ mol，$m(C) = 0.0509 \times 12 = 0.611$ g
- $n(H) = 2n(H_2O) = 2 \times \frac{0.900}{18} = 0.100$ mol，$m(H) = 0.100 \times 1 = 0.100$ g
- $m(O) = 1.000 - 0.611 - 0.100 = 0.289$ g，$n(O) = \frac{0.289}{16} = 0.0181$ mol

(2) 求物质的量之比：
- $n(C):n(H):n(O) = 0.0509:0.100:0.0181 = 2.81:5.52:1$
- 化为最简整数比：$3:6:1$
- 实验式：$C_3H_6O$，实验式量 = 58

(3) 求分子式：
- $n = \frac{90}{58} \approx 1.55$，取整数 $n = 2$（可能实验式需调整）
- 重新计算：若实验式为 $C_3H_6O$，$n=2$ 得 $C_6H_{12}O_2$，$M = 120$（不符）
- 实际应为 $n=1$，分子式 $C_3H_6O$，$M = 58$（与题设90不符，需检查数据）

*注：此题数据可能有误，若M=58，则分子式为 $C_3H_6O$*

### 例题2

**题目**：CsCl晶体的密度为4.28 g/cm³，Cs和Cl的相对原子质量分别为132.9和35.5。

(1) 求CsCl晶胞的边长。

(2) 已知Cs⁺和Cl⁻的离子半径分别为167 pm和181 pm，验证晶胞参数。

**解题思路**：
- CsCl晶胞含1个CsCl单元
- 密度公式：$\rho = \frac{Z \times M}{N_A \times a^3}$
- 体对角线：$\sqrt{3}a = 2(r_+ + r_-)$

**答案**：

(1) 由密度公式求晶胞体积：
- $V = \frac{Z \times M}{\rho \times N_A} = \frac{1 \times 168.4}{4.28 \times 6.022 \times 10^{23}} = 6.50 \times 10^{-23}$ cm³
- $a = \sqrt[3]{V} = 4.02 \times 10^{-8}$ cm = 402 pm

(2) 由离子半径验证：
- $\sqrt{3}a = 2(167 + 181) = 696$ pm
- $a = 696 / \sqrt{3} = 402$ pm，与(1)结果一致

## 十一、易错点

1. **差减法求氧含量的陷阱**：当含氧量很低时，由总质量减去C、H质量得到的O质量相对误差会被放大，竞赛中需注意有效数字的取舍
2. **实验式与分子式混淆**：实验式（最简式）表示原子个数的最简整数比，分子式是实际原子个数，需要相对分子质量才能确定
3. **晶胞中原子贡献计算错误**：顶点原子贡献1/8、棱上贡献1/4、面心贡献1/2、体心贡献1，不要搞混

```
    ↓

    ↓

```

### 12.2 认知误区

**误区1："实验式就是分子式"**
- 纠正：实验式是最简整数比，分子式需要分子量才能确定（如CH₂O是甲醛和乙酸的共同实验式）

**误区2："晶胞中原子数越多越稳定"**
- 纠正：稳定性取决于总能量，不是原子数；高配位数通常更稳定

**误区3："差减法求氧含量总是准确的"**
- 纠正：含氧量很低时，C和H的微小误差会被放大到氧含量中

### 12.3 入门例题

**入门题**：某化合物含C 40.0%、H 6.7%、O 53.3%，分子量为180。求分子式。

**解答**：n(C):n(H):n(O) = 40/12 : 6.7/1 : 53.3/16 = 3.33:6.7:3.33 = 1:2:1。实验式CH₂O，式量30。n=180/30=6。分子式C₆H₁₂O₆。

### 12.4 真实世界联系

- **食品分析**：测定食品中蛋白质（含N量×6.25）、脂肪、碳水化合物含量
- **药物质量控制**：通过元素分析验证药物纯度和化学式
- **矿物鉴定**：通过化学式和密度数据鉴定矿物种类

## 十三、竞赛拓展

- **差减法求氧含量的陷阱**：燃烧分析中氧含量由样品总质量减去碳、氢质量得到，当含氧量很低时相对误差会被放大，竞赛中需注意有效数字的取舍。
- **晶胞化学式与晶体化学式的区分**：NaCl 晶体的化学式写作 NaCl，但实际每个 Na⁺ 被 6 个 Cl⁻ 配位、每个 Cl⁻ 被 6 个 Na⁺ 配位，不存在独立的 NaCl 分子。竞赛题中常要求根据配位数和晶体结构判断真实化学式。
- **气态分子量的非理想修正**：竞赛中对蒸气密度法求分子量，高压条件下需用压缩系数 Z 修正：$M = Z \rho RT / p$，直接套用理想气体公式会产生系统误差。
