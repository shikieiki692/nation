## 二、问题-修复时间线

### P1: Word管线图片误删（管线Bug）
**时间**：会话早期
**现象**：分子结构Word清稿9张图片全部丢失；配位化合物也受影响
**根因**：`_strip_non_image_wikilink_lines()` 原始代码只保留 `![[media/...]]` 前缀的图片
**错误代码**：
```python
# 旧代码（错误）
if "[[" in line and "![[media/" not in line and "![[Media/" not in line:
    continue
```
**实际使用**：题组文件引用 `![[mineru/...]]` 和 `![[06-外部资料导入/...]]` 等非media路径
**修复**：
```python
# 新代码（正确）
if "[[" in line and "! [[" not in line:
    continue
```
**影响范围**：所有使用非media路径图片的 Word 清稿文件
**验证**：生成后检查图片数量，分子结构9张✅ 配位化合物9张✅

### P2: 题目替换后答案未同步（流程缺陷）
**时间**：会话中期
**现象**：16道题替换后，23道题答案与题目完全不匹配
**根因**：替换题目时只更新了题面和来源索引，未同步更新答案区
**修复**：手动逐一更新16道题的答案
**教训**：建立了"题目替换四件套"规则（题面+答案+来源索引+变更日志）

### P3: 银镜方程式H不平衡（化学知识错误）
**时间**：会话早期
**现象**：Q15银镜反应方程式氢原子不守恒
**根因**：初始编写时未逐原子核验方程式
**修复**：使用标准配平：`HCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → HCOO⁻ + 2Ag↓ + 4NH₃ + 2H₂O`
**教训**：建立了"方程式逐原子核验"规则

## 三、经验教训

### 3.1 管线层面
- **图片路径不能硬编码**：管线函数必须支持所有合法的图片路径模式
- **验证步骤必不可少**：生成后必须检查图片数量、公式数量等指标

### 3.2 流程层面
- **替换即四件套**：题目替换必须同步更新题面、答案、来源索引、变更日志
- **方程式必须验证**：涉及多元素的方程式必须逐原子核验守恒
- **选题必须查重**：构建题组前必须对比讲义已有题目

### 3.3 知识层面
- **OCR不等于正确**：构型类OCR结果必须与d电子数交叉验证
- **CFSE归因陷阱**：不同氧化态比较→归因电荷效应，不说"CFSE大"
