## 三、本轮踩出并已固化的判据坑（⛔ 违者返工）

1. 🔴 **源 PDF 文字层 ≠ 已开采**。先前的「源池无答案」判定只在 `2026机构初赛模拟题/` 的 **MinerU md** 里搜——`06-外部资料导入/OCR/01-题目/` 下 **646 份 PDF 有 370 份自带文字层**，纯文本通道一直空着。工具：**venv 里的 `pymupdf`**（`…/binaries/python/envs/default`）。
2. 🔴 **指纹定位必须「汉字归一 + 位置回映射」**。指纹是**连续汉字串**，PDF 原文含空格/换行 ⇒ 直接 `txt.find(fp)` **必然 0 命中**；⛔ 禁 `j=0` 退化（会把一批卡全指到文首）。
3. 🔴 **题号区间端点须同认 `第N题` 与行首 `^\s{0,3}N\s*[-.．、]`**（答案稿常写 `4. 5. 6.`；只认前者会把 4~8 题并段）。
4. 🔴 **不可据卡文件名推题号**：`题-<机构>-<卷>-<号>-<题名>` 的「号」常是**卡序**（实测 `…有机综合-04-烷烃光卤代` 对应源「4.」却是「环辛烯」）。
5. **北斗学友卡结构不同**：答案在 `<details>` 内 **`### 答案`**、**无 `## 知识点映射`** ⇒ 分区须「题面止于答案起点」；图用 `![[hash.jpg]]` 走 `媒体仓库/`。
6. **`⛔`/`⚠️` 不等于缺陷**：全专区 3,482 条注记里 2,949 条是每卡都有的「自动拆卡标记」；另有「题源为「参考答案」稿」等信息注。只有**内容缺失/不可靠类（17 类关键词）**才算缺陷。
7. **两种自动过滤都不可靠**：①「孤立单字母数」误伤化学式（`F 的电负性`、`I6 = …`）；②「分」计数漏掉**讲评型**答案。⇒ 拿不准**全写 + 醒目免责**：
   `> 📄 **答案（源 PDF 文字层自动提取，未逐字校对；如有出入以源为准）**` + `> 源：<pdf>`
8. **A5/A7 自动附图曾试并放弃**：我的题号区间与先前台账不一致（`BJLY-09-04` 台账 11 图 vs 我 20 图）⇒ 会附错图，按「宁可留白不塞错内容」**不写盘**。
9. 🔴 **`pdf_fp_scan.py` 存的是 `found[:3]`（只留前 3 命中源）**——**回搜结论必须用不截断版重跑**（`_probe3.py`），否则会把"第 4 个才是答案 PDF"的卡误判成"只中试题类"。
10. 🔴 **QX 补图只有渲染一条路**：`doc.extract_image(xref)` 取出的内嵌图**全部是空白**（真实内容走 SMask/渲染层）；MinerU 图片名 **≠** 内嵌图 sha256（raw/PNG 重编码均 0 命中）；缺失哈希在 `媒体仓库/`、源 `*_images/`、`.workbuddy/tmp/mineru_raw/` **全库 0 命中**（悬空引用）。
11. 🔴 **QX 定位须「长锚点唯一定页」**：取卡内 `⛔` 前 40 汉字，在逐页汉字串里从 36 字降到 10 字，**只在唯一命中页生效**——否则"完成下列反应"这类泛词会跨第 7/8 页误命中（旧短探针法实测就撞了这个坑）。锚点若为**结构词**（`## 参考答案 / 第 N 题（…分）`）则无唯一命中 ⇒ 判定不可自动，不写盘。
12. ⚠️ **卡片 `title`/`# 标题` 里的 artifact 会误命中缺陷判据**：`题-BJLY-09-有机综合-07-…配图缺失Mine.md` 的标题含 **"配图缺失Mine"** ⇒ 即使图已补齐，`DEFECT_PAT` 仍命中。清理题面缺陷时**要连标题一起清**（该卡待与 A7 一并处理）。
13. **缺陷注记有"变体措辞"**：审计 `DEFECT_PAT` 还拦下 `源答案 OCR 公式损毁`（5 张）、`在源 OCR 中损毁`（3 张）、`答案疑不完整`（3 张）、`图未导出`（1 张）等**未列入 `triage.py` KEY 的变体**——`triage.py` 的 13 个 KEY 会漏它们，核对时以 `newsim_audit.py` 的 `DEFECT_PAT` 为准。
14. 🔴 **判"答案可用"必须双维：形式 ＋ 内容**。只查**形式**（`$$` 配对 / 行内 `$` / `<table>` / `\ce`）会误判——`HYS-04-06 / HYS-40-05 / HYS-40-06 / HYS-40-07` 形式全过，但答案区**结尾戛然而止**（停在 `，解得`／`两种…引`／`5.14 (dd,`）＝**内容截断**。⇒ **第一动作：读答案区结尾**，句末没收尾就是截断。我曾据此一度误判"注记过期"，已在报告 §五 更正。
15. 🔴 **"手写 vs 印刷"判据：彩墨占比（`b2_ink2.py`）**。判据 `色差 = max(RGB)−min(RGB) ≥ 45 且 max ≥ 70`。**两个坑**：① 用 `sat=(mx−mn)/mx` ⇒ **近黑像素爆表**（RGB(5,4,9)→sat=142），把灰度水印全判成"彩"；② 用**缩略图**量 ⇒ **重采样把细笔画冲淡**。⇒ 必须**全分辨率抽样**。分界实测干净：印刷 0.00–0.32% ／ 手写 0.38–8.46%。
16. 🔴 **彩色 ≠ 手写**：质心UChO「芳香性」答案末图是**排版机理图**（蓝原子标＋红弯箭头）⇒ 需**目检确认**，不可只看彩墨数值。反向亦须核：26 张保留卡逐张复看"最高彩墨图"，确认确为手写，防误伤。
17. 🔴 **矢量题面图无内嵌图**：`GChO-76-09` 题面三路径反应式**矢量绘制**（`get_image_info` 为空），页面上表现为**大段空白**（第12页 y143–392）⇒ 直接渲染该空白区即可，别以为"没有图"就放弃。
