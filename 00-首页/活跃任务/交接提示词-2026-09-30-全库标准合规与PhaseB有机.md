## 四、必须知道的判据坑（Phase A 新发现，5 条）

1. 🔴 **反斜杠翻倍会静默丢图**：反复给图加宽度会把 `\|320` 写成 `\\|320`，**docx 管线认不出文件名 → 静默丢图**（本轮电化学基础 14→6、分光光度法 5→0），而 Gate1/2/4 **全绿**。⇒ 图版式脚本的正则必须 `\.rstrip("\\")`，且**终检＝「docx media 数 == md 图数」**（脚本 `.workbuddy/tmp/e12_media.py`）。
2. 🔴 **「表头被图片占据」**：`| ![[img]] |` ＋（分隔行）＋ `| 图注 |` ⇒ 图片渲染在表头行。判据＝表块首行含 `![[` 且非分隔行；修法＝插标签行（`.workbuddy/tmp/e12_label_fix.py`）。
3. 🔴 **图注有两种样式**：正文 `> 图 N-M：…` 与 **习题区** `| 图 N-M 标签 |`（无 `>`、无 `：`）。审计正则须同时认；**重编号前必须查正文引用**（`图 P-\d+` 出现次数 − 图注数 > 0 ⇒ 有正文引用 ⇒ 禁机械重编号）。
4. 🔴 **审计读文件须 `utf-8-sig`**（BOM 会让 `\A---` 的 FM 正则失配，把 frontmatter 的 `- "[[…]]"` 误算成「并段」）；**独立图行判据限正文区**；**图片计数要含非哈希命名**（旧图如 `TS_d2_diagram.png`）。
5. ⚠️ **提交先单次直试**：`export GIT_INDEX_FILE=… && git read-tree HEAD && git add -- <路径> && git commit`；失败后 `git reset -q HEAD -- <路径>`。⛔ 永不 `git add -A`（工作区长期有 2 万+ 并行会话改动）。
