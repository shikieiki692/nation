## 三、必须知道的判据坑（沿用 + 本轮新增）

### 沿用（Phase A 已固化）

1. 🔴 **反斜杠翻倍会静默丢图**：`![[hash\|320]]` 再加宽一次 ⇒ `![[hash\\|320]]`，**docx 管线认不出文件名、图直接消失**，而 Gate1/2/4 **全绿**。⇒ 正则须 `\.rstrip("\\")`，终检＝「docx media 数 == md 图数」。
2. 🔴 **「表头被图片占据」**：`| ![[img]] |` ＋分隔行＋`| 图注 |` ⇒ 图片渲染在表头行；修法＝插标签行。
3. 🔴 **图注有两种样式**：正文 `> 图 N-M：…` 与例题/习题区 `| 图 N-M 标签 |`（无 `>`、无 `：`，**合法**，勿当缺陷）。**重编号前必须查正文引用**（`图 P-\d+` 出现数 − 图注数 > 0 ⇒ 禁机械重编号）。
4. 🔴 **审计脚本读文件须 `utf-8-sig`**（BOM 会让 `\A---` 的 FM 正则失配，把 frontmatter 的 `- "[[…]]"` 误算成「并段」）。**独立图行判据限正文区**；**图片计数含非哈希命名**。
5. ⚠️ **提交先单次直试**：`export GIT_INDEX_FILE=… && git read-tree HEAD && git add -- <路径> && git commit`；失败后 `git reset -q HEAD -- <路径>`。⛔ 永不 `git add -A`（工作区长期有 2 万+ 并行会话改动）。

### 本轮新增

6. 🔴 **「无图注」不能判「图注跳号」**：`caps` 为空时（无图讲义）须直接放过，否则 4 份无图讲义被误报。
7. 🔴 **「学生版图数 < 母版」属预期**（答案区/例题解析区的图被删，如电化学基础 14→13 删的是「7.2.2 画出阴离子结构」的标准答案图）。⇒ 只报「学生版 > 母版」这类异常；差值需**人工确认删的是答案图而非题面图**。
8. 🔴 **例题区 ≠ 习题区**：`## §N 课后习题` 之前仍有「典型例题／综合例题」节（如电化学基础 §8.5/§8.6/§9.5/§9.6/§10），其中的题面图注用 `| 图 N-M 标签 |` 管道式，**不是正文插图**，勿当「图注在表外」。
9. ⚠️ **H4 判据**：`#### N.M.K 标题`（有层级编号）可接受；`#### 1. 微分形式`（序号式）与 `#### 定义`／`#### 汞`（无编号）属**非规范**——后者是「用标题实现列表/分隔」的旧习惯。
