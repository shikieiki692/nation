## 二、精度标准（硬性）

1. 必读三样：**题面全文 ＋ 题面全部图（逐张、碎片须拼合）＋ 答案区**。
2. 每题判 **2–5 个**考点，**宁少勿滥**（挂错比漏挂更伤下游检索）。
3. 标签必须是 `03-知识点/**` 的**规范页名**（禁自造；禁 `deprecated` 两式）。
4. 必须**交叉验证**：该页正文确实覆盖此考点（否则改挂语义宿主页 / 登记缺口）。
5. **题面级标注只能作「预标」**，不得作为交付。

## 三、七步流程（每题）

|  #  | 动作                                                      | 关键点                                                          |

|  2  | **逐张读题面图**                                              | 同时覆盖 `![](images/…)` 与 `<img src="images/…">` 两种语法；碎片按出现顺序拼合 |
|  3  | 读答案区，**交叉确认**化学落点                                       | 防被题面措辞误导（如把「给材料学习」读成基础知识题）                                   |
|  4  | 判 2–5 考点 → `kn.py`／双索引映射规范页名                            | 索引须 **文件名 + title + aliases**，且**文件名优先**                     |
|  5  | **交叉验证覆盖**                                              | 该考点在页内＝L2 宿主已覆盖／需补小节／真缺口                                     |

|  7  | 三闸门（`p5_verify_links` / FM strict / `r3_dep_check`）→ 提交 | ⛔ 只 add 本批路径                                                 |

## 四、质控（三道，新增）

1. **二次独立判定抽检**：每批随机 **2 题**，由「只看答案、不看已有标注」**再判一遍**；不一致 ⇒ 人工仲裁。→ 给出**批级一致率**。
2. **下游可用性反查**：判完按 KP 反查题库，确认新题**能被拉到**（题型页 Dataview / 外挂索引可用）。
3. **缺口登记**：题中考到、库内无规范页者 → 三层评估（L1 同名/别名 → L2 语义宿主 → L3 正文覆盖），**不硬塞**。
