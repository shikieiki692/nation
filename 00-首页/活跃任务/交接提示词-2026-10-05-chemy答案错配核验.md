## §五 核验方法（照此执行，勿简化）

对每张卡 4 步（**必须渲染原 PDF 页面肉眼核验，不许只做文本比对**）：

```bash
cd /c/Obsidion/妙妙屋
V="C:/Users/蕾赛/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
# ① 定位：在 PDF 里按关键词找页号（0 基）
$V -X utf8 .workbuddy/scripts/cmy_pdf_findpage.py "<pdf路径>" "关键词1" "关键词2"
# ② 渲染该页为 PNG（输出到 .workbuddy/tmp/cmy_pdf_pages/）
$V -X utf8 .workbuddy/scripts/cmy_pdf_render.py "<pdf路径>" "页号" 120
```

1. **读卡**：记下题面 H3 标题（题名+分值）、题面首句、答案区标题/首句。
2. **核题面**：在题面 PDF 定位并渲染 → 确认该页题号/题名/分值与卡内题面一致。
3. **核答案**：在答案 PDF（清单里的 `ans_pdfs`）定位并渲染 → 确认该页的题名/分值。
4. **判定**：一致 → `OK`；不一致 → `MISMATCH`（并在答案 PDF 里反搜题面独有词，尽量给出**正确答案页**）；
   搜不到/无关 → `UNKNOWN`（写明原因）。

结论 JSON 键=完整卡名去 `.md`，字段：`verdict` / `card_stem` / `card_ans_head` / `pdf_stem_page` /
`pdf_ans_page` / `pdf_ans_title_on_page` / `note`。**键数必须等于清单行数**。
