## 一、问题是什么

题库/习题文件里残留 OCR 原始的 HTML 图片写法：

```html
<table><tr><td><img src="images/4bb9c57b….jpg"/>A</td><td>…</td></tr></table>
```

**两个致命点**（缺一不可地导致图片看不见）：

1. `src="images/…"` —— `images/` 目录**不在该 md 旁边**（源 OCR 目录里它叫 `*_images/`），路径无法解析；
2. 该 `<img>` 位于 `<table>` 内 —— **HTML 块里的 markdown 不被解析**，所以只把 `<img>` 换成 `![[…]]` **仍然不渲染**，必须先把图片挪出 HTML 块。

## 三、方法（4 条硬约束 + 2 种手法）

### 硬约束（全部满足才算完成）

1. 每张图最终写作 **`![[<64位哈希>.jpg]]`** —— **纯哈希名，禁路径前缀、禁别名**（库规范，见 §七）。
2. 该引用**必须不在 HTML 块内**（`<table>` / `<div>` / `<td>` 里都不行）。
3. **文字、公式（`$…$` / `$$…$$`）、分值、题号、答案内容零改动**；唯一允许的新增是**极简图片标签**（沿用原单元格里已有的 `A` / `8-1-1` / `9-3-2` 等编号，不要自创新词）。
4. 每个 `<table>` 的**行列语义须保留** —— 并排关系不能打散成无序列表。

### 手法 1：图片移出成段（**真表格** 用）

适用于图片是**表格单元格内容**、且表格有真实的行列语义（如「序号 | 量子数 | 轨道符号 | 轨道角度分布图 | 电子云径向分布图」这种参数表）。

- **保留表格结构**；把原来放 `<img>` 的单元格改为**该图的极简标签**（或留 `见下图`）；
- 图片以 `![[hash.jpg]]` **独立成段**（每图一段），顺序**严格照原 `<tr>` 出现顺序**；
- 表格可用 HTML 或转 markdown，但列数与表头须与原来一致。

**先例（照此办理）**：2026-08-30「习题书V2 批 B」把 27 个 `<img>` 归一化为 `![[哈希名.jpg]]`，并"原表格单元格内图片**全部移出为独立带标签图片段落**" —— 见 `00-首页/活跃任务/习题书V2内容瘦身与排版迭代计划.md` 第 131 / 434 行。

### 手法 2：整表摊平为 markdown 行（**线性容器表** 用）

适用于 `<table>` 只是**排版容器**、内容是单列顺序罗列（答案逐条），无并排语义。

- 每个 `<tr>` → **一行**；行内单元格以空格连接；`<img src="…/X.jpg">` → `![[X.jpg]]`；
- 行与行之间空一行（避免图片挤在一段）；
- 剥掉 `<td>/<tr>/<table>` 等标签与 `colspan`。

**先例（照此办理）**：本会话产出的 `04-题库/教材习题/北斗学友/题-069-北斗-联三-08-关于自由基的基础有机化学.md` 与 `题-070-北斗-联三-09-可见光诱导的甲基化反应.md` —— **同一目录内的成品样例，直接对照**。

### 一句话判据

> **行内多列并排 = 真表格 → 手法 1；仅单列顺序罗列 = 容器 → 手法 2。**

### 表格外的 `<img>`（不入 `<table>` 的）

直接原位替换为 `![[hash.jpg]]` 即可。**样例**：`题-067` / `题-068`（同目录，写法即目标形态）。
