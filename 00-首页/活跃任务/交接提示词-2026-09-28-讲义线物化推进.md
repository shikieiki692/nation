  ```bash
  BASE=$(git rev-parse HEAD)
  export GIT_INDEX_FILE=.workbuddy/tmp/index_wl_001
  git read-tree "$BASE"
  git add -- <本会话文件...>          # 中文路径多时用 --pathspec-from-file
  NOW=$(git rev-parse HEAD)           # 并行会话可能已前移 HEAD
  [ "$BASE" != "$NOW" ] && { git read-tree "$NOW"; git add -- <本会话文件...>; }
  git commit -m "..."
  unset GIT_INDEX_FILE; rm -f .workbuddy/tmp/index_wl_001
  git reset -q                        # 刷新主索引
  git diff-tree --no-commit-id --name-only -r HEAD | wc -l   # 应 = 本会话文件数
  ```

## 七、判据坑（⛔ 违者返工，均为实测踩出）

1. 🔴 **`$$…$$` 与行内 `$…$` 正则配对会错位** ⇒ 先**暂存 `$$` 块**，再处理行内 `$…$`，最后还原。
2. 🔴 **`^`/`_` 花括号内压缩空格会误伤反斜杠命令**（`^{\Delta n}`→`^{\Deltan}` ⇒ Gate2 挂）⇒ 先把 `\命令␣` 换占位符，压缩后还原。
3. 🔴 **去掉 `{\mathrm{X}}` 外层花括号必须加 `[_^]` 前瞻**，否则 `\frac {\mathrm{平衡浓度}}{…}` 首参被削成 `\frac \mathrm{平衡浓度}`。
4. 🔴 **题干内嵌解答的切分锚点若落在 `$$` 块内会切断定界符** ⇒ 判据 `q.count("$$",0,cut) % 2 == 1` 则回退到最近 `$$`。
5. **array 处理须保守**：先删全部 `\begin{array}{…}`/`\end{array}`，再按 `\\` 拆 `$$` 块（原书有 array 套 array）；去尾部 `}` 只对 `& {` 开头的行。
6. **FM 字符串禁写反斜杠命令**（`\boxed` → `\b` 成退格符 `\x08` ⇒ pandoc 报 `control characters are not allowed` 并中止转换）。
7. **`$$` 块内留空行 ⇒ pandoc 判非数学**（`strip_boxed` 后会留空行）⇒ 每块 `re.sub(r"\n\s*\n+", "\n", inner)`。
8. **`$$` 块内行首 `- ` 会被 Gate4 判 bullet** ⇒ 改写为 `{} - `。
9. **行内数学 `$` 后不可紧跟空格**（写 `$a>0.5$`，非 `$ a>0.5 $`）。
10. **`> 对齐考纲` 必须在「## 学习目标…」节内**（其后、表格前）；放 H1 后节标题前会被 Gate1 判 Warning。
11. **清理引用框禁兜底正则** `^>\s*(?!…)`（会回溯误删 `> 对齐考纲`）⇒ 逐行 `re.sub(r"^[>\s]+","",L)` 并显式豁免 `图 `/`对齐考纲`。
12. **CRLF 必转 LF**（Gate 不查行尾，须自查；已验收 6 份物化全为 LF）。
13. **图注必须与实图核对**（曾出现图注称「水/CO₂ 相图」而实图为通用单组分相图）。
