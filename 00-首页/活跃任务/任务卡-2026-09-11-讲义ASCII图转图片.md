## 七、踩过的坑（批次13 新增）

7. **换图 / 转文本都必须"拆围栏"**（批次12 已踩，批次13 又踩一次）：
   - **换图**：`new = "```\n" + 图片行 + "\n```"` → 图片与说明落进代码块，pandoc 当纯文本，
     `--strict-images` 报 "expected 2, docx 1"。**正确做法：把整块（含上下围栏）替换为图片行**，
     并在脚本里 `assert "```" not in new` 硬拦。
   - **转文本**：只替换块内原文、未拆围栏 → 文本仍被 ``` 包裹，docx 侧 `SourceCode` 段未减少。
     **正确做法：`do_text` 定位 `rfind("```",0,i)` 与 `find("```",i+len)`，整段替换（含围栏）**。
   - 两处坑的共同根因：把"块内内容"当成替换单位，而真正的替换单位是"**围栏 + 内容 + 围栏**"。

## 八、踩过的坑（批次12）

1. **`imshow(extent=[x0,x1,y1,y0])` 会垂直镜像**——配合默认 `origin='upper'` 相当于整图翻转，
   立体化学图会**变成对映体**（`(S)` 被翻成 `(2)`、Br 跑到顶部看着像被裁切）。必须
   `extent=[x0,x1,y0,y1]`。
2. **图片行的缩进只能从围栏行取**，不能从块内 ASCII 首行取（会得到 4-5 空格 → Markdown 代码块）。
3. **`EOL.join(rows)` 是错的**：CRLF 文件下会写出**孤立 CR**（`\r` 而非 `\r\n`）。必须
   `sep = "\r\n"`；写后用"孤立 CR 计数 == 0"自检。
4. **同一文件的两次 `Edit` 不能放在同一条消息里**——后写会覆盖先写（本会话 padding 改动就这么丢过一次）。
5. **WinError 5（目标 docx 被 WPS 占用）**：WPS 允许写内容但禁止改名/删除 → `os.replace` 失败。
   项目既定做法是**就地 `open(dst,'wb')` 覆盖**（绕开删除步骤），覆盖后比对 sha256。
6. **残留 `_*.tmp.docx` 会污染产物统计**（`verbatim_report.py` 把它当成一份产物算进去了）→
   每批收尾 `find 06-学生侧材料/讲义 -name "_*.tmp.docx" -delete`。
