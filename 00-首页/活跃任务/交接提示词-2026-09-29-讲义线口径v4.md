## 五、硬纪律（git）

- **逐路径精确 `add`**，⛔ 永不 `git add -A`、⛔ 永不 `git add -- <目录>`。
- **隔离索引提交**：`export GIT_INDEX_FILE=.workbuddy/tmp/index_xxx` → `git read-tree $BASE` → `git add -- <files>` → `git commit`。
- 🔴 **提交后必须清主索引残留**：`unset GIT_INDEX_FILE; git reset -q HEAD -- <同批路径>`（否则 `git status` 报 `MM`/`D `，他人一提交就把你的改动撤了）。
- 🔴 **写清单文件时注意行尾**：Python `open(...,'w')` 在 Windows 会写 CRLF ⇒ `xargs`/`git add` 会把 `\r` 当路径一部分（报 `pathspec ...?`）。落盘后 `sed -i 's/\r$//'`。
- 红区：`04-题库/`、`05-真题库/`、`_归档/` 不动；并行会话的未跟踪文件不动。
- ⚠️ 工作区长期有**并行会话**（题库线）的大量脏文件，本线只 commit 自己的模块。

## 七、判据坑（⛔ 违者返工）

1. **docx 管线会把「连续非空行」并进同一个 Word 段落**：`**小标题**：` / `1. …；` / `2. …；` 之间**无空行** ⇒ Word 里挤成一整段。**并列项与小标题行须前后补空行**（全库已补 696 处）。凡「学生版看着并成一段」先查 md 空行。
2. **图谱索引的 filename/description 不可尽信**：索引标 `pourbaix_water` 的图实为 **Mn Frost 图**。**必须开图目检**（化学式下标 / 标注语言），不合格直接剔除。
3. **删整节会带走节内配图** ⇒ FM `image_count` 失配（Gate1 报 Error）。删节后必查 `![[` 计数并改 FM。
4. **写盘护栏用「有无变更」判据**，⛔ 不用 `len(new) > len(raw)`（只改 `updated` 日期这类等长改动会被误拒）。
5. **剥标题后缀必须加护栏**：若剥完节标题为空（如 `## §6 常见失分陷阱与认知冲突辨析`），说明该节是**整节**而非子节 ⇒ 回滚不剥，交人工裁决。
6. **行内 `§N` 交叉引用**：删节重编号时须按映射同步改写；指向被删节者只报告不改（人工处置）。
7. **题面不自洽/自编题**：交叉引用教材（「参考教材例题 6.7」）⇒ 把答案所用常数**回填题面**改自洽；`[经典例题·…]` 类自编题 ⇒ 删除（题量可低于 25，⛔ 不补自编）。
8. `**题源**：` 只允许**真题届次**；非真题来源标注（`[普化原理…]`／`（赵鑫光）`／`（来源：…）`）一律清除。
