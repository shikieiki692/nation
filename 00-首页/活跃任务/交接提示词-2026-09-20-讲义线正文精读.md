【五、纪律铁律（每条都踩过坑）】

▍边界
· 🔴 **红区禁碰**：`04-题库/`、`05-真题库/`、`_归档/`。题库**只可只读**回源核答案
· 🔴 **开工前扫目标文件 mtime 静默 >45 分钟**，确认未被并行会话占用
· 🔴 不动并行会话的未跟踪/未提交文件；`.workbuddy/memory/*` 一律不提交
· 🔴 改完即 commit；**只 add 本会话改动文件**，禁 add→commit 一条龙

▍写文件
· **含正则 / 反斜杠 / 非 ASCII / 反引号的脚本必须 Write 成 `.py` 再跑**
  （bash 内联反引号会被当命令替换吞掉；heredoc 非 ASCII 会 mojibake）
· **同一文件的多个 Edit 禁并行**（实测会各静默丢改动）→ 串行 + 改完 Read 复核
· 报「有问题」之前先怀疑自己的脚本；与闸门冲突**以闸门为准**
· **比字节要用 `len(x.encode())` 或 `wc -c`**，别拿 `len(str)`（字符数）当字节数
  （曾因此误报「文件缩水 3620 字节」，实为 +659）
· **禁 `os.removedirs()` / `git rm -r` / `Remove-Item -Recurse`**（本库曾误删 646 个文件）
· 删文件逐条 `os.remove` 并登记失败清单；删空目录只用 `os.rmdir`

▍提交与并发
· 统计一律 `git status --porcelain -uall`（不加 `-uall` 会把子目录折叠成一行）
· 中文路径 git 输出 → `-c core.quotepath=false`（**`-c` 必须在子命令前**）或用 `-z`
· **暂存区可能被并行会话污染**（本库实测：add 后 commit 前被塞进他人的钩子测试夹具）
  → 正解 = **临时索引**：
    `GIT_INDEX_FILE=<临时路径> git read-tree HEAD`
    `GIT_INDEX_FILE=<临时路径> git add -- <file>`
    `GIT_INDEX_FILE=<临时路径> git commit -F <msg>`
  → 提交后 re-add 真实索引消除 `MM`，并删掉临时索引文件（曾残留 17 MB）
· **`.git/index.lock` 活锁**（`fatal: Unable to create '…/.git/index.lock': File exists`）
  → **不要手删**：先查时效（可能已自动消失）+ 复核暂存内容未被夹带 → 再重试
· **禁 `--no-verify`**。pre-commit `render_gate` 拦下时**改内容**而不是跳钩子
  （它统计非代码段里的字面数学分隔符；正文里引用该记号要改写成文字描述）
· **本线默认不 push**：本地长期领先远端（交接时 HEAD 领先 **14 笔**，其中多笔属并行会话在途）。
  代推会把他人半成品一并公开 → **由用户拍板**。要推时：
  `git -c http.proxy=http://127.0.0.1:7897 -c credential.helper=manager push origin master`
  推完 `ls-remote == git rev-parse HEAD` 核验
