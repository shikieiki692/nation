## 一、定位

独立于专项卷／习题书／讲义的**单独一套**：只收模拟卷类题目，跨机构多源混编，全系列**非有机**。

| 项 | 口径 |
|:--|:--|
| 产物（md 源） | `04-题库/初赛模拟卷N（非有机·答案版｜学生版）.md` |
| 产物（Word） | `00-首页/题组Word/初赛模拟卷/`（**入库**，md 改后必须重出并一起提交） |
| 每卷 | 16 题，三段（元素与分析／结构化学／化学原理），满分约 144~156 |
| 难度 | ⭐⭐⭐⭐~⭐⭐⭐⭐⭐（`difficulty≥4`） |
| 硬约束 | **系列内零重复**；**排除有机**；**只排除国内初赛真题** |

## 二、真题口径（用户四度确认，勿自行扩大）

🔴 **唯一硬排除＝「国内初赛真题」**。曾一度按「初赛**层级**」一刀切（把预赛/省赛/选拔赛/夏令营/联考/自招也排了），被用户纠正：「**我说的是初赛真题，没让你排除其他的**」。

| 类别 | 处置 |
|---|:--:|
| 国内**初赛真题**（含「第N届…初赛」「20XX年初赛」「初赛试题」） | ❌ 排除 |
| 国际竞赛真题（IChO／国际化学竞赛） | ✅ 收录 |
| 决赛题（含国内决赛） | ✅ 收录 |
| 预赛／省赛／选拔赛／夏令营／赛区选拔 | ✅ 保留 |
| 联考／自招 | ✅ 保留 |
| **初赛模拟**（本系列主体） | ✅ 保留 |

**判据＝全文（去 HTML 注释）**，不是「标题＋摘要」——后者实测漏 31 张，标注藏身 FM `特别说明`／FM `tags`／题面中断／校勘注同题说明。
**模拟豁免只能限「模拟」与「初赛」紧邻**（豁免词含「演练」时，「第5讲实战演练4（2000年全国初赛试题）」会被当成模拟题放行）。

## 四、学生版形态（用户指示）

> 「不要出现题目来源和难度。只要有完整的题目就行了」

- 卷头＝**考试说明（题数/满分/用时）＋ 范围（三段题号与分值）**
- 逐题＝**`### 第 N 题（M 分）` ＋ 完整题面**
- 🔴 **不写题名**——题卡标题多为出处（「教程第一分册 第1讲【竞赛对接】例5」「（第17届IChO）」），本身就是「来源」
- 不写 `> 来源…｜难度 ⭐` 行、不写卷末选题清单；FM `source` 用中性表述
- 另剥：题面首句出处括注、答案区校勘注（**须整行匹配**，非贪婪括号正则遇嵌套括号会残留半句）
- **双版核验判据＝学生版 ⊆ 答案版**（逐句包含，**不是相等**）

## 六、已踩坑（8 条，详速查 §十七·补）

1. 跨源必带**题卡目录**参数（各源独立题号体系，`题-013` 在不同源是不同题）
2. 北斗学友卡内 `## 第N题` 源标题须剥（否则破坏卷内标题层级）
3. **小题前缀须卡内实测＋投票后回查**（日期串会投出假前缀；题-046 文件名序位 06 而卡内实为 `7-1…`）
4. 裸源序号（`9.`）与真小问（`1.`）要分开
5. `$$` **块内禁空行 且 块外须空行**，两件事**必须用状态机**（独立正则互相打架，守恒一度 0 FAIL→8 FAIL）
6. **plan 固化**（见上）；次生坑：修图引用会改题面长度 ⇒ 按长度排序的选题跟着漂移
7. 校验以 **pandoc 第三方口径**为基准（自写正则与 pandoc 总差 ±1）
8. **提交判据不能用 `git commit … | tail`**（管道退出码取 tail 的 0 ⇒ 失败被误报成功）；须 `>file 2>&1; rc=$?` ＋ 校验 HEAD 真的前移
