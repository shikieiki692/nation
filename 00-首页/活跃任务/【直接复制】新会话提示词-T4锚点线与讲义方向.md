### 5.1 提交

1. ⛔ **永不 `git add -A`／永不目录级 `git add`** ⇒ **逐路径精确 add**（中文/空格路径加引号，分批 ≤100）。
2. ⛔ **add 前记录暂存区基线**，add 后**核对「暂存区 == 本会话路径集合」**，多一个就 `git reset` 掉再中止。
3. 🔴 **本库正解＝主索引 ＋ 隔离索引脚本**：本线用 `.workbuddy/tmp/commit_multi.py`（多机构一次提交）与
   `commit_paths.py`（少量路径）；二者均用隔离索引并在提交后 `git reset -q HEAD -- <路径>` 复原主索引。
4. `git commit` 给 **600 s 超时**（pre-commit 钩子含 75 s render_gate ＋ 18 MB 索引 `read-tree`）。
5. 🔴 **报「暂存面不符(N vs 0)」＝ HEAD 已被并行会话推入本波内容** ⇒ **跳过本波提交、先核对 HEAD 是否已含**（`git cat-file -e HEAD:<路径>` 或 `git show HEAD:<路径>`）。
6. **推送**：`git -c credential.helper=manager push origin master`，推完 `git ls-remote` 核对。
