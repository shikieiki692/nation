# 规则：讲义质量检查清单

> **用途**：讲义定稿后、导出 Word/PDF 前的逐句审查标准操作。适用学生讲义、复习讲义、新课讲义。
> **来源**：结构化学第一轮复习四轮逐句审查实战沉淀（语言 → 逻辑 → 格式 → 收紧），2026-08-15。
> **配套阅读**：[[00-首页/讲义生产SOP与双向映射规范]]（生产流程）、[[00-首页/规则-配图来源优先级]]（配图）。

## 一、五类问题清单（逐句审查时逐类过一遍）

| 类 | 检查点 | 典型例子 |
|---|---|---|
| ① 术语与用词 | 同一概念全文统一不混用；口语化改规范；中英混排统一 | 「电子排斥大」→「电子间排斥能大」；vs→与；d-pπ 键→d–p π 键 |
| ② 数值与事实（**最高优先级**） | 换算系数、公式常数、Δχ、键长/晶胞参数对照源稿核验；公式前后自洽 | Mulliken 折算 Pauling：χ_P≈0.18(I+E)，系数作用于 (I+E) 而非 χ_M |
| ③ 逻辑链与衔接 | 因果链站得住；「故/因此」前因成立；对比/递进/转折连接词准确 | 结论句与上文对应；每段展开顺序符合教学逻辑 |
| ④ 格式规范 | 括号全/半角、数值与单位间空格、上下标、键型符号 | 250.4 pm（非 250.4pm）；拉弗斯相（非拉夫斯相） |
| ⑤ 冗余与啰嗦 | 能一句说清不用两句；删重复铺垫；合并重复知识卡 | 「收紧」意图下只做不增加篇幅的修正 |

## 二、三读审查法

1. **第一读（找错）**：通读抓术语、语病、明显事实错误。
2. **第二读（抠逻辑）**：逐句检查因果链、衔接、严谨性。
3. **第三读（格式+收紧）**：统一格式，按「不要啰嗦」做减法。

> 每轮只动一类问题，改完即停，避免混合改动难回归。用户说「太啰嗦」时切换为纯减法模式。

---

## 三、修改纪律

- 小修改用 `kb_edit`（先读后改、oldText 唯一锚点），禁止 Read 全文再 Write。
- 批量 >5 处需 `confirm: true`；一处失败整批回滚 → 缩锚点重试。
- 每轮改完：build 预检 → 重新生成 docx → 验证 images/math 数量与关键公式。
- **math 数量变化要核实**：oMath 增减可能来自公式替换（新增公式 +1）而非丢失。
- 存疑项不硬改：先登记「存疑未改清单」，再对源验证（教材提炼 / 知识库 KP / 权威来源），验证后集中修正。
- **判「不规范/存疑」前先搜库内 KP + 真题集**：CH₂SF₄ 曾因「不像教材例」被误换为 PF₃Cl₂，实为 32 届初赛真题 + VSEPR KP 的规范例——先查库内依据再动手，避免过度修正。
- **正确性优先级 > 措辞优先级**：存疑数据（换算系数、Δχ、晶胞参数）比语言更值得处理。

---

## 四、有意保留清单（不要为统一而 churn）

- 小节编号刻意镜像考纲条目（如 `### 9.1b`）→ 保留。
- 题目回链、跨文件引用规范 → 审查时不动。
- 已由源稿确认的写法 → 不改。

---

## 五、收尾流程

```
kb_gate verify → close → 工作日志记录（轮次、处数、存疑验证结果）→ archive
```

工作日志记在 `00-首页/工作日志/YYYY-MM-DD.md`，需在 `kb_gate close` 之后编辑（VERIFYING_ONLY_REPAIR 限制）。
