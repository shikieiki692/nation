- **Vault 根**：`C:\Obsidion\妙妙屋`；KB 文件一律用相对路径（无前导斜杠）。
- **KB 文件操作**：必须走 MCP `kb_*` 工具（kb_read / kb_write / kb_edit / kb_search / kb_gate）；**禁止**原生 Read/Write/Edit/Bash 修改 KB 文件（只读分析可用原生 Grep/PowerShell）。

- **搜可信替代图**：优先 grep [[10-索引与统计/视觉已验证图片索引]]（803 张人工确认）；未命中再 grep [[10-索引与统计/全库核心图谱总索引]]（2703 条 HIGH）。讲义插入必须用**完整 64 位哈希**：`![[<64位哈希>.jpg]]`。
- **工作流**：开工 kb_session init → kb_gate create → confirm → 编辑 → verify → close → archive。

## 三、判定标准与红线

1. **书籍教材优先**：优先教材扫描原图；化学结构/电化学类**严禁自绘**（2026-08-05 先例：21 张元素自绘被全量否决）。
2. **降级原则**：纯文字公式/算式/数据表能文本表达的不占图位，description 标注（纯文字算式片段，不推荐讲义配图）。
3. **不改语义字段**：图注若需改，只修正与图内容不符处；不确定就标 🔄 不改。
4. **图号连续性**：替换/删除图后检查图号是否重排（图注编号连续）。
