# 题集构建工作流

> **触发条件**：用户要求"组一套题集"、"编练习题"、"做一套习题"等
> **适用范围**：任何主题的竞赛练习题组构建（分子结构、原子结构、热力学等）
> **v2.0更新**：新增Step 5B答案交叉核验，解决v1.0中答案凭记忆编写导致大量错误的问题
> **v2.1更新**：新增Step 5C编辑验证（防假修复）、CFSE归因高频错误、OCR源可信度警告、Agent并行核验模式、Word预检集成、来源索引格式标准
> **v2.2更新**：新增错误模式知识库联动、跨套重叠检查、来源索引细化标准

---

## 核心原则

**先扫描，再选题，答案必须有据可查。** 绝不凭印象挑选来源，绝不凭记忆编写答案。

---

## 9步标准流程（v2.2）

### Step 1：题库全量扫描（最关键）

在动手编题之前，**必须**扫描题库中所有可能包含相关题目的来源：

| 扫描位置 | 说明 |
|:---|:---|
| `04-题库/化学原理/` | 按章节组织的题库（每题独立文件） |
| `04-题库/教材习题/` | 各教材的习题提取（初赛讲义、无机例题、上海中学等） |
| `04-题库/教学改编题/` | 已有的教学改编题 |
| `04-题库/真题/` | 历届初赛/决赛真题 |
| `06-外部资料导入/` | 外部导入的题库（如汇智竞赛题库） |
| `07-资料提炼/` | **已提炼的教材习题集（如赵鑫光竞赛题集OCR忠实版）** |
| `07-资料提炼/书籍提炼/` | **教材章节提炼（普化原理、无机化学、上海中学等）** |
| `04-专题与题型/专题/` | 专题页（含例题和参考答案） |

**扫描方法**：
1. 用 `Glob` 列出目标主题下的所有文件
2. 用 `Grep` 搜索关键词（如"分子结构"、"VSEPR"、"杂化"等）
3. 对每个命中的文件，`Read` 前30行确认题目数量和子话题
4. **输出来源清单**：文件路径 | 题目数量 | 已纳入/未纳入 | 子话题

> ⚠️ **禁止凭印象判断"某教材未提取"**，必须实际扫描确认。

### Step 2：重叠分析

将扫描到的所有来源与当前题集（如有）进行对比：
- 标记已纳入的来源和题号
- 标记未纳入的来源，按"独特性"和"质量"排序
- 识别可能重复的考点（如同一分子出现在多道题中）

**跨套重叠检查（v2.2新增）**：
- 用 `Grep` 在 `04-题库/教学改编题/无机和结构化学/题-改编-*.md` 中搜索目标分子/离子名
- 检查已有练习题组中是否已包含相同分子的题目
- 同一分子跨套出现**可以接受**（如二茂铁在分子结构考对称性、配合物考命名、晶体结构考晶胞），但需确保**考察角度不同**
- 同一分子同一角度跨套出现→必须去重

### Step 3：选题与组卷

按以下优先级选题：
1. **覆盖度优先**：确保所有核心考点都有题目覆盖
2. **难度梯度**：基础(⭐⭐) → 提升(⭐⭐⭐) → 挑战(⭐⭐⭐⭐)
3. **去重**：同一考点最多2道不同角度的题，避免重复
4. **来源多样**：自编 + 真题 + 教材 + 竞赛笔记，不偏废

**来源多样性最低要求（v2.2新增）**：
- 初赛真题 ≥ 15%（初赛题组的根基）
- 自编题 ≤ 65%（避免答案全凭记忆写）
- 决赛真题 ≤ 10%（慎用，标注"挑战"，注意不超纲）
- 单一来源 ≤ 30%（避免过度依赖某一本书/某个人）

### Step 4：编写题目

- 自编题：确保题目信息完整、无歧义
- 引用题：标注来源（届次/教材/页码）
- 每道题标注难度星级

### Step 5：答案编写（初稿）

- 每道题必须有对应答案
- 计算题给出完整过程和最终数值
- MO电子排布用标准记号
- VSEPR构型用"AXₙEₘ"标记

> ⚠️ **此步仅写初稿答案，不得直接发布！必须经过Step 5B交叉核验。**

### Step 5B：答案交叉核验（最关键·v2.0新增）

> **此步骤解决v1.0中答案凭记忆编写导致大量错误的核心问题。**
> **历史教训**：分子结构习题首次编写的97道题中，经过3轮修改仍有7处以上错误（HOMO方向写反、形式电荷算错、杂化方式标错、键级错误等）。

**核验前准备（v2.2新增）**：
- 先读 `04-题库/教学改编题/无机和结构化学/错误模式知识库.md`，加载历史错误模式
- 重点关注与当前主题相关的错误模式条目

**交叉核验的权威来源（按优先级排序）**：

| 优先级 | 来源 | 位置 | 说明 |
|:---:|:---|:---|:---|
| 1 | **真题解析** | `mineru/02-真题解析/` | 竞赛官方答案，最权威 |
| 2 | **专题页例题答案** | `04-专题与题型/专题/` | 教师编写的参考答案 |
| 3 | **教材提炼** | `07-资料提炼/书籍提炼/` | 普化原理、无机化学等教材内容 |
| 4 | **赵鑫光OCR忠实版** | `07-资料提炼/*-OCR忠实版.md` | 原书逐题提取 |
| 5 | **教材习题答案** | `04-题库/教材习题/` | 已有答案的习题 |
| 6 | **初赛讲义** | `06-外部资料导入/化学竞赛初赛讲义/` | 讲义配套习题 |

**核验规则**：

1. **引用题**（有明确来源的）：
   - 必须Read对应的原文件，逐字核对答案
   - 禁止"我大概记得答案是…"——必须看到原文才算核验通过

2. **自编题**：
   - 对于涉及MO理论、VSEPR、杂化、形式电荷等核心概念的题目
   - 必须在上述权威来源中找到**相同或类似知识点**的正确表述
   - 特别关注以下高频出错点：

   **MO理论必查清单**：
   - ☐ O₂系列MO排布：O₂²⁻(反磁)、O₂⁻(顺磁)、O₂(顺磁)、O₂⁺(顺磁)
   - ☐ C₂的MO：(σ2s)²(σ*2s)²(π2p)⁴→反磁性（π2p<σ2p的倒置排序）
   - ☐ CO的HOMO是5σ（C端孤对），不是σ2p（O端）
   - ☐ 键级计算公式：(成键电子-反键电子)/2

   **VSEPR/杂化必查清单**：
   - ☐ XeOF₂ = T形(sp³d)，不是直线形
   - ☐ SO₃²⁻ = 三角锥(sp³)，S形式电荷=+1（不是0）
   - ☐ CsF₅ = 四方锥(sp³d²，6域)，不是sp³d
   - ☐ F₄SCH₂中S = sp³d(5域)，不是sp³d²

   **形式电荷必查清单**：
   - ☐ FC = 价电子数 - 孤对电子数 - 成键数
   - ☐ 中性分子所有原子FC之和=0
   - ☐ 离子所有原子FC之和=离子电荷

   **离域π键必查清单**：
   - ☐ Πₘⁿ中m=参与原子数，n=π电子总数
   - ☐ 苯 = Π₆⁶，CO₃²⁻ = Π₄⁶，BF₃ = Π₄⁶
   - ☐ 环硼氮烷B₃N₃H₆(D₃h)偶极矩=0（对称抵消）

   **键角/偶极矩必查清单**：
   - ☐ NF₃键角(102°) < NH₃(107°)，因为F电负性大→键电子远离N→排斥减小
   - ☐ H₂O沸点>>HF：水有2供体+2受体→4氢键/分子；HF仅1供体→链状
   - ☐ CO偶极矩C⁻O⁺：HOMO(5σ)集中在C端

   **3c键必查清单**：
   - ☐ B₂H₆桥键是3c-2e键（不是3c-4e键），仅2个电子填入成键MO
   - ☐ XeF₂/I₃⁻的3c-4e键模型：4个电子填入成键+非键MO

   **CFSE归因必查清单（v2.1新增·配合物高频错误）**：
   - ☐ d⁵低自旋CFSE(-2.0Δₒ) **小于** d⁶低自旋CFSE(-2.4Δₒ)，不能说d⁵"CFSE特别大"
   - ☐ 高价态配合物更稳定的主要原因通常是**电荷效应+共价作用**，而非CFSE（例：Fe(CN)₆³⁻ vs Fe(CN)₆⁴⁻，Fe³⁺电荷更高→静电引力和共价作用更强→更稳定）
   - ☐ 同一金属不同氧化态比较稳定性时，优先归因于**电荷效应**，而非CFSE
   - ☐ 只有在**相同氧化态、相同配体**条件下，才能用CFSE解释稳定性差异

   **Nernst方程必查清单**：
   - ☐ 注意n值：Hg²⁺/Hg半反应n=2（不是1），Fe³⁺/Fe²⁺ n=1
   - ☐ 标准态活度=1（纯固体、纯液体、1 mol/L溶液）

3. **OCR来源可信度警告（v2.1新增）**：
   > ⚠️ OCR忠实版≠完全正确。原书排版/OCR识别可能引入错误（如PtCl₄²⁻在赵鑫光原书中被写为"正四面体"，实际应为"平面正方形"，这是d⁸电子构型的常识）。
   >
   - 当OCR答案与**基本化学常识**矛盾时，应以化学逻辑为准并标注"OCR原文可能有误"
   - 引用OCR来源时，对构型/空间结构类答案需额外验证

4. **逐题核验（推荐Agent并行模式）**：
   - **并行核验**：启动2个Agent分别核验题目（如Agent A核验1-42题，Agent B核验43-85题）
   - **交叉验证**：两个Agent独立发现的错误取并集；同一题两个Agent结论矛盾时，人工复核
   - 每个Agent输出每题的✅/❌状态及错误描述
   - 所有❌必须修正后重新核验
   - 修正后重新生成Word

5. **核验记录**：
   - 核验结果保存为内部记录
   - 报告给用户：共N题，通过N题，修正N题
   - v2.1建议：记录发现的错误模式类型（如"CFSE归因错误×3"），便于后续加入高频错误清单

### Step 5C：编辑验证（防假修复·v2.1新增）

> **此步骤解决AI声称"已修复"但实际文件未修改的问题。**
> **历史教训**：详见 [[model-hallucination-fake-fixes]]——原子结构讲义经历6轮"假修复"，文件一个字没改。

**每处编辑完成后，必须执行**：
1. **Read回读**：对编辑位置附近区域执行 `Read`，确认文本已变更
2. **Grep验证**：搜索新文本是否出现在文件中（`grep "新文本" 文件路径`）
3. **禁止跳过**：即使Edit工具返回"成功"，仍需回读确认——工具可能报告成功但实际未写入
4. **报告格式**：不说"修复了Q13b"，说"Q13b第X行：'d⁵低自旋CFSE特别大' → 'Fe³⁺电荷更高→静电引力和共价作用更强'"

### Step 6：质量检查（3轮）

**第1轮：重复检查**
- 用 `Grep` 搜索关键分子/离子名，找出可能重复的题目
- 特别关注：O₂系列MO、NH₃/NF₃偶极矩、常见VSEPR分子

**第2轮：答案正确性**（与Step 5B合并）
- Step 5B已完成逐题核验
- 此步仅做补充抽查

**第3轮：图片检查**
- 用 `Grep` 搜索 `![[` 找出所有图片引用
- 用 `Glob` 验证每张图片文件存在

**第4轮：Word预检（v2.1新增）**：
```bash
python "11-模板/scripts/build-all-handout-docx.py" --precheck-only --path "04-题库/教学改编题/目标文件.md"
```
- precheck会标记：bare_subscript（裸下标）、standard_state（标准态符号）、E°不兼容等
- **已知可忽略的警告**：`bare_subscript_generic`（如 N_A 表示阿伏加德罗常数——这是约定写法，Word中N~A~已通过Lua filter处理）
- **必须修复的警告**：`standard_state_degree_symbol`（E°→替换为"标准电极电势"文字）

### Step 7：Word导出

```bash
python "11-模板/scripts/build-all-handout-docx.py" --path "04-题库/教学改编题/目标文件.md" --output-dir "00-首页/学生讲义Word"
```

**常见问题及对策**：
- **WinError 5（文件被占用）**：用户在Word中打开了该文件→关闭Word后重试
- **MCP会话过期**：kb_session超时→重新执行 `kb_session init` 后继续
- **公式渲染异常**：检查Step 6第4轮precheck是否遗漏了关键警告

### Step 8：更新系统文件

- 更新题集的 frontmatter（question_count、updated）
- 更新难度总览表
- 更新知识点索引和来源索引
- 同步首页相关内容

**更新错误模式知识库（v2.2新增）**：
- 核验中发现的新错误模式→归档到 `04-题库/教学改编题/无机和结构化学/错误模式知识库.md`
- 收录标准：≥2次出现 或 系统性可预见陷阱
- 每条记录 = 一行规则 + 一个典型案例（题号）

**来源索引格式标准（v2.1新增，v2.2细化）**：

来源索引必须**逐题列出具体题目内容**，不能只写题号范围。格式：

```markdown
| 题号 | 来源 | 具体内容 |
|:---:|:---|:---|
| Q1 | 赵鑫光竞赛题集 例1 | 配合物命名：[Co(NH₃)₅Br]SO₄ |
| Q2 | 自编 | 硫酸四氨合铜化学式书写（2小问） |
| Q3 | 2023初赛 | 配合物几何构型判断（正四面体vs平面正方形） |
| Q4 | 《普通化学原理》(第4版) 习题13.5 | BaTiO₃钙钛矿（原子数/配位数/半径计算） |
```

> ⚠️ 不要使用 `Q1-15 赵鑫光` 这种合并写法——读者无法从索引判断具体题目内容。
> ⚠️ 教材题必须写明 **《书名》(版次) 习题号**，不能只写"教材习题"。

## 常见踩坑（v2.1更新）

| 坑 | 规避 |
|:---|:---|
| 只看2-3个来源就开始编 | 必须完成Step 1全量扫描 |
| 同一O₂系列MO出现3-4次 | Step 2重叠分析中标记，最多保留2道 |
| **答案凭记忆编写，MO/VSEPR/杂化/形式电荷出错** | **Step 5B强制交叉核验——引用题必须Read原文逐字核对，自编题必须在权威来源中找到相同知识点的正确表述** |
| **自编题比例过高(>50%)，质量无法保证** | **Step 3来源多样性要求——以题库现有题目为主，自编≤65%** |
| CO的HOMO方向写反 | Step 5B MO理论必查清单 |
| 形式电荷算错 | Step 5B形式电荷必查清单，验证FC之和 |
| 环硼氮烷偶极矩判断错 | Step 5B离域π键必查清单 |
| B₂H₆桥键类型写错(3c-4e→应为3c-2e) | Step 5B 3c键必查清单 |
| **CFSE归因错误（d⁵说CFSE大、高价态说CFSE大）** | **Step 5B CFSE归因必查清单——优先归因电荷效应** |
| **OCR来源答案有误（构型/空间结构）** | **Step 5B OCR可信度警告——与化学常识矛盾时以逻辑为准** |
| **声称"已修复"但文件未修改** | **Step 5C强制回读验证——Read+Grep确认文本已变更** |
| **E°符号导致Word公式渲染失败** | **Step 6第4轮precheck + 替换为"标准电极电势"** |
| **Word文件被占用(WinError 5)** | **Step 7关闭Word后重试** |
| **MCP会话过期(kb_session)** | **Step 7重新init后继续** |
| 图片引用指向不存在的文件 | Step 6第3轮Glob验证 |
| 题集越编越长没有边界 | Step 3控制总量（建议60-100题） |
| 来源索引只写题号不写内容 | Step 8逐题列出具体题目描述 |

## 附录：答案编写自查清单（每次编写答案前必读）

编写每道题的答案时，先问自己：

1. **这个答案我在哪个权威来源中见过相同/类似的表述？**
   - 有 → Read该来源核对
   - 没有 → 这道题的答案可能需要更谨慎

2. **涉及MO理论时**：
   - HOMO/LUMO方向是否正确？（CO的HOMO在C端）
   - 键级计算是否正确？（成键-反键）/2
   - 磁性判断是否正确？（未成对电子数）

3. **涉及VSEPR/杂化时**：
   - 电子域数是否正确？（孤对+σ键+π键在VSEPR中各算1域）
   - FC之和是否匹配分子/离子电荷？

4. **涉及离域π键时**：
   - Πₘⁿ中m和n是否正确？
   - 是否考虑了所有参与原子？

5. **涉及键角/偶极矩时**：
   - 电负性对键角的影响方向是否正确？
   - 矢量叠加是否正确？

6. **涉及CFSE/配合物稳定性时**（v2.1新增）：
   - 比较的是**相同氧化态**还是**不同氧化态**？
   - 如果是不同氧化态，主要归因应该是**电荷效应**而非CFSE
   - d⁵低自旋的CFSE(-2.0Δₒ)比d⁶(-2.4Δₒ)小，不要说d⁵"CFSE特别大"

7. **涉及OCR来源的答案时**（v2.1新增）：
   - 构型/空间结构是否与d电子数一致？
   - 与基本化学常识矛盾时，以逻辑为准并标注
