# 题集构建工作流

> **触发条件**：用户要求"组一套题集"、"编练习题"、"做一套习题"等
> **适用范围**：任何主题的竞赛练习题组构建（分子结构、原子结构、热力学等）

---

## 核心原则

**先扫描，再选题，最后编写。** 绝不凭印象挑选来源。

---

## 8步标准流程

### Step 1：题库全量扫描（最关键）

在动手编题之前，**必须**扫描题库中所有可能包含相关题目的来源：

| 扫描位置 | 说明 |
|:---|:---|
| `04-题库/化学原理/` | 按章节组织的题库（每题独立文件） |
| `04-题库/教材习题/` | 各教材的习题提取（初赛讲义、无机例题、上海中学等） |
| `04-题库/教学改编题/` | 已有的教学改编题 |
| `06-外部资料导入/` | 外部导入的题库（如汇智竞赛题库） |
| `07-资料提炼/` | 已提炼的教材习题集（如赵鑫光竞赛题集） |
| `04-专题与题型/题型/` | 题型方法论指南（含典型例题） |

**扫描方法**：
1. 用 `Glob` 列出目标主题下的所有文件
2. 用 `Grep` 搜索关键词（如"分子结构"、"VSEPR"、"杂化"等）
3. 对每个命中的文件，`Read` 前30行确认题目数量和子话题
4. **输出来源清单**：文件路径 | 题目数量 | 已纳入/未纳入 | 子话题

> ⚠️ **禁止凭印象判断"某教材未提取"**，必须实际扫描确认。

### Step 2：重叠分析

将扫描到的所有来源与当前题集（如有）进行对比：
- 标记已纳入的来源和题号
- 标记未纳入的来源，按"独特性"和"质量"排序
- 识别可能重复的考点（如同一分子出现在多道题中）

### Step 3：选题与组卷

按以下优先级选题：
1. **覆盖度优先**：确保所有核心考点都有题目覆盖
2. **难度梯度**：基础(⭐⭐) → 提升(⭐⭐⭐) → 挑战(⭐⭐⭐⭐)
3. **去重**：同一考点最多2道不同角度的题，避免重复
4. **来源多样**：自编 + 真题 + 教材 + 竞赛笔记，不偏废

### Step 4：编写题目

- 自编题：确保题目信息完整、无歧义
- 引用题：标注来源（届次/教材/页码）
- 每道题标注难度星级

### Step 5：答案编写

- 每道题必须有对应答案
- 计算题给出完整过程和最终数值
- MO电子排布用标准记号
- VSEPR构型用"AXₙEₘ"标记

### Step 6：质量检查（3轮）

**第1轮：重复检查**
- 用 `Grep` 搜索关键分子/离子名，找出可能重复的题目
- 特别关注：O₂系列MO、NH₃/NF₃偶极矩、常见VSEPR分子

**第2轮：答案正确性**
- 逐题核对答案（至少抽查50%）
- 重点检查：键能计算、MO排布、杂化判断、形式电荷

**第3轮：图片检查**
- 用 `Grep` 搜索 `![[` 找出所有图片引用
- 用 `Glob` 验证每张图片文件存在

### Step 7：Word导出

```bash
python "11-模板/scripts/build-all-handout-docx.py" --path "04-题库/教学改编题/目标文件.md" --output-dir "00-首页/学生讲义Word"
```

### Step 8：更新系统文件

- 更新题集的 frontmatter（question_count、updated）
- 更新难度总览表
- 更新知识点索引和来源索引
- 同步首页相关内容

---

## 常见踩坑

| 坑 | 规避 |
|:---|:---|
| 只看2-3个来源就开始编 | 必须完成Step 1全量扫描 |
| 同一O₂系列MO出现3-4次 | Step 2重叠分析中标记，最多保留2道 |
| 答案中MO排布写错 | Step 6第2轮逐题核对 |
| 图片引用指向不存在的文件 | Step 6第3轮Glob验证 |
| 题集越编越长没有边界 | Step 3控制总量（建议60-100题） |
