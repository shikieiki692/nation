# 习题书 · 学生版（黑白打印版）

> 在 `../学生版/`（彩色 · 屏幕阅读）基础上改造，专为**黑白打印**与**分发给学生手写**优化。
> 原版保留不动。

## 改动清单

| 项目 | 原版 | 打印版 | 目的 |
|------|------|--------|------|
| **封面** | 每章首页有书名/篇/章/题量/版本/日期 + 分隔线 | 删除 | 省纸 33 页 |
| **文字颜色** | 灰蓝 5B6975、深蓝 17324D 等 6+ 种彩色 | 全部纯黑 `#000000` | 黑白打印可辨 |
| **背景底纹** | 无 | 无 | — |
| **化学结构式/晶胞图** | 17 张彩色（元素用不同颜色标记） | 自动转灰度 + 对比度增强 | 黑白打印仍可辨元素 |
| **其他图片** | 491 张灰度/黑白 | 保留不变 | 避免无谓降质 |
| **页眉** | 无 | 右对齐：`第一篇 化学原理 · 第1章 热力学`，下加细线 | 散页可归位 |
| **页脚** | 仅页码 | `第 X 页 / 共 Y 页`（自动算总页数） | 方便核对是否缺页 |
| **题组标题** | 段前 14pt | 段前 ≥14pt，与下一段同行（防孤行） | 打印翻页友好 |
| **字体** | Times New Roman | 不变 | 尊重原排版 |
| **公式（OMML）** | 3,952 处 | 100% 保留 | 化学表达不能损坏 |

## 打印建议

- 纸张：A4，单面 / 双面皆可
- 模式：单面（双面的话学生答题背面易脏；如要双面请把页边距加装订线 0.5cm）
- 质量：标准 / 草稿皆可（已无底纹，纯文本与线稿，省墨）
- 页边距：保持默认 2cm / 2.2cm

## ⚠️ 源数据遗留问题

**约 51% 图片原始分辨率偏低**（有效 DPI < 150，主要是波谱图与小型结构式）。
原素材本身就是低分辨率（72-100 DPI），转换未将其放大（放大无效），打印时小图会略虚。
若需高清版，需回溯到 04-题库/ 对应题目的源图替换。

## 复现命令

python .workbuddy/scripts/build_print_student.py
