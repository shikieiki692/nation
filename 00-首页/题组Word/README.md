## 统一命名规范（成品输出规则收拢）

1. **版本后缀词表**（全局唯一，禁再发明）：
   - `-教师版`＝题面＋参考答案区；`-学生版`＝纯题面；`-学生版-打印版`＝黑白灰度打印
   - `-答案`＝答案单独册（仅阶段测试卷族历史惯例保留）
2. **分隔符**：一律连字符 `-`（文件名禁中点 `·`、空格混排）
   - ⚠️ 例外：「第一轮·竞赛教材版」「第一轮·综合套卷」两族现存名为**全角括号** `第XX卷（学生版）`；
     其打印版按同风格命名为 `第XX卷（学生版-打印版）`（不新增第三种风格；日后若要统一到 `-` 需连带改引用）
3. **卷号**：罗马数字 I~XII 保留（卷族既有谱系）；章号阿拉伯数字
4. **组卷规则**：每卷 ≤15 题；同一来源 ≤2 题（模拟卷）；教师版/学生版双版成对
5. **出口双轨**：讲义类产物 → `06-学生侧材料/讲义/`；题库类产物 → `00-首页/题组Word/`；旧版一律进各自 `_archive/`，禁止在产物目录自建归档夹
