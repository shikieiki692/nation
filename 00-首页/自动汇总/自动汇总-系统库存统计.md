# 自动汇总 · 系统库存统计

> 本页聚合各内容系统的**文件库存计数**，全部由 frontmatter / 文件夹**自动计算**。
> 用途：替代 [[全局导航]] 与各系统 README 中的手更硬编码快照，消灭数字漂移。
> 阶段判断、完成度解读不在本页维护（见 [[自动汇总-说明]]）。

## 知识点（03-知识点 · type=知识点）

```dataview
TABLE length(rows) AS 文件数
FROM "03-知识点"
WHERE type = "知识点"
GROUP BY subject
SORT length(rows) DESC
```
