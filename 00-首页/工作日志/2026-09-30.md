## 五、🆕 判据坑（本轮实测，均已入记忆）

1. 🔴 **哈希比对正则必须含 `\|宽度` 后缀** —— 表格化的 `![[hash\|250]]` 否则全部漏统计（会得出「缺一大半图」的假警报）。
2. 🔴 **`validate_kb.py --changed` 不带参数＝「受检 0 文件」** —— 不会自动读 git 改动，必须显式传路径。
3. 🔴 **`jsyaml_verify.js` 报 `EBUSY: spawnSync python`**（PATH 无 `python`）⇒ 用 `validate_kb` 的 FM 检查兜底。
4. 🔴 **并行会话会清空主索引**：`git add` 后他人一提交，暂存消失，commit 报 **`no changes added to commit`**（不是 `cannot lock ref`）。判据＝`git status` 仍为 ` M`；处置＝重新精确 add。
5. 🔴 **`build-all-handout-docx.py --path` 有 subpath bug**：要求 md 在 `04-课件/学生讲义` 下，试卷在 `04-课件/习题集/` ⇒ `ValueError`。绕过＝staging + `--batch-root`。
6. 🔴 **XeChem 大合并 PDF（85–113MB/200 页）禁硬翻** —— 用「讲义（答案讲评版）」分级小 PDF（每卷 5–7MB，含题目+答案）。
