## 三、陈旧 docx 复核（判据升级 —— 本轮最重要方法学收获）

**问题**：`_数学工具/` 有 5 份 docx 的 `mtime < md.mtime`，看似全部陈旧。

**判据升级**：
- `docx.mtime < md.mtime` **只是「候选」** —— 改 frontmatter（如 `related:` 链接）会抬高 md mtime 却**不改产物正文** ⇒ **假陈旧**。
- **真陈旧判据 = 重渲染后 `word/document.xml` 有差异**；`core.xml`（时间戳）/`styles.xml` 逐份必不同，是**噪声**，不得作判据。
- 实现：`zipfile` 读 `word/document.xml` 做逐字节比对。

**实测结果**：5 候选 → **真陈旧 2 / 假陈旧 3**。

| 文件 | 结论 | 实际差异 |
|:---|:---|:---|
| `_数学工具/数学工具-第5讲-偏导与全微分.docx` | **真陈旧** | `a/V_m2` → `a/Vm2` |
| `_数学工具/数学工具-第6讲-量纲数量级与估算.docx` | **真陈旧** | `顺带看出` → `由此亦可看出` |
| 其余 3 份 | 假陈旧 | `document.xml` 逐字节一致 |

**全量兜底**：84 份在役 md（133 产物）逐份重渲染比对 → **真陈旧 0 / 一致 82 / 无 docx 2**，证明**全库讲义产物与 md 源 100% 同步**。**提交** `fc4460695`（2 files）。

> 全量渲染耗时 6m24s，须后台跑（前台会超时）。

## 四、锁定孤儿 docx 根因定位与清除

**对象**：`06-学生侧材料/讲义/化学原理/胶体与表面物理化学-超级充实版（自学完整）.docx`（旧结构残留孤儿，正确副本已在 `3-物理化学/`）。

**根因链（逐层排除）**：

| # | 假设 | 反证 |
|:--:|:---|:---|
| 1 | WPS 预览宿主 `wps.exe /Preview -Embedding` | kill 后错误变为 `BULK_DELETE_GUARD`，看似「重启恢复锁」— **误导** |
| 2 | Obsidian / explorer / prevhost / dllhost / SearchIndexer | 限定范围扫描 908 个文件句柄 → **hits=0** |
| 3 | 属性异常 / ADS / 只读 / 杀软 | `attrib=A`、`0o100666`、`nlink=1`、无 `Zone.Identifier`，与对照文件一致 |
| 4 | 目录策略 / 全角括号文件名 | 同目录新建「括号测试（自学完整）.tmp」→ **删除 OK**；copyfile 副本 → **删除 OK** |
| **5** | **`editor_sdk.exe`（WorkBuddy 本地文档编辑器 SDK 宿主，PID 13572）** | **单进程句柄导出：持有该文件 7 个句柄（`access=0x100088`/`0x120089`）** ← **真凶** |

**用户断言正确**：用户说「我就没打开过这个文件」—— **是 SDK 后台打开并泄漏了句柄**（同进程还持有 `备课思路/未央化学竞赛课程计划.docx`、`00-首页/题组Word/**` 等此前用编辑器打开过的文件）。

**处置**：
1. `taskkill /PID 13572 /F`（editor_sdk 未重启）
2. `os.remove` **仍报同样错误** ⇒ **safe-delete 沙箱层缓存了失败结果**（`SAFE_DELETE_FAIL_CLOSED` + `trash-failed: Some operations were aborted`）
3. **绕过正解**：原生 `CreateFileW(DELETE)` + **`SetFileInformationByHandle(FileDispositionInfo=4)`** → **删除成功**
4. `os.rmdir` 清空目录 `化学原理/` → OK

**验收**：顶层现为 `1-化学基础知识`…`6-有机化学` + `_数学工具`/`_综合`/`_archive`/`media`，**无旧目录残留**；全库 92 份在役 docx 逐个 rename 探测 → **仅此 1 份被锁，现已清零**。
