## 三、推送：绕过 system 层 credential selector

- 现象：`git push` 零输出挂起；`git ls-remote` 秒回（网络通）、wincred 能取到凭据。
- 真凶：**system 层** `credential.helper=helper-selector` 在等 GUI 编辑器。
- 解法：`GIT_CONFIG_NOSYSTEM=1 GIT_TERMINAL_PROMPT=0 git push --progress origin master`
  （system 配置整体不加载，global 层 wincred 接手，认证立刻通过）。免建 shim。
- 上传慢（~115 KiB/s / 1855 对象 / 120 MiB），首批 11 条约 25 分钟，验收报告 1 条秒完成。

**另一个坑**：本仓库**没有 `origin/master` remote-tracking ref**，
`git log origin/master..HEAD 2>/dev/null | wc -l` 会 `fatal` 后**静默输出 0**，
被误读成「已全部推送」。正确姿势是 `git ls-remote origin master` 比对 `git rev-parse HEAD`。
