# Word友好 Markdown 符号速查表

> **定位**：这是公式/上下标的快速避坑页；正式源稿规范以 [[11-模板/MD通用规范（Word-PDF共同最优子集）]] 为准。

## 一句话规则

简单就 Unicode，复杂就整段 math，绝不要半截 math。

## 默认写法优先级

1. 固定离子、固定电子排布、简单上下标，优先直接写成 Unicode 正文。
2. 变量角标、字母角标、复杂轨道标签、推导公式，整段放进一个数学模式。
3. 图注、表注、提示语，优先纯文本，不要塞复杂公式。

## 直接可用的安全写法

| 场景 | 推荐写法 |
| --- | --- |
| 简单离子 | `Na⁺`、`Fe²⁺`、`S²⁻`、`Cl⁻` |
| 常见分子/离子 | `H₂O`、`NH₄⁺`、`SO₄²⁻`、`ClO⁻` |
| 简单电子排布 | `2s²2p³`、`3d¹⁰4s¹`、`[Ar]3d⁶` |
| 简单物理量记号 | `I₁`、`I₂`、`Z*` |
| 复杂轨道标签 | `$d_{xy}$`、`$t_{2g}$`、`$e_g$` |
| 复杂轨道名称 | `$4f_{+3}$`、`$4f_{x(x^2-3y^2)}$` |
| 复杂离子/配合物 | `$[\mathrm{Fe(H_2O)_6}]^{2+}$` |
| 复杂比较链 | `$O^{2-}(140\ \mathrm{pm}) > F^{-}(133\ \mathrm{pm}) > Na^{+}(102\ \mathrm{pm})$` |
| 定义/推导公式 | `$Z^{*} = Z - \sigma$`、`$E = -13.6 (Z^{*})^2 / n^2$` |

## 严禁写法

这些写法最容易在 Word 里炸成“字母和上下标分家”或“半截公式残留”：

| 错误写法 | 原因 | 推荐改法 |
| --- | --- | --- |
| `Na$^+$` | 正文 + 半截上标公式 | `Na⁺` 或 `$Na^+$` |
| `2s$^2$2p$^3$` | 一个排布拆成多段 | `2s²2p³` 或 `$2s^22p^3$` |
| `4f$_{+3}$` | 正文 + 空基底下标公式 | `$4f_{+3}$` |
| `2p$_0$` | 正文 + 空基底下标公式 | `$2p_0$` |
| `$I_1$(Na)` | 公式结束后立刻黏正文 | `I₁(Na)` 或 `$I_1(\mathrm{Na})$` |
| `Z$^*$` | 正文 + 半截上标公式 | `Z*` 或 `$Z^{*}$` |
| `Na$^+$+F$^-$` | 一串反应式被拆碎 | `Na⁺+F⁻` 或 `$Na^+ + F^-$` |

## 什么时候用 Unicode

下列情况优先 Unicode：

- 只是固定名称，不需要推导。
- 放在中文解释句里，目标是“读起来顺”。
- 上下标只包含数字或简单电荷，如 `²⁺`、`⁻`、`₂`。
- 内容会反复出现很多次，想减少 Word 公式编辑器介入。

例子：

- `S²⁻ > Cl⁻`
- `O²⁻(140 pm) > F⁻(133 pm) > Na⁺(102 pm)`
- `P 的 3p 电子更容易失去，因此 I₁ 低于 ...`

## 什么时候用整段数学模式

下列情况整段写成一个 `$...$`：

- 角标里有字母、括号、正负号组合。
- 需要分式、根号、求和、箭头、向量、矩阵。
- 是真正的推导式，不只是符号展示。
- 轨道标签、群论标签、配位场符号等具有严格排版需求。

例子：

- `$Z^{*}$`
- `$I_1(\mathrm{Na}) - EA(\mathrm{F})$`
- `$4f_{x(x^2-3y^2)}$`
- `$B_2: \sigma_{2s}^2 \sigma_{2s}^{*2} \pi_{2p}^2$`

## 正文写作建议

- 同一句里尽量只选一种策略，不要一半 Unicode 一半 `$...$`。
- 能写成自然中文就不要强行塞公式编辑器。
- 如果要进数学模式，把整个最小 token 一次性包完整。
- `I₁`、`I₂`、`Na⁺`、`Fe²⁺` 这种正文记号可以直接写，不必硬改成公式。
- `Z*` 在解释句里可直接用；推导式里优先 `$Z^{*}$`。

## 图注与表注

- 图注只保留纯文本说明。
- 图注不要放长公式，不要放复杂上下标组合。
- 表格正文中的简单离子、电子排布可继续用 Unicode。
- 表头若只是固定标签，优先纯文本，如 `I₁`、`Z*`、`电子排布`。

## Mermaid 与流程图

- 不要在学生讲义源稿里直接保留 ```` ```mermaid ```` 或 `~~~mermaid`。
- 不要写 `![[xxx.md]]` 去依赖 Mermaid/笔记嵌入兼容层。
- 正式成品只保留两种形态：
  - `![[media/xxx.png]]`
  - 表格 / 步骤列表 / 判定清单
- 经验规则：能用静态图说清楚的，就不要把图源码留给 Word 管线处理。

## 生成前快速自检

生成 Word 前，优先检查有没有这些高风险片段：

- `Na$^+$`
- `2s$^2$2p$^3$`
- `4f$_{+3}$`
- `2p$_0$`
- `$I_1$(`
- `Z$^*$`
- 图注里出现 `$...$`
- ` ```mermaid `
- `![[xxx.md]]`
