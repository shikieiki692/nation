## 三、链接指标的边界

`broken_candidates = 7491` 只能表述为“断链候选”。当前脚本已经排除：

- 代码块中的伪链接；
- 图片嵌入路径；
- 审计报告引用的来源文件名；
- 归档、外部导入等噪声目录。

但候选集中仍可能包含模板占位、目录型引用、特殊索引路径和动态命名。后续必须继续分类，完成分类前不得对外宣称“存在 7491 条真实断链”。

## 四、更新规则

1. 在知识库根目录运行：`python .workbuddy/scripts/kb_metrics.py`
2. 将脚本的完整 JSON 输出同步到 [[00-首页/指标事实源.json]]。
3. 更新本页的指标表和 `updated` 字段。
4. 指标发生变化时，在 [[00-首页/状态摘要]] 记录变化原因，不覆盖历史结论。
5. 禁止直接编辑 JSON 中的数字；它是脚本生成的机器快照。
