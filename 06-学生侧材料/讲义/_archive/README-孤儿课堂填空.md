## 为什么归档

1. 全库 34 份「超级充实版」md 源**全部是（自学完整）版，`（课堂填空）` 版 md 源为 0 份**，这 5 个 docx 只能由已不存在的 md 导出。
2. 违反 SOP「docx/PDF 是派生物，可随时删除重新导出」——它们删了就再也出不来。
3. 保留在主目录会让学生/教师误以为是当前可用版本。

## 如需课堂填空版

不要直接改这些 docx。正确做法是**从对应的（自学完整）md 重新生成**：

1. 先确定挖空规则（挖哪些内容：结论句 / 关键数据 / 方程式产物？挖空比例？是否留提示？）——这是产品决策，未定则不应开工。
2. 按规则写生成脚本，输出 `xx-超级充实版（课堂填空）.md` 到 `04-课件/学生讲义/`。
3. 用 `11-模板/scripts/build-all-handout-docx.py --path <该 md>` 导出。

> 参考：`11-模板/归档/模板-学生讲义-课堂填空版.md` 已 `status: deprecated`（2026-06-25 废弃）；
> `11-模板/scripts/clean_inline_answers.py` 是消费方（给已存在的填空 md 删答案），其 `handouts` 列表硬编码的 3 个 md 现已不存在，同样失效。
