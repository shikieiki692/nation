# 06-学生侧材料/讲义 — 讲义 docx 产物目录

## 定位

讲义 Word 产物的**唯一当前落点**。2026-09-07 起，`11-模板/scripts/build-all-handout-docx.py` 的默认输出指向这里（此前是 `00-首页/学生讲义Word`，导航区不再堆产物）。

- **源**：`04-课件/学生讲义/*.md`
- **生成**：`python -X utf8 11-模板/scripts/build-all-handout-docx.py`（默认批量，不递归 `_归档`）
- **性质**：派生物，删除可随时重建；改需求一律改 md 源，不要直接改 docx

## 子目录

| 目录 | 内容 | 能否用 |
|:--|:--|:--|
| `_archive-旧版产物/` | 2026-06 及更早的历史产物（含手工拷贝、旧版导出；内含 `试印版/` 试印件），**已过时** | ❌ 仅供回溯 |
| `_archive/` | 「-超级充实版（课堂填空）」5 个孤儿 docx，**无 md 源、不可重建** | ❌ 见其内 README |
| `media/` | 讲义图片 | ✅ |

> 注：原根级 `试印版/`（2026-06-23 试印件）已于 2026-09-07 归档至 `_archive-旧版产物/试印版/`；根级两个 `2026-06-16-*_render/` 渲染中间产物已删除（对应 md 源已废弃）。

## 为什么旧物不删而归档

同名对比显示：两边同名的 36 个文件里，当前产物**全部**新于旧物（旧物无一更新），理论上旧物可删。但其中 44 个是历史独有文件（对应 `_归档/` 里的旧命名 md），保留可回溯，故统一移入 `_archive-旧版产物/` 而非删除。

## 使用提醒

- 找讲义只在本目录根下找；文件名 = md 源名（不含日期前缀的变体）。
- 看到 `_archive` 开头的一律不要发给学生。
- 需要「课堂填空」版？目前无源可生成，须先定挖空规则，再从对应的「（自学完整）」md 生成（见 `_archive/README-孤儿课堂填空.md`）。
