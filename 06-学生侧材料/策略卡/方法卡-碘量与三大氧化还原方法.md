# 方法卡：氧化还原滴定三大方法速查（KMnO₄ / 碘量法 / K₂Cr₂O₇）

## 正面（识别面）

**【一句话定位】**
面对待测物，快速选法并记对滴定条件。

**【适用信号】**
- ⭐ 问"测某物质用什么氧化还原滴定法"
- ⭐ 问该法的介质、指示剂、淀粉加入时机
- ⭐ 问误差来源（I₂ 挥发、淀粉加早、诱导反应）

**【不适用陷阱】**
- ❌ 只有判据题（能否滴定）先查 [[方法卡-氧化还原滴定判据]]
- ❌ 碘量法测氧化性物质用直接法、测还原性用间接法（方向别反）

## 背面（操作面）

**【操作步骤】**
1. 判断待测物是**氧化性**还是**还原性**
2. 氧化性物质 → **间接碘量法**（弱酸介质；淀粉**近终点浅黄**才加；加早包裹 I₂ 终点滞后）
3. 还原性物质：
   - 强还原 → **KMnO₄ 法**（强酸用 H₂SO₄ 不用 HCl；紫红色自身指示剂）
   - 强还原 → **K₂Cr₂O₇ 法**（基准物直接配制；测全铁加 H₃PO₄ 降 Fe³⁺/Fe²⁺ 电位）
   - 弱还原（Sn²⁺、S²⁻、As(III)）→ **直接碘量法**（中性/弱酸，淀粉可随加）
4. 计量关系：**I₂ : S₂O₃²⁻ = 1 : 2**
5. Cu²⁺ 间接碘量法近终点加 **KSCN**，释放被吸附的 I₂

**【口诀】**
"氧化物间接碘，强还原高锰重铬，弱还原直接碘；淀粉别早加"

**【典例速查】**
- 测 Cu²⁺：加过量 KI → I₂ 析出 → Na₂S₂O₃ 滴定 → 近终点加淀粉 + KSCN
- KMnO₄ 标定 Na₂C₂O₄：需加热、慢滴、先慢后快（Mn²⁺ 自催化）

**【检查清单】**
- ☐ 淀粉时机：间接法**近终点浅黄**才加
- ☐ KMnO₄ 介质用 H₂SO₄，禁 HCl（Cl⁻ 被氧化，诱导误差）
- ☐ 硫代硫酸钠标准液滴定 I₂，计量比 1:2
