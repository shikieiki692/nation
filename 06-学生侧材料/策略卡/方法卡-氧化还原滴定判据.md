# 方法卡：氧化还原滴定可行性判据

## 正面（识别面）

**【一句话定位】**
判断某个氧化还原反应能否直接用于滴定，并预判突跃与指示剂。

**【适用信号】**
- ⭐ 问"能否准确滴定某物质"
- ⭐ 问突跃范围大小 / 计量点电位 / 选什么指示剂
- ⭐ 给定两电对的标准（条件）电位让判断

**【不适用陷阱】**
- ❌ 配平题、化学计量比计算不归这张卡管
- ❌ 必须用**条件电位**（介质修正后），不能裸用标准电位

**适用**：分析化学 / 氧化还原滴定

## 背面（操作面）

**【操作步骤】**
1. 查出/算出两电对的条件电位 E°′（注意介质：酸度、络合、沉淀影响）
2. 算 ΔE°′ = E°′(氧化剂) − E°′(还原剂)
3. ΔE°′ **≥ 0.35 V** → 突跃明显，可准确滴定
4. 计量点电位（对称电对）：Esp = (n₁E₁ + n₂E₂) / (n₁+n₂)
5. 指示剂：变电位的条件电位落在突跃范围内（选得越接近计量点越好）

**【口诀】**
"ΔE 零点三五判可行，计量点电位加权均"

**【典例速查】**
- 氧化剂 E°′=1.00 V，还原剂 E°′=0.68 V → ΔE°′=0.32 V < 0.35 → **不可准确滴定**
- Esp 例：(6×1.00 + 1×0.68)/7 ≈ 0.95 V（两电对电子转移数 6 与 1）

**【检查清单】**
- ☐ 用的是条件电位还是标准电位（有介质条件时用前者）
- ☐ 不对称电对计量点电位公式不同（含 n 交叉项），别套错
- ☐ 指示剂变色电位须落在突跃范围内
