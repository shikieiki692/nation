# 方法卡：Lambert-Beer 定量与测量条件

## 正面（识别面）

**【一句话定位】**
用吸光度求浓度：会换算 A–T–c，会选测量范围，会判断偏离。

**【适用信号】**
- ⭐ A = κbc 直接求 c / 求摩尔吸收系数 κ
- ⭐ A 与 T（透光率）互换算
- ⭐ 问最佳测量范围、最小误差点、标准曲线法
- ⭐ 问"曲线为何弯曲偏离 Beer 定律"

**【不适用陷阱】**
- ❌ A 与 T **不是正比**（A = −lgT），不能把 A 当 T 直接比
- ❌ 浓度过高已偏离 Beer 时，不能再用单点 A 直接算 c

**来源**：[[分光光度法-超级充实版（自学完整）]] §一~§四
**适用**：分析化学 / 分光光度法

## 背面（操作面）

**【操作步骤】**
1. 定量关系：**A = −lgT = κ·b·c**（κ 摩尔吸收系数 L·mol⁻¹·cm⁻¹，b 液层厚 cm，c mol/L）
2. 换算：T = 10^(−A)，A = −lgT（透光率常给百分数）
3. 最佳测量范围：**A = 0.2~0.8**（T = 15%~65%）；最小相对误差在 **A = 0.434**（T≈36.8%）
4. 高浓度偏离：曲线向 **c 轴**弯曲（负偏离）→ 分子相互作用/解离/缔合/非单色光所致
5. 标准曲线法：配系列标准液 → 测 A → 作 A–c 图 → 内插读未知浓度
6. 波长选 **λmax**（最大吸收）；控制显色剂、酸度、时间、温度

**【口诀】**
"A 是负 logT；0.2 到 0.8 最佳；高浓度向 c 弯"

**【典例速查】**
- T = 50.0% → A = −lg 0.500 = 0.301（落在最佳范围内 ✓）
- 待测液太浓（A > 0.8）→ 稀释后测，再乘稀释倍数

**【检查清单】**
- ☐ A–T 用对数换算，不是线性
- ☐ 偏离 Beer 时优先稀释 / 改波长，不硬算
- ☐ κ、b、c 单位配套（mol/L、cm、L·mol⁻¹·cm⁻¹）
