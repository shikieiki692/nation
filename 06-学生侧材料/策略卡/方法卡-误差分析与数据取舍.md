# 方法卡：误差三分法 + 离群值取舍（Q 检验）

## 正面（识别面）

**【一句话定位】**
评价一组数据好不好：先分误差来源，再决定可疑值去留。

**【适用信号】**
- ⭐ 判断某误差属于系统 / 随机 / 过失
- ⭐ 比较"准确度"与"精密度"（哪组数据更好）
- ⭐ n 次测量中某数据明显偏离，问是否应剔除

**【不适用陷阱】**
- ❌ Q 检验只用于剔除**少数**（1~2 个）离群值，不能连环剔
- ❌ 需严格小样本推断（t 检验、F 检验）时 Q 检验不够用

**适用**：分析化学 / 实验数据处理

## 背面（操作面）

**【操作步骤】**
1. 误差三分：系统（方法/仪器/试剂，可校正找来源）｜随机（不可避免，统计处理）｜过失（操作错误，直接剔除）
2. 准确度 = |x̄ − μ|，用绝对/相对误差描述；精密度用标准偏差 s、RSD 描述
3. 疑似离群值 → 算 Q = |x可疑 − x邻| / (xmax − xmin)
4. 查 Q 临界值表（按 n 与置信度 90%/95%）：Q计算 > Q表 → 舍弃
5. 舍弃后重算平均值与精密度

**【口诀】**
"过失直接扔，随机算偏差，系统找来源"

**【典例速查】**
数据 2.50、2.53、2.55、2.70，怀疑 2.70：
Q = |2.70−2.55| / (2.70−2.50) = 0.75；n=4 时 Q表(0.90)≈0.76 → 0.75 < 0.76，**不能舍**

**【检查清单】**
- ☐ Q 检验分母是极差 (xmax−xmin)，不是别的
- ☐ n 要与临界值表行严格对应
- ☐ 舍弃后样本量变小，报告均值/偏差用新数据
