# 方法卡：有效数字运算与修约

## 正面（识别面）

**【一句话定位】**
任何定量计算结果，先定有效位数，再按规则运算、报告。

**【适用信号】**
- ⭐ 计算题问"结果应保留几位有效数字"
- ⭐ 给一组带有效位数的测量值，求加减/乘除结果
- ⭐ 修约题（四舍六入五成双）

**【不适用陷阱】**
- ❌ 纯数学常数（π、系数 2、化学计量系数）不参与限位
- ❌ 不可分步修约：0.5749 → 只能一步得 0.57，不能先 0.575 再 0.58

**适用**：分析化学 / 一切定量计算

## 背面（操作面）

**【操作步骤】**
1. 数每位数的有效位数：非零都算；前导零不算；末位零算；科学计数法只看系数
2. 加减 → 结果小数点后位数 = 各项中位数最少者
3. 乘除 → 结果有效位数 = 各项中有效位数最少者
4. 对数/反对数（pH、pK）→ 有效位数只由小数部分决定
5. 修约：四舍六入五成双，一次到位

**【口诀】**
"加减看小数，乘除看位数，对数看尾数，修约五成双"

**【典例速查】**
- 0.5749 保留两位 → **0.57**（5 后还有 4，舍）
- 0.5750 保留两位 → **0.58**（5 后全 0，看前一位 7 为奇数 → 进）
- 0.5650 保留两位 → **0.56**（5 后全 0，前一位 6 为偶数 → 舍）

**【检查清单】**
- ☐ 是否一次修约到位（禁止分步）
- ☐ 5 后有无数字：有 → 直接进；无 → 看前一位奇偶（奇进偶舍）
- ☐ pH 的整数部分是数量级，不计入有效数字
