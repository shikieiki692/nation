# 方法卡：银量法三法选择（Mohr / Volhard / Fajans）

## 正面（识别面）

**【一句话定位】**
测 Cl⁻ / Br⁻ / I⁻ / Ag⁺ 时，按酸度与干扰选沉淀滴定法。

**【适用信号】**
- ⭐ 问"测某卤素离子选哪种银量法"
- ⭐ 问酸度条件（中性 or 强酸）、指示剂
- ⭐ 问返滴定沉淀转化误差

**【不适用陷阱】**
- ❌ Mohr 法**不能测 I⁻**（AgI 强烈吸附 CrO₄²⁻ 指示剂）
- ❌ Mohr 体系**禁铵盐**（NH₃ 络合 Ag⁺，破坏终点）
- ❌ Volhard 返滴定 Cl⁻ 会有沉淀转化误差，需防

## 背面（操作面）

**【操作步骤】**
1. 看待测物与干扰：
   - Cl⁻、无干扰 → **Mohr 法**：中性 **pH 6.5~10.0**，K₂CrO₄ 指示剂，直接滴定
   - Cl⁻ 有干扰（PO₄³⁻、有色离子等）→ **Volhard 返滴定**：强酸 **0.1~1 mol/L HNO₃**，铁铵矾指示剂
   - Br⁻ / I⁻ → **Volhard 返滴定**（先加过量 AgNO₃，再 SCN⁻ 回滴）
   - Ag⁺ → **Volhard 直接滴定**（强酸，Fe³⁺ 指示）
2. Volhard 返滴定 Cl⁻：先加过量 AgNO₃ → AgCl 沉淀 → 滤去或加硝基苯包裹 → SCN⁻ 回滴剩余 Ag⁺

**【口诀】**
"Mohr 中性直接滴，Volhard 强酸返滴"

**【典例速查】**
Volhard 返滴定 Cl⁻ 若**不防转化**：AgCl + SCN⁻ → AgSCN↓ 使 SCN⁻ 多耗 → 算得 Cl⁻ **偏低**

**【检查清单】**
- ☐ Mohr 酸度 6.5~10.0（偏酸 CrO₄²⁻ 变 Cr₂O₇²⁻ 失效；偏碱 Ag₂O 沉淀）
- ☐ Volhard 强酸环境，Fe³⁺ 才不水解
- ☐ 返滴定 Cl⁻ 记得防沉淀转化（过滤 / 硝基苯）
