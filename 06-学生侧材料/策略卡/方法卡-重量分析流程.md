# 方法卡：重量分析五步流程

## 正面（识别面）

**【一句话定位】**
从"沉淀→称量"的完整流程：选对沉淀类型，做对条件，算对因数。

**【适用信号】**
- ⭐ 问晶形沉淀 vs 无定形沉淀的沉淀条件
- ⭐ 问要不要陈化、洗涤几次、怎么干燥灼烧
- ⭐ 问沉淀形式 / 称量形式 / 换算因数 F

**【不适用陷阱】**
- ❌ 沉淀形式 ≠ 称量形式，两者别混（如 Fe³⁺ 沉为 Fe(OH)₃，灼烧称 Fe₂O₃）
- ❌ 无定形沉淀**不能陈化**（趁热过滤），晶形沉淀才陈化

**来源**：[[络合滴定与重量分析-超级充实版（自学完整）]] §五
**适用**：分析化学 / 重量分析

## 背面（操作面）

**【操作步骤】**
1. 选沉淀形式：溶解度小、纯净、易转化为称量形式
2. 沉淀条件：
   - **晶形沉淀**：稀溶液、加热、慢加沉淀剂、搅拌 → **陈化**（Ostwald 熟化，小晶溶大晶长，纯度高）
   - **无定形沉淀**：浓溶液、热、快加、加电解质凝聚 → **趁热过滤、不陈化**
3. 洗涤：少量多次（防止胶溶 / 溶解损失）
4. 干燥/灼烧 → 得**称量形式**
5. 换算因数 **F = (a·M待测) / (b·M称量形式)**，m待测 = m称量 × F

**【口诀】**
"晶形稀热慢搅陈；无定形浓热快不陈"

**【典例速查】**
测 Ba²⁺：BaSO₄ 沉淀（晶形）→ 陈化 → 洗涤 → 灼烧称 BaSO₄；
F = M(Ba) / M(BaSO₄)，m(Ba) = m(BaSO₄) × F

**【检查清单】**
- ☐ 晶形"稀热慢搅陈"，无定形"浓热快不陈"（分清楚）
- ☐ 换算因数中系数 a/b 按反应计量对齐
- ☐ 洗涤"少量多次"，不是一次大量
