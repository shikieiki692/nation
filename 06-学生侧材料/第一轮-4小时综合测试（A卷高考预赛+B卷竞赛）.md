# A卷 参考答案与详解

## 一、选择题

**1. C**　丁达尔效应是胶体的特性。①Fe(OH)₃胶体和⑤云、雾是胶体，有丁达尔效应；②水是纯液体，③蔗糖溶液和④FeCl₃溶液是溶液（粒子直径 <1 nm），无丁达尔效应。

**2. B**　A 错：Cu 不与稀硫酸反应（Cu 在 H 之后）。C 错：电荷不守恒，应为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag。D 错：H₂CO₃ 应分解为 H₂O + CO₂↑，应写为 CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑。

**3. A**　两个反应中 Al 均从 0 价 → +3 价，每 mol Al 均转移 3 mol 电子。相同质量 → 相同物质的量 → 转移电子数相同 → 生成 H₂ 相同。

**4. C**　两个 p 轨道可以形成 p-p σ 键（如 Cl₂ 中两个 3p 轨道沿键轴方向头碰头重叠），也可以形成 p-p π 键（如 O₂ 中 p 轨道肩并肩重叠）。

**5. B**　键长与稳定性密切相关：键长越短，原子轨道重叠程度越大，键能越大，化学键越稳定。

**6. C**　BF₃ 中 B 有 3 个价电子，与 3 个 F 形成 3 个 σ 键，无孤对电子，价层电子对数 = 3，sp² 杂化，平面三角形。NH₃：sp³（3σ+1孤）；CH₄：sp³（4σ）；H₂O：sp³（2σ+2孤）。

**7. D**　CO₂：C 无孤对，2σ，sp 杂化，直线形。SO₂：S 有 1 对孤电子，2σ+1孤 = 3 对，sp² 杂化，V 形。虽都是 AB₂ 型，但因孤电子对的存在，空间结构不同。

**8. C**　X 射线衍射是区分晶体和非晶体最可靠的方法。晶体能产生明锐的衍射斑点/环，非晶体只产生弥散的衍射图样。

**9. A**　生成液态水时多释放"水蒸气 → 液态水"的凝结热（气化热的逆过程），故反应①放热更多。

**10. B**　ΔH = 反应物键能 − 生成物键能 = [E(N≡N) + 3×436] − 6×391 = −92.4，故 E(N≡N) = −92.4 + 1038 = 945.6 kJ/mol。

**11. D**　自发性的判据是 ΔG = ΔH − TΔS，由 ΔH 和 ΔS 共同决定；放热、熵增都不是自发性的充分条件，自发反应也受温度等条件限制。

**12. B**　平衡时 v正(SO₂) = v逆(SO₃)；B 中 v正(SO₂) = 2v逆(SO₃)，即 v正 > v逆，反应仍正向进行。A、C 表示达到平衡；D 表示逆向进行。

**13. B**　CH₃COONa 为强电解质，完全电离，c(CH₃COO⁻) ≈ 0.1 mol/L 最大；A、C 中 CH₃COO⁻ 浓度小于 0.1（弱酸部分电离 / 水解消耗）；D 受同离子效应抑制。

**14. D**　0.1 mol/L NaOH 中 c(OH⁻) = 0.1 mol/L，pOH = 1，pH = 13。A 错：中性须看温度（25 ℃ 才以 pH = 7 为中性）。B 错：100 ℃ 时 Kw ≈ 10⁻¹²，中性 pH = 6，pH = 6 为中性。C 错：醋酸稀释时继续电离，pH 与盐酸不同。

## 二、非选择题

**15.**（必修一，14 分）
**（1）**①CO₂ 被 NaOH 吸收，罐内气压降低，大气压将罐压瘪。离子方程式：CO₂ + 2OH⁻ = CO₃²⁻ + H₂O。②Al₂O₃ 膜先与 NaOH 反应，然后 Al 再与 NaOH 反应放出 H₂，罐内气压回升使罐鼓起。离子方程式：2Al + 2OH⁻ + 2H₂O = 2AlO₂⁻ + 3H₂↑。
**（2）**Fe³⁺ 先与 Fe 反应：2Fe³⁺ + Fe = 3Fe²⁺；Cu²⁺ 再与 Fe 反应：Cu²⁺ + Fe = Fe²⁺ + Cu。剩余固体可被磁铁吸引 → 含 Fe（铁粉过量或 Fe 生成）。溶液中较多的阳离子是 **Fe²⁺**（Fe³⁺ 和 Cu²⁺ 已被完全还原）。
**（3）**NaOH：离子键（Na⁺ 与 OH⁻）+ 共价键（O—H）；H₂O₂：只含共价键（O—H 和 O—O）；NH₄Cl：离子键（NH₄⁺ 与 Cl⁻）+ 共价键 / 配位键（NH₄⁺ 内部）。

**16.**（选修一，14 分）
**（1）**目标反应 = ① − ②：ΔH = ΔH₁ − ΔH₂ = 255.7 − 131.5 = **+124.2 kJ/mol**。
**（2）**ⅰ. 设 H₂ 为 x mol，C₃H₈ 为 (5 − x) mol。由 285.8x + 2219.9(5 − x) = 6264.2，解得 x = 2.5 mol，故 n(H₂) : n(C₃H₈) = 2.5 : 2.5 = **1 : 1**，同温同压体积比 = 1 : 1。ⅱ. C₃H₈(g) + 5O₂(g) = 3CO₂(g) + 4H₂O(l) 的 ΔH = −2219.9；由 H₂O(l) → H₂O(g) 需吸热 4×44.0 = 176 kJ，故 C₃H₈(g) + 5O₂(g) = 3CO₂(g) + 4H₂O(g)，ΔH = −2219.9 + 176 = **−2043.9 kJ/mol**。
**（3）**CO + H₂O ⇌ CO₂ + H₂，初 1 / 1 / 0 / 0，设转化 x，平衡 (1−x) / (1−x) / x / x（V = 1 L）。K = x² / (1−x)² = 1，x = 0.5。c(CO) = c(H₂O) = 0.5 mol/L，c(CO₂) = c(H₂) = 0.5 mol/L；CO 转化率 = 0.5 / 1 = **50%**。

**17.**（选修一，16 分）
**（1）**pH = 2.88，c(H⁺) = 10^(−2.88) = 1.32×10⁻³ mol/L。CH₃COOH ⇌ H⁺ + CH₃COO⁻，Kₐ = c(H⁺)·c(CH₃COO⁻) / c(CH₃COOH) = (1.32×10⁻³)² / (0.1 − 1.32×10⁻³) ≈ **1.76×10⁻⁵**。
**（2）**沉淀时所需 c(Ag⁺) = Kₛₚ / c(阴离子)。设 c(Cl⁻) = c(I⁻)，则 c(Ag⁺)(AgCl) = 1.8×10⁻¹⁰ / c(Cl⁻)，c(Ag⁺)(AgI) = 8.5×10⁻¹⁷ / c(I⁻)。因 1.8×10⁻¹⁰ ≫ 8.5×10⁻¹⁷，生成 AgI 所需的 Ag⁺ 浓度小得多，故 **AgI 先生成**。
**（3）**负极（Zn）：Zn − 2e⁻ + 2OH⁻ = Zn(OH)₂；正极（MnO₂）：2MnO₂ + 2H₂O + 2e⁻ = 2MnOOH + 2OH⁻。总反应：Zn + 2MnO₂ + 2H₂O = Zn(OH)₂ + 2MnOOH。原理：负极 Zn 失电子被氧化，电子经外电路流向正极，正极 MnO₂ 得电子被还原，OH⁻ 在两极间迁移形成闭合回路。

**18.**（选修二，14 分）
**（1）**①Na 的 I₁ 对应失去最外层 3s¹ 电子，I₂ 对应失去内层 2p⁶ 电子，内层电子受核引力大得多，故 I₂ 远大于 I₁。②Mg 的 I₁、I₂ 分别失去两个 3s 电子，I₃ 需失去内层（2p⁶）电子，故 I₃ 突增。③Al 失 3 个电子后为 [Ne] 构型（3s²3p¹ 的 3 个外层电子全部失去），I₃ 对应仍是外层电子；而 Mg 的 I₃ 已涉及内层电子。故 Al 的 I₃ = 2745 远小于 Mg 的 I₃ = 7733。
**（2）**H₂O 分子间存在氢键（O—H···O），而 H₂S 分子间只有范德华力。氢键强度（5~30 kJ/mol）远大于范德华力（0.5~5 kJ/mol），需要更多能量克服分子间作用力，故 H₂O 沸点远高于 H₂S。H₂S 虽相对分子质量更大（色散力更大），但色散力的增加远不足以弥补缺少氢键的影响。
**（3）**面心立方：8×(1/8) + 6×(1/2) = 1 + 3 = **4 个**；体心立方：8×(1/8) + 1×1 = 1 + 1 = **2 个**。

**22.**（题155）：

| | Co(NH₃)₆³⁺ | Fe(H₂O)₆³⁺ |
|:---|:---:|:---:|
| Δ₀ / cm⁻¹ | 23000 | 13700 |
| P / cm⁻¹ | 22000 | 30000 |

Co(NH₃)₆³⁺ 中 Δ₀ > P，为低自旋态，6 个 d 电子全部填入 t₂g 轨道。Fe(H₂O)₆³⁺ 中 Δ₀ < P，为高自旋态，5 个 d 电子按洪特规则分布。

**23.**（题203）：Bragg 方程两种表达形式为
2d(hkl)·sinθn = nλ　与　2dhkl·sinθ = λ
式中 (hkl) 为点阵面指标，3 个数互质；hkl 为衍射指标，3 个数不要求互质，可有公因子 n。d(hkl) 为点阵面间距；dhkl 为衍射面间距，与公因子 n 有关：dhkl = d(hkl)/n。按前式，对同一族点阵面 (hkl) 可有 n 个不同级别衍射，相邻两面波程差可为 1λ、2λ、3λ、…、nλ，相应衍射角为 θ₁、θ₂、θ₃、…、θn。

**24.**（16 分）（28 届初赛 3-1）
总价电子数 = 8×5 = 40；达八偶体所需总电子数 = 8×8 = 64；成键数 = (64 − 40)/2 = 12；孤对电子对数 = 40/2 − 12 = 8 对。N₈ 为链状结构，分子内有 7 根 σ 键和 5 根 π 键。合理安排 π 键位置、绘出孤对电子并标形式电荷（形式电荷 = 价电子数 − 成键与未成键电子总数），得 Lewis 结构：
:N≡N−N=N−N−N−N−N:（链上形式电荷（左→右）为 +1、0、0、0、0、0、−1、0 的一种合理排布）
（1）（8 分）40 个价电子、12 个成键电子对、链状含 7 个 σ 键 + 5 个 π 键；Lewis 结构含叁键、双键、单键并正确标出形式电荷。
（2）（8 分）端位以外的 N 原子采用 **sp、sp²、sp³** 三种杂化轨道。

**25.**（16 分）（题156）
水是弱场配位体，故 Mn(H₂O)₆³⁺ 为高自旋离子（P = 28000 cm⁻¹，Δ₀ = 21000 cm⁻¹），d 电子排布为 (t₂g)³(eg*)¹，配位场稳定化能 = 0.6Δ₀。处于 eg* 轨道上的电子易失去，失去后配位场稳定化能增大为 1.2Δ₀，这就是 Mn(H₂O)₆³⁺ 不稳定的原因（且易发生 Jahn-Teller 畸变）。

## 三、化学原理综合

**27.**（14 分）（35 届初赛 2-1）
①（7 分）反应（5）= 反应（1）+ 反应（2）：
ΔH₅θ = ΔH₁θ + ΔH₂θ = (−285) + (−119) = **−404 kJ·mol⁻¹**。
②（7 分）反应（6）= 反应（2）+ ½反应（3）+ ½反应（4）：
ΔH₆θ = ΔH₂θ + ½ΔH₃θ + ½ΔH₄θ = (−119) + 249 + (−23) = **+107 kJ·mol⁻¹**。
（验证：½反应(4) 为 KO₃ → KO₂ + ½O₂，ΔH = −23；½反应(3) 为 ½O₂ → O，ΔH = +249；三者相加消去 KO₂、KO₃ 得 O₃ → O₂ + O。）

**28.**（16 分）（Ch10-21）
**（1）**氧化半反应（负极）：Fe²⁺ → Fe³⁺ + e⁻；还原半反应（正极）：Ag⁺ + e⁻ → Ag。
电池符号：Pt∣Fe²⁺(aq), Fe³⁺(aq)∥Ag⁺(aq)∣Ag(s)
**（2）**Eθ池 = Eθ(正极) − Eθ(负极) = Eθ(Ag⁺/Ag) − Eθ(Fe³⁺/Fe²⁺) = 0.799 − 0.771 = **0.028 V**。
**（3）**ΔrGθ = −nFEθ池 = −1 × 96485 × 0.028 = −2702 J·mol⁻¹ ≈ **−2.70 kJ·mol⁻¹**。
**（4）**由 ΔrGθ = −RT·lnKθ：lnKθ = nFEθ池/(RT) = (1 × 96485 × 0.028)/(8.314 × 298.15) = 2702/2479 ≈ 1.090，Kθ = e^(1.090) ≈ **2.97**。
（要点：设计原电池的关键是把自发反应拆成氧化/还原两半反应；Eθ 大者作正极发生还原，Eθ 小者作负极发生氧化；Eθ池 > 0，反应自发进行。）
