## 标准结构序列（v5.3）

v5.3 模板的正文结构分为 **学生可见区** 和 **教师信息区（HTML 注释）**：

### 教师信息区（HTML 注释，不进 PDF）

| 内容 | 说明 |
|:---|:---|
| 适用轮次 | 第一轮（初学）→ 第二轮（深化参照） |
| 本讲定位 | 这讲在课程链中的角色 |
| 上节衔接 / 下节衔接 | 显式链接上下讲 |
| 深度边界 | 讲到哪、不讲到哪 |
| 主框架/辅助教材 | 来源说明 |
| 配图规划表 | 每图的候选来源和落地文件名 |

### 学生可见区（正文）

| 序号 | 段名 | 功能 |
|:---:|:---|:---|
| 0 | frontmatter | 元数据（含 sources/insights/problems/exercise_count/exercise_levels/stage/last_audit） |
| 1 | 元信息块 | 对应专题·备课大纲·前置要求·考纲覆盖（HTML 注释教师区，见上） |
| 2 | 使用说明 | 主线导航表 + 深度分层说明（📝🌟🔒）+ 📋轮次划分表（跨轮讲义必填） |
| 3 | 学习目标 | 3~12 条 ✅ 可测量目标 |
| 4 | §一~§N 内容正文 | 核心教学内容（动机→概念→规律→应用递进） |
| 5 | 典型例题 | 三件套：题号链接 + 题干全文 + 解析 |
| 6 | 本讲速查 | 核心结论/公式/判断框架汇总 |
| 7 | 练习题 | 基础巩固 + 竞赛入门 + 真题挑战（现役 5+5+5=15，见 [[11-模板/模板-习题三级分类]]） |
| 8 | 参考答案与提示 | 练习题统一答案节 |
| 9 | 本讲小结 | 主线收束：知识结构表或要点 |
| 10 | 附录 | 易错清单 + 延伸阅读 + 数据表（可选） |
