# 讲义学习目标·考纲锚点规范 v1.0（教学价值战 B 批，2026-09-19）

> 上位规范：`11-模板/讲义练习区格式规范.md`（练习区）。本规范只管「学习目标」节。
> 样板：`04-课件/学生讲义/6-有机化学/有机人名反应系统归类-超级充实版（自学完整）.md`

## 一、锚点编码唯一注册表

- 唯一合法来源：`02-考纲条目/` 各条目页 frontmatter 的 `syllabus_code` 与 `title`。
- 基础要求：`§01`~`§56` + `§57 化学动力学`；决赛要求：`决赛01`~`决赛15`。
- **禁自造条目名**（如「缩合反应」「金属有机与偶联」——2026-09-19 样板自检时发现并修正）。
- 引用格式固定为 `§<码> <注册表title去编号前缀>`，如 `§46 羰基α位反应`、`决赛03 配合物深化`。
  - title 形如 `39-重排反应`，展示名取编号后部分。
- 一份讲义锚点 1~5 条为宜；必须与本讲正文真实覆盖匹配，宁少勿滥。

## 二、节名与位置

- 节名统一 `## 学习目标`（旧变体 `## 学习目标（可测量）` 归一为前者）。
- 节结构三件套：锚点行 → 对照表 → `---` 分隔线。

## 三、节内格式

```markdown
## 学习目标

> 对齐考纲：§<码> <名> · §<码> <名>（按码升序）

| 考纲条目 | 学完本讲你应能 |
|:---|:---|
| §<码> <名> | <可测能力句，吸收原目标文本> |
| §<码> <名> · <子主题> | <同一码拆多行时用「 · 子主题」> |

---
```

- 左格必须以 `§码` / `决赛码` 开头，名称与注册表逐字一致；子主题可选。
- 右格为可测能力（「能…」句式优先），内容必须吸收原学习目标文本，**禁止凭空新造能力项**。

## 四、转换铁律（脚本强制）

1. **零损失断言**：原节内每一条目标行（规范化去标记后）的文本必须作为子串出现在新节内。
2. **码名一致**：`§` 后码与名称组合必须命中注册表（脚本校验）。
3. **行尾保持**：读写一律 `open(newline="")`，保持原文件 CRLF/LF。
4. 节标题行、锚点行、表头行格式固定（脚本校验）。

## 五、豁免类（不要求锚点化，登记即可）

| 类别 | 判据 | 例 |
|---|---|---|
| 索引/README | basename 以 README 开头或 FM type ∈ {索引, 说明} | 学生讲义 README.md |
| 速查卡/附录 | basename 含「速查」「附录」且无教学目标语义 | 数学工具-附录-数学符号速查卡 |
| 真题/小问总集 | FM title 含「真题小问总集」「真题模拟拆解」或 type=题目集类 | 分子轨道式相关真题小问总集 |
| 数学工具讲次 | `serve_rounds` 非空且 module=_数学工具 的第 1~7 讲（考纲无数学条目，禁伪锚点） | 数学工具-第1讲~第7讲 |
| 导航合集 | 全文为课程/文件导航、无本讲自身教学内容 | 结构化学专题课-学生用合集（判定后登记） |

## 七、闸门口径（validate_handout.py 扩展项）

- ERROR：`## 学习目标` 节存在但锚点行/表头缺失；`§` 码或名不命中注册表；表行左格格式非法。
- WARNING：非豁免讲义缺「学习目标」节（登记类逐项核销）。
- 豁免类不检查。
