# 讲义语言规范

> **定位**：管「语言本身」——重复控制、提示体系形态、用词、句式与段落、编校差错、术语一致性、断言纪律。管「结构/符号/元数据」的既有规范（SOP、v5.3 模板、MD 通用规范）不因本文件改变权威归属。
> **适用**：`04-课件/学生讲义/` 全体现役讲义（85 份）。改造批次按本文件逐条判定；新写讲义在 SOP 验收时同检。
> **依据**：教材编写通则（概念严格定义且全篇含义不变；新概念必须解释定义；术语全篇统一——「即使轻微重复也优于同义词混用」）；CY/T 266—2023《图书编校质量差错判定和计算方法》（语法性差错、科技名词差错、量与单位、标点与数字用法的差错分类）；GB/T 15834—2011（标点，含连接号三态）、GB/T 15835—2011（数字用法）、GB 3100～3102（量和单位）、《中国高等学校自然科学学报编排规范（修订版）》（三线表／图序图题／反应式转行／量与单位）、中国化学会《无机化学命名原则》《有机化学命名原则》与 IUPAC 规则、IUPAC/ISO 80000 正斜体约定、全国科学技术名词审定委员会审定名词；教学写作典范（费曼讲义：概念先于形式化、类比紧扣物理由来、坦承不确定；Clayden 机理叙述句式；人教版「把……叫做/称为」定义句式）；国际风格指南借鉴（Microsoft/Google 词表机制、主动语态与句长控制；Wikipedia MOS 措辞纪律的可验证性精神）。

## 一、重复控制（主病条款）

**1.1 命题单元与「同一结论」判定**
一个结论＝「命题主体＋判定条件（或数值/方向）」的完整陈述。判定同一结论：命题主体相同（同义词归一后）且谓词结论等价（同向、同数量级、同条件域）。**措辞不同不算不同结论。**

**1.2 唯一权威表述**
每个核心结论在**正文完整推导恰好一次**，该处为唯一权威表述。其余位置只允许三种形态：速查表公式行、答案节「（理由见 §x.x）」式回链、交叉引用 wikilink。

**1.3 速查表纪律**
每格只允许：公式行、定性排序（如 3°>2°>1°）、§号回链。**禁止**理由句、「因为/所以」、推导片段、口诀全文（口诀名可入）。

**1.4 答案纪律**
练习答案只回答本题：该题条件下的具体判定＋一步关键理由。通用结论重讲视为违规，改回链。

**1.5 提示块转述清除**
`> [!tip]`/`> [!warning]` 与伪 callout 引用块内，出现正文已有结论的转述（未新增信息）一律删除；确需强调的，在正文权威表述处就地加粗关键词，不另开提示块。

## 二、提示体系归一（三轨 → 一轨＋正文）

**2.1 废除伪 callout**
`> **标题**：` 独立引用块不再允许。逐个按三分法处置：
- (a) 内容为方法论/易错点且正文无此结论 → 升格为 `> [!tip]` 或 `> [!warning]`；
- (b) 内容为正文结论的强调复述 → 删除；
- (c) 内容属正文逻辑（承接句、推导步骤、「这说明……」）→ 去引用块降为正文段落。
整段推导（含公式、表格）塞入引用块视为主次颠倒，必须降回正文。

**2.1b 降正文的两种标题头策略（按内容特征选）**
- **strip（剥头）**：标题头为**空泛引导词**（「关键区别」「要点」「理解关键」「重要提醒」等）时，标题头无信息量，剥去后正文自然衔接（原子结构试点模式）；
- **keep_title（留头）**：标题头为**具体术语或独立命题**（「三中心四电子键（3c-4e）」「Jahn-Teller 效应」「钙钛矿容忍因子」「近年真题」等）时，标题头本身是主题句，保留加粗头仅剥引用形态（第一轮复习模式）——信息零损失的主次归位。
- 判据一句话：**删掉标题头后段落是否仍能一眼看出在讲什么**——能则 strip，不能则 keep_title。

**2.1c 形态变体人工扫描清单（机检正则的已知盲区）**
以下形态**机检不报、改造时必须人工扫**：
- 标题带括号插语：`> **配位化合物**（coordination compound）：`（冒号前有括号）；
- 无冒号标题：`> **配位键与普通共价键**的差别…`；
- 行尾缀字块：`$$…$$ 行尾缀中文`（干扰状态机的其他形态已修复，仍须抽验）；
- callout 内部加粗引导行（`[!tip]` 块内的 `> **抓手**：`）——机检已豁免，但内容若为正文复述仍应精简。
扫描动作：改造前对全文 `^>` 行做一次目视过滤（约每份 30~80 行，成本可控）。

**2.1d 考情情报行**：「近年真题」「考纲覆盖」等考试指向行按 keep_title 保留（对学生有信息量），不视为装饰性脚手架。

**2.2 废除 `⚠` 加粗前缀**
并入 `[!warning]`，或改为正文「注意：」引导句。图注（`*图 N …*`）不受此条约束。

**2.3 密度上限**
正式 callout（tip/warning/info/note）单讲总数 ≤ ⌈正文行数/100⌉ 且 ≤12 个；任意连续 200 行 ≤3 个。超限优先合并同类，其次删转述类。

**2.4 行内伪标签禁令（v1.3 新增）**
正文、口诀行、表格行内**禁止自创加粗标签词**——`**安全边界**：`、`**打破中学定式**：`、`**口径注**：`、`**类比**：`、`**注意**：`、`**结论**：`等未在 callout 类型白名单（tip/warning/note/info）与模板固定栏目（口诀/思路/解答/反思）内登记的标签，一律不允许以「`**标签**：内容`」形态出现。判据：**该标签是否自成一条排版惯例**——不是则违规。
处置三分法：
- 信息性内容（安全、口径、辨析）→ 去标签改写为正文自然句，承接上下文；
- 安全信息 → 按 §14.1 写法并入正文（危害途径＋防护/处置成对给出），不单挂标签；
- 纯强调/过渡标签（「打破中学定式」「注意」）→ 删除标签，内容有信息量则保留为正文句。
改造动作用 grep 基线：`grep -n '\*\*[^*]\{2,10\}\*\*：' <file>`，命中逐条人工裁决。

## 四、正面表述规范

**4.1 结论句式**：规律性结论用「条件域＋判定」（「当/在……时，……」）。只给结论不给条件域视为不完整（条件与原因至少具其一；速查表除外）。

**4.2 首次定义句式**：术语首次出现给「标准名（又称别名）＋一句可操作定义」，对齐「××叫做××」（人教版）与「称为××（又称××）」（周公度）句式；此后只用标准名，不再重复定义。**同义词全篇只选一个**。规范名以全国科技名词委审定名词为准；与教材译名冲突时，讲义内自选其一并全篇统一（见 §八）。

**4.3 段落下限**：一个段落/引用块 ≥2 个完整句或 1 个完整推导步骤；单句孤立成块视为碎片段，并入相邻段（图注、公式行、表行除外）。推导链中「另一方面，」「即：」不得独立成行。

**4.4 语气**：面向学生的陈述句；允许设问引入（每节 ≤1 处）；禁用反问句做结论、禁用感叹号连用；标题不加情绪修辞。

**4.5 跨讲义详略分级**：同一核心概念在多份讲义出现时，按讲义类型定详略——**新授讲义给完整推导与「为什么」**（权威表述所在地）；**复习讲义用一行推理回勾**（如「由重心守恒 2x=3y 联立解出」，不重复完整推导）；**速查表只留公式行**。跨文件详略分歧不是重复违规，但**口径必须一致**（数值、符号、结论方向），后改的向先改的对齐。

## 五、口诀与类比

**5.1 功能性口诀**：保留，但首次出现处必须紧跟一句严谨对齐句（口诀 → 判据的翻译）；同屏口诀与等价公式/正文双编码视为重复，删其一。

**5.2 设计性类比**（熵税、裸露等）：保留，登记白名单；类比只出现一次、紧跟「严格地说……」的严格表述；不进速查表。

**5.3 口诀唯一性**：同一口诀全文逐字出现 ≤1 次；速查表可收口诀名不收全文。**口诀韵文内的用词豁免负面词表**（韵文改词破坏节奏），但豁免须登记。

**5.4 生活类比禁令（v1.3 新增）**
禁止生活化类比——用亲属、日常物品、社会角色作比（如「孩子不像父母像舅舅」「独生子/双胞胎」「叛变」）。竞赛讲义的类比只允许 §5.2 设计性类比一档，且须**同时满足**：① 结构同构（类比双方的对应关系可逐点映射到化学机制，不是氛围相似）；② 增量信息（类比传达了机制本身没有直接给出的视角）；③ 紧跟「严格地说……」式严格表述；④ 单份讲义 ≤2 处，入 §3.3 白名单登记。不满足任一条即删除，改严格表述。**检验：删掉类比后正文是否损失信息——不损失就删。**

## 六、段落与结构

**6.1 收尾节归一**：每讲收尾固定「本讲速查」（公式行汇总）＋「本讲小结」（主线收束，v5.3 唯一强制收尾节）；「本节总结·速查」「核心速查卡」「方法总结」等变体名废弃。**双轨改造件一律补齐缺失的「本讲小结」**，质量三要求：① 网络化主线概括（各节关系与推断链），不是逐节流水账；② 与本讲速查呼应但不重复其内容；③ 首选从 frontmatter `insights` 字段展开（作者意图已在，展开即可）。**附录/速查卡性质文件豁免小结**（其本身就是速查层，非「讲」）。

**6.1b 例题因果链自查（每件改造的固定工序）**：逐题问一遍「**结论是否由所述原因必然导出**」——数值正确 ≠ 论证成立。已知案例：配位例 14.4(2)「空间位阻影响螯合」（真因是配位数计数超限）。发现含糊论证径改＋校勘注；无法确证时标存疑记录，不猜。

**6.1c 产物名归一**：H1 含 LaTeX/特殊字符的讲义（如 `d[A]/dt`、`$S=k-ln W$`），docx 导出会按 H1 全名生成「残片名」文件——**每次重出后核对产物目录，统一改为短名**，防止残片名与历史短名并存导致学生误用旧版。

**6.1d 全册型讲义的收尾**：多讲成册系列（如数学工具 8 份）末讲小结可承担**全册收束**（七讲主线闭环）；附录/速查卡不设小结。

**6.2 章节内聚**：每节只服务一个主题句；跨主题内容拆节或移附录；不设「题外话」式引用块。

**6.3 例题解析三层**：「思路 → 关键步骤 → 结论」，层间不互重复；结论不重讲正文通用规律（回链）。

**6.4 练习题来源纪律（v1.3 新增，用户 2026-09-24 拍板）**
1. **题目一律取自题库**（`04-题库/`）：普通教材题（普化原理等教材习题卡）＋一般竞赛教材题（上海中学竞赛课程等），**禁止讲义内自编题**。每题标注来源（「普化原理 15.2」「题库卡 题-元s-01」），并回链接题库卡。
2. **禁止难度分层小标题**：「基础巩固／竞赛入门／真题挑战」等分层子节废除；练习题连续编号、平铺为一节（允许按来源分组标注，不允许按难度分组）。
3. **题面必须完整**：内嵌题面须达到「学生脱离链接即可独立作答」的完整度；**禁止一句话概括＋「完整题面见……」式半截题**。完整题面超长的真题（>60 行）不入练习题节，仅在「延伸阅读」保留回链。
4. **答案节同步重写**：按 §1.4 答案纪律（只答本题＋一步关键理由，通用结论回链 §x.x），并标来源卡回链。
5. 题库对应讲次无合适题时，宁缺毋滥（少题、回链专题页），不自编凑数。

## 七、编校差错类（对接 CY/T 266—2023）

**7.1 语法性差错禁则**（CY/T 266 条目 1-11）：正文不得出现——
- **句式杂糅**：同一句内两套句式套叠（「原因是……造成的」「目的是……为目的」「围绕……为中心」「关键在于……的问题」）；
- **前后矛盾**：同节内数值、符号方向、条件表述不一致；
- **表意不明**：指代词（「它」「这个」）跨越句界仍不明确所指；
- **歧义、不合事理、语句不通**。
矛盾/歧义/表意不明属语义级判定，机检初筛＋人工复核。

**7.2 科技名词规范**（CY/T 266 条目 1-7）：化学术语采用全国科技名词委审定名；异形词（旧译、俗写、音译残留）按 §八词表替换。

**7.3 量与单位**（GB 3100～3102；《中国高等学校自然科学学报编排规范》6.9.5）：
- **正斜体**：量符号（单个拉丁/希腊字母）一律**斜体**（$m$、$V$、$E^\theta$、$c$、$p$、$T$）；**正体**者——单位符号（kg、kPa、mol·L⁻¹）、SI 词头（k、μ、M）、**化学元素符号**（H₂O、NaCl）、数学常数（e、π）、函数名与运算符（sin、lg、exp、d、Δ）；**pH 为正体**（GB 特例）。
- **下标**：表示物理量/变量的斜体（$K_p$、$c_B$、$E_{cell}$）；说明性或固定词的正体（$N_A$、$c_\mathrm{ox}$、$E^\theta$）。
- **数值与单位**：二者间留 1 个半角空格（101.3 kPa、0.1 mol·L⁻¹）。**温度为例外——本库统一采用教材惯例的连写「1907°C」**（不写「摄氏度」、不写 ℃；ISO 80000 允许连写与空一格两式，本库从教材惯例）。实测库内连写 400 处／42 份 vs 空一格 35 处／12 份，故取连写为规范形。**同一篇内不得混排**「1907°C」与「1907 °C」——发现混排即统一为连写。
- **组合单位**：用「·」或负指数幂，不用多重斜线（kJ·mol⁻¹ / kJ/mol ✓；J/mmol ✗——分母一般不加词头）；图表标目采用「**量/单位**」形式（$c$/(mol·L⁻¹)、$p$/kPa）。
- **单位不得修饰**：不加缩写点、角标、复数，不在组合单位内插入元素符号等说明性记号。
- **禁用缩写单位**：ppm、ppb、ppt、rpm 等不得作单位使用（改 10⁻⁶、体积分数、r/min）。
- **词头**：不得独立使用（μm 不写 μ），不得重叠（pF 不写 μμF）。
- 时间单位用 s / min / h / d；同一量纲序列内单位不中英文混用。

**7.4 差错率意识**：编校类条款以「机检清零＋人工抽检」为准（对齐图书编校差错率 ≤1/10000 的行业线并适配讲义文体），不设逐条零差错机械达标。

**7.5 连接号三态**（GB/T 15834—2011 4.13；化学讲义高频差错点）
三种连接号**形状与用途不可互替**：

| 形式 | 名称 | 用途 | 例 |
|:--|:--|:--|:--|
| `-` | 短横线（半字） | ① 化合物名称中的位次/构型标记 ② 表格插图编号 ③ 号码、日期 ④ 复合名词 ⑤ 产品型号 | 3-戊酮、`trans`-丁-2-烯、`N,N`-二甲基苯胺；表 2-8；2011-02-15；吐鲁番-哈密盆地 |
| `—` | 一字线 | ① 相关项目（时间/地域）起止 ② 标准代号年份前 ③ **化学式中单键** | 沈括（1031—1095）；GB/T 15834—2011；—O—O— |
| `～` | 浪纹线 | **数值范围**（本库统一用浪纹线；数值范围属于数值起止，故用浪纹线，而时间/地域起止用一字线——见本表上一行） | 10～20 mL、25～30 g、第五～八课 |

禁则：数值范围**不得用短横线**（10-20 mL ✗）；单键不得用短横线或减号代替（`-O-O-` ✗）；同一篇内范围线形式须统一。

**7.6 数字用法**（GB/T 15835—2011）
- 计量与计数一律用阿拉伯数字；**年份不简写**（1997 年不写 97 年）。
- 多位阿拉伯数字不得拆开转行；数值范围两端完整写出（10～20，不写 10～0）。
- 带「约」「大约」时只写一次（约 10～20 ✓；约 10～约 20 ✗）。
- 百分数范围两端都带 %（10%～20%）；偏差写作（25±1）°C（温度连写口径见 §7.3，不写 25 °C ± 1 °C）。
- 小数点与千位：讲义正文**千位不加空格**（适配中学教材习惯），但同一篇内不得时而分节时而不分节。
- 序数词、题号、章节号、图序表序用阿拉伯数字；「第～课」类用汉字数字时保持全篇一致。

**7.7 标点符号**（GB/T 15834—2011；补挂载——原散见样本例句，无正文章节，导致手册判例误引为「§7.3 标点」）
- **引号**：正文引用与着重，全篇统一用「」；**不得混用**弯引号“”与「」（配位件实测 78 处混用已统一）。行内需要第二层引号时用『』，不叠用同形引号。
- **括号**：尽量不套用同一形式的括号；必须套用时改用不同形式配合（GB/T 15834 4.9.3.6）。数学/化学式中允许括号嵌套。
- **顿号与逗号**：按并列层级使用，不同层次的停顿不用顿号（原 §7.3 末条，本条为完整挂载）。
- **省略号**用「……」（六点），不用三点「...」。
- **书名号**：书名、教材名、试卷名用《》；篇/章/卷名用间隔号分隔（《淮南子·本经训》）。
- **装饰性标点清除**：独立成行的「——」装饰线、连续感叹号、无意义破折号一律删除（§6.2 章节内聚）。
- 图注 `*图 N 说明*` 本身的斜体形态属模板约定，**其中的标点仍按本条执行**。

## 十一、化学式与反应式编排（新增）

**11.1 元素与化合物符号**
- 元素符号一律正体，大小写严格（Co 钴 vs CO 一氧化碳；NO 一氧化氮 vs No 锘）；上下标位置正确（$m/z$、$^{13}$C、$\mathrm{SO_4^{2-}}$）。
- 行文中分子式写成一行（CH₃CH(OH)CO₂H），不断行；结构式中的**键号与数学符号严格区分**：单键「—」（一字线）vs 减号/位次「-」（短横线），双键「＝」vs 等号「=」。
- 取代基缩写用 Me / Et / Pr / Bu / Ph / Ac / Ar（**不用 f 表示苯基**）；不同取代基用 R¹、R²（不用 RⅠ、RⅡ）。
- 电子构型用正体并加括号：$(1s)^2(2s)^2(2p)^4$。

**11.2 反应式**
- **箭头语义不得混用**：`→` 主反应/不可逆，`⇌` 可逆平衡，`↔` 共振式，`⇒` 逻辑推导；共振与平衡不得互替。
- **反应条件标于箭头上下**（$\xrightarrow{\text{浓 } \mathrm{H_2SO_4},\ \triangle}$），不写在式子中间作正文。
- 物态标注统一：(aq)/(s)/(l)/(g)；沉淀 `↓`、气体 `↑` 紧随物种，不标在箭头外。
- **转行规则**：必须在 `→`、`=`、`+` 之后断开，下一行开头**不重复**该符号。
- **配平与电荷守恒自查**（改造固定工序）：逐式核 ① 原子数 ② 电荷代数和 ③ 电子得失数；三者任一不符即为硬伤，径改＋校勘注。
- 热化学：ΔH 须带物态与计量对应关系；不写「放热多少 kJ」而漏正负号。

**11.3 命名**（中国化学会《无机化学命名原则》《有机化学命名原则》，未规定者从 IUPAC/CA）
- 配合物：配体列序按**先阴离子后中性**、同类按配位原子元素符号英文字母序；倍数词头用 di/tri/tetra（复杂配体用 bis/tris/tetrakis）。
- 含氧酸盐按中心原子氧化态命名（硫酸根 vs 亚硫酸根；高/正/亚/次）。
- 有机主链与官能团优先序从命名原则；惯用名（如甘汞、朱砂、胆矾）首次出现给「惯用名（系统名）」，此后只用其一。

## 十二、图表编排（新增，对齐学报编排规范）

**12.1 表（三线表）**
- Markdown pipe table 天然无竖线，**导出即近似三线表**，是本库有利形态；**不得为画竖线改回 HTML 表格**。
- **表题不得缺**：表格须有可识别的表题，三种合规形态——① 独立表题行（`**表 1 卤化银的 Ksp 与溶解行为**`）；② **紧邻上方的节/子节标题直辖该节唯一表格**（此时节标题即表题，不另起）；③ 速查节内多表并列时，每表须有独立表题或加粗引导行。判据：**读者能否不读上下文就知道这张表在列什么**——不能则补。表序按全文连续编号（仅 1 个表时不强制编号）。
- 全表同单位时把单位标在表题后或右上角，不写「单位」二字；各栏单位不同时标在栏目名后（`$c$/(mol·L⁻¹)`）。
- 相邻栏/上下栏内容相同须**重复写出**，不用「同左」「同上」「″」代替。
- 表内术语、符号、单位与正文一致；表随文排（先见正文提及，后见表）。

**12.2 图**
- 图序图题置于图**下方**（本库 `*图 N 说明*` 形态即符合）；图序与图题间空 1 字距；全文连续编号。
- **图须被正文提及**：正文中至少一处「见图 N／如图 N 所示」交叉引用——纯罗列不引用的图不符合编排规范（**图注重编前必先 grep 交叉引用，为 0 时须补写引用句，不得只顾重编号**）。
- 图内术语、符号、单位与表及正文一致；函数图标目用「量/单位」。
- 图注须自明（不依赖正文也能读懂）；错贴图、跨题污染图宁标「待补」不将就（沿用既有判据）。

**12.3 图文一致性**：同一数据不得既用图又用大表重复呈现；图表与正文数值冲突时以**可复算推导**为准并留校勘注。

## 十四、安全与伦理表述（新增，化学讲义必备）

**14.1 危险试剂安全边界**：涉及剧毒（Hg、As、CN⁻、Ba²⁺ 可溶盐）、强腐蚀、易燃、易爆（Ag₃N/Ag₂NH 雷银、叠氮化物、过氧化物）的内容，必须**同时给出安全边界**——危害途径＋防护/处置（如汞泼洒→硫粉研磨成 HgS；氰化物→碱性条件下严禁酸化）。
**14.2 禁止可误用细节**：不给出超出教学必要的制备/提纯操作细节（尤其爆炸物、剧毒气体发生装置）。
**14.3 事故与毒理案例**：水俣病、光气、光化学烟雾等案例**客观陈述机理与后果**，不作情绪化渲染，不省略剂量/暴露途径等关键事实。
**14.4 实验描述**：涉及加热、加压、有毒气体的实验须写明通风与尾气吸收；涉及高压（如 Fe(CO)₅ 50–200 atm）须标注危险等级。
**14.5 伦理与合规**：不使用未经伦理审查的人体实验描述；涉及环境与健康影响时给出客观数据而非断言。

### 22.1 知识点一律进正文

- 定义、规律、数据、适用边界，一律写成**正文陈述句**（可配表格/公式），**不得**靠 callout、元信息行、`**关联知识点**：` 之类的标签承载；

### 22.2 警示类板块准入四条（易错点／注意／误区／提醒／陷阱）

设这一类板块前须**同时满足**四条，缺一即删：

| 条 | 判据 | 反例（必须删） |
|:--:|:---|:---|
| ① **具体性** | 指出**具体错法**（错在哪一步、错成什么值），不是泛泛提醒 | 「注意单位换算」「小心陷阱」 |
| ② **增量性** | 提供正文**没有**的信息 | 把正文已写过的结论再提醒一遍 |
| ③ **锚点性** | 能挂到原文章节/行号或真题题号 | 无出处的经验之谈 |
| ④ **可操作性** | 给出可执行的判定动作（怎么查、怎么验） | 「要多加注意」 |

- **删板块不删信息**：板块内有价值的那一句**并入正文**相应位置，再删板块（§1.5 就地并入原则）；
- 单份讲义警示类小标题 **≤2 处**（超标即按四条逐条清）；
- 实测基线（口径 v2）：警示类小标题 **50 处/36 份**，警示类 callout **204 处**；逐份随批改零。

### 22.3 平铺直叙四律

1. **一句一事实**：一句话只承载一个判断，不叠加转折；
2. **先结论后条件**：结论在前，适用条件/例外紧随其后（「……，适用于……；当……时不成立」）；
3. **可验证**：每个数值给出来源锚点（原文章节/行号或题号），可复算；
4. **不旁生枝节**：不抒情、不考情鸡汤、不复述模板固定栏目之外的内容。
