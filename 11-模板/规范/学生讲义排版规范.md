# 学生讲义排版规范

> **用途**：统一 04-课件/学生讲义/ 下所有讲义（含主目录、_待升级、_归档）的排版标准，确保 .md 源文件 → docx 输出的一致性。
> **适用范围**：`04-课件/学生讲义/` 下所有讲义。
> **排版管线**：.md 源文件 → [本规范] → 预处理脚本 → Pandoc → 后处理（docx_utils.py）。

## 三、标题规范

> **口径 v4（2026-09-28 起为唯一权威；本规范 2026-10-01 对齐）**：讲义**不写 H1**；正文节标题统一 `## §N 标题`、全篇连续编号；练习区固定 `## §N 课后习题`。
> 实测（现役 41 份母版）：首标题 **41/41 为 `## §1 …`**，H1 残留 **0**，`## §N 课后习题` 覆盖 **41/41**。

### 3.1 讲义标题（无 H1）

- **不写 `# ` 一级标题**：讲义名由文件名承载（`{专题名}-超级充实版（自学完整）.md`），正文首行即 `## §1 …`。
- 历史口径的 `# 第N讲：标题` / `# 主题名` **已废止**。

### 3.2 节标题（`##`）

- 统一编号：`## §N 标题`（N 自 1 起、全篇连续无跳号），示例 `## §1 化学反应速率的定义与实验测定`。
- 练习区固定：`## §N 课后习题`（N 为紧邻的下一节号；**不写导语**）。
- **⛔ 禁止**：`## 一、标题`（中文数字序）、`## 学习目标`、`## 课后练习`、`## 思考题`。

### 3.3 子节标题（`###`）

- 编号格式：`### N.M 标题`（N = 所属节号，M = 子节内顺序），示例 `### 2.1 SN2（双分子亲核取代）——一步协同`。
- 更深一层用 `#### S.a.b 标题`；**必须带编号**，⛔ 不得写无编号的裸标签（如 `#### 定义`）。
## 四、学习目标与考纲锚点（口径 v4：已废止独立板块）

> **⛔ 口径 v4 起，讲义正文不再设「学习目标」节及其表格**（与 SOP §阶段一.3 同规）：学生侧应通过对齐考纲的精准正文直接切入核心知识。
> 考纲锚点统一写入 **Frontmatter `syllabus_codes`**（前缀 `基础-XX` / `决赛-XX`），不以学生可见的表格或 `## 学习目标` 标题呈现。
> 实测：现役 41 份讲义中「学习目标」标题 **0 处**（该词仅存于 FM `last_audit` 审计说明）。
## 五、图片规范

### 5.1 图片嵌入

> **权威口径**：图片一律用 `媒体仓库/` 的 64 位哈希名（本规范此前的 `media/filename.jpg` 写法**已废止**，仅存量遗留）。
> **宽度与图注口径以全库实测为准**（详见 [[11-模板/规范/讲义重塑与制作标准SOP]] §阶段三.5）。

图块统一为「短标签表头 + 分隔行 + 图行 + 图注末行」的**单个连续表格**：

```markdown
| 短标签 |
| :---: |
| ![[8b075f14f4228e2c22b24bced77b231556bc201ae54133dd9265b0de4969f593.jpg\|320]] |
| > 图 3-1：对象与用途 |
```

- 引用格式 `![[<64位哈希>.jpg|宽度]]`，**禁止子目录前缀**；`media/`、`mineru/`、`06-外部资料导入/` 前缀仅存量遗留，新增禁用、大修时归一。
- 替代文本（alt）**不写**：Word 导出 alt 不显示，且题库审计黑名单要求图片无 alt。
- **限宽固定（实测 934 张）**：单图 `|320`（548 处）｜并排双图 `|250`（144 处）｜并排三图 `|175`（18 处）；4 图 2×2、5 图以上 3 列多行。
- **图注**：置于图块表格**末行**，写作 `| > 图 N-M：… |`（纯中文单句，≤30 字，来源不写进图注）。**⛔ 不用斜体 `*图 N*`**（历史写法，实测 0 处）。
- 正文区**禁止**把图片写成 `|` 之外的独立裸图行。
- 图注字号 10.5pt，居中。
### 5.2 图片命名与取图

- 引用名以 `媒体仓库/` 的哈希名为准，Obsidian 全库自动解析，无需相对路径
- 新图先入库 `媒体仓库/` 取得哈希名，再写入讲义
- 找图入口：[[00-首页/00-图谱雷达总入口]]（学科分流索引）→ 复用优先于新找（[[00-首页/规则-配图来源优先级]]）
- 存量命名（`11-13-orbital-shapes-s-p-d.jpg` 等教材图号名）保留，随大修迁哈希名

### 6.1 表格格式

```markdown
| 列1 | 列2 | 列3 |
|:---|:---:|---:|
| 左对齐 | 居中 | 右对齐 |
```

- **表头**：加粗 `**` 包裹，黑体 SimHei
- **表体**：普通，宋体 SimSun
- **字号**：10.5pt
- **行距**：1.15

### 6.2 表格编号

长表格（≥5行）建议加表格编号：
```markdown
*表1 量子数取值范围与物理意义*
```

## 七、公式规范

### 7.1 行内公式

```markdown
能量 $E = -\dfrac{13.6}{n^2}\ \mathrm{eV}$
```

- 使用 `$...$` 包裹
- 单位和纯数字用 `\mathrm{}` 包裹
- 化学式用 `\mathrm{}` 包裹（避免被当作变量斜体）

### 7.2 展示公式

```markdown
$$
\Delta G^\theta = -RT \ln K^\theta
$$
```

- 使用 `$$...$$` 包裹（不要用 `\[...\]`）
- 需要编号时在公式后加 `\tag{N}`

### 7.3 化学式

- 简单化学式用 `\mathrm{H_2O}` 或直接写 H₂O（有 Unicode 下标）
- 复杂反应式用 `$$...$$`  + `\ce{}`（预处理脚本会转为 `\text{}` 兼容 OMML）
