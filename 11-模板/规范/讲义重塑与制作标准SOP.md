# 讲义重塑与制作标准SOP（执行总规 v2.0）

> **红线警示**：所有进入本知识库进行讲义重塑、编写、优化的 Agent **必须 100% 严格执行本规范**。严禁凭空捏造、严禁大干快上式批量造假、严禁在学生可见区堆叠教辅黑话或小说式叙事。

---

## 阶段一：范围定界与考点精度标定（Scope & Competition Focus）

1. **输入依据与考纲绑定**：
   - `02-考纲条目/`：必须绑定明确的考纲域码，前缀严格为 `"基础-XX"` 或 `"决赛-XX"`，填入 Frontmatter `syllabus_codes`。
   - `04-课件/备课大纲/`：必须参考对应讲次的备课大纲，落实**四级考点分类与篇幅强约束（绝非教材搬家）**：
     - 🔴 **必考点（初赛/决赛近10年高频考点）**：集中火力，深入透彻阐述微观机制、反应机理、数学物理模型与定量解题套路，配经典例题全解；
     - 🟡 **中频点（偶考或支撑性概念）**：直奔核心，提炼物理意义、关键计算公式与关键防错，1~2 个自然段收口，不作散漫推演；
     - 🟢 **低频拓展点（仅决赛/IChO或边缘知识）**：严格控制篇幅，采用精炼对比三线表或结论段落呈现，严禁泛滥展开大篇幅背景陈述；
     - ⚪ **不考/超纲细节（仅为教材前言、琐碎分类、繁冗高等统计/纯数理展开）**：**坚决砍掉或最多一笔带过**！严禁把教材内容事无巨细直接整盘端上讲义！
2. **重心与信息密度原则**：
   - 目标是**竞赛讲义**，让学生快速掌握竞赛知识、解题套路与避坑法则；
   - 严禁为了“讲全”而陷入平铺直叙，把版面和认知精力集中在“考什么、怎么破、怎么算、怎么防坑”；
   - 正文篇幅严格克制，坚决杜绝通篇漫无边际的长篇大论。
3. **格式清理**：
   - ⛔ **严禁在讲义中保留 `## 学习目标` 空泛口号板块及其表格**（学生侧通过对齐考纲的精准内容直接切入核心知识）。

---

## 阶段二：素材溯源（Materials & Sourcing）

1. **S 级真教材排他性（唯一主基准源）**：
   每份讲义在 Frontmatter `sources` 中必须挂载可逐节对照的真实教材原文（落入 S/A 级源池），**严禁双基准混用**：
   - **化学原理 / 基础物化**：《普通化学原理》（第 4 版，北大）；
   - **元素化学**：宋天佑《无机化学》下册（全本 504 页）＋《上海中学竞赛教程》第 3 分册；
   - **结构与高阶无机**：《结构化学基础》（第 5 版）＋唐宗薰《中级无机化学》（343 页全本）＋Weller；
   - **有机化学**：Clayden《有机化学》中文版（全本在库可用，11–800 页与 787–1199 页）；
   - **无机机理推动**：《Arrow Pushing in Inorganic Chemistry》（336 页全本）。
2. **严禁二手污染**：
   - `07-资料提炼/` 与转写笔记（Zchem、质心、学而思等）仅作为检索定位线索；
   - ⛔ **严禁提炼页与笔记进入 `sources` 字段，严禁作为正文补写的内容依据**。

## 阶段三：语言规范与正文呈现（Language & Presentation）

### 1. 知识点 100% 入正文，Callout 彻底清零
- **主视觉原则**：核心化学原理、反应机理、数学推导与物理意义必须平铺在正文段落中。
- **引用块白名单**：**仅允许图片图注**——图注紧随图、置于图块所在表格的**末行单元格**，写作 `| > 图 N-M：… |`（纯中文单句，≤2 句）。除此之外正文不得出现任何 `> ` 引用框。
- **违规即改**：所有用于承载公式本质、易错提醒、机理解析的 `> ` 引用框（Callout），必须脱去引用壳，改写为正式的学术段落。

### 2. 彻底清除管理元信息与作者内测痕迹
学生可见区严禁出现任何内部指导与测试残留：
- ⛔ **全量删除**：
  - 教学指导语：`> **本小节要求**：`、`> **学习建议**：`、`> **本章做到**：`
  - 试题批注语：`> **评分说明**：`、`> 考点：`、`> 评分：`
  - 内部标记：`（P0-C 补强）`、`> **立项依据**：`、`> **自校验**：`、`注：原配图为...已删除` 等开发日志
- **合规转化**：若有关键数学验证，改写为客观推导句（如“代入吉布斯自由能加和计算验证：$\dots$ 与实验测定值完全吻合”）。

### 3. 语言全面转向大学权威教材与学术期刊（《物理化学》《化学学报》体例）
- **彻底终结小说式/通俗化叙事**：
  - ❌ 拟人/生活比喻：`镀层破损后的不同命运`、`用金属配合物把 N₂ 抓住`、`用质子给电子铺路`、`孩子像舅舅`
  - ✅ 学术规范：`金属表面保护镀层的分类与破损电化学行为`、`过渡金属配合物的端基配位与活化机制`、`质子耦合电子转移（PCET）热力学与动力学协同效应`
- **标题去轻浮化、去粗俗黑话与去浮夸噱头词汇**：
  - ❌ 标题设问：`为什么 N₂ 这么难还原`、`为什么两道题数值不同`
  - ❌ 粗俗/焦虑化教辅黑话：`常死点`、`死点`、`赛场常死`
  - ❌ 浮夸/生造噱头词汇：`防截断雪崩策略`、`黄金视窗/视窗`、`破局心法`、`终极密码`
  - ✅ 学术规范标题：`氮分子的热力学稳定性与电还原能垒`、`二茂铁标度的环境依赖性与参比换算`
  - ✅ 得体避坑标题：`常见失分陷阱`、`典型易错雷区`、`认知冲突辨析`、`赛场防错指南`
  - ✅ 严谨实验标题：`分析测量范围与误差控制界限`、`中间过程精度保持与修约控制`
- **严密论述三律**：
  1. 结论必带**完整条件域**（温度、介质、酸碱度、聚集态）；
  2. 数值严谨带**单位与物理量符号**（$p^\theta = 100\ \mathrm{kPa}, F = 96485\ \mathrm{C\cdot mol^{-1}}$）；
  3. 全文采用第三人称客观学术叙述，严禁感叹号与情绪化修辞。
- **认知友好与梯次进阶铁律（夯实大纲优先·拒绝早期超纲劝退）**：
  - 前两轮讲义必须以**夯实初赛考纲**为第一要务，降低认知门槛，讲透基础概念、机理和计算套路，绝不可一上来就用高阶超纲理论给学生造成严重挫败感；
  - 极度偏门、深入的决赛或 IChO 理论，必须剥离后置到专门的“高阶深化/专题拔高”模块，前序讲义严禁喧宾夺主。

### 4. 习题平铺、紧扣正文与去偏怪规范
- **100% 紧扣讲义核心内容**：讲什么就练什么，课后习题的考查范围必须在正文讲授的方法、机理与计算公式射程之内，**严禁正文讲基础、习题塞入完全脱节的偏门理论**；
- **拒绝偏门怪题与大学刁难**：题目可以有难度和思维梯度，但背景必须贴合全国初赛与经典决赛真实考法，**严禁编排纯高等数学推导、纯统计学或大学专业课专属的偏怪题目**；
- 100% 取自 `04-题库/`（真题或原书习题），严禁讲义内随意编造非标题目；
- 题面必须完整独立，学生不点链接即可作答；
- ⛔ **彻底废除“基础概念与基本计算 / 基础巩固 / 竞赛入门 / 真题挑战”等分层小标题**；
- 习题统一平铺编号：直接以 `**题 1**`、`**题 2**`…… 在综合练习题大节下连续罗列。

### 5. 图片尺寸控制与多图紧凑排版

> **宽度口径（2026-10-01 按全库实测收敛，唯一权威）**：下表为现役 41 份讲义 934 张图的实测分布，**是本节、§8 与 [[11-模板/规范/学生讲义排版规范]] §5 的共同基准**。历史上 §5 记 `|260|`、§8 记 `280~320px`／`|220|~|260|`／`|300|~|360|`，三者互相矛盾，现全部废止。

| 版式 | 限宽 | 实测占比 |
|:---|:---:|:---:|
| 单图独立成行 | `![[图片名.jpg\|320]]` | 548 处 |
| 并排双图（2 列三线表） | `\|250` | 144 处 |
| 并排三图（3 列三线表） | `\|175` | 18 处 |

- **图块结构（统一形态）**：一张图或一组并排图，外加**短标签表头行**与**图注末行**，共同构成一个连续表格——`| 短标签 |` / `| :---: |` / `| ![[…\|320]] |` / `| > 图 N-M：… |`；并排则表头与图注行同宽并列。**禁止**把图片作为正文区的独立裸图行（`|` 之外单独一行的 `![[…]]`）。
- **单图尺寸**：统一 `|320`。Word 转换管线（`build-all-handout-docx.py`）据此约束宽度，严禁巨幅图片充斥页面破坏版面。
- **多图并列排版纪律**：多张小图（如分子结构对比、催化剂前驱体）**严禁竖向堆叠单占一行**，必须采用并列排版（双列/三列居中表格），紧跟对应文字之后：**双图 `|250`、三图 `|175`**（4 图用 2×2、5 图以上用 3 列多行，宽度算法见 `11-模板/scripts/layout_figs.py`）。

### 6. 表格规范与学术三段式（三线表）
- **国标学术三段式（三线表）体例**：所有正文数据表、物化参数表、电对电势对比表均必须对标 GB/T 7713.1 科技出版三线表标准：
  - **顶线**：1.5 磅粗实线（`sz="12"`，颜色 `#333333`）；
  - **表头栏目线**：0.75 磅细实线（`sz="6"`，颜色 `#333333`），区分表头属性与正文数值；
  - **底线**：1.5 磅粗实线（`sz="12"`，颜色 `#333333`），界定表格终点；
  - **竖线与网格线**：全表无竖线、无多余内网格横线，开敞清爽；
  - **居中排布**：Word 导出管线（`docx_utils.py`）自动将表格整体水平居中，表头加粗居中，正文数据居中。
- **多图并列表格应用**：
  - 两张并列小图（如机理图＋晶胞图）统一置入 Markdown 双列表格第一行，图注置入第二行；
  - 导出管线赋予三段式外框界定，使图注与图幅规整对齐，杜绝页面元素浮空离散。

### 7. 去列表化与出版级自然叙述段落（De-bulleting 铁律）
- **杜绝碎片化清单**：核心化学原理、推导与机理分析**严禁泛滥使用 `- ` 无序列表（Bullet Points）堆砌**。列表体只适用于简单的并列实验编号或速查数据；
- **重构为论述性自然段落**：正文核心内容必须写成逻辑连贯、语流舒展的经典教材式自然段，段与段之间空一行，展现大学经典学术教材与期刊论文的宏观逻辑张力；
- **出版级首行缩进 2 字符**：Word 导出管线自动为正文段落注入 2 字符首行缩进（21pt / 420 dxa），严禁靠手动加空格或靠 `- ` 列表强行做段落缩进。

### 8. 图像资产 100% 视觉核验铁律（五严禁与四必备）
化学讲义极度依赖微观结构与势能图。写入讲义的图片必须遵循**视觉核验标准**：
- **配图“五严禁”（触碰即打回）**：
  1. **严禁公式误作图**：严禁把 OCR 扫描切碎的数学公式、反应式截屏当作图片插入；
  2. **严禁图注张冠李戴**：正文讨论动力学/热力学，配图绝不可使用晶胞或无关反应器图片（如伪 Latimer 图事件）；
  3. **严禁模糊毛刺扫描图**：严禁手机翻拍、带摩尔纹、字迹不清或坐标轴歪斜的低劣图片；
  4. **严禁巨幅撑破页面**：单图宽度统一固定为 `|320`（口径见 §阶段三.5 表），杜绝单图强占一整页；
  5. **严禁孤儿失联引用**：严禁引用未在 `媒体仓库/` 顶层落盘的图片。
- **配图“四必备”标准**：
  1. **必须视觉核验**：写入 `![[<哈希>.jpg]]` 前，Agent 必须通过 `view_file` 等视觉能力工具在物理磁盘上亲自查看图片内容，核验坐标文字与化学实体；
  2. **必须版面工程控制**：对比图/机理循环强制使用 2 列三线表并排，并排小图宽度 **双图 `|250`、三图 `|175`**；独立单图宽度固定 **`|320`**（与 §阶段三.5 表同一口径）；
  3. **必须纯中文图注**：图注置于图块表格**末行单元格**，写作 `| > 图 N-M：… |`（纯中文单句，紧跟图后），杜绝在图注内书写复杂 LaTeX 导致 Word XML 崩溃；
  4. **优先复用高清原生/矢量重绘资产**：优先从 `10-索引与统计/` 学科图谱雷达中检索经过验证的高清原图。

## 阶段四：双轨派生体系（自学完整版 ＋ 学生专用版）

每份讲义在完成上述规范后，必须同时生成**两套对应版本**：

1. **自学完整版（母版）**：
   - 命名：`{专题名}-超级充实版（自学完整）.md`
   - 内容：完整理论正文 ＋ 典型例题详细解析 ＋ 综合练习题完整题面 ＋ 练习题参考答案。
2. **学生专用版（无答案刷题版）**：
   - 命名：`{专题名}-超级充实版（学生专用版）.md`
   - 内容：完整理论正文 ＋ 典型例题题干 ＋ 综合练习题完整题面。
   - **留空纪律**：**严禁出现任何诸如 `【解题作答留空区】` 等文字横幅标语，直接空行或 `<br>` 留白**；例题答案全部抹除留白，练习题参考答案章节全量抹除。
   - 目的：供学生线下课印刷作答与自主模考，避免学生边做边看答案失去思维训练价值。

## 阶段五：实施阶段五步流水线与四闸门机检闭环

任何讲义的精修与重塑，必须严格按照以下顺序执行：

```
[Step 1] 运行 metrics 基线体检 ──→ 明确现有缺陷（Callout数、伪标签数、二手源数）
    ↓
[Step 2] 锁定考纲域码与 S 级教材 ──→ 补全 Frontmatter 字段
    ↓
[Step 3] 执行正文重塑与学术化 ──→ 拆除知识 Callout、消灭小说化、提炼高密度学术段落
    ↓
[Step 4] 习题规范化与去分层 ──→ 保证题面完整独立，题卡短链对齐
    ↓
[Step 5] 派生学生专用版 ──→ 抹除例题解答与练习答案，插入标准作答留空区
    ↓
[Step 6] 运行四大机检闸门 ──→ 必须四绿全过方可提交
```

### 必须通过的四大机检命令（硬判据）

```bash
# 闸门 1：知识库合规机检（必须 0 Error, 0 Warning）
python -X utf8 11-模板/scripts/validate_kb.py --changed <讲义路径>

# 闸门 2：公式渲染断言闸门（必须 RENDER_GATE=PASS）
python -X utf8 11-模板/scripts/render_gate.py --changed <讲义路径>

# 闸门 3：Docx 真实导出与更新（必须 0 errors 且修改时间最新）
python -X utf8 11-模板/scripts/build-all-handout-docx.py --file <讲义名称，不带.md>

# 闸门 4：纯净度断言（知识 Callout 与管理元信息必须为 0）
python -X utf8 -c "
import pathlib
p = pathlib.Path('<讲义路径>')
quotes = [l for l in p.read_text(encoding='utf-8').splitlines() if l.startswith('>') and not l.startswith('> 图注：')]
assert len(quotes) == 0, f'检测到 {len(quotes)} 处违规引用框！'
print('✅ 纯净度检查 100% 通过：零违规引用框与元信息')
"
```

## 阶段六：外部教材与参考书五步资产化导入 SOP

为了防止后续引入海量经典教材（Atkins、Weller、Clayden、胡英、李振声等）时导致知识库臃肿、Token 暴涨、文件污染或失联图片，必须确立**五步资产化导入标准**：

```
[原始教材 PDF] ──→ 步骤 1：按章语义切片（单章 30~80 KB，落入 03-教材书籍/）
       ↓
```
