# 机构模拟题组卷管线 SOP（定版 v1.0 · 2026-10-06）

## 〇、铁律（最高优先级）

**每一道进卷的题，必须【对照原 PDF】用视觉能力核验「题目／图片／答案」三元；只信 OCR 中间产物一律判不合格。**
发现问题**优先换卡**（池内另选），不硬修；确需修源卡时逐条回源、带断言、可复核。

## 二、标准动作（七步，顺序不可乱）

```bash
PY="C:/Users/蕾赛/AppData/Local/Programs/Python/Python312/python.exe"
O=.workbuddy/tmp/opt_pipe

# ⓪ 前置闸：回源视觉三元核验（★ 不给过不进卷）
"$PY" -X utf8 $O/build_org.py --vol <VOL> --all-years      # 先看候选（不写盘）
"$PY" -X utf8 $O/verify_dump.py <卡路径...>                 # 卡 → 题面页/答案页
"$PY" -X utf8 $O/pdf_text_check.py --cards <清单>           # 卡 vs PDF 文字层覆盖（快筛）
#   逐张打开渲染页，比对「①题面逐句 ②图片逐张 ③答案回源」；有问题换卡

# ① 组卷（先看不写）→ ② 写盘
"$PY" -X utf8 $O/build_org.py --vol <VOL> --all-years
"$PY" -X utf8 $O/build_org.py --vol <VOL> --all-years --apply
#   打印 pool[元素与分析]/[结构化学]/[化学原理] ＋ 16 题清单；⚠️ 某段池 < 所需 ⇒ 停手报告

# ③ 出交付物（真题版式）
"$PY" -X utf8 $O/build_volX_zhenti.py --vol <VOL>
#   期望「图准备 N 张，已铺 N 张，缺 0」＋[OK] 两行；⚠️ 缺>0 立即停手查图

# ④ 终检
"$PY" -X utf8 $O/qa_volX2.py
#   全绿：图守恒(md==media)/字面<table>=0/字面$=0/题面泄露=0/表体空行=0/清单16行7列

# ⑤ 视觉核验（不可省）
"$PY" -X utf8 $O/render_any.py "<docx 绝对路径>" <tag> 1 45
#   逐页打开 PNG：图过大?多图并排?水印/二维码垃圾图?表格正常?公式乱码?

# ⑥ 提交（逐路径精确 add，禁目录级 add）
git add -- <本卷改动的每个路径>      # .workbuddy/ 下须加 -f
git commit -m "…"                    # render_gate 拦下 ⇒ 先 --changed 自证，登 allowlist，绝不 --no-verify
```

| 图引用 | 纯哈希 wikilink `![[<name>]]` | 并排图是转义形态 `![[hash.jpg\|250]]`，正则须容忍 |

## 四、交付前验收闸门（全过才叫完成）

1. `build_volX_zhenti.py` → **图准备 N / 铺 N / 缺 0**；`[OK]` 两行。
2. `qa_volX2.py` → **问题数 0**。
3. 渲染逐页**目视**通过（图不超大、无垃圾图、公式不乱码）。
4. 回源三元核验结论表**无 ⛔**（P0 全清）。
5. `git diff` 复核：只含本卷预期改动。
