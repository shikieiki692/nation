# 机构模拟题解析撰写规范（v1.0 · 2026-10-08）

> 上游：[[机构模拟题组卷管线SOP]]（管线与闸门）、`~/.workbuddy/skills/multisource-exam-paper-compose/SKILL.md`（工具与坑表）。
> 本文＝**「解析」这一环的定版口径**：结构、取材、排版、验收。

## 〇、为什么需要它

源答案（机构卷/试卷附的答案）通常**只有算式与结论**，缺少「为什么这样列式、这一步靠哪条原理、容易错在哪」。
交付物的读者是学生，因此本线统一要求：**逐题撰写结构化解析**。
解析不是复述答案，而是**用知识库的判据框架把解法讲透**。

**边界**：解析**不修改**答案区（答案区保持源答案原貌，仅按 SOP §五-b 修缺陷）；
解析是**追加**在答案之后的独立段落。

## 一、四段式结构（固定）

每题一段引用块，首行为居中横幅，之后依次四段：

```markdown
> —— 解析 ——
>
> **考点**：<考点词> · <考点词>（知识点：〈页名A〉、〈页名B〉）
>
> **思路**：<2~4 句，讲清整体路线与关键选择>
>
> **1-1**（N 分）<该小问的详细推导>
>
> **1-2**（N 分）<…>
>
> **易错**：<①… ②… ③…，1~4 条>
```

| 段 | 写什么 | 不写什么 |
|:--|:--|:--|
| `—— 解析 ——` | 居中横幅（`—` 开头的引用块会被出卷器居中） | 不写成 `**解析**` 之类左对齐标题 |
| **考点** | 本题考的**方法/原理**（不是「知识点名称罗列」），并给出**所引知识点页名** | 不写「本题考查学生的计算能力」这类空话 |
| **思路** | 整体路线、为什么这样切入、用了什么守恒/近似 | 不复述题干 |
| **分步** | 按**卷内小问号**（`1-1`/`3-2`…）逐问推导；算式写全、单位写全、结果给出 | 不写「由上式可得」而跳过关键步骤 |
| **易错** | 该题真正的坑（符号、方向、单位、忽略项、近似条件） | 不写与本题无关的通病 |

## 二、知识库取材口径（★ 本规范的核心）

解析的**判据级内容**必须来自 `03-知识点`，不得自行发明术语或与库内判据冲突。操作步骤：

1. **定位**：按题的模块找页。常用页（均已在库中核实存在）：
   - 热力学/平衡：〈化学热力学〉〈Gibbs自由能〉〈化学平衡〉〈化学平衡计算〉〈van't Hoff方程〉〈Le Châtelier原理〉〈反应商〉〈内能〉〈体积功〉
   - 相平衡/溶液：〈Clapeyron方程〉〈相变热力学〉〈化学势〉〈相图与相平衡〉〈稀溶液依数性〉
   - 电化学：〈Latimer图〉〈Frost图〉〈Nernst方程〉〈原电池〉〈电极过程热力学〉
   - 平衡耦合：〈多重平衡〉〈稳定常数〉〈溶解度〉〈溶度积〉〈pH〉〈酸碱平衡〉〈缓冲溶液〉〈亨德森-哈塞尔巴赫方程〉
   - 动力学：〈化学动力学〉〈反应级数〉〈半衰期〉〈稳态近似〉
2. **抄判据**：把该页「核心原理/判据」的**表述方式**搬进解析。例：
   - Latimer 图：不相邻电对电位须**按电子数加权** $E=\sum n_iE_i/\sum n_i$；**歧化判据＝右侧电位 $>$ 左侧电位**；
     电势差与 $\Delta G$ 用 $\Delta_rG^\ominus=-nFE^\ominus$ 贯通。（见 〈Latimer图〉）
   - 多重平衡：方程相加 ⇒ $K=K_1K_2$；沉淀+配位 ⇒ $K=K_{sp}\beta$。（见 〈多重平衡〉）
   - Clapeyron：$\mathrm{d}p/\mathrm{d}T=\Delta_{\text{trans}}H/(T\Delta_{\text{trans}}V)$；冰熔化 $\Delta V<0$ ⇒ 斜率为负。（见 〈Clapeyron方程〉）
3. **引用**：在「考点」段用 〈页名〉 标出（**纯文本书名号**，不用 `[[wikilink]]`——docx 不渲染 wikilink）。
   页名必须**真实存在**；写之前用 `find 03-知识点 -name "<页名>.md"` 核一遍。
4. **不冲突**：若源的解法与库内判据不一致，**以库内判据为准**，并在解析中说明差异。

## 三、数值与符号（铁律）

1. **逐环复算**：凡数值链（$\Delta H\to\Delta S\to\Delta G\to K$、$n\to c\to \mathrm{pH}$ 等），必须自己算一遍。
   源答案的数值**默认可疑**——本线已实测出源答案把 $15355/1808$ 印成 8.5924 的笔误（整链错）。
2. **发现源错**：解析中按更正值讲解，并加一句校勘说明；答案区同步**径改 + 校勘注**（SOP §五-b 缺陷 8）。
3. **符号**：$\Delta_rH_m^\ominus$／$\Delta_{\mathrm{mel}}S_m$／$K^\ominus$／$E^\ominus$ 的标准态一律用 `\ominus`
   （不用 `\theta`/`\circ`；也不要省略）。
4. **单位**：一律 `\mathrm{kJ\cdot mol^{-1}}`、`\mathrm{J\cdot K^{-1}\cdot mol^{-1}}`（不写 `kJ/mol`、不写 `J/(mol·K)`）。
5. **有效数字**：与题给数据位数一致；近似值用 `\approx`，精确复算值用 `=`，并保持一致。

## 四、排版细则（docx 呈现）

| 项 | 规则 |
|:--|:--|
| 块类型 | `>` 引用块；**每段之间用空 `>` 行分隔**（否则 pandoc 会并成一段） |
| 横幅 | 首行 `> —— 解析 ——`（出卷器对 `—` 开头引用块**居中**，形成分隔条） |
| 小标题 | `**考点**`／`**思路**`／`**易错**` 加粗；分步用 `**1-1**（N 分）` |
| 公式 | **行内 `$…$` 两端禁空格**（否则印字面 `$`）；显示式 `$$` **必须独占一行**（SOP 铁律二） |
| 长式 | 超页宽的式子**拆成多段行内 `$…$`**，不要塞进一行 |
| 嵌套 | `\frac` 不超过两层；避免 `\begin{array}`/`\xlongequal`/`\dfrac`（texmath 支持受限） |
| 语言 | 教研语气：不用网络用语/黑话/装饰性 emoji；术语用规范写法 |

## 五、工具与流程

- 数据文件：`an13_data1.py`（1~5 题）、`an13_data2.py`（6~10 题）——字典结构
  `{题号: {考点, 思路, 步骤[(tag, score, text)], 易错}}`。
- 注入器：`add_analysis_<VOL>.py` —— 幂等（答案版 md 已含 `> **考点**：` 则跳过）；
  插入位置＝每题块**最后一个 `---` 之前**。
- **仅写入答案版 md**；学生版 md 不含解析（由 `build_volX_zhenti.py` 出学生版 docx 时自动无解析）。
- 重写解析：先 `build_org.py --apply` 重出卷 md（清空旧解析），再跑注入器。

## 六、验收闸门

1. `qa_volX2.py --vol <VOL>` → **问题数 0**（尤其「字面 `$` = 0」）。
2. `[OK] answ` 行的 **`引块` 与 `数式字体` 计数显著上升**（说明解析确实进了 docx）。
3. **答案版逐页目检**：横幅居中、四段加粗正确、公式无乱码、分步编号与卷内小问一致。
4. 每条「考点」引用的页名**已 `find` 核实存在**。
5. 数值链**已复算**，与答案区口径一致（不一致处已写明校勘）。

## 七、反面清单（不要做）

- ⛔ 不复述题干充当解析。
- ⛔ 不写「易得」「显然」「由上式可得」跳过关键步骤。
- ⛔ 不在解析里引入库中不存在的自造术语；不与 `03-知识点` 判据冲突。
- ⛔ 不用 `[[wikilink]]` 引知识点（docx 不渲染）。
- ⛔ 不把 `$$` 写在行尾（会静默摧毁整卷数学解析）。
- ⛔ 不臆造源答案的数值；引用源值前先复算。
