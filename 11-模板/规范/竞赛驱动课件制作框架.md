# 竞赛驱动课件制作框架 v1.0

> **目标**：让学生考竞赛。每份课件都必须能回答三件事——
> ① 在真题里**考什么**；② 对应**考纲哪几条**；③ 配套**哪些题（可溯源）**。
> **原则**：⛔ 不平行复制现有体系；⛔ 不凭直觉选题；✅ 一切结论可回链到真题 / 考纲 / 模拟题 / 教辅。

---

## 第 2 层 · 类型分流层（先判型，再动笔）

| 课型 | 定位 | 使用者 | 组织轴 | 必备板块 |
|:--|:--|:--|:--|:--|
| **复习课（课堂型）** | 章后整合 | 教师 | 知识网络 + 易错点 | 学习目标 → **本章考试地图** → 知识网络总图 → 统一框架 → 易错点 → 速查卡 |
| **复习课（自学型）** | 模块自学 1–2h | 学生 | 考纲逐条 | `§1..§N` 逐主题 + 考纲对照 + 练习题 |
| **专题课** | 真题驱动击破 | 教师 | **四段式** | `一、开场·真题直击(10min)` → `二、知识拆解(15min)` → `三、真题精练(20–30min)` → `四、总结·速查卡(5min)` |
| **习题课** | 方法训练 | 教师 | 题组 | 课前准备 → 习题课目标 → **题组设计**（示范＋练习＋变式） → 课时大纲 → 典型错误预判 |

⚠️ 判型依据＝`lesson_type` ＋ `audience_level`；⛔ 复习课与专题课**不可互套结构**。

## 第 3 层 · 抽料层（7 层优先级，源自《专题驱动的备课方法论》§0.1）

| 优先 | 材料 | 作用 |
|:--:|:--|:--|

| P0 | 备课大纲 / 现有主稿 | 决定课堂主线、认知台阶 |
| P0 | **主教材提炼**（普化原理 / Weller / Atkins / Clayden / 中级无机） | 稳定主干：定义、规则、推导、图景 |
| P1 | 网课资料与教学逻辑提炼 | 课堂口令、分层讲法、易错提醒 |
| P1 | KP / 专题页 | 现成知识块、对照表、桥梁解释 |
| P1 | **题库 / 真题链** | 例题推进链、变式、收束题 |
| P2 | 图片资产 / 教材图 | 视觉证据 |

**抽料顺序**：先定边界 → 再定 1 条主教学链（＋1~2 条外扩链）→ 按「教材主干 → 网课讲法 → KP/专题 → 题库 → 图片」抽 → 先抓**桥梁内容**（能把前后串起来、能承担"为什么"的解释点）。

## 第 5 层 · 质量层（验收标准）

### 每份课件（可机检）
- [ ] 含命题分布表，行数 ≥3，且**每题回链题卡**（`[[04-题库/…]]`）
- [ ] 回链**全部可解析**（`os.path.exists` 逐条核验）
- [ ] FM 含 `exam_syllabus`（→ `02-考纲条目/`）≥1 条
- [ ] 无自编题；所有题回链题库（真题优先，机构题补位）
- [ ] P0 缺口在对应课件有落点（`Stokes|竞争反应|活度|BDE|超电势` 命中）
- [ ] 三闸门：js-yaml → validate_kb → render_gate 全绿

### 全局
- [ ] 回链可解析率 100%
- [ ] 表格列数一致（转义 `\|` 正确）
