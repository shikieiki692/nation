# 讲义语言规范

> **定位**：管「语言本身」——重复控制、提示体系形态、用词、句式与段落。管「结构/符号/元数据」的既有规范（SOP、v5.3 模板、MD 通用规范）不因本文件改变权威归属。
> **适用**：`04-课件/学生讲义/` 全体现役讲义（85 份）。改造批次按本文件逐条判定；新写讲义在 SOP 验收时同检。
> **依据**：教材编写通则（概念严格定义且全篇含义不变；新概念必须解释定义；术语全书统一，「即使轻微重复也优于同义词混用」）；科技编辑规范（准确简洁、忌语言杂糅、避免主题离题、不使用拟人与俚语——教学讲义场景放宽为「受控类比须对齐」）；教材重复规律（重要概念全书螺旋重复 5~6 次**分布在全书不同章节**；讲义是单篇自足形态，同一结论的重复上限压缩为「正文 1＋速查 1＋回链」）。

## 一、重复控制（主病条款）

**1.1 命题单元与「同一结论」判定**
一个结论＝「命题主体＋判定条件（或数值/方向）」的完整陈述，如「极性非质子溶剂使亲核阴离子溶剂化弱，SN2 速率可提高 10³~10⁵ 倍」。判定同一结论：命题主体相同（同义词归一后）且谓词结论等价（同向、同数量级、同条件域）。**措辞不同不算不同结论。**

**1.2 唯一权威表述**
每个核心结论在**正文完整推导恰好一次**，该处为唯一权威表述。其余位置只允许三种形态：速查表公式行、答案节「（理由见 §x.x）」式回链、交叉引用 wikilink。

- 反例（原子结构）：「先失 n 最大的电子」在 warning、正文、规则行、§4.1 表、误区表、速查表出现 5 遍，其中两处相隔 2 行逐字重复 → 保留正文推导 1 处＋速查表 1 格，其余删除或改回链。

**1.3 速查表纪律**
每格只允许：公式行、定性排序（如 3°>2°>1°）、§号回链。**禁止**理由句、「因为/所以」、推导片段、口诀全文（口诀名可入）。

**1.4 答案纪律**
练习答案只回答本题：该题条件下的具体判定＋一步关键理由。通用结论重讲视为违规，改回链。

**1.5 提示块转述清除**
`> [!tip]`/`> [!warning]`/`⚠` 前缀/伪 callout 引用块内，出现正文已有结论的转述（未新增信息）一律删除；确需强调的，在正文权威表述处就地加粗关键词，不另开提示块。

## 二、提示体系归一（三轨 → 一轨＋正文）

**2.1 废除伪 callout**
`> **标题**：` 独立引用块不再允许。逐个按三分法处置：
- (a) 内容为方法论/易错点且正文无此结论 → 升格为 `> [!tip]` 或 `> [!warning]`；
- (b) 内容为正文结论的强调复述 → 删除；
- (c) 内容属正文逻辑（承接句、推导步骤、「这说明……」）→ 去引用块降为正文段落。
整段推导（含公式、表格）塞入引用块视为主次颠倒，必须降回正文（反例：原子结构 Koopmans 能量分解 27 行）。

**2.2 废除 `⚠` 加粗前缀**
并入 `[!warning]`，或改为正文「注意：」引导句。图注（`*图 N …*`）不受此条约束。

**2.3 密度上限**
正式 callout（tip/warning/info/note）单讲总数 ≤ ⌈正文行数/100⌉ 且 ≤12 个；任意连续 200 行 ≤3 个。超限优先合并同类，其次删转述类。

## 三、用词负面清单（首版；扩充须同步登记白名单例外）

**3.1 替换表**

| 负面词 | 替换 | 说明 |
|:--|:--|:--|
| 塞进 | 填入 / 排布至 | 拟人动作 |
| 划算 | 能量上更有利 | 拟人评价 |
| 走人（离子/基团离去语境） | 离去 | 口语 |
| 不给力 | 离去能力弱 / 亲核性弱 | 网络语 |
| 抢答 | 过早下结论 | 课堂口语 |
| 翻盘 | 逆转主导因素 / 按语境改写（如「熵项贡献超过焓项」） | 口语 |
| 踢走 | 排出 / 弹出（保留于「通俗理解」栏时须带引号） | 拟人 |
| 纠结（试剂选择语境） | 竞争激烈 / 判定依赖试剂 | 口语（已进口诀的按 §5.3 处理） |

**3.2 判定标准**：负面词＝日常口语带情绪/拟人色彩、且可用术语无损替换。替换后损失信息的不属负面词，转 §5 处理。

**3.3 白名单**（保留，改造前登记）：「熵税」（热力学 L571，须补「严格地说……」对齐句）；「裸露」（亲核取代，已术语化带引号）；「小炸弹」比喻（符合事实的形状类比）；「通俗理解」栏整体机制（须紧跟严格表述）。

## 四、正面表述规范

**4.1 结论句式**：规律性结论用「条件域＋判定」（「当/在……时，……」）。只给结论不给条件域视为不完整（「高温利消除」须为「底物相同时，升温使消除/取代比增大，因消除活化熵变更正」——条件与原因至少具其一；速查表除外）。

**4.2 首次定义句式**：术语首次出现给「标准名（又称别名）＋一句可操作定义」（对齐人教版「××叫做××」与周公度「称为××（又称××）」句式）；此后只用标准名，不再重复定义。**同义词全篇只选一个**（对齐科技编辑通则：术语一致性优先于避免重复）。

**4.3 段落下限**：一个段落/引用块 ≥2 个完整句或 1 个完整推导步骤；单句孤立成块视为碎片段，并入相邻段（图注、公式行、表行除外）。推导链中「另一方面，」「即：」不得独立成行。

**4.4 语气**：面向学生的陈述句；允许设问引入（每节 ≤1 处）；**禁用反问句做结论、禁用感叹号连用**；标题不加情绪修辞（「天才猜想」→「德布罗意假设」）。

## 五、口诀与类比

**5.1 功能性口诀**：保留，但首次出现处必须紧跟一句严谨对齐句（口诀 → 判据的翻译）；同屏口诀与等价公式/正文双编码视为重复，删其一。

**5.2 设计性类比**（熵税、裸露等）：保留，登记白名单；类比只出现一次、紧跟「严格地说……」；不进速查表。

**5.3 口诀唯一性**：同一口诀全文逐字出现 ≤1 次（反例：亲核取代「强碱大位阻走 E2……」在 L473 与 L733 逐字重复）；速查表可收口诀名不收全文。

## 六、段落与结构

**6.1 收尾节归一**：每讲收尾固定「本讲速查」（公式行汇总）＋「本讲小结」（主线收束，v5.3 唯一强制收尾节）；「本节总结·速查」「核心速查卡」等变体名废弃。

**6.2 章节内聚**：每节只服务一个主题句；跨主题内容拆节或移附录；不设「题外话」式引用块（对齐「避免主题离题」编辑通则）。

**6.3 例题解析三层**：「思路 → 关键步骤 → 结论」，层间不互重复；结论不重讲正文通用规律（回链）。

## 七、判定流程（改造时怎么用本规范）

1. 跑 `scan_handout_lang_audit.py` 得量化基线（伪callout/密度/⚠/碎片/负面词/口诀重复/速查命名/重复对）；
2. 重复对逐个人工裁决：定权威表述锚点 → 删副本（「只删副本、正文加厚」）；
3. 伪callout 逐个三分法（§2.1）；
4. 负面词替换（对照 §3.1，白名单跳过）；
5. 收尾节改名（§6.1）；
6. 重跑脚本逐项达阈值，grep 复核被删结论的权威表述在位。
