# 讲义语言规范

> **定位**：管「语言本身」——重复控制、提示体系形态、用词、句式与段落、编校差错、术语一致性、断言纪律。管「结构/符号/元数据」的既有规范（SOP、v5.3 模板、MD 通用规范）不因本文件改变权威归属。
> **适用**：`04-课件/学生讲义/` 全体现役讲义（85 份）。改造批次按本文件逐条判定；新写讲义在 SOP 验收时同检。
> **依据**：教材编写通则（概念严格定义且全篇含义不变；新概念必须解释定义；术语全篇统一——「即使轻微重复也优于同义词混用」）；CY/T 266—2023《图书编校质量差错判定和计算方法》（语法性差错、科技名词差错、量与单位、标点与数字用法的差错分类）；GB/T 15834—2011（标点）、GB/T 15835—2011（数字用法）、GB 3100（量和单位）、全国科学技术名词审定委员会审定名词；教学写作典范（费曼讲义：概念先于形式化、类比紧扣物理由来、坦承不确定；Clayden 机理叙述句式；人教版「把……叫做/称为」定义句式）；国际风格指南借鉴（Microsoft/Google 词表机制、主动语态与句长控制；Wikipedia MOS 措辞纪律的可验证性精神）。
> **样本**：各条款的正反例句见 [[11-模板/讲义语言规范·语体参照样本]]（按条款号编排）。

## 一、重复控制（主病条款）

**1.1 命题单元与「同一结论」判定**
一个结论＝「命题主体＋判定条件（或数值/方向）」的完整陈述。判定同一结论：命题主体相同（同义词归一后）且谓词结论等价（同向、同数量级、同条件域）。**措辞不同不算不同结论。**

**1.2 唯一权威表述**
每个核心结论在**正文完整推导恰好一次**，该处为唯一权威表述。其余位置只允许三种形态：速查表公式行、答案节「（理由见 §x.x）」式回链、交叉引用 wikilink。

**1.3 速查表纪律**
每格只允许：公式行、定性排序（如 3°>2°>1°）、§号回链。**禁止**理由句、「因为/所以」、推导片段、口诀全文（口诀名可入）。

**1.4 答案纪律**
练习答案只回答本题：该题条件下的具体判定＋一步关键理由。通用结论重讲视为违规，改回链。

**1.5 提示块转述清除**
`> [!tip]`/`> [!warning]` 与伪 callout 引用块内，出现正文已有结论的转述（未新增信息）一律删除；确需强调的，在正文权威表述处就地加粗关键词，不另开提示块。

## 二、提示体系归一（三轨 → 一轨＋正文）

**2.1 废除伪 callout**
`> **标题**：` 独立引用块不再允许。逐个按三分法处置：
- (a) 内容为方法论/易错点且正文无此结论 → 升格为 `> [!tip]` 或 `> [!warning]`；
- (b) 内容为正文结论的强调复述 → 删除；
- (c) 内容属正文逻辑（承接句、推导步骤、「这说明……」）→ 去引用块降为正文段落。
整段推导（含公式、表格）塞入引用块视为主次颠倒，必须降回正文。

**2.2 废除 `⚠` 加粗前缀**
并入 `[!warning]`，或改为正文「注意：」引导句。图注（`*图 N …*`）不受此条约束。

**2.3 密度上限**
正式 callout（tip/warning/info/note）单讲总数 ≤ ⌈正文行数/100⌉ 且 ≤12 个；任意连续 200 行 ≤3 个。超限优先合并同类，其次删转述类。

## 三、用词负面清单

**3.1 替换表**

| 负面词 | 替换 | 说明 |
|:--|:--|:--|
| 塞进 | 填入 / 排布至 | 拟人动作 |
| 划算 | 能量上更有利 | 拟人评价 |
| 走人（离子/基团离去语境） | 离去 | 口语 |
| 不给力 | 离去能力弱 / 亲核性弱 | 网络语 |
| 抢答 | 过早下结论 | 课堂口语 |
| 翻盘 | 按语境改写（如「熵项贡献超过焓项」） | 口语 |
| 踢走 | 排出 / 弹出（保留于「通俗理解」栏时须带引号） | 拟人 |
| 纠结（试剂选择语境） | 竞争激烈 / 判定依赖试剂 | 口语（已进口诀的按 §5.3 处理） |

**3.2 判定标准**：负面词＝日常口语带情绪/拟人色彩、且可用术语无损替换。替换后损失信息的不属负面词，转 §5 处理。**扩充词条须经 §七 差错分类校验：属「词语差错」类（CY/T 266 条目 1-5）方可入表**，防止负面词表无限膨胀。

**3.3 白名单**（保留，改造前登记）：「熵税」「裸露」（术语化带引号）、「小炸弹」形状类比、「通俗理解」栏机制（须紧跟严格表述）。功能口诀的韵文用词（如 E1cb 口诀「不给力/走人」）按 §5.3 豁免。

## 四、正面表述规范

**4.1 结论句式**：规律性结论用「条件域＋判定」（「当/在……时，……」）。只给结论不给条件域视为不完整（条件与原因至少具其一；速查表除外）。

**4.2 首次定义句式**：术语首次出现给「标准名（又称别名）＋一句可操作定义」，对齐「××叫做××」（人教版）与「称为××（又称××）」（周公度）句式；此后只用标准名，不再重复定义。**同义词全篇只选一个**。规范名以全国科技名词委审定名词为准；与教材译名冲突时，讲义内自选其一并全篇统一（见 §八）。

**4.3 段落下限**：一个段落/引用块 ≥2 个完整句或 1 个完整推导步骤；单句孤立成块视为碎片段，并入相邻段（图注、公式行、表行除外）。推导链中「另一方面，」「即：」不得独立成行。

**4.4 语气**：面向学生的陈述句；允许设问引入（每节 ≤1 处）；禁用反问句做结论、禁用感叹号连用；标题不加情绪修辞。

## 五、口诀与类比

**5.1 功能性口诀**：保留，但首次出现处必须紧跟一句严谨对齐句（口诀 → 判据的翻译）；同屏口诀与等价公式/正文双编码视为重复，删其一。

**5.2 设计性类比**（熵税、裸露等）：保留，登记白名单；类比只出现一次、紧跟「严格地说……」的严格表述；不进速查表。

**5.3 口诀唯一性**：同一口诀全文逐字出现 ≤1 次；速查表可收口诀名不收全文。**口诀韵文内的用词豁免负面词表**（韵文改词破坏节奏），但豁免须登记。

## 六、段落与结构

**6.1 收尾节归一**：每讲收尾固定「本讲速查」（公式行汇总）＋「本讲小结」（主线收束，v5.3 唯一强制收尾节）；「本节总结·速查」「核心速查卡」等变体名废弃。

**6.2 章节内聚**：每节只服务一个主题句；跨主题内容拆节或移附录；不设「题外话」式引用块。

**6.3 例题解析三层**：「思路 → 关键步骤 → 结论」，层间不互重复；结论不重讲正文通用规律（回链）。

## 七、编校差错类（对接 CY/T 266—2023）

**7.1 语法性差错禁则**（CY/T 266 条目 1-11）：正文不得出现——
- **句式杂糅**：同一句内两套句式套叠（「原因是……造成的」「目的是……为目的」「围绕……为中心」「关键在于……的问题」）；
- **前后矛盾**：同节内数值、符号方向、条件表述不一致；
- **表意不明**：指代词（「它」「这个」）跨越句界仍不明确所指；
- **歧义、不合事理、语句不通**。
矛盾/歧义/表意不明属语义级判定，机检初筛＋人工复核。

**7.2 科技名词规范**（CY/T 266 条目 1-7）：化学术语采用全国科技名词委审定名；异形词（旧译、俗写、音译残留）按 §八词表替换。

**7.3 量与单位、标点、数字**（GB 3100、GB/T 15834、GB/T 15835；CY/T 266 条目 1-6/1-17）：
- 量符号斜体、单位符号正体（$p$ = 101.3 kPa）；
- 数值范围用「～」（10～20 mL），不用连字符（10-20 mL）；
- 同一量纲序列内单位符号不中英文混用；
- 顿号/逗号按并列层级使用，不同层次停顿不用顿号。

**7.4 差错率意识**：编校类条款以「机检清零＋人工抽检」为准（对齐图书编校差错率 ≤1/10000 的行业线并适配讲义文体），不设逐条零差错机械达标。

## 八、术语一致性（词表机制，借鉴 Google word list）

**8.1 规范词表**：三列式「规范词｜禁用形｜说明」；讲义全篇同一概念只用规范词一形。

**8.2 首版词表**（入表标准：只收库内实测混用＋调研确证的易混用字组；扩充走「发现混用→查术语在线→入表→全库替换」流程）：

| 规范词 | 禁用形 | 说明 |
|:--|:--|:--|
| 阿伏伽德罗常数 | 阿佛加德罗、阿伏加德罗 | 库内实测混用 3 处（2026-09-23 扫描） |
| 烯烃 | 稀烃 | 音近误写 |
| 氨（NH₃）/ 铵（NH₄⁺）/ 胺（有机 -NH₂ 衍生物） | 三字互混 | 易混用字组：氨指分子/气体，铵指阳离子及铵盐，胺指有机衍生物（苯胺、甲胺） |
| 酯（RCOOR'）/ 脂（油脂、类脂） | 互混 | 易混用字组：酯类化合物 vs 脂肪、脂溶性 |
| 氰（-C≡N 无机，氰化物）/ 腈（有机 -C≡N，丙烯腈） | 互混 | 易混用字组 |
| 羟基（-OH）/ 羧基（-COOH）/ 羰基（C=O） | 三者互混 | 易混用字组（音近：qiǎng/suō/tāng） |

**8.3 与 §3 负面词表互斥**：§3 管「语体」（口语/拟人），§8 管「名实」（异形/误写/易混）；两表不重叠，扫描器分列报告。

## 九、可验证性与出处（措辞纪律）

**9.1 断言分级措辞**：「竞赛高频」「常考」「教材级」等程度断言须可回溯——限定用于附真题出处（年份+卷号）、例题回链或题源标注的场合；裸断言改写为中性陈述或删程度词。

**9.2 Weasel 词禁用**（借鉴 Wikipedia MOS「Words to watch」）：
- 匿名权威：「研究表明」（不指明何研究）、「人们认为」「众所周知」→ 有出处写实名（「由 Hess 定律可知」「据 CY/T 266」），无出处删；
- 跳步遮蔽：「显然」「易见」「不难发现」——推导省步必须可由前文一步补全，否则补步；判定合法时可用「可得」「即得」；
- 预设断言：「值得注意的是」类引导须真有实质内容支撑，不得作语气填充。

**9.3 不确定性坦承**（费曼式）：近似模型、超纲推广、边界情形明写「这是近似，适用范围是……」「严格处理见第 x 轮」，不伪装成定则。

## 十、判定流程（改造时怎么用本规范）

1. 跑 `scan_handout_lang_audit.py` 得量化基线（含伪callout/密度/⚠/碎片/负面词/口诀重复/速查命名/重复对/术语异形词/weasel 词/杂糅特征/数值范围）；
2. 重复对逐个人工裁决：定权威表述锚点 → 删副本（「只删副本、正文加厚」）；
3. 伪callout 逐个三分法（§2.1）；
4. 负面词替换（§3.1）与术语异形词替换（§8.1 词表）分列执行；
5. weasel 词与杂糅特征人工复核（§9.2/§7.1）；
6. 收尾节改名（§6.1）；
7. 重跑脚本逐项达阈值，grep 复核被删结论的权威表述在位。
