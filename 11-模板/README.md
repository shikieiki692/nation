## 🔴 scripts/ 目录的特殊约定（务必知悉）

`11-模板/scripts/*` 被 `.gitignore` 排除，因此**新脚本默认进不了版本管理**。

- 只有 `qa/**` 与**在 `.gitignore` 中逐条反向放行**的脚本在库内。
- 新增正式工具时，**必须**在 `.gitignore` 的「格式线·闸门工具箱」段落追加一行 `!11-模板/scripts/<新脚本>.py`，否则 `git add` 会**静默跳过**。
- 校验判据：`git check-ignore -q --no-index <路径>`——**不带 `--no-index` 对已跟踪文件不报错，会误判为「OK」**。
