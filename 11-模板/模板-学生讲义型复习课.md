# 模板：学生讲义型复习课

> 📋 **使用方式**：按本模板生成竞赛复习讲义，落到 `04-课件/学生讲义/<模块名>第一轮复习.md`。
>
> 🎯 **定位**：学生**自学用**的复习讲义，覆盖整个模块（1-2小时自学量）。与[[模板-复习课]]（课堂型，有时间分配/师生互动）互补。
>
> 💡 **典型场景**：竞赛第一轮复习（按考纲逐模块过）、考前冲刺复习、模块总结。

## 制作流程（7步）

### Step 1：确定考纲范围和章节划分

```
1. 读取目标模块的考纲（如2024修订版考纲）
2. 按考纲章节划分§节（通常3-6个§节 + 1个综合串联板块）
3. 每个§节对应一个考纲大点
4. §节内按考纲小点分小节（如§4分为4.1/4.2/4.3/4.4）
5. 小节标题用考纲原文或关键词
```

**章节分配参考**（以结构化学为例）：

| §节 | 考纲 | 建议题数 | 建议配图 |
|:---|:---|:---:|:---:|
| §1 基础概念 | §4 | 3-5 | 2-3 |
| §2 核心理论 | §9 | 3-5 | 4-6 |
| §3 应用分析 | §10 | 3-5 | 5-7 |
| §4 进阶内容 | §11 | 2-4 | 2-3 |
| §5 专题 | §14 | 1-3 | 1-2 |
| §6 综合 | §15-17 | 2-4 | 8-12 |
| 综合串联 | 跨§节 | 3-6 | 2-3 |
| **合计** | | **20-30** | **30-40** |

### Step 2：填充知识速查内容

```
1. 读取对应的知识点文件（03-知识点/）
2. 提取核心表格/公式/规则（精炼速查，非全文复制）
3. 每个小节控制在200-400字
4. 重点/易错点用 > 引用块标注
5. 关键概念配图辅助理解
```

**速查原则**：
- 表格优先（对比型知识用表格最高效）
- 公式/规则用粗体或引用块突出
- 不需要详细推导，只需结论和关键步骤
- 每§节末尾附练习题

### Step 3：从题库选题

```
1. 读取题库速查（04-题库/教材习题/结构化学基础/题库格式速查.md）
2. 读取习题章节摘要（07-资料提炼/习题提炼/结构化学基础-习题章节摘要.md）
3. 按§节主题从题库选题（每§节2-4题）
4. 综合串联题从真题/汇智/上海中学等综合性来源选
5. 总题量控制在20-30题
```

**选题原则**：

| 原则 | 说明 |
|:---|:---|
| 考点覆盖 | 每个考纲小点至少1题 |
| 难度梯度 | 基础题(60%) + 竞赛题(30%) + 真题(10%) |
| 来源多样 | 至少3个来源（题库/真题/教材习题） |
| 不重复 | 相同考点不同角度，避免重复练习 |
| 综合性 | 综合串联题必须跨2+个§节 |

**来源优先级**：
1. 竞赛真题（第25-39届初赛）
2. 汇智竞赛题目 / 上海中学竞赛课程
3. 化学竞赛初赛讲义
4. 赵鑫光竞赛笔记例题
5. 无机化学例题与习题 / ABOC

### Step 4：编写答案与解析

```
1. 每题答案独立成段（### 题N）
2. 解析包含：关键公式 → 代入数据 → 计算过程 → 结论
3. 选择题：给出正确选项 + 每个选项的判断理由
4. 计算题：保留中间步骤，标注关键数值
5. 解释题：分点作答，每点简洁明确
```

**答案格式**：
```markdown
### 题N

{解题思路一句话}

{详细过程}

**答案**：{最终答案}
```

### Step 5：添加配图

```
1. 每个§节至少1-2张配图
2. 图片格式：![[filename.jpg]]（wiki-link格式，无media/前缀）
3. 图片位置：紧跟相关知识点，不要远离上下文
4. 图片必须在media/目录中（Word生成需要）
```

**图片来源优先级**：
1. media/中已验证的图片（zgxg-/weller-/puha-/11-13-等）
2. 自制matplotlib图（化学结构/图表）
3. 暂不配图（不要放错误图片）

**图片验证**（必须做）：
- 确认文件存在（PowerShell Test-Path）
- 确认内容正确（实际查看图片）
- 确认无broken引用（Grep反查）

### Step 6：答案编号审计

```
1. 检查题目编号：题1, 题2, ..., 题N（连续无重复）
2. 检查答案编号：题1, 题2, ..., 题N（与题目一一对应）
3. 检查每个§节的题号范围是否正确
4. 特别注意§节切换时的题号连续性
5. 综合串联题单独编号（题A/题B 或 题26/题27...）
```

**常见错误**：
- 答案编号错位（题5的答案标为题6）
- 重复的题号（两个题23）
- 某个§节的题号跳过（题14之后直接题16）

### Step 7：Word生成与验证

```
1. 确保所有图片在media/目录（不是.obsidian/media/）
2. 表格对齐符用------（不是:---:，后者在Word中不稳定）
3. 运行 python build-all-handout-docx.py --path "..." -v
4. 检查输出：0 errors, 图片数匹配
5. 打开Word验证排版
```

## 质量检查清单

### 内容检查
```
□ 考纲覆盖：每个考纲小点都有对应知识点和练习题
□ 知识速查：每个小节有精炼的表格/要点（非全文复制）
□ 题目质量：题目完整（含数据），不是占位符
□ 答案正确：每个答案经过验证，数值计算正确
□ 编号连续：题1→题N无跳号、无重复
□ 来源多样：题目来自至少3个不同来源
```

### 图片检查
```
□ 图片存在：所有![[...]]引用的图片在media/目录中
□ 图片正确：图片内容与文件名/上下文匹配
□ 图片位置：图片紧跟相关知识点
□ 图片数量：每§节1-3张，不过多也不过少
□ 无broken引用：Grep反查确认零遗漏
```

### 格式检查
```
□ 表格格式：对齐符用------（非:---:）
□ 无°符号：数学模式中的°已移除（Word兼容性）
□ YAML完整：frontmatter包含所有必要字段
□ 答案格式：每题独立段落，格式统一
□ 无media/前缀：wiki-link格式 ![[filename.jpg]]（不是 ![[media/filename.jpg]]）
```

## 已知陷阱

| # | 陷阱 | 后果 | 正确做法 |
|:---:|:---|:---|:---|
| 1 | 答案编号错位 | 学生对答案时混乱 | 每次修改后重新审计编号 |
| 2 | 图片文件名≠内容 | 放了错误的图 | 必须实际查看图片验证 |
| 3 | zgxg-源目录文件腐蚀 | 从源目录复制得到错误图片 | 优先用media/中已验证图片 |
| 4 | 表格:---:在Word中不稳定 | 排版错乱 | 统一用------ |
| 5 | 数学模式中的°符号 | Word生成报错 | 生成前批量移除 |
| 6 | 综合串联题难度过高 | 学生无法独立完成 | 综合题也要有梯度，先易后难 |
| 7 | 知识速查太详细 | 篇幅过长，失去"速查"意义 | 每小节控制在200-400字 |
| 8 | 题目来源单一 | 练习覆盖面不足 | 至少3个来源，优先真题 |
| 9 | 图片用media/前缀 | Obsidian显示正常但Word生成失败 | 统一用 ![[filename.jpg]] |
| 10 | 答案有占位符 | 学生无法核对 | 每个答案必须完整 |
