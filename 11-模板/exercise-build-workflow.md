# 习题组构建工作流

> **用法**：构建或修改练习题组时，按此流程执行。每步完成后打勾确认。
> **适用范围**：所有第一轮/第二轮练习题组（配位化合物、分子结构、晶体结构等）

---

## 一、标准构建流程（8步）

### Step 1: 需求分析
- [ ] 确定专题范围（如"配位化合物基础"）
- [ ] 确定题量目标（建议60-100题）
- [ ] 确定难度分布：⭐基础15-20% / ⭐⭐提升30-35% / ⭐⭐⭐挑战25-30% / ⭐⭐⭐⭐拓展15-20%
- [ ] 确定来源分布：自编≤30% / 教材15-20% / 教辅≥25% / 真题≥20%

### Step 2: 来源选题
- [ ] **重叠检查**：读取对应讲义文件，列出已有题目来源标签，确保新题不重复
- [ ] **来源多样化**：至少覆盖3种不同来源（教辅、教材、真题等）
- [ ] **真题占比**：初赛真题≥15%，决赛真题需标注"挑战"
- [ ] **来源标签规范**：每道题标注 `> **来源**：[具体来源]`

### Step 3: 题面编写
- [ ] **方程式核验**：涉及化学方程式/离子方程式的题目，逐原子验证守恒（H/O/N等）
- [ ] **数学公式**：使用 `$...$` 行内LaTeX，化学式用 `\ce{...}` 或 `\mathrm{...}`
- [ ] **子题编号**：(a)(b)(c) 或 (1)(2)(3) 保持一致
- [ ] **难度标注**：每题用⭐标注难度等级

### Step 4: 答案编写
- [ ] **逐题对齐**：每道题的答案必须对应正确的题号
- [ ] **方程式核验**：答案中的方程式同样需要逐原子验证
- [ ] **CFSE归因**：不同氧化态比较→归因电荷效应，不说"CFSE大"
- [ ] **d电子数验证**：构型/磁性答案需与d电子数交叉验证

### Step 5: 索引构建
- [ ] **知识点索引**：列出每个知识点对应的题目编号
- [ ] **来源索引**：列出每道题的来源标签
- [ ] **交叉验证**：索引中的题号必须与实际题目一一对应

### Step 6: 交叉核验（5B）
- [ ] **读取错误模式知识库**：`04-题库/教学改编题/无机和结构化学/错误模式知识库.md`
- [ ] **逐条核验**：按知识库中的规则逐条检查
- [ ] **OCR可信度**：构型类OCR结果必须与d电子数交叉验证
- [ ] **答案-题目对齐**：确认答案区的题号与题目区的题号完全匹配

### Step 7: 变更日志
- [ ] 在文件末尾添加变更日志，记录：
  - 修改日期
  - 修改内容摘要（如"替换Q4/Q5/Q6来源"）
  - 修改原因（如"与讲义重叠"）

### Step 8: Word生成
- [ ] **输出位置**：统一使用 `00-首页/学生讲义Word/`
- [ ] **图片验证**：生成后检查Word文件中的图片数量是否与源文件一致
- [ ] **公式验证**：检查数学公式是否正确渲染

## 二、替换题目的检查清单（四件套）

> **每次替换题目时，必须同步执行以下4步，缺一即系统性错位。**

| 步骤 | 操作 | 验证方法 |
|:---|:---|:---|
| 1. 更新题面 | 替换 `### 第N题` 下的内容 | 对比新旧题面 |
| 2. 更新答案 | 在 `## 参考答案` 区域找到对应题号，替换答案 | 答案中的子题编号与题面一致 |
| 3. 更新来源索引 | 在 `## 题目来源索引` 表格中找到对应行，更新来源 | 来源标签与题面中的 `> **来源**` 一致 |
| 4. 更新变更日志 | 在文件末尾添加修改记录 | 包含日期、题号、修改内容 |

**额外步骤**（如适用）：
- 更新知识点索引（如果新题涉及不同的知识点）
- 更新frontmatter中的 `question_count`（如果题量变化）

## 三、来源选题规则

### 3.1 来源分布要求
| 来源类型 | 建议占比 | 备注 |
|:---|:---:|:---|
| 自编题 | ≤30% | 用于填补特定知识点空白 |
| 教材习题 | 15-20% | 标注具体教材和章节 |
| 教辅书籍 | ≥25% | 赵鑫光、程鹏等竞赛教辅 |
| 初赛真题 | ≥15% | 标注届次和年份 |
| 决赛真题 | ≤10% | 必须标注"挑战"难度 |

### 3.2 禁止事项
- ❌ 来源标签与讲义已有题目重复
- ❌ 全部来自单一来源
- ❌ 初赛题组中无初赛真题
- ❌ 决赛真题不标注"挑战"

### 3.3 推荐教辅来源
- 赵鑫光《无机化学竞赛题集》— 例题、选择题、综合题
- 程鹏《无机化学》— 例题与习题
- 《无机化学例题与习题》(第4版) — 教材配套
- 《普通化学原理》(第4版) — 习题（注意与讲义重叠）

## 四、方程式验证规则

### 4.1 逐原子核验清单
对于每个化学方程式/离子方程式：
- [ ] 左右两侧每种元素的原子数相等
- [ ] 电荷守恒（左侧总电荷 = 右侧总电荷）
- [ ] 常见陷阱：
  - HCHO银镜反应：HCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → HCOO⁻ + 2Ag↓ + 4NH₃ + 2H₂O
  - 配平时注意NH₃和H₂O的系数
  - 有机反应中C的氧化态变化

### 4.2 常见错误模式
| 错误类型 | 案例 | 正确做法 |
|:---|:---|:---|
| H不平衡 | 银镜方程式左侧H数≠右侧 | 逐个计数H原子 |
| 电荷不守恒 | 离子方程式左右电荷不等 | 计算每侧总电荷 |
| 漏写产物 | 忘记写H₂O或NH₃ | 列出所有产物再配平 |

## 五、图片路径规范

### 5.1 支持的图片路径模式
| 路径模式 | 示例 | 说明 |
|:---|:---|:---|
| `![[media/...]]` | `![[media/octahedral.jpg]]` | 标准media目录 |
| `![[mineru/...]]` | `![[mineru/02-真题解析/...]]` | mineru OCR图片 |
| `![[06-外部资料导入/...]]` | `![[06-外部资料导入/...]]` | 外部导入资料 |

### 5.2 管线行为
- `_strip_non_image_wikilink_lines()` 检查所有 `![[` 前缀的行
- 非图片的wiki链接（如 `[[配合物]]`）会被移除
- 图片嵌入（如 `![[media/test.jpg]]`）会被保留

### 5.3 新增图片时的约定
- 图片文件名使用英文（避免中文路径问题）
- 优先放在 `media/` 目录下
- 在Markdown中使用 `![[media/filename.ext]]` 格式嵌入
- 图片描述文字放在 `> **结构参考**：` 块引用中
