# 讲义练习区样板格式规范 v1.0

> 2026-09-19 基建战 A2 定稿。适用范围：`04-课件/学生讲义/` 全部现役讲义（排除 `_归档/`、索引/README）。
> 本规范是 A4 `validate_handout.py` 闸门的实现依据；与样板讲义（有机人名反应系统归类、原子结构、分子结构基础）现状对齐。

## 一、题目编号

| 题型 | 格式 | 示例 |
|:---|:---|:---|
| 普通练习题（无题名） | `**N.** 题干` | `**3.** 说明盖斯定律的应用条件。` |
| 带来源标签题 | `**N.** [来源] 题干` | `**1.** [普化原理12-1] 写出下列离子的核外电子构型…` |
| 真题挑战（整行加粗题名） | `**N. [标签] 题名**`，题干另起行 | `**26. [第34届初赛] 晶胞参数推断元素与化学式**` |

- 编号从 1 起连续，全练习区一套编号（跨分级小节连续，不重排）；答案区 `**N.**` 与题目一一对应。
- 来源标签统一半角方括号 `[...]`，禁用全角括号 `（第40届…）` 直接跟在编号后。
- 题内小问用 `(1)(2)` 或 `**N.M**` 式，不占用题目编号序列。
- 练习/答案区内的步骤列表、学习目标编号列表**不是**题目，不加粗（闸门按「位于练习/答案节内 + 行首」识别）。
- 「练 N」「练习 N」式编号一律改造为 `**N.**`。

## 二、分级标题

- 形态：`### N.N 段名（M 题）`，编号与所在 `##` 节号一致（`## 六、练习题` → `6.1/6.2/6.3`）。
- 题数 M 必须为该段实际题数（虚标实数化，Session 4 已立例）。
- 禁用 emoji。
- 段名按**内容真实**映射，不做一刀切：
  - 第一段一律「基础巩固」；
  - 第二段「竞赛入门」或「提高训练」均可（现状保留）；
  - 第三段含真实真题（有届次标注）→「真题挑战」；纯自编难题 →「挑战题」/「综合挑战」保留现状命名。
  - 闸门校验：段名含「真题」的段落内应存在 `[届次]` 或来源标签。

## 三、答案区

- 节名不强制统一（「参考答案 / 参考答案与提示 / 练习题答案 / 练习参考答案」均合法），闸门按标题含「答案」识别。
- 答案编号格式必须与题目一致：`**N.** 答案内容`。
- 答案条数与练习题数配平；答案内嵌于练习节（「练习题答案」节）的形态合法。

## 四、选题口径引言

- 可选项。已有则保留原样（选题口径/编排说明/使用建议/训练顺序建议/自编声明五种形态均合法）；缺省不强制新增。

## 五、FM 字段（A5 落地）

- `exercise_count` = 练习区纯练习题数（不含例题、不含题内小问）。
- 有练习题的讲义必填；速查/教师版/合集/附录类无练习节讲义可缺省或为 0。
- `exercise_levels` 若填写须与分段实数一致。

## 六、豁免形态（闸门不报错）

- 无练习节讲义：速查卡、教师增强版、学生用合集、附录、真题小问总集等（以「综合串联题」等不含「练习」的节名承载题目的，闸门纳入识别后同样校验）。
- 有题无答案节：`validate_handout.py` 报 WARNING（登记待补清单，见 2026-09-19 日志），不作为 ERROR 阻断。

## 七、闸门校验口径（A4 实现要点）

1. 练习节定位：标题含「练习」，或含「综合串联题」（节名变体白名单）。
2. 答案节定位：标题含「答案」且不含「练习」（内嵌式取练习节内含「答案」子标题之后的内容）。
3. 编号识别只认 `**N.**` / `**N. [标签] 题名**` 两种（统一后不再需要裸编号歧义消解）。
4. 扫描文件数为 0 → 直接 FAIL（防静默失效）；输出受检数。
