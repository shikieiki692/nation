# 模板-专题课（题目驱动专题课）

> **定位**：专题课是**桥梁深化单元**——承载"必须显式补出、但不足以成为独立章"的内容（`[[备课思路/六大新课大章节总表]]` §10.2 点名：结构表征与波谱桥、配位光谱与对称性桥），或对单一大章做专题击破。
> **一句话**：**以真题开场、以真题收束**；知识拆解只为把真题讲透，不为铺教材。
> **依据**：`[[11-模板/规范/竞赛驱动课件制作框架]]` §1、§2；事实标准取自现役 6 讲（`第一轮结构化学专题课-01~06`）。

## 一、frontmatter（必挂）

```yaml
---
title: 第N轮XX专题课-MM-主题
type: 课件
role: "专题课"
lesson_type: 题目驱动专题课
audience_level: 基础班（第一轮）    # 或 提高班/冲刺班（第二/三/四轮）
duration: 45min                    # 45min 或 60min（按真题精练量定）
source_lectures: []                # 本讲挂靠的小章节讲义
related_kps: []                    # 关联知识点页
exam_syllabus: []                  # ★ 考纲条目（→ 02-考纲条目/）
exam_evidence: []                  # ★ 命题趋势依据（→ 近五年真题命题拆解分析）
exam_trend: ""                     # ★ 一句话：本专题近五年"变了什么"
exam_weight: ""                    # ★ 本专题在初赛中的权重判断
problem_count: 0
real_exam_count: 0                 # 本讲引用的真题数
tags: [课件, 专题课, 竞赛]
---
```

> ★ 三项 `exam_*` 是**竞赛驱动的硬字段**，与章后层（`§11.4`）同源，⛔ 不得留空。

## 二、正文骨架（四段式，时间轴固定）

### `## 一、开场·真题直击（10 min）`
- 直接抛 **1 道真题**（优先最近届次，标注届次＋题号＋分值），点出本专题要解决的核心矛盾。
- 真题须**回链题卡**（写法见 §三）。
- 结尾给出本讲的"主问题"一句话，供学生带着问题进入第二段。
- ⛔ 不在此处展开讲解（只呈现与设问）。

### `## 二、知识拆解（15 min）`
- 只拆解**回答第一段那道题所必需**的方法/机制/判据，不铺完整教材。
- 承接考纲：显式列出本段对应的考纲条目（`exam_syllabus`）。
- 输出形式：判据表、对比表、流程图、机理链（避免成段叙述堆积）。
- 若引用教辅/教材，标注出处（落实框架 §2 依据④）。

### `## 三、真题精练（20–30 min）`
- **≥3 道真题**，难度递进；逐题格式：
  ```
  ### 真题N：<主题>（<届次> 第M题，<分值>分）
  > 📄 **题库原卡**：<双链指向 04-题库/真题/…>
  ```
- 逐题给「**解题链 / 陷阱 / 迁移价值**」三栏（对齐章后习题课 `§11.4` 的标准）。
- 时间分配按真题量定：3 题用 20 min，4 题及以上用 30 min（`duration` 相应取 60min）。

### `## 四、总结·速查卡（5 min）`
- 输出**一张决策树/速查卡**（判断顺序 / 方法选择 / 边界提醒）。
- 跨模块综合课可命名为「总结·做题决策树」（现役 06 讲做法）。
- 速查卡须能被学生课后独立复用。

## 三、真题回链写法（本库硬规范）

**场景 A · 标题行（不在表格内）——不转义**：

```markdown
### 真题1：晶体场分裂能比较（第39届 第5题，18分）
> 📄 **题库原卡**：[[04-题库/真题/第39届初赛/无机和结构化学/题-039-5-…|题-039-5]]
```

**场景 B · 表格单元格内——别名分隔符必须转义**：

```markdown
| 届次 | 回链题卡 |
|:--|:--|
| 39 | [[04-题库/真题/第39届初赛/…\|题-039-5]] |
```

⚠️ 回链前必须 `find` 出**真实路径**：35/39/40 届带学科子目录；36 届第二场为 `第36届初赛第二场/`、命名 `题-036b-N`。

**学生版规则**：若派生"学生版-无解析"合集，⛔ **不回链含答案的题库卡**（等于给学生答案入口）。

## 四、验收清单（可机检）

- [ ] FM 含 `lesson_type` / `audience_level` / `duration` ＋ `exam_syllabus` / `exam_evidence` / `exam_trend`
- [ ] 四段式完整，标题含时间轴（`（N min）`）
- [ ] 真题数 ≥4（开场 1 ＋ 精练 ≥3），逐题回链，`os.path.exists` **100% 可解析**
- [ ] 每道精练真题有「解题链 / 陷阱 / 迁移价值」
- [ ] 无自编题；表格列数一致
- [ ] 三闸门：`js-yaml` → `validate_kb` → `render_gate` 全绿
- [ ] 体量参考 23–32 KB（现役 6 讲实测区间）
