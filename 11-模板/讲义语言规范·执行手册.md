## 一、精改档工序（A 档逐份，约 40~60 分钟/份）

1. **通读全文**（铁律：机检清单只当线索不当判据；本步骤不可跳过——配位件 3 处漏检、复习件误判均靠通读纠正）；
2. **形态变体人工扫描**（规范 §2.1c）：对全文 `^>` 引用块行目视过滤——括号插语标题/无冒号标题/行尾缀字块是机检盲区；
3. **语言轨改造**：Write 成 .py 脚本（**禁 bash 内联**，见 §四防坑），结构固定为「锚点预检（全部断言先行）→ 操作按行号降序 → 原子写盘」；降正文策略按规范 §2.1b 选 strip/keep_title；
4. **内容轨**（三轴）：推导覆盖（理论节必须有「为什么」，给结论不给来历=病灶）／例题完整性＋**因果链自查**（§6.1b：数值对≠论证对）／讲解深度；新增内容必须带素材锚点（库内提炼/KP 页/教材 OCR/题库）＋数值脚本先复算；
5. **收尾节补全**：「本讲速查」命名归一＋「本讲小结」（§6.1 三要求，insights 字段优先展开）；
6. **v1.2 出版层落实**（新写/改造件均不得跳过）：
   - **图序连续**＋**图被正文引用**（§12.2）：先 grep「见图 N」——**为 0 时逐图按图注语义人工定位锚点补引用**（防坑 30/31；表格内引用放单元格内＝防坑 36）；
   - **表题**（§12.1）：读者不读上下文能否知道这表列什么，不能则补；
   - **连接号三态**（§7.5）与**数字用法**（§7.6）扫一遍；
   - **反应式配平与电荷守恒自查**（§11.2）＋**危险试剂安全边界**（§14）；
7. **机检归零验证**：重跑扫描器，伪callout=0 即完成（S0 白名单后无需人工对照豁免）；
8. **docx 双版本重出**＋**产物名归一**（H1 含 LaTeX/特殊字符的必改短名，见 §四）；
9. **闸门**：validate_kb --changed → 手动 render_gate full（>1200 行先 **allowlist 预登记**再 commit）；
10. **清稿抽查**：教师区/负面词剥离＋新增内容在位＋oMath 计数。**抽查必须双版本都查**（清稿版会剥离含 wikilink 的表格行，防坑 37）；
11. **commit**（临时索引链 GIT_INDEX_FILE，裁决明细入 message）→ **主索引对齐** → 收尾核验本次路径 D=0/MM=0。

## 二、轻扫档工序（B 档）

同 §一，但**不通读全文**：只裁决机检清单真病灶（伪callout 12~24 中扣除豁免底数的部分）＋⚠ 归一＋小结补齐＋速查改名。每份约 10~15 分钟。

## 三、达标检查轮工序（C 档，数学工具模式）

1. 机检复扫确认伪callout/⚠ = 0；
2. **三轴抽查**：每份抽 1~2 个核心推导段目检＋确认例题/练习答案体系在位（不重做历史批次已做的数值复算）；
3. 小结补齐＋速查节改名（附录/速查卡性质文件**豁免小结**——速查性质非「讲」）；
4. docx 双版本重出＋闸门＋commit（可多份合一 commit，如 be4abcc36 七讲一批）。
单份约 5~10 分钟，可大批量推进。

## 四、防坑清单（全部实战踩过，逐条有案例）

| # | 坑 | 对策 |
|:--|:--|:--|
| 1 | bash 内联转义三连坑：`\n`→字面 `/n`、`$(...)` 命令替换吞文本、dict 相等性判集合归属误判 | **含正则/反斜杠/非 ASCII/替换逻辑的脚本一律 Write 成 .py 再跑**，不内联 |
| 2 | pre-commit 渲染闸门 75s 硬预算，>1200 行讲义必 SIGTERM | 手动 `render_gate.py --changed` 拿 full 真值 → **allowlist 预登记** → commit |
| 3 | 体检报告 md（09-审计报告）也会被 pre-commit 扫描拉长耗时 | add 时知悉；必要时报告文件随批入 allowlist 语境 |
| 4 | H1 含 LaTeX/特殊字符（如 `d[A]/dt`、`$S=k-ln W$`）→ docx 文件名残片且与手动短名并存 | **每次重出后核对产物目录并改名归一**；mtime 判属注意（新产物可能比旧短名新） |
| 5 | 暂存区被并行会话注入（staged 他人文件/他人已提交文件的注删） | 临时索引链 `GIT_INDEX_FILE` + read-tree HEAD + 只 add 本会话文件；**每件提交后对本会话路径重新 git add 对齐**；收尾查 D=0/MM=0 |
| 6 | 幻影 D/MM（临时链提交后主索引漂移） | 收尾对本会话全部路径逐条 `git add` 一次 |
| 7 | 机检数字≠真病灶 | 豁免底数 ≈7~12/份（frontmatter 元信息/来源/题干行）；S0 白名单后「机检归零=完成」成立 |
