## 三、标题规范

### 3.1 讲义标题（`#`）

**统一格式**：`# 第N讲：标题` 或 `# 主题名：子标题`

例外规则：
- 有讲次编号的 → `# 第N讲：标题`（如 `# 第十讲：滴定分析`）
- 无讲次编号的自编讲义 → `# 主题名`（如 `# 晶体结构基础`）
- 跨讲次整合的 → `# 主题名：子标题`（如 `# 热能篇：化学热力学基础`）

### 3.2 节标题 (`##`)

- 一级阿拉伯数字编号：`## 一、标题` / `## 二、标题`
- 学习目标：固定 `## 学习目标`
- 作业/练习：固定 `## 课后练习` 或 `## 思考题`

### 3.3 子节标题 (`###`)

- 编号格式：`### N.M 标题`（N = 节号，M = 子节号）
- 示例：`### 2.1 SN2（双分子亲核取代）——一步协同`


## 五、图片规范

### 5.1 图片嵌入

> **权威口径（2026-09-07 收敛）**：图片一律用 `媒体仓库/` 的 64 位哈希名，与 [[00-首页/讲义生产SOP与双向映射规范]] §3.2/3.3 及 AGENTS.md 一致。
> 本规范此前的 `media/filename.jpg` 写法**已废止**，仅为存量遗留。全库实测：498 处引用中 497 处已是哈希名、0 断链。

```markdown
![[8b075f14f4228e2c22b24bced77b231556bc201ae54133dd9265b0de4969f593.jpg]]
*图 N 对象+用途*
```

- 引用格式 `![[<64位哈希>.jpg]]`，**禁止子目录前缀**；`media/`、`mineru/`、`06-外部资料导入/` 前缀仅存量遗留，新增禁用、大修时归一
- 替代文本（alt）**不写**：Word 导出 alt 不显示，且题库审计黑名单要求图片无 alt；存量 176 处带 alt 不溯及，同篇内保持一致即可
- 图注用斜体 `*` 包裹，格式：`*图 N 对象+用途*`（≤30字符，来源不写在图注中）
- 图注字号 9.5pt，居中

### 5.2 图片命名与取图

- 引用名以 `媒体仓库/` 的哈希名为准，Obsidian 全库自动解析，无需相对路径
- 新图先入库 `媒体仓库/` 取得哈希名，再写入讲义
- 找图入口：[[00-首页/00-图谱雷达总入口]]（学科分流索引）→ 复用优先于新找（[[00-首页/规则-配图来源优先级]]）
- 存量命名（`11-13-orbital-shapes-s-p-d.jpg` 等教材图号名）保留，随大修迁哈希名

## 七、公式规范

### 7.1 行内公式

```markdown
能量 $E = -\dfrac{13.6}{n^2}\ \mathrm{eV}$
```

- 使用 `$...$` 包裹
- 单位和纯数字用 `\mathrm{}` 包裹
- 化学式用 `\mathrm{}` 包裹（避免被当作变量斜体）

### 7.2 展示公式

```markdown
$$
\Delta G^\theta = -RT \ln K^\theta
$$
```

- 使用 `$$...$$` 包裹（不要用 `\[...\]`）
- 需要编号时在公式后加 `\tag{N}`

### 7.3 化学式

- 简单化学式用 `\mathrm{H_2O}` 或直接写 H₂O（有 Unicode 下标）
- 复杂反应式用 `$$...$$`  + `\ce{}`（预处理脚本会转为 `\text{}` 兼容 OMML）
