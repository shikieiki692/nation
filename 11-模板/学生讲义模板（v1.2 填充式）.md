# 学生讲义模板（v1.2 填充式）

> **用法**：复制本模板下半部分「模板正文」为新讲义，把 `{{...}}` 占位替换为实际内容，删除所有 `<!-- -->` 注释块。
> **分工**：生产流程看 [[00-首页/讲义生产SOP与双向映射规范]]；格式细则（数学/化学式/callout/表格/PDF 管线）看 [[11-模板/MD讲义格式参考（原子结构样板）]]；找图看 [[00-首页/图片索引]] + [[00-首页/规则-配图来源优先级]]。
> **定位（v1.2）**：学生讲义是**学生侧完整自学材料**——正文自足（概念讲透、题目三件套、随题解析），教师向管理信息只进 frontmatter 或 HTML 注释。

## 图片利用要点（本模板相对旧样板的强化）

1. **先规划后写作**：frontmatter 下方注释块里的「配图规划表」在起草前先填，每图定一个教学功能（定义/结构/对比/读图推理），不允许拿重复图充版面。
2. **找图顺序**（详见 [[规则-配图来源优先级]]）：[[图片索引]] 精标表 → 同主题存量讲义的已配图片（候选池）→ mineru/教材 OCR/真题原图 → 库内其他 → 外部 → Excalidraw/Mermaid（仅限逻辑型图，禁伪造教材级结构图/机理图/谱图/晶胞图）。
3. **落地规则**：来源仓（mineru/OCR）的图复制到根目录 `media/` 并改稳定英文名（`topic-keyword-purpose.ext`）后才进讲义；正文只写 `![[media/...]]`；图注 `*图 N 对象+用途*` ≤30 字，来源说明不进图注。
4. **写完对账**：`image_count` 与正文 `![[media/...]]` 数量一致；`has_images` 如实。
5. **题号链接统一 `[[全路径|别名]]`**（题库存在 Ch05/05-01 与 题-0XX 多套命名体系，短名链接有撞名风险）。
6. **长讲义交叉引用**：900+ 行讲义用「见例 N / 见练习 N」双向导航，概念章与题目互相指向。
7. **数据表槽位**：热力学/平衡类讲义用文末可选「附：数据表」节集中放查用数据，长题干不塞数据。
