# 学生讲义模板（v5.3 统一版）

> **用法**：复制本模板下半部分「模板正文」为新讲义，把 `{{...}}` 占位替换为实际内容，删除所有 `<!-- -->` 注释块。
> **分工**：生产流程看 [[00-首页/讲义生产SOP与双向映射规范]]；格式细则看 [[11-模板/MD讲义格式参考（原子结构样板）]]；升级方法看 [[04-课件/学生讲义/讲义升级模式-原子结构样板]]；课程结构看 [[11-模板/学生讲义内容结构规划]]；找图看 [[00-首页/图片索引]] + [[00-首页/规则-配图来源优先级]]；练习题分级看 [[11-模板/模板-习题三级分类]]；配套习题集看 [[11-模板/模板-习题组]]。
> **定位（v5.0）**：学生讲义是**学生侧完整自学材料**——正文自足（概念讲透、公式推全、题目三件套、随题解析），教师向管理信息只进 frontmatter 或 HTML 注释。
> **v5.3 核心升级**：在「写作前信息收集」中新增**步骤0：备课框架与深度边界**（最高优先级）——先读第一轮总体备课框架、轮次深度切分总表、讲义改造执行表，确认深度上限、三层结构（主讲/略讲/后置）和主问题线。这是讲义质量的决定性步骤。

## 零、写作前信息收集（必做）

> **核心原则**：讲义不是凭空写的。动笔前必须从知识库的多个维度收集素材，形成完整的教学设计底稿，再进入正文写作。这一步决定了讲义的质量上限。

### 0.1 信息收集清单

写任何一份讲义之前，**必须按顺序读取并综合以下 7 类知识库资源**：

| 序号 | 资源类型 | 知识库位置 | 读取目的 | 产出 |
|:---:|:---|:---|:---|:---|
| ① | **备课框架与深度边界** | `备课思路/` 下的三个权威文件（见下方详解） | 确定本讲在整条课程链中的位置、覆盖范围、深度上限和分层口径 | 深度边界声明（📝🌟🔒）、后置内容清单、讲义三层结构（主讲/略讲/后置） |
| ② | **考纲** | `02-课纲/` 相关文件 | 明确本讲覆盖哪些考纲条目、考试深度要求 | frontmatter `考纲覆盖` 字段；深度边界声明 |
| ③ | **知识点** | `03-知识点/` 对应 KP 文件 | 获取核心概念的准确定义、关键公式、已有表格/图示 | 正文概念陈述、公式推导的起点、KP wikilink 锚点 |
| ④ | **教学洞察** | `12-教学洞察/` 相关文件 | 获取学生常见误区、教学难点突破策略、最佳教学顺序 | 易错提醒、理解要点、主线导航表的设计依据 |
| ⑤ | **备课大纲** | `04-课件/备课大纲/` 对应大纲文件 | 获取课时安排、知识点教学顺序、课堂活动设计 | 主线导航表、课堂建议顺序 |
| ⑥ | **资料提炼** | `07-资料提炼/` 对应提炼文件 | 获取教材原始内容的结构化提炼（关键定义、例题、数据表） | 正文引用素材、数据表槽位、例题来源 |
| ⑦ | **教材原文** | `06-外部资料导入/` 对应教材 OCR 或 PDF | 核实关键陈述的原始表述、获取推导细节、补充提炼未覆盖的内容 | 教材引用标注、公式推导的精确步骤 |

### 0.2 备课框架与深度边界——最重要的第一步

> ⚠️ **这是写讲义前必须首先读取的资源**。它决定了讲义的**深度上限**和**内容边界**——哪些必须讲透、哪些只需提及、哪些明确后置。

**必须读取的三个权威文件**：

| 文件 | 知识库路径 | 决定什么 |
|:---|:---|:---|
| **第一轮总体备课框架** | `[[备课思路/第一轮总体备课框架]]` | 本轮覆盖哪些专题、每个专题的课时分配、深度边界五原则、三条常驻线程 |
| **轮次深度切分总表** | `[[备课思路/轮次深度切分总表]]` | 每个考纲条目在第几轮讲到什么深度（📝/🌟/🔒）、后置到哪里、跨轮次边界权威依据 |
| **讲义改造执行表**（如有） | `[[备课思路/第一轮化学原理讲义改造执行表]]` 等 | 本讲的改造方向：主问题线是什么、三层结构怎么分、例题怎么跟知识点走 |

**从这三个文件中提取的关键信息**：

1. **深度边界**：本讲对应的考纲条目在第一轮应达到什么深度（对照轮次深度切分总表的 📝/🌟/🔒 标记）
2. **覆盖范围**：《普通化学原理》对应章节是否在本轮全覆盖（对照第一轮备课框架 §0.1 全景表）
3. **三层结构**：哪些是课堂主讲（必须讲透）、哪些是略讲/选讲（提一句）、哪些是后置内容（明确写"后置到第二轮/第三轮"）
4. **主问题线**：本讲围绕哪一条核心问题展开（对照讲义改造执行表 §2.1）
5. **超越普化的内容**：结构化学专题（分子结构、晶体、配合物）可达到《无机化学》甚至《结构化学基础》入门水平

**第一轮深度边界总原则**（摘自备课框架 §零）：

| 原则 | 第一轮讲到哪里 | 第一轮禁止提前展开 |
|:---|:---|:---|
| 普化主线全覆盖 | 《普通化学原理》12/15 章系统落地 | 不因课时紧张而砍专题 |
| 工具先于理论完整性 | 会用公式/模型解决基础题 | 完整理论推导、模型边界证明 |
| 结构专题可超越普化 | 分子结构到 MO+离域π；晶体到七大晶系+Pauling；配合物到 CFT+CFSE | 群论、Tanabe-Sugano、完整配位场 MO |
| 基础班结论后置 | 问题→铺垫→推理→结论 | 直接把结论堆到开头 |
| 同一 KP 分轮次使用 | 第一轮只取入门直觉和基础应用 | 把决赛内容平铺进第一轮 |

### 0.3 各类资源的使用原则

**考纲**：
- 考纲条目决定讲义的**覆盖范围**和**深度上限**
- 不在考纲内的内容标记为 `🌟` 或 `🔒`，不作为正文主线
- frontmatter 中的 `考纲覆盖` 字段必须与实际内容一致

**知识点（KP）**：
- KP 文件是概念定义的**权威来源**，正文陈述必须与 KP 一致
- 正文中每个核心概念首次出现时用 `**加粗**` 并附 `[[KP名]]` 锚点
- KP 中的公式/数据可直接引用，但需标注来源
- **注意**：KP 是锚点增强，不是内容替代品——正文必须把概念讲透

**教学洞察**：
- 教学洞察中的「学生误区」直接转化为正文的 `> **易错提醒**` callout
- 教学洞察中的「突破策略」转化为正文的「物理直觉/类比」段落
- 教学洞察中的「教学顺序建议」影响主线导航表的设计

**备课思路/大纲**：
- 大纲中的课时分配决定讲义各章的**篇幅比例**
- 大纲中的知识点顺序决定讲义的**章节排列**
- 大纲中的「上下讲衔接」直接填入教师信息区

**资料提炼**：
- 提炼文件是教材内容的**结构化摘要**，比直接读教材更高效
- 提炼中的例题和数据表可直接作为讲义素材
- 当提炼内容不足时，才回溯到教材原文补充

**教材原文**：
- 用于**交叉验证**提炼内容的准确性
- 用于获取提炼中省略的推导细节
- 核心概念的陈述性内容**优先直接引用教材原文**，并标注出处
- 格式：`（参考教材《{{书名}}》第X版 §X.X.X）`

## 一、知识点模块写作规范（§一 ~ §N 的每一节）

### 1.1 每个小节的标准写作结构

每个 `### X.Y {{小节标题}}` 应按以下顺序组织内容，**缺一不可**（可省略的已标注）：

```
① 一句话定义/引入（必写）
② 教材引用陈述（必写）
③ 物理直觉/类比（强烈建议）
④ 表格/图示/对比（视内容而定）
⑤ 公式及其推导（如有公式则必推）
⑥ 嵌入式「练一练」（每小节至少1道）
⑦ 理解要点 + 易错提醒（必写）
```

### 1.2 各环节写作要求

**① 一句话定义/引入**

概念首次出现时，用 **加粗** 标注中英文名称，紧跟一句话定义。定义必须精准、可直接引用。

> 示例：
> **晶格能**（lattice energy，U）：相互远离的气态正离子和负离子结合成 1mol 离子晶体时所释放的能量。

**② 教材引用陈述**

核心概念和定律的陈述性内容，**优先直接引用教材原文或原文的忠实改写**，并标注教材出处。不允许用含糊的"教材上说……"代替具体内容。

> 格式：`（参考教材《{{书名}}》第X版 §X.X.X）` 或在段落末尾注明。
>
> 示例：
> > **Pauling 电负性标度**：以 F = 4.0 为基准，通过键能数据定义。对于双原子分子 A-B，$\chi_A - \chi_B = 0.102\sqrt{\Delta}$，其中 $\Delta$ 为键能偏差（kJ/mol）。（参考《普通化学原理》第4版 §12.2.3）

**③ 物理直觉/类比**

每个核心概念都应给出一句"为什么"或"怎么理解"的直觉解释，帮助学生建立物理图像，而不只是记住定义。

> 示例：
> > **物理直觉**：键级越大→电子云重叠越多→键长越短→键能越大→键越稳定。就像两个人握手——握得越紧（电子云重叠越多），要掰开就越难（键能越大）。

**④ 表格/图示/对比**

- **对比表**：概念容易混淆时，用表格并列对比。表头用明确的维度（特征/键型/实例）。
- **数据表**：定量规律用表格展示，附趋势说明。如"从 NaF→NaI，U 略降→熔点略降"。
- **图示**：按图片利用规范（见下方§五）插入配图，图注 ≤30 字。

**⑤ 公式及其推导**

见下方§二「公式推导写作规范」。

**⑥ 嵌入式「练一练」**

每讲完一个知识点小节，嵌入 1~2 道即时练习。格式：

```markdown
> **练一练**：{{题目正文，要求具体、可操作、有明确数据或条件}}
>
> **答案**：{{简要解题过程 + 最终答案}}
```

要求：
- 题目必须**直接应用刚讲完的知识点**，不涉及后续内容
- 难度为"看懂了就能做"的级别（对标 🌱 基础巩固）
- **来源优先**：普通化学原理课后习题 > 上海中学竞赛教程习题 > 自编
- 标注来源：`[普化原理X-X]` 或 `[上海中学第X分册]` 或自编不标

**⑦ 理解要点 + 易错提醒**

每个小节末尾用 callout 给出：

```markdown
> **理解要点**：{{本节最核心的 1~2 条规律，用一句话概括}}

> **易错提醒**：{{最常见的错误做法 → 正确做法}}
```

## 二、公式推导写作规范

### 2.1 推导结构

每个公式推导必须包含：

```
① 推导目标声明（一句话说明要推什么、从什么出发）
② 起点公式/假设（标注理论来源）
③ 推导步骤（每步标注物理意义或数学操作）
④ 最终公式（独立成行，用 $$...$$ 展示）
⑤ 物理意义解读（公式中每个变量代表什么、正比/反比关系）
⑥ 数值验证（代入一个具体数字验证公式合理性，可选但强烈建议）
⑦ 适用范围与限制
```

### 2.2 推导示例（以 Born-Haber 循环为例）

```markdown
**Born-Haber 循环求算晶格能**——用热化学循环间接计算。

以 NaCl 为例，设计热化学循环（参考教材《普通化学原理》第4版 图12.2）：

| 步骤 | 过程 | 能量变化/(kJ/mol) |
|:---:|:---|:---:|
| ① | ½Cl₂(g) → Cl(g)（离解热 D/2） | +121.5 |
| ② | Na(s) → Na(g)（升华热 S） | +107.5 |
| ③ | Na(g) → Na⁺(g) + e（电离能 I） | +495.8 |
| ④ | Cl(g) + e → Cl⁻(g)（电子亲和能 E） | −348.6 |
| ⑤ | Na⁺(g) + Cl⁻(g) → NaCl(s)（晶格能 −U） | −U |
| **合计** | Na(s) + ½Cl₂(g) → NaCl(s)（生成焓 ΔHf） | −411.2 |

根据 Hess 定律，各步能量之和等于总反应的焓变：

$$\Delta H_f = \frac{D}{2} + S + I + (-E) + (-U)$$

移项得晶格能：

$$U = -\Delta H_f + \frac{D}{2} + S + I - E$$

代入数值验证：

$$U = 411.2 + 121.5 + 107.5 + 495.8 - 348.6 = \mathbf{787.4\ kJ/mol}$$

> **物理意义**：晶格能 U = 787.4 kJ/mol 表示由气态 Na⁺ 和 Cl⁻ 结合生成 1mol NaCl 晶体释放的能量。U 越大→离子键越强→熔点越高。

> **适用范围**：Born-Haber 循环适用于所有离子晶体，但需要已知生成焓、离解热、升华热、电离能和电子亲和能五项数据。
```

### 2.3 数学格式与 Unicode/LaTeX 边界

> **完整规范**：详见 [[11-模板/MD通用规范（Word-PDF共同最优子集）]] 和 [[00-首页/Word友好 Markdown 符号速查表]]。以下为核心规则速查。

**行内公式**：`$...$`，一个最小公式一次性包完整。
**独立公式**：`$$...$$`（前后各空一行），复杂推导整段处理。
**变量首次出现时**用文字解释：其中 $N_A$ 为 Avogadro 常数，$Z_1, Z_2$ 为离子电荷数。

**Unicode vs LaTeX 速查**：

| 场景 | 正确写法 | 错误写法 |
|:---|:---|:---|
| 简单离子/电荷 | `Na⁺`、`Cl⁻`、`Fe²⁺`、`SO₄²⁻` | `Na$^+$`（半截 math）🔥 |
| 简单电子排布 | `2s²2p³`、`3d¹⁰4s¹` | `2s$^2$2p$^3$`（拆碎） |
| 简单下标 | `mₛ`、`mₗ`、`I₁` | — |
| 字母/变量下标 | `$K_p$`、`$K_c$`、`$K_{sp}$` | `K_p`（裸下划线）🔥 |
| 轨道符号 | `$e_g$`、`$t_{2g}$`、`$d_{z^2}$` | `e_g`（裸下划线）🔥 |
| 热力学标准态 | `$\Delta_\mathrm{r} H^\theta$` | `ΔᵣH°`（Word 不稳） |
| 正文箭头/趋势 | `→`、`↑`、`↓`、`≤`、`≥` | `$\rightarrow$`（CJK 字间距异常）🔥 |
| 化学反应式 | `$\ce{^{238}_{92}U -> ^{234}_{90}Th + ^{4}_{2}He}$` | — |
| 罗马数字 | `Ⅱ` `Ⅲ` `Ⅳ`（Unicode 直写） | 手动转 ASCII |

**铁律**：
1. 固定短记号优先 Unicode，保证阅读自然
2. 复杂表达式必须整段放进一个 `$...$`，严禁"半截 math"
3. `$e_g$`、`$t_{2g}$` 等轨道符号**永远用 LaTeX 下标**，不用纯文本 `_`
4. Unicode 箭头 `→` **直接写正文中**，不要替换为 `$\rightarrow$`

**常用符号统一**：$E$（能量）、$H$（焓）、$S$（熵）、$G$（Gibbs 自由能）、$K$（平衡常数）

## 三、练习题写作规范

### 3.1 三级分类体系

| 级别 | 标记 | 定位 | 题量建议 | 出题原则 |
|:---|:---|:---|:---:|:---|
| 🌱 **基础巩固** | `🌱` | 讲义内容理解了就能做 | 8-15 题 | 直接应用讲义公式/规则/步骤；填空/选择/简单计算 |
| 🔥 **竞赛入门** | `🔥` | 需要综合 2+ 个知识点 | 5-10 题 | 中等计算；排除干扰信息；跨节综合 |
| 🏆 **真题挑战** | `🏆` | 近年初赛/决赛真题或改编 | 3-8 题 | 标注年份和届次；完全竞赛级 |

**最低标准**：🌱6 + 🔥4 + 🏆2 = 合计 ≥12 题
**理想标准**：🌱10 + 🔥8 + 🏆5 = 合计 ≥23 题

### 3.2 题目来源优先级

🌱 基础巩固和 🔥 竞赛入门的题目**优先从以下来源选取**：

| 优先级 | 来源 | 标注格式 | 适用级别 |
|:---:|:---|:---|:---|
| 1 | 《普通化学原理》第4版 课后习题 | `[普化原理X-X]` | 🌱 + 🔥 |
| 2 | 《上海中学竞赛课程·化学》第1/2分册 | `[上海中学第X分册/页码]` | 🌱 + 🔥 |
| 3 | 竞赛讲义/专题讲义 | `[初赛讲义X.XX]` | 🔥 |
| 4 | 赵鑫光《高中化学竞赛基本理论学习笔记》 | `[赵鑫光题集 例X]` | 🔥 + 🏆 |
| 5 | 历届初赛/决赛真题 | `[第XX届初赛（YYYY）]` | 🏆 |
| 6 | 汇智题库 | `[汇智第X题]` | 🌱 + 🔥 |

**要求**：
- 每道题必须**题干全文内嵌**（不允许只写"见教材XX题"）

- 真题必须标注年份和届次
- 自编题比例 ≤30%

### 3.3 子话题分组

每个级别内部按知识点/方法分组，用 `**加粗标题**` 标记：

### 3.4 编号规则

- **全局连续编号**：从 1 开始，跨三级连续递增
- **小问编号**：`(a)` `(b)` `(c)` 缩进 3 空格

## 五、图片利用规范

### 5.1 写作流程中的图片使用

1. **先规划后写作**：frontmatter 下方注释块里的「配图规划表」在起草前先填，每图定一个教学功能（定义/结构/对比/读图推理），不允许拿重复图充版面。
2. **找图顺序**（详见 [[规则-配图来源优先级]]）：[[图片索引]] 精标表 → 同主题存量讲义的已配图片 → mineru/教材 OCR/真题原图 → 库内其他 → 外部 → Excalidraw/Mermaid（仅限逻辑型图，禁伪造教材级结构图/机理图/谱图/晶胞图）。
3. **落地规则**：来源仓（mineru/OCR）的图复制到根目录 `media/` 并改稳定英文名（`topic-keyword-purpose.ext`）后才进讲义；正文只写 `![[media/...]]`；图注 `*图 N 对象+用途*` ≤30 字，来源说明不进图注。
4. **写完对账**：`image_count` 与正文 `![[media/...]]` 数量一致；`has_images` 如实。

### 5.2 图片在知识点中的嵌入方式

每个知识点小节中，图片应紧跟相关文字之后，并附带读图指引：

```markdown
![[media/h2_energy_curve_textbook.jpg]]
*图 H₂ 分子的势能曲线——横轴为核间距，纵轴为体系能量。*

> **读图提示**：平衡位置 r₀ = 74 pm 处势能最低（E = −452 kJ/mol），这就是键长和键能的物理来源。
```

### 5.3 图片教学功能分类

| 功能 | 说明 | 示例 |
|:---|:---|:---|
| **定义型** | 帮助理解概念的结构图/示意图 | 电子云重叠图、晶体场分裂图 |
| **结构型** | 展示分子/晶体的空间构型 | VSEPR 模型图、晶胞图 |
| **对比型** | 并列对比不同概念 | σ 键与 π 键对比图 |
| **读图推理型** | 学生需要从图中提取信息做题 | 势能曲线、MO 能级图 |
| **数据型** | 展示定量规律/趋势 | 电负性周期趋势图 |

### 5.4 黑白打印适配

- 不依赖颜色传达核心信息
- 关键判断链保留文字版或表格版
- 图片只作辅助，不依赖颜色区分重点/次重点

## 六、Word/PDF 管线兼容性

> **完整规范**：详见 [[11-模板/MD通用规范（Word-PDF共同最优子集）]]、[[00-首页/Word管线总览]]、[[00-首页/Word友好 Markdown 符号速查表]]。

### 6.1 源稿写法必须遵守共同最优子集

讲义源 Markdown 最终要走两条管线：Word（Pandoc → python-docx）和 PDF（LaTeX）。源稿必须按**共同最优子集**写，优先保证 Word 稳，再让 PDF 自然兼容。

**关键约束**：

| 约束项 | 要求 | 原因 |
|:---|:---|:---|
| 图片路径 | `![[media/xxx.png]]`，只用根目录 media/ | Word 管线扫描此路径 |
| 无 Mermaid 代码块 | 先渲染成图片再引用 | Word 会漏成代码文本 |
| 无裸下划线 | `$e_g$` 而非 `e_g` | Word 端渲染失稳 |
| 无半截 math | `Na⁺` 或 `$Na^+$`，不写 `Na$^+$` | Word 公式对象断裂 |
| 标准态用 θ | `$\Delta_\mathrm{r} H^\theta$` | Word/PDF 共同口径 |
| Unicode 箭头 | `→` 直接写，不用 `$\rightarrow$` | CJK 字间距异常 |
| 表格对齐线 | ASCII `|:---|` | 中文破折号不识别 |

### 6.2 生成 Word 的流程

```
源稿（04-课件/学生讲义/*.md）
  → 预处理（剥离 frontmatter、处理 wikilink/图片、公式预检）
  → Pandoc 转 docx
  → python-docx 后处理（统一字体/段落/标题风格）
  → 输出到 00-首页/学生讲义Word/
```

主脚本：`11-模板/scripts/build-all-handout-docx.py`

### 6.3 写稿自检（管线相关）

- [ ] 图片都写成 `![[media/...]]`，无 `![[mineru/...]]` 直引
- [ ] 无 ` ```mermaid ` 代码块
- [ ] 无 `![[xxx.md]]` 历史嵌入
- [ ] 无 `Na$^+$`、`2s$^2$2p$^3$` 半截 math
- [ ] 无 `K_p`、`e_g`、`t_2g` 裸下划线
- [ ] 标准态记号用 θ，不用 °
- [ ] Unicode 箭头直接写，不用 `$\rightarrow$`
- [ ] 表格对齐线是 ASCII，不用中文破折号
