# render_gate 允许清单
#
# 用途：登记**确认属于启发式误报**的文件，使其不计入失败（汇总里单列为「另有允许 N」）。
# 这与库里既有惯例一致 —— 参见 `09-审计报告/2026-08-30-习题书V2-预检WARN允许清单.md`：
# 那里把「`°` 在角度/温度语境被误判标准态」登记为允许项（共 9 条）。
#
# 格式：<相对 vault 的相对路径>TAB<原因>
#       `#` 开头为注释；空行忽略。
#
# ── 使用纪律 ────────────────────────────────────────────────────────────
# ⚠️ **只登记「误报」，绝不用它掩盖真问题。**
#    判据：产物里那个 `$` 是不是**本来就该原样显示**？
#      · 是  → 误报，可登记（价格 `~$300` / 散文里描述该字符 / DataviewJS `$=`；
#             代码里的 `$` 已由代码样式自动排除，无需登记）
#      · 否  → **真问题**，不许登记。即使根因是「内容截断」这类非格式问题，
#             闸门报出来也是**对的**（它就是坏了），该修内容而不是屏蔽闸门。
#             反例：`06-学生侧材料/练习卷/补弱卷-化学平衡-2026-09-02.md`
#             内容被截断导致 `$` 不配平 —— 我一度把它登记进来，**属误用，已撤**。
#
# ⚠️ 成片的误报**优先用域划分**（`render_gate.py` 的 `DOC_SKIP_DOMAINS` / README 规则），
#    不要往这里堆。本清单只用于「个别文件、按域划不开」的情形。
#
# ── 使用痕迹 ────────────────────────────────────────────────────────────
# 2026-09-20 建立。当前**为空** —— 实测到的 3 类误报
# （代码块 `$PY`、行内代码 `` `$...$` ``、非数学用途的 `$`）已分别由
# 「代码样式排除」与「域划分」解决，无需逐文件登记。
#
