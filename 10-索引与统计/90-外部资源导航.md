# 外部资源导航

> 本页解决「顶层目录看不出哪个是哪个」的问题。
> **本页只登记、不移动**：所有目录保持物理位置不变，因此不存在断链风险。
> 若将来要物理收纳进统一容器，必须先跑引用扫描——本页末尾记录了风险点。

## 一、顶层目录的两套体系

本库顶层混排了两类目录，性质完全不同：

| 体系 | 目录 | 性质 | 是否日常编辑 |
|---|---|---|---|
| **编号体系**（生产区） | `00-首页` `01-考纲导航` `02-考纲条目` `02-数据库` `03-知识点` `04-课件` `04-题库` `04-专题与题型` `05-真题库` `06-学生侧材料` `07-资料提炼` `08-可视化资源` `09-审计报告` `10-索引与统计` `11-模板` `12-教学洞察` `13-教案` | 知识库本体，产出与治理都在这里 | 是 |

## 三、⚠ 一个必须知道的结构隐患：存在第二套编号体系

`高考化学/`（1,480 文件，233 md）**自带一套完整编号子库**：

```
高考化学/00-导航  01-考纲  02-知识点  03-题库  04-讲义  05-备课  06-资料提炼  07-索引与统计
```

它与主库的 `00-首页 … 13-教案` **平行重复**，导致：

- 出现同名文件冲突：`高考化学/00-导航/活跃任务.md` 与 `00-首页/活跃任务.md`、
  `高考化学/00-导航/状态摘要.md` 与 `00-首页/状态摘要.md`
- Obsidian 按 basename 解析 `[[状态摘要]]` 时会**二义**，命中哪一个不确定
- 任何按「编号前缀」做的统计都会把两套混在一起

**建议**：把 `高考化学/` 视为独立子库，在其 README 中明确「本目录内编号自成体系，不与顶层编号互通」；若要彻底解决，需重命名其下同名文件（如 `高考化学-状态摘要.md`）。此项涉及改名，**暂未执行**。

## 四、物理收纳的风险提示（今���若要移动）

扫描结论：短链（形如 `` `[[文件名]]` ``，不含路径）按 basename 解析，因此**只要 basename 唯一，移动目录不会断链**。但已发现冲突：

- `04-题库/` 根目录 77 个散落文件中，3 个 basename 不唯一（`README`、`化学原理阶段测试卷`、`有机化学阶段测试卷` 与 `04-课件/习题集/二·评测层` 下同名）
- `00-首页/` 根目录 53 个散落文件中，6 个不唯一（`状态摘要`、`活跃任务`、`模块连接覆盖表`、`知识库待补充清单`、`连接工程总表`、`KP-提炼-题库挂接巡检表`）

→ 移动这些文件前必须先消解同名冲突，否则会改变链接解析结果。
