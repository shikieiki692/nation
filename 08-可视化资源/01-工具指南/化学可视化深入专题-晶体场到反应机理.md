## 专题一：晶体场理论可视化

### 1.1 d 轨道分裂的三种几何构型

#### 八面体场（Oh）

```
        eg  ↑   ↑      dx²-y², dz²     (+0.6Δo)
        ───────────
              ↑
              ↑ Δo
        ───────────
        t2g  ↑ ↑ ↑    dxy, dxz, dyz    (-0.4Δo)
```

**d 电子填充与 CFSE 计算**：

| dⁿ | 弱场(高自旋) | CFSE | 强场(低自旋) | CFSE |
|:---|:-------------|:-----|:-------------|:-----|
| d¹ | t2g¹ | -0.4Δo | t2g¹ | -0.4Δo |
| d² | t2g² | -0.8Δo | t2g² | -0.8Δo |
| d³ | t2g³ | -1.2Δo | t2g³ | -1.2Δo |
| d⁴ | t2g³ eg¹ | -0.6Δo | t2g⁴ | -1.6Δo + P |
| d⁵ | t2g³ eg² | 0 | t2g⁵ | -2.0Δo + 2P |
| d⁶ | t2g⁴ eg² | -0.4Δo | t2g⁶ | -2.4Δo + 2P |
| d⁷ | t2g⁵ eg² | -0.8Δo | t2g⁶ eg¹ | -1.8Δo + P |
| d⁸ | t2g⁶ eg² | -1.2Δo | t2g⁶ eg² | -1.2Δo |
| d⁹ | t2g⁶ eg³ | -0.6Δo | t2g⁶ eg³ | -0.6Δo |
| d¹⁰ | t2g⁶ eg⁴ | 0 | t2g⁶ eg⁴ | 0 |

#### 四面体场（Td）

```
        t₂   ↑ ↑ ↑    dxy, dxz, dyz    (+0.4Δt)
        ───────────
              ↑
              ↑ Δt ≈ 4/9 Δo
        ───────────
        e    ↑ ↑      dz², dx²-y²      (-0.6Δt)
```

**关键区别**：
- 分裂顺序与八面体**相反**
- Δt ≈ 4/9 Δo（分裂能更小）
- **没有**高自旋/低自旋之分（Δt 太小）

#### 平面正方形场（D4h）

```
        dx²-y²         (最高能量)
        ─────────
        dxy
        ─────────
        dz²
        ─────────
        dxz, dyz       (最低能量，简并)
```

**特点**：
- 可以看作八面体场沿 z 轴**极度拉长**的结果
- d⁸ 离子（Pt²⁺, Pd²⁺, Ni²⁺ 强场）常见
- 与八面体场的 Jahn-Teller 畸变相关

### 1.2 Jahn-Teller 畸变可视化

**原理**：非线性分子在简并电子态下不稳定，会发生几何畸变以消除简并。

**典型例子**：Cu²⁺ (d⁹) 配合物

```
正八面体 → 畸变八面体

     Cu²⁺                    Cu²⁺
    / | \                   / | \
   L  L  L       →        L  L  L    (赤道：短键)
   L  L  L                 L  L  L
    \|/                    \ | /
     L                      L
                          (轴向：长键)
```

**d 轨道能级变化**：

```
八面体 Oh               畸变 D4h
    eg                      dx²-y²  (↑)
    ───                    ─────────
    ↑↑                     dz²  (↓)
    ───                    ─────────
    t2g                     dxy  (↑↑)
    ───                    ─────────
    ↑↑↑                    dxz, dyz  (↑↑)
```

**VESTA 观察方法**：
```
1. 打开 CuSO4·5H2O 的 CIF 文件
2. 测量所有 Cu-O 键长
3. 发现赤道键（~2.0 Å）< 轴向键（~2.4 Å）
4. 这就是 Jahn-Teller 畸变的直接证据
```

### 1.3 Tanabe-Sugano 图

**用途**：预测配合物的 d-d 跃迁吸收波长。

**关键特征**：
- x 轴：Δ/B（分裂能 / Racah 参数）
- y 轴：E/B（跃迁能量 / Racah 参数）
- 线的斜率对应不同的电子态

**在线工具**：
- [WebQC Tanabe-Sugano Diagrams](https://www.webqc.org/tanabe-sugano.php)（可交互选择 dⁿ 构型）

**使用方法**：
```
1. 确定金属离子的 d 电子数（如 Fe²⁺ → d⁶）
2. 在图上找到 Δ/B 的位置（从光谱数据或估算）
3. 从基态到激发态的垂直距离 → 跃迁能量
4. 跃迁能量 → 吸收波长 → 颜色
```

### 1.4 光谱化学序列

| 弱场 | ← 场强增强 → | 强场 |
|:-----|:-------------|:-----|
| I⁻ < Br⁻ < Cl⁻ < F⁻ < OH⁻ < H₂O < NH₃ < en < NO₂⁻ < CN⁻ < CO |

**可视化理解**：
- 弱场配体：Δ 小 → 高自旋 → 颜色偏红（吸收低能光）
- 强场配体：Δ 大 → 低自旋 → 颜色偏蓝（吸收高能光）

## 专题二：分子轨道理论可视化

### 2.1 σ 和 π 成键/反键轨道

#### σ 成键与反键

```
σ (成键)              σ* (反键)
  ⊕⊕                  ⊕  ⊕
  ████                █  █
  ████                █  █
  ████                █  █
电子密度集中在核间    节面在核间
能量降低              能量升高
```

#### π 成键与反键

```
π (成键)              π* (反键)
  ┌───┐                ┌───┐
  │███│                │███│
  └───┘                └───┘
  ┌───┐                ┌───┐
  │███│                │███│
  └───┘                └───┘
侧面重叠              节面在核间
能量降低              能量升高
```

### 2.2 常见分子的 MO 能级图

#### H₂（最简单）

```
  σ*   ───    (0 e⁻)
  ───
   ↑↓
  ───
  σ    ───    (2 e⁻)

键级 = (2-0)/2 = 1
```

#### O₂（解释顺磁性）

```
  σ2p*   ───   (0 e⁻)
  ───
  π2p*   ↑  ↑   (2 e⁻)  ← 两个未成对电子！
  ───
  σ2p    ↑↓    (2 e⁻)
  ───
  π2p    ↑↓ ↑↓  (4 e⁻)
  ───
  σ2s*   ↑↓    (2 e⁻)
  ───
  σ2s    ↑↓    (2 e⁻)

键级 = (8-4)/2 = 2（双键）
顺磁性：2个未成对电子
```

#### N₂

```
  π2p*   ↑↓ ↑↓  (4 e⁻)
  ───
  σ2p    ↑↓    (2 e⁻)
  ───
  π2p    ↑↓ ↑↓  (4 e⁻)
  ───
  σ2s*   ↑↓    (2 e⁻)
  ───
  σ2s    ↑↓    (2 e⁻)

键级 = (8-4)/2 = 3（三键）
```

### 2.3 前线轨道（HOMO/LUMO）

| 概念 | 定义 | 重要性 |
|:-----|:-----|:-------|
| **HOMO** | 最高占据分子轨道 | 亲核反应位点 |
| **LUMO** | 最低未占分子轨道 | 亲电反应位点 |
| **HOMO-LUMO gap** | 两者能量差 | 分子稳定性、颜色 |

**可视化方法**：
```
1. Gaussian/ORCA 计算分子轨道
2. Multiwfn 分析波函数
3. Avogadro/VMD 可视化 HOMO/LUMO 等值面
4. 或使用 MolView 在线查看
```

## 专题三：配位化学异构体可视化

### 3.1 几何异构（顺反异构）

#### 八面体配合物

**[Co(NH₃)₄Cl₂]⁺**

```
顺式 (cis-)              反式 (trans-)
    Cl                      Cl
    |                       |
NH₃-Co-NH₃              NH₃-Co-NH₃
    |                       |
    Cl                      NH₃

两个 Cl 相邻              两个 Cl 相对
（90°）                  （180°）
```

**[Co(en)₃]³⁺**
- 三(乙二胺)合钴(III)
- 无几何异构（所有配体相同）

#### 平面正方形配合物

**[Pt(NH₃)₂Cl₂]**

```
顺式 (cis-)              反式 (trans-)
    Cl                      Cl
    |                       |
NH₃-Pt-NH₃              Cl-Pt-Cl
    |                       |
    Cl                      NH₃
```

**顺铂 vs 反铂**：
- 顺铂：抗癌药物
- 反铂：无抗癌活性

### 3.2 光学异构（对映异构）

#### [Co(en)₃]³⁺

```
Δ (右旋)                Λ (左旋)
    en                      en
   / \                     / \
  Co   en                en   Co
   \ /                     \ /
    en                      en

镜像关系，不可重叠
```

#### 识别方法
```
1. 构建分子的两种镜像
2. 尝试旋转重叠
3. 如果不能重叠 → 手性分子 → 有光学异构
```

### 3.3 结构异构类型

| 类型 | 例子 | 特点 |
|:-----|:-----|:-----|
| **电离异构** | [Co(NH₃)₅Br]SO₄ vs [Co(NH₃)₅SO₄]Br | 不同离子在外界 |
| **水合异构** | [Cr(H₂O)₆]Cl₃ vs [Cr(H₂O)₅Cl]Cl₂·H₂O | 水分子位置不同 |
| **配位异构** | [Co(NH₃)₆][Cr(CN)₆] vs [Cr(NH₃)₆][Co(CN)₆] | 配体在不同金属上 |
| **键合异构** | [Co(NH₃)₅(NO₂)]²⁺ vs [Co(NH₃)₅(ONO)]²⁺ | 同一配体不同配位原子 |

## 专题四：反应机理可视化

### 4.1 SN1 机理（单分子亲核取代）

```
步骤1：离去基团离开（慢，决速步）
    R-L  →  R⁺ + L⁻
    (碳正离子形成)

步骤2：亲核试剂进攻（快）
    R⁺ + Nu⁻  →  R-Nu

能量图：
    ↑ E
    |      TS1
    |     /  \
    |    /    \     TS2
    |   /      \   /  \
    |  /        \ /    \
    | / 反应物   I       \
    |/          中间体    产物
    └─────────────────────→ 反应坐标
```

**3D 可视化要点**：
- 碳正离子：平面 sp² 杂化
- 亲核试剂可以从两侧进攻
- 导致**外消旋化**

### 4.2 SN2 机理（双分子亲核取代）

```
一步完成：
    Nu⁻ + R-L  →  [Nu···R···L]⁻‡  →  R-Nu + L⁻
                   (过渡态)

能量图：
    ↑ E
    |        TS
    |       /  \
    |      /    \
    |     /      \
    |    /        \
    |   / 反应物   \
    |/              产物
    └─────────────────────→ 反应坐标
```

**3D 可视化要点**：
- 背面进攻（backside attack）
- 过渡态：五配位碳（三角双锥）
- **Walden 翻转**（构型反转）

### 4.3 E2 机理（双分子消除）

```
一步完成：
    B:⁻ + H-C-C-L  →  B-H + C=C + L⁻

关键：反式共平面（anti-periplanar）
    H   L
     \ /
      C-C
     / \
    B:⁻ → 进攻
```

**3D 可视化要点**：
- H 和 L 必须在**反式共平面**位置
- Newman 投影：H 和 L 二面角 = 180°
- 协同消除

### 4.4 Diels-Alder 反应

```
[4+2] 环加成：
    +  →  

能量图：
    ↑ E
    |     TS
    |    /  \
    |   /    \
    |  /      \
    | / 反应物  \
    |/          产物
    └─────────────────────→ 反应坐标
```

**3D 可视化要点**：
- 协同反应（一步完成）
- 需要**同面-同面**（suprafacial-suprafacial）
- 二烯必须是 s-cis 构象
- 产物：环己烯

## 专题五：对称性与点群

### 5.1 点群判定流程图

```
开始
  ↓
线性？ → 是 → 有反演中心？ → 是 → D∞h
  ↓                      否 → C∞v
  ↓
高对称？ → 是 → 选择 Td/Oh/Ih
  ↓
  否
  ↓
找主旋转轴 Cn
  ↓
有垂直 C2 轴？ → 是 → 有 σh？ → 是 → Dnh
  ↓                      否 → 有 σd？ → 是 → Dnd
  ↓                                    否 → Dn
  否
  ↓
有 σh？ → 是 → Cnh
  ↓
  否
  ↓
有 σv？ → 是 → Cnv
  ↓
  否
  ↓
有 Sn？ → 是 → Sn
  ↓
  否 → C1（无对称性）
```

### 5.2 常见分子的点群

| 分子 | 点群 | 对称元素 |
|:-----|:-----|:---------|
| H₂O | C2v | C2, 2σv |
| NH₃ | C3v | C3, 3σv |
| CH₄ | Td | 4C3, 3C2, 3S4, 6σd |
| SF₆ | Oh | 4C3, 3C4, 3C2, 6C2', 3σh, 6σd, i, 4S6, 3S4 |
| C₆₀ | Ih | 最高对称性（足球烯） |
| BF₃ | D3h | C3, 3C2, σh, 3σv |
| CO₂ | D∞h | C∞, ∞σv, i |
| HCl | C∞v | C∞, ∞σv |
| CHFClBr | C1 | 无对称性 |

### 5.3 对称操作可视化

**旋转轴 Cn**：
```
C2：旋转 180° 重合
C3：旋转 120° 重合
C4：旋转 90° 重合
```

**镜面 σ**：
```
σh：水平镜面（垂直于主轴）
σv：垂直镜面（包含主轴）
σd：对角镜面（平分 C2 轴夹角）
```

**反演中心 i**：
```
(x,y,z) → (-x,-y,-z)
每个原子通过中心对称找到对应原子
```

## 专题六：静电势图（MEP）

### 6.1 原理

```
MEP = 静电势能 = 正试探电荷在分子表面的能量

颜色编码：
  🔴 红色 = 负电势 = 电子富集 = 亲核位点
  🔵 蓝色 = 正电势 = 电子缺乏 = 亲电位点
  🟢 绿色 = 中性
```

### 6.2 应用

| 应用 | 解释 |
|:-----|:-----|
| **预测反应活性** | 红色区域易受亲电进攻，蓝色区域易受亲核进攻 |
| **氢键分析** | H 附近的蓝色区域 → 氢键供体 |
| **分子间作用力** | 预测分子如何相互识别 |
| **芳香取代定位** | 苯环上 MEP 值决定取代位置 |

### 6.3 计算方法

```
1. Gaussian/ORCA 计算分子波函数
2. Multiwfn 分析 MEP
3. Avogadro/VMD 可视化
4. 或 MolView 在线查看
```

## 专题七：电子局域化函数（ELF）

### 7.1 原理

```
ELF = 电子局域化程度

ELF ≈ 1：高局域化（共价键、孤对电子）
ELF ≈ 0.5：均匀电子气（金属键）
ELF ≈ 0：低电子密度区
```

### 7.2 化学键分类

| ELF 值 | 键类型 | 例子 |
|:-------|:-------|:-----|
| 高（~1） | 共价键 | C-C, C-H |
| 中（~0.5） | 金属键 | Fe-Fe |
| 低（~0.3） | 离子键 | Na-Cl |
| 中等 | 氢键 | O-H···O |

### 7.3 计算方法

```
1. Gaussian/ORCA 计算波函数
2. Multiwfn 计算 ELF
3. VESTA/VMD 可视化 ELF 等值面
4. 分析 ELF basin（基区）得到化学信息
```

## 专题八：Born-Haber 循环

### 8.1 原理

```
Na(s) + ½Cl₂(g) → NaCl(s)  ΔHf = -411 kJ/mol

步骤分解：
1. Na(s) → Na(g)          ΔHsub = +107 kJ/mol（升华）
2. Na(g) → Na⁺(g) + e⁻    IE = +496 kJ/mol（电离）
3. ½Cl₂(g) → Cl(g)        ½D = +122 kJ/mol（解离）
4. Cl(g) + e⁻ → Cl⁻(g)   EA = -349 kJ/mol（电子亲和）
5. Na⁺(g) + Cl⁻(g) → NaCl(s)  U = -787 kJ/mol（晶格能）

验证：ΔHf = 107 + 496 + 122 - 349 - 787 = -411 kJ/mol ✓
```

### 8.2 能量图

```
    ↑ E (kJ/mol)
    |
    |  Na⁺(g)+Cl⁻(g)+e⁻
    |  ──────────────────  +576
    |
    |  Na⁺(g)+Cl(g)+e⁻
    |  ──────────────────  +724
    |
    |  Na(g)+Cl(g)+e⁻
    |  ──────────────────  +228
    |
    |  Na(s)+½Cl₂(g)
    |  ──────────────────    0 (参考点)
    |
    |  NaCl(s)
    |  ──────────────────  -411
    └──────────────────────────→
```

## 专题九：相图可视化

### 9.1 二元相图

```
    T ↑
    |      液相
    |    /    \
    |   /      \
    |  / 液+固  \
    | /          \
    |/   固+固    \
    └──────────────→ x
       A          B
```

**关键特征**：
- 液相线（liquidus）：液相稳定的下限
- 固相线（solidus）：固相稳定的上限
- 共晶点：最低熔点
- 杠杆规则：确定相比例

### 9.2 三元相图

```
    A
    /\
   /  \
  / 液相\
 /      \
/────────\
B         C
```

**Gibbs 三角形**：
- 三个顶点：纯组分 A、B、C
- 边上的点：二元混合物
- 内部的点：三元混合物
- 等温截面：固定温度的相分布
