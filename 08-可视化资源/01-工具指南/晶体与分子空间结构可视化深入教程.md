# 晶体与分子空间结构可视化深入教程

> 面向化学竞赛的实操教程，从晶体结构到分子空间结构。

---

## 第一部分：晶体结构可视化（VESTA）

### 1.1 VESTA 基础操作流程

#### 步骤1：打开CIF文件
```
File → Open → 选择 CIF 文件
建议从 NaCl 开始（最简单的立方晶体）
```

#### 步骤2：设置显示样式
```
Edit → Edit Data → Style

常用设置：
- Style: Ball-and-stick（球棍模型）或 Polyhedral（多面体）
- Radius: 调整原子半径
- Bond: 设置键长范围
```

#### 步骤3：设置晶胞显示
```
Edit → Edit Data → Unit Cell

勾选：
- Show unit cell（显示晶胞）
- Show atoms in unit cell（显示晶胞内原子）
```

#### 步骤4：导出图片
```
File → Export Raster Image

设置：
- Format: PNG 或 TIFF
- Resolution: 300 DPI（论文用）
- Background: White（白色背景）
```

### 1.2 典型晶体结构详细分析

#### 案例1：NaCl 岩盐结构

**文件位置**：`08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif`

**结构要点**：
```
晶系：立方
空间群：Fm-3m (225)
晶胞参数：a = 5.64 Å
配位数：Na⁺ = 6, Cl⁻ = 6
堆积方式：Cl⁻ 立方最密堆积，Na⁺ 填充八面体空隙
```

**VESTA 操作**：
```
1. 打开 NaCl-Fm-3m.cif
2. Edit → Edit Data → Style
   - Style: Polyhedral（显示 Na⁺ 的八面体配位）
   - 或 Ball-and-stick（显示球棍模型）
3. 测量键长：
   Edit → Edit Data → Bonds
   点击两个原子，测量 Na-Cl 键长（约 2.82 Å）
4. 导出图片
```

**竞赛考点**：
- 配位数：6:6
- 晶胞中原子数：Na⁺ = 12×1/4 + 1 = 4，Cl⁻ = 8×1/8 + 6×1/2 = 4
- 空间利用率：约 67%
- 马德隆常数：1.748

### 1.3 晶面与晶向标注

#### 晶面标注操作

**步骤**：
```
1. 打开晶体结构文件
2. Edit → Edit Data → Planes
3. 点击 "Add" 添加晶面
4. 输入密勒指数 (h k l)
5. 设置显示样式（颜色、透明度）
```

**常见晶面**：
| 晶面 | 密勒指数 | 面间距公式（立方晶系） |
|:-----|:---------|:----------------------|
| (100) | h=1, k=0, l=0 | d = a/h |
| (110) | h=1, k=1, l=0 | d = a/√(h²+k²+l²) |
| (111) | h=1, k=1, l=1 | d = a/√3 |
| (200) | h=2, k=0, l=0 | d = a/2 |

#### 晶向标注操作

**步骤**：
```
1. 打开晶体结构文件
2. Edit → Edit Data → Directions
3. 点击 "Add" 添加晶向
4. 输入晶向指数 [u v w]
5. 设置显示样式
```

## 第二部分：分子空间结构可视化（Avogadro 2）

### 2.1 Avogadro 2 基础操作流程

#### 步骤1：构建分子
```
方法1：手动绘制
- 按 D 进入 Draw 模式
- 点击添加原子
- 拖动添加键
- 滚轮改变原子类型

方法2：SMILES 输入
- Build → Insert → SMILES
- 输入 SMILES 字符串
- 点击 OK
```

#### 步骤2：力场优化
```
Extensions → Molecular Mechanics → Quick Optimization
或
Extensions → Molecular Mechanics → Optimized Geometry

选择力场：
- MMFF94（推荐，通用）
- UFF（通用，但精度较低）
- GAFF（有机分子）
```

#### 步骤3：测量几何参数
```
按 M 进入 Measure 模式

测量键长：点击两个原子
测量键角：点击三个原子
测量二面角：点击四个原子
```

#### 步骤4：导出文件
```
File → Save As

常用格式：
- XYZ（简单，通用）
- PDB（蛋白质，含氢）
- CML（化学标记语言）
- SDF（含电荷信息）
```

## 第三部分：综合案例

### 案例1：尖晶石结构 MgAl₂O₄

**文件位置**：`08-可视化资源/02-CIF文件库/02-离子晶体/MgAl2O4-Fd-3m.cif`

**结构要点**：
```
晶系：立方
空间群：Fd-3m (227)
晶胞参数：a = 8.08 Å
结构类型：正常尖晶石
堆积方式：O²⁻ 立方最密堆积
Mg²⁺：填充 1/8 四面体空隙
Al³⁺：填充 1/2 八面体空隙
```

**VESTA 操作**：
```
1. 打开 MgAl2O4-Fd-3m.cif

4. 测量键长
```

**竞赛考点**：
- 正常尖晶石 vs 反尖晶石
- Mg²⁺ 在四面体位，Al³⁺ 在八面体位
- 反尖晶石：Fe₃O₄（Fe³⁺ 在四面体位，Fe²⁺/Fe³⁺ 在八面体位）

### 案例3：BaTiO₃ 钙钛矿（铁电体）

**文件位置**：`08-可视化资源/02-CIF文件库/02-离子晶体/BaTiO3-P4mm.cif`

**结构要点**：
```
晶系：四方
空间群：P4mm (99)
晶胞参数：a = 3.99 Å, c = 4.03 Å
结构特点：Ti⁴⁺ 偏离中心位置
偶极矩：Ti⁴⁺ 位移产生自发极化
```

**VESTA 操作**：
```
1. 打开 BaTiO3-P4mm.cif
2. Edit → Edit Data → Style
   - 显示 TiO₆ 八面体
   - 观察 Ti⁴⁺ 的位置偏移
3. 测量 Ti-O 键长（不等长）
```

**竞赛考点**：
- 铁电性来源：Ti⁴⁺ 位移
- 居里温度：120°C
- 相变：立方→四方→正交→三方
- 压电效应应用

### 4.3 常见问题解决

| 问题 | 原因 | 解决方案 |
|:-----|:-----|:---------|
| VESTA 打不开 CIF | 文件编码错误 | 用记事本另存为 UTF-8 |
| Avogadro 优化失败 | 原子重叠 | 手动调整初始结构 |

## 第五部分：练习题

### 晶体结构练习

1. **NaCl vs CsCl**
   - 打开两个结构文件
   - 对比配位数、晶胞参数、空间利用率
   - 绘制对比表格

2. **ZnS 两种结构**
   - 闪锌矿（立方）vs 纤锌矿（六方）
   - 对比堆积方式、配位数、稳定性

3. **CaF₂ vs Li₂O**
   - 萤石结构 vs 反萤石结构
   - 对比阳离子/阴离子位置

4. **尖晶石结构**
   - 正常尖晶石（MgAl₂O₄）vs 反尖晶石（Fe₃O₄）
   - 对比阳离子分布

### 分子结构练习

1. **VSEPR 模型**
   - 构建 CH₄、NH₃、H₂O
   - 测量键角，解释差异原因

2. **杂化轨道**
   - 构建 CO₂、BF₃、CH₄
   - 对比杂化方式和分子几何

3. **配合物构型**
   - 构建 [Co(NH₃)₆]³⁺ 和 [Cu(NH₃)₄]²⁺
   - 对比八面体和平面正方形

4. **手性分子**
   - 构建乳酸的两种对映体
   - 测量二面角，理解 R/S 构型
