# 化学可视化工具速查卡

> 一页掌握所有工具的核心操作，快速查阅。

---

## 1. VESTA（晶体结构可视化）

### 核心操作
```
打开文件: File → Open → 选择 .cif
设置样式: Edit → Edit Data → Style
导出图片: File → Export Raster Image → PNG
导出3D: File → Export Data → VRML/X3D
```

### 常用快捷键
| 操作 | 方法 |
|:-----|:-----|
| 旋转 | 鼠标左键拖动 |
| 平移 | 鼠标中键拖动 |
| 缩放 | 鼠标滚轮 |
| 测量 | Edit → Edit Data → Bonds |

---

## 2. Avogadro（分子构建与编辑）

### 核心操作
```
构建分子: Draw 工具 (D) 或 SMILES 输入
力场优化: Extensions → Molecular Mechanics → Quick Optimization
测量键长: Measure 工具 (M) → 点击两个原子
测量键角: Measure 工具 (M) → 点击三个原子
导出文件: File → Save As → XYZ/PDB/CIF
```

### 常用快捷键
| 操作 | 快捷键 |
|:-----|:-------|
| Draw 工具 | D |
| Select 工具 | S |
| Measure 工具 | M |
| 优化 | Extensions → Molecular Mechanics |

### SMILES 常用输入
| 分子 | SMILES |
|:-----|:-------|
| 水 | O |
| 氨 | N |
| 甲烷 | C |
| 苯 | c1ccccc1 |
| 乙醇 | CCO |

## 3. Blender（高质量渲染与动画）

### 核心操作
```
添加物体: Shift + A
移动: G
旋转: R
缩放: S
渲染: F12
动画: I → 插入关键帧
```

### 常用快捷键
| 操作 | 快捷键 |
|:-----|:-------|
| 旋转视图 | 鼠标中键 |
| 平移视图 | Shift + 鼠标中键 |
| 缩放视图 | 鼠标滚轮 |
| 全选 | A |
| 取消选择 | Alt + A |
| 编辑模式 | Tab |
| 物体模式 | Tab |

### 三点灯光设置
| 灯光 | 位置 | 强度 |
|:-----|:-----|:-----|
| 主光 | (5, -5, 5) | 250 |
| 补光 | (-3, -3, 3) | 100 |
| 背光 | (0, 5, 3) | 150 |

### CPK 配色
| 元素 | 颜色 |
|:-----|:-----|
| H | 白色 |
| C | 灰色 |
| N | 蓝色 |
| O | 红色 |
| S | 黄色 |
| P | 橙色 |
| Cl | 绿色 |

## 4. Molecular Nodes（Blender 化学插件）

### 核心操作
```
导入分子: Molecular Nodes → Import → PDB/CIF/XYZ
调整样式: Geometry Nodes 编辑器
设置材质: Material Properties
```

### 导入方式
| 格式 | 方法 |
|:-----|:-----|
| PDB | Import → PDB → 输入 PDB ID |
| CIF | Import → CIF → 选择文件 |
| XYZ | Import → XYZ → 选择文件 |

### 显示模式
| 模式 | 用途 |
|:-----|:-----|
| Ball and Stick | 分子结构（推荐） |
| Spacefill | 分子体积 |
| Ribbon | 蛋白质二级结构 |
| Surface | 分子表面 |

## 5. Gaussian（量子化学计算）

### 核心操作
```
生成输入: Avogadro → Extensions → Quantum Chemistry → Set up Calculation
运行计算: g16 < input.gjf > output.log
查看结果: Avogadro → Extensions → Quantum Chemistry → Open Result File
```

### 常用计算类型
| 类型 | 关键词 | 用途 |
|:-----|:-------|:-----|
| 几何优化 | Opt | 优化分子结构 |
| 频率计算 | Freq | 红外光谱 |
| 单点能 | SP | 精确能量 |
| 分子轨道 | Pop=Full | HOMO/LUMO |

### 推荐方法/基组
| 场景 | 方法/基组 |
|:-----|:----------|
| 教学演示 | HF/STO-3G |
| 日常计算 | B3LYP/6-31G* |
| 高精度 | B3LYP/6-311G** |

## 6. 工作流速查

### 场景1：快速出晶体结构图
```
VESTA 打开 CIF → 设置样式 → 导出 PNG
```

### 场景2：分子3D结构
```
Avogadro 构建 → 力场优化 → 导出 XYZ → VESTA 查看
```

### 场景3：高质量渲染
```
Avogadro 构建 → 导出 PDB → Blender + Molecular Nodes → Cycles 渲染
```

### 场景4：分子轨道
```
Avogadro 构建 → Gaussian 计算 → Avogadro 读取 → 可视化
```

### 场景5：动画
```
Molecular Nodes 导入 → 设置关键帧 → 渲染动画
```

## 7. 常见问题速查

| 问题 | 解决方案 |
|:-----|:---------|
| VESTA 打不开 CIF | 检查文件编码（UTF-8） |
| Avogadro 优化失败 | 换用力场（UFF/MMFF94） |
| Blender 渲染太慢 | 降低采样数或用 Eevee |
| Molecular Nodes 导入失败 | 检查版本兼容性 |
| Gaussian 计算不收敛 | 增加迭代次数或换基组 |

## 8. 文件格式转换

| 从 | 到 | 方法 |
|:---|:---|:-----|
| CIF → XYZ | VESTA 导出 |
| XYZ → PDB | Avogadro 导出 |
| PDB → Blender | Molecular Nodes 导入 |
| CIF → VRML | VESTA 导出 |
| VRML → Blender | Blender 导入 |

## 9. 渲染设置速查

### Cycles 设置（高质量）
```
Render Engine: Cycles
Samples: 128-256
Resolution: 2000×1500
Format: PNG
```

### Eevee 设置（快速）
```
Render Engine: Eevee
Samples: 64
Resolution: 1920×1080
Format: PNG
```
