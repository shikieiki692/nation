# Blender 预设场景模板

> 存放 Blender 预设场景文件（.blend），用于快速开始新的渲染项目。

## 使用方式

```
Blender → File → Open → 选择 .blend 文件
```

## 模板分类

### 基础模板
| 模板 | 功能 | 包含内容 |
|:-----|:-----|:---------|
| basic_render.blend | 基础渲染场景 | 三点灯光 + 相机 + 背景 |
| crystal_view.blend | 晶体结构查看 | 灯光 + 相机 + 晶胞边框 |

### 教学模板
| 模板 | 功能 | 包含内容 |
|:-----|:-----|:---------|
| comparison_view.blend | 对比视图 | 双窗口 + 两个相机 |
| animation_setup.blend | 动画设置 | 灯光 + 相机 + 关键帧预设 |

## 创建模板的步骤

1. 在 Blender 中搭建好场景（灯光、相机、材质）
2. 保存为 .blend 文件到对应目录
3. 在此 README 中记录模板信息
4. 使用时直接打开，替换分子/晶体数据即可

## CPK 配色方案（快速参考）

| 元素 | 颜色 | RGB |
|:-----|:-----|:----|
| H | 白色 | (1.0, 1.0, 1.0) |
| C | 灰色 | (0.4, 0.4, 0.4) |
| N | 蓝色 | (0.1, 0.1, 0.9) |
| O | 红色 | (0.9, 0.1, 0.1) |
| S | 黄色 | (1.0, 1.0, 0.0) |
| P | 橙色 | (1.0, 0.5, 0.0) |
| Cl | 绿色 | (0.0, 0.9, 0.0) |
| Fe | 棕色 | (0.8, 0.5, 0.0) |
| Cu | 蓝绿色 | (0.0, 0.6, 0.8) |

## 注意事项

1. 模板文件可能较大（包含材质和灯光信息）
2. 建议定期清理未使用的模板
3. 模板中的 Molecular Nodes 节点组需要对应插件版本
4. 建议为不同用途创建不同模板（如"晶体结构"、"分子结构"、"动画"）
