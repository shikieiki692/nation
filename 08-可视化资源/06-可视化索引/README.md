## 索引格式

每个索引文件中的条目格式：

```markdown
| KP 文件 | 可视化需求 | 推荐工具 | 资源路径 | 状态 |
|:--------|:-----------|:---------|:---------|:-----|
| [[KP文件名]] | 需求描述 | VESTA/Blender/Avogadro | 资源路径 | 待做/已完成 |
```

## 状态说明

| 状态 | 含义 |
|:-----|:-----|
| 待做 | 有可视化需求，尚未制作 |
| 进行中 | 正在制作 |
| 已完成 | 已有对应可视化资源 |
| 跳过 | 经评估不需要可视化 |

## 与知识库的关联

KP 文件可通过 frontmatter 字段引用可视化资源：

```yaml
---
visuals:
  - path: 08-可视化资源/03-渲染图片/01-晶体结构/NaCl-岩盐结构.png
    type: 图片
    description: NaCl 岩盐结构正面视图
  - path: 08-可视化资源/04-动画脚本/crystal_rotation.py
    type: 动画脚本
    description: NaCl 晶体旋转动画
---
```
