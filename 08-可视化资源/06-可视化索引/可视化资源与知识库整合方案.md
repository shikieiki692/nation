# 可视化资源与知识库整合方案

> 目标：将 08-可视化资源/ 与 03-知识点/、04-题库/ 整合，形成可引用的可视化资产。

---

## 一、整合策略

### 1.1 核心思路

```
可视化资源（08-可视化资源/）
    ↓ 通过索引文件映射
知识点（03-知识点/）
    ↓ 通过 knowledge_points 字段关联
题目（04-题库/）
```

### 1.2 整合层级

| 层级 | 内容 | 工具 |
|:-----|:-----|:-----|
| **L1: 工具层** | VESTA/Avogadro/Blender 操作指南 | 已完成 |
| **L2: 数据层** | CIF 文件库、渲染图片 | 已完成（CIF 84个） |
| **L3: 映射层** | 可视化资源 ↔ 知识点映射 | 待创建 |
| **L4: 应用层** | 知识点中的可视化引用 | 待修改 |
| **L5: 生产层** | 批量化渲染脚本 | 待创建 |
