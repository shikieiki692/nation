# 可视化资源更新维护流程

> 定义如何定期更新和维护可视化资源。

---

## 一、更新类型

| 类型 | 说明 | 频率 |
|:-----|:-----|:-----|
| 新增资源 | 添加新的CIF文件或渲染图片 | 按需 |
| 更新资源 | 修改现有资源的元数据或内容 | 按需 |
| 修复问题 | 修复错误或损坏的资源 | 及时 |
| 优化改进 | 优化现有资源的质量 | 定期 |

---

## 二、新增资源流程

### 2.1 添加CIF文件

```
1. 获取CIF文件
   - 从数据库下载（COD、Materials Project等）
   - 或自己创建

2. 验证CIF文件
   - 检查文件完整性
   - 检查数据准确性

3. 命名规范
   - 按命名规范重命名
   - 例: NaCl-Fm-3m.cif

4. 放入目录
   - 放入正确的子目录
   - 例: 02-CIF文件库/02-离子晶体/

5. 添加元数据
   - 在README中添加条目
   - 或创建单独的元数据文件

6. 更新索引
   - 更新无机化学-可视化索引.md
   - 更新相关知识点文件

7. 渲染图片（可选）
   - 用VESTA渲染PNG图片
   - 放入渲染图片目录

8. 验证
   - 检查文件是否可正常打开
   - 检查引用是否正确
```

### 2.2 添加渲染图片

```
1. 渲染图片
   - 用VESTA打开CIF文件
   - 设置显示参数
   - 导出PNG图片

2. 命名规范
   - 按命名规范重命名
   - 例: NaCl-Fm-3m-ball-stick-crystal.png

3. 放入目录
   - 放入正确的子目录
   - 例: 03-渲染图片/01-晶体结构/01-离子晶体/

4. 添加元数据
   - 在README中添加条目

5. 更新索引
   - 更新相关知识点文件

6. 验证
   - 检查图片是否正常显示
   - 检查引用是否正确
```

## 三、更新资源流程

### 3.1 更新CIF文件

```
1. 备份原文件
   - 复制原CIF文件到备份目录

2. 替换文件
   - 用新文件替换旧文件
   - 保持文件名不变

3. 验证新文件
   - 检查文件完整性
   - 检查数据准确性

4. 更新元数据
   - 更新updated字段
   - 更新版本号（如有）

5. 重新渲染（可选）
   - 如果结构变化，重新渲染图片

6. 更新索引
   - 更新相关文档

7. 验证
   - 检查文件是否可正常打开
   - 检查引用是否正确
```

### 3.2 更新渲染图片

```
1. 备份原图片
   - 复制原PNG文件到备份目录

2. 重新渲染
   - 用VESTA重新渲染图片
   - 保持文件名不变

3. 验证新图片
   - 检查图片质量
   - 检查内容准确性

4. 更新元数据
   - 更新updated字段

5. 验证
   - 检查图片是否正常显示
   - 检查引用是否正确
```

## 四、修复问题流程

### 4.1 修复损坏的CIF文件

```
1. 识别问题
   - 检查错误信息
   - 确定损坏原因

2. 获取修复文件
   - 重新下载
   - 或从备份恢复

3. 替换文件
   - 用修复文件替换损坏文件

4. 验证
   - 检查文件是否可正常打开
   - 检查数据是否正确

5. 更新记录
   - 记录修复操作
   - 更新版本号
```

### 4.2 修复错误的引用

```
1. 识别错误
   - 检查引用路径
   - 确定错误原因

2. 修正引用
   - 修正路径错误
   - 修正语法错误

3. 验证
   - 检查引用是否正确
   - 检查链接是否有效

4. 更新记录
   - 记录修复操作
```

## 五、定期维护流程

### 5.1 每周维护

```
1. 检查新增资源
   - 是否有新的CIF文件需要添加
   - 是否有新的渲染图片需要添加

2. 检查引用有效性
   - 检查Wiki-link是否有效
   - 检查路径是否正确

3. 更新索引
   - 更新可视化索引文件
```

### 5.2 每月维护

```
1. 质量检查
   - 运行质量检查清单
   - 修复发现的问题

2. 元数据检查
   - 检查元数据完整性
   - 检查元数据一致性

3. 索引完整性
   - 检查索引是否完整
   - 更新索引

4. 生成报告
   - 生成维护报告
   - 记录发现的问题和改进
```

### 5.3 每季度维护

```
1. 全面审查
   - 审查所有资源
   - 评估资源质量

2. 优化改进
   - 优化现有资源
   - 改进工作流程

3. 更新规范
   - 更新命名规范
   - 更新元数据标准

4. 备份
   - 备份重要资源
   - 验证备份完整性
```

## 六、版本管理

### 6.1 版本号规则

```
主版本号.次版本号.修订号
例: 1.0.0

- 主版本号：重大变更（如目录结构调整）
- 次版本号：新增资源（如新增CIF文件）
- 修订号：修复问题（如修复错误引用）
```

### 6.2 版本记录

```yaml
versions:
  - version: "1.0.0"
    date: "2026-08-02"
    changes:
      - "初始版本"
      - "添加84个CIF文件"
      - "创建索引文件"
  - version: "1.1.0"
    date: "2026-08-02"
    changes:
      - "添加渲染图片目录结构"
      - "创建批量化渲染脚本"
      - "创建元数据标准"
```

## 七、备份策略

### 7.1 备份内容

| 内容 | 优先级 | 频率 |
|:-----|:-------|:-----|
| CIF文件 | 高 | 每周 |
| 渲染图片 | 中 | 每周 |
| 元数据 | 高 | 每周 |
| 索引文件 | 高 | 每周 |
| 脚本文件 | 中 | 每月 |

### 7.2 备份位置

```
备份目录结构：
08-可视化资源/
├── _backup/
│   ├── 2026-08-02/
│   │   ├── 02-CIF文件库/
│   │   ├── 03-渲染图片/
│   │   └── 06-可视化索引/
│   └── ...
```

### 7.3 备份验证

```
1. 验证备份文件完整性
2. 验证备份文件可正常打开
3. 验证备份文件与原文件一致
```

## 八、问题跟踪

### 8.1 问题记录格式

```yaml
issues:
  - id: "ISSUE-001"
    title: "NaCl CIF文件数据错误"
    description: "晶胞参数不正确"
    severity: "high"
    status: "open"
    created: "2026-08-02"
    assignee: "Claude"
    resolution: ""
```

### 8.2 问题状态

| 状态 | 说明 |
|:-----|:-----|
| open | 待处理 |
| in_progress | 处理中 |
| resolved | 已解决 |
| closed | 已关闭 |

## 九、文档更新

### 9.1 需要更新的文档

| 文档 | 更新频率 | 触发条件 |
|:-----|:---------|:---------|
| README.md | 每次变更 | 新增/更新资源 |
| 无机化学-可视化索引.md | 每次变更 | 新增/更新CIF |
| 质量检查清单 | 每季度 | 流程优化 |
| 命名规范 | 每季度 | 规范变更 |
| 元数据标准 | 每季度 | 标准变更 |

### 9.2 更新流程

```
1. 检测变更
   - 发现需要更新的内容

2. 评估影响
   - 评估变更的影响范围

3. 更新文档
   - 更新相关文档

4. 验证
   - 检查文档是否正确

5. 通知
   - 通知相关人员（如有）
```
