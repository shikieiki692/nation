# 可视化资源使用教程

> 教用户如何在知识点和题目中引用可视化资源。

---

## 一、可视化资源类型

| 类型 | 说明 | 用途 |
|:-----|:-----|:-----|
| CIF文件 | 晶体结构数据文件 | 用VESTA打开查看3D结构 |
| 渲染图片 | 静态PNG图片 | 直接嵌入文档 |
| 分子模型 | 分子3D结构 | 用Avogadro打开查看 |

---

## 二、引用CIF文件

### 2.1 在知识点中引用CIF文件

#### 方法1：在frontmatter中添加

```yaml
---
visualizations:
  - type: crystal_structure
    cif: "08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif"
    description: "NaCl岩盐结构"
---
```

#### 方法2：在正文中使用Wiki-link

```markdown
## 可视化资源

- [[08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif|NaCl结构]]
- [[08-可视化资源/02-CIF文件库/02-离子晶体/CsCl-Pm-3m.cif|CsCl结构]]
```

#### 方法3：在表格中引用

```markdown
## 典型晶体结构

| 物质 | CIF文件 | 配位数 |
|:-----|:--------|:-------|
| NaCl | [[08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif]] | 6:6 |
| CsCl | [[08-可视化资源/02-CIF文件库/02-离子晶体/CsCl-Pm-3m.cif]] | 8:8 |
```

### 2.2 打开CIF文件

1. 确保已安装VESTA
2. 点击Wiki-link打开CIF文件
3. VESTA会自动打开并显示3D结构

## 五、在题目中使用

### 5.1 在题目中添加可视化引用

```yaml
---
title: "NaCl晶胞原子数计算"
visualizations:
  - ref: "[[08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif]]"
    purpose: "辅助理解晶胞结构"
---
```

### 5.2 在题目解析中使用

```markdown
## 解析

NaCl晶胞结构如图所示：

![[08-可视化资源/03-渲染图片/01-晶体结构/01-离子晶体/NaCl-Fm-3m-ball-stick-crystal.png]]

*图：NaCl晶胞*

**晶胞中原子数计算**：
- Na⁺：12×1/4 + 1 = 4
- Cl⁻：8×1/8 + 6×1/2 = 4

因此，每个晶胞含有4个NaCl"分子"。
```

## 六、批量引用

### 6.1 使用Dataview查询

```dataview
TABLE 
  file.name AS "文件名",
  visualizations.cif AS "CIF文件",
  visualizations.description AS "描述"
FROM "03-知识点/无机和结构化学"
WHERE visualizations
SORT file.name ASC
```

### 6.2 使用Dataview查询所有可视化资源

```dataview
TABLE 
  file.name AS "文件名",
  type AS "类型",
  exam_importance AS "重要性"
FROM "08-可视化资源"
WHERE type = "crystal_structure"
SORT exam_importance DESC
```

## 七、常见问题

### Q1：点击CIF链接没有反应？

**A**：确保已安装VESTA并关联了.cif文件扩展名。

### Q2：图片不显示？

**A**：检查图片路径是否正确，文件是否存在。

### Q3：如何添加新的可视化资源？

**A**：
1. 创建CIF文件或渲染图片
2. 按命名规范命名
3. 放入正确的目录
4. 添加元数据
5. 更新索引

### Q4：如何批量引用？

**A**：使用Dataview插件查询。
