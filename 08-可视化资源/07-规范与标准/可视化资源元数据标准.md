# 可视化资源元数据标准

> 定义每个可视化资源应该包含的元数据字段，确保一致性和可管理性。

---

## 一、元数据字段定义

### 1.1 基本信息

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| title | string | ✅ | 资源标题 | "NaCl岩盐结构" |
| type | enum | ✅ | 资源类型 | crystal_structure |
| created | date | ✅ | 创建日期 | 2026-08-02 |
| updated | date | ✅ | 更新日期 | 2026-08-02 |
| status | enum | ✅ | 状态 | draft/published |
| author | string | ❌ | 作者 | "Claude" |

### 1.2 化学信息

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| formula | string | ✅ | 化学式 | "NaCl" |
| formula_html | string | ❌ | HTML格式化学式 | "NaCl" |
| space_group | string | ✅ | 空间群符号 | "Fm-3m" |
| space_group_number | int | ❌ | 空间群编号 | 225 |
| crystal_system | enum | ✅ | 晶系 | cubic |
| structure_type | string | ✅ | 结构类型 | "rock salt" |

### 1.3 结构参数

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| lattice_parameters | object | ❌ | 晶格参数 | {"a": 5.64, "b": 5.64, "c": 5.64} |
| angles | object | ❌ | 晶格角度 | {"alpha": 90, "beta": 90, "gamma": 90} |
| coordination_number | string | ✅ | 配位数 | "6:6" |
| packing_efficiency | float | ❌ | 空间利用率(%) | 67.0 |
| atoms_per_cell | int | ❌ | 晶胞原子数 | 8 |

### 1.4 文件信息

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| cif_file | string | ✅ | CIF文件路径 | "02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif" |
| image_file | string | ❌ | 渲染图片路径 | "03-渲染图片/01-晶体结构/01-离子晶体/NaCl-Fm-3m-ball-stick-crystal.png" |
| file_size | int | ❌ | 文件大小(bytes) | 1024 |
| format | string | ✅ | 文件格式 | "cif" |

### 1.5 关联信息

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| knowledge_points | array | ✅ | 关联知识点 | ["晶体结构", "配位数"] |
| related_cif | array | ❌ | 相关CIF文件 | ["CsCl-Pm-3m.cif", "ZnS-F-43m.cif"] |
| exam_importance | enum | ✅ | 竞赛重要性 | critical/important/optional |
| difficulty | enum | ✅ | 难度 | basic/intermediate/advanced |

### 1.6 可视化信息

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|:-------|:-----|:-----|:-----|:-----|
| display_style | enum | ✅ | 显示样式 | ball-and-stick |
| color_scheme | enum | ❌ | 配色方案 | CPK |
| render_tool | enum | ✅ | 渲染工具 | VESTA |
| render_settings | object | ❌ | 渲染设置 | {"resolution": "3000x2400", "background": "white"} |

## 二、枚举值定义

### 2.1 资源类型 (type)

| 值 | 说明 |
|:---|:-----|
| crystal_structure | 晶体结构 |
| molecule_model | 分子模型 |
| orbital | 轨道 |
| energy_diagram | 能级图 |
| reaction_mechanism | 反应机理 |
| animation | 动画 |

### 2.2 状态 (status)

| 值 | 说明 |
|:---|:-----|
| draft | 草稿 |
| published | 已发布 |
| archived | 已归档 |

### 2.3 晶系 (crystal_system)

| 值 | 说明 |
|:---|:-----|
| cubic | 立方 |
| tetragonal | 四方 |
| orthorhombic | 正交 |
| hexagonal | 六方 |
| trigonal | 三方 |
| monoclinic | 单斜 |
| triclinic | 三斜 |

### 2.4 显示样式 (display_style)

| 值 | 说明 |
|:---|:-----|
| ball-and-stick | 球棍模型 |
| polyhedral | 多面体模型 |
| spacefill | 空间填充模型 |
| wireframe | 线框模型 |

### 2.5 竞赛重要性 (exam_importance)

| 值 | 说明 | 说明 |
|:---|:-----|:-----|
| critical | 必考 | 化学竞赛高频考点 |
| important | 常考 | 较重要的考点 |
| optional | 选学 | 了解即可 |

### 2.6 难度 (difficulty)

| 值 | 说明 |
|:---|:-----|
| basic | 基础 |
| intermediate | 中级 |
| advanced | 高级 |

## 三、元数据模板

### 3.1 CIF文件元数据模板

```yaml
---
title: "{物质名称}{结构类型}"
type: crystal_structure
created: 2026-08-02
updated: 2026-08-02
status: published
author: "Claude"

formula: "{化学式}"
space_group: "{空间群符号}"
crystal_system: {晶系}
structure_type: "{结构类型}"

coordination_number: "{配位数}"
packing_efficiency: {空间利用率}
atoms_per_cell: {晶胞原子数}

cif_file: "02-CIF文件库/{子目录}/{CIF文件名}.cif"
format: "cif"

knowledge_points:
  - "{知识点1}"
  - "{知识点2}"
exam_importance: {critical/important/optional}
difficulty: {basic/intermediate/advanced}

display_style: {ball-and-stick/polyhedral/spacefill}
render_tool: VESTA
---
```

### 3.2 渲染图片元数据模板

status: published

image_file: "03-渲染图片/{子目录}/{图片文件名}.png"

  - "{知识点1}"
  - "{知识点2}"

## 五、验证规则

### 5.1 必填字段检查

- [ ] title 非空
- [ ] type 为有效枚举值
- [ ] created 和 updated 为有效日期
- [ ] formula 非空
- [ ] space_group 非空
- [ ] crystal_system 为有效枚举值
- [ ] coordination_number 非空
- [ ] cif_file 路径存在
- [ ] knowledge_points 至少包含一个知识点
- [ ] exam_importance 为有效枚举值
- [ ] difficulty 为有效枚举值

### 5.2 数据格式检查

- [ ] created 和 updated 为 ISO 8601 格式
- [ ] packing_efficiency 在 0-100 之间
- [ ] atoms_per_cell 为正整数
- [ ] image_file 路径格式正确（如果提供）

### 5.3 一致性检查

- [ ] formula 与 CIF 文件一致
- [ ] space_group 与 CIF 文件一致
- [ ] knowledge_points 与关联知识点文件一致
