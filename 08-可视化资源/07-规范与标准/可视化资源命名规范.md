# 可视化资源命名规范

> 统一命名规则，方便查找、引用和管理。

---

## 一、CIF文件命名

### 格式

```
{化学式}-{空间群符号}.cif
```

### 规则

| 部分 | 说明 | 示例 |
|:-----|:-----|:-----|
| 化学式 | 使用标准化学式，下标用数字表示 | NaCl, CaF2, ZnS |
| 空间群符号 | Hermann-Mauguin符号，去掉空格和上标 | Fm-3m, P63mmc, F-43m |
| 连接符 | 短横线 `-` | - |

### 示例

| 正确 | 错误 | 问题 |
|:-----|:-----|:-----|
| NaCl-Fm-3m.cif | NaCl.cif | 缺少空间群 |
| CaF2-Fm-3m.cif | CaF₂-Fm-3m.cif | 使用了下标字符 |
| ZnS-F-43m.cif | ZnS_F-43m.cif | 使用了下划线 |
| MgAl2O4-Fd-3m.cif | MgAl₂O₄-Fd-3m.cif | 使用了下标字符 |

### 特殊情况

| 情况 | 处理方式 | 示例 |
|:-----|:---------|:-----|
| 同一物质多种结构 | 添加后缀区分 | ZnS-F-43m.cif, ZnS-P63mc.cif |
| 水合物 | 用下划线连接 | CuSO4_5H2O-P21c.cif |
| 配合物 | 用下划线连接配体 | K3FeCN6-R-3c.cif |

## 二、渲染图片命名

### 格式

```
{物质}-{结构类型}-{视角}-{尺寸}.png
```

### 规则

| 部分 | 说明 | 示例 |
|:-----|:-----|:-----|
| 物质 | CIF文件名（不含.cif） | NaCl-Fm-3m |
| 结构类型 | ball-stick / polyhedral / spacefill | ball-stick |
| 视角 | 默认视角可省略，或指定 crystal / [hkl] / [uvw] | crystal, 100, 110 |
| 尺寸 | 可选，如 2x2x2 表示超胞 | 2x2x2 |

### 示例

| 文件名 | 说明 |
|:-------|:-----|
| NaCl-Fm-3m-ball-stick-crystal.png | NaCl球棍模型，晶体视角 |
| NaCl-Fm-3m-polyhedral-crystal.png | NaCl多面体模型，晶体视角 |
| NaCl-Fm-3m-ball-stick-100.png | NaCl球棍模型，(100)面视角 |
| NaCl-Fm-3m-ball-stick-2x2x2.png | NaCl球棍模型，2×2×2超胞 |

## 三、知识库文件中的引用

### CIF文件引用格式

```yaml
---
visualizations:
  - type: crystal_structure
    cif: "08-可视化资源/02-CIF文件库/{子目录}/{CIF文件名}.cif"
    description: "{物质名称}{结构类型}"
---
```

### 示例

```yaml
visualizations:
  - type: crystal_structure
    cif: "08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif"
    description: "NaCl岩盐结构"
```

### Wiki-link引用格式

```markdown
[[08-可视化资源/02-CIF文件库/02-离子晶体/NaCl-Fm-3m.cif|NaCl]]
```

## 四、目录命名

### 格式

```
{序号}-{中文名称}
```

### 规则

| 部分 | 说明 | 示例 |
|:-----|:-----|:-----|
| 序号 | 两位数字，从01开始 | 01, 02, 03 |
| 中文名称 | 简洁明了 | 工具指南, CIF文件库 |

### 示例

| 目录名 | 说明 |
|:-------|:-----|
| 01-工具指南 | 工具操作手册 |
| 02-CIF文件库 | CIF数据文件 |
| 03-渲染图片 | 渲染后的图片 |
| 04-动画脚本 | 动画制作脚本 |
| 05-模板场景 | Blender模板 |
| 06-可视化索引 | 映射关系索引 |

## 六、文件命名禁止事项

| 禁止 | 原因 | 正确做法 |
|:-----|:-----|:---------|
| 使用中文空格 | 会导致链接失效 | 使用英文短横线 |
| 使用特殊字符 | 可能导致编码问题 | 只用字母、数字、短横线、下划线 |
| 使用下标字符 | 不同系统可能不支持 | 使用普通数字 |
| 文件名过长 | 不方便操作 | 控制在50字符以内 |
| 大小写混乱 | 可能导致跨平台问题 | 统一使用小写 |

## 七、验证检查清单

### CIF文件命名检查

- [ ] 化学式使用标准格式（无下标字符）
- [ ] 空间群符号正确（去掉空格和上标）
- [ ] 文件扩展名为 `.cif`
- [ ] 文件名无特殊字符
- [ ] 文件名长度合理

### 渲染图片命名检查

- [ ] 包含物质名称
- [ ] 包含结构类型
- [ ] 视角信息正确
- [ ] 文件扩展名为 `.png`
- [ ] 文件名无特殊字符

### 知识库引用检查

- [ ] 路径正确（相对于vault根目录）
- [ ] CIF文件存在
- [ ] Wiki-link语法正确
- [ ] description字段有意义
