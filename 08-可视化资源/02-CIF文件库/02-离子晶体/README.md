# 离子晶体 CIF 文件库

> 存放离子化合物晶体结构的 CIF 文件。

## 教学重点

| 化合物 | 晶体类型 | 空间群 | 配位数 | 教学要点 |
|:-------|:---------|:-------|:-------|:---------|
| NaCl | 岩盐结构 | Fm-3m | 6:6 | 典型离子晶体、6配位 |
| CsCl | CsCl型 | Pm-3m | 8:8 | 大阳离子、8配位 |
| ZnS（闪锌矿） | 闪锌矿结构 | F-43m | 4:4 | sp³杂化、4配位 |
| ZnS（纤锌矿） | 纤锌矿结构 | P6₃mc | 4:4 | 六方晶系 |
| CaF₂ | 萤石结构 | Fm-3m | 8:4 | 反萤石、8:4配位 |
| TiO₂ | 金红石结构 | P4₂/mnm | 6:3 | 重要氧化物 |
| Al₂O₃ | 刚玉结构 | R-3c | 6:4 | 硬度、宝石 |

## 命名规范

```
{化学式}-{空间群符号}.cif
例：NaCl-Fm-3m.cif、CsCl-Pm-3m.cif
```
