## 教学重点

| 分子 | 晶体类型 | 空间群 | 分子间作用力 | 教学要点 |
|:-----|:---------|:-------|:-------------|:---------|
| H₂O（冰 Ih） | 六方冰 | P6₃/mmc | 氢键 | 氢键网络、密度反常 |
| CO₂（干冰） | 分子晶体 | Pa-3 | 范德华力 | 线性分子堆积 |
| I₂ | 分子晶体 | Cmca | 范德华力 | 卤素晶体、颜色 |
| S₈ | 分子晶体 | Fddd | 范德华力 | 环状分子 |
| C₆₀ | 面心立方 | Fm-3m | 范德华力 | 富勒烯、足球烯 |
| CH₄ | 分子晶体 | F-43m | 范德华力 | 最简单有机晶体 |

## 分子间作用力对比

| 作用力类型 | 强度 | 典型物质 |
|:-----------|:-----|:---------|
| 离子键 | 强 | NaCl、CsCl |
| 共价键 | 强 | 金刚石、SiO₂ |
| 金属键 | 中-强 | Cu、Fe |
| 氢键 | 中 | 冰、HF |
| 范德华力 | 弱 | 干冰、I₂ |
