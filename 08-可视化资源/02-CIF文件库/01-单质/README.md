# 单质 CIF 文件库

> 存放单质晶体结构的 CIF 文件。

## 教学重点

| 单质 | 晶体类型 | 空间群 | 配位数 | 教学要点 |
|:-----|:---------|:-------|:-------|:---------|
| Cu | 面心立方（fcc） | Fm-3m | 12 | 金属键、密堆积 |
| Fe | 体心立方（bcc） | Im-3m | 8 | 金属键、铁磁性 |
| Na | 体心立方（bcc） | Im-3m | 8 | 碱金属晶体 |
| Mg | 六方密堆（hcp） | P6₃/mmc | 12 | A3型密堆积 |
| C（金刚石） | 金刚石结构 | Fd-3m | 4 | 共价键、sp³杂化 |
| C（石墨） | 层状结构 | P6₃/mmc | 3 | sp²杂化、层间范德华力 |
| Si | 金刚石结构 | Fd-3m | 4 | 半导体、sp³杂化 |

## 使用方法

```
VESTA → File → Open → 选择 .cif 文件
```
