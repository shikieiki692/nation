## 命名规范

### CIF文件命名

```
{化学式}-{空间群符号}.cif
例：NaCl-Fm-3m.cif
     CsCl-Pm-3m.cif
     ZnS-F-43m.cif
```

### 渲染图片命名

```
{物质}-{结构类型}-{视角}.png
例：NaCl-Fm-3m-ball-stick-crystal.png
     NaCl-Fm-3m-polyhedral-crystal.png
     Cu-Fm-3m-ball-stick-100.png
```

### 命名规则

| 部分 | 说明 | 示例 |
|:-----|:-----|:-----|
| 物质 | CIF文件名（不含.cif） | NaCl-Fm-3m |
| 结构类型 | ball-stick / polyhedral / spacefill | ball-stick |
| 视角 | crystal / [hkl] / [uvw] | crystal, 100, 110 |

## 渲染流程

### VESTA 渲染步骤

```
1. File → Open → 选择CIF文件
2. Edit → Edit Data → Style → 设置显示样式
3. Edit → Edit Data → Bonds → 设置键长范围
4. View → Rotation → 调整视角
5. File → Export Raster Image → 设置参数 → 导出PNG
```

### 推荐显示参数

| 结构类型 | 样式 | 原子半径 | 键长范围 |
|:---------|:-----|:---------|:---------|
| 离子晶体 | Polyhedral | 标准 | 自动 |
| 共价晶体 | Ball-and-stick | 标准 | 自动 |
| 金属晶体 | Spacefill | 标准 | 无 |
| 分子晶体 | Ball-and-stick | 标准 | 自动 |
| 配合物 | Ball-and-stick | 标准 | 自动 |
