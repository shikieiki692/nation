# 第一轮化学原理讲义改造执行表

> **定位**：基于现有“超级充实版”和已落地备课大纲，改造成更适合第一轮课堂的新授主线。  
> **总口径**：主框架以《普通化学原理》为骨架，课堂难度至少达到《上海中学竞赛教程》对应章节；可适当吸收无机化学和真题中高频、但不破坏主线的内容。

## 一、这次改造到底改什么

- 不再追求“把所有相关知识一次性堆进一讲”。
- 优先解决三类问题：
  - 讲授顺序乱，同一知识点前后分散，学生听完抓不住主线。
  - 一轮主讲内容和二轮分析化/提高内容混在一起，课堂边界不清。
  - 例题、图示、判断流程不够集中，导致学生会背结论但不会调用工具。

## 二、统一改造原则

### 2.1 一讲只围绕一条主问题线

- 气体讲“模型和条件”。
- 热力学讲“方向判据和状态函数”。
- 平衡讲“Q/K 框架”。
- 酸碱讲“质子转移和弱电解质计算”。
- 沉淀讲“Ksp 是平衡在固液体系中的落地”。
- 电化学讲“E°/Nernst 把热力学和平衡翻译成电势”。

### 2.2 每讲都分三层，不再混讲

| 层级 | 用途 | 写法要求 |
|:---|:---|:---|
| **课堂主讲** | 第一轮必须讲透、必须会算、必须会判断 | 放在正文主线和例题链里 |
| **略讲/选讲** | 第一轮可提一句，作为视野或桥梁 | 单独标注“略讲/阅读” |
| **后置内容** | 第二轮分析线、提高班、综合题再系统展开 | 明确写“后置到哪里” |

### 2.3 例题必须跟着知识点走

- 新定义后面立刻跟 1 个最小例题。
- 新公式后面立刻跟 1 个“能算出数”的题。
- 新判断框架后面立刻跟 1 个“会不会发生”的题。
- 不把大量综合题堆到讲义末尾才出现。

### 2.4 第一轮讲义统一结构

1. 为什么要学这个
2. 本讲主线工具
3. 典型例题链
4. 易错点
5. 课后练习
6. 下一讲衔接

## 三、当前执行顺序

| 优先级 | 讲义 | 当前判断 | 本次改造动作 |
|:---:|:---|:---|:---|
| 1 | 酸碱理论 | 主体已厚，但混入了不少分析线内容 | 保留母版厚度，补“第一轮使用说明”，把滴定曲线/指示剂/缓冲容量定量分析明确后置 |
| 1 | 沉淀溶解平衡 | 目前被“水中的几种平衡”宽页代替，主线不够干净 | 独立成第一轮主讲讲义，主线聚焦 $K_{\mathrm{sp}}$、溶解度、同离子效应、$Q/K_{\mathrm{sp}}$、酸溶、分步沉淀入门 |
| 1 | 电化学基础 | 主体已厚，但末段过宽 | 保留母版厚度，补“第一轮使用说明”，把腐蚀、电池分类、较重的 Latimer 使用分层 |
| 1 | 化学计量与计算规范 | 已独立成桥梁讲义，是第一轮计算入口 | 后续继续补和气体、溶液、滴定的跨页挂接 |

| 2 | 气体与溶液基础 | 现有内容可用，但入口仍偏合并 | 后续继续拆清“计量工具”“气体模型”“溶液语言”三层关系 |
| 2 | 热力学初步 | 主线已经比较稳 | 继续补图示和真题映射，不急着重写骨架 |
| 2 | 化学动力学初步 | 主线已经比较稳 | 继续补图示和题型回链，不急着重写骨架 |
| 2 | 化学平衡 | 主线已经比较稳 | 继续强化和酸碱/沉淀/电化学的统一入口作用 |

## 四、每讲的最低完成标准

| 项目 | 标准 |
|:---|:---|
| 主线 | 学生能说清“本讲到底在解决什么问题” |
| 顺序 | 不出现同一知识点在三处零散出现的情况 |
| 例题 | 至少 3 题：定义题、公式题、判断题 |
| 边界 | 明确哪些内容只是略讲，哪些后置 |
| 练习 | 至少 5 题，覆盖基础到提高的连续梯度 |
| 衔接 | 明确写出与上一讲、下一讲的关系 |

## 五、目前对第一轮化学原理的简化口径

> **一句话**：第一轮不是百科全书，也不是只讲皮毛，而是把普化主干真正压成学生能听懂、能计算、能判断、能迁移的课堂语言。

| 讲次 | 第一轮主讲焦点 | 明确不在这一讲里展开的内容 |
|:---|:---|:---|
| 化学计量与计算规范 | 单位、有效数字、守恒、计量步骤 | 复杂分析误差统计 |
| 气体与溶液基础 | 理想气体、分压、浓度、依数性基础 | 活度和复杂相图 |
| 热力学初步 | $\Delta H$、$\Delta S$、$\Delta G$、方向判据 | 严格物化推导 |
| 化学动力学初步 | 速率、级数、Arrhenius | 复杂反应机理和稳态近似 |
| 化学平衡 | $Q/K$、平衡移动、统一框架 | 活度平衡和复杂耦合严密求解 |
| 酸碱理论 | Brønsted、弱酸弱碱、两性、缓冲 | 滴定曲线、终点误差、系统分析线 |
| 沉淀溶解平衡 | $K_{\mathrm{sp}}$、溶解度、同离子、酸溶、选择性沉淀入门 | 沉淀转化完整计算、复杂多重平衡 |
| 氧化还原与电化学 | 原电池、E°、Nernst、$\Delta G^\theta-E^\theta-K^\theta$ | 腐蚀体系、电池分类大全、电极动力学 |

## 六、当前落点

- 本轮先把“酸碱理论、沉淀溶解平衡、电化学基础”三讲改到课堂可直接使用。
- 后续继续把“化学计量与计算规范”“方程式书写专项”两份桥梁讲义与具体新授课做更细连接。
- 这样做的好处是：先把最容易混轮次、最容易把学生讲晕的三讲收干净，第一轮化学原理主线就会立刻顺很多。
