# 未央化学竞赛课程计划（初二至高二）

## 一、总体课程规划

| 时间 | 预计课时 | 课程模块 |
|:---|:---|:---|
| 初二学年 | 24次 | 化学基础知识｜结构化学｜物理化学 |
| 初三上学期 | 36次 | 无机化学 |
| 寒假 | 12次 | 无机化学 |
| 初三下学期 | 36次 | 无机化学｜分析化学 |
| 暑假 | 12次 | 分析化学 |
| 高一上学期 | 36次 | 有机化学 |
| 寒假 | 12次 | 有机化学 |
| 高一下学期 | 36次 | 有机化学｜结构化学 |
| 暑假 | 12次 | 结构化学｜物理化学 |
| 高二上学期 | 36次 | 一轮复习 |
| 寒假 | 12次 | 外出学习（结构化学为主） |
| 高二下学期 | 36次 | 一轮复习｜真题训练 |
| 暑假 | 12次 | 外出学习（综合培训） |
