## 一、总原则：什么内容该放在哪一轮

> **核心判定原则**：第一轮深度边界以《普通化学原理》、《上海中学竞赛教程》和赵鑫光《高中化学竞赛基本理论学习笔记》为三本并列基石基准，原则上应当**覆盖这三本书里绝大多数会直接服务初赛的主线内容**。换句话说，除了元素化学系统轮、分析化学系统轮、明显偏深的物化推导、以及科普/边缘章节外，这三本书里系统讲了且能稳定服务第一轮课堂的内容，都应尽量在第一轮找到课堂落点；再往上的内容（如热力学严格推导、物理化学深化、群论/统计力学等）放到第三轮或更后。

| 判断标准     | 第一轮              | 第二轮                  | 第三轮             | 第四轮      |
| :------- | :--------------- | :------------------- | :-------------- | :--------- |
| **定位**   | 高中→竞赛衔接          | 元素系统 + 分析系统           | 有机系统 + 物化/结构基础提升 | 冲刺/决赛      |
| **内容特征** | 基础语言、工具建立、直觉形成   | 把化学原理/无机知识压回元素主线，把分析技术压成方法系统 | 机理、选择性、结构与物化基础系统化 | 综合、难点、决赛专题 |
| **基石教材** | 《普通化学原理》+ 《上海中学竞赛教程》+ 赵鑫光笔记（三本并列基石）；辅助：无机化学 | 《分析化学》（武大）+ 《无机化学》下册（并列）；衔接参考：普化原理Ch15 | Atkins物理化学 + 结构化学基础（待导入）；ABOC + Clayden | 高等有机 + 有机合成策略 + 人名反应 + 高等无机结构化学 + 元素化学（多为待导入） |
| **数学要求** | 高中数学             | 简单微积分/对数运算           | 微积分、线性代数基础      | 高阶数学工具     |
| **分析化学** | 只涉及酸碱平衡基础计算      | **以《分析化学》第六版相关内容为上限，四大滴定+重量+误差+分光光度+条件平衡系统讲完** | 仪器分析深化          | 前沿方法       |
| **元素化学** | 不讲（除配合物基础）       | **以元素为主线，把竞赛所需的化学原理 + 无机化学相关内容系统讲完** | 深化（多酸、簇合物、生物无机） | 前沿元素化学     |
| **有机化学** | 只讲分子结构预热（官能团、杂化） | 不讲                   | **系统讲完**        | 全合成、前沿反应   |
| **学生侧材料** | KP闪卡+基础练习卷+方法策略卡+自查清单 | 性质速记卡+过程分训练卷+易错点便携版+方程式听写卡 | 完整四层（机理闪卡+逆合成策略卡+诊断报告+薄弱点追踪） | 决赛专题冲刺材料 |

> **第五轮规划说明（2026-07-27）**：第五轮目前在规划中，主要定位为**内容收尾与决赛深化**，不另设独立的轮次深度切分条目。R5内容将从R4中自然延伸，具体专题待R4执行后根据决赛需求确定。详细骨架见 `[[备课思路/第五轮总体备课框架]]`。

> **补充口径（2026-06-20 修订 2026-07-27）**：第一轮不是”只讲一点计量和平衡”，而是应把《普通化学原理》、《上海中学竞赛教程》和赵鑫光笔记中的**气体、溶液、热力学、化学平衡、动力学基础、酸碱、电化学、原子结构、化学键、分子结构、晶体与配位入门**尽量系统吃进。真正后置的，主要是 `元素化学系统展开 / 分析化学系统展开 / 更深的物化理论化处理`。

> **第二轮同步口径（2026-06-21 修订 2026-07-27）**：第二轮不是”背元素性质 + 做几种滴定”这么窄，而是以**《分析化学》（武大）和《无机化学》下册为并列基石**，把**竞赛相关的化学原理与无机化学内容按元素主线重组讲完**，并把**《分析化学》相关内容按分析流程讲完**。《普通化学原理》第15章（元素化学）作为衔接参考，保留从原理到元素的过渡桥梁功能。

> **第三轮同步口径（2026-06-21 修订 2026-07-27）**：第三轮不是”有机稍微深化一点”，而是要以**基础有机化学（ABOC）+ Clayden 主线**系统讲完有机，并以**Atkins物理化学 + 结构化学基础**为无机/结构深化基石，把第一轮的原理/结构主题提升到至少**物理化学基础 + 结构化学基础**层级；重要选择性、立体化学、周环、自由基、配位光谱与对称桥梁都应在这一轮形成稳定课堂入口。辅助材料包括有机化学基础（第四版，待导入）、中级有机化学（待导入）、超分子化学（Steed，已导入）、无机化学（Weller第五版选择性导入+第六版已导入）等。

> **外部校准（2026-06-21）**：
> - [IChO 2026 Exam information](https://www.icho2026.uz/exam-info) 明确把 practical 放在 `organic / inorganic / physical chemistry`，theoretical 放在 `physical / organic / inorganic / analytical chemistry`。
> - [IChO 概览（含 regulations 摘要）](https://en.wikipedia.org/wiki/International_Chemistry_Olympiad) 进一步提示竞赛 syllabus 长期覆盖 `organic / inorganic / physical / analytical / biochemistry / spectroscopy`。
> - [USNCO exam format](https://en.wikipedia.org/wiki/United_States_National_Chemistry_Olympiad) 的题序则非常接近 `descriptive/lab -> stoichiometry -> gases/liquids/solids -> thermo -> kinetics -> equilibrium -> electrochem -> structure/periodic -> bonding -> organic`。
>
> **第四轮同步口径（2026-07-27）**：第四轮不是"再学一堆新知识"，而是把前三轮已建立的工具、模型和专题能力**压缩成决赛可调用的综合判断链**。有机线以高等有机化学+有机合成策略+人名反应为基石（4-1/4-2/4-3），无机结构线以高等无机结构化学为基石（4-4/4-5），元素化学深化为基础（4-6），物化综合计算为压轴（4-7），真题模拟为全轮收束（4-8）。R4的核心原则是"压缩不扩张、缝合不堆砌、题型不背景"——不讲新概念，只把已有知识压成速查卡、判据链和课堂投影型判断链。详见 [[备课思路/第四轮总体备课框架]]。
>
> **由此得到的执行推论**：
> - 轮次切分不能只按“知识点深浅”切，还要显式维护 `实验与测量 / 波谱与表征 / 结构-性质-反应桥梁 / 生化低频线` 这些跨模块线程。
> - 第一轮必须足够像一条稳定的“普化骨架”，否则第二轮元素化学和第三轮结构/有机会失去承接面。
> - 第三轮不能只写“有机 + 结构深化”，还要把 `波谱、配位光谱、对称桥梁` 明确成常驻线程。

> 💡 **学生侧材料说明**：四层体系（记忆/理解/应用/元认知）已纳入各轮次总体备课框架。详见 [[备课思路/第一轮总体备课框架]] §六、[[备课思路/第二轮总体备课框架]] §七、[[备课思路/第三轮总体备课框架]] §八。

> **🎯 深度标记统一 schema（2026-08-03 全表推广）**

## 四、除考纲条目外，必须显式维护的跨模块线程

> 这几条线程不是单独某一条考纲，却会直接决定课堂是否“像竞赛课”，因此在轮次切分时必须显式维护。

### 4.1 线程A：实验与测量

| 轮次 | 目标 |
|:---|:---|
| 第一轮 | 单位、有效数字、条件控制、气体收集、基础观察语言 |
| 第二轮 | 滴定、重量、比色、误差、标准曲线、定性分析信号 |
| 第三轮 | 动力学/光谱/XRD 数据解释，实验设计与结果回判 |
| 第四轮 | IChO practical 风格整合与复杂实验解释 |

### 4.2 线程B：波谱与表征

| 轮次 | 目标 |
|:---|:---|
| 第一轮 | Lewis/VSEPR/MO 初步、颜色与结构的最基础联系 |
| 第二轮 | Lambert-Beer、颜色信号、配位/沉淀/价态的表征直觉 |
| 第三轮 | IR / NMR / UV-Vis / 配位光谱 / XRD / 对称性-选律系统入口 |
| 第四轮 | 真题中的谱图-结构-机理联动整合 |

### 4.3 线程C：结构-性质-反应桥梁

| 轮次 | 目标 |
|:---|:---|
| 第一轮 | 周期律、键型、几何、平衡、电化学的基础桥接 |
| 第二轮 | 元素结构 → 性质 → 信号 → 反应的整套调用 |
| 第三轮 | 轨道、对称、场强、选择性、机理、光谱的高阶桥接 |
| 第四轮 | 跨专题压轴题整合 |

### 4.4 线程D：生化与材料低频线

| 轮次 | 目标 |
|:---|:---|
| 第一轮 | 不单列主线，只保留氢键、溶剂化、聚集态等必要直觉 |
| 第二轮 | 在元素和分析情境中少量穿插材料/环境/生命化学现象 |
| 第三轮 | 糖、氨基酸、高分子、超分子形成系统入口 |
| 第四轮 | 生化与材料化学深化，按真题/决赛需要扩展 |

## 五、使用规范

### 5.1 备课大纲引用本表的方式

备课大纲中的 `deferred_topics` 不应写"放到第二轮"，而应写：

```markdown
| deferred_topic | 为什么本轮不展开 | 正确轮次归属 | 课堂若被问到如何处理 |
|:---|:---|:---|:---|
| 酸碱滴定曲线与指示剂选择 | 第一轮只建立酸碱平衡基础计算；滴定系统内容在第二轮分析化学专题 | **第二轮专题9** | "滴定曲线和指示剂选择是分析化学的核心内容，第二轮系统学习酸碱滴定时会深入讲。" |
```

### 5.2 本表的更新流程

```text
发现某备课大纲的 deferred_topic 归属与本表冲突
  ↓
判断：是备课大纲错了，还是本表需要调整？
  ├─ 备课大纲错了 → 修正备课大纲，保持本表不变
  └─ 本表需要调整 → 修正本表，并同步更新所有引用该 deferred_topic 的备课大纲
```

### 5.3 备课时不要只查“轮次”，还要查“线程”

```text
确定专题属于哪一轮
  ↓
检查该专题挂在哪些线程上
  ├─ 实验与测量
  ├─ 波谱与表征
  ├─ 结构-性质-反应桥梁
  └─ 生化与材料低频线
  ↓
再决定课堂里是否要提前埋入口、是否只讲信号不讲定量、是否该在下一轮系统展开
```
