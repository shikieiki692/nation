## 命名规范

格式：`年份-来源-类型[-版本].pdf`

| 示例 | 说明 |
|------|------|
| `2024-湖北预赛-试题.pdf` | 省预赛 |
| `2024-湖北预赛-答案.pdf` | 配套答案单独成卷时 |
| `2023-UKChO-Round1-试题.pdf` | 国际赛事注明轮次 |
| `2019-USNCO-Local-试题.pdf` | USNCO 注明 Local/National |

原则：
1. **试题与答案分开下载就分开命名**，方便 OCR 时对齐；
2. 同名文件加 `-v2` 后缀，不覆盖；
3. 中文优先，国际赛事保留英文原名关键词。

## OCR 后入库流程

1. PDF 移入对应子目录，按规范命名；
2. OCR（mineru 流程），md 输出至 `06-外部资料导入/` 对应目录；
3. 图片提取到同级 `_images/` 目录（沿用哈希原名规则）；
4. 按 `11-模板/` 与题库格式速查拆题入库到 `04-题库/`，frontmatter 标注 source/year/difficulty/knowledge_points；
5. 更新 `04-题库/题库总索引.md` 计数；
6. 在 `06-外部资料导入/OCR待整理清单.md` 中销账。
