# 题型 · 氮族化合物推断

## 解题思路

氮族化合物推断题是元素推断题的高频考点，涉及氮及其化合物的性质、结构、反应等。解题流程如下：

1. **识别化合物类型**：根据题目现象或描述，判断涉及的是哪种氮化合物
2. **分析氧化态**：确定氮的氧化态（-3, 0, +1, +2, +3, +4, +5）
3. **判断反应类型**：氧化还原、歧化、归中、配合等
4. **结合实验现象**：颜色、沉淀、气体、气味等
5. **推断结论**：根据以上分析得出答案

**快速判断口诀：**
- **N₂O**：笑气，麻醉气体，无色，直线形
- **NO**：无色气体，遇空气变红棕色，顺磁性
- **NO₂**：红棕色气体，刺激性气味，二聚平衡
- **HNO₃**：强氧化性酸，浓/稀产物不同
- **NH₃**：碱性气体，遇HCl白烟，配位能力强

## 核心方法与知识点

### 1. 氮的氧化态与化合物

| 氧化态 | 化合物 | 性质 | 常见反应 |
---:|:---|:---|:---|
| **-3** | NH₃（氨） | 碱性气体，配位能力强 | 与HCl→白烟（NH₄Cl） |
| **0** | N₂（氮气） | 惰性，三键稳定 | 高温高压→NH₃（Haber法） |
| **+1** | N₂O（笑气） | 麻醉气体，无色 | 加热分解→N₂ + O₂ |
| **+2** | NO（一氧化氮） | 无色，顺磁性 | 遇空气→NO₂（红棕色） |
| **+3** | HNO₂（亚硝酸） | 弱酸，不稳定 | 歧化→NO + NO₂ + H₂O |
| **+4** | NO₂（二氧化氮） | 红棕色，刺激性 | 与水→HNO₃ + NO |
| **+5** | HNO₃（硝酸） | 强酸，强氧化性 | 与金属→硝酸盐 + NOx |

### 2. 氮氧化物（NOx）性质对比

| 化合物 | 氧化态 | 颜色 | 磁性 | 关键性质 | 常见陷阱 |
|:---|:---:|:---|:---|:---|:---|
| **N₂O** | +1 | 无色 | 抗磁性 | 直线形，π₃⁴ 键 | 不是NO的二聚体 |
| **NO** | +2 | 无色 | 顺磁性 | 奇电子分子 | 易被O₂氧化为NO₂ |
| **NO₂** | +4 | 红棕色 | 顺磁性 | 二聚平衡 | 低温→N₂O₄（无色） |
| **N₂O₅** | +5 | 白色固体 | 抗磁性 | 离子型[NO₂]⁺[NO₃]⁻ | 气态为共价分子 |
| **N₂O₃** | +3 | 蓝色液体 | 抗磁性 | 仅低温/固态存在 | 易分解为NO + NO₂ |

### 3. NOx的歧化反应

| 反应物 | 介质 | 歧化产物 | 现象 | 应用 |
|:---|:---|:---|:---|:---|
| **NO₂** | 水 | HNO₃ + NO | 红棕色气体溶解 | 制硝酸 |
| **NO₂** | 碱 | NO₃⁻ + NO₂⁻ | 气体被吸收 | 尾气处理 |
| **HNO₂** | 酸 | NO + NO₂ + H₂O | 不稳定分解 | 亚硝酸性质 |

### 4. 硝酸的氧化性

**浓硝酸（12-16 mol/L）**：主要还原产物NO₂
```
Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
```

**稀硝酸（6-8 mol/L）**：主要还原产物NO
```
3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
```

**极稀硝酸**：主要还原产物NH₄⁺
```
4Zn + 10HNO₃(极稀) → 4Zn(NO₃)₂ + NH₄NO₃ + 3H₂O
```

### 5. 氨的配位反应

| 配合物 | 颜色 | 稳定常数 | 应用 |
|:---|:---|:---|:---|
| [Ag(NH₃)₂]⁺ | 无色 | K=1.6×10⁷ | 银镜反应 |
| [Cu(NH₃)₄]²⁺ | 深蓝色 | K=1.1×10¹³ | 铜的鉴定 |
| [Zn(NH₃)₄]²⁺ | 无色 | K=2.9×10⁹ | 锌的分离 |
| [Ni(NH₃)₆]²⁺ | 蓝紫色 | K=2.0×10⁸ | 镍的鉴定 |

## 典型例题

### 例题1：NOx的性质推断（基础）

**题目**：某无色气体A在空气中变为红棕色气体B。
(1) 写出A和B的化学式
(2) 写出A在空气中反应的方程式
(3) B溶于水的反应方程式
(4) 解释为什么B溶于水后溶液呈酸性

**解题过程**：

**(1) 化学式推断**

- **现象分析**：无色气体在空气中变红棕色
- **判断**：A是NO（无色），B是NO₂（红棕色）
- **验证**：NO遇空气立即被氧化为NO₂

**(2) A在空气中的反应**

- **反应方程式**：
  ```
  2NO + O₂ → 2NO₂
  ```
- **现象**：无色气体变为红棕色
- **说明**：该反应是NO的特征反应，可用于NO的检验

**(3) B溶于水的反应**

- **反应方程式**：
  ```
  3NO₂ + H₂O → 2HNO₃ + NO
  ```
- **现象**：红棕色气体溶解，生成无色气体NO
- **应用**：工业制硝酸的关键步骤

**(4) 溶液呈酸性的原因**

- **分析**：生成的HNO₃是强酸，完全电离
- **电离方程式**：
  ```
  HNO₃ → H⁺ + NO₃⁻
  ```
- **pH计算**：若NO₂完全反应，溶液pH取决于HNO₃浓度

**反思**：NOx的歧化反应是氮化学的核心，需掌握NO→NO₂→HNO₃的转化链。

### 例题2：硝酸与金属反应（综合）

**题目**：将足量铜加入一定量浓硝酸中，观察到以下现象：
(1) 铜片溶解，溶液变蓝
(2) 产生红棕色气体
(3) 反应后期气体颜色变浅

解释以上现象，并写出相关反应方程式。

**解题过程**：

**(1) 铜片溶解，溶液变蓝**

- **原因**：Cu与浓HNO₃反应生成Cu(NO₃)₂
- **反应方程式**：
  ```
  Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
  ```
- **现象解释**：Cu²⁺在溶液中呈蓝色

**(2) 产生红棕色气体**

- **原因**：生成的NO₂是红棕色气体
- **反应方程式**：同上
- **现象解释**：NO₂有刺激性气味，可使湿润的蓝色石蕊试纸变红

**(3) 反应后期气体颜色变浅**

- **原因**：随着反应进行，HNO₃浓度降低，变为稀硝酸
- **反应方程式**：
  ```
  3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
  ```
- **现象解释**：NO是无色气体，所以颜色变浅

**总结**：
- **初始阶段**：浓HNO₃ → NO₂（红棕色）
- **后期阶段**：稀HNO₃ → NO（无色）
- **总反应**：取决于HNO₃的浓度变化

**反思**：硝酸的还原产物取决于浓度，这是竞赛高频考点，需掌握浓/稀/极稀三种情况。

### 例题3：氮氧化物的综合推断（竞赛）

**题目**：某混合气体可能含有N₂O、NO、NO₂中的两种或三种。进行如下实验：
(1) 混合气体通入水中，气体体积减少1/3，溶液呈酸性
(2) 剩余气体通入NaOH溶液，体积又减少2/3

判断混合气体的组成，并说明理由。

**解题过程**：

**分析思路**：根据气体体积变化和反应特性进行推断

**实验(1)分析**：
- 混合气体通入水中，体积减少1/3
- 可能的反应：
  - 3NO₂ + H₂O → 2HNO₃ + NO（体积减少2/3）
  - N₂O与水不反应
  - NO与水不反应
- 若只有NO₂：体积应减少2/3，但实际减少1/3，说明还有其他气体

**实验(2)分析**：
- 剩余气体通入NaOH溶液，体积又减少2/3
- 可能的反应：
  - 2NO₂ + 2NaOH → NaNO₃ + NaNO₂ + H₂O（体积减少1/2）
  - NO + NO₂ + 2NaOH → 2NaNO₂ + H₂O（体积减少1）
- 若剩余气体是NO₂和NO的混合物，体积减少2/3

**推断结论**：
- **组成**：NO₂和NO的混合物
- **比例**：设NO₂为x mol，NO为y mol
- **实验(1)**：3x/2 = (x+y)/3 → x = 2y
- **实验(2)**：剩余NO为y + x/3 = 5y/3，通入NaOH后减少2/3，符合
- **验证**：NO₂:NO = 2:1

**答案**：混合气体由NO₂和NO组成，体积比为2:1。

**反思**：氮氧化物推断题需要综合考虑反应特性、体积变化、溶液性质等多方面信息。

## 易错点与注意事项

### 1. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|:---|:---|:---|
| **NOx颜色错误** | "NO是红棕色气体" | NO是无色气体，NO₂是红棕色 |
| **氧化态计算错误** | "N₂O₅中N为+4" | N₂O₅中N为+5 |
| **歧化反应错误** | "NO₂溶于水生成HNO₂" | NO₂溶于水生成HNO₃和NO |
| **硝酸还原产物错误** | "稀硝酸与铜反应生成NO₂" | 稀硝酸与铜反应生成NO |

### 2. 解题检查清单

- [ ] 是否正确识别了氮的氧化态
- [ ] 是否判断了反应类型（歧化/归中/氧化还原）
- [ ] 产物是否合理（气体、溶液）
- [ ] 方程式是否配平（质量守恒、电荷守恒）
- [ ] 实验现象是否与产物一致

### 3. 高频考点

1. **NOx的性质对比**：颜色、磁性、二聚平衡
2. **NO₂溶于水的反应**：3NO₂ + H₂O → 2HNO₃ + NO
3. **硝酸的氧化性**：浓/稀/极稀产物不同
4. **氨的配位反应**：[Ag(NH₃)₂]⁺、[Cu(NH₃)₄]²⁺等
5. **NOx的歧化**：NO₂、HNO₂的歧化反应

### 4. 实验注意事项

- **NO处理**：有毒气体，需在通风橱中操作
- **NO₂处理**：强刺激性，需用NaOH溶液吸收
- **硝酸保存**：需避光保存，防止分解
