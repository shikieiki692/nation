# 题型 · 沉淀转化

> **核心支撑页**：[[专题-沉淀溶解平衡]]

## 解题思路

沉淀转化题的核心在于 **转化方向由 Ksp 大小决定——向 Ksp 更小的方向自发进行**。面对这类题型，第一步是写出转化反应方程式（旧沉淀 + 新沉淀剂 → 新沉淀 + 旧沉淀的离子）；第二步是计算转化平衡常数 $K = K_{\text{sp}}(\text{旧})/K_{\text{sp}}(\text{新})$；第三步是判断转化是否完全——通常 $K > 10^6$ 视为定量转化。

沉淀转化的本质是溶解平衡的竞争：两种沉淀争夺同一种离子，Ksp 更小的沉淀"赢得"该离子。例如 AgCl(s) + I⁻ → AgI(s) + Cl⁻，$K = K_{\text{sp}}(\text{AgCl})/K_{\text{sp}}(\text{AgI}) \gg 1$，说明 AgI 更难溶，转化自发。此原理在元素分离、定性分析和 Mohr 法测氯中有广泛应用。注意：沉淀转化的平衡常数只与两个 Ksp 有关，与沉淀剂浓度无关。

## 核心方法

1. **平衡常数计算法**：$K = K_{\text{sp}}(\text{旧沉淀})/K_{\text{sp}}(\text{新沉淀})$。K > 10⁶ 定量转化；K 在 10²-10⁶ 部分转化；K < 10² 基本不转化。
2. **方向判断法**：转化总是向 Ksp 更小（更难溶）的方向进行。不能仅凭经验判断"谁更难溶"，必须计算 K 值。
3. **多步转化法**：当存在多种沉淀时，逐步计算每步转化的 K 值。例如 AgCl → AgBr → AgI，每步 K 都很大，说明逐步转化完全。
4. **离子浓度追踪法**：转化过程中，旧沉淀释放的离子浓度等于新沉淀消耗的离子浓度（化学计量比 1:1 时）。可用 Q > Ksp 判断新沉淀是否生成。
5. **溶度积比值速查法**：常见转化对的 K 值可速记——AgCl/AgI ≈ 2×10⁶，BaSO₄/BaCO₃ ≈ 10⁻⁴（反向转化需加 Na₂CO₃）。

## 典型例题

### 例题 1：AgCl 向 AgI 的转化

**题目**：向含有 AgCl 沉淀的悬浮液中加入 KI 溶液，观察到白色沉淀变为黄色。(1) 写出转化反应方程式；(2) 计算转化平衡常数；(3) 若初始 [I⁻] = 0.010 mol/L，计算转化达平衡时 [Cl⁻]/[I⁻] 的比值。已知 $K_{\text{sp}}(\text{AgCl}) = 1.8 \times 10^{-10}$，$K_{\text{sp}}(\text{AgI}) = 8.5 \times 10^{-17}$。

**解答**：

(1) $\mathrm{AgCl(s)} + \mathrm{I^-} \rightleftharpoons \mathrm{AgI(s)} + \mathrm{Cl^-}$

(2) $K = \frac{[\mathrm{Cl^-}]}{[\mathrm{I^-}]} = \frac{K_{\text{sp}}(\mathrm{AgCl})}{K_{\text{sp}}(\mathrm{AgI})} = \frac{1.8 \times 10^{-10}}{8.5 \times 10^{-17}} = 2.1 \times 10^{6}$

(3) 平衡时 $\frac{[\mathrm{Cl^-}]}{[\mathrm{I^-}]} = K = 2.1 \times 10^{6}$

即 [Cl⁻] 远大于 [I⁻]，说明转化几乎完全。

---

### 例题 2：BaSO₄ 向 BaCO₃ 的转化（反向转化）

**题目**：$K_{\text{sp}}(\mathrm{BaSO_4}) = 1.1 \times 10^{-10}$，$K_{\text{sp}}(\mathrm{BaCO_3}) = 5.1 \times 10^{-9}$。(1) 计算反应 $\mathrm{BaSO_4(s)} + \mathrm{CO_3^{2-}} \rightleftharpoons \mathrm{BaCO_3(s)} + \mathrm{SO_4^{2-}}$ 的平衡常数；(2) 若要使 BaSO₄ 转化为 BaCO₃，[CO₃²⁻]/[SO₄²⁻] 的最小比值是多少？

**解答**：

(1) $K = \frac{[\mathrm{SO_4^{2-}}]}{[\mathrm{CO_3^{2-}}]} = \frac{K_{\text{sp}}(\mathrm{BaSO_4})}{K_{\text{sp}}(\mathrm{BaCO_3})} = \frac{1.1 \times 10^{-10}}{5.1 \times 10^{-9}} = 0.022$

K ≪ 1，说明 BaSO₄ 向 BaCO₃ 的转化在标准条件下**不自发**。

(2) 要使转化发生，需 $Q > K_{\text{sp}}(\mathrm{BaCO_3})$，即需要高浓度 CO₃²⁻：
$$\frac{[\mathrm{CO_3^{2-}}]}{[\mathrm{SO_4^{2-}}]} > \frac{1}{K} = \frac{1}{0.022} = 46$$

即 [CO₃²⁻] 至少是 [SO₄²⁻] 的 46 倍以上才可能推动转化。

## 易错点

1. **K 值方向写反**：$K = K_{\text{sp}}(\text{旧})/K_{\text{sp}}(\text{新})$，不是反过来。转化向 Ksp 更小的方向进行。
2. **K 值与转化程度的对应关系**：K > 10⁶ 才算定量转化，K = 10³ 只是部分转化，不能说"完全转化"。
3. **忽略沉淀转化的可逆性**：沉淀转化是可逆平衡，即使 K 很大也不能说"100% 转化"——只能说"在实验精度内完全转化"。
4. **反向转化需要过量沉淀剂**：BaSO₄ → BaCO₃ 的 K < 1，需要大量过量 Na₂CO₃（浓度比 > 46 倍）才能推动转化。实际操作中需多次更换饱和 Na₂CO₃ 溶液。
