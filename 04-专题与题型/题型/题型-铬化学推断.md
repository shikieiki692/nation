# 题型 · 铬化学推断

> **核心支撑页**：[[专题-过渡金属（一）钛钒铬锰]]、[[专题-过渡金属元素化学]]

## 解题思路

铬化学推断的核心在于 **Cr(III)/Cr(VI) 的颜色互转及其 pH 依赖性**。面对这类题型，首先锁定颜色信号：绿色溶液 → Cr³⁺（最稳定氧化态）；橙色溶液 → Cr₂O₇²⁻（酸性 Cr(VI)）；黄色溶液 → CrO₄²⁻（碱性 Cr(VI)）。然后判断转化方向——CrO₄²⁻ 与 Cr₂O₇²⁻ 之间的平衡受 pH 驱动（2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O），加酸变橙、加碱变黄是经典现象。

铬的氧化还原推断需结合介质条件：酸性介质中 Cr₂O₇²⁻ 是强氧化剂（Eθ = 1.36 V），可氧化 Fe²⁺、I⁻、C₂O₄²⁻、乙醇等，自身被还原为 Cr³⁺（绿色）；碱性介质中 Cr(III) 可被 H₂O₂、NaClO 等氧化为 CrO₄²⁻（黄色）。此外，Cr(OH)₃ 是两性氢氧化物，既溶于酸又溶于过量碱（生成 [Cr(OH)₄]⁻），这一点与 Al(OH)₃ 类似但可通过颜色区分（Cr³⁺ 有颜色，Al³⁺ 无色）。

## 核心方法

1. **颜色-介质锁定法**：绿色 → Cr³⁺；橙色（酸性） → Cr₂O₇²⁻；黄色（碱性） → CrO₄²⁻。先判介质再判物种。
2. **CrO₄²⁻/Cr₂O₇²⁻ 平衡调控法**：加酸 → 平衡右移变橙（Cr₂O₇²⁻）；加碱 → 平衡左移变黄（CrO₄²⁻）。此平衡是 pH 指示的基础。
3. **酸性氧化性利用法**：Cr₂O₇²⁻ 在酸性条件下可氧化多种还原剂，自身还原为绿色 Cr³⁺——"橙色变绿色"是 Cr(VI) 氧化性的标志信号。
4. **碱性氧化法**：Cr(III) 在碱性条件下可被 H₂O₂、NaClO 氧化为 CrO₄²⁻——"绿色变黄色"是 Cr(III) 被氧化的标志信号。必须碱性条件，酸性下 Cr(VI) 会反向氧化还原剂。
5. **两性区分法**：Cr(OH)₃ 灰绿色沉淀溶于过量 NaOH → [Cr(OH)₄]⁻（绿色）；与 Al(OH)₃ 的区分靠颜色（Cr³⁺ 有色，Al³⁺ 无色）。

## 典型例题

### 例题 1：Cr(VI)/Cr(III) 互转推断

**题目**：向黄色溶液 A 中加入稀 H₂SO₄，溶液变为橙色。向橙色溶液中加入 Na₂SO₃，溶液变为绿色。向绿色溶液中加入过量 NaOH，出现灰绿色沉淀，继续加 NaOH 沉淀溶解变为绿色溶液。推断各步变化涉及的铬的物种，并写出相关离子方程式。

**解答**：

(1) 黄色 + 酸 → 橙色：CrO₄²⁻ 在酸性条件下转化为 Cr₂O₇²⁻。
$$2\mathrm{CrO_4^{2-}} + 2\mathrm{H^+} \rightleftharpoons \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O}$$

(2) 橙色 + Na₂SO₃ → 绿色：酸性 Cr₂O₇²⁻ 氧化 SO₃²⁻，自身还原为 Cr³⁺。
$$\mathrm{Cr_2O_7^{2-}} + 3\mathrm{SO_3^{2-}} + 8\mathrm{H^+} \longrightarrow 2\mathrm{Cr^{3+}} + 3\mathrm{SO_4^{2-}} + 4\mathrm{H_2O}$$

(3) 绿色 + 过量 NaOH → 沉淀溶解：Cr³⁺ 生成 Cr(OH)₃ 两性沉淀，过量碱溶解。
$$\mathrm{Cr^{3+}} + 3\mathrm{OH^-} \longrightarrow \mathrm{Cr(OH)_3}\downarrow\ (\text{灰绿色})$$
$$\mathrm{Cr(OH)_3} + \mathrm{OH^-} \longrightarrow [\mathrm{Cr(OH)_4}]^-\ (\text{绿色})$$

### 例题 2：Cr₂O₇²⁻ 氧化乙醇定量计算

**题目**：取 10.00 mL 酸性 K₂Cr₂O₇ 溶液（浓度 0.1000 mol/L），加入过量乙醇，充分反应后，剩余的 Cr₂O₇²⁻ 用 0.1000 mol/L FeSO₄ 标准溶液返滴定，消耗 15.00 mL。计算与乙醇反应的 Cr₂O₇²⁻ 的物质的量。（反应：Cr₂O₇²⁻ + 3C₂H₅OH + 8H⁺ → 2Cr³⁺ + 3CH₃COOH + 7H₂O）

**解答**：

总 Cr₂O₇²⁻：$n_{\text{总}} = 0.1000 \times 10.00 \times 10^{-3} = 1.000 \times 10^{-3}\ \mathrm{mol}$

剩余 Cr₂O₇²⁻ 被 Fe²⁺ 还原（1:6 计量比）：
$$\mathrm{Cr_2O_7^{2-}} + 6\mathrm{Fe^{2+}} + 14\mathrm{H^+} \longrightarrow 2\mathrm{Cr^{3+}} + 6\mathrm{Fe^{3+}} + 7\mathrm{H_2O}$$
$$n(\mathrm{Fe^{2+}}) = 0.1000 \times 15.00 \times 10^{-3} = 1.500 \times 10^{-3}\ \mathrm{mol}$$
$$n_{\text{剩余}}(\mathrm{Cr_2O_7^{2-}}) = \frac{1.500 \times 10^{-3}}{6} = 2.500 \times 10^{-4}\ \mathrm{mol}$$

与乙醇反应的 Cr₂O₇²⁻：
$$n_{\text{反应}} = 1.000 \times 10^{-3} - 2.500 \times 10^{-4} = 7.500 \times 10^{-4}\ \mathrm{mol}$$

## 易错点

1. **CrO₄²⁻/Cr₂O₇²⁻ 平衡的 pH 方向写反**：加酸变橙（Cr₂O₇²⁻），加碱变黄（CrO₄²⁻）。口诀："酸橙碱黄"。
2. **Cr(III) 被氧化必须碱性条件**：碱性条件下 Cr(III) 才能被 H₂O₂ 等氧化为 CrO₄²⁻。酸性条件下 Cr₂O₇²⁻ 反而是氧化剂，会氧化 H₂O₂。
3. **Cr₂O₇²⁻ 与还原剂的计量比**：1 mol Cr₂O₇²⁻ 得 6 mol e⁻（Cr 从 +6 到 +3，两个 Cr），与 Fe²⁺ 的计量比为 1:6，不是 1:3。
4. **CrO₅（过氧化铬）的蓝色不代表 Cr(III)**：Cr(VI) 与 H₂O₂ 在酸性条件下生成蓝色 CrO₅（乙醚萃取上层显蓝色），这是 Cr(VI) 的鉴定反应，放置后分解为 Cr³⁺ + O₂。
