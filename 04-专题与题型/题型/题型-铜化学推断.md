# 题型 · 铜化学推断

> **核心支撑页**：[[专题-过渡金属（二）铁钴镍铜锌]]、[[专题-过渡金属元素化学]]

## 解题思路

铜化学推断的核心在于 **Cu⁺/Cu²⁺ 的稳定性差异与配位化学**。面对这类题型，首先从颜色信号入手：蓝色溶液 → Cu²⁺；无色溶液 → 可能含 Cu⁺（d¹⁰ 无 d-d 跃迁）或不含铜。然后根据试剂反应判断：Cu²⁺ 加过量氨水 → 深蓝色 [Cu(NH₃)₄]²⁺ 是 Cu²⁺ 的经典鉴定反应；Cu²⁺ 加 I⁻ → 白色 CuI 沉淀 + I₂（棕黄色），说明 Cu²⁺ 氧化了 I⁻（Cu²⁺ + 2I⁻ → CuI↓ + ½I₂），这是 Cu²⁺ 的特征氧化还原反应。

Cu⁺ 在水溶液中不稳定，会发生歧化反应（2Cu⁺ → Cu²⁺ + Cu，K ≈ 10⁶），因此水溶液中几乎不存在 Cu⁺。但 Cu⁺ 在固态（Cu₂O 红色、CuCl 白色）和配合态（如 [Cu(CN)₂]⁻）中稳定。Cu²⁺ 配合物存在显著的 Jahn-Teller 效应，导致八面体构型发生四短二长的变形，这是 Cu²⁺ 配合物的结构特征。

## 核心方法

1. **氨水分步法**：Cu²⁺ 加少量 NH₃ → 蓝色 Cu(OH)₂ 沉淀；加过量 NH₃ → 沉淀溶解变为深蓝色 [Cu(NH₃)₄]²⁺。"先沉淀后溶解"是 Cu²⁺ 的标志行为。
2. **碘化钾氧化还原法**：Cu²⁺ + 2I⁻ → CuI↓（白色）+ ½I₂。CuI 极难溶（Ksp = 1.3×10⁻¹²），此反应可用于定量测定 Cu²⁺（碘量法）。
3. **歧化反应判断法**：Cu⁺ 在水溶液中自发歧化（2Cu⁺ → Cu²⁺ + Cu），但在固态或形成难溶/稳定配合物时可稳定存在。判断 Cu⁺ 能否存在的关键是看产物的稳定性。
4. **Jahn-Teller 效应识别法**：Cu²⁺（d⁹）配合物几乎总是变形八面体或平面正方形，四个短键两个长键。此效应在磁性和光谱性质中有体现。
5. **NaOH 区分法**：Cu²⁺ 加 NaOH → 蓝色 Cu(OH)₂ 沉淀（加热脱水变黑色 CuO）；Zn²⁺ 加 NaOH → 白色 Zn(OH)₂ 沉淀（过量溶解）。可通过沉淀颜色和两性区分 Cu²⁺ 和 Zn²⁺。

## 典型例题

### 例题 1：Cu²⁺ 配合物颜色推断

**题目**：溶液 A 为蓝色。向 A 中加入少量 NaOH 溶液，出现蓝色沉淀；继续加入过量 NaOH，沉淀不溶解。另取 A 溶液，加入过量氨水，先出现蓝色沉淀，继续加氨水沉淀溶解，得到深蓝色溶液。向深蓝色溶液中加入 Na₂S 溶液，出现黑色沉淀。推断 A 中的金属离子，并写出相关反应方程式。

**解答**：

(1) 蓝色溶液 → 优先考虑 Cu²⁺。
(2) 加 NaOH → 蓝色沉淀，不溶于过量 NaOH → Cu(OH)₂（非两性，区别于 Zn(OH)₂）。
$$\mathrm{Cu^{2+}} + 2\mathrm{OH^-} \longrightarrow \mathrm{Cu(OH)_2}\downarrow\ (\text{蓝色})$$
(3) 加过量氨水 → 先沉淀后溶解 → 深蓝色 [Cu(NH₃)₄]²⁺。
$$\mathrm{Cu(OH)_2} + 4\mathrm{NH_3} \longrightarrow [\mathrm{Cu(NH_3)_4}]^{2+} + 2\mathrm{OH^-}\ (\text{深蓝色})$$
(4) 深蓝溶液 + Na₂S → 黑色 CuS 沉淀（Ksp 极小，不溶于稀酸）。
$$[\mathrm{Cu(NH_3)_4}]^{2+} + \mathrm{S^{2-}} \longrightarrow \mathrm{CuS}\downarrow\ (\text{黑色}) + 4\mathrm{NH_3}$$

**结论**：A 中金属离子为 Cu²⁺。

### 例题 2：Cu²⁺ 与 I⁻ 的氧化还原反应

**题目**：向 25.00 mL 0.1000 mol/L CuSO₄ 溶液中加入过量 KI 固体，充分反应后，释放出的 I₂ 用 0.1000 mol/L Na₂S₂O₃ 标准溶液滴定，消耗 24.00 mL。(1) 写出 Cu²⁺ 与 I⁻ 反应的离子方程式；(2) 计算反应的 Cu²⁺ 占总 Cu²⁺ 的百分比。

**解答**：

(1) Cu²⁺ 氧化 I⁻ 为 I₂，自身还原为 CuI 沉淀：
$$2\mathrm{Cu^{2+}} + 4\mathrm{I^-} \longrightarrow 2\mathrm{CuI}\downarrow + \mathrm{I_2}$$
(2) 滴定反应：$\mathrm{I_2} + 2\mathrm{S_2O_3^{2-}} \longrightarrow 2\mathrm{I^-} + \mathrm{S_4O_6^{2-}}$

计量关系：$n(\mathrm{Cu^{2+}}) = 2n(\mathrm{I_2}) = 2 \times \frac{1}{2} n(\mathrm{S_2O_3^{2-}}) = n(\mathrm{S_2O_3^{2-}})$
$$n(\mathrm{S_2O_3^{2-}}) = 0.1000 \times 24.00 \times 10^{-3} = 2.400 \times 10^{-3}\ \mathrm{mol}$$
$$n_{\text{反应}}(\mathrm{Cu^{2+}}) = 2.400 \times 10^{-3}\ \mathrm{mol}$$
$$n_{\text{总}}(\mathrm{Cu^{2+}}) = 0.1000 \times 25.00 \times 10^{-3} = 2.500 \times 10^{-3}\ \mathrm{mol}$$
$$\text{反应百分比} = \frac{2.400}{2.500} \times 100\% = 96.0\%$$

## 易错点

1. **Cu⁺ 歧化条件的忽视**：Cu⁺ 在水溶液中歧化（K ≈ 10⁶），但在形成难溶盐（CuCl、CuI、CuCN）或稳定配合物时可存在。不能一概而论说"Cu⁺ 不存在"。
2. **Cu²⁺ 与 I⁻ 反应的产物写错**：产物是 CuI（白色沉淀）+ I₂，不是 CuI₂（CuI₂ 不存在，Cu²⁺ 会氧化 I⁻）。CuI₂ 不稳定，立即分解为 CuI + ½I₂。
3. **氨水中 Cu²⁺ 的沉淀-溶解顺序**：少量氨水先生成 Cu(OH)₂ 蓝色沉淀，过量氨水才溶解为 [Cu(NH₃)₄]²⁺ 深蓝色。不能跳过沉淀步骤直接写深蓝色。
4. **Jahn-Teller 效应的表述**：Cu²⁺（d⁹）的 Jahn-Teller 变形是不可避免的（e_g 轨道不对称占据），不是"可能"变形。描述时应说"Cu²⁺ 配合物总是呈现显著的 Jahn-Teller 变形"。
