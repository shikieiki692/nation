# 题型 · 沸点比较

## 解题思路

### 核心判断依据
- **沸点**由分子间作用力决定：分子间力越强，沸点越高
- 分子间力类型：色散力（London）< 取向力（Keesom）< 诱导力（Debye）< 氢键
- **氢键是最强的分子间力**，含 N/O/F 且有 H–X 键的分子可形成氢键
- 同系物沸点递变的主因是色散力随分子量增大

### 常见出题角度
1. 比较同系物沸点（分子量递变）
2. 比较同分异构体沸点（支链效应）
3. 比较不同官能团沸点（氢键影响）
4. 解释沸点异常（如 H₂O、HF）
5. 预测分子沸点相对高低

## 核心方法与知识点

### 关键知识点

**分子间力类型对比**：

| 作用力类型 | 本质 | 存在范围 | 相对强弱 | 典型实例 |
|:---|:---|:---|:---|:---|
| 色散力（London） | 瞬时偶极–诱导偶极 | **所有分子** | 最弱，随分子量增大 | Ar、I₂、烷烃系列 |
| 取向力（Keesom） | 永久偶极–永久偶极 | 极性分子之间 | 中等 | HCl、H₂O（部分） |
| 诱导力（Debye） | 永久偶极–诱导偶极 | 极性–非极性、极性–极性 | 较弱 | HCl–Ar |
| 氢键 | X–H···Y 静电吸引 | 含 N/O/F 的分子 | **最强**（5–40 kJ/mol） | H₂O、HF、NH₃ |

**沸点比较的一般规律**：
1. **分子间氢键** → 沸点显著升高（如 H₂O > H₂S）
2. **分子内氢键** → 沸点降低（如邻硝基苯酚 < 对硝基苯酚）
3. **同系物**：分子量越大 → 色散力越强 → 沸点越高
4. **同分异构体**：支链越多 → 分子越接近球形 → 接触面积越小 → 色散力减弱 → 沸点降低

**常见物质沸点反常**：
| 物质 | 预期沸点 | 实际沸点 | 原因 |
|:---|:---|:---|:---|
| H₂O | 低于 H₂S | 100°C | 氢键（H₂S 仅 -60°C） |
| HF | 低于 HCl | 19.5°C | 氢键（HCl 仅 -85°C） |
| NH₃ | 低于 PH₃ | -33°C | 氢键（PH₃ 仅 -87°C） |

**羧酸的特殊沸点**：
- 羧酸可形成**双分子氢键二聚体**，沸点异常高
- 例：丙酸沸点 141°C（远高于丙醇 97°C）

### 解题步骤框架

**步骤 1**：判断分子间作用力类型
- 是否有氢键（N/O/F 与 H 相连）？
- 是否为极性分子？
- 分子量大小？

**步骤 2**：比较分子间力强弱
- 氢键 > 取向力 > 诱导力 > 色散力
- 同类型力比较强度（如氢键数目、分子量）

**步骤 3**：预测沸点高低
- 分子间力越强，沸点越高

**步骤 4**：解释反常现象
- 检查氢键（分子间/分子内）
- 检查分子量、分子形状

## 典型例题

### 例题 1：同系物沸点比较

**题目**：比较下列物质的沸点高低：
(1) CH₄、C₂H₆、C₃H₈、C₄H₁₀
(2) HF、HCl、HBr、HI

**解答**：

**(1) 烷烃同系物**
- 均为非极性分子，只有色散力
- 分子量：CH₄(16) < C₂H₆(30) < C₃H₈(44) < C₄H₁₀(58)
- 色散力随分子量增大而增强
- **沸点：CH₄ < C₂H₆ < C₃H₈ < C₄H₁₀**
- 实验值：CH₄(-161°C) < C₂H₆(-89°C) < C₃H₈(-42°C) < C₄H₁₀(-0.5°C)

**(2) 卤化氢**
- 均为极性分子，有取向力和色散力
- HF 有**氢键**，沸点反常高
- **沸点：HCl < HBr < HI < HF**
- 实验值：HCl(-85°C) < HBr(-67°C) < HI(-35°C) < HF(19.5°C)
- HF 沸点远高于其他卤化氢，因为氢键作用

---

### 例题 2：同分异构体沸点比较

**题目**：比较下列同分异构体的沸点高低：
(1) 正戊烷、异戊烷、新戊烷
(2) 正丁醇、仲丁醇、异丁醇、叔丁醇

**解答**：

**(1) 戊烷异构体**
- 均为非极性分子，只有色散力
- 支链越多，分子越接近球形，接触面积越小
- **沸点：正戊烷 > 异戊烷 > 新戊烷**
- 实验值：正戊烷(36.1°C) > 异戊烷(27.7°C) > 新戊烷(9.5°C)
- 原因：支链增加 → 分子表面积减小 → 色散力减弱

**(2) 丁醇异构体**
- 均有氢键（O–H 键）
- 支链效应：支链越多，分子越接近球形，氢键数目可能减少
- **沸点：正丁醇 > 仲丁醇 > 异丁醇 > 叔丁醇**
- 实验值：正丁醇(117°C) > 仲丁醇(99°C) > 异丁醇(108°C) > 叔丁醇(82°C)
- 注意：叔丁醇沸点最低，因为支链最多，氢键数目减少

---

### 例题 3：不同官能团沸点比较

**题目**：比较下列化合物的沸点高低：
(1) 丙烷、丙醇、丙酸、丙醛
(2) 乙醇、乙二醇、丙三醇

**解答**：

**(1) 丙烷、丙醇、丙酸、丙醛**
- 分子量相近（C₃ 系列）
- 作用力类型：
  - 丙烷：非极性，只有色散力
  - 丙醛：极性（C=O），有取向力，无氢键
  - 丙醇：有氢键（O–H 键）
  - 丙酸：有氢键，且可形成双分子二聚体
- **沸点：丙酸 > 丙醇 > 丙醛 > 丙烷**
- 实验值：丙酸(141°C) > 丙醇(97°C) > 丙醛(49°C) > 丙烷(-42°C)

**(2) 乙醇、乙二醇、丙三醇**
- 均有氢键，且羟基数目不同
- 羟基越多 → 氢键数目越多 → 沸点越高
- **沸点：丙三醇 > 乙二醇 > 乙醇**
- 实验值：丙三醇(290°C) > 乙二醇(197°C) > 乙醇(78°C)
- 原因：羟基数目增加 → 分子间氢键数目增多 → 分子间力增强

## 易错点与注意事项

### 高频错误

1. **忽略氢键对沸点的影响**
   - 错误：HF 沸点低于 HCl
   - 正确：HF 沸点（19.5°C）远高于 HCl（-85°C），因氢键

2. **混淆分子间氢键和分子内氢键**
   - 错误：所有含氢键的物质沸点都高
   - 正确：分子间氢键 → 沸点升高；分子内氢键 → 沸点降低

3. **同分异构体沸点判断错误**
   - 错误：支链越多沸点越高
   - 正确：支链越多 → 分子越接近球形 → 接触面积越小 → 沸点**降低**

4. **色散力比较忽略分子量**
   - 错误：分子量小的色散力强
   - 正确：色散力随分子量增大而增强

5. **羧酸沸点判断错误**
   - 错误：羧酸沸点低于醇
   - 正确：羧酸可形成双分子二聚体，沸点**高于**醇

### 检查清单
- [ ] 判断是否有氢键（N/O/F 与 H 相连）
- [ ] 比较分子量大小（色散力）
- [ ] 考虑支链效应（接触面积）
- [ ] 区分分子间氢键和分子内氢键
- [ ] 比较氢键数目（多羟基化合物）
