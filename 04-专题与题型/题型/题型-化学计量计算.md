# 题型 · 化学计量计算

## 解题思路

化学计量计算的核心在于建立反应物与产物之间的摩尔关系。解题时首先需要写出配平的化学方程式，然后根据题意确定已知量和未知量。对于多步反应，关键是找到各步反应之间的"桥梁物质"（中间产物），通过摩尔比串联各步计算。

遇到限量试剂问题时，需要先分别计算各反应物按化学计量比完全反应所需另一种反应物的量，与实际量比较后确定限量试剂。计算产物量时必须以限量试剂为准。产率（收率）则通过实际产量与理论产量的比值来衡量反应效率，理论产量由限量试剂完全转化计算得到。

在处理多步反应串联计算时，建议采用"关系式法"：将各步反应方程式叠加，消去中间产物，直接得到始态反应物与终态产物的摩尔比关系，从而避免逐步计算带来的累积误差。

## 核心方法

1. **关系式法**：将多步反应方程式叠加，消去中间产物，建立始态反应物与终态产物的直接摩尔比关系
2. **限量试剂判断法**：分别计算各反应物完全反应所需另一反应物的量，比较后确定限量试剂，所有产量计算以限量试剂为基准
3. **产率计算法**：$\text{产率} = \dfrac{\text{实际产量}}{\text{理论产量}} \times 100\%$，理论产量由限量试剂的完全转化计算

## 典型例题

### 例题1：多步反应限量试剂计算+产率

**题目**：工业上以硫铁矿（主要成分 $\mathrm{FeS_2}$）为原料制备硫酸。某批次投入 $2.40\;\mathrm{mol}$ $\mathrm{FeS_2}$ 和 $3.80\;\mathrm{mol}$ $\mathrm{O_2}$，经过以下三步反应：

$$4\mathrm{FeS_2} + 11\mathrm{O_2} \xrightarrow{\text{高温}} 2\mathrm{Fe_2O_3} + 8\mathrm{SO_2}$$

$$2\mathrm{SO_2} + \mathrm{O_2} \xrightarrow{\text{催化剂}} 2\mathrm{SO_3}$$

$$\mathrm{SO_3} + \mathrm{H_2O} \rightarrow \mathrm{H_2SO_4}$$

若每步反应的转化率均为 $80\%$，最终实际得到 $\mathrm{H_2SO_4}$ $1.23 \times 10^2\;\mathrm{g}$。求：（1）第一步反应的限量试剂；（2）$\mathrm{SO_2}$ 的总理论产量；（3）全程总产率。

**解答**：

**（1）判断第一步反应的限量试剂**

按化学计量比，$4\;\mathrm{mol}$ $\mathrm{FeS_2}$ 需要 $11\;\mathrm{mol}$ $\mathrm{O_2}$。

现有 $2.40\;\mathrm{mol}$ $\mathrm{FeS_2}$ 完全反应需要 $\mathrm{O_2}$：$2.40 \times \dfrac{11}{4} = 6.60\;\mathrm{mol}$

实际仅有 $\mathrm{O_2}$ $3.80\;\mathrm{mol}$，故 $\mathrm{O_2}$ 为**限量试剂**。

**（2）求 $\mathrm{SO_2}$ 的理论产量**

由关系式 $4\mathrm{FeS_2} \sim 8\mathrm{SO_2}$，即 $1\;\mathrm{FeS_2} \sim 2\;\mathrm{SO_2}$

但第一步中 $\mathrm{O_2}$ 限量，按 $\mathrm{O_2}$ 计算：$11\;\mathrm{O_2} \sim 8\;\mathrm{SO_2}$

$$n(\mathrm{SO_2})_{\text{第一步}} = 3.80 \times \frac{8}{11} = 2.764\;\mathrm{mol}$$

考虑转化率 $80\%$：

$$n(\mathrm{SO_2})_{\text{实际}} = 2.764 \times 0.80 = 2.211\;\mathrm{mol}$$

若不考虑后续转化率损失，$\mathrm{SO_2}$ 理论产量为 $2.764\;\mathrm{mol}$，即 $2.764 \times 64 = 176.9\;\mathrm{g}$。

**（3）求全程总产率**

利用关系式法，将三步反应叠加：

$$2\mathrm{FeS_2} \sim 4\mathrm{SO_2} \sim 4\mathrm{SO_3} \sim 4\mathrm{H_2SO_4}$$

即 $1\;\mathrm{FeS_2} \sim 2\;\mathrm{H_2SO_4}$（但受 $\mathrm{O_2}$ 限制）

按限量试剂 $\mathrm{O_2}$：$11\;\mathrm{O_2} \sim 8\;\mathrm{H_2SO_4}$

$$n(\mathrm{H_2SO_4})_{\text{理论}} = 3.80 \times \frac{8}{11} = 2.764\;\mathrm{mol}$$

考虑三步各 $80\%$ 转化率：

$$n(\mathrm{H_2SO_4})_{\text{三步后}} = 2.764 \times (0.80)^3 = 1.415\;\mathrm{mol}$$

$$m(\mathrm{H_2SO_4})_{\text{理论}} = 1.415 \times 98 = 138.7\;\mathrm{g}$$

总产率：

$$\text{总产率} = \frac{123}{138.7} \times 100\% = 88.7\%$$

## 易错点

1. **限量试剂判断错误**：不能仅凭物质的量大小判断，必须按化学计量比换算后比较。物质的量多的反应物不一定过量
2. **多步反应累计产率**：多步反应每步转化率不足 $100\%$ 时，总产率是各步转化率的乘积，不是简单相加
3. **关系式叠加遗漏**：将多步反应叠加消去中间产物时，要注意系数配平，容易在配平时出错导致摩尔比错误
4. **实际产量与理论产量混淆**：产率公式中分子是实际产量（实验测得），分母是理论产量（由限量试剂计算），不可颠倒
