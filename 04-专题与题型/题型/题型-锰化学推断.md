# 题型 · 锰化学推断

> **核心支撑页**：[[专题-过渡金属（一）钛钒锰]]、[[专题-过渡金属元素化学]]

## 解题思路

锰化学推断的核心在于 **MnO₄⁻ 的还原产物严格依赖介质条件**——这是竞赛最高频考点。面对含锰推断题，第一步是识别紫色信号（MnO₄⁻），第二步是判断介质酸碱性（题目中"酸性""中性/弱碱性""强碱性"等关键词），第三步才确定还原产物：酸性 → Mn²⁺（近无色，5e⁻ 转移）；中性/弱碱性 → MnO₂↓（棕黑色，3e⁻ 转移）；强碱性 → MnO₄²⁻（绿色，1e⁻ 转移）。

锰的多价态颜色序列也是推断的关键信息："紫七绿六黑四粉二"（MnO₄⁻ 紫色、MnO₄²⁻ 绿色、MnO₂ 棕黑、Mn²⁺ 淡粉色/近无色）。Mn²⁺ 是锰最稳定的氧化态（d⁵ 半满），稀溶液近无色，不要与无色溶液混淆。MnO₄²⁻（绿色锰酸根）仅在强碱性条件下稳定，酸性/中性条件下自发歧化为 MnO₄⁻ + MnO₂。MnO₂ 与浓 HCl 加热可生成 Cl₂，这是实验室制 Cl₂ 的经典方法。

## 核心方法

1. **介质-产物三步法**：先判介质（酸/中/碱）→ 再判还原产物（Mn²⁺/MnO₂/MnO₄²⁻）→ 最后配平方程式（注意电子转移数：5e⁻/3e⁻/1e⁻）。
2. **颜色序列识别法**：紫色 → 绿色 → 棕黑色 → 近无色，对应 MnO₄⁻ → MnO₄²⁻ → MnO₂ → Mn²⁺ 的逐步还原过程。
3. **MnO₂ 催化与氧化法**：MnO₂ 是 H₂O₂ 分解的催化剂（棕黑色固体表面催化）；MnO₂ + 浓 HCl 加热 → Cl₂（实验室制 Cl₂）。
4. **Mn²⁺ 半满稳定法**：Mn²⁺（d⁵）是锰最稳定的氧化态，不易被氧化也不易被还原。KMnO₄ 在酸性条件下还原的最终产物就是 Mn²⁺。
5. **歧化判断法**：MnO₄²⁻ 在酸性/中性条件下自发歧化：3MnO₄²⁻ + 4H⁺ → 2MnO₄⁻ + MnO₂↓ + 2H₂O。判断依据：φ(MnO₄²⁻/MnO₂) = 2.26 V > φ(MnO₄⁻/MnO₄²⁻) = 0.56 V。

## 典型例题

### 例题 1：KMnO₄ 在不同介质中的还原产物

**题目**：将 KMnO₄ 溶液分别加入三种溶液中：(1) 稀 H₂SO₄ 酸化；(2) NaHCO₃ 溶液（弱碱性）；(3) 浓 NaOH 溶液。描述各体系的颜色变化，写出还原半反应方程式，并指出电子转移数。

**解答**：

(1) **酸性条件**：紫色褪去，溶液近无色（Mn²⁺ 极淡粉）。
$$\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5e^- \longrightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$$
电子转移数：**5e⁻**（Mn 从 +7 到 +2）

(2) **弱碱性条件**：紫色褪去，出现棕黑色沉淀（MnO₂）。
$$\mathrm{MnO_4^-} + 2\mathrm{H_2O} + 3e^- \longrightarrow \mathrm{MnO_2}\downarrow + 4\mathrm{OH^-}$$
电子转移数：**3e⁻**（Mn 从 +7 到 +4）

(3) **强碱性条件**：紫色变为绿色（MnO₄²⁻）。
$$\mathrm{MnO_4^-} + e^- \longrightarrow \mathrm{MnO_4^{2-}}$$
电子转移数：**1e⁻**（Mn 从 +7 到 +6）

### 例题 2：MnO₂ 与浓 HCl 反应的定量计算

**题目**：将 8.70 g MnO₂ 与足量浓盐酸加热反应。(1) 写出化学方程式；(2) 计算生成 Cl₂ 的体积（标准状况）；(3) 若实际收集到 2.00 L Cl₂（标准状况），计算产率。

**解答**：

(1) $\mathrm{MnO_2} + 4\mathrm{HCl(浓)} \xrightarrow{\Delta} \mathrm{MnCl_2} + \mathrm{Cl_2}\uparrow + 2\mathrm{H_2O}$

(2) $n(\mathrm{MnO_2}) = \frac{8.70}{86.94} = 0.100\ \mathrm{mol}$
$$V_{\text{理论}}(\mathrm{Cl_2}) = 0.100 \times 22.4 = 2.24\ \mathrm{L}$$

(3) 产率 $= \frac{2.00}{2.24} \times 100\% = 89.3\%$

## 易错点

1. **MnO₄⁻ 还原产物不看还原剂种类看介质**：无论还原剂是 Fe²⁺、C₂O₄²⁻ 还是 SO₃²⁻，MnO₄⁻ 的还原产物由介质决定，不由还原剂决定。
2. **Mn²⁺ 淡粉色被当作无色**：Mn²⁺ 水合离子 [Mn(H₂O)₆]²⁺ 为淡粉色（d⁵ 自旋禁阻跃迁，颜色极浅），稀溶液近无色。推断题中"近无色"不等于"无色"。
3. **MnO₄²⁻ 的稳定条件遗忘**：MnO₄²⁻（绿色）仅在强碱性条件下稳定，酸性/中性下自发歧化。不能在酸性条件下写出 MnO₄²⁻ 作为产物。
4. **MnO₂ 与浓 HCl 反应需要加热**：此反应在常温下速率极慢，必须加热才能产生明显量的 Cl₂。稀 HCl 不与 MnO₂ 反应。
