# 题型 · 氧化还原方程式配平

> **核心支撑页**：[[专题-氧化还原与电化学]]

## 解题思路

氧化还原方程式配平的核心在于 **半反应法（离子-电子法）**——将总反应拆分为氧化半反应和还原半反应，分别配平原子和电荷后合并。面对这类题型，第一步是判断介质条件（酸性/碱性/中性），这直接决定配平中用 H⁺/OH⁻ 还是 H₂O；第二步是分别写出氧化半反应和还原半反应，确定电子转移数；第三步是使两个半反应的电子数相等后相加，消去电子。

酸性介质配平步骤：O 原子用 H₂O 配平 → H 原子用 H⁺ 配平 → 电荷用 e⁻ 配平。碱性介质配平步骤：先按酸性配平 → 再在两边加等量 OH⁻ 消去 H⁺（生成 H₂O）。介质判断的关键是看题目中是否给出 "H⁺""OH⁻""酸性""碱性" 等关键词；若未明确说明，根据反应物和产物的化学式推断（如 MnO₄⁻ → Mn²⁺ 需要 H⁺，说明是酸性）。

## 核心方法

1. **半反应法配平**：拆分为氧化/还原两个半反应 → 配平原子（O 用 H₂O，H 用 H⁺/OH⁻）→ 配电荷（加 e⁻）→ 电子数相等后相加。
2. **酸碱介质转换法**：先按酸性配平（用 H⁺ 和 H₂O）→ 碱性介质时两边加等量 OH⁻ 中和 H⁺ 生成 H₂O → 化简 H₂O。
3. **氧化数法（化合价升降法）**：标出变价元素的氧化态 → 计算升降总数 → 使升降总数相等 → 配平其他原子。适用于简单反应。
4. **歧化反应配平法**：歧化反应中同一元素既被氧化又被还原。拆分为两个半反应（一个氧化、一个还原），分别配平后合并。
5. **离子-电荷守恒检验法**：配平后检查两边电荷是否相等、原子数是否相等。这是配平正确性的最终检验。

## 典型例题

### 例题 1：酸性介质配平

**题目**：用半反应法配平以下酸性介质中的氧化还原反应：$\mathrm{MnO_4^-} + \mathrm{Fe^{2+}} \rightarrow \mathrm{Mn^{2+}} + \mathrm{Fe^{3+}}$

**解答**：

**还原半反应**（MnO₄⁻ → Mn²⁺）：
- O 配平：$\mathrm{MnO_4^-} \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$
- H 配平：$\mathrm{MnO_4^-} + 8\mathrm{H^+} \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$
- 电荷配平：$\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5e^- \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$（左：+7→右：+2，差 5）

**氧化半反应**（Fe²⁺ → Fe³⁺）：
- $\mathrm{Fe^{2+}} \rightarrow \mathrm{Fe^{3+}} + e^-$

**合并**：×5 氧化半反应后与还原半反应相加：
$$\mathrm{MnO_4^-} + 5\mathrm{Fe^{2+}} + 8\mathrm{H^+} \longrightarrow \mathrm{Mn^{2+}} + 5\mathrm{Fe^{3+}} + 4\mathrm{H_2O}$$

**验证**：Mn: 1=1 ✓；Fe: 5=5 ✓；O: 4=4 ✓；H: 8=8 ✓；电荷：(-1)+(+10)+(+8)=+17 = (+2)+(+15)=+17 ✓

### 例题 2：碱性介质配平

**题目**：配平以下碱性介质中的反应：$\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} \rightarrow \mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}}$

**解答**：

**还原半反应**（MnO₄⁻ → MnO₄²⁻）：
- $\mathrm{MnO_4^-} + e^- \rightarrow \mathrm{MnO_4^{2-}}$（电荷：-1+(-1)=-2 = -2 ✓）

**氧化半反应**（SO₃²⁻ → SO₄²⁻）：
- O 配平：$\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow \mathrm{SO_4^{2-}}$
- H 配平（酸性先配）：$\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow \mathrm{SO_4^{2-}} + 2\mathrm{H^+}$
- 电荷：$\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow \mathrm{SO_4^{2-}} + 2\mathrm{H^+} + 2e^-$
- 碱性转换：两边加 2OH⁻，消去 H⁺ → $\mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \rightarrow \mathrm{SO_4^{2-}} + \mathrm{H_2O} + 2e^-$

**合并**：×2 还原半反应 + 氧化半反应：
$$2\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \longrightarrow 2\mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}} + \mathrm{H_2O}$$

**验证**：Mn: 2=2 ✓；S: 1=1 ✓；O: 8+3+2=13 = 8+4+1=13 ✓；H: 2=2 ✓；电荷：(-2)+(-2)+(-2)=-6 = (-4)+(-2)=-6 ✓

## 易错点

1. **碱性介质中出现游离 H⁺**：碱性配平的最终方程式中不能出现 H⁺。必须用 OH⁻ 和 H₂O 替代。
2. **电子转移数计算错误**：MnO₄⁻ → Mn²⁺ 转移 5e⁻（+7→+2），MnO₄⁻ → MnO₂ 转移 3e⁻（+7→+4），MnO₄⁻ → MnO₄²⁻ 转移 1e⁻（+7→+6）。
3. **配平后未验算电荷**：很多学生只验算原子数不验算电荷。电荷不守恒说明配平有误，必须重新检查。
4. **H₂O 的系数遗漏或多余**：配平过程中 H₂O 可能在多个步骤中出现和消去，最终需确认两边 H₂O 系数正确。
