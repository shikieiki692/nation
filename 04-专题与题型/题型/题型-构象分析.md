# 题型 · 构象分析

## 解题思路

构象分析是化学竞赛中有机立体化学的核心题型之一，涉及环己烷椅式/船式构象、Newman 投影构象能差、环翻转以及构象对反应选择性的控制。

**通用解题流程：**

1. **识别体系类型**：判断底物是环己烷、环戊烷、开链分子还是杂环分子。
2. **画出所有可能构象**：环己烷优先画椅式，开链优先画 Newman 投影。
3. **比较构象能差**：利用 A 值、gauche 效应、偶极排斥、1,3-二轴排斥等因素判断优势构象。
4. **判断反应性**：若题目涉及反应选择性，需考虑 Curtin-Hammett 原理——产物比由过渡态能差决定，不由构象浓度比决定。

**一屏判断卡：**

```
构象分析题 → 先画椅式/Newman
    │
    ├─ 比构象能差
    │   ├─ A 值大 → equatorial 占优（t-Bu 锁定构象）
    │   ├─ 氢键/偶极 → 可能反转构象偏好
    │   └─ 立体电子效应 → 端基效应/异头效应
    │
    ├─ 判断反应面
    │   ├─ Felkin-Anh（α-手性醛酮 + 无金属）
    │   ├─ Cram 螯合（α-烷氧基醛酮 + 金属）
    │   └─ 环状酮 → equatorial 面进攻优先
    │
    └─ 特殊情况
        ├─ Curtin-Hammett → 产物比 ≠ 构象浓度比
        └─ 反式共平面 → E2 消除的几何要求
```

## 核心方法与知识点

### 1. 环己烷 A 值速查

| 取代基 | A 值 (kJ/mol) | equatorial 占比 (298K) |
---|:---:|:---:|
| H | 0 | -- |
| Me | 7.3 | 95% |
| Et | 7.5 | 95% |
| i-Pr | 9.2 | 97% |
| t-Bu | >20 | >99.9% |
| Ph | 12.1 | 99% |
| OH | 2.5--4.2 | 70--84% |
| F | 0.6--1.0 | 56--63% |
| COOH | 5.9 | 92% |

### 2. 构象能差的来源

| 来源 | 机制 | 典型示例 |
|:---|:---|:---|
| 1,3-二轴排斥 | axial 取代基与同侧 C3/C5 上的 H 产生空间排斥 | Me 在 axial 位不稳定 |
| gauche 效应 | 相邻极性基团的偶极排斥或 n→σ\* 稳定化 | 1,2-二氟乙烷的 gauche 构象 |
| 偶极-偶极排斥 | 基团偶极矩方向影响构象稳定性 | α-氟代羰基 anti 构象占优 |
| 氢键 | 分子内氢键可稳定特定构象 | 邻硝基苯酚的 intramolecular H-bond |

### 3. Curtin-Hammett 原理

> 产物比由过渡态能差决定，不由构象浓度比决定。

$$\frac{[P_A]}{[P_B]} = e^{-\Delta\Delta G^{\ddagger}/RT}$$

即使低能构象占 99%，若高能构象的活化能更低，主要产物来自高能构象。

### 4. 立体电子效应

- **反式共平面**：E2 消除要求 H 和离去基处于 anti-periplanar 位（180°）。环己烷中只有 trans-diaxial 的 H 和 LG 才能 E2。
- **端基效应**（异头效应）：O-C-O 片段中，gauche 构象因 n→σ\* 轨道重叠比 anti 更稳定。

## 典型例题

### 例题 1：环己烷取代基构象偏好

**题目：** 1-甲基-4-叔丁基环己烷中，两个取代基分别处于什么位置时构象最稳定？画出优势构象。

**解题过程：**

1. t-Bu 的 A 值 >20 kJ/mol，几乎锁定 equatorial 位。
2. Me 的 A 值为 7.3 kJ/mol，也偏好 equatorial 位。
3. 1,4-取代有两种相对排布：
   - **trans-1,4**：两个取代基一 a 一 e（当一取代基固定 e 后，另一基团的 a/e 取决于环翻转）
   - **cis-1,4**：两个取代基可同时为 e（e,e 排布）
4. 但关键在于：t-Bu 锁定 equatorial → 环被锁定 → Me 的取向由其相对于 t-Bu 的 cis/trans 关系决定。
   - cis-1,4-二取代：当 t-Bu 在 e 位时，Me 也在 e 位（e,e）→ 最稳定
   - trans-1,4-二取代：当 t-Bu 在 e 位时，Me 在 a 位（e,a）→ 较不稳定

**结论：** cis-1,4-二取代最稳定，两个取代基均在 equatorial 位。t-Bu 作为构象锚定基团，迫使环锁定在这一构象。

**反思：** t-Bu 是竞赛中最常见的"构象锚定基"——当它出现时，其他取代基的构象偏好直接在锁定的椅式上判断即可。

### 例题 2：Felkin-Anh 模型预测加成面选择性

**题目：** (S)-2-苯基丙醛与 CH₃MgBr 反应，预测主产物的立体化学。

**解题过程：**

1. 底物是 α-手性醛（Cα 上有 Me、H、Ph 三个取代基）。
2. 无螯合金属 → 使用 Felkin-Anh 模型。
3. 画 Newman 投影：将 Cα 上最大取代基（Ph）置于与 C=O 垂直的位置。
4. 从 C=O 方向看：Ph（大基团）竖直向上，Me（中等）在左下，H（最小）在右下。
5. 亲核试剂（CH₃⁻）从位阻最小面进攻——即从 H 一侧进攻（远离 Ph 的方向）。
6. 按 Felkin-Anh 过渡态，亲核试剂沿 Bürgi-Dunitz 轨迹（~107°）从位阻最小面接近羰基碳。

**结论：** 主产物为 anti 构型（Ph 和新引入的 Me 在 Fischer 投影式的异侧）。

**反思：** Felkin-Anh 的核心是"大基团竖起来，小基团两边躺，亲核试剂打空旷那一侧"。如果 Cα 有电负性取代基（如 F、OR），偶极效应可能反转选择性——这在 2025 初赛第 8 题中有体现。

### 例题 3：反式共平面与 E2 消除

**题目：** trans-1-溴-2-甲基环己烷在强碱条件下进行 E2 消除，画出反应构象并预测产物。

**解题过程：**

1. E2 要求 H 与 Br 处于反式共平面（anti-periplanar，180°）。
2. 在环己烷椅式中，反式共平面 = trans-diaxial。
3. 画两种椅式：
   - 构象 A：Br(a), Me(e) → Br 和 C2 上的 H 均为 axial → 可以 E2
   - 构象 B：Br(e), Me(a) → Br 为 equatorial → 无法满足反式共平面
4. 因此 E2 只从构象 A 进行：Br 与 C2 上的 H 为 trans-diaxial。
5. 消除后在 C1-C2 之间形成双键。

**结论：** 主产物为 1-甲基环己烯（Hofmann 产物/取代较少的烯烃），因为只有构象 A 中 C2 上的 H 与 Br 满足 anti-periplanar。

**反思：** 环状底物的 E2 区域选择性首先由几何要求决定（能否成 anti），而不是碱的强弱。即使用强碱（如 EtO⁻），如果几何上只有一种 anti-periplanar H 可选，就只能走那条路。

## 易错点与注意事项

1. **不要把构象浓度比等同于产物比**：Curtin-Hammett 原理告诉我们，产物比由过渡态能差决定。低能构象不一定产生主要产物。
2. **不要忽视 A 值很小的取代基**：F 的 A 值仅 0.6--1.0 kJ/mol，但通过 gauche 效应（如 α-氟代羰基）可能强烈影响构象偏好。
3. **E2 反应先判断几何要求，再判断碱性**：在环状体系中，能否成 anti-periplanar 比碱的强度更先决定反应能否发生。
4. **t-Bu 锁定构象时不要做环翻转**：一旦 t-Bu 在 equatorial 位，环就被锁定，其他取代基只能在这一个固定椅式上判断。
5. **Felkin-Anh 与 Cram 螯合的第一分叉看"有没有螯合金属"**：有金属（TiCl₄、Zn²⁺等）走 Cram 螯合，无金属走 Felkin-Anh。
6. **环己烷上 trans-diaxial ≠ 反式**：trans 是相对构型（一上一下），trans-diaxial 是特定构象（两个取代基都在 axial 位且处于 1,2-或 1,3-关系）。
