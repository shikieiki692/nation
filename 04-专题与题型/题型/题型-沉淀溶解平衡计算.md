# 题型 · 沉淀溶解平衡计算

> **状态**: 已填充，待审核

## 解题思路

沉淀溶解平衡计算的核心是溶度积常数 $K_{sp}$。对于难溶电解质 $A_mB_n$，其溶解平衡为 $A_mB_n(s) \rightleftharpoons mA^{n+}(aq) + nB^{m-}(aq)$，溶度积表达式为 $K_{sp} = [A^{n+}]^m[B^{m-}]^n$。解题时首先需要写出正确的溶解平衡方程式和 $K_{sp}$ 表达式。

离子积 $Q$ 用于判断沉淀是否生成或溶解：当 $Q > K_{sp}$ 时，有沉淀生成；当 $Q = K_{sp}$ 时，体系处于平衡；当 $Q < K_{sp}$ 时，沉淀溶解。这是定性判断沉淀方向的基本依据。

溶解度与 $K_{sp}$ 的换算需要注意化学计量关系。对于 $A_mB_n$ 型沉淀，若溶解度为 $s\ \text{mol/L}$，则 $[A^{n+}] = ms$，$[B^{m-}] = ns$，代入 $K_{sp}$ 表达式得 $K_{sp} = (ms)^m(ns)^n = m^m n^n s^{m+n}$，因此 $s = \sqrt[m+n]{\frac{K_{sp}}{m^m n^n}}$。

在混合离子沉淀顺序判断中，需要计算各离子开始沉淀所需的最小浓度。对于同类型沉淀（如都是 1:1 型），$K_{sp}$ 越小越先沉淀；对于不同类型的沉淀，需计算各离子开始沉淀所需的 $[\text{沉淀剂}]$ 浓度，浓度越小越先沉淀。

## 核心方法

1. **溶度积计算法**：利用 $K_{sp}$ 表达式计算平衡时各离子浓度
2. **离子积判断法**：通过 $Q$ 与 $K_{sp}$ 的比较判断沉淀方向
3. **溶解度换算法**：利用 $K_{sp} = m^m n^n s^{m+n}$ 进行溶解度与 $K_{sp}$ 的换算
4. **分步沉淀计算法**：计算各离子开始沉淀所需的最小浓度，判断沉淀顺序
5. **沉淀转化计算**：利用 $K_{sp}$ 计算沉淀转化的平衡常数 $K = \frac{K_{sp}(\text{难溶})}{K_{sp}(\text{易溶})}$

## 典型例题

### 例题1：混合离子沉淀顺序判断

**题目**：在含有 $0.010\ \text{mol/L}\ \text{Cl}^-$ 和 $0.010\ \text{mol/L}\ \text{I}^-$ 的混合溶液中，逐滴加入 $\text{AgNO}_3$ 溶液。已知 $K_{sp}(\text{AgCl}) = 1.8 \times 10^{-10}$，$K_{sp}(\text{AgI}) = 8.5 \times 10^{-17}$。计算：
(1) 哪种沉淀先析出？
(2) 当 $\text{Cl}^-$ 开始沉淀时，溶液中 $\text{I}^-$ 的残留浓度是多少？

**解答**：
(1) 判断沉淀顺序：
- $\text{AgCl}$ 开始沉淀所需的 $[\text{Ag}^+]$：
$$[\text{Ag}^+]_{\text{AgCl}} = \frac{K_{sp}(\text{AgCl})}{[\text{Cl}^-]} = \frac{1.8 \times 10^{-10}}{0.010} = 1.8 \times 10^{-8}\ \text{mol/L}$$

- $\text{AgI}$ 开始沉淀所需的 $[\text{Ag}^+]$：
$$[\text{Ag}^+]_{\text{AgI}} = \frac{K_{sp}(\text{AgI})}{[\text{I}^-]} = \frac{8.5 \times 10^{-17}}{0.010} = 8.5 \times 10^{-15}\ \text{mol/L}$$

由于 $[\text{Ag}^+]_{\text{AgI}} < [\text{Ag}^+]_{\text{AgCl}}$，$\text{AgI}$ 先析出。

(2) 当 $\text{Cl}^-$ 开始沉淀时，溶液中 $[\text{Ag}^+] = 1.8 \times 10^{-8}\ \text{mol/L}$。此时 $\text{I}^-$ 的残留浓度：
$$[\text{I}^-] = \frac{K_{sp}(\text{AgI})}{[\text{Ag}^+]} = \frac{8.5 \times 10^{-17}}{1.8 \times 10^{-8}} = 4.7 \times 10^{-9}\ \text{mol/L}$$

### 例题2：溶解度与 $K_{sp}$ 的换算

**题目**：已知 $\text{CaF}_2$ 在 $25^\circ\text{C}$ 时的 $K_{sp} = 3.9 \times 10^{-11}$。计算：
(1) $\text{CaF}_2$ 在纯水中的溶解度（以 $\text{mol/L}$ 和 $\text{g/L}$ 表示）
(2) $\text{CaF}_2$ 在 $0.10\ \text{mol/L}\ \text{NaF}$ 溶液中的溶解度

**解答**：
(1) 设 $\text{CaF}_2$ 在纯水中的溶解度为 $s\ \text{mol/L}$，则：
$$[\text{Ca}^{2+}] = s,\quad [\text{F}^-] = 2s$$

代入 $K_{sp}$ 表达式：
$$K_{sp} = [\text{Ca}^{2+}][\text{F}^-]^2 = s \times (2s)^2 = 4s^3$$
$$s = \sqrt[3]{\frac{K_{sp}}{4}} = \sqrt[3]{\frac{3.9 \times 10^{-11}}{4}} = \sqrt[3]{9.75 \times 10^{-12}} = 2.14 \times 10^{-4}\ \text{mol/L}$$

以 $\text{g/L}$ 表示（$\text{CaF}_2$ 摩尔质量 $78.08\ \text{g/mol}$）：
$$s = 2.14 \times 10^{-4}\ \text{mol/L} \times 78.08\ \text{g/mol} = 0.0167\ \text{g/L}$$

(2) 在 $0.10\ \text{mol/L}\ \text{NaF}$ 溶液中，设溶解度为 $s'\ \text{mol/L}$，则：
$$[\text{Ca}^{2+}] = s',\quad [\text{F}^-] = 0.10 + 2s' \approx 0.10\ \text{mol/L}$$（因 $s'$ 很小，$2s' \ll 0.10$）

代入 $K_{sp}$ 表达式：
$$K_{sp} = [\text{Ca}^{2+}][\text{F}^-]^2 = s' \times (0.10)^2 = 0.010s'$$
$$s' = \frac{K_{sp}}{0.010} = \frac{3.9 \times 10^{-11}}{0.010} = 3.9 \times 10^{-9}\ \text{mol/L}$$

可见，同离子效应使 $\text{CaF}_2$ 的溶解度从 $2.14 \times 10^{-4}\ \text{mol/L}$ 降低到 $3.9 \times 10^{-9}\ \text{mol/L}$，降低了约 5 万倍。

## 易错点

1. **$K_{sp}$ 表达式书写错误**：必须根据化学式确定离子计量数。如 $\text{CaF}_2$ 的 $K_{sp} = [\text{Ca}^{2+}][\text{F}^-]^2$，而不是 $[\text{Ca}^{2+}][\text{F}^-]$。

2. **同离子效应处理不当**：在计算含有共同离子的溶液中的溶解度时，必须考虑共同离子的总浓度。如例题2(2)中，$\text{F}^-$ 的总浓度为 $0.10 + 2s'$，不能忽略 $2s'$ 的贡献（当 $s'$ 较大时）。

3. **沉淀顺序判断错误**：对于不同类型的沉淀（如 1:1 型和 1:2 型），不能直接比较 $K_{sp}$ 大小，而应计算各离子开始沉淀所需的最小浓度。

4. **溶解度单位混淆**：溶解度可用 $\text{mol/L}$ 或 $\text{g/L}$ 表示，两者换算需乘以摩尔质量。在比较溶解度时，必须统一单位。

5. **多步沉淀计算忽略离子浓度变化**：在分步沉淀计算中，当一种沉淀析出后，溶液中相关离子的浓度会发生变化，需重新计算。
