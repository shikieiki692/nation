# 题型 · 合成路线设计

## 解题思路

合成路线设计是有机化学竞赛中的综合能力题型，核心是从目标分子出发，逆向推导出合理的合成路线。需要掌握逆合成分析、C-C键构建、官能团转化和保护基策略。

**标准解题流程：**

1. **分析目标分子**：数碳原子数、识别官能团、判断立体化学
2. **逆合成切断**：优先切断C-C键，利用已知反应的逆过程
3. **简化到起始原料**：逐步简化到≤6碳的常见化合物
4. **正向验证**：从起始原料出发，验证每步反应的可行性
5. **优化路线**：考虑步骤数、产率、选择性等因素

**关键原则：**
- 逆合成分析是核心思维
- 优先切断C-C键，尤其是带有官能团的碳附近
- 利用已知反应的逆过程进行切断
- 考虑官能团兼容性和保护基策略

## 核心方法与知识点

### 1. 逆合成分析基本概念

| 概念 | 定义 | 应用 |
|:---|:---|:---|
| **逆合成（Retrosynthesis）** | 从目标分子出发，逆向推导起始原料 | 合成路线设计的基础 |
| **合成子（Synthon）** | 逆合成分析中的虚拟结构单元 | 代表反应中的电子对供体/受体 |
| **等价试剂（Equivalent）** | 合成子的实际反应试剂 | 将虚拟合成子转化为真实试剂 |

### 2. 常用断开策略

| 策略 | 适用情况 | 典型转化 |
|:---|:---|:---|
| **官能团转化（FGI）** | 目标官能团难以直接引入 | 羧酸 → 醛 → 醇 |
| **官能团添加（FGA）** | 需要引入活化基团 | 在目标位点引入羰基再还原 |
| **碳-碳键断开** | 构建碳骨架 | 羰基化合物的α,β-断开 |

### 3. 常见C-C键构建反应

#### 亲核加成类
| 反应 | 合成子 | 产物类型 |
|:---|:---|:---|
| Grignard + 醛/酮 | 碳负离子 + 亲电羰基 | 醇 |
| 羟醛缩合 | 烯醇负离子 + 亲电羰基 | β-羟基羰基/α,β-不饱和羰基 |
| Wittig反应 | 磷叶立德 + 羰基 | 烯烃 |
| 氰化物加成 | CN⁻ + 羰基 | α-羟基腈 |

#### 亲核取代类
| 反应 | 合成子 | 产物类型 |
|:---|:---|:---|
| 炔钠烷基化 | 炔负离子 + 卤代烷 | 高级炔烃 |
| 丙二酸酯合成 | 烯醇负离子 + 卤代烷 | 取代乙酸 |
| 有机铜锂试剂 | R₂CuLi + 卤代烷/酰卤 | 酮/烷烃 |

#### 偶联反应（金属有机）
| 反应 | 催化剂 | 产物类型 |
|:---|:---|:---|
| Suzuki偶联 | Pd(0) | 联芳基/烯基芳基 |
| Heck反应 | Pd(0) | 芳基烯烃 |
| Sonogashira偶联 | Pd/Cu | 芳基炔烃 |

### 4. 保护基策略

#### 羟基保护
| 保护基 | 保护条件 | 脱保护条件 |
|:---|:---|:---|
| 甲基醚 (Me) | NaH, MeI | BBr₃或HI |
| 苄基醚 (Bn) | NaH, BnBr | H₂/Pd或Na/NH₃ |
| 硅醚 (TMS, TBS) | R₃SiCl, 碱 | TBAF或HF |
| 缩醛/缩酮 | 酮/醛 + 醇/二醇 | 酸水溶液 |

#### 羰基保护
| 保护形式 | 保护条件 | 脱保护条件 |
|:---|:---|:---|
| 缩醛/缩酮 | 乙二醇, 酸催化 | 酸水溶液 |
| 硫缩醛/硫缩酮 | 乙二硫醇, BF₃ | Hg²⁺或Raney Ni |

### 5. 常见起始原料

**≤6碳的常见化合物**：
- 乙醇、乙醛、丙酮、乙酸、苯、甲苯
- 环己烷、环己烯、环己酮
- 丙二酸二乙酯、乙酰乙酸乙酯

## 典型例题

### 例题1：简单醇的合成

**题目**：设计从≤6碳起始原料合成2-苯基-2-丙醇的路线。

**解题过程：**

**Step 1：分析目标分子**
- 碳原子数：9碳（苯环6碳 + 侧链3碳）
- 官能团：羟基（叔醇）
- 结构：Ph-C(CH₃)₂-OH

**Step 2：逆合成切断**
- 切断C-C键：Ph-C(CH₃)₂-OH → PhMgBr + 丙酮
- 合成子：Ph⁻（亲核）+ (CH₃)₂C=O（亲电）

**Step 3：简化到起始原料**
- PhMgBr：溴苯 + Mg
- 丙酮：≤6碳常见化合物

**Step 4：正向验证**
1. 溴苯 + Mg → PhMgBr（无水乙醚）
2. PhMgBr + 丙酮 → Ph-C(CH₃)₂-OMgBr
3. Ph-C(CH₃)₂-OMgBr + H₃O⁺ → Ph-C(CH₃)₂-OH

**关键点**：Grignard反应是构建C-C键的重要方法。

---

### 例题2：α,β-不饱和酮的合成

**题目**：设计从≤6碳起始原料合成4-苯基-3-丁烯-2-酮的路线。

**解题过程：**

**Step 1：分析目标分子**
- 碳原子数：10碳（苯环6碳 + 侧链4碳）
- 官能团：α,β-不饱和酮
- 结构：Ph-CH=CH-CO-CH₃

**Step 2：逆合成切断**
- 切断α,β-C-C键（羟醛缩合逆过程）：Ph-CH=CH-CO-CH₃ → PhCHO + CH₃COCH₃
- 合成子：PhCHO（亲电）+ CH₃COCH₃（亲核）

**Step 3：简化到起始原料**
- 苯甲醛：苯 → 侧链氧化
- 丙酮：≤6碳常见化合物

**Step 4：正向验证**
1. 苯 + (CH₃CO)₂O/AlCl₃ → 苯乙酮（Friedel-Crafts酰基化）
2. 苯乙酮还原 → 苯甲醇
3. 苯甲醇氧化 → 苯甲醛
4. 苯甲醛 + 丙酮/NaOH → Ph-CH=CH-CO-CH₃（羟醛缩合）

**关键点**：羟醛缩合是构建α,β-不饱和羰基的重要方法。

---

### 例题3：含保护基的合成

**题目**：设计从≤6碳起始原料合成4-羟基-2-丁酮的路线，需考虑羟基保护。

**解题过程：**

**Step 1：分析目标分子**
- 碳原子数：4碳
- 官能团：羟基和酮基
- 结构：HO-CH₂-CH₂-CO-CH₃

**Step 2：逆合成切断**
- 切断C-C键：HO-CH₂-CH₂-CO-CH₃ → 环氧乙烷 + CH₃MgBr
- 但羟基与Grignard试剂不兼容，需要保护

**Step 3：保护基策略**
- 羟基保护：使用TBSCl保护羟基
- 脱保护：最后用TBAF脱保护

**Step 4：正向验证**
1. 乙二醇 → 2-溴乙醇
2. 2-溴乙醇 + TBSCl → TBSO-CH₂-CH₂-Br
3. TBSO-CH₂-CH₂-Br + Mg → TBSO-CH₂-CH₂-MgBr
4. TBSO-CH₂-CH₂-MgBr + 环氧乙烷 → TBSO-CH₂-CH₂-CH₂-CH₂-OH
5. TBSO-CH₂-CH₂-CH₂-CH₂-OH → TBSO-CH₂-CH₂-CO-CH₃（氧化）
6. TBSO-CH₂-CH₂-CO-CH₃ + TBAF → HO-CH₂-CH₂-CO-CH₃

**关键点**：保护基策略是解决官能团兼容性问题的关键。

---

### 例题4：立体选择性合成

**题目**：设计从≤6碳起始原料合成(R)-2-甲基-1-丁醇的路线。

**解题过程：**

**Step 1：分析目标分子**
- 碳原子数：5碳
- 官能团：伯醇，手性中心
- 结构：(R)-CH₃-CH₂-CH(CH₃)-CH₂-OH

**Step 2：逆合成切断**
- 切断C-C键：(R)-CH₃-CH₂-CH(CH₃)-CH₂-OH → CH₃CH₂MgBr + 丙醛
- 但需考虑手性控制

**Step 3：手性控制策略**
- 使用手性助剂（如Evans助剂）
- 或使用不对称催化（如Sharpless不对称环氧化）

**Step 4：正向验证**
1. 使用(S)-丙二醇作为手性助剂
2. 与丙酰氯反应形成手性酯
3. LDA去质子化，形成Z-烯醇负离子
4. 与CH₃I反应，甲基化
5. LiAlH₄还原，脱手性助剂
6. 得到(R)-2-甲基-1-丁醇

**关键点**：立体选择性合成需要使用手性控制策略。

## 易错点与注意事项

1. **忽视碳原子数守恒**：起始原料碳原子数之和必须等于目标分子
2. **忽略官能团兼容性**：反应条件不能破坏已有官能团
3. **错误使用保护基**：保护基的引入和脱除条件必须合理
4. **忽略步骤数优化**：合成路线应尽可能简洁
5. **错误判断逆合成切断点**：应优先切断C-C键，尤其是带有官能团的碳附近
6. **忽视起始原料限制**：起始原料应为≤6碳的常见化合物
7. **忽略立体化学考虑**：手性中心需要使用手性控制策略
