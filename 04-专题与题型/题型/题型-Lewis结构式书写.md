# 题型 · Lewis结构式书写

> **适用定位**：第一轮分子结构入门训练页。  
> **使用目标**：不是把图画“漂亮”，而是稳定拿到三个结果：**骨架连对、孤对放对、形式电荷合理**。  
> **后续衔接**：Lewis 结构画完后，立刻转去做 VSEPR，把结构翻译成 AXₙEₘ。

## 一、什么时候这题要先画 Lewis 结构

遇到下列题型，优先先画 Lewis 结构，不要直接猜构型：

1. 题目给了分子式或离子式，要你判断单键、双键、三键或共振。
2. 题目要求比较形式电荷、判断最优共振式。
3. 题目后面还要继续问 VSEPR、杂化、极性、离域π。
4. 题目出现缺电子、扩展八隅体、奇电子分子这类“反常结构”。

> **一句话**：只要题目里有“怎么连、几根键、哪里带电、有没有共振”这些信息，Lewis 结构几乎都是起点。

## 二、先记这条五步法

> **Lewis 五步法**：算 → 排 → 连 → 填 → 查

| 步骤 | 你在做什么 | 关键动作 | 常见错误 |
|:---|:---|:---|:---|
| **算** | 算总价电子数 | 各原子价电子数求和，阴离子加电荷，阳离子减电荷 | 漏掉离子电荷 |
| **排** | 选中心原子和骨架 | 电负性较小者居中；H 和卤素通常在端基 | 把 O、F、H 放中心 |
| **连** | 先用单键把骨架搭起来 | 每根单键用 2e⁻ | 一上来就乱加双键 |
| **填** | 先满足端基，再补中心 | 先给端基补满八隅体；中心不满再升多键 | 忘了第二周期必须先看 8e⁻ |
| **查** | 算形式电荷，判断是否要共振 | 看 FC 是否小、负电荷是否在电负性大的原子上 | 只画得出，不检查合理性 |

## 三、骨架选择的硬规则

1. **H 永远在端基**，因为 H 只能形成 1 个键。
2. **F、Cl、Br、I 通常在端基**，它们大多只形成 1 个共价键。
3. **中心原子优先选电负性较小者**，但不要机械把最小者都放中心，要结合常见骨架。
4. **同一类含氧酸根常有固定骨架**：NO₃⁻、CO₃²⁻、SO₄²⁻、ClO₄⁻ 都是“中心原子在中间，O 在外围”。
5. **如果总价电子数是奇数**，要先警觉这是奇电子分子，不可能让所有原子都完美成对。
6. **第三周期及以后元素可能扩展八隅体**，不要拿第二周期的规则硬套到 P、S、Cl、Xe 上。

## 四、形式电荷和共振怎么快筛

形式电荷公式：

$$
\mathrm{FC} = \text{价电子数} - \text{孤对电子数} - \frac{1}{2}\times \text{成键电子数}
$$

筛选共振式时，按下面顺序看：

| 优先级 | 判断规则 | 课堂理解 |
|:---:|:---|:---|
| ① | 第二周期中心原子尽量满足八隅体 | 先别让 C、N、O、F“缺 8e⁻” |
| ② | 形式电荷绝对值总和尽量小 | 少出现 +2、−2 这类大电荷 |
| ③ | 负电荷优先落在电负性大的原子上 | O 带负通常比 C 带负更合理 |
| ④ | 相邻原子别同时堆太多同号电荷 | 静电排斥太强，结构不优 |
| ⑤ | 若多个共振式等价，就都要保留 | NO₃⁻、CO₃²⁻、SO₃ 都是典型 |

> **提醒**：形式电荷只是“账面分配”，不等于真实电荷密度分布。

## 五、这类题最常见的四个层级

| 层级 | 典型对象 | 训练目标 |
|:---|:---|:---|
| **层 1：中性、无共振** | CO₂、NH₃、CH₄ | 会算电子、会排骨架 |
| **层 2：中心有孤对** | SO₂、ClF₃、H₂O | 会把“补孤对”和“升多键”区分开 |
| **层 3：离子 + 共振** | NO₃⁻、CO₃²⁻、SCN⁻ | 会比较形式电荷和最优共振式 |
| **层 4：八隅体例外** | BF₃、NO、SF₆、XeF₂ | 会识别缺电子、奇电子、扩展八隅体 |

## 六、典型例题

### 例 1：CO₂

**题目**：画出 CO₂ 的 Lewis 结构。

**判断链**：

1. 总价电子数：C 4 + O 6×2 = 16
2. 骨架：O-C-O
3. 两根单键先连上，用去 4e⁻
4. 先给两个 O 补八隅体后，C 还只有 4e⁻
5. 各拿 1 对 O 的孤对升成双键

**答案**：O=C=O  
**要点**：两个双键都算 1 个电子区域，后面 VSEPR 判断为直线形。

### 例 2：SO₂

**题目**：画出 SO₂ 的 Lewis 结构，并说明中心原子是否有孤对电子。

**判断链**：

1. 总价电子数：S 6 + O 6×2 = 18
2. 骨架：O-S-O
3. 两根单键后先给 O 补满，再看中心 S
4. S 周围仍需调整，最终可写成两个 S=O 共振式，S 上保留 1 对孤对

**答案**：SO₂ 有共振，S 上有 1 对孤对。  
**要点**：这类题最容易漏掉中心原子的孤对，导致后面 AXₙEₘ 写错。

### 例 3：NO₃⁻

**题目**：画出 NO₃⁻ 的 Lewis 结构，并指出为什么要保留 3 个共振式。

**判断链**：

1. 总价电子数：N 5 + O 6×3 + 1 = 24
2. 骨架：N 在中间，3 个 O 在外围
3. 三根单键后先给 3 个 O 补满
4. N 仍未满八隅体，于是把 1 个 O 的孤对升成双键
5. 双键可以放在 3 个 O 中任意一个位置，得到 3 个等价共振式

**答案**：NO₃⁻ 应写 3 个等价共振式。  
**要点**：不是“3 个结构轮流切换”，而是真实电子离域在 3 个 N-O 键上。

### 例 4：SCN⁻

**题目**：SCN⁻ 可以写成哪些 Lewis 结构？哪个更合理？

**判断链**：

1. 总价电子数：S 6 + C 4 + N 5 + 1 = 16
2. 骨架优先写成 S-C-N
3. 常见可比的两个结构：
   - S=C=N⁻
   - S⁻-C≡N
4. 两者都满足八隅体，但负电荷落在 N 上通常更合理

**答案**：两者都可作为共振式，通常 **S=C=N⁻** 贡献更大。  
**要点**：负电荷更偏向电负性更大的 N，这是形式电荷判断的常见考法。

## 七、最容易错在哪里

1. **漏算离子电荷**，导致总价电子数从第一步就错。
2. **把 H、F 放中心**，骨架一开始就偏了。
3. **一上来就猜双键**，没有先把单键骨架搭起来。
4. **只顾端基八隅体，忘了回头看中心原子是否满 8e⁻**。
5. **把终端原子的孤对当成中心原子的孤对**，后续 VSEPR 会跟着错。
6. **看到多个画法就随便选一个**，不比较形式电荷。
7. **把共振式当成不同物质**，忘了原子位置并没有变化。
8. **把第二周期和第三周期规则混用**，导致 BF₃、SF₆ 这类题全乱。

## 八、配套训练

### 8.1 基础热身

1. 写出 CO₂、HCN、NH₃ 的 Lewis 结构。
2. 写出 SO₂、O₃ 的 Lewis 结构，并指出中心原子是否有孤对电子。
3. 写出 NO₂⁻、CO₃²⁻ 的 Lewis 结构，并判断是否存在共振。
4. 写出 BF₃、NO、SF₆ 的 Lewis 结构，并说明它们分别属于哪种八隅体例外。

### 8.2 进阶迁移

5. 写出 N₂O 的 Lewis 结构，比较不同共振式的形式电荷。
6. 写出 ClO₃⁻ 的 Lewis 结构，说明中心 Cl 是否带孤对电子。
7. 写出 SCN⁻ 的主要共振式，并判断哪个贡献更大。
8. 写出 XeF₂ 的 Lewis 结构，并据此说明 Xe 周围有几对电子。

## 九、参考答案

1. CO₂：O=C=O；HCN：H-C≡N；NH₃：N 与 3 个 H 成键，N 上 1 对孤对。
2. SO₂、O₃ 都有共振；SO₂ 和 O₃ 的中心原子都带孤对电子。
3. NO₂⁻、CO₃²⁻ 都存在共振。
4. BF₃ 是缺电子；NO 是奇电子；SF₆ 是扩展八隅体。
5. N₂O 常写作 N-N-O 骨架，需要比较 N≡N⁺-O⁻ 与 N⁻=N⁺=O 等结构。
6. ClO₃⁻ 的中心 Cl 有 1 对孤对电子，后续可转成 AX₃E₁。
7. SCN⁻ 常比较 S=C=N⁻ 和 S⁻-C≡N，通常前者贡献更大。
8. XeF₂ 中 Xe 周围共有 5 对电子，后续 VSEPR 为 AX₂E₃。

## 十、用完这一页后下一步做什么

1. 如果你刚练完骨架、孤对和形式电荷，下一步直接转 [[VSEPR理论]] 或讲义中的 VSEPR 小节。
2. 如果你已经能稳定画结构，就把题目往后推进：判断 AXₙEₘ、构型、杂化和极性。
3. 如果你在离子共振题上仍卡顿，优先重复做 `NO₃⁻ / CO₃²⁻ / SCN⁻ / N₂O` 这一组经典题。
