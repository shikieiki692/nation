# 题型 · 电极电势计算

> **状态**: 已填充，待审核

## 解题思路

电极电势计算的核心是 Nernst 方程。对于电极反应 $\text{Ox} + ne^- \rightleftharpoons \text{Red}$，Nernst 方程为 $E = E^\circ - \frac{RT}{nF}\ln\frac{[\text{Red}]}{[\text{Ox}]}$，或在 $25^\circ\text{C}$ 时简化为 $E = E^\circ - \frac{0.0592}{n}\log\frac{[\text{Red}]}{[\text{Ox}]}$。该方程将电极电势与溶液中氧化态和还原态的浓度联系起来。

标准电极电势 $E^\circ$ 是在标准状态下（各离子浓度 $1\ \text{mol/L}$，气体分压 $1\ \text{atm}$，温度 $25^\circ\text{C}$）的电极电势。标准电极电势具有加和性：若反应可由几个半反应线性组合得到，则总反应的 $E^\circ$ 等于各半反应 $E^\circ$ 的代数和。

对于非标准状态下的电极电势，需用 Nernst 方程进行计算。特别要注意：(1) 纯固体和纯液体的浓度视为常数，不写入 Nernst 方程；(2) 气体用分压代替浓度；(3) 对于涉及 $\text{H}^+$ 或 $\text{OH}^-$ 的电极反应，pH 会影响电极电势。

在计算电极电势时，还需注意电极电势的符号与反应方向的关系。$E > 0$ 表示反应正向自发；$E < 0$ 表示反应逆向自发。电极电势与 $\Delta G$ 的关系为 $\Delta G = -nFE$。

## 核心方法

1. **Nernst 方程法**：利用 $E = E^\circ - \frac{0.0592}{n}\log\frac{[\text{Red}]}{[\text{Ox}]}$ 计算非标态电极电势
2. **标准电极电势组合法**：利用 $\Delta G^\circ = -nFE^\circ$ 和 $\Delta G^\circ = \sum \Delta G^\circ_{\text{产物}} - \sum \Delta G^\circ_{\text{反应物}}$ 计算组合反应的标准电极电势
3. **pH 影响分析法**：对于涉及 $\text{H}^+$ 的电极反应，分析 pH 变化对电极电势的影响
4. **浓度影响计算法**：计算离子浓度变化对电极电势的影响，特别注意稀释效应
5. **电极电势比较法**：比较不同电对的电极电势，判断氧化还原反应方向

## 典型例题

### 例题1：非标态电极电势计算

**题目**：计算在 $\text{pH} = 3.00$ 的溶液中，$\text{MnO}_4^-/\text{Mn}^{2+}$ 电对的电极电势。已知 $E^\circ(\text{MnO}_4^-/\text{Mn}^{2+}) = 1.51\ \text{V}$，假设 $[\text{MnO}_4^-] = [\text{Mn}^{2+}] = 0.10\ \text{mol/L}$。

**解答**：
电极反应：
$$\text{MnO}_4^- + 8\text{H}^+ + 5e^- \rightleftharpoons \text{Mn}^{2+} + 4\text{H}_2\text{O}$$

Nernst 方程：
$$E = E^\circ - \frac{0.0592}{5}\log\frac{[\text{Mn}^{2+}]}{[\text{MnO}_4^-][\text{H}^+]^8}$$

已知 $\text{pH} = 3.00$，则 $[\text{H}^+] = 1.0 \times 10^{-3}\ \text{mol/L}$，$[\text{MnO}_4^-] = [\text{Mn}^{2+}] = 0.10\ \text{mol/L}$。

代入数据：
$$E = 1.51 - \frac{0.0592}{5}\log\frac{0.10}{0.10 \times (1.0 \times 10^{-3})^8}$$
$$E = 1.51 - 0.01184 \times \log\frac{1}{(1.0 \times 10^{-3})^8}$$
$$E = 1.51 - 0.01184 \times \log(10^{24})$$
$$E = 1.51 - 0.01184 \times 24$$
$$E = 1.51 - 0.284 = 1.23\ \text{V}$$

可见，pH 从 0 增加到 3，电极电势从 $1.51\ \text{V}$ 降低到 $1.23\ \text{V}$，$\text{MnO}_4^-$ 的氧化性减弱。

### 例题2：电极电势组合计算

**题目**：已知以下标准电极电势：
$$\text{Fe}^{3+} + e^- \rightleftharpoons \text{Fe}^{2+} \quad E^\circ_1 = 0.77\ \text{V}$$
$$\text{Fe}^{2+} + 2e^- \rightleftharpoons \text{Fe}(s) \quad E^\circ_2 = -0.44\ \text{V}$$

计算 $\text{Fe}^{3+} + 3e^- \rightleftharpoons \text{Fe}(s)$ 的 $E^\circ_3$。

**解答**：
反应 (3) 可由反应 (1) 和 (2) 线性组合得到：
$$\text{Fe}^{3+} + 3e^- \rightarrow \text{Fe}(s) = [\text{Fe}^{3+} + e^- \rightarrow \text{Fe}^{2+}] + [\text{Fe}^{2+} + 2e^- \rightarrow \text{Fe}(s)]$$

利用 $\Delta G^\circ = -nFE^\circ$：
$$\Delta G^\circ_3 = \Delta G^\circ_1 + \Delta G^\circ_2$$
$$-3FE^\circ_3 = -1FE^\circ_1 + (-2FE^\circ_2)$$
$$3E^\circ_3 = E^\circ_1 + 2E^\circ_2$$
$$E^\circ_3 = \frac{E^\circ_1 + 2E^\circ_2}{3} = \frac{0.77 + 2 \times (-0.44)}{3} = \frac{0.77 - 0.88}{3} = \frac{-0.11}{3} = -0.037\ \text{V}$$

注意：标准电极电势不能直接相加减，必须通过 $\Delta G^\circ$ 进行组合，因为 $\Delta G^\circ$ 具有加和性，而 $E^\circ$ 不具有加和性。

## 易错点

1. **Nernst 方程中浓度项写错**：对于电极反应 $\text{Ox} + ne^- \rightleftharpoons \text{Red}$，Nernst 方程中的浓度比是 $\frac{[\text{Red}]}{[\text{Ox}]}$，而不是 $\frac{[\text{Ox}]}{[\text{Red}]}$。需根据电极反应式确定。

2. **标准电极电势直接相加减**：标准电极电势不具有加和性，不能直接相加减。必须通过 $\Delta G^\circ = -nFE^\circ$ 转换为 $\Delta G^\circ$ 进行组合，再转换回 $E^\circ$。

3. **纯固体和纯液体处理不当**：在 Nernst 方程中，纯固体和纯液体的浓度视为常数（通常为 1），不写入方程。如 $\text{Zn}^{2+} + 2e^- \rightleftharpoons \text{Zn}(s)$ 的 Nernst 方程为 $E = E^\circ - \frac{0.0592}{2}\log\frac{1}{[\text{Zn}^{2+}]}$。

4. **pH 影响方向判断错误**：对于涉及 $\text{H}^+$ 的电极反应，pH 增大（$[\text{H}^+]$ 减小）会使电极电势降低（氧化性减弱）。但需注意，对于涉及 $\text{OH}^-$ 的电极反应，pH 增大（$[\text{OH}^-]$ 增大）会使电极电势升高。

5. **电子转移数 $n$ 确定错误**：$n$ 是电极反应中转移的电子数，必须根据电极反应式确定。对于多步反应，需将各步相加得到总反应，再确定 $n$。
