# 题型 · 铁化学推断

> **核心支撑页**：[[专题-过渡金属（二）铁钴镍铜锌]]、[[专题-过渡金属元素化学]]

## 解题思路

铁化学推断题的核心在于 **Fe²⁺/Fe³⁺ 的颜色、沉淀与氧化还原互转**。面对这类题型，第一步是观察溶液颜色信号：浅绿色溶液优先考虑 Fe²⁺，黄棕色溶液优先考虑 Fe³⁺（水解后颜色）。第二步是根据题目给出的试剂（NaOH、KSCN、K₃[Fe(CN)₆]、K₄[Fe(CN)₆]、邻菲罗啉等）逐步缩小候选范围。第三步是结合氧化还原条件判断 Fe²⁺ 与 Fe³⁺ 之间的转化方向——Fe²⁺ 具有还原性（易被 KMnO₄、H₂O₂ 等氧化），Fe³⁺ 具有弱氧化性（E° = 0.771 V，可被 Fe、Cu、SnCl₂ 等还原）。

铁的配合物颜色变化也是推断的关键信号。Fe³⁺ 与 SCN⁻ 生成血红色 [Fe(SCN)]²⁺ 是 Fe³⁺ 的灵敏鉴定反应；Fe²⁺ 与邻菲罗啉（phen）生成深红色 [Fe(phen)₃]²⁺ 用于比色测定 Fe²⁺。滕氏蓝（Fe²⁺ + K₃[Fe(CN)₆]）和普鲁士蓝（Fe³⁺ + K₄[Fe(CN)₆]）本质上是同一物质，只是原料不同。此外，Fe²⁺ 溶液需酸性保存并加铁屑防氧化，Fe³⁺ 在 pH > 2 即开始水解聚合，这些实验细节常出现在推断题的隐含条件中。

## 核心方法

1. **颜色快判法**：浅绿色 → Fe²⁺；黄棕色（水解） → Fe³⁺；加 KSCN 血红色 → 确认 Fe³⁺
2. **NaOH 沉淀序列法**：Fe²⁺ 加 NaOH → 白色 Fe(OH)₂ → 迅速灰绿 → 棕红 Fe(OH)₃（被空气氧化）；Fe³⁺ 加 NaOH → 直接棕红 Fe(OH)₃ 沉淀
3. **氧化还原互转法**：Fe²⁺ → Fe³⁺（加 H₂O₂、KMnO₄、Cl₂ 等氧化剂）；Fe³⁺ → Fe²⁺（加 Fe 粉、Cu、SnCl₂ 等还原剂）
4. **特征配合物鉴定法**：Fe³⁺ + SCN⁻ → 血红色；Fe²⁺ + phen → 深红色；Fe²⁺/Fe³⁺ + K₄/K₃[Fe(CN)₆] → 蓝色沉淀
5. **磁性辅助判断法**：Fe²⁺（d⁶ 高自旋，4 未成对，顺磁）；Fe³⁺（d⁵ 高自旋，5 未成对，顺磁强）

## 典型例题

### 例题 1：Fe²⁺/Fe³⁺ 互转推断

**题目**：溶液 A 为浅绿色，加入少量 KSCN 溶液无明显变化。向 A 中加入 H₂O₂ 后，溶液变为血红色。另取 A 溶液，加入 NaOH 溶液，先出现白色沉淀，迅速变为灰绿色，最终变为棕红色。推断 A 中的金属离子，并写出所有涉及的离子方程式。

**解答**：

(1) 浅绿色溶液 + KSCN 不显色 → 排除 Fe³⁺，确认含 Fe²⁺。

(2) 加 H₂O₂ 后变血红色：H₂O₂ 将 Fe²⁺ 氧化为 Fe³⁺，Fe³⁺ 与 SCN⁻ 络合显血红色。
$$2\mathrm{Fe^{2+}} + \mathrm{H_2O_2} + 2\mathrm{H^+} \longrightarrow 2\mathrm{Fe^{3+}} + 2\mathrm{H_2O}$$
$$\mathrm{Fe^{3+}} + n\mathrm{SCN^-} \longrightarrow [\mathrm{Fe(SCN)_n}]^{3-n}\ (\text{血红色})$$

(3) 加 NaOH 的沉淀序列：白色 → 灰绿 → 棕红，是 Fe(OH)₂ 被空气中 O₂ 氧化的经典现象。
$$\mathrm{Fe^{2+}} + 2\mathrm{OH^-} \longrightarrow \mathrm{Fe(OH)_2}\downarrow\ (\text{白色})$$
$$4\mathrm{Fe(OH)_2} + \mathrm{O_2} + 2\mathrm{H_2O} \longrightarrow 4\mathrm{Fe(OH)_3}\ (\text{棕红色})$$

**结论**：A 中金属离子为 Fe²⁺。

### 例题 2：KMnO₄ 滴定 Fe²⁺ 定量计算

**题目**：用 0.02000 mol/L KMnO₄ 标准溶液滴定 25.00 mL 含 Fe²⁺ 的酸性溶液，消耗 KMnO₄ 溶液 20.00 mL。(1) 写出滴定反应的离子方程式；(2) 计算原溶液中 Fe²⁺ 的浓度。

**解答**：

(1) 酸性条件下 MnO₄⁻ 被还原为 Mn²⁺（5e⁻ 转移），Fe²⁺ 被氧化为 Fe³⁺（1e⁻ 转移）：
$$\mathrm{MnO_4^-} + 5\mathrm{Fe^{2+}} + 8\mathrm{H^+} \longrightarrow \mathrm{Mn^{2+}} + 5\mathrm{Fe^{3+}} + 4\mathrm{H_2O}$$

(2) 计量关系：$n(\mathrm{Fe^{2+}}) = 5 \times n(\mathrm{MnO_4^-})$
$$n(\mathrm{MnO_4^-}) = 0.02000 \times 20.00 \times 10^{-3} = 4.000 \times 10^{-4}\ \mathrm{mol}$$
$$n(\mathrm{Fe^{2+}}) = 5 \times 4.000 \times 10^{-4} = 2.000 \times 10^{-3}\ \mathrm{mol}$$
$$c(\mathrm{Fe^{2+}}) = \frac{2.000 \times 10^{-3}}{25.00 \times 10^{-3}} = 0.08000\ \mathrm{mol/L}$$

## 易错点

1. **混淆滕氏蓝与普鲁士蓝**：现代表征认为二者结构相同（均为 Fe₄[Fe(CN)₆]₃），只是原料不同——前者用 Fe²⁺ + K₃[Fe(CN)₆]，后者用 Fe³⁺ + K₄[Fe(CN)₆]。竞赛中不要写成两种不同物质。
2. **Fe(OH)₂ 颜色变化的条件遗漏**：白色沉淀必须在无氧条件下才能保持白色，暴露空气中迅速氧化变色。若题目强调"隔绝空气"，则沉淀可保持白色。
3. **KMnO₄ 滴定 Fe²⁺ 时忘记酸性条件**：MnO₄⁻ 在酸性条件下才还原为 Mn²⁺（5e⁻），中性/弱碱性下还原为 MnO₂（3e⁻），配平时电子转移数完全不同。
4. **Fe³⁺ 水解颜色的忽视**：Fe³⁺ 稀溶液因水解显黄棕色而非紫色（[Fe(H₂O)₆]³⁺ 本身为浅紫色），竞赛题中"黄色溶液"不一定排除 Fe³⁺。
