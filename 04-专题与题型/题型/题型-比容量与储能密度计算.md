# 题型 · 比容量与储能密度计算

## 解题思路

比容量与储能密度计算是化学竞赛电化学部分的重要题型，常出现在决赛中。比容量衡量单位质量活性物质能存储/释放的电荷量（mAh/g），储能密度衡量单位质量电池系统能存储的能量（Wh/kg）。两者都是评价电池性能的核心指标。

**通用解题流程：**

1. **确定电极反应**：写出正极/负极的半反应方程式。
2. **确定电子转移数 n**：每摩尔活性物质转移多少摩尔电子。
3. **确定活性物质的式量 M**：用**反应物**（不是产物）的式量。
4. **代入公式计算**：
   - 比容量：C = nF / (3.6M)（单位 mAh/g）
   - 储能密度：ρ = nFE / (3.6M)（单位 Wh/kg）
5. **检查单位和变量**：n 取对了吗？M 用的是哪个物质？

**一屏判断卡：**

```
比容量/储能密度题 → 先写电极反应
    │
    ├─ 确定电子数 n
    │   ├─ 看变价元素的氧化态变化
    │   ├─ 注意题目给的"可逆储钾/锂"全过程
    │   └─ n ≠ 反应式中的系数！是电子转移数
    │
    ├─ 确定式量 M
    │   └─ 必须用反应物（不是产物）的式量
    │
    ├─ 代入公式
    │   ├─ 比容量 C = nF / (3.6M)  [mAh/g]
    │   └─ 储能密度 ρ = nFE / (3.6M)  [Wh/kg]
    │
    └─ 检查
        ├─ n 是否正确
        ├─ M 是否用了反应物
        └─ 单位换算（A·s → mA·h 要除以 3.6）
```

## 核心方法与知识点

### 1. 核心公式

**比容量**（单位质量的电荷量）：

$$C = \frac{nF}{M}$$

其中：
- n = 每摩尔活性物质转移的电子数
- F = 96485 C/mol（法拉第常数）
- M = 活性物质的摩尔质量（g/mol）
- 单位换算：1 A·s = 1 C，1 mA·h = 3.6 C
- 因此 $C\ (\mathrm{mAh/g}) = \frac{n \times 96485}{3.6 \times M} = \frac{n \times 26801}{M}$

**储能密度**（单位质量的能量）：

$$\rho = \frac{nFE}{3.6 \times M}$$

其中 E 为电池电动势（V），单位为 Wh/kg。

### 3. 计算中的关键陷阱

| 陷阱 | 正确做法 | 示例 |
|:---|:---|:---|
| n 取错 | 看变价元素的氧化态变化，不是反应式系数 | LiCoO₂ 中 Co³⁺→Co⁴⁺，n=1（每个 Li 对应 1e⁻） |
| M 用错 | 用反应物（放电前）的式量，不用产物 | LiFePO₄ 用 157.76，不用 FePO₄ 的 150.82 |
| 单位换算遗漏 | F/3.6 才得到 mAh/g，不是直接用 F | 96485/3.6 = 26801 |
| 多步反应 | 总 n = 各步 n 之和 | 2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺：n = 2（按 Cu 计）或 n = 1（按每个 Fe³⁺ 计） |

### 4. 储能密度的两种算法

| 算法 | 公式 | 适用场景 |
|:---|:---|:---|
| 基于活性物质 | ρ = nFE / (3.6M) | 只考虑电极活性物质的质量 |
| 基于电池总质量 | ρ = 总电能 / 总质量 | 包括正极+负极+电解质+集流体等 |

竞赛中通常用第一种（基于活性物质），除非题目明确要求"基于电池总质量"。

### 5. 法拉第效率与能量效率

| 效率类型 | 公物 | 含义 |
|:---|:---|:---|
| 法拉第效率 | η_F = 实际电荷量 / 理论电荷量 | 反映反应选择性（副反应消耗电子） |
| 能量效率 | η_E = 放电能量 / 充电能量 | 反映能量损失（过电位、内阻等） |
| 库仑效率 | 同法拉第效率 | 可逆电池中反映循环稳定性 |

## 典型例题

### 例题 1：普鲁士蓝电极的比容量（基于 39 届初赛第 2 题风格）

**题目：** 普鲁士蓝类化合物 PBA-1 的化学式为 KFe₂(CN)₆，式量 306.92。(1) 写出生成普鲁士白的电极反应方程式；(2) 计算其作为正极材料的理论比容量（mAh/g）。

**解题过程：**

**(1) 电极反应：**
- PBA-1 中 K 为 +1，CN⁻ 为 -1 × 6 = -6，故 2Fe 总价态为 +3 → 混合价态 Fe(III)Fe(II)
- 嵌入 K⁺ 后变成普鲁士白（全白），所有 Fe 被还原为 Fe(II)
- 电极反应：KFe(III)Fe(II)(CN)₆ + K⁺ + e⁻ → K₂Fe(II)₂(CN)₆
- n = 1（每个化学式单元转移 1 个电子）

**(2) 比容量计算：**
- C = nF / (3.6M) = 1 × 96485 / (3.6 × 306.92)
- C = 96485 / 1104.91 = 87.3 mAh/g

**但题目后续提示可逆储钾过程为 2K⁺ + 2e⁻（两个 Fe 均可变价），因此 n = 2：**
- C = 2 × 96485 / (3.6 × 306.92) = 192970 / 1104.91 = **174.7 mAh/g**

**结论：** 理论比容量为 174.7 mAh/g（取 n = 2）。

**反思：**
- n 的判定要结合题目给出的"可逆储钾"全过程，不能仅看单步反应。
- M 必须用反应物（PBA-1）的式量，不能用产物。
- 颜色变化（蓝→白）反映的是 d-d 跃迁或 CT 跃迁，不是比容量计算的直接依据。

### 例题 2：Zn-I₂ 电池的储能密度

**题目：** 某 Zn-I₂ 电池，负极为 Zn，正极为 I₂/C 复合物。总反应：Zn + I₂ → ZnI₂。电池电动势 E = 1.30 V。计算基于正负极活性物质的储能密度（Wh/kg）。

**解题过程：**

1. **总反应**：Zn + I₂ → ZnI₂
2. **电子转移数**：Zn → Zn²⁺ + 2e⁻，n = 2
3. **活性物质总质量**：
   - 负极：Zn，M(Zn) = 65.38 g/mol
   - 正极：I₂，M(I₂) = 253.81 g/mol
   - 总式量 = 65.38 + 253.81 = 319.19 g/mol
4. **储能密度**：
   - ρ = nFE / (3.6 × M总)
   - ρ = 2 × 96485 × 1.30 / (3.6 × 319.19)
   - ρ = 250861 / 1149.08
   - ρ = **218.3 Wh/kg**

**结论：** 基于正负极活性物质的储能密度为 218.3 Wh/kg。

**反思：**
- 储能密度计算中，M 是正负极活性物质的**总质量**（不是单侧）。
- 如果题目要求"基于电池总质量"，还需要加上电解质、隔膜、集流体等的质量。
- 电动势 E 的大小直接影响储能密度——提高 E 是提升储能密度的关键途径之一。

### 例题 3：恒流放电后的电动势计算

**题目：** 某电池以 200 mA 恒电流放电 482 s，已知转移电子数 n_e = 1.00 mmol。放电前 [Zn²⁺] = 1.0 mol/L，放电后 [Zn²⁺] = 1.5 mol/L。计算放电后的负极电势。已知 E°(Zn²⁺/Zn) = -0.762 V。

**解题过程：**

1. **验证电量守恒**：
   - It = 0.200 A × 482 s = 96.4 C
   - n_e = 96.4/96485 = 1.00 × 10⁻³ mol = 1.00 mmol ✓

2. **负极反应**：Zn → Zn²⁺ + 2e⁻
   - 每 2 mmol 电子对应 1 mmol Zn²⁺ 生成
   - 实际生成 [Zn²⁺] = 1.0 + 1.00/(2 × V)，但题目已直接给出放电后 [Zn²⁺] = 1.5 mol/L

3. **Nernst 方程**：
   - E(Zn²⁺/Zn) = E° + (0.0592/2) × lg[Zn²⁺]
   - E = -0.762 + (0.0592/2) × lg(1.5)
   - E = -0.762 + 0.0296 × 0.176
   - E = -0.762 + 0.005 = **-0.757 V**

**结论：** 放电后负极电势为 -0.757 V（略正于标准值，因为 [Zn²⁺] 升高）。

**反思：** 恒流放电题的核心是"电量守恒"：Q = It = n_e F。算出 n_e 后，把它分配到两个电极的浓度变化中，再用 Nernst 方程计算新电势。

## 易错点与注意事项

1. **比容量必须用反应物的式量作分母**：不能用产物的式量。
2. **n 是电子转移数，不是反应式中的系数**：要从变价元素的氧化态变化来确定。
3. **单位换算**：F = 96485 C/mol，1 mA·h = 3.6 C。所以 C(mAh/g) = nF/(3.6M)。
4. **储能密度中 M 是总质量**：如果是基于活性物质，M = M(正极活性物) + M(负极活性物)。
5. **多步放电反应**：总能量 = 各阶段 n_i F E_i 之和，不能简单用一个 E 代替。
6. **题目可能给"可逆"过程**：如可逆储钾/储锂，要按全过程的 n 计算，不要只看单步。
