# 题型 · 陌生方程式书写

> **核心支撑页**：综合能力题（无直接对应专题）

## 解题思路

陌生方程式书写是竞赛中区分度最高的题型之一——题目给出一个你从未见过的反应体系，要求你根据已知信息（反应物、产物、条件）写出配平的方程式。面对这类题型，第一步是**提取已知信息**：题目给出的反应物和产物是什么？反应条件是什么（酸性/碱性/高温/催化剂）？是否有中间产物或副产物？第二步是**判断反应类型**：是氧化还原（有变价元素）、酸碱中和、络合、还是分解/化合？第三步是**用半反应法或观察法配平**。

竞赛中陌生方程式的常见来源有：(1) 过渡金属在不同条件下的特殊反应（如 MnO₂ 与浓 HCl 制 Cl₂、Cr₂O₇²⁻ 氧化有机物）；(2) 工业过程中的重要反应（如接触法制 H₂SO₄、氨氧化法制 HNO₃）；(3) 新型材料的合成反应（如固相反应、水热合成）。解题关键是"从已知推未知"——利用元素守恒、氧化还原守恒和电荷守恒逐步构建方程式。

## 核心方法

1. **元素守恒法**：先确定所有反应物和产物的化学式 → 根据元素守恒确定未知产物（如缺 H 和 O → 可能生成 H₂O）。
2. **氧化态追踪法**：标出所有变价元素的氧化态 → 计算电子得失总数 → 使电子得失守恒 → 确定计量系数。
3. **介质推断法**：根据反应物和产物的化学式推断介质——产物含 H⁺ 说明酸性介质，产物含 OH⁻ 说明碱性介质。
4. **分步构建法**：对于复杂反应，先写出已知的半反应 → 再根据条件补充其他半反应 → 合并得到总反应。
5. **文献/经验迁移法**：竞赛中陌生方程式往往与已知反应类似（如同族元素的相似反应），利用已知反应的模式迁移推断。

## 典型例题

### 例题 1：根据实验现象推断方程式

**题目**：向含有 Cr³⁺ 的绿色溶液中加入过量 NaOH，得到绿色溶液。再向该绿色溶液中缓慢加入 H₂O₂，溶液变为黄色。写出加入 H₂O₂ 后反应的离子方程式。

**解答**：

分析：
- Cr³⁺ + 过量 NaOH → [Cr(OH)₄]⁻（绿色，Cr(III) 的四羟基合铬酸根）
- [Cr(OH)₄]⁻ + H₂O₂ → 黄色溶液 → CrO₄²⁻（Cr(VI) 的铬酸根，黄色）
- 这是碱性条件下 Cr(III) 被 H₂O₂ 氧化为 Cr(VI) 的反应

配平：
- 氧化半反应：$\mathrm{[Cr(OH)_4]^-} + 4\mathrm{OH^-} \rightarrow \mathrm{CrO_4^{2-}} + 4\mathrm{H_2O} + 3e^-$
- 还原半反应：$\mathrm{H_2O_2} + 2e^- \rightarrow 2\mathrm{OH^-}$
- 合并（×2 氧化 + ×3 还原）：
$$2[\mathrm{Cr(OH)_4}]^- + 3\mathrm{H_2O_2} + 2\mathrm{OH^-} \longrightarrow 2\mathrm{CrO_4^{2-}} + 8\mathrm{H_2O}$$

**验证**：Cr: 2=2 ✓；O: 8+6+2=16 = 8+8=16 ✓；H: 8+6+2=16 = 16 ✓；电荷：(-2)+0+(-2)=-4 = (-4)+0=-4 ✓

### 例题 2：根据元素守恒推断方程式

**题目**：在酸性条件下，MnO₂ 可以将 H₂O₂ 氧化为 O₂，自身还原为 Mn²⁺。写出该反应的离子方程式。

**解答**：

分析：
- 氧化剂：MnO₂（Mn 从 +4 → +2，得 2e⁻）
- 还原剂：H₂O₂（O 从 -1 → 0，失 1e⁻/O，共 2e⁻/H₂O₂）
- 酸性介质（H⁺ 参与）

配平：
- 还原半反应：$\mathrm{MnO_2} + 4\mathrm{H^+} + 2e^- \rightarrow \mathrm{Mn^{2+}} + 2\mathrm{H_2O}$
- 氧化半反应：$\mathrm{H_2O_2} \rightarrow \mathrm{O_2} + 2\mathrm{H^+} + 2e^-$
- 合并（电子数已相等）：
$$\mathrm{MnO_2} + \mathrm{H_2O_2} + 2\mathrm{H^+} \longrightarrow \mathrm{Mn^{2+}} + \mathrm{O_2}\uparrow + 2\mathrm{H_2O}$$

**验证**：Mn: 1=1 ✓；O: 2+2=4 = 2+2=4 ✓；H: 2+2=4 = 4 ✓；电荷：0+0+(+2)=+2 = +2+0+0=+2 ✓

## 易错点

1. **陌生反应中介质的判断错误**：题目未明确说明介质时，需从产物推断——产物含 H⁺ → 酸性；含 OH⁻ → 碱性；含 H₂O 但无 H⁺/OH⁻ → 可能是中性。
2. **氧化态标注错误导致电子数不对**：对于不常见化合物（如过氧化物、超氧化物），必须正确标出氧化态才能确定电子转移数。例如 Na₂O₂ 中 O 为 -1（不是 -2）。
3. **配平后忘记加介质条件**：半反应法配平时，酸性用 H⁺ 和 H₂O，碱性用 OH⁻ 和 H₂O。最终方程式中不能出现与介质矛盾的物种。
4. **忽略副产物**：竞赛中陌生方程式的产物可能不止一个（如同时生成沉淀和气体），必须根据元素守恒确认所有产物。
