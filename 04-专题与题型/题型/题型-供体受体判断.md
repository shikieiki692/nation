# 题型 · 供体受体判断

## 解题思路

供体-受体判断是有机化学反应活性分析的核心能力，要求判断一个分子中哪个部分是电子供体（donor，富电子端），哪个部分是电子受体（acceptor，缺电子端），从而预测反应的区域选择性和立体选择性。

**通用解题流程：**

1. **识别分子中的极性位点**：通过电负性差异、共轭效应、超共轭效应判断电子云分布。
2. **判断供体端**：HOMO 能量高、电子云密度大、有孤对电子或 π 电子的区域。
3. **判断受体端**：LUMO 能量低、有缺电子中心（碳正离子、羰基碳、Lewis 酸性中心）的区域。
4. **预测反应方向**：供体的 HOMO 与受体的 LUMO 相互作用 → 亲核端进攻亲电端。
5. **结合 FMO 理论深化**：对于复杂体系，用前线轨道系数精确判断进攻位点。

**一屏判断卡：**

```
供体-受体判断 → 先看电子云分布
    │
    ├─ 谁是供体（电子源）？
    │   ├─ 孤对电子（N, O, S, P）
    │   ├─ π 电子（烯烃、芳环、共轭体系）
    │   ├─ σ 电子（C-H 超共轭给电子）
    │   └─ 金属的 d 电子
    │
    ├─ 谁是受体（电子汇）？
    │   ├─ 碳正离子 / 空轨道
    │   ├─ 羰基碳 / 碳卤键碳
    │   ├─ Lewis 酸（BF₃, AlCl₃）
    │   └─ 低 LUMO 的 π* 轨道
    │
    └─ 反应方向
        └─ 供体 HOMO → 受体 LUMO
```

### 2. 前线轨道理论（FMO）框架

| 分析对象 | 用哪个轨道 | 判断方法 |
|:---|:---|:---|
| 亲核体（供体） | **HOMO** | HOMO 越高 → 越容易给出电子 → 亲核性越强 |
| 亲电体（受体） | **LUMO** | LUMO 越低 → 越容易接受电子 → 亲电性越强 |
| 进攻位点 | HOMO/LUMO 系数 | 系数最大的位置反应活性最高 |

### 3. 典型供体-受体对

| 供体类型 | 代表 | 受体类型 | 代表 | 反应类型 |
|:---|:---|:---|:---|:---|
| 烯烃 π 电子 | CH₂=CH₂ | 碳正离子 / 卤素 | H⁺, Br₂ | 亲电加成 |
| 胺的孤对电子 | R₃N: | 羰基碳 | R₂C=O | 亲核加成 |
| 烯醇负离子 | C=C-O⁻ | α,β-不饱和羰基 | CH₂=CH-COR | Michael 加成 |
| 二烯 HOMO | 1,3-丁二烯 | 亲二烯体 LUMO | CH₂=CH-CHO | Diels-Alder |
| 碳负离子 | R⁻ | 碳正离子 / 金属 | R'X | SN2 |

### 4. Hard-Soft Acid-Base（HSAB）理论

| 类型 | 特征 | 代表 | 选择性规则 |
|:---|:---|:---|:---|
| 硬酸 | 小、高电荷、不易极化 | H⁺, Li⁺, BF₃, Al³⁺ | 优先与硬碱结合 |
| 软酸 | 大、低电荷、易极化 | Cu⁺, Ag⁺, Pd⁰, Pt⁰ | 优先与软碱结合 |
| 硬碱 | 小、电负性大、不易极化 | F⁻, OH⁻, NH₃, RO⁻ | 优先与硬酸结合 |
| 软碱 | 大、电负性小、易极化 | I⁻, RS⁻, PR₃, CO | 优先与软酸结合 |

**竞赛应用**：
- 烯醇化学中：硬亲电体（如 RX）→ 烯醇氧进攻（硬碱端）；软亲电体（如 CH₂=CH-COR）→ 烯醇碳进攻（软碱端）
- 配位化学中：IrCl(CO)(PPh₃)₂ 的氧化加成——Ir(I) 是软酸 → 优先与软碱底物反应

### 5. 从电荷分布判断供体/受体

| 分子特征 | 供体端 | 受体端 |
|:---|:---|:---|
| C=O（羰基） | O 上的孤对电子（Lewis 碱） | C（缺电子，Lewis 酸） |
| C=C（烯烃） | π 电子云整体 | 被吸电子基活化的 β 位 |
| 芳环 | π 电子云整体 | 被吸电子基活化的位点 |
| C-X（碳卤键） | X 上的孤对电子 | C（δ+） |
| N-H | N 的孤对电子 | H（可解离） |

## 典型例题

### 例题 1：Diels-Alder 反应中的供体-受体匹配

**题目：** 1-甲氧基-1,3-丁二烯与丙烯醛进行 Diels-Alder 反应，判断哪个分子是供体、哪个是受体，并预测主产物的区域选择性。

**解题过程：**

1. **判断供体**：1-甲氧基-1,3-丁二烯上连有 -OMe（+M 基团）→ 通过共轭效应向二烯体系注入电子 → HOMO 能量升高 → **二烯是供体**。
2. **判断受体**：丙烯醛上连有 -CHO（-M 基团）→ 通过共轭效应拉走 π 电子 → LUMO 能量降低 → **烯烃是受体**。
3. **区域选择性**：供体-受体 Diels-Alder 中，二烯 HOMO 系数最大的位置（C4，靠近 OMe 的远端）与亲二烯体 LUMO 系数最大的位置（β 位，即远离 CHO 的碳）优先对接。
4. 预测产物："ortho"产物为主（甲氧基和 CHO 在产物的 1,2-位）。

**结论：** 甲氧基二烯（供体）+ 丙烯醛（受体），主产物为 ortho 取向的环己烯醛。

**反思：** 供体-受体 Diels-Alder 的区域选择性可以用 FMO 系数预测，不需要死记"ortho/meta"规则——理解了 HOMO-LUMO 匹配，规则自然推导出来。

### 例题 2：α,β-不饱和羰基的 1,2- vs 1,4-加成

**题目：** 丙烯醛（CH₂=CH-CHO）分别与 (a) CH₃MgBr 和 (b) (CH₃)₂CuLi 反应，预测各自的加成方式。

**解题过程：**

1. **分析底物**：丙烯醛中，C=C 与 C=O 共轭 → 有两个亲电位点：羰基碳（1,2-位）和 β-碳（1,4-位）。
2. **(a) CH₃MgBr（硬亲核体）**：
   - Grignard 试剂是强碱/硬亲核体
   - 硬亲核体优先与硬亲电位点结合 → 羰基碳（C=O）是较硬的亲电位点
   - → **1,2-加成** → 产物为 CH₂=CH-C(OH)(CH₃)₂（烯丙醇）
3. **(b) (CH₃)₂CuLi（软亲核体）**：
   - 有机铜锂是较软的亲核体
   - 软亲核体优先与软亲电位点结合 → β-碳（C=C 的 LUMO 系数端）是较软的亲电位点
   - → **1,4-加成（共轭加成）** → 产物为 CH₃CH₂CH₂CHO（饱和醛）

**结论：** Grignard → 1,2-加成（直接加成）；有机铜锂 → 1,4-加成（共轭加成）。

**反思：** 这是 HSAB 理论在有机合成中最经典的应用——同一底物，换一个试剂的软硬度，加成位点就不同。竞赛中常考这个对比。

### 例题 3：Michael 加成中的供体-受体匹配

**题目：** 2-甲基环己酮在 LDA 作用下生成烯醇负离子，再与丙烯腈反应。判断供体和受体，写出产物。

**解题过程：**

1. **生成供体**：LDA（大位阻强碱）夺取 2-甲基环己酮的 α-H → 动力学控制的烯醇负离子。
2. **烯醇负离子的供体性质**：氧上负电荷离域到碳上 → 烯醇碳（较软的碱端）是主要供体位点。
3. **受体**：丙烯腈 CH₂=CH-CN 中，CN 是 -M 基团 → β-碳缺电子（LUMO 系数大）→ 丙烯腈是受体。
4. **反应**：烯醇碳（供体）进攻丙烯腈的 β-碳（受体）→ Michael 加成。
5. 产物：在环己酮的 α 位引入 -CH₂CH₂CN 侧链。

**结论：** 烯醇负离子（供体）+ 丙烯腈（受体），发生 Michael 加成，产物为 α-(2-氰乙基)环己酮。

**反思：** Michael 加成的本质是"软碳负离子对缺电子烯烃的共轭加成"。供体必须是稳定的烯醇负离子（软碱），受体必须是共轭的缺电子烯烃（Michael 受体）。

## 易错点与注意事项

1. **供体-受体是相对概念**：同一分子在不同反应中可能扮演不同角色。例如，丙烯醛在 DA 反应中是受体（作为亲二烯体），但在与 Grignard 反应中，其羰基碳是受体而 β-碳也是受体。
2. **不要把"带负电"等同于"供体"**：碳负离子的供体能力取决于其软硬度和 HOMO 能量，不是只看形式电荷。
3. **HSAB 不是万能的**：在快速判断时很好用，但在涉及溶剂效应、位阻效应、动力学控制时可能需要更精细的 FMO 分析。
4. **不要忽视杂原子的供体/受体双重性**：例如，N 在胺中是供体（孤对电子），但在酰胺中既可以通过共轭向 C=O 供电子，又可以作为弱碱接受质子。
5. **亲核性 ≠ 碱性**：碱性是热力学概念（pKa），亲核性是动力学概念。I⁻ 是好的亲核体但不是强碱。
