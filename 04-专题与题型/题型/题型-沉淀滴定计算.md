# 题型 · 沉淀滴定计算

> **来源专题**：[[专题-容量分析基础与酸碱滴定]]
> **核心考向**：Mohr法、Volhard法、Fajans法、返滴定、沉淀滴定计量关系

## 解题思路

沉淀滴定的核心是利用**沉淀反应的化学计量关系**进行定量计算。三种经典方法各有适用范围：**Mohr法**（铬酸钾指示剂，直接滴定Cl⁻/Br⁻，中性或弱碱性）、**Volhard法**（铁铵矾指示剂，返滴定，酸性条件）、**Fajans法**（吸附指示剂，直接滴定）。选择方法时需考虑被测离子种类、溶液酸度和干扰离子。

Mohr法的关键是控制pH（6.5~10.5）和指示剂用量。AgNO₃滴定Cl⁻时，计量点后过量的Ag⁺与CrO₄²⁻生成砖红色Ag₂CrO₄沉淀指示终点。Volhard法适用于酸性条件下测定卤化物（返滴定：先加过量AgNO₃，再用NH₄SCN返滴剩余Ag⁺，Fe³⁺作指示剂）。

计算时关键是建立**滴定剂与被测物的计量关系**。例如Mohr法中$n(\mathrm{AgNO_3}) = n(\mathrm{Cl^-})$；Volhard返滴定中$n(\mathrm{Cl^-}) = n(\mathrm{AgNO_3})_{\text{总}} - n(\mathrm{NH_4SCN})$。注意返滴定中两次滴定消耗的体积要分别处理。

## 核心方法

1. **Mohr法**：AgNO₃直接滴定Cl⁻/Br⁻，$n(\mathrm{AgNO_3}) = n(\mathrm{Cl^-})$，pH 6.5~10.5
2. **Volhard法**：返滴定，先加过量AgNO₃，再用NH₄SCN返滴，$n(\mathrm{Cl^-}) = n(\mathrm{AgNO_3})_{\text{总}} - n(\mathrm{SCN^-})$
3. **Fajans法**：吸附指示剂（荧光黄、伊红等），直接滴定
4. **返滴定优势**：适用于反应慢、无合适指示剂或被测物为沉淀的体系
5. **林邦误差公式**：沉淀滴定终点误差$E_t = (10^{\Delta\text{pAg}} - 10^{-\Delta\text{pAg}})/\sqrt{c_{\text{sp}}K_t}$

## 典型例题

### 例题 1：Mohr法测定NaCl含量（⭐⭐⭐）

**题目**：称取NaCl试样0.2500 g，溶于水后用0.1000 mol/L AgNO₃标准溶液滴定，以K₂CrO₄为指示剂，消耗AgNO₃溶液24.32 mL。求NaCl的质量分数。（$M(\mathrm{NaCl}) = 58.44$ g/mol）

**解答**：

滴定反应：$\mathrm{Ag^+ + Cl^- \to AgCl\downarrow}$（白色）

计量关系：$n(\mathrm{NaCl}) = n(\mathrm{AgNO_3})$

$$n(\mathrm{AgNO_3}) = 0.1000 \times 24.32 \times 10^{-3} = 2.432 \times 10^{-3}\ \mathrm{mol}$$

$$m(\mathrm{NaCl}) = 2.432 \times 10^{-3} \times 58.44 = 0.1421\ \mathrm{g}$$

$$w(\mathrm{NaCl}) = \frac{0.1421}{0.2500} \times 100\% = \mathbf{56.84\%}$$

**反思**：Mohr法操作简便但需严格控制pH。酸性太强时CrO₄²⁻转化为Cr₂O₇²⁻，指示剂失效；碱性太强时Ag⁺生成AgOH/Ag₂O沉淀。滴定过程中需避光（AgCl见光分解）。

---

### 例题 2：Volhard返滴定测定Cl⁻（⭐⭐⭐⭐）

**题目**：称取含NaCl的试样0.2000 g，加入25.00 mL 0.1000 mol/L AgNO₃标准溶液（过量），摇匀后过滤。滤液及洗涤液合并，用0.05000 mol/L NH₄SCN标准溶液滴定剩余Ag⁺，消耗12.50 mL。求NaCl的质量分数。

**解答**：

$$n(\mathrm{AgNO_3})_{\text{总}} = 0.1000 \times 25.00 \times 10^{-3} = 2.500 \times 10^{-3}\ \mathrm{mol}$$

$$n(\mathrm{NH_4SCN}) = 0.05000 \times 12.50 \times 10^{-3} = 6.250 \times 10^{-4}\ \mathrm{mol}$$

$$n(\mathrm{Cl^-}) = n(\mathrm{AgNO_3})_{\text{总}} - n(\mathrm{NH_4SCN}) = 2.500 \times 10^{-3} - 6.250 \times 10^{-4} = 1.875 \times 10^{-3}\ \mathrm{mol}$$

$$m(\mathrm{NaCl}) = 1.875 \times 10^{-3} \times 58.44 = 0.1096\ \mathrm{g}$$

$$w(\mathrm{NaCl}) = \frac{0.1096}{0.2000} \times 100\% = \mathbf{54.79\%}$$

**反思**：返滴定的关键是"两次滴定"——第一次加过量标准溶液与被测物完全反应，第二次用另一种标准溶液滴定剩余试剂。计算时必须用差减法求被测物的量。Volhard法在酸性条件下进行，可避免Fe³⁺水解。

## 易错点

1. **返滴定计量关系搞反**：$n(\text{被测}) = n(\text{过量试剂})_{\text{总}} - n(\text{返滴定剂})$，不是直接等于返滴定剂的量
2. **Mohr法pH控制不当**：酸性太强CrO₄²⁻失效，碱性太强Ag⁺沉淀，必须控制pH 6.5~10.5
3. **Volhard法中AgCl溶解**：AgCl的$K_{sp}$大于AgSCN，滴定过程中AgCl可能溶解导致误差，需过滤后再返滴
4. **指示剂用量影响终点**：K₂CrO₄浓度过高会使终点提前（CrO₄²⁻本身消耗Ag⁺），过低则终点滞后
