# 题型 · 杂化类型判断

## 解题思路

杂化类型判断的核心工具是 VSEPR（价层电子对互斥）理论。第一步，画出中心原子的 Lewis 结构，确定其周围的 $\sigma$ 键数目和孤对电子对数。第二步，计算杂化轨道数：$\text{杂化轨道数} = \sigma\text{键数} + \text{孤对电子对数} = \text{VSEPR 电子对数}$。该值直接决定杂化类型：2 → $sp$（直线形），3 → $sp^2$（平面三角形），4 → $sp^3$（四面体），5 → $sp^3d$（三角双锥），6 → $sp^3d^2$（八面体）。

最可靠的判断方法是由实验构型反推杂化方式。例如已知 $\text{CO}_2$ 为直线形分子，则中心 C 必为 $sp$ 杂化；已知 $\text{BF}_3$ 为平面正三角形，则 B 必为 $sp^2$ 杂化。这种逆推法避免了对孤对电子的误判。对于过渡金属配合物，杂化方式还与配体场强度有关，但主族元素的判断严格遵循 VSEPR 规则。

需要注意的特殊情况包括：$\text{SF}_6$ 中 S 的杂化为 $sp^3d^2$（利用了 d 轨道参与成键），$\text{XeF}_2$ 中 Xe 为 $sp^3d$ 杂化（2 个成键对 + 3 个孤对，直线形构型）。第二周期元素（C、N、O、F）一般不利用 d 轨道，故最多 $sp^3$ 杂化。

## 核心方法

1. **VSEPR 计数法**：$\text{杂化轨道数} = \sigma\text{键} + \text{孤对}$，直接对应杂化类型，这是最基本的方法
2. **由构型反推杂化**：已知分子空间构型可唯一确定杂化类型，如直线形 $\to sp$，V形 $\to sp^3$（2 成键 + 2 孤对）
3. **孤对电子对杂化的选择**：孤对电子占据杂化轨道，$\text{NH}_3$ 中 N 有 3 个 $\sigma$ 键 + 1 对孤对 $= 4$，故为 $sp^3$ 杂化（非 $sp^2$）
4. **第二周期元素无 d 轨道**：C、N、O、F 最多 $sp^3$ 杂化，$\text{CF}_4$ 为 $sp^3$，不存在 $sp^3d$ 可能
5. **超价分子的扩展杂化**：第三周期及以下元素可利用 d 轨道，$\text{PCl}_5$（$sp^3d$）、$\text{SF}_6$（$sp^3d^2$）

## 典型例题

**例题 1：确定 $\text{H}_2\text{O}$、$\text{CO}_2$、$\text{NH}_3$ 的杂化类型和空间构型**

**解答：**

**(a) $\text{CO}_2$**

Lewis 结构：$\text{O}\!=\!\text{C}\!=\!\text{O}$，C 上有 2 个 $\sigma$ 键、0 对孤对电子。

$$\text{VSEPR 对数} = 2 + 0 = 2 \implies sp \text{ 杂化}$$

空间构型：直线形，$\angle\text{O-C-O} = 180°$。C 的两个 $sp$ 杂化轨道分别与两个 O 的 $2p$ 轨道形成 $\sigma$ 键，C 上剩余的两个未杂化 $2p$ 轨道分别与两个 O 形成 $\pi$ 键（两个正交的 $\pi$ 键）。

**(b) $\text{NH}_3$**

Lewis 结构：N 连接 3 个 H、有 1 对孤对电子。

$$\text{VSEPR 对数} = 3 + 1 = 4 \implies sp^3 \text{ 杂化}$$

空间构型：三角锥形（四面体的变形），$\angle\text{H-N-H} = 107°$。孤对电子占据一个 $sp^3$ 轨道，由于孤对-成键对排斥大于成键对-成键对排斥，键角被压缩至 $107°$（小于理想四面体角 $109.5°$）。

**(c) $\text{H}_2\text{O}$**

Lewis 结构：O 连接 2 个 H、有 2 对孤对电子。

$$\text{VSEPR 对数} = 2 + 2 = 4 \implies sp^3 \text{ 杂化}$$

空间构型：V 形（弯曲形），$\angle\text{H-O-H} = 104.5°$。两对孤对电子占据两个 $sp^3$ 轨道，孤对-孤对排斥最强，进一步压缩键角至 $104.5°$。

---

**例题 2：判断 $\text{SF}_6$ 和 $\text{XeF}_2$ 的杂化类型**

**解答：**

**(a) $\text{SF}_6$**

S 的价电子数为 6，与 6 个 F 形成 6 个 $\sigma$ 键，S 上无孤对电子（6 个价电子全部用于成键）。

$$\text{VSEPR 对数} = 6 + 0 = 6 \implies sp^3d^2 \text{ 杂化}$$

空间构型：正八面体，$\angle\text{F-S-F} = 90°$（相邻）或 $180°$（对位）。S 利用一个 $3s$、三个 $3p$ 和两个 $3d$ 轨道杂化，形成 6 个等价的 $sp^3d^2$ 杂化轨道。实验测得 S-F 键长 $156.4\,\text{pm}$，全部等价，符合八面体对称性。

**(b) $\text{XeF}_2$**

Xe 的价电子数为 8，与 2 个 F 形成 2 个 $\sigma$ 键，剩余 3 对孤对电子（Xe 上共 6 个非键电子 + 2 个成键电子 $= 8$ 个价电子）。

$$\text{VSEPR 对数} = 2 + 3 = 5 \implies sp^3d \text{ 杂化}$$

空间构型：直线形（3 对孤对电子占据赤道位置，2 个 F 占据轴向位置）。尽管 VSEPR 电子对为三角双锥排布，但实际分子为直线形。Xe 利用 $5s$、$5p$ 和 $5d$ 轨道进行 $sp^3d$ 杂化，3 对孤对在赤道面内以 $120°$ 排布以最小化排斥，F-Xe-F 键角为 $180°$。

## 易错点

1. **孤对电子遗漏**：$\text{NH}_3$ 中 N 有 1 对孤对，杂化数为 4（$sp^3$）而非 3（$sp^2$），这是最常见的错误
2. **混淆杂化与构型**：$\text{NH}_3$ 是 $sp^3$ 杂化但构型为三角锥形（非正四面体），杂化方式由电子对数决定，构型由原子排布决定
3. **第二周期元素滥用 d 轨道**：$\text{CF}_4$ 中 C 为 $sp^3$ 杂化，不可能是 $sp^3d$；第二周期元素无 $d$ 轨道可用
4. **大pi键体系的误判**：苯环中每个 C 为 $sp^2$ 杂化，而非根据整个分子的复杂度来判断，应聚焦单个中心原子
