# 题型 · 重量分析计算

## 解题思路

重量分析计算是分析化学中的经典方法，通过称量沉淀的质量来确定被测组分的含量。解题流程如下：

1. **确定被测组分**：明确要测定的元素或化合物
2. **选择沉淀形式**：确定合适的沉淀剂和沉淀形式
3. **确定称量形式**：沉淀经过滤、洗涤、烘干或灼烧后的稳定形式
4. **计算换算因数**：建立被测组分与称量形式之间的计量关系
5. **计算含量**：根据称量质量和换算因数计算被测组分含量

**核心公式**：
```
被测组分含量 = (沉淀质量 × 换算因数 / 样品质量) × 100%
```

## 核心方法与知识点

### 1. 重量分析的基本步骤

| 步骤 | 操作 | 关键点 | 常见错误 |
|:---|:---|:---|:---|
| **沉淀** | 加入沉淀剂，控制条件 | 稀、热、慢、搅、陈 | 沉淀剂过量太多 |
| **陈化** | 沉淀与母液一起放置 | Ostwald熟化，提高纯度 | 陈化时间不足 |
| **过滤** | 分离沉淀与溶液 | 无灰滤纸或玻璃砂芯漏斗 | 沉淀穿过滤纸 |
| **洗涤** | 除去吸附的杂质 | 少量多次，检验洗涤完全 | 洗涤不彻底 |
| **烘干/灼烧** | 除去水分和挥发物 | 恒重操作 | 未达到恒重 |

### 2. 常见沉淀类型与条件

| 沉淀类型 | 典型例子 | 沉淀条件 | 称量形式 | 换算因数 |
|:---|:---|:---|:---|:---|
| **晶形沉淀** | BaSO₄ | 稀、热、慢、搅、陈 | BaSO₄ | F = M(Ba)/M(BaSO₄) = 0.5885 |
| **晶形沉淀** | CaC₂O₄ | 稀、热、慢、搅、陈 | CaCO₃或CaO | F = M(Ca)/M(CaC₂O₄) = 0.2743 |
| **无定形沉淀** | Fe(OH)₃ | 浓、热、快、搅、电解质 | Fe₂O₃ | F = 2M(Fe)/M(Fe₂O₃) = 0.6994 |
| **晶形沉淀** | MgNH₄PO₄ | 稀、热、慢、搅、陈 | Mg₂P₂O₇ | F = 2M(Mg)/M(Mg₂P₂O₇) = 0.3622 |

### 3. 换算因数计算方法

**换算因数F的定义**：
```
F = (被测组分的摩尔质量 × 化学计量数) / (称量形式的摩尔质量 × 化学计量数)
```

**计算步骤**：
1. 写出沉淀反应方程式
2. 确定被测组分与称量形式的计量关系
3. 计算摩尔质量
4. 代入公式计算F

**例子**：测定Ba²⁺，以BaSO₄为称量形式
- 反应：Ba²⁺ + SO₄²⁻ → BaSO₄↓
- 计量关系：Ba ~ BaSO₄（1:1）
- F = M(Ba) / M(BaSO₄) = 137.33 / 233.39 = 0.5885

### 4. 沉淀完全度判断

**溶度积规则**：
```
Ksp = [Mⁿ⁺][Aᵐ⁻]
```

**沉淀完全的标准**：
- 一般认为：[Mⁿ⁺] ≤ 10⁻⁵ mol/L 时沉淀完全
- 对于1:1型沉淀：需 [A⁻] ≥ √(Ksp/10⁻⁵)
- 对于1:2型沉淀：需 [A⁻] ≥ ³√(Ksp/10⁻⁵)

**同离子效应**：
- 加入过量沉淀剂可降低溶解度
- 但过量太多可能导致盐效应或形成配合物

### 5. 重量分析的误差来源

| 误差来源 | 影响 | 减免方法 |
|:---|:---|:---|
| **沉淀不完全** | 结果偏低 | 控制沉淀条件，加入过量沉淀剂 |
| **共沉淀** | 结果偏高 | 陈化、洗涤、控制沉淀条件 |
| **后沉淀** | 结果偏高 | 缩短沉淀与母液接触时间 |
| **溶解损失** | 结果偏低 | 控制洗涤条件，快速操作 |
| **称量误差** | 结果偏高或偏低 | 恒重操作，准确称量 |

## 典型例题

### 例题1：BaSO₄重量法测定Ba²⁺（基础）

**题目**：称取0.5000g含Ba²⁺的试样，溶解后加入过量稀H₂SO₄，得到BaSO₄沉淀。经洗涤、烘干后称得沉淀质量为0.4668g。
(1) 计算换算因数
(2) 计算试样中Ba²⁺的含量
(3) 计算试样中BaCl₂的含量

**解题过程**：

**(1) 计算换算因数**

- **反应方程式**：Ba²⁺ + SO₄²⁻ → BaSO₄↓
- **计量关系**：Ba ~ BaSO₄（1:1）
- **摩尔质量**：
  - M(Ba) = 137.33 g/mol
  - M(BaSO₄) = 233.39 g/mol
- **换算因数**：
  ```
  F = M(Ba) / M(BaSO₄) = 137.33 / 233.39 = 0.5885
  ```

**(2) 计算Ba²⁺的含量**

- **已知**：
  - 试样质量 = 0.5000 g
  - 沉淀质量 = 0.4668 g
- **计算**：
  ```
  Ba²⁺含量 = (沉淀质量 × 换算因数 / 试样质量) × 100%
  Ba²⁺含量 = (0.4668 × 0.5885 / 0.5000) × 100%
  Ba²⁺含量 = (0.2747 / 0.5000) × 100% = 54.94%
  ```

**(3) 计算BaCl₂的含量**

- **计量关系**：Ba ~ BaCl₂（1:1）
- **摩尔质量**：M(BaCl₂) = 208.23 g/mol
- **换算因数**：
  ```
  F' = M(BaCl₂) / M(BaSO₄) = 208.23 / 233.39 = 0.8922
  ```
- **计算**：
  ```
  BaCl₂含量 = (0.4668 × 0.8922 / 0.5000) × 100%
  BaCl₂含量 = (0.4165 / 0.5000) × 100% = 83.30%
  ```

**反思**：重量分析的关键是准确称量和正确的换算因数计算。

### 例题2：Fe₂O₃重量法测定Fe³⁺（综合）

**题目**：称取含铁矿样0.2500g，溶解后将Fe³⁺沉淀为Fe(OH)₃，经过滤、洗涤、灼烧后得到Fe₂O₃沉淀0.1200g。
(1) 计算换算因数
(2) 计算矿样中Fe的质量分数
(3) 计算矿样中Fe₂O₃的质量分数
(4) 若沉淀过程中有少量Fe(OH)₃溶解损失，对结果有何影响？

**解题过程**：

**(1) 计算换算因数**

- **反应方程式**：Fe³⁺ + 3OH⁻ → Fe(OH)₃↓
- **灼烧反应**：2Fe(OH)₃ → Fe₂O₃ + 3H₂O
- **计量关系**：2Fe ~ Fe₂O₃
- **摩尔质量**：
  - M(Fe) = 55.85 g/mol
  - M(Fe₂O₃) = 159.69 g/mol
- **换算因数**：
  ```
  F = 2M(Fe) / M(Fe₂O₃) = (2 × 55.85) / 159.69 = 111.70 / 159.69 = 0.6994
  ```

**(2) 计算Fe的质量分数**

- **已知**：
  - 矿样质量 = 0.2500 g
  - Fe₂O₃质量 = 0.1200 g
- **计算**：
  ```
  Fe含量 = (Fe₂O₃质量 × 换算因数 / 矿样质量) × 100%
  Fe含量 = (0.1200 × 0.6994 / 0.2500) × 100%
  Fe含量 = (0.08393 / 0.2500) × 100% = 33.57%
  ```

**(3) 计算Fe₂O₃的质量分数**

- **方法一**：直接用沉淀质量
  ```
  Fe₂O₃含量 = (0.1200 / 0.2500) × 100% = 48.00%
  ```

- **方法二**：由Fe含量换算
  ```
  Fe₂O₃含量 = Fe含量 × (M(Fe₂O₃) / 2M(Fe))
  Fe₂O₃含量 = 33.57% × (159.69 / 111.70) = 33.57% × 1.4296 = 48.00%
  ```

**(4) Fe(OH)₃溶解损失的影响**

- **影响**：沉淀质量减少，导致Fe含量结果偏低
- **原因**：Fe(OH)₃有微小溶解度，洗涤过程中可能部分溶解
- **减免方法**：
  - 控制洗涤条件（用稀NH₄NO₃溶液洗涤）
  - 快速操作，减少溶解时间
  - 使用大量母液，减少溶解损失比例

**反思**：重量分析需严格控制操作条件，避免沉淀损失。

### 例题3：MgNH₄PO₄重量法测定Mg²⁺（竞赛）

**题目**：称取含镁试样0.2000g，溶解后加入(NH₄)₂HPO₄沉淀剂，得到MgNH₄PO₄·6H₂O沉淀。经洗涤、烘干后称得沉淀质量为0.3960g。
(1) 写出沉淀反应方程式
(2) 计算换算因数
(3) 计算试样中Mg的质量分数
(4) 若沉淀剂(NH₄)₂HPO₄不足，对结果有何影响？

**解题过程**：

**(1) 沉淀反应方程式**

- **反应方程式**：
  ```
  Mg²⁺ + NH₄⁺ + PO₄³⁻ + 6H₂O → MgNH₄PO₄·6H₂O↓
  ```
- **计量关系**：Mg ~ MgNH₄PO₄·6H₂O（1:1）

**(2) 计算换算因数**

- **摩尔质量**：
  - M(Mg) = 24.31 g/mol
  - M(MgNH₄PO₄·6H₂O) = 245.41 g/mol
- **换算因数**：
  ```
  F = M(Mg) / M(MgNH₄PO₄·6H₂O) = 24.31 / 245.41 = 0.09906
  ```

**(3) 计算Mg的质量分数**

- **已知**：
  - 试样质量 = 0.2000 g
  - 沉淀质量 = 0.3960 g
- **计算**：
  ```
  Mg含量 = (沉淀质量 × 换算因数 / 试样质量) × 100%
  Mg含量 = (0.3960 × 0.09906 / 0.2000) × 100%
  Mg含量 = (0.03923 / 0.2000) × 100% = 19.62%
  ```

**(4) 沉淀剂不足的影响**

- **影响**：Mg²⁺沉淀不完全，导致Mg含量结果偏低
- **原因**：沉淀剂不足时，[PO₄³⁻]浓度低，沉淀不完全
- **判断**：需满足 [Mg²⁺] ≤ 10⁻⁵ mol/L 才算沉淀完全
- **减免方法**：
  - 加入过量沉淀剂（但不能过量太多，防止形成可溶性配合物）
  - 控制pH在9-10（氨性缓冲液）
  - 陈化提高沉淀纯度

**反思**：MgNH₄PO₄是晶形沉淀，需控制沉淀条件以获得易过滤的沉淀。

## 易错点与注意事项

### 1. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|:---|:---|:---|
| **换算因数计算错误** | "F = M(称量形式)/M(被测)" | F = M(被测)/M(称量形式) |
| **计量关系错误** | "1mol BaSO₄对应2mol Ba²⁺" | 1mol BaSO₄对应1mol Ba²⁺ |
| **沉淀条件混淆** | "所有沉淀都需陈化" | 无定形沉淀不需陈化 |
| **恒重判断错误** | "两次称量差<0.1mg即恒重" | 应连续两次称量差<0.2-0.4mg |

### 2. 解题检查清单

- [ ] 是否正确写出沉淀反应方程式
- [ ] 是否确定了正确的计量关系
- [ ] 换算因数计算是否正确
- [ ] 样品质量和沉淀质量是否准确
- [ ] 结果是否合理（与预期值比较）

### 3. 高频考点

1. **换算因数计算**：建立被测组分与称量形式的计量关系
2. **沉淀条件控制**：晶形沉淀vs无定形沉淀的条件
3. **误差分析**：各种误差来源对结果的影响
4. **恒重操作**：正确的称量和判断方法
5. **洗涤完全性检验**：检验沉淀是否洗涤干净

### 4. 实验注意事项

- **恒重操作**：两次称量差<0.2-0.4mg
- **沉淀洗涤**：少量多次，检验洗涤完全
- **陈化时间**：通常2-4小时或过夜
- **称量瓶使用**：盖好瓶盖，防止吸湿
