# 题型 · 周期律比较

## 解题思路

### 核心判断依据
- **元素周期律**：元素性质随原子序数递增呈周期性变化
- 同周期从左到右：原子半径减小、电离能增大（总体）、电负性增大、金属性减弱
- 同族从上到下：原子半径增大、电离能减小（总体）、电负性减小、金属性增强
- **反常点**：半满/全满稳定构型导致的电离能异常（ⅡA > ⅢA、ⅤA > ⅥA）

### 常见出题角度
1. 比较原子半径大小
2. 比较第一电离能大小
3. 比较电负性大小
4. 比较金属性/非金属性强弱
5. 解释周期律中的反常现象

## 核心方法与知识点

### 关键知识点

**同周期性质递变规律**（从左到右）：

| 性质 | 趋势 | 核心原因 | 反常点 |
|:---|:---|:---|:---|
| 原子半径 | ↓ 减小 | Z* 增大，核引力增强 | — |
| 第一电离能 I₁ | ↑ 增大（总体） | Z* 增大，更难失电子 | ⅡA > ⅢA（s²全满）、ⅤA > ⅥA（p³半满） |
| 电负性 χ | ↑ 增大 | 吸引电子能力增强 | F 最大（4.0），稀有气体无定义 |
| 金属性 | ↓ 减弱 | 失电子能力减弱 | — |
| 非金属性 | ↑ 增强 | 得电子能力增强 | — |

**同族性质递变规律**（从上到下）：

| 性质 | 趋势 | 核心原因 | 反常点 |
|:---|:---|:---|:---|
| 原子半径 | ↑ 增大 | 电子层数增加 | — |
| 第一电离能 I₁ | ↓ 减小（总体） | 核对外层电子引力减弱 | ⅡA > ⅢA（同周期） |
| 电负性 χ | ↓ 减小 | 吸引电子能力减弱 | — |
| 金属性 | ↑ 增强 | 失电子能力增强 | — |
| 非金属性 | ↓ 减弱 | 得电子能力减弱 | — |

**电离能反常的解释**：

| 反常位置 | 预期 | 实际 | 原因 |
|:---:|:---:|:---:|:---|
| ⅡA vs ⅢA | I₁(ⅡA) < I₁(ⅢA) | I₁(ⅡA) > I₁(ⅢA) | ⅡA 的 ns² 全满，稳定；ⅢA 的 np¹ 易失 |
| ⅤA vs ⅥA | I₁(ⅤA) < I₁(ⅥA) | I₁(ⅤA) > I₁(ⅥA) | ⅤA 的 np³ 半满，稳定；ⅥA 的 np⁴ 有配对能排斥 |

**有效核电荷 Z\* 的影响**：
- Z* = Z - σ（σ 为屏蔽常数）
- Z* 越大，核对外层电子引力越强
- 同周期 Z* 增大 → 原子半径减小、电离能增大

### 解题步骤框架

**步骤 1**：确定比较方向
- 同周期：从左到右
- 同族：从上到下

**步骤 2**：写出电子排布
- 确定价电子构型
- 判断是否有半满/全满稳定构型

**步骤 3**：应用周期律趋势
- 同周期：半径↓、电离能↑、电负性↑
- 同族：半径↑、电离能↓、电负性↓

**步骤 4**：检查反常点
- ⅡA > ⅢA（ns² 全满）
- ⅤA > ⅥA（np³ 半满）

**步骤 5**：给出结论

## 典型例题

### 例题 1：原子半径比较

**题目**：比较下列原子半径大小：
(1) Na、Mg、Al
(2) F、Cl、Br
(3) Na、K、Rb

**解答**：

**(1) Na、Mg、Al（同周期）**
- 三者均在第三周期
- 从左到右：Na → Mg → Al
- 电子层数相同（3层），但核电荷数增加
- 核对外层电子引力增强 → 半径减小
- **半径顺序：Na > Mg > Al**
- 实验值：Na(186 pm) > Mg(160 pm) > Al(143 pm)

**(2) F、Cl、Br（同族）**
- 三者均在ⅦA族
- 从上到下：F → Cl → Br
- 电子层数增加（2→3→4）
- 外层电子离核更远 → 半径增大
- **半径顺序：F < Cl < Br**
- 实验值：F(64 pm) < Cl(99 pm) < Br(114 pm)

**(3) Na、K、Rb（同族）**
- 三者均在ⅠA族
- 从上到下：Na → K → Rb
- 电子层数增加（3→4→5）
- **半径顺序：Na < K < Rb**
- 实验值：Na(186 pm) < K(227 pm) < Rb(248 pm)

### 例题 2：第一电离能比较

**题目**：比较下列元素的第一电离能大小：
(1) B、C、N、O
(2) Na、Mg、Al、Si、P、S、Cl

**解答**：

**(1) B、C、N、O（第二周期）**
- 预期顺序（按 Z* 递增）：B < C < N < O
- 实际顺序：**B < C < O < N**
- 反常点：N > O
- 原因：
  - N 的 2p³ 为**半满**稳定构型，电离能反常升高
  - O 的 2p⁴ 有一个电子配对，存在**配对能排斥**，易失去
- 电离能（kJ/mol）：B(801) < C(1086) < O(1314) < N(1402)

**(2) Na→Cl（第三周期）**
- 预期：Na < Mg < Al < Si < P < S < Cl（单调递增）
- 实际：**Na < Al < Mg < Si < S < P < Cl**
- 反常点：
  - Mg > Al：Mg 的 3s² 全满，Al 的 3p¹ 易失
  - P > S：P 的 3p³ 半满，S 的 3p⁴ 有配对能排斥
- 电离能（kJ/mol）：
  - Na(496) < Al(578) < Mg(738) < Si(786) < S(1000) < P(1012) < Cl(1251)

### 例题 3：电负性比较与应用

**题目**：
(1) 比较 O、S、Se 的电负性大小
(2) 解释为什么 HF 是强酸而 HCl 是弱酸

**解答**：

**(1) O、S、Se 电负性比较**
- 三者均在ⅥA族
- 从上到下：O → S → Se
- 电子层数增加，原子半径增大
- 核对外层电子引力减弱 → 电负性减小
- **电负性顺序：O > S > Se**
- Pauling 电负性：O(3.44) > S(2.58) > Se(2.55)

**(2) HF 与 HCl 酸性比较**
- 电负性：F(3.98) > Cl(3.16)
- H–F 键能：567 kJ/mol（强）
- H–Cl 键能：431 kJ/mol（较弱）
- HF 中 H–F 键强，不易电离 → 弱酸
- HCl 中 H–Cl 键较弱，易电离 → 强酸
- **酸性：HF < HCl**
- 注意：这是键能主导的结果，不是电负性直接决定

## 易错点与注意事项

### 高频错误

1. **忽视电离能反常**
   - 错误：电离能从左到右单调递增
   - 正确：ⅡA > ⅢA，ⅤA > ⅥA（半满/全满稳定）

2. **混淆原子半径和离子半径**
   - 错误：Na 原子半径 < Na⁺ 半径
   - 正确：Na 原子半径（186 pm）> Na⁺ 半径（102 pm）

3. **电负性比较方向错误**
   - 错误：同族从上到下电负性增大
   - 正确：同族从上到下电负性**减小**

4. **忽略相对论效应**
   - 错误：Au 的电负性低于 Ag
   - 正确：Au 的电负性（2.54）> Ag（1.93），因 6s 收缩

5. **金属性与非金属性混淆**
   - 错误：金属性从左到右增强
   - 正确：金属性从左到右**减弱**
