# 题型 · 综合计算

## 解题思路

综合计算是化学竞赛中难度最高的题型之一，常见于决赛。它要求将热力学、动力学、电化学、平衡等多个模块的知识串联起来，进行多步联立计算。2025 初赛计算量暴增（从 5 分升至 30 分），综合计算能力已成为竞赛区分度的核心。

**通用解题流程：**

1. **识别题目的"桥"**：题目给出哪些已知量？要求什么未知量？中间需要经过哪些桥梁量？
2. **列出所有相关公式**：ΔGθ = -nFEθ、ΔGθ = -RT ln K、Ksp、Nernst、Arrhenius 等。
3. **构建计算路径**：从已知量出发，逐步推到未知量。每一步标注依据的公式。
4. **执行计算**：注意单位统一、有效数字、对数运算。
5. **交叉验证**：结果是否与已知化学直觉一致？是否自洽？

**一屏判断卡：**

```
综合计算题 → 先找桥
    │
    ├─ Eθ 起手
    │   └─ Eθ → ΔGθ = -nFEθ → K = 10^(nEθ/0.0592)
    │
    ├─ 热化学起手
    │   └─ Hess 定律 → ΔHθ, ΔSθ → ΔGθ = ΔHθ - TΔSθ
    │
    ├─ 平衡起手
    │   └─ K → ΔGθ → Eθ 或 ΔHθ/ΔSθ
    │
    ├─ 动力学起手
    │   └─ k(T) → Arrhenius → Ea → 热力学参数
    │
    └─ 多桥联立
        └─ Eθ ↔ ΔGθ ↔ K ↔ ΔHθ/ΔSθ（四大热力学量互转）
```

## 核心方法与知识点

### 1. 热力学四大桥梁

| 桥梁公式 | 连接的量 | 使用条件 |
---|:---|:---|
| ΔGθ = -nFEθ | 电化学 → 热力学 | 电池电动势 |
| ΔGθ = -RT ln K | 平衡 → 热力学 | 平衡常数 |
| ΔGθ = ΔHθ - TΔSθ | 量热 → 热力学 | 焓变和熵变 |
| Eθ = (0.0592/n) lg K | 电化学 → 平衡 | 298 K 标准态 |

### 2. 常见联立计算模式

| 模式 | 已知 | 求解路径 | 示例 |
|:---|:---|:---|:---|
| Eθ → K | 标准电动势 | K = 10^(nEθ/0.0592) | 电池平衡常数 |
| Ksp + Eθ | 溶度积 + 电极电势 | Ksp → [Mⁿ⁺] → E(Nernst) | 沉淀对电势的影响 |
| ΔHθ, ΔSθ → K(T) | 焓变、熵变 | van't Hoff: ln(K₂/K₁) = ΔHθ/R × (1/T₁ - 1/T₂) | 温度对平衡的影响 |
| BDE + Eθ | 键解离能 + 电极电势 | BDE → ΔH → ΔG → K 或 E | 热化学循环 |
| Ksp + Ka → s | 溶度积 + 酸常数 | 联立方程组 | 酸中溶解度 |
| k₁, k₂(T) | 不同温度的速率常数 | Arrhenius: ln(k₂/k₁) = Ea/R × (1/T₁ - 1/T₂) | 活化能 |

### 3. Born-Haber 循环

$$\Delta H_f = \Delta H_{sub}(M) + IE + \frac{1}{2}D(X_2) + EA + U$$

| 项 | 含义 | 对氧化态稳定性的影响 |
|:---|:---|:---|
| IE（电离能） | 气态原子 → 气态阳离子 | IE 越高 → 高氧化态越不稳定 |
| EA（电子亲和能） | 气态原子 → 气态阴离子 | EA 越大（越负）→ 阴离子越稳定 |
| U（晶格能） | 气态离子 → 晶体 | U 越大 → 晶体越稳定 |

### 4. Latimer 图与元素电势图

**歧化判断**：Eθ(右) > Eθ(左) → 中间氧化态歧化。

**电势计算**（不能直接加减 Eθ）：

$$E_3^\theta = \frac{n_1 E_1^\theta + n_2 E_2^\theta}{n_1 + n_2}$$

### 5. van't Hoff 方程

$$\ln\frac{K_2}{K_1} = \frac{\Delta H^\theta}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)$$

用于计算温度变化对平衡常数的影响。

## 典型例题

### 例题 1：Eθ → K → ΔGθ 三联算

**题目：** 已知 Eθ(Cu²⁺/Cu) = 0.34 V，Eθ(Zn²⁺/Zn) = -0.762 V。(1) 计算 Cu-Zn 电池的标准电动势；(2) 计算 25°C 时电池反应的 ΔGθ；(3) 计算平衡常数 K。

**解题过程：**

**(1) 标准电动势：**
- 正极（还原）：Cu²⁺ + 2e⁻ → Cu，Eθ = 0.34 V
- 负极（氧化）：Zn → Zn²⁺ + 2e⁻，Eθ = -0.762 V
- Eθ(池) = Eθ(正) - Eθ(负) = 0.34 - (-0.762) = **1.102 V**

**(2) ΔGθ：**
- ΔGθ = -nFEθ = -2 × 96485 × 1.102
- ΔGθ = -212,636 J/mol = **-212.6 kJ/mol**

**(3) 平衡常数 K：**
- ΔGθ = -RT ln K
- ln K = -ΔGθ/(RT) = 212636/(8.314 × 298.15) = 85.8
- K = e^85.8 = **10^37.3**

**或用简化公式：**
- lg K = nEθ/0.0592 = 2 × 1.102/0.0592 = 37.2
- K = 10^37.2 ≈ 1.6 × 10^37

**结论：** Eθ(池) = 1.102 V，ΔGθ = -212.6 kJ/mol，K ≈ 10^37。K 极大说明反应几乎完全。

**反思：** 三个量（Eθ、ΔGθ、K）描述的是同一个反应的热力学趋势，只是语言不同。竞赛中常要求三者互转。

### 例题 2：Born-Haber 循环判断氧化态稳定性

**题目：** 已知以下数据（kJ/mol）：
- ΔH_sub(Cu) = 338
- IE₁(Cu) = 745
- IE₂(Cu) = 1958
- D(Cl₂) = 242
- EA(Cl) = -349
- U(CuCl) = -992
- U(CuCl₂) = -2480

(1) 计算 ΔH_f(CuCl) 和 ΔH_f(CuCl₂)。(2) 解释为什么 CuCl₂ 在热力学上不稳定（容易分解）。

**解题过程：**

**(1) ΔH_f 计算：**

**CuCl（Cu⁺）：**
$$\Delta H_f = \Delta H_{sub} + IE_1 + \frac{1}{2}D + EA + U$$
$$= 338 + 745 + 121 + (-349) + (-992) = -137\ \mathrm{kJ/mol}$$

**CuCl₂（Cu²⁺）：**
$$\Delta H_f = \Delta H_{sub} + IE_1 + IE_2 + D + 2EA + U$$
$$= 338 + 745 + 1958 + 242 + 2(-349) + (-2480)$$
$$= 338 + 745 + 1958 + 242 - 698 - 2480 = 105\ \mathrm{kJ/mol}$$

**(2) 稳定性分析：**
- ΔH_f(CuCl) = -137 kJ/mol < 0 → CuCl 热力学稳定
- ΔH_f(CuCl₂) = +105 kJ/mol > 0 → CuCl₂ 热力学不稳定！
- CuCl₂ 倾向分解：CuCl₂ → CuCl + ½Cl₂（ΔH = -137 + 105 = -32 kJ/mol，放热）

**原因分析**：
- Cu²⁺ 的第二电离能（1958 kJ/mol）非常高 → 这一项是 ΔH_f(CuCl₂) 为正的主要原因
- 晶格能 U(CuCl₂) = -2480 虽然很大（绝对值），但不足以补偿高 IE₂

**结论：** CuCl 稳定（ΔH_f < 0），CuCl₂ 不稳定（ΔH_f > 0），因为 Cu⁺ → Cu²⁺ 的第二电离能太高。

**反思：** Born-Haber 循环是判断氧化态稳定性的核心工具。竞赛中常问"为什么某氧化态不存在"——答案往往是"该氧化态的 ΔH_f > 0"。

### 例题 3：多步联立——Ksp + Nernst + K

**题目：** 已知 Ksp(AgCl) = 1.8 × 10⁻¹⁰，Eθ(Ag⁺/Ag) = 0.80 V。(1) 计算 Eθ(AgCl/Ag)；(2) 计算反应 AgCl(s) + I⁻(aq) ⇌ AgI(s) + Cl⁻(aq) 的平衡常数 K。已知 Ksp(AgI) = 8.5 × 10⁻¹⁷。

**解题过程：**

**(1) Eθ(AgCl/Ag)：**
- AgCl/Ag 电对的半反应：AgCl(s) + e⁻ ⇌ Ag(s) + Cl⁻
- Eθ(AgCl/Ag) = Eθ(Ag⁺/Ag) + 0.0592 lg Ksp(AgCl)
- = 0.80 + 0.0592 × lg(1.8 × 10⁻¹⁰)
- = 0.80 + 0.0592 × (-9.74)
- = 0.80 - 0.577 = **0.223 V**

**(2) 沉淀转化的平衡常数：**
- 反应：AgCl(s) + I⁻ ⇌ AgI(s) + Cl⁻
- K = [Cl⁻]/[I⁻] = Ksp(AgCl)/Ksp(AgI)
- = 1.8 × 10⁻¹⁰ / 8.5 × 10⁻¹⁷
- = **2.1 × 10⁶**

K > 10⁶ → 转化完全。微量 I⁻ 即可将 AgCl 转化为 AgI。

**反思：** 这道题展示了三个知识点的联立：Ksp → 电极电势（Nernst）、Ksp 比值 → 沉淀转化平衡常数。竞赛综合计算的核心就是这种"搭桥"能力。

## 易错点与注意事项

1. **电势不能直接加减**：必须通过 ΔG = -nFE 转换。Eθ(AgCl/Ag) ≠ Eθ(Ag⁺/Ag) + Ksp，正确的公式是 Eθ(AgCl/Ag) = Eθ(Ag⁺/Ag) + 0.0592 lg Ksp。
2. **van't Hoff 方程中的温度用绝对温度**：T 必须是 K，不是 °C。
3. **ΔHθ 和 ΔSθ 通常与温度无关**（近似）：可以先算一个温度下的 ΔGθ，再用 ΔGθ = ΔHθ - TΔSθ 推其他温度。
4. **有效数字**：对数的有效数字看尾数。lg(1.8 × 10⁻¹⁰) = -9.74，有效数字 2 位在尾数（0.74）。
5. **Born-Haber 循环中各步的符号**：ΔH_sub > 0（吸热），IE > 0（吸热），EA < 0（放热），U < 0（放热）。不要搞混符号。
6. **综合计算题先写公式再代数**：不要一上来就代数字。先写清楚每一步用什么公式，再执行计算。
