# 题型 · 实验鉴别

## 解题思路

实验鉴别题要求设计化学实验方案，区分两种或多种物质，或鉴定未知物的组成。这类题考查的是对化学反应现象、分析方法和实验设计逻辑的综合掌握。

**通用解题流程：**

1. **明确鉴别目标**：区分 A 和 B？还是鉴定未知物 X？还是检验某种离子的存在？
2. **找差异**：A 和 B 的化学性质差异是什么？（颜色、溶解性、酸碱性、氧化还原性、配位能力、沉淀特征等）
3. **选择特征反应**：选一个 A 能反应而 B 不能（或反过来）的反应，或者反应现象明显不同的反应。
4. **设计实验步骤**：取样 → 加试剂 → 观察现象 → 得出结论。步骤要具体、可操作。
5. **排除干扰**：确认试剂不会与其他物质反应产生混淆现象。

**一屏判断卡：**

```
实验鉴别题 → 先找 A/B 的核心差异
    │
    ├─ 颜色差异？
    │   └─ 直接观察或加试剂看颜色变化
    │
    ├─ 溶解性差异？
    │   └─ 水溶/酸溶/碱溶/有机溶剂溶
    │
    ├─ 酸碱性差异？
    │   └─ pH 试纸、指示剂、与酸/碱的反应
    │
    ├─ 氧化还原性差异？
    │   └─ 加氧化剂/还原剂，看现象
    │
    ├─ 沉淀反应差异？
    │   └─ 加特定试剂，看沉淀颜色/溶解性
    │
    └─ 配位反应差异？
        └─ 加配体，看颜色变化或沉淀溶解
```

### 2. 定性分析中的系统分组

| 分组 | 沉淀条件 | 包含离子 | 典型试剂 |
|:---|:---|:---|:---|
| 第一组（HCl 组） | 酸性条件下加 HCl | Ag⁺, Pb²⁺, Hg₂²⁺ | 6 M HCl |
| 第二组（H₂S 组） | 0.3 M HCl 中通 H₂S | Cu²⁺, Cd²⁺, Bi³⁺, Sn²⁺ | H₂S/HCl |
| 第三组（NH₃ 组） | NH₃/NH₄Cl 缓冲 + H₂S | Fe³⁺, Co²⁺, Ni²⁺, Al³⁺, Cr³⁺ | NH₃ + H₂S |
| 第四组（碳酸盐组） | (NH₄)₂CO₃ | Ba²⁺, Ca²⁺, Sr²⁺ | (NH₄)₂CO₃ |
| 第五组（可溶组） | 以上均不沉淀 | Na⁺, K⁺, NH₄⁺, Mg²⁺ | 焰色反应等 |

### 3. 实验设计的逻辑框架

| 设计要素 | 要求 | 示例 |
|:---|:---|:---|
| 取样量 | 适量（~1-2 mL 溶液或 ~0.1 g 固体） | 不要取太多，节约试剂 |
| 试剂选择 | 专一性强、现象明显 | KSCN 检 Fe³⁺（血红色，灵敏度高） |
| 操作步骤 | 先做什么后做什么，顺序不能乱 | 先酸化再加 BaCl₂（排除 CO₃²⁻ 干扰） |
| 现象描述 | 颜色、沉淀、气体、热量变化 | "产生白色沉淀，不溶于稀硝酸" |
| 结论逻辑 | 如果...则...；如果...则不... | "若加 KSCN 显红色，则含 Fe³⁺" |

### 4. 有机物的鉴别方法

| 官能团 | 鉴别试剂 | 现象 |
|:---|:---|:---|
| 醇 (-OH) | Lucas 试剂（ZnCl₂/HCl） | 仲醇 ~5 min 变浑浊，叔醇立即变浑浊 |
| 醛 (-CHO) | Tollens 试剂（银氨溶液） | 加热产生银镜 |
| 醛 (-CHO) | Fehling 试剂 | 加热产生砖红色 Cu₂O 沉淀 |
| 酮 (C=O) | 2,4-DNP 试剂 | 橙/红色沉淀 |
| 烯烃 (C=C) | Br₂/CCl₄ | 褪色 |
| 烯烃 (C=C) | KMnO₄ (稀) | 褪色 + 棕色 MnO₂ 沉淀 |
| 胺 (-NH₂) | Hinsberg 试验（苯磺酰氯） | 伯胺：产物溶于碱；仲胺：产物不溶于碱 |
| 羧酸 (-COOH) | NaHCO₃ | 产生 CO₂ 气泡 |

## 典型例题

### 例题 1：鉴别 NaCl 和 NaBr

**题目：** 设计实验方案区分 NaCl 和 NaBr 固体。

**解题过程：**

1. **找差异**：Cl⁻ 和 Br⁻ 的银盐颜色不同（AgCl 白色，AgBr 淡黄色），且 AgBr 溶于 Na₂S₂O₃ 而 AgCl 不溶（但 AgCl 也可溶于浓氨水）。

2. **方案一（AgNO₃ 法）**：
   - 分别取少量样品溶于水
   - 各加稀 HNO₃ 酸化（排除 CO₃²⁻ 等干扰）
   - 各加 AgNO₃ 溶液
   - NaCl → 白色沉淀（AgCl）
   - NaBr → 淡黄色沉淀（AgBr）

3. **方案二（氯水法）**：
   - 分别取少量样品溶于水
   - 加氯水（Cl₂）和少量 CCl₄，振荡
   - NaCl → 无明显变化（Cl₂ 不氧化 Cl⁻）
   - NaBr → CCl₄ 层变为橙红色（Br₂ 被萃取）

4. **方案三（浓氨水法，辅助确认）**：
   - AgCl 溶于浓氨水（形成 [Ag(NH₃)₂]⁺），AgBr 不溶

**结论：** 方案一最简单直接，通过沉淀颜色即可区分。

**反思：** 鉴别题的核心是"找差异，选特征反应"。Cl⁻ 和 Br⁻ 最经典的差异就是银盐颜色。

---

### 例题 2：鉴别 Fe²⁺ 和 Fe³⁺

**题目：** 设计至少三种方法区分 Fe²⁺ 溶液和 Fe³⁺ 溶液。

**解题过程：**

**方法一：KSCN 法**
- 取少量待测液，加 KSCN 溶液
- Fe³⁺ → 血红色（[Fe(SCN)]²⁺ 等配合物）
- Fe²⁺ → 无明显颜色变化（或极浅绿色）

**方法二：K₃[Fe(CN)₆] 法**
- 取少量待测液，加 K₃[Fe(CN)₆]（铁氰化钾）溶液
- Fe²⁺ → 深蓝色沉淀（Turnbull 蓝，KFe[Fe(CN)₆]）
- Fe³⁺ → 棕色溶液（无蓝色沉淀）

**方法三：NaOH 法**
- 取少量待测液，加 NaOH 溶液
- Fe²⁺ → 白色沉淀 → 迅速变灰绿色 → 最终变棕红色（Fe(OH)₂ → Fe(OH)₃）
- Fe³⁺ → 立即产生红棕色沉淀（Fe(OH)₃）

**方法四：KMnO₄ 法**
- 取少量待测液，加稀 KMnO₄ 溶液
- Fe²⁺ → KMnO₄ 紫色褪去（Fe²⁺ 被氧化为 Fe³⁺，MnO₄⁻ 被还原为 Mn²⁺）
- Fe³⁺ → 紫色不褪（Fe³⁺ 已是高氧化态，不还原 MnO₄⁻）

**结论：** KSCN 法最灵敏、最常用；KMnO₄ 法同时检验了 Fe²⁺ 的还原性。

**反思：** 同一鉴别对象可以用多种方法，竞赛中要求至少写出两种。选择时优先选"现象明显、操作简单、专一性高"的方法。

---

### 例题 3：鉴别白色粉末

**题目：** 有四种白色粉末：Na₂CO₃、NaHCO₃、NaCl、Na₂SO₄。设计实验方案一一鉴别。

**解题过程：**

1. **分别取样溶于水**，得到四种无色溶液。

2. **加 BaCl₂ 溶液**：
   - Na₂CO₃ → 白色沉淀（BaCO₃）
   - Na₂SO₄ → 白色沉淀（BaSO₄）
   - NaHCO₃ → 无沉淀（Ba(HCO₃)₂ 可溶）
   - NaCl → 无沉淀

3. **对有沉淀的两个**，加稀 HNO₃：
   - BaCO₃ → 溶解，产生气泡（CO₂）
   - BaSO₄ → 不溶解

4. **对无沉淀的两个**，加稀 HCl：
   - NaHCO₃ → 立即产生气泡（CO₂）
   - NaCl → 无气泡

5. **验证**：Na₂CO₃ 也会与 HCl 产生气泡，但速率不同（Na₂CO₃ 先生成 NaHCO₃ 再产生 CO₂，有延迟）。

**结论流程：**
```
四种粉末 → 加 BaCl₂
    ├─ 有沉淀 → 加 HNO₃
    │   ├─ 溶解+气泡 → Na₂CO₃
    │   └─ 不溶 → Na₂SO₄
    └─ 无沉淀 → 加 HCl
        ├─ 有气泡 → NaHCO₃
        └─ 无气泡 → NaCl
```

**反思：** 多物质鉴别要用"树形分叉法"——每次实验将样品分成两组，逐步缩小范围。不要试图一步到位。

## 易错点与注意事项

1. **先酸化再加试剂**：加 AgNO₃ 前必须加稀 HNO₃ 酸化，否则 CO₃²⁻、OH⁻ 等也会产生沉淀。
2. **AgCl 和 AgBr 的颜色区分**：AgCl 纯白色，AgBr 淡黄色。在光线好的时候可以直接用颜色区分。
3. **不要把"反应"等同于"鉴别"**：有些反应现象不够明显（如无色变无色），不适合作为鉴别方法。
4. **Fe(OH)₂ 的颜色变化**：白色 → 灰绿色 → 棕红色，整个过程很快（几分钟），观察时要快。
5. **有机鉴别要注意官能团的相似性**：醛和酮都能与 2,4-DNP 反应（都有 C=O），但只有醛能发生银镜反应。
6. **实验方案要写完整**：取样 → 加试剂 → 现象 → 结论，四步缺一不可。
