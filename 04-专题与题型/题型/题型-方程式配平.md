# 题型 · 方程式配平

> **核心支撑页**：[[专题-化学计量与气体]]、[[专题-氧化还原与电化学]]

## 解题思路

方程式配平是化学计算的"第一关"——配平错了，后面的计量关系全部错误。面对这类题型，首先判断反应类型：非氧化还原反应（如复分解、化合、分解）用观察法或最小公倍数法配平；氧化还原反应用化合价升降法（氧化数法）或半反应法（离子-电子法）配平。配平的核心原则是**质量守恒**（原子数相等）和**电荷守恒**（离子方程式中两边电荷相等）。

氧化还原配平的两种主要方法：(1) **化合价升降法**：标出变价元素的氧化态 → 计算升降总数 → 找最小公倍数确定系数 → 配平其他原子。适用于分子方程式。(2) **半反应法**：拆分为氧化/还原半反应 → 分别配平原子和电荷 → 电子数相等后合并。适用于离子方程式，特别是需要介质条件的。

## 核心方法

1. **化合价升降法**：标氧化态 → 算升降数 → 找最小公倍数 → 定系数 → 配平其他原子。适用于简单氧化还原反应。
2. **半反应法**：拆半反应 → 配原子（O 用 H₂O，H 用 H⁺/OH⁻）→ 配电荷（加 e⁻）→ 合并。适用于复杂反应和介质敏感反应。
3. **观察法**：从化学式最复杂的物质开始，逐步调整系数使原子数相等。适用于非氧化还原反应和简单氧化还原反应。
4. **待定系数法**：设各物质系数为未知数 → 根据原子守恒和电荷守恒列方程 → 解方程组。适用于复杂反应。
5. **分步配平法**：对于多步反应或连串反应，先配平每一步，再合并为总反应。

## 典型例题

### 例题 1：化合价升降法配平

**题目**：用化合价升降法配平以下反应：$\mathrm{Cu} + \mathrm{HNO_3(稀)} \rightarrow \mathrm{Cu(NO_3)_2} + \mathrm{NO}\uparrow + \mathrm{H_2O}$

**解答**：

(1) 标氧化态：Cu: 0 → +2（升 2）；N: +5 → +2（降 3）

(2) 升降总数相等：Cu 升 2 × 3 = 6；N 降 3 × 2 = 6

(3) 定系数：3Cu + 2HNO₃（被还原）→ 3Cu(NO₃)₂ + 2NO

(4) 配平其他原子：
- Cu: 3=3 ✓
- N: 右边 3×2 + 2 = 8 个 N → 左边 8 HNO₃（其中 2 个被还原，6 个提供 NO₃⁻）
- H: 8H → 4H₂O
- O: 8×3=24 = 3×6+2+4=24 ✓

$$3\mathrm{Cu} + 8\mathrm{HNO_3(稀)} \longrightarrow 3\mathrm{Cu(NO_3)_2} + 2\mathrm{NO}\uparrow + 4\mathrm{H_2O}$$

### 例题 2：半反应法配平（碱性介质）

**题目**：配平碱性介质中的反应：$\mathrm{Cr(OH)_3} + \mathrm{ClO^-} \rightarrow \mathrm{CrO_4^{2-}} + \mathrm{Cl^-}$

**解答**：

**氧化半反应**（Cr(OH)₃ → CrO₄²⁻，Cr 从 +3 → +6，失 3e⁻）：
- $\mathrm{Cr(OH)_3} \rightarrow \mathrm{CrO_4^{2-}}$
- O 配平：$\mathrm{Cr(OH)_3} + \mathrm{H_2O} \rightarrow \mathrm{CrO_4^{2-}}$
- H 配平：$\mathrm{Cr(OH)_3} + \mathrm{H_2O} \rightarrow \mathrm{CrO_4^{2-}} + 5\mathrm{H^+}$
- 电荷：$\mathrm{Cr(OH)_3} + \mathrm{H_2O} \rightarrow \mathrm{CrO_4^{2-}} + 5\mathrm{H^+} + 3e^-$
- 碱性转换：加 5OH⁻ 消去 H⁺ → $\mathrm{Cr(OH)_3} + 5\mathrm{OH^-} \rightarrow \mathrm{CrO_4^{2-}} + 4\mathrm{H_2O} + 3e^-$

**还原半反应**（ClO⁻ → Cl⁻，Cl 从 +1 → -1，得 2e⁻）：
- $\mathrm{ClO^-} + \mathrm{H_2O} + 2e^- \rightarrow \mathrm{Cl^-} + 2\mathrm{OH^-}$

**合并**：×2 氧化 + ×3 还原：
$$2\mathrm{Cr(OH)_3} + 3\mathrm{ClO^-} + 4\mathrm{OH^-} \longrightarrow 2\mathrm{CrO_4^{2-}} + 3\mathrm{Cl^-} + 5\mathrm{H_2O}$$

**验证**：Cr: 2=2 ✓；Cl: 3=3 ✓；O: 6+3+4=13 = 8+5=13 ✓；H: 6+4=10 = 10 ✓；电荷：0+(-3)+(-4)=-7 = (-4)+(-3)=-7 ✓

## 易错点

1. **化合价升降法中最小公倍数找错**：Cu 升 2，N 降 3，最小公倍数是 6（不是 2×3=6 以外的数）。对应 3Cu 和 2N。
2. **稀 HNO₃ 与浓 HNO₃ 的还原产物不同**：稀 HNO₃ → NO（+2）；浓 HNO₃ → NO₂（+4）。配平时产物不同，系数也不同。
3. **碱性介质配平后出现 H⁺**：碱性介质的最终方程式中不能有 H⁺，必须用 OH⁻ 和 H₂O 替代。
4. **配平后未检验电荷守恒**：分子方程式检验原子数即可，离子方程式必须同时检验电荷守恒。只检验原子数可能遗漏电荷错误。
