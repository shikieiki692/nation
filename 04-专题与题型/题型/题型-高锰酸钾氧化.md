# 题型 · 高锰酸钾氧化

> **核心支撑页**：[[专题-氧化还原与电化学]]、[[专题-过渡金属（一）钛钒铬锰]]

## 解题思路

高锰酸钾氧化题的核心在于 **介质条件决定还原产物**——同一氧化剂在不同酸碱性下还原产物完全不同。面对这类题型，第一步是判断反应介质：酸性条件下 MnO₄⁻ 还原为 Mn²⁺（无色，5e⁻ 转移，Eθ = +1.51 V，氧化性最强）；中性/弱碱性条件下还原为 MnO₂↓（棕黑色，3e⁻ 转移，Eθ = +0.59 V）；强碱性条件下还原为 MnO₄²⁻（绿色，1e⁻ 转移，Eθ = +0.56 V）。

KMnO₄ 滴定是竞赛中最高频的氧化还原滴定场景。酸性 KMnO₄ 滴定 Fe²⁺ 时，KMnO₄ 本身可作指示剂（紫色褪去即终点）。滴定条件需控制：(1) 必须酸性（通常用 H₂SO₄ 酸化，不能用 HCl——Cl⁻ 会被 MnO₄⁻ 氧化）；(2) 温度控制（室温反应慢，需加热至 70-80°C，但不能沸腾）；(3) 滴定速度（先快后慢，临近终点时逐滴加入）。KMnO₄ 标准溶液不能直接配制（含 MnO₂ 杂质催化分解），需用 Na₂C₂O₄ 基准物质标定。

## 核心方法

1. **介质锁定产物法**：酸性 → Mn²⁺（5e⁻）；中性/弱碱性 → MnO₂↓（3e⁻）；强碱性 → MnO₄²⁻（1e⁻）。先判介质再配平。
2. **滴定条件控制法**：酸性 KMnO₄ 滴定必须用 H₂SO₄ 酸化（不能用 HCl，Cl⁻ 被氧化）；温度 70-80°C；自身指示剂（紫色褪去即终点）。
3. **Nernst 方程修正法**：非标准态时，MnO₄⁻/Mn²⁺ 电对的电势受 [H⁺] 影响显著：$E = E^\theta - \frac{0.0592}{5}\lg\frac{[\mathrm{Mn^{2+}}]}{[\mathrm{MnO_4^-}][\mathrm{H^+}]^8}$。[H⁺] 降低 → 电势下降 → 氧化性减弱。
4. **KMnO₄ 标定法**：用 Na₂C₂O₄ 基准物质标定（2MnO₄⁻ + 5C₂O₄²⁻ + 16H⁺ → 2Mn²⁺ + 10CO₂ + 8H₂O），反应有自催化效应（Mn²⁺ 催化）。
5. **歧化逆推法**：MnO₄²⁻ 在酸性/中性下歧化：3MnO₄²⁻ + 4H⁺ → 2MnO₄⁻ + MnO₂↓ + 2H₂O。此反应解释了为什么 MnO₄²⁻ 仅在强碱中稳定。

## 典型例题

### 例题 1：酸性 KMnO₄ 滴定 H₂C₂O₄

**题目**：用 0.02000 mol/L KMnO₄ 标准溶液滴定 25.00 mL H₂C₂O₄ 溶液，以 H₂SO₄ 酸化，消耗 KMnO₄ 20.00 mL。(1) 写出滴定反应的离子方程式；(2) 计算 H₂C₂O₄ 的浓度。

**解答**：

(1) 酸性条件下 MnO₄⁻ 还原为 Mn²⁺，C₂O₄²⁻ 氧化为 CO₂：
$$2\mathrm{MnO_4^-} + 5\mathrm{C_2O_4^{2-}} + 16\mathrm{H^+} \longrightarrow 2\mathrm{Mn^{2+}} + 10\mathrm{CO_2}\uparrow + 8\mathrm{H_2O}$$

(2) 计量关系：$n(\mathrm{C_2O_4^{2-}}) = \frac{5}{2} n(\mathrm{MnO_4^-})$
$$n(\mathrm{MnO_4^-}) = 0.02000 \times 20.00 \times 10^{-3} = 4.000 \times 10^{-4}\ \mathrm{mol}$$
$$n(\mathrm{C_2O_4^{2-}}) = \frac{5}{2} \times 4.000 \times 10^{-4} = 1.000 \times 10^{-3}\ \mathrm{mol}$$
$$c(\mathrm{H_2C_2O_4}) = \frac{1.000 \times 10^{-3}}{25.00 \times 10^{-3}} = 0.04000\ \mathrm{mol/L}$$

### 例题 2：KMnO₄ 氧化还原产物与电子转移

**题目**：将 0.0100 mol KMnO₄ 分别加入以下三种溶液中，写出各反应的还原半反应，计算转移电子数，并描述现象：(1) 20 mL 1.0 mol/L H₂SO₄；(2) 20 mL 蒸馏水；(3) 20 mL 1.0 mol/L NaOH。

**解答**：

(1) **酸性**：紫色褪去，溶液近无色。
$$\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5e^- \longrightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$$
转移电子：$n_e = 0.0100 \times 5 = 0.0500\ \mathrm{mol}$

(2) **中性**：紫色褪去，出现棕黑色沉淀。
$$\mathrm{MnO_4^-} + 2\mathrm{H_2O} + 3e^- \longrightarrow \mathrm{MnO_2}\downarrow + 4\mathrm{OH^-}$$
转移电子：$n_e = 0.0100 \times 3 = 0.0300\ \mathrm{mol}$

(3) **强碱性**：紫色变为绿色。
$$\mathrm{MnO_4^-} + e^- \longrightarrow \mathrm{MnO_4^{2-}}$$
转移电子：$n_e = 0.0100 \times 1 = 0.0100\ \mathrm{mol}$

## 易错点

1. **酸化试剂选择错误**：酸性 KMnO₄ 滴定不能用 HCl 酸化（Cl⁻ 被氧化为 Cl₂），不能用 HNO₃（本身是氧化剂），只能用稀 H₂SO₄。
2. **电子转移数随介质变化**：同一 KMnO₄ 在不同介质中转移电子数不同（5e⁻/3e⁻/1e⁻），配平时必须先确定介质再确定电子数。
3. **KMnO₄ 不能直接配制标准溶液**：KMnO₄ 含 MnO₂ 杂质会催化自身分解，且见光分解，必须用 Na₂C₂O₄ 基准物质标定后才能使用。
4. **滴定终点判断**：酸性 KMnO₄ 滴定中，KMnO₄ 自身即为指示剂——滴入一滴 KMnO₄ 后溶液出现浅紫色且 30 秒不褪色即为终点。不能另加指示剂。
