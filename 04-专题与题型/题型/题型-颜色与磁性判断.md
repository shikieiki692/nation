# 题型 · 颜色与磁性判断

## 解题思路

颜色与磁性判断是过渡金属化学的核心题型，涉及配合物的颜色来源、磁性判断、电子构型分析等。解题流程如下：

1. **确定中心金属离子**：根据题目信息识别金属元素和氧化态
2. **写出电子构型**：确定d电子数（dⁿ）
3. **判断颜色来源**：d-d跃迁、电荷转移、f-f跃迁
4. **判断磁性类型**：顺磁性（有未成对电子）、抗磁性（无未成对电子）
5. **计算磁矩**：μ = √(n(n+2)) B.M.

**快速判断口诀：**
- **d⁰/d¹⁰无色**：无d-d跃迁（如Sc³⁺、Zn²⁺、Cu⁺）
- **d⁵高自旋浅色**：自旋禁阻（如Mn²⁺极淡粉）
- **其他d¹-d⁹有色**：d-d跃迁允许
- **磁性与未成对电子数相关**：n个未成对电子→μ = √(n(n+2)) B.M.

### 2. 配合物颜色来源

**（1）d-d跃迁**
- **条件**：d¹-d⁹构型
- **颜色**：取决于晶体场分裂能Δ
- **强度**：通常较弱（ε < 100 L·mol⁻¹·cm⁻¹）
- **例子**：[Ti(H₂O)₆]³⁺紫色（d¹，Δ ≈ 20000 cm⁻¹）

**（2）电荷转移跃迁**
- **条件**：金属与配体间电荷转移
- **颜色**：通常很深（ε > 1000 L·mol⁻¹·cm⁻¹）
- **例子**：MnO₄⁻紫色（O→Mn电荷转移）、CrO₄²⁻黄色

**（3）f-f跃迁（镧系/锕系）**
- **条件**：f¹-f¹³构型
- **颜色**：通常很浅（ε < 10 L·mol⁻¹·cm⁻¹）
- **例子**：Nd³⁺淡紫色，Er³⁺粉红色

### 3. 磁性判断方法

**（1）顺磁性与抗磁性**
- **顺磁性**：有未成对电子，被磁场吸引
- **抗磁性**：无未成对电子，被磁场排斥
- **判断依据**：d电子数和配体场强度

**（2）高自旋与低自旋**
- **高自旋**：弱场配体（如H₂O、F⁻），电子优先分占轨道
- **低自旋**：强场配体（如CN⁻、CO），电子优先配对
- **判断依据**：Δ与电子成对能P的比较

**（3）磁矩计算公式**
```
μ = √(n(n+2)) B.M.
```
- n：未成对电子数
- B.M.：玻尔磁子（Bohr magneton）

### 5. 晶体场分裂与颜色

**八面体场**：
- t₂g轨道（dxy, dyz, dxz）：能量较低
- eg轨道（dx²-y², dz²）：能量较高
- 分裂能Δ₀：取决于配体和金属

**四面体场**：
- e轨道（dz², dx²-y²）：能量较低
- t₂轨道（dxy, dyz, dxz）：能量较高
- 分裂能Δₜ ≈ 4/9 Δ₀

**光谱化学序列**（配体场强度）：
```
I⁻ < Br⁻ < S²⁻ < Cl⁻ < N₃⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < py < NH₃ < en < bipy < phen < NO₂⁻ < PPh₃ < CN⁻ < CO
```

## 典型例题

### 例题1：d-d跃迁与颜色（基础）

**题目**：[Ti(H₂O)₆]³⁺ 呈紫色，[Cu(H₂O)₆]²⁺ 呈蓝色。
(1) 写出Ti³⁺和Cu²⁺的电子构型
(2) 解释为什么两者都有颜色
(3) 解释颜色差异的原因

**解题过程**：

**(1) 电子构型**

- **Ti³⁺**：原子序数22，电子构型[Ar]3d²4s²
  - Ti³⁺：失去3个电子→[Ar]3d¹
  - d电子数：1（d¹）

- **Cu²⁺**：原子序数29，电子构型[Ar]3d¹⁰4s¹
  - Cu²⁺：失去2个电子→[Ar]3d⁹
  - d电子数：9（d⁹）

**(2) 颜色来源解释**

- **Ti³⁺（d¹）**：
  - 1个d电子从t₂g跃迁到eg
  - 吸收黄绿光（~20000 cm⁻¹），透过紫色光
  - 颜色：紫色

- **Cu²⁺（d⁹）**：
  - 1个d空穴从eg跃迁到t₂g
  - 吸收橙红光（~12000 cm⁻¹），透过蓝色光
  - 颜色：蓝色

**(3) 颜色差异原因**

- **分裂能不同**：
  - Ti³⁺的Δ₀ ≈ 20000 cm⁻¹
  - Cu²⁺的Δ₀ ≈ 12000 cm⁻¹
- **d电子构型不同**：
  - Ti³⁺：d¹，跃迁类型为t₂g→eg
  - Cu²⁺：d⁹，跃迁类型为eg→t₂g（等价于空穴跃迁）
- **Jahn-Teller效应**：
  - Cu²⁺（d⁹）有显著的Jahn-Teller畸变，导致能级进一步分裂

**反思**：d-d跃迁是配合物颜色的主要来源，颜色取决于分裂能和d电子构型。

### 例题2：磁性判断与电子构型（综合）

**题目**：某金属离子M³⁺在八面体场中，磁矩为3.87 B.M.。
(1) 判断M³⁺的未成对电子数
(2) 写出可能的d电子构型
(3) 判断该离子可能是什么元素

**解题过程**：

**(1) 计算未成对电子数**

- **磁矩公式**：μ = √(n(n+2)) B.M.
- **已知**：μ = 3.87 B.M.
- **解方程**：
  - 3.87² = n(n+2)
  - 14.98 = n² + 2n
  - n² + 2n - 14.98 = 0
  - n ≈ 3（舍去负根）

**(2) 可能的d电子构型**

- **未成对电子数n=3**，可能的情况：
  - **d³**：高自旋，3个未成对电子（如Cr³⁺）
  - **d⁷**：高自旋，3个未成对电子（如Co²⁺）
  - **d⁵**：低自旋，1个未成对电子（不符合）
  - **d⁸**：低自旋，2个未成对电子（不符合）

**(3) 可能的元素**

- **Cr³⁺（d³）**：
  - 颜色：绿色/紫色
  - 常见配合物：[Cr(H₂O)₆]³⁺、[Cr(NH₃)₆]³⁺
  - 符合条件

- **Co²⁺（d⁷）**：
  - 颜色：粉红色
  - 常见配合物：[Co(H₂O)₆]²⁺、[CoCl₄]²⁻
  - 符合条件

**判断方法**：结合颜色信息进一步区分
- 若溶液呈绿色→Cr³⁺
- 若溶液呈粉红色→Co²⁺

**反思**：磁性判断需结合颜色、配体场强度等信息综合分析。

### 例题3：高自旋与低自旋判断（竞赛）

**题目**：[Fe(CN)₆]⁴⁻ 和 [Fe(H₂O)₆]²⁺ 的磁矩分别为0 B.M. 和 4.90 B.M.。
(1) 解释两者磁性差异的原因
(2) 判断两者的高/低自旋状态
(3) 计算[Fe(H₂O)₆]²⁺的未成对电子数

**解题过程**：

**(1) 磁性差异原因**

- **[Fe(CN)₆]⁴⁻**：
  - 配体：CN⁻（强场配体）
  - 分裂能Δ > 电子成对能P
  - 电子优先配对→低自旋
  - 未成对电子数：0
  - 磁矩：0 B.M.（抗磁性）

- **[Fe(H₂O)₆]²⁺**：
  - 配体：H₂O（弱场配体）
  - 分裂能Δ < 电子成对能P
  - 电子优先分占轨道→高自旋
  - 未成对电子数：4
  - 磁矩：4.90 B.M.（顺磁性）

**(2) 高/低自旋判断**

- **Fe²⁺**：d⁶构型
- **八面体场**：
  - 高自旋：t₂g⁴eg²，4个未成对电子
  - 低自旋：t₂g⁶eg⁰，0个未成对电子
- **判断依据**：配体场强度
  - CN⁻：强场→低自旋
  - H₂O：弱场→高自旋

**(3) 未成对电子数计算**

- **磁矩公式**：μ = √(n(n+2)) B.M.
- **已知**：μ = 4.90 B.M.
- **解方程**：
  - 4.90² = n(n+2)
  - 24.01 = n² + 2n
  - n² + 2n - 24.01 = 0
  - n ≈ 4（舍去负根）

**验证**：
- d⁶高自旋：t₂g⁴eg²
- 未成对电子：4个
- 磁矩：√(4×6) = √24 ≈ 4.90 B.M. ✓

**反思**：配体场强度决定高/低自旋，进而影响磁性和颜色。

## 易错点与注意事项

### 1. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|:---|:---|:---|
| **d电子数计算错误** | "Fe³⁺是d⁵" | Fe³⁺是d⁵正确，但Fe²⁺是d⁶ |
| **高/低自旋判断错误** | "H₂O是强场配体" | H₂O是弱场配体，CN⁻是强场配体 |
| **磁矩计算错误** | "μ = √n B.M." | μ = √(n(n+2)) B.M. |
| **颜色来源混淆** | "所有颜色都来自d-d跃迁" | 电荷转移也能产生颜色（如MnO₄⁻） |

### 2. 解题检查清单

- [ ] 是否正确写出d电子构型
- [ ] 是否判断了高/低自旋状态
- [ ] 磁矩计算是否正确
- [ ] 颜色来源是否正确判断（d-d/电荷转移/f-f）
- [ ] 与已知实验现象是否一致

### 3. 高频考点

1. **d电子构型与颜色**：d⁰/d¹⁰无色，d¹-d⁹有色
2. **磁矩计算**：μ = √(n(n+2)) B.M.
3. **高/低自旋判断**：配体场强度与Δ/P比较
4. **Jahn-Teller效应**：Cu²⁺配合物的拉长八面体
5. **光谱化学序列**：配体场强度排序

### 4. 实验验证方法

- **磁性测量**：古埃磁天平、SQUID磁强计
- **颜色测量**：UV-Vis分光光度计
- **结构测定**：X射线单晶衍射
