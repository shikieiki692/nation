# 题型 · 滴定计算

> **状态**: 已填充，待审核

## 解题思路

滴定计算的核心是等当点（Equivalence Point）和滴定突跃（Titration Jump）。等当点是化学计量点，此时加入的滴定剂与被测物质恰好完全反应。滴定突跃是指等当点附近溶液 pH（或电位）的急剧变化，这是选择指示剂的依据。

滴定曲线描述了滴定过程中溶液性质（如 pH、电位）随滴定剂加入量的变化。对于酸碱滴定，曲线分为四个区域：滴定前、滴定开始至等当点前、等当点附近、等当点后。每个区域的计算方法不同，需要根据溶液组成选择合适的公式。

指示剂选择的原则是：指示剂的变色范围应落在滴定突跃范围内。对于强酸强碱滴定，突跃范围约为 pH 4~10；对于弱酸弱碱滴定，突跃范围较小，需选择变色范围较窄的指示剂。多元酸滴定时，若 $K_{a1}/K_{a2} > 10^4$，可分步滴定，每个等当点对应一个滴定突跃。

在滴定计算中，还需考虑滴定误差（Titration Error）。滴定误差定义为：$\text{TE} = \frac{V_e - V_t}{V_t} \times 100\%$，其中 $V_e$ 为等当点体积，$V_t$ 为实际滴定体积。通常要求滴定误差小于 $0.1\%$。

## 核心方法

1. **等当点计算法**：根据化学计量关系计算等当点时溶液的组成和 pH
2. **滴定曲线绘制法**：分区域计算滴定过程中溶液 pH 的变化
3. **指示剂选择法**：根据滴定突跃范围选择合适的指示剂
4. **多元酸分步滴定法**：判断是否满足分步滴定条件（$K_{a1}/K_{a2} > 10^4$），计算各等当点 pH
5. **滴定误差计算法**：利用滴定误差公式计算实验误差，评估滴定准确性

## 典型例题

### 例题1：NaOH 滴定 H₃PO₄ 各等当点 pH

**题目**：用 $0.1000\ \text{mol/L}$ 的 $\text{NaOH}$ 标准溶液滴定 $20.00\ \text{mL}$ 的 $0.1000\ \text{mol/L}\ \text{H}_3\text{PO}_4$ 溶液。已知 $\text{H}_3\text{PO}_4$ 的 $K_{a1} = 7.1 \times 10^{-3}$，$K_{a2} = 6.3 \times 10^{-8}$，$K_{a3} = 4.2 \times 10^{-13}$。计算：
(1) 第一等当点的 pH
(2) 第二等当点的 pH
(3) 说明第三等当点能否准确滴定

**解答**：
(1) 第一等当点：$\text{NaOH}$ 与 $\text{H}_3\text{PO}_4$ 按 $1:1$ 反应，生成 $\text{NaH}_2\text{PO}_4$

此时溶液体积：$V = 20.00 + 20.00 = 40.00\ \text{mL}$

$\text{NaH}_2\text{PO}_4$ 浓度：$c = \frac{0.1000 \times 20.00}{40.00} = 0.05000\ \text{mol/L}$

$\text{NaH}_2\text{PO}_4$ 是两性物质，pH 计算公式为：
$$[\text{H}^+] = \sqrt{\frac{K_{a1}K_{a2}c + K_{a1}K_w}{K_{a1} + c}}$$

由于 $c \gg K_{a1}$，简化为：
$$[\text{H}^+] \approx \sqrt{K_{a1}K_{a2}} = \sqrt{7.1 \times 10^{-3} \times 6.3 \times 10^{-8}} = \sqrt{4.47 \times 10^{-10}} = 2.11 \times 10^{-5}\ \text{mol/L}$$
$$\text{pH} = -\log(2.11 \times 10^{-5}) = 4.68$$

(2) 第二等当点：$\text{NaOH}$ 与 $\text{H}_3\text{PO}_4$ 按 $2:1$ 反应，生成 $\text{Na}_2\text{HPO}_4$

此时溶液体积：$V = 20.00 + 40.00 = 60.00\ \text{mL}$

$\text{Na}_2\text{HPO}_4$ 浓度：$c = \frac{0.1000 \times 20.00}{60.00} = 0.03333\ \text{mol/L}$

$\text{Na}_2\text{HPO}_4$ 也是两性物质，pH 计算公式为：
$$[\text{H}^+] = \sqrt{\frac{K_{a2}K_{a3}c + K_{a2}K_w}{K_{a2} + c}}$$

由于 $c \gg K_{a2}$，简化为：
$$[\text{H}^+] \approx \sqrt{K_{a2}K_{a3}} = \sqrt{6.3 \times 10^{-8} \times 4.2 \times 10^{-13}} = \sqrt{2.65 \times 10^{-20}} = 1.63 \times 10^{-10}\ \text{mol/L}$$
$$\text{pH} = -\log(1.63 \times 10^{-10}) = 9.79$$

(3) 第三等当点：$\text{NaOH}$ 与 $\text{H}_3\text{PO}_4$ 按 $3:1$ 反应，生成 $\text{Na}_3\text{PO}_4$

此时溶液体积：$V = 20.00 + 60.00 = 80.00\ \text{mL}$

$\text{Na}_3\text{PO}_4$ 浓度：$c = \frac{0.1000 \times 20.00}{80.00} = 0.02500\ \text{mol/L}$

$\text{Na}_3\text{PO}_4$ 是弱碱，$K_{b1} = \frac{K_w}{K_{a3}} = \frac{1.0 \times 10^{-14}}{4.2 \times 10^{-13}} = 0.0238$

由于 $K_{b1}$ 较大，不能用近似公式，需解一元二次方程。但更重要的是，$K_{a3} = 4.2 \times 10^{-13}$ 太小，滴定突跃不明显，无法准确滴定第三等当点。

### 例题2：酸碱指示剂选择

**题目**：用 $0.1000\ \text{mol/L}$ 的 $\text{HCl}$ 标准溶液滴定 $20.00\ \text{mL}$ 的 $0.1000\ \text{mol/L}\ \text{Na}_2\text{CO}_3$ 溶液。计算：
(1) 第一等当点的 pH 和应选择的指示剂
(2) 第二等当点的 pH 和应选择的指示剂

**解答**：
(1) 第一等当点：$\text{HCl}$ 与 $\text{Na}_2\text{CO}_3$ 按 $1:1$ 反应，生成 $\text{NaHCO}_3$

此时溶液体积：$V = 20.00 + 20.00 = 40.00\ \text{mL}$

$\text{NaHCO}_3$ 浓度：$c = \frac{0.1000 \times 20.00}{40.00} = 0.05000\ \text{mol/L}$

$\text{NaHCO}_3$ 是两性物质，pH 计算公式为：
$$[\text{H}^+] = \sqrt{K_{a1}K_{a2}} = \sqrt{4.3 \times 10^{-7} \times 5.6 \times 10^{-11}} = \sqrt{2.41 \times 10^{-17}} = 4.91 \times 10^{-9}\ \text{mol/L}$$
$$\text{pH} = 8.31$$

应选择变色范围在碱性区域的指示剂，如酚酞（变色范围 8.2~10.0），但更合适的是百里酚蓝（变色范围 8.0~9.6）。

(2) 第二等当点：$\text{HCl}$ 与 $\text{Na}_2\text{CO}_3$ 按 $2:1$ 反应，生成 $\text{H}_2\text{CO}_3$（饱和 $\text{CO}_2$ 溶液）

此时溶液体积：$V = 20.00 + 40.00 = 60.00\ \text{mL}$

$\text{H}_2\text{CO}_3$ 浓度：$c = \frac{0.1000 \times 20.00}{60.00} = 0.03333\ \text{mol/L}$

饱和 $\text{CO}_2$ 溶液浓度约为 $0.04\ \text{mol/L}$，与计算值接近。$\text{H}_2\text{CO}_3$ 的 $K_{a1} = 4.3 \times 10^{-7}$，由于 $c/K_{a1} = 0.03333/4.3 \times 10^{-7} = 7.75 \times 10^4 > 400$，可用近似公式：
$$[\text{H}^+] = \sqrt{K_{a1}c} = \sqrt{4.3 \times 10^{-7} \times 0.03333} = \sqrt{1.43 \times 10^{-8}} = 1.20 \times 10^{-4}\ \text{mol/L}$$
$$\text{pH} = 3.92$$

应选择变色范围在酸性区域的指示剂，如甲基橙（变色范围 3.1~4.4）或甲基红（变色范围 4.4~6.2）。

## 易错点

1. **等当点体积计算错误**：需根据化学计量关系计算。如 $\text{NaOH}$ 滴定 $\text{H}_3\text{PO}_4$，第一等当点需 $20.00\ \text{mL}$ $\text{NaOH}$，第二等当点需 $40.00\ \text{mL}$，第三等当点需 $60.00\ \text{mL}$。

2. **两性物质 pH 计算公式误用**：对于 $\text{NaH}_2\text{PO}_4$，应使用 $K_{a1}$ 和 $K_{a2}$；对于 $\text{Na}_2\text{HPO}_4$，应使用 $K_{a2}$ 和 $K_{a3}$。不能混淆。

3. **指示剂选择不当**：指示剂的变色范围必须落在滴定突跃范围内。如强酸滴定弱碱（如 $\text{HCl}$ 滴定 $\text{NH}_3$），等当点 pH < 7，应选择甲基橙等酸性指示剂。

4. **多元酸分步滴定条件判断错误**：只有当 $K_{a1}/K_{a2} > 10^4$ 时，才能准确滴定第一等当点。若比值太小，两个突跃会合并，无法分步滴定。

5. **滴定误差计算忽略体积变化**：计算滴定误差时，分母应为实际滴定体积 $V_t$，而不是等当点体积 $V_e$。且体积变化会影响各组分浓度。
