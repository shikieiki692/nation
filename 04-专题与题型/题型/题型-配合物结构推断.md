# 题型 · 配合物结构推断

## 解题思路

配合物结构推断需要综合运用磁矩、颜色、配位数、几何构型等信息。解题的第一步是根据中心金属离子的电子构型和配体类型判断可能的几何构型（八面体、四面体、平面正方形等）。然后利用磁矩数据判断未成对电子数，确定是高自旋还是低自旋构型。

颜色信息可辅助判断配体场强度：强场配体（$\mathrm{CN^-}$、$\mathrm{CO}$、$\mathrm{en}$）产生大的分裂能 $\Delta$，吸收短波长光（蓝移），配合物显互补色；弱场配体（$\mathrm{I^-}$、$\mathrm{Br^-}$、$\mathrm{Cl^-}$）分裂能小，吸收长波长光。

磁矩计算：$\mu = \sqrt{n(n+2)}\;\mathrm{B.M.}$，其中 $n$ 为未成对电子数。实验磁矩与理论值对比可判断自旋态。对于八面体 $\mathrm{d^4-d^7}$ 构型的配合物，高自旋和低自旋的未成对电子数不同，磁矩差异明显。

## 核心方法

1. **磁矩判断法**：由实验磁矩 $\mu$ 计算未成对电子数 $n$，判断高/低自旋态，进而推断配体场强度和电子构型
2. **颜色-配体场强度关联**：吸收波长越短（偏向紫/蓝），配体场越强，分裂能越大。光谱化学序列：$\mathrm{I^- < Br^- < Cl^- < F^- < OH^- < H_2O < NH_3 < en < NO_2^- < CN^-}$
3. **配位数-几何构型推断**：配位数2→直线形，4→四面体或平面正方形，6→八面体。$\mathrm{d^8}$ 离子（$\mathrm{Ni^{2+}}$、$\mathrm{Pd^{2+}}$、$\mathrm{Pt^{2+}}$）易形成平面正方形

## 典型例题

### 例题1：由磁矩和颜色推断配合物结构

**题目**：某配合物的分子式为 $\mathrm{[Co(NH_3)_5Cl]Cl_2}$，实验测得磁矩为 $0\;\mathrm{B.M.}$，水溶液中电导率表明它解离出3个离子。回答以下问题：

（1）中心 $\mathrm{Co^{3+}}$ 的电子构型是什么？

（2）判断该配合物是高自旋还是低自旋？

（3）预测配合物的颜色（给出大致颜色范围）。

（4）若将配体 $\mathrm{Cl^-}$ 替换为 $\mathrm{F^-}$，磁矩和颜色如何变化？

**解答**：

**（1）$\mathrm{Co^{3+}}$ 的电子构型**

$\mathrm{Co}$ 原子序数27，$\mathrm{Co^{3+}}$ 为 $\mathrm{[Ar]3d^6}$ 构型。

**（2）高/低自旋判断**

磁矩 $\mu = 0\;\mathrm{B.M.}$，由 $\mu = \sqrt{n(n+2)}$ 得 $n = 0$，即**无未成对电子**。

$d^6$ 构型无未成对电子，说明为**低自旋八面体配合物**。6个d电子全部成对填充在 $t_{2g}$ 轨道中：$t_{2g}^6 e_g^0$。

**（3）颜色预测**

低自旋 $d^6$ 配合物的电子跃迁为 $t_{2g} \to e_g$（$\Delta_o$ 跃迁）。$\mathrm{NH_3}$ 为中强场配体，$\Delta_o$ 较大，吸收波长在可见光的蓝-紫区（~400-450 nm），配合物显**橙黄色至黄色**。

实际上 $[\mathrm{Co(NH_3)_6}]^{3+}$ 为橙黄色，$\mathrm{[Co(NH_3)_5Cl]^{2+}}$ 因引入一个弱场 $\mathrm{Cl^-}$ 略微降低 $\Delta_o$，颜色偏向**黄色**。

**（4）替换 $\mathrm{Cl^-}$ 为 $\mathrm{F^-}$ 的影响**

按光谱化学序列 $\mathrm{I^- < Br^- < Cl^- < F^- < OH^- < H_2O < NH_3 < ...}$，$\mathrm{F^-}$ 的配体场强度略高于 $\mathrm{Cl^-}$，但两者都是弱场配体。

$\mathrm{[Co(NH_3)_5F]^{2+}}$ 仍为低自旋 $d^6$（因为5个 $\mathrm{NH_3}$ 已足够维持低自旋），磁矩仍为 $0\;\mathrm{B.M.}$。

$\Delta_o$ 略增大（$\mathrm{F^-}$ > $\mathrm{Cl^-}$），吸收蓝移，颜色可能偏向**浅黄色**。

## 易错点

1. **磁矩公式应用错误**：$\mu = \sqrt{n(n+2)}$ 中 $n$ 为未成对电子数，不是d电子总数。$d^6$ 高自旋有4个未成对电子，低自旋为0个
2. **光谱化学序列记忆错误**：常见错误是将 $\mathrm{Cl^-}$ 和 $\mathrm{F^-}$ 的位置记反。正确顺序：$\mathrm{I^- < Br^- < Cl^- < F^- < OH^- < H_2O < NH_3 < en < NO_2^- < CN^- < CO}$
3. **忽略Jahn-Teller效应**：$d^9$ 和高自旋 $d^4$ 的八面体配合物会发生Jahn-Teller畸变，导致八面体拉长或压扁
4. **电导率判断配位数**：配合物在水溶液中的电导率反映解离出的离子数，可用于判断外界离子数，从而确定内界配体数
