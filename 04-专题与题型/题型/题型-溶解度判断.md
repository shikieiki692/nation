# 题型 · 溶解度判断

## 解题思路

溶解度判断题要求根据溶度积（Ksp）、同离子效应、pH 效应、配位效应等因素计算或比较物质的溶解度。这类题是化学竞赛中化学原理部分的高频考点，核心是"Ksp 不变，但溶解度 s 可以变"。

**通用解题流程：**

1. **写出溶解平衡方程和 Ksp 表达式**：固体不写入 Ksp，指数与化学计量系数一致。
2. **判断溶解条件**：纯水？同离子溶液？酸性/碱性溶液？含配体的溶液？
3. **选择计算方法**：
   - 纯水：直接用 Ksp 和类型公式算 s
   - 同离子：s = Ksp/c₀（近似）
   - pH 依赖：联立 Ksp 与 Ka/Kb
   - 配位效应：联立 Ksp 与 K稳
4. **比较不同条件下 s 的大小**：同离子使 s 降低，pH/配位使 s 升高。
5. **检查单位和近似条件**：s ≪ c₀ 时近似才成立。

**一屏判断卡：**

```
溶解度判断题 → 先写 Ksp 表达式
    │
    ├─ 纯水中
    │   ├─ AB 型 → s = √Ksp
    │   ├─ AB₂/A₂B 型 → s = ³√(Ksp/4)
    │   └─ AB₃ 型 → s = ⁴√(Ksp/27)
    │
    ├─ 同离子溶液
    │   └─ s ≈ Ksp/c₀（s ≪ c₀ 时近似）
    │
    ├─ pH 依赖（弱酸盐/氢氧化物）
    │   └─ 联立 Ksp 与 Ka
    │
    └─ 配位效应
        └─ 联立 Ksp 与 K稳
```

**关键区分**：同类型沉淀（如 AgCl vs AgBr，均为 1:1）可直接比 Ksp；异类型（如 AgCl 1:1 vs Ag₂CrO₄ 2:1）必须算 s 再比。

### 2. 影响溶解度的因素

| 因素 | Ksp | s | 机制 | 定量关系 |
|:---|:---:|:---:|:---|:---|
| 温度 ↑ | 变（通常 ↑） | ↑ | 溶解吸热 | van't Hoff 方程 |
| 同离子 | 不变 | **↓** | 平衡左移 | s ≈ Ksp/c₀ |
| 盐效应 | 不变 | 略 ↑ | 离子氛降低有效浓度 | Ksp⁰ = γ₊γ₋Ksp |
| pH ↓（弱酸盐） | 不变 | ↑ | H⁺ 消耗阴离子 | s = √[Ksp(1+[H⁺]/Ka)] |
| 配位 | 不变 | ↑ | 配体消耗金属离子 | 与 K稳 耦合 |

### 3. "完全沉淀"判据

离子浓度降至 < 10⁻⁵ mol/dm³ 时视为"已完全沉淀"。这是分步沉淀和沉淀分离的核心判据。

### 4. 沉淀转化

$$\mathrm{AgCl(s) + I^- \rightleftharpoons AgI(s) + Cl^-}$$
$$K = \frac{K_{sp}(\mathrm{AgCl})}{K_{sp}(\mathrm{AgI})}$$

K > 10⁶ 视为定量转化。

## 典型例题

### 例题 1：同离子效应对溶解度的影响

**题目：** BaSO₄ 在纯水中的溶解度为多少？在 0.10 mol/dm³ Na₂SO₄ 溶液中的溶解度为多少？已知 Ksp(BaSO₄) = 1.1 × 10⁻¹⁰。

**解题过程：**

**(1) 纯水中：**
$$s = \sqrt{K_{sp}} = \sqrt{1.1 \times 10^{-10}} = 1.05 \times 10^{-5}\ \mathrm{mol/dm^3}$$

**(2) 在 0.10 mol/dm³ Na₂SO₄ 中：**
- SO₄²⁻ 的初始浓度 c₀ = 0.10 mol/dm³
- 设溶解度为 s，则 [Ba²⁺] = s，[SO₄²⁻] = 0.10 + s ≈ 0.10（因为 s ≪ 0.10）
- Ksp = s × 0.10 = 1.1 × 10⁻¹⁰
- s = 1.1 × 10⁻⁹ mol/dm³

**对比**：纯水中 s = 1.05 × 10⁻⁵，同离子溶液中 s = 1.1 × 10⁻⁹。溶解度降低了约 10⁴ 倍！

**反思**：同离子效应是降低溶解度最有效的方法。近似条件 s ≪ c₀ 在本题中完全满足（10⁻⁹ ≪ 0.10）。

---

### 例题 2：pH 对溶解度的影响

**题目：** 计算 CaF₂ 在 pH = 3.0 的缓冲溶液中的溶解度。已知 Ksp(CaF₂) = 3.9 × 10⁻¹¹，Ka(HF) = 6.8 × 10⁻⁴。

**解题过程：**

1. CaF₂ 的溶解平衡：CaF₂(s) ⇌ Ca²⁺ + 2F⁻
2. F⁻ 会与 H⁺ 结合：F⁻ + H⁺ ⇌ HF（因为 HF 是弱酸）
3. 在 pH = 3.0 时，[H⁺] = 10⁻³ mol/dm³

4. 联立方程：
   - Ksp = [Ca²⁺][F⁻]² = 3.9 × 10⁻¹¹
   - 设溶解度为 s，则 [Ca²⁺] = s，总 F⁻ 浓度 = 2s
   - [F⁻] = 2s × δF⁻，其中 δF⁻ = Ka/([H⁺] + Ka)
   - δF⁻ = 6.8 × 10⁻⁴/(10⁻³ + 6.8 × 10⁻⁴) = 6.8 × 10⁻⁴/1.68 × 10⁻³ = 0.405

5. Ksp = s × (2s × 0.405)² = s × 0.656s² = 0.656s³
6. s³ = 3.9 × 10⁻¹¹/0.656 = 5.95 × 10⁻¹¹
7. s = ³√(5.95 × 10⁻¹¹) = 3.9 × 10⁻⁴ mol/dm³

**对比**：纯水中 s = ³√(3.9 × 10⁻¹¹/4) = 2.1 × 10⁻⁴ mol/dm³。酸性条件下溶解度增加约 2 倍。

**反思**：pH 对弱酸盐溶解度的影响取决于 Ka 和 [H⁺] 的相对大小。当 [H⁺] ≫ Ka 时，F⁻ 几乎全部质子化 → 溶解度大幅增加。本题中 [H⁺] 和 Ka 同数量级，影响中等。

---

### 例题 3：异类型沉淀的溶解度比较

**题目：** 比较 AgCl 和 Ag₂CrO₄ 在纯水中的溶解度大小。已知 Ksp(AgCl) = 1.8 × 10⁻¹⁰，Ksp(Ag₂CrO₄) = 1.1 × 10⁻¹²。

**解题过程：**

1. **AgCl（1:1 型）**：
   s = √Ksp = √(1.8 × 10⁻¹⁰) = 1.34 × 10⁻⁵ mol/dm³

2. **Ag₂CrO₄（2:1 型）**：
   s = ³√(Ksp/4) = ³√(1.1 × 10⁻¹²/4) = ³√(2.75 × 10⁻¹³) = 6.5 × 10⁻⁵ mol/dm³

3. **比较**：s(AgCl) = 1.34 × 10⁻⁵ < s(Ag₂CrO₄) = 6.5 × 10⁻⁵

**结论**：虽然 Ksp(Ag₂CrO₄) 数值上更小（10⁻¹² < 10⁻¹⁰），但 Ag₂CrO₄ 的溶解度反而更大！这是因为两者是异类型沉淀，不能直接比 Ksp。

**反思**：这是经典的"Ksp 陷阱"——异类型沉淀的 Ksp 数值大小不能直接反映溶解度大小。Mohr 法测定 Cl⁻ 正是利用了这个原理：AgCl 先沉淀完全，过量一滴 Ag⁺ 才与 CrO₄²⁻ 生成砖红色 Ag₂CrO₄ 指示终点。

## 易错点与注意事项

1. **异类型沉淀不能直接比 Ksp**：1:1 型 vs 2:1 型必须算 s 再比。
2. **混合后体积变化不要忘记**：两溶液混合后浓度减半，Q 的计算要用混合后浓度。
3. **同离子效应中 Ksp 不变**：Ksp 只与温度有关，同离子改变的是 s，不是 Ksp。
4. **近似条件 s ≪ c₀ 要验证**：如果算出的 s 与 c₀ 接近（如 > 5%），不能用近似，需要解二次方程。
5. **pH 效应要考虑 Ka 与 [H⁺] 的相对大小**：当 [H⁺] ≫ Ka 时效果显著，当 [H⁺] ≪ Ka 时效果可忽略。
6. **沉淀转化的 K 值是两个 Ksp 的比值**：K > 10⁶ 视为定量转化。
