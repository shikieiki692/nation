# 题型 · 浓度计算

> **来源专题**：[[专题-化学计量与气体]]
> **核心考向**：质量摩尔浓度、摩尔分数、物质的量浓度、密度换算、浓度表示法互转

## 解题思路

浓度计算的核心是**理解不同浓度表示法的定义和适用场景**。竞赛中常用的有五种：质量分数$w$（无量纲）、摩尔分数$x$（无量纲）、质量摩尔浓度$b$（mol/kg溶剂）、物质的量浓度$c$（mol/L溶液）、体积分数$\varphi$。选择哪种表示法取决于题目条件和计算目的。

浓度换算的桥梁公式是$c = 1000\rho w/M$（$\rho$单位g/cm³，$c$单位mol/dm³）。从一种浓度转到另一种，关键是找到"共同量"——通常通过**质量**或**物质的量**建立联系。例如已知质量分数求质量摩尔浓度：先假设取100g溶液，算出溶质和溶剂的质量，再分别转为物质的量和质量（kg）。

稀水溶液中$c \approx b$（因1 kg水$\approx$1 L溶液），但**不能通用**。精确计算时必须用定义式。配制$c$溶液时必须用容量瓶定容，不能将溶质加入固定体积溶剂中——因为体积不具有加和性。

## 核心方法

1. **定义式出发**：$c = n/V$、$b = n_{\text{质}}/m_{\text{剂}}$、$x_i = n_i/\sum n$、$w = m_{\text{质}}/m_{\text{液}}$
2. **桥梁公式**：$c = 1000\rho w/M$，连接$c$、$\rho$、$w$、$M$四个量
3. **假设法换算**：假设取一定量溶液（如100g或1L），分别算各组分量，再转目标浓度
4. **稀溶液近似**：$c \approx b$仅在稀水溶液中成立，精确计算必须用定义式
5. **有效数字**：浓度计算涉及乘除，以有效数字位数最少者为准

## 典型例题

### 例题 1：质量分数→物质的量浓度换算（⭐⭐）

**题目**：浓硫酸的质量分数为98%，密度为1.84 g/cm³，$M(\mathrm{H_2SO_4}) = 98$ g/mol。求其物质的量浓度$c$。

**解答**：

桥梁公式：
$$c = \frac{1000\rho w}{M} = \frac{1000 \times 1.84 \times 0.98}{98} = \mathbf{18.4\ \mathrm{mol \cdot dm^{-3}}}$$

验证：假设取1 L溶液，质量$= 1000 \times 1.84 = 1840$ g，其中$\mathrm{H_2SO_4}$质量$= 1840 \times 0.98 = 1803$ g，$n = 1803/98 = 18.4$ mol ✓

**反思**：这是最基本的浓度换算。记住桥梁公式$c = 1000\rho w/M$可以一步到位。常见错误：$\rho$的单位忘记从g/cm³换算（1000的来源就是1 L = 1000 cm³）。

### 例题 2：混合溶液浓度计算（⭐⭐⭐）

**题目**：将100 mL 0.50 mol/L HCl与200 mL 0.20 mol/L NaOH混合，求混合后溶液中各离子的浓度。

**解答**：

反应前各物质的量：
$$n(\mathrm{HCl}) = 0.50 \times 0.100 = 0.050\ \mathrm{mol}$$
$$n(\mathrm{NaOH}) = 0.20 \times 0.200 = 0.040\ \mathrm{mol}$$

反应：$\mathrm{HCl + NaOH \to NaCl + H_2O}$，NaOH为限量试剂。

反应后：
$$n(\mathrm{H^+}) = 0.050 - 0.040 = 0.010\ \mathrm{mol}\ (\text{过量})$$
$$n(\mathrm{Na^+}) = 0.040\ \mathrm{mol}$$
$$n(\mathrm{Cl^-}) = 0.050\ \mathrm{mol}$$

混合后总体积$\approx 300$ mL = 0.300 L（假设体积可加和）：

$$[\mathrm{H^+}] = \frac{0.010}{0.300} = \mathbf{0.033\ \mathrm{mol \cdot L^{-1}}}$$
$$[\mathrm{Na^+}] = \frac{0.040}{0.300} = \mathbf{0.13\ \mathrm{mol \cdot L^{-1}}}$$
$$[\mathrm{Cl^-}] = \frac{0.050}{0.300} = \mathbf{0.17\ \mathrm{mol \cdot L^{-1}}}$$

验证电荷平衡：$[\mathrm{H^+}] + [\mathrm{Na^+}] = 0.033 + 0.13 = 0.163$，$[\mathrm{Cl^-}] = 0.17$，近似相等（舍入误差）✓

**反思**：混合溶液计算的关键是"先反应、后算浓度"。先判断限量试剂，算出反应后各物种的物质的量，再除以总体积。电荷平衡是最后的校验工具。

## 易错点

1. **桥梁公式中$\rho$单位混淆**：$c = 1000\rho w/M$中$\rho$单位为g/cm³（或g/mL），1000来源于1 L = 1000 cm³
2. **体积不具有加和性**：两种溶液混合后总体积不一定等于两者之和，精确计算需已知混合后密度
3. **$c \approx b$误用**：稀水溶液中近似成立，但浓溶液或非水体系中必须用定义式
4. **配制溶液方法错误**：配制物质的量浓度$c$溶液必须用容量瓶定容至刻度线，不能将溶质加入固定体积溶剂中
