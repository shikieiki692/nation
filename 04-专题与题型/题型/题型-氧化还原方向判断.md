# 题型 · 氧化还原方向判断

> **来源专题**：[[专题-氧化还原与电化学]]
> **核心考向**：标准电极电势$E^\theta$比较法、Nernst方程判断非标态反应方向、浓度/pH对反应方向的影响

## 解题思路

氧化还原方向判断的核心工具是**电极电势**。标准状态下，比较两个半反应的$E^\theta$：$E^\theta$更正的电对中氧化态氧化性更强（更容易被还原），$E^\theta$更负的电对中还原态还原性更强（更容易被氧化）。电池电动势$E^\theta_{\text{池}} = E^\theta_{\text{正}} - E^\theta_{\text{负}}$，$E^\theta_{\text{池}} > 0$对应$\Delta G^\theta < 0$，反应自发。

非标准态必须用**Nernst方程**修正：$E = E^\theta - \frac{0.0592}{n}\lg Q$（25°C）。只要题目出现具体浓度、分压、pH偏离标准态，立刻从$E^\theta$切换到Nernst。pH对含H⁺/OH⁻的半反应影响尤为显著——例如MnO₄⁻在酸性中$E^\theta = 1.51$ V，碱性中$E^\theta = 0.56$ V，氧化能力相差近3倍。

判断反应方向的完整流程：**判介质**（酸性/碱性，决定产物）→ **查$E^\theta$**（标准态）或**用Nernst**（非标态）→ **算$E_{\text{池}}$** → **判断方向**。注意$E^\theta$不能直接加减求总电势，必须通过$\Delta G^\theta = -nFE^\theta$转换。

## 核心方法

1. **$E^\theta$比较法**：$E^\theta_{\text{正}} > E^\theta_{\text{负}}$ → 正向自发（标准态下）
2. **Nernst方程**：$E = E^\theta - \frac{0.0592}{n}\lg Q$，处理非标准态
3. **pH影响**：含H⁺/OH⁻的半反应，pH变化显著改变电极电势
4. **$\Delta G^\theta = -nFE^\theta$**：连接电化学与热力学，$E^\theta_{\text{池}} > 0 \iff \Delta G^\theta < 0$
5. **Latimer图**：$\varphi_{\text{右}} > \varphi_{\text{左}}$则中间态歧化

## 典型例题

### 例题 1：标准电极电势判断反应方向（⭐⭐⭐）

**题目**：利用标准电极电势判断以下反应在标准状态下能否自发进行：
$$\mathrm{Sn^{2+} + 2Fe^{3+} \to Sn^{4+} + 2Fe^{2+}}$$

已知：$E^\theta(\mathrm{Fe^{3+}/Fe^{2+}}) = +0.771\ \mathrm{V}$，$E^\theta(\mathrm{Sn^{4+}/Sn^{2+}}) = +0.154\ \mathrm{V}$

**解答**：

识别半反应：
- 还原（正极）：$\mathrm{Fe^{3+} + e^- \to Fe^{2+}}$，$E^\theta = +0.771\ \mathrm{V}$
- 氧化（负极）：$\mathrm{Sn^{2+} \to Sn^{4+} + 2e^-}$，$E^\theta = +0.154\ \mathrm{V}$

$$E^\theta_{\text{池}} = E^\theta_{\text{正}} - E^\theta_{\text{负}} = 0.771 - 0.154 = +0.617\ \mathrm{V}$$

$E^\theta_{\text{池}} > 0$，反应在标准状态下**自发**进行。

验证：$\Delta G^\theta = -nFE^\theta_{\text{池}} = -2 \times 96485 \times 0.617 = -119.1\ \mathrm{kJ/mol} < 0$ ✓

$$\lg K^\theta = \frac{nE^\theta_{\text{池}}}{0.0592} = \frac{2 \times 0.617}{0.0592} = 20.8$$

$K^\theta \approx 10^{20.8}$，反应几乎完全进行。

**反思**：$E^\theta$不能直接相加——$0.771 + 0.154$是错误的！必须用$E^\theta_{\text{池}} = E^\theta_{\text{正}} - E^\theta_{\text{负}}$，或通过$\Delta G^\theta$转换。

### 例题 2：Nernst方程判断非标态反应方向（⭐⭐⭐⭐）

**题目**：在pH = 5.0的溶液中，$[\mathrm{Mn^{2+}}] = 1.0\ \mathrm{mol/L}$，$[\mathrm{MnO_4^-}] = 1.0\ \mathrm{mol/L}$，判断$\mathrm{MnO_4^-}$能否氧化$\mathrm{Cl^-}$（$[\mathrm{Cl^-}] = 1.0\ \mathrm{mol/L}$）生成$\mathrm{Cl_2}$。

已知：$E^\theta(\mathrm{MnO_4^-/Mn^{2+}}) = 1.51\ \mathrm{V}$（酸性），$E^\theta(\mathrm{Cl_2/Cl^-}) = 1.36\ \mathrm{V}$

**解答**：

标准态下$E^\theta_{\text{池}} = 1.51 - 1.36 = 0.15\ \mathrm{V} > 0$，正向自发。

但pH = 5.0（非标准态），需用Nernst修正MnO₄⁻/Mn²⁺的电势：

还原半反应：$\mathrm{MnO_4^- + 8H^+ + 5e^- \to Mn^{2+} + 4H_2O}$

$$E = E^\theta - \frac{0.0592}{5}\lg\frac{[\mathrm{Mn^{2+}}]}{[\mathrm{MnO_4^-}][\mathrm{H^+}]^8}$$

$$E = 1.51 - \frac{0.0592}{5}\lg\frac{1.0}{1.0 \times (10^{-5})^8}$$

$$= 1.51 - \frac{0.0592}{5} \times (-40) = 1.51 + 0.474 = 1.984\ \mathrm{V}$$

等等——pH升高应使电势降低（H⁺浓度减小不利于MnO₄⁻还原）。重新检查：$Q = [\mathrm{Mn^{2+}}]/([\mathrm{MnO_4^-}][\mathrm{H^+}]^8) = 1/(1 \times 10^{-40}) = 10^{40}$

$$E = 1.51 - \frac{0.0592}{5}\lg(10^{40}) = 1.51 - 0.474 = 1.036\ \mathrm{V}$$

Cl₂/Cl⁻在标准态：$E = 1.36$ V（不受pH影响）

$$E_{\text{池}} = 1.036 - 1.36 = -0.324\ \mathrm{V} < 0$$

反应**不自发**——在pH = 5.0时，MnO₄⁻的氧化能力不足以氧化Cl⁻。

**反思**：pH从0升至5，MnO₄⁻/Mn²⁺的电势从1.51 V降至1.04 V，降低了0.47 V——H⁺浓度对含氧酸根的氧化能力影响巨大。这就是为什么KMnO₄滴定Cl⁻必须在强酸性条件下进行。

## 易错点

1. **$E^\theta$直接相加**：电极电势是强度量，不能直接加减！必须通过$\Delta G^\theta = -nFE^\theta$转换，或用$E^\theta_{\text{池}} = E^\theta_{\text{正}} - E^\theta_{\text{负}}$
2. **Nernst方程中$Q$写反**：还原半反应$E = E^\theta - \frac{0.0592}{n}\lg\frac{[\mathrm{Red}]}{[\mathrm{Ox}][\mathrm{H^+}]^m}$，氧化态在分母
3. **pH对含氧酸根电势的影响**：pH升高使$[\mathrm{H^+}]$降低，含H⁺的半反应电势降低，氧化能力减弱
4. **标准态与非标准态不区分**：题目给浓度/pH时必须用Nernst修正，不能直接用$E^\theta$比较
