# 题型 · 酸碱平衡计算

> **状态**: 已填充，待审核

## 解题思路

酸碱平衡计算的核心是质子条件（Proton Condition）和分布系数（Distribution Coefficient）。质子条件是处理酸碱平衡问题的基本方程，它基于质子守恒：酸失去的质子总数等于碱得到的质子总数。解题时首先需要选择参考水准（通常是溶液中的主要组分），然后写出质子条件。

分布系数 $\alpha$ 描述了多元酸各型体在溶液中的分数。对于二元酸 $\text{H}_2\text{A}$，$\alpha_0 = \frac{[\text{H}_2\text{A}]}{c}$，$\alpha_1 = \frac{[\text{HA}^-]}{c}$，$\alpha_2 = \frac{[\text{A}^{2-}]}{c}$，且 $\alpha_0 + \alpha_1 + \alpha_2 = 1$。分布系数与 pH 的关系可用于计算各型体的浓度。

pH 计算需要根据溶液类型选择合适的方法。强酸强碱溶液直接计算；一元弱酸弱碱溶液可用近似公式 $[\text{H}^+] = \sqrt{K_a c}$（当 $c/K_a > 400$ 时）；多元酸碱溶液需考虑分步电离，通常以第一步为主；两性物质溶液需用精确公式 $[\text{H}^+] = \sqrt{\frac{K_{a1}K_{a2}c + K_{a1}K_w}{K_{a1} + c}}$。

缓冲溶液的 pH 计算常用 Henderson-Hasselbalch 方程：$\text{pH} = \text{p}K_a + \log\frac{[\text{A}^-]}{[\text{HA}]}$。但需注意，该方程仅适用于缓冲对浓度较大且比值在 0.1~10 之间的情况。

## 核心方法

1. **质子条件法**：选择参考水准，根据质子守恒建立方程求解 $[\text{H}^+]$
2. **分布系数法**：利用 $\alpha$ 值计算各型体浓度，适用于多元酸碱体系
3. **近似计算法**：根据 $c/K_a$ 和 $c/K_b$ 判断是否可用简化公式
4. **精确公式法**：使用一元二次方程或迭代法求解，适用于稀溶液或弱酸
5. **缓冲溶液法**：利用 Henderson-Hasselbalch 方程计算缓冲溶液 pH

## 典型例题

### 例题1：多元酸 Na₂CO₃ 溶液 pH 计算

**题目**：计算 $0.10\ \text{mol/L}\ \text{Na}_2\text{CO}_3$ 溶液的 pH。已知 $\text{H}_2\text{CO}_3$ 的 $K_{a1} = 4.3 \times 10^{-7}$，$K_{a2} = 5.6 \times 10^{-11}$。

**解答**：
$\text{Na}_2\text{CO}_3$ 是二元弱碱，在水中分步水解：
$$\text{CO}_3^{2-} + \text{H}_2\text{O} \rightleftharpoons \text{HCO}_3^- + \text{OH}^- \quad K_{b1} = \frac{K_w}{K_{a2}} = \frac{1.0 \times 10^{-14}}{5.6 \times 10^{-11}} = 1.79 \times 10^{-4}$$
$$\text{HCO}_3^- + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3 + \text{OH}^- \quad K_{b2} = \frac{K_w}{K_{a1}} = \frac{1.0 \times 10^{-14}}{4.3 \times 10^{-7}} = 2.33 \times 10^{-8}$$

由于 $K_{b1} \gg K_{b2}$，以第一步水解为主。设 $[\text{OH}^-] = x\ \text{mol/L}$，则：
$$K_{b1} = \frac{[\text{HCO}_3^-][\text{OH}^-]}{[\text{CO}_3^{2-}]} = \frac{x^2}{0.10 - x} \approx \frac{x^2}{0.10}$$
$$x = \sqrt{K_{b1} \times 0.10} = \sqrt{1.79 \times 10^{-4} \times 0.10} = \sqrt{1.79 \times 10^{-5}} = 4.23 \times 10^{-3}\ \text{mol/L}$$

检验近似条件：$\frac{x}{0.10} = 4.23\% < 5\%$，近似成立。

$$\text{pOH} = -\log(4.23 \times 10^{-3}) = 2.37$$
$$\text{pH} = 14.00 - 2.37 = 11.63$$

### 例题2：两性物质溶液 pH 计算

**题目**：计算 $0.10\ \text{mol/L}\ \text{NaHCO}_3$ 溶液的 pH。已知 $\text{H}_2\text{CO}_3$ 的 $K_{a1} = 4.3 \times 10^{-7}$，$K_{a2} = 5.6 \times 10^{-11}$。

**解答**：
$\text{NaHCO}_3$ 是两性物质，既可作为酸电离，也可作为碱水解。

**方法一：质子条件法**
选择 $\text{H}_2\text{O}$ 和 $\text{HCO}_3^-$ 为参考水准，质子条件为：
$$[\text{H}^+] + [\text{H}_2\text{CO}_3] = [\text{CO}_3^{2-}] + [\text{OH}^-]$$

将平衡关系代入：
$$[\text{H}_2\text{CO}_3] = \frac{[\text{H}^+][\text{HCO}_3^-]}{K_{a1}},\quad [\text{CO}_3^{2-}] = \frac{K_{a2}[\text{HCO}_3^-]}{[\text{H}^+]}$$
$$[\text{OH}^-] = \frac{K_w}{[\text{H}^+]}$$

代入质子条件：
$$[\text{H}^+] + \frac{[\text{H}^+][\text{HCO}_3^-]}{K_{a1}} = \frac{K_{a2}[\text{HCO}_3^-]}{[\text{H}^+]} + \frac{K_w}{[\text{H}^+]}$$

由于 $c = 0.10\ \text{mol/L}$ 较大，$[\text{HCO}_3^-] \approx c = 0.10\ \text{mol/L}$，化简得：
$$[\text{H}^+]^2 \approx \frac{K_{a1}(K_{a2}[\text{HCO}_3^-] + K_w)}{K_{a1} + [\text{HCO}_3^-]}$$

因为 $K_{a2}[\text{HCO}_3^-] = 5.6 \times 10^{-11} \times 0.10 = 5.6 \times 10^{-12} \ll K_w = 1.0 \times 10^{-14}$，可忽略，且 $K_{a1} \ll [\text{HCO}_3^-]$，进一步简化：
$$[\text{H}^+] \approx \sqrt{K_{a1}K_{a2}} = \sqrt{4.3 \times 10^{-7} \times 5.6 \times 10^{-11}} = \sqrt{2.41 \times 10^{-17}} = 4.91 \times 10^{-9}\ \text{mol/L}$$

$$\text{pH} = -\log(4.91 \times 10^{-9}) = 8.31$$

**方法二：直接公式法**
对于两性物质 $\text{NaHA}$，pH 近似公式为：
$$\text{pH} = \frac{1}{2}(\text{p}K_{a1} + \text{p}K_{a2}) = \frac{1}{2}(6.37 + 10.25) = 8.31$$

两种方法结果一致。

## 易错点

1. **质子条件写错**：选择参考水准时，应包括溶液中的主要酸碱组分。如 $\text{Na}_2\text{CO}_3$ 溶液，参考水准为 $\text{H}_2\text{O}$ 和 $\text{CO}_3^{2-}$；$\text{NaHCO}_3$ 溶液，参考水准为 $\text{H}_2\text{O}$ 和 $\text{HCO}_3^-$。

2. **多元酸近似条件判断不当**：当 $K_{a1}/K_{a2} > 10^4$ 时，可认为第一步电离为主，忽略第二步。但当两者接近时，需同时考虑两步电离。

3. **两性物质公式误用**：$[\text{H}^+] = \sqrt{K_{a1}K_{a2}}$ 仅适用于 $c \gg K_{a1}$ 且 $K_{a2}c \ll K_w$ 的情况。当浓度较小时，需用精确公式。

4. **分布系数计算错误**：分布系数与 pH 的关系为 $\alpha_0 = \frac{[\text{H}^+]^2}{[\text{H}^+]^2 + K_{a1}[\text{H}^+] + K_{a1}K_{a2}}$，分母中各项次序不能颠倒。

5. **缓冲溶液 pH 计算忽略活度系数**：当缓冲对浓度较大或离子强度较高时，活度系数的影响不可忽略，此时需用活度代替浓度。
