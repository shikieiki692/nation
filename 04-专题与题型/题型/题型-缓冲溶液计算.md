# 题型 · 缓冲溶液计算

> **来源专题**：[[专题-酸碱理论]]
> **核心考向**：缓冲容量、稀释效应、温度影响、Henderson-Hasselbalch方程应用

## 解题思路

缓冲溶液计算的核心工具是**Henderson-Hasselbalch方程**：$\mathrm{pH} = \mathrm{p}K_a + \lg\dfrac{[\mathrm{A}^-]}{[\mathrm{HA}]}$。该方程告诉我们，缓冲溶液的pH由两个因素决定：弱酸的$\mathrm{p}K_a$（固定值）和共轭碱/酸的浓度比（可调节）。当$[\mathrm{A}^-] = [\mathrm{HA}]$时，$\mathrm{pH} = \mathrm{p}K_a$，此时缓冲能力最强。

计算缓冲溶液pH变化时，关键是追踪**加入强酸/强碱后共轭酸碱对物质的量的变化**。加入强碱OH⁻会消耗HA生成A⁻，加入强酸H⁺会消耗A⁻生成HA。先算出反应后各自的物质的量，再代入H-H方程。注意：体积变化通常很小可忽略，但若加入体积较大则需考虑稀释。

缓冲容量（buffer capacity）$\beta$ 反映溶液抵抗pH变化的能力，$\beta = \mathrm{d}c_B/\mathrm{dpH}$。总浓度$c$越大、$[\mathrm{A}^-]/[\mathrm{HA}]$越接近1，缓冲能力越强。有效缓冲范围为$\mathrm{pH} = \mathrm{p}K_a \pm 1$，超出此范围几乎无缓冲能力。

## 核心方法

1. **H-H方程直读pH**：$\mathrm{pH} = \mathrm{p}K_a + \lg([\mathrm{A}^-]/[\mathrm{HA}])$，比值为1时$\mathrm{pH} = \mathrm{p}K_a$
2. **加酸/碱后追踪物质的量**：先算反应消耗/生成量，再代入H-H方程
3. **缓冲容量判断**：$c$越大、$[\mathrm{A}^-]/[\mathrm{HA}]$越接近1，$\beta$越大
4. **有效范围判据**：$\mathrm{pH} = \mathrm{p}K_a \pm 1$，超出范围缓冲能力急剧下降
5. **稀释效应**：稀释不改变浓度比，pH不变（理想情况）；但极端稀释时水的电离不可忽略

## 典型例题

### 例题 1：缓冲溶液pH计算与加碱后pH变化（⭐⭐⭐）

**题目**：某溶液含有0.10 mol/L HAc和0.10 mol/L NaAc（$\mathrm{p}K_a = 4.76$）。
(1) 计算该缓冲溶液的pH。
(2) 向100 mL该溶液中加入1.0 mL 1.0 mol/L NaOH，计算新的pH。
(3) 若改为向100 mL pH = 4.76的HCl溶液中加入等量NaOH，pH变为多少？对比说明缓冲作用。

**解答**：

(1) 直接用H-H方程：
$$\mathrm{pH} = \mathrm{p}K_a + \lg\frac{[\mathrm{Ac}^-]}{[\mathrm{HAc}]} = 4.76 + \lg(1) = \mathbf{4.76}$$

(2) 加入NaOH物质的量：
$$n(\mathrm{OH}^-) = 1.0 \times 10^{-3} \times 1.0 = 1.0 \times 10^{-3}\ \mathrm{mol}$$

反应后：
$$n(\mathrm{HAc}) = 0.10 \times 0.100 - 1.0 \times 10^{-3} = 9.0 \times 10^{-3}\ \mathrm{mol}$$
$$n(\mathrm{Ac}^-) = 0.10 \times 0.100 + 1.0 \times 10^{-3} = 1.1 \times 10^{-2}\ \mathrm{mol}$$

$$\mathrm{pH} = 4.76 + \lg\frac{1.1 \times 10^{-2}}{9.0 \times 10^{-3}} = 4.76 + 0.09 = \mathbf{4.85}$$

pH变化仅 **+0.09**。

(3) HCl溶液中：
$$n(\mathrm{H}^+) = 10^{-4.76} \times 0.100 \approx 1.74 \times 10^{-5}\ \mathrm{mol}$$

加入$1.0 \times 10^{-3}$ mol OH⁻后中和H⁺，剩余$9.83 \times 10^{-4}$ mol OH⁻：
$$[\mathrm{OH}^-] = \frac{9.83 \times 10^{-4}}{0.101} \approx 9.7 \times 10^{-3}\ \mathrm{mol/L}$$

$$\mathrm{pOH} = 2.01,\quad \mathrm{pH} = \mathbf{11.99}$$

pH变化从4.76到11.99，变化了 **+7.23**。

**反思**：缓冲体系pH变化<0.1，非缓冲体系pH变化>7——定量感受缓冲作用的本质：共轭酸碱对的"储备军"使得少量外加酸碱只改变比值而非耗尽一方。

### 例题 2：缓冲溶液稀释效应（⭐⭐⭐）

**题目**：将0.10 mol/L HAc-0.10 mol/L NaAc缓冲溶液稀释10倍（用水稀释至原体积的10倍），求稀释前后的pH。若稀释1000倍呢？

**解答**：

稀释前：
$$\mathrm{pH} = 4.76 + \lg\frac{0.10}{0.10} = 4.76$$

稀释10倍后，$[\mathrm{HAc}] = [\mathrm{Ac}^-] = 0.010$ mol/L：
$$\mathrm{pH} = 4.76 + \lg\frac{0.010}{0.010} = 4.76$$

理想情况下pH不变。但极端稀释需考虑水的电离贡献。稀释1000倍后，$[\mathrm{HAc}] = [\mathrm{Ac}^-] = 1.0 \times 10^{-4}$ mol/L，此时$[\mathrm{H}^+]_{\text{水}} \approx 10^{-7}$ mol/L已不可忽略：

精确计算：设$[\mathrm{H}^+] = x$，由电荷平衡和物料平衡联立：
$$K_a = \frac{x \cdot (1.0 \times 10^{-4} + x)}{1.0 \times 10^{-4} - x} = 1.8 \times 10^{-5}$$

解得$x \approx 1.2 \times 10^{-5}$ mol/L，$\mathrm{pH} \approx 4.92$。

pH偏移约0.16个单位——极端稀释下缓冲能力显著下降。

**反思**：稀释不改变浓度比（理想情况），但极端稀释时水的电离贡献变得显著，缓冲能力大幅下降。竞赛中需注意"有效缓冲浓度"的下限。

## 易错点

1. **H-H方程中比值用错**：$[\mathrm{A}^-]/[\mathrm{HA}]$不是$[\mathrm{HA}]/[\mathrm{A}^-]$，比值位置颠倒会导致pH计算偏差$2\lg([\mathrm{A}^-]/[\mathrm{HA}])$
2. **加酸/碱后忘记追踪物质的量变化**：不能直接用浓度加减，必须先算反应消耗/生成的物质的量
3. **忽略稀释效应**：当加入体积较大时，体积变化影响浓度比，需重新计算
4. **超出有效缓冲范围仍套用H-H方程**：$\mathrm{pH} = \mathrm{p}K_a \pm 1$之外，缓冲能力极弱，H-H方程虽数学上成立但实际意义不大
