# 题型 · 给材料学习

## 解题思路

"给材料学习"是近年化学竞赛中日益重要的题型，题目给出一段文献片段、实验数据、陌生反应体系或催化循环图，要求学生在限定时间内阅读理解、提取信息并回答相关问题。这类题考查的不是已知知识的背诵，而是**化学信息的即时学习与迁移能力**。

**通用解题流程：**

1. **快速浏览全文**：先看整体结构——有几段？有几张图/表？有几道小问？时间分配心中有数。
2. **识别核心信息**：找出新概念、新反应、新术语。不要被细节淹没，先抓"这篇文章在说什么"。
3. **建立逻辑链**：把新信息翻译成已知的化学语言。例如，陌生催化剂 → 画电子计数 → 判断氧化态变化 → 确定催化循环。
4. **逐题作答**：每道小问独立审题，从材料中找证据支撑，不要凭空想象。
5. **交叉验证**：答案是否与材料中的其他信息自洽？是否与已知化学原理矛盾？

**一屏判断卡：**

```
给材料学习题 → 先读题后读文
    │
    ├─ 第一遍：看结构
    │   ├─ 有几张图/表？
    │   ├─ 有几道小问？
    │   └─ 时间分配（~1.5 min/小问）
    │
    ├─ 第二遍：抓核心
    │   ├─ 陌生催化剂/反应 → 画电子计数
    │   ├─ 实验数据 → 找趋势/找异常
    │   └─ 催化循环 → 标每步氧化态变化
    │
    ├─ 第三遍：逐题作答
    │   ├─ 从材料中找证据，不凭空想象
    │   ├─ 用已知化学语言翻译新概念
    │   └─ 答案要自洽
    │
    └─ 最后检查
        └─ 答案是否与材料其他信息矛盾？
```

### 2. 陌生反应的拆解策略

| 线索 | 翻译成化学语言 | 判断 |
|:---|:---|:---|
| 陌生试剂/催化剂 | 先画结构 → 判断电子数/氧化态 | 是否满足 18e 规则？ |
| 陌生产物 | 反推可能的键断裂/形成 | 哪些键断了？哪些键成了？ |
| 异常现象（颜色/磁性/活性） | 回归到 d-d 跃迁/CT 跃迁/配位场 | 配体场强弱？自旋态？ |
| 新术语/新概念 | 从上下文推断含义 | 不要被术语吓住，先理解"它在做什么" |

### 3. 从材料中提取信息的常见模式

| 材料类型 | 信息提取重点 | 常见考法 |
|:---|:---|:---|
| 催化循环图 | 每步的氧化态变化、电子数变化 | 写出某一步的方程式 |
| 反应条件表 | 不同条件下的产物差异 | 判断主产物 |
| 光谱/磁性数据 | 吸收波长/磁矩/化学位移 | 反推结构/氧化态 |
| 晶体结构数据 | 键长/键角/配位数 | 判断构型/键型 |
| 古文/文献材料 | 翻译出现代化学对象 | 写方程式+热力学分析 |

### 4. 与已知知识的桥接

"给材料学习"的最终目标是让学生把新信息用已知工具解释。常见桥接点：

| 新信息可能涉及 | 已知工具/知识点 |
|:---|:---|
| 陌生过渡金属催化 | 18e 规则、氧化加成/还原消除、配位化学 |
| 陌生有机反应 | 前线轨道理论、电子效应、机理推断 |
| 陌生物质的性质 | 配体场理论、d-d 跃迁、磁性判据 |
| 热力学数据 | Born-Haber 循环、Ellingham 图、Latimer 图 |
| 材料/晶体信息 | 晶胞计算、Wade 规则、多酸结构 |

## 典型例题

### 例题 1：陌生催化循环的阅读与理解（基于 2025 初赛第 10 题风格）

**题目背景：** 给出 NHC-硼自由基催化循环图，包含：(1) NHC 与硼烷形成加合物；(2) 光引发产生自由基；(3) 自由基加成到底物上；(4) HAT（氢原子转移）再生自由基；(5) 产物释放与催化剂再生。

**问题 1：** 写出链引发步骤的方程式。

**解题过程：**
1. 从材料中找到"光引发"步骤：NHC-BH₃ 加合物在光照下均裂。
2. NHC-BH₃ → NHC-BH₂· + H·（或等效的自由基生成方式）。
3. 实际上通常是 NHC-BH₃ → NHC-BH₂·（硼自由基），H 原子转移到底物或被碱捕获。
4. 方程式：NHC-BH₃ →hν→ NHC-BH₂· + H·

**问题 2：** 该催化循环中硼的氧化态如何变化？

**解题过程：**
1. NHC-BH₃ 中 B 的氧化态：NHC 是中性 2e 给体，H 是 -1 → B 为 +3。
2. NHC-BH₂· 自由基中：B 上有一个单电子 → B 的形式氧化态仍为 +3（自由基不影响氧化态计算）。
3. 整个催化循环中 B 的氧化态基本不变（自由基催化 vs 氧化还原催化的区别）。

**反思：** 给材料学习题不要求你提前知道 NHC-硼自由基催化——材料会给你足够的信息。关键是把"自由基催化循环"翻译成已知的自由基链式反应语言（引发→传递→终止）。

### 例题 2：陌生反应条件的产物判断

**题目背景：** 给出一个表格，显示同一底物在不同条件下的产物：

| 条件 | 产物 | 选择性 |
|:---|:---|:---|
| LDA, -78°C, THF | 产物 A（较少取代的烯醇锂） | 动力学控制 |
| NaOH, H₂O, 25°C | 产物 B（较多取代的烯醇） | 热力学控制 |
| LDA, 然后 TMSCl | 产物 C（silyl enol ether） | 动力学捕获 |

**问题：** 为什么 LDA 给动力学产物而 NaOH 给热力学产物？

**解题过程：**
1. **LDA（二异丙基氨基锂）**：大位阻强碱，pKa ~36。拔取位阻最小的 α-H（动力学选择性），生成较少取代的烯醇负离子。
2. **NaOH**：小位阻碱，pKa ~15.7。拔取后可以回质子化再拔取，最终达到平衡 → 较多取代的烯醇负离子（热力学更稳定）。
3. **关键差异**：LDA 是不可逆去质子化（pKa 差距大，~20 个 pKa 单位），NaOH 是可逆去质子化（pKa 差距小，~2 个 pKa 单位）。

**反思：** 材料已经告诉了你"动力学控制"和"热力学控制"——你需要做的是用 pKa 和位阻的语言解释为什么。

### 例题 3：古文材料的化学翻译（基于 39 届初赛第 1 题风格）

**题目背景：** 给出一段中国古代炼丹术文献，描述"雄黄（As₄S₄）烧之有烟，凝则成黄白色粉末"。

**问题：** 从现代化学角度解释上述过程，写出主要反应方程式。

**解题过程：**
1. **翻译"雄黄"**：As₄S₄（四硫化四砷，realgar）。
2. **翻译"烧之有烟"**：加热 → As₄S₄ 与空气中 O₂ 反应 → 生成 As₂O₃（白烟/白霜）和 SO₂（有刺激性气味的气体）。
3. **翻译"凝则成黄白色粉末"**：As₂O₃ 蒸气冷凝 → 白色固体（砒霜）。
4. **方程式**：As₄S₄ + 7O₂ → 2As₂O₃ + 4SO₂
5. 如继续氧化或高温：As₂O₃ 可进一步变化。

**结论：** 雄黄煅烧 = As₄S₄ 的氧化反应，产物为 As₂O₃（砒霜）和 SO₂。

**反思：** 化学史材料题的本质是"用化学知识解构古文描述的化学过程"。先做古名→现代化学对象翻译，再写方程式。

## 易错点与注意事项

1. **不要被陌生术语吓住**：材料中出现的新概念通常会在后文给出定义或提示。先读完全文再答题。
2. **不要凭空想象**：答案必须从材料中找到依据或与材料信息自洽。如果材料没提到某个信息，不要自己编。
3. **时间管理**：给材料学习题通常较长，先看有几道小问，分配好时间。不要在一道小问上花太多时间。
4. **催化循环图要跟踪电子数**：16e → 18e → 16e 是过渡金属催化循环的常见模式。
5. **古文翻译要准确**：雄黄 ≠ 雌黄，砒霜 ≠ 雄黄。常见的矿物古名需要积累。
6. **答案要写化学方程式**：不要只写文字描述，竞赛要求写出具体的化学方程式和电子转移。
