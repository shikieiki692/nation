# 题型：元素推断

## 一、题型定位

以元素性质、反应现象、周期位置和化合价信息为线索，倒推未知元素或物种身份。

## 二、核心支撑页
- [[元素推断]]
- 元素周期律和元素周期表
- [[氧化还原反应]]

## 三、常见能力点
- 周期表定位
- 化合价与电子排布联动
- 现象信息转译为结构信息

## 四、解题思路

### Step 1：收集所有线索
- 化学式、化合价、氧化态
- 物理性质（颜色、磁性、熔点等）
- 化学性质（酸碱性、氧化还原性、配位能力等）
- 反应现象（气体、沉淀、颜色变化等）
- 周期位置暗示（"短周期"、"第四周期"等）

### Step 2：建立关联网络
- 将线索按元素周期表位置分组
- 利用同族、同周期元素性质递变规律
- 注意特殊性质（如对角线规则）

### Step 3：假设与验证
- 提出候选元素
- 验证所有线索是否一致
- 排除矛盾假设

### Step 4：确认并写出完整推断
- 写出元素符号和名称
- 解释每条线索的对应关系

## 五、核心方法

### 1. 化合价推断法
- 根据化合物化学式确定元素可能化合价
- 结合周期表位置缩小范围

### 2. 性质特征推断法
- 特殊颜色：Cu²⁺蓝色、Fe³⁺黄色、MnO₄⁻紫色等
- 特殊磁性：顺磁性（未成对电子）、抗磁性
- 特殊反应：焰色反应、沉淀特征等

### 3. 周期律推断法
- 同族元素性质相似性
- 同周期元素性质递变性
- 对角线规则（Li-Mg, Be-Al, B-Si）

### 4. 计量关系推断法
- 利用反应中的计量关系确定元素
- 如：1 mol 某金属与酸反应生成 1 mol H₂

## 六、典型例题

### 例 1
**题目**：A、B、C、D 是短周期元素，原子序数依次增大。A 的最外层电子数是内层电子数的 2 倍，B 的最高价氧化物对应水化物与其氢化物反应生成盐，C 与 A 同主族，D 的最外层电子数等于最内层电子数。推断 A、B、C、D 的元素符号。

**解答**：
- A：最外层电子数是内层电子数的 2 倍 → 只能是 C（碳），电子排布 2,4
- B：最高价氧化物对应水化物与其氢化物反应 → N（氮），HNO₃ + NH₃ → NH₄NO₃
- C：与 A 同主族（ⅣA 族），原子序数大于 B（7） → Si（硅）
- D：最外层电子数等于最内层电子数（2 个） → Mg（镁），电子排布 2,8,2

验证：原子序数 C(6) < N(7) < Si(14) < Mg(12) 不满足"依次增大"，故 D 应为 Ca，但 Ca 不是短周期。重新考虑：D 最外层电子数 = 最内层电子数 = 2，短周期中可能是 Be(4) 或 Mg(12)。若 D 为 Mg，原子序数 Si(14) > Mg(12) 不满足。故可能题目有误或需重新理解。

**更正**：若 D 为 Ca，则原子序数 C(6) < N(7) < Si(14) < Ca(20) 满足"依次增大"，且 Ca 最外层电子数为 2，最内层也是 2。

**答案**：A: C, B: N, C: Si, D: Ca

### 例 2
**题目**：某金属 M 在化合物中只有 +2 和 +3 两种氧化态。其 +2 价离子在水溶液中为浅绿色，+3 价离子在水溶液中为黄色。M 的硫化物不溶于水，但可溶于稀盐酸。推断 M 是什么元素。

**解答**：
- +2 价浅绿色：Fe²⁺ 的特征颜色
- +3 价黄色：Fe³⁺ 的特征颜色
- 硫化物溶于稀盐酸：FeS 溶于稀盐酸，而 CuS、PbS 等不溶

**答案**：M 是 Fe（铁）

## 七、易错点

1. **忽视化合价范围**：元素化合价不能超过最外层电子数（主族）或常见氧化态
2. **混淆相似元素**：如 Al³⁺ 和 Be²⁺ 性质相似（对角线规则）
3. **忽略特殊化合物**：如过氧化物、超氧化物中元素的特殊化合价
4. **周期表位置错误**：混淆主族、副族元素的位置
5. **计算错误**：电子排布、化合价计算时出错
