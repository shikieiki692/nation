# 题型 · 结构推断

## 解题思路

结构推断是化学竞赛中综合性最强的题型之一，要求从实验数据（元素分析、光谱数据、物理性质、反应性等）反推化合物的分子式、结构式和可能的化学键。这类题常见于初赛和决赛，尤其在无机和元素化学部分。

**通用解题流程：**

1. **收集所有线索**：元素组成/分子式 → 物理性质（颜色、熔点、磁性）→ 光谱数据（IR、UV-Vis、NMR）→ 化学反应性。
2. **确定分子式**：通过元素分析、质谱或题目直接给出。
3. **计算不饱和度（Ω）**：Ω = (2C + 2 + N - H) / 2。Ω ≥ 4 通常提示芳环。
4. **缩小结构范围**：结合官能团特征（IR 吸收峰）、对称性（NMR 信号数）、磁性（未成对电子数）逐步排除不可能结构。
5. **写出候选结构并验证**：画出所有可能结构，与数据逐一对比，排除矛盾的。

**一屏判断卡：**

```
结构推断题 → 先收集所有线索
    │
    ├─ 元素/分子式 → 算不饱和度
    │
    ├─ 物理性质
    │   ├─ 颜色 → d-d/CT 跃迁 → 过渡金属？混合价？
    │   ├─ 磁性 → 未成对电子数 → 高/低自旋？
    │   └─ 熔点/挥发性 → 离子型/共价型/分子型？
    │
    ├─ 光谱数据
    │   ├─ IR → 官能团（C=O ~1700, O-H ~3400, N-H ~3300）
    │   ├─ NMR → 对称性 → 等价 H/C 的数目
    │   └─ UV-Vis → d-d 跃迁/CT 跃迁 → 配体场强弱
    │
    └─ 化学反应性
        ├─ 与酸/碱的反应 → 两性？酸性？
        ├─ 氧化还原 → 变价元素？
        └─ 配位反应 → 配位数？配体类型？
```

## 核心方法与知识点

### 1. 不饱和度计算

$$\Omega = \frac{2C + 2 + N - H}{2}$$

| Ω 值 | 可能结构特征 |
---|:---|
| 0 | 饱和链状化合物 |
| 1 | 一个双键或一个环 |
| 4 | 可能含苯环（3 个 π 键 + 1 个环） |
| >4 | 多环/稠环/高不饱和体系 |

### 2. 颜色-结构对应关系（无机）

| 颜色 | 可能来源 | 示例 |
|:---|:---|:---|
| 蓝/绿 | d-d 跃迁（弱场） | [Cu(H₂O)₆]²⁺ 蓝色，[Ni(H₂O)₆]²⁺ 绿色 |
| 黄/橙 | CT 跃迁或 d-d 跃迁 | FeCl₃ 黄棕色（Cl→Fe CT），CrO₄²⁻ 黄色 |
| 紫/红 | d-d 跃迁（较强场） | [Ti(H₂O)₆]³⁺ 紫色，[Co(NH₃)₆]³⁺ 橙黄色 |
| 黑色 | 混合价或窄带隙 | Fe₃O₄（Fe²⁺Fe³⁺₂O₄），MnO₂ |
| 无色 | d⁰ 或 d¹⁰ | Zn²⁺, Sc³⁺, Ti⁴⁺ 的配合物 |

### 3. 磁性判据

$$\mu_{SO} = \sqrt{n(n+2)}\ \mu_B$$

| μ (μ_B) | n（未成对电子） | 可能组态 |
|:---|:---|:---|
| 0 | 0 | d⁶ 低自旋（如 [Fe(CN)₆]⁴⁻），d⁸ 平面四方 |
| 1.73 | 1 | d⁵ 低自旋（如 [Fe(CN)₆]³⁻） |
| 3.87 | 2 | d⁸ 八面体高自旋，d⁷ 低自旋 |
| 5.92 | 5 | d⁵ 高自旋（如 [FeF₆]³⁻） |

### 4. 常见结构推断线索

| 线索类型 | 推断方向 | 检查点 |
|:---|:---|:---|
| 分子式 + 不饱和度 | Ω = 4 → 芳环？Ω = 0 → 饱和？ | 注意杂原子对 Ω 的贡献 |
| 红外光谱 | C=O (~1700 cm⁻¹), O-H (~3400), N-H (~3300), CN (~2200) | 注意峰的宽窄和位置 |
| NMR 信号数 | 信号数 = 等价 H/C 的种类数 | 注意对称元素 |
| 磁矩 | 反磁性 → 全配对；顺磁性 → 未成对电子 | 注意旋轨耦合对重原子的影响 |
| 摩尔电导率 | 高电导 → 离子型；低电导 → 共价型 | 区分内外界离子 |
| 化学反应性 | 两性 → Al/Zn/Cr 等；变价 → Fe/Cu/Mn 等 | 结合颜色交叉验证 |

### 5. 配合物结构推断四步法

| 步骤 | 操作 | 依据 |
|:---|:---|:---|
| Step 1 | 确定中心离子氧化态和 d 电子数 | 电荷平衡、元素分析 |
| Step 2 | 判断配位数和构型 | 配体种类和数目 |
| Step 3 | 确定高/低自旋 → 磁性 | 光谱化学序列 |
| Step 4 | 画出结构 → 检查异构体 | 几何异构/光学异构 |

## 典型例题

### 例题 1：从元素分析和磁性推断配合物结构

**题目：** 某配合物的元素分析结果为：Co 22.04%, N 31.19%, H 6.71%, Cl 40.06%。该配合物为反磁性物质。写出其分子式和结构。

**解题过程：**

1. **求实验式**：
   - Co: 22.04/58.93 = 0.374 mmol
   - N: 31.19/14.01 = 2.226 mmol
   - H: 6.71/1.008 = 6.657 mmol
   - Cl: 40.06/35.45 = 1.130 mmol
   - 比例 Co:N:H:Cl ≈ 1:6:18:3 → Co(NH₃)₆Cl₃

2. **验证式量**：Co(NH₃)₆Cl₃ = 58.93 + 6×17.03 + 3×35.45 = 267.48
   - Co% = 58.93/267.48 = 22.03% ✓
   - N% = 84.06/267.48 = 31.42% ✓

3. **判断氧化态和磁性**：
   - NH₃ 为中性配体，Cl⁻ × 3 = -3 → Co 为 +3
   - Co³⁺ = d⁶。配合物反磁性 → 未成对电子数 n = 0 → 低自旋
   - NH₃ 是中强场配体 → 对 Co³⁺ 可以使 d⁶ 低自旋

4. **结构**：[Co(NH₃)₆]³⁺ 为正八面体，t₂g⁶ eg⁰ → 全配对 → 反磁性 ✓

**结论：** 分子式 Co(NH₃)₆Cl₃，结构为 [Co(NH₃)₆]³⁺(Cl⁻)₃。

**反思：** 反磁性 + Co(III) + NH₃ 配体 → 几乎可以确定是低自旋 d⁶ 八面体配合物。磁性数据是结构推断中最有力的约束之一。

### 例题 2：从 IR 和 NMR 推断有机物结构

**题目：** 分子式 C₄H₈O₂。IR：1740 cm⁻¹（强），1240 cm⁻¹（强）。¹H NMR：δ 2.05 (s, 3H)，δ 4.12 (q, 2H)，δ 1.26 (t, 3H)。推断结构。

**解题过程：**

1. **不饱和度**：Ω = (2×4 + 2 - 8)/2 = 1 → 一个双键或一个环。

2. **IR 分析**：
   - 1740 cm⁻¹（强）→ C=O 伸缩振动，酯羰基（~1735-1750）
   - 1240 cm⁻¹（强）→ C-O 伸缩振动，进一步支持酯

3. **NMR 分析**：
   - δ 2.05 (s, 3H) → CH₃-C=O（甲基酮或乙酸酯的甲基）
   - δ 4.12 (q, 2H) → -O-CH₂-CH₃（四重峰 = 与 CH₃ 相邻）
   - δ 1.26 (t, 3H) → -CH₂-CH₃（三重峰 = 与 CH₂ 相邻）

4. **拼接**：CH₃-CO-O-CH₂-CH₃ = 乙酸乙酯

**验证**：
- 分子式 C₄H₈O₂ ✓
- IR：酯 C=O + C-O ✓
- NMR：三种等价 H（3:2:3），耦合模式正确 ✓

**结论：** 乙酸乙酯（CH₃COOCH₂CH₃）。

**反思：** 有机结构推断中，IR 给官能团，NMR 给骨架和对称性。两者结合可以快速锁定结构。注意 q 和 t 的耦合关系——q(2H) + t(3H) 是典型的 -OCH₂CH₃ 片段。

---

### 例题 3：从颜色和反应性推断未知物

**题目：** 某绿色晶体溶于水得绿色溶液。加入 NaOH 得灰绿色沉淀，继续加 NaOH 沉淀溶解得亮绿色溶液。加入 H₂O₂ 后溶液变黄色。推断该晶体的可能组成。

**解题过程：**

1. **绿色晶体 + 绿色溶液**：过渡金属离子 → Co²⁺（粉红）? Ni²⁺（绿）? Cr³⁺（绿/紫）?
2. **加 NaOH → 灰绿色沉淀 → 溶于过量 NaOH**：两性氢氧化物 → 可能是 Cr(OH)₃ 或 Al(OH)₃。但 Al(OH)₃ 无色，且无后续氧化反应 → 排除。
3. **Cr(OH)₃ 溶于过量 NaOH**：Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻（亮绿色溶液）✓
4. **加 H₂O₂ → 黄色**：[Cr(OH)₄]⁻ 被 H₂O₂ 氧化 → CrO₄²⁻（黄色）✓
5. **综合**：Cr³⁺ 盐 → 绿色；Cr(OH)₃ 两性 → 溶于过量碱；Cr(III) → Cr(VI) 被 H₂O₂ 氧化。

**结论：** 该晶体含 Cr³⁺，可能是 CrCl₃·6H₂O 或 Cr₂(SO₄)₃·18H₂O。

**反思：** 颜色 + 两性 + 氧化还原 → 这三重约束几乎可以唯一确定是铬(III)盐。元素推断题中，"绿色 + 两性 + 可被 H₂O₂ 氧化为黄色"是 Cr³⁺ 的指纹特征。

## 易错点与注意事项

1. **不饱和度不要忘记杂原子的贡献**：N 加 1，O 和 S 不加。
2. **磁矩计算注意旋轨耦合**：对于重原子（如 Co²⁺、Fe²⁺），旋轨耦合会使实测磁矩偏离纯自旋值。竞赛中通常只需用纯自旋公式。
3. **IR 峰位不要死记**：理解官能团特征频率的规律（双键区 ~1500-1800，单键区 ~500-1500）比死记具体数值更可靠。
4. **NMR 的 q/t/s 是耦合模式**：s = singlet（单峰），d = doublet（双峰），t = triplet（三重峰），q = quartet（四重峰）。峰分裂由相邻 H 的数目决定（n+1 规则）。
5. **配合物的氧化态要用电荷平衡算**：不能只看元素组成，要扣除配体的电荷。
6. **颜色推断要区分 d-d 和 CT 跃迁**：d-d 跃迁通常较弱（ε ~1-100），CT 跃迁通常较强（ε ~1000-50000）。
