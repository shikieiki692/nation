# 题型 · 相图分析

> **来源专题**：[[专题-溶液与相图]]
> **核心考向**：单组分/二组分相图读图、杠杆规则、相律应用、蒸馏分析

## 解题思路

相图分析的核心工具是**相律**$F = C - P + 2$（$C$为独立组分数，$P$为相数，$F$为自由度）。单组分系统$C=1$，$F = 3 - P$；双组分系统$C=2$，$F = 4 - P$。三相点处$F=0$（温度、压力唯一确定），临界点处$F=0$（液气界面消失）。

读图三步法：**定位**（在相图上找到体系坐标）→ **判相**（点落在哪个区就是几相共存）→ **定量**（两相区用杠杆规则）。杠杆规则$n_\alpha \cdot l_\alpha = n_\beta \cdot l_\beta$中，$l$是相点到边界的距离——离哪相远，哪相就少。

二组分气-液平衡相图中，泡点线（液相线）和露点线（气相线）之间的区域是气液两相共存区。恒沸点处气相组成等于液相组成，普通蒸馏无法分离。精馏利用多级蒸馏逐步富集更挥发组分。

## 核心方法

1. **相律计算**：$F = C - P + 2$，验证读图结果的自洽性
2. **读图三步法**：定位→判相→定量（杠杆规则）
3. **杠杆规则**：$n_\alpha \cdot l_\alpha = n_\beta \cdot l_\beta$，求两相物质的量比
4. **恒沸判断**：气-液平衡图中泡点线与露点线相切 → 恒沸组成，不能普通蒸馏分离
5. **相图类型识别**：单组分p-T图、二组分T-x图、二组分p-x图各有不同特征

## 典型例题

### 例题 1：水的相图分析与相律应用（⭐⭐）

**题目**：在水的三相点处，体系的自由度是多少？在标准大气压下将冰从-10°C加热到150°C，描述经历的相变过程。

**解答**：

三相点：$C = 1$（单组分），$P = 3$（固+液+气共存）
$$F = C - P + 2 = 1 - 3 + 2 = \mathbf{0}$$

自由度为零：三相点的温度和压力唯一确定（273.16 K, 611 Pa），不能独立改变。

101.325 kPa下加热路径：
- $-10^\circ\mathrm{C}$：冰（固相，单相区，$F=2$）
- $0^\circ\mathrm{C}$：冰-水平衡（固+液两相，$F=1$，相变吸热）
- $0 \sim 100^\circ\mathrm{C}$：液态水（单相区，$F=2$）
- $100^\circ\mathrm{C}$：水-水蒸气平衡（液+气两相，$F=1$，沸腾）
- $>100^\circ\mathrm{C}$：水蒸气（气相区，$F=2$）

**反思**：注意三相点（273.16 K, 611 Pa）与正常凝固点（273.15 K, 101.325 kPa）的区别——压力差了两个数量级，温度仅差0.01 K。

### 例题 2：二组分相图与杠杆规则（⭐⭐⭐）

**题目**：苯-甲苯二组分体系在80°C时的气-液平衡数据如下：$x_A(\text{苯}) = 0.400$（液相），$y_A = 0.694$（气相）。若体系总组成为$z_A = 0.500$，处于80°C两相区，求气相与液相的物质的量之比。

**解答**：

在气-液两相区中，由杠杆规则：
$$n_{\text{液}} \cdot (z_A - x_A) = n_{\text{气}} \cdot (y_A - z_A)$$

$$\frac{n_{\text{气}}}{n_{\text{液}}} = \frac{z_A - x_A}{y_A - z_A} = \frac{0.500 - 0.400}{0.694 - 0.500} = \frac{0.100}{0.194} = \mathbf{0.515}$$

即气相物质的量约为液相的51.5%。

验证：$n_{\text{气}} \cdot y_A + n_{\text{液}} \cdot x_A = (n_{\text{气}} + n_{\text{液}}) \cdot z_A$
$$0.515 \times 0.694 + 1.000 \times 0.400 = 0.357 + 0.400 = 0.757$$
$$1.515 \times 0.500 = 0.758$$ ✓（舍入误差范围内）

**反思**：杠杆规则的直觉是"离哪相远，哪相就少"。本题中$z_A = 0.500$更接近液相组成$x_A = 0.400$，所以液相更多。这是蒸馏塔设计的理论基础。

## 易错点

1. **三相点与正常凝固点混淆**：三相点（611 Pa, 0.01°C）是固-液-气三相平衡的唯一状态点，正常凝固点（101.325 kPa, 0°C）只是固-液平衡线上的一个点
2. **杠杆规则距离量度方向**：$l$是相点到总组成点的距离，不是到坐标轴的距离
3. **恒沸点误认为可分离**：恒沸组成处气相和液相组成相同，普通蒸馏无法分离，需要特殊方法（如萃取蒸馏）
4. **相律中$P$的计数**：界面相通常不计入$P$，只计体相
