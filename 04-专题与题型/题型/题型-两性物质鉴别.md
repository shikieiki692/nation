# 题型 · 两性物质鉴别

## 解题思路

### 核心判断依据
- **两性物质**：既能与酸反应又能与碱反应的物质
- 常见两性物质：两性金属（Al、Zn、Sn、Pb、Cr）、两性氧化物、两性氢氧化物
- 鉴别关键：在酸中和碱中的溶解行为

### 常见出题角度
1. 判断某物质是否为两性
2. 鉴别不同两性金属离子（Al³⁺、Zn²⁺、Cr³⁺）
3. 利用两性进行分离和提纯
4. 解释两性的成因（离子势 φ）
5. 设计实验鉴别未知溶液

## 核心方法与知识点

### 关键知识点

**常见两性物质**：

| 物质 | 两性表现 | 与酸反应 | 与碱反应 | 特殊性质 |
|:---|:---|:---|:---|:---|
| Al(OH)₃ | 两性 | Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O | Al(OH)₃ + OH⁻ → [Al(OH)₄]⁻ | 不溶于氨水 |
| Zn(OH)₂ | 两性 | Zn(OH)₂ + 2H⁺ → Zn²⁺ + 2H₂O | Zn(OH)₂ + 2OH⁻ → [Zn(OH)₄]²⁻ | 溶于氨水 |
| Cr(OH)₃ | 两性 | Cr(OH)₃ + 3H⁺ → Cr³⁺ + 3H₂O | Cr(OH)₃ + OH⁻ → [Cr(OH)₄]⁻ | 灰绿色沉淀 |
| Be(OH)₂ | 两性 | Be(OH)₂ + 2H⁺ → Be²⁺ + 2H₂O | Be(OH)₂ + 2OH⁻ → [Be(OH)₄]²⁻ | 对角线规则 |
| Sn(OH)₂ | 两性 | Sn(OH)₂ + 2H⁺ → Sn²⁺ + 2H₂O | Sn(OH)₂ + 2OH⁻ → [Sn(OH)₃]⁻ | — |
| Pb(OH)₂ | 两性 | Pb(OH)₂ + 2H⁺ → Pb²⁺ + 2H₂O | Pb(OH)₂ + 2OH⁻ → [Pb(OH)₃]⁻ | — |

**离子势 φ 判断两性**：
- φ = Z/r（Z 为离子电荷，r 为离子半径）
- φ < 0.22 → 碱性
- 0.22 ≤ φ ≤ 0.32 → **两性**
- φ > 0.32 → 酸性

**两性金属离子鉴别方法**：

| 离子 | 与 NaOH 反应 | 与 NH₃ 反应 | 颜色 | 其他特征 |
|:---|:---|:---|:---|:---|
| Al³⁺ | 白色沉淀，溶于过量 NaOH | 白色沉淀，**不溶于过量氨水** | 无色 | 焰色无色 |
| Zn²⁺ | 白色沉淀，溶于过量 NaOH | 白色沉淀，**溶于过量氨水** | 无色 | 焰色无色 |
| Cr³⁺ | 灰绿色沉淀，溶于过量 NaOH | 灰绿色沉淀，不溶于氨水 | 绿色 | 溶液绿色 |
| Be²⁺ | 白色沉淀，溶于过量 NaOH | 白色沉淀，不溶于氨水 | 无色 | 焰色无色（与 Al 区分困难） |

### 解题步骤框架

**步骤 1**：判断是否为两性物质
- 加酸：是否溶解？
- 加碱：是否溶解？
- 两者均溶解 → 两性物质

**步骤 2**：根据颜色初步判断
- 白色沉淀 → Al(OH)₃、Zn(OH)₂、Be(OH)₂
- 灰绿色沉淀 → Cr(OH)₃
- 其他颜色 → 可能不是两性氢氧化物

**步骤 3**：利用氨水进一步区分
- 加过量氨水：
  - 溶解 → Zn²⁺（形成 [Zn(NH₃)₄]²⁺）
  - 不溶解 → Al³⁺、Be²⁺、Cr³⁺

**步骤 4**：结合其他特征确认
- 焰色反应、氧化还原性等

## 典型例题

### 例题 1：两性物质判断

**题目**：判断下列物质是否为两性物质，并写出相关反应方程式：
(1) Al₂O₃
(2) MgO
(3) ZnO
(4) SiO₂

**解答**：

**(1) Al₂O₃**
- 与酸反应：Al₂O₃ + 6H⁺ → 2Al³⁺ + 3H₂O
- 与碱反应：Al₂O₃ + 2OH⁻ + 3H₂O → 2[Al(OH)₄]⁻
- **是两性物质**

**(2) MgO**
- 与酸反应：MgO + 2H⁺ → Mg²⁺ + H₂O
- 与碱反应：不反应
- **不是两性物质**（碱性氧化物）

**(3) ZnO**
- 与酸反应：ZnO + 2H⁺ → Zn²⁺ + H₂O
- 与碱反应：ZnO + 2OH⁻ + H₂O → [Zn(OH)₄]²⁻
- **是两性物质**

**(4) SiO₂**
- 与酸反应：不反应（HF 除外）
- 与碱反应：SiO₂ + 2OH⁻ → SiO₃²⁻ + H₂O
- **不是两性物质**（酸性氧化物）

### 例题 2：两性金属离子鉴别

**题目**：设计实验鉴别下列三种无色溶液：AlCl₃、ZnCl₂、MgCl₂

**解答**：

**分析思路**：
- 三者均为无色溶液
- Al³⁺ 和 Zn²⁺ 的氢氧化物两性，Mg²⁺ 的氢氧化物碱性
- 利用两性差异进行鉴别

**实验方案**：

| 步骤 | 操作 | AlCl₃ 现象 | ZnCl₂ 现象 | MgCl₂ 现象 |
|:---:|:---|:---|:---|:---|
| 1 | 加入过量 NaOH 溶液 | 白色沉淀溶解 | 白色沉淀溶解 | 白色沉淀不溶解 |
| 2 | 取步骤 1 的沉淀，加过量氨水 | 沉淀不溶解 | 沉淀溶解 | — |
| 3 | 焰色反应 | 无色 | 无色 | 砖红色（Ca²⁺干扰时）或无色 |

**鉴别结论**：
- 加 NaOH 沉淀溶解 → Al³⁺ 或 Zn²⁺
- 加氨水沉淀溶解 → Zn²⁺
- 加氨水沉淀不溶解 → Al³⁺
- 加 NaOH 沉淀不溶解 → Mg²⁺

**反应方程式**：
- Al³⁺ + 3OH⁻ → Al(OH)₃↓
- Al(OH)₃ + OH⁻ → [Al(OH)₄]⁻
- Zn²⁺ + 2OH⁻ → Zn(OH)₂↓
- Zn(OH)₂ + 2OH⁻ → [Zn(OH)₄]²⁻
- Zn(OH)₂ + 4NH₃ → [Zn(NH₃)₄]²⁺ + 2OH⁻

### 例题 3：两性物质分离

**题目**：设计实验分离 Al³⁺ 和 Mg²⁺ 的混合溶液。

**解答**：

**分离原理**：
- Al(OH)₃ 两性，溶于过量 NaOH
- Mg(OH)₂ 碱性，不溶于过量 NaOH

**分离方案**：

| 步骤 | 操作 | 产物 | 说明 |
|:---:|:---|:---|:---|
| 1 | 加入过量 NaOH 溶液 | Al(OH)₃ 溶解，Mg(OH)₂ 沉淀 | 分离两性与碱性 |
| 2 | 过滤 | 滤液含 [Al(OH)₄]⁻，滤渣为 Mg(OH)₂ | — |
| 3 | 滤液加酸 | Al(OH)₃↓，继续加酸得 Al³⁺ | 回收 Al³⁺ |
| 4 | 滤渣加酸 | Mg²⁺ | 回收 Mg²⁺ |

**反应方程式**：
- Al³⁺ + 4OH⁻ → [Al(OH)₄]⁻
- Mg²⁺ + 2OH⁻ → Mg(OH)₂↓
- [Al(OH)₄]⁻ + H⁺ → Al(OH)₃↓ + H₂O
- Mg(OH)₂ + 2H⁺ → Mg²⁺ + 2H₂O

## 易错点与注意事项

### 高频错误

1. **混淆两性和碱性**
   - 错误：Mg(OH)₂ 是两性氢氧化物
   - 正确：Mg(OH)₂ 是**碱性**氢氧化物，不溶于过量 NaOH

2. **忽略氨水对 Zn²⁺ 的溶解**
   - 错误：Al(OH)₃ 和 Zn(OH)₂ 都不溶于氨水
   - 正确：Zn(OH)₂ **溶于过量氨水**，Al(OH)₃ 不溶

3. **Cr(OH)₃ 颜色判断错误**
   - 错误：Cr(OH)₃ 是白色沉淀
   - 正确：Cr(OH)₃ 是**灰绿色**沉淀

4. **两性氧化物与两性氢氧化物混淆**
   - 错误：Al₂O₃ 和 Al(OH)₃ 性质完全相同
   - 正确：两者都两性，但反应活性和溶解度不同

5. **Be(OH)₂ 与 Al(OH)₃ 区分困难**
   - 错误：用焰色反应区分 Be 和 Al
   - 正确：两者焰色均为无色，需用其他方法（如 Be 有毒、BeO 熔点极高）

### 检查清单
- [ ] 判断物质是否两性（酸碱均溶解）
- [ ] 观察沉淀颜色（白色/灰绿色等）
- [ ] 利用氨水区分 Al³⁺ 和 Zn²⁺
- [ ] 考虑离子势 φ 判断酸碱性
- [ ] 设计分离方案时考虑回收
