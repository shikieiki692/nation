# 题型：机理推断

## 一、题型定位

根据底物、条件、中间体与产物信息，重建反应历程并解释选择性来源。

## 二、核心支撑页
- [[反应机理]]
- [[亲核取代]]
- [[消除反应]]

## 三、常见能力点
- 识别关键中间体
- 比较竞争机理
- 解释区域与立体选择性

## 四、解题思路

### Step 1：收集反应信息
- 底物结构（官能团、立体化学）
- 反应条件（试剂、溶剂、温度、催化剂）
- 产物结构（区域选择性、立体选择性）
- 动力学数据（如速率方程）

### Step 2：识别可能的机理类型
- 亲核取代（SN1/SN2）
- 消除反应（E1/E2）
- 亲电加成/消除
- 自由基反应
- 协同反应（如 Diels-Alder）
- 重排反应

### Step 3：提出可能的机理路径
- 画出所有合理的中间体
- 考虑电子流向（箭头推动）
- 评估每步的合理性

### Step 4：用实验证据验证
- 同位素标记实验
- 立体化学结果
- 动力学级数
- 中间体捕获实验

## 五、核心方法

### 1. 箭头推动法
- 用弯箭头表示电子对移动
- 从富电子区（孤对电子、π键）到缺电子区
- 保持电荷守恒

### 2. 中间体稳定性分析
- 碳正离子稳定性：3° > 2° > 1° > 甲基
- 自由基稳定性：3° > 2° > 1° > 甲基
- 碳负离子稳定性：与碳正离子相反
- 离去基团能力：I⁻ > Br⁻ > Cl⁻ > F⁻

### 3. 立体化学分析
- SN2：构型翻转（Walden 翻转）
- SN1：外消旋化（平面碳正离子）
- E2：反式共平面消除
- 周环反应：轨道对称性守恒

### 4. 动力学分析
- 一级动力学：单分子过程（SN1/E1）
- 二级动力学：双分子过程（SN2/E2）
- 酸碱催化：pH 依赖性

## 六、典型例题

### 例 1
**题目**：叔丁基溴在乙醇中加热，生成乙基叔丁基醚和异丁烯。请写出可能的反应机理。

**解答**：
**SN1 机理**（生成醚）：
1. (CH₃)₃C-Br → (CH₃)₃C⁺ + Br⁻（慢，决速步）
2. (CH₃)₃C⁺ + EtOH → (CH₃)₃C-O⁺(H)Et（快）
3. (CH₃)₃C-O⁺(H)Et → (CH₃)₃C-OEt + H⁺（快）

**E1 机理**（生成烯烃）：
1. (CH₃)₃C-Br → (CH₃)₃C⁺ + Br⁻（慢）
2. (CH₃)₃C⁺ → (CH₃)₂C=CH₂ + H⁺（快）

**解释**：3° 底物在弱亲核/弱碱条件下，SN1 和 E1 竞争。高温有利于 E1（熵增）。

### 例 2
**题目**：溴乙烷与 NaOH 水溶液反应生成乙醇。请判断反应机理并解释。

**解答**：
**SN2 机理**：
HO⁻ + CH₃CH₂-Br → [HO···CH₃CH₂···Br]⁻‡ → CH₃CH₂-OH + Br⁻

**解释**：
- 底物：1° 卤代烷，空间位阻小
- 试剂：OH⁻ 是强亲核试剂/强碱
- 动力学：二级（rate = k[底物][OH⁻]）
- 立体化学：构型翻转（若为手性碳）

**对比**：若用叔丁基溴，则主要发生 E2 消除（空间位阻大）。

### 例 3
**题目**：苯与 Br₂ 在 FeBr₃ 催化下生成溴苯。请写出反应机理。

**解答**：
**亲电芳香取代机理**：
1. Br₂ + FeBr₃ → Br⁺ + FeBr₄⁻（生成亲电试剂）
2. Br⁺ + C₆H₆ → [C₆H₆Br]⁺（σ-络合物，决速步）
3. [C₆H₆Br]⁺ → C₆H₅Br + H⁺（去质子化）
4. H⁺ + FeBr₄⁻ → HBr + FeBr₃（催化剂再生）

**解释**：苯环富电子，进攻亲电试剂 Br⁺，形成共振稳定的 σ-络合物，最后失去质子恢复芳香性。

## 七、易错点

1. **箭头方向错误**：箭头应从电子源指向电子汇，不可反向
2. **中间体结构错误**：碳正离子为平面 sp² 杂化，自由基也为平面
3. **忽略重排**：碳正离子可能发生 1,2-氢迁移或 1,2-烷基迁移
4. **立体化学混淆**：SN1 是外消旋化，SN2 是翻转，不要混淆
5. **溶剂效应忽略**：极性质子溶剂利于 SN1，极性非质子溶剂利于 SN2
6. **酸碱催化错误**：酸催化中质子化发生在亲核进攻之前
7. **环状中间体**：如溴鎓离子、碘鎓离子的形成
8. **芳香性恢复**：亲电取代最后一步必须去质子化恢复芳香性
