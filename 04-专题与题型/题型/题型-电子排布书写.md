# 题型 · 电子排布书写

## 解题思路

### 核心判断依据
- **基态电子排布**遵循三大原理：Aufbau 原理（能量最低）、Pauli 不相容原理（最多 2 电子/轨道、自旋相反）、Hund 规则（简并轨道先分占、自旋平行）
- **书写顺序**按主量子数 n 递增，**填充顺序**按能级高低（n+l 规则），**失电子顺序**先失 n 最大的轨道
- 异常排布（Cr、Cu 等）需考虑**交换能**稳定化效应

### 常见出题角度
1. 写出指定元素的基态电子排布式（全排布或价电子排布）
2. 写出离子的电子排布式（注意失电子顺序）
3. 根据价电子排布推断元素位置（周期、族、区）
4. 判断未成对电子数、磁性
5. 解释异常排布的稳定性（半满/全满效应）

## 核心方法与知识点

### 关键知识点

**电子排布书写三原则**：
1. **Aufbau 原理**：电子按能级从低到高填充（1s→2s→2p→3s→3p→4s→3d→...）
2. **Pauli 不相容原理**：每个轨道最多容纳 2 个电子，且自旋必须相反
3. **Hund 规则**：简并轨道（如 3 个 p 轨道）先各占 1 个电子且自旋平行，再配对

**能级填充顺序（n+l 规则）**：
```
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p
```

**失电子顺序**：先失 n 最大的轨道（与填充顺序相反）
- 例：Fe 失电子先失 4s²，再失 3d⁶

**异常排布**：
| 元素 | 预期排布 | 实际排布 | 原因 |
|:---:|:---:|:---:|:---|
| Cr | [Ar] 3d⁴ 4s² | [Ar] 3d⁵ 4s¹ | d⁵ 半满稳定，交换能收益 |
| Cu | [Ar] 3d⁹ 4s² | [Ar] 3d¹⁰ 4s¹ | d¹⁰ 全满稳定，交换能收益 |

### 解题步骤框架

**步骤 1**：确定原子序数 Z → 总电子数 = Z

**步骤 2**：按 Aufbau 顺序填充电子
- 写出能级顺序，逐级填入电子
- 注意 d 轨道最多 10 电子，f 轨道最多 14 电子

**步骤 3**：按 n 递增顺序书写（书写顺序 ≠ 填充顺序）
- 例：Fe 填充顺序 [Ar] 4s² 3d⁶，书写顺序 [Ar] 3d⁶ 4s²

**步骤 4**：如涉及离子，先失 n 最大的轨道
- Fe²⁺：先失 4s² → [Ar] 3d⁶
- Fe³⁺：再失 1 个 3d → [Ar] 3d⁵

## 典型例题

### 例题 1：基态电子排布书写

**题目**：写出以下元素的基态电子排布式和价电子排布式：
(1) Fe（Z=26）
(2) Br（Z=35）
(3) Mo（Z=42）

**解答**：

**(1) Fe（Z=26）**
- 总电子数 26，按 Aufbau 填充：
  1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁶
- 书写顺序（按 n 排列）：
  **[Ar] 3d⁶ 4s²**
- 价电子排布式：**3d⁶ 4s²**

**(2) Br（Z=35）**
- 总电子数 35：
  1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d¹⁰ 4p⁵
- 书写顺序：
  **[Ar] 3d¹⁰ 4s² 4p⁵**
- 价电子排布式：**4s² 4p⁵**

**(3) Mo（Z=42）**
- Mo 与 Cr 同族（ⅥB），存在异常排布
- 正常预期：[Kr] 4d⁴ 5s²
- 实际排布：**[Kr] 4d⁵ 5s¹**（d⁵ 半满稳定）
- 价电子排布式：**4d⁵ 5s¹**

---

### 例题 2：离子电子排布与未成对电子数

**题目**：写出 Fe²⁺ 和 Fe³⁺ 的电子排布式，并判断各自的未成对电子数和磁性。

**解答**：

**Fe²⁺（失去 2 个电子）**
- Fe 基态：[Ar] 3d⁶ 4s²
- 失电子顺序：先失 n 最大的 4s 电子
- Fe²⁺：**[Ar] 3d⁶**
- 3d⁶ 排布：↑↓ ↑ ↑ ↑ ↑（5 个轨道中 4 个单电子 + 1 对）
- 未成对电子数：**4 个**
- 磁性：**顺磁性**（有未成对电子）

**Fe³⁺（失去 3 个电子）**
- 再失 1 个 3d 电子
- Fe³⁺：**[Ar] 3d⁵**
- 3d⁵ 排布：↑ ↑ ↑ ↑ ↑（5 个轨道各 1 个电子，半满）
- 未成对电子数：**5 个**
- 磁性：**顺磁性**
- 注意：3d⁵ 半满构型特别稳定，这就是 Fe³⁺ 比 Fe²⁺ 更稳定的原因之一

---

### 例题 3：根据价电子排布推断元素

**题目**：某元素基态原子价电子排布为 3d⁷ 4s²。
(1) 该元素的原子序数是多少？
(2) 它位于周期表第几周期、第几族、哪个区？
(3) 写出其 +2 价和 +3 价离子的电子排布式，并判断磁性。

**解答**：

**(1) 原子序数**
- [Ar] 核心 = 18 电子
- 价电子 = 3d⁷ + 4s² = 9 电子
- Z = 18 + 9 = **27（Co）**

**(2) 周期表位置**
- 最高 n = 4 → **第四周期**
- 价电子数 = 7 + 2 = 9 → **Ⅷ族**（过渡金属，Ⅷ族包含 8、9、10 三列）
- d 电子参与成键 → **d 区**

**(3) 离子电子排布**
- Co²⁺：失 4s² → **[Ar] 3d⁷**
  - 3d⁷：↑↓ ↑↑ ↑ ↑ ↑（3 个未成对）
  - 磁性：**顺磁性**
- Co³⁺：再失 1 个 3d → **[Ar] 3d⁶**
  - 3d⁶：↑↓ ↑ ↑ ↑ ↑（4 个未成对）
  - 磁性：**顺磁性**

## 易错点与注意事项

### 高频错误

1. **书写顺序与填充顺序混淆**
   - 错误：Fe 写成 [Ar] 4s² 3d⁶
   - 正确：**[Ar] 3d⁶ 4s²**（书写按 n 递增）

2. **离子失电子顺序错误**
   - 错误：Fe²⁺ 先失 3d 电子 → [Ar] 3d⁴ 4s²
   - 正确：**先失 4s 电子** → [Ar] 3d⁶

3. **忽视异常排布**
   - Cr 不是 [Ar] 3d⁴ 4s²，而是 **[Ar] 3d⁵ 4s¹**
   - Cu 不是 [Ar] 3d⁹ 4s²，而是 **[Ar] 3d¹⁰ 4s¹**

4. **未成对电子数判断错误**
   - 3d⁴ 不是 4 个未成对，而是按 Hund 规则先分占 4 个轨道（4 个未成对）
   - 3d⁵ 是 5 个未成对（半满），3d⁶ 是 4 个未成对（1 对 + 4 单）

5. **价电子范围错误**
   - 过渡金属价电子包括 (n-1)d + ns
   - 主族元素价电子只是 ns + np

### 检查清单
- [ ] 总电子数 = 原子序数
- [ ] 每个轨道 ≤ 2 电子
- [ ] 简并轨道先分占后配对（Hund 规则）
- [ ] 书写顺序按 n 递增
- [ ] 离子先失 n 最大的轨道
- [ ] 异常排布元素（Cr、Cu、Mo、Ag 等）已特殊处理
