# 题型 · 键级与磁性判断

## 解题思路

键级与磁性判断需要借助分子轨道（MO）理论。第一步，确定分子的电子总数和各原子的价电子数。第二步，按照正确的 MO 能级顺序填入电子。对于第二周期双原子分子，关键区分两种能级序列：$\text{B}_2$、$\text{C}_2$、$\text{N}_2$ 由于 $s$-$p$ 混杂显著，$\pi_{2p}$ 轨道能量低于 $\sigma_{2p}$；而 $\text{O}_2$、$\text{F}_2$ 的 $s$-$p$ 混杂很弱，$\sigma_{2p}$ 能量低于 $\pi_{2p}$。第三步，由填充结果计算键级：$\text{键级} = \frac{n_{\text{成键}} - n_{\text{反键}}}{2}$。第四步，由未成对电子数判断磁性：有未成对电子为顺磁性，全部配对为反磁性。

MO 理论的一大成功是解释了 $\text{O}_2$ 的顺磁性。价键理论将 $\text{O}_2$ 写为 $\text{O}\!=\!\text{O}$（双键），暗示所有电子配对，与实验矛盾。MO 理论中 $\text{O}_2$ 的 $\pi_{2p}^*$ 反键轨道上有 2 个未成对电子，完美解释了顺磁性。此外，MO 理论还能解释离子的稳定性：$\text{O}_2^+$ 键级 $2.5$（键能最大）、$\text{O}_2$ 键级 $2$、$\text{O}_2^-$ 键级 $1.5$、$\text{O}_2^{2-}$ 键级 $1$，键长依次增大。

## 核心方法

1. **两种 MO 能级序列必须分清**：$\text{B}_2/\text{C}_2/\text{N}_2$：$\sigma_{2s} < \sigma_{2s}^* < \pi_{2p} < \sigma_{2p} < \pi_{2p}^* < \sigma_{2p}^*$；$\text{O}_2/\text{F}_2$：$\sigma_{2s} < \sigma_{2s}^* < \sigma_{2p} < \pi_{2p} < \pi_{2p}^* < \sigma_{2p}^*$
2. **键级公式**：$\text{键级} = (\text{成键电子数} - \text{反键电子数}) / 2$，键级越大键能越大、键长越短
3. **顺磁性判断**：$\text{O}_2$ 的 $\pi_{2p}^*$ 轨道上 2 个电子分占两个简并轨道（Hund 规则），产生顺磁性（$\mu = 2.83\,\mu_B$）
4. **同核双原子离子系列**：$\text{O}_2^+ > \text{O}_2 > \text{O}_2^- > \text{O}_2^{2-}$ 键级递减、键长递增、键能递减
5. **键级与稳定性**：$\text{He}_2$ 键级 $= 0$（不成键），解释了惰性气体不形成双原子分子

## 典型例题

**例题 1：用 MO 理论判断 $\text{N}_2$ 和 $\text{O}_2$ 的键级与磁性**

**解答：**

**(a) $\text{N}_2$（14 个电子）**

$\text{N}_2$ 的 MO 能级序列（$s$-$p$ 混杂显著，$\pi_{2p} < \sigma_{2p}$）：

$$(\sigma_{1s})^2(\sigma_{1s}^*)^2(\sigma_{2s})^2(\sigma_{2s}^*)^2(\pi_{2p})^4(\sigma_{2p})^2$$

- 成键电子数：$2(\sigma_{1s}) + 2(\sigma_{2s}) + 4(\pi_{2p}) + 2(\sigma_{2p}) = 10$
- 反键电子数：$2(\sigma_{1s}^*) + 2(\sigma_{2s}^*) = 4$
- $\text{键级} = (10 - 4)/2 = 3$（三重键，与 $\text{N}\equiv\text{N}$ 一致）
- 未成对电子数：$0 \implies$ **反磁性**
- 实验验证：$\text{N}_2$ 键能 $945\,\text{kJ/mol}$（最大），键长 $110\,\text{pm}$（很短）

**(b) $\text{O}_2$（16 个电子）**

$\text{O}_2$ 的 MO 能级序列（$s$-$p$ 混杂弱，$\sigma_{2p} < \pi_{2p}$）：

$$(\sigma_{1s})^2(\sigma_{1s}^*)^2(\sigma_{2s})^2(\sigma_{2s}^*)^2(\sigma_{2p})^2(\pi_{2p})^4(\pi_{2p}^*)^2$$

- 成键电子数：$2(\sigma_{1s}) + 2(\sigma_{2s}) + 2(\sigma_{2p}) + 4(\pi_{2p}) = 10$
- 反键电子数：$2(\sigma_{1s}^*) + 2(\sigma_{2s}^*) + 2(\pi_{2p}^*) = 6$
- $\text{键级} = (10 - 6)/2 = 2$（双键）
- 未成对电子数：$2$（$\pi_{2p}^*$ 上两个电子各占一个轨道，Hund 规则）$\implies$ **顺磁性**

$$\boxed{\text{N}_2:\text{键级}=3,\text{反磁性};\quad \text{O}_2:\text{键级}=2,\text{顺磁性}}$$

**例题 2：比较 $\text{O}_2^+$、$\text{O}_2$、$\text{O}_2^-$、$\text{O}_2^{2-}$ 的键级、键长和稳定性**

**解答：**

以 $\text{O}_2$（16 电子）MO 填充为基准：

$$(\sigma_{1s})^2(\sigma_{1s}^*)^2(\sigma_{2s})^2(\sigma_{2s}^*)^2(\sigma_{2p})^2(\pi_{2p})^4(\pi_{2p}^*)^2$$

**(1) $\text{O}_2^+$（15 电子）**：从 $\pi_{2p}^*$ 失去 1 个电子

$$\text{键级} = \frac{10 - 5}{2} = 2.5$$

**(2) $\text{O}_2$（16 电子）**：基准态

$$\text{键级} = \frac{10 - 6}{2} = 2.0$$

**(3) $\text{O}_2^-$（17 电子，超氧离子）**：$\pi_{2p}^*$ 增加 1 个电子

$$\text{键级} = \frac{10 - 7}{2} = 1.5$$

**(4) $\text{O}_2^{2-}$（18 电子，过氧离子）**：$\pi_{2p}^*$ 增加 2 个电子

$$\text{键级} = \frac{10 - 8}{2} = 1.0$$

排序结果：

$$\boxed{\text{键级}:\text{O}_2^+(2.5) > \text{O}_2(2.0) > \text{O}_2^-(1.5) > \text{O}_2^{2-}(1.0)}$$

$$\text{键长}:\text{O}_2^+(112\,\text{pm}) < \text{O}_2(121\,\text{pm}) < \text{O}_2^-(133\,\text{pm}) < \text{O}_2^{2-}(149\,\text{pm})$$

$$\text{键能}:\text{O}_2^+(626\,\text{kJ/mol}) > \text{O}_2(498\,\text{kJ/mol}) > \text{O}_2^-(395\,\text{kJ/mol}) > \text{O}_2^{2-}(146\,\text{kJ/mol})$$

稳定性与键级正相关：键级越大，化学键越强，分子越稳定。$\text{O}_2^{2-}$ 的键级仅为 1（等价于单键），这解释了过氧化物（如 $\text{H}_2\text{O}_2$）容易发生断裂反应的原因。

## 易错点

1. **MO 能级顺序错误**：$\text{N}_2$ 中 $\pi_{2p}$ 在 $\sigma_{2p}$ 之前（$s$-$p$ 混杂），$\text{O}_2$ 中 $\sigma_{2p}$ 在 $\pi_{2p}$ 之前（$s$-$p$ 混杂弱），用错顺序会导致键级计算错误
2. **忘记内层电子**：$\sigma_{1s}$ 和 $\sigma_{1s}^*$ 各 2 个电子（共 4 个），成键和反键各 2 个，对键级贡献为 0，但必须计入总电子数
3. **$\text{O}_2$ 顺磁性的解释错误**：$\text{O}_2$ 顺磁性来自 $\pi_{2p}^*$ 上的 2 个未成对电子（Hund 规则），而非来自"孤对电子"或其他错误解释
4. **混淆键级与氧化态**：$\text{O}_2^-$ 中 O 的氧化态为 $-1/2$（超氧根），键级为 $1.5$；两者是不同概念，不可混为一谈
