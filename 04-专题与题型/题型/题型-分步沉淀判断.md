# 题型 · 分步沉淀判断

> **核心支撑页**：[[专题-沉淀溶解平衡]]

## 解题思路

分步沉淀判断的核心在于 **不是看谁的 Ksp 小，而是看谁的离子积 Q 先达到 Ksp**。面对这类题型，首先判断沉淀类型：同类型沉淀（如 AgCl 与 AgBr，均为 1:1 型）可直接比较 Ksp，Ksp 小的先沉淀；异类型沉淀（如 AgCl 1:1 型与 Ag₂CrO₄ 2:1 型）必须分别计算各离子开始沉淀所需的沉淀剂浓度，所需浓度最小的先沉淀。

"完全沉淀"的判据是离子浓度降至 < 10⁻⁵ mol/L。当第一种离子完全沉淀时，第二种离子是否开始沉淀，决定了两种离子能否通过分步沉淀实现定量分离。例如 Mohr 法测 Cl⁻ 中，AgCl（白色）先沉淀完全，过量一滴 Ag⁺ 与 CrO₄²⁻ 生成砖红色 Ag₂CrO₄ 指示终点——虽然 Ksp(Ag₂CrO₄) 数值上小于 Ksp(AgCl)，但 AgCl 反而先沉淀（异类型不能直接比 Ksp）。

## 核心方法

1. **同类型直接比 Ksp 法**：同为 1:1 型（AgCl vs AgBr）或同为 2:1 型（Ag₂CrO₄ vs Ag₂S），Ksp 小的先沉淀。
2. **异类型算浓度法**：分别计算各沉淀所需最小 [沉淀剂]：对于 AₘBₙ 型，$[\text{沉淀剂}]_{\min} = \left(\frac{K_{\text{sp}}}{[\text{被沉淀离子}]^m}\right)^{1/n}$。所需 [沉淀剂] 最小的先沉淀。
3. **完全沉淀判据法**：当被沉淀离子浓度降至 < 10⁻⁵ mol/L 时视为"完全沉淀"。判断第二种离子是否在第一种完全沉淀前就开始沉淀。
4. **Mohr 法原理应用法**：Cl⁻/CrO₄²⁻ 混合液中加 Ag⁺，AgCl 先沉淀完全，CrO₄²⁻ 作终点指示剂（过量 Ag⁺ 生成砖红色 Ag₂CrO₄）。
5. **分离可行性判断法**：若第一种离子完全沉淀时 [第二种离子] < 10⁻⁵ mol/L，则可定量分离；否则不能。

## 典型例题

### 例题 1：同类型分步沉淀

**题目**：溶液中 [Cl⁻] = 0.010 mol/L，[Br⁻] = 0.010 mol/L，逐滴加入 AgNO₃ 溶液。已知 $K_{\text{sp}}(\mathrm{AgCl}) = 1.8 \times 10^{-10}$，$K_{\text{sp}}(\mathrm{AgBr}) = 5.0 \times 10^{-13}$。(1) 哪种沉淀先生成？(2) AgBr 开始沉淀时，[Cl⁻] 剩余多少？能否定量分离？

**解答**：

(1) 同为 1:1 型，直接比较 Ksp：$K_{\text{sp}}(\mathrm{AgBr}) = 5.0 \times 10^{-13} < K_{\text{sp}}(\mathrm{AgCl}) = 1.8 \times 10^{-10}$ → **AgBr 先沉淀**。

(2) AgBr 开始沉淀时需 [Ag⁺]：
$$[\mathrm{Ag^+}] = \frac{K_{\text{sp}}(\mathrm{AgBr})}{[\mathrm{Br^-}]} = \frac{5.0 \times 10^{-13}}{0.010} = 5.0 \times 10^{-11}\ \mathrm{mol/L}$$

此时 [Cl⁻]：
$$[\mathrm{Cl^-}] = \frac{K_{\text{sp}}(\mathrm{AgCl})}{[\mathrm{Ag^+}]} = \frac{1.8 \times 10^{-10}}{5.0 \times 10^{-11}} = 3.6\ \mathrm{mol/L}$$

[Cl⁻] = 3.6 mol/L >> 10⁻⁵ mol/L → **Cl⁻ 几乎没有沉淀，不能通过分步沉淀分离**（两者 Ksp 相差不够大）。

---

### 例题 2：异类型分步沉淀（Mohr 法原理）

**题目**：溶液中 [Cl⁻] = [CrO₄²⁻] = 0.010 mol/L，逐滴加入 AgNO₃。(1) 哪种沉淀先生成？(2) Ag₂CrO₄ 开始沉淀时，[Cl⁻] 剩余多少？已知 $K_{\text{sp}}(\mathrm{AgCl}) = 1.8 \times 10^{-10}$，$K_{\text{sp}}(\mathrm{Ag_2CrO_4}) = 1.1 \times 10^{-12}$。

**解答**：

(1) 异类型，分别计算所需 [Ag⁺]：

AgCl（1:1 型）：$[\mathrm{Ag^+}]_{\min} = \frac{K_{\text{sp}}}{[\mathrm{Cl^-}]} = \frac{1.8 \times 10^{-10}}{0.010} = 1.8 \times 10^{-8}\ \mathrm{mol/L}$

Ag₂CrO₄（2:1 型）：$[\mathrm{Ag^+}]_{\min} = \sqrt{\frac{K_{\text{sp}}}{[\mathrm{CrO_4^{2-}}]}} = \sqrt{\frac{1.1 \times 10^{-12}}{0.010}} = 1.0 \times 10^{-5}\ \mathrm{mol/L}$

$1.8 \times 10^{-8} < 1.0 \times 10^{-5}$ → **AgCl 先沉淀**。

(2) Ag₂CrO₄ 开始沉淀时 [Ag⁺] = 1.0 × 10⁻⁵ mol/L：
$$[\mathrm{Cl^-}] = \frac{K_{\text{sp}}(\mathrm{AgCl})}{1.0 \times 10^{-5}} = \frac{1.8 \times 10^{-10}}{1.0 \times 10^{-5}} = 1.8 \times 10^{-5}\ \mathrm{mol/L}$$

[Cl⁻] ≈ 10⁻⁵ mol/L → **Cl⁻ 已定量沉淀**。这正是 Mohr 法的原理：AgCl 先沉淀完全，CrO₄²⁻ 作终点指示剂。

## 易错点

1. **异类型沉淀不能直接比 Ksp**：AgCl（Ksp = 1.8×10⁻¹⁰）的 Ksp 大于 Ag₂CrO₄（Ksp = 1.1×10⁻¹²），但 AgCl 反而先沉淀。必须计算所需 [沉淀剂] 才能判断。
2. **"完全沉淀"的定量标准是 10⁻⁵ mol/L**：不能用"沉淀完全"的模糊说法，必须给出具体浓度数值并与 10⁻⁵ mol/L 比较。
3. **混合后浓度变化的遗漏**：两种溶液混合后体积增大、浓度减半，Q 必须用混合后浓度计算。直接用混合前浓度是常见错误。
4. **分离可行性与 Ksp 差值的关系**：两种离子能否通过分步沉淀分离，取决于它们的 Ksp 差值是否足够大（通常需差 10⁴ 倍以上）。差值不够大时，第一种未完全沉淀第二种就开始沉淀了。
