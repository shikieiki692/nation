# 题型 · 离子方程式书写与正误判断

> **核心支撑页**：[[专题-化学计量与气体]]、[[专题-离子反应]]

## 解题思路

离子方程式书写与正误判断的核心在于 **"拆"与"不拆"的规则**以及 **电荷守恒与原子守恒的双重检验**。面对这类题型，第一步是将化学方程式改写为离子形式——强酸、强碱、可溶性盐"拆"为离子；弱酸、弱碱、难溶物、气体、氧化物、水"不拆"保留分子式。第二步是消去两边相同的离子（旁观离子），得到净离子方程式。第三步是检验：原子守恒 ✓、电荷守恒 ✓、化学计量比正确 ✓。

正误判断题的常见错误类型包括：(1) 违反拆分规则（将弱电解质拆为离子，或将强电解质保留分子式）；(2) 电荷不守恒；(3) 电子不守恒（氧化还原反应中）；(4) 过量/少量条件处理不当（如少量 CO₂ 通入 NaOH 生成 CO₃²⁻，过量 CO₂ 生成 HCO₃⁻）；(5) 忽略反应的实际发生顺序（如向含多种离子的溶液中加试剂，优先反应的判断）。

## 核心方法

1. **拆分规则速查法**：强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶性盐 → 拆为离子；弱酸（CH₃COOH、H₂CO₃、H₂S）、弱碱（NH₃·H₂O、Fe(OH)₃）、难溶物（BaSO₄、AgCl）、气体（CO₂、SO₂）、水 → 保留分子式。
2. **过量-少量判断法**：少量 CO₂ + NaOH → CO₃²⁻（OH⁻ 过量）；过量 CO₂ + NaOH → HCO₃⁻（CO₂ 过量）。类似地，少量 NaOH + AlCl₃ → Al(OH)₃↓；过量 NaOH + AlCl₃ → [Al(OH)₄]⁻。
3. **双重守恒检验法**：原子守恒（各元素原子数左右相等）+ 电荷守恒（两边总电荷相等）。氧化还原反应还需电子守恒。
4. **反应优先序判断法**：多种离子共存时，加试剂的优先反应顺序——一般是"先沉淀后溶解""先中和后其他""先氧化还原后络合"。
5. **系数最简化原则**：离子方程式的系数应为最简整数比，不能出现分数系数。

## 典型例题

### 例题 1：离子方程式书写

**题目**：写出以下反应的离子方程式：(1) 碳酸钙与盐酸反应；(2) 氢氧化钡溶液与稀硫酸反应；(3) 少量 CO₂ 通入 NaOH 溶液。

**解答**：

(1) $\mathrm{CaCO_3} + 2\mathrm{H^+} \longrightarrow \mathrm{Ca^{2+}} + \mathrm{CO_2}\uparrow + \mathrm{H_2O}$

CaCO₃ 难溶不拆；HCl 拆为 H⁺ 和 Cl⁻；CaCl₂ 可溶拆为离子。

(2) $\mathrm{Ba^{2+}} + 2\mathrm{OH^-} + 2\mathrm{H^+} + \mathrm{SO_4^{2-}} \longrightarrow \mathrm{BaSO_4}\downarrow + 2\mathrm{H_2O}$

Ba(OH)₂ 可溶拆为 Ba²⁺ 和 OH⁻；H₂SO₄ 拆为 H⁺ 和 SO₄²⁻；BaSO₄ 难溶不拆，H₂O 不拆。

(3) $2\mathrm{OH^-} + \mathrm{CO_2} \longrightarrow \mathrm{CO_3^{2-}} + \mathrm{H_2O}$

少量 CO₂ 时 OH⁻ 过量，产物为 CO₃²⁻（不是 HCO₃⁻）。

### 例题 2：离子方程式正误判断

**题目**：判断以下离子方程式是否正确，若不正确请改正：

(A) 铁与稀盐酸反应：$2\mathrm{Fe} + 6\mathrm{H^+} \rightarrow 2\mathrm{Fe^{3+}} + 3\mathrm{H_2}\uparrow$

(B) 碳酸钠溶液与醋酸反应：$\mathrm{CO_3^{2-}} + 2\mathrm{CH_3COOH} \rightarrow 2\mathrm{CH_3COO^-} + \mathrm{CO_2}\uparrow + \mathrm{H_2O}$

(C) 氯化铝溶液与过量氨水反应：$\mathrm{Al^{3+}} + 4\mathrm{NH_3 \cdot H_2O} \rightarrow [\mathrm{Al(OH)_4}]^- + 4\mathrm{NH_4^+}$

**解答**：

(A) **错误**。Fe 与稀盐酸反应生成 Fe²⁺ 而非 Fe³⁺（稀酸氧化性不足以将 Fe 氧化为 +3）。
正确：$\mathrm{Fe} + 2\mathrm{H^+} \rightarrow \mathrm{Fe^{2+}} + \mathrm{H_2}\uparrow$

(B) **正确**。醋酸是弱酸不拆；碳酸钠拆为 Na⁺ 和 CO₃²⁻；产物 CH₃COONa 可溶拆为离子；CO₂ 和 H₂O 不拆。

(C) **错误**。Al(OH)₃ 不溶于过量氨水（氨水碱性不够强），不能生成 [Al(OH)₄]⁻。
正确：$\mathrm{Al^{3+}} + 3\mathrm{NH_3 \cdot H_2O} \rightarrow \mathrm{Al(OH)_3}\downarrow + 3\mathrm{NH_4^+}$

## 易错点

1. **Fe 与稀酸的产物**：Fe 与稀 HCl/H₂SO₄ 反应生成 Fe²⁺（不是 Fe³⁺），因为稀酸氧化性不够强。只有与浓 HNO₃、浓 H₂SO₄（热）或 Cl₂ 反应才生成 Fe³⁺。
2. **弱电解质的拆分**：CH₃COOH、NH₃·H₂O、H₂CO₃、H₂S、HF 等弱电解质不能拆为离子。即使浓度很高也不拆。
3. **过量/少量条件的产物不同**：少量 CO₂ + NaOH → CO₃²⁻；过量 CO₂ + NaOH → HCO₃⁻。类似地，少量 NaOH + AlCl₃ → Al(OH)₃；过量 NaOH + AlCl₃ → [Al(OH)₄]⁻。
4. **Al(OH)₃ 不溶于氨水**：Al(OH)₃ 只溶于强碱（NaOH、KOH），不溶于弱碱（氨水）。这是区分 Al³⁺ 和 Zn²⁺ 的重要依据。
