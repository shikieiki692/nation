# 题型 · 电池电动势计算

> **状态**: 已填充，待审核

## 解题思路

电池电动势计算的核心是电池电动势与热力学函数的关系。电池电动势 $E_{\text{cell}}$ 等于正极电势减去负极电势：$E_{\text{cell}} = E_+ - E_-$。电池符号的书写规则是：负极（氧化反应）在左，正极（还原反应）在右，用单竖线表示相界面，双竖线表示盐桥。

热力学函数与电动势的关系为：$\Delta G = -nFE_{\text{cell}}$，$\Delta G^\circ = -nFE^\circ_{\text{cell}}$。其中 $n$ 为电池反应转移的电子数，$F$ 为法拉第常数（$96485\ \text{C/mol}$）。$\Delta G < 0$ 对应 $E_{\text{cell}} > 0$，反应自发进行。

电池电动势与平衡常数的关系为：$E^\circ_{\text{cell}} = \frac{RT}{nF}\ln K$，或在 $25^\circ\text{C}$ 时 $E^\circ_{\text{cell}} = \frac{0.0592}{n}\log K$。该式将电化学数据与化学平衡联系起来，可用于由电动势计算平衡常数，或由平衡常数计算电动势。

设计电池求平衡常数是常见题型。步骤为：(1) 将目标反应拆分为两个半反应；(2) 确定正负极；(3) 写出电池符号；(4) 计算 $E^\circ_{\text{cell}}$；(5) 由 $E^\circ_{\text{cell}}$ 计算 $K$。

## 核心方法

1. **电动势计算法**：利用 $E_{\text{cell}} = E_+ - E_-$ 计算电池电动势
2. **Nernst 方程法**：利用 Nernst 方程计算非标态下的电池电动势
3. **热力学函数转换法**：利用 $\Delta G = -nFE$ 在电动势与吉布斯自由能之间转换
4. **平衡常数计算法**：利用 $E^\circ_{\text{cell}} = \frac{0.0592}{n}\log K$ 计算平衡常数
5. **电池设计法**：根据目标反应设计原电池，计算电动势和平衡常数

## 典型例题

### 例题1：设计电池求平衡常数

**题目**：设计一个原电池，计算反应 $\text{Zn}(s) + \text{Cu}^{2+}(aq) \rightleftharpoons \text{Zn}^{2+}(aq) + \text{Cu}(s)$ 在 $25^\circ\text{C}$ 时的平衡常数。已知 $E^\circ(\text{Zn}^{2+}/\text{Zn}) = -0.76\ \text{V}$，$E^\circ(\text{Cu}^{2+}/\text{Cu}) = 0.34\ \text{V}$。

**解答**：
(1) 拆分为两个半反应：
负极（氧化反应）：$\text{Zn}(s) \rightarrow \text{Zn}^{2+}(aq) + 2e^-$
正极（还原反应）：$\text{Cu}^{2+}(aq) + 2e^- \rightarrow \text{Cu}(s)$

(2) 电池符号：
$$\text{Zn}(s) \mid \text{Zn}^{2+}(aq) \| \text{Cu}^{2+}(aq) \mid \text{Cu}(s)$$

(3) 计算标准电池电动势：
$$E^\circ_{\text{cell}} = E^\circ_+ - E^\circ_- = E^\circ(\text{Cu}^{2+}/\text{Cu}) - E^\circ(\text{Zn}^{2+}/\text{Zn}) = 0.34 - (-0.76) = 1.10\ \text{V}$$

(4) 计算平衡常数：
$$E^\circ_{\text{cell}} = \frac{0.0592}{n}\log K$$
$$1.10 = \frac{0.0592}{2}\log K$$
$$\log K = \frac{1.10 \times 2}{0.0592} = \frac{2.20}{0.0592} = 37.2$$
$$K = 10^{37.2} = 1.6 \times 10^{37}$$

平衡常数非常大，说明反应正向进行得非常完全。

### 例题2：非标态电池电动势计算

**题目**：对于电池 $\text{Zn}(s) \mid \text{Zn}^{2+}(0.010\ \text{mol/L}) \| \text{Cu}^{2+}(1.0\ \text{mol/L}) \mid \text{Cu}(s)$，计算 $25^\circ\text{C}$ 时的电池电动势。

**解答**：
电池反应：$\text{Zn}(s) + \text{Cu}^{2+}(aq) \rightarrow \text{Zn}^{2+}(aq) + \text{Cu}(s)$

标准电动势：$E^\circ_{\text{cell}} = 0.34 - (-0.76) = 1.10\ \text{V}$

Nernst 方程：
$$E_{\text{cell}} = E^\circ_{\text{cell}} - \frac{0.0592}{n}\log\frac{[\text{Zn}^{2+}]}{[\text{Cu}^{2+}]}$$

代入数据（$n = 2$）：
$$E_{\text{cell}} = 1.10 - \frac{0.0592}{2}\log\frac{0.010}{1.0}$$
$$E_{\text{cell}} = 1.10 - 0.0296 \times \log(0.010)$$
$$E_{\text{cell}} = 1.10 - 0.0296 \times (-2)$$
$$E_{\text{cell}} = 1.10 + 0.0592 = 1.16\ \text{V}$$

可见，降低 $\text{Zn}^{2+}$ 浓度（从 $1.0\ \text{mol/L}$ 到 $0.010\ \text{mol/L}$）使电池电动势从 $1.10\ \text{V}$ 增加到 $1.16\ \text{V}$，反应更趋于正向进行。

## 易错点

1. **电池符号书写错误**：负极（氧化反应）在左，正极（还原反应）在右。不能颠倒。单竖线表示相界面，双竖线表示盐桥。如 $\text{Zn}(s) \mid \text{Zn}^{2+}(aq) \| \text{Cu}^{2+}(aq) \mid \text{Cu}(s)$。

2. **$n$ 值确定错误**：$n$ 是电池反应中转移的电子数，不是电极反应的电子数。对于 $\text{Zn} + \text{Cu}^{2+} \rightarrow \text{Zn}^{2+} + \text{Cu}$，$n = 2$（$\text{Zn}$ 失去 2 个电子，$\text{Cu}^{2+}$ 得到 2 个电子）。

3. **Nernst 方程中浓度比写错**：对于电池反应 $\text{Zn}(s) + \text{Cu}^{2+}(aq) \rightarrow \text{Zn}^{2+}(aq) + \text{Cu}(s)$，Nernst 方程为 $E = E^\circ - \frac{0.0592}{n}\log\frac{[\text{Zn}^{2+}]}{[\text{Cu}^{2+}]}$，分子是产物浓度，分母是反应物浓度。

4. **平衡常数与电动势关系误解**：$E^\circ_{\text{cell}} = \frac{0.0592}{n}\log K$ 仅适用于 $25^\circ\text{C}$。其他温度需用 $E^\circ_{\text{cell}} = \frac{RT}{nF}\ln K$。

5. **电池设计方向错误**：设计电池时，目标反应必须自发进行（$\Delta G < 0$，$E_{\text{cell}} > 0$）。若计算得到 $E_{\text{cell}} < 0$，需反转电池方向。
