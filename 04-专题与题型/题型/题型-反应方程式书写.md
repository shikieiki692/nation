# 题型 · 反应方程式书写

> **核心支撑页**：[[专题-化学计量与气体]]

## 解题思路

反应方程式书写是化学计算的基础——方程式写错，后续所有计量计算都错。面对这类题型，第一步是**确定反应物和产物**：根据题目描述的实验现象（沉淀、气体、颜色变化）或化学知识判断产物；第二步是**配平**：用最小公倍数法、观察法或半反应法使两边原子数相等；第三步是**标注条件和状态**：反应条件（加热、催化剂、点燃等）和物质状态（↑、↓、↑）。

竞赛中方程式书写的高频场景包括：(1) 元素化学中的特征反应（如 Fe²⁺ 被 H₂O₂ 氧化、Cr₂O₇²⁻ 氧化乙醇）；(2) 工业制备反应（如接触法制 H₂SO₄、氨催化氧化）；(3) 定性分析中的鉴定反应（如 Fe³⁺ + SCN⁻ 血红色、Ni²⁺ + DMG 鲜红色沉淀）。书写原则是"事实优先"——必须写出真实发生的反应，不能凭想象编造。

## 核心方法

1. **观察法配平**：从化学式最复杂的物质开始配平，逐步调整其他物质的系数，使两边原子数相等。适用于简单反应。
2. **最小公倍数法**：找到变价元素的化合价升降总数的最小公倍数，确定氧化剂和还原剂的系数。适用于氧化还原反应。
3. **半反应法配平**：拆分为氧化/还原半反应分别配平后合并。适用于复杂氧化还原反应，特别是需要介质条件的。
4. **产物推断法**：根据实验现象推断产物——沉淀（↓）、气体（↑）、颜色变化（→ 某价态离子）。例如"棕色气体"→ NO₂；"黄绿色气体"→ Cl₂；"刺激性气味气体"→ SO₂ 或 NH₃。
5. **条件标注法**：加热（Δ 或 △）、催化剂（写在箭头上方）、点燃（用于燃烧反应）、浓（写在化学式旁）。

## 典型例题

### 例题 1：元素化学特征反应

**题目**：写出以下反应的化学方程式：(1) FeCl₃ 溶液与铜片反应；(2) MnO₂ 与浓盐酸加热反应；(3) Cu₂O 与稀 HNO₃ 反应。

**解答**：

(1) Fe³⁺ 氧化 Cu 为 Cu²⁺，自身还原为 Fe²⁺：
$$2\mathrm{FeCl_3} + \mathrm{Cu} \longrightarrow 2\mathrm{FeCl_2} + \mathrm{CuCl_2}$$
离子方程式：$2\mathrm{Fe^{3+}} + \mathrm{Cu} \longrightarrow 2\mathrm{Fe^{2+}} + \mathrm{Cu^{2+}}$

(2) MnO₂ 氧化浓 HCl 中的 Cl⁻ 为 Cl₂：
$$\mathrm{MnO_2} + 4\mathrm{HCl(浓)} \xrightarrow{\Delta} \mathrm{MnCl_2} + \mathrm{Cl_2}\uparrow + 2\mathrm{H_2O}$$

(3) Cu₂O 中 Cu⁺ 被 HNO₃ 氧化为 Cu²⁺，HNO₃ 被还原为 NO：
$$3\mathrm{Cu_2O} + 14\mathrm{HNO_3(稀)} \longrightarrow 6\mathrm{Cu(NO_3)_2} + 2\mathrm{NO}\uparrow + 7\mathrm{H_2O}$$

### 例题 2：根据现象推断并配平

**题目**：某实验中，将 K₂Cr₂O₇ 固体与浓 H₂SO₄ 混合后加入乙醇，观察到溶液变为绿色，并产生刺激性气味的气体。写出该反应的化学方程式。

**解答**：

分析：
- K₂Cr₂O₇ + 浓 H₂SO₄ → 酸性 Cr₂O₇²⁻（橙色）
- 加入乙醇 → Cr₂O₇²⁻ 氧化乙醇为乙酸（或 CO₂），自身还原为 Cr³⁺（绿色）
- 刺激性气味气体 → 可能是 CO₂（乙醇被完全氧化）或乙醛（不完全氧化）

以乙醇被氧化为乙酸为例：
$$\mathrm{K_2Cr_2O_7} + 3\mathrm{C_2H_5OH} + 4\mathrm{H_2SO_4} \longrightarrow \mathrm{Cr_2(SO_4)_3} + 3\mathrm{CH_3COOH} + \mathrm{K_2SO_4} + 7\mathrm{H_2O}$$

Cr₂O₇²⁻ → 2Cr³⁺（得 6e⁻）；C₂H₅OH → CH₃COOH（C 从 -2 到 0，失 2e⁻ × 2C = 4e⁻... 实际上需仔细计算碳的氧化态变化）。

更精确的配平：乙醇中 C 平均氧化态 -2，乙酸中 C 平均氧化态 0，两碳共失 4e⁻。但 Cr₂O₇²⁻ 得 6e⁻，最小公倍数 12 → 3 乙醇 + 2 Cr₂O₇²⁻。此反应较复杂，竞赛中通常直接给出配平结果。

## 易错点

1. **浓 HCl 与稀 HCl 的产物不同**：浓 HCl + MnO₂ → Cl₂（Cl⁻ 被氧化）；稀 HCl + MnO₂ → 不反应。浓 H₂SO₄ 与稀 H₂SO₄ 同理。
2. **Fe 与不同氧化剂的产物**：Fe + 稀 HCl → FeCl₂（+2）；Fe + Cl₂ → FeCl₃（+3）；Fe + 稀 HNO₃（过量）→ Fe(NO₃)₃（+3）。
3. **反应条件的遗漏**：MnO₂ + 浓 HCl 必须加热才能反应；Mg 在空气中燃烧需点燃条件；催化反应必须标注催化剂。
4. **离子方程式与化学方程式的混淆**：题目要求写"化学方程式"时写分子形式，要求写"离子方程式"时拆为离子。竞赛中两种都可能考。
