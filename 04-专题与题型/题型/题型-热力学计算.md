# 题型 · 热力学计算

> **状态**: 已填充，待审核

## 解题思路

热力学计算的核心是状态函数和途径函数。热力学第一定律 $\Delta U = Q + W$ 将内能变化与热量和功联系起来。对于恒压过程，$\Delta H = Q_p$；对于恒容过程，$\Delta U = Q_v$。焓变 $\Delta H$ 和内能变 $\Delta U$ 的关系为 $\Delta H = \Delta U + \Delta(pV)$，对于理想气体反应，$\Delta H = \Delta U + \Delta n_g RT$。

Hess 定律指出，化学反应的焓变只与始态和终态有关，与途径无关。这是计算反应热的基本原理。利用 Hess 定律，可以通过已知反应的焓变计算未知反应的焓变。常用方法包括：(1) 反应方程式相加减；(2) 利用生成焓计算：$\Delta_r H^\circ = \sum \nu_i \Delta_f H^\circ(\text{产物}) - \sum \nu_j \Delta_f H^\circ(\text{反应物})$；(3) 利用键能估算：$\Delta H = \sum E(\text{断裂键}) - \sum E(\text{形成键})$。

Kirchhoff 方程描述了焓变随温度的变化：$\Delta H(T_2) = \Delta H(T_1) + \int_{T_1}^{T_2} \Delta C_p dT$。若 $\Delta C_p$ 为常数，则 $\Delta H(T_2) = \Delta H(T_1) + \Delta C_p(T_2 - T_1)$。该方程可用于由一个温度下的焓变计算另一个温度下的焓变。

相变热是物质在相变过程中吸收或放出的热量，如熔化热、蒸发热、升华热等。相变热与温度的关系由 Clausius-Clapeyron 方程描述：$\frac{dp}{dT} = \frac{\Delta_{\text{trs}}H}{T\Delta V}$。对于液-气或固-气相变，若气相为理想气体且凝聚相体积可忽略，则 $\ln\frac{p_2}{p_1} = -\frac{\Delta_{\text{vap}}H}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)$。

## 核心方法

1. **Hess 定律法**：通过反应方程式的线性组合计算未知反应的焓变
2. **生成焓法**：利用 $\Delta_r H^\circ = \sum \nu_i \Delta_f H^\circ(\text{产物}) - \sum \nu_j \Delta_f H^\circ(\text{反应物})$ 计算反应热
3. **键能估算法**：利用键能数据估算反应焓变，适用于气相反应
4. **Kirchhoff 方程法**：利用 $\Delta H(T_2) = \Delta H(T_1) + \int_{T_1}^{T_2} \Delta C_p dT$ 计算不同温度下的焓变
5. **相变热计算法**：利用 Clausius-Clapeyron 方程计算相变热或不同温度下的蒸气压

## 典型例题

### 例题1：由生成焓计算反应热

**题目**：计算反应 $\text{CH}_4(g) + 2\text{O}_2(g) \rightarrow \text{CO}_2(g) + 2\text{H}_2\text{O}(l)$ 在 $25^\circ\text{C}$ 时的标准反应焓变。已知标准生成焓：
$$\Delta_f H^\circ(\text{CH}_4, g) = -74.8\ \text{kJ/mol}$$
$$\Delta_f H^\circ(\text{CO}_2, g) = -393.5\ \text{kJ/mol}$$
$$\Delta_f H^\circ(\text{H}_2\text{O}, l) = -285.8\ \text{kJ/mol}$$

**解答**：
利用生成焓计算反应焓变的公式：
$$\Delta_r H^\circ = \sum \nu_i \Delta_f H^\circ(\text{产物}) - \sum \nu_j \Delta_f H^\circ(\text{反应物})$$

代入数据：
$$\Delta_r H^\circ = [1 \times \Delta_f H^\circ(\text{CO}_2, g) + 2 \times \Delta_f H^\circ(\text{H}_2\text{O}, l)] - [1 \times \Delta_f H^\circ(\text{CH}_4, g) + 2 \times \Delta_f H^\circ(\text{O}_2, g)]$$

注意：$\text{O}_2(g)$ 是最稳定单质，$\Delta_f H^\circ(\text{O}_2, g) = 0$。

$$\Delta_r H^\circ = [1 \times (-393.5) + 2 \times (-285.8)] - [1 \times (-74.8) + 2 \times 0]$$
$$\Delta_r H^\circ = [-393.5 - 571.6] - [-74.8]$$
$$\Delta_r H^\circ = -965.1 + 74.8 = -890.3\ \text{kJ/mol}$$

该反应为放热反应，$\Delta_r H^\circ = -890.3\ \text{kJ/mol}$。

### 例题2：Kirchhoff 方程应用

**题目**：已知反应 $\text{N}_2(g) + 3\text{H}_2(g) \rightarrow 2\text{NH}_3(g)$ 在 $298\ \text{K}$ 时 $\Delta_r H^\circ = -92.2\ \text{kJ/mol}$。各物质的定压摩尔热容为：
$$C_p(\text{N}_2, g) = 29.1\ \text{J/(mol·K)}$$
$$C_p(\text{H}_2, g) = 28.8\ \text{J/(mol·K)}$$
$$C_p(\text{NH}_3, g) = 35.1\ \text{J/(mol·K)}$$

计算该反应在 $500\ \text{K}$ 时的 $\Delta_r H^\circ$。

**解答**：
首先计算 $\Delta C_p$：
$$\Delta C_p = \sum \nu_i C_p(\text{产物}) - \sum \nu_j C_p(\text{反应物})$$
$$\Delta C_p = [2 \times C_p(\text{NH}_3)] - [1 \times C_p(\text{N}_2) + 3 \times C_p(\text{H}_2)]$$
$$\Delta C_p = [2 \times 35.1] - [29.1 + 3 \times 28.8]$$
$$\Delta C_p = 70.2 - [29.1 + 86.4] = 70.2 - 115.5 = -45.3\ \text{J/(mol·K)}$$

利用 Kirchhoff 方程：
$$\Delta_r H^\circ(500\ \text{K}) = \Delta_r H^\circ(298\ \text{K}) + \Delta C_p \times (500 - 298)$$
$$\Delta_r H^\circ(500\ \text{K}) = -92.2\ \text{kJ/mol} + (-45.3\ \text{J/(mol·K)}) \times 202\ \text{K}$$
$$\Delta_r H^\circ(500\ \text{K}) = -92.2\ \text{kJ/mol} - 9.15\ \text{kJ/mol} = -101.4\ \text{kJ/mol}$$

可见，温度从 $298\ \text{K}$ 升高到 $500\ \text{K}$，反应焓变从 $-92.2\ \text{kJ/mol}$ 变为 $-101.4\ \text{kJ/mol}$，放热更多。这是因为 $\Delta C_p < 0$，升高温度使反应放热增加。

## 易错点

1. **生成焓符号错误**：生成焓的符号表示吸热（+）或放热（-）。常见错误是将放热反应的生成焓写成正值。如 $\Delta_f H^\circ(\text{H}_2\text{O}, l) = -285.8\ \text{kJ/mol}$，负号表示放热。

2. **最稳定单质的生成焓**：最稳定单质的标准生成焓为零。如 $\Delta_f H^\circ(\text{O}_2, g) = 0$，$\Delta_f H^\circ(\text{C}, \text{石墨}) = 0$，但 $\Delta_f H^\circ(\text{O}_3, g) \neq 0$，$\Delta_f H^\circ(\text{C}, \text{金刚石}) \neq 0$。

3. **Kirchhoff 方程温度单位**：温度必须用开尔文（$\text{K}$），不能用摄氏度。计算时注意 $T(\text{K}) = T(^\circ\text{C}) + 273.15$。

4. **$\Delta C_p$ 计算错误**：$\Delta C_p$ 是产物热容之和减去反应物热容之和，需乘以化学计量数。如 $\Delta C_p = \sum \nu_i C_p(\text{产物}) - \sum \nu_j C_p(\text{反应物})$。

5. **相变热符号混淆**：熔化热、蒸发热为正值（吸热），凝固热、冷凝热为负值（放热）。在计算总焓变时，需注意相变方向。
