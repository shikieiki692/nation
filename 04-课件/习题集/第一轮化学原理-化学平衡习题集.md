### 第1题 ⭐⭐ [普化]
> 来源：库外·普化

**题目**：
写出下列反应的平衡常数表达式（$K_{p}, K_{c}$ 都可以）。

(1) $\mathrm{CH}_4(\mathrm{g}) + 2\mathrm{O}_2(\mathrm{g}) = \mathrm{CO}_2(\mathrm{g}) + 2\mathrm{H}_2\mathrm{O}(l)$

(2) $2\mathrm{H}_{2}\mathrm{S}(\mathrm{g}) \rightleftharpoons 2\mathrm{H}_{2}(\mathrm{g}) + 2\mathrm{S}(\mathrm{s})$

(3) $\mathrm{PbI}_2(\mathrm{s})\rightleftharpoons \mathrm{Pb}^{2+}(\mathrm{aq}) + 2\mathrm{I}^-(\mathrm{aq})$

(4) $\mathrm{AgCl(s)} + 2\mathrm{NH}_3(\mathrm{aq}) \rightleftharpoons \mathrm{Ag(NH_3)_2^+(aq)} + \mathrm{Cl^- (aq)}$

**参考答案**：

（1）$K_{p} = \frac{p(\mathrm{CO}_{2})}{p(\mathrm{CH}_{4})\cdot p^{2}(\mathrm{O}_{2})}$

（2）$K_{p} = \frac{p^{2}(\mathrm{H}_{2})}{p^{2}(\mathrm{H}_{2}\mathrm{S})}$

（3）$K_{c} = [\mathrm{Pb}^{2+}][\mathrm{I}^{-}]^{2}$

（4）$K_{c} = \frac{[\mathrm{Ag(NH_{3})}_{2}^{+}][\mathrm{Cl}^{-}]}{[\mathrm{NH}_{3}]^{2}}$

### 第2题 ⭐⭐ [普化]
> 原题：[[06-03]]

**题目**：
在 $698\mathrm{K}$，往 $10\mathrm{dm}^3$ 真空容器中注入 $0.10\mathrm{mol}$ $\mathrm{H_2(g)}$ 和 $0.10\mathrm{mol}$ $\mathrm{I_2(g)}$，反应平衡后 $\mathrm{I}_2(\mathrm{g})$ 的浓度为 $0.0021\mathrm{mol\cdot dm^{-3}}$。试求：

（1）在 $698\mathrm{K}$ 时，$\mathrm{H}_2 + \mathrm{I}_2 = 2\mathrm{HI}$ 的平衡常数；

（2）平衡时各物质的分压。

**参考答案**：

（1）起始浓度：$[\mathrm{H}_2]_0 = [\mathrm{I}_2]_0 = 0.010\mathrm{mol\cdot dm^{-3}}$

平衡时 $[\mathrm{I}_2] = 0.0021$，则反应消耗 $0.010 - 0.0021 = 0.0079\mathrm{mol\cdot dm^{-3}}$

$[\mathrm{HI}] = 2 \times 0.0079 = 0.0158\mathrm{mol\cdot dm^{-3}}$

$K_c = \frac{[\mathrm{HI}]^2}{[\mathrm{H}_2][\mathrm{I}_2]} = \frac{(0.0158)^2}{(0.0021)^2} = 57$

该反应 $\Delta n = 0$，$K_p = K_c = 57$。

（2）平衡时总物质的量 $n_{\text{总}} = (0.0021 + 0.0021 + 0.0158) \times 10 = 0.20\mathrm{mol}$

$p_{\text{总}} = \frac{0.20 \times 8.31 \times 698}{10} = 1.2 \times 10^{2}\mathrm{kPa}$

$p(\mathrm{H}_2) = p(\mathrm{I}_2) = 120 \times \frac{0.021}{0.20} = 13\mathrm{kPa}$

$p(\mathrm{HI}) = 120 \times \frac{0.158}{0.20} = 95\mathrm{kPa}$

### 第3题 ⭐⭐ [普化]
> 来源：库外·普化

**题目**：
已知下列反应的平衡常数，试求 $298\mathrm{K}$ 时反应 $2\mathrm{N}_2\mathrm{O}(\mathrm{g}) + 3\mathrm{O}_2(\mathrm{g}) \rightleftharpoons 2\mathrm{N}_2\mathrm{O}_4(\mathrm{g})$ 的 $K_{c}$ 和 $K_{p}^{\mathrm{bar}}$。

(1) $\mathrm{N}_{2}(\mathrm{g}) + \frac{1}{2}\mathrm{O}_{2}(\mathrm{g}) \rightleftharpoons \mathrm{N}_{2}\mathrm{O}(\mathrm{g})$，$K_{c_1} = 3.4\times 10^{-18}$

(2) $\mathrm{N}_{2}\mathrm{O}_{4}(\mathrm{g}) \rightleftharpoons 2\mathrm{NO}_{2}(\mathrm{g})$，$K_{c_2} = 4.6 \times 10^{-3}$

(3) $\frac{1}{2}\mathrm{N}_{2}(\mathrm{g}) + \mathrm{O}_{2}(\mathrm{g}) = \mathrm{NO}_{2}(\mathrm{g})$，$K_{c_3} = 4.1 \times 10^{-9}$

**参考答案**：

$4\times(3)$式 $- 2\times(1)$式 $- 2\times(2)$式得所求反应。

$K_c = \frac{K_{c_3}^4}{K_{c_1}^2 \cdot K_{c_2}^2} = \frac{(4.1\times10^{-9})^4}{(3.4\times10^{-18})^2 \times (4.6\times10^{-3})^2} = 1.2\times10^{6}$

$K_p^{\mathrm{bar}} = K_c(RT)^{\Delta n} = 1.2\times10^{6} \times (0.083\times298)^{-3} = 79$

### 第4题 ⭐⭐ [普化]
> 来源：库外·普化

**题目**：
氧化银遇热分解：$2\mathrm{Ag_2O(s)} = 4\mathrm{Ag(s)} + \mathrm{O_2(g)}$。已知 $298\mathrm{K}$，$\mathrm{Ag_2O(s)}$ 的 $\Delta H_{\mathrm{f}}^{\ominus} = -31.1\mathrm{kJ\cdot mol^{-1}}$，$\Delta G_{\mathrm{f}}^{\ominus} = -11.2\mathrm{kJ\cdot mol^{-1}}$。求：

（1）在 $298\mathrm{K}$ 时 $\mathrm{Ag_2O}$-$\mathrm{Ag}$ 体系的 $p(\mathrm{O}_2)$；

（2）$\mathrm{Ag}_{2}\mathrm{O}$ 的热分解温度（分解时 $p(\mathrm{O}_2)=100\mathrm{kPa}$）。

**参考答案**：

（1）$\Delta G^{\ominus} = -2\times(-11.2) = 22.4\mathrm{kJ\cdot mol^{-1}}$

$\lg K^{\ominus} = \frac{-22.4\times10^{3}}{2.30\times8.31\times298} = -3.93$，$K^{\ominus} = 1.2\times10^{-4}$

$p(\mathrm{O}_2) = 1.2\times10^{-4}\mathrm{bar} = 1.2\times10^{-2}\mathrm{kPa}$

（2）分解时 $K^{\ominus} = p(\mathrm{O}_2)/p^{\ominus} = 1.00$

$\Delta H^{\ominus} = -2\times(-31.1) = 62.2\mathrm{kJ\cdot mol^{-1}}$

$\lg\frac{1.2\times10^{-4}}{1.00} = \frac{62.2\times10^{3}}{2.30\times8.31}\left(\frac{298 - T_1}{298\times T_1}\right)$

解得 $T_1 = 464\mathrm{K}$，即 $191^{}\mathrm{C}$。

### 第5题 ⭐⭐ [普化]
> 来源：库外·普化

> 🔁 **重复说明**：与本文第54题（[[06-09]]）为同一道题（固氮反应三途径），验算答案一致，两处保留。

**题目**：
将空气中的单质氮转变成各种含氮化合物的反应叫做固氮反应。根据 $\Delta G_{\mathrm{f}}^{\ominus}$，计算下列三种固氮反应 $25^{}\mathrm{C}$ 的 $\Delta G^{\ominus}$ 及 $K^{\ominus}$。从热力学角度看，选择哪个反应最好？

(1) $\mathrm{N}_{2} + \mathrm{O}_{2} \rightleftharpoons 2\mathrm{NO}$

(2) $2\mathrm{N}_{2} + \mathrm{O}_{2} \rightleftharpoons 2\mathrm{N}_{2}\mathrm{O}$

(3) $\mathrm{N}_{2} + 3\mathrm{H}_{2} = 2\mathrm{NH}_{3}$

**参考答案**：

（1）$\Delta G^{\ominus} = 2\times87.6 = 175.2\mathrm{kJ\cdot mol^{-1}}$，$K^{\ominus} = 2\times10^{-31}$

（2）$\Delta G^{\ominus} = 2\times103.7 = 207.4\mathrm{kJ\cdot mol^{-1}}$，$K^{\ominus} = 4\times10^{-37}$

（3）$\Delta G^{\ominus} = 2\times(-16.4) = -32.8\mathrm{kJ\cdot mol^{-1}}$，$K^{\ominus} = 5.8\times10^{5}$

第三个反应平衡常数远大于前两个，热力学上最优。

### 第6题 ⭐⭐ [普化]
> 来源：库外·普化

**题目**：
根据热力学数据计算 $\mathrm{BCl}_3$ 在 $298\mathrm{K}$ 时的饱和蒸气压及正常沸点。在 $298\mathrm{K}$ 和 $100\mathrm{kPa}$ 条件下，$\mathrm{BCl}_3$ 呈液态还是气态？

**参考答案**：

$\mathrm{BCl}_3(l) \to \mathrm{BCl}_3(g)$

$\Delta G^{\ominus} = (-388.7) - (-387.4) = -1.3\mathrm{kJ\cdot mol^{-1}}$

$\Delta G^{\ominus} = -2.30RT\lg K_p$，设 $p(\mathrm{BCl}_3) = x$ bar：

$1.3 = 2.30\times0.00831\times298\times\lg x$，$x = 1.7$

$p(\mathrm{BCl}_3) = 1.7\mathrm{bar} = 1.7\times10^{2}\mathrm{kPa}$

$\Delta H^{\ominus} = (-403.8)-(-427.2) = 23.4\mathrm{kJ\cdot mol^{-1}}$

$\Delta S^{\ominus} = 290.1 - 206.3 = 83.8\mathrm{J\cdot mol^{-1}\cdot K^{-1}}$

$T_b = \frac{\Delta H^{\ominus}}{\Delta S^{\ominus}} = \frac{23.4}{0.0838} = 279\mathrm{K}$

$298\mathrm{K} > 279\mathrm{K}$（沸点），$100\mathrm{kPa} < 170\mathrm{kPa}$（饱和蒸气压），故 $\mathrm{BCl}_3$ 呈**气态**。

### 第7题 ⭐⭐ [普化]
> 原题：[[06-13]]

**题目**：
已知反应 $\mathrm{N}_2 + \mathrm{O}_2 = 2\mathrm{NO}$ 的 $\Delta G^{\ominus}(2273\mathrm{K}) = +43.4\mathrm{kJ\cdot mol^{-1}}$。判断在 $2273\mathrm{K}$ 时，下列各种起始状态反应自发进行的方向。

| 状态 | $c(\mathrm{N_2})$/(mol·dm⁻³) | $c(\mathrm{O_2})$/(mol·dm⁻³) | $c(\mathrm{NO})$/(mol·dm⁻³) |
|:---:|:---:|:---:|:---:|
| I | 0.81 | 0.81 | 0 |
| II | 0.98 | 0.68 | 0.26 |
| III | 1.0 | 1.0 | 1.0 |

**参考答案**：

$\lg K_p^{\ominus} = \frac{-43.4\times10^{3}}{2.30\times8.31\times2273} = -0.999$，$K_p^{\ominus} = 0.100$

$\Delta n = 0$，$K_c^{\ominus}$ 数值上等于 $K_p^{\ominus}$。

状态I：$Q_c = \frac{0^2}{0.81^2} = 0 < K_c^{\ominus}$，正向进行

状态II：$Q_c = \frac{0.26^2}{0.98\times0.68} = 0.10 = K_c^{\ominus}$，已达平衡

状态III：$Q_c = \frac{1.0^2}{1.0^2} = 1.0 > K_c^{\ominus}$，逆向进行

### 第51题 ⭐⭐ [普化]

### 第52题 ⭐⭐ [普化]
> 原题：[[06-02]]

**题目**：

已知 $\mathrm{N}_2 + 3\mathrm{H}_2 \rightleftharpoons 2\mathrm{NH}_3$ $K_{p}(673\mathrm{K}) = 6.1 \times 10^{-4}$ 。问此 $K_{p}$ 与下述3个 $K$ 的意义是否相同？在进行合成氨反应的平衡计算时，是否可用任意一种 $K_{p}$ ？

(1) $\frac{1}{2}\mathrm{N}_{2} + \frac{3}{2}\mathrm{H}_{2} \rightleftharpoons \mathrm{NH}_{3}$ $K_{p}^{\prime} = ?$

(2) $\frac{1}{3} \mathrm{~N}_{2} + \mathrm{H}_{2} \rightleftharpoons \frac{2}{3} \mathrm{NH}_{3}$ $K_{p}^{\prime \prime} = ?$

(3) $2\mathrm{NH}_{3} \rightleftharpoons \mathrm{N}_{2} + 3\mathrm{H}_{2}$ $K_{p}^{\prime \prime} = ?$

**参考答案**：

解 (1) $K_{p}^{\prime} = \sqrt{K_{p}} = 0.025$ ；(2) $K_{p}^{\prime \prime} = \sqrt[3]{K_{p}} = 0.085$ ；(3) $K_{p}^{\prime \prime \prime} = \frac{1}{K_{p}} = 1.6 \times 10^{3}$

这 4 个 K 意义相同, 讨论合成氨反应时, 可用任一种 $K_{p}$ 。注意, 当选定一种 $K_{p}$ 后, 必须按照它所对应的化学方程式进行计算。

### 第53题 ⭐⭐ [普化]
> 原题：[[06-04]]

**题目**：

已知 $\mathrm{FeO(s) + CO(g)}\rightleftharpoons \mathrm{Fe(s) + CO_2(g)}$ 的 $K_{c}(1273\mathrm{K}) = 0.50$ 。若起始浓度 $c(\mathrm{CO}) = 0.050\mathrm{mol}\cdot \mathrm{dm}^{-3},c(\mathrm{CO}_2) = 0.010\mathrm{mol}\cdot \mathrm{dm}^{-3}$ ，问：

（1）反应物、生成物的平衡浓度各是多少？
（2）CO的转化率是多少？
（3）增加FeO的量，对平衡有何影响？

**参考答案**：

$$
\begin{array}{r l r}{\mathrm{解}}&{(1) \mathrm{FeO(s)} + \mathrm{CO(g)} \rightleftharpoons \mathrm{Fe(s)} + \mathrm {CO_ {2} (g)}}&{K _ {c} (1 2 7 3 \mathrm{K}) = 0. 5}\\{\frac {\text {起始浓度}}{\mathrm{mol} \cdot \mathrm{dm} ^ {- 3}}}&{0. 0 5 0}&{0. 0 1 0}\\{\frac {\text {平衡浓度}}{\mathrm{mol} \cdot \mathrm{dm} ^ {- 3}}}&{0. 0 5 0 - x}&{0. 0 1 0 + x}\end{array}
$$

$$
K _ {c} = \frac {[ \mathrm{CO} _ {2} ]}{[ \mathrm{CO} ]} = \frac {0 . 0 1 0 + x}{0 . 0 5 0 - x} = 0. 5 0, \qquad x = 0. 0 1 0
$$

$$
[ \mathrm{CO} ] = 0. 0 4 0 \mathrm{mol} \cdot \mathrm{dm} ^ {- 3}, \quad [ \mathrm{CO} _ {2} ] = 0. 0 2 0 \mathrm{mol} \cdot \mathrm{dm} ^ {- 3}
$$

(2) CO 转化率为 $\frac{0.010\mathrm{mol}\cdot\mathrm{dm}^{-3}}{0.050\mathrm{mol}\cdot\mathrm{dm}^{-3}}\times 100\% = 20\%$

(3) 增加 FeO 的量, 对平衡无影响。

### 第54题 ⭐⭐ [普化]
> 原题：[[06-09]]

**题目**：

将空气中的单质氮转变成各种含氮的化合物的反应叫做固氮反应。根据 $\Delta G_{\mathrm{f}}^{\ominus}$ ，计算下列三种固氮反应 $25^{\circ} \mathrm{C}$ 的 $\Delta G^{\ominus}$ 及 $K^{\ominus}$ 。从热力学的角度看，选择哪个反应最好？

(1) $\mathrm{N}_{2} + \mathrm{O}_{2} \rightleftharpoons 2 \mathrm{NO}$

(2) $2 \mathrm{~N}_{2} + \mathrm{O}_{2} \rightleftharpoons 2 \mathrm{~N}_{2} \mathrm{O}$

(3) $\mathrm{N}_{2} + 3\mathrm{H}_{2} = 2\mathrm{NH}_{3}$

**参考答案**：

$$2 \mathrm{NH} _ {3}$$

解 (1) $\Delta G^{\ominus} = 2 \times \Delta G_{\mathrm{f}}^{\ominus} (\mathrm{NO}, \mathrm{g}) = 2 \times 87.6 \mathrm{~kJ} \cdot \mathrm{mol}^{-1} = 175.2 \mathrm{~kJ} \cdot \mathrm{mol}^{-1}$

$$\lg K ^ {\ominus} = \frac {- 1 7 5 . 2 \times 1 0 ^ {3} \mathrm{J} \cdot \mathrm{mol} ^ {- 1}}{2 . 3 0 \times 8 . 3 1 \mathrm{J} \cdot \mathrm{mol} ^ {- 1} \cdot \mathrm{K} ^ {- 1} \times 2 9 8 \mathrm{K}} = - 3 0. 8, \quad K ^ {\ominus} = 2 \times 1 0 ^ {- 3 1}$$

$$\Delta G ^ {\ominus} = 2 \times \Delta G _ {1} ^ {\ominus} (\mathrm{N} _ {2} \mathrm{O}, \mathrm{g}) = 2 \times 1 0 3. 7 \mathrm{kJ} \cdot \mathrm{mol} ^ {- 1} = 2 0 7. 4 \mathrm{kJ} \cdot \mathrm{mol} ^ {- 1}$$

$$\lg K ^ {\ominus} = \frac {- 2 0 7 . 4 \times 1 0 ^ {3} \mathrm{J} \cdot \mathrm{mol} ^ {- 1}}{2 . 3 0 \times 8 . 3 1 \mathrm{J} \cdot \mathrm{mol} ^ {- 1} \cdot \mathrm{K} ^ {- 1} \times 2 9 8 \mathrm{K}} = - 3 6. 4, \quad K ^ {\ominus} = 4 \times 1 0 ^ {- 3 7}$$

$$\Delta G ^ {\ominus} = 2 \times \Delta G _ {f} ^ {\ominus} (\mathrm{NH} _ {3}, \mathrm{g}) = 2 \times (- 1 6. 4) \mathrm{kJ} \cdot \mathrm{mol} ^ {- 1} = - 3 2. 8 \mathrm{kJ} \cdot \mathrm{mol} ^ {- 1}$$

$$\lg K ^ {\ominus} = \frac {3 2 . 8 \times 1 0 ^ {3} \mathrm{J} \cdot \mathrm{mol} ^ {- 1}}{2 . 3 0 \times 8 . 3 1 \mathrm{J} \cdot \mathrm{mol} ^ {- 1} \cdot \mathrm{K} ^ {- 1} \times 2 9 8 \mathrm{K}} = 5. 7 6, \quad K ^ {\ominus} = 5. 8 \times 1 0 ^ {5}$$

计算结果表明，第三个反应的平衡常数比第一、二个反应大得多，故选择第三个反应较好。

### 第55题 ⭐⭐ [普化]
> 原题：[[06-29]]

**题目**：

估算常压下单质溴的沸点。已知液态溴与气态溴的相变反应 $Br_2(l) \rightleftharpoons Br_2(g)$ 的热力学参数为：
$$\Delta_r H_m^\circ = 30.9 \, \text{kJ} \cdot \text{mol}^{-1}$$
$$\Delta_r S_m^\circ = 93.3 \, \text{J} \cdot \text{mol}^{-1} \cdot \text{K}^{-1}$$

**参考答案**：

在沸点时，液态溴与气态溴达到平衡，$\Delta_r G_m^\circ = 0$。

根据公式 $\Delta_r G_m^\circ = \Delta_r H_m^\circ - T \Delta_r S_m^\circ = 0$，解得：
$$T = \frac{\Delta_r H_m^\circ}{\Delta_r S_m^\circ} = \frac{30.9 \times 10^3}{93.3} \approx 331 \, \text{K}$$

### 第9题 ⭐⭐⭐ [普化]
> 来源：库外·普化

**题目**：

$Q_c = \frac{0.15^2}{0.822 \times 0.028^3} = \mathbf{1.25\times 10^{3}}$

$Q_c < K_c$，反应**正向进行**。

(2) 原平衡气体 $n_{\text{总}} = 1.00$ mol（$V = 1.0\mathrm{L}$）。注入体积 $xV$ 的纯 $\mathrm{N_2}$（同温同压）即注入 $x$ mol $\mathrm{N_2}$，恒压下总气体变为 $(1+x)$ mol，体积变为 $(1+x)V$：

$c''(\mathrm{N_2}) = \frac{0.11+x}{1+x}$，$c''(\mathrm{H_2}) = \frac{0.14}{1+x}$，$c''(\mathrm{NH_3}) = \frac{0.75}{1+x}\ \mathrm{mol/L}$

$Q_c = \frac{[0.75/(1+x)]^2}{[(0.11+x)/(1+x)] \cdot [0.14/(1+x)]^3} = K_c \cdot \frac{0.11(1+x)^2}{0.11+x}$

令 $Q_c = K_c$：$\frac{0.11(1+x)^2}{0.11+x} = 1$，解得 $x = 7.1$。

当 $0 < x < 7.1$ 时 $Q_c < K_c$，反应**正向进行**；当 $x > 7.1$ 时 $Q_c > K_c$，反应**逆向进行**。

### 第44题 ⭐⭐⭐ [初赛讲义]
> 来源：库外·初赛讲义

**题目**：
普鲁卡因是一种常用的麻醉剂，其化学名称为 $2$-(二乙氨基)乙基-$4$-氨基苯甲酸酯。它具有碱性（$\mathrm{p}K_{\mathrm{b}} = 6.6$），本题中将其简写为 $\mathrm{B}$，其共轭酸写为 $\mathrm{HB^+}$。在人体中，普鲁卡因需要穿过细胞膜后与细胞内的受体结合才能发挥麻醉作用。穿过细胞膜时必须以 $\mathrm{B}$ 的形式通过，速率 $r_1 = k_1[\mathrm{B}]$；与受体结合时必须以 $\mathrm{HB^+}$ 形式发挥作用，速率 $r_2 = k_2[\mathrm{HB^+}]$。求刚注射药物瞬间，普鲁卡因发挥麻醉作用的最佳 $\mathrm{pH}$。已知 $k_1 = k_2 = 0.0010\mathrm{s^{-1}}$。

**参考答案**：

总麻醉速率 $r = k_1[\mathrm{B}] \cdot k_2[\mathrm{HB^+}]$。设总浓度 $c = [\mathrm{B}] + [\mathrm{HB^+}]$：

$[\mathrm{B}] = \frac{K_{\mathrm{a}} c}{K_{\mathrm{a}} + [\mathrm{H}^+]}$，$[\mathrm{HB^+}] = \frac{[\mathrm{H}^+] c}{K_{\mathrm{a}} + [\mathrm{H}^+]}$

$r = k_1 k_2 c^2 \cdot \frac{K_{\mathrm{a}} [\mathrm{H}^+]}{(K_{\mathrm{a}} + [\mathrm{H}^+])^2}$

对 $[\mathrm{H}^+]$ 求导令为零，得最佳 $[\mathrm{H}^+] = K_{\mathrm{a}}$，即 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} = 14 - 6.6 = \mathbf{7.4}$

### 第45题 ⭐⭐⭐ [初赛讲义]
> 来源：库外·初赛讲义

**题目**：
$4000\mathrm{K}$ 下，在 $\mathrm{X(s)}$ 和 $\mathrm{Y_2(g)}$ 的平衡体系中，可能存在以下物种：

| 物质 | $\Delta_{\mathrm{f}}G^{\ominus}/(\mathrm{kJ\cdot mol^{-1}})$ |
|:---|:---:|
| $\mathrm{X(s)}$ | $0$ |
| $\mathrm{X(g)}$ | $92.427$ |
| $\mathrm{Y_2(g)}$ | $0$ |
| $\mathrm{Y(g)}$ | $-15.541$ |
| $\mathrm{XY_2(g)}$ | $353.687$ |
| $\mathrm{XY(g)}$ | $194.335$ |

向某恒压容器中充入 $0.100\mathrm{mol}$ $\mathrm{XY_2(g)}$ 和 $0.100\mathrm{mol}$ $\mathrm{Y_2(g)}$ 并达平衡，此时容器体积为 $20.0\mathrm{L}$。求体系中 $\mathrm{X(s)}$ 的物质的量及各气态物种的分压。

**参考答案**：

$\Delta_{\mathrm{f}}G^{\ominus}(\mathrm{XY_2,g}) = 353.7\mathrm{kJ/mol} > 0$，$\mathrm{XY_2}$ 完全分解：

$\mathrm{XY_2(g)} \to \mathrm{X(s)} + \mathrm{Y_2(g)}$，产生 $0.100\mathrm{mol}$ $\mathrm{X(s)}$，总 $Y$ 原子 $0.400$ mol（$\mathrm{Y_2}$ 计 $0.200$ mol）。

主要平衡（$T = 4000\mathrm{K}$，$RT = 33.26\mathrm{kJ/mol}$，$p^{\ominus} = 100\mathrm{kPa}$）：

- $\mathrm{Y_2(g)} \rightleftharpoons 2\mathrm{Y(g)}$：$\Delta_r G^{\ominus} = 2\times(-15.541) = -31.082\mathrm{kJ/mol}$，$K_2 = e^{31082/33256} = 2.546$，即 $p(\mathrm{Y})^2/p(\mathrm{Y_2}) = 254.6\ \mathrm{kPa}$
- $\mathrm{X(s)} \rightleftharpoons \mathrm{X(g)}$：$K_1 = e^{-92427/33256} = 0.0621$，$p(\mathrm{X}) = 6.2\ \mathrm{kPa}$（有 $\mathrm{X(s)}$ 存在时恒定）
- $\mathrm{X(s)} + \tfrac{1}{2}\mathrm{Y_2(g)} \rightleftharpoons \mathrm{XY(g)}$：$\Delta_r G^{\ominus} = \Delta_{\mathrm{f}}G^{\ominus}(\mathrm{XY,g}) = 194.335\mathrm{kJ/mol}$（$\mathrm{X(s)}$、$\mathrm{Y_2(g)}$ 为单质取 0），$K_3 = e^{-194335/33256} = 2.9\times10^{-3}$，$p(\mathrm{XY}) = K_3\sqrt{p(\mathrm{Y_2})p^{\ominus}} = 0.029\sqrt{p(\mathrm{Y_2})}$
- $\mathrm{X(s)} + \mathrm{Y_2(g)} \rightleftharpoons \mathrm{XY_2(g)}$：$\Delta_r G^{\ominus} = \Delta_{\mathrm{f}}G^{\ominus}(\mathrm{XY_2,g}) = 353.687\mathrm{kJ/mol}$，$K_4 = e^{-353687/33256} = 2.4\times10^{-5}$，$p(\mathrm{XY_2}) = 2.4\times10^{-5}p(\mathrm{Y_2})$

设 $u = \sqrt{p(\mathrm{Y_2})}$，由 $Y$ 原子守恒（$n_i = p_iV/RT = p_i\times 20.0/(33.26\times 10^3) = p_i\times 6.014\times10^{-4}$ mol，$p_i$ 以 kPa 计）：

$[2p(\mathrm{Y_2}) + p(\mathrm{Y}) + p(\mathrm{XY}) + 2p(\mathrm{XY_2})]\times 6.014\times10^{-4} = 0.400$，即 $2p(\mathrm{Y_2}) + p(\mathrm{Y}) + p(\mathrm{XY}) + 2p(\mathrm{XY_2}) = 665.2\ \mathrm{kPa}$

代入 $p(\mathrm{Y}) = 15.96u$，$p(\mathrm{XY}) = 0.029u$，$p(\mathrm{XY_2}) = 2.4\times10^{-5}u^2$：$2.000u^2 + 15.99u = 665.2$，解得 $u = 14.7$

$p(\mathrm{Y_2}) = \mathbf{215\mathrm{kPa}}$，$p(\mathrm{Y}) = \mathbf{234\mathrm{kPa}}$，$p(\mathrm{X}) = 6.2\mathrm{kPa}$，$p(\mathrm{XY}) = 0.43\mathrm{kPa}$，$p(\mathrm{XY_2}) = 0.005\mathrm{kPa}$

总压 $P = 215+234+6.2+0.43+0.005 = \mathbf{456\mathrm{kPa}}$

$n(\mathrm{X,s}) = 0.100 - (6.2+0.43+0.005)\times 6.014\times10^{-4} = 0.100-0.0040 = \mathbf{0.096\mathrm{mol}}$

### 第46题 ⭐⭐⭐ [赵鑫光]
> 原题：[[题-赵鑫光-动力学-习16]]

**题目**：
乙苯脱氢制苯乙烯的反应如下：

$$\mathrm{C_6H_5\text{-}C_2H_5(g) \longrightarrow C_6H_5\text{-}C_2H_3(g) + H_2(g)}$$

若 $873\mathrm{K}$ 时其 $K^{\ominus} = 0.178$，则在该温度及平衡压力为 $101325\ \mathrm{Pa}$ 下，乙苯的转化率为（）

A. 18.9%　B. 15.1%　C. 30.2%　D. 38.9%

**参考答案**：

设起始 $1.00\ \mathrm{mol}$ 乙苯，转化率 $\alpha$，平衡时乙苯 $(1-\alpha)\ \mathrm{mol}$，苯乙烯 $\alpha\ \mathrm{mol}$，$\mathrm{H_2}$ $\alpha\ \mathrm{mol}$。

总物质的量 $= 1+\alpha$，各组分摩尔分数：$x(\text{乙苯})=\dfrac{1-\alpha}{1+\alpha}$，$x(\text{苯乙烯})=x(\mathrm{H_2})=\dfrac{\alpha}{1+\alpha}$。

$$K^{\ominus} = \frac{x(\text{苯乙烯})\cdot x(\mathrm{H_2})}{x(\text{乙苯})} = \frac{\alpha^2}{(1-\alpha)(1+\alpha)} = \frac{\alpha^2}{1-\alpha^2} = 0.178$$

$\alpha^2 = 0.178(1-\alpha^2)$，$\alpha^2 = \dfrac{0.178}{1.178} = 0.1511$，$\alpha = 0.389 = 38.9\%$

**答案：D**

### 第47题 ⭐⭐⭐ [赵鑫光]
> 来源：库外·赵鑫光

**题目**：
$298\mathrm{K}$ 时 $\mathrm{NH_4Cl(s)}$ 按下式分解：

$$\mathrm{NH_4Cl(s) = NH_3(g) + HCl(g)} \quad \Delta_r G_m^{\ominus} = 92.0\ \mathrm{kJ/mol}$$

则该体系的总压力（$\mathrm{kPa}$）为

A. $1.76 \times 10^{-6}$　B. $6.86 \times 10^{-7}$　C. $8.67 \times 10^{-4}$　D. $5.45 \times 10^{-8}$

**参考答案**：

$$K^{\ominus} = e^{-\Delta_r G_m^{\ominus}/(RT)} = e^{-92000/(8.314\times298)} = e^{-37.14} = 7.4\times 10^{-17}$$

设平衡时 $p(\mathrm{NH_3}) = p(\mathrm{HCl}) = p$，则：

$$K^{\ominus} = \frac{p(\mathrm{NH_3})}{p^{\ominus}}\cdot\frac{p(\mathrm{HCl})}{p^{\ominus}} = \frac{p^2}{(p^{\ominus})^2}$$

$$p^2 = K^{\ominus}\times(p^{\ominus})^2 = 7.4\times 10^{-17}\times(101.325)^2 = 7.6\times 10^{-13}$$

$p = 8.7\times 10^{-7}\ \mathrm{kPa}$，总压 $= 2p = 1.74\times 10^{-6}\ \mathrm{kPa}$

**答案：A**

### 第48题 ⭐⭐⭐ [赵鑫光]

**题目**：
在一定温度下，密闭容器中 $100\ \mathrm{kPa}$ 的 $\mathrm{NO_2}$ 发生聚合反应，$2\mathrm{NO_2} = \mathrm{N_2O_4}$，达平衡时最终压力为 $85\ \mathrm{kPa}$，则 $\mathrm{NO_2}$ 的聚合百分率为（）

A. 15%　B. 30%　C. 45%　D. 60%

**参考答案**：

设初始 $\mathrm{NO_2}$ 为 $n\ \mathrm{mol}$，聚合百分率（转化率）为 $\alpha$。

平衡时：$n(\mathrm{NO_2}) = n(1-\alpha)$，$n(\mathrm{N_2O_4}) = n\alpha/2$

总物质的量 $= n(1-\alpha) + n\alpha/2 = n(1-\alpha/2)$

恒温恒容下，$\dfrac{p_0}{p_{\text{eq}}} = \dfrac{n_0}{n_{\text{eq}}}$：

$$\frac{100}{85} = \frac{1}{1-\alpha/2}$$

$1-\alpha/2 = 0.85$，$\alpha/2 = 0.15$，$\alpha = 30\%$

**答案：B**

### 第49题 ⭐⭐⭐ [赵鑫光]

**题目**：
在 $21.8^{}\mathrm{C}$ 时，反应 $\mathrm{NH_4HS(s) = NH_3(g) + H_2S(g)}$ 的标准平衡常数 $K^{\ominus} = 0.070$，则平衡时混合气体的总压是

A. $7.0\ \mathrm{kPa}$　B. $26\ \mathrm{kPa}$　C. $53\ \mathrm{kPa}$　D. $0.26\ \mathrm{kPa}$

$\mathrm{NH_4HS}$ 分解产生的 $\mathrm{NH_3}$ 和 $\mathrm{H_2S}$ 等物质的量，设各为 $p/2$（$p$ 为总压）。

$$p^2 = 4K^{\ominus}(p^{\ominus})^2 = 4\times 0.070\times(100)^2 = 2800$$

$p = 52.9\ \mathrm{kPa}$

**答案：C**

### 第50题 ⭐⭐⭐ [赵鑫光]
> 来源：库外·赵鑫光

**题目**：
某化合物 $\mathrm{A}$ 的水合晶体 $\mathrm{A\cdot 3H_2O}$ 的脱水反应过程：

$$\mathrm{A\cdot 3H_2O(s) = A\cdot 2H_2O(s) + H_2O(g)} \quad K_1^{\ominus}$$

$$\mathrm{A\cdot 2H_2O(s) = A\cdot H_2O(s) + H_2O(g)} \quad K_2^{\ominus}$$

$$\mathrm{A\cdot H_2O(s) = A(s) + H_2O(g)} \quad K_3^{\ominus}$$

为使 $\mathrm{A\cdot 2H_2O}$ 晶体保持稳定（不风化也不潮解），容器中的水蒸气压力 $p(\mathrm{H_2O})$ 与平衡常数的关系应满足

A. $K_2^{\ominus} > p(\mathrm{H_2O})/p^{\ominus} > K_3^{\ominus}$　B. $p(\mathrm{H_2O})/p^{\ominus} > K_2^{\ominus}$　C. $p(\mathrm{H_2O})/p^{\ominus} > K_1^{\ominus}$　D. $K_1^{\ominus} > p(\mathrm{H_2O})/p^{\ominus} > K_2^{\ominus}$

**参考答案**：

$\mathrm{A\cdot 2H_2O}$ 稳定的条件：

- 不风化（不失去结晶水）：$\mathrm{A\cdot 2H_2O}$ 不应转化为 $\mathrm{A\cdot H_2O}$，需 $p(\mathrm{H_2O})/p^{\ominus} > K_2^{\ominus}$
- 不潮解（不吸收水变成 $\mathrm{A\cdot 3H_2O}$）：需 $p(\mathrm{H_2O})/p^{\ominus} < K_1^{\ominus}$

故 $K_1^{\ominus} > p(\mathrm{H_2O})/p^{\ominus} > K_2^{\ominus}$

**答案：D**
