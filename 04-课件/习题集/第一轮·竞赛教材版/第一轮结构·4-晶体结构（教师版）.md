### 第3题

> 来源：真题·讲评层

NaCl 晶体属于立方晶系，面心立方结构。使用 $\mathrm{Cu\ K\alpha}$ X 射线（$\lambda = 154.18\ \mathrm{pm}$）进行粉末衍射，测得 (200) 晶面的衍射角 $2\theta = 31.70^\circ$。

(1) 计算 NaCl 晶胞参数 $a$（单位 pm）。

(2) NaCl 的实测密度为 $2.165\ \mathrm{g\cdot cm^{-3}}$，计算每个晶胞中含有的 NaCl 化学式数目 $Z$，并验证上述晶胞参数的合理性。

已知：$M(\mathrm{NaCl}) = 58.44\ \mathrm{g\cdot mol^{-1}}$，$N_A = 6.022 \times 10^{23}\ \mathrm{mol^{-1}}$。

![[13-4-bragg-reflection.jpg]]

![[nacl-structure.jpg]]

**参考答案**：

**分析**
1. **Bragg 方程**：$n\lambda = 2d\sin\theta$，其中 $\theta = 2\theta/2$ 是 Bragg 角
2. 立方晶系：(200) 晶面间距 $d_{200} = \frac{a}{\sqrt{h^2+k^2+l^2}} = \frac{a}{\sqrt{4+0+0}} = \frac{a}{2}$
3. 由 $d_{200}$ → $a$ → 晶胞体积 $V = a^3$ → 理论密度 → 验证 $Z$

**(1) 计算晶胞参数 $a$**

Bragg 角：$\theta = 31.70^\circ/2 = 15.85^\circ$

一级衍射（$n=1$）：
$$d_{200} = \frac{\lambda}{2\sin\theta} = \frac{154.18}{2 \times \sin 15.85^\circ} = \frac{154.18}{2 \times 0.2731} = \frac{154.18}{0.5462} = 282.3\ \mathrm{pm}$$

$$a = 2 \times d_{200} = 2 \times 282.3 = 564.6\ \mathrm{pm}$$

**(2) 验证 $Z$**

晶胞体积：$V = a^3 = (564.6 \times 10^{-10}\ \mathrm{cm})^3 = (5.646 \times 10^{-8})^3 = 1.800 \times 10^{-22}\ \mathrm{cm^3}$

密度公式：$\rho = \frac{Z \cdot M}{N_A \cdot V}$

$$Z = \frac{\rho \cdot N_A \cdot V}{M} = \frac{2.165 \times 6.022 \times 10^{23} \times 1.800 \times 10^{-22}}{58.44}$$

$$Z = \frac{2.165 \times 6.022 \times 1.800 \times 10^{1}}{58.44} = \frac{2.165 \times 108.4}{58.44} = \frac{234.7}{58.44} = 4.02 \approx 4$$

NaCl 是面心立方结构，每个晶胞预期含有 $Z = 4$ 个 NaCl 化学式（Na⁺: 8×1/8 + 6×1/2 = 4; Cl⁻: 12×1/4 + 1 = 4）。

**验证通过**  $Z$ 的计算值与理论值一致，晶胞参数合理。

(1) $a = 565\ \mathrm{pm}$（564.6 pm）

(2) $Z \approx 4$，与 NaCl 面心立方结构的理论值一致。

### 第4题

> 来源：真题·讲评层

已知下列离子半径（单位：pm）：

| 离子 | 半径 |
|------|------|
| $\mathrm{Cs^+}$ | 167 |
| $\mathrm{Na^+}$ | 102 |
| $\mathrm{Zn^{2+}}$ | 74 |
| $\mathrm{Cl^-}$ | 181 |
| $\mathrm{O^{2-}}$ | 140 |

(1) 根据离子半径比规则，分别计算 $\mathrm{CsCl}$、$\mathrm{NaCl}$、$\mathrm{ZnS}$（实际为 $\mathrm{Zn^{2+}/S^{2-}}$，$r_{\mathrm{S^{2-}}} = 184\ \mathrm{pm}$）的 $r_+/r_-$ 值，并判断各自预期的阳离子配位数。

(2) 半径比规则预测的配位数与实际晶体结构是否一致？简要说明半径比规则的适用范围和局限性。

(3) 在高压下，$\mathrm{CsCl}$ 会从 CsCl 型转变为 NaCl 型，还是 NaCl 型转变为 CsCl 型？从离子半径的角度简要解释。

![[晶体结构-NaCl-CsCl-ZnS对比.关系图.png]]

![[半径比规则-配位数判断.决策图.png]]

**参考答案**：

**分析**
1. 半径比规则：$r_+/r_-$ 决定阳离子在阴离子密堆积中的配位数和占据的空隙类型
2. 临界值：$r_+/r_- < 0.225$（CN=3-4），$0.225{-}0.414$（CN=4, ZnS型），$0.414{-}0.732$（CN=6, NaCl型），$>0.732$（CN=8, CsCl型）
3. 高压使离子压缩，$r_-$ 比 $r_+$ 更易压缩（阴离子电子云更弥散），$r_+/r_-$ 增大

**(1) 半径比计算**

$$\mathrm{CsCl}:\ \frac{r_+}{r_-} = \frac{167}{181} = 0.923 > 0.732$$
预测配位数：**CN = 8**（CsCl 型结构）

$$\mathrm{NaCl}:\ \frac{r_+}{r_-} = \frac{102}{181} = 0.564 \in [0.414, 0.732]$$
预测配位数：**CN = 6**（NaCl 型结构）

$$\mathrm{ZnS}:\ \frac{r_+}{r_-} = \frac{74}{184} = 0.402 \in [0.225, 0.414)$$
预测配位数：**CN = 4**（ZnS 型结构，闪锌矿或纤锌矿）

**(2) 半径比规则的评价**

上述三个例子中预测与实际**一致**。

半径比规则是**经验的半定量规则**，适用范围和局限性：

- 适用于**纯离子晶体**（碱金属卤化物、碱土金属氧化物等），假设离子为刚性球
- 对于**共价成分显著**的晶体（如 $\mathrm{AgI}$、$\mathrm{HgS}$），预测可能失准
- 忽略了**极化效应**——大阳离子与小阴离子间极化作用会降低有效配位数
- 只考虑了阳离子配位数，对复杂结构（如钙钛矿、尖晶石）需结合其他规则

**(3) 高压下的相转变**

在高压下，$\mathrm{CsCl}$ 保持 CsCl 型（CN=8），而**NaCl 型可能在极高压力下转变为 CsCl 型**。因为高压使阴离子（$\mathrm{Cl^-}$）比阳离子更易被压缩，$r_+/r_-$ 增大，当超过 0.732 阈值时 NaCl 型 → CsCl 型。

反过来，$\mathrm{CsCl}$ 在高压下不会变为 NaCl 型（$r_+/r_-$ 本已 > 0.732，高压使其更大）。

> 补充：实际实验中，NaCl 在约 30 GPa 压力下确实转变为 CsCl 型结构。

### 第5题

> 来源：真题·讲评层

钙钛矿（$\mathrm{CaTiO_3}$）是矿物钙钛矿的代表，其结构是众多功能材料（如铁电体 $\mathrm{BaTiO_3}$、高温超导相关结构等）的母结构。钙钛矿属于立方晶系，空间群 $Pm\bar{3}m$。

(1) 在理想立方钙钛矿结构中，指出 $\mathrm{Ca^{2+}}$、$\mathrm{Ti^{4+}}$、$\mathrm{O^{2-}}$ 各占据晶胞中的什么位置（写出分数坐标）。

(2) 分别指出 $\mathrm{Ca^{2+}}$ 和 $\mathrm{Ti^{4+}}$ 的氧配位数（即与几个 $\mathrm{O^{2-}}$ 相邻），以及 $\mathrm{O^{2-}}$ 的阳离子配位环境（与几个 $\mathrm{Ca^{2+}}$ 和几个 $\mathrm{Ti^{4+}}$ 相邻）。

(3) Goldschmidt 容忍因子 $t = \dfrac{r_A + r_X}{\sqrt{2}(r_B + r_X)}$ 是判断钙钛矿结构稳定性的经验参数。已知 $r_{\mathrm{Ca^{2+}}} = 100\ \mathrm{pm}$，$r_{\mathrm{Ti^{4+}}} = 61\ \mathrm{pm}$，$r_{\mathrm{O^{2-}}} = 140\ \mathrm{pm}$，计算 $\mathrm{CaTiO_3}$ 的容忍因子 $t$。钙钛矿结构的稳定范围通常为 $0.8 < t < 1.0$，$\mathrm{CaTiO_3}$ 是否在此范围内？

![[perovskite_catio3_structure.jpg]]

**参考答案**：

**分析**
1. 钙钛矿 $\mathrm{ABX_3}$ 结构：A 为大阳离子（12 配位），B 为小阳离子（6 配位），X 为阴离子
2. 理想立方结构中 A 在顶点，B 在体心，X 在面心
3. 容忍因子 $t=1$ 对应理想立方钙钛矿结构；$t$ 偏离 1 时结构发生畸变（四方、正交等）

**(1) 各离子的分数坐标**

理想立方钙钛矿结构（空间群 $Pm\bar{3}m$，$Z = 1$）：

| 离子 | Wyckoff 位置 | 分数坐标 |
|------|-------------|---------|
| $\mathrm{Ca^{2+}}$（A位） | $1a$ | $(0, 0, 0)$ |
| $\mathrm{Ti^{4+}}$（B位） | $1b$ | $\left(\frac{1}{2}, \frac{1}{2}, \frac{1}{2}\right)$ |
| $\mathrm{O^{2-}}$（X位） | $3d$ | $\left(\frac{1}{2}, \frac{1}{2}, 0\right)$，$\left(\frac{1}{2}, 0, \frac{1}{2}\right)$，$\left(0, \frac{1}{2}, \frac{1}{2}\right)$ |

**(2) 配位数**

- **$\mathrm{Ca^{2+}}$（A位）**：被 12 个 $\mathrm{O^{2-}}$ 包围（$\mathrm{Ca—O}$ 距离 $= \frac{a}{\sqrt{2}}$），**CN = 12**（立方八面体配位）

- **$\mathrm{Ti^{4+}}$（B位）**：被 6 个 $\mathrm{O^{2-}}$ 包围（$\mathrm{Ti—O}$ 距离 $= \frac{a}{2}$），**CN = 6**（正八面体配位）

- **$\mathrm{O^{2-}}$（X位）**：每个 $\mathrm{O^{2-}}$ 被 4 个 $\mathrm{Ca^{2+}}$（以共面方式）和 2 个 $\mathrm{Ti^{4+}}$（线性 $\mathrm{Ti—O—Ti}$ 排列）包围，即 **CN = 4（Ca）+ 2（Ti）= 6** 个阳离子。

可以理解为 $\mathrm{O^{2-}}$ 处于 $\mathrm{Ti^{4+}}$ 八面体的顶点 = $\mathrm{Ca^{2+}}$ 立方八面体的棱中心。

**(3) 容忍因子**

$$t = \frac{r_{\mathrm{Ca}} + r_{\mathrm{O}}}{\sqrt{2}(r_{\mathrm{Ti}} + r_{\mathrm{O}})} = \frac{100 + 140}{\sqrt{2} \times (61 + 140)}$$

$$= \frac{240}{\sqrt{2} \times 201} = \frac{240}{284.3} = 0.844$$

$t = 0.844 \in (0.8, 1.0)$，在钙钛矿结构的稳定范围内。但由于 $t < 1$，$\mathrm{CaTiO_3}$ 不是理想立方结构，实际在室温下为正交晶系（$\mathrm{GdFeO_3}$ 型畸变，$\mathrm{Ti—O—Ti}$ 键弯曲）。

### 第7题

> 来源：汇智竞赛题目

由烷基镁热分解制得镁的氢化物。实验测定，该氢化物中氢的质量分数为 $7.6\%$ ，氢的密度为 $0.101\mathrm{g/cm^3}$ 镁和氢的核间距为 $194.8\mathrm{pm}$ 。已知氢原子的共价半径为 $37\mathrm{pm}$ ， $\mathrm{Mg}^{2+}$ 的离子半径为 $72\mathrm{pm}$ 。

**参考答案**：

39-1 写出该氢化物中氢的存在形式，并简述理由。

39-2 将上述氢化物与金属镍在一定条件下用球磨机研磨，可制得化学式为 $Mg_{2}NiH_{4}$ 的化合物。X-射线衍射分析表明，该化合物的立方晶胞的面心和顶点均被镍原子占据，所有镁原子的配位数都相等。推断镁原子在 $Mg_{2}NiH_{4}$ 晶胞中的位置(写出推理过程)。

39-3 实验测定，上述 $Mg_{2}NiH_{4}$ 晶体的晶胞参数为 646.5pm，计算该晶体中镁和镍的核间距。已知镁和镍的原子半径分别为 159.9pm 和 124.6pm。

39-4 若以材料中氢的密度与液态氢密度之比定义储氢材料的储氢能力，计算 $\mathrm{Mg_2NiH_4}$ 的储氢能力(假定氢可全部放出：液氢的密度为 $0.0708\mathrm{g / cm^3}$ )

39-1 镁—氢间距离为 194.8pm， $\text{Mg}^{2+}$ 离子半径为 72pm，则氢的半径为 194.8pm-72pm=123pm。此值远大于氢原子的共价半径，这说明 H 原子以 H⁻离子的形式存在。镁的氢化物中氢可能有三种存在形式：与 Mg 原子共价结合、以 H⁻的形式存在、以游离的 H₂ 分子形式存在。由题中数据可算出 H 原子的半径为 123pm，远大于共价半径，也大于共价半径的两倍(不可能以 H₂ 存在)，所以氢只可能以 H⁻存在。

39-2 Mg 原子数与 Ni 原子数之比为 2:1，故每个晶胞中含 8 个镁原子，所有援原子的配位数相等，它们只能填人由镍原子形成的四面体空隙。Ni 原子采取面心立方堆积，Mg 原子数为 Ni 原子数的 2 倍，则晶胞中有 8 个 Mg 原子，而 Mg 原子配位数相等，因而 Mg 原子应填满晶胞中的四面体空隙。

39-3 镁镍间的距离为 $d_{Mg-Ni} = \frac{1}{4} \times \sqrt{3} a = \frac{\sqrt{3}}{4} \times 646.5 = 279.9\mathrm{pm}$ ，Mg 原子在四面体空隙，Ni 原子在顶点，则 Mg 与 Ni 的核间距应为晶胞对角线长度的 1/4，由此可算出结果。

39-4 储氢能力=晶体的密度×氢的质量分数÷液氢密度

$$
\begin{array}{r l} & = \frac {4 \times M (\mathrm{Mg} _ {2} \mathrm{NiH} _ {4})}{N _ {\mathrm{A}} a ^ {3}} \times \frac {3.622 / 100}{0.0708 \mathrm{g} \cdot \mathrm{cm} ^ {- 3}} \\ & = \frac {4 \times 111.34 \mathrm{g} \cdot \mathrm{mol} ^ {- 1}}{6.022 \times 10 ^ {- 23} \mathrm{mol} ^ {- 1} \times (6.465 \times 10 ^ {- 8} \mathrm{cm}) ^ {3}} \times \frac {3.622 / 100}{0.0708 \mathrm{g} \cdot \mathrm{cm} ^ {- 3}} \\ & = 1.40 \end{array}
$$

题目中已经给出了"储氢能力"的定义"材料中氢的密度与液态氢密度之比", 若氢可全部放出, 则一个晶胞中氢的体积就是晶胞的体积, 氢的质量便是晶胞中氢原子的质量(整个晶体中 $\mathbf{H}$ 的质量/ $\mathbf{N}_{\mathrm{A}}$ ); 或由"晶体的密度×氢的质量分数"算出氢的密度。在此应特别注意 $\mathbf{H}$ 的相对原子质量的取值问题, 只要没有特殊说明, 都应该按试卷前给出的周期表里的数值来取值, 本题中就应取1.008而不是1。总体来说, 本题是一道基本的晶胞计算问题, 考察的内容也是竞赛中热门储氢材料问题, 晶胞的基本计算是我们日常训练的大量接触的题型, 常见的NaCl型、CsCl型、立方ZnS型、六方ZnS型、 $\mathrm{CaF}_2$ 型晶体的晶胞结构、原子的位置坐标、四面体空隙和八面体空隙的位置以及基本的计算应该了然于胸, 而遇到本题中"储氢能力"这样的陌生概念时, 也应该仔细审题, 尝试将其转化为已知的知识来求解。

写出晶胞中锆原子和钨原子的数目。

晶体中，氧原子的化学环境有几种？各是什么类型？在一个晶胞中各有多少？

![[a1f90ee389862a118b51c32ba3fdcd3ddecabb2acbc4916447aa7ac5d0d071bc.jpg]]

已知晶胞参数 $a = 0.916 \mathrm{~nm}$，计算该晶体的密度（以 $\mathrm{g} \mathrm{cm}^{-3}$ 为单位）。

![[a1f90ee389862a118b51c32ba3fdcd3ddecabb2acbc4916447aa7ac5d0d071bc.jpg]]

**参考答案**：

**（1）**
晶胞中有 4 个锆原子和 8 个钨原子。

本题的考点为晶体结构，考查了同学们对面心立方结构的熟悉程度、多面体间原子的共用问题以及识图能力。

题中的信息主要由晶胞示意图给出，观察晶胞图并结合题干中所给的信息可以看出：晶胞的 6 个面和 8 个顶点被八面体占据（即锆原子位于面心立方位置）；晶胞内有 8 个四面体（即钨原子位于晶胞内部）。

锆原子位于面心立方位置：

- 顶点：8 × 1/8 = 1
- 面心：6 × 1/2 = 3
- 总计：4 个锆原子

钨原子位于晶胞内部：

- 8 个钨原子

**（2）**
$\mathrm{ZrW}_{2}\mathrm{O}_{8}$ 或 $\mathrm{Zr}(\mathrm{WO}_{4})_{2}$

由 5-1 已经确定了晶胞中有 4 个锆原子和 8 个钨原子。锆位于 IV B 族，钨位于 VI B 族，所以它们的氧化数分别为 +4 和 +6。

设化学式为 $\mathrm{Zr}_{x}\mathrm{W}_{y}\mathrm{O}_{z}$，根据电荷平衡：

- 4x + 6y = 2z
- x:y = 4:8 = 1:2

代入得：4×1 + 6×2 = 2z，即 z = 8

因此化学式为 $\mathrm{ZrW}_{2}\mathrm{O}_{8}$，也可写作 $\mathrm{Zr}(\mathrm{WO}_{4})_{2}$。

**（3）**
氧原子的化学环境有 2 种：

① 只位于四面体上（端基氧）：8 个
② 位于四面体与八面体之间（桥连氧）：24 个

这一小题是本题的难点。晶体中氧原子可能的化学环境有 5 种：
① 只位于四面体上；② 只位于八面体上；③ 四面体与四面体之间；④ 四面体与八面体之间；⑤ 八面体与八面体之间。

由于晶胞中氧原子太多，无法通过观察得出氧原子有几种化学环境，但我们可以看出：

(a) 每个四面体都单独拥有一个氧原子；
(b) 四面体和四面体之间没有共用氧原子。

据此，在一个晶胞中，四面体上的氧原子有 $4 \times 8 = 32$ 个，等于晶胞中所有的氧原子数（由化学式 ZrW₂O₈ 可知，一个晶胞含 4 个 ZrW₂O₈，共 32 个氧原子）。这说明不存在只位于八面体上的氧原子和位于八面体之间的氧原子，从而可以确定晶胞中氧原子的化学环境有 (a)(b) 两种：

- 只位于四面体上的端基氧：每个四面体有 1 个，8 个四面体共 8 个
- 位于四面体与八面体之间的桥连氧：32 - 8 = 24 个

**（4）**
该晶体的密度为 $5.07 \mathrm{~g} \mathrm{cm}^{-3}$。

题中给出了晶胞参数 $a$，第二问已经得到了化学式，晶体的密度也就不难算得：

$$
\rho = \frac{Z M}{N _ {\mathrm{A}} V} = \frac{4 \times 586.92 \mathrm{g} \mathrm{mol} ^ {-1}}{6.022 \times 10 ^ {23} \mathrm{mol} ^ {-1} \times (0.916 \times 10 ^ {-7} \mathrm{cm}) ^ {3}} = 5.07 \mathrm{g} \mathrm{cm} ^ {-3}
$$

其中：

- $Z = 4$（一个晶胞含 4 个 ZrW₂O₈ 式单位）
- $M = 586.92 \mathrm{~g} \mathrm{~mol}^{-1}$（ZrW₂O₈ 的摩尔质量）
- $N_{\mathrm{A}} = 6.022 \times 10^{23} \mathrm{~mol}^{-1}$
- $V = a^3 = (0.916 \times 10^{-7} \mathrm{~cm})^3$

完整的解答要具备"列公式""代数据""得答案"这三个步骤，且要注意有效数字修约。

**（1）**
**得分点**：
1. **有芳香性**（2分）：咔咯环具有芳香性
2. **$\pi$ 电子数为 18**（2分）：对应的 $\pi$ 电子数为 18

判断芳香性的经典方法是 Hückel 规则。需要注意的是，Hückel 规则是一种经验规则，只适用于单环、平面、共轭多烯的芳香性判断。若偏离这三点基本要求，则会得到错误的结论。

以一个常见的稠环化合物芘 $\left(\mathrm{C}_{16} \mathrm{H}_{10}\right)$ 为例。在对这个平面分子应用 Hückel 规则时，首先找到其中的单环，即最外侧的大环，然后重写共振式使其形成共轭多烯，最后对参与共轭的 $\pi$ 电子计数。因为这是一个完全由 C 原子组成的共轭大环，所以 $\pi$ 电子数目等于其原子的数目，为 14，符合 $4n + 2$ 规则。因此芘具有芳香性。然而，若直接对稠环中的所有 $\pi$ 电子计数，则会得到16，做出反芳香性的荒谬判断。

![[7cf39b7c6b86b937db15e9df4b8c0ac07ba3d4b885339e88686859fd2af7e1d6.jpg]]

类似地，对平面的咔咯环应用Hückel规则时，也需要先找出其中的共轭单环，其有两种等价的选择方式。为什么没有其他等价的共轭单环，请同学们自行思考。随后，对参与共轭的 $\pi$ 电子计数：有共轭孤对电子的N原子贡献2个 $\pi$ 电子，有非共轭孤对电子的N原子贡献1个 $\pi$ 电子， $\pi$ 电子总数为18。因此咔咯环具有芳香性，对应的 $\pi$ 电子数为18。若将所有 $\pi$ 电子都计算在内，则有26个，是典型错误答案。

### 第25题

> 来源：真题·第35届初赛

在一定条件下，$\mathrm{CO_2}$ 分子可形成俗称干冰的晶体。在干冰的立方晶胞中，碳原子位于顶点和面心位置，分子轴平行于立方体的体对角线，如边栏图所示。其中 C-O 键长为 $116\,\mathrm{pm}$。

![[168e9846aed157693653e22253a5d4dd12fb1709cb9487a796cc1bc1142f4594.jpg]]
干冰的结构

**4-1-1** 写出干冰的结构基元。

**4-1-2** 写出干冰的点阵型式。

**4-1-3** 已知干冰的密度为 $1.64\,\mathrm{g\,cm^{-3}}$，计算干冰的晶胞参数 $a$ 和两个分子中心之间的最短距离 $L$。

**4-1-4** 计算图中所标出的那一个氧原子的坐标参数。

有趣的碳氧物种：存在一类通式为 $(\mathrm{C_nO_n})^{2-}$（$n = 3, 4, 5, 6$）的环状阴离子，呈平面结构。这些物种在合成化学中起着重要的作用。

**4-2-1** 画出 $\mathrm{H_2C_4O_4}$（方酸）的结构。

**4-2-2** 画出方酸根的结构，要求给出所有稳定的共振式。

**4-2-3** 探索新的碳单质：全碳环 [18]（记为 **O**）是一种环状结构的碳单质。20 世纪 60 年代就已提出，在 2019 年由科学家借助原子力显微镜（AFM）技术，通过对碳氧化物 $\mathrm{C_{24}O_6}$（记为 **P**）进行原子尺度的操作而得以实现。在全碳环 [18] 的探索中，正是借助于方酸的衍生物 $(\mathrm{CH_3})_2\mathrm{C_4O_4}$ 以及 $\mathrm{Li-C \equiv C-SiR_3}$（$\mathrm{R = iPr, Me}$）等试剂，科学家巧妙设计反应路线，制得环状分子 **P**。**P** 分子中有三重旋转轴，在 **P** 转化为 **O** 的过程中，主要有 4 种途径，涉及两个中间体 **X** 和 **Y**，**X** 的质量比 **P** 减少 $14.6\%$，**Y** 则减少 $29.2\%$。画出 **O**、**P**、**X** 和 **Y** 的结构。

**参考答案**：

**（1）**
**得分点**：
1. **4-1-1 正确写出结构基元**（1分）：**4 个 $\mathrm{CO_2}$ 分子**
2. **4-1-2 正确写出点阵型式**（1分）：**简单立方（cP）**
3. **4-1-3 正确计算 $a$ 和 $L$**（3分）：$a = 563\,\mathrm{pm}$，$L = 398\,\mathrm{pm}$
4. **4-1-4 正确计算坐标参数**（2分）：$(0.119, 0.119, 0.119)$

**完整推导**：

**4-1-1 结构基元**
结构基元是指晶体结构中周期性重复的最小单元。干冰晶胞中位于顶点和面心的 $\mathrm{CO_2}$ 分子**取向并不相同**：

- 顶点上的 $\mathrm{CO_2}$ 分子轴沿某一条体对角线方向
- 面心上的 $\mathrm{CO_2}$ 分子轴沿另一条体对角线方向

因此不能将单个 $\mathrm{CO_2}$ 分子都取为点阵点。干冰晶体的正当晶胞中含有 **4 个 $\mathrm{CO_2}$ 分子**，故结构基元为 **4 个 $\mathrm{CO_2}$ 分子**。

**4-1-2 点阵型式**
由于结构基元含 4 个 $\mathrm{CO_2}$ 分子，而立方晶胞中顶点 + 面心共有 4 个位置（8×1/8 + 6×1/2 = 4），故每个点阵点对应 4 个 $\mathrm{CO_2}$ 分子。

干冰晶体的点阵型式是 **简单立方点阵（cP）**，属于素点阵单位，只含有一个点阵点。

**4-1-3 晶胞参数与最短距离**
根据晶体的密度计算公式：

$$
\rho = \frac{ZM}{N_\mathrm{A}V}
$$

一个晶胞中包含 4 个 $\mathrm{CO_2}$ 分子，$Z = 4$；$\mathrm{CO_2}$ 的摩尔质量 $M = 44.01\,\mathrm{g\,mol^{-1}}$。假设晶胞参数 $a$ 的单位是 $\mathrm{pm}$，注意 $1\,\mathrm{pm} = 10^{-10}\,\mathrm{cm}$：

$$
1.64\,\mathrm{g\,cm^{-3}} = \frac{4 \times 44.01\,\mathrm{g\,mol^{-1}}}{6.022 \times 10^{23}\,\mathrm{mol^{-1}} \times a^3 \times 10^{-30}\,\mathrm{cm^3}}
$$

解得：

$$
a = 563\,\mathrm{pm}
$$

两个 $\mathrm{CO_2}$ 分子中心（C 原子）之间的最短距离即为晶胞面对角线长度的一半：

$$
L = \frac{\sqrt{2}}{2}a = \frac{\sqrt{2}}{2} \times 563\,\mathrm{pm} = 398\,\mathrm{pm}
$$

**4-1-4 氧原子坐标参数**
根据题干信息「分子轴平行于立方体的体对角线」，故图中所标出的那一个 O 原子位于晶胞的体对角线上，其原子坐标中的三个值是相同的，设为 $(x, x, x)$。

该 O 原子到顶点 C 原子的距离为 C-O 键长 $116\,\mathrm{pm}$。由相关的几何关系，体对角线方向的单位矢量为 $(1,1,1)/\sqrt{3}$，故：

$$
x \cdot a \cdot \sqrt{3} = 116\,\mathrm{pm}
$$

$$
x = \frac{116}{\sqrt{3} \times 563} = 0.119
$$

故图中所标出的那一个 O 原子坐标为 **$(0.119, 0.119, 0.119)$**。

**（2）**
**得分点**：
1. **4-2-1 正确画出方酸结构**（1分）：四元碳环，两个对位 C 各连两个 OH，两个对位 C 各连两个 =O（或两个对位 C 连一个 =O 和一个 -OH，经烯醇-酮互变异构）
2. **4-2-2 正确画出方酸根共振式**（2分）：给出所有 C-C 键等长、C-O 键等长的共振式，至少3种
3. **4-2-3 正确画出 O、P、X、Y 的结构**（4分）：O 为单叁键交替的18元碳环；P 为含3个方酸单元的环状分子；X 为脱去1个方酸单元（2CO）的结构；Y 为脱去2个方酸单元（4CO）的结构

**完整推导**：

**4-2-1 方酸的结构**
方酸分子 $\mathrm{H_2C_4O_4}$ 的不饱和度为 4，其中四元碳环占 1 个不饱和度。

两个羟基同时连在同一 C 原子上的结构（偕二醇）不稳定，故 4 个 C 原子各连一个 O 原子。为满足剩下的 3 个不饱和度，方酸的结构只能是如下两个可能结构之一：

```
      HO          O
       |          |
|
   HO--C          C
       |
|        |
|
       C==C  或   C--C
       |          |
       C==C       C--C
       |
|        |
|
       C          C
      / \        / \
     O   OH     O   OH
```

实际上，方酸以烯醇-酮互变异构的形式存在，其稳定结构为：

```
         O                O⁻
         |
|              //
     HO-C                C
         |
|              |
|
         C======C   ↔    C------C
         |               |   |
         C======C        C------C
         |
|              |
|
     HO-C                C
         |
|              \\
         O                O⁻
    （方酸）         （方酸根的一种共振式）
```

俗称「方酸」，也意味着其酸性较强。实验测定方酸双负离子 $\mathrm{C_4O_4^{2-}}$ 的结构中，所有的 C-C 键等长、C-O 键等长，证实了其非常稳定的共振结构。

**4-2-2 方酸根的共振式**
方酸根 $\mathrm{C_4O_4^{2-}}$ 为含有 $\pi_4^6$ 体系的平面闭合环状体系，满足 Hückel 芳香性条件（$4n+2$，$n=1$），因而具备一定的稳定性。

稳定的共振式需满足：

- 所有 C-C 键等长（键级 1.5）
- 所有 C-O 键等长（键级 1.5）
- 负电荷离域分布在 O 原子上

主要共振式包括（至少给出以下3种）：

```
    O⁻          O           O⁻
    |

|          |
|          |
    C           C           C
   /  \        //  \\       /  \
  C====C  ↔  C----C  ↔   C====C
   \  /        \\  //       \  /
    C           C           C
    |

|          |
|          |
    O⁻          O⁻          O
```

（注：实际答题需画出完整的带电荷的 Lewis 结构）

**4-2-3 O、P、X、Y 的结构推断**
**P 的结构**：

根据题意，P 的分子式为 $\mathrm{C_{24}O_6}$，分子中有三重旋转轴。方酸衍生物 $(\mathrm{CH_3})_2\mathrm{C_4O_4}$ 中的两个甲基只能取代两个羟基上的 H 原子，故其为方酸二甲酯。

由于化合物 P 中不含有 H 原子，故 $\mathrm{Li-C \equiv C-SiR_3}$ 应作为亲核试剂，反应最终将方酸二甲酯中的甲氧基取代，使方酸结构单元与 $-\mathrm{C \equiv C-}$ 相连。

最后根据「P 分子中有三重旋转轴」，可推出化合物 **P** 的结构为：由 3 个方酸单元通过 6 个 $-\mathrm{C \equiv C-}$ 链连接形成的环状分子。

**X 和 Y 的结构**：

由前体化合物 P 得到全碳环 [18] **O** 的过程，仅需要将环上的三个方酸单元「去掉」即可。

合理推测中间体 **X** 和 **Y** 对应「去掉」一个和两个方酸单元的结构：

- **X** 的分子式为 $\mathrm{C_{22}O_4}$（脱去 2 个 CO）
- **Y** 的分子式为 $\mathrm{C_{20}O_2}$（脱去 4 个 CO）

用题干中的失重数据验算：

- 化合物 P 的相对分子质量为 $24 \times 12.01 + 6 \times 16.00 = 384.24$
- 中间体 X 的相对分子质量比 P 少 $384.24 \times 14.6\% = 56.1$，对应 **2 分子 CO**
- 中间体 Y 的相对分子质量比 P 少 $384.24 \times 29.2\% = 112.2$，对应 **4 分子 CO**

故推测的结果符合题意。

**O 的结构**：

全碳环 [18]（O）是 18 元碳环且含有叁键，因此它必为**单、叁键交替结构**。其结构为：

$$
\mathrm{-C \equiv C - C \equiv C - C \equiv C - \cdots}
$$

（共 9 个 $-\mathrm{C \equiv C}-$ 和 9 个 $-\mathrm{C}-$ 单键交替形成 18 元环）

> 也可以通过逆合成分析和对称性分析推断出 Y、X 和 P 的结构。
