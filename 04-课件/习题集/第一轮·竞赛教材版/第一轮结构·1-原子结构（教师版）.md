### 第1题 ⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》第2章

【例 1】（1）核磁共振(NMR)技术已广泛应用于复杂分子结构的测定和医学诊断等高科技领域。已知只有质子数或中子数为奇数的原子核有 NMR 现象。试判断下列哪组原子均可产生 NMR 现象
A. $^{18}$ O³¹ P¹¹⁹ Sn
B. $^{27}$ Al¹⁹ F¹² C
C. 元素周期表中ⅢA族所有元素的原子
D. 元素周期表中第三周期所有元素的原子

(2)假定在下列电子的各组量子数中 n 正确，请指出哪个能存在?
A. n=1, l=1, m=1, $m_{s}=-1$ B. $n=3, l=1, m=2, m_{s}=+1/2$ C. $n=3, l=2, m=1, m_{s}=-1/2$ D. n=2, l=0, m=0, $m_{s}=0$ E. $n=2, l=-1, m=1, m_{s}=+1/2$ F. $n=4, l=3, m=2, m_{s}=2$

**参考答案**：

**·** (1) 答案：C

**分析：**

- **A**: ¹⁸O 质子数8(偶)、中子数10(偶) → 无NMR；³¹P 质子数15(奇) → 有NMR；¹¹⁹Sn 质子数50(偶)、中子数69(奇) → 有NMR。¹⁸O无NMR，排除。
- **B**: ²⁷Al 质子数13(奇) → 有NMR；¹⁹F 质子数9(奇) → 有NMR；¹²C 质子数6(偶)、中子数6(偶) → 无NMR。¹²C无NMR，排除。
- **C**: ⅢA族元素（B、Al、Ga、In、Tl），质子数分别为5、13、31、49、81，均为奇数 → 均有NMR。**正确。**
- **D**: 第三周期含 ²⁸Si（质子数14偶、中子数14偶）无NMR，排除。

**·** (2) 答案：C

**分析：**

量子数取值规则：n ≥ 1（正整数），0 ≤ l ≤ n-1，-l ≤ m ≤ l，$m_s$ = ±1/2。

| 选项 | 判断 | 原因 |
|:---:|:---:|:---|
| A | 不合法 | l = 1，但 n = 1 时 l 最大为 0 |
| B | 不合法 | l = 1 时 m 最大为 1，m = 2 超出范围 |
| **C** | **合法** | **n=3, l=2, m=1，均在允许范围内** |
| D | 不合法 | $m_s$ 只能取 ±1/2，不能为 0 |
| E | 不合法 | l 不能为负值 |
| F | 不合法 | $m_s$ 只能取 ±1/2，不能为 2 |

---

**·** 知识点映射

- 核心考点：NMR活性判断（质子数或中子数为奇数）、量子数合法性判断
- 关键规则：n ≥ 1；0 ≤ l ≤ n-1；-l ≤ m ≤ l；$m_s$ = ±1/2
- NMR条件：原子核自旋量子数 I ≠ 0，即质子数或中子数为奇数

### 第3题 ⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》第2章

【例 4】 现有 $_{a}$ A、 $_{b}$ B、 $_{c}$ C、 $_{d}$ D、 $_{e}$ E 五种短周期元素，它们都是生命体不可缺少的重要元素。已知它们的原子序数有如下关系： $a+b=c,a+c=d,c+d=e$ ，B、D、E 都有多种同素异形体。B 的化合物种类与 A 的化合物种类何者更多, 目前学术界还有争议, 但有一点是肯定的, 那就是没有第三种元素的化合物种数会超出它们。根据以上信息回答下列有关问题:

(1)请比较 $B_{2}A_{4}$ 、 $C_{2}A_{4}$ 、 $E_{2}A_{4}$ 三种化合物的沸点由高到低的顺序 \_\_\_\_。

(2)从给定的元素中选出若干种组成化合物，写出相对分子质量最小的离子化合物的化学式\_\_\_\_。

(3)以题中元素为选择对象，写出不少于三种炸药的化学式或名称。\_\_\_\_、\_\_\_\_、\_\_\_\_。

(4)有人设想某种分子式为 $C_{4}N_{4}O_{8}$ 的物质(该物质中同种原子的化学环境完全相同)是一种威力极强的炸药，请推测它的结构简式。

**参考答案**：

**·** 元素推断

由条件推导：

- a + b = c，a + c = d，c + d = e
- 设 a = 1（H），则 c = 1 + b，d = 1 + c = 2 + b，e = c + d = (1+b) + (2+b) = 3 + 2b
- B、D、E 有多种同素异形体 → B 为 C（碳，多种同素异形体：金刚石、石墨、富勒烯等），b = 6
- 则 c = 7（N），d = 8（O），e = 15（P）
- 验证：D = O 有 O₂/O₃ 同素异形体 ✓；E = P 有白磷/红磷/黑磷同素异形体 ✓

**A = H, B = C, C = N, D = O, E = P**

**·** (1) 沸点比较

B₂A₄ = C₂H₄（乙烯），C₂A₄ = N₂H₄（联氨），E₂A₄ = P₂H₄（联磷）

$$\text{N}_2\text{H}_4 > \text{P}_2\text{H}_4 > \text{C}_2\text{H}_4$$

- N₂H₄：分子间存在氢键，沸点最高（113.5 °C）
- P₂H₄：分子量较大，范德华力较强（沸点 51.7 °C）
- C₂H₄：分子量最小且无氢键，沸点最低（-103.7 °C）

**·** (2) 最小相对分子质量的离子化合物

**NH₄H**（氢化铵），相对分子质量 = 18

NH₄⁺ 和 H⁻ 组成的离子化合物，是含这些元素的最小相对分子质量的离子化合物。

**·** (3) 三种炸药

由 C, H, N, O, P 组成的炸药：

1. **硝酸甘油酯**（甘油三硝酸酯）：C₃H₅(ONO₂)₃
2. **TNT**（三硝基甲苯）：CH₃C₆H₂(NO₂)₃
3. **苦味酸**（三硝基苯酚）：C₆H₂(NO₂)₃OH

**·** (4) C₄N₄O₈ 的结构

该分子式可写作 **(NO₂)₄C₄**，即四硝基四元环结构或四(硝基)丁烷类化合物。

更合理的是将其理解为 **RDX（黑索金）的同分异构体** 或 **四硝基乙烷类** 结构。实际上 C₄N₄O₈ 对应的是 **四硝基乙二胺** 或环状四硝基化合物的分子式。

---

**·** 知识点映射

- 核心考点：根据原子序数关系和同素异形体特征推断元素
- 关键推理：a+b=c, a+c=d, c+d=e + 同素异形体条件锁定五种元素
- 沸点规律：氢键 > 范德华力（分子量大者沸点高）

### 第4题 ⭐⭐⭐【竞赛教材】

> 来源：高中化学竞赛教程第一分册·第5讲 实战演练 1（1996年陕西省化学竞赛试题）

> **同题异版**：题-098-一分册-L5对例3-双原子分子式量同位素（本讲竞赛对接 例3 同素材，两版互证）

**·** 题目

某元素构成的双原子单质分子有三种，其式量分别是 158、160 和 162。在天然单质中，此三种单质的物质的量之比为 $1:2:1$。由此推断以下结论正确的是（　）

A. 此元素有三种同位素

B. 其中一种同位素质量数为 80

C. 其中质量数为 79 的同位素原子占总数的 1/2

D. 此元素的单质的平均式量为 160

**·** 知识点映射

| 库内知识点 | 对应题目内容 |
|---|---|
| 原子结构 | 同位素组合、质量数与式量的区分 |
| 元素周期律 | 天然丰度与平均式量 |

**参考答案**：

**原书答案**（答案区 L2931）：CD——原书以 $(X+Y)^2=X^2+2XY+Y^2$ 模型说明两种同位素组合成三种分子。

**解析**：三种分子的式量只能由两种同位素组合而成：$79+79=158$、$79+81=160$、$81+81=162$，即该元素有两种同位素 $^{79}\mathrm{X}$、$^{81}\mathrm{X}$，丰度相等。

- A 错：只有两种同位素（三种分子是两两组合，不是三种同位素）；
- B 错：不存在质量数 80 的同位素（80 是分子的式量，不是核素的质量数）；
- C 对：$n(^{79}\mathrm{X}):n(^{81}\mathrm{X})=1:1$，质量数 79 的同位素原子占总数的 1/2；
- D 对：平均式量 $=\dfrac{158\times1+160\times2+162\times1}{4}=\dfrac{640}{4}=160$。

**参考解答**：CD

### 第5题 ⭐⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》

12. 下列实验不能达到预期目的的是

<table><tr><td>序号</td><td>实验操作</td><td>实验目的</td></tr><tr><td>A</td><td> $Cl_{2}$ 、 $Br_{2}$  分别与  $H_{2}$  反应</td><td>比较氯、溴的非金属性强弱</td></tr><tr><td>B</td><td> $MgCl_{2}$ 、 $AlCl_{3}$  溶液中分别通入  $NH_{3}$ </td><td>比较镁、铝的金属性强弱</td></tr><tr><td>C</td><td>测定  $Na_{2}CO_{3}$ 、 $Na_{2}SO_{4}$  两溶液的 pH</td><td>比较碳、硫的非金属性强弱</td></tr><tr><td>D</td><td>同一电路测定等浓度的盐酸、醋酸溶液的导电性</td><td>比较盐酸、醋酸的酸性强弱</td></tr></table>

**参考答案**：

**答案：B（MgCl₂/AlCl₃ + NH₃ 不能区分）**

**解题思路：**

区分 Mg²⁺ 和 Al³⁺ 的常用方法之一是利用 Al(OH)₃ 的两性：

- Al(OH)₃ 能溶于过量 NaOH 溶液（强碱），而 Mg(OH)₂ 不溶
- 这是因为 Al³⁺ 形成的 Al(OH)₃ 是两性氢氧化物

但题目中的方法是用 **NH₃·H₂O（氨水）**：

- Mg²⁺ + 2NH₃·H₂O → Mg(OH)₂↓ + 2NH₄⁺
- Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺

关键问题：**Al(OH)₃ 不溶于过量氨水**（氨水是弱碱，碱性不够强，无法溶解 Al(OH)₃）。

因此，无论是 MgCl₂ 还是 AlCl₃ 加入过量氨水中，都会产生白色沉淀且沉淀不溶解，**无法区分这两种离子**。这个实验不能达到目的。

正确的区分方法应使用 NaOH：Al(OH)₃ 溶于过量 NaOH 而 Mg(OH)₂ 不溶。

### 第6题 ⭐⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》

25.金属钠形成离子时一般为+1价，而不是+2价的原因是 ( )
A.钠的第一电离能很大    B.钠的第二电离能很大
C.钠的电负性很小    D.钠的原子半径很大

**参考答案**：

**答案：B（第二电离能很大）**

**解析：**

Na 的电子排布为 $1s^22s^22p^63s^1$。

Na 呈 $+1$ 价的原因需要从能量角度分析：

- Na 失去 1 个 $3s$ 电子后变为 $Na^+$，电子排布为 $1s^22s^22p^6$，即 **Ne 的稳定构型**（稀有气体构型）。
- 要从 $Na^+$ 再失去第 2 个电子，需要从已填满的 $2p$ 轨道（内层稳定结构）中电离电子，**第二电离能 $I_2$ 远大于第一电离能 $I_1$**。

数据参考：$I_1(Na) = 496 \text{ kJ/mol}$，$I_2(Na) = 4562 \text{ kJ/mol}$，$I_2/I_1 \approx 9.2$ 倍。

**A**（原子半径大）和 **D**（只有一个价电子）是相关因素，但不是根本原因。
**C**（第一电离能小）描述的是容易失电子，但不能解释为什么只失 1 个。

根本原因是：失去 1 个电子后达到稳定结构，**第二电离能突增**，使得再失去第二个电子在能量上极其不利。

因此选 **B**。

### 第9题 ⭐⭐⭐【竞赛教材】

5. 周期表中有些元素有“对角线相似”现象（即周期表中处于对角线位置的两元素性质相似），如 Li、Mg；Be、Al；B、Si 等两两性质相似。现用熔融 LiCl 电解的方法可得锂和氯气。若用已潮解的 LiCl 加热蒸干并强热至熔融，再用惰性电极电解，结果得到金属锂和一种无色无味的气体。据此，下列说法正确的是（多选）
A. 无色气体为电解生成的锂与水反应放出的 $H_{2}$ B. 电解前 LiCl 在加热时已发生水解
C. 电解时产生的无色气体是 $O_{2}$ D. 无色气体是阳极放出的 $Cl_{2}$ 与水作用生成的 $O_{2}$

**参考答案**：

**答案：BC**

**解题思路：**

LiCl 潮解后形成 LiCl 水溶液。电解 LiCl 水溶液时：

**阴极反应：**
- H⁺ 的放电能力强于 Li⁺（因为 Li 的标准电极电势非常负，Eθ(Li⁺/Li) = -3.04 V）

### 第14题 ⭐⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》第2章

14. A、B 是短周期元素, 最外层电子排布式分别为

$ms^{x}, ns^{x}np^{x+1}$ 。A 与 B 形成的离子化合物加蒸馏水溶解后可使酚酞试液变红，同时有气体逸出，该气体可使湿润的红色石蕊试纸变蓝，则该化合物的相对分子质量是（）
A. 38 B. 55 C. 100 D. 135

**参考答案**：

**答案：C（相对分子质量100）**

**解析：**

由 $m_s^x$ 和 $ns^x np^{x+1}$ 的电子排布信息推断元素：

- $m_s^x$ 为第ⅡA族元素的 $s$ 轨道排布，$x=2$，即 $m_s^2$。若为第三周期的 Mg，则 Mg 的电子排布为 $[Ne]3s^2$，相对原子质量约为 24。
- $ns^x np^{x+1}$ 中 $x=2$，则排布为 $ns^2 np^3$，为第ⅤA族元素。若为第三周期的 P（磷），电子排布为 $[Ne]3s^23p^3$，相对原子质量约为 31。

Mg 形成 $Mg^{2+}$，P 形成 $P^{3-}$，离子化合物化学式为 $Mg_3P_2$。

$$M_r(Mg_3P_2) = 3 \times 24 + 2 \times 31 = 72 + 62 = 134$$

但若考虑更一般的情形，设 $m_s^x$ 中 $m$ 为第二周期 Be（$2s^2$，$M_r=4$），$ns^x np^{x+1}$ 为 $ns^2 np^3$ 即第ⅤA族。Be₃P₂ 的 $M_r = 3 \times 4 + 2 \times 31 = 12 + 62 = 74$。

综合分析，当 $m_s^x$ 取 Ca（$4s^2$，$M_r=40$）而 $ns^x np^{x+1}$ 取 N（$2s^22p^3$，$M_r=14$）时：$Ca_3N_2$ 的 $M_r = 3 \times 40 + 2 \times 14 = 120 + 28 = 148$。

实际上正确的组合为：$m_s^x$ 为 $Mg^{2+}$（$M_r=24$），$ns^x np^{x+1}$ 为 $P^{3-}$（$M_r=31$），但需要满足 $m$ 与 $n$ 同周期等条件。经检验，$x=2$ 时，$m_s^2$ 取 Mg（24），$ns^2 np^3$ 取 N（14），化合物 $Mg_3N_2$ 的 $M_r = 3 \times 24 + 2 \times 14 = 100$，选 **C**。

### 第16题 ⭐⭐⭐【竞赛教材】

> 来源：赵鑫光《高中化学竞赛基本理论学习笔记》第2章

16. 自英国科学家狄拉克提出反粒子存在的预言, 人类开始在茫茫宇宙中寻找反物质的例证。后又聚焦于反物质的合成研究。1997 年人类首次合成了 9 个反氢原子。2002 年是人类合成反物质的丰收年, 合成了 5 万个反氢原子, 也是对狄拉克诞辰 100 周年祭典的一份厚礼。你认为反氢原子的组成应该为 ( )

A. 由 1 个带负电荷的质子与一个带正电荷的电子构成

B. 由 1 个带正电荷的质子与一个带负电荷的电子构成

C. 由 1 个不带电荷的中子与一个带负电荷的电子构成

D. 由 1 个带负电荷的质子与一个带负电荷的电子构成

**参考答案**：

**答案：A（负电质子 + 正电电子）**

**解析：**

反氢原子是氢原子的反物质对应物。根据反物质理论：

- 普通氢原子由一个**正电质子**（$p^+$）和一个**负电电子**（$e^-$）组成。
- 反氢原子则由每个粒子的反粒子组成：**负电质子**（反质子，$\bar{p}$，即 $p^-$）和**正电电子**（正电子，$e^+$）。

反粒子与对应的正粒子质量相同，但电荷相反。反氢原子的"原子核"是一个反质子（带负电），核外是一个正电子（带正电），与普通氢原子的电荷分布正好相反。

因此选 **A**。

(5)1984年，联邦德国达姆塔特重离子研究机构阿姆布鲁斯特和明岑贝格等人在重离子加速器上用⁵⁸ Fe离子轰击²⁰⁸ Pb靶时，发生核合成反应，发现了²⁶⁵ X。最近有人用高能²⁶ Mg核轰击 $^{248}_{96}$ Cm核，发生相似反应，得到X的另一种同位素²⁶⁹ X。

①X 的元素符号是\_\_\_\_，最高价氧化物的化学式是\_\_\_\_。

②用元素符号并在左上角和左下角分别标注其质量数和质子数，写出合成 X 的 2 个核反应方程式(方程式涉及的其他符号请按常规书写)。

**参考答案**：

**(1)** 166号元素位于 **第八周期ⅥA族**。

**(2)** 合成112号元素的核反应方程：

$$^{70}_{30}\text{Zn} + ^{208}_{82}\text{Pb} \rightarrow ^{277}_{112}\text{Cn} + n$$

**(3)** ²³⁵U 的裂变方程（示例）：

$$^{235}_{92}\text{U} + n \rightarrow ^{144}_{54}\text{Xe} + ^{90}_{38}\text{Sr} + 2n$$

**(5)** ²⁶⁵X 和 ²⁶⁹X 均为 **Hs**（鿔，108号元素）。
