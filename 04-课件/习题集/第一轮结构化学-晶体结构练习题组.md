**第52题**：（1）由晶胞图读出：l_x = a/2 = 0.192 nm（a = 0.384 nm），l_z = 0.207 nm（J-T拉长的轴向Cu–O键）。A为La₂CuO₄（M = 405.4 g/mol），体心四方晶胞含Z = 2个化学式单位，由ρ = ZM/(N_A·a²c) = 2×405.4/(6.022×10²³×a²c) = 6.88 g/cm³。（2）B = La₂Cu(C₄O₄)₄·18H₂O。验算：M_B = 2×138.9 + 63.5 + 4×112.0 + 18×18.0 = 1113.8 g/mol；200°C失水 18×18/1113.8 = 29.1% ✓；至700°C方酸根分解（失CO₂并消耗空气中O₂）残留La₂CuO₄，总失重(1113.8−405.4)/1113.8 = 63.6% ✓。（3）Sr²⁺取代La³⁺产生空穴：La位点数/m³ = 2×6.88×10⁶/(405.4×6.022×10²³) = 2.044×10²⁸；取代率 = 空穴数2.05×10²⁷/2.044×10²⁸ = 10.0%。
