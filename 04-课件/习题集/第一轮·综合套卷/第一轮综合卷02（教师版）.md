> 来源：高中化学竞赛教程·第一分册

据 2009 年的报道，采用 1:1 硫酸溶液同槽浸出锰结核矿[质量分数 $w(\mathrm{MnO}_2)=0.20$]和锌精矿[质量分数 $w(\mathrm{ZnS})=0.70$]的工艺方法提取锰和锌获得成功。该方法的原理是利用 $\mathrm{MnO}_2$ 与 $\mathrm{ZnS}$ 在酸性条件下发生氧化还原反应，使矿物中的锰与锌以 $\mathrm{Mn}^{2+}$、$\mathrm{Zn}^{2+}$ 的形式浸出。研究发现，两种矿物同槽酸浸 4 h 后，锰和锌的浸出率只有 80% 左右，为了提高浸出率，在实际工艺中，需将过滤后的滤渣用四氯乙烷处理后再做二次酸浸，此处的四氯乙烷所起的作用是（ ）。

### 第24题

> 来源：一分册能力测试

1885年，德国夫赖堡(Frieberg)矿业学院的一位教授在分析夫赖堡附近发现的一种新矿石(以X表示，X为整比化合物)的时候，发现其中有一种当时未知的新元素(以Y表示，在X中Y的化合价为+4)，并通过实验验证了自己的推断。经分析，X中含有银元素(化合价为+1)和硫元素(化合价为-2)，其中Ag的质量分数为76.53%。在氢气流中加热X，可得到 $\mathrm{Ag_2S}$、$\mathrm{H_2S}$ 和 Y 的低价硫化物(Y的化合价为+2)。如果在200℃和100kPa条件下完全转化16.0 g 的 X 需要 0.557 L 的氢气。根据上面的描述：

4-1 计算 Y 的摩尔质量并指出 Y 在元素周期表中的位置。

4-2 写出氢气和 X 反应的化学方程式。

**参考答案**：

4-1 $M(\mathrm{Y}) = 73\ \mathrm{g\cdot mol^{-1}}$；Y 为 Ge 元素，位于第四周期ⅣA族。

4-2 $\mathrm{Ag_8GeS_6} + \mathrm{H_2} \xrightarrow{\Delta} 4\mathrm{Ag_2S} + \mathrm{GeS} + \mathrm{H_2S}$

4-1 设 X 的化学式为 $\mathrm{Ag_{2a}Y_bS_{a+2b}}$（或 $a\,\mathrm{Ag_2S}\cdot b\,\mathrm{YS_2}$）：$216a / M(\mathrm{X}) = 0.7653$，$M(\mathrm{X}) = 216a / 0.7653$。

参加反应的 $\mathrm{H_2}$ 的物质的量是 $n(\mathrm{H_2}) = 100 \times 0.557 / (473 \times 8.31) = 0.01417\ \mathrm{mol}$。

$$\mathrm{Ag_{2a}Y_bS_{a+2b}} + b\mathrm{H_2} = a\mathrm{Ag_2S} + b\mathrm{YS} + b\mathrm{H_2S}$$

$$\frac{216a/0.7653}{b} = \frac{16.0}{0.01417}$$

$a/b = 4.00$，因 X 是整比化合物，$a$、$b$ 都是正整数，得 $a = 4, b = 1$，$M(\mathrm{Y}) = 73\ \mathrm{g\cdot mol^{-1}}$。查元素周期表可得 Y 为 Ge 元素，它的位置是第四周期IVA族。

4-2 $\mathrm{Ag_8GeS_6} + \mathrm{H_2} \xrightarrow{\Delta} 4\mathrm{Ag_2S} + \mathrm{GeS} + \mathrm{H_2S}$

### 第25题

> 来源：一分册能力测试

固体材料的制备中，常遇到缺陷和非整比（非化学计量）的化合物，$Na_{1-x+y}Ca_{x/2}LaTiO_{4}$ 就是非整比化合物，也是一类新的高温超导体。

它的制备方法如下：用 $\mathrm{NaLaTiO_{4}(I)}$ 作为母体化合物，和无水 $\mathrm{Ca(NO_{3})_{2}}$ 混合，封闭在耐热玻管中，加热到 $350^{\circ}\mathrm{C}$，维持3天，然后打开，取出样品，用水冲洗，直到没有杂质（用X射线衍射证实），得到 $Ca^{2+}$ 交换产物，记为 $Na_{1-x}Ca_{x/2}LaTiO_{4}(II)$，光谱实验证明，上述过程中(I)有86%的 $Na^{+}$ 被交换，所以产生离子空位（即部分原本 $Na^{+}$ 的位置空置了）。

将样品(II)放入 $300^{\circ}\mathrm{C}$ 下的钠蒸气中，经历数天，该物质由白色渐变为黑色，这是 $Na^{+}$ 插入空位所致，光谱实验证明，有 88% 的离子空位被 $Na^{+}$ 插入了，生成目标化合物 $\mathrm{Na}_{1-x+y}\mathrm{Ca}_{x/2}\mathrm{LaTiO}_{4}(\mathrm{III})$。试回答：

5-1 制备时，为何选用 $\mathrm{Ca(NO_{3})_{2}}$ 而不用其他钙盐？

5-2 产物(III)中 $x$ 和 $y$ 分别是多少？

5-3 当化合物(II)中的离子空位被 $\mathrm{Na}^{+}$ 插入时，为保持晶体的电中性，部分 Ti 的化合价发生了改变，求化合物(III)中高、低价态钛离子的个数比为何？

**参考答案**：

5-1 硝酸盐易分解完全，易彻底用水洗去。

5-2 $x = 0.86$；$y = 0.38$。

5-3 高、低价态钛离子（$\mathrm{Ti}^{4+}:\mathrm{Ti}^{3+}$）个数比 $= 0.62 : 0.38 = 31 : 19$。

5-1 硝酸盐易分解完全，易彻底用水洗去（不引入杂质阴离子残留）。

5-2 交换产生空位：86% 的 $Na^{+}$ 被 $Ca^{2+}$ 交换，$x = 0.86$；按化学式 $Na_{1-x}Ca_{x/2}$，$Ca^{2+}$ 占据 $1/2 \times 0.86 = 0.43$；(II) 中空位分数为 $x/2 = 0.43$；钠蒸气插入其中 88%：$y = 0.88 \times 0.43 = 0.38$。

5-3 (III) 中每个化学式单元：$Na$ 为 $1-x+y = 0.14+0.38 = 0.52$，$Ca$ 为 $0.43$，$La$ 为 $1$。设 $n\ \mathrm{mol}\ Ti^{4+}$、$m\ \mathrm{mol}\ Ti^{3+}$（$n+m=1$），由电中性：

$$0.52 \times 1 + 0.43 \times 2 + 3 \times 1 + 4n + 3m = 8$$

解得 $n = 0.62$，$m = 0.38$，即高价（$\mathrm{Ti}^{4+}$）与低价（$\mathrm{Ti}^{3+}$）钛离子个数比为 $0.62:0.38 = 31:19$。

碘能形成多种氟化物，具有许多有趣的性质。

**6-1** 画出 $\mathrm{IF_3}$、$\mathrm{IF_5}$、$\mathrm{IF_7}$ 的立体结构。

**6-3** $\mathrm{IF_5}$ 和 $\mathrm{SO_3}$ 以摩尔比 $1:1$ 反应得到一种离子化合物 C，给出 C 的结构简式，画出 C 中阳离子的结构。

**6-4** IF、$\mathrm{IF_3}$、$\mathrm{IF_5}$ 均可能发生歧化反应，生成碘单质和碘元素价态升高二价的氟化物。写出歧化反应的方程式，并计算反应热。事实上 IF，$\mathrm{IF_3}$，$\mathrm{IF_5}$ 只有一个不能发生歧化，指出是何种物质。已知某些物质的标准生成热如下：

| | IF | $\mathrm{IF_3}$ | $\mathrm{IF_5}$ | $\mathrm{IF_7}$ |
|---|---|---|---|---|
| $\Delta_{\mathrm{f}}H^{\ominus}/\mathrm{kJ\cdot mol^{-1}}$ | −95.4 | −486 | −843 | −962.5 |

**参考答案**：

**6-1** 立体结构图略。$\mathrm{IF_3}$ T 型，$\mathrm{IF_5}$ 四方锥型，$\mathrm{IF_7}$ 五角双锥形。

**6-2** A $[\mathrm{IF_6^+}][\mathrm{AsF_6^-}]$，B $[\mathrm{IF_6^+}][\mathrm{Sb_2F_{11}^-}]$；$\mathrm{Sb_2F_{11}^-}$ 立体结构图略；两个 $\mathrm{SbF_6}$ 正八面体以氟桥键相连。

**6-4**

$3\mathrm{IF} \longrightarrow \mathrm{I_2} + \mathrm{IF_3}$

$\Delta_{\mathrm{r}}H^{\ominus} = -3\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF}) + \Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_3}) = (286.2 - 486)\ \mathrm{kJ\cdot mol^{-1}} = -199.8\ \mathrm{kJ\cdot mol^{-1}}$
