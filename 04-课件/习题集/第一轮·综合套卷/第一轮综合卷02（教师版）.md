**6-2** 请问：式中的 M 是一个什么物理量？为什么？用上述两种燃料作为火箭燃料，以氧气为火箭氧化剂，按化学计量比发生燃烧反应，推动火箭前进，分别计算 M 值。

**6-3** 设火箭特性常数 K 与燃料无关，通过计算说明，上述哪种燃料用作火箭燃料的性能较好？

**参考答案**：

**6-1**

反应：CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(g)

$$\Delta_\mathrm{r}H^\theta_\mathrm{m} = 2\Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{H_2O,g}) + \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{CO_2,g}) - \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{CH_4,g}) - 2\Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{O_2,g})$$

$$= -802.3\ \mathrm{kJ\cdot mol^{-1}}$$

（注：题给 H₂O(l) ΔfH=−285.8 与 H₂O(g) ΔfH=−241.8，按产物为 H₂O(g) 用 −241.8）

$$\Sigma C_\mathrm{p} = 2C_\mathrm{p}(\mathrm{H_2O,g}) + C_\mathrm{p}(\mathrm{CO_2,g}) = 2\times 33.6 + 37.1 = 104.3\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

(注：此处的"mol"为 [2H₂O(g)+CO₂(g)] 粒子组合。)

$$\Delta T = -\Delta_\mathrm{r}H^\theta_\mathrm{m}/\Sigma C_\mathrm{p} = 7692\ \mathrm{K},\quad T = 298 + 7692 = 7990\ \mathrm{K}$$

反应：H₂(g) + ½O₂(g) → H₂O(g)

$$\Delta_\mathrm{r}H^\theta_\mathrm{m} = -241.8\ \mathrm{kJ\cdot mol^{-1}}$$

$$C_\mathrm{p} = 33.6\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

$$\Delta T = 7196\ \mathrm{K},\quad T = 298 + 7196 = 7494\ \mathrm{K}$$

**6-2** M 是平均摩尔质量：

- CH₄−O₂：总质量 = 16 + 64 = 80 g，总摩尔 = 1 + 2 = 3 mol，M = 80/3 = 26.7 g·mol⁻¹
- H₂−O₂：源答案给 18 g·mol⁻¹（按 H₂(2) + ½O₂(16) 总质量 18 总摩尔 1.5 平均 12，源答案疑误为产物 H₂O 摩尔质量而非平均反应物；按源答案照录+注存疑）

气体分子动能 $E = \tfrac{1}{2}mv^2$ 中，$m = nM$，动能一定和 n 一定时，M 越大速度 v 越小，故在 Isp 公式中 M 在分母中。

**6-3**

$$\mathrm{CH_4-O_2:}\quad I_\mathrm{sp} = K\times (104.3\times 7990)/(44 + 2\times 18) = 1.0\times 10^4\ K$$

$$\mathrm{H_2-O_2:}\quad I_\mathrm{sp} = K\times (33.6\times 7494)/18 = 1.4\times 10^4\ K$$

H₂−O₂ 是性能较好的火箭燃料。

注：平均摩尔质量也可是上述数据除以总摩尔数，此时，平均摩尔热容也除总摩尔数，两项相约，与上述结果相同。

### 第30题

> 来源：高中化学竞赛教程·第二分册
> 曾用于：二分册专项卷I, 第一轮综合卷02（教师版）

（2003 年江苏预赛）1273 K 时 $H_2O(g)$ 通过红热的铁生产 $H_2$，发生如下反应：

$$
\mathrm{Fe(s)} + \mathrm{H_2O(g)} \rightleftharpoons \mathrm{FeO(s)} + \mathrm{H_2(g)}
$$

反应的平衡常数 $K_p = 1.49$（$K_p$ 是以各平衡混合气体分压表示的化学平衡常数）。

(1) 每生成 1.00 mol 氢气需通入水蒸气的物质的量为多少？

(2) 1273 K 时，若反应体系中只有 0.30 mol 的铁并通入 1.00 mol 水蒸气与其反应，试计算反应后各组分的物质的量。反应后体系是否处于平衡状态，为什么？

(3) 1273 K 时，当 1.00 mol 水蒸气与 0.80 mol 铁接触时，最后各组分的物质的量是多少？

**参考答案**：

**过程探究**（原书 L604~658）

(1) 因为 $p(\mathrm{H_2}) = n(\mathrm{H_2})RT/V$、$p(\mathrm{H_2O}) = n(\mathrm{H_2O})RT/V$，故

$$
K_p = \frac{p(\mathrm{H_2})}{p(\mathrm{H_2O})} = \frac{n(\mathrm{H_2})}{n(\mathrm{H_2O})} = 1.49
$$

平衡时 $n(\mathrm{H_2O}) = \dfrac{n(\mathrm{H_2})}{1.49}\approx 0.671\,\mathrm{mol}$。因此起始时通入 $\mathrm{H_2O(g)}$ 的物质的量为 $n(\mathrm{H_2})_{\text{平}} + n(\mathrm{H_2O})_{\text{平}} = 1.00 + 0.671 = 1.67\,\mathrm{mol}$。

注意该反应是一个可逆反应，存在化学平衡，故该反应不能进行到底，所以不能误认为通入的水蒸气的物质的量就是氢气的物质的量。

(2) 假设 0.30 mol 铁与 1.00 mol 水蒸气完全反应，则生成 $n(\mathrm{H_2}) = 0.30\,\mathrm{mol}$。此时用于平衡的 $n(\mathrm{H_2O}) = \dfrac{0.30}{1.49}\approx 0.20\,\mathrm{mol}$。0.30 mol Fe 完全反应共需 $H_2O(g)$ 0.20+0.30 = 0.50 mol < 1.00 mol，故铁粉可完全反应。此时各组分的物质的量分别为 $n(\mathrm{H_2})=0.30$、$n(\mathrm{H_2O})=0.70$、$n(\mathrm{FeO})=0.30$、$n(\mathrm{Fe})=0$。

故 $\dfrac{n(\mathrm{H_2})}{n(\mathrm{H_2O})} = \dfrac{0.30}{0.70}\approx 0.43 < K_p = 1.49$，因此此时体系没有达到平衡。

(3) 设反应的 Fe 为 $x$ mol，则 $\dfrac{x}{1.00-x} = K_p = 1.49$，解得 $x = 0.60\,\mathrm{mol}$。此时体系各组分的物质的量分别为 $n(\mathrm{H_2})=0.60$、$n(\mathrm{H_2O})=0.40$、$n(\mathrm{FeO})=0.60$、$n(\mathrm{Fe})=0.20$ mol。

**参考解答**（1）需通入水蒸气 1.67 mol；（2）$n(\mathrm{H_2})=0.30$、$n(\mathrm{H_2O})=0.70$、$n(\mathrm{FeO})=0.30$、$n(\mathrm{Fe})=0$ mol，未达平衡，理由见上；（3）$n(\mathrm{H_2})=0.60$、$n(\mathrm{H_2O})=0.40$、$n(\mathrm{FeO})=0.60$、$n(\mathrm{Fe})=0.20$ mol。
