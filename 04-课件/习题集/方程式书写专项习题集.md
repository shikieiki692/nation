## 第1题 ⭐ [上中·氧化还原]

配平下列化学反应方程式：

(1) $\mathrm{KMnO_4 + FeCl_2 + H_2SO_4 \longrightarrow K_2SO_4 + MnSO_4 + Fe_2(SO_4)_3 + Cl_2 + H_2O}$

(2) $\mathrm{K_2Cr_2O_7 + Fe_3O_4 + H_2SO_4 \longrightarrow Cr_2(SO_4)_3 + Fe_2(SO_4)_3 + K_2SO_4 + H_2O}$

(3) $\mathrm{Fe_3P + HNO_3 \longrightarrow Fe(NO_3)_3 + NO + H_3PO_4 + H_2O}$

(4) $\mathrm{Cu(IO_3)_2 + KI + H_2SO_4 \longrightarrow CuI\downarrow + I_2 + K_2SO_4 + H_2O}$

(5) $\mathrm{NH_4ClO_4 \longrightarrow N_2\uparrow + HCl\uparrow + O_2\uparrow + H_2O}$

**参考答案**：

(1) $\mathrm{6KMnO_4 + 10FeCl_2 + 24H_2SO_4 = 3K_2SO_4 + 6MnSO_4 + 5Fe_2(SO_4)_3 + 10Cl_2 + 24H_2O}$

(2) $\mathrm{K_2Cr_2O_7 + 6Fe_3O_4 + 31H_2SO_4 = Cr_2(SO_4)_3 + 9Fe_2(SO_4)_3 + K_2SO_4 + 31H_2O}$

(3) $\mathrm{3Fe_3P + 41HNO_3 = 9Fe(NO_3)_3 + 14NO + 3H_3PO_4 + 16H_2O}$

(4) $\mathrm{2Cu(IO_3)_2 + 24KI + 12H_2SO_4 = 2CuI\downarrow + 13I_2 + 12K_2SO_4 + 12H_2O}$

(5) $\mathrm{4NH_4ClO_4 = 2N_2\uparrow + 4HCl\uparrow + 5O_2\uparrow + 6H_2O}$

> 来源：[上海中学竞赛课程·第1分册·第一讲 题1(1)-(5)](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第2题 ⭐ [上中·氧化还原]

配平下列化学反应方程式：

(6) $\mathrm{AsH_3 + AgNO_3 + H_2O \longrightarrow As_2O_3 + Ag + HNO_3}$

(7) $\mathrm{NO_x + NH_3 \longrightarrow N_2 + H_2O}$（x 为 NOₓ 中氧原子数）

(8) $\mathrm{Cl_m + OH^- \longrightarrow ClO_n^- + Cl^- + H_2O}$（m、n 为正整数）

(9) $\mathrm{VO_2^+ + H_2C_2O_4\cdot 2H_2O + H^+ \longrightarrow VO^{2+} + CO_2\uparrow + H_2O}$

(10) $\mathrm{CrCl_3 + KMnO_4 + H_2O \longrightarrow K_2Cr_2O_7 + MnCl_2 + HCl + MnCr_2O_7}$

**参考答案**：

(6) $\mathrm{2AsH_3 + 12AgNO_3 + 3H_2O = As_2O_3 + 12Ag + 12HNO_3}$

(7) $\mathrm{6NO_x + 4xNH_3 = (2x+3)N_2 + 6xH_2O}$

(8) $\mathrm{\dfrac{2n}{m}Cl_m + 2nOH^- = ClO_n^- + (2n-1)Cl^- + nH_2O}$

(9) $\mathrm{2VO_2^+ + H_2C_2O_4\cdot 2H_2O + 2H^+ = 2VO^{2+} + 2CO_2\uparrow + 4H_2O}$

(10) $\mathrm{10CrCl_3 + 6KMnO_4 + 11H_2O = 3K_2Cr_2O_7 + 4MnCl_2 + 22HCl + 2MnCr_2O_7}$

> 通式题提示：(7) 中 N 从 +2x（NOₓ）降到 0、从 −3（NH₃）升到 0，得失电子相等；(8) 中 Cl⁰ 歧化为 ClOₙ⁻（+2n−1）与 Cl⁻（−1），须 (2n−1) = (2n−1)。
> 来源：[上海中学竞赛课程·第1分册·第一讲 题1(6)-(10)](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第5题 ⭐ [上中·氧化还原]

一个完整的氧化-还原反应式可以拆写成两个"半反应"，如 $2\mathrm{Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}}$ 拆写为：氧化反应 $\mathrm{Cu - 2e = Cu^{2+}}$；还原反应 $\mathrm{Fe^{3+} + e = Fe^{2+}}$。据此，请将下列反应拆写成两个"半反应"式：

$$\mathrm{3NO_2 + H_2O = 2H^+ + 2NO_3^- + NO}$$

氧化反应：____；还原反应：____。

**参考答案**：

氧化反应：$\mathrm{H_2O + NO_2 - e = NO_3^- + 2H^+}$

还原反应：$\mathrm{2H^+ + NO_2 + 2e = NO + H_2O}$

> 合并验证：氧化×2 + 还原×1 → 3NO₂ + H₂O = 2NO₃⁻ + NO + 2H⁺。氮从 +4 歧化为 +5（失 e）与 +2（得 2e）。
> 来源：[上海中学竞赛课程·第1分册·第一讲 题3](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第6题 ⭐ [初赛讲义]

制备硫代硫酸盐的一种方法是令甲酸盐在碱性条件下还原亚硫酸盐。写出反应的离子方程式。已知反应过程中没有产生气体。

**参考答案**：

$$\mathrm{2SO_3^{2-} + 4HCO_2^- \longrightarrow S_2O_3^{2-} + 2C_2O_4^{2-} + 2OH^- + H_2O}$$

> 甲酸根（HCO₂⁻，C⁺²）被氧化为草酸根（C₂O₄²⁻，C⁺³），S⁺⁴ → S⁺²，电子守恒 4e。无气体生成是关键提示。
> 来源：[化学竞赛初赛讲义·第1讲 习题1.10](04-题库/教材习题/化学竞赛初赛讲义/题-011-初赛讲义-反应方程式-习题1.10)

## 第7题 ⭐ [初赛讲义]

氨基磺酸（$\mathrm{NH_3SO_3}$）的制备有多种方法，其中一种是用 $\mathrm{SO_3}$ 与 $\mathrm{NH_3}$ 直接反应，另一种则是令尿素与发烟硫酸反应。请写出两个反应的方程式，要求各物种以体系中实际存在的主要形式表示。

**参考答案**：

第一个反应：$\mathrm{SO_3 + NH_3 \longrightarrow NH_2SO_3H}$

第二个反应：$\mathrm{CO(NH_2)_2 + H_2SO_4\cdot SO_3 \longrightarrow 2NH_2SO_3H + CO_2}$

## 第8题 ⭐ [初赛讲义]

一定条件下，在氯化亚铁的溶液中加入碳酸钠溶液后得到一种绿色沉淀，其化学式为 $\mathrm{Fe_{12}(OH)_{24}(CO_3)Cl_2}$，该沉淀进一步被空气氧化为氢氧化铁。写出后一步反应的化学方程式。

**参考答案**：

$$\mathrm{Fe_{12}(OH)_{24}(CO_3)Cl_2 + 2O_2 + 8H_2O + 3CO_3^{2-} \longrightarrow 12Fe(OH)_3 + 4HCO_3^- + 2Cl^-}$$

> 提示：产物中有碳酸氢根，不能补酸碱；可以拆开配平。Fe 平均价态为 +7/3，升至 +3 共失 8e，2O₂ 得 8e。

## 第9题 ⭐ [真题·第38届初赛]

写出 $\mathrm{KMnO_4}$ 氧化 KI 以及 $\mathrm{Na_2S_2O_3}$ 溶液滴定 $\mathrm{I_2}$ 的离子方程式。

## 第10题 ⭐ [元素·氧族]

(1) 画出 $\mathrm{S_2O_3^{2-}}$ 的结构特点，指出两种 S 的氧化态。(2) 解释为何 $\mathrm{S_2O_3^{2-}}$ 与 $\mathrm{I_2}$ 反应生成连四硫酸根 $\mathrm{S_4O_6^{2-}}$ 而非 $\mathrm{SO_4^{2-}}$，写出配平方程式。

**参考答案**：

(1) 硫代硫酸根可看作 $\mathrm{SO_4^{2-}}$ 中一个端氧被硫取代——中心 S（+6）与三个 O 和一个端 S（−2）四面体配位。两个 S 氧化态截然不同（+6 与 −2）。

(2) $\mathrm{S_2O_3^{2-}}$ 中**端 S(−2)** 被氧化偶联：

$$\mathrm{2S_2O_3^{2-} + I_2 \longrightarrow S_4O_6^{2-} + 2I^-}$$

两个端 S 由 −2 氧化到平均 0 价，S—S 键相连成 $\mathrm{S_4O_6^{2-}}$；**不发生中心 S(+6) 的变化**，故不直接生成 $\mathrm{SO_4^{2-}}$（只有强氧化剂如 Cl₂ 才进一步氧化到 $\mathrm{SO_4^{2-}}$）。这正是碘量法用 $\mathrm{Na_2S_2O_3}$ 滴定 I₂ 的依据。

> 易错点：$\mathrm{S_4O_6^{2-}}$ 中 S 平均价态 +2.5，不是整数价态；计量比 I₂:S₂O₃²⁻ = 1:2。
> 来源：[元素化学·题-元氧-02](04-题库/元素化学/p区-氧族氮族/题-元氧-02-S2O3与I2反应)

## 第11题 ⭐⭐⭐ [上中·氧化还原]

已知铁溶于一定浓度的硝酸溶液中，反应的离子方程式为（系数 a～k 均为正整数）：

$$a\mathrm{Fe} + b\mathrm{NO_3^-} + c\mathrm{H^+} \longrightarrow d\mathrm{Fe^{2+}} + f\mathrm{Fe^{3+}} + g\mathrm{NO\uparrow} + h\mathrm{N_2O\uparrow} + k\mathrm{H_2O}$$

(1) 根据反应中氮、氢、氧三种元素的原子个数守恒，可得 c、g、h 的关系式是____；

(2) 根据反应中离子的电荷守恒，可得 b、c、d、f 的关系式是____；

(3) 根据反应中电子转移的总数相等，可得 d、f、g、h 的关系式是____；

(4) 若 a = 12，且铁和稀硝酸恰好完全反应，则 b 的取值范围是____。

**参考答案**：

(1) $c = 4g + 10h$（由 N：b = g + 2h；O：3b = g + h + k；H：c = 2k 联立）

(2) $c - b = 2d + 3f$

(3) $2d + 3f = 3g + 8h$

(4) $6 \leqslant b \leqslant 12$

> 第(4)问：a=12 时 d+f=12，2d+3f ∈ [24, 36]；b = g + 2h。下界取 Fe 全为 Fe²⁺ 且只生成 N₂O（3g+8h=24，h=3,g=0）→ b=6；上界取 Fe 全为 Fe³⁺ 且只生成 NO（3g=36,g=12）→ b=12。
> 来源：[上海中学竞赛课程·第1分册·第一讲 题2](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第12题 ⭐⭐⭐ [上中·氧化还原]

已知某物质 $\mathrm{XO(OH)_2^+}$ 与 $\mathrm{Na_2SO_3}$ 反应时，$\mathrm{XO(OH)_2^+}$ 作氧化剂，$\mathrm{Na_2SO_3}$ 被氧化为 $\mathrm{Na_2SO_4}$。现有 0.1 mol $\mathrm{XO(OH)_2^+}$ 需要 100 mL 2.5 mol/L $\mathrm{Na_2SO_3}$ 溶液才能把该物质还原。试问 $\mathrm{XO(OH)_2^+}$ 还原后 X 的最终价态是多少？

**参考答案**：

X 的最终价态为 **0**。

解析：$n(\mathrm{Na_2SO_3}) = 0.100 \times 2.5 = 0.25$ mol。S⁺⁴ → S⁺⁶ 每个失 2e，共失 $0.25 \times 2 = 0.50$ mol e⁻。0.1 mol $\mathrm{XO(OH)_2^+}$ 得 0.5 mol e⁻，即每个 X 得 5e⁻。$\mathrm{XO(OH)_2^+}$ 中 X 价态：$x + 2(-2) + 2(-1) + 1 = 0$ → $x = +5$。+5 − 5 = 0。

> 来源：[上海中学竞赛课程·第1分册·第一讲 题4（1995年山西省竞赛）](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第13题 ⭐⭐⭐ [上中·氧化还原]

法医常用马氏试砷法检验是否砷中毒。这种方法是用锌、盐酸和试样混合，将产生的气体导入热玻璃管，如试样中含有砷的化合物，将在玻璃管中形成亮黑色的砷镜。有关反应是①____；②____。确证亮黑色物质是砷镜而不是锑镜，可用 NaClO 溶液检验，锑镜不溶而砷镜能溶于 NaClO 溶液，反应方程式是____。

**参考答案**：

① $\mathrm{As_2O_3 + 6Zn + 12HCl = 2AsH_3\uparrow + 6ZnCl_2 + 3H_2O}$

② $2\mathrm{AsH_3 \xrightarrow{\triangle} 2As + 3H_2\uparrow}$

砷镜与 NaClO 反应：$2\mathrm{As + 5NaClO + 3H_2O = 2H_3AsO_4 + 5NaCl}$

> 来源：[上海中学竞赛课程·第1分册·第一讲 题5](04-题库/教材习题/上海中学竞赛课程/题-042-上海中学-氧化还原反应-习题1)

## 第14题 ⭐⭐⭐ [上中·氧化还原]

2 mol $\mathrm{I_2}$ 和 3 mol $\mathrm{I_2O_5}$ 的混合物在浓硫酸中反应生成 $(\mathrm{IO})_2\mathrm{SO_4}$；若在发烟硫酸（化学式为 $\mathrm{H_2SO_4\cdot SO_3}$）中反应得 $\mathrm{I_2(SO_4)_3}$。后者小心和水反应得碘和四氧化二碘。请写出生成 $\mathrm{I_2(SO_4)_3}$ 及其和水反应的方程式。

**参考答案**：

生成 $\mathrm{I_2(SO_4)_3}$：$2\mathrm{I_2 + 3I_2O_5 + 15H_2SO_4\cdot SO_3 = 5I_2(SO_4)_3 + 15H_2SO_4}$

与水反应：$4\mathrm{I_2(SO_4)_3 + 12H_2O = I_2 + 3I_2O_4 + 12H_2SO_4}$

## 第30题 ⭐⭐⭐⭐ [元素·氧族]

## 第31题 ⭐⭐⭐⭐ [真题·第35届初赛]

$4.38\,\mathrm{g}$ 元素 A 的单质在 $\mathrm{HNO_3}$ 中加热，完全反应后得到 $6.16\,\mathrm{g}$ 固体 B（A 的氧化物），并放出红棕色的气体（反应1）。A 也可以与氢氧化钠反应，发生歧化，生成两种盐 C 和 D（反应2），C 中 A 元素的氧化数与其在 B 中相同。B 与邻苯二胺反应生成 E，E 含元素 A 且具有特征的荧光光谱，据此可进行苯二胺异构体共存下邻苯二胺的含量分析。

**5-1** 通过计算和分析，确定元素 A。

**5-2** 分别写出 A 在酸和碱中反应的方程式。

**5-3** 画出化合物 E 的结构简式。

**参考答案**：

**5-1** 元素 A 为 **Se（硒）**。设氧化物 B 为 $\mathrm{A_2O_n}$，由 $n_\mathrm{A} = \dfrac{4.38}{M_\mathrm{A}} = 2\times\dfrac{6.16}{2M_\mathrm{A}+16.00n}$ 得 $M_\mathrm{A} = 19.7n$。分类讨论：n=4 时 $M_\mathrm{A}\approx 78.8$，对应 Se（79.0）；且 Se 为非金属，可在碱中歧化。B 为 $\mathrm{SeO_2}$。

**5-2** 反应1（酸）：$\mathrm{Se + 4HNO_3 \longrightarrow SeO_2 + 4NO_2 + 2H_2O}$；反应2（碱，歧化）：$\mathrm{3Se + 6NaOH \longrightarrow 2Na_2Se + Na_2SeO_3 + 3H_2O}$

**5-3** 邻苯二胺与 $\mathrm{SeO_2}$ 缩合得**苯并硒二唑**（含 N—Se—N 五元杂环，大共轭体系 → 特征荧光）：

```
      __________
     /          \
    |    N===Se  |
    |    |       |
    |    N       |
     \__________/
    （苯并硒二唑）
```

> 得分点：5-1 正确确定元素 3 分；5-2 正确写两方程式 2 分；5-3 正确画结构 2 分。C 为 $\mathrm{Na_2SeO_3}$（Se +4，与 SeO₂ 相同），D 为 $\mathrm{Na_2Se}$（−2）。间位、对位苯二胺不能成环 → 可用于选择性检测。
> 来源：[第35届初赛 第5题](04-题库/真题/第35届初赛/无机和结构化学/题-035-5-元素推断与反应方程式)

## 第32题 ⭐⭐⭐⭐ [初赛讲义]

$\mathrm{SOCl_2}$ 与 $\mathrm{NaN_3}$ 在 −30°C 的条件下反应生成无色晶体 **X**，其中含有 36.4%（质量分数）的 Cl。**X** 由环状三聚体构成。写出反应方程式，**X** 要用结构式表示。又，无色液体 **Y** 由 **X** 与 $\mathrm{SbF_3}$ 反应得到。在过量 $\mathrm{Ba(CH_3COO)_2}$ 溶液中加入 1.00 g **Y** 生成 3.96 g 沉淀（两种常见含钡的白色沉淀）。试问：产生沉淀的化学方程式是什么？

**参考答案**：

$3\mathrm{SOCl_2 + 3NaN_3 \longrightarrow S_3O_3N_3Cl_3 + 3NaCl + 3N_2}$

X 为环状三聚体，六元环由 S 与 N 交替构成，每个 S 上连 1 个 O（S=O）与 1 个 Cl：$\mathrm{[{-}S{=}O(Cl){-}N{=}]_3}$。验证 Cl 含量：$3\times35.45\,/\,291.5 = 36.5\% \approx 36.4\%$ ✓。

Y 为氟代产物 $\mathrm{S_3O_3N_3F_3}$（$M = 243$）。$n(\mathrm{Y}) = 1.00/243 = 4.12\times10^{-3}$ mol，按 $2\mathrm{Y} \sim 3\mathrm{BaF_2} + 6\mathrm{BaSO_4}$：$m = 0.00618\times175 + 0.0123\times233 = 1.08 + 2.87 = 3.95$ g ≈ 3.96 g ✓。故沉淀反应为：

$2\mathrm{S_3O_3N_3F_3 + 9Ba(CH_3COO)_2 + 18H_2O \longrightarrow 3BaF_2 + 6BaSO_4 + 6NH_4CH_3COO + 12CH_3COOH}$

> 来源：[化学竞赛初赛讲义·第1讲 习题1.30](04-题库/教材习题/化学竞赛初赛讲义/题-004-初赛讲义-反应方程式-习题1.30)
