### 基础回顾（第1–10题）

**第1题**：A。轨道能级顺序为 2s < 2p < 3s < 3p < 4s < 3d，故3d能量最高。

**第2题**：A。氢原子为单电子体系，轨道能量仅取决于主量子数n，与角量子数l无关。因此 $E(2s) = E(2p)$，$E(3s) = E(3p) = E(3d)$，能级简并。其他多电子原子因屏蔽效应和钻穿效应，$E(ns) < E(np) < E(nd)$。

**第3题**：

| n | l | m | 轨道符号 | 亚层轨道数 | 电子数 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 4 | 0 | 0 | 4s | 1 | 2 |
| 4 | 1 | -1, 0, 1 | 4p | 3 | 6 |

**第19题**：

（1）Na + Rb⁺ → Na⁺ + Rb：$I_1(\mathrm{Na}) = 496 > I_1(\mathrm{Rb}) = 403$ kJ/mol → $\Delta H > 0$ → **不自发**。
（2）F⁻ + Cl → Cl⁻ + F：$EA(\mathrm{Cl}) = 349 > EA(\mathrm{F}) = 328$ kJ/mol → $\Delta H = 328 - 349 = -21$ kJ/mol → **自发**。
（3）N⁺ + O → N + O⁺：$I_1(\mathrm{N}) = 1402 > I_1(\mathrm{O}) = 1314$ kJ/mol → $\Delta H < 0$ → **自发**。
（4）Br⁻ + I → I⁻ + Br：$EA(\mathrm{Br}) = 325 > EA(\mathrm{I}) = 295$ kJ/mol → $\Delta H = 295 - 325 = -30$ kJ/mol → **自发**。

（2）的反应热：$\Delta H = EA(\mathrm{F}) - EA(\mathrm{Cl}) = -328 - (-349) = -21$ kJ/mol，或由 $\Delta H = I_1(\mathrm{F}) - I_1(\mathrm{Cl})$ 的等效方式（两种分析等价）。

- 角动量量子化：$mvr = \frac{nh}{2\pi}$

（a）A的$I_3 \gg I_2$（7733 vs 1451）→A有2个价电子→IIA族。$I_1 = 738$接近Mg(738)→**A = Mg**。验证：Mg²⁺为[Ne]全满构型→移除第三个电子需破坏核心→I₃骤增。

（b）Mg的$I_3 \gg I_2$：Mg²⁺为$1s^2 2s^2 2p^6$（Ne构型），全满→第三个电子需从稳定的2p核心移除→能量骤增。Na的$I_2 \gg I_1$：Na⁺为$1s^2 2s^2 2p^6$（Ne构型），全满→第二个电子需从核心移除→能量骤增。两者本质相同：离子达到稀有气体构型后再电离需破坏核心电子。

（c）$I_1(\mathrm{Mg}) = 738 > I_1(\mathrm{Na}) = 496$。Mg的$3s^2$全满→额外交换能稳定化→比Na的$3s^1$更难失去电子。Mg核电荷(12)也大于Na(11)，对最外层电子束缚更强。

**第29题**：
（a）X：含氧酸中X为+7氧化态→VIIA族，气态氢化物为强酸→**X = Cl**（HCl强酸，HClO₄强酸）。Y：+1价离子与Ne等电子→$Y^+$为$1s^2 2s^2 2p^6$→Y为Na（第三周期IA族，金属性最强）。Z：气态氢化物弱碱性→NH₃型→VA族，最高氧化态含氧酸为强酸→**Z = N**（HNO₃强酸）。

（b）Cl：$[Ne] 3s^2 3p^5$。Na：$[Ne] 3s^1$。N：$[He] 2s^2 2p^3$。

（c）$I_1$大小：N(1402) > Cl(1251) > Na(496)。N的$2p^3$半满稳定→I₁最高。Cl的$2p^5$接近全满→I₁较高。Na的$3s^1$易失去→I₁最低。

（d）$\chi$大小：Cl(3.16) > N(3.04) > Na(0.93)。Cl和N为非金属→电负性高。Cl的核电荷大、原子半径相对小→对电子束缚强→$\chi$略高于N。Na为活泼金属→极易失去电子→$\chi$极低。

### 补充拓展（第30–35题）

**第30题**：
（a）Mulliken电负性定义：$\chi_M = (I_1 + EA)/2$，即电离能和电子亲和能的平均值。物理意义：原子同时给出和接受电子能力的综合度量。与Pauling标度的线性关系：$\chi_P \approx 1.35\sqrt{\chi_M} - 1.37$（近似），两者衡量的是相同的电子亲和属性，只是参考标度不同。对非金属元素，两种标度数值接近。

（b）$\chi_M(\mathrm{C}) = (11.26 + 1.26)/2 = 6.26$ eV；$\chi_M(\mathrm{O}) = (13.62 + 1.46)/2 = 7.54$ eV。Pauling标度：C = 2.55, O = 3.44。比值：$\chi_M(\mathrm{O})/\chi_M(\mathrm{C}) = 7.54/6.26 = 1.20$，$\chi_P(\mathrm{O})/\chi_P(\mathrm{C}) = 3.44/2.55 = 1.35$。趋势一致（O > C），但定量有偏差，因Pauling标度基于键能数据而Mulliken基于光谱数据。

（c）Li($[He]2s^1$)和Mg($[Ne]3s^2$)位于对角线位置。Li的$I_1 = 520$, $EA \approx 0$ eV → $\chi_M \approx 2.60$ eV；Mg的$I_1 = 738$, $EA \approx 0$ → $\chi_M \approx 3.69$ eV。Pauling标度Li=0.98, Mg=1.31。两者电负性接近的原因：Li虽核电荷小但仅1个价电子屏蔽差，Mg核电荷大但2个3s电子互相屏蔽→有效核电荷效应部分抵消→电负性相近。这也是对角线关系的根本原因。

**第31题**：
（a）Be²⁺：$Z=4, r=27$ pm, $\phi = 4/27 = 0.148$ pm⁻¹。Al³⁺：$Z=13, r=50$ pm, $\phi = 13/50 = 0.260$ pm⁻¹。Al³⁺的离子势更大，但两者都属于"高电荷密度小"的阳离子→极化能力强→与O²⁻形成共价性显著的键→氧化物为两性。BeO + 2OH⁻ → [Be(OH)₄]²⁻（溶于碱）；BeO + 2H⁺ → Be²⁺ + H₂O（溶于酸）。

（b）$\mathrm{Be(OH)}_2 + 2\mathrm{NaOH} \to \mathrm{Na_2[Be(OH)_4]}$
$\mathrm{Al(OH)}_3 + \mathrm{NaOH} \to \mathrm{Na[Al(OH)_4]}$
Be(OH)₂酸性比Al(OH)₃强：Be²⁺的离子势(0.148)虽小于Al³⁺(0.260)，但Be²⁺的电荷/半径比在同族中较高→Be-O键共价性更强→更易形成含氧酸形式→酸性更强。实际pKₐ：Be(OH)₂约6（弱酸），Al(OH)₃约12（极弱酸）。

（c）有共同原因：阳离子极化能力。Li⁺半径小(76 pm)→极化CO₃²⁻中O²⁻→削弱C-O键→易分解。Mg²⁺电荷高(+2)且半径小(72 pm)→极化CO₃²⁻→易分解。Na⁺(102 pm)和Ca²⁺(100 pm)半径较大→极化能力弱→碳酸盐稳定。这与离子极化理论（Fajans规则）一致。

**第32题**：
（a）Na的3s电子：电子排布$1s^2 2s^2 2p^6 3s^1$。按Slater规则分组：(1s²)(2s²2p⁶)(3s¹)。

对3s电子的屏蔽来自：
- 同组(3s)：0个其他电子 → 0
- n-1层(2s²2p⁶)：8个电子 × 0.85 = 6.80
- n-2层(1s²)：2个电子 × 1.00 = 2.00

$\sigma = 6.80 + 2.00 = 8.80$（注：对3s电子，(3s)组中只有1个电子，无同组屏蔽）

$Z^* = 11 - 8.80 = 2.20$

（b）Ti的3d电子：$[\mathrm{Ar}] 3d^2 4s^2$。3d电子：来自内层的全部电子（$1s^2 2s^2 2p^6 3s^2 3p^6$ = 18个）对3d的屏蔽：18 × 1.00 = 18.00。

$Z^* = 22 - 18.00 = 4.00$

（c）Fe²⁺的3d电子：Fe²⁺为$[\mathrm{Ar}] 3d^6$（24个电子）。3d有6个电子，对目标3d电子的屏蔽：内层18个电子 × 1.00 = 18.00 + 同组5个电子 × 0.35 = 1.75。

$\sigma = 18.00 + 1.75 = 19.75$

$Z^* = 26 - 19.75 = 6.25$

**第33题**：
（a）加入KSCN后变血红色→溶液中有Fe³⁺→A中铁为+3氧化态。

（b）Fe³⁺为$3d^5$。在强场配体（如CN⁻）场中，$d^5$可以为低自旋$t_{2g}^5 e_g^0$（1个未成对电子）或$t_{2g}^3 e_g^2$（高自旋，5个未成对）。但A为反磁性（0个未成对电子）→不可能是$d^5$构型。修正：若配体为强场（如CN⁻），$d^5$低自旋仍有1个未成对电子→不可能完全反磁。因此A可能为[Fe(CN)₆]⁴⁻（Fe²⁺, $d^6$低自旋$t_{2g}^6$，0个未成对电子→反磁性）。

重新分析：溶液加KSCN变血红→说明有Fe³⁺存在。可能是配合物A在酸中解离释放Fe²⁺，后被氧化为Fe³⁺。或者A本身为Fe²⁺配合物，酸溶后被空气氧化。**A = [Fe(CN)₆]⁴⁻**（亚铁氰化钾，黄血盐），Fe²⁺ $d^6$低自旋$t_{2g}^6$，0个未成对电子，反磁性。酸中解离释放Fe²⁺→被氧化为Fe³⁺→与SCN⁻显血红色。

（c）化学式：$\mathrm{K_4[Fe(CN)_6]}$（黄血盐）或$\mathrm{[Fe(H_2O)_6]^{2+}}$不满足反磁性（$d^6$高自旋有4个未成对电子）。最合理答案：$\mathrm{[Fe(CN)_6]^{4-}}$。

**第34题**：
（a）Mo（Z=42）：常规预测$[\mathrm{Kr}] 4d^4 5s^2$，实际为 $[\mathrm{Kr}] 4d^5 5s^1$。原因：4d⁵半满（5个电子分占5个d轨道，交换能最大化）→额外稳定化→比4d⁴ 5s²更稳定。与Cr（3d⁵ 4s¹）同理。

（b）Ag（Z=47）：常规预测$[\mathrm{Kr}] 4d^9 5s^2$，实际为 $[\mathrm{Kr}] 4d^{10} 5s^1$。原因：4d¹⁰全满→额外稳定化能→比4d⁹ 5s²更稳定。与Cu（3d¹⁰ 4s¹）同理。

（c）Pd（Z=46）：常规预测$[\mathrm{Kr}] 4d^8 5s^2$，实际为 $[\mathrm{Kr}] 4d^{10} 5s^0$（所有电子都在4d中，5s为空）。原因：Pd的4d轨道能量与5s非常接近，且4d¹⁰全满的额外稳定化能足够大→将5s的2个电子也"拉入"4d→形成全满构型。这是最极端的Aufbau例外。

**第35题**：
（a）H原子：$I_1(\text{expt}) = 13.598$ eV，$-\varepsilon_{1s} = 13.6$ eV。差值仅0.002 eV（0.015%）。Koopmans定理适用极好——因为H是单电子体系，电离后无电子弛豫（没有其他电子重排），定理的近似条件完全满足。

（b）He的$I_1 = 24.6$ eV，而$-\varepsilon_{1s} \approx 54.4/1 = 54.4$ eV（若忽略电子间排斥）。差值 $54.4 - 24.6 = 29.8$ eV。原因：$-\varepsilon_{1s} = 54.4$ eV是将两个电子视为完全独立时的计算值（$E = -2 \times Z^2 \times 13.6$ eV / 2 = -Z² × 13.6 eV）。实际上两个1s电子间有强烈的排斥→每个电子的有效核电荷远小于Z=2→真实轨道能量远高于理论值。Koopmans定理在此偏差大因为：①忽略了电子间排斥（电子相关能）；②He⁺（电离后）与He的轨道弛豫效应显著。

（c）过渡金属中：4s轨道虽然先填充（因中性原子中4s能量低于3d），但3d电子对4s的屏蔽使4s的有效核电荷下降。电离时，从轨道能量角度看，4s电子的实际轨道能量高于3d（因3d对4s的屏蔽+3d更强的核吸引）。根据Koopmans定理，$I \approx -\varepsilon$，$\varepsilon(4s) > \varepsilon(3d)$ → $I(4s) < I(3d)$ → 先失去4s。
