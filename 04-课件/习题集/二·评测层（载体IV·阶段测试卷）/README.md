# 二 · 评测层（载体 IV · 阶段测试卷）

> **用途**：**限时计分**的单科整卷。题源以**竞赛导向·真题**（小问拼卷）为主。
> 规格：100 分 / 150 分钟 / 约 50 小问；**卷答分离**（答案单独成册，含易错分析）。
> **规格**见 [[04-题库/题库按用途分类说明]] §3C「规格 IV」。

## 与其他层的关系

- 与**一·随堂层**：本层**限时计分**、卷答分离；随堂层不限时、题答同卷。
- 与**三·竞赛导向层**：本层为**真题小问拼卷**（考核定位）；竞赛导向层为**专题/综合训练**（教学定位）。
- ⚠️ **同名注意**：`04-题库/有机化学阶段测试卷`（题库侧中间产物）与课件侧正式卷同名 —— 见 [[04-题库/组卷工作台]] 说明。
- 共题台账：各卷 `used_in` 字段（**累积台账，非当前占用**，详见 [[04-题库/题库按用途分类说明]] §3E）。
