## 6.1 核反应方程式 〔🟢 d2〕（第36届初赛第二场）

>

初步研究表明，嫦娥石中含有 ${}^{3}He$ ，$FeO_6$ 和 $PO_4$ 可能是其吸附位置。${}^{3}He$ 已用于中子探测，也很可能成为人类未来的能源。${}^{3}He$ 与中子作用产生质子和氚，写出核反应方程式。

<details>
<summary>📖 查看答案</summary>

书写核反应方程式时，要注意将所有粒子物种的核电荷数和质量数标出，同时保证反应前后核电荷数和质量数守恒：

将 $^{3}_{1}H$ 写为 $^{3}_{1}T$ 也可以。

$$
{ } _ { 2 } ^ { 3 } \mathrm{He} + { } _ { 0 } ^ { 1 } \mathrm{n} \longrightarrow { } _ { 1 } ^ { 3 } \mathrm{H} + { } _ { 1 } ^ { 1 } \mathrm{H}
$$

| 知识点 | 直接关联 |
|:---|:---:|
| 核反应 | ✅ |
| 核反应方程式 | ✅ |
| 质量数与核电荷数守恒 | ✅ |

</details>

## 6.2 题-赵鑫光-基础-习13 〔🟢 d4〕

13. 在科学院出版物《化学指南》里有下列一些物质饱和蒸气压的数据。

| 物质 | 温度(°C) | 蒸气压(mmHg) | 密度(g/L) |
| --- | --- | --- | --- |
| 苯 $C_6H_6$ | 80.1 | 760 | 2.710 |
| 甲醇 $CH_3OH$ | 49.9 | 400 | 0.673 |
| 醋酸 $CH_3COOH①$ | 29.9 | 20 | 0.126 |
| 醋酸 $CH_3COOH②$ | 118.1 | 760 | 3.110 |

(1)根据所列数字计算蒸气的摩尔质量(假设蒸气中的分子类似理想气体分子)。

(2)如何解释相对质量的理论值与所得计算值之间的偏差？对此给出定性的并尽可能定量的解释。

<details>
<summary>📖 查看答案</summary>

(1) $M(\mathrm{C}_{6}\mathrm{H}_{6}) = 78.5 \, \text{g/mol}, M(\mathrm{CH}_{3}\mathrm{OH}) = 33 \, \text{g/mol}, M(\mathrm{HAc})$ ① $= 118.9 \, \text{g/mol}, M(\mathrm{HAc})$ ② $= 99.8 \, \text{g/mol}$；

(2) 误差是由蒸气分子的性质偏离理想气体分子的性质引起的。此外在甲醇分子中有少量的分子缔合，而在醋酸分子中有二聚分子 $\left(\mathrm{CH}_{3}\mathrm{COOH}\right)_{2}$ 。

</details>
