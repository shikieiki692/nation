## 2.1 铬酸铅沉淀方程式（第29届初赛）

将热的硝酸铅溶液滴入热的铬酸钾溶液，产生碱式铬酸铅沉淀 $\left[\mathrm{Pb}_{2}(\mathrm{OH})_{2}\mathrm{CrO}_{4}\right]$ 。

向含氰化氢的废水中加入铁粉和 $\mathrm{K}_{2}\mathrm{CO}_{3}$ 制备黄血盐 $\left[\mathrm{K}_{4}\mathrm{Fe}(\mathrm{CN})_{6}\cdot3\mathrm{H}_{2}\mathrm{O}\right]$ 。

酸性溶液中，黄血盐用 $\mathrm{KMnO}_4$ 处理，被彻底氧化，产生 $\mathrm{NO}_3^{-}$ 和 $\mathrm{CO}_2$ 。

在水中 $\mathrm{Ag}_2\mathrm{SO}_4$ 与单质 S 作用，沉淀变为 $\mathrm{Ag}_2\mathrm{S}$ ，分离，所得溶液中加碘水不褪色。

<details>
<summary>📖 查看答案</summary>

**（1）**
化学方程式：

$$
2 \mathrm{Pb} (\mathrm{NO} _ {3}) _ {2} + 3 \mathrm{K} _ {2} \mathrm{CrO} _ {4} + \mathrm{H} _ {2} \mathrm{O} \longrightarrow \mathrm{Pb} _ {2} (\mathrm{OH}) _ {2} \mathrm{CrO} _ {4} + 4 \mathrm{KNO} _ {3} + \mathrm{K} _ {2} \mathrm{Cr} _ {2} \mathrm{O} _ {7}
$$

离子方程式：

$$
2 \mathrm{Pb} ^ {2 +} + 3 \mathrm{CrO} _ {4} ^ {2 -} + \mathrm{H} _ {2} \mathrm{O} \longrightarrow \mathrm{Pb} _ {2} (\mathrm{OH}) _ {2} \mathrm{CrO} _ {4} + \mathrm{Cr} _ {2} \mathrm{O} _ {7} ^ {2 -}
$$





这是一个非氧化还原的离子反应。首先明确酸碱性，本题中硝酸铅溶液为酸性，而铬酸钾为碱性，将硝酸铅溶液滴入碱性铬酸钾溶液，这说明产物体系为碱性，生成的 $\mathrm{H}^{+}$ 需要被中和。总反应可以看作下列两个反应的耦合：

沉淀反应 $2\mathrm{Pb}^{2+} + 2\mathrm{CrO}_4^{2-} + 2\mathrm{H}_2\mathrm{O}\longrightarrow \mathrm{Pb}_2(\mathrm{OH})_2\mathrm{CrO}_4 + 2\mathrm{H}^+$

同多酸缩聚反应 $2\mathrm{CrO}_4^{2-} + 2\mathrm{H}^+ \longrightarrow \mathrm{Cr}_2\mathrm{O}_7^{2-} + \mathrm{H}_2\mathrm{O}$

题目未要求写出化学方程式或离子方程式，故两种答案均可。

实际上，若交换滴加顺序，将铬酸钾滴入酸性的硝酸铅，会生成"铬黄"铬酸铅 $\mathrm{PbCrO}_{4}$ 。

## 2.6 一分册测试-Ch13A-1-碳族与硼族反应方程式

完成反应式：

1-1 适量的 $\mathrm{SnCl_2}$ 溶液加入 $\mathrm{HgCl_2}$ 溶液中得到白色沉淀。

1-2 Sn(Ⅱ) 的强碱溶液中加入硝酸铋溶液。

1-3 $\mathrm{BF_3}$ 通入 $\mathrm{Na_2CO_3}$ 溶液。

1-4 将 $\mathrm{Cl_2}$ 通入 $\mathrm{Pb(II)}$ 的碱性溶液中。

1-5 硼砂 $\mathrm{[Na_2B_4O_5(OH)_4 \cdot 8H_2O]}$ 溶液具有缓冲作用的原因。

<details>
<summary>📖 查看答案</summary>

**1-1** $\mathrm{2HgCl_2 + SnCl_2 = Hg_2Cl_2\downarrow + SnCl_4}$

**1-2** $\mathrm{3Sn(OH)_3^- + 2Bi^{3+} + 9OH^- = 3Sn(OH)_6^{2-} + 2Bi\downarrow}$

电子转移：Sn(II)→Sn(IV) 失 2e×3=6e；Bi(III)→Bi(0) 得 3e×2=6e。Bi(III) 在强碱中本应沉淀 Bi(OH)₃，但被 Sn(II) 还原为单质 Bi。

**1-3** $\mathrm{4BF_3 + 2CO_3^{2-} + 2H_2O = 3BF_4^- + B(OH)_4^- + 2CO_2\uparrow}$

部分 BF₃ 接受 F⁻ 形成 BF₄⁻（CO₃²⁻ 水解提供 OH⁻、F⁻ 在溶液中迁移）；部分 B 形成硼酸根 B(OH)₄⁻。

**1-4** $\mathrm{Pb(OH)_3^- + OH^- + Cl_2 = PbO_2 + 2Cl^- + 2H_2O}$

Pb(II)→Pb(IV) 失 2e；Cl₂→2Cl⁻ 得 2e。

**1-5** 硼砂在水中完全解离：$\mathrm{Na_2B_4O_5(OH)_4 = 2Na^+ + B_4O_5(OH)_4^{2-}}$

$\mathrm{B_4O_5(OH)_4^{2-} + 5H_2O \rightleftharpoons 2H_3BO_3 + 2B(OH)_4^-}$

硼砂水溶液同时含有弱酸 H₃BO₃（硼酸）与弱碱 B(OH)₄⁻（硼酸根），构成酸碱缓冲对。遇酸时 B(OH)₄⁻ + H⁺ → H₃BO₃；遇碱时 H₃BO₃ + OH⁻ → B(OH)₄⁻，从而稳定 pH。

## 2.7 一分册测试-Ch13B-1-碳族锗锡铅反应方程式

完成反应式：

1-1 足量 $\mathrm{SiF_4}$ 通入碳酸钠溶液。

1-2 $\mathrm{Ge(OH)_2}$ 溶于氢氧化钠溶液生成无色气体。

1-3 $\mathrm{GeO_2}$ 与 $\mathrm{BrF_3}$ 作用得到两种单质气体。

1-4 酸性 $\mathrm{SnCl_2}$ 溶液吸收臭氧。

1-5 硫化铅溶于稀硝酸。

<details>
<summary>📖 查看答案</summary>

**1-1** $\mathrm{3SiF_4 + 2Na_2CO_3 + 2H_2O = 2Na_2SiF_6 + H_2SiO_3\downarrow + 2CO_2\uparrow}$

部分 SiF₄ 水解生成 H₂SiO₃，部分 SiF₄ 与 NaF（F⁻ 来自水解产物）结合生成 Na₂SiF₆。

**1-2** $\mathrm{Ge(OH)_2 + 2NaOH = Na_2GeO_3 + H_2O + H_2\uparrow}$

Ge(II) 在强碱中歧化：3 Ge(OH)₂ → 2 GeO₃²⁻ + Ge↓（部分），此处题面按「生成 H₂」理解为 Ge(II) 还原水中 H⁺ 放 H₂，同时形成 GeO₃²⁻。答案侧以 H₂ 形式给出，照录。

**1-3** $\mathrm{3GeO_2 + 4BrF_3 = 3GeF_4 + 3O_2 + 2Br_2}$

BrF₃ 强氧化性氟化剂，将 GeO₂ 中 Ge(+4) 转为 GeF₄（仍 +4 价），同时 O²⁻ 被氧化为 O₂、BrF₃ 中 Br(+3) 被还原为 Br₂(0)。

**1-4** $\mathrm{3SnCl_2 + 6HCl + O_3 = 3SnCl_4 + 3H_2O}$

或 $\mathrm{3SnCl_2 + 12HCl + O_3 = 3H_2SnCl_6 + 3H_2O}$

O₃ 氧化 Sn(II)→Sn(IV) + 还原产物 O₂（隐含）。

**1-5** $\mathrm{3PbS + 8HNO_3 = 3Pb(NO_3)_2 + 3S\downarrow + 2NO\uparrow + 4H_2O}$

PbS 中 S(-2) 部分被 HNO₃ 氧化为 S(0) 沉淀（不被进一步氧化为 SO₄²⁻），Pb²⁺ 与 NO₃⁻ 形成 Pb(NO₃)₂。

## 2.8 一分册测试-Ch14A-1-碱金属反应方程式

写出下列反应的方程式：

1-1 亚硝酸钠与钠反应得到一种单质和一种氧化物。

1-2 铁远不如钠活泼，但高温下可以与碳酸钠反应制备出钠单质。

1-3 氟化铍溶于熔融的氟化钾。

1-4 氢化钙与碳酸钠溶液作用。

1-5 $\mathrm{Na_2O_2}$ 溶于水立即滴加 $\mathrm{KMnO_4}$ 溶液时，出现 $\mathrm{MnO_2}$ 沉淀并有氧气放出。

<details>
<summary>📖 查看答案</summary>

**1-1** $\mathrm{2NaNO_2 + 6Na \longrightarrow 4Na_2O + N_2\uparrow}$

Na 还原 NaNO₂（N+3 → 0）：6 Na 失 6e（每个 Na 失 1e），2 N(+3) 得 6e。

**1-2** $\mathrm{3Fe + 2Na_2CO_3 = Fe_3O_4 + 2CO\uparrow + 4Na\uparrow}$

从 $\mathrm{Fe_3O_4}$ 晶格的高度稳定性和大量气体的放出（体系的熵显著增大）解释高温反应推动力。

**1-3** $\mathrm{2KF + BeF_2 = K_2[BeF_4]}$（$\mathrm{BeF_4^{2-}}$ 配离子，Be sp³ 四面体）

**1-4** $\mathrm{CaH_2 + Na_2CO_3 + 2H_2O = CaCO_3\downarrow + 2NaOH + 2H_2\uparrow}$

$\mathrm{H^+}$ 由 CaH₂ 提供，与 $\mathrm{CO_3^{2-}}$ 反应生成 CO₂（与 H₂O 形成 $\mathrm{HCO_3^-}$），最终 Ca²⁺ 形成更难溶 CaCO₃。

**1-5** $\mathrm{2KMnO_4 + Na_2O_2 + 2H_2O = 2MnO_2\downarrow + 2KOH + 2NaOH + O_2\uparrow}$

Na₂O₂ 强氧化剂，KMnO₄ 还原为 MnO₂（Mn+4），Na₂O₂ 中过氧 O₂²⁻ 自分解放 O₂。

## 2.9 一分册测试-Ch14B-1-碱金属碱土金属反应方程式

<summary>📖 查看答案</summary>

## 2.27 元氧-02-S2O3与I2反应

(1) 画出 S₂O₃²⁻ 的结构特点，指出两种 S 的氧化态。(2) 解释为何 S₂O₃²⁻ 与 I₂ 反应生成连四硫酸根 S₄O₆²⁻ 而非 SO₄²⁻，写出配平方程式。

<details>
<summary>📖 查看答案</summary>

**(1) 结构**：硫代硫酸根可看作 SO₄²⁻ 中一个端氧被硫取代——中心 S(+6) 与三个 O 和一个端 S(−2) 四面体配位。两个 S 氧化态截然不同（+6 与 −2）。

**(2) 与 I₂ 反应**：S₂O₃²⁻ 中**端 S(−2)** 被氧化偶联：

$$2\mathrm{S_2O_3^{2-} + I_2 \rightarrow S_4O_6^{2-} + 2I^-}$$

两个端 S 由 −2 氧化到平均 0 价，S—S 键相连成 S₄O₆²⁻。**不发生中心 S(+6) 的变化**，故不直接生成 SO₄²⁻（只有强氧化剂如 Cl₂ 才进一步氧化到 SO₄²⁻）。这正是碘量法用 Na₂S₂O₃ 滴定 I₂ 的依据。

**答案**：S 为 +6 与 −2；I₂ 仅氧化端 S(−2) 偶联成 S₄O₆²⁻。

> **核心辨析**：S₂O₃²⁻ 的"两种 S 化学环境不同"是结构推断高频题；与 I₂ 的定量关系 1:1 是碘量法标定的基础。
