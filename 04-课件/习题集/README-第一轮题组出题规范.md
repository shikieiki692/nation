# 第一轮题组出题规范（竞赛导向练习）

> **用途**：本页是第一轮「竞赛导向练习」两系列（A 竞赛教材版 / B 综合套卷）的**唯一出题方法论**。
> **下次出题、扩卷、换题一律照此执行**，不要重新发明口径。
> **边界**：本规范只管**选题与编排**；Word 产物格式见 `工程细则速查.md` §六；题源字段口径见 `题库选题口径速查.md`。

## 一、先搞清「做什么产物」——这不是习题集

> ⚠️ **最容易搞错的一条。** 用户 2026-09-18 明确纠正：

| | **习题集**（不是本产物） | **竞赛导向练习**（本产物） |
|:---|:---|:---|
| 用途 | 上新课时的**课堂/课后**练习 | 第一轮**拔高训练** |
| 题源 | 可选**普通教材**习题 | **只能**来自竞赛书籍/教辅/真题 |
| 难度 | 贴课本 | **可超纲**、逐步向**真题靠拢** |
| 判据 | 覆盖知识点 | **「思路、理念、题型越接近真题，质量越好」** |

**推论**：`大学教材课后习题`（普化一类）**不进本系列**（`prio()` 里 = 99 排除）。历史上「第一轮化学原理·8 卷习题集」因普化占 32–40% 被用户判为「不太适合」，正是踩了这条。

## 二、题源优先序（`prio()`）

选题池 = `type ∈ {题目, 真题}` 且非 deprecated，**且**来源优先序 < 99：

| 序 | 来源类别 | 说明 |
|:--:|:---|:---|
| 0 | **真题** | 最优先，恒排最前（哨兵 `(-9,0,0,0)`） |
| 1 | 竞赛导向题集 | 竞赛教辅 |
| 2 | 竞赛教程 | |
| 3 | 竞赛教材·讲义 | |
| 4 | 自编/改编章节题 | |
| **99** | **大学教材课后习题** | **排除** |

> ⚠️ `source_category` 实际值**带前缀**（`竞赛导向·真题` / `竞赛导向·真题（省级）` / `其他类型·自编章节题`）。
> 匹配必须用 `in` 或带前缀，**按裸 `真题` 匹配会得 0**（09-18 踩过）。

## 三、质量闸门（`gate_v2` + `qscore`）

### 3.1 `gate_v2(r, fm, q, a, rej)` 结构闸门
过滤：题面/答案缺失、答案区混入题面、图片不在媒体仓库、题干过短等。
**设计意图（L1075）**：「有完整自足引子的多小问题」判**通过**（小问在答案侧是正确形态）。

### 3.2 `qscore(q, a)` 排序分：`(-fill, -ansc, optonly, -ctx)`
- `fill`：填空占比越高越靠后
- `ansc`：答案解析充分度
- `optonly`：纯选择题惩罚
- `ctx`：情境/引子长度
- **多题容器**（`_is_multi`：顶层题号 ≥2）→ 返回中性 `(0,0,0,0)`，不参与偏好排序

### 3.3 排序键（**不可随意调序**）
```
(reuse_tier, LEVMAP, qs, seq, path)
```
- `reuse_tier` **第一键**：未用 0 < 已用可回收 1 < 已发给学生 2 → **未用 B 级排在已用 A 级之前，是设计意图**（用户要「优先用未用的题」）
- `qs` **必须排在 `LEVMAP` 之后**（否则 `nsub` 主导 → S1 卷 A/A- 由 20 掉 15）
- `seq` 用**同源 round-robin 序号**（防短文件名源垄断前 N 题）

## 四、两个产物怎么分（核心区别）

| 维度 | **A · 竞赛教材版**（15 专题卷） | **B · 综合套卷**（12 套） |
|:---|:---|:---|
| 用途 | **跟课用**（学完一章练一章） | **阶段检验**（跨专题迁移） |
| 路由 | 按章标签 → **单一专题桶** | 「结构 ＋ 原理」→ **跨桶打散** |
| 规模 | 566 题（14 卷×40 ＋ S6=9 ＋ P7=37） | 315 题（去重）／每套 26~27 题 |
| 配额 | `QUOTA = {2:2, 3:18, 4:20}` ／卷 | 每套 结构 14~15 ＋ 原理 12 |
| 生成器 | `gen_r1.py` | `gen_r1_mixed.py`（`exec` 复用 A 的 `load/route/prio/gate_v2/qscore`） |
| 卷头 | 题源纪律 ＋ 难度分布 ＋ 难度总览 | 构成（结构/原理 ＋ 难度分布） |
| 时机 | 课后 / 周练，单点打透 | 阶段测 / 寒暑假回顾 |

### 🔴 两系列互斥（铁律）
B 的生成逻辑带「**避开 A 已用题**」（防学生重复做题）→ **A 扩容会吃掉 B 的池子**。
09-18 实测：A 扩到 566 题后，B 由 30 题掉到 26~27 题、结构仅 14 题。
**用户拍板「保持互斥，接受短卷」**（宁可短也不重复）。
⚠️ **推论**：以后 A 每次扩卷，都要**重新核 B 的题数与构成**，不能假定 B 不变。

## 五、卷面规范（硬规则）

1. **题面首行源书编号一律剥离**（`**5.** …` / `5. …` / `**5.**…` 三形态）
   - ⚠️ **只作用首行**，绝不用全文 `(?m)^`（会误删题内小问 `1. 计算…`）
   - ⚠️ 后缀可含 `.` / `．` / `、`，**不含 `)`**（`(1)` 是题内小问必须保留）
   - ⚠️ **星号守恒**：剥完必须保证 `**` 成对
2. **卷头「难度总览」按连续题号分区段**（`1–2、5、7–9`），**禁 `idx[0]–idx[-1]`**（会把不连续的同层题虚报成全覆盖）
3. **教师版** = FM ＋ `# 第一轮X · Y｜练习` ＋ 题源纪律 ＋ 难度分布 ＋ `## 难度总览` ＋ `## 题目`
4. **学生版** = FM ＋ 标题 ＋ `> 共 N 题。建议先独立完成，再核对答案。`（**无来源行 / 无难度标记**）
5. **题名禁现**「一分册测试-」「化学能力测试-」等源书前缀
6. **图引用**用纯哈希名 `![[<hash>.jpg]]`，且必须在 `媒体仓库/` 内有实体
7. **卷内不得出现库内路径**（`> 答案见 04-题库/…`，学生版尤其）
8. **难度标签**用文字（`### 例N [主题]（基础/进阶/挑战）`），**禁装饰性 emoji `⭐`**（Word 渲染不稳）

## 六、两条「不要做」——踩过的坑

### ⛔ 不要为「补满某桶」而加跨桶预留
09-18 曾为把 P7 补满 40 而加「紧缺桶锁定跨桶题」→ **质量倒退**：
- 误判根因：`_own` 按**过滤后的 buckets** 统计会**低估专属数** → 误判 P5/P7 紧缺
  （全库口径实测只有 S6:10、P2:20 真紧缺，P5 有 51、P7 有 63 专属题）
- 锁定 39 道跨桶题后 → **81 道 A 级题（含多道真题）落选**，净损失
- **用户拍板撤销，接受 P7=37**
- ⚠️ **推论**：将来若要补足某桶，**必须先验证目标桶存在同质量替代**

### ⛔ 不要用「占比」判断质量变化
- 09-18 曾把「A 级占比 61.3% → 49.9%」当质量倒退 —— **错**。
- 占比降只因**分母涨了**（可回溯题 465 → 566，是回溯能力提升的假象）。
- **正解：看绝对数** —— A 级题 **285 → 298（上升）**。

### ⛔ 不要凭「探针命中」直接断言「影响面」
- 09-18 第二轮探针命中 31 道图缺陷题，初稿**臆断「8 题已在现役卷内」** → **二重验证后仅 1 题**。
- **正解**：判断某题是否已进卷，**唯一权威是 `_选题清单.json` 的 `paths` 字段**
  （`used_in` 是累积台账，含同卷旧版本，**不可用来数「某卷用了多少题」**）。
- **推论**：**探针命中 ≠ 已进卷** → 报「影响面」前必须查台账。

### ⛔ 图依赖题的「图」必须在题面（**判据已于 2026-09-18 落地**）
- **原状态**：`gate_v2` **不检查图片位置**，只在 `imgs_ok()` 里检查**图是否存在**（在媒体仓库内）→
  题面说「如下图」但**图落在答案区**（`题-汇智-晶体结构-5`）或**图全缺**（`题-049-…习题4`）的题被放过。
- ✅ **已修复（09-18 第二轮，commit `5f3239205`）**：`gen_r1.py::gate_v2()` 新增判据 ——
  **题面图引用数 == 0** 且 题面含 `如图/下图/如下左图/如下右图/结构如图` → 拒收（`rej["题面引图但图缺失"]`）。
  - ⚠️ **例外 1**：真题有独立 `## 题目图示与结构参考` 区 → 图不在题面属规范形态，**须豁免**（判据内按 `^##\s*题目图示|^##\s*图示` 豁免）。
  - ⚠️ **例外 2**：**文字自足的图占位题**（题面给中文全名如「SPS（过硫酸钠）」）→ 列入 `FIG_REF_OK` 白名单豁免。
    - 现役白名单 **1 条**：`04-题库/真题/第36届初赛第二场/题-036b-6-SPS与ME反应方程式及平衡常数.md`。
  - ⚠️ **不要**把「如下表」当缺图 —— Markdown 表格是正常形态（v1 探针曾误报 82 题）。
  - ⚠️ **不要**用「答案区多出图」判缺陷 —— 「题图＋答图」是正常配对（v1 探针曾误报 136 题）。
  - ⚠️ **两系列共用** → `gen_r1_mixed.py` 也须调用同一 `gate_v2()`（见下节 P0 修复）。
- 清单与实证见 `09-审计报告/2026-09-18-第二轮-gate_v2盲区探针.md`。

### ⛔ 整页扫描图 ≠ 单题配图（**2026-09-18 实测补记｜处置已于 09-18 深夜落地**）

- **病灶**：省预赛题在库里**只有整页 A4 扫描**（`06-外部资料导入/真题/省预赛/images/{卷名}_pNN.png`，
  1653×2339，一页含页眉＋考生须知＋周期表＋**多道题的文字与插图**），**没有单题裁剪图**。
- **后果**：题面写「EMIM⁺ 结构如图所示」，学生拿到的却是**一整页试卷**，须自行在页内定位那一个小结构式。
- **实测规模**（09-18 深夜**全量复核**，取代此前误报的「9 题/18 处」）：
  **被消费源题 33 道 / 涉及整页 26 个 / 裁剪目标 33 个**（A 竞赛教材版 **8 道**、B 综合套卷 **25 道**，A∩B=0）。
  其中 **8 个页面被两道题共用**（须按题定位，不能按页定位）。
- ⚠️ **本判据 `gate_v2` 抓不到**：题面**有**图引用（非 0），`imgs_ok()` 也只查「图是否存在」→ 整页图**照常通过**。
- ✅ **处置（09-18 已落地，治本）——生成层替代映射**：
  - **架构**：不动 `04-题库/` 红区源题，只在**生成层**换图（沿用 `load()`「卷生成层，不动红区源库」先例）。
  - **数据**：33 个单题裁剪图（逐张目检确认边界），落 `媒体仓库/<sha256-16>.png`
    （满足 `MEDIA_IDX`+`resolve_img`+pandoc），备份于 `06-外部资料导入/真题/省预赛/crops/`（跟踪入库）。
  - **代码**：`gen_r1.py::norm_images(s, qpath=None)` 新增**前置**一步 `fig_crop_lookup(qpath, page_base)`：
    ① `FIG_CROP_BY_Q`（键 `<题文件stem>|<页名>`）精确命中 → ② `FIG_CROP_PAGE`（键 `<页名>`）回退。
    ⚠️ 替代**必须先于**常规归一：否则整页名先被归一为纯名（部分页已在 `媒体仓库/`），就再无从区分。
    ⚠️ **调用点须传 `qpath`**（`r["_path"]`）；`gen_r1_mixed.py` 经 `G` 复用同一函数，**无需改常量**。
  - **验证**：A∪B 引用 33/33 全覆盖、0 未用；两系列整页引用**清零**；docx「缺图 0 处」；
    题量守恒 40/40/26 对齐；PDF 目检单题图正确落版。
- 🔎 **顺带查实一处源题标注错误**：`题-浙江21-单选-51-有机碱性强弱比较` 标注「原卷第10页下图」，
  但**四种胺结构实际在第 11 页顶部**（目检确认）。故其映射键为 `(<题51stem>|2021-浙江预赛_p10.png)`
  → 值为 **p11 的裁剪图**（引用页＝源题所写 p10，裁剪来源页＝p11）。
- **新增源题时的预防**：转录省预赛图依赖题，**先确认能否裁出单题图**；能则**同时登记 `FIG_CROP_BY_Q`**
  （同页两题必须用按题键，不能只登记页级）；不能则**不要录入**该题。

### ⛔ `gen_r1_mixed.py` 必须自带 `EXCLUDE_PATHS` 过滤（**09-18 P0 修复**）

- **事故**：两系列共用 `gate_v2`，但**混卷生成器的建池循环漏写 `EXCLUDE_PATHS` 判定** →
  黑名单题**从 B 系列侧漏进现役交付物**（实测 **8 处**，散在卷 01/02/03/12）。
- **正解**：`EXCLUDE_PATHS` 判定须与 `prio(r) >= 99` **同层**（都在 `route()` 之前）。
- **推论（通用）**：**任何复用 `gate_v2` 的新生成器，都必须同时复核它是否也复用了黑名单过滤。**
  判据层面共享，**不等于**调用层面自动生效。
- 实证见 `09-审计报告/2026-09-18-第二轮-gate_v2盲区探针.md` §六·补。

## 七、执行流程（照此跑）

```
① 改 gen_r1.py（或先 grep -rln "gen_r1" .workbuddy/ 确认引用面）
② 跑 gen_r1.py → 产出 A 系列 md（staging）
③ 跑 gen_r1_mixed.py → 产出 B 系列 md（staging；自动避开 A 已用题）
④ 卷质检：残号计数、孤立 ** 计数、题数守恒、难度总览一致性
⑤ docx 重出（skill dual-edition-docx-regen）：
   build-all-handout-docx.py --batch-root <staging> --output-dir <out> --strict-images --parallel 4
   ⚠️ 必须用 staging 目录（直指源目录会扫全部 md 且报 not in subpath）
   ⚠️ 输出用现役旧名（先 ls 现役目录确认命名，禁凭 README 推演）
⑥ 双闸门：jsyaml_verify.js --list <清单> ＋ validate_kb.py --changed <显式文件列表>
   ⚠️ 核「受检数 == 清单行数」；跑完删副产物 09-审计报告/auto-validation/<日期>-validation.md
⑦ docx 质检：题数逐卷守恒、图 ref==media、0 答案泄漏、0 LaTeX 泄漏
```
