## 与其他层的关系

- **习题书 ≠ 第一轮教辅**：本层 `teaching_level=拓展` 档 **1,483 题** ≠ 成书 **4,279 题**（**两个不同源**，勿混）。
- 与**一/三 层**：习题书收**整大题**（不拆散）；习题集可取**单个小问**（改写后入卷）→ 设计互补。
