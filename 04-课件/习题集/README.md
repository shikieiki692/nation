# 习题集

> 本目录收录**正式习题书**与第一轮基础训练的**配套习题集**两套体系。
> 正式习题书：四篇共 **31 章 / 1,283 题**（构建实测 2026-09-01），学生版（无答案）/教师版（含答案）双版本，见下节。
> 第一轮配套习题集：共 **16 个 .md 文件**，按学科分为化学原理（8套）和结构化学（5套+2复习），另有1个总索引。
>
> **三载体分工**（定稿见 [[04-题库/习题集体系总纲]]「五种载体形式分工」）：
> ① **随堂层·第一轮习题集**——配套讲义的章末练习，手编，难度三层分级，题答同卷，`pack` 不限；
> ② **成书层·习题书**——管线生成的模块精选成书，大题合并不拆散、师生双版本、溯源映射防漂移；
> ③ **评测层·阶段测试卷**——真题小问拼卷限时计分（仅化学原理一份）。
> 同一道题可同时出现在不同载体（习题书收整大题、习题集可取单个小问），属设计互补而非重复收录。

## 🔧 构建与迭代（2026-08-31 晚更新）

**构建管线**（`build_module_book.py`）：`gather_questions` → 大题归并 → 关键词分章 → 难度排序 → 生成章节/目录/来源索引。教师版 `<details>` 答案块、学生版无答案。

**防漂移三件套（本轮已落地）**：
1. **README 自动同步**：`--write` 构建末尾自动回写题数/章节构成（`sync_readme_stats`），不再手工维护
2. **校验增强**：`validate_module_book.py` 新增"目录 vs 章节文件"一致性检查（章数/章名/题数），排除来源索引/附录误报——`--root 习题书-教师版 --edition teacher` 全绿
3. **双向溯源**：`溯源映射.json`（1262 题，含每题的源文件路径）——题库修改后据此核对成书是否需重建

**后续迭代方向（按优先级）**：
- **✅ P0 已完成（2026-08-31）**：Word 成品重建——教师版/学生版各 33 个 docx（31 章 + 来源索引 + 附录）基于 1,262 题新 md 生成，`33 converted, 0 errors` 双版本通过；旧版（含 8-结构推断与综合.docx 旧 7 题版）已归档至 `_archive_v2/旧平面结构-2026-08-31/`
- **P1 源文件命名**：53 处标题退化为纯题号（`## 1.3 05-07`），因源文件名无主题词——新题命名规范带概念词
- **✅ P1 汇智缺题（2026-08-31 已补全 4 题）**：分子结构-**36**（平面 σ 芳香性 5 子问）、晶体结构-**65**（Ge/Nb 金属间化合物晶胞 Nb₃Ge）、**73**（K₈Nb₆O₁₉ 金属 M 推断）、**75**（ZnO₁₋ₓ 缺陷显色 + α/β-HgS）——深挖教师版源 OCR（编号与题库一一对应）后全部提取补全，4 张图已入媒体仓库，恢复 9 处引用；题库 3,929→3,933

**迭代节奏**：题库增量修改 → 对照 `溯源映射.json` 评估受影响章节 → 重建 md（`--write`，自动同步 README）→ 重建 docx → `validate_module_book.py` + 三件套验证 → 形成固定流程。
