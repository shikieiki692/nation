## 六、数据口径

1. 随堂层题数＝各卷 frontmatter `question_count`（原理 8 份与卷面题头全等；结构 5 份中分子结构 92 含 21 道前缀式题头〔教-N/汇-N/赵-N〕，原子 35、晶体 62 与卷面全等）；方程式专项 32 为卷面 `## 第N题` 计数。
2. 评测层题数＝卷面小问节 `### N.M` 计数（50＋25＋25）。
3. 竞赛导向层题数＝`_选题清单.json` 的 `n` 字段，2026-09-19 已核对 `n == len(paths) == 教师版卷面题头数` 全等、跨卷重复 0（详见 [[04-题库/题库按用途分类说明]] §3E）。
4. 交付状态取自各卷 frontmatter `status`／目录 README 交付记录；「未标注」指 FM 缺 status 字段，非未交付判定。
