### 第5题

> 来源：真题·讲评层

五氯化磷的分解反应是研究化学平衡的经典体系：

$$\mathrm{PCl_5(g) \rightleftharpoons PCl_3(g) + Cl_2(g)}$$

在 523 K 时，该反应的 $K_p = 1.78\ \mathrm{atm}$。

(1) 将纯 $\mathrm{PCl_5}$ 注入一真空密闭容器中，523 K 下平衡时总压为 2.00 atm。求 $\mathrm{PCl_5}$ 的分解率 $\alpha$。

(2) 若上述容器中在注入 $\mathrm{PCl_5}$ 的同时，已含有 $\mathrm{Cl_2}$ 使其初始分压为 0.50 atm，平衡时 $\mathrm{PCl_5}$ 的分解率 $\alpha'$ 为多少？

(3) 比较 (1) 和 (2) 的结果，用平衡移动原理加以解释。

![[gibbs-free-energy-changes.png]]

**参考答案**：

**分析**
1. 用分压表示 $K_p$：设初始 $\mathrm{PCl_5}$ 压力为 $p_0$，分解率 $\alpha$，则平衡时各组分分压用 $p_0$ 和 $\alpha$ 表达
2. 由总压条件可求 $p_0$，再代入 $K_p$ 表达式求解 $\alpha$
3. 加入产物 $\mathrm{Cl_2}$ 后，根据 **Le Chatelier 原理**，平衡向逆反应方向移动，$\alpha$ 减小
4. 注意单位一致性：$K_p$ 以 atm 为单位

**(1) 纯 PCl₅ 分解**

设初始 $\mathrm{PCl_5}$ 分压为 $p_0$，分解率为 $\alpha$：

|  | $\mathrm{PCl_5}$ | $\mathrm{PCl_3}$ | $\mathrm{Cl_2}$ |
|:---:|:---:|:---:|:---:|
| 初始/atm | $p_0$ | 0 | 0 |
| 变化/atm | $-p_0\alpha$ | $+p_0\alpha$ | $+p_0\alpha$ |
| 平衡/atm | $p_0(1-\alpha)$ | $p_0\alpha$ | $p_0\alpha$ |

平衡总压：$p_{\text{总}} = p_0(1-\alpha) + p_0\alpha + p_0\alpha = p_0(1+\alpha)$

已知 $p_{\text{总}} = 2.00\ \mathrm{atm}$：

$$p_0(1+\alpha) = 2.00 \quad\Rightarrow\quad p_0 = \frac{2.00}{1+\alpha}$$

平衡常数：

$$K_p = \frac{p_{\mathrm{PCl_3}} \cdot p_{\mathrm{Cl_2}}}{p_{\mathrm{PCl_5}}} = \frac{(p_0\alpha)^2}{p_0(1-\alpha)} = \frac{p_0\alpha^2}{1-\alpha} = 1.78$$

代入 $p_0$ 表达式：

$$\frac{2.00}{1+\alpha} \cdot \frac{\alpha^2}{1-\alpha} = 1.78$$

$$\frac{2\alpha^2}{(1+\alpha)(1-\alpha)} = \frac{2\alpha^2}{1-\alpha^2} = 1.78$$

$$2\alpha^2 = 1.78(1-\alpha^2)$$

$$2\alpha^2 = 1.78 - 1.78\alpha^2$$

$$3.78\alpha^2 = 1.78$$

$$\alpha = \sqrt{\frac{1.78}{3.78}} = 0.686$$

$$\alpha = 68.6\%$$

**(2) 含初始 Cl₂**

设初始 $\mathrm{PCl_5}$ 分压为 $p_0$，初始 $\mathrm{Cl_2}$ 分压为 0.50 atm：

|  | $\mathrm{PCl_5}$ | $\mathrm{PCl_3}$ | $\mathrm{Cl_2}$ |
|:---:|:---:|:---:|:---:|
| 初始/atm | $p_0$ | 0 | 0.50 |
| 平衡/atm | $p_0(1-\alpha')$ | $p_0\alpha'$ | $0.50 + p_0\alpha'$ |

总压：$p_{\text{总}} = p_0(1-\alpha') + p_0\alpha' + 0.50 + p_0\alpha' = p_0(1+\alpha') + 0.50 = 2.00$

$$p_0 = \frac{1.50}{1+\alpha'}$$

代入 $K_p$：

$$K_p = \frac{p_0\alpha' \cdot (0.50 + p_0\alpha')}{p_0(1-\alpha')} = \frac{\alpha'(0.50 + p_0\alpha')}{1-\alpha'} = 1.78$$

由 $p_0(1+\alpha') = 1.50$ 得 $p_0$ 代入后用数值求解。为简化，利用 $p_0\alpha'$ 整体处理。

设 $x = p_0\alpha'$，则 $p_0 = \frac{1.50}{1+\alpha'}$，$x = \frac{1.50\alpha'}{1+\alpha'}$

$$\frac{\alpha'(0.50 + x)}{1-\alpha'} = 1.78$$

用试差法（逐次逼近）或用总压关系 $p_0 + x + (0.50+x) = 2.00 \Rightarrow p_0 + 2x = 1.50$：

代入 $x = p_0\alpha'$，$p_0(1+2\alpha') = 1.50$

由 $K_p = \frac{p_0\alpha'(0.50+p_0\alpha')}{p_0(1-\alpha')} = 1.78$

令 $\alpha' \approx 0.50$ 试算：

- $1+2 \times 0.50 = 2.00$，$p_0 = 1.50/2.00 = 0.75$
- $x = 0.75 \times 0.50 = 0.375$
- $K_p = 0.50 \times (0.50+0.375)/(1-0.50) = 0.50 \times 0.875/0.50 = 0.875$（偏小）

令 $\alpha' \approx 0.58$：

- $1+2 \times 0.58 = 2.16$，$p_0 = 1.50/2.16 = 0.694$
- $x = 0.694 \times 0.58 = 0.403$
- $K_p = 0.58 \times (0.50+0.403)/(1-0.58) = 0.58 \times 0.903/0.42 = 1.247$（仍偏小）

令 $\alpha' \approx 0.63$：

- $1+2 \times 0.63 = 2.26$，$p_0 = 1.50/2.26 = 0.664$
- $x = 0.664 \times 0.63 = 0.418$
- $K_p = 0.63 \times (0.50+0.418)/(1-0.63) = 0.63 \times 0.918/0.37 = 1.563$（偏小）

令 $\alpha' \approx 0.66$：

- $1+2 \times 0.66 = 2.32$，$p_0 = 1.50/2.32 = 0.647$
- $x = 0.647 \times 0.66 = 0.427$
- $K_p = 0.66 \times (0.50+0.427)/(1-0.66) = 0.66 \times 0.927/0.34 = 1.80 \approx 1.78$

$$\alpha' \approx 66\%$$

验证：$\alpha' = 0.657$ 时更精确，$K_p \approx 1.78$。

$$\alpha' \approx 65.7\%$$

**(3) 结果比较**

| 条件 | 分解率 $\alpha$ |
|:---|:---:|
| 纯 PCl₅ | 68.6% |
| 含 0.50 atm Cl₂ | ~65.7% |

加入产物 $\mathrm{Cl_2}$ 使分解率**略有降低**。根据 **Le Chatelier 原理**：增加产物的浓度（分压），平衡向消耗该产物的方向——即逆反应方向移动，因此 $\mathrm{PCl_5}$ 的分解受到抑制。

注意此体系中 $K_p = 1.78$ 并不大，加 0.50 atm Cl₂ 的影响较显著（约 3 个百分点），定量反映了平衡移动的程度。

(1) $\alpha = 68.6\%$

(2) $\alpha' \approx 65.7\%$

(3) 加入 Cl₂ 使分解率降低，符合 Le Chatelier 原理——增加产物抑制正反应

### 第8题

> 来源：真题·第36届初赛第二场

电镀铜是电子工业中的关键技术之一。电镀铜的基本电化学过程如下：

(1) $\mathrm{Cu}^{2+} + \mathrm{e}^{-} \longrightarrow \mathrm{Cu}^{+}$ (慢)
(2) $\mathrm{Cu}^{+} + \mathrm{e}^{-} \longrightarrow \mathrm{Cu}$ (快)

在电解体系中引入各种有机配体或者添加剂，可以改进电解效率和镀层品质。末端含有磺酸基团的短碳链的二硫化物或硫醇（分子式见下图），如 SPS（二硫二丙烷磺酸）和 MPS（3-巯基-1-丙烷磺酸），常用作镀铜工艺的加速剂。有研究认为 SPS 或 MPS 加速电镀铜沉积的原因是因为它们能促进 $\mathrm{Cu}^{2+}$ 还原为 $\mathrm{Cu}^{+}$ 的反应。

鉴于难以采用电化学方法直接测定该电对的电极电势，研究人员设计了巧妙的方法，通过 ${}^{1}$H NMR 谱的定量分析（谱峰面积正比于氢原子的数目），间接求算电极电势。该方法具体实验如下：298 K 下，在氮气保护下将 SPS 和 ME（巯基乙醇）在密封容器中混合，二者起始浓度分别为 10.0 mmol L⁻¹ 和 20.0 mmol L⁻¹ 。待反应达平衡后，测试混合体系的 ${}^{1}$H NMR，发现 MPS 和 SPS 的 $\beta$ 位氢原子的谱峰（分别在 2.02 ppm 和 2.15 ppm 处）面积比为 1.00:1.00。ME 氧化产物为 DE，已知 $E^{\ominus}(\mathrm{DE}/\mathrm{ME}) = 0.153 \mathrm{~V}$ 。

写出 SPS 和 ME 反应的方程式。计算该反应的平衡常数（提示：可以采用简写符号）。

计算电极反应 $\mathrm{SPS} + 2\mathrm{H}^{+} + 2\mathrm{e}^{-}\longrightarrow 2\mathrm{MPS}$ 的标准电极电势。

实验中观察到 $\mathrm{Cu}^{2+}$ 可以将 MPS 氧化为 SPS 并形成配合物 $\mathrm{Cu}^{\mathrm{I}}(\mathrm{MPS})$ （反应 1）而吸附在镀件表面，$\mathrm{Cu}^{\mathrm{I}}(\mathrm{MPS})$ 获得电子在镀件表面发生电沉积并放出 MPS（反应 2），写出反应方程式。

**参考答案**：

**（1）**
题目中给出了 4 个参与电镀铜过程的有机加速剂的结构，其中的关键部分在于巯基和二硫键属于一对氧化还原电对。二硫键是"中间氧化态"的结构，广泛存在于无机和有机化合物中，其还原态为 -2 价的硫离子或巯基，氧化态为磺酸、亚磺酸类化合物。故 SPS 与 ME 反应，产物应为 MPS 和 DE：

$$
\mathrm{SPS} + 2 \mathrm{ME} \longrightarrow \mathrm{DE} + 2 \mathrm{MPS}
$$

上述反应平衡常数的计算，需结合 ${}^{1}$H NMR 谱对平衡体系中物种 $\beta$-氢谱峰的面积比测定：反应达平衡后，MPS 和 SPS 的 $\beta$-H 谱峰面积比为 1.00:1.00；而 MPS 和 SPS 分别有 2 个和 4 个 $\beta$-H，故 [MPS]/[SPS] = 2.00。又由于 SPS 的还原产物为 MPS，由物料守恒，有

$$
[ \mathrm{SPS} ] + \frac {[ \mathrm{MPS} ]}{2} = 10.0 \mathrm{mmolL} ^ {- 1}
$$

可解得 $[SPS] = 5.00 \, \mathrm{mmol} \, L^{-1}$ , $[MPS] = 10.0 \, \mathrm{mmol} \, L^{-1}$ 。由反应的计量关系，可得另外两物种 ME 和 DE 的平衡浓度：

格外注意：SPS 是一个对称结构，很多粗心大意的同学误以为 SPS 只有 2 个 $\beta$ -H。

$$
\begin{array}{l} [ \mathrm{ME} ] = 20.0 \mathrm{mmolL} ^ {- 1} - 2 \times 5.0 \mathrm{mmolL} ^ {- 1} = 10.0 \mathrm{mmolL} ^ {- 1} \\ [ \mathrm{DE} ] = 5.0 \mathrm{mmolL} ^ {- 1} \\ \end{array}
$$

故反应的平衡常数为

$$
K ^ {\ominus} = \frac {\left(\frac {[ \mathrm{DE} ]}{c ^ {\ominus}}\right) \left(\frac {[ \mathrm{MPS} ]}{c ^ {\ominus}}\right) ^ {2}}{\left(\frac {[ \mathrm{ME} ]}{c ^ {\ominus}}\right) ^ {2} \left(\frac {[ \mathrm{SPS} ]}{c ^ {\ominus}}\right)} = \frac {0.00500 \times 0.0100 ^ {2}}{0.0100 ^ {2} \times 0.00500} = 1.00
$$

注意 $c^{\ominus}=1\ \mathrm{mol}\ L^{-1}=$ 1000 mmol $L^{-1}$ 。

**（2）**
由于反应

$$
\mathrm{SPS} + 2 \mathrm{ME} \longrightarrow \mathrm{DE} + 2 \mathrm{MPS} \quad K ^ {\ominus} = 1.00
$$

是氧化还原反应，有平衡常数和反应的标准电动势之间的关系：

$$
\Delta_ {\mathrm{r}} G _ {\mathrm{m}} ^ {\ominus} = R T \ln K ^ {\ominus} = - n F E ^ {\ominus}
$$

由 $K^{\ominus}=1.00$ 可以直接得到反应的标准电动势 $E^{\ominus}=0.00\ V$ 。反应中的两个电对标准电极电势之差即为反应的标准电动势，有

$$
E ^ {\ominus} = E ^ {\ominus} (\mathrm{SPS/MPS}) - E ^ {\ominus} (\mathrm{DE/ME}) = 0.00 \mathrm{V}
$$

故

$$
E ^ {\ominus} (\mathrm{SPS/MPS}) = E ^ {\ominus} (\mathrm{DE/ME}) = 0.153 \mathrm{V} = 0.15 \mathrm{V}
$$

有效数字不修约亦可。

**（3）**
根据题目中的信息，可写出反应方程式：

**反应 1：**
$$
2 \mathrm{Cu} ^ {2 +} + 4 \mathrm{MPS} \longrightarrow 2 \mathrm{Cu} ^ {\mathrm{I}} (\mathrm{MPS}) + \mathrm{SPS} + 4 \mathrm{H} ^ {+}
$$

**反应 2：**
$$
\mathrm{Cu} ^ {\mathrm{I}} (\mathrm{MPS}) + \mathrm{H} ^ {+} + \mathrm{e} ^ {-} \longrightarrow \mathrm{Cu} + \mathrm{MPS}
$$

同样，用代号表示化合物时需要注意计量数的配平与补足易忽略的 $H^{+}$ 、 $H_{2}O$ 等小分子（离子）。

若认为与 $\mathrm{Cu(I)}$ 配位的 MPS 是未电离的分子形式，方程式写为

**反应 1'：**
$$
2 \mathrm{Cu} ^ {2 +} + 4 \mathrm{MPS} \longrightarrow 2 \mathrm{Cu} ^ {\mathrm{I}} (\mathrm{MPS}) ^ {+} + \mathrm{SPS} + 2 \mathrm{H} ^ {+}
$$

**反应 2'：**
$$
\mathrm{Cu} ^ {\mathrm{I}} (\mathrm{MPS}) ^ {+} + \mathrm{e} ^ {-} \longrightarrow \mathrm{Cu} + \mathrm{MPS}
$$

也是合理的。

### 第12题

> 来源：真题·第25届初赛

$\mathrm{NO}_{2}$ 和 $\mathrm{N}_{2}\mathrm{O}_{4}$ 混合气体的针管实验是高中化学的经典素材。理论估算和实测发现，混合气体体积由 V 压缩为 V/2，温度由 298 K 升至 311 K。已知，这两个温度下 $\mathrm{N}_{2}\mathrm{O}_{4}(\mathrm{g}) \rightleftharpoons 2\mathrm{NO}_{2}(\mathrm{g})$ 的压力平衡常数 $K_{p}$ 分别为 0.141 和 0.363。

通过计算回答，混合气体经上述压缩后，$\mathrm{NO}_{2}$ 的浓度比压缩前增加了多少倍。

动力学实验证明，上述混合气体几微秒内即可达成化学平衡。压缩后的混合气体在室温下放置，颜色如何变化？为什么？

**参考答案**：

**（1）**
设压缩前后转化率为 $\alpha_1$ 和 $\alpha_2$，压力为 $p_1$ 和 $p_2$。

由298K平衡条件解得：$p_1 = 1\ \mathrm{atm}$，$\alpha_1 = 0.185$

由理想气体状态方程和311K平衡条件联立：

$$\alpha_2 = 0.203,\quad p_2 = 2.120\ \mathrm{atm}$$

$$\frac{c_{\mathrm{NO}_2,2}}{c_{\mathrm{NO}_2,1}} = \frac{p_{\mathrm{NO}_2,2}}{p_{\mathrm{NO}_2,1}} \cdot \frac{T_1}{T_2} = \frac{0.714}{0.312} \times \frac{298}{311} = 2.19$$

**NO₂浓度增加了1.19倍**（即变为原来的2.19倍）。

**（2）**
**颜色逐渐变浅**。

**原因**：$\mathrm{N_2O_4 \rightleftharpoons 2NO_2}$ 是吸热反应（$\Delta_r H_m > 0$，断裂N—N键需要能量）。压缩后温度升至311K，放置过程中温度逐渐降回室温(298K)。根据Le Chatelier原理，降温使平衡向放热方向（左）移动，NO₂浓度减小，颜色变浅，直至体系温度达到室温达到新平衡。

 $\mathrm{CuCl(s)} \rightleftharpoons \mathrm{Cu}^{+} + \mathrm{Cl}^{-} \quad (\mathrm{K}_{2} = [\mathrm{Cu}^{+}][\mathrm{Cl}^{-}])$

初始加入 a 克 CuCl，其摩尔数为

 $n_{(\mathrm{CuCl})} = a / M_{(\mathrm{CuCl})}$

全部溶解时，由于每溶解 1 摩尔 CuCl 产生 1 摩尔  $Cl^{-}$ ，在体积 V = b mL = b/1000 L 中，

 $[\mathrm{Cl}^{-}] = n_{(\mathrm{CuCl})}/(b/1000) = 1000 \cdot a / (M_{(\mathrm{CuCl})} \cdot b)$

为了防止沉淀生成，溶液中自由  $Cu^{+}$  的浓度必须满足

假设几乎所有  $Cu^{+}$  都转化为  $[\mathrm{Cu}(\mathrm{NH}_{3})_{2}]^{+}$ ，则

 $[\mathrm{Cu}(\mathrm{NH}_{3})_{2}]^{+} \approx n_{\mathrm{i}}\mathrm{CuCl}/(b/1000) = 1000 \cdot a / (M_{\mathrm{i}}\mathrm{CuCl}, \cdot b)$

 $b/1000 - 2 \cdot n_{(\mathrm{CuCl})}$

其浓度为

 $[\mathrm{NH}_{3}] = (b/1000 - 2 \cdot a / M_{(\mathrm{CuCl})}) / (b/1000) = 1 - (2000 \cdot a) / (M_{(\mathrm{CuCl})}, \cdot b)$

将已知的  $[Cu^{+}]$  和  $[NH_{3}]$  代入络合平衡表达式，有

### 第20题

> 来源：高中化学竞赛教程·第二分册

（2003 年江苏预赛）1273 K 时 $H_2O(g)$ 通过红热的铁生产 $H_2$，发生如下反应：

$$
\mathrm{Fe(s)} + \mathrm{H_2O(g)} \rightleftharpoons \mathrm{FeO(s)} + \mathrm{H_2(g)}
$$

反应的平衡常数 $K_p = 1.49$（$K_p$ 是以各平衡混合气体分压表示的化学平衡常数）。

(1) 每生成 1.00 mol 氢气需通入水蒸气的物质的量为多少？

(2) 1273 K 时，若反应体系中只有 0.30 mol 的铁并通入 1.00 mol 水蒸气与其反应，试计算反应后各组分的物质的量。反应后体系是否处于平衡状态，为什么？

(3) 1273 K 时，当 1.00 mol 水蒸气与 0.80 mol 铁接触时，最后各组分的物质的量是多少？

**参考答案**：

**过程探究**（原书 L604~658）

(1) 因为 $p(\mathrm{H_2}) = n(\mathrm{H_2})RT/V$、$p(\mathrm{H_2O}) = n(\mathrm{H_2O})RT/V$，故

$$
K_p = \frac{p(\mathrm{H_2})}{p(\mathrm{H_2O})} = \frac{n(\mathrm{H_2})}{n(\mathrm{H_2O})} = 1.49
$$

平衡时 $n(\mathrm{H_2O}) = \dfrac{n(\mathrm{H_2})}{1.49}\approx 0.671\,\mathrm{mol}$。因此起始时通入 $\mathrm{H_2O(g)}$ 的物质的量为 $n(\mathrm{H_2})_{\text{平}} + n(\mathrm{H_2O})_{\text{平}} = 1.00 + 0.671 = 1.67\,\mathrm{mol}$。

注意该反应是一个可逆反应，存在化学平衡，故该反应不能进行到底，所以不能误认为通入的水蒸气的物质的量就是氢气的物质的量。

(2) 假设 0.30 mol 铁与 1.00 mol 水蒸气完全反应，则生成 $n(\mathrm{H_2}) = 0.30\,\mathrm{mol}$。此时用于平衡的 $n(\mathrm{H_2O}) = \dfrac{0.30}{1.49}\approx 0.20\,\mathrm{mol}$。0.30 mol Fe 完全反应共需 $H_2O(g)$ 0.20+0.30 = 0.50 mol < 1.00 mol，故铁粉可完全反应。此时各组分的物质的量分别为 $n(\mathrm{H_2})=0.30$、$n(\mathrm{H_2O})=0.70$、$n(\mathrm{FeO})=0.30$、$n(\mathrm{Fe})=0$。

故 $\dfrac{n(\mathrm{H_2})}{n(\mathrm{H_2O})} = \dfrac{0.30}{0.70}\approx 0.43 < K_p = 1.49$，因此此时体系没有达到平衡。

(3) 设反应的 Fe 为 $x$ mol，则 $\dfrac{x}{1.00-x} = K_p = 1.49$，解得 $x = 0.60\,\mathrm{mol}$。此时体系各组分的物质的量分别为 $n(\mathrm{H_2})=0.60$、$n(\mathrm{H_2O})=0.40$、$n(\mathrm{FeO})=0.60$、$n(\mathrm{Fe})=0.20$ mol。

**参考解答**（1）需通入水蒸气 1.67 mol；（2）$n(\mathrm{H_2})=0.30$、$n(\mathrm{H_2O})=0.70$、$n(\mathrm{FeO})=0.30$、$n(\mathrm{Fe})=0$ mol，未达平衡，理由见上；（3）$n(\mathrm{H_2})=0.60$、$n(\mathrm{H_2O})=0.40$、$n(\mathrm{FeO})=0.60$、$n(\mathrm{Fe})=0.20$ mol。

### 第21题

> 来源：高中化学竞赛教程·第二分册

⑥ 人体中的血红蛋白（简写为 Hb）可以携带氧气变为氧合血红蛋白（简写为 $HbO_2$），其化学平衡方程式可写为 $Hb + O_2 \rightleftharpoons HbO_2$。在海拔比较高的地方，氧气的分压比较低，平衡将向左移动，人体会感到比较累并易有眩晕感；严重时还会导致疾病。CO 可与 $HbO_2$ 反应生成 HbCO，并且 HbCO 比 $HbO_2$ 要稳定得多，其化学平衡方程式可写为 $HbO_2 + CO \rightleftharpoons HbCO + O_2$，$K_c = \dfrac{c(HbCO)c(O_2)}{c(HbO_2)c(CO)} = 2.1\times10^{2}$，HbCO 的形成使得血红蛋白不再携带氧气而造成人员中毒。一旦发生 CO 中毒，首先要做的事是让患者呼吸新鲜的空气。试从化学平衡的角度分析这样做的意义：____。除了 CO 和 $O_2$，$HbO_2$ 还可以吸附 $CO_2$ 和氢离子，且反应几乎是完全的，其方程式如下：$HbO_2 + H^{+} + CO_2 \rightleftharpoons Hb(H^{+})CO_2 + O_2$。人体肌肉在剧烈运动时会产生乳酸 $[CH_3CH(OH)COOH]$，乳酸在血液中会和氧合血红蛋白发生怎样的反应？____。肌肉剧烈运动时放出大量的热量，氧合血红蛋白会放出更多氧气，你认为乳酸和氧合血红蛋白的反应是吸热反应还是放热反应？____。简述理由：____。

**参考答案**：

本题只要利用勒夏特列原理就可顺利求解。因为 CO 与 $HbO_2$ 反应的平衡常数不大，可通过改变浓度使平衡发生移动：呼吸新鲜的空气能够增加 $O_2$ 的分压、降低 CO 的分压，使 $HbO_2 + CO \rightleftharpoons HbCO + O_2$ 平衡逆向移动，HbCO 解离释放出 Hb，恢复携氧能力。

题干中所提供的方程式 $HbO_2 + H^{+} + CO_2 \rightleftharpoons Hb(H^{+})CO_2 + O_2$，表明 $CO_2$ 在酸性条件下和 $HbO_2$ 结合放出 $O_2$，因此乳酸在血液中和氧合血红蛋白作用，就是利用其酸性使 $HbO_2$ 和 $CO_2$ 作用而放出 $O_2$：

$$
HbO_2 + CH_3CH(OH)COOH + CO_2 \rightleftharpoons Hb(H^{+})CO_2 + O_2 + CH_3CH(OH)COO^{-}
$$

乳酸和氧合血红蛋白的反应是吸热反应，理由是升高温度时，平衡向右移动（放出更多氧气）。

| 时间/s | 0 | 500 | 1000 | 1500 | 2000 | 2500 | 3000 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| $c(N_2O_5)$/(mol·L⁻¹) | 5.00 | 3.52 | 2.4 | 1.75 | 1.23 | 0.87 | 0.61 |

(2) 求 1000 s 时，生成 $NO_2$ 的瞬时反应速率。

(3) 若上述反应的正、逆反应速率分别为 $v_{\text{正}} = k\,c(N_2O_5)$ 和 $v_{\text{逆}} = k'c^{2}(NO_2)\cdot c^{1/2}(O_2)$，试写出该反应的平衡常数的表达式。

**参考答案**：

(1) 各时间间隔内 $N_2O_5$ 分解的平均反应速率依次为：$2.96\times10^{-3}$、$2.24\times10^{-3}$、$1.30\times10^{-3}$、$1.04\times10^{-3}$、$0.72\times10^{-3}$、$0.52\times10^{-3}$（单位：mol·L⁻¹·s⁻¹）。

### 第28题

> 来源：高中化学竞赛教程·第二分册

⑬ 人的牙齿表面有一层釉质，其组成为羟基磷灰石 $\mathrm{Ca}_{10}(\mathrm{OH})_{2}(\mathrm{PO}_{4})_{6}$（$K_{sp} = 3.8\times10^{-37}$）。为防止龋齿的产生，人们常常使用含氟牙膏，牙膏中的氟化钙可使羟基磷灰石转化为氟磷灰石 $\mathrm{Ca}_{10}\mathrm{F}_{2}(\mathrm{PO}_{4})_{6}$（$K_{sp} = 1.0\times10^{-60}$）。写出羟基磷灰石与牙膏中的 $\mathrm{F}^{-}$ 反应转化为氟磷灰石的离子方程式，并通过计算其转化反应的平衡常数说明哪种物质更稳定。

**参考答案**：

$$
\mathrm{Ca}_{10}(\mathrm{OH})_{2}(\mathrm{PO}_{4})_{6}(\mathrm{s}) + 2\mathrm{F}^{-} \longrightarrow \mathrm{Ca}_{10}\mathrm{F}_{2}(\mathrm{PO}_{4})_{6}(\mathrm{s}) + 2\mathrm{OH}^{-}
$$

$$
K = \frac{c^{2}(\mathrm{OH}^{-})}{c^{2}(\mathrm{F}^{-})} = \frac{K_{sp}[\mathrm{Ca}_{10}(\mathrm{OH})_{2}(\mathrm{PO}_{4})_{6}]}{K_{sp}[\mathrm{Ca}_{10}\mathrm{F}_{2}(\mathrm{PO}_{4})_{6}]} = \frac{3.8\times10^{-37}}{1.0\times10^{-60}} = 3.8\times10^{23}
$$

此反应的平衡常数很大，说明羟基磷灰石转化为氟磷灰石的倾向很大，即氟磷灰石更稳定。

### 第30题

> 来源：高中化学竞赛教程·第二分册

（2006 年全国初赛）有人设计了如下甲醇(methanol)合成工艺：

![[66b08849fe50da7fa23fe000960efe44646e71e048d843c98b3048b0edcefdd2.jpg]]

其中，①为甲烷气源，压强 250.0 kPa，温度 25℃，流速 $55.0\,\mathrm{m^3\cdot s^{-1}}$。②为水蒸气气源，压强 200.0 kPa，温度 150℃，流速 $150.0\,\mathrm{m^3\cdot s^{-1}}$。合成气和剩余反应物的混合物经管路③进入 25℃ 的冷凝器(condenser)，冷凝物由管路⑤流出。在步骤 B 中合成的甲醇和剩余反应物的混合物经⑥进入 25℃ 的冷凝器，甲醇冷凝后经管路⑦流出，其密度为 $0.791\,\mathrm{g\cdot mL^{-1}}$。

(1) 分别写出在步骤 A 和步骤 B 中所发生的化学反应的方程式。

(2) 假定：所有气体皆为理想气体，在步骤 A 和 B 中完全转化，气液在冷凝器中完全分离，计算经步骤 A 和步骤 B 后，在一秒钟内剩余物的量。

(3) 实际上，在步骤 B 中 CO 的转化率只有三分之二。计算在管路⑥中 $CO$、$H_2$ 和 $CH_3OH$ 的分压（总压强为 10.0 MPa）。

(4) 当甲醇反应器足够大，反应达到平衡，管路⑥中的各气体的分压服从方程

$$
K_p = \frac{p(\mathrm{CH_3OH})\times p_0^{2}}{p(\mathrm{CO})\times p^{2}(\mathrm{H_2})}
$$

式中 $p_0=0.100\,\mathrm{MPa}$，计算平衡常数 $K_p$。

**参考答案**：

**过程探究**（原书 L736~776）

(1) $\mathrm{CH_4(g)} + \mathrm{H_2O(g)} \longrightarrow \mathrm{CO(g)} + 3\mathrm{H_2(g)}$；$\mathrm{CO(g)} + 2\mathrm{H_2(g)} \longrightarrow \mathrm{CH_3OH(g)}$

$$
n(\mathrm{CH_4}) = (250.0\times10^{3}\times55.0)/(8.314\times298) = 5.55\times10^{3}\,(\mathrm{mol})
$$

$$
n[\mathrm{H_2O(g)}] = (200.0\times10^{3}\times150.0)/(8.314\times423) = 8.53\times10^{3}\,(\mathrm{mol})
$$

经步骤 A 后在③中过量的 $H_2O(g)$ 为 $(8.53-5.55)\times10^{3} = 2.98\times10^{3}\,\mathrm{mol}$。步骤 A 中生成 CO 和 $H_2$ 摩尔比为 1:3，步骤 B 中消耗比 1:2，故经步骤 B 后剩余的 $H_2$ 为 $5.55\times10^{3}$ mol。

$$
n_T = n(\mathrm{CO})+n(\mathrm{H_2})+n(\mathrm{CH_3OH}) = \left[5.55\times10^{3}\times\tfrac{1}{3} + (16.65\times10^{3}-5.55\times10^{3}\times\tfrac{2}{3}\times2) + 5.55\times10^{3}\times\tfrac{2}{3}\right] = 14.8\times10^{3}\,\mathrm{mol}
$$

(3) $p(i) = p_T\times n_i/n_T$：

$$
p(\mathrm{CO}) = 10.0\times\tfrac{5.55\times10^{3}/3}{14.8\times10^{3}} = 1.25\,\mathrm{MPa},\quad p(\mathrm{H_2}) = 10.0\times\tfrac{9.25\times10^{3}}{14.8\times10^{3}} = 6.25\,\mathrm{MPa},\quad p(\mathrm{CH_3OH}) = 10.0\times\tfrac{5.55\times10^{3}\times2/3}{14.8\times10^{3}} = 2.50\,\mathrm{MPa}
$$

(4) $K_p = 2.50\times(0.100)^{2}/(1.25\times6.25^{2}) = 5.12\times10^{-4}$

**参考解答**（1）$\mathrm{CH_4+H_2O\to CO+3H_2}$、$\mathrm{CO+2H_2\to CH_3OH}$；（2）步骤 A 后过量 $H_2O(g)$ 为 $2.98\times10^{3}$ mol，步骤 B 后剩余 $H_2$ 为 $5.55\times10^{3}$ mol；（3）$p(\mathrm{CO})=1.25$、$p(\mathrm{H_2})=6.25$、$p(\mathrm{CH_3OH})=2.50$ MPa；（4）$K_p=5.12\times10^{-4}$。

### 第31题

> 来源：高中化学竞赛教程·第二分册

⑩ 配制 $\mathrm{KI}(0.100\,\mathrm{mol\cdot L^{-1}})-\mathrm{I}_2$ 的水溶液，用 $0.100\,\mathrm{mol\cdot L^{-1}}$ 的 $\mathrm{Na}_2\mathrm{S}_2\mathrm{O}_3$ 标准溶液测得 $c(\mathrm{I}_2) = 4.85\times10^{-3}\,\mathrm{mol\cdot L^{-1}}$。量取 $50.0\,\mathrm{mL}\,\mathrm{KI}-\mathrm{I}_2$ 溶液和 $50.0\,\mathrm{mL}\,\mathrm{CCl}_4$ 置于分液漏斗中振荡达平衡，分液后测知 $\mathrm{CCl}_4$ 相中 $c(\mathrm{I}_2) = 2.60\times10^{-3}\,\mathrm{mol\cdot L^{-1}}$。已知实验温度下 $\mathrm{CCl}_4$ 从水溶液中萃取 $\mathrm{I}_2$ 的分配比为 85:1，求水溶液中 $\mathrm{I}_2 + \mathrm{I}^{-} \rightleftharpoons \mathrm{I}_3^{-}$ 的平衡常数。

**参考答案**：

设萃取平衡时水溶液中 $c(\mathrm{I}_2) = x\,\mathrm{mol\cdot L^{-1}}$：

$$
\frac{c(\mathrm{I_2},\mathrm{CCl_4})}{c(\mathrm{I_2},\mathrm{H_2O})} = \frac{2.60\times10^{-3}}{x} = 85 \Rightarrow x = 3.06\times10^{-5}\,\mathrm{mol\cdot L^{-1}}
$$

水溶液中 $\mathrm{I_2} + \mathrm{I}^{-} \rightleftharpoons \mathrm{I}_3^{-}$，平衡浓度：

$c(\mathrm{I_2}) = 3.06\times10^{-5}\,\mathrm{mol\cdot L^{-1}}$

$c(\mathrm{I_3}^{-}) = (4.85-2.60)\times10^{-3} - 3.06\times10^{-5} = 2.22\times10^{-3}\,\mathrm{mol\cdot L^{-1}}$

$c(\mathrm{I}^{-}) = 0.100 - 2.22\times10^{-3} = 0.0978\,\mathrm{mol\cdot L^{-1}}$

$$
K = \frac{2.22\times10^{-3}}{3.06\times10^{-5}\times0.0978} = 7.4\times10^{2}\,\mathrm{L\cdot mol^{-1}}
$$
