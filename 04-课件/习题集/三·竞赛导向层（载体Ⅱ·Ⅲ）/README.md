## 与其他层的关系

- 与**一·随堂层**：本层为**竞赛导向拔高**；随堂层为**课内巩固**（大学教材源）。
- 与**二·评测层**：本层为**教学训练**（跟课）；评测层为**考核计分**。
- **同源多视角**：同一道竞赛题可同时进入专题卷与综合卷（不同卷用途不同），**不属于重复收录**；但两系列内部**互斥**（综合卷只从专题卷选剩的题里选）。
