## 3.41 苯炔中间体机理

**例题1：写出反应的机理**

以下一些反应产物的形成可能通过苯炔中间体，试写出这些反应的机理。

（给出三个涉及苯炔中间体的反应式）

**苯炔中间体的主要反应类型**：
- **亲核加成反应**：苯炔可与烷氧基负离子（如醇钠）发生亲核加成，缺电子炔碳接受亲核进攻后结合质子得到产物
- **Diels-Alder 反应**：苯炔作为缺电子二烯体与富电子二烯烃发生[4+2]环加成
- **二聚反应**：苯炔在常温下可发生[2+2]环二聚

**反应共性**：三个反应的第一步都是生成苯炔中间体，但具体机理各有特点。需特别注意每一步电子转移的方向和中间体形成过程。

**关键特征**：当产物连有易离去基团（如 $CO_{2}$）时更易发生逆向反应，反应可表示为协同过程，键的生成和断裂同时进行。

## 3.48 化学能力测试-Ch6B-4-二苯基丙烷热解自由基机理

煤热解建模用 α,ω-二苯基烷烃作模型化合物。1,3-二苯基丙烷（S=PhCH₂CH₂CH₂Ph）热解主产物甲苯与苯乙烯，副产物乙苯等。机理（第一步慢反应）：

① S → PhCH₂· + PhCH₂CH₂·（k₁，引发）
② PhCH₂CH₂· + S → PhCH₂CH₃ + PhĊHCH₂CH₂Ph（k₂）
③ PhCH₂· + S → PhCH₃ + PhĊHCH₂CH₂Ph（k₃）
④ PhĊHCH₂CH₂Ph → PhCH=CH₂ + PhCH₂·（k₄，β-断裂）

**4-1** 稳态近似处理自由基 2（PhCH₂CH₂·），导出生成乙苯的副反应速率方程。

**4-2** 求自由基 1（PhCH₂·）与自由基 3（PhĊHCH₂CH₂Ph）稳态浓度比值。

**4-3** 自由基可耦合 R₁·+R₂·→R₁R₂（k_R，对所有自由基同速率）。为何 (1)(2) 中可忽略这些反应？

**4-4** 反应混合物中浓度最大自由基是哪个？（a/c/b 三选）

**4-5** 导出甲苯生成的速率常数与反应级数，用基元活化能表示有效活化能。

**4-1** 稳态法 d[2]/dt = 0 = k₁[S] − k₂[S][2]：

$$r_\text{乙苯} = k_2[\mathrm S][2] = k_1[\mathrm S]$$

（乙苯副反应速率 = 引发速率——每生成一个自由基 2 就带走一个 S 成乙苯）

**4-2** d[3]/dt = 0 = k₂[S][2] + k₃[S][1] − k₄[3]。第一步为决速步故 k₁[S]≪k₃[S][1]，忽略 k₁[S]：

$$k_3[\mathrm S][1] = k_4[3] \Rightarrow [1]/[3] = k_4/(k_3[\mathrm S])$$

**4-3** 自由基生成速率小、浓度低；与 [R] 成比例的链增长速率远高于与 [R]² 成比例的重组速率——**长链近似**（许多链增长步骤发生在重组之前）。

**4-4** **(b)** PhCH₂· 浓度最大——因反应 4（β-断裂）的 k₄ 比反应 3 大得多（PhCH₂· 是稳定苄基自由基）。

**4-5** 自由基生成速率 = 重组速率（仅考虑 PhCH₂· 二聚）：

$$\frac{\mathrm d[\mathrm R]}{\mathrm dt} = 0 = 2k_1[\mathrm S] - 2k_\mathrm{R}[1]^2 \Rightarrow [1] = \sqrt{\frac{k_1[\mathrm S]}{k_\mathrm{R}}}$$

$$r_\text{甲苯} = k_3[1][\mathrm S] = \frac{k_1^{1/2}k_3}{k_\mathrm{R}^{1/2}}[\mathrm S]^{3/2}$$

**3/2 级反应**。表观速率常数 k = k₁^½k₃/k_R^½：

$$E = \frac{E_1}{2} + E_3 - \frac{E_\mathrm{R}}{2} \approx \frac{E_1}{2} + E_3$$

（自由基耦合活化能 $E_R$≈0）
