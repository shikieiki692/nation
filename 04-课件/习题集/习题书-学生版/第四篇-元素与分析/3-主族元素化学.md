## 3.1 锂氮氢化物储氢（第25届初赛）

$$2\mathbf{A} = \mathbf{C} + \mathbf{D}\tag{1}$$

A、C、E均能水解生成F和D。G是由X和Y组成的二元化合物，其阴离子是二氧化碳的等电子体，G分解生成E和一种无色无味的气体I。写出A、B、C、D、E、F、G和I的化学式。

某磷酸盐矿化学式是 A₅(PO₄)₃B（记为 N），具有熔融后重新结晶的性质。该磷酸盐矿结晶属于六方晶系，晶胞参数：a = b = 0.999 nm、c = 0.733 nm、α = γ = 90°、β = 120°、Z = 2。其密度 ρ = 7.111 g·cm⁻³。

## 3.151 化学能力测试-Ch7B-10-金属硫化物溶解性与酸

$$[\mathrm{S^{2-}}] \approx 0.1/(5.39\times 10^{49}) = 1.86\times 10^{-51}\ \mathrm{mol/L}$$

$$[\mathrm{Cu^{2+}}][\mathrm{S^{2-}}] = 0.1\times 1.86\times 10^{-51} \ll K_\mathrm{sp}(\mathrm{CuS})$$

**氧化使 S²⁻ 浓度骤降 → CuS 溶于 HNO₃**。
