### 22.54 解释实验现象

**(1) FeCl3溶液加KSCN变红，加铁粉后红色消失**

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n}\text{（n=1～6，血红色）}$$

加入铁粉后，铁粉将 $\left[\mathrm{Fe}(\mathrm{SCN})_{n}\right]^{3-n}$ 还原，生成的 $\mathrm{Fe}^{2+}$ 不与 $\mathrm{SCN}^{-}$ 生成有色配位化合物，因而血红色消失：


**(2) FeCl3加(NH4)2C2O4后加KSCN不变红，加盐酸后变红**

$\mathrm{FeCl}_{3}$ 遇 $(\mathrm{NH}_{4})_{2}\mathrm{C}_{2}\mathrm{O}_{4}$ 生成稳定的 $[\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]^{3-}$，其稳定性比 $[\mathrm{Fe}(\mathrm{SCN})]^{2+}$ 高，因而加入少量 KSCN 溶液时不变红：

$$\mathrm{Fe}^{3+} + 3\mathrm{C}_{2}\mathrm{O}_{4}^{2-} = [\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]^{3-}$$

再加入盐酸时，$\mathrm{C}_{2}\mathrm{O}_{4}^{2-}$ 转化为 $\mathrm{HC}_{2}\mathrm{O}_{4}^{-}$ 弱酸或 $\mathrm{H}_{2}\mathrm{C}_{2}\mathrm{O}_{4}$ 中强酸，而使 $\left[\mathrm{Fe}\left(\mathrm{C}_{2}\mathrm{O}_{4}\right)_{3}\right]^{3-}$ 破坏，再由 $\mathrm{Fe}^{3+}$ 与 $\mathrm{SCN}^{-}$ 结合使溶液变红：



**(3) 蓝色变色硅胶吸水后变粉红色**

变色硅胶中含有吸湿指示剂 $\left(\mathrm{CoCl}_{2}\right)$，随所含结晶水的数目不同，颜色不同：

$$\mathrm{CoCl}_{2}\cdot6\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}\cdot2\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}\cdot\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}$$

所以，无水 $\mathrm{CoCl}_{2}$ 显蓝色，$\mathrm{CoCl}_{2}$ 结晶水较多时显粉红色。

**(4) [Co(NH3)6]SO4加稀盐酸先沉淀后溶解**

向 $\left[\mathrm{Co}\left(\mathrm{NH}_{3}\right)_{6}\right]^{2+}$ 溶液中缓慢滴加稀盐酸，先有蓝绿色沉淀生成：

$$[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{2+} + \mathrm{HCl} + \mathrm{H}_{2}\mathrm{O} = \mathrm{Co(OH)Cl}\downarrow + 4\mathrm{NH}_{3} + 2\mathrm{NH}_{4}^{+}$$

盐酸过量则蓝绿色沉淀溶解，生成粉红色 $\left[\mathrm{Co}\left(\mathrm{H}_{2}\mathrm{O}\right)_{6}\right]^{2+}$ 溶液：

$$\mathrm{Co(OH)Cl} + \mathrm{HCl} + 5\mathrm{H}_{2}\mathrm{O} = [\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + 2\mathrm{Cl}^{-}$$

**(5) FeCl3溶液通入H2S无硫化物沉淀**

酸性条件下，$\mathrm{FeCl}_{3}$ 可以将 $\mathrm{H}_{2}\mathrm{S}$ 氧化，生成单质硫：

$$2\mathrm{FeCl}_{3} + \mathrm{H}_{2}\mathrm{S} = 2\mathrm{FeCl}_{2} + \mathrm{S}\downarrow + 2\mathrm{HCl}$$

$\mathrm{FeCl}_{3}$ 溶液的酸性较强，上述反应过程中又生成 HCl，而 FeS 在酸中的溶解度较大，不能沉淀。所以向 $\mathrm{FeCl}_{3}$ 溶液中通入 $\mathrm{H}_{2}\mathrm{S}$ 气体不会有硫化物沉淀生成。
