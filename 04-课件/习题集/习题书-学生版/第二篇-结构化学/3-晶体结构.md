## 3.1 晶体-习6

6. 在离子晶体中，阴、阳离子间力求尽可能多的接触，以降低体系的能量，使晶体稳定存在。因为阴离子一般都比阳离子的半径大，所以构成离子晶体时，阳离子必按此要求嵌在阴离子所堆积的空隙中。在离子晶体中每个阳(或阴)离子所接触的阴(或阳)离子总数，称为阳(或阴)离子的配位数。当阳、阴离子的电荷数相等时，这种配位数的多少，显然只与阳、阴离子的半径比 $r_{+}/r_{-}$ 的大小直接相关。为了研究这种关系，可用小黑点和小圆圈代表阳离子和阴离子(相当于把离子抽象为几何学中的点),在想象的空间格子中标出它们的所在位置，从而画出某种型式的晶体结构中最基本的重复单位(称为“晶胞”),如图1(CsCl型晶胞)和图3(NaCl型晶胞)所示；再从晶胞中切割出一些平面(切面),形象地画出阳、阴离子的接触切面图，如图2(与图1对应)和图4(与图3对应)所示。

(3) Na⁺ 离子：棱心 12 个 ×1/4 = 3，体心 1 个，合计 4 个；Cl⁻ 离子：面心 6×1/2 = 3，顶点 8×1/8 = 1，合计 4 个。故每个 NaCl 晶胞中有 4 个 Na⁺ + 4 个 Cl⁻，即 4 个 NaCl。

(4) 就 NaCl 晶胞，其面心立方的对角线长相当于 √2 倍的 a 长度，而对角线上的阴-阴离子彼此接触；边上的阴-阳离子也彼此接触，因此 $a = 2(r_{\mathrm{Na^+}} + r_{\mathrm{Cl^-}})$。由几何关系（接触条件为阴-阳相切而阴-阴不相切）得极限半径比 $r_+/r_- = 0.414$。

(5) 既然 $r_{\mathrm{Na^+}}/r_{\mathrm{Cl^-}}$ 比值 0.564 远大于六配位正八面体的最小理想值 0.414，氯离子膨胀排列使得八面体孔洞大得足够容纳钠离子。

(6) 当阳离子半径逐渐增加，阴离子不再彼此接触，将使该结构逐渐不稳定。没有充足的空间容纳更多的阴离子，直到阳离子/阴离子的半径比值等于 0.732，就像配位数八的体心立方 CsCl，其阳离子周围恰好可围绕 8 个阴离子。

(7) 配位数为六的 fcc 结构，其阳离子/阴离子半径比值范围从 0.414 至 0.732 是稳定的，即若 $0.414 < r^+/r^- < 0.732$，则离子结构就会像 NaCl 的 fcc 型态。

**1-2** (1) 根据布拉格定律 $\lambda = 2d\sin\theta$：

$$154\ \mathrm{pm} = 2\times d_{(200)}\sin(15.8^{\circ})$$

$$d_{(200)} = \frac{154}{2\times 0.272} = 283\ \mathrm{pm}$$

(2) 晶胞边长 $a = d_{(100)} = 2\times d_{(200)} = 2\times 283 = 566\ \mathrm{pm}$。

(3) 钠离子的半径 $r_{\mathrm{Na^+}} = (a - 2r_{\mathrm{Cl^-}})/2 = (566 - 362)/2 = 102\ \mathrm{pm}$。

**1-3** (1) hcp 与 ccp 的排列差异：hcp 以 ABAB…形式排列，第二层后再重复；ccp 以 ABCABC…形式堆积，重复形式在第三层之后。ccp 以立方晶格为基础，hcp 以六方晶格为基础。

(2) 空间占有率 = 4 个原子所占体积/晶胞体积。fcc：面对角线 $\sqrt{2}a = 4r$，$a = 2\sqrt{2}r$：

$$\text{空间占有率} = \frac{4\times\frac{4}{3}\pi r^3}{a^3} = \frac{16\pi r^3/3}{(2\sqrt{2}r)^3} = \frac{\pi}{3\sqrt{2}} = 0.74$$

(3) hcp 排列的配位数（12）和空间占有率（0.74）与 ccp 相同。

**1-4** (1) 对于 fcc，面对角线长 $\sqrt{2}a = 4r_{\mathrm{Ni}}$，$r_{\mathrm{Ni}} = \frac{\sqrt{2}\times 352.4}{4} = 124.6\ \mathrm{pm}$。

(2) 晶胞体积 $V = a^3 = (3.524\ \mathrm{Å})^3 = 43.76\ \mathrm{Å^3}$。

(3) $N_A = ZM/(\rho V) = \frac{4\times 58.69}{8.902\times 43.76\times 10^{-24}} = 6.02\times 10^{23}\ \mathrm{mol^{-1}}$。

## 3.191 化学能力测试-Ch3A-6-黄铁矿FeS2晶胞

X 射线衍射结果表明，黄铁矿（$\mathrm{FeS_2}$）的结构与氯化钠的结构相似。$\mathrm{Na^+}$ 被 Fe 原子取代，$\mathrm{Cl^-}$ 被 $\mathrm{S_2}$ 取代。用波长为 154 pm 的 X 射线进行衍射实验，发现在 8.17° 发生一级衍射。

**6-2** 铁原子的硫原子配位多面体是什么？配位数是多少？这些配位多面体按怎样的方式相互连接？根据对这些问题的解答，可推知 Fe—S 键的键型如何？

**6-3** X 射线测定结果表明，在 $\mathrm{S_2}$ 基团中 S 原子间的键距为 210 pm；而典型的 $\mathrm{S^{2-}}$ 半径为 312 pm，这些事实表明 $\mathrm{S_2}$ 基团中的键型如何？

**6-1** 布拉格方程 $2d\sin\theta = n\lambda$（此处 n=1）：

$$a = d = \frac{\lambda}{2\sin\theta} = \frac{154\times 10^{-10}}{2\times \sin 8.17^{\circ}} = 5.42\times 10^{-8}\ \mathrm{cm}$$

每个晶胞中 Fe 原子数 $= 1 + 12\times 1/4 = 4$，$\mathrm{S_2}$ 基团数 $= 8\times 1/8 + 6\times 1/2 = 4$（NaCl 型 Z=4）。晶胞体积 $V = a^3 = (5.42\times 10^{-8})^3 = 1.59\times 10^{-22}\ \mathrm{cm^3}$：

$$N_A = \frac{ZM}{VD} = \frac{4\times (55.85 + 32.06\times 2)}{1.59\times 10^{-22}\times 5.01} = 6.02\times 10^{23}$$

**6-2** 同 NaCl 晶体类似，FeS₂ 中 Fe 原子的 S 原子配位多面体是八面体，配位数为 6。但它又不同于 NaCl，Fe 原子的配位多面体可共面连接，这一事实说明在 FeS₂ 晶体中 Fe—S 键包含相当大的共价键成分（离子性更强的化合物很难形成共面连接的配位多面体）。这一事实还说明在 FeS₆ 八面体中，Fe 原子采用 d²sp³ 杂化轨道和 S 原子成键。

**6-3** S—S 键距（210 pm）小于典型的 S²⁻ 半径（312 pm，即若离子键则键距应接近 2×312 = 624 pm），说明两个 S 原子间的化学键是共价键（$\mathrm{[S_2]^{2-}}$ 过硫根中的 S—S 共价单键）。若是离子键，则键距会非常接近于离子半径的两倍。

| 知识点 | 体现 |
|--------|------|
| NaCl 型类比 | FeS₂ = Fe + [S₂]²⁻ 哑铃在 Cl⁻ 位 |
| Bragg 一级衍射 | a = d = λ/(2sinθ) |
| 阿伏伽德罗常数计算 | ρ = $ZM/(N_A\,V)$ |
| 杂化与键型 | 共面八面体 → d²sp³ 共价键 |
| S—S 键 | 210 pm ≪ 2×312 pm → 共价 |
