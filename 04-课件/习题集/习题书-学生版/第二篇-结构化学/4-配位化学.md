## 4.35 化学能力测试-Ch4B-1-Co氨配合物稳定性与晶体场

已知 $\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{3+} + \mathrm{e}^- \rightleftharpoons \left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{2+}$，$\varphi^{\theta} = 1.84\ \mathrm{V}$；

$\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+} + \mathrm{e}^- \rightleftharpoons \left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$，$\varphi^{\theta} = 0.10\ \mathrm{V}$。

$\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+}$、$\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$ 的磁矩分别为 0、3.88 B.M.。试分析：

**1-1** +2 价钴和 +3 价钴在配位状态的相对稳定性。

**1-2** 根据晶体场理论，说明上述两电对 $\varphi^{\theta}$ 值的差别。

**1-1** 根据软硬酸碱理论可知其稳定性：$\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+} > \left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$。Co³⁺ 电荷高、半径小，属硬酸，与硬碱 NH₃ 结合更稳定；Co(NH₃)₆³⁺ 不易被还原为 Co(NH₃)₆²⁺。

**1-2** 由于 $\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+}$ 的 $\mu = 0$，无未成对电子，八面体场分裂能 Δ₀ 大，是八面体强场，电子分布为 $\mathrm{t}_{2\mathrm{g}}^{6}\mathrm{e}_{\mathrm{g}}^{0}$，属低自旋；晶体稳定化能 $\mathrm{CFSE} = 6\times(-4D_q) + 0\times 6D_q = -24D_q$。

$\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$ 的 $\mu = 3.88$ B.M.，故 n=3，八面体场分裂能 Δ₀ 小，是八面体弱场，电子分布为 $\mathrm{t}_{2\mathrm{g}}^{5}\mathrm{e}_{\mathrm{g}}^{2}$，属高自旋；$\mathrm{CFSE} = 5\times(-4D_q) + 2\times 6D_q = -8D_q$。

前者 CFSE 负值大（注意二者 Dq 的个数和数值都不相同），体系能量下降得多，故 $\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+}$ 比 $\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$ 稳定得多。所以 $\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{3+}$ 不易被还原为 $\left[\mathrm{Co}(\mathrm{NH}_3)_6\right]^{2+}$，即 φθ 正值较小（0.10 V）。

$\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{3+}$ 为八面体弱场，电子分布为 $\mathrm{t}_{2\mathrm{g}}^{4}\mathrm{e}_{\mathrm{g}}^{2}$，属高自旋：$\mathrm{CFSE} = 4\times(-4D_q) + 2\times 6D_q = -4D_q$。$\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{2+}$ 为八面体弱场，电子分布为 $\mathrm{t}_{2\mathrm{g}}^{5}\mathrm{e}_{\mathrm{g}}^{2}$，属高自旋：$\mathrm{CFSE} = 5\times(-4D_q) + 2\times 6D_q = -8D_q$。根据 CFSE 大小，显然 $\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{3+}$ 不如 $\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{2+}$ 稳定，故 $\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{3+}$ 很容易被还原为 $\left[\mathrm{Co}(\mathrm{H}_2\mathrm{O})_6\right]^{2+}$，即 φθ 正值较大（1.84 V）。



| 知识点 | 本题应用 |
|---|---|
| 配合物 | 氨/水合 Co(II/III) 八面体配合物 |
| 晶体场理论 | t₂g/$e_g$ 分裂、强/弱场、低/高自旋与 CFSE 计算 |
| 磁矩 | μ=0（低自旋 d⁶）与 3.88 B.M.（n=3）判定自旋态 |
| 软硬酸碱理论 | Co³⁺ 硬酸亲 NH₃ 硬碱 |
| 氧化还原反应基础 | 配位环境改变氧化还原稳定性（φθ 1.84→0.10 V） |

## 4.128 化学能力测试-Ch6A-10-Cr配合物顺反对峙反应

正、逆均为一级的对峙反应：A ⇌ B（A、B 分别为反式/顺式 [Cr(en)₂(OH)₂]⁺，k₁/k₋₁ 为正逆速率常数）。

| T/K | t/min | $C_A$/mmol·L⁻¹ | $C_B$/mmol·L⁻¹ |
|---|---|---|---|
| 298 | 0 | 1.2 | 0 |
| 298 | 2.2 | | 0.05 |
| 298 | 足够长 | | 0.15 |
| 308 | 0 | 1.2 | 0 |
| 308 | 0.7 | | 0.05 |
| 308 | 足够长 | | 0.15 |

速率方程 $dc_B/dt = k_1c_A - k_{-1}c_B$，推导式：

$$\ln\frac{k_1c_\mathrm{A}^\theta}{k_1c_\mathrm{A}^\theta - (k_1+k_{-1})c_\mathrm{B}} = (k_1+k_{-1})t$$

**10-1** t=0 时仅有 A，$c_{A,0}$=2.1 mmol·L⁻¹。要求 $C_B$=0.1 mmol·L⁻¹ 时反应速率 0.13 mmol·L⁻¹·min⁻¹，确定合适温度是否在 298~308 K 范围内？

**10-2** 已知 S^θₘ(顺式,298K) > S^θₘ(反式,298K)，确定 A、B 中哪个是顺式哪个反式？

**10-1** 平衡常数 K = $k_1/k_{-1} = c_{B,e}/c_{A,e} = c_{B,e}/(c_{A,0}-c_{B,e})$：

$$K = \frac{0.15}{1.2 - 0.15} = \frac{1}{7},\quad k_{-1} = 7k_1$$

298 K：由速率积分式（$c_B$=0.05 at t=2.2）：

$$k_1 = \frac{c_{Be}}{c_\mathrm{A}^\theta t}\ln\frac{c_{Be}}{c_{Be}-c_\mathrm{B}} = \frac{0.15}{1.2\times 2.2}\ln\frac{0.15}{0.10} = 0.023\ \mathrm{min^{-1}}$$

$$k_{-1} = 7k_1 = 0.16\ \mathrm{min^{-1}}$$

308 K：

$$k_1 = \frac{0.15}{1.2\times 0.7}\ln\frac{0.15}{0.10} = 0.072\ \mathrm{min^{-1}}$$

$$k_{-1} = 7\times 0.072 = 0.50\ \mathrm{min^{-1}}$$

目标：$c_{A,0}$=2.1、$c_B$=0.1 时 v=$dc_B/dt = k_1(c_{A,0}-c_B) - k_{-1}c_B$：

- 298 K：v = 0.023×(2.1−0.1) − 0.16×0.1 = 0.046−0.016 = 0.030 mmol·L⁻¹·min⁻¹
- 308 K：v = 0.072×2.0 − 0.50×0.1 = 0.144−0.05 = 0.094 mmol·L⁻¹·min⁻¹

0.13 不在 0.030~0.094 范围内 → **温度不能在 298~308 K 内选择，需更高温度**。

**10-2** K 在两温度相同 → ΔrH^θ=0（Van't Hoff）。ΔrG^θ=−RT ln K = −TΔrS^θ（ΔH^θ=0）：

$$\Delta_\mathrm{r}S^\theta(298) = R\ln K = 8.314\ln(1/7) = -16.35\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

ΔrS^θ = S^θ(B) − S^θ(A) < 0 → S^θ(B) < S^θ(A)。

已知 S^θ(顺式) > S^θ(反式) → **A=顺式、B=反式**（反式对称性高、熵低）。



| 知识点 | 本题应用 |
|---|---|
| 化学动力学 | 对峙反应速率方程积分 |
| 速率方程 | $dc_B/dt = k_1c_A - k_{-1}c_B$ |
| 配合物异构 | [Cr(en)₂(OH)₂]⁺ 顺反异构 |
| Gibbs自由能 | ΔG^θ=−RT ln K、ΔS^θ=R ln K |
