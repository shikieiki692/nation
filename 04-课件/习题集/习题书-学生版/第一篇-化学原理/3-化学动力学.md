## 3.1 化学能力测试-Ch6A-1-鸡蛋蛋白热变与煮熟时间

鸡蛋中蛋白热变作用是一级反应，活化能 Eₐ=85 kJ·mol⁻¹。海平面沸水中煮熟一个鸡蛋需 10 分钟。登山队员登上珠穆朗玛峰（8848 m）后用水煮鸡蛋需多少分钟？

设空气中 80% N₂ + 20% O₂，气温 25℃ 恒定。

**1-1** 求 8848 m 处气体压强。

**1-2** 求 8848 m 处的沸点。

**1-3** 求 8848 m 处 vs 海平面反应速率之比 k₂/k₁。

**1-4** 求山顶煮熟鸡蛋所需时间。

**1-1** 空气 M=0.800×28×10⁻³+0.200×32×10⁻³=28.8×10⁻³ kg/mol

$$\ln(p_2/p_1) = \frac{28.8\times 10^{-3}\times 9.80\times 8848}{8.314\times 298.2} = 1.007,\quad p_2 = 0.365\ p^\theta$$

**1-2** p₂=0.365 p°，T₁=373.2 K，ΔvH(H₂O)=44010 J/mol

$$\ln(0.365) = \frac{44010(T_2 - 373.2)}{8.314\times 373.2\times T_2},\quad T_2 = 348.5\ \mathrm K$$

**1-3** Arrhenius：

$$\ln(k_2/k_1) = \frac{85000(348.5 - 373.2)}{8.314\times 373.2\times 348.5} = -1.945,\quad k_2/k_1 = 0.143$$

**1-4** 一级反应 ln(c/c₀) = -kt，对同一终点 c/c₀ 相同 → t₁/t₂ = k₂/k₁（注意 ln(c/c₀) 相同意味着 k t 相同 → k₁t₁ = k₂t₂ → t₂ = k₁t₁/k₂ = 10/0.143 = 70 min）

注：源答案文字「t₁/t₂ = k₂/k₁」与 k₁t₁=k₂t₂ 关系看似相反，实则源于 ln(k₁/k₂) 导出关系；按验算 t₂ ≈ 70 min（7 倍时间煮熟）。

## 3.4 化学能力测试-Ch6A-7-A2B反应级数与速率常数

298.2 K 时，反应 A + 2B = 2C + 2D 的速率方程为 v = k[A]ˣ[B]ʸ。

[A]₀=0.010 mol/L、[B]₀=0.020 mol/L 时（即 [A]₀=½[B]₀ 计量比）测得 [B] 随时间变化：

| t/h | 0 | 90 | 217 |
|---|---|---|---|
| [B]/mol·L⁻¹ | 0.020 | 0.010 | 0.0050 |

**7-1** 求该反应的总反应级数。

**7-2** 当 A、B 初始浓度均为 0.020 mol·L⁻¹ 时，测得初始反应速率为实验(1)的 1.4 倍。求 x 和 y。

**7-3** 算速率常数 k。

**7-1** 半衰期法：[B] 两次减半时间 t₁/₂(0.020→0.010)=90 h，t₁/₂'(0.010→0.0050)=217−90=127 h。

[A]=½[B] → v = k(½)ˣ[B]ˣ⁺ʸ = k′[B]ⁿ（n=x+y）：

$$n = 1 + \frac{\lg(t'_{1/2}/t_{1/2})}{\lg(c_0/c'_0)} = 1 + \frac{\lg(127/90)}{\lg(0.020/0.010)} = 1.5$$

**总反应级数 1.5 级**。

**7-2** 两实验初速率比（[B]₀ 相同 0.020，[A]₀ 从 0.010→0.020）：

$$v'/v = (0.020/0.010)^x = 2^x = 1.4 \Rightarrow x = 0.5$$

$$y = n - x = 1.5 - 0.5 = 1$$

**x=0.5（对 A）、y=1（对 B）**。

**7-3** 由实验(1)（[A]=½[B] 恒成立）：

$$v = -\frac{\mathrm d[\mathrm B]}{\mathrm dt} = k(1/2)^{0.5}[\mathrm B]^{1.5}$$

积分：[B] 从 0.020→0.010 用 90 h：

$$k = \frac{1}{90}\left[\frac{1}{0.35\times (0.010)^{0.5}} - 20\right] = 0.095\ \mathrm{L^{1.5}\cdot mol^{-0.5}\cdot h^{-1}}$$

| 半衰期 | t₁/₂ 与浓度关系 |

## 3.5 化学能力测试-Ch6A-8-环戊二烯二聚动力学

环戊二烯（沸点 40℃）气相二聚：2C₅H₆(g) → C₁₀H₁₂(g)。将 0.50 cm³ 液态环戊二烯（密度 0.802 g/cm³）放入真空 1000 cm³ 密闭容器。

**8-1** 容器升温至 130℃ 时的起始压力 p₀。

**8-2** 130℃ 测得容器总压随时间变化：

| t/min | 10 | 20 | 30 | 40 | 50 | 60 |
|---|---|---|---|---|---|---|
| p总/kPa | 18.07 | 16.62 | 15.63 | 14.87 | 14.33 | 13.88 |

推导 C₅H₆ 分压 p₁ 与 p₀、p总 的函数关系，计算各时刻 p₁。

**8-3** 推证反应级数。

**8-4** 计算速率常数。

**8-5** 计算转化率达 80% 所需时间。

**8-1** 环戊二烯 M=66.0（C₅H₆）：

$$p_0 = (0.802\times 0.50/66.0)\times 8.314\times 403/1.00 = 20.3\ \mathrm{kPa}\ (\text{用 m³·Pa·mol⁻¹·K⁻¹ 单位校准≈20 kPa})$$

**8-2** 2C₅H₆(g) = C₁₀H₁₂(g)：

| | C₅H₆ | C₁₀H₁₂ |
|---|---|---|
| 起始 | p₀ | 0 |
| 反应后 | p₀−2p₂ | p₂ |

p总 = p₀−2p₂+p₂ = p₀−p₂ → p₂ = p₀−p总：

$$p_1 = p_0 - 2p_2 = 2p_\text{总} - p_0$$

各时刻 p₁：

| t/min | 0 | 10 | 20 | 30 | 40 | 50 | 60 |
|---|---|---|---|---|---|---|---|
| p₁/kPa | 20.35 | 15.79 | 12.89 | 10.91 | 9.39 | 8.31 | 7.42 |

**8-3** 二级反应 1/p₁ = 1/p₀ + kt（p∝c 恒温），作 1/p₁~t 图为直线 → **二级反应**。

**8-4** 各点 k=(1/p₁−1/p₀)/t 近恒定，平均：

$$k = 1.43\times 10^{-3}\ \mathrm{kPa^{-1}\cdot min^{-1}}$$

**8-5** 转化率 80%：p₁ = p₀×(1−0.8) = 20.35×0.2 = 4.07 kPa

$$t = \frac{1/4.07 - 1/20.35}{1.43\times 10^{-3}} = 137\ \mathrm{min}$$

## 3.6 化学能力测试-Ch6A-9-N2O5分解动力学

N₂O₅ 是晶体，气相或在惰性溶剂中能全部分解：N₂O₅ ⇌ ½O₂ + NO₂ + ½N₂O₄（一级反应）。NO₂ 和 N₂O₄ 溶于 CCl₄，仅 O₂ 逸出，故 N₂O₅ 在 CCl₄ 中的分解可用气量管测 O₂ 体积。0.7372 g N₂O₅ 在 30℃ 和 p° 下的数据：

| t/s | 0 | 2400 | 9600 | 16800 |
|---|---|---|---|---|
| V(O₂)/mL | 0 | 15.65 | 45.85 | 63.00 |

**9-1** 求速率常数 k 及半衰期 t₁/₂。

**9-2** 30℃ 分解 90.0% 需多少秒？

**9-3** 活化能 1.03×10⁵ J/mol。若 2400 s 内收集 60.00 mL O₂（30℃ 时体积），需在什么温度实验？

**9-1** V∞ = 0.7372 g N₂O₅ 完全分解产 O₂ 体积。N₂O₅ M=108：

$$\mathrm{N_2O_5 \to NO_2 + \tfrac{1}{2}O_2 + \tfrac{1}{2}N_2O_4}$$

每 mol N₂O₅ 产 ½ mol O₂：

$$V_\infty = \tfrac{1}{2}\times\frac{0.7372/108\times 8.314\times 303}{101325} = 8.48\times 10^{-5}\ \mathrm{m^3} = 84.9\ \mathrm{cm^3}$$

一级：ln[V∞/(V∞−V)] = kt

k₁=ln(84.9/69.25)/2400=8.49×10⁻⁵；k₂=ln(84.9/39.05)/9600=8.09×10⁻⁵；k₃=ln(84.9/21.9)/16800=8.07×10⁻⁵ s⁻¹

$$k_\text{平均} = 8.22\times 10^{-5}\ \mathrm{s^{-1}}$$

$$t_{1/2} = \ln 2/k = 0.693/8.22\times 10^{-5} = 8.43\times 10^3\ \mathrm s$$

**9-2**

$$t = \frac{1}{k}\ln\frac{1}{1-y} = \frac{1}{8.22\times 10^{-5}}\ln\frac{1}{0.1} = 2.80\times 10^4\ \mathrm s$$

**9-3** 2400 s 内收 60.00 cm³ O₂，所需速率常数：

$$k_{T_2} = \frac{1}{2400}\ln\frac{84.9}{84.9-60.00} = 5.11\times 10^{-4}\ \mathrm{s^{-1}}$$

Arrhenius：

$$\ln\frac{k_{T_2}}{k_{T_1}} = \frac{E_\mathrm{a}(T_2-T_1)}{RT_1T_2}$$

$$\ln\frac{5.11\times 10^{-4}}{8.22\times 10^{-5}} = \frac{1.03\times 10^5(T_2-303)}{8.314\times 303\times T_2}$$

1.827 = 40.88×(T₂−303)/T₂ → T₂−303 = 0.0447T₂ → **T₂ = 317 K**

## 3.7 化学能力测试-Ch6B-1-酸雨H2SO4生成途径动力学

Molina 教授（1995 诺贝尔化学奖）研究大气酸雨 H₂SO₄ 生成过程，提出两个可能反应：

- 途径 A：H₂O(g) + SO₃(g) → H₂SO₄(g)
- 途径 B：2H₂O(g) + SO₃(g) → H₂SO₄(g) + H₂O(g)

**1-1** 简单碰撞理论下 A、B 的反应级数应为多少？

途径 B 分两步：SO₃ + 2H₂O ⇌ SO₃·2H₂O（k₁/k₋₁，快）、SO₃·2H₂O → H₂SO₄ + H₂O（k₂，慢）。

**1-2** 稳态法推导途径 B 的速率方程及反应级数。

**1-3** 量子化学活化能：途径 A 的 $E_A$=+80 kJ/mol；途径 B 的 $E_B$=−20 kJ/mol。给出 A、B 的 Arrhenius 方程并预测 $k \sim T$ 函数。

**1-4** H₂SO₄ 在高空（175 K）形成比地表（300 K）快。A、B 哪种途径在高空是主要机理？

**1-1** 途径 A 若为基元反应：d[H₂SO₄]/dt = k[H₂O][SO₃]，**二级**。

途径 B 由 2 个 H₂O + 1 个 SO₃ 一次碰撞：d[H₂SO₄]/dt = k[H₂O]²[SO₃]，**三级**。

**1-2** 稳态法（SO₃·2H₂O）：

$$\frac{\mathrm d[\mathrm{SO_3\cdot 2H_2O}]}{\mathrm dt} = k_1[\mathrm{SO_3}][\mathrm{H_2O}]^2 - k_{-1}[\mathrm{SO_3\cdot 2H_2O}] - k_2[\mathrm{SO_3\cdot 2H_2O}] = 0$$

$$[\mathrm{SO_3\cdot 2H_2O}] = \frac{k_1[\mathrm{SO_3}][\mathrm{H_2O}]^2}{k_2 + k_{-1}}$$

$$\frac{\mathrm d[\mathrm{H_2SO_4}]}{\mathrm dt} = k_2[\mathrm{SO_3\cdot 2H_2O}] = \frac{k_1k_2}{k_2+k_{-1}}[\mathrm{SO_3}][\mathrm{H_2O}]^2$$

k₂≪k₋₁ → d[H₂SO₄]/dt = k[SO₃][H₂O]²（k = k₁k₂/k₋₁），**三级反应**，与碰撞预测一致。

**1-3** Arrhenius：k_A = A_A·exp(−80×10³/RT)（k 随 T 升高增大）；k_B = A_B·exp(+20×10³/RT)（**k 随 T 升高减小**——负活化能）。

**1-4** 高空 175 K 低温下，exp(+20/RT) 项较大（指数中负号少）→ **途径 B 占优**。从碰撞几率看途径 A 合理，但其较大正活化能使之在高空不可行。

| 化学动力学 | 碰撞理论反应级数预测 |
| 反应级数 | A 二级 / B 三级 |
| Arrhenius方程 | 正/负活化能对 k-T 的影响 |
| 稳态近似 | SO₃·2H₂O 稳态处理 |

机理：① 碰撞活环丙烷分子 A+A→A\*+A（k₁/k₋₁）；② 活化分子转化为丙烯 A\*→B（k₂）。

**3-2** 稳态法（A\* 浓度不变）：

$$\frac{\mathrm d[\mathrm{A^*}]}{\mathrm dt} = k_1[\mathrm A]^2 - k_{-1}[\mathrm A][\mathrm{A^*}] - k_2[\mathrm{A^*}] = 0$$

$$[\mathrm{A^*}] = \frac{k_1[\mathrm A]^2}{k_{-1}[\mathrm A] + k_2}$$

$$\text{rate} = \frac{\mathrm d[\mathrm B]}{\mathrm dt} = k_2[\mathrm{A^*}] = \frac{k_1k_2[\mathrm A]^2}{k_{-1}[\mathrm A] + k_2}$$

**高压**（[A] 大）：k₋₁[A]≫k₂ → r = k₁k₂[A]/k₋₁ = k[A]（**一级**）

**低压**（[A] 小）：k₋₁[A]≪k₂ → r = k₁[A]²（**二级**）

中间压力范围级数复杂，既非一级亦非二级。

**5-1** 设 v = k[A]ᵅ[H⁺]ᵝ。缓冲液中 [H⁺] 恒定 → v = k'[A]ᵅ。

事实①：ln[A]₀/[A] = ln[p∞/(p∞−p)] = k't（[A]∝p∞−p）→ **对 A 一级（α=1）**。

准一级 t₁/₂ = 0.693/k' = 0.693/(k[H⁺]ᵝ)：

$$\lg t_{1/2} = \lg(0.693/k) - \beta\lg[\mathrm{H^+}] = \lg(0.693/k) + \beta\,\mathrm{pH}$$

斜率 −1 → β = −1。

**实验速率方程：v = k[A][H⁺]⁻¹**（即对 A 一级、对 H⁺ 负一级，碱催化）。

**5-2** 机理检验（稳态近似 I）：

$$v = k_2[\mathrm I],\quad \frac{\mathrm d[\mathrm I]}{\mathrm dt} = k_1[\mathrm A][\mathrm{OH^-}] - k_{-1}[\mathrm{H_2O}][\mathrm I] - k_2[\mathrm I] = 0$$

$$[\mathrm I] = \frac{k_1[\mathrm A][\mathrm{OH^-}]}{k_2 + k_{-1}[\mathrm{H_2O}]}$$

$$v = \frac{k_1k_2[\mathrm A][\mathrm{OH^-}]}{k_2 + k_{-1}[\mathrm{H_2O}]}$$

当 k₋₁[H₂O]≫k₂：

$$v = \frac{k_1k_2}{k_{-1}}\cdot\frac{[\mathrm A][\mathrm{OH^-}]}{[\mathrm{H_2O}]}$$

水的离子积 K = [H⁺][OH⁻]/[H₂O] → [OH⁻]/[H₂O] = K/[H⁺]：

$$v = \frac{Kk_1k_2}{k_{-1}}\cdot\frac{[\mathrm A]}{[\mathrm H^+]} = k[\mathrm A][\mathrm H^+]^{-1},\quad k = \frac{Kk_1k_2}{k_{-1}}$$

与实验速率方程相符（对 A 一级、对 H⁺ 负一级），机理成立。

## 3.29 化学能力测试-Ch6B-10-Langmuir吸附与多相催化

气体反应物在固体催化剂表面上的多相催化最常见。Langmuir 等温吸附模型：θ = Kp/(1+Kp)（θ 表面覆盖分数、p 气体压强、K 吸附平衡常数）。

**10-1** 固体表面气体 A 在 180 K、350 kPa 的吸附量与 240 K、1.02 MPa 的吸附量相同。求摩尔吸附焓变 Δ_adH^θₘ，并分析等温等压吸附是否自发。

**10-2** 表面吸附 A 分解直接生成气相产物（忽略产物吸附），r = k₁θ_A。298 K 测表观速率常数：高压下 500 kPa·s⁻¹、低压下 10 s⁻¹。求 A 分压 50 kPa 时的表观速率，并给高/低压下反应级数。

**10-3** 双分子反应 A(g)+B(g)→C(g)，表面反应发生在两吸附物种间且为速率决定步（L-H 机理）。已知 $p_A$、$p_B$、$K_A$、$K_B$、k₂，求表观反应速率；若 A 分压变化 B 分压不变，求速率极大值条件并解释。

**10-1** 相同吸附量 → $θ_A$ 相同 → $K_A$·$p_A$ 同为常数：

$$\frac{K_A(T_2)}{K_A(T_1)} = \frac{p_A(T_1)}{p_A(T_2)}$$

$$\Delta_\mathrm{ad}H^\theta_\mathrm m = R\left(\frac{1}{T_1}-\frac{1}{T_2}\right)^{-1}\ln\frac{p_A(T_1)}{p_A(T_2)} = 8.314\times\left(\frac{1}{180}-\frac{1}{240}\right)^{-1}\times\ln\frac{350}{1020} = -9.06\ \mathrm{kJ\cdot mol^{-1}}$$

ΔH<0 放热、ΔS<0（三维→二维有序）→ 低温下 ΔG=ΔH−TΔS<0，**吸附自发**。

**10-2** r = k₁·$K_A$ $p_A$/(1+$K_A$ $p_A$)：

- 高压（Kp≫1）：r=k₁=500 kPa·s⁻¹，**零级**
- 低压（Kp≪1）：r=k₁K_A $p_A$，k₁K_A=10 s⁻¹，**一级**

$K_A$ = 10/500 = 0.02 kPa⁻¹；50 kPa 时：

$$r = 500\times\frac{0.02\times 50}{1 + 0.02\times 50} = 500\times\frac{1}{2} = 250\ \mathrm{kPa\cdot s^{-1}}$$

**10-3** L-H 机理：

$$\theta_A = \frac{K_Ap_A}{1+K_Ap_A+K_Bp_B},\quad \theta_B = \frac{K_Bp_B}{1+K_Ap_A+K_Bp_B}$$

$$r = k_2\theta_A\theta_B = \frac{k_2K_Ap_AK_Bp_B}{(1+K_Ap_A+K_Bp_B)^2}$$

B 分压不变（$K_B$ $p_B$=C 常数），设 x=$K_A$ $p_A$：

$$r = \frac{k_2Cx}{(x+C+1)^2} = \frac{k_2C}{x + (C+1)^2/x + 2(C+1)}$$

双曲线函数 y=px+q/x 在 px=q/x 时取极小 → 分母最小、r 最大当 x=C+1：

$$K_Ap_A = K_Bp_B + 1 \quad (\theta_A = \tfrac{1}{2})$$

**解释**：双分子反应需表面相邻 A·B 吸附物种；$θ_A$=½ 时表面 A/B 配比最优。继续增大 $p_A$ → $θ_A$ 过高挤掉 B → 速率下降。
