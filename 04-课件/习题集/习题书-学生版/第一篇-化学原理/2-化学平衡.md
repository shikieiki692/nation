## 2.14 化学能力测试-Ch5A-10-CO2与H2转化率

在 500 K、101325 Pa 下，使等摩尔的 CO₂ 和 H₂ 发生如下反应。根据热力学原理求反应在此温度下的最大转化率。

$$\mathrm{CO_2(g) + H_2(g) \rightleftharpoons CO(g) + H_2O(g)}$$

已知 298.15 K 时下列物质的热力学数据为：

| 物质名称 | ΔfH^θₘ / kJ·mol⁻¹ | S^θₘ / J·K⁻¹·mol⁻¹ |
|---|---|---|
| CO₂(g) | −393.5 | 218.6 |
| H₂(g) | 0 | 130.6 |
| CO(g) | −110.5 | 197.9 |
| H₂O(g) | −241.8 | 188.7 |

**(1)** 求反应 K^θθ：

298.15 K 时：

$$\Delta_\mathrm{r}H^\theta_\mathrm{m} = \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{CO}) + \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{H_2O}) - \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{CO_2}) - \Delta_\mathrm{f}H^\theta_\mathrm{m}(\mathrm{H_2}) = +41.2\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta_\mathrm{r}S^\theta_\mathrm{m} = (197.9 + 188.7) - (218.6 + 130.6) = +37.4\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

500 K 时（假设 ΔH^θ、ΔS^θ 不随温度变）：

$$\Delta_\mathrm{r}G^\theta_\mathrm{m}(500) = \Delta_\mathrm{r}H^\theta - 500\times \Delta_\mathrm{r}S^\theta/1000 = 41.2 - 18.7 = +22.5\ \mathrm{kJ\cdot mol^{-1}}$$

由 $\Delta_\mathrm{r}G^\theta = -2.303RT\lg K^\theta$：

$$\lg K^\theta = -22.5\times 10^3/(2.303\times 8.314\times 500) = -2.35$$

$$K^\theta = 10^{-2.35} = 4.5\times 10^{-3}$$

**(2)** 求反应的最大转化率：

设等摩尔各 n mol，转化率 α：

| | CO₂ | H₂ | CO | H₂O |
|---|---|---|---|---|
| 起始 | n | n | 0 | 0 |
| 平衡 | n(1−α) | n(1−α) | nα | nα |

总物质的量 = 2n。

$$p(\mathrm{CO_2}) = p(\mathrm{H_2}) = (1-\alpha)/2\cdot p^\theta$$

$$p(\mathrm{CO}) = p(\mathrm{H_2O}) = \alpha/2\cdot p^\theta$$

$$K^\theta = \frac{(\alpha/2)^2}{[(1-\alpha)/2]^2} = \frac{\alpha^2}{(1-\alpha)^2} = 4.5\times 10^{-3}$$

$$\frac{\alpha}{1-\alpha} = \sqrt{4.5\times 10^{-3}} = 0.0671$$

$$\alpha = 0.0671 - 0.0671\alpha \Rightarrow 1.0671\alpha = 0.0671$$

$$\alpha = 6.3\%$$

源答案给 α = 40%（与验算 6.3% 不符），照录并注存疑（疑源答案 K^θ 计算误用 ΔrG^θ 符号或 ΔrG^θ=22.5 应为 −22.5 而 K^θ=10²·³⁵=224）。



| 知识点 | 本题应用 |
|---|---|
| Gibbs自由能 | ΔG^θ=−RT ln K^θ，α²/(1−α)²=K^θ |
| 热力学第一定律 | ΔG^θ(T)≈ΔH^θ(298K)−TΔS^θ(298K)（忽略 T 依赖） |
