### 6.1 〔🟢 d2〕

> KP：[[MnO₄⁻分解]] ｜ 来源：第26届中国化学奥林匹克（初赛）第3题第(3-2)小问

> **来源**：第26届中国化学奥林匹克（初赛）第3题(10分) 第(3-2)小问

写出步骤(b)中溶液由淡紫色变为蓝色的过程中所发生反应的方程式。

<details>
<summary>📖 查看答案</summary>

$$
4\mathrm{MnO}_4^{-} + 12\mathrm{H}^{+} = 4\mathrm{Mn}^{2+} + 5\mathrm{O}_2 \uparrow + 6\mathrm{H}_2\mathrm{O}
$$

加热条件下MnO₄⁻分解为Mn²⁺（浅粉红/无色）和O₂。紫红色褪去后，溶液显Cu²⁺的蓝色。

## 知识点映射

- MnO₄⁻热分解
- 颜色变化

## 解题思路

1. 步骤(a)过量KMnO₄→溶液显浅紫红色
2. 加热→MnO₄⁻分解→Mn²⁺（无色）
3. 紫红色褪去→Cu²⁺蓝色显现

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 分解条件 | 加热促进MnO₄⁻分解 |
| 产物 | Mn²⁺（不是MnO₂沉淀） |

</details>

### 6.2 〔🟢 d2〕

> KP：[[化学势与平衡]] ｜ 来源：第30届中国化学奥林匹克（初赛）第6题第2小问

> **来源**：[[07-资料提炼/提炼-第30届初赛试题解析|第30届初赛第6题]]（原始文件：[[mineru/02-真题解析/30届初赛试题解析]]）
> **小问关联**：本文件为第6-2小问；其余小问见 [[题-030-6-1-295K下N2O4NO2分压计算]]、[[题-030-6-3-体积比及物质的量之比]]、[[题-030-6-4-NO2分压最大理论趋近值]]、[[题-030-6-5-平衡移动方向选择题]]、[[题-030-6-6-恒压vs恒容平衡移动程度]]

将上述体系温度升至 $315 \mathrm{~K}$，计算达平衡时 $\mathrm{N}_{2} \mathrm{O}_{4}$ 和 $\mathrm{NO}_{2}$ 的分压。

<details>
<summary>📖 查看答案</summary>

- $\mathrm{NO}_{2}$ 分压：$46.3 \mathrm{~kPa}$
- $\mathrm{N}_2\mathrm{O}_4$ 分压：$53.7 \mathrm{~kPa}$

## 解析

与 6-1 解法相同，只需把平衡常数换作 0.400 即可：

$$
K^{\ominus} = \frac{(x / p^{\ominus})^{2}}{(100 - x) / p^{\ominus}} = 0.400
$$

$$
x = 46.3 \mathrm{~kPa}
$$

故 $\mathrm{NO}_{2}$ 分压为 $46.3 \mathrm{~kPa}$，$\mathrm{N}_2\mathrm{O}_4$ 分压为 $53.7 \mathrm{~kPa}$。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 温度对平衡的影响 | 升温使K增大，平衡向吸热方向（右）移动 |
| 平衡常数应用 | 同一计算方法，只需更换K值 |
| 分压变化趋势 | 升温后NO₂分压增大，N₂O₄分压减小 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 用错平衡常数 | 315K时K=0.400，不是0.100 |
| 认为分压不变 | 温度改变，平衡位置改变，分压随之改变 |
| 计算错误 | 解方程得x=46.3（另一根为负舍去） |

</details>

### 6.3 〔🟢 d2〕

> KP：[[核反应]] ｜ 来源：第36届中国化学奥林匹克（初赛）第二场第7题第(7-3)小问

> 关联小问：[[题-036b-7-1-1-晶胞中化学式数目n|7-1-1]] | [[题-036b-7-1-2-Mg2+分数坐标|7-1-2]] | [[题-036b-7-1-3-Mg2+最短距离计算|7-1-3]] | [[题-036b-7-2-1-嫦娥石化学式|7-2-1]] | [[题-036b-7-2-2-嫦娥石密度计算|7-2-2]]
>
> 来源：[[07-资料提炼/提炼-第36届初赛试题解析（第二场）|提炼笔记]] | [[mineru/02-真题解析/36届初赛试题解析2|原始解析]]

初步研究表明，嫦娥石中含有 ${}^{3}He$ ，$FeO_6$ 和 $PO_4$ 可能是其吸附位置。${}^{3}He$ 已用于中子探测，也很可能成为人类未来的能源。${}^{3}He$ 与中子作用产生质子和氚，写出核反应方程式。

<details>
<summary>📖 查看答案</summary>

书写核反应方程式时，要注意将所有粒子物种的核电荷数和质量数标出，同时保证反应前后核电荷数和质量数守恒：

将 $^{3}_{1}H$ 写为 $^{3}_{1}T$ 也可以。

$$
{ } _ { 2 } ^ { 3 } \mathrm{He} + { } _ { 0 } ^ { 1 } \mathrm{n} \longrightarrow { } _ { 1 } ^ { 3 } \mathrm{H} + { } _ { 1 } ^ { 1 } \mathrm{H}
$$

## 知识点映射

| 知识点 | 直接关联 |
|:---|:---:|
| 核反应 | ✅ |
| 核反应方程式 | ✅ |
| 质量数与核电荷数守恒 | ✅ |

## 解题思路

1. 确定反应物：$^{3}_{2}\mathrm{He}$ 和 $^{1}_{0}\mathrm{n}$
2. 确定产物：$^{3}_{1}\mathrm{H}$（氚）和 $^{1}_{1}\mathrm{H}$（质子）
3. 验证质量数守恒：3 + 1 = 3 + 1
4. 验证核电荷数守恒：2 + 0 = 1 + 1

## 易错分析

- **未标注质量数和核电荷数**：核反应方程式必须标注
- **守恒验证错误**：未验证质量数和核电荷数是否守恒
- **产物判断错误**：将氚误写为其他粒子

### 6.4 〔🟢 d2〕

> KP：[[电子传导]] ｜ 来源：第38届中国化学奥林匹克（初赛）第7题第(7-3-2)小问

复合膜中加入碳纳米管的作用是什么？

---

<details>
<summary>📖 查看答案</summary>

碳纳米管的作用是使复合膜兼具**电子传输能力**。

阴离子交换树脂是一种结构聚合物材料，通常只具备**离子导电性**，而不能导通电子。因此加入碳纳米管的目的是使得复合膜兼具**电子传导性能**。

---

## 知识点映射

- **直接 KP**：电子传导、复合材料
- **间接 KP**：碳纳米管性质、膜材料

---

## 解题思路

1. 题目提示"这种薄膜兼具离子和电子传导性能"
2. 阴离子交换树脂只具备离子导电性
3. 碳纳米管具有优异的电子传导性能
4. 两者复合后实现离子和电子双重传导

---

## 易错分析

- 需要理解阴离子交换树脂的导电特性（仅离子导电）
- 碳纳米管的主要贡献是电子传导而非离子传导

### 6.5 〔🟢 d3〕

> KP：[[复杂氧化还原配平]] ｜ 来源：第32届中国化学奥林匹克（初赛）第1题第(1-4)小问

> **来源**：[[07-资料提炼/提炼-第32届初赛试题解析|第32届初赛第1题]]（原始文件：[[mineru/02-真题解析/32届初赛试题解析]]）
> **小问关联**：本文件为第(1-4)小问；其余小问见 [[题-032-1-1-氮化硅制备方程式]]、[[题-032-1-2-铜与浓硫酸反应方程式]]、[[题-032-1-3-碲氢化钠制备方程式]]

1-4 天然气的无机成因说十分诱人。据称，地幔主成分之一的橄榄石与水和二氧化碳反应，可以生成甲烷。橄榄石以 $\mathrm{Mg}_{2}\mathrm{SiO}_{4}$ 和 $\mathrm{Fe}_{2}\mathrm{SiO}_{4}$ 表示，反应后变为蛇纹石 $[\mathrm{Mg}_{3}\mathrm{Si}_{2}\mathrm{O}_{5}(\mathrm{OH})_{4}]$ 和磁铁矿。

<details>
<summary>📖 查看答案</summary>

**得分点**：
1. **正确判断磁铁矿化学式**（1分）：$\mathrm{Fe}_{3}\mathrm{O}_{4}$
2. **正确分析氧化还原过程**（1分）：$\mathrm{CO}_{2}$ 中 C(+4) 被还原为 $\mathrm{CH}_{4}$ 中 C(-4)，$\mathrm{Fe}_{2}\mathrm{SiO}_{4}$ 中 Fe(+2) 被氧化为 $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 中 Fe(+3 和 +2)
3. **正确计算电子得失比并配平**（1分）：$n(\mathrm{CH}_{4}):n(\mathrm{Fe}_{3}\mathrm{O}_{4}) = 1:4$

$$
18\mathrm{Mg}_{2}\mathrm{SiO}_{4} + 6\mathrm{Fe}_{2}\mathrm{SiO}_{4} + 26\mathrm{H}_{2}\mathrm{O} + \mathrm{CO}_{2} \longrightarrow 12\mathrm{Mg}_{3}\mathrm{Si}_{2}\mathrm{O}_{5}(\mathrm{OH})_{4} + \mathrm{CH}_{4} + 4\mathrm{Fe}_{3}\mathrm{O}_{4}
$$

## 知识点映射

| 关联 KP | 考查角度 | 直接/间接 |
|---|---|:---:|
| 复杂氧化还原配平 | 多反应物多产物的氧化还原方程式配平 | 直接 |
| 蛇纹石 | 蛇纹石的化学式与结构 | 直接 |
| 磁铁矿 | 磁铁矿 $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 的化学式 | 直接 |

## 解题思路

1. **读题定位**：题目要求书写橄榄石与水和二氧化碳反应生成甲烷、蛇纹石和磁铁矿的方程式。
2. **🔑 关键转换**：磁铁矿化学式为 $\mathrm{Fe}_{3}\mathrm{O}_{4}$；$\mathrm{CO}_{2}$ 中 C(+4) 被还原为 $\mathrm{CH}_{4}$ 中 C(-4)，得 8e；$\mathrm{Fe}_{2}\mathrm{SiO}_{4}$ 中 Fe(+2) 被氧化为 $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 中 Fe(+3)，失 2e（按平均氧化态计算）。因此 $n(\mathrm{CH}_{4}):n(\mathrm{Fe}_{3}\mathrm{O}_{4}) = 1:4$。
3. **配平要点**：先根据电子得失确定 $\mathrm{CH}_{4}$ 和 $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 的比例，再用元素守恒配平 Mg、Si、H、O。

## 易错分析

| 错误 | 原因 | 纠正 | 课堂提问 |
|---|---|---|---|
| 磁铁矿化学式写错 | 不熟悉磁铁矿的化学式 | 磁铁矿为 $\mathrm{Fe}_{3}\mathrm{O}_{4}$（可看作 $\mathrm{FeO}\cdot\mathrm{Fe}_{2}\mathrm{O}_{3}$） | 磁铁矿中 Fe 的氧化态分别是多少？ |
| 电子得失计算错误 | 未正确计算 $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 中 Fe 的氧化数变化 | $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 中 Fe 平均氧化态为 +8/3，从 +2 氧化失 2/3 e  per Fe，即 1 mol $\mathrm{Fe}_{3}\mathrm{O}_{4}$ 失 2e | 如何计算复杂氧化物中元素的平均氧化态？ |
| 蛇纹石化学式写错 | 未注意蛇纹石化学式中的括号 | 蛇纹石为 $\mathrm{Mg}_{3}\mathrm{Si}_{2}\mathrm{O}_{5}(\mathrm{OH})_{4}$ | 蛇纹石与橄榄石在结构上有何关系？ |

</details>

### 6.6 〔🟢 d3〕

> KP：[[Nernst方程]] ｜ 来源：第37届中国化学奥林匹克（初赛）第7题第(7-1-2)小问

> 关联小问：[[题-037-7-1-1-磷脂双层膜离子通透性|7-1-1]] · [[题-037-7-1-3-脂质体粒径计算|7-1-3]] · [[题-037-7-1-4-磷脂排布密度计算|7-1-4]] · [[题-037-7-2-1-二聚反应热力学计算|7-2-1]] · [[题-037-7-2-2-熵驱动反应分析|7-2-2]]
> 来源：[[mineru/02-真题解析/37届初赛试题解析|37届初赛试题解析]] · [[07-资料提炼/提炼-第37届初赛试题解析|提炼笔记]]

细胞膜是由磷脂层膜组成，由于细胞内外离子浓度的不均匀性，造成了膜两边形成了一定的电势差，被称为膜电位。由离子 $A^{n+}$ 浓差形成的膜电位（定义细胞外的电势为零）可以通过如下方程计算：

$$
\varphi_{A^{n+}} = \frac{RT}{nF} \ln \frac{[A^{n+}]_{\text{外}}}{[A^{n+}]_{\text{内}}}
$$

神经元细胞内和细胞外的钠离子和钾离子浓度分别为 $[\mathrm{Na}^{+}]_{\text{内}} = 12.0 \, \mathrm{mmol \, L}^{-1}$，$[\mathrm{K}^{+}]_{\text{内}} = 155 \, \mathrm{mmol \, L}^{-1}$，$[\mathrm{Na}^{+}]_{\text{外}} = 145 \, \mathrm{mmol \, L}^{-1}$，$[\mathrm{K}^{+}]_{\text{外}} = 4.00 \, \mathrm{mmol \, L}^{-1}$，计算 $37.0^{\circ}\mathrm{C}$ 下此种细胞的膜电位（注明正负）。

<details>
<summary>📖 查看答案</summary>

**计算钠离子贡献的膜电位**：

$$
\varphi_{\mathrm{Na}^{+}} = \frac{8.314 \times (273.15 + 37)}{1 \times 96485} \ln \frac{145}{12.0} = 66.6 \, \mathrm{mV}
$$

**计算钾离子贡献的膜电位**：

$$
\varphi_{\mathrm{K}^{+}} = \frac{8.314 \times (273.15 + 37)}{1 \times 96485} \ln \frac{4.00}{155} = -97.7 \, \mathrm{mV}
$$

**计算总膜电位**（并联关系）：

$$
E = \frac{\varphi_{\mathrm{K}^{+}} + \varphi_{\mathrm{Na}^{+}}}{2} = \frac{-97.7 + 66.6}{2} = -15.6 \, \mathrm{mV}
$$

**答案**：膜电位为 **-15.6 mV**（或 -31.2 mV，见易错分析）。

## 知识点映射

| 知识点 | 关联程度 | 说明 |
|:---|:---:|:---|
| Nernst方程 | 直接 | 浓差电位的计算 |
| 膜电位 | 直接 | 细胞内外离子浓差形成的电位 |
| 并联电路 | 间接 | 两种离子贡献的膜电位的叠加 |
| 温度换算 | 直接 | 摄氏度转换为开尔文 |

## 解题思路

1. **分别计算Na⁺和K⁺的膜电位**：利用Nernst方程，注意温度为37°C（310.15 K）。
2. **确定叠加方式**：两种离子的膜电位看作并联关系，取平均值。
3. **计算总膜电位**：$E = (\varphi_{K^{+}} + \varphi_{Na^{+}})/2$。
4. **注明正负**：负号表示细胞内电势低于细胞外。

## 易错分析

- **温度错误**：使用37°C而非25°C，不能直接用0.0592 V。
- **并联关系忽略**：直接将两个电位相加得-31.2 mV也给分，但精确计算应取平均。
- **对数符号错误**：注意$[外]/[内]$的顺序。
- **Goldman方程**：精确计算需用Goldman-Hodgkin-Katz方程，结果为+3.04 mV，但本题不要求。

### 6.8 〔🟢 d3〕

> KP：[[电化学反应]] ｜ 来源：第38届中国化学奥林匹克（初赛）第7题第(7-3-1)小问

科学家发明了一种由阴离子交换树脂-碳纳米管构成的膜分离装置（如下图所示），可以连续去除空气中的 $\mathrm{CO}_{2}$，在富集 $\mathrm{CO}_{2}$ 的同时获得基本不含 $\mathrm{CO}_{2}$ 的空气。除去 $\mathrm{CO}_{2}$ 的空气可用于碱性燃料电池。这种薄膜兼具离子和电子传导性能，膜的 A 侧通入含 $\mathrm{CO}_{2}$ 的空气，B 侧通入少量 $\mathrm{H}_{2}$。经过反应后，A 侧得到基本不含 $\mathrm{CO}_{2}$ 的空气，$\mathrm{CO}_{2}$ 转化成了 $\mathrm{HCO}_{3}^{-}$；B 侧得到较高浓度的 $\mathrm{CO}_{2}$。

![[mineru/02-真题解析/38届初赛试题解析_images/f9e12ea483b96d3938061688a7df554e9ba3124365057f065a00673836bad17d.jpg]]

写出 A 侧 $\mathrm{CO}_{2}$ 转化成 $\mathrm{HCO}_{3}^{-}$ 和 B 侧释放 $\mathrm{CO}_{2}$ 的反应方程式。

---

<details>
<summary>📖 查看答案</summary>

**A 侧（CO2 转化为 HCO3⁻）：**

$$\mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} + 4\mathrm{CO}_{2} + 4\mathrm{e}^{-} \longrightarrow 4\mathrm{HCO}_{3}^{-}$$

**B 侧（HCO3⁻ 释放 CO2）：**

$$\mathrm{H}_{2} - 2\mathrm{e}^{-} + 2\mathrm{HCO}_{3}^{-} \longrightarrow 2\mathrm{H}_{2}\mathrm{O} + 2\mathrm{CO}_{2}$$

## 解题思路

**A 侧：**
1. CO2 转化为 HCO3⁻ 需要 OH⁻
2. O(-II) 由空气中 O2 通过电还原反应提供
3. H 元素由水分子提供

**B 侧：**
1. HCO3⁻ 通过阴离子交换树脂转移到 B 侧

3. H⁺ 由 H2 的电氧化反应提供

## 10.25 浓盐酸制氯气的原因

在实验室中通常用下列反应制取氯气：

$$
\mathrm{MnO}_{2} + 4\mathrm{HCl} = \mathrm{MnCl}_{2} + \mathrm{Cl}_{2} + 2\mathrm{H}_{2}\mathrm{O}
$$

试通过计算回答：为什么必须使用浓盐酸？

已知 $E^{\ominus}(\mathrm{MnO}_{2}/\mathrm{Mn}^{2+}) = 1.22 \; \mathrm{V}$，$E^{\ominus}(\mathrm{Cl}_{2}/\mathrm{Cl}^{-}) = 1.36 \; \mathrm{V}$

### 解答

正极：$\mathrm{MnO}_{2} + 4\mathrm{H}^{+} + 2\mathrm{e}^{-} = \mathrm{Mn}^{2+} + 2\mathrm{H}_{2}\mathrm{O}$，$E_{+}^{\ominus} = 1.22 \; \mathrm{V}$

负极：$\mathrm{Cl}_{2} + 2\mathrm{e}^{-} = 2\mathrm{Cl}^{-}$，$E_{-}^{\ominus} = 1.36 \; \mathrm{V}$

在标准状态下：$E^{\ominus} = 1.22 \; \mathrm{V} - 1.36 \; \mathrm{V} = -0.14 \; \mathrm{V}$，为负值，反应不能自发进行。

正极反应的能斯特方程为：

$$
E_{+} = E_{+}^{\ominus} + \frac{0.059 \; \mathrm{V}}{2} \lg [c(\mathrm{H}^{+})]^{4}
$$

负极反应的能斯特方程为：

$$
E_{-} = E_{-}^{\ominus} + \frac{0.059 \; \mathrm{V}}{2} \lg \frac{1}{[c(\mathrm{Cl}^{-})]^{2}}
$$

当 $E_{+} = E_{-}$ 时（平衡状态），在盐酸中 $c(\mathrm{H}^{+}) = c(\mathrm{Cl}^{-}) = c(\text{盐酸})$，故有：

$$
1.22 \; \mathrm{V} + \frac{0.059 \; \mathrm{V}}{2} \lg [c(\text{盐酸})]^{4} = 1.36 \; \mathrm{V} + \frac{0.059 \; \mathrm{V}}{2} \lg \frac{1}{[c(\text{盐酸})]^{2}}
$$

解得：$c(\text{盐酸}) = 6.18 \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$

**结论**：只有用浓盐酸才能制 $\mathrm{Cl}_{2}$，而且需要加热，以保证反应速率足够快。

## 10.26 CuS 溶度积常数的测定

某学生为测定 CuS 的溶度积常数，设计如下原电池：正极为铜片，在 $0.1 \; \mathrm{mol} \cdot \mathrm{dm}^{-3} \; \mathrm{Cu}^{2+}$ 溶液中，再通入 $\mathrm{H}_{2}\mathrm{S}$ 气体使之达到饱和；负极为标准锌电极。测得电池电动势为 $0.67 \; \mathrm{V}$。

已知 $E^{\ominus}(\mathrm{Cu}^{2+}/\mathrm{Cu}) = 0.34 \; \mathrm{V}$，$E^{\ominus}(\mathrm{Zn}^{2+}/\mathrm{Zn}) = -0.76 \; \mathrm{V}$，$\mathrm{H}_{2}\mathrm{S}$ 的 $K_{\mathrm{a1}}^{\ominus} = 1.1 \times 10^{-7}$，$K_{\mathrm{a2}}^{\ominus} = 1.3 \times 10^{-13}$。试求 CuS 的溶度积常数。

### 解答

设生成 CuS 沉淀后，正极溶液中 $\mathrm{Cu}^{2+}$ 的浓度为 $x \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$。

$$
(-)\mathrm{Zn} | \mathrm{Zn}^{2+}(1 \; \mathrm{mol} \cdot \mathrm{dm}^{-3}) \| \mathrm{Cu}^{2+}(x \; \mathrm{mol} \cdot \mathrm{dm}^{-3}) | \mathrm{Cu}(+)
$$

电池反应：$\mathrm{Cu}^{2+} + \mathrm{Zn} = \mathrm{Cu} + \mathrm{Zn}^{2+}$

$$
E = E^{\ominus} - \frac{0.059 \; \mathrm{V}}{2} \lg \frac{c(\mathrm{Zn}^{2+})}{c(\mathrm{Cu}^{2+})}
$$

$$
0.67 \; \mathrm{V} = [0.34 \; \mathrm{V} - (-0.76 \; \mathrm{V})] - \frac{0.059 \; \mathrm{V}}{2} \lg \frac{1}{x}
$$

解得 $x = 2.7 \times 10^{-15}$，即 $c(\mathrm{Cu}^{2+}) = 2.7 \times 10^{-15} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$。

平衡时 $0.1 \; \mathrm{mol} \cdot \mathrm{dm}^{-3} \; \mathrm{Cu}^{2+}$ 几乎全部转化为 CuS：

$$
\mathrm{Cu}^{2+} + \mathrm{H}_{2}\mathrm{S} = \mathrm{CuS} \downarrow + 2\mathrm{H}^{+}
$$

则溶液中 $c(\mathrm{H}^{+}) = 2 \times 0.1 = 0.2 \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$。

饱和溶液时 $c(\mathrm{H}_{2}\mathrm{S}) = 0.1 \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$：

$$
c(\mathrm{S}^{2-}) = \frac{K_{\mathrm{a1}}^{\ominus} \cdot K_{\mathrm{a2}}^{\ominus} \cdot c(\mathrm{H}_{2}\mathrm{S})}{[c(\mathrm{H}^{+})]^{2}} = \frac{1.1 \times 10^{-7} \times 1.3 \times 10^{-13} \times 0.1}{(0.2)^{2}} = 3.6 \times 10^{-20} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}
$$

$$
K_{\mathrm{sp}}^{\ominus}(\mathrm{CuS}) = c(\mathrm{Cu}^{2+}) \cdot c(\mathrm{S}^{2-}) = 2.7 \times 10^{-15} \times 3.6 \times 10^{-20} = 9.7 \times 10^{-35}
$$

## 10.30 CuCl 沉淀对反应自发性的影响

$$

\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus} = -2 \times 1.53 \times 96.5 \; \mathrm{kJ} \cdot \mathrm{mol}^{-1} = -295.3 \; \mathrm{kJ} \cdot \mathrm{mol}^{-1}
$$

**(c)** $z = 6$：

$$
E^{\ominus}(\mathrm{c}) = E^{\ominus}(\mathrm{Tl}^{3+}/\mathrm{Tl}^{+}) - E^{\ominus}(\mathrm{Tl}^{3+}/\mathrm{Tl}) = 1.25 \; \mathrm{V} - 0.74 \; \mathrm{V} = 0.51 \; \mathrm{V}
$$

$$
\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus} = -6 \times 0.51 \times 96.5 \; \mathrm{kJ} \cdot \mathrm{mol}^{-1} = -295.3 \; \mathrm{kJ} \cdot \mathrm{mol}^{-1}
$$

**结论**：三个电池反应的 $\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus}$ 相同，这是因为电池反应式完全相同，$G$ 是状态函数。

## 10.33 KMnO₄ 滴加到过量 KI 溶液中的产物

在酸性条件下，将 $\mathrm{KMnO}_{4}$ 滴加到过量 KI 溶液中，产物是什么？

已知元素电势图：

$$
E_{\mathrm{A}}^{\ominus} / \mathrm{V}: \quad \mathrm{H}_{5}\mathrm{IO}_{6} \xrightarrow{1.70} \mathrm{IO}_{3}^{-} \xrightarrow{1.14} \mathrm{HOI} \xrightarrow{1.45} \mathrm{I}_{3}^{-} \xrightarrow{0.54} \mathrm{I}^{-}
$$

$$
\mathrm{MnO}_{4}^{-} \xrightarrow{0.56} \mathrm{MnO}_{4}^{2-} \xrightarrow{2.26} \mathrm{MnO}_{2} \xrightarrow{0.95} \mathrm{Mn}^{3+} \xrightarrow{1.51} \mathrm{Mn}^{2+} \xrightarrow{-1.18} \mathrm{Mn}
$$

### 解答

从元素电势图可知：

1. $\mathrm{HIO}$、$\mathrm{MnO}_{4}^{2-}$、$\mathrm{Mn}^{3+}$ 能发生歧化反应，在酸性介质中不能稳定存在，不可能是反应产物。
2. 在酸性介质中，单质 Mn 能与 $\mathrm{H}^{+}$ 反应，不是反应产物。
3. 题中 KI 溶液过量，凡能与 $\mathrm{I}^{-}$ 发生反应的物质也不能是反应产物，则反应产物不能是 $\mathrm{IO}_{3}^{-}$、$\mathrm{H}_{5}\mathrm{IO}_{6}$ 和 $\mathrm{MnO}_{2}$：

$$
3\mathrm{H}_{5}\mathrm{IO}_{6} + \mathrm{I}^{-} = 4\mathrm{IO}_{3}^{-} + 3\mathrm{H}^{+} + 6\mathrm{H}_{2}\mathrm{O}
$$

$$
3\mathrm{MnO}_{2} + \mathrm{I}^{-} + 6\mathrm{H}^{+} = \mathrm{IO}_{3}^{-} + 3\mathrm{Mn}^{2+} + 3\mathrm{H}_{2}\mathrm{O}
$$

$$
\mathrm{IO}_{3}^{-} + 5\mathrm{I}^{-} + 6\mathrm{H}^{+} = 3\mathrm{I}_{2} + 3\mathrm{H}_{2}\mathrm{O}
$$

**结论**：反应产物只能是 $\mathrm{I}_{3}^{-}$ 和 $\mathrm{Mn}^{2+}$：

$$
2\mathrm{MnO}_{4}^{-} + 15\mathrm{I}^{-} + 16\mathrm{H}^{+} = 5\mathrm{I}_{3}^{-} + 2\mathrm{Mn}^{2+} + 8\mathrm{H}_{2}\mathrm{O}
$$

## 10.34 Fe³⁺与Hg反应求E°(Hg₂²⁺/Hg)

向酸性的 $1.0 \times 10^{-3} \; \mathrm{mol} \cdot \mathrm{dm}^{-3} \; \mathrm{Fe}^{3+}$ 溶液中加入过量液态汞，发生反应：$2\mathrm{Fe}^{3+} + 2\mathrm{Hg} = 2\mathrm{Fe}^{2+} + \mathrm{Hg}_{2}^{2+}$，达平衡时溶液中还有 $4.6\% \; \mathrm{Fe}^{3+}$。

已知 $E^{\ominus}(\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}) = 0.771 \; \mathrm{V}$，求 $E^{\ominus}(\mathrm{Hg}_{2}^{2+}/\mathrm{Hg})$。

### 解答

平衡时各离子的浓度为：

$$
c(\mathrm{Fe}^{3+}) = 1.0 \times 10^{-3} \times 4.6\% = 4.60 \times 10^{-5} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}
$$

$$
c(\mathrm{Fe}^{2+}) = 1.0 \times 10^{-3} - 4.6 \times 10^{-5} = 9.54 \times 10^{-4} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}
$$

$$
c(\mathrm{Hg}_{2}^{2+}) = \frac{1}{2} c(\mathrm{Fe}^{2+}) = 4.77 \times 10^{-4} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}
$$

平衡常数：

$$
K^{\ominus} = \frac{c(\mathrm{Hg}_{2}^{2+})[c(\mathrm{Fe}^{2+})]^{2}}{[c(\mathrm{Fe}^{3+})]^{2}} = \frac{4.77 \times 10^{-4} \times (9.54 \times 10^{-4})^{2}}{(4.6 \times 10^{-5})^{2}} = 0.205
$$

电池标准电动势：

$$
E^{\ominus} = \frac{0.059 \; \mathrm{V}}{2} \lg K^{\ominus} = \frac{0.059 \; \mathrm{V}}{2} \lg 0.205 = -0.020 \; \mathrm{V}
$$

由 $E^{\ominus} = E^{\ominus}(\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}) - E^{\ominus}(\mathrm{Hg}_{2}^{2+}/\mathrm{Hg})$ 得：

$$
E^{\ominus}(\mathrm{Hg}_{2}^{2+}/\mathrm{Hg}) = 0.771 \; \mathrm{V} - (-0.02 \; \mathrm{V}) = 0.79 \; \mathrm{V}
$$

## 10.35 Ag 在 KCN 溶液中的溶解

已知 $E^{\ominus}(\mathrm{Ag}^{+}/\mathrm{Ag}) = 0.80 \; \mathrm{V}$，$E^{\ominus}(\mathrm{O}_{2}/\mathrm{OH}^{-}) = 0.401 \; \mathrm{V}$，$E^{\ominus}(\mathrm{H}^{+}/\mathrm{H}_{2}) = 0$；$[\mathrm{Ag(CN)}_{2}]^{-}$ 的 $K_{\text{稳}}^{\ominus} = 1 \times 10^{21}$，$K_{\mathrm{a}}^{\ominus}(\mathrm{HCN}) = 1.0 \times 10^{-10}$。

(1) 在碱性条件下通入空气时，Ag 能否溶于 KCN 溶液？

(2) Ag 能否从 KCN 溶液中置换出 $\mathrm{H}_{2}$？

### 解答

**(1)** $[\mathrm{Ag(CN)}_{2}]^{-}/\mathrm{Ag}$ 的标准电极电势：

$$
E^{\ominus}([\mathrm{Ag(CN)}_{2}]^{-}/\mathrm{Ag}) = 0.80 \; \mathrm{V} + 0.059 \; \mathrm{V} \lg \frac{1}{1 \times 10^{21}} = -0.44 \; \mathrm{V}
$$

对反应 $4\mathrm{Ag} + \mathrm{O}_{2} + 8\mathrm{KCN} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{K}[\mathrm{Ag(CN)}_{2}] + 4\mathrm{KOH}$：

$$
E^{\ominus} = E^{\ominus}(\mathrm{O}_{2}/\mathrm{OH}^{-}) - E^{\ominus}([\mathrm{Ag(CN)}_{2}]^{-}/\mathrm{Ag}) = 0.401 \; \mathrm{V} - (-0.44 \; \mathrm{V}) = 0.84 \; \mathrm{V}
$$

$E^{\ominus} > 0$，说明在碱性条件下通入空气时，**Ag 能溶于 KCN 溶液**。

**(2)** 在 KCN 溶液中，$\mathrm{CN}^{-}$ 水解使溶液呈弱碱性，$c(\mathrm{H}^{+}) \approx 10^{-12} \; \mathrm{mol} \cdot \mathrm{dm}^{-3}$。

$$
E(\mathrm{H}_{2}\mathrm{O}/\mathrm{H}_{2}) = 0 \; \mathrm{V} + 0.059 \; \mathrm{V} \lg 10^{-12} = -0.71 \; \mathrm{V}
$$

$$
E = E(\mathrm{H}_{2}\mathrm{O}/\mathrm{H}_{2}) - E^{\ominus}([\mathrm{Ag(CN)}_{2}]^{-}/\mathrm{Ag}) = -0.71 \; \mathrm{V} - (-0.44 \; \mathrm{V}) = -0.27 \; \mathrm{V}
$$

$E < 0$，故 **Ag 不能从 KCN 溶液中置换出 $\mathrm{H}_{2}$**。

**9.**（2013年全国决赛）光合作用是自然界最重要的过程之一，其总反应一般表示为：

$$6 \mathrm{CO_2} + 6 \mathrm{H_2O} \longrightarrow \mathrm{C_6H_{12}O_6} + 6 \mathrm{O_2}$$

实际反应分多步进行。其中，水的氧化过程是一个重要环节，此过程在光系统Ⅱ（简称 PSⅡ）中发生，使水氧化的活性中心是含有 4 个 Mn 原子的配位簇（称为锰氧簇）。初始状态的锰氧簇（S0）在光照下依次失去电子变为 S1、S2、S3 和 S4，S4 氧化 H₂O 生成 O₂。该过程简示如下：

![[5567cac96870c09239f6bcaafa031bf995548b2922738432b5c3b2d9d352831f.jpg]]

(1) 光合作用中，水的氧化是几个电子转移的过程？

(2) 25 ℃，标态下，下列电极反应的电极电势分别为：

- ① $\mathrm{MnO_4^{3-} + 4H^+ + e^- = MnO_2 + 2H_2O}$，$E^{\theta}(\mathrm{MnO_4^{3-}/MnO_2}) = 2.90\ \mathrm{V}$

- ④ $\mathrm{Mn^{3+} + e^- = Mn^{2+}}$，$E^{\theta}(\mathrm{Mn^{3+}/Mn^{2+}}) = 1.51\ \mathrm{V}$

在 $[\mathrm{H_2P_2O_7^{2-}}] = 0.40\ \mathrm{mol/L}$、$[\mathrm{Mn(H_2P_2O_7)_3^{3-}}] = [\mathrm{Mn(H_2P_2O_7)_2^{2-}}]$ 的溶液中：

- ⑤ $\mathrm{Mn(H_2P_2O_7)_3^{3-} + 2H^+ + e^- = Mn(H_2P_2O_7)_2^{2-} + H_4P_2O_7}$，$E = 1.15\ \mathrm{V}$

计算⑤半反应的标准电极电势。（已知 $\mathrm{H_4P_2O_7}$ 的四级解离常数 $pK_{a1}=0.92$，$pK_{a2}=3.10$，$pK_{a3}=7.70$，$pK_{a4}=9.35$）

（注：本题法拉第常数 F 均取 96470 C/mol）

## 解答

**(1)** 4 个电子转移。

**(2)** 注意本题信息"中性条件"，计算时 $[\mathrm{H^+}]$ 用 $10^{-7}\ \mathrm{mol/L}$ 代入。由能斯特方程：

$$E(\mathrm{MnO_4^{3-}/MnO_2}) = 2.90 + \frac{8.314\times298}{96470}\ln(0.1\times10^{-28})\ \mathrm{V} = 1.19\ \mathrm{V}$$

$$E(\mathrm{MnO_2/Mn^{3+}}) = 0.95 + \frac{8.314\times298}{96470}\ln\!\left(\frac{10^{-28}}{0.1}\right)\mathrm{V} = -0.65\ \mathrm{V}$$

$$E(\mathrm{O_2/H_2O}) = 1.23 + \frac{8.314\times298}{4\times96470}\ln(0.21\times10^{-28})\ \mathrm{V} = 0.81\ \mathrm{V}$$

比较可知：该条件下 $E(\mathrm{MnO_4^{3-}/MnO_2}) = 1.19\ \mathrm{V} > E(\mathrm{O_2/H_2O}) = 0.81\ \mathrm{V}$，故 **$\mathrm{MnO_4^{3-}}$ 可以将 H₂O 氧化**；而 $E(\mathrm{MnO_2/Mn^{3+}}) = -0.65\ \mathrm{V} < 0.81\ \mathrm{V}$，故 **$\mathrm{MnO_2}$ 不能氧化 H₂O**。

**(3)** 由反应⑤可写出能斯特方程：

$$E = E^{\theta} + \frac{RT}{F}\ln\!\left(\frac{[\mathrm{H^+}]^2[\mathrm{Mn(H_2P_2O_7)_3^{3-}}]}{[\mathrm{H_4P_2O_7}][\mathrm{Mn(H_2P_2O_7)_2^{2-}}]}\right)$$

其中 $[\mathrm{Mn(H_2P_2O_7)_3^{3-}}] = [\mathrm{Mn(H_2P_2O_7)_2^{2-}}]$。由 $K_{a1}K_{a2} = \dfrac{[\mathrm{H^+}]^2[\mathrm{H_2P_2O_7^{2-}}]}{[\mathrm{H_4P_2O_7}]}$ 得 $\dfrac{[\mathrm{H_4P_2O_7}]}{[\mathrm{H^+}]^2} = \dfrac{[\mathrm{H_2P_2O_7^{2-}}]}{K_{a1}K_{a2}} = \dfrac{0.40}{10^{-0.92}\times10^{-3.10}} \approx 4.2\times10^{3}$，代入解得：

$$E^{\theta} = 1.15 + \frac{8.314\times298}{96470}\ln(4.2\times10^{3}) \approx 1.36\ \mathrm{V}$$

> 原书给出的 $E^{\theta}=1.31\ \mathrm{V}$ 系**漏计 $\mathrm{H_4P_2O_7}$ 的第一级解离**（只除了 $K_{a2}$，正确应除以 $K_{a1}K_{a2}$）。复算得 $E^{\theta}\approx1.36\ \mathrm{V}$，本页以订正值为准；稳定常数比部分不受影响。

$$1.15\ \mathrm{V} = 1.51\ \mathrm{V} + \frac{8.314\times298}{96470}\ln\!\left(\frac{K_{\text{稳}}^{\mathrm{III}}}{K_{\text{稳}}^{\mathrm{II}}\times0.40}\right)$$

解得：

$$\frac{K_{\text{稳}}^{\mathrm{III}}}{K_{\text{稳}}^{\mathrm{II}}} = 3.3\times10^{-7}$$

> KP：[[相律与相图]] ｜ 来源：教学改编（溶液与相图讲义 §相图）

(1) 用相律求**纯水三相点**的自由度，并说明为何三相点是固定的温度-压力组合。(2) 某 A-B 二元体系在 $T$ 温度下处于两相区：α 相含 B 20%，β 相含 B 70%，体系总含 B 50%（均为质量分数）。求两相质量比 $m_\alpha : m_\beta$。

<details>
<summary>📖 查看答案</summary>

**(1) 相律**：

$$F = C - P + 2 = 1 - 3 + 2 = 0$$

纯水 $C = 1$，三相（固-液-气）$P = 3$，自由度 $F = 0$——温度、压力均固定，故三相点是一个确定的点（0.01°C，0.612 kPa）。

**(2) 杠杆规则**：

$$m_\alpha(x_S - x_\alpha) = m_\beta(x_\beta - x_S)$$

代入 $x_S = 50,\ x_\alpha = 20,\ x_\beta = 70$：

$$m_\alpha\times 30 = m_\beta\times 20\ \Rightarrow\ m_\alpha : m_\beta = 20 : 30 = 2 : 3$$

**答案**：(1) $F = 0$，三相点固定；(2) $m_\alpha : m_\beta = 2:3$。

> **核心辨析**：杠杆规则本质是质量守恒——体系点在两相组成之间的位置决定两相数量（"离哪相近哪相多"）。两相区温度固定时组成不变，只改变两相比例。
