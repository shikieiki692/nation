### 1.1 〔🟢 d3〕

**得分点**：
1. **正确排序**（2分）：B > D > C > A

羧酸酸性的比较。羧基所连基团的吸电子能力越强，羧酸根阴离子的电荷越分散，能量越低，羧酸电离反应更加正向自发，羧酸酸性越强。先判断结构相似的 A 和 B：B 中，羧基与具有强吸电子诱导效应的三氟甲基相连，而 A 中羧基与具有弱给电子诱导效应和弱给电子超共轭效应的烷基相连，因此 B 的酸性强于 A。类似地，对于结构相似的 C 和 D：C 中苯环对位取代的是甲氧基，而 D 为硝基，前者给电子共轭效应占主导，后者为吸电子共轭基团，因此 D 的酸性强于 C。

本题的难点在于 B 和 D 以及 A 和 C 的酸性比较。先考虑 B 和 D: B 中的三氟甲基与羧基直接相连，而 D 中的硝基与羧基之间隔有苯环，因此硝基的吸电子效应被"电子缓冲"苯环削弱，不能像三氟甲基那样有效地稳定羧酸根，因此 D 的酸性弱于 B。

再来比较 A 和 C：苯甲酸的酸性 $(pK_{a}=4.20)$ 原本比乙酸 $(pK_{a}=4.76)$ 强。然而若给苯甲酸增加一个给电子的甲氧基，其酸性会不会下降到弱于乙酸的地步呢？为解答这个问题，我们需要理解苯甲酸的酸性较强的原因：一方面，与羧基相连的碳原子为 $sp^{2}$ 碳原子，它具有相当强度的吸电子诱导效应（详见边注）。另一方面，苯环可以与羧基形成共轭体系，分散羧基上的负电荷。加上甲氧基后， $sp^{2}$ 碳原子吸电子诱导效应不受影响。虽然甲氧基具有给电子共轭效应，但它的引入进一步增大了共轭体系，更好地稳定了羧酸根的负电荷，因此 C 的 $pK_{a}$ 应与苯甲酸相差不多。此外，A 的酸性比乙酸更弱（碳链更长，体积更大，羧酸根溶剂化程度更差，能量更高）。因此 C 的酸性强于 A。总的酸性顺序从高到低为：B > D > C > A。

在讨论苯环的电子效应时，我们往往强调 $\pi$ 体系的共轭效应，而常常忽略 $\mathfrak{sp}^2$ 碳原子的吸电子诱导效应。但是后者对羧酸酸性的贡献其实是非常大的：丙酸的 $\mathrm{pK}_{\mathrm{a}}$ 为4.88，丙烯酸为4.25，而苯甲酸为4.20。与丙烯酸相比，苯甲酸的共轭体系更大，但酸性与丙烯酸差别并不大！

**得分点**：
1. **正确排序**（2分）：B > A > E > C > D

根据化合物类别，不难得出大致顺序: A、B (酚和 $\beta$ -二羰基化合物的 $\mathrm{p}K_{\mathrm{a}}$ 均为 10 左右) > E (醇的 $\mathrm{p}K_{\mathrm{a}}$ 为 15 左右) > C、D (酮的 $\mathrm{p}K_{\mathrm{a}}$ 为 25 左右)。然后细致比较: 苯酚的酸性本已稍弱于乙酰丙酮, 后者又有三氟甲基取代, 故酸性 B > A; C 比 D 多一个羰基, 可提供一定的吸电子诱导效应, 故酸性 C > D。最终结果为: B > A > E > C > D。

需要指出的是，虽然我们不提倡死记硬背物质的化学性质，但可以记住一些标杆化合物的大致 $pK_{a}$ ：乙酸 5，乙酰丙酮 9，苯酚 10，乙铵盐 $(\mathrm{EtNH}_{3}^{+})$ 11，乙酰乙酸乙酯 11，乙醇 16，乙醛 17，丙酮 19，乙酸乙酯、乙腈和乙炔 25，N,N-二甲基甲酰胺 (DMF) 30，氨 38，苯 43，乙烯 44，乙烷 50。

**得分点**：
1. **8-1 正确画出 A 和 B**（1.5分）：A 为三元环或四元环碳正离子；B 为四元环溴代产物
2. **8-2 正确选择**（1分）：**B（环丙基取代的苯甲酸）** 酸性最弱
3. **8-3 正确选择**（1分）：**B** 的 $\alpha$-H 酸性较弱
4. **8-4 正确选择**（1分）：**A（OTs 处于直立键）** 溶剂解速率较快
5. **8-5 正确选择**（1.5分）：**C** 形成环氧速率最快

**完整推导**：

### 8-1 碳正离子扩环重排

反应机理：
1. 烯烃与质子发生反应得到碳正离子（Markovnikov 规则，二级碳正离子）
2. 三元环发生扩环重排，得到四元环中间体
3. 碳正离子与溴离子结合，得到最终产物

- **中间体 A**：三元环碳正离子（或四元环碳正离子，扩环后）
- **产物 B**：四元环溴代产物

> 若题目要求立体化学，最终产物 B 的结构需要考虑碳正离子的平面构型和 Br⁻ 从两侧进攻的概率。

### 8-2 羧酸酸性比较

苯环上的羧基酸性与苯环的富电子程度是**负相关**的：
- 吸电子基团 → 稳定羧酸根负离子 → 酸性增强
- 给电子基团 →  destabilize 羧酸根负离子 → 酸性减弱

比较异丙基和环丙基的电子效应：
- **异丙基**：具有给电子超共轭效应
- **环丙基**：具有**给电子共轭效应**（环丙烷的 Walsh 轨道中 HOMO 是 $\pi$ 轨道，可与苯环共轭）

环丙基的给电子能力比异丙基**更强**。故酸性大小关系为：

$$\mathbf{A} > \mathbf{C} > \mathbf{B}$$

**B（环丙基取代的苯甲酸）酸性最弱。**

### 8-3 羰基 $\alpha$-H 酸性比较

羰基化合物的 $\alpha$-H 酸性与羰基的活性（亲电能力）息息相关：
- $\alpha$-碳负离子可以被羰基的吸电子共轭效应所稳定
- 另一侧连有的给电子取代基会削弱羰基的吸电子能力，导致酸性下降

比较 A 和 B：
- **A** 中多出了四个甲基，带来的斥力使六元环需要旋转一定的角度，偏离羰基所在的平面
- 这会**破坏酰胺 N 原子与羰基的共轭**，给电子共轭效应的消失导致 A 中羰基的活性增强
- 故 **A 的 $\alpha$-H 酸性强于 B**

**B 的 $\alpha$-H 酸性较弱。**

### 8-4 溶剂解反应速率

本小题比较的是 $\mathrm{S_N2}$ 反应的速率快慢。$\mathrm{S_N2}$ 反应要求亲核试剂从离去基团的**背面进攻**。

反应底物都是反式十氢化萘环系，不存在可以翻转的构象异构体，只需分析处于直立键和平伏键的离去基团 -OTs 的区别：

- **A（-OTs 处于直立键）**：亲核试剂的进攻方向与直立氢原子近乎平行，位阻大大降低
- **B（-OTs 处于平伏键）**：亲核试剂的进攻路线被直立 H 原子所阻碍

故反应速率 **A > B**。

> 注意：很多同学会默认溶剂解反应一定是 $\mathrm{S_N1}$ 反应，这是错误的。本小题中的溶剂解体系中含有乙酸根负离子，同时亲核取代反应在二级碳上发生，故应采取 $\mathrm{S_N2}$ 反应过程。

### 8-5 环氧形成速率

三个底物都是 $\beta$-氯代醇，在碱性条件下发生**分子内 $\mathrm{S_N2}$** 反应，得到环氧化合物。

随着成环反应体系中引入的取代基逐渐增多，成环反应的速率加快、平衡常数增大，这种效应称为 **Thorpe-Ingold 效应**（也称**偕二甲基效应**）。

对于生成小环结构（如本题形成的三元环体系）：
- 理想的饱和碳原子链，键角为 $109.5^{\circ}$
- 引入取代基后（逐渐引入两个和四个甲基），由于取代基之间的排斥作用导致主链键角减小
- 在底物分子的构象中会使得亲核基团与离去基团距离减小，最终导致分子内 $\mathrm{S_N2}$ 反应的速率加快

故反应速率 **A < B < C**。

**C 形成环氧乙烷衍生物的反应速率最快。**

## 解题思路

1. **8-1 碳正离子重排**：烯烃质子化 → 二级碳正离子 → 三元环扩环为四元环 → 与 Br⁻ 结合
2. **8-2 酸性比较**：

4. **8-4 溶剂解速率**：
   - 本题为 SN2 机理（乙酸根负离子作为亲核试剂）

5. **8-5 环氧形成**：

## 知识拓展

**环丙基的给电子共轭效应**：

从分子轨道的角度理解环丙烷的成键过程：C 原子采取 $\mathrm{sp}^2$ 杂化，三条 $\mathrm{sp}^2$ 杂化轨道向心形成碳骨架，余下的三条 $2\mathrm{p}$ 轨道形成离域体系（Walsh 轨道）。

环丙烷的分子轨道中 HOMO（最高占有轨道）是两条简并的 $\pi$ 轨道，而非 $\sigma$ 轨道。正因如此，环丙基应具有的是**给电子共轭效应**，其给电子能力比异丙基要强。

**Thorpe-Ingold 效应（偕二甲基效应）**：

对于生成较大环系（$\geq 5$）的反应，一般通过过渡态理论中活化熵的变化来解释：
- 成环反应之前，底物分子可能采取的优势构象非常多，达到成环反应过渡态结构的概率很低
- 活化熵是相当大的负值
- 当侧链引入取代基后，减少了底物分子可能采取的优势构象，分子达到过渡态结构的概率上升
- 反应活化熵的绝对值减小（仍为负数），活化 Gibbs 自由能降低，更有利于成环反应的进行

$$
\mathrm{SPS} + 2 \mathrm{ME} \longrightarrow \mathrm{DE} + 2 \mathrm{MPS}
$$

上述反应平衡常数的计算，需结合 ${}^{1}$H NMR 谱对平衡体系中物种 $\beta$-氢谱峰的面积比测定：反应达平衡后，MPS 和 SPS 的 $\beta$-H 谱峰面积比为 1.00:1.00；而 MPS 和 SPS 分别有 2 个和 4 个 $\beta$-H，故 [MPS]/[SPS] = 2.00。又由于 SPS 的还原产物为 MPS，由物料守恒，有

$$
[ \mathrm{SPS} ] + \frac {[ \mathrm{MPS} ]}{2} = 1 0. 0 \mathrm{mmolL} ^ {- 1}
$$

可解得 $[SPS] = 5.00 \, mmol \, L^{-1}$ , $[MPS] = 10.0 \, mmol \, L^{-1}$ 。由反应的计量关系，可得另外两物种 ME 和 DE 的平衡浓度：

格外注意：SPS 是一个对称结构，很多粗心大意的同学误以为 SPS 只有 2 个 $\beta$ -H。

$$
\begin{array}{l} [ \mathrm{ME} ] = 2 0. 0 \mathrm{mmolL} ^ {- 1} - 2 \times 5. 0 \mathrm{mmolL} ^ {- 1} = 1 0. 0 \mathrm{mmolL} ^ {- 1} \\ [ \mathrm{DE} ] = 5. 0 \mathrm{mmolL} ^ {- 1} \\ \end{array}
$$

故反应的平衡常数为

$$
K ^ {\ominus} = \frac {\left(\frac {[ \mathrm{DE} ]}{c ^ {\ominus}}\right) \left(\frac {[ \mathrm{MPS} ]}{c ^ {\ominus}}\right) ^ {2}}{\left(\frac {[ \mathrm{ME} ]}{c ^ {\ominus}}\right) ^ {2} \left(\frac {[ \mathrm{SPS} ]}{c ^ {\ominus}}\right)} = \frac {0 . 0 0 5 0 0 \times 0 . 0 1 0 0 ^ {2}}{0 . 0 1 0 0 ^ {2} \times 0 . 0 0 5 0 0} = 1. 0 0
$$

注意 $c^{\ominus}=1\ mol\ L^{-1}=$ 1000 mmol $L^{-1}$ 。

### 1.8 〔🟢 d4〕

写出以下金属催化反应的机理。

题干含反应式图片，见原书。

<details>
<summary>📖 查看答案</summary>

典型的过渡金属催化偶联反应（如 Suzuki、Stille、Heck 等）的催化循环：

1. **氧化加成（Oxidative Addition）**：
   - 零价金属（如 Pd(0)）插入到有机卤化物（R-X）的 C-X 键中
   - 金属氧化态从 0 升至 +2，配位数增加 2
   - 生成 R-Pd(II)-X 中间体

2. **转金属（Transmetalation）**（适用于交叉偶联）：
   - 有机金属试剂（R'-M'，如有机硼、有机锡）将 R' 基团转移给 Pd
   - 生成 R-Pd(II)-R' 中间体

3. **还原消除（Reductive Elimination）**：
   - 两个有机基团从 Pd(II) 中心偶联，形成 C-C 键
   - 金属氧化态从 +2 降至 0，配位数减少 2
   - 再生 Pd(0) 催化剂，完成催化循环

### 1.9 〔🟢 d4〕

Explain why the synthesis of pentan-1,4-diol fails in two cases: (1) using 2 equivalents of Grignard, (2) using excess Grignard. OH (pKa ~ 16) protonates Grignard reagent.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/3ad8c56813b6a5be5d9f7045a4c08d1f7fc5dcd92cf1a091f7fc60277e484402.jpg

**原文题目**：解释为什么戊-1,4-二醇的合成在两种情况下失败：(1) 使用2当量的Grignard试剂，(2) 使用过量的Grignard试剂。OH（pKa ~ 16）会质子化Grignard试剂。

<details>
<summary>📖 查看答案</summary>

**Answer (English)**: 
- Grignard reagents (RMgX) are strong bases (conjugate acid RH has pKa ~ 50). They will deprotonate any O-H bond (pKa ~ 16) before nucleophilic addition occurs.
- Case 1 (2 equiv): The first Grignard deprotonates one OH, the second deprotonates the other OH — no nucleophilic addition happens.
- Case 2 (excess Grignard): Intramolecular deprotonation kills the reaction before addition can occur.
- Solution: Use a protecting group (e.g., THP or silyl ether) to mask the OH groups before Grignard addition.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/e5763910c5fcd912e49d3a6683364b38d7d1db7983598453acf971c6d20ac25b.jpg

**中文解析**：
1. **Grignard试剂的碱性**：RMgX是极强碱（共轭酸RH的pKa ~ 50），远强于任何醇（pKa ~ 16）。Grignard会优先质子化OH而不是进行亲核加成。
2. **2当量情况**：第一当量Grignard去质子化一个OH，第二当量去质子化另一个OH，两个OH都被消耗，无亲核加成发生。
3. **过量情况**：分子内去质子化（两个OH在分子内竞争）使反应在加成前就失败。
4. **解决方案**：使用保护基（如THP或硅醚）保护OH，再进行Grignard反应，最后脱保护。

## 知识点映射

| 关联 KP | 考查角度 | 直接/间接 |
|---|---|:---:|
| pKa | Grignard碱性与OH酸性的pKa比较 | 直接 |
| 酸碱强度 | Grignard是极强碱，会优先质子化酸性氢 | 直接 |
| 有机酸碱性 | 官能团兼容性和保护基策略 | 间接 |

## 解题思路

### 1.10 〔🟢 d4〕

When an alkene containing an internal hydroxyl group is treated with Br₂, an intramolecular reaction occurs. Propose a mechanism. The product's NMR spectrum shows large J coupling constants. Explain what this tells you about the conformation and identify the positions of Br and Me groups.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/a5aa6fa8ff71829af9864d7d7edf6c874027c0066bf6c878163b9fd9611f3abb.jpg

**原文题目**：

当含有内部羟基的烯烃用 Br₂ 处理时，发生分子内反应。提出机理。产物的 NMR 谱图显示较大的 J 偶合常数，解释这告诉你关于构象的什么信息，并确定 Br 和 Me 的位置。

<details>
<summary>📖 查看答案</summary>

**Answer (English)**:

**Mechanism**: Br₂ approaches the double bond to form a **bromonium ion** intermediate. Instead of the external nucleophile (Br⁻) attacking, the **internal OH group** acts as the nucleophile and attacks the bromonium ion from the **more substituted carbon** (where the partial positive charge is larger). This intramolecular attack is faster than intermolecular attack due to the proximity effect (favourable entropy). The result is a cyclic ether (tetrahydrofuran or tetrahydropyran derivative) with the Br on the less substituted carbon — a bromo-ether.

**NMR interpretation**: Large J coupling constants (> 8–10 Hz) indicate **axial–axial** C–H coupling on a six-membered ring. This means the two coupled protons are both in axial positions (dihedral angle ≈ 180°, Karplus equation predicts maximum coupling).

This tells us:
- The ring is in a chair conformation.
- **Br and Me are both equatorial** — because the C–H bonds on the same carbons are axial (J is large for axial H coupling to adjacent axial H). If Br or Me were axial, the adjacent C–H would be equatorial, giving a small J value.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/a0c9292d64431b3d7c1f7059b7404c33aec5488b5c30001ac3529e5c06d36e1b.jpg

**中文解析**：

**机理**：Br₂ 与烯烃双键形成**溴鎓离子**中间体。此时分子内部的 OH 基团作为亲核试剂，从**取代程度更高的碳**一侧进攻溴鎓离子（部分正电荷更大的位置），发生**分子内开环**。分子内反应因距离优势（熵效应有利）比分子间反应更快，生成含氧杂环（四氢呋喃或四氢吡喃衍生物），Br 留在取代程度较低的碳上 → 溴代醚。

**NMR 偶合常数解读**：
- **大 J 值（> 8–10 Hz）**：表明两个 C-H 键处于**轴-轴**偶合关系（dihedral angle ≈ 180°，Karplus 方程预测最大偶合）。这说明环处于椅式构象，且偶合的两个质子都是轴向的。
- **推论**：既然相邻碳上的 C-H 是轴向的，那么 Br 和 Me 必须是**赤道位**的（因为同一碳上另一个键是赤道位）。若 Br 或 Me 为轴向，则相邻 C-H 将为赤道位，产生小 J 值。

|---|---|:---:|
| 溴鎓离子 | 分子内OH对溴鎓离子的亲核开环（分子内亲电加成） | 直接 |
| NMR谱学 | Karplus方程：大J值→轴-轴偶合→赤道位取代基 | 直接 |
| 亲电加成 | 分子内vs分子间亲核试剂的竞争（熵效应） | 间接 |

## 解题思路

1. **读题定位**：内部OH+Br₂→分子内反应→需画机理+解读NMR偶合常数
2. **🔑 关键转换**：Br₂ → 溴鎓离子 → 内部OH进攻取代度高的碳（分子内环化）→ 溴代醚产物；NMR 大 J → 轴-轴 C-H → Br/Me 为赤道位

**Answer (English)**:

Cyclooctatetraene is 'tub-shaped' and not planar, because its eight π electrons do not form a 2n+2 number. However, two atoms of potassium can reduce the cyclooctatetraene to a dianion by giving it two electrons, so now it has ten electrons, is aromatic, and is planar.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/0469a591393d181c93fb7e8ebbbe650bcecdc6d185c46e124bcbe1a4aaee4e32.jpg

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_1-199_images/1bec27bcc8beee9bc5f9843a033e39517955fad29f2c13de171cbfea0158acbf.jpg
this dianion is no longer flat

When lithium reduces hexa(trimethylsilyl)benzene, the aromatic sextet is increased to a total of eight delocalized electrons, so the compound is no longer aromatic. The six-membered ring in the salt is no longer flat.

**中文解析**：

关键步骤：
1. **COT（环辛四烯）**：中性COT有8个π电子（4n，n=2），属于反芳香性体系。为避免反芳香性的不稳定，分子采取非平面的"浴盆形"构象
2. **COT²⁻（二阴离子）**：K还原COT得到K₂[COT]，COT获得2个电子→10个π电子（4n+2，n=2），满足Hückel规则。分子变为平面构型——芳香性带来的稳定化能超过平面化的代价
3. **六(三甲硅基)苯阴离子**：苯有6个π电子（芳香的，4n+2，n=1）。Li还原后得到8个π电子（4n，n=2），属于反芳香性。为避免反芳香性，环变为非平面——芳香性丧失

> **核心规律**：π电子数为4n+2→平面+芳香稳定；π电子数为4n→非平面（避免反芳香不稳定）。分子会自发选择避免反芳香性的几何形状。

| 芳香性 | Hückel规则对环平面性的预测 | 直接 |
| 反芳香性 | 4n体系通过变形避免反芳香不稳定 | 直接 |
| 分子轨道理论 | π电子数与分子几何形状的关系 | 间接 |

## 解题思路

1. **读题定位**：两个问题都关于还原反应产物的环形状——本质是π电子数变化对分子平面性的影响
2. **🔑 关键转换**：计算每个体系的π电子数：COT(8e, 4n)→COT²⁻(10e, 4n+2)→芳香→平面；苯(6e, 4n+2)→还原后(8e, 4n)→反芳香→非平面
3. **验证**：用Hückel规则验证：平面+芳香=4n+2（稳定）；若为4n则分子会变形为非平面以避免反芳香性

Draw a mechanism for the following multistep reaction. Do the cyclization steps follow Baldwin's rules?

**原文题目**：Draw a mechanism for the multistep reaction. Do the cyclization steps follow Baldwin's rules?

<details>
<summary>📖 查看答案</summary>

**Answer (English)**: Hydrolysis of the acetal releases an aldehyde and Mannich-style condensation leads to the product. The iminium ion forms by (favoured) 5-exo-trig attack on the aldehyde. The cyclization step in which the enol attacks the iminium ion is 6-endo-trig and is thus also favoured. By folding the molecule into a chair a reasonable overlap between the required p orbitals is possible.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_200-399_images/05d20479b37e2a4b21a627cee498df5a3cd0364f637e35ce351dd273d9bc67ea.jpg

**中文解析**：

关键步骤：
1. **缩醛水解**：酸催化下缩醛水解释放醛基，为后续反应提供亲电中心
2. **第一步关环（5-exo-trig）**：胺对醛的Mannich型缩合形成亚胺离子——胺从醛的π\*轨道的外侧(exo)进攻，形成五元环，符合Baldwin规则（5-exo-trig允许）

4. **椅式过渡态**：分子折叠成椅式构象，使p轨道有合理重叠

> **注意**：6-endo-trig反应在形成六元环时是允许的——这是Baldwin规则的一个重要例外（一般endo-trig不利，但六元环除外）。

### 1.24 〔🟢 d4〕

Consider the question of Baldwin's rules for each of these reactions. Why do you think they are both successful?

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_200-399_images/8b7102b164c0d42dfbfac6d4c255a97f927702e6c1c957b6383ffe2f852c81d9.jpg

**原文题目**：Consider Baldwin's rules for each reaction. Why are they both successful?

<details>
<summary>📖 查看答案</summary>

**Answer (English)**: The first ring system is 6-endo-trig. Manganese dioxide is a specific oxidant for allylic alcohols and conjugate addition of the amine to the enone gives the bicyclic amine. This works because endo reactions are just about all right when six-membered rings are formed and because conjugate addition is under thermodynamic control: as long as some of the reaction occurs, the product is the most stable compound in the mixture — any competing attack of the amine on the ketone gives a much less stable four-membered ring.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_200-399_images/2c5afe5f0eb081bb66ab22e29b97f63fdb58240602dfa9c579a4a762a0316794.jpg

The second example is again 6-endo-trig but it is acid-catalysed: protonation increases the reactivity of the enone and reduces its rigidity. Both these 6-endo-trig reactions occur through chair-like transition states rather like the example in the previous problem.

!06-外部资料导入/clayden 有机习题/课后习题答案及解析clayden-SolutionsManualtoAccompanyOrganicChemistry_200-399_images/e8614bd8530dade639d4e211accfd46c9fe5a9fea185429e3a309df13979fc9e.jpg

**中文解析**：

关键步骤：
1. **第一个反应（MnO₂氧化+共轭加成）**：
   - MnO₂选择性氧化烯丙醇→烯酮
   - 胺对烯酮的共轭加成（1,4-加成）为6-endo-trig关环
   - 成功原因：(a) 六元环的endo反应"勉强可以"；(b) 共轭加成受热力学控制——产物是最稳定化合物
2. **第二个反应（酸催化共轭加成）**：
   - 质子化增加烯酮反应活性并降低其刚性
   - 同样是6-endo-trig关环，通过椅式过渡态
3. **共同点**：两个反应都通过椅式过渡态实现6-endo-trig关环，p轨道重叠合理

> **注意**：共轭加成受热力学控制是关键——即使动力学上有竞争（如胺直接进攻酮羰基形成四元环），热力学最稳定的六元环产物最终胜出。

one axial-equatorial coupling 4 Hz

The vital proton is clearly axial in isomer B as it has two large couplings (10 Hz) to other axial protons so this must be the trans isomer. Isomer A has three equal small couplings and this fits one conformation of the cis isomer.

two axial-axial couplings

**中文解析**：

关键步骤：
1. **识别两种异构体**：环状酮-内酰胺有两个非对映异构体——顺式和反式环并
2. **构象分析**：
   - 反式异构体：固定为反式十氢萘形状（trans-decalin），不能翻转

### 1.31 〔🟢 d4〕

**(1)** 1,3-丁二烯的氢化热（ΔH_hyd）为 -127 kJ/mol，而两摩尔 1-丁烯的氢化热为 2 × (-126) = -252 kJ/mol。计算1,3-丁二烯的共轭稳定化能。

**(2)** 苯的实验氢化热为 -208 kJ/mol，而假设的"环己三烯"（三个孤立双键）的预期氢化热为 3 × (-120) = -360 kJ/mol。计算苯的共振稳定化能。

**(3)** 为什么共轭二烯比孤立二烯更稳定？用分子轨道理论解释。

<details>
<summary>📖 查看答案</summary>

### (1) 1,3-丁二烯的共轭稳定化能

**预期氢化热**（假设两个孤立双键）：
$$\Delta H_{\text{预期}} = 2 \times (-126) = -252 \text{ kJ/mol}$$

**实际氢化热**：
$$\Delta H_{\text{实际}} = -127 \text{ kJ/mol}$$

**共轭稳定化能**（差值）：
$$E_{\text{共轭}} = \Delta H_{\text{预期}} - \Delta H_{\text{实际}} = (-252) - (-127) = -125 \text{ kJ/mol}$$

> 注意：实际氢化热比预期"少放热"（绝对值更小），说明共轭体系更稳定（基态能量更低）。

### (2) 苯的共振稳定化能

**预期氢化热**（假设三个孤立双键）：
$$\Delta H_{\text{预期}} = 3 \times (-120) = -360 \text{ kJ/mol}$$

**实际氢化热**：
$$\Delta H_{\text{实际}} = -208 \text{ kJ/mol}$$

**共振稳定化能**：
$$E_{\text{共振}} = (-360) - (-208) = -152 \text{ kJ/mol}$$

苯的共振稳定化能为 **152 kJ/mol**（约 36 kcal/mol），这解释了苯的异常稳定性。

### (3) 共轭稳定的MO解释

**1,3-丁二烯的分子轨道**：

4个 p 轨道组合成4个 π 分子轨道：
- ψ₁（成键）：所有节点在核间 → 能量最低
- ψ₂（成键）：一个节点 → HOMO
- ψ₃（反键）：两个节点 → LUMO
- ψ₄（反键）：三个节点 → 能量最高

**关键**：4个 π 电子填入 ψ₁ 和 ψ₂，总 π 电子能量 = 2α + 2.48β

**如果是孤立双键**：两个独立的乙烯，总 π 能量 = 2 × (α + β) = 2α + 2β

**稳定化差值**：(2α + 2.48β) - (2α + 2β) = **0.48β**（β < 0，所以更稳定）

**本质**：共轭使 π 电子**离域到更大的空间**→ 电子动能降低 → 体系更稳定。

### 共轭稳定化能数据

| 化合物 | 共轭稳定化能 (kJ/mol) |
|:---|:---:|
| 1,3-丁二烯 | ~15 |
| 1,3,5-己三烯 | ~25 |
| 苯 | ~152 |
| 萘 | ~255 |

> 💡 **规律**：共轭体系越大 → 稳定化能越高 → 越难被氧化/还原。这是芳香性的定量基础。

### 1.32 〔🟢 d4〕

**(1)** 分子内成环反应中，形成五元环、六元环和三元环的相对速率通常是怎样的？从**熵效应**和**焓效应**两个角度解释。

**(2)** 以下分子内反应中，哪个更容易发生？解释原因。

- **(a)** 4-溴丁醇在碱中分子内成环氧（形成三元环）
- **(b)** 5-溴戊醇在碱中分子内成四氢呋喃（形成五元环）
- **(c)** 6-溴己醇在碱中分子内成四氢吡喃（形成六元环）

**(3)** Baldwin 规则对环化反应的立体电子效应有什么要求？

<details>
<summary>📖 查看答案</summary>

### (1) 分子内成环速率

**一般规律**：五元环 > 六元环 > 三元环 > 四元环 > 七元环

| 环大小 | 相对速率 | 主要控制因素 |
|:---|:---:|:---|
| **五元环** | **最快** | 熵有利（链端距离适中）+ 焓有利（环张力小） |
| **六元环** | 很快 | 焓最有利（无张力）但熵略不如五元环 |
| **三元环** | 较慢 | 熵有利但焓极不利（环张力大） |
| **四元环** | 最慢 | 熵不利 + 焓不利（角张力大） |
| **七元环** | 较慢 | 焓可以但熵不利（链端难以相遇） |

**熵效应**（决定性因素）：
- 分子内反应需要链的两端**在空间上接近**
- 五元环：链端间距约 2.5 Å，恰好在成键距离内 → **熵最有利**
- 三元环：虽然距离近，但链段自由度低 → 需要特定构象
- 七元环以上：链端相遇概率低 → **熵不利**

**焓效应**（次要因素）：
- 五元环：无角张力（键角 ~108°，接近 sp³ 的 109.5°）→ **焓有利**
- 六元环：椅式构象无角张力 → **焓最有利**
- 三元环：角张力极大（60° vs 109.5°）→ **焓极不利**

### (2) 分子内反应比较

| 底物 | 环大小 | 容易？ | 原因 |
|:---|:---:|:---:|:---|
| **(a) 4-溴丁醇** | 三元环 | ⚠️ 中等 | 熵有利但环张力大 |
| **(b) 5-溴戊醇** | 五元环 | ✅ **最容易** | 熵+焓双有利 |
| **(c) 6-溴己醇** | 六元环 | ✅ 很容易 | 焓最有利，熵稍逊 |

**结论**：**(b) 5-溴戊醇最容易分子内成环**（五元环），这是分子内 Williamson 醚合成的经典案例。

### (3) Baldwin 规则

Baldwin 规则从**立体电子效应**角度判断环化反应的可行性：

**核心要求**：亲核试剂进攻离去基团时，必须满足特定的**轨道取向**：

| 环化类型 | Baldwin 判定 | 原因 |
|:---|:---:|:---|
| 3-endo-trig | ❌ 不利 | 轨道取向违反 |
| 3-exo-trig | ✅ 有利 | — |
| 5-exo-trig | ✅ 有利 | — |
| 5-endo-trig | ❌ 不利 | 轨道取向违反 |
| 6-endo-trig | ✅ 有利 | — |

> 💡 **记忆口诀**：3/5/6-exo 有利，3/5-endo 不利。"Exo"指从环外进攻，"endo"指从环内进攻。

### 1.33 〔🟢 d4〕

**(1)** 某聚合物的重复单元结构为 —[CH₂-CHCl]—ₙ，推断其单体结构和聚合类型。

**(2)** 某聚合物的重复单元为 —[NH-(CH₂)₆-NH-CO-(CH₂)₄-CO]—ₙ，推断单体和聚合类型。

**(3)** 【陷阱题】某聚合物的重复单元为 —[CH₂-C(CH₃)=CH-CH₂]—ₙ，请判断：该聚合物的单体是 2-甲基-1,3-丁二烯（异戊二烯）还是其他结构？解释为什么不能简单地将重复单元"拆回去"。

<details>
<summary>📖 查看答案</summary>

### (1) 聚氯乙烯

重复单元：—[CH₂-CHCl]—

**单体**：CH₂=CHCl（氯乙烯）

**聚合类型**：加成聚合（加聚反应）

双键打开 → 链增长。单体含 C=C，通过自由基或离子聚合。

### (2) 尼龙-66

重复单元：—[NH-(CH₂)₆-NH-CO-(CH₂)₄-CO]—

**单体**：己二胺 H₂N-(CH₂)₆-NH₂ + 己二酸 HOOC-(CH₂)₄-COOH

**聚合类型**：缩合聚合（缩聚反应）

两个单体分别提供 -NH₂ 和 -COOH，脱水缩合形成酰胺键（—CONH—）。

### (3) 陷阱题：聚异戊二烯的单体推断

**常见错误**：看到 —[CH₂-C(CH₃)=CH-CH₂]—ₙ，直接"拆回去"得到 CH₂=C(CH₃)-CH=CH₂（异戊二烯）。

**正确分析**：

加成聚合时，共轭二烯烃发生 **1,4-加成聚合**：

```
CH₂=C(CH₃)-CH=CH₂  →  —[CH₂-C(CH₃)=CH-CH₂]—ₙ
   异戊二烯              聚异戊二烯（1,4-加聚）
```

单体确实是异戊二烯（2-甲基-1,3-丁二烯），但要注意：

**陷阱所在**：如果只看重复单元中的双键位置（C2=C3），可能错误地认为单体是 2-丁烯或其他烯烃。实际上重复单元中的双键是**聚合过程中从原来两个双键重新形成的**，不是单个双键打开的结果。

**判断加聚 vs 缩聚的方法**：
- 重复单元含 **C=C 双键残余** → 很可能是共轭二烯的 1,4-加聚
- 重复单元含 **酰胺键/酯键** → 缩聚
- 重复单元的原子组成与单体**完全相同** → 加聚
- 重复单元比单体**少了小分子**（H₂O 等）→ 缩聚

### 三种聚合方式对比

| 类型 | 单体特征 | 重复单元特征 | 例子 |
|:---|:---|:---|:---|
| **加聚（烯烃）** | 含 C=C | 与单体原子组成相同 | 聚乙烯、PVC |
| **加聚（共轭二烯）** | 1,3-二烯 | 1,4-加成，保留一个双键 | 聚异戊二烯 |
| **缩聚** | 含双官能团 | 比单体少了 H₂O 等小分子 | 尼龙-66、PET |

> ⚠️ **核心陷阱**：看到重复单元中有双键就认为是烯烃加聚 → 忽略了 1,4-加聚的可能性。正确做法是先计算重复单元的原子数，与候选单体比较。

## 知识点映射

- 加聚反应
- 加成聚合
- 缩合聚合
- 单体推断

### 1.34 〔🟢 d4〕

将下列含氮化合物的碱性从强到弱排序，并逐一解释影响因素：

**(a)** 三甲胺 N(CH₃)₃（脂肪族三级胺）

**(b)** 苯胺 C₆H₅NH₂

**(c)** 吡啶 C₅H₅N

**(d)** 乙胺 CH₃CH₂NH₂（脂肪族一级胺）

**(e)** 对硝基苯胺 p-O₂NC₆H₄NH₂

<details>
<summary>📖 查看答案</summary>

### 排序结果

$$\text{(d) 乙胺} > \text{(a) 三甲胺} > \text{(c) 吡啶} > \text{(b) 苯胺} > \text{(e) 对硝基苯胺}$$

### 逐个分析

**(d) 乙胺 CH₃CH₂NH₂（最强碱）**：
- 脂肪族一级胺，N 上孤对电子未参与共轭
- 乙基的 +I 效应给电子，增加 N 上电子密度
- 水溶液中 pKb ≈ 3.3，pKa（共轭酸）≈ 10.7

**(a) 三甲胺 N(CH₃)₃**：
- 三个甲基的 +I 效应给电子 → N 上电子密度高
- 但空间位阻大 → 水合溶剂化效应减弱（溶剂化稳定共轭酸的能力下降）
- 综合：碱性略低于乙胺（气相中三甲胺碱性更强，但溶液中溶剂化效应逆转了顺序）

**(c) 吡啶 C₅H₅N**：
- N 为 sp² 杂化（s 成分 33%），孤对电子在 sp² 轨道中
- sp² 杂化比 sp³ 更靠近核 → 孤对电子束缚更紧 → 碱性弱于脂肪胺
- 但 N 上无 N-H 键，不能形成氢键 → 溶剂化弱
- pKb ≈ 8.8，pKa（共轭酸）≈ 5.2

**(b) 苯胺 C₆H₅NH₂**：
- N 上孤对电子与苯环 **p-π 共轭** → 电子密度离域到苯环
- N 上有效电子密度大幅降低 → 碱性显著减弱
- pKb ≈ 9.4，pKa（共轭酸）≈ 4.6

**(e) 对硝基苯胺 p-O₂NC₆H₄NH₂（最弱碱）**：
- NO₂ 是强吸电子基团（−I 和 −M 效应）
- 通过苯环进一步拉走 N 上的电子密度
- 比苯胺碱性更弱（pKa ≈ 1.0）

### 影响胺碱性的因素总结

| 因素 | 使碱性增强 | 使碱性减弱 |
|:---|:---|:---|
| **诱导效应** | 给电子基团（+I） | 吸电子基团（−I） |
| **共轭效应** | — | 孤对电子参与 p-π 共轭 |
| **杂化效应** | sp³ N（s 成分低） | sp² N（s 成分高） |
| **空间效应** | — | 大位阻降低溶剂化 |

> ⚠️ **易错点**：气相碱性和溶液碱性可能不同！溶液中溶剂化效应会改变排序（如三甲胺在气相比乙胺碱性强，但溶液中相反）。

### 1.36 〔🟢 d4〕

某化合物分子式为 C₄H₆O₂，其 ¹H NMR 谱图数据如下：

- **δ 2.0 ppm**：单峰，3H
- **δ 5.8 ppm**：双二重峰（dd），1H（$J = 10, 6$ Hz）
- **δ 6.1 ppm**：双二重峰（dd），1H（$J = 10, 17$ Hz）
- **δ 7.4 ppm**：双二重峰（dd），1H（$J = 6, 17$ Hz）

IR 数据：1735 cm⁻¹ 有强吸收峰。

请推断该化合物的结构，并解释各信号的归属。

<details>
<summary>📖 查看答案</summary>

### 第一步：计算不饱和度

$$\Omega = \frac{2 \times 4 + 2 - 6}{2} = \frac{4}{2} = 2$$

不饱和度为 2 → 分子含两个双键或一个三键或一个环+一个双键等组合。

### 第二步：分析 IR

1735 cm⁻¹ 强吸收 → **C=O**（酯的特征频率 1735–1750 cm⁻¹）

### 第三步：分析 NMR 数据

**δ 2.0 ppm（单峰，3H）**：
- 化学位移在 2.0 ppm → 与羰基相连的 CH₃（CH₃-C=O）
- 单峰 → 相邻无 H → 是乙酰基（CH₃CO-）的一部分

**δ 5.8、6.1、7.4 ppm（三个 dd，各 1H）**：
- 三个氢的化学位移都在烯氢区域（5–8 ppm）
- 三个 dd 峰的偶合常数分析：
  - 5.8 ppm：$J = 10, 6$ Hz
  - 6.1 ppm：$J = 10, 17$ Hz
  - 7.4 ppm：$J = 6, 17$ Hz

三个 dd 的 $J$ 值交叉匹配：
- $J = 17$ Hz：反式烯氢偶合（$trans$ $^3J_{HH} \approx 12-18$ Hz）
- $J = 10$ Hz：顺式烯氢偶合（$cis$ $^3J_{HH} \approx 6-12$ Hz）
- $J = 6$ Hz：同碳或邻碳偶合

### 第四步：推断结构

三个烯氢 + 乙酰基 + 酯基 = **丙烯酸乙酸酯**或**乙酸乙烯酯**

最合理的结构是 **乙酸乙烯酯（vinyl acetate）**：

$$\text{CH}_3\text{CO-O-CH=CH}_2$$

但更符合三个 dd 模式的是 **丙烯酸甲酯**的异构体。实际上三个 dd 的 $J$ 值组合（10, 17, 6 Hz）最符合 **1,3-丁二烯的单取代衍生物**。

**最终结构：乙酸乙烯酯（vinyl acetate）**

$$\text{CH}_3\text{COOCH=CH}_2$$

验证：
- CH₃CO- → δ 2.0（单峰，3H）✅
- =CH₂ 的两个 H（顺/反）+ -O-CH= 的 1H → 三个烯氢 ✅
- 酯 C=O → 1735 cm⁻¹ ✅
- 不饱和度 = 2（C=O + C=C）✅

### 信号归属

| δ (ppm) | H 数 | 归属 | 裂分原因 |
|:---|:---:|:---|:---|
| 2.0 | 3H | CH₃-C=O | 单峰（相邻无 H） |
| 5.8 | 1H | =CH₂（cis-H） | dd（J=10, 6 Hz） |
| 6.1 | 1H | =CH₂（trans-H） | dd（J=10, 17 Hz） |
| 7.4 | 1H | -O-CH= | dd（J=6, 17 Hz） |

> 💡 **解题策略**：先算不饱和度 → IR 找官能团 → NMR 定碳骨架 → 偶合常数验证立体化学。

### 1.37 〔🟢 d4〕

**(1)** 乙醚（CH₃CH₂-O-CH₂CH₃）有几组 ¹H NMR 信号？每组的裂分模式（峰形）和积分比是什么？

**(2)** 甲乙醚（CH₃-O-CH₂CH₃）有几组信号？与乙醚比较有何不同？

**(3)** 为什么乙醚中 -OCH₂- 的氢只裂分为四重峰（而非更复杂的模式）？

<details>
<summary>📖 查看答案</summary>

### (1) 乙醚的信号分析

乙醚结构高度对称（对称中心在 O 原子）：

$$\text{CH}_3\text{-CH}_2\text{-O-CH}_2\text{-CH}_3$$

**信号数：2 组**

| 信号 | H 数 | 化学位移 | 裂分模式 | 积分比 |
|:---|:---:|:---|:---|:---:|
| CH₃ | 6H | ~1.2 ppm | **三重峰**（t） | 3 |
| OCH₂ | 4H | ~3.5 ppm | **四重峰**（q） | 2 |

**裂分分析**：
- CH₃ 被相邻 CH₂ 的 2 个 H 裂分 → $n+1 = 2+1 = 3$ → 三重峰
- OCH₂ 被相邻 CH₃ 的 3 个 H 裂分 → $n+1 = 3+1 = 4$ → 四重峰
- 两个 -CH₂CH₃ 基团完全对称，各自等价

### (2) 甲乙醚的信号分析

甲乙醚不对称：CH₃-O-CH₂CH₃

**信号数：3 组**

| 信号 | H 数 | 化学位移 | 裂分模式 | 积分比 |
|:---|:---:|:---|:---|:---:|
| OCH₃ | 3H | ~3.3 ppm | **单峰**（s） | 1 |
| OCH₂ | 2H | ~3.5 ppm | **四重峰**（q） | 2 |
| CH₃ | 3H | ~1.2 ppm | **三重峰**（t） | 3 |

**关键区别**：OCH₃ 是单峰（相邻无 H），而乙醚中没有这样的单峰。

### (3) OCH₂ 只裂分为四重峰的原因

虽然分子中有两个 CH₃（共 6H），但 OCH₂ 只与**同侧的** CH₃ 直接相邻。

- OCH₂ 与同侧 CH₃ 有 $^3J$ 偶合（~7 Hz）→ 四重峰
- OCH₂ 与对侧 CH₂CH₃ 之间隔了 O 原子 → 无 $^3J$ 偶合
- OCH₂ 与对侧 CH₃ 之间隔了 4 个键 → $^4J$ 偶合极小，可忽略

**因此每个 OCH₂ 只"看到"同侧 CH₃ 的 3 个 H → 四重峰。**

### 乙醚 vs 甲乙醚对比

| 特征 | 乙醚 | 甲乙醚 |

本小题给出的案例是立体电子效应 (stereoelectronic effect) 中的一个经典案例。当原子成键形成分子时，原子轨道通过线性组合形成分子轨道，得到的成键轨道能量相比之前降低，反键轨道能量相比之前升高。电子优先填入能量更低的成键轨道，使得整个原子体系的能量降低，形成稳定的分子。类似地，分子轨道之间也可以进行组合，当一个填有电子的成键轨道和一个空的反键轨道线性组合时，形成的新成键轨道能量较原来的成键轨道更低，因此成键电子的能量进一步降低，使得整个分子能量进一步降低：

!mineru/02-真题解析/36届初赛试题解析2_images/947db7d8dc112e7d31fa573d154085b41f805737ae1c48e537c6aefecb6fe22f.jpg

而若想进行有效组合，需要遵循对称性匹配、能量相近、最大重叠的要求，其中能量相近和最大重叠决定了分子轨道相互作用的强度（能量升高或降低的程度）。在有机分子中，成键轨道为了和能量相近的反键轨道进行有效组合，会使得分子采取某些特定的构象，以达到最大重叠。此即立体电子效应，即空间（立体）效应和电子（轨道）效应耦合，形成了 $1 + 1 > 2$ 的效果。

以 1,2-二氟乙烷为例：在 1,2-二氟乙烷的诸多极限构象中，交叉式构象的能量比重叠式能量要低，其原因不仅在于重叠式构象中斥力的存在，更重要的是交叉式构象中各键的空间分布使得分子中存在诸多的轨道重叠。分子轨道的重叠本质上是轨道的重新线性组合，组合后会得到能量更低的成键轨道，电子填入新的成键轨道使能量降低，进而稳定整个分子体系。而在 1,2-二氟乙烷分子中，存在两种交叉式构象：（全）对交叉与邻交叉，存在的轨道重叠如下图所示。从空间分布的角度出发，在 1,2-二氟乙烷分子中，当成键轨道与反键轨道处于反式共平面的位置时，可以发生最大重叠。

   - M⁺ = 202，从碎片 174 = M⁺-28（丢失 CO）推断含醛基

   - δC 80.8 → **关键信号！** 这是 sp 杂化碳的典型区域 → 含 C≡C 炔键

   - δ 2.06 (3H, dd, J=1.0, 1.6 Hz)：甲基通过烯丙基偶合与 =CH₂ 相连（J 值很小，符合远程偶合）

   - δ 196.6：醛 C=O
   - δ 80.8：炔碳（sp 杂化，关键诊断信号）
   - δ 22.8：甲基碳
   - 其余为 sp² 碳（烯烃 + 芳香环）

### 1.43 〔🟢 d5〕

比较下列两对化合物的酸性强弱，并解释为什么直觉判断可能出错：

**(a)** 苯酚 C₆H₅OH vs 环己醇 C₆H₁₁OH

**(b)** 对硝基苯酚 p-O₂NC₆H₄OH vs 苯酚 C₆H₅OH

**(c)** 【冲突题】化合物 A（邻羟基苯甲酸，水杨酸）的 pKa₁ = 2.97，化合物 B（对羟基苯甲酸）的 pKa₁ = 4.54。从共振结构数目看，B 的共轭碱（对位负电荷）应该更稳定（共振式更多），但实际酸性 A > B。解释这个"冲突"。

<details>
<summary>📖 查看答案</summary>

### (a) 苯酚 vs 环己醇

**苯酚酸性更强**（pKa ≈ 10 vs ~16）

原因：苯酚的共轭碱（苯氧负离子 C₆H₅O⁻）中，负电荷可以通过 **p-π 共轭**离域到苯环上：

```
C₆H₅O⁻ ← 共振结构：负电荷分散到邻位和对位碳上
```

共轭碱更稳定 → 酸性更强。环己醇的共轭碱无此离域效应。

### (b) 对硝基苯酚 vs 苯酚

**对硝基苯酚酸性更强**（pKa ≈ 7.1 vs 10）

NO₂ 是强吸电子基团（−I 和 −M 效应），通过苯环拉走负电荷：

```
O₂N-C₆H₄-O⁻ ← 负电荷进一步离域到 NO₂ 的氧上
```

共轭碱更稳定 → 酸性更强。

### (c) 冲突题：水杨酸 vs 对羟基苯甲酸

**直觉判断**：对羟基苯酚的共轭碱中，负电荷可以离域到对位（与 -OH 对位），共振式更多 → 应该更稳定 → 酸性更强。

**实际结果**：水杨酸（邻位）pKa₁ = 2.97，对羟基苯甲酸 pKa₁ = 4.54 → **邻位酸性更强**。

**解释这个"冲突"**：

酸性强弱不仅取决于共振稳定化，还取决于**共轭碱的绝对稳定性**。水杨酸的邻位效应来自：

1. **氢键稳定化**：水杨酸的 -COO⁻ 与邻位 -OH 形成**分子内氢键**（六元环螯合），大幅稳定共轭碱
2. **诱导效应**：邻位 -OH 的 −I 效应比对位更强（距离更近）
3. **溶剂化效应**：邻位取代基的位阻可能影响溶剂化，但氢键的稳定化贡献更大

**关键教训**：共振稳定化不是唯一因素。**分子内氢键、诱导效应、溶剂化效应**都可能逆转仅靠共振结构数做出的判断。

### 酸性判断的完整框架

| 因素 | 使酸性增强 | 使酸性减弱 |
|:---|:---|:---|
| **共轭碱稳定化** | 负电荷离域（共振） | 负电荷集中 |
| **诱导效应** | −I 基团（吸电子） | +I 基团（给电子） |
| **氢键** | 分子内氢键稳定共轭碱 | — |
| **杂化** | sp > sp² > sp³（C-H 酸性） | — |
| **溶剂化** | 共轭碱溶剂化好 | 共轭碱溶剂化差 |

> ⚠️ **核心教训**：不能只数共振式！酸性判断需要综合考虑多种效应的叠加。当共振判断与实验结果矛盾时，检查是否有氢键或强诱导效应在起作用。
