### 4.1 〔🟢 d3〕

> **来源**：第27届中国化学奥林匹克（初赛）第2题(23分) 第(2-2)小问

在液氨中，$E^{\ominus}(\mathrm{Na}^{+}/\mathrm{Na})=-1.89\ \mathrm{V}$，$E^{\ominus}(\mathrm{Mg}^{2+}/\mathrm{Mg})=-1.74\ \mathrm{V}$，但可以发生 Mg 置换 Na 的反应：$\mathrm{Mg}+2\mathrm{NaI}=\mathrm{MgI}_{2}+2\mathrm{Na}$。指出原因。

<details>
<summary>📖 查看答案</summary>

虽然标准电极电势 Na < Mg（即Na更活泼），但此反应在液氨中进行，$\mathrm{MgI}_{2}$ 在液氨中为**难溶物**，沉淀的生成降低了溶液中 $\mathrm{Mg}^{2+}$ 的有效浓度，根据能斯特方程，$\mathrm{Mg}^{2+}/\mathrm{Mg}$ 的实际电极电势显著降低，使得 $E(\mathrm{MgI}_{2}/\mathrm{Mg}) < E(\mathrm{NaI}/\mathrm{Na})$，反应方向逆转。

| 知识点 | 对应内容 |
|:---|:---|
| 非水溶剂效应 | 液氨中溶解度不同于水溶液 |
| 能斯特方程 | 难溶物降低离子浓度，改变电极电势 |

## 解题思路

1. 水溶液中Na⁺/Na电势低于Mg²⁺/Mg → Na更活泼

### 4.2 〔🟢 d3〕

> **来源**：第27届中国化学奥林匹克（初赛）第2题(23分) 第(2-7)小问

实验得到一种含钯化合物 $\mathrm{Pd}[\mathrm{C}_{x}\mathrm{H}_{y}\mathrm{N}_{z}](\mathrm{ClO}_{4})_{2}$，该化合物中 C 和 H 的质量分数分别为 30.15% 和 5.06%。将此化合物转化为硫氰酸盐 $\mathrm{Pd}[\mathrm{C}_{x}\mathrm{H}_{y}\mathrm{N}_{z}](\mathrm{SCN})_{2}$，则 C 和 H 的质量分数分别为 40.46% 和 5.94%。通过计算确定其组成。

<details>
<summary>📖 查看答案</summary>

**Pd[C₁₄H₂₈N₄](ClO₄)₂**

计算过程：
1. 由ClO₄⁻化合物：C/H摩尔比 = (30.15/12.01):(5.06/1.008) = 1:2 → y = 2x
2. 由SCN⁻化合物：(x+2)/y = (40.46/12.01)/(5.94/1.008) → 解得 x ≈ 14, y = 28
3. 由分子量计算z：z = [14×12.01/30.15% - (106.4+12.01×4+1.008×28+2×99.45)]/14.01 ≈ 4

### 4.3 〔🟢 d3〕

> **来源**：第27届中国化学奥林匹克（初赛）第6题(10分)

某同学得知一定浓度的 $\mathrm{Fe}^{2+}$、$\mathrm{Cr(OH)}_{4}^{-}$、$\mathrm{Ni}^{2+}$、$\mathrm{MnO}_{4}^{2-}$ 和 $\mathrm{CuCl}_{3}^{-}$ 的水溶液都呈绿色。用蒸馏水、稀 H₂SO₄ 及简单器材，以尽可能少的步骤鉴别它们。

<details>
<summary>📖 查看答案</summary>

**第1步**：将5种溶液分别滴到点滴板上，滴加稀H₂SO₄：
- $\mathrm{CuCl}_{3}^{-}$ → 蓝色溶液（配合物解离）：$\mathrm{CuCl}_{3}^{-} + 4\mathrm{H}_{2}\mathrm{O} = \mathrm{Cu(H_{2}O)}_{4}^{2+} + 3\mathrm{Cl}^{-}$

- Fe²⁺和Ni²⁺ → 无明显变化

**第2步**：用已鉴出的 $\mathrm{Cr(OH)}_{4}^{-}$ 滴加到Fe²⁺和Ni²⁺中：
- Fe²⁺ → 沉淀迅速变红褐色（Fe(OH)₂→Fe(OH)₃氧化）
- Ni²⁺ → 绿色沉淀不变色

### 4.4 〔🟢 d3〕

> **来源**：第35届初赛第3题（原始文件：06-外部资料导入/真题/第35届初赛试题解析）
> **小问关联**：本文件为第 3 题第(2)小问；第(1)小问见 题-035-3-1-硫代硼酸二聚三聚结构；第(3)小问见 题-035-3-3-卟吩类似物芳香性

A（即题-035-3-1中的二聚体 $(\mathrm{HBS_2})_2$）和 $\mathrm{BCl_3}$ 按计量系数 $1:1$ 反应，得到相同计量系数的 $\mathrm{H_2S}$ 和另一产物 **C**（反应1），C 受热分解为 **D** 和 $\mathrm{BCl_3}$（反应2）。在低温惰性介质中 D 可以单分子形式存在，结构中有且仅有二重旋转轴以及过二重轴的两个镜面。

**3-2-1** 写出 **C** 生成（反应 1）和分解（反应 2）的反应方程式。

**3-2-2** C 易水解。写出 C 发生水解的反应方程式。

**3-2-3** 画出 **C** 和 **D** 的结构。

<details>
<summary>📖 查看答案</summary>

**得分点**：
1. **3-2-1 反应1正确**（1分）：$(\mathrm{HBS_2})_2 + \mathrm{BCl_3} \longrightarrow \mathrm{H_2S} + \mathrm{B_3S_3Cl_3}$
2. **3-2-1 反应2正确**（1分）：$\mathrm{B_3S_3Cl_3} \longrightarrow \mathrm{BCl_3} + \mathrm{B_2S_3}$
3. **3-2-2 水解方程式正确**（1.5分）：$\mathrm{B_3S_3Cl_3} + 9\mathrm{H_2O} \longrightarrow 3\mathrm{B(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}$
4. **3-2-3 C 的结构正确**（1分）：三个 Cl 取代三聚体 B 中三个端基 -SH 的结构
5. **3-2-3 D 的结构正确**（1.5分）：折线形 $\mathrm{B_2S_3}$（$C_{2v}$ 点群）

**完整推导**：

### 3-2-1 反应方程式

由于题目中给出了二聚体 A 与 $\mathrm{BCl_3}$ 反应（反应1）的计量系数，合理推测1当量的 $\mathbf{A} = (\mathrm{HBS_2})_2 = \mathrm{H_2B_2S_4}$ 与1当量的 $\mathrm{BCl_3}$ 反应，生成1当量的 $\mathrm{H_2S}$。

根据原子守恒，另一产物 **C** 的化学式应为 $\mathrm{B_3S_3Cl_3}$。

$\mathrm{B_3S_3Cl_3}$ 受热分解，生成 $\mathrm{BCl_3}$ 和另一产物 **D**（反应2）。假设反应物 $\mathrm{B_3S_3Cl_3}$ 中的1个B原子和3个Cl原子变为 $\mathrm{BCl_3}$，剩下的原子构成产物 **D**，即 **D** 分子式为 $\mathrm{B_2S_3}$。

$$
(\mathrm{HBS_2})_2 + \mathrm{BCl_3} \longrightarrow \mathrm{H_2S} + \mathrm{B_3S_3Cl_3} \quad (\text{反应 1})
$$

$$
\mathrm{B_3S_3Cl_3} \longrightarrow \mathrm{BCl_3} + \mathrm{B_2S_3} \quad (\text{反应 2})
$$

### 3-2-2 水解方程式

对比 **C**（$\mathrm{B_3S_3Cl_3}$）与硫代硼酸三聚体 B（$\mathrm{HBS_2})_3 = \mathrm{B_3S_6H_3}$ 的分子式，可推测 **C** 是 3 个 Cl 原子取代了 B 中三个巯基的结构。

**C** 中的 **B-Cl 键**极易水解（可以类比 $\mathrm{BCl_3}$ 极易水解为硼酸），但这里容易忽略的是 **B-S 键也会发生水解**：

- B 原子半径较小，S 原子半径较大，形成 B-S 键的轨道并不能很好地重叠
- O 原子的半径与 B 原子半径匹配，形成的 B-O 键更强
- 从软硬酸碱的角度来理解：B 是硬酸，O 是硬碱，S 是软碱；B-O 键比 B-S 键更稳定

若未考虑到 B-S 键的水解，只写出 B-Cl 键水解的部分水解方程式，只能拿到一半的分数。**C** 彻底水解的反应方程式为：

$$
\mathrm{B_3S_3Cl_3} + 9\mathrm{H_2O} \longrightarrow 3\mathrm{B(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}
$$

> 如果将含硼产物写为三聚硼酸 $\mathrm{B_3O_3(OH)_3} = \mathrm{B_3O_6H_3}$，也算正确：
> $$\mathrm{B_3S_3Cl_3} + 6\mathrm{H_2O} \longrightarrow \mathrm{B_3O_3(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}$$

### 3-2-3 C 和 D 的结构

**C 的结构**：根据前一小问的分析，C 的结构是容易画出的——三个 Cl 原子取代三聚体 B 中三个端基 -SH 的结构，保持 $\mathrm{B_3S_3}$ 六元环骨架不变。

**D 的结构**：题目中给出了 $\mathbf{D} = \mathbf{B_2S_3}$ 的对称性信息：「有且仅有二重旋转轴以及过二重轴的两个镜面」。

对常见化合物对称性比较熟悉的同学应很快意识到，这与 $\mathrm{H_2O}$ 分子具有完全相同的对称元素（$C_{2v}$ 点群）。故 **D** 也应为**折线形结构**；其中的一个 S 原子作为中心原子，在中心原子的两侧对称地分布两个 $[\mathrm{BS}]$ 单元。

为使 S 原子满足 8 电子结构，两个 $[\mathrm{BS}]$ 单元应为 $\mathrm{B=S}$ 双键。B 原子虽然是 6 电子的缺电子中心，但可以通过形成离域 $\pi$ 键来削弱其缺电子性质。

**C 的结构**：六元环 $\mathrm{B_3S_3}$，每个 B 上连一个 Cl，每个 S 为桥连 S（保持与三聚体相同的骨架）。

**D 的结构**：
```
    S=B=S=B=S
      折线形，中心S
```
（实际为：中心S原子两侧对称分布 B=S 单元）

> 思考题：D 中的 B 原子能否画成折线形？给出理由。D 中形成了哪种离域 $\pi$ 键？

## 知识点映射

| 关联 KP | 考查角度 | 直接/间接 |
|---|---|:---:|
| 杂化轨道理论 | B 的三配位、S 的杂化与成键 | 直接 |
| 硼化学 | BCl₃ 的 Lewis 酸性、B-Cl 与 B-S 键的水解 | 直接 |
| 软硬酸碱理论 | B（硬酸）偏好 O（硬碱）而非 S（软碱） | 间接 |
| 分子对称性初步 | $C_{2v}$ 点群的识别（与 H₂O 相同） | 间接 |

## 解题思路

1. **读题定位**：看到「按计量系数1:1」「受热分解」「对称性」→ 识别为 **原子守恒 + 结构推断** 题
2. **3-2-1 推导C和D的分子式**：
   - A ($\mathrm{H_2B_2S_4}$) + $\mathrm{BCl_3}$ → $\mathrm{H_2S}$ + C
   - 原子守恒：C = $\mathrm{B_3S_3Cl_3}$
   - C 分解 → $\mathrm{BCl_3}$ + D，D = $\mathrm{B_2S_3}$
3. **3-2-2 水解方程式**：
   - **🔑 关键转换**：C 中既有 B-Cl 键又有 B-S 键，两者都会水解
   - B-Cl → B-OH + HCl；B-S → B-OH + H₂S
   - 彻底水解需 9 H₂O，生成 3 B(OH)₃ + 3 H₂S + 3 HCl
4. **3-2-3 D的结构**：
   - 对称性信息：仅有 $C_2$ 轴 + 2个镜面 → $C_{2v}$ 点群
   - 类比 H₂O → 折线形结构
   - 中心 S 原子，两侧对称分布 B=S 单元

## 易错分析

| 错误 | 原因 | 纠正 | 课堂提问 |
|---|---|---|---|
| 3-2-2 只写 B-Cl 水解 | 忽略了 B-S 键也会水解 | B-S 键轨道重叠差，B-O 键更强，故 B-S 也会水解 | 「B-S 键和 B-O 键哪个更强？为什么？」 |
| 3-2-2 产物写成 BCl₃ | 混淆了水解产物和热分解产物 | 水解产物是硼酸 B(OH)₃，热分解产物才是 BCl₃ | 「水解和热分解有什么区别？产物分别是什么？」 |
| 3-2-3 D 画成环状 | 未利用对称性信息 | $C_{2v}$ 点群要求折线形，不是环状 | 「H₂O 是什么形状？$C_{2v}$ 点群的典型分子有哪些？」 |
| 3-2-3 D 中 B 成键错误 | 未满足八隅体规则 | D 中 B=S 双键可使 B 满足 6 电子（缺电子），或通过离域 $\pi$ 键稳定 | 「B 原子满足八隅体吗？如何稳定缺电子中心？」 |

## 知识拓展

**B-S 键与 B-O 键的稳定性比较**：

从软硬酸碱理论（HSAB）来看：
- B³⁺ 是 **硬酸**（电荷密度高、极化性小）
- O²⁻ 是 **硬碱**（电负性高、极化性小）
- S²⁻ 是 **软碱**（电负性较低、极化性大、易变形）

根据「硬亲硬，软亲软」原则，B-O 键比 B-S 键更稳定。这也解释了为什么含 B-S 键的化合物（如本题中的 C）在水中容易发生 B-S → B-O 的转换。

> 也可以从轨道重叠的角度理解：B 原子半径较小，S 原子半径较大，形成 B-S 键的轨道并不能很好地重叠；而 O 原子的半径与 B 原子半径匹配，形成的 B-O 键更强。

</details>

### 4.5 〔🟢 d3〕

（题干见源文件）

<details>
<summary>📖 查看答案</summary>

- **A**：$\mathrm{Fe}_4^{\mathrm{II}}\mathrm{Fe}_2^{\mathrm{III}}(\mathrm{OH})_{12}(\mathrm{SO}_4)$（GR-II，绿锈）
- **B**：$\mathrm{FeO(OH)}$（羟基氧化铁，也可写作 $\mathrm{Fe}_2\mathrm{O}_3 \cdot \mathrm{H}_2\mathrm{O}$）
- **C**：$\mathrm{Fe}_3\mathrm{O}_4$（四氧化三铁，磁性氧化铁）
- **D**：$\mathrm{Fe}_2\mathrm{O}_3$（三氧化二铁，砖红色）

## 知识点映射

- **直接 KP**：铁化合物、绿锈结构、氧化态表示、失重计算
- **间接 KP**：层状结构、氢氧化物脱水、磁性材料

## 解题思路

1. **推断 B**：B 是黄色固体，且为 A 进一步氧化所得，结合铁元素性质推断 B 为三价铁的氢氧化物。B 在 150℃ 彻底脱水得到 D，失重 10.0%。设 B 为 $\mathrm{Fe}_2\mathrm{O}_3 \cdot x\mathrm{H}_2\mathrm{O}$，计算得 $x \approx 1$，因此 B 为 $\mathrm{FeO(OH)}$（羟基氧化铁）。

2. **推断 D**：D 为砖红色氧化物，含有 Fe，应为 $\mathrm{Fe}_2\mathrm{O}_3$。

3. **推断 C**：C 为含有 Fe 的黑色磁性物质，应为 $\mathrm{Fe}_3\mathrm{O}_4$（反尖晶石型结构）。

## 解题思路

### 19.57 工业生产过程

**(1) 黄铜矿炼铜**是火法冶金的经典流程：

1. **焙烧**：将 CuFeS₂ 部分氧化，除去部分硫和铁，转化为 Cu₂S 和 FeO
2. **造锍熔炼**：加 SiO₂ 作熔剂，FeO 形成 FeSiO₃ 浮渣被除去，Cu₂S 和 FeS 熔融形成"冰铜"沉于底部
3. **转炉吹炼**：鼓入空气，Cu₂S 先氧化为 Cu₂O，再与剩余 Cu₂S 发生自还原反应得到粗铜

**(2) 氰化法炼金**利用 Au 的强配位能力：NaCN 在 O₂ 存在下溶解 Au 形成 [Au(CN)₂]⁻，再用廉价 Zn 置换回收 Au。

**(3) 闪锌矿炼 Zn**：焙烧得 ZnO，用 CO 碳热还原得 Zn 蒸气，蒸馏收集。利用 Zn 和 Cd 沸点差异进行精馏除 Cd。

**(4) 辰砂制 Hg**：HgS 在空气中灼烧直接得 Hg（利用 Hg 为液态金属易蒸馏收集的特殊性质），或溶于 Na₂S 后电解。

### 19.58 合成路线设计

**关键思路**：从原料出发，经过最少步骤得到目标产物，每步反应选择性好、产率高。

**(1) CuSO₄ → CuBr**：利用 Cu(II) 与 Cu(0) 的归中反应。

**(2) ZnS → 无水 ZnCl₂**：HCl 溶解 + HCl 气氛脱水（防止水解）。

**(3) Hg → K₂[HgI₄]**：稀 HNO₃ 溶 Hg → Hg(NO₃)₂ → 过量 KI → K₂[HgI₄]。

**(5) Ag 的系列化合物**：Ag 溶于稀 HNO₃ 得 AgNO₃，分别加 Cl⁻、I⁻、S²⁻ 沉淀。

**(8) Cu(III) 化合物**：Cu(III) 极不稳定，需强氧化 + 强配位条件，如与 F₂ 和 K 共热得 K₃[CuF₆]，或与 KO₂ 反应得 KCuO₂。

### 19.59 混合物分离

**(1) ZnS、CdS、HgS**：利用 Ksp 差异。Ksp(ZnS) ≈ 10⁻²⁴ >> Ksp(CdS) ≈ 10⁻²⁷ >> Ksp(HgS) ≈ 10⁻⁵²。稀 HCl 溶 ZnS，浓 HCl 溶 CdS，HgS 极难溶。

**(2) AgCl、Hg₂Cl₂、HgCl₂**：先用水溶 HgCl₂（可溶性共价分子），再用氨水区分 AgCl（溶为无色溶液）和 Hg₂Cl₂（歧化为灰黑色不溶物）。

### 19.60-19.62 离子分离方案

**核心策略**：利用两性差异、配合物稳定性差异和溶度积差异进行选择性沉淀和溶解。

**19.60**：NaOH 过量 → Zn²⁺ 和 Al³⁺ 成可溶配离子，Cd²⁺ 和 Hg²⁺ 沉淀 → 滤液通 CO₂ 分别沉淀 → 氨水分离 Zn/Al。

**19.61**：HCl 沉淀 AgCl 和 HgCl₂ → NaOH 溶解两性离子 → 加热使 [Al(OH)₄]⁻ 转化为 Al(OH)₃。

**19.62**：不能用 NaOH 分离 Zn²⁺ 和 Cu²⁺（Cu(OH)₂ 在过量 NaOH 中部分溶解），需另选方案。

### 19.63 三种白色氯化物的鉴别

用氨水一种试剂即可鉴别：

- **Hg₂Cl₂**：歧化反应，生成 Hg(NH₂)Cl(白) + Hg(黑) = 灰黑色沉淀
- **CuCl**：溶解为 [Cu(NH₃)₂]⁺(无色)，被空气氧化为 [Cu(NH₃)₄]²⁺(深蓝)
- **AgCl**：溶解为 [Ag(NH₃)₂]⁺(无色稳定溶液)

## 解题思路

### 19.64 实验现象解释

**(1) CuSO₄ + NaOH → 加热变黑**

两步反应：
- $\mathrm{CuSO_4 + 2NaOH = Cu(OH)_2\downarrow(浅蓝) + Na_2SO_4}$
- $\mathrm{Cu(OH)_2 \xrightarrow{\triangle} CuO(黑) + H_2O}$

Cu(OH)₂ 热稳定性差，加热脱水是常见的性质。

**(2) HgCl₂ 加 NaOH 与加 NH₃ 的不同**

- NaOH 提供 OH⁻：$\mathrm{Hg^{2+} + 2OH^- = HgO\downarrow(黄) + H_2O}$（Hg(OH)₂ 极不稳定，立即脱水）
- NH₃ 提供 NH₂⁻（通过 NH₃ + H₂O ⇌ NH₄⁺ + OH⁻）：$\mathrm{HgCl_2 + 2NH_3 = Hg(NH_2)Cl\downarrow(白) + NH_4Cl}$

两种试剂提供的阴离子不同，产物不同。

**(3) Hg(NO₃)₂ vs HgCl₂ 的水解差异**

Hg(NO₃)₂ 是离子化合物，Hg²⁺ 水解强烈：$\mathrm{2Hg(NO_3)_2 + H_2O = HgO\cdot Hg(NO_3)_2\downarrow + 2HNO_3}$。

HgCl₂ 是共价分子（直线形 Cl-Hg-Cl），在水中主要以分子形式存在，水解程度很小。

**(4) AgI 颜色随温度变化**

这是**电荷迁移光谱**的经典例子。AgI 中 Ag⁺ 和 I⁻ 之间的极化作用很强，电子从 I⁻ 向 Ag⁺ 跃迁（电荷迁移）吸收可见光。温度升高→晶格膨胀→极化更强→吸收峰红移（吸收更长波长的光）→颜色从白→黄→红。

AgCl 中 Cl⁻ 变形性小，电荷迁移需吸收紫外光，故显白色。

**(5) Cu 溶于 CN⁻ 和氨水**

**核心原理**：配合物的形成降低了金属的电极电势。

- $E^\ominus(\mathrm{Cu^{2+}/Cu}) = 0.34$ V → 形成 $[\mathrm{Cu(CN)_4}]^{3-}$ 后，$E^\ominus$ 大幅降低，低于 $E^\ominus(\mathrm{H_2O/H_2})$，故 Cu 可置换水中的 H⁺ 放出 H₂
- 形成 $[\mathrm{Cu(NH_3)_4}]^{2+}$ 后，$E^\ominus$ 降低至低于 $E^\ominus(\mathrm{O_2/OH^-})$，故 O₂ 可氧化 Cu

**(6) Cu 溶于硝酸，Au 只溶于王水**

金属活泼性：Cu > Au。Cu 可被 HNO₃ 氧化（NO₃⁻/NO 的 E = 0.96 V > Cu²⁺/Cu 的 E = 0.34 V）。Au 极不活泼（E = 1.69 V），只有王水中 HNO₃（氧化）和 HCl（配位 Cl⁻ 稳定 Au³⁺）协同作用才能溶解。

**(7) [Zn(OH)₄]²⁻ + HCl**

两步：先中和过量 OH⁻ 生成 Zn(OH)₂ 沉淀，继续加酸使 Zn(OH)₂（两性）溶解为 Zn²⁺。

**(8)-(9) Hg₂²⁺ 和 Hg²⁺ 与 KI**

Hg₂²⁺ + I⁻ 先生成 Hg₂I₂(黄)，但 Hg₂I₂ 不稳定（Hg(I) 的不稳定性），歧化为 Hg(黑) + HgI₂(红)，混合显黑色。过量 I⁻ 配位溶解 HgI₂。

Hg²⁺ + I⁻ 直接生成 HgI₂(红)，过量 I⁻ 溶解为 $[\mathrm{HgI_4}]^{2-}$(无色)。

### 19.68 实验事实解释

**(1) CuCl₂·2H₂O 加热得不到无水 CuCl₂**

Cu²⁺ 极化能力强，HCl 是挥发性酸。加热时 Cu²⁺ 极化 H₂O 中的 OH⁻，导致水解脱 HCl：$\mathrm{CuCl_2\cdot 2H_2O \xrightarrow{\triangle} Cu(OH)Cl + HCl\uparrow + H_2O}$。

要制备无水 CuCl₂，需在 HCl 气流中加热脱水（抑制水解）。

**(2) HgC₂O₄ 溶于 HCl**

HgC₂O₄ 虽然难溶于水，但 HCl 提供的 Cl⁻ 与 Hg²⁺ 形成稳定的 $[\mathrm{HgCl_4}]^{2-}$ 配离子，使溶解平衡右移。

**(3) NH₄NO₃ 存在时 Hg(NO₃)₂ + NH₃ 不生成氨基化合物**

NH₄⁺ 的存在抑制了 NH₃ + H₂O ⇌ NH₄⁺ + OH⁻ 平衡右移，减少 OH⁻ 浓度，不利于 Hg(NH₂)NO₃ 沉淀的形成。反而有利于形成可溶的 $[\mathrm{Hg(NH_3)_4}]^{2+}$。

### 19.69 Ag 与 HCl 和 HI 反应差异

**关键**：比较 $E^\ominus(\mathrm{AgX/Ag})$ 与 $E^\ominus(\mathrm{H^+/H_2}) = 0$ V。

利用能斯特方程：$E^\ominus(\mathrm{AgX/Ag}) = E^\ominus(\mathrm{Ag^+/Ag}) + 0.0592\lg K_{sp}(\mathrm{AgX})$

- AgCl：$E^\ominus = 0.799 + 0.0592\lg(1.77\times10^{-10}) = 0.222$ V > 0 → 不反应
- AgI：$E^\ominus = 0.799 + 0.0592\lg(8.52\times10^{-17}) = -0.152$ V < 0 → 可反应

Ksp 越小，AgX/Ag 电对的电极电势越低，越容易被还原。

### 19.70-19.77 物质推断

这些推断题的关键是利用各物质的特征反应和现象进行逻辑推理。解题步骤：
1. 列出每步实验的现象和可能的反应
2. 利用排除法逐步缩小范围

### 22.45 如何在不引入杂质的情况下，将粗ZnSO4溶液中含有的Fe3+、Fe2+、Cu2+杂质除去？

### 3-3-1 E 的分子式与氧化态

白色固体 **E** 是 $\mathrm{B_2S_3}$ 与单质硫反应的产物，这是一个氧化还原反应。B 元素的常见价态为 +3，除硼烷类化合物以外，只有在比较苛刻的条件下 B 元素才会发生变价。故这个反应中应当只有 S 原子的氧化态发生改变：
- 还原剂 $\mathrm{B_2S_3}$ 中 S 为 $-2$ 价
- 氧化剂硫单质中 S 为 $0$ 价
- 联想到多硫离子的制备反应：$\mathrm{S^{2-}} + n\mathrm{S} \longrightarrow \mathrm{S_{n+1}^{2-}}$

- 所有的 **8 个 B 原子位置均等价**，也即只存在 1 种 B 原子
- S 原子的位置有 **3 种**：
  1. 五元环内 B-S-B 位置的 4 个 **$-2$ 价 S 原子**
  2. 五元环外 B-S-B 位置的 4 个 **$-2$ 价 S 原子**
  3. 五元环内 B-S-S-B 位置的 8 个 **$-1$ 价 S 原子**

### 3-3-2 E 的经典 Lewis 结构

根据上一小问的结论，先将 B 原子和 S 原子放置在正确的位置（类似卟吩的平面大环骨架）。其中包含的 28 条 $\sigma$ 键形成了类似卟吩结构的骨架。

> 2. 所有 S 原子满足八隅体
> 3. B=S 双键不相邻

### 3-3-3 芳香性判断

对于大环中稠环体系或轮烯体系的芳香性判断，在 E 的经典 Lewis 结构中，最大的共轭体系是硼硫交替的「内圈结构」，属于轮烯模型。

每个 B=S 双键都是 S 原子通过一对电子向 B 原子进行「配位」形成的，而 S 原子上剩余的一对孤对电子所处的轨道与离域 $\pi$ 轨道**正交**，不参与离域。故共轭体系中总的 $\pi$ 电子数为：

$$8 \times 2 = 16$$

根据 Hückel 规则，芳香性要求 $\pi$ 电子数为 $4n+2$。$16 = 4n$（$n=4$），不符合 $4n+2$ 规则。

**故此结构无芳香性。**

> 思考：如果取外圈作为轮烯，分子有无芳香性？这种取法是否更加（不）合理？给出你的解释。

## 知识拓展

**大环共轭体系的芳香性判断**：

对于含有杂原子的大环共轭体系，判断芳香性时需注意：

1. **哪些原子参与共轭**：通常只考虑形成连续共轭链的原子
2. **每个原子贡献多少 $\pi$ 电子**：
   - 双键：2 个 $\pi$ e⁻
   - 杂原子的孤对电子：若该孤对电子所在的 p 轨道与环平面垂直，则参与共轭；若平行（或近似平行），则不参与
3. **Hückel 规则**：$\pi$ 电子数为 $4n+2$ 时具有芳香性

在本题中，S 原子上有两对孤对电子：
- 一对用于形成 B=S 的 $\pi$ 键（配位键）
- 另一对处于与 $\pi$ 体系正交的轨道中，不参与离域

这正是 $4n$（而非 $4n+2$）的原因，也是该大环**无芳香性**的关键。

### 4-2-1 方酸的结构
