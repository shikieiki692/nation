### 99.1 〔🟢 d2〕

> **来源**：第35届初赛第1题（原始文件：06-外部资料导入/真题/第35届初赛试题解析）
> **小问关联**：本文件为第 1 题第(1)小问；第(2)小问见 题-035-1-2-二氯二甲基硅烷水解；第(3)小问见 题-035-1-3-Fe3+氧化硫化物矿；第(4)小问见 题-035-1-4-钢铁发蓝处理

砷化镓是一种重要的半导体材料，可利用气相外延法制备。常用工艺中，采用 Ga 和 $\mathrm{AsCl}_3$ 在 $\mathrm{H}_2$ 中制备。写出该反应的化学方程式。

<details>
<summary>📖 查看答案</summary>

**得分点**：
1. **正确推断产物**（1分）：GaAs 和 HCl
2. **正确配平**（1分）：$2\mathrm{Ga} + 2\mathrm{AsCl}_3 + 3\mathrm{H}_2 \longrightarrow 2\mathrm{GaAs} + 6\mathrm{HCl}$

**推导过程**：
- 反应物 Ga 氧化数为 0，$\mathrm{AsCl}_3$ 中 As 为 $+3$
- 产物 GaAs 中 Ga 为 $+3$、As 为 $-3$
- Ga 被氧化（0 → +3），As 被还原（+3 → −3）
- 需要还原剂使电子守恒：$\mathrm{H}_2$ 氧化为 HCl 中的 $+1$ 价 H

$$
2 \mathrm{Ga} + 2 \mathrm{AsCl}_3 + 3 \mathrm{H}_2 \longrightarrow 2 \mathrm{GaAs} + 6 \mathrm{HCl}
$$

**巧设氧化数法（快速配平技巧）**：
假设 GaAs 中 Ga 和 As 的氧化数均为 0，则只有 As 从 $+3$ 被还原为 0，唯一还原剂为 $\mathrm{H}_2$，可快速推出 $\mathrm{AsCl}_3$ 和 $\mathrm{H}_2$ 的当量比为 $2:3$。

## 知识点映射

| 关联 KP | 考查角度 | 直接/间接 |
|---|---|:---:|
| 氧化还原反应方程式配平 | 氧化数法配平氧化还原方程式 | 直接 |
| 砷 | As 的常见氧化态（+3 → −3） | 间接 |
| 镓 | Ga 的氧化态变化（0 → +3） | 间接 |

## 解题思路

1. **读题定位**：看到「气相外延」「制备」→ 识别为 **氧化还原反应方程式书写** 题
2. **确定产物**：Ga + AsCl₃ → GaAs（半导体材料）+ HCl（H₂参与反应）
3. **🔑 关键转换**：GaAs 中 Ga 为 +3、As 为 −3（III-V 族半导体特征）
4. **配平验证**：电子转移守恒（Ga 失 3e⁻ × 2 = 6e⁻；As 得 6e⁻ × 2 = 12e⁻；H₂ 失 2e⁻ × 3 = 6e⁻）

## 易错分析

| 错误 | 原因 | 纠正 | 课堂提问 |
|---|---|---|---|
| 产物写成 GaCl₃ + As | 未理解「外延制备」是合成 GaAs 单晶 | GaAs 是目标产物，AsCl₃ 提供 As 源 | 「气相外延法制备 GaAs，产物应该是什么？」 |
| 配平错误 | 未检查氧化数是否合理 | 配平后用氧化数验证 | 「Ga 从 0 到 +3 失几个电子？As 从 +3 到 −3 得几个电子？」 |
| 漏写 HCl | 忽略了 H₂ 的氧化产物 | H₂ 作为还原剂，氧化产物为 H⁺（即 HCl） | 「H₂ 在反应中起什么作用？它的氧化产物是什么？」 |

### 99.2 〔🟢 d3〕

> **来源**：第27届中国化学奥林匹克（初赛）第2题(23分) 第(2-2)小问

在液氨中，$E^{\ominus}(\mathrm{Na}^{+}/\mathrm{Na})=-1.89\ \mathrm{V}$，$E^{\ominus}(\mathrm{Mg}^{2+}/\mathrm{Mg})=-1.74\ \mathrm{V}$，但可以发生 Mg 置换 Na 的反应：$\mathrm{Mg}+2\mathrm{NaI}=\mathrm{MgI}_{2}+2\mathrm{Na}$。指出原因。

<details>
<summary>📖 查看答案</summary>

虽然标准电极电势 Na < Mg（即Na更活泼），但此反应在液氨中进行，$\mathrm{MgI}_{2}$ 在液氨中为**难溶物**，沉淀的生成降低了溶液中 $\mathrm{Mg}^{2+}$ 的有效浓度，根据能斯特方程，$\mathrm{Mg}^{2+}/\mathrm{Mg}$ 的实际电极电势显著降低，使得 $E(\mathrm{MgI}_{2}/\mathrm{Mg}) < E(\mathrm{NaI}/\mathrm{Na})$，反应方向逆转。

| 知识点 | 对应内容 |

### 99.3 〔🟢 d3〕

> **来源**：第27届中国化学奥林匹克（初赛）第6题(10分)

某同学得知一定浓度的 $\mathrm{Fe}^{2+}$、$\mathrm{Cr(OH)}_{4}^{-}$、$\mathrm{Ni}^{2+}$、$\mathrm{MnO}_{4}^{2-}$ 和 $\mathrm{CuCl}_{3}^{-}$ 的水溶液都呈绿色。用蒸馏水、稀 H₂SO₄ 及简单器材，以尽可能少的步骤鉴别它们。

<details>
<summary>📖 查看答案</summary>

**第1步**：将5种溶液分别滴到点滴板上，滴加稀H₂SO₄：
- $\mathrm{CuCl}_{3}^{-}$ → 蓝色溶液（配合物解离）：$\mathrm{CuCl}_{3}^{-} + 4\mathrm{H}_{2}\mathrm{O} = \mathrm{Cu(H_{2}O)}_{4}^{2+} + 3\mathrm{Cl}^{-}$
- $\mathrm{Cr(OH)}_{4}^{-}$ → 绿色沉淀：$\mathrm{Cr(OH)}_{4}^{-} + \mathrm{H}^{+} = \mathrm{Cr(OH)}_{3}\downarrow + \mathrm{H}_{2}\mathrm{O}$
- $\mathrm{MnO}_{4}^{2-}$ → 紫色溶液+棕色沉淀：$3\mathrm{MnO}_{4}^{2-} + 4\mathrm{H}^{+} = 2\mathrm{MnO}_{4}^{-} + \mathrm{MnO}_{2}\downarrow + 2\mathrm{H}_{2}\mathrm{O}$
- Fe²⁺和Ni²⁺ → 无明显变化

**第2步**：用已鉴出的 $\mathrm{Cr(OH)}_{4}^{-}$ 滴加到Fe²⁺和Ni²⁺中：
- Fe²⁺ → 沉淀迅速变红褐色（Fe(OH)₂→Fe(OH)₃氧化）
- Ni²⁺ → 绿色沉淀不变色

### 99.4 〔🟢 d3〕

> **来源**：第35届初赛第3题（原始文件：06-外部资料导入/真题/第35届初赛试题解析）
> **小问关联**：本文件为第 3 题第(2)小问；第(1)小问见 题-035-3-1-硫代硼酸二聚三聚结构；第(3)小问见 题-035-3-3-卟吩类似物芳香性

A（即题-035-3-1中的二聚体 $(\mathrm{HBS_2})_2$）和 $\mathrm{BCl_3}$ 按计量系数 $1:1$ 反应，得到相同计量系数的 $\mathrm{H_2S}$ 和另一产物 **C**（反应1），C 受热分解为 **D** 和 $\mathrm{BCl_3}$（反应2）。在低温惰性介质中 D 可以单分子形式存在，结构中有且仅有二重旋转轴以及过二重轴的两个镜面。

**3-2-1** 写出 **C** 生成（反应 1）和分解（反应 2）的反应方程式。

**3-2-2** C 易水解。写出 C 发生水解的反应方程式。

**3-2-3** 画出 **C** 和 **D** 的结构。

<details>
<summary>📖 查看答案</summary>

**得分点**：
1. **3-2-1 反应1正确**（1分）：$(\mathrm{HBS_2})_2 + \mathrm{BCl_3} \longrightarrow \mathrm{H_2S} + \mathrm{B_3S_3Cl_3}$
2. **3-2-1 反应2正确**（1分）：$\mathrm{B_3S_3Cl_3} \longrightarrow \mathrm{BCl_3} + \mathrm{B_2S_3}$
3. **3-2-2 水解方程式正确**（1.5分）：$\mathrm{B_3S_3Cl_3} + 9\mathrm{H_2O} \longrightarrow 3\mathrm{B(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}$
4. **3-2-3 C 的结构正确**（1分）：三个 Cl 取代三聚体 B 中三个端基 -SH 的结构
5. **3-2-3 D 的结构正确**（1.5分）：折线形 $\mathrm{B_2S_3}$（$C_{2v}$ 点群）

**完整推导**：

### 3-2-1 反应方程式

由于题目中给出了二聚体 A 与 $\mathrm{BCl_3}$ 反应（反应1）的计量系数，合理推测1当量的 $\mathbf{A} = (\mathrm{HBS_2})_2 = \mathrm{H_2B_2S_4}$ 与1当量的 $\mathrm{BCl_3}$ 反应，生成1当量的 $\mathrm{H_2S}$。

根据原子守恒，另一产物 **C** 的化学式应为 $\mathrm{B_3S_3Cl_3}$。

$\mathrm{B_3S_3Cl_3}$ 受热分解，生成 $\mathrm{BCl_3}$ 和另一产物 **D**（反应2）。假设反应物 $\mathrm{B_3S_3Cl_3}$ 中的1个B原子和3个Cl原子变为 $\mathrm{BCl_3}$，剩下的原子构成产物 **D**，即 **D** 分子式为 $\mathrm{B_2S_3}$。

$$
(\mathrm{HBS_2})_2 + \mathrm{BCl_3} \longrightarrow \mathrm{H_2S} + \mathrm{B_3S_3Cl_3} \quad (\text{反应 1})
$$

$$
\mathrm{B_3S_3Cl_3} \longrightarrow \mathrm{BCl_3} + \mathrm{B_2S_3} \quad (\text{反应 2})
$$

### 3-2-2 水解方程式

对比 **C**（$\mathrm{B_3S_3Cl_3}$）与硫代硼酸三聚体 B（$\mathrm{HBS_2})_3 = \mathrm{B_3S_6H_3}$ 的分子式，可推测 **C** 是 3 个 Cl 原子取代了 B 中三个巯基的结构。

**C** 中的 **B-Cl 键**极易水解（可以类比 $\mathrm{BCl_3}$ 极易水解为硼酸），但这里容易忽略的是 **B-S 键也会发生水解**：

- B 原子半径较小，S 原子半径较大，形成 B-S 键的轨道并不能很好地重叠
- O 原子的半径与 B 原子半径匹配，形成的 B-O 键更强
- 从软硬酸碱的角度来理解：B 是硬酸，O 是硬碱，S 是软碱；B-O 键比 B-S 键更稳定

若未考虑到 B-S 键的水解，只写出 B-Cl 键水解的部分水解方程式，只能拿到一半的分数。**C** 彻底水解的反应方程式为：

$$
\mathrm{B_3S_3Cl_3} + 9\mathrm{H_2O} \longrightarrow 3\mathrm{B(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}
$$

> 如果将含硼产物写为三聚硼酸 $\mathrm{B_3O_3(OH)_3} = \mathrm{B_3O_6H_3}$，也算正确：
> $$\mathrm{B_3S_3Cl_3} + 6\mathrm{H_2O} \longrightarrow \mathrm{B_3O_3(OH)_3} + 3\mathrm{H_2S} + 3\mathrm{HCl}$$

### 3-2-3 C 和 D 的结构

**C 的结构**：根据前一小问的分析，C 的结构是容易画出的——三个 Cl 原子取代三聚体 B 中三个端基 -SH 的结构，保持 $\mathrm{B_3S_3}$ 六元环骨架不变。

**D 的结构**：题目中给出了 $\mathbf{D} = \mathbf{B_2S_3}$ 的对称性信息：「有且仅有二重旋转轴以及过二重轴的两个镜面」。

对常见化合物对称性比较熟悉的同学应很快意识到，这与 $\mathrm{H_2O}$ 分子具有完全相同的对称元素（$C_{2v}$ 点群）。故 **D** 也应为**折线形结构**；其中的一个 S 原子作为中心原子，在中心原子的两侧对称地分布两个 $[\mathrm{BS}]$ 单元。

为使 S 原子满足 8 电子结构，两个 $[\mathrm{BS}]$ 单元应为 $\mathrm{B=S}$ 双键。B 原子虽然是 6 电子的缺电子中心，但可以通过形成离域 $\pi$ 键来削弱其缺电子性质。

**C 的结构**：六元环 $\mathrm{B_3S_3}$，每个 B 上连一个 Cl，每个 S 为桥连 S（保持与三聚体相同的骨架）。

**D 的结构**：
```
    S=B=S=B=S
      折线形，中心S
```
（实际为：中心S原子两侧对称分布 B=S 单元）

> 思考题：D 中的 B 原子能否画成折线形？给出理由。D 中形成了哪种离域 $\pi$ 键？

## 知识点映射

| 关联 KP | 考查角度 | 直接/间接 |
|---|---|:---:|
| 杂化轨道理论 | B 的三配位、S 的杂化与成键 | 直接 |
| 硼化学 | BCl₃ 的 Lewis 酸性、B-Cl 与 B-S 键的水解 | 直接 |
| 软硬酸碱理论 | B（硬酸）偏好 O（硬碱）而非 S（软碱） | 间接 |
| 分子对称性初步 | $C_{2v}$ 点群的识别（与 H₂O 相同） | 间接 |

## 解题思路

1. **读题定位**：看到「按计量系数1:1」「受热分解」「对称性」→ 识别为 **原子守恒 + 结构推断** 题
2. **3-2-1 推导C和D的分子式**：
   - A ($\mathrm{H_2B_2S_4}$) + $\mathrm{BCl_3}$ → $\mathrm{H_2S}$ + C
   - 原子守恒：C = $\mathrm{B_3S_3Cl_3}$
   - C 分解 → $\mathrm{BCl_3}$ + D，D = $\mathrm{B_2S_3}$
3. **3-2-2 水解方程式**：
   - **🔑 关键转换**：C 中既有 B-Cl 键又有 B-S 键，两者都会水解
   - B-Cl → B-OH + HCl；B-S → B-OH + H₂S
   - 彻底水解需 9 H₂O，生成 3 B(OH)₃ + 3 H₂S + 3 HCl
4. **3-2-3 D的结构**：
   - 对称性信息：仅有 $C_2$ 轴 + 2个镜面 → $C_{2v}$ 点群
   - 类比 H₂O → 折线形结构
   - 中心 S 原子，两侧对称分布 B=S 单元

## 易错分析

| 错误 | 原因 | 纠正 | 课堂提问 |
|---|---|---|---|
| 3-2-2 只写 B-Cl 水解 | 忽略了 B-S 键也会水解 | B-S 键轨道重叠差，B-O 键更强，故 B-S 也会水解 | 「B-S 键和 B-O 键哪个更强？为什么？」 |
| 3-2-2 产物写成 BCl₃ | 混淆了水解产物和热分解产物 | 水解产物是硼酸 B(OH)₃，热分解产物才是 BCl₃ | 「水解和热分解有什么区别？产物分别是什么？」 |
| 3-2-3 D 画成环状 | 未利用对称性信息 | $C_{2v}$ 点群要求折线形，不是环状 | 「H₂O 是什么形状？$C_{2v}$ 点群的典型分子有哪些？」 |
| 3-2-3 D 中 B 成键错误 | 未满足八隅体规则 | D 中 B=S 双键可使 B 满足 6 电子（缺电子），或通过离域 $\pi$ 键稳定 | 「B 原子满足八隅体吗？如何稳定缺电子中心？」 |

## 知识拓展

**B-S 键与 B-O 键的稳定性比较**：

从软硬酸碱理论（HSAB）来看：
- B³⁺ 是 **硬酸**（电荷密度高、极化性小）
- O²⁻ 是 **硬碱**（电负性高、极化性小）
- S²⁻ 是 **软碱**（电负性较低、极化性大、易变形）

根据「硬亲硬，软亲软」原则，B-O 键比 B-S 键更稳定。这也解释了为什么含 B-S 键的化合物（如本题中的 C）在水中容易发生 B-S → B-O 的转换。

> 也可以从轨道重叠的角度理解：B 原子半径较小，S 原子半径较大，形成 B-S 键的轨道并不能很好地重叠；而 O 原子的半径与 B 原子半径匹配，形成的 B-O 键更强。

### 99.5 〔🟢 d3〕

（题干见源文件）

<details>
<summary>📖 查看答案</summary>

**反应 1**（选择性去除 Al 层）：

$$
2\mathrm{Ti}_{3}\mathrm{AlC}_{2} + 6\mathrm{HF} \longrightarrow 2\mathrm{Ti}_{3}\mathrm{C}_{2} + 3\mathrm{H}_{2} + 2\mathrm{AlF}_{3}
$$

或：

$$
2\mathrm{Ti}_{3}\mathrm{AlC}_{2} + 8\mathrm{HF} \longrightarrow 2\mathrm{Ti}_{3}\mathrm{C}_{2} + 3\mathrm{H}_{2} + 2\mathrm{HAlF}_{4}
$$

或：

$$
2\mathrm{Ti}_{3}\mathrm{AlC}_{2} + 12\mathrm{HF} \longrightarrow 2\mathrm{Ti}_{3}\mathrm{C}_{2} + 3\mathrm{H}_{2} + 2\mathrm{H}_{3}\mathrm{AlF}_{6}
$$

**反应 2**（F 端基功能化）：

$$
\mathrm{Ti}_{3}\mathrm{C}_{2} + 2\mathrm{HF} \longrightarrow \mathrm{Ti}_{3}\mathrm{C}_{2}\mathrm{F}_{2} + \mathrm{H}_{2}
$$

**说明**：
- 反应 1 是氧化还原反应，将 "$\mathrm{Ti}_{3}\mathrm{C}_{2}$" 单元视为整体（反应前后不得失电子），等价于 Al 单质与 HF 溶液的反应。
- 题目未明确 HF 溶液的量，以上三个方程式均合理。

### 99.17 〔🟢 d4〕

硼酸 $\mathrm{H_3BO_3}$ 的 $K_{\mathrm{a}} = 5.8 \times 10^{-10}$，酸性极弱，不能直接用 $\mathrm{NaOH}$ 准确滴定。但加入甘露醇后，生成的络合酸 $K_{\mathrm{a}} \approx 10^{-4}$，可用酚酞作指示剂以 $\mathrm{NaOH}$ 准确滴定。(1) 解释硼酸为何不能直接用 $\mathrm{NaOH}$ 滴定；(2) 简述甘露醇增强硼酸酸性的原理，并写出相关反应式。

---

<details>
<summary>📖 查看答案</summary>

**(1) 硼酸不能直接滴定的原因**

$\mathrm{H_3BO_3}$ 的 $K_{\mathrm{a}} = 5.8 \times 10^{-10}$，酸性极弱。对于一元弱酸，准确滴定的判据为 $cK_{\mathrm{a}} \geq 10^{-8}$。即使硼酸浓度为 $1\,\mathrm{mol\cdot L^{-1}}$，$cK_{\mathrm{a}} \approx 5.8 \times 10^{-10} \ll 10^{-8}$，终点突跃极小，无法用指示剂准确判断终点。因此不能直接用 $\mathrm{NaOH}$ 标准溶液滴定。

**(2) 甘露醇增强酸性的原理**

硼酸并非 Brønsted 酸（质子酸），而是 **Lewis 酸**——硼原子为 $sp^2$ 杂化，有一个空的 $2p$ 轨道，可接受电子对。在水中硼酸实际上是通过接受 $\mathrm{OH^-}$ 而非电离 $\mathrm{H^+}$ 来表现酸性：
$$\mathrm{B(OH)_3 + H_2O \rightleftharpoons B(OH)_4^- + H^+} \quad K_{\mathrm{a}} = 5.8 \times 10^{-10}$$
甘露醇等多羟基化合物（含有邻位顺式二醇结构）与硼酸发生酯化反应，生成环状硼酸酯络合物：
$$\mathrm{H_3BO_3 + 2\,C_6H_{14}O_6 \longrightarrow H[B(C_6H_{12}O_6)_2] + 3H_2O}$$
该络合酸 $K_{\mathrm{a}} \approx 10^{-4} \sim 10^{-5}$，酸性比硼酸增强了约 5–6 个数量级，满足 $cK_{\mathrm{a}} \geq 10^{-8}$，可用酚酞作指示剂以 $\mathrm{NaOH}$ 标准溶液准确滴定：
$$\mathrm{H[B(C_6H_{12}O_6)_2] + NaOH \longrightarrow Na[B(C_6H_{12}O_6)_2] + H_2O}$$

> **方法要点**：极弱酸的强化滴定是通过化学转化将待测物转化为酸性更强的物质。类似方法还包括：$\mathrm{H_3BO_3}$ 加甘油强化、$\mathrm{NH_4^+}$ 用甲醛法强化（生成 $(\mathrm{CH_2})_6\mathrm{N_4H^+}$）、$\mathrm{H_2O_2}$ 的碘量法等。

**(1)** 单质硅具有较强的非金属性，所以硅不易与酸反应。氧化性的酸如 $\mathrm{HNO}_{3}$ 可以将 Si 氧化成 $\mathrm{SiO}_{2}$：

$$3 \mathrm{Si} + 4 \mathrm{HNO}_{3}(\text{浓}) = 3 \mathrm{SiO}_{2} + 4 \mathrm{NO} \uparrow + 2 \mathrm{H}_{2}\mathrm{O}$$

但是生成物 $\mathrm{SiO}_{2}$ 不溶于水，附在反应物 Si 的表面，使反应不能进行下去。

在加热条件下 Si 可与氢氟酸反应：

$$\mathrm{Si} + 4 \mathrm{HF} = \mathrm{SiF}_{4} \uparrow + 2 \mathrm{H}_{2} \uparrow$$

其原因是产物 $\mathrm{SiF}_{4}$ 挥发脱离体系，使反应进行彻底。

硅易与碱反应：

$$\mathrm{Si} + 2 \mathrm{NaOH} + \mathrm{H}_{2}\mathrm{O} = \mathrm{Na}_{2}\mathrm{SiO}_{3} + 2 \mathrm{H}_{2} \uparrow$$

这体现了硅的非金属性，而且产物为可溶性的 $\mathrm{Na}_{2}\mathrm{SiO}_{3}$，反应较为容易进行。

**(2)** $\mathrm{CCl}_{4}$ 分子中的 C 原子没有空的价层轨道，加之 C—Cl 键较强而难以解离，所以 $\mathrm{CCl}_{4}$ 不水解。

$$\mathrm{BCl}_{3} + 3 \mathrm{H}_{2}\mathrm{O} = \mathrm{B(OH)}_{3} + 3 \mathrm{HCl}$$

**17.48** 解释实验现象。

**(1)** 向KI溶液中滴加少量KClO溶液，溶液变黄。但向KClO溶液中滴加入少量KI溶液，溶液不变黄。

> 前者KI过量，生成的 $\mathrm{I_3^-}$ 不再反应，溶液显黄色；后者KClO过量，生成的 $\mathrm{I_2}$ 进一步被氧化为 $\mathrm{IO_3^-}$，溶液为无色。

**(2)** 向 $\mathrm{KClO_3}$ 溶液中加入少量浓盐酸，溶液不变黄；向浓盐酸中加入 $\mathrm{KClO_3}$ 晶体，则溶液变黄。

> 前者 $\mathrm{H^+}$ 浓度低，$\mathrm{KClO_3}$ 与HCl不反应；后者 $\mathrm{H^+}$ 浓度高，$\mathrm{KClO_3}$ 与HCl反应生成 $\mathrm{ClO_2}$（黄绿色，部分溶于水后溶液呈黄色）：
>
> $8\mathrm{KClO_3+24HCl=9Cl_2\uparrow+8KCl+6ClO_2\uparrow+12H_2O}$

**(3)** 向 $\mathrm{FeSO_4}$ 溶液中加入碘水，碘水不褪色；再加入 $\mathrm{NH_4F}$ 溶液，则碘水褪色。

> $E^{\ominus}(\mathrm{Fe^{3+}/Fe^{2+}})=0.771\mathrm{V}$，$E^{\ominus}(\mathrm{I_2/I^-})=0.535\mathrm{V}$。由于 $E^{\ominus}(\mathrm{I_2/I^-})<E^{\ominus}(\mathrm{Fe^{3+}/Fe^{2+}})$，碘水不能氧化 $\mathrm{Fe^{2+}}$。加入 $\mathrm{NH_4F}$ 溶液后，$\mathrm{F^-}$ 与 $\mathrm{Fe^{3+}}$ 生成稳定的配位化合物使 $\mathrm{Fe^{2+}}$ 的还原性增强，碘水褪色：
>
> $\mathrm{I_2+2Fe^{2+}+12F^-=2I^-+2[FeF_6]^{3-}}$

**(4)** NaClO溶液能够氧化 $\mathrm{I^-}$，而 $\mathrm{NaClO_3}$ 溶液却不能。

> NaClO的氧化性强于 $\mathrm{NaClO_3}$。$\mathrm{NaClO_3}$ 的氧化性依赖于介质，有酸存在时才具有氧化性。没有 $\mathrm{H^+}$，$\mathrm{ClO_3^-}$ 不能氧化 $\mathrm{I^-}$。
>
> $\mathrm{ClO^-}$ 氧化 $\mathrm{I^-}$ 的反应为：$\mathrm{ClO^-+2I^-+H_2O=Cl^-+I_2+2OH^-}$

**(5)** 浓 $\mathrm{HClO_4}$ 溶液能够氧化 $\mathrm{I_2}$，而稀 $\mathrm{HClO_4}$ 溶液却不能氧化 $\mathrm{I_2}$。

> 在浓溶液中，$\mathrm{HClO_4}$ 以分子形式存在，只有一个氧原子与质子结合，形成对称性较低的分子，同时 $\mathrm{H^+}$ 的反极化作用使高氯酸分子不稳定。所以浓 $\mathrm{HClO_4}$ 溶液有较强的氧化性：
>
> $2\mathrm{HClO_4(\text{浓})+I_2+4H_2O=2H_5IO_6+Cl_2\uparrow}$
>
> 稀溶液中，$\mathrm{HClO_4}$ 完全解离，$\mathrm{ClO_4^-}$ 为正四面体结构，对称性高，且不受 $\mathrm{H^+}$ 的反极化作用影响，比较稳定，所以氧化能力弱。

**(6)** 加热 $\mathrm{KClO_3}$ 固体无气体生成，但有 $\mathrm{MnO_2}$ 存在时却产生了气体。

> 没有催化剂时，$\mathrm{KClO_3}$ 歧化分解生成两种固体产物：
>
> $4\mathrm{KClO_3}\stackrel{\triangle}{=}3\mathrm{KClO_4+KCl}$
>
> 有 $\mathrm{MnO_2}$ 时，产生 $\mathrm{O_2}$：
>
> $2\mathrm{KClO_3}\xrightarrow[\triangle]{\mathrm{MnO_2}}2\mathrm{KCl+3O_2\uparrow}$

**(7)** $\mathrm{I_2}$ 溶于KI溶液后可能呈现不同的颜色。

> 由于 $\mathrm{I_2}$ 在KI溶液中的浓度不同，溶液的颜色不同。按照浓度由低到高，溶液可以是黄色、橙色、红色、棕色。

**17.49** 比较 $\mathrm{KI_3}$、$\mathrm{KIBr_2}$ 和 $\mathrm{KI_2Br}$ 的稳定性并说明原因。

**17.50** 比较下列各组酸强度的强弱，并简要说明理由。

**(1)** HF、HCl、HBr和HI。

> 酸性由强到弱顺序为HI、HBr、HCl、HF。除HF是弱酸外，其余均为强酸。
>
> $\mathrm{X^-}$ 对 $\mathrm{H^+}$ 的吸引力弱，则解离度大，溶液的酸性强。按 $\mathrm{I^-}$、$\mathrm{Br^-}$、$\mathrm{Cl^-}$、$\mathrm{F^-}$ 顺序，离子半径逐渐减小，电荷密度逐渐升高，对 $\mathrm{H^+}$ 的吸引力逐渐增大，导致解离度依次减小，酸性逐渐减弱。

**(2)** HClO、$\mathrm{HClO_2}$ 和 $\mathrm{HClO_3}$。

> 酸性依顺序HClO、$\mathrm{HClO_2}$、$\mathrm{HClO_3}$ 逐渐增强。随着中心原子Cl的氧化数增大，抵抗 $\mathrm{H^+}$ 的反极化作用的能力变大，$\mathrm{H-O-X}$ 中的 $\mathrm{HO-X}$ 键逐渐增强，$\mathrm{H-O}$ 键逐渐减弱，$\mathrm{H^+}$ 更易解离出，故酸性增强。

**(3)** $\mathrm{HClO_3}$、$\mathrm{HBrO_3}$ 和 $\mathrm{HIO_3}$。

> 从Cl到I，随原子序数增加，半径增大，电负性减小，拉动O原子电子云能力变小，$\mathrm{H-O-X}$ 中的 $\mathrm{HO-X}$ 键逐渐减弱，$\mathrm{H-O}$ 键逐渐增强，不易解离出 $\mathrm{H^+}$，所以酸性依次减弱。

**(4)** $\mathrm{HClO_4}$ 和 $\mathrm{H_3PO_4}$。

> Cl(VII)对氧原子的吸引力大于氢与氧的结合力，且Cl(VII)抵抗 $\mathrm{H^+}$ 的反极化作用的能力强，保持Cl—OH之间的强结合力，从而使O—H键的结合力被削弱，另外 $\mathrm{ClO_4^-}$ 的对称性高，稳定性好，所以高氯酸在水溶液中几乎完全解离，是无机酸中酸性最强的酸。
>
> $\mathrm{H_3PO_4}$ 分子内中心原子P(V)的吸电子能力弱于Cl(VII)，O—H键的结合力较强，不易解离出 $\mathrm{H^+}$，故酸性弱于 $\mathrm{HClO_4}$，为中强酸。

**17.51** 将下列各组物质的有关性质由大到小排序，并简要说明理由。

**(1)** 键解离能 $\mathrm{Cl_2}$、$\mathrm{Br_2}$ 和 $\mathrm{I_2}$。

> 从 $\mathrm{Cl_2}$ 到 $\mathrm{Br_2}$ 到 $\mathrm{I_2}$ 键的解离能逐渐下降。因为原子半径增大，在卤素双原子分子中，核对成键电子对的引力随原子半径增大而减小，所以解离能呈现逐渐下降的趋势。

**(2)** 溶解度 $\mathrm{HgF_2}$、$\mathrm{HgCl_2}$、$\mathrm{HgBr_2}$ 和 $\mathrm{HgI_2}$。

> 溶解度逐渐降低。由于 $\mathrm{F^-}$ 的半径小，变形性小，$\mathrm{HgF_2}$ 为离子化合物，溶解度最大。从 $\mathrm{Cl^-}$ 到 $\mathrm{Br^-}$ 到 $\mathrm{I^-}$ 半径逐渐增大，变形性逐渐变大，$\mathrm{HgX_2}$ 中键的共价成分越来越多，所以溶解度依次降低，$\mathrm{HgI_2}$ 难溶。

**(3)** 氧化性 $\mathrm{HClO}$、$\mathrm{HClO_3}$ 和 $\mathrm{HClO_4}$。

**(4)** 稳定性 $\mathrm{ClO_2}$ 和 $\mathrm{I_2O_5}$。

**17.52** 解释原因。

**(1)** 漂白粉长期暴露于空气中会失效。

> 漂白粉的有效成分是 $\mathrm{Ca(ClO)_2}$，在空气中吸收 $\mathrm{CO_2}$ 生成HClO：
>
> $\mathrm{Ca(ClO)_2+CO_2+H_2O=CaCO_3+2HClO}$
>
> HClO不稳定，易分解而失效：$2\mathrm{HClO=2HCl+O_2\uparrow}$
>
> HClO氧化性强，与HCl或漂白粉中的杂质 $\mathrm{CaCl_2}$ 反应也会损失有效成分：
>
> $\mathrm{HCl+HClO=Cl_2\uparrow+H_2O}$

**(2)** $\mathrm{AlF_3}$ 在温度高达1000 ℃时不熔化，而 $\mathrm{AlCl_3}$ 的熔点却只有192.6 ℃。

> 一般认为，两元素的电负性差大于1.7生成离子化合物，小于1.7生成共价化合物。Al与F的电负性差为2.37，$\mathrm{AlF_3}$ 为典型的离子化合物；Al与Cl的电负性差为1.55，$\mathrm{AlCl_3}$ 应为共价化合物。所以 $\mathrm{AlF_3}$ 的熔点比 $\mathrm{AlCl_3}$ 高得多。

**(3)** 氟的电子亲和能比氯小，但 $\mathrm{F_2}$ 却比 $\mathrm{Cl_2}$ 活泼。

> 氟为第二周期元素，半径特别小，富电子的F电子密度较大，生成 $\mathrm{F^-}$ 时放出的能量较少，因此氟的电子亲和能比氯小。
>
> $\mathrm{F_2}$ 比 $\mathrm{Cl_2}$ 活泼的原因：F的半径小，$\mathrm{F_2}$ 中孤电子对之间的斥力较大，使 $\mathrm{F_2}$ 的解离能远小于 $\mathrm{Cl_2}$；同时，氟化物的晶格能比氯化物大，氟化物的能量更低；此外，$\mathrm{F^-}$ 水合时放出的热量远多于 $\mathrm{Cl^-}$。

### 99.40 〔🟢 d4〕

**21.57** 计算在盐酸浓度为 $1\ \mathrm{mol\cdot dm^{-3}}$ 和 $12\ \mathrm{mol\cdot dm^{-3}}$ 时, $\mathrm{K}_{2}\mathrm{Cr}_{2}\mathrm{O}_{7}$ 能否将 $\mathrm{Cl}^{-}$ 氧化为 $\mathrm{Cl}_{2}$ 。

## 解答

盐酸浓度为 $1\ \mathrm{mol\cdot dm^{-3}}$ 时(标准状态下):

$$
E^{\ominus}(\mathrm{Cr}_{2}\mathrm{O}_{7}^{2-}/\mathrm{Cr}^{3+}) = E^{\ominus}(\mathrm{Cl}_{2}/\mathrm{Cl}^{-})
$$

考虑由 $\mathrm{Cl}^{-}$ 生成 $\mathrm{Cl}_{2}$ 时存在超电势, 所以 $\mathrm{K}_{2}\mathrm{Cr}_{2}\mathrm{O}_{7}$ 不能氧化 $1\ \mathrm{mol\cdot dm^{-3}}$ 盐酸中的 $\mathrm{Cl}^{-}$ 。

盐酸浓度为 $12\ \mathrm{mol\cdot dm^{-3}}$ 时, $c(\mathrm{H}^{+}) = c(\mathrm{Cl}^{-}) \approx 12\ \mathrm{mol\cdot dm^{-3}}$ 。由电极反应

$$
\mathrm{Cr}_{2}\mathrm{O}_{7}^{2-} + 14\mathrm{H}^{+} + 6\mathrm{e}^{-} = 2\mathrm{Cr}^{3+} + 7\mathrm{H}_{2}\mathrm{O}
$$

则 $Cr_{2}O_{7}^{2-}/Cr^{3+}$ 电对的电极电势(设 $Cr_{2}O_{7}^{2-}$ 和 $Cr^{3+}$ 的浓度符合标准状态):

$$
\begin{array}{r l} E & = E^{\ominus} + \frac{0.059\mathrm{V}}{6} \lg \frac{c(\mathrm{Cr}_{2}\mathrm{O}_{7}^{2-})^{14} [c(\mathrm{H}^{+})]^{14}}{c(\mathrm{Cr}^{3+})} \\ & = E^{\ominus} + \frac{0.059\mathrm{V}}{6} \lg [c(\mathrm{H}^{+})]^{14} = 1.36\mathrm{V} + \frac{0.059\mathrm{V}}{6} \lg (12)^{14} \\ & = 1.51\mathrm{V} \end{array}
$$

由电极反应

$$
\mathrm{Cl}_{2} + 2\mathrm{e}^{-} = 2\mathrm{Cl}^{-}
$$

则 $\mathrm{Cl}_{2}/\mathrm{Cl}^{-}$ 电对的电极电势（设 $\mathrm{Cl}_{2}$ 的分压符合标准状态）：

$$
\begin{array}{r l} E & = E^{\ominus} + \frac{0.059\mathrm{V}}{2} \lg \frac{p(\mathrm{Cl}_{2})/p^{\ominus}}{[c(\mathrm{Cl}^{-})/c^{\ominus}]^{2}} \\ & = E^{\ominus} + \frac{0.059\mathrm{V}}{2} \lg \frac{1}{[c(\mathrm{Cl}^{-})]^{2}} = 1.36\mathrm{V} + \frac{0.059\mathrm{V}}{2} \lg \frac{1}{12^{2}} \\ & = 1.30\mathrm{V} \end{array}
$$

因为 $E(\mathrm{Cr}_{2}\mathrm{O}_{7}^{2-}/\mathrm{Cr}^{3+}) = 1.51\mathrm{V} > E(\mathrm{Cl}_{2}/\mathrm{Cl}^{-}) = 1.30\mathrm{V}$ ，所以在浓盐酸中 $\mathrm{K}_{2}\mathrm{Cr}_{2}\mathrm{O}_{7}$ 可以将 $\mathrm{Cl}^{-}$ 氧化为 $\mathrm{Cl}_{2}$ 。

本题考查能斯特方程的应用。在标准状态下，K₂Cr₂O₇不能氧化稀盐酸中的Cl⁻（电极电势相等，且有超电势影响）。但在浓盐酸中，由于H⁺浓度增大，Cr₂O₇²⁻/Cr³⁺电对的电极电势升高（能斯特方程中H⁺的14次方项），而Cl⁻浓度增大使Cl₂/Cl⁻电对的电极电势降低，两者之差足以使氧化反应发生。这是实验室制备Cl₂的反应之一。

### 22.42 如何鉴别分别含有 Fe3+、Co2+ 和 Ni2+ 的溶液？

**答案**：

**Fe3+ 的鉴别：**

(1) 与 KSCN 作用产生血红色：

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n}\text{（血红色）}$$

(2) 与黄血盐 $\mathrm{K}_{4}[\mathrm{Fe}(\mathrm{CN})_{6}]$ 作用产生蓝色沉淀：

$$\mathrm{K}^{+} + \mathrm{Fe}^{3+} + [\mathrm{Fe}(\mathrm{CN})_{6}]^{4-} = \mathrm{K}[\mathrm{FeFe}(\mathrm{CN})_{6}]\downarrow\text{（蓝色）}$$

**Co2+ 的鉴别：**

加入饱和 KSCN 溶液及丙酮（或乙醚），在丙酮（或乙醚）层中产生蓝色：

$$\mathrm{Co}^{2+} + 4\mathrm{SCN}^{-} = [\mathrm{Co}(\mathrm{SCN})_{4}]^{2-}$$

若防止 $\mathrm{Fe}^{3+}$ 干扰 $\mathrm{Co}^{2+}$ 的鉴别，可加入 NaF 或 $\mathrm{NH}_{4}\mathrm{F}$ 掩蔽 $\mathrm{Fe}^{3+}$。

**Ni2+ 的鉴别：**

向溶液中滴加丁二酮肟，生成鲜红色沉淀，表示有 $\mathrm{Ni}^{2+}$ 存在。

### 22.45 如何在不引入杂质的情况下，将粗ZnSO4溶液中含有的Fe3+、Fe2+、Cu2+杂质除去？

### 3-3-1 E 的分子式与氧化态

白色固体 **E** 是 $\mathrm{B_2S_3}$ 与单质硫反应的产物，这是一个氧化还原反应。B 元素的常见价态为 +3，除硼烷类化合物以外，只有在比较苛刻的条件下 B 元素才会发生变价。故这个反应中应当只有 S 原子的氧化态发生改变：
- 还原剂 $\mathrm{B_2S_3}$ 中 S 为 $-2$ 价
- 氧化剂硫单质中 S 为 $0$ 价
- 联想到多硫离子的制备反应：$\mathrm{S^{2-}} + n\mathrm{S} \longrightarrow \mathrm{S_{n+1}^{2-}}$

在本题中，得到的是类似 $\mathbf{S_2^{2-}}$ 的结构（即每个新增 S 以 S-S 键形式嵌入）。

观察卟吩大环骨架的特征：
- 所有的 **8 个 B 原子位置均等价**，也即只存在 1 种 B 原子
- S 原子的位置有 **3 种**：
  1. 五元环内 B-S-B 位置的 4 个 **$-2$ 价 S 原子**
  2. 五元环外 B-S-B 位置的 4 个 **$-2$ 价 S 原子**
  3. 五元环内 B-S-S-B 位置的 8 个 **$-1$ 价 S 原子**

故能表示 E 组成特点的结构简式为：

$$
\begin{array}{l}
+3\quad -2\quad -2\quad -1 \\
(\mathrm{B_8})(\mathrm{S_4})(\mathrm{S_4})(\mathrm{S_2})_4
\end{array}
$$

官方答案中未区分两种不同环境的 $-2$ 价 S 原子，故将其合并起来写也算正确：

$$
\begin{array}{l}
+3\quad -2\quad -1 \\
(\mathrm{B_8})(\mathrm{S_8})(\mathrm{S_2})_4
\end{array}
$$

分子式为 $\mathbf{B_8S_{16}}$。

### 3-3-2 E 的经典 Lewis 结构

根据上一小问的结论，先将 B 原子和 S 原子放置在正确的位置（类似卟吩的平面大环骨架）。其中包含的 28 条 $\sigma$ 键形成了类似卟吩结构的骨架。

显然在此之外还需要有若干条 $\pi$ 键，来构建出类似卟吩的平面大环离域体系。问题在于 $\pi$ 键有几条？如何合理放置它们？

**计算共价键总数**：

共价键个数 $= \dfrac{8 \times \text{原子个数} - \text{所有原子价电子数总和}}{2}$

$\mathrm{B_8S_{16}}$ 共价键个数 $= \dfrac{8 \times 24 - (3 \times 8 + 6 \times 16)}{2} = \dfrac{192 - 120}{2} = 36$

再次观察骨架结构，可以发现其中的 8 个 B 原子如要满足八隅体结构，则必须形成双键，所以 **8 条 $\pi$ 键均应为 B=S 双键**。为保证 S 原子也满足八隅体规则，$\mathrm{B=S}$ 双键**不可以相邻**形成「$\mathrm{B=S=B}$」的结构。

> 2. 所有 S 原子满足八隅体
> 3. B=S 双键不相邻

### 3-3-3 芳香性判断

对于大环中稠环体系或轮烯体系的芳香性判断，在 E 的经典 Lewis 结构中，最大的共轭体系是硼硫交替的「内圈结构」，属于轮烯模型。

每个 B=S 双键都是 S 原子通过一对电子向 B 原子进行「配位」形成的，而 S 原子上剩余的一对孤对电子所处的轨道与离域 $\pi$ 轨道**正交**，不参与离域。故共轭体系中总的 $\pi$ 电子数为：

$$8 \times 2 = 16$$

根据 Hückel 规则，芳香性要求 $\pi$ 电子数为 $4n+2$。$16 = 4n$（$n=4$），不符合 $4n+2$ 规则。

## 知识拓展

**大环共轭体系的芳香性判断**：

对于含有杂原子的大环共轭体系，判断芳香性时需注意：

1. **哪些原子参与共轭**：通常只考虑形成连续共轭链的原子
2. **每个原子贡献多少 $\pi$ 电子**：
   - 双键：2 个 $\pi$ e⁻
   - 杂原子的孤对电子：若该孤对电子所在的 p 轨道与环平面垂直，则参与共轭；若平行（或近似平行），则不参与
3. **Hückel 规则**：$\pi$ 电子数为 $4n+2$ 时具有芳香性

在本题中，S 原子上有两对孤对电子：
- 一对用于形成 B=S 的 $\pi$ 键（配位键）
- 另一对处于与 $\pi$ 体系正交的轨道中，不参与离域

这正是 $4n$（而非 $4n+2$）的原因，也是该大环**无芳香性**的关键。

## 知识拓展

**全碳环（cyclo[n]carbon）的研究进展**：

在碳的同素异形体家族中：
- 金刚石：$\mathrm{sp}^3$ 杂化，三维网络
- 石墨烯、富勒烯、碳纳米管：$\mathrm{sp}^2$ 杂化，平面环系
- 全碳环：$\mathrm{sp}$ 杂化，环状分子

自 1966 年 Hoffmann 首次预言 $\mathrm{C_{18}}$ 的存在以来，其合成始终是碳材料科学领域的「圣杯」级难题。2019 年，IBM-牛津大学联合团队通过精密设计的脱羧反应策略，在 $5\,\mathrm{K}$ 的超低温环境下，利用原子力显微镜（AFM）首次捕获到 $\mathrm{C_{18}}$ 分子的真实形貌。

**全碳环的双芳香性**：

环系上所有的 C 原子均存在 2 条正交的 p 轨道，形成了垂直于环平面与朝向环平面内的 2 个正交的离域 $\pi$ 体系。这种罕见的双芳香性导致理论化学界对全碳环的键型产生重大分歧——键长平均化（累积双键）与键长交替（单、叁键交替）两种模型长期对峙。

AFM 成像显示 $\mathrm{C_{18}}$ 存在约 $15\,\mathrm{pm}$ 的键长差异（典型 C-C 单键约 $154\,\mathrm{pm}$，C≡C 叁键约 $120\,\mathrm{pm}$），而 $\mathrm{C_{10}}$ 和 $\mathrm{C_{14}}$ 则呈现更平均化的键长分布。这说明 $\mathrm{C_{18}}$ 实际处于两种极限结构的中间态，正是量子化学中电子离域与环张力动态平衡的直观体现。

由(3)可知，加 KSCN 无颜色变化，说明 $\mathrm{FeCl}_{3}$ 与 $\mathrm{SnCl}_{2}$ 共存（Fe3+被还原为Fe2+）。加入戊醇也无颜色变化，说明 $\mathrm{CoCl}_{2}$ 肯定不存在。

由(4)可知，加入过量 NaOH 时溶液几乎无色，则肯定不存在 $\mathrm{CuSO}_{4}$（否则有蓝色 $\left[\mathrm{Cu}(\mathrm{OH})_{4}\right]^{2-}$）。考虑到(2)的结果，$\mathrm{NiSO}_{4}$ 肯定存在。加盐酸酸化时，有白色沉淀生成，说明存在 $\mathrm{ZnSO}_{4}$ 或 $\mathrm{SnCl}_{2}$ 中的一种或两种：

$$\left[\mathrm{Zn}(\mathrm{OH})_{4}\right]^{2-} + 2\mathrm{H}^{+} = \mathrm{Zn}(\mathrm{OH})_{2}\downarrow + 2\mathrm{H}_{2}\mathrm{O}$$

$$\left[\mathrm{Sn}(\mathrm{OH})_{4}\right]^{2-} + 2\mathrm{H}^{+} = \mathrm{Sn}(\mathrm{OH})_{2}\downarrow + 2\mathrm{H}_{2}\mathrm{O}$$

由(5)可知，混合物中肯定不存在 KI，因 AgI 为黄色沉淀。沉淀溶于氨水，说明沉淀为 AgCl。

**综合结论**：混合物中肯定存在 $\mathrm{FeCl}_{3}$、$\mathrm{SnCl}_{2}$ 和 $\mathrm{NiSO}_{4}$；肯定不存在 $\mathrm{CuSO}_{4}$、$\mathrm{CoCl}_{2}$ 和 KI；而 $\mathrm{ZnSO}_{4}$ 是否存在还需进一步实验确认。

### 22.57 K3[Fe(C2O4)3]·3H2O中FeC2O4杂质含量测定

某同学在确定所合成的 $\mathrm{K}_{3}\left[\mathrm{Fe}\left(\mathrm{C}_{2}\mathrm{O}_{4}\right)_{3}\right]\cdot3\mathrm{H}_{2}\mathrm{O}$ 晶体中 $\mathrm{FeC}_{2}\mathrm{O}_{4}$ 杂质的含量时，进行了以下实验：将一定量样品加入稀硫酸中，微热溶解后用 $0.0500\ \mathrm{mol}\cdot\mathrm{dm}^{-3}$ 高锰酸钾溶液滴定，用去 $108.00\ \mathrm{cm}^{3}$；再加入适量还原剂将三价铁还原为二价铁后，用 $\mathrm{KMnO}_{4}$ 溶液滴定，恰好用去 $20.00\ \mathrm{cm}^{3}$。

(1) 给出滴定反应的离子反应方程式；
(2) 计算所合成产品的组成（不考虑结晶水）。

**答案**：

**(1) 滴定反应的离子方程式：**

$$2\mathrm{MnO}_{4}^{-} + 5\mathrm{C}_{2}\mathrm{O}_{4}^{2-} + 16\mathrm{H}^{+} = 2\mathrm{Mn}^{2+} + 10\mathrm{CO}_{2}\uparrow + 8\mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{MnO}_{4}^{-} + 5\mathrm{Fe}^{2+} + 8\mathrm{H}^{+} = \mathrm{Mn}^{2+} + 5\mathrm{Fe}^{3+} + 4\mathrm{H}_{2}\mathrm{O}$$

**(2) 计算产品组成：**

设混合物中有 $x\ \mathrm{mol}\ \mathrm{K}_{3}[\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]\cdot3\mathrm{H}_{2}\mathrm{O}$，$y\ \mathrm{mol}\ \mathrm{FeC}_{2}\mathrm{O}_{4}$，则有：

$$\begin{cases}(3x+y)\times\dfrac{2}{5}+y\times\dfrac{1}{5}=0.05\times\dfrac{108}{1000}\\[6pt](x+y)\times\dfrac{1}{5}=0.05\times\dfrac{20}{1000}\end{cases}$$

解得 $x=0.004$，$y=0.001$。

**产物组成为** $4\mathrm{K}_{3}\left[\mathrm{Fe}\left(\mathrm{C}_{2}\mathrm{O}_{4}\right)_{3}\right]\cdot1\mathrm{FeC}_{2}\mathrm{O}_{4}$。

### 22.58 混合物定性分析

有一固体混合物可能含有 $\mathrm{FeCl}_{3}$、$\mathrm{NaNO}_{2}$、$\mathrm{Ca(OH)}_{2}$、$\mathrm{AgNO}_{3}$、$\mathrm{CuCl}_{2}$、$\mathrm{NaF}$、$\mathrm{NH}_{4}\mathrm{Cl}$ 七种物质中的若干种。若将此混合物加水后，可得白色沉淀和无色溶液，在此无色溶液中加入 KSCN 没有变化；无色溶液可使酸化的 $\mathrm{KMnO}_{4}$ 溶液紫色褪去；将无色溶液加热有气体放出。另外，白色沉淀可溶于 $\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O}$ 中。试根据上述现象，判断在混合物中，哪些物质肯定存在，哪些肯定不存在，哪些可能存在，说明理由，并用化学反应方程式表示。

**答案**：

**肯定存在**：$\mathrm{NaNO}_{2}$、$\mathrm{AgNO}_{3}$、$\mathrm{NH}_{4}\mathrm{Cl}$

**肯定不存在**：$\mathrm{CuCl}_{2}$、$\mathrm{Ca(OH)}_{2}$

**可能存在**：$\mathrm{NaF}$、$\mathrm{FeCl}_{3}$

理由如下：

(1) 混合物加水后可得白色沉淀和无色溶液，说明混合物中不含带颜色的离子 $\mathrm{Cu}^{2+}$，即不存在 $\mathrm{CuCl}_{2}$。

(2) 无色溶液可使 $\mathrm{MnO}_{4}^{-}$ 褪色，说明混合物中有还原剂存在，即 $\mathrm{NaNO}_{2}$ 存在：

$$5\mathrm{NaNO}_{2} + 2\mathrm{MnO}_{4}^{-} + 6\mathrm{H}^{+} = 2\mathrm{Mn}^{2+} + 5\mathrm{NaNO}_{3} + 3\mathrm{H}_{2}\mathrm{O}$$

(3) 加热溶液有气体放出，则混合物中存在 $\mathrm{NH}_{4}\mathrm{Cl}$，$\mathrm{NaNO}_{2}$ 与 $\mathrm{NH}_{4}\mathrm{Cl}$ 在一起加热有 $\mathrm{N}_{2}$ 生成：

$$\mathrm{NH}_{4}\mathrm{Cl} + \mathrm{NaNO}_{2} = \mathrm{NaCl} + 2\mathrm{H}_{2}\mathrm{O} + \mathrm{N}_{2}\uparrow$$

(4) 加水后有白色沉淀，它又溶于 $\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O}$，说明混合物中有 $\mathrm{AgNO}_{3}$，与体系中的 $\mathrm{NH}_{4}\mathrm{Cl}$ 作用生成 AgCl 沉淀，后溶于 $\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O}$：

$$\mathrm{Ag}^{+} + \mathrm{Cl}^{-} = \mathrm{AgCl}\downarrow$$

$$\mathrm{AgCl} + 2\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = [\mathrm{Ag}(\mathrm{NH}_{3})_{2}]^{+} + \mathrm{Cl}^{-} + 2\mathrm{H}_{2}\mathrm{O}$$

(5) 从以上反应中可以看出，溶液中不存在 $\mathrm{Ca(OH)}_{2}$。因为溶液中含有 $\mathrm{NH}_{4}^{+}$，若 $\mathrm{Ca(OH)}_{2}$ 存在，则应有 $\mathrm{NH}_{3}$ 生成，实验中无 $\mathrm{NH}_{3}$ 气体生成。

(6) 混合物中可能含有 $\mathrm{FeCl}_{3}$、$\mathrm{NaF}$，但二者必须同时存在。因为若无 $\mathrm{NaF}$ 存在，则 $\mathrm{FeCl}_{3}$ 会显颜色，并与 KSCN 作用生成血红色物质。但有 NaF 时 $\mathrm{FeCl}_{3}$ 可能同时存在，它可形成 $\left[\mathrm{FeF}_{6}\right]^{3-}$，无色且不易与 $\mathrm{SCN}^{-}$ 作用。
