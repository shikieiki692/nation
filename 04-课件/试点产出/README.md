# 试点产出

> **定位**：`01-备课` 之外，用于存放「试点 / 试验性」生成的成品文件（课件 pptx、上课大纲 docx、PDF 渲染、页面预览 png 等），与正式沉淀到 `<04-课件>` 各章节的文件区分开。本目录下的文件多为流水线 / 渲染过程的产物，不直接作为讲义素材引用。

## 内容组织

| 类型 | 示例 | 说明 |
|:---|:---|:---|
| 课件源文件 | `*-课件.pptx` | 可编辑幻灯片 |
| 上课大纲 | `*-上课大纲.docx` | 教案 / 大纲文档 |
| PDF 渲染 | `*.pdf` | docx 渲染的最终阅读版 |
| 渲染预览 | `*/page-*.png`、`_render/`、`-render/` | 逐页渲染预览图（供快速查看） |
| 过程产物 | `*.inspect.ndjson` | 中间检查 / 日志文件，可清理 |

## 约定

- 命名：`YYYY-MM-DD-主题-课型-文件作用.扩展名`。
- `_render/` / `-render/` 子目录存放对应主文件的逐页渲染；若主文件已删除，其渲染目录可一并清理。
- 正式课件请使用 `<04-课件>` 相应章节路径 + `01-备课` 工作流，本目录仅作试点沉淀。
