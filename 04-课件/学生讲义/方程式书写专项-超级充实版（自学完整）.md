>
> **适用**：第一轮基础班（⭐~⭐⭐⭐）｜第二轮强化与元素推断衔接（⭐⭐⭐⭐）

## 学习目标

- ✅ 能先判断题目属于**哪一类**方程式题（纯配平 / 存在形体 / 图景推断 / 数据反推 / 极简信息），不盲目上手配平。
- ✅ 能根据「沉淀、气体、弱电解质、水、配位、两性溶解」等驱动力，写出第一轮常见的非氧化还原方程式。
- ✅ 能掌握离子方程式「拆 / 留 / 删」规则，并用原子守恒、电荷守恒自查。
- ✅ 能熟练判定氧化态与介质条件，使用离子-电子法（半反应法）配平常见氧化还原方程式。
- ✅ 能熟记常见氧化剂在不同介质中的典型还原产物，建立「介质优先」思维。
- ✅ **（第二轮）** 能判断溶液中物种的真实存在形体（酸碱、配位、水解、沉淀），把「产物」写对。
- ✅ **（第二轮）** 能在信息少时先判断「谁在推动反应、谁是主产物」（化学图景），再动笔。
- ✅ **（第二轮）** 能对困难骨架用叠加法拆子反应、对给数据题用「设未知量 + 守恒」反推组成。

## 本讲主线

方程式题的最大误区是「一上来就凑系数」。正确的顺序是：

```
拿到题 → ①判题型（五类分流）→ ②定介质/氧化态 → ③判存在形体 → ④搭骨架（或拆反应/数据反推）→ ⑤配平 → ⑥守恒验证
```

| 层级 | 你要先想什么 | 主工具 | 对应节 |
|:---|:---|:---|:---|
| 0 | 这题属于哪一类？ | 五类题型分流 | §一 |
| 1 | 什么介质？谁变价？ | 介质判断 + 氧化态 | §二 |
| 2 | 产物在溶液里长什么样？ | 存在形体判断 | §三 |
| 3 | 信息少，先看谁主谁次 | 化学图景 | §四 |
| 4 | 骨架难凑，拆子反应 | 叠加法 | §五 |
| 5 | 有数据，反推组成 | 设未知量 + 守恒 | §六 |
| 6 | 写半反应、合并、检查 | 离子-电子法 | §七 |

> **做题口令**：先判题型，再判介质；先判产物，再谈配平；最后一定检查原子守恒和电荷守恒。

## 一、方程式题五类分流（先判题型）

> [!tip] 核心纠偏
> 很多学生不是「不会配平」，而是第一步就把题型认错了。复分解题硬上半反应法，氧化还原题只靠观察法，都会越写越乱。**先分类，再选工具。**

| 题型 | 特征 | 主工具 | 典型信号 |
|:---|:---|:---|:---|
| ① 纯配平题 | 反应骨架已知，只是系数难定 | **叠加法 / 待定系数法** | 「配平下列方程式」 |
| ② 存在形体题 | 产物大致知道，但溶液中真实形态不清 | **酸碱 / 配位 / 沉淀 / 水解判断** | 「写出离子方程式」「通入 X 溶液」 |
| ③ 图景推断题 | 提示少，需先判断最可能反应逻辑 | **化学图景** | 现象描述、陌生体系 |
| ④ 数据反推题 | 给质量分数、失重、摩尔比、式量 | **设未知量 + 代数约束** | 「对 H₂ 相对密度为 23」 |
| ⑤ 极简信息题 | 条件看似不够 | **简单处理**（走最基本反应） | 信息极少、防过拟合 |

> **优先级**：先看能不能**拆反应**（叠加法）→ 再看要不要**改物种存在形式**（存在形体）→ 再看是否必须**先讲清反应图景** → 再看是否**借数据反推** → 最后才用「机理与配凑」硬推。

## 二、介质判断与氧化态判定（所有题的地基）

### 2.1 氧化态判定规则

| 规则 | 内容 | 例外 |
|:---|:---|:---|
| 单质 | 元素氧化态为 0 | — |
| 离子化合物 | 氧化态 = 离子电荷 | — |
| 共价化合物 | 电负性大的原子得电子（负氧化态） | — |
| H | 通常为 +1 | 金属氢化物中为 −1（NaH、CaH₂） |
| O | 通常为 −2 | 过氧化物 −1（H₂O₂）、超氧化物 −1/2（KO₂）、OF₂ 中 +2 |
| 分子总电荷 | 各原子氧化态代数和 = 分子总电荷 | — |

> **示例**：Cr₂O₇²⁻ 中 O 为 −2，总电荷 −2，设 Cr 为 x：2x + 7×(−2) = −2 → x = +6。
> **多原子变价务必乘原子个数**：Cr₂O₇²⁻ 含 2 个 Cr，整体得 **6e⁻**；As₂S₃ 含 2 个 As + 3 个 S。

### 2.2 介质判断

| 判断依据 | 酸性介质 | 碱性介质 | 中性介质 |
|:---|:---|:---|:---|
| 题目明确说明 | 「酸性条件」「稀 H₂SO₄」 | 「碱性条件」「NaOH」 | 「中性」「水溶液」 |
| 反应物特征 | 含 H⁺、强酸 | 含 OH⁻、强碱 | 无强酸强碱 |
| 产物提示 | 生成 CO₂（碳酸盐分解） | 生成 CO₃²⁻ | 视情况而定 |

> **核心纪律**：**碱性条件绝不允许出现游离 H⁺，酸性条件绝不允许出现游离 OH⁻。**

## 三、存在形体判断（把「产物」写对的关键）

> [!tip] 这层最有「竞赛味」
> 方程式题不是只看元素守恒，而是要写出**题目条件下真实存在的主要物种**。很多时候配平对了、电荷平了，但**物种写错了**——例如弱碱性下硬写 OH⁻ 并列、Ti(IV) 不写成 TiO²⁺、沉淀又被后续氧化/配位/歧化「吃」掉。

### 3.1 四个课堂按钮

1. **先看介质**：强酸、弱酸、弱碱、强碱、非水体系。
2. **再看中心粒子高价是否水解**：如 Ti(IV) 常写成 TiO²⁺、Fe(III) 在水溶液中实际以水合离子存在。
3. **再看生成的酸碱是否继续反应**：如产生的 OH⁻ 会不会被缓冲体系消掉，写 HSO₃⁻ 还是 SO₃²⁻。
4. **最后看配合物 / 沉淀是否改变主物种**：如 AgCl 遇 NH₃ 变为 [Ag(NH₃)₂]⁺、硫化物沉淀是否继续被氧化。

### 3.2 常见误判清单

| 误判 | 正确理解 |
|:---|:---|
| 酸碱性错 | 先定介质再写 H⁺/OH⁻ |
| 水解产物没改写 | 高电荷离子（Fe³⁺、Al³⁺）与 CO₃²⁻ 双水解 → 沉淀 + 气体 |
| 配合物先解离还是先参与没想清 | 配位可拉动沉淀溶解（AgCl + NH₃、王水溶金） |
| 沉淀被后续氧化/配位/歧化没跟 | Ag₂SO₄ + S：Ag₂S 沉淀拉动硫歧化 |
| 有机边缘题未写质子化形式 | 胺在无机口径下应写成质子化形式 |

> **例**（弱碱性）：弱碱性条件下 OH⁻ 不能粗暴并列，要结合缓冲体系改写到 HSO₃⁻/SO₃²⁻ 的实际分布。

## 四、化学图景推断（信息少时先看谁主谁次）

> 当题目提示少、反应陌生时，最忌讳直接瞎猜产物。先判断：**哪个物质最可能被氧化/还原/歧化？哪个更像驱动力而不是主反应物？哪个已知经验能解释现象？**

### 4.1 三步

1. 从「颜色 / 沉淀 / 气体 / 光照 / 溶剂」推反应类型。
2. 从常见通性出发：非金属在碱性下易歧化；光敏配合物易光还原；复合氧化物可形式拆成简单组分。
3. 先看「**谁在推动反应**」，再看「谁是最终主产物」。

### 4.2 常见通性弹药库

| 现象/触发词 | 优先想到的反应逻辑 |
|:---|:---|
| 光照 | 光敏组分（卤化银、普鲁士蓝、Fe 配合物）光还原 |
| 强碱共煮 | 非金属歧化、铝/锌两性溶解 |
| 非水体系 | 溶剂参与或溶剂解反应 |
| 配位后再氧化 | 配位降低电势（王水溶金、硫脲溶金） |
| 复合氧化物 | 形式拆成简单氧化物再叠加 |

## 五、叠加法配平（困难骨架拆子反应）

化学方程式本质是「等式」，可形式叠加。当**未知系数数多于独立守恒方程数**时，单纯待定系数法不够，需要拆成若干更简单的反应再叠加。

### 5.1 判断标准

| 情形 | 处理 |
|:---|:---|
| 元素守恒方程数 + 1 = 未知系数数 | 通常可唯一配平 |
| 元素守恒方程数 + 1 < 未知系数数 | **需要拆反应（叠加法）** |
| 元素守恒方程数 + 1 > 未知系数数 仍难配平 | 怀疑反应骨架本身写错了 |

### 5.2 示例：BrF₃ + H₂O

> 这不是「难配平」，而是同时存在多个子过程：
> - BrF₃ 水解生成 Br(III) 的含氧酸：BrF₃ + 3H₂O → HBrO₃ + 5HF（部分 Br 保持 +3）
> - 部分 Br(III) 又被体系还原为 Br₂、同时水被氧化放出 O₂
>
> 把子过程按电子守恒叠加，取最简整数比：
> $$\mathrm{3BrF_3 + 5H_2O \longrightarrow HBrO_3 + Br_2 + 9HF + O_2}$$

> **叠加法不仅是配平工具，更是「识别反应由哪些子过程组成」的思维方法**——这恰好也是化学图景的进阶形态。

## 六、借助数据反推（方程式题与推断题的交界）

给数据时，不要只想配平，要想「**反推物种**」：质量分数、元素分析、失重、平均式量、气体摩尔比、投料比。

### 6.1 策略

1. 把未知化合物设成尽量一般的形式（如 XeFₓ、NOₓ、NiₓBᵧ）。
2. 用最硬的数据先确定元素个数关系（相对密度 → 式量；质量分数 → 原子数比）。
3. 再用价态、常见结构、化学合理性排除不合理解。
4. 最后回写总方程式。

### 6.2 示例：某氮氧化物与水

见 §十 例 9（数据反推：式量 + 元素分析 → NO₂；产物量比 → 3NO₂ + H₂O → 2HNO₃ + NO）。

## 七、离子-电子法五步配平（氧化还原主工具）

### 7.1 配平口诀

> **介质定 → 产物定 → 原子平 → 电荷平**
> 完整五动作：`判介质 → 拆半反应 → 配非 H/O → 配 H/O → 配电荷并合并`

### 7.2 五步详解（以 MnO₄⁻ 酸性还原为 Mn²⁺ 为例）

| 步骤 | 操作 | 示例 |
|:---:|:---|:---|
| ① 写骨架 | 写出氧化/还原半反应骨架 | MnO₄⁻ → Mn²⁺ |
| ② 配非 H/O | 配平除 H、O 外的原子 | 已平（1 个 Mn） |
| ③ 配 O | 缺 O 一侧加 H₂O | MnO₄⁻ → Mn²⁺ + 4H₂O |
| ④ 配 H | 酸性加 H⁺，碱性加 OH⁻ | MnO₄⁻ + 8H⁺ → Mn²⁺ + 4H₂O |
| ⑤ 配电荷 | 用 e⁻ 平衡两侧电荷 | MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O |

**碱性快捷法**：先按酸性配平，再两边加等量 OH⁻ 中和 H⁺，合并 H⁺ + OH⁻ → H₂O，最后化简（碱性半反应中不含游离 H⁺ ✓）。

## 八、常见氧化剂不同介质还原产物速查表

| 氧化剂 | 酸性介质 | 中性/弱碱性 | 强碱性介质 |
|:---|:---|:---|:---|
| KMnO₄ | **Mn²⁺**（近无色） | **MnO₂↓**（棕黑） | **MnO₄²⁻**（绿色） |
| K₂Cr₂O₇ | **Cr³⁺**（绿色） | — | — |
| HNO₃（浓） | **NO₂** | — | — |
| HNO₃（稀） | **NO** | — | — |
| H₂SO₄（浓） | **SO₂** | — | — |
| H₂O₂ | **H₂O** | H₂O（或 O₂↑） | — |
| Cl₂ | Cl⁻ | Cl⁻ / ClO⁻（歧化） | Cl⁻ / ClO⁻（冷）或 ClO₃⁻（热） |

**记忆要点**：
- MnO₄⁻：酸性降 5 价（+7→+2）、中性降 3 价（+7→+4）、碱性降 1 价（+7→+6）
- Cr₂O₇²⁻：只在酸性作氧化剂，每个 Cr 得 3e⁻，**整体得 6e⁻**
- Cl₂ 歧化：冷稀碱 → Cl⁻ + ClO⁻；热浓碱 → Cl⁻ + ClO₃⁻（温度影响产物）

**常见离子颜色**：MnO₄⁻ 紫红｜MnO₄²⁻ 绿｜Mn²⁺ 浅粉｜Cr₂O₇²⁻ 橙红｜Cr³⁺ 绿/紫｜Fe²⁺ 浅绿｜Fe³⁺ 淡黄｜Cu²⁺ 蓝

## 九、默认反应源（元素化学产物线）

> 很多方程式题表面考「配平」，前半步考的是「**你知不知道这个体系通常生成什么**」。

| 反应线 | 第一轮最低要求 | 代表方程式 |
|:---|:---|:---|
| 氯气歧化线 | 区分水、冷稀碱、热浓碱三种产物 | Cl₂ + H₂O ⇌ HCl + HClO；Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O；3Cl₂ + 6OH⁻ → 5Cl⁻ + ClO₃⁻ + 3H₂O |
| 氯酸盐/二氧化锰制氯线 | 知道浓盐酸既给酸性又给 Cl⁻ | MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O；KClO₃ + 6HCl → KCl + 3Cl₂↑ + 3H₂O |
| 硫化物/亚硫酸盐放气线 | 见酸先想 H₂S、SO₂ 逸出 | S²⁻ + 2H⁺ → H₂S↑；SO₃²⁻ + 2H⁺ → SO₂↑ + H₂O |
| 硫化氢还原性线 | 知道 H₂S 常被氧化到单质硫 | H₂S + Cl₂ → 2HCl + S↓；Cr₂O₇²⁻ + 3H₂S + 8H⁺ → 2Cr³⁺ + 3S↓ + 7H₂O |
| 铵盐与硝酸线 | 区分「铵盐遇碱放氨」与「稀/浓硝酸产物不同」 | NH₄⁺ + OH⁻ → NH₃↑ + H₂O；Cu 遇稀硝酸产 NO、浓硝酸产 NO₂ |
| 两性金属与水解线 | 会写 Al/Zn 两性反应；Fe³⁺ + CO₃²⁻ 不停留在碳酸盐 | Al(OH)₃ + OH⁻ → [Al(OH)₄]⁻；Zn(OH)₂ + 2OH⁻ → [Zn(OH)₄]²⁻；2Fe³⁺ + 3CO₃²⁻ + 3H₂O → 2Fe(OH)₃↓ + 3CO₂↑ |

### 别写错产物清单（课堂快问快答）

| 看到的反应物 | 先调哪条线 | 默认主产物 | 最常见误写 |
|:---|:---|:---|:---|
| Cl₂ + H₂O | 卤素含氧酸线 | HCl + HClO | 只想到「溶于水」 |
| Cl₂ + OH⁻（冷稀） | 氯气歧化线 | Cl⁻ + ClO⁻ | 直接写 ClO₃⁻ |
| Cl₂ + OH⁻（热浓） | 次氯酸盐继续歧化 | Cl⁻ + ClO₃⁻ | 停在 ClO⁻ |
| MnO₂ + HCl(浓) | 制氯线 | MnCl₂ + Cl₂ + H₂O | 只按「酸 + 碱性氧化物」 |
| KClO₃ + HCl | 归中线 | KCl + Cl₂ + H₂O | 误判成全部到 Cl⁻ |
| Fe³⁺ + CO₃²⁻（溶液） | 水解线 | Fe(OH)₃ + CO₂ | 生搬硬套 Fe₂(CO₃)₃ |
| Cu + HNO₃（稀/浓） | 硝酸线 | NO / NO₂ | 看到酸就写 H₂ |
| S²⁻、SO₃²⁻ + H⁺ | 放气线 | H₂S / SO₂ | 只写「生成相应弱酸」就停 |

## 十、典型例题串讲

### 例 1 — KMnO₄ 在不同介质中氧化 Na₂SO₃ ⭐⭐⭐（介质优先）

**题目**：分别写出 KMnO₄ 在酸性、中性、碱性介质中氧化 Na₂SO₃ 的离子方程式。

**思路**：先判断介质 → 确定 MnO₄⁻ 还原产物 → 用离子-电子法配平。

**解答**：
- 酸性（MnO₄⁻ → Mn²⁺）：$$\mathrm{2MnO_4^- + 5SO_3^{2-} + 6H^+ \longrightarrow 2Mn^{2+} + 5SO_4^{2-} + 3H_2O}$$
- 中性（MnO₄⁻ → MnO₂）：$$\mathrm{2MnO_4^- + 3SO_3^{2-} + H_2O \longrightarrow 2MnO_2\downarrow + 3SO_4^{2-} + 2OH^-}$$
- 碱性（MnO₄⁻ → MnO₄²⁻）：$$\mathrm{2MnO_4^- + SO_3^{2-} + 2OH^- \longrightarrow 2MnO_4^{2-} + SO_4^{2-} + H_2O}$$

**教学要点**：同一反应物在不同介质中产物完全不同，**「介质优先」是配平第一原则**。
> 相关真题：[[题-038-2-1-KMnO4浓度测定计算]]（酸性 KMnO₄ 氧化 I⁻）

### 例 2 — Cr₂O₇²⁻ 酸性氧化 Fe²⁺ ⭐⭐⭐（多原子变价）

**题目**：写出 K₂Cr₂O₇ 在酸性条件下氧化 FeSO₄ 的离子方程式。

**思路**：Cr₂O₇²⁻ 中 Cr 为 +6 → Cr³⁺；Fe²⁺ → Fe³⁺。**Cr₂O₇²⁻ 含 2 个 Cr，整体得 6e⁻。**

**解答**：
还原半反应：Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O
氧化半反应：Fe²⁺ → Fe³⁺ + e⁻（×6）
$$\mathrm{Cr_2O_7^{2-} + 6Fe^{2+} + 14H^+ \longrightarrow 2Cr^{3+} + 6Fe^{3+} + 7H_2O}$$

> 相关真题：[[题-030-1-离子化合物A2B化学式推断]]（Cr(VI) → Cr(III) 离子方程式书写）

### 例 3 — FeCl₃ 溶液与 Na₂CO₃ 溶液 ⭐⭐⭐（非氧化还原驱动力 + 存在形体）

**题目**：写出 FeCl₃ 与 Na₂CO₃ 溶液反应的分子方程式和离子方程式，说明为什么产物不能简单写成 Fe₂(CO₃)₃。

**思路**：Fe³⁺ 水解能力强，CO₃²⁻ 遇酸转 CO₂ + H₂O，体系最终表现为「沉淀 + 放气」。

**解答**：
分子方程式：$$\mathrm{2FeCl_3 + 3Na_2CO_3 + 3H_2O \longrightarrow 2Fe(OH)_3\downarrow + 3CO_2\uparrow + 6NaCl}$$
离子方程式：$$\mathrm{2Fe^{3+} + 3CO_3^{2-} + 3H_2O \longrightarrow 2Fe(OH)_3\downarrow + 3CO_2\uparrow}$$

**教学要点**：遇到高电荷金属离子，不能只会「交换搭配」，要问「这个产物在水里真的稳定存在吗」——这就是**存在形体判断**。

### 例 4 — Cl₂ 与 NaOH 歧化 ⭐⭐⭐（温度影响歧化深度）

**题目**：写出 Cl₂ 与冷稀 NaOH、热浓 NaOH 反应的离子方程式。

**解答**：
- 冷稀：$$\mathrm{Cl_2 + 2OH^- \longrightarrow Cl^- + ClO^- + H_2O}$$
- 热浓：$$\mathrm{3Cl_2 + 6OH^- \xrightarrow{\Delta} 5Cl^- + ClO_3^- + 3H_2O}$$

**为什么温度影响产物**：ClO⁻ 加热不稳定，进一步歧化：3ClO⁻ → 2Cl⁻ + ClO₃⁻，叠加即得热碱总反应。

### 例 5 — KClO₃ 与 HCl 归中 ⭐⭐⭐（先认出归中）

**题目**：配平 KClO₃ + HCl → KCl + Cl₂ + H₂O，说明为什么氯酸根中 Cl 优先到 Cl₂(0) 而非全部到 Cl⁻。

**思路**：ClO₃⁻ 中 Cl(+5) 与 HCl 中 Cl(−1) 归中到 0 价的 Cl₂。ClO₃⁻ 得 5e⁻，每个 Cl⁻ 失 1e⁻，需 5 个 Cl⁻。

**解答**：$$\mathrm{KClO_3 + 6HCl \longrightarrow KCl + 3Cl_2\uparrow + 3H_2O}$$

> **口径提醒**：电子转移数是 5 而不是 6。若把氯酸根直接还原到 Cl⁻，就把主产物线判错了。

### 例 6 — NaNO₂ 酸化分解 ⭐⭐⭐⭐（存在形体：HNO₂ 不稳定）

**题目**：写出 NaNO₂ 在酸性条件下分解的总反应，并指出生成的两种气体。

**思路**：先写 NaNO₂ + HCl → HNO₂ + NaCl（存在形体：酸化得到不稳定的亚硝酸）；HNO₂ 歧化分解。

**解答**：$$\mathrm{2NaNO_2 + 2HCl \longrightarrow 2NaCl + NO\uparrow + NO_2\uparrow + H_2O}$$
两种气体：**NO 和 NO₂**。

### 例 7 — BrF₃ 与 H₂O ⭐⭐⭐⭐（叠加法）

**题目**：配平 BrF₃ 与 H₂O 的反应。

**思路**：BrF₃ 中 Br 为 +3。它同时发生水解（Br 保持 +3 → HBrO₃）和歧化/氧化还原（部分 Br → Br₂，水被氧化 → O₂）。用叠加法拆成子过程再按电子守恒叠加。

**解答**：$$\mathrm{3BrF_3 + 5H_2O \longrightarrow HBrO_3 + Br_2 + 9HF + O_2}$$

### 例 8 — Ag₂SO₄ 与 S ⭐⭐⭐⭐（化学图景）

**题目**：分析 Ag₂SO₄ 与硫单质在水中的反应，写出配平方程式。

**思路（图景推断）**：
1. S 单质为 0 价，可歧化（一部分升到 +6、一部分降到 −2）。
2. Ag⁺ 与 S²⁻ 生成极难溶的黑色 Ag₂S——**沉淀拉动还原半反应**，是「谁在推动反应」的答案。
3. 电子守恒：4 个 S 中 3 个去 Ag₂S（共得 6e⁻），1 个去 H₂SO₄（失 6e⁻）。

**解答**：$$\mathrm{3Ag_2SO_4 + 4S + 4H_2O \longrightarrow 3Ag_2S\downarrow + 4H_2SO_4}$$

### 例 9 — 氮氧化物的数据反推 ⭐⭐⭐⭐（数据反推 + 化学图景）

**题目**：标准状况下 0.672 L 无色气体 A（对 H₂ 相对密度 23，含氧 69.6%）通入足量水中，得 1.26 g 一元酸 B 和 0.224 L 气体 C（对 H₂ 相对密度 15）。推断 A/B/C 并写出反应方程式。

**思路（数据反推）**：
1. A 式量 = 23×2 = 46；含氧 69.6% → O 原子数 = 46×0.696/16 ≈ 2 → **A = NO₂**；0.672 L = 0.03 mol。
2. C 式量 = 15×2 = 30 → **C = NO**；0.224 L = 0.01 mol。
3. B 为 1.26 g 一元酸，由 0.03 mol A 生成 → n(B) = 0.02 mol，M = 63 → **B = HNO₃**。
4. **化学图景**：NO₂ 遇水歧化-氧化还原（N +4 既升到 +5 又降到 +2）。

**解答**：$$\mathrm{3NO_2 + H_2O \longrightarrow 2HNO_3 + NO}$$

## 十一、方法总结

### 11.1 总流程

| 先判断什么 | 接下来做什么 |
|:---|:---|
| 题型是①~⑤哪一类 | 先选对工具，不要一上来就套半反应法 |
| 若是纯配平题 | 先试守恒方程数，不够就**叠加法拆子反应** |
| 若是存在形体题 | 按介质/配位/水解/沉淀判断真实物种 |
| 若是图景推断题 | 先看「谁推动、谁主产物」再动笔 |
| 若是数据反推题 | 设未知量 → 用式量/质量分数/摩尔比收束 |
| 若涉及变价 | 按「判介质 → 判产物 → 写半反应 → 配平」推进 |
| 最后统一检查 | 原子守恒、电荷守恒、电子守恒、介质自洽 |

### 11.2 核心结论

1. **先分题型，再选工具**：不是所有方程式题都要上半反应法。
2. **非氧化还原题先找驱动力**：沉淀、气体、水、弱电解质、配位和两性溶解是第一轮最常见的几类。
3. **离子方程式先决定「拆 / 留 / 删」**：强电解质可拆，弱电解质/沉淀/气体/水一般保留，旁观离子可删。
4. **氧化还原题介质优先**：介质判断直接决定产物形态。
5. **第二轮进阶**：产物之前先问「真实存在形体是什么」，信息少先看「化学图景」。
6. **配平后必须检查**原子守恒和电荷守恒。

### 11.3 常见易错点

| 错误想法 | 为什么错 | 正确理解 |
|:---|:---|:---|
| 看见方程式就先凑系数 | 题型没判清，容易用错工具 | 先分清是哪一类、是不是氧化还原、是不是离子方程式 |
| 所有溶液里物质都应拆成离子 | 弱电解质、沉淀、气体和水不能乱拆 | 先判断物种在水中的真实存在形式 |
| 碱性条件也可以写 H⁺ | 违反基本化学事实 | 碱性条件只能用 OH⁻ 和 H₂O 配平 |
| Cr₂O₇²⁻ 得 3 个电子 | 忽略 1 个 Cr₂O₇²⁻ 含 2 个 Cr | Cr₂O₇²⁻ 整体得 6e⁻ |
| MnO₄⁻ 总是还原成 Mn²⁺ | 忽略介质影响 | 酸 → Mn²⁺，中 → MnO₂，碱 → MnO₄²⁻ |
| 产物只知道配平、不考虑存在形体 | 配平对了物种也错 | 先问「这个物种在题目条件下真实存在吗」 |

## 十三、参考答案与提示

**基础巩固**
1. 分子：BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl；离子：Ba²⁺ + SO₄²⁻ → BaSO₄↓
2. 分子：CaCO₃ + 2HCl → CaCl₂ + CO₂↑ + H₂O；离子：CaCO₃(s) + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O
3. 分子：NH₄Cl + NaOH → NH₃↑ + NaCl + H₂O；离子：NH₄⁺ + OH⁻ → NH₃↑ + H₂O
4. 2KMnO₄ + 10FeSO₄ + 8H₂SO₄ → 2MnSO₄ + 5Fe₂(SO₄)₃ + K₂SO₄ + 8H₂O；离子：2MnO₄⁻ + 10Fe²⁺ + 16H⁺ → 2Mn²⁺ + 10Fe³⁺ + 8H₂O
5. Cr₂O₇²⁻ + 3H₂S + 8H⁺ → 2Cr³⁺ + 3S↓ + 7H₂O
6. 冷稀：Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O；热浓：3Cl₂ + 6OH⁻ → 5Cl⁻ + ClO₃⁻ + 3H₂O

**提高训练**
7. Zn + 2OH⁻ + 2H₂O → [Zn(OH)₄]²⁻ + H₂↑
8. 碱性 MnO₄⁻ → MnO₂：2MnO₄⁻ + 3S²⁻ + 4H₂O → 2MnO₂↓ + 3S↓ + 8OH⁻
9. 5I⁻ + IO₃⁻ + 6H⁺ → 3I₂ + 3H₂O（归中）
10. 4H₂O₂ + PbS → PbSO₄ + 4H₂O（H₂O₂ 中 O −1 → −2；PbS 中 S −2 → +6）
11. 3Cu + 8H⁺ + 2NO₃⁻ → 3Cu²⁺ + 2NO↑ + 4H₂O；Fe + 4H⁺ + NO₃⁻ → Fe³⁺ + NO↑ + 2H₂O（稀硝酸过量）
12. 分子：2FeCl₃ + 3Na₂CO₃ + 3H₂O → 2Fe(OH)₃↓ + 3CO₂↑ + 6NaCl；离子：2Fe³⁺ + 3CO₃²⁻ + 3H₂O → 2Fe(OH)₃↓ + 3CO₂↑。不能写 Fe₂(CO₃)₃，因为 Fe³⁺ 水解强、CO₃²⁻ 遇酸转 CO₂+H₂O。

**挑战题**
13. 2NaNO₂ + 2HCl → 2NaCl + NO↑ + NO₂↑ + H₂O；两种气体为 NO 和 NO₂。HNO₂ 极不稳定（2HNO₂ → NO + NO₂ + H₂O），故「存在形体」上先写 HNO₂ 再歧化。
14. 3BrF₃ + 5H₂O → HBrO₃ + Br₂ + 9HF + O₂（叠加法，见例 7）
15. 提示：As₂S₃ 中 As(+3)→H₃AsO₄(+5)（2 个 As 共失 4e⁻），S(−2)→H₂SO₄(+6)（3 个 S 共失 24e⁻），一个 As₂S₃ 共失 28e⁻；HNO₃ 中 N(+5)→NO(+2) 得 3e⁻。
    $$3\mathrm{As_2S_3} + 28\mathrm{HNO_3} + 4\mathrm{H_2O} \longrightarrow 6\mathrm{H_3AsO_4} + 9\mathrm{H_2SO_4} + 28\mathrm{NO}\uparrow$$
16. MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O。不能只看「酸 + 金属氧化物」：MnO₂ 中 Mn 为 +4，Cl⁻ 可被氧化，必须先认出产物里有 Cl₂（默认反应源：制氯线），再做配平。
17. A = NO₂（Mr 46，0.03 mol），B = HNO₃（0.02 mol，1.26 g），C = NO（Mr 30，0.01 mol）；3NO₂ + H₂O → 2HNO₃ + NO。
18. NaPO₃ + NaF → Na₂PO₃F（氟磷酸钠）。信息越少，越不该过拟合——走最基本的复分解/化合逻辑即可。
