## 学习目标

- ✅ 能先判断题目是在写分子方程式、离子方程式，还是氧化还原配平方程式，而不是一上来就乱凑系数。
- ✅ 能根据“沉淀、气体、弱电解质、水、配位、两性溶解”等驱动力，写出第一轮常见的非氧化还原方程式。
- ✅ 能掌握离子方程式中“哪些要拆、哪些要保留、哪些要删”的基本规则，并用原子守恒和电荷守恒自查。
- ✅ 能熟练判定元素氧化态和介质条件，使用离子-电子法（半反应法）配平常见氧化还原方程式。
- ✅ 能熟记常见氧化剂在不同介质中的典型还原产物，建立“介质优先”的配平思维习惯。
- ✅ 能把卤素、硫、氮、两性金属和 Fe/Cu 这些第一轮高频元素反应事实，转化成写产物时的“默认底稿”。

## 本讲主线

1. 先把方程式题分型：它到底是“判断有没有反应”、写“离子方程式”，还是做“氧化还原配平”。
2. 非氧化还原题先看驱动力，再决定要不要拆成离子形式。
3. 氧化还原题再走“介质判断 → 产物判断 → 半反应配平 → 守恒检查”的固定流程。
4. 把这份讲义当成第一轮的总工具页，后续元素化学、酸碱、沉淀、电化学都会默认复用这里的语言。

### 0.1 本讲先分四类题

1. **有没有反应**：先看是否有沉淀、气体、弱电解质、水或配位驱动。
2. **写分子方程式**：先把反应物和生成物判清，再谈系数。
3. **写离子方程式**：先拆强电解质，再删旁观离子。
4. **做氧化还原配平**：先判介质和产物，再用半反应法。

> **做题口令**：先判题型，再判介质；先判产物，再谈配平；最后一定检查原子守恒和电荷守恒。

## 一、先分清题目到底让你写什么

| 题型 | 你真正要做的事 | 首先要问自己的问题 |
|:---|:---|:---|
| 分子方程式 | 写出反应前后物种并配平 | 反应有没有明显驱动力？ |
| 离子方程式 | 保留真正变化的粒子 | 哪些物质应拆成离子，哪些不能拆？ |
| 氧化还原配平 | 处理电子转移并配平介质 | 谁升价、谁降价、题目在什么介质里？ |
| 陌生反应判断 | 先判断产物，再决定工具 | 是复分解、酸碱、沉淀、配位，还是氧化还原？ |

> **核心提醒**：很多学生不是“不会配平”，而是第一步就把题型认错了。复分解题硬上半反应法，或者氧化还原题只靠观察法，都会越写越乱。

## 二、先找驱动力，再补元素反应事实

### 2.1 第一轮最常见的五种驱动力

| 驱动力 | 典型信号 | 例子 |
|:---|:---|:---|
| 生成沉淀 | 产物中有难溶盐 | $\mathrm{Ba^{2+} + SO_4^{2-} \rightarrow BaSO_4 \downarrow}$ |
| 生成气体 | 碳酸盐、亚硫酸盐、硫化物遇酸 | $\mathrm{CO_3^{2-} + 2H^+ \rightarrow CO_2 \uparrow + H_2O}$ |
| 生成弱电解质 / 水 | 酸碱中和、弱酸弱碱生成 | $\mathrm{H^+ + OH^- \rightarrow H_2O}$ |
| 配位或两性溶解 | 形成稳定配离子、两性物质溶于强酸强碱 | $\mathrm{Al(OH)_3 + OH^- \rightarrow [Al(OH)_4]^-}$ |
| 挥发性分子逸出 | 生成 $\mathrm{NH_3}$、$\mathrm{HCl}$ 等 | $\mathrm{NH_4^+ + OH^- \rightarrow NH_3 \uparrow + H_2O}$ |

### 2.2 离子方程式的“拆 / 留 / 删”规则

1. **强电解质且在溶液中存在**：一般拆成离子，如 HCl、NaOH、NaCl、CuSO₄。
2. **弱电解质、沉淀、气体、纯液体**：一般保留整体，如 HAc、NH₃·H₂O、BaSO₄、CO₂、H₂O。
3. **旁观离子**：反应前后完全一样的离子可以删去。
4. **最后检查两件事**：原子是否守恒，电荷是否守恒。

> **常见错法**：把弱酸、弱碱拆掉；把沉淀拆成离子；或者只顾删离子，结果把电荷守恒也删没了。

### 2.3 两个最典型的第一轮例子

**例 A：碳酸钙与盐酸**

分子方程式：

$$
\mathrm{CaCO_3 + 2HCl \rightarrow CaCl_2 + CO_2 \uparrow + H_2O}
$$

离子方程式：

$$
\mathrm{CaCO_3(s) + 2H^+ \rightarrow Ca^{2+} + CO_2 \uparrow + H_2O}
$$

**关键判断**：这题的驱动力不是“氧化还原”，而是 **酸把 $\mathrm{CO_3^{2-}}$ 变成了不稳定的 $\mathrm{H_2CO_3}$，后者分解成 $\mathrm{CO_2 + H_2O}$**。

**例 B：氯化钡与硫酸钠**

分子方程式：

$$
\mathrm{BaCl_2 + Na_2SO_4 \rightarrow BaSO_4 \downarrow + 2NaCl}
$$

离子方程式：

$$
\mathrm{Ba^{2+} + SO_4^{2-} \rightarrow BaSO_4 \downarrow}
$$

**关键判断**：这题真正保留下来的只有“生成难溶硫酸钡”这一件事，$\mathrm{Na^+}$ 和 $\mathrm{Cl^-}$ 都是旁观离子。

### 2.4 第一轮写产物前必须会的“默认反应源”

> [!tip] 理解要点
> 很多方程式题表面上在考“配平”，其实前半步考的是“你知不知道这个体系通常生成什么”。下面这几条，是根据上海中学元素化学部分抽出来的第一轮高频反应线。

| 反应线 | 第一轮最低要求 | 代表方程式 |
|:---|:---|:---|
| 氯气的歧化线 | 会区分水、冷稀碱、热浓碱三种条件下的产物 | $\mathrm{Cl_2 + H_2O \rightleftharpoons HCl + HClO}$；$\mathrm{Cl_2 + 2OH^- \rightarrow Cl^- + ClO^- + H_2O}$；$\mathrm{3Cl_2 + 6OH^- \rightarrow 5Cl^- + ClO_3^- + 3H_2O}$ |
| 氯酸盐/二氧化锰制氯线 | 知道“浓盐酸既给酸性又给 Cl⁻”，产物不是乱猜 | $\mathrm{MnO_2 + 4HCl(浓) \rightarrow MnCl_2 + Cl_2 \uparrow + 2H_2O}$；$\mathrm{KClO_3 + 6HCl \rightarrow KCl + 3Cl_2 \uparrow + 3H_2O}$ |
| 硫化物/亚硫酸盐放气线 | 见酸先想到 H₂S、SO₂ 逸出，再决定是不是氧化还原 | $\mathrm{S^{2-} + 2H^+ \rightarrow H_2S \uparrow}$；$\mathrm{SO_3^{2-} + 2H^+ \rightarrow SO_2 \uparrow + H_2O}$ |
| 硫化氢的还原性线 | 知道 H₂S 常被氧化到单质硫，再往后才谈更深终态 | $\mathrm{H_2S + Cl_2 \rightarrow 2HCl + S \downarrow}$；$\mathrm{Cr_2O_7^{2-} + 3H_2S + 8H^+ \rightarrow 2Cr^{3+} + 3S \downarrow + 7H_2O}$ |
| 铵盐与硝酸线 | 会区分“铵盐遇碱放氨”和“稀、浓硝酸产物不同” | $\mathrm{NH_4^+ + OH^- \rightarrow NH_3 \uparrow + H_2O}$；Cu 遇稀硝酸产 NO、遇浓硝酸产 NO₂ |
| 两性金属与水解线 | 会写 Al/Zn 的两性反应，也知道 Fe³⁺ + CO₃²⁻ 不会稳定停在碳酸盐 | $\mathrm{Al(OH)_3 + OH^- \rightarrow [Al(OH)_4]^-}$；$\mathrm{Zn(OH)_2 + 2OH^- \rightarrow [Zn(OH)_4]^{2-}}$；$\mathrm{2Fe^{3+} + 3CO_3^{2-} + 3H_2O \rightarrow 2Fe(OH)_3 \downarrow + 3CO_2 \uparrow}$ |

### 2.5 这张“默认反应源”表怎么用

1. **先看反应物组合**：比如看到 `Cl₂ + OH⁻`，先别忙着配平，先调出“冷稀碱 / 热浓碱”这条产物线。
2. **再看题目条件**：是否给了浓度、温度、酸碱性、是否加热、是否浓盐酸。
3. **最后才选工具**：若只是判产物，可先写分子方程式；若涉及变价，再转入化合价升降法或半反应法。

> **课堂口令**：先从元素化学里把“产物骨架”叫出来，再用方程式工具把它写对。

### 2.6 第一轮最常见的“别写错产物”清单

> [!tip] 理解要点
> 第一轮不是要求学生背完所有元素化学，而是先把最容易误写的几条主产物线抓牢。下面这张表可以直接当课堂快问快答。

| 看到的反应物 | 先调哪条元素线 | 默认主产物 | 最常见误写 |
|:---|:---|:---|:---|
| Cl₂ + H₂O | 卤素含氧酸线 | HCl + HClO | 只想到“溶于水”，却写不出歧化产物 |
| Cl₂ + OH⁻（冷稀） | 氯气歧化线 | Cl⁻ + ClO⁻ | 直接写成 ClO₃⁻ |
| Cl₂ + OH⁻（热浓） | 次氯酸盐继续歧化 | Cl⁻ + ClO₃⁻ | 仍停在 ClO⁻ |
| MnO₂ + HCl(浓) | 制氯线 | MnCl₂ + Cl₂ + H₂O | 只按“酸 + 碱性氧化物”去写 |
| KClO₃ + HCl | 归中线 | KCl + Cl₂ + H₂O | 误判成“全部到 Cl⁻” |
| Fe³⁺ + CO₃²⁻（溶液） | 水解线 | Fe(OH)₃ + CO₂ | 生搬硬套成 Fe₂(CO₃)₃ |
| Cu + HNO₃（稀 / 浓） | 硝酸线 | NO / NO₂ | 看到酸就条件反射写 H₂ |
| S²⁻、SO₃²⁻ + H⁺ | 放气线 | H₂S / SO₂ | 只写成“生成相应弱酸”就停住 |

> **课堂建议**：先把这 8 条做成“口头秒答”，学生对陌生方程式的恐惧会明显下降，因为他们知道自己不是从零开始猜产物。

## 三、氧化态判定与介质判断

> [!tip] 理解要点
> 方程式写不出来，通常不是最后一步不会配，而是前两步先错了：一是没判清谁升谁降，二是没判清题目到底在什么介质里。

### 3.1 氧化态判定规则（复习）

氧化态（氧化数）是配平的基础。判定规则如下：

| 规则 | 内容 | 例外 |
|:---|:---|:---|
| 单质 | 元素氧化态为 0 | — |
| 离子化合物 | 氧化态 = 离子电荷 | — |
| 共价化合物 | 电负性大的原子得电子（负氧化态） | — |
| H | 通常为 +1 | 金属氢化物中为 -1（如 NaH、CaH₂） |
| O | 通常为 -2 | 过氧化物中为 -1（H₂O₂），超氧化物中为 -1/2（KO₂），OF₂ 中为 +2 |
| 分子总电荷 | 各原子氧化态代数和 = 分子总电荷 | — |

> [!info] 深入思考
> 示例**：Cr₂O₇²⁻ 中 O 为 -2，总电荷 -2，设 Cr 氧化态为 x，则 2x + 7×(-2) = -2 → x = +6，即 Cr 为 +6 价。

### 3.2 介质判断原则

介质决定了产物的形态，是配平的第一步。

| 判断依据 | 酸性介质 | 碱性介质 | 中性介质 |
|:---|:---|:---|:---|
| 题目明确说明 | "酸性条件"、"稀 H₂SO₄" | "碱性条件"、"NaOH" | "中性"、"水溶液" |
| 反应物特征 | 含 H⁺、强酸 | 含 OH⁻、强碱 | 无强酸强碱 |
| 产物提示 | 生成 CO₂（碳酸盐分解） | 生成 CO₃²⁻ | 视情况而定 |

> **核心纪律**：**碱性条件绝不允许出现游离 H⁺，酸性条件绝不允许出现游离 OH⁻**

### 3.3 先判断该走哪条方法线

拿到一道题，先问自己三件事：

1. 有没有元素化合价发生变化？
2. 题目有没有给出或暗示介质条件？
3. 这题到底需要离子-电子法，还是只要观察法和守恒法？

| 题型 | 优先方法 |
|:---|:---|
| 明显有变价 | 离子-电子法 |
| 酸碱中和、沉淀、复分解 | 观察法 |
| 产物已知但系数混乱 | 先看是否有变价，再决定是否拆半反应 |

## 四、离子-电子法（半反应法）配平

### 4.1 配平总口诀

| 环节 | 你要先想什么 |
|:---|:---|
| 介质定 | 先判酸性、碱性还是中性，避免一开始就把 H⁺、OH⁻ 写错 |
| 产物定 | 根据介质与常见变价终点，先确定产物形态 |
| 原子平 | 先配非 H/O 原子，再用 H₂O、H⁺、OH⁻ 去配 H、O |
| 电荷平 | 最后用 e⁻ 平电荷，再合并同类项并化简 |

> **操作提醒**：真正上手时可以写成更完整的五个动作：  
> `判介质 → 拆半反应 → 配非 H/O → 配 H/O → 配电荷并合并`

### 4.2 五步骤详解

以 **MnO₄⁻ 在酸性介质中还原为 Mn²⁺** 为例：

| 步骤 | 操作 | 示例 |
|:---:|:---|:---|
| ① 写出骨架 | 写出氧化/还原半反应的骨架形式 | MnO₄⁻ → Mn²⁺ |
| ② 配非 H/O 原子 | 配平除 H、O 外的原子 | 已平（1 个 Mn） |
| ③ 配 O（加 H₂O） | 在缺 O 的一侧加 H₂O | MnO₄⁻ → Mn²⁺ + **4H₂O** |
| ④ 配 H（加 H⁺ 或 OH⁻） | 酸性加 H⁺，碱性加 OH⁻ | MnO₄⁻ + **8H⁺** → Mn²⁺ + 4H₂O |
| ⑤ 配电荷（加 e⁻） | 用电子平衡两侧电荷 | MnO₄⁻ + 8H⁺ + **5e⁻** → Mn²⁺ + 4H₂O |

**完整半反应**：

还原半反应：$\text{MnO}_4^- + 8\text{H}^+ + 5\text{e}^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}$
氧化半反应：$\text{SO}_3^{2-} + \text{H}_2\text{O} \rightarrow \text{SO}_4^{2-} + 2\text{H}^+ + 2\text{e}^-$

**合并**：最小公倍数法（10e⁻），两式分别乘以 2 和 5，相加消去电子：

$$2\text{MnO}_4^- + 5\text{SO}_3^{2-} + 6\text{H}^+ \rightarrow 2\text{Mn}^{2+} + 5\text{SO}_4^{2-} + 3\text{H}_2\text{O}$$

### 4.3 碱性介质处理技巧

> **技巧**：先按酸性条件配平，再两边加等量 OH⁻ 中和 H⁺，合并 H⁺ + OH⁻ → H₂O，最后化简。

**酸性配平结果**：$\text{MnO}_4^- + 8\text{H}^+ + 5\text{e}^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}$

**转为碱性**：两边加 8 个 OH⁻：
$\text{MnO}_4^- + 8\text{H}^+ + 8\text{OH}^- + 5\text{e}^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O} + 8\text{OH}^-$

合并 H⁺ + OH⁻ → H₂O：
$\text{MnO}_4^- + 4\text{H}_2\text{O} + 5\text{e}^- \rightarrow \text{Mn}^{2+} + 8\text{OH}^-$

> **验证**：碱性半反应中不含游离 H⁺ ✓

## 五、常见氧化剂在不同介质中的还原产物

### 5.1 还原产物速查表

| 氧化剂 | 酸性介质 | 中性/弱碱性 | 强碱性介质 |
|:---|:---|:---|:---|
| KMnO₄ | **Mn²⁺**（无色） | **MnO₂↓**（棕黑） | **MnO₄²⁻**（绿色） |
| K₂Cr₂O₇ | **Cr³⁺**（绿色） | — | — |
| HNO₃（浓） | **NO₂** | — | — |
| HNO₃（稀） | **NO** | — | — |
| H₂SO₄（浓） | **SO₂** | — | — |
| H₂O₂ | **H₂O** | H₂O（或 O₂↑） | — |
| Cl₂ | Cl⁻ | Cl⁻ / ClO⁻（歧化） | Cl⁻ / ClO⁻（冷）或 ClO₃⁻（热） |

### 5.2 记忆要点

- **MnO₄⁻ 的降价规律**：酸性降 5 价（Mn⁷⁺→Mn²⁺），中性降 3 价（Mn⁷⁺→Mn⁴⁺），碱性降 1 价（Mn⁷⁺→Mn⁶⁺）
- **Cr₂O₇²⁻**：只在酸性条件下作氧化剂，每个 Cr 得 3e⁻，**整体得 6e⁻**（含 2 个 Cr）
- **Cl₂ 歧化**：冷稀碱 → Cl⁻ + ClO⁻；热浓碱 → Cl⁻ + ClO₃⁻（温度影响产物）
- **KClO₃ + HCl 经典归中**：$\mathrm{Cl(+5)}$ 和 $\mathrm{Cl(-1)}$ 归中到 $\mathrm{Cl_2(0)}$，关键不是“死记产物”，而是先看哪条电子转移路径更自然

### 5.3 常见离子在溶液中的颜色

| 离子 | 颜色 | 离子 | 颜色 |
|:---|:---:|:---|:---:|
| MnO₄⁻ | 紫红 | MnO₄²⁻ | 绿 |
| Mn²⁺ | 浅粉（稀时无色） | Cr₂O₇²⁻ | 橙红 |
| Cr³⁺ | 绿/紫 | Fe²⁺ | 浅绿 |
| Fe³⁺ | 淡黄 | Cu²⁺ | 蓝 |

## 六、典型例题

### 例 1 — KMnO₄ 在不同介质中氧化 Na₂SO₃ ⭐⭐

**题目**：分别写出 KMnO₄ 在酸性、中性、碱性介质中氧化 Na₂SO₃ 的离子方程式。

**思路分析**：先判断介质 → 确定 MnO₄⁻ 的还原产物 → 用离子-电子法配平。

**完整解答**：

**（1）酸性介质**（MnO₄⁻ → Mn²⁺）：

还原半反应：$\text{MnO}_4^- + 8\text{H}^+ + 5\text{e}^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}$（×2）
氧化半反应：$\text{SO}_3^{2-} + \text{H}_2\text{O} \rightarrow \text{SO}_4^{2-} + 2\text{H}^+ + 2\text{e}^-$（×5）

合并：
$$2\text{MnO}_4^- + 5\text{SO}_3^{2-} + 6\text{H}^+ \rightarrow 2\text{Mn}^{2+} + 5\text{SO}_4^{2-} + 3\text{H}_2\text{O}$$

**（2）中性介质**（MnO₄⁻ → MnO₂）：

$$2\text{MnO}_4^- + 3\text{SO}_3^{2-} + \text{H}_2\text{O} \rightarrow 2\text{MnO}_2\downarrow + 3\text{SO}_4^{2-} + 2\text{OH}^-$$

**（3）碱性介质**（MnO₄⁻ → MnO₄²⁻）：

$$2\text{MnO}_4^- + \text{SO}_3^{2-} + 2\text{OH}^- \rightarrow 2\text{MnO}_4^{2-} + \text{SO}_4^{2-} + \text{H}_2\text{O}$$

**教学要点**：同一反应物在不同介质中产物完全不同，**"介质优先"** 是配平的第一原则。

> **相关真题**：[[题-038-2-1-KMnO4浓度测定计算]]（酸性条件 KMnO₄ 氧化 I⁻ 的离子方程式）

### 例 2 — Cr₂O₇²⁻ 酸性氧化 Fe²⁺ ⭐⭐

**题目**：写出 K₂Cr₂O₇ 在酸性条件下氧化 FeSO₄ 的离子方程式。

**思路分析**：Cr₂O₇²⁻ 中 Cr 为 +6 价，还原为 Cr³⁺；Fe²⁺ 氧化为 Fe³⁺。

**完整解答**：

还原半反应：$\text{Cr}_2\text{O}_7^{2-} + 14\text{H}^+ + 6\text{e}^- \rightarrow 2\text{Cr}^{3+} + 7\text{H}_2\text{O}$
氧化半反应：$\text{Fe}^{2+} \rightarrow \text{Fe}^{3+} + \text{e}^-$（×6）

合并：
$$\text{Cr}_2\text{O}_7^{2-} + 6\text{Fe}^{2+} + 14\text{H}^+ \rightarrow 2\text{Cr}^{3+} + 6\text{Fe}^{3+} + 7\text{H}_2\text{O}$$

> **关键**：Cr₂O₇²⁻ 含 **2 个 Cr**，整体得 **6e⁻**（每个 Cr 得 3e⁻）。常见错误是误以为只得了 3e⁻。

> **相关真题**：[[题-030-1-离子化合物A2B化学式推断]]（Cr(VI)还原为 Cr(III) 的离子方程式书写）

### 例 3 — Al 与 NaOH 溶液反应 ⭐⭐

**题目**：写出 Al 与 NaOH 溶液反应的离子方程式。

**思路分析**：Al 是两性金属；碱性条件下产物是四羟基合铝酸盐（[Al(OH)₄]⁻）；H₂O 中的 H⁺ 被还原为 H₂。

**完整解答**：

Al 失电子（氧化）：$\text{Al} + 4\text{OH}^- \rightarrow [\text{Al(OH)}_4]^- + 3\text{e}^-$
H₂O 得电子（还原）：$2\text{H}_2\text{O} + 2\text{e}^- \rightarrow \text{H}_2\uparrow + 2\text{OH}^-$

合并（最小公倍数 6e⁻）：
$$2\text{Al} + 2\text{OH}^- + 6\text{H}_2\text{O} \rightarrow 2[\text{Al(OH)}_4]^- + 3\text{H}_2\uparrow$$

**化学方程式形式**：
$$2\text{Al} + 2\text{NaOH} + 6\text{H}_2\text{O} \rightarrow 2\text{Na}[\text{Al(OH)}_4] + 3\text{H}_2\uparrow$$

> [!warning] 易错提醒
> Al 与碱反应的本质是 Al 还原 H₂O 中的 H⁺，而非直接还原 NaOH。产物是四羟基合铝酸盐，过去常写为 AlO₂⁻（偏铝酸盐），但现代化学中正确写法为 [Al(OH)₄]⁻。

### 例 4 — Cl₂ 与 NaOH 歧化反应 ⭐⭐⭐

**题目**：写出 Cl₂ 与冷稀 NaOH 溶液以及热浓 NaOH 溶液反应的离子方程式。

**思路分析**：歧化反应中 Cl₂ 中的 Cl 既是氧化剂又是还原剂，Cl 从 0 价既升高又降低。

**完整解答**：

**（1）冷稀碱**：
$$\text{Cl}_2 + 2\text{OH}^- \rightarrow \text{Cl}^- + \text{ClO}^- + \text{H}_2\text{O}$$

**（2）热浓碱**：
$$3\text{Cl}_2 + 6\text{OH}^- \rightarrow 5\text{Cl}^- + \text{ClO}_3^- + 3\text{H}_2\text{O}$$

> **为什么温度影响产物？**：ClO⁻ 在加热条件下不稳定，进一步歧化为 Cl⁻ 和 ClO₃⁻：
> 加热条件下：
>
> $$3\text{ClO}^- \rightarrow 2\text{Cl}^- + \text{ClO}_3^-$$
> 将两式叠加即得热碱条件下的总反应。

### 例 5 — KClO₃ 与 HCl 的经典归中反应 ⭐⭐⭐

**题目**：配平下列反应，并说明为什么氯酸根中的 Cl 优先变成 $\mathrm{Cl_2}$ 中的 Cl(0)，而不是直接全部到 Cl⁻。

$$
\mathrm{KClO_3 + HCl \rightarrow KCl + Cl_2 + H_2O}
$$

**思路分析**：这题的关键不在“最后怎么凑系数”，而在**先认出它是同一元素的归中反应**。一个 Cl 来自 $\mathrm{ClO_3^-}$（+5 价），另一些 Cl 来自 HCl（-1 价），二者在酸性条件下汇到 0 价的 $\mathrm{Cl_2}$。

**完整解答**：

- $\mathrm{ClO_3^-}$ 中 Cl：$+5 \rightarrow 0$，**得 5e⁻**
- HCl 中 Cl⁻：$-1 \rightarrow 0$，每个 **失 1e⁻**

所以需要 5 个 Cl⁻ 去配 1 个 $\mathrm{ClO_3^-}$，再补上 K、H、O：

$$
\mathrm{KClO_3 + 6HCl \rightarrow KCl + 3Cl_2 \uparrow + 3H_2O}
$$

> **上海中学口径提醒**：这题经典就经典在“电子转移数是 5 而不是 6”。如果把氯酸根中的 Cl 直接还原到 Cl⁻，你就把真正生成的主产物线判错了。

### 例 6 — FeCl₃ 溶液与 Na₂CO₃ 溶液反应 ⭐⭐⭐

**题目**：写出 $\mathrm{FeCl_3}$ 溶液与 $\mathrm{Na_2CO_3}$ 溶液反应的分子方程式和离子方程式，并说明为什么产物不能简单写成 $\mathrm{Fe_2(CO_3)_3}$。

**思路分析**：这题最容易把“复分解模板”套过头。表面看像是 $\mathrm{Fe^{3+}}$ 与 $\mathrm{CO_3^{2-}}$ 成盐，但真正进入溶液稳定性判断后，要立刻想到两件事：

1. $\mathrm{Fe^{3+}}$ 水解能力强，不会安静停在“碳酸铁(III)”这一步。
2. $\mathrm{CO_3^{2-}}$ 在酸化过程中会转成 $\mathrm{CO_2 + H_2O}$，所以体系最终表现为“沉淀 + 放气”。

**完整解答**：

分子方程式：

$$
\mathrm{2FeCl_3 + 3Na_2CO_3 + 3H_2O \rightarrow 2Fe(OH)_3 \downarrow + 3CO_2 \uparrow + 6NaCl}
$$

离子方程式：

$$
\mathrm{2Fe^{3+} + 3CO_3^{2-} + 3H_2O \rightarrow 2Fe(OH)_3 \downarrow + 3CO_2 \uparrow}
$$

> **教学要点**：这题特别适合用来给学生立规矩：遇到高电荷金属离子时，不能只会“交换搭配”，还要问一句“这个产物在水里真的能稳定存在吗？”

**题目**：写出 Zn 与 NaOH 溶液反应的离子方程式。

**思路分析**：Zn 也是两性金属（与 Al 类似），碱性条件下生成 [Zn(OH)₄]²⁻。

**完整解答**：

### 例 8（拓展）— Cu 与浓 HNO₃ 反应 ⭐⭐⭐

**题目**：写出 Cu 与浓 HNO₃ 反应的化学方程式。

**思路分析**：Cu 被氧化为 Cu²⁺；浓 HNO₃ 被还原为 NO₂。

**完整解答**：
$$\text{Cu} + 4\text{HNO}_3(\text{浓}) \rightarrow \text{Cu(NO}_3)_2 + 2\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

**离子方程式**：
$$\text{Cu} + 4\text{H}^+ + 2\text{NO}_3^- \rightarrow \text{Cu}^{2+} + 2\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

## 七、方法总结

### 7.1 方程式题总流程

| 先判断什么 | 接下来做什么 |
|:---|:---|
| 题型是分子方程式、离子方程式还是氧化还原方程式 | 先选对工具，不要一上来就套半反应法 |
| 若是非氧化还原题 | 先找驱动力，再判断产物能否稳定存在 |
| 若是离子方程式 | 按“拆强电解质、留弱电解质/沉淀/气体/水、删旁观离子”处理 |
| 若是氧化还原题 | 按“判介质 → 判产物 → 写半反应 → 配平”推进 |
| 最后统一检查 | 原子守恒、电荷守恒、介质条件是否自洽 |

### 7.2 核心结论

1. **先分题型，再选工具**：不是所有方程式题都要上半反应法。
2. **非氧化还原题先找驱动力**：沉淀、气体、水、弱电解质、配位和两性溶解是第一轮最常见的几类。
3. **离子方程式先决定“拆/留/删”**：强电解质可拆，弱电解质/沉淀/气体/水一般保留，旁观离子可删。
4. **氧化还原题介质优先**：介质判断直接决定产物形态。
5. **碱性条件绝不允许出现游离 H⁺，酸性条件绝不允许出现游离 OH⁻**。
6. **配平后必须检查**原子守恒和电荷守恒。

### 7.3 常见易错点

| 错误想法 | 为什么错 | 正确理解 |
|:---|:---|:---|
| "看见方程式就先凑系数" | 题型还没判清，容易用错工具 | 先分清是不是氧化还原、是不是离子方程式 |
| "所有溶液里的物质都应该拆成离子" | 弱电解质、沉淀、气体和水不能乱拆 | 先判断物种在水中的真实存在形式 |
| "碱性条件也可以写 H⁺" | 违反基本化学事实 | 碱性条件只能用 OH⁻ 和 H₂O 配平 |
| "Cr₂O₇²⁻ 得 3 个电子" | 忽略了 1 个 Cr₂O₇²⁻ 含 2 个 Cr | Cr₂O₇²⁻ 整体得 **6e⁻** |
| "MnO₄⁻ 总是还原成 Mn²⁺" | 忽略了介质影响 | 酸 → Mn²⁺，中 → MnO₂，碱 → MnO₄²⁻ |

## 九、参考答案与提示

**8.1 基础巩固**

1. 分子方程式：$\mathrm{BaCl_2 + Na_2SO_4 \rightarrow BaSO_4 \downarrow + 2NaCl}$；离子方程式：$\mathrm{Ba^{2+} + SO_4^{2-} \rightarrow BaSO_4 \downarrow}$。
2. 分子方程式：$\mathrm{CaCO_3 + 2HCl \rightarrow CaCl_2 + CO_2 \uparrow + H_2O}$；离子方程式：$\mathrm{CaCO_3(s) + 2H^+ \rightarrow Ca^{2+} + CO_2 \uparrow + H_2O}$。
3. 分子方程式：$\mathrm{NH_4Cl + NaOH \rightarrow NH_3 \uparrow + NaCl + H_2O}$；离子方程式：$\mathrm{NH_4^+ + OH^- \rightarrow NH_3 \uparrow + H_2O}$。
4. 酸性条件：
   - $2\text{KMnO}_4 + 10\text{FeSO}_4 + 8\text{H}_2\text{SO}_4 \rightarrow 2\text{MnSO}_4 + 5\text{Fe}_2(\text{SO}_4)_3 + \text{K}_2\text{SO}_4 + 8\text{H}_2\text{O}$
   - 离子：$2\text{MnO}_4^- + 10\text{Fe}^{2+} + 16\text{H}^+ \rightarrow 2\text{Mn}^{2+} + 10\text{Fe}^{3+} + 8\text{H}_2\text{O}$
   - $\text{Cr}_2\text{O}_7^{2-} + 3\text{H}_2\text{S} + 8\text{H}^+ \rightarrow 2\text{Cr}^{3+} + 3\text{S}\downarrow + 7\text{H}_2\text{O}$

**8.2 提高训练**

5. 碱性/中性：
   - $\text{Cl}_2 + 2\text{OH}^- \rightarrow \text{Cl}^- + \text{ClO}^- + \text{H}_2\text{O}$
   - $\text{Zn} + 2\text{OH}^- + 2\text{H}_2\text{O} \rightarrow [\text{Zn(OH)}_4]^{2-} + \text{H}_2\uparrow$
   - $2\text{MnO}_4^- + 3\text{SO}_3^{2-} + \text{H}_2\text{O} \rightarrow 2\text{MnO}_2\downarrow + 3\text{SO}_4^{2-} + 2\text{OH}^-$
6. 碱性条件 MnO₄⁻ → MnO₂：$2\text{MnO}_4^- + 3\text{S}^{2-} + 4\text{H}_2\text{O} \rightarrow 2\text{MnO}_2\downarrow + 3\text{S}\downarrow + 8\text{OH}^-$
7. $5\text{I}^- + \text{IO}_3^- + 6\text{H}^+ \rightarrow 3\text{I}_2 + 3\text{H}_2\text{O}$（归中反应，I⁻ 和 IO₃⁻ 均生成 I₂）
8. $2\text{Cl}_2 + 2\text{Ca(OH)}_2 \rightarrow \text{Ca(ClO)}_2 + \text{CaCl}_2 + 2\text{H}_2\text{O}$。  
   有效成分是 $\text{Ca(ClO)}_2$，这一题本质上还是在考“Cl₂ 的歧化产物线”。
9. $4\text{H}_2\text{O}_2 + \text{PbS} \rightarrow \text{PbSO}_4 + 4\text{H}_2\text{O}$  
   （H₂O₂ 中 O 从 -1 降为 -2，PbS 中 S 从 -2 升为 +6）
10. 离子方程式：
   - $3\text{Cu} + 8\text{H}^+ + 2\text{NO}_3^- \rightarrow 3\text{Cu}^{2+} + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$
   - $\text{Fe} + 4\text{H}^+ + \text{NO}_3^- \rightarrow \text{Fe}^{3+} + \text{NO}\uparrow + 2\text{H}_2\text{O}$（稀硝酸过量时）
11. 分子方程式可写为：$2\mathrm{FeCl_3} + 3\mathrm{Na_2CO_3} + 3\mathrm{H_2O} \rightarrow 2\mathrm{Fe(OH)_3}\downarrow + 3\mathrm{CO_2}\uparrow + 6\mathrm{NaCl}$。  
    离子方程式：$2\mathrm{Fe^{3+}} + 3\mathrm{CO_3^{2-}} + 3\mathrm{H_2O} \rightarrow 2\mathrm{Fe(OH)_3}\downarrow + 3\mathrm{CO_2}\uparrow$。  
    不能简单写成稳定的 $\mathrm{Fe_2(CO_3)_3}$，因为 $\mathrm{Fe^{3+}}$ 水解能力强，$\mathrm{CO_3^{2-}}$ 在酸化过程中会转成 $\mathrm{CO_2 + H_2O}$，体系最终表现为“沉淀 + 放气”。
12. $\mathrm{MnO_2 + 4HCl(浓) \rightarrow MnCl_2 + Cl_2 \uparrow + 2H_2O}$。  
    这题不能只看“酸 + 金属氧化物”，因为 $\mathrm{MnO_2}$ 中 Mn 为 +4 价，Cl⁻ 还能被氧化，所以必须先认出“产物里会有 $\mathrm{Cl_2}$”这一条元素反应事实，再做配平。
13. $\mathrm{KClO_3 + 6HCl \rightarrow KCl + 3Cl_2 \uparrow + 3H_2O}$。  
    其中氯酸根中的 Cl 从 +5 价降到 0 价，**电子转移数为 5**。
14. FeS 与稀盐酸：$\mathrm{FeS + 2HCl \rightarrow FeCl_2 + H_2S \uparrow}$。  
    CuS 与稀盐酸：通常不反应。  
    原因是 FeS 属于“难溶但可被稀酸处理”的硫化物，而 CuS 的溶度积极小，单靠稀酸不足以把 $\mathrm{S^{2-}}$ 拉走。
15. 先有 $\mathrm{NaNO_2 + HCl \rightarrow HNO_2 + NaCl}$，随后 $\mathrm{2HNO_2 \rightarrow NO \uparrow + NO_2 \uparrow + H_2O}$。  
    合并得：$\mathrm{2NaNO_2 + 2HCl \rightarrow 2NaCl + NO \uparrow + NO_2 \uparrow + H_2O}$。  
    两种气体分别是 NO 和 NO₂。
16. $\mathrm{Cl_2 + H_2O \rightleftharpoons HCl + HClO}$；$\mathrm{H_2S + Cl_2 \rightarrow 2HCl + S \downarrow}$。  
    前者体现氯气在水中的歧化，后者体现 H₂S 的强还原性和“先到单质硫”的第一轮主产物线。

**8.3 挑战题**

17. 提示：As₂S₃ 中 As(+3)→H₃AsO₄(+5)，S(-2)→H₂SO₄(+6)，一个 As₂S₃ 共失去 28e⁻；HNO₃ 中 N(+5)→NO(+2)，得 3e⁻。
    $$3\text{As}_2\text{S}_3 + 28\text{HNO}_3 + 4\text{H}_2\text{O} \rightarrow 6\text{H}_3\text{AsO}_4 + 9\text{H}_2\text{SO}_4 + 28\text{NO}\uparrow$$

> 本题为选做，涉及复杂多元素同时变价，第二轮将系统训练。
