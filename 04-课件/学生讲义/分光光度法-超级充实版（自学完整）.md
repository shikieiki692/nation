## 一、Lambert-Beer 定律

> **关联知识点**：[[03-知识点/分析化学/Lambert-Beer定律]] · [[03-知识点/分析化学/分光光度法]]
> **考纲对应**：§20 分光光度法

### 1.1 定律的表述

**Lambert-Beer 定律**（朗伯-比尔定律）是分光光度法定量分析的基石：

$$A = \lg\frac{I_0}{I_{\mathrm{t}}} = \kappa b c$$

| 符号 | 名称 | 单位 | 物理意义 |
|:---|:---|:---:|:---|
| $A$ | 吸光度 | 无量纲 | 反映溶液对光的吸收程度 |
| $I_0$ | 入射光强度 | — | — |
| $I_{\mathrm{t}}$ | 透射光强度 | — | — |
| $T$ | 透射比（透光度）| 无量纲（或 %）| $T = I_{\mathrm{t}}/I_0$ |
| $\kappa$（或 $\varepsilon$）| 摩尔吸收系数 | $\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$ | 吸收灵敏度的特征常数 |
| $b$ | 液层厚度（光程）| cm | 通常用 1 cm 吸收池 |
| $c$ | 浓度 | $\mathrm{mol\cdot L^{-1}}$ | — |

![[f3b13d5b25e048c72d46429249e6522dfd7dc3d27a991e4ff92da0340b283dce.jpg]]
*图 1 Lambert-Beer 定律示意图——入射光通过溶液后强度减弱，吸光度 A 与浓度 c、光程 b 成正比。*

> [!info] 深入思考
> 吸收就像"光被切走几刀"——浓度越高、光程越长，被切走的光越多。但吸光度是**对数刻度**：每切走 90% 光，$A$ 才 +1。

### 1.2 吸光度与透射比的关系

$$A = \lg\frac{1}{T} = -\lg T$$

- $T$ 范围 0~1（0%~100%），$A$ 范围 0~∞
- **$T$ 从 100% → 10% 时，$A$ 从 0 → 1**（对数关系！）

> **易错提醒**：**$A$ 与 $T$ 不是反比，是对数关系**。浓度加倍 → $A$ 加倍 → $T$ 是原来的**平方**（不是减半）。例：$T = 50\%$（$A = 0.30$），浓度加倍 → $A = 0.60$ → $T = 25\%$。

> [!example] 练一练
> $T = 40.0\%$ 时 $A = ?$（$\kappa = 2.0\times10^4$，$b = 1$ cm 时 $c = ?$）
>
> **答案**：$A = -\lg 0.400 = 0.398$；$c = \frac{0.398}{2.0\times10^4 \times 1} = 1.99\times10^{-5}$ mol/L。

### 1.3 吸光度的加和性

若溶液含多种吸光物质且无相互作用：

$$A_{\text{总}} = A_1 + A_2 + \cdots + A_n = \sum \kappa_i b c_i$$

这是**多组分同时测定**的理论基础（双波长联立方程组）。

### 1.4 摩尔吸收系数与灵敏度

- **$\kappa$ 的物理意义**：浓度 1 mol/L、光程 1 cm 时的吸光度——是物质固有的吸收本领
- **$\kappa$ 灵敏度分级**：$<10^4$ 低；$10^4\sim 5\times10^4$ 中；$5\times10^4\sim 10^5$ 高；$>10^5$ 超高
- **桑德尔灵敏度** $S = \frac{M}{\kappa}$（$\mu\mathrm{g}\cdot\mathrm{cm}^{-2}$）——能检出 1 cm² 截面上被测物的质量，$S$ 越小灵敏度越高

> 竞赛中 $\kappa$ 常见数值：邻二氮菲-Fe²⁺ $\kappa = 1.1\times10^4$，丁二酮肟-Ni²⁺ $\kappa = 1.3\times10^4$。

## 二、吸收光谱与波长选择

> **关联知识点**：[[03-知识点/分析化学/分光光度法]]
> **考纲对应**：§20 分光光度法

### 2.1 吸收光谱

**吸收光谱**（吸收曲线）以**波长为横坐标、吸光度为纵坐标**。关键特征：
- **最大吸收波长** $\lambda_{\max}$：此处吸光度最大，灵敏度最高
- 同一物质不同浓度时，光谱形状和 $\lambda_{\max}$ **不变**，仅 $A$ 值改变——这是定量分析的依据

![[9b02e6d89681c6fb5cdd43595815a28d1e8a31b5352fc4b20f78e058321e4bac.png]]
*图 2 吸收光谱（吸收曲线）——横轴波长，纵轴吸光度，峰值对应最大吸收波长 λmax。不同浓度仅吸光度成比例变化，形状不变。*

### 2.2 测定波长选择

- **首选 $\lambda_{\max}$**：灵敏度最高，且此处吸收曲线最平坦（$\kappa$ 随波长变化小，非单色光影响小）
- **有干扰时**：选"**吸收最大、干扰最小**"的波长——即使灵敏度稍低，但准确度更高

> **易错提醒**：$\lambda_{\max}$ 不是无条件最优。如丁二酮肟镍 $\lambda_{\max} = 470$ nm 但 Fe 在此有干扰，可改选 520 nm 测定。

## 三、偏离 Lambert-Beer 定律的原因

> **考纲对应**：§20 分光光度法

严格说，Lambert-Beer 定律只在**稀溶液**和**单色光**下成立。两类偏离：

### 3.1 光学因素——非单色光

- 实际仪器是复合光（非严格单色光）
- 不同波长 $\kappa$ 不同 → $A$-$c$ 曲线向吸光度轴弯曲（**负偏离**）
- **克服**：选 $\lambda_{\max}$（此处 $\kappa$ 随波长变化最小）

### 3.2 化学因素

| 原因 | 说明 | 示例 |
|:---|:---|:---|
| **解离** | 酸碱型吸光物质随 pH 变化 | 指示剂不同 pH 颜色不同 |
| **缔合** | 高浓度时分子间作用改变吸收 | 高浓度标准曲线向下弯 |
| **配位** | 多级配合物各级配比不同 | Fe(SCN)$_n^{3-n}$ 随 SCN⁻ 增大颜色加深 |
| **互变异构** | 同一物质不同结构吸收不同 | CrO₄²⁻ 酸中变 Cr₂O₇²⁻ |

> **竞赛高频考点**：高浓度时标准曲线**向 $c$ 轴弯曲**（负偏离）——分子间相互作用使有效吸光度小于预期。

> [!example] 练一练
> 某学生发现高浓度区（$c > 5.0\times10^{-4}$ mol/L）的 $A$-$c$ 点明显向 $c$ 轴弯曲。可能原因？如何避免？
>
> **答案**：化学因素主导（高浓度解离/缔合/配合比改变）+ 光学因素（非单色光）。避免：控制浓度在 $A = 0.2\sim 0.8$ 线性范围内、必要时稀释、选 $\lambda_{\max}$。

## 四、最佳测量条件

> **考纲对应**：§20 分光光度法

| 项目 | 最优值 | 原因 |
|:---|:---|:---|
| 最佳吸光度范围 | $A = 0.2\sim 0.8$（$T = 15\%\sim 65\%$）| 读数误差较小 |
| **误差最小点** | $A = 0.434$（$T = 36.8\%$）| 相对误差最小 |
| 测定波长 | $\lambda_{\max}$ 或"吸收最大干扰最小"| 灵敏度 + 选择性 |

> [!info] 深入思考
> $A$ 太小（近 0）时测量信号弱，$A$ 太大（近 2）时透射光太弱、仪器噪声占比大——**0.434 是"信号/噪声"的最优点**。

## 五、显色反应

> **考纲对应**：§20 分光光度法

### 5.1 显色反应要求

将无色/浅色离子转化为有色配合物。要求：

| 要求 | 标准 | 原因 |
|:---|:---:|:---|
| 灵敏度高 | $\kappa > 10^4$ | 可测低浓度 |
| 选择性好 | 干扰少或易消除 | 避免分离 |
| 组成恒定 | 配合比确定 | 计量关系稳定 |
| 性质稳定 | 配合物不易分解 | 重现性好 |
| 色差大 | $\Delta\lambda > 60$ nm | 容易区分 |

### 5.2 显色条件优化

**酸度（pH）→ 显色剂用量 → 反应时间 → 温度 → 溶剂**

> **易错提醒**：标准曲线和样品测定必须在**完全相同的显色条件**下进行。磺基水杨酸-Fe³⁺ 在 pH 2~3 紫红（1:1）、pH 4~7 橙（1:2）、pH 8~10 黄（1:3）——$\kappa$ 完全不同，条件不一致结果不可比。

## 六、仪器与参比溶液

> **关联知识点**：[[03-知识点/分析化学/分光光度法]]
> **考纲对应**：§20 分光光度法

### 6.1 可见分光光度计结构

$$\text{光源} \rightarrow \text{单色器} \rightarrow \text{吸收池} \rightarrow \text{检测器} \rightarrow \text{显示记录}$$

| 部件 | 功能 | 可见区常用 |
|:---|:---|:---:|
| 光源 | 提供复合光 | 钨丝灯（360~800 nm）|
| 单色器 | 分解复合光 | 棱镜（玻璃）或光栅 |
| 吸收池 | 盛放试液 | 玻璃池（可见区）；石英池（紫外区）|
| 检测器 | 光→电信号 | 光电管或光电倍增管 |

![[231e0c602f53b2f9152816f2ffa13129fee0ddd1df3a513118e0a7516894a311.png]]
*图 3 可见分光光度计基本结构——光源 → 单色器 → 吸收池 → 检测器 → 显示。核心功能是分解复合光并测定各波长单色光的吸收。*

### 6.2 参比溶液选择

| 情况 | 参比溶液 | 目的 |
|:---|:---|:---|
| 试液和显色剂均无色 | 蒸馏水/溶剂空白 | 扣除吸收池和溶剂影响 |
| 显色剂无色，试液有色 | **不加显色剂的试液** | 扣除试液本底 |
| 显色剂有色 | **试剂空白**（仅显色剂）| 扣除显色剂颜色 |
| 两者均有色 | **加掩蔽剂的试液** | 扣除共同影响 |

> **参比溶液选择原则**：**扣除一切非待测组分的吸收贡献**。

## 七、标准曲线法

> **考纲对应**：§20 分光光度法

### 7.1 操作步骤

```
① 配制系列标准溶液（4~6 个不同浓度）
② 在 λ_max 处测定各标准溶液的 A
③ 以 A 为纵坐标、c 为横坐标作 A-c 标准曲线
④ 测定未知样品的 A
⑤ 在标准曲线上查得浓度 c
```

**注意**：标准曲线必须在**线性范围**内使用（$A = 0.2\sim 0.8$），且每次测定需同时带标准曲线。

### 7.2 常见问题

- 标准曲线**不过原点**：参比溶液选择不当、存在系统误差
- 标准曲线**弯曲**：偏离 Beer 定律（高浓度或非单色光）
- 标准曲线**斜率异常**：波长不准或显色条件（pH、时间）不当

> [!example] 练一练
> 标准数据 $c$/10⁻⁵: 0,2,4,6,8,10 → A: 0,0.220,0.440,0.660,0.880,1.100。未知样 $A = 0.550$。求浓度。
>
> **答案**：斜率 $k = \frac{1.100}{10.00\times10^{-5}} = 1.100\times10^4$；$c_x = \frac{0.550}{1.100\times10^4} = 5.00\times10^{-5}$ mol/L。

## 八、典型例题

### 例1 [Lambert-Beer 基础计算]（基础）　▸ [[04-题库/教材习题/赵鑫光/题-赵鑫光-容量分析-光度例1|赵鑫光-光度例1]]

1.0 μg/mL Fe²⁺ 邻二氮菲显色，2 cm、510 nm，$A = 0.380$。求 $T$、吸光系数 $a$、摩尔吸收系数 $\varepsilon$。

**解析**：$T = 10^{-0.380} = 0.417$；$a = \frac{A}{bc} = \frac{0.380}{2 \times 1.0\times10^{-6}\ \mathrm{g/mL}} = 1.9\times10^2\ \mathrm{L\cdot g^{-1}\cdot cm^{-1}}$；换算为摩尔：$c = \frac{1.0\times10^{-6}}{55.85} = 1.79\times10^{-8}$ mol/mL $= 1.79\times10^{-5}$ mol/L；$\varepsilon = \frac{0.380}{2 \times 1.79\times10^{-5}} = 1.1\times10^4$。

**答案**：$T = 0.417$，$a = 1.9\times10^2$，$\varepsilon = 1.1\times10^4$。

> **核心辨析**：$A$-$T$ 换算（对数）与 g/L→mol/L 单位转换是这类题的两个关键动作。

### 例2 [桑德尔灵敏度]（进阶）　▸ [[04-题库/教材习题/赵鑫光/题-赵鑫光-容量分析-光度例2|赵鑫光-光度例2]]

25.5 μg/50 mL Cu²⁺ 双环己酮草酰二腙，600 nm、2 cm，$T = 50.5\%$。求 $\varepsilon$ 和桑德尔灵敏度 $S$。

**解析**：$A = -\lg 0.505 = 0.297$；$c = \frac{25.5\ \mu\mathrm{g}}{50\ \mathrm{mL}} = 5.10\times10^{-4}\ \mathrm{g/L} = 8.03\times10^{-6}$ mol/L（$M_{\mathrm{Cu}} = 63.55$）；$\varepsilon = \frac{0.297}{2 \times 8.03\times10^{-6}} = 1.85\times10^4$；$S = \frac{63.55}{1.85\times10^4} = 3.4\times10^{-3}\ \mu\mathrm{g}\cdot\mathrm{cm}^{-2}$。

**答案**：$\varepsilon \approx 1.8\times10^4$，$S \approx 3.5\times10^{-3}$。

### 例3 [多组分联立]（挑战）　▸ [[04-题库/教材习题/赵鑫光/题-赵鑫光-容量分析-光度例3|赵鑫光-光度例3]]

Ti + V 与 H₂O₂ 络合，415/455 nm 双波长联立。由加和性列方程组，解出各组分浓度。

**解析**：$A_{415} = \varepsilon_{\mathrm{Ti,415}} b c_{\mathrm{Ti}} + \varepsilon_{\mathrm{V,415}} b c_{\mathrm{V}}$；$A_{455} = \varepsilon_{\mathrm{Ti,455}} b c_{\mathrm{Ti}} + \varepsilon_{\mathrm{V,455}} b c_{\mathrm{V}}$。已知各 $\varepsilon$ 后解二元一次方程组，注意稀释倍数回算。

**答案**：见题库文件（双波长联立，$c_{\mathrm{Ti}}$、$c_{\mathrm{V}}$）。

> **核心辨析**：多组分测定的前提是**吸光度加和性**——各组分无相互作用、分别在两波长有不同 $\varepsilon$。

### 例4 [摩尔比法测组成]（挑战）　▸ [[04-题库/教材习题/赵鑫光/题-赵鑫光-容量分析-光度例4|赵鑫光-光度例4]]

固定 $c(\mathrm{Fe^{2+}}) = 8\times10^{-6}$，改变 $c(\mathrm{phen}) = k\cdot c_0$，516 nm。$k \geq 3$ 时 $A$ 平台 → $n = 3$（Fe(phen)₃）；由离解度 $\alpha$ 算 $K_{\text{稳}}$。

**解析**：摩尔比法——配位剂浓度增大到配位饱和时 $A$ 不再增加，拐点对应配比。$n = 3$ 说明 Fe²⁺ : phen = 1 : 3。由拐点前后离解度求稳定常数。

**答案**：Fe(phen)₃，$K_{\text{稳}} \approx 2.1\times10^{21}$（见题库文件）。

### 例5 [指示剂 HIn 吸光度-pH]（挑战）　▸ [[04-题库/教材习题/赵鑫光/题-赵鑫光-容量分析-光度例5|赵鑫光-光度例5]]

$\mathrm{Ka} = 5.4\times10^{-7}$ 指示剂，三波长强酸/强碱 $A$ 数据。求等吸收点、酸型颜色、pH 为 6.02 时的组成。

**解析**：等吸收点（555 nm）处 $A$ 与 pH 无关；由 $\mathrm{pH} = \mathrm{p}K_a + \lg\frac{[\mathrm{In^-}]}{[\mathrm{HIn}]}$ 求型体比；$A$ 加合性验证。

**答案**：见题库文件（等吸收点 555 nm，pH = 6.02）。

> **核心辨析**：酸碱型指示剂吸光度随 pH 变化的本质是两种型体比例改变——这同时是**分光光度法测 pKa** 的原理（衔接初赛 9.41 二甲基黄）。

## 九、本讲速查

| 概念 | 公式/规则 | 关键点 |
|:---|:---|:---|
| Lambert-Beer | $A = \kappa b c$ | $A$ 与 $c$ 成正比 |
| $A$-$T$ 关系 | $A = -\lg T$ | 对数关系，非反比 |
| 加和性 | $A_{\text{总}} = \sum \kappa_i b c_i$ | 多组分同时测定基础 |
| 摩尔吸收系数 | $\kappa = A/(bc)$ | 物质固有吸收本领 |
| 桑德尔灵敏度 | $S = M/\kappa$ | 越小灵敏度越高 |
| 最佳范围 | $A = 0.2\sim 0.8$ | $T = 15\%\sim 65\%$ |
| 最小误差点 | $A = 0.434$ | $T = 36.8\%$ |
| 波长选择 | $\lambda_{\max}$ 或"吸收最大干扰最小"| 有干扰时舍灵敏度保准确 |
| 偏离定律 | 化学（解离/缔合/配位）+ 光学（非单色光）| 稀溶液 + 单色光 + 均匀介质 |

### 标准曲线法流程

```text
配标准系列 → 选 λ_max → 测 A → 画 A-c 曲线 → 测样品 A → 查浓度
   (4-6个)       (灵敏度)   (0.2-0.8)        (线性范围)   (相同显色条件)
```

## 十一、参考答案与提示

### 基础巩固答案

**1.** $A = -\lg 0.50 = 0.30$；$T = 10^{-0.60} = 0.25 = 25\%$。

**2.** $c = \frac{0.56}{2.0\times10^4 \times 1} = 2.8\times10^{-5}$ mol/L。

**5.** 化学因素（高浓度解离/缔合/配合比改变）+ 光学因素（非单色光）→ 负偏离，曲线向 $c$ 轴弯。

**6.** 斜率 $k \approx 0.0600$；$c_x = \frac{0.325}{0.0600}\times10^{-5} = 5.42\times10^{-5}$ mol/L。

| 模块 | 本讲拿走什么 |
|:---|:---|
| 定量原理 | $A = \kappa b c$；$A = -\lg T$（对数）；加和性 |
| 测量条件 | 选 $\lambda_{\max}$（或吸收最大干扰最小）；$A = 0.2\sim 0.8$；最小误差 $A = 0.434$ |

| 方法实现 | 显色条件一致 → 参比溶液 → 标准曲线法查浓度 |

## 附：核心公式速查

> 考前一张纸：按模块查公式。易错提醒与正文各节 [!warning] 呼应。

### 定量原理 · Lambert-Beer 定律

| 公式 / 规则 | 适用条件 / 要点 | 易错提醒 |
|:---|:---|:---|
| $A = \kappa b c$ | 单色光、稀溶液、均匀介质、无散射 | $c$ 必须换成摩尔浓度；$\kappa$ 单位 $L\cdot mol^{-1}\cdot cm^{-1}$ |
| $A = -\lg T$ | $T$ 为透光率（0~1），%T 先 ÷100 | $T$ 减半 ≠ $A$ 减半：$T$ 平方 ⇔ $A$ 加倍（对数刻度） |
| $A = A_1 + A_2 + \cdots$ | 多组分彼此无相互作用 | 加和的是吸光度，不是透光率 |

### 测量条件 · 波长与读数范围

| 公式 / 规则 | 适用条件 / 要点 | 易错提醒 |
|:---|:---|:---|
| 选 $\lambda_{\max}$ | 无干扰时取最大吸收波长 | 有干扰时选「吸收最大、干扰最小」波长，$\lambda_{\max}$ 并非无条件最优 |
| $A = 0.2\sim 0.8$ | 最佳测量范围 | 最小相对误差在 $A = 0.434$（即 $T = 36.8\%$） |
| 标准曲线 $A = kc + b$ | 参比溶液校正系统误差 | 不过原点未必废弃——先查参比与显色条件，必要时用 $A = kc + b$ 截距式 |

### 方法实现 · 显色与定量

| 公式 / 规则 | 适用条件 / 要点 | 易错提醒 |
|:---|:---|:---|
| $\varepsilon = A/(bc)$ | 先统一到摩尔浓度 | 样品 g/L 必须先换 mol/L 再算 $\varepsilon$ |
| **稀释回算**：$c_0 = c_1 \times n$ | 稀释后测定，$n$ 为稀释倍数 | 忘记乘稀释倍数是高频失误，原始浓度会偏低 |
| 显色条件一致 | 标准曲线与样品同步操作 | 显色剂用量、pH、时间、温度必须完全相同 |

### 偏离 Beer 定律 · 原因判别

| 偏离类型 | 主要原因 | 判断要点 |
|:---|:---|:---|
| 化学偏离 | 解离、缔合、配位、互变异构 | 高浓度弯曲常见；稀释后 $A$-$c$ 仍非线性 |
| 光学偏离 | 非单色光 | 吸收光谱越宽偏离越明显；可用窄带滤光或锐线光源 |
