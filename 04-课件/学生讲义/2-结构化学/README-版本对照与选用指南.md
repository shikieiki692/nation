## 一、为什么同一主题会有多份？

化学原理 / 有机化学 / 元素与分析三个模块：每份主题唯一，命名统一为 `XX-超级充实版（自学完整）`，不显乱。

**只有结构化学模块**混用了 7 种后缀（超级充实版 / 补充 / 深化 / 新课 / 第一轮基础版（普化原理）/ 教师增强版 / 超级充实融合版 / 前置知识速查），所以看起来「好几个相同、分不清」。

本目录共 **22 份** md ＝ **12 份现役主线**（`…-超级充实版（自学完整）`）＋ **10 份非现役**（9 份变体 ＋ 1 份本说明）。**目录为平铺，无子文件夹。**

## 七、给学生发哪份？

默认发每个主题的 **「超级充实版（自学完整）」**（12 份现役主线）；需要进阶时再发「补充 / 深化」。

其余版本（基础版 / 新课 / 教师增强版 / 超级充实融合版 / 前置知识速查 / 跨主题合集）属**同源早期版、教师专属或复习合集**，非必发——除非明确要发给学生某一轮次的特定版本。
