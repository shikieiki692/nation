# 数学工具区 · 全册导言与大纲

> 本文件是**导言与大纲**，不是讲义正文，不进讲义统计（脚本按 `README` 前缀排除）。
> 每讲一个独立文件，文件名前缀 `数学工具-第N讲-`，与库内「第X讲」命名习惯一致。

## 一、为什么有这个区

化学竞赛的物理化学部分要用到一批高中数学课不讲的工具：`d[A]/dt`、`∂G/∂p`、`∫`、配分函数里的 `ln(N!)`。
**现有 65 份讲义在大量使用这些符号，但库内原本没有任何一页材料解释它们**——扫描结果：偏导 3 处、微分式贯穿动力学全篇、积分 40 处、ln/对数 738 次命中、统计与配分函数 584 次命中，而数学讲义 0 份、数学类知识点页 0 个。

三处已确认的能力断层：

| 讲义 | 轮次 | 断层 |
|:--|:--|:--|
| 有效数字与误差分析 | 第二轮 | 误差传递公式直接给 `∂R/∂A`，`∂` 从未解释 |
| 化学动力学 | 第一轮 | 开篇即 `v = −d[A]/dt`；积分式计算被 🔒 推到第三轮 |
| 统计热力学与Maxwell关系 | 决赛 | 直接假定"二阶混合偏导数相等"，还配记忆口诀 |

## 二、深度口径（2026-09-10 用户修订）

初版定位是"认符号 + 套公式，不教到会算"。**用户要求上调为"按新课讲法讲仔细，导数微分、偏导、积分要讲计算"**。现口径：

**要讲到会算**：
- 多项式、幂函数、指数函数、对数函数的导数；四则法则；一重复合的链式法则
- 微分 `dy` 的写法与线性近似 `Δy ≈ dy`
- 5 条基本积分公式；定积分的面积含义；分离变量法解一阶微分方程（导出零/一/二级积分速率方程）
- 偏导数的计算、全微分、二阶混合偏导相等（用于推导 Maxwell 关系）

**不追求**（控制篇幅，避免变成数学教材）：
- ε-δ 严格极限定义、多元链式法则一般式、泰勒级数一般式
- 线性代数、群论、复变函数
- 积分技巧（换元法、分部积分只给最简情形）

## 四、怎么配合化学讲义用

不要从头读到尾。**上物化课遇到看不懂的符号 → 跳到对应讲次读 20~30 分钟 → 回化学讲义**。

| 化学讲义 | 卡在哪里 | 补哪一讲 |

### 中文怎么拿（优先看这段）

中文没有 LibreTexts 那种 CC 授权全本，但有两条真实可走的通道：

**通道一：全国图书馆参考咨询联盟（免费，中文书章节直发邮箱）**

- 网址 `ucdrs.superlib.net`，**邮箱注册即可用**，公益性、免费，不限高校身份
- 检索到书 → 点「图书馆文献传递」→ 填页数与邮箱 → **一天内收到 PDF**
- 限制：**每本书每天 ≤ 50 页，一周 ≤ 全书的 80%**，邮件 20 天内限打开 20 次
- 用法要点：**先定好要哪几章再申请**，别整本申请，省额度

最划算的申请清单（按本册讲次排序）：

| 想补哪一讲 | 申请哪本书的哪一章 | 大约页数 |
|:--|:--|:--|
| 第 3 讲 导数与微分 | 《物理化学中的数学》廖沐真译（科学社 1987）**第三章 函数和微分运算** 3-3 导数、3-4 微分、3-5 导数若干有用的事实、3-6 高阶导数、3-7 极大极小 | ≈25 页 |
| 第 4 讲 积分 | 同上 **第四章 积分运算** 4-2 反导数、4-3 积分、4-4 不定积分表、4-6 几率分布与平均值；**第七章 7-4 可分离变量的微分方程** | ≈35 页 |
| **第 5 讲 偏导** | 同上 **第六章 多自变量微积分** 6-2 微分和偏导数、6-3 变量变换、6-4 偏导数关系式、6-5 恰当与不恰当微分 —— **这一章是全册最该拿到手的** | ≈30 页 |
| 第 1 讲 最小二乘 | 同上 **第十章 实验数据处理**（曲线拟合、误差传递） | ≈20 页 |

> 两本书都在科学出版社，属该平台中文电子图书库（230 万种）覆盖范围内，命中率很高。

**通道二：科学文库（科学出版社电子书平台）**

- `book.sciencereading.cn`，5.6 万种以上**中文**电子书，原版高清 PDF，可在线读也可下载借阅
- 关键：上面那两本中译本正是科学出版社出的，**大概率在库**
- 访问：机构 IP 或 CARSI 校外认证。中学若无高校账号，可试所在省市公共图书馆（多数省图已购），或走通道一
