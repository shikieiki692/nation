## 三、对数与指数（§2）

```
ln(xy) = ln x + ln y        ln(x/y) = ln x − ln y        ln(x^n) = n ln x
lg x = ln x / 2.303         ln x = 2.303 lg x
e^{ln x} = x                10^{lg x} = x
```

| 必背 | 值 |
|:--|:--|
| $\lg 2$ | `0.3010` |
| $\lg 3$ | `0.4771` |
| $\lg 7$ | `0.8451` |
| $\ln 2$ | `0.6931` |
| $\ln 10$ | `2.3026` |
| $e$ | `2.7183` |

**常用近似**（$\lvert x\rvert\ll1$ 时）：

```
ln(1+x) ≈ x − x²/2          e^x ≈ 1 + x
(1+x)^n ≈ 1 + nx            sin x ≈ x（x 用弧度）
```

## 四、导数表（§3）

| $f(x)$ | $f'(x)$ |
|:--|:--|
| $c$（常数） | `0` |
| $x^n$ | $nx^{n-1}$ |
| $\dfrac1x$ | $-\dfrac1{x^2}$ |
| $\sqrt x$ | $\dfrac1{2\sqrt x}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x\ln a$ |
| $\ln x$ | $\dfrac1x$ |
| $\log_a x$ | $\dfrac1{x\ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |

**法则**：

```
(cu)' = c u'                        (u+v)' = u' + v'
(uv)' = u'v + uv'                   (u/v)' = (u'v − uv')/v²
链式：[f(g(x))]' = f'(g(x))·g'(x)
```

**微分与线性近似**：$dy = f'(x)\,dx$；$f(x+\Delta x)\approx f(x) + f'(x)\Delta x$

**极值判据**：$f'(x_0)=0$；$f''(x_0)>0$ 极小，$<0$ 极大。

## 五、积分表（§4，8 条够用）

| 被积函数 | 原函数 |
|:--|:--|
| $x^n\ (n\neq-1)$ | $\dfrac{x^{n+1}}{n+1}$ |
| $\dfrac1x$ | $\ln\lvert x\rvert$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x/\ln a$ |
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\dfrac1{x+a}$ | $\ln\lvert x+a\rvert$ |
| $\dfrac1{(x+a)^2}$ | $-\dfrac1{x+a}$ |

**定积分**：$\displaystyle\int_a^b f(x)dx = F(b)-F(a)$（$F'=f$）
**平均值**：$\langle f\rangle = \dfrac1{b-a}\displaystyle\int_a^b f(x)dx$

**零/一/二级反应速率方程**（由分离变量导出）：

| 级数 | 速率方程 | 积分式 | 直线关系 | 半衰期 |
|:--|:--|:--|:--|:--|
| 0 | $v=k$ | $[\mathrm{A}]=[\mathrm{A}]_0-kt$ | $[\mathrm{A}]$–$t$ | $[\mathrm{A}]_0/(2k)$ |
| 1 | $v=k[\mathrm{A}]$ | $\ln[\mathrm{A}]=\ln[\mathrm{A}]_0-kt$ | $\ln[\mathrm{A}]$–$t$ | $0.693/k$ |
| 2 | $v=k[\mathrm{A}]^2$ | $\dfrac1{[\mathrm{A}]}=\dfrac1{[\mathrm{A}]_0}+kt$ | $1/[\mathrm{A}]$–$t$ | $1/(k[\mathrm{A}]_0)$ |

## 六、偏导与 Maxwell 关系（§5）

**记号**：$\left(\dfrac{\partial G}{\partial p}\right)_T$ 读「定温下 $G$ 对 $p$ 的偏导」，下标是**被固定**的量。

**全微分**：$df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy$

**混合偏导相等**（Clairaut）：$\dfrac{\partial^2f}{\partial x\partial y} = \dfrac{\partial^2f}{\partial y\partial x}$

**恰当微分判据**：$Mdx+Ndy$ 恰当 ⇔ $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$ ⇔ 对应一个状态函数。

**四个热力学势的全微分**：

```
dU = T dS − p dV
dH = T dS + V dp
dA = −S dT − p dV
dG = −S dT + V dp
```

**四条 Maxwell 关系**（由混合偏导相等推出，不要背口诀，现推）：

```
(∂T/∂V)_S = −(∂p/∂S)_V        （由 dU）
(∂T/∂p)_S =  (∂V/∂S)_p        （由 dH）
(∂S/∂V)_T =  (∂p/∂T)_V        （由 dA）
(∂S/∂p)_T = −(∂V/∂T)_p        （由 dG）
```

**误差传递**：

```
ΔR ≈ |∂R/∂A|·ΔA + |∂R/∂B|·ΔB + …            （最坏情形）
σ_R = sqrt( (∂R/∂A)²σ_A² + (∂R/∂B)²σ_B² + … ) （方和根）
```
特例：
- $R = A+B$：$\Delta R = \Delta A + \Delta B$（绝对误差相加）
- $R = AB$ 或 $A/B$：$\dfrac{\Delta R}{R} = \dfrac{\Delta A}{A} + \dfrac{\Delta B}{B}$（**相对**误差相加）
- $R = A^n$：$\dfrac{\Delta R}{R} = n\dfrac{\Delta A}{A}$

## 七、组合与 Stirling（§7）

```
P(n,m) = n!/(n−m)!                    C(n,m) = n!/(m!(n−m)!)
C(n,m) = C(n, n−m)                    Σ_m C(n,m) = 2^n
可区分球入 g 盒：g^N                  不可区分：C(N+g−1, N)
二项分布：P(n) = C(N,n) p^n (1−p)^{N−n}
        ⟨n⟩ = Np        σ = sqrt(Np(1−p))
```

**Stirling**：

```
ln N! ≈ N ln N − N                        （N ≳ 10³，化学常用）
ln N! ≈ N ln N − N + ½ ln(2πN)            （N ≲ 100 时必须用）
```

| $N$ | $\ln N!$ 真值 | 简单式误差 |
|:--|:--|:--|
| 10 | 15.104 | 13.7% |
| 100 | 363.74 | 0.89% |
| 1000 | 5912.1 | 0.074% |
| $10^{23}$ | $5.20\times10^{24}$ | `~10⁻²⁴`（可忽略） |

**统计热力学两条**：

```
S = k ln W
ΔS_mix = −nR Σ x_i ln x_i        等摩尔二元 = R ln 2 = 5.76 J mol⁻¹ K⁻¹
Boltzmann 分布：N_i/N = g_i e^{−ε_i/kT} / q        q = Σ_i g_i e^{−ε_i/kT}
```

## 八、量纲速查（§6）

| 量 | 量纲式 |
|:--|:--|
| 能量 | $ML^2T^{-2}$ |
| 压力 | $ML^{-1}T^{-2}$ |
| 黏度 | $ML^{-1}T^{-1}$ |
| 扩散系数 | $L^2T^{-1}$ |
| 表面张力 | $MT^{-2}$ |
| 电位 / 电动势 | $ML^2T^{-3}I^{-1}$ |
| Faraday 常数 | $ITN^{-1}$ |
| 速率常数（$n$ 级） | $(\mathrm{L\,mol^{-1}})^{n-1}\mathrm{s^{-1}}$ |

**两条铁律**：①只有同量纲的量能相加减；②$\ln$、$\exp$、$\sin$ 的自变量**必须无量纲**。

**估算四法**：一位有效数字 / 上下界夹逼 / 对数化 / 分解（Fermi）。

## 九、易错清单（按出现频率排序）

1. $\ln p$ 非法 → 写 $\ln(p/p^\circ)$。
2. $A$ 与 $k$ 单位不一致（Arrhenius）。
3. $\lg(x\times10^n)$ 算成 $n+\lg x$ 时符号写错（如 $\lg(6\times10^{-4}) = -3.222$，**不是** `-4.778`）。
4. 混淆 $\Delta$（有限变化）与 $d$、$\delta$（无限小；$\delta$ 用于非状态函数）。
5. 偏导下标漏写或写错（$(\partial p/\partial T)_p$ 无意义）。
6. 积分忘常数 $C$（不定积分）/ 定积分上下限代反。
7. 忽略 $(1/[\mathrm{A}])$ 二级图斜率为 **$+k$**（负号在 $\int x^{-2}dx=-x^{-1}$ 中已抵消）。
8. Stirling 在小 $N$（`<100`）用简单式 → 熵值偏大。
9. 单位未换算就代入（旧书 atm、cal、Å）。
10. 相对误差在乘除中**相加**，在幂运算中**乘指数**。
