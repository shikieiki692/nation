# 第6讲：量纲、数量级与估算——算之前先知道答案长什么样

## 学习目标

1. 能说清「数值」「单位」「量纲」三者的区别，会对常见化学量写出量纲式。
2. 掌握**量纲一致性**的两条规则，并能用它们在 10 秒内判断一个公式是否可能正确。
3. 理解为什么 `$\ln x$`、`$\exp x$`、`$\sin x$` 的自变量必须**无量纲**，并能找出化学式中隐藏的归一化（如 `$K$` 除以标准态、`$p$` 除以 `$p^\circ$`）。
4. 会用**量纲反推**速率常数 `$k$` 的单位（任意反应级数），以及由 `$k$` 的单位反推反应级数。
5. 会用「乘 1 法」做链式单位换算，记住化学里必背的五个换算常数（eV、cm⁻¹、atm·L、`$k_BT$`、`$RT/F$`）。
6. 会用科学记数法做数量级运算，会心算 `$\lg$`（只需背 `$\lg 2$`、`$\lg 3$`）。
7. 掌握四种估算手法（一位有效数字、上下界夹逼、对数化、分解），能估算教室里的分子数这一量级的问题。
8. 能在化学计算中现场使用五条快算律：`$\Delta G^\circ \approx -5.71\lg K$`、`$t_{1/2}=0.693/k$`、`$[\mathrm{H}^+]\approx\sqrt{K_ac}$`、`$\bar v\approx\sqrt{3RT/M}$`、`$E_{\text{光子}}\approx 119627/\lambda(\mathrm{nm})$`。

## 一、量纲：不看数字，先看它是「什么东西」

### 1.1 三件事别混为一谈

拿到 `12.0 g` 这个量，里面其实有三层信息：

| 层次 | 内容 | 例子 |
|:--|:--|:--|
| 数值 | 纯粹的数 | `12.0` |
| 单位 | 计量时约定的人为标准 | `g`、`kg`、`lb` |
| 量纲 | 这个量的**物理本质**，与单位选择无关 | 「质量」 |

换成 `0.0120 kg`，数值和单位都变了，但**量纲没变**——还是质量。正因为量纲与单位无关，它才能用来检验公式：一个正确的物理公式，在任何单位制下都必须成立。

### 1.2 七个 SI 基本量

化学里真正用到的只有前六个（发光强度 `cd` 用不上）：

| 物理量 | 单位符号 | 量纲记号 | 化学里的出现频率 |
|:--|:--|:--|:--|
| 长度 | m | `L` | 极高（键长、波长） |
| 质量 | kg | `M` | 极高 |
| 时间 | s | `T` | 极高（速率、半衰期） |
| 电流 | A | `I` | 中（电化学） |
| 热力学温度 | K | `$\Theta$` | 极高 |
| 物质的量 | mol | `N` | 极高 |

其余全是**导出量**。例如能量的量纲：`[E] = ML^2T^{-2}`（由 `$E=\frac12 mv^2$` 读出）；压力：`[p] = ML^{-1}T^{-2}`（力除以面积）。

### 1.3 常见化学量的量纲（背下来，检验公式时直接用）

| 量 | 常用单位 | 量纲式 |
|:--|:--|:--|
| 压力 `$p$` | Pa（`N/m²`） | `$ML^{-1}T^{-2}$` |
| 能量 `$U, H, G$` | J（mol 级用 J/mol） | `$ML^2T^{-2}$`（每 mol 再 `$N^{-1}$`） |
| 密度 `$\rho$` | kg/m³ | `$ML^{-3}$` |
| 黏度 `$\eta$` | Pa·s | `$ML^{-1}T^{-1}$` |
| 扩散系数 `$D$` | m²/s | `$L^2T^{-1}$` |
| 表面张力 `$\gamma$` | N/m | `$MT^{-2}$` |
| 速率 `$v$` | mol·L⁻¹·s⁻¹ | `$NL^{-3}T^{-1}$` |
| 气体常数 `$R$` | J·mol⁻¹·K⁻¹ | `$ML^2T^{-2}N^{-1}\Theta^{-1}$` |

> [!tip] 记法
> 不用死记。记住三个锚点：`$[E]=ML^2T^{-2}$`、`$[p]=E/L^3=ML^{-1}T^{-2}$`、`$[\text{浓度}]=NL^{-3}$`，
> 其余都能临时推出来。

## 二、量纲一致性：第一件武器

### 2.1 两条规则（整个量纲分析只有这两条）

**规则 A（加减）**：只有**量纲相同**的量才能相加减，结果的量纲不变。
**规则 B（等号）**：等式两边量纲必须相同；指数、对数的**自变量必须无量纲**。

乘法除法没有任何限制——量纲照常相乘除，得到新的量纲。比如由 `$v=s/t$` 得 `[v] = L/T = LT⁻¹`，完全合法。

### 2.2 规则 B 里最容易踩的坑：超越函数

为什么 `$\ln x$`、`$e^x$`、`$\sin x$` 里的 `$x$` 必须无量纲？看泰勒展开就明白了：

```
e^x = 1 + x + x²/2! + x³/3! + …
```

第一项 `1` 是无量纲的纯数。如果 `$x$` 带量纲（比如 Pa），那么 `1 + x` 就违反了规则 A。**所以 `$x$` 只能是纯数。**

这条推论在化学里是硬约束，直接导致三个必须记住的写法：

| 常见写法 | 是否合法 | 正确写法 |
|:--|:--|:--|
| `$\ln p$` | ✗ | `$\ln(p/p^\circ)$`，`$p^\circ = 1\ \mathrm{bar}$` |
| `$\ln K$` | ✗（严格） | `$K$` 应理解为以标准态归一化后的**无量纲**平衡常数 |
| `$e^{-E_a/RT}$` | ✓ | `$E_a$` 与 `$RT$` 量纲同为 J/mol，比值无量纲 |

> [!warning] 竞赛里的真实陷阱
> 用 `$\ln k = \ln A - E_a/RT$` 时，有人把 `$A$` 和 `$k$` 写成不同单位（例如 `$k$` 用 `L·mol⁻¹·s⁻¹`、`$A$` 用 `s⁻¹`）。
> 这是错的——`$\ln k - \ln A = \ln(k/A)$`，两者**必须同单位**。检验方法：`$A$` 与 `$k$` 的单位永远相同。

### 2.3 现场检验三个公式

**练一练 2-1**：检验 `$pV = nRT$` 的量纲。

## 三、量纲分析的三招

### 3.1 第一招：检验公式对错

这是最高频的用法。做法：把等式两边的量纲各写成 `$M^aL^bT^cN^d\Theta^e$`，比对指数。

**例 3-1：Clausius-Clapeyron 方程**

```
ln(p₂/p₁) = −(ΔH_vap/R)(1/T₂ − 1/T₁)
```

- 左边：`$p_2/p_1$` 同量纲相除 → 无量纲，`$\ln$` 合法，左边**无量纲** ✓
- 右边：`$\Delta H_{\text{vap}}/R$` → `$(ML^2T^{-2}N^{-1})/(ML^2T^{-2}N^{-1}\Theta^{-1}) = \Theta$`；`$(1/T_2-1/T_1)$` → `$\Theta^{-1}$`；乘积无量纲 ✓

两边都是无量纲，**通过检验**。

**例 3-2：Nernst 方程**

```
E = E° − (RT/nF)·ln Q
```

- `$RT/nF$`：`$[F] = ITN^{-1}$`（法拉第常数，C/mol），故 `$[RT/F] = ML^2T^{-2}N^{-1}/(ITN^{-1}) = ML^2T^{-3}I^{-1}$`
- 而 `$\text{V} = \text{J/C} = ML^2T^{-2}/(IT) = ML^2T^{-3}I^{-1}$` ✓ 完全一致
- `$\ln Q$`：`$Q$` 是无量纲活度商 ✓

**例 3-3：一个「看起来很像」的假公式**

有人把平均速率记成 `$\bar v = \sqrt{3RT/(2M)}$`，还有人记成 `$\bar v = 3RT/M$`（忘了开方）。后者一眼就被量纲枪毙：`$[3RT/M] = L^2T^{-2}$` 是**速度平方**的量纲，不是速度。

### 3.2 第二招：反推未知量的单位（`$k$` 单位公式）

速率方程 `$v = k[\mathrm{A}]^\alpha[\mathrm{B}]^\beta$`，总级数 `$n = \alpha+\beta$`：

```
[k] = [v]/[c]^n = (NL^{-3}T^{-1})/(NL^{-3})^n = (L^3N^{-1})^{n-1}T^{-1}
```

用浓度单位 mol/L、时间单位 s 写出来：

| 总级数 `$n$` | `$k$` 的单位 | 例子 |
|:--|:--|:--|
| 0 | `mol·L⁻¹·s⁻¹` | 表面催化零级反应 |
| 1 | `s⁻¹` | 一级衰变 |
| 2 | `L·mol⁻¹·s⁻¹` | 二级双分子反应 |
| 3 | `L²·mol⁻²·s⁻¹` | 三级反应 |

**逆用**：已知 `$k$` 的单位反推级数。若 `$k = 4.2\times10^{-3}\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$`，则 `$n=2$`。这是选择题的经典送分点。

> [!note] 用分压表示时
> 若速率方程用分压写 `$v_p = k_p p_A^\alpha$`，则 `$[k_p] = (\text{压强})^{1-n}\cdot(\text{时间})^{-1}$`，
> 例如二级： kPa⁻¹·s⁻¹。换算到浓度 `$k$` 时别忘了 `$c = p/RT$` 带来的 `$(RT)^{n-1}$` 因子。

### 3.3 第三招：猜公式（量纲法定指数）

当知道一个量依赖哪些变量、但不知道具体形式时，量纲能定出大部分指数。

**例 3-4：硬球气体的黏度**

设 `$\eta$` 只依赖分子质量 `$m$`、热运动能量 `$k_BT$`、碰撞直径 `$\sigma$`，且是幂律形式：

```
η ∝ m^a (k_BT)^b σ^c
```

写量纲（`$[m]=M$`，`$[k_BT]=ML^2T^{-2}$`，`$[\sigma]=L$`，`$[\eta]=ML^{-1}T^{-1}$`）：

| 基本量纲 | 左边 | 右边 |
|:--|:--|:--|
| `M` | 1 | `$a+b$` |
| `L` | −1 | `$2b+c$` |
| `T` | −1 | `$-2b$` |

解：`$-2b=-1 \Rightarrow b=1/2$`；`$a+b=1 \Rightarrow a=1/2$`；`$2b+c=-1 \Rightarrow c=-2$`。

```
η ∝ sqrt(m k_B T) / σ²
```

这正是硬球模型黏度的正确形式（差一个数量级为 1 的常数因子）。**注意**：量纲法只能定出指数，定不出那个常数——这是它的能力边界。

## 四、单位换算：乘 1 法

### 4.1 方法：把换算当成「乘以 1」

任何等式都能写成比值等于 1 的形式，例如 `1 eV = 1.602×10⁻¹⁹ J`，于是 `$\dfrac{1.602\times10^{-19}\ \mathrm{J}}{1\ \mathrm{eV}} = 1$`。链式相乘，单位自然约掉：

```
1.5 eV × (1.602e-19 J / 1 eV) × (6.022e23 / 1 mol) = 1.447e5 J/mol = 144.7 kJ/mol
```

不需要记「eV 换算 kJ/mol 的公式」，只需要记 `1 eV = 96.485 kJ/mol` 这个结论来提速。

### 4.2 化学必背换算表

| 关系 | 数值 | 用途 |
|:--|:--|:--|
| `$1\ \mathrm{eV}$` | `96.485 kJ/mol` | 电离能、功函数、能带 |
| `$1\ \mathrm{cm^{-1}}$` | `11.96 J/mol = 0.01196 kJ/mol` | 红外、转动光谱 |
| `$1\ \mathrm{atm\cdot L}$` | `101.325 J` | `$\Delta U = q + w$` 的体积功 |
| `$1\ \mathrm{cal}$` | `4.184 J` | **老书**（Mortimer 早期中译本用 cal） |
| `$k_BT$`（298 K） | `4.11×10⁻²¹ J = 208.5 cm⁻¹ = 2.48 kJ/mol` | 判断「热能不能不能克服」 |
| `$RT$`（298 K） | `2.479 kJ/mol` | `$\Delta G^\circ = -RT\ln K$` |
| `$RT/F$`（298 K） | `25.69 mV` | Nernst 方程 |
| `$(2.303RT/F)$`（298 K） | `59.16 mV` | Nernst 的 `$\lg$` 形式 |

### 4.3 R 的四张面孔（看清楚题里给的是什么单位）

| `$R$` | 配套单位 |
|:--|:--|
| `8.314` | `J·mol⁻¹·K⁻¹`（**首选**，SI） |
| `0.08206` | `L·atm·mol⁻¹·K⁻¹` |
| `0.08314` | `L·bar·mol⁻¹·K⁻¹` |
| `1.987` | `cal·mol⁻¹·K⁻¹`（老书） |

> [!warning] 旧译本的坑
> Mortimer 中译本（廖沐真等译，科学出版社 1987）与很多早期物理化学教材用 **atm、cal、Å**。
> 引用其中的数值时**必须换算到 SI 再代入**：`1 cal = 4.184 J`，`1 atm = 101.325 kPa`，`1 Å = 10⁻¹⁰ m`。
> 换算后再比对现代数据，能省掉大量「为什么差这么多」的困惑。

## 五、数量级：科学记数法与 `lg` 心算

### 5.1 运算规则

- **乘除**：系数相乘除，指数相加减。`$(2.0\times10^3)(3.0\times10^{-5}) = 6.0\times10^{-2}$`
- **加减**：先**对齐指数**再算系数。`$2.0\times10^3 + 3.0\times10^2 = 2.0\times10^3 + 0.30\times10^3 = 2.3\times10^3$`
- **乘方开方**：`$(a\times10^n)^2 = a^2\times10^{2n}$`；`$\sqrt{a\times10^n}$`：若 `$n$` 为奇数，先化成 `$(10a)\times10^{n-1}$` 再开方。

### 5.2 只要背三个对数

| 值 | 数值 | 推出 |
|:--|:--|:--|
| `$\lg 2$` | `0.3010` | `$\lg 4 = 0.602$`，`$\lg 8 = 0.903$`，`$\lg 5 = 1-\lg2 = 0.699$` |
| `$\lg 3$` | `0.4771` | `$\lg 6 = 0.778$`，`$\lg 9 = 0.954$` |
| `$\ln 10$` | `2.303` | `$\ln x = 2.303\lg x$`；`$\ln 2 = 0.693$` |

`$\lg 7 = 0.845$` 顺手记，`$\pi$` 相关的不用记。

### 5.3 心算流程

```
lg x  =  lg(m × 10^n)  =  n + lg m
```

**例 5-1**：`$\lg(6.0\times10^{-4}) = -4 + \lg 6 = -4 + 0.778 = -3.222$`
若这是某弱酸的 `$K_a$`，则 `$pK_a = 3.22$`。检验：`$K_a = 10^{-3.22} = 6.0\times10^{-4}$` ✓
（易错点：指数 `-4` 与尾数 `0.778` 相加后是 `-3.222`，**不要**写成 `-4.778`。）

**例 5-2**：`$\ln(6.0\times10^{-4}) = 2.303\times(-3.222) = -7.42$`
检验：`$e^{-7.42} = 6.0\times10^{-4}$` ✓

**练一练 5-1**：不用计算器，估算 `$\lg(3.5\times10^5)$`。（`$\lg 3.5$` 可用 `$\lg 3.5 = \lg 7 - \lg 2 = 0.845-0.301 = 0.544$`）

### 5.4 化学数量级尺（贴在桌角）

| 尺度 | 典型值 | 备注 |
|:--|:--|:--|
| 原子核 | `10⁻¹⁵ m` | 比原子小 5 个数量级 |
| 键长 | `10⁻¹⁰ m`（1 Å） | C–H 约 109 pm |
| 分子间距（气体，1 bar） | `3.5×10⁻⁹ m` | 约为分子直径的 10 倍——理想气体成立的原因 |
| 可见光波长 | `5×10⁻⁷ m`（500 nm） | 比分子大 5000 倍 |
| `$k_BT$`（298 K） | `2.5 kJ/mol` | **化学的「能量单位」** |
| 氢键 | `10~40 kJ/mol` | 约 `4~16 k_BT` |
| 共价键 | `150~500 kJ/mol` | 约 `60~200 k_BT` |
| 分子振动周期 | `10⁻¹³ s` | 比扩散快 4 个数量级 |
| 典型一级反应半衰期 | `1~10⁴ s` | 跨越极大 |

> [!tip] 一句话直觉
> `k_BT ≈ 2.5 kJ/mol` 是判断「这个相互作用在高温下顶不顶得住」的标尺：
> 小于 `k_BT` 的（范德华 ~2 kJ/mol）室温下一撞就散；远大于 `k_BT` 的（共价键）室温下稳如泰山。

## 六、估算的四把斧

### 6.1 一位有效数字法

把所有输入都四舍五入到一位有效数字再算，误差通常不超过 3 倍——却能把计算速度提高 10 倍。

**例**：`$n = \dfrac{pV}{RT} = \dfrac{(1.0\times10^5)(1.7\times10^2)}{(8.3)(3.0\times10^2)}$`（1 bar、168 m³、298 K）
粗算：`$\dfrac{1.7\times10^7}{2.5\times10^3} = 6.8\times10^3\ \mathrm{mol}$`
精算：`$6.79\times10^3\ \mathrm{mol}$` —— 误差 0.1%，运气好；一般能保证在 30% 内。

### 6.2 上下界夹逼

当不确定系数时，算两个极端，答案必在中间。

**例**：估算 `$\sqrt{1.8\times10^{-6}}$`。
下界 `$\sqrt{1.0\times10^{-6}} = 1.0\times10^{-3}$`；上界 `$\sqrt{4.0\times10^{-6}} = 2.0\times10^{-3}$`。
真值 `1.34×10⁻³` ∈ [1.0, 2.0]×10⁻³ ✓ 选择题足够用。

### 6.3 对数化（把乘除变加减）

处理连续相乘（如 `$\prod$`、多次方）时取对数，把指数运算变成算术运算。第 2 讲已铺垫，第 7 讲算 `$\ln(N!)$` 时还要用。

### 6.4 分解法（Fermi 式）

把一个无法直接测的量拆成若干个**能估的量**相乘。

**例 6-1：一间教室（6 m × 8 m × 3.5 m）里有多少个空气分子？**

```
V = 6×8×3.5 ≈ 1.7×10² m³
n = pV/RT ≈ (1.0×10⁵)(1.7×10²)/(8.3×298) ≈ 6.8×10³ mol
N = n·N_A ≈ 6.8×10³ × 6.0×10²³ = 4.1×10²⁷ 个
```

答案量级：`10²⁷`。这类题的关键不是精确值，而是**别把数量级搞错一位**。

## 七、化学估算实战：五条快算律

### 7.1 `$\Delta G^\circ$` 与 `$K$` 的互化（5.71 律）

```
ΔG° = −RT ln K = −2.303 RT lg K
```
298 K 时 `$2.303RT = 2.303\times2.479 = 5.71\ \mathrm{kJ/mol}$`，于是：

```
ΔG°(kJ/mol) ≈ −5.71 × lg K      （298 K）
lg K ≈ −ΔG° / 5.71
```

**「10 倍律」**：`$\lg K$` 每变化 1（即 `$K$` 变 10 倍），`$\Delta G^\circ$` 变化约 **5.7 kJ/mol**。

| `$\lg K$` | `$K$` | `$\Delta G^\circ$`（kJ/mol） | 化学含义 |
|:--|:--|:--|:--|
| +3 | `10³` | `−17.1` | 明显偏向产物 |
| 0 | 1 | 0 | 双方相当 |
| −3 | `10⁻³` | `+17.1` | 明显偏向反应物 |
| −10 | `10⁻¹⁰` | `+57.1` | 几乎不发生 |

> [!tip] 判据
> 室温下 `$\Delta G^\circ$` 的绝对值超过约 `±30 kJ/mol`（对应 `$K$` 在 `10^{±5}` 之外）时，反应在热力学上可以判定为「彻底进行」或「彻底不发生」。

### 7.2 pH 快算

| 情形 | 公式 | 条件 |
|:--|:--|:--|
| 强酸 | `$[\mathrm{H}^+] = c$` | 完全电离 |
| 强酸极稀（`$c<10^{-6}$`） | `$[\mathrm{H}^+] = \dfrac{c+\sqrt{c^2+4K_w}}{2}$` | 水的电离不能忽略 |
| 弱酸 HA | `$[\mathrm{H}^+]\approx\sqrt{K_ac}$` | 电离度 `<5%`（即 `$c/K_a > 400$`） |
| 缓冲液 | `$\mathrm{pH} = \mathrm{p}K_a + \lg\dfrac{[\mathrm{A}^-]}{[\mathrm{HA}]}$` | Henderson-Hasselbalch |

**例 7-1**：0.10 M HAc（`$K_a = 1.8\times10^{-5}$`）
`$[\mathrm{H}^+] = \sqrt{1.8\times10^{-5}\times0.10} = \sqrt{1.8\times10^{-6}} = 1.34\times10^{-3}$`
`$\mathrm{pH} = 3 - \lg 1.34 = 3 - 0.127 = 2.87$`
检验：`$1.34\times10^{-3}/0.10 = 1.3\% < 5\%$` ✓ 近似合法。

### 7.3 半衰期与速率常数

```
一级：t₁/₂ = ln2 / k = 0.693 / k
零级：t₁/₂ = [A]₀ / (2k)
二级：t₁/₂ = 1 / (k[A]₀)
```

**例 7-2**：某放射性核素半衰期 12.3 a，求 `$k$`：`$k = 0.693/12.3 = 5.63\times10^{-2}\ \mathrm{a^{-1}}$`。
反查：100 年后剩余分数 `$e^{-5.63} = 3.6\times10^{-3}$`。

### 7.4 分子速率的量级

```
最概然速率：v_mp = sqrt(2RT/M)
平均速率：  v̄    = sqrt(8RT/(πM))
均方根速率：v_rms = sqrt(3RT/M)
```
三者比例 `$1 : 1.128 : 1.225$`，量级相同，估算时**统一用 `$\sqrt{3RT/M}$`**。

**例 7-3**：N₂（`$M = 0.028\ \mathrm{kg/mol}$`），298 K：
`$v_{\text{rms}} = \sqrt{3\times8.314\times298/0.028} = \sqrt{2.65\times10^5} = 5.2\times10^2\ \mathrm{m/s}$`
量级：`10² m/s`（与空气中声速 340 m/s 同量级，不是巧合——声速正是分子热运动速率量级的体现）。

### 7.5 温度对 `$K$` 与 `$k$` 的影响（「10 度翻倍」的来历）

van't Hoff：`$\lg\dfrac{K_2}{K_1} = \dfrac{\Delta H^\circ}{2.303R}\left(\dfrac{1}{T_1}-\dfrac{1}{T_2}\right)$`
Arrhenius：`$\lg\dfrac{k_2}{k_1} = \dfrac{E_a}{2.303R}\left(\dfrac{1}{T_1}-\dfrac{1}{T_2}\right)$`

**例 7-4**：`$E_a = 50\ \mathrm{kJ/mol}$`，300 K → 310 K：
`$\dfrac{E_a}{2.303R} = \dfrac{5.0\times10^4}{19.15} = 2.61\times10^3$`
`$\left(\dfrac1{300}-\dfrac1{310}\right) = \dfrac{10}{93000} = 1.075\times10^{-4}$`
乘积 = `$0.281$`? 重新算：`$2.61\times10^3\times1.075\times10^{-4} = 0.281$`… 应为 `$0.281$`？核对：`$2611\times1.075\times10^{-4} = 0.2807$`。

嗯，得到 `$k_2/k_1 = 10^{0.281} = 1.91$`，约 **2 倍** ✓

> [!note] 「升温 10 K 速率翻倍」的适用范围
> 由上式可见：室温附近、`$E_a \approx 50\ \mathrm{kJ/mol}$`（典型值）时确实约翻倍。
> 但 `$E_a = 100\ \mathrm{kJ/mol}$` 时约 3.6 倍，`$E_a = 25$` 时只有 1.4 倍。
> **这是一个量级估算，不是定律。**

## 八、选择题的秒杀：量纲与量级排除

### 8.1 量纲排除（最快）

**例 8-1**：某反应速率常数的单位是 `$\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$`，该反应级数为（ ）
A. 0 级　B. 1 级　C. 2 级　D. 3 级
→ 由 3.2 的表格直接得 **A**（0 级）。用时 5 秒。

### 8.2 量级排除

**例 8-2**：1 mol 物质发生下列变化，能量的**数量级**最大的是（ ）
A. 升温 10 K（`$\sim nC_p\Delta T \sim 10^2\ \mathrm{J}$`）
B. 融化（融化热 `$\sim 5\ \mathrm{kJ/mol}$`）
C. 断一根共价键（`$\sim 4\times10^2\ \mathrm{kJ/mol}$`）
D. 断一根氢键（`$\sim 2\times10^1\ \mathrm{kJ/mol}$`）
→ **C**，差了 2~3 个数量级，无需精确值。

### 8.3 极端情形检验

**例 8-3**：判断 `$\Delta G = \Delta H - T\Delta S$` 有没有记成 `$\Delta G = \Delta H + T\Delta S$`。
取 `$T\to 0$`：两式都趋于 `$\Delta H$`，无法区分。
改取「熵增很大的高温过程」：若 `$\Delta S>0$`，温度足够高时反应应自发，即 `$\Delta G<0$`。
`$-T\Delta S$` 能给出负值 ✓，`$+T\Delta S$` 给出正值 ✗ → 原式正确。

> [!abstract] 通用检验清单（算完花 10 秒走一遍）
> 1. **量纲**：等式两边量纲一致吗？对数/指数的自变量无量纲吗？
> 2. **量级**：结果在 5.4 表里的合理区间吗？
> 3. **极限**：`$T\to0$`、`$c\to0$`、`$n\to1$` 等特殊值时退化成已知结论吗？
> 4. **符号**：吸热反应升温 `$K$` 增大吗？（Le Chatelier 直觉）

## 十一、参考答案

### 练一练

**练一练 2-1**：
- 左边：`$[pV] = ML^{-1}T^{-2}\times L^3 = ML^2T^{-2}$`（能量量纲）
- 右边：`$[nRT] = N\times ML^2T^{-2}N^{-1}\Theta^{-1}\times\Theta = ML^2T^{-2}$` ✓
两边一致。顺带看出 `$pV$` 具有能量的量纲——这正是体积功 `$w = -\int p\,dV$` 成立的原因。

**练一练 5-1**：
`$\lg(3.5\times10^5) = 5 + \lg 3.5 = 5 + (\lg7-\lg2) = 5 + (0.845-0.301) = 5.544$`。
（检验：`$10^{0.544} = 3.50$` ✓）
