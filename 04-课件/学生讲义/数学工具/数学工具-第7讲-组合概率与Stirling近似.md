# 第7讲：排列组合、概率与 Stirling 近似——$S=k\ln W$ 里的 $W$ 是怎么数出来的

## 学习目标

1. 会用**乘法原理**与**加法原理**处理基础计数，分清「可区分」与「不可区分」这两种对象。
2. 会算排列 $P(n,m)$ 与组合 $C(n,m)$，知道 $0! = 1$ 与 $C(n,0)=1$ 的约定。
3. 会数「$N$ 个不可区分分子放进 $g$ 个盒子（每盒不限容量）」的状态数 $C(N+g-1,\,N)$，并知道它对应玻色型计数。
4. 会写二项式定理与二项分布 $P(n)=C(N,n)p^n(1-p)^{N-n}$，会算其最概然值、均值 $Np$ 与标准差 $\sqrt{Np(1-p)}$。
5. 能用「求和变积分」推出 **Stirling 近似**，会写简单式与完整式，并能用数值表判断**什么时候可以用**。
6. 会用 Stirling 把 $\ln W = \ln\dfrac{N!}{\prod N_i!}$ 化简成 $-N\sum x_i\ln x_i$，进而推出混合熵。
7. 能由「最大化 $\ln W$」推出两能级的 **Boltzmann 分布**，会算配分函数 $q$ 与各能级布居。
8. 能用 $W\propto V^N$ 解释理想气体自由膨胀的熵变，并验证它与热力学公式 $\Delta S = nR\ln(V_2/V_1)$ 一致。

---

## 一、为什么要数「有多少种」

### 1.1 从单个分子到一摩尔分子

前六讲处理的都是**一个量怎么变**：浓度随时间、能量随温度。统计热力学要处理的是另一类问题——

- 有 $N$ 个分子、若干个能级，分子在能级上可以有很多**分布方式**；
- 每种分布方式对应若干个**微观状态**；
- 体系实际处于哪个微观状态我们不知道，但**宏观状态包含的微观状态数 $W$ 是可以数的**。

Boltzmann 公式把这两个层次连起来：

```
S = k ln W
```

$W$ 越大，熵越大。所以**熵本质上是「数出来的」**。要会数，就得先会组合数学。

### 1.2 一个能数清的小例子

$N=4$ 个分子，每个只能处于低能级 $\varepsilon_0$ 或高能级 $\varepsilon_1$。设有 $n$ 个在高能级：

| $n$ | 状态数 $W$ | 具体（$N=4$，分子编号 1~4） |
|:--|:--|:--|
| 0 | 1 | 全部在 $\varepsilon_0$ |
| 1 | 4 | 任一个在高能级（4 种选法） |
| 2 | 6 | 从 4 个里选 2 个 = $C(4,2)$ |
| 3 | 4 | $C(4,3)$ |
| 4 | 1 | 全部在高能级 |

总数 $1+4+6+4+1 = 16 = 2^4$ ✓（每个分子 2 种选择）
**最概然分布**：$n=2$，$W=6$ 最大。

$N=4$ 时「最概然」的优势不明显；当 $N=10^{23}$ 时，最概然分布的概率压倒性地大于其他分布——这正是统计热力学能用「最概然分布」代替「真实分布」的原因。

## 二、计数：乘法原理、排列、组合

### 2.1 两条基本原理

- **加法原理**（分类）：做一件事有若干**类**方法，总数 = 各类方法数之和。
- **乘法原理**（分步）：做一件事要分若干**步**，总数 = 各步方法数之积。

### 2.2 排列 $P(n,m)$：从 $n$ 个里取 $m$ 个**排成一列**

```
P(n,m) = n(n−1)(n−2)…(n−m+1) = n!/(n−m)!
```

特例：$P(n,n) = n!$。约定 $0! = 1$。

### 2.3 组合 $C(n,m)$：从 $n$ 个里取 $m$ 个**不计顺序**

排列里每组被重复数了 $m!$ 次（组内顺序），所以

```
C(n,m) = P(n,m)/m! = n! / ( m! (n−m)! )
```

性质（都很有用）：

- $C(n,m) = C(n,\,n-m)$（选 $m$ 个留下 ≡ 选 $n-m$ 个去掉）
- $C(n,0) = C(n,n) = 1$
- $\sum_{m=0}^{n}C(n,m) = 2^n$（每个元素选或不选）

**练一练 2-1**：算 $C(10,3)$ 与 $P(10,3)$。（答案见文末。）

### 2.4 可重复选取：「放球入盒」的两种模型

这是化学计数里最容易搞混的一对，务必分清：

| 模型 | 球（分子） | 盒（能级/状态） | 每盒容量 | 状态数 |
|:--|:--|:--|:--|:--|
| 可区分球入盒 | 可区分 | 可区分 | 不限 | $g^N$ |
| 不可区分球入盒 | 不可区分 | 可区分 | 不限 | $C(N+g-1,\,N)$ |

**为什么第二种是 $C(N+g-1,N)$**：用「隔板法」——$N$ 个球与 $g-1$ 块隔板共 $N+g-1$ 个位置，从中选 $N$ 个位置放球，其余放隔板。

**例 2-1**：3 个**不可区分**的振动量子分给 1 个有 4 个能级的振子（能级 0,1,2,3，每级容量不限）→ $C(3+4-1,3) = C(6,3) = 20$ 种分布方式。

> [!note] 与化学的对应
> 经典极限下（气体分子，能级简并度远大于分子数）分子**视为可区分**→ 用 $N!/\prod N_i!$ 计数（见第五节）。
> 光子、声子等**不可区分**的玻色子 → 用 $C(N+g-1,N)$。
> 电子等费米子每态至多一个 → 用 $C(g,N)$。竞赛一般只考第一种。

## 三、二项式定理与二项分布

### 3.1 二项式定理

```
(a+b)^n = Σ_{m=0}^{n} C(n,m) a^{n−m} b^m
```

系数 $C(n,m)$ 构成 Pascal 三角（每行是上一行相邻两项之和）。令 $a=b=1$ 即得 $\sum C(n,m) = 2^n$。

### 3.2 二项分布

$N$ 次独立试验，每次「成功」概率 $p$，成功 $n$ 次的概率：

```
P(n) = C(N,n) · p^n · (1−p)^{N−n}
```

这就是 $(p + (1-p))^N$ 展开的第 $n$ 项，故 $\sum_n P(n) = 1$ 自动归一化 ✓

### 3.3 均值、最概然值与标准差

| 量 | 公式 |
|:--|:--|
| 均值（期望） | $\langle n\rangle = Np$ |
| 最概然值 | $Np$ 附近的整数 |
| 方差 | $\sigma^2 = Np(1-p)$ |
| 标准差 | $\sigma = \sqrt{Np(1-p)}$ |

**关键直觉：相对涨落**

```
σ/⟨n⟩ = sqrt(Np(1−p)) / (Np) = sqrt((1−p)/(Np)) ∝ 1/√N
```

- $N=1000$、$p=0.5$：$\sigma/\langle n\rangle = \sqrt{0.25/500} = 2.2\%$
- $N=10^{23}$：$\sigma/\langle n\rangle \approx 3\times10^{-12}$

**这就是统计热力学成立的根基**：粒子数宏观大时，涨落相对量趋于零，「最概然分布」与「平均分布」没有可观测的差别。

### 3.4 $N$ 很大时的极限：正态分布

```
P(n) ≈ 1/(σ√(2π)) · exp( −(n−Np)² / (2σ²) )
```

（由 Stirling 代入 $C(N,n)$ 可推得，此处从略。）用于估计「偏离均值超过 $k\sigma$」的概率：

| 偏离 | 落在区间内的概率 |
|:--|:--|
| $\pm 1\sigma$ | 68.3% |
| $\pm 2\sigma$ | 95.4% |
| $\pm 3\sigma$ | 99.7% |

## 四、Stirling 近似：把 $N!$ 变成能算的东西

### 4.1 问题

$1\ \mathrm{mol}$ 物质的微观状态数含 $N_A! = (6.022\times10^{23})!$——这个数大到任何计算器都无法直接处理。但熵里出现的是 $\ln(N!)$，而**对数把连乘变成连加**：

```
ln(N!) = ln 1 + ln 2 + ln 3 + … + ln N = Σ_{k=1}^{N} ln k
```

### 4.2 推导：求和变积分

$\ln k$ 在 $k$ 增大时变化缓慢，故求和可用积分近似（矩形法）：

```
Σ_{k=1}^{N} ln k ≈ ∫_{1}^{N} ln x dx = [ x ln x − x ]_{1}^{N} = N ln N − N + 1
```

$N$ 很大时常数 1 可忽略，得**简单式**：

```
ln(N!) ≈ N ln N − N          （N 很大时）
```

加上更精细的修正项（由 Euler-Maclaurin 或 Laplace 方法给出，此处不推）得**完整式**：

```
ln(N!) ≈ N ln N − N + (1/2) ln(2πN)      （Stirling 完整式）
```

等价的阶乘形式：$N! \approx \sqrt{2\pi N}\,(N/e)^N$。

### 4.3 精度校验（务必看这张表）

| $N$ | $\ln(N!)$ 真值 | 简单式 $N\ln N-N$ | 简单式相对误差 | 完整式 | 完整式相对误差 |
|:--|:--|:--|:--|:--|:--|
| 10 | 15.1044 | 13.0259 | **13.7%** | 15.0963 | 0.054% |
| 100 | 363.7394 | 360.517 | **0.89%** | 363.7385 | `2.5×10⁻⁶` |
| 1000 | 5912.128 | 5907.755 | **0.074%** | 5912.128 | `~10⁻⁷` |
| $10^6$ | 12815518 | 12815514 | `3×10⁻⁵`% | 12815518 | `~10⁻⁸` |
| $10^{23}$ | $5.296\times10^{24}$ | 同左（差约 27） | `~5×10⁻²⁴` | — | 可忽略 |

**读表结论**：

- $N\lesssim 100$：**必须用完整式**，简单式误差接近 1%~14%，会毁掉熵的绝对值。
- $N \geq 10^3$：简单式误差 `< 0.1%`，可用。
- $N \sim 10^{23}$（化学的真实情形）：简单式的绝对误差只有约 27，而 $\ln(N!)\sim 5\times10^{24}$——**相对误差约 $10^{-24}$，完全可忽略**。这就是为什么化学教材敢直接写 $\ln N! \approx N\ln N - N$。

> [!warning] 一个必须知道的例外
> 当 $N!$ 出现在**分子分母相消**的位置（如 $\ln W = \ln N! - \sum\ln N_i!$）时，$-N$ 项会抵消，
> 剩下的 $\frac12\ln(2\pi N)$ 项**不会完全抵消**。
> 例如 $N=100$ 两等分组：$\ln W$ 真值 66.79，简单式给 69.32，**误差 3.8%**。
> 所以：**小体系务必用完整式；$N\sim10^{23}$ 时两者都行。**

### 4.4 两个常用推论

**推论 1**（$n\ll N$ 时）：

```
ln( N!/(N−n)! ) ≈ n ln N
```

推导：$N\ln N - N - [(N-n)\ln(N-n) - (N-n)]$，用 $\ln(N-n)\approx\ln N - n/N$ 展开即得（练习 16）。

**推论 2**（二项式系数）：

```
ln C(2n, n) ≈ 2n ln 2 − (1/2) ln(π n)
```
（即 $C(2n,n)\approx 4^n/\sqrt{\pi n}$）

## 五、第一个化学应用：混合熵

### 5.1 数状态数

$N$ 个分子，其中 $N_1$ 个是 A、$N_2$ 个是 B（$N_1+N_2=N$）。分子**可区分**（经典极限），则把 $N$ 个位置分配给 A、B 的方式数：

```
W = N! / ( N₁! N₂! )
```

（先全排列 $N!$，再除掉 A 内部 $N_1!$ 与 B 内部 $N_2!$ 的重复计数。）

### 5.2 代入 Stirling

```
ln W = ln N! − ln N₁! − ln N₂!
     = (N ln N − N) − (N₁ ln N₁ − N₁) − (N₂ ln N₂ − N₂)
     = N ln N − N₁ ln N₁ − N₂ ln N₂          （−N + N₁ + N₂ = 0，抵消）
```

提出 $N$：令 $x_i = N_i/N$（摩尔分数），$N_i\ln N_i = N_i(\ln N + \ln x_i)$：

```
ln W = N ln N − (N₁+N₂) ln N − N₁ ln x₁ − N₂ ln x₂
     = −N ( x₁ ln x₁ + x₂ ln x₂ )
```

**注意**：这一步里 $N\ln N$ 正好抵消，所以**高阶修正项才是主要误差源**——与 4.3 的警告一致。

### 5.3 熵

```
S = k ln W = −Nk Σ x_i ln x_i = −nR Σ x_i ln x_i
```

（用了 $Nk = nR$。）混合理想气体的**混合熵**：

```
ΔS_mix = −nR Σ x_i ln x_i
```

### 5.4 数值

**等摩尔二元混合**（$x_1=x_2=0.5$）：

```
ΔS_mix = −R(0.5 ln 0.5 + 0.5 ln 0.5) = R ln 2 = 8.314 × 0.693 = 5.76 J·mol⁻¹·K⁻¹
```

**非等摩尔**（$x_1=0.25,\,x_2=0.75$）：

```
ΔS_mix = −R(0.25 ln 0.25 + 0.75 ln 0.75) = −R(−0.3466 − 0.2158) = 4.68 J·mol⁻¹·K⁻¹
```

等摩尔时混合熵最大——图像上 $-x\ln x$ 在 $x=0.5$ 处取极大。（可用第 3 讲的极值判据验证：$\dfrac{d}{dx}(-x\ln x) = -\ln x - 1 = 0 \Rightarrow x = 1/e$？核对：对 $f=-x\ln x-(1-x)\ln(1-x)$ 求导得 $-\ln x - 1 + \ln(1-x) + 1 = \ln\dfrac{1-x}{x}$，令其为零得 $x = 0.5$ ✓）

## 六、Boltzmann 分布：最概然分布

### 6.1 一般设定

$N$ 个（近独立）分子分布在能级 $\varepsilon_0, \varepsilon_1, \varepsilon_2,\dots$（简并度 $g_i$）上，占据数为 $N_0, N_1, N_2,\dots$。约束条件：

```
Σ N_i = N        （分子数守恒）
Σ N_i ε_i = E    （总能量守恒）
```

给定分布 $\{N_i\}$ 的微观状态数：

```
W = N! / ( N₀! N₁! N₂! … ) × g₀^{N₀} g₁^{N₁} g₂^{N₂} …
```

（前半段是「哪些分子在哪一级」，后半段是「每级内部有 $g_i$ 个简并态可选」。）

### 6.2 思路：最大化 $\ln W$

严格的做法是在两个约束下用 **Lagrange 乘子法**求 $\ln W$ 的条件极值（此处只用结论）。核心技巧有三步：

1. 取对数（连乘变连加，且 $\ln$ 单调，极大点不变）
2. 用 Stirling 把 $\ln(N_i!)$ 换成 $N_i\ln N_i - N_i$
3. 对 $N_i$ 求导，配合两个约束

结果：

```
N_i / N = g_i e^{−ε_i/kT} / q
q ≡ Σ_i g_i e^{−ε_i/kT}      （配分函数）
```

这就是 **Boltzmann 分布**。两个直接推论：

```
N_j / N_i = (g_j/g_i) · e^{−(ε_j − ε_i)/kT}
```

- 温度 $T\to0$：只有最低能级有布居（$e^{-\Delta\varepsilon/kT}\to0$）
- $T\to\infty$：各能级布居比趋于简并度之比 $g_j/g_i$（全部均匀摊开）

### 6.3 两能级特例（会算就够了）

设 $\varepsilon_0 = 0$、$\varepsilon_1 = \varepsilon$、简并度 $g_0=g_1=1$。

```
q = 1 + e^{−ε/kT}
N₁/N₀ = e^{−ε/kT}
N₁/N = e^{−ε/kT} / (1 + e^{−ε/kT})
```

**数值例**（取 $\varepsilon = 208.5\ \mathrm{cm^{-1}}$，恰好等于 298 K 的 $k_BT$，见第 6 讲 4.2 表）：

| $T$ | $k_BT$（cm⁻¹） | $\varepsilon/k_BT$ | $N_1/N_0$ | $N_1/N$ |
|:--|:--|:--|:--|:--|
| 298 K | 208.5 | 1.00 | 0.368 | 26.9% |
| 600 K | 420 | 0.496 | 0.609 | 37.8% |
| 1000 K | 700 | 0.298 | 0.742 | 42.6% |
| $\infty$ | — | 0 | 1 | 50% |

规律：温度升高 → 高能级布居增加 → 但**永远不超过 50%**（等简并两能级的极限）。

### 6.4 配分函数 $q$ 的物理意义

```
q = Σ_i g_i e^{−ε_i / kT}
```

- 它是「按 Boltzmann 因子加权后的**有效可及状态数**」。
- 数值上：基态贡献 1，其余能级各贡献一个 `<1` 的数。故 $q \geq 1$。
- $kT \ll \Delta\varepsilon$ 时 $q \to g_0$（只基态可及）；$kT \gg \Delta\varepsilon$ 时 $q \to \sum g_i$（全部可及）。

**例 6-1**：三能级 $0,\ \varepsilon,\ 2\varepsilon$（简并度均 1），$T$ 使 $k_BT = \varepsilon$：

```
q = 1 + e^{−1} + e^{−2} = 1 + 0.368 + 0.135 = 1.503
P₀ = 1/1.503 = 66.5%     P₁ = 0.368/1.503 = 24.5%     P₂ = 0.135/1.503 = 9.0%
```

检验：$66.5+24.5+9.0 = 100\%$ ✓

## 七、概率与平均值：三条够用的

### 7.1 期望值

```
⟨x⟩ = Σ_i x_i P(x_i)
```

对二项分布：$\langle n\rangle = Np$（3.3 已给）；对 Boltzmann 分布，平均能量：

```
⟨ε⟩ = Σ_i ε_i · g_i e^{−ε_i/kT} / q
```

（可用 $-\partial\ln q/\partial\beta$ 简洁求出，$\beta = 1/kT$；此处只要求会直接按定义算。）

### 7.2 方差与标准差

```
σ² = ⟨x²⟩ − ⟨x⟩²
```

$N$ 很大时 $\sigma \propto \sqrt{N}$，而均值 $\propto N$，故相对涨落 $\propto 1/\sqrt{N}$（3.3 已述）。

### 7.3 一句话：为什么宏观体系「看起来是确定的」

因为 $\sigma/\langle n\rangle \sim 10^{-12}$（$N\sim10^{23}$）。**不是分子不涨落，是涨落相对量小到测不出来。** 这也是为什么用「最概然分布」代替真实分布是合法的。

## 八、核心公式速查

| 主题 | 公式 |
|:--|:--|
| 排列 | $P(n,m) = n!/(n-m)!$ |
| 组合 | $C(n,m) = n!/(m!(n-m)!)$；$\sum_m C(n,m) = 2^n$ |
| 可区分球入盒 | $g^N$ |
| 不可区分球入盒 | $C(N+g-1,\,N)$ |
| 二项分布 | $P(n) = C(N,n)p^n(1-p)^{N-n}$；$\langle n\rangle = Np$；$\sigma = \sqrt{Np(1-p)}$ |
| Stirling 简单式 | $\ln N! \approx N\ln N - N$（$N\gtrsim10^3$） |
| Stirling 完整式 | $\ln N! \approx N\ln N - N + \frac12\ln(2\pi N)$（$N\lesssim100$ 时必用） |
| 微观状态数 | $W = N!/\prod N_i!$（经典极限） |
| 混合熵 | $\Delta S_{\text{mix}} = -nR\sum x_i\ln x_i$；等摩尔二元 $=R\ln2=5.76$ |
| Boltzmann 分布 | $N_i/N = g_i e^{-\varepsilon_i/kT}/q$；$q=\sum_i g_i e^{-\varepsilon_i/kT}$ |
| 自由膨胀熵变 | $\Delta S = nR\ln(V_2/V_1)$ |
| 相对涨落 | $\sigma/\langle n\rangle \propto 1/\sqrt{N}$ |

### 真题挑战（6 题，竞赛风格改编）

13. $N$ 个分子分到两个等简并能级，$W = C(N,n)$。对 $\ln W$ 用 Stirling 并对 $n$ 求导，证明最概然分布为 $n = N/2$。

> [!abstract] 这一讲能解开哪份讲义的什么坎
> - **统计热力学与 Maxwell 关系**：$\ln(N!)\approx N\ln N - N$ 不再是天降公式（4.2 给出推导与精度表）；「最概然分布」有了可操作的求法（第六节）；$W$ 的计数规则清楚了（2.4 与 5.1）。
> - **化学热力学**：混合熵 $\Delta S_{\text{mix}} = -nR\sum x_i\ln x_i$ 从「要背的结论」变成「数出来再取对数」的结果；自由膨胀熵变与热力学公式互相印证。
> - **化学动力学**：Boltzmann 因子 $e^{-E_a/RT}$ 与配分函数形式同源，Arrhenius 的指数项不再是孤立写法。
