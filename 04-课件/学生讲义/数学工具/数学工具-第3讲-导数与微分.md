## 一、从平均变化率到瞬时变化率

### 1.1 复习：平均变化率就是斜率

第 1 讲说过，直线斜率为

`$\dfrac{\Delta y}{\Delta x} = \dfrac{y_2 - y_1}{x_2 - x_1}$`

它回答"横轴每增加 1 个单位，纵轴平均变多少"。对曲线，这个比值只描述**一段区间内的平均效果**。

### 1.2 问题：平均的不够用

看一级反应的浓度数据（k = 0.0500 min⁻¹，`[A]₀` = 1.000 mol·L⁻¹）：

| 区间 | Δt | Δ[A] | Δ[A]/Δt |
|:--|--:|--:|--:|
| 0 → 20 min | 20 | −0.632 | −0.0316 mol·L⁻¹·min⁻¹ |
| 0 → 10 min | 10 | −0.393 | −0.0393 |
| 0 → 5 min | 5 | −0.221 | −0.0442 |
| 0 → 1 min | 1 | −0.0488 | −0.0488 |
| 0 → 0.1 min | 0.1 | −0.00499 | −0.0499 |

区间取得越短，比值越接近 −0.0500——**这正是速率常数 k**（一级反应在 t = 0 时的瞬时速率 = `k[A]₀` = 0.0500 × 1.000 = 0.0500）。

**这就是导数要解决的问题**：区间缩短到极限时，平均变化率趋向的那个确定值。

### 1.3 极限的直观说法

`$\Delta x \to 0$` 读作"Δx 趋向于 0"——不是"等于 0"（那样分母就没了），而是"要多小有多小，但始终不是 0"。

> [!tip] 理解要点
> 你可以这样验证：上面的表继续往下算，Δt = 0.01、0.001…，比值会依次变成 −0.04995、−0.049995…，它们**稳定地趋向** −0.0500。这个"最终稳定到的值"，就是瞬时变化率，也就是导数。
> 严格的定义（ε-δ 语言）本讲不讲——竞赛只需要这个"稳定趋向"的直观。

### 1.4 为什么化学非要瞬时值

因为**化学反应的速率本身在变**（反应物越消耗越慢）。用 20 分钟的平均速率描述第 1 分钟发生了什么，必然失真。所以速率必须定义为瞬时量：

`$v = -\dfrac{d[\mathrm{A}]}{dt}$`

**练一练 1-1**：上表中，若你只能用 0→20 min 的平均速率 −0.0316 来估算 t = 0 时的真实速率 0.0500，相对误差是多少？这说明了什么？（答案见 §十二）

## 二、导数的定义

### 2.1 定义式

**导数**（derivative）：函数 `$y = f(x)$` 在 x 处的导数，是平均变化率当 `$\Delta x \to 0$` 时的极限：

`$\displaystyle f'(x) = \lim_{\Delta x \to 0}\frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0}\frac{f(x+\Delta x) - f(x)}{\Delta x}$`

如果这个极限存在，就说 f 在 x 处**可导**。

### 2.2 三种记号（都必须认识）

| 记号 | 写法 | 强调什么 | 化学里的常见场合 |
|:--|:--|:--|:--|
| 撇记号 | `$f'(x)$` | 简洁，强调"导函数" | 数学推导 |
| 莱布尼茨 | `$\dfrac{dy}{dx}$` | **强调"对谁求导"**（分母是自变量） | `$d[\mathrm{A}]/dt$`、`$\partial G/\partial p$` |
| 算子 | `$\dfrac{d}{dx}$` | 强调"这是一个操作" | `$\dfrac{d}{dt}\ln[\mathrm{A}]$` |

> [!warning] 易错提醒
> `$\dfrac{dy}{dx}$` 是一个**整体记号**，不是分数（虽然它常常"表现得像"分数，见 §8 微分）。**不能约分、不能拆开**。分子分母的位置不能颠倒：`$\dfrac{dt}{d[\mathrm{A}]}$` 与 `$\dfrac{d[\mathrm{A}]}{dt}$` 互为倒数关系，物理意义完全不同。

### 2.3 用定义求一次导数（完整演示）

**例**：用定义求 `$f(x) = x^2$` 的导数。

**第一步**——写出增量：

`$f(x+\Delta x) - f(x) = (x+\Delta x)^2 - x^2 = x^2 + 2x\Delta x + (\Delta x)^2 - x^2 = 2x\Delta x + (\Delta x)^2$`

**第二步**——作比值：

`$\dfrac{\Delta y}{\Delta x} = \dfrac{2x\Delta x + (\Delta x)^2}{\Delta x} = 2x + \Delta x$`

**第三步**——取极限：

`$f'(x) = \lim_{\Delta x\to 0}(2x + \Delta x) = 2x$`

所以 `$(x^2)' = 2x$`。几何上：抛物线 `$y = x^2$` 在 x 处的切线斜率就是 2x（x = 3 处斜率为 6）。

**练一练 2-1**：仿照上面的三步，用定义求 `$f(x) = 3x + 1$` 的导数（提示：一次函数的斜率处处相同）。（答案见 §十二）

## 三、导数的意义

### 3.1 几何意义：切线斜率

`$f'(x_0)$` = 曲线在 `$x_0$` 处**切线的斜率**。

`$f'(x_0) > 0$` → 上升；`$f'(x_0) < 0$` → 下降；`$f'(x_0) = 0$` → 水平（通常对应极值或平台）。

### 3.2 物理意义：瞬时变化率

| 导数 | 物理含义 |
|:--|:--|
| `$d[\mathrm{A}]/dt$` | 浓度随时间的变化率（负号表示减少） |
| `$dT/dt$` | 升温速率（量热实验里要测） |
| `$dG/d\xi$` | 反应进度推进时 Gibbs 自由能的变化率（= 0 即平衡） |
| `$d\ln k/dT$` | 速率常数对温度的敏感度（正比于 Eₐ/T²） |

### 3.3 符号与单位

导数的单位 = **因变量单位 ÷ 自变量单位**。例如：

`$\dfrac{d[\mathrm{A}]}{dt}$` 的单位 = `mol·L⁻¹ ÷ s` = `mol·L⁻¹·s⁻¹`

`$\dfrac{d\ln k}{dT}$` 的单位 = `1 ÷ K` = `K⁻¹`（ln 无量纲）

> [!info] 深入思考
> 这也解释了为什么**一级反应的 k 单位是 s⁻¹**：由 `$-\dfrac{d[\mathrm{A}]}{dt} = k[\mathrm{A}]$`，左边单位 `mol·L⁻¹·s⁻¹`，右边 `[A]` 单位 `mol·L⁻¹`，故 k 的单位必须是 `s⁻¹`。**不是背出来的，是量纲逼出来的**。

**练一练 3-1**：由 `$v = k[\mathrm{A}]^2$` 推出二级反应 k 的单位。（答案见 §十二）

## 四、基本导数公式（必背 6 条）

| 函数 | 导数 | 备注 |
|:--|:--|:--|
| `$y = c$`（常数） | `$y' = 0$` | 不变化率当然为 0 |
| `$y = x^n$` | `$y' = nx^{n-1}$` | n 可以是负数、分数 |
| `$y = \mathrm{e}^{x}$` | `$y' = \mathrm{e}^{x}$` | 唯一"导数等于自己"的函数 |
| `$y = \ln x$` | `$y' = \dfrac{1}{x}$` | x > 0 |
| `$y = \sin x$` | `$y' = \cos x$` | 化学少用 |
| `$y = \cos x$` | `$y' = -\sin x$` | 化学少用 |

### 4.1 幂函数求导（n 为负、分数也成立）

| 函数 | 导数 | 说明 |
|:--|:--|:--|
| `$x^3$` | `$3x^2$` | 常规 |
| `$\dfrac{1}{x} = x^{-1}$` | `$-x^{-2} = -\dfrac{1}{x^2}$` | **高频**：二级反应 `1/[A]` 对 t 求导时会遇到 |
| `$\sqrt{x} = x^{1/2}$` | `$\dfrac{1}{2}x^{-1/2} = \dfrac{1}{2\sqrt{x}}$` | 常出现在扩散、碰撞理论 |
| `$\dfrac{1}{x^2} = x^{-2}$` | `$-2x^{-3}$` | |
| `$x^{-1/2}$` | `$-\dfrac{1}{2}x^{-3/2}$` | |

**例**：求 `$\dfrac{d}{dt}\left(\dfrac{1}{[\mathrm{A}]}\right)$`（把 [A] 看作 t 的函数）。

这是复合，先记为 `$\dfrac{d}{dt}\left([\mathrm{A}]^{-1}\right)$`。用链式法则（§6）：

`$-[\mathrm{A}]^{-2}\cdot\dfrac{d[\mathrm{A}]}{dt} = -\dfrac{1}{[\mathrm{A}]^2}\cdot\dfrac{d[\mathrm{A}]}{dt}$`

若 `$\dfrac{d[\mathrm{A}]}{dt} = -k[\mathrm{A}]^2$`（二级），代入得

`$\dfrac{d}{dt}\left(\dfrac{1}{[\mathrm{A}]}\right) = -\dfrac{1}{[\mathrm{A}]^2}\cdot(-k[\mathrm{A}]^2) = k$`

**这是一个漂亮的结果**：`1/[A]` 对 t 求导是常数 k —— 也就是说 `1/[A]` 随 t **线性增长**。这正是第 1 讲那张表中"二级反应 `1/[A]`–t 为直线，斜率 = +k"的来历。

### 4.2 ln x 与 eˣ 的导数（为什么化学偏爱它们）

`$\dfrac{d}{dx}\ln x = \dfrac{1}{x}$` 是最"干净"的导数：一个超越函数的导数变成了简单的代数式。

这带来一个在化学里极其重要的推论：

`$\dfrac{d}{dt}\ln[\mathrm{A}] = \dfrac{1}{[\mathrm{A}]}\cdot\dfrac{d[\mathrm{A}]}{dt}$`

若一级反应 `$\dfrac{d[\mathrm{A}]}{dt} = -k[\mathrm{A}]$`，代入得

`$\dfrac{d}{dt}\ln[\mathrm{A}] = \dfrac{1}{[\mathrm{A}]}\cdot(-k[\mathrm{A}]) = -k$`

**又是一个常数**：`ln[A]` 对 t 的导数是 `−k`，即 `ln[A]` 随 t 线性下降 —— 第 1 讲"一级反应 `ln[A]`–t 是直线"的完整解释。

> [!tip] 理解要点
> 记住这两个结果，你就拥有了对 0/1/2 级反应的完整图像：
> `$\dfrac{d[\mathrm{A}]}{dt} = -k$`（零级）→ [A] 线性；
> `$\dfrac{d\ln[\mathrm{A}]}{dt} = -k$`（一级）→ ln[A] 线性；
> `$\dfrac{d(1/[\mathrm{A}])}{dt} = +k$`（二级）→ 1/[A] 线性。
> **积分（第 4 讲）只是把这三句话"翻译"成浓度表达式**。

**练一练 4-1**：求 `$\dfrac{d}{dx}\left(3x^2 - 5x + 2\right)$`、`$\dfrac{d}{dx}\left(\dfrac{2}{x^3}\right)$`、`$\dfrac{d}{dx}\left(4\sqrt{x}\right)$`。（答案见 §十二）

## 五、四则运算法则

设 u、v 都是 x 的可导函数，c 为常数：

| 法则 | 式子 |
|:--|:--|
| 常数倍 | `$(cu)' = cu'$` |
| 和差 | `$(u \pm v)' = u' \pm v'$` |
| 乘积 | `$(uv)' = u'v + uv'$` |
| 商 | `$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$` |

> [!tip] 理解要点
> 乘积法则口诀：**"前导后不导 + 前不导后导"**；商法则口诀：**"上导下不导 − 上不导下导，除以下的平方"**。注意商法则是**减法**，且分子次序不能颠倒。

**例1（乘积）**：求 `$\dfrac{d}{dx}\left(x^2\ln x\right)$`。

`$u = x^2$`，`$u' = 2x$`；`$v = \ln x$`，`$v' = 1/x$`

`$(x^2\ln x)' = 2x\cdot\ln x + x^2\cdot\dfrac{1}{x} = 2x\ln x + x$`

**例2（商）**：求 `$\dfrac{d}{dx}\left(\dfrac{\ln x}{x}\right)$`。

`$u = \ln x$`，`$u' = 1/x$`；`$v = x$`，`$v' = 1$`

`$\left(\dfrac{\ln x}{x}\right)' = \dfrac{\frac{1}{x}\cdot x - \ln x\cdot 1}{x^2} = \dfrac{1 - \ln x}{x^2}$`

**例3（化学量纲检验）**：Nernst 方程 `$E = E^\circ - \dfrac{RT}{nF}\ln Q$` 中，把 T 看作变量，求 `$dE/dT$`。

`$\dfrac{dE}{dT} = -\dfrac{R}{nF}\ln Q$`（`$E^\circ$` 与 Q 在此视为常数）

单位检验：`$R/(nF)$` 的单位 = `J·mol⁻¹·K⁻¹ ÷ C·mol⁻¹` = `J·K⁻¹·C⁻¹` = `V·K⁻¹`，乘以无量纲的 ln Q，得 `V·K⁻¹` —— 正是 `dE/dT` 应有的单位 ✓

**练一练 5-1**：求 `$\dfrac{d}{dx}\left(x\mathrm{e}^{x}\right)$` 与 `$\dfrac{d}{dx}\left(\dfrac{x}{1+x}\right)$`。（答案见 §十二）

## 六、复合函数与链式法则

### 6.1 什么是复合函数

`$y = f(g(x))$` 叫复合函数：`g` 是**内层**，`f` 是**外层**。

识别练习：

| 函数 | 外层 | 内层 | 拆解 |
|:--|:--|:--|:--|
| `$\ln[\mathrm{A}(t)]$` | ln | `[A](t)` | `$y = \ln u$`，`$u = [\mathrm{A}](t)$` |
| `$\mathrm{e}^{-E_a/RT}$` | e 的幂 | `$-E_a/RT$` | `$y = \mathrm{e}^{u}$`，`$u = -E_a/(RT)$` |
| `$(1 + kt)^{-1}$` | −1 次幂 | `$1+kt$` | `$y = u^{-1}$`，`$u = 1+kt$` |
| `$([\mathrm{A}])^n$` | n 次幂 | `[A](t)` | `$y = u^n$`，`$u = [\mathrm{A}](t)$` |

### 6.2 链式法则

`$\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}$`

一句话：**由外向内逐层求导，逐层相乘**。

### 6.3 化学里必练的三种复合

**(1) 对 T 求 `$\mathrm{e}^{-E_a/RT}$` 的导数**（求活化能时常用）：

`$y = \mathrm{e}^{u}$`，`$u = -\dfrac{E_a}{R}\cdot\dfrac{1}{T} = -\dfrac{E_a}{R}T^{-1}$`

`$\dfrac{du}{dT} = -\dfrac{E_a}{R}\cdot(-1)T^{-2} = \dfrac{E_a}{RT^2}$`

`$\dfrac{dy}{dT} = \mathrm{e}^{u}\cdot\dfrac{E_a}{RT^2} = \mathrm{e}^{-E_a/RT}\cdot\dfrac{E_a}{RT^2}$`

即 `$\dfrac{dk}{dT} = k\cdot\dfrac{E_a}{RT^2}$`（因 `$k = A\mathrm{e}^{-E_a/RT}$`）。

**结论**：`$E_a > 0$` 时 `$dk/dT > 0$` —— 升温使速率常数增大，与常识一致 ✓

**(2) 对 T 求 `$\ln k$` 的导数**（Arrhenius 作图的斜率）：

`$\ln k = \ln A - \dfrac{E_a}{RT}$`

`$\dfrac{d\ln k}{dT} = 0 - \dfrac{E_a}{R}\cdot(-T^{-2}) = \dfrac{E_a}{RT^2}$`

而第 1 讲说 Arrhenius 图的**横轴是 1/T**，所以真正要的是

`$\dfrac{d\ln k}{d(1/T)} = -\dfrac{E_a}{R}$`

这就是"斜率 = `−Eₐ/R`"的严格来源。注意两个导数差一个 `$d(1/T)/dT = -1/T^2$` 因子。

> [!warning] 易错提醒
> **对 T 求导**与**对 1/T 求导**不是一回事，二者相差 `$-T^2$` 倍。看到"斜率"先看清横轴是 T 还是 1/T。

**(3) 对 t 求 `$\ln[\mathrm{A}]$` 的导数**（§4.2 已算）：`$-k$`。

**练一练 6-1**：求 `$\dfrac{d}{dx}\ln(3x^2 + 1)$` 与 `$\dfrac{d}{dx}\mathrm{e}^{-2x^2}$`。（答案见 §十二）

## 七、高阶导数与极值判据

### 7.1 二阶导数

对导数再求导，得**二阶导数**：

`$f''(x) = \dfrac{d}{dx}\left(\dfrac{dy}{dx}\right) = \dfrac{d^2y}{dx^2}$`

含义：**斜率本身的变化率**，即曲线的弯曲方向（凹凸）。

- `$f'' > 0$`：斜率在增大，曲线向上弯（凹），像碗口朝上
- `$f'' < 0$`：斜率在减小，曲线向下弯（凸），像碗口朝下

**例**：`$y = x^2$`，`$y' = 2x$`，`$y'' = 2 > 0$` —— 处处向上弯，确实是抛物线。

**例（化学）**：一级反应 `$[\mathrm{A}] = [\mathrm{A}]_0\mathrm{e}^{-kt}$`。

`$[\mathrm{A}]' = -k[\mathrm{A}]_0\mathrm{e}^{-kt} < 0$`（浓度下降）

`$[\mathrm{A}]'' = k^2[\mathrm{A}]_0\mathrm{e}^{-kt} > 0$`（向上弯，下降越来越慢）

这正对应第 1 讲观察到的"c–t 曲线越来越平"。

### 7.2 极值判据（求最大值/最小值）

找函数极值的两步：

1. **一阶条件**：解 `$f'(x) = 0$`，得驻点（斜率为 0 的点）。
2. **二阶判别**：代入 `$f''$`——
   - `$f'' > 0$` → 该点为**极小值**（碗底）
   - `$f'' < 0$` → 该点为**极大值**（碗顶）
   - `$f'' = 0$` → 需进一步判断（可能是拐点）

> [!warning] 易错提醒
> `$f'(x_0) = 0$` **只是必要条件**，不是充分条件。`$y = x^3$` 在 x = 0 处 `$y' = 0$` 但不是极值（是拐点）。务必用 `$f''$` 或两侧符号确认。

### 7.3 化学里的极值问题

| 场景 | 令什么为零 | 含义 |
|:--|:--|:--|
| 反应平衡 | `$\dfrac{dG}{d\xi} = 0$` | Gibbs 自由能最小 |
| 稳态近似 | `$\dfrac{d[\mathrm{I}]}{dt} = 0$` | 中间体浓度不再变化 |
| 最概然速率 | `$\dfrac{df(v)}{dv} = 0$` | Maxwell 分布峰值 |
| 最大产率温度 | `$\dfrac{dK}{dT}$` 与转化率联立 | 放热反应的最优温度 |
| 缓冲容量最大 | `$\dfrac{d\beta}{d(\mathrm{pH})} = 0$` | pH = pKa 处 |

**例（稳态近似的手算）**：对连串反应 `$\mathrm{A}\xrightarrow{k_1}\mathrm{I}\xrightarrow{k_2}\mathrm{P}$`，中间体 I 的浓度满足

`$\dfrac{d[\mathrm{I}]}{dt} = k_1[\mathrm{A}] - k_2[\mathrm{I}]$`

稳态近似令 `$\dfrac{d[\mathrm{I}]}{dt} = 0$`，得

`$k_1[\mathrm{A}] = k_2[\mathrm{I}] \quad\Rightarrow\quad [\mathrm{I}] = \dfrac{k_1}{k_2}[\mathrm{A}]$`

这就是"稳态浓度"的由来——**不是中间体不动了，而是生成与消耗速率相等，净变化率为零**。

**练一练 7-1**：函数 `$y = x^3 - 3x$`，求驻点并判断极大/极小。（答案见 §十二）

## 八、微分 dy —— 为什么化学里到处是 d

### 8.1 定义

**微分**（differential）：若 `$y = f(x)$` 可导，则定义

`$dy = f'(x)\,dx$`

其中 dx 是自变量的**任意增量**（可大可小，在极限意义下"无穷小"），dy 是相应的线性主部。

关键关系：

`$f'(x) = \dfrac{dy}{dx}$`

**现在它真的像分数了**——因为微分就是这么定义的：dy 除以 dx。

### 8.2 为什么要有微分：Δy ≈ dy

设 `$x$` 变化了 `$\Delta x$`，真实变化量是

`$\Delta y = f(x+\Delta x) - f(x)$`

而微分给出的是**用切线近似**的预测值：

`$\Delta y \approx dy = f'(x)\Delta x$`

| | 真实 Δy | 近似 dy | 几何 |
|:--|:--|:--|:--|
| 含义 | 沿曲线的实际变化 | 沿切线的变化 | 以直代曲 |
| 误差 | — | 约与 `$(\Delta x)^2$` 同量级 | Δx 越小越准 |

**例**：`$y = x^2$`，x 从 3 变到 3.01。

真实：`$\Delta y = 3.01^2 - 3^2 = 9.0601 - 9 = 0.0601$`

微分：`$dy = 2x\cdot\Delta x = 2\times3\times0.01 = 0.06$`

误差 0.0001（相对 0.17%），确实很小。

### 8.3 微分形式不变性（好用的性质）

无论 u 是自变量还是中间变量，都有

`$d(\ln u) = \dfrac{du}{u}$`　　`$d(\mathrm{e}^{u}) = \mathrm{e}^{u}du$`　　`$d(u^n) = nu^{n-1}du$`

**例（化学里最常用的一个微分）**：

`$d\ln[\mathrm{A}] = \dfrac{d[\mathrm{A}]}{[\mathrm{A}]}$`

读作"浓度的**相对**变化 = 浓度对数的变化"。这在误差分析里极其有用：`$\Delta\ln[\mathrm{A}] \approx \dfrac{\Delta[\mathrm{A}]}{[\mathrm{A}]}$` —— 对数坐标下的误差就是相对误差。

### 8.4 化学里那些 d 都是什么

| 写法 | 读法 | 含义 |
|:--|:--|:--|
| `$d[\mathrm{A}]$` | 浓度的微分 | 浓度在 dt 时间内的微小变化 |
| `$dT$` | 温度的微分 | 温度的微小变化 |
| `$dG$` | Gibbs 自由能的微分 | 状态函数的微小变化（第 5 讲会展开成全微分） |
| `$d\xi$` | 反应进度的微分 | 反应推进了极少量 |
| `$\dfrac{d[\mathrm{A}]}{dt}$` | 浓度对时间的导数 | 瞬时变化率 |

> [!info] 深入思考
> 微分是**第 5 讲偏导与全微分**的入口：当 y 依赖多个变量（如 G 依赖 T 和 p），微分就要写成各变量贡献之和 `$dG = (\partial G/\partial T)_p dT + (\partial G/\partial p)_T dp$`。第 5 讲会完整讲这个式子，本讲只需记住：**d 表示"极小的变化量"**。

**练一练 8-1**：`$[\mathrm{A}] = 0.200\ \mathrm{mol\cdot L^{-1}}$`，若测量误差 `$\Delta[\mathrm{A}] = 0.002\ \mathrm{mol\cdot L^{-1}}$`，估算 `$\Delta\ln[\mathrm{A}]$` 及对应的相对误差。（答案见 §十二）

## 九、化学里的 d[A]/dt 与"令导数为零"

### 9.1 速率的严格定义

对反应 `$a\mathrm{A} + b\mathrm{B} \to g\mathrm{G} + h\mathrm{H}$`，**统一速率**定义为

`$v = -\dfrac{1}{a}\dfrac{d[\mathrm{A}]}{dt} = -\dfrac{1}{b}\dfrac{d[\mathrm{B}]}{dt} = \dfrac{1}{g}\dfrac{d[\mathrm{G}]}{dt} = \dfrac{1}{h}\dfrac{d[\mathrm{H}]}{dt}$`

三个要点：
- **负号**：反应物在减少，加负号使 v 为正
- **除以化学计量数**：消除"不同物质变化快慢不同"的影响
- **d 而不是 Δ**：强调是瞬时值

### 9.2 从微分式到微分方程

实验发现速率与浓度的关系（速率方程）本身就是微分式：

| 级数 | 微分速率方程 | 写成导数形式 |
|:--|:--|:--|
| 零级 | `$v = k$` | `$-\dfrac{d[\mathrm{A}]}{dt} = k$` |
| 一级 | `$v = k[\mathrm{A}]$` | `$-\dfrac{d[\mathrm{A}]}{dt} = k[\mathrm{A}]$` |
| 二级 | `$v = k[\mathrm{A}]^2$` | `$-\dfrac{d[\mathrm{A}]}{dt} = k[\mathrm{A}]^2$` |

**这类"含有导数的方程"叫微分方程**。第 4 讲要做的，就是解这三个方程，得到第 1 讲那张"积分式"表里的内容。

### 9.3 稳态近似：令导数为零

对活泼中间体（自由基、碳正离子等），其浓度低且寿命短，可认为

`$\dfrac{d[\mathrm{I}]}{dt} \approx 0$`

**这不是"浓度为零"，而是"浓度不再随时间变化"**——生成速率 = 消耗速率。把它代入机理方程，就能把难测的中间体浓度用可测的反应物浓度表示出来。

### 9.4 平衡条件：令 dG = 0

反应进行到 Gibbs 自由能最低点时达到平衡：

`$\dfrac{dG}{d\xi} = 0$`

`$\xi$` 是反应进度。这个条件配合 `$G$` 的表达式，就能推出 `$ΔG = ΔG^\circ + RT\ln Q$` 以及平衡时 `$ΔG^\circ = -RT\ln K$` —— 也就是第 2 讲反复出现的那个式子。

**练一练 9-1**：反应 `$\mathrm{2N_2O_5 \to 4NO_2 + O_2}$`，若 `$\dfrac{d[\mathrm{O_2}]}{dt} = 1.20\times10^{-4}\ \mathrm{mol\cdot L^{-1}\cdot s^{-1}}$`，求 `$-\dfrac{d[\mathrm{N_2O_5}]}{dt}$` 与统一速率 v。（答案见 §十二）

## 十、典型例题

### 例1 [基本求导]（基础）

求下列函数的导数：
(a) `$y = 4x^3 - 2x^2 + 5x - 1$`
(b) `$y = \dfrac{3}{x} + 2\ln x$`
(c) `$y = \sqrt{x}\,\mathrm{e}^{x}$`

**解答**：

(a) `$y' = 12x^2 - 4x + 5$`

(b) `$y = 3x^{-1} + 2\ln x$`，故 `$y' = -3x^{-2} + \dfrac{2}{x} = -\dfrac{3}{x^2} + \dfrac{2}{x}$`

(c) 乘积法则：`$u = \sqrt{x} = x^{1/2}$`，`$u' = \dfrac{1}{2\sqrt{x}}$`；`$v = \mathrm{e}^{x}$`，`$v' = \mathrm{e}^{x}$`

`$y' = \dfrac{1}{2\sqrt{x}}\mathrm{e}^{x} + \sqrt{x}\,\mathrm{e}^{x} = \mathrm{e}^{x}\left(\dfrac{1}{2\sqrt{x}} + \sqrt{x}\right)$`

### 例2 [链式法则·化学]（进阶）

已知 `$k = A\mathrm{e}^{-E_a/RT}$`，求 `$\dfrac{d\ln k}{d(1/T)}$`，并用它说明"Arrhenius 图斜率 = `−Eₐ/R`"。

**解答**：

`$\ln k = \ln A - \dfrac{E_a}{R}\cdot\dfrac{1}{T}$`

令 `$x = 1/T$`，则 `$\ln k = \ln A - \dfrac{E_a}{R}x$` 是 x 的一次函数。

`$\dfrac{d\ln k}{d(1/T)} = \dfrac{d\ln k}{dx} = -\dfrac{E_a}{R}$`

故以 `1/T` 为横轴、`ln k` 为纵轴作图，直线斜率为 `$-\dfrac{E_a}{R}$`。

**自检**：`$E_a > 0 \Rightarrow$` 斜率为负 ⇒ `1/T` 增大（降温）时 `ln k` 减小 ⇒ 降温反应速率下降 ✓

### 例3 [微分与线性近似]（进阶）

某量热实验中 `$T = 298.0\ \mathrm{K}$`，测得 `$\ln K = -4.60$`。若 K 有 1% 的相对误差，估算 `ln K` 的绝对误差，并进一步估算 `ΔG° = −RT ln K` 的误差。

**解答**：

由 `$d\ln K = \dfrac{dK}{K}$`，相对误差 1% ⇒ `$\Delta\ln K \approx 0.01$`。

`$\Delta G^\circ = -RT\ln K$`，故 `$\Delta(\Delta G^\circ) = -RT\cdot\Delta\ln K = -8.314\times298\times0.01 = -24.8\ \mathrm{J\cdot mol^{-1}}$`

即 ΔG° 的误差约 ±25 J·mol⁻¹（0.025 kJ·mol⁻¹）。

**结论**：K 的 1% 误差在 ΔG° 上只造成约 25 J·mol⁻¹ 的偏差——**对数把相对误差压缩成了绝对误差**，这就是热力学计算对 K 的精度要求不高的原因。

### 例4 [极值判据]（挑战）

连串反应 `$\mathrm{A}\xrightarrow{k_1}\mathrm{I}\xrightarrow{k_2}\mathrm{P}$`，`$[\mathrm{A}] = [\mathrm{A}]_0\mathrm{e}^{-k_1 t}$`，用稳态近似求 `[I](t)`，并求 `[I]` 达到极大的时刻（精确解中 `[I]` 先增后减）。

**解答**：

稳态：`$\dfrac{d[\mathrm{I}]}{dt} = k_1[\mathrm{A}] - k_2[\mathrm{I}] \approx 0$`

`$[\mathrm{I}] \approx \dfrac{k_1}{k_2}[\mathrm{A}] = \dfrac{k_1}{k_2}[\mathrm{A}]_0\mathrm{e}^{-k_1 t}$`

（注：稳态近似下 [I] 单调随 [A] 衰减，没有极大值——因为稳态近似在诱导期之后才成立。）

若不用稳态近似，精确解为

`$[\mathrm{I}] = \dfrac{k_1[\mathrm{A}]_0}{k_2 - k_1}\left(\mathrm{e}^{-k_1 t} - \mathrm{e}^{-k_2 t}\right)$`

令 `$\dfrac{d[\mathrm{I}]}{dt} = 0$`：

`$-k_1\mathrm{e}^{-k_1 t} + k_2\mathrm{e}^{-k_2 t} = 0 \Rightarrow \dfrac{k_1}{k_2} = \mathrm{e}^{-(k_2-k_1)t}$`

`$t_{\max} = \dfrac{\ln(k_2/k_1)}{k_2 - k_1}$`

> [!tip] 理解要点
> 精确解有极值而稳态解没有——**这正是稳态近似的适用条件**：在 `$t > t_{\max}$` 之后，[I] 缓慢下降的阶段才成立。近似的边界比近似本身更重要。

| 法则 | 式子 |

**练一练 2-1**：`$f(x+\Delta x)-f(x) = 3(x+\Delta x)+1-(3x+1) = 3\Delta x$`；比值 = 3；极限 = 3。即一次函数的导数就是它的斜率 k。

**练一练 4-1**：`$6x - 5$`；`$-6x^{-4} = -\dfrac{6}{x^4}$`；`$\dfrac{2}{\sqrt{x}}$`。

**练一练 5-1**：`$(x\mathrm{e}^{x})' = \mathrm{e}^{x} + x\mathrm{e}^{x} = \mathrm{e}^{x}(1+x)$`；`$\left(\dfrac{x}{1+x}\right)' = \dfrac{1\cdot(1+x) - x\cdot1}{(1+x)^2} = \dfrac{1}{(1+x)^2}$`。

**练一练 6-1**：`$\dfrac{d}{dx}\ln(3x^2+1) = \dfrac{6x}{3x^2+1}$`；`$\dfrac{d}{dx}\mathrm{e}^{-2x^2} = \mathrm{e}^{-2x^2}\cdot(-4x) = -4x\mathrm{e}^{-2x^2}$`。

**练一练 7-1**：`$y' = 3x^2 - 3 = 0 \Rightarrow x = \pm 1$`。`$y'' = 6x$`：x = 1 时 `$y'' = 6 > 0$` → 极小值 `$y = -2$`；x = −1 时 `$y'' = -6 < 0$` → 极大值 `$y = 2$`。

**练一练 8-1**：`$\Delta\ln[\mathrm{A}] \approx \dfrac{0.002}{0.200} = 0.010$`，即 ln[A] 的绝对误差约 0.010，对应相对误差 1.0%。

**练一练 9-1**：`$v = \dfrac{d[\mathrm{O_2}]}{dt} = 1.20\times10^{-4}$`（O₂ 系数 1）；`$-\dfrac{1}{2}\dfrac{d[\mathrm{N_2O_5}]}{dt} = v \Rightarrow -\dfrac{d[\mathrm{N_2O_5}]}{dt} = 2v = 2.40\times10^{-4}\ \mathrm{mol\cdot L^{-1}\cdot s^{-1}}$`。
