# 结构化学学生讲义·版本对照与选用指南

## 为什么同一主题会有多份？

这些**不是重复/冗余文件**，而是按「深度层级 + 用途」分层的正经教学材料。

- 化学原理 / 有机化学 / 元素与分析 三个模块：每份主题唯一，命名统一为 `XX-超级充实版（自学完整）`，不显乱。
- **只有结构化学模块**混用了 7 种后缀（超级充实版 / 新课 / 第一轮基础版（普化原理）/ 教师增强版 / 超级充实融合版 / 补充 / 前置知识速查），所以看起来「好几个相同、分不清」。
- **已按主题归入子文件夹**：`原子结构/` `分子结构/` `晶体学/` `配位化学/`（同源多版本聚在一起）；单主题与跨主题合集（`元素周期表与周期律`、`结构化学专题课-学生用合集`、`结构化学第一轮复习`、`超分子化学`）留在 `结构化学/` 根级。文件夹视图即按主题分组，不再平铺混淆。

## 版本后缀语义字典

| 后缀 | 含义 | 给谁用 | 深度轮次 |
|:--|:--|:--|:--|
| `超级充实版（自学完整）` | 学生自学完整**主版** | 学生 | 第一轮~第四轮 |
| `补充` / `深化` | 决赛级**进阶**材料 | 学生（进阶） | 第三轮 / 决赛 |
| `第一轮基础版（普化原理）` | 早期基础版（来源：普化原理第4版） | 学生 | 第一轮基础 |
| `新课` | 某轮新课讲义 | 学生 | 第一轮 |
| `教师增强版` | 含教师向信息（学生不可见部分，导出 docx 自动忽略） | 教师 | 第一轮 |
| `超级充实融合版` | 该讲次的融合版 | 学生 | 第一轮 |
| `前置知识速查` | 高一入门速查表（draft） | 辅助 | 高一入门 |

## 给学生发哪份？

默认发每个主题的 **「超级充实版（自学完整）」**（学生主线）；需要进阶时再发「补充 / 深化」。

其余版本（基础版 / 新课 / 教师增强版 / 超级充实融合版 / 前置知识速查）属于**同源早期版或教师专属**，非必发——除非你明确要给学生某一轮次的特定版本。
