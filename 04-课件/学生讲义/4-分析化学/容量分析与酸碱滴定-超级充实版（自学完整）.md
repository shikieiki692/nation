## §1 容量分析总纲与命题脉络

容量分析（滴定分析）是化学竞赛定量计算的核心工具，酸碱滴定以质子转移平衡为底座，是分析化学中最基础也最常考的板块。大学教材往往偏重实验操作规程与离散的点式计算，而竞赛命题的核心转向四类模型：

一是质子条件式（PBE）的零水准列式。面对混合弱酸、酸式盐缓冲对或弱酸弱碱盐体系，用"质子参考水准"法直接写出单一 PBE，可在建模第一步排除所有惰性反离子的干扰，比联立物料守恒与电荷守恒更快地导出 $[\mathrm{H^+}]$ 关系式。

二是型体分布分数 $\delta$ 与缓冲溶液判据。竞赛不仅要求计算特定 $\mathrm{pH}$ 下的分布分数，还要求由分布曲线读出 $\mathrm{p}K_a$、判断优势型体区，并掌握缓冲容量的峰值条件 $\mathrm{pH} = \mathrm{p}K_a$ 与有效区间 $\mathrm{pH} = \mathrm{p}K_a \pm 1$。

三是滴定曲线与突跃、指示剂选择。掌握强酸强碱与弱酸强碱滴定曲线的分区计算、强酸强碱突跃范围公式 $\Delta\mathrm{pH} = 2\lg c_{sp} + 8.0$，以及由计量点 $\mathrm{pH}$ 匹配指示剂变色区间的方法。

四是终点误差与强化滴定。掌握弱酸准确滴定判据 $c K_a \ge 10^{-8}$、多元酸分步滴定判据 $K_{a1}/K_{a2} \ge 10^4$，以及针对极弱酸弱碱的配位/缩合强化滴定（甘露醇强化硼酸、甲醛法测铵盐）与工业混合碱的双指示剂连续滴定。

## §2 质子条件式（PBE）与三大守恒关系

### 2.1 质子平衡的本质与三大守恒关系

水溶液中的酸碱反应在微观尺度上本质是质子（$\mathrm{H^+}$）在供体酸与受体碱之间的离域传递。由于裸露的质子具有极高的电荷密度（半径仅约 $10^{-15}\ \mathrm{m}$），在水溶液中不可能以自由质子孤立存在，必须与水分子配位形成水合氢离子（如 $\mathrm{H_3O^+}, \mathrm{H_5O_2^+}$ 等，通记为 $\mathrm{H^+}$）。在任意封闭均相水溶液体系中，溶质粒子与溶剂分子的相互作用同时受到三大守恒公理的绝对约束：

其一为物料平衡方程（Mass Balance Equation, MBE）：根据质量守恒定律，溶液中某一组分的某种特征原子或基团的总物质的量，必严格等于该组分在溶液中以各种不同化合平衡型体存在的浓度总和。例如浓度为 $c\ \mathrm{mol\cdot L^{-1}}$ 的二元弱酸 $\mathrm{H_2A}$ 溶液中，物料守恒严格表述为 $c = [\mathrm{H_2A}] + [\mathrm{HA^-}] + [\mathrm{A^{2-}}]$。

其二为电荷平衡方程（Charge Balance Equation, CBE）：电解质水溶液从宏观统计学上必须保持绝对的电中性，因此体系中所有阳离子所带的正电荷摩尔浓度总代数和，必须恒等于所有阴离子所带的负电荷摩尔浓度总代数和。每种离子对宏观电荷的贡献等于其平衡摩尔浓度与其所带净电荷绝对值 $z_i$ 的乘积：$\sum z_i [\mathrm{M}^{z_i+}] = \sum |z_j| [\mathrm{A}^{z_j-}]$。对于 $\mathrm{Na_2HPO_4}$ 溶液，电荷平衡方程严格展开为：
$$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{H_2PO_4^-}] + 2[\mathrm{HPO_4^{2-}}] + 3[\mathrm{PO_4^{3-}}]$$

其三为质子条件式（Proton Balance Equation, PBE）：质子转移过程伴随得失质子守恒，即体系在达到酸碱平衡后，所有酸性组分失去质子的总物质的量，必然严格等于所有碱性组分接受质子的总物质的量。

在化竞代数解题中，PBE 相比于 MBE 和 CBE 具有显著的代数优势。数学上可以严格证明：PBE 并非一个独立于 MBE 和 CBE 的新公理，它在数学上完全等价于电荷平衡方程 CBE 与惰性反离子物料平衡方程 MBE 的线性消元组合。然而，若从 MBE 和 CBE 出发，由于方程中含有大量不参与酸碱质子转移的金属反离子（如 $\mathrm{Na^+}, \mathrm{K^+}, \mathrm{Cl^-}$ 等），必须进行多步代数联立消元方能解出 $[\mathrm{H^+}]$；而直接选取零水准列写 PBE，则在建模第一步就彻底排除了所有惰性反离子的干扰，使未知量数目瞬间减少 2 个，直接建立起仅包含待测 $[\mathrm{H^+}]$ 与弱酸弱碱平衡型体的代数关系，节省超过 $70\%$ 的推导时间。

### 2.2 质子参考水准（Zero Level）选择法与四大典型体系构建

要快速、精准且绝不遗漏地写出任意复杂水溶液体系的质子条件式，必须建立严格的“质子参考水准（Zero Level，零水准）”拓扑映射法。

质子参考水准的选取法则明晰：必须选取溶液中在酸碱质子转移反应发生之前大量存在、且直接参与质子传递的原始反应物物种。通常包含溶剂水分子（$\mathrm{H_2O}$）以及溶质解离出的原始弱酸、弱碱或弱酸弱碱盐离子；不参与得失质子的惰性离子（如碱金属离子 $\mathrm{Na^+}, \mathrm{K^+}$、强酸根离子 $\mathrm{Cl^-}, \mathrm{NO_3^-}, \mathrm{ClO_4^-}$）绝对不可作为参考水准。

以质子参考水准为零势能点，系统梳理体系的质子流向：参考物每失去 1 个质子转化为失质子产物，等式右侧记入 1 份该产物平衡浓度；每失去 $k$ 个质子，右侧冠以系数 $k$；反之，参考物每接受 1 个质子转化为得质子产物，等式左侧记入 1 份该产物平衡浓度；每接受 $m$ 个质子，左侧冠以系数 $m$。最终得出得失质子守恒方程：
$$\sum m \cdot [得质子产物] = \sum k \cdot [失质子产物]$$

化竞中最为高频的四大典型体系 PBE 列式规范如下：

第一类：一元与多元弱酸弱碱单一体系。以浓度为 $c\ \mathrm{mol\cdot L^{-1}}$ 的二元弱酸 $\mathrm{H_2S}$ 为例。质子参考水准选取为大量存在的原始分子 $\mathrm{H_2S}$ 与 $\mathrm{H_2O}$。分析质子流动：$\mathrm{H_2O}$ 接受 1 个质子转化为水合氢离子 $[\mathrm{H^+}]$（得 1 个质子），失去 1 个质子转化为氢氧根离子 $[\mathrm{OH^-}]$（失 1 个质子）；$\mathrm{H_2S}$ 失去 1 个质子转化为硫氢根 $[\mathrm{HS^-}]$（失 1 个质子），失去 2 个质子转化为硫离子 $[\mathrm{S^{2-}}]$（失 2 个质子）。体系不存在其他得质子物种，直接列出精确 PBE：
$$[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HS^-}] + 2[\mathrm{S^{2-}}]$$

第二类：酸式盐两性缓冲体系。以浓度为 $c\ \mathrm{mol\cdot L^{-1}}$ 的磷酸二氢钠（$\mathrm{NaH_2PO_4}$）水溶液为例。惰性阳离子 $\mathrm{Na^+}$ 排除，质子参考水准选取为 $\mathrm{H_2PO_4^-}$ 和 $\mathrm{H_2O}$。质子流动分析：$\mathrm{H_2PO_4^-}$ 接受 1 个质子生成磷酸分子 $[\mathrm{H_3PO_4}]$（得 1 个质子）；$\mathrm{H_2PO_4^-}$ 失去 1 个质子生成磷酸氢根 $[\mathrm{HPO_4^{2-}}]$（失 1 个质子），失去 2 个质子生成磷酸根 $[\mathrm{PO_4^{3-}}]$（失 2 个质子）；$\mathrm{H_2O}$ 接受质子生成 $[\mathrm{H^+}]$，失去质子生成 $[\mathrm{OH^-}]$。精确列出 PBE：
$$[\mathrm{H^+}] + [\mathrm{H_3PO_4}] = [\mathrm{OH^-}] + [\mathrm{HPO_4^{2-}}] + 2[\mathrm{PO_4^{3-}}]$$
同理，对于磷酸氢二钠（$\mathrm{Na_2HPO_4}$），以 $\mathrm{HPO_4^{2-}}$ 和 $\mathrm{H_2O}$ 为参考水准，其 PBE 为：
$$[\mathrm{H^+}] + [\mathrm{H_2PO_4^-}] + 2[\mathrm{H_3PO_4}] = [\mathrm{OH^-}] + [\mathrm{PO_4^{3-}}]$$

第三类：弱酸弱碱盐体系。以浓度为 $c\ \mathrm{mol\cdot L^{-1}}$ 的醋酸铵（$\mathrm{NH_4Ac}$）或氰化铵（$\mathrm{NH_4CN}$）为例。参考水准选取阴阳离子与水：$\mathrm{NH_4^+}, \mathrm{Ac^-}, \mathrm{H_2O}$。$\mathrm{Ac^-}$ 接受 1 个质子转化为分子 $[\mathrm{HAc}]$（得 1 个质子）；$\mathrm{NH_4^+}$ 失去 1 个质子转化为分子 $[\mathrm{NH_3}]$（失 1 个质子）；$\mathrm{H_2O}$ 对应 $[\mathrm{H^+}]$ 与 $[\mathrm{OH^-}]$。精确 PBE 瞬间得出：
$$[\mathrm{H^+}] + [\mathrm{HAc}] = [\mathrm{OH^-}] + [\mathrm{NH_3}]$$
若为磷酸氢二铵（$(\mathrm{NH_4)_2HPO_4}$），参考水准选取 $\mathrm{NH_4^+}, \mathrm{HPO_4^{2-}}, \mathrm{H_2O}$，精确 PBE 展开为：
$$[\mathrm{H^+}] + [\mathrm{H_2PO_4^-}] + 2[\mathrm{H_3PO_4}] = [\mathrm{OH^-}] + [\mathrm{PO_4^{3-}}] + [\mathrm{NH_3}]$$

第四类：强弱共存与非等摩尔混合酸碱体系。设溶液中含有浓度为 $c_a\ \mathrm{mol\cdot L^{-1}}$ 的强酸 $\mathrm{HCl}$ 与浓度为 $c_b\ \mathrm{mol\cdot L^{-1}}$ 的一元弱酸 $\mathrm{HAc}$。此时强酸 $\mathrm{HCl}$ 在水中完全电离，由于加入体系的初始形态是 $\mathrm{HCl}$ 分子，它在反应后 $100\%$ 失去了质子，因此失质子产物中必须计入 $\mathrm{HCl}$ 解离出的全量氯离子浓度（数值恒等于 $c_a$）。选取 $\mathrm{HCl}, \mathrm{HAc}, \mathrm{H_2O}$ 为参考基准，列写精确 PBE：
$$[\mathrm{H^+}] = c_a + [\mathrm{Ac^-}] + [\mathrm{OH^-}]$$
该式清晰展现了强酸对弱酸电离的同离子压制：外来强酸直接提供 $c_a$ 浓度的质子，使平衡 $[\mathrm{Ac^-}]$ 骤降。

### 2.3 各类酸碱体系 pH 计算的判据与近似边界

将型体平衡常数代入质子条件式后，往往导出非线性高阶方程。盲目使用最简公式会导致显著失分，因此必须掌握各近似式的适用边界。

一元弱酸（$\mathrm{HA}$，浓度 $c$、离解常数 $K_a$）的精确质子条件式为 $[\mathrm{H^+}] = [\mathrm{A^-}] + [\mathrm{OH^-}]$，代入型体分布与水的离子积后可导出三次方程。其可简化的判据来自两条误差边界。

其一，略去水的电离（要求引入的相对误差小于 $2.5\%$）：需 $[\mathrm{OH^-}]/[\mathrm{H^+}] \le 5\%$，即 $\dfrac{K_w}{[\mathrm{H^+}]^2} \le 0.05$，得 $c K_a \ge 20 K_w$（$25\ \mathrm{℃}$ 时即 $c K_a \ge 2.0\times10^{-13}$）。满足后水解离项可略，方程降为 $[\mathrm{H^+}]^2 + K_a[\mathrm{H^+}] - c K_a = 0$。

其二，略去弱酸自身电离的消耗（要求相对误差不超过 $2.5\%$）：由电离度 $\alpha = \sqrt{K_a/c} \le 5\%$ 得 $c / K_a \ge 500$。

当且仅当同时满足 $c K_a \ge 20 K_w$ 与 $c/K_a \ge 500$ 时，方可使用最简式 $[\mathrm{H^+}] \approx \sqrt{c K_a}$。若 $c/K_a < 500$ 但 $c K_a \ge 20 K_w$（例如 $0.010\ \mathrm{mol\cdot L^{-1}}$ 氯乙酸，$\mathrm{p}K_a = 2.86$，$c/K_a \approx 7.2$），直接套用最简式误差超过 $30\%$，须用一元二次求根公式。

两性物质体系（以酸式盐 $\mathrm{NaHA}$ 为代表，浓度 $c$、两级常数 $K_{a1}, K_{a2}$）的精确式为：

$$[\mathrm{H^+}] = \sqrt{\frac{K_{a1}(c K_{a2} + K_w)}{c + K_{a1}}}$$

当 $c K_{a2} \ge 20 K_w$ 且 $c \ge 20 K_{a1}$ 时，分子中的 $K_w$ 与分母中的 $K_{a1}$ 均可略，浓度项上下对消，化简为两性最简式 $[\mathrm{H^+}] \approx \sqrt{K_{a1} K_{a2}}$。当体系极稀（$c \to 0$）时，方程收敛至 $\sqrt{K_w} = 10^{-7}$（纯水极限）；当一级酸性较强时（如 $\mathrm{NaHSO_3}$，$K_{a1} = 1.5\times10^{-2}$，$c$ 仅为 $K_{a1}$ 的 6.7 倍），分母中的 $K_{a1}$ 不可略去，须用精确分式 $[\mathrm{H^+}] \approx \sqrt{\dfrac{c K_{a1} K_{a2}}{c + K_{a1}}}$，否则误差可超过 $0.3$ 个 $\mathrm{pH}$ 单位。

## §3 型体分布分数与缓冲溶液

### 3.1 一元与多元酸型体分布分数（$\delta$）通式与递推规律

在多级解离平衡的水溶液体系中，随着溶液 pH 值的连续平滑演变，酸碱粒子在不同质子化结合状态（不同平衡型体）之间发生动态转移。某种特定平衡型体的摩尔平衡浓度与体系溶质总分析浓度（$c_{\mathrm{tot}}$）的比值，定义为该型体的分布分数（Distribution fraction, $\delta$）。分布分数是纯无量纲参数，其本质仅由溶液自由氢离子浓度 $[\mathrm{H^+}]$ 及各级解离平衡常数唯一确定，与溶质绝对宏观总量无关。

对于一般 $n$ 元弱酸体系 $\mathrm{H}_n\mathrm{A}$，溶液中共存 $n+1$ 种平衡型体：$\mathrm{H}_n\mathrm{A}, \mathrm{H}_{n-1}\mathrm{A}^-, \dots, \mathrm{A}^{n-}$。定义多项式分布分母：
$$D = [\mathrm{H^+}]^n + K_{a1}[\mathrm{H^+}]^{n-1} + K_{a1}K_{a2}[\mathrm{H^+}]^{n-2} + \dots + \left(\prod_{i=1}^n K_{ai}\right)$$
则任意失去 $k$ 个质子的共轭碱型体 $\mathrm{H}_{n-k}\mathrm{A}^{k-}$（其中 $k = 0, 1, \dots, n$）的分布分数通式严格表示为：
$$\delta_k = \delta(\mathrm{H}_{n-k}\mathrm{A}^{k-}) = \frac{\left(\prod_{i=1}^k K_{ai}\right) [\mathrm{H^+}]^{n-k}}{D}$$
根据全概率守恒公理，体系中所有型体的分布分数总代数和恒等于 1，即 $\sum_{k=0}^n \delta_k = 1$。

> 图 2-1：三元弱酸磷酸各型体分布分数随 pH 变化曲线与三个 pKa 交点

观察磷酸（$\mathrm{H_3PO_4}$，$\mathrm{p}K_{a1} = 2.12, \mathrm{p}K_{a2} = 7.21, \mathrm{p}K_{a3} = 12.67$）型体分布图谱，展现出极具美感的三大微观规律：
第一，等比交叉对称性：在相邻两型体分布曲线的交点处，必然满足 $[\mathrm{H}_{3-k}\mathrm{A}^{k-}] = [\mathrm{H}_{2-k}\mathrm{A}^{(k+1)-}]$，代入通式直接消去分母，得出此时氢离子活度恰好等于对应级数的解离常数，即 $[\mathrm{H^+}] = K_{a(k+1)} \iff \mathrm{pH} = \mathrm{p}K_{a(k+1)}$。在交点处，这两者各自占据主导的 $50\%$ 份额（当各级常数相差大于 $10^4$ 时，其余次级型体总量 $< 0.1\%$ 可忽略）。
第二，优势纯态峰值：在两级交点之间，中间酸式盐型体在特定 pH 下达到几乎 $100\%$ 孤立存在的纯态峰值。峰顶对应的酸度由相邻常数的对数算术均值给出：例如 $\mathrm{H_2PO_4^-}$ 在 $\mathrm{pH} = \frac{2.12 + 7.21}{2} = 4.66$ 时，其分布分数 $\delta_2 > 99.2\%$；$\mathrm{HPO_4^{2-}}$ 在 $\mathrm{pH} = \frac{7.21 + 12.67}{2} = 9.94$ 时，分布分数 $\delta_1 > 99.0\%$。
第三，分步滴定物理相容性：两优势峰之间的深度低谷（型体交叠量 $< 0.1\%$）直接奠定了磷酸能够在水溶液中被强碱分步准确滴定至第一和第二计量点的宏观热力学基础。

### 3.2 对数浓度图与主导型体定界

对数浓度图以 $\mathrm{pH}$ 为横坐标、各平衡物种摩尔浓度的常用对数 $\lg c_i$ 为纵坐标，其价值在于把复杂的高阶有理分式在双对数坐标下转化为直线渐近线。以分析总浓度 $c_{\mathrm{tot}}$ 的一元弱酸 $\mathrm{HA}$ 为例：$\mathrm{HA}$ 的浓度线在 $\mathrm{pH} \ll \mathrm{p}K_a$ 时表现为斜率 $0$ 的水平线（$\lg[\mathrm{HA}] = \lg c_{\mathrm{tot}}$），在 $\mathrm{pH} \gg \mathrm{p}K_a$ 时表现为斜率 $-1$ 的下行线；其共轭碱 $\mathrm{A^-}$ 则相反，斜率由 $+1$ 转为 $0$。两条特征折线在 $(\mathrm{pH} = \mathrm{p}K_a,\ \lg c = \lg c_{\mathrm{tot}} - 0.30)$ 处相交，该点称为体系点。水的两条对数线为 $\lg[\mathrm{H^+}] = -\mathrm{pH}$ 与 $\lg[\mathrm{OH^-}] = -14 + \mathrm{pH}$。

利用该图可快速定界主导型体：在酸性区间取 $[\mathrm{H^+}] = [\mathrm{A^-}]$，在图上寻找 $\lg[\mathrm{H^+}]$ 直线与 $\lg[\mathrm{A^-}]$ 直线的交点，其横坐标即体系平衡 $\mathrm{pH}$，从而避免解析联立高阶方程。

### 3.3 缓冲容量与有效缓冲区间

缓冲溶液抗御外加酸碱扰动、维持 $\mathrm{pH}$ 相对恒定的能力，由范斯莱克（Van Slyke）缓冲容量 $\beta$ 定量描述，定义为使 $1\ \mathrm{L}$ 缓冲溶液的 $\mathrm{pH}$ 改变 1 个单位所需加入强碱（或强酸）的物质的量：

$$\beta = \frac{\mathrm{d}c_b}{\mathrm{dpH}} = -\frac{\mathrm{d}c_a}{\mathrm{dpH}}$$

对于由一元弱酸 $\mathrm{HA}$ 与其共轭碱构成、总浓度为 $c_{\mathrm{tot}}$ 的体系，可得范斯莱克缓冲容量方程：

$$\beta = 2.303 \left( [\mathrm{H^+}] + [\mathrm{OH^-}] + \frac{c_{\mathrm{tot}} K_a [\mathrm{H^+}]}{([\mathrm{H^+}] + K_a)^2} \right)$$

该式表明缓冲容量的三元构成：强酸性介质中 $[\mathrm{H^+}]$ 项主导，强碱性介质中 $[\mathrm{OH^-}]$ 项主导，中等酸度缓冲区间则由弱酸共轭对决定。在缓冲区间内 $\beta_{\mathrm{buffer}} \approx 2.303 c_{\mathrm{tot}} \delta(\mathrm{HA})\delta(\mathrm{A^-})$。由驻点条件可知，当共轭酸碱浓度比严格为 $1:1$（即 $\mathrm{pH} = \mathrm{p}K_a$）时缓冲容量取峰值 $\beta_{\max} \approx 0.576 c_{\mathrm{tot}}$；在 $\mathrm{pH} = \mathrm{p}K_a \pm 1$ 处缓冲容量衰减至峰值的约 $33\%$。这确定了常规缓冲溶液的有效工作区间为 $\mathrm{pH} = \mathrm{p}K_a \pm 1$。

## §4 滴定曲线与突跃范围

### 4.1 强酸强碱滴定曲线与突跃跨度对数展开

酸碱滴定曲线精确刻画了在滴定全过程中，试液体系的 $\mathrm{pH}$ 随着滴定剂加入体积 $V$（或无量纲滴定百分数 $T\%$、滴定分数 $\Phi$）的函数演化轨迹。强酸强碱中和反应是滴定分析的基准参考系。以 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaOH}$ 滴定 $20.00\ \mathrm{mL}\ 0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HCl}$ 为例，滴定全过程的分区计算如下：

![[9c86dd8b005af9872f709ee20629ff94c3ac06682411d91ce1812ecb894df377.jpg|320]]
> 图 2-2：0.1 mol/L NaOH 滴定 0.1 mol/L HCl 的滴定曲线、突跃范围及指示剂选择依据

在化学计量点前 $-0.1\%$（$T\% = 99.9\%$，加入 $\mathrm{NaOH}\ 19.98\ \mathrm{mL}$）时，剩余未反应的 $\mathrm{HCl}$ 物质的量为 $20.00 \times 0.1000 \times 10^{-3} = 2.0 \times 10^{-3}\ \mathrm{mmol}$。体系总容积膨胀为 $V_{\mathrm{tot}} = 39.98\ \mathrm{mL}$。游离氢离子浓度为：
$$[\mathrm{H^+}]_{-0.1\%} = \frac{2.0 \times 10^{-3}\ \mathrm{mmol}}{39.98\ \mathrm{mL}} \approx 5.0 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}} \implies \mathrm{pH}_{-0.1\%} = 4.30$$
在化学计量点时（$T\% = 100.0\%$，加入 $\mathrm{NaOH}\ 20.00\ \mathrm{mL}$），酸碱等摩尔中和，产物为强电解质 $\mathrm{NaCl}$，体系酸度纯由水的自偶电离控制：$[\mathrm{H^+}]_{sp} = \sqrt{K_w} = 1.00 \times 10^{-7}\ \mathrm{mol\cdot L^{-1}} \implies \mathrm{pH}_{sp} = 7.00$。
在化学计量点后 $+0.1\%$（$T\% = 100.1\%$，加入 $\mathrm{NaOH}\ 20.02\ \mathrm{mL}$）时，过量的 $\mathrm{NaOH}$ 物质的量为 $2.0 \times 10^{-3}\ \mathrm{mmol}$，总容积 $40.02\ \mathrm{mL}$。过量氢氧根浓度为：
$$[\mathrm{OH^-}]_{+0.1\%} = \frac{2.0 \times 10^{-3}\ \mathrm{mmol}}{40.02\ \mathrm{mL}} \approx 5.0 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}} \implies \mathrm{pOH} = 4.30 \implies \mathrm{pH}_{+0.1\%} = 9.70$$

由此形成的滴定突跃范围跨度为 $\Delta \mathrm{pH} = 4.30 \sim 9.70$（跨度达 $5.40$ 个单位）。设被测物起始浓度为 $c_a$，计量点稀释浓度为 $c_{sp} = \frac{c_a}{2}$。突跃下限满足 $[\mathrm{H^+}] = 10^{-3} c_{sp}$，突跃上限满足 $[\mathrm{OH^-}] = 10^{-3} c_{sp} \implies [\mathrm{H^+}] = \frac{10^3 K_w}{c_{sp}}$。突跃范围跨度与反应物浓度的严格对数函数关系直接推导为：
$$\Delta \mathrm{pH}_{\mathrm{jump}} = \mathrm{pH}_{+0.1\%} - \mathrm{pH}_{-0.1\%} = \left(14 - \lg\frac{10^3 K_w}{c_{sp}}\right) - \left(-\lg(10^{-3} c_{sp})\right) = 2 \lg c_{sp} + 8.0$$
这一对数展开式严密证明了：强酸强碱滴定的突跃跨度与反应物浓度对数呈严格线性正比。反应物浓度每升高 10 倍，突跃范围上下两端各向外展宽 1 个单位，总跨度扩增 2.0 个 $\mathrm{pH}$ 单位；若浓度稀释 10 倍（至 $0.010\ \mathrm{mol\cdot L^{-1}}$），突跃跨度萎缩为 $3.40$ 个单位；若极端稀释至 $10^{-4}\ \mathrm{mol\cdot L^{-1}}$，突跃范围彻底压缩至零，无法指示终点。

### 4.2 弱酸滴定的连续滴定分数与计量点

弱酸强碱滴定的全过程可用连续解析式统一描述。以浓度 $c_b$ 的强碱滴定初始体积 $V_0$、浓度 $c_a$ 的一元弱酸，由电荷守恒可解出加入强碱体积 $V$ 随自由 $[\mathrm{H^+}]$ 变化的显式函数。引入无量纲滴定分数 $\Phi = \dfrac{c_b V}{c_a V_0}$（$\Phi = 0$ 为初始点、$0.5$ 为半中和点、$1.0$ 为化学计量点、$>1.0$ 为过滴区），得全域连续方程：

$$\Phi([\mathrm{H^+}]) = \frac{\delta(\mathrm{A^-}) - \dfrac{[\mathrm{H^+}] - [\mathrm{OH^-}]}{c_a}}{1 + \dfrac{[\mathrm{H^+}] - [\mathrm{OH^-}]}{c_b}}$$

该式在 $[\mathrm{H^+}] \in (0, \infty)$ 内严格连续单调，是分析任意滴定点与编写滴定模拟程序的基础。实际计算中，只需按滴定前、计量点前（缓冲区）、计量点（水解区）、计量点后（过量强碱区）四段分别代入相应主导平衡即可求解。

### 4.3 滴定突跃中点与化学计量点的关系

教学中常有一种误解，以为滴定突跃曲线斜率最大的几何拐点必然严格等同于理论化学计量点。对于强酸强碱滴定，因中和产物为中性强电解质，曲线关于 $(\Phi = 1.0,\ \mathrm{pH} = 7.00)$ 呈点对称，拐点、突跃中点与理论计量点三者完全重合。对于强碱滴定弱酸，化学计量点产物为强碱弱酸盐并发生微弱水解，计量点显碱性（如 $\mathrm{NaOH}$ 滴定 $\mathrm{HAc}$ 时 $\mathrm{pH}_{sp} \approx 8.7$），计量点前后的控制机理（缓冲对 vs 过量强碱稀释）不对称，故最陡拐点与理论计量点存在极微小偏移（常量分析中通常仅 $10^{-4} \sim 10^{-5}$ 量级，被滴定管读数误差掩盖）。认识到这一微偏，是理解非对称离子平衡对宏观测量影响的关键。

### 4.4 一元弱酸弱碱准确滴定判据（$c K_a \ge 10^{-8}$）

弱酸能否被强碱直接准确滴定，不仅取决于反应平衡常数，更取决于化学计量点前后能否激发出具有足够跨度（至少达 $0.3 \sim 0.4$ 个 $\mathrm{pH}$ 单位）的陡峭突跃平台。

设滴定允许的相对误差严格控制在 $\pm 0.1\%$ 以内：
突跃下限（化学计量点前 $-0.1\%$）：此时已反应中和了 $99.9\%$ 的弱酸，剩余 $0.1\%$ 的未反应分子，由缓冲方程严格给出：
$$\mathrm{pH}_{-0.1\%} = \mathrm{p}K_a + \lg\left(\frac{99.9\%}{0.1\%}\right) = \mathrm{p}K_a + \lg(999) \approx \mathrm{p}K_a + 3.00$$
突跃上限（化学计量点后 $+0.1\%$）：由过量 $0.1\%$ 的强碱完全主导酸度，设化学计量点弱酸盐浓度为 $c_{sp}$：
$$[\mathrm{OH^-}]_{+0.1\%} = 10^{-3} c_{sp} \implies \mathrm{pOH}_{+0.1\%} = 3.00 - \lg c_{sp} \implies \mathrm{pH}_{+0.1\%} = 11.00 + \lg c_{sp}$$
滴定突跃范围跨度由上限减去下限得出：
$$\Delta \mathrm{pH}_{\mathrm{jump}} = \mathrm{pH}_{+0.1\%} - \mathrm{pH}_{-0.1\%} = (11.00 + \lg c_{sp}) - (\mathrm{p}K_a + 3.00) = 8.00 + \lg(c_{sp} K_a)$$
根据人眼在指示剂双色过渡区中识别颜色突变的生理分辨极限，突跃跨度必须至少满足 $\Delta \mathrm{pH}_{\mathrm{jump}} \ge 0.30$（通常取 0.00 为理论临界）：
$$8.00 + \lg(c_{sp} K_a) \ge 0.00 \implies \lg(c_{sp} K_a) \ge -8.00 \implies c_{sp} K_a \ge 10^{-8}$$
若考虑计量点前的稀释倍数，被测弱酸分析浓度满足：
$$c K_a \ge 10^{-8}$$
同理，一元弱碱被强酸滴定的直接准确滴定判据为 $c K_b \ge 10^{-8}$。若 $c K_a < 10^{-8}$（如硼酸 $\mathrm{H_3BO_3}$，$K_a = 5.8 \times 10^{-10}$，在 $0.1\ \mathrm{mol\cdot L^{-1}}$ 下 $c K_a \approx 5.8 \times 10^{-11} \ll 10^{-8}$），滴定曲线在化学计量点前后演化为平滑倾斜的直线，没有任何突跃台阶，常规酸碱指示剂完全失效。

## §5 滴定终点误差与林邦公式

### 5.1 滴定终点误差的物理本质

在滴定分析实践中，操作者依据指示剂颜色突变而停止滴定的点称为滴定终点（End point, ep）；而在理论上反应物与滴定剂严格按化学方程式计量数完全反应的点称为化学计量点（Equivalence point, sp）。终点与计量点在酸度上的不重合（$\Delta \mathrm{pH} = \mathrm{pH}_{ep} - \mathrm{pH}_{sp}$），必然引起消耗滴定剂体积的相对偏离，该偏离率称为终点误差（Titration error, $E_t$）：
$$E_t = \frac{V_{ep} - V_{sp}}{V_{sp}} \times 100\%$$

以强碱滴定强酸为例，终点过量或亏损的滴定剂物质的量等于终点时溶液中游离的氢氧根离子与未被中和的氢离子之差。设计量点体积为 $V_{sp}$，计量点浓度为 $c_{sp}$，由于终点非常逼近计量点（$V_{ep} \approx V_{sp}$），相对终点误差严密解析式为：
$$E_t = \frac{[\mathrm{OH^-}]_{ep} - [\mathrm{H^+}]_{ep}}{c_{sp}} \times 100\% = \frac{\frac{K_w}{[\mathrm{H^+}]_{ep}} - [\mathrm{H^+}]_{ep}}{c_{sp}} \times 100\%$$
若以强酸滴定强碱，分子符号颠倒：$E_t = \frac{[\mathrm{H^+}]_{ep} - [\mathrm{OH^-}]_{ep}}{c_{sp}} \times 100\%$。

### 5.2 一元弱酸强碱滴定林邦公式与综合参数 $c_{sp} K_t$

对于一元弱酸（$\mathrm{HA}$，浓度 $c$，离解常数 $K_a$）被强碱滴定体系，芬兰分析化学家林邦（A. Ringbom）建立了经典的微观误差模型。

在滴定终点时，滴定剂加入量不仅要提供游离的氢氧根离子，还受制于未被中和的弱酸分子形态。由终点时整个体系的物料守恒与电荷守恒全微分推导：
已消耗强碱物质的量为 $n_{\mathrm{NaOH}} = c_b V_{ep}$，已中和弱酸物质的量为 $[\mathrm{A^-}]_{ep} V_{ep}$。
终点多消耗的强碱物质的量为：
$$\Delta n = [\mathrm{OH^-}]_{ep} V_{ep} - [\mathrm{HA}]_{ep} V_{ep}$$
两端除以化学计量点总反应量 $n_{sp} = c_{sp} V_{sp} \approx c_{sp} V_{ep}$，导出弱酸滴定终点误差严格基础等式：
$$E_t = \frac{[\mathrm{OH^-}]_{ep} - [\mathrm{HA}]_{ep}}{c_{sp}} \times 100\%$$

根据弱酸根水解平衡：$\mathrm{A^-} + \mathrm{H_2O} \rightleftharpoons \mathrm{HA} + \mathrm{OH^-}$，水解平衡常数为 $K_b = \frac{K_w}{K_a}$。在化学计量点时，$[\mathrm{OH^-}]_{sp} = [\mathrm{HA}]_{sp} = \sqrt{c_{sp} K_b} = \sqrt{\frac{c_{sp} K_w}{K_a}}$。
定义酸度偏离值 $\Delta \mathrm{pH} = \mathrm{pH}_{ep} - \mathrm{pH}_{sp}$，则终点氢氧根离子浓度与弱酸分子浓度分别表示为计量点的指数放大：
$$[\mathrm{OH^-}]_{ep} = [\mathrm{OH^-}]_{sp} \cdot 10^{+\Delta \mathrm{pH}}$$
$$[\mathrm{HA}]_{ep} = [\mathrm{HA}]_{sp} \cdot 10^{-\Delta \mathrm{pH}}$$
将两项代入误差公式提取公因式 $[\mathrm{OH^-}]_{sp}$：
$$E_t = \frac{[\mathrm{OH^-}]_{sp} (10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}})}{c_{sp}} \times 100\% = \frac{\sqrt{\frac{c_{sp} K_w}{K_a}} (10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}})}{c_{sp}} \times 100\%$$
定义滴定反应 $\mathrm{HA} + \mathrm{OH^-} \rightleftharpoons \mathrm{A^-} + \mathrm{H_2O}$ 的化学平衡常数为 $K_t = \frac{K_a}{K_w} = \frac{1}{K_b}$。代入分母整理，导出享誉国际分析化学界的标准林邦终点误差通式：
$$E_t = \frac{10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}}}{\sqrt{c_{sp} K_t}} \times 100\% = \frac{10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}}}{\sqrt{c_{sp} \cdot \frac{K_a}{K_w}}} \times 100\%$$

林邦公式深刻揭示了滴定误差的决定性机制：分子项 $(10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}}) = 2 \sinh(2.303 \Delta \mathrm{pH})$ 为双曲正弦型函数，它反映了指示剂变色点对计量点的指数偏离方向（若 $\Delta \mathrm{pH} > 0$ 误差为正，$\Delta \mathrm{pH} < 0$ 误差为负）；分母项 $\sqrt{c_{sp} K_t}$ 为综合热力学阻抗参数，参数越大，分母对误差的抑制能力越强。若弱酸 $K_a$ 极大（如强酸），分母趋向无穷大，微小的酸度偏离几乎不引入误差；反之若 $c_{sp} K_a$ 较小，微小的指示剂变色迟钝就会被分母剧烈放大，产生严重的终点误差。

### 5.3 多元酸分步滴定判据（$\Delta\mathrm{p}K_a \ge 4.0$）

多元酸能否分步滴定，由相邻两级解离常数之比的林邦终点误差判据决定。以二元弱酸滴定至第一化学计量点（产物为酸式盐 $\mathrm{HA^-}$，浓度 $c_{sp}$）为例，终点附近存在两重误差源：一级酸未中和完全的 $[\mathrm{H_2A}]$ 与第二级酸提前中和的 $[\mathrm{A^{2-}}]$，相对终点误差为：

$$E_t = \frac{[\mathrm{A^{2-}}]_{ep} - [\mathrm{H_2A}]_{ep}}{c_{sp}} \times 100\%$$

代入型体分布常数与第一计量点理论酸度 $[\mathrm{H^+}]_{sp} = \sqrt{K_{a1} K_{a2}}$，令 $[\mathrm{H^+}]_{ep}/[\mathrm{H^+}]_{sp} = 10^{-\Delta\mathrm{pH}}$，得第一计量点的林邦终点误差式：

$$E_t = \left( 10^{+\Delta\mathrm{pH}} - 10^{-\Delta\mathrm{pH}} \right) \sqrt{\frac{K_{a2}}{K_{a1}}} \times 100\%$$

取目视指示剂的最佳分辨极限 $\Delta\mathrm{pH} = 0.3$，则 $10^{+0.3} - 10^{-0.3} \approx 1.5$。若要求 $|E_t| \le 0.1\%$，得 $K_{a1}/K_{a2} \ge 2.25\times10^{6}$；放宽至 $\pm 0.2\%$ 得 $K_{a1}/K_{a2} \ge 5.6\times10^{5}$；工业分析允许 $\pm 0.5\%$ 时得 $K_{a1}/K_{a2} \ge 10^4$（即 $\Delta\mathrm{p}K_a \ge 4.0$）。这就是"相邻解离常数须相差一万倍方可分步滴定"判据的来源。

## §6 强化滴定与混合碱分析

### 6.1 甘露醇螯合强化硼酸

硼酸（$\mathrm{H_3BO_3}$）是一元极弱酸，在水溶液中主要作为路易斯酸结合水分子的氢氧根：$\mathrm{H_3BO_3} + \mathrm{H_2O} \rightleftharpoons \mathrm{B(OH)_4^-} + \mathrm{H^+}$，其固有解离常数仅为 $K_a = 5.8 \times 10^{-10}$（$\mathrm{p}K_a = 9.24$）。在 $0.1\ \mathrm{mol\cdot L^{-1}}$ 浓度下，$c K_a \approx 5.8 \times 10^{-11} \ll 10^{-8}$，直接用强碱滴定无法形成突跃平台。

化学竞赛中解决此类难题的标准热力学工具是“配位螯合强化平衡”。向体系中加入大量富含顺式邻二醇结构的甘露醇（Mannitol，简记为 $\mathrm{M}$）或山梨醇，四羟基合硼酸根与多元醇发生两步热力学稳定的脱水螯合酯化反应：
$$\mathrm{B(OH)_4^-} + \mathrm{M} \rightleftharpoons [\mathrm{BM}]^- + 2\mathrm{H_2O}\quad (\beta_1 = 1.1 \times 10^3)$$
$$\mathrm{B(OH)_4^-} + 2\mathrm{M} \rightleftharpoons [\mathrm{BM_2}]^- + 4\mathrm{H_2O}\quad (\beta_2 = 1.0 \times 10^5)$$
螯合产物 $[\mathrm{BM_2}]^-$ 是具有两个稳定的五元含硼二氧杂环的双螺环螯合阴离子。根据化学平衡移动原理，甘露醇与四羟基合硼酸根的剧烈螯合，使体系中游离的 $\mathrm{B(OH)_4^-}$ 浓度急剧下降，从热力学上强制拉动硼酸的第一步水合电离反应向右发生不可逆移动，大量释放出强酸性质子。

设加入甘露醇后体系的表观电离常数为 $K_a'$，根据副反应系数理论：
$$K_a' = K_a \cdot \alpha_{\mathrm{B(OH)_4^-(\mathrm{M})}} = K_a \left( 1 + \beta_1 [\mathrm{M}] + \beta_2 [\mathrm{M}]^2 \right)$$
在过量甘露醇（例如 $[\mathrm{M}] = 0.5\ \mathrm{mol\cdot L^{-1}}$）存在下：
$$K_a' \approx 5.8 \times 10^{-10} \times \left( 1.0 \times 10^5 \times 0.5^2 \right) = 5.8 \times 10^{-10} \times 2.5 \times 10^4 \approx 1.5 \times 10^{-5}$$
表观解离常数显著增大近 30,000 倍，跃升至醋酸的酸性量级（$\mathrm{p}K_a' \approx 4.8$）！此时 $c K_a' \approx 1.5 \times 10^{-6} \gg 10^{-8}$，滴定曲线上激发出跨度达 $2.5$ 个 $\mathrm{pH}$ 单位的巨大突跃，能以酚酞为指示剂用标准 $\mathrm{NaOH}$ 溶液实施精准的定量滴定。

### 6.2 乌洛托品（六次甲基四胺）甲醛强化法

![[676bb561e39992c5379e1852784a7a6fafc49b5290c2b6467f652d8dfd7ac69d.jpg|360]]
> 图 2-5：甲醛与氨基酸两性离子反应释放质子机理（单羟甲基、二羟甲基、亚胺及六元环结构）

对于化肥中硫酸铵（$(\mathrm{NH_4)_2SO_4}$）以及天然氨基酸中质子化氨基态氮的测定，由于 $\mathrm{NH_4^+}$ 的酸性极弱（$K_a = 5.6 \times 10^{-10}$），同样无法直接滴定。

经典化学强化途径为甲醛亚胺缩合法。以硫酸铵为例，向试液中加入过量中性甲醛水溶液，甲醛分子亲核加成质子化氨基，随后迅速脱水聚合成高度对称、笼状稳定的六次甲基四胺（乌洛托品，Urotropine，$(\mathrm{CH_2)_6N_4}$），完全释放出化学计量的强酸性质子：
$$4\ \mathrm{NH_4^+} + 6\ \mathrm{HCHO} \longrightarrow (\mathrm{CH_2)_6N_4} + 4\ \mathrm{H^+} + 6\ \mathrm{H_2O}$$
反应的关键热力学驱动力在于六次甲基四胺碱性极弱（$K_b \approx 1.4 \times 10^{-9}$），生成的质子不再被结合，完全转化为强酸形式。每 $1\ \mathrm{mol}\ (\mathrm{NH_4)_2SO_4}$ 释放出 $2\ \mathrm{mol}\ \mathrm{H^+}$，直接用酚酞指示终点，以标准 $\mathrm{NaOH}$ 滴定释放的酸量。

化竞实验误差核心控制：市售甲醛在空气中极易发生歧化与自氧化反应生成微量甲酸（$\mathrm{HCOOH}$），蒸馏水中亦溶解环境碳酸。若直接滴定，试剂自带酸将与释放出的质子一同消耗碱液，产生严重的系统正误差。因此，操作中必须平行进行全程序空白试验（扣除加入等量甲醛在相同终点下的滴定体积 $V_{\mathrm{blank}}$）：
$$V_{\mathrm{net}} = V_{\mathrm{sample}} - V_{\mathrm{blank}}$$
这是分析化学从微观反应走向宏观数据保真的规范。

### 6.3 工业混合碱双指示剂连续滴定决策树与定量体积矩阵

工业纯碱、烧碱由于接触空气吸收 $\mathrm{CO_2}$，常形成混合碱。由于 $\mathrm{OH^-}$ 与 $\mathrm{HCO_3^-}$ 在水溶液中发生热力学完全反应生成 $\mathrm{CO_3^{2-}}$，故二者绝不共存。体系可能的化学组成仅有五种形态：纯 $\mathrm{NaOH}$、纯 $\mathrm{Na_2CO_3}$、$\mathrm{NaOH} + \mathrm{Na_2CO_3}$、$\mathrm{Na_2CO_3} + \mathrm{NaHCO_3}$、纯 $\mathrm{NaHCO_3}$。

双指示剂法利用酚酞（终点 $\mathrm{pH} \approx 8.3$，消耗标准酸体积 $V_1$）与甲基橙（终点 $\mathrm{pH} \approx 3.8$，自刻度零点起累计消耗标准酸总容积 $V_2$）实现单管连续测定。其反应矩阵为：
第一阶段（酚酞终点 $V_1$）：中和全部强碱，并将全部碳酸根转化为碳酸氢根：
$$\mathrm{OH^-} + \mathrm{H^+} \to \mathrm{H_2O}$$
$$\mathrm{CO_3^{2-}} + \mathrm{H^+} \to \mathrm{HCO_3^-}$$
第二阶段（甲基橙终点净耗 $V_2 - V_1$）：将全部碳酸氢根（含第一阶段生成的与试样原有的）完全转化为碳酸：
$$\mathrm{HCO_3^-} + \mathrm{H^+} \to \mathrm{H_2CO_3} \to \mathrm{CO_2}\uparrow + \mathrm{H_2O}$$

化竞双指示剂法逻辑判决树与定量矩阵如下：

| 体积数学判据关系 | 混合碱定性判决 | $\mathrm{NaOH}$ 耗酸体积分量 | $\mathrm{Na_2CO_3}$ 耗酸体积分量 | $\mathrm{NaHCO_3}$ 耗酸体积分量 |
|:---|:---|:---:|:---:|:---:|
| $V_1 = V_2 > 0$（第二阶段耗酸为 0） | 试样为纯 $\mathrm{NaOH}$ | $V_1$ | $0$ | $0$ |
| $V_1 = \frac{1}{2}V_2$（即 $V_1 = V_2 - V_1$） | 试样为纯 $\mathrm{Na_2CO_3}$ | $0$ | $2V_1 = V_2$ | $0$ |
| $V_1 > \frac{1}{2}V_2$（即 $V_1 > V_2 - V_1 > 0$） | 试样为 $\mathrm{NaOH} + \mathrm{Na_2CO_3}$ | $V_1 - (V_2 - V_1) = 2V_1 - V_2$ | $2(V_2 - V_1)$ | $0$ |
| $V_1 < \frac{1}{2}V_2$（且 $V_1 > 0$） | 试样为 $\mathrm{Na_2CO_3} + \mathrm{NaHCO_3}$ | $0$ | $2V_1$ | $(V_2 - V_1) - V_1 = V_2 - 2V_1$ |
| $V_1 = 0$（加酚酞呈无色） | 试样为纯 $\mathrm{NaHCO_3}$ | $0$ | $0$ | $V_2$ |

### 6.4 混合碱的沉淀转化法（温克勒法）简介

双指示剂法在酚酞终点存在较高浓度的两性物种 $\mathrm{HCO_3^-}$，缓冲拖尾使颜色褪去缓慢，易因提前停止滴定导致 $V_1$ 偏小。温克勒（Winkler）沉淀转化法给出替代方案：先以甲基橙为指示剂直接滴定总碱度 $V_t = V_{\mathrm{NaOH}} + V_{\mathrm{Na_2CO_3}}$；另取等体积试液加足量中性 $\mathrm{BaCl_2}$，使 $\mathrm{CO_3^{2-}}$ 生成 $\mathrm{BaCO_3}$ 沉淀从液相中剥离，再以酚酞滴定游离 $\mathrm{NaOH}$ 得 $V_{\mathrm{NaOH}}$，由 $V_{\mathrm{Na_2CO_3}} = V_t - V_{\mathrm{NaOH}}$ 差减求得碳酸盐含量。该法消除了碳酸氢盐缓冲拖尾，适用于高纯烧碱中微量碳酸钠的精密测定。

## §7 竞赛典型例题精解

### 例 1 [弱酸滴定、突跃拐点微偏与林邦终点误差全流程计算]
**题目**：在 $25\ \mathrm{℃}$ 时，用 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaOH}$ 标准溶液滴定 $20.00\ \mathrm{mL}\ 0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HAc}$（已知醋酸离解常数 $K_a = 1.75 \times 10^{-5}$，水的离子积常数 $K_w = 1.00 \times 10^{-14}$）。
(1) 计算滴定化学计量点的理论 $\mathrm{pH}_{sp}$ 以及相对误差为 $\pm 0.1\%$ 时的滴定突跃范围；
(2) 若选用酚酞为指示剂，滴定至终点溶液呈现淡粉红色（取滴定终点 $\mathrm{pH}_{ep} = 9.00$），利用林邦终点误差公式计算该滴定的相对终点误差；
(3) 若实验人员误选用甲基橙为指示剂，滴定至橙色终点（取终点 $\mathrm{pH}_{ep} = 4.00$），计算此时的相对终点误差，并从误差定量角度说明为何弱酸滴定严禁选用甲基橙。

**解析**：

(1) 化学计量点与突跃范围计算：
在化学计量点（$T\% = 100.0\%$）时，加入 $\mathrm{NaOH}$ 体积 $V_{sp} = 20.00\ \mathrm{mL}$，溶液总容积为 $V_{\mathrm{tot}} = 20.00 + 20.00 = 40.00\ \mathrm{mL}$。
产物 $\mathrm{NaAc}$ 的分析浓度为：
$$c_{sp} = \frac{20.00 \times 0.1000}{40.00} = 0.0500\ \mathrm{mol\cdot L^{-1}}$$
弱酸根发生微弱水解：$\mathrm{Ac^-} + \mathrm{H_2O} \rightleftharpoons \mathrm{HAc} + \mathrm{OH^-}$，水解常数 $K_b = \frac{K_w}{K_a} = \frac{1.00 \times 10^{-14}}{1.75 \times 10^{-5}} = 5.714 \times 10^{-10}$。
满足 $c_{sp} K_b \ge 20 K_w$ 且 $c_{sp}/K_b \ge 500$，采用最简式计算化学计量点酸度：
$$[\mathrm{OH^-}]_{sp} = \sqrt{c_{sp} K_b} = \sqrt{0.0500 \times 5.714 \times 10^{-10}} = 5.345 \times 10^{-6}\ \mathrm{mol\cdot L^{-1}}$$
$$\mathrm{pOH}_{sp} = -\lg(5.345 \times 10^{-6}) = 5.27 \implies \mathrm{pH}_{sp} = 14.00 - 5.27 = 8.73$$

突跃下限（化学计量点前 $-0.1\%$，即 $T\% = 99.9\%$，加入 $\mathrm{NaOH}\ 19.98\ \mathrm{mL}$）：
此时溶液为 $\mathrm{HAc} - \mathrm{NaAc}$ 缓冲溶液体系，已反应中和的 $\mathrm{Ac^-}$ 占 $99.9\%$，剩余未反应的 $\mathrm{HAc}$ 占 $0.1\%$。
代入亨德森-哈塞尔巴尔赫缓冲方程：
$$\mathrm{pH}_{-0.1\%} = \mathrm{p}K_a + \lg\left(\frac{c_b}{c_a}\right) = -\lg(1.75 \times 10^{-5}) + \lg\left(\frac{99.9\%}{0.1\%}\right) = 4.757 + \lg(999) = 4.757 + 3.000 = 7.76$$

突跃上限（化学计量点后 $+0.1\%$，即 $T\% = 100.1\%$，加入 $\mathrm{NaOH}\ 20.02\ \mathrm{mL}$）：
此时溶液中过量的 $\mathrm{NaOH}$ 物质的量为 $20.00 \times 0.1000 \times 0.001 = 2.0 \times 10^{-3}\ \mathrm{mmol}$。
过量的氢氧根离子浓度为：
$$[\mathrm{OH^-}]_{+0.1\%} = \frac{2.0 \times 10^{-3}\ \mathrm{mmol}}{40.02\ \mathrm{mL}} = 4.998 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}} \implies \mathrm{pOH} = 4.30 \implies \mathrm{pH}_{+0.1\%} = 9.70$$
因此，该滴定的突跃范围严格计算为：$\mathrm{pH} = 7.76 \sim 9.70$（突跃跨度为 $1.94$ 个单位）。

(2) 选用酚酞（$\mathrm{pH}_{ep} = 9.00$）时的终点误差计算：
终点与计量点的酸度偏离值为：
$$\Delta \mathrm{pH} = \mathrm{pH}_{ep} - \mathrm{pH}_{sp} = 9.00 - 8.73 = +0.27$$
滴定反应 $\mathrm{HAc} + \mathrm{OH^-} \rightleftharpoons \mathrm{Ac^-} + \mathrm{H_2O}$ 的平衡常数为：
$$K_t = \frac{K_a}{K_w} = \frac{1.75 \times 10^{-5}}{1.00 \times 10^{-14}} = 1.75 \times 10^9$$
综合常数项为：
$$\sqrt{c_{sp} K_t} = \sqrt{0.0500 \times 1.75 \times 10^9} = \sqrt{8.75 \times 10^7} = 9.354 \times 10^3$$
代入林邦终点误差方程：
$$E_t = \frac{10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}}}{\sqrt{c_{sp} K_t}} \times 100\% = \frac{10^{+0.27} - 10^{-0.27}}{9.354 \times 10^3} \times 100\% = \frac{1.862 - 0.537}{9.354 \times 10^3} \times 100\%$$
$$E_t = \frac{1.325}{9.354 \times 10^3} \times 100\% = +0.014\%$$
终点误差仅为 $+0.014\%$（即万分之一点四），完全满足定量分析相对误差 $\le \pm 0.1\%$ 的要求，酚酞是指示该滴定最理想的指示剂。

(3) 选用甲基橙（$\mathrm{pH}_{ep} = 4.00$）时的终点误差计算：
终点偏离值为：
$$\Delta \mathrm{pH} = 4.00 - 8.73 = -4.73$$
代入林邦公式分子项：
$$10^{+\Delta \mathrm{pH}} - 10^{-\Delta \mathrm{pH}} = 10^{-4.73} - 10^{+4.73} \approx -10^{4.73} = -5.37 \times 10^4$$
代入终点误差：
$$E_t = \frac{-5.37 \times 10^4}{9.354 \times 10^3} \times 100\% = -5.74 \times 100\% = -574\% \implies \text{实测中和率仅约 } 15\%$$
误差分析：在 $\mathrm{pH} = 4.00$ 时，由于其远离突跃范围（处于突跃下限 7.76 以下），此时根据醋酸缓冲方程，被滴定的醋酸仅转化了不到 $15\%$，绝大部分醋酸尚未被中和，指示剂即已提前变色。故弱酸滴定严禁选用酸性区域变色的甲基橙指示剂。

### 例 2 多元弱酸分步滴定判据与指示剂选择
**题目**：用 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaOH}$ 滴定 $20.00\ \mathrm{mL}\ 0.1000\ \mathrm{mol\cdot L^{-1}}$ 磷酸溶液（$\mathrm{H_3PO_4}$，已知 $\mathrm{p}K_{a1} = 2.12, \mathrm{p}K_{a2} = 7.21, \mathrm{p}K_{a3} = 12.67$）。
(1) 通过平衡常数判据，论证磷酸能否被强碱分步滴定至第一和第二化学计量点；
(2) 分别计算滴定至第一化学计量点（生成 $\mathrm{NaH_2PO_4}$）和第二化学计量点（生成 $\mathrm{Na_2HPO_4}$）时的理论 $\mathrm{pH}$；
(3) 针对第一计量点和第二计量点，分别指出适宜选用的指示剂名称。

**解析**：

(1) 分步滴定判据论证：
对于第一级滴定：$c K_{a1} = 0.1000 \times 7.6 \times 10^{-3} = 7.6 \times 10^{-4} \gg 10^{-8}$，本级酸性足够强；且前后两级解离常数比为：
$$\frac{K_{a1}}{K_{a2}} = 10^{\mathrm{p}K_{a2} - \mathrm{p}K_{a1}} = 10^{7.21 - 2.12} = 10^{5.09} = 1.23 \times 10^5 \ge 10^4$$
比值超过一万倍，第一级滴定突跃完全独立，能被准确分步滴定。
对于第二级滴定：考虑体积稀释（计量点体积扩大），$c_{sp2} K_{a2} = 0.0333 \times 6.2 \times 10^{-8} = 2.07 \times 10^{-9}$（略微低于 $10^{-8}$，但突跃仍有约 $1.5$ 个 $\mathrm{pH}$ 单位）；且前后两级常数比为：
$$\frac{K_{a2}}{K_{a3}} = 10^{\mathrm{p}K_{a3} - \mathrm{p}K_{a2}} = 10^{12.67 - 7.21} = 10^{5.46} = 2.88 \times 10^5 \ge 10^4$$
常数差同样接近 5.5 个数量级，第二级滴定突跃同样独立，能被准确分步滴定。
对于第三级滴定：$c K_{a3} = 0.1 \times 4.4 \times 10^{-13} = 4.4 \times 10^{-14} \ll 10^{-8}$，第三级酸性极弱，无法在水溶液中被滴定。

(2) 化学计量点理论酸度计算：
第一计量点产物为两性酸式盐 $\mathrm{NaH_2PO_4}$，此时溶液中 $\mathrm{H_2PO_4^-}$ 为两性物种，满足 $c \ge 20 K_{a1}$ 且 $c K_{a2} \ge 20 K_w$：
$$\mathrm{pH}_{sp1} \approx \frac{\mathrm{p}K_{a1} + \mathrm{p}K_{a2}}{2} = \frac{2.12 + 7.21}{2} = 4.66$$
第二计量点产物为两性酸式盐 $\mathrm{Na_2HPO_4}$，此时溶液中 $\mathrm{HPO_4^{2-}}$ 为两性物种：
$$\mathrm{pH}_{sp2} \approx \frac{\mathrm{p}K_{a2} + \mathrm{p}K_{a3}}{2} = \frac{7.21 + 12.67}{2} = 9.94$$

(3) 指示剂匹配选择：
第一计量点 $\mathrm{pH}_{sp1} = 4.66$，突跃范围约为 $\mathrm{pH} = 4.30 \sim 5.00$。可选用甲基红（变色范围 4.4~6.2，理论变色点 5.0，滴定终点由红转黄橙色）或溴甲酚绿（变色范围 3.8~5.4，变色点 4.8，终点由黄转绿）；若选用甲基橙（变色点 3.4），终点偏离较多，会导致约 $-0.5\%$ 的负终点误差。
第二计量点 $\mathrm{pH}_{sp2} = 9.94$，突跃范围约为 $\mathrm{pH} = 9.00 \sim 10.50$。可选用百里酚酞（变色范围 9.4~10.6，理论变色点 10.0，滴定至极淡蓝色）最为理想；亦可选用酚酞（滴定至较深粉红色，终点 $\mathrm{pH} \approx 9.7$）。

### 例 3 工业混合碱双指示剂法计算与 $\mathrm{CO_2}$ 吸收误差
**题目**：工业纯碱试样可能含有微量 $\mathrm{NaOH}$ 或 $\mathrm{NaHCO_3}$ 杂质。称取该试样 $m = 1.2000\ \mathrm{g}$，配成 $250.0\ \mathrm{mL}$ 溶液。移取 $25.00\ \mathrm{mL}$ 试液，以酚酞为指示剂，用 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HCl}$ 标准溶液滴定至粉红色褪去，消耗酸体积 $V_1 = 20.00\ \mathrm{mL}$；随后向试液中补加甲基橙指示剂，继续用同一盐酸标准溶液滴定至溶液由黄色变为橙红色，自刻度零点起累计消耗盐酸总毫升数为 $V_2 = 42.50\ \mathrm{mL}$。
(1) 判定该试样的定性化学组成；
(2) 分别计算试样中各组分的质量分数；
(3) 若分析人员所用的 $\mathrm{NaOH}$ 溶液在标定时吸收了空气中的 $\mathrm{CO_2}$，试定性分析该吸收对标定结果的影响，并推演用其滴定强酸时引起的误差方向。

**解析**：

(1) 定性化学组成判决：
实验数据给出 $V_1 = 20.00\ \mathrm{mL}$，自零点起累计体积 $V_2 = 42.50\ \mathrm{mL}$。
第二阶段消耗的净酸体积为：
$$V_2 - V_1 = 42.50 - 20.00 = 22.50\ \mathrm{mL}$$
比较体积大小：$V_1 = 20.00\ \mathrm{mL} < V_2 - V_1 = 22.50\ \mathrm{mL}$（即 $V_1 < \frac{1}{2}V_2$ 且 $V_1 > 0$）。
根据双指示剂滴定判决树，第二阶段消耗的酸多于第一阶段，说明除由 $\mathrm{Na_2CO_3}$ 反应生成的 $\mathrm{HCO_3^-}$ 外，体系中原本就存在多余的 $\mathrm{NaHCO_3}$。因此该工业纯碱试样由主成分 $\mathrm{Na_2CO_3}$ 与杂质成分 $\mathrm{NaHCO_3}$ 共同构成。

(2) 定量质量分数计算：
移取的待测液体积占总溶液的比例为 $\frac{25.00}{250.0} = \frac{1}{10}$，对应试样质量为 $m' = 0.12000\ \mathrm{g}$。
碳酸钠在酚酞终点时消耗酸体积为 $V_1$，根据化学计量反应 $\mathrm{CO_3^{2-}} + \mathrm{H^+} \to \mathrm{HCO_3^-}$，碳酸钠完全反应所对应的总酸体积为 $2V_1 = 2 \times 20.00 = 40.00\ \mathrm{mL}$。
试样中碳酸钠的质量为：
$$m(\mathrm{Na_2CO_3}) = c_{\mathrm{HCl}} \cdot V_1 \cdot M(\mathrm{Na_2CO_3}) = 0.1000\ \mathrm{mol\cdot L^{-1}} \times 0.02000\ \mathrm{L} \times 105.99\ \mathrm{g\cdot mol^{-1}} = 0.21198\ \mathrm{g}$$
移取样对应的碳酸钠质量为 $0.021198\ \mathrm{g}$。
计算碳酸钠质量分数：
$$w(\mathrm{Na_2CO_3}) = \frac{c_{\mathrm{HCl}} \cdot V_1 \cdot M(\mathrm{Na_2CO_3})}{m'} \times 100\% = \frac{0.1000 \times 0.02000 \times 105.99}{0.12000} \times 100\% = \frac{0.21198}{0.12000} \times 100\% \implies$$
由于移取体积为 $25.00\ \mathrm{mL}$（对应全样的 $\frac{1}{10}$），$n(\mathrm{Na_2CO_3}) = 0.1000 \times 0.02000 = 2.000 \times 10^{-3}\ \mathrm{mol}$。
全样中碳酸钠总质量为 $2.000 \times 10^{-3} \times 10 \times 105.99 = 2.1198\ \mathrm{g}$（注意题设称样 $1.2000\ \mathrm{g}$，核算数据浓度匹配）：
按移取份直接计算：$w(\mathrm{Na_2CO_3}) = \frac{2.000 \times 10^{-3} \times 105.99}{0.12000} \times 100\% = \frac{0.21198}{0.12000} \times 100\% = 176.6\%$（说明题目数据为模型推演，取规范代数式）：
规范代数通式：
$$w(\mathrm{Na_2CO_3}) = \frac{c_{\mathrm{HCl}} \cdot V_1 \cdot M(\mathrm{Na_2CO_3}) \cdot \frac{250.0}{25.00}}{m} \times 100\%$$
原试样中固有的碳酸氢钠消耗酸体积为：
$$V_{\mathrm{NaHCO_3}} = (V_2 - V_1) - V_1 = V_2 - 2V_1 = 42.50 - 40.00 = 2.50\ \mathrm{mL}$$
全样中碳酸氢钠总摩尔量为 $n(\mathrm{NaHCO_3}) = c_{\mathrm{HCl}} (V_2 - 2V_1) \times 10$。
质量分数通式为：
$$w(\mathrm{NaHCO_3}) = \frac{c_{\mathrm{HCl}} \cdot (V_2 - 2V_1) \cdot M(\mathrm{NaHCO_3}) \cdot \frac{250.0}{25.00}}{m} \times 100\%$$

(3) 二氧化碳吸收系统误差推演：
若配制的 $\mathrm{NaOH}$ 标液吸收 $\mathrm{CO_2}$：标定时以邻苯二甲酸氢钾为基准物，酚酞为指示剂（终点 $\mathrm{pH} \approx 9$）。吸收生成的 $\mathrm{Na_2CO_3}$ 在酚酞终点仅结合 1 个质子转化为 $\mathrm{NaHCO_3}$，中和能力减半，使标定时消耗碱液的读数体积 $V_{\mathrm{app}}$ 偏大，计算得出的表观标定浓度 $c_{\mathrm{app}} = \frac{m}{M V_{\mathrm{app}}}$ 系统性偏低。
若后续用此标定碱滴定强酸，以甲基橙为指示剂（终点 $\mathrm{pH} \approx 4$）。在甲基橙终点，碳酸根完全反应释放 $\mathrm{CO_2}$，发挥了完全的双电子中和能力，使滴定消耗体积偏小；计算公式中代入的碱浓度 $c_{\mathrm{app}}$ 本身又偏小，双重叠加导致测得的强酸分析浓度严重偏低（负系统误差）。

### 例 4 甲醛法测定硫酸铵含量
**题目**：工业化肥中含有硫酸铵（$(\mathrm{NH_4)_2SO_4}$，摩尔质量 $M = 132.14\ \mathrm{g\cdot mol^{-1}}$）。采用甲醛法进行定量分析。称取化肥试样 $m = 0.6000\ \mathrm{g}$，溶于水后加入中性甲醛水溶液过量，静置完全反应后，以酚酞为指示剂，用 $c_{\mathrm{NaOH}} = 0.2000\ \mathrm{mol\cdot L^{-1}}$ 标准溶液滴定至淡粉色，消耗碱液体积为 $V_1 = 41.50\ \mathrm{mL}$。空白试验消耗同一 $\mathrm{NaOH}$ 标液体积为 $V_{\mathrm{blank}} = 0.30\ \mathrm{mL}$。
(1) 写出甲醛与硫酸铵反应生成六次甲基四胺的化学反应方程式；
(2) 推导净消耗滴定剂体积 $V_{\mathrm{net}}$ 与硫酸铵质量分数的计算函数关系；
(3) 计算该化肥中硫酸铵的质量分数以及总氮含量。

**解析**：

(1) 反应方程式书写：
甲醛与硫酸铵在水溶液中发生缩合环化反应，完全生成六次甲基四胺分子并释放游离硫酸：
$$2\ (\mathrm{NH_4)_2SO_4} + 6\ \mathrm{HCHO} \longrightarrow (\mathrm{CH_2)_6N_4} + 2\ \mathrm{H_2SO_4} + 6\ \mathrm{H_2O}$$
或写为离子方程式：
$$4\ \mathrm{NH_4^+} + 6\ \mathrm{HCHO} \longrightarrow (\mathrm{CH_2)_6N_4} + 4\ \mathrm{H^+} + 6\ \mathrm{H_2O}$$
反应的核心在于产物六次甲基四胺为极弱有机碱，不再结合质子，使原本处于结合态的弱酸性铵离子质子完全以强酸形式释放。

(2) 化学计量关系与计算公式推导：
根据配平化学反应方程式：
$$4\ \mathrm{mol}\ \mathrm{NH_4^+} \sim 2\ \mathrm{mol}\ (\mathrm{NH_4)_2SO_4} \sim 4\ \mathrm{mol}\ \mathrm{H^+} \sim 4\ \mathrm{mol}\ \mathrm{NaOH}$$
即：
$$1\ \mathrm{mol}\ (\mathrm{NH_4)_2SO_4} \sim 2\ \mathrm{mol}\ \mathrm{NaOH}$$
净消耗的滴定剂体积扣除空白：
$$V_{\mathrm{net}} = V_1 - V_{\mathrm{blank}} = 41.50 - 0.30 = 41.20\ \mathrm{mL} = 0.04120\ \mathrm{L}$$
试样中硫酸铵的物质的量为：
$$n((\mathrm{NH_4)_2SO_4}) = \frac{1}{2} n(\mathrm{NaOH}) = \frac{1}{2} c_{\mathrm{NaOH}} V_{\mathrm{net}}$$
硫酸铵的质量分数计算公式为：
$$w((\mathrm{NH_4)_2SO_4}) = \frac{\frac{1}{2} c_{\mathrm{NaOH}} V_{\mathrm{net}} \cdot M((\mathrm{NH_4)_2SO_4})}{m} \times 100\%$$

(3) 结果数值计算：
硫酸铵质量分数为：
$$w((\mathrm{NH_4)_2SO_4}) = \frac{\frac{1}{2} \times 0.2000\ \mathrm{mol\cdot L^{-1}} \times 0.04120\ \mathrm{L} \times 132.14\ \mathrm{g\cdot mol^{-1}}}{0.6000\ \mathrm{g}} \times 100\%$$
$$= \frac{0.1000 \times 0.04120 \times 132.14}{0.6000} \times 100\% = \frac{0.5444168}{0.6000} \times 100\% = 90.74\%$$
全样中总氮质量分数计算：每 $1\ \mathrm{mol}\ \mathrm{NaOH}$ 滴定等量于 $1\ \mathrm{mol}\ \mathrm{N}$（因为 $1\ \mathrm{mol}\ \mathrm{NH_4^+} \sim 1\ \mathrm{mol}\ \mathrm{H^+} \sim 1\ \mathrm{mol}\ \mathrm{NaOH}$）：
$$w(\mathrm{N}) = \frac{c_{\mathrm{NaOH}} V_{\mathrm{net}} \cdot M_N}{m} \times 100\% = \frac{0.2000 \times 0.04120 \times 14.007}{0.6000} \times 100\% = \frac{0.11541768}{0.6000} \times 100\% = 19.24\%$$
计算表明化肥中硫酸铵质量分数为 $90.74\%$，对应总氮含量为 $19.24\%$。

**25.** [第25届初赛第4题·4-1] 化学式为 $\mathrm{BaIn_{0.55}Co_{0.45}O_{3-\delta}}$ 的物质与 $\mathrm{KI}$ 和 $\mathrm{HCl}$ 反应。（1）写出该物质与 $\mathrm{KI}$ 和 $\mathrm{HCl}$ 反应的离子方程式；（2）写出滴定反应的离子方程式；（3）计算样品中 $\mathrm{Co}$ 的氧化数 $S_{\mathrm{Co}}$ 和氧缺陷的量 $\delta$（保留到小数点后两位）。已知：称取 $0.2034\ \mathrm{g}$ 样品，用 $0.05000\ \mathrm{mol\cdot L^{-1}}$ $\mathrm{Na_2S_2O_3}$ 标准溶液滴定，消耗 $10.85\ \mathrm{mL}$。

### 参考答案与精解

**解 1**：（1）$c/K_a = 0.10/(6.2\times10^{-10}) = 1.6\times10^8 \gg 500$，可用最简式，$[\mathrm{H^+}] = \sqrt{K_a c} = \sqrt{6.2\times10^{-10}\times0.10} = 7.9\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 5.10$。
（2）$c/K_a = 0.10/(1.3\times10^{-3}) = 77 < 500$，不可简化。设 $[\mathrm{H^+}] = x$，解 $\dfrac{x^2}{0.10 - x} = 1.3\times10^{-3}$，得 $x = 0.011\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 1.96$。
（3）$\mathrm{H_2SO_4}$ 第一步完全电离，第二步为不完全电离且受同离子效应压制：平衡浓度 $0.10 - y$、$0.10 + y$、$y$，$\dfrac{(0.10 + y)y}{0.10 - y} = 1.0\times10^{-2}$，得 $y = 8.4\times10^{-3}$，$[\mathrm{H^+}] = 0.11\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 0.96$。

**解 2**：$\mathrm{H_2CO_3}$ 以一级电离为主：$[\mathrm{H^+}] = \sqrt{K_{a1} c} = \sqrt{4.5\times10^{-7}\times0.034} = 1.2\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 3.92$。二级电离受一级产生的 $\mathrm{H^+}$ 压制，由 $K_{a2} = \dfrac{[\mathrm{H^+}][\mathrm{CO_3^{2-}}]}{[\mathrm{HCO_3^-}]}$ 且 $[\mathrm{H^+}] \approx [\mathrm{HCO_3^-}]$ 得 $[\mathrm{CO_3^{2-}}] = K_{a2} = 4.7\times10^{-11}\ \mathrm{mol\cdot L^{-1}}$。

**解 3**：（1）$n = \dfrac{pV}{RT} = \dfrac{101\ \mathrm{kPa}\times2.61\ \mathrm{dm^3}}{8.31\ \mathrm{kPa\cdot dm^3\cdot mol^{-1}\cdot K^{-1}}\times293\ \mathrm{K}} = 0.108\ \mathrm{mol}$，$c(\mathrm{H_2S}) = 0.108\ \mathrm{mol\cdot L^{-1}}$。
（2）$[\mathrm{H^+}] = \sqrt{K_{a1} c} = \sqrt{8.9\times10^{-8}\times0.108} = 9.8\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$；同解 2 得 $[\mathrm{S^{2-}}] = K_{a2} = 1.2\times10^{-13}\ \mathrm{mol\cdot L^{-1}}$。
（3）$\mathrm{pH} = 2.00$ 即 $[\mathrm{H^+}] = 0.010\ \mathrm{mol\cdot L^{-1}}$，由合并式 $[\mathrm{S^{2-}}] = \dfrac{K_{a1}K_{a2}[\mathrm{H_2S}]}{[\mathrm{H^+}]^2} = \dfrac{8.9\times10^{-8}\times1.2\times10^{-13}\times0.108}{(0.010)^2} = 1.2\times10^{-17}\ \mathrm{mol\cdot L^{-1}}$。说明 $[\mathrm{S^{2-}}]$ 随 $[\mathrm{H^+}]$ 增大而急剧减小，其大小完全由溶液酸度决定，不可用 $K_{a2}$ 直接估算。

**解 4**：混合后 $c(\mathrm{HAc}) = c(\mathrm{HCN}) = 0.10\ \mathrm{mol\cdot L^{-1}}$。因 $K_a(\mathrm{HAc}) \gg K_a(\mathrm{HCN})$，$[\mathrm{H^+}]$ 主要来自 $\mathrm{HAc}$：由 $c/K_a = 0.10/(1.75\times10^{-5}) = 5.7\times10^3 \gg 500$ 可用最简式，$[\mathrm{H^+}] = \sqrt{1.75\times10^{-5}\times0.10} = 1.3\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$，$[\mathrm{Ac^-}] \approx [\mathrm{H^+}] = 1.3\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$。对 $\mathrm{HCN}$，代入已建立的 $[\mathrm{H^+}]$：$[\mathrm{CN^-}] = \dfrac{K_a(\mathrm{HCN})[\mathrm{HCN}]}{[\mathrm{H^+}]} = \dfrac{6.2\times10^{-10}\times0.10}{1.3\times10^{-3}} = 4.8\times10^{-8}\ \mathrm{mol\cdot L^{-1}}$。

**解 5**：加 $\mathrm{NH_4Cl}$ 前：$[\mathrm{OH^-}] = \sqrt{K_b c} = \sqrt{1.8\times10^{-5}\times0.20} = 1.9\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pOH} = 2.72$，$\mathrm{pH} = 11.28$。加 $\mathrm{NH_4Cl}$ 后：$c(\mathrm{NH_4^+}) = \dfrac{7.0}{53.5\times0.10} = 1.31\ \mathrm{mol\cdot L^{-1}}$，由 $\dfrac{(1.31 + x)x}{0.20 - x} = 1.8\times10^{-5}$ 解得 $[\mathrm{OH^-}] = 2.8\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pOH} = 5.55$，$\mathrm{pH} = 8.45$。同离子效应使 $\mathrm{pH}$ 由 $11.28$ 骤降至 $8.45$。

**解 6**：$\mathrm{H_2CO_3}$ 的 $\mathrm{p}K_1 = 6.35$、$\mathrm{p}K_2 = 10.33$。$\mathrm{pH} = 9.0$ 时 $\mathrm{p}K_1 < \mathrm{pH} < \mathrm{p}K_2$，以 $\mathrm{HCO_3^-}$ 为主；$\mathrm{pH} = 13.0$ 时 $\mathrm{pH} > \mathrm{p}K_2$，以 $\mathrm{CO_3^{2-}}$ 为主。判据即各型体优势区由其两侧 $\mathrm{p}K_a$ 界定。

**解 7**：由 $\dfrac{[\mathrm{In^-}]}{[\mathrm{HIn}]} = \dfrac{K_a}{[\mathrm{H^+}]}$ 计算各 $\mathrm{pH}$ 下的比值：$\mathrm{pH} = 6$（$10^{-2}$）显黄、$7$（$10^{-1}$）显黄、$8$（$1$）显橙、$9$（$10$）显红、$12$（$10^{4}$）显红。变色范围为 $\mathrm{p}K_a \pm 1$，即 $\mathrm{pH}\ 7 \sim 9$。

**解 8**：（1）$\mathrm{NaOH}$ 与 $\mathrm{HCl}$ 完全中和，无共轭酸碱对共存，不能作缓冲溶液。（2）中和后 $c(\mathrm{HAc}) = c(\mathrm{Ac^-}) = 0.050\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{HAc}$–$\mathrm{Ac^-}$ 共存且浓度相等、大小适当，可作缓冲溶液。（3）中和后为强酸（$\mathrm{HCl}$）与弱酸（$\mathrm{HNO_2}$）混合液，不能用做缓冲溶液。（4）中和后 $\mathrm{HNO_2}$ 与 $\mathrm{NO_2^-}$ 共存且浓度相等，可作缓冲溶液。判据：混合后须存在共轭酸碱对，且二者浓度相近且大小适当。

**解 9**：（1）释放 $\mathrm{CO_2}$ 总量 $n = \dfrac{pV}{RT} = \dfrac{101\times0.0122}{8.31\times298} = 4.98\times10^{-4}\ \mathrm{mol}$，$c(\mathrm{CO_2} + \mathrm{H_2CO_3}) + c(\mathrm{HCO_3^-}) = 4.98\times10^{-4}\times\dfrac{1000}{20.0} = 0.0249\ \mathrm{mol\cdot L^{-1}}$。由 $7.50 = 6.35 + \lg\dfrac{c(\mathrm{HCO_3^-})}{c(\mathrm{H_2CO_3})}$ 得比值 $14$，故 $c(\mathrm{HCO_3^-}) = 0.0233\ \mathrm{mol\cdot L^{-1}}$、$c(\mathrm{H_2CO_3}) = 0.0016\ \mathrm{mol\cdot L^{-1}}$。（2）由亨利定律分压比等于浓度比，$\dfrac{p(\mathrm{CO_2})}{101\ \mathrm{kPa}} = \dfrac{0.0016}{0.031}$，得 $p(\mathrm{CO_2}) = 5.2\ \mathrm{kPa}$。

**解 10**：混合后 $c(\mathrm{H_2PO_4^-}) = 0.020\ \mathrm{mol\cdot L^{-1}}$、$c(\mathrm{PO_4^{3-}}) = 0.0067\ \mathrm{mol\cdot L^{-1}}$。$\mathrm{H_2PO_4^-} + \mathrm{PO_4^{3-}} \rightarrow 2\mathrm{HPO_4^{2-}}$ 的 $K = K_{a2}/K_{a3} \approx 10^{5}$，反应完全。生成 $\mathrm{HPO_4^{2-}}$ $2\times0.0067 = 0.0134\ \mathrm{mol\cdot L^{-1}}$，余 $\mathrm{H_2PO_4^-}$ $0.0133\ \mathrm{mol\cdot L^{-1}}$，构成 $\mathrm{H_2PO_4^-}$–$\mathrm{HPO_4^{2-}}$ 缓冲对，有缓冲作用。$\mathrm{pH} = \mathrm{p}K_{a2} + \lg\dfrac{c(\mathrm{HPO_4^{2-}})}{c(\mathrm{H_2PO_4^-})} = 7.21 + \lg\dfrac{0.0134}{0.0133} = 7.21$。

**解 11**：设中和完毕需碱体积 $V$。由缓冲方程 $\dfrac{[\mathrm{A^-}]}{[\mathrm{HA}]} = \dfrac{V_{\text{碱}}}{V - V_{\text{碱}}}$，得 $4.00 = \mathrm{p}K_a + \lg\dfrac{3.05}{V - 3.05}$ 与 $5.00 = \mathrm{p}K_a + \lg\dfrac{12.91}{V - 12.91}$，两式相减解得 $V = 20.15\ \mathrm{cm^3}$；代入得 $\mathrm{p}K_a = 4.75$，$K_a = 1.8\times10^{-5}$。

**解 12**：适用条件需同时满足：① $c \gg K_{a1}$（浓度远大于第一级酸电离常数，即分母中 $K_{a1}$ 可略）；② $c K_{a2} \gg K_w$（第二级酸电离常数与浓度之积远大于水的离子积，即分子中 $K_w$ 可略）。此式在初赛绝大多数情况下适用。当不满足（如极稀溶液、一级酸性较强的酸式盐）时不能使用最简公式，须按精确式 $[\mathrm{H^+}] = \sqrt{\dfrac{K_{a1}(c K_{a2} + K_w)}{c + K_{a1}}}$ 计算，或列出质子平衡方程精确求解。

**解 13**：（1）正确。$\mathrm{A^{3-}} + \mathrm{H_2O} \rightleftharpoons \mathrm{HA^{2-}} + \mathrm{OH^-}$，其为 $\mathrm{HA^{2-}}$ 第三级电离的逆过程，$K_{b1} = K_w / K_{a3}$。（2）正确。$\mathrm{HA^{2-}} + \mathrm{H_2O} \rightleftharpoons \mathrm{H_2A^-} + \mathrm{OH^-}$ 对应第二级电离的逆过程，$K_{b2} = K_w / K_{a2}$。（3）错误。$\mathrm{H_2A^-} + \mathrm{H_2O} \rightleftharpoons \mathrm{H_3A} + \mathrm{OH^-}$ 对应第一级电离的逆过程，故 $K_{b3} = K_w / K_{a1}$ 而非 $K_w / K_{a3}$。规律：逐级水解常数与逐级电离常数按**逆序**对应（$K_{bi} = K_w / K_{a(n+1-i)}$）。

**解 14**：（1）验证 $c K_a > 20K_w$ 且 $c/K_a > 500$，用最简式 $[\mathrm{H^+}] = \sqrt{c K_a} = \sqrt{0.10\times6.2\times10^{-10}} = 7.9\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 5.10$。（2）先求 $K_b = K_w / K_a = 10^{-14}/(6.2\times10^{-10}) = 1.6\times10^{-5}$；$[\mathrm{OH^-}] = \sqrt{c K_b} = \sqrt{1.6\times10^{-6}} = 1.3\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pOH} = 2.90$，$\mathrm{pH} = 11.10$。

**解 15**：两性物质精确式 $[\mathrm{H^+}] = \sqrt{\dfrac{c K_{a2} + K_w}{c/K_{a1} + 1}}$。验证 $c K_{a2} = 0.10\times4.7\times10^{-11} = 4.7\times10^{-12} > 20 K_w$（不足 $20K_w$ 时须保留 $K_w$ 项）且 $c/K_{a1} = 0.10/(4.5\times10^{-7}) \gg 20$，可用最简式 $[\mathrm{H^+}] = \sqrt{K_{a1}K_{a2}} = \sqrt{4.5\times10^{-7}\times4.7\times10^{-11}} = \sqrt{2.12\times10^{-17}} = 4.6\times10^{-9}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 8.34$。

**解 16**：极稀碱溶液须同时考虑碱电离与水的自电离。电荷守恒：$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}]$，即 $1.0\times10^{-8} + x = \dfrac{10^{-14}}{x}$（$x = [\mathrm{H^+}]$），解得 $x = 7.9\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} \approx 7.04$。结论：极稀碱溶液实际仅呈微弱碱性（$\mathrm{pH}\approx7.04$），绝不可套用 $[\mathrm{OH^-}] = c$ 得 $\mathrm{pH} = 6$ 的荒谬结果。

**解 17**：错误原因：$c K_{a1} = 0.010\times0.059 = 5.9\times10^{-4} < 10$，不满足最简公式的近似条件，故 $2.71$ 偏差显著。正确方法用精确式 $[\mathrm{H^+}] = \sqrt{\dfrac{K_{a1}K_{a2}c}{K_{a1} + c}} = \sqrt{\dfrac{5.9\times10^{-2}\times6.4\times10^{-5}\times0.010}{5.9\times10^{-2} + 0.010}} = 7.4\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 3.13$（计算机按质子守恒精确解得 $7.1\times10^{-4}$，$\mathrm{pH} = 3.15$，误差仅 $0.02$）。判据：$c \ge 20K_{a1}$ 成立与否决定两性最简式能否使用。

**解 18**：$n(\mathrm{HCl}) = 0.10\times25\times10^{-3} = 2.5\times10^{-3}\ \mathrm{mol}$。标定酸须用**碱性**基准物质：草酸与邻苯二甲酸氢钾是标定碱的**酸性**基准，与 $\mathrm{HCl}$ 不发生酸碱反应，直接淘汰。碳酸钠（二元碱，$1:2$ 反应）：$m = \frac{1}{2}\times2.5\times10^{-3}\times105.99 = 0.132\ \mathrm{g}$，两次读数绝对误差 $\pm0.2\ \mathrm{mg}$，$E_{\mathrm{r}} = 0.2/132 \approx 0.15\% > 0.1\%$，超差，且终点需甲基橙并煮沸驱 $\mathrm{CO_2}$。Tris（一元碱，$1:1$ 反应）：$m = 2.5\times10^{-3}\times121.14 = 0.303\ \mathrm{g}$，$E_{\mathrm{r}} = 0.2/303 \approx 0.07\% < 0.1\%$，满足要求。**最佳基准物质为 Tris**。

**解 19**：溶液中的离子型体盘点——阳离子 $\mathrm{Na^+}$、$\mathrm{H^+}$；阴离子 $\mathrm{HCO_3^-}$、$\mathrm{CO_3^{2-}}$、$\mathrm{HIn^-}$、$\mathrm{In^{2-}}$、$\mathrm{OH^-}$。按电中性原理列式，带 2 个电荷的离子浓度须乘 2，$\mathrm{H_2CO_3}$ 与 $\mathrm{H_2In}$ 为中性分子不进入：
$$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{HCO_3^-}] + 2[\mathrm{CO_3^{2-}}] + [\mathrm{HIn^-}] + 2[\mathrm{In^{2-}}] + [\mathrm{OH^-}]$$

**解 20**：（1）净电荷为 0 的形态是 $\mathrm{A}$，分布在 $\mathrm{p}K_{a2}$ 与 $\mathrm{p}K_{a3}$ 之间，故碱性氨基酸 $\mathrm{pI} = \frac{1}{2}(\mathrm{p}K_{a2} + \mathrm{p}K_{a3}) = \frac{1}{2}(8.95 + 10.50) = 9.72$。
（2）$\mathrm{pH} = 9.60$ 时：$\dfrac{[\mathrm{A}]}{[\mathrm{HA^+}]} = 10^{9.60-8.95} = 4.47$，$\dfrac{[\mathrm{A^-}]}{[\mathrm{A}]} = 10^{9.60-10.50} = 0.126$，$\dfrac{[\mathrm{H_2A^{2+}}]}{[\mathrm{HA^+}]} = 10^{2.18-9.60} \approx 3.8\times10^{-8} \approx 0$。设 $[\mathrm{A}] = x$，则 $[\mathrm{HA^+}] = x/4.47$、$[\mathrm{A^-}] = 0.126x$，由物料平衡 $x(1 + 1/4.47 + 0.126) = 1.350x = 0.345$，得 $x = 0.256$。故 $[\mathrm{A}] = 0.256\ \mathrm{mol\cdot L^{-1}}$、$[\mathrm{HA^+}] = 0.057\ \mathrm{mol\cdot L^{-1}}$、$[\mathrm{A^-}] = 0.032\ \mathrm{mol\cdot L^{-1}}$、$[\mathrm{H_2A^{2+}}] \approx 0$。

**解 21**：（1）滴定剂选 $0.10\ \mathrm{mol\cdot L^{-1}}$ $\mathrm{HCl}$ 标准溶液。赖氨酸净电荷为 0 的 $\mathrm{A}$ 形态含可质子化的 $\alpha$-$\mathrm{NH_2}$，可被强酸定量滴定至两性形态 $\mathrm{HA^+}$，突跃清晰；若用 $\mathrm{NaOH}$ 只能去质子化 $\mathrm{NH_3^+}$ 基（$\mathrm{p}K_{a2} = 8.95$、$\mathrm{p}K_{a3} = 10.50$），等当点在强碱区且突跃弱。反应：$\mathrm{C_6H_{14}N_2O_2} + \mathrm{HCl} \rightarrow [\mathrm{C_6H_{15}N_2O_2}]^+\mathrm{Cl^-}$。
（2）第一等当点产物为两性形态 $\mathrm{HA^+}$，$\mathrm{pH} \approx \frac{1}{2}(\mathrm{p}K_{a1} + \mathrm{p}K_{a2}) = \frac{1}{2}(2.18 + 8.95) = 5.57$；甲基红变色范围 $4.4 \sim 6.2$ 恰覆盖 $5.57$，选**甲基红**。
（3）标定 $\mathrm{HCl}$ 须用碱性基准：草酸、邻苯二甲酸氢钾不适用。碳酸钠 $m = 1.25\ \mathrm{mmol}\times105.99 = 0.132\ \mathrm{g}$，相对误差 $\approx 0.15\% > 0.1\%$ 超差；Tris $m = 2.5\ \mathrm{mmol}\times121.14 = 0.303\ \mathrm{g}$，相对误差 $\approx 0.07\% < 0.1\%$，**最佳为 Tris**（其等当点 $\mathrm{TrisH^+}$ 的 $\mathrm{pH} \approx 4.7$ 亦在甲基红区间）。
（4）计量比 $1:1$，$w = \dfrac{cVM}{1000\,m}$（$M = 146.2\ \mathrm{g\cdot mol^{-1}}$，$V$ 以 $\mathrm{mL}$、$m$ 以 $\mathrm{g}$ 计）。

**解 22**：由 $\mathrm{pH} = 6.99$ 分配指示剂型体：$[\mathrm{HIn^-}] = \dfrac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_{In}}\times50.0 = \dfrac{1.0\times10^{-7}}{3.0\times10^{-7}}\times50.0 = 17\ \mathrm{\mu mol\cdot L^{-1}}$，$[\mathrm{In^{2-}}] = \dfrac{K_{In}}{[\mathrm{H^+}] + K_{In}}\times50.0 = 33\ \mathrm{\mu mol\cdot L^{-1}}$。碳酸各型体用 $[\mathrm{CO_2(aq)}]$ 表达：$[\mathrm{HCO_3^-}] = \dfrac{K_1}{[\mathrm{H^+}]}[\mathrm{CO_2}] = 3.0[\mathrm{CO_2}]$，$[\mathrm{CO_3^{2-}}] = \dfrac{K_1K_2}{[\mathrm{H^+}]^2}[\mathrm{CO_2}] = 9.0\times10^{-4}[\mathrm{CO_2}]$，$[\mathrm{OH^-}] = K_w/[\mathrm{H^+}] = 6.7\times10^{-8}\ \mathrm{mol\cdot L^{-1}}$。代入电荷平衡方程（$[\mathrm{Na^+}] = 92.0\ \mathrm{\mu mol\cdot L^{-1}}$）：$92.0\times10^{-6} + 1.0\times10^{-7} = 3.0[\mathrm{CO_2}] + 2(9.0\times10^{-4})[\mathrm{CO_2}] + 17\times10^{-6} + 2\times33\times10^{-6} + 6.7\times10^{-8}$，解得 $[\mathrm{CO_2(aq)}] = 3.0\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$。

**解 23**：$c_{In} = [\mathrm{HIn^-}] + [\mathrm{In^{2-}}] = 50.0\ \mathrm{\mu mol\cdot L^{-1}}$，$[\mathrm{Na^+}] = 50.0 + 42.0 = 92.0\ \mathrm{\mu mol\cdot L^{-1}}$。令 $x = [\mathrm{In^{2-}}]/[\mathrm{HIn^-}]$，由 $A_{620} = \varepsilon^{\mathrm{In^{2-}}}_{620}b[\mathrm{In^{2-}}]$、$A_{434} = \varepsilon^{\mathrm{HIn^-}}_{434}b[\mathrm{HIn^-}] + \varepsilon^{\mathrm{In^{2-}}}_{434}b[\mathrm{In^{2-}}]$ 及 $A_{620}/A_{434} = 2.84$：$1.70\times10^{4}x = 2.84(8.00\times10^{3} + 1.90\times10^{3}x)$，解得 $x = 1.96$。由 ${K_{In}}$ 取对数，$\mathrm{pH} = \mathrm{p}K_{In} + \lg\dfrac{[\mathrm{In^{2-}}]}{[\mathrm{HIn^-}]} = 6.70 + \lg1.96 = 6.99$。

**解 24**：设 $\mathrm{ClO^-}$ 为 1、$\mathrm{ClO_3^-}$ 为 2（比例待定量）。（1）由两次滴定耗 $\mathrm{Na_2S_2O_3}$ 5.0 mL 与 30.0 mL，得 $n(\mathrm{ClO^-}) : n(\mathrm{ClO_3^-}) = 5.0 : 30.0 = 1 : 6$ 的电子计量关系，即 $\mathrm{ClO^-}$ 与 $\mathrm{ClO_3^-}$ 的物质的量之比经电子守恒核算为 $1:2$。取 $\mathrm{ClO^-}$ $1\ \mathrm{mol}$、$\mathrm{ClO_3^-}$ $2\ \mathrm{mol}$：氧化半反应失电子 $1\times1 + 2\times5 = 11\ \mathrm{mol}$，还原生成 $\mathrm{Cl^-}$ $11\ \mathrm{mol}$。（2）由 $\mathrm{Cl}$、$\mathrm{Na}$、$\mathrm{H}$ 原子守恒配平：$5\mathrm{Cl_2} + 12\mathrm{NaOH} = 8\mathrm{NaCl} + \mathrm{NaClO} + 2\mathrm{NaClO_3} + 6\mathrm{H_2O}$。（3）$n(\mathrm{Na_2S_2O_3})$ 与电子转移对应，结合取样稀释倍数逐级放大至原溶液，得 $n(\mathrm{NaClO}) = 5.0\times10^{-3}\ \mathrm{mol}$、$n(\mathrm{NaClO_3}) = 1.0\times10^{-2}\ \mathrm{mol}$（$500\ \mathrm{mL}$ 原液），故 $c(\mathrm{NaClO}) = 0.010\ \mathrm{mol\cdot L^{-1}}$、$c(\mathrm{NaClO_3}) = 0.020\ \mathrm{mol\cdot L^{-1}}$。

**解 25**：（1）$\mathrm{Ba}$、$\mathrm{In}$ 保持原氧化态，$\mathrm{Co}$ 被还原为 $\mathrm{Co^{2+}}$，$\mathrm{I^-}$ 被氧化为 $\mathrm{I_2}$，按电荷守恒与物料守恒配平：
$$\mathrm{BaIn_{0.55}Co_{0.45}O_{3-\delta}} + (1.45 - 2\delta)\mathrm{I^-} + (6 - 2\delta)\mathrm{H^+} = \mathrm{Ba^{2+}} + 0.55\mathrm{In^{3+}} + 0.45\mathrm{Co^{2+}} + (0.725 - \delta)\mathrm{I_2} + (3 - \delta)\mathrm{H_2O}$$
（$\mathrm{I_2}$ 在水中以 $\mathrm{I_3^-}$ 形式存在，写出含 $\mathrm{I_3^-}$ 的方程式亦正确。）
（2）滴定反应：$2\mathrm{S_2O_3^{2-}} + \mathrm{I_2} = \mathrm{S_4O_6^{2-}} + 2\mathrm{I^-}$。
（3）由电子转移计量关系 $2\mathrm{I^-} \sim \mathrm{I_2} \sim 2\mathrm{S_2O_3^{2-}} \sim 2\mathrm{e^-}$，$n_{\mathrm{S_2O_3^{2-}}} = 0.05000\times10.85\times10^{-3} = 5.425\times10^{-4}\ \mathrm{mol}$，$n_e = 5.425\times10^{-4}\ \mathrm{mol}$（$\mathrm{S_2O_3^{2-}}\sim\mathrm{e^-}$ 为 $1:1$）。结合样品摩尔质量表达式 $M = 137.3 + 0.55\times114.8 + 0.45\times58.93 + (3 - \delta)\times16.00$ 与电荷守恒 $2 + 0.55\times3 + 0.45 S_{\mathrm{Co}} = 2(3 - \delta)$，解得 $\delta = 0.37$、$S_{\mathrm{Co}} = 3.58$。
