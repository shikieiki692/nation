## §1 光度分析总纲与命题脉络

分光光度法是分析化学定量测定、配位平衡与反应动力学实时监测的交叉枢纽。大学教材大量篇幅用于分光光度计的内部光路与显色反应的工程操作描述，而竞赛命题真正反复设置考查点的，是基于光吸收定律的定量计算与平衡常数的图解解析。本讲的五类命题模型为：

一是朗伯-比尔定律与光度测量条件。掌握 $A = \varepsilon b c$、加和性与适用条件，掌握最佳吸光度区间 $A \in [0.2, 0.8]$ 与示差分光光度法扩大量程的原理。

二是配合物组成与稳定常数的测定。掌握等摩尔连续变换法（Job 法）的极值点 $x_{\max} = n/(1+n)$ 与切线外推法求 $\beta_n$，以及摩尔比法的折点判据。

三是弱酸解离常数与等吸收点。掌握光度法测 $\mathrm{p}K_a$ 的线性化作图方程 $\mathrm{pH} = \mathrm{p}K_a + \lg\dfrac{A - A_{\mathrm{HA}}}{A_{\mathrm{A^-}} - A}$，以及等吸收点作为"仅存在两个互变吸光型体"的诊断判据。

四是分光光度滴定。掌握六类特征折线形态与体积校正因子 $\dfrac{V_0 + V}{V_0}$。

五是分光光度法在动力学与光化学中的应用。掌握由吸光度-时间数据判断反应级数、求速率常数与活化能，以及量子产率的光度测定与外标法。

## §2 朗伯-比尔定律与光度测量条件

### 2.1 朗伯-比尔定律及其适用条件

分光光度法的物理基石是物质分子或离子对特定波长电磁辐射的选择性吸收。当一束平行单色光垂直通过含吸光质点的均匀透明介质时，光强由入射光强 $I_0$ 指数衰减至透射光强 $I_t$。由光吸收的微元模型积分可得朗伯-比尔定律：

$$A = -\lg T = \lg\frac{I_0}{I_t} = \varepsilon b c$$

其中 $A$ 为吸光度，$T = I_t/I_0$ 为透光度，$b$ 为光程（$\mathrm{cm}$），$c$ 为吸光物质浓度（$\mathrm{mol\cdot L^{-1}}$），$\varepsilon$ 为摩尔吸光系数（$\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$）。

朗伯-比尔定律的成立需满足四个条件：①入射光为足够纯的单色光；②吸光物质在溶液中以单一、稳定的型体存在，各质点间无相互作用；③溶液均匀透明、无散射；④浓度不过高（一般 $c < 0.01\ \mathrm{mol\cdot L^{-1}}$）。当溶液发生缔合、解离、配位或颗粒散射时，吸光度将偏离线性关系。

### 2.2 摩尔吸光系数的化学物理本质与加和性

在朗伯-比尔定律表达式中，光程 $b$ 通常以厘米（$\mathrm{cm}$）为单位，溶质浓度 $c$ 以 $\mathrm{mol\cdot L^{-1}}$ 为单位，比例常数 $\varepsilon$ 被严格定义为摩尔吸光系数（Molar Absorptivity），其法定单位为 $\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。摩尔吸光系数是吸光物质在特定波长、特定溶剂和特定温度下的特有本征物理化学常数，其数值直接决定了光度测定方法的灵敏度极限。

微观量子力学表明，$\varepsilon$ 正比于跃迁偶极矩的平方与爱因斯坦自发辐射吸收系数。根据光谱选择定则，由电偶极跃迁完全允许的跃迁过程（如有机分子共轭体系的 $\pi \to \pi^*$ 强吸收带、过渡金属配位场电荷转移跃迁 CT 等），其振子强度大，摩尔吸光系数通常高达 $10^4 \sim 10^5\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$，构成了高灵敏痕量分析的基础；而受自旋禁阻或拉波特（Laporte）宇称对称性禁阻的跃迁过程（如八面体配合物中 $3\mathrm{d} \to 3\mathrm{d}$ 的配位场跃迁），其摩尔吸光系数通常仅在 $1 \sim 100\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$ 之间，难以直接用于微量测定。

在均相溶液中若同时共存多种互不发生化学反应的吸光组分，在特定入射波长 $\lambda$ 处，各吸光物种对该波长光子的截获行为彼此独立。因此，溶液的总吸光度严格满足线性加和性原理（Principle of Additivity）：

$$A_{\mathrm{total}} = \sum_{i=1}^{n} A_i = b \sum_{i=1}^{n} \varepsilon_i c_i = b (\varepsilon_1 c_1 + \varepsilon_2 c_2 + \cdots + \varepsilon_n c_n)$$

吸光度加和性是推导多组分同时测定、配合物离解平衡以及酸碱指示剂解离常数的根本基石。当且仅当各组分之间不存在缔合、互变异构、化学配位干扰以及荧光二次发射时，加和性才严格成立。

### 2.3 透光度读数误差与最佳吸光度区间

分光光度计直接测量的是透光度 $T$，吸光度 $A$ 由对数运算间接得到。仪器噪声引起的透光度绝对读数误差 $\Delta T$ 会传递为浓度的相对误差。由 $c = -\dfrac{0.4343}{\varepsilon b}\ln T$ 求导可得：

$$\frac{\Delta c}{c} = -\frac{0.4343\,\Delta T}{T A}$$

![[49bb462324e71e44678127f85aa6075a7993ee02bd2258b9e35ae56b9b835cd3.jpg|500]]
> 图 9-2：分光光度法测量相对误差与透光率关系曲线（适宜吸光度范围在 0.2 至 0.8 之间）

当仪器透光度绝对误差 $\Delta T$ 近似为常数时，浓度的相对误差仅取决于 $T$（或 $A$）。令 $\dfrac{\mathrm{d}}{\mathrm{d}T}(T\ln T) = \ln T + 1 = 0$，得最佳透光度 $T = \mathrm{e}^{-1} \approx 36.8\%$，对应最佳吸光度 $A = 0.4343$，此时浓度相对误差最小。

由此，待测液吸光度应调配在 $A \in [0.2, 0.8]$（对应 $T$ 约 $15\% \sim 65\%$）的低误差区间。吸光度过大（$T$ 过小、透射光逼近检测器暗电流）或过小（$T$ 过大、$I_0$ 与 $I_t$ 差别微弱）都会使相对误差显著增大。

### 2.4 示差分光光度法的标尺扩展与误差压缩机制

当待测试样中目标组分含量极高（吸光度远远大于 1.0）时，常规分光光度法因透射光太弱而导致测量误差不可接受。此时，竞赛中常考查**示差分光光度法（Differential Spectrophotometry）**。该方法不使用纯溶剂或空白试剂校准零吸光度，而是精选一个浓度略低于待测液的已知标准溶液 $c_{\mathrm{r}}$（吸光度为 $A_{\mathrm{r}}$）作为参比参调透光度 $100\%$。

设待测试液浓度为 $c_x$（$c_x > c_{\mathrm{r}}$），两者的单色透射光强分别为 $I_x$ 与 $I_{\mathrm{r}}$。以浓度为 $c_{\mathrm{r}}$ 的参比液入射光强 $I_{\mathrm{r}}$ 作为新的相对“入射光强”，则仪器实测的示差透光度为 $T_{\mathrm{r}} = \frac{I_x}{I_{\mathrm{r}}}$。根据朗伯-比尔定律的对数展开：

$$A_{\mathrm{r}} = \lg\left(\frac{I_0}{I_{\mathrm{r}}}\right) = \varepsilon b c_{\mathrm{r}},\quad A_x = \lg\left(\frac{I_0}{I_x}\right) = \varepsilon b c_x$$

仪器直接读出的相对示差吸光度 $\Delta A$ 满足：

$$\Delta A = -\lg T_{\mathrm{r}} = \lg\left(\frac{I_{\mathrm{r}}}{I_x}\right) = \lg\left(\frac{I_0}{I_x}\right) - \lg\left(\frac{I_0}{I_{\mathrm{r}}}\right) = A_x - A_{\mathrm{r}} = \varepsilon b (c_x - c_{\mathrm{r}}) = \varepsilon b \Delta c$$

![[60732d570d1d94548ed4b0f793f76e279af73a62735cab1ce07fa31507333ec2.jpg|500]]
> 图 9-3：示差法测量原理示意图（标样消减参比光度与标尺扩展）

示差法的数学本质是将吸光度测量的物理原点平移了 $A_{\mathrm{r}}$，相当于将检测器的透光度标尺成倍放大扩展。其浓度的相对误差变为：

$$\frac{\Delta c_x}{c_x} = \frac{0.4343 \Delta T_{\mathrm{r}}}{T_{\mathrm{r}} \Delta A} \cdot \frac{\Delta c}{c_x}$$

由于浓度增量 $\Delta c = c_x - c_{\mathrm{r}} \ll c_x$，因子 $\frac{\Delta c}{c_x}$ 远小于 1，使得高含量组分测定的相对误差被大幅压缩至 $0.1\% \sim 0.2\%$，精度逼近经典容量滴定法。

## §3 配合物组成与稳定常数的光度测定

### 3.1 等摩尔连续变换法（Job 法）

确定配合物的络合比 $n$ 与稳定常数 $\beta_n$，是配位化学与溶液平衡的常考题型。法国化学家 Job 提出的等摩尔连续变换法（Method of Continuous Variations）是最经典的工具。

实验设计上严格保持金属离子与配体的分析总浓度恒定，即令 $c_{\mathrm{M}} + c_{\mathrm{L}} = c_0$。引入配体摩尔分数 $x = c_{\mathrm{L}}/c_0$，配制 $x$ 从 $0$ 到 $1$ 连续变化的一系列混合溶液（如 $x = 0.1, 0.2, \dots, 0.9$）。

设生成单一配合物 $\mathrm{M} + n\mathrm{L} \rightleftharpoons \mathrm{ML}_n$，其平衡浓度 $[\mathrm{ML}_n]$ 随 $x$ 变化并在某点取极大值。令 $\dfrac{\mathrm{d}[\mathrm{ML}_n]}{\mathrm{d}x} = 0$，结合物料平衡化简可得极值条件 $[\mathrm{L}] = n[\mathrm{M}]$，进一步代入物料关系解得极值点位置：

$$x_{\max} = \frac{n}{1 + n}$$

即无论配合物稳定常数大小如何，吸光度差曲线的极大值点位置严格满足此式：$1:1$ 型配合物 $x_{\max} = 0.50$，$1:2$ 型 $x_{\max} \approx 0.67$，$1:3$ 型 $x_{\max} = 0.75$。

![[a5060dc4047ddc4ecd786dcbccbc3d033d21da9560eaf1a3d6ba4d387091efbc.jpg|500]]
> 图 9-4：等摩尔连续变换法（Job法）测定配合物组成曲线

### 3.2 Job 曲线外推切线交点与稳定常数的快速算法

在实际光度测量中，若仅有配合物吸光，而金属离子与配体在测定波长处均无吸收，则溶液吸光度直接正比于配合物平衡浓度：$A = \varepsilon_{\mathrm{ML}_n} b [\mathrm{ML}_n]$。若反应物也存在微弱背景吸收，则定义吸光度增量差 $\Delta A = A_{\mathrm{obs}} - \varepsilon_{\mathrm{M}} b c_{\mathrm{M}} - \varepsilon_{\mathrm{L}} b c_{\mathrm{L}}$ 作为 Y 轴作图。

如图所示，若反应完全进行（$\beta_n \to \infty$，无任何解离），则混合溶液的吸光度将由两条严格的斜线组成：在 $x \le x_{\max}$ 时，配体是限量组分，全部转化为配合物，吸光度随 $x$ 直线线性上升；在 $x \ge x_{\max}$ 时，金属离子是限量组分，随 $x$ 增大而线性下降。两条外推渐近线在 $x_{\max}$ 处相交，交点的纵坐标即为配合物完全不解离时的**理论极大吸光度** $A_{\max}^{\text{理论}}$。

而在真实体系中，由于配合物存在一定程度的解离平衡，实验测得的曲线是一条平滑圆弧，其实际峰顶为**实测极大吸光度** $A_{\max}^{\text{实测}}$。根据朗伯-比尔定律的线性比例关系：

$$\frac{[\mathrm{ML}_n]_{\text{实测}}}{[\mathrm{ML}_n]_{\text{理论}}} = \frac{A_{\max}^{\text{实测}}}{A_{\max}^{\text{理论}}}$$

在理论完全反应的假想状态下，配比 $x_{\max} = \frac{n}{1+n}$ 对应投入的金属总浓度为 $c_{\mathrm{M}} = c_0(1 - x_{\max}) = \frac{c_0}{1+n}$。由于全部转化为 $\mathrm{ML}_n$，其理论最大浓度为：

$$[\mathrm{ML}_n]_{\text{理论}} = c_{\mathrm{M}} = \frac{c_0}{1 + n}$$

因此，在真实极大值点处的配合物实际平衡浓度可由实验数据直接算出：

$$[\mathrm{ML}_n]_{\text{实测}} = [\mathrm{ML}_n]_{\text{理论}} \cdot \frac{A_{\max}^{\text{实测}}}{A_{\max}^{\text{理论}}} = \frac{c_0}{1 + n} \cdot \frac{A_{\max}^{\text{实测}}}{A_{\max}^{\text{理论}}}$$

定义配合物在极大值点处的解离分数 $\alpha$：

$$\alpha = \frac{A_{\max}^{\text{理论}} - A_{\max}^{\text{实测}}}{A_{\max}^{\text{理论}}}$$

则游离未络合的金属离子平衡浓度与配体平衡浓度分别为：

$$[\mathrm{M}] = c_{\mathrm{M}} - [\mathrm{ML}_n]_{\text{实测}} = \frac{c_0}{1 + n} \alpha$$

$$[\mathrm{L}] = c_{\mathrm{L}} - n[\mathrm{ML}_n]_{\text{实测}} = \frac{n c_0}{1 + n} \alpha = n [\mathrm{M}]$$

将上述平衡浓度代回稳定常数定义式，导出化竞中计算稳定常数的计算通式：

$$\beta_n = \frac{[\mathrm{ML}_n]_{\text{实测}}}{[\mathrm{M}][\mathrm{L}]^n} = \frac{\frac{c_0}{1+n} (1 - \alpha)}{\left[ \frac{c_0}{1+n} \alpha \right] \left[ n \frac{c_0}{1+n} \alpha \right]^n} = \frac{1 - \alpha}{n^n \left( \frac{c_0}{1+n} \right)^n \alpha^{n+1}}$$

特别地，对于最常见的 $1:1$ 型配合物（$n = 1$，$x_{\max} = 0.5$）：

$$\beta_1 = \frac{1 - \alpha}{\left(\frac{c_0}{2}\right) \alpha^2} = \frac{2(1 - \alpha)}{c_0 \alpha^2}$$

在化学竞赛命题中，题干往往给出 Job 曲线的极大值坐标与两条外推渐近线斜率，利用上述推导即可无需复杂联立方程直接快速求解稳定常数 $\beta_n$。

### 3.3 摩尔比法（饱和法）与逐级解离判断

**摩尔比法（Molar Ratio Method）**是测定配合物组成的另一重要经典手段。与 Job 法不同，摩尔比法保持金属离子分析浓度 $c_{\mathrm{M}}$ 恒定，连续向其中加入不同量的配体使 $c_{\mathrm{L}}$ 逐渐递增。以配体与金属的摩尔比 $r = \frac{c_{\mathrm{L}}}{c_{\mathrm{M}}}$ 为横坐标，以吸光度 $A$ 为纵坐标绘制摩尔比曲线。

![[3fee03aabc617ed5e7ff18d33b49d6879ff30b6d946ac2d2f13cf7822a2013cc.jpg|500]]
> 图 9-5：摩尔比法测定络合物组成的吸光度变化曲线

若生成的配合物稳定（$\beta_n$ 极大且为单一物种），当 $r < n$ 时，随着配体加入，吸光配合物浓度线性上升，曲线为一段上升直线；当加入配体达到配比 $r = n$ 后，金属离子被完全络合消耗殆尽，继续加入配体吸光度不再增加（保持水平横线）。两条直线的清晰外推折点拐点坐标横截值，直接读出配合物的络合比 $n$。

若体系生成的配合物稳定常数中等，折点处将钝化为圆滑过渡曲线；而若溶液中存在逐级配位平衡（如依次形成 $\mathrm{ML}$、$\mathrm{ML}_2$、$\mathrm{ML}_3$），且各级配合物的摩尔吸光系数差异显著，摩尔比曲线上将依次出现多个不同斜率的折点，每个拐点分别对应一级配合物的化学计量饱和点。

## §4 弱酸解离常数与等吸收点

### 4.1 一元弱酸解离体系的吸收光谱与线性化作图方程

测定有机弱酸、药物分子以及酸碱指示剂的酸解离常数 $\mathrm{p}K_a$，是施朱鸣等名师讲座与全国决赛常设的经典题型。设一元弱酸分子 $\mathrm{HA}$（如酚类或指示剂）在水溶液中发生电离平衡：

$$\mathrm{HA} \rightleftharpoons \mathrm{H^+} + \mathrm{A^-},\quad K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]}$$

由于共轭酸碱对 $\mathrm{HA}$ 与 $\mathrm{A^-}$ 具有不同的共轭发色体系（去质子化通常伴随着电子离域扩展，产生明显的红移现象），两者的摩尔吸光系数在所选波长处显著不同，分别记为 $\varepsilon_{\mathrm{HA}}$ 与 $\varepsilon_{\mathrm{A^-}}$。

设体系中该弱酸的分析总浓度为 $c_0 = [\mathrm{HA}] + [\mathrm{A^-}]$。根据酸碱平衡分布系数定义：

$$\alpha_{\mathrm{HA}} = \frac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a},\quad \alpha_{\mathrm{A^-}} = \frac{K_a}{[\mathrm{H^+}] + K_a}$$

在光程为 $b$ 的吸收池中，在特定波长下根据吸光度加和性原理，溶液的实测总吸光度 $A$ 为：

$$A = \varepsilon_{\mathrm{HA}} b [\mathrm{HA}] + \varepsilon_{\mathrm{A^-}} b [\mathrm{A^-}] = b c_0 (\varepsilon_{\mathrm{HA}} \alpha_{\mathrm{HA}} + \varepsilon_{\mathrm{A^-}} \alpha_{\mathrm{A^-}})$$

当溶液处于强酸性极值环境（$\mathrm{pH} \ll \mathrm{p}K_a - 2$）时，弱酸完全被压制在分子态，$\alpha_{\mathrm{HA}} \approx 1,\ \alpha_{\mathrm{A^-}} \approx 0$，此时实测吸光度记为 $A_{\mathrm{HA}} = \varepsilon_{\mathrm{HA}} b c_0$。

反之，当溶液处于强碱性极值环境（$\mathrm{pH} \gg \mathrm{p}K_a + 2$）时，弱酸完全解离为阴离子态，$\alpha_{\mathrm{HA}} \approx 0,\ \alpha_{\mathrm{A^-}} \approx 1$，此时实测吸光度记为 $A_{\mathrm{A^-}} = \varepsilon_{\mathrm{A^-}} b c_0$。

在两者之间的任意过渡缓冲介质中，实测吸光度可简洁写为：

$$A = A_{\mathrm{HA}} \alpha_{\mathrm{HA}} + A_{\mathrm{A^-}} \alpha_{\mathrm{A^-}} = A_{\mathrm{HA}} \frac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a} + A_{\mathrm{A^-}} \frac{K_a}{[\mathrm{H^+}] + K_a}$$

两边同乘 $([\mathrm{H^+}] + K_a)$ 并移项整理：

$$A [\mathrm{H^+}] + A K_a = A_{\mathrm{HA}} [\mathrm{H^+}] + A_{\mathrm{A^-}} K_a \implies (A - A_{\mathrm{HA}}) [\mathrm{H^+}] = (A_{\mathrm{A^-}} - A) K_a$$

由此推导出极具数学对称形式的代数比值：

$$\frac{[\mathrm{H^+}]}{K_a} = \frac{A_{\mathrm{A^-}} - A}{A - A_{\mathrm{HA}}}$$

两边同时取以 10 为底的负常用对数：

$$-\lg[\mathrm{H^+}] - (-\lg K_a) = -\lg\left( \frac{A_{\mathrm{A^-}} - A}{A - A_{\mathrm{HA}}} \right) = \lg\left( \frac{A - A_{\mathrm{HA}}}{A_{\mathrm{A^-}} - A} \right)$$

整理即可得到光度法测定 $\mathrm{p}K_a$ 的核心线性方程：

$$\mathrm{pH} = \mathrm{p}K_a + \lg\left( \frac{A - A_{\mathrm{HA}}}{A_{\mathrm{A^-}} - A} \right)$$

这一公式在形式上与著名的 Henderson-Hasselbalch 缓冲方程完全等价。在实际竞赛数据处理中，实验通过改变缓冲溶液的 $\mathrm{pH}$ 测定一系列吸光度 $A$，以 $\mathrm{pH}$ 为纵坐标，以对数项 $\lg\left( \frac{A - A_{\mathrm{HA}}}{A_{\mathrm{A^-}} - A} \right)$ 为横坐标作图。理论上曲线严格为一条直线，其斜率严格等于 1，而该直线在纵轴上的截距直接对应待测弱酸的真实酸解离常数 $\mathrm{p}K_a$。

### 4.2 等吸收点（Isosbestic Point）的微观物理化学本质

当测量同一弱酸在不同固定 $\mathrm{pH}$ 缓冲介质中的全波长吸收光谱曲线时，可以观察到一个值得注意的物理现象：在某一或某些特定波长 $\lambda_{\mathrm{iso}}$ 处，不论溶液酸度如何剧烈变化、两种组分的平衡比例如何迁移，所有不同 $\mathrm{pH}$ 的光谱曲线都精确地相交于同一个单一点。该交点被称为**等吸收点（Isosbestic Point）**。

等吸收点的微观形成条件严格。根据吸光度方程：

$$A(\lambda) = b c_0 \left[ \varepsilon_{\mathrm{HA}}(\lambda) \alpha_{\mathrm{HA}} + \varepsilon_{\mathrm{A^-}}(\lambda) (1 - \alpha_{\mathrm{HA}}) \right] = b c_0 \left[ \varepsilon_{\mathrm{A^-}}(\lambda) + (\varepsilon_{\mathrm{HA}}(\lambda) - \varepsilon_{\mathrm{A^-}}(\lambda)) \alpha_{\mathrm{HA}} \right]$$

若要使 $A(\lambda)$ 完全独立于酸度（即对任何 $\alpha_{\mathrm{HA}}$，吸光度恒定不变），其必要充分条件是括号内的差值为零：

$$\varepsilon_{\mathrm{HA}}(\lambda_{\mathrm{iso}}) = \varepsilon_{\mathrm{A^-}}(\lambda_{\mathrm{iso}})$$

此时在该特征波长处，体系的总吸光度恒等于：

$$A(\lambda_{\mathrm{iso}}) = \varepsilon_{\mathrm{iso}} b c_0$$

等吸收点在现代分析与化学竞赛中具有重要的诊断判据价值：

1. **纯粹双组分平衡的判据**：溶液中存在清晰的等吸收点，是证明该吸光体系中**仅仅存在两个相互转化的吸光单体，且两者总物质的量严格守恒（无第三方未知副产物生成）**的严格判据。若体系在反应过程中逐渐析出沉淀、生成第三方配合物或发生降解，等吸收点将瞬间发生模糊或漂移。

2. **总浓度测定的无干扰标尺**：由于 $A(\lambda_{\mathrm{iso}})$ 与体系所处的化学平衡状态完全无关，仅取决于分析总浓度 $c_0$，因此在等吸收波长处测定吸光度，可以彻底摆脱溶液酸碱波动、离解程度的干扰，直接测定弱酸或染料的总含量。

## §5 分光光度滴定

### 5.1 分光光度滴定的基本原理与高灵敏度优势

在传统容量分析中，终点判定高度依赖目视酸碱指示剂、金属指示剂或氧化还原指示剂的颜色突变。然而，当被测溶液浓度十分稀薄（如低于 $10^{-4}\ \mathrm{mol\cdot L^{-1}}$）、反应平衡常数较小（导致化学计量点附近的电位或 pH 突跃平缓模糊），或者待测溶液本身具有深厚浑浊的背景颜色时，常规指示剂法彻底失效。**分光光度滴定（Photometric Titration）**巧妙地将光度测量的光谱选择性与容量滴定的化学计量性熔于一炉。

分光光度滴定的核心原理是：在滴定进行过程中，利用单色光连续或间隔照射滴定池，实时追踪溶液吸光度随加入滴定剂体积 $V$ 的演化规律。滴定终点的判定并不依赖突跃点瞬间的剧烈跳跃，而是依据化学计量点前后两条具有不同斜率的吸光度直线，通过数学外推两线交点来精确定位化学计量点体积 $V_{\mathrm{ep}}$。

正因为其依赖整段滴定过程的全局线性回归而非瞬间突跃，分光光度滴定展现出三大显著的化竞实战优势：
其一，突破化学平衡常数的苛刻限制。对于酸碱滴定，常规方法要求 $c K_a \ge 10^{-8}$，而分光光度滴定在 $K_a$ 极小（即使解离度在终点附近达不到 $99.9\%$）时，只要在过量滴定剂存在下反应能被拉平，通过终点两边直线的清晰交截仍能精确读出终点；
其二，超强抗干扰能力。如果干扰离子在所选测量波长处不吸收，即使其浓度比被测物高几个数量级，也完全不干扰滴定终点的几何判定；
其三，能够拓展至超稀溶液（检测下限可达 $10^{-6}\ \mathrm{mol\cdot L^{-1}}$），在痕量络合滴定与生化酶催化反应滴定中地位不可替代。

### 5.2 六类经典分光光度滴定曲线几何形态分析

设在特定测定波长下，待滴定物为 $\mathrm{A}$，滴定剂为 $\mathrm{B}$，滴定反应产物为 $\mathrm{P}$：$\mathrm{A} + \mathrm{B} \to \mathrm{P}$。三种物种的摩尔吸光系数分别记为 $\varepsilon_{\mathrm{A}}$、$\varepsilon_{\mathrm{B}}$ 与 $\varepsilon_{\mathrm{P}}$。根据化学计量点前后主导吸光物种的不同，分光光度滴定曲线呈现六类高度特征化的几何形态：

| 曲线类型 | 摩尔吸光系数条件 | 终点前吸光度演化 | 终点后吸光度演化 | 几何曲线形态与赛场题眼 |
| :--- | :--- | :--- | :--- | :--- |
| **类型 I** | $\varepsilon_{\mathrm{A}} > 0,\ \varepsilon_{\mathrm{B}} = 0,\ \varepsilon_{\mathrm{P}} = 0$ | 随 A 消耗直线下降 | A 耗尽，吸光度恒为 0 | **向下折线（倾斜下降后转水平）**。典型如用无色 EDTA 滴定吸光的 $\mathrm{Cu^{2+}}$ 或 $\mathrm{Bi^{3+}}$。 |
| **类型 II** | $\varepsilon_{\mathrm{A}} = 0,\ \varepsilon_{\mathrm{B}} > 0,\ \varepsilon_{\mathrm{P}} = 0$ | 反应物与产物均不吸光，恒为 0 | 终点后过量 B 引起直线上升 | **先平后升折线（水平后倾斜上升）**。典型如用高锰酸钾滴定无色的草酸或亚铁盐。 |
| **类型 III** | $\varepsilon_{\mathrm{A}} = 0,\ \varepsilon_{\mathrm{B}} = 0,\ \varepsilon_{\mathrm{P}} > 0$ | 产物 P 生成，吸光度直线上升 | 反应完全，P 浓度恒定，水平不变 | **倒 V 型折线（上升后转水平）**。典型如无色金属离子与无色配体生成深色配合物。 |
| **类型 IV** | $\varepsilon_{\mathrm{A}} > 0,\ \varepsilon_{\mathrm{B}} > 0,\ \varepsilon_{\mathrm{P}} = 0$ | A 被消耗，吸光度下降 | 终点后 B 过量，吸光度重新上升 | **经典 V 型对称/非对称折线**。在两直线最低极小交点处直接读出终点体积。 |
| **类型 V** | $\varepsilon_{\mathrm{P}} > \varepsilon_{\mathrm{A}} > 0,\ \varepsilon_{\mathrm{B}} = 0$ | A 转化为吸光更强的 P，斜率上升 | A 耗尽，产物不再增加，转为水平 | **两段不同斜率折线（上升后平缓）**。常用于弱配体被强配体置换的有色反应。 |
| **类型 VI** | $\varepsilon_{\mathrm{B}} > 0,\ \varepsilon_{\mathrm{P}} > 0,\ \varepsilon_{\mathrm{A}} = 0$ | 产物生成引起吸光度以斜率 $k_1$ 上升 | 终点后过量滴定剂以斜率 $k_2$ 叠加 | **双斜率单向折线（转折拐点为终点）**。根据 $k_1$ 与 $k_2$ 差异判定折点。 |

### 5.3 滴定剂稀释效应的体积校正因子

在分光光度滴定实验中，随着滴定管中滴定剂体积 $V$ 的不断滴入，滴定池内溶液的总容积由起始体积 $V_0$ 逐渐增大为 $V_0 + V$。这种溶剂体积的持续膨胀引起非反应性的物理稀释，导致实测吸光度 $A_{\mathrm{obs}}$ 相对理想无稀释状态发生系统性下弯。

为恢复吸光度与反应进度之间的严格线性几何关系，必须引入体积校正因子（Volume Correction Factor）。由比尔定律可知，在无稀释的基准状态下，吸光度直接正比于溶质总摩尔数：

$$A_{\mathrm{corr}} = \varepsilon b \frac{n}{V_0} = \varepsilon b \frac{c(V_0 + V)}{V_0} = A_{\mathrm{obs}} \left( \frac{V_0 + V}{V_0} \right)$$

在处理竞赛考卷中的分光光度滴定原始数据时，必须首先运用上式将实测的 $A_{\mathrm{obs}}$ 转换为校正吸光度 $A_{\mathrm{corr}}$。只有经过体积校正后的 $A_{\mathrm{corr}} - V$ 图谱，化学计量点前后的实验点才能严格拟合为两条直线，两者外推交点对应的横坐标方为真实、无系统误差的化学计量点体积 $V_{\mathrm{ep}}$。

## §6 竞赛典型例题精解

### 例题 1：等摩尔连续变换法（Job 法）测定配合物组成与累积稳定常数

**题目**：在化学竞赛与无机化学前沿研究中，常利用等摩尔连续变换法确定过渡金属配合物的配位比与热力学稳定常数。在 $25\ ^\circ\mathrm{C}$ 下，将金属离子 $\mathrm{M^{2+}}$ 溶液与有机单齿配体 $\mathrm{L}$ 溶液进行混合，两者的总分析浓度始终维持恒定：$c_0 = c_{\mathrm{M}} + c_{\mathrm{L}} = 1.00 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}}$。配制一系列配体摩尔分数 $x = \frac{c_{\mathrm{L}}}{c_0}$ 不同的混合体系（溶液光程 $b = 1.00\ \mathrm{cm}$）。已知在测试波长 $\lambda = 520\ \mathrm{nm}$ 处，游离金属离子与配体本身的吸光度均为零（$\varepsilon_{\mathrm{M}} = \varepsilon_{\mathrm{L}} = 0$），测得的吸光度 $A$ 完全由生成的配合物 $\mathrm{ML}_n$ 所贡献。
(1) 实验测得吸光度 $A$ 随 $x$ 的变化曲线呈现平滑圆弧，并在 $x = 0.667$ 处达到最大实测吸光度 $A_{\max}^{\text{实测}} = 0.600$。两条外推初始切线（分别为 $x \to 0$ 与 $x \to 1$ 处的切线）的交点纵坐标为 $A_{\max}^{\text{理论}} = 0.800$。求配合物的化学计量配比 $n$。
(2) 求配合物 $\mathrm{ML}_n$ 在 $520\ \mathrm{nm}$ 处的摩尔吸光系数 $\varepsilon$。
(3) 计算该配合物在极大值点体系中的离解度 $\alpha$。
(4) 严格推导并计算配合物在 $25\ ^\circ\mathrm{C}$ 下的累积形成常数 $\beta_n$。

**解析**：

(1) 根据等摩尔连续变换法的极值定理，吸光度达到全域极大值处的配体分数满足：
$$x_{\max} = \frac{n}{1 + n}$$
将实验极大值 $x_{\max} = 0.667 = \frac{2}{3}$ 代入方程：
$$\frac{n}{1 + n} = \frac{2}{3} \implies 3n = 2 + 2n \implies n = 2$$
因此，该配合物的化学计量组成为 $\mathrm{ML_2}$（络合比为 $1:2$）。

(2) 外推渐近切线交点 $A_{\max}^{\text{理论}}$ 对应配合物完全没有发生任何离解（$\beta_2 \to \infty$）时的理想假想状态。在 $x_{\max} = \frac{2}{3}$ 处，投入的金属离子分析浓度为：
$$c_{\mathrm{M}} = c_0(1 - x_{\max}) = 1.00 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}} \times \left(1 - \frac{2}{3}\right) = 3.333 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$$
在理想完全络合状态下，全部金属离子转化为配合物，其理论最大平衡浓度为：
$$[\mathrm{ML_2}]_{\text{理论}} = c_{\mathrm{M}} = 3.333 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$$
由朗伯-比尔定律 $A_{\max}^{\text{理论}} = \varepsilon b [\mathrm{ML_2}]_{\text{理论}}$，解得摩尔吸光系数：
$$\varepsilon = \frac{A_{\max}^{\text{理论}}}{b [\mathrm{ML_2}]_{\text{理论}}} = \frac{0.800}{1.00\ \mathrm{cm} \times 3.333 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}} = 2.40 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$$

(3) 在真实实验体系中，极大值点处的配合物实际平衡浓度为：
$$[\mathrm{ML_2}]_{\text{实测}} = \frac{A_{\max}^{\text{实测}}}{\varepsilon b} = \frac{0.600}{2.40 \times 10^3 \times 1.00} = 2.50 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$$
因此，配合物在极大值点处的离解度 $\alpha$ 为：
$$\alpha = \frac{A_{\max}^{\text{理论}} - A_{\max}^{\text{实测}}}{A_{\max}^{\text{理论}}} = \frac{0.800 - 0.600}{0.800} = 0.250\ (\text{即 } 25.0\%)$$

(4) 溶液中游离金属离子与游离配体的平衡浓度分别为：
$$[\mathrm{M}] = c_{\mathrm{M}} - [\mathrm{ML_2}]_{\text{实测}} = 3.333 \times 10^{-4} - 2.50 \times 10^{-4} = 8.333 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$$
$$[\mathrm{L}] = c_{\mathrm{L}} - 2[\mathrm{ML_2}]_{\text{实测}} = \frac{2}{3} \times 1.00 \times 10^{-3} - 2 \times 2.50 \times 10^{-4} = 6.667 \times 10^{-4} - 5.00 \times 10^{-4} = 1.667 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$$
注意到游离浓度满足极值条件：$[\mathrm{L}] = 2[\mathrm{M}] = 2 \times 8.333 \times 10^{-5} = 1.667 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$。
将各平衡浓度代入二级累积稳定常数表达式：
$$\beta_2 = \frac{[\mathrm{ML_2}]_{\text{实测}}}{[\mathrm{M}][\mathrm{L}]^2} = \frac{2.50 \times 10^{-4}}{(8.333 \times 10^{-5}) \times (1.667 \times 10^{-4})^2} = \frac{2.50 \times 10^{-4}}{8.333 \times 10^{-5} \times 2.778 \times 10^{-8}} \approx 1.08 \times 10^8\ \mathrm{L^2\cdot mol^{-2}}$$
其稳定常数的对数值为 $\lg\beta_2 = 8.03$。

### 例题 2：分光光度法测定溴甲酚绿指示剂酸解离常数与等吸收点微观分析

**题目**：酸碱指示剂溴甲酚绿（记为 $\mathrm{HIn}$，分析总浓度恒为 $c_0 = 4.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$）在水溶液中存在电离平衡：$\mathrm{HIn} \rightleftharpoons \mathrm{H^+} + \mathrm{In^-}$。在光程 $b = 1.00\ \mathrm{cm}$ 下测定其在不同波长与不同酸度下的吸光度。
(1) 在强酸介质中（$\mathrm{pH} = 1.0$），指示剂全部以酸式体 $\mathrm{HIn}$ 形式存在，测得在波长 $\lambda_1 = 615\ \mathrm{nm}$ 处的吸光度为 $A_{\mathrm{HIn}} = 0.040$；在强碱介质中（$\mathrm{pH} = 10.0$），指示剂全部解离为碱式体 $\mathrm{In^-}$，在 $\lambda_1 = 615\ \mathrm{nm}$ 处的吸光度为 $A_{\mathrm{In^-}} = 0.840$。在缓冲溶液调节至 $\mathrm{pH} = 4.70$ 时，实测吸光度为 $A = 0.440$。求该指示剂的酸解离常数 $K_a$ 与 $\mathrm{p}K_a$。
(2) 全波长扫描发现，在 $\lambda_{\mathrm{iso}} = 515\ \mathrm{nm}$ 处，无论溶液 $\mathrm{pH}$ 在 $1.0 \sim 10.0$ 之间如何变化，所有光谱曲线均精确相交于一点，测得该点吸光度恒为 $0.200$。求酸式体与碱式体在该波长处的摩尔吸光系数。

**解析**：

(1) 在 $\lambda_1 = 615\ \mathrm{nm}$ 处，溶液在特定 pH 缓冲体系中的吸光度服从线性化混合方程：
$$\mathrm{pH} = \mathrm{p}K_a + \lg\left(\frac{A - A_{\mathrm{HIn}}}{A_{\mathrm{In^-}} - A}\right)$$
将实验实测数据代入公式：
$$\mathrm{pH} = 4.70,\quad A = 0.440,\quad A_{\mathrm{HIn}} = 0.040,\quad A_{\mathrm{In^-}} = 0.840$$
计算对数项分子与分母差值：
$$A - A_{\mathrm{HIn}} = 0.440 - 0.040 = 0.400$$
$$A_{\mathrm{In^-}} - A = 0.840 - 0.440 = 0.400$$
由此直接得到比值：
$$\frac{A - A_{\mathrm{HIn}}}{A_{\mathrm{In^-}} - A} = \frac{0.400}{0.400} = 1.00 \implies \lg\left(\frac{A - A_{\mathrm{HIn}}}{A_{\mathrm{In^-}} - A}\right) = \lg(1.00) = 0$$
因此直接求得酸解离常数：
$$\mathrm{p}K_a = \mathrm{pH} - 0 = 4.70$$
$$K_a = 10^{-4.70} \approx 2.00 \times 10^{-5}$$

(2) 在等吸收点 $\lambda_{\mathrm{iso}} = 515\ \mathrm{nm}$ 处，酸式体与碱式体的摩尔吸光系数完全相等：
$$\varepsilon_{\mathrm{HIn}}(\lambda_{\mathrm{iso}}) = \varepsilon_{\mathrm{In^-}}(\lambda_{\mathrm{iso}}) = \varepsilon_{\mathrm{iso}}$$
此时总吸光度严格独立于解离度：$A_{\mathrm{iso}} = \varepsilon_{\mathrm{iso}} b c_0$。
将数据代入：
$$\varepsilon_{\mathrm{iso}} = \frac{A_{\mathrm{iso}}}{b c_0} = \frac{0.200}{1.00\ \mathrm{cm} \times 4.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}} = 5.00 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$$
即两者的摩尔吸光系数在该波长下均为 $5.00 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。

### 例题 3：双波长分光光度法消除背景浊度干扰

**题目**：在工业废水中测定微量铁离子 $\mathrm{Fe^{3+}}$。废水中存在微小不可沉降的悬浮胶体颗粒，导致整个可见光区存在平缓的背景光散射吸收，且由于胶体絮凝状态不稳定，吸光本底无法通过简单空白参比完全扣除。选用磺基水杨酸为显色剂，在碱性介质中生成黄色配合物 $\mathrm{FeL_3^{3-}}$。
已知配合物在特征吸收波长 $\lambda_1 = 425\ \mathrm{nm}$ 处的摩尔吸光系数为 $\varepsilon_1 = 6.00 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$；在波长 $\lambda_2 = 560\ \mathrm{nm}$ 处配合物完全不吸收，即 $\varepsilon_2 = 0$。根据瑞利散射微观定律，悬浊胶体在两波长处引起的表观吸光度差异极小，满足 $A_{\mathrm{scat}}(\lambda_1) \approx A_{\mathrm{scat}}(\lambda_2)$。
(1) 阐述双波长分光光度法消除背景散射干扰的数学代数原理。
(2) 若吸收池光程 $b = 1.00\ \mathrm{cm}$，仪器实测波长 $\lambda_1$ 处吸光度为 $0.485$，波长 $\lambda_2$ 处吸光度为 $0.125$。计算废水中铁离子的真实浓度。

**解析**：

(1) 在双波长分光光度法中，仪器以波长 $\lambda_2$ 处的透射光信号作为参比通道，以波长 $\lambda_1$ 处的透射光信号作为测定通道，直接测量两波长处的吸光度差值 $\Delta A$。
在波长 $\lambda_1$ 处，实测吸光度为配合物真实吸收与胶体散射的加和：
$$A_1 = A_{\mathrm{Fe}}(\lambda_1) + A_{\mathrm{scat}}(\lambda_1) = \varepsilon_1 b c_{\mathrm{Fe}} + A_{\mathrm{scat}}(\lambda_1)$$
在参比波长 $\lambda_2$ 处，因配合物不吸收，实测吸光度完全由胶体散射贡献：
$$A_2 = A_{\mathrm{Fe}}(\lambda_2) + A_{\mathrm{scat}}(\lambda_2) = 0 + A_{\mathrm{scat}}(\lambda_2)$$
两式作差得到双波长示差吸光度：
$$\Delta A = A_1 - A_2 = \varepsilon_1 b c_{\mathrm{Fe}} + [A_{\mathrm{scat}}(\lambda_1) - A_{\mathrm{scat}}(\lambda_2)]$$
由于选取的两波长处胶体散射本底相等，方括号项严格等于零，从而完全消除了浑浊背景的干扰，差值 $\Delta A$ 严格与铁离子浓度呈线性正比：
$$\Delta A = \varepsilon_1 b c_{\mathrm{Fe}}$$

(2) 代入实验测定数据：
$$\Delta A = 0.485 - 0.125 = 0.360$$
求出废水中铁离子的真实浓度：
$$c_{\mathrm{Fe}} = \frac{\Delta A}{\varepsilon_1 b} = \frac{0.360}{6.00 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}} \times 1.00\ \mathrm{cm}} = 6.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$$

### 例题 4：分光光度滴定法测定极稀重金属离子及体积校正

**题目**：取 $V_0 = 100.0\ \mathrm{mL}$ 含有微量 $\mathrm{Bi^{3+}}$ 的强酸性水溶液（吸收池光程 $b = 1.00\ \mathrm{cm}$），置于光度滴定池中，在波长 $\lambda = 265\ \mathrm{nm}$ 下用 $0.0100\ \mathrm{mol\cdot L^{-1}}$ 的 EDTA 标准溶液进行光度滴定。滴定反应生成极稳定的无色螯合物 $\mathrm{BiY^-}$。
已知在该波长下：游离 $\mathrm{Bi^{3+}}$ 具有很强的紫外吸收，摩尔吸光系数为 $\varepsilon_{\mathrm{Bi}} = 9.50 \times 10^3\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$；螯合物 $\mathrm{BiY^-}$ 完全不吸收，$\varepsilon_{\mathrm{BiY}} = 0$；过量 EDTA 在该波长下的摩尔吸光系数亦为零，$\varepsilon_{\mathrm{Y}} = 0$。
滴定过程中，向体系加入不同体积 $V$ 的 EDTA 溶液，测得初始及滴定过程中的吸光度数据如下：加入 $V = 0.00\ \mathrm{mL}$ 时，$A_{\mathrm{obs}} = 0.950$；加入 $V = 0.40\ \mathrm{mL}$ 时，$A_{\mathrm{obs}} = 0.568$；加入 $V = 0.80\ \mathrm{mL}$ 时，$A_{\mathrm{obs}} = 0.188$；加入 $V = 1.20\ \mathrm{mL}$ 时，$A_{\mathrm{obs}} = 0.000$；加入 $V = 1.60\ \mathrm{mL}$ 时，$A_{\mathrm{obs}} = 0.000$。
(1) 对上述实测吸光度数据进行体积稀释效应校正，写出校正公式并计算各点校正吸光度 $A_{\mathrm{corr}}$。
(2) 指出该分光光度滴定曲线属于哪类几何形态，并通过线性拟合外推求出化学计量点体积 $V_{\mathrm{ep}}$。
(3) 计算原水样中 $\mathrm{Bi^{3+}}$ 的分析浓度。

**解析**：

(1) 滴定剂加入引起总体积膨胀，体积校正公式为：
$$A_{\mathrm{corr}} = A_{\mathrm{obs}} \left( \frac{V_0 + V}{V_0} \right) = A_{\mathrm{obs}} \left( \frac{100.0 + V}{100.0} \right)$$
计算各点校正吸光度：
当 $V = 0.00\ \mathrm{mL}$ 时：$A_{\mathrm{corr}} = 0.950 \times \frac{100.0}{100.0} = 0.950$；
当 $V = 0.40\ \mathrm{mL}$ 时：$A_{\mathrm{corr}} = 0.568 \times \frac{100.4}{100.0} = 0.570$；
当 $V = 0.80\ \mathrm{mL}$ 时：$A_{\mathrm{corr}} = 0.188 \times \frac{100.8}{100.0} = 0.190$；
当 $V = 1.20\ \mathrm{mL}$ 时：$A_{\mathrm{corr}} = 0.000 \times \frac{101.2}{100.0} = 0.000$；
当 $V = 1.60\ \mathrm{mL}$ 时：$A_{\mathrm{corr}} = 0.000 \times \frac{101.6}{100.0} = 0.000$。

(2) 在该波长下仅被滴物 $\mathrm{Bi^{3+}}$ 吸光，产物与过量滴定剂均无吸收，符合类型 I 分光光度滴定曲线，呈典型的向下折线形态（倾斜下降后转为水平底线）。
终点前吸光度与体积呈严格线性下降：
斜率 $k = \frac{0.570 - 0.950}{0.40 - 0.00} = -0.950\ \mathrm{mL^{-1}}$。
直线方程为：$A_{\mathrm{corr}} = 0.950 - 0.950 V$。
化学计量点处 $\mathrm{Bi^{3+}}$ 恰好完全消耗，校正吸光度降为水平底线 $A_{\mathrm{corr}} = 0$：
$$0.950 - 0.950 V_{\mathrm{ep}} = 0 \implies V_{\mathrm{ep}} = 1.00\ \mathrm{mL}$$

(3) 根据化学计量点物料守恒比：
$$n(\mathrm{Bi^{3+}}) = n(\mathrm{EDTA}) \implies c_{\mathrm{Bi}} V_0 = c_{\mathrm{EDTA}} V_{\mathrm{ep}}$$
代入数据求浓度：
$$c_{\mathrm{Bi}} = \frac{c_{\mathrm{EDTA}} V_{\mathrm{ep}}}{V_0} = \frac{0.0100\ \mathrm{mol\cdot L^{-1}} \times 1.00\ \mathrm{mL}}{100.0\ \mathrm{mL}} = 1.00 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}}$$

**25.** 普通玻璃瓶从瓶壁方向看去几乎无色，但从瓶底方向看去（光线透过玻璃的光程较长）则显绿色。这种颜色与硅酸盐基质中 $\mathrm{Fe^{3+}}$ 的存在有关。试解释这一现象。

### 参考答案与精解

**解 1**：（1）$T = 10^{-A} = 10^{-0.380} = 0.417$。（2）$a = \dfrac{A}{bc} = \dfrac{0.380}{2.0\times1.0\times10^{-3}} = 1.9\times10^{2}\ \mathrm{L\cdot g^{-1}\cdot cm^{-1}}$。（3）$c = \dfrac{1.0\times10^{-3}}{55.85}\ \mathrm{mol\cdot L^{-1}}$，$\varepsilon = \dfrac{A}{bc} = \dfrac{0.380}{2.0\times1.0\times10^{-3}/55.85} = 1.1\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。

**解 2**：$c = \dfrac{25.5\times10^{-6}}{63.55\times0.050} = 8.02\times10^{-6}\ \mathrm{mol\cdot L^{-1}}$，$A = -\lg T = -\lg 0.505 = 0.297$，$\varepsilon = \dfrac{A}{bc} = \dfrac{0.297}{2\times8.02\times10^{-6}} = 1.8\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。桑德尔灵敏度 $S = \dfrac{M}{\varepsilon} = \dfrac{63.55}{1.8\times10^{4}} = 3.5\times10^{-3}\ \mathrm{\mu g\cdot cm^{-2}}$。

**解 3**：先求各波长下的摩尔吸光系数：$\varepsilon_{415}^{\mathrm{Ti}} = 8.21\times10^{2}$、$\varepsilon_{455}^{\mathrm{Ti}} = 4.64\times10^{2}$、$\varepsilon_{415}^{\mathrm{V}} = 1.60\times10^{2}$、$\varepsilon_{455}^{\mathrm{V}} = 2.40\times10^{2}$（单位 $\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$）。对合金建立联立方程：
$$\begin{cases} 0.645 = 8.21\times10^{2}\,c(\mathrm{Ti}) + 1.60\times10^{2}\,c(\mathrm{V}) \\ 0.555 = 4.64\times10^{2}\,c(\mathrm{Ti}) + 2.40\times10^{2}\,c(\mathrm{V}) \end{cases}$$
解得发色液中 $c(\mathrm{Ti}) = 5.37\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$、$c(\mathrm{V}) = 1.28\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$。折算回原试液（$20.0\ \mathrm{mL} \to 100\ \mathrm{mL}$，稀释 $5$ 倍）：$c_0(\mathrm{Ti}) = 2.69\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$、$c_0(\mathrm{V}) = 6.40\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$。

**解 4**：偶联产物浓度 $c = \dfrac{A}{\varepsilon l} = \dfrac{0.225}{1\times1.8\times10^{4}} = 1.3\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$。由 $4\ \mathrm{Ag^+} \sim 1$ 偶联产物及稀释 $1000$ 倍，饱和溶液中 $[\mathrm{Ag^+}] = 4\times1.3\times10^{-5}\times1000 = 5.2\times10^{-2}\ \mathrm{mol\cdot L^{-1}}$。乙酸银 $1:1$ 解离，$[\mathrm{CH_3COO^-}] = [\mathrm{Ag^+}]$，故 $K_{sp} = [\mathrm{Ag^+}]^2 = (5.2\times10^{-2})^2 = 2.7\times10^{-3}$。

**解 5**：设 $[\mathrm{OxyHb}] = x$、$[\mathrm{DeoxyHb}] = y$（光程 $1\ \mathrm{cm}$），由两波长吸光度加和性：
$$319x + 3227y = 0.406, \qquad 1214x + 693y = 1.20$$
解得 $x = 9.715\times10^{-4}$、$y = 2.978\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$。故 $\mathrm{SpO_2} = \dfrac{x}{x + y}\times100\% = 97.0\%$。

**解 6**：$\mathrm{pH} = 1$ 时全为 $\mathrm{HIn}$，$A = 0$ 故 $\varepsilon_{\mathrm{HIn}} = 0$；$\mathrm{pH} = 11$ 时全为 $\mathrm{In^-}$，样品浓度 $c = \dfrac{1.00\ \mathrm{mmol}}{100.0\ \mathrm{mL}}\times\dfrac{2.50}{25.0} = 1.00\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$，$\varepsilon_{\mathrm{In^-}} = \dfrac{0.840}{1.00\times1.00\times10^{-3}} = 840\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。$\mathrm{pH} = 7$ 时 $A = 0.588$，$[\mathrm{In^-}] = \dfrac{A}{\varepsilon l} = 7.0\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$，$[\mathrm{HIn}] = 3.0\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$，故 $\mathrm{p}K_a = \mathrm{pH} + \lg\dfrac{[\mathrm{HIn}]}{[\mathrm{In^-}]} = 7.00 + \lg\dfrac{3.0}{7.0} = 6.63$（即由 $K_a = \dfrac{[\mathrm{H^+}][\mathrm{In^-}]}{[\mathrm{HIn}]}$ 得 $\mathrm{p}K_a = 6.63$）。

**解 7**：酚酞在碱性条件下显色，显色体为碱式形体，故由下至上对应 $\mathrm{pH}$ 增大。应选取 $\lambda = 560\ \mathrm{nm}$（取值在 $550 \sim 575\ \mathrm{nm}$ 均可，即碱性形体的最大吸收处）。

**解 8**：由分布分数与朗伯-比尔定律：
$$A = \frac{\varepsilon l c\, K_{a,1} K_{a,2}}{K_{a,1} K_{a,2} + K_{a,1}[\mathrm{H^+}] + [\mathrm{H^+}]^2}$$

**解 9**：$\mathrm{pH}$ 较大时 $A$ 趋于稳定，近似 $K_{a,1}K_{a,2} \gg K_{a,1}[\mathrm{H^+}] + [\mathrm{H^+}]^2$，此时 $A \approx \varepsilon l c = 2.499$。将原式变形为线性式：
$$\frac{\varepsilon l c - A}{A[\mathrm{H^+}]} = \frac{1}{K_{a,2}} + \frac{[\mathrm{H^+}]}{K_{a,1}K_{a,2}}$$
对 $8.0 < \mathrm{pH} < 11.9$ 的数据回归得 $\dfrac{\varepsilon l c - A}{A[\mathrm{H^+}]} = 1.211\times10^{20}[\mathrm{H^+}] + 9.509\times10^{8}$，故 $K_{a,2} = 1.05\times10^{-9}$、$K_{a,1} = 7.85\times10^{-12}$，即 $\mathrm{p}K_{a,2} = 8.98$、$\mathrm{p}K_{a,1} = 11.10$。

**解 10**：未电离的酚酞基团通过与自身或其他分子的疏水环糊精空腔结合（疏水自缔合／包结），使其表观酸度发生变化；浓度越高缔合越强，$\mathrm{p}K_{a,1}$ 越大。两种浓度下 $\mathrm{p}K_{a,1} > \mathrm{p}K_{a,2}$，说明第一步电离（受疏水基团影响）比第二步电离更困难。

**解 11**：（1）$\mathrm{HCHO} + \mathrm{NH_2OH\cdot HCl} \rightarrow \mathrm{CH_2NOH} + \mathrm{HCl} + \mathrm{H_2O}$。（2）$2\mathrm{Mn^{2+}} + \mathrm{O_2} + 8\mathrm{OH^-} + 12\mathrm{CH_2NOH} \rightarrow 2[\mathrm{Mn(CH_2NO)_6}]^{2-} + 10\mathrm{H_2O}$。

**解 12**：先由标液定 $\varepsilon$：$A_s = \varepsilon b c_s$，$0.880 = \varepsilon\times1\times8.00\times10^{-5}$，$\varepsilon = 1.10\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$。示差法 $\Delta A = \varepsilon b\,\Delta c$，$\Delta c = \dfrac{0.200}{1.10\times10^{4}\times1} = 1.82\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$，$c_x = c_s + \Delta c = 1.60\times10^{-4} + 1.82\times10^{-5} = 1.78\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$。浓缩 $1\ \mathrm{L} \to 10\ \mathrm{mL}$ 即 $100$ 倍，故原水样 $\rho(\mathrm{Mn}) = 1.78\times10^{-4}\times54.94\times1000/100 = 9.77\times10^{-2}\ \mathrm{mg\cdot L^{-1}} < 0.1\ \mathrm{mg\cdot L^{-1}}$，**水样合格**。

**解 13**：（1）利用过硫酸铵的氧化性消除尿液中具有还原性的干扰物；（2）利用过硫酸铵的漂白作用消除尿样本身的颜色干扰。

**解 14**：（1）$\mathrm{H_3AsO_3} + 2\mathrm{Ce^{4+}} + \mathrm{H_2O} \rightarrow \mathrm{H_3AsO_4} + 2\mathrm{Ce^{3+}} + 2\mathrm{H^+}$；（2）$2\mathrm{Ce^{4+}} + 2\mathrm{I^-} \rightarrow 2\mathrm{Ce^{3+}} + \mathrm{I_2}$；（3）$\mathrm{H_3AsO_3} + \mathrm{I_2} + \mathrm{H_2O} \rightarrow \mathrm{H_3AsO_4} + 2\mathrm{I^-} + 2\mathrm{H^+}$。

**解 15**：由 $\rho = 45.715 - 311.09\lg A_t$ 代入六个吸光度得待测液 $\rho$ 分别为 $77.56$、$73.35$、$68.95$、$74.52$、$67.51$、$66.25\ \mathrm{\mu g\cdot L^{-1}}$；乘以稀释倍数 $2$ 得 $155.1$、$146.7$、$137.9$、$149.0$、$135.0$、$132.5\ \mathrm{\mu g\cdot L^{-1}}$；平均 $\overline{\rho} = 142.7\ \mathrm{\mu g\cdot L^{-1}}$。

**解 16**：$\mathrm{Ce^{4+}}$ 同时被 $\mathrm{H_3AsO_3}$（本底）与 $\mathrm{I^-}$（支路）消耗：
$$-\frac{\mathrm{d}c_t(\mathrm{Ce^{4+}})}{\mathrm{d}t} = (k_1 + k_2 c(\mathrm{I^-}))\,c_t(\mathrm{Ce^{4+}})$$
积分得 $\ln\dfrac{c_0(\mathrm{Ce^{4+}})}{c_t(\mathrm{Ce^{4+}})} = (k_1 + k_2 c(\mathrm{I^-}))t$；由朗伯-比尔定律 $\dfrac{c_0(\mathrm{Ce^{4+}})}{c_t(\mathrm{Ce^{4+}})} = \dfrac{A_0}{A_t}$，故 $\ln\dfrac{A_0}{A_t} = (k_1 + k_2 c(\mathrm{I^-}))t$。以无碘空白（$c(\mathrm{I^-}) = 0$）的吸光度 $A_F$ 消去 $k_1$，得：
$$c(\mathrm{I^-}) = \frac{\ln A_F - \ln A_t}{k_2 t} = \frac{\lg A_F - \lg A_t}{2.303\,k_2 t}$$

**解 17**：由上式 $\times 126.90\times10^{6}$ 换算单位：$\rho = 50\ \mathrm{\mu g\cdot L^{-1}}$ 时 $k_2 = \dfrac{\ln 1.460 - \ln 1.316}{50\times5}\times126.90\times10^{6} = 5.27\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot min^{-1}}$；$\rho = 100\ \mathrm{\mu g\cdot L^{-1}}$ 时 $k_2 = 5.45\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot min^{-1}}$。平均 $\overline{k_2} = 5.36\times10^{4}\ \mathrm{L\cdot mol^{-1}\cdot min^{-1}}$。

**解 18**：由朗伯-比尔定律 $A = \varepsilon l c_{\mathrm{CR}}$，即吸光度与 $c_{\mathrm{CR}}$ 成正比。各初始浓度下 $A(9.0\ \mathrm{min})/A(6.0\ \mathrm{min})$ 均约为 $0.405$（消耗比例相同），符合一级反应特征（半衰期与初始浓度无关），故 $\alpha = 1$。

**解 19**：$\gamma = 1$ 时 $-\dfrac{\mathrm{d}[\mathrm{CR}]}{\mathrm{d}t} = k[\mathrm{CR}][\mathrm{Mn(II)}]$，积分得 $\ln\dfrac{[\mathrm{CR}]_t}{[\mathrm{CR}]_0} = -k[\mathrm{Mn(II)}]t$；由 $A = \varepsilon l[\mathrm{CR}]$ 得 $\ln\dfrac{A_t}{A_{t+\Delta t}} = k[\mathrm{Mn(II)}]\,\Delta t$。

**解 20**：$\mathrm{Mn(II)}$ 定值时 $\ln\dfrac{A_t}{A_{t+\Delta t}} = k'\Delta t$。代入数据：$k'_{363.15} = \dfrac{1}{2}\ln\dfrac{0.686}{0.490} = 0.168\ \mathrm{min^{-1}}$，$k'_{373.15} = \dfrac{1}{2}\ln\dfrac{0.240}{0.090} = 0.490\ \mathrm{min^{-1}}$。由 $\ln\dfrac{k'_{373.15}}{k'_{363.15}} = \dfrac{E_a}{R}\left(\dfrac{1}{363.15} - \dfrac{1}{373.15}\right)$ 解得 $E_a \approx 1.2\times10^{5}\ \mathrm{J\cdot mol^{-1}} = 121\ \mathrm{kJ\cdot mol^{-1}}$。

**解 21**：$\mathrm{CO_2}$ 可逆吸放的总反应为 $\mathrm{MC\text{-}H^+} + \mathrm{HCO_3^-} \rightleftharpoons \mathrm{CO_2} + \mathrm{H_2O} + \mathrm{MC'}$（$\mathrm{MC'}$ 为非质子化光敏分子，$[\mathrm{MC'}] = [\mathrm{MC}] + [\mathrm{SP}]$）。其平衡常数：
$$K = \frac{[\mathrm{CO_2}][\mathrm{MC'}]}{[\mathrm{MC\text{-}H^+}][\mathrm{HCO_3^-}]} = \frac{[\mathrm{CO_2}][\mathrm{MC}](1 + K_0)}{[\mathrm{MC\text{-}H^+}][\mathrm{HCO_3^-}]} = \frac{K_a(\mathrm{MC\text{-}H^+})(1 + K_0)}{K_{a1}(\mathrm{CO_2})} = 1$$
故 $K_a(\mathrm{MC\text{-}H^+}) = \dfrac{K_{a1}(\mathrm{CO_2})}{1 + K_0}$。

**解 22**：设 $N$ 个入射光子中被吸收的光子数为 $N_{abs}$，由吸光度定义 $A(\lambda_1) = \lg\dfrac{I_0}{I} = \lg\dfrac{N}{N - N_{abs}}$，得 $N_{abs} = N\left(1 - 10^{-A(\lambda_1)}\right)$。生成 $\mathrm{PB^+}$ 的物质的量由 $\Delta A(\lambda_2) = \varepsilon(\lambda_2) l\,[\mathrm{PB^+}]$ 得 $n(\mathrm{PB^+}) = \dfrac{\Delta A(\lambda_2) V}{\varepsilon(\lambda_2) l}$，故：
$$\Phi = \frac{n(\mathrm{PB^+})}{N_{abs}} = \frac{\Delta A(\lambda_2) V}{\varepsilon(\lambda_2)\,l\,N\left(1 - 10^{-A(\lambda_1)}\right)}$$

**解 23**：外标与样品在 $\lambda_1$ 处吸收光子数相同。由 $\Phi(\mathrm{Ru^*}) = 1$ 得 $N = \dfrac{\Delta A(448)}{ \varepsilon(\mathrm{Ru^*},448)\,l\,(1 - 10^{-A(\lambda_1)})}$，代入 $\Phi$ 表达式消去 $N$、$V$、$l$ 与 $A(\lambda_1)$：
$$\Phi(\mathrm{PB^+}) = \frac{\Delta A(515)\,\varepsilon(\mathrm{Ru^*},448)}{\Delta A(448)\,\varepsilon(\mathrm{PB^+},515)} = \frac{13\times10^{-3}\times11300}{42\times10^{-3}\times26600} = 0.12 = 12\%$$

**解 24**：$c_{In} = 50.0\ \mathrm{\mu mol\cdot L^{-1}}$，$[\mathrm{Na^+}] = 92.0\ \mathrm{\mu mol\cdot L^{-1}}$。令 $x = [\mathrm{In^{2-}}]/[\mathrm{HIn^-}]$，由 $A_{620} = \varepsilon^{\mathrm{In^{2-}}}_{620}b[\mathrm{In^{2-}}]$、$A_{434} = \varepsilon^{\mathrm{HIn^-}}_{434}b[\mathrm{HIn^-}] + \varepsilon^{\mathrm{In^{2-}}}_{434}b[\mathrm{In^{2-}}]$ 及 $A_{620}/A_{434} = 2.84$：$1.70\times10^{4}x = 2.84(8.00\times10^{3} + 1.90\times10^{3}x)$，解得 $x = 1.96$。故 $\mathrm{pH} = \mathrm{p}K_{In} + \lg x = 6.70 + \lg 1.96 = 6.99$。

**解 25**：$\mathrm{Fe^{3+}}$ 为 $d^5$ 组态，在硅酸盐基质的弱场中取高自旋 $t_{2g}^3 e_g^2$，基谱项为 $^6A_{1g}$。任何 $d$-$d$ 激发都会把自旋多重度由六重改变为四重（$^6A_{1g} \rightarrow {}^4T$ 系列），属自旋禁阻跃迁，摩尔吸光系数很小。由 $A = \varepsilon c l$ 可知瓶壁方向光程短，弱吸收带累计的吸光度极小，玻璃看似无色；从瓶底方向看时光程显著增大，同一弱吸收带累积吸收增强，可见区部分波长被吸收，透射光呈补色而显绿色。
