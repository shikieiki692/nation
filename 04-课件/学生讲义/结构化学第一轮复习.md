## §1 元素周期律与元素周期系（考纲§4）

> **考纲§4** 4.1 了解1~18族、主族、副族、过渡元素、铂系元素、稀土元素的概念 | 4.2 了解同族元素、同周期元素的原子序数和性质变化之间的规律及对角规则 | 4.3 了解各区元素的基本化学性质

### 4.1 基本概念

| 概念 | 定义 |
|:---|:---|
| **族** | 纵列，共18列16族。主族（ⅠA-ⅦA）= 价电子数 = 族序数 |
| **副族** | ⅢB-ⅦB、ⅠB-ⅡB，含过渡元素 |
| **过渡元素** | d区 + ds区元素（ⅢB-ⅡB） |
| **铂系元素** | Ru、Rh、Pd、Os、Ir、Pt（第六周期Ⅷ族） |
| **稀土元素** | Sc、Y + 镧系（La-Lu，57-71号） |

**分区规则**：

| 区 | 最后填入电子 | 价电子构型 | 典型元素 |
|------|------|------|------|
| s | ns | ns¹⁻² | H、碱金属、碱土金属 |
| p | np | ns²np¹⁻⁶ | B-Ne、Al-Ar、Ga-Kr |
| d | (n-1)d | (n-1)d¹⁻⁹ns¹⁻² | Sc-Zn、Y-Cd |
| ds | (n-1)d¹⁰ | (n-1)d¹⁰ns¹⁻² | Cu、Zn、Ag、Cd、Au、Hg |
| f | (n-2)f | (n-2)f¹⁻¹⁴(n-1)d⁰⁻²ns² | 镧系、锕系 |

![[zgxg-periodic-table-blocks.jpg]]

### 4.2 周期律四大趋势

| 性质 | 同周期（→） | 同族（↓） | 反常点 |
|:---|:---|:---|:---|
| **原子半径** | 减小（核电荷增大） | 增大（能层增加） | 镧系收缩导致第五/六过渡系半径相近 |
| **第一电离能** | 总体增大 | 减小 | Be>B（全满）、N>O（半满）反常 |
| **电子亲和能** | 总体增大（放热增多） | 减小 | N(EA≈0，半满2p³稳定)；第二周期反常：F<Cl、O<S（原子半径小，电子排斥大） |
| **电负性** | 增大 | 减小 | F(4.0)最大；惰性气体通常不讨论 |

**电负性标度**：Pauling标度（最常用），χ(F)=4.0为基准。

![[zgxg-electronegativity-periodic-table.jpg]]

### 4.3 各区元素基本化学性质

- **s区**：活泼金属，+1/+2氧化态，形成离子化合物
- **p区**：多样性最高，非金属→类金属→金属，可形成共价/离子/金属键
- **d区**：可变氧化态，配合物形成能力强，催化活性
- **ds区**：+1/+2常见（Cu⁺/Cu²⁺、Zn²⁺、Ag⁺、Au³⁺）
- **f区**：+3为主，离子半径大，配位数高（8-12）

### 4.4 对角规则与镧系收缩

**对角规则**：左上→右下方向的元素性质相似
- Li-Mg、Be-Al、B-Si 三对最典型
- 原因：有效核电荷变化速率相近

**镧系收缩**：镧系元素新增电子进入(n-2)f轨道，f电子屏蔽效应差，导致有效核电荷持续增大，原子半径逐渐减小（La→Lu：1.06→0.86 Å），导致：
- 第五周期过渡元素（如Zr）与第六周期同族元素（如Hf）半径极其相近
- 性质高度相似，分离困难

## §2 原子结构（考纲§9）

> **考纲§9** 9.1 了解原子结构的基本知识，理解核外电子的运动状态，会用s、p、d、f等表示电子构型 | 9.2 了解电离能、电子亲合能、电负性的概念 | 9.3 了解原子半径、离子半径、共价半径的概念

### 9.1 四个量子数与轨道标签

| 量子数 | 符号 | 取值范围 | 物理意义 |
|------|------|------|------|
| 主量子数 | n | 1, 2, 3, … | 能层（电子离核远近） |
| 角量子数 | l | 0, 1, 2, …, n-1 | 能级/轨道形状（s=0, p=1, d=2, f=3） |
| 磁量子数 | mₗ | -l, …, 0, …, +l | 轨道空间取向 |
| 自旋量子数 | mₛ | +1/2 或 -1/2 | 电子自旋方向 |

![[11-13-orbital-shapes-s-p-d.jpg]]

**Pauli不相容原理**：同一原子中不能有两个电子具有完全相同的四个量子数。

### 9.2 电子排布三原则

| 原则 | 内容 |
|:---|:---|
| **Aufbau原理** | 电子优先填入能量最低的轨道 |
| **Pauli不相容原理** | 每个轨道最多容纳2个自旋相反的电子 |
| **Hund规则** | 简并轨道上电子优先单占且自旋平行 |

**轨道能量顺序**（1-36号）：1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p

![[aufbau.jpg]]

**特例**（半满/全满稳定化）：
- Cr: [Ar]3d⁵4s¹（非3d⁴4s²）
- Cu: [Ar]3d¹⁰4s¹（非3d⁹4s²）
- Mo: [Kr]4d⁵5s¹
- Ag: [Kr]4d¹⁰5s¹
- Pd: [Kr]4d¹⁰（5s⁰）

![[zgxg-transition-metal-elec-config.jpg]]

**常见离子电子构型**：
- 过渡金属先失ns电子，再失(n-1)d电子
- Fe²⁺: [Ar]3d⁶, Fe³⁺: [Ar]3d⁵（半满稳定）, Cu²⁺: [Ar]3d⁹, Cu⁺: [Ar]3d¹⁰（全满稳定）
- Cr³⁺: [Ar]3d³, Mn²⁺: [Ar]3d⁵（半满稳定）

**离子失电子顺序**：先失最外层ns电子，再失(n-1)d电子
- Fe: [Ar]3d⁶4s² → Fe²⁺: [Ar]3d⁶ → Fe³⁺: [Ar]3d⁵（半满稳定）

### 9.3 屏蔽效应与Slater规则

**屏蔽效应**：内层电子排斥外层电子，削弱核对外层电子的吸引力。

**有效核电荷**：Z* = Z - σ

**Slater规则**（计算σ）：
1. 将电子按 (1s)(2s,2p)(3s,3p)(3d)(4s,4p)… 分组
2. 同组右边电子对该电子的屏蔽：σ = 0.35（1s组内为0.30）
3. 相邻内组电子：σ = 0.85（(n-1)d和更内层为1.00）
4. 更内层电子：σ = 1.00

![[zgxg-slater-calculation.jpg]]

**示例**：Na (Z=11) 3s电子
- 电子排布：(1s)²(2s,2p)⁶(3s)¹
- σ = 2×1.00 + 6×0.85 = 7.10
- Z* = 11 - 7.10 = 3.90

### 9.4 电离能/电子亲和能/电负性

| 性质 | 定义 | 周期律 |
|:---|:---|:---|
| **电离能 (IE)** | 气态原子失去一个电子所需最低能量 | 同周期↑，同族↓ |
| **电子亲和能 (EA)** | 气态原子获得一个电子释放的能量 | 同周期总体↑（放热增多） |
| **电负性 (χ)** | 原子在分子中吸引电子的能力 | 同周期↑，同族↓ |

**IE反常解释**：
- Be(1s²2s²) > B(1s²2s²2p¹)：全满2s²稳定，且2p电子受2s电子屏蔽，更容易失去
- N(1s²2s²2p³) > O(1s²2s²2p⁴)：半满2p³稳定；O的第4个p电子与已有电子成对，配对排斥使其更容易失去

![[zgxg-electron-affinity-periodicity.jpg]]

![[zhao_ionization_energy_def.jpg]]

### 9.5 原子半径/离子半径/共价半径

| 类型 | 定义 | 大小关系 |
|:---|:---|:---|
| **原子半径** | 共价半径/金属半径/vdW半径 | r_vdW > r_metal > r_cov |
| **离子半径** | 晶体中离子间距离分配 | 阳离子 < 原子 < 阴离子 |
| **共价半径** | 共价键键长的一半 | — |

> 同一元素三种半径不同：vdW半径 > 金属半径 > 共价半径

**离子半径比较规则**：
- 电子层结构相同时，核电荷越大半径越小：Na⁺ > Mg²⁺ > Al³⁺
- 同族离子，从上到下半径增大：F⁻ < Cl⁻ < Br⁻

## §3 分子结构与化学键（考纲§10）

> **考纲§10** 10.1 了解共价键、离子键和金属键的概念 | 10.2 了解键长、键角、键级、键能的概念 | 10.3 了解键的极性和分子极性、分子偶极矩及其关系 | 10.4 了解价层电子对互斥理论、杂化轨道理论 | 10.5 了解分子轨道的概念和双原子体系的分子轨道各能级排布，会书写Lewis结构式 | 10.6 了解σ键、π键、离域π键、等电子体等概念

### 10.1 化学键分类

| 键型 | 本质 | 判断依据 | 典型 |
|:---|:---|:---|:---|
| **离子键** | 阴阳离子静电作用 | 电负性差 > 1.7（经验参考，不绝对） | NaCl |
| **共价键** | 原子共享电子对 | 电负性差 < 1.7 | H₂、H₂O |
| **金属键** | 金属阳离子与自由电子作用 | 金属元素 | Fe、Cu |

### 10.2 键参数

| 参数 | 定义 | 影响 |
|:---|:---|:---|
| **键长** | 两原子核间平衡距离 | 键长↓ → 键能↑ |
| **键角** | 相邻两键间夹角 | 决定分子空间构型 |
| **键能** | 断裂1mol键所需能量 | 键能↑ → 分子越稳定 |
| **键级** | 键的强度指标（MO理论：键级 = (成键电子-反键电子)/2） | 键级↑ → 键能↑ |

### 10.3 Lewis结构（五步法）

1. **算**：计算总价电子数
2. **排**：中心原子 + 配体排列
3. **连**：用单键连接
4. **填**：满足八隅体（H满足二隅体）
5. **查**：检查形式电荷，选最优共振式

**形式电荷**：FC = 价电子数 - 成键电子数/2 - 孤对电子数

### 10.6 σ键/π键/离域π键/等电子体

| 概念 | 定义 |
|:---|:---|
| **σ键** | 头对头重叠，可旋转，较强 |
| **π键** | 肩并肩重叠，不可旋转 |
| **离域π键 πₙᵐ** | n个原子m个电子的大π键。条件：共平面、每个原子至少一个p轨道、m < 2n |
| **等电子体** | 原子数相同、价电子数相同的微粒，结构相似 |

### 10.7 分子轨道理论（双原子）

**同核双原子MO能级顺序**（Z≤7，如B₂/C₂/N₂）：σ1s < σ*1s < σ2s < σ*2s < π2p < σ2p < π*2p < σ*2p

**同核双原子MO能级顺序**（Z≥8，如O₂/F₂）：σ1s < σ*1s < σ2s < σ*2s < σ2p < π2p < π*2p < σ*2p

> **注意**：N₂中π2p低于σ2p（s-p混杂使σ2p上移），O₂/F₂中σ2p低于π2p（2s-2p能级差增大，s-p混杂减弱）。

| 分子 | 电子排布 | 键级 | 磁性 |
|------|------|------|------|
| H₂ | KK(σ1s)² | 1 | 顺 |
| N₂ | KK(σ2s)²(σ*2s)²(π2p)⁴(σ2p)² | 3 | 顺 |
| O₂ | KK(σ2s)²(σ*2s)²(σ2p)²(π2p)⁴(π*2p)² | 2 | 顺（两个单电子） |
| F₂ | KK(σ2s)²(σ*2s)²(σ2p)²(π2p)⁴(π*2p)⁴ | 1 | 顺 |

### 10.8 键极性/分子极性/偶极矩

**键极性与分子极性**：键的极性由电负性差决定，分子极性由键矩的矢量叠加决定。对称分子（CO₂、BF₃、CCl₄）键矩相互抵消，偶极矩 μ=0；不对称分子（H₂O、NH₃）键矩不能完全抵消，μ>0。偶极矩单位为D（德拜）。

## §4 分子间作用力（考纲§11）

### 16.1 点阵与晶胞

- **点阵**：周期性排列的几何点
- **基元**：每个点阵点代表的结构单元
- **晶胞**：点阵的最小重复单元（平行六面体）

**晶胞参数**：a, b, c（边长）+ α, β, γ（夹角）

**七大晶系**：

| 晶系 | 边长关系 | 角度关系 |
|------|------|------|
| 立方 | a=b=c | α=β=γ=90° |
| 四方 | a=b≠c | α=β=γ=90° |
| 正交 | a≠b≠c | α=β=γ=90° |
| 六方 | a=b≠c | α=β=90°, γ=120° |
| 三方 | a=b=c | α=β=γ≠90° |
| 单斜 | a≠b≠c | α=γ=90°, β≠90° |
| 三斜 | a≠b≠c | α≠β≠γ≠90° |

**14种布拉维格子**：七大晶系共对应14种布拉维格子（简单P、体心I、面心F、底心C），其中立方晶系有简单立方(P)、体心立方(I)、面心立方(F)三种。

### 16.3 晶胞参数计算

**密度公式**：ρ = ZM / (Nₐ × V)
- Z = 每个晶胞中的结构单元数
- M = 摩尔质量
- Nₐ = 阿伏伽德罗常数
- V = 晶胞体积

**原子坐标参数**：分数坐标 (x, y, z)，表示原子在晶胞中的相对位置

### 15.1 晶格能与Born-Haber循环

**晶格能 U**：气态阴、阳离子形成1mol离子晶体释放的能量

**Born-Haber循环**（以NaCl为例）：
ΔH_f = ΔH_sub + IE + ½D + EA + (-U)

![[zgxg-born-haber-kcl.jpg]]

**影响因素**：离子电荷↑ → U↑；离子半径↓ → U↑；离子极化↑ → 共价成分↑，晶型可能改变

**离子极化效应**：正离子极化能力越强（半径小、电荷高、dⁿ构型）、负离子变形性越大（半径大），键型越偏向共价，导致晶型从NaCl型(6:6)→ZnS型(4:4)，配位数下降。典型实例：AgF(NaCl型)→AgI(ZnS型)

### §1 元素周期律

**题1**
(1) Al和Ga电离能相近：Ga填充3d后有效核电荷增加，3d电子云弥散对最外层4p电子屏蔽不完全，使Ga核对外层电子吸引力增强，抵消了因电子层数增加带来的原子半径增大效应。Tl电离能比In大：Tl存在6s²惰性电子对效应，6s电子因钻穿效应能量低更难失去。
(2) Cu: +2价因水合能+CFSE补偿第二电离能，且Cu²⁺配合物CFSE高；Ag: +1价因d¹⁰稳定构型，Ag²⁺与Ag⁺半径差距小水合能差值不足以补偿电离能；Au: +3价因平面四方CFSE高，受镧系收缩影响第一电离能高但第二三电离能相对不高。

**题25**
(1) H₂O沸点高于HF的原因：每个H₂O分子可形成4个氢键（2个H+2个孤对），构成三维氢键网络；每个HF只能形成2个氢键（1个H+1个孤对有效），形成链状结构。水的氢键网络更致密，需要更多能量破坏。
(2) F的电子亲和能小于Cl的原因：F原子半径极小(0.64Å)，电子云密度极高，加入一个电子后电子间排斥能很大，抵消了部分核吸引能。Cl原子半径较大(0.99Å)，电子间排斥较小，因此释放更多能量。
