## §1 第一过渡系通性与多价态—氧化还原主线

第一过渡系指第四周期从钪（Sc）到锌（Zn）的十个元素，其电子依次填入 $3d$ 轨道。与主族元素「一个元素对应一个主要价态」的模式截然不同，过渡金属的核心特征是**同一元素可以携带一整串价态**，而这些价态之间的相互转化为氧化还原反应提供了极丰富的素材。钛、钒、铬、锰四个元素恰好覆盖了第一过渡系左部，也完整展现了一条从「高价稳定」经「多价共存」到「低价稳定」的渐变主线。

形成多价态的根本原因在于 $(n-1)d$ 与 $ns$ 轨道能量相近。对于第四周期元素，$3d$ 与 $4s$ 的能量差很小，$4s$ 电子与 $3d$ 电子都可参与成键，因此最高氧化数等于 $ns$ 与 $(n-1)d$ 电子数之和：Ti 为 +4，V 为 +5，Cr 为 +6，Mn 为 +7。随着原子序数增大，有效核电荷上升，$3d$ 轨道逐步收缩下沉，价电子越来越难以全部失去，于是**最高氧化态的稳定性沿 Ti→V→Cr→Mn 方向递减，其氧化性则同步递增**。与之相对，**低氧化态（+2）的稳定性则沿同一方向递增**，到 Mn²⁺ 时，$3d^5$ 半满构型带来的交换能优势使其成为极难被氧化的稳定离子。

下表汇总四个元素的价电子构型、常见价态与其在本讲中的教学定位。

| 元素 | 价电子构型 | 最高氧化态 | 常见稳定价态 | 本讲主线特征 |
| :---: | :---: | :---: | :--- | :--- |
| Ti | $3d^24s^2$ | +4 | +4（$d^0$，无色）、+3 | 热力学活泼而动力学钝化；TiCl₄ 剧烈水解 |
| V | $3d^34s^2$ | +5 | +5、+4、+3、+2 | 单元素多价态颜色序列，推断题经典指纹 |
| Cr | $3d^54s^1$ | +6 | +3（最稳）、+6、+2 | 氧化还原身份随价态反转；酸碱互变双色信号 |
| Mn | $3d^54s^2$ | +7 | +7、+4、+2 | 价态最丰富；高锰酸根还原产物由介质决定 |

三条递变规律贯穿本讲，可以直接用于未知物的性质推断。第一条是最高氧化态的氧化性递增：TiO₂ 中的 Ti(IV) 几乎不显示氧化性，VO₂⁺ 具弱氧化性，Cr₂O₇²⁻ 为强氧化剂，MnO₄⁻ 则是水溶液体系中最强的氧化剂之一。第二条是低氧化态还原性递减：Ti³⁺ 与 V²⁺ 都极易被空气中的氧氧化，Cr²⁺ 更不稳定，而 Mn²⁺ 在酸性介质中异常稳定。第三条是最高价含氧酸（氢氧化物）的酸性递增：Ti(OH)₄ 两性偏碱，H₃VO₄ 两性偏酸，H₂CrO₄ 呈酸性，HMnO₄ 为强酸。这三条规律并非彼此独立，它们共同源于同一物理根源——从左到右有效核电荷增大、离子半径减小，中心原子的电荷密度持续升高，既增强了对电子的夺取倾向，也增强了对氧的极化能力，从而同时抬高了氧化性与含氧酸强度。

颜色是过渡金属最直观的信号，其来源需要区分两种机制。绝大多数水合离子的颜色来自 $d$-$d$ 跃迁：中心离子的 $d$ 轨道在配体场中发生分裂，电子在分裂能级间跃迁吸收可见光，$d^0$ 与 $d^{10}$ 构型没有可用的 $d$-$d$ 跃迁因而无色，$d^5$ 半满构型的跃迁自旋禁阻、吸收极弱因而颜色最浅。少数高价含氧酸根（如紫色的 MnO₄⁻、黄色的 VO₂⁺）的颜色则来自电荷迁移跃迁（LMCT），即配体氧的电子向高氧化态中心金属转移，这类跃迁完全允许、吸收极强，因此显色十分浓烈。推断题中判断颜色归属时，先看中心离子的 $d$ 电子数，再看是否属于高价含氧酸根，可以避免把两种机制混为一谈。

## §2 钛的热力学活泼性与动力学钝化

钛的化学由两个表面上互相矛盾的事实共同支配。其一是热力学上的活泼：标准电极电势 $E^\theta(\mathrm{Ti^{2+}/Ti}) = -1.63\ \mathrm{V}$，比锌（$-0.76\ \mathrm{V}$）还要负得多，说明钛失去电子的热力学倾向极强。其二是实际使用中的稳定：钛制的器皿在常温下既不被王水腐蚀，也不与氯气、氢氧化钠溶液反应，甚至可长期置于海水中而不生锈。解决这一矛盾的关键在于把「反应能不能发生」与「反应能不能开始」区分开来：前者由热力学判据决定，后者由动力学能垒即表面钝化膜决定。

钛的价态化学相对简单。Ti(IV) 为 $d^0$ 构型，是最稳定也是唯一广泛存在的价态，其水合离子无色，几乎不显示氧化还原活性；Ti(III) 为 $d^1$ 构型，六水合离子 $[\mathrm{Ti(H_2O)_6}]^{3+}$ 呈紫色，具强还原性，在空气中迅速被氧化为无色的 Ti(IV)，这一「紫色褪去」的现象是推断钛的重要信号。需要注意的是，$[\mathrm{Ti(H_2O)_6}]^{3+}$ 与 MnO₄⁻ 都是紫色，但前者是易被氧化褪色的还原剂，后者是强氧化剂，两者在氧化还原方向上的身份完全相反，仅凭颜色不足以判定，必须结合加还原剂或加酸后的变化加以区分。

钛的表面钝化源于一层致密且与基体结合牢固的 TiO₂ 氧化膜，它把内部金属与外界介质完全隔开，使腐蚀反应无法起始。但钝化并非绝对，以下三类介质可以破膜进而溶解钛：氢氟酸通过生成稳定的氟配离子 $[\mathrm{TiF_6}]^{2-}$ 破坏氧化膜，热浓盐酸通过生成 $[\mathrm{TiCl_6}]^{2-}$ 实现溶解，热浓硫酸则生成硫酸钛。对应的反应可以写成 $\mathrm{Ti} + 6\mathrm{HF} \rightarrow [\mathrm{TiF_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$ 与 $\mathrm{Ti} + 6\mathrm{HCl} \rightarrow [\mathrm{TiCl_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$。判据是：凡是能与 Ti(IV) 形成稳定配离子、从而降低产物活度的配体，都能推动钛的溶解。

钛的冶炼路线同样体现热力学判断的深度。从表面看，用碳还原二氧化钛似乎可行：$\mathrm{TiO_2} + 2\mathrm{C} \rightarrow \mathrm{Ti} + 2\mathrm{CO}\uparrow$。但生成的钛会立即与碳结合为热力学上更为稳定的碳化钛 TiC，其生成焓极负，使得碳还原的实际产物是 TiC 而非单质钛，还原路线被热力学阻断。工业上因此改用两段式的氯化—镁热还原法：第一段在高温下用氯气与碳处理矿石，把钛转化为易挥发的四氯化钛，$\mathrm{TiO_2} + 2\mathrm{Cl_2} + 2\mathrm{C} \rightarrow \mathrm{TiCl_4} + 2\mathrm{CO}$；第二段在惰性气氛中用镁还原，$\mathrm{TiCl_4} + 2\mathrm{Mg} \rightarrow \mathrm{Ti} + 2\mathrm{MgCl_2}$。这条路线之所以优越，关键在于 TiCl₄ 的沸点仅 136 °C，可以先行蒸馏提纯，从而把原料中的杂质在还原之前彻底除去，得到高纯海绵钛。

二氧化钛与四氯化钛是钛的两个核心化合物。TiO₂ 具有金红石型结构，其中每个钛原子被六个氧原子以八面体方式配位，每个氧原子与三个钛原子相连，配位比为 6∶3，单位晶胞内含 2 个 Ti⁴⁺ 与 4 个 O²⁻，晶体化学式为 TiO₂。TiO₂ 化学惰性极强、折射率高且无毒，是遮盖力最优异的白色颜料（俗称钛白粉），可替代有剧毒的铅白；它只溶于热的浓硫酸生成硫酸钛，对其他常见强酸稳定。TiCl₄ 是无色液体，熔点 −25 °C、沸点 136 °C，是典型的强路易斯酸，遇水发生剧烈水解并放出大量热，生成的氢氧化钛脱水为 TiO₂ 微粒与氯化氢酸雾共同形成浓厚的白色烟雾：

$$\mathrm{TiCl_4} + 2\mathrm{H_2O} \rightarrow \mathrm{TiO_2}\downarrow + 4\mathrm{HCl}\uparrow$$

水解剧烈的原因在于 Ti⁴⁺ 电荷高、半径小，电荷密度极大，对配位水分子有强烈的极化作用，使水分子中的氧氢键被削弱而易于断裂，从而在室温下即可自发进行。工业上以气相氧化法由四氯化钛制备钛白粉：$\mathrm{TiCl_4} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2} + 2\mathrm{Cl_2}$，副产的氯气可循环用于氯化段。钛的另一条重要定性检验是过氧化氢显色：在酸性条件下 Ti(IV) 与 H₂O₂ 生成橘黄色的过氧配合物 $[\mathrm{TiO(H_2O_2)}]^{2+}$，颜色特征明显，可用于比色分析。

![[8e0f112f90a5e68eabcc1f954ab833ca7d16bbeb76523b0f93eb63a0958d7bde.png]]
> 图 5-1：金红石型 TiO₂ 的晶胞结构（灰色球为钛、红色球为氧，钛呈正八面体六配位）

钛与硅在成键倾向上有明显共性，都因为存在能量可用的价层空轨道而易于接受配体孤对电子：两者的四卤化物都剧烈水解并产生白色烟雾（TiCl₄ 与 SiCl₄），都能形成稳定的六氟配离子（$[\mathrm{TiF_6}]^{2-}$ 与 $[\mathrm{SiF_6}]^{2-}$），最高氧化态也都很稳定。这一类比有助于理解为什么钛的化学在很大程度上与硅相似，而不是像同族更重的锆、铪那样更偏金属性。

| T1 | $\mathrm{TiCl_4} + 2\mathrm{H_2O} \rightarrow \mathrm{TiO_2}\downarrow + 4\mathrm{HCl}\uparrow$ | 白色烟雾，推断钛的指纹现象 |
| T2 | $\mathrm{TiCl_4} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2} + 2\mathrm{Cl_2}$ | 气相氧化法制钛白粉 |

| T5 | $\mathrm{TiO^{2+}} + \mathrm{H_2O_2} \rightarrow [\mathrm{TiO(H_2O_2)}]^{2+}$（橘黄） | 钛的定性检验与比色分析 |

## §3 钒的多价态颜色序列与催化中介化学

钒是「单元素多价态颜色序列」最系统的范例：在酸性溶液中以锌粉为还原剂逐级还原钒酸根，溶液颜色会按黄、蓝、绿、紫的顺序依次变化，每一步都对应钒的一个特定价态。这一序列是竞赛推断题中辨识度最高的指纹之一，其内在规律是**价态越高、$d$ 电子数越少、颜色越浅**。

| 氧化态 | 主要存在形式 | 颜色 | 备注 |
| :---: | :--- | :---: | :--- |
| +5 | VO₂⁺（酸性）或 VO₄³⁻（碱性） | 黄或无 | 最高价，含氧酸根形式最稳定 |
| +4 | VO²⁺ | 蓝 | 双原子氧钒离子，最稳定的中间价态 |
| +3 | V³⁺(aq) | 绿 | 具还原性 |
| +2 | V²⁺(aq) | 紫 | 强还原剂 |

还原过程的净反应可写作 $2\mathrm{VO_2^+} + 3\mathrm{Zn} + 8\mathrm{H^+} \rightarrow 2\mathrm{V^{2+}} + 3\mathrm{Zn^{2+}} + 4\mathrm{H_2O}$，随锌粉不断加入，溶液中依次出现黄色（VO₂⁺）、蓝色（VO²⁺）、绿色（V³⁺）、紫色（V²⁺）四种颜色。反向操作即用氧化剂（如过氧化氢或硝酸）逐步氧化，颜色按紫、绿、蓝、黄逆向复原，可据此判断样品处于哪一价态。

钒的零价到五价的电势关系可以用 Latimer 图表达。在酸性介质中，各相邻价态之间的标准电极电势为：

$$\mathrm{VO_2^+} \xrightarrow{+1.00} \mathrm{VO^{2+}} \xrightarrow{+0.34} \mathrm{V^{3+}} \xrightarrow{-0.26} \mathrm{V^{2+}} \xrightarrow{-1.18} \mathrm{V}$$

![[bc1691164978e033769dd51e0cffe8e4d29c303eb471a03b6076adc4ae14f5c3.jpg]]
> 图 5-2：钒在酸性介质中的 Latimer 图

Latimer 图提供了两条直接可用的判据。第一条是中间价态的歧化判据：若某一价态右侧的电势大于左侧的电势，则该价态会自发歧化。对本图而言，左侧电势始终大于右侧（$1.00 > 0.34 > -0.26$），因此 VO²⁺ 与 V³⁺ 都不会歧化，反而都是相对稳定的中间价态，这与 §3.1 中「+4 价最稳定」的实验事实一致。第二条是最强还原剂的识别：$E^\theta(\mathrm{V^{3+}/V^{2+}}) = -0.26\ \mathrm{V}$、$E^\theta(\mathrm{V^{2+}/V}) = -1.18\ \mathrm{V}$，V²⁺ 的还原能力甚至强于锌本身，这正是锌粉能把钒酸根一路还原到 V²⁺ 的热力学基础。此外，酸性 VO₂⁺ 具中等氧化性（+1.00 V），能氧化碘离子（$E^\theta(\mathrm{I_2/I^-}) = +0.54\ \mathrm{V}$）与亚铁离子（$+0.77\ \mathrm{V}$），但不能氧化氯离子（$+1.36\ \mathrm{V}$）；VO₂⁺ 到 V²⁺ 的三步平均电势为 $(1.00 + 0.34 - 0.26)/3 = +0.36\ \mathrm{V}$。

五氧化二钒是钒最重要的化合物，橙红色固体，两性偏酸，可溶于强碱生成钒酸盐：$\mathrm{V_2O_5} + 6\mathrm{NaOH} \rightarrow 2\mathrm{Na_3VO_4} + 3\mathrm{H_2O}$。它通常由偏钒酸铵热分解制得：$2\mathrm{NH_4VO_3} \xrightarrow{\Delta} \mathrm{V_2O_5} + 2\mathrm{NH_3}\uparrow + \mathrm{H_2O}\uparrow$。V₂O₅ 最重要的应用是作接触法制硫酸的催化剂，其作用机制是一个典型的变价氧化物氧转移循环：第一步 V(V) 把氧交给二氧化硫而自身被还原，$\mathrm{V_2O_5} + \mathrm{SO_2} \rightarrow \mathrm{V_2O_4} + \mathrm{SO_3}$；第二步空气中的氧把 V(IV) 重新氧化回 V(V)，$\mathrm{V_2O_4} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{V_2O_5}$。两步相加即为净反应 $\mathrm{SO_2} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{SO_3}$。从中可以看出，催化剂并未「不参与反应」，而是在循环的每一步都实际参与了化学变化，只是其净变化为零；钒在此扮演的是氧原子的传递中介，V(V) 与 V(IV) 的可逆切换正是过渡金属氧化物催化氧化的普遍模式。同一原理也用于萘氧化制邻苯二甲酸酐。

钒酸根在水溶液中随 pH 降低而逐步缩合，聚合度增大，这是多酸化学的入门范例。在高 pH 条件下以正钒酸根 VO₄³⁻（四面体构型）为主，溶液无色；随 pH 下降依次生成 V₂O₇⁴⁻、V₂O₆(OH)³⁻、V₃O₉³⁻，溶液转为淡黄；pH 进一步降低生成十钒酸根 V₁₀O₂₈⁶⁻，呈深红色；在强酸中则以黄色的 VO₂⁺ 为主。缩合的本质是在碱性条件下钒酸根以分立四面体存在，而酸化后质子化促使四面体之间共用顶角氧而聚合成更大的多核阴离子，聚合度与溶液的红色深度正相关。钒的另一类化合物是三氯氧钒，黄色液体，遇水剧烈水解：$2\mathrm{VOCl_3} + 3\mathrm{H_2O} \rightarrow \mathrm{V_2O_5} + 6\mathrm{HCl}$，其行为与 TiCl₄、SiCl₄ 类似，都是高价氯化物水解生成相应氧化物与氯化氢。

## §4 铬的价态—颜色—介质三联动

铬的价电子构型为 $3d^54s^1$，而非按规律填入所得的 $3d^44s^2$。这一「反常」来自半满 $d^5$ 构型在交换能上的额外稳定化：把 $4s$ 的一个电子移入 $3d$ 使 $3d$ 达到半满，体系总能量反而降低。这一构型在本讲中反复出现，是判断铬的化学行为的起点，也常被作为「反常电子构型」的经典考点。铬单质为银白色，是已知金属单质中硬度最大的元素，其原因是六个未成对电子贡献了极强的金属键。常温下铬表面覆盖一层致密的氧化膜，因此耐腐蚀，可溶于稀盐酸或稀硫酸生成绿色的 Cr(III)，但不溶于浓硝酸（钝化）。工业上以铝热法冶炼，$2\mathrm{Al} + \mathrm{Cr_2O_3} \rightarrow \mathrm{Al_2O_3} + 2\mathrm{Cr}$，实验室则通过碘化铬真空热分解获得高纯铬。

在铬的全部价态中，+3 价在酸、中、碱三种条件下都是最稳定的。六水合离子 $[\mathrm{Cr(H_2O)_6}]^{3+}$ 呈紫色，但常见的铬(III)盐如 $\mathrm{CrCl_3 \cdot 6H_2O}$ 呈绿色，稀溶液与久置溶液也呈绿色，原因是紫红色的水合离子会逐步发生水合异构转化，形成外界氯离子被水分子取代的绿色水合异构体。铬(III) 的氢氧化物具两性，$\mathrm{Cr^{3+}} + 3\mathrm{OH^-} \rightarrow \mathrm{Cr(OH)_3}\downarrow$（灰绿），继续加入过量碱则溶解为亮绿色的四羟基合铬酸根 $[\mathrm{Cr(OH)_4}]^-$。铬(III) 最引人注目的性质是其**动力学惰性**：$d^3$ 构型使晶体场稳定化能很高，配体交换速率极慢，配体交换半衰期可达 $10^5$ 秒（约 1 至 3 天），因此三种水合异构体可以被分离提纯，这在过渡金属水合离子中相当罕见。

铬(III) 与铝(III) 表面相似而本质相异，二者的对比是区分主族与过渡金属离子化学的典型范例。相同点是：二者的氢氧化物均具两性，均能溶于过量强碱；三价离子都能形成矾类复盐；都能发生双水解。不同点则集中体现过渡金属的特征：Cr³⁺ 有色而 Al³⁺ 无色；Cr³⁺ 动力学惰性而 Al³⁺ 配体交换极快；在碱性条件下 Cr(III) 可被过氧化氢氧化为 Cr(VI)，即具有还原性，而 Al³⁺ 不显示任何氧化还原活性。判断一道题中给出的是哪种三价离子，可以把「颜色」「配体交换快慢」「碱性介质中能否被氧化」三条并列检查。

铬(VI) 的化学展示了同一元素在不同价态下氧化还原身份的完全反转。在酸性介质中 Cr(VI) 以重铬酸根 Cr₂O₇²⁻ 存在，是强氧化剂，$E^\theta(\mathrm{Cr_2O_7^{2-}/Cr^{3+}}) = +1.33\ \mathrm{V}$；而在低氧化态一端，Cr(II) 是强还原剂，其 $E^\theta(\mathrm{Cr^{3+}/Cr^{2+}})$ 为负值，极易失电子被氧化。介于两者之间的 Cr(III) 则居中：遇到强氧化剂（如碱性过氧化氢）可被氧化到 +6，遇到强还原剂（如锌）可被还原到 +2。把 Cr 的各价态按电势从高到低排成一条数轴就可以看出，氧化还原角色并不由元素本身决定，而是由**该价态在电势数轴上的位置**决定：坐在高电势端的价态倾向得电子去氧化别人，坐在低电势端的价态倾向失电子去还原别人，居中的价态则视对手而变。这一认识是处理 Cr(VI)/Cr(III) 相互转化问题的核心。

铬酸根与重铬酸根之间的互变是铬化学中最典型的酸碱依赖平衡：

$$2\mathrm{CrO_4^{2-}}\ (\text{黄}) + 2\mathrm{H^+} \rightleftharpoons \mathrm{Cr_2O_7^{2-}}\ (\text{橙}) + \mathrm{H_2O},\quad K = 4.2 \times 10^{14}$$

平衡常数极大，说明在酸性条件下二聚形式占绝对优势。当 pH 大于 6 时以黄色的 CrO₄²⁻ 为主，pH 小于 1 时以橙色的 Cr₂O₇²⁻ 为主，因此可以用一句判据概括：加酸变橙、加碱变黄。二者的氧化性强弱也随之分化：酸性介质中的 Cr₂O₇²⁻ 是强氧化剂（$E^\theta = +1.33\ \mathrm{V}$），而碱性介质中的 CrO₄²⁻ 氧化性很弱（$E^\theta = -0.13\ \mathrm{V}$，还原为 Cr(OH)₃），这说明**同一个元素同一价态的氧化性也会被介质显著改变**。

| 物种 | 颜色 | 介质 | 氧化性 | $E^\theta$ |
| :---: | :---: | :---: | :---: | :---: |
| CrO₄²⁻ | 黄 | 碱性或中性 | 弱 | −0.13 V |
| Cr₂O₇²⁻ | 橙 | 酸性 | 强 | +1.33 V |

> 图 5-3：铬酸根与重铬酸根的酸碱互变平衡（$2[\mathrm{CrO_4}]^{2-} + 2\mathrm{H^+} \rightarrow [\mathrm{Cr_2O_7}]^{2-} + \mathrm{H_2O}$，加酸平衡右移使橙色加深，加碱左移使黄色加深）

重铬酸根的强氧化性有两个直接应用。其一是铁的测定：$\mathrm{Cr_2O_7^{2-}} + 6\mathrm{Fe^{2+}} + 14\mathrm{H^+} \rightarrow 2\mathrm{Cr^{3+}} + 6\mathrm{Fe^{3+}} + 7\mathrm{H_2O}$，橙色随还原过程转为绿色，是重铬酸钾滴定法的依据。其二是酒精检测，$\mathrm{Cr_2O_7^{2-}}$ 被乙醇还原同样呈现橙转绿的颜色变化：$2\mathrm{Cr_2O_7^{2-}} + 3\mathrm{C_2H_5OH} + 16\mathrm{H^+} \rightarrow 4\mathrm{Cr^{3+}} + 3\mathrm{CH_3COOH} + 11\mathrm{H_2O}$。与此对应的是铬(VI) 的毒性问题：Cr(VI) 兼具强氧化性与致癌性，含铬废液必须先经还原处理，标准做法是加入适量硫酸亚铁把 Cr(VI) 还原为无毒的 Cr(III)，再调节 pH 使其以 Cr(OH)₃ 形式沉淀除去，最终铬含量达到排放标准。

铬酸盐的溶解性提供了检验 CrO₄²⁻ 的沉淀信号。除碱金属、铵和镁的铬酸盐可溶外，其余金属的铬酸盐均难溶，其中三种具有鲜明颜色，可用于定性判断与沉淀滴定。加入银离子生成砖红色的 Ag₂CrO₄，是莫尔法沉淀滴定的指示剂；加入铅离子生成橙黄色的 PbCrO₄，即工业颜料铬黄；加入钡离子生成黄色的 BaCrO₄，可用于检验 CrO₄²⁻ 的存在，但需注意与白色的 BaSO₄ 区分。从平衡移动的角度看，这些沉淀的生成都会降低溶液中 CrO₄²⁻ 的浓度，从而拉动 §4 中的二聚平衡左移。

| 阳离子 | 沉淀 | 颜色 | 用途 |
| :---: | :--- | :---: | :--- |
| Ag⁺ | $\mathrm{Ag_2CrO_4}$ | 砖红 | 沉淀滴定指示剂（莫尔法） |
| Pb²⁺ | $\mathrm{PbCrO_4}$ | 橙黄 | 黄色颜料（铬黄） |
| Ba²⁺ | $\mathrm{BaCrO_4}$ | 黄 | 检验铬酸根 |

新鲜配制的六水合铬(III)离子呈淡紫色，久置后会变绿并逐渐变浑浊，这一过程并非简单的变色，而是铬(III) 逐步水解缩合的连续链。以碱逐步加入为例，铬(III)在溶液中的形态按如下顺序递进：先是配位水被氢氧根取代生成 $[\mathrm{Cr(H_2O)_5(OH)}]^{2+}$，进而缩合成双核羟桥配合物 $[\mathrm{Cr_2(OH)_2(H_2O)_8}]^{4+}$，再经配位水脱去质子形成氧桥 $[\mathrm{Cr_2O(H_2O)_{10}}]^{4+}$，最后聚合沉降为水合氢氧化铬$\mathrm{Cr(OH)_3 \cdot nH_2O}$沉淀。整条链的关键在于羟桥到氧桥的转变是不可逆的，一旦形成氧桥，铬(III) 就难以再回到单核状态。理解这一步在实际操作中有直接价值：如果要在水溶液中制备铬(III) 配合物，必须加入草酸根或乙酰丙酮等强配体竞争配位，阻断水解链的推进。

铬(VI) 的特征鉴定反应是利用其在酸性条件下与过氧化氢生成过氧化铬，再用乙醚萃取，有机层显深蓝色：

$$2\mathrm{Cr_2O_7^{2-}} + 8\mathrm{H_2O_2} + 4\mathrm{H^+} \rightarrow 4\mathrm{CrO_5} + 10\mathrm{H_2O}$$

过氧化铬的分子式为 CrO(O₂)₂，其中含两个过氧根 O₂²⁻（各 −2）与一个端基氧 O²⁻（−2），据此可以算出铬的氧化态为 +6 而非 +10。判断这类「高价态含过氧基」物种的价态时，必须先把过氧根按 −2 单独扣除，剩余的负电荷才由中心原子承担，这是竞赛中反复考查的记账要点。铬的另一类重要化合物是含金属—金属多重键的双核配合物，例如二醋酸铬(II) $\mathrm{Cr_2(OAc)_4 \cdot 2H_2O}$ 中含 Cr—Cr 四重键，键级为 4，由 σ、两组 π 与一组 δ 分子轨道叠加而成。其分子轨道能级顺序与 $d$ 轨道的面对面、肩并肩、面对肩三种重叠方式一一对应，是金属—金属多重键最经典的实例，也常用作 $d$ 轨道成键与磁性的分析素材。

铬的三步显色链是鉴别铬的核心操作流程：绿色的 Cr³⁺ 加入氢氧根生成灰绿色的 Cr(OH)₃ 沉淀，继续加过量碱溶解为亮绿色的 $[\mathrm{Cr(OH)_4}]^-$，再加入过氧化氢则被氧化为黄色的 CrO₄²⁻。三步颜色依次为绿、灰绿、亮绿、黄，每一步都对应一种确定的形态，是推断题中最常出现的铬信号组合。

## §5 锰的 pH 调控氧化还原体系

锰的价态覆盖从 +2 到 +7 几乎全部整数价态，是第一过渡系中价态最丰富的元素。但在竞赛中真正高频的考点集中在一点：**高锰酸根的还原产物由溶液介质决定，而不由还原剂的强弱决定**。

| 氧化态 | 代表物种 | 颜色 | 稳定性与行为 |
| :---: | :--- | :---: | :--- |
| +2 | Mn²⁺ | 淡粉（近无色） | 酸性中很稳定（$d^5$ 半满） |
| +3 | Mn³⁺ | 酒红 | 易歧化：$2\mathrm{Mn^{3+}} + 2\mathrm{H_2O} \rightarrow \mathrm{Mn^{2+}} + \mathrm{MnO_2} + 4\mathrm{H^+}$ |
| +4 | MnO₂ | 黑 | 中性条件下稳定 |
| +6 | MnO₄²⁻ | 绿 | 仅强碱中稳定，酸性歧化：$3\mathrm{MnO_4^{2-}} + 4\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + \mathrm{MnO_2}\downarrow + 2\mathrm{H_2O}$ |
| +7 | MnO₄⁻ | 紫 | 强氧化剂，颜色来自电荷迁移 |

酸性条件下稳定的是两端价态 Mn²⁺ 与 MnO₂，中间的 Mn³⁺ 与 Mn⁶⁺ 都易歧化；碱性条件下歧化趋势减弱，Mn(VI) 以绿色的锰酸根稳定存在。这一规律同样可以用电势图判断：凡右侧电势大于左侧电势的价态必歧化，而酸碱性改变会重新分配各相邻电对的电势，从而改变哪些价态能够稳定存在。

高锰酸钾在不同介质中的还原产物是本讲最高频的考点，必须按介质逐一对上。

| 介质 | 还原产物 | Mn 价态 | 转移电子数 | 颜色变化 | $E^\theta$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 强酸（pH < 1） | Mn²⁺ | +2 | 5 | 紫红转近无色 | +1.51 V |
| 中性或弱碱 | MnO₂ | +4 | 3 | 紫红转棕黑沉淀 | +0.59 V |
| 强碱 | MnO₄²⁻ | +6 | 1 | 紫红转绿 | +0.56 V |

三个还原半反应必须完整记忆：

$$\begin{aligned}\text{酸性：}\quad &\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5\mathrm{e^-} \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O} \\ \text{中性：}\quad &\mathrm{MnO_4^-} + 2\mathrm{H_2O} + 3\mathrm{e^-} \rightarrow \mathrm{MnO_2}\downarrow + 4\mathrm{OH^-} \\ \text{强碱：}\quad &\mathrm{MnO_4^-} + \mathrm{e^-} \rightarrow \mathrm{MnO_4^{2-}}\end{aligned}$$

为什么同一个氧化剂面对同一个还原剂会产生三种不同产物，关键在于介质改变了锰各价态之间电势梯度的形状。在强酸中，$\mathrm{MnO_4^-}$ 还原为 Mn²⁺ 的电势高达 +1.51 V，驱动力极大，反应可以一路走到最低价；在中性介质中电势梯度被压缩，反应进行到 MnO₂ 便停下；在强碱中驱动力进一步减弱，反应刚起步就停止在 MnO₄²⁻。因此判断产物时应先确定介质，再据此确定还原产物，最后才写方程式，产物与还原剂的强弱无关。

以亚硫酸钠为还原剂的完整反应可以写成三个形式，分别对应三种介质：酸性 $2\mathrm{MnO_4^-} + 5\mathrm{SO_3^{2-}} + 6\mathrm{H^+} \rightarrow 2\mathrm{Mn^{2+}} + 5\mathrm{SO_4^{2-}} + 3\mathrm{H_2O}$；中性 $2\mathrm{MnO_4^-} + 3\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow 2\mathrm{MnO_2}\downarrow + 3\mathrm{SO_4^{2-}} + 2\mathrm{OH^-}$；强碱 $2\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \rightarrow 2\mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}} + \mathrm{H_2O}$。这三个方程式的电子数分别为 10、6、2，与上表中转移电子数相对应，配平时可据此核对。此外，高锰酸根与 Mn²⁺ 共存时存在自催化效应，即反应初期生成少量 Mn²⁺ 之后反应速率显著加快，这是高锰酸钾滴定需要解释的现象之一。

![[0dd7814e42d9e05e77ad0df9be863b27efc03c9caf19e85556311fec38cc7662.jpg]]
> 图 5-5：高锰酸根三种介质还原产物的颜色对照（左近无色 $\mathrm{Mn^{2+}}$，中棕黑 $\mathrm{MnO_2}$ 沉淀，右绿色 $\mathrm{MnO_4^{2-}}$）

锰(II) 的鉴定依赖两个把 Mn²⁺ 氧化到高锰酸根的强氧化剂，都通过「近无色转紫红」这一颜色变化加以确认。一是铋酸钠法，在硝酸介质中铋酸钠把 Mn²⁺ 氧化：$2\mathrm{Mn^{2+}} + 5\mathrm{NaBiO_3} + 14\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$；二是过硫酸铵法，需要银离子催化：$2\mathrm{Mn^{2+}} + 5\mathrm{S_2O_8^{2-}} + 8\mathrm{H_2O} \rightarrow 2\mathrm{MnO_4^-} + 10\mathrm{SO_4^{2-}} + 16\mathrm{H^+}$。两种方法的现象完全一致，都是溶液由近无色转为特征的紫红色。

二氧化锰是锰最重要的氧化物之一，黑色固体，两性偏碱，兼具氧化性与催化性。其氧化性体现在与浓盐酸加热时可把氯离子氧化为氯气：$\mathrm{MnO_2} + 4\mathrm{HCl(浓)} \xrightarrow{\Delta} \mathrm{MnCl_2} + \mathrm{Cl_2}\uparrow + 2\mathrm{H_2O}$，此处 MnO₂ 是氧化剂而非催化剂，锰由 +4 降至 +2，这是实验室制氯气的经典反应。其催化性体现在可加速过氧化氢与氯酸钾的分解，但这两个反应的机理属后续轮次内容，本轮只需记住结论，不必展开。锰的另一种氧化物 Mn₃O₄ 为黑色，可看作 Mn₂O₃ 与 MnO 的结合，由碳酸锰受热分解并逐级氧化得到：$\mathrm{MnCO_3} \xrightarrow{\Delta} \mathrm{MnO} + \mathrm{CO_2}\uparrow$，随后 $4\mathrm{MnO} + \mathrm{O_2} \rightarrow 2\mathrm{Mn_2O_3}$，$\mathrm{Mn_2O_3} + \mathrm{MnO} \rightarrow \mathrm{Mn_3O_4}$。

尖晶石型锰酸锂 $\mathrm{LiMn_2O_4}$ 是锂电池正极材料，也是 37 届初赛的考点。其中锰的平均氧化态可由电中性条件求得：锂为 +1，氧共 −8，设锰平均为 $x$，则 $1 + 2x - 8 = 0$，解得 $x = +3.5$，说明锰以 +3 与 +4 按 1∶1 的比例混合存在，而非形式上的分数价。其合成路线为 $8\mathrm{MnO_2} + 2\mathrm{Li_2CO_3} \xrightarrow{\text{高温}} 4\mathrm{LiMn_2O_4} + 2\mathrm{CO_2}\uparrow + \mathrm{O_2}\uparrow$，需要注意碳与氧的守恒以确定氧气的计量系数。凡遇到含分数平均价态的混合价化合物，正确做法是先写出所有已知元素的价态与原子数，再由电中性条件反解中心元素的平均价态，最后按结构或磁学证据把平均价态拆分为具体价态组合。

高锰酸钾的工业制备以软锰矿为原料，先经碱熔氧化再电解。碱熔段把 MnO₂ 与氢氧化钾在约 240 °C 下通空气焙烧，生成暗绿色的锰酸钾：$2\mathrm{MnO_2} + 4\mathrm{KOH} + \mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{K_2MnO_4} + 2\mathrm{H_2O}$；水浸出后以锰酸钾为阳极液电解，阳极氧化得到紫色的高锰酸钾：$2\mathrm{K_2MnO_4} + 2\mathrm{H_2O} \xrightarrow{\text{电解}} 2\mathrm{KMnO_4} + 2\mathrm{KOH} + \mathrm{H_2}\uparrow$，粗品经重结晶提纯。在分析化学的操作层面，高锰酸钾滴定有一项必须遵守的限制：绝对不能用盐酸调节酸度。原因是酸性高锰酸根的标准电极电势（+1.51 V）高于氯的（$E^\theta(\mathrm{Cl_2/Cl^-}) = +1.36\ \mathrm{V}$），会把氯离子氧化为氯气而额外消耗标准溶液；若溶液中同时存在亚铁离子，氯离子还会被诱导氧化，使误差进一步放大。因此高锰酸钾滴定一律用硫酸调节酸度，且标准溶液需避光保存以防见光分解。

## §6 横向递变规律与周期趋势

把钛、钒、铬、锰并排观察，才能把零散的化合物性质上升为可以外推的周期趋势。四个元素在同一周期内从左到右排列，其价电子构型、特征价态、单质活泼性与最高价含氧酸强度都呈现单调的变化规律，下表给出可直接用于推断的对照关系。

| 对比维度 | Ti | V | Cr | Mn |
| :--- | :--- | :--- | :--- | :--- |
| 价电子构型 | $3d^24s^2$ | $3d^34s^2$ | $3d^54s^1$ | $3d^54s^2$ |
| 最高氧化态 | +4（$d^0$） | +5（$d^0$） | +6（$d^0$） | +7（$d^0$） |
| 最高价氧化物性质 | TiO₂ 两性偏碱，极稳定 | V₂O₅ 两性偏酸，中等氧化性 | CrO₃ 酸性，强氧化性 | Mn₂O₇ 强酸性，极不稳定 |
| 最稳定氧化态 | +4 | +4 | +3 | +2 |
| 单质钝化倾向 | 强（致密 TiO₂ 膜） | 有（浓硝酸、浓硫酸中钝化） | 有（表面氧化膜） | 无（接近镁） |
| 酸性介质中最稳定形态 | Ti(IV)（易水解） | VO₂⁺ 或 VO²⁺ | Cr³⁺（绿） | Mn²⁺（淡粉） |
| 碱性介质中最稳定形态 | TiO₃²⁻（偏钛酸根） | VO₄³⁻（钒酸根） | CrO₄²⁻（黄） | MnO₄²⁻（绿） |
| 特征颜色 | Ti³⁺ 紫 | V²⁺ 紫→V³⁺ 绿→VO²⁺ 蓝→VO₂⁺ 黄 | Cr³⁺ 绿、Cr₂O₇²⁻ 橙、CrO₄²⁻ 黄 | MnO₄⁻ 紫、MnO₂ 黑 |
| 最高价含氧酸强度 | 两性偏碱 | 两性偏酸 | 酸性 | 强酸 |
| $E^\theta(\mathrm{M^{2+}/M})$ | −1.63 V | −1.18 V | −0.91 V | −1.19 V |

最高价含氧酸（氢氧化物）的强度递变可以严格比较：

$$\mathrm{Ti(OH)_4}\ (\text{两性偏碱}) < \mathrm{H_3VO_4}\ (\text{两性偏酸}) < \mathrm{H_2CrO_4}\ (\text{酸性}) < \mathrm{HMnO_4}\ (\text{强酸})$$

造成这一递变的物理根源是中心原子的电荷密度。从左到右，中心原子的电荷数增加而离子半径减小，对氧的极化能力增强，使 O—H 键的电子云被拉向中心原子一侧，质子因此更容易解离，酸性随之增强。同一周期主族元素含氧酸的强度顺序（$\mathrm{HClO_4} > \mathrm{H_2SO_4} > \mathrm{H_3PO_4} > \mathrm{H_2SiO_3}$）与这一过渡系序列完全同构，可见「中心原子电荷密度决定含氧酸强度」是一条跨主族与过渡系的普遍规律。与之同步的是最高氧化态氧化性的递增：中心原子越缺电子、电荷密度越高，越倾向于夺取电子回到较稳定的低氧化态，因此 $\mathrm{TiO_2}$ 几乎无氧化性，而 $\mathrm{MnO_4^-}$ 成为水溶液中最强的氧化剂之一。

| :---: | :--- | :--- | :--- |
| 颜色 | 紫色溶液且具强氧化性 | MnO₄⁻（Mn +7） | 改变介质观察还原产物 |

**24.** 固体材料制备中常遇到非整比化合物，$\mathrm{Na_{1-x+y}Ca_{x/2}LaTiO_4}$ 就是其中一类高温超导体。将母体化合物 $\mathrm{NaLaTiO_4}$（Ⅰ）与无水 $\mathrm{Ca(NO_3)_2}$ 混合，密封加热至 350 °C 维持 3 天，水洗除去杂质，得到 $\mathrm{Ca^{2+}}$ 交换产物 $\mathrm{Na_{1-x}Ca_{x/2}LaTiO_4}$（Ⅱ）；光谱实验证明（Ⅰ）中有 86% 的 Na 被交换而产生离子空位。将（Ⅱ）放入 300 °C 的钠蒸气中数天，$\mathrm{Na^+}$ 插入空位使物质由白变黑，光谱实验证明有 88% 的离子空位被 $\mathrm{Na^+}$ 插入，生成目标化合物 $\mathrm{Na_{1-x+y}Ca_{x/2}LaTiO_4}$（Ⅲ）。（1）制备时为何选用 $\mathrm{Ca(NO_3)_2}$ 而不用其他钙盐？（2）产物（Ⅲ）中 $x$ 和 $y$ 分别是多少？（3）化合物（Ⅱ）中的离子空位被 $\mathrm{Na^+}$ 插入时，为保持晶体电中性，部分 Ti 的化合价发生改变，求化合物（Ⅲ）中高、低价态钛离子的个数比。

**25.** [37届初赛3-1] 以 $\mathrm{Li_2CO_3}$ 和 $\mathrm{MnO_2}$ 为原料，充分混合后在 720 °C 下煅烧 3 h，冷却至室温后即可得到复合氧化物 $\mathrm{LiMn_2O_4}$（LMO）。（1）写出合成 $\mathrm{LiMn_2O_4}$ 的方程式；（2）用酸处理 LMO 时，除离子交换反应之外还会发生一个副反应，该副反应导致固体中 Mn 的平均氧化态有所升高，写出该副反应对应的化学方程式，并说明这一副反应对再生后的 HMO 锂富集性能的影响。

### 参考答案与精解

**1.** 先用浓硫酸处理钛铁矿粉：$\mathrm{FeTiO_3} + 3\mathrm{H_2SO_4} \xrightarrow{\Delta} \mathrm{Ti(SO_4)_2} + \mathrm{FeSO_4} + 3\mathrm{H_2O}$。过程中加入铁粉防止 $\mathrm{Fe^{2+}}$ 被氧化，低温下结晶析出 $\mathrm{FeSO_4 \cdot 7H_2O}$；过滤后稀释并加热，使 $\mathrm{Ti(SO_4)_2}$ 水解转化为 $\mathrm{TiOSO_4}$，进一步沉淀出偏钛酸 $\mathrm{H_2TiO_3}$；将偏钛酸煅烧脱水即得钛白粉：$\mathrm{H_2TiO_3} \xrightarrow{\text{煅烧}} \mathrm{TiO_2} + \mathrm{H_2O}$。整条路线可概括为酸解、除铁、水解、煅烧四步。

**2.** 高温下二氧化钛与炭粉的混合物与氯气反应：$\mathrm{TiO_2} + 2\mathrm{C} + 2\mathrm{Cl_2} \xrightarrow{\Delta} \mathrm{TiCl_4} + 2\mathrm{CO}$；二氧化钛与四氯化碳共热也能生成四氯化钛：$\mathrm{TiO_2} + \mathrm{CCl_4} \xrightarrow{\Delta} \mathrm{TiCl_4} + \mathrm{CO_2}\uparrow$。两条途径的共同点是都需要氯化剂，差别在于前者以炭作还原剂把氧带走，后者直接用四氯化碳兼作氯化剂与还原剂。

**3.** 金属钒与氧气在 660 °C 共热得五氧化二钒：$4\mathrm{V} + 5\mathrm{O_2} \xrightarrow{660\ \text{°C}} 2\mathrm{V_2O_5}$；五氧化二钒溶于热的氢氧化钠溶液生成偏钒酸根：$\mathrm{V_2O_5} + 2\mathrm{OH^-} \xrightarrow{\Delta} 2\mathrm{VO_3^-} + \mathrm{H_2O}$；用盐酸中和至 pH 为 7.5~8，过滤后把滤液加热至 70~80 °C，在搅拌下加入氯化铵溶液，析出偏钒酸铵：$\mathrm{VO_3^-} + \mathrm{NH_4^+} \rightarrow \mathrm{NH_4VO_3}\downarrow$。

**4.** 铬铁矿制备重铬酸钾按氧化焙烧、酸化、复分解三步进行。第一步将铬铁矿与纯碱置于铁坩埚中在空气中加热：$4\mathrm{Fe(CrO_2)_2} + 8\mathrm{Na_2CO_3} + 7\mathrm{O_2} \xrightarrow{\Delta} 8\mathrm{Na_2CrO_4} + 2\mathrm{Fe_2O_3} + 8\mathrm{CO_2}$，产物中铬酸钠与氧化铁结成块状物，置于水中煮沸浸取后滤去氧化铁，得铬酸钠溶液。第二步向铬酸钠溶液中加酸：$2\mathrm{Na_2CrO_4} + 2\mathrm{H^+} \rightarrow \mathrm{Na_2Cr_2O_7} + \mathrm{H_2O} + 2\mathrm{Na^+}$。第三步向重铬酸钠溶液中加入氯化钾：$\mathrm{Na_2Cr_2O_7} + 2\mathrm{KCl} \rightarrow \mathrm{K_2Cr_2O_7} + 2\mathrm{NaCl}$。分离提纯的关键在于重铬酸钾的溶解度随温度变化较大，蒸发浓缩后趁热过滤除去氯化钠等杂质，再将滤液冷却即可析出重铬酸钾晶体。

**5.** 各步转化方程式依次为：$\mathrm{Cr^{3+}} + 3\mathrm{OH^-} \rightarrow \mathrm{Cr(OH)_3}\downarrow$ 与 $\mathrm{Cr(OH)_3} + 3\mathrm{H^+} \rightarrow \mathrm{Cr^{3+}} + 3\mathrm{H_2O}$；$\mathrm{Cr(OH)_3} + \mathrm{OH^-} \rightarrow \mathrm{CrO_2^-} + 2\mathrm{H_2O}$ 与 $\mathrm{CrO_2^-} + \mathrm{H^+} + \mathrm{H_2O} \rightarrow \mathrm{Cr(OH)_3}\downarrow$；$2\mathrm{CrO_2^-} + 3\mathrm{H_2O_2} + 2\mathrm{OH^-} \rightarrow 2\mathrm{CrO_4^{2-}} + 4\mathrm{H_2O}$ 与 $2\mathrm{CrO_4^{2-}} + 3\mathrm{Zn} + 4\mathrm{OH^-} \rightarrow 2\mathrm{CrO_2^-} + 3\mathrm{ZnO_2^{2-}} + 2\mathrm{H_2O}$；$2\mathrm{CrO_4^{2-}} + 2\mathrm{H^+} \rightarrow \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O}$ 与 $\mathrm{Cr_2O_7^{2-}} + 2\mathrm{OH^-} \rightarrow 2\mathrm{CrO_4^{2-}} + \mathrm{H_2O}$；$\mathrm{Cr_2O_7^{2-}} + 3\mathrm{SO_3^{2-}} + 8\mathrm{H^+} \rightarrow 2\mathrm{Cr^{3+}} + 3\mathrm{SO_4^{2-}} + 4\mathrm{H_2O}$ 与 $10\mathrm{Cr^{3+}} + 6\mathrm{MnO_4^-} + 11\mathrm{H_2O} \rightarrow 6\mathrm{Mn^{2+}} + 5\mathrm{Cr_2O_7^{2-}} + 22\mathrm{H^+}$。

**6.** 各步转化方程式依次为：$\mathrm{MnO_4^-}$ 与 $\mathrm{Mn^{2+}}$ 之间，$2\mathrm{MnO_4^-} + 5\mathrm{SO_3^{2-}} + 6\mathrm{H^+} \rightarrow 2\mathrm{Mn^{2+}} + 5\mathrm{SO_4^{2-}} + 3\mathrm{H_2O}$ 与 $2\mathrm{Mn^{2+}} + 5\mathrm{NaBiO_3} + 14\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$；$\mathrm{MnO_4^-}$ 与 $\mathrm{MnO_4^{2-}}$ 之间，$2\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \rightarrow 2\mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}} + \mathrm{H_2O}$ 与 $2\mathrm{MnO_4^{2-}} + \mathrm{Cl_2} \rightarrow 2\mathrm{MnO_4^-} + 2\mathrm{Cl^-}$；$\mathrm{MnO_4^-}$ 与 $\mathrm{MnO_2}$ 之间，$2\mathrm{MnO_4^-} + 3\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow 2\mathrm{MnO_2}\downarrow + 3\mathrm{SO_4^{2-}} + 2\mathrm{OH^-}$ 与 $3\mathrm{MnO_2} + 6\mathrm{KOH} + \mathrm{KClO_3} \xrightarrow{\text{熔融}} 3\mathrm{K_2MnO_4} + \mathrm{KCl} + 3\mathrm{H_2O}$；$\mathrm{MnO_4^{2-}}$ 与 $\mathrm{MnO_2}$ 之间，$\mathrm{MnO_4^{2-}} + \mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow \mathrm{MnO_2}\downarrow + \mathrm{SO_4^{2-}} + 2\mathrm{OH^-}$ 与 $2\mathrm{MnO_2} + 4\mathrm{KOH} + \mathrm{O_2} \xrightarrow{\text{熔融}} 2\mathrm{K_2MnO_4} + 2\mathrm{H_2O}$；$\mathrm{MnO_2}$ 与 $\mathrm{Mn^{2+}}$ 之间，$\mathrm{MnO_2} + \mathrm{H_2O_2} + 2\mathrm{H^+} \rightarrow \mathrm{Mn^{2+}} + 2\mathrm{H_2O} + \mathrm{O_2}\uparrow$ 与 $\mathrm{Mn^{2+}} + 2\mathrm{OH^-} + \mathrm{H_2O_2} \rightarrow \mathrm{MnO_2}\downarrow + 2\mathrm{H_2O}$。这一组转化完整覆盖了锰由 +2 到 +7 的全部价态通道，其方向由介质决定。

**7.** （1）先用浓硫酸与草酸把重铬酸钾还原为硫酸铬：$\mathrm{K_2Cr_2O_7} + \mathrm{H_2SO_4}\ (\text{浓}) + \mathrm{H_2C_2O_4} \rightarrow \mathrm{Cr_2(SO_4)_3}$；再向其中加入氯化钡使硫酸根沉淀：$\mathrm{Cr_2(SO_4)_3} + \mathrm{BaCl_2} \rightarrow \mathrm{BaSO_4}\downarrow + \mathrm{CrCl_3}$；最后浓缩结晶得 $\mathrm{CrCl_3 \cdot 6H_2O}$。（2）高锰酸钾与浓盐酸反应：$2\mathrm{KMnO_4} + 16\mathrm{HCl} \rightarrow 2\mathrm{KCl} + 2\mathrm{MnCl_2} + 5\mathrm{Cl_2}\uparrow + 8\mathrm{H_2O}$，浓缩结晶即得氯化锰。

**8.** 向紫色溶液中滴加 $\mathrm{FeCl_3}$ 溶液，若紫色褪去则原溶液为 $\mathrm{TiCl_3}$ 溶液，发生 $\mathrm{Ti^{3+}} + \mathrm{Fe^{3+}} + \mathrm{H_2O} \rightarrow \mathrm{TiO^{2+}} + \mathrm{Fe^{2+}} + 2\mathrm{H^+}$；若紫色不褪去则为高锰酸钾溶液。鉴别依据是 $\mathrm{Ti^{3+}}$ 具强还原性、可被 $\mathrm{Fe^{3+}}$ 氧化为无色的 $\mathrm{TiO^{2+}}$，而 $\mathrm{MnO_4^-}$ 是强氧化剂，不与 $\mathrm{Fe^{3+}}$ 反应。

**9.** 钛白为二氧化钛 $\mathrm{TiO_2}$，属惰性颜料；锌白为氧化锌 $\mathrm{ZnO}$；锌钡白为硫化锌与硫酸钡的复合物 $\mathrm{ZnS \cdot BaSO_4}$。钛白作为白色颜料的优点在于折射率高、着色力与遮盖力强，且化学性质稳定、无毒，可替代有毒的铅白。

**10.** 三氯化钛可由金属钛还原四氯化钛制得：$\mathrm{Ti} + 2\mathrm{Cl_2} \xrightarrow{\text{高温}} \mathrm{TiCl_4}$，$3\mathrm{TiCl_4} + \mathrm{Ti} \xrightarrow{600\ \text{°C}} 4\mathrm{TiCl_3}$；金属钛在加热条件下与盐酸反应也可得到紫色的三氯化钛溶液。钛酸钡可按两步制备：$\mathrm{Ti} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2}$，$\mathrm{TiO_2} + \mathrm{BaCO_3} \xrightarrow{\text{熔融}} \mathrm{BaTiO_3} + \mathrm{CO_2}\uparrow$。

**11.** （1）$\mathrm{TiCl_3 \cdot 6H_2O}$ 存在三种水合异构体：$[\mathrm{Ti(H_2O)_6}]\mathrm{Cl_3}$ 呈紫色，$[\mathrm{Ti(H_2O)_5Cl}]\mathrm{Cl_2 \cdot H_2O}$ 与 $[\mathrm{Ti(H_2O)_4Cl_2}]\mathrm{Cl \cdot 2H_2O}$ 呈绿色。冷却析出的是全水合异构体，故为紫色；乙醚萃取改变了结晶时的配位环境，析出的是含氯配体的绿色异构体。（2）$\mathrm{Ti^{3+}}$ 的还原能力强于 $\mathrm{Sn^{2+}}$，可把 $\mathrm{Cu^{2+}}$ 还原为 $\mathrm{Cu^+}$ 并生成白色的氯化亚铜沉淀：$\mathrm{Ti^{3+}} + \mathrm{Cu^{2+}} + \mathrm{Cl^-} + \mathrm{H_2O} \rightarrow \mathrm{TiO^{2+}} + \mathrm{CuCl}\downarrow + 2\mathrm{H^+}$。（3）高锰酸根把蓝色的 $\mathrm{VO^{2+}}$ 氧化为黄色的 $\mathrm{VO_2^+}$：$\mathrm{MnO_4^-} + 5\mathrm{VO^{2+}} + \mathrm{H_2O} \rightarrow \mathrm{Mn^{2+}} + 5\mathrm{VO_2^+} + 2\mathrm{H^+}$。（4）高锰酸根逐级把钒由低氧化态氧化到高氧化态，体系颜色依次经过 $\mathrm{V^{2+}}$ 的紫色、$\mathrm{V^{3+}}$ 的绿色、$\mathrm{VO^{2+}}$ 的蓝色，最后到 $\mathrm{VO_2^+}$ 的黄色，对应的反应分别为 $5\mathrm{V^{2+}} + \mathrm{MnO_4^-} + 8\mathrm{H^+} \rightarrow 5\mathrm{V^{3+}} + \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$、$5\mathrm{V^{3+}} + \mathrm{MnO_4^-} + \mathrm{H_2O} \rightarrow 5\mathrm{VO^{2+}} + \mathrm{Mn^{2+}} + 2\mathrm{H^+}$、$5\mathrm{VO^{2+}} + \mathrm{MnO_4^-} + \mathrm{H_2O} \rightarrow 5\mathrm{VO_2^+} + \mathrm{Mn^{2+}} + 2\mathrm{H^+}$。（5）黄棕色的五氧化二钒先溶于浓盐酸生成三氯氧钒的黄色溶液：$\mathrm{V_2O_5} + 6\mathrm{HCl} \rightarrow 2\mathrm{VOCl_3} + 3\mathrm{H_2O}$；随后三氯氧钒分解放出氯气并得到氯化氧钒的蓝色溶液：$2\mathrm{VOCl_3} \rightarrow 2\mathrm{VOCl_2} + \mathrm{Cl_2}\uparrow$，两式合并即 $\mathrm{V_2O_5} + 6\mathrm{HCl} \rightarrow 2\mathrm{VOCl_2} + \mathrm{Cl_2}\uparrow + 3\mathrm{H_2O}$。

**12.** （1）溶液变为紫色，有 $\mathrm{TiCl_3}$ 生成：$2\mathrm{TiCl_4} + \mathrm{Zn} \xrightarrow{\mathrm{HCl}} 2\mathrm{TiCl_3} + \mathrm{ZnCl_2}$。（2）有紫色沉淀生成：$\mathrm{TiCl_3} + 3\mathrm{NaOH} \rightarrow \mathrm{Ti(OH)_3}\downarrow + 3\mathrm{NaCl}$。（3）紫色沉淀被硝酸氧化后得到无色溶液：$3\mathrm{Ti(OH)_3} + 7\mathrm{HNO_3} \rightarrow 3\mathrm{TiO(NO_3)_2} + \mathrm{NO}\uparrow + 8\mathrm{H_2O}$；再加入稀碱又得到白色沉淀：$\mathrm{TiO^{2+}} + 2\mathrm{OH^-} + \mathrm{H_2O} \rightarrow \mathrm{Ti(OH)_4}\downarrow$。

**13.** 五价钒在酸性介质中以 $\mathrm{VO_2^+}$ 存在，四价钒以 $\mathrm{VO^{2+}}$ 存在。通入 $\mathrm{SO_2}$ 时因 $E^\theta(\mathrm{VO_2^+/VO^{2+}}) > E^\theta(\mathrm{SO_4^{2-}/SO_2})$ 而发生还原，生成蓝色溶液：$2\mathrm{VO_2^+} + \mathrm{SO_2} \rightarrow 2\mathrm{VO^{2+}} + \mathrm{SO_4^{2-}}$。锌汞齐则因 $E^\theta(\mathrm{VO_2^+/V^{2+}}) > E^\theta(\mathrm{Zn^{2+}/Zn})$ 把钒一路还原到二价，得到紫色溶液：$2\mathrm{VO_2^+} + 3\mathrm{Zn(Hg)} + 8\mathrm{H^+} \rightarrow 2\mathrm{V^{2+}} + 3\mathrm{Zn^{2+}} + 4\mathrm{H_2O}$。两溶液相混时因 $E^\theta(\mathrm{VO^{2+}/V^{3+}}) > E^\theta(\mathrm{V^{3+}/V^{2+}})$ 而发生归中，四价钒被二价钒还原为三价钒，得到绿色溶液：$\mathrm{VO^{2+}} + \mathrm{V^{2+}} + 2\mathrm{H^+} \rightarrow 2\mathrm{V^{3+}} + \mathrm{H_2O}$。

**14.** （1）向含 $\mathrm{Cr^{3+}}$ 与 $\mathrm{Al^{3+}}$ 的溶液中加入过量 $\mathrm{NaOH}$ 与 $\mathrm{H_2O_2}$，$\mathrm{Cr^{3+}}$ 被氧化为 $\mathrm{CrO_4^{2-}}$，$\mathrm{Al^{3+}}$ 转化为 $\mathrm{AlO_2^-}$：$2\mathrm{CrO_2^-} + 3\mathrm{H_2O_2} + 2\mathrm{OH^-} \rightarrow 2\mathrm{CrO_4^{2-}} + 4\mathrm{H_2O}$、$\mathrm{Al^{3+}} + 4\mathrm{OH^-} \rightarrow \mathrm{AlO_2^-} + 2\mathrm{H_2O}$；加热分解过量的 $\mathrm{H_2O_2}$ 后将溶液调至弱酸性并加入 $\mathrm{BaCl_2}$，$\mathrm{CrO_4^{2-}}$ 转化为 $\mathrm{BaCrO_4}$ 沉淀而铝留在溶液中：$\mathrm{CrO_4^{2-}} + \mathrm{Ba^{2+}} \rightarrow \mathrm{BaCrO_4}\downarrow$。（2）向含 $\mathrm{Cr^{3+}}$ 与 $\mathrm{Mn^{2+}}$ 的溶液中加入过量 $\mathrm{NaOH}$，$\mathrm{Mn^{2+}}$ 生成沉淀而 $\mathrm{Cr^{3+}}$ 生成可溶性物质留在溶液中：$\mathrm{Mn^{2+}} + 2\mathrm{OH^-} \rightarrow \mathrm{Mn(OH)_2}\downarrow$、$\mathrm{Cr^{3+}} + 4\mathrm{OH^-} \rightarrow [\mathrm{Cr(OH)_4}]^-$。（3）向含 $\mathrm{Mn^{2+}}$ 与 $\mathrm{Cu^{2+}}$ 的溶液中加入一定量 $1\ \mathrm{mol \cdot L^{-1}}$ 盐酸并通入 $\mathrm{H_2S}$，$\mathrm{Cu^{2+}}$ 生成硫化铜沉淀而 $\mathrm{Mn^{2+}}$ 在酸性条件下不沉淀：$\mathrm{Cu^{2+}} + \mathrm{H_2S} \rightarrow \mathrm{CuS}\downarrow + 2\mathrm{H^+}$。

**15.** 四种方法的反应方程式分别为：过硫酸铵法 $2\mathrm{Mn^{2+}} + 5\mathrm{S_2O_8^{2-}} + 8\mathrm{H_2O} \xrightarrow[\Delta]{\mathrm{Ag^+}} 2\mathrm{MnO_4^-} + 10\mathrm{SO_4^{2-}} + 16\mathrm{H^+}$；二氧化铅法 $2\mathrm{Mn^{2+}} + 5\mathrm{PbO_2} + 4\mathrm{H^+} + 5\mathrm{SO_4^{2-}} \xrightarrow{\Delta} 2\mathrm{MnO_4^-} + 5\mathrm{PbSO_4} + 2\mathrm{H_2O}$；铋酸钠法 $2\mathrm{Mn^{2+}} + 5\mathrm{NaBiO_3} + 14\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$。就优缺点而言：过硫酸铵法需要银离子催化并加热，反应速率慢；二氧化铅法需要加热，且生成硫酸铅沉淀影响观察；铋酸钠法氧化能力强、反应快、无需加热，是三种固体氧化剂中效果最好的，最适合作为锰(II)的鉴定方法。高锰酸钾本身虽也能在特定条件下氧化锰(II)，但实操中不如铋酸钠法简便，因此教材中通常把它与过硫酸铵、二氧化铅、铋酸钠并列比较而非优先推荐。

**16.** 三种黄色铬酸盐的鉴别依据是它们在酸、碱中的溶解性差异。若固体溶于醋酸，则为 $\mathrm{SrCrO_4}$：$2\mathrm{SrCrO_4} + 2\mathrm{H^+} \rightarrow 2\mathrm{Sr^{2+}} + \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O}$。若分别加入硝酸与氢氧化钠固体均溶解，则为 $\mathrm{PbCrO_4}$：$2\mathrm{PbCrO_4} + 2\mathrm{H^+} \rightarrow 2\mathrm{Pb^{2+}} + \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O}$、$\mathrm{PbCrO_4} + 4\mathrm{OH^-} \rightarrow [\mathrm{Pb(OH)_4}]^{2-} + \mathrm{CrO_4^{2-}}$。若固体溶于硝酸但在硫酸中转化为白色沉淀，则为 $\mathrm{BaCrO_4}$：$2\mathrm{BaCrO_4} + 2\mathrm{H_2SO_4} \rightarrow 2\mathrm{BaSO_4}\downarrow + \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O} + 2\mathrm{H^+}$。三步鉴别正好利用了两性（铅）、碱土金属硫酸盐难溶（钡）与普通可溶盐（锶）三种性质。

**17.** $\mathrm{TiF_4}$ 熔点最高，说明它是离子型化合物：$\mathrm{Ti^{4+}}$ 极化能力很强，而 $\mathrm{F^-}$ 半径小、变形性很小，两者形成的化合物以离子键为主，故熔点高。其余三个卤化物均为共价型分子晶体，熔点明显偏低；按 $\mathrm{Cl^-}$、$\mathrm{Br^-}$、$\mathrm{I^-}$ 顺序，卤离子半径依次增大，相应的 $\mathrm{TiCl_4}$、$\mathrm{TiBr_4}$、$\mathrm{TiI_4}$ 分子体积依次增大、分子间范德华力依次增强，因此熔点依次升高（−25 °C < 39 °C < 150 °C）。

**18.** （1）$\mathrm{V^{2+}/V}$ 电对的电势很负，钒溶于盐酸时被氧化为三价：$2\mathrm{V} + 6\mathrm{H^+} \rightarrow 2\mathrm{V^{3+}} + 3\mathrm{H_2}\uparrow$。（2）利用相邻电对的电势按电子数加权平均：$E^\theta(\mathrm{V^{3+}/V}) = \dfrac{(-0.26) \times 1 + (-1.175) \times 2}{1 + 2} = -0.87\ \mathrm{V}$。（3）三价钒与四价钒均不发生歧化：对 $\mathrm{V^{3+}}$ 而言左侧电势 +0.34 V 大于右侧 −0.26 V；对 $\mathrm{VO^{2+}}$ 而言左侧 +1.00 V 大于右侧 +0.34 V，两侧电势关系均满足中间价态稳定的条件。（4）金属钒与三价钒发生归中反应生成二价钒：$\mathrm{V} + 2\mathrm{V^{3+}} \rightarrow 3\mathrm{V^{2+}}$。

**19.** （1）pH 越小时质子化程度越高、聚合度越小，主要以黄色的 $\mathrm{VO_2^+}$ 存在；pH 越大时以四面体构型的 $\mathrm{VO_4^{3-}}$ 存在。（2）$\mathrm{VO_4^{3-}}$ 为正四面体结构；$\mathrm{V_2O_7^{4-}}$ 由两个四面体共用一个顶角氧而成；$\mathrm{V_3O_{10}^{5-}}$ 由三个四面体共顶连成链状。随着 pH 降低，质子化促使四面体之间共用顶角氧而逐步聚合，聚合度依次增大。（3）颜色加深源于聚合度增大：分立的 $\mathrm{VO_4^{3-}}$ 四面体中钒氧之间仅发生定域跃迁，吸收落在紫外区而显无色；缩合后相邻四面体之间形成 $\mathrm{V-O-V}$ 桥连，电子离域范围随聚合度扩大，跃迁能量相应降低、吸收带向长波移动并进入可见区，于是溶液依次呈现淡黄、深红。

**20.** 盐酸浓度为 $1\ \mathrm{mol \cdot L^{-1}}$ 时，$\mathrm{Cr_2O_7^{2-}/Cr^{3+}}$ 电对与 $\mathrm{Cl_2/Cl^-}$ 电对的标准电势相等（均为 1.36 V），考虑到由 $\mathrm{Cl^-}$ 生成 $\mathrm{Cl_2}$ 时存在超电势，$\mathrm{K_2Cr_2O_7}$ 不能氧化该浓度盐酸中的氯离子。盐酸浓度为 $12\ \mathrm{mol \cdot L^{-1}}$ 时，$c(\mathrm{H^+}) = c(\mathrm{Cl^-}) \approx 12\ \mathrm{mol \cdot L^{-1}}$，由能斯特方程 $E(\mathrm{Cr_2O_7^{2-}/Cr^{3+}}) = 1.36 + \dfrac{0.059}{6}\lg (12)^{14} = 1.51\ \mathrm{V}$，而 $E(\mathrm{Cl_2/Cl^-}) = 1.36 + \dfrac{0.059}{2}\lg\dfrac{1}{12^{2}} = 1.30\ \mathrm{V}$。因 1.51 V 大于 1.30 V，故在浓盐酸中 $\mathrm{K_2Cr_2O_7}$ 可以把氯离子氧化为氯气。这一结果表明，含氧酸根的氧化性随介质变化的幅度有时足以跨越反应能否发生的界限，因此判断氧化还原方向时必须同时给出介质条件。

**21.** 各物质为：（A）$\mathrm{TiCl_4}$，（B）$\mathrm{TiO_2}$，（C）$\mathrm{TiCl_3}$，（D）$\mathrm{CuCl}$，（E）$\mathrm{TiO(NO_3)_2}$。推理链条为：无色液体（A）在高温下与氧气反应生成不溶于水的白色粉末（B），符合 $\mathrm{TiCl_4}$ 的性质；锌粉与盐酸把钛还原为紫色的 $\mathrm{TiCl_3}$（C）；$\mathrm{Ti^{3+}}$ 把 $\mathrm{Cu^{2+}}$ 还原为白色的 $\mathrm{CuCl}$（D）；$\mathrm{TiCl_3}$ 被过量硝酸氧化为无色的 $\mathrm{TiO(NO_3)_2}$（E）；后者蒸干并高温加热又分解回到 $\mathrm{TiO_2}$；$\mathrm{TiCl_4}$ 与铝粉高温反应也可把钛还原为三价，得到 $\mathrm{TiCl_3}$。

**22.** 有关的化学反应方程式为：溶解二氧化钛 $\mathrm{TiO_2} + \mathrm{H_2SO_4} \rightarrow \mathrm{TiOSO_4} + \mathrm{H_2O}$；隔绝空气下用铝还原 $3\mathrm{TiO^{2+}} + \mathrm{Al} + 6\mathrm{H^+} \rightarrow 3\mathrm{Ti^{3+}} + \mathrm{Al^{3+}} + 3\mathrm{H_2O}$；用铁(III)滴定 $\mathrm{Ti^{3+}} + \mathrm{Fe^{3+}} + \mathrm{H_2O} \rightarrow \mathrm{TiO^{2+}} + \mathrm{Fe^{2+}} + 2\mathrm{H^+}$；指示剂显色 $\mathrm{Fe^{3+}} + 6\mathrm{SCN^-} \rightarrow [\mathrm{Fe(SCN)_6}]^{3-}$。测定方法的依据是两级电势关系：因为 $E^\theta(\mathrm{TiO^{2+}/Ti^{3+}}) > E^\theta(\mathrm{Al^{3+}/Al})$，铝能把四价钛定量还原为三价钛；又因为 $E^\theta(\mathrm{Fe^{3+}/Fe^{2+}}) > E^\theta(\mathrm{TiO^{2+}/Ti^{3+}})$，铁(III)能把三价钛定量氧化回四价。当三价钛反应完全后，过量的铁(III)与硫氰酸根生成红色配合物，溶液由无色变为红色即为终点。

**23.** （1）五氧化二钒的还原产物中钒为四价且离子只带一个单位正电荷，即 $\mathrm{VO^+}$。草酸法：$\mathrm{V_2O_5} + 2\mathrm{C_2O_4^{2-}} + 6\mathrm{H^+} \rightarrow 2\mathrm{VO^+} + 4\mathrm{CO_2}\uparrow + 3\mathrm{H_2O}$，再用高锰酸钾滴定过量的草酸：$5\mathrm{C_2O_4^{2-}} + 2\mathrm{MnO_4^-} + 16\mathrm{H^+} \rightarrow 2\mathrm{Mn^{2+}} + 10\mathrm{CO_2}\uparrow + 8\mathrm{H_2O}$。碘量法：$\mathrm{V_2O_5} + 4\mathrm{I^-} + 6\mathrm{H^+} \rightarrow 2\mathrm{VO^+} + 2\mathrm{I_2} + 3\mathrm{H_2O}$，再用硫代硫酸钠滴定生成的碘：$\mathrm{I_2} + 2\mathrm{S_2O_3^{2-}} \rightarrow \mathrm{S_4O_6^{2-}} + 2\mathrm{I^-}$。草酸定量法属返滴定，必须准确加入过量的草酸再用高锰酸钾返滴，故草酸用量需要定量；碘量法属间接滴定，被钒(V)氧化出的碘与硫代硫酸钠的计量关系直接确定，因此碘化钾需过量而不必定量。（2）由滴定数据得 $n(\mathrm{Ce^{4+}}) = 0.100 \times 41.3 \times 10^{-3} = 4.13 \times 10^{-3}\ \mathrm{mol}$。设氧化物中氧的缺位数为 $n$，则 $\mathrm{V_2O_{5-n}}$ 的摩尔质量为 $181.88 - 16.00n\ \mathrm{g \cdot mol^{-1}}$；该氧化物中钒的平均氧化态为 $5 - n$，被四价铈完全氧化到 +5 时每摩尔氧化物需转移 $2n\ \mathrm{mol}$ 电子，因此 $\dfrac{2.648}{181.88 - 16.00n} \times 2n = 4.13 \times 10^{-3}$，解得 $n = 0.14$，故氧化物组成为 $\mathrm{V_2O_{4.86}}$。

**24.** （1）选用硝酸钙是因为硝酸盐受热易分解完全，未反应的过量部分也易被水洗去，不会在产物中残留难溶杂质而影响物相纯度。（2）母体（Ⅰ）中 86% 的钠离子被 $\mathrm{Ca^{2+}}$ 交换，故 $x = 0.86$；由于每个 $\mathrm{Ca^{2+}}$ 置换两个 $\mathrm{Na^+}$ 而只占据一个阳离子位，留下的空位比例为 $0.86/2 = 0.43$，其中 88% 被 $\mathrm{Na^+}$ 插入，故 $y = 0.43 \times 0.88 = 0.38$。（3）化合物（Ⅰ）中钛为 +4 价。化合物（Ⅲ）中插入的 0.38 mol $\mathrm{Na^+}$ 带来等量正电荷，为保持电中性必须有等量钛被还原，故 0.38 mol 钛降为 +3 价、其余 0.62 mol 仍为 +4 价，高、低价态钛离子的个数比为 $0.62 : 0.38 = 31 : 19$。

**25.** （1）$2\mathrm{Li_2CO_3} + 8\mathrm{MnO_2} \rightarrow 4\mathrm{LiMn_2O_4} + 2\mathrm{CO_2}\uparrow + \mathrm{O_2}\uparrow$。配平要点是先由电中性条件确定 $\mathrm{LiMn_2O_4}$ 中锰的平均氧化态为 +3.5（锂为 +1、氧共 −8，故 $1 + 2x - 8 = 0$，解得 $x = +3.5$），说明锰由 +4 被还原；锂与碳均已处于最高氧化态，唯一能被氧化的物种是氧（−2），故氧化产物为氧气，据此配平氧与电子。（2）酸处理时的副反应是锰的歧化：$2\mathrm{LiMn_2O_4} + 4\mathrm{H^+} \rightarrow 3\mathrm{MnO_2} + \mathrm{Mn^{2+}} + 2\mathrm{Li^+} + 2\mathrm{H_2O}$，其中 Mn(+3.5) 歧化为 Mn(+4) 与 Mn(+2)，固体中锰的平均氧化态由 +3.5 升至 +4，与题意相符。该副反应使部分 HMO 转变为 $\mathrm{MnO_2}$（或变为 $x < 1$ 的 $\mathrm{H_xMn_2O_4}$），而二氧化锰难以再与锂离子反应重新生成 LMO，因此再生后材料的锂富集性能下降。
