## §1 方法总纲：推断四步法

**关联知识点**：元素推断

**主线**：推断题不是「回忆元素性质」的记忆题，而是「由现象证据锁定唯一答案」的推理题。题目给的每一个现象都是**信号**，你的任务是把信号按优先级组织起来，先建候选、再排除、后验证。

### 1.1 推断题的本质

1. 题目现象（颜色/沉淀/气体/焰色/磁性/溶解性）

2. 信号 → 候选元素列表（≤4 个）

3. 否定排除 + 交叉验证 → 唯一元素

4. 价态 + 化合物 + 关键方程式（反向验证全链）

三条基本准则：

1. **现象 ≠ 结论**：每一个现象都要问「它还可能是谁？」（单一颜色通常 2-4 种可能）。

2. **否定信息与肯定信息同等重要**：「不溶解」「无沉淀」「无色」是排除法的利器。

3. **最后一题验证全链**：推断结果必须能解释**所有**题目条件（包括否定信息），否则回头重查。

### 1.2 推断四步法（核心方法论）

| 步骤 | 核心操作 | 依据 KP | 检查点 |
|:---:|:---|:---|:---|
| **① 提取信号** | 通读题目，标出所有现象与条件；把「不/无/没有」全部圈出；确认介质（酸/碱/中性）、温度、浓度 | 元素化学 | ☐ 颜色 ☐ 沉淀 ☐ 气体 ☐ 焰色 ☐ 磁性 ☐ 所有「不」字 ☐ 介质/条件 |
| **② 最强信号 → 候选列表** | 从五类信号中选最特征的一条，查信号-响应矩阵，列出可能元素（**≤4 个**） | 焰色反应 · 难溶物 · 过渡金属通性 | ☐ 最强信号已识别 ☐ 候选 2-4 个 ☐ 每个候选都有依据 |
| **③ 否定排除 + 交叉验证** | 用其他信号（尤其否定信息）逐条排除候选；矛盾时回到硬约束重查 | 铬 · 锰 · 铁 · 铜 · 主族元素化学 | ☐ 每个候选都过至少一条其他信号 ☐ 否定信息已用 ☐ 剩余候选 ≤2 |
| **④ 定价态 + 反向验证** | 根据介质与氧化还原行为定氧化态；写关键方程式；逐条回核全部条件 | 价态-氧化态-形式电荷 · 元素化学 | ☐ 价态与介质一致 ☐ 颜色与电子构型一致 ☐ 全部条件被解释 ☐ 结果唯一 |

推断四步法的闭环关系见图 1（抓取信号 → 建立候选池 → 否定排除 → 反向验证）。

**值得注意（假熟悉陷阱）**：**第一眼最像的元素，往往不是最后答案。**

命题人最常用的手法就是「制造熟题错觉」——给你一个「看起来很熟」的信号（比如黄色沉淀），让你第一反应写 PbI₂，再用第二条证据推翻。破解：**先列 2-3 个候选再下笔**，永远不要凭第一个念头锁定答案。

**值得注意（推断即排除）**：**推断题不是记忆题，而是排除题。**

肯定信号只负责「把谁请进候选」，否定信号才决定「把谁赶出去」。只写「这个元素是 X」不够，必须写「为什么不是 Y/Z」——排除理由正是过程分所在。

## §2 颜色信号法

**关联知识点**：过渡金属通性

**主线**：颜色是最直观的信号，但**多数颜色不具有唯一性**。正确用法：颜色定候选范围，再靠沉淀行为/配位行为/氧化行为交叉锁定。

### 2.1 常见离子 / 固体颜色速查

| 颜色 | 可能物种 | 优先级 | 需配合的验证 |
|:---|:---|:---:|:---|
| 蓝色 | Cu²⁺（aq）、[Cu(NH₃)₄]²⁺（深蓝） | 强指向 | 加 NaOH 浅蓝沉淀；加 NH₃ 变深蓝 |
| 紫色 | MnO₄⁻（氧化性）、[Ti(H₂O)₆]³⁺（还原性） | 强指向 | 加酸是否褪色（MnO₄⁻ 酸性被还原褪色） |
| 绿色 | Cr³⁺、Ni²⁺、Fe²⁺（浅绿）、MnO₄²⁻（绿） | 弱指向 | 加 NaOH：Cr³⁺→灰绿沉淀溶于过量碱；Fe²⁺→白→绿→红棕 |
| 黄色 | Fe³⁺（水解黄棕）、CrO₄²⁻、VO₂⁺、Br₂ 水（橙黄） | 需区分 | 加 SCN⁻→血红（Fe³⁺）；加酸变橙（CrO₄²⁻） |
| 橙色 | Cr₂O₇²⁻、Br₂ | 强指向 | 加碱变黄（CrO₄²⁻） |
| 粉红 | Co²⁺、Mn²⁺（极淡） | 需区分 | 加 NH₃：Co²⁺→土黄→空气中变红 |
| 血红色 | Fe³⁺ + SCN⁻ | **唯一性** | 加 F⁻/PO₄³⁻ 褪色（掩蔽） |
| 黑色固体 | Fe₃O₄、FeO、CuO、MnO₂、PbS、CuS、Ag₂S | 需区分 | 结合其他线索（与酸反应/催化行为） |
| 白色固体/沉淀 | Zn²⁺/Al³⁺/Mg²⁺/Ca²⁺/Ba²⁺ 盐、TiO₂、SiO₂、AgCl、BaSO₄ | 弱指向 | 加酸/加过量碱/加氨水区分 |

**颜色进阶两问**：①这是**水合离子**的颜色还是**固体**的颜色？（固体中电荷转移色更深更艳，如 PbCrO₄ 黄、Fe₃O₄ 黑）②是 d-d 跃迁还是电荷转移？（MnO₄⁻ 的紫是 O→Mn 电荷转移，不是 d-d）。（见图 3）

### 2.2 信号优先级（四层）

| 优先级 | 信号类型 | 示例 | 可靠性 |
|:---:|:---|:---|:---:|
| 1 | **唯一性** | 焰色黄→Na；血红色→Fe³⁺+SCN⁻；NO 遇空气变红棕 | 几乎无干扰 |
| 2 | **组合信号** | 灰绿沉淀 + 溶于过量 NaOH → Cr³⁺ 指纹 | 两个特征 = 可靠 |
| 3 | **强指向** | 蓝色溶液→Cu²⁺；紫色→MnO₄⁻ | 少数干扰 |
| 4 | **弱指向** | 白色沉淀、无色溶液 | 需配合其他信号（见图 2） |

**值得注意（单一颜色不能定案）**：绿色溶液不是 Cr³⁺ 专属，而是 Cr³⁺、Ni²⁺、Fe²⁺（浅绿）、MnO₄²⁻ 四种可能，区分靠沉淀行为。

| 绿色来源 | 加 NaOH 后的沉淀行为 |
|:---|:---|
| Cr³⁺ | 灰绿沉淀，**溶于过量 NaOH**（两性） |
| Fe²⁺ | 白色沉淀**迅速变灰绿再变红棕**（被空气氧化） |
| Ni²⁺ | 浅绿色沉淀，不溶过量碱 |

单一颜色只能开「候选账户」，交叉验证才负责「结账」。

### 2.3 颜色驱动的推断策略

1. 紫色 → MnO₄⁻（氧化剂）或 [Ti(H₂O)₆]³⁺（还原剂）——用「是否褪色」区分；

2. 蓝色 → Cu²⁺——加 NH₃ 变深蓝确认；

3. 黄色/橙黄 → Fe³⁺ 或 Cr(VI)——加 SCN⁻ 确认 Fe³⁺，加酸变橙确认 CrO₄²⁻；

4. 血红色 → Fe³⁺ + SCN⁻——**唯一性信号**，直接锁定 Fe³⁺；

5. 白→灰绿→红棕 → Fe(OH)₂ 被空气氧化 → 原溶液含 Fe²⁺。

## §3 沉淀信号法与气体信号法

**关联知识点**：主族元素化学 · 难溶物

**主线**：沉淀的**颜色 + 溶解行为**两个维度构成强信号；气体的**气味 + 颜色变化 + 特征反应**构成强信号。两者都擅长「否定排除」。

### 3.1 沉淀颜色与溶解行为

| 触发条件（题目关键词） | 沉淀 | 颜色 | 溶解性特征 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|:---|:---|
| 白色沉淀，溶于氨水 | AgCl | 白 | 溶于 NH₃ 生成 [Ag(NH₃)₂]⁺ | Ag | 与 Hg₂Cl₂ 区分：后者加氨变灰黑 |
| 白色沉淀，不溶于稀酸 | BaSO₄ | 白 | 不溶于酸 | Ba/Sr | 与 BaCO₃（溶于酸放 CO₂）区分 |
| 黄色沉淀，不溶于稀酸 | CdS / PbI₂ | 黄 | CdS 不溶稀 HCl | Cd/Pb | 黄色 ≠ PbI₂ 专属 |
| 黑色沉淀，不溶于稀酸 | CuS / PbS / Ag₂S / HgS | 黑 | 均不溶稀 HCl | Cu/Pb/Ag/Hg | 需 HNO₃/王水区分 |
| 灰绿色沉淀，溶于过量 NaOH | Cr(OH)₃ | 灰绿 | 两性 → [Cr(OH)₄]⁻ | Cr | **Cr³⁺ 指纹反应** |
| 浅蓝色沉淀，溶于过量氨水 | Cu(OH)₂ | 浅蓝 | 过量 NH₃ → 深蓝 [Cu(NH₃)₄]²⁺ | Cu | 与 Ni(OH)₂（绿）区分 |
| 白色沉淀，溶于过量 NaOH | Al(OH)₃ / Zn(OH)₂ / Cr(OH)₃ | 白/灰绿 | 两性 | Al/Zn/Cr | 加过量氨水：Al(OH)₃ 不溶、Zn(OH)₂ 溶 |
| 白色沉淀，不溶于过量 NaOH 和氨水 | Mg(OH)₂ | 白 | 弱碱不溶 | Mg | 与两性组区分 |
| 砖红色沉淀 | Ag₂CrO₄ | 砖红 | 溶于酸 | Ag | 与 PbCrO₄（黄）区分 |
| 白→灰绿→红棕 | Fe(OH)₂ → Fe(OH)₃ | 白→红棕 | 空气氧化 | Fe | Fe²⁺ 经典鉴定 |

**沉淀信号的关键一步**：永远追问「这沉淀溶不溶」——不溶于什么（稀酸/过量碱/氨水/Na₂S₂O₃）比颜色更能区分候选。（见图 4）

### 3.2 气体信号

| 触发条件（题目关键词） | 气体 | 颜色/气味 | 特征反应 | 指向 |
|:---|:---|:---|:---|:---|
| 红棕色气体 | NO₂ / Br₂ | 红棕 | NO₂ 低温二聚变无色 N₂O₄；Br₂ 加水橙色 | N / Br |
| 无色气体，遇空气变红棕 | NO | 无色 | 2NO + O₂ → 2NO₂ | N（稀硝酸反应） |
| 无色刺激性，使品红褪色 | SO₂ | 无色 | 可逆漂白（加热复色） | S |
| 无色臭鸡蛋味 | H₂S | 无色 | 使 Pb(Ac)₂ 试纸变黑 | S |
| 黄绿色刺激性 | Cl₂ | 黄绿 | 使湿润 KI-淀粉试纸变蓝 | Cl |
| 无色，使带火星木条复燃 | O₂ | 无色无味 | 助燃 | 过氧化物/分解 |
| 无色，使澄清石灰水变浑浊 | CO₂ | 无色无味 | Ca(OH)₂ + CO₂ → CaCO₃↓ | C（碳酸盐） |
| 无色，与 HCl 产生白烟 | NH₃ | 无色刺激性 | NH₃ + HCl → NH₄Cl 白烟 | N（铵盐） |
| 无色，燃烧淡蓝色 | H₂ | 无色无味 | 2H₂ + O₂ → 2H₂O | 活泼金属与酸/水 |

**气体两大约分**：①「无色遇空气变红棕」是 NO 的**唯一性**信号（与 NO₂ 区分看颜色变化顺序）；②「使石灰水浑浊」SO₂ 也能做到（CaSO₃↓），需结合「能否漂白品红」区分。（见图 5）

| 气体 | 颜色 | 气味 | 特征反应或唯一性推断信息 |
| :---: | :---: | :---: | :--- |
| $\mathrm{NO}$ | 无色 | 无味 | 遇空气迅速变为红棕色（唯一） |
| $\mathrm{NO_2}$ | 红棕色 | 刺激性 | 溶于水得无色气体 $\mathrm{NO}$ 与硝酸 |
| $\mathrm{SO_2}$ | 无色 | 刺激性 | 可逆漂白品红溶液（唯一） |
| $\mathrm{Cl_2}$ | 黄绿色 | 刺激性 | 使湿润的淀粉碘化钾试纸变蓝 |
| $\mathrm{Br_2}$（气） | 红棕色 | 刺激性 | 强氧化性，溶于有机溶剂呈橙红色 |
| $\mathrm{I_2}$（气） | 紫红色 | 刺激性 | 遇淀粉显蓝色，易升华 |
| $\mathrm{F_2}$ | 淡黄绿色 | 刺激性 | 与水剧烈反应放出 $\mathrm{O_2}$，氧化性极强 |
| $\mathrm{H_2S}$ | 无色 | 臭鸡蛋味 | 遇 $\mathrm{Pb^{2+}}$、$\mathrm{Cu^{2+}}$ 生成黑色硫化物沉淀 |
| $\mathrm{NH_3}$ | 无色 | 氨臭味 | 使湿润红色石蕊试纸变蓝，遇挥发性酸生白烟 |
| $\mathrm{HCl}$ | 无色 | 刺激性 | 极易溶于水，在湿润空气中产生白雾 |
| $\mathrm{HCN}$ | 无色 | 苦杏仁味 | 剧毒，溶于水为弱酸 |
| $\mathrm{PH_3}$ | 无色 | 大蒜味 | 剧毒，混有 $\mathrm{P_2H_4}$ 时在空气中极易自燃 |
| $(\mathrm{CN})_2$ | 无色 | 苦杏仁味 | 拟卤素，与碱歧化，剧毒 |
| $\mathrm{CO}$ | 无色 | 无味 | 剧毒，燃烧呈蓝色火焰，能还原金属氧化物 |
| $\mathrm{CO_2}$ | 无色 | 无味 | 使澄清石灰水变浑浊 |
| $\mathrm{O_3}$ | 淡蓝色 | 鱼腥味 | 强氧化性，使碘化钾淀粉溶液变蓝 |
| $\mathrm{O_2}$ | 无色 | 无味 | 使带火星的木条复燃 |
| $\mathrm{H_2}$ | 无色 | 无味 | 燃烧呈淡蓝色火焰，点燃爆鸣 |

## §4 价态变化法与配合物生成法

**关联知识点**：氧化还原 · 配合物

**主线**：前三种信号「看到什么」，后两种信号「反应后变成什么」——变色/歧化/配体诱导显色，指向性往往更强。

### 4.1 价态变化信号（价态数轴 + 歧化）

**核心问题**：题目给出「氧化还原导致的颜色变化」时，用价态数轴判断中间价态。

| 变化 | 涉及物种 | 条件 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|:---|
| 紫色→无色 | MnO₄⁻ → Mn²⁺ | 酸性 | Mn | 中性/碱性产物不同 |
| 紫色→棕色沉淀 | MnO₄⁻ → MnO₂ | 中性/弱碱 | Mn | 注意介质 |
| 紫色→绿色 | MnO₄⁻ → MnO₄²⁻ | 强碱 | Mn | 锰酸根绿，易歧化 |
| 橙色→绿色 | Cr₂O₇²⁻ → Cr³⁺ | 酸性还原 | Cr | Cr(VI)/Cr(III) 互化 |
| 黄色→橙色 | CrO₄²⁻ → Cr₂O₇²⁻ | 加酸 | Cr | pH 控制平衡 |
| 浅绿→黄色 | Fe²⁺ → Fe³⁺ | 氧化剂/空气 | Fe | Fe²⁺ 易被空气氧化 |
| 蓝色→无色 | Cu²⁺ → Cu⁺/Cu | 还原剂 | Cu | Cu⁺ 水溶液歧化 |

**中间价态歧化判断**：中间价态元素「既可升又可降」时，题目常考歧化。判据：查电势图，若左 $E^\theta$ < 右 $E^\theta$ 则歧化自发（如 Cu⁺：$E^\theta(\mathrm{Cu^{2+}/Cu^+})$=+0.15、$E^\theta(\mathrm{Cu^+/Cu})$=+0.52，左<右 → 歧化）。价态数轴一眼看出「谁在中间、能往哪头走」。（见图 6）

### 4.2 配合物生成信号（配体诱导颜色突变）

| 变化 | 涉及反应 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|
| 无色→深蓝 | Cu²⁺ + 过量 NH₃ → [Cu(NH₃)₄]²⁺ | Cu | 与 [CuCl₄]²⁻（黄绿）区分 |
| 黄色→血红色 | Fe³⁺ + SCN⁻ → [Fe(SCN)]²⁺ | Fe | Fe²⁺ 不显色，需先氧化 |
| 白色沉淀→溶解 | AgCl + NH₃ → [Ag(NH₃)₂]⁺ | Ag | 与 Hg₂Cl₂（灰黑）区分 |
| 白色沉淀→溶解 | Zn(OH)₂ + 过量 NH₃ → [Zn(NH₃)₄]²⁺ | Zn | Al(OH)₃ 不溶过量氨水（关键区分！） |
| 无色→黄色/橙色 | 加配体形成有色配合物 | 视配体 | 配位显色 ≠ d-d 显色 |

**配位信号的鉴别威力**：「加过量氨水溶解」是 Zn²⁺ 与 Al³⁺ 的**指纹级区分**——Al(OH)₃ 不溶过量氨水，Zn(OH)₂ 溶解。这一条能独立判定 Zn。（见图 7）

## §5 否定信息利用与交叉验证

**关联知识点**：元素推断

**主线**：否定信息是推断题中「最不值钱却最能拉开分差」的部分——多数人忽略「不」字，高手靠「不」字一步到位。

### 5.1 「不」字标记法

通读题目时，把所有「不」「无」「没有」「难溶」「不溶」「不变色」**全部圈出来**。每条否定信息都是一次排除操作。操作要点：**「先列候选，再看证据；能排就排，不能先留。」**

### 5.2 四大否定信号排除表

| 否定信号 | 排除谁 | 保留谁 |
|:---|:---|:---|
| 「加 NaOH 不溶解」 | Al³⁺/Cr³⁺/Zn²⁺/Be²⁺（两性氢氧化物） | Mg²⁺/Ca²⁺/Fe³⁺/Cu²⁺ |
| 「加 HCl 无沉淀」 | Ag⁺/Pb²⁺/Hg₂²⁺ | 其余 |
| 「无色溶液」 | 多数过渡金属（d-d 有色） | d⁰：Ti⁴⁺/V⁵⁺；d¹⁰：Zn²⁺/Cu⁺/Ag⁺/Hg²⁺；主族 |
| 「酸性通 H₂S 无沉淀」 | Cu²⁺/Pb²⁺/Ag⁺/Hg²⁺（硫化物极难溶） | Zn²⁺/Mn²⁺/Fe²⁺（硫化物可溶稀酸） |

**额外常用否定信号**：

| 否定信号 | 排除谁 |
|:---|:---|
| 白色沉淀不溶于过量 NaOH | Al/Zn/Cr 两性组 |
| 无焰色反应 | Na（黄）/K（紫）/Ca（砖红）碱金属碱土金属（Mg/Be 除外） |
| 不溶于氨水 | AgCl（AgBr/AgI 也不溶，需结合颜色） |

### 5.3 「无色」不等于无过渡金属

**值得注意（d⁰/d¹⁰ 无色陷阱）**：「无色溶液」只能排除 d¹~d⁹ 有色离子，不能排除过渡金属——d⁰ 构型（Ti⁴⁺、V⁵⁺、Mo⁶⁺、W⁶⁺ 等无 d 电子）与 d¹⁰ 构型（Zn²⁺、Cu⁺、Ag⁺、Hg²⁺ 等 d 轨道全满）都无 d-d 跃迁、均呈无色。所以看到「无色溶液」要保留这两组过渡金属候选，再靠沉淀/配合物/氧化还原信号区分。

### 5.4 交叉验证决策路径

| 环节 | 判据 | 操作 |
|:---|:---|:---|
| 识别最强信号 | 唯一性信号 | 直接锁定 |
| | 组合信号 | 列 2~4 个候选 |
| | 单一信号 | 提取第二信号 |
| 否定信息排除 | 剩余候选 >2 | 提取第三信号交叉验证，回到候选 |
| | 剩余候选 ≤2 | 进入反向验证 |
| 反向验证 | 所有条件都能解释 | 定价态 + 写关键方程式 → 完成 |
| | 有条件不能解释 | 回溯、重新识别信号（止损） |

**止损原则**（初赛讲义第 6 讲）：**如果两个信号互相矛盾，回到硬约束重新检查**，而不是硬凑一个答案。最危险的不是不会，而是被表面熟词带偏。

## §6 五步推断法与进阶工具

**关联知识点**：提炼-化学竞赛初赛讲义-第6讲-推断技术

**主线**：前面是「实验现象驱动」的推断（四步法，第二轮主力）；遇到**数据零碎、物种陌生**的综合题，升级为「五步推断法」——从物理性质一路过滤到方程式。

### 6.1 五步推断法（进阶框架）

| 线索类型 | 步骤 | 核心问题 | 常用工具 |
|:---|:---|:---|:---|
| 物理性质 | ① 物理 → 缩小范围 | 颜色/磁性/溶解性能先排掉谁？ | 颜色表 + 溶解性表 + 磁性判据 |
| 结构数据 | ② 结构 → 确定类型 | 晶胞参数/构型/光谱在告诉我什么？ | VSEPR + 杂化 + 晶胞计算 |
| 化学性质 | ③ 反应性 → 定位元素 | 氧化还原/酸碱/配位/鉴定反应指向谁？ | 氧化还原 + 酸碱 + 配位 + 鉴定反应 |
| 定量数据 | ④ 热力学 → 排除错误 | $E^\theta$/$K_{sp}$/键能是否支持假设？ | 电势图 + 热力学判据（定性） |
| 方程式 | ⑤ 写方程式 → 验证全链 | 质量/电荷/现象全对得上吗？ | 氧化数法 + 半反应法 + 现象回核 |

**回查规则**：第五步验证不通过 → 回到前四步重新调整假设，**不是硬往下算**。

**磁性判据速查**（$\mu_{\mathrm{eff}}$ = √[n(n+2)] BM）：
| n | 1 | 2 | 3 | 4 | 5 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| $\mu_{\mathrm{eff}}$ / BM | 1.73 | 2.83 | 3.87 | 4.90 | 5.92 |

由 $\mu_{\mathrm{eff}}$ 反推未成对电子数 n → 判断 dⁿ 构型 → 辅助定位元素（配合物推断常用）。

### 6.2 广义复盐法（整体打包）

**适用**：陌生化学式 + 热重/组成数据题。把一个陌生物**形式上拆成「已知盐 + 氧化物」「复盐 + 配位部分」**，很多计量和性质立刻变清楚。

| 拆写方式 | 示例 | 用途 |
|:---|:---|:---|
| 已知盐 + 氧化物 | 黑色晶体拆成 AgNO₃·Agₓ$O_y$ | 热重数据变得可算 |
| 复盐/混盐 | X·YSO₄·Z 型 | 读出组成比例与热分解路径 |
| 低氧化物 + 高氧化物 | BiO₀.₇₅ ≈ 2Bi + Bi₂O₃ | 氧化态与比例一目了然 |

**本质**：不是「它真的是复盐」，而是先给陌生对象一个可计算、可解释的整体包装，借包装快速读出组成、价态、热分解路径。（见图 9）

### 6.3 六大命题模式

| 模式 | 特点 | 典型例题 |
|:---|:---|:---|
| 颜色递推型 | 以颜色变化为主线串联推断 | 绿色晶体→黑色→黄色→血红色 |
| 计算确证型 | 定量数据（摩尔质量/百分比/气体体积）反推 | 2.00 g 金属 + 酸 → 0.0800 mol H₂ |
| 古文翻译型 | 古代文献描述 → 现代物质与反应 | 「胆矾煅之，醋淬，赤色气体」 |
| 结构推断型 | 晶胞参数/空间构型/光谱 | 晶胞参数反推化学式 |
| 性质比较型 | 同族/同周期多组性质对比 | A/B/C/D 位置推断 |
| 工业流程型 | 以化工生产流程为载体 | 从矿石到产品多步转化 |

**计算型推断核心公式**：n(e⁻ 转移) = 2 × n(H₂) = (m/M) × 金属化合价变化量。摩尔质量算出的结果允许 ±1 偏差。

### 6.4 化学史推断（三步翻译法）

1. 圈古文操作词：「煅」→高温加热；「淬」→水中冷却；「飞」→升华；「点」→加入少量

2. 定位关键物质：雄黄=As₄S₄；砒霜=As₂O₃；胆矾=CuSO₄·5H₂O；绿矾=FeSO₄·7H₂O；皓矾=ZnSO₄·7H₂O；明矾=KAl(SO₄)₂·12H₂O；硝石=KNO₃；朱砂=HgS；铅丹=Pb₃O₄

3. 按操作写方程式：把古文操作链翻译为现代化学反应

**操作链识别**：原料处理（煅烧/研磨/淘洗）→ 反应转化（加酸/加热/点入）→ 产物分离（飞/升华/沉淀/结晶）。

**图解：五步推断法闭环流程**

| 步骤 | 核心线索 | 作用 | 依据 |
| :---: | :--- | :--- | :--- |
| ① 物理性质 | 颜色 / 磁性 / 溶解性 | 缩圈排除 | 经验判据 |
| ② 结构数据 | 参数 / 构型 / 光谱 | 确定类型 | 结构化学 |
| ③ 化学性质 | 氧化还原 / 配位 | 定位元素 | 反应规律 |
| ④ 定量数据 | 电势 / 热力学 | 确实验证 | 数据核对 |
| ⑤ 写方程式 | 电荷 / 质量平衡 | 落脚下结论 | 规范表达 |

若第⑤步出现矛盾或算不通，则回退到第①步重新缩圈，直到闭环。

**主线**：方法练到真题里才算数。真题讲评不只看答案，而是拆解**信号优先级 + 否定排除 + 推理链完整性**。

### 7.1 真题链映射（按认知台阶递进）

### 7.2 排除法标准模板：真题-无机-元素推断-卤素-001

**题核**：三种无色钠盐 A/B/C 与 AgNO₃ 分别得白/淡黄/黄沉淀，且溶解性在浓氨水中依次「溶/微溶/不溶」；与浓 H₂SO₄ 共热分别得 HCl↑ / Br₂(红棕)+SO₂ / I₂(紫色蒸气)。

**四步法执行**：

| 步骤 | 操作 | 结论 |
|:---|:---|:---|
| ① 提取信号 | AgCl 白+溶氨水；AgBr 淡黄+微溶；AgI 黄+不溶；浓 H₂SO₄ 表现：Cl⁻ 仅复分解、Br⁻ 被氧化、I⁻ 更强还原 | 卤化银颜色+溶解行为是关键信号对 |
| ② 最强信号候选 | 银盐沉淀颜色 + 氨水溶解性 → A=Cl⁻、B=Br⁻、C=I⁻ | 逐一对应 |
| ③ 否定排除 | 沉淀不溶稀 HNO₃ 排除碳酸盐/亚硫酸盐；不溶浓氨水排除 AgCl | 确定卤素 |
| ④ 验证 | 浓 H₂SO₄ 反应佐证还原性强弱：Cl⁻<Br⁻<I⁻ | 2NaBr+3H₂SO₄→△→ 2NaHSO₄+Br₂↑+SO₂↑+2H₂O |

**本题教学点**：卤化银「颜色 + 氨水溶解性」是一组经典的**唯一性组合信号**；I⁻ 能把 H₂SO₄ 还原到 H₂S 说明卤素还原性 I⁻>Br⁻>Cl⁻——这就是「从反应现象推断性质」的排除法骨架。

### 7.3 国初真题实战

| 真题 | 核心信号 | 分值 | 训练点 |
|:---|:---|:---:|:---|
| **37 届 Q5**（NO/H₂S 反应体系） | 气体信号：NO 遇空气变红棕；H₂S 臭鸡蛋味；氧化还原价态变化 | 13 | 中等难度入门：熟悉「信号提取→推断→验证」全流程 |
| **38 届 Q1**（炼丹元素推断） | 颜色信号（多离子）+ 沉淀 + 配合物 + 价态变化 | 22 | 高难度核心：多信号交叉验证 + 过程分对照 |
| **39 届 Q1**（砷化学） | 颜色 + 沉淀 + 价态变化（含剧毒元素 As） | 15 | 心理建设：剧毒元素也按同一套逻辑客观推理 |

**心态提示（39 届 Q1）**：砷是剧毒元素，但化学推断不需要「害怕它」——As 的推断逻辑与其他元素完全相同（As₂O₃ 两性、砷酸盐/亚砷酸盐、雄黄 As₄S₄ 等信号照常处理）。客观理性就是最好的科学态度。

| 序号 | 自查项 |
|:---:|:---|

A. CaCl₂　　B. (NH₄)₂CO₃　　C. NaOH　　D. (NH₄)₂SO₄

### 参考答案与精解

**解 1**：(1) A = NaCl，B = NaBr，C = NaI，D = HCl，E = Br₂（伴 SO₂），F = I₂。判据：AgCl 白↓溶于浓氨水、AgBr 淡黄↓微溶、AgI 黄↓不溶；与浓 H₂SO₄ 共热，Cl⁻ 仅复分解得 HCl，Br⁻ 被氧化得 Br₂（红棕）＋SO₂，I⁻ 还原性更强被氧化得 I₂（紫色蒸气）。(2) $2\mathrm{NaBr} + 3\mathrm{H_2SO_4(浓)} \xrightarrow{\Delta} 2\mathrm{NaHSO_4} + \mathrm{Br_2} + \mathrm{SO_2}\uparrow + 2\mathrm{H_2O}$。(3) 还原性 I⁻ > Br⁻ > Cl⁻。

**解 2**：(1) $2\mathrm{Fe^{3+}} + \mathrm{Ag_2S} \rightarrow 2\mathrm{Ag^+} + 2\mathrm{Fe^{2+}} + \mathrm{S}$（S²⁻ 氧化为 S⁰）。(2) 用巧设氧化数法（Fe、S 均视为 0 价），每分子 Fe₇S₈ 全部转化失电子 $6 \times 8 + 2 \times 7 = 62$，配平得 $\mathrm{Fe_7S_8} + 32\mathrm{H_2O} + 62\mathrm{Fe^{3+}} \rightarrow 69\mathrm{Fe^{2+}} + 64\mathrm{H^+} + 8\mathrm{SO_4^{2-}}$。

**解 3**：Fe 为还原剂（0 → +8/3），NO₂⁻ 为氧化剂（N +3）；「无色刺激性气体」指向 N 的还原产物为 NH₃。配平：$9\mathrm{Fe} + 8\mathrm{H_2O} + 4\mathrm{NO_2^-} \rightarrow 3\mathrm{Fe_3O_4} + 4\mathrm{OH^-} + 4\mathrm{NH_3}$（Fe 共失 24e⁻、N 共得 24e⁻，碱性条件产物含 OH⁻）。

**解 4**：(1) $\mathrm{As_4S_4} + 2\mathrm{Fe} \rightarrow 4\mathrm{As} + 2\mathrm{FeS_2}$（Fe 置换出 As，FeS₂ 即金色「愚人金」）。(2) $\mathrm{As_2O_3} + 2x\mathrm{Cu} + 3\mathrm{C} \rightarrow 2\mathrm{Cu_xAs} + 3\mathrm{CO}$，由 $\omega(\mathrm{As}) = 5\%$ 解得 $x \approx 22.4$，最简整数比：$5\mathrm{As_2O_3} + 224\mathrm{Cu} + 15\mathrm{C} \rightarrow 2\mathrm{Cu_{112}As_5} + 15\mathrm{CO}$。

**解 5**：(1) 将含 ICl/IBr 的 I₂ 与 KI 共热：$\mathrm{ICl} + \mathrm{KI} \xrightarrow{\Delta} \mathrm{KCl} + \mathrm{I_2}$、$\mathrm{IBr} + \mathrm{KI} \xrightarrow{\Delta} \mathrm{KBr} + \mathrm{I_2}$——反应方向是生成晶格能更大的 KCl/KBr；加热中 I₂ 升华，与 KCl/KBr 分离。(2) 溶于水通入少量 Cl₂：$2\mathrm{NaBr} + \mathrm{Cl_2} = 2\mathrm{NaCl} + \mathrm{Br_2}$，加 CCl₄ 萃取 Br₂ 与过量 Cl₂ 后分液，水相浓缩结晶得纯 NaCl。(3) 分别溶于水后滴加 AgNO₃：白色沉淀且溶于稀氨水者为 KCl；淡黄色沉淀且溶于 Na₂S₂O₃ 者为 KBr；黄色沉淀且不溶于 Na₂S₂O₃ 者为 KI。

**解 6**：分别加少许 CCl₄ 与 KMnO₄：CCl₄ 层变黄/橙者为 HBr（Br₂ 溶于 CCl₄）；变紫者为 HI（I₂ 溶于 CCl₄）；CCl₄ 层不变色但 KMnO₄ 褪色或变浅者为 HCl；无明显变化者为 H₂SO₄。

**解 7**：方法一——分别加稀盐酸，有 Cl₂ 放出者为 KClO（$\mathrm{KClO} + 2\mathrm{HCl} = \mathrm{KCl} + \mathrm{Cl_2}\uparrow + \mathrm{H_2O}$）；加浓盐酸有 Cl₂ 放出且溶液变黄者为 KClO₃（$8\mathrm{KClO_3} + 24\mathrm{HCl(浓)} = 9\mathrm{Cl_2}\uparrow + 8\mathrm{KCl} + 6\mathrm{ClO_2}\uparrow + 12\mathrm{H_2O}$）；余者为 KClO₄。方法二——加水溶解，几乎不溶者为 KClO₄；加 KI 立即生成 I₂ 者为 KClO，加 KI 无变化而酸化后才生成 I₂ 者为 KClO₃。

**解 8**：KMnO₄ 的 $E^\ominus$（1.51 V）大于所给全部电对，故六种阴离子都能使 KMnO₄ 褪色。碘-淀粉褪色需还原剂电对低于 $E^\ominus(\mathrm{I_2/I^-}) = 0.535\ \mathrm{V}$：只有 S₂O₃²⁻（0.08）、S²⁻（0.142）、SO₃²⁻（0.172）满足；Br⁻（1.07）、I⁻（0.535 以上需 MnO₄⁻ 直接氧化，此处指碘水）与 NO₂⁻（0.934）不能使碘-淀粉褪色。故试液中可能存在的阴离子是 **Br⁻、I⁻、NO₂⁻**。

**解 9**：由 (1) 加 AgNO₃ 得白色沉淀 → 不含 S²⁻（Ag₂S 黑）、S₂O₃²⁻（Ag₂S₂O₃ 白但分解变黑）；由 (2) 加 BaCl₂ 得白色沉淀 → 含 SO₄²⁻；由 (3) 酸化溴水不褪色 → 不含具还原性的 S²⁻、S₂O₃²⁻、SO₃²⁻。结论：**SO₄²⁻ 肯定存在；S²⁻、S₂O₃²⁻、SO₃²⁻ 肯定不存在；Cl⁻ 可能存在**。

**解 10**：(1) 加 HCl，Ag⁺ 生成 AgCl 沉淀分离；滤液通 H₂S，Fe²⁺ 生成 FeS 沉淀分离；Ba²⁺ 留在溶液中。(2) 加过量 NaOH：Al³⁺→[Al(OH)₄]⁻、Zn²⁺→[Zn(OH)₄]²⁻ 留在溶液，Fe³⁺→Fe(OH)₃↓、Cu²⁺→Cu(OH)₂↓ 沉淀；过滤后滤液通 CO₂ 可分别沉淀 Al(OH)₃（CO₂ 不足）与 Zn(OH)₂（继续）；沉淀加 H₂S，Cu(OH)₂ 转化为 CuS↓ 而 Fe(OH)₃ 不反应，过滤分离。

**解 11**：(1) 加过量 NaOH：$\mathrm{Sb^{3+}} + 6\mathrm{OH^-} = \mathrm{SbO_3^{3-}} + 3\mathrm{H_2O}$（溶解），$\mathrm{Bi^{3+}} + 3\mathrm{OH^-} = \mathrm{Bi(OH)_3}\downarrow$（沉淀）。(2) 加 AgNO₃：PO₄³⁻ 生成 Ag₃PO₄↓，NO₃⁻ 留液。(3) 硝酸酸化后加 BaCl₂：SO₄²⁻ 生成 BaSO₄↓，PO₄³⁻ 转化为 H₂PO₄⁻ 留液。(4) 硝酸酸化后加 AgNO₃：Cl⁻ 生成 AgCl↓，PO₄³⁻ 留液。

**解 12**：(1) 通过赤热铜粉除 O₂（$\mathrm{O_2} + 2\mathrm{Cu} = 2\mathrm{CuO}$），再用 P₂O₅ 干燥。(2) 通过水或 NaOH 除 NO₂：$3\mathrm{NO_2} + \mathrm{H_2O} = 2\mathrm{HNO_3} + \mathrm{NO}$，再用 P₂O₅ 干燥。(3) 加少量 HNO₃ 后加热：$2\mathrm{NO_2^-} + 2\mathrm{H^+} = \mathrm{NO_2}\uparrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$；或加少量 NH₄NO₃ 后加热：$\mathrm{NH_4^+} + \mathrm{NO_2^-} = \mathrm{N_2}\uparrow + 2\mathrm{H_2O}$。

**解 13**：方法一——加 AgNO₃，黄色沉淀为 Na₃PO₄（Ag₃PO₄‎黄）、白色沉淀为 Na₂SO₄（Ag₂SO₄ 白）。方法二——加 BaCl₂，白色沉淀不溶于硝酸者为 Na₂SO₄（BaSO₄），沉淀溶于硝酸者为 Na₃PO₄。方法三——加碘水，能使碘水褪色者为 Na₃PO₄（溶液碱性较强、碘发生歧化），不能褪色者为 Na₂SO₄。

**解 14**：方法一——加酸性 KMnO₄，褪色者为 KNO₂。方法二——用 HAc 酸化后加 KI，变黄（生成 I₂）者为 KNO₂。方法三——加 AgNO₃，黄色沉淀者为 KNO₂（AgNO₂ 黄）。方法四——加 FeSO₄ 后沿壁缓倒浓硫酸，界面呈棕色环者为 KNO₃（棕色环试验），棕色溶液者为 KNO₂。方法五——加 HAc 与 CoCl₂ 水浴加热后冷却，黄色沉淀者为 KNO₂。方法六——加浓硝酸，有棕色气体者为 KNO₂。

**解 15**：焙烧：$2\mathrm{Bi_2S_3} + 9\mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{Bi_2O_3} + 6\mathrm{SO_2}$；与盐酸：$\mathrm{Bi_2O_3} + 6\mathrm{HCl} = 2\mathrm{BiCl_3} + 3\mathrm{H_2O}$；碱性介质中 Cl₂ 氧化 Bi(Ⅲ) 到 Bi(Ⅴ)：$\mathrm{BiCl_3} + \mathrm{Cl_2} + 6\mathrm{NaOH} = \mathrm{NaBiO_3}\downarrow + 5\mathrm{NaCl} + 3\mathrm{H_2O}$。

**解 16**：(1) XeF₂：$\mathrm{Xe} + \mathrm{F_2} = \mathrm{XeF_2}$，须 Xe 大过量以避免 XeF₄ 生成。(2) XeF₄：$\mathrm{Xe} + 2\mathrm{F_2} = \mathrm{XeF_4}$，控制 Xe 与 F₂ 物质的量之比约 1∶2 并适当控制反应条件。(3) XeF₆：$\mathrm{Xe} + 3\mathrm{F_2} = \mathrm{XeF_6}$，须 F₂ 大过量且保证反应时间足够长。

**解 17**：分别用氨水处理。生成灰黑色沉淀者为 Hg₂Cl₂：$\mathrm{Hg_2Cl_2} + 2\mathrm{NH_3\cdot H_2O} = \mathrm{Hg(NH_2)Cl(白)} + \mathrm{Hg(黑)} + \mathrm{NH_4Cl} + 2\mathrm{H_2O}$（歧化生 Hg 黑，故显灰黑）。先得无色溶液、遇空气变深蓝者为 CuCl：$\mathrm{CuCl} + 2\mathrm{NH_3\cdot H_2O} = [\mathrm{Cu(NH_3)_2}]^+ + \mathrm{Cl^-} + 2\mathrm{H_2O}$，无色 [Cu(NH₃)₂]⁺ 遇空气氧化为深蓝 [Cu(NH₃)₄]²⁺。溶解得无色稳定溶液者为 AgCl：$\mathrm{AgCl} + 2\mathrm{NH_3\cdot H_2O} = [\mathrm{Ag(NH_3)_2}]^+ + \mathrm{Cl^-} + 2\mathrm{H_2O}$。

**解 18**：(1) Cu 被 O₂ 氧化并与 NH₃ 配位协同：$2\mathrm{Cu} + \mathrm{O_2} + 8\mathrm{NH_3} + 2\mathrm{H_2O} = 2[\mathrm{Cu(NH_3)_4}]^{2+} + 4\mathrm{OH^-}$（生成稳定铜氨配合物促进溶解）。(2) $\mathrm{[Zn(OH)_4]^{2-}} + 2\mathrm{H^+} = \mathrm{Zn(OH)_2}\downarrow + 2\mathrm{H_2O}$（先析出白色 Zn(OH)₂），继续加酸：$\mathrm{Zn(OH)_2} + 2\mathrm{H^+} = \mathrm{Zn^{2+}} + 2\mathrm{H_2O}$（沉淀溶解）。(3) 先生成黄色 Hg₂I₂：$\mathrm{Hg_2^{2+}} + 2\mathrm{I^-} = \mathrm{Hg_2I_2}\downarrow$（黄）；继续加 KI 发生歧化：$\mathrm{Hg_2I_2} + 2\mathrm{I^-} = [\mathrm{HgI_4}]^{2-} + \mathrm{Hg}\downarrow$（黑），最终黑色 Hg 与无色 [HgI₄]²⁻ 溶液共存。

**解 19**：向紫色溶液中滴加 FeCl₃ 溶液——若紫色褪去，则原溶液为 TiCl₃：$\mathrm{Ti^{3+}} + \mathrm{Fe^{3+}} + \mathrm{H_2O} = \mathrm{TiO^{2+}} + \mathrm{Fe^{2+}} + 2\mathrm{H^+}$（Ti³⁺ 具强还原性）；若紫色不褪，则为 KMnO₄ 溶液（KMnO₄ 不与 Fe³⁺ 反应）。

**解 20**：(1) 加过量 NaOH：Fe³⁺→Fe(OH)₃↓、Ni²⁺→Ni(OH)₂↓，而 Al³⁺→[Al(OH)₄]⁻、Cr³⁺→[Cr(OH)₄]⁻ 留液；过滤后滤液通 CO₂ 得 Al(OH)₃↓ 与 Cr(OH)₃↓；沉淀加过量氨水时 Fe(OH)₃ 不溶、Ni(OH)₂ 溶于氨水为 [Ni(NH₃)₆]²⁺，据此分离。(2) 加过量 NaOH：Fe(OH)₂↓、Co(OH)₂↓、Cu(OH)₂↓，Zn²⁺→[Zn(OH)₄]²⁻ 留液；过滤后滤液加酸得 Zn(OH)₂↓；沉淀加过量氨水，Cu 与 Co 分别溶于氨水为 [Cu(NH₃)₄]²⁺、[Co(NH₃)₆]²⁺，Fe(OH)₂ 不溶，据此分离。

**解 21**：先加 Zn 粉将 Cu²⁺ 还原为 Cu 过滤除去：$\mathrm{Zn} + \mathrm{Cu^{2+}} = \mathrm{Zn^{2+}} + \mathrm{Cu}$；再向滤液加 H₂O₂ 将 Fe²⁺ 氧化为 Fe³⁺：$2\mathrm{Fe^{2+}} + \mathrm{H_2O_2} + 2\mathrm{H^+} = 2\mathrm{Fe^{3+}} + 2\mathrm{H_2O}$；加 ZnO 调 pH ≈ 4~5 使 Fe(OH)₃ 沉淀完全并过滤；最后加热分解多余 H₂O₂。全程只引入 Zn²⁺（目标产物成分），不引入杂质。

**解 22**：加盐酸是为抑制 Sn²⁺ 水解；加锡粒是因一旦 Sn²⁺ 被空气氧化为 Sn⁴⁺，Sn 与 Sn⁴⁺ 归中又生 Sn²⁺（$\mathrm{Sn} + \mathrm{Sn^{4+}} = 2\mathrm{Sn^{2+}}$）。久置空气中酸度**变小**，因发生 $2\mathrm{Sn^{2+}} + \mathrm{O_2} + 4\mathrm{H^+} = 2\mathrm{Sn^{4+}} + 2\mathrm{H_2O}$，消耗 H⁺。

**解 23**：可以。$\mathrm{Ce^{4+}} + \mathrm{Fe^{2+}} = \mathrm{Ce^{3+}} + \mathrm{Fe^{3+}}$，电池标准电动势 $E^\ominus = (1.45 - 0.77)\ \mathrm{V} = 0.68\ \mathrm{V}$，平衡常数 $K \approx 3 \times 10^{11}$，反应进行得很彻底，故可用已知浓度的 Ce⁴⁺ 溶液定量测定 Fe²⁺。

**解 24**：(1) X = C，Y = N，Z = O，W = Cl（Y 能形成 6 种氧化物且 Z 电负性更大 → N/O；W 单质用于自来水消毒 → Cl；配合三氯异氰尿酸结构 C₃N₃O₃Cl₃ 印证）。(2) 选 **A、B**。A：最高价含氧酸酸性 H₂CO₃ < HNO₃ < HClO₄ ✓；B：离子半径 r(Cl⁻) > r(N³⁻) > r(O²⁻) ✓。C 错（Cl 不能形成含非极性键的二元氢化物）；D 错（简单氢化物还原性 HCl 最弱，给定序不成立）。

**解 25**：选 **A、C**。溶于水得无色澄清溶液且无其他现象 → 不能同时存在 CaCl₂ 与碳酸铵（否则生成 CaCO₃ 沉淀）；加 Ba(NO₃)₂ 得白色沉淀、加硝酸后沉淀部分消失 → 既有 BaSO₄（不溶于硝酸）又有 BaCO₃（溶于硝酸），故含 (NH₄)₂SO₄ 与 (NH₄)₂CO₃；既有 NH₄⁺ 又含 CO₃²⁻，则不能含 NaOH（否则 NH₄⁺ + OH⁻ 会放出 NH₃、且 CO₃²⁻ 与 Ca²⁺ 生成沉淀），故 CaCl₂、NaOH 肯定不存在。
