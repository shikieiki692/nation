## 一、氢：三种成键形态与氢化物分类

### 1.1 氢的三种成键形态

| 形态 | 代表 | 本质 | 化学特征 |
|:---|:---|:---|:---|
| **H⁺（质子）** | HCl、H₂O、H₂SO₄ | 失去唯一电子 | 裸质子半径极小、电荷密度极大，水溶液中必以 H₃O⁺ 存在 |
| **H⁻（氢负离子）** | NaH、CaH₂、LiAlH₄ | 得一个电子，1s² | **强还原剂**；离子型氢化物遇水放 H₂：NaH + H₂O → NaOH + H₂↑ |
| **共价 H** | H₂、CH₄、卤化氢 HX | 与电负性相近或更高元素共用 | 极性取决于对端元素电负性：X 电负性大 → H 显部分正 |

> **关键判断**：氢的成键形态由对端元素的电负性差决定。电负性差 > ~1.7 → 离子型（H 得电子成 H⁻ 或失电子成 H⁺）；电负性差小 → 共价型。

### 1.2 氢化物三大类型

| 类型 | 代表 | 键型 | 物理/化学特征 |
|:---|:---|:---|:---|
| **离子型**（盐型） | NaH、CaH₂、KH | 离子键（H⁻） | 白色晶体、熔沸点高、熔融导电；**遇水强还原**：CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂↑ |
| **共价型**（分子型） | HX、H₂O、NH₃、CH₄ | 极性/非极性共价键 | 熔沸点低；水溶液酸碱性取决于 H 的离去倾向 |
| **金属型**（间充型） | PdHₓ、LaNi₅H₆、TiH₂ | 金属键 + 间隙 H | 保留金属光泽/导电；**储氢材料**（LaNi₅ 储氢合金） |

> **竞赛考点**：NaH 的强还原性——它能把 TiCl₄ 还原为 Ti：TiCl₄ + 4NaH → Ti + 4NaCl + 2H₂↑。金属型氢化物则常考储氢密度计算。

## 二、卤素通性与制备

卤素位于周期表第ⅦA族，价层电子构型 $ns^2np^5$，与稀有气体八电子稳定结构只差一个电子，因此都是活泼非金属，在自然界中以化合态存在：

| 元素 | 主要存在形态 | 丰度特征 |
|:---|:---|:---|
| F | 萤石 CaF₂、冰晶石 Na₃AlF₆、氟磷灰石 Ca₅F(PO₄)₃ | 地壳约 0.015%，第 15 位 |
| Cl | 海水、盐湖、盐井；钾石盐 KCl、光卤石 KCl·MgCl₂·6H₂O | 海水约含氯 1.9%；地壳约 0.031%，第 11 位 |
| Br | 主要在海水中（约为氯的 1/300），盐湖、盐井少许 | 地壳约 1.6×10⁻⁴% |
| I | 被海藻吸收富集；某些盐井、盐湖；智利硝石含少量 NaIO₃ | 海水中仅约 5×10⁻⁸% |

At 为放射性元素，研究较少，从略。这些存在形态本身就是推断题与工业提取题的素材：Br⁻、I⁻ 从海水提取（见本节制备部分）、智利硝石母液中的 IO₃⁻，都直接对应后文的制备方法。

### 2.1 卤素单质物理性质递变

| 性质 | F₂ | Cl₂ | Br₂ | I₂ |
|:---|:---:|:---:|:---:|:---:|
| 颜色 | 浅黄绿 | 黄绿 | 红棕 | 紫黑 |
| 常温状态 | 气体 | 气体 | 液体 | 固体 |
| 熔点 (K) | 53.5 | 172.2 | 265.9 | 386.8 |
| 沸点 (K) | 85.0 | 239.1 | 332.4 | 457.5 |
| 氧化性 | 极强 | 强 | 中 | 弱 |
| X⁻ 还原性 | 极弱 | 弱 | 中 | 强 |
| 键能 (kJ/mol) | 159（反常低）| 243 | 193 | 151 |
| 电负性 (Pauling) | 4.0 | 3.2 | 3.0 | 2.5 |

**递变规律**：F₂ → I₂ 颜色加深、熔沸点升高、**氧化性递减**、X⁻ 还原性递增。

![[019e2d55c9d2e04b748edae0bad9b315e40f85af4f098263f4af001b4d0bea99.jpg|389]]
*图 1 固体氯、溴、碘的层状结构——从 Cl₂ 到 I₂ 分子间距离依次压缩，碘已呈现半导体性质*

> [!tip] 理解要点
> 颜色加深源于电子吸收光谱向长波方向移动（外层电子越易激发，吸收波长越长）；熔沸点升高源于色散力随分子量增大；氧化性递减源于 X 原子半径增大、得电子能力减弱。

> [!warning] 易错提醒
> F₂ 键能反常低（159 kJ/mol）——F 原子半径极小，2p 轨道重叠效率低，且孤对电子-孤对电子排斥显著，使 F₂ 的键能反而低于 Cl₂。这是「原子越小键越强」直觉的第一个反例。

![[e737fd7c6a5ba608b7e1fc80806807d1e5747cf1705719a7fa6b7d851bd4ab52.jpg]]
*图 2 卤素分子键解离焓——F₂ 键能反常低（159 kJ/mol），低于 Br₂（193 kJ/mol）和 Cl₂（243 kJ/mol）*

**颜色递变的分子轨道解释**：X₂ 分子中，能量最高的电子占有轨道是 $\pi_{np}^*$，能量最低的空轨道是 $\sigma_{np}^*$。卤素分子吸收可见光，使一个电子由 $\pi_{np}^*$ 激发到 $\sigma_{np}^*$：

$$\left(\sigma_{np}\right)^2\left(\pi_{np}\right)^4\left(\pi_{np}^{*}\right)^4 \rightarrow \left(\sigma_{np}\right)^2\left(\pi_{np}\right)^4\left(\pi_{np}^{*}\right)^3\left(\sigma_{np}^{*}\right)^1$$

F₂ 的 $\pi_{2p}^*$ 与 $\sigma_{2p}^*$ 能量差大，需要吸收能量高、波长短的光，显示剩余长波部分的补色（浅黄绿色）；随 n 增大，两反键轨道能差逐渐缩小，吸收光波波长由短到长，I₂ 主要吸收能量低、波长长的光而显紫黑色。

**溶解度与萃取**：卤素单质均不易溶于水（F₂ 除外，与水剧烈反应），相对溶解度 Br₂ 最大、I₂ 最小；易溶于有机溶剂，故可用 CCl₄ 等萃取（见例题 1 的验证方案）。I₂ 在 KI 溶液中因生成 I₃⁻（见 §七）而溶解度显著增大，这是「碘易溶于碘化钾溶液」的结构原因。

### 2.2 卤素单质的化学性质与储存

**与水反应**：F₂ 与水剧烈反应放出 O₂：$$\mathrm{2F_2 + 2H_2O = 4HF + O_2}\uparrow$$。其余卤素单质仅少量与水歧化，大部分以单质分子存在于水溶液中，歧化平衡常数依次减小：

$$\mathrm{Cl_2 + H_2O \rightleftharpoons HCl + HClO} \quad K = 5.6\times10^{-5}$$

$$\mathrm{3Br_2 + 3H_2O \rightleftharpoons 5HBr + HBrO_3} \quad K = 2.5\times10^{-9}$$

$$\mathrm{3I_2 + 3H_2O \rightleftharpoons 5HI + HIO_3} \quad K = 4.8\times10^{-16}$$

K 值说明 I₂ 歧化倾向极弱，常温下碘水基本上是 I₂ 分子溶液；碱性介质中反应可以进行完全，酸性环境中则发生归中反应。

**与金属反应——单质的储存**：F₂ 在任何温度下都与金属直接化合生成高价氟化物；但 F₂ 与 Cu、Ni、Mg 作用时，金属表面生成一薄层致密氟化物保护膜而使反应中止，因此 F₂ 可储存于 Cu、Ni、Mg 或其合金制成的容器中。Cl₂ 可与各种金属作用，但干燥的 Cl₂ 不与 Fe 反应，故 Cl₂ 可储存在铁罐中。Br₂、I₂ 常温下只能与活泼金属反应，与不活泼金属需加热。

**与非金属反应**：F₂ 除 O₂、N₂ 与稀有气体 He、Ne 外，能与所有非金属直接化合生成高价氟化物，低温下即可与 C、Si、S、P 剧烈反应，生成的氟化物大多具有挥发性。Cl₂ 能与大多数非金属直接作用，但不及 F₂ 剧烈。Br₂、I₂ 与非金属反应时不能将其氧化到最高价。

**与氢反应**：F₂ 在低温、黑暗中即与 H₂ 化合放出大量热而爆炸；Cl₂ 与 H₂ 需点燃才迅速化合，强光照射则爆炸；Br₂ 与 H₂ 需加热，且高温下 HBr 不稳定、易分解；I₂ 与 H₂ 加热反应且为可逆反应。这一活性递变是 §3 卤化氢性质的结构根源。

### 2.3 制备方法

| 卤素 | 实验室制法 | 工业制法 | 特点 |
|:---|:---|:---|:---|
| F₂ | K₂MnF₆ + 2SbF₅ → 2KSbF₆ + MnF₃ + ½F₂（Christe 化学法）| 电解 KHF₂ 熔盐（Moisson 法）| 只能用特殊方法，F⁻ 极难氧化 |
| Cl₂ | MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O | 电解饱和食盐水（氯碱工业）| 实验室可用氧化剂氧化 Cl⁻ |
| Br₂ | Cl₂ + 2Br⁻ → Br₂ + 2Cl⁻ | 海水提溴：Cl₂ 氧化 Br⁻ | 工业上从海水/卤水中提取 |
| I₂ | Cl₂ + 2I⁻ → I₂ + 2Cl⁻ | 海藻灰化→氧化 I⁻ | 从海带/卤水中提取 |

**F₂ 的特殊性**：
- F⁻ 极难氧化（标准电极电势 $E^\theta(\mathrm{F_2/F^-}) = +2.87\ \mathrm{V}$，是最难氧化的阴离子之一）
- 无法通过化学氧化从 F⁻ 得到 F₂（没有任何化学氧化剂比 F₂ 更强）
- 电解时也不能在水溶液中电解（水的氧化电势 +1.23 V < +2.87 V，先析 O₂）
- 只能用 **电解 KHF₂ 熔盐**（Moisson 法，~300°C）或 **Christe 化学法**（K₂MnF₆ + SbF₅）

> **竞赛考点**：电解食盐水为什么能得到 Cl₂？因为 Cl⁻ 放电电势（+1.36 V）低于 O₂ 析出电势（考虑过电位后），Cl⁻ 优先被氧化；而 F⁻ 放电电势（+2.87 V）远高于水，F⁻ 永远轮不到。

各单质制备的完整反应式如下。

**F₂——电解法（工业）**：电解质为氟氢化钾 KHF₂ 与 HF 的熔融混合物。石墨阳极：$$\mathrm{2F^- - 2e^- = F_2}\uparrow$$；钢阴极：$$\mathrm{2HF_2^- + 2e^- = H_2}\uparrow + \mathrm{4F^-}$$。总反应：

$$\mathrm{2KHF_2 = 2KF + H_2}\uparrow + \mathrm{F_2}\uparrow \quad（电解，熔融）$$

阴、阳极之间用钢网隔开，避免 F₂ 与 H₂ 接触发生爆炸。

**F₂——化学法（Christe 法，1986）**：先用 KMnO₄、KF、HF 与 H₂O₂ 制六氟合锰(Ⅳ)酸钾：$$\mathrm{2KMnO_4 + 2KF + 10HF + 3H_2O_2 = 2K_2MnF_6 + 8H_2O + 3O_2}\uparrow$$；强路易斯酸 SbF₅（由 $$\mathrm{SbCl_5 + 5HF = SbF_5 + 5HCl}$$ 制得）把较弱的路易斯酸 MnF₄ 从 $[\mathrm{MnF_6}]^{2-}$ 中置换出来：

$$\mathrm{K_2MnF_6 + SbF_5 \rightarrow KSbF_6 + MnF_4 + KF} \quad（423\ \mathrm{K}）$$

MnF₄ 热力学上不稳定，立即分解放出氟：$$\mathrm{MnF_4 = MnF_3 + \frac{1}{2}F_2}\uparrow$$。这是首例不经电解的制氟方法，要点是「用更强的路易斯酸夺取含氟络离子中的配体，迫使不稳定的金属氟化物分解」。

**Cl₂——实验室**：除 MnO₂ 法外，还可用 KMnO₄ 等强氧化剂与浓盐酸反应：$$\mathrm{2KMnO_4 + 16HCl = 2KCl + 2MnCl_2 + 5Cl_2}\uparrow + \mathrm{8H_2O}$$。

**Br₂——工业（海水提溴）**：氯气通入酸化（pH = 3.5）的苦卤：$$\mathrm{Cl_2 + 2Br^- = 2Cl^- + Br_2}$$，再用热空气把 Br₂ 吹出并吸收。酸化的目的是防止 Cl₂、Br₂ 在碱性介质中歧化损耗。

**Br₂——实验室**：$$\mathrm{MnO_2 + 2NaBr + 3H_2SO_4 = Br_2 + MnSO_4 + 2NaHSO_4 + 2H_2O}$$。

**I₂——工业**：方法一，智利硝石（NaNO₃ 中伴生少量 NaIO₃）制取 KNO₃ 的母液含 IO₃⁻，用还原剂 HSO₃⁻ 分两步还原：

$$\mathrm{2IO_3^- + 5HSO_3^- = I_2 + 5SO_4^{2-} + 3H^+ + H_2O}$$

$$\mathrm{IO_3^- + 5I^- + 6H^+ = 3I_2 + 3H_2O}$$

方法二，海藻（海带）灰化浸取后氧化 I⁻：$$\mathrm{Cl_2 + 2I^- = 2Cl^- + I_2}$$，必须控制 Cl₂ 用量——过量 Cl₂ 会把 I₂ 继续氧化成 IO₃⁻ 而损失。

**I₂——实验室**：$$\mathrm{2I^- + MnO_2 + 4H^+ = Mn^{2+} + I_2 + 2H_2O}$$。

## 三、卤化氢

### 3.1 酸性递变

$$\text{HF} \ll \text{HCl} < \text{HBr} < \text{HI}$$

| 性质 | HF | HCl | HBr | HI |
|:---|:---:|:---:|:---:|:---:|
| 酸性 | **弱酸** | 强酸 | 强酸 | **最强酸** |
| Ka | 6.6×10⁻⁴ | ~10⁷ | ~10⁹ | ~10¹¹ |
| 沸点 (K) | **293**（异常高）| 188 | 206 | 237 |
| 键能 (kJ/mol) | 565（最大）| 431 | 366 | 299 |
| 还原性 | 极弱 | 弱 | 中 | **强** |
| 热稳定性 | **最高** | 高 | 中 | **低** |

**核心原因**：H—X 键能递减（HF 键能极大，不易解离），**键能是 HX 酸性的主导因素**。

> **为什么 HF 是弱酸而 HCl 是强酸？**
> 三因素综合：① H—F 键能最大（565 kJ/mol），解离需更多能量；② F⁻ 水合能极大（−506 kJ/mol），部分补偿但不足以逆转；③ HF 水溶液中存在氢键（F—H···F⁻ 形成 HF₂⁻），消耗部分 HF。最终净效应：HF 仅部分解离 → 弱酸。

### 3.2 氢键异常

HF 分子间形成**强氢键**（H—F···H—F），导致沸点异常高（293 K，远高于 HCl 的 188 K）。其他 HX 无氢键，沸点仅受范德华力控制（HCl < HBr < HI）。

**HF 的特殊反应**：
- 刻蚀玻璃：$\mathrm{SiO_2 + 4HF \rightarrow SiF_4\uparrow + 2H_2O}$
- 必须用塑料瓶或铅皿盛装

**卤化银的溶解性**（鉴别卤离子的经典方法）：
$$\text{AgF} > \text{AgCl} > \text{AgBr} > \text{AgI}$$
白 → 白（光照变灰）→ 淡黄 → 黄，溶解度依次减小

**HF 的缔合与恒沸**：蒸气密度测定表明，常温下 HF 主要以缔合分子 (HF)₂ 和 (HF)₃ 形式存在，359 K 以上才以单分子状态出现；其他卤化氢常温下均为单分子。溶解性方面，HF 极性大，与水任意比互溶；1 L 水可溶解约 500 L HCl 气体。常压蒸馏氢卤酸时，溶液的沸点与组成不断变化，最后恒定下来的溶液称为恒沸溶液——这是市售盐酸浓度存在恒沸上限的原因。

**HF 浓溶液的酸性增强**：HF 稀溶液是弱酸，但浓度增大时表观酸性反而增强，因为 F⁻ 被络合成氢二氟根：

$$\mathrm{HF + F^- \rightleftharpoons HF_2^-} \quad K = 5$$

HF₂⁻ 的生成消耗 F⁻，使 HF 电离平衡右移。这是「弱酸浓溶液不弱」的反常点，处理浓 HF 体系时必须考虑。

### 3.3 无氧酸酸性比较的通用逻辑

> **同周期**：H—X 键能越弱 → 越易解离 → 酸性越强（如 H₂S < HCl）
> **同族**：X 原子半径越大 → H—X 键越长 → 越易断裂 → 酸性越强（HF < HCl < HBr < HI）
> **同一元素不同氧化数**：中心原子氧化数越高 → 吸引电子越强 → O—H 键越易断裂 → 酸性越强

> [!warning] 易错提醒
> 酸性强 ≠ 热稳定性强。HI 酸性最强但热稳定性最差；HF 酸性最弱但热稳定性最高——**两个顺序恰好相反**。

### 3.4 卤化氢的制备

**不挥发性酸制挥发性酸**：实验室制 HF、HCl 的经典路线是用浓硫酸与金属卤化物反应：

$$\mathrm{CaF_2 + H_2SO_4(浓) = CaSO_4 + 2HF}\uparrow$$

$$\mathrm{NaCl + H_2SO_4(浓) = NaHSO_4 + HCl}\uparrow \quad（微热）$$

$$\mathrm{2NaCl + H_2SO_4(浓) = Na_2SO_4 + 2HCl}\uparrow \quad（强热）$$

此路线的适用边界有两条：其一，HF 腐蚀玻璃，制备必须在铅皿中进行；其二，HBr、HI 还原性较强，会被浓硫酸氧化，故改用非氧化性的磷酸：

$$\mathrm{NaBr + H_3PO_4 = NaH_2PO_4 + HBr}\uparrow \quad（加热，制 HI 同理）$$

**直接化合**：工业上仅用 Cl₂ 与 H₂ 直接化合制备 HCl（$$\mathrm{H_2 + Cl_2 = 2HCl}$$，点燃）；F₂ 反应太剧烈，Br₂、I₂ 与 H₂ 化合缓慢且不完全，均不采用。

**卤化物水解法**：

$$\mathrm{PX_3 + 3H_2O = H_3PO_3 + 3HX} \quad (X = \mathrm{Br},\ \mathrm{I})$$

三类方法的选择逻辑：原料酸要有足够挥发性、不能氧化产物 HX，且要考虑目标 HX 的热稳定性。

## 四、卤素歧化反应与元素电势图

### 4.1 氯的元素电势图（Latimer 图）

**酸性条件**（pH = 0）：

$$\mathrm{ClO_4^- \xrightarrow{1.19} ClO_3^- \xrightarrow{1.21} HClO_2 \xrightarrow{1.65} HClO \xrightarrow{1.61} Cl_2 \xrightarrow{1.36} Cl^-}$$

**碱性条件**（pH = 14）：

$$\mathrm{ClO_4^- \xrightarrow{0.36} ClO_3^- \xrightarrow{0.33} ClO_2^- \xrightarrow{0.66} ClO^- \xrightarrow{0.40} Cl_2 \xrightarrow{1.36} Cl^-}$$

**歧化反应判断规则**：对于相邻三种氧化态 A → B → C，若右侧标准电极电势大于左侧标准电极电势，则 B 能歧化为 A 和 C。

### 4.2 Cl₂ 的歧化行为分析

| 条件 | 左半反应 $E^\theta$ | 右半反应 $E^\theta$ | 池电势 $E^\theta$ | 是否歧化 | 产物 |
|:---:|:---:|:---:|:---:|:---:|:---|
| 酸性 | Cl⁻/Cl₂: 1.36 V | Cl₂/HClO: 1.61 V | −0.25 V | 不歧化（逆向归中）| 逆向：HClO + HCl → Cl₂ |
| 碱性 | Cl⁻/Cl₂: 1.36 V | Cl₂/ClO⁻: 0.40 V | +0.96 V | **歧化** | Cl⁻ + ClO⁻ |

> **核心结论**：Cl₂ 在碱性条件下歧化，在酸性条件下不歧化（逆向归中反应自发）。这就是 84 消毒液（NaClO）不能与洁厕灵（HCl）混用的原因——归中反应产生有毒 Cl₂。

### 4.3 卤素与碱反应的温度效应

| 卤素 | 冷稀碱（<15°C） | 热浓碱（>70°C） |
|:---|:---|:---|
| Cl₂ | Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O | 3Cl₂ + 6OH⁻ → 5Cl⁻ + ClO₃⁻ + 3H₂O |
| Br₂ | Br₂ + 2OH⁻ → Br⁻ + BrO⁻ + H₂O | 3Br₂ + 6OH⁻ → 5Br⁻ + BrO₃⁻ + 3H₂O |
| I₂ | 3I₂ + 6OH⁻ → 5I⁻ + IO₃⁻ + 3H₂O（**常温即到 IO₃⁻**）| 同左 |
| F₂ | 2F₂ + 4OH⁻ → 4F⁻ + O₂ + 2H₂O（**不歧化，氧化水**）| 同左 |

> [!tip] 理解要点
> **判据**：冷稀碱 → 次卤酸根，热浓碱 → 卤酸根；I₂ 特殊，常温即歧化到碘酸根；F₂ 特殊，无正氧化态，不发生歧化（氧化水）。

> **本质解释**：ClO⁻ 在高温下自身歧化 3ClO⁻ → 2Cl⁻ + ClO₃⁻。所以低温碱 → 次氯酸盐（漂白液），高温碱 → 氯酸盐（氯酸钾原料）。

## 五、卤化物与卤素互化物

### 5.1 金属卤化物：氧化态规律与离子极化

除 He、Ne、Ar 外，几乎所有元素都与卤素形成卤化物。氟的氧化能力强，元素形成氟化物往往呈现最高价：SiF₄、SF₆、IF₇、OsF₈；而碘的氧化能力弱得多，元素形成碘化物往往呈较低氧化态：CuI、Hg₂I₂。卤化物按化学键类型分为两类：离子型（碱金属、碱土金属及较活泼金属、镧系锕系元素的低价态）与共价型（大多数金属的高价态卤化物及非金属卤化物，如 AlCl₃、FeCl₃、SnCl₄、TiCl₄）。金属氟化物主要显离子型。

**离子极化的三重后果**：碱金属、碱土金属的卤化物是典型的离子型化合物，离子性随金属氧化数增高、半径减小而减弱；同一金属低价态显离子型、高价态显共价型（SnCl₂ 离子型、SnCl₄ 共价型）。离子极化导致三类物理性质递变：

| 性质 | 极化规律 | 实例 |
|:---|:---|:---|
| 溶解度 | F⁻ 变形性小，AgF、Hg₂F₂ 显离子型而溶于水；Cl⁻→I⁻ 变形性依次增大，共价性增强，溶解度递减 | 溶解度 AgCl > AgBr > AgI |
| 颜色 | 极化使外层电子变形、价电子与核结合松弛，更易吸收可见光，颜色加深 | AgCl 白 → AgBr 浅黄 → AgI 黄 |
| 熔点 | 共价成分增多 → 熔沸点降低 | 熔点 MgCl₂ > CuCl₂ |

**卤离子的配位溶解**：难溶卤化物可溶于过量卤离子生成可溶性络离子，这是「沉淀溶解于浓盐酸、浓 KI」的原因：

$$\mathrm{CuCl + Cl^- = [CuCl_2]^-} \qquad \mathrm{CuCl_2 + 2Cl^- = [CuCl_4]^{2-}}\ （绿色）$$

$$\mathrm{Hg^{2+} + 2I^- = HgI_2}\downarrow \qquad \mathrm{HgI_2 + 2I^- = [HgI_4]^{2-}}\ （无色）$$

金属卤化物的重要工业制法还包括金属氧化物的氯化（氯化法）：$$\mathrm{TiO_2 + 2C + 2Cl_2 = TiCl_4 + 2CO}$$（加热），是钛白粉氯化制 TiCl₄ 的关键步骤。

> **判断要点**：卤素互化物中**电负性小的做中心，与原子序数无关**——IF₇ 中 I 做中心不是因为原子序数大，而是因为 I 电负性（2.5）小于 F（4.0）。

| BrF₅ | Br | 6 | sp³d² | 四方锥 | AX₅E |
| IF₇ | I | 7 | sp³d³ | 五角双锥 | AX₇ |
| ICl₃ | I | 5 | sp³d | T 型 | AX₃E₂ |
| ICl | I | 2 | sp | 直线 | AX₂ |

### 5.3 拟卤素

**定义**：某些由非金属原子组成的原子团，其性质与卤素单质相似。拟卤素也能形成「拟卤化氢」（如 HCN、HSCN）和「拟卤化银」等。

| 拟卤素 | 对应酸（酸性） | 银盐 | 特征 |
|:---|:---|:---:|:---|
| (CN)₂（氰）| HCN（弱酸）| AgCN↓（白色）| 剧毒 |
| (SCN)₂（硫氰）| HSCN（强酸）| AgSCN↓（白色）| 与 Fe³⁺ 显血红色 |
| (SeCN)₂（硒氰）| HSeCN | AgSeCN↓ | 类比 SCN |

**与卤素的类比反应**：

| 反应类 | 卤素反应 | 拟卤素类比 |
|:---|:---|:---|
| 与 H₂ | Cl₂ + H₂ → 2HCl | (CN)₂ + H₂ → 2HCN |
| 与金属 | Cl₂ + 2Na → 2NaCl | (CN)₂ + 2Na → 2NaCN |
| 歧化 | Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O | (CN)₂ + 2OH⁻ → CN⁻ + CNO⁻ + H₂O |
| 与 Fe³⁺ 显色 | — | 3SCN⁻ + Fe³⁺ → Fe(SCN)₃（血红色）|

拟卤素主要包括 (CN)₂（氰）、(SCN)₂（硫氰）、(OCN)₂（氧氰）、(SeCN)₂（硒氰）。物理性质上，(CN)₂ 剧毒、有苦杏仁味，273 K 时 1 L 水约溶解 4 L，常温为无色气体；(SCN)₂ 不稳定、易聚合成 (SCN)x 多聚物，为不溶于水的砖红色固体。

**拟卤化氢的酸性量级**：HCN（$K_a = 4.0\times10^{-10}$，极弱）< HOCN（$1.2\times10^{-4}$）< HSCN（$1.4\times10^{-1}$，强酸）——除 HCN 外酸性都较强。

**与水歧化**：(CN)₂ 与卤素类似可发生歧化，水中：$$\mathrm{(CN)_2 + H_2O = HCN + HOCN}$$；碱中：$$\mathrm{(CN)_2 + 2OH^- = CN^- + OCN^- + H_2O}$$。

**拟卤化物的溶解性与配位溶解**：重金属氰化物（AgCN、Pb(CN)₂、Hg₂(CN)₂ 等）与重金属硫氰酸盐（AgSCN、Pb(SCN)₂、Hg(SCN)₂ 等）都难溶于水；碱金属氰化物溶解度很大，但在水中强烈水解显碱性并放出 HCN。难溶盐可溶于过量 CN⁻／SCN⁻ 生成可溶性配合物：

$$\mathrm{AgCN + CN^- = [Ag(CN)_2]^-} \qquad \mathrm{AgI + 2CN^- = [Ag(CN)_2]^- + I^-}$$

$$\mathrm{Fe^{3+} + xSCN^- = [Fe(SCN)_x]^{3-x}}$$（血红色，x = 1～6，随 SCN⁻ 浓度变化）

Fe³⁺ 与 SCN⁻ 生成一系列配位数可变的血红色配合物，这是 Fe³⁺ 鉴定的化学基础，也是配合物平衡移动的常用素材。

**氧化还原性**：拟卤素氧化能力总体低于 Cl₂、Br₂，且彼此差异很大，使用时应逐个核对电极电势，不能一概而论——共性是类比基础，差异是考题考点。

**氰化物废液的处理**：氰化物剧毒，毫克量级即可致死，含氰废液必须处理。碱性条件下用 ClO⁻ 分步氧化：第一步 $$\mathrm{CN^- + ClO^- = OCN^- + Cl^-}$$（生成的 OCN⁻ 仍有毒性）；酸性条件下继续氧化至完全无毒：$$\mathrm{2OCN^- + 3ClO^- + 2H^+ = 2CO_2}\uparrow + \mathrm{N_2}\uparrow + \mathrm{3Cl^- + H_2O}$$。亦可用臭氧在加热下直接氧化：$$\mathrm{2CN^- + 5O_3 + H_2O = 2HCO_3^- + N_2 + 5O_2}$$（加热）。

> **类比边界**：拟卤素是「类卤素」不是「卤素」——氧化性顺序与卤素不同。例如 **(CN)₂ 不能置换 I₂**（按卤素逻辑应能置换，但实验事实是不能）。类比是认知捷径，但每个拟卤素都有自己的 $E^\theta$，需逐个确认；「共性是类比基础，差异是考题考点」。

> [!info] 深入思考
> 看到 CN⁻ 或 SCN⁻ 的反应，先思考「如果换成 Cl⁻/Br⁻/I⁻ 会怎样？」，再反推差异点。这是元素推断题的常用思路。

## 六、卤素氧化物与含氧酸

### 6.1 氯的含氧酸体系

| 含氧酸 | 氧化态 | 非羟基氧数 | pKa | 酸性 | 氧化性 | 结构特点 |
|:---|:---:|:---:|:---:|:---|:---|:---|
| HClO（次氯酸）| +1 | 0 | 7.5 | 极弱酸 | **极强** | Cl—O—H |
| HClO₂（亚氯酸）| +3 | 1 | 2.0 | 中强酸 | 强 | — |
| HClO₃（氯酸）| +5 | 2 | −1.2 | 强酸 | 中强 | — |
| HClO₄（高氯酸）| +7 | 3 | −10 | **最强无机酸** | **极弱**（动力学惰性）| 正四面体 |

**核心递变规律**：

$$\text{氧化数升高} \rightarrow \text{酸性增强、氧化性减弱}$$

**解释**：
- **酸性递增**（Pauling 规则）：非羟基氧数 N 越多 → 中心 Cl 电负性越强 → O—H 键中电子被拉向 Cl → H⁺ 越易解离（pKa ≈ 7 − 5N）
- **氧化性递减**：Cl 氧化数越高 → Cl—O 键共价性越强 → 键越牢固 → 越难断裂释放氧化能力；同时 ClO₄⁻ 对称性高 → 反应活化能大（动力学惰性）

### 6.2 奇偶价规律（卤素氧化物稳定性）

> **认知冲突**：一般氧化物「高价更稳定」（SO₃ > SO₂），但卤素氧化物例外——**ClO₂（+4）稳定存在，而 Cl₂O₃（+3）不稳定、易歧化；Cl₂O₆（+6）稳定，而 Cl₂O₅（+5）不存在**。

| 氯的氧化态 | 氧化物 | 稳定性 |
|:---:|:---|:---:|
| +1 | Cl₂O | ✅ 稳定 |
| +3 | Cl₂O₃ | ✗ 不稳定/歧化 |
| +4 | ClO₂ | ✅ 稳定（有单电子但 π 键稳定化）|
| +5 | Cl₂O₅ | ✗ 不存在 |
| +6 | Cl₂O₆ | ✅ 稳定 |
| +7 | Cl₂O₇ | ✅ 稳定 |

> **规律**：**奇数价态的卤素氧化物往往比邻近偶数价态更稳定**。本质是结构稳定性的问题——奇数价态往往允许更有利的电子自旋配对；偶数价态夹在中间倾向于二聚或歧化。ClO₂ 有单电子却可存在，说明「结构稳定性 > 价态直觉」。

### 6.3 热力学 vs 动力学（含氧酸氧化性辨析）

> **认知冲突**：HClO₄ 是 +7 价最强无机酸，但它在溶液中氧化性极弱；HClO（+1）氧化性反而最强。为什么「最强酸」不是「最强氧化剂」？

**两套独立的判断坐标**：

| 维度 | 判断依据 | 例子 |
|:---|:---|:---|
| **热力学氧化能力**（能不能）| 电极电势 $E^\theta$ | HClO₄ 的 $E^\theta$ < HClO₃ 的 $E^\theta$ → 热力学氧化性弱 |
| **动力学反应速率**（快不快）| 活化能/对称性 | ClO₄⁻ 对称性高 → 活化能大 → 反应慢 |

> **类比**：电极电势像地图上的海拔差（告诉你从 A 到 B 能释放多少势能），活化能像中间隔了一座山（决定走得快不快）。「电势大 ≠ 反应快」——题目问氧化能力看 $E^\theta$，问反应快慢看动力学。

**补充**：固体高氯酸盐在高温下是强氧化剂（热力学在高能态下占主导），但溶液中的 HClO₄ 却动力学惰性。

### 6.4 其他卤素的含氧酸

**溴的含氧酸**：
- 酸性递变规律同氯：HBrO < HBrO₂ < HBrO₃ < HBrO₄
- HBrO₄ 的氧化性反常地 **强于** HClO₄：Br 的原子半径明显大于 Cl，Br—O 键较弱、易断裂，且 Br(Ⅶ) 的氧化性本就强于 Cl(Ⅶ)（同族从上到下高价氧化性递增）。
  > **口径提示**：「d 轨道参与成键」是早期解释，现代认为主族元素 d 轨道能量过高、基本不参与成键；高价卤素含氧酸的不稳定性用「键能 + 中心原子氧化性」已足够解释。

**碘的含氧酸**：
- 高碘酸的化学式为 **H₅IO₆**（不是 HIO₄！），为六配位八面体结构
- H₅IO₆ 为中强酸（pKa₁ = 1.6），氧化性强

**卤素含氧酸稳定性**：HClO > HBrO > HIO（同族从上到下稳定性递减）

### 6.5 次卤酸及其盐

HXO 的 $K_a$：HClO（$3.4\times10^{-8}$）> HBrO（$2\times10^{-9}$）> HIO（$1\times10^{-11}$）。酸性随 X 半径增大而减弱的结构解释：H—O—X 中 X—O 结合力随半径增大而减小，X 对 O 上电子的吸引减弱，O—H 键增强，H⁺ 更难解离。

HXO 均不稳定、仅存在于水溶液中，稳定性从 Cl 到 I 递减，分解有两类方式——光照分解：$$\mathrm{2HClO = 2HCl + O_2}\uparrow$$；加热歧化：$$\mathrm{3HClO = 2HCl + HClO_3}$$。

各族细节：HOF 常温下即自发分解为 HF 和 O₂，与 H₂O 迅速反应（稀酸溶液中生成 H₂O₂，碱性溶液中 O₂ 是主要产物）；BrO⁻ 室温即发生歧化，只有在 273 K 时才存在，323～353 K 时完全转化为 BrO₃⁻；IO⁻ 歧化更快，溶液中不存在次碘酸盐。不稳定性正是 HXO 强氧化性的另一面：$$\mathrm{2HClO + 2HCl = 2Cl_2}\uparrow + \mathrm{2H_2O}$$、$$\mathrm{3HClO + S + H_2O = H_2SO_4 + 3HCl}$$。XO⁻ 盐比 HXO 酸稳定，故常在酸性介质中用其盐作氧化剂：$$\mathrm{KClO + PbCl_2 + H_2O = PbO_2 + 2HCl + KCl}$$。

HClO 的制备：次氯酸酐 Cl₂O 溶于水：$$\mathrm{Cl_2O + H_2O = 2HClO}$$；或电解冷的稀 NaCl 溶液并搅拌，使生成的 Cl₂ 与 NaOH 充分反应得到 NaClO 后酸化：$$\mathrm{Cl_2 + 2NaOH = NaCl + NaClO + H_2O}$$，$$\mathrm{ClO^- + H^+ = HClO}$$。

### 6.6 亚卤酸及其盐

亚卤酸中仅 HClO₂ 存在，$K_a = 5.0\times10^{-3}$，酸性远强于 HClO。HClO₂ 不稳定，其盐在溶液中较稳定且有强氧化性（NaClO₂ 固体加热、撞击会爆炸分解）。制备与转化路线：

$$\mathrm{H_2SO_4 + Ba(ClO_2)_2 = BaSO_4}\downarrow + \mathrm{2HClO_2}$$

滤去 BaSO₄ 即得 HClO₂，但随即分解：$$\mathrm{8HClO_2 = Cl_2}\uparrow + \mathrm{6ClO_2}\uparrow + \mathrm{4H_2O}$$

$$\mathrm{2ClO_2 + 2NaOH = NaClO_2 + NaClO_3 + H_2O} \qquad \mathrm{Na_2O_2 + 2ClO_2 = 2NaClO_2 + O_2}\uparrow$$

后两式分别是 ClO₂ 与碱作用的歧化吸收、以及制取较纯净 NaClO₂ 的方法——亚氯酸盐是 ClO₂ 漂白体系工业的重要中间体。

### 6.7 卤酸及其盐

**制备**三条路线：① 利用卤素在碱性介质中歧化：$$\mathrm{3X_2 + 6OH^- = 5X^- + XO_3^- + 3H_2O}$$——优点是 X⁻ 与 XO₃⁻ 易分离、反应彻底，缺点是 XO₃⁻ 的转化率只有 1/6；② 卤酸盐与硫酸复分解：$$\mathrm{H_2SO_4 + Ba(ClO_3)_2 = BaSO_4}\downarrow + \mathrm{2HClO_3}$$（硫酸浓度不宜过高，否则爆炸分解）；③ 直接氧化：$$\mathrm{I^- + 3Cl_2 + 6OH^- = IO_3^- + 6Cl^- + 3H_2O}$$、$$\mathrm{I_2 + 10HNO_3 = 2HIO_3 + 10NO_2 + 4H_2O}$$。

**稳定性**：HClO₃ 可存在的最大质量浓度为 40%、HBrO₃ 为 50%、HIO₃ 可以固体形式存在——稳定性依次增强。分解方式多样：

$$\mathrm{2HClO_3 \xrightarrow{h\nu} 2HCl + 3O_2}\uparrow \qquad \mathrm{4HClO_3 \xrightarrow{\Delta} HCl + 3HClO_4}$$

$$\mathrm{8HClO_3 \xrightarrow{\Delta} 4HClO_4 + 2Cl_2}\uparrow + \mathrm{3O_2}\uparrow + \mathrm{2H_2O}$$

$$\mathrm{4HBrO_3 \xrightarrow{\Delta} 2Br_2 + 5O_2}\uparrow + \mathrm{2H_2O} \qquad \mathrm{2HIO_3 \xrightarrow{\Delta} I_2O_5 + H_2O}$$

盐比相应酸稳定，但受热也分解。KClO₃ 的分解路径由条件决定（MnO₂ 催化是实验室制氧气的来源）：

$$\mathrm{2KClO_3 \xrightarrow[\Delta]{MnO_2} 2KCl + 3O_2}\uparrow \qquad \mathrm{4KClO_3 \xrightarrow{\Delta} KCl + 3KClO_4}$$

**氧化性**：$$\mathrm{HBrO_3 > HClO_3 > HIO_3}$$——注意不是随族向下递减。结构解释：分子构型相同时，Br 与 Cl 相比，外层 18 电子的 Br 吸引电子的能力大于 8 电子的 Cl；Br 与 I 相比同为 18 电子，但半径 Br < I，得电子能力 Br > I。故 BrO₃⁻ 的氧化能力最强。

**盐类溶解度**：氯酸盐基本可溶，但溶解度不大；溴酸盐中 AgBrO₃、Pb(BrO₃)₂、Ba(BrO₃)₂ 难溶，其余可溶；可溶性碘酸盐更少，Cu(IO₃)₂ 水合物为蓝色、无水盐为绿色，AgIO₃、Pb(IO₃)₂、Hg(IO₃)₂ 及 Ca、Sr、Ba 的碘酸盐均难溶。总规律：$$M\mathrm{ClO_3} > M\mathrm{BrO_3} > M\mathrm{IO_3}$$。

### 6.8 高卤酸及其盐

**制备**：① 酸置换：$$\mathrm{KClO_4 + H_2SO_4 = KHSO_4 + HClO_4}$$，减压蒸馏分离，温度须低于 365 K；② 电解法（工业）：Pt 阳极电解氧化盐酸，阳极反应 $$\mathrm{Cl^- + 4H_2O - 8e^- = ClO_4^- + 8H^+}$$，Ag／Cu 阴极析氢，可得 20% 溶液，减压蒸馏浓缩至 70%；③ 高溴酸需用 XeF₂ 或 F₂ 氧化溴酸盐：$$\mathrm{NaBrO_3 + XeF_2 + H_2O = NaBrO_4 + Xe + 2HF}$$、$$\mathrm{BrO_3^- + F_2 + 2OH^- = BrO_4^- + 2F^- + H_2O}$$；④ 高碘酸盐：$$\mathrm{Cl_2 + 6OH^- + IO_3^- = 2Cl^- + IO_6^{5-} + 3H_2O}$$，再酸化 $$\mathrm{Ba_5(IO_6)_2 + 5H_2SO_4 = 5BaSO_4}\downarrow + \mathrm{2H_5IO_6}$$。

**浓度与稳定性**：质量分数低于 60% 的 HClO₄ 溶液加热不分解；72.4% 的 HClO₄ 为恒沸混合物，476 K 时分解。55% 的 HBrO₄ 溶液稳定、不易分解，高于 55% 则不稳定。

**酸性**：$$\mathrm{HClO_4 > HBrO_4 > H_5IO_6}$$（$K_{a1} = 2.3$）。HClO₄ 是无机酸中最强的酸，在水中完全解离：Cl(+7) 对 O(−2) 的吸引力大于 H(+1) 与 O(−2) 的结合力，且抵抗 H⁺ 反极化的能力强。正高碘酸 H₅IO₆ 为无色单斜晶体，I 采取 sp³d² 杂化、六配位正八面体；强酸中以 H₅IO₆ 形式存在，碱中以 H₃IO₆²⁻ 形式存在。Cl→Br→I 半径逐渐增大，反极化力逐渐减小，酸性逐渐减弱。

**氧化性**：浓溶液中 $$\mathrm{HBrO_4 > H_5IO_6 > HClO_4}$$——浓 HClO₄ 以分子状态存在居多，H⁺ 的反极化作用使 HXO₄ 不稳定，表现强氧化性；而稀 HClO₄ 完全解离，ClO₄⁻ 为正四面体、对称性高、结构稳定，氧化能力低（稀 HClO₄ 甚至不能被 Zn 还原）。这与 §6.3 的热力学／动力学框架一致。

**盐类溶解度**：ClO₄⁻ 的 K⁺、Rb⁺、Cs⁺、NH₄⁺ 盐溶解度小，其余易溶；BrO₄⁻ 只有 K⁺、Rb⁺、Cs⁺ 盐相对可溶，其他盐基本难溶。

### 6.9 卤素的氧化物

卤素氧化物大多不稳定，重点掌握以下几种。

**OF₂**：将 F₂ 通过 2% 的 NaOH 溶液：$$\mathrm{2F_2 + 2OH^- = OF_2 + H_2O + 2F^-}$$。碱浓度必须低，否则 OF₂ 分解：$$\mathrm{OF_2 + 2OH^- = O_2 + 2F^- + H_2O}$$。

**Cl₂O**：1834 年即用氧化汞直接氧化氯气制得，是 HClO 的酸酐：$$\mathrm{Cl_2O + H_2O = 2HClO}$$。

**ClO₂**（稳定性见 §6.2 奇偶价规律）：制备有三条路线——亚氯酸钠氯化法 $$\mathrm{2NaClO_2 + Cl_2 = 2ClO_2 + 2NaCl}$$；草酸还原氯酸盐 $$\mathrm{2ClO_3^- + C_2O_4^{2-} + 4H^+ = 2ClO_2}\uparrow + \mathrm{2CO_2}\uparrow + \mathrm{2H_2O}$$；工业上用 SO₂ 还原氯酸钠。淡黄色气体，11°C 凝聚为液体，易溶于水与 CCl₄。

**BrO₂**：低温下以 CF₃Cl 为溶剂使溴与臭氧作用，得亮黄色晶体：$$\mathrm{Br_2 + 4O_3 = 2BrO_2 + 4O_2}$$（低温，CF₃Cl 溶剂）。不稳定，0°C 即分解：$$\mathrm{2BrO_2 = Br_2 + 2O_2}$$；在碱中歧化：$$\mathrm{6BrO_2 + 6OH^- = 5BrO_3^- + Br^- + 3H_2O}$$。

**I₂O₅**：最重要、热稳定性最好的碘氧化物，由 HIO₃ 在 200°C 下脱水制得，白色易吸潮固体，是碘酸的酸酐（溶于水生成碘酸）。氧化性的典型应用：$$\mathrm{I_2O_5 + 5CO = I_2 + 5CO_2}$$，该反应可定量测定空气或其他气体中的 CO 含量。I₄O₉ 为黄色吸湿物质，实为三碘酸碘 I(IO₃)₃。

## 七、多卤离子与结构深化

### 7.1 多碘阴离子的形成

碘离子可与 I₂ 结合生成多碘阴离子：

$$\mathrm{I^- \xrightarrow{+I_2} I_3^- \xrightarrow{+I_2} I_5^- \xrightarrow{+I_2} I_7^-}$$

| 离子 | 结构 | 说明 |
|:---|:---|:---|
| I₃⁻ | 直线形 | 中心 I 为 sp³d 杂化（5 对电子：2 成键 + 3 孤对）；实为 3c-4e 键，sp³d 仅是 VSEPR 简化记法，成键本质是 p 轨道三中心组合 |
| I₅⁻ | V 形（实际已知）| = I₃⁻ + I₂，I₂ 进攻端基碘孤对电子 |
| I₇⁻ | 多种异构体 | 由 I₅⁻ 的 V/T 构型继续加 I₂ 枚举去重得 6 种 |

### 7.2 为什么 I₃⁻ 的 I—I 键比 I₂ 长？

- I₃⁻ 中 I—I 键长 **2.91 Å**，而 I₂ 中 **2.71 Å**
- 类比 **$\mathrm{S_N2}$ 过渡态**：I₃⁻ 可看作「亲核试剂」I⁻ 进攻 I₂——I⁻ 的电子进入 I₂ 的 σ\* 反键轨道（LUMO），形成**三中心四电子（3c-4e）键**
- 反键轨道被占据 → I—I 键级降低 → **键长变长**，键能减弱
- I 原子半径大，可稳定容纳五配位，使 I₃⁻ 成为稳定物种（不同于 $\mathrm{S_N2}$ 过渡态的高能短命）

> [!info] 深入思考
> 超价化合物（I₃⁻、ICl₄⁻、XeF₂ 等）需要分子轨道理论解释，经典价键（8 电子规则）会失效。这是「结构化学基础」在决赛前的自然桥梁。

**多卤化物的通性**：多卤离子可看作卤素离子与卤素分子（或互卤化物）的加合物，结构与性质近似对应的卤素互化物，两点通性：

- **热稳定性差**，受热分解为卤化物、卤素或互卤化物：$$\mathrm{CsBr_3 \xrightarrow{\Delta} CsBr + Br_2}$$、$$\mathrm{CsICl_2 \xrightarrow{\Delta} CsCl + ICl}$$；
- **水解规律**：高价态的中心原子与水中的 OH⁻ 发生亲核取代生成含氧酸，低价态的配体与 H⁺ 结合生成氢卤酸：$$\mathrm{ICl + H_2O = HIO + HCl}$$（HIO 可继续歧化）、$$\mathrm{BrF_5 + 3H_2O = HBrO_3 + 5HF}$$。判断互卤化物水解产物时，先定中心原子氧化数，再按此规则拆分。

## 八、方法总结与思维框架

### 8.1 卤素介质判定速查表

| 先看条件 | 再看对象 | 结论 |
|:---|:---|:---|
| 酸性 / 水 | F₂ | 不按歧化处理，直接氧化水：2F₂ + 2H₂O → 4HF + O₂ |
| 酸性 / 水 | Cl₂ | 部分歧化：Cl₂ + H₂O ⇌ HCl + HClO |
| 酸性 / 水 | Br₂ | 歧化很少 |
| 酸性 / 水 | I₂ | 几乎不反应 |
| 冷稀碱 | Cl₂、Br₂ | 生成次卤酸根 XO⁻ |
| 冷稀碱 | I₂ | 直接到 IO₃⁻ |
| 冷稀碱 | F₂ | 不按歧化处理，仍表现为强氧化剂 |
| 热浓碱 | Cl₂、Br₂、I₂ | 生成卤酸根 XO₃⁻ |

> **判题顺序**：先看介质条件，再判是哪种卤素，最后单独检查 F₂ 这个特例。

### 8.2 卤素推断题四步法

| 步骤 | 做什么 | 示例 |
|:---|:---|:---|
| **1. 颜色状态定位** | 看颜色 → 锁定哪种卤素 | 黄绿气体 → Cl₂；红棕液体 → Br₂ |
| **2. 介质条件判产物** | 酸/碱/冷/热 → 歧化产物 | 冷碱 → ClO⁻；热碱 → ClO₃⁻ |
| **3. 沉淀显色验证** | AgX 颜色、CCl₄ 萃取、KI-淀粉 | AgCl 白、AgBr 淡黄、AgI 黄 |
| **4. 反常点检查** | F₂ 不歧化、HF 弱酸、ICl 中 I 正价 | 确认没有机械套递变规律 |

### 8.3 反常点总表

| 反常点 | 规律预期 | 实际 | 原因 |
|:---|:---|:---|:---|
| F₂ 键能 | 应最大 | 159 kJ/mol（最低之一）| 孤对电子排斥，2p 重叠效率低 |
| HF 酸性 | 应最强 | 弱酸（Ka=6.6×10⁻⁴）| H—F 键能极大（主导）|
| HF 沸点 | 应最低 | 293 K（最高）| 分子间强氢键 |
| F₂ 歧化 | 应歧化 | 氧化水不歧化 | F 无正氧化态 |
| I₂ 冷碱 | 应到 XO⁻ | 直接到 IO₃⁻ | I⁻ 更稳定，歧化彻底 |
| HClO₄ 氧化性 | 应最强 | 溶液中极弱 | 动力学惰性（对称性高）|
| 卤素氧化物 | 高价更稳 | 奇数价更稳 | 结构/自旋稳定性 |

## 九、典型例题

### 例题 1：卤素置换顺序

**题目**：将 Cl₂ 通入含有 Br⁻ 和 I⁻ 的混合溶液中，预测反应先后顺序并写出离子方程式。如何用实验验证产物？

**思路分析**：看到「Cl₂ 通入混合卤离子」→ 卤素氧化性顺序 F₂ > Cl₂ > Br₂ > I₂ → 对应卤离子还原性顺序 I⁻ > Br⁻ > Cl⁻ > F⁻。Cl₂ 优先氧化更强的还原剂 → 先氧化 I⁻。

**解答**：
(1) 反应先后顺序：
- **第一步**（优先）：$\mathrm{Cl_2 + 2I^- \rightarrow 2Cl^- + I_2}$（I⁻ 还原性更强）
- **第二步**（Cl₂ 足量时）：$\mathrm{Cl_2 + 2Br^- \rightarrow 2Cl^- + Br_2}$

(2) 实验验证（CCl₄ 萃取）：先见 CCl₄ 层呈**紫色**（I₂），后变**红棕色**（Br₂）。

(3) **本质解释**：$E^\theta(\mathrm{Cl_2/Cl^-}) = 1.36$，$E^\theta(\mathrm{Br_2/Br^-}) = 1.07$，$E^\theta(\mathrm{I_2/I^-}) = 0.54\ \mathrm{V}$。Cl₂ 氧化 I⁻ 的 ΔG 更负 → 优先氧化 I⁻。

**反思**：考查的不是「谁反应」而是「谁先反应」——同一氧化剂对混合还原剂的氧化顺序由电极电势差决定。

### 例题 2：卤素歧化反应与电势图

**题目**：已知氯在碱性介质中的 Latimer 图：ClO⁻ →(0.40 V) Cl₂ →(1.36 V) Cl⁻。(1) 判断 Cl₂ 在碱性条件下能否歧化，写出离子方程式。(2) 为什么 84 消毒液不能与洁厕灵混用？

**思路分析**：歧化判断——中间氧化态 Cl₂ 右侧 $E^\theta$ 大于左侧 $E^\theta$ 则歧化自发。

**解答**：
(1) 池电势 $E^\theta = 1.36 − 0.40 = +0.96\ \mathrm{V} > 0$ → **歧化自发**。离子方程式：$\mathrm{Cl_2 + 2OH^- \rightarrow Cl^- + ClO^- + H_2O}$。

(2) 酸性条件 Cl₂ 不歧化（池电势 −0.25 V），**逆向归中自发**：$\mathrm{ClO^- + Cl^- + 2H^+ \rightarrow Cl_2\uparrow + H_2O}$。84 消毒液（含 ClO⁻）与洁厕灵（HCl）混合 → 产生有毒 Cl₂ → **不能混用**。

**反思**：同一体系在不同酸碱介质中反应方向可能完全相反。元素电势图是判断歧化方向的核心工具。

### 例题 3：HF 反常酸性解释

**题目**：HF 的 Ka = 6.6×10⁻⁴（弱酸），而 HCl 是强酸（Ka ~ 10⁷），两者相差 10¹⁰ 倍。从结构角度解释为什么 HF 的酸性显著弱于 HCl。

**思路分析**：看到「HF 弱酸 vs HCl 强酸」→ 想到 H—X 键能差异 + F⁻ 水合能 + 氢键三重因素。

**解答**：

| 因素 | HF | HCl | 比较结果 |
|:---|:---:|:---:|:---:|
| H—X 键能 (kJ/mol) | **565** | 431 | HF 键能最大 → 最难解离（主导因素）|
| X⁻ 水合能 (kJ/mol) | −506 | −351 | F⁻ 水合能极大 → 部分补偿，但不足以逆转 |
| 氢键影响 | 水溶液中存在 HF₂⁻ | 无 | 消耗部分 HF，降低表观酸性 |

**综合结论**：虽然 F⁻ 的水合能很大，但 H—F 键能过大这一「不利因素」占主导地位，导致 HF 仅为弱酸。

### 例题 4：卤素互化物结构判断

**题目**：用 VSEPR 理论判断 ICl₃ 和 BrF₅ 的分子构型，给出中心原子的杂化方式和孤对电子数。

**思路分析**：VSEPR 标准流程：计算中心原子价层电子对数 → 电子对几何 → 根据孤对电子位置确定实际构型。注意**中心原子由电负性决定**。

**解答**：
(1) **ICl₃**：价层电子对数 = (7+3)/2 = **5**；成键 3、孤对 **2**；杂化 **sp³d**；构型 **T 型**（AX₃E₂）。
(2) **BrF₅**：价层电子对数 = (7+5)/2 = **6**；成键 5、孤对 **1**；杂化 **sp³d²**；构型 **四方锥**（AX₅E）。

**反思**：卤素互化物是 VSEPR 理论应用的理想体系。关键是准确计算孤对电子数——孤对越多，实际构型与电子对几何的偏离越大。

### 例题 5：含氧酸综合比较

**题目**：比较 HClO、HClO₃、HClO₄ 的酸性和氧化性，解释「酸性递增、氧化性递减」的反向规律。

**思路分析**：用 Pauling 规则解释酸性（非羟基氧数），用 Cl—O 键强度 + 动力学解释氧化性。

**解答**：

| 含氧酸 | 非羟基氧数 N | pKa | 酸性 | Cl—O 键强度 | 氧化性 |
|:---|:---:|:---:|:---|:---|:---:|
| HClO | 0 | 7.5 | 极弱酸 | 弱 | 极强 |
| HClO₃ | 2 | −1.2 | 强酸 | 强 | 中 |
| HClO₄ | 3 | −10 | 极强酸 | 最强 | 极弱 |

**反向规律解释**：酸性递增（Pauling：pKa ≈ 7 − 5N）；氧化性递减（Cl 氧化数越高 → Cl—O 键越牢固，且 ClO₄⁻ 对称性高 → 活化能大 → 动力学惰性）。

### 例题 6：拟卤素类比推理

**题目**：已知 Cl₂ + 2NaOH(冷) → NaCl + NaClO + H₂O。预测 (CN)₂ 与 NaOH 反应的产物，写出配平的离子方程式。类似地，写出 (CN)₂ 与 H₂ 反应的方程式。

**思路分析**：看到「拟卤素」→ 类比 Cl₂ 的反应模式。

**解答**：
(1) $\mathrm{(CN)_2 + 2OH^- \rightarrow CN^- + CNO^- + H_2O}$（CN⁻ 对应 Cl⁻，CNO⁻ 对应 ClO⁻）
(2) $\mathrm{(CN)_2 + H_2 \rightarrow 2HCN}$

**反思**：拟卤素/卤素的类比如同一面双面镜——**主体结构**相同（歧化、与 H₂ 反应、与金属反应），但**细节数据**不同（HCN 是弱酸、(CN)₂ 不能置换 I₂）。类比是工具而非铁律。

### 例题 7：卤素氧化物稳定性判断（奇偶价规律）

**题目**：判断 ClO₂（+4）和 Cl₂O₃（+3）在常温下哪个更稳定？说明理由。

**思路分析**：看到「卤素氧化物稳定性」→ 不要套「高价更稳定」的通性，改用奇偶价规律。

**解答**：**ClO₂ 更稳定**。奇数价态的卤素氧化物往往比邻近偶数价态更稳定：+3 的 Cl₂O₃ 不稳定、易歧化；+4 的 ClO₂ 虽有单电子，但 π 键稳定化使其可稳定存在。同理 Cl₂O₆（+6）稳定而 Cl₂O₅（+5）不存在。

**反思**：这是竞赛与高中认知的分水岭——「结构稳定性 > 价态直觉」。

### 例题 8：多卤离子的键长变化

**题目**：I₃⁻ 的 I—I 键长（2.91 Å）比 I₂（2.71 Å）长，用分子轨道观点解释。

**思路分析**：键长变长 → 键级降低 → 反键轨道被占据。

**解答**：I₃⁻ 可看作 I⁻ 进攻 I₂ 的 σ\* 反键轨道（LUMO），形成 3c-4e 键。反键轨道被占据 → I—I 键级从 1 降至 ~0.5 → **键长变长、键能减弱**。中心 I 以 sp³d 杂化容纳 5 对电子。

**关联**：本题来自第 39 届初赛 [[题-039-4-碘量法测定KI浓度]]，还涉及 I₅⁻/I₇⁻ 的异构体计数。

## 十一、本讲小结

1. **氢的成键光谱**：H⁺ / H⁻ / 共价三种形态，氢化物分离子型/共价型/金属型三类；NaH 的 H⁻ 是强还原剂。
2. **卤素递变主线**：F₂ → I₂ 氧化性递减、X⁻ 还原性递增、颜色加深、熔沸点升高；F₂ 键能反常低。
3. **介质决定方向**：Cl₂ 酸性不歧化、碱性歧化；冷稀碱 → XO⁻、热浓碱 → XO₃⁻；F₂ 永远不歧化。
4. **电势图是工具**：Latimer/Frost 图判歧化方向——右侧 $E^\theta$ > 左侧 $E^\theta$ 即歧化。
5. **含氧酸反向规律**：酸性递增（Pauling 非羟基氧）、氧化性递减（键牢固 + 动力学惰性）。
6. **互化物/拟卤素**：电负性小做中心；拟卤素「类比 + 差异标注」双轨思维。
7. **结构深化**：I₃⁻ 的 3c-4e 键解释键长变长；超价化合物需 MO 理论。

## 十四、参考答案与提示

> 各题详细解答、配平过程与评分要点见对应题卡；此处只给判题抓手。

**1.** 终点反应为 $2\mathrm{Ag^+} + \mathrm{CrO_4^{2-}} = \mathrm{Ag_2CrO_4}\downarrow$（砖红）；由 AgNO₃ 用量计算 Cl⁻ 浓度；终点时先由 $K_{sp}(\mathrm{Ag_2CrO_4})$ 与 $[\mathrm{CrO_4^{2-}}] = 0.020$ mol/L 求 $[\mathrm{Ag^+}]$，再代入 $K_{sp}(\mathrm{AgCl})$ 求残余 Cl⁻；酸性介质中 $\mathrm{CrO_4^{2-}}$ 转化为 $\mathrm{HCrO_4^-}$／$\mathrm{Cr_2O_7^{2-}}$，终点推迟。详解见 [[题-001-上海中学-卤族元素-习题1]]。

**2.** 抓住「四面体气体＋KClO₃ 低温氟化」确定 A 组成；(2)(3)(4) 均为非氧化还原反应，按原子守恒与类质同晶线索配平。详解见 [[题-002-上海中学-卤族元素-习题2]]。

**3.** 由 BaSO₄ 与 AgX 沉淀质量反推 n 与原化合物组成；注意「不含某元素」的结论来自两组沉淀质量的比例关系。详解见 [[题-003-上海中学-卤族元素-习题3]]。

**4.** (1) CN⁻ 配位把 Au 的氧化溶解与 Zn 的还原提取耦合成两个电极电势差极大的自发反应，$K$ 由 $K_{稳}$ 与 $\lg K = n\varepsilon^{\ominus}/0.059$ 计算；(2) 除杂试剂须除去 Cl₂ 而不吸收 CO₂；处理率大小比较用碳元素守恒。详解见 [[题-004-上海中学-卤族元素-习题4]]。

**5.** 由 I₂／S₂O₃²⁻ 计量比定 A 为 BrO₂，其后各问按氧化态递推（B 为 BrO₂F，C 为 BrF₃）；C 的电离是 BrF₃ 的自耦电离。详解见 [[题-005-上海中学-卤族元素-习题5]]。

**6.** 由 Xe 质量分数与 BF₄⁻ 组成确定 C 的化学式；正离子中 C—Xe 键是「有机氙」的结构判据；IF₅ 构型用 VSEPR（AX₅E）判断。详解见 [[题-006-上海中学-卤族元素-习题6]]。

**7.** (1) 设计热力学循环：键能（Cl₂⁺）= 键能（Cl₂）+ 电离能（Cl）− 电离能（Cl₂）= 242 + 1250 − 1085 = 407 kJ/mol；(2) ① 酸性归中、碱性歧化，由自发方向定 1.63 与 0.40；② 由 $E_{电池}$ 求 K，再求氯水 pH ≈ 1.5。详解见 [[题-007-上海中学-卤族元素-习题7]]。

**8.** 步骤 A：$\mathrm{IO_3^- + 5I^- + 6H^+ = 3I_2 + 3H_2O}$；步骤 C：$\mathrm{IO_3^- + 8I^- + 6H^+ = 3I_3^- + 3H_2O}$；滴定：$\mathrm{2S_2O_3^{2-} + I_3^- = S_4O_6^{2-} + 3I^-}$。不能直接滴定是因为剩余 IO₃⁻ 会氧化 S₂O₃²⁻；水封防止 I₂ 挥发。详解见 [[题-039-4-碘量法测定KI浓度]]。
