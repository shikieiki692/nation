## §1 方法总纲：推断四步法

**关联知识点**：元素推断
**主线**：推断题不是「回忆元素性质」的记忆题，而是「由现象证据锁定唯一答案」的推理题。题目给的每一个现象都是**信号**，你的任务是把信号按优先级组织起来，先建候选、再排除、后验证。

### 1.1 推断题的本质

1. 题目现象（颜色/沉淀/气体/焰色/磁性/溶解性）

2. 信号 → 候选元素列表（≤4 个）

3. 否定排除 + 交叉验证 → 唯一元素

4. 价态 + 化合物 + 关键方程式（反向验证全链）

三条基本准则：

1. **现象 ≠ 结论**：每一个现象都要问「它还可能是谁？」（单一颜色通常 2-4 种可能）。

2. **否定信息与肯定信息同等重要**：「不溶解」「无沉淀」「无色」是排除法的利器。

3. **最后一题验证全链**：推断结果必须能解释**所有**题目条件（包括否定信息），否则回头重查。

### 1.2 推断四步法（核心方法论）

| 步骤 | 核心操作 | 依据 KP | 检查点 |
|:---:|:---|:---|:---|
| **① 提取信号** | 通读题目，标出所有现象与条件；把「不/无/没有」全部圈出；确认介质（酸/碱/中性）、温度、浓度 | 元素化学 | ☐ 颜色 ☐ 沉淀 ☐ 气体 ☐ 焰色 ☐ 磁性 ☐ 所有「不」字 ☐ 介质/条件 |
| **② 最强信号 → 候选列表** | 从五类信号中选最特征的一条，查信号-响应矩阵，列出可能元素（**≤4 个**） | 焰色反应 · 难溶物 · 过渡金属通性 | ☐ 最强信号已识别 ☐ 候选 2-4 个 ☐ 每个候选都有依据 |
| **③ 否定排除 + 交叉验证** | 用其他信号（尤其否定信息）逐条排除候选；矛盾时回到硬约束重查 | 铬 · 锰 · 铁 · 铜 · 主族元素化学 | ☐ 每个候选都过至少一条其他信号 ☐ 否定信息已用 ☐ 剩余候选 ≤2 |
| **④ 定价态 + 反向验证** | 根据介质与氧化还原行为定氧化态；写关键方程式；逐条回核全部条件 | 价态-氧化态-形式电荷 · 元素化学 | ☐ 价态与介质一致 ☐ 颜色与电子构型一致 ☐ 全部条件被解释 ☐ 结果唯一 |

推断四步法的闭环关系见图 1（抓取信号 → 建立候选池 → 否定排除 → 反向验证）。

**值得注意（假熟悉陷阱）**：**第一眼最像的元素，往往不是最后答案。**
命题人最常用的手法就是「制造熟题错觉」——给你一个「看起来很熟」的信号（比如黄色沉淀），让你第一反应写 PbI₂，再用第二条证据推翻。破解：**先列 2-3 个候选再下笔**，永远不要凭第一个念头锁定答案。

**值得注意（推断即排除）**：**推断题不是记忆题，而是排除题。**
肯定信号只负责「把谁请进候选」，否定信号才决定「把谁赶出去」。只写「这个元素是 X」不够，必须写「为什么不是 Y/Z」——排除理由正是过程分所在。

## §2 颜色信号法

**关联知识点**：过渡金属通性
**主线**：颜色是最直观的信号，但**多数颜色不具有唯一性**。正确用法：颜色定候选范围，再靠沉淀行为/配位行为/氧化行为交叉锁定。

### 2.1 常见离子 / 固体颜色速查

| 颜色 | 可能物种 | 优先级 | 需配合的验证 |
|:---|:---|:---:|:---|
| 蓝色 | Cu²⁺（aq）、[Cu(NH₃)₄]²⁺（深蓝） | 强指向 | 加 NaOH 浅蓝沉淀；加 NH₃ 变深蓝 |
| 紫色 | MnO₄⁻（氧化性）、[Ti(H₂O)₆]³⁺（还原性） | 强指向 | 加酸是否褪色（MnO₄⁻ 酸性被还原褪色） |
| 绿色 | Cr³⁺、Ni²⁺、Fe²⁺（浅绿）、MnO₄²⁻（绿） | 弱指向 | 加 NaOH：Cr³⁺→灰绿沉淀溶于过量碱；Fe²⁺→白→绿→红棕 |
| 黄色 | Fe³⁺（水解黄棕）、CrO₄²⁻、VO₂⁺、Br₂ 水（橙黄） | 需区分 | 加 SCN⁻→血红（Fe³⁺）；加酸变橙（CrO₄²⁻） |
| 橙色 | Cr₂O₇²⁻、Br₂ | 强指向 | 加碱变黄（CrO₄²⁻） |
| 粉红 | Co²⁺、Mn²⁺（极淡） | 需区分 | 加 NH₃：Co²⁺→土黄→空气中变红 |
| 血红色 | Fe³⁺ + SCN⁻ | **唯一性** | 加 F⁻/PO₄³⁻ 褪色（掩蔽） |
| 黑色固体 | Fe₃O₄、FeO、CuO、MnO₂、PbS、CuS、Ag₂S | 需区分 | 结合其他线索（与酸反应/催化行为） |
| 白色固体/沉淀 | Zn²⁺/Al³⁺/Mg²⁺/Ca²⁺/Ba²⁺ 盐、TiO₂、SiO₂、AgCl、BaSO₄ | 弱指向 | 加酸/加过量碱/加氨水区分 |

**颜色进阶两问**：①这是**水合离子**的颜色还是**固体**的颜色？（固体中电荷转移色更深更艳，如 PbCrO₄ 黄、Fe₃O₄ 黑）②是 d-d 跃迁还是电荷转移？（MnO₄⁻ 的紫是 O→Mn 电荷转移，不是 d-d）。（见图 3）

### 2.2 信号优先级（四层）

| 优先级 | 信号类型 | 示例 | 可靠性 |
|:---:|:---|:---|:---:|
| 1 | **唯一性** | 焰色黄→Na；血红色→Fe³⁺+SCN⁻；NO 遇空气变红棕 | 几乎无干扰 |
| 2 | **组合信号** | 灰绿沉淀 + 溶于过量 NaOH → Cr³⁺ 指纹 | 两个特征 = 可靠 |
| 3 | **强指向** | 蓝色溶液→Cu²⁺；紫色→MnO₄⁻ | 少数干扰 |
| 4 | **弱指向** | 白色沉淀、无色溶液 | 需配合其他信号（见图 2） |

**值得注意（单一颜色不能定案）**：绿色溶液不是 Cr³⁺ 专属，而是 Cr³⁺、Ni²⁺、Fe²⁺（浅绿）、MnO₄²⁻ 四种可能，区分靠沉淀行为。

| 绿色来源 | 加 NaOH 后的沉淀行为 |
|:---|:---|
| Cr³⁺ | 灰绿沉淀，**溶于过量 NaOH**（两性） |
| Fe²⁺ | 白色沉淀**迅速变灰绿再变红棕**（被空气氧化） |
| Ni²⁺ | 浅绿色沉淀，不溶过量碱 |

单一颜色只能开「候选账户」，交叉验证才负责「结账」。

### 2.3 颜色驱动的推断策略

1. 紫色 → MnO₄⁻（氧化剂）或 [Ti(H₂O)₆]³⁺（还原剂）——用「是否褪色」区分；

2. 蓝色 → Cu²⁺——加 NH₃ 变深蓝确认；

3. 黄色/橙黄 → Fe³⁺ 或 Cr(VI)——加 SCN⁻ 确认 Fe³⁺，加酸变橙确认 CrO₄²⁻；

4. 血红色 → Fe³⁺ + SCN⁻——**唯一性信号**，直接锁定 Fe³⁺；

5. 白→灰绿→红棕 → Fe(OH)₂ 被空气氧化 → 原溶液含 Fe²⁺。

## §3 沉淀信号法与气体信号法

**关联知识点**：主族元素化学 · 难溶物
**主线**：沉淀的**颜色 + 溶解行为**两个维度构成强信号；气体的**气味 + 颜色变化 + 特征反应**构成强信号。两者都擅长「否定排除」。

### 3.1 沉淀颜色与溶解行为

| 触发条件（题目关键词） | 沉淀 | 颜色 | 溶解性特征 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|:---|:---|
| 白色沉淀，溶于氨水 | AgCl | 白 | 溶于 NH₃ 生成 [Ag(NH₃)₂]⁺ | Ag | 与 Hg₂Cl₂ 区分：后者加氨变灰黑 |
| 白色沉淀，不溶于稀酸 | BaSO₄ | 白 | 不溶于酸 | Ba/Sr | 与 BaCO₃（溶于酸放 CO₂）区分 |
| 黄色沉淀，不溶于稀酸 | CdS / PbI₂ | 黄 | CdS 不溶稀 HCl | Cd/Pb | 黄色 ≠ PbI₂ 专属 |
| 黑色沉淀，不溶于稀酸 | CuS / PbS / Ag₂S / HgS | 黑 | 均不溶稀 HCl | Cu/Pb/Ag/Hg | 需 HNO₃/王水区分 |
| 灰绿色沉淀，溶于过量 NaOH | Cr(OH)₃ | 灰绿 | 两性 → [Cr(OH)₄]⁻ | Cr | **Cr³⁺ 指纹反应** |
| 浅蓝色沉淀，溶于过量氨水 | Cu(OH)₂ | 浅蓝 | 过量 NH₃ → 深蓝 [Cu(NH₃)₄]²⁺ | Cu | 与 Ni(OH)₂（绿）区分 |
| 白色沉淀，溶于过量 NaOH | Al(OH)₃ / Zn(OH)₂ / Cr(OH)₃ | 白/灰绿 | 两性 | Al/Zn/Cr | 加过量氨水：Al(OH)₃ 不溶、Zn(OH)₂ 溶 |
| 白色沉淀，不溶于过量 NaOH 和氨水 | Mg(OH)₂ | 白 | 弱碱不溶 | Mg | 与两性组区分 |
| 砖红色沉淀 | Ag₂CrO₄ | 砖红 | 溶于酸 | Ag | 与 PbCrO₄（黄）区分 |
| 白→灰绿→红棕 | Fe(OH)₂ → Fe(OH)₃ | 白→红棕 | 空气氧化 | Fe | Fe²⁺ 经典鉴定 |

**沉淀信号的关键一步**：永远追问「这沉淀溶不溶」——不溶于什么（稀酸/过量碱/氨水/Na₂S₂O₃）比颜色更能区分候选。（见图 4）

### 3.2 气体信号

| 触发条件（题目关键词） | 气体 | 颜色/气味 | 特征反应 | 指向 |
|:---|:---|:---|:---|:---|
| 红棕色气体 | NO₂ / Br₂ | 红棕 | NO₂ 低温二聚变无色 N₂O₄；Br₂ 加水橙色 | N / Br |
| 无色气体，遇空气变红棕 | NO | 无色 | 2NO + O₂ → 2NO₂ | N（稀硝酸反应） |
| 无色刺激性，使品红褪色 | SO₂ | 无色 | 可逆漂白（加热复色） | S |
| 无色臭鸡蛋味 | H₂S | 无色 | 使 Pb(Ac)₂ 试纸变黑 | S |
| 黄绿色刺激性 | Cl₂ | 黄绿 | 使湿润 KI-淀粉试纸变蓝 | Cl |
| 无色，使带火星木条复燃 | O₂ | 无色无味 | 助燃 | 过氧化物/分解 |
| 无色，使澄清石灰水变浑浊 | CO₂ | 无色无味 | Ca(OH)₂ + CO₂ → CaCO₃↓ | C（碳酸盐） |
| 无色，与 HCl 产生白烟 | NH₃ | 无色刺激性 | NH₃ + HCl → NH₄Cl 白烟 | N（铵盐） |
| 无色，燃烧淡蓝色 | H₂ | 无色无味 | 2H₂ + O₂ → 2H₂O | 活泼金属与酸/水 |

**气体两大约分**：①「无色遇空气变红棕」是 NO 的**唯一性**信号（与 NO₂ 区分看颜色变化顺序）；②「使石灰水浑浊」SO₂ 也能做到（CaSO₃↓），需结合「能否漂白品红」区分。（见图 5）

## §4 价态变化法与配合物生成法

**关联知识点**：氧化还原 · 配合物
**主线**：前三种信号「看到什么」，后两种信号「反应后变成什么」——变色/歧化/配体诱导显色，指向性往往更强。

### 4.1 价态变化信号（价态数轴 + 歧化）

**核心问题**：题目给出「氧化还原导致的颜色变化」时，用价态数轴判断中间价态。

| 变化 | 涉及物种 | 条件 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|:---|
| 紫色→无色 | MnO₄⁻ → Mn²⁺ | 酸性 | Mn | 中性/碱性产物不同 |
| 紫色→棕色沉淀 | MnO₄⁻ → MnO₂ | 中性/弱碱 | Mn | 注意介质 |
| 紫色→绿色 | MnO₄⁻ → MnO₄²⁻ | 强碱 | Mn | 锰酸根绿，易歧化 |
| 橙色→绿色 | Cr₂O₇²⁻ → Cr³⁺ | 酸性还原 | Cr | Cr(VI)/Cr(III) 互化 |
| 黄色→橙色 | CrO₄²⁻ → Cr₂O₇²⁻ | 加酸 | Cr | pH 控制平衡 |
| 浅绿→黄色 | Fe²⁺ → Fe³⁺ | 氧化剂/空气 | Fe | Fe²⁺ 易被空气氧化 |
| 蓝色→无色 | Cu²⁺ → Cu⁺/Cu | 还原剂 | Cu | Cu⁺ 水溶液歧化 |

**中间价态歧化判断**：中间价态元素「既可升又可降」时，题目常考歧化。判据：查电势图，若左 $E^\theta$ < 右 $E^\theta$ 则歧化自发（如 Cu⁺：$E^\theta(\mathrm{Cu^{2+}/Cu^+})$=+0.15、$E^\theta(\mathrm{Cu^+/Cu})$=+0.52，左<右 → 歧化）。价态数轴一眼看出「谁在中间、能往哪头走」。（见图 6）

### 4.2 配合物生成信号（配体诱导颜色突变）

| 变化 | 涉及反应 | 关联元素 | 陷阱 |
|:---|:---|:---|:---|
| 无色→深蓝 | Cu²⁺ + 过量 NH₃ → [Cu(NH₃)₄]²⁺ | Cu | 与 [CuCl₄]²⁻（黄绿）区分 |
| 黄色→血红色 | Fe³⁺ + SCN⁻ → [Fe(SCN)]²⁺ | Fe | Fe²⁺ 不显色，需先氧化 |
| 白色沉淀→溶解 | AgCl + NH₃ → [Ag(NH₃)₂]⁺ | Ag | 与 Hg₂Cl₂（灰黑）区分 |
| 白色沉淀→溶解 | Zn(OH)₂ + 过量 NH₃ → [Zn(NH₃)₄]²⁺ | Zn | Al(OH)₃ 不溶过量氨水（关键区分！） |
| 无色→黄色/橙色 | 加配体形成有色配合物 | 视配体 | 配位显色 ≠ d-d 显色 |

**配位信号的鉴别威力**：「加过量氨水溶解」是 Zn²⁺ 与 Al³⁺ 的**指纹级区分**——Al(OH)₃ 不溶过量氨水，Zn(OH)₂ 溶解。这一条能独立判定 Zn。（见图 7）

### 4.3 介质和条件决定产物

同一物质在不同条件下产物不同——推断题最爱用这个设问。

| 体系 | 条件 | 产物 |
|:---|:---|:---|
| MnO₄⁻ | 酸性 / 中性 / 强碱 | Mn²⁺（近无色）/ MnO₂（棕沉）/ MnO₄²⁻（绿） |
| Cu + HNO₃ | 浓 / 稀 | NO₂（红棕）/ NO（无色，遇空气变红棕） |

## §5 否定信息利用与交叉验证

**关联知识点**：元素推断
**主线**：否定信息是推断题中「最不值钱却最能拉开分差」的部分——多数人忽略「不」字，高手靠「不」字一步到位。

### 5.1 「不」字标记法

通读题目时，把所有「不」「无」「没有」「难溶」「不溶」「不变色」**全部圈出来**。每条否定信息都是一次排除操作。操作要点：**「先列候选，再看证据；能排就排，不能先留。」**

### 5.2 四大否定信号排除表

| 否定信号 | 排除谁 | 保留谁 |
|:---|:---|:---|
| 「加 NaOH 不溶解」 | Al³⁺/Cr³⁺/Zn²⁺/Be²⁺（两性氢氧化物） | Mg²⁺/Ca²⁺/Fe³⁺/Cu²⁺ |
| 「加 HCl 无沉淀」 | Ag⁺/Pb²⁺/Hg₂²⁺ | 其余 |
| 「无色溶液」 | 多数过渡金属（d-d 有色） | d⁰：Ti⁴⁺/V⁵⁺；d¹⁰：Zn²⁺/Cu⁺/Ag⁺/Hg²⁺；主族 |
| 「酸性通 H₂S 无沉淀」 | Cu²⁺/Pb²⁺/Ag⁺/Hg²⁺（硫化物极难溶） | Zn²⁺/Mn²⁺/Fe²⁺（硫化物可溶稀酸） |

**额外常用否定信号**：

| 否定信号 | 排除谁 |
|:---|:---|
| 白色沉淀不溶于过量 NaOH | Al/Zn/Cr 两性组 |
| 无焰色反应 | Na（黄）/K（紫）/Ca（砖红）碱金属碱土金属（Mg/Be 除外） |
| 不溶于氨水 | AgCl（AgBr/AgI 也不溶，需结合颜色） |

### 5.3 「无色」不等于无过渡金属

**值得注意（d⁰/d¹⁰ 无色陷阱）**：「无色溶液」只能排除 d¹~d⁹ 有色离子，不能排除过渡金属——d⁰ 构型（Ti⁴⁺、V⁵⁺、Mo⁶⁺、W⁶⁺ 等无 d 电子）与 d¹⁰ 构型（Zn²⁺、Cu⁺、Ag⁺、Hg²⁺ 等 d 轨道全满）都无 d-d 跃迁、均呈无色。所以看到「无色溶液」要保留这两组过渡金属候选，再靠沉淀/配合物/氧化还原信号区分。

### 5.4 交叉验证决策路径

| 环节 | 判据 | 操作 |
|:---|:---|:---|
| 识别最强信号 | 唯一性信号 | 直接锁定 |
| | 组合信号 | 列 2~4 个候选 |
| | 单一信号 | 提取第二信号 |
| 否定信息排除 | 剩余候选 >2 | 提取第三信号交叉验证，回到候选 |
| | 剩余候选 ≤2 | 进入反向验证 |
| 反向验证 | 所有条件都能解释 | 定价态 + 写关键方程式 → 完成 |
| | 有条件不能解释 | 回溯、重新识别信号（止损） |

**止损原则**（初赛讲义第 6 讲）：**如果两个信号互相矛盾，回到硬约束重新检查**，而不是硬凑一个答案。最危险的不是不会，而是被表面熟词带偏。

**图解：否定信息排除法（“不字标记法”）**
| 候选池 | 信号1: 黑色沉淀 | 信号2: 不溶于强酸 | 信号3: 溶于热稀硝酸 | 结论 |
|:---|:---:|:---:|:---:|:---|
| $Ag_2S$ | ✔ | ✔ | ✔ | **保留 (候选)** |
| $FeS$ | ✔ | ✗ (溶于酸) | - | 排除 |
| $HgS$ | ✔ | ✔ | ✗ (仅溶于王水) | 排除 |
*利用“不/无”等强硬约束，迅速对候选池打叉*

## §6 五步推断法与进阶工具

**关联知识点**：提炼-化学竞赛初赛讲义-第6讲-推断技术
**主线**：前面是「实验现象驱动」的推断（四步法，第二轮主力）；遇到**数据零碎、物种陌生**的综合题，升级为「五步推断法」——从物理性质一路过滤到方程式。

### 6.1 五步推断法（进阶框架）

| 线索类型 | 步骤 | 核心问题 | 常用工具 |
|:---|:---|:---|:---|
| 物理性质 | ① 物理 → 缩小范围 | 颜色/磁性/溶解性能先排掉谁？ | 颜色表 + 溶解性表 + 磁性判据 |
| 结构数据 | ② 结构 → 确定类型 | 晶胞参数/构型/光谱在告诉我什么？ | VSEPR + 杂化 + 晶胞计算 |
| 化学性质 | ③ 反应性 → 定位元素 | 氧化还原/酸碱/配位/鉴定反应指向谁？ | 氧化还原 + 酸碱 + 配位 + 鉴定反应 |
| 定量数据 | ④ 热力学 → 排除错误 | $E^\theta$/$K_{sp}$/键能是否支持假设？ | 电势图 + 热力学判据（定性） |
| 方程式 | ⑤ 写方程式 → 验证全链 | 质量/电荷/现象全对得上吗？ | 氧化数法 + 半反应法 + 现象回核 |

**回查规则**：第五步验证不通过 → 回到前四步重新调整假设，**不是硬往下算**。

**磁性判据速查**（$\mu_{\mathrm{eff}}$ = √[n(n+2)] BM）：
| n | 1 | 2 | 3 | 4 | 5 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| $\mu_{\mathrm{eff}}$ / BM | 1.73 | 2.83 | 3.87 | 4.90 | 5.92 |

由 $\mu_{\mathrm{eff}}$ 反推未成对电子数 n → 判断 dⁿ 构型 → 辅助定位元素（配合物推断常用）。

### 6.2 广义复盐法（整体打包）

**适用**：陌生化学式 + 热重/组成数据题。把一个陌生物**形式上拆成「已知盐 + 氧化物」「复盐 + 配位部分」**，很多计量和性质立刻变清楚。

| 拆写方式 | 示例 | 用途 |
|:---|:---|:---|
| 已知盐 + 氧化物 | 黑色晶体拆成 AgNO₃·Agₓ$O_y$ | 热重数据变得可算 |
| 复盐/混盐 | X·YSO₄·Z 型 | 读出组成比例与热分解路径 |
| 低氧化物 + 高氧化物 | BiO₀.₇₅ ≈ 2Bi + Bi₂O₃ | 氧化态与比例一目了然 |

**本质**：不是「它真的是复盐」，而是先给陌生对象一个可计算、可解释的整体包装，借包装快速读出组成、价态、热分解路径。（见图 9）

### 6.3 六大命题模式

| 模式 | 特点 | 典型例题 |
|:---|:---|:---|
| 颜色递推型 | 以颜色变化为主线串联推断 | 绿色晶体→黑色→黄色→血红色 |
| 计算确证型 | 定量数据（摩尔质量/百分比/气体体积）反推 | 2.00 g 金属 + 酸 → 0.0800 mol H₂ |
| 古文翻译型 | 古代文献描述 → 现代物质与反应 | 「胆矾煅之，醋淬，赤色气体」 |
| 结构推断型 | 晶胞参数/空间构型/光谱 | 晶胞参数反推化学式 |
| 性质比较型 | 同族/同周期多组性质对比 | A/B/C/D 位置推断 |
| 工业流程型 | 以化工生产流程为载体 | 从矿石到产品多步转化 |

**计算型推断核心公式**：n(e⁻ 转移) = 2 × n(H₂) = (m/M) × 金属化合价变化量。摩尔质量算出的结果允许 ±1 偏差。

### 6.4 化学史推断（三步翻译法）

1. 圈古文操作词：「煅」→高温加热；「淬」→水中冷却；「飞」→升华；「点」→加入少量

2. 定位关键物质：雄黄=As₄S₄；砒霜=As₂O₃；胆矾=CuSO₄·5H₂O；绿矾=FeSO₄·7H₂O；皓矾=ZnSO₄·7H₂O；明矾=KAl(SO₄)₂·12H₂O；硝石=KNO₃；朱砂=HgS；铅丹=Pb₃O₄

3. 按操作写方程式：把古文操作链翻译为现代化学反应

**操作链识别**：原料处理（煅烧/研磨/淘洗）→ 反应转化（加酸/加热/点入）→ 产物分离（飞/升华/沉淀/结晶）。

**图解：五步推断法闭环流程**

| 步骤 | 核心线索 | 作用 | 依据 |
| :---: | :--- | :--- | :--- |
| ① 物理性质 | 颜色 / 磁性 / 溶解性 | 缩圈排除 | 经验判据 |
| ② 结构数据 | 参数 / 构型 / 光谱 | 确定类型 | 结构化学 |
| ③ 化学性质 | 氧化还原 / 配位 | 定位元素 | 反应规律 |
| ④ 定量数据 | 电势 / 热力学 | 确实验证 | 数据核对 |
| ⑤ 写方程式 | 电荷 / 质量平衡 | 落脚下结论 | 规范表达 |

若第⑤步出现矛盾或算不通，则回退到第①步重新缩圈，直到闭环。

### 7.2 排除法标准模板：真题-无机-元素推断-卤素-001

**题核**：三种无色钠盐 A/B/C 与 AgNO₃ 分别得白/淡黄/黄沉淀，且溶解性在浓氨水中依次「溶/微溶/不溶」；与浓 H₂SO₄ 共热分别得 HCl↑ / Br₂(红棕)+SO₂ / I₂(紫色蒸气)。

**四步法执行**：

| 步骤 | 操作 | 结论 |
|:---|:---|:---|
| ① 提取信号 | AgCl 白+溶氨水；AgBr 淡黄+微溶；AgI 黄+不溶；浓 H₂SO₄ 表现：Cl⁻ 仅复分解、Br⁻ 被氧化、I⁻ 更强还原 | 卤化银颜色+溶解行为是关键信号对 |
| ② 最强信号候选 | 银盐沉淀颜色 + 氨水溶解性 → A=Cl⁻、B=Br⁻、C=I⁻ | 逐一对应 |
| ③ 否定排除 | 沉淀不溶稀 HNO₃ 排除碳酸盐/亚硫酸盐；不溶浓氨水排除 AgCl | 确定卤素 |
| ④ 验证 | 浓 H₂SO₄ 反应佐证还原性强弱：Cl⁻<Br⁻<I⁻ | 2NaBr+3H₂SO₄→△→ 2NaHSO₄+Br₂↑+SO₂↑+2H₂O |

**本题教学点**：卤化银「颜色 + 氨水溶解性」是一组经典的**唯一性组合信号**；I⁻ 能把 H₂SO₄ 还原到 H₂S 说明卤素还原性 I⁻>Br⁻>Cl⁻——这就是「从反应现象推断性质」的排除法骨架。

### 7.3 国初真题实战

| 真题 | 核心信号 | 分值 | 训练点 |
|:---|:---|:---:|:---|
| **37 届 Q5**（NO/H₂S 反应体系） | 气体信号：NO 遇空气变红棕；H₂S 臭鸡蛋味；氧化还原价态变化 | 13 | 中等难度入门：熟悉「信号提取→推断→验证」全流程 |

**心态提示（39 届 Q1）**：砷是剧毒元素，但化学推断不需要「害怕它」——As 的推断逻辑与其他元素完全相同（As₂O₃ 两性、砷酸盐/亚砷酸盐、雄黄 As₄S₄ 等信号照常处理）。客观理性就是最好的科学态度。
