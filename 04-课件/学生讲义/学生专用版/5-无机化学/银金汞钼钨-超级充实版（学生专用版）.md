## §1 ds 区与 VIB 族定位

### 1.1 ds 区（IB/IIB）通性

| 性质 | IB 族（Cu/Ag/Au） | IIB 族（Zn/Cd/Hg） |
|:---|:---|:---|
| 基态电子构型 | (n−1)d¹⁰ns¹ | (n−1)d¹⁰ns² |
| 常见氧化态 | +1（Cu 还有 +2，Au 还有 +3） | 几乎只 +2（Hg 有 Hg₂²⁺） |
| 配合物颜色 | 有色（d-d 跃迁） | 无色（d¹⁰ 全满） |
| 化学行为 | 较不活泼，可单质存在 | Zn 活泼，Hg 极不活泼 |

**核心**：IB 族失去 ns 电子后是 d¹⁰ 构型（Ag⁺、Au⁺），但 Au 还可再失部分 d 电子成 Au³⁺（d⁸，平面正方形）。同族从上到下活泼性递减，Au 因相对论效应 6s 收缩而惰性。

### 1.2 IB vs IA 的根本差异（族间对比）

| 对比维度 | IB（Cu/Ag/Au） | IA（Na/K 等） |
|:---|:---|:---|
| 价电子构型 | (n−1)d¹⁰ns¹ | ns¹ |
| 单质活泼性 | **不活泼**，不反应水 | **极活泼**，剧烈反应水 |
| 配合物能力 | 极强（d 轨道参与） | 极弱（无空 d 轨道） |
| 自然界存在 | 有单质 | 仅化合物 |
| $E^\theta$(M⁺/M)/V | 正值（Cu +0.52、Ag +0.80、Au +1.68） | 极负（Na −2.71） |

**理解**：同为 ns¹，但 IB 有内层 d¹⁰ 屏蔽差 → 有效核电荷大 → 电子难失去（电离能高）→ 单质惰性；同时空 d 轨道 + d 电子可参与 → 配合物倾向强。

### 1.3 VIB 族（Cr/Mo/W）——多酸化学的基础

| 性质 | Cr | Mo | W |
|:---|:---:|:---:|:---:|
| 周期 | 四 | 五 | 六 |
| 电子构型 | 3d⁵4s¹ | 4d⁵5s¹ | 5d⁴6s² |
| 熔点 | 1907°C | 2623°C | **3422°C（金属之最）** |
| 常见氧化态 | +3、+6 | +6 | +6 |
| 多酸规模 | 小（Cr₂O₇²⁻、Cr₃O₁₀²⁻） | **丰富**（[Mo₇O₂₄]⁶⁻） | **丰富**（Keggin 等） |

**核心**：VIB 同族向下，最高氧化态稳定性增强、多酸缩合倾向增大。Mo/W 因 4d/5d 轨道径向延展、可形成 MO₆ 八面体共边/共角连接，多酸化学远比只能形成 MO₄ 四面体的 Cr 丰富。（见图 7-1）

## §2 银：Ag⁺ 化学与「不歧化」的特例

### 2.1 电子构型与氧化态

电子构型：[Kr]4d¹⁰5s¹；最稳氧化态 **+1**（d¹⁰，无色）。
$E^\theta(\mathrm{Ag^+/Ag}) = +0.799\ \mathrm{V}$——氧化性适中（比 Cu 强、比 Au 弱）。
单质：溶于稀 HNO₃（3Ag + 4HNO₃(稀) → 3AgNO₃ + NO↑ + 2H₂O），不溶于 HCl/稀 H₂SO₄。
空气中被硫化物侵蚀变黑：4Ag + 2H₂S + O₂ → 2Ag₂S↓(黑) + 2H₂O。

### 2.2 Ag⁺ 为什么不歧化（而 Cu⁺ 歧化）？

[!important]
Cu⁺：2Cu⁺ → Cu²⁺ + Cu（K≈10⁶，几乎完全歧化）；Ag⁺：2Ag⁺ → Ag²⁺ + Ag（K 极小，不歧化）。同为 d¹⁰，行为完全相反。
**突破——Born-Haber 三要素对比（方向性）**：
Cu 的第二电离能约 1960 kJ/mol，Cu²⁺ 水合能（约 −2100 kJ/mol）足以补偿 → 歧化有利。
**Ag 的第二电离能更大（约 2070 kJ/mol）**，而 Ag²⁺ 水合能不足以完全补偿 → 歧化热力学不利 → Ag⁺ 稳定。
综合来看，同族元素的歧化行为取决于第二电离能与水合能的相对平衡。

### 2.3 卤化银：Ksp 顺序与溶解行为

| 化合物 | 颜色 | Ksp | 溶 NH₃·H₂O | 溶 Na₂S₂O₃ | 用途 |
|:---|:---:|:---:|:---:|:---:|:---|
| AgCl | 白 | 1.8×10⁻¹⁰ | **易溶** | 溶 | Cl⁻ 鉴定 |
| AgBr | 浅黄 | 5.0×10⁻¹³ | 微溶 | **溶（定影）** | 感光材料 |
| AgI | 黄 | 8.5×10⁻¹⁷ | 不溶 | 需浓溶液 | 人工降雨晶核 |

**感光性**（竞赛必考）：2AgBr →光照→ 2Ag + Br₂。
**定影原理**（配位溶解）：AgBr + 2S₂O₃²⁻ → [Ag(S₂O₃)₂]³⁻ + Br⁻。
**本质**：Ksp 越小越难被弱配位剂（NH₃）拉动；S₂O₃²⁻ 与 Ag⁺ 形成稳定常数更大的 [Ag(S₂O₃)₂]³⁻，能克服 AgBr 的溶解平衡。（见图 7-2）
卤化银的颜色由白到浅黄再到黄，溶度积依次减小，被氨水溶解的难度依次增大。

[!note] **显影 vs 定影（感光材料两步，别混淆）**
**显影（影像出现）**：已感光的 AgBr 晶粒内生成 Agₙ 显影中心（潜影），显影剂（如对苯二酚）在中心上**催化加速还原 Ag⁺ → Ag**，未感光的 AgBr 几乎不反应 → 潜影被放大成可见影像。
**定影（影像固定）**：随后用 Na₂S₂O₃ 溶解**未感光**的 AgBr（AgBr + 2S₂O₃²⁻ → [Ag(S₂O₃)₂]³⁻ + Br⁻），否则剩余 AgBr 见光继续变黑、影像毁掉。
**对比**：显影是「催化还原已感光的」→ 长银出像；定影是「配位溶解未感光的」→ 除银固定。一个长银、一个除银。

### 2.4 Ag⁺ 的配位与银镜反应

**与 NH₃ 分步反应**：

  1. Ag⁺ + NH₃·H₂O → AgOH↓(白) + NH₄⁺
  2. AgOH + 2NH₃·H₂O(过量) → [Ag(NH₃)₂]⁺ + OH⁻ + 2H₂O
现象：白色沉淀 → 过量 NH₃ → 溶解（直线形 [Ag(NH₃)₂]⁺，sp 杂化，见图 3）。（实际出棕黑色 Ag₂O——AgOH 仅简化表示，见下）
**AgOH 常温不存在**——Ag⁺ + OH⁻ 直接出 Ag₂O 棕色沉淀（AgOH 仅 −45°C 以下短暂存在）。课本常用 AgOH 表达分步，实际写 Ag₂O 更准确。
**银镜反应**（Tollens 试剂，醛基检验）：
RCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → RCOO⁻ + 2Ag↓ + 4NH₃ + 2H₂O
条件：水浴加热（勿直接加热或久置——Tollens 试剂会产生 Ag₃N、Ag₂NH 等爆炸性沉淀（雷银），现配现用、余液及时酸化销毁）。

## §3 金：惰性与王水

### 3.1 电子构型与氧化态

电子构型：[Xe]4f¹⁴5d¹⁰6s¹。
最稳氧化态 **+3**（d⁸，平面正方形 dsp²）；+1 较不稳定。
**相对论效应**：6s 电子收缩、能量降低 → Au 极惰性 + 金黄颜色（5d→6s 跃迁吸收蓝光）+ 可形成 Au⁻（auride，获得电子填满 6s² 模仿 Hg 的稳定构型）。

### 3.2 Au 为什么溶于王水？——氧化 + 配位双因素协同

[!important]
Au 不溶于浓 HNO₃（$E^\theta$(Au³⁺/Au)≈+1.50 V > $E^\theta$(NO₃⁻/NO)=+0.96 V）；不溶于浓 HCl（无氧化剂）；但溶于王水（HNO₃ + 3HCl）。
**突破——拆成两个耦合子反应**：
1. **氧化**（HNO₃ 提供驱动力）：Au → Au³⁺ + 3e⁻

2. **配位**（HCl 提供 Cl⁻）：Au³⁺ + 4Cl⁻ → [AuCl₄]⁻（稳定常数极大）
配位使游离 [Au³⁺] 极低 → 据 Nernst 方程 $E = E^\theta + \frac{0.059}{3}\lg[\mathrm{Au^{3+}}]$，Au³⁺/Au 有效电势**大幅降低**（[AuCl₄]⁻/Au 的 $E^\theta$ 降至约 +1.00 V），配合浓硝酸在高酸度下增强的实际氧化能力即可驱动溶解。
**总反应**：Au + 4HCl + HNO₃ → HAuCl₄ + NO↑ + 2H₂O（见图 7-4）
王水溶金的本质是硝酸氧化与氯离子配位的协同，二者缺一不可。
**类比迁移（氰化提金）**：4Au + 8CN⁻ + O₂ + 2H₂O → 4[Au(CN)₂]⁻ + 4OH⁻——O₂ 氧化 + CN⁻ 配位，同一逻辑。氰化法提取 Ag/Au 是工业核心。

### 3.3 Au(III) 的配合物

| 化合物 | 化学式 | 性质 | 结构 |
|:---|:---|:---|:---:|
| 氯金酸 | HAuCl₄·nH₂O | 黄色晶体，最常见金化合物 | [AuCl₄]⁻ 平面正方形 |
| 氯化金(III) | AuCl₃ | 红色固体，易潮解 | 二聚体 Au₂Cl₆ |
| 金氰配合物 | [Au(CN)₂]⁻ | 极稳定，用于提金 | 直线形（sp） |

**构型判断**：Au³⁺ = d⁸ → 4 配位 → 强场 → **平面正方形 dsp²**（与 Ni²⁺ d⁸ 平面正方形同理，但 5d 分裂能更大，几乎总低自旋）。这是竞赛判断贵金属配合物构型的高频考点。（见图 7-5）

## §4 汞：Hg₂²⁺ 与相对论

### 4.1 Hg 为什么常温液态？

[!important]
Au 黄色固体（熔点 1064°C）；Hg 无色液体（熔点 −39°C）。原子间相互作用发生了什么？

**突破——相对论效应三步链**：

1. 相对论效应使 **6s 轨道收缩、能量降低**（质量-速度效应）。

2. Hg 的 **6s² 电子对异常「懒惰」**——紧贴原子核，不参与成键，不参与金属能带。

3. 结果：Hg 原子间只有弱范德华力 → 熔点极低 → 常温液态。（见图 7-6）
**同一根因串三件事**：Au 黄色（5d→6s 跃迁吸收蓝光）、Hg 液态（6s² 惰性）、Au⁻ 存在（Au 得电子填满 6s² 模仿 Hg 稳定构型）。
汞常温为液态、金显黄色，都源于相对论效应引起的 6s 轨道收缩。

### 4.2 Hg₂²⁺ 双核离子

**一价汞不是 Hg⁺，而是 Hg₂²⁺**——含 **Hg—Hg 键**的双核离子（每个 Hg 形式 +1 价，键长约 253 pm）（见图 7-9）。
代表：甘汞 Hg₂Cl₂（白色，微溶，感光变黑）；升汞 HgCl₂（白色，可溶，剧毒）。（见图 7-7）
易错：不要写成两个独立 Hg⁺；Hg₂²⁺ 的「2」表示双核，不是价态。

### 4.3 Hg₂²⁺ 不歧化 vs Cu⁺ 歧化（电势图对比）

| 对比项 | Cu⁺ | Hg₂²⁺ |
|:---|:---|:---|
| 歧化反应 | 2Cu⁺ ⇌ Cu + Cu²⁺ | Hg₂²⁺ ⇌ Hg + Hg²⁺ |
| 水溶液行为 | **歧化完全**（K≈10⁶） | **基本不歧化**（K≈10⁻²） |
| 热力学依据 | $E^\theta$(Cu²⁺/Cu⁺)=+0.15 V < $E^\theta$(Cu⁺/Cu)=+0.52 V → 左<右 → **歧化** | $E^\theta$(Hg²⁺/Hg₂²⁺)=+0.91 V > $E^\theta$(Hg₂²⁺/Hg)=+0.80 V → 左>右 → **不歧化** |

**关键辨析**：Hg₂²⁺ 「不歧化」≠「不能被拉动歧化」。加入能与 Hg²⁺ 形成沉淀/配合物的试剂（I⁻、S²⁻、OH⁻、CN⁻），Hg²⁺ 被捕获 → 拉动 Hg₂²⁺ 歧化平衡向右。例：Hg₂²⁺ + 4I⁻ → [HgI₄]²⁻ + Hg↓。（见图 7-8）
一价汞以双核 Hg₂²⁺ 形式存在，含 Hg—H g 键，键长约 253 pm。

### 4.4 汞的鉴定与毒性

**甘汞鉴定（SnCl₂ 分步还原，白→灰→黑）**：
  1. 2HgCl₂ + SnCl₂ → Hg₂Cl₂↓(白) + SnCl₄
  2. Hg₂Cl₂ + SnCl₂(过量) → 2Hg↓(黑) + SnCl₄
**AgCl vs Hg₂Cl₂ 鉴别**（加氨水）：AgCl 溶解；Hg₂Cl₂ 变灰黑（Hg₂Cl₂ + 2NH₃ → Hg(NH₂)Cl↓白 + Hg↓黑 + NH₄Cl）。
**Nessler 试剂**（NH₄⁺ 鉴定）：Hg²⁺ + 2I⁻ → HgI₂↓(红)；过量 I⁻ → [HgI₄]²⁻(无色)；K₂[HgI₄] 碱性液遇 NH₄⁺ 生成红棕色 Hg₂NI·H₂O↓。

**毒性**：① 汞蒸气（室温蒸气压大，饱和浓度超标千倍，损害中枢神经）；② 甲基汞 CH₃Hg⁺（脂溶性，生物富集，**水俣病**）。

## §5 钼与钨：多酸化学

### 5.1 Mo/W 巨型多酸 vs Cr 小多酸

[!important]
Cr 的最高多酸是 Cr₃O₁₀²⁻（三个铬）；V 可到 V₁₀O₂₈⁶⁻（十钒酸根）；Mo/W 可到 [PMo₁₂O₄₀]³⁻（12 个 Mo 围一个 P）甚至更大。

**突破——两个关键因素**：

1. **离子半径**：Cr⁶⁺ 太小（~0.44 Å），CrO₆ 八面体共边/共面时阳离子排斥过强 → 结构散架；Mo⁶⁺（~0.59 Å）、W⁶⁺（~0.60 Å）半径大 → 八面体连接不打架。

2. **d 轨道径向延展**：4d（Mo）/5d（W）轨道比 3d（Cr）弥散 → Mo—O—Mo/W—O—W 的 d-p π 键更强 → 稳定更大骨架。
随离子半径与 d 轨道延展性增大，多酸的缩合规模依次增大。（见图 7-11）

### 5.2 同多酸 vs 杂多酸

| 比较维度 | 同多酸 | 杂多酸 |
|:---|:---|:---|
| 组成 | 仅含一种金属元素 | 含杂原子（P、Si、As 等）+ 金属 |
| Mo 代表 | [Mo₇O₂₄]⁶⁻（七钼酸根） | H₃[PMo₁₂O₄₀]（磷钼酸，Keggin 型） |
| W 代表 | [W₁₂O₄₀(OH)₂]¹⁰⁻（十二钨酸） | H₃[PW₁₂O₄₀]（磷钨酸，Keggin 型） |
| 缩合条件 | 酸性 MO₄²⁻ 脱水缩合 | 含氧酸根 + 杂原子含氧酸共缩合 |

判断依据是看是否含有异种中心原子：含 P、Si 等杂原子者为杂多酸，仅含一种金属者为同多酸。（见图 7-10）
**缩合规律**：酸性条件下 MO₄²⁻ 质子化后脱水缩合，**酸度越高缩合度越大**；碱性条件下解聚回单酸根。

### 5.3 Mo/W 的重要化合物与催化

| 化合物 | 性质/用途 |
|:---|:---|
| MoO₃ / WO₃ | 酸性氧化物，白色 / 黄色 |

| Mo(CO)₆ / W(CO)₆ | 满足 18 电子规则，易挥发 |
| 碳化钨 WC | 间隙化合物，高硬度，硬质合金 |
| 钨青铜 MₓWO₃ | 非化学计量，金属光泽，颜色随 x 变 |

**催化应用**：MoS₂ 加氢脱硫（HDS，石油工业去硫）；Mo 在固氮酶活性中心（Mo-Fe 簇）；W 用于灯丝（熔点最高）与高温合金（层状结构见图 12）。

### 6.3 推断三件套（ds 区版）

1. **先看沉淀颜色 + 加氨水后的变化**：AgCl 溶 vs Hg₂Cl₂ 灰黑——第一分流。

2. **再看配位剂选择**：S₂O₃²⁻（AgBr 定影）、过量 I⁻（HgI₂→[HgI₄]²⁻ 溶解）、CN⁻/Cl⁻（Au 配位溶解）。

3. **最后判构型与价态**：Ag⁺ 直线形（d¹⁰）、Au³⁺ 平面正方形（d⁸）、Hg²⁺ 四面体（d¹⁰）；Hg₂²⁺ 双核不歧化。

**通法（贵金属溶解）**：凡涉及 Au/Ag 等贵金属的溶解，都按「氧化 + 配位」双因素写——王水、氰化法、硫脲法都是同一逻辑的两个组分，缺一不可。

**AgCl vs Hg₂Cl₂ 鉴别流程**

1. 取白色沉淀（可能是 AgCl 或 Hg₂Cl₂），加入过量氨水 NH₃·H₂O，观察现象

2. 若完全溶解得无色溶液 → 为 AgCl，生成 $[\mathrm{Ag(NH_3)_2}]^{+}$

3. 若沉淀变灰黑 → 为 Hg₂Cl₂，发生歧化：$\mathrm{Hg_2Cl_2 + 2NH_3 \to Hg(NH_2)Cl\downarrow + Hg\downarrow + NH_4Cl}$（白色与黑色混合显灰黑）

### 7.3 规则与易错提醒

按模块查判据，「易错提醒」列对应正文各节的辨析点。

#### 贵金属溶解

| 规则 | 适用条件 / 要点 | 易错提醒 |
|:---|:---|:---|
| 王水 = 氧化 + 配位协同 | HNO₃ 氧化 + Cl⁻ 配位，缺一不可 | 「只是更强的酸」是错的 |

| AgOH 常温不存在 | Ag⁺ + OH⁻ 直接出 Ag₂O 棕色沉淀 | 「AgOH 常温稳定存在」是错的 |

#### 汞

| 规则 | 适用条件 / 要点 | 易错提醒 |
|:---|:---|:---|
| Hg 液态根因 = 相对论 6s² 惰性 | 只剩范德华力 | 「金属键弱」只是表象 |
| 一价汞是 Hg₂²⁺ 双核 | Hg—Hg 键（253 pm）| 写成 Hg⁺ 是错的 |
| Hg₂²⁺ 不歧化、Cu⁺ 歧化 | 左>右 vs 左<右 | 两者行为相反 |

#### 多酸与 Mo/W

| 规则 | 适用条件 / 要点 | 易错提醒 |
