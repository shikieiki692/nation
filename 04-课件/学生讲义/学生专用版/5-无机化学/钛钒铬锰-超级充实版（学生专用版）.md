## §1 第一过渡系通性与多价态—氧化还原主线

### 1.1 第一过渡系的价态特征

第一过渡系＝第四周期 Sc→Zn 十元素，电子依次填入 $3d$。与主族「一个元素一个主要价态」不同，过渡金属的核心特征是**同一元素可携带一整串价态**，价态间转化为氧化还原提供丰富素材。钛、钒、铬、锰覆盖第一过渡系左部，完整呈现「高价稳定→多价共存→低价稳定」的渐变主线。

### 1.2 多价态的成键根源

多价态根源是 $(n-1)d$ 与 $ns$ 轨道能量相近，$4s$ 与 $3d$ 电子都能参与成键，故最高氧化数＝两者电子数之和：**Ti +4、V +5、Cr +6、Mn +7**。随原子序数增大有效核电荷上升、$3d$ 收缩下沉，价电子越来越难全部失去，故**最高氧化态稳定性沿 Ti→V→Cr→Mn 递减、氧化性递增**；**低氧化态（+2）稳定性递增**，Mn²⁺ 因 $3d^5$ 半满的交换能优势成为极难被氧化的稳定离子。

| 元素 | 价电子构型 | 最高氧化态 | 常见稳定价态 | 本讲主线特征 |
| :---: | :---: | :---: | :--- | :--- |
| Ti | $3d^24s^2$ | +4 | +4（$d^0$，无色）、+3 | 热力学活泼而动力学钝化；TiCl₄ 剧烈水解 |
| V | $3d^34s^2$ | +5 | +5、+4、+3、+2 | 单元素多价态颜色序列，推断题经典指纹 |
| Cr | $3d^54s^1$ | +6 | +3（最稳）、+6、+2 | 氧化还原身份随价态反转；酸碱互变双色信号 |
| Mn | $3d^54s^2$ | +7 | +7、+4、+2 | 价态最丰富；高锰酸根还原产物由介质决定 |

### 1.3 三条可用于推断的递变规律

三条递变规律可直接用于推断：① **最高氧化态氧化性递增**：TiO₂ 中 Ti(IV) 几乎无氧化性，VO₂⁺ 弱，Cr₂O₇²⁻ 强，MnO₄⁻ 为水溶液中最强氧化剂之一；② **低氧化态还原性递减**：Ti³⁺、V²⁺ 极易被空气氧化，Cr²⁺ 更不稳定，Mn²⁺ 在酸性介质中异常稳定；③ **最高价含氧酸酸性递增**：Ti(OH)₄ 两性偏碱 < H₃VO₄ 两性偏酸 < H₂CrO₄ 酸性 < HMnO₄ 强酸。三者同源：从左到右有效核电荷增大、半径减小、中心原子电荷密度升高。

### 1.4 颜色的两种来源

过渡金属颜色有两种来源：① 多数水合离子的颜色来自 **$d$-$d$ 跃迁**——$d^0$、$d^{10}$ 无可跃迁电子故无色，$d^5$ 半满自旋禁阻、吸收极弱、颜色最浅；② 少数高价含氧酸根（紫色 MnO₄⁻、黄色 VO₂⁺）的颜色来自**电荷迁移（LMCT）**，跃迁完全允许、显色浓烈。判断颜色归属先看中心离子 $d$ 电子数，再看是否高价含氧酸根。

## §2 钛的热力学活泼性与动力学钝化

### 2.1 热力学活泼与动力学钝化的矛盾

钛的化学由两个矛盾事实支配：热力学上极活泼（$E^\theta(\mathrm{Ti^{2+}/Ti}) = -1.63\ \mathrm{V}$，比锌还负），实际使用中却极稳定（常温不被王水腐蚀、不与氯气或 NaOH 反应、海水长期不生锈）。关键是区分「反应能否发生」（热力学）与「反应能否开始」（动力学，即表面钝化膜）。

### 2.2 钛的价态与紫色信号

钛价态简单：**Ti(IV)** 为 $d^0$、最稳定且唯一广泛存在，水合离子**无色**、几乎无氧化还原活性；**Ti(III)** 为 $d^1$，六水合离子 $[\mathrm{Ti(H_2O)_6}]^{3+}$ 呈**紫色**、强还原性，空气中迅速氧化为无色 Ti(IV)——「紫色褪去」是推断钛的重要信号。注意 $[\mathrm{Ti(H_2O)_6}]^{3+}$ 与 MnO₄⁻ 均紫色，但前者是还原剂、后者是强氧化剂，须结合加还原剂或加酸后的变化区分。

### 2.3 表面钝化与破膜溶解

表面钝化源于致密且与基体牢固结合的 TiO₂ 膜，但三类介质可破膜溶钛：HF（生成 $[\mathrm{TiF_6}]^{2-}$）、热浓盐酸（生成 $[\mathrm{TiCl_6}]^{2-}$）、热浓硫酸（生成硫酸钛）：$\mathrm{Ti} + 6\mathrm{HF} \to [\mathrm{TiF_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$、$\mathrm{Ti} + 6\mathrm{HCl} \to [\mathrm{TiCl_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$。判据：凡能与 Ti(IV) 形成稳定配离子、降低产物活度的配体，都能推动钛溶解。

### 2.4 氯化—镁热还原冶炼路线

钛的冶炼：碳还原 TiO₂ 不可行（生成的 Ti 立即与 C 结合为更稳定的 **TiC**，生成焓极负，路线被热力学阻断）。工业改用两段**氯化—镁热还原法**：$\mathrm{TiO_2} + 2\mathrm{Cl_2} + 2\mathrm{C} \to \mathrm{TiCl_4} + 2\mathrm{CO}$（高温）、$\mathrm{TiCl_4} + 2\mathrm{Mg} \to \mathrm{Ti} + 2\mathrm{MgCl_2}$（惰性气氛）；关键是 TiCl₄ 沸点仅 136 °C，可先蒸馏提纯，把杂质在还原前除去，得高纯海绵钛。

### 2.5 二氧化钛与四氯化钛

**TiO₂**：金红石型结构（每个 Ti 被 6 个 O 八面体配位、配位比 6∶3），化学惰性强、折射率高、无毒，是遮盖力最优异的**白色颜料（俗称钛白粉）**，可替代剧毒铅白；只溶于热浓硫酸：$\mathrm{TiO_2} + \mathrm{H_2SO_4} \xrightarrow{\Delta} \mathrm{Ti(SO_4)_2} + 2\mathrm{H_2O}$。**TiCl₄**：无色液体（熔点 −25 °C、沸点 136 °C），典型强路易斯酸，遇水剧烈水解，生成 TiO₂ 微粒与 HCl 酸雾（浓厚白烟）。

$$\mathrm{TiCl_4} + 2\mathrm{H_2O} \rightarrow \mathrm{TiO_2}\downarrow + 4\mathrm{HCl}\uparrow$$

水解剧烈因 Ti⁴⁺ 电荷高、半径小、电荷密度极大，强烈极化配位水。工业以气相氧化制钛白粉：$\mathrm{TiCl_4} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2} + 2\mathrm{Cl_2}$（副产氯气循环）。**Ti(IV) 的定性检验**：酸性下与 $\mathrm{H_2O_2}$ 生成**橘黄色**过氧配合物 $[\mathrm{TiO(H_2O_2)}]^{2+}$，可用于比色分析。

### 2.6 钛与硅的相似性

钛与硅共性明显：价层有空轨道易接受配体孤对电子，四卤化物都剧烈水解产生白色烟雾（TiCl₄ 与 SiCl₄），都形成稳定六氟配离子（$[\mathrm{TiF_6}]^{2-}$ 与 $[\mathrm{SiF_6}]^{2-}$），最高氧化态都稳定——故钛的化学更似硅，而非同族更重的锆、铪。

## §3 钒的多价态颜色序列与催化中介化学

### 3.1 多价态颜色序列

钒是**单元素多价态颜色序列**最系统的范例：酸性溶液中以锌粉为还原剂逐级还原钒酸根，颜色按**黄→蓝→绿→紫**依次变化，每步对应一个价态，是竞赛推断中辨识度最高的指纹之一。内在规律：**价态越高、$d$ 电子数越少、颜色越浅**。

| 氧化态 | 主要存在形式 | 颜色 | 备注 |
| :---: | :--- | :---: | :--- |
| +5 | VO₂⁺（酸性）或 VO₄³⁻（碱性） | 黄或无 | 最高价，含氧酸根形式最稳定 |
| +4 | VO²⁺ | 蓝 | 双原子氧钒离子，最稳定的中间价态 |
| +3 | V³⁺(aq) | 绿 | 具还原性 |
| +2 | V²⁺(aq) | 紫 | 强还原剂 |

净反应 $2\mathrm{VO_2^+} + 3\mathrm{Zn} + 8\mathrm{H^+} \to 2\mathrm{V^{2+}} + 3\mathrm{Zn^{2+}} + 4\mathrm{H_2O}$，随锌粉加入依次出现**黄色 VO₂⁺、蓝色 VO²⁺、绿色 V³⁺、紫色 V²⁺**。反向用氧化剂（H₂O₂ 或硝酸）逐步氧化，颜色按紫→绿→蓝→黄复原，可据此判断样品价态。

### 3.2 Latimer 图与两条判据

钒的零价到五价的电势关系可以用 Latimer 图表达。在酸性介质中，各相邻价态之间的标准电极电势为：

$$\mathrm{VO_2^+} \xrightarrow{+1.00} \mathrm{VO^{2+}} \xrightarrow{+0.34} \mathrm{V^{3+}} \xrightarrow{-0.26} \mathrm{V^{2+}} \xrightarrow{-1.18} \mathrm{V}$$

Latimer 图两条判据：① **歧化判据**——某价态右侧电势 > 左侧则自发歧化。本图左侧电势始终大于右侧（$1.00 > 0.34 > -0.26$），故 VO²⁺ 与 V³⁺ 都不歧化、是相对稳定的中间价态（与「+4 价最稳定」一致）。② **最强还原剂识别**——$E^\theta(\mathrm{V^{3+}/V^{2+}}) = -0.26\ \mathrm{V}$、$E^\theta(\mathrm{V^{2+}/V}) = -1.18\ \mathrm{V}$，V²⁺ 还原能力甚至强于锌，这正是锌粉能把钒酸根一路还原到 V²⁺ 的热力学基础。此外酸性 VO₂⁺（+1.00 V）能氧化 $\mathrm{I^-}$（+0.54 V）与 $\mathrm{Fe^{2+}}$（+0.77 V），不能氧化 $\mathrm{Cl^-}$（+1.36 V）。

### 3.3 五氧化二钒与接触法制硫酸

**V₂O₅**：**橙红色**固体，两性偏酸，溶于强碱生成钒酸盐：$\mathrm{V_2O_5} + 6\mathrm{NaOH} \to 2\mathrm{Na_3VO_4} + 3\mathrm{H_2O}$；由偏钒酸铵热分解制得：$2\mathrm{NH_4VO_3} \xrightarrow{\Delta} \mathrm{V_2O_5} + 2\mathrm{NH_3}\uparrow + \mathrm{H_2O}\uparrow$。

V₂O₅ 最重要的应用是**接触法制硫酸的催化剂**，机制为变价氧转移循环：$\mathrm{V_2O_5} + \mathrm{SO_2} \to \mathrm{V_2O_4} + \mathrm{SO_3}$；$\mathrm{V_2O_4} + \frac{1}{2}\mathrm{O_2} \to \mathrm{V_2O_5}$；两步相加即 $\mathrm{SO_2} + \frac{1}{2}\mathrm{O_2} \to \mathrm{SO_3}$。催化剂并非不参与反应，而是 V(V)/V(IV) 可逆切换、净变化为零；同一原理用于萘氧化制邻苯二甲酸酐。

### 3.4 钒酸根的缩合与多酸

钒酸根随 pH 降低逐步缩合（多酸化学入门）：高 pH 以**无色**正钒酸根 VO₄³⁻（四面体）为主；pH 依次下降生成 V₂O₇⁴⁻、V₂O₆(OH)³⁻、V₃O₉³⁻（**淡黄**）；再降低生成十钒酸根 V₁₀O₂₈⁶⁻（**深红**）；强酸中以**黄色** VO₂⁺ 为主。本质是酸化后质子化促使四面体共用顶角氧聚合成多核阴离子。**VOCl₃** 为**黄色液体**，遇水剧烈水解：$2\mathrm{VOCl_3} + 3\mathrm{H_2O} \to \mathrm{V_2O_5} + 6\mathrm{HCl}$。

## §4 铬的价态—颜色—介质三联动

### 4.1 电子构型与单质性质

铬价电子构型为 $3d^54s^1$（而非 $3d^44s^2$），源于半满 $d^5$ 的交换能稳定化。铬单质**银白色**，是已知金属中**硬度最大**者（六个未成对电子贡献极强金属键）；常温表面覆盖致密氧化膜故耐腐蚀，溶于稀盐酸或稀硫酸生成**绿色** Cr(III)，不溶于浓硝酸（钝化）。冶炼用铝热法：$2\mathrm{Al} + \mathrm{Cr_2O_3} \to \mathrm{Al_2O_3} + 2\mathrm{Cr}$；高纯铬用碘化铬真空热分解。

### 4.2 铬(III) 的稳定性与动力学惰性

铬以 **+3 价**在酸、中、碱三种条件下都最稳定。$[\mathrm{Cr(H_2O)_6}]^{3+}$ 呈**紫色**，但常见铬(III)盐（如 $\mathrm{CrCl_3\cdot6H_2O}$）及稀溶液、久置溶液呈**绿色**（水合异构）。Cr(III) 氢氧化物两性：$\mathrm{Cr^{3+}} + 3\mathrm{OH^-} \to \mathrm{Cr(OH)_3}\downarrow$（**灰绿**），过量碱中溶解为**亮绿色** $[\mathrm{Cr(OH)_4}]^-$。Cr(III) 最突出的是**动力学惰性**：$d^3$ 晶体场稳定化能高、配体交换极慢（半衰期可达 $10^5$ s），故三种水合异构体可分离提纯，这在过渡金属水合离子中相当罕见。

### 4.3 铬(III) 与铝(III) 的对比

Cr³⁺ 与 Al³⁺ 表面相似而本质不同——**相同**：氢氧化物均两性、均溶于过量强碱，三价离子都能形成矾、都能双水解；**不同**：Cr³⁺ 有色而 Al³⁺ 无色，Cr³⁺ 动力学惰性而 Al³⁺ 交换极快，碱性下 Cr(III) 可被 H₂O₂ 氧化为 Cr(VI)（有还原性）而 Al³⁺ 无氧化还原活性。判题时并列检查「颜色／配体交换快慢／碱性介质能否被氧化」。

### 4.4 价态与氧化还原身份的反转

铬(VI) 展示同一元素不同价态氧化还原身份的完全反转：酸性中 Cr(VI) 以重铬酸根 Cr₂O₇²⁻ 存在、是强氧化剂（$E^\theta(\mathrm{Cr_2O_7^{2-}/Cr^{3+}}) = +1.33\ \mathrm{V}$）；低氧化态端 Cr(II) 是强还原剂（$E^\theta(\mathrm{Cr^{3+}/Cr^{2+}})$ 为负）；居中 Cr(III) 遇强氧化剂（碱性 H₂O₂）升高到 +6，遇强还原剂（Zn）降到 +2。**氧化还原角色不由元素本身决定，而由该价态在电势数轴上的位置决定**。

### 4.5 铬酸根—重铬酸根平衡

铬酸根与重铬酸根之间的互变是铬化学中最典型的酸碱依赖平衡：

$$2\mathrm{CrO_4^{2-}}\ (\text{黄}) + 2\mathrm{H^+} \rightleftharpoons \mathrm{Cr_2O_7^{2-}}\ (\text{橙}) + \mathrm{H_2O},\quad K = 4.2 \times 10^{14}$$

平衡常数极大，酸性条件下二聚形式占明显优势：**pH > 6 以黄色 CrO₄²⁻ 为主，pH < 1 以橙色 Cr₂O₇²⁻ 为主**——概括为「**加酸变橙、加碱变黄**」。氧化性随介质分化：酸性 Cr₂O₇²⁻ 强（$+1.33\ \mathrm{V}$），碱性 CrO₄²⁻ 很弱（$-0.13\ \mathrm{V}$，还原为 Cr(OH)₃），说明**同一元素同一价态的氧化性也被介质显著改变**。

| :---: | :---: | :---: | :---: | :---: |
| CrO₄²⁻ | 黄 | 碱性或中性 | 弱 | −0.13 V |
| Cr₂O₇²⁻ | 橙 | 酸性 | 强 | +1.33 V |

### 4.6 重铬酸根氧化性的应用

重铬酸根强氧化性的两个应用：① **铁的测定** $\mathrm{Cr_2O_7^{2-}} + 6\mathrm{Fe^{2+}} + 14\mathrm{H^+} \to 2\mathrm{Cr^{3+}} + 6\mathrm{Fe^{3+}} + 7\mathrm{H_2O}$（橙转绿，重铬酸钾滴定法依据）；② **酒精检测** $2\mathrm{Cr_2O_7^{2-}} + 3\mathrm{C_2H_5OH} + 16\mathrm{H^+} \to 4\mathrm{Cr^{3+}} + 3\mathrm{CH_3COOH} + 11\mathrm{H_2O}$（橙转绿）。Cr(VI) 强氧化且致癌，含铬废液须先用硫酸亚铁还原为 Cr(III)、再调 pH 以 Cr(OH)₃ 沉淀除去。

### 4.7 铬酸盐的溶解性与沉淀信号

铬酸盐溶解性提供检验 CrO₄²⁻ 的沉淀信号：除碱金属、铵、镁的铬酸盐可溶外，其余多难溶，其中三种颜色鲜明——$\mathrm{Ag^+}$ 生成**砖红色** Ag₂CrO₄（莫尔法沉淀滴定指示剂）；$\mathrm{Pb^{2+}}$ 生成**橙黄色** PbCrO₄（工业颜料**铬黄**）；$\mathrm{Ba^{2+}}$ 生成**黄色** BaCrO₄（检验 CrO₄²⁻，须与白色 BaSO₄ 区分）。生成沉淀降低 CrO₄²⁻ 浓度，使二聚平衡左移。

### 4.8 铬(III) 的水解缩合链

新制六水合铬(III) 呈**淡紫**，久置变绿、渐浑浊，是 Cr(III) 逐步水解缩合的连续链：$[\mathrm{Cr(H_2O)_5(OH)}]^{2+}$ → 双核羟桥 $[\mathrm{Cr_2(OH)_2(H_2O)_8}]^{4+}$ → 氧桥 $[\mathrm{Cr_2O(H_2O)_{10}}]^{4+}$ → 水合 $\mathrm{Cr(OH)_3\cdot nH_2O}$ 沉淀。关键是**羟桥→氧桥不可逆**，一旦成氧桥难以回到单核。故水溶液中制备 Cr(III) 配合物须加草酸根或乙酰丙酮等强配体竞争配位。

### 4.9 过氧化铬与 Cr—Cr 四重键

铬(VI) 的特征鉴定反应是利用其在酸性条件下与过氧化氢生成过氧化铬，再用乙醚萃取，有机层显深蓝色：

$$2\mathrm{Cr_2O_7^{2-}} + 8\mathrm{H_2O_2} + 4\mathrm{H^+} \rightarrow 4\mathrm{CrO_5} + 10\mathrm{H_2O}$$

过氧化铬分子式 CrO(O₂)₂，含两个过氧根 $\mathrm{O_2^{2-}}$（各 −2）与一个端基氧，故铬为 **+6**（非 +10）。判断「高价态含过氧基」物种价态时，须先把过氧根按 −2 单独扣除。另一类重要化合物是含 **Cr—Cr 四重键**的双核配合物，如二醋酸铬(II) $\mathrm{Cr_2(OAc)_4\cdot2H_2O}$（键级 4，由 σ、两组 π 与一组 δ 分子轨道叠加）。

## §5 锰的 pH 调控氧化还原体系

### 5.1 价态谱与介质调控

锰的价态覆盖 +2 到 +7 几乎全部整数价，是第一过渡系价态最丰富的元素。竞赛真正高频的考点集中在一点：**高锰酸根的还原产物由溶液介质决定，而不由还原剂强弱决定**。

| 氧化态 | 代表物种 | 颜色 | 稳定性与行为 |
| :---: | :--- | :---: | :--- |
| +2 | Mn²⁺ | 淡粉（近无色） | 酸性中很稳定（$d^5$ 半满） |
| +3 | Mn³⁺ | 酒红 | 易歧化：$2\mathrm{Mn^{3+}} + 2\mathrm{H_2O} \rightarrow \mathrm{Mn^{2+}} + \mathrm{MnO_2} + 4\mathrm{H^+}$ |
| +4 | MnO₂ | 黑 | 中性条件下稳定 |
| +6 | MnO₄²⁻ | 绿 | 仅强碱中稳定，酸性歧化：$3\mathrm{MnO_4^{2-}} + 4\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + \mathrm{MnO_2}\downarrow + 2\mathrm{H_2O}$ |
| +7 | MnO₄⁻ | 紫 | 强氧化剂，颜色来自电荷迁移 |

酸性条件下两端价态 Mn²⁺ 与 MnO₂ 稳定，中间 Mn³⁺、Mn⁶⁺ 易歧化；碱性条件歧化趋势减弱，Mn(VI) 以**绿色**锰酸根稳定存在。规律仍可用电势图判断：右侧电势 > 左侧的价态必歧化，介质改变会重新分配各相邻电对电势，从而改变哪些价态能稳定存在。

### 5.2 高锰酸根的三种还原产物

| 介质 | 还原产物 | Mn 价态 | 转移电子数 | 颜色变化 | $E^\theta$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 强酸（pH < 1） | Mn²⁺ | +2 | 5 | 紫红转近无色 | +1.51 V |
| 中性或弱碱 | MnO₂ | +4 | 3 | 紫红转棕黑沉淀 | +0.59 V |
| 强碱 | MnO₄²⁻ | +6 | 1 | 紫红转绿 | +0.56 V |

$$\begin{aligned}\text{酸性：}\quad &\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5\mathrm{e^-} \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O} \\ \text{中性：}\quad &\mathrm{MnO_4^-} + 2\mathrm{H_2O} + 3\mathrm{e^-} \rightarrow \mathrm{MnO_2}\downarrow + 4\mathrm{OH^-} \\ \text{强碱：}\quad &\mathrm{MnO_4^-} + \mathrm{e^-} \rightarrow \mathrm{MnO_4^{2-}}\end{aligned}$$

### 5.3 介质决定产物的原因

同一氧化剂面对同一还原剂产生三种产物，根源是介质改变了锰各价态之间的电势梯度：强酸中 $\mathrm{MnO_4^-} \to \mathrm{Mn^{2+}}$ 电势高达 +1.51 V，驱动力极大、一路走到最低价；中性介质梯度压缩、进行到 MnO₂ 即停；强碱驱动力更弱、刚起步就停在 MnO₄²⁻。故判断产物应**先定介质，再定还原产物，最后写方程式**。

### 5.4 亚硫酸钠还原的三种形式

以亚硫酸钠为还原剂的三个反应（对应三种介质）：酸性 $2\mathrm{MnO_4^-} + 5\mathrm{SO_3^{2-}} + 6\mathrm{H^+} \to 2\mathrm{Mn^{2+}} + 5\mathrm{SO_4^{2-}} + 3\mathrm{H_2O}$；中性 $2\mathrm{MnO_4^-} + 3\mathrm{SO_3^{2-}} + \mathrm{H_2O} \to 2\mathrm{MnO_2}\downarrow + 3\mathrm{SO_4^{2-}} + 2\mathrm{OH^-}$；强碱 $2\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \to 2\mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}} + \mathrm{H_2O}$。三者转移电子数分别为 10、6、2，配平可据此核对。此外 $\mathrm{MnO_4^-}$ 与 $\mathrm{Mn^{2+}}$ 共存存在**自催化效应**（生成少量 Mn²⁺ 后反应速率显著加快）。

### 5.5 锰(II) 的鉴定

Mn(II) 鉴定依赖两个把 Mn²⁺ 氧化到 MnO₄⁻ 的强氧化剂，现象均为「近无色→紫红」：① **铋酸钠法** $2\mathrm{Mn^{2+}} + 5\mathrm{NaBiO_3} + 14\mathrm{H^+} \to 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$（硝酸介质）；② **过硫酸铵法** $2\mathrm{Mn^{2+}} + 5\mathrm{S_2O_8^{2-}} + 8\mathrm{H_2O} \to 2\mathrm{MnO_4^-} + 10\mathrm{SO_4^{2-}} + 16\mathrm{H^+}$（需 $\mathrm{Ag^+}$ 催化）。

### 5.6 二氧化锰

**MnO₂**：**黑色**固体，两性偏碱，兼具氧化性与催化性。氧化性——与浓盐酸加热把 $\mathrm{Cl^-}$ 氧化为氯气：$\mathrm{MnO_2} + 4\mathrm{HCl(浓)} \xrightarrow{\Delta} \mathrm{MnCl_2} + \mathrm{Cl_2}\uparrow + 2\mathrm{H_2O}$（此处 MnO₂ 是氧化剂，实验室制氯气的经典反应）；催化性——加速 H₂O₂ 与 KClO₃ 分解。**Mn₃O₄**（黑色）可看作 Mn₂O₃ 与 MnO 的结合，由 MnCO₃ 受热分解并逐级氧化得到：$\mathrm{MnCO_3} \xrightarrow{\Delta} \mathrm{MnO} + \mathrm{CO_2}\uparrow$，$4\mathrm{MnO} + \mathrm{O_2} \to 2\mathrm{Mn_2O_3}$。

### 5.7 锰酸锂与平均价态的计算

**尖晶石型锰酸锂 $\mathrm{LiMn_2O_4}$**（**黑色**）是锂电池正极材料，也是 37 届初赛考点。锰平均氧化态由电中性条件求：$1 + 2x - 8 = 0 \Rightarrow x = +3.5$，即 Mn 以 +3、+4 按 1∶1 混合存在。合成 $8\mathrm{MnO_2} + 2\mathrm{Li_2CO_3} \xrightarrow{\text{高温}} 4\mathrm{LiMn_2O_4} + 2\mathrm{CO_2}\uparrow + \mathrm{O_2}\uparrow$。遇到含分数平均价态的混合价化合物，做法是先由电中性反解平均价态，再按结构或磁学证据拆分为具体价态组合。

### 5.8 高锰酸钾的制备与滴定限制

高锰酸钾工业制备以软锰矿为原料，先碱熔氧化再电解：碱熔 $2\mathrm{MnO_2} + 4\mathrm{KOH} + \mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{K_2MnO_4} + 2\mathrm{H_2O}$（约 240 °C，生成**暗绿色**锰酸钾）；电解 $2\mathrm{K_2MnO_4} + 2\mathrm{H_2O} \xrightarrow{\text{电解}} 2\mathrm{KMnO_4} + 2\mathrm{KOH} + \mathrm{H_2}\uparrow$（阳极得**紫色**高锰酸钾），粗品重结晶提纯。**滴定限制：绝不能用盐酸调酸**——$\mathrm{MnO_4^-}$（+1.51 V）高于 $\mathrm{Cl_2/Cl^-}$（+1.36 V），会把 $\mathrm{Cl^-}$ 氧化为氯气而额外耗标准液，故一律用硫酸调酸，标准液避光保存。

### 6.2 含氧酸强度的物理根源

最高价含氧酸（氢氧化物）的强度递变可以严格比较：

$$\mathrm{Ti(OH)_4}\ (\text{两性偏碱}) < \mathrm{H_3VO_4}\ (\text{两性偏酸}) < \mathrm{H_2CrO_4}\ (\text{酸性}) < \mathrm{HMnO_4}\ (\text{强酸})$$

递变的物理根源是中心原子电荷密度：从左到右电荷数增加、半径减小，对氧的极化增强，O—H 电子云被拉向中心原子、质子更易解离，酸性增强。这一序列与主族 $\mathrm{HClO_4} > \mathrm{H_2SO_4} > \mathrm{H_3PO_4} > \mathrm{H_2SiO_3}$ 完全同构，可见「中心原子电荷密度决定含氧酸强度」跨主族与过渡系普遍成立。同步地，最高氧化态氧化性递增（$\mathrm{TiO_2}$ 几乎无氧化性，$\mathrm{MnO_4^-}$ 为水溶液中最强氧化剂之一）。
