## §1 第一过渡系通性与多价态—氧化还原主线

第一过渡系指第四周期从钪（Sc）到锌（Zn）的十个元素，其电子依次填入 $3d$ 轨道。与主族元素「一个元素对应一个主要价态」的模式截然不同，过渡金属的核心特征是**同一元素可以携带一整串价态**，而这些价态之间的相互转化为氧化还原反应提供了极丰富的素材。钛、钒、铬、锰四个元素恰好覆盖了第一过渡系左部，也完整展现了一条从「高价稳定」经「多价共存」到「低价稳定」的渐变主线。

形成多价态的根本原因在于 $(n-1)d$ 与 $ns$ 轨道能量相近。对于第四周期元素，$3d$ 与 $4s$ 的能量差很小，$4s$ 电子与 $3d$ 电子都可参与成键，因此最高氧化数等于 $ns$ 与 $(n-1)d$ 电子数之和：Ti 为 +4，V 为 +5，Cr 为 +6，Mn 为 +7。随着原子序数增大，有效核电荷上升，$3d$ 轨道逐步收缩下沉，价电子越来越难以全部失去，于是**最高氧化态的稳定性沿 Ti→V→Cr→Mn 方向递减，其氧化性则同步递增**。与之相对，**低氧化态（+2）的稳定性则沿同一方向递增**，到 Mn²⁺ 时，$3d^5$ 半满构型带来的交换能优势使其成为极难被氧化的稳定离子。

下表汇总四个元素的价电子构型、常见价态与其在本讲中的教学定位。

| 元素 | 价电子构型 | 最高氧化态 | 常见稳定价态 | 本讲主线特征 |
| :---: | :---: | :---: | :--- | :--- |
| Ti | $3d^24s^2$ | +4 | +4（$d^0$，无色）、+3 | 热力学活泼而动力学钝化；TiCl₄ 剧烈水解 |
| V | $3d^34s^2$ | +5 | +5、+4、+3、+2 | 单元素多价态颜色序列，推断题经典指纹 |
| Cr | $3d^54s^1$ | +6 | +3（最稳）、+6、+2 | 氧化还原身份随价态反转；酸碱互变双色信号 |
| Mn | $3d^54s^2$ | +7 | +7、+4、+2 | 价态最丰富；高锰酸根还原产物由介质决定 |

三条递变规律贯穿本讲，可以直接用于未知物的性质推断。第一条是最高氧化态的氧化性递增：TiO₂ 中的 Ti(IV) 几乎不显示氧化性，VO₂⁺ 具弱氧化性，Cr₂O₇²⁻ 为强氧化剂，MnO₄⁻ 则是水溶液体系中最强的氧化剂之一。第二条是低氧化态还原性递减：Ti³⁺ 与 V²⁺ 都极易被空气中的氧氧化，Cr²⁺ 更不稳定，而 Mn²⁺ 在酸性介质中异常稳定。第三条是最高价含氧酸（氢氧化物）的酸性递增：Ti(OH)₄ 两性偏碱，H₃VO₄ 两性偏酸，H₂CrO₄ 呈酸性，HMnO₄ 为强酸。这三条规律并非彼此独立，它们共同源于同一物理根源——从左到右有效核电荷增大、离子半径减小，中心原子的电荷密度持续升高，既增强了对电子的夺取倾向，也增强了对氧的极化能力，从而同时抬高了氧化性与含氧酸强度。

颜色是过渡金属最直观的信号，其来源需要区分两种机制。绝大多数水合离子的颜色来自 $d$-$d$ 跃迁：中心离子的 $d$ 轨道在配体场中发生分裂，电子在分裂能级间跃迁吸收可见光，$d^0$ 与 $d^{10}$ 构型没有可用的 $d$-$d$ 跃迁因而无色，$d^5$ 半满构型的跃迁自旋禁阻、吸收极弱因而颜色最浅。少数高价含氧酸根（如紫色的 MnO₄⁻、黄色的 VO₂⁺）的颜色则来自电荷迁移跃迁（LMCT），即配体氧的电子向高氧化态中心金属转移，这类跃迁完全允许、吸收极强，因此显色十分浓烈。推断题中判断颜色归属时，先看中心离子的 $d$ 电子数，再看是否属于高价含氧酸根，可以避免把两种机制混为一谈。

## §2 钛的热力学活泼性与动力学钝化

钛的化学由两个表面上互相矛盾的事实共同支配。其一是热力学上的极度活泼：标准电极电势 $E^\theta(\mathrm{Ti^{2+}/Ti}) = -1.63\ \mathrm{V}$，比锌（$-0.76\ \mathrm{V}$）还要负得多，说明钛失去电子的热力学倾向极强。其二是实际使用中的极度稳定：钛制的器皿在常温下既不被王水腐蚀，也不与氯气、氢氧化钠溶液反应，甚至可长期置于海水中而不生锈。解决这一矛盾的关键在于把「反应能不能发生」与「反应能不能开始」区分开来：前者由热力学判据决定，后者由动力学能垒即表面钝化膜决定。

钛的价态化学相对简单。Ti(IV) 为 $d^0$ 构型，是最稳定也是唯一广泛存在的价态，其水合离子无色，几乎不显示氧化还原活性；Ti(III) 为 $d^1$ 构型，六水合离子 $[\mathrm{Ti(H_2O)_6}]^{3+}$ 呈紫色，具强还原性，在空气中迅速被氧化为无色的 Ti(IV)，这一「紫色褪去」的现象是推断钛的重要信号。需要注意的是，$[\mathrm{Ti(H_2O)_6}]^{3+}$ 与 MnO₄⁻ 都是紫色，但前者是易被氧化褪色的还原剂，后者是强氧化剂，两者在氧化还原方向上的身份完全相反，仅凭颜色不足以判定，必须结合加还原剂或加酸后的变化加以区分。

钛的表面钝化源于一层致密且与基体结合牢固的 TiO₂ 氧化膜，它把内部金属与外界介质完全隔开，使腐蚀反应无法起始。但钝化并非绝对，以下三类介质可以破膜进而溶解钛：氢氟酸通过生成稳定的氟配离子 $[\mathrm{TiF_6}]^{2-}$ 破坏氧化膜，热浓盐酸通过生成 $[\mathrm{TiCl_6}]^{2-}$ 实现溶解，热浓硫酸则生成硫酸钛。对应的反应可以写成 $\mathrm{Ti} + 6\mathrm{HF} \rightarrow [\mathrm{TiF_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$ 与 $\mathrm{Ti} + 6\mathrm{HCl} \rightarrow [\mathrm{TiCl_6}]^{2-} + 2\mathrm{H_2}\uparrow + 2\mathrm{H^+}$。判据是：凡是能与 Ti(IV) 形成稳定配离子、从而降低产物活度的配体，都能推动钛的溶解。

钛的冶炼路线同样体现热力学判断的深度。从表面看，用碳还原二氧化钛似乎可行：$\mathrm{TiO_2} + 2\mathrm{C} \rightarrow \mathrm{Ti} + 2\mathrm{CO}\uparrow$。但生成的钛会立即与碳结合为热力学上更为稳定的碳化钛 TiC，其生成焓极负，使得碳还原的实际产物是 TiC 而非单质钛，还原路线被热力学阻断。工业上因此改用两段式的氯化—镁热还原法：第一段在高温下用氯气与碳处理矿石，把钛转化为易挥发的四氯化钛，$\mathrm{TiO_2} + 2\mathrm{Cl_2} + 2\mathrm{C} \rightarrow \mathrm{TiCl_4} + 2\mathrm{CO}$；第二段在惰性气氛中用镁还原，$\mathrm{TiCl_4} + 2\mathrm{Mg} \rightarrow \mathrm{Ti} + 2\mathrm{MgCl_2}$。这条路线之所以优越，关键在于 TiCl₄ 的沸点仅 136 °C，可以先行蒸馏提纯，从而把原料中的杂质在还原之前彻底除去，得到高纯海绵钛。

二氧化钛与四氯化钛是钛的两个核心化合物。TiO₂ 具有金红石型结构，其中每个钛原子被六个氧原子以八面体方式配位，每个氧原子与三个钛原子相连，配位比为 6∶3，单位晶胞内含 2 个 Ti⁴⁺ 与 4 个 O²⁻，晶体化学式为 TiO₂。TiO₂ 化学惰性极强、折射率高且无毒，是遮盖力最优异的白色颜料（俗称钛白粉），可替代有剧毒的铅白；它只溶于热的浓硫酸生成硫酸钛，对其他常见强酸稳定。TiCl₄ 是无色液体，熔点 −25 °C、沸点 136 °C，是典型的强路易斯酸，遇水发生剧烈水解并放出大量热，生成的氢氧化钛脱水为 TiO₂ 微粒与氯化氢酸雾共同形成浓厚的白色烟雾：

$$\mathrm{TiCl_4} + 2\mathrm{H_2O} \rightarrow \mathrm{TiO_2}\downarrow + 4\mathrm{HCl}\uparrow$$

水解剧烈的原因在于 Ti⁴⁺ 电荷高、半径小，电荷密度极大，对配位水分子有强烈的极化作用，使水分子中的氧氢键被削弱而易于断裂，从而在室温下即可自发进行。工业上以气相氧化法由四氯化钛制备钛白粉：$\mathrm{TiCl_4} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2} + 2\mathrm{Cl_2}$，副产的氯气可循环用于氯化段。钛的另一条重要定性检验是过氧化氢显色：在酸性条件下 Ti(IV) 与 H₂O₂ 生成橘黄色的过氧配合物 $[\mathrm{TiO(H_2O_2)}]^{2+}$，颜色特征明显，可用于比色分析。

![[3df546d147928519973d9f9b3d028db9f02955d68e70af03f44d2d820db813ca.jpg]]
> 图 5-1：金红石型 TiO₂ 四方晶胞与沿 c 轴投影结构（单位晶胞内含 4 个 O²⁻ 与 2 个 Ti⁴⁺，$Z = 2$）

钛与硅在成键倾向上有明显共性，都因为存在能量可用的价层空轨道而易于接受配体孤对电子：两者的四卤化物都剧烈水解并产生白色烟雾（TiCl₄ 与 SiCl₄），都能形成稳定的六氟配离子（$[\mathrm{TiF_6}]^{2-}$ 与 $[\mathrm{SiF_6}]^{2-}$），最高氧化态也都很稳定。这一类比有助于理解为什么钛的化学在很大程度上与硅相似，而不是像同族更重的锆、铪那样更偏金属性。

| T2 | $\mathrm{TiCl_4} + \mathrm{O_2} \xrightarrow{\text{高温}} \mathrm{TiO_2} + 2\mathrm{Cl_2}$ | 气相氧化法制钛白粉 |

## §3 钒的多价态颜色序列与催化中介化学

钒是「单元素多价态颜色序列」最系统的范例：在酸性溶液中以锌粉为还原剂逐级还原钒酸根，溶液颜色会按黄、蓝、绿、紫的顺序依次变化，每一步都对应钒的一个特定价态。这一序列是竞赛推断题中辨识度最高的指纹之一，其内在规律是**价态越高、$d$ 电子数越少、颜色越浅**。

| 氧化态 | 主要存在形式 | 颜色 | 备注 |
| :---: | :--- | :---: | :--- |
| +5 | VO₂⁺（酸性）或 VO₄³⁻（碱性） | 黄或无 | 最高价，含氧酸根形式最稳定 |
| +4 | VO²⁺ | 蓝 | 双原子氧钒离子，最稳定的中间价态 |
| +3 | V³⁺(aq) | 绿 | 具还原性 |
| +2 | V²⁺(aq) | 紫 | 强还原剂 |

还原过程的净反应可写作 $2\mathrm{VO_2^+} + 3\mathrm{Zn} + 8\mathrm{H^+} \rightarrow 2\mathrm{V^{2+}} + 3\mathrm{Zn^{2+}} + 4\mathrm{H_2O}$，随锌粉不断加入，溶液中依次出现黄色（VO₂⁺）、蓝色（VO²⁺）、绿色（V³⁺）、紫色（V²⁺）四种颜色。反向操作即用氧化剂（如过氧化氢或硝酸）逐步氧化，颜色按紫、绿、蓝、黄逆向复原，可据此判断样品处于哪一价态。

钒的零价到五价的电势关系可以用 Latimer 图表达。在酸性介质中，各相邻价态之间的标准电极电势为：

$$\mathrm{VO_2^+} \xrightarrow{+1.00} \mathrm{VO^{2+}} \xrightarrow{+0.34} \mathrm{V^{3+}} \xrightarrow{-0.26} \mathrm{V^{2+}} \xrightarrow{-1.18} \mathrm{V}$$

![[bc1691164978e033769dd51e0cffe8e4d29c303eb471a03b6076adc4ae14f5c3.jpg]]
> 图 5-2：钒在酸性介质中的 Latimer 图（相邻价态间的标准电极电势依次为 +1.000 V、+0.337 V、−0.255 V，虚线标注 VO₂⁺ 直接还原至 V³⁺ 的合并电势 +0.668 V）

Latimer 图提供了两条直接可用的判据。第一条是中间价态的歧化判据：若某一价态右侧的电势大于左侧的电势，则该价态会自发歧化。对本图而言，左侧电势始终大于右侧（$1.00 > 0.34 > -0.26$），因此 VO²⁺ 与 V³⁺ 都不会歧化，反而都是相对稳定的中间价态，这与 §3.1 中「+4 价最稳定」的实验事实一致。第二条是最强还原剂的识别：$E^\theta(\mathrm{V^{3+}/V^{2+}}) = -0.26\ \mathrm{V}$、$E^\theta(\mathrm{V^{2+}/V}) = -1.18\ \mathrm{V}$，V²⁺ 的还原能力甚至强于锌本身，这正是锌粉能把钒酸根一路还原到 V²⁺ 的热力学基础。此外，酸性 VO₂⁺ 具中等氧化性（+1.00 V），能氧化碘离子（$E^\theta(\mathrm{I_2/I^-}) = +0.54\ \mathrm{V}$）与亚铁离子（$+0.77\ \mathrm{V}$），但不能氧化氯离子（$+1.36\ \mathrm{V}$）；VO₂⁺ 到 V²⁺ 的三步平均电势为 $(1.00 + 0.34 - 0.26)/3 = +0.36\ \mathrm{V}$。

五氧化二钒是钒最重要的化合物，橙红色固体，两性偏酸，可溶于强碱生成钒酸盐：$\mathrm{V_2O_5} + 6\mathrm{NaOH} \rightarrow 2\mathrm{Na_3VO_4} + 3\mathrm{H_2O}$。它通常由偏钒酸铵热分解制得：$2\mathrm{NH_4VO_3} \xrightarrow{\Delta} \mathrm{V_2O_5} + 2\mathrm{NH_3}\uparrow + \mathrm{H_2O}\uparrow$。V₂O₅ 最重要的应用是作接触法制硫酸的催化剂，其作用机制是一个典型的变价氧化物氧转移循环：第一步 V(V) 把氧交给二氧化硫而自身被还原，$\mathrm{V_2O_5} + \mathrm{SO_2} \rightarrow \mathrm{V_2O_4} + \mathrm{SO_3}$；第二步空气中的氧把 V(IV) 重新氧化回 V(V)，$\mathrm{V_2O_4} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{V_2O_5}$。两步相加即为净反应 $\mathrm{SO_2} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{SO_3}$。从中可以看出，催化剂并未「不参与反应」，而是在循环的每一步都实际参与了化学变化，只是其净变化为零；钒在此扮演的是氧原子的传递中介，V(V) 与 V(IV) 的可逆切换正是过渡金属氧化物催化氧化的普遍模式。同一原理也用于萘氧化制邻苯二甲酸酐。

钒酸根在水溶液中随 pH 降低而逐步缩合，聚合度增大，这是多酸化学的入门范例。在高 pH 条件下以正钒酸根 VO₄³⁻（四面体构型）为主，溶液无色；随 pH 下降依次生成 V₂O₇⁴⁻、V₂O₆(OH)³⁻、V₃O₉³⁻，溶液转为淡黄；pH 进一步降低生成十钒酸根 V₁₀O₂₈⁶⁻，呈深红色；在强酸中则以黄色的 VO₂⁺ 为主。缩合的本质是在碱性条件下钒酸根以分立四面体存在，而酸化后质子化促使四面体之间共用顶角氧而聚合成更大的多核阴离子，聚合度与溶液的红色深度正相关。钒的另一类化合物是三氯氧钒，黄色液体，遇水剧烈水解：$2\mathrm{VOCl_3} + 3\mathrm{H_2O} \rightarrow \mathrm{V_2O_5} + 6\mathrm{HCl}$，其行为与 TiCl₄、SiCl₄ 类似，都是高价氯化物水解生成相应氧化物与氯化氢。

| 编号 | 反应 | 用途或信号 |
| :---: | :--- | :--- |
| V1 | $\mathrm{V_2O_5} + 6\mathrm{NaOH} \rightarrow 2\mathrm{Na_3VO_4} + 3\mathrm{H_2O}$ | 两性偏酸，溶于强碱 |
| V2 | $2\mathrm{NH_4VO_3} \xrightarrow{\Delta} \mathrm{V_2O_5} + 2\mathrm{NH_3}\uparrow + \mathrm{H_2O}\uparrow$ | 制备五氧化二钒 |
| V3 | $2\mathrm{VOCl_3} + 3\mathrm{H_2O} \rightarrow \mathrm{V_2O_5} + 6\mathrm{HCl}$ | 高价氯化物剧烈水解 |
| V4 | $2\mathrm{VO_2^+} + 3\mathrm{Zn} + 8\mathrm{H^+} \rightarrow 2\mathrm{V^{2+}} + 3\mathrm{Zn^{2+}} + 4\mathrm{H_2O}$ | 颜色序列的四段总反应 |
| V5 | $\mathrm{V_2O_5} + \mathrm{SO_2} \rightarrow \mathrm{V_2O_4} + \mathrm{SO_3}$；$\mathrm{V_2O_4} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{V_2O_5}$ | 接触法制硫酸的氧转移循环 |

## §4 铬的价态—颜色—介质三联动

铬的价电子构型为 $3d^54s^1$，而非按规律填入所得的 $3d^44s^2$。这一「反常」来自半满 $d^5$ 构型在交换能上的额外稳定化：把 $4s$ 的一个电子移入 $3d$ 使 $3d$ 达到半满，体系总能量反而降低。这一构型在本讲中反复出现，是判断铬的化学行为的起点，也常被作为「反常电子构型」的经典考点。铬单质为银白色，是已知金属单质中硬度最大的元素，其原因是六个未成对电子贡献了极强的金属键。常温下铬表面覆盖一层致密的氧化膜，因此耐腐蚀，可溶于稀盐酸或稀硫酸生成绿色的 Cr(III)，但不溶于浓硝酸（钝化）。工业上以铝热法冶炼，$2\mathrm{Al} + \mathrm{Cr_2O_3} \rightarrow \mathrm{Al_2O_3} + 2\mathrm{Cr}$，实验室则通过碘化铬真空热分解获得高纯铬。

在铬的全部价态中，+3 价在酸、中、碱三种条件下都是最稳定的。六水合离子 $[\mathrm{Cr(H_2O)_6}]^{3+}$ 呈紫色，但常见的铬(III)盐如 $\mathrm{CrCl_3 \cdot 6H_2O}$ 呈绿色，稀溶液与久置溶液也呈绿色，原因是紫红色的水合离子会逐步发生水合异构转化，形成外界氯离子被水分子取代的绿色水合异构体。铬(III) 的氢氧化物具两性，$\mathrm{Cr^{3+}} + 3\mathrm{OH^-} \rightarrow \mathrm{Cr(OH)_3}\downarrow$（灰绿），继续加入过量碱则溶解为亮绿色的四羟基合铬酸根 $[\mathrm{Cr(OH)_4}]^-$。铬(III) 最引人注目的性质是其**动力学惰性**：$d^3$ 构型使晶体场稳定化能很高，配体交换速率极慢，配体交换半衰期可达 $10^5$ 秒（约 1 至 3 天），因此三种水合异构体可以被分离提纯，这在过渡金属水合离子中相当罕见。

![[2fa3a25aa59c7cb992740172864da2c2a46a4fccf75ed4eb0a59549ac4c39f31.png]]
> 图 5-3：铬(III) 三种水合异构体的配位组成与特征颜色（外界氯离子数分别为 3、2、1，可通过加入硝酸银后沉淀出的氯化银量加以区分）

铬(III) 与铝(III) 表面相似而本质相异，二者的对比是区分主族与过渡金属离子化学的典型范例。相同点是：二者的氢氧化物均具两性，均能溶于过量强碱；三价离子都能形成矾类复盐；都能发生双水解。不同点则集中体现过渡金属的特征：Cr³⁺ 有色而 Al³⁺ 无色；Cr³⁺ 动力学惰性而 Al³⁺ 配体交换极快；在碱性条件下 Cr(III) 可被过氧化氢氧化为 Cr(VI)，即具有还原性，而 Al³⁺ 不显示任何氧化还原活性。判断一道题中给出的是哪种三价离子，可以把「颜色」「配体交换快慢」「碱性介质中能否被氧化」三条并列检查。

铬(VI) 的化学展示了同一元素在不同价态下氧化还原身份的完全反转。在酸性介质中 Cr(VI) 以重铬酸根 Cr₂O₇²⁻ 存在，是强氧化剂，$E^\theta(\mathrm{Cr_2O_7^{2-}/Cr^{3+}}) = +1.33\ \mathrm{V}$；而在低氧化态一端，Cr(II) 是强还原剂，其 $E^\theta(\mathrm{Cr^{3+}/Cr^{2+}})$ 为负值，极易失电子被氧化。介于两者之间的 Cr(III) 则居中：遇到强氧化剂（如碱性过氧化氢）可被氧化到 +6，遇到强还原剂（如锌）可被还原到 +2。把 Cr 的各价态按电势从高到低排成一条数轴就可以看出，氧化还原角色并不由元素本身决定，而是由**该价态在电势数轴上的位置**决定：坐在高电势端的价态倾向得电子去氧化别人，坐在低电势端的价态倾向失电子去还原别人，居中的价态则视对手而变。这一认识是处理 Cr(VI)/Cr(III) 相互转化问题的核心。

铬酸根与重铬酸根之间的互变是铬化学中最典型的酸碱依赖平衡：

$$2\mathrm{CrO_4^{2-}}\ (\text{黄}) + 2\mathrm{H^+} \rightleftharpoons \mathrm{Cr_2O_7^{2-}}\ (\text{橙}) + \mathrm{H_2O},\quad K = 4.2 \times 10^{14}$$

平衡常数极大，说明在酸性条件下二聚形式占绝对优势。当 pH 大于 6 时以黄色的 CrO₄²⁻ 为主，pH 小于 1 时以橙色的 Cr₂O₇²⁻ 为主，因此可以用一句判据概括：加酸变橙、加碱变黄。二者的氧化性强弱也随之分化：酸性介质中的 Cr₂O₇²⁻ 是强氧化剂（$E^\theta = +1.33\ \mathrm{V}$），而碱性介质中的 CrO₄²⁻ 氧化性很弱（$E^\theta = -0.13\ \mathrm{V}$，还原为 Cr(OH)₃），这说明**同一个元素同一价态的氧化性也会被介质显著改变**。

| 物种 | 颜色 | 介质 | 氧化性 | $E^\theta$ |
| :---: | :---: | :---: | :---: | :---: |
| CrO₄²⁻ | 黄 | 碱性或中性 | 弱 | −0.13 V |
| Cr₂O₇²⁻ | 橙 | 酸性 | 强 | +1.33 V |

重铬酸根的强氧化性有两个直接应用。其一是铁的测定：$\mathrm{Cr_2O_7^{2-}} + 6\mathrm{Fe^{2+}} + 14\mathrm{H^+} \rightarrow 2\mathrm{Cr^{3+}} + 6\mathrm{Fe^{3+}} + 7\mathrm{H_2O}$，橙色随还原过程转为绿色，是重铬酸钾滴定法的依据。其二是酒精检测，$\mathrm{Cr_2O_7^{2-}}$ 被乙醇还原同样呈现橙转绿的颜色变化：$2\mathrm{Cr_2O_7^{2-}} + 3\mathrm{C_2H_5OH} + 16\mathrm{H^+} \rightarrow 4\mathrm{Cr^{3+}} + 3\mathrm{CH_3COOH} + 11\mathrm{H_2O}$。与此对应的是铬(VI) 的毒性问题：Cr(VI) 兼具强氧化性与致癌性，含铬废液必须先经还原处理，标准做法是加入适量硫酸亚铁把 Cr(VI) 还原为无毒的 Cr(III)，再调节 pH 使其以 Cr(OH)₃ 形式沉淀除去，最终铬含量达到排放标准。

铬酸盐的溶解性提供了检验 CrO₄²⁻ 的沉淀信号。除碱金属、铵和镁的铬酸盐可溶外，其余金属的铬酸盐均难溶，其中三种具有鲜明颜色，可用于定性判断与沉淀滴定。加入银离子生成砖红色的 Ag₂CrO₄，是莫尔法沉淀滴定的指示剂；加入铅离子生成橙黄色的 PbCrO₄，即工业颜料铬黄；加入钡离子生成黄色的 BaCrO₄，可用于检验 CrO₄²⁻ 的存在，但需注意与白色的 BaSO₄ 区分。从平衡移动的角度看，这些沉淀的生成都会降低溶液中 CrO₄²⁻ 的浓度，从而拉动 §4 中的二聚平衡左移。

| Pb²⁺ | $\mathrm{PbCrO_4}$ | 橙黄 | 黄色颜料（铬黄） |

新鲜配制的六水合铬(III)离子呈淡紫色，久置后会变绿并逐渐变浑浊，这一过程并非简单的变色，而是铬(III) 逐步水解缩合的连续链。以碱逐步加入为例，铬(III)在溶液中的形态按如下顺序递进：先是配位水被氢氧根取代生成 $[\mathrm{Cr(H_2O)_5(OH)}]^{2+}$，进而缩合成双核羟桥配合物 $[\mathrm{Cr_2(OH)_2(H_2O)_8}]^{4+}$，再经配位水脱去质子形成氧桥 $[\mathrm{Cr_2O(H_2O)_{10}}]^{4+}$，最后聚合沉降为水合氢氧化铬$\mathrm{Cr(OH)_3 \cdot nH_2O}$沉淀。整条链的关键在于羟桥到氧桥的转变是不可逆的，一旦形成氧桥，铬(III) 就难以再回到单核状态。理解这一步在实际操作中有直接价值：如果要在水溶液中制备铬(III) 配合物，必须加入草酸根或乙酰丙酮等强配体竞争配位，阻断水解链的推进。

铬(VI) 的特征鉴定反应是利用其在酸性条件下与过氧化氢生成过氧化铬，再用乙醚萃取，有机层显深蓝色：

$$2\mathrm{Cr_2O_7^{2-}} + 8\mathrm{H_2O_2} + 4\mathrm{H^+} \rightarrow 4\mathrm{CrO_5} + 10\mathrm{H_2O}$$

过氧化铬的分子式为 CrO(O₂)₂，其中含两个过氧根 O₂²⁻（各 −2）与一个端基氧 O²⁻（−2），据此可以算出铬的氧化态为 +6 而非 +10。判断这类「高价态含过氧基」物种的价态时，必须先把过氧根按 −2 单独扣除，剩余的负电荷才由中心原子承担，这是竞赛中反复考查的记账要点。铬的另一类重要化合物是含金属—金属多重键的双核配合物，例如二醋酸铬(II) $\mathrm{Cr_2(OAc)_4 \cdot 2H_2O}$ 中含 Cr—Cr 四重键，键级为 4，由 σ、两组 π 与一组 δ 分子轨道叠加而成。其分子轨道能级顺序与 $d$ 轨道的面对面、肩并肩、面对肩三种重叠方式一一对应，是金属—金属多重键最经典的实例，也常用作 $d$ 轨道成键与磁性的分析素材。

铬的三步显色链是鉴别铬的核心操作流程：绿色的 Cr³⁺ 加入氢氧根生成灰绿色的 Cr(OH)₃ 沉淀，继续加过量碱溶解为亮绿色的 $[\mathrm{Cr(OH)_4}]^-$，再加入过氧化氢则被氧化为黄色的 CrO₄²⁻。三步颜色依次为绿、灰绿、亮绿、黄，每一步都对应一种确定的形态，是推断题中最常出现的铬信号组合。

## §5 锰的 pH 调控氧化还原体系

锰的价态覆盖从 +2 到 +7 几乎全部整数价态，是第一过渡系中价态最丰富的元素。但在竞赛中真正高频的考点集中在一点：**高锰酸根的还原产物由溶液介质决定，而不由还原剂的强弱决定**。

| 氧化态 | 代表物种 | 颜色 | 稳定性与行为 |
| :---: | :--- | :---: | :--- |
| +2 | Mn²⁺ | 淡粉（近无色） | 酸性中很稳定（$d^5$ 半满） |
| +3 | Mn³⁺ | 酒红 | 易歧化：$2\mathrm{Mn^{3+}} + 2\mathrm{H_2O} \rightarrow \mathrm{Mn^{2+}} + \mathrm{MnO_2} + 4\mathrm{H^+}$ |
| +4 | MnO₂ | 黑 | 中性条件下稳定 |
| +6 | MnO₄²⁻ | 绿 | 仅强碱中稳定，酸性歧化：$3\mathrm{MnO_4^{2-}} + 4\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + \mathrm{MnO_2}\downarrow + 2\mathrm{H_2O}$ |
| +7 | MnO₄⁻ | 紫 | 强氧化剂，颜色来自电荷迁移 |

酸性条件下稳定的是两端价态 Mn²⁺ 与 MnO₂，中间的 Mn³⁺ 与 Mn⁶⁺ 都易歧化；碱性条件下歧化趋势减弱，Mn(VI) 以绿色的锰酸根稳定存在。这一规律同样可以用电势图判断：凡右侧电势大于左侧电势的价态必歧化，而酸碱性改变会重新分配各相邻电对的电势，从而改变哪些价态能够稳定存在。

高锰酸钾在不同介质中的还原产物是本讲最高频的考点，必须按介质逐一对上。

| 介质 | 还原产物 | Mn 价态 | 转移电子数 | 颜色变化 | $E^\theta$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 强酸（pH < 1） | Mn²⁺ | +2 | 5 | 紫红转近无色 | +1.51 V |
| 中性或弱碱 | MnO₂ | +4 | 3 | 紫红转棕黑沉淀 | +0.59 V |
| 强碱 | MnO₄²⁻ | +6 | 1 | 紫红转绿 | +0.56 V |

三个还原半反应必须完整记忆：

$$\begin{aligned}\text{酸性：}\quad &\mathrm{MnO_4^-} + 8\mathrm{H^+} + 5\mathrm{e^-} \rightarrow \mathrm{Mn^{2+}} + 4\mathrm{H_2O} \\ \text{中性：}\quad &\mathrm{MnO_4^-} + 2\mathrm{H_2O} + 3\mathrm{e^-} \rightarrow \mathrm{MnO_2}\downarrow + 4\mathrm{OH^-} \\ \text{强碱：}\quad &\mathrm{MnO_4^-} + \mathrm{e^-} \rightarrow \mathrm{MnO_4^{2-}}\end{aligned}$$

为什么同一个氧化剂面对同一个还原剂会产生三种不同产物，关键在于介质改变了锰各价态之间电势梯度的形状。在强酸中，$\mathrm{MnO_4^-}$ 还原为 Mn²⁺ 的电势高达 +1.51 V，驱动力极大，反应可以一路走到最低价；在中性介质中电势梯度被压缩，反应进行到 MnO₂ 便停下；在强碱中驱动力进一步减弱，反应刚起步就停止在 MnO₄²⁻。因此判断产物时应先确定介质，再据此确定还原产物，最后才写方程式，产物与还原剂的强弱无关。

以亚硫酸钠为还原剂的完整反应可以写成三个形式，分别对应三种介质：酸性 $2\mathrm{MnO_4^-} + 5\mathrm{SO_3^{2-}} + 6\mathrm{H^+} \rightarrow 2\mathrm{Mn^{2+}} + 5\mathrm{SO_4^{2-}} + 3\mathrm{H_2O}$；中性 $2\mathrm{MnO_4^-} + 3\mathrm{SO_3^{2-}} + \mathrm{H_2O} \rightarrow 2\mathrm{MnO_2}\downarrow + 3\mathrm{SO_4^{2-}} + 2\mathrm{OH^-}$；强碱 $2\mathrm{MnO_4^-} + \mathrm{SO_3^{2-}} + 2\mathrm{OH^-} \rightarrow 2\mathrm{MnO_4^{2-}} + \mathrm{SO_4^{2-}} + \mathrm{H_2O}$。这三个方程式的电子数分别为 10、6、2，与上表中转移电子数相对应，配平时可据此核对。此外，高锰酸根与 Mn²⁺ 共存时存在自催化效应，即反应初期生成少量 Mn²⁺ 之后反应速率显著加快，这是高锰酸钾滴定需要解释的现象之一。

> 图 5-8：高锰酸根三种介质还原产物的颜色对照（左近无色 $\mathrm{Mn^{2+}}$，中棕黑 $\mathrm{MnO_2}$ 沉淀，右绿色 $\mathrm{MnO_4^{2-}}$）

锰(II) 的鉴定依赖两个把 Mn²⁺ 氧化到高锰酸根的强氧化剂，都通过「近无色转紫红」这一颜色变化加以确认。一是铋酸钠法，在硝酸介质中铋酸钠把 Mn²⁺ 氧化：$2\mathrm{Mn^{2+}} + 5\mathrm{NaBiO_3} + 14\mathrm{H^+} \rightarrow 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$；二是过硫酸铵法，需要银离子催化：$2\mathrm{Mn^{2+}} + 5\mathrm{S_2O_8^{2-}} + 8\mathrm{H_2O} \rightarrow 2\mathrm{MnO_4^-} + 10\mathrm{SO_4^{2-}} + 16\mathrm{H^+}$。两种方法的现象完全一致，都是溶液由近无色转为特征的紫红色。

二氧化锰是锰最重要的氧化物之一，黑色固体，两性偏碱，兼具氧化性与催化性。其氧化性体现在与浓盐酸加热时可把氯离子氧化为氯气：$\mathrm{MnO_2} + 4\mathrm{HCl(浓)} \xrightarrow{\Delta} \mathrm{MnCl_2} + \mathrm{Cl_2}\uparrow + 2\mathrm{H_2O}$，此处 MnO₂ 是氧化剂而非催化剂，锰由 +4 降至 +2，这是实验室制氯气的经典反应。其催化性体现在可加速过氧化氢与氯酸钾的分解，但这两个反应的机理属后续轮次内容，本轮只需记住结论，不必展开。锰的另一种氧化物 Mn₃O₄ 为黑色，可看作 Mn₂O₃ 与 MnO 的结合，由碳酸锰受热分解并逐级氧化得到：$\mathrm{MnCO_3} \xrightarrow{\Delta} \mathrm{MnO} + \mathrm{CO_2}\uparrow$，随后 $4\mathrm{MnO} + \mathrm{O_2} \rightarrow 2\mathrm{Mn_2O_3}$，$\mathrm{Mn_2O_3} + \mathrm{MnO} \rightarrow \mathrm{Mn_3O_4}$。

尖晶石型锰酸锂 $\mathrm{LiMn_2O_4}$ 是锂电池正极材料，也是 37 届初赛的考点。其中锰的平均氧化态可由电中性条件求得：锂为 +1，氧共 −8，设锰平均为 $x$，则 $1 + 2x - 8 = 0$，解得 $x = +3.5$，说明锰以 +3 与 +4 按 1∶1 的比例混合存在，而非形式上的分数价。其合成路线为 $8\mathrm{MnO_2} + 2\mathrm{Li_2CO_3} \xrightarrow{\text{高温}} 4\mathrm{LiMn_2O_4} + 2\mathrm{CO_2}\uparrow + \mathrm{O_2}\uparrow$，需要注意碳与氧的守恒以确定氧气的计量系数。凡遇到含分数平均价态的混合价化合物，正确做法是先写出所有已知元素的价态与原子数，再由电中性条件反解中心元素的平均价态，最后按结构或磁学证据把平均价态拆分为具体价态组合。

高锰酸钾的工业制备以软锰矿为原料，先经碱熔氧化再电解。碱熔段把 MnO₂ 与氢氧化钾在约 240 °C 下通空气焙烧，生成暗绿色的锰酸钾：$2\mathrm{MnO_2} + 4\mathrm{KOH} + \mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{K_2MnO_4} + 2\mathrm{H_2O}$；水浸出后以锰酸钾为阳极液电解，阳极氧化得到紫色的高锰酸钾：$2\mathrm{K_2MnO_4} + 2\mathrm{H_2O} \xrightarrow{\text{电解}} 2\mathrm{KMnO_4} + 2\mathrm{KOH} + \mathrm{H_2}\uparrow$，粗品经重结晶提纯。在分析化学的操作层面，高锰酸钾滴定有一项必须遵守的限制：绝对不能用盐酸调节酸度。原因是酸性高锰酸根的标准电极电势（+1.51 V）高于氯的（$E^\theta(\mathrm{Cl_2/Cl^-}) = +1.36\ \mathrm{V}$），会把氯离子氧化为氯气而额外消耗标准溶液；若溶液中同时存在亚铁离子，氯离子还会被诱导氧化，使误差进一步放大。因此高锰酸钾滴定一律用硫酸调节酸度，且标准溶液需避光保存以防见光分解。

最高价含氧酸（氢氧化物）的强度递变可以严格比较：

$$\mathrm{Ti(OH)_4}\ (\text{两性偏碱}) < \mathrm{H_3VO_4}\ (\text{两性偏酸}) < \mathrm{H_2CrO_4}\ (\text{酸性}) < \mathrm{HMnO_4}\ (\text{强酸})$$

造成这一递变的物理根源是中心原子的电荷密度。从左到右，中心原子的电荷数增加而离子半径减小，对氧的极化能力增强，使 O—H 键的电子云被拉向中心原子一侧，质子因此更容易解离，酸性随之增强。同一周期主族元素含氧酸的强度顺序（$\mathrm{HClO_4} > \mathrm{H_2SO_4} > \mathrm{H_3PO_4} > \mathrm{H_2SiO_3}$）与这一过渡系序列完全同构，可见「中心原子电荷密度决定含氧酸强度」是一条跨主族与过渡系的普遍规律。与之同步的是最高氧化态氧化性的递增：中心原子越缺电子、电荷密度越高，越倾向于夺取电子回到较稳定的低氧化态，因此 $\mathrm{TiO_2}$ 几乎无氧化性，而 $\mathrm{MnO_4^-}$ 成为水溶液中最强的氧化剂之一。

## §7 常见失分陷阱与认知冲突辨析

本讲的四个元素在命题中反复出现，其易错点高度集中在「热力学与动力学混淆」「电势位置的误判」与「价态记账的疏忽」三类。以下 8 条雷区按重要程度排列，每一条都给出错误做法与规范判据的对照。

第一，把钛的电势极负误读为实际活泼。由 $E^\theta(\mathrm{Ti^{2+}/Ti}) = -1.63\ \mathrm{V}$ 得出「钛像钠一样活泼、遇水即反应」是常见误判。规范判据是区分热力学倾向与动力学速率：电势只回答反应能否发生，实际能否进行还取决于表面氧化膜的阻隔。正确表述应为钛热力学上极活泼、动力学上因致密 TiO₂ 膜而常温稳定。凡涉及钛的稳定性问题，必须同时给出这两句，缺一即失分。

第二，TiCl₄ 水解方程式配平与产物书写疏漏。水解产物应写为 TiO₂ 与氯化氢气体，$\mathrm{TiCl_4} + 2\mathrm{H_2O} \rightarrow \mathrm{TiO_2}\downarrow + 4\mathrm{HCl}\uparrow$，氯与氢的计量系数必须配平到 4；写成 HCl 溶液而漏标气体、或误把产物写成偏钛酸 $\mathrm{H_2TiO_3}$ 而未说明脱水关系，都会造成扣分。题目若要求解释白烟成分，必须答出「TiO₂ 微粒与 HCl 酸雾的混合物」，只答「白烟是 HCl」不完整。

第三，钒颜色序列的还原方向记反。在锌粉还原的语境下，颜色变化方向是黄→蓝→绿→紫，价态由高到低；若题目指明逆向（用氧化剂），则方向相反。答题时必须先确认题设是「加入还原剂」还是「加入氧化剂」，再定颜色走向。此外，VO₂⁺ 的黄色与 CrO₄²⁻ 的黄色不是同一物种，须结合后续的沉淀或互变检验加以区分。

第四，把 V₂O₅ 的催化作用误述为「催化剂不参与反应」。规范答法是写出完整的两步氧转移循环：$\mathrm{V_2O_5} + \mathrm{SO_2} \rightarrow \mathrm{V_2O_4} + \mathrm{SO_3}$ 与 $\mathrm{V_2O_4} + \frac{1}{2}\mathrm{O_2} \rightarrow \mathrm{V_2O_5}$，并指出钒在 +5 与 +4 之间往返、净变化为零。只写「催化剂降低活化能」而不给出变价循环，在考查机理的题中不得分。

第五，铬的基态电子构型写成 $3d^44s^2$。铬的正确构型是 $3d^54s^1$，源于半满 $d^5$ 的交换能稳定化效应。这一构型直接解释了为什么铬在最高氧化态（+6）与中间氧化态（+3）都表现稳定，也是本讲多个性质讨论的起点。涉及铬的任何电子结构问题，都必须先确认构型写对。

第六，把过氧化铬中的铬判为 +10 价。过氧化铬的分子式为 $\mathrm{CrO(O_2)_2}$，其中两个过氧根各带 −2 电荷、端基氧带 −2 电荷，据此铬为 +6 价。错误来源是把分子式记成 CrO₅ 后直接按五个氧原子都取 −2 记账。规范做法是先把过氧根与端基氧分别列出再求中心原子价态，凡含过氧基的物种都必须走这一步。

第七，误认为 Cr(VI) 在任何介质中都是强氧化剂。事实上 Cr(VI) 的氧化性强烈依赖介质：酸性中以 Cr₂O₇²⁻ 存在且 $E^\theta = +1.33\ \mathrm{V}$，属强氧化剂；碱性中以 CrO₄²⁻ 存在且 $E^\theta = -0.13\ \mathrm{V}$，氧化性很弱。判断 Cr(VI) 能否氧化某物种时，必须同时给出介质条件，只答「Cr(VI) 是强氧化剂」属于条件缺失。

第八，混淆高锰酸根的强碱还原产物与二氧化锰的身份。在强碱介质中高锰酸根的还原产物是绿色的 MnO₄²⁻（仅得 1 个电子），而不是棕黑色的 MnO₂，更不是 Mn²⁺；把强碱产物记成 MnO₂ 是本讲出现频率最高的错误。另需注意 MnO₂ 在与浓盐酸加热制氯气的反应中充当氧化剂（锰由 +4 降至 +2），而不是催化剂，两个身份不可混淆。
