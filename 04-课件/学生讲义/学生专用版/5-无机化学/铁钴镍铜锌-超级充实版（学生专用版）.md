## §1 铁系定位与价态竞争主线

第四周期过渡金属的左半部（Ti 至 Mn）以「高价态的强氧化性」为主线，右半部（Fe 至 Zn）则以「价态竞争与配体稳定化」为主线。从铁到锌，$3d$ 轨道逐步填满，元素的最高氧化态变得难以维持，低价态逐渐占据主导，颜色从丰富走向消失，配合物的性质也从«对配体场高度敏感»过渡到«近乎纯静电作用»。Fe、Co、Ni、Cu、Zn 五元素的化合物颜色、沉淀形态与配合物转变构成了元素推断中最密集的信号库。

五元素的价电子构型与价态竞争特征汇总如下。

| 元素 | 价电子构型 | 常见氧化态 | 价态竞争特征 |
| :---: | :---: | :---: | :--- |
| Fe | $3d^64s^2$ | +2、+3 | Fe³⁺ 为中强氧化剂（$E^\theta = +0.77\ \mathrm{V}$），Fe²⁺ 具还原性 |
| Co | $3d^74s^2$ | +2、+3 | Co³⁺ 水合离子极强氧化，仅在强场配合物中稳定 |
| Ni | $3d^84s^2$ | +2 | 水溶液中几乎只有 +2，高价态须特殊条件 |
| Cu | $3d^{10}4s^1$ | +1、+2 | Cu²⁺ 水相稳定，Cu⁺ 歧化而仅在固态或配位/沉淀态稳定 |
| Zn | $3d^{10}4s^2$ | +2 | 只有 +2，$d^{10}$ 无 $d$-$d$ 跃迁故无色 |

三条递变规律贯穿本讲。第一，高氧化态的稳定性自左向右下降：铁有常见的 +3 价，钴的 +3 价必须依靠配体才能维持，镍几乎不显 +3，铜的最高价为 +2，锌只有 +2。第二，$E^\theta(\mathrm{M^{3+}/M^{2+}})$ 自铁到钴剧升：Fe 为 $+0.77\ \mathrm{V}$，Co 高达约 $+1.92\ \mathrm{V}$，说明三价钴的水合离子足以把水氧化。第三，$d$ 电子数决定了配位几何的偏好：Fe³⁺（$d^5$）与 Co³⁺（$d^6$）倾向八面体，Ni²⁺（$d^8$）在强场下取平面正方形，Cu²⁺（$d^9$）因 Jahn-Teller 效应形成变形八面体，而 Zn²⁺（$d^{10}$）无晶体场稳定化能、只依静电与空间因素取向。把握这条 $d$ 电子主线，就能把零散的化合物性质串成可推理的体系。

> 图 6-1：第四周期 Fe→Zn 的常见氧化态分布与价电子构型（随有效核电荷增大，高氧化态越来越难形成）

## §2 铁的价态互变与配体调控

铁是「一个元素、两个价态、一组信号」的典型：Fe(II) 与 Fe(III) 之间的互变几乎支配了铁的全部水溶液化学，而硫氰酸根显色、普鲁士蓝沉淀与邻菲罗啉显色则提供了三条高灵敏度的鉴定途径。

Fe(II) 的水合离子 $[\mathrm{Fe(H_2O)_6}]^{2+}$ 呈浅绿色，为高自旋 $d^6$ 构型，具有还原性，在空气中缓慢被氧化。Fe(III) 的情况需要格外注意：$[\mathrm{Fe(H_2O)_6}]^{3+}$ 本身呈淡紫色，但因电荷高、半径小，在 pH 大于 2 时即发生水解聚合，实际观察到的黄棕色来自水解产物而非水合离子本身；当溶液含氯离子时还会生成显黄色的氯合配合物。把黄棕色归因于 $[\mathrm{Fe(H_2O)_6}]^{3+}$ 本身是常见误判，凡涉及铁(III) 溶液颜色的讨论都必须先说明酸度条件。

以 $E^\theta(\mathrm{Fe^{3+}/Fe^{2+}}) = +0.77\ \mathrm{V}$ 为标尺，可以判断 Fe(III) 能氧化与不能氧化的对象。还原电势低于 $+0.77\ \mathrm{V}$ 的还原剂可被氧化：铜（$+0.34\ \mathrm{V}$）被氧化为 Cu²⁺，碘离子（$+0.54\ \mathrm{V}$）被氧化为 I₂；还原电势高于 $+0.77\ \mathrm{V}$ 的则不能被氧化：溴离子（$+1.09\ \mathrm{V}$）与氯离子（$+1.36\ \mathrm{V}$）都不受影响。反向地，Fe(II) 可被氧气、氯气与过氧化氢氧化。铁(III)氧化铜的反应是印刷电路板蚀刻的化学基础，FeCl₃ 溶液之所以适合做蚀刻液，正是因为它既能氧化铜又不会腐蚀线路间的绝缘与基底。保存亚铁盐溶液时，需要同时加入少量硫酸抑制水解、加入铁屑把被氧化的 Fe(III) 还原为 Fe(II)。

配体可以在很宽的范围内改变同一种金属的电对电势。以铁为例，游离水合离子的 $E^\theta(\mathrm{Fe^{3+}/Fe^{2+}})$ 为 $+0.77\ \mathrm{V}$，而在邻菲罗啉配合物中该值升至约 $+1.14\ \mathrm{V}$，在氰配合物中则降至 $+0.36\ \mathrm{V}$，跨度超过 $1.2\ \mathrm{V}$。其规律可用电子推拉理解：阴离子型给体配体（$\mathrm{OH^-}$、$\mathrm{C_2O_4^{2-}}$、$\mathrm{CN^-}$）把电子推向金属，使高价态得到额外稳定，从而降低电势，此时低价态反而变得容易被空气氧化；含 $\pi$ 受体的配体（邻菲罗啉、联吡啶）从金属拉走电子，使低价态更稳定，从而升高电势，此时高价态变得难以生成。电势因此不是元素的固有常数，而是随配位环境变化的可调参数，这是配位化学解释氧化还原行为时最基本的出发点。

铁(III) 最灵敏的鉴定是硫氰酸根显色反应：$\mathrm{Fe^{3+}} + n\mathrm{SCN^-} \rightarrow [\mathrm{Fe(SCN)}_n]^{3-n}$，生成血红色配合物。该显色可被氟离子、磷酸根或草酸根破坏，因为这些配体与 Fe³⁺ 形成更稳定的无色配合物；反过来，这一性质常被用来掩蔽 Fe³⁺ 对钴离子鉴定的干扰。

亚铁离子与铁离子同六氰合铁配合物之间的沉淀反应生成同一物质，是混合价配合物的经典案例。

| 反应 | 传统名称 | 产物颜色 |
| :--- | :--- | :---: |
| $\mathrm{Fe^{3+}} + \mathrm{K^+} + [\mathrm{Fe(CN)_6}]^{4-} \rightarrow \mathrm{KFe[Fe(CN)_6]}\downarrow$ | 普鲁士蓝 | 深蓝 |
| $\mathrm{Fe^{2+}} + \mathrm{K^+} + [\mathrm{Fe(CN)_6}]^{3-} \rightarrow \mathrm{KFe[Fe(CN)_6]}\downarrow$ | 滕氏蓝 | 深蓝 |

历史上曾认为普鲁士蓝与滕氏蓝是两种不同物质，直到 X 射线衍射与穆斯堡尔谱证明二者结构完全相同，才确认它们本是一物，只是制备时原料的铁价态相反。该配合物为立方骨架：Fe(II) 与氰根的碳端配位（低自旋），Fe(III) 与氮端配位（高自旋），钾离子位于骨架空隙中以平衡电荷。理解「同构但原料价态相反」这一要点，是解决相关推断题的关键。

> 图 6-2：普鲁士蓝 $\mathrm{KFe[Fe(CN)_6]}$ 的立方骨架（Fe(III) 连氮端、Fe(II) 连碳端，钾离子充填于骨架空隙）

| 编号 | 反应 | 用途或信号 |
| :---: | :--- | :--- |
| Fe1 | $2\mathrm{Fe^{3+}} + \mathrm{Cu} \rightarrow 2\mathrm{Fe^{2+}} + \mathrm{Cu^{2+}}$ | 印刷电路板蚀刻 |
| Fe2 | $2\mathrm{Fe^{3+}} + 2\mathrm{I^-} \rightarrow 2\mathrm{Fe^{2+}} + \mathrm{I_2}$ | 验证 Fe³⁺ 的氧化性边界 |
| Fe3 | $2\mathrm{Fe^{2+}} + \mathrm{Cl_2} \rightarrow 2\mathrm{Fe^{3+}} + 2\mathrm{Cl^-}$ | 验证 Fe²⁺ 的还原性 |
| Fe4 | $\mathrm{Fe^{3+}} + n\mathrm{SCN^-} \rightarrow [\mathrm{Fe(SCN)}_n]^{3-n}$（血红） | Fe³⁺ 的特征鉴定 |
| Fe5 | $\mathrm{Fe^{3+}} + \mathrm{K^+} + [\mathrm{Fe(CN)_6}]^{4-} \rightarrow \mathrm{KFe[Fe(CN)_6]}\downarrow$ | 普鲁士蓝沉淀 |
| Fe6 | $5\mathrm{Fe^{2+}} + \mathrm{MnO_4^-} + 8\mathrm{H^+} \rightarrow 5\mathrm{Fe^{3+}} + \mathrm{Mn^{2+}} + 4\mathrm{H_2O}$ | 高锰酸钾滴定亚铁 |

## §3 钴的价态竞争与配体稳定化

钴的化学集中体现了「配体决定价态稳定性」这一命题：同一种 Co(III)，配水分子时足以把水氧化，配氨分子时却可以长期稳定存放。三价钴配合物还是配位化学理论的历史起点，维尔纳的内外界理论正是靠 $\mathrm{CoCl_3 \cdot 6NH_3}$ 与硝酸银的沉淀实验建立起来的。

| 电对 | $E^\theta$ | 含义 |
| :--- | :---: | :--- |
| $\mathrm{Co^{2+}/Co}$ | $-0.28\ \mathrm{V}$ | 钴单质比铁略不活泼 |
| $\mathrm{Co^{3+}/Co^{2+}}$ | $+1.92\ \mathrm{V}$ | 三价钴水合离子极强氧化，可氧化水放出氧气 |

由于该电势远高于水的氧化电势，水溶液中不可能存在自由的 $\mathrm{Co^{3+}(aq)}$，它一经生成即定量地把水氧化：$4\mathrm{Co^{3+}} + 2\mathrm{H_2O} \rightarrow 4\mathrm{Co^{2+}} + \mathrm{O_2}\uparrow + 4\mathrm{H^+}$。然而当钴被氨或氰根等强场配体配位后，情况完全改变：$[\mathrm{Co(NH_3)_6}]^{3+}$ 还原为二价氨配合物的电势骤降至约 $+0.10\ \mathrm{V}$，远低于水的氧化电势，于是三价钴氨配合物可以稳定存在。其原因是强场配体使 $d^6$ 的 Co(III) 形成低自旋 $t_{2g}^6$ 构型并获得很大的晶体场稳定化能，而 $d^7$ 的 Co(II) 在该场下所得稳定化能较小，两者之差把电对电势大幅拉低。这一「强场配体选择性稳定高氧化态」的规律不限于钴，也是理解整个过渡金属配位化学的重要工具。

钴(II) 的颜色与鉴定同样依赖配位环境的改变。六水合钴(II)离子 $[\mathrm{Co(H_2O)_6}]^{2+}$ 呈粉红色，是水溶液中最稳定的形态。氯化钴的变色平衡是常见的课堂演示与湿度指示剂原理：干燥条件下钴以四面体的 $[\mathrm{CoCl_4}]^{2-}$ 存在而显蓝色，吸水后转化为八面体的 $[\mathrm{Co(H_2O)_6}]^{2+}$ 而显粉红：

$$[\mathrm{CoCl_4}]^{2-}\ (\text{蓝，四面体}) + 6\mathrm{H_2O} \rightleftharpoons [\mathrm{Co(H_2O)_6}]^{2+}\ (\text{粉红，八面体}) + 4\mathrm{Cl^-}$$

钴(II) 的特征鉴定是在醋酸介质中加入亚硝酸钾生成黄色的六亚硝基合钴(III)酸钾沉淀：$\mathrm{Co^{2+}} + 7\mathrm{NO_2^-} + 3\mathrm{K^+} + 2\mathrm{H^+} \rightarrow \mathrm{K_3[Co(NO_2)_6]}\downarrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$。该反应中，亚硝酸根同时充当配体与氧化剂，把 Co(II) 氧化到 Co(III) 后再行配位，配平要点是注意氮元素的变价与消耗。此外，向钴(II)溶液中加入氨水先生成土黄色的 $[\mathrm{Co(NH_3)_6}]^{2+}$，它在空气中缓慢氧化为红棕色的三价氨配合物，这一现象与铁(II)、镍(II)的氢氧化物氧化性递变相呼应。

| 编号 | 反应 | 用途或信号 |
| :---: | :--- | :--- |
| Co1 | $4\mathrm{Co^{3+}} + 2\mathrm{H_2O} \rightarrow 4\mathrm{Co^{2+}} + \mathrm{O_2}\uparrow + 4\mathrm{H^+}$ | 三价钴水合离子的强氧化性 |
| Co2 | $[\mathrm{CoCl_4}]^{2-} + 6\mathrm{H_2O} \rightleftharpoons [\mathrm{Co(H_2O)_6}]^{2+} + 4\mathrm{Cl^-}$ | 蓝粉变色，湿度指示剂 |
| Co3 | $\mathrm{Co^{2+}} + 7\mathrm{NO_2^-} + 3\mathrm{K^+} + 2\mathrm{H^+} \rightarrow \mathrm{K_3[Co(NO_2)_6]}\downarrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$ | Co²⁺ 特征鉴定（黄色沉淀） |
| Co4 | $2\mathrm{Co(OH)_2} + \mathrm{H_2O_2} \rightarrow 2\mathrm{Co(OH)_3}$ | 二价钴氢氧化物被氧化变棕 |

## §4 镍的配位几何与羰基化学

镍在水溶液中几乎只以 +2 价存在，但其 $d^8$ 构型使 Ni(II) 配合物的几何构型随配体场强弱而系统变化，是晶体场理论最经典的教学案例之一。配体场强既决定了电子的成对方式，也决定了配合物的颜色与磁性，因此判断 Ni(II) 配合物的性质只需两步：先数 $d$ 电子，再看配体场强弱。

| 配合物 | 几何构型 | 杂化方式 | 磁性 | 颜色 |
| :--- | :---: | :---: | :---: | :---: |
| $[\mathrm{Ni(H_2O)_6}]^{2+}$ | 八面体 | $sp^3d^2$ | 顺磁（2 个未成对电子） | 绿 |
| $[\mathrm{Ni(NH_3)_6}]^{2+}$ | 八面体 | $sp^3d^2$ | 顺磁 | 蓝紫 |
| $[\mathrm{Ni(CN)_4}]^{2-}$ | 平面正方形 | $dsp^2$ | 反磁（无未成对电子） | 黄 |
| $[\mathrm{NiCl_4}]^{2-}$ | 四面体 | $sp^3$ | 顺磁（2 个未成对电子） | 蓝 |

$d^8$ 构型在弱场配体（氯离子、溴离子）下保持两个未成对电子，取四面体构型；在中等场配体（水、氨）下仍保留两个未成对电子，取八面体构型；而在强场配体（氰根、丁二酮肟）作用下，$d$ 电子被迫重排成对，腾出内层轨道参与杂化，形成平面正方形构型并转变为反磁性。这一「强场趋于平面正方形、弱场趋于四面体」的判据，与实验测得的颜色和磁性完全吻合。

![[e24689caf3117fe72dc27d03961a30f2e9a41988159b39887b4aa3a15c0ee84c.png]]
> 图 6-3：$d$ 轨道在八面体场、四面体场与平面正方形场中的分裂方式

镍(II) 最灵敏的鉴定是丁二酮肟反应。在弱碱性（氨水）介质中，Ni²⁺ 与两分子丁二酮肟结合生成平面正方形的螯合物 $\mathrm{Ni(DMG)_2}$，呈鲜红色沉淀：$\mathrm{Ni^{2+}} + 2\mathrm{DMG} \rightarrow \mathrm{Ni(DMG)_2}\downarrow + 2\mathrm{H^+}$。该反应灵敏度极高，是镍的定量分析基础。操作时必须保证溶液呈弱碱性，因为丁二酮肟本身是弱酸，在酸性介质中会质子化而失去配位能力。若溶液中同时存在 Fe³⁺ 与 Co²⁺，可先用氨水把 Fe³⁺ 沉淀为氢氧化铁并离心除去，而 Co²⁺ 不与丁二酮肟反应，不干扰测定。

镍与铁都能生成羰基配合物，但二者的制备条件差别很大：四羰基镍可在常压、约 50 °C 下生成，而五羰基铁需要 50 至 200 个大气压与约 200 °C。差异的根源可用 18 电子规则解释：镍原子有 10 个价电子，结合 4 个羰基（每个提供 2 个电子）恰好达到 18 电子，配位数与空间都合适；铁原子只有 8 个价电子，必须结合 5 个羰基才能凑满 18 电子，而第 5 个配体在空间上难以挤入，故需高压推动。这一规律在工业上被用于镍的提纯（蒙德法）：$\mathrm{Ni} + 4\mathrm{CO} \xrightleftharpoons[200\ \text{°C}]{50\ \text{°C}} \mathrm{Ni(CO)_4}$，利用四羰基镍的低沸点先低温生成、再高温分解，从而实现粗镍的深度提纯。

铁、钴、镍的氢氧化物在还原性上呈规律性递变，这是纵向比较三个元素的重要线索。

| 氢氧化物 | 颜色变化 | 空气氧化行为 | $E^\theta(\mathrm{M^{3+}/M^{2+}})$ |
| :--- | :--- | :--- | :---: |
| $\mathrm{Fe(OH)_2}$ | 白 → 灰绿 → 红棕 | 极易氧化，瞬间转为 Fe(OH)₃ | $+0.77\ \mathrm{V}$ |
| $\mathrm{Co(OH)_2}$ | 粉红 → 棕褐 | 缓慢氧化 | $+1.92\ \mathrm{V}$ |
| $\mathrm{Ni(OH)_2}$ | 绿 | 不被空气氧化 | 无稳定 +3 态 |

还原性自左向右减弱，与 $E^\theta(\mathrm{M^{3+}/M^{2+}})$ 的升高方向一致。三者的溶解性差异还可用于分离：氢氧化亚铁与氢氧化钴可溶于浓碱或氨水形成配合物，而氢氧化镍在过量氨水中仅缓慢溶解，这一差异常被用作分离与鉴别的手段。

| 编号 | 反应 | 用途或信号 |
| :---: | :--- | :--- |
| Ni1 | $\mathrm{Ni^{2+}} + 2\mathrm{DMG} \rightarrow \mathrm{Ni(DMG)_2}\downarrow$（鲜红，弱碱） | Ni²⁺ 的特征鉴定 |
| Ni2 | $\mathrm{Ni} + 4\mathrm{CO} \xrightleftharpoons[200\ \text{°C}]{50\ \text{°C}} \mathrm{Ni(CO)_4}$ | 蒙德法提纯镍 |
| Ni3 | $\mathrm{Ni^{2+}} + 2\mathrm{OH^-} \rightarrow \mathrm{Ni(OH)_2}\downarrow$ | 绿色沉淀，不被空气氧化 |

## §5 铜的价态环境依赖与歧化

铜的化学围绕一对矛盾展开：亚铜离子在气相与固态中相当稳定，在水溶液中却几乎完全歧化。理解这一环境依赖，是掌握铜的全部化合物行为的关键。

从能量角度看，气相中生成 Cu⁺ 只需付出第一电离能，而生成 Cu²⁺ 还须付出很大的第二电离能（约 $1958\ \mathrm{kJ \cdot mol^{-1}}$），因此气相中 Cu⁺ 更稳定。但进入水溶液后，离子必须经过水合，而 Cu²⁺ 电荷高、半径小，水合放热远大于 Cu⁺，其水合焓的差额足以补偿第二电离能的代价并有余，因此溶液中 Cu²⁺ 成为稳定形态。这一「气相看电离能、溶液看水合能」的对比，同样适用于解释其他过渡金属低价态的溶液不稳定性。

![[80ec00029edef599c69a65e71cdad8c9a9b349a38a687959bdd2bc954837f19a.jpg]]
> 图 6-4：Cu⁺ 与 Cu²⁺ 的能量循环对比（气相中 Cu⁺ 占优，但 Cu²⁺ 巨大的水合焓在溶液中扭转了能量关系）

溶液中 Cu⁺ 的歧化反应为 $2\mathrm{Cu^+} \rightleftharpoons \mathrm{Cu^{2+}} + \mathrm{Cu}$，平衡常数约为 $10^6$。用电势判断同样可得结论：$E^\theta(\mathrm{Cu^{2+}/Cu^+}) = +0.153\ \mathrm{V}$ 小于 $E^\theta(\mathrm{Cu^+/Cu}) = +0.521\ \mathrm{V}$，右侧电势大于左侧，中间价态不稳定，故歧化自发进行。因此自由 Cu⁺ 在水溶液中的浓度极低。

要让 Cu⁺ 稳定存在，必须设法降低其在水溶液中的有效浓度或改变其所处的环境，常用策略有三类。

| 策略 | 原理 | 典型实例 |
| :--- | :--- | :--- |
| 生成难溶沉淀 | 降低 Cu⁺ 活度，拉动歧化平衡左移 | $\mathrm{CuCl}$（白）、$\mathrm{CuI}$（白）、$\mathrm{Cu_2O}$（红） |
| 形成稳定配合物 | 以配位作用降低游离 Cu⁺ 浓度 | $[\mathrm{Cu(CN)_2}]^-$、$[\mathrm{CuCl_2}]^-$、$[\mathrm{Cu(NH_3)_2}]^+$ |
| 固态高温条件 | 无水合能项参与，热力学控制 | $\mathrm{Cu_2O}$、$\mathrm{Cu_2S}$ |

必须区分「沉淀稳定 Cu⁺」与「Cu⁺ 在溶液中稳定」这两个说法：前者只是把 Cu⁺ 转移到固相，使其离开溶液，并未改变 Cu⁺ 在水中的歧化倾向；一旦沉淀溶解、Cu⁺ 重新进入稀溶液，歧化立即发生。制备氯化亚铜的常用方法是逆歧化：把铜粉加入热的浓盐酸与铜(II)盐的混合液，生成无色的二氯合铜(I)酸根，$\mathrm{Cu^{2+}} + \mathrm{Cu} + 2\mathrm{Cl^-} \rightarrow 2[\mathrm{CuCl_2}]^-$；随后稀释或加水即析出白色的氯化亚铜沉淀。

铜(II) 的水合离子 $[\mathrm{Cu(H_2O)_6}]^{2+}$ 呈蓝色，$d^9$ 构型使其发生 Jahn-Teller 畸变，形成四短两长的变形八面体。铜(II) 配合物的颜色随配体改变而明显变化，这为鉴别提供了依据。

| 配体 | 生成物种 | 颜色 |
| :--- | :--- | :---: |
| 水 | $[\mathrm{Cu(H_2O)_6}]^{2+}$ | 蓝 |
| 过量氨 | $[\mathrm{Cu(NH_3)_4}]^{2+}$ | 深蓝（特征鉴定） |
| 浓氯离子 | $[\mathrm{CuCl_4}]^{2-}$ | 黄绿 |
| 氢氧根 | $\mathrm{Cu(OH)_2}\downarrow$，加热脱水为 $\mathrm{CuO}$ | 浅蓝转黑 |

铜的定量分析常用碘量法：铜(II) 与碘离子反应生成白色的碘化亚铜沉淀并放出碘，$2\mathrm{Cu^{2+}} + 4\mathrm{I^-} \rightarrow 2\mathrm{CuI}\downarrow + \mathrm{I_2}$，再用硫代硫酸钠滴定生成的碘。该反应之所以能够进行，正是因为生成的 CuI 沉淀把 Cu⁺ 移出溶液，使 $E^\theta(\mathrm{Cu^{2+}/Cu^+})$ 实际升高，从而能够氧化碘离子。工业上铜的获取以火法为主，经焙烧熔炼得到冰铜、再吹炼得粗铜、最后电解精炼；火法吹炼的核心反应为 $2\mathrm{Cu_2S} + 3\mathrm{O_2} \rightarrow 2\mathrm{Cu_2O} + 2\mathrm{SO_2}$ 与 $2\mathrm{Cu_2O} + \mathrm{Cu_2S} \rightarrow 6\mathrm{Cu} + \mathrm{SO_2}\uparrow$。低品位矿与回收料则用湿法，以铁置换铜离子：$\mathrm{Fe} + \mathrm{Cu^{2+}} \rightarrow \mathrm{Fe^{2+}} + \mathrm{Cu}$。

| 编号 | 反应 | 用途或信号 |
| :---: | :--- | :--- |
| Cu1 | $2\mathrm{Cu^+} \rightleftharpoons \mathrm{Cu^{2+}} + \mathrm{Cu}$（$K \approx 10^6$） | Cu⁺ 水相不稳定的定量依据 |
| Cu2 | $\mathrm{Cu^{2+}} + \mathrm{Cu} + 2\mathrm{Cl^-} \rightarrow 2[\mathrm{CuCl_2}]^-$ | 逆歧化制备氯化亚铜 |
| Cu3 | $2\mathrm{Cu^{2+}} + 4\mathrm{I^-} \rightarrow 2\mathrm{CuI}\downarrow + \mathrm{I_2}$ | 碘量法测铜 |
| Cu4 | $\mathrm{Cu^{2+}} + 4\mathrm{NH_3} \rightarrow [\mathrm{Cu(NH_3)_4}]^{2+}$（深蓝） | Cu²⁺ 的特征鉴定 |
| Cu5 | $\mathrm{Cu(OH)_2} \xrightarrow{\Delta} \mathrm{CuO} + \mathrm{H_2O}$ | 浅蓝沉淀转黑色氧化铜 |

## §6 锌的两性与电化学防护

锌位于第一过渡系的最右端，$d$ 轨道全充满。$d^{10}$ 构型既没有 $d$-$d$ 跃迁因而化合物无色，也没有晶体场稳定化能因而配合物几何纯由静电与空间因素决定。锌的常见考点集中在两性与牺牲阳极两个方面。

氢氧化锌具两性，但比氢氧化铝弱。它既能溶于酸生成锌离子，也能溶于强碱生成无色锌酸根：$\mathrm{Zn(OH)_2} + 2\mathrm{H^+} \rightarrow \mathrm{Zn^{2+}} + 2\mathrm{H_2O}$，$\mathrm{Zn(OH)_2} + 2\mathrm{OH^-} \rightarrow [\mathrm{Zn(OH)_4}]^{2-}$。金属锌本身也能与强碱反应放出氢气：$\mathrm{Zn} + 2\mathrm{NaOH} + 2\mathrm{H_2O} \rightarrow \mathrm{Na_2[Zn(OH)_4]} + \mathrm{H_2}\uparrow$。锌与铝的关键鉴别点在于对氨水的行为：氢氧化锌可溶于过量氨水生成 $[\mathrm{Zn(NH_3)_4}]^{2+}$，而氢氧化铝不溶于氨水，因为 Al³⁺ 不能形成稳定的氨配合物。

由于 $E^\theta(\mathrm{Zn^{2+}/Zn}) = -0.76\ \mathrm{V}$ 比 $E^\theta(\mathrm{Fe^{2+}/Fe}) = -0.44\ \mathrm{V}$ 更负，锌比铁活泼，在腐蚀电池中优先失去电子而被消耗，铁因此受到保护。海水中的船体与地下管道常焊接锌块作为牺牲阳极；镀锌铁（白铁）则是利用锌层既作物理屏障、又作牺牲阳极的双重防护。需要注意，牺牲阳极属«以更活泼金属保护较不活泼金属»，与外加电流的阴极保护法机理不同。

锌与同族的镉、汞构成 IIB 族，它们与 IIA 族碱土金属表面同族实则迥异。

| 对比项 | IIB 族（Zn、Cd、Hg） | IIA 族（Mg、Ca、Ba） |
| :--- | :--- | :--- |
| 价电子构型 | $(n-1)d^{10}ns^2$ | $ns^2$ |
| 阳离子极化力 | 强（$d^{10}$ 屏蔽差） | 弱（稀有气体构型屏蔽好） |
| 活泼性递变 | Zn > Cd，Hg 因 6s² 惰性电子对而反常惰性 | 自镁至钡递增 |
| 氢氧化物 | $\mathrm{Zn(OH)_2}$ 两性 | $\mathrm{Mg(OH)_2}$ 为中强碱 |
| 配位倾向 | 较强 | 较弱 |

差异的根源在于 $d^{10}$ 电子对核电荷的屏蔽较差，使有效核电荷偏大、离子极化力偏强，锌的化合物因而带明显的共价成分并易于形成配合物。这也是锌的氢氧化物呈两性而氢氧化镁呈碱性的原因。

## §7 横向递变规律

把五个元素并排观察，可以把分散的实验事实归纳为一张可查询的对照表，并据此外推未知体系的性质。

| 对比维度 | Fe | Co | Ni | Cu | Zn |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 价电子构型 | $3d^64s^2$ | $3d^74s^2$ | $3d^84s^2$ | $3d^{10}4s^1$ | $3d^{10}4s^2$ |
| 常见氧化态 | +2、+3 | +2（+3 需配合物） | +2 | +1、+2 | +2 |
| M²⁺ 水合离子颜色 | 浅绿 | 粉红 | 绿 | 蓝 | 无色 |
| $E^\theta(\mathrm{M^{2+}/M})$ | $-0.44\ \mathrm{V}$ | $-0.28\ \mathrm{V}$ | $-0.23\ \mathrm{V}$ | $+0.34\ \mathrm{V}$ | $-0.76\ \mathrm{V}$ |
| 特征鉴定 | SCN⁻ 血红 | $\mathrm{K_3[Co(NO_2)_6]}$ 黄 | 丁二酮肟鲜红 | 过量氨深蓝 | 两性溶解 |
| 氢氧化物 | 白→灰绿→红棕 | 粉红→棕褐 | 绿（不变） | 浅蓝 | 白（两性） |
| $d$ 电子与几何 | $d^5$ 八面体 | $d^6$ 八面体（强场低自旋） | $d^8$ 强场平面正方形 | $d^9$ 变形八面体 | $d^{10}$ 四面体 |

推断题的可靠解法是按「颜色—沉淀—配合物」三步推进。第一步由水合离子的颜色缩小范围：浅绿对应 Fe²⁺ 或 Ni²⁺，蓝对应 Cu²⁺，粉红对应 Co²⁺，黄棕对应 Fe³⁺，无色且具两性则考虑 Zn²⁺。第二步由加碱后的沉淀行为区分：白色沉淀迅速变灰绿再变红棕是 Fe²⁺ 的招牌现象，绿色沉淀且长时间不变为 Ni²⁺，粉红沉淀缓慢转棕褐为 Co²⁺，白色沉淀溶于过量碱则为 Zn²⁺。第三步用特征试剂确认：硫氰酸根确认 Fe³⁺，丁二酮肟确认 Ni²⁺，过量氨水确认 Cu²⁺，亚硝酸钾确认 Co²⁺。若题目涉及配合物构型，则先数 $d$ 电子、再判配体场强弱，据此确定几何与磁性。

本讲的高频失分点集中在以下几个方面。

第一，把铁(III)溶液的黄棕色归因于水合离子本身。规范的表述是：$[\mathrm{Fe(H_2O)_6}]^{3+}$ 呈淡紫色，仅在强酸性条件下可见；pH 大于 2 后水解聚合产生的羟基配合物才显黄棕，含氯离子时更因生成氯合配合物而偏黄。凡讨论铁(III)溶液颜色，必须交代酸度与阴离子环境。

第二，误认为 $\mathrm{Fe^{3+}/Fe^{2+}}$ 的电势是固定值 $+0.77\ \mathrm{V}$。该数值仅适用于水合离子；配体改变可使电势在 $+0.36\ \mathrm{V}$ 至 $+1.14\ \mathrm{V}$ 之间变动。涉及配合物参与的铁氧化还原问题，必须使用配合物的条件电势。

第三，把普鲁士蓝与滕氏蓝当成两种物质。X 射线衍射与穆斯堡尔谱已证明二者结构相同，都是铁(II)连碳端、铁(III)连氮端的立方骨架；差异只在制备时原料的铁价态相反。回答「是否同一物质」时必须给出同构的证据。

第四，认为三价钴在任何条件下都强氧化。$E^\theta(\mathrm{Co^{3+}/Co^{2+}}) = +1.92\ \mathrm{V}$ 只适用于水合离子；被氨或氰根配位后，强场带来的晶体场稳定化能使电势骤降，$[\mathrm{Co(NH_3)_6}]^{3+}$ 因而可以稳定存在。判断钴的价态稳定性必须先看配体环境。

第五，把 $[\mathrm{Ni(CN)_4}]^{2-}$ 判为四面体构型。Ni²⁺ 为 $d^8$ 构型，氰根是强场配体，使电子重排成对并腾出内层轨道，形成平面正方形的 $dsp^2$ 杂化，体现为反磁性。若配体为氯离子等弱场配体，则生成顺磁性的四面体配合物 $[\mathrm{NiCl_4}]^{2-}$。

第六，把「氯化亚铜沉淀」等同于「Cu⁺ 在溶液中稳定」。沉淀只是把 Cu⁺ 转入固相以降低其活度，并未改变 Cu⁺ 在水中的歧化趋势；一旦重新进入稀溶液，歧化立即发生。回答 Cu⁺ 稳定性问题时要区分固相与溶液两种环境。

第七，把氧化亚铜的颜色记成黑色。$\mathrm{Cu_2O}$ 为红色或红褐色，黑色的是氧化铜 $\mathrm{CuO}$；氢氧化铜受热脱水变为黑色的氧化铜，这一颜色变化常被用作铜(II)盐的确认步骤。

第八，认为氢氧化锌的两性与氢氧化铝完全相同。两者虽都溶于强碱，但对氨水的行为不同：氢氧化锌可溶于过量氨水生成 $[\mathrm{Zn(NH_3)_4}]^{2+}$，氢氧化铝不溶于氨水。这一差别正是鉴别 Zn²⁺ 与 Al³⁺ 的关键依据。
