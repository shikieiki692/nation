## §1 两亲性分子与胶束热力学

两亲性分子（amphiphilic molecules）是指在同一个分子结构中同时包含亲水极性基团（hydrophilic head）与疏水非极性碳氢链（hydrophobic tail）的特殊化学实体。根据亲水头基的解离性质，表面活性剂主要划分为四类：以硬脂酸钠 $\mathrm{C_{17}H_{35}COONa}$、十二烷基硫酸钠（SDS, $\mathrm{C_{12}H_{25}SO_4Na}$）为代表的阴离子型表面活性剂；以十六烷基三甲基溴化铵（CTAB, $\mathrm{C_{16}H_{33}N(CH_3)_3Br}$）为代表的阳离子型表面活性剂；以聚氧乙烯醚类（吐温、Triton X-100）为代表的非离子型表面活性剂；以及以卵磷脂、甜菜碱为代表的两性离子与生物两亲分子。

在水溶液中，低浓度的两亲性分子会自发迁移并富集于气-液界面。亲水极性头基伸入水中与水分子发生强烈的偶极配位或氢键作用，而长链疏水烃尾则被水网络挤出并竖直伸向气相，形成定向排列的单分子吸附膜。将两亲性分子的烃尾暴露在水中会在其周围诱导水分子的有序排列，形成类似笼状水合物的高有序度配位鞘（疏水水合），导致体系的构象熵与混合熵大幅降低。随着溶液浓度的逐步增加，气-液界面的单分子吸附逐渐达到几何紧密排列的饱和状态。此时，继续向体系中加入表面活性剂，多余的分子不再富集于界面，而是在溶液体相中自发缔合组装成微观有序聚集体，即胶束（micelles）。

表面活性剂在溶液中开始大量缔合自组装形成胶束的临界浓度称为临界胶束浓度（Critical Micelle Concentration, CMC）。在水介质中形成的正常正胶束，其内核由几十至上百个两亲分子的疏水烷基链交织聚集形成类似液态烃的微观非极性油核，外壳则由水合充分的亲水极性头基紧密排列构成，并朝向连续水相以屏蔽水相与油核的直接接触。反之，在环己烷或正己烷等非极性有机溶剂中，两亲性分子则组装形成反胶束（reverse micelles），亲水头基内卷聚集在核心形成微型水滴水池，疏水烃链向外伸展溶剂化。

关于胶束形成的热力学驱动机制，经典物理化学研究曾长期存在争论。表面活性剂烷基烃链之间的范德华引力并不足以克服同种带电头基的库仑静电排斥与组装导致的平动熵损失。胶束形成的真正核心热力学驱动力是疏水效应（hydrophobic effect）引起的体系熵增。当孤立的烷基烃链分散在水中时，非极性基团破坏了周围天然水分子之间的三维氢键四面体网络，迫使邻近的水分子形成高定向、紧密笼蔽的“冰状结构”，导致水体系的结构熵急剧下降。当两亲分子缔合形成胶束并将烃链深埋于胶束内部后，先前被束缚在烃链表面的大量结构化水分子被彻底释放回自由无序的体相本体水中，产生巨大的正熵增（$\Delta S > 0$）。

由于疏水水合结构的崩解往往伴随着少量氢键的重组，在室温附近胶束缔合过程的标准摩尔焓变 $\Delta_{\mathrm{mic}}H_m^\theta$ 实际上通常为微弱的正值（吸热）或接近于零。整个缔合聚集过程完全是由强烈的熵增驱动（$-T\Delta_{\mathrm{mic}}S_m^\theta \ll 0$），使得标准摩尔 Gibbs 自由能大幅为负（$\Delta_{\mathrm{mic}}G_m^\theta < 0$）。基于准化学相分离平衡模型，非离子型表面活性剂胶束形成的 Gibbs 自由能与 CMC 之间满足精确的热力学关系式：$\Delta_{\mathrm{mic}}G_m^\theta = RT \ln(\mathrm{CMC}/c^\theta)$；对于 $1:1$ 离子型表面活性剂，考虑抗衡离子在胶束表面的静电结合度 $\beta$，该式拓展为 $\Delta_{\mathrm{mic}}G_m^\theta = (1 + \beta) RT \ln(\mathrm{CMC}/c^\theta)$。

胶束特殊的核-壳微观相态使其具有优异的相转移与增溶能力（solubilization）。原本在水中溶解度极低的强疏水性有机小分子（如多环芳烃、紫杉醇抗癌药、油溶性染料），能够自发分配进入胶束的非极性烃核内部并稳定分散，宏观上表现为表观溶解度提升数个数量级。增溶过程不是真正的分子级相均匀溶解，而是一种热力学稳定的微观非均相包载。在现代靶向给药系统中，利用生物相容性两亲性嵌段共聚物（如聚乙二醇-聚乳酸 PEG-PLA）构筑功能胶束，不仅可大幅提高难溶药物的生物利用度，还能利用肿瘤组织增强的渗透与滞留效应（EPR 效应）实现靶向聚集。

## §2 胶体分散系物理化学

胶体分散体系是指分散相粒子的几何线度在 $1\ \mathrm{nm}$ 至 $100\ \mathrm{nm}$ 之间的多相多分散系统。根据相态关联与亲和性质，胶体分散系可划分为热力学稳定的真高分子亲液溶胶（如明胶、聚乙烯醇水溶液）以及具有巨大相界面的高度分散、热力学不稳定的憎液溶胶（如氢氧化铁水溶胶、碘化银水溶胶、金溶胶）。憎液溶胶的比表面积巨大，表面原子处于高度配位不饱和的高能态，因此具有强烈的自发减小表面自由能的趋势，在热力学上属于亚稳体系（metastable system）。

胶体之所以能够在长时间内保持分散状态而不迅速沉聚，是因为它同时拥有动力学稳定性与电学斥力稳定性。动力学稳定性的微观根源在于介质溶剂分子的剧烈热运动（布朗运动）。当胶粒质量足够小且尺度处于纳米级时，溶剂分子非对称碰撞赋予胶粒的随机动能足以完全抗衡重力引起的沉降分层，建立动态的沉降平衡（sedimentation equilibrium）。在高度为 $h$ 的胶体柱中，胶粒的粒子数密度 $n(h)$ 满足类似气压公式的 Boltzmann 分布规律：$n(h) = n_0 \exp[-m_{\mathrm{eff}}gh/(k_{\mathrm{B}}T)]$，其中 $m_{\mathrm{eff}} = \frac{4}{3}\pi r^3 (\rho - \rho_0)$ 为扣除浮力后的粒子有效质量。

憎液溶胶的电学稳定性来源于胶团（micelle unit）特殊的双电层结构。溶胶颗粒在成核生成过程中，会优先选择性化学吸附溶液中与其晶格离子同类的某种过量离子（电位决定离子），使胶核表面带上坚固的原生电荷。为了保持电中性，溶液中带相反电荷的反离子被静电吸引到胶核周围。在 Stern 双电层模型中，部分反离子与水合分子在强静电与范德华引力下紧密贴合在胶核表面，构成厚度仅几个分子尺寸的紧密层（Stern 层或吸附层）；其余反离子则因受到热扩散运动的竞争干扰，呈弥散衰减分布在紧密层外围的扩散层（Gouy-Chapman 层）中。

以过量 $\mathrm{FeCl_3}$ 水解制备的氢氧化铁水溶胶为例，水解生成的 $\mathrm{FeO^+}$ 离子作为电位决定离子吸附在微晶表面，其胶团结构通式可严谨表达为：
$$\left\{ \left[ \mathrm{Fe(OH)_3} \right]_m \cdot n\mathrm{FeO}^+ \cdot (n - x)\mathrm{Cl}^- \right\}^{x+} \cdot x\mathrm{Cl}^-$$
其中，难溶中性固体核心构成“胶核”；胶核结合吸附层中的电位决定离子与部分反离子构成“胶粒”，带 $x$ 个单位的正电荷；胶粒与扩散层中的 $x$ 个 $\mathrm{Cl^-}$ 构成宏观电中性的完整“胶团”。当带电胶粒在外加电场作用下发生相对位移（电泳）时，紧密吸附层内的液体与胶核固相作为整体共同运动，而扩散层液体则滞后滑动。该滑动面（shear plane）与溶液本体之间的电势差定义为动电电位或 $\zeta$ 电位（zeta potential）。$\zeta$ 电位反映了胶粒外露的净电荷密度，是衡量胶体双电层静电斥力强度的物理量。

胶体光学性质的典型代表是丁达尔效应（Tyndall effect）。当可见光照射溶胶时，由于胶粒尺寸（$1\sim100\ \mathrm{nm}$）远小于可见光波长（$400\sim760\ \mathrm{nm}$），光波在胶粒周围发生明显的弹性电偶极散射，即 Rayleigh 散射。Rayleigh 散射定律指出，单位体积的散射光强 $I$ 满足：
$$I = I_0 \frac{24\pi^3 n_0 V^2}{\lambda^4} \left( \frac{n_1^2 - n_0^2}{n_1^2 + 2n_0^2} \right)^2 \sin^2\theta$$
式中 $V$ 为单个微粒体积，$n_1, n_0$ 分别为粒子与介质的折射率，$\lambda$ 为入射光波长。散射光强与入射波长的四次方成反比（$I \propto \lambda^{-4}$），因而短波长的蓝紫光散射效率远高于长波长的红黄光。这解释了日间天空呈现湛蓝、而落日余晖呈现深红的物理光学本质。

胶体稳定性的现代微观定量理论是由 Derjaguin、Landau、Verwey 和 Overbeek 共同建立的 DLVO 理论。DLVO 理论将两个相遇溶胶粒子之间的相互作用总势能 $V_{\mathrm{total}}$ 表达为范德华长程吸引势能 $V_A$ 与双电层静电排斥势能 $V_R$ 之和：$V_{\mathrm{total}}(H) = V_A(H) + V_R(H)$。吸引势能主要源于各分子间 London 色散力的宏观体相积分，对于半径为 $a$、表面间距为 $H$ 的两个球形粒子，当 $H \ll a$ 时满足 $V_A \approx - \frac{A_H a}{12 H}$（$A_H$ 为 Hamaker 常数，始终为负值）。双电层静电排斥能则源于扩散层重叠造成的反离子渗透压与电场重叠，表达式为 $V_R \approx 2\pi\varepsilon a \zeta^2 \ln(1 + \mathrm{e}^{-\kappa H})$。

参数 $\kappa$ 为 Debye-Hückel 倒数长度，表征双电层厚度的倒数，其与介质溶液的离子强度 $I$ 紧密关联：$\kappa = \sqrt{\frac{2 e^2 N_A I}{\varepsilon_r \varepsilon_0 k_{\mathrm{B}} T}}$。在低电解质浓度的纯净溶胶中，双电层延展充分（$\kappa$ 很小），$V_{\mathrm{total}}$ 曲线在中间距离处形成高达数十 $k_{\mathrm{B}}T$ 的排斥势能峰（能量势垒），胶粒热碰撞无法逾越势能峰，因而体系处于动力学稳定的亚稳态。当向体系中加入外加电解质时，溶液离子强度 $I$ 急剧上升导致 $\kappa$ 增大，双电层被严重压缩变薄，滑动面 $\zeta$ 电位迅速下降。当静电斥力势能峰完全被削平至临界势垒高度消失时，胶粒即可无阻碍地跌入接触距离处的强引力“第一极小值”（深势阱），发生不可逆的聚结凝聚，此现象称为聚沉（coagulation）。

外加电解质诱发溶胶聚沉的能力具有强烈的价态效应，即著名的 Schulze-Hardy 规则。该规则指出，起聚沉主导作用的是与胶粒表面带电电性相反的抗衡离子；反离子的价数越高，使胶体发生聚沉所需的最低电解质浓度（临界聚沉浓度，Critical Coagulation Concentration, CCC 或聚沉值）越低，其聚沉能力越强。根据 DLVO 理论中势垒最大值及其导数同时为零（$V_{\mathrm{total}}=0$ 且 $\frac{\mathrm{d}V_{\mathrm{total}}}{\mathrm{d}H}=0$）的极值判据进行严格数学推导，单价、二价与三价反离子的临界聚沉浓度满足反比于离子电荷数六次方的普适渐近关系：
$$\mathrm{CCC} \propto \frac{1}{z^6} \implies \mathrm{CCC}(z=1) : \mathrm{CCC}(z=2) : \mathrm{CCC}(z=3) \approx \frac{1}{1^6} : \frac{1}{2^6} : \frac{1}{3^6} \approx 729 : 11.4 : 1$$
这一悬殊的数值比例深刻揭示了多价反离子对双电层扩散势垒显著的压缩聚沉效率。

## §3 界面热力学基础

在均相体系的热力学基本方程中，通常只包含体积功项 $-p\mathrm{d}V$。当体系被高分散为纳米晶体、多孔材料或微小液滴时，巨大比表面积上的原子配位状态严重偏离体相内部。体相内部的分子在三维空间中被同类邻近分子对称包围，各向受力完全抵消平衡；而处于两相界面表层的分子，受到来自相内部的吸引力远大于稀疏气相或异相的吸引力，导致界面分子受到指向体系内部的净法向垂直拉力。这种法向引力使表面分子具有自发向体相内迁移的收缩本能，宏观上表现为体系抵抗表面积扩大的张力效应。

在恒温恒压和恒定组成条件下，可逆地增加单位相界面面积 $\mathrm{d}A_s$ 时体系所吸收的可逆非体积功，定义为该界面的比表面 Gibbs 自由能 $G^{\mathrm{s}}$。从力的宏观力学平衡角度，平行于表面、垂直作用于表面任一边界单位长度上的收缩切向拉力定义为表面张力 $\sigma$（或记为 $\gamma$）。热力学证明，在纯液体表面，表面张力在数值上与比表面 Gibbs 自由能严格等价，即：
$$\gamma \equiv \sigma = \left(\frac{\partial G}{\partial A_s}\right)_{T, p, n} = G^{\mathrm{s}}$$
其单位可写作 $\mathrm{N\cdot m^{-1}}$ 或 $\mathrm{J\cdot m^{-2}}$，物理量纲完全一致（$1\ \mathrm{N\cdot m^{-1}} = 1\ \mathrm{J\cdot m^{-2}}$）。一切不受外力约束的孤立液体均会自发收缩至比表面积最小的几何形态——球形，这是体系自发降低自身表面自由能的直接结果。

将表面相视为具有宏观热力学广延量的独立二维相，由基本热力学微分式 $\mathrm{d}G^{\mathrm{s}} = -S^{\mathrm{s}}\mathrm{d}T + V^{\mathrm{s}}\mathrm{d}p$（忽略表面微小过剩体积 $V^{\mathrm{s}}\approx 0$），可直接导出比表面熵 $S^{\mathrm{s}}$ 与表面张力温度依赖性的精确关系：
$$S^{\mathrm{s}} = -\left(\frac{\partial \sigma}{\partial T}\right)_{p}$$
实验表明，绝大多数常见液体的表面张力 $\sigma$ 均随着温度 $T$ 的升高而单调下降，当达到临界温度 $T_c$ 时两相界限完全模糊消失，$\sigma \to 0$。因此，液体的温度系数 $\left(\frac{\partial \sigma}{\partial T}\right)_p < 0$，对应的比表面熵恒为正值（$S^{\mathrm{s}} > 0$）。表面形成伴随着分子热乱度的净增益。在此基础上，根据 Legendre 变换式 $H^{\mathrm{s}} = G^{\mathrm{s}} + TS^{\mathrm{s}}$，单位面积的表面焓（或比表面内能）可表述为：
$$H^{\mathrm{s}} = \sigma - T\left(\frac{\partial \sigma}{\partial T}\right)_{p}$$
由于 $-\left(\frac{\partial \sigma}{\partial T}\right)_p > 0$，比表面焓必定严格大于比表面 Gibbs 自由能（$H^{\mathrm{s}} > \sigma$）。

| 热力学表面量 | 数学定义式 | 物理量纲 | 微观本质与热力学意义 |
| :--- | :--- | :--- | :--- |
| **比表面自由能 $G^{\mathrm{s}}$** | $G^{\mathrm{s}} = \sigma = \left(\frac{\partial G}{\partial A_s}\right)_{T,p}$ | $\mathrm{J\cdot m^{-2}}$ 或 $\mathrm{N\cdot m^{-1}}$ | 恒温恒压可逆扩展单位界面所需的非体积功 |
| **比表面熵 $S^{\mathrm{s}}$** | $S^{\mathrm{s}} = -\left(\frac{\partial \sigma}{\partial T}\right)_{p} > 0$ | $\mathrm{J\cdot K^{-1}\cdot m^{-2}}$ | 分子由三维体相迁移至二维表面时的构象熵与排布熵增 |
| **比表面焓 $H^{\mathrm{s}}$** | $H^{\mathrm{s}} = \sigma - T\left(\frac{\partial \sigma}{\partial T}\right)_{p} > \sigma$ | $\mathrm{J\cdot m^{-2}}$ | 扩展单位表面时体系吸收的总热量与能量投入总和 |
| **分散功 $\Delta G$** | $\Delta G = \sigma \cdot \Delta A_s$ | $\mathrm{J}$ | 将大颗粒机械粉碎分散为纳米级微滴时增加的总表面能 |

当半径为 $R$ 的宏观母液滴在恒温恒压下被粉碎分散为 $N$ 个均一的微小液滴（半径为 $r$）时，体系的质量守恒约束为：$\frac{4}{3}\pi R^3 = N \cdot \frac{4}{3}\pi r^3 \implies N = (R/r)^3$。初始表面积为 $A_1 = 4\pi R^2$，分散后的总表面积则膨胀为 $A_2 = N \cdot 4\pi r^2 = 4\pi R^3/r$。表面积净增量与表面 Gibbs 自由能增加量分别为：
$$\Delta A_s = 4\pi R^2 \left( \frac{R}{r} - 1 \right) \approx \frac{4\pi R^3}{r}, \qquad \Delta G = \sigma \Delta A_s = \frac{3 V \sigma}{r}$$
当液滴尺寸由毫米级（$1\ \mathrm{mm}$）细化至纳米级（$1\ \mathrm{nm}$）时，表面积放大约 $10^6$ 倍，体系贮存了可观的表面过剩自由能。

在固-液界面热力学实验中，高分散粉末的比表面积可借助浸润热法（heat of immersion calorimetry）测定。将质量为 $m$ 的脱气洁净固体粉末完全浸入充分润湿它的液体中时，由于高能的固体表面被低能的固-液界面完全取代，相界面的能量释放全部以恒压热效应 $Q_p$ 释放：
$$Q_p = - \Delta H = A_s \cdot m \cdot H^{\mathrm{s}} \implies A_s = \frac{Q_p}{m H^{\mathrm{s}}}$$
式中 $A_s$ 为被测固体的质量比表面积（$\mathrm{m^2\cdot g^{-1}}$），$m$ 为固体粉末质量。必须格外注意：浸润放热反映的是体系的焓变，因此计算分母中必须代入比表面焓 $H^{\mathrm{s}} = \sigma - T(\frac{\partial \sigma}{\partial T})_p$，若错误代入表面张力 $\sigma$ 会导致测定结果出现显著的系统偏差。

## §4 弯曲液面与润湿现象

当液体界面为平液面时，界面两侧分子受到的合力对称，表面张力的合力平行于平面切线，两侧压力平衡相等。当界面弯曲呈凸液面或凹液面时，由于相界面存在曲率，沿曲面切线方向分布的表面张力在垂直于界面的法向产生一个净合力指向曲率中心，使得曲率中心一侧所承受的内压力高于背向曲率中心一侧的外压力。这一由表面弯曲引起的内外相压差称为附加压力 $\Delta p$。

经典的 Young-Laplace 方程给出了附加压力与曲面几何曲率的普适数学表达式：
$$\Delta p = p_{\text{凹}} - p_{\text{凸}} = \gamma \left( \frac{1}{R_1} + \frac{1}{R_2} \right)$$
式中 $R_1, R_2$ 为在弯曲液面上某点处两个互相垂直的主截面圆的主曲率半径。曲率半径的正负惯例规定为：曲面法向朝向液相内部为正（凸液面），曲面朝向气相内部为负（凹液面）。

1. **球形液滴或球形气泡**：曲面上各向同性，两主曲率半径相等（$R_1 = R_2 = R$），此时 Young-Laplace 方程简化为：
   $$\Delta p = \frac{2\gamma}{R}$$
   液滴内部所受实际总静压力等于外界大气压 $p_0$ 与附加压力之和：$p_{\mathrm{in}} = p_0 + \frac{2\gamma}{R}$。液滴半径 $R$ 越微小，内部附加压力越呈倒数急剧飙升。

2. **球形肥皂泡（液膜泡）**：肥皂泡由内、外两个彼此独立的薄液膜表面构成，两个弯曲球面的附加压力相互叠加，因此空心液膜泡内外的总附加压力为：
   $$\Delta p = \frac{4\gamma}{R}$$

若将内径为 $r$ 的细玻璃毛细管竖直插入能够润湿管壁的液体（接触角 $\theta < 90^\circ$）中，管内液面将自发形成曲率半径为 $R = \frac{r}{\cos\theta}$ 的凹弯月面。凹液面下方的液体内部承受负的附加压力 $\Delta p = -\frac{2\gamma \cos\theta}{r}$，从而驱动水柱在管内自发攀升，直至悬升液柱的自身重力静压 $\rho g h$ 与管口附加压力严格抗衡抵消：
$$\rho g h = \frac{2\gamma \cos\theta}{r} \implies h = \frac{2\gamma \cos\theta}{\rho g r}$$
若液体不能润湿管壁（如金属汞在玻璃管内，$\theta > 90^\circ$），凹凸反转，管内液面将发生自发毛细下降。

附加压力的存在深刻改变了弯曲相态的相平衡热力学参数，最核心的物理规律即为 Kelvin 方程。微小球形液滴表面为凸液面，其内部液体承受额外的附加压力 $\Delta p = \frac{2\gamma}{r}$，导致液相化学势升高：$\mathrm{d}\mu_l = V_{m,l} \mathrm{d}p = V_{m,l} \frac{2\gamma}{r}$。在恒温相平衡条件下，气相化学势增量与液相化学势增量必须相等：$\mathrm{d}\mu_g = RT \mathrm{d}\ln p_r = \mathrm{d}\mu_l$。在假设气体服从理想气体状态方程的前提下进行积分，得到著名的 **Kelvin 蒸气压公式**：
$$\ln\left(\frac{p_r}{p_0}\right) = \frac{2\gamma V_{m,l}}{r R T} = \frac{2\gamma M}{\rho r R T}$$
式中 $p_r$ 为曲率半径为 $r$ 的微小液滴的饱和蒸气压，$p_0$ 为普通平面宏观液体的标称饱和蒸气压，$V_{m,l}$ 为液体摩尔体积，$M$ 为摩尔质量，$\rho$ 为液体密度。

Kelvin 方程奠定了现代多相成核动力学与介孔材料微观表征的理论基石，其在物理化学中有四项重要推论：

1. **小液滴的极高蒸气压与 Ostwald 熟化**：对于凸液滴（$r > 0$），$p_r > p_0$。液滴半径越微小，蒸气压越高。当大小不均的微粒共存于同一密闭系统时，小微粒由于高蒸气压（或高微观溶解度）而自发发生挥发或溶解消失，蒸气或溶质向大微粒迁移富集并促进大微粒进一步粗化长大，这一自发相分离动力学过程称为 Ostwald 熟化（Ostwald ripening）。

2. **凹液面与毛细孔凝结（Capillary Condensation）**：对于多孔材料孔道内的微小凹液面，曲率中心在气相一侧（$r < 0$），Kelvin 公式指出其平衡蒸气压必定小于宏观平液面（$p_r < p_0$）。这意味着在未达到平液面饱和蒸气压（相对压力 $p/p_0 < 1$）时，多孔吸附剂内即可提前发生气相毛细凝聚填充，这一原理被广泛应用于气体吸附法表征介孔材料孔径分布（BJH 模型）。

3. **过饱和蒸气与人工降雨**：若纯净蒸气中缺乏尘埃等大曲率半径的外来凝聚核心，由于最初随机成核生成的微观分子簇液核尺寸处于亚纳米量级（$r \to 0$），其理论平衡蒸气压极高，导致蒸气即使达到数倍的过饱和度也不会自发液化（亚稳过饱和状态）。向积雨云层中喷洒碘化银（$\mathrm{AgI}$）气溶胶或干冰，能以极高效率提供与冰晶相近的大尺寸人工结晶晶核，迅速打破过饱和亚稳态并引发雨滴降落。

4. **过热液体与防暴沸**：无汽化中心的均质液体受热升温时，新生成的小气泡在微观上表现为极微小的凹液面空腔，外部液体对气泡施加巨大的收缩性附加压力，导致小气泡极易被压缩湮灭。液体即便加热超过标称沸点仍无法自发形成气泡沸腾，形成高能的过热液体（superheated liquid）。加入素烧瓷片或沸石等多孔助剂，其孔道内截留的大量微气泡提供了宏观曲率半径的气化核心，从而彻底消除了突沸暴沸的安全隐患。

当液体微滴放置于平整的固体基底上时，界面相互作用将形成气-液-固三相交界面。自固-液交界线向液体内部作液-气界面的切线，该切线与固-液界面在液体内部所夹的角定义为接触角 $\theta$（contact angle）。在机械平衡状态下，三相界面张力在水平方向上的代数和必须为零，导出经典的 **Young 方程**：
$$\gamma_{SG} = \gamma_{SL} + \gamma_{LG}\cos\theta \implies \cos\theta = \frac{\gamma_{SG} - \gamma_{SL}}{\gamma_{LG}}$$
式中 $\gamma_{SG}, \gamma_{SL}, \gamma_{LG}$ 分别为固-气、固-液和液-气界面的表面张力。

| 接触角范围 | 润湿状态 | 界面热力学判据 | 典型物理实例 |
| :--- | :--- | :--- | :--- |
| **$\theta = 0^\circ$** | **完全润湿**（完全铺展成膜） | $\gamma_{SG} \ge \gamma_{SL} + \gamma_{LG}$，铺展系数 $S \ge 0$ | 纯水在经过强酸碱洗涤的洁净亲水玻璃表面 |
| **$0^\circ < \theta < 90^\circ$** | **部分润湿**（能润湿） | $\gamma_{SG} > \gamma_{SL}$，液体能部分铺展 | 水在金属氧化物表面，有机液体在常规基底表面 |
| **$90^\circ \le \theta < 180^\circ$** | **不润湿**（疏液成珠） | $\gamma_{SG} < \gamma_{SL}$，液体呈球珠状收缩 | 水在石蜡表面（$\theta \approx 105^\circ$）、聚四氟乙烯特氟龙表面 |
| **$\theta = 180^\circ$** | **完全不润湿** | $\gamma_{SL} \ge \gamma_{SG} + \gamma_{LG}$，点接触完全排斥 | 金属汞在洁净玻璃表面（$\theta \approx 140^\circ\sim180^\circ$） |

## §5 多组分界面热力学与吸附理论

在处理多组分溶液体系的相界面现象时，热力学量不再能够通过简单的摩尔乘积直接加和，必须借助于偏摩尔量（partial molar quantities）与 Gibbs-Duhem 约束关系。对于任一广延热力学性质 $X$（如总体积 $V$、总内能 $U$、总 Gibbs 自由能 $G$ 等），体系中组分 $i$ 的偏摩尔量定义为在恒温、恒压且其他所有组分摩尔数均保持不变的条件下，广延量随组分 $i$ 摩尔数 $n_i$ 的偏导数：
$$X_i \equiv \bar{X}_i = \left( \frac{\partial X}{\partial n_i} \right)_{T, p, n_{j \neq i}}$$
根据 Euler 齐次函数定理，多组分体系的总广延量等于各组分摩尔数与其偏摩尔量乘积的代数总和：$X = \sum_i n_i X_i$。化学势 $\mu_i$ 的热力学本质即为偏摩尔 Gibbs 自由能：$\mu_i \equiv \bar{G}_i = \left( \frac{\partial G}{\partial n_i} \right)_{T, p, n_{j \neq i}}$，体系总 Gibbs 自由能表达为 $G = \sum_i n_i \mu_i$。在恒温恒压下，各组分的偏摩尔量之间并不是相互独立的，它们受到严格的 Gibbs-Duhem 方程的制约：$\sum_i n_i \mathrm{d}X_i = 0$；特别地，对化学势满足 $\sum_i n_i \mathrm{d}\mu_i = 0$ 或以摩尔分数表示为 $\sum_i x_i \mathrm{d}\mu_i = 0$。

为了严谨描述两相界面层内组分浓度的非均一空间分布，J. W. Gibbs 提出了著名的假想数学界面——Gibbs 分界面（Gibbs dividing surface）。真实界面是一个具有几个分子厚度、物理性质呈连续梯度过渡的三维非均相过渡相。Gibbs 在两相界面处引入一个没有厚度的理想几何平面，假定自相内部至此几何面之前，两相的体相体积分数与浓度均保持均一不变。实际系统在界面区域实际包含的组分 $i$ 物质的量，减去按均匀体相延伸到该假想面所推算的物质的量，其差额即定义为界面层相对于该假想面的表面过剩物质的量 $n_i^{\mathrm{s}}$。单位面积上的表面过剩物质的量定义为组分 $i$ 的表面过剩量（surface excess）$\Gamma_i$：
$$\Gamma_i = \frac{n_i^{\mathrm{s}}}{A_s} \qquad (\text{单位：}\mathrm{mol\cdot m^{-2}})$$

若将分界面选取在使溶剂（组分 1）的表面过剩量严格等于零（$\Gamma_1 = 0$）的特异位置，此时溶质（组分 2）的表面过剩量即为相对表面过剩量 $\Gamma_{2,1}$（简记为 $\Gamma$）。将表面相热力学基本式与两相本体的 Gibbs-Duhem 方程联立消去溶剂化学势项，即可严谨推导出著名的 **Gibbs 吸附等温式**：
$$\mathrm{d}\gamma = -\Gamma \mathrm{d}\mu_2 \implies \Gamma = -\left( \frac{\partial \gamma}{\partial \mu_2} \right)_T$$
在理想稀溶液中，溶质化学势可表达为 $\mu_2 = \mu_2^\theta + RT \ln(c/c^\theta)$，$\mathrm{d}\mu_2 = RT \mathrm{d}\ln c$。由此得到溶液吸附中应用最为广泛的 Gibbs 表达式：
$$\Gamma = -\frac{c}{RT} \left( \frac{\partial \gamma}{\partial c} \right)_T = -\frac{1}{RT} \left( \frac{\partial \gamma}{\partial \ln c} \right)_T$$

根据导数 $\left( \frac{\partial \gamma}{\partial c} \right)_T$ 的符号，溶质在溶液表面层的吸附行为分为两类截然不同的物理现象：

1. **正吸附（$\Gamma > 0$）**：若溶质的加入使溶液的表面张力急剧下降，即 $\left( \frac{\partial \gamma}{\partial c} \right)_T < 0$，则表面过剩量 $\Gamma > 0$。溶质分子在表面层的局部摩尔浓度高于溶液本体浓度，溶质在界面自发富集。低级醇、有机羧酸及各类表面活性剂均表现出强烈的正吸附特征。由于两亲分子的疏水烷基链具有脱离极性水相的强烈倾向，它们富集在表面并定向排列，用低表面能的甲基/亚甲基碳氢屏障取代了原本高表面能的水-气界面，从而大幅降低体系的表面自由能。

2. **负吸附（$\Gamma < 0$）**：若溶质的加入使溶液表面张力微弱升高，即 $\left( \frac{\partial \gamma}{\partial c} \right)_T > 0$，则表面过剩量 $\Gamma < 0$。溶质在表面层的浓度低于溶液本体浓度，表面层呈现溶质贫化、纯溶剂富集的微观结构。典型无机强电解质（如 $\mathrm{NaCl}$、$\mathrm{K_2SO_4}$）属于负吸附物质。这是由于高价小半径的无机离子具有强烈的静电水合能，水分子对离子的库仑静电引力远强于对水分子的分子间作用力，使得离子更倾向于深陷在水相内部形成充分的溶剂化水合鞘，自发从界面层向体相内部迁移。

当研究气-固相界面上的分子吸附时，Irving Langmuir 于 1916 年提出了开创性的单分子层化学吸附理论。Langmuir 吸附模型基于四项严格的微观物理假定：

1. 固体吸附剂表面能量在微观上完全均一，所有吸附位点（adsorption sites）具有完全等价的微观几何构型与吸附活化能；

2. 吸附质分子在固体表面仅形成局域化的单分子层吸附，每个活性吸附中心最多仅能容纳吸附一个气体分子；

3. 已吸附在邻近位点上的吸附质分子之间不存在横向侧向的相互吸引或排斥作用，吸附热不随表面覆盖度的改变而变化；

4. 吸附过程是一个处于动态统计平衡的可逆过程，即气相分子的表面撞击吸附速率与吸附态分子的热解吸速率在宏观平衡时相等。

设固体吸附剂表面的总吸附位点分数为 1，吸附质所占据的表面位点分数（表面覆盖度）为 $\theta$，空白裸露的未被占据位点分数为 $1 - \theta$。气相吸附质的平衡分压为 $p$。根据微观碰撞与动力学速率方程：
吸附过程的动力学平衡条件为：其一，吸附速率 $r_a$ 正比于气相分子的碰撞频率（即分压 $p$）及表面空白位点分数，即 $r_a = k_a p (1 - \theta)$；其二，解吸速率 $r_d$ 正比于处于吸附态的分子覆盖度，即 $r_d = k_d \theta$。

当体系达到宏观吸附动态平衡时，吸附速率与解吸速率严格相等：$k_a p (1 - \theta) = k_d \theta$。整理即可导出著名的 **Langmuir 单分子层吸附等温方程**：
$$\theta = \frac{b p}{1 + b p} = \frac{v}{v_m}$$
式中 $b = \frac{k_a}{k_d}$ 为吸附平衡常数，表征吸附剂对吸附质分子的微观亲和力强弱；$v$ 为在平衡分压 $p$ 下吸附气体的标态体积，$v_m$ 为固体表面完全铺满均一单分子层时所需的饱和吸附体积。

Langmuir 方程在不同的压力极限下展现出鲜明的特征动力学规律：
Langmuir 方程在不同压力极限下展现出鲜明的特征动力学规律：第一，在**低压极限（$b p \ll 1$）**下，分母中 $1 + b p \approx 1$，覆盖度简化为 $\theta \approx b p$，吸附体积 $v \approx v_m b p$，吸附量与平衡压力呈严格线性正比，服从 Henry 经验定律；第二，在**高压极限（$b p \gg 1$）**下，分母中 $1 + b p \approx b p$，覆盖度渐近逼近极值 $\theta \to 1$，$v \to v_m$，表面所有活性吸附中心被分子全部占满，吸附量达到饱和平台，与外部平衡压力无关。

在实际实验数据处理中，Langmuir 方程可通过代数变换转化为线性化形式以提取热力学参数：
$$\frac{p}{v} = \frac{1}{b v_m} + \frac{p}{v_m}$$
以实验测定的 $\frac{p}{v}$ 对平衡分压 $p$ 进行最小二乘线性拟合，由直线的斜率 $k_{\mathrm{slope}} = \frac{1}{v_m}$ 可直接求得单分子饱和容量 $v_m$，再由纵截距 $i_{\mathrm{int}} = \frac{1}{b v_m}$ 计算吸附平衡常数 $b$。

对于非理想固体表面或宽压力区间内的物理吸附，Langmuir 模型的“单分子层”与“能量均一”假设常被打破。德国化学家 Freundlich 提出了著名的经验等温式：$q = k p^{1/n}$（$n > 1$），该式在对数坐标下呈线性，适用于微观非均匀表面的中等覆盖度吸附。

为了解决低温惰性气体（如 $77\ \mathrm{K}$ 下的氮气）在固体表面发生多层物理凝聚的实际物理过程，Brunauer、Emmett 和 Teller 于 1938 年突破性建立了多分子层吸附理论，即 **BET 等温吸附模型**。BET 理论假定：固体表面具有多层物理吸附能力；第一层吸附直接发生在固体活性位点上，其吸附热为特异的表面吸附热 $Q_1$；自第二层起至无穷高层的分子间吸附，本质上均属于吸附质自身的蒸汽冷凝凝聚过程，各后续层的吸附热均等于吸附质在测定温度下的纯物质液化潜热 $Q_L$。在各吸附层均处于局部动态平衡的微观统计假定下，推导出标准 **BET 多层吸附方程**：
$$\frac{p}{v (p_0 - p)} = \frac{1}{v_m C} + \frac{C - 1}{v_m C} \left( \frac{p}{p_0} \right)$$
式中 $p_0$ 为被吸附气体在吸附测定温度下的饱和蒸气压，$p/p_0$ 为相对压力，$v_m$ 为第一层完全铺满时的单分子饱和吸附体积。无量纲常数 $C$ 反映第一层特异吸附热与液化潜热之差：$C \approx \exp\left( \frac{Q_1 - Q_L}{RT} \right)$。

BET 方程是现代材料化学与非均相催化领域测定多孔材料微观质量比表面积（$S_{\mathrm{BET}}$）的标准方法。通常选取 $p/p_0 = 0.05 \sim 0.35$ 的线性区进行测试，以 $\frac{p}{v(p_0 - p)}$ 对相对压力 $p/p_0$ 作图，求得直线斜率 $m$ 与截距 $i$。单分子饱和吸附体积计算为 $v_m = \frac{1}{m + i}$。若已知单个氮气分子在 $77\ \mathrm{K}$ 紧密堆积下的有效分子截面积 $\sigma_m \approx 0.162\ \mathrm{nm^2}$，样品的总比表面积可高精度计算为：
$$S_{\mathrm{BET}} = \frac{v_m N_A \sigma_m}{V_{m,\text{gas}} \cdot m_{\mathrm{sample}}}$$

## §6 多相催化表面反应动力学

气-固非均相催化反应是在催化剂固体表面微观活性中心上发生的多步连续动力学过程。典型的多相催化历程包括五个基元物理化学步骤：反应物分子由流体外层向催化剂外表面扩散（外扩散）；分子深入多孔材料微孔内部向活性中心扩散（内扩散）；反应物分子在表面活性中心发生化学吸附；在吸附活化态下发生表面化学基元反应（表面反应）；产物分子自表面脱附并沿微孔扩散返回气相本体。当催化剂颗粒足够微小且物料处于剧烈搅拌紊流状态时，内外扩散传质阻力可以完全忽略，反应整体速率受表面吸附与表面化学转化步骤严格控制。

根据反应物分子在表面反应发生前是否均需经历化学吸附活化，多相催化机理确立了两个经典的理论模型：

1. **Langmuir-Hinshelwood（LH）机理**：该机理假定**所有参与基元反应的反应物分子必须首先通过化学吸附定位在催化剂表面**，成为共吸附态物种；随后，相邻吸附位上的活化吸附态分子之间发生双分子重组或双分子相互作用，生成吸附态产物；最后产物发生解吸。

2. **Eley-Rideal（ER）机理**：该机理假定**仅有一种反应物分子在固体表面发生化学吸附**，而另一种反应物分子不经历吸附活化，直接从气相（或物理吸附弱结合的游离层）以空间动量碰撞撞击处于化学吸附态的吸附物种，瞬间发生断键重组并转化为产物。

| 动力学特征 | Langmuir-Hinshelwood（LH）机理 | Eley-Rideal（ER）机理 |
| :--- | :--- | :--- |
| **微观碰撞路径** | 两种反应物均在相邻吸附位发生共吸附，在表面进行二维碰撞反应 | 反应物 A 发生化学吸附，气相游离反应物 B 直接撞击吸附态 A 反应 |
| **决速步速率表达式** | $r = k \theta_A \theta_B = \frac{k K_A K_B p_A p_B}{(1 + K_A p_A + K_B p_B)^2}$ | $r = k \theta_A p_B = \frac{k K_A p_A p_B}{1 + K_A p_A}$ |
| **分母与分压依赖** | 分母包含两种气体的分压项 $(1 + K_A p_A + K_B p_B)^2$ | 分母仅包含被吸附组分分压 $1 + K_A p_A$，完全不出现 $p_B$ |
| **恒定分压 $p_B$ 下 $r-p_A$ 曲线** | 呈现典型的**倒 U 形极大值曲线**（过高 $p_A$ 竞争挤占 $B$ 位点导致抑制） | 呈现典型的**双曲线渐近饱和**，单调上升趋向极限常数速率 |

对于 LH 双分子反应 $\mathrm{A(g) + B(g) \to P(g)}$，设两组分在固体表面进行均一竞争吸附。吸附与空白位点满足守恒关系：$\theta_A + \theta_B + \theta_{\mathrm{vac}} = 1$。各分子的吸附与解吸平衡式为：$K_A p_A \theta_{\mathrm{vac}} = \theta_A$，$K_B p_B \theta_{\mathrm{vac}} = \theta_B$。求解得到双组分竞争吸附覆盖度：
$$\theta_A = \frac{K_A p_A}{1 + K_A p_A + K_B p_B}, \qquad \theta_B = \frac{K_B p_B}{1 + K_A p_A + K_B p_B}$$
若表面反应为决速步，基元反应速率为 $r = k_s \theta_A \theta_B$，代入覆盖度得：
$$r = \frac{k_s K_A K_B p_A p_B}{(1 + K_A p_A + K_B p_B)^2}$$
在固定反应物 B 的分压 $p_B$ 的实验条件下，考察反应速率 $r$ 随 A 组分分压 $p_A$ 的函数依赖。对 $p_A$ 求一阶导数并令其等于零：
$$\frac{\mathrm{d}r}{\mathrm{d}p_A} = k_s K_A K_B p_B \cdot \frac{(1 + K_A p_A + K_B p_B)^2 - 2 K_A p_A (1 + K_A p_A + K_B p_B)}{(1 + K_A p_A + K_B p_B)^4} = 0$$
$$\implies 1 + K_B p_B - K_A p_A = 0 \implies K_A p_A = 1 + K_B p_B$$
此时反应物 A 的表面覆盖度达到精确的最优平衡比：$\theta_A = \frac{1 + K_B p_B}{1 + (1 + K_B p_B) + K_B p_B} = \frac{1}{2}$。该极值条件具有深刻的微观物理图景：表面反应需要吸附态 A 与吸附态 B 处于互为紧邻的空间位点。当 $p_A$ 较低时，表面覆盖度不足，增加 $p_A$ 显著提升反应几率；但当 $p_A$ 过高时，强吸附的 A 分子大量占据吸附中心，反而将反应物 B 彻底排挤出固体表面（导致 $\theta_B \to 0$），导致表面反应速率逆势下滑。这种因某一组分过量吸附引发的自抑制效应是多相催化 LH 机理最鲜明的动力学特征。

若反应体系中存在不参与反应但具有极强吸附亲和力的杂质气体 I（催化剂毒物，如含硫化合物、一氧化碳），竞争吸附分母中将引入附加项 $K_I p_I$：
$$\theta_A = \frac{K_A p_A}{1 + K_A p_A + K_B p_B + K_I p_I}$$
当杂质分压极微小但吸附常数极大（$K_I p_I \gg 1 + K_A p_A + K_B p_B$）时，表面几乎全部被毒物分子封死钝化，反应速率急剧坍塌下降，这构成了催化剂中毒（catalyst poisoning）的微观热力学根源。
