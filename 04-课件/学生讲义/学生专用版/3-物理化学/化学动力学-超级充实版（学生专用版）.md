## §1 化学反应速率的定义与实验测定

化学热力学能够明确判定某一化学变化在给定外界条件下的自发进行方向与理论最大转换限度（平衡态），但无法回答反应完成究竟需要微秒还是数万年。**化学动力学（Chemical Kinetics）**是物理化学的核心分支学科，专门研究化学反应的行进速率、反应历程（微观机理）以及各种宏观物理化学条件（浓度、温度、压力、催化剂、溶剂介质、光照辐射等）对反应速率的定量调控规律。

### 1.1 反应进度与均相恒容反应速率的严格定义

为了消除因选取的化学反应方程式中不同参与物质导致的速率数值差异，必须基于国际纯粹与应用化学联合会（IUPAC）推荐的**反应进度（Extent of Reaction, 记作 $\xi$）**建立统一标准。

#### 1.1.1 反应进度与化学计量数定义
对于任意通用的化学计量方程式：
$$0 = \sum_{\mathrm{B}} \nu_{\mathrm{B}} \mathrm{B} \quad \text{即} \quad a\mathrm{A} + b\mathrm{B} \rightarrow g\mathrm{G} + h\mathrm{H}$$
其中物质 $\mathrm{B}$ 的化学计量数 $\nu_{\mathrm{B}}$ 规定为无量纲纯数：反应物取负值（$\nu_{\mathrm{A}} = -a, \nu_{\mathrm{B}} = -b$），生成物取正值（$\nu_{\mathrm{G}} = +g, \nu_{\mathrm{H}} = +h$）。
若反应过程中某组分 $\mathrm{B}$ 的物质的量改变了 $\mathrm{d}n_{\mathrm{B}}$，则系统反应进度的微元增量定义为：
$$\mathrm{d}\xi = \frac{\mathrm{d}n_{\mathrm{B}}}{\nu_{\mathrm{B}}} \quad (\mathrm{B} \text{ 为体系中任意反应物或生成物})$$
反应进度 $\xi$ 的量纲为摩尔（$\mathrm{mol}$）。无论以哪一种参与物种计算，系统的反应进度增量 $\mathrm{d}\xi$ 恒定且唯一。

#### 1.1.2 恒容均相系统反应速率的严格解析
对于反应体系体积恒定（$V = \text{常数}$）的均相液相或气相封闭体系，宏观**化学反应速率（Reaction Rate, 记作 $v$ 或 $r$）**严格定义为单位体积内反应进度随时间的变化率：
$$v = \frac{1}{V} \frac{\mathrm{d}\xi}{\mathrm{d}t} = \frac{1}{V} \left( \frac{1}{\nu_{\mathrm{B}}} \frac{\mathrm{d}n_{\mathrm{B}}}{\mathrm{d}t} \right) = \frac{1}{\nu_{\mathrm{B}}} \frac{\mathrm{d}(n_{\mathrm{B}} / V)}{\mathrm{d}t} = \frac{1}{\nu_{\mathrm{B}}} \frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t}$$
展开为常规代数形式：
$$v = -\frac{1}{a} \frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = -\frac{1}{b} \frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = +\frac{1}{g} \frac{\mathrm{d}[\mathrm{G}]}{\mathrm{d}t} = +\frac{1}{h} \frac{\mathrm{d}[\mathrm{H}]}{\mathrm{d}t}$$
反应速率 $v$ 的标准国际单位（$\mathrm{SI}$）为 $\mathrm{mol\cdot m^{-3}\cdot s^{-1}}$，实验化学中最常用的单位为 $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$ 或 $\mathrm{mol\cdot L^{-1}\cdot min^{-1}}$。在速率定义式中除以各组分的化学计量数绝对值，其核心物理意义在于保证：**同一化学反应在同一时刻，无论通过哪一种反应物的消耗速率还是产物的生成速率来表达，其所测定的宏观统一反应速率数值完全严格唯一相等**。

### 1.2 平均速率、瞬时速率与初始速率

由于随着反应进行，反应物不断被消耗使得浓度单调下降，化学反应速率在时间序列上呈现非线性的动态衰减过程。

#### 1.2.1 平均速率（Average Rate）
指在某一宏观有限时间段 $\Delta t = t_2 - t_1$ 内反应物或产物浓度的平均变化率：
$$\overline{v} = -\frac{1}{a} \frac{\Delta [\mathrm{A}]}{\Delta t} = +\frac{1}{g} \frac{\Delta [\mathrm{G}]}{\Delta t}$$
平均速率仅能反映系统在该时间跨度内的粗略宏观进度，掩盖了过程内部速率随浓度的连续变化特征。

#### 1.2.2 瞬时速率（Instantaneous Rate）
当时间微元 $\Delta t$ 趋向于零的极限时，平均速率的极限即为特定时刻 $t$ 的**瞬时速率**：
$$v = \lim_{\Delta t \to 0} \left( -\frac{1}{a} \frac{\Delta [\mathrm{A}]}{\Delta t} \right) = -\frac{1}{a} \frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t}$$
在几何图象上，瞬时速率等于特定时刻浓度-时间（$c-t$）反应曲线上对应数据点的**切线斜率绝对值除以计量系数**（如图 1 所示）。

#### 1.2.3 初始速率（Initial Rate, 记作 $v_0$）
反应刚刚启动、时间趋于零（$t \to 0$）极限处的瞬时速率称为**初始速率**。初始速率在实验动力学中具有极其重要的战略地位：
1. 在反应初始瞬间，产物浓度几乎为零，逆向反应速率微不足道，测得的数据是纯粹正向单向反应速率的真实体现；
2. 此时反应尚未产生副产物，完全排除了中间体或副反应产物对催化剂表面活性位点的毒化与自抑制效应；
3. 反应物各组分浓度严格等于初始配料浓度，无需通过复杂的积分方程即可直接应用微分速率方程进行反应级数的高精度解析。

### 1.3 现代反应动力学实验监控技术

动力学实验的本质在于连续高频或实时原位监测系统组分浓度随时间的变化曲线（$c(t)$ 曲线）。
实验室中测定反应速率的典型物理与化学方法主要包括：其一，**化学淬灭滴定法（Chemical Quenching Method）**，在离散时间点移取微量反应液，通过骤冷、剧烈稀释或加入定量竞争淬灭剂瞬间终止反应，随后采用标准酸碱或氧化还原滴定测定残留物浓度；其二，**分光光度吸收法（Spectrophotometry）**，根据朗伯-比尔定律（Lambert-Beer Law, $A = \varepsilon b c$），利用特征反应物或产物在特定紫外-可见吸收波长处的吸光度 $A$ 与浓度 $c$ 的严格线性正比关系，实现在线无损连续光电监测；其三，**电导测定法（Conductometry）**，对于涉及水合离子产生或消除的离子反应，溶液电导率与离子浓度及极限摩尔电导率严格关联，灵敏度极高；其四，**气压法与膨胀计法（Manometry and Dilatometry）**，利用气相反应分子数改变引起的恒容容器内压力变化（由道尔顿分压推导）或液相体积的细微涨缩进行原位跟踪；其五，**停流技术（Stopped-Flow Technique）与飞秒激光光谱**，针对半衰期处于毫秒（$\mathrm{ms}$）至飞秒（$\mathrm{fs}$）量级的超快基元反应，通过微量注射泵高压碰撞腔与瞬态吸收光谱实现纳秒级时间分辨动力学测量。

## §2 反应速率方程、反应级数与速率常数

在恒温条件下，均相化学反应速率是各参与物种瞬时浓度的多变量函数。将反应速率与各组分浓度之间的定量代数关联表达式称为**动力学速率方程（Rate Law）**。

### 2.1 微分速率方程与反应级数

对于一般的均相反应 $a\mathrm{A} + b\mathrm{B} \rightarrow \text{产物}$，其实验测定的微分速率方程通常具有如下幂函数形式：
$$v = k [\mathrm{A}]^m [\mathrm{B}]^n$$

#### 2.1.1 反应级数（Reaction Order）的物理内涵
在微分速率方程中：指数 $m$ 称为**反应关于反应物 $\mathrm{A}$ 的分级数（Partial Order）**；指数 $n$ 称为**反应关于反应物 $\mathrm{B}$ 的分级数**；各分级数的代数和 $n_{\text{总}} = m + n + \cdots$ 称为该化学反应的**总反应级数（Overall Reaction Order）**。
反应级数的数值直接反映了特定反应物浓度变化对宏观反应速率调控的灵敏程度：
分级数的大小定量刻画了反应速率对反应物浓度的敏感程度：若 $m = 1$（一级），浓度加倍则反应速率加倍；若 $m = 2$（二级），浓度加倍则反应速率激增为原来的 4 倍；若 $m = 0$（零级），反应速率完全独立于该反应物的瞬时浓度。反应级数不仅可以是整数（$0, 1, 2, 3$），还可以是**分数**（如乙醛热解生成甲烷和一氧化碳反应总级数为 $\frac{3}{2}$ 级，光化学合成溴化氢反应中溴的分级数为 $\frac{1}{2}$ 级），甚至可以是**负数**（如臭氧分解反应中氧气分级数为 $-1$ 级，表明产物对正向分解具有动力学自抑制阻滞效应）。

#### 2.1.2 反应级数与化学计量系数的根本分野
除一步完成的微观基元反应外，对于绝大多数由若干基元步骤构成的复杂复合反应，**速率方程中的分级数 $m, n$ 与宏观化学计量方程式中的计量系数 $a, b$ 完全没有任何先验的必然代数关系**！化学计量方程式表达的仅仅是系统在化学变化始末的原子质量守恒与原子配比关联，丝毫不蕴含微观分子发生有效碰撞与化学键重组的具体物理路径。因此，**任意复杂反应的动力学速率方程必须通过实验严格测定判定，绝对严禁直接依据总反应方程式的系数主观臆断**！

### 2.2 速率常数（Rate Constant, $k$）及其量纲分析

比例常数 $k$ 称为该温度下的**反应速率常数（Rate Constant）**。

#### 2.2.1 速率常数的物理本质
当反应体系中所有参与反应物的浓度均恰好处于标准单位浓度（即 $[\mathrm{A}] = [\mathrm{B}] = 1\ \mathrm{mol\cdot L^{-1}}$）时，由速率方程可知：
$$v = k \cdot (1)^m (1)^n = k$$
因此速率常数 $k$ 在物理本质上即为**特征比速率（Specific Rate）**。速率常数 $k$ 完全独立于反应物的瞬时浓度与反应进度，它是体系**温度、溶剂介质性质以及催化剂活性**的单值敏感函数。

#### 2.2.2 速率常数 $k$ 的量纲通式与级数倒推
在 $\mathrm{SI}$ 制中，由于反应速率 $v$ 的量纲恒为 $[\text{浓度}]\cdot [\text{时间}]^{-1} = \mathrm{mol\cdot L^{-1}\cdot s^{-1}}$，根据速率方程两端量纲必须严格闭合对等的物理规律：
$$[v] = [k] \cdot [\text{浓度}]^{n_{\text{总}}} \implies [k] = \frac{[v]}{[\text{浓度}]^{n_{\text{总}}}} = \frac{\mathrm{mol\cdot L^{-1}\cdot s^{-1}}}{(\mathrm{mol\cdot L^{-1}})^{n_{\text{总}}}}$$
由此导出总反应级数为 $n_{\text{总}}$ 时速率常数 $k$ 的普适量纲解析通式：
$$[k] = (\mathrm{mol\cdot L^{-1}})^{1 - n_{\text{总}}} \cdot \mathrm{s^{-1}} = \mathrm{mol}^{1 - n_{\text{总}}}\cdot \mathrm{L}^{n_{\text{总}} - 1}\cdot \mathrm{s^{-1}}$$

在化学奥赛与科学研究中，**直接审视题目中速率常数 $k$ 的物理单位，即可瞬间倒推断定该反应的真实总反应级数**：

| 总反应级数（$n_{\text{总}}$） | 速率常数 $k$ 标准单位（$\mathrm{SI}$ / 常用） | 典型反应微分速率方程 | 浓度加倍对速率的放大效应 |
| :---: | :--- | :--- | :---: |
| **零级反应（$n=0$）** | $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$ | $v = k$ | $2^0 = 1$ 倍（速率恒定不变） |
| **一级反应（$n=1$）** | $\mathrm{s^{-1}}$ 或 $\mathrm{min^{-1}}$ | $v = k [\mathrm{A}]$ | $2^1 = 2$ 倍（速率线性翻倍） |
| **二级反应（$n=2$）** | $\mathrm{L\cdot mol^{-1}\cdot s^{-1}}$ | $v = k [\mathrm{A}]^2$ 或 $k[\mathrm{A}][\mathrm{B}]$ | $2^2 = 4$ 倍（速率变为 4 倍） |
| **三级反应（$n=3$）** | $\mathrm{L^2\cdot mol^{-2}\cdot s^{-1}}$ | $v = k [\mathrm{A}]^2 [\mathrm{B}]$ | $2^3 = 8$ 倍（速率变为 8 倍） |
| **半级反应（$n=1/2$）** | $\mathrm{mol^{1/2}\cdot L^{-1/2}\cdot s^{-1}}$ | $v = k [\mathrm{A}]^{1/2}$ | $2^{1/2} \approx 1.414$ 倍 |

### 2.3 确定反应级数的实验物理化学方法

#### 2.3.1 初始速率法（Method of Initial Rates）
通过系统地改变某一反应物的初始浓度 $[\mathrm{A}]_0$，同时保持其他所有反应物的初始浓度严格恒定，分别精确测定反应启动时的初始速率 $v_0$。
设其他组分浓度恒定，对于反应物 $\mathrm{A}$ 的两次独立实验 1 与 2：
$$v_{0, 1} = k [\mathrm{A}]_{0, 1}^m [\mathrm{B}]_{0, 1}^n, \quad v_{0, 2} = k [\mathrm{A}]_{0, 2}^m [\mathrm{B}]_{0, 1}^n$$
两式相比消去未知的 $k$ 和组分 $\mathrm{B}$ 浓度项：
$$\frac{v_{0, 1}}{v_{0, 2}} = \left( \frac{[\mathrm{A}]_{0, 1}}{[\mathrm{A}]_{0, 2}} \right)^m \implies m = \frac{\ln(v_{0, 1} / v_{0, 2})}{\ln([\mathrm{A}]_{0, 1} / [\mathrm{A}]_{0, 2})}$$
由此严格精确求解出反应物 $\mathrm{A}$ 的分级数 $m$。同理变换其他组分浓度即可解出全部各分级数，进而代入任意一组实验数据反求出速率常数 $k$。

#### 2.3.2 浓度隔离法（Flooding Method / 假级数法）
当反应物较多时，可使反应物 $\mathrm{B}$ 大大过量于 $\mathrm{A}$（如 $[\mathrm{B}]_0 \ge 100 [\mathrm{A}]_0$）。在整个反应进程中，由于 $\mathrm{A}$ 消耗极微，过量反应物 $\mathrm{B}$ 的浓度几乎恒定不变（$[\mathrm{B}]_t \approx [\mathrm{B}]_0 = \text{常数}$）。
此时速率方程可简化为：
$$v = k [\mathrm{A}]^m [\mathrm{B}]^n \approx (k [\mathrm{B}]_0^n) [\mathrm{A}]^m = k_{\text{表观}} [\mathrm{A}]^m$$
原复合多组分反应被降阶等效为一个只关于 $\mathrm{A}$ 的单组分**准级数（Pseudo-order）反应**（若 $m=1$ 则称为**准一级反应, Pseudo-first-order**），随后利用简单的单变量积分法测定其分级数。

**例1（初始速率法解析一氧化氮与氢气气相反应机理与动力学参数）**：
在 $800\ ^\circ\mathrm{C}$ 恒温密闭反应容器中，一氧化氮与氢气发生如下气相氧化还原反应：
$$\mathrm{2 NO(g) + 2 H_2(g) \rightarrow N_2(g) + 2 H_2O(g)}$$

## §3 简单级数反应的积分速率方程与半衰期

微分速率方程建立了反应瞬时速率与浓度的关系，而在化学工程与定量分析中，更需要获得组分浓度与反应时间 $t$ 之间的显式解析关联函数 $c(t)$。通过对微分方程进行定积分，可推导出简单级数反应的**积分速率方程（Integrated Rate Law）**。

### 3.1 零级反应（Zeroth-Order Reaction）

零级反应的速率完全独立于反应物浓度，宏观反应以恒定恒速向前推进。

#### 3.1.1 积分方程式推导
微分速率方程：
$$v = -\frac{\mathrm{d}c}{\mathrm{d}t} = k_0$$
分离变量并积分：
$$\int_{c_0}^{c_t} \mathrm{d}c = -k_0 \int_{0}^{t} \mathrm{d}t \implies c_t - c_0 = -k_0 t$$
整理得到零级反应标准积分形式：
$$c_t = c_0 - k_0 t$$
零级反应具有两大显著特征：其一，**线性特征**，以反应物浓度 $c_t$ 对时间 $t$ 作图，呈现一条严格下倾的直线，直线斜率等于 $-k_0$，纵截距为初始浓度 $c_0$；其二，**反应耗尽时间（$t_{\text{终}}$）**，当 $c_t = 0$ 时反应彻底耗尽，$t_{\text{终}} = \frac{c_0}{k_0}$。

#### 3.1.2 零级反应半衰期（Half-life, 记作 $t_{1/2}$）
半衰期定义为反应物浓度消耗至其初始值一半（$c_t = \frac{1}{2}c_0$）所需的时间。
代入积分方程式：
$$\frac{1}{2}c_0 = c_0 - k_0 t_{1/2} \implies k_0 t_{1/2} = \frac{1}{2}c_0 \implies t_{1/2} = \frac{c_0}{2 k_0}$$
零级反应的核心特征：**其半衰期与初始浓度 $c_0$ 成严格正比例关系**！初始浓度越高，消耗掉一半物质所需的时间越长。

### 3.2 一级反应（First-Order Reaction）

一级反应在放射性核物理、环境化学降解与药物代谢动力学中占据核心统治地位。

#### 3.2.1 积分方程式推导
微分速率方程：
$$v = -\frac{\mathrm{d}c}{\mathrm{d}t} = k_1 c$$
分离变量：
$$\frac{\mathrm{d}c}{c} = -k_1 \mathrm{d}t$$
积分：
$$\int_{c_0}^{c_t} \frac{\mathrm{d}c}{c} = -k_1 \int_{0}^{t} \mathrm{d}t \implies \ln\left( \frac{c_t}{c_0} \right) = -k_1 t$$
对数积分形式：
$$\ln c_t = \ln c_0 - k_1 t \quad \text{或} \quad \ln\left( \frac{c_0}{c_t} \right) = k_1 t$$
指数衰减形式：
$$c_t = c_0 \exp(-k_1 t)$$
一级反应的核心线性关系为：以浓度的自然对数 $\ln c_t$ 对时间 $t$ 作图呈严格直线，斜率为 $-k_1$，截距为 $\ln c_0$；若采用常用对数 $\lg$，则表达式为 $\lg c_t = \lg c_0 - \frac{k_1}{2.303} t$，此时对应直线斜率为 $-\frac{k_1}{2.303}$。

#### 3.2.2 一级反应半衰期与指纹特征
将 $c_t = \frac{1}{2}c_0$ 代入积分方程：
$$\ln\left( \frac{c_0}{\frac{1}{2}c_0} \right) = \ln 2 = k_1 t_{1/2}$$
解得：
$$t_{1/2} = \frac{\ln 2}{k_1} = \frac{0.693147\dots}{k_1} \approx \frac{0.693}{k_1}$$
一级反应最核心的动力学物理定律：**一级反应的半衰期完全由速率常数 $k_1$ 唯一决定，与反应物的初始浓度 $c_0$ 彻底无关！**无论反应初始浓度多高或多低，每消耗剩余物质的一半所花费的时间严格恒定相等。
经 $n$ 个半衰期（$t = n \cdot t_{1/2}$）后，反应物残留摩尔分数为：
$$\frac{c_t}{c_0} = \left( \frac{1}{2} \right)^n = 2^{-n}$$

#### 3.2.3 平均寿命（Mean Lifetime, 记作 $\tau$）
定义为微观反应分子能够稳定存活的统计平均寿命：
$$\tau = \frac{\int_{0}^{\infty} t (-\mathrm{d}c / \mathrm{d}t) \mathrm{d}t}{\int_{0}^{\infty} (-\mathrm{d}c / \mathrm{d}t) \mathrm{d}t} = \frac{1}{k_1}$$
平均寿命等于速率常数的倒数，与半衰期的数学关系为：
$$\tau = \frac{t_{1/2}}{\ln 2} \approx 1.443 t_{1/2}$$
当时间 $t = \tau$ 时，反应物浓度恰好衰减为初始浓度的 $e^{-1} \approx 36.79\%$。

### 3.3 二级反应（Second-Order Reaction）

最常见的二级反应分为单反应物自缩合（$\mathrm{2A \rightarrow P}$）与双分子复分解（$\mathrm{A + B \rightarrow P}$）。

#### 3.3.1 单反应物二级反应积分推导
微分方程式：
$$-\frac{\mathrm{d}c}{\mathrm{d}t} = k_2 c^2$$
分离变量并积分：
$$\int_{c_0}^{c_t} -\frac{\mathrm{d}c}{c^2} = k_2 \int_{0}^{t} \mathrm{d}t \implies \left[ \frac{1}{c} \right]_{c_0}^{c_t} = k_2 t$$
积分方程式：
$$\frac{1}{c_t} - \frac{1}{c_0} = k_2 t \implies \frac{1}{c_t} = \frac{1}{c_0} + k_2 t$$
**线性特征**：以浓度的倒数 $\frac{1}{c_t}$ 对时间 $t$ 作图呈严格向上倾斜的直线，斜率为 $+k_2$，纵截距为 $\frac{1}{c_0}$。

#### 3.3.2 二级反应半衰期
代入 $c_t = \frac{1}{2}c_0$：
$$\frac{1}{\frac{1}{2}c_0} - \frac{1}{c_0} = \frac{2}{c_0} - \frac{1}{c_0} = \frac{1}{c_0} = k_2 t_{1/2} \implies t_{1/2} = \frac{1}{k_2 c_0}$$
二级反应的核心特征：**其半衰期与初始浓度 $c_0$ 成严格反比**！初始物料浓度越浓，分子间碰撞频率越高，前一半反应耗时越短；随着反应进行浓度稀释，后继各个半衰期将呈级数倍剧烈延长（连续半衰期比例为 $1 : 2 : 4 : 8 \cdots$）。

#### 3.3.3 双反应物不等浓度二级反应
对于反应 $\mathrm{A + B \rightarrow P}$，初始浓度分别为 $a = [\mathrm{A}]_0, b = [\mathrm{B}]_0$ 且 $a \neq b$。
设在时间 $t$ 时反应消耗的物质的量浓度为 $x$（此时 $[\mathrm{A}]_t = a - x, [\mathrm{B}]_t = b - x$）：
$$\frac{\mathrm{d}x}{\mathrm{d}t} = k_2 (a - x)(b - x)$$
采用部分分式拆分积分后，得到标准解析式：
$$\frac{1}{a - b} \ln\left( \frac{b(a - x)}{a(b - x)} \right) = k_2 t \quad \text{即} \quad \frac{1}{[\mathrm{A}]_0 - [\mathrm{B}]_0} \ln\left( \frac{[\mathrm{B}]_0 [\mathrm{A}]_t}{[\mathrm{A}]_0 [\mathrm{B}]_t} \right) = k_2 t$$
若以 $\ln\left( \frac{[\mathrm{A}]_t}{[\mathrm{B}]_t} \right)$ 对时间 $t$ 作图，将得到一条斜率为 $([\mathrm{A}]_0 - [\mathrm{B}]_0) k_2$ 的直线。

## §4 反应速率与温度的关系：阿伦尼乌斯定律

在化学反应动力学研究中，温度是影响化学反应速率极其敏感的外界变量。实验表明，绝大多数均相化学反应的速率随温度升高呈现出极其显著的指数加速效应。1889年，瑞典化学家阿伦尼乌斯（Svante Arrhenius）在系统归纳总结范特霍夫（van 't Hoff）热力学平衡常数温度依赖关系的基础上，提出了描述反应速率常数与热力学绝对温度定量依赖关系的经验定律——阿伦尼乌斯定律（Arrhenius Law）。

### 4.1 阿伦尼乌斯经验公式的三大数学形式

阿伦尼乌斯定律在动力学定量分析与工程计算中具有三种相互等价的标准数学表现形式：

#### 1. 微分形式（Differential Form）
$$\frac{\mathrm{d}\ln k}{\mathrm{d}T} = \frac{E_\mathrm{a}}{RT^2}$$
式中：
式中各项参数的物理意义分别为：$k$ 为该反应在热力学温度 $T$ 下的反应速率常数；$T$ 为热力学绝对温度（单位：$\mathrm{K}$）；$R$ 为摩尔气体常数（$R = 8.3144626\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$）；$E_\mathrm{a}$ 为该反应的**表观活化能（Apparent Activation Energy）**（单位：$\mathrm{J\cdot mol^{-1}}$ 或 $\mathrm{kJ\cdot mol^{-1}}$）。

微分式深刻揭示了速率常数随温度变化的导数行为：在正常化学反应中，$E_\mathrm{a} > 0$，因此 $\frac{\mathrm{d}\ln k}{\mathrm{d}T} > 0$，即**温度升高，反应速率常数必单调增大**。

#### 2. 指数形式（Exponential Form）
将微分式两端分别对 $T$ 进行不定积分并取指数映射，得到指数形式：
$$k = A \exp\left( -\frac{E_\mathrm{a}}{RT} \right) = A \mathrm{e}^{-E_\mathrm{a}/(RT)}$$
式中：
其中，参数 $A$ 称为**指前因子（Pre-exponential Factor）**或**频率因子（Frequency Factor）**，其物理量纲与该反应的速率常数 $k$ 的量纲完全相同；指数项 $\mathrm{e}^{-E_\mathrm{a}/(RT)}$ 称为**麦克斯韦-玻尔兹曼能量因子（Boltzmann Factor）**，在统计物理与碰撞理论中，该因子直接表征在温度 $T$ 的平衡热库中，体系内能量超过阈值活化能 $E_\mathrm{a}$ 的“活化分子”占体系分子总数的概率分数。

#### 3. 对数线性形式与定积分形式（Integrated Form）
对指数式两边取自然对数，即得到用于动力学实验数据线性化处理的对数方程：
$$\ln k = -\frac{E_\mathrm{a}}{R} \cdot \frac{1}{T} + \ln A$$
若采用以 10 为底的常用对数表示，则为：
$$\lg k = -\frac{E_\mathrm{a}}{2.3026 R} \cdot \frac{1}{T} + \lg A$$

在温度变化范围不太大（如 $\Delta T \le 50\ \mathrm{K}$）的常规实验区间内，$E_\mathrm{a}$ 和 $A$ 通常可近似视为与温度无关的常数。此时在两个不同温度 $T_1$ 和 $T_2$ 之间进行定积分，得到定积分解析式：
$$\ln\left(\frac{k_2}{k_1}\right) = -\frac{E_\mathrm{a}}{R} \left( \frac{1}{T_2} - \frac{1}{T_1} \right) = \frac{E_\mathrm{a}}{R} \left( \frac{T_2 - T_1}{T_1 T_2} \right)$$
常用对数工作方程形式为：
$$\lg\left(\frac{k_2}{k_1}\right) = \frac{E_\mathrm{a}}{2.3026 R} \left( \frac{T_2 - T_1}{T_1 T_2} \right)$$
利用该定积分公式，已知某一温度下的速率常数 $k_1$ 与活化能 $E_\mathrm{a}$，即可精确推算任意指定温度 $T_2$ 下的理论反应速率常数 $k_2$。

---

### 4.2 阿伦尼乌斯活化能的现代微分定义与物理图像

阿伦尼乌斯最初将活化能视为“普通分子转变为能够发生反应的活化分子所需的最低能量”。在现代物理化学中，为了消除唯象模型对微观机理假设的依赖，IUPAC 给出阿伦尼乌斯活化能的严格微分定义：
$$E_\mathrm{a} \equiv RT^2 \frac{\mathrm{d}\ln k}{\mathrm{d}T} = -R \frac{\mathrm{d}\ln k}{\mathrm{d}(1/T)}$$

该定义的优越性在于：
1. **不依赖于活化能是否恒定**：无论 $\ln k$ 对 $1/T$ 是否为严格直线，在任何指定温度 $T$ 下，实验曲线上切线的局域斜率乘上 $-R$，即为该温度下的阿伦尼乌斯活化能；
2. **连接唯象动力学与微观动力学理论**：在后续碰撞理论与过渡态理论中，可以通过统计力学严格求出微观势能面与能级配分函数随温度的导数，进而与实验测得的阿伦尼乌斯活化能建立直接映射。

### 4.4 温度对反应速率影响的四大核心动力学规律

根据阿伦尼乌斯微分式与指数式，可总结出支配化学反应温敏行为的四大普遍规律：

1. **活化能 $E_\mathrm{a}$ 决定反应对温度变化的敏感度**：
   $$\frac{\mathrm{d}\ln k}{\mathrm{d}T} = \frac{E_\mathrm{a}}{RT^2}$$
   在相同绝对温度 $T$ 下，活化能 $E_\mathrm{a}$ 越大的反应，$\frac{\mathrm{d}\ln k}{\mathrm{d}T}$ 越大。这意味着**活化能越大的反应，其反应速率对温度的变化越敏感**。升高相同温度，难反应的高活化能过程其速率倍增效应远比易反应的低活化能过程剧烈。
2. **反应温度区间决定升温加速的相对效能**：
   微分式分母中含有 $T^2$ 项。当 $E_\mathrm{a}$ 恒定时，温度 $T$ 越高，$\frac{\mathrm{d}\ln k}{\mathrm{d}T}$ 反而越小。因此，**在低温区升高相同温差 $\Delta T$，反应速率常数的相对增量比在高温区升高相同温差要显著得多**。
3. **范特霍夫近似经验规则及其适用界限**：
   范特霍夫曾总结出经验法则：在常温室温附近（$300\ \mathrm{K}$ 左右），温度每升高 $10\ ^\circ\mathrm{C}$，一般化学反应的速率大约增加 $2 \sim 4$ 倍，该比值称为**温度系数（Temperature Coefficient）**：
   $$\gamma = \frac{k_{T + 10\ \mathrm{K}}}{k_T} \approx 2 \sim 4$$
   根据定积分式计算，在 $T_1 = 300\ \mathrm{K}$ 至 $T_2 = 310\ \mathrm{K}$ 区间，若 $\gamma = 2$，对应活化能 $E_\mathrm{a} \approx 53\ \mathrm{kJ\cdot mol^{-1}}$；若 $\gamma = 4$，对应活化能 $E_\mathrm{a} \approx 105\ \mathrm{kJ\cdot mol^{-1}}$。可见该经验法则仅在常规活化能（$50 \sim 100\ \mathrm{kJ\cdot mol^{-1}}$）和常温区间成立，超出此范围切勿盲目套用。
4. **非典型温度效应（反常温敏动力学行为）**：
   自然界中并非所有反应速率都随温度升高而单调上升，存在几类经典反常动力学体系：
除了经典的正活化能热激活反应外，自然界与工业催化中还存在三大类反常行为：其一，**负活化能反应（表观活化能 $E_{\mathrm{a},\text{app}} < 0$）**，温度升高时反应速率反而降低（$\frac{\mathrm{d}k}{\mathrm{d}T} < 0$），典型案例为气相一氧化氮氧化 $2\mathrm{NO(g)} + \mathrm{O_2(g)} \rightarrow 2\mathrm{NO_2(g)}$，该反应历程由快速放热前平衡 $\mathrm{2 NO \rightleftharpoons N_2O_2}$（$\Delta_\mathrm{r}H_1 < 0$）与后续慢反应 $\mathrm{N_2O_2 + O_2 \rightarrow 2 NO_2}$（活化能 $E_{\mathrm{a},2} > 0$）构成，表观活化能 $E_{\mathrm{a},\text{app}} = \Delta_\mathrm{r}H_1 + E_{\mathrm{a},2}$，由于第一步二聚强烈放热（$\Delta_\mathrm{r}H_1$ 负值极大且绝对值超过 $E_{\mathrm{a},2}$），导致 $E_{\mathrm{a},\text{app}} < 0$；其二，**酶催化反应的钟形曲线**，在温和温度范围内分子热碰撞加剧使速率随温度上升，但超过某一最适温度（$T_\mathrm{opt} \approx 37 \sim 45\ ^\circ\mathrm{C}$）后酶蛋白高级空间构象发生热变性不可逆失活，使有效催化中心急剧丧失，表现为“钟形（Bell-shaped）”驼峰动力学轨迹；其三，**链式分支爆炸反应**，在特定临界温度与压力边界上支链产生速率瞬时超越链终止速率，导致反应速率呈几何级数爆炸式跃迁。

## §5 基元反应与反应速率理论初步

阿伦尼乌斯定律从宏观唯象角度成功定量刻画了反应速率对温度的依赖关系，但无法解释指前因子 $A$ 与活化能 $E_\mathrm{a}$ 的微观微观起源。为了从分子结构与微观运动本质阐明化学反应机理，物理化学发展出简单碰撞理论（Simple Collision Theory, SCT）与过渡态理论（Transition State Theory, TST）。

### 5.1 基元反应与反应分子数

在微观反应机理研究中，化学反应按历程复杂度被严格划分为**基元反应（Elementary Reaction）**与**非基元反应（复合反应，Composite Reaction）**：

#### 1. 基元反应的定义
反应物微观粒子（分子、原子、自由基或离子）在**一次微观碰撞或简单振动事件**中，直接完成反应物旧化学键的协同断裂与产物新化学键的协同形成，过程中不经过任何可分离检测的稳态中间体，该单一反应步骤称为基元反应。

#### 2. 反应分子数（Molecularity of Reaction）
在基元反应中，同时发生有效碰撞相互作用并导致化学变化的微观反应物粒子数目，称为该基元反应的**反应分子数**。
**单分子反应（Monomolecular Reaction, $m=1$）**：单个反应物分子通过内态激发发生异构化或单向解离，如高能环丙烷异构化为丙烯：
  $$\mathrm{cyclo\text{-}C_3H_6 \rightarrow CH_3CH=CH_2}$$
**双分子反应（Bimolecular Reaction, $m=2$）**：两个粒子发生相互二体碰撞完成反应，这是化学反应中最普遍的形式，如：
  $$\mathrm{NO_2(g) + CO(g) \rightarrow NO(g) + CO_2(g)}$$
**三分子反应（Termolecular Reaction, $m=3$）**：三个粒子在极其微小的时间间隔（约 $10^{-13}\ \mathrm{s}$ 碰撞持续期）内同时碰撞发生反应。由于三个自由微观粒子在空间同一点同时相撞的微观概率极低，自然界中三分子基元反应极其罕见，仅见于少量自由基或原子的三体复合反应，如：
  $$\mathrm{2 I\cdot(g) + Ar(g) \rightarrow I_2(g) + Ar(g)}$$
必须强调的是，自然界中**不存在四分子及更高分子数的基元反应**，且反应分子数在微观定义上**必为正整数（1, 2, 3）**，绝不可能为零、负数或分数。

#### 3. 质量作用定律（Law of Mass Action）的适用边界
质量作用定律的现代科学表述为：**基元反应的反应速率与各反应物浓度的其化学计量数次方的乘积成正比**。
对任意基元反应：$a \mathrm{A} + b \mathrm{B} \rightarrow \text{产物}$，其反应分子数 $m = a + b$，其微分速率方程必严格遵循：
$$v = k [\mathrm{A}]^a [\mathrm{B}]^b$$
**关键判据界限**：质量作用定律**仅且仅对基元反应成立**。对于宏观总反应（复合反应），绝不可根据化学计量方程式随意照抄其浓度乘积；其总速率方程的分级数必须由微观机理的稳态推导或宏观实验测定决定。

### 5.2 简单碰撞理论（Simple Collision Theory, SCT）

简单碰撞理论由路易斯（W. C. McC. Lewis）和特劳茨（M. Trautz）在1916—1918年基于气体分子运动论提出，是动力学史上首个定量微观模型。

#### 1. 理论核心假定
1. **硬球质点模型**：将气相反应物分子视为没有内部复杂空间构象、没有内部振动/转动自由度的刚性无弹性硬球；
2. **碰撞前提假定**：反应物分子之间必须发生空间物理接触（碰撞）才可能发生化学反应；
3. **有效碰撞假定**：并非每一次碰撞都能反应。只有当碰撞粒子沿质心连线方向的相对平动动能超过某一临界能量阈值 $E_\mathrm{c}$ 时，分子外层价电子云才能克服斥力势垒引发反应，此类碰撞称为**有效碰撞**；
4. **麦克斯韦-玻尔兹曼能量分布**：气相分子各自由度的能量分布严格服从经典统计平衡分布。

#### 2. 速率常数公式与参数微观诠释
根据气体分子运动论，两同类或异类硬球分子 $\mathrm{A}$ 与 $\mathrm{B}$ 的二体空间碰撞频率为：
$$Z_\mathrm{AB} = \pi (r_\mathrm{A} + r_\mathrm{B})^2 \left( \frac{8 k_\mathrm{B} T}{\pi \mu} \right)^{1/2} [\mathrm{A}][\mathrm{B}]$$
式中：
在简单碰撞理论中：$\sigma_\mathrm{AB} = \pi (r_\mathrm{A} + r_\mathrm{B})^2$ 称为**碰撞截面（Collision Cross Section）**；$\mu = \frac{m_\mathrm{A} m_\mathrm{B}}{m_\mathrm{A} + m_\mathrm{B}}$ 为双分子折合质量（Reduced Mass）；$k_\mathrm{B} = 1.380649 \times 10^{-23}\ \mathrm{J\cdot K^{-1}}$ 为玻尔兹曼常数。

引入空间方位限制修正因子——**空间位阻因子（方位因子/概率因子，Steric Factor）** $P$ 后，双分子反应的碰撞理论速率常数为：
$$k = P \cdot Z_\mathrm{AB},0 \cdot \exp\left( -\frac{E_\mathrm{c}}{RT} \right)$$
式中：
其中，$Z_{\mathrm{AB},0} = L \sigma_\mathrm{AB} \left( \frac{8 k_\mathrm{B} T}{\pi \mu} \right)^{1/2}$ 为单位浓度下的碰撞频率常数（$L$ 为阿伏伽德罗常数）；空间立体因子 $P$ 则反映反应物必须以满足特定空间相对几何方位的构型碰撞，活性官能团方可有效接触。对于复杂大分子反应，$P$ 通常远小于 1（在 $10^{-1} \sim 10^{-6}$ 之间）；但对于某些电子转移型碱金属反应（如 $\mathrm{K + Br_2}$ 通过长程库仑引力“鱼叉机制”反应），有效反应截面远大于几何截面，$P$ 可显著大于 1（达 $2 \sim 5$）。

#### 3. 碰撞理论对阿伦尼乌斯参数的微观阐明
将碰撞理论公式对温度求导可得活化能对应关系：
$$E_\mathrm{a} = E_\mathrm{c} + \frac{1}{2} RT$$
指前因子对应关系为：
$$A = P Z_\mathrm{AB},0 \mathrm{e}^{1/2}$$
由于在常温下 $\frac{1}{2} RT \approx 1.25\ \mathrm{kJ\cdot mol^{-1}}$，远小于化学键断裂所需的临界能 $E_\mathrm{c}$，因此实验阿伦尼乌斯活化能与微观碰撞临界能基本相当。

#### 4. 碰撞理论的主要局限
碰撞理论最大缺陷在于将分子过度简化为无内部结构的“台球硬球”，完全忽略了分子的化学键骨架振动、转动及电子激发能级，且模型无法独立从理论第一性预测空间因子 $P$ 的精确数值，必须依赖经验拟合。

### 5.3 过渡态理论（Transition State Theory, TST）

为了突破碰撞理论的局限，艾林（Henry Eyring）、波兰尼（Michael Polanyi）与威格纳（Eugene Wigner）在1935年基于量子力学与统计热力学创立了**过渡态理论（TST）**（亦称**活化络合物理论，ACT**）。

#### 1. 势能面（PES）、反应坐标与鞍点构型
过渡态理论的核心基石是**玻恩-奥本海默近似下的多维分子势能面（Potential Energy Surface, PES）**：
势能面的几何拓扑特征揭示了反应动态学的直观图像：其一，势能面上能量最低的谷底代表稳定的分子几何构型（反应物谷与产物谷）；其二，反应物从反应物谷越过能量屏障转化为产物的路径中，能量最低的连续空间轨迹称为**最小能量路径（MEP, Minimum Energy Path）**；其三，沿着最小能量路径的弧长变量称为**反应坐标（Reaction Coordinate）**；其四，在反应坐标轨迹上，势能最高处所对应的微观几何构型位于多维超曲面的**马鞍形转折点（鞍点，Saddle Point）**。鞍点的微观动力学特征极其独特：**在沿着反应坐标的一维运动方向上势能为极大值，而在与反应坐标正交的所有其他空间振动自由度方向上势能均为极小值**。

处于鞍点位置的临界微观组合体分子被称为**活化络合物（Activated Complex）**，记作 $\mathrm{X}^\ddagger$；该临界动态状态称为**过渡态（Transition State）**。

#### 2. 过渡态理论三大基本假设与 Eyring 方程推导
过渡态理论基于以下三大科学假设展开严格推导：
1. **拟热力学平衡假设**：处于鞍点的活化络合物 $\mathrm{X}^\ddagger$ 与反应物基态分子之间，始终维持着快速微观热力学平衡：
   $$\mathrm{A + B \rightleftharpoons X^\ddagger \rightarrow \text{产物}}$$
   平衡常数记为 $K^\ddagger$；
2. **一维全平动分解假设**：活化络合物沿着反应坐标方向的弱束缚键伸缩振动，已不再属于束缚态振动，而是完全转化为跨越鞍点的一维自由平动。该分解为产物的单向物理运动频率满足统计力学普适常数：
   $$\nu = \frac{k_\mathrm{B} T}{h}$$
   （$h = 6.62607015 \times 10^{-34}\ \mathrm{J\cdot s}$ 为普朗克常数）；
3. **透射系数假设**：跨过鞍点到达产物侧的络合物不会发生量子反射折返，全部不可逆转化为产物分子（透射系数 $\kappa \approx 1$）。

由上述假设，总反应速率由鞍点络合物浓度与其分解频率的乘积决定：
$$v = \kappa \nu [\mathrm{X}^\ddagger] = \frac{k_\mathrm{B} T}{h} [\mathrm{X}^\ddagger]$$
根据准平衡关系，络合物浓度为 $[\mathrm{X}^\ddagger] = K_c^\ddagger [\mathrm{A}][\mathrm{B}]$。代入后即可导出著名的**微观 Eyring 方程**：
$$k = \frac{k_\mathrm{B} T}{h} K_c^\ddagger$$

#### 3. 热力学形式的 Eyring 方程与活化参数
利用化学热力学等温方程，将活化平衡常数转换为活化吉布斯自由能变 $\Delta^\ddagger G_\mathrm{m}^\ominus$：
$$K^\ddagger = \exp\left( -\frac{\Delta^\ddagger G_\mathrm{m}^\ominus}{RT} \right) = \exp\left( \frac{\Delta^\ddagger S_\mathrm{m}^\ominus}{R} \right) \exp\left( -\frac{\Delta^\ddagger H_\mathrm{m}^\ominus}{RT} \right)$$
引入标准浓度参考态 $(c^\ominus)^{1-n}$（$n$ 为反应级数），导出**热力学 Eyring 速率常数公式**：
$$k = \frac{k_\mathrm{B} T}{h} (c^\ominus)^{1-n} \exp\left( \frac{\Delta^\ddagger S_\mathrm{m}^\ominus}{R} \right) \exp\left( -\frac{\Delta^\ddagger H_\mathrm{m}^\ominus}{RT} \right)$$
式中：
在热力学表象中：$\Delta^\ddagger G_\mathrm{m}^\ominus$ 称为**标准摩尔活化吉布斯自由能（Activation Free Energy）**；$\Delta^\ddagger H_\mathrm{m}^\ominus$ 称为**标准摩尔活化焓（Activation Enthalpy）**；$\Delta^\ddagger S_\mathrm{m}^\ominus$ 称为**标准摩尔活化熵（Activation Entropy）**。

#### 4. 阿伦尼乌斯活化能 $E_\mathrm{a}$ 与过渡态活化参数的严格定量转换
根据 IUPAC 活化能微分定义式 $E_\mathrm{a} = RT^2 \frac{\mathrm{d}\ln k}{\mathrm{d}T}$，对 Eyring 方程两边求微商，可严格建立宏观活化能与微观活化参数之间的定量对应映射：
**对于气相基元反应**：活化分子数变化量定义为 $\Delta n^\ddagger = 1 - \sum_{\text{反应物}} \nu_i$，通式满足：
$$E_\mathrm{a} = \Delta^\ddagger H_\mathrm{m}^\ominus + (1 - \Delta n^\ddagger) RT$$
具体分流情况为：其一，气相单分子基元反应（$n=1,\ \Delta n^\ddagger = 0$）满足 $E_\mathrm{a} = \Delta^\ddagger H_\mathrm{m}^\ominus + RT$；其二，气相双分子基元反应（$n=2,\ \Delta n^\ddagger = -1$）满足 $E_\mathrm{a} = \Delta^\ddagger H_\mathrm{m}^\ominus + 2 RT$；其三，气相三分子基元反应（$n=3,\ \Delta n^\ddagger = -2$）满足 $E_\mathrm{a} = \Delta^\ddagger H_\mathrm{m}^\ominus + 3 RT$。

**对于溶液相凝聚态基元反应**：在溶液中体系体积功极小（$p\Delta V^\ddagger \approx 0$），活化摩尔体积变化对温度微商的贡献可忽略不计，严格统一满足：
$$E_\mathrm{a} = \Delta^\ddagger H_\mathrm{m}^\ominus + RT$$

#### 5. 指前因子与活化熵的微观化学解析
将上述关系代回 Eyring 公式，阿伦尼乌斯指前因子 $A$ 与活化熵 $\Delta^\ddagger S_\mathrm{m}^\ominus$ 的直接函数关系为（以气相双分子反应为例）：
$$A = \mathrm{e}^2 \frac{k_\mathrm{B} T}{h c^\ominus} \exp\left( \frac{\Delta^\ddagger S_\mathrm{m}^\ominus}{R} \right)$$

该式赋予了指前因子极深刻的微观立体结构与熵效应涵义：
1. **缔合型过渡态（$\Delta^\ddagger S_\mathrm{m}^\ominus < 0$）**：若基元反应由两个独立的游离反应物分子紧密结合形成具有高度空间取向限制的环状或刚性过渡态，分子的平动和转动自由度大幅转化为低振幅振动，微观态数减少导致体系活化熵为显著负值（$\Delta^\ddagger S_\mathrm{m}^\ominus \ll 0$）。因此 $\exp(\Delta^\ddagger S_\mathrm{m}^\ominus / R) \ll 1$，指前因子 $A$ 呈现极低数值（$A \ll 10^{11}\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$），这与简单碰撞理论中空间位阻因子 $P \ll 1$ 的物理图像完全吻合；
2. **解离型过渡态（$\Delta^\ddagger S_\mathrm{m}^\ominus > 0$）**：若反应经历某些单分子断裂或溶剂化去溶剂化解脱，过渡态分子结构变得极其松弛开放，键伸展振动频率降低，转动自由度增加，活化熵为正值（$\Delta^\ddagger S_\mathrm{m}^\ominus > 0$），导致指前因子显著升高（$A > 10^{14}\ \mathrm{s^{-1}}$）。

## §6 典型复合反应动力学与机理近似处理

自然界与化学工程中绝大多数化学反应并非单步完成的基元反应，而是由若干基元步骤相互交织构成的**复合反应（Complex Reaction）**。根据基元步骤的拓扑拓扑连接构型，典型复合反应可分为对峙反应、平行反应和连续反应三大基元拓扑类型。

### 6.1 三大典型复合反应动力学特征

#### 1. 对峙反应（可逆反应，Reversible Reaction）
在同一反应条件下，正向反应与逆向反应同时显著进行的反应体系：
$$\mathrm{A} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \mathrm{B}$$
**微观可逆性原理（Principle of Microscopic Reversibility）**：在宏观化学平衡时，任何基元步骤的正向反应速率必精确等于其逆向反应速率：
  $$v_+ = k_1 [\mathrm{A}]_\mathrm{eq} = v_- = k_{-1} [\mathrm{B}]_\mathrm{eq}$$
  由此导出动力学速率常数比值与热力学平衡常数的严格联系：
  $$K_c = \frac{[\mathrm{B}]_\mathrm{eq}}{[\mathrm{A}]_\mathrm{eq}} = \frac{k_1}{k_{-1}}$$
**弛豫动力学与松弛法（Relaxation Method）**：若对处于平衡状态的反应体系施加极其微小的瞬时物理跃迁（如温度跃迁 T-jump、压力跃迁 P-jump），使体系偏离原平衡浓度微小量 $\Delta x$。体系自发向新平衡状态恢复的动力学过程服从一阶指数衰减：
  $$\Delta x(t) = \Delta x_0 \exp\left( -\frac{t}{\tau} \right)$$
  其中 $\tau$ 称为**弛豫时间（Relaxation Time）**。对于对峙反应 $\mathrm{A \rightleftharpoons B}$，其弛豫时间解析式为：
  $$\tau = \frac{1}{k_1 + k_{-1}}$$
  弛豫法巧妙地将极快速化学反应的测定转化为测量体系物理量随时间的指数衰减时间常数，是测定飞秒至微秒级超快基元反应速率常数的利器。

#### 2. 平行反应（竞争反应，Parallel / Competitive Reaction）
相同反应物在同一体系中同时发生两条或两条以上不同路径的反应：
$$\begin{array}{l} \mathrm{A} \xrightarrow{k_1} \mathrm{B} \quad (\text{主反应}) \\ \mathrm{A} \xrightarrow{k_2} \mathrm{C} \quad (\text{副反应}) \end{array}$$
**产物分布与选择性比率**：若两条平行反应具有相同的反应级数（如均为一级）：
  $$\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = k_1 [\mathrm{A}], \quad \frac{\mathrm{d}[\mathrm{C}]}{\mathrm{d}t} = k_2 [\mathrm{A}]$$
  两式相除积分得到产物浓度分布守恒：
  $$\frac{[\mathrm{B}]_t}{[\mathrm{C}]_t} = \frac{k_1}{k_2}$$
  无论反应进行到何种深度，**产物的摩尔比始终等于各自分支的速率常数之比**。
**动力学控制与热力学控制（Kinetic vs Thermodynamic Control）**：若产物 $\mathrm{B}$ 活化能较低（$E_{\mathrm{a},1} < E_{\mathrm{a},2}$），低温或短时间反应时 $k_1 \gg k_2$，体系快速生成 $\mathrm{B}$，反应受**动力学控制**；若产物 $\mathrm{C}$ 处于更低的吉布斯自由能谷底（更稳定），而在高温或延长反应时间条件下逆反应被激活，体系通过动态平衡逐渐转化为热力学最稳定的产物 $\mathrm{C}$，反应受**热力学控制**。

#### 3. 连续反应（连串反应，Consecutive Reaction）
反应经过中间体分步递进进行：
$$\mathrm{A} \xrightarrow{k_1} \mathrm{B} \xrightarrow{k_2} \mathrm{C}$$
**微分演化方程组**：
  $$\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = -k_1 [\mathrm{A}]$$
  $$\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = k_1 [\mathrm{A}] - k_2 [\mathrm{B}]$$
  $$\frac{\mathrm{d}[\mathrm{C}]}{\mathrm{d}t} = k_2 [\mathrm{B}]$$
**中间体浓度的极大值与最佳出料时间**：
  联立求解微分方程组（初始条件 $[\mathrm{A}]_0 = c_0,\ [\mathrm{B}]_0 = [\mathrm{C}]_0 = 0$）：
  $$[\mathrm{B}]_t = \frac{k_1 c_0}{k_2 - k_1} \left( \mathrm{e}^{-k_1 t} - \mathrm{e}^{-k_2 t} \right)$$
  求导置零 $\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = 0$，导出目标中间产物 $\mathrm{B}$ 达到最高理论浓度的**最佳反应时间 $t_{\max}$**：
  $$t_{\max} = \frac{\ln(k_1 / k_2)}{k_1 - k_2}$$
  中间体 $\mathrm{B}$ 的极大值浓度为：
  $$[\mathrm{B}]_{\max} = c_0 \left( \frac{k_2}{k_1} \right)^{\frac{k_2}{k_1 - k_2}}$$

### 6.2 处理复杂反应机理的三大近代近似方法

对于多步复杂反应体系，微观微分动力学方程组往往高度非线性且难以求得解析通解，物理化学常用三大机理近似理论：

#### 1. 决速步近似（Rate-Determining Step Approximation, RDS）
若复合反应机理中某一基元步骤的活化能显著高于其他所有步骤（该步速率常数极其微小），该步骤在整个反应网络中成为限速“瓶颈”，该步骤即为**速率控制步骤（决速步）**。总反应速率近似等于决速步的反应速率：
$$v_{\text{总}} \approx v_{\text{RDS}}$$

#### 2. 平衡假设法（Pre-equilibrium Approximation, PEA）
若在决速步之前存在一个快速建立对峙平衡的可逆步骤，且该快平衡的正逆反应速率远大于后续慢步骤的消耗速率，则可假定该快平衡在反应全程中始终处于准热力学平衡状态：
$$\mathrm{A + B} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \mathrm{AB^*} \quad (\text{快平衡，} K_c = k_1 / k_{-1})$$
$$\mathrm{AB^* + C} \xrightarrow{k_2} \mathrm{P} \quad (\text{慢决速步})$$
由平衡假设：$[\mathrm{AB^*}] = K_c [\mathrm{A}][\mathrm{B}]$，代入决速步速率：
$$v = k_2 [\mathrm{AB^*}][\mathrm{C}] = k_2 K_c [\mathrm{A}][\mathrm{B}][\mathrm{C}] = \frac{k_1 k_2}{k_{-1}} [\mathrm{A}][\mathrm{B}][\mathrm{C}]$$

#### 3. 稳态近似（Steady-State Approximation, SSA）
由鲍登斯坦（Max Bodenstein）于1913年提出。在反应历程中，某些高活性的不稳定中间体（如自由基、配位不饱和物、激发态离子）能量极高、反应活性极大，其在体系中的瞬时绝对浓度极低；当反应越过极短暂的诱导期后，活泼中间体的生成速率与消耗速率达到动态准稳态，其中间体浓度随时间的变化率可近似置为零：
$$\frac{\mathrm{d}[\mathrm{中间体}]}{\mathrm{d}t} \approx 0$$
稳态近似将繁琐的常微分方程组转化为简捷的代数方程，是求解链式反应与多步催化机理的通用数学工具。

## §7 催化作用动力学机制

催化作用是现代化学化工与生命科学过程的核心基石。催化剂通过介入反应历程，开辟一条具有更低活化能的新反应通道，使反应速率获得成千上万倍的剧烈提升。

### 7.1 催化剂的基本物理化学特征

1. **改变反应历程，显著降低活化能**：催化剂通过与反应物分子形成不稳定的中间过渡物种，将原本单步高能垒跨越分解为若干低能垒基元步骤，从而大幅削减活化自由能势垒 $\Delta^\ddagger G^\ominus$；
2. **同等程度加速正逆反应，绝不改变热力学化学平衡**：由微观可逆性原理，催化剂改变的是正逆反应共同的活化状态，正逆反应活化能降低的数值严格相等：
   $$\Delta E_\mathrm{a},+ = \Delta E_\mathrm{a},-$$
   因此平衡常数 $K_c = \frac{k_+}{k_-}$ 保持严格不变。**催化剂绝不能使原本热力学不可能进行（$\Delta_\mathrm{r}G_\mathrm{m}^\ominus > 0$）的反应自发发生，也不能改变终态化学平衡组成，它仅缩短达到化学平衡所需的物理时间**；
3. **自身在反应循环终态恢复原状**：催化剂参与反应循环的中间步骤，但在净总反应中既不净消耗也不净生成；
4. **具有高度的选择性与专一性**：在多路径平行竞争反应体系中，特异性催化剂能够针对性极大地加速目标产物路径，使产物分布产生决定性倾斜。

### 7.2 酶催化动力学与米氏方程（Michaelis-Menten Kinetics）

酶（Enzyme, $\mathrm{E}$）是生物体内最高效、最专一的生物大分子催化剂。1913年，德国化学家米夏埃利斯（L. Michaelis）与加拿大医师门滕（M. L. Menten）建立了经典的酶促动力学模型：

#### 1. 酶促反应基元机理模型
底物（Substrate, $\mathrm{S}$）与游离酶分子可逆结合为酶-底物络合物（$\mathrm{ES}$），络合物再单向催化水解或分解生成产物 $\mathrm{P}$ 并再生游离酶：
$$\mathrm{E + S} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \mathrm{ES} \xrightarrow{k_2} \mathrm{E + P}$$

#### 2. 米氏方程的稳态近似推导
体系中酶的总浓度守恒式为：$[\mathrm{E}]_0 = [\mathrm{E}] + [\mathrm{ES}]$。
产物生成速率由催化步骤决定：
$$v = \frac{\mathrm{d}[\mathrm{P}]}{\mathrm{d}t} = k_2 [\mathrm{ES}]$$
对中间活性络合物 $\mathrm{ES}$ 应用稳态近似：
$$\frac{\mathrm{d}[\mathrm{ES}]}{\mathrm{d}t} = k_1 [\mathrm{E}][\mathrm{S}] - k_{-1} [\mathrm{ES}] - k_2 [\mathrm{ES}] = 0$$
将游离酶浓度 $[\mathrm{E}] = [\mathrm{E}]_0 - [\mathrm{ES}]$ 代入：
$$k_1 ([\mathrm{E}]_0 - [\mathrm{ES}]) [\mathrm{S}] - (k_{-1} + k_2) [\mathrm{ES}] = 0$$
$$k_1 [\mathrm{E}]_0 [\mathrm{S}] = [k_1 [\mathrm{S}] + (k_{-1} + k_2)] [\mathrm{ES}]$$
定义**米氏常数（Michaelis Constant）** $K_\mathrm{m}$：
$$K_\mathrm{m} \equiv \frac{k_{-1} + k_2}{k_1}$$
则络合物浓度为：
$$[\mathrm{ES}] = \frac{[\mathrm{E}]_0 [\mathrm{S}]}{K_\mathrm{m} + [\mathrm{S}]}$$
代入速率式，并定义**最大理论反应速率** $V_{\max} \equiv k_2 [\mathrm{E}]_0$（$k_2$ 亦称催化转换数 $k_{\text{cat}}$），导出著名的**米氏方程（Michaelis-Menten Equation）**：
$$v = \frac{V_{\max} [\mathrm{S}]}{K_\mathrm{m} + [\mathrm{S}]}$$

#### 3. 米氏动力学的极限渐近行为
**底物浓度极低区间（$[\mathrm{S}] \ll K_\mathrm{m}$）**：
  分母中的 $[\mathrm{S}]$ 可忽略不计：
  $$v \approx \frac{V_{\max}}{K_\mathrm{m}} [\mathrm{S}] = \frac{k_{\text{cat}}}{K_\mathrm{m}} [\mathrm{E}]_0 [\mathrm{S}]$$
  反应对底物呈现**典型的一级反应动力学**。其中比值 $\frac{k_{\text{cat}}}{K_\mathrm{m}}$ 称为酶的**特异性常数（Catalytic Efficiency）**，是衡量酶对特定底物催化效能与亲和力的终极判据；
**底物浓度极高饱和区间（$[\mathrm{S}] \gg K_\mathrm{m}$）**：
  分母中的 $K_\mathrm{m}$ 可忽略不计：
  $$v \approx \frac{V_{\max} [\mathrm{S}]}{[\mathrm{S}]} = V_{\max} = k_2 [\mathrm{E}]_0$$
  此时体系内全部酶分子的活性中心均被底物分子紧密占据饱和（$[\mathrm{ES}] \approx [\mathrm{E}]_0$），反应速率达到理论极限峰值，对底物浓度呈现**典型的零级反应动力学**。

#### 4. 林-贝双倒数作图法（Lineweaver-Burk Plot）
对米氏方程两边取倒数，实现完全线性化：
$$\frac{1}{v} = \frac{K_\mathrm{m} + [\mathrm{S}]}{V_{\max} [\mathrm{S}]} = \frac{K_\mathrm{m}}{V_{\max}} \cdot \frac{1}{[\mathrm{S}]} + \frac{1}{V_{\max}}$$
以 $\frac{1}{v}$ 对 $\frac{1}{[\mathrm{S}]}$ 作图：
在双倒数线性图中：直线斜率（Slope）等于 $\frac{K_\mathrm{m}}{V_{\max}}$；纵截距（Y-intercept）等于 $\frac{1}{V_{\max}}$；横截距（X-intercept）等于 $-\frac{1}{K_\mathrm{m}}$。
