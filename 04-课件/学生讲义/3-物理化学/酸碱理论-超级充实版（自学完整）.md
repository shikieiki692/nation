## §1 酸碱理论演进与化学本质

酸碱概念是定量化学反应与化学平衡体系的核心基石之一。随着人类对微观物质结构认知与化学键理论的深入，酸碱理论经历了从宏观现象归纳到微观电子结构本质的深刻演进。

### 1.1 Arrhenius 水离子理论及其历史局限

1887年，阿伦尼乌斯（S. Arrhenius）提出电离理论，首次将酸碱性质与水溶液中的特定离子联系起来：
在 Arrhenius 电离理论体系中，酸被定义为在水溶液中发生电离且产生的阳离子全部为氢离子（$\mathrm{H^+}$，实质以水合氢离子 $\mathrm{H_3O^+}$ 存在）的化合物，例如 $\mathrm{HCl}$、$\mathrm{HNO_3}$ 与 $\mathrm{CH_3COOH}$ 等；碱则被定义为在水溶液中发生电离且产生的阴离子全部为氢氧根离子（$\mathrm{OH^-}$）的化合物，例如 $\mathrm{NaOH}$ 与 $\mathrm{Ba(OH)_2}$ 等。在此框架下，酸与碱的中和反应本质被单一归结为水合质子与氢氧根离子结合生成水分子并伴随恒定摩尔反应热的基元过程：
$$\mathrm{H^+(aq) + OH^-(aq) \to H_2O(l)}, \quad \Delta_r H_{\mathrm{m}}^\theta = -55.84\ \mathrm{kJ\cdot mol^{-1}}$$

**局限性分析**：

Arrhenius 理论对于稀水溶液中的典型强酸强碱反应具有简明直观的描述力，但在面对无机化学与现代配位化学时暴露了明显的不可逾越的局限性：

1. **介质受限**：将酸碱行为严格限制在“水溶液”中，无法解释非水溶剂（如液氨、纯硫酸、液态二氧化硫、冰醋酸）中的酸碱现象；

2. **气相反应缺失**：无法解释无水介质或气相反应中的酸碱行为。例如气态氯化氢与气态氨相遇瞬间生成白色氯化铵固体微粒：
$$\mathrm{NH_3(g) + HCl(g) \to NH_4Cl(s)}$$
该反应中不存在水分子参与，更无游离的 $\mathrm{OH^-}$，但反应产物具备典型的盐类特征；

3. **碱的定义过窄**：Arrhenius 碱必须在分子组成上含有可离解的 $\mathrm{OH}$ 基团，无法解释本身不含 $\mathrm{OH}$ 基团但水溶液呈明显碱性的物质（如氨水 $\mathrm{NH_3}$、碳酸钠 $\mathrm{Na_2CO_3}$、醋酸钠 $\mathrm{CH_3COONa}$、磷酸三钠 $\mathrm{Na_3PO_4}$）。

### 1.2 Brønsted-Lowry 质子理论与共轭酸碱对

1923年，丹麦化学家布朗斯特（J. N. Brønsted）与英国化学家劳里（T. M. Lowry）各自独立提出了质子传递酸碱理论（Brønsted-Lowry Acid-Base Theory）：
Brønsted-Lowry 理论从微观质子转移视角统一重塑了酸与碱的本质：凡是具有给出质子（$\mathrm{H^+}$）倾向或能力的分子或离子，统称为质子酸（即质子供体，Proton Donor）；凡是具有接受质子倾向或能力的分子或离子，统称为质子碱（即质子受体，Proton Acceptor）。

#### 1.2.1 共轭酸碱对（Conjugate Acid-Base Pair）
当一个质子酸 $\mathrm{HA}$ 释放出一个质子后，剩余的部分 $\mathrm{A^-}$ 必然具备结合质子的潜能，因而转变为相应的质子碱；反之，一个质子碱 $\mathrm{B}$ 结合一个质子后，形成的物种 $\mathrm{HB^+}$ 即具备重新给出质子的潜能，转变为相应的质子酸。这种仅相差一个质子（$\mathrm{H^+}$）的一对酸和碱，称为**共轭酸碱对**（Conjugate Acid-Base Pair），记作 $\mathrm{HA / A^-}$：
$$\mathrm{HA \rightleftharpoons H^+ + A^-}$$
$$\text{酸} \rightleftharpoons \text{质子} + \text{共轭碱}$$

共轭酸碱对的相对强弱遵循严格的热力学互补反比规律：酸给出质子的倾向越强（即酸常数越大、酸性越强），其共轭碱结合质子的能力就越弱（即共轭碱的碱常数越小、碱性越弱）；反之，酸给出质子的倾向越弱，其共轭碱结合质子的能力则越强。
例如，高氯酸（$\mathrm{HClO_4}$）是极强酸，其共轭碱高氯酸根（$\mathrm{ClO_4^-}$）结合质子的能力极弱，是极弱碱；而氢氰酸（$\mathrm{HCN}$，$K_a = 6.2 \times 10^{-10}$）是极弱酸，其共轭碱氰根（$\mathrm{CN^-}$）则是极强的水解型质子碱。

#### 1.2.2 两性物种（Amphiprotic Species）
在质子理论中，部分分子或离子既能给出质子充当质子酸，又能结合质子充当质子碱，此类物种称为两性物种。典型的两性物种主要包括：其一，溶剂水分子，既可给出质子生成 $\mathrm{OH^-}$，亦可结合质子生成 $\mathrm{H_3O^+}$；其二，多元弱酸的酸式酸根离子，例如碳酸氢根 $\mathrm{HCO_3^-}$（作为酸离解给出质子 $\mathrm{HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}}$，作为碱结合质子 $\mathrm{HCO_3^- + H^+ \rightleftharpoons H_2CO_3}$）、磷酸二氢根 $\mathrm{H_2PO_4^-}$ 以及氢硫根 $\mathrm{HS^-}$ 等；其三，氨基酸分子，分子内同时含有质子供体羧基 $-\mathrm{COOH}$ 与质子受体氨基 $-\mathrm{NH_2}$，常以两性偶极离子形态存在。

#### 1.2.3 质子传递反应的普适实质
质子是半径仅约为 $1.5 \times 10^{-15}\ \mathrm{m}$ 的裸核，极高的正电荷密度使其在凝聚相溶剂中绝不可能以游离孤立状态存在。因此，酸给出质子的过程必须与另一个碱结合质子的过程同时发生。酸碱反应的本质是**两个共轭酸碱对之间的质子转移平衡**：
$$\mathrm{Acid_1 + Base_2 \rightleftharpoons Base_1 + Acid_2}$$

例如：

1. 醋酸溶于水：
$$\mathrm{CH_3COOH(aq) + H_2O(l) \rightleftharpoons CH_3COO^-(aq) + H_3O^+(aq)}$$
其中共轭对为 $\mathrm{CH_3COOH / CH_3COO^-}$ 与 $\mathrm{H_3O^+ / H_2O}$。

2. 氨溶于水：
$$\mathrm{NH_3(aq) + H_2O(l) \rightleftharpoons NH_4^+(aq) + OH^-(aq)}$$
其中共轭对为 $\mathrm{NH_4^+ / NH_3}$ 与 $\mathrm{H_2O / OH^-}$。在此体系中，水分子充当了质子酸。

3. 纯酸碱气相反应：
$$\mathrm{HCl(g) + NH_3(g) \rightleftharpoons NH_4^+Cl^-(s)}$$
在此反应中，$\mathrm{HCl}$ 充当质子酸，$\mathrm{NH_3}$ 充当质子碱，完成质子转移直接生成离子晶体，脱离溶剂依赖。

### 1.3 Lewis 电子理论与配位共价键本质

为了将酸碱概念彻底推广到不含质子转移的更广泛化学反应体系，美国物理化学家吉尔伯特·路易斯（G. N. Lewis）于1923年提出了电子对受体-给体理论（Lewis Acid-Base Theory）：
Lewis 电子理论从价层电子对的授受重构了更为宽广的酸碱图景：凡是可以接受外来孤对电子以形成配位共价键的分子、原子或阳离子，统称为 Lewis 酸（即电子对受体，Electron-Pair Acceptor），Lewis 酸必须具备可供容纳外来孤对电子的未填满空轨道（如缺电子原子、低能量空轨道或多重键极化正中心）；凡是可以给出孤对电子以形成配位共价键的分子或阴离子，统称为 Lewis 碱（即电子对给体，Electron-Pair Donor），Lewis 碱必须具备至少一对未成键的价层孤对电子。酸碱反应的微观本质则是 Lewis 酸与 Lewis 碱之间通过电子对共享（配位共价键）结合生成稳定的酸碱加合物（Acid-Base Adduct）：
$$\mathrm{A + :B \rightleftharpoons A-B}$$

#### 1.3.1 Lewis 酸碱的结构分类

| 分类类型 | 结构特征 | 典型实例 |
| :--- | :--- | :--- |
| **中心缺电子分子（Lewis 酸）** | 价层未满足八隅体稳定结构，拥有空 p 轨道 | $\mathrm{BF_3}$、$\mathrm{BCl_3}$、$\mathrm{AlCl_3}$、$\mathrm{BeCl_2}$ |
| **金属阳离子（Lewis 酸）** | 具有空的价层 d、s、p 轨道，可接受配体孤对电子 | $\mathrm{Fe^{3+}}$、$\mathrm{Cu^{2+}}$、$\mathrm{Ag^+}$、$\mathrm{Zn^{2+}}$、$\mathrm{H^+}$ |
| **高价态主族分子（Lewis 酸）** | 中心原子具有空的 d 轨道，可发生配位数扩张（超价分子） | $\mathrm{SiF_4}$、$\mathrm{SnCl_4}$、$\mathrm{PF_5}$、$\mathrm{SF_4}$ |
| **极化双键/多重键分子（Lewis 酸）** | 含有不等性电负性原子构成的极化多重键，正电中心易受攻击 | $\mathrm{CO_2}$、$\mathrm{SO_3}$、$\mathrm{SO_2}$ |
| **阴离子（Lewis 碱）** | 带有净负电荷且具有未共用电子对 | $\mathrm{F^-}$、$\mathrm{Cl^-}$、$\mathrm{OH^-}$、$\mathrm{CN^-}$、$\mathrm{I^-}$ |
| **中性含孤对电子分子（Lewis 碱）** | 富含非键孤对电子的中性分子 | $\mathrm{:NH_3}$、$\mathrm{H_2\ddot{O}:}$、$\mathrm{:CO}$、$\mathrm{R_3P:}$、$\mathrm{R_2\ddot{O}:}$ |

#### 1.3.2 配位配合物作为 Lewis 加合物的统一
Lewis 理论将无机配位化学与经典酸碱理论完美统一：在经典配位反应中，金属中心阳离子（如 $\mathrm{Ag^+}$、$\mathrm{Cu^{2+}}$、$\mathrm{Co^{3+}}$）充当 Lewis 酸提供空轨道，配体分子或离子（如 $\mathrm{NH_3}$、$\mathrm{CN^-}$、$\mathrm{H_2O}$、$\mathrm{Cl^-}$）充当 Lewis 碱提供孤对电子，配离子（如 $[\mathrm{Cu(NH_3)_4}]^{2+}$）即为酸碱加合物。在非金属氧化物的水合反应中，二氧化碳溶于水水合生成碳酸：
$$\mathrm{CO_2 + H_2O \rightleftharpoons H_2CO_3}$$
$\mathrm{CO_2}$ 中碳原子受两个高电负性氧原子极化呈显著正电性，作为 Lewis 酸接受水分子的氧原子孤对电子（Lewis 碱）进攻，形成加合物并继而重排生成碳酸。

### 1.4 HSAB 软硬酸碱原理与前线轨道匹配

为了定性预测 Lewis 酸碱加合物的稳定性与反应方向，皮尔逊（R. G. Pearson）于1963年提出了**软硬酸碱原理（Hard and Soft Acids and Bases, HSAB）**：
**HSAB 核心定律**：硬酸优先与硬碱结合形成稳定加合物；软酸优先与软碱结合形成稳定加合物（Hard loves hard, soft loves soft）；硬软交错的结合相对不稳定。

#### 1.4.1 硬度与软度的本质判据
基于微观电子云的可极化性与前线轨道能级特征，Pearson 将 Lewis 酸与碱系统划分为硬、软及交界三类：
第一类，硬酸与硬碱具有半径小、电荷高（对酸而言）、氧化态高、极化率低、不易变形及电负性高（对碱而言）的物理特征。硬酸的最低未占分子轨道（LUMO）能级高，硬碱的最高占据分子轨道（HOMO）能级低，两者能级差巨大，相互作用以静电库仑引力（离子键）为主导。
第二类，软酸与软碱具有半径大、电荷低、氧化态低、外层电子云极易受极化变形及极化率高的物理特征。软酸的 LUMO 能级相对较低，软碱的 HOMO 能级相对较高，两者能级极为接近且前线轨道重叠积分大，结合以共价轨道重叠共享（共价键与反馈 $\pi$ 键）为主导。
第三类，交界酸与交界碱的理化特性介于硬与软之间（例如金属离子 $\mathrm{Fe^{2+}}$、$\mathrm{Cu^{2+}}$、$\mathrm{Zn^{2+}}$ 以及阴离子 $\mathrm{Br^-}$、$\mathrm{NO_2^-}$ 等）。

#### 1.4.2 HSAB 典型物种分类矩阵

| 分类 | Lewis 酸（电子受体） | Lewis 碱（电子给体） |
| :--- | :--- | :--- |
| **硬（Hard）** | $\mathrm{H^+}$, $\mathrm{Li^+}$, $\mathrm{Na^+}$, $\mathrm{K^+}$, $\mathrm{Mg^{2+}}$, $\mathrm{Ca^{2+}}$, $\mathrm{Al^{3+}}$, $\mathrm{Cr^{3+}}$, $\mathrm{Fe^{3+}}$, $\mathrm{Ti^{4+}}$, $\mathrm{BF_3}$, $\mathrm{CO_2}$, $\mathrm{SO_3}$ | $\mathrm{H_2O}$, $\mathrm{OH^-}$, $\mathrm{F^-}$, $\mathrm{Ac^-}$, $\mathrm{SO_4^{2-}}$, $\mathrm{NO_3^-}$, $\mathrm{CO_3^{2-}}$, $\mathrm{PO_4^{3-}}$, $\mathrm{NH_3}$, $\mathrm{ROH}$, $\mathrm{R_2O}$ |
| **交界（Borderline）** | $\mathrm{Fe^{2+}}$, $\mathrm{Co^{2+}}$, $\mathrm{Ni^{2+}}$, $\mathrm{Cu^{2+}}$, $\mathrm{Zn^{2+}}$, $\mathrm{Pb^{2+}}$, $\mathrm{Sn^{2+}}$, $\mathrm{Ru^{2+}}$, $\mathrm{SO_2}$, $\mathrm{B(OCH_3)_3}$ | $\mathrm{NO_2^-}$, $\mathrm{SO_3^{2-}}$, $\mathrm{Br^-}$, $\mathrm{N_3^-}$, 吡啶（$\mathrm{py}$）, 苯胺（$\mathrm{PhNH_2}$）, 咪唑 |
| **软（Soft）** | $\mathrm{Cu^+}$, $\mathrm{Ag^+}$, $\mathrm{Au^+}$, $\mathrm{Tl^+}$, $\mathrm{Hg_2^{2+}}$, $\mathrm{Hg^{2+}}$, $\mathrm{Cd^{2+}}$, $\mathrm{Pt^{2+}}$, $\mathrm{Pd^{2+}}$, $\mathrm{I_2}$, $\mathrm{Br_2}$, 金属原子（$\mathrm{M^0}$） | $\mathrm{I^-}$, $\mathrm{CN^-}$, $\mathrm{SCN^-}$（$\mathrm{S}$端）, $\mathrm{S_2O_3^{2-}}$, $\mathrm{H^-}$, $\mathrm{R_3P}$, $\mathrm{R_2S}$, $\mathrm{CO}$, $\mathrm{C_2H_4}$（烯烃） |

#### 1.4.3 HSAB 原理在无机地球化学与配位化学中的定量体现
1. **天然矿物分布规律（Goldschmidt 地球化学分类）**：
硬硬匹配形成强离子键晶格，软软结合形成强共价键网络。这一原理深刻支配着地质矿物的自然赋存规律：硬酸阳离子（如 $\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{Al^{3+}}$、$\mathrm{Ti^{4+}}$）在自然界中主要与硬碱（$\mathrm{O^{2-}}$、$\mathrm{CO_3^{2-}}$、$\mathrm{SiO_4^{4-}}$、$\mathrm{F^-}$）结合，以氧化物、碳酸盐、硅酸盐矿物（亲石元素）赋存；而软酸与交界酸阳离子（如 $\mathrm{Cu^+}$、$\mathrm{Ag^+}$、$\mathrm{Hg^{2+}}$、$\mathrm{Pb^{2+}}$、$\mathrm{Cd^{2+}}$）在自然界中主要与软碱（$\mathrm{S^{2-}}$）结合，以难溶硫化物矿石（黄铜矿、辉银矿、辰砂、方铅矿，亲硫元素）赋存。

2. **沉淀溶解度与配合物稳定常数对决**：
   $\mathrm{Ag^+}$ 为经典软酸，与卤素阴离子结合时：硬度大小顺序为 $\mathrm{F^-} > \mathrm{Cl^-} > \mathrm{Br^-} > \mathrm{I^-}$，软度则为 $\mathrm{I^-} > \mathrm{Br^-} > \mathrm{Cl^-} > \mathrm{F^-}$。根据软亲软原理，$\mathrm{Ag^+}$ 与 $\mathrm{I^-}$ 形成的键共价性最强、稳定性极高，溶度积常数呈现显著反向规律：
   $$K_{\mathrm{sp}}(\mathrm{AgF})\text{（易溶）} \gg K_{\mathrm{sp}}(\mathrm{AgCl}) = 1.77 \times 10^{-10} > K_{\mathrm{sp}}(\mathrm{AgBr}) = 5.35 \times 10^{-13} \gg K_{\mathrm{sp}}(\mathrm{AgI}) = 8.52 \times 10^{-17}$$
   同理，软酸 $\mathrm{Ag^+}$ 与软碱 $\mathrm{CN^-}$ 或 $\mathrm{S_2O_3^{2-}}$ 生成配离子配位稳定常数极大（$\beta_2[\mathrm{Ag(CN)_2^-}] = 1.3 \times 10^{21}$），因而能使微溶的 $\mathrm{AgCl}$ 甚至 $\mathrm{AgBr}$ 沉淀顺利溶解。

## §2 质子传递热力学与活度修正

### 2.1 水的自偶电离与离子积常数 $K_w$

水是一种弱电解质，在水溶液中水分子既可充当质子酸，又可充当质子碱，彼此发生自偶质子传递反应：
$$\mathrm{H_2O(l) + H_2O(l) \rightleftharpoons H_3O^+(aq) + OH^-(aq)}$$
简写为：
$$\mathrm{H_2O(l) \rightleftharpoons H^+(aq) + OH^-(aq)}$$

热力学平衡常数表达式为：
$$K_w^\theta = \frac{a(\mathrm{H^+}) a(\mathrm{OH^-})}{a(\mathrm{H_2O})}$$
在稀水溶液中，纯溶剂的活度取标准态纯态值 $a(\mathrm{H_2O}) \approx 1$。引入**水的离子积常数（Ion-Product Constant of Water, $K_w$）**：
$$K_w = a(\mathrm{H^+}) a(\mathrm{OH^-}) \approx [\mathrm{H^+}][\mathrm{OH^-}]$$

水的自偶电离反应为吸热反应（$\Delta_{\mathrm{sol}} H_{\mathrm{m}}^\theta = +55.84\ \mathrm{kJ\cdot mol^{-1}}$）。根据 van 't Hoff 方程：
$$\frac{\mathrm{d}\ln K_w}{\mathrm{d}T} = \frac{\Delta_r H_{\mathrm{m}}^\theta}{RT^2} > 0$$
表明温度升高时，水的电离平衡向正反应方向移动，$K_w$ 单调递增：
由于水分子自偶电离为显著的吸热过程（$\Delta_{\mathrm{w}} H_{\mathrm{m}}^\theta = +55.84\ \mathrm{kJ\cdot mol^{-1}}$），根据范特霍夫方程，升温将强烈驱动电离平衡向正向移动，$K_w$ 随温度升高呈现出跨数量级的跃升：在 $0\ ^\circ\mathrm{C}$ 下，$K_w = 1.14 \times 10^{-15}$，中性纯水的氢离子浓度为 $[\mathrm{H^+}] = 3.38 \times 10^{-8}\ \mathrm{mol\cdot L^{-1}}$（对应中性点 $\mathrm{pH} = 7.47$）；在 $25\ ^\circ\mathrm{C}$ 常温下，$K_w = 1.008 \times 10^{-14} \approx 1.00 \times 10^{-14}$（对应中性点 $\mathrm{pH} = 7.00$）；而在 $100\ ^\circ\mathrm{C}$ 沸水工况下，$K_w$ 骤增至 $5.45 \times 10^{-13}$，中性点对应 $\mathrm{pH} = 6.13$。这有力警示选手：水溶液呈中性的物理化学真谛是 $[\mathrm{H^+}] = [\mathrm{OH^-}]$，而绝非机械死记 $\mathrm{pH} = 7$。

必须特别强调：**溶液中性与否的唯一热力学物理判据为 $a(\mathrm{H^+}) = a(\mathrm{OH^-})$（或 $[\mathrm{H^+}] = [\mathrm{OH^-}]$），绝非机械地等同于 $\mathrm{pH} = 7.00$**。在 $100\ ^\circ\mathrm{C}$ 的沸水中，$\mathrm{pH} = 6.13$ 即为纯净中性状态。

### 2.2 共轭酸碱对离解常数的热力学关联

考虑弱酸 $\mathrm{HA}$ 在水溶液中的质子传递平衡：
$$\mathrm{HA(aq) + H_2O(l) \rightleftharpoons H_3O^+(aq) + A^-(aq)}, \quad K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]}$$
其共轭碱 $\mathrm{A^-}$ 在水中的结合质子平衡（水解平衡）：
$$\mathrm{A^-(aq) + H_2O(l) \rightleftharpoons HA(aq) + OH^-(aq)}, \quad K_b = \frac{[\mathrm{HA}][\mathrm{OH^-}]}{[\mathrm{A^-}]}$$
两化学反应式直接相加：
$$\begin{aligned}
\mathrm{HA(aq) + H_2O(l)} &\rightleftharpoons \mathrm{H^+(aq) + A^-(aq)} \\
+\quad \mathrm{A^-(aq) + H_2O(l)} &\rightleftharpoons \mathrm{HA(aq) + OH^-(aq)} \\
\hline
\mathrm{H_2O(l)} &\rightleftharpoons \mathrm{H^+(aq) + OH^-(aq)}
\end{aligned}$$
根据多重平衡多反应相加规则，总反应平衡常数等于分步平衡常数之乘积：
$$K = K_a \cdot K_b = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]} \cdot \frac{[\mathrm{HA}][\mathrm{OH^-}]}{[\mathrm{A^-}]} = [\mathrm{H^+}][\mathrm{OH^-}] = K_w$$
两边取负对数：
$$\mathrm{p}K_a + \mathrm{p}K_b = \mathrm{p}K_w$$
在 $25\ ^\circ\mathrm{C}$ 水溶液中，恒有：
$$K_a \cdot K_b = 1.00 \times 10^{-14}, \qquad \mathrm{p}K_a + \mathrm{p}K_b = 14.00$$

对于多元弱酸体系（如二元弱酸 $\mathrm{H_2A}$），其分步电离与共轭碱分步结合质子之间存在严格的交叉共轭对应关系：

1. 一级电离常数 $K_{a1}$ 对应于二级水解结合质子常数 $K_{b2}$：
$$\mathrm{H_2A \rightleftharpoons H^+ + HA^-}, \quad K_{a1}$$
$$\mathrm{HA^- + H_2O \rightleftharpoons H_2A + OH^-}, \quad K_{b2} = \frac{K_w}{K_{a1}}$$
2. 二级电离常数 $K_{a2}$ 对应于一级水解结合质子常数 $K_{b1}$：
$$\mathrm{HA^- \rightleftharpoons H^+ + A^{2-}}, \quad K_{a2}$$
$$\mathrm{A^{2-} + H_2O \rightleftharpoons HA^- + OH^-}, \quad K_{b1} = \frac{K_w}{K_{a2}}$$
即满足通式：
$$K_{a, i} \cdot K_{b, n-i+1} = K_w, \qquad \mathrm{p}K_{a, i} + \mathrm{p}K_{b, n-i+1} = \mathrm{p}K_w$$

### 2.3 离子强度与 Debye-Hückel 活度修正

在真实电解质水溶液中，离子间存在长程静电库仑相互作用。每个离子都被异号电荷构成的“离子氛”包围，限制了离子的自由平动热力学有效浓度。因此，热力学严密平衡应使用活度 $a$ 代替摩尔浓度 $c$：
$$a_i = \gamma_i \cdot \frac{c_i}{c^\theta}$$
式中 $\gamma_i$ 为物种 $i$ 的活度系数，$c^\theta = 1\ \mathrm{mol\cdot L^{-1}}$ 为热力学标准态浓度。

#### 2.3.1 离子强度（Ionic Strength, $I$）
刘易斯（G. N. Lewis）提出用离子强度定量表征溶液中离子环境的静电场强弱：
$$I = \frac{1}{2} \sum_{i} c_i z_i^2$$
式中 $c_i$ 为离子 $i$ 的摩尔浓度，$z_i$ 为该离子的带电荷数。

#### 2.3.2 德拜-休克尔极限公式（Debye-Hückel Limiting Law）
德拜与休克尔（P. Debye & E. Hückel）基于稀溶液静电场分布统计模型，导出了 $25\ ^\circ\mathrm{C}$ 水溶液中离子单离子活度系数计算式：

1. **极限公式（适用于稀溶液 $I < 0.01\ \mathrm{mol\cdot L^{-1}}$）**：
$$\lg \gamma_i = -0.509 \cdot z_i^2 \sqrt{I}$$
2. **扩展公式（适用于中等浓度溶液 $I \le 0.1\ \mathrm{mol\cdot L^{-1}}$）**：
$$\lg \gamma_i = -\frac{0.509 \cdot z_i^2 \sqrt{I}}{1 + B a_0 \sqrt{I}} \approx -\frac{0.509 \cdot z_i^2 \sqrt{I}}{1 + \sqrt{I}}$$
式中 $a_0$ 为离子有效水合半径参数。

#### 2.3.3 盐效应对弱酸电离平衡的影响
向弱酸溶液中引入不含共有离子的惰性强电解质（如 $\mathrm{KNO_3}$、$\mathrm{NaCl}$）时，溶液离子强度 $I$ 显著增加，导致 $\mathrm{H^+}$ 与 $\mathrm{A^-}$ 的活度系数 $\gamma_{\mathrm{H^+}}$ 与 $\gamma_{\mathrm{A^-}}$ 减小（$\gamma < 1$）。由于真实热力学常数 $K_a^\theta$ 保持恒定：
$$K_a^\theta = \frac{a(\mathrm{H^+}) a(\mathrm{A^-})}{a(\mathrm{HA})} = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]} \cdot \frac{\gamma_{\mathrm{H^+}} \gamma_{\mathrm{A^-}}}{\gamma_{\mathrm{HA}}} = K_a^c \cdot \frac{\gamma_{\mathrm{H^+}} \gamma_{\mathrm{A^-}}}{\gamma_{\mathrm{HA}}}$$
中性分子 $\mathrm{HA}$ 的活度系数在稀溶液中近似为 1（$\gamma_{\mathrm{HA}} \approx 1$）。因此浓度平衡常数 $K_a^c$ 满足：
$$K_a^c = \frac{K_a^\theta}{\gamma_{\mathrm{H^+}} \gamma_{\mathrm{A^-}}} > K_a^\theta$$
这表明：**加入惰性强电解质会导致弱电解质的浓度离解常数表观增大，离解度略微升高**，此即为酸碱平衡中的**盐效应（Salt Effect）**。

## §3 平衡体系三大守恒方程与精确状态描述

在定量分析化学中，处理任何复杂的酸碱平衡体系时，均需依据物理化学基本定律建立联立代数方程组。三大守恒方程构成了构建精确数学模型的完备物理基础。

### 3.1 物料守恒（Mass Balance Equation, MBE）

物料平衡方程基于**原子守恒定律**：在封闭化学体系中，某一特定组分加入溶液后，不论其在溶液中发生何种电离、水解、互变或配位转化，该组分在各存在形态中的摩尔浓度（乘以对应物料计量化学系数）之总和，必须严格等于该组分的原始分析分析总浓度 $c_{\mathrm{total}}$。

**典型书写实例**：

1. **$c\ \mathrm{mol\cdot L^{-1}}$ 的一元弱酸 $\mathrm{HAc}$ 溶液**：
醋酸根原子骨架保持守恒：
$$c = [\mathrm{HAc}] + [\mathrm{Ac^-}]$$
2. **$c\ \mathrm{mol\cdot L^{-1}}$ 的二元弱酸 $\mathrm{H_2A}$ 溶液**：
$\mathrm{A}$ 物种的所有电离形态总和等于总分析浓度：
$$c = [\mathrm{H_2A}] + [\mathrm{HA^-}] + [\mathrm{A^{2-}}]$$
3. **$c\ \mathrm{mol\cdot L^{-1}}$ 的碳酸氢钠 $\mathrm{NaHCO_3}$ 溶液**：
钠离子不参与质子平衡，与碳酸化合物物种总量保持 1:1 计量比：
$$[\mathrm{Na^+}] = c = [\mathrm{H_2CO_3}] + [\mathrm{HCO_3^-}] + [\mathrm{CO_3^{2-}}]$$
4. **$c\ \mathrm{mol\cdot L^{-1}}$ 的磷酸氢二铵 $(\mathrm{NH_4)_2HPO_4}$ 溶液**：
体系中铵根与磷酸根的原子计量比为 2:1：
$$[\mathrm{NH_4^+}] + [\mathrm{NH_3}] = 2 \left( [\mathrm{H_3PO_4}] + [\mathrm{H_2PO_4^-}] + [\mathrm{HPO_4^{2-}}] + [\mathrm{PO_4^{3-}}] \right)$$

### 3.2 电荷守恒（Charge Balance Equation, CBE）

电荷平衡方程基于**宏观溶液电中性原理（Electroneutrality Principle）**：任何宏观电解质溶液必须保持绝对电中性，即溶液中所有阳离子所带的正电荷摩尔浓度总和，必须恒等于所有阴离子所带的负电荷摩尔浓度总和。
通用数学表达式为：
$$\sum_{j} z_j [M_j^{z_j+}] = \sum_{k} |z_k| [A_k^{|z_k|-}]$$
注意：离子的摩尔浓度前面必须乘以该离子的带电荷数绝对值。

**典型书写实例**：

1. **水溶液体系的天然电中性基准**：
水溶液中恒存在质子 $\mathrm{H^+}$ 与氢氧根 $\mathrm{OH^-}$。

2. **$c\ \mathrm{mol\cdot L^{-1}}$ 的 $\mathrm{Na_2CO_3}$ 溶液**：
正电荷仅由 $\mathrm{Na^+}$ 与 $\mathrm{H^+}$ 提供；负电荷由 $\mathrm{OH^-}$、$\mathrm{HCO_3^-}$ 及二价的 $\mathrm{CO_3^{2-}}$ 提供：
$$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HCO_3^-}] + 2[\mathrm{CO_3^{2-}}]$$
3. **$c\ \mathrm{mol\cdot L^{-1}}$ 的磷酸 $\mathrm{H_3PO_4}$ 溶液**：
$$[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{H_2PO_4^-}] + 2[\mathrm{HPO_4^{2-}}] + 3[\mathrm{PO_4^{3-}}]$$

### 3.3 质子守恒与质子条件式（Proton Balance Equation, PBE）

质子平衡方程（质子条件式）基于**质子转移守恒定律**：在质子传递酸碱平衡建立过程中，体系中一部分物种给出质子的摩尔总数，必须恒等于另一部分物种接受质子的摩尔总数。

#### 3.3.1 零水准法（Reference Level Method）书写步骤
1. **选取零水准（Zero Level / Reference Level）**：
选取参与反应前溶液中大量存在、并且在质子转移过程中充当起始物质的稳定物种。通常为：溶剂水分子（$\mathrm{H_2O}$）以及加入溶液的原生酸碱质点（溶质分子或原始离子）。

2. **列出得失质子产物**：
建立质子条件式遵循质子守恒法则：零水准物种接受质子后生成的产物称为“得质子产物”，统一列于方程一侧；零水准物种释放质子后生成的产物称为“失质子产物”，统一列于方程另一侧；若单个基元物种发生多级得失质子转移，对应物种的浓度项前必须乘以相应的得失质子化学计量数。

3. **写出 PBE 表达式**：
$$\sum (\text{得质子数} \times [\text{得质子产物}]) = \sum (\text{失质子数} \times [\text{失质子产物}])$$

#### 3.3.2 典型体系 PBE 的推导与检验

| 溶液体系 | 零水准物种（Reference Level） | 得质子产物 | 失质子产物 | 质子条件式（PBE） |
| :--- | :--- | :--- | :--- | :--- |
| **纯水（$\mathrm{H_2O}$）** | $\mathrm{H_2O}$ | $\mathrm{H^+}$ | $\mathrm{OH^-}$ | $[\mathrm{H^+}] = [\mathrm{OH^-}]$ |
| **一元弱酸（$\mathrm{HAc}$）** | $\mathrm{H_2O}$, $\mathrm{HAc}$ | $\mathrm{H^+}$ | $\mathrm{OH^-}$, $\mathrm{Ac^-}$ | $[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{Ac^-}]$ |
| **一元弱碱（$\mathrm{NH_3}$）** | $\mathrm{H_2O}$, $\mathrm{NH_3}$ | $\mathrm{H^+}$, $\mathrm{NH_4^+}$ | $\mathrm{OH^-}$ | $[\mathrm{H^+}] + [\mathrm{NH_4^+}] = [\mathrm{OH^-}]$ |
| **二元弱酸（$\mathrm{H_2A}$）** | $\mathrm{H_2O}$, $\mathrm{H_2A}$ | $\mathrm{H^+}$ | $\mathrm{OH^-}$, $\mathrm{HA^-}$, $\mathrm{A^{2-}}$ | $[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HA^-}] + 2[\mathrm{A^{2-}}]$ |
| **两性酸式盐（$\mathrm{NaHA}$）** | $\mathrm{H_2O}$, $\mathrm{HA^-}$（$\mathrm{Na^+}$不参与） | $\mathrm{H^+}$, $\mathrm{H_2A}$ | $\mathrm{OH^-}$, $\mathrm{A^{2-}}$ | $[\mathrm{H^+}] + [\mathrm{H_2A}] = [\mathrm{OH^-}] + [\mathrm{A^{2-}}]$ |
| **弱酸弱碱盐（$\mathrm{NH_4Ac}$）** | $\mathrm{H_2O}$, $\mathrm{NH_4^+}$, $\mathrm{Ac^-}$ | $\mathrm{H^+}$, $\mathrm{HAc}$ | $\mathrm{OH^-}$, $\mathrm{NH_3}$ | $[\mathrm{H^+}] + [\mathrm{HAc}] = [\mathrm{OH^-}] + [\mathrm{NH_3}]$ |

**代数联立验证**：

PBE 亦可直接由 MBE 与 CBE 联立线性消去惰性外加离子（如 $\mathrm{Na^+}$）严格导出。
以 $\mathrm{NaHA}$ 为例：
将物料守恒式 $[\mathrm{Na^+}] = c = [\mathrm{H_2A}] + [\mathrm{HA^-}] + [\mathrm{A^{2-}}]$ 与电荷守恒式 $[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HA^-}] + 2[\mathrm{A^{2-}}]$ 联立相减消去惰性外加离子 $[\mathrm{Na^+}]$, 立即导出质子条件式：
$$([\mathrm{H_2A}] + [\mathrm{HA^-}] + [\mathrm{A^{2-}}]) + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HA^-}] + 2[\mathrm{A^{2-}}]$$
化简两边同类项即得：
$$[\mathrm{H^+}] + [\mathrm{H_2A}] = [\mathrm{OH^-}] + [\mathrm{A^{2-}}]$$
结果与零水准直观法完全一致，证明了质子条件的严密自洽性。

## §4 酸碱型体分布分数（$\delta$）与形态分析

在酸碱溶液中，溶质往往以多种不同的质子化或去质子化型体（Species）共存。型体分布分数（Distribution Fraction, 记作 $\delta$ 或 $\alpha$）用于定量表征平衡体系中某一特定存在形态的平衡摩尔浓度占该组分总分析浓度的百分比。通过分析分布分数随溶液 $\mathrm{pH}$ 的函数关系，可以清晰阐明各型体的优势赋存区间与形态演化规律。

### 4.1 一元弱酸的分布分数

设一元弱酸 $\mathrm{HA}$ 的分析总浓度为 $c$。体系中存在的酸碱形态仅有未离解的分子形态 $\mathrm{HA}$ 与完全离解的共轭碱阴离子形态 $\mathrm{A^-}$。
根据物料平衡（MBE）：
$$c = [\mathrm{HA}] + [\mathrm{A^-}]$$
根据电离平衡常数定义：
$$K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]} \implies [\mathrm{A^-}] = \frac{K_a [\mathrm{HA}]}{[\mathrm{H^+}]}$$
代入物料平衡式：
$$c = [\mathrm{HA}] + \frac{K_a [\mathrm{HA}]}{[\mathrm{H^+}]} = [\mathrm{HA}] \left( 1 + \frac{K_a}{[\mathrm{H^+}]} \right) = [\mathrm{HA}] \cdot \frac{[\mathrm{H^+}] + K_a}{[\mathrm{H^+}]}$$

由此解出分子形态的分布分数 $\delta_0$（或记为 $\delta_{\mathrm{HA}}$）：
$$\delta_0 = \frac{[\mathrm{HA}]}{c} = \frac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a}$$
解出共轭碱阴离子形态的分布分数 $\delta_1$（或记为 $\delta_{\mathrm{A^-}}$）：
$$\delta_1 = \frac{[\mathrm{A^-}]}{c} = \frac{K_a}{[\mathrm{H^+}] + K_a}$$
显然，归一化条件恒成立：
$$\delta_0 + \delta_1 = 1$$

**分布分数特征分析**：

1. **$\mathrm{pH}$ 独立性与浓度无关性**：分布分数 $\delta_0$ 和 $\delta_1$ 仅取决于溶液中氢离子浓度 $[\mathrm{H^+}]$（即 $\mathrm{pH}$）与电离常数 $K_a$，与酸的分析总浓度 $c$ 彻底无关；

2. **特征交叉点**：当 $[\mathrm{H^+}] = K_a$（即 $\mathrm{pH} = \mathrm{p}K_a$）时，$\delta_0 = \delta_1 = 0.50$（即 50%）。此时分子形态与酸根离子形态浓度严格相等；

3. **优势区域判据**：
在极限酸度条件下：当溶液处于强酸性区 $\mathrm{pH} < \mathrm{p}K_a - 1$（即 $[\mathrm{H^+}] > 10 K_a$）时，分布分数 $\delta_0 > 0.91$，未离解分子 $\mathrm{HA}$ 占据绝对压倒性优势；反之，当溶液处于碱性区 $\mathrm{pH} > \mathrm{p}K_a + 1$（即 $[\mathrm{H^+}] < 0.1 K_a$）时，分布分数 $\delta_1 > 0.91$，共轭碱离子 $\mathrm{A^-}$ 占据绝对压倒性优势。

### 4.2 二元弱酸的分布分数与形态图

对于二元弱酸 $\mathrm{H_2A}$（总分析浓度为 $c$），溶液中存在三种共存型体：$\mathrm{H_2A}$、$\mathrm{HA^-}$ 与 $\mathrm{A^{2-}}$。
各级电离常数定义为：
$$K_{a1} = \frac{[\mathrm{H^+}][\mathrm{HA^-}]}{[\mathrm{H_2A}]}, \qquad K_{a2} = \frac{[\mathrm{H^+}][\mathrm{A^{2-}}]}{[\mathrm{HA^-}]}$$
物料平衡关系式为：
$$c = [\mathrm{H_2A}] + [\mathrm{HA^-}] + [\mathrm{A^{2-}}]$$
将各离子浓度统一用自由质子浓度 $[\mathrm{H^+}]$ 与未电离分子浓度 $[\mathrm{H_2A}]$ 线性表达：
$$[\mathrm{HA^-}] = \frac{K_{a1}}{[\mathrm{H^+}]} [\mathrm{H_2A}]$$
$$[\mathrm{A^{2-}}] = \frac{K_{a2}}{[\mathrm{H^+}]} [\mathrm{HA^-}] = \frac{K_{a1} K_{a2}}{[\mathrm{H^+}]^2} [\mathrm{H_2A}]$$
代入物料平衡方程：
$$c = [\mathrm{H_2A}] \left( 1 + \frac{K_{a1}}{[\mathrm{H^+}]} + \frac{K_{a1} K_{a2}}{[\mathrm{H^+}]^2} \right) = [\mathrm{H_2A}] \cdot \frac{[\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1} K_{a2}}{[\mathrm{H^+}]^2}$$

令多项式分母为：
$$D = [\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1} K_{a2}$$
由此导出各型体分布分数的严密数学解析表达式：
$$\delta_0 = \frac{[\mathrm{H_2A}]}{c} = \frac{[\mathrm{H^+}]^2}{D} = \frac{[\mathrm{H^+}]^2}{[\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1} K_{a2}}$$
$$\delta_1 = \frac{[\mathrm{HA^-}]}{c} = \frac{K_{a1}[\mathrm{H^+}]}{D} = \frac{K_{a1}[\mathrm{H^+}]}{[\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1} K_{a2}}$$
$$\delta_2 = \frac{[\mathrm{A^{2-}}]}{c} = \frac{K_{a1} K_{a2}}{D} = \frac{K_{a1} K_{a2}}{[\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1} K_{a2}}$$
满足归一化法则：
$$\delta_0 + \delta_1 + \delta_2 = 1$$

> 图 8-2：二元弱酸各型体分布分数 δ 随 pH 的变化，两个交点分别对应 pKa₁ 与 pKa₂

#### 4.2.1 曲线特征与三大特征交叉点解析
二元弱酸分布曲线呈现三个具有特殊物理化学含义的关键系统特征点：

1. **第一交叉点（$\delta_0 = \delta_1$）**：
   $$\frac{[\mathrm{H^+}]^2}{D} = \frac{K_{a1}[\mathrm{H^+}]}{D} \implies [\mathrm{H^+}] = K_{a1} \implies \mathrm{pH} = \mathrm{p}K_{a1}$$
   在此酸度下，未离解分子 $\mathrm{H_2A}$ 与一级电离产物 $\mathrm{HA^-}$ 浓度完全相等；若两级电离常数差距足够大（$K_{a1} \gg K_{a2}$，如 $\mathrm{p}K_{a2} - \mathrm{p}K_{a1} \ge 3$），此时 $\mathrm{A^{2-}}$ 型体含量几乎为零，有 $\delta_0 = \delta_1 \approx 0.50$。

2. **第二交叉点（$\delta_1 = \delta_2$）**：
   $$\frac{K_{a1}[\mathrm{H^+}]}{D} = \frac{K_{a1} K_{a2}}{D} \implies [\mathrm{H^+}] = K_{a2} \implies \mathrm{pH} = \mathrm{p}K_{a2}$$
   在此酸度下，酸式阴离子 $\mathrm{HA^-}$ 与二级完全电离产物 $\mathrm{A^{2-}}$ 浓度完全相等，通常有 $\delta_1 = \delta_2 \approx 0.50$。

3. **中间两性形态 $\mathrm{HA^-}$ 的最大极值点（$\delta_{1, \max}$）**：
   对 $\delta_1$ 关于自由质子浓度求一阶导数并令其等于零：
   $$\frac{\mathrm{d}\delta_1}{\mathrm{d}[\mathrm{H^+}]} = 0 \implies \frac{\mathrm{d}}{\mathrm{d}[\mathrm{H^+}]} \left( \frac{K_{a1}}{[\mathrm{H^+}] + K_{a1} + \frac{K_{a1} K_{a2}}{[\mathrm{H^+}]}} \right) = 0$$
   令分母导数等于零，即：
   $$1 - \frac{K_{a1} K_{a2}}{[\mathrm{H^+}]^2} = 0 \implies [\mathrm{H^+}]_{\max} = \sqrt{K_{a1} K_{a2}}$$
   两边取负对数：
   $$\mathrm{pH}_{\max} = \frac{\mathrm{p}K_{a1} + \mathrm{p}K_{a2}}{2}$$
   将此极值质子浓度代入 $\delta_1$ 表达式，得到中间酸式酸根能达到的理论最大分布极限：
   $$\delta_{1, \max} = \frac{K_{a1} \sqrt{K_{a1} K_{a2}}}{K_{a1} K_{a2} + K_{a1} \sqrt{K_{a1} K_{a2}} + K_{a1} K_{a2}} = \frac{1}{1 + 2\sqrt{\frac{K_{a2}}{K_{a1}}}}$$
   当 $K_{a1} / K_{a2} \ge 10^4$（即两级常数差达 4 个 $\mathrm{p}K$ 单位以上，如碳酸、草酸、马来酸等常见体系）时，$\sqrt{K_{a2} / K_{a1}} \le 0.01$，$\delta_{1, \max} \ge 0.98$。表明在两个 $\mathrm{p}K_a$ 的算术平均点附近，体系中几乎 100% 的溶质均转化收敛为单一的中间型体 $\mathrm{HA^-}$。

4. **极端次级交叉点（$\delta_0 = \delta_2$）**：
   $$[\mathrm{H^+}]^2 = K_{a1} K_{a2} \implies [\mathrm{H^+}] = \sqrt{K_{a1} K_{a2}}$$
   在此对称中心点处，处于两端的分子形态 $\mathrm{H_2A}$ 与二价阴离子形态 $\mathrm{A^{2-}}$ 浓度严格相等，各自处于其极低浓度的交点位置。

## §5 常见酸碱溶液 $\mathrm{pH}$ 精确与近似计算模型

在实际科研与化竞计算中，根据质子条件建立的精确方程往往是关于 $[\mathrm{H^+}]$ 的高次代数多项式。掌握从精确方程出发、基于物理化学边界条件实施合理工程近似的判据，是高效求解酸碱平衡的核心能力。

### 5.1 一元弱酸与一元弱碱的计算模型

以浓度为 $c\ \mathrm{mol\cdot L^{-1}}$ 的一元弱酸 $\mathrm{HA}$ 为例，电离常数为 $K_a$。
体系质子条件（PBE）为：
$$[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{A^-}]$$
代入水离子积常数与分布分数：
$$[\mathrm{H^+}] = \frac{K_w}{[\mathrm{H^+}]} + \frac{c K_a}{[\mathrm{H^+}] + K_a}$$
整理得到关于 $[\mathrm{H^+}]$ 的精确一元三次代数方程：
$$[\mathrm{H^+}]^3 + K_a [\mathrm{H^+}]^2 - (c K_a + K_w) [\mathrm{H^+}] - K_a K_w = 0$$

#### 5.1.1 忽略水自偶电离（一阶近似）
在绝大多数实际弱酸体系中，弱酸电离产生的 $[\mathrm{H^+}]$ 远大于水自偶电离产生的质子贡献（即体系显酸性，$[\mathrm{OH^-}] \ll [\mathrm{A^-}]$）。
第一，水自偶电离忽略判据：若弱酸的初始浓度与酸常数乘积满足 $c K_a \ge 20 K_w = 2.0 \times 10^{-13}$，则水自身离解贡献所引起的计算相对误差严格小于 5%，可在电荷或质子平衡中安全忽略水离解产生的 $[\mathrm{OH^-}]$ 项。
此时方程简化为：
$$[\mathrm{H^+}] \approx [\mathrm{A^-}] = \frac{c K_a}{[\mathrm{H^+}] + K_a}$$
整理得到**精确一元二次方程**：
$$[\mathrm{H^+}]^2 + K_a [\mathrm{H^+}] - c K_a = 0$$
解二次方程求根公式取物理合理正根：
$$[\mathrm{H^+}] = \frac{-K_a + \sqrt{K_a^2 + 4 c K_a}}{2}$$

#### 5.1.2 忽略酸的自身离解消耗（极简近似）
当弱酸电离程度极微弱时，平衡时未离解分子的平衡浓度几乎等于原始分析浓度，即 $[\mathrm{HA}] = c - [\mathrm{H^+}] \approx c$。
第二，酸自身离解消耗忽略判据（5% 判据 / 20 倍准则）：若弱酸的解离度 $\alpha = [\mathrm{H^+}]/c \le 0.05$（即 5%），则忽略分子离解消耗带来的相对误差不超过 2.5%。由极简式 $\alpha \approx \sqrt{K_a / c} \le 0.05$ 平方可得经典工程近似判据：
  $$\frac{c}{K_a} \ge 400 \sim 500$$
在此条件下，$[\mathrm{H^+}] + K_a \approx [\mathrm{H^+}]$，代入展开直接得到**极简计算公式**：
$$[\mathrm{H^+}] \approx \sqrt{c K_a}, \qquad \mathrm{pH} \approx \frac{1}{2}(\mathrm{p}K_a - \lg c)$$

同理，对于浓度为 $c$ 的一元弱碱（离解常数为 $K_b$），在满足 $c K_b \ge 20 K_w$ 且 $c / K_b \ge 500$ 条件下，直接有：
$$[\mathrm{OH^-}] \approx \sqrt{c K_b}, \qquad \mathrm{pOH} \approx \frac{1}{2}(\mathrm{p}K_b - \lg c), \qquad \mathrm{pH} = 14.00 - \mathrm{pOH}$$

**例1（一元弱酸电离与近似检验）**：在 $25\ ^\circ\mathrm{C}$ 下，分别计算：
(a) $0.10\ \mathrm{mol\cdot L^{-1}}$ 乙酸（$\mathrm{HAc}$，$K_a = 1.75 \times 10^{-5}$）溶液的 $\mathrm{pH}$ 与电离度 $\alpha$；
(b) $0.10\ \mathrm{mol\cdot L^{-1}}$ 氢氟酸（$\mathrm{HF}$，$K_a = 6.6 \times 10^{-4}$）溶液的 $\mathrm{pH}$ 与电离度 $\alpha$。并定量论证近似条件的适用性。

**解**：
(a) 对 $0.10\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HAc}$：

1. 检验忽略水的自偶电离条件：
   $$c K_a = 0.10 \times (1.75 \times 10^{-5}) = 1.75 \times 10^{-6} \gg 20 K_w = 2.0 \times 10^{-13}$$
   完全可忽略 $[\mathrm{OH^-}]$。

2. 检验极简近似条件：
   $$\frac{c}{K_a} = \frac{0.10}{1.75 \times 10^{-5}} \approx 5714 \gg 500$$
   满足极简近似条件，采用极简公式计算：
   $$[\mathrm{H^+}] \approx \sqrt{c K_a} = \sqrt{0.10 \times 1.75 \times 10^{-5}} = \sqrt{1.75 \times 10^{-6}} \approx 1.32 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pH} = -\lg(1.32 \times 10^{-3}) = 2.88$$

3. 计算电离度：
   $$\alpha = \frac{[\mathrm{H^+}]}{c} = \frac{1.32 \times 10^{-3}}{0.10} = 1.32\% < 5\%$$
   近似严密成立。

(b) 对 $0.10\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HF}$：

1. 检验忽略水的自偶电离条件：
   $$c K_a = 0.10 \times (6.6 \times 10^{-4}) = 6.6 \times 10^{-5} \gg 20 K_w$$
   可忽略水的电离。

2. 检验极简近似条件：
   $$\frac{c}{K_a} = \frac{0.10}{6.6 \times 10^{-4}} \approx 152 < 500$$
   比值显著小于 500，表明若采用极简公式将引入较大系统偏差（$\alpha > 5\%$），必须采用精确一元二次方程求解：
   $$[\mathrm{H^+}]^2 + K_a [\mathrm{H^+}] - c K_a = 0$$
   代入数值：
   $$[\mathrm{H^+}]^2 + 6.6 \times 10^{-4} [\mathrm{H^+}] - 6.6 \times 10^{-5} = 0$$
   解此一元二次方程：
   $$[\mathrm{H^+}] = \frac{-6.6 \times 10^{-4} + \sqrt{(6.6 \times 10^{-4})^2 + 4 \times 6.6 \times 10^{-5}}}{2} = \frac{-6.6 \times 10^{-4} + \sqrt{4.356 \times 10^{-7} + 2.64 \times 10^{-4}}}{2}$$
   $$\sqrt{2.644 \times 10^{-4}} \approx 1.626 \times 10^{-2}$$
   $$[\mathrm{H^+}] = \frac{1.626 \times 10^{-2} - 6.6 \times 10^{-4}}{2} \approx 7.80 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pH} = -\lg(7.80 \times 10^{-3}) = 2.11$$

3. 计算电离度：
   $$\alpha = \frac{7.80 \times 10^{-3}}{0.10} = 7.80\% > 5\%$$
   若误用极简公式计算，得到 $[\mathrm{H^+}]_{\text{粗}} = \sqrt{0.10 \times 6.6 \times 10^{-4}} = 8.12 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}}$（$\mathrm{pH} = 2.09$），相对误差高达 $+4.1\%$。此例充分证明了在化竞中严格执行 $c/K_a \ge 500$ 边界判据的必要性。

### 5.2 多元弱酸体系的近似处理准则

以典型的二元弱酸 $\mathrm{H_2A}$（总浓度 $c$）为例，其电离常数分别为 $K_{a1}$ 与 $K_{a2}$。
质子条件式为：
$$[\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{HA^-}] + 2[\mathrm{A^{2-}}]$$

#### 5.2.1 二级电离忽略判据
对于大多数常见多元酸（如碳酸 $\mathrm{H_2CO_3}$、硫化氢 $\mathrm{H_2S}$、亚硫酸 $\mathrm{H_2SO_3}$、草酸 $\mathrm{H_2C_2O_4}$），两级电离常数满足：
$$\frac{K_{a1}}{K_{a2}} \ge 10^3 \sim 10^4$$
一级电离产生的较大浓度质子对二级电离产生极强的同离子效应，将二级电离压缩至极其微弱的程度。因此，溶液中的自由质子浓度几乎 100% 由第一级电离提供：
$$[\mathrm{H^+}] \approx [\mathrm{HA^-}]$$
在此条件下，二元弱酸的氢离子浓度计算完全等价于一元弱酸的一级电离：
若满足二级离解忽略准则，且第一级电离同时满足 $c / K_{a1} \ge 500$ 与 $c K_{a1} \ge 20 K_w$，体系的氢离子浓度即可采用极简根式计算：
$$[\mathrm{H^+}] \approx \sqrt{c K_{a1}}$$

#### 5.2.2 二级酸根离子浓度的经典常数定则
在上述二级电离被深度抑制的体系中，考察二级完全电离产物 $\mathrm{A^{2-}}$ 的平衡浓度：
$$K_{a2} = \frac{[\mathrm{H^+}][\mathrm{A^{2-}}]}{[\mathrm{HA^-}]}$$
由于第一级电离占据绝对主导，$[\mathrm{H^+}] \approx [\mathrm{HA^-}]$，代入上式分子分母直接精确约分消去：
$$[\mathrm{A^{2-}}] \approx K_{a2}$$
这是一个极为深刻的结论：**在多元弱酸溶液中，只要 $K_{a1}/K_{a2} \ge 10^3$，完全脱质子形态的酸根阴离子浓度在数值上就近乎等于该酸的二级电离常数 $K_{a2}$，且在很大浓度范围内与该多元酸的初始加入浓度 $c$ 几乎无关！**

### 5.3 两性物质与酸式盐（$\mathrm{NaHA}$）的精确模型与极值化简

两性酸式盐（如 $\mathrm{NaHCO_3}$、$\mathrm{NaHS}$、$\mathrm{NaH_2PO_4}$、$\mathrm{Na_2HPO_4}$）既具有给出质子的酸性倾向，又具有结合质子的碱性倾向。建立其精确计算模型具有极高的理论与应用价值。
设 $\mathrm{NaHA}$ 的分析总浓度为 $c$。体系的质子条件式（PBE）为：
$$[\mathrm{H^+}] + [\mathrm{H_2A}] = [\mathrm{OH^-}] + [\mathrm{A^{2-}}]$$
将各平衡分量表达为自由质子浓度与酸式离子浓度 $[\mathrm{HA^-}]$ 的函数：
$$[\mathrm{H_2A}] = \frac{[\mathrm{H^+}][\mathrm{HA^-}]}{K_{a1}}, \qquad [\mathrm{A^{2-}}] = \frac{K_{a2}[\mathrm{HA^-}]}{[\mathrm{H^+}]}, \qquad [\mathrm{OH^-}] = \frac{K_w}{[\mathrm{H^+}]}$$
代入 PBE：
$$[\mathrm{H^+}] + \frac{[\mathrm{H^+}][\mathrm{HA^-}]}{K_{a1}} = \frac{K_w}{[\mathrm{H^+}]} + \frac{K_{a2}[\mathrm{HA^-}]}{[\mathrm{H^+}]}$$
两端同乘以 $[\mathrm{H^+}]$：
$$[\mathrm{H^+}]^2 \left( 1 + \frac{[\mathrm{HA^-}]}{K_{a1}} \right) = K_w + K_{a2}[\mathrm{HA^-}]$$
整理得到自由质子浓度的严格解析通式：
$$[\mathrm{H^+}] = \sqrt{\frac{K_{a1} K_{a2}[\mathrm{HA^-}] + K_{a1} K_w}{K_{a1} + [\mathrm{HA^-}]}}$$

#### 5.3.1 近似处理法则
在一般浓度下，酸式酸根自身电离与水解程度均较微弱，可进行一级物理近似：
$$[\mathrm{HA^-}] \approx c$$
代入上式得到广为应用的**酸式盐近似方程**：
$$[\mathrm{H^+}] \approx \sqrt{\frac{K_{a1} K_{a2} c + K_{a1} K_w}{c + K_{a1}}}$$

#### 5.3.2 进阶极简近似条件（双重判据）
1. **分母简化判据**：若 $c \gg K_{a1}$（工程上满足 $c / K_{a1} \ge 20$），则分母中 $c + K_{a1} \approx c$；

2. **分子简化判据**：若 $c K_{a2} \gg K_w$（工程上满足 $c K_{a2} \ge 20 K_w$），则分子中 $K_{a1} K_{a2} c + K_{a1} K_w \approx K_{a1} K_{a2} c$。
当上述两个判据同时满足时，分子分母中的浓度项 $c$ 精确相互对消，导出极其简洁的**两性物种极简公式**：
$$[\mathrm{H^+}] \approx \sqrt{K_{a1} K_{a2}}$$
两端取负对数：
$$\mathrm{pH} \approx \frac{\mathrm{p}K_{a1} + \mathrm{p}K_{a2}}{2}$$

此公式揭示出两性物种溶液的核心物理化学特征：**在一定浓度阈值以上，酸式盐溶液的 $\mathrm{pH}$ 完全由前后两级电离常数所锚定，具有显著的抗浓度稀释稳定性！**

**例2（两性酸式盐体系定量计算）**：在 $25\ ^\circ\mathrm{C}$ 下：
(a) 计算 $0.050\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaHCO_3}$ 溶液的 $\mathrm{pH}$（已知碳酸的 $\mathrm{p}K_{a1} = 6.38$，$\mathrm{p}K_{a2} = 10.25$）；
(b) 计算 $0.10\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaH_2PO_4}$ 溶液的 $\mathrm{pH}$（已知磷酸的 $\mathrm{p}K_{a1} = 2.16$，$\mathrm{p}K_{a2} = 7.21$，$\mathrm{p}K_{a3} = 12.32$），并检验近似条件的严谨性。

**解**：
(a) 对 $0.050\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaHCO_3}$：

1. 涉及的两级电离常数为碳酸的 $K_{a1} = 10^{-6.38} = 4.17 \times 10^{-7}$，与 $K_{a2} = 10^{-10.25} = 5.62 \times 10^{-11}$。

2. 检验双重判据：分母判据为 $c / K_{a1} = 0.050 / (4.17 \times 10^{-7}) \approx 1.2 \times 10^5 \gg 20$，高度满足；分子判据为 $c K_{a2} = 0.050 \times (5.62 \times 10^{-11}) = 2.81 \times 10^{-12} > 20 K_w = 2.0 \times 10^{-13}$，同样满足。

3. 采用极简公式计算：
   $$\mathrm{pH} \approx \frac{\mathrm{p}K_{a1} + \mathrm{p}K_{a2}}{2} = \frac{6.38 + 10.25}{2} = 8.32$$
   溶液显微弱碱性。

(b) 对 $0.10\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaH_2PO_4}$：

1. $\mathrm{H_2PO_4^-}$ 为磷酸的一级酸式盐，其涉及的两级常数为 $K_{a1} = 10^{-2.16} = 6.92 \times 10^{-3}$ 与 $K_{a2} = 10^{-7.21} = 6.17 \times 10^{-8}$。

2. 检验双重判据：分子判据为 $c K_{a2} = 0.10 \times (6.17 \times 10^{-8}) = 6.17 \times 10^{-9} \gg 20 K_w$，水自偶电离可完全忽略；但分母判据为 $c / K_{a1} = 0.10 / (6.92 \times 10^{-3}) \approx 14.5 < 20$，未能满足 20 倍准则！这表明磷酸的一级电离常数相对较大，分母中的 $K_{a1}$ 修正项绝不可粗暴略去。

3. 必须采用包含分母修正的精确展开式计算：
   $$[\mathrm{H^+}] \approx \sqrt{\frac{K_{a1} K_{a2} c}{c + K_{a1}}} = \sqrt{\frac{(6.92 \times 10^{-3}) \times (6.17 \times 10^{-8}) \times 0.10}{0.10 + 6.92 \times 10^{-3}}} = \sqrt{\frac{4.270 \times 10^{-11}}{0.1069}} = \sqrt{3.994 \times 10^{-10}} \approx 2.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pH} = -\lg(2.00 \times 10^{-5}) = 4.70$$
   若直接误用极简算术平均公式：$\mathrm{pH}_{\text{粗}} = \frac{2.16 + 7.21}{2} = 4.685$，虽数值偏差看似仅 0.015 个 pH 单位，但 $[\mathrm{H^+}]$ 理论偏差达 $+3.4\%$。在严密竞赛推演中必须精确交代修正源由。

## §6 缓冲溶液理论与定量设计

缓冲溶液（Buffer Solution）是指能够抵抗外加少量强酸、强碱或经适度稀释后，溶液自身 $\mathrm{pH}$ 保持相对稳定不变的溶液体系。缓冲体系在生命化学代谢调控、工业发酵以及分析化学定量分离中具有至关重要的作用。

### 6.1 Henderson-Hasselbalch 方程热力学推导

典型的共轭酸碱缓冲体系由弱酸及其共轭碱（如 $\mathrm{HAc - NaAc}$）或弱碱及其共轭酸（如 $\mathrm{NH_3 - NH_4Cl}$）按一定比例混合构成。
以弱酸 $\mathrm{HA}$（分析浓度为 $c_a$）与其共轭碱 $\mathrm{A^-}$（分析浓度为 $c_b$）构成的混合体系为例。体系中存在弱酸的电离平衡：
$$\mathrm{HA(aq) + H_2O(l) \rightleftharpoons H_3O^+(aq) + A^-(aq)}, \quad K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]}$$
由此解出氢离子平衡浓度：
$$[\mathrm{H^+}] = K_a \cdot \frac{[\mathrm{HA}]}{[\mathrm{A^-}]}$$
两边取负对数，即导出著名的**亨德森-哈塞尔巴尔赫方程（Henderson-Hasselbalch Equation）**：
$$\mathrm{pH} = \mathrm{p}K_a + \lg \frac{[\mathrm{A^-}]}{[\mathrm{HA}]}$$

在常规缓冲溶液中，总浓度通常处于 $0.05 \sim 0.5\ \mathrm{mol\cdot L^{-1}}$ 区间，且酸碱共轭对浓度较为接近。同离子效应双向强烈抑制了弱酸自身的电离与共轭碱自身的水解，因此在平衡时：
$$[\mathrm{HA}] \approx c_a, \qquad [\mathrm{A^-}] \approx c_b$$
由此得到缓冲溶液 $\mathrm{pH}$ 的工程实用计算式：
$$\mathrm{pH} \approx \mathrm{p}K_a + \lg \frac{c_b}{c_a}$$
若体系为弱碱 $\mathrm{B}$ 及其共轭酸 $\mathrm{BH^+}$ 构成的缓冲体系，则通过共轭关联 $\mathrm{p}K_a(\mathrm{BH^+}) = \mathrm{p}K_w - \mathrm{p}K_b(\mathrm{B})$，可等价表述为：
$$\mathrm{pOH} \approx \mathrm{p}K_b + \lg \frac{c_{\text{共轭酸}}}{c_{\text{弱碱}}}, \qquad \mathrm{pH} = \mathrm{p}K_w - \mathrm{pOH}$$

### 6.2 缓冲容量（Buffer Capacity, $\beta$）定量定义与数学严格求导

为了定量度量缓冲溶液抵抗外加酸碱导致 $\mathrm{pH}$ 发生微小变化的能力，范斯莱克（D. D. Van Slyke）引入了**缓冲容量（Buffer Capacity, 记作 $\beta$）**的概念：
**缓冲容量定量定义**：向 $1\ \mathrm{L}$ 缓冲溶液中加入强酸或强碱，使溶液的 $\mathrm{pH}$ 发生改变 $1$ 个单位（即 $\mathrm{dpH} = 1$）时所消耗强酸（$\mathrm{d}a$）或强碱（$\mathrm{d}b$）的摩尔数：
$$\beta = \frac{\mathrm{d}b}{\mathrm{dpH}} = -\frac{\mathrm{d}a}{\mathrm{dpH}}$$

#### 6.2.1 范斯莱克公式（Van Slyke Equation）的数学推导
考虑总缓冲物料浓度为 $c_{\mathrm{total}} = c_a + c_b = [\mathrm{HA}] + [\mathrm{A^-}]$ 的弱酸-共轭碱体系。向其中引入强碱 $\mathrm{NaOH}$（强碱浓度为 $b$）。
体系的电荷平衡方程（CBE）为：
$$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{A^-}]$$
由于加入的强碱完全解离，$[\mathrm{Na^+}] = b$。整理得到：
$$b = [\mathrm{OH^-}] - [\mathrm{H^+}] + [\mathrm{A^-}] = \frac{K_w}{[\mathrm{H^+}]} - [\mathrm{H^+}] + c_{\mathrm{total}} \cdot \frac{K_a}{[\mathrm{H^+}] + K_a}$$
对自由质子浓度 $[\mathrm{H^+}]$ 求微商：
$$\frac{\mathrm{d}b}{\mathrm{d}[\mathrm{H^+}]} = -\frac{K_w}{[\mathrm{H^+}]^2} - 1 - \frac{c_{\mathrm{total}} K_a}{([\mathrm{H^+}] + K_a)^2}$$
根据微分链式法则，$\mathrm{pH} = -\lg[\mathrm{H^+}] = -\frac{\ln[\mathrm{H^+}]}{2.303}$，有：
$$\frac{\mathrm{dpH}}{\mathrm{d}[\mathrm{H^+}]} = -\frac{1}{2.303 [\mathrm{H^+}]} \implies \frac{\mathrm{d}[\mathrm{H^+}]}{\mathrm{dpH}} = -2.303 [\mathrm{H^+}]$$
由此合成缓冲容量 $\beta$：
$$\beta = \frac{\mathrm{d}b}{\mathrm{dpH}} = \frac{\mathrm{d}b}{\mathrm{d}[\mathrm{H^+}]} \cdot \frac{\mathrm{d}[\mathrm{H^+}]}{\mathrm{dpH}} = \left( \frac{K_w}{[\mathrm{H^+}]^2} + 1 + \frac{c_{\mathrm{total}} K_a}{([\mathrm{H^+}] + K_a)^2} \right) \cdot (2.303 [\mathrm{H^+}]) $$
展开整理即得到著名的**范斯莱克严格微分解析方程**：
$$\beta = 2.303 \left( [\mathrm{H^+}] + [\mathrm{OH^-}] + \frac{c_{\mathrm{total}} K_a [\mathrm{H^+}]}{(K_a + [\mathrm{H^+}])^2} \right) = 2.303 \left( [\mathrm{H^+}] + [\mathrm{OH^-}] + c_{\mathrm{total}} \delta_0 \delta_1 \right)$$

#### 6.2.2 缓冲容量的核心物理规律
1. **水自身溶剂的缓冲贡献**：式中前两项 $2.303([\mathrm{H^+}] + [\mathrm{OH^-}])$ 来源于水溶剂自身。当溶液处于极端强酸（$\mathrm{pH} < 2$，$[\mathrm{H^+}] \ge 0.01\ \mathrm{mol\cdot L^{-1}}$）或极端强碱（$\mathrm{pH} > 12$，$[\mathrm{OH^-}] \ge 0.01\ \mathrm{mol\cdot L^{-1}}$）介质时，高浓度的游离 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$ 自身即赋予了体系巨大的抗酸碱缓冲能力；

2. **共轭对浓度的线性正比关系**：在常规中等酸度范围（$\mathrm{pH} = 3 \sim 11$），水自身的质子和氢氧根贡献极小，缓冲能力绝大部分由第三项贡献。缓冲容量 $\beta$ 与缓冲对总浓度 $c_{\mathrm{total}}$ 成正比，体系总浓度越大，耐受外加酸碱的容量越高；

3. **最大缓冲容量点（$\beta_{\max}$）**：考察函数 $f([\mathrm{H^+}]) = \delta_0 \delta_1 = \frac{[\mathrm{HA}][\mathrm{A^-}]}{c_{\mathrm{total}}^2}$。根据算术-几何均值不等式，当且仅当：
   $$[\mathrm{HA}] = [\mathrm{A^-}] \implies c_a = c_b \implies \mathrm{pH} = \mathrm{p}K_a$$
   乘积取得数学极大值 $\delta_0 \delta_1 = (0.50) \times (0.50) = 0.25$。
   此时弱酸弱碱共轭对达到**最大缓冲容量**：
   $$\beta_{\max} \approx 2.303 \times (0.25\ c_{\mathrm{total}}) = 0.576\ c_{\mathrm{total}}$$

### 6.3 缓冲范围与缓冲溶液工程配制原则

#### 6.3.1 有效缓冲范围（Buffer Range）
当缓冲对摩尔比例严重失调时，缓冲容量急剧衰减。通常认为当比例达到 $1:10$ 或 $10:1$ 之外时，体系已丧失抗拒单侧酸碱进攻的能力。
根据 Henderson-Hasselbalch 方程，当共轭对比例偏离至极限时：若 $c_b / c_a = 1/10$，则 $\mathrm{pH} = \mathrm{p}K_a - 1$；若 $c_b / c_a = 10/1$，则 $\mathrm{pH} = \mathrm{p}K_a + 1$。因此，缓冲溶液的有效缓冲控制窗口严格界定为：
$$\mathrm{pH} = \mathrm{p}K_a \pm 1$$

#### 6.3.2 缓冲溶液设计三步法
1. **依据目标 $\mathrm{pH}$ 遴选共轭酸碱对**：选取的弱酸其 $\mathrm{p}K_a$ 必须与待控制的目标 $\mathrm{pH}$ 尽可能接近，确保 $|\mathrm{pH} - \mathrm{p}K_a| \le 0.5$（最优为相符，处于最大缓冲容量点附近）；

2. **计算酸碱共轭物质的量浓度配比**：由 $\lg(c_b / c_a) = \mathrm{pH} - \mathrm{p}K_a$ 确定 $c_b / c_a$ 的理论比例；

3. **确定总浓度**：兼顾足够的缓冲容量 $\beta$ 与溶液离子强度及渗透压限制，总浓度通常配置在 $0.05 \sim 0.20\ \mathrm{mol\cdot L^{-1}}$ 范围。

**例3（缓冲溶液设计与缓冲容量定量计算）**：
现需要配制 $1.00\ \mathrm{L}$ 具有 $\mathrm{pH} = 4.74$ 的乙酸-乙酸钠缓冲溶液，要求体系的总浓度为 $c_{\mathrm{total}} = 0.200\ \mathrm{mol\cdot L^{-1}}$。已知 $25\ ^\circ\mathrm{C}$ 下乙酸的 $\mathrm{p}K_a = 4.74$。
(a) 计算所需冰醋酸（$\mathrm{HAc}$，密度 $1.05\ \mathrm{g\cdot mL^{-1}}$，纯度 99.5%，摩尔质量 $60.05\ \mathrm{g\cdot mol^{-1}}$）的体积与无水乙酸钠（$\mathrm{NaAc}$，摩尔质量 $82.03\ \mathrm{g\cdot mol^{-1}}$）的质量；
(b) 计算该缓冲溶液的缓冲容量 $\beta$；
(c) 向该 $1.00\ \mathrm{L}$ 缓冲溶液中加入 $5.00\ \mathrm{mL}\ 1.00\ \mathrm{mol\cdot L^{-1}}$ 的盐酸溶液（忽略加入后总体积的微小变化），计算溶液的最终 $\mathrm{pH}$ 及变化量 $\Delta\mathrm{pH}$；若向 $1.00\ \mathrm{L}$ 纯水中加入相同量的盐酸，对比其 $\mathrm{pH}$ 变化。

**解**：
(a) 缓冲组分配制计算：

1. 目标 $\mathrm{pH} = 4.74 = \mathrm{p}K_a$，根据 Henderson 方程：
   $$\lg \frac{[\mathrm{Ac^-}]}{[\mathrm{HAc}]} = \mathrm{pH} - \mathrm{p}K_a = 4.74 - 4.74 = 0 \implies [\mathrm{Ac^-}] = [\mathrm{HAc}]$$

2. 由于总浓度 $c_{\mathrm{total}} = [\mathrm{HAc}] + [\mathrm{Ac^-}] = 0.200\ \mathrm{mol\cdot L^{-1}}$：
   $$[\mathrm{HAc}] = [\mathrm{Ac^-}] = 0.100\ \mathrm{mol\cdot L^{-1}}$$

3. 计算所需无水乙酸钠质量：
   $$m(\mathrm{NaAc}) = 0.100\ \mathrm{mol} \times 82.03\ \mathrm{g\cdot mol^{-1}} = 8.203\ \mathrm{g}$$

4. 计算所需冰醋酸体积：
   所需纯醋酸的摩尔数 $n = 0.100\ \mathrm{mol}$，质量 $m = 0.100 \times 60.05 = 6.005\ \mathrm{g}$。
   $$V(\mathrm{HAc}) = \frac{6.005\ \mathrm{g}}{1.05\ \mathrm{g\cdot mL^{-1}} \times 0.995} \approx 5.75\ \mathrm{mL}$$

(b) 缓冲容量计算：
在 $\mathrm{pH} = \mathrm{p}K_a$ 处，体系达到最大缓冲容量：
$$\beta = \beta_{\max} \approx 0.576 \times c_{\mathrm{total}} = 0.576 \times 0.200\ \mathrm{mol\cdot L^{-1}} \approx 0.115\ \mathrm{mol\cdot L^{-1}\cdot pH^{-1}}$$

(c) 加入强酸后 $\mathrm{pH}$ 响应与抗酸性能对比：

1. 加入盐酸的摩尔量为：
   $$n(\mathrm{H^+})_{\text{外加}} = 5.00 \times 10^{-3}\ \mathrm{L} \times 1.00\ \mathrm{mol\cdot L^{-1}} = 0.00500\ \mathrm{mol}$$

2. 外加强酸与溶液中的共轭碱 $\mathrm{Ac^-}$ 发生定量抗酸中和反应：
   $$\mathrm{H^+ + Ac^- \to HAc}$$
   反应后各物种的摩尔浓度变为：
   $$[\mathrm{Ac^-}] = 0.100 - 0.00500 = 0.0950\ \mathrm{mol\cdot L^{-1}}$$
   $$[\mathrm{HAc}] = 0.100 + 0.00500 = 0.1050\ \mathrm{mol\cdot L^{-1}}$$

3. 代入 Henderson 方程重新求取 $\mathrm{pH}$：
   $$\mathrm{pH}_{\text{后}} = 4.74 + \lg \frac{0.0950}{0.1050} = 4.74 + \lg(0.9048) = 4.74 - 0.043 = 4.697 \approx 4.70$$
   $$\Delta\mathrm{pH} = 4.70 - 4.74 = -0.04$$
   加入强酸后，缓冲体系的 $\mathrm{pH}$ 仅微弱漂移了 $0.04$ 个单位，缓冲稳定性极其优异。

4. 对照组：若向 $1.00\ \mathrm{L}\ \mathrm{pH} = 7.00$ 的纯水中加入相同量的盐酸（$0.00500\ \mathrm{mol}$）：
   $$[\mathrm{H^+}] = 0.00500\ \mathrm{mol\cdot L^{-1}} \implies \mathrm{pH} = -\lg(0.00500) = 2.30$$
   $$\Delta\mathrm{pH}_{\text{纯水}} = 2.30 - 7.00 = -4.70$$
   纯水的 $\mathrm{pH}$ 暴跌了整整 $4.70$ 个单位（质子浓度暴增了 50000 倍）。鲜明的定量对比彰显出缓冲溶液强大的物理化学稳定功能。

## §7 酸碱指示剂变色原理与滴定曲线突跃

酸碱滴定分析是定量分析化学的核心支柱之一。准确监测滴定反应的化学计量点（Equivalence Point, EP）并合理选择酸碱指示剂，对于控制滴定终点误差（Titration Error, TE）至关重要。

### 7.1 酸碱指示剂变色理论与微观结构本质

酸碱指示剂（Acid-Base Indicator）通常是一类结构复杂的有机弱酸（记作 $\mathrm{HIn}$）或有机弱碱。其核心特征在于：**未电离的酸色分子形态 $\mathrm{HIn}$ 与共轭去质子化的碱色离子形态 $\mathrm{In^-}$ 具有截然不同的分子共轭生色结构与对可见光的吸收光谱，因而在溶液中呈现不同的颜色**。

#### 7.1.1 变色平衡常数与理论变色点
在水溶液中，指示剂存在质子传递电离平衡：
$$\mathrm{HIn(aq) + H_2O(l) \rightleftharpoons H_3O^+(aq) + In^-(aq)}, \quad K_{\mathrm{In}} = \frac{[\mathrm{H^+}][\mathrm{In^-}]}{[\mathrm{HIn}]}$$
整理得到自由质子浓度表达式：
$$[\mathrm{H^+}] = K_{\mathrm{In}} \cdot \frac{[\mathrm{HIn}]}{[\mathrm{In^-}]}$$
两边取负对数：
$$\mathrm{pH} = \mathrm{p}K_{\mathrm{In}} + \lg \frac{[\mathrm{In^-}]}{[\mathrm{HIn}]}$$

人眼对双色混合体系的视觉辨识存在生理阈值感知特性：当比例 $\frac{[\mathrm{In^-}]}{[\mathrm{HIn}]} \le \frac{1}{10}$（即酸色型体浓度占优达 10 倍以上）时，人眼仅能感知到纯粹的酸色，对应 $\mathrm{pH} \le \mathrm{p}K_{\mathrm{In}} - 1$；当比例 $\frac{[\mathrm{In^-}]}{[\mathrm{HIn}]} \ge \frac{10}{1}$（即碱色型体浓度占优达 10 倍以上）时，人眼仅能感知到纯粹的碱色，对应 $\mathrm{pH} \ge \mathrm{p}K_{\mathrm{In}} + 1$；而当比值处于 $1/10$ 与 $10/1$ 之间时，两类色相在视网膜上叠加互混，人眼感知到特征过渡混合色。由此导出指示剂的理论变色范围为：
$$\mathrm{pH} = \mathrm{p}K_{\mathrm{In}} \pm 1$$
理论变色区间跨越约 $2$ 个 $\mathrm{pH}$ 单位。当 $[\mathrm{In^-}] = [\mathrm{HIn}]$ 时，$\mathrm{pH} = \mathrm{p}K_{\mathrm{In}}$，称为指示剂的**理论变色点**。

### 7.2 酸碱滴定曲线与滴定突跃

酸碱滴定曲线是以加入的滴定剂体积（或滴定百分数 $a$）为横坐标、溶液的 $\mathrm{pH}$ 为纵坐标绘制的关系曲线。在化学计量点前后加入微量滴定剂（如 $\pm 0.1\%$，即 $0.02\ \mathrm{mL}$ / 滴）引起的 $\mathrm{pH}$ 剧烈急剧改变区间，称为**滴定突跃范围（Titration Jump）**。

#### 7.2.1 强酸强碱相互滴定
以 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaOH}$ 滴定 $20.00\ \mathrm{mL}\ 0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HCl}$ 为例：

1. **化学计量点前 $-0.1\%$（即加入 $19.98\ \mathrm{mL}\ \mathrm{NaOH}$）**：
   剩余末被滴定的 $\mathrm{HCl}$ 浓度为：
   $$[\mathrm{H^+}] = \frac{0.1000\ \mathrm{mol\cdot L^{-1}} \times 0.02\ \mathrm{mL}}{20.00\ \mathrm{mL} + 19.98\ \mathrm{mL}} = \frac{2.00 \times 10^{-3}\ \mathrm{mmol}}{39.98\ \mathrm{mL}} \approx 5.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pH} = -\lg(5.00 \times 10^{-5}) = 4.30$$

2. **化学计量点（加入 $20.00\ \mathrm{mL}\ \mathrm{NaOH}$）**：
   两者恰好完全中和生成 $\mathrm{NaCl}$，由水自偶电离决定：
   $$[\mathrm{H^+}] = [\mathrm{OH^-}] = 1.00 \times 10^{-7}\ \mathrm{mol\cdot L^{-1}}, \qquad \mathrm{pH} = 7.00$$

3. **化学计量点后 $+0.1\%$（即加入 $20.02\ \mathrm{mL}\ \mathrm{NaOH}$）**：
   过量的 $\mathrm{NaOH}$ 浓度为：
   $$[\mathrm{OH^-}] = \frac{0.1000\ \mathrm{mol\cdot L^{-1}} \times 0.02\ \mathrm{mL}}{20.00\ \mathrm{mL} + 20.02\ \mathrm{mL}} = \frac{2.00 \times 10^{-3}\ \mathrm{mmol}}{40.02\ \mathrm{mL}} \approx 5.00 \times 10^{-5}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pOH} = 4.30, \qquad \mathrm{pH} = 14.00 - 4.30 = 9.70$$
因此，滴定突跃范围为 **$\mathrm{pH} = 4.30 \sim 9.70$**（跨越整整 $5.40$ 个 $\mathrm{pH}$ 单位）。
指示剂选择结论：甲基橙（变色范围 3.1~4.4）、甲基红（4.4~6.2）与酚酞（8.2~10.0）的变色范围全部或大部分落入此突跃区间内，均可作为指示剂。

#### 7.2.2 强碱滴定一元弱酸
以 $0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{NaOH}$ 滴定 $20.00\ \mathrm{mL}\ 0.1000\ \mathrm{mol\cdot L^{-1}}\ \mathrm{HAc}$（$\mathrm{p}K_a = 4.74$）为例：

1. **滴定开始前**：为单纯的弱酸体系，$[\mathrm{H^+}] \approx \sqrt{c K_a} = 1.32 \times 10^{-3}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 2.88$；

2. **滴定中途（化学计量点前）**：生成大量的 $\mathrm{NaAc}$，与剩余未反应的 $\mathrm{HAc}$ 构成典型的**缓冲体系**，曲线平缓上升；在半计量点（加入 $10.00\ \mathrm{mL}\ \mathrm{NaOH}$）处，$[\mathrm{HAc}] = [\mathrm{Ac^-}]$，$\mathrm{pH} = \mathrm{p}K_a = 4.74$；

3. **化学计量点（加入 $20.00\ \mathrm{mL}\ \mathrm{NaOH}$）**：两者完全反应生成 $\mathrm{NaAc}$，浓度稀释为 $c = 0.0500\ \mathrm{mol\cdot L^{-1}}$。强碱弱酸盐水解显碱性：
   $$[\mathrm{OH^-}] \approx \sqrt{c K_b} = \sqrt{c \frac{K_w}{K_a}} = \sqrt{0.0500 \times \frac{1.0 \times 10^{-14}}{1.75 \times 10^{-5}}} \approx 5.35 \times 10^{-6}\ \mathrm{mol\cdot L^{-1}}$$
   $$\mathrm{pOH} = 5.27, \qquad \mathrm{pH}_{\text{EP}} = 8.73$$
   **化学计量点明显偏向碱性区域**！

4. **化学计量点后（加入 $20.02\ \mathrm{mL}\ \mathrm{NaOH}$）**：过量强碱决定体系 $\mathrm{pH}$，与强酸强碱滴定相同，$\mathrm{pH} = 9.70$。
因此，突跃范围大幅收窄为 **$\mathrm{pH} = 7.74 \sim 9.70$**（仅跨越约 $2.0$ 个单位）。
指示剂选择结论：**只能选用碱性区变色的指示剂（酚酞，8.2~10.0）**；若误选酸性区变色的甲基橙（3.1~4.4），将在滴定仅完成约一半时即发生变色，产生高达数十个百分点的极大的负终点误差。

#### 7.2.3 准确滴定的判据
在分析化学中，若要求终点误差 $|\mathrm{TE}| \le 0.1\%$，且突跃范围 $\Delta\mathrm{pH} \ge 0.4$，则反应物必须满足下列定量阈值判据：

1. **一元弱酸能被强碱准确直接滴定的判据**：
   $$c K_a \ge 10^{-8}$$
   （若 $c = 0.1\ \mathrm{mol\cdot L^{-1}}$，则要求弱酸的 $K_a \ge 10^{-7}$，$\mathrm{p}K_a \le 7$。若 $c K_a < 10^{-8}$，突跃消失，无法用常规指示剂确定终点）；

2. **一元弱碱能被强酸准确直接滴定的判据**：
   $$c K_b \ge 10^{-8}$$

3. **多元弱酸分步滴定的分界判据**：
   若多元弱酸欲分步滴定并出现独立的两个突跃平台，必须同时满足：
   $$\frac{K_{a1}}{K_{a2}} \ge 10^4 \quad \text{且} \quad c K_{a1} \ge 10^{-8}, \quad c K_{a2} \ge 10^{-8}$$

### 8.1 酸碱平衡核心模型与计算公式速查

| 体系类型 | 质子条件式（PBE） | 精确方程或一阶展开 | 最简近似公式与适用判据 |
| :--- | :--- | :--- | :--- |
| **一元强酸（$c$）** | $[\mathrm{H^+}] = c + [\mathrm{OH^-}]$ | $[\mathrm{H^+}]^2 - c[\mathrm{H^+}] - K_w = 0$ | 当 $c \ge 10^{-6}\ \mathrm{mol\cdot L^{-1}}$ 时：$[\mathrm{H^+}] \approx c$ |
| **一元弱酸（$c, K_a$）** | $[\mathrm{H^+}] = [\mathrm{A^-}] + [\mathrm{OH^-}]$ | $[\mathrm{H^+}]^2 + K_a[\mathrm{H^+}] - c K_a = 0$ | 当 $\frac{c}{K_a} \ge 500$ 且 $c K_a \ge 20 K_w$ 时：$[\mathrm{H^+}] \approx \sqrt{c K_a}$ |
| **一元弱碱（$c, K_b$）** | $[\mathrm{OH^-}] = [\mathrm{HB^+}] + [\mathrm{H^+}]$ | $[\mathrm{OH^-}]^2 + K_b[\mathrm{OH^-}] - c K_b = 0$ | 当 $\frac{c}{K_b} \ge 500$ 且 $c K_b \ge 20 K_w$ 时：$[\mathrm{OH^-}] \approx \sqrt{c K_b}$ |
| **二元弱酸（$c, K_{a1}, K_{a2}$）**| $[\mathrm{H^+}] = [\mathrm{HA^-}] + 2[\mathrm{A^{2-}}] + [\mathrm{OH^-}]$ | 视同以 $K_{a1}$ 为准的一元弱酸求解 | 当 $\frac{K_{a1}}{K_{a2}} \ge 10^3$ 时：$[\mathrm{H^+}] \approx \sqrt{c K_{a1}}$；$[\mathrm{A^{2-}}] \approx K_{a2}$ |
| **两性酸式盐（$\mathrm{NaHA}, c$）** | $[\mathrm{H^+}] + [\mathrm{H_2A}] = [\mathrm{A^{2-}}] + [\mathrm{OH^-}]$ | $[\mathrm{H^+}] \approx \sqrt{\frac{K_{a1}K_{a2}c + K_{a1}K_w}{c + K_{a1}}}$ | 当 $c \ge 20 K_{a1}$ 且 $c K_{a2} \ge 20 K_w$ 时：$[\mathrm{H^+}] \approx \sqrt{K_{a1}K_{a2}}$ |
| **弱酸弱碱盐（$c, K_a, K_b$）** | $[\mathrm{H^+}] + [\mathrm{HA}] = [\mathrm{B}] + [\mathrm{OH^-}]$ | 联立离解与水解质子条件代数化简 | 当 $c \ge 20 K_a$ 且 $c \ge 20 K_b$ 时：$[\mathrm{H^+}] \approx \sqrt{\frac{K_w K_a}{K_b}}$ |
| **缓冲溶液（$c_a, c_b, K_a$）** | 由电离平衡常数严格展开 | $\mathrm{pH} = \mathrm{p}K_a + \lg \frac{[\mathrm{A^-}]}{[\mathrm{HA}]}$ | 当 $c_a, c_b \gg [\mathrm{H^+}], [\mathrm{OH^-}]$ 时：$\mathrm{pH} \approx \mathrm{p}K_a + \lg \frac{c_b}{c_a}$ |

**解 1**：$$
\mathrm{HCN} + \mathrm{H}_{2} \mathrm{O} \rightleftharpoons \mathrm{H}_{3} \mathrm{O}^{+} + \mathrm{CN}^{-} \quad \mathrm{酸1 碱2 酸2 碱1}
$$

$$
K_{\mathrm{a}} = \frac {[ \mathrm{H}_{3} \mathrm{O}^{+} ] [ \mathrm{CN}^{-} ]}{[ \mathrm{HCN} ]} = 6.2 \times 10^{-10}
$$

$$
(2) \mathrm{NO}_{2}^{-} + \mathrm{H}_{2} \mathrm{O} \rightleftharpoons \mathrm{HNO}_{2} + \mathrm{OH}^{-}   \mathrm{   碱   } 1 \quad \mathrm{   酸   } 2 \quad \mathrm{   酸   } 1 \quad \mathrm{   碱   } 2
$$

$$
K_{\mathrm{b}} = \frac {[ \mathrm{HNO}_{2} ] [ \mathrm{OH}^{-} ]}{[ \mathrm{NO}_{2}^{-} ]} = \frac {K_{\mathrm{w}}}{K (\mathrm{HNO}_{2})} = \frac {1.0 \times 10^{-14}}{5.6 \times 10^{-4}} = 1.8 \times 10^{-11}
$$

(3) $S^{2-} + H_{2}O \rightleftharpoons HS^{-} + OH^{-}$ 碱1 酸2 酸1 碱2

$$
K_{\mathrm{b}} = \frac {[ \mathrm{HS}^{-} ] [ \mathrm{OH}^{-} ]}{[ \mathrm{S}^{2-} ]} = \frac {K_{\mathrm{w}}}{K_{\mathrm{a}_{2}}} = \frac {1.0 \times 10^{-14}}{1.2 \times 10^{-13}} = 8.3 \times 10^{-2}
$$

$$(4) \mathrm{PO}_{4}^{3-} + \mathrm{H}_{2} \mathrm{O} \rightleftharpoons \mathrm{HPO}_{4}^{2-} + \mathrm{OH}^{-}$$

$$\mathrm{   碱   } 1 \quad \mathrm{   酸   } 2 \quad \mathrm{   酸   } 1 \quad \mathrm{   碱   } 2$$

$$\qquad K_{\mathrm{b}} = \frac {[ \mathrm{HPO}_{4}^{2-} ] [ \mathrm{OH}^{-} ]}{[ \mathrm{PO}_{4}^{3-} ]} = \frac {K_{\mathrm{w}}}{K_{\mathrm{a}_{3}}} = \frac {1.0 \times 10^{-14}}{4.8 \times 10^{-13}} = 2.1 \times 10^{-2}$$

**解 2**：$$
\mathrm{HAc} + \mathrm{H}_{2} \mathrm{O} \rightleftharpoons \mathrm{H}_{3} \mathrm{O}^{+} + \mathrm{Ac}^{-}
$$

平衡浓度 $\mathrm{mol}\cdot \mathrm{dm}^{-3}$

$$K (\mathrm{HAc}) = \frac {[ \mathrm{H}_{3} \mathrm{O}^{+} ] [ \mathrm{Ac}^{-} ]}{[ \mathrm{HAc} ]}, \quad \frac {x^{2}}{0.050 - x} = 1.75 \times 10^{-5}$$

$$x = 9.4 \times 10^{-4}, \quad [ \mathrm{H}_{3} \mathrm{O} ] ^{+} = [ \mathrm{Ac}^{-} ] = 9.4 \times 10^{-4} \mathrm{mol} \cdot \mathrm{dm}^{-3}$$

$$[ \mathrm{HAc} ] = (0.050 - 9.4 \times 10^{-4}) \mathrm{mol} \cdot \mathrm{dm}^{-3} = 0.049 \mathrm{mol} \cdot \mathrm{dm}^{-3}$$

质点总浓度

$$c = (0.049 + 2 \times 9.4 \times 10^{-4}) \mathrm{mol} \cdot \mathrm{dm}^{-3} = 0.051 \mathrm{mol} \cdot \mathrm{dm}^{-3}$$

$$m \approx 0.051 \mathrm{mol} \cdot \mathrm{kg}^{-1}$$

$$\Delta T_{\mathrm{f}} = K_{\mathrm{f}} m = 1.86^{\circ} \mathrm{C} \cdot \mathrm{kg} \cdot \mathrm{mol}^{-1} \times 0.051 \mathrm{mol} \cdot \mathrm{kg}^{-1} = 0.095^{\circ} \mathrm{C}$$

即 $0.050 \, mol \cdot dm^{-3}$ HAc 溶液的凝固点降低值为 $0.095^{\circ}C$ 。

**解 3**：(1) $c / K = 0.10 / (6.2 \times 10^{-10}) = 1.6 \times 10^{8} \gg 400$ ，可简化计算。设 $[\mathrm{H}_{3}\mathrm{O}^{+}] = x\mathrm{mol} \cdot \mathrm{dm}^{-3}$

$$
\left[ \mathrm{H}_{3} \mathrm{O}^{+} \right] = \sqrt {K_{\mathrm{a}} c}, \quad x = \sqrt {6.2 \times 10^{-10} \times 0.10} = 7.9 \times 10^{-6}
$$

$$
[ \mathrm{H}_{3} \mathrm{O}^{+} ] = 7.9 \times 10^{-6} \mathrm{mol} \cdot \mathrm{dm}^{-3}, \quad \mathrm{pH} = 5.10
$$

(2) $c / K = 0.10 / (1.3 \times 10^{-3}) = 77 < 400$ ，不可简化计算。设 $[\mathrm{H}_3\mathrm{O}^+] = x\mathrm{mol}\cdot \mathrm{dm}^{-3}$

$$
\frac {x^{2}}{0.10 - x} = 1.3 \times 10^{-3}   x = 0.011, \quad [ \mathrm{H}_{3} \mathrm{O}^{+} ] = 0.011 \mathrm{mol} \cdot \mathrm{dm}^{-3}, \quad \mathrm{pH} = 1.96
$$

(3) $\mathrm{H}_{2} \mathrm{SO}_{4}$ 第一步完全电离, 第二步为不完全电离。第一步电离产生的 $\mathrm{H}_{3} \mathrm{O}^{+}$ 会对第二步电离产生同离子效应, 即

$$\mathrm{HSO_{4}^{-}} + \mathrm{H_{2} O} \rightleftharpoons \mathrm{H_{3} O^{+}} + \mathrm{SO_{4}^{2-}}$$

$$\frac {\mathrm{平衡浓度}}{\mathrm{mol} \cdot \mathrm{dm}^{-3}} = 0.10 - y, \quad 0.10 + y, \quad y$$

$$\frac {(0.10 + y) y}{0.10 - y} = 1.0 \times 10^{-2}, \quad y = 8.4 \times 10^{-3}$$

$$[ \mathrm{H_{3} O^{+}} ] = (0.10 + 8.4 \times 10^{-3}) \mathrm{mol} \cdot \mathrm{dm}^{-3} = 0.11 \mathrm{mol} \cdot \mathrm{dm}^{-3}, \quad \mathrm{pH} = 0.96$$

$\mathrm{pH} = 2.94$ ，即 $[\mathrm{H}_3\mathrm{O}^+ ] = 1.1\times 10^{-3}\mathrm{mol}\cdot \mathrm{dm}^{-3}$

$$\mathrm{HC_{6} H_{11} O_{2} + H_{2} O\rightleftharpoons H_{3} O^{+} + C_{6} H_{11} O_{2}^{-}}$$

$$\frac {\mathrm{平衡浓度}}{\mathrm{mol} \cdot \mathrm{dm}^{-3}} \quad 0.095 - x \qquad \qquad x \qquad \qquad x$$

**解 21**：(1) 错误。pH 是否小于 7 取决于该温度下 $K_w$ 的大小，不能单凭 pH = 6.4 判断酸碱性。$K_w$ 随温度升高而增大，高温下中性水 pH < 7，此时 pH = 6.4 完全可能是中性甚至弱碱性。判断中性必须用两个判据：$[\mathrm{H^+}] = [\mathrm{OH^-}]$，或 $\mathrm{pH} = \tfrac{1}{2}\mathrm{p}K_w$。(2) 错误。$K_w$ 是热力学平衡常数，为**无量纲**量（其量纲归入标准浓度 $c^\ominus$），正确写法是 $K_w = 1.0\times10^{-14}$。(3) 正确但**仅限 298 K**：此时 $K_w = 1.0\times10^{-14}$，故 $\mathrm{pH} + \mathrm{pOH} = \mathrm{p}K_w = 14$；其他温度下 $\mathrm{p}K_w \neq 14$，该关系不成立。

**解 22**：溶解度取决于晶格能与水合能的相对大小。$\mathrm{Ag^+}$ 是**软酸**，$\mathrm{F^-}$ 是硬碱而 $\mathrm{Cl^-}$、$\mathrm{Br^-}$、$\mathrm{I^-}$ 依次变软：按软硬酸碱原理，软酸 $\mathrm{Ag^+}$ 与较软的 $\mathrm{Cl^-}$、$\mathrm{Br^-}$、$\mathrm{I^-}$ 结合时共价成分显著、晶格能高（且随离子变形性增强而增大），故卤化银难溶且溶解度 $\mathrm{AgCl} > \mathrm{AgBr} > \mathrm{AgI}$；而 $\mathrm{AgF}$ 中 $\mathrm{F^-}$ 半径极小、不易变形，$\mathrm{AgF}$ 的晶格能较低但水合能很大，加之 $\mathrm{AgF}$ 具有明显的离子性，故它易溶于水。

**解 23**：(1) 因 $K_{a1} \gg K_{a2}$ 且 $K_{a1} \gg K_w$，可只按第一级电离处理。检验 $c/K_{a1} = 0.10/(8.9\times10^{-8}) = 1.1\times10^{6} \gg 500$，可用最简式：$[\mathrm{H^+}] = \sqrt{cK_{a1}} = \sqrt{0.10\times8.9\times10^{-8}} = 9.4\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$，$\mathrm{pH} = 4.03$。(2) 由 $K_{a1}K_{a2} = \dfrac{[\mathrm{H^+}]^2[\mathrm{S^{2-}}]}{[\mathrm{H_2S}]}$ 得$$[\mathrm{S^{2-}}] = \frac{K_{a1}K_{a2}[\mathrm{H_2S}]}{[\mathrm{H^+}]^2} = \frac{8.9\times10^{-8}\times1.2\times10^{-13}\times0.10}{(9.4\times10^{-5})^2} = 1.2\times10^{-13}\ \mathrm{mol\cdot L^{-1}}$$可见 $[\mathrm{S^{2-}}] \approx K_{a2}$——对 $K_{a1} \gg K_{a2}$ 的二元弱酸，酸根离子浓度约等于 $K_{a2}$，与酸的浓度无关，这是常考判据。

**解 24**：此体系碱性极弱，不能忽略水的自偶电离。由电荷守恒 $[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}]$，其中 $[\mathrm{Na^+}] = 1.0\times10^{-8}$，设 $[\mathrm{H^+}] = x$、$[\mathrm{OH^-}] = K_w/x$，得$$1.0\times10^{-8} + x = \frac{1.0\times10^{-14}}{x}$$整理为 $x^2 + 1.0\times10^{-8}x - 1.0\times10^{-14} = 0$，解得 $x = [\mathrm{H^+}] = 9.5\times10^{-8}\ \mathrm{mol\cdot L^{-1}}$，故 $\mathrm{pH} = 7.02$。可见极稀强碱溶液仍显**微弱**碱性（pH 略大于 7），绝不能套用 $[\mathrm{OH^-}] = c$ 得 pH = 6 的错误结论。

**解 25**：两性物质最简式要求 $c \ge 20K_{a1}$ 且 $cK_{a2} \ge 20K_w$。本题 $K_{a1} = 5.9\times10^{-2}$，$c/K_{a1} = 0.010/0.059 = 0.17 \ll 20$，条件**不满足**，故最简式失算：$\mathrm{pH} = \tfrac{1}{2}(1.23 + 4.19) = 2.71$ 是错的。此时须用分母修正公式$$[\mathrm{H^+}] = \sqrt{\frac{K_{a1}K_{a2}c}{K_{a1} + c}} = \sqrt{\frac{5.9\times10^{-2}\times6.4\times10^{-5}\times0.010}{5.9\times10^{-2} + 0.010}} = 7.1\times10^{-3}\ \mathrm{mol\cdot L^{-1}}$$得 $\mathrm{pH} = 2.15$。由质子条件式数值求解可得 $[\mathrm{H^+}] = 7.1\times10^{-3}$，与之吻合——本题的判据是：$K_{a1}$ 较大（酸性较强）的酸式盐，必须使用含 $K_{a1}$ 分母的精确式。
