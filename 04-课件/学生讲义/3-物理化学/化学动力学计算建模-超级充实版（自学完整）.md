## §1 速率微分方程积分与实验数据线性化拟合

化学动力学的核心任务在于阐明化学转化的时间进程，并通过宏观反应速率对反应物浓度、温度、催化剂及介质环境的函数依赖关系，深入揭示微观基元反应网络历程。对于一般化学反应 $\sum \nu_{\mathrm{B}} \mathrm{B} = 0$，严格的反应速率定义基于系统反应进度 $\xi$ 随时间的微分变化率：$r = \frac{1}{V}\frac{\mathrm{d}\xi}{\mathrm{d}t} = \frac{1}{\nu_{\mathrm{B}}}\frac{\mathrm{d}c_{\mathrm{B}}}{\mathrm{d}t}$。该定义消除了选取不同物质作为监测基准时数值的差异，其标准量纲统一为 $\mathrm{mol\cdot dm^{-3}\cdot s^{-1}}$ 或 $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$。在恒温恒容条件下，质量作用定律严格仅适用于无中间物种积累的单步基元反应。对于复杂的非基元总包反应，速率方程通常由实验测定表述为各反应物浓度的幂函数积：$r = k \prod c_{\mathrm{B}}^{n_{\mathrm{B}}}$，其中分级数 $n_{\mathrm{B}}$ 可为正整数、分数、零乃至负数。

对于具有简单级数特征的单反应物动力学系统，通过分离变量积分可建立特征浓度随时间的解析关系式。常见零级、一级、二级与 $n$ 级反应的微分方程、积分方程与半衰期关系归纳如下表所示：

| 反应级数 $n$ | 微分速率方程 | 积分速率方程 | 线性作图关系 | 速率常数 $k$ 的量纲 | 半衰期 $t_{1/2}$ 表达式 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $0$ 级 | $-\frac{\mathrm{d}c}{\mathrm{d}t} = k$ | $c_0 - c = kt$ | $c \sim t$ | $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$ | $t_{1/2} = \frac{c_0}{2k}$ |
| $1$ 级 | $-\frac{\mathrm{d}c}{\mathrm{d}t} = kc$ | $\ln\frac{c_0}{c} = kt$ | $\ln c \sim t$ | $\mathrm{s^{-1}}$ | $t_{1/2} = \frac{\ln 2}{k}$ |
| $2$ 级 ($A+A$) | $-\frac{\mathrm{d}c}{\mathrm{d}t} = kc^2$ | $\frac{1}{c} - \frac{1}{c_0} = kt$ | $\frac{1}{c} \sim t$ | $\mathrm{L\cdot mol^{-1}\cdot s^{-1}}$ | $t_{1/2} = \frac{1}{k c_0}$ |
| $n$ 级 ($n \neq 1$) | $-\frac{\mathrm{d}c}{\mathrm{d}t} = kc^n$ | $\frac{1}{n-1}\left(\frac{1}{c^{n-1}} - \frac{1}{c_0^{n-1}}\right) = kt$ | $c^{1-n} \sim t$ | $(\mathrm{mol\cdot L^{-1}})^{1-n}\mathrm{s^{-1}}$ | $t_{1/2} = \frac{2^{n-1}-1}{(n-1)k c_0^{n-1}}$ |

在多组分复杂反应动力学研究中，初始速率法（Initial Rate Method）结合过量隔离技术是消除产物反馈抑制与自催化干扰的标准实验方法。通过大幅过量引入某种反应物使其实际浓度在反应初期近似保持常数，可将多元高阶方程有效降级为准一级或准二级方程进行分离测定。对于多组离散实验观测点 $(x_i, y_i)$，经典最小二乘回归法（Ordinary Least Squares, OLS）通过最小化残差平方和 $S = \sum [y_i - (a + b x_i)]^2$ 确定最佳拟合斜率 $b = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}$ 与截距 $a = \bar{y} - b\bar{x}$。在竞赛实验数据处理中，严禁仅选取两个端点做简易两点计算，必须通过全程多点线性拟合验证动力学模型的假定自洽性。

在胶体微粒与生物大分子溶液中，物质的布朗运动由微观扩散行为主导。根据流体力学 Stokes 定律，半径为 $r$ 的刚性球形粒子在黏度为 $\eta$ 的介质中受到的流体阻力系数为 $f = 6\pi\eta r$。结合 Einstein 扩散涨落热力学理论，粒子扩散系数满足著名的 Stokes-Einstein 关系式：
$$D = \frac{k_{\mathrm{B}} T}{f} = \frac{k_{\mathrm{B}} T}{6\pi\eta r} = \frac{R T}{6\pi\eta r N_{\mathrm{A}}}$$
当实验通过动态光散射或核磁共振测得不同黏度介质中的扩散系数时，以扩散系数 $D$ 对流动度倒数 $1/\eta$ 作线性回归，直线的斜率即为 $\frac{k_{\mathrm{B}} T}{6\pi r}$，由此可高精度反推球形纳米粒子或球蛋白分子的有效流体力学半径与微观水合尺度。

## §2 典型复杂反应动力学解析解与极值时间

在实际化学体系中，大多数反应以对峙（可逆）、平行（竞争）或连串（连续）反应的形式交织进行。

对峙反应是化学平衡的动力学微观基石。对于一级对峙反应 $A \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} B$，若初始条件为 $c_A(0) = c_{A,0}, c_B(0) = 0$，体系任一时刻消耗量为 $x$，平衡转化量为 $x_e$。由于在平衡点正逆速率相等满足 $k_1(c_{A,0} - x_e) = k_{-1}x_e$，分离变量积分给出标准指数趋近方程：
$$\ln\frac{x_e}{x_e - x} = (k_1 + k_{-1})t \iff x(t) = x_e\left[1 - \mathrm{e}^{-(k_1 + k_{-1})t}\right]$$
对峙反应的表观驰豫速率常数严格等于正、逆反应速率常数之和 $k_{\mathrm{obs}} = k_1 + k_{-1}$，而平衡常数则决定了两者的比值 $K_c = k_1 / k_{-1}$。

平行反应由相同反应物沿不同路径竞争生成多种产物：$A \xrightarrow{k_1} B$ 与 $A \xrightarrow{k_2} C$。总消耗速率由两路径并联相加决定：$-\frac{\mathrm{d}c_A}{\mathrm{d}t} = (k_1 + k_2)c_A$。对任意时刻，产物浓度之比严格恒等于速率常数之比：$\frac{c_B(t)}{c_C(t)} = \frac{k_1}{k_2}$。结合 Arrhenius 方程，相对产率与温度的定量关系为：
$$\ln\frac{c_B}{c_C} = \ln\frac{A_1}{A_2} - \frac{E_{a,1} - E_{a,2}}{RT}$$
若主产物生成步骤的活化能较高（$E_{a,1} > E_{a,2}$），升高温度将显著放大主副反应速率之比，提高目标产物选择性；反之若主反应活化能较低，则适度降低反应温度有利于抑制副产物生成。

对于一级连串反应 $A \xrightarrow{k_1} B \xrightarrow{k_2} C$，设起始 $c_A(0) = c_{A,0}, c_B(0) = 0, c_C(0) = 0$。连串反应微分方程组具有严格的解析解：
$$c_A(t) = c_{A,0}\mathrm{e}^{-k_1 t}$$
$$c_B(t) = \frac{k_1 c_{A,0}}{k_2 - k_1}\left(\mathrm{e}^{-k_1 t} - \mathrm{e}^{-k_2 t}\right) \quad (k_1 \neq k_2)$$
$$c_C(t) = c_{A,0}\left[1 - \frac{k_2}{k_2 - k_1}\mathrm{e}^{-k_1 t} + \frac{k_1}{k_2 - k_1}\mathrm{e}^{-k_2 t}\right]$$
中间活性产物 $B$ 随时间的演变呈现先增长后衰减的单峰形态。对中间体浓度求导令 $\frac{\mathrm{d}c_B}{\mathrm{d}t} = 0$，解得达到最大中间体浓度的特征极值时间 $t_{\max}$ 及其对应的极大产率 $c_{B,\max}$：
$$t_{\max} = \frac{\ln(k_1 / k_2)}{k_1 - k_2}$$
$$c_{B,\max} = c_{A,0}\left(\frac{k_1}{k_2}\right)^{\frac{k_2}{k_1 - k_2}} = c_{A,0}\left(\frac{k_2}{k_1}\right)^{\frac{k_1}{k_2 - k_1}}$$

总包反应的表观活化能是各基元步骤活化能的代数综合。复杂反应速率与温度的依赖关系并不局限于经典的单调上升 Arrhenius 曲线，在化学工业与生命体系中广泛存在极大值型（如受吸附控制的多相催化或酶的热变性失活）及负活化能型（反常动力学，如 $2\mathrm{NO + O_2 \to 2NO_2}$ 因前置放热二聚平衡导致升温速率反而变慢）。

## §3 拟稳态近似（QSSA）与平衡假设（PEA）的数理判据与误差边界

在解析包含高活性自由基、金属络合物中间体的多步复杂反应历程时，直接求解高维非线性常微分方程组往往面临数理困难。为此，化学动力学确立了两种核心简化近似法。

拟稳态近似（Quasi-Steady-State Approximation, QSSA）假定高活性中间体在短暂的初始诱导期过后，其生成速率与消耗速率几乎实时动态抵消，宏观表现为其净积累速率与生成速率相比为极小量：$\frac{\mathrm{d}[I]}{\mathrm{d}t} \approx 0$。该假定的数学本质是建立代数消元方程替代微分方程。稳态法的适用性取决于中间体的活性：中间体的消耗速率必须远大于体系主物种的消耗速率，且中间体绝对浓度满足 $[I] \ll [A]$。

前置快速平衡假设（Pre-Equilibrium Approximation, PEA）假定复杂反应的前置可逆对峙步骤速率极快，而后续生成产物的步骤缓慢成为速率决定步（Rate-Determining Step, RDS）：$A + B \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} I \xrightarrow{k_2} P$（其中 $k_{-1} \gg k_2$）。此时中间体浓度直接由热力学平衡常数决定：$[I] = K_c [A][B] = \frac{k_1}{k_{-1}}[A][B]$，总速率表现为 $r = k_2 K_c [A][B]$。

| 对比维度 | 前置快速平衡假设（PEA） | 拟稳态近似法（QSSA） |
| :---: | :---: | :---: |
| 物理本质 | 前置步骤维持微观热力学动平衡 | 中间体产生速率与消耗速率动态相等 |
| 数学形式 | $[I] = \frac{k_1}{k_{-1}}[A][B]$ | $\frac{\mathrm{d}[I]}{\mathrm{d}t} = k_1[A][B] - (k_{-1} + k_2)[I] = 0$ |
| 最终速率表达式 | $r = \frac{k_1 k_2}{k_{-1}}[A][B]$ | $r = \frac{k_1 k_2}{k_{-1} + k_2}[A][B]$ |
| 适用严格判据 | 必须满足逆向解离远快于向前转化：$k_{-1} \gg k_2$ | 仅需中间体浓度极低且消耗快：$[I] \ll [A]$ |
| 理论包含关系 | 属于稳态近似在 $k_2 \to 0$ 极限下的特例 | 普适性更强，自然涵盖决速步在第一步或第二步的所有区间 |

在多路径交叉网络与支链反应中，通过对所有反应性中间体分别列写稳态代数方程，利用线性矩阵消元法消除所有不可观测的中间体浓度，即可推导出纯粹由宏观稳定反应物表示的表观速率方程与表观活化能表达式。

## §4 超快反应微扰弛豫动力学与溶液反应原盐效应

对于反应速率极快（半衰期达微秒至皮秒量级）的溶液平衡体系（如弱电解质质子转移、金属络合水合），传统混合进样速度（约毫秒级）受流体力学限制，无法捕捉初态动力学。微扰弛豫法（Relaxation Method）通过对平衡系统施加脉冲式外界微扰（如纳秒激光脉冲引起的温度跃变 T-jump、冲击波引起的压力跃变 P-jump），打破原化学平衡并监测系统向新平衡位置指数弛豫的速率。

以最简单的一级对峙反应 $A \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} B$ 为例，设体系跃迁至新温度后的最终新平衡浓度为 $\bar{c}_A, \bar{c}_B$。在弛豫过程任一时刻偏离新平衡位置的浓度扰动量为 $x(t) = c_A(t) - \bar{c}_A = \bar{c}_B - c_B(t)$。将浓度代入速率微分方程并消去满足新平衡的项 $k_1\bar{c}_A - k_{-1}\bar{c}_B = 0$，即得标准一阶线性弛豫方程：
$$\frac{\mathrm{d}x}{\mathrm{d}t} = -(k_1 + k_{-1})x \iff x(t) = x_0 \mathrm{e}^{-t/\tau}$$
其中定义弛豫时间 $\tau$ 为微扰量衰减至初始值 $1/\mathrm{e}$ 所需的时间：
$$\tau = \frac{1}{k_1 + k_{-1}}$$
对于双分子可逆结合体系 $A + B \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} C$，忽略二次扰动极小项 $x^2 \approx 0$ 后，导出特征线性弛豫公式：
$$\frac{1}{\tau} = k_1(\bar{c}_A + \bar{c}_B) + k_{-1}$$
实验测定不同平衡浓度下的弛豫时间 $\tau$，以 $1/\tau$ 对 $(\bar{c}_A + \bar{c}_B)$ 进行线性回归，直线的斜率即为双分子正向结合速率常数 $k_1$，纵截距即为单分子逆向解离速率常数 $k_{-1}$。

在电解质水溶液中，离子之间的长程库仑作用显著影响活化络合物的生成热力学。根据过渡态理论与 Debye-Hückel 稀溶液电离理论，两离子反应 $A^{z_A} + B^{z_B} \rightleftharpoons [X^\ddagger]^{z_A + z_B} \to \text{产物}$ 的表观速率常数满足著名的 Brønsted-Bjerrum 公式：
$$\lg k = \lg k_0 + 2 \times 0.509 z_A z_B \sqrt{I} \approx \lg k_0 + 1.02 z_A z_B \sqrt{I}$$
其中 $I = \frac{1}{2}\sum c_i z_i^2$ 为溶液离子强度，$k_0$ 为无限稀释理想状态下的速率常数。同号离子反应（$z_A z_B > 0$）表现出正原盐效应，增加惰性强电解质浓度使速率常数显著增大；异号离子反应（$z_A z_B < 0$）表现出负原盐效应；中性分子参与的反应（$z_A z_B = 0$）对离子强度不敏感。

## §5 自由基链反应机理与支链爆炸微分判据

自由基链式反应是燃烧、爆炸、高分子聚合与烃类裂解的普遍机理，其动力学历程严格分为链引发（Initiation）、链传递（Propagation）与链终止（Termination）三个阶段。在直链反应中，每个自由基参与反应生成一个等价的自由基，反应速率平缓可控。

当一个自由基参与反应能够生成两个或两个以上的新自由基时，构成支链反应（Branching-Chain Reaction）。设初始链引发速率为 $v_0$，分支速率为 $f[R]$，链销毁（气相或器壁吸附）速率为 $g[R]$。体系自由基浓度满足非齐次微分方程：
$$\frac{\mathrm{d}[R]}{\mathrm{d}t} = v_0 + (f - g)[R]$$
其动力学积分展现出截然相反的两类结果：

1. 若销毁能力占优势（$g > f$）：随着反应进行，自由基浓度收敛至有限稳态值 $[R]_{\mathrm{st}} = \frac{v_0}{g - f}$，反应平稳进行；

2. 若分支速率超过销毁速率（$f \ge g$）：微分方程表现为正反馈指数发散，自由基数量随时间呈几何级数爆炸式倍增，引发**支链爆炸**。

在 $p-T$ 状态相图上，经典的氢氧反应体系展现出独特的“爆炸半岛”形态。在恒温条件下随系统压力由低到高递增，体系经历三类明确的动力学边界：第一爆炸界限（低压下限）受器壁自由基扩散碰撞销毁控制；第二爆炸界限（高压上限）由气相三体碰撞链终止（如 $\mathrm{H\cdot + O_2 + M \to HO_2\cdot + M}$）主导，三体碰撞几率正比于压力平方 $p^2$，高压下销毁速率反超分支速率使爆炸熄灭；第三爆炸界限以上则由高压放热来不及耗散导致的**热爆炸**所接管。

## §6 酶催化动力学与非线性化学振荡建模

酶催化作为高效专一的生物化学过程，其经典动力学由 Michaelis 与 Menten 提出的单底物络合机理所奠定：
$$E + S \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} ES \xrightarrow{k_2} E + P$$
对中间络合物 $ES$ 应用拟稳态近似，结合游离酶与复合物的物料守恒 $[E]_0 = [E] + [ES]$，严格推导出米氏方程（Michaelis-Menten Equation）：
$$r = \frac{V_{\max}[S]}{K_M + [S]}$$
其中定义最大反应速率 $V_{\max} = k_2[E]_0$，米氏常数 $K_M = \frac{k_{-1} + k_2}{k_1}$。米氏方程在低底物浓度下呈现关于底物的一级动力学，在饱和高底物浓度下渐近趋于零级动力学。

为高精度求得 $K_M$ 与 $V_{\max}$，实验数据常用 Lineweaver-Burk 双倒数线性方程进行回归：
$$\frac{1}{r} = \frac{K_M}{V_{\max}}\frac{1}{[S]} + \frac{1}{V_{\max}}$$
其纵轴截距对应 $1/V_{\max}$，横轴截距对应 $-1/K_M$。竞争性抑制剂使 $K_M$ 增大而 $V_{\max}$ 不变，非竞争性抑制剂使 $V_{\max}$ 减小而 $K_M$ 不变。

在多相气-固催化中，固体表面吸附状态决定了反应速率方程的数学形态。Langmuir-Hinshelwood 机理认为反应发生在均一表面上两个相邻的化学吸附物种之间：$A(\text{ads}) + B(\text{ads}) \to P$。若两气体竞争吸附，速率方程为：
$$r = \frac{k K_A K_B p_A p_B}{(1 + K_A p_A + K_B p_B)^2}$$
该模型预言，当固定一反应物分压时，反应速率随另一反应物分压呈现先增大后减小的特征极大值，过高的吸附分压会导致活性位点被单一种类分子饱和阻塞。而 Eley-Rideal 机理则假定气相分子直接撞击吸附分子反应：$r = \frac{k K_A p_A p_B}{1 + K_A p_A}$，在高压下对吸附物种呈现零级、对气相撞击物种呈现一级。

## §7 典型真题与计算建模全解

### 例 1 · Stokes-Einstein 与最小二乘：由扩散测胶体与生物分子粒径

**题目（第 37 届中国化学奥林匹克初赛第 7 题第 7-1-1 问拓展）**：在 $25.0^\circ\mathrm{C}$（$298.15\ \mathrm{K}$）恒温条件下，通过脉冲梯度自旋回波核磁共振测定某种单分散球形微囊在不同黏度甘油-水混合溶剂中的扩散系数 $D$，实验数据如下表所示：

| 实验组 | 溶剂黏度 $\eta/(\mathrm{mPa\cdot s})$ | 扩散系数 $D/(10^{-11}\ \mathrm{m^2\cdot s^{-1}})$ |
| :---: | :---: | :---: |
| 1 | 0.890 | 4.88 |
| 2 | 1.150 | 3.78 |
| 3 | 1.500 | 2.90 |
| 4 | 2.000 | 2.17 |
| 5 | 2.500 | 1.74 |

试利用 Stokes-Einstein 关系式推导线性作图方程，采用最小二乘法进行线性拟合计算，求该球形微囊分子的有效水合半径 $r$（以 $\mathrm{nm}$ 为单位，玻尔兹曼常数取 $k_{\mathrm{B}} = 1.3806 \times 10^{-23}\ \mathrm{J\cdot K^{-1}}$）。

**详细微观解析**：

根据 Stokes-Einstein 扩散理论，球形粒子扩散系数满足 $D = \frac{k_{\mathrm{B}} T}{6\pi r} \cdot \frac{1}{\eta}$。令因变量 $y = D$（单位 $10^{-11}\ \mathrm{m^2\cdot s^{-1}}$），自变量 $x = \frac{1}{\eta}$（单位 $\mathrm{Pa^{-1}\cdot s^{-1}}$），理论方程严格为过原点的正比例线性模型：$y = m x$，斜率 $m = \frac{k_{\mathrm{B}} T}{6\pi r}$。

先对各组自变量 $x_i = \frac{1}{\eta_i}$ 进行精确计算：组 1 为 $x_1 = 1 / (0.890 \times 10^{-3}) = 1123.6\ \mathrm{Pa^{-1}\cdot s^{-1}}$，$y_1 = 4.88 \times 10^{-11}$；组 2 为 $x_2 = 1 / (1.150 \times 10^{-3}) = 869.6\ \mathrm{Pa^{-1}\cdot s^{-1}}$，$y_2 = 3.78 \times 10^{-11}$；组 3 为 $x_3 = 1 / (1.500 \times 10^{-3}) = 666.7\ \mathrm{Pa^{-1}\cdot s^{-1}}$，$y_3 = 2.90 \times 10^{-11}$；组 4 为 $x_4 = 1 / (2.000 \times 10^{-3}) = 500.0\ \mathrm{Pa^{-1}\cdot s^{-1}}$，$y_4 = 2.17 \times 10^{-11}$；组 5 为 $x_5 = 1 / (2.500 \times 10^{-3}) = 400.0\ \mathrm{Pa^{-1}\cdot s^{-1}}$，$y_5 = 1.74 \times 10^{-11}$。

对 5 组数据采用最小二乘法取最优斜率 $m = \frac{\sum x_i y_i}{\sum x_i^2}$：
$$\sum x_i y_i = 10^{-11} \times (1123.6 \times 4.88 + 869.6 \times 3.78 + 666.7 \times 2.90 + 500.0 \times 2.17 + 400.0 \times 1.74)$$
$$\sum x_i y_i = 10^{-11} \times (5483.2 + 3287.1 + 1933.4 + 1085.0 + 696.0) = 1.2485 \times 10^{-7}\ \mathrm{m^2\cdot Pa}$$
$$\sum x_i^2 = 1123.6^2 + 869.6^2 + 666.7^2 + 500.0^2 + 400.0^2 = 1262477 + 756204 + 444489 + 250000 + 160000 = 2.8732 \times 10^6\ \mathrm{Pa^{-2}\cdot s^{-2}}$$
拟合斜率为：
$$m = \frac{1.2485 \times 10^{-7}}{2.8732 \times 10^6} = 4.345 \times 10^{-14}\ \mathrm{m^2\cdot Pa\cdot s}$$
根据理论关系式 $m = \frac{k_{\mathrm{B}} T}{6\pi r}$，解得粒子流体力学半径：
$$r = \frac{k_{\mathrm{B}} T}{6\pi m} = \frac{1.3806 \times 10^{-23} \times 298.15}{6 \times 3.1416 \times 4.345 \times 10^{-14}} = \frac{4.116 \times 10^{-21}}{8.190 \times 10^{-13}} = 5.026 \times 10^{-9}\ \mathrm{m} \approx 5.03\ \mathrm{nm}$$
计算结果表明该微囊粒径约为 $10.0\ \mathrm{nm}$，完全符合单分散小单室脂质体纳米囊泡的理论尺度。

### 例 2 · 一级平行反应：温度如何调控选择性

**题目**：反应物 $A$ 经两条平行的基元反应路径转化为主产物 $B$ 和副产物 $C$：

路径 1：$A \xrightarrow{k_1} B, \quad E_{a,1} = 105.0\ \mathrm{kJ\cdot mol^{-1}}, \quad A_1 = 2.0 \times 10^{13}\ \mathrm{s^{-1}}$
路径 2：$A \xrightarrow{k_2} C, \quad E_{a,2} = 75.0\ \mathrm{kJ\cdot mol^{-1}}, \quad A_2 = 1.0 \times 10^{11}\ \mathrm{s^{-1}}$
(1) 计算在 $300\ \mathrm{K}$ 时产物浓度比 $[B]/[C]$；

(2) 计算在 $600\ \mathrm{K}$ 时产物浓度比 $[B]/[C]$；

(3) 欲使产物中主产物 $B$ 的选择性分数达到 $80.0\%$，反应温度应控制在多少绝对温度？

**详细微观解析**：

根据平行反应选择性原理，任何时刻产物浓度之比严格由两路径速率常数之比决定：
$$\frac{[B]}{[C]} = \frac{k_1}{k_2} = \frac{A_1}{A_2} \exp\left(-\frac{E_{a,1} - E_{a,2}}{RT}\right)$$
已知活化能差值 $\Delta E_a = E_{a,1} - E_{a,2} = 105.0 - 75.0 = 30.0\ \mathrm{kJ\cdot mol^{-1}} = 30000\ \mathrm{J\cdot mol^{-1}}$，指前因子之比 $\frac{A_1}{A_2} = \frac{2.0 \times 10^{13}}{1.0 \times 10^{11}} = 200$。

(1) 在 $T_1 = 300\ \mathrm{K}$ 下：
$$\frac{[B]}{[C]} = 200 \times \exp\left(-\frac{30000}{8.314 \times 300}\right) = 200 \times \exp(-12.028) = 200 \times 5.975 \times 10^{-6} = 1.195 \times 10^{-3}$$
低温下主产物占比极微，副产物 $C$ 占据绝对优势（选择性 $< 0.12\%$）。

(2) 在 $T_2 = 600\ \mathrm{K}$ 下：
$$\frac{[B]}{[C]} = 200 \times \exp\left(-\frac{30000}{8.314 \times 600}\right) = 200 \times \exp(-6.014) = 200 \times 2.444 \times 10^{-3} = 0.489$$
高温下主副产物比值剧烈提升了约 409 倍。

(3) 目标产物 $B$ 的选择性定义为 $S_B = \frac{[B]}{[B] + [C]} = \frac{k_1/k_2}{k_1/k_2 + 1} = 0.800$。

由此解得所需的比值：$\frac{k_1}{k_2} = \frac{0.800}{1 - 0.800} = 4.00$。

代入 Arrhenius 比值方程：
$$200 \times \exp\left(-\frac{30000}{8.314 T}\right) = 4.00 \implies \exp\left(-\frac{30000}{8.314 T}\right) = 0.0200$$
两边取自然对数：
$$-\frac{30000}{8.314 T} = \ln(0.0200) = -3.912 \implies T = \frac{30000}{8.314 \times 3.912} = \frac{30000}{32.524} = 922.4\ \mathrm{K}$$
动力学结论：高活化能路径在高温下具有更高的速率增长倍率，需将反应器加热至 $922\ \mathrm{K}$ 方可使高活化能的主产物占据 $80\%$ 主导优势。

### 例 3 · 竞争路径与由速率常数提取热力学量

**题目（第 37 届中国化学奥林匹克决赛第 2 场第 2-3 题）**：甲酸在水溶液中发生热催化裂解生成一氧化碳：$\mathrm{HCOOH(aq) \rightleftharpoons CO(aq) + H_2O(l)}$，真平衡常数为 $K$。体系由水相（体积 $V_{aq}$）与气相（体积 $V_g$）构成，生成的 $\mathrm{CO}$ 分配于两相之间，分配系数定义为 $K_D = \frac{[\mathrm{CO(g)}]}{[\mathrm{CO(aq)}]}$。定义表观产物总量与反应物平衡比 $Q = \frac{n_{\mathrm{CO},\text{总}}}{n_{\mathrm{HCOOH(aq)}}}$，设水相体积占总体积的分数为 $x_T = \frac{V_{aq}}{V_{aq} + V_g}$。

(1) 推导真化学平衡常数 $K$ 与 $Q, x_T, K_D$ 的解析表达式；

(2) 若由 van 't Hoff 方程测得 $\frac{\mathrm{d}\ln K}{\mathrm{d}(1/T)} = -6.908 \times 10^3\ \mathrm{K}$，求反应标准摩尔反应焓 $\Delta_r H_m^\theta$。

**详细微观解析**：

(1) 气相与液相中 $\mathrm{CO}$ 的物质的量分别为：$n_{\mathrm{CO(g)}} = V_g [\mathrm{CO(g)}] = V_g K_D [\mathrm{CO(aq)}]$，$n_{\mathrm{CO(aq)}} = V_{aq} [\mathrm{CO(aq)}]$。

总产物量为两相之和：
$$n_{\mathrm{CO},\text{总}} = n_{\mathrm{CO(g)}} + n_{\mathrm{CO(aq)}} = [\mathrm{CO(aq)}]\left(V_g K_D + V_{aq}\right)$$
代入表观平衡比 $Q$ 的定义式：
$$Q = \frac{n_{\mathrm{CO},\text{总}}}{V_{aq}[\mathrm{HCOOH(aq)}]} = \frac{[\mathrm{CO(aq)}]}{[\mathrm{HCOOH(aq)}]} \left(\frac{V_g}{V_{aq}}K_D + 1\right)$$
由液相真平衡常数定义 $K = \frac{[\mathrm{CO(aq)}]}{[\mathrm{HCOOH(aq)}]}$，且根据水积分数定义 $x_T = \frac{V_{aq}}{V_{aq} + V_g} \implies \frac{V_g}{V_{aq}} = \frac{1 - x_T}{x_T} = \frac{1}{x_T} - 1$。
将几何体积比代入展开：
$$Q = K \left[\left(\frac{1}{x_T} - 1\right)K_D + 1\right] = K \left[\frac{(1 - x_T)K_D + x_T}{x_T}\right]$$
变形解出真平衡常数 $K$：
$$K = \frac{x_T Q}{(1 - x_T)K_D + x_T}$$

(2) 根据 van 't Hoff 等压热力学方程：
$$\frac{\mathrm{d}\ln K}{\mathrm{d}(1/T)} = -\frac{\Delta_r H_m^\theta}{R}$$
已知实验斜率 $\frac{\mathrm{d}\ln K}{\mathrm{d}(1/T)} = -6.908 \times 10^3\ \mathrm{K}$，代入摩尔气体常数 $R = 8.314\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$：
$$\Delta_r H_m^\theta = -R \left(\frac{\mathrm{d}\ln K}{\mathrm{d}(1/T)}\right) = -8.314 \times (-6.908 \times 10^3) = +5.743 \times 10^4\ \mathrm{J\cdot mol^{-1}} \approx +57.4\ \mathrm{kJ\cdot mol^{-1}}$$
计算表明甲酸水相解离生成一氧化碳为吸热过程，升高温度使平衡显著正向移动。

### 例 4 · 双倒数作图判反应机理

**题目（第 38 届中国化学奥林匹克决赛第 5 题拓展）**：乙醇脱氢酶（ADH）催化乙醇与辅酶 $\mathrm{NAD}^+$ 反应生成乙醛与 $\mathrm{NADH}$。固定三种不同浓度的第一底物 $[\mathrm{NAD}^+]$，分别改变第二底物乙醇浓度 $[\mathrm{EtOH}]$ 测定初速率 $r$，以 $\frac{1}{r}$ 对 $\frac{1}{[\mathrm{EtOH}]}$ 作双倒数 Lineweaver-Burk 图，得到一组相交于负横轴与正纵轴之间的直线族。

(1) 若各直线在纵轴上的截距完全重合为单一点，且各直线交点恰好落在纵轴上，试判定其遵循何种微观机理；

(2) 实验测得直线族并非平行线，且纵截距随着 $[\mathrm{NAD}^+]$ 的降低而显著增大，相交点位于第二象限，试严格证明该反应遵循结合三元络合物的有序顺序（Ordered Bi-Bi）机理。

**详细微观解析**：

(1) 双底物反应若遵循萍蓬（Ping-Pong）穿梭机理，即第一底物反应后产物先行释放，酶转变为修饰态酶中间体，再结合第二底物。萍蓬机理的双倒数速率方程具有如下形式：
$$\frac{1}{r} = \frac{K_{M,S2}}{V_{\max}}\frac{1}{[S_2]} + \frac{1}{V_{\max}}\left(1 + \frac{K_{M,S1}}{[S_1]}\right)$$
在此机理下，改变 $[S_1]$ 仅改变纵截距，斜率 $\frac{K_{M,S2}}{V_{\max}}$ 严格保持恒定，作图表现为一族**严格平行的等斜率直线**。
若所有直线在纵轴重合为单一点（截距恒为 $\frac{1}{V_{\max}}$ 与 $[S_1]$ 无关），则表明 $S_1$ 结合是前置平衡且不影响最大转换数，属于特异性饱和。

(2) 有序顺序三元复合物（Ordered Sequential Bi-Bi）机理中，酶必须按严格先后次序结合底物：
$$E + S_1 \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} ES_1 \underset{k_{-2}}{\overset{k_2[S_2]}{\rightleftharpoons}} ES_1S_2 \xrightarrow{k_3} E + P_1 + P_2$$
对总酶量建立平衡物料守恒：$[E]_0 = [E] + [ES_1] + [ES_1S_2]$。
由稳态平衡解得各微观物种浓度，产物生成速率微分方程为：
$$r = \frac{V_{\max}[S_1][S_2]}{K_{M1}K_{M2} + K_{M2}[S_1] + [S_1][S_2]}$$
两边取倒数整理成关于 $\frac{1}{[S_2]}$ 的线性表达式：
$$\frac{1}{r} = \left[\frac{K_{M2}}{V_{\max}}\left(1 + \frac{K_{M1}}{[S_1]}\right)\right]\frac{1}{[S_2]} + \frac{1}{V_{\max}}\left(1 + \frac{K_{M2}}{[S_1]}\right)$$
从表达式可见：
在此双倒数图谱中，直线的**斜率**为 $m = \frac{K_{M2}}{V_{\max}}\left(1 + \frac{K_{M1}}{[S_1]}\right)$，随 $[S_1]$ 增大而单调减小；直线的**纵截距**为 $b = \frac{1}{V_{\max}}\left(1 + \frac{K_{M2}}{[S_1]}\right)$，同样随 $[S_1]$ 增大而单调减小。
因此各直线斜率与截距均随 $[S_1]$ 的变化而系统改变，直线族在第二象限相交于一点，该交叉点坐标由解联立方程确定，有力地证实了三元络合物 $ES_1S_2$ 的存在及顺序结合历程。

**1.** 测定化合物 S 的某一种酶催化反应速率时获得的实验数据如下表。试判定在下述浓度范围内的反应级数。

| t/min | 0 | 20 | 60 | 100 | 160 |
