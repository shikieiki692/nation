你是一名资深高中化学教师兼 PPT 设计专家。请基于下面的课程内容，**直接生成一份可用的 PowerPoint 演示文稿**（16:9，共 25 页，40–45 分钟），而不是输出文字稿。生成时严格遵循下面「模板要求」的化学元素主题设计规范。

## 一、模板要求（化学元素主题，必须遵守）

### 整体风格
- 主题：「化学元素」。专业、明亮、有化学学科辨识度，同时适合高一新生——不过度严肃、不幼稚。

### 配色（固定使用这组色板）
- 主色 钴蓝 `#1E6FB8`：标题、色条、强调线、按钮
- 辅色 翡翠绿 `#2FA36B`：数据强调、图标、元素卡片、勾选符号
- 背景 纯白 `#FFFFFF`，可搭配浅灰 `#F5F7FA` 做内容分区
- 正文文字 深灰 `#1F2937`；深底上的文字用纯白 `#FFFFFF`
- 装饰色：按周期表惯例点缀——金属类=青、非金属=绿、惰性气体=紫；仅作装饰，每页不超过 2 种

### 字体
- 中文标题：思源黑体 / 微软雅黑 Bold，大标题 32–36pt，页标题 24–28pt
- 中文正文：思源黑体 / 微软雅黑 Regular，14–18pt
- 数字与元素符号：Times New Roman / Arial，数据强调 20–24pt
- 同一页字号层次不超过 3 级

### 页面版式（六类）
1. **封面页**：顶部一条细元素周期表装饰带；主标题居中大号；副标题「高一·化学·开学第一课」；底部「遇见化学」。
2. **章节页**（Part 0–Part 5）：正中央一个大号**元素符号卡片**（元素符号 + 原子序数，对应关系见下方「元素符号装饰规则」），下方板块名 + 小计时长。
3. **内容页**：左上页标题（左侧带 4px 钴蓝色条）；要点区用**元素卡片式小圆标**作项目符号（圆形色块内放元素符号缩写或数字）；底部页脚放页码 + 一个浅色元素符号装饰。
4. **数据页**（P3 / P7 / P11）：关键数字用**元素卡片式大数字框**展示——像周期表单元格：粗边框方框 + 超大数字 + 下方一行小字说明，颜色用翡翠绿强调。
5. **图片页**：大图为主体，一句标题 + 底部一行小字说明；图按「配图关键词」从工具图库搜索。
6. **对比页**（P16）：左右双栏对比，左栏蓝色「初中」、右栏绿色「高中」，中间竖向分隔线。

### 元素符号装饰规则
- 章节页元素对应：Part 0 = **Ne**（点亮）、Part 1 = **H**（万物起点）、Part 2 = **C**（交叉中心）、Part 3 = **Fe**（淬炼）、Part 4 = **Au**（方法如金）、Part 5 = **He**（圆满）。
- 每页页脚放一个**不重复**的元素符号：按周期表顺序 H, He, Li, Be, B, C, N, O, F, Ne…，P1 放 H、P2 放 He，依次类推到 P25。
- 数据强调处可用「元素符号 + 原子序数」风格数字框（例如 48% 用一个大方框 + 小字「约一半人口」）。
- 装饰性元素符号用 10–15% 透明度的浅色做背景水印，不干扰正文阅读。

### 通用约束
- 16:9 比例；动画轻量（淡入即可），不炫技；图片高清、无水印。
- 每页要点 ≤5 条、每条 ≤12 字（数据密集页 P3/P7/P11 可放宽到 ≤18 字、整页 ≤5 条）。

## 二、课程背景

- 对象：**普通高一班新生**（无竞赛需求，全文禁止出现「竞赛/奥赛/集训」）
- 时长：40–45 分钟，共 **25 页**
- 语言：平实、口语化，不夸张、不说教、不煽情
- 定位：第一节化学课——让学生「看见」化学、认同化学与生活和国家发展相关、了解初高中变化并带走学习方法
- 数据：必须使用「素材库」中的真实内容，**禁止编造数字、案例、奖项**

## 三、素材库（数字必须原样使用，不得改动）

- **化肥与人口**：有统计认为化学肥料间接供养全球约 **48%** 人口（来源：新华网/中国农科院白由路）。
- **合成氨**：1909 年德国化学家哈伯实现，工程师博施工业化；氮肥让粮食大幅增产。
- **门捷列夫**：1869 年把当时已知 **63** 种元素排成周期表，留空位预言新元素；「类铝」=镓、「类硅」=锗，后被证实。
- **2025 诺贝尔化学奖**：授予北川进（日）、罗布森（澳）、亚吉（美/约旦）；成果为金属有机骨架（MOF），像「分子房子」的多孔晶体；几克 MOF 内部总面积≈一个足球场；可储气、碳捕集、空气净化、药物递送、半导体制造除毒气。
- **青蒿素**：屠呦呦团队从古籍找到线索、改造出抗疟药物，**2015** 年诺贝尔生理学或医学奖，中国本土科学家首次获科学类诺奖。
- **尼龙 66 / 己二腈**：己二腈是尼龙 66 核心原料（汽车轻量化、航空航天、高端瑜伽服/冲锋衣）；此前技术被国外垄断；**2025 年 12 月**中国化学天辰齐翔（山东）年产 **20 万吨**己二腈装置达产。
- **稀土**：17 种金属元素（镧系+钪、钇），不是「土」也不真的稀有，难在互相分离；中国储量全球第一约 **36%**（2024）、开采量占全球 **60%** 以上、精炼产能约 **90%**；我国化学家徐光宪上世纪 70 年代建立串级萃取理论，获 **2008** 年国家最高科学技术奖；应用：手机振动马达、新能源汽车电机、风力发电、光刻机玻璃。
- **生活化学**：人体元素（缺铁贫血、缺碘甲状腺问题）；食品保存（盐腌/冷藏/真空）；⚠️ 84 消毒液 + 洁厕灵混用会产生有毒氯气。
- **初高中衔接依据**：《普通高中化学课程标准（2017 年版 2020 年修订）》核心素养——「宏观辨识与微观探析」「证据推理与模型认知」；《义务教育化学课程标准（2022 年版）》核心素养——「化学观念、科学思维、科学探究与实践、科学态度与责任」；衔接研究共识——「初中多靠记忆、高中重在逻辑推理」。

### P3 你碗里的饭，有化学的功劳（化学×农业）
- 要点：约一半人口靠化肥增产 / 合成氨：哈伯（1909）→ 博施 / 化学和「吃饭」直接相关
- 配图关键词：农田麦穗大图
- 备注：全球约 48% 人口靠化肥间接供养；1909 年哈伯把空气里的氮气变成氮肥，博施工业化，化肥让粮食大幅增产。（来源：新华网/白由路）（→ 下页：那化学到底是什么？）（1.5 min）

### P4 化学是什么
- 要点：在原子、分子水平研究 / 组成 · 结构 · 性质 · 转化

### P5 化学家做三件事
- 要点：识别——这是什么 / 创造——造出新物质 / 解释——为什么这样
- 配图关键词：实验室中的科学家

### P6 一张表的故事
- 要点：元素周期表 / 门捷列夫 1869 / 63 种元素 → 预言新元素

### P7 2025 诺贝尔化学奖（MOF）
- 要点：金属有机骨架（MOF） / 「分子房子」多孔晶体 / 几克 ≈ 一个足球场 / 储气 · 碳捕集 · 送药

- 备注：授予北川进、罗布森、亚吉。大白话：MOF 像分子搭的「房子」，里面能装气体、送药物。（来源：诺贝尔奖官方/知识库）（→ 下页：化学为什么这么重要？因为它是中心科学。）（2 min）

### P8 化学是中心科学
