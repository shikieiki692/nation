# 备课大纲

> 本目录存放各课次的**备课大纲**，共 **64 个 .md 文件**。
> 文件命名格式：`YYYY-MM-DD-{主题}-{班型}.md`
> 备课大纲是讲义和课件的上游规划文件，定义每次课的教学目标、知识点覆盖、时间分配。

---

## 📂 组织方式

按日期和主题组织，覆盖四个轮次：

| 轮次 | 典型主题 | 说明 |
|------|---------|------|
| 第一轮基础班 | 原子结构、分子结构、晶体结构、化学平衡、酸碱理论等 | 竞赛入门 |
| 第二轮提高班 | 配位化学、元素化学、有机化学等 | 系统深化 |
| 第三轮 | 有机化学深化（重排、周环、波谱等） | 专题突破 |
| 冲刺班 | 真题拆解、综合训练 | 考前冲刺 |
