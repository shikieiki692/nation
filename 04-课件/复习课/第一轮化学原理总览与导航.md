# 第一轮化学原理总览与导航

> 定位：把第一轮化学原理的**新授课、复习课、习题课、跨模块接口**压到一页里，后续备课、排课、巡检、补讲都从这里进。

---

## 一、内容边界

第一轮化学原理当前主干覆盖 9 个核心模块：

1. 气体与溶液
2. 热力学初步
3. 化学动力学初步
4. 化学平衡
5. 酸碱理论
6. 沉淀溶解平衡
7. 电化学
8. 溶液与相图
9. 定量化学分析

> 建议理解方式：这 9 个模块不是并列散点，而是三层结构。
>
> 第一层是**工具层**：气体、溶液、计量与方程式语言。
>
> 第二层是**核心判断链**：热力学 → 平衡 → 动力学。
>
> 第三层是**特殊应用场景**：酸碱、沉淀、电化学、分析。

### 3.2 更稳的教学理解

- `气体与溶液`：补齐分压、浓度、状态量语言
- `热力学初步`：回答“能不能”
- `化学平衡`：回答“到哪里停”
- `化学动力学初步`：回答“多快到”
- `酸碱 / 沉淀 / 电化学`：都是 Q/K 判断链的特例
- `溶液与相图 / 定量分析`：把前面语言真正落到复杂体系

> 如果班上模型切换能力弱，建议把 `化学动力学初步` 放到 `化学平衡` 后面讲评式处理。

## 四、每一模块最该抓住什么

| 模块 | 最核心的问题 | 学生最容易错在哪里 | 讲完后至少要会什么 |
| --- | --- | --- | --- |
| 气体与溶液 | 状态量怎么表达 | 单位乱、分压和总压混 | 会在题目里稳定写出浓度和分压 |
| 热力学初步 | 反应能不能发生 | 把 ΔG、ΔH、放热吸热混成一团 | 会用 ΔG 判断自发方向 |
| 化学动力学初步 | 反应有多快 | 把“能发生”和“发生得快”混淆 | 会区分热力学与动力学 |
| 化学平衡 | 体系到哪里停 | Le Chatelier 机械套用，不回到 Q/K | 会用 Q 和 K 判断移动方向 |
| 酸碱理论 | 质子转移如何定量 | 守恒式写不全、近似乱用 | 会做单一弱酸弱碱与缓冲 |
| 沉淀溶解平衡 | 什么时候沉、什么时候溶 | 只背 Ksp，不会写 Q | 会做沉淀判据和简单分步沉淀 |
| 电化学 | 电势和方向怎么连 | 电极正负、阴阳极、E 与 ΔG 混乱 | 会写电池反应并用 Nernst |
| 溶液与相图 | 非理想溶液怎么描述 | 把依数性和相图拆成两套语言 | 会把溶液性质和相行为接起来 |
| 定量化学分析 | 计算怎么真正落地 | 方程式、滴定、守恒链断裂 | 会把守恒、平衡、计量串起来 |

## 五、三条最重要的跨模块链

### 5.1 判断链

`热力学初步 → 化学平衡 → 化学动力学初步`

- 热力学决定“能不能”
- 平衡决定“停在哪”
- 动力学决定“多快到”

### 5.2 平衡特例链

`化学平衡 → 酸碱理论 → 沉淀溶解平衡 → 电化学`

- 四者底层都是“反应商 Q 与平衡常数 K 的比较”
- 电化学只是把 Q/K 语言改写成了电势语言

### 5.3 计算落地链

`气体与溶液 → 化学平衡 → 定量化学分析`

- 前者提供表达变量
- 中间给出模型
- 最后落实到守恒、滴定和综合计算
