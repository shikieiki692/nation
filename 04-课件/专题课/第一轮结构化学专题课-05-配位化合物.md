## 一、开场·真题直击（10 min）

### 真题1：37届初赛第5题 5-3 — Ru配合物d轨道分裂+磁性

> **5-3** 为理解金属离子在相关过程的作用，开展了如下研究：空气中，络离子A（[Ru(EDTA)(OH)]²⁻, EDTA为乙二胺四乙酸根）的溶液中，加入NaHS溶液并充分搅拌，溶液变为蓝绿色，对应于双核络离子B的生成（反应4）。分别取A和B的溶液，在惰性气体保护下，加入被NO饱和的磷酸盐缓冲液(pH=8.2)，充分反应，A转化为C，B转化为D（反应5）。借助于质谱分析，计算出四个络离子的式量分别为A: 406.3, B: 842.7, C: 419.3, D: 451.4。磁性测量发现，C为抗磁性，D为顺磁性。
>
> **5-3-1** 写出络离子B、C、D的结构简式。
>
> **5-3-2** 写出反应4和5的离子方程式。
>
> **5-3-3** 画出C和D中金属离子d轨道在八面体场（近似看作正八面体）中的分裂图并给出d电子排布。

**分值**：约8分 | **建议用时**：8 min

**课堂操作**：先给学生2 min独立分析A→B→C→D的转化关系，然后收卷统计思路正确率，再讲解析。

### 解析

**第一步：由式量确定各络离子组成**

已知A = [Ru(EDTA)(OH)]²⁻，式量406.3。分析转化关系：

| 络离子 | 式量 | 与前驱物差值 | 推断 |
|:---:|:---:|:---:|:---|
| A | 406.3 | — | [Ru(EDTA)(OH)]²⁻ |
| B | 842.7 | ≈ 2A − 2H⁺ + S | 双核，含硫桥联 |
| C | 419.3 | A + 13 | A中OH⁻被NO取代（质量差=30−17=13） |
| D | 451.4 | C + 32 | C再结合一个OH⁻（质量差≈17，实际含水合修正） |

**关键推断**：

- **C = [Ru(EDTA)(NO)]⁻**：C为抗磁性，说明Ru的d电子全部成对。Ru²⁺为d⁶构型，在强场配体NO⁺（线型NO作为3电子给体，等效NO⁺）作用下，d电子全部填入$t_{2g}$轨道（$t_{2g}^{6}e_{g}^{0}$），无未成对电子 → 抗磁性。

- **D = [Ru(EDTA)(NO)(OH)]²⁻**：D为顺磁性。Ru³⁺为d⁵构型，$t_{2g}^{5}e_{g}^{0}$，有1个未成对电子（来自$t_{2g}$上未配对的电子），同时NO上也有未成对电子 → 顺磁性。

- **B**：式量842.7 ≈ 2 × 406.3 − 2 + 32，由NaHS提供硫，形成含μ-S桥联的双核Ru配合物。结合EDTA的六齿配位特性，B为两个Ru中心通过硫桥和可能的桥联OH连接。

**第二步：写出结构简式（5-3-1）**

**C的结构**（八面体，Ru²⁺）：

**[Ru(EDTA)(NO)]⁻ 结构特征**：Ru²⁺(d⁶)中心，EDTA六齿配位（2N+4O）+ NO轴向配位 → 八面体构型。$t_{2g}^{6}e_{g}^{0}$，无未成对电子，抗磁性。

EDTA以六齿方式配位（2N + 4O），NO沿轴向配位，构成近似八面体构型。

**D的结构**（八面体，Ru³⁺）：

**[Ru(EDTA)(NO)(OH)]²⁻ 结构特征**：Ru³⁺(d⁵)，EDTA六齿 + NO + OH → 七配位。$t_{2g}^{5}e_{g}^{0}$，1个未成对电子，顺磁性。

EDTA六齿配位 + NO + OH⁻，共7个配位原子 → 七配位（近似八面体+1额外配位），或EDTA以五齿方式配位，留下一个位置给OH⁻。

**B的结构**（双核）：

**[Ru₂(EDTA)₂(μ-S)(OH)]³⁻ 结构特征**：两个Ru³⁺中心通过μ-S桥联，每个Ru由EDTA六齿配位。三核配合物与NaHS反应的产物。

**第三步：写出离子方程式（5-3-2）**

**反应4**（A + NaHS → B）：

$$2[\text{Ru(EDTA)(OH)}]^{2-} + \text{HS}^{-} \rightarrow [\text{Ru}_2\text{(EDTA)}_2\text{(μ-S)(OH)}]^{3-} + \text{H}_2\text{O} + \text{OH}^{-}$$

空气中搅拌，Ru²⁺可能被部分氧化为Ru³⁺，形成混合价态双核配合物。

**反应5**（A/B + NO → C/D）：

$$[\text{Ru(EDTA)(OH)}]^{2-} + \text{NO} \rightarrow [\text{Ru(EDTA)(NO)}]^{-} + \text{OH}^{-}$$

$$[\text{Ru}_2\text{(EDTA)}_2\text{(μ-S)(OH)}]^{3-} + \text{NO} + \text{OH}^{-} \rightarrow [\text{Ru(EDTA)(NO)(OH)}]^{2-} + \text{产物}$$

**第四步：画d轨道分裂图（5-3-3）**

> 来源：[[d轨道分裂]]、[[晶体场分裂与磁性]]

**八面体场d轨道分裂**：5个简并d轨道分裂为两组——

- **$t_{2g}$**（3个轨道，低能级）：$d_{xy}$, $d_{xz}$, $d_{yz}$
- **$e_{g}$**（2个轨道，高能级）：$d_{z^2}$, $d_{x^2-y^2}$

分裂能记为$\Delta_o$（或$10\text{Dq}$）。

**C中Ru²⁺（d⁶）的排布**：

![Ru²⁺ d⁶低自旋排布](media/cft-octahedral-d6-lowspin.png)
*Ru²⁺(d⁶)：Δₒ > P（强场），t₂g全充满，抗磁性*

$t_{2g}^{6}e_{g}^{0}$：6个d电子全部成对填入$t_{2g}$，无未成对电子 → 抗磁性。

**D中Ru³⁺（d⁵）的排布**：

![Ru³⁺ d⁵低自旋排布](media/cft-octahedral-d5-lowspin.png)
*Ru³⁺(d⁵)：Δₒ > P（强场），t₂g⁵有1个单电子，顺磁性*

$t_{2g}^{5}e_{g}^{0}$：5个d电子中4个成对填入$t_{2g}$的两个轨道，第5个电子单独占据$t_{2g}$的第三个轨道 → 1个未成对电子 → 顺磁性。

> ⚠️ **易错提醒**
> - NO在配合物中通常以**线型M-N-O**方式配位，作为**3电子给体**（等效NO⁺），是**强场配体**（π受体），能导致d电子全部成对。
> - 不要把NO和NO₂⁻混淆——NO₂⁻是弯曲配位（1电子给体），场强弱于NO。
> - 抗磁性 ≠ 无d电子，而是**所有d电子全部成对**。d⁶在强场中$t_{2g}^{6}$就是抗磁性的经典例子。

## 二、知识拆解（15 min）

本节针对配位化合物推断题暴露的八个核心工具做**定向串讲**。不求面面俱到，只求考场能用。

### 工具1：配位化合物推断链7步流程

> 来源：[[配位化学]]

拿到任何配合物推断题，按以下步骤依次操作：

| 步骤 | 操作 | 关键问题 |
|:---:|:---|:---|
| **1** | 由式量/元素分析确定**化学式** | 配位数？配体种类？ |
| **2** | 由反应条件/产物确定**氧化态** | 金属是几价？ |
| **3** | 由氧化态计算**d电子数** | dⁿ中n = ? |
| **4** | 由配位数确定**几何构型** | 八面体？四面体？平面正方？ |
| **5** | 由配体类型判断**场强**（光谱化学序列） | 强场还是弱场？ |
| **6** | 由场强确定**高/低自旋**（仅d⁴-d⁷有选择） | 未成对电子数n = ? |
| **7** | 画**d轨道分裂图** → 算**CFSE** → 判断**磁性** | 抗磁/顺磁？μ = ? |

**口诀**："化氧d几配几场，高低自旋磁CFSE"

**考场应用**：不要跳步！每一步的结论都是下一步的前提。氧化态错 → d电子数错 → 全盘皆错。

### 工具2：d轨道分裂三步法

> 来源：[[d轨道分裂]]

**第一步：画5条等能级线**

$$\text{d}_{z^2} \quad \text{d}_{x^2-y^2} \quad \text{d}_{xy} \quad \text{d}_{xz} \quad \text{d}_{yz}$$

**第二步：按几何构型分裂**

| 构型 | 分裂方式 | 低能级 | 高能级 |
|:---:|:---:|:---:|:---:|
| **八面体** | 3 + 2 | $t_{2g}$（$d_{xy}, d_{xz}, d_{yz}$） | $e_g$（$d_{z^2}, d_{x^2-y^2}$） |
| **四面体** | 2 + 3 | $e$（$d_{z^2}, d_{x^2-y^2}$） | $t_2$（$d_{xy}, d_{xz}, d_{yz}$） |
| **平面正方** | 1 + 2 + 1 + 1 | $d_{xy}$ → $d_{z^2}$ → $d_{xz},d_{yz}$ → $d_{x^2-y^2}$ |

**第三步：填电子**

- 弱场（$\Delta$ 小）：先尽量单占（ Hund 规则）→ **高自旋**
- 强场（$\Delta$ 大）：先填满低能级 → **低自旋**

### 工具3：光谱化学序列——σ/π理解框架

> 来源：[[光谱化学序列]]、[[配体类型与电子给受性质]]

**光谱化学序列**（场强由弱到强）：

$$\text{I}^- < \text{Br}^- < \text{Cl}^- < \text{F}^- < \text{OH}^- < \text{H}_2\text{O} < \text{NH}_3 < \text{en} < \text{NO}_2^- < \text{CN}^- < \text{CO}$$

**σ/π理解框架**（三类配体）：

| 配体类型 | 机制 | 场强 | 典型配体 |
|:---|:---|:---:|:---|
| **π给体** | 配体π轨道向金属d轨道**给电子** → 抬高$t_{2g}$ → 减小$\Delta_o$ | **弱场** | I⁻, Br⁻, Cl⁻, F⁻, OH⁻ |
| **纯σ给体** | 仅σ配位，无π作用 | **中等** | H₂O, NH₃, en |
| **π受体** | 配体π*轨道从金属d轨道**拉电子** → 降低$t_{2g}$ → 增大$\Delta_o$ | **强场** | NO₂⁻, CN⁻, CO, NO |

**考场速记**：
- 卤素离子全是π给体 → 弱场 → 高自旋
- NH₃是纯σ给体 → 中等场
- CN⁻、CO、NO是π受体 → 强场 → 低自旋

### 工具4：高/低自旋判断——只有d⁴-d⁷有选择

> 来源：[[晶体场分裂与磁性]]

| d电子数 | 弱场（高自旋） | 强场（低自旋） | 未成对电子数差 |
|:---:|:---:|:---:|:---:|
| d¹ | ↑ | ↑ | 0 |
| d² | ↑↑ | ↑↑ | 0 |
| d³ | ↑↑↑ | ↑↑↑ | 0 |
| **d⁴** | ↑↑↑↑ | ↑↑↑↓ | **1** |
| **d⁵** | ↑↑↑↑↑ | ↑↑↓↓↓ | **3** |
| **d⁶** | ↑↑↓↑↑↓ | ↑↓↑↓↑↓ | **4** |
| **d⁷** | ↑↑↓↑↑↓↑ | ↑↓↑↓↑↓↑ | **2** |
| d⁸ | ↑↓↑↓↑↓↑↑ | ↑↓↑↓↑↓↑↑ | 0 |
| d⁹ | ↑↓↑↓↑↓↑↓↑ | ↑↓↑↓↑↓↑↓↑ | 0 |
| d¹⁰ | ↑↓↑↓↑↓↑↓↑↓ | ↑↓↑↓↑↓↑↓↑↓ | 0 |

**关键结论**：
- **d¹-d³、d⁸-d¹⁰**：无论场强如何，只有一种排布 → 无需判断高/低自旋
- **d⁴-d⁷**：必须结合光谱化学序列判断 → 这是考点！
- **d⁶强场**（如[Fe(CN)₆]⁴⁻、[Ru(EDTA)(NO)]⁻）：$t_{2g}^{6}e_{g}^{0}$，全部成对 → **抗磁性**

### 工具5：CFSE计算速查表

> 来源：[[CFSE计算流程]]

**晶体场稳定化能**（CFSE）公式：

$$\text{CFSE} = (-0.4x + 0.6y) \Delta_o + \text{额外成对能修正}$$

其中$x$ = $t_{2g}$电子数，$y$ = $e_g$电子数。

**八面体场CFSE速查**：

| d电子 | 高自旋CFSE | 低自旋CFSE | 选哪个？ |
|:---:|:---:|:---:|:---:|
| d⁰ | 0 | 0 | — |
| d¹ | −0.4$\Delta_o$ | −0.4$\Delta_o$ | 相同 |
| d² | −0.8$\Delta_o$ | −0.8$\Delta_o$ | 相同 |
| d³ | −1.2$\Delta_o$ | −1.2$\Delta_o$ | 相同 |
| d⁴ | −0.6$\Delta_o$ | −1.6$\Delta_o$ + P | 强场有利 |
| d⁵ | 0 | −2.0$\Delta_o$ + 2P | 强场有利 |
| d⁶ | −0.4$\Delta_o$ | −2.4$\Delta_o$ + 2P | 强场有利 |
| d⁷ | −0.8$\Delta_o$ | −1.8$\Delta_o$ + P | 看$\Delta_o$ vs P |
| d⁸ | −1.2$\Delta_o$ | −1.2$\Delta_o$ | 相同 |
| d⁹ | −0.6$\Delta_o$ | −0.6$\Delta_o$ | 相同 |
| d¹⁰ | 0 | 0 | — |

**注意**：P = 电子成对能。当$\Delta_o$ > P时选低自旋，$\Delta_o$ < P时选高自旋。

**四面体场CFSE**：$\Delta_t = \frac{4}{9}\Delta_o$，四面体场几乎总是弱场 → 几乎总是高自旋。

### 工具6：仅自旋磁矩公式

> 来源：[[抗磁性]]

$$\boxed{\mu_s = \sqrt{n(n+2)} \;\mu_B}$$

其中$n$ = 未成对电子数。

**速查表**：

| $n$（未成对电子数） | $\mu_s$（$\mu_B$） | 常见实例 |
|:---:|:---:|:---|
| 0 | 0 | 抗磁性：[Fe(CN)₆]⁴⁻, [Co(NH₃)₆]³⁺ |
| 1 | 1.73 | [Cu(NH₃)₄]²⁺, Ru(EDTA)(NO)]⁻ |
| 2 | 2.83 | [Ni(H₂O)₆]²⁺ |
| 3 | 3.87 | [Cr(H₂O)₆]³⁺, [CoF₆]³⁻ |
| 4 | 4.90 | [Fe(H₂O)₆]²⁺ |
| 5 | 5.92 | [Fe(H₂O)₆]³⁺, [Mn(H₂O)₆]²⁺ |

**考场注意**：实验值常比仅自旋值偏高（尤其是第一过渡系的$d^4-d^7$构型），因为轨道角动量贡献未完全猝灭。$d^1, d^2, d^6, d^7$的$T$态基谱项轨道贡献显著。

### 工具7：Cr-Cr四重键（σ + 2π + δ）

> 来源：[[多核簇]]

**四重键的组成**（设Cr-Cr沿z轴）：

| 键类型 | 参与轨道 | 键级贡献 |
|:---:|:---|:---:|
| **σ键** | $d_{z^2}$ − $d_{z^2}$ 头对头重叠 | 1 |
| **2个π键** | $d_{xz}$ − $d_{xz}$, $d_{yz}$ − $d_{yz}$ 侧面重叠 | 2 |
| **δ键** | $d_{xy}$ − $d_{xy}$ 面对面重叠 | 1 |
| **总计** | | **4** |

**四重键特征**：
- 键长短于单键（如Cr₂(OAc)₄中Cr-Cr = 2.36 Å，远短于Cr单键约2.5 Å）
- **抗磁性**：四重键中8个电子全部成对 → 无未成对电子
- $d_{x^2-y^2}$不参与Cr-Cr成键，用于与配体σ配位

**Cr₂(OAc)₄(H₂O)₂结构**：桨轮型（paddlewheel），两个Cr之间四重键，四个醋酸根桥联两个Cr，两个轴向水分子。

**无水 vs 水合**：水合物中轴向H₂O与Cr的$d_{z^2}$有微弱相互作用，略微削弱Cr-Cr δ键 → 无水物Cr-Cr键长**更短**（无轴向配体干扰δ重叠）。

### 工具8：异构体枚举法

> 来源：[[配位数]]、[[八面体配位]]

**系统枚举四步法**：

1. **固定一个配体位置**（消除旋转等价）
2. **排列其余配体**
3. **去重**（对称操作等价的只算一个）
4. **查手性**（有无对映异构体）

**八面体配合物MA₂B₄型**：2种异构体（顺式/反式）

**八面体配合物MA₂B₂C₂型**：

| 异构体 | 相同配体位置关系 | 手性 |
|:---:|:---|:---:|
| 全反式 | 三对相同配体均互为反位 | 无 |
| 两顺一反 | 两对顺式，一对反式 | 无 |
| 一顺两反 | 一对顺式，两对反式 | **有**（存在对映体） |
| 全顺式 | 三对相同配体均互为顺式 | **有**（存在对映体） |

**快速判断手性**：看配合物有无$S_n$轴（含$S_4$=旋转180°+镜面反映）。无$S_n$轴 → 手性 → 有对映体。

### 补充：配合物基础与螯合效应（考纲§12.1-12.2, 12.5）

**配位键基本概念（§12.1）：**
- 配位键 = 一方提供孤对电子，另一方提供空轨道
- 配体：提供孤对电子的分子或离子
- 中心原子/离子：接受孤对电子的金属离子
- 配位数：直接与中心原子成键的配位原子数

**螯合效应（§12.2）：**
- 螯合物 = 含多齿配体的配合物（en=二齿, EDTA=六齿）
- 螯合效应：螯合物比同类单齿配体配合物更稳定
- 本质：**熵驱动**——螯合反应释放更多配体分子，ΔS > 0
- 例：[Ni(NH₃)₆]²⁺ + 3en → [Ni(en)₃]²⁺ + 6NH₃，K >> 1

**配合反应与其他反应的关联（§12.5）：**
- 配位 vs 沉淀：AgCl + 2NH₃ → [Ag(NH₃)₂]⁺ + Cl⁻（配位消耗Ag⁺→沉淀溶解）
- 配位 vs 氧化还原：[Fe(CN)₆]⁴⁻比[Fe(H₂O)₆]²⁺更难被氧化（CN⁻强场→低自旋d⁶→CFSE大→稳定）

## 三、真题精练（15 min）

### 真题2：36届二场第5题 — Ni高价配合物+磁矩+t₂g/eₘ

> **5-1** 镍在化合物中的常见氧化数是+2，但在一定条件下，可制得其高价化合物。将KCl和NiCl₂按一定计量比混合与F₂反应，300°C下得到紫色顺磁性晶体A（反应1），275°C下得到红色抗磁性晶体B（反应2）。A和B中的络离子均为正八面体构型。A和B遇水均放出氧气，并得到具有金红石型结构的化合物C（反应3和反应4）。若在真空下处理，A可以稳定到450°C，而B在350°C即分解（反应5），放出浅黄色气体，固体中检出A和C且二者摩尔比为2:1。A在液态HF中发生歧化（反应6），产物中含B和C，而B在液态HF中与足量BF₃发生反应形成红色沉淀（反应7）。B还可与强Lewis酸BiF₅混合形成固体推进剂，引发后放出浅黄色气体（反应8）。
>
> **5-1** 写出A的化学式和磁矩（单位：μB）。写出B的化学式及其中镍离子价层电子组态（要求：用$t_{2g}^{x}e_{g}^{y}$方式表示，x和y分别代表电子数）。（提示：A和B中络离子的晶体场分裂能近似相等。）

**分值**：约10分 | **建议用时**：7 min

### 解析

**第一步：推断C**

A和B遇水均放出O₂，得到**金红石型结构**的C。金红石（rutile）是TiO₂的典型结构。Ni的氟化物中，**NiF₂具有金红石结构**。

→ **C = NiF₂**

**第二步：推断A的化学式和磁矩**

A为**紫色顺磁性**晶体，八面体构型。A真空下稳定到450°C，B分解时产生A和C（摩尔比2:1）且放出浅黄色气体（F₂）。

设A = K₃NiF₆（Ni为+3价，d⁷）：

- **验证**：Ni³⁺在八面体弱场（F⁻为弱场配体）中，d⁷ → 高自旋
- 价层电子组态：$t_{2g}^{5}e_{g}^{2}$
- 未成对电子数：**3个**
- 磁矩：$\mu = \sqrt{3(3+2)} = \sqrt{15} \approx$ **3.87 μB**

**A = K₃NiF₆**，磁矩 ≈ **3.87 μB**

**第三步：推断B的化学式和电子组态**

B为**红色抗磁性**晶体，八面体构型，B分解产生A和C且摩尔比2:1，放出F₂。

设B中Ni为+4价（d⁶）。由分解反应推断B的组成：

B分解：$2\text{A} + \text{C} + \text{F}_2$

即B → 2K₃NiF₆ + NiF₂ + F₂

配平得：$\text{K}_{10}\text{Ni}_2\text{F}_{14} \rightarrow 2\text{K}_3\text{NiF}_6 + \text{NiF}_2 + 3\text{F}_2$

但此式量不符。考虑B为含Ni⁴⁺的八面体络离子化合物：

**B = K₂NiF₆**（或K₃NiF₆的含Ni⁴⁺类似物）

Ni⁴⁺为**d⁶**构型。B为**抗磁性** → 所有d电子全部成对 → 低自旋排布：

$$t_{2g}^{6}e_{g}^{0}$$

**关键**：虽然F⁻通常是弱场配体，但Ni⁴⁺电荷极高（+4），有效核电荷大 → 极化能力强 → 实际$\Delta_o$很大 → 足以使d⁶全部成对。

题目提示"A和B中络离子的晶体场分裂能近似相等" → 同为八面体[F₆]单元，$\Delta_o$相近。A的d⁷高自旋（$\Delta_o$ < P），B的d⁶低自旋（$\Delta_o$ > P）——这是合理的，因为d⁶只需$\Delta_o$ > P即可低自旋，而d⁷需要$\Delta_o$ > P + 额外能量才能低自旋。

**答案汇总**：

| 项目 | A | B |
|:---|:---|:---|
| 化学式 | K₃NiF₆ | K₂NiF₆ |
| Ni氧化态 | +3 | +4 |
| d电子数 | d⁷ | d⁶ |
| 组态 | $t_{2g}^{5}e_{g}^{2}$ | $t_{2g}^{6}e_{g}^{0}$ |
| 磁性 | 顺磁性（3个未成对电子） | 抗磁性（无未成对电子） |
| 磁矩 | ≈ 3.87 μB | 0 |

> ⚠️ **易错提醒**
> - d⁷在弱场中高自旋$t_{2g}^{5}e_{g}^{2}$有3个未成对电子，**不是**4个！$t_{2g}$中3个轨道先各填1个（3个↑），再填2个到$e_g$（2个↑），然后$t_{2g}$开始配对（第5个电子配对）。正确排布：$t_{2g}$有1对+1单，$e_g$有2个单 → 共3个未成对电子。
> - d⁶在强场中低自旋$t_{2g}^{6}e_{g}^{0}$是**抗磁性的经典例子**，与真题1中Ru²⁺(d⁶)的情况相同。
> - 高价态（+3、+4）金属的有效核电荷大，实际$\Delta_o$远大于仅由配体场强推断的值。

### 真题3：38届初赛第6题 — Cr-Cr四重键

> **6-1-4** 醋酸亚铬水合物为抗磁性，其中Cr均为六配位，画出醋酸亚铬水合物的结构式(本题画图时AcO⁻可用○表示)，并指出Cr-Cr键的键级。
>
> **6-1-5** 该水合物中Cr-Cr π键来自于Cr的d轨道。假定Cr-Cr为z轴方向，写出形成π键的d轨道名称。
>
> **6-1-6** 醋酸亚铬在水溶液中很容易被空气氧化，其中一个产物为+1价的三核Cr³⁺配合物阳离子。该阳离子中Cr³⁺与AcO⁻的比例与醋酸亚铬中Cr原子与AcO⁻的比例相同，三个Cr³⁺环境等价，均为6配位，其中一个配体是水分子，不存在Cr-Cr键。画出该三核配合物的结构式。
>
> **6-2-3** 与醋酸亚铬水合物相比，无水醋酸亚铬中Cr-Cr键长（）。(a) 更长 (b) 更短 (c) 相同

**分值**：约8分 | **建议用时**：6 min

### 解析

**6-1-4 醋酸亚铬水合物结构**

Cr₂(OAc)₄(H₂O)₂为**桨轮型（paddlewheel）结构**：两个Cr通过四重键（σ+2π+δ）连接，四个醋酸根以μ₂方式桥联，两个H₂O分别轴向配位。

- 两个Cr之间形成**四重键**（σ + 2π + δ）
- 四个醋酸根以μ₂方式桥联两个Cr
- 两个H₂O分别轴向配位于两个Cr
- Cr为六配位（4O来自醋酸根 + 1O来自H₂O + 1Cr-Cr键方向）

**Cr-Cr键级 = 4**（四重键）

**6-1-5 形成π键的d轨道**

Cr-Cr沿z轴方向：

- **σ键**：$d_{z^2} - d_{z^2}$（头对头重叠）
- **π键**：$d_{xz} - d_{xz}$ 和 $d_{yz} - d_{yz}$（侧面重叠）
- **δ键**：$d_{xy} - d_{xy}$（面对面重叠）

**形成π键的d轨道名称**：$d_{xz}$ 和 $d_{yz}$

**6-1-6 三核Cr³⁺配合物结构**

醋酸亚铬中Cr:AcO⁻ = 1:2（Cr₂(OAc)₄ → 每个Cr对应2个AcO⁻）。

三核配合物：三个Cr³⁺，每个Cr³⁺为六配位（4O来自AcO⁻ + 1H₂O + 1个桥联位），Cr³⁺与AcO⁻比例同样为1:2，总共6个AcO⁻。

**结构**：三个Cr³⁺排列成**等边三角形**，每个边由两个AcO⁻桥联（每条边2个AcO⁻ → 共6个AcO⁻），每个Cr轴向各配位一个H₂O。

> Cr₁—Cr₂—Cr₃ 等边三角形，每条边两个AcO⁻桥联，各Cr轴向配位H₂O

- 三个Cr³⁺等价，均为八面体配位
- 无Cr-Cr键（Cr³⁺为d³，无法形成有效的金属-金属键）
- 每个Cr配位环境：4个O（来自桥联AcO⁻）+ 1个H₂O + 1个位置参与三角形结构

**6-2-3 无水 vs 水合物Cr-Cr键长**

**答案：(b) 更短**

水合物中轴向H₂O的孤对电子与Cr的$d_{z^2}$轨道有微弱的σ排斥作用（或配位作用），这会略微削弱Cr-Cr之间的δ键（$d_{xy}-d_{xy}$重叠受到间接影响）和σ键。去掉轴向H₂O后：

- 无轴向配体 → $d_{z^2}$轨道上的电子密度更集中于Cr-Cr方向 → σ键增强
- 无轴向干扰 → δ键重叠更充分
- 综合效果：Cr-Cr键长**缩短**

> ⚠️ **易错提醒**
> - 四重键只在**同种过渡金属之间**出现（如Cr-Cr, Mo-Mo, Re-Re），且需要**合适的配体环境**（桥联配体缩短金属间距）。
> - $d_{x^2-y^2}$**不参与**Cr-Cr成键——它在xy平面内，指向配体方向，用于σ配位。
> - 三核配合物中"Cr³⁺与AcO⁻比例相同"是关键线索：Cr₂(OAc)₄中比例为1:2，三核中每个Cr仍需2个AcO⁻ → 总共6个AcO⁻桥联三核三角形。

### 真题4：38届决赛第7题 — Co自旋化学+高/低自旋+CFSE

> **7-1** 估算$1_{hs}$和$1_{ls}$的自旋量子数S;
>
> **7-2** 画出$1_{hs}$和$1_{ls}$的结构，并标明Co的氧化态，八面体场近似下3d轨道电子占据情况，以及配体上未成对电子的自旋取向(bpy可以简画为N~N)。
>
> **7-3** 说明由$1_{ls}$到$1_{hs}$变化过程中Co-O、Co-N配位键的键长变化情况，并简述判断理由。

![[2024年第38届化学竞赛决赛试题及解析_images/22cd89e511d423db3f4e29394823d67719ce783090427e303403f4582cc5fb2f.jpg]]

**分值**：约12分 | **建议用时**：8 min

### 解析

**背景分析**

化合物1：Co(O₂C₆H₂(tBu)₂)₂(bpy)，配位环境O₄N₂。

- DTBSQ = 3,5-二叔丁基半醌阴离子自由基（记为L•⁻）
- bpy = 2,2'-联吡啶（中性双齿N配体）
- 每个DTBSQ含1个未配对电子（半醌自由基）

**7-1 估算自旋量子数S**

**$1_{ls}$（低温态）**：

- 在230K时，μ(1) = 2.07 μB
- 该磁矩对应$n \approx 1.4$个未成对电子（由$\mu = \sqrt{n(n+2)}$反算）
- EPR证明$1_{ls}$信号源于**配体** → 金属Co无未成对电子
- Co为抗磁性（$S_{metal} = 0$），未配对电子来自DTBSQ配体自由基
- 两个DTBSQ各1个未配对电子，若反铁磁耦合 → $S = 0$；若仅考虑一个自由基贡献 → $S = 1/2$
- 实验值2.07 μB接近$S = 1/2$的仅自旋值1.73 μB（偏高来自轨道贡献或配体间耦合）

$$\boxed{S(1_{ls}) = 1/2}$$

**$1_{hs}$（高温态）**：

- 在350K时，μ(1) = 4.26 μB，进一步升温趋近4.33 μB
- 由$\mu = \sqrt{n(n+2)}$反算：$4.33^2 = n^2 + 2n$ → $n^2 + 2n - 18.75 = 0$ → $n \approx 3.4$
- 3个未成对电子：$\mu = \sqrt{3 \times 5} = 3.87$ μB（仅自旋值）
- 4个未成对电子：$\mu = \sqrt{4 \times 6} = 4.90$ μB（仅自旋值）
- 4.33介于3.87和4.90之间，但更接近3.87 → 未成对电子数为3（轨道贡献使实验值偏高）
- Co在$1_{hs}$中提供未成对d电子，DTBSQ自由基配对

$$\boxed{S(1_{hs}) = 3/2}$$

**7-2 结构与电子占据**

> **核心概念**：这是一个**金属-配体氧化还原耦合驱动的自旋交叉**（metal-ligand redox-coupled spin crossover），不是传统的仅改变电子排布的自旋交叉。DTBSQ是**半醌阴离子自由基配体**，配体本身可以参与氧化还原。

**$1_{ls}$结构**（低温，S = 1/2）：

Co为**+3价**（d⁶），八面体场O₄N₂；DTBSQ为**半醌阴离子自由基**（DTBSQ•⁻）：
- Co³⁺(d⁶)：$t_{2g}^{6}e_{g}^{0}$，金属无未成对电子（抗磁性）
- DTBSQ•⁻配体：每个配体带1个未配对电子（自由基）
- 两个DTBSQ•⁻自由基反铁磁耦合 → 配体总自旋 ≈ 0
- 净自旋主要来自未完全抵消的自由基贡献 → **S(总) ≈ 1/2**

**磁矩验证**：μ(1ls) ≈ 1.92-2.07 μB，与S = 1/2的仅自旋值 μ = √(1×3) = 1.73 μB 接近（略高，可能有轨道贡献或反铁磁耦合不完全）。

**$1_{hs}$结构**（高温，S = 3/2）：

Co为**+2价**（d⁷），DTBSQ被还原为**DTBSQ²⁻**（邻苯二酚形式，无自由基）：
- Co²⁺(d⁷)：$t_{2g}^{5}e_{g}^{2}$，3个未成对电子
- DTBSQ²⁻：无未成对电子（完全还原态）
- **S(Co) = 3/2 → S(总) = 3/2**

**磁矩验证**：μ(1hs) → 4.33 μB。Co(II) d⁷高自旋，S = 3/2，仅自旋值 μ = √(3×5) = 3.87 μB。实验值4.33明显高于仅自旋值，这在八面体Co(II)中非常典型——由于**轨道角动量贡献**（轨道简并未被完全淬灭），实际磁矩通常高于仅自旋值。

> **关键总结**：低温时Co(III) d⁶ + DTBSQ•⁻自由基配体；高温时Co(II) d⁷ + DTBSQ²⁻（配体被还原，失去自由基）。自旋交叉过程中**金属氧化态改变（III → II）被配体氧化还原（DTBSQ•⁻ → DTBSQ²⁻）补偿**，总电荷不变。

**7-3 键长变化**

由$1_{ls}$到$1_{hs}$（升温过程中）：

**Co-O和Co-N键长均增大（变长）**。

**理由**：

| 状态 | Co氧化态 | d电子组态 | $e_g$占据 | 键长 |
|:---:|:---:|:---:|:---:|:---:|
| $1_{ls}$ | Co³⁺ (d⁶) | $t_{2g}^{6}e_{g}^{0}$ | 空 | 较短 |
| $1_{hs}$ | Co²⁺ (d⁷) | $t_{2g}^{5}e_{g}^{2}$ | 2个电子 | 较长 |

- $e_g$轨道（$d_{z^2}$和$d_{x^2-y^2}$）**直接指向配体**，是**反键轨道**（σ*）
- $1_{ls}$（$e_{g}^{0}$）：反键轨道为空 → 配位键强 → 键长短
- $1_{hs}$（$e_{g}^{2}$）：反键轨道被占据2个电子 → 削弱配位键 → 键长变长
- 同时Co²⁺（d⁷）半径大于Co³⁺（d⁶），离子半径增大也导致键长增加

> ⚠️ **易错提醒**
> - 自旋交叉（spin crossover）的本质是**温度改变$\Delta_o$与P的相对大小**：低温下$\Delta_o$ > P → 低自旋；高温下P增大（热激发使电子成对能的代价变小）→ 高自旋。
> - "EPR信号源于配体"是判断金属抗磁性的**铁证**——如果金属有未配对电子，EPR一定会检测到金属信号。
> - $e_g$占据影响键长是高频考点：$e_g$是σ*轨道，每占据1个电子就削弱一根σ配位键。
