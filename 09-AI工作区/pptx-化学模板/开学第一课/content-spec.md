## P5 化学家做三件事（三图标卡）
- 识别——这是什么：分析成分、鉴定物质，比如检测一杯水的质量
- 创造——造出新物质：合成自然界没有的材料、药物和功能分子
- 解释——为什么这样：用规律说明现象背后的原因，并做出预测
- 底部一行：这三件事，也是你们三年要练的三种能力

## P12 健康与安全（三元素卡 + 砖红警示块）
- 铁——血红蛋白的核心成分：缺铁容易贫血、疲劳；红肉、动物肝脏、菠菜能补
- 碘——甲状腺激素的原料：缺碘会让甲状腺肿大；加碘盐就是为这个设计的
- 钙——骨骼和牙齿的主要成分：长身体的关键期，奶、豆制品要跟上
- 砖红警示块（三角图标）：84 消毒液 + 洁厕灵 = 有毒氯气；方程式 NaClO + 2HCl ═ NaCl + H₂O + Cl₂↑；说明：84 含次氯酸钠（NaClO），洁厕灵含盐酸（HCl）——混用放出黄绿色、刺鼻的氯气，吸入会灼伤呼吸道。记住两条：清洁剂绝不混用；闻到刺鼻气味，立刻开窗、离开现场

## P16 变化①：内容——从「认识」到「讲理」（对比表，含方程式）
| | 初中 · 多靠记忆 | 高中 · 重在逻辑推理 |
| 氧气 | 记住性质和制法：2H₂O₂ ═ 2H₂O + O₂↑（MnO₂ 催化） | 追问为什么：2H₂O₂ ═ 2H₂O + O₂↑——MnO₂ 为什么能加快？ |
| 化学方程式 | 背下来、会配平：3Fe + 2O₂ ═ Fe₃O₄（点燃） | 同一个方程式还要算「量」：3Fe + 2O₂ ═ Fe₃O₄——系数 3∶2∶1，就是物质的量之比，能算出要多少铁、生成多少产物（依据：人教版必修第一册「物质的量在化学方程式计算中的应用」） |
| 实验 | 看现象、记结论 | 用证据推出结论 |
- 高中列浅黄高亮；表下小字：衔接研究共识：初中多靠记忆，高中重在逻辑推理

## P17 变化②：思维——宏观辨识与微观探析（左右对照卡）

## P19 三个「掉队」陷阱（三警示卡：陷阱 + 破解）
- 只背不思考：背得滚瓜烂熟，一换情境就不会 → 破解：多问一句「为什么」，把结论还原成推理过程
- 攒问题不问：小问题攒成大窟窿 → 破解：当天问，当天清；问老师、问同学，问题不过夜
- 怕计算：一看到数字题就想跳过 → 破解：跟着例题一步步算；计算题套路固定，动手三遍就熟
- 底部一行：这三个坑避开了，高一化学就稳了一半
