## 安装 Claude Code CLI
- 在受管 Node workspace（`~/.workbuddy/binaries/node/workspace`）安装 `@anthropic-ai/claude-code`。
- 踩坑：受管 Node 的 `genie-safe-delete` 删除拦截器导致 npm install 失败（中文用户名路径回收站操作乱码、fail-closed）。
- 解法：运行 npm 时清空 `CODEBUDDY_SESSION_ID`/`CLAUDE_SESSION_ID` 让拦截器空操作退出；残留用 PowerShell `Remove-Item` 清理。
- 结果：Claude Code 2.1.246 安装成功，已将 `node_modules/.bin` 加入用户 PATH，新终端可直接 `claude`。
