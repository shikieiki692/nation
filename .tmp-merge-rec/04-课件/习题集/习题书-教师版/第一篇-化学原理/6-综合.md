## 6.1 〔🟢 d2〕

> 关联小问：7-1-1 | 7-1-2 | 7-1-3 | 7-2-1 | 7-2-2
>
> 来源：提炼笔记 | 原始解析

初步研究表明，嫦娥石中含有 ${}^{3}He$ ，$FeO_6$ 和 $PO_4$ 可能是其吸附位置。${}^{3}He$ 已用于中子探测，也很可能成为人类未来的能源。${}^{3}He$ 与中子作用产生质子和氚，写出核反应方程式。

<details>
<summary>📖 查看答案</summary>

书写核反应方程式时，要注意将所有粒子物种的核电荷数和质量数标出，同时保证反应前后核电荷数和质量数守恒：

将 $^{3}_{1}H$ 写为 $^{3}_{1}T$ 也可以。

$$
{ } _ { 2 } ^ { 3 } \mathrm{He} + { } _ { 0 } ^ { 1 } \mathrm{n} \longrightarrow { } _ { 1 } ^ { 3 } \mathrm{H} + { } _ { 1 } ^ { 1 } \mathrm{H}
$$

| 知识点 | 直接关联 |
|:---|:---:|
| 核反应 | ✅ |
| 核反应方程式 | ✅ |
| 质量数与核电荷数守恒 | ✅ |

1. 确定反应物：$^{3}_{2}\mathrm{He}$ 和 $^{1}_{0}\mathrm{n}$
2. 确定产物：$^{3}_{1}\mathrm{H}$（氚）和 $^{1}_{1}\mathrm{H}$（质子）
3. 验证质量数守恒：3 + 1 = 3 + 1
4. 验证核电荷数守恒：2 + 0 = 1 + 1

- **未标注质量数和核电荷数**：核反应方程式必须标注
- **守恒验证错误**：未验证质量数和核电荷数是否守恒
- **产物判断错误**：将氚误写为其他粒子

</details>

## 6.2 〔🟢 d3〕

列出与盘状双层胶束形状形成相关的作用力。

---

<details>
<summary>📖 查看答案</summary>

1. **静电作用**：亲水部分中，带有电荷的基团 $-\mathrm{NH}_3^{+}$ 和 $-\mathrm{P}(\mathrm{OR})_2\mathrm{O}_2^{-}$ 之间存在静电引力（盐键）。

2. **氢键**：亲水部分中，铵根基团的 N-H 键可以与磷酸基团中的 O 原子形成氢键。

3. **疏水效应**：水分子之间通过氢键形成稳定的网络，当非极性分子进入水中时，水分子必须重新排列成有序的结构来围绕非极性分子，这种"有序围绕"会降低水的熵。当多个疏水分子或基团靠在一起时，总表面积下降，围绕它们的水分子总数降低，更多的水分子"重获自由"，体系熵增。因此 DMPE 中的疏水尾链互相聚集，最小化它们与水的接触面积。

---

- **直接 KP**：静电作用、氢键、疏水效应
- **间接 KP**：胶束自组装、生物膜结构

---

1. DMPE 分子具有"亲水头基"和"疏水尾链"的两亲结构
2. 亲水头基之间的相互作用：静电吸引、氢键
3. 疏水尾链之间的相互作用：疏水效应（熵驱动）
4. 这三种非键相互作用共同维持盘状双层胶束的结构

---

- 容易遗漏疏水效应（疏水效应是胶束形成的主要驱动力）
- 疏水效应的本质是熵增，而非能量降低
- 需要区分"静电作用"和"氢键"的不同

</details>

## 6.3 〔🟢 d3〕

聚脲是一类高性能聚合物树脂材料，广泛应用于防水防腐涂料、胶黏剂和浇铸材料等领域；而聚硫脲具有优异的自修复性能、高折光指数、高介电常数、强金属配位能力等优势。这两种材料均可以通过链间的氢键作用增强其性能。以下说法正确的有：（）

![[cf338b560e475df06ecc323e1101b27c8c7f6e3cf5d618e1aa6d01991ebbc0ed.jpg]]
A

![[a9abcbaf6750ce3483643f6e78351758ef73b167ceb42a5dac2a6db40ccbed35.jpg]]
B

(a) 聚合物 A 分子间氢键更强

(b) 聚合物 B 分子间氢键更强

(c) 无法比较

---

<details>
<summary>📖 查看答案</summary>

**(a) 聚合物 A 分子间氢键更强**

---

- **直接 KP**：氢键强度、电负性、共振杂化体
- **间接 KP**：聚脲/聚硫脲化学、氢键催化

---

1. O 原子比 S 原子电负性更高
2. 形成的共振杂化体中，聚脲（A）的电荷分离极限式贡献更大
3. 因此相比聚硫脲（B），聚脲中的分子间氢键更强

---

- 不要仅凭原子电负性判断，需要考虑共振杂化体的贡献
- 脲和硫脲的氢键成键形式被用于氢键催化中

</details>
