## 一、课标对应

- **内容要求**：知道常见的氧化剂和还原剂；能根据元素化合价的变化预测物质的氧化性和还原性；能从氧化还原视角分析四类基本反应类型。

  1. **证据推理与模型认知**（建立"价态位置 → 性质倾向"的预测模型：最高价只氧化、最低价只还原、中间价兼具）；

  3. **科学态度与社会责任**（用"有单质≠氧化还原""高价≠强氧化"等反例破除绝对化认知）。

## 二、学情分析（本课时）

**【课前诊断·4 处典型误解预判】**

- 学生常把"氧化剂 / 还原剂"当成物质的**固有标签**（如"H₂O₂ 就是氧化剂"），不理解角色由**对手强弱**决定。
- 学生常把"有单质参与或生成"当成氧化还原的判据（反例：3O₂=2O₃ 同素异形体转化无价变，不是氧化还原）。
- 学生常把"高价态 = 强氧化性"绝对化（反例：Na₂SO₄ 中 S 为 +6 却稳定、氧化性弱；浓稀硫酸氧化性差异）。
- 学生常把"中间价态兼具氧化性和还原性"说成"两性"（"两性"是酸碱范畴的专属术语，指既能与酸又能与碱反应）。

学生已在 1.7 掌握氧化数与双线桥，但面对"这个物质是氧化剂还是还原剂"时仍靠死记常见剂清单，遇到陌生物质就不会判断。本课新难点有三：一是建立"价态位置决定性质倾向"的预测模型（最高价只氧化、最低价只还原、中间价兼具），这是从"记忆"走向"预测"的关键跃迁；二是理解同一物质（H₂O₂、SO₂、Fe²⁺）在不同对手面前角色切换，需要"关系性思维"；三是四大基本反应类型与氧化还原的韦恩关系（置换⊂氧化还原、复分解与之不相交、化合分解部分相交），这是初中四大反应类型的升级整合。对策：用 H₂O₂ 遇 KMnO₄ 作还原剂、遇 Fe²⁺ 作氧化剂的正反对照暴露"关系性"，用四条误区反例链（同素异形体、CuO+CO、Na₂SO₃、2H₂O₂）逐条破除绝对化，用韦恩图把四大类型与氧化还原的关系可视化。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过归纳常见氧化剂 / 还原剂清单及其典型价态变化，培养**证据推理与模型认知**素养：把零散的物质记忆整合为"价态变化 + 产物"的结构化清单。
- 通过分析 H₂O₂、SO₂ 在不同反应中角色切换，培养**变化观念与平衡思想**素养：认识氧化性与还原性是**关系属性**而非固有标签，取决于对手的相对强弱。
- 通过建立"最高价只氧化、最低价只还原、中间价兼具"的预测模型，培养**证据推理与模型认知**素养：能从价态位置预测陌生物质的性质倾向。
- 通过辨析四条典型误区反例，培养**科学态度与社会责任**素养：养成以事实证据破除直觉绝对化的严谨态度。

### 3.2 学习目标（学生能……，可观测）

- 能**列举**常见氧化剂（KMnO₄、浓 H₂SO₄、HNO₃、Cl₂、Br₂、FeCl₃、H₂O₂）与还原剂（Na/Fe/Al、C、CO、H₂、Fe²⁺、S²⁻、I⁻、SO₃²⁻），并说出各自的典型价态变化与代表产物。
- 能**用"是否处于中间价态"**判断给定物质能否兼具氧化性与还原性，并举例说明同一物质在不同反应中的角色切换（H₂O₂、SO₂、Fe²⁺）。
- 能**判定**四类基本反应类型与氧化还原的包含关系，并用韦恩图语言表述（置换⊂氧化还原；复分解与之不相交；化合、分解部分相交）。
- 能**识破**四条典型误区：有单质≠氧化还原；高价≠强氧化；中间价态"兼具"不等于"两性"；无单质也可能是氧化还原。

### 环节三：中间价兼性物质、常见剂清单、四大反应类型与误区反例

**教师**："哪些物质既能作氧化剂又能作还原剂？关键看元素是否处于**中间价态**。Cl₂（0 价）、S（0 价）、H₂O₂（O 为 −1）、Fe²⁺（+2 中间价）、SO₂（S 为 +4）、NO（N 为 +2）都在此列。例如 H₂O₂ 遇强氧化剂 KMnO₄ 时作还原剂（O 从 −1 升到 0 放出 O₂），遇强还原剂 Fe²⁺ 时作氧化剂（O 从 −1 降到 −2 生成 H₂O）——同一物质在不同反应中角色切换，全看对手强弱。再看 SO₂：遇 H₂S 作氧化剂（S +4→0），遇 Cl₂/H₂O₂ 作还原剂（S +4→+6）。"

**常见氧化剂/还原剂清单（含价态变化）**：
- 常见氧化剂（得电子、氧化数降低）：KMnO₄（Mn +7→+2，酸性）、浓 H₂SO₄（S +6→+4）、HNO₃（N +5→+4 或 +2）、Cl₂（0→−1）、Br₂（0→−1）、FeCl₃（Fe +3→+2）、H₂O₂（O −1→−2）。
- 常见还原剂（失电子、氧化数升高）：活泼金属 Na、Fe、Al、Zn；C（0→+4）、CO（+2→+4）、H₂（0→+1）；Fe²⁺（+2→+3）、S²⁻（−2→0）、I⁻（−1→0）、SO₃²⁻（S +4→+6）。
- 特殊（中间价，兼具氧化性和还原性）：S（0）、Cl₂（0）、H₂O₂（O −1）、Fe²⁺（+2）、SO₂（S +4）、NO（N +2）**既可作氧化剂又可作还原剂**；判断依据：该元素是否处于中间价态。

**【常见剂与典型反应速配表】**（帮助记忆"什么剂常和什么反应"）：

| 常见氧化剂 | 典型被还原产物 | 代表反应（节选） |
|---|---|---|
| KMnO₄（酸性） | Mn²⁺（+2） | 2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → K₂SO₄ + 2MnSO₄ + 5O₂↑ + 8H₂O |
| 浓 H₂SO₄ | SO₂（+4） | Cu + 2H₂SO₄(浓) → CuSO₄ + SO₂↑ + 2H₂O |
| HNO₃（浓/稀） | NO₂ / NO | Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O |
| Cl₂ | Cl⁻ | Cl₂ + 2KBr → 2KCl + Br₂ |
| FeCl₃ | Fe²⁺ | 2FeCl₃ + Cu → 2FeCl₂ + CuCl₂ |
| H₂O₂ | H₂O（O −2） | H₂O₂ + 2Fe²⁺ + 2H⁺ → 2Fe³⁺ + 2H₂O |

| 常见还原剂 | 典型被氧化产物 | 代表反应（节选） |
|---|---|---|
| Na / Fe / Al | Na⁺ / Fe²⁺ / Al³⁺ | 2Al + Fe₂O₃ → 2Fe + Al₂O₃（铝热） |
| H₂ | H⁺ | H₂ + CuO → Cu + H₂O |
| CO | CO₂ | CO + CuO → Cu + CO₂ |
| Fe²⁺ | Fe³⁺ | 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ |
| I⁻ | I₂ | 2I⁻ + Cl₂ → I₂ + 2Cl⁻ |
| SO₃²⁻ | SO₄²⁻ | Na₂SO₃ + Cl₂ + H₂O → Na₂SO₄ + 2HCl |

**教师**："四类基本反应与氧化还原的包含关系（韦恩图逻辑），逐类看：
- **置换反应**（A+BC→AC+B）：一定是氧化还原——例 Zn + H₂SO₄ = ZnSO₄ + H₂↑（Zn 0→+2，H +1→0）。
- **复分解反应**（交换成分）：一定不是氧化还原——例 NaOH + HCl = NaCl + H₂O（无变价）。
- **化合反应**：不一定是——2H₂+O₂=2H₂O 是（H 0→+1，O 0→−2）；CaO+H₂O=Ca(OH)₂ 不是（无变价）。
- **分解反应**：不一定是——2H₂O₂=2H₂O+O₂↑ 是（O −1→−2 与 0）；CaCO₃=CaO+CO₂↑ 不是（无变价）。
韦恩图表述：氧化还原集合**真包含**置换集合；复分解集合与氧化还原**不相交**；化合、分解两个集合与氧化还原**部分相交**。"

**教师**："误区深度辨析，记四条：① 有单质参与/生成**未必**是氧化还原——同素异形体转化 3O₂=2O₃、石墨→金刚石，虽有单质但无变价，不是氧化还原。**根本判据是化合价是否变化**，不是有没有单质。② 反例 CuO + CO → Cu + CO₂ 有单质 Cu 生成，它**是**氧化还原（C +2→+4，Cu +2→0），说明'有单质'既不能当充分也不能当必要条件。③ 把'高价=强氧化'绝对化是另一大坑，已用 Na₂SO₃、浓稀硫酸讲清——Na₂SO₃ 中 S +4 处于中间价态、兼具氧化性和还原性，既可被氧化为 +6，又可被还原为 0 或 −2。④ '有单质就是 redox'的兄弟谬误是'无单质就一定不是'——错，CaCO₃ 分解无单质却也不是 redox，而 2H₂O₂ 分解有 O₂ 却是 redox，二者互不决定。"

**【典型易错辨析对照表】**（课堂投影，逐行对照）：

| 迷思说法 | 正确判断 | 反例/正解 |
|---|---|---|
| 有单质参与或生成的反应一定是氧化还原 | 错 | 3O₂=2O₃（同素异形体转化，无变价） |
| 无单质参与就一定不是氧化还原 | 错 | 2H₂O₂=2H₂O+O₂↑、CO+CuO→Cu+CO₂ |
| 含最高价元素的物质氧化性一定最强 | 错 | 稀 H₂SO₄（S +6）不能氧化 Cu；氧化性看浓度介质 |
| Na₂SO₃ 中 S +4，所以它是强氧化剂 | 错 | S +4 是中间价，兼具氧化性和还原性，可被氧化也可被还原 |
| 还原剂被还原、氧化剂被氧化 | 错 | 还原剂被**氧化**，氧化剂被**还原** |
| 双线桥箭头从还原剂指向氧化剂 | 错 | 双线桥按**同种元素**自身升降连，电子流向看单线桥 |
| 电子数 = 价态变化数 | 错 | 电子数 = 价态变化数 × **变价原子个数** |
| 归中是任意两价态相遇都行 | 错 | 须"只靠拢不交叉"，产物价态在二者之间 |
| NO₂ 歧化反应是归中 | 错 | 3NO₂+H₂O 中反应物只有 +4 一种价态，属**歧化** |
| 氧化数就是真实电荷 | 错 | 氧化数是人为规定的**形式电荷**，可为零/分数 |
| 自身氧化还原=歧化 | 错 | 自身氧化还原还含"归中型"（如 NH₄NO₃ 分解：N −3 与 +5 归中到 +1），并非都歧化 |

        交叉（如 Zn+2H⁺→Zn²⁺+H₂↑、2Fe³⁺+Cu→2Fe²⁺+Cu²⁺ 既是）
  本课焦点：氧化剂 / 还原剂清单 · 中间价兼性 · 四大类型韦恩

## 八、作业布置

### 必做

1. **题5**（见 [[高中化学必修一-习题精选]]）：判断 2FeCl₃ + Cu = 2FeCl₂ + CuCl₂ 中的氧化剂、还原剂、氧化产物、还原产物。
   - 解答：Fe 元素 +3→+2（降价），故 FeCl₃ 是氧化剂、FeCl₂ 是还原产物；Cu 元素 0→+2（升价），故 Cu 是还原剂、CuCl₂ 是氧化产物。氧化性 Fe³⁺ > Cu²⁺。
2. 默写常见氧化剂与还原剂清单（各 7 项），并注明各自的典型价态变化与代表产物。
3. 判断下列物质在通常反应中主要作氧化剂、还原剂，还是兼具两者：Cl₂、S、H₂O₂、Fe²⁺、SO₂、NO、KMnO₄、浓 H₂SO₄、Fe 粉、I⁻。

### 选做

4. 判断下列反应所属的基本反应类型，并判断是否为氧化还原反应（若是，指出氧化剂与还原剂）：
   ① Zn + H₂SO₄ = ZnSO₄ + H₂↑；② NaOH + HCl = NaCl + H₂O；③ 2H₂ + O₂ = 2H₂O；④ CaO + H₂O = Ca(OH)₂；⑤ 2H₂O₂ = 2H₂O + O₂↑；⑥ CaCO₃ = CaO + CO₂↑。
   - 解答：① 置换，是（氧化剂 H₂SO₄、还原剂 Zn）；② 复分解，非；③ 化合，是（氧化剂 O₂、还原剂 H₂）；④ 化合，非；⑤ 分解，是（H₂O₂ 既是氧化剂又是还原剂，歧化）；⑥ 分解，非。
5. 举例说明"同一物质在不同反应中可作不同角色"：以 H₂O₂ 为例，分别写出它作氧化剂与作还原剂各一个反应，并标出 O 元素的价态变化。
6. 辨析四条误区，各举一例说明：① 有单质参与≠氧化还原；② 有单质生成的反应也可能是非氧化还原；③ 高价态≠强氧化性；④ "中间价态兼具"不能说成"两性"。

### 挑战（有区分度，鼓励学有余力者完成）

7. **介质效应初探**：KMnO₄ 在酸性、中性、碱性介质中的还原产物分别为 Mn²⁺、MnO₂、MnO₄²⁻。请分别计算三种产物中 Mn 的氧化数，比较其得电子数差异，并解释为何酸性条件下 KMnO₄ 的氧化能力最强（提示：从电极电势与 H⁺ 参与反应的角度思考）。
8. **多角色判断**：在反应 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ 中，Na₂O₂ 中 O 为 −1。请指出该反应中氧化剂、还原剂、氧化产物、还原产物各是什么，并说明为何 Na₂O₂ 在此既不是单纯的氧化剂也不是单纯的还原剂（提示：歧化反应的特征）。

## 十、教学反思（课后填写）

- **时间分配预案**：回顾导入 5 min、兼性与清单 15 min、韦恩与误区 15 min、辨析与随堂练 10 min。若清单记忆耗时过多，可从随堂练压缩 3 min 补到速配表讲解。
- **分层落实**：基础薄弱生以"常见剂清单 + 基本指认"为保底；中等生主攻中间价兼性与双重判定；拔高生冲击介质效应与歧化多角色判断。

- [ ] 学生是否真正理解"氧化性 / 还原性是关系属性"？H₂O₂ 在不同对手面前角色切换的例子是否被理解而非死记？
- [ ] "最高价只氧化、最低价只还原、中间价兼具"的预测模型是否建立？能否用它判断陌生物质（如 NO、Fe²⁺）的性质倾向？
- [ ] 四大基本反应类型与氧化还原的韦恩关系是否打通？学生能否同时给出"反应类型"与"是否氧化还原"两个判断？
- [ ] 四条误区（有单质≠氧化还原、高价≠强氧化、兼具≠两性、无单质也可能是）是否逐条破除？学生能否各举反例？
