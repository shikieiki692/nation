# 第四章 物质结构 元素周期律 · 知识体系与概念关联图

> 配套 8 课时教案使用。本章不是孤立知识点的堆砌，而是围绕"**位（周期表位置）× 构（原子结构）× 性（元素性质）**"三角（升维并系统化第一~三章"类别×价态"双轴）与"**宏—微—符三重表征**"展开的一个体系，并以"**化学键与分子间作用**"回到性质的微观根源。本图给出系统骨架、原子结构/周期表/周期律/化学键四张网络、各课时 ★ 站位、双轴与第一~三章打通、后续接口，供板书"体系关联站位图"衔接，便于学生建立结构化认知。内容以 [[原子结构]]、[[元素周期律]]、[[化学键]]、[[共价键]]、[[氢键]]、[[分子极性]]、[[分子间力]]、[[元素周期表分区]] 为据。

## 一、本章知识系统的"三层视角 + 位—构—性三角"

```
              物质结构 元素周期律 · 结构化学体系
   ┌──────────────────┬──────────────────┐
   │   宏观视角          │   微观视角          │
   │   现象/性质/物性     │   结构/粒子/电子/键   │
   └──────────────────┴──────────────────┘
           符号视角：原子结构示意图 / 电子式 / 结构式
   ┌──────────────────────────────────────────┐
   │   位—构—性 三角（本章灵魂）                 │
   │   位（周期表位置）── 位置反映结构            │
   │      ╱          ╲                         │
   │   构（原子结构）──── 性（元素性质）          │
   │   结构决定性质，性质验证位置，位置反推结构    │
   └──────────────────────────────────────────┘
   三重表征：宏观现象 ⇄ 微观粒子 ⇄ 符号表达
```

- **三层视角**：① 宏观——放射性衰变、金属性/非金属性实验现象、沸点反常（H₂O/HF/NH₃）、冰浮于水、DNA 双螺旋；② 微观——原子核、核外电子排布、能级、共用电子对、氢键网络、s/p/d/ds/f 电子构型；③ 符号——原子结构示意图、电子式、结构式、周期表位置。
- **位—构—性三角**：周期表位置（位）由原子结构（构）决定，结构又决定元素性质（性），性质通过实验验证并可反推位置——三者循环互推，是本章最核心的思维模型。

## 二、原子结构网络（微粒关系 · 电子排布）

```
   原子构成（中性原子）
   ┌─────────────────────────────────────────┐
   │  原子核（带正电）          核外电子（带负电）  │
   │   ├ 质子 Z（决定元素）      分层 K/L/M/N…   │
   │   └ 中子 N（决定核素）      每层最多 2n²    │
   │  关系：A = Z + N（质量数）                  │
   │  原子序数 = 核电荷数 = 质子数 = 核外电子数   │
   └─────────────────────────────────────────┘
   排布规律：
     · 能量最低原理（先内后外）
     · 最外层≤8（K 层作最外层≤2）、次外层≤18、倒数第三层≤32
     · 1~20 号：H 1 / He 2 / Ne 2,8 / Ar 2,8,8 / Ca 2,8,8,2
   原子结构示意图：圈内 +Z，弧线标各层电子数
   深度补点：电子云小黑点=概率密度非电子本身
            能层能级 s/p/d/f；能级交错 E(4s) < E(3d)（钻穿效应）
   原子模型史（6 阶段，螺旋上升）：
     德谟克利特 → 道尔顿(1803实心球) → 汤姆生(1897葡萄干布丁)
     → 卢瑟福(1911核式) → 玻尔(1913定态轨道) → 薛定谔(1920s电子云)
```

- 标注：核素/同位素由 Z 与 N 组合决定；同位素化学性质几乎相同（电子排布定）、物理性质（质量）不同。

## 三、元素周期表网络（周期 · 族 · s/p/d/ds/f 区）

```
   编排：按原子序数递增；原子序数=核电荷数=质子数=电子数
   周期（横行，7 个）：短 2/8/8，长 18/18/32/32，镧系 57–71/锕系 89–103 单列
   族（纵列，16 个）：IA–VIIA 主族 / IIIB–IIB 副族 / VIII 族(8,9,10) / 0 族
   位置⇄结构⇄性质：
     周期序数 = 电子层数
     主族族序数 = 最外层电子数
     ┌──────────────────────────────────────┐
     │  由原子序数推位置 → 由位置推性质（递变）   │
     └──────────────────────────────────────┘
   五区划分（按最后填入电子轨道，源自 [[元素周期表分区]]）：
     s 区：ns¹/ns² → IA/IIA 活泼金属（H 除外；H 在 s 区但性质近 VIIA）
     p 区：ns²np¹⁻⁶ → IIIA–VIIA+0 金属→非金属渐变
     d 区：(n-1)d¹⁻⁹ ns¹⁻² → IIIB–VIII 过渡金属多变价
     ds 区：(n-1)d¹⁰ ns¹⁻² → IB/IIB 类过渡金属
     f 区：(n-2)f¹⁻¹⁴ → 镧系/锕系 内过渡金属（性质极相似）
   特殊：He(1s²) 电子属 s 区但化学行为归 0 族
   科学史：门捷列夫 1869 按相对原子质量排列、留空位；4 年后 Ga(类铝)证实
```

- 标注：分族强调"性质规律"，分区强调"电子结构本源"（性质看族，电子看区）。

## 四、元素周期律网络（半径 · 第一电离能 · 电负性 · 金属/非金属性）

```
   随原子序数递增的周期性（同周期/同主族）
   ┌──────────────────────────────────────────────────┐
   │ 原子半径：同周期左→右↓（核电荷↑吸引↑）             │
   │           同主族上→下↑（电子层↑屏蔽↑）             │
   │           离子半径 O²⁻>F⁻>Na⁺>Mg²⁺>Al³⁺（等电子构型）│
   │ 化合价：最高正价=族序数(O/F除外)；最低负价=最外层−8  │
   │         最高正价+最低负价绝对值=8（第三周期递变）    │
   │ 第一电离能 I₁：同周期总体↑，反常 ⅡA>ⅢA（ns²全满）  │
   │                   ⅤA>ⅥA（np³半满）；同主族↓          │
   │ 电负性：F=4.0 最大、Cs=0.7 最小；同周期↑同主族↓    │
   │         差值>1.7 一般离子键（近似规则，AlCl₃ 例外）  │
   └──────────────────────────────────────────────────┘
   金属性（失电子能力）：同周期↓ 同主族↑
     判据：单质与水/酸反应难易 + 最高价氧化物水化物碱性
   非金属性（得电子能力）：同周期↑ 同主族↓
     判据：与 H₂ 化合难易 + 氢化物稳定性 + 最高价含氧酸酸性
   本质（核心）：同周期核电荷↑、半径↓ → 失电子↓得电子↑
                → 金属性↓非金属性↑；结构决定性质
   第三周期"元素争霸赛"实验（4.5）：
     Na>Mg>Al 金属性（NaOH强碱→Mg(OH)₂中强→Al(OH)₃两性）
     Si<P<S<Cl 非金属性（H₂SiO₃弱→H₃PO₄中强→H₂SO₄强→HClO₄最强）
```

- 标注：HClO 不是 Cl 最高价，不能据此判非金属性；最高价含氧酸酸性≠非金属性（须看最高价）。

## 五、化学键网络（离子键 · 共价键 · 分子间力 · 氢键）

```
   化学键（相邻原子/离子间强烈作用）
   ├─ 离子键：阴阳离子间静电作用（引力+斥力平衡）
   │   成键=电子转移；活泼金属(IA/IIA)↔活泼非金属(VIA/VIIA)、铵盐
   │   离子化合物必含离子键（可同时含共价键：NaOH、Na₂O₂）
   │   熔融/水溶液导电、熔沸点高
   └─ 共价键：原子间共用电子对
        ├─ 极性键/非极性键（同种原子非极性，不同种原子极性 δ⁻/δ⁺）
        └─ σ键/π键：单=1σ 双=1σ+1π 三=1σ+2π
        共价化合物只含共价键（可含配位键，如 NH₄⁺ 内），熔融不导电
        配位键：一方孤对+一方空轨道（NH₃+H⁺→NH₄⁺），形成后与共价键无区别
   分子间作用力（比化学键弱，分子之间）
   ├─ 范德华力：取向力(永久偶极-永久偶极)/诱导力/色散力(瞬时偶极,常主导)
   │   分子量↑/极性↑ → 范德华力↑ → 熔沸点↑
   └─ 氢键：X—H···Y（X,Y 多为 F/O/N），5~40 kJ/mol 量级（强分子间作用）
        · 条件：H 连强电负性 F/O/N 作供体 + 另一 F/O/N 有孤对作受体
        · 有 H 不等于有氢键（CH₄、HCl 非典型供体）
        · 分子间氢键↑沸点（H₂O、HF、NH₃）；分子内氢键常↓沸点（邻硝基苯酚<对硝基苯酚）
        · 氢键不是化学键；DNA 碱基对 A-T(2)/G-C(3)、蛋白质二级结构、水的反常(冰密度<水)
   电子式（梁老师规范）：
     原子 H· Na· ·Mg· ·O· ；阳离子 Na⁺ Mg²⁺ ；阴离子 [:Cl:]⁻ [:O:]²⁻
     离子化合物相同离子不合并 [:Cl:]⁻Mg²⁺[:Cl:]⁻ ；形成 Na× + ·Cl: → Na⁺[:Cl:]⁻
     共价分子 H:H  Cl₂ :Cl—Cl:  H₂O H:O:H  CO₂ O=C=O  N₂ N≡N
```

- 标注：NH₄Cl 是离子化合物但 NH₄⁺ 内是共价键（含配位键）；Na₂O₂ 既有离子键又有 O—O 非极性共价键；AlCl₃ 是共价化合物（熔融不导电）；π 键先于 σ 键断裂。

## 六、双轴与第一~三章打通

```
            "位—构—性"三角 升维 "类别 × 价态"双轴
   第一~三章：具体元素（Na/Cl/Fe/Al）用"类别×价态"双轴预测性质
   第四章：  把具体元素升维为一般规律——原子结构决定位置、位置呈现递变、键型决定物性
   打通链：
     Ch1 分类观 / 离子反应 / 氧化还原
       → Ch2 钠氯范式（双轴 + 宏微符）+ n 桥梁
       → Ch3 铁/铝双轴迁移 + 材料模型 + n 收口
       → Ch4 位—构—性三角（结构决定性质的总纲）
   实例对照：
     前面学 Na 活泼（最外层 1e）→ 本章知 Na 在第 IA、s 区、金属性最强之一
     前面学 Cl 强氧化（最外层 7e）→ 本章知 Cl 在第 VIIA、p 区、非金属性强
     前面学 Al 两性 → 本章知 Al 在第 IIIA、p 区、电负性差使 AlCl₃ 为共价（例外）
     前面学 Fe 变价 → 本章知 Fe 在 d 区(3d⁶4s²)、过渡金属多变价根源在 d 电子
```

- **研究方法贯通**：Ch1 分类→预测→实验→离子反应/氧化还原解释；Ch2/Ch3 双轴+宏微符；Ch4 位—构—性三角是上述方法的系统化与升维，回答"为什么"而非仅"是什么"。

## 八、与后续知识系统的接口

- **位—构—性三角（结构决定性质）** → 选择性必修2《物质结构与性质》：电子排布式（1~36 号）、能级交错与钻穿、洪特规则特例（Cr 3d⁵4s¹、Cu 3d¹⁰4s¹）、σ/π 键、杂化轨道、分子空间结构、晶体（离子/共价/金属/分子晶体）；→ 选择性必修3《有机化学基础》分子结构与官能团性质。
- **周期律数据（半径·第一电离能·电负性）** → 选择性必修2 元素性质递变深化、对角线规则（Li-Mg、Be-Al、B-Si）；→ 竞赛衔接（第一电离能反常 ⅡA>ⅢA、ⅤA>ⅥA 高频考点）。
- **化学键与分子间力** → 选择性必修1《化学反应原理》反应与能量（旧键断新键成→反应热 ΔH≈Σ反应物键能−Σ生成物键能）；→ 选择性必修2 晶体结构与性质（氢键网络决定冰密度<水、蛋白质/DNA 结构稳定）；→ 范德华力/氢键解释沸点、溶解度、相似相溶。
- **分区与过渡元素** → 选择性必修2 过渡元素（d 区多变价、配合物色彩）、f 区镧系（镧系收缩）、稀土战略与 STSE 议题；→ [[元素周期表分区]]、[[过渡元素]]、[[稀土元素]] 深化。
- **第一~三章方法承接**：Ch4 把 Ch1 分类观/离子反应/氧化还原、Ch2/Ch3"类别×价态"双轴与宏微符范式，升维为"位—构—性"三角；前面学的 Na/Cl/Fe/Al 具体性质，在本章获得"电子排布—周期位置—递变规律—键型物性"的统一解释。
