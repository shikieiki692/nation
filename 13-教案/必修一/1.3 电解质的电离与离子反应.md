# 教案：1.3 电解质的电离与离子反应（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.3 电解质的电离与离子反应 / 第 3 课时 / 45 min / 新授课 / 高一基础班（兼顾拔高）
> 库内锚点：[[物质分类与离子反应]]、[[离子方程式]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：将"1.2.1 电解质的电离"与"1.2.2 离子反应与离子方程式"两节深度融合，从电离微观模型一路推进到离子共存、与量有关、信息型方程式，建立"电离—拆写—反应—共存"的完整方法链，难度较旧版两节明显加深加全。

## 一、课标对应

- **内容要求**（必修课程主题 2 常见的无机物及其应用）：认识酸、碱、盐等电解质在水溶液中的电离；通过实验探究认识离子反应及其发生的条件；能从宏观与微观相结合的视角分析与解决实际问题；能书写简单的离子方程式。
- **学业质量水平**（必修，水平 2）：能根据物质的组成对物质进行分类，能用电离方程式表示酸、碱、盐的电离；能运用"写—拆—删—查"书写离子方程式；能判断离子能否大量共存；能从微观离子视角解释宏观导电、沉淀、净化等真实问题。
- **核心素养落点**（本课重点发展的 4 个素养）：
  1. **宏观辨识与微观探析**——从"灯泡亮/不亮""电导仪读数变化""白色沉淀"等宏观现象，建立"自由移动离子"与"某些离子浓度降低"的微观解释模型，并统一金属导电（电子）与电解质溶液导电（离子）的异同。
  2. **变化观念与平衡思想**——认识电离是溶质溶于水自发发生的变化（弱电解质存在电离平衡），离子反应产物受相对用量制约（少量/过量不同），体会反应随条件变化的限度思想。
  3. **证据推理与模型认知**——用"向蒸馏水渐加 NaCl 灯渐亮""Ba(OH)₂ 滴稀 H₂SO₄ 导电性先降后升"等证据推理，建构"化合物→电离与否→电解质/非电解质""完全/部分电离→强/弱""写—拆—删—查"与"拆/不拆判定"等判据模型。
  4. **科学态度与社会责任**——通过"湿手触电""粗盐水净化"等真实情境，形成用电安全意识与用化学视角审视生活信息的习惯；养成书写必查"原子+电荷守恒"、共存必排隐含条件的严谨科学态度。

- **课时内容结构（A→B→C→D 四层递进）**：
  - **A 电离层**：导电本质（自由移动离子，导电能力 ∝ 离子浓度 × 电荷数）→ 电解质/非电解质（化合物前提，CO₂/SO₂/NH₃ 自身非电解质）→ 强/弱电解质（完全/部分电离，与溶解度无关）→ 电离方程式（= 与 ⇌、酸式盐、多元弱酸分步）。
  - **B 离子反应层**：本质（某些离子浓度降低）→ 四步法（写—拆—删—查）→ 拆写精确边界（强溶才拆，澄清石灰水/石灰乳、微溶物、浓 H₂SO₄、NH₃·H₂O 不拆）→ 表示"一类反应" → 五角度正误判断。
  - **C 共存层**：六类受阻（沉淀/气体/弱电解/氧化还原/双水解/络合）+ 隐含条件（无色、酸性、碱性，HCO₃⁻ 四不共存）。
  - **D 难度提升层**：导电性曲线（Ba(OH)₂ 滴 H₂SO₄，B 处≈0）→ 与量有关（不足量定系数 1）→ 滴加顺序影响 → 信息型离子方程式 → 氧化还原/双水解综合共存大题。

## 二、学情分析（本课时）

**【课前诊断·5 处典型误解预判】**

- 学生常把"能导电"直接等同"电解质"，忽略"化合物"前提，易误判 Cu、食盐水为电解质。
- 学生常把"溶解性"与"电离程度"混淆，认为 BaSO₄ 难溶即弱电解质、CH₃COOH 易溶即强电解质（强弱看是否完全电离，与溶解度无关）。
- 学生写离子方程式时"拆"的边界模糊，常错拆 BaSO₄、浓 H₂SO₄、弱碱与微溶物。
- 学生对 CO₂ 通入 NaOH、AlCl₃ 滴加 NaOH 等"与量有关"的反应缺乏"以不足量定基准"的方法。
- 学生判断离子共存仅记"沉淀/气体/弱电解质"，漏掉氧化还原、双水解、络合及"无色、酸性、碱性"等隐含条件。

本节前，学生已在 1.1 建立物质分类框架，但在"电离—离子反应"链条上仍存在多处顽固认知偏差：① 把"能导电"直接等同"电解质"，忽略"化合物"前提，易误判 Cu、食盐水；② 长期把"溶解性"与"电离程度"混淆，认为 BaSO₄ 难溶即弱电解质、CH₃COOH 易溶即强电解质；③ 写离子方程式时"拆"的边界模糊，常错拆 BaSO₄、浓 H₂SO₄、弱碱与微溶物；④ 对 CO₂ 通入 NaOH、AlCl₃ 滴加 NaOH 等"与量有关"反应缺乏"以不足量定基准"的方法；⑤ 离子共存仅记"沉淀/气体/弱电解"，漏掉氧化还原、双水解、络合及"无色、酸性、碱性"等隐含条件。本课即从这五处聚焦突破，将两节合并为一条可迁移的方法链。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标

- **宏观辨识与微观探析**：能基于"自由移动带电粒子"统一解释金属导电（电子）与电解质溶液/熔融导电（离子）的异同；能由沉淀、气体、导电性变化等宏观现象反推"某些离子浓度降低"的微观本质。
- **变化观念与平衡思想**：能阐明电离是溶质溶于水自发发生的过程（弱电解质存在电离平衡，用 ⇌）；能说明同一组反应物因相对用量不同产物不同，建立"以不足量物质为基准配平"的变化观。
- **证据推理与模型认知**：能建构"化合物→是否电离→电解质/非电解质""完全/部分电离→强/弱"的判据模型；能用"写—拆—删—查"规范书写离子方程式，并据"物质在溶液中主要以什么形式存在"判定拆/不拆。
- **科学态度与社会责任**：能运用离子共存与离子反应原理解释湿手触电、粗盐水净化等真实问题；养成书写必查"原子+电荷守恒"、共存必排隐含条件的严谨习惯。

### 3.2 学习目标（学生能……，可观测）

1. 能正确判断约 12 种给定物质（单质、混合物、化合物）是否属于电解质/非电解质，独立说出"化合物"前提，并完整写出"CO₂ 溶于水导电但 CO₂ 自身是非电解质"的因果链（点明是 H₂CO₃ 电离）。
2. 能依据"是否完全电离"区分强/弱电解质，举例说明 BaSO₄ 难溶却为强电解质、CH₃COOH 易溶却为弱电解质；能规范书写强电解质（=）、弱电解质（⇌）电离方程式，含多元弱酸分步（H₃PO₄ 三步、H₂CO₃ 两步）与酸式盐（NaHSO₄、NaHCO₃、NaHSO₃）拆写。
3. 能独立用四步法书写 CaCO₃+HCl、Ba(OH)₂+H₂SO₄、MgO+盐酸 等常见离子方程式，"拆/不拆"零错误，并能从"事实/拆写/守恒/符号/量比"五角度判断给定式正误。
4. 能按"先排颜色→再排六类（沉淀/气体/弱电解/氧化还原/双水解/络合）→再排酸碱性"顺序判断限定条件下的离子共存，含隐含条件与氧化还原型（如 Fe³⁺ 与 I⁻）。
5. 能就 CO₂ 通 NaOH、AlCl₃ 加 NaOH、Na₂CO₃ 加 HCl、Ca(HCO₃)₂ 加 NaOH 四组"与量有关"反应，用"不足量定系数 1"法写出少量/过量两式，并说明滴加顺序的影响。

## 五、教学媒体与素材

- **实验装置**：低压导电性实验器（灯泡或数字电导仪）、电极、烧杯、滴管；演示用 NaCl 固体、蒸馏水、NaCl 溶液、蔗糖溶液、盐酸、醋酸、BaSO₄ 粉末、Cu 片、食盐水、Ba(OH)₂ 溶液、稀 H₂SO₄、CaCO₃ 粉末。
- **核心演示一**：向蒸馏水中小心渐加 NaCl 粉末，实时读数由近 0 持续上升——佐证电离是自发的，离子浓度决定导电性。
- **核心演示二**：向 Ba(OH)₂ 溶液滴加稀 H₂SO₄，测导电性记"先降—B 处≈0—后升"曲线，观白色 BaSO₄ 沉淀——得出离子反应本质与"恰好完全反应"判据。
- **微观动画**：NaCl 晶体受水分子极性作用解离为自由移动的 Na⁺、Cl⁻ 并水合；Ba²⁺ 与 SO₄²⁻ 结合成 BaSO₄ 沉淀网格。
- **大情境**：①"湿手触电"安全科普（自来水含离子，湿手电阻骤降）；②粗盐水净化（用 BaCl₂、NaOH、Na₂CO₃ 顺序除去 Ca²⁺、Mg²⁺、SO₄²⁻）。
- **化学史**：阿伦尼乌斯电离理论（1883 提出电离假说，1903 获 Nobel 化学奖；库内 KP 含详述）。

### 环节一：情境导入——从"导电"到"离子重组"

**【逐字稿】**

**教师**："两个生活问题。其一，长辈说'湿手别碰开关'，纯水不是绝缘体吗，危险从哪来？其二，海水晒盐得到的粗盐水，怎么把里面的 Ca²⁺、Mg²⁺、SO₄²⁻ 这些杂质'抓'出去变成精盐？"

**学生（预期）**："自来水不是纯水，里面有杂质能导电……""加试剂让杂质沉淀？"

**学生（预期，典型错误）**："是不是水本身通电后变成离子才导电？"

**教师（追问/理答）**："两个问题的答案都指向'看不见的离子'。先破除误区：不是'通电后'才产生能导电的粒子，而是某些物质**溶于水之前、没通电时**就以离子形式存在了。湿手触电，正是因为自来水中含 Na⁺、Cl⁻、Ca²⁺ 等自由离子，电阻骤降。而粗盐水净化，本质是让杂质离子和加入的离子结合成沉淀'离开'溶液——这是离子之间的重新组合，即离子反应。今天我们把'电离'与'离子反应'合成一条链讲透。"

### 环节二：电离模型——导电本质与电解质/非电解质

**【逐字稿】**

**教师**："桌上五组待测：NaCl 固体、蒸馏水、NaCl 溶液、蔗糖溶液、Cu 片。预测灯泡亮暗再实测。注意 NaCl 固体是干燥的，别被'盐'字骗了。"

**学生（预期）**："NaCl 固体不亮、蒸馏水几乎不亮、NaCl 溶液亮、蔗糖溶液不亮、Cu 片亮。"

**教师（追问/理答）**："两组'亮'本质一样吗？NaCl 溶液亮因 Na⁺、Cl⁻ 自由移动；Cu 亮因金属有自由电子。所以**导电本质 = 有自由移动的带电粒子**：金属靠电子，溶液/熔融靠离子。导电能力强弱 ∝ 单位体积内'离子浓度 × 离子电荷数'——同浓度下二价离子比一价贡献更大。那蔗糖溶液为什么不亮？"

**学生（预期）**："蔗糖在水里还是分子，没拆成离子。"

**教师（追问/理答）**："准确。现在看更妙的演示——" *（向蒸馏水中小量多次加 NaCl 粉末，电导读数从近 0 持续上升）* "读数变大说明电离是**自发过程**，通电只是让已有离子定向移动。下面给'能电离的化合物'命名。"

**教师**："定义：在**水溶液里或熔融状态下**能导电的**化合物**，叫电解质。三要素，谁最易忘？"

**学生（预期，典型错误）**："Cu 能导电，Cu 是电解质吧？""食盐水导电，食盐水是电解质！"

**教师（追问/理答）**："两个经典错答，根子在同一处——忘了'**化合物**'。Cu 是单质、食盐水是混合物（NaCl+水），它们**既不是电解质也不是非电解质**。判据第一步：先问'是不是化合物'，不是直接踢出局。"

**教师**："第二类坑：CO₂ 溶于水后溶液能导电，CO₂ 是电解质吗？"

**学生（预期，典型错误）**："能导电，应该是电解质。"

**教师（追问/理答）**："错。CO₂ 溶于水导电，是因它和水反应生成 H₂CO₃，是 H₂CO₃ 电离出 H⁺ 和 HCO₃⁻；CO₂ **自身**在水溶液里不电离。同理 SO₂ 靠 H₂SO₃、NH₃ 靠 NH₃·H₂O 电离。所以 CO₂、SO₂、NH₃ 都是**非电解质**，而 H₂CO₃、H₂SO₃、NH₃·H₂O 才是弱电解质。判据第二步：看'谁'电离，别被'溶液导电'带偏。"

**教师（制造冲突）**："BaSO₄ 难溶几乎不导电，它是不是非电解质？"

**学生（预期，典型错误）**："难溶，溶都溶不了，应不是电解质。"

**教师（追问/理答）**："这正是'难溶≠非电解质'。先记结论：BaSO₄ **是强电解质**——它溶解的那一点点，100% 电离。'溶不溶得出来'和'溶出来后电不电离'是两件事。"

### 环节三：强/弱电解质本质与电离方程式

**【逐字稿】**

**教师**："强电解质 = 在水里**完全电离**（用 =）；弱电解质 = **部分电离**（存在电离平衡，用 ⇌）。先破执念：强弱看'电离程度'，不看'溶解度'。三连比——"

**教师**："BaSO₄：难溶但溶解部分全电离→**强**；CH₃COOH：极易溶但只部分电离→**弱**；Ca(OH)₂：微溶但溶解部分全电离→**强**。所以'难溶=弱电解质'是错的。"

**学生（预期，典型错误）**："那 BaSO₄ 电离式用 '=' 还是 '⇌'？"

**教师（追问/理答）**："BaSO₄ 是强电解质，用 '='；但它难溶，整体写电离式意义不大。重点清单：NaCl、HCl、NaOH、BaSO₄、Ca(OH)₂、熔融 NaOH 全用 '='；CH₃COOH、NH₃·H₂O、H₂CO₃、H₃PO₄、Cu(OH)₂ 用 '⇌'。多元弱酸**分步**写，不能一步写完。"

**教师**："练手：H₃PO₄ 三元中强酸，写三步；H₂CO₃ 二元弱酸，写两步。"

**学生（预期）**："H₃PO₄ ⇌ H⁺ + H₂PO₄⁻；H₂PO₄⁻ ⇌ H⁺ + HPO₄²⁻；HPO₄²⁻ ⇌ H⁺ + PO₄³⁻。H₂CO₃ ⇌ H⁺ + HCO₃⁻；HCO₃⁻ ⇌ H⁺ + CO₃²⁻。"

**教师（追问/理答）**："对。多元弱碱（如 Cu(OH)₂）则一步写齐：Cu(OH)₂ ⇌ Cu²⁺ + 2OH⁻。再看酸式盐——这是易错高发区："

**教师**："NaHSO₄ 在水溶液完全电离成 Na⁺ + H⁺ + SO₄²⁻（HSO₄⁻ 强酸的酸式根，进一步电离）；NaHSO₃ = Na⁺ + HSO₃⁻（HSO₃⁻ 是弱酸的酸式根，**不拆**，保留 HSO₃⁻）；NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 弱酸酸式根不拆）。规律：**弱酸的酸式根一律不拆**，只有强酸的酸式根（HSO₄⁻ 在稀溶液中）才继续电离出 H⁺。"

**教师（抛反直觉）**："最后：浓 H₂SO₄ 为什么不导电？"

**学生（预期，典型错误）**："硫酸是强酸，应该导电啊。"

**教师（追问/理答）**："导电靠自由移动的离子。浓 H₂SO₄ 里水极少，几乎以 H₂SO₄ 分子态存在，电离被'渴死'；只有加水稀释成稀 H₂SO₄，才大量电离出 H⁺ 和 SO₄²⁻ 而导电。所以'强酸'≠'任何浓度都导电'，关键看有没有水让它电离——这也直接决定它写离子方程式时**浓的不拆、稀的拆**。"

### 环节四：离子反应本质与四步法

**【逐字稿】**

**教师**："向 Ba(OH)₂ 溶液滴加稀 H₂SO₄，看电导仪与沉淀。预言曲线形状。"

**学生（预期）**："有白色沉淀；读数先降后升？"

**教师（追问/理答）**："为何'先降'？因 Ba²⁺ + SO₄²⁻ → BaSO₄↓、H⁺ + OH⁻ → H₂O，自由离子被消耗，离子浓度降低，导电性下降——这正是**离子反应本质：某些离子浓度降低**（生成沉淀/气体/弱电解质/发生氧化还原）。"

**学生（预期，典型错误）**："那为什么后又升？不是反应完了吗？"

**教师（追问/理答）**："恰好完全反应时（曲线最低点 B 处），四种离子几乎被消耗完，导电性≈0——B 处≈0 是'恰好完全反应'的铁证：此时溶液中几乎没有自由移动的离子。继续滴过量稀 H₂SO₄，新引入的 H⁺、SO₄²⁻ 让离子浓度回升，导电性回升。这条曲线是离子反应本质最直观的证据。"

**教师**："把反应写成离子方程式，四步法——写、拆、删、查。先'写'：Ba(OH)₂ + H₂SO₄ = BaSO₄↓ + 2H₂O。"

**学生（预期）**："Ba(OH)₂ 拆 Ba²⁺+2OH⁻；H₂SO₄ 拆 2H⁺+SO₄²⁻；BaSO₄、H₂O 不拆。"

**教师（追问/理答）**："第二步'拆'——易溶且易电离才拆。于是：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO₄↓ + 2H₂O。第三步'删'旁观离子：本式 Ba²⁺、OH⁻、H⁺、SO₄²⁻ 全参与了（成沉淀或水），**零旁观离子**，无需删。第四步'查'——原子守恒且电荷守恒：左总电荷 +2−2+2−2=0，右中性，守恒。"

**教师**："关键认知：此式不只代表'Ba(OH)₂ 和 H₂SO₄ 这一个反应'，它代表**所有**生成 BaSO₄ 的'钡盐 + 硫酸根'反应；而 H⁺ + OH⁻ = H₂O 更代表**所有强酸强碱中和**。所以离子方程式表示'一类反应'。五角度正误判断：① 是否符合事实；② 质量守恒；③ 电荷守恒；④ 拆分规则；⑤ 符号（↓↑⇌）与反应环境。"

**教师**："用五角度现场挑错三个式：甲. Fe + 2H⁺ = Fe²⁺ + H₂↑（稀硫酸）；乙. CaCO₃ + H⁺ = Ca²⁺ + CO₂↑ + H₂O；丙. Ba²⁺ + OH⁻ + H⁺ + SO₄²⁻ = BaSO₄↓ + H₂O。"

**学生（预期，典型错误）**："甲对？乙好像缺个 2？丙是不是也缺系数？"

**教师（追问/理答）**："甲：事实对（Fe 在 H 前，稀酸出 H₂）、质量电荷均守恒、拆写对（H₂SO₄ 拆、H₂O 不拆）→正确。乙：电荷不守恒（左 +1、右 +2），应 CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O→错在电荷。丙：这是把 Ba(OH)₂ 拆成'Ba²⁺+OH⁻'（少 1 个 OH⁻）、H₂SO₄ 拆成'H⁺+SO₄²⁻'（少 1 个 H⁺），Ba(OH)₂、H₂SO₄ 都是 1:2 电离→错在拆写（系数）。五角度逐条过，比死记高效。"

### 环节五：拆写精确边界与离子共存

**【逐字稿】**

**教师**："把'拆/不拆'做成判定清单，核心只问一句：它在溶液里主要以什么形式存在？能拆——强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶盐。不拆——难溶物（BaSO₄、CaCO₃）、弱电解质（CH₃COOH、NH₃·H₂O、H₂O）、气体、单质、氧化物。"

**教师**："现在抛精确边界冲突。① BaSO₄ 是强电解质，离子方程式拆不拆？"

**学生（预期，典型错误）**："强电解质，应该拆吧？"

**教师（追问/理答）**："错，'强电解质'和'拆不拆'两件事。BaSO₄ 是强电解质（溶解部分全电离），但**难溶**，溶液里几乎以固体存在，作沉淀**不拆**。口诀'**强溶才拆**'——既强电解、又要可溶可电离才拆。② 浓 H₂SO₄ 分子态为主→不拆；稀 H₂SO₄ 才拆。③ 微溶物 Ca(OH)₂：**澄清石灰水拆成 Ca²⁺+2OH⁻，石灰乳不拆（写 Ca(OH)₂(s)）**。④ 作反应物：微溶物稀溶液拆、浊液不拆；作生成物一律不拆。⑤ NH₃·H₂O 弱碱不拆；氧化物、单质不拆。"

**教师**："进入共存。离子不能大量共存有六类原因——"

**学生（预期）**："生成沉淀、气体、弱电解质，还有氧化还原！比如 Fe³⁺ + I⁻。"

**教师（追问/理答）**："齐了，再加双水解与络合。六类：① 沉淀（如 Ba²⁺+SO₄²⁻、Ca²⁺+CO₃²⁻）；② 气体（CO₃²⁻+2H⁺=H₂O+CO₂↑）；③ 弱电解质（H⁺+OH⁻=H₂O、CH₃COOH 与 CH₃COO⁻ 等）；④ 氧化还原（Fe³⁺ 氧化 I⁻、S²⁻、SO₃²⁻；酸性 MnO₄⁻/NO₃⁻ 氧化 Fe²⁺、I⁻）；⑤ 双水解（Al³⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻；Fe³⁺ 与 CO₃²⁻——且有时伴随氧化还原，如 Fe³⁺ 与 S²⁻ 既双水解又氧化还原）；⑥ 络合（Fe³⁺ + SCN⁻ = [Fe(SCN)]²⁺ 等）。"

**教师**："隐含条件三件套：无色先排除 Cu²⁺(蓝)、Fe³⁺(棕黄)、Fe²⁺(浅绿)、MnO₄⁻(紫)；酸性含 H⁺；碱性含 OH⁻。特殊：HCO₃⁻ 与 H⁺、OH⁻、Al³⁺、Fe³⁺ 均不共存（遇 H⁺ 出 CO₂，遇 OH⁻ 转 CO₃²⁻，遇 Al³⁺/Fe³⁺ 双水解）。解题顺序我强调：**先排颜色，再排六类反应，最后排酸碱性**——别一上来就盯反应漏颜色。"

**教师**："现场练一道综合共存：'无色、碱性'溶液中，下列能否大量共存？A. Na⁺、K⁺、Cl⁻、SO₄²⁻；B. Cu²⁺、K⁺、SO₄²⁻、NO₃⁻；C. Na⁺、NH₄⁺、K⁺、Cl⁻、SO₄²⁻；D. Na⁺、K⁺、CO₃²⁻、Ba²⁺。"

**学生（预期，典型错误）**："A 可以；B 有 Cu²⁺ 蓝色不行；C……NH₄⁺ 在碱性下？D 有 Ba²⁺ 和 CO₃²⁻ 沉淀？"

**教师（追问/理答）**："全中。A 全部彼此无六类反应→可存。B 含 Cu²⁺ 违'无色'→否。C 在碱性下 NH₄⁺ + OH⁻ = NH₃·H₂O→不存（隐含条件踩雷）。D 中 Ba²⁺ + CO₃²⁻ = BaSO₄↓？不，是 BaCO₃↓（沉淀）→不存。注意 D 的沉淀属'六类第一阻'，与颜色无关。所以解题顺序真能避免漏网：先颜色踢 B，再六类踢 D，再酸碱性踢 C。"

### 环节六：与量有关、滴加顺序、信息型（核心示范 + 课后延伸）

**【逐字稿】**

**教师**："最难一层：同一组反应物，量不同产物不同。核心方法——'**不足量定系数 1**'：把少量一方系数设为 1，按需配平过量方。四组示范："

**教师**："① CO₂ 通 NaOH：CO₂ 少量→CO₂ + 2OH⁻ = CO₃²⁻ + H₂O；CO₂ 过量→生成的 CO₃²⁻ 被继续转化→CO₂ + OH⁻ = HCO₃⁻。② AlCl₃ 滴加 NaOH：NaOH 少量→Al³⁺ + 3OH⁻ = Al(OH)₃↓；NaOH 过量→Al³⁺ + 4OH⁻ = AlO₂⁻ + 2H₂O（沉淀溶）。③ Na₂CO₃ 加 HCl：HCl 少量→CO₃²⁻ + H⁺ = HCO₃⁻；HCl 过量→CO₃²⁻ + 2H⁺ = H₂O + CO₂↑。④ Ca(HCO₃)₂ 加 NaOH：NaOH 少量（按 1 计）→Ca²⁺ + HCO₃⁻ + OH⁻ = CaCO₃↓ + H₂O；NaOH 过量→Ca²⁺ + 2HCO₃⁻ + 2OH⁻ = CaCO₃↓ + CO₃²⁻ + 2H₂O。"

**教师**："**滴加顺序影响产物**：向 AlCl₃ 滴加 NaOH（OH⁻ 不足先沉淀，过量才溶）vs 向 NaOH 滴加 AlCl₃（Al³⁺ 不足直接生成 AlO₂⁻），现象与最终式都不同。信息型：给陌生反应先判产物再拆——如用 FeCl₃ 溶液刻蚀铜电路板：2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（氧化还原，无沉淀气体仍属离子反应）。"

### 环节七：随堂检测与即时理答（并入末 2 min + 课后即时反馈）

**【逐字稿】**

**教师**："当堂口答三题，检验方法链是否落地。题一：稀硫酸 + Cu 能写 Cu + 2H⁺ = Cu²⁺ + H₂↑ 吗？"

**学生（预期，典型错误）**："活泼金属和酸出氢气，应该可以？"

**教师（追问/理答）**："陷阱。Cu 在金属活动性顺序中位于 H 之后，**稀硫酸与 Cu 不反应**——此式违背事实，判错。只有浓硫酸加热才氧化 Cu，且产物是 SO₂ 而非 H₂，且浓硫酸不拆。题二：MgO + 盐酸，写 MgO + 2H⁺ = Mg²⁺ + H₂O，对吗？"

**学生（预期）**："对，MgO 是氧化物不拆，盐酸强酸拆，生成水弱电解质不拆。"

**教师（追问/理答）**："完全正确，这是规范式。题三：Cu + AgNO₃ 写成 Cu + Ag⁺ = Cu²⁺ + Ag，错在哪？"

**学生（预期，典型错误）**："好像……电荷没守恒？左边 +1，右边 +2。"

**教师（追问/理答）**："正是。电荷不守恒：应为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag。五角度里'电荷守恒'最易漏，写完必查一遍左右总电荷。"

**即时检测题（课后作业前口头过一遍）**

1. 判断正误并说明理由：① 食盐水是电解质；② BaSO₄ 难溶故为弱电解质；③ CO₂ 溶于水导电故 CO₂ 是电解质；④ 浓 H₂SO₄ 是强酸故一定导电；⑤ 离子方程式 H⁺ + OH⁻ = H₂O 只代表 NaOH 与 HCl 一个反应。
2. 写出 NaHCO₃ 溶于水、NaHSO₄ 溶于水、H₂CO₃ 两步电离的方程式。
3. 用四步法写 CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑ 的离子方程式（提示：CaCO₃ 不拆、HCl 拆、CO₂ 气体不拆、H₂O 不拆）。
4. 在"无色碱性"溶液中，Na⁺、K⁺、NH₄⁺、Cl⁻、SO₄²⁻、CO₃²⁻、MnO₄⁻、Cu²⁺ 哪些必不能共存？写出理由。

**解析要点（教师理答，供课后对照）**

- ① 错（混合物，既不是）；② 错（难溶但溶解部分全电离，强电解质）；③ 错（自身不电离，非电解质，H₂CO₃ 才是弱电解质）；④ 错（分子态为主不电离，不导电）；⑤ 错（代表所有强酸强碱中和，表"一类反应"）。
- NaHCO₃ = Na⁺ + HCO₃⁻；NaHSO₄ = Na⁺ + H⁺ + SO₄²⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻，HCO₃⁻ ⇌ H⁺ + CO₃²⁻。
- CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑（左电荷 +2、右 +2，守恒；CaCO₃、CO₂、H₂O 均不拆）。
- 无色⇒排 MnO₄⁻(紫)、Cu²⁺(蓝)；碱性含 OH⁻⇒NH₄⁺ + OH⁻ = NH₃·H₂O 不共存。故必不能共存：MnO₄⁻、Cu²⁺、NH₄⁺；可共存：Na⁺、K⁺、Cl⁻、SO₄²⁻、CO₃²⁻（彼此无六类反应）。

| 澄清石灰水 = 石灰乳（都拆/都不拆） | 澄清石灰水拆 Ca²⁺+2OH⁻；石灰乳不拆 Ca(OH)₂(s) | 忽略状态差异 |
| NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻ | NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 不拆） | 弱酸酸式根误拆 |
| 离子方程式只代表"一个反应" | 代表"一类反应"（如 H⁺+OH⁻=H₂O 表所有强酸强碱中和） | 未建立离子视角抽象 |
| 共存只看沉淀/气体/弱电解 | 还须排氧化还原、双水解、络合 + 隐含条件 | 漏六类与隐含 |
| 无色酸性溶液忽略颜色/酸碱性 | 先排 Cu²⁺/Fe³⁺/Fe²⁺/MnO₄⁻，再看 H⁺ 相关反应 | 解题顺序混乱 |

**【逐字稿小结】**

**教师**："把这张表贴在学案第一页。前六行是'电离判据'坑，核心一句话——**电解质先问'化合物'，强弱只看'电离程度'不看'溶解度'**。中间三行是'拆写'坑，核心——**强溶才拆**，状态决定拆不拆。最后三行是'离子式与共存'坑，核心——**离子式表一类、共存排六类加隐含**。下节课我们拿这张表做 5 分钟快闪检测。"

## 七、板书设计

```
**Part 1 本课逻辑主线（主板书）**——逻辑：导电现象→电离(钻进离子)→离子反应(离子浓度降低)→共存/与量有关。

【A 电离】
- 导电本质=自由移动的带电粒子（金属→自由电子；溶液/熔融→自由离子）；导电能力 ∝ 离子浓度 × 离子所带电荷数
- 电解质=在水溶液中**或**熔融状态下能导电的**化合物**（前提：必须是化合物！Cu、食盐水既不是电解质也不是非电解质）
- 非电解质=两态均不能导电的化合物（蔗糖、酒精、CCl₄、CO₂、SO₂、NH₃）；关键：CO₂/SO₂/NH₃ 自身不电离→非电解质，其水溶液导电是因与水生成 H₂CO₃/NH₃·H₂O（才是弱电解质）电离
- 强电解质=完全电离（"="）：强酸/强碱/大多数盐（含难溶盐 BaSO₄ 溶解部分完全电离）、活泼金属氧化物（熔融导电）；弱电解质=部分电离（"⇌"）：弱酸/弱碱/水
- 铁律：难溶≠弱（BaSO₄ 强）、易溶≠强（CH₃COOH 弱）、"通电才电离"是错（阿伦尼乌斯：电离自发，通电前已有离子）
- 酸式盐：NaHSO₄=Na⁺+H⁺+SO₄²⁻（电离出 H⁺ 显酸）；NaHCO₃=Na⁺+HCO₃⁻（HCO₃⁻ 弱酸根不拆、部分电离 HCO₃⁻⇌H⁺+CO₃²⁻）；NaHSO₃=Na⁺+HSO₃⁻
- 多元弱酸分步：H₃PO₄⇌H⁺+H₂PO₄⁻⇌H⁺+HPO₄²⁻⇌H⁺+PO₄³⁻；H₂CO₃⇌H⁺+HCO₃⁻⇌H⁺+CO₃²⁻
- 浓 H₂SO₄ 分子态不导电、不拆；稀 H₂SO₄ 才拆

【B 离子反应】
- 本质=溶液中某些离子浓度降低（沉淀/气体/弱电解质/氧化还原）
- 离子方程式表示"一类反应"（H⁺+OH⁻=H₂O 代表所有强酸强碱中和生成可溶盐）
- 四步法：写→拆→删(旁观离子)→查(原子+电荷守恒，电荷最易漏)
- 拆的精确边界：可溶强电解质拆（强酸/强碱/可溶盐）；不拆=难溶物/弱电解质/气体/单质/氧化物/浓 H₂SO₄/NH₃·H₂O/微溶物作生成物或浊液。澄清石灰水拆 Ca²⁺+2OH⁻；石灰乳不拆 Ca(OH)₂(s)；微溶物反应物稀溶液拆、浊液不拆
- 五角度正误：事实/拆写/守恒(质+电)/符号(↓↑⇌)/量比

【C 共存】六阻+隐含：沉淀/气体/弱电解/氧化还原/双水解/络合 + 无色(排 Cu²⁺蓝/Fe³⁺棕黄/Fe²⁺浅绿/MnO₄⁻紫)/酸碱性/HCO₃⁻ 与 H⁺/OH⁻/Al³⁺/Fe³⁺ 均不共存。解题序：先颜色→再六类→再酸碱性

【D 与量有关】不足量定系数1：CO₂少→CO₃²⁻、过→HCO₃⁻；Al³⁺+少OH⁻→Al(OH)₃↓、+过OH⁻→AlO₂⁻；Na₂CO₃+少H⁺→HCO₃⁻、过→H₂O+CO₂；Ca(HCO₃)₂+少/过NaOH 两式；滴加顺序影响；信息型 2Fe³⁺+Cu=2Fe²⁺+Cu²⁺（刻蚀电路板，既是离子反应又是氧化还原）
```

## 八、作业布置（三层，区分度）

> 分层说明：必做保底全体学生，选做面向中等及以上，挑战面向拔高与有志高考难题者；批改时按三层分别给反馈，错题回扣"易错点速记对照表"。

- **必做**（基础达标，覆盖事实与拆写陷阱）：[[高中化学必修一-习题精选]] 题3——判断下列离子方程式是否正确，错误的改正并说明理由：① 稀硫酸 + Cu：Cu + 2H⁺ = Cu²⁺ + H₂↑（陷阱：稀硫酸与 Cu 不反应）；② MgO + 盐酸：MgO + 2H⁺ = Mg²⁺ + H₂O（正确）；③ Cu + AgNO₃：Cu + Ag⁺ = Cu²⁺ + Ag（陷阱：电荷不守恒，应为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag）；④ CaCO₃ + 盐酸：CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O（正确）。题4——根据 Ba(OH)₂ 溶液滴加稀 H₂SO₄ 的导电性曲线，解释"先降—B 处≈0—后升"：B 处说明恰好完全反应、溶液中几乎无自由离子。
- **选做**（能力提升，与量有关 + 共存综合）：① 写出下列四组"与量有关"离子方程式的少量/过量两式：CO₂ + NaOH、AlCl₃ + NaOH、Na₂CO₃ + HCl、Ca(HCO₃)₂ + NaOH（用"不足量定系数 1"法）；② 共存判断（含隐含条件与氧化还原型）：在"无色酸性"溶液中，A. Na⁺、K⁺、SO₄²⁻、Cl⁻，B. Cu²⁺、K⁺、SO₄²⁻、NO₃⁻，C. Na⁺、CO₃²⁻、K⁺、Cl⁻，D. Fe²⁺、K⁺、MnO₄⁻、H⁺——分别判断能否大量共存并说理（答案 A；B 违无色，C 在酸性下 CO₃²⁻+2H⁺=H₂O+CO₂↑ 不存，D 中酸性 MnO₄⁻ 氧化 Fe²⁺ 且均不存）。
- **挑战**（拔高区分，信息型 + 双水解/氧化还原综合 + 复杂与量）：① 信息型离子方程式两道（给陌生反应写离子式）：(a) 用 FeCl₃ 溶液刻蚀铜电路板；(b) 向 KI 溶液中通入过量氯气（I⁻ 被氧化为 IO₃⁻）。② 一道含双水解 + 氧化还原的共存综合大题：在"无色、酸性"溶液中混有 Fe³⁺、Al³⁺、S²⁻、CO₃²⁻、NO₃⁻、K⁺、SO₄²⁻，要求逐离子判定哪些必不能大量共存，并写出涉及的双水解/氧化还原反应离子方程式（如 2Fe³⁺ + S²⁻ = 2Fe²⁺ + S↓ 兼氧化还原，2Al³⁺ + 3S²⁻ + 6H₂O = 2Al(OH)₃↓ + 3H₂S↑ 双水解，且 Fe³⁺ 与 CO₃²⁻ 双水解）。③ 一道"不足量定系数 1"的复杂与量方程式推导：向 NH₄Al(SO₄)₂ 溶液中逐滴加入 Ba(OH)₂ 溶液，分别写出 Ba(OH)₂ 少量与过量时的离子方程式（少量时 Ba²⁺ 优先与 SO₄²⁻ 成 BaSO₄↓、OH⁻ 先与 Al³⁺ 成 Al(OH)₃↓；过量时 NH₄⁺ 亦被 OH⁻ 反应、Al(OH)₃ 溶于过量 OH⁻ 转 AlO₂⁻），并验算电荷守恒。

**作业解析提示（供批改与讲评）**

- 题3 四式速判：① 错（Cu 与稀硫酸不反应，违背事实）；② 对（MgO 氧化物不拆，H⁺ 拆，H₂O 不拆）；③ 错（电荷不守恒，应 Cu + 2Ag⁺ = Cu²⁺ + 2Ag）；④ 对（CaCO₃ 沉淀不拆，HCl 拆，CO₂ 气体、H₂O 不拆）。题4 曲线：滴加初期 Ba²⁺+SO₄²⁻→BaSO₄↓、H⁺+OH⁻→H₂O，自由离子浓度下降→导电性降；恰好完全反应 B 处四离子近耗尽→导电性≈0；过量稀硫酸引入 H⁺、SO₄²⁻→回升。本质证据：离子反应使某些离子浓度降低。
- 选做四组与量：CO₂ 少→CO₂+2OH⁻=CO₃²⁻+H₂O，过→CO₂+OH⁻=HCO₃⁻；Al³⁺+少OH⁻→Al(OH)₃↓，过→Al³⁺+4OH⁻=AlO₂⁻+2H₂O；CO₃²⁻+少H⁺→HCO₃⁻，过→CO₃²⁻+2H⁺=H₂O+CO₂↑；Ca(HCO₃)₂+少NaOH→Ca²⁺+HCO₃⁻+OH⁻=CaCO₃↓+H₂O，过→Ca²⁺+2HCO₃⁻+2OH⁻=CaCO₃↓+CO₃²⁻+2H₂O。共存选做题：A 全可存；B 含 Cu²⁺ 违无色；C 在酸性下 CO₃²⁻+2H⁺=H₂O+CO₂↑ 不存；D 酸性 MnO₄⁻ 氧化 Fe²⁺（5Fe²⁺+MnO₄⁻+8H⁺=5Fe³⁺+Mn²⁺+4H₂O）且均不存。
- 挑战① 信息型：(a) 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺；(b) I⁻ 被过量 Cl₂ 氧化为 IO₃⁻：I⁻ + 3Cl₂ + 3H₂O = IO₃⁻ + 6Cl⁻ + 6H⁺（先 I⁻→I₂ 再 I₂→IO₃⁻，过量 Cl₂ 下最终态）。② 综合大题要点：Fe³⁺ 与 S²⁻ 以氧化还原为主（2Fe³⁺+S²⁻=2Fe²⁺+S↓，氧化还原优先）；Fe³⁺ 与 CO₃²⁻ 双水解（2Fe³⁺+3CO₃²⁻+3H₂O=2Fe(OH)₃↓+3CO₂↑）；Al³⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻ 双水解；酸性下 Fe²⁺ 被 NO₃⁻ 氧化。③ NH₄Al(SO₄)₂ + Ba(OH)₂：少量 Ba(OH)₂ 时 Ba²⁺ 与 SO₄²⁻ 成 BaSO₄↓、OH⁻ 先沉淀 Al³⁺→2Al³⁺+3SO₄²⁻+3Ba²⁺+6OH⁻=3BaSO₄↓+2Al(OH)₃↓（按 Ba(OH)₂ 系数 3 计对应 2 个 NH₄Al(SO₄)₂）；过量时 Al(OH)₃ 溶于过量 OH⁻、NH₄⁺ 亦被反应→NH₄⁺+Al³⁺+2SO₄²⁻+2Ba²⁺+5OH⁻=AlO₂⁻+2BaSO₄↓+NH₃·H₂O+2H₂O，须验算电荷守恒。

### 本节方法链总览（供学生课后自测）

1. **判物质**：先问"是不是化合物"→再问"水溶液/熔融能否电离"→得电解质/非电解质；再看"完全/部分电离"→得强/弱。
2. **写电离式**：强用 =、弱用 ⇌；多元弱酸分步、弱碱一步；弱酸酸式根（HCO₃⁻、HSO₃⁻）不拆。
3. **写离子式**：写（化学方程）→拆（强溶才拆，强酸/强碱/可溶盐；沉淀/弱电解/气体/单质/氧化物/微溶物浊液/浓 H₂SO₄/NH₃·H₂O 不拆）→删（旁观离子）→查（原子+电荷守恒）。
4. **判共存**：先颜色→再六类（沉淀/气体/弱电解/氧化还原/双水解/络合）→再酸碱性；HCO₃⁻ 四不共存。
5. **与量有关**：不足量定系数 1；注意滴加顺序与信息型（先判产物再拆）。
6. **本质证据**：导电性曲线 B 处≈0 ⇔ 恰好完全反应、几乎无自由离子 ⇔ 离子反应使某些离子浓度降低。
