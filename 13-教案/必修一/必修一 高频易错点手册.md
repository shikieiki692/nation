## 三、主题① 物质的分类与转化 / 分散系（胶体）

| 错误表述 | 正确结论 | 对应课时/锚点 |
|---|---|---|
| 金属氧化物必显碱性 | 不一定，可能酸性/两性/过氧化物/超氧化物（Mn₂O₇ 酸性、Al₂O₃ 两性、Na₂O₂ 过氧化物） | [[1.1 物质的分类及转化]] |
| 非金属氧化物必显酸性 | 不一定，CO、NO 不成盐；NO₂ 歧化非典型酸性氧物 | [[1.1 物质的分类及转化]] |
| 盐溶液都呈中性 | 酸式盐可显酸或显碱：NaHSO₄ 电离出 H⁺ 显酸，NaHCO₃ 水解显弱碱 | [[1.1 物质的分类及转化]] |
| 显酸性就是酸 | 分类看组成，NaHSO₄ 是盐（酸式盐），因电离出 H⁺ 才显酸 | [[1.1 物质的分类及转化]] |
| 同素异形体 = 同位素 | O₂/O₃ 是单质间转化；¹⁶O/¹⁸O 是核素间，层次不同 | [[1.1 物质的分类及转化]] |
| 明矾是络合物 | 明矾是复盐（无配离子），络合物如 [Cu(NH₃)₄]SO₄ 含稳定配离子 | [[1.1 物质的分类及转化]] |
| 胶体"自行发光"产生丁达尔 | 丁达尔是光散射（Rayleigh），胶体不发光，溶液透明也可能无丁达尔 | [[1.2 分散系与胶体]] |
| 透明液体一定是溶液 | 胶体也可透明，须按粒子直径（1–100 nm）而非外观判断 | [[1.2 分散系与胶体]] |
| 胶体整体带电 | 胶粒带电、胶体整体电中性（反离子在扩散层平衡） | [[1.2 分散系与胶体]] |
| 聚沉能力看盐浓度 | 看与胶粒电荷相反的反离子价数（Al³⁺ > Mg²⁺ > Na⁺，与浓度无关） | [[1.2 分散系与胶体]] |
| 转化无条件就能发生 | 类别反应有溶解度/条件门槛（CuO 不溶于水、SiO₂ 不溶于水） | [[1.1 物质的分类及转化]] |

## 四、主题② 离子反应 / 离子方程式书写与判断

| 错误表述 | 正确结论 | 对应课时/锚点 |
|---|---|---|
| Cu 能导电，故 Cu 是电解质 | Cu 是单质，既非电解质也非非电解质（忘"化合物"前提） | [[1.3 电解质的电离与离子反应]] |
| 食盐水导电，故食盐水是电解质 | 食盐水是混合物（NaCl+水），电解质必须是化合物 | [[1.3 电解质的电离与离子反应]] |
| CO₂ 溶液导电，故 CO₂ 是电解质 | CO₂ 自身不电离，是非电解质；H₂CO₃ 才是弱电解质 | [[1.3 电解质的电离与离子反应]] |
| BaSO₄ 难溶，故是弱电解质 | BaSO₄ 溶解部分全电离，是强电解质（难溶≠弱） | [[1.3 电解质的电离与离子反应]] |
| 浓 H₂SO₄ 是强酸，必导电 | 浓 H₂SO₄ 分子态为主不电离、不导电，稀 H₂SO₄ 才拆 | [[1.3 电解质的电离与离子反应]] |
| BaSO₄ 是强电解质，离子式就拆 | 难溶作沉淀，离子方程式不拆 | [[1.3 电解质的电离与离子反应]] |
| 澄清石灰水 = 石灰乳（拆写相同） | 澄清石灰水拆 Ca²⁺+2OH⁻；石灰乳不拆 Ca(OH)₂(s) | [[1.3 电解质的电离与离子反应]] |
| NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻ | NaHCO₃ = Na⁺ + HCO₃⁻（弱酸根不拆） | [[1.3 电解质的电离与离子反应]] |
| 离子方程式只代表一个反应 | 代表"一类反应"（如 H⁺+OH⁻=H₂O 表所有强酸强碱中和） | [[1.3 电解质的电离与离子反应]] |
| 共存只看沉淀/气体/弱电解质 | 还须排氧化还原、双水解、络合及隐含条件（颜色/酸碱性） | [[1.3 电解质的电离与离子反应]] |
| CO₂ 与 NaOH 不论量都写同式 | 少量→CO₃²⁻，过量→HCO₃⁻（用"不足量定系数 1"法） | [[1.3 电解质的电离与离子反应]] |

## 五、主题③ 氧化还原反应（概念/双线桥/配平/计算）

| 错误表述 | 正确结论 | 对应课时/锚点 |
|---|---|---|
| 有单质参与或生成必为氧化还原 | 错，3O₂ = 2O₃ 同素异形体转化无价变 | [[1.4 氧化还原反应：概念与规律]] |
| 无单质参与就一定不是氧化还原 | 错，2H₂O₂ = 2H₂O + O₂↑、CO+CuO→Cu+CO₂ 均无单质起始 | [[1.4 氧化还原反应：概念与规律]] |
| 含最高价元素氧化性一定最强 | 错，稀 H₂SO₄（S+6）不能氧化 Cu，强弱看浓度介质 | [[1.4 氧化还原反应：概念与规律]] |
| Na₂SO₃ 中 S+4 是强氧化剂 | 错，S+4 是中间价，兼具氧化性和还原性 | [[1.4 氧化还原反应：概念与规律]] |
| 还原剂被还原、氧化剂被氧化 | 错，还原剂被氧化、氧化剂被还原 | [[1.4 氧化还原反应：概念与规律]] |
| 双线桥箭头从还原剂指向氧化剂 | 错，双线桥按同种元素自身升降连，电子流向看单线桥 | [[1.4 氧化还原反应：概念与规律]] |
| 电子数 = 价态变化数 | 错，电子数 = 价态变化数 × 变价原子个数 | [[1.4 氧化还原反应：概念与规律]] |
| 氧化数就是真实电荷 | 错，氧化数是人为规定的形式电荷，可为零/分数 | [[1.4 氧化还原反应：概念与规律]] |
| FeS₂ 中 S 为 −2 价 | 错，过硫根 S₂²⁻ 中 S 为 −1 | [[1.4 氧化还原反应：概念与规律]] |
| Na₂O₂ 中 O 按 −2 价计算 | 错，过氧键 O−O 中 O 为 −1，按 −2 会算出 Na 为 +4 荒谬 | [[1.4 氧化还原反应：概念与规律]] |
| 归中反应任意两价态相遇都可 | 错，须"只靠拢不交叉"，产物价态介于二者之间 | [[1.5 氧化还原反应方程式的配平与计算]] |
| 多步反应必须逐步计算 | 错，抓关键元素守恒写关系式一步到位（如 NH₃~HNO₃） | [[2.10 物质的量在化学计算中的应用]] |
| 电子守恒比例式系数易搞反 | 须用"每 mol 被还原产物对应多少 e⁻"列式，勿颠倒 | [[1.5 氧化还原反应方程式的配平与计算]] |
| "部分被氧化/还原"不必管 | 最易错：电子转移数 ≠ 参加反应的该物质系数，看产物有无原样价态 | [[1.5 氧化还原反应方程式的配平与计算]] |
| NO₂ 歧化反应算归中 | 错，3NO₂+H₂O 中反应物只有 +4 一种价态，属歧化 | [[1.4 氧化还原反应：概念与规律]] |
| 高价=强氧化是绝对真理 | 错，同一高价随浓度/介质表现不同（浓稀 HNO₃ 还原产物不同） | [[1.4 氧化还原反应：概念与规律]] |

## 六、主题④ 金属及其化合物——钠系

| 错误表述 | 正确结论 | 对应课时/锚点 |
|---|---|---|
| 钠密度比水大、会沉底 | ρ=0.97 g/cm³ 比水小，浮于水面（"浮熔游响红"之浮） | [[2.1 钠]] |
| 钠燃烧生成 Na₂O | 常温才得 Na₂O（白），点燃/加热得淡黄 Na₂O₂（条件决定产物） | [[2.1 钠]] |
| 钠能从 CuSO₄ 溶液置换出 Cu | 先与水反应生成 NaOH，再与 Cu²⁺ 复分解得蓝色 Cu(OH)₂ 沉淀 | [[2.1 钠]] |
| 钠着火可用水/CO₂ 灭 | 禁水禁 CO₂，用干燥沙土（4Na+3CO₂=2Na₂CO₃+C 夺氧助燃） | [[2.1 钠]] |
| 钠可存于 CCl₄ | CCl₄ 更重，钠浮面露空；应存煤油/石蜡油 | [[2.1 钠]] |
| 所有碱金属燃烧产物相同 | Li₂O / Na₂O₂ / KO₂ 随金属递变，产物不同 | [[2.1 钠]] |
| Na₂O₂ 是碱性氧化物 | 错，与酸反应额外放 O₂，属过氧化物（O 为 −1） | [[2.2 钠的氧化物]] |
| Na₂O₂ 与水反应是置换反应 | 错，是歧化：O 从 −1 既升到 0（O₂）又降到 −2（NaOH） | [[2.2 钠的氧化物]] |
| Na₂O₂ 只作氧化剂 | 错，同一 O₂²⁻ 中 O 既升又降，兼作两剂 | [[2.2 钠的氧化物]] |
| 供氧剂 1 mol 放 1 mol O₂ | 错，2Na₂O₂ ~ O₂，1 mol Na₂O₂ 只放 0.5 mol O₂ | [[2.2 钠的氧化物]] |
| Na₂CO₃ 与 NaHCO₃ 性质一样可互换 | 热稳定性、与酸速率、碱性、与 CaCl₂ 沉淀均不同 | [[2.3 碳酸钠和碳酸氢钠]] |
| "盐"溶液都中性 | CO₃²⁻/HCO₃⁻ 均水解显碱，同浓度 Na₂CO₃ 碱性更强 | [[2.3 碳酸钠和碳酸氢钠]] |
| Na₂CO₃ 加酸更猛（强=快） | 速率为步数之差：NaHCO₃ 一步、Na₂CO₃ 分步（CO₃²⁻→HCO₃⁻→CO₂） | [[2.3 碳酸钠和碳酸氢钠]] |
| 焰色试验是化学变化 | 错，是电子受热跃迁回落发光，物理变化 | [[2.3 碳酸钠和碳酸氢钠]] |
| 侯氏制碱先通 CO₂ | 错，先通 NH₃（高溶解度促吸收 CO₂） | [[2.3 碳酸钠和碳酸氢钠]] |
| 碳酸氢盐都稳定 | 错，递变 LiHCO₃ < NaHCO₃ < KHCO₃，LiHCO₃ 无固体 | [[2.3 碳酸钠和碳酸氢钠]] |

## 七、主题⑤ 铁系（Fe/Fe²⁺/Fe³⁺/铁三角）与铝系（Al/Al₂O₃/Al(OH)₃/铝三角）

| 错误表述 | 正确结论 | 对应课时/锚点 |
|---|---|---|
| Fe 与 Cl₂ 产物是 FeCl₂ | Cl₂ 强氧化，无论 Fe 是否过量均得 FeCl₃（Fe 到 +3） | [[3.1 铁的单质]] |
| Fe 与稀 HNO₃ 一律写 Fe³⁺ 且放 H₂ | 氧化性酸不放 H₂；产物看用量（少→Fe³⁺、过量→Fe²⁺） | [[3.1 铁的单质]] |
| Fe 冷水就放 H₂ | 常温不与液态水反应；红热才与 H₂O(g) 反应：3Fe+4H₂O(g)→Fe₃O₄+4H₂ | [[3.1 铁的单质]] |
| 钝化 = 不反应 | 反应生成致密氧化膜阻断进一步反应，可储运浓硫酸 | [[3.1 铁的单质]] |
| 高炉里焦炭直接还原铁 | CO 才是主还原剂（Fe₂O₃+3CO→2Fe+3CO₂） | [[3.1 铁的单质]] |
| Fe₃O₄ 是 FeO·Fe₂O₃ 混合物 | 反尖晶石纯净物，Fe²⁺/Fe³⁺ 在晶格中有序排列 | [[3.1 铁的单质]] [[3.2 铁的氧化物与氢氧化物]] |
| Fe(OH)₂ 是稳定白色沉淀 | 极易被 O₂ 氧化：白→灰绿→红褐（4Fe(OH)₂+O₂+2H₂O=4Fe(OH)₃） | [[3.2 铁的氧化物与氢氧化物]] |
| Fe₂O₃ 与酸反应只生成 Fe²⁺ | 铁为 +3，生成 Fe³⁺（KSCN 血红色佐证） | [[3.2 铁的氧化物与氢氧化物]] |
| Fe²⁺ 比 Fe³⁺ 稳定 | Fe²⁺ 还原性为主、易氧化为 Fe³⁺（E°=0.771 V） | [[3.3 铁盐与亚铁盐]] |
| KSCN 可检验 Fe²⁺ | KSCN 只对 Fe³⁺ 显血红色，Fe²⁺ 须先加氯水氧化 | [[3.3 铁盐与亚铁盐]] |
| Fe³⁺ 与 Cu 不反应 | 2Fe³⁺+Cu=2Fe²⁺+Cu²⁺（Fe³⁺ 氧化性氧化 Cu，非金属置换） | [[3.3 铁盐与亚铁盐]] |
| Fe³⁺+SCN⁻ 是氧化还原反应 | 错，是配位显色，无化合价变化 | [[3.3 铁盐与亚铁盐]] |
| 废水除铁直接加碱 | 须先氧化 Fe²⁺→Fe³⁺ 再沉淀 Fe(OH)₃ | [[3.3 铁盐与亚铁盐]] |
| 铝不活泼（铝锅耐用） | Al 很活泼，耐用靠致密 Al₂O₃ 膜保护 | [[3.5 铝单质与氧化铝]] |
| Al 与 NaOH 反应是置换 | 2Al+2NaOH+2H₂O=2NaAlO₂+3H₂↑ 含三种反应物，H₂ 来自 H₂O | [[3.5 铝单质与氧化铝]] |
| 铝热反应只生成 Al₂O₃ | 同时还原出 Fe：2Al+Fe₂O₃→2Fe+Al₂O₃ | [[3.5 铝单质与氧化铝]] |
| 炼铝也可用碳热还原 | Al₂O₃ 太稳定，须 Hall-Héroult 熔盐电解 | [[3.5 铝单质与氧化铝]] |
| Al₂O₃ 只与酸反应 | 两性氧化物，与酸也与碱生成盐和水 | [[3.5 铝单质与氧化铝]] |
| 制 Al(OH)₃ 用 NaOH | 过量 NaOH 溶成 AlO₂⁻，须用弱碱氨水 | [[3.6 氢氧化铝与铝三角]] |
| Al(OH)₃ 很活泼易反应 | 极稳定，仅强酸强碱才溶；弱酸(CO₂)/氨水均不溶 | [[3.6 氢氧化铝与铝三角]] |
| 两性物水溶液必中性 | 两性指反应行为，非 pH 中性（pH 由电离/水解竞争定） | [[3.6 氢氧化铝与铝三角]] |
| Al 与氨水也能溶 | Al 只吃强碱；Zn/Cu 吃氨水靠配合 [Zn(NH₃)₄]²⁺ | [[3.6 氢氧化铝与铝三角]] |

## 十一、使用建议（考前诊断）

1. **按主题筛查**：用上表各主题做 5 分钟快闪默写，错一条即回链对应课时 wikilink 复盘。
2. **Nₐ 陷阱三查**：先查状态（标况是否气态）、再查条件（是否标况）、后查构成（子微粒个数）。
3. **方程式三问**：拆解对象对不对、条件/状态对不对、价态（尤其 −1 价 O、Fe₃O₄、FeS₂）对不对。
4. **化学键与氢键**：凡见"氢键"先定位能量档（化学键≫氢键>范德华力），凡写电子式先查阴离子 [ ] 与电荷。
