# 教案：1.6 离子反应的应用（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.6 离子反应的应用 / 第 6 课时 / 45 min / 新授课（应用提升） / 高一基础班
> 库内锚点：[[物质分类与离子反应]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：离子反应的高阶应用课。前两课时（1.4 电离、1.5 离子反应）建立了"离子从哪来"与"离子怎么反应"，本课时处理三类最难也最高频的题型——**与量有关**（不足量定系数 1）、**滴加顺序影响产物**、**信息型离子方程式书写**，并用随堂检测与易错速记表收口整个离子反应单元。

## 一、课标对应

- **内容要求**：能书写与量有关的离子方程式；能根据实验现象与信息书写陌生的离子方程式；能从宏观与微观相结合的视角分析与解决实际问题。
- **学业质量水平**：必修水平 2~3——能分析反应物用量对产物的影响并正确书写对应的离子方程式；能依据题给信息推断陌生反应的产物并书写离子方程式。
- **核心素养落点**：
  1. **变化观念与平衡思想**（认识"量变引起产物变"，同一组反应物在不同用量下走向不同产物）；
  2. **证据推理与模型认知**（掌握"不足量定系数 1"这一可操作的配平模型，并能迁移到陌生情境）；
  3. **科学探究与创新意识**（面对信息型陌生反应，能先判产物、再拆写，敢于用已有规则处理新情境）。

### 1.6 课标细目与课时落点对照

| 能书写与量有关的离子方程式 | 四组示范：CO₂+NaOH、AlCl₃+NaOH、Na₂CO₃+HCl、Ca(HCO₃)₂+NaOH | "不足量定系数 1"法 |
| 能根据信息书写陌生离子方程式 | 刻蚀电路板 2Fe³⁺+Cu | 先判产物再拆写 |

## 二、学情分析（本课时）

**【课前诊断·3 处典型误解预判】**

- 学生常把"与量有关"当成需要死记的特例清单（CO₂ 少量 / 过量各一式），不掌握"不足量定系数 1"这一通法，遇到新组合就不会。
- 学生常忽略"滴加顺序"对产物的影响，默认"同样两种溶液混合产物必然相同"（实为向 AlCl₃ 滴 NaOH 先沉淀后溶，向 NaOH 滴 AlCl₃ 直接生成 AlO₂⁻）。
- 学生面对信息型陌生反应时不敢下手，常跳过"先判产物"这一步直接套形式。

学生已在 1.5 掌握四步法与拆写边界，但面对"量不同产物不同"时仍倾向于背结论，遇到未见过组合（如 NH₄Al(SO₄)₂ + Ba(OH)₂）就无从下手。本课新难点有三：一是"不足量定系数 1"的操作化（把少量方系数设为 1，按需配平过量方），这是本单元唯一需要"配平策略"而非"套规则"的地方；二是滴加顺序造成的局部过量差异，需要动态想象滴加过程；三是信息型反应中"先判断产物（尤其氧化还原产物）再拆写"的两步走。对策：用四组经典示范把"定系数 1"练成肌肉记忆，用 AlCl₃/NaOH 双向滴加对照暴露顺序效应，用刻蚀电路板与 KI+Cl₂ 两个信息型题训练"先判产物"的思维顺序。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"不足量定系数 1"法书写四组与量有关的离子方程式，培养**变化观念与平衡思想**素养：认识用量是决定产物的重要变量，建立"量变→产物变"的动态观。
- 通过对比 AlCl₃ 滴 NaOH 与 NaOH 滴 AlCl₃ 的现象与产物差异，培养**宏观辨识与微观探析**素养：从滴加过程中的局部浓度差异解释宏观现象的不同。
- 通过书写刻蚀电路板、KI 通氯气等信息型离子方程式，培养**证据推理与模型认知**素养：建立"先判产物（尤其氧化还原产物）→ 再拆写 → 最后查守恒"的三步通法。
- 通过随堂检测与易错速记表收口，培养**科学态度与社会责任**素养：养成"写完必查电荷守恒"的严谨习惯。

### 3.2 学习目标（学生能……，可观测）

- 能**用"不足量定系数 1"法**写出 CO₂+NaOH、AlCl₃+NaOH、Na₂CO₃+HCl、Ca(HCO₃)₂+NaOH 四组的少量 / 过量两式。
- 能**解释**滴加顺序对产物的影响，写出向 AlCl₃ 滴 NaOH 与向 NaOH 滴 AlCl₃ 两种情形的离子方程式与现象差异。
- 能**书写**信息型离子方程式：先判断产物（含氧化还原产物），再按拆写规则书写，最后验算原子与电荷守恒（如 2Fe³⁺+Cu、I⁻ 与过量 Cl₂）。
- 能**完成**随堂检测五题（电解质判定、电离方程式、四步法、离子共存）并自查，正确率 ≥ 80%。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 四、教学重难点

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | "不足量定系数 1"法：把少量方系数设为 1，按需配平过量方 | 学生背特例、无通法，遇新组合不会 | 四组示范统一用同一方法操作，暴露"方法比记忆可靠" | 能用该法写出 NH₄Al(SO₄)₂+Ba(OH)₂ 的少量 / 过量两式 |
| 重点 | 滴加顺序影响产物（AlCl₃ 滴 NaOH vs NaOH 滴 AlCl₃） | 默认"混合产物唯一"，忽略滴加过程中的局部过量 | 双向对照：前者 OH⁻ 不足先沉淀、过量才溶；后者 Al³⁺ 不足直接生成 AlO₂⁻ | 能写出两向的离子方程式并说明现象差异 |
| 难点 | 信息型离子方程式：先判产物再拆写 | 面对陌生反应不敢下手，跳过"判产物"直接套形式 | 两步走训练：刻蚀电路板（判氧化还原产物）→ KI+Cl₂（过量氧化到 IO₃⁻） | 能对给定信息独立写出离子方程式并验算守恒 |
| 难点 | 复杂体系（NH₄Al(SO₄)₂ + Ba(OH)₂）的多离子竞争顺序 | 不知道 OH⁻ 先与谁反应、Ba²⁺ 与 SO₄²⁻ 如何配平 | 明确竞争顺序：Ba²⁺ 与 SO₄²⁻ 成沉淀；OH⁻ 先沉淀 Al³⁺、再与 NH₄⁺ 反应、最后溶 Al(OH)₃ | 能写出少量 / 过量两式并验算电荷守恒 |
| 难点 | 电荷守恒的自觉验算 | 写完不查，尤其复杂式易漏 | 每题强制"查"一步，用总电荷数对账 | 全部作业题电荷守恒无误 |

### 环节六：与量有关、滴加顺序、信息型（核心示范 + 课后延伸）

**【逐字稿】**

**教师**："最难一层：同一组反应物，量不同产物不同。核心方法——'**不足量定系数 1**'：把少量一方系数设为 1，按需配平过量方。四组示范："

**教师**："① CO₂ 通 NaOH：CO₂ 少量→CO₂ + 2OH⁻ = CO₃²⁻ + H₂O；CO₂ 过量→生成的 CO₃²⁻ 被继续转化→CO₂ + OH⁻ = HCO₃⁻。② AlCl₃ 滴加 NaOH：NaOH 少量→Al³⁺ + 3OH⁻ = Al(OH)₃↓；NaOH 过量→Al³⁺ + 4OH⁻ = AlO₂⁻ + 2H₂O（沉淀溶）。③ Na₂CO₃ 加 HCl：HCl 少量→CO₃²⁻ + H⁺ = HCO₃⁻；HCl 过量→CO₃²⁻ + 2H⁺ = H₂O + CO₂↑。④ Ca(HCO₃)₂ 加 NaOH：NaOH 少量（按 1 计）→Ca²⁺ + HCO₃⁻ + OH⁻ = CaCO₃↓ + H₂O；NaOH 过量→Ca²⁺ + 2HCO₃⁻ + 2OH⁻ = CaCO₃↓ + CO₃²⁻ + 2H₂O。"

**教师**："**滴加顺序影响产物**：向 AlCl₃ 滴加 NaOH（OH⁻ 不足先沉淀，过量才溶）vs 向 NaOH 滴加 AlCl₃（Al³⁺ 不足直接生成 AlO₂⁻），现象与最终式都不同。信息型：给陌生反应先判产物再拆——如用 FeCl₃ 溶液刻蚀铜电路板：2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（氧化还原，无沉淀气体仍属离子反应）。"

### 环节七：随堂检测与即时理答（并入末 2 min + 课后即时反馈）

**【逐字稿】**

**教师**："当堂口答三题，检验方法链是否落地。题一：稀硫酸 + Cu 能写 Cu + 2H⁺ = Cu²⁺ + H₂↑ 吗？"

**学生（预期，典型错误）**："活泼金属和酸出氢气，应该可以？"

**教师（追问/理答）**："陷阱。Cu 在金属活动性顺序中位于 H 之后，**稀硫酸与 Cu 不反应**——此式违背事实，判错。只有浓硫酸加热才氧化 Cu，且产物是 SO₂ 而非 H₂，且浓硫酸不拆。题二：MgO + 盐酸，写 MgO + 2H⁺ = Mg²⁺ + H₂O，对吗？"

**学生（预期）**："对，MgO 是氧化物不拆，盐酸强酸拆，生成水弱电解质不拆。"

**教师（追问/理答）**："完全正确，这是规范式。题三：Cu + AgNO₃ 写成 Cu + Ag⁺ = Cu²⁺ + Ag，错在哪？"

**学生（预期，典型错误）**："好像……电荷没守恒？左边 +1，右边 +2。"

**教师（追问/理答）**："正是。电荷不守恒：应为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag。五角度里'电荷守恒'最易漏，写完必查一遍左右总电荷。"

**即时检测题（课后作业前口头过一遍）**

1. 判断正误并说明理由：① 食盐水是电解质；② BaSO₄ 难溶故为弱电解质；③ CO₂ 溶于水导电故 CO₂ 是电解质；④ 浓 H₂SO₄ 是强酸故一定导电；⑤ 离子方程式 H⁺ + OH⁻ = H₂O 只代表 NaOH 与 HCl 一个反应。
2. 写出 NaHCO₃ 溶于水、NaHSO₄ 溶于水、H₂CO₃ 两步电离的方程式。
3. 用四步法写 CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑ 的离子方程式（提示：CaCO₃ 不拆、HCl 拆、CO₂ 气体不拆、H₂O 不拆）。
4. 在"无色碱性"溶液中，Na⁺、K⁺、NH₄⁺、Cl⁻、SO₄²⁻、CO₃²⁻、MnO₄⁻、Cu²⁺ 哪些必不能共存？写出理由。

**解析要点（教师理答，供课后对照）**

- ① 错（混合物，既不是）；② 错（难溶但溶解部分全电离，强电解质）；③ 错（自身不电离，非电解质，H₂CO₃ 才是弱电解质）；④ 错（分子态为主不电离，不导电）；⑤ 错（代表所有强酸强碱中和，表"一类反应"）。
- NaHCO₃ = Na⁺ + HCO₃⁻；NaHSO₄ = Na⁺ + H⁺ + SO₄²⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻，HCO₃⁻ ⇌ H⁺ + CO₃²⁻。
- CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑（左电荷 +2、右 +2，守恒；CaCO₃、CO₂、H₂O 均不拆）。
- 无色⇒排 MnO₄⁻(紫)、Cu²⁺(蓝)；碱性含 OH⁻⇒NH₄⁺ + OH⁻ = NH₃·H₂O 不共存。故必不能共存：MnO₄⁻、Cu²⁺、NH₄⁺；可共存：Na⁺、K⁺、Cl⁻、SO₄²⁻、CO₃²⁻（彼此无六类反应）。---

### 易错点速记对照表（当堂投影，配逐字稿小结）

> 下表汇总离子反应单元的 12 行易错点，前六行来自 1.4 电离、中间三行来自 1.5 拆写、末三行来自本课应用。贴在学案第一页。

| 易错表述 | 正解 | 根源 |
|---|---|---|
| Cu 能导电 → Cu 是电解质 | Cu 是单质，既不是电解质也不是非电解质 | 忘"化合物"前提 |
| 食盐水导电 → 食盐水是电解质 | 食盐水是混合物（NaCl+水），既不是 | 忘"化合物"前提 |
| CO₂ 溶液导电 → CO₂ 是电解质 | CO₂ 自身不电离，是非电解质；H₂CO₃ 才是弱电解质 | 把"溶液导电"等同"该物质电离" |
| BaSO₄ 难溶 → 弱电解质 | BaSO₄ 溶解部分全电离，是强电解质 | 混淆溶解度与电离程度 |
| CH₃COOH 易溶 → 强电解质 | CH₃COOH 部分电离，是弱电解质 | 混淆溶解度与电离程度 |
| 浓 H₂SO₄ 是强酸 → 一定导电 | 浓 H₂SO₄ 分子态为主，不电离，不导电 | 忽略"水才能让它电离" |
| BaSO₄ 是强电解质 → 离子式拆 | BaSO₄ 难溶作沉淀，离子方程式不拆 | 混淆"强电解质"与"拆不拆" |
| 澄清石灰水 = 石灰乳（都拆/都不拆） | 澄清石灰水拆 Ca²⁺+2OH⁻；石灰乳不拆 Ca(OH)₂(s) | 忽略状态差异 |
| NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻ | NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 不拆） | 弱酸酸式根误拆 |
| 共存只看沉淀/气体/弱电解 | 还须排氧化还原、双水解、络合 + 隐含条件 | 漏六类与隐含 |
| 无色酸性溶液忽略颜色/酸碱性 | 先排 Cu²⁺/Fe³⁺/Fe²⁺/MnO₄⁻，再看 H⁺ 相关反应 | 解题顺序混乱 |

**【逐字稿小结】**

**教师**："把这张表贴在学案第一页。前六行是'电离判据'坑，核心一句话——**电解质先问'化合物'，强弱只看'电离程度'不看'溶解度'**。中间三行是'拆写'坑，核心——**强溶才拆**，状态决定拆不拆。最后三行是'离子式与共存'坑，核心——**离子式表一类、共存排六类加隐含**。下节课我们拿这张表做 5 分钟快闪检测。"

## 七、板书设计

```
**Part 1 本课逻辑主线（主板书）**——逻辑：量不同产物不同 → 不足量定系数1 → 滴加顺序 → 信息型。

【D 与量有关】不足量定系数1：CO₂少→CO₃²⁻、过→HCO₃⁻；Al³⁺+少OH⁻→Al(OH)₃↓、+过OH⁻→AlO₂⁻；Na₂CO₃+少H⁺→HCO₃⁻、过→H₂O+CO₂；Ca(HCO₃)₂+少/过NaOH 两式；滴加顺序影响；信息型 2Fe³⁺+Cu=2Fe²⁺+Cu²⁺（刻蚀电路板，既是离子反应又是氧化还原）

**Part 2 体系关联站位图（副板书）**
【体系关联·本章知识系统】  ★=本课焦点
  物质分类(宏观类别视角)  物质转化(类别⇄类别)
         │
  分散系·胶体(粒子尺度视角)
         │
  电离 → 离子反应(离子浓度降低)  ← 轴①：复分解为主·多非氧化还原
  氧化还原反应(电子转移)★        ← 轴②：与价态相关（2Fe³⁺+Cu 既是离子反应又是氧化还原）
  关系：复分解⊂非氧化还原；置换⊂氧化还原；
        离子反应与氧化还原交叉（如 2Fe³⁺+Cu→2Fe²⁺+Cu²⁺ 既是）
  后续：1.7 氧化还原反应正式展开轴②；离子反应→选择性必修1 水溶液离子平衡
```

## 八、作业布置（三层，区分度）

> 分层说明：必做保底全体学生，选做面向中等及以上，挑战面向拔高与有志高考难题者；本课时为应用提升课，作业以"与量有关 + 信息型"为主线。

- **必做**（基础达标，覆盖与量有关四组）：
  ① 写出下列四组"与量有关"离子方程式的少量 / 过量两式（用"不足量定系数 1"法）：CO₂ + NaOH、AlCl₃ + NaOH、Na₂CO₃ + HCl、Ca(HCO₃)₂ + NaOH。
  ② 向 AlCl₃ 溶液中逐滴加入 NaOH 溶液至过量，与向 NaOH 溶液中逐滴加入 AlCl₃ 溶液至过量，两者的现象与最终离子方程式有何不同？分别写出并说明原因。
  ③ 用"不足量定系数 1"法写出：向 NaHCO₃ 溶液中加入少量 Ca(OH)₂ 溶液、加入过量 Ca(OH)₂ 溶液的离子方程式。

- **选做**（能力提升，信息型 + 共存综合）：
  ① 信息型离子方程式两道：(a) 用 FeCl₃ 溶液刻蚀铜电路板；(b) 向 KI 溶液中通入过量氯气（I⁻ 被氧化为 IO₃⁻）。写出离子方程式并验算电荷守恒。
  ② 共存判断（含氧化还原型）：在"无色酸性"溶液中，A. Na⁺、K⁺、SO₄²⁻、Cl⁻，B. Cu²⁺、K⁺、SO₄²⁻、NO₃⁻，C. Na⁺、CO₃²⁻、K⁺、Cl⁻，D. Fe²⁺、K⁺、MnO₄⁻、H⁺——分别判断能否大量共存并说理。
  ③ 双水解判断：Al³⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻ 能否大量共存？写出 Al³⁺ 与 CO₃²⁻ 双水解的离子方程式。

- **挑战**（拔高区分，复杂与量 + 多离子竞争）：
  ① 一道"不足量定系数 1"的复杂与量方程式推导：向 NH₄Al(SO₄)₂ 溶液中逐滴加入 Ba(OH)₂ 溶液，分别写出 Ba(OH)₂ 少量与过量时的离子方程式（少量时 Ba²⁺ 优先与 SO₄²⁻ 成 BaSO₄↓、OH⁻ 先与 Al³⁺ 成 Al(OH)₃↓；过量时 NH₄⁺ 亦被 OH⁻ 反应、Al(OH)₃ 溶于过量 OH⁻ 转 AlO₂⁻），并验算电荷守恒。
  ② 一道含双水解 + 氧化还原的共存综合大题：在"无色、酸性"溶液中混有 Fe³⁺、Al³⁺、S²⁻、CO₃²⁻、NO₃⁻、K⁺、SO₄²⁻，要求逐离子判定哪些必不能大量共存，并写出涉及的双水解 / 氧化还原反应离子方程式。

**作业解析提示（供批改与讲评）**

- 必做①：CO₂ 少→CO₂+2OH⁻=CO₃²⁻+H₂O，过→CO₂+OH⁻=HCO₃⁻；Al³⁺+少OH⁻→Al(OH)₃↓（Al³⁺+3OH⁻），过→Al³⁺+4OH⁻=AlO₂⁻+2H₂O；CO₃²⁻+少H⁺→HCO₃⁻，过→CO₃²⁻+2H⁺=H₂O+CO₂↑；Ca(HCO₃)₂+少NaOH→Ca²⁺+HCO₃⁻+OH⁻=CaCO₃↓+H₂O，过→Ca²⁺+2HCO₃⁻+2OH⁻=CaCO₃↓+CO₃²⁻+2H₂O。
- 必做②：向 AlCl₃ 滴 NaOH（OH⁻ 局部不足）→先 Al³⁺+3OH⁻=Al(OH)₃↓（白色沉淀），继续滴至过量→Al(OH)₃+OH⁻=AlO₂⁻+2H₂O（沉淀溶解），总式 Al³⁺+4OH⁻=AlO₂⁻+2H₂O；向 NaOH 滴 AlCl₃（Al³⁺ 局部不足、OH⁻ 始终过量）→直接 Al³⁺+4OH⁻=AlO₂⁻+2H₂O，开始无沉淀（或局部沉淀立即溶解），AlCl₃ 过量后才出现 Al(OH)₃↓ 并不再溶解。
- 必做③：少量 Ca(OH)₂（定 Ca(OH)₂ 系数为 1，即 Ca²⁺+2OH⁻）→2HCO₃⁻+Ca²⁺+2OH⁻=CaCO₃↓+CO₃²⁻+2H₂O；过量 Ca(OH)₂（定 NaHCO₃ 系数为 1）→HCO₃⁻+Ca²⁺+OH⁻=CaCO₃↓+H₂O。
- 选做①：(a) 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（左 +6、右 +6，守恒）；(b) I⁻ + 3Cl₂ + 3H₂O = IO₃⁻ + 6Cl⁻ + 6H⁺（左 −1、右 −1−6+6=−1，守恒；过量 Cl₂ 下 I₂ 继续氧化至 IO₃⁻）。
- 挑战①：少量 Ba(OH)₂ 时按 Ba(OH)₂ 系数 3 计（对应 2 个 NH₄Al(SO₄)₂）→2Al³⁺+3SO₄²⁻+3Ba²⁺+6OH⁻=3BaSO₄↓+2Al(OH)₃↓；过量时→NH₄⁺+Al³⁺+2SO₄²⁻+2Ba²⁺+5OH⁻=AlO₂⁻+2BaSO₄↓+NH₃·H₂O+2H₂O。
- 挑战②要点：Fe³⁺ 与 S²⁻ 以氧化还原为主（2Fe³⁺+S²⁻=2Fe²⁺+S↓）；Fe³⁺ 与 CO₃²⁻ 双水解（2Fe³⁺+3CO₃²⁻+3H₂O=2Fe(OH)₃↓+3CO₂↑）；Al³⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻ 双水解；酸性下 Fe²⁺ 被 NO₃⁻ 氧化；S²⁻、CO₃²⁻ 在酸性下分别生成 H₂S、CO₂ 亦不存。
