## 一、课标对应

- **内容要求**：认识单质、氧化物、酸、碱、盐之间的转化关系，能用转化关系预测和解释常见物质的制备与变化；能从价态视角认识物质的转化方向。
- **学业质量水平**：必修水平 2——能基于分类模型与价态预测一类物质的通性与转化关系；能根据给定物质设计简单的转化路径。
- **核心素养落点**：
  1. **变化观念与平衡思想**（认识物质不是孤立的，而是在一定条件下相互转化的，建立"转化需要条件、条件决定方向"的动态观）；
  2. **证据推理与模型认知**（建构"八圈"转化模型与"类别×价态"二维图，用模型预测转化可行性）；
  3. **科学探究与创新意识**（在限制条件下设计转化路径，体会"条件可控则路径可行"）。

## 二、学情分析（本课时）

**【课前诊断·3 处典型误解预判】**

- 学生常默认"八圈网络里能转化 = 无条件就转"（实为有溶解度/条件门槛，如 CuO、Fe₂O₃ 不溶于水不能直接得碱，SiO₂ 不溶于水不能直接得硅酸）。
- 学生常孤立记"化合/分解/置换/复分解"，未与分类和氧化还原打通（实为置换必 redox、复分解必非 redox，化合/分解两者皆可能）。
- 学生缺价态视角，设计转化路径时无方向感，不知"同价态横向变类别"与"纵向变价态"是两类不同手段。

学生已在 1.1 建立类别概念，但习惯背转化结论、不会据"类别×价态"设计路径，更不会判断转化的可行性门槛。本课新难点有三：一是"转化需要条件"的动态观，学生易把八圈网络当成"任意两点都能连"；二是"类别×价态"二维图的使用，要同时操作横轴（类别）与纵轴（价态）两个变量；三是 4 种基本反应类型与氧化还原的对应关系，这是后续氧化还原的伏笔。典型误解还包括认为同一金属与不同氧化剂反应产物相同（实为 Fe 与稀硫酸得 Fe²⁺、与 Cl₂ 得 Fe³⁺）。对策：以 CaCO₃ → CaO → Ca(OH)₂ → CaCl₂ 循环为锚标出每步条件，用"限制试剂"制造路径唯一性，用 Fe 的多产物对照说明"氧化剂强弱决定价态方向"。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过建构"单质/氧化物/酸/碱/盐"八圈转化网络并据"类别×价态"设计路径，培养**变化观念与平衡思想**素养：认识物质在条件下相互转化，形成动态、条件化的变化观。
- 通过使用"类别×价态"二维图定位陌生物质并预测其通性，培养**证据推理与模型认知**素养：学会同时操作类别与价态两个坐标。
- 通过辨析"转化门槛"（溶解度、条件）并在限制条件下设计 CaCO₃ 循环与陌生物质转化路径，培养**科学探究与创新意识**素养：体会"条件可控则路径可行"，敢于用模型预测陌生物质。
- 通过打通 4 种基本反应类型与氧化还原的关系，培养**宏观辨识与微观探析**素养：从宏观反应形式辨识微观价态变化。

### 3.2 学习目标（学生能……，可观测）

- 能**画出并应用八圈转化网络**，对给定起点物质写出 2–3 步转化链与条件，并指出每步的溶解度/条件门槛。
- 能**用"类别×价态"二维图**给陌生物质定位，预测其 1–2 条通性与可行转化方向（如由 Mn₂O₇ 的"+7 价 + 酸性氧化物"推出 HMnO₄ 与 NaMnO₄）。
- 能**判断**给定转化属哪类基本反应，并说明该类型与氧化还原的对应关系（置换必 redox、复分解必非 redox）。
- 能**在限制试剂条件下**设计 CaCO₃ 四步闭环，并说明每一步依赖"类别反应"还是"氧化还原"。

## 六、教学过程（含逐字稿）
**探究 4（八圈转化网络 + 4 基本反应类型 + 类别×价态二维图）**

**教师**："分类认识'是什么'，转化认识'能去哪'。先看八圈网络：单质、氧化物、酸、碱、盐四类的两两转化。主链一：金属 + O₂ → 碱性氧化物（如 2Ca + O₂ → 2CaO）；碱性氧化物 + H₂O → 碱（CaO + H₂O → Ca(OH)₂，注意 CuO、Fe₂O₃ 等不溶于水不能直接得碱）；碱 + 酸 → 盐（Ca(OH)₂ + 2HCl → CaCl₂ + 2H₂O）；盐可经复分解制另一种盐。主链二：非金属 + O₂ → 酸性氧化物（C + O₂ → CO₂）；酸性氧化物 + H₂O → 酸（CO₂ + H₂O → H₂CO₃）；酸 + 碱/碱性氧化物 → 盐；盐之间复分解。下面把具体链做实：
铝——4Al + 3O₂ → 2Al₂O₃；Al₂O₃ 与酸得 AlCl₃，与碱得 NaAlO₂（两性体现）；
铁——3Fe + 2O₂ → Fe₃O₄（也可 2Fe + O₂ → 2FeO、4Fe + 3O₂ → 2Fe₂O₃）；
碳——2C + O₂(不足) → 2CO、C + O₂(充足) → CO₂；
硫——S + O₂ → SO₂，SO₂ + H₂O → H₂SO₃，2SO₂ + O₂ → 2SO₃（需催化）；
氮——N₂ + O₂(放电) → 2NO，4NH₃ + 5O₂ → 4NO + 6H₂O。
这些链都印证'类别×价态'。"

**教师**："现在统一工具——'类别×价态'二维图：横轴是类别（单质/氧化物/酸/碱/盐），纵轴是价态。把 Ca（0 价单质）、CaO（+2 氧化物）、Ca(OH)₂（+2 碱）、CaCl₂（+2 盐）落点，发现它们在同一条竖线上——**同价态、横向变类别**，靠'加氧/加水/加酸'实现，属于非 redox；把 Cl₂（0 价单质）、HCl（-1 酸）、HClO（+1 酸）、KClO₃（+5 盐）落点，是**纵向变价态**，靠氧化还原反应实现。用这张图预测：给陌生物质 Mn₂O₇，先判类别——它是酸性氧化物（前面反例），价态 +7，那它该能和水生成对应含氧酸 HMnO₄，也能和碱生成高锰酸盐。这就是'由类别+价态反推通性'。"

**学生（预期）**："那 ZnO 呢？它是金属氧化物，但……"

**教师（追问/理答）**："好问题。ZnO 是两性氧化物（像 Al₂O₃），既能和酸又能和碱反应：ZnO + 2HCl → ZnCl₂ + H₂O，ZnO + 2NaOH → Na₂ZnO₂ + H₂O。所以'金属氧化物'只告诉你元素，不告诉你酸碱性，必须回到反应事实。再看 FeO（+2）与 Fe₂O₃（+3）：同是铁的氧化物，价态不同，Fe₂O₃ 更稳定在碱性环境中，FeO 易被氧化，这正是'价态决定稳定性与转化方向'的例子。"

**教师**："最后把转化和'4 基本反应类型'打通。化合（多变一，如 CaO + H₂O → Ca(OH)₂）、分解（一变多，如 CaCO₃ 高温 → CaO + CO₂）、置换（单质+化合物→新单质+新化合物，必有单质参与，如 Zn + H₂SO₄ → ZnSO₄ + H₂↑）、复分解（两种化合物交换成分，如 Ca(OH)₂ + 2HCl → CaCl₂ + 2H₂O，均生成水/沉淀/气体才发生）。注意：置换反应一定伴随价态变化（氧化还原反应），复分解反应价态不变（非 redox）；化合与分解可能 redox 也可能非 redox。这正好和二维图呼应：横向同价态变类别多是复分解/化合(非 redox)，纵向变价态必是 redox（置换或氧化还原型化合/分解）。"

**转化链条件深究 + 含条件缺失推断（深化探究 4）**

**教师**："八圈网络里'能转化'不等于'无条件就转'。比如碱性氧化物 + H₂O → 碱，CaO 可以，但 CuO、Fe₂O₃ 不行——因为它们不溶于水，必须先和酸反应生成盐，再让盐与碱复分解得碱（如 CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄）。再看酸性氧化物 + H₂O → 酸：CO₂、SO₃ 可以，但 SiO₂ 不行——SiO₂ 不溶于水，要和碱共热得硅酸盐再酸化。这说明'类别反应'也有**溶解度/条件门槛**。下面做一道'条件缺失推断'：已知 A 是白色固体钙盐，受热分解得 B（碱性氧化物）和 CO₂；B 加水得 C（碱）；C 加某酸得 D（可溶钙盐）；D 加可溶性碳酸盐回 A。请填 A/B/C/D 并补每步条件。"

**学生（预期）**："A 是 CaCO₃，B 是 CaO，C 是 Ca(OH)₂，D 是 CaCl₂（若加盐酸）。条件：高温、加水、加盐酸、加 Na₂CO₃。"

**教师（追问/理答）**："完全正确，这就是 CaCO₃ 循环的逆向表述。注意第 1 步必须'高温'（CaCO₃ 常温不分解），第 3 步'加盐酸'只是众多可能之一——加 HNO₃ 也行，D 就变成 Ca(NO₃)₂，循环仍成立。所以推断题给'限制试剂'才会唯一确定 D。再练一条含变价的：Fe 在 O₂ 中燃烧得 Fe₃O₄（混合价态 +2/+3），Fe 在潮湿空气中生锈得 Fe₂O₃·xH₂O，Fe 与稀硫酸得 FeSO₄（Fe²⁺），Fe 在 Cl₂ 中燃烧得 FeCl₃（Fe³⁺）——同一金属 Fe，因**氧化剂强弱/条件**不同，产物价态不同，这又回到'类别×价态'：横向靠类别反应、纵向靠 redox，而纵向的方向由氧化剂决定。"

**信息型氧化物进阶**

**教师**："再升一级：若告诉你'某氧化物溶于水生成 H₂MO₄ 且 M 为 +6 价金属'，你能猜出什么？溶于水得含氧酸 ⇒ 酸性氧化物；M 为金属且 +6 ⇒ 联想到 CrO₃（铬酸酐，溶于水得 H₂CrO₄）或类似。若'某非金属氧化物与碱歧化生成两种盐'，像 Cl₂O₃? 不，典型是 NO₂（已讲）和 Cl₂O₇? Cl₂O₇ 是酸性氧化物（得 HClO₄）不歧化；真正歧化的是 NO₂、Cl₂ 与冷碱等。这类'由性质反推类别/化学式'的题，套路就是：先判'与酸/碱产物'定氧化物类别，再由价态与组成锁化学式。高考与初赛都爱考这种'信息型氧化物'，因为它同时查分类与价态两张网。"

**转化推断压轴 + 信息型氧化物**

**教师**："压轴一：从 CaCO₃ 出发设计 CaCO₃ → CaO → Ca(OH)₂ → CaCl₂ 四步循环，加限制——'回到 CaCO₃ 须用可溶碳酸盐沉淀法而非盐酸'（反应链与条件见前文 CaCO₃ 循环，此处追问本质）。"

**学生（预期）**："CaCO₃ 高温分解；CaO 加水；Ca(OH)₂ 加盐酸得 CaCl₂；CaCl₂ 加 Na₂CO₃ 沉淀回 CaCO₃，不靠盐酸。"

**教师（追问/理答）**："四步都是非 redox，Ca 价态全程 +2——这正是'同价态横向变类别'的典型（第 1 步分解需高温、第 4 步复分解靠沉淀驱动）。压轴二（信息型）：某陌生氧化物 X 溶于水得 HXO₄、中心元素为 +7 价金属，请写 X 化学式、类别、与 NaOH 产物。"

**学生（预期）**："X 是 Mn₂O₇？因为 Mn 是 +7，Mn₂O₇ 溶于水得 HMnO₄，是酸性氧化物，和 NaOH 得 NaMnO₄ 和水：Mn₂O₇ + 2NaOH → 2NaMnO₄ + H₂O。"

**教师（追问/理答）**："完全正确。这就是用'类别×价态'从性质反推物质的完整闭环——先由'溶于水得含氧酸'判为酸性氧化物，再由'+7 价金属'锁定 Mn₂O₇。回去把作业三层做完，挑战题务必指出反直觉点。"

---

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 反例/判据 |
|---|---|---|
| 金属氧化物必碱性 | 不一定，可能酸性/两性/过氧化物/超氧化物 | Mn₂O₇ 酸性、Al₂O₃/ZnO 两性、Na₂O₂ 过氧化物、KO₂ 超氧化物 |
| 非金属氧化物必酸性 | 不一定，可能不成盐 | CO、NO 不成盐；NO₂ 歧化非典型 |
| 盐溶液都中性 | 酸式盐可显酸或显碱 | NaHSO₄ 电离出 H⁺ 显酸；NaHCO₃ 水解显弱碱 |
| 同素异形体=同位素 | 二者层次不同 | O₂/O₃ 是单质间；¹⁶O/¹⁸O 是核素间 |
| 明矾是络合物 | 明矾是复盐（无配离子） | 络合物如 [Cu(NH₃)₄]SO₄ 含稳定配离子 |
| 转化无条件就发生 | 类别反应有溶解度/条件门槛 | CuO 不溶于水→先成盐再复分解得碱；SiO₂ 不溶于水 |
| 显酸性就是酸 | 分类看组成，酸碱性是性质 | NaHSO₄ 是盐（酸式盐），因电离出 H⁺ 显酸 |
| 氧化物看元素金属性判 | 一律看与酸/碱反应产物 | 所有六类均按反应事实判定 |

**核心口诀**：分类选坐标，三性要记牢（层级/完备/互斥）；氧化物六类，看反应不看出身；酸式盐两路，电离或水解；转化靠条件，类别×价态定方向。

二、物质的转化
1. 八圈网络：单质 ⇄ 氧化物 ⇄ 酸/碱 ⇄ 盐
   主链一：金属 → 碱性氧化物 → 碱 → 盐
   主链二：非金属 → 酸性氧化物 → 酸 → 盐
   条件门槛：
     · CuO、Fe₂O₃ 不溶于水 → 先成盐再复分解得碱
     · SiO₂ 不溶于水 → 先成盐再酸化得酸

2. CaCO₃ 循环（Ca 全程 +2，全非 redox）
   CaCO₃(高温分解) → CaO(+H₂O) → Ca(OH)₂(+酸) → CaCl₂(+Na₂CO₃沉淀) → CaCO₃↓

3. 具体转化链（标条件/价态）
   铝：4Al + 3O₂ → 2Al₂O₃；Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O；Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O
   铁：3Fe + 2O₂ → Fe₃O₄；Fe + H₂SO₄ → FeSO₄ + H₂↑（Fe²⁺）；2Fe + 3Cl₂ → 2FeCl₃（Fe³⁺）
   碳：2C + O₂(不足) → 2CO；C + O₂(充足) → CO₂；CO₂ + H₂O → H₂CO₃
   硫：S + O₂ → SO₂；SO₂ + H₂O → H₂SO₃；2SO₂ + O₂ → 2SO₃(催化)
   氮：N₂ + O₂(放电) → 2NO；4NH₃ + 5O₂ → 4NO + 6H₂O

4. 4 基本反应类型与氧化还原关系（先埋伏笔）
   化合（多变一）/ 分解（一变多）/ 置换（单+化→新单+新化，必有单质）/ 复分解（交换成分）
   规律：置换必 redox（有单质参与、价态变）；复分解非 redox（靠水/沉淀/气体驱动）
         化合与分解不一定（可能 redox，也可能非 redox）

5. 类别×价态二维图（横轴类别，纵轴价态）
   同价态横向变类别（非 redox）：如 Ca 系 Ca / CaO / Ca(OH)₂ / CaCl₂ 同 +2
   纵向变价态靠 redox：如 Cl₂(0) / HCl(−1) / HClO(+1) / KClO₃(+5)
   预测：Mn₂O₇(+7, 酸性氧化物) → HMnO₄、NaMnO₄；CrO₃(+6) → H₂CrO₄

## 八、作业布置

- **必做**（基础达标）：[[高中化学必修一-习题精选]] 题1 的转化部分。
  ① 从 Zn、BaCl₂、NaOH、KClO₃、CuCl₂、Na₂SO₄、Na₂O、H₂O、H₂SO₄ 中选物质，分别写出**化合、分解、置换、复分解**四种基本反应类型各一例，并注明每步是否涉及价态变化；
  ② 以 CaCO₃ 为起点，写出 CaCO₃ → CaO → Ca(OH)₂ → CaCl₂ 三步转化，标出每步条件与所属基本反应类型；
  ③ 说明 CuO 能否直接加水得 Cu(OH)₂，若不能请写出正确的绕行路径。

- **选做**（能力提升）：
  ① 转化推断：以 CaCO₃ 为起点，设计 CaCO₃ ⇌ CaO ⇌ Ca(OH)₂ ⇌ CaCl₂ 的 4 步循环，加限制"回到 CaCO₃ 须用可溶碳酸盐沉淀法而非盐酸"，写出每步反应式与条件，并标注各步所属基本反应类型及是否 redox；
  ② 另举 Al、Fe、C、S、N 中任两条转化链并标注价态变化，指出其中哪些步是"纵向变价态"（redox）、哪些是"横向变类别"（非 redox）。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① 转化推断设计题（限制条件）：给定起点物质 CaCO₃ 与可选试剂 H₂O、NaOH 溶液、盐酸、Na₂CO₃ 溶液、O₂、CO₂，请实现 CaCO₃ → CaO → Ca(OH)₂ → CaCl₂ → CaCO₃（闭环），写出每步反应式与条件，并说明哪一步依赖"氧化还原"、哪一步仅依赖"类别反应"（复分解/化合）；再额外设计一条从 Ca(OH)₂ 出发、经与 Cl₂ 或 CO₂ 反应得到新类别物质的支线转化（提示：Ca(OH)₂ + Cl₂ → Ca(ClO)Cl + H₂O 是漂白粉原理，Ca(ClO)Cl 为混盐；Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O），说明支线产物的类别归属。
  ② 信息型氧化物（初赛入门）：某金属 M 的氧化物 X 溶于水生成含氧酸 H₂MO₄ 且 M 为 +6 价，另一非金属 N 的氧化物 Y 与 NaOH 反应发生歧化生成两种盐。请推断 X、Y 可能的化学式与类别，并各写一条判定反应式。

**作业评价要点（教师批阅参考）**

- **必做评分**：① 四类基本反应各一例且物质选自给定清单、方程式配平正确，每例 1 分（共 4 分）；标注价态变化与否 1 分。② CaCO₃ 三步转化反应式 + 条件 + 类型各 1 分（共 3 分）。③ CuO 绕行路径正确 2 分（先成盐再复分解）。
- **选做评分**：① CaCO₃ 循环四步反应式 + 条件各 1 分；基本反应类型与 redox 标注 1 分；限制条件的路径唯一性说明 2 分。② 额外两条转化链各 1 分，价态标注与横纵判断各 1 分。
- **挑战评分**：① 闭环四步每步 2 分、条件与 redox/非 redox 说明 4 分；支线转化 4 分（含混盐类别判定）。② 信息型氧化物推断每物质 3 分（化学式 + 类别 + 反应式）。区分度由"限制条件路径唯一性"与"信息型反推"拉开。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否据给定物质写 2–3 步转化链并标条件，而非仅背八圈网络的结论？"转化需要条件"的动态观是否建立？
- [ ] "类别×价态"二维图是否落地——学生能否用横轴（类别）+ 纵轴（价态）给 Mn₂O₇ 类陌生物质定位，并预测其通性（HMnO₄、NaMnO₄）？
- [ ] 转化的溶解度/条件门槛是否被理解——学生能否说出 CuO→Cu(OH)₂、SiO₂→H₂SiO₃ 的绕行路径，而非认为"氧化物加水必得酸/碱"？
- [ ] 4 种基本反应类型与氧化还原的对应关系是否打通（置换必 redox、复分解必非 redox、化合/分解两者皆可能）？限制条件下的路径唯一性设计是否达成？
