# 第三章 铁 金属材料 · 教材分析（人教版必修第一册 2019）

> 适用：高一必修第一册第三章备课。课标依据为《普通高中化学课程标准（2017 年版 2020 年修订）》"主题 2：常见的无机物及其应用"。条目以概要描述，[建议] 以本校教材与课标原文核对。内容以库内锚点页 [[铁及其化合物]]、[[金属材料]]、[[两性物质]] 为据，竞赛衔接级素材见 [[铁]]、[[铝]]。

## 一、课标定位

- **内容要求（概要）**：结合真实情境中的应用实例或通过实验探究，了解铁、铝、铜等金属及其重要化合物的主要性质、制备方法和用途；了解金属材料在生产和生活中的重要应用，认识金属材料的成分—结构—性能—用途之间的关系；能从物质的类别和元素价态的视角说明铁、铝及其化合物的转化路径，能利用离子反应、氧化还原反应概念对铁系与铝系反应进行分类与解释；体会物质的量 n 在铁、铝定量计算与合金表征中的作用。
- **学业要求（必修水平 1–2）**：能依据类别与价态列举铁、铝的代表物，并用离子反应、氧化还原概念对其常见反应分类；能描述、辨识铁系与铝系物质的重要性质与实验现象，用化学方程式、离子方程式正确表示主要反应；能从"类别 × 价态"预测铁、铝及其化合物的性质、设计实验验证并解释现象；初步建立"宏观—微观—符号"三重表征思维；能运用物质的量进行铁盐/铝盐计量与简单产率计算。

## 二、本章在课程体系中的地位

本章是**元素化合物学习的第二块基石**，也是初中金属通性通向高中"过渡金属 + 主族金属 + 材料"的枢纽，承载三重任务：

1. **传范式**：延续第二章建立的"类别视角 × 价态视角"双轴研究范式与宏—微—符三重表征，把方法迁移到铁（过渡金属、变价）、铝（主族金属、两性）两条新主线上；铁三角 Fe⁰/Fe²⁺/Fe³⁺ 是双轴预测的标杆案例。
2. **建模型**：以铁合金、铝合金、新型合金为载体，建立"成分—结构—性能—用途"的材料认知模型，把"性质决定用途"从单质层面上升到材料层面，回应"化学促进社会发展的 STSE 主线"。
3. **收定量**：用第一章的物质的量 n 作为定量桥梁，对铁盐/铝盐计量、合金含碳量、铝的产氢量做收口计算，呼应第二章 n 枢纽，为后续水溶液平衡与电化学铺垫。

后续（硫、氮、物质结构·元素周期律、电化学腐蚀、选择性必修 水溶液离子平衡）全部建立在本章"铁/铝双轴转化 + 材料模型 + n 定量"之上；铁三角、铝三角、合金微观解释是历年必考点，须从起始年级种下规范与深度的种子。

## 三、内容结构与逻辑主线

两节呈螺旋递进：先以铁系（变价）展开"定性研究范式 + 双轴预测"，再以铝系与合金展开"两性本质 + 材料模型"，最后用新型材料与全章整合收口。

| 节 | 解决的核心问题 | 认识视角跃迁 |
|---|---|---|
| 第一节 铁及其化合物 | 过渡金属代表铁有哪些价态与转化路径 | 铁三角 Fe⁰/Fe²⁺/Fe³⁺，双轴预测 + 宏微符表征 + n 收口 |
| 第二节 金属材料 | 铝为何两性、合金为何硬而熔低、材料如何因用选材 | 铝三角 Al³⁺⇌Al(OH)₃⇌AlO₂⁻；成分—结构—性能—用途模型 |

**全章大概念**：用"类别 × 价态"双轴预测金属及其化合物性质，用实验探究验证，用宏—微—符三重表征刻画转化，用"成分—结构—性能—用途"模型认识材料，用物质的量 n 统摄定量规律。

## 四、各节内容深析（备课抓手）

**第一节 铁及其化合物（过渡金属代表，3.1–3.3）**

### 3.1 铁的单质（铁系 ★：Fe⁰，变价与冶炼）

- 原子结构 [Ar]3d⁶4s²，最外层 2e 但 3d⁶ 参与，常见 +2/+3（过渡金属第一例，呼应第二章碱金属 ns¹ 对比）。
- 物理性质：银白、延展、导电导热、铁磁性，ρ=7.86，熔点 1538 ℃。
- 与非金属：O₂（常温→Fe₂O₃ 疏松锈；点燃→Fe₃O₄，含 +2/+3）；Cl₂→FeCl₃（无论 Fe 是否过量均 +3，**强于 S**）；S→FeS（弱氧化剂只到 +2）。
- 与水：高温 H₂O(g) → Fe₃O₄ + H₂（红热条件）；常温在浓 H₂SO₄/浓 HNO₃ 中**钝化**（致密氧化膜）。
- 与酸：非氧化性酸 → Fe²⁺ + H₂；稀 HNO₃ 看用量（Fe 少→Fe³⁺，Fe 过量→Fe²⁺）；与盐 Fe+Cu²⁺=Fe²⁺+Cu（湿法炼铜/腐蚀本质）。
  - 与非金属：O₂（常温→Fe₂O₃ 疏松锈；点燃→Fe₃O₄，含 +2/+3）；Cl₂→FeCl₃（无论 Fe 是否过量均 +3，**强于 S**）；S→FeS（弱氧化剂只到 +2）。
  - 与水：高温 H₂O(g) → Fe₃O₄ + H₂（红热条件）；常温在浓 H₂SO₄/浓 HNO₃ 中**钝化**（致密氧化膜）。
  - 与酸：非氧化性酸 → Fe²⁺ + H₂；稀 HNO₃ 看用量（Fe 少→Fe³⁺，Fe 过量→Fe²⁺）；与盐 Fe+Cu²⁺=Fe²⁺+Cu（湿法炼铜/腐蚀本质）。
  - 冶炼：高炉炼铁以 CO 为主还原剂（非焦炭直接），造渣 CaCO₃→CaO→CaSiO₃；对比 Ch2 电解熔融 NaCl 制 Na、后文 Hall-Héroult 电解 Al。
  - 深度补点：Fe 是地壳丰度第四（金属中仅次于 Al）；血红蛋白必需元素；Fe₃O₄ 是反尖晶石纯净物（非 FeO·Fe₂O₃ 混合物）；与 Ch2 钠对比（Na 遇水炸、Fe 需高温才与水蒸气反应）。真实情境：缺铁性贫血/补铁剂、钢铁腐蚀。
- **氧化物与氢氧化物（3.2）**：FeO（黑，+2，碱性，易氧化）、Fe₂O₃（红棕，铁红/颜料/故宫红墙）、Fe₃O₄（黑，磁性氧化铁）；Fe(OH)₂ 白→灰绿→红褐（4Fe(OH)₂+O₂+2H₂O=4Fe(OH)₃，极易被空气氧化），制备须**三防氧化**（NaOH 煮沸、滴管伸入液面下、覆苯/植物油）；Fe(OH)₃ 受热分解。易错：Fe₃O₄ 非混合物、Fe(OH)₂ 不稳定。
- **铁盐与亚铁盐（3.3）**：Fe²⁺（浅绿，还原为主）/Fe³⁺（黄/棕黄，氧化为主）对比；检验 Fe³⁺ 用 KSCN（血红色最灵敏）、NaOH（红棕沉淀）；Fe²⁺ 用 KSCN 不变+氯水变红、铁氰化钾 K₃[Fe(CN)₆] 滕氏蓝；铁三角转化 2Fe³⁺+Fe=3Fe²⁺、2Fe³⁺+Cu=2Fe²⁺+Cu²⁺。
  - 深度补点：E°(Fe³⁺/Fe²⁺)=0.771 V；普鲁士蓝=滕氏蓝（同一物质 KFe[Fe(CN)₆]）；硫酸亚铁铵（莫尔盐）稳定亚铁盐；应用如补铁剂维 C 同服、印刷电路腐蚀、K₂FeO₄ 净水消毒。
  - 真实情境：补铁剂说明书、工业废水除 Fe²⁺（氧化→沉淀）、菠菜补铁（多为 Fe³⁺ 需维 C 转化）。

**第二节 金属材料（铝系 + 合金，3.4–3.7）**

### 3.4 合金（合金与材料 ★：硬度↑熔点↓，微观解释）

- 定义：金属+其他金属/非金属熔合，具金属特性；日常大多为合金。
- 性能：硬度↑、熔点↓、耐蚀↑；微观解释（大小不同原子破坏规整层状排列→原子层滑动受阻→硬）。
- 铁合金：生铁（2%~4.3% C，脆，机座/管道）/钢（0.03%~2% C，延展好）；合金钢不锈钢 Cr~18% Ni~8%（医疗/炊具/车体）。
- 常见合金：青铜/黄铜/白铜/焊锡；铝合金（硬铝 Cu/Mg/Mn/Si，飞机飞船）；超级钢（2017 我国）。真实情境："蛟龙号"钛合金球壳、材料发展史（石→铜→铁器）。

### 3.5 铝单质与氧化铝（铝系 ★：活泼性/氧化膜/两性膜/铝热/Hall-Héroult）

- 铝：地壳最高金属（~8.2%）；原子结构 [Ne]3s²3p¹；轻、延展、导电；**活泼但氧化膜显"不活泼"假象**。
- 与 O₂：常温致密 Al₂O₃ 膜（保护）；点燃/高温 → Al₂O₃。与酸：先溶膜后反应放 H₂（打磨 vs 未打磨对比实验）。
- 与强碱：2Al+2NaOH+2H₂O=2NaAlO₂+3H₂↑（**非置换**，三种物质）；钝化：冷浓 H₂SO₄/浓 HNO₃。
- 铝热：2Al+Fe₂O₃→高温 2Fe+Al₂O₃（焊接铁轨/冶炼难熔金属；Ellingham 图 Al 对氧亲和力极强）。
- Al₂O₃ 两性：Al₂O₃+6H⁺=2Al³⁺+3H₂O；Al₂O₃+2OH⁻=2AlO₂⁻+H₂O（本课用 AlO₂⁻ 与教材一致，可注"实际为 [Al(OH)₄]⁻"）；α-Al₂O₃ 刚玉/红蓝宝石，γ-Al₂O₃ 多孔载体。
- 冶炼 Hall-Héroult 法（Al₂O₃ 溶于冰晶石 Na₃AlF₆ ~950 ℃ 熔盐电解，不能热还原，对比炼铁）。深度补点：Be-Al 对角线规则（BeO/BeCl₂ 同两性/共价）；AlCl₃ 共价二聚 Al₂Cl₆（3c-4e 桥）。

### 3.6 氢氧化铝与铝三角（铝系 ★：两性氢氧化物，铝三角，明矾净水）

- 制备：Al³⁺+3NH₃·H₂O=Al(OH)₃↓+3NH₄⁺（**用氨水不用强碱**，过量 NaOH 溶）；偏铝酸盐+CO₂（弱酸沉淀）。
- 两性：Al(OH)₃+3H⁺=Al³⁺+3H₂O；Al(OH)₃+OH⁻=AlO₂⁻+2H₂O（实质酸式电离 H⁺+AlO₂⁻+H₂O⇌Al(OH)₃⇌Al³⁺+3OH⁻ 一对耦合平衡）。
- 铝三角：Al³⁺⇌Al(OH)₃⇌AlO₂⁻（左加碱/右加酸；加过量强碱 Al(OH)₃→AlO₂⁻，通 CO₂ 回沉淀）。
- 两性机理（深度）：离子势 φ=z/r（Al³⁺ φ≈4.8 居中→两性）；两性金属名单"铝锌铅锡铬铍"；pH 窗口（Al³⁺ pH<~3.5 溶、3.5~12 沉淀、>~12 溶 AlO₂⁻）；与配合溶解区分（Al 只吃强碱不吃氨水，Zn/Cu 吃氨水→配合）。
- 应用：明矾 KAl(SO₄)₂·12H₂O 净水（Al³⁺ 水解 Al(OH)₃ 胶体吸附）；胃药 Al(OH)₃ 中和胃酸；"铝的功与过"（少明矾食品）。真实情境：胃药、明矾净水、铝锅熬中药、铝土矿制铝工艺。

### 3.7 新型金属材料与本章整合（三分支同亮）

- 储氢合金：Ti-Fe、La-Ni，吸 H₂ 成金属氢化物，氢能储运。
- 其他新型合金：钛合金（蛟龙号球壳）、耐热合金（喷气发动机叶片 Ni-Co）、形状记忆合金（Ti-Ni，航空航天/生物工程）。
- 稀土金属：17 种（镧系 15+Sc+Y），"冶金维生素"，我国储量/产量/用量/出口均世界第一；永磁/催化/超导。
- 全章整合：铁系转化网络（铁三角）、铝三角、合金性质三条主线；双轴（类别×价态）与第一二章打通；研究方法（预测—实验—结论）闭环；后续接口（元素周期律、电化学腐蚀）。

## 六、重难点与突破整体思路

- **重点**：铁三角（Fe⁰/Fe²⁺/Fe³⁺ 转化）与 Fe²⁺/Fe³⁺ 检验；Fe(OH)₂ 防氧化制备；铝的两性与铝三角；合金性能与微观解释；"成分—结构—性能—用途"模型。
- **难点**：铁与不同氧化剂产物价态判断（弱→Fe²⁺、强→Fe³⁺；稀 HNO₃ 看用量）；Fe(OH)₂ 易氧化操作控制；铝两性本质（Al、Al₂O₃ 均吃酸碱，且与强碱反应非置换）；铝三角数形结合（pH 窗口与沉淀量图像）；合金微观解释。
- **突破策略**："三阶转化"（宏观现象→微观模型→符号表达）；用铁三角/铝三角 ASCII 网络把转化可视化；对比教学（Fe₃O₄ 纯 vs 混、Na₂O/Na₂O₂ 类比 Al₂O₃ 两性、氯水永久漂白）；用真实情境（补铁剂、胃药、蛟龙号、稀土）承载；用反例制造认知冲突后重构（铝"不活泼"假象、合金非化合物）。

- **课时**：建议 7 课时——①3.1 铁的单质（变价/冶炼）②3.2 铁的氧化物与氢氧化物（Fe(OH)₂ 防氧化）③3.3 铁盐与亚铁盐（铁三角闭合）④3.4 合金（微观解释）⑤3.5 铝单质与氧化铝（两性膜/铝热/Hall-Héroult）⑥3.6 氢氧化铝与铝三角（两性机理/数形结合）⑦3.7 新型金属材料与本章整合。每课含"学情分析"小节、以学科核心素养统领、配必做/选做/挑战三层作业；落实库内锚点（03-知识点）与 [[高中化学必修一-习题精选]] 挂接。
