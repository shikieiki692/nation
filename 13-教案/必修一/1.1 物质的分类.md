## 一、课标对应

- **内容要求**：能根据物质的组成和性质对物质进行分类，掌握物质分类的常用方法（树状分类、交叉分类），建立物质分类的认识模型；能从不同视角（组成、性质）认识物质，初步建立"结构决定性质、性质决定类别"的观念。
- **学业质量水平**：必修水平 2——能依据物质的组成与性质对陌生物质进行分类，能举例说明分类标准对认识结果的影响。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从宏观组成出发认识物质类别，关联微观结构差异，如同素异形体的结构—性质差异）；
  2. **证据推理与模型认知**（建立"树状—交叉"双模型，用模型预测物质通性）；
  3. **科学态度与社会责任**（以事实证据纠正直觉偏见，破除"金属氧化物必碱性"的绝对化认知）。

## 二、学情分析（本课时）

**【课前诊断·4 处典型误解预判】**

- 学生常误认为交叉分类是"再分一次"（实为换一个坐标重新定位同类事物）。
- 学生常误认为"金属氧化物必碱性、非金属氧化物必酸性"绝对成立（实为 Mn₂O₇ 呈酸性、Al₂O₃ 与 ZnO 两性、Na₂O₂ 为过氧化物、CO 与 NO 不成盐等诸多反例）。
- 学生常把同素异形体与同位素混淆（同素异形体是同种元素形成的不同单质，如 O₂ 与 O₃；同位素是同种元素的不同核素，如 ¹⁶O 与 ¹⁸O）。
- 学生常误认为酸式盐一律水解显碱性（实为 NaHSO₄ 因电离出 H⁺ 而显酸性）。

学生在初三已建立"混合物/纯净物""单质/化合物""酸/碱/盐/氧化物"的粗浅概念，但多为"名词记忆"，未形成层级化、可操作的分类方法。本课新难点有二：一是把二维交叉分类（换坐标）与树状分类区分开，学生易把交叉分类当成"再分一次"；二是氧化物六类辨析，初中"金属氧化物=碱性、非金属氧化物=酸性"的绝对化经验会被 Mn₂O₇、Al₂O₃、Na₂O₂、CO、NO₂、KO₂ 等反例强烈冲击。典型误解还包括把同素异形体与同位素混淆、把酸式盐一律当成"盐水解显碱"。对策：用反例链制造认知冲突，用维恩图说明"换坐标"本质，用"与酸/碱反应产物"作为氧化物归类的硬标准。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"自选标准—逐级分类—互评标准差异"活动，培养**证据推理与模型认知**素养：体会分类本质是为认识对象选择"坐标"，标准即认识视角；交叉分类是换一个坐标重新定位。
- 通过对比金刚石、石墨、C₆₀ 及同位素、同素异形体概念，培养**宏观辨识与微观探析**素养：建立"微观结构差异 → 宏观性质差异 → 类别归属"的认知链。
- 通过辨析氧化物反例、用"与酸/碱反应产物"给陌生氧化物归类，培养**科学探究与创新意识**素养：学会用反应事实而非元素出身判定类别。
- 通过破除"金属氧化物必碱性"等直觉偏见，培养**科学态度与社会责任**素养：形成以事实证据纠正直觉的严谨态度。

### 3.2 学习目标（学生能……，可观测）

- 能**独立建构**树状分类树（物质→混合物/纯净物→单质/化合物→酸/碱/盐/氧化物到三级），并说明每一级分类所依据的标准，自检"层级/完备/互斥"三性。
- 能**用交叉分类法**对 Na₂CO₃、KAl(SO₄)₂·12H₂O、NaHSO₄ 给出至少两个维度的归类，并解释"同一物质为何占多个分类节点"。
- 能**辨析酸性/碱性/两性/不成盐/过氧化物/超氧化物**六类氧化物，对 Mn₂O₇、Al₂O₃、Na₂O₂、CO、NO₂、KO₂ 等"反常"氧化物正确归类与写判定反应式。
- 能**区分同素异形体与同位素**，并举例用结构差异解释性质差异；能初步区分复盐与络合物概念（明矾 vs [Cu(NH₃)₄]SO₄）。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 六、教学过程（含逐字稿）
**导入**

**教师**："同学们，先看一段 30 秒的视频——这是快递自动化分拣中心。如果所有包裹不按地址、不按大小堆在一个仓库，我要找一个寄给你的耳机，大概要翻多久？"

**学生（预期）**："可能几天都找不到！""分类之后扫个码几秒钟就出来了。"

**教师（追问/理答）**："对，人类已发现并人工合成的物质超过 1 亿种。化学不分类，就等于把 1 亿个包裹扔在一个仓库。但图书馆可以按'学科'分，也可以按'语种'分——分类结果会变吗？这就引出一个关键思想：**分类标准，就是你看世界的视角**。再看第二个问题：CaCO₃（石灰石）能变成 CaO（生石灰）、再变成 Ca(OH)₂（熟石灰）、再变成 CaCl₂，它们不是孤立的，而是'能互相变'。今天我们用'分类'认识物质是什么，用'转化'认识它能去哪。"

**探究 1（树状分类）**

**教师**："我们先画'树'。树状分类的特点是一分为二、逐级细分，上一级是下一级的'母类'。请从'物质'开始，一直分到第三级。第一级先分什么？"

**学生（预期）**："先分纯净物和混合物！"（典型错误：有学生把'水'直接画在'混合物'下，理由是'自来水不纯'）

**教师（追问/理答）**："很好。但刚才有同学把'水'放进混合物，注意——分类要看**研究对象本身的组成**，不是看'你手边的样品'。纯 H₂O 是纯净物；'自来水'是混合物，是因为溶了别的物质，那已不是 H₂O 本身。**纯净物有固定组成和化学式**。继续，纯净物往下分？"

**学生（预期）**："单质和化合物！"

**教师**："对。单质再分金属、非金属；化合物是重点——既可按'含不含碳'分有机/无机，也可按组成分为氧化物、酸、碱、盐、氢化物。注意：CO、CO₂、碳酸盐含碳但**属无机物**，这是规定也符合'性质更像无机物'的事实。现在看挑战：金刚石、石墨、C₆₀ 都是碳的单质，为什么性质差那么多？"

**学生（预期）**："它们都是碳，应该一样啊？"

**教师（追问/理答）**："这就是'同素异形体'的核心——**同种元素形成的不同单质，因微观原子排列不同，性质不同**。金刚石空间网状共价结构，硬；石墨层状，软、能导电；C₆₀ 足球状分子。所以'结构决定性质'。进阶一点：同素异形体的差异在'分子或晶体结构'层面——O₂ 是双原子分子、O₃ 是三原子分子，二者互为同素异形体，但 O₂ 与 O₃ 的化学活泼性差别很大。而同位素差异在'原子核内中子数'：¹⁶O 与 ¹⁸O 质子数同（都是 8）、中子数异（8 与 10），它们属于同种元素的不同核素，化学性质几乎相同。一句话记忆：**同素异形体管'单质之间'，同位素管'原子之间'**，层次根本不同，别混。"

**教师**："把化合物细分说全。酸按四个坐标分：① 含不含氧——含氧酸（H₂SO₄、HNO₃、H₂CO₃）与无氧酸（HCl、H₂S）；② 能电离出几个 H⁺——一元（HCl、HNO₃）、二元（H₂SO₄、H₂CO₃）、三元（H₃PO₄）；③ 是否完全电离——强酸（HCl、HNO₃、H₂SO₄）与弱酸（H₂CO₃、CH₃COOH）；④ 是否易挥发——挥发性酸（HNO₃、HCl）与不挥发性酸（H₂SO₄、H₃PO₄）。碱分强碱（NaOH、KOH、Ba(OH)₂、Ca(OH)₂）与弱碱（NH₃·H₂O、Cu(OH)₂、Fe(OH)₃）。盐分：正盐（NaCl、K₂SO₄）、酸式盐（NaHCO₃、NaHSO₄、NaH₂PO₄）、碱式盐（Cu₂(OH)₂CO₃、Mg(OH)Cl）、复盐（KAl(SO₄)₂·12H₂O）、络合物初探（[Cu(NH₃)₄]SO₄）。注意酸式盐性质不单一，这点后面专门讲。"

**探究 2（交叉分类 + 酸式盐/复盐/络合物）**

**教师**："树状是一棵'树'。但 Na₂CO₃ 既可以是'钠盐'也可以是'碳酸盐'——怎么放进一棵树？说明要'换一个坐标'。按阳离子分它是钠盐，按阴离子分它是碳酸盐，这就是**交叉分类**：不是再分一次，而是从新维度定位。请对 KAl(SO₄)₂·12H₂O（明矾）做交叉分类。"

**学生（预期）**："按阳离子有 K⁺ 和 Al³⁺，是钾盐和铝盐；按阴离子是硫酸盐；它还是复盐！"

**教师（追问/理答）**："漂亮。明矾是**复盐**——由两种或多种简单盐组成的晶体，溶于水完全电离出 K⁺、Al³⁺、SO₄²⁻，没有稳定配离子。注意和**络合物**区分：络合物 [Cu(NH₃)₄]SO₄ 含有稳定配离子 [Cu(NH₃)₄]²⁺，电离时配离子作为一个整体不易拆开，溶液中 Cu²⁺ 浓度很低、加碱才慢慢放出 Cu(OH)₂。复盐与络合物的关键区别就在'是否含稳定配离子'，概念先点到为止，高二配位化学再深挖。下面看酸式盐的多重性质——这是最容易翻车的地方。"

**教师**："NaHCO₃ 与 NaHSO₄ 都叫'酸式盐'，水溶液酸碱性一样吗？写电离：NaHCO₃ → Na⁺ + HCO₃⁻，HCO₃⁻ 既能微弱电离出 H⁺ 也能水解，但以水解为主，溶液**显弱碱性**；NaHSO₄ → Na⁺ + H⁺ + SO₄²⁻（在水溶液完全电离出 H⁺），溶液**显酸性**。所以**不能因为叫'盐'就认为盐溶液都中性**，酸式盐要看它'电离出 H⁺'还是'水解产生 OH⁻'。NaHSO₄ 甚至能和活泼金属 Zn 反应放出 H₂：Zn + 2NaHSO₄ → ZnSO₄ + Na₂SO₄ + H₂↑，表现出酸的通性。"

**学生（预期，典型错误）**："NaHSO₄ 是酸吧？因为它显酸性。"

**教师（追问/理答）**："这是典型误区。显酸性 ≠ 是酸。分类看'组成'：NaHSO₄ 由金属阳离子 Na⁺ 和酸根 SO₄²⁻ 构成，属于**盐（酸式盐）**；它显酸性是因为在水里电离出了 H⁺。判断物质类别靠组成与结构，酸碱性是性质，二者不能反过来推。记住一句话：**酸式盐是盐，不是酸；但它可能显酸性**。"

**化合物细分坐标对照表（随探究 2 投影，供学生填表）**

```
酸的四坐标细分示例：
  物质      含氧/无氧   元数   强弱      挥发
  HCl       无氧       一元   强酸      挥发
  HNO₃      含氧       一元   强酸      挥发
  H₂SO₄     含氧       二元   强酸      不挥
  H₂CO₃     含氧       二元   弱酸      不挥(易分解)
  H₃PO₄     含氧       三元   中强(弱)  不挥
  CH₃COOH   含氧       一元   弱酸      不挥

盐的组成细分示例：
  物质              类型        关键特征
  NaCl             正盐        仅金属阳离子+酸根
  NaHCO₃           酸式盐     含可电离H⁺(HCO₃⁻)，水解显弱碱
  NaHSO₄           酸式盐     电离出H⁺，显酸性
  Cu₂(OH)₂CO₃     碱式盐      含OH⁻与酸根
  KAl(SO₄)₂·12H₂O 复盐        电离出K⁺、Al³⁺、SO₄²⁻(无配离子)
  [Cu(NH₃)₄]SO₄   络合物      含稳定配离子[Cu(NH₃)₄]²⁺
```

**探究 3（氧化物五类辨析）**

**教师**："大家初中记过'非金属氧化物是酸性、金属氧化物是碱性'，这句话……"

**学生（预期）**："应该对吧？"

**教师（追问/理答）**："错，而且危险。氧化物至少分六类，判定硬标准是'它和酸/碱反应生不生成盐和水'，不看元素是金属还是非金属。看反例链：
① Mn₂O₇，锰是 +7 价金属，溶于水生成 HMnO₄，是**酸性氧化物**——'金属氧化物=碱性'被打破；
② Al₂O₃、ZnO 既能和酸又能和碱生成盐和水，是**两性氧化物**；
③ Na₂O₂ 和酸反应除盐和水还放 O₂，属**过氧化物**；
④ KO₂ 是**超氧化物**，与水/酸反应更剧烈放出 O₂；
⑤ CO、NO 既不与酸也不与碱生成盐和水，是**不成盐氧化物**；
⑥ NO₂ 和 NaOH 反应生成 NaNO₂ 和 NaNO₃——这是**歧化**，NO₂ 因发生歧化不能归为酸性氧化物，也非不成盐氧化物。
判定反应式示例：
Mn₂O₇ + H₂O → 2HMnO₄（酸性氧化物）；
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O，Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O（两性）；
ZnO + 2HCl → ZnCl₂ + H₂O，ZnO + 2NaOH → Na₂ZnO₂ + H₂O（两性）；
2Na₂O₂ + 4HCl → 4NaCl + 2H₂O + O₂↑（过氧化物）；
4KO₂ + 2H₂O → 4KOH + 3O₂↑（超氧化物，放 O₂，K 仍为 +1）；
CO、NO 常温不与酸碱成盐（不成盐）。"

**学生（预期，典型错误）**："Na₂O₂ 是碱性氧化物，因为有 Na，是金属氧化物。"

**教师（追问/理答）**："这是最常见坑。碱性氧化物硬标准：和酸反应**只**生成盐和水。Na₂O₂ 反应多出氧气，所以是过氧化物，性质反常。**归类看反应事实，不看元素种类**。同理 ZnO 虽是金属氧化物却是两性，KO₂ 是超氧化物——'金属氧化物'只告诉你元素，不告诉你酸碱性。"

**氧化物挑战卡逐张诊疗（深化探究 3）**

**教师**："投影五张挑战卡：Mn₂O₇、Al₂O₃、Na₂O₂、CO、NO₂。请逐张说类别和理由，并尽量写判定反应式。"

**学生（预期，典型错误）**："CO₂ 之外的非金属氧化物都是酸性，所以 NO₂ 也是酸性氧化物。"

**教师（追问/理答）**："NO₂ 这里最刁。它和碱反应：2NO₂ + 2NaOH → NaNO₂ + NaNO₃ + H₂O，同一物质中 N 从 +4 既升到 +5 又降到 +3，这是**歧化**。它不符合'只生成一种盐和水'的酸性氧化物定义（酸性氧化物与碱反应 N 价态不变，如 CO₂ + 2NaOH → Na₂CO₃ + H₂O），所以 NO₂ 不能简单归为酸性氧化物，是'非典型'特殊情况，单独记。再看 Mn₂O₇：它溶于水得 HMnO₄（高锰酸），是典型酸性氧化物，尽管中心 Mn 是金属——再次证明**看反应事实，不看元素金属性**。Al₂O₃ 两性已讲。Na₂O₂ 过氧化物（放 O₂）。CO 不成盐（常温不与酸碱成盐）。"

**学生（预期）**："那超氧化物 KO₂ 怎么判定？它也是放 O₂ 的。"

**教师（追问/理答）**："KO₂ 是超氧化物，与水的反应更剧烈：4KO₂ + 2H₂O → 4KOH + 3O₂↑（重点是产物有 O₂ 且 K 为 +1）。它和过氧化物 Na₂O₂ 一样不属于碱性氧化物，但'过氧'与'超氧'阴离子不同（O₂²⁻ vs O₂⁻），分类上各立一类。记住六类清单：酸性、碱性、两性、不成盐、过氧化物、超氧化物——不带'金属/非金属'前缀去猜，一律回到'与酸/碱反应产物'判定。"

**同素异形体结构进阶（穿插探究 1 后）**

**教师**："回到金刚石/石墨/C₆₀。它们的化学式都可写 C，但性质天差地别：金刚石熔点 >3550 ℃、硬度 10、不导电；石墨质软、有滑腻感、能导电；C₆₀ 是分子晶体、易升华。根源是**微观结构**：金刚石中每个 C 以 sp³ 杂化连成三维网状共价骨架；石墨中 C 以 sp² 层状排列、层间靠范德华力、有离域电子故导电；C₆₀ 是 60 个 C 组成的足球状封闭笼分子。可见'同种元素 + 不同结构 = 不同单质 = 不同性质'，这正是宏观辨识要追到微观结构的根本原因。对比同位素：¹²C、¹³C、¹⁴C 质子数都是 6，中子数 6/7/8，它们是碳的三种核素，化学性质几乎相同（因核外电子排布一致），物理上 ¹⁴C 有放射性用于年代测定。一句话：**同素异形体动'结构'，同位素动'原子核'，层次不同**。"

   Na₂CO₃ = 钠盐 ∩ 碳酸盐
   NaHSO₄ = 钠盐 ∩ 硫酸盐 ∩ 酸式盐（电离出 H⁺ 显酸）

3. 同素异形体 ≠ 同位素
   同素异形体：同种元素形成的不同单质，差在结构（微观原子/晶体排列不同）
     O₂（双原子分子）/ O₃（三原子分子）
     金刚石 / 石墨 / C₆₀（碳骨架结构不同，故性质不同）
   同位素：同种元素的不同核素，差在中子数（原子核内）
     ¹⁶O（中子 8）/ ¹⁸O（中子 10）：质子数同（均 8），化学性质几乎相同
   口诀：同素异形体动"结构"，同位素动"原子核"

4. 氧化物六类判定硬标准：与酸/碱反应是否只生成盐和水（不看元素金属性）
   酸性氧化物：与碱反应只生成盐和水，如 CO₂、SO₃、Mn₂O₇
     · Mn₂O₇ 是高锰酸 HMnO₄ 的酸酐（溶于水得 HMnO₄，Mn 为金属），故仍属酸性氧化物
   碱性氧化物：与酸反应只生成盐和水，如 CaO、Fe₂O₃
   两性氧化物：既与酸也与碱反应生成盐和水，如 Al₂O₃、ZnO
   不成盐氧化物：不与酸或碱生成盐和水，如 CO、NO
   过氧化物：含 O₂²⁻ 过氧键，与酸反应生成 H₂O₂ 和盐（并非碱性氧化物），如 Na₂O₂
   超氧化物：如 KO₂（含 O₂⁻），4KO₂ + 2H₂O → 4KOH + 3O₂↑
   特例澄清：
     · SiO₂ 不溶于水不能直得硅酸，但与碱反应生成盐和水，仍是酸性氧化物
     · NO₂ 与碱歧化（2NO₂ + 2NaOH → NaNO₃ + NaNO₂ + H₂O，N 价态 +4→+5/+3，属氧化还原），故不是酸性氧化物

5. 酸式盐酸碱性差异根源（电离 vs 水解）
   NaHSO₄ → Na⁺ + H⁺ + SO₄²⁻（水溶液完全电离出 H⁺）→ 显酸性
   NaHCO₃ → Na⁺ + HCO₃⁻；HCO₃⁻ 为弱酸根不拆，且水解程度 > 电离 → 显弱碱性
