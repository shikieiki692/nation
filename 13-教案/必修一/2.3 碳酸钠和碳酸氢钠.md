# 教案：2.3 碳酸钠和碳酸氢钠（必修第一册 第二章 海水中的重要元素——钠和氯）

> **课时元信息**：第 2 章 / 2.3 碳酸钠和碳酸氢钠 / 第 3 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[钠及其化合物]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：钠系元素化合物的"性质对比 + 工业应用"课。以 Na₂CO₃ 与 NaHCO₃ 的**物理性质、热稳定性、与酸/碱/CaCl₂ 反应、碱性、相互转化、鉴别、用途**为主线，穿插**侯氏制碱法**与**焰色试验**两个高价值模块，落实"类别×价态"双轴认识方法，并为 2.4/2.5 氯章节的"84 消毒液 + 洁厕灵"埋下伏笔。

## 一、课标对应

- **内容要求**：能依据含钠元素的物质类别和元素化合价列举典型代表物（Na₂CO₃、NaHCO₃）；能用离子反应、氧化还原反应对碳酸盐/碳酸氢盐的常见反应进行分类；能从物质类别、元素价态角度预测 Na₂CO₃ 与 NaHCO₃ 的化学性质与转化，设计实验初步验证（加热分解、与酸速率、加 CaCl₂ 沉淀、焰色试验）；能利用二者性质设计方案完成检验、鉴别与简单制备（侯氏制碱）。
- **学业质量水平**：必修水平 2——能基于"盐的类别（正盐/酸式盐）× C 价态（+4 最高价只氧化）"预测二者通性与差异；能正确书写相关化学方程式、离子方程式；能解释热稳定性差异的微观根源，并进行鉴别与定量推断。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从宏观溶解性/热稳定性/与酸速率差异，追到 CO₃²⁻ 与 HCO₃⁻ 结构、水解程度、分步电离的微观根源）；
  2. **变化观念与平衡思想**（认识 Na₂CO₃ ⇌ NaHCO₃ 可双向转化、转化依赖条件，建立动态转化观）；
  3. **证据推理与模型认知**（用"类别×价态"模型统一解释二者性质差异；用离子反应模型解释沉淀/气体/水解驱动）；
  4. **科学探究与创新意识**（设计加热、加酸、加 CaCl₂ 三种鉴别方案，体会"现象—证据—结论"的推断逻辑）；
  5. **科学态度与社会责任**（通过侯氏制碱法体会中国化学家的家国情怀与绿色化工思想，落实"科学态度与社会责任"）。

### 1.1 课标细目与课时落点对照

| 课标表述 | 本课对应落点 | 达成方式 |
|---|---|---|
| 依类别与价态列举代表物 | Na₂CO₃（正盐）、NaHCO₃（酸式盐），C 均为 +4 | 对比表落点"类别×价态"二维图 |
| 用离子/氧化还原分类反应 | 与酸（分步/一步）、与碱、与 CaCl₂（复分解）、加热分解 | 逐反应标离子式与 redox 与否 |

**本课在单元中的地位**：2.1/2.2 已完成 Na 单质、Na₂O/Na₂O₂、NaOH 的性质建构，本课进入"钠盐"层级——Na₂CO₃ 与 NaHCO₃ 是碱金属碳酸盐/碳酸氢盐的代表，既是"类别×价态"方法在盐类上的直接应用，又是后续侯氏制碱（工业转化）与焰色试验（物理性质鉴别）的载体。本课与 2.4/2.5 氯章节通过"CO₃²⁻/HCO₃⁻ 遇酸放 CO₂"和"84 消毒液 + 洁厕灵生成 Cl₂"形成"离子反应 + 氧化还原"双线呼应，是全章承上启下的枢纽课。

## 二、学情分析（本课时）

学生在初三已接触"纯碱（Na₂CO₃）/小苏打（NaHCO₃）"的生活名称，知道二者都用于发酵/洗涤，但仅有名词记忆，未建立性质对比框架。本课新难点有四：一是**混用二者性质**——把 NaHCO₃ 受热分解记成 Na₂CO₃，或把"小苏打去污"等同于 Na₂CO₃；二是**默认二者溶液都中性**——由"盐"字直接推出中性，忽略 CO₃²⁻、HCO₃⁻ 水解显碱且 Na₂CO₃ 碱性更强；三是**不会鉴别**——说不清加热法、加酸速率法、加 CaCl₂ 沉淀法的原理与证据；四是**不知热稳定性差异的根源**——只背"NaHCO₃ 受热分解"，不懂 HCO₃⁻ 中 H 受极化"易脱"、阳离子半径越小极化越强（LiHCO₃ 甚至无固体）的微观逻辑。典型误解还把"焰色试验"当作化学变化。对策：用对比表制造认知冲突，用"多步 vs 一步"解释加酸速率差，用阳离子极化能力解释热稳定性递变，用"电子跃迁"点明焰色是物理变化。

**【课前诊断·4 处典型误解预判】**

为落实框架"误区/易错前置"要求，先列出本课四类典型误解及其对策，作为导入与探究的靶向：

| 典型误解 | 正确认识 | 突破策略 |
|---|---|---|
| 二者性质一样、厨房可互换 | 热稳定性、与酸速率、碱性、与 CaCl₂ 沉淀均不同 | 对比表 + 实验活动 3 现场验证 |
| "盐"溶液都中性 | CO₃²⁻/HCO₃⁻ 均因水解显碱，同浓度 Na₂CO₃ 碱性更强 | pH 试纸/酚酞同浓度溶液对比 |
| Na₂CO₃ 加酸更猛（"强=快"） | 速率比的是反应步数：NaHCO₃ 一步、Na₂CO₃ 分步多步 | 写离子分步历程 CO₃²⁻→HCO₃⁻→CO₂ |
| 焰色试验是化学变化 | 物理变化——电子受热跃迁回落发光，无新物质 | 强调无化学键断裂/形成 |

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过对比 Na₂CO₃ 与 NaHCO₃ 的溶解性、热稳定性、与酸/碱/CaCl₂ 反应、碱性强弱，培养**宏观辨识与微观探析**素养：建立"宏观差异 → CO₃²⁻/HCO₃⁻ 结构与水解决定性质 → 符号表达"的表征链。
- 通过建构 Na₂CO₃ ⇌ NaHCO₃ 双向转化网络并分析转化条件（CO₂+H₂O 沉淀驱动、NaOH 中和、加热分解），培养**变化观念与平衡思想**素养：认识盐的类别转化依赖条件，形成动态转化观。
- 通过"类别×价态"模型（正盐/酸式盐 × C +4 最高价）统一解释二者性质差异，并用离子方程式解释沉淀/气体/水解，培养**证据推理与模型认知**素养。
- 通过设计加热、加酸、加 CaCl₂ 三套鉴别方案与侯氏制碱流程分析，培养**科学探究与创新意识**素养：体会"现象—证据—结论"与"工艺条件决定产物"的工程思维。
- 通过侯氏制碱法（侯德榜、NaCl 利用率 96%、副产 NH₄Cl  fertilizer、无 CaCl₂ 废渣）与焰色试验在烟花中的应用，培养**科学态度与社会责任**素养：体会中国化学家的家国情怀与化学的实用价值。

### 3.2 学习目标（学生能……，可观测）

- 能**独立填写** Na₂CO₃ 与 NaHCO₃ 的对比表（俗名、溶解性、热稳定性、与酸/碱/CaCl₂、碱性、用途），并指出每一差异的微观/离子根源。
- 能**正确书写并标注**本课全部核心方程式：2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑、Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑（分步）、NaHCO₃ + HCl → NaCl + H₂O + CO₂↑、NaHCO₃ + NaOH → Na₂CO₃ + H₂O、Na₂CO₃ + CaCl₂ → CaCO₃↓ + 2NaCl、Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃。
- 能**用离子反应与分步机理**解释"为何 NaHCO₃ 与酸更快更剧烈"（一步 vs 多步），并能用碱性（水解）原理解释同浓度 Na₂CO₃ 碱性 > NaHCO₃。
- 能**设计并说明**三种鉴别方案（加热放 CO₂ 使石灰水浑浊 / 加酸速率 / 加 CaCl₂ 沉淀），并写出侯氏制碱两步核心方程式与"先通 NH₃ 后通 CO₂"的理由。
- 能**正确陈述**焰色试验是物理变化（电子跃迁非化学键变化），列举 Na 黄、K 紫（透蓝钴玻璃）、Ca 砖红、Cu 绿、Ba 黄绿，并说明操作为"铂丝/铁丝蘸盐酸洗后灼烧"。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 四、教学重难点

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | Na₂CO₃ 与 NaHCO₃ 物理性质、热稳定性、与酸/碱/CaCl₂ 反应、碱性的系统对比 | 初三只有生活名词，未建性质框架，易混用 | 填对比表 + 逐项宏—微—符三栏；实验活动 3 现场演示 | 能独立完整填出对比表并说差异根源 |
| 重点 | 相互转化 Na₂CO₃ ⇌ NaHCO₃ 及条件（CO₂+H₂O 通饱和液析沉淀、NaOH 中和、加热分解） | 误以为单向、不标注条件 | 画转化网络，标"向饱和 Na₂CO₃ 通 CO₂ 因 NaHCO₃ 溶解度小析出" | 能写出双向转化且各步条件完整 |
| 重点 | 三种鉴别方案（加热/加酸/CaCl₂）原理与证据 | 只会背"加热"一种，不懂另外两种证据 | 三方案并列，逐一写现象+离子式+推论 | 能口头说明三方案各自的判别证据 |
| 难点 | 与酸速率差异根源（NaHCO₃ 一步、Na₂CO₃ 分步多步） | 直觉"弱酸盐慢"，与事实冲突 | 逐离子式拆解：CO₃²⁻+H⁺=HCO₃⁻ 再 HCO₃⁻+H⁺=CO₂↑+H₂O | 能写出分步历程并解释"多步更慢" |
| 难点 | 热稳定性序列 H₂CO₃ < NaHCO₃ < Na₂CO₃ 及碳酸氢盐递变（LiHCO₃ 无固体） | 只背结论，不知极化根源 | 用阳离子半径→极化能力→O–H 键被极化→易脱 H 解释 | 能说出 LiHCO₃ 不存在固体的微观理由 |
| 难点 | 侯氏制碱"先通 NH₃ 后通 CO₂"与 NaCl 利用率 96% | 不懂气体溶解度与吸收驱动 | 对比：NH₃ 极易溶使溶液呈碱性，促 CO₂ 吸收析出 NaHCO₃ | 能写出两步方程式并说明顺序原因 |
| 难点 | 焰色试验是物理变化（电子跃迁非化学键变化） | 常误当化学变化 | 强调"无新物质、仅是电子激发—回落发光" | 能区分物理/化学变化并说 K 透蓝钴玻璃 |

- 库内关联图：钠系转化链、焰色颜色表（见 [[钠及其化合物]] 内嵌内容，正文仅文字引用）。

## 六、教学过程（含逐字稿）

| 约 7 分钟 | 应用衔接（84+洁厕灵伏笔）+ 小结作业 | 回扣氧化还原、埋氯章节伏笔 | 板书 |

> 说明：本节内容密度高（对比表 + 侯氏制碱 + 焰色），按 45 min 单课时设计，时间块以"核心性质对比充分展开 + 两处逐字稿"为优先；实际可据校情微调。

**导入**

**教师**："同学们，厨房里有两种白色粉末——纯碱（Na₂CO₃）和小苏打（NaHCO₃）。做馒头时放小苏打能蓬松，洗油污时放纯碱能去油。问题来了：它们能互相替代吗？比如用纯碱代替小苏打发面，行不行？"

**学生（预期）**："应该都差不多吧，都是'碱'。"（典型错误：默认二者性质相同、溶液都中性）

**教师（追问/理答）**："今天学完你会发现——它们'像'却'不一样'：热稳定性不一样、和醋反应的剧烈程度不一样、水溶液酸碱性也不一样。先记住一句提醒：**叫'盐'不等于溶液中性**，后面我们用 pH 试纸验证。今天我们就用'类别×价态'这把尺子，把这两种钠盐彻底比清楚。"

**探究 1（物理性质 + 热稳定性）**

**教师**："先比物理性质。二者都是白色固体。溶解性呢？同温下 Na₂CO₃ 溶解度 > NaHCO₃——所以向饱和 Na₂CO₃ 溶液通 CO₂，会析出 NaHCO₃ 沉淀，这正是后面侯氏制碱的关键。俗名：Na₂CO₃ 叫纯碱、苏打；NaHCO₃ 叫小苏打。

热稳定性是今天第一个重点。序列：**H₂CO₃ < NaHCO₃ < Na₂CO₃**。H₂CO₃ 室温就分解；NaHCO₃ 约 50 ℃ 开始分解、270 ℃ 完全：2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑；Na₂CO₃ 在 851 ℃ 才熔化而不分解。

现在我们做实验：两支试管分别装 Na₂CO₃、NaHCO₃，加热，导管通入澄清石灰水。"

**学生（预期）**："只有 NaHCO₃ 那支的石灰水变浑浊！Na₂CO₃ 这支不变。"

**教师（追问/理答）**："对。证据就是石灰水浑浊——说明放出了 CO₂，NaHCO₃ 受热分解、Na₂CO₃ 稳定。这步也是鉴别法之一。

追问根源：为什么碳酸氢盐更不稳定？微观上，HCO₃⁻ 里有个 H，阳离子半径越小、极化能力越强，对 O–H 键极化越厉害，H 越容易脱掉。所以碱金属碳酸氢盐递变：**LiHCO₃ < NaHCO₃ < KHCO₃**。Li⁺ 半径最小（约 76 pm）、极化最强，LiHCO₃ 甚至**不存在固体**（只能在水溶液里），加热即分解；这也是 Li₂CO₃ 受热都能分解成 Li₂O + CO₂ 的原因——小阳离子高电荷密度拉低了碳酸盐热稳定性。Na⁺（约 102 pm）、K⁺（约 138 pm）依次减弱，越来越稳定。一句话：热稳定性递变的根源是**阳离子极化能力**，不是凭空背的。"

**实验现象记录表（学生随堂填写，落实"证据推理"）**

| 实验 | 操作 | Na₂CO₃ 现象 | NaHCO₃ 现象 | 推论 |
|---|---|---|---|---|
| 加热导管入石灰水 | 两管分别加热、导管通澄清石灰水 | 石灰水不变浑浊 | 石灰水变浑浊 | NaHCO₃ 受热分解放 CO₂，Na₂CO₃ 稳定 |
| 点滴板滴加盐酸 | 同浓度同温、逐滴加稀盐酸 | 先无明显气泡，后缓出 | 立刻剧烈冒泡 | Na₂CO₃ 分步（慢热）、NaHCO₃ 一步（剧烈） |
| 加 CaCl₂ 溶液 | 各取少量溶液加数滴 CaCl₂ | 白色 CaCO₃ 沉淀 | 无沉淀 | 沉淀判别 Na₂CO₃ |
| pH 试纸测同浓度 | 等质量溶于水、滴 pH 试纸 | 更深蓝（碱性强） | 浅蓝（弱碱） | 均水解显碱，Na₂CO₃ 水解更强 |

此表把四个差异（热稳定性、与酸速率、与 CaCl₂、碱性）一次性实证，直接回应学情中的四类误解。

**探究 2（与酸/碱/CaCl₂ + 碱性，含逐字稿①）**

**教师**："再看和酸的反应，这是第二个重点，也最容易翻车。

Na₂CO₃ 与盐酸是**分步**的：先 Na₂CO₃ + HCl → NaHCO₃ + NaCl（CO₃²⁻ + H⁺ → HCO₃⁻），再加盐酸才放出 CO₂：NaHCO₃ + HCl → NaCl + H₂O + CO₂↑，合并即 Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑。

NaHCO₃ 与盐酸是**一步**：NaHCO₃ + HCl → NaCl + H₂O + CO₂↑（HCO₃⁻ + H⁺ → CO₂↑ + H₂O），更快更剧烈。

碱性：同浓度下 Na₂CO₃ 碱性 > NaHCO₃。因为二者都因水解显碱，但 CO₃²⁻ 水解程度更大（CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻，比 HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻ 强得多）。用 pH 试纸测同浓度溶液，Na₂CO₃ 那张更蓝。这就直接打碎'盐溶液都中性'的错觉——CO₃²⁻、HCO₃⁻ 都会水解产 OH⁻，只是程度不同。

与碱：NaHCO₃ + NaOH → Na₂CO₃ + H₂O（HCO₃⁻ + OH⁻ → CO₃²⁻ + H₂O），但 Na₂CO₃ **不与 NaOH 反应**（都是碱性、无 H 可给）。与 Ca(OH)₂ 要注意量：NaHCO₃（足量 Ca(OH)₂）时，NaHCO₃ + Ca(OH)₂ → CaCO₃↓ + NaOH + H₂O。

与 CaCl₂：Na₂CO₃ + CaCl₂ → CaCO₃↓ + 2NaCl（出沉淀）；NaHCO₃ 与 CaCl₂ **不沉淀**（除非溶液里有足量碱把 HCO₃⁻ 转成 CO₃²⁻）。这点也是鉴别关键。"

**逐字稿①（与酸速率对比，认知冲突）**

**教师**："这里有个反直觉的点，大家先猜：同样浓度、同样温度，把盐酸滴进 Na₂CO₃ 和 NaHCO₃，谁冒泡更猛更快？"

**学生（预期）**："Na₂CO₃ 吧？它'碱性更强、更强'应该反应更厉害。"（典型错误：直觉"强=快"）

**教师（追问/理答）**："实验结果恰恰相反——NaHCO₃ 那支'嘶'地一下更剧烈。为什么'弱'的反而快？看机理：

Na₂CO₃ 是**多步**：CO₃²⁻ 先吃一个 H⁺ 变成 HCO₃⁻（这一步不出气），HCO₃⁻ 再吃一个 H⁺ 才出 CO₂。要冒泡，得先'攒'出 HCO₃⁻ 中间体，所以起步慢、且逐滴加酸时先无明显气泡。

NaHCO₃ 是**一步**：HCO₃⁻ 直接 + H⁺ → CO₂↑ + H₂O，没有中间体，撞上就放气。

所以'剧烈程度'比的是**反应步数**，不是碱性强弱。碱性（水解）和热力学有关，速率（快慢）是动力学——两码事。记一句：Na₂CO₃ 与酸'慢热、分步、逐滴加先无泡'；NaHCO₃ 与酸'一步、剧烈、立刻冒泡'。"

**双轴定位（承接第一章"类别×价态"方法）**

把 Na₂CO₃/NaHCO₃ 落进"类别×价态"二维图，二者都是钠盐，C 均为 +4 最高价：
- **类别轴**：Na₂CO₃ = 正盐（无酸性 H），NaHCO₃ = 酸式盐（含可电离 H⁺，故能与 NaOH 反应）；
- **价态轴**：CO₃²⁻/HCO₃⁻ 中 C 为 +4 最高价，**只可能被氧化、不可能被还原**（无还原性，除非极苛刻条件）；
- **预测**：二者与酸/碱/盐的反应均为非氧化还原（复分解/水解/中和），印证"横轴同价态类别反应多非 redox"。这也解释了为什么本课所有反应都不写化合价变化——它们走的是离子反应通道，而非氧化还原通道。

**核心概念的宏—微—符三重表征（落实"宏观辨识与微观探析"）**

| 核心概念 | 宏观现象 | 微观粒子/结构 | 符号表达 |
|---|---|---|---|
| 溶解性差异 | 同温 Na₂CO₃ 溶得更多 | CO₃²⁻ 电荷高、水合作用强 | 溶解度：Na₂CO₃ > NaHCO₃ |
| 热稳定性 | NaHCO₃ 加热放 CO₂ 浑石灰水 | HCO₃⁻ 中 O–H 受阳离子极化易脱 H | 2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑ |
| 与酸速率 | NaHCO₃ 剧烈、Na₂CO₃ 慢热 | NaHCO₃ 一步、Na₂CO₃ 分步多步 | HCO₃⁻+H⁺→CO₂↑+H₂O；CO₃²⁻+H⁺→HCO₃⁻→CO₂↑ |
| 碱性 | 同浓度 Na₂CO₃ pH 更高 | CO₃²⁻ 水解程度 > HCO₃⁻ | CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻ |
| 加 CaCl₂ | Na₂CO₃ 出白色沉淀 | CO₃²⁻ 与 Ca²⁺ 结合 Ksp 小 | Ca²⁺ + CO₃²⁻ → CaCO₃↓ |
| 焰色 | Na 黄、K 紫（透蓝钴玻璃） | 电子受热激发—回落发光（物理） | —（非化学键变化） |

**探究 3（相互转化 + 三种鉴别）**

**教师**："把转化串成网——Na₂CO₃ ⇌ NaHCO₃ 是双向的：

正向（Na₂CO₃ → NaHCO₃）：Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃。关键是向**饱和 Na₂CO₃** 通 CO₂，因为生成的 NaHCO₃ 溶解度更小，以固体析出推动反应向右。

逆向（NaHCO₃ → Na₂CO₃）：两条路——① 加碱中和 NaHCO₃ + NaOH → Na₂CO₃ + H₂O；② 加热 2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑。

鉴别三种方案，任选其一即可判别：
1. **加热法**：加热放 CO₂ 使澄清石灰水浑浊的是 NaHCO₃，Na₂CO₃ 不浑。
2. **加酸速率法**：同条件下与盐酸反应更快更剧烈的是 NaHCO₃（一步），较慢的是 Na₂CO₃（分步）。
3. **加 CaCl₂ 法**：加 CaCl₂ 溶液产生白色 CaCO₃ 沉淀的是 Na₂CO₃；NaHCO₃ 不沉淀（除非先加足量碱）。

三种方案的'证据'分别是：CO₂ 使石灰水浑、反应速率差、沉淀生成。这就是'现象—证据—结论'。"

**逐字稿②（侯氏制碱）**

**教师**："最后一个高价值模块——侯氏制碱法，侯德榜先生的贡献。先问：怎么用便宜的 NaCl、NH₃、CO₂、H₂O 制得 Na₂CO₃？核心两步。

第一步：向**饱和 NaCl** 溶液里先通 NH₃、再通 CO₂，析出 NaHCO₃：
NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl

第二步：把 NaHCO₃ 加热分解得纯碱：
2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑（放出的 CO₂ 可循环再用）

现在关键问题：为什么**先通 NH₃ 后通 CO₂**，反过来不行吗？"

**学生（预期）**："先通 CO₂ 不行吗？CO₂ 不是主角吗？"（典型错误：以为 CO₂ 是目标气体就该先通）

**教师（追问/理答）**："不行，顺序有硬道理。CO₂ 在水里溶解度很小、直接通吸收差；而 NH₃ 极易溶于水，先通 NH₃ 让溶液变成**碱性氨水环境**，碱性环境能大量'抓住'随后通入的 CO₂，生成 HCO₃⁻，再和 Na⁺ 结合成微溶的 NaHCO₃ 析出。如果先通 CO₂，溶液近似中性、CO₂ 吸收极少，几乎不出 NaHCO₃。所以顺序是'**先氨后碳**'——用 NH₃ 的高溶解度去'催'CO₂ 的吸收。

对比索尔维法（氨碱法）：旧法 NaCl 利用率只有约 70%，副产的 CaCl₂ 几乎没用、成废渣。侯氏制碱把 NaCl 利用率提到 **96% 以上**，副产的 NH₄Cl 直接作氮肥，还避免了大量 CaCl₂ 废渣——既提高原子利用率又绿色，这就是家国情怀与工程智慧的体现。"

**探究 4（焰色试验）**

**教师**："最后看焰色试验。某些金属及其化合物在火焰中呈现特征颜色——Na 黄、K 紫（要透蓝色钴玻璃滤掉 Na 的黄光，否则被掩盖）、Ca 砖红、Cu 绿、Ba 黄绿。关键判断：**焰色试验是物理变化**——火焰热量使原子外层电子跃迁到激发态，回落到基态时放出特征波长光。整个过程**没有新物质生成、没有化学键断裂或形成**，所以不是化学变化。

注意误区：焰色不是钠的化合物特有，所有含钠物质（包括单质 Na）都显黄色，与阴离子无关；同理钾的化合物显紫色。操作上：铂丝（或光洁无锈铁丝）先蘸盐酸在火焰上烧至无色，再蘸样品灼烧观察；K 的紫色需隔蓝色钴玻璃观察。应用举例：节日烟花的五彩缤纷，正是不同金属盐的焰色叠加。"

**拓展（竞赛衔接，点到即止，必修不超纲）**

- **碳酸氢盐递变再深一层**：不仅 LiHCO₃ 无固体，Li₂CO₃ 受热也分解（Li₂CO₃ →△ Li₂O + CO₂↑），而 Na₂CO₃ 不分解——根源都是 Li⁺ 高电荷密度（小半径、强极化）拉低了含氧酸盐热稳定性。这是"阳离子极化能力"规律的统一体现，与 NaHCO₃ < Na₂CO₃ 同源。
- **混合物定量思想**：Na₂CO₃/NaHCO₃ 混合物加热失重只来自 NaHCO₃（2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑，每 2 mol 失 62 g），再结合后续盐酸溶解放出的总 CO₂，可用**关系式法**联立求解质量分数——挑战题①即此模型，是高考与初赛都爱考的"定量观"载体。

**应用衔接**

**教师**："本课收个尾、埋个伏笔。Na₂CO₃/NaHCO₃ 都含 CO₃²⁻/HCO₃⁻，遇到酸就放 CO₂。到了氯章节我们会遇到一个危险组合：84 消毒液（含 ClO⁻）和洁厕灵（含 Cl⁻）混用，在酸性条件下：
ClO⁻ + Cl⁻ + 2H⁺ → Cl₂↑ + H₂O
生成有毒 Cl₂！所以二者**绝不能混用**——这背后是第一章的氧化还原 + 离子反应，第二章氯章节（2.4/2.5）我们再深挖。今天记住：化学服务生活，但用错也会伤人。"

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 反例/判据 |
|---|---|---|
| 二者性质一样、可互换 | 热稳定性/加酸速率/碱性都不同 | 加热只有 NaHCO₃ 放 CO₂；NaHCO₃ 加酸更剧烈 |
| "盐"溶液都中性 | 均因水解显碱，Na₂CO₃ 更强 | CO₃²⁻、HCO₃⁻ 水解产 OH⁻；pH 试纸验证 |
| Na₂CO₃ 加酸更猛（强=快） | 速率比步数：NaHCO₃ 一步、Na₂CO₃ 分步 | 机理 CO₃²⁻→HCO₃⁻→CO₂ 多步 |
| NaHCO₃ 受热不分解 | 270 ℃ 完全分解放 CO₂ | 石灰水变浑浊 |
| 碳酸氢盐都稳定 | 递变 LiHCO₃ < NaHCO₃ < KHCO₃；LiHCO₃ 无固体 | 阳离子极化能力决定 |
| 焰色试验是化学变化 | 物理变化（电子跃迁） | 无新物质，仅发光 |
| 侯氏制碱先通 CO₂ | 先通 NH₃（高溶解度促吸收 CO₂） | 先碳则吸收差、不析出 |

**核心口诀**：两钠盐、比六性（溶解/热稳/酸/碱/CaCl₂/用途）；转化双向靠条件；鉴别三法（热/酸/沉）；侯氏先氨后碳；焰色是物理、电子跃迁发光。

  "物质的量"桥梁：宏观可称量 ⇄ 微观粒子数
  承接第一章：离子浓度(离子反应)·电子转移(氧化还原)
    · 本课衔接：84 消毒液(ClO⁻)+洁厕灵(Cl⁻)+2H⁺ → Cl₂↑+H₂O（为 2.4/2.5 埋伏笔）
  后续接口：铁与金属材料 / 物质结构·元素周期律 / 选择性必修 水溶液离子平衡·电化学
  核心方法：分类观 + 转化观 + 定量观 + 宏微符表征

## 八、作业布置

- **必做**（基础达标）：[[高中化学必修一-习题精选]] 题3。
  ① 完成 Na₂CO₃ 与 NaHCO₃ 对比表（俗名、溶解性、热稳定性、与酸/碱/CaCl₂、碱性、用途六栏）并各写一条核心方程式；
  ② 写出下列方程式并标条件：NaHCO₃ 加热分解、Na₂CO₃ 与足量盐酸（分步写出两步）、NaHCO₃ 与 NaOH、Na₂CO₃ 与 CaCl₂、向饱和 Na₂CO₃ 通 CO₂；
  ③ 用"加热 / 加酸速率 / 加 CaCl₂"三种方法鉴别二者，各写判别证据（现象 + 离子式）。

- **易错方程式专项（必做补充，针对常见错写）**：
  ① 向 Na₂CO₃ 溶液逐滴加盐酸，前段只生成 NaHCO₃——务必写分步：Na₂CO₃ + HCl → NaHCO₃ + NaCl，不可直接跳到出 CO₂；
  ② NaHCO₃ 与 CaCl₂ 混合**不写沉淀**，除非先加足量碱：NaHCO₃ + CaCl₂（无碱）→ 不反应，NaHCO₃ + Ca(OH)₂（足量）→ CaCO₃↓ + NaOH + H₂O；
  ③ 侯氏制碱第一步产物是 NaHCO₃↓（沉淀），不是 Na₂CO₃，需在第二步加热才得纯碱；
  ④ 焰色试验不写化学方程式（物理变化），只记颜色与操作。

- **选做**（能力提升）：
  ① 转化设计：限用试剂 H₂O、CO₂、NaOH 溶液、盐酸，设计 Na₂CO₃ ⇌ NaHCO₃ 的双向转化，写出每步反应式与条件，并说明"向饱和 Na₂CO₃ 通 CO₂ 析出 NaHCO₃"的驱动因素（溶解度差）；
  ② 写出侯氏制碱两步核心方程式，并说明"先通 NH₃ 后通 CO₂"的理由（NH₃ 高溶解度促 CO₂ 吸收）与对比索尔维法的两点优势（利用率、副产）。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① 混合物定量：现有 Na₂CO₃ 与 NaHCO₃ 混合物 m g，充分加热至恒重得 (m−a) g 固体，再用盐酸全部溶解生成标准状况下 V L CO₂。请用质量守恒/关系式法求原混合物中 Na₂CO₃ 的质量分数，并写出所列方程与关系式。
  ② 侯氏制碱计算：以 1 mol NaCl 为起点，按 NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl、2NaHCO₃ →△ Na₂CO₃ + H₂O + CO₂↑，若 NaHCO₃ 步骤 NaCl 利用率 96%，计算理论上可得 Na₂CO₃ 多少 mol；并说明放出的 CO₂ 循环通入前一步的意义。
  ③ 焰色鉴别方案设计：现有一包白色固体，可能是 Na₂CO₃、K₂CO₃、NaHCO₃、KCl 中的一种或两种混合。请设计一套完整鉴别方案（限用铂丝/盐酸/酒精灯/蓝色钴玻璃/盐酸/澄清石灰水），说明每一步操作、现象与结论，并指出"透蓝钴玻璃"滤去的是什么光、为何要滤。
