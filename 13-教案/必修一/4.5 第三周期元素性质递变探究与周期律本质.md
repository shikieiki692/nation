# 教案：4.5 第三周期元素性质递变探究与周期律本质（必修第一册 第四章 物质结构 元素周期律）

> **课时元信息**：第 4 章 / 4.5 第三周期元素性质递变探究与周期律本质 / 第 5 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[元素周期律]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：周期律主线的"性质验证"高潮课。4.3/4.4 已建立"位（周期表位置）—构（原子结构）—性（元素性质）"三角的"位"与"构"，本课进入"性"的实验验证与本质收束——用第三周期 Na→Cl 的金属性↓、非金属性↑递变链，把"结构决定性质"落到位-构-性闭环，并为 4.6 化学键（微粒间作用）转场。

---

## 一、课标对应

- **内容要求**：能结合有关资料和实验事实，认识元素性质随原子序数递增的周期性变化，能利用原子结构解释元素金属性、非金属性及其递变规律；能对第三周期、碱金属、卤素等元素性质进行预测和假设，并通过实验（与水/酸反应难易、最高价氧化物对应水化物的酸碱性、卤素置换等）进行验证；能结合原子结构说明元素周期律的本质。
- **学业质量水平**：必修水平 2——能基于原子结构（核电荷数、原子半径、电子层数）预测并解释同周期/同主族元素性质的递变；能设计或评价验证金属性/非金属性递变的实验方案；能说出周期律的哲学意义（量变到质变）。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从 Na 浮熔游响红、Mg/Al 与酸反应缓急等宏观现象，追到原子半径、核电荷数等微观结构差异，建立"宏观现象 → 微观结构 → 符号表达"表征链）；
  2. **变化观念与平衡思想**（认识元素性质随原子序数呈周期性变化，建立"结构渐变 → 性质递变"的动态变化观）；
  3. **证据推理与模型认知**（用实验证据链——金属性看单质与水/酸反应难易 + 最高价氧化物水化物碱性、非金属性看气态氢化物稳定性 + 最高价含氧酸酸性——建立"位-构-性"模型）；
  4. **科学探究与创新意识**（分组完成"元素争霸赛"实验探究——Na/Mg/Al 金属性大比拼、Cl/Br/I 非金属擂台赛，体会"假设—实验—证据—结论"）；
  5. **科学态度与社会责任**（通过门捷列夫预言"类铝"被证实的科学史，体会周期表的预测价值与科学家的求真精神）。

### 1.1 课标细目与课时落点对照

| 课标表述 | 本课对应落点 | 达成方式 |
|---|---|---|
| 结合实验认识性质周期性变化 | 第三周期 Na→Cl 金属性↓、非金属性↑ 递变链 | Na/Mg/Al 对照实验 + 最高价含氧酸酸性比较 |
| 用原子结构解释递变规律 | 同周期核电荷↑、半径↓→失电难得电易 | 原子结构示意图逐元素分析 + 本质板书 |
| 预测并实验验证元素性质 | 金属性/非金属性判定依据、卤素置换 | "元素争霸赛"分组实验探究 |
| 结合资料说明周期表指导作用 | 门捷列夫预言类铝→镓证实 | 科学史导入 + 周期律哲学意义升华 |
| 结构决定性质的观念 | 位-构-性三角闭合 | 小结收束 + 体系关联板书 |

**本课在单元中的地位**：4.1/4.2 原子结构铺垫"构"，4.3 元素周期表建立"位"，4.4 元素周期律给出半径、电离能、电负性等的递变规律。本课是"性"的实验验证落点——用真实实验把 4.4 的规律变成看得见的事实，并以原子结构为根源讲透"为什么"，完成"位-构-性"三角闭环，是全章周期律主线的高潮与收口。

## 二、学情分析（本课时）

学生在 4.1–4.4 已掌握原子结构（核电荷数 = 质子数 = 原子序数）、元素周期表位置（周期 = 电子层数、主族族序 = 最外层电子数）、以及原子半径、第一电离能、电负性的递变趋势，初步知道"同周期从左到右金属性减弱、非金属性增强"的结论。但此结论在学生脑中多为"背诵条文"，未经过实验验证，更未从原子结构角度真正理解"为什么"。本课新难点有四：一是**把"活泼外观"当成金属性**——凭"钠很软、能切、遇水炸"误判金属性强弱，不会用"与水/酸反应难易 + 最高价氧化物水化物碱性"两条标准判定；二是**误用含氧酸酸性代表非金属性**——看到 HClO 是弱酸就以为 Cl 非金属性弱，不懂必须看"最高价"含氧酸（HClO₄）；三是**误以为同周期电离能一直单调增大**——忽略 ⅡA>ⅢA、ⅤA>ⅥA 两处反常，把"趋势"当"绝对"；四是**忽略实验操作前提**——镁条表面氧化膜不打磨导致"与冷水也剧烈"的错觉，以及氯水久置失效仍当新制用。对策：用"元素争霸赛"分组竞赛制造认知冲突，用实验证据说话，用原子结构示意图逐元素讲透本质。

从能力基础看，学生在 Ch1~Ch3 已积累 Na 与水/氧气反应、Cl₂ 与 Na/Fe 反应、Al 与 NaOH 反应等具体元素化合物事实，但这些事实是"散点"，尚未被"周期律"这根线串起；本课正要把这些散点纳入同周期递变框架，让学生第一次用"规律"而非"记忆"去预判陌生元素性质。从思维习惯看，学生偏好"背结论、套关键词"，缺乏"用原子结构解释现象"的微观推理由此及彼的能力，因此本课把"本质解释"作为仅次于"实验探究"的第二重点，刻意放慢节奏、逐元素画原子结构示意图，逼学生从"是什么"走到"为什么"。

为落实框架"误区/易错前置"要求，先列出本课五处典型误解及其对策，作为导入与探究的靶向：

**【课前诊断·5 处典型误解预判】**

| 典型误解 | 正确认识 | 突破策略 |
|---|---|---|
| 金属性看金属"活泼外观"（软、能切、遇水炸） | 金属性 = 失电子能力，看单质与水/酸反应难易 + 最高价氧化物水化物碱性 | Na/Mg/Al 对照实验，淡化"外观"强调"反应难易" |
| HClO 酸性弱故 Cl 非金属性弱 | HClO 不是 Cl 最高价含氧酸；最高价为 HClO₄（最强酸）→ Cl 非金属性最强 | 强调"看最高价"，列 H₂SiO₃<H₃PO₄<H₂SO₄<HClO₄ 酸性序 |
| 同周期电离能一直单调增大 | 存在 ⅡA>ⅢA、ⅤA>ⅥA 反常（全满/半满稳定性），是"总体递增" | 4.4 已知，本课用 Mg、Al 对比巩固，不展开深度 |
| 镁与冷水也剧烈反应 | 镁条表面有氧化膜且本身活性居中；须打磨，与冷水缓、与热水/酸较快 | 实验前强调"打磨除氧化膜"，对比现象 |
| 氯水久置仍可用 | 久置 HClO 分解（2HClO → 2HCl + O₂↑）失氧化性，卤素置换须用新制氯水 | 实验活动 3 讨论题，课前点明"现用现配" |

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过 Na/Mg/Al 与水/酸反应及氢氧化物碱性的对照实验，培养**宏观辨识与微观探析**素养：从"浮熔游响红"等宏观现象追到原子半径、核电荷数的微观差异，建立"宏观现象 → 原子结构 → 符号表达"的表征链。
- 通过建构第三周期"金属性↓、非金属性↑"的递变链并分析"为什么会递变"，培养**变化观念与平衡思想**素养：认识元素性质随原子序数呈周期性变化，形成"结构渐变 → 性质递变"的动态变化观。
- 通过"金属性/非金属性判定依据"建立证据链，并用原子结构解释递变本质，培养**证据推理与模型认知**素养：用"位-构-性"三角模型统一解释实验现象与规律。
- 通过"元素争霸赛"分组实验（Na/Mg/Al 金属性大比拼、Cl/Br/I 非金属擂台赛），培养**科学探究与创新意识**素养：体会"假设—实验—现象—证据—结论"的探究逻辑，学会控制变量（如打磨镁条）。
- 通过门捷列夫预言"类铝"被布瓦博德朗发现镓证实的科学史，培养**科学态度与社会责任**素养：体会周期表的预测威力与科学家求真精神，理解周期律"量变到质变"的哲学意义。

### 3.2 学习目标（学生能……，可观测）

- 能**独立说出**金属性、非金属性的判定依据（金属性：单质与水/酸反应难易 + 最高价氧化物水化物碱性；非金属性：与 H₂ 化合难易 + 气态氢化物稳定性 + 最高价含氧酸酸性），并据此判断第三周期 Na→Cl 的递变方向。
- 能**正确书写并解释**本课核心事实：Na 与冷水 Na + H₂O → NaOH + H₂↑（浮熔游响红）；Mg 与热水/酸反应；Al 与酸反应且与碱反应（两性前奏）；最高价含氧酸酸性 H₂SiO₃ < H₃PO₄ < H₂SO₄ < HClO₄；卤素置换 Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂、Br₂ + 2I⁻ → 2Br⁻ + I₂。
- 能**用原子结构**解释递变本质：同周期核电荷数↑、原子半径↓ → 失电子能力↓、得电子能力↑ → 金属性↓、非金属性↑；同主族电子层数↑ → 金属性↑、非金属性↓。
- 能**画出**第三周期 Na→Cl 的"金属性↓、非金属性↑"递变链，标注本质（核电荷↑/半径↓），并指出 NaOH 强碱、Mg(OH)₂ 中强碱、Al(OH)₃ 两性对应的碱性递变。
- 能**复述**门捷列夫预言"类铝"→4 年后布瓦博德朗发现镓（Ga）的科学史，并说出周期律"量变到质变"的哲学意义与"结构决定性质"的位-构-性闭环。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 五、教学媒体与素材

- 实物/药品：钠（绿豆大小、煤油保存）、打磨后的镁条、铝片（或铝丝）、酚酞试液、蒸馏水、热水、稀盐酸、NaOH 溶液、新制氯水（课前现配）、溴水、碘水、NaBr 溶液、NaI 溶液、点滴板、试管若干、胶头滴管、酒精灯、砂纸（打磨镁条/铝片）。
- 实验装置/安全：通风橱、护目镜、橡胶手套（溴水强腐蚀）、坩埚（钠与水，不俯视）、镊子、滤纸。
- 情境素材：门捷列夫 1869 周期表留空位手稿文字引用、布瓦博德朗 1875 年发现镓的新闻文字引用、"元素争霸赛"分组竞赛任务卡（金属性大比拼 / 非金属擂台赛）。
- 学案：① 第三周期金属性对照实验记录表；② 最高价含氧酸酸性序填空；③ 卤素置换实验记录卡；④ 原子结构递变本质分析单；⑤ 周期律哲学意义微写作。
- **课前预习任务**（衔接 4.3/4.4，降低本课起点）：
  ① 回忆第三周期元素顺序 Na Mg Al Si P S Cl，并写出各自周期（均第 3 周期）与族序（IA→VIIA）；
  ② 回忆 4.4 原子半径递变（同周期左→右减小）与电负性递变（左→右增大），预测金属性/非金属性方向；
  ③ 查"门捷列夫预言元素"资料，看是否听说过"类铝"，带到课堂揭晓；
  ④ 思考"如何证明 Cl 的非金属性比 Br、I 强"，课上用卤素置换验证。

- **本课与《实验活动 3 同周期、同主族元素性质的递变》衔接说明**：本课 45 min 新授课是实验活动 3 的"理论收口与本质提炼"版本——实验活动 3 为分组操作课（Na/Mg/Al 对照、卤素置换点滴板），本课在其后或用其素材，重在把操作现象上升为"判定依据 + 原子结构本质"。若校情将实验活动 3 独立排课，本课的"元素争霸赛"情境可直接复用其分组数据与"三色"观察法（反应前/加入后/反应后颜色对比），避免重复操作、突出证据推理与模型认知。

## 六、教学过程（含逐字稿）

| 弹性时长 | 内容 | 师生活动 | 媒介 |
|---|---|---|---|---|
| 约 6 分钟 | 导入：门捷列夫预言"类铝" | 讲科学史，设问周期表为何能"算"出未知元素 | PPT+手写稿 |
| 约 14 分钟 | 探究1：第三周期金属性实验（Na/Mg/Al） | 分组做元素争霸赛·金属性大比拼，记录现象 | 实验+板书 |
| 约 11 分钟 | 探究2：非金属性递变（含氧酸酸性/卤素置换） | 列酸性序 + 卤素置换擂台赛（新制氯水） | 实验+PPT |
| 约 9 分钟 | 探究3：本质解释（原子结构角度） | 逐元素画原子结构示意图讲透本质 | 板书+学案 |
| 约 5 分钟 | 小结：结构决定性质 + 周期律哲学意义 | 闭合位-构-性三角，升华量变到质变 | 板书 |

> 说明：本节以"实验探究 + 本质解释"双核心展开，按 45 min 单课时设计，时间块以"分组实验充分展开 + 三处逐字稿"为优先；实际可据校情微调。

**导入**

**教师**："1869 年，门捷列夫把当时已知的 63 种元素按相对原子质量排成一张表，他做了一个大胆的事——在表里留了几个空位，并'算'出这些未知元素的性质：其中一种他叫'类铝'，预言它密度约 5.9、熔点低、性质像铝。4 年后，也就是 1875 年，法国化学家布瓦博德朗真的发现了一种新元素，性质与预言几乎完全吻合——它就是镓（Ga）。同学们，门捷列夫没见过镓，为什么敢预言？"

**学生（预期）**："因为他发现了规律？""元素之间有某种顺序？"

**教师（追问/理答）**："对！门捷列夫发现的正是**元素周期律**——元素的性质随原子序数递增呈周期性变化。今天我们就来验证这条规律的'性质'一半：用第三周期 Na→Cl 八个元素，看金属性怎么递减、非金属性怎么递增，最后回到原子结构，搞清楚'为什么会这样'。这既是验证，也是全章周期律主线的收口。"

**探究 1（第三周期金属性实验探究·元素争霸赛）**

**教师**："我们办一场'元素争霸赛'——金属性大比拼，选手是 Na、Mg、Al。判定金属性强弱，不看谁软、谁亮，只看两条硬标准：**单质与水或酸反应的难易程度**，以及**最高价氧化物对应水化物的碱性强弱**。先做实验，三张实验台分别上 Na、Mg、Al。"

**学生（预期）**："钠一扔进水就炸了！镁条在热水里才有气泡，还慢；铝片和酸反应更慢。"

**教师（追问/理答）**："注意操作细节——镁条、铝片**必须先用砂纸打磨除氧化膜**，否则表面氧化膜会挡住反应，让你误以为'不反应'或'冷水也剧烈'。现在看现象链：
① Na 与冷水**剧烈**反应：浮、熔（放热成球）、游、响、滴酚酞**红**（生成碱）——Na + H₂O → NaOH + H₂↑。
② Mg 与冷水**缓**、与热水或酸**较快**：Mg + 2H₂O(热) → Mg(OH)₂ + H₂↑，与酸更明显——说明 Mg 失电子比 Na 难。
③ Al 与酸**更缓**，且 Al 还能与碱反应（Al(OH)₃ 两性前奏）——失电子比 Mg 更难。
三者碱性：NaOH 强碱、Mg(OH)₂ 中强碱、Al(OH)₃ 两性（既溶于酸又溶于碱）。所以金属性：**Na > Mg > Al**。这就是证据链。"

**实验现象记录表（学生随堂填写，落实"证据推理"）**

| 选手 | 与冷水 | 与热水/酸 | 氢氧化物碱性 | 金属性推论 |
|---|---|---|---|---|
| Na | 剧烈（浮熔游响红） | 极快 | NaOH 强碱 | 最强 |
| Mg（已打磨） | 缓 | 较快 | Mg(OH)₂ 中强碱 | 居中 |
| Al（已打磨） | 很缓 | 与酸更缓、与碱也反应 | Al(OH)₃ 两性 | 最弱 |

此表直接回应学情中"金属性看外观""镁与冷水也剧烈""不打磨致失真"等误解。

**核心概念的宏—微—符三重表征（落实"宏观辨识与微观探析"）**

| 核心概念 | 宏观现象 | 微观结构根源 | 符号表达 |
|---|---|---|---|
| Na 与水反应 | 浮、熔、游、响、滴酚酞变红 | Na 原子半径大、最外层 1e⁻ 易失，放热使熔成球 | Na + H₂O → NaOH + H₂↑ |
| Mg 与热水/酸 | 有气泡、较缓 | Mg 半径小于 Na、核电荷更大，失 e⁻ 较难 | Mg + 2H₂O(热) → Mg(OH)₂ + H₂↑ |
| Al 与酸/碱 | 更缓、且溶于碱 | Al 半径最小、核电荷最大，失 e⁻ 最难（两性前奏） | 2Al + 6HCl → 2AlCl₃ + 3H₂↑ |
| 氢氧化物碱性 | NaOH 强碱 / Mg(OH)₂ 中强碱 / Al(OH)₃ 两性 | 金属性 Na>Mg>Al，阳离子对 OH⁻ 束缚递减→碱性递减 | —（碱性强弱序 Na>Mg>Al） |

**实验安全与操作要点（小组讨论前强调， 穿插）**

**教师**："三组实验都有安全红线，先说再动。钠取**绿豆大小**、用滤纸吸干煤油、绝不俯视坩埚；镁条、铝片**砂纸打磨至发亮**除氧化膜，否则现象失真；氯水、溴水有强腐蚀，**戴护目镜与橡胶手套**，点滴板微量操作即可，白色背景下颜色变化更明显；所有卤素实验在通风橱进行。安全不是束缚，是让证据可靠的前提。"

**探究 2（非金属性递变·含氧酸酸性 + 卤素置换擂台赛）**

**教师**："金属性看左边，非金属性看右边 Si、P、S、Cl。判定非金属性也有硬标准：与 H₂ 化合难易、气态氢化物稳定性、**最高价氧化物对应水化物的酸性**。看最高价含氧酸酸性序——注意是**最高价**：
H₂SiO₃（弱酸）< H₃PO₄（中强酸）< H₂SO₄（强酸）< HClO₄（最强酸）。
酸性越强，对应非金属性越强，所以**非金属性 Si < P < S < Cl**。"

**学生（预期，典型错误）**："可是 HClO 也是氯的酸，它还弱呢，凭什么 Cl 最强？"

**教师（追问/理答）**："问得好，这正是最大坑！HClO 里 Cl 是 +1 价，**不是最高价**；Cl 的最高价是 +7 价的 HClO₄（高氯酸），是已知最强无机酸。判定非金属性**必须看最高价含氧酸**，绝不能用低价含氧酸（如 HClO、HClO₃）代替。再看卤素置换擂台赛——同主族 Cl、Br、I 谁更强？用新制氯水、溴水、NaBr、NaI 在点滴板上做："
- Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂（氯水加入 NaBr，溶液变橙黄，说明 Cl₂ 把 Br⁻ 氧化）
- Br₂ + 2I⁻ → 2Br⁻ + I₂（溴水加入 NaI，溶液变紫褐，说明 Br₂ 把 I⁻ 氧化）
"氧化能力 Cl₂ > Br₂ > I₂，即非金属性 **Cl > Br > I**。注意——氯水必须**新制**，久置会 2HClO → 2HCl + O₂↑，HClO 分解失氧化性，实验就失败了（这正是实验活动 3 的讨论题）。"

**非金属性判定依据对照（落实"证据推理"）**

| 判定维度 | 具体证据 | 第三周期实例 | 推论 |
|---|---|---|---|
| 与 H₂ 化合难易 | 越易化合、氢化物越稳定，非金属性越强 | Cl₂ 与 H₂ 光照/点燃即爆，S 需加热且 H₂S 易分解 | Cl > S |
| 气态氢化物稳定性 | 氢化物越稳定，非金属性越强 | HCl 极稳定 > H₂S 不稳定 | Cl > S |
| 最高价含氧酸酸性 | 酸性越强，非金属性越强（★看最高价） | H₂SiO₃<H₃PO₄<H₂SO₄<HClO₄ | Si<P<S<Cl |

**逐字稿（卤素置换与"最高价"陷阱）**

**教师**："有同学课后会纠结：'Cl 有 HClO 这种弱酸，凭什么说它非金属性最强？'记住铁律——**比非金属性，只认最高价含氧酸**。HClO 里 Cl 是 +1，HClO₃ 里是 +5，都不是顶；Cl 的顶是 +7 价的 HClO₄（高氯酸），是无机酸里最强的。用低价含氧酸比强弱，就像用 Fe²⁺ 的还原性去比 Fe 的金属性，张冠李戴。再回头看置换：Cl₂ 能把 Br⁻、I⁻ 依次氧化，说明 Cl 抢夺电子的能力在同族最强，这和非金属性 Cl>Br>I 完全自洽。"

**探究 3（本质解释·原子结构角度）**

**教师**："现象都看到了，可'为什么'会递变？回到原子结构。第三周期 Na→Cl，电子层数都是 3 层不变，但**核电荷数从 11 一路增到 17**，原子核对核外电子的吸引力越来越强，原子半径就越来越小。结果——"

**学生（预期）**："越往右越抓得紧，所以越难失去电子？"

**教师（追问/理答）**："完全正确。原子半径减小 + 核电荷增大 → **失电子能力↓、得电子能力↑** → 金属性↓、非金属性↑。这就是同周期递变的本质。同主族正好反过来：从上到下**电子层数增多**，原子半径增大、屏蔽增强，核对外层电子抓不住 → 金属性↑、非金属性↓。一句话收口：**结构决定性质**。再看门捷列夫——他之所以能预言'类铝'，正是因为周期表背后是原子结构的周期性，空位元素的'邻居'决定了它的性质区间。"

**逐字稿（本质与哲学升华）**

**教师**："把今天串起来：左边 Na 易失电子（金属性最强），右边 Cl 易得电子（非金属性最强），中间渐变——这不是突变，是核电荷一个个加、半径一点点缩的**量变积累**，到了最外层 8 电子就发生**质变**（稀有气体稳定结构）。这种'量变引起质变'，正是元素周期律深刻的哲学意义：自然界不是一堆孤立的元素，而是有内在秩序的整体。下一课我们进入化学键，看这些原子之间怎么'拉手'成物质——那是'构'向'物质'的下一站。"

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 反例/判据 |
|---|---|---|
| 金属性看活泼外观 | 看与水/酸反应难易 + 最高价氧化物水化物碱性 | Na/Mg/Al 对照，Na 反应最易 |
| HClO 弱故 Cl 非金属性弱 | 须看**最高价**含氧酸 HClO₄（最强） | HClO 中 Cl 为 +1，非最高价 |
| 同周期电离能一直增大 | 总体增但有 ⅡA>ⅢA、ⅤA>ⅥA 反常 | 全满/半满稳定性 |
| 镁与冷水也剧烈 | 镁条须打磨；本身与冷水缓、热水/酸较快 | 不打磨被氧化膜误导 |
| 氯水久置仍可用 | 久置 HClO 分解失氧化性，须新制 | 2HClO → 2HCl + O₂↑ |
| 同主族递变同周期 | 同主族电子层↑→金属性↑非金属性↓（反向） | Cl>Br>I 与 Na<K<Rb 反向 |

**核心口诀**：金属性看反应易不难 + 碱性强不强；非金属性看氢化物稳不稳 + 最高价含氧酸强不强；递变本质——核电荷↑、半径↓；结构决定性质；量变到质变。

  ⑤ 同主族递变方向不可与同周期混淆：同主族电子层↑ → 金属性↑、非金属性↓（与同周期反向），不得把"左弱右强"误推到上下关系。

- **选做**（能力提升）：
  ① 用原子结构示意图（Na 2,8,1 至 Cl 2,8,7）逐一说明核电荷数与原子半径如何导致金属性递减，并解释为何 ⅡA>ⅢA、ⅤA>ⅥA 第一电离能出现反常（全满/半满稳定性，点到即可）；
  ② 整理"金属性 vs 非金属性判定依据对照表"：左列金属性两条、右列非金属性三条，各配一个第三周期实例。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① 设计验证同主族递变的实验方案：限用试剂钠、钾（或 Li/Rb 任一对碱金属）与冷水，证明同主族从上到下金属性增强；另设计卤素（Cl₂/Br₂/I₂）置换方案证明非金属性 Cl>Br>I。写出操作、预期现象、结论与"控制变量"要点；
  ② 写一则"门捷列夫预言元素的故事"微写作（300 字内）：以"类铝"预言到镓被发现的经过为线索，说明周期律如何体现"结构决定性质"与"量变到质变"，并联系本课第三周期递变链；
  ③ 辨析题：已知某同学说"同周期从左到右原子半径减小，所以电负性增大、非金属性增强，但电离能却一直增大没有例外"。请指出其中错误（电离能两处反常），并结合 Mg、Al 的电子构型（Mg 3s² 全满、Al 3s²3p¹）说明反常根源。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否独立排出第三周期金属性 Na>Mg>Al、非金属性 Si<P<S<Cl，并说出判定依据（金属性看反应难易+碱性、非金属性看最高价含氧酸酸性）？"金属性看外观""HClO 弱故 Cl 弱"等误解是否被破除？
- [ ] 分组实验"元素争霸赛"是否真正展开——Mg/Al 是否落实"打磨除氧化膜"、钠取用量是否安全（绿豆大小、不俯视）、氯水是否新制？现象记录是否被准确观察而非背结论？
- [ ] 本质解释是否讲透——学生能否用"同周期核电荷↑、半径↓ → 失电难得电易"解释递变，而非仅背"左弱右强"？门捷列夫预言"类铝"→镓的科学史与"量变到质变"哲学意义是否被有效对接？
- [ ] 两段式板书是否完整（Part1 递变链+本质+科学史，Part2 体系关联套骨架且 ★ 标"元素周期律"）；位-构-性三角是否在小结中闭合；作业三层（含同主族实验方案设计/门捷列夫故事/电离能反常辨析）是否达成区分度？
- [ ] "元素争霸赛"情境是否真正激发了探究动机、证据链是否完整闭合（金属性双判据 + 非金属性三判据各被实验/事实支撑）；门捷列夫预言"类铝"→镓的科学史是否自然升华到"量变到质变"哲学意义，而非仅作为导入花絮带过？
