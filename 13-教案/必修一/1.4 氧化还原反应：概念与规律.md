# 教案：1.4 氧化还原反应——概念与规律（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.4 氧化还原反应：概念与规律 / 第 4 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[氧化还原反应基础]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：合并原"概念"与"规律"两课时，沿"得氧失氧→化合价升降→电子转移"三级认识台阶建立氧化还原核心视角，掌握氧化数计算、双线桥/单线桥规范；进而提炼价态规律、强弱五法、先后规律、归中与歧化，形成可迁移的判断与预测工具。比旧版明显加深、加全、加难。

## 一、课标对应

- **内容要求**：认识有化合价变化的反应是氧化还原反应；了解氧化还原反应的本质是电子的转移（得失或偏移）；知道常见的氧化剂和还原剂；能从物质类别和元素价态变化的视角说明物质的转化路径。
- **学业质量水平**（必修）：水平 2——能从化合价变化判断反应类型，能正确标出电子转移方向与数目，能指认氧化剂、还原剂、氧化产物、还原产物；能比较物质氧化性与还原性强弱，用价态规律分析不同价态间的转化，判断反应先后顺序与归中/歧化产物。
- **核心素养落点**：**宏观辨识与微观探析**（从物质宏观变化追溯电子微观迁移）；**证据推理与模型认知**（用双线桥/单线桥、价态数轴模型表征电子守恒与归中歧化）；**变化观念与平衡思想**（理解价态—性质随浓度/介质而变的动态性）；**科学态度与社会责任**（以 84+洁厕灵中毒等真实事件建立"化学服务于安全生活"的意识）。
- **高考/会考指向**：氧化还原的考查贯穿必修与选择性必修，核心落点有三——一是电子转移方向与数目的规范表征（双线桥/单线桥），二是依据价态与强弱五法判断氧化剂/还原剂/产物价态，三是归中歧化的价态数轴推断与信息型陌生反应分析。本节是所有后续电化学、金属非金属性质、配平计算的基石，须从高一就建立"标价态→找升降→定角色→查守恒"的稳定解题程序。

**【本节与前后知识的衔接】**：向前，它承接第一章"物质的分类与转化"，把"有无电子转移"作为反应分类的深层标准；向后，它是第二章"海水中的卤素""金属及其化合物"中 Fe²⁺/Fe³⁺ 转化、Cl₂ 歧化、铝热反应的解释工具，更是选择性必修"化学反应原理"中原电池/电解池、电化学腐蚀、氧化还原滴定的前置能力。换言之，本节是整座高中氧化还原知识大厦的承重墙——今天练熟的氧化数、双线桥、价态数轴，会在后续每一章反复调用。

## 二、学情分析（本课时）

**【课前诊断·5 处典型误解预判】**

- 学生常把"化合价变化"与"有没有氧"混为一谈（根本判据是化合价是否变化，无氧气参与的反应也可能是氧化还原）。
- 学生常把氧化数（人为规定的形式电荷）误认为真实电荷。
- 学生画双线桥时常出现箭头跨元素、电子数目误等于价态变化数两类错误（电子数应为价态变化数 × 变价原子个数）。
- 学生对中间价兼性物质（Cl₂、S、H₂O₂、Fe²⁺ 等）在不同反应中的氧化剂/还原剂角色切换是认知盲区。
- 学生常绝对化"高价＝强氧化性"，把归中反应画成交叉，并把 NO₂ 的歧化（3NO₂+H₂O→2HNO₃+NO）误判为归中。

学生在初中已建立"得氧失氧"的旧框架，能凭直觉判断燃烧、生锈等少数反应；进入本章后，已初步接触元素化合价，但常把"化合价变化"与"有没有氧"混为一谈。本节须帮助他们完成三级跃迁：从得氧失氧上升为"化合价是否变化"这一根本判据，再深入到电子转移本质。学情上，氧化数作为形式电荷的引入最易与"真实电荷"混淆；双线桥常出现箭头跨元素、电子数目误等于价态变化数两类错误；中间价兼性物质（Cl₂、S、H₂O₂、Fe²⁺ 等）的角色切换是认知盲区；规律层面，"高价=强氧化"的绝对化、归中画成交叉、把 NO₂ 歧化误判为归中，是最典型的三处误区。强弱五法、先后规律（如向 Fe³⁺/Cu²⁺/H⁺ 混合液加 Fe 粉）、归中与歧化的价态数轴分析，则需在旧版基础上明显提难度与完整度。整体看，学生"背口诀"容易、"用模型推理"困难，本课时须以数轴与排队模型把抽象规律外显化。此外，班级两极分化明显：部分学生已能凭直觉判氧化剂/还原剂，但一遇"部分变价""歧化""信息型陌生反应"就卡壳；另一部分仍停留在"看有没有氧"的初中直觉。因此课堂须以高频短反馈（即时练习、随堂诊断）把两类学生都拉到"标价态→找升降→定角色→查守恒"的统一程序上，再用选做/挑战分层托举尖子。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标

- **宏观辨识与微观探析**：能从化合价升降这一宏观可观测证据，推断反应内部电子得失/偏移的微观本质；能把宏观可观察的反应先后、产物价态，回溯到微观电子得失的相对难易。
- **证据推理与模型认知**：能建构并熟练使用双线桥、单线桥、价态数轴模型，将"电子守恒""只靠拢不交叉"等抽象规律外显为可操作的表征与预测工具；能依据五类证据建构氧化性/还原性强弱推理链。
- **变化观念与平衡思想**：认识元素价态与氧化还原性质的对应是"变化中有规律"的——最高价只氧化、最低价只还原、中间价兼具，但同一物质表现受浓度与介质调节。
- **科学态度与社会责任**：能运用氧化还原视角解释 84 消毒液与洁厕灵混用等生活安全风险，形成审慎、实证的态度。

### 3.2 学习目标（学生能……）

- 能说出"得氧失氧、化合价升降、电子转移"三级判据各自的适用边界，并用"看化合价是否变化"作为氧化还原反应的根本判据；能按规则计算 Fe₃O₄、Na₂S₂O₃、H₂C₂O₄、CH₃CH₂OH 中关键元素的氧化数。
- 能规范画出双线桥与单线桥，正确标注"得失电子数目、氧化/还原、氧化剂/还原剂、氧化产物/还原产物"，并厘清"升失氧/降得还"针对元素/物质而非整个反应的准确含义。
- 能列举常见氧化剂/还原剂，指出 Cl₂、S、H₂O₂、Fe²⁺、SO₂、NO 等中间价物质在不同反应中的角色切换；能判断四类基本反应与氧化还原的包含关系并辨析典型误区。
- 能口述价态规律，运用强弱五法比较陌生物质氧化性强弱，用"强者优先"推断混合体系中反应先后顺序与最终产物。
- 能用"只靠拢不交叉"预判归中产物价态，区分归中与歧化，识别 NO₂ 等"看似归中实为歧化"的边界案例，并能用价态数轴可视化分析与预测未知剂。

> 注：旧三维目标框架（知识与技能、过程与方法、情感态度与价值观）已废止，本课目标均以学科核心素养统领，不再沿用旧框架字样。

## 五、教学媒体与素材

- 情境：84 消毒液（ClO⁻）与洁厕灵（HCl）混用生成有毒 Cl₂；切开的苹果变黄（酚类被 O₂ 氧化）；食品脱氧剂中铁粉消耗 O₂。
- 微观动画：Na 与 Cl₂ 形成 NaCl 的电子得失（Na 失 e⁻ 成 Na⁺，Cl 得 e⁻ 成 Cl⁻）；H₂ 与 Cl₂ 中共用电子对偏向 Cl（电子偏移）。
- 模型：四类基本反应类型与氧化还原关系的韦恩图（文字描述，见库内锚点，本次不嵌入哈希图）；元素价态数轴（S：−2 / 0 / +4 / +6；N：−3 / 0 / +1 / +2 / +4 / +5；Cl：−1 / 0 / +1 / +3 / +5 / +7）。
- 认知史素材：拉瓦锡（1774，得氧失氧）→ 弗兰克兰（1852，化合价升降）→ 汤姆孙（1897，电子转移）三级台阶。
- 电化学素材：原电池/电解原理示意图（库内锚点，本次不嵌入哈希图，电子定向移动直观说明电化学法比较强弱）。
- 常见剂清单卡：氧化剂（KMnO₄、浓 H₂SO₄、HNO₃、Cl₂、Br₂、FeCl₃、H₂O₂ 等）、还原剂（Na、Fe、Al、C、CO、H₂、Fe²⁺、S²⁻、I⁻、SO₃²⁻ 等），供课堂匹配价态使用。

### 环节一：情境导入（84+洁厕灵）

**教师**："同学们，新闻里常有这样的提醒——84 消毒液和洁厕灵绝对不能混用，混用会放'毒气'。大家看屏幕：84 含 ClO⁻，洁厕灵含 HCl，二者相遇会生成 Cl₂。问题来了：这两种东西单独用都很安全、天天见，为什么一混合就危险？今天我们就用一类特殊反应的眼光来拆穿它。"

**学生（预期）**："因为它们混在一起发生了化学反应，产生了氯气！""是不是有氧气参加的反应？"

**教师（追问/理答）**："对，反应生成了 Cl₂，但关键不是'有没有氧'，而是反应内部发生了电子的重新分配。这种伴随电子转移的反应，化学上叫——氧化还原反应。从今天起，我们判断它不再看'有没有氧'，而要看一条更本质的线索。我们一步步来。"

**教师**："其实氧化还原就在身边，举三个：① 切开的苹果变黄——酚类物质被空气中的 O₂ 氧化（O₂ 是氧化剂，O 从 0 降到 −2）；② 食品脱氧剂里的铁粉消耗 O₂ 生成铁锈（Fe 0→+3，被氧化，铁粉作还原剂）；③ 煤气燃烧 CH₄ + 2O₂ → CO₂ + 2H₂O（C −4→+4、O 0→−2，典型的氧化还原）。可见'有没有氧参加'只是特例，本质是电子的重新分配——哪怕像 84+洁厕灵那样根本没有氧气，也一样是氧化还原。"

### 环节二：三级认识台阶、氧化数初探与双线桥规范

**教师**："我们先走三级台阶。第一级，初中说法：物质**得氧**叫被氧化，**失氧**叫被还原——比如 CuO + H₂ → Cu + H₂O，H₂ 得氧被氧化。但这台阶有个大漏洞：没有氧参与的反应怎么办？比如 Fe + CuSO₄ = FeSO₄ + Cu，没氧，可它明明是一类反应。所以第二级——弗兰克兰提出：看**化合价升降**。只要反应前后有元素化合价变化，就是氧化还原。第三级，汤姆孙揭示本质：**电子转移**。离子化合物里是电子得失（NaCl 中 Na 把电子给 Cl）；共价化合物里是电子偏移（HCl 里共用电子对偏向 Cl）。化合价的升降，只是电子'记账'的语言。"

**学生（预期）**："那 Fe + CuSO₄ 里，Fe 从 0 升到 +2，Cu 从 +2 降到 0，所以它也是氧化还原！""化合价升降比得氧失氧管用。"

**教师（追问/理答）**："非常好。但你有没有想过——化合价为什么变？根子在电子转移。**化合价是否变化，就是根本判据**，得氧失氧只是它的特例。这里要引入一个重要概念：**氧化数**。中学里我们说的'化合价'，实际是氧化数——人为规定的形式电荷数，不是真实电荷。规则有五条：① 单质氧化数=0；② 化合物各元素氧化数代数和=0；③ O 通常 −2，过氧键（−O−O−）中 O 为 −1；④ H 通常 +1，金属氢化物（如 NaH）中 H 为 −1；⑤ 金属显正价，单原子离子氧化数=电荷数（Na⁺ 为 +1，Cl⁻ 为 −1）。"

**教师**："练几个复杂算例。Fe₃O₄：O 为 −2×4=−8，3 个 Fe 合计 +8，平均每个 Fe 为 +8/3——注意氧化数可以是分数，因为它是'平均形式电荷'，实际是 1 个 Fe²⁺ + 2 个 Fe³⁺。Na₂S₂O₃：2Na 共 +2，3O 共 −6，2 个 S 合计 +4，平均每个 S 为 +2（结构上是 1 个 S 为 −1、1 个 S 为 +5）。H₂C₂O₄：2H 共 +2，4O 共 −8，2 个 C 合计 +6，平均每个 C 为 +3。CH₃CH₂OH：C₂H₆O 总 0，2C+6×(+1)+(−2)=0，得 2C=−4，平均 C 为 −2（CH₃ 上的 C 为 −3，CH₂OH 上的 C 为 −1）。K₂Cr₂O₇：2K 共 +2，7O 共 −14，2Cr 共 +12，Cr 为 +6，这是重铬酸根中 Cr 的典型最高价。NH₄NO₃ 中 N 也一分为二：铵根 N 为 −3，硝酸根 N 为 +5。H₂O₂ 中 O 为 −1（过氧键）。"

**教师**："核心关系口诀——'**升失氧/降得还**'，但必须说清针对对象：某**元素**化合价**升**高 → 该物质中该元素**失**电子 → 该元素被**氧**化 → 含该元素的反应物作**还**原剂；某**元素**化合价**降**低 → 该物质中该元素**得**电子 → 该元素被**还**原 → 作**氧**化剂。逻辑链'物质→元素→过程→角色'一一对应，绝不能把'元素被氧化'说成'物质被氧化作氧化剂'。氧化产物是还原剂被氧化后得到的产物，还原产物是氧化剂被还原后得到的产物。"

**教师**："我们用 Fe + CuSO₄ = FeSO₄ + Cu 画**双线桥**。第一步标变价：Fe 0→+2，Cu +2→0。第二步连双线——箭头必须**从反应物同种元素指向产物同种元素**，Fe 指 Fe、Cu 指 Cu，不能跨元素！第三步注得失：上方 Fe→Fe 写'失去 2e⁻，化合价升高，被氧化'；下方 Cu→Cu 写'得到 2e⁻，化合价降低，被还原'。第四步查电子守恒：失 2e⁻=得 2e⁻。**单线桥**只画一条线，从还原剂指向氧化剂：Fe ──2e⁻──→ Cu²⁺（线上只标电子总数，不标得/失、不标两端角色）。"

**学生（预期，典型错误）**："老师，我把箭头从 Fe 连到了 Cu 那边，因为电子是 Fe 给 Cu 的。""还有，Fe 变了 2 价，电子数不就是 2 个 e⁻ 吗？"

**教师（追问/理答）**："两个典型错误都来了——第一，双线桥的箭头是'同种元素自身'的升降标记，不是电子流动方向，所以 Fe 只能指 Fe、Cu 只能指 Cu，电子流动另有'单线桥'表示；跨元素就乱了。第二，电子数目 = 价态变化数 × **变价原子个数**，这里 1 个 Fe 原子变 2 价，所以 2e⁻；若 2 个 Fe 原子各变 2 价，才是 4e⁻——别把'价态变化数'直接当'电子数'。"

**教师**："再练两个带'部分变价'的。例二：MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O。变价元素：Mn +4→+2（得 2e⁻），Cl 在 HCl 中是 −1，产物 Cl₂ 中 0——但 4 个 HCl 里只有 2 个 Cl 被氧化成 Cl₂，另 2 个 Cl 以 −1 留在 MnCl₂ 中没变价！双线桥：Mn 线'得 2e⁻，降，被还原'，2Cl⁻→Cl₂ 线'失 2e⁻，升，被氧化'，总转移 2e⁻。例三（歧化）：Cl₂ + 2NaOH = NaCl + NaClO + H₂O，Cl₂ 中 Cl 0 既降到 −1（NaCl）又升到 +1（NaClO），双线桥从同一 Cl₂ 分别指向 NaCl 中的 Cl(−1) 与 NaClO 中的 Cl(+1)，各转移 1e⁻ 共 2e⁻——这正是'同种元素既升又降'的歧化表征。"

**教师**："再给第四个例子——铜与浓硝酸：Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O。变价：Cu 0→+2（失 2e⁻），N 在 HNO₃ 中 +5→NO₂ 中 +4（得 1e⁻×2 个 N）。双线桥：Cu→Cu²⁺ 失 2e⁻、升、被氧化；2 个 N(+5)→2 个 N(+4) 共得 2e⁻、降、被还原。注意：4 个 HNO₃ 中只有 2 个被还原成 NO₂，另 2 个以 NO₃⁻ 形式留在 Cu(NO₃)₂ 中没变价——这又是'部分变价'。双线桥文字图：Cu 线'失 2e⁻ 升 被氧化'、N 线'得 2e⁻ 降 被还原'，二者在 2e⁻ 处守恒。"

**【双线桥 vs 单线桥 对比表】**（投影，避免混用）：

| 维度 | 双线桥 | 单线桥 |
|---|---|---|
| 线条数 | 两条（同种元素各一条） | 一条 |
| 箭头方向 | 反应物某元素 → 产物同种元素 | 还原剂 → 氧化剂 |
| 标注内容 | 失/得 e⁻×n、价升/降、被氧化/还原 | 仅标转移电子总数 e⁻ |
| 表达重点 | 谁升谁降、各元素电子得失 | 电子从哪里转移到哪里 |
| 能否跨元素 | 绝不可（必须同种元素） | 本就跨物质（还→氧） |
| 守恒检查 | 失电子总数 = 得电子总数 | 线上数目 = 总转移数 |

**学生（预期，典型错误）**："老师，FeS₂ 里 S 是不是 −2？和 Na₂S 一样？""Na₂O₂ 我按 O −2 算出来 Na 居然 +4，肯定哪里错了。"

**教师（追问/理答）**："两个都踩在'默认价态'的坑里。FeS₂ 是过硫根 S₂²⁻，两个 S 共用一对电子、整体 −2，所以每个 S 是 −1，不是硫化物里的 −2；Na₂O₂ 是过氧键 O−O，O 是 −1 不是 −2，你用 −2 去算当然得到 Na 为 +4 的荒谬结果——一旦算出金属正价超过其常见最高价，立刻回头检查过氧键！这正是氧化数'形式电荷'本性：它服从代数和规则，不服从你的直觉。"

**【常见氧化数特例汇总表】**（贴于学案背面，随时查）：

| 物质 | 关键元素 | 氧化数 | 易错提醒 |
|---|---|---|---|
| Fe₃O₄ | Fe | 平均 +8/3（1×+2 + 2×+3） | 不可写成 +2 或 +3 单一值 |
| FeS₂ | S | −1（过硫根 S₂²⁻） | 非 −2 |
| Na₂O₂ / H₂O₂ | O | −1（过氧键） | 非 −2 |
| K₂Cr₂O₇ / CrO₃ | Cr | +6 | 最高价，只具氧化性 |
| KMnO₄ | Mn | +7 | 酸性中还原为 +2 |
| NH₄NO₃ | N | −3（铵根）与 +5（硝酸根） | 同一物质两价态 |
| H₂C₂O₄ | C | +3（平均） | 有机酸，用代数和 |
| CH₃CH₂OH | C | −2（平均；CH₃ 上 −3、CH₂OH 上 −1） | 有机物按 C 平均算 |

**学生（预期，巩固提问）**："老师，那 H₂O 里 H 是 +1、O 是 −2，可金属氢化物 NaH 里 H 怎么成 −1 了？"

**教师（追问/理答）**："好问题，这正是规则④ 的边界——H 通常 +1，但和电负性比它大的金属（如 Na）成键时，电子偏向 H，于是 H 显 −1（如 NaH、CaH₂）。同理，O 通常 −2，但和 F 成键（OF₂）时 O 显 +2。规则要记'通常'，更要记住'例外来自电负性'——氧化数是按电负性分配电子的形式结果，不是死板标签。"

### 环节三：中间价兼性物质、常见剂清单、四大反应类型与误区反例

**教师**："哪些物质既能作氧化剂又能作还原剂？关键看元素是否处于**中间价态**。Cl₂（0 价）、S（0 价）、H₂O₂（O 为 −1）、Fe²⁺（+2 中间价）、SO₂（S 为 +4）、NO（N 为 +2）都在此列。例如 H₂O₂ 遇强氧化剂 KMnO₄ 时作还原剂（O 从 −1 升到 0 放出 O₂），遇强还原剂 Fe²⁺ 时作氧化剂（O 从 −1 降到 −2 生成 H₂O）——同一物质在不同反应中角色切换，全看对手强弱。再看 SO₂：遇 H₂S 作氧化剂（S +4→0），遇 Cl₂/H₂O₂ 作还原剂（S +4→+6）。"

**常见氧化剂/还原剂清单（含价态变化）**：
- 常见氧化剂（得电子、氧化数降低）：KMnO₄（Mn +7→+2，酸性）、浓 H₂SO₄（S +6→+4）、HNO₃（N +5→+4 或 +2）、Cl₂（0→−1）、Br₂（0→−1）、FeCl₃（Fe +3→+2）、H₂O₂（O −1→−2）。
- 常见还原剂（失电子、氧化数升高）：活泼金属 Na、Fe、Al、Zn；C（0→+4）、CO（+2→+4）、H₂（0→+1）；Fe²⁺（+2→+3）、S²⁻（−2→0）、I⁻（−1→0）、SO₃²⁻（S +4→+6）。
- 特殊（中间价，兼具氧化性和还原性）：S（0）、Cl₂（0）、H₂O₂（O −1）、Fe²⁺（+2）、SO₂（S +4）、NO（N +2）**既可作氧化剂又可作还原剂**；判断依据：该元素是否处于中间价态。

**【常见剂与典型反应速配表】**（帮助记忆"什么剂常和什么反应"）：

| 常见氧化剂 | 典型被还原产物 | 代表反应（节选） |
|---|---|---|
| KMnO₄（酸性） | Mn²⁺（+2） | 2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → K₂SO₄ + 2MnSO₄ + 5O₂↑ + 8H₂O |
| 浓 H₂SO₄ | SO₂（+4） | Cu + 2H₂SO₄(浓) → CuSO₄ + SO₂↑ + 2H₂O |
| HNO₃（浓/稀） | NO₂ / NO | Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O |
| Cl₂ | Cl⁻ | Cl₂ + 2KBr → 2KCl + Br₂ |
| FeCl₃ | Fe²⁺ | 2FeCl₃ + Cu → 2FeCl₂ + CuCl₂ |
| H₂O₂ | H₂O（O −2） | H₂O₂ + 2Fe²⁺ + 2H⁺ → 2Fe³⁺ + 2H₂O |

**教师**："四类基本反应与氧化还原的包含关系（韦恩图逻辑），逐类看：
- **置换反应**（A+BC→AC+B）：一定是氧化还原——例 Zn + H₂SO₄ = ZnSO₄ + H₂↑（Zn 0→+2，H +1→0）。
- **复分解反应**（交换成分）：一定不是氧化还原——例 NaOH + HCl = NaCl + H₂O（无变价）。
- **化合反应**：不一定是——2H₂+O₂=2H₂O 是（H 0→+1，O 0→−2）；CaO+H₂O=Ca(OH)₂ 不是（无变价）。
- **分解反应**：不一定是——2H₂O₂=2H₂O+O₂↑ 是（O −1→−2 与 0）；CaCO₃=CaO+CO₂↑ 不是（无变价）。
韦恩图表述：氧化还原集合**真包含**置换集合；复分解集合与氧化还原**不相交**；化合、分解两个集合与氧化还原**部分相交**。"

**教师**："误区深度辨析，记四条：① 有单质参与/生成**未必**是氧化还原——同素异形体转化 3O₂=2O₃、石墨→金刚石，虽有单质但无变价，不是氧化还原。**根本判据是化合价是否变化**，不是有没有单质。② 反例 CuO + CO → Cu + CO₂ 有单质 Cu 生成，它**是**氧化还原（C +2→+4，Cu +2→0），说明'有单质'既不能当充分也不能当必要条件。③ 把'高价=强氧化'绝对化是另一大坑，已用 Na₂SO₃、浓稀硫酸讲清——Na₂SO₃ 中 S +4 处于中间价态、兼具氧化性和还原性，既可被氧化为 +6，又可被还原为 0 或 −2。④ '有单质就是 redox'的兄弟谬误是'无单质就一定不是'——错，CaCO₃ 分解无单质却也不是 redox，而 2H₂O₂ 分解有 O₂ 却是 redox，二者互不决定。"

**【典型易错辨析对照表】**（课堂投影，逐行对照）：

| 迷思说法 | 正确判断 | 反例/正解 |
|---|---|---|
| 有单质参与或生成的反应一定是氧化还原 | 错 | 3O₂=2O₃（同素异形体转化，无变价） |
| 无单质参与就一定不是氧化还原 | 错 | 2H₂O₂=2H₂O+O₂↑、CO+CuO→Cu+CO₂ |
| 含最高价元素的物质氧化性一定最强 | 错 | 稀 H₂SO₄（S +6）不能氧化 Cu；氧化性看浓度介质 |
| Na₂SO₃ 中 S +4，所以它是强氧化剂 | 错 | S +4 是中间价，兼具氧化性和还原性，可被氧化也可被还原 |
| 还原剂被还原、氧化剂被氧化 | 错 | 还原剂被**氧化**，氧化剂被**还原** |
| 双线桥箭头从还原剂指向氧化剂 | 错 | 双线桥按**同种元素**自身升降连，电子流向看单线桥 |
| 电子数 = 价态变化数 | 错 | 电子数 = 价态变化数 × **变价原子个数** |
| 归中是任意两价态相遇都行 | 错 | 须"只靠拢不交叉"，产物价态在二者之间 |
| NO₂ 歧化反应是归中 | 错 | 3NO₂+H₂O 中反应物只有 +4 一种价态，属**歧化** |
| 氧化数就是真实电荷 | 错 | 氧化数是人为规定的**形式电荷**，可为零/分数 |
| 自身氧化还原=歧化 | 错 | 自身氧化还原还含"归中型"（如 NH₄NO₃ 分解：N −3 与 +5 归中到 +1），并非都歧化 |

### 环节四：规律上——价态规律、强弱五法、先后规律

**教师**："建一条**价态数轴**，以 S 为例：−2（S²⁻）/ 0（S）/ +4（SO₂）/ +6（SO₄²⁻）。规律——最低价（−2）只有升价空间，**只具还原性**；最高价（+6）只有降价空间，**只具氧化性**；中间价（0、+4）升降皆可，**兼具氧化性和还原性**。Na、Mg 等金属只有 0 价和正价，所以金属单质只具还原性。但再次强调：最高价只具氧化性，是说它'有能力'被还原，不代表它'很强'——浓硫酸（S +6）能氧化 Cu，稀硫酸（同为 S +6）却不能，只表现酸性；浓 HNO₃ 与稀 HNO₃ 同为 N +5，还原产物却分别为 NO₂ 与 NO，取决于浓度。"

**教师**："价态规律还要叠加'浓度与介质'才完整，记三个典型：
- ① **浓度效应**：浓 HNO₃ 还原产物多为 NO₂（+5→+4），稀 HNO₃ 多为 NO（+5→+2）；浓 HCl 与 MnO₂ 加热才反应生成 Cl₂，稀盐酸则不能。说明同一高价态物质在不同浓度下'夺取电子的彻底程度'不同，强弱随条件而变。
- ② **介质效应（酸碱性）**：KMnO₄ 在**酸性**中还原为 Mn²⁺（+7→+2，氧化性极强），在**中性/弱碱**中还原为 MnO₂（+7→+4），在**强碱**中还原为 MnO₄²⁻（+7→+6，氧化性减弱）。同一氧化剂，介质不同产物价态不同。
- ③ **温度/催化**：许多反应需加热或催化才进行，条件越温和通常氧化剂/还原剂越强。综上：**价态规律给'能不能'，强弱五法给'谁更强'，浓度/介质/条件给'实际表现'，三者要合起来看**。"

**教师**："比较氧化性强弱有**五法**，每条都配两个例子：
- ① **反应方向（强制弱）**：同一反应中，氧化剂氧化性 > 氧化产物，还原剂还原性 > 还原产物。由 2FeCl₃ + Cu = 2FeCl₂ + CuCl₂ 得氧化性 Fe³⁺ > Cu²⁺、还原性 Cu > Fe²⁺；由 Cl₂ + 2KBr = 2KCl + Br₂ 得氧化性 Cl₂ > Br₂。
- ② **产物价态法**：同种氧化剂与不同还原剂反应，被还原到越低价态，说明该氧化剂氧化性越强（夺取电子越彻底）。浓 HNO₃ 遇 Cu 主要还原为 NO₂（+5→+4），稀 HNO₃ 还原为 NO（+5→+2），须结合浓度综合判断强弱表现。
- ③ **金属/非金属置换**：金属还原性 K…Ca…Na…Mg…Al…Zn…Fe…Cu…Ag 递减；非金属氧化性 F₂>Cl₂>Br₂>I₂，对应阴离子还原性 I⁻>Br⁻>Cl⁻>F⁻。由 Cl₂ + 2KBr = 2KCl + Br₂ 知 Cl₂ > Br₂；由 Br₂ + 2KI = 2KBr + I₂ 知 Br₂ > I₂。
- ④ **电化学法**：原电池中负极金属还原性强于正极（Zn−Cu 原电池中 Zn 还原性强）；电解池中阳极先放电的阴离子还原性强、阴极先放电的阳离子氧化性强。
- ⑤ **元素周期律与金属活动性**：同周期从左向右非金属氧化性增强、金属还原性减弱；同主族从上到下金属还原性增强、非金属氧化性减弱（如氧化性 Cl₂ > Br₂ > I₂，还原性 I⁻ > Br⁻ > Cl⁻）。"

**【五法实战：用多种证据排出 Cl₂/Br₂/I₂ 与 Fe³⁺/Fe²⁺ 的强弱顺序】**
- 用 ③ 非金属置换：Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂，Br₂ + 2I⁻ → 2Br⁻ + I₂ ⇒ 氧化性 Cl₂ > Br₂ > I₂；对应还原性 I⁻ > Br⁻ > Cl⁻。
- 用 ① 反应方向：2Fe³⁺ + 2I⁻ → 2Fe²⁺ + I₂ ⇒ 氧化性 Fe³⁺ > I₂；又已知 I₂ > Fe²⁺（Fe²⁺ 不被 I₂ 氧化），故氧化性 Fe³⁺ > I₂ > Fe²⁺。
- 综合两链：氧化性 Cl₂ > Br₂ > Fe³⁺ > I₂ > Fe²⁺（其中 Fe³⁺ 介于 Br₂ 与 I₂ 之间，常用结论 Br₂ > Fe³⁺ > I₂）。
- 验证 ④ 电化学：Fe−Cu 原电池中 Fe 为负极被氧化，Cu 为正极，说明还原性 Fe > Cu；若把 Cu 换成 Fe³⁺ 体系，则 Fe 把 Fe³⁺ 还原，印证 Fe（单质）还原性强于 Fe²⁺。
- 验证 ② 产物价态：Cl₂ 氧化 Br⁻ 只生成 Br₂（0 价），而把 Fe²⁺ 氧化为 Fe³⁺（+3 高价态），说明 Cl₂ 夺取电子能力足够强，与顺序一致。

**学生（预期，典型误判）**："既然 Fe³⁺ 能氧化 I⁻，那它应该比 I₂ 强很多，是不是也比 Br₂ 强？"

**教师（追问/理答）**："Fe³⁺ > I₂ 没错，但不能跳过 Br₂。判断要看'谁氧化了谁'：Fe³⁺ 氧化的是 I⁻（对应产物 I₂），它并没有氧化 Br⁻ 的能力（Br⁻ 比 I⁻ 难失电子），所以顺序上 Fe³⁺ 排在 Br₂ 之后、I₂ 之前。记住：'A 能氧化 B'只能推出 A > (B 的氧化产物)，不能直接跟所有物质比大小，要一条链一条链拼。"

**教师**："为什么花大力气学强弱比较？因为它能**预测反应能否发生、预测产物价态、解释金属腐蚀与防护**。例如：已知 Fe³⁺ > Cu²⁺，则 FeCl₃ 能腐蚀铜电路板（2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺）；已知 活泼金属还原性顺序，则 Fe 能从 Cu²⁺ 溶液置换 Cu，反过来不能。强弱顺序就是一张'反应可能性地图'，高考里配平、电极反应、流程推断都靠它。"

**教师**："混合体系里，一种还原剂遇多种氧化剂，先和**氧化性最强**的那个反应——**强者优先**。情境一：向含 Fe³⁺、Cu²⁺、H⁺ 的混合液中加 Fe 粉。Fe 自己还原性很强，按氧化性顺序 Fe³⁺ > Cu²⁺ > H⁺ > Fe²⁺，它会先还原最强的 Fe³⁺：2Fe³⁺ + Fe = 3Fe²⁺；Fe³⁺ 耗尽后再还原 Cu²⁺：Cu²⁺ + Fe = Fe²⁺ + Cu；最后若 Fe 仍有剩余才与 H⁺ 反应。氧化性顺序 I₂ < Fe³⁺ < Cl₂ 也常考：Fe³⁺ 能氧化 I⁻ 生成 I₂（2Fe³⁺ + 2I⁻ = 2Fe²⁺ + I₂），但不能氧化 Cl⁻；Cl₂ 则既能氧化 Fe²⁺ 又能氧化 I⁻。"

**教师**："情境二（与 I⁻/S²⁻ 竞争）：若同一混合液含 Fe³⁺、I⁻、S²⁻，加入还原剂（如 Fe 粉）时，Fe 先还原氧化性更强的 Fe³⁺，待 Fe³⁺ 耗尽才轮到 I⁻、S²⁻。反过来，若加入氧化剂 Cl₂，则 Cl₂ 先氧化还原性更强的 S²⁻（S²⁻ > I⁻ > Fe²⁺ > Cl⁻），S²⁻ 耗尽再氧化 I⁻，最后才氧化 Fe²⁺。这就是'强者优先'的对称应用：强者（无论氧化剂还是还原剂）先被消耗。"

**学生（预期，易乱序）**："先和 H⁺ 反应冒氢气？还是先和 Cu²⁺ 置换出铜？"

**教师（追问/理答）**："按'氧化性：Fe³⁺ > Cu²⁺ > H⁺ > Fe²⁺'，Fe 先还原最强的 Fe³⁺，再 Cu²⁺，最后才轮到 H⁺。'强者优先'就是个排队模型：强氧化剂先被消耗，弱的后排，它与电子守恒是同一件事的两面。我们来定量算一笔：设混合液中 n(Fe³⁺)=0.10 mol、n(Cu²⁺)=0.10 mol、n(H⁺)=0.20 mol，加入 0.18 mol Fe 粉。按强者优先逐步消耗：第一步 2Fe³⁺+Fe→3Fe²⁺，耗 Fe 0.05 mol，Fe³⁺ 全转化，生成 Fe²⁺ 0.15 mol；第二步 Cu²⁺+Fe→Fe²⁺+Cu，耗 Fe 0.10 mol，Cu²⁺ 全转化，生成 Fe²⁺ 0.10 mol 与 Cu 0.10 mol；前两步累计耗 Fe 0.15 mol，剩 0.03 mol Fe，进入第三步 Fe+2H⁺→Fe²⁺+H₂↑，耗 H⁺ 0.06 mol（0.20 mol 中仅用 0.06），生 Fe²⁺ 0.03 mol，Fe 耗尽。最终：剩余固体只有 Cu 0.10 mol（不含 Fe，不能被磁铁吸引）；溶液中阳离子为 Fe²⁺ 共 0.15+0.10+0.03=0.28 mol，以及未反应完的 H⁺ 0.14 mol；无 Fe³⁺、Cu²⁺。这就是严格排队后的结果。"

> **教学提示**：上述定量推演是"先后规律"的高频错题。关键动作是"先排顺序、再逐步消耗、最后看剩余"，切勿凭直觉先算 H⁺。教师应在板书上分步列消耗表：Fe 先与 Fe³⁺（耗 0.05 mol）、再与 Cu²⁺（耗 0.10 mol）、最后才与 H⁺（剩 0.03 mol Fe 耗 H⁺ 0.06 mol）。易错点是误以为 Fe 先和 H⁺ 冒氢气，或算错剩余固体——本题 Fe 粉恰好耗尽，固体仅余 Cu，不能被磁铁吸引，溶液中 Fe²⁺ 与 H⁺ 共存。

### 环节五：规律下——归中与歧化（只靠拢不交叉）+ 价态数轴 + 边界案例

**教师**："不同价态的同种元素相遇，会**归中**到中间价态，但必须遵守——**只靠拢不交叉**。文字数轴（S 价态）：−2 ─── 0 ─── +4 ─── +6；S²⁻(−2) 箭头向右到 0，SO₃²⁻(+4) 箭头向左到 0，**两箭头在 0 汇合，不越过对方**。能不能一个升到 +4、一个降到 −2？那是'交叉'，不可能，因为那样没有净的电子优势。再如 SO₂(+4) + 2H₂S(−2) = 3S(0) + 2H₂O；浓 H₂SO₄（S +6）与 H₂S（S −2）反应生成 S(0) 与 SO₂(+4)，−2 升到 0、+6 降到 +4，两线在 0 与 +4 之间靠拢而不交叉。画价态数轴时，反应物价态在两端，产物价态必落在二者'之间'且互不越过。"

**教师**："**歧化**则相反——同一物质中同一元素既升又降，自身既是氧化剂又是还原剂。文字数轴（Cl 价态）：0 居中，左 −1、右 +1；Cl₂(0) 一部分向左到 −1（NaCl）、一部分向右到 +1（NaClO）。实例：Cl₂ + H₂O = HCl + HClO；Cl₂ + 2NaOH = NaCl + NaClO + H₂O；S 与热 KOH：3S + 6KOH = 2K₂S + K₂SO₃ + 3H₂O；白磷 P₄ + 3KOH + 3H₂O = PH₃ + 3KH₂PO₂。歧化判据：同一物质中同一元素既升又降。现在考你们一个边界：3NO₂ + H₂O = 2HNO₃ + NO，它是归中还是歧化？"

**学生（预期，典型误判）**："NO₂ 里 N 都是 +4，看起来像两种价态凑一起……是归中？"

**教师（追问/理答）**："错——归中要求'不同价态的同种元素'做反应物，而这里反应物只有一种价态（+4）。同一物质、同一价态、同种元素既升（+5）又降（+2），这正是**歧化**。结论：NO₂ 歧化而非归中。判断口诀——'不同价相遇=归中，同种价自裂=歧化'。遇到同素异形体转化 3O₂=2O₃ 这种'有单质但无变价'的，连氧化还原都不是，更谈不上归中或歧化。"

**教师**："回到开头的 84+洁厕灵——它的真实离子方程式是 ClO⁻ + Cl⁻ + 2H⁺ → Cl₂ + H₂O。注意 Cl 的价态：ClO⁻ 中 Cl 为 +1，Cl⁻ 中 Cl 为 −1，产物 Cl₂ 为 0。+1 与 −1 两种不同价态的同种元素相遇、都向 0 靠拢——这恰恰是**归中**！所以'毒气'的本质是归中反应生成了氯气。一个开头、一个结尾，我们用两种视角（氧化还原判据 + 归中规律）把它彻底拆穿了。"

**【易混概念一句话区分】**：
- 氧化剂/还原剂是**反应物**角色；氧化产物/还原产物是**生成物**角色，别把"剂"和"产物"混谈。
- "被氧化"的是还原剂（升失氧），"被还原"的是氧化剂（降得还）——"剂"与"过程"反着记。
- 中间价物质"兼性"指同一物质在不同反应中可氧化可还原，不是同一反应里同时既氧化又还原（那叫歧化，且须同一元素既升又降）。
- 归中（不同价→中间价）与歧化（同价→两价）是互为镜像的两种过程。
- 自身氧化还原反应包含两类：① 歧化（同一物质中同一元素既升又降，如 Cl₂+NaOH、S+KOH）；② 归中型自身氧化还原（同一物质内不同价态的同种元素靠拢，如 NH₄NO₃ 分解、KClO₃ 热分解 4KClO₃=3KClO₄+KCl）。二者都"无外部氧化剂/还原剂"，但歧化是"一种价态自裂"、归中是"两种价态靠拢"，不可混为一谈。

**【价态数轴作图指南】**（以氮为例，归中/歧化都先在脑中画轴）：
- N 价态数轴：−3（NH₃）── 0（N₂）── +1（N₂O）── +2（NO）── +4（NO₂）── +5（HNO₃）。
- 归中示例：NH₄NO₃(加热) → N₂O + 2H₂O。NH₄⁺ 中 N(−3) 与 NO₃⁻ 中 N(+5) 向中间价 +1（N₂O）靠拢，在 +1 汇合，不交叉；产物 N₂O 价态 +1 落在 −3 与 +5 之间。
- 歧化示例：3NO₂(+4) + H₂O → 2HNO₃(+5) + NO(+2)。同一 +4 既升到 +5 又降到 +2，自裂；若误画成"−3 与 +5 归中"就错在把反应物当成两种价态。
- 作图铁律：横坐标写价态、纵坐标无；反应物在两端、产物必在"区间内部且互不越过"；若两产物箭头交叉，必错。

**【归中与歧化实例速查表】**：

| 类型 | 反应 | 关键元素价态变化 | 判据 |
|---|---|---|---|
| 归中 | S²⁻ + SO₃²⁻ → S | −2 与 +4 → 0 | 不同价相遇、只靠拢不交叉 |
| 归中 | SO₂(+4) + 2H₂S(−2) → 3S(0) | +4 与 −2 → 0 | 产物 0 在区间内 |
| 归中 | 浓 H₂SO₄(+6) + H₂S(−2) → S(0)+SO₂(+4) | +6 与 −2 → 0 与 +4 | 两产物均在 [−2,+6] 内 |
| 归中 | NH₄NO₃(加热) → N₂O + 2H₂O | −3 与 +5 → +1 | 归中到中间价 +1 |
| 歧化 | Cl₂ + H₂O → HCl + HClO | 0 → −1 与 +1 | 同种价自裂 |
| 歧化 | Cl₂ + 2NaOH → NaCl + NaClO | 0 → −1 与 +1 | 同种价自裂 |
| 歧化 | 3NO₂ + H₂O → 2HNO₃ + NO | +4 → +5 与 +2 | 同种价自裂（非归中） |
| 歧化 | 3S + 6KOH → 2K₂S + K₂SO₃ | 0 → −2 与 +4 | 同种价自裂 |
| 歧化 | P₄ + 3KOH + 3H₂O → PH₃ + 3KH₂PO₂ | 0 → −3 与 +1 | 白磷歧化 |

**【价态数轴手绘三步】**（让学生上台画，强化可视化）：
- 第一步**标端点**：把涉及的所有价态从小到大排在一条横线上，如 S：−2 / 0 / +4 / +6。
- 第二步**画箭头**：反应物价态为起点，产物价态为终点；归中时两箭头相向、在中间价汇合且不越过；歧化时从同一中心价向两侧分开。
- 第三步**验不交叉**：若画出来两箭头交叉（如一个升过对方、一个降过对方），立即判错重画——"只靠拢不交叉"是硬约束。

**【课堂即时反馈 + 随堂诊断（教师巡批）】**：
- 题 A（歧化）：判断 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ 与 2H₂O₂ = 2H₂O + O₂↑ 中 Na₂O₂ / H₂O₂ 的角色与 O 价态变化。
  - 答：均属**歧化**；O 从 −1 一部分升到 0（O₂）、一部分降到 −2（OH⁻/H₂O），二者既是氧化剂又是还原剂。
- 题 B（归中）：用"只靠拢不交叉"判断 H₂S(−2) 与 H₂SO₄(+6) 能否归中、产物价态区间？
  - 答：能归中；产物价态须落在 [−2,+6] 内且不交叉，典型为 S(0) 与 SO₂(+4)。
- 诊断（强者优先边界）：向 FeBr₂ 溶液通入少量 Cl₂，先氧化 Fe²⁺ 还是 Br⁻？
  - 答：先氧化 Fe²⁺；还原性 Fe²⁺ > Br⁻，Cl₂ 先氧化还原性更强者。同法，Cl₂ 与 NaOH 冷（0→−1 与 +1）、热（0→−1 与 +5）条件均属歧化，仅产物价态区间随温度改变。

### 环节六：信息型氧化还原分析与小结

**教师**："遇到陌生反应，就用四步法：标价态 → 找升降 → 定角色 → 查守恒。例一（黑火药）：2KNO₃ + 3C + S = K₂S + N₂↑ + 3CO₂↑。标：N +5→0（降）、S 0→−2（降）、C 0→+4（升）。故氧化剂 KNO₃ 与 S，还原剂 C，氧化产物 CO₂ 与 N₂，还原产物 K₂S。例二（碘量法）：2Na₂S₂O₃ + I₂ = Na₂S₄O₆ + 2NaI。I 0→−1（降），I₂ 氧化剂、NaI 还原产物；S 平均 +2→+2.5（升），Na₂S₂O₃ 还原剂、Na₂S₄O₆ 氧化产物。例三（铜与稀硝酸）：3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。Cu 0→+2（升），N +5→+2（降），氧化剂 HNO₃（仅部分被还原）、还原剂 Cu。这类题就是考你'标—找—定—查'熟不熟。"

**【信息型氧化还原"四步法"通用模板】**（任何陌生反应都套用）：
- 第一步**标价态**：给反应前后各变价元素写出氧化数。
- 第二步**找升降**：锁定哪些元素价态升高（失电子）、哪些降低（得电子）。
- 第三步**定角色**：升高者所在反应物是还原剂、对应生成物是氧化产物；降低者所在反应物是氧化剂、对应生成物是还原产物。
- 第四步**查守恒**：失电子总数 = 得电子总数；若给出方程式，顺带检查原子与电荷守恒。
- 示范（铝热反应）：2Al + Fe₂O₃ → 2Fe + Al₂O₃。Al 0→+3（升，还原剂，Al₂O₃ 氧化产物）；Fe +3→0（降，氧化剂 Fe₂O₃，Fe 还原产物）。一举四得。

**教师**："本节课主线：根本判据（化合价变）→ 氧化数记账 → 双线桥/单线桥表征 → 中间价兼性 → 价态规律+强弱五法+先后规律 → 归中（只靠拢不交叉）/歧化（同种价自裂）。课后用题5、题6 把工具练熟，选做与挑战把难度提上去。一句话收尾：氧化还原不是'看有没有氧'，而是'看电子怎么走'。"

## 七、板书设计

```
═══════════ Part 1 本课逻辑主线（主板书） ════════════
逻辑：判据(化合价变) → 本质(电子转移) → 概念系统 → 规律

· 根本判据 = 化合价(氧化数)是否变化；本质 = 电子得失/偏移；化合价/氧化数 = 记账语言
· 三级台阶：得氧失氧(局限) → 化合价升降(普适) → 电子转移(本质)

· 升失氧(被氧化、作还原剂)；降得还(被还原、作氧化剂)
       —— 针对「元素/物质」，非整个反应
       记忆：还原剂被氧化(升失氧)，氧化剂被还原(降得还)

· 氧化数规则：单质0 / 化合物代数和0 / 单原子离子=电荷
              / H通常+1(金属氢化物 NaH 中−1)
              / O通常−2(过氧化物 Na₂O₂ 中−1；OF₂ 中+2) / 金属正价
   算例：Fe₃O₄ 中 Fe 平均 +8/3（实为 Fe²⁺Fe₂³⁺O₄ 混合价）
         Na₂S₂O₃ 中 S 平均 +2（一个 S 视作 +6、一个 −2）
         H₂C₂O₄ 中 C 平均 +3；CH₃CH₂OH 中 C 平均 −2；K₂Cr₂O₇ 中 Cr +6

· 双线桥：标变价→连双线(同元素)→注得失(得/失·e⁻数·氧化/还原)→电子守恒
  单线桥：一条线，还原剂→氧化剂，只标电子总数
  电子数 = 价态变化数 × 变价原子个数（注意部分变价：MnO₂+4HCl、Cl₂+NaOH 歧化）
· 中间价兼性：Cl₂、S、H₂O₂、Fe²⁺、SO₂、NO（遇强氧化剂作还原剂、遇强还原剂作氧化剂）
· 常见剂清单（氧化剂 KMnO₄/浓H₂SO₄/HNO₃/Cl₂/Br₂/FeCl₃/H₂O₂；
               还原剂 Na/Fe/C/CO/H₂/Fe²⁺/S²⁻/I⁻/SO₃²⁻）
· 四大类型与 redox 韦恩：置换必是 / 复分解必非 / 化合分解不一定
· 误区：有单质≠redox（3O₂=2O₃ 同素异形体转化无价变；石墨→金刚石）；
        高价态≠强氧化性（如 Na₂SO₄ 中 S+6 稳定氧化性弱）；
        「中间价态兼具氧化性和还原性」（勿说"两性"）
· 价态规律：最高价只氧化(只作氧化剂) / 最低价只还原 / 中间价兼具(受浓度·介质调节)
· 强弱五法：①反应方向强制弱 ②产物价态 ③金属/非金属置换 ④电化学 ⑤周期律·金属活动性
· 先后：强者优先（氧化性 Fe³⁺>Cu²⁺>H⁺>Fe²⁺；还原性 S²⁻>I⁻>Fe²⁺>Br⁻>Cl⁻；I₂<Fe³⁺<Cl₂）；
        向混合液加 Fe 粉先与 Fe³⁺ 反应
· 归中：只靠拢不交叉（S²⁻+SO₃²⁻→S；SO₂+2H₂S→3S；浓H₂SO₄+H₂S→S+SO₂）
```

## 八、作业布置

### 必做
1. **题5**（见 [[高中化学必修一-习题精选]]）：判断 2FeCl₃ + Cu = 2FeCl₂ + CuCl₂ 中的氧化剂、还原剂、氧化产物、还原产物。
   - 解答：Fe 元素 +3→+2（降价），故 FeCl₃ 是氧化剂、FeCl₂ 是还原产物；Cu 元素 0→+2（升价），故 Cu 是还原剂、CuCl₂ 是氧化产物。氧化性 Fe³⁺ > Cu²⁺。
2. **题6**（见 [[高中化学必修一-习题精选]]）：用双线桥标出 MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O 的电子转移，并指认氧化剂、还原剂。
   - 解答：Mn +4→+2 得 2e⁻（MnO₂ 氧化剂）；2 个 Cl⁻(−1)→Cl₂(0) 失 2e⁻（HCl 还原剂，4 个 HCl 中仅 2 个被氧化）；总转移 2e⁻；MnCl₂ 还原产物、Cl₂ 氧化产物。

### 选做
3. 氧化数计算（5 物质，写过程）：Fe₃O₄ 中 Fe 平均氧化数；Na₂S₂O₃ 中 S 平均氧化数；H₂C₂O₄ 中 C 平均氧化数；CH₃CH₂OH 中 C 平均氧化数；K₂Cr₂O₇ 中 Cr 氧化数。
   - 提示：Fe₃O₄ → (2×4 + 3x = 0) → x=+8/3；Na₂S₂O₃ → (+2 + 3×(−2) + 2x = 0) → x=+2；H₂C₂O₄ → (+2 + 4×(−2) + 2x = 0) → x=+3；CH₃CH₂OH（C₂H₆O）→ (2x + 6 − 2 = 0) → x=−2；K₂Cr₂O₇ → (+2 + 7×(−2) + 2x = 0) → x=+6。
   - 分步详解：① Fe₃O₄ 视为 FeO·Fe₂O₃，含 1 个 Fe²⁺ 与 2 个 Fe³⁺，平均氧化数 (2+3+3)/3 = +8/3；② Na₂S₂O₃（硫代硫酸钠）结构等价于把 Na₂SO₄ 中一个 O 换成 S，故一个 S 为 +5、一个 S 为 −1，平均 +2；③ H₂C₂O₄ 中两个 C 等价，2x + 2 + (−8) = 0 ⇒ x = +3；④ CH₃CH₂OH 用整体代数和，2x + 6×(+1) + (−2) = 0 ⇒ x = −2（若拆开：CH₃ 上 C 连 3H 与 1C，氧化数 −3；CH₂OH 上 C 连 2H、1C、1O，氧化数 −1，平均仍是 −2）；⑤ K₂Cr₂O₇ 中 Cr₂O₇²⁻ 整体 −2，2x + 7×(−2) = −2 ⇒ x = +6。
4. 归中与歧化各举 3 例判断，并分别画出价态数轴（标反应物价态、产物价态、靠拢/自裂方向）：
   - 归中：SO₂ + 2H₂S = 3S + 2H₂O；浓 H₂SO₄ + H₂S → S + SO₂ + H₂O；KClO₃ 热分解 4KClO₃ = 3KClO₄ + KCl（注明是歧化还是归中：是歧化，Cl +5 一部分→+7、一部分→−1）。
   - 歧化：Cl₂ + H₂O = HCl + HClO；Cl₂ + 2NaOH = NaCl + NaClO + H₂O；3NO₂ + H₂O = 2HNO₃ + NO。

### 挑战（有区分度，鼓励学有余力者完成）
5. **多氧化剂竞争综合题**：向含 Fe³⁺、Cu²⁺、H⁺、Fe²⁺ 的混合溶液中逐步加入还原剂 Fe 粉（设 n(Fe³⁺)=0.10 mol、n(Cu²⁺)=0.10 mol、n(H⁺)=0.20 mol，加入 0.18 mol Fe 粉），充分反应后：
   - 写出反应发生的先后顺序（用离子方程式）；
   - 计算各步消耗 Fe 的物质的量；
   - 判断剩余固体能否被磁铁吸引，并写出最终溶液中存在的阳离子及其物质的量。
   - 解答要点：顺序 2Fe³⁺+Fe→3Fe²⁺（耗 0.05 mol）→ Cu²⁺+Fe→Fe²⁺+Cu（耗 0.10 mol）→ Fe+2H⁺→Fe²⁺+H₂↑（剩 0.03 mol Fe 耗 0.06 mol H⁺）。Fe 共耗 0.15 mol，余 0.03 mol 与 H⁺ 反应后耗尽。最终固体仅 Cu 0.10 mol（不能被磁铁吸引）；溶液阳离子 Fe²⁺ = 0.15+0.10+0.03 = 0.28 mol、H⁺ 余 0.14 mol；无 Fe³⁺、Cu²⁺。
6. **信息型氧化还原分析 2 道**（给陌生反应式，写双线桥 + 指认氧化剂/还原剂/氧化产物/还原产物四类）：
   - 2KNO₃ + 3C + S = K₂S + N₂↑ + 3CO₂↑（黑火药）：氧化剂 KNO₃、S；还原剂 C；氧化产物 CO₂、N₂；还原产物 K₂S。
   - 2Na₂S₂O₃ + I₂ = Na₂S₄O₆ + 2NaI（碘量法）：I 0→−1（降价），I₂ 氧化剂、NaI 还原产物；S 平均 +2→+2.5（升价），Na₂S₂O₃ 还原剂、Na₂S₄O₆ 氧化产物。
7. **复杂归中产物推断**：已知硫的价态数轴 −2 / 0 / +4 / +6，将 H₂S（S −2）、S（0）、H₂SO₃（S +4）、H₂SO₄（S +6）四者两两混合，用"只靠拢不交叉"判断哪些组合能发生归中、产物价态落在何处，并指出哪些组合因"价态已相邻/无净电子优势"而不反应。
   - 解答要点：相邻价态（−2 与 0、0 与 +4、+4 与 +6）之间无中间空档，理论上归中产物即落在二者之间但不交叉；−2 与 +4 归中到 0（H₂S+H₂SO₃→S）；−2 与 +6 归中可到 0 与 +4（H₂S+H₂SO₄→S+SO₂）；0 与 +6 归中到 +4（S+H₂SO₄→SO₂）；同价态混合（如 −2 与 −2）不反应。
   - 完整示范（−2 与 +6 组合）：H₂S 中 S −2，H₂SO₄ 中 S +6。画数轴 −2 ─── 0 ─── +4 ─── +6；−2 向右升、+6 向左降，二者在 0 与 +4 之间靠拢而不越过（−2 升到 0 生成 S，+6 降到 +4 生成 SO₂）。若误写成 H₂S 降到 −2、H₂SO₄ 升到 +6（交叉），则无净电子优势，舍去。故反应为 H₂S + H₂SO₄(浓) → S + SO₂ + H₂O（配平后系数 1:1:1:1，另补 H₂O 平衡氢氧）。
