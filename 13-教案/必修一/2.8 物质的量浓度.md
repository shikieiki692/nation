# 教案：2.8 物质的量浓度（必修第一册 第二章 海水中的重要元素——钠和氯）

> **课时元信息**：第 2 章 / 2.8 物质的量浓度 / 第 8 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[物质的量与气体计算]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：定量桥梁课——把"质量分数"升级为"物质的量浓度"，建立 n 与溶液体积之间的桥梁，是第一章离子反应（离子浓度）与后续滴定、水溶液离子平衡的接口。本节围绕 c = n / V 定义、离子浓度规律、与质量分数换算、稀释定律、m↔n↔N↔V(气)↔c 关系网展开，重点破除"V 是溶剂体积""离子浓度漏乘个数""配制时加 100 mL 水"三大典型误解。

**本课内容主线概览**

| 环节 | 核心知识 | 关键认知突破 |
|---|---|---|
| 定义 | c = n/V，单位 mol/L | V 是溶液体积，非溶剂体积、非加水体积 |
| 离子浓度 | c(离子)=c(溶质)×离子个数 | 下角标即乘数，Al₂(SO₄)₃ → c(Al³⁺)=0.2、c(SO₄²⁻)=0.3 |
| 换算 | c = 1000ρω/M | 取 1 L 为基准，ρ 用 g/mL、ω 用小数 |
| 稀释 | c₁V₁ = c₂V₂ | 本质：稀释前后溶质 n 守恒 |
| 关系网 | m↔n↔N↔V(气)↔c | n 为枢纽，c 是 n 与溶液体积的接口 |
| 深度 | 混合离子浓度综合、过量计算雏形、公式推导 | 离子累加、c×V=n 判断限量 |

## 一、课标对应

- **内容要求**：认识物质的量浓度，能运用物质的量、摩尔质量、气体摩尔体积、物质的量浓度之间的相互关系进行简单计算；初步学会配制一定物质的量浓度的溶液（容量瓶使用方法）。
- **学业质量水平**：必修水平 2——能从定量的角度认识溶液的组成，能进行物质的量浓度与质量分数、溶液稀释之间的换算，能根据离子组成计算溶液中离子浓度，能解释配制过程中"定容至刻度"的含义。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从"溶液质量分数"的宏观比例，过渡到"单位体积溶液中含多少溶质粒子"的微观粒子计数，建立 c 的宏—微桥梁）；
  2. **变化观念与平衡思想**（认识溶液组成可用多种浓度表示，浓度换算反映同一组成的多种表征，稀释是溶质物质的量守恒下的体积变化）；
  3. **证据推理与模型认知**（建立"以 n 为枢纽"的计量关系网 m↔n↔N↔V(气)↔c，用模型统一分散的计算）；
  4. **科学探究与创新意识**（通过容量瓶配制实验，体会"定容至刻度"如何保证 V 为溶液体积，设计探究验证浓度）；
  5. **科学态度与社会责任**（联系医院输液、环境监测、药剂配制等真实情境，认识浓度精确计算的现实价值）。

## 二、学情分析（本课时）

**【课前诊断·3 处典型误解预判】**

学生在初三已掌握"质量分数"，会用 m(溶质)/m(溶液) 表示浓度，也初步接触过"体积"概念，但进入物质的量浓度时存在三处典型误解：一是把公式 c = n / V 中的 V 误当成"溶剂体积"，以为"加多少水"就是 V；二是求离子浓度时只写出溶质的 c，漏乘化学式中"该离子的个数"（如把 0.1 mol/L Al₂(SO₄)₃ 的 c(SO₄²⁻) 直接写成 0.1 mol/L）；三是配制时把"加水至 100 mL（定容到刻度）"错误理解为"加 100 mL 水"。本课新难点：c = 1000ρω / M 的单位换算（1000 的来历、ρ 用 g/mL）、稀释定律的守恒本质、以及关系网中 c 作为"n 与溶液体积"接口的定位。对策：用 5.85 g NaCl 两种操作的对比制造认知冲突，落实"V 是溶液体积"；用 Al₂(SO₄)₃ 的离子个数乘积做机械化训练；用"取 1 L 溶液"的基准法推导换算公式，把稀释统一到"溶质 n 不变"。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"质量分数 → 物质的量浓度"的表征转换，培养**宏观辨识与微观探析**素养：从"每 100 g 溶液含多少克溶质"转译为"每 1 L 溶液含多少摩尔粒子"，建立浓度概念的宏—微桥梁。
- 通过建构以 n 为枢纽的 m↔n↔N↔V(气)↔c 关系网，培养**证据推理与模型认知**素养：用统一模型整合分散的计算，体会"计量即找枢纽"的方法。
- 通过分析稀释前后溶质 n 守恒、配制时定容至刻度保证 V 为溶液体积，培养**变化观念与平衡思想**素养：认识浓度变化是"量守恒下的体积重组"。
- 通过容量瓶"定容"操作的探究与误差分析，培养**科学探究与创新意识**素养：从实验需求理解仪器设计，敢于质疑"加 100 mL 水"的直觉。
- 通过医院输液、环境监测中浓度精确性的真实案例，培养**科学态度与社会责任**素养：认识定量化学对生命与环境的现实价值。

### 3.2 学习目标（学生能……，可观测）

- 能**准确表述**物质的量浓度的定义 c = n/V，说出单位 mol/L，并明确"V 是溶液体积而非溶剂体积"，能指出"加水至 100 mL"与"加 100 mL 水"的本质差异。
- 能**计算**指定溶液中某离子的浓度：运用 c(离子) = c(溶质) × 化学式中该离子个数，对 Al₂(SO₄)₃、Na₂SO₄、CuSO₄ 等给出正确离子浓度（如 0.1 mol/L Al₂(SO₄)₃ → c(Al³⁺)=0.2 mol/L、c(SO₄²⁻)=0.3 mol/L）。
- 能**推导并应用** c = 1000ρω/M 进行质量分数与物质的量浓度的换算，说清 ρ（g/mL）、ω（小数）、M（g/mol）、1000（mL→L）各量的意义。
- 能**运用**稀释定律 c₁V₁ = c₂V₂ 解决浓溶液稀释问题，并解释其守恒本质为"稀释前后溶质 n 不变"。
- 能**绘制并调用** m↔n↔N↔V(气)↔c 关系网，以 n 为枢纽在质量、粒子数、气体体积、溶液浓度间转换；初步处理两溶液混合后离子浓度综合与结合化学方程式的过量计算雏形。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 五、教学媒体与素材

- 文字引用库内图：物质的量浓度定义、配制一定物质的量浓度溶液流程、m↔n↔N↔V(气)↔c 关系网（见 [[物质的量与气体计算]]，正文仅作文字引用，不实际嵌入物理图片；导出 Word 时随包引用）。
- 实验器材（演示/学生分组）：容量瓶（100 mL 或 250 mL）、烧杯、玻璃棒、胶头滴管、电子天平、称量纸、NaCl 固体、蒸馏水。
- 情境素材：医院输液标签（葡萄糖注射液 5%、氯化钠注射液 0.9%）、环境监测 SO₂ 浓度报告、汽车安全气囊 NaN₃ 分解（PV=nRT 关联，点到即止）。
- 学案：① 定义与单位填空；② 离子浓度"下角标即乘数"训练单；③ 质量分数↔浓度换算推导纸；④ 稀释与混合后离子浓度综合题单；⑤ 过量计算雏形题单。
- 实验安全与规范警示：
  - 容量瓶是"量器"非"反应器"，不可用于溶解固体或长期贮存溶液（尤其碱液会腐蚀玻璃塞）；
  - 溶解放热物质（如 NaOH、浓 H₂SO₄ 稀释）必须在烧杯中冷却至室温后再转入容量瓶，否则热胀使定容 V 偏小、c 偏高；
  - NaOH 腐蚀性强的固体须用烧杯/表面皿快速称取，不可直接放称量纸；
  - 定容用胶头滴管逐滴加入，视线与凹液面最低处相切，仰视/俯视均引入系统误差（见配制误差分析表）；
  - 浓 H₂SO₄ 稀释须"酸入水、慢搅拌"，严禁水入酸，防止暴沸飞溅。

> 说明：本节为定量桥梁课，重在"破除误解 + 建立关系网"，实验操作以演示为主、分组练习为辅，时间块以"V 是溶液体积"与"离子浓度×个数"两处难点充分展开为优先。

**导入**

**教师**："同学们看这张输液标签——'氯化钠注射液 0.9%'。初三我们管这叫质量分数。但医生开医嘱时有时会写'0.154 mol/L 氯化钠'。0.9% 和 0.154 mol/L，说的是同一瓶盐水吗？"

**学生（预期）**："应该是同一瓶吧，只是写法不同？"

**教师（追问/理答）**："对，是同一瓶，但两种'语言'。质量分数说的是'每 100 g 溶液里有多少克 NaCl'；物质的量浓度说的是'每 1 L 溶液里有多少摩尔 NaCl'。今天我们就把初三的'质量分数语言'翻译成高中更趁手的'物质的量浓度语言'——它的核心只有一个式子：c = n/V。"

**探究 1（定义与 V 是溶液体积，，逐字稿①）**

**教师**："先动手配一瓶：取 5.85 g NaCl，要配成 100 mL、1 mol/L 的溶液。两种说法——A：'加水至 100 mL'；B：'加 100 mL 水'。哪个对？"

**学生（预期，典型错误）**："B 吧，加 100 mL 水，体积不就是 100 mL 了嘛。"

**教师（追问/理答）**："这是今天第一坑。5.85 g NaCl 本身有体积，它占掉一部分空间。如果你'加 100 mL 水'，最后溶液总体积会是'NaCl 体积 + 100 mL 水' > 100 mL，那 c = n / V 里的 V 就变大了，浓度就不到 1 mol/L。正确做法是 A——先加水溶解，再加水**至刻度线**，让'溶液体积恰好 100 mL'。记住铁律：**公式里的 V 是溶液体积，不是溶剂体积，也不是你加的水的体积**。"

**教师**："我们用容量瓶来保证这一点：称量 → 烧杯溶解 → 玻璃棒引流转移 → 洗涤 2~3 次 → 加蒸馏水至刻度线附近 → 胶头滴管逐滴加至凹液面最低处与刻度线相切 → 摇匀。定容的'至刻度'，正是强制 V 成为溶液体积。摇匀后液面微降是正常现象，不要补加水——补加会让 V 变大、c 偏低。"

**宏—微—符三重表征（围绕 c = n / V，落实"宏观辨识与微观探析"）**

| 表征维度 | 物质的量浓度 c 的内涵 | 示例（1 mol/L NaCl，V=1 L） |
|---|---|---|
| 宏观 | 每单位体积溶液中所含溶质的质量/quantity 比例（从质量分数升级为"以物质的量计"的定量组成） | 1 L 溶液里溶有 58.5 g NaCl |
| 微观 | 每单位体积溶液里所含的溶质粒子数（N = nNₐ，离子还要乘个数） | 1 L 溶液中含 1 mol Na⁺ 与 1 mol Cl⁻，即各约 6.02×10²³ 个 |
| 符号 | c = n/V，单位 mol/L；离子浓度 c(离子)=c(溶质)×个数 | c(NaCl)=1 mol/L ⇒ c(Na⁺)=c(Cl⁻)=1 mol/L |

> 说明：质量分数回答"每 100 g 溶液含几克溶质"（宏观质量比）；物质的量浓度回答"每 1 L 溶液含几摩尔粒子"（微观粒子计数）。二者描述同一组成，只是表征语言不同——这正是"宏—微—符"三重表征在浓度概念上的具体体现。

**配制误差分析（紧扣 c = n / V，V 是溶液体积）**

配制一定物质的量浓度溶液时，误差最终都归结为 n 或 V 的变化：c = n / V，n 偏小则 c 偏低，V 偏大则 c 偏低（反之亦然）。典型情形：

| 操作失误 | 对 n 的影响 | 对 V(溶液) 的影响 | c 偏差 |
|---|---|---|---|
| 称量 NaCl 时左码右物（用游码） | n 偏小 | — | 偏低 |
| 溶解后未冷却至室温即转移 | — | 热胀，冷却后 V 变小 | 偏高 |
| 转移时未用玻璃棒引流，少量洒出 | n 偏小 | — | 偏低 |
| 烧杯/玻璃棒未洗涤，洗涤液未转入 | n 偏小 | — | 偏低 |
| 定容仰视刻度（视线低于凹液面） | — | 实际 V 偏大 | 偏低 |
| 定容俯视刻度（视线高于凹液面） | — | 实际 V 偏小 | 偏高 |
| 摇匀后液面下降，又补加蒸馏水 | — | V 变大 | 偏低 |
| 容量瓶未检漏，定容后漏液 | n 偏小 | — | 偏低 |

> 核心判据：先问"这一步改的是 n 还是 V"，再用 c = n / V 判断方向。注意"摇匀后液面下降"是润湿瓶塞瓶颈的正常现象，若补加水就相当于错误地增大了 V（溶液体积），是典型易错点，再次印证"V 是溶液体积、由定容一次性决定"。

**探究 2（离子浓度规律，，逐字稿②）**

**教师**："配好 0.1 mol/L 的 Al₂(SO₄)₃ 溶液，问：溶液里 Al³⁺ 浓度是多少？SO₄²⁻ 浓度是多少？"

**学生（预期，典型错误）**："都是 0.1 mol/L 吧，溶液浓度就是 0.1 mol/L。"

**教师（追问/理答）**："漏乘了！1 个 Al₂(SO₄)₃ 电离出 **2 个 Al³⁺ 和 3 个 SO₄²⁻**：Al₂(SO₄)₃ → 2Al³⁺ + 3SO₄²⁻。所以离子浓度 = 溶质浓度 × 化学式中该离子的个数——c(Al³⁺) = 0.1 × 2 = 0.2 mol/L；c(SO₄²⁻) = 0.1 × 3 = 0.3 mol/L。口诀：**下角标就是乘数**。注意离子浓度与溶液取多少体积无关，只与溶质浓度和化学式有关。"

**教师**："再练：0.2 mol/L Na₂SO₄ 中 c(Na⁺) = ？c(SO₄²⁻) = ？——Na₂SO₄ → 2Na⁺ + SO₄²⁻，故 c(Na⁺)=0.4 mol/L，c(SO₄²⁻)=0.2 mol/L。再注意电荷守恒：正电荷浓度总和 = 负电荷浓度总和，这里 0.4×1 = 0.2×2，成立，可作为验算。"

**探究 3（质量分数换算与稀释）**

**教师**："怎样把质量分数 ω 直接换成 c？我们用'取 1 L 溶液'当基准来推导，避免乱套公式。1 L 溶液质量 = 1000 mL × ρ（g/mL）= 1000ρ g；其中溶质质量 = 1000ρ × ω g；溶质物质的量 n = (1000ρω) / M mol；这恰好是 1 L 溶液里的溶质物质的量，所以 c = 1000ρω/M。注意：ρ 用 g/mL，ω 是小数，M 是 g/mol，1000 是把 mL 变 L。"

**学生（预期）**："那 98% 的 H₂SO₄（ρ ≈ 1.84 g/mL）浓度多少？"

**教师（追问/理答）**："直接代：c = (1000 × 1.84 × 0.98) / 98 ≈ 18.4 mol/L。这里要先知道密度 ρ——溶质是以'物质的量'计的，质量分数只给比例，必须靠 ρ 把'质量'接上'体积'。再讲稀释：把 18.4 mol/L 的浓 H₂SO₄ 稀释到 1 mol/L，取 V₁ 则 c₁V₁ = c₂V₂，即 18.4 × V₁ = 1 × V₂。本质就一句话——**稀释前后溶质的 n 不变**，V 变大了但 n 守恒。"

**探究 4（关系网整合与 c 接口定位）**

**教师**："把第一章到本节所有计量关系串起来：m ↔ n ↔ N ↔ V(气) ↔ c，枢纽都是 n。m = nM；N = nNₐ；标准状况下 V(气) = n × 22.4 L/mol；c = n / V(溶液)。只要抓住 n，质量、粒子数、气体体积、溶液浓度就能互相转换。c 的特殊之处：它把 n 和'溶液体积'连起来——这正是第一章离子反应里'离子浓度'的量化语言，也是后续滴定、水溶液离子平衡的接口。"

**关系网互转例题（n 为枢纽的机械化训练）**

- 例 1（m → n → c）：取 11.7 g NaCl 配成 500 mL 溶液，求 c(NaCl)。
  解：n(NaCl) = 11.7 / 58.5 = 0.20 mol；c = 0.20 / 0.500 = 0.40 mol/L；c(Na⁺)=c(Cl⁻)=0.40 mol/L。
- 例 2（c → n → N）：0.50 mol/L H₂SO₄ 溶液 200 mL 中含 H₂SO₄ 分子多少个？
  解：n = 0.50 × 0.200 = 0.10 mol；N = 0.10 × 6.02×10²³ = 6.02×10²²；注意 c(H⁺)=1.0 mol/L（H₂SO₄ → 2H⁺ + SO₄²⁻，乘 2）。
- 例 3（V(气) → n → c）：标准状况下 3.36 L HCl 溶于水配成 250 mL 溶液，求 c(HCl)。
  解：n(HCl) = 3.36 / 22.4 = 0.15 mol；c = 0.15 / 0.250 = 0.60 mol/L。
  三步都只围绕 n 转：已知量先化到 n，再由目标量反推——这就是"计量即找枢纽"的方法，也是高考选择题里 NA 与浓度换算题的通法。

**深度拓展（衔接高考中档与初赛入门，点到即止）**

1. **溶液中离子浓度综合（两溶液混合后）**：混合后离子浓度 = 混合后该离子的总物质的量 ÷ 混合后总体积（体积可加和时直接相加）。关键是"离子来自多个溶质、要累加"，且若发生反应生成沉淀/气体/弱电解质，需先算反应消耗。例：将 100 mL 0.30 mol/L Al₂(SO₄)₃ 与 100 mL 0.60 mol/L Na₂SO₄ 混合，体积可加和。
   - n(Al³⁺) = 0.100 L × 0.30 × 2 = 0.060 mol；混合后 c(Al³⁺) = 0.060 / 0.200 = 0.30 mol/L。
   - n(SO₄²⁻) 来自两源：Al₂(SO₄)₃ 贡献 0.100 × 0.30 × 3 = 0.090 mol；Na₂SO₄ 贡献 0.100 × 0.60 = 0.060 mol；合计 0.150 mol；c(SO₄²⁻) = 0.150 / 0.200 = 0.75 mol/L。
   - n(Na⁺) = 0.100 × 0.60 = 0.060 mol；c(Na⁺) = 0.060 / 0.200 = 0.30 mol/L。
   验算电荷：正电荷 = c(Al³⁺)×3 + c(Na⁺)×1 = 0.90 + 0.30 = 1.20；负电荷 = c(SO₄²⁻)×2 = 1.50 —— 此处看似不等，是因为 Al³⁺ 实际会发生水解使 c(Al³⁺) 略低于 0.30，精确计算需计入水解，必修阶段点到"离子要累加、用电荷守恒验算"即可。

2. **与化学方程式结合（过量计算雏形）**：浓度 × 体积 = 物质的量，这是判断反应"谁过量"的工具。例：标准状况下 2.24 L HCl（n = 2.24/22.4 = 0.10 mol）溶于水配成 100 mL，c(HCl) = 0.10 / 0.100 = 1.0 mol/L；若加入 0.10 mol/L NaOH 150 mL，则 n(NaOH) = 0.10 × 0.150 = 0.015 mol < 0.10 mol，NaOH 不足，按 NaOH 计量生成 n(NaCl) = 0.015 mol。核心：先由 c、V 求出 n，再用化学方程式的计量数比判断限量——这是后续"关系式法""滴定计算"的雏形。

3. **c = 1000ρω/M 的推导再确认**：取 1 L（=1000 mL）溶液为基准，是化解单位混乱的关键技巧。若改用 ρ 的单位为 g/cm³（数值等于 g/mL）、V 为 mL，则"1000"正是 mL→L 的换算系数，不可省略；若有人用 ρ 单位 kg/L 则系数变为 1，故务必先统一单位再代公式。

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 反例/判据 |
|---|---|---|
| V 是溶剂体积 / 加多少水 | V 是溶液体积（定容至刻度） | 加 100 mL 水 ≠ 加水至 100 mL |
| 离子浓度 = 溶质浓度 | 离子浓度 = 溶质浓度 × 离子个数 | 0.1 mol/L Al₂(SO₄)₃ → c(SO₄²⁻)=0.3 mol/L |
| 配制"加 100 mL 水" | 应"加水至 100 mL" | 溶质占体积，定容才保证 V=溶液体积 |
| 质量分数直接当 c | 需经 c = 1000ρω/M 换算（要 ρ） | 98% H₂SO₄ 先求 ρ 再算 c |
| 稀释是浓度凭空变小 | 稀释前后溶质 n 守恒（c₁V₁=c₂V₂） | n 不变，V 增大 |

**核心口诀**：c = n / V，V 是溶液体积莫当水；离子浓度乘个数，下角标里找乘数；换算要乘 1000ρ，稀释守住 n 守恒。

**课前诊断小测（3 题，用于暴露典型误解，约 2 min 课前或导入前）**

1. "配制 100 mL 1 mol/L NaCl，应加 100 mL 水。"——判断并说明理由（预期暴露"加 100 mL 水"误解）。

3. "c = n / V 里的 V 指溶剂体积。"——判断并说明理由（预期暴露"V 是溶剂体积"误解）。

> 诊断意图：三题分别瞄准本课三大典型误解，课前快速摸底，课中针对错答在相应探究环节重点击破；若多数学生已过关，可将更多时间投入"混合离子浓度综合"与"过量计算雏形"的深度拓展。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否正确表述 c = n / V，并明确"V 是溶液体积而非溶剂体积"，能否区分"加水至 100 mL"与"加 100 mL 水"？容量瓶定容演示是否真正落地"V=溶液体积"？
- [ ] 离子浓度规律 c(离子)=c(溶质)×个数是否被真正理解——对 Al₂(SO₄)₃、Na₂SO₄ 能否正确写出各离子浓度，能否用电荷守恒验算，而非"把溶质浓度直接当离子浓度"？
- [ ] c = 1000ρω/M 是否被推导而非死记——学生能否说清 1000、ρ(g/mL)、ω(小数)、M 各量的意义，能否换算 98% H₂SO₄ 等实例；稀释定律的"n 守恒"本质是否讲透？
- [ ] 关系网 m↔n↔N↔V(气)↔c 是否建立，c 作为"n 与溶液体积接口"的定位是否清晰；混合离子浓度综合与过量计算雏形是否达成，还是仅停留在单溶质计算？
