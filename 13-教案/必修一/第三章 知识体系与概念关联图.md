# 第三章 铁 金属材料 · 知识体系与概念关联图

> 配套 7 课时教案使用。本章不是孤立知识点的堆砌，而是围绕"**类别视角 × 价态视角**"双轴（承接第一、二章）与"**宏—微—符三重表征**"展开的铁系、铝系两条转化主线，并以"**成分—结构—性能—用途**"模型认识合金材料，用"**物质的量 n**"收口定量。本图给出系统骨架、铁三角/铝三角转化网络、合金性质链、定量桥梁、双轴与第一二章打通、各课时 ★ 站位与后续接口，供板书"体系关联站位图"衔接，便于学生建立结构化认知。内容以 [[铁及其化合物]]、[[金属材料]]、[[两性物质]] 为据，深度衔接见 [[铁]]、[[铝]]。

## 一、本章知识系统的"三层视角 + 双轴"

```
              铁 金属材料 · 元素化合物与材料体系
   ┌──────────────────┬──────────────────┐
   │   宏观视角          │   微观视角          │
   │   现象/性质/用途     │   结构/粒子/电子     │
   └──────────────────┴──────────────────┘
           符号视角：化学方程式 / 离子方程式
   ┌──────────────────────────────────────────┐
   │   双轴分类（承接第一、二章"类别 × 价态"）     │
   │   轴① 类别视角：单质/氧化物/氢氧化物/盐/合金  │
   │   轴② 价态视角：Fe 0→+2/+3；Al 0→+3       │
   └──────────────────────────────────────────┘
   三重表征：宏观现象 ⇄ 微观粒子 ⇄ 符号表达
   材料视角：成分 → 结构 → 性能 → 用途（合金主线）
```

- **三层视角**：① 宏观——铁锈、血红色、白→灰绿→红褐、铝箔熔球、合金硬而熔低、钛合金球壳；② 微观——[Ar]3d⁶4s² 变价、致密 Al₂O₃ 膜、原子层滑动受阻、Al³⁺ 耦合电离平衡、Fe³⁺ 水解胶体；③ 符号——铁三角/铝三角/离子方程式。
- **双轴**：同一物质/反应可同时按"类别（它属于哪类化合物）"与"价态（元素处于什么化合价）"定位，交叉预测性质（见第六、七节）。

## 二、铁系转化网络（铁三角，文字 + 箭头，标注价态/反应类型）

```
             O₂(常温)        O₂(点燃)         Cl₂/S/弱氧化
                │              │                 │
                ▼              ▼                 ▼
        Fe ──→ Fe₂O₃      Fe ──→ Fe₃O₄      Fe ──→ FeCl₃ / FeS
       (0价)   (红棕,+3)   (0价)  (黑,+2+3)  (0价)   (均+3 / 弱到+2)
        │  Fe+2H⁺→Fe²⁺+H₂↑(非氧化酸)
        │  Fe+Cu²⁺→Fe²⁺+Cu (湿法炼铜/腐蚀本质, redox)
        │  浓H₂SO₄/浓HNO₃ 常温钝化(致密氧化膜)
        ▼
   高价态 Fe³⁺ 与低价态 Fe²⁺ 的相互转化（铁三角核心）
   ┌──────────────────────────────────────────────┐
   │   Fe⁰  ──氧化剂(Cl₂/HNO₃/浓H₂SO₄)──►  Fe³⁺      │
   │    │                                     ▲      │
   │    │ Fe³⁺+Fe→3Fe²⁺ (还原剂Fe)          │ 加氧化剂│
   │    ▼                                     │ (Cl₂/ │
   │   Fe²⁺ ──加氧化剂(Cl₂/H₂O₂/O₂/KMnO₄)──►│  H₂O₂/ │
   │   浅绿,还原性为主           棕黄,氧化性为主│ O₂/Cu?)│
   └──────────────────────────────────────────────┘
   典型：2Fe³⁺+Fe=3Fe²⁺（腐蚀电路板）  2Fe³⁺+Cu=2Fe²⁺+Cu²⁺
         2Fe²⁺+Cl₂=2Fe³⁺+2Cl⁻          5Fe²⁺+MnO₄⁻+8H⁺=5Fe³⁺+Mn²⁺+4H₂O
   氢氧化物：Fe²⁺+2OH⁻→Fe(OH)₂↓(白→灰绿→红褐, 4Fe(OH)₂+O₂+2H₂O=4Fe(OH)₃)
             Fe³⁺+3OH⁻→Fe(OH)₃↓(红棕, 受热→Fe₂O₃+3H₂O)
   检验：Fe³⁺ — KSCN血红色 / NaOH红棕沉淀
         Fe²⁺ — KSCN不变+氯水变红 / K₃[Fe(CN)₆]滕氏蓝(=普鲁士蓝 KFe[Fe(CN)₆])
   深度：E°(Fe³⁺/Fe²⁺)=0.771 V；Fe₃O₄ 反尖晶石纯净物(非 FeO·Fe₂O₃ 混合物)
```

- 标注：**氧化还原**——铁三角全部转化、Fe 与酸/盐/非金属；**非氧化还原**——Fe(OH)₂/Fe(OH)₃ 与酸成盐（复分解）、氧化物与酸反应。
- **铁三角闭合**即"类别 × 价态"双轴最高频范式：纵向变价态 = 氧化还原，横向同价态变类别 = 非氧化还原。

## 三、铝系转化网络（铝三角，文字 + 箭头）

```
   铝单质 Al (0价, 活泼, 致密Al₂O₃膜显"不活泼"假象)
   ├─ 2Al+6H⁺→2Al³⁺+3H₂↑          (先溶膜后反应)
   ├─ 2Al+2NaOH+2H₂O→2NaAlO₂+3H₂↑ (非置换, 三物质, redox)
   ├─ 铝热 2Al+Fe₂O₃→(高温)2Fe+Al₂O₃ (焊接铁轨/还原难熔金属)
   └─ 常温钝化(冷浓H₂SO₄/浓HNO₃)

   两性氧化物 Al₂O₃：
     Al₂O₃+6H⁺→2Al³⁺+3H₂O        Al₂O₃+2OH⁻→2AlO₂⁻+H₂O (水溶液中实际 [Al(OH)₄]⁻)
     α-Al₂O₃ 刚玉/红蓝宝石   γ-Al₂O₃ 多孔载体

   铝三角 Al³⁺ ⇌ Al(OH)₃ ⇌ AlO₂⁻（核心）
   ┌────────────────────────────────────────────────┐
   │  Al³⁺ ──(加限/弱碱)──► Al(OH)₃ ──(加酸)──► Al³⁺  │
   │   (浅)    NH₃·H₂O沉淀     (白胶)   3H⁺→Al³⁺+3H₂O │
   │            Al³⁺+3NH₃·H₂O=Al(OH)₃↓+3NH₄⁺          │
   │  Al(OH)₃ ──(加过量强碱)──► AlO₂⁻                 │
   │   (白胶)   OH⁻→AlO₂⁻+2H₂O                        │
   │  AlO₂⁻ ──(通CO₂弱酸)──► Al(OH)₃↓                │
   │           AlO₂⁻+CO₂+2H₂O=Al(OH)₃↓+HCO₃⁻          │
   └────────────────────────────────────────────────┘
   两性机理(深度)：酸式电离 H⁺+AlO₂⁻+H₂O ⇌ Al(OH)₃ ⇌ Al³⁺+3OH⁻ 一对耦合平衡
   判据：离子势 φ=z/r（Al³⁺ φ≈4.8 居中→两性）；两性金属名单"铝锌铅锡铬铍"
   pH 窗口：Al³⁺ (pH<~3.5) ⇌ Al(OH)₃ (3.5~12 沉淀) ⇌ AlO₂⁻ (pH>~12)
   应用：明矾 KAl(SO₄)₂·12H₂O 净水(Al³⁺水解胶体吸附)；胃药 Al(OH)₃ 中和胃酸
   深度：Be-Al 对角线(BeO/BeCl₂ 同两性/共价)；AlCl₃ 共价二聚 Al₂Cl₆(3c-4e 桥)
```

- 标注：**非置换**：Al 与强碱是三种物质的氧化还原；**两性**指氢氧化物/氧化物酸碱两性，单质与酸碱反应不算两性（区分配合溶解：Zn/Cu 吃氨水、Al 只吃强碱）。
- **铝三角数形结合**：沉淀量—pH 图像是高频考点（n(OH⁻) 由 0→3 沉淀生成、3→4 溶解为 AlO₂⁻；制 Al(OH)₃ 用氨水、溶铝酸盐用 CO₂ 均落在 pH 窗口逻辑内）。

## 四、合金性质链（成分—结构—性能—用途，文字 + 箭头）

```
   成分(金属+其他金属/非金属熔合, 混合物非化合物)
        │  微观：异径原子破坏纯金属规整层状排列
        ▼
   结构(原子层相对滑动受阻 → 硬；原子间作用改变 → 熔↓)
        │
        ▼
   性能(硬度↑ / 熔点↓ / 耐蚀↑，可调控)
        │
        ▼
   用途(因性能选材)
   ├─ 铁合金：生铁(2%~4.3%C,脆,机座) / 钢(0.03%~2%C,延展)
   │         碳素钢(低/中/高碳) / 合金钢(不锈钢 Cr~18% Ni~8%)
   ├─ 铝合金：硬铝(Cu/Mg/Mn/Si,飞机飞船) / 易拉罐
   ├─ 新型：储氢 Ti-Fe·La-Ni / 钛合金(蛟龙号球壳)
   │        耐热 Ni-Co(发动机叶片) / 形状记忆 Ti-Ni
   └─ 稀土：17种(镧系15+Sc+Y)"冶金维生素"，我国储量/产量/用量/出口均世界第一
   深度：合金熔点一般低于成分中较高者(非必低于最低)；性能可经组分/含量/条件调控
```

- **成分—结构—性能—用途**是本章材料认知的总模型，把"性质决定用途"从单质升级到工程材料层面。

## 五、定量桥梁：物质的量 n

```
            宏观可称量                微观粒子数
         ┌──────────────┐         ┌──────────────┐
   质量 m │              │  N (粒子数)│              │
   体积 V │   枢纽 n      │← N/Nₐ →│  Nₐ≈6.022×10²³│
   (溶液) │   (mol)      │         │   mol⁻¹       │
         └──────────────┘         └──────────────┘
   核心关系： n = N / Nₐ = m / M = V / Vₘ = c · V
   本章收口：
     · 铁盐/铝盐计量：n(Al)=m/M → 由 2Al+2NaOH+2H₂O→2NaAlO₂+3H₂↑ 算 V(H₂)
     · 合金含碳量：钢(0.03%~2%) vs 生铁(2%~4.3%) 边界判别
     · 铝与酸/碱放 H₂ 体积比 1:1（Al 均 0→+3，等电子转移）
     · 铁三角电子守恒(如 5Fe²⁺+MnO₄⁻+8H⁺=5Fe³⁺+Mn²⁺+4H₂O)
```

- n 是"桥"：一端连宏观可称量（m、V 溶液），一端连微观粒子数（N）；本章把第二章的定性研究推向铁/铝定量计算与合金表征。

## 六、双轴分类与第一、二章打通

```
            "类别 × 价态"二维图（同第一、二章骨架）
   价态轴 ↑
    +3  │ Fe³⁺ / Al³⁺ / Fe₂O₃ / Al(OH)₃(两性的高价侧)
    +2  │ Fe²⁺ / FeO / Fe₃O₄(含铁)
     0  │ Fe  Al  单质(只氧化, 强还原)
    −1  │ AlO₂⁻(氢氧根视角, 碱性介质中的铝存在形式)
     0  │ 单质 Fe / Al(强还原, 只氧化)
    ↓ 类别轴 → 单质 / 氧化物 / 氢氧化物 / 盐 / 合金
   规律（与第一、二章一致）：
     同价态横向变类别 = 非氧化还原(如 Fe³⁺→Fe(OH)₃→Fe₂O₃)
     纵向变价态       = 氧化还原(如 Fe⁰→Fe²⁺→Fe³⁺、Al⁰→Al³⁺)
```

- **两标签法（与第一、二章双轴一致）**：铁/铝任一反应同贴"是否离子反应""是否氧化还原"。
  - 离子反应 + 氧化还原：2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑、Fe + Cu²⁺ → Fe²⁺ + Cu。
  - 离子反应 + 非氧化还原：Fe₂O₃ + 6H⁺ → 2Fe³⁺ + 3H₂O（复分解）、Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺。
  - 氧化还原 + 非离子：3Fe + 2O₂ → Fe₃O₄、铝热 2Al + Fe₂O₃ → 2Fe + Al₂O₃（固/气反应，无自由离子）。
- **研究方法贯通**：Ch1 分类观/离子反应/氧化还原 → Ch2 钠氯范式 + n 桥梁 → Ch3 铁/铝双轴迁移 + 材料模型 + n 收口；氯水成分、歧化(Cl₂ 与碱)曾练手，本三角价态转化(Fe²⁺/Fe³⁺)是进阶演练。

## 八、与后续知识系统的接口

- **铁/铝研究范式（双轴 + 宏微符）** → 后续"硫、氮及其化合物""物质结构·元素周期律"（过渡金属 Fe 的变价、主族 Al 的两性在此周期化：同周期 Na→Mg→Al→Si 氢氧化物碱→两→酸递变，对角线 Be-Al；[[铁]]、[[铝]] 深化）。
- **铁三角 / 铝三角 / 离子反应 / 氧化还原** → 选择性必修1《化学反应原理》水溶液中的离子反应与平衡（Fe³⁺ 水解、Al³⁺ 水解、沉淀溶解与 pH 控制）；→ 选择性必修1 电化学（原电池、电解池，钢铁腐蚀与防护、铝电解即 Hall-Héroult 应用）。
- **物质的量 n（计量桥梁）** → 选择性必修 滴定、产率、关系式计算、气体计算（PV = nRT）的核心等量关系；→ 后续所有定量章节的计量前提。
- **合金材料模型** → 必修二"材料科学基础"、选择性必修"物质结构与性质"（晶体结构、合金固溶体、稀土功能材料）；稀土战略与 STSE 议题衔接。
- **第一、二章方法承接**：铁/铝研究沿用第一、二章"分类（类别视角）→ 预测性质 → 实验验证 → 用离子反应/氧化还原解释"；Fe²⁺/Fe³⁺ 价态转化、Al 两性本质均属氧化还原视角进阶；"物质的量"是连接第二章"离子浓度"与本章铁盐/铝盐计量、合金表征的桥梁。
