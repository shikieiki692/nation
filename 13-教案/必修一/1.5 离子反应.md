# 教案：1.5 离子反应（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.5 离子反应 / 第 5 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[物质分类与离子反应]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：上一课时 1.4 解决了"离子从哪来"，本课时解决"离子之间怎么反应"。建立**离子反应本质（某些离子浓度降低）**与**离子方程式四步法（写—拆—删—查）**两块核心，并把"拆 / 不拆"的精确边界与离子共存规则讲透。与量有关、信息型等高阶应用留待下一课时 1.6。

## 一、课标对应

- **内容要求**：通过实验探究认识离子反应及其发生的条件；能书写简单的离子方程式；能判断离子方程式书写是否正确；了解常见离子的检验方法。
- **学业质量水平**：必修水平 2——能用离子方程式表示常见的离子反应；能依据"离子浓度降低"判断反应能否发生；能判断常见离子在溶液中能否大量共存。
- **核心素养落点**：
  1. **变化观念与平衡思想**（认识离子反应的本质是"某些离子浓度降低"，生成沉淀 / 气体 / 弱电解质 / 发生氧化还原）；
  2. **证据推理与模型认知**（建立"写—拆—删—查"四步法模型，用五角度判断离子方程式正误）；
  3. **宏观辨识与微观探析**（由导电性曲线的宏观变化，追溯离子浓度降低这一微观本质）。

## 二、学情分析（本课时）

**【课前诊断·4 处典型误解预判】**

- 学生常把"离子方程式"当成"化学方程式的简写"，未理解它表示**一类反应**（如 H⁺ + OH⁻ = H₂O 代表所有强酸强碱中和）。
- 学生常把"强电解质"直接等同于"离子方程式里要拆"（实为 BaSO₄ 是强电解质但难溶、作沉淀不拆，口诀是"**强溶才拆**"）。
- 学生常忽略"电荷守恒"，只检查原子个数（如把 Cu + Ag⁺ = Cu²⁺ + Ag 判为正确）。
- 学生判断离子共存时只想到"生成沉淀 / 气体 / 弱电解质"，遗漏**氧化还原、双水解、络合**三类，也常漏掉"无色""酸性""碱性"等隐含条件。

学生已在 1.4 掌握电离与强弱电解质，但面对离子方程式时往往把"会不会拆"当成唯一难点，忽略了"是否符合反应事实"与"电荷守恒"这两个更基础也更易错的维度。本课新难点有三：一是"拆 / 不拆"的精确边界（难溶物、弱电解质、浓硫酸、微溶物的状态差异：澄清石灰水拆、石灰乳不拆）；二是离子共存的六类原因与"先颜色→再六类→再酸碱性"的解题顺序；三是把导电性曲线（先降—B 处≈0—后升）这一现象证据，转化为"离子浓度降低"这一本质结论。对策：用 Ba(OH)₂ 滴 H₂SO₄ 的实时电导曲线作直观证据，用"五角度正误判断"把检查项清单化，用"综合共存题"训练固定解题顺序。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过分析 Ba(OH)₂ 与 H₂SO₄ 反应的导电性曲线，培养**宏观辨识与微观探析**素养：把"导电性先降后升"的宏观现象，解释为"离子被消耗 → 浓度降低 → 过量后回升"的微观过程。
- 通过建构"写—拆—删—查"四步法并总结"强溶才拆"规则，培养**证据推理与模型认知**素养：把书写过程标准化、可检查化。
- 通过归纳离子不能大量共存的六类原因与隐含条件，培养**变化观念与平衡思想**素养：认识离子反应发生的判据是"浓度降低"，六类只是其具体表现。
- 通过五角度挑错训练，培养**科学态度与社会责任**素养：养成写完后逐条复核的严谨习惯。

### 3.2 学习目标（学生能……，可观测）

- 能**说明**离子反应的本质是"溶液中某些离子浓度降低"，并能从导电性曲线指出恰好完全反应的位置（B 处≈0）。
- 能**用四步法**正确书写常见离子方程式，并对给定离子方程式用五角度（事实 / 拆分 / 守恒 / 符号 / 量比）判断正误、改正错式。
- 能**准确判定**各类物质的拆与不拆，尤其掌握 BaSO₄（强电解质但作沉淀不拆）、浓 H₂SO₄（分子态不拆）、澄清石灰水拆 vs 石灰乳不拆、微溶物反应物稀溶液拆 / 浊液不拆、生成物一律不拆。
- 能**用"先颜色→再六类→再酸碱性"的顺序**判断给定条件下离子能否大量共存，并逐条说理。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

### 环节四：离子反应本质与四步法

**【逐字稿】**

**教师**："向 Ba(OH)₂ 溶液滴加稀 H₂SO₄，看电导仪与沉淀。预言曲线形状。"

**学生（预期）**："有白色沉淀；读数先降后升？"

**教师（追问/理答）**："为何'先降'？因 Ba²⁺ + SO₄²⁻ → BaSO₄↓、H⁺ + OH⁻ → H₂O，自由离子被消耗，离子浓度降低，导电性下降——这正是**离子反应本质：某些离子浓度降低**（生成沉淀/气体/弱电解质/发生氧化还原）。"

**学生（预期，典型错误）**："那为什么后又升？不是反应完了吗？"

**教师（追问/理答）**："恰好完全反应时（曲线最低点 B 处），四种离子几乎被消耗完，导电性≈0——B 处≈0 是'恰好完全反应'的铁证：此时溶液中几乎没有自由移动的离子。继续滴过量稀 H₂SO₄，新引入的 H⁺、SO₄²⁻ 让离子浓度回升，导电性回升。这条曲线是离子反应本质最直观的证据。"

**教师**："把反应写成离子方程式，四步法——写、拆、删、查。先'写'：Ba(OH)₂ + H₂SO₄ = BaSO₄↓ + 2H₂O。"

**学生（预期）**："Ba(OH)₂ 拆 Ba²⁺+2OH⁻；H₂SO₄ 拆 2H⁺+SO₄²⁻；BaSO₄、H₂O 不拆。"

**教师（追问/理答）**："第二步'拆'——易溶且易电离才拆。于是：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO₄↓ + 2H₂O。第三步'删'旁观离子：本式 Ba²⁺、OH⁻、H⁺、SO₄²⁻ 全参与了（成沉淀或水），**零旁观离子**，无需删。第四步'查'——原子守恒且电荷守恒：左总电荷 +2−2+2−2=0，右中性，守恒。"

**教师**："关键认知：此式不只代表'Ba(OH)₂ 和 H₂SO₄ 这一个反应'，它代表**所有**生成 BaSO₄ 的'钡盐 + 硫酸根'反应；而 H⁺ + OH⁻ = H₂O 更代表**所有强酸强碱中和**。所以离子方程式表示'一类反应'。五角度正误判断：① 是否符合事实；② 质量守恒；③ 电荷守恒；④ 拆分规则；⑤ 符号（↓↑⇌）与反应环境。"

**教师**："用五角度现场挑错三个式：甲. Fe + 2H⁺ = Fe²⁺ + H₂↑（稀硫酸）；乙. CaCO₃ + H⁺ = Ca²⁺ + CO₂↑ + H₂O；丙. Ba²⁺ + OH⁻ + H⁺ + SO₄²⁻ = BaSO₄↓ + H₂O。"

**学生（预期，典型错误）**："甲对？乙好像缺个 2？丙是不是也缺系数？"

**教师（追问/理答）**："甲：事实对（Fe 在 H 前，稀酸出 H₂）、质量电荷均守恒、拆写对（H₂SO₄ 拆、H₂O 不拆）→正确。乙：电荷不守恒（左 +1、右 +2），应 CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O→错在电荷。丙：这是把 Ba(OH)₂ 拆成'Ba²⁺+OH⁻'（少 1 个 OH⁻）、H₂SO₄ 拆成'H⁺+SO₄²⁻'（少 1 个 H⁺），Ba(OH)₂、H₂SO₄ 都是 1:2 电离→错在拆写（系数）。五角度逐条过，比死记高效。"

### 环节五：拆写精确边界与离子共存

**【逐字稿】**

**教师**："把'拆/不拆'做成判定清单，核心只问一句：它在溶液里主要以什么形式存在？能拆——强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶盐。不拆——难溶物（BaSO₄、CaCO₃）、弱电解质（CH₃COOH、NH₃·H₂O、H₂O）、气体、单质、氧化物。"

**教师**："现在抛精确边界冲突。① BaSO₄ 是强电解质，离子方程式拆不拆？"

**学生（预期，典型错误）**："强电解质，应该拆吧？"

**教师（追问/理答）**："错，'强电解质'和'拆不拆'两件事。BaSO₄ 是强电解质（溶解部分全电离），但**难溶**，溶液里几乎以固体存在，作沉淀**不拆**。口诀'**强溶才拆**'——既强电解、又要可溶可电离才拆。② 浓 H₂SO₄ 分子态为主→不拆；稀 H₂SO₄ 才拆。③ 微溶物 Ca(OH)₂：**澄清石灰水拆成 Ca²⁺+2OH⁻，石灰乳不拆（写 Ca(OH)₂(s)）**。④ 作反应物：微溶物稀溶液拆、浊液不拆；作生成物一律不拆。⑤ NH₃·H₂O 弱碱不拆；氧化物、单质不拆。"

**教师**："进入共存。离子不能大量共存有六类原因——"

**学生（预期）**："生成沉淀、气体、弱电解质，还有氧化还原！比如 Fe³⁺ + I⁻。"

**教师（追问/理答）**："齐了，再加双水解与络合。六类：① 沉淀（如 Ba²⁺+SO₄²⁻、Ca²⁺+CO₃²⁻）；② 气体（CO₃²⁻+2H⁺=H₂O+CO₂↑）；③ 弱电解质（H⁺+OH⁻=H₂O、CH₃COOH 与 CH₃COO⁻ 等）；④ 氧化还原（Fe³⁺ 氧化 I⁻、S²⁻、SO₃²⁻；酸性 MnO₄⁻/NO₃⁻ 氧化 Fe²⁺、I⁻）；⑤ 双水解（Al³⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻；Fe³⁺ 与 CO₃²⁻——且有时伴随氧化还原，如 Fe³⁺ 与 S²⁻ 既双水解又氧化还原）；⑥ 络合（Fe³⁺ + SCN⁻ = [Fe(SCN)]²⁺ 等）。"

**教师**："隐含条件三件套：无色先排除 Cu²⁺(蓝)、Fe³⁺(棕黄)、Fe²⁺(浅绿)、MnO₄⁻(紫)；酸性含 H⁺；碱性含 OH⁻。特殊：HCO₃⁻ 与 H⁺、OH⁻、Al³⁺、Fe³⁺ 均不共存（遇 H⁺ 出 CO₂，遇 OH⁻ 转 CO₃²⁻，遇 Al³⁺/Fe³⁺ 双水解）。解题顺序我强调：**先排颜色，再排六类反应，最后排酸碱性**——别一上来就盯反应漏颜色。"

**教师**："现场练一道综合共存：'无色、碱性'溶液中，下列能否大量共存？A. Na⁺、K⁺、Cl⁻、SO₄²⁻；B. Cu²⁺、K⁺、SO₄²⁻、NO₃⁻；C. Na⁺、NH₄⁺、K⁺、Cl⁻、SO₄²⁻；D. Na⁺、K⁺、CO₃²⁻、Ba²⁺。"

**学生（预期，典型错误）**："A 可以；B 有 Cu²⁺ 蓝色不行；C……NH₄⁺ 在碱性下？D 有 Ba²⁺ 和 CO₃²⁻ 沉淀？"

**教师（追问/理答）**："全中。A 全部彼此无六类反应→可存。B 含 Cu²⁺ 违'无色'→否。C 在碱性下 NH₄⁺ + OH⁻ = NH₃·H₂O→不存（隐含条件踩雷）。D 中 Ba²⁺ + CO₃²⁻ = BaSO₄↓？不，是 BaCO₃↓（沉淀）→不存。注意 D 的沉淀属'六类第一阻'，与颜色无关。所以解题顺序真能避免漏网：先颜色踢 B，再六类踢 D，再酸碱性踢 C。"

### 易错点速记对照表（当堂投影，配逐字稿小结）

| 易错表述 | 正解 | 根源 |
|---|---|---|
| BaSO₄ 是强电解质 → 离子式拆 | BaSO₄ 难溶作沉淀，离子方程式不拆 | 混淆"强电解质"与"拆不拆" |
| 澄清石灰水 = 石灰乳（都拆/都不拆） | 澄清石灰水拆 Ca²⁺+2OH⁻；石灰乳不拆 Ca(OH)₂(s) | 忽略状态差异 |
| NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻ | NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 不拆） | 弱酸酸式根误拆 |
| 离子方程式只代表"一个反应" | 代表"一类反应"（如 H⁺+OH⁻=H₂O 表所有强酸强碱中和） | 未建立离子视角抽象 |

**【逐字稿小结】**

**教师**："这三行是'拆写'与'离子式'坑，核心两点——**强溶才拆，状态决定拆不拆**；**离子方程式表示的是一类反应，不是一个反应**。BaSO₄ 是强电解质没错，但它难溶、作沉淀就不拆；澄清石灰水拆、石灰乳就不拆；H⁺ + OH⁻ = H₂O 说的是'所有强酸强碱中和'，不是专指 NaOH 和 HCl。下一课时我们处理最难的一层——同样的反应物，量不同产物就不同。"

## 八、作业布置（三层，区分度）

> 分层说明：必做保底全体学生，选做面向中等及以上，挑战面向拔高与有志高考难题者；批改时按三层分别给反馈，错题回扣"易错点速记对照表"。

- **必做**（基础达标，覆盖四步法与拆写陷阱）：[[高中化学必修一-习题精选]] 题3——判断下列离子方程式是否正确，错误的改正并说明理由：① 稀硫酸 + Cu：Cu + 2H⁺ = Cu²⁺ + H₂↑（陷阱：稀硫酸与 Cu 不反应）；② MgO + 盐酸：MgO + 2H⁺ = Mg²⁺ + H₂O（正确）；③ Cu + AgNO₃：Cu + Ag⁺ = Cu²⁺ + Ag（陷阱：电荷不守恒，应为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag）；④ CaCO₃ + 盐酸：CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O（正确）。题4——根据 Ba(OH)₂ 溶液滴加稀 H₂SO₄ 的导电性曲线，解释"先降—B 处≈0—后升"：B 处说明恰好完全反应、溶液中几乎无自由离子。
  另加：⑤ 判定下列物质在离子方程式中拆还是不拆，并各举一个反应例：BaSO₄、浓 H₂SO₄、澄清石灰水、石灰乳、NH₃·H₂O、CH₃COOH、CuO、CO₂。

- **选做**（能力提升）：
  ① 用四步法写出下列反应的离子方程式，并自查原子守恒与电荷守恒：Ba(OH)₂ + H₂SO₄、CuSO₄ + Ba(OH)₂、Na₂CO₃ + CaCl₂、Fe + CuSO₄、NaHCO₃ + NaOH。
  ② 共存判断（含隐含条件）：在"无色酸性"溶液中，A. Na⁺、K⁺、SO₄²⁻、Cl⁻，B. Cu²⁺、K⁺、SO₄²⁻、NO₃⁻，C. Na⁺、CO₃²⁻、K⁺、Cl⁻，D. Fe²⁺、K⁺、MnO₄⁻、H⁺——分别判断能否大量共存并说理。
  ③ 用五角度检查下列离子方程式，指出错误类型（事实 / 拆分 / 守恒 / 符号 / 量比）：a. Fe + 2H⁺ = Fe²⁺ + H₂↑（稀硫酸）；b. CaCO₃ + H⁺ = Ca²⁺ + CO₂↑ + H₂O；c. Ba²⁺ + OH⁻ + H⁺ + SO₄²⁻ = BaSO₄↓ + H₂O；d. Cu(OH)₂ + 2H⁺ = Cu²⁺ + 2H₂O（盐酸）。

- **挑战**（拔高区分）：
  ① 写出向 NaHSO₄ 溶液中逐滴加入 Ba(OH)₂ 溶液至中性、至沉淀完全两种情形的离子方程式，并说明两式为何不同（提示：NaHSO₄ 在水中完全电离为 Na⁺、H⁺、SO₄²⁻，Ba(OH)₂ 提供 Ba²⁺ 与 2OH⁻，"至中性"需 H⁺ 与 OH⁻ 恰好等量，"至沉淀完全"需 SO₄²⁻ 与 Ba²⁺ 恰好等量）。
  ② 一道含隐含条件的共存综合：在"无色、碱性"溶液中混有 Na⁺、K⁺、NH₄⁺、Cl⁻、SO₄²⁻、CO₃²⁻、MnO₄⁻、Cu²⁺、HCO₃⁻，逐离子判定哪些必不能大量共存并写出理由（注意 HCO₃⁻ 与 OH⁻ 也不能共存）。

---

**作业解析提示（供批改与讲评）**

- 必做题3 四式速判：① 错（Cu 与稀硫酸不反应，违背事实）；② 对（MgO 氧化物不拆，H⁺ 拆，H₂O 不拆）；③ 错（电荷不守恒，应 Cu + 2Ag⁺ = Cu²⁺ + 2Ag）；④ 对（CaCO₃ 沉淀不拆，HCl 拆，CO₂ 气体、H₂O 不拆）。题4 曲线：滴加初期 Ba²⁺+SO₄²⁻→BaSO₄↓、H⁺+OH⁻→H₂O，自由离子浓度下降→导电性降；恰好完全反应 B 处四离子近耗尽→导电性≈0；过量稀硫酸引入 H⁺、SO₄²⁻→回升。
- 必做⑤：BaSO₄ 不拆（难溶沉淀）、浓 H₂SO₄ 不拆（分子态）、澄清石灰水拆（Ca²⁺+2OH⁻）、石灰乳不拆（Ca(OH)₂(s)）、NH₃·H₂O 不拆（弱碱）、CH₃COOH 不拆（弱酸）、CuO 不拆（氧化物）、CO₂ 不拆（气体/氧化物）。
- 选做②共存：A 全可存；B 含 Cu²⁺ 违无色；C 在酸性下 CO₃²⁻+2H⁺=H₂O+CO₂↑ 不存；D 酸性 MnO₄⁻ 氧化 Fe²⁺（5Fe²⁺+MnO₄⁻+8H⁺=5Fe³⁺+Mn²⁺+4H₂O）且 MnO₄⁻ 本身有色，均不存。
- 选做③：a 对；b 错在电荷守恒（应 CaCO₃ + 2H⁺）；c 错在拆分系数（Ba(OH)₂ 与 H₂SO₄ 均 1:2 电离，应 Ba²⁺+2OH⁻+2H⁺+SO₄²⁻）；d 对（Cu(OH)₂ 难溶不拆，盐酸拆）。
- 挑战①：至中性时 2H⁺+SO₄²⁻+Ba²⁺+2OH⁻ = BaSO₄↓+2H₂O（NaHSO₄ 与 Ba(OH)₂ 按 2:1）；至沉淀完全时 H⁺+SO₄²⁻+Ba²⁺+OH⁻ = BaSO₄↓+H₂O（按 1:1）。
- 挑战②：必不能共存者——MnO₄⁻（紫，违无色）、Cu²⁺（蓝，违无色）、NH₄⁺（+OH⁻=NH₃·H₂O）、HCO₃⁻（+OH⁻=CO₃²⁻+H₂O）；可共存者 Na⁺、K⁺、Cl⁻、SO₄²⁻、CO₃²⁻（碱性下彼此无六类反应）。
