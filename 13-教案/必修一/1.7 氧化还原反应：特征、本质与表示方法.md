# 教案：1.7 氧化还原反应：特征、本质与表示方法（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.7 氧化还原反应：特征、本质与表示方法 / 第 7 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[氧化还原反应基础]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：氧化还原单元的第一课，也是本章第二根轴（轴②：电子转移·与价态相关）的起点。回答三个问题——**什么反应是氧化还原（特征判据）**、**为什么是（电子转移本质）**、**怎么表示（氧化数与双线桥 / 单线桥）**。氧化剂和还原剂的具体清单留待 1.8，价态规律与归中歧化留待 1.9。

## 一、课标对应

- **内容要求**：认识有化合价变化的反应是氧化还原反应；了解氧化还原反应的本质是电子的转移；知道常见的氧化还原反应；能根据化合价变化判断氧化还原反应，能标出电子转移的方向和数目。
- **学业质量水平**：必修水平 2——能用化合价变化判断氧化还原反应，能用双线桥 / 单线桥正确表示电子转移的方向与数目；能计算常见物质中元素的氧化数。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从"得氧失氧"的宏观描述，深入到"化合价升降"的特征判据，再深到"电子转移"的微观本质）；
  2. **证据推理与模型认知**（建立"氧化数"这一形式电荷的记账模型，用双线桥把电子转移可视化）；
  3. **科学态度与社会责任**（用"84+洁厕灵混用放毒气"的真实事故，建立化学与生活的关联与风险意识）。

## 二、学情分析（本课时）

**【课前诊断·4 处典型误解预判】**

- 学生停留在初中"得氧失氧"定义，遇到无氧参与的反应（如 Fe + CuSO₄）就判不出来。
- 学生常把"化合价"当成真实电荷，不理解氧化数是**人为规定的形式电荷**，因而算 Fe₃O₄（Fe 平均 +8/3）时觉得荒谬。
- 学生画双线桥时常把箭头**跨元素**连接（从 Fe 指向 Cu），混淆"元素自身升降标记"与"电子流动方向"。
- 学生常把"价态变化数"直接当成"电子转移数"，忘了乘**变价原子个数**（如 MnO₂+4HCl 中只有 2 个 Cl 被氧化）。

学生在初三学过"氧化反应 / 还原反应"的得氧失氧定义，也接触过化合价，但两者是割裂的：既不知道化合价变化才是根本判据，也不知道化合价为什么会变。本课新难点有三：一是从"得氧失氧"到"化合价升降"再到"电子转移"的三级跃迁，学生易停留在第二级；二是氧化数的计算（尤其过氧键 O 为 −1、过硫根 S 为 −1 这类反直觉特例）；三是双线桥的规范（同种元素、箭头方向、电子数计算）与单线桥的区别。对策：用"84+洁厕灵"的真实事故制造认知冲突（无氧参与却危险），用"Na₂O₂ 按 O −2 算出 Na +4"的荒谬结果反逼学生回头检查过氧键，用四例渐进示范（简单 → 部分变价 → 歧化 → 部分变价+多原子）把双线桥练成规范动作。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"84+洁厕灵混用放毒气"的情境分析与三个生活实例的辨析，培养**科学态度与社会责任**素养：认识氧化还原反应在生活中的真实存在与风险，破除"必须有氧才是氧化还原"的迷思。
- 通过"得氧失氧 → 化合价升降 → 电子转移"三级认识台阶的建构，培养**宏观辨识与微观探析**素养：从宏观描述深入到微观本质，理解化合价只是电子的"记账语言"。
- 通过氧化数规则的应用与复杂算例（Fe₃O₄、Na₂S₂O₃、H₂C₂O₄、CH₃CH₂OH、K₂Cr₂O₇）的计算，培养**证据推理与模型认知**素养：掌握形式电荷的代数和模型，并能用"金属价态超常"反查特例。
- 通过双线桥 / 单线桥的规范训练与四例示范，培养**宏观辨识与微观探析**素养：把不可见的电子转移转化为可检查的符号表征。

### 3.2 学习目标（学生能……，可观测）

- 能**说明**氧化还原反应的根本判据是"化合价（氧化数）是否变化"，并指出"得氧失氧"只是其特例。
- 能**复述**三级认识台阶（得氧失氧 → 化合价升降 → 电子转移）各自的提出者与局限。
- 能**用氧化数五条规则**计算给定物质中指定元素的氧化数，正确处理 Fe₃O₄（+8/3）、FeS₂（S 为 −1）、Na₂O₂/H₂O₂（O 为 −1）、NaH（H 为 −1）等特例。
- 能**正确画出**双线桥（同种元素、标得失与价升降、电子守恒）与单线桥（还原剂→氧化剂、只标电子总数），并能处理"部分变价"（MnO₂+4HCl）与"歧化"（Cl₂+2NaOH）两类情形。
- 能**用"升失氧 / 降得还"口诀**并说清其针对对象是"元素 / 物质"，不把"元素被氧化"说成"物质被氧化作氧化剂"。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

### 环节一：情境导入（84+洁厕灵）

**教师**："同学们，新闻里常有这样的提醒——84 消毒液和洁厕灵绝对不能混用，混用会放'毒气'。大家看屏幕：84 含 ClO⁻，洁厕灵含 HCl，二者相遇会生成 Cl₂。问题来了：这两种东西单独用都很安全、天天见，为什么一混合就危险？今天我们就用一类特殊反应的眼光来拆穿它。"

**学生（预期）**："因为它们混在一起发生了化学反应，产生了氯气！""是不是有氧气参加的反应？"

**教师（追问/理答）**："对，反应生成了 Cl₂，但关键不是'有没有氧'，而是反应内部发生了电子的重新分配。这种伴随电子转移的反应，化学上叫——氧化还原反应。从今天起，我们判断它不再看'有没有氧'，而要看一条更本质的线索。我们一步步来。"

**教师**："其实氧化还原就在身边，举三个：① 切开的苹果变黄——酚类物质被空气中的 O₂ 氧化（O₂ 是氧化剂，O 从 0 降到 −2）；② 食品脱氧剂里的铁粉消耗 O₂ 生成铁锈（Fe 0→+3，被氧化，铁粉作还原剂）；③ 煤气燃烧 CH₄ + 2O₂ → CO₂ + 2H₂O（C −4→+4、O 0→−2，典型的氧化还原）。可见'有没有氧参加'只是特例，本质是电子的重新分配——哪怕像 84+洁厕灵那样根本没有氧气，也一样是氧化还原。"

### 环节二：三级认识台阶、氧化数初探与双线桥规范

**教师**："我们先走三级台阶。第一级，初中说法：物质**得氧**叫被氧化，**失氧**叫被还原——比如 CuO + H₂ → Cu + H₂O，H₂ 得氧被氧化。但这台阶有个大漏洞：没有氧参与的反应怎么办？比如 Fe + CuSO₄ = FeSO₄ + Cu，没氧，可它明明是一类反应。所以第二级——弗兰克兰提出：看**化合价升降**。只要反应前后有元素化合价变化，就是氧化还原。第三级，汤姆孙揭示本质：**电子转移**。离子化合物里是电子得失（NaCl 中 Na 把电子给 Cl）；共价化合物里是电子偏移（HCl 里共用电子对偏向 Cl）。化合价的升降，只是电子'记账'的语言。"

**学生（预期）**："那 Fe + CuSO₄ 里，Fe 从 0 升到 +2，Cu 从 +2 降到 0，所以它也是氧化还原！""化合价升降比得氧失氧管用。"

**教师（追问/理答）**："非常好。但你有没有想过——化合价为什么变？根子在电子转移。**化合价是否变化，就是根本判据**，得氧失氧只是它的特例。这里要引入一个重要概念：**氧化数**。中学里我们说的'化合价'，实际是氧化数——人为规定的形式电荷数，不是真实电荷。规则有五条：① 单质氧化数=0；② 化合物各元素氧化数代数和=0；③ O 通常 −2，过氧键（−O−O−）中 O 为 −1；④ H 通常 +1，金属氢化物（如 NaH）中 H 为 −1；⑤ 金属显正价，单原子离子氧化数=电荷数（Na⁺ 为 +1，Cl⁻ 为 −1）。"

**教师**："练几个复杂算例。Fe₃O₄：O 为 −2×4=−8，3 个 Fe 合计 +8，平均每个 Fe 为 +8/3——注意氧化数可以是分数，因为它是'平均形式电荷'，实际是 1 个 Fe²⁺ + 2 个 Fe³⁺。Na₂S₂O₃：2Na 共 +2，3O 共 −6，2 个 S 合计 +4，平均每个 S 为 +2（结构上是 1 个 S 为 −1、1 个 S 为 +5）。H₂C₂O₄：2H 共 +2，4O 共 −8，2 个 C 合计 +6，平均每个 C 为 +3。CH₃CH₂OH：C₂H₆O 总 0，2C+6×(+1)+(−2)=0，得 2C=−4，平均 C 为 −2（CH₃ 上的 C 为 −3，CH₂OH 上的 C 为 −1）。K₂Cr₂O₇：2K 共 +2，7O 共 −14，2Cr 共 +12，Cr 为 +6，这是重铬酸根中 Cr 的典型最高价。NH₄NO₃ 中 N 也一分为二：铵根 N 为 −3，硝酸根 N 为 +5。H₂O₂ 中 O 为 −1（过氧键）。"

**教师**："核心关系口诀——'**升失氧/降得还**'，但必须说清针对对象：某**元素**化合价**升**高 → 该物质中该元素**失**电子 → 该元素被**氧**化 → 含该元素的反应物作**还**原剂；某**元素**化合价**降**低 → 该物质中该元素**得**电子 → 该元素被**还**原 → 作**氧**化剂。逻辑链'物质→元素→过程→角色'一一对应，绝不能把'元素被氧化'说成'物质被氧化作氧化剂'。氧化产物是还原剂被氧化后得到的产物，还原产物是氧化剂被还原后得到的产物。"

**教师**："我们用 Fe + CuSO₄ = FeSO₄ + Cu 画**双线桥**。第一步标变价：Fe 0→+2，Cu +2→0。第二步连双线——箭头必须**从反应物同种元素指向产物同种元素**，Fe 指 Fe、Cu 指 Cu，不能跨元素！第三步注得失：上方 Fe→Fe 写'失去 2e⁻，化合价升高，被氧化'；下方 Cu→Cu 写'得到 2e⁻，化合价降低，被还原'。第四步查电子守恒：失 2e⁻=得 2e⁻。**单线桥**只画一条线，从还原剂指向氧化剂：Fe ──2e⁻──→ Cu²⁺（线上只标电子总数，不标得/失、不标两端角色）。"

**学生（预期，典型错误）**："老师，我把箭头从 Fe 连到了 Cu 那边，因为电子是 Fe 给 Cu 的。""还有，Fe 变了 2 价，电子数不就是 2 个 e⁻ 吗？"

**教师（追问/理答）**："两个典型错误都来了——第一，双线桥的箭头是'同种元素自身'的升降标记，不是电子流动方向，所以 Fe 只能指 Fe、Cu 只能指 Cu，电子流动另有'单线桥'表示；跨元素就乱了。第二，电子数目 = 价态变化数 × **变价原子个数**，这里 1 个 Fe 原子变 2 价，所以 2e⁻；若 2 个 Fe 原子各变 2 价，才是 4e⁻——别把'价态变化数'直接当'电子数'。"

**教师**："再练两个带'部分变价'的。例二：MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O。变价元素：Mn +4→+2（得 2e⁻），Cl 在 HCl 中是 −1，产物 Cl₂ 中 0——但 4 个 HCl 里只有 2 个 Cl 被氧化成 Cl₂，另 2 个 Cl 以 −1 留在 MnCl₂ 中没变价！双线桥：Mn 线'得 2e⁻，降，被还原'，2Cl⁻→Cl₂ 线'失 2e⁻，升，被氧化'，总转移 2e⁻。例三（歧化）：Cl₂ + 2NaOH = NaCl + NaClO + H₂O，Cl₂ 中 Cl 0 既降到 −1（NaCl）又升到 +1（NaClO），双线桥从同一 Cl₂ 分别指向 NaCl 中的 Cl(−1) 与 NaClO 中的 Cl(+1)，各转移 1e⁻ 共 2e⁻——这正是'同种元素既升又降'的歧化表征。"

**教师**："再给第四个例子——铜与浓硝酸：Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O。变价：Cu 0→+2（失 2e⁻），N 在 HNO₃ 中 +5→NO₂ 中 +4（得 1e⁻×2 个 N）。双线桥：Cu→Cu²⁺ 失 2e⁻、升、被氧化；2 个 N(+5)→2 个 N(+4) 共得 2e⁻、降、被还原。注意：4 个 HNO₃ 中只有 2 个被还原成 NO₂，另 2 个以 NO₃⁻ 形式留在 Cu(NO₃)₂ 中没变价——这又是'部分变价'。双线桥文字图：Cu 线'失 2e⁻ 升 被氧化'、N 线'得 2e⁻ 降 被还原'，二者在 2e⁻ 处守恒。"

**【双线桥 vs 单线桥 对比表】**（投影，避免混用）：

| 维度 | 双线桥 | 单线桥 |
|---|---|---|
| 线条数 | 两条（同种元素各一条） | 一条 |
| 箭头方向 | 反应物某元素 → 产物同种元素 | 还原剂 → 氧化剂 |
| 标注内容 | 失/得 e⁻×n、价升/降、被氧化/还原 | 仅标转移电子总数 e⁻ |
| 表达重点 | 谁升谁降、各元素电子得失 | 电子从哪里转移到哪里 |
| 能否跨元素 | 绝不可（必须同种元素） | 本就跨物质（还→氧） |
| 守恒检查 | 失电子总数 = 得电子总数 | 线上数目 = 总转移数 |

**学生（预期，典型错误）**："老师，FeS₂ 里 S 是不是 −2？和 Na₂S 一样？""Na₂O₂ 我按 O −2 算出来 Na 居然 +4，肯定哪里错了。"

**教师（追问/理答）**："两个都踩在'默认价态'的坑里。FeS₂ 是过硫根 S₂²⁻，两个 S 共用一对电子、整体 −2，所以每个 S 是 −1，不是硫化物里的 −2；Na₂O₂ 是过氧键 O−O，O 是 −1 不是 −2，你用 −2 去算当然得到 Na 为 +4 的荒谬结果——一旦算出金属正价超过其常见最高价，立刻回头检查过氧键！这正是氧化数'形式电荷'本性：它服从代数和规则，不服从你的直觉。"

**【常见氧化数特例汇总表】**（贴于学案背面，随时查）：

| 物质 | 关键元素 | 氧化数 | 易错提醒 |
|---|---|---|---|
| Fe₃O₄ | Fe | 平均 +8/3（1×+2 + 2×+3） | 不可写成 +2 或 +3 单一值 |
| FeS₂ | S | −1（过硫根 S₂²⁻） | 非 −2 |
| Na₂O₂ / H₂O₂ | O | −1（过氧键） | 非 −2 |
| K₂Cr₂O₇ / CrO₃ | Cr | +6 | 最高价，只具氧化性 |
| KMnO₄ | Mn | +7 | 酸性中还原为 +2 |
| NH₄NO₃ | N | −3（铵根）与 +5（硝酸根） | 同一物质两价态 |
| H₂C₂O₄ | C | +3（平均） | 有机酸，用代数和 |
| CH₃CH₂OH | C | −2（平均；CH₃ 上 −3、CH₂OH 上 −1） | 有机物按 C 平均算 |
| KClO₃ / KClO | Cl | +5 / +1 | 含氧酸根高价 |

**学生（预期，巩固提问）**："老师，那 H₂O 里 H 是 +1、O 是 −2，可金属氢化物 NaH 里 H 怎么成 −1 了？"

**教师（追问/理答）**："好问题，这正是规则④ 的边界——H 通常 +1，但和电负性比它大的金属（如 Na）成键时，电子偏向 H，于是 H 显 −1（如 NaH、CaH₂）。同理，O 通常 −2，但和 F 成键（OF₂）时 O 显 +2。规则要记'通常'，更要记住'例外来自电负性'——氧化数是按电负性分配电子的形式结果，不是死板标签。"

## 八、作业布置

### 必做

1. **题6**（见 [[高中化学必修一-习题精选]]）：用双线桥标出 MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O 的电子转移，并指认氧化剂、还原剂。
   - 解答：Mn +4→+2 得 2e⁻（MnO₂ 氧化剂）；2 个 Cl⁻(−1)→Cl₂(0) 失 2e⁻（HCl 还原剂，4 个 HCl 中仅 2 个被氧化）；总转移 2e⁻；MnCl₂ 还原产物、Cl₂ 氧化产物。
2. 判断下列反应是否为氧化还原反应，若是请指出化合价变化的元素与升降方向：
   ① 3O₂ = 2O₃；② CaO + H₂O = Ca(OH)₂；③ 2H₂O₂ = 2H₂O + O₂↑；④ Zn + H₂SO₄ = ZnSO₄ + H₂↑。
   - 解答：① 不是（同素异形体转化，无价变）；② 不是；③ 是（O −1→−2 与 0，歧化）；④ 是（Zn 0→+2 升，H +1→0 降）。

### 选做

3. **氧化数计算（5 物质，写过程）**：Fe₃O₄ 中 Fe 平均氧化数；Na₂S₂O₃ 中 S 平均氧化数；H₂C₂O₄ 中 C 平均氧化数；CH₃CH₂OH 中 C 平均氧化数；K₂Cr₂O₇ 中 Cr 氧化数。
   - 提示：Fe₃O₄ → (2×4 + 3x = 0) → x=+8/3；Na₂S₂O₃ → (+2 + 3×(−2) + 2x = 0) → x=+2；H₂C₂O₄ → (+2 + 4×(−2) + 2x = 0) → x=+3；CH₃CH₂OH（C₂H₆O）→ (2x + 6 − 2 = 0) → x=−2；K₂Cr₂O₇ → (+2 + 7×(−2) + 2x = 0) → x=+6。
   - 分步详解：① Fe₃O₄ 视为 FeO·Fe₂O₃，含 1 个 Fe²⁺ 与 2 个 Fe³⁺，平均氧化数 (2+3+3)/3 = +8/3；② Na₂S₂O₃（硫代硫酸钠）结构等价于把 Na₂SO₄ 中一个 O 换成 S，故一个 S 为 +5、一个 S 为 −1，平均 +2；③ H₂C₂O₄ 中两个 C 等价，2x + 2 + (−8) = 0 ⇒ x = +3；④ CH₃CH₂OH 用整体代数和，2x + 6×(+1) + (−2) = 0 ⇒ x = −2（若拆开：CH₃ 上 C 连 3H 与 1C，氧化数 −3；CH₂OH 上 C 连 2H、1C、1O，氧化数 −1，平均仍是 −2）；⑤ K₂Cr₂O₇ 中 Cr₂O₇²⁻ 整体 −2，2x + 7×(−2) = −2 ⇒ x = +6。
4. 对反应 Cl₂ + 2NaOH = NaCl + NaClO + H₂O 分别画出双线桥与单线桥，并说明两条线各表示什么、为什么双线桥不能跨元素连接。
