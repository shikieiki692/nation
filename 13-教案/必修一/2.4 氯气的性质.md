## 一、课标对应

- **内容要求**：结合真实情境中的应用实例或通过实验探究，了解氯及其重要化合物的主要性质，认识其在生产、生活中的应用和对生态环境的影响。能从物质类别和元素价态的视角，依据氧化还原反应原理预测并解释氯单质的化学性质。
- **本课在章节中的定位**：继 2.1–2.3 钠及其化合物之后，本章转入"卤素代表"Cl₂。钠系侧重"强还原、碱性与盐"，氯系侧重"强氧化、歧化与含氧酸/次氯酸盐"，二者共同构成"典型金属 + 典型非金属"的完整元素化合物研究范式，为后续卤素递变与定量制备奠基。
- **学业质量水平**：必修水平 2——能依据元素化合物的物质类别和化合价列举典型代表物，能用化学方程式、离子方程式正确表示其主要化学性质；能从类别、价态角度预测氯单质的反应并设计简单实验验证；能初步分析氯水多粒子体系中的离子反应与氧化还原关系。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（由 Cl 原子结构 3s²3p⁵、最外层 7e⁻ 预测其强氧化性、非金属性，建立"结构→性质"认知链）；
  2. **变化观念与平衡思想**（认识 Cl₂ + H₂O ⇌ HCl + HClO 是可逆歧化、氯水新制与久置是动态平衡过程）；
  3. **证据推理与模型认知**（用"歧化模型"解释 Cl₂ 与 H₂O/碱反应，用"成分归属"把氯水的酸性/漂白性/氧化性分别落到具体粒子）；
  4. **科学探究与创新意识**（设计"干燥 Cl₂ 能否漂白"对比实验，训练变量控制与证据获取）；
  5. **科学态度与社会责任**（以一战化学武器史实做安全教育，联系自来水消毒、84 与洁厕灵误混中毒等真实议题）。

## 二、学情分析（本课时）

**【课前诊断·4 处典型误解预判】**

学生在初三已学过"非金属""燃烧"等概念，对 Cl₂ 的"黄绿色、有毒"有粗略生活印象（如消毒水气味），并初步接触过燃烧（H₂ 在 Cl₂ 中燃烧的条件特殊）。本课新难点有四：一是 Cl₂ 强氧化性带来的"高价产物"规律，学生易把 Cl₂ 与稀 HCl 混淆，误以为 Fe 与 Cl₂ 生成 FeCl₂（其实无论 Fe 是否过量都只到 +3 价 FeCl₃）；二是氯水"多粒子共存"的复合体系，学生误以为有效漂白成分是 Cl₂ 本身；三是 HClO 漂白"永久不可逆"，与 SO₂ 的"可逆漂白"本质不同，学生易混为一谈；四是干燥 Cl₂ 不能漂白却对湿润布条有漂白作用，反直觉。典型误解：① Fe + Cl₂ → FeCl₂；② 干燥 Cl₂ 能漂白有色布条；③ 氯水的有效成分是 Cl₂；④ HClO 漂白同 SO₂ 一样可逆。对策：以"原子结构→强氧化性"主线统一解释高价产物；用对比实验（干燥 vs 湿润布条、石蕊先红后褪）制造冲突并归因到 HClO；用"成分归属表"把酸性/漂白/氧化性分别落到 H⁺ / HClO / 整体氧化性，彻底纠正三大误区。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"由 Cl 原子结构（3s²3p⁵，最外层 7e⁻）预测其强氧化性"活动，培养**宏观辨识与微观探析**素养：建立"结构（最外层 7e⁻）→ 易得 1e⁻ 成 Cl⁻ → 强氧化性、非金属性"的微观认知链。
- 通过建构 Cl₂ 与金属/非金属/水/碱的反应网络，培养**变化观念与平衡思想**素养：认识 Cl₂ + H₂O 是可逆歧化、氯水体系处于动态平衡（新制⇄久置）。
- 通过"氯水成分归属"与"Cl₂ 与碱歧化"模型分析，培养**证据推理与模型认知**素养：能用歧化模型解释价态变化，用粒子归属解释宏观现象。
- 通过设计"干燥 Cl₂ 能否漂白"对比实验并论证"漂白需 HClO"，培养**科学探究与创新意识**素养：体会变量控制与证据驱动的探究路径。
- 通过一战化学武器史实安全教育、84 与洁厕灵误混中毒分析、自来水消毒原理，培养**科学态度与社会责任**素养：形成"化学双刃剑、安全为先"的社会责任感。

### 3.2 学习目标（学生能……，可观测）

- 能**从 Cl 原子结构**说明其强氧化性来源（最外层 7e⁻、易得 1e⁻ 成 Cl⁻），并据此预测 Cl₂ 与金属反应"一律生成高价态氯化物"。
- 能**正确书写** Cl₂ 与 Na、Fe、Cu、H₂、P、H₂O、NaOH 的反应方程式，描述对应实验现象（烟/雾/火焰），特别是 Fe 与 Cl₂ 只生成 FeCl₃。
- 能**说出新制氯水的成分**（3 分子：Cl₂、HClO、H₂O；3 离子：H⁺、Cl⁻、ClO⁻，少量 OH⁻），并解释"酸性谁负责、漂白谁负责、氧化性谁负责"。
- 能**解释 HClO 的弱酸性（弱于 H₂CO₃）与永久不可逆漂白**，并对比 SO₂ 的可逆漂白说明本质区别。
- 能**设计对比实验**证明"干燥 Cl₂ 不漂白、漂白需 HClO"，并能写出 Cl₂ 与冷/热 NaOH 的歧化方程式。

## 四、教学重难点

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | Cl₂ 与金属反应一律生成高价氯化物（Fe→FeCl₃、Cu→CuCl₂、Na→NaCl） | 学生用"稀 HCl 弱氧化性→Fe²⁺"的直觉误推 Cl₂ | 对比 Cl₂（强氧化）与稀 HCl（弱氧化）氧化性差异；强调"无论 Fe 是否过量，Cl₂ 都把它氧化到 +3" | 能正确写 2Fe + 3Cl₂ = 2FeCl₃ 并说明"只到 +3" |
| 重点 | Cl₂ 与 H₂O 可逆歧化及氯水三分子三离子成分 | 初中生不会处理"多种粒子共存"的复合体系，易把 Cl₂ 当唯一有效成分 | 用矿泉水瓶对比实验（注水变瘪、注 NaOH 黄绿色褪）证反应发生；成分归属表把宏观性质落到具体粒子 | 能写出氯水成分并能答"酸性/H⁺、漂白/HClO、氧化性/Cl₂+HClO" |
| 重点 | HClO 弱酸性 + 永久不可逆漂白，与 SO₂ 可逆漂白对比 | 学生把"漂白"一律当成 SO₂ 型可逆，忽略氧化性破坏色素结构 | 以石蕊先红后褪、干燥布条对比实验归因；列表对比 HClO（氧化破坏，不可逆）vs SO₂（加合，可逆） | 能说出二者本质差异并举例 |
| 难点 | Cl₂ 与碱歧化（冷→NaClO，热→NaClO₃），承接第一章 1.4 歧化规律 | 不理解"温度改变歧化产物"，未把本课与第一章氧化还原歧化打通 | 从电子转移（0→−1、0→+1 / 0→+5）分析；点明承接 1.4；整段配平热碱方程（标注价态变化） | 能双写冷/热两式并标注价态变化 |
| 难点 | 干燥 Cl₂ 不漂白、漂白需 HClO（反直觉） | "有毒黄绿色气体"外表让人直觉它直接腐蚀/漂白 | 设计对比实验：干燥布条+干燥 Cl₂ 不褪 vs 湿润布条+干燥 Cl₂ 褪；追问"差别在哪儿"→水生成了 HClO | 能独立说出"干燥 Cl₂ 无 HClO 故不漂白" |
| 难点 | 氧化性递变 Cl₂ > Br₂ > I₂ 的初步建立（为 2.5 铺垫） | 尚未系统学卤素，仅从 Cl 推不出递变 | 以"同族从上到下得电子能力减弱"初步给出递变，标明"2.5 展开"不超纲 | 能复述 Cl₂ > Br₂ > I₂ 并说出依据（非金属性递减） |

> 说明：本课为 Cl₂ 性质主体新授课，密度大；若校情需放慢，可将"与碱歧化/应用"移至次课时衔接 2.5，本教案保留单课时完整设计，重难点优先展开。

**导入**

**教师**："1774 年，瑞典化学家舍勒把 MnO₂ 和浓盐酸一起加热，得到了一种黄绿色的气体——他以为这是'含氧的盐酸'。直到 1810 年，戴维用实验证明它不是化合物，而是一种新元素，命名为 Chlorine（黄绿色之意）。但 101 年后的 1915 年，一战伊普尔战场上，这种气体被制成毒气弹，造成大规模伤亡。所以今天学 Cl₂，既要看到它的有用，也要敬畏它的危险。"

**学生（预期）**："氯气有毒，我们实验中怎么保证安全？"

**教师（追问/理答）**："问得好。Cl₂ 密度比空气大、有毒，实验室用 NaOH 溶液吸收尾气，演示实验都在通风橱进行。现在我们从'结构'预测它的性质：Cl 的原子结构是 3s²3p⁵，最外层 7 个电子，只差 1 个就满壳层——所以它**极容易得到 1 个电子变成 Cl⁻**，表现出很强的**氧化性**和非金属性。记住这句话：强氧化性，是 Cl₂ 所有化学性质的'总开关'。"

**研究方法回扣（双轴）**：我们沿用第一章的方法——**类别视角 × 价态视角**。从类别看，Cl₂ 是"非金属单质、卤素代表"；从价态看，Cl 在 Cl₂ 中为 0 价，处在"中间价态"区间（上可升到 +1/+3/+5/+7，下可降到 −1），因此既有氧化性又有还原性，但**以氧化性为主**（因最外层 7e⁻ 极易得电子）。本课所有反应，都能用"它得电子变 Cl⁻（氧化别人）"这一条主线串起来。这正是第一章"分类观 + 转化观 + 价态观"在元素化合物中的落地。

**探究 1（物理性质 + 与金属反应）**

**教师**："先读数据卡：Cl₂ 是黄绿色气体、刺激性气味、有毒（空气中浓度约 1000 ppm 即 0.1% 短时致死）、密度比空气大（Mr=71 > 29）、1 体积水约溶 2 体积 Cl₂（1:2）、易液化（−34.6 ℃ 即液化为黄绿色油状液体）。下面看它和金属的反应——因为强氧化性，Cl₂ 一律把金属氧化到**最高价或常见高价**。"

| 反应 | 方程式 | 实验现象 | 宏—微—符 |
|---|---|---|---|
| 与 Na | 2Na + Cl₂ = 2NaCl | 剧烈燃烧，生成**白烟**（NaCl 固体小颗粒） | 宏观白烟 / 微观 Na 失 e⁻、Cl₂ 得 e⁻ / 符号 2Na + Cl₂ = 2NaCl |
| 与 Fe | 2Fe + 3Cl₂ = 2FeCl₃ | 红热铁丝在 Cl₂ 中燃烧，生成**棕褐色烟**（FeCl₃） | 宏观棕褐烟 / 微观 Fe 失 3e⁻→Fe³⁺ / 符号 2Fe + 3Cl₂ = 2FeCl₃ |
| 与 Cu | Cu + Cl₂ = CuCl₂ | 红热铜丝在 Cl₂ 中燃烧，生成**棕黄色烟**（CuCl₂） | 宏观棕黄烟 / 微观 Cu 失 2e⁻→Cu²⁺ / 符号 Cu + Cl₂ = CuCl₂ |

**教师**："关键规律——Cl₂ 强氧化性 → 一律生成高价氯化物。Fe 在这里只生成 FeCl₃，**无论 Fe 是否过量**，都不生成 FeCl₂。这和稀 HCl 完全不同：稀 HCl 中只是 H⁺ 弱氧化，Fe + 2HCl = FeCl₂ + H₂↑，产物是 Fe²⁺。氧化剂越强，把 Fe 推得越'高'。"

**电子转移与价态分析（宏—微—符贯通）**

从氧化还原视角看，Cl₂ 中 Cl 为 0 价，反应中 Cl₂ 得 2e⁻ 变成 2Cl⁻（被还原），金属失电子被氧化。以 Fe 为例：2Fe + 3Cl₂ = 2FeCl₃，每 1 mol Fe 失 3 mol e⁻（Fe → Fe³⁺），每 1 mol Cl₂ 得 2 mol e⁻（Cl₂ → 2Cl⁻），总电子转移 6 mol e⁻——这正是第一章"化合价升降守恒"的实例。

| 反应 | 金属失电子 | Cl₂ 得电子 | 产物价态 | 宏观"烟"的成因 |
|---|---|---|---|---|
| 2Na + Cl₂ = 2NaCl | Na − e⁻ → Na⁺ | Cl₂ + 2e⁻ → 2Cl⁻ | Na(+1), Cl(−1) | NaCl 白色固体小颗粒悬浮 |
| 2Fe + 3Cl₂ = 2FeCl₃ | Fe − 3e⁻ → Fe³⁺ | 3Cl₂ + 6e⁻ → 6Cl⁻ | Fe(+3), Cl(−1) | FeCl₃ 棕褐色固体小颗粒 |
| Cu + Cl₂ = CuCl₂ | Cu − 2e⁻ → Cu²⁺ | Cl₂ + 2e⁻ → 2Cl⁻ | Cu(+2), Cl(−1) | CuCl₂ 棕黄色固体小颗粒 |

"烟"是**固体小颗粒**分散在空气中（区别于"雾"——小液滴）。Cl₂ 与金属反应生成的氯化物多为固体，故现象是"烟"；而 Cl₂ 与 H₂ 生成的 HCl 遇水蒸气成盐酸小液滴，才是"雾"。这一字之差，正是宏—微—符表征的落脚点。

**探究 2（与非金属反应，含逐字稿②）**

**教师**："Cl₂ 也能和某些非金属反应。最经典的是和 H₂：H₂ 在 Cl₂ 中能'安静燃烧'，发出**苍白色火焰**，瓶口出现**白雾**（HCl 气体遇水蒸气形成盐酸小液滴）：H₂ + Cl₂ = 2HCl（点燃）。但如果把 H₂ 和 Cl₂ 混合后再**光照**，会**爆炸**：H₂ + Cl₂ = 2HCl（光照）。条件不同，剧烈程度天差地别——点燃时反应受限于气体接触面、平稳进行；光照引发链反应、瞬时大量放热导致气体体积急剧膨胀而爆炸。这也提示我们：可燃性气体与 Cl₂ 混合需严防光照。

另外红磷也能和 Cl₂ 反应，且体现 Cl₂ 的'量'对产物的影响：
- 氯气不足：2P + 3Cl₂ = 2PCl₃（无色液体三氯化磷，空气中发白雾，因遇水蒸气水解）
- 氯气过量：PCl₃ + Cl₂ = PCl₅（白色固体五氯化磷）

PCl₃（P 为 +3）继续被 Cl₂ 氧化到 PCl₅（P 为 +5），再次印证 Cl₂ 的强氧化性把非金属也推到较高价态。注意磷用**红磷**（白磷易自燃、危险），演示实验取红磷更安全。"

**逐字稿②（Fe 与 Cl₂ 为何只到 +3，对比稀 HCl）**

**教师**："有同学课前问我：'Fe 和 Cl₂ 反应，要是 Fe 加多了，会不会像 Fe 和稀 HCl 那样出 FeCl₂？'大家先猜。"

**学生（预期，典型错误）**："Fe 过量的话应该生成 FeCl₂ 吧？多余的 Fe 会把 Fe³⁺ 还原成 Fe²⁺。"

**教师（追问/理答）**："这是个很聪明的猜测，但 Cl₂ 的情况不是这样。注意区分两件事：第一，稀 HCl 是 H⁺ 在氧化 Fe，H⁺ 氧化性弱，只能把 Fe 推到 +2，即 Fe + 2HCl = FeCl₂ + H₂↑；第二，Cl₂ 是比 H⁺ 强得多的氧化剂，它一旦接触 Fe，直接把 Fe 氧化到最高可达的 +3 价——2Fe + 3Cl₂ = 2FeCl₃，**无论 Fe 是否过量都只有 FeCl₃**。因为即使有多余 Fe，在干燥 Cl₂ 体系里也没有'水'让 Fe 和 Fe³⁺ 发生归中（Fe + 2Fe³⁺ = 3Fe²⁺ 需要水溶液环境）。所以结论锁死：Cl₂ 与 Fe → 只生成 FeCl₃。这就是'强氧化性→高价'最硬的一条。"

**探究 3（与水反应 + 氯水成分，含逐字稿①）**

**教师**："Cl₂ 能溶于水，但不仅仅是'溶解'——它会和水发生反应。看矿泉水瓶实验：集满 Cl₂ 的瓶子注入少量水，盖紧振荡，瓶子变瘪、黄绿色变浅，说明 Cl₂ 被消耗了；再注入 NaOH 溶液振荡，黄绿色几乎褪尽，说明发生了反应。"

**教师**："Cl₂ 与水的反应是**可逆的歧化反应**：Cl₂ + H₂O ⇌ HCl + HClO。这里 Cl 从 0 价既降到 −1（成 Cl⁻）又升到 +1（成 HClO），同一元素化合价有升有降，正是第一章 1.4 讲的**歧化**。新制氯水因此是一个'多粒子共存'的复合体系：

- **3 种分子**：Cl₂、HClO、H₂O
- **3 种离子**：H⁺、Cl⁻、ClO⁻（还有少量 OH⁻）

也就是说，氯水里既有 Cl₂、又有 HClO、又有盐酸成分。那么——它的各种性质分别'归谁负责'？"

**氯水性质成分归属表**

| 宏观性质 | 负责粒子 | 说明 |
|---|---|---|
| 酸性（使石蕊变红） | H⁺（来自 HCl 与 HClO 电离） | 氯水显酸性，pH < 7 |
| 漂白性（使有色物质褪色） | HClO（次氯酸） | 强氧化性氧化破坏色素，**永久不可逆** |
| 氧化性（杀菌、氧化 I⁻ 等） | Cl₂ 与 HClO 共同承担 | 二者均有强氧化性 |
| 黄绿色 | 溶解的 Cl₂ 分子 | Cl₂ 本身黄绿色 |

**教师**："注意一个致命误区：氯水的有效漂白成分**不是 Cl₂，而是 HClO**。Cl₂ 只是'原料'，真正干活漂白的是它和水反应生成的 HClO。"

**新制 vs 久置氯水（动态平衡链）**

新制氯水处于 Cl₂ + H₂O ⇌ HCl + HClO 的可逆平衡中。但 HClO 不稳定，**见光易分解**：2HClO = 2HCl + O₂↑（光照）。这一分解不断消耗 HClO，又推动平衡持续右移，最终 Cl₂ 几乎全部转化为 HCl，氯水就"退化"成稀盐酸——黄绿色消失、漂白性丧失、酸性略有增强（H⁺ 增多）。理解这条链，就理解了"为什么氯水要现用现配、棕色瓶避光保存"。

| 对比项 | 新制氯水 | 久置氯水 |
|---|---|---|
| 主要成分 | Cl₂、HClO、H₂O、H⁺、Cl⁻、ClO⁻ | 稀盐酸（H⁺、Cl⁻、H₂O） |
| 颜色 | 黄绿色（溶解的 Cl₂） | 无色 |
| 酸性 | 较强（H⁺ 来自 HCl 与 HClO） | 酸性（H⁺ 增多） |
| 漂白性 | 有（含 HClO） | 无（HClO 已分解） |
| 保存 | 棕色瓶、避光、冷暗处 | — |

**逐字稿①（氯水使石蕊先红后褪，追问干燥布条对比）**

**教师**："往新制氯水里滴一滴石蕊试液，大家观察——先变红，很快又褪成无色。为什么'先红后褪'？"

**学生（预期）**："先变红是因为有酸，褪色是因为……Cl₂ 漂白？"

**教师（追问/理答）**："前半句对，后半句要改。'先红'是 H⁺ 的酸性；'后褪'是 HClO 的强氧化性把石蕊的色素结构破坏了——是**永久漂白**，不是 Cl₂ 直接漂。那问题来了：如果换成**干燥的 Cl₂** 通到**干燥的有色布条**上，布条会褪色吗？"

**学生（预期，典型错误）**："会吧，Cl₂ 不是有漂白性吗？"

**教师（追问/理答）**："我们来做对比实验：左边是干燥布条 + 干燥 Cl₂，右边是湿润布条 + 干燥 Cl₂。结果——左边不褪，右边褪。差别就在'水'：干燥体系里 Cl₂ 没和水反应生成 HClO，就没有漂白剂；一加水，Cl₂ + H₂O → HClO，HClO 才漂白。所以铁律：**干燥 Cl₂ 不漂白，漂白必须靠 HClO**。"

**探究 4（HClO 性质 + 干燥 Cl₂ 不漂白）**

**教师**："把 HClO 单独拎出来看，它有两个关键性质。第一，**弱酸性**——它比碳酸还弱。证据：向 NaClO 溶液通 CO₂，能生成 HClO：NaClO + CO₂ + H₂O → HClO + NaHCO₃。'强酸制弱酸'反过来推，说明 H₂CO₃ 比 HClO 强，所以 CO₂（弱酸酐）能把 HClO 从盐里'挤'出来。第二，**强氧化性漂白，永久不可逆**——HClO 氧化有色物质时直接破坏其分子结构，色素再也回不来。

这要和 SO₂ 的漂白严格区分：

| 对比项 | HClO 漂白 | SO₂ 漂白 |
|---|---|---|
| 原理 | 强氧化，**破坏**色素结构 | 与色素**加合**生成无色化合物 |
| 是否可逆 | **不可逆**（永久） | **可逆**（加热/久置复原） |
| 范围 | 绝大多数有色物质 | 部分有机色素（如品红） |
| 本质 | 氧化还原反应 | 非氧化还原（加合） |

一句话：HClO 是'毁掉'色素，SO₂ 是'暂时藏起'色素，二者本质不同。"

**探究 5（与碱歧化 + 氧化性递变 + 应用）**

**教师**："Cl₂ 和碱的反应，是第一章 1.4 歧化规律的直接应用。冷碱（常温稀 NaOH）：Cl₂ + 2NaOH = NaCl + NaClO + H₂O，Cl 从 0 歧化为 −1（NaCl）和 +1（NaClO）。但如果用**热碱**，产物会升级："

**前置知识连接（回扣第一章）**：从价态看，冷碱中 Cl(0) → Cl(−1) + Cl(+1)，两个 Cl 原子各得/失 1e⁻，电子守恒；热碱中 Cl(0) → Cl(−1) + Cl(+5)，5 个 Cl(−1) 共得 5e⁻、1 个 Cl(+5) 失 5e⁻，所以系数配成"5NaCl + 1NaClO₃"。这正是第一章"用化合价升降配平氧化还原"的实战。碱性条件让歧化自发（电势图右侧高于左侧），酸性条件则逆向归中——这点 2.5/84 与洁厕灵误混会再用到。

3Cl₂ + 6NaOH(热) = 5NaCl + NaClO₃ + 3H₂O

**教师**："热碱里 Cl 歧化到 +5 价的 ClO₃⁻（NaClO₃）。这就是'温度改变歧化产物'——冷得次氯酸盐，热得氯酸盐。承接第一章：凡是中间价态、电势图右侧高于左侧，就自发歧化。

最后看氧化性递变，为 2.5 做铺垫。卤素同族从上到下，原子半径增大、得电子能力减弱，故氧化性递减：

| 单质 | F₂ | Cl₂ | Br₂ | I₂ |
|---|---|---|---|---|
| 颜色/状态 | 淡黄绿·气 | 黄绿·气 | 深红棕·液 | 紫黑·固 |
| 氧化性 | 最强 | 强 | 中 | 弱 |
| 与 H₂ 反应 | 冷暗爆炸 | 光照爆炸 | 加热反应 | 持续加热可逆 |

所以 **Cl₂ 的氧化性强于 Br₂、I₂**（Cl₂ 能置换 Br⁻、I⁻：Cl₂ + 2Br⁻ = 2Cl⁻ + Br₂）。注意 F₂ 极特殊——它不歧化，而是氧化水：2F₂ + 2H₂O = 4HF + O₂，这点 2.5 会专门讲，本课不展开。

应用上，Cl₂ 的氧化性被大量用于消毒与漂白：
- **自来水消毒**：用 Cl₂ 或 ClO₂ 通入水中，利用氧化性杀灭细菌病毒。ClO₂ 消毒能力约为等质量 Cl₂ 的 2.63 倍，且不生成致癌副产物，是发展方向。
- **84 消毒液**：NaClO 溶液（Cl₂ + 2NaOH = NaCl + NaClO + H₂O 的工业延伸），靠 ClO⁻ 水解/酸化释放 HClO 起杀菌漂白作用。
- **漂白粉**：将 Cl₂ 通入消石灰制得 2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O，是 Ca(ClO)₂ 与 CaCl₂ 的混合物，**有效成分是 Ca(ClO)₂**（不是 CaCl₂）。漂白粉需密封干燥保存，因 Ca(ClO)₂ + CO₂ + H₂O = CaCO₃ + 2HClO，HClO 见光分解导致失效。详细制备与有效氯计算 2.5 展开。

千万记住：**84 消毒液（含 ClO⁻）不能和洁厕灵（含 HCl）混用**，二者在酸性条件下归中放出剧毒 Cl₂：NaClO + 2HCl = NaCl + Cl₂↑ + H₂O。这是第一章氧化还原'归中'在生活中的真实风险。"

**课堂即时检测（3 题快速反馈）**

为检验本课核心是否落地，小结前做 3 道即时检测（口答+举手）：

1. （概念）新制氯水中能使干燥红色布条褪色的粒子是？——**HClO**（而非 Cl₂）。若布条干燥、Cl₂ 也干燥，则不褪。
2. （价态）Fe 在 Cl₂ 中燃烧，Fe 过量时产物是什么？——**FeCl₃**，强调"无论 Fe 是否过量只到 +3"。
3. （歧化）向冷的 NaOH 溶液中通入 Cl₂，产物是 NaCl 和什么盐？——**NaClO（次氯酸钠）**；若加热则得 **NaClO₃（氯酸钠）**，点明温度效应。

三题对应本课三大难点（HClO 漂白、高价产物、歧化温度），全对率达 80% 以上方可进入小结。

**随堂小结：核心口诀与误区速查**

| 易错直觉 | 正确认知 | 判据/反例 |
|---|---|---|
| Fe 与 Cl₂ 生成 FeCl₂ | 一律 FeCl₃，无论 Fe 是否过量 | Cl₂ 强氧化→Fe³⁺；稀 HCl 才是 Fe²⁺ |
| 干燥 Cl₂ 能漂白 | 干燥 Cl₂ 不漂白，漂白需 HClO | 干燥布条+干燥 Cl₂ 不褪，湿润才褪 |
| 氯水有效成分是 Cl₂ | 有效漂白成分是 HClO | 氯水多粒子：酸性/H⁺、漂白/HClO |
| HClO 漂白同 SO₂ 可逆 | HClO 永久不可逆，SO₂ 可逆 | 破坏结构 vs 加合，本质不同 |
| 与碱只生成一种产物 | 冷→NaClO，热→NaClO₃ | 歧化温度效应（承接 1.4） |

**核心口诀**：结构定氧化（3s²3p⁵→强氧化）；高价金属盐（Fe→FeCl₃，Cu→CuCl₂）；氯水三分子三离子，漂白只认 HClO；干燥氯不漂白，遇水生 HClO；冷碱次氯热氯酸，歧化温度说了算。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否由 Cl 原子结构（3s²3p⁵、最外层 7e⁻）说明强氧化性来源，并据此正确写出 Fe→FeCl₃、Cu→CuCl₂、Na→NaCl 且理解"Cl₂ 一律高价、Fe 无论是否过量只到 +3"？典型误区"Fe + Cl₂ → FeCl₂"是否真正破除？
- [ ] 氯水"三分子三离子"成分是否建立，"酸性/H⁺、漂白/HClO、氧化性/Cl₂+HClO"的归属是否能落到具体粒子？"氯水有效成分是 Cl₂"的误区是否纠正？干燥 Cl₂ 不漂白的对比实验是否让其信服？
- [ ] HClO 弱酸性（弱于 H₂CO₃）与永久不可逆漂白是否讲透？与 SO₂ 可逆漂白的"破坏结构 vs 加合、氧化还原 vs 非氧化还原"本质区别是否被理解，而非仅记结论？
- [ ] Cl₂ 与碱冷/热歧化是否打通第一章 1.4 歧化规律，热碱方程（3Cl₂ + 6NaOH(热) = 5NaCl + NaClO₃ + 3H₂O）配平与价态变化是否清楚？氧化性递变 Cl₂ > Br₂ > I₂ 是否为 2.5 铺垫到位？
