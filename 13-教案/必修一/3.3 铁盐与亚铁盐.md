# 教案：3.3 铁盐与亚铁盐（必修第一册 第三章 铁 金属材料）

> **课时元信息**：第 3 章 / 3.3 铁盐与亚铁盐 / 第 3 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[铁及其化合物]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：铁系元素的"性质对比 + 检验 + 转化"收口课。以 Fe²⁺（浅绿，还原性为主）/ Fe³⁺（黄棕，氧化性为主）为核心，串联**检验方法**、**铁三角转化**、**真实应用**三条主线，用"价-类二维图（价态 × 类别）"作为贯穿全课的认识模型，闭合前两课（3.1 铁单质、3.2 氧化物与氢氧化物）建立的 Fe⁰/Fe²⁺/Fe³⁺ 变价网络，并为 3.4 合金、3.5–3.6 铝系及后续"物质结构·元素周期律""电化学腐蚀"埋下接口。

---

## 一、课标对应

- **内容要求**：能依据物质类别和元素价态列举铁元素的典型代表物（Fe²⁺、Fe³⁺ 两类铁盐）；能用离子反应、氧化还原反应对 Fe²⁺/Fe³⁺ 的相关反应进行分类和分析说明；能从物质类别、元素价态角度预测 Fe²⁺/Fe³⁺ 的化学性质和变化，设计实验（KSCN 检验、铁粉还原、氯水氧化）进行初步验证；能利用二者性质设计方案完成常见含铁物质的检验、鉴别、转化、分离与提纯。
- **学业质量水平**：必修水平 2——能基于"铁盐类别 × Fe 价态（+2/+3）"预测二者氧化还原性与反应产物；能正确书写 Fe²⁺/Fe³⁺ 检验与双向转化的化学方程式、离子方程式；能解释 Fe²⁺ 易氧化、Fe³⁺ 易水解的本质，并能用于补铁剂、废水除铁、印刷电路等真实情境的分析。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从 Fe²⁺ 浅绿、Fe³⁺ 黄棕的宏观颜色，追到 d⁶/d⁵ 电子构型与配位显色的微观根源，建立"颜色—离子—价态"表征链）；
  2. **变化观念与平衡思想**（认识 Fe²⁺ ⇌ Fe³⁺ 可双向转化、转化方向由所加氧化剂/还原剂决定，建立"条件决定方向"的动态转化观）；
  3. **证据推理与模型认知**（用"价-类二维图"统一解释检验与转化；用氧化还原反应模型判断氧化剂/还原剂强弱与产物价态）；
  4. **科学探究与创新意识**（设计 Fe²⁺/Fe³⁺ 检验与铁三角转化的分组实验，体会"现象—证据—结论"的推断逻辑）；
  5. **科学态度与社会责任**（通过补铁剂维 C 同服、工业废水除铁、印刷电路腐蚀等体会化学服务生活与生产的价值，落实"科学态度与社会责任"）。

### 1.1 课标细目与课时落点对照

| 课标表述 | 本课对应落点 | 达成方式 |
|---|---|---|
| 依类别与价态列举代表物 | Fe²⁺（亚铁盐，还原性为主）、Fe³⁺（铁盐，氧化性为主） | 对比表落点"价-类二维图" |
| 用离子/氧化还原分类反应 | 与 SCN⁻（配位，非 redox）、与 OH⁻（复分解）、与 Cl₂/Cu（redox） | 逐反应标类型与价态变化 |
| 预测性质并设计验证 | KSCN 检验 Fe³⁺、铁氰化钾检验 Fe²⁺、氯水氧化/铁粉还原转化 | 分组实验探究 + 现象记录 |
| 利用性质设计方案（检验/转化/分离） | 补铁剂检验、废水除 Fe²⁺（氧化→沉淀）、印刷电路腐蚀 | 真实情境方案设计 |
| 物质转化路径（类别×价态视角） | 铁三角 Fe⁰/Fe²⁺/Fe³⁺ 闭合转化网络 | 转化网络 + 氧化剂/还原剂表 |

**本课在单元中的地位**：3.1/3.2 已完成铁单质、铁的氧化物与氢氧化物的性质建构，本课进入"铁盐/亚铁盐"层级——Fe²⁺ 与 Fe³⁺ 是铁变价的核心存在形式，既是"价-类二维图"方法在铁系上的直接应用，又是补铁剂、净水、印刷电路等工业生活的载体。本课与前两课通过"Fe 变价（Fe⁰→Fe²⁺/Fe³⁺→Fe(OH)₂/Fe(OH)₃）"形成铁系完整网络，是全章"铁三角"模型闭合的枢纽课。

## 二、学情分析（本课时）

学生在 3.1 已学铁单质与不同氧化剂反应产物价态不同（Cl₂ 强氧化到 +3、S 弱氧化到 +2），在 3.2 已学 Fe(OH)₂ 白色→灰绿→红棕的氧化现象，初步感知"Fe²⁺ 容易被氧化"。但到铁盐层面，学生仍多为"名词 + 零散现象"记忆，未建立系统的检验与转化框架。本课新难点有四：一是**混淆 Fe²⁺/Fe³⁺ 稳定性**——凭"Fe³⁺ 电荷高、更'强'"误判 Fe³⁺ 比 Fe²⁺ 更稳定，忽略水溶液 E°=0.771 V 下 Fe²⁺ 才是还原剂、易氧化；二是**把"Fe³⁺ 一定生成 Fe²⁺ 才是还原产物"绝对化**——误以为 Fe³⁺ 与任何还原剂都只降到 +2，不懂还原剂强弱不同产物可能不同（如强还原剂 Mg 可将 Fe³⁺ 一路还原到 Fe⁰）；三是**误以为 KSCN 能检验 Fe²⁺**——把"加 KSCN 变红"当成两种离子共有的现象，不懂 KSCN 只对 Fe³⁺ 显血红色、对 Fe²⁺ 无现象；四是**误以为 Fe³⁺ 与 Cu 不反应**——受"金属活动性顺序 Cu 在 Fe 后"干扰，忽略这是 Fe³⁺ 的氧化性而非 Fe 单质的置换。典型误解还把"Fe³⁺ 与 SCN⁻ 反应"当成氧化还原反应。对策：用对比表制造认知冲突，用铁三角图统一转化，用分组实验让现象说话。

为落实框架"误区/易错前置"要求，先列出本课四处典型误解及其对策，作为导入与探究的靶向：

**【课前诊断·4 处典型误解预判】**

| 典型误解 | 正确认识 | 突破策略 |
|---|---|---|
| Fe²⁺ 比 Fe³⁺ 稳定 | 水溶液 E°(Fe³⁺/Fe²⁺)=0.771 V，Fe²⁺ 还原性为主、易氧化为 Fe³⁺；Fe³⁺ 氧化性为主 | 讲电势判据 + 补铁剂维 C 防氧化实例 |
| Fe³⁺ 一定生成 Fe²⁺ 才是还原产物 | 还原剂强弱不同，产物价态不同（强还原剂可到 Fe⁰）；Fe³⁺+Cu→Fe²⁺ 仅因 Cu 还原性适中 | 铁三角图列多还原剂 + 价-类图标纵向落点 |
| KSCN 可检验 Fe²⁺ | KSCN 只对 Fe³⁺ 显血红色；Fe²⁺ 加 KSCN 无现象，需先加氯水氧化再变红 | 分组实验对比 Fe²⁺/Fe³⁺ + KSCN 现象 |
| Fe³⁺ 与 Cu 不反应 | 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺，是 Fe³⁺ 氧化性氧化 Cu，非金属置换 | 印刷电路腐蚀情境 + 方程式配平演示 |

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过对比 Fe²⁺（浅绿）与 Fe³⁺（黄棕）的颜色、氧化还原性、与 SCN⁻/OH⁻/Cl₂ 的反应，培养**宏观辨识与微观探析**素养：建立"宏观颜色 → 离子价态/配位显色 → 符号表达"的表征链，并能从 d⁶/d⁵ 电子构型层面理解显色机理。
- 通过建构 Fe²⁺ ⇌ Fe³⁺ 双向转化网络并分析转化方向（氧化剂/还原剂强弱决定），培养**变化观念与平衡思想**素养：认识铁盐价态转化依赖条件，形成动态、条件化的变化观。
- 通过"价-类二维图"模型（价态纵轴 × 类别横轴）统一解释检验与转化，并用氧化还原电势/氧化性还原性强弱判断产物，培养**证据推理与模型认知**素养。
- 通过设计 Fe²⁺/Fe³⁺ 检验（KSCN、铁氰化钾、NaOH）与铁三角转化（铁粉还原、氯水氧化）的分组实验，培养**科学探究与创新意识**素养：体会"现象—证据—结论"与"条件可控则路径可行"的探究逻辑。
- 通过补铁剂维 C 同服、工业废水除 Fe²⁺（氧化→沉淀）、印刷电路腐蚀、K₂FeO₄ 净水消毒等真实情境，培养**科学态度与社会责任**素养：体会化学在健康、环境与生产中的价值。

### 3.2 学习目标（学生能……，可观测）

- 能**独立填写** Fe²⁺ 与 Fe³⁺ 的对比表（颜色、氧化还原性、与 OH⁻、与 SCN⁻、与 Cl₂ 五栏），并指出每一差异的价态/配位根源。
- 能**正确书写并标注**本课核心方程式：2Fe³⁺ + Fe = 3Fe²⁺、2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺、2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻、5Fe²⁺ + MnO₄⁻ + 8H⁺ = 5Fe³⁺ + Mn²⁺ + 4H₂O、Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ、2Fe³⁺ + 2OH⁻ = Fe(OH)₃↓、Fe²⁺ + 2OH⁻ = Fe(OH)₂↓。
- 能**用 KSCN 法、NaOH 法、铁氰化钾法**检验并鉴别 Fe²⁺/Fe³⁺，说明"Fe²⁺ 加 KSCN 无现象、加氯水变红"的判别证据，并指出 KSCN 只对 Fe³⁺ 显血红色。
- 能**画出"铁三角"转化网络**（Fe⁰/Fe²⁺/Fe³⁺）并标注每条边的氧化剂或还原剂，解释"Fe²⁺→Fe³⁺ 加氧化剂、Fe³⁺→Fe²⁺ 加还原剂"的方向逻辑。
- 能**用价-类二维图**把 Fe、FeO/Fe₂O₃、FeCl₂/FeCl₃、Fe(OH)₂/Fe(OH)₃ 落点，并据此预测陌生含铁物质的检验与转化路径；能说明补铁剂维 C 同服、废水除 Fe²⁺、印刷电路腐蚀的应用原理。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | Fe²⁺ 与 Fe³⁺ 性质系统对比（颜色/氧化还原性/与 OH⁻/SCN⁻/Cl₂） | 仅记零散现象，未建对比框架，易混 | 填对比表 + 宏—微—符三栏；分组实验现场验证 | 能独立完整填出对比表并说差异根源 |

## 六、教学过程（含逐字稿）

| 约 14 分钟 | Fe²⁺/Fe³⁺ 性质对比 + 检验实验 | 填对比表；分组做 KSCN/NaOH/铁氰化钾检验 | 实验+板书 |
| 约 12 分钟 | 铁三角转化探究（逐字稿①） | 分组：铁粉还原 Fe³⁺、氯水氧化 Fe²⁺，画网络 | 实验+PPT |
| 约 8 分钟 | 真实应用（废水除铁/印刷电路/净水） | 情境方案设计 + 价-类图定位（逐字稿②） | 板书+学案 |
| 约 5 分钟 | 深度补点 + 小结作业 | 电势/普鲁士蓝/莫尔盐/菠菜补铁 + 小结 | 板书 |

> 说明：本节以"检验 + 转化"双核心展开，按 45 min 单课时设计，时间块以"分组实验充分展开 + 两处逐字稿"为优先；实际可据校情微调。

**导入**

**教师**："同学们，这是一盒补铁剂——硫酸亚铁片，主治缺铁性贫血。大家看说明书右下角写了一句：'建议与维生素 C 同服，促进吸收'。问题来了：硫酸亚铁里含铁是 Fe²⁺ 还是 Fe³⁺？为什么偏偏要和维 C 一起吃不单独吃？"

**学生（预期）**："应该是 Fe²⁺ 吧？但维 C 是酸性的，难道帮它溶解？"（典型错误：只想到溶解，未想到氧化）

**教师（追问/理答）**："今天学完你会发现——补铁剂里是 Fe²⁺，而 Fe²⁺ 在空气中、在胃里都**容易被氧化成 Fe³⁺**，Fe³⁺ 反而不好吸收。维 C 是还原剂，能把已经氧化的 Fe³⁺ 还原回 Fe²⁺，还能保护 Fe²⁺ 不被氧化。一句话提醒：**Fe²⁺ 并不'稳定'，它恰恰是个'容易被氧化'的离子**。今天我们就用'价-类二维图'这把尺子，把 Fe²⁺ 和 Fe³⁺ 这两类铁盐彻底比清楚，并闭合前两课的'铁三角'。"

**探究 1（Fe²⁺/Fe³⁺ 性质对比 + 检验实验）**

**教师**："先填对比表。Fe²⁺ 浅绿色、以还原性为主；Fe³⁺ 黄棕色、以氧化性为主。看四个反应：
① 与 OH⁻：Fe²⁺ + 2OH⁻ = Fe(OH)₂↓（白色→灰绿→红棕，因被空气氧化）；Fe³⁺ + 3OH⁻ = Fe(OH)₃↓（红棕色）。
② 与 SCN⁻：Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ，生成血红色配合物，这是**检验 Fe³⁺ 最灵敏的方法**；Fe²⁺ 与 SCN⁻ 无现象。
③ 与 Cl₂：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻（Fe²⁺ 被氧化）；Fe³⁺ 与 Cl₂ 不反应。

现在我们分组实验，四支试管：A 装 FeCl₃、B 装 FeSO₄、C 装 FeSO₄ 先加 KSCN、D 装 FeSO₄ 先加 KSCN 再加氯水。请观察现象。"

**学生（预期）**："A 加 KSCN 立刻血红色；B 加 KSCN 没变色；C 直接没色；D 加氯水后变红了！"

**教师（追问/理答）**："对，这就是检验 Fe²⁺ 的关键招：Fe²⁺ 加 KSCN 不变色，但**先加 KSCN 无明显现象、再加氯水变红**，就证明原溶液有 Fe²⁺（氯水把它氧化成了 Fe³⁺，Fe³⁺ 再与 SCN⁻ 显红）。注意氯水别过量——过量会氧化 SCN⁻ 使红色褪去。

还有第三种检验 Fe²⁺ 的专属试剂：**铁氰化钾 K₃[Fe(CN)₆]**（赤血盐），与 Fe²⁺ 生成**滕氏蓝**沉淀；而亚铁氰化钾 K₄[Fe(CN)₆]（黄血盐）与 Fe³⁺ 生成**普鲁士蓝**。深度补点：现代结构分析证明普鲁士蓝和滕氏蓝是同一种物质 KFe[Fe(CN)₆]，只是制备原料不同。课堂我们记'铁氰化钾验 Fe²⁺ 出滕氏蓝'即可。"

**实验现象记录表（学生随堂填写，落实"证据推理"）**

| 实验 | 操作 | Fe³⁺ 现象 | Fe²⁺ 现象 | 推论 |
|---|---|---|---|---|
| 加 KSCN | 各取少量溶液加数滴 KSCN | 血红色（最灵敏） | 无现象 | KSCN 专检验 Fe³⁺ |
| KSCN+氯水 | Fe²⁺ 溶液先 KSCN 后氯水 | — | 先无变、后变红 | 氯水氧化 Fe²⁺→Fe³⁺ 再显红 |
| 加 NaOH | 各取少量溶液加 NaOH | 红棕 Fe(OH)₃↓ | 白→灰绿→红棕 | 二者均出氢氧化物 |
| 加铁氰化钾 | Fe²⁺ 溶液加 K₃[Fe(CN)₆] | — | 滕氏蓝沉淀 | 铁氰化钾专检验 Fe²⁺ |

此表把检验差异一次性实证，直接回应学情中"KSCN 可检验 Fe²⁺"的误解。

**探究 2（铁三角转化探究 + 逐字稿①）**

**教师**："把前两课的变价和今天连起来，就是'铁三角'——Fe⁰、Fe²⁺、Fe³⁺ 三者如何互相转化？先看 Fe²⁺→Fe³⁺（氧化，加氧化剂）：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻；也能被 H₂O₂、O₂、KMnO₄ 氧化，如酸性高锰酸根：5Fe²⁺ + MnO₄⁻ + 8H⁺ = 5Fe³⁺ + Mn²⁺ + 4H₂O（紫红褪去、变黄）。再看 Fe³⁺→Fe²⁺（还原，加还原剂）：2Fe³⁺ + Fe = 3Fe²⁺（加铁粉）、2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（加铜片）。

分组实验：E 管 FeCl₃ 加铁粉振荡、F 管 FeCl₃ 加铜片、G 管 FeSO₄ 通氯水。观察颜色变化。"

**逐字稿①（铁三角方向与条件，认知冲突）**

**教师**："这里有个反直觉的点。有同学说'Fe³⁺ 比 Fe²⁺ 高级、肯定更稳定'。真的是这样吗？看电势：E°(Fe³⁺/Fe²⁺) = 0.771 V。这个 0.771 V 说明什么？"

**学生（预期）**："电荷更高、应该更稳定？"（典型错误：Fe³⁺ 比 Fe²⁺ 稳定）

**教师（追问/理答）**："恰恰相反。0.771 V 是个**正且适中**的电势——它告诉我们 Fe²⁺ 是个不错的还原剂，在水溶液里很容易被空气、氯水氧化成 Fe³⁺；而 Fe³⁺ 是个较弱的氧化剂，能把 Fe、Cu 氧化。所以**Fe²⁺ 并不比 Fe³⁺ 稳定，它恰恰'想变成 Fe³⁺'**。这就是为什么补铁剂要加维 C 保护、配 FeSO₄ 溶液要加酸和铁屑防氧化。

再破第二个误解：'Fe³⁺ 与 Cu 不反应'。看金属活动性顺序，Cu 在 Fe 后面，那是 Fe 单质置换 Cu²⁺ 的逻辑。但这里是 **Fe³⁺ 离子**在氧化 Cu：2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺。借印刷电路板的例子——用 FeCl₃ 溶液'腐蚀'覆铜板，正是靠 Fe³⁺ 把 Cu 氧化溶掉留下电路。所以不是'不反应'，而是**反应的本质是 Fe³⁺ 的氧化性，不是金属置换**。"

**双轴定位（承接第一、二章"类别×价态"方法）**

把 Fe 系落进"价-类二维图"：横轴类别（单质/氧化物/碱/盐），纵轴价态（0/+2/+3）。
- Fe⁰ 在单质行、0 价列；FeO/Fe(OH)₂/Fe²⁺ 盐在 +2 列；Fe₂O₃/Fe(OH)₃/Fe³⁺ 盐在 +3 列。
- **纵向变价态靠氧化还原**：Fe²⁺→Fe³⁺（氧化剂）、Fe³⁺→Fe²⁺（还原剂）、Fe⁰→Fe²⁺/Fe³⁺（与非氧化性酸/氧化性酸）。
- **横向同价态变类别靠离子反应**：Fe²⁺ + 2OH⁻ = Fe(OH)₂↓、Fe³⁺ + 3OH⁻ = Fe(OH)₃↓（复分解，非 redox）。
- 预测：给陌生含铁物先判价态再判类别——若含 Fe²⁺ 必考虑被氧化，若含 Fe³⁺ 必考虑水解与氧化性。

**价-类二维图实操举例（学生随堂练习）**

教师在黑板画出空白二维坐标，请学生把下列物质落点并连线：
① Fe（0 价·单质）→ 与稀 HCl 得 FeCl₂（Fe 落 +2·盐）；
② FeCl₂（Fe²⁺·盐）→ 通 Cl₂ 得 FeCl₃（Fe³⁺·盐，纵向升价，redox）；
③ FeCl₃（Fe³⁺·盐）→ 加 Fe 粉得 FeCl₂（Fe²⁺·盐，纵向降价，redox）；
④ FeCl₃（Fe³⁺·盐）→ 加 NaOH 得 Fe(OH)₃（Fe³⁺·碱，横向变类别，非 redox）。
学生归纳口诀："铁三角走纵轴（redox），同价变类别走横轴（离子反应）"。此练习把前两课 Fe⁰ 与 3.2 的 Fe(OH)₂/Fe(OH)₃ 一并纳入同一张图，实现铁系全网络闭合。

**核心概念的宏—微—符三重表征（落实"宏观辨识与微观探析"）**

| 核心概念 | 宏观现象 | 微观粒子/构型 | 符号表达 |
|---|---|---|---|
| 颜色 | Fe²⁺ 浅绿、Fe³⁺ 黄棕 | [Fe(H₂O)₆]²⁺ 浅绿、[Fe(H₂O)₆]³⁺ 水解黄 | —（配位显色） |
| Fe³⁺ 检验 | KSCN 血红色 | [Fe(SCN)ₙ]³⁻ⁿ 配合物显色 | Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ |
| Fe²⁺ 检验 | 铁氰化钾出滕氏蓝 | KFe[Fe(CN)₆] 沉淀 | 3Fe²⁺ + 2[Fe(CN)₆]³⁻ → Fe₃[Fe(CN)₆]₂↓ |
| Fe²⁺→Fe³⁺ | 浅绿变黄 | Fe²⁺ 失 e⁻ 成 Fe³⁺ | 2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻ |
| Fe³⁺→Fe²⁺ | 黄变浅绿 | Fe³⁺ 得 e⁻ 成 Fe²⁺ | 2Fe³⁺ + Fe = 3Fe²⁺；2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺ |

**探究 3（真实应用 + 逐字稿②）**

**教师**："转化不是纸上谈兵，落地到三个真实情境。
① 工业废水除 Fe²⁺：废水中 Fe²⁺ 易溶、难沉淀；先加氧化剂（如 H₂O₂、通空气）把 Fe²⁺ 氧化成 Fe³⁺，Fe³⁺ 水解生成 Fe(OH)₃ 沉淀，调 pH 沉淀过滤除铁。本质是'氧化升价→水解沉淀'。
② 印刷电路腐蚀：覆铜板用 FeCl₃ 溶液腐蚀，2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺，溶掉不需要的铜留下电路。
③ FeCl₃ 净水：Fe³⁺ 水解 Fe³⁺ + 3H₂O ⇌ Fe(OH)₃(胶体) + 3H⁺，Fe(OH)₃ 胶体吸附悬浮物沉降。
④ 深度：K₂FeO₄（高铁酸钾）中 Fe 为 +6 价，强氧化性可消毒，还原产物 Fe³⁺ 再水解胶体净水，一举两得。"

**逐字稿②（废水除铁方案设计）**

**教师**："现在请你当工程师：含 Fe²⁺ 的工业废水，为什么不能直接加碱沉淀除铁？"

**学生（预期）**："加 NaOH 不就出 Fe(OH)₂ 沉淀了吗？"（典型错误：以为 Fe²⁺ 直接沉淀即可）

**教师（追问/理答）**："Fe(OH)₂ 溶解度比 Fe(OH)₃ 大得多，且 Fe²⁺ 在碱性下仍会被空气氧化成 Fe(OH)₃，沉淀不完全、还夹带氧化过程。规范流程是**先氧化、后沉淀**：先加 H₂O₂（或通空气/Cl₂）把 Fe²⁺ 全部转成 Fe³⁺，再调 pH 让 Fe³⁺ 水解成 Fe(OH)₃ 彻底沉淀。这就是'价-类图'的指导——先把 +2 升到 +3，再利用 Fe³⁺ 易水解、Fe(OH)₃ Ksp 极小除干净。记住顺序：**氧化在前、沉淀在后**。"

**拓展（竞赛衔接，点到即止，必修不超纲）**

- **电势与稳定性**：E°(Fe³⁺/Fe²⁺)=0.771 V，正值说明 Fe²⁺ 在水溶液有还原性；酸性条件下 Fe³⁺ 相对稳定，但碱性下 Fe²⁺ 更易被氧化（Fe(OH)₂ 极不稳定）。这与 3.2 防氧化制备 Fe(OH)₂ 一致。
- **配合物显色再深一层**：邻菲罗啉（phen）与 Fe²⁺ 生成 [Fe(phen)₃]²⁺ 深红色（ferroin，氧化还原滴定指示剂）；[Fe(SCN)]²⁺ 血红色用于鉴 Fe³⁺。普鲁士蓝=滕氏蓝=KFe[Fe(CN)₆]，是 Fe(II)/Fe(III) 混合价态配合物。
- **稳定亚铁盐**：硫酸亚铁铵 (NH₄)₂Fe(SO₄)₂·6H₂O（莫尔盐）因 NH₄⁺ 同离子效应与结晶稳定，是实验室常用的稳定亚铁盐，比 FeSO₄ 不易氧化——配制标准亚铁溶液多用它。

**应用衔接**

**教师**："回到导入——补铁剂与维 C 同服，本质是维 C（还原剂）保护 Fe²⁺ 不被氧化，呼应铁三角 Fe³⁺→Fe²⁺。还有生活误区：都说'菠菜补铁'，其实菠菜里多为 Fe³⁺（植物草酸铁），人体难直接吸收，需配维 C 把 Fe³⁺ 还原成 Fe²⁺ 才好吸收。化学服务健康，但用错方法会白补。本课收口：铁三角闭合，价-类图贯穿。"

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 反例/判据 |
|---|---|---|
| Fe²⁺ 比 Fe³⁺ 稳定 | Fe²⁺ 还原性为主、易氧化；E°=0.771 V | 补铁剂须维 C、配液加铁屑 |
| KSCN 可检验 Fe²⁺ | KSCN 只对 Fe³⁺ 血红色；Fe²⁺ 须先氯水氧化 | Fe²⁺+KSCN 无现象，+氯水变红 |
| Fe³⁺ 与 Cu 不反应 | 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（氧化性氧化） | 印刷电路腐蚀 |
| Fe³⁺+SCN⁻ 是氧化还原 | 配位显色，非 redox | 无化合价变化 |
| 废水除铁直接加碱 | 先氧化 Fe²⁺→Fe³⁺ 再沉淀 Fe(OH)₃ | Fe(OH)₂ 溶度大、沉淀不全 |
| 菠菜直接补铁 | 多为 Fe³⁺，需维 C 转 Fe²⁺ 吸收 | 价-类图：+3 不易吸收 |

**核心口诀**：两铁盐、比五性（色/氧还/OH⁻/SCN⁻/Cl₂）；检验三法（KSCN 验 Fe³⁺、铁氰化钾验 Fe²⁺、NaOH）；铁三角双向靠氧还；废水先氧后沉；补铁配维 C；价-类图贯穿。

## 八、作业布置

- **必做**（基础达标）：[[高中化学必修一-习题精选]] 题3。
  ① 完成 Fe²⁺ 与 Fe³⁺ 对比表（颜色、氧化还原性、与 OH⁻、与 SCN⁻、与 Cl₂ 五栏）并各写一条核心方程式；
  ② 写出下列方程式并标类型/条件：2Fe³⁺ + Fe = 3Fe²⁺、2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺、2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻、5Fe²⁺ + MnO₄⁻ + 8H⁺ = 5Fe³⁺ + Mn²⁺ + 4H₂O、Fe³⁺ + nSCN⁻ → [Fe(SCN)ₙ]³⁻ⁿ；
  ③ 用"KSCN 法 / NaOH 法 / 铁氰化钾法"鉴别 Fe²⁺ 与 Fe³⁺，各写判别证据（现象 + 离子式或配合物式）。

- **易错方程式专项（必做补充，针对常见错写）**：
  ① Fe²⁺ 加 KSCN **不写血红色**，须先加氯水氧化成 Fe³⁺ 再显红，不能直接写 Fe²⁺+SCN⁻ 变红；
  ② Fe³⁺ + Cu 反应产物是 Fe²⁺ 与 Cu²⁺（2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺），不是 Fe 单质析出、也不是 Fe³⁺ 不反应；
  ③ Fe³⁺ + SCN⁻ 是**配位显色、非氧化还原**，不标化合价变化、不写"="生成物为配合物 [Fe(SCN)ₙ]³⁻ⁿ；
  ④ 废水除 Fe²⁺ 流程：**先氧化后沉淀**，不可直接加碱指望 Fe(OH)₂ 沉淀除尽。

- **选做**（能力提升）：
  ① 转化设计：限用试剂 Fe 粉、氯水、Cu 片、KSCN，设计 Fe²⁺ ⇌ Fe³⁺ 的双向转化，写出每步反应式与氧化剂/还原剂，并说明"向 FeCl₃ 加铁粉黄色变浅绿"的驱动因素（Fe³⁺ 被 Fe 还原）；
  ② 写出印刷电路腐蚀原理方程式，并说明"为何 Fe³⁺ 能氧化 Cu（金属活动性顺序 Cu 在 Fe 后却不矛盾）"的理由（Fe³⁺ 氧化性氧化 Cu，非 Fe 单质置换）。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① 工业废水除铁流程设计：某酸性废水含 Fe²⁺（浓度 c mol·L⁻¹）及少量 Cu²⁺。请设计完整除铁除铜方案（限用 H₂O₂、NaOH、铁粉），写出每步反应式、顺序理由（先氧后沉、铁粉置换 Cu），并说明为何不能先加碱除 Fe²⁺；
  ② 补铁剂检验方案：现有市售"补铁口服液"疑似 Fe²⁺ 制剂，但久置可能部分氧化为 Fe³⁺。请设计一套检验方案（限用 KSCN、氯水、铁氰化钾），说明如何判断"含 Fe²⁺""含 Fe³⁺""是否部分氧化"，并指出维 C 在其中的保护原理（还原 Fe³⁺→Fe²⁺）；
  ③ 价-类图推断：给出陌生含铁物 X（浅黄色晶体，溶于水得黄棕溶液，加 KSCN 血红色，加 NaOH 红棕沉淀）。请用价-类二维图推断 X 的可能化学式（如 FeCl₃·6H₂O），说明其类别（铁盐）与价态（+3），并写两条转化（加 Fe 得 Fe²⁺、加 Cu 得 Cu²⁺）方程式。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否独立填出 Fe²⁺/Fe³⁺ 五栏对比表并说差异根源（尤其"Fe²⁺ 比 Fe³⁺ 稳定"错觉是否被破除、E°=0.771 V 是否用来支撑"Fe²⁺ 易氧化"）？KSCN 只对 Fe³⁺ 显色的专属检验是否被真正理解而非仅背结论？
- [ ] 铁三角转化网络是否落地——学生能否画出 Fe⁰/Fe²⁺/Fe³⁺ 三角并标注氧化剂/还原剂；2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺ 的"氧化性氧化、非置换"本质是否被理解；分组实验中颜色变化（浅绿↔黄棕）是否被准确观察记录？
- [ ] 三组检验（KSCN 验 Fe³⁺、铁氰化钾验 Fe²⁺、KSCN+氯水）是否都会用且能说证据；废水除铁"先氧后沉"流程是否被真正理解，而非直接加碱的直觉残留？
- [ ] 价-类二维图是否贯穿全课——学生能否把 Fe 系物质落点并预测陌生含铁物的检验与转化；补铁剂维 C 同服、菠菜补铁、K₂FeO₄ 双功能等真实情境是否被有效对接；普鲁士蓝=滕氏蓝、莫尔盐稳定亚铁盐等深度补点是否点到而不超纲？
