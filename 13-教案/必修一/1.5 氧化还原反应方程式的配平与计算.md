# 教案：1.5 氧化还原反应方程式的配平与计算（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.5 氧化还原反应方程式的配平与计算 / 第 5 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[氧化还原反应基础]]、[[氧化还原反应方程式配平]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：把"电子守恒"落为可操作的配平四步，植入"部分被氧化/还原"、多元素变价、缺项配平、陌生情境与电子守恒计算，收口全章并为后续氧化还原滴定与电化学打底。

---

## 一、课标对应

- **内容要求（必修）**：认识有元素化合价变化的反应是氧化还原反应；了解氧化还原反应的本质是电子的转移；能根据电子守恒配平氧化还原反应方程式，并能进行简单的计算（氧化剂与还原剂比例、电子转移数目、产物量等）。
- **学业质量水平**：水平 2——能用化合价升降法配平常见与较复杂的氧化还原方程式；能识别"部分被氧化/还原"；能按介质完成缺项配平；能将电子守恒用于简单计算与陌生情境方程式的建构。
- **核心素养落点**：
  - **证据推理与模型认知**——"氧化剂得电子总数 = 还原剂失电子总数"的守恒模型是本课核心推理工具，须外显为稳定操作流程。
  - **科学探究与创新意识**——面对 K₂FeO₄ 净水、ClO₂ 消毒、SCR 脱硝等陌生情境，能依据价态与介质自主书写方程式，而非套背模板。
  - **宏观辨识与微观探析**——能将宏观配平系数与微观电子转移数对应，理解"系数就是电子账本的外在表现"。
  - **变化观念与平衡思想**——在归中/歧化、多步反应守恒中体会"总量不变、去向不同"的变化观。

## 二、学情分析（本课时）

**【课前诊断·5 处典型误解预判】**

- 学生易沿用先配 H、O 的原子习惯，未把"配平"的统领切换为"电子守恒为纲"，陷入来回试错。
- 学生常误以为"参与反应的该物质都被氧化/还原"（如 MnO₂+浓 HCl 中仅 2 个 HCl 被氧化，另 2 个起酸性成盐）。
- 面对 FeS₂、Cu₂S、NH₄NO₃ 等多元素变价或 P+CuSO₄+H₂O 等多产物变价，学生不会"按原子个数乘系数、按产物拆分电子账"。
- 缺项配平时学生不会用电荷守恒判定补 H⁺/H₂O 还是 OH⁻/H₂O（介质规则：酸不出 OH⁻、碱不出 H⁺）。
- 学生对高铁酸钾、ClO₂、SCR 等陌生情境方程式与电子守恒计算（关系式法）存在畏难。

学生在前几课时已掌握"双线桥/单线桥表示电子转移""氧化剂/还原剂判断""价态升降即电子得失"等基础（见 [[氧化还原反应基础]]），能从单一变价元素出发完成质量守恒配平。但本课的跃迁点在于：把"配平"的统领从**质量守恒**切换为**电子守恒为纲**——学生易沿用先配 H、O 的原子习惯而陷入来回试错；对"部分被氧化/还原"（如 MnO₂ 与浓 HCl 反应中仅 2 个 HCl 被氧化）普遍误以为"参与反应的都被氧化"；面对 FeS₂、Cu₂S、NH₄NO₃ 这类**多元素同时变价**或 P、CuSO₄、H₂O 共热生成 Cu₃P 与 H₃PO₄ 的**多产物变价**，不会"按原子个数乘系数、按产物拆分电子账"；缺项配平时不会用**电荷守恒**判定补 H⁺/H₂O 还是 OH⁻/H₂O；对高铁酸钾、ClO₂、SCR 等**陌生情境**方程式存在畏难；电子守恒**计算**（多步反应、归中、与滴定挂钩）尚缺"关系式法"训练。本课即从上述断层逐点补齐。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标

- **证据推理与模型认知**：能将"氧化剂得电子总数 = 还原剂失电子总数"这一守恒规律，外显为"标变价 → 算升降×系数 → 求最小公倍数使电子守恒 → 配平其他（观察法/原子守恒）"的稳定配平模型，并理解"先电子后原子"的必然性。
- **科学探究与创新意识**：面对陌生情境（K₂FeO₄ 制备与净水、ClO₂ 消毒、SCR 脱硝、锂电池/高铁电池电极反应、化学镀、工业尾液处理），能先依据氧化还原规律与物料守恒推出产物，再完成配平，而非机械记忆。
- **宏观辨识与微观探析**：能将宏观配平系数与微观电子转移数目一一对应，理解"每 1 个系数背后是若干 e⁻ 的账"。
- **变化观念与平衡思想**：在归中反应、歧化反应、多步反应守恒中体会"电子守恒是贯穿始终的总账"，为后续氧化还原滴定与电化学建立守恒直觉。

### 3.2 学习目标（学生能……）

- 能用"电子守恒为纲"的四步法独立配平含单元素/多元素变价、含部分被氧化/还原的方程式，并严格查原子守恒与电荷守恒。
- 能识别"部分被氧化/还原"（如 MnO₂ + 4HCl(浓) 中仅 2 个 HCl 被氧化，另 2 个起酸性成盐），正确写出电子转移数。
- 能按介质（酸性补 H⁺/H₂O、碱性补 OH⁻/H₂O）用电荷守恒完成缺项配平。
- 能处理多元素变价（FeS₂、Cu₂S、NH₄NO₃ 自身氧化还原、P+CuSO₄+H₂O 多产物变价），做到"乘原子个数、分产物记账"。
- 能用电子守恒进行简单计算：氧化剂/还原剂比例、电子转移数目、多步反应守恒法、价态归中计算，并能书写 1–2 道陌生情境方程式。

> 旧三维目标框架已废止，本课目标统一以"核心素养 + 可观测学习目标"表述。

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|

### 6.2 环节一：回顾导入（题 6 电子转移口述）

**教师**："上节课题 6：MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O。现在谁说：这个反应转移了多少电子？4 个 HCl 是不是都被氧化了？"

**学生（预期，常见误答）**："Mn 从 +4 降到 +2 得 2e⁻，Cl 从 −1 升到 0……4 个 HCl 每个失 1e⁻，所以转移 4e⁻？"

**教师（追问/理答）**："先记一个悬念——转移数不是 4e⁻，是 2e⁻。哪 2 个 Cl 被氧化？我们这节课专门拆。今天先把'配平'变成可操作流程：核心是**电子守恒**——氧化剂得的电子总数必须 = 还原剂失的电子总数。这是总纲，质量守恒是总纲之下的'收尾查账'。"

### 6.3 环节二：配平四步法示范（KMnO₄ + HCl，边写边讲）

**教师**："配平四步，请记死顺序。

**① 标变价**——KMnO₄ 中 Mn +7→+2（得 5e⁻），HCl 中 Cl −1→0（失 1e⁻，每生成 1 个 Cl₂ 失 2e⁻）。

**② 算升降、求最小公倍定变价元素系数**——Mn 得 5、Cl₂ 失 2，最小公倍 10，所以 Mn 系数 2、Cl₂ 系数 5（10e⁻ 对 10e⁻）。

**③ 配平其他（先变价后旁观）**——KMnO₄ = 2 ⇒ KCl = 2、MnCl₂ = 2；Cl₂ = 5，产物共需 Cl：KCl 2 + MnCl₂ 4 + Cl₂ 的 10 = 16，故 HCl = 16。

**④ 查守恒**——H：16 = 2×H₂O ⇒ H₂O = 8；再核 O：左 2×4 = 8，右 8×1 = 8，原子与电荷（酸性介质）均守恒。"

**完整式**：

2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O

**学生（预期，典型错误）**："老师，为什么不先配 H₂O 和 HCl，先定 Mn 和 Cl₂ 系数？"

**教师（追问/理答）**："因为变价元素的系数是'被电子守恒钉死'的——它们决定了总电子账。先动它们，后面的旁观物质（K、H、O）才能被唯一确定。顺序错了就会来回试错。口诀：**先守电子再守原子，两个守恒不能偏**。"

> **单线桥法补充**：在 KMnO₄ + HCl 中，画一条线从还原剂 HCl（指向 Cl₂ 一侧）到氧化剂 MnO₄⁻，标"10e⁻"，不标得/失两端、不画双箭头。单线桥强调"电子从谁流向谁"，双线桥强调"各元素升降多少"，二者互补。

### 6.3.5 配平四步示范②：Cu + 浓 H₂SO₄（完整板演，强化"部分被还原"）

**教师**："再练一个，把四步走实：Cu + H₂SO₄(浓) → CuSO₄ + SO₂↑ + H₂O。

**① 标变价**——Cu 0→+2（失 2e⁻）；H₂SO₄ 中 S +6→+4（得 2e⁻，入 SO₂）。注意 Cu 是还原剂、H₂SO₄ 是氧化剂，但 H₂SO₄ 只有'去 SO₂ 的那一份'被还原。

**② 算升降、定变价元素系数**——Cu 失 2、S 得 2，LCM = 2 ⇒ Cu 系数 1、SO₂ 系数 1（2e⁻ 对 2e⁻）。

**③ 配旁观**——Cu = 1 ⇒ CuSO₄ = 1（这里 CuSO₄ 的 SO₄ 来自'起酸性'的 H₂SO₄，价态未变）；SO₂ = 1 来自 1 个'被还原'的 H₂SO₄。故 H₂SO₄ 共需 1（起酸）+ 1（被还原）= 2。

**④ 查守恒**——H：左 2×2 = 4 ⇒ 右 H₂O = 2；O：左 2×4 = 8，右 CuSO₄ 4 + SO₂ 2 + H₂O 2 = 8，守恒。"

**完整式**：

Cu + 2H₂SO₄(浓) = CuSO₄ + SO₂↑ + 2H₂O

**学生（预期，典型错误）**："老师，既然 2 个 H₂SO₄ 才 1 个被还原，那电子转移数到底几 e⁻？"

**教师（追问/理答）**："转移 2e⁻。判定口诀：'看产物里有没有原样价态的该元素'——CuSO₄ 里的 S 仍是 +6（原样），说明它没被还原，只负责提供 SO₄²⁻ 成盐；只有变成 SO₂（S +4）的那 1 个 H₂SO₄ 被还原。所以氧化剂 H₂SO₄ 的'有效量'是 1，不是 2。算电子转移数永远按'实际变价的部分'算。"

> **方法小结（配平四步的两条铁律）**：
> 1. 变价元素系数是"电子账钉死"的，先定它，再配旁观；
> 2. "部分被氧化/还原"时，氧化剂/还原剂的"有效物质的量" = 实际变价的部分，比对产物价态再数，别用反应物总系数代替。

### 6.4 环节三："部分被氧化/还原"突破 + 多元素变价

**教师**："回到开头的悬念：MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O。4 个 HCl 都被氧化了吗？看产物——MnCl₂ 里也有 Cl，且价态仍是 −1！这些 Cl 来自哪？"

**学生（预期）**："MnCl₂ 里的 Cl 没变价，还是 −1……所以它不是被氧化的那部分？"

**教师（追问/理答）**："对。4 个 HCl 中，**只有 2 个 Cl 被氧化成 Cl₂（失 2e⁻），另 2 个只起酸的作用**——提供 Cl⁻ 与 Mn²⁺ 结合成 MnCl₂，价态没变。所以电子转移数 = 2e⁻，不是 4e⁻。'部分被氧化/还原'是高频坑：看产物里有没有'原样价态'的该元素。对比 Cu + 2H₂SO₄(浓) = CuSO₄ + SO₂↑ + 2H₂O：2 个 H₂SO₄ 中**只有 1 个被还原成 SO₂（S +6→+4 得 2e⁻），另 1 个只起酸的作用**生成 CuSO₄。再对比 KClO₃ 分解：KClO₃ 中 Cl 全被还原（无残留原样 Cl），属于整体变价。"

**多元素变价（一个物质多种元素同时变价，先算"每 1 mol 该物质共失/得多少 e⁻"）**：

- **FeS₂**：Fe 为 +2，S 为 −1（两个 S 平均 −1）。焙烧：4FeS₂ + 11O₂ = 2Fe₂O₃ + 8SO₂。Fe +2→+3（每 mol 失 1e），每个 S −1→+4（每 mol 失 5e），**每 mol FeS₂ 共失 1 + 2×5 = 11e**。配平时先按物质整体失电子数定系数，再查原子。

完整式：

4FeS₂ + 11O₂ = 2Fe₂O₃ + 8SO₂

- **Cu₂S**：Cu +1→+2（每 Cu 失 1e），S −2→+6（入 H₂SO₄，失 8e），**每 mol Cu₂S 共失 2×1 + 8 = 10e**。与稀 HNO₃ 反应（Cu 入 Cu(NO₃)₂、S 入 H₂SO₄、N +5→+2 入 NO）：每 mol Cu₂S 失 10e，每 mol 被还原 HNO₃ 得 3e，LCM(10,3) = 30 ⇒ 3Cu₂S、10NO。补起酸性 NO₃⁻：6Cu²⁺ 需 6 个 Cu(NO₃)₂ = 12 个 NO₃⁻，总 HNO₃ = 10（被还原）+ 12（起酸）= 22。H 平衡：22 = 3×2（H₂SO₄）+ 2x（H₂O）⇒ x = 8。O 核查：左 22×3 = 66；右 6×6 + 3×4 + 10 + 8 = 36 + 12 + 10 + 8 = 66，守恒。

3Cu₂S + 22HNO₃(稀) = 6Cu(NO₃)₂ + 3H₂SO₄ + 10NO↑ + 8H₂O

电子核查：失 3×10 = 30e；得 10×3 = 30e，守恒。注意：产物里 H₂SO₄ 的 S 来自 Cu₂S、H 来自 H₂O，不是来自 HNO₃ 被还原——被还原的 HNO₃ 只去了 NO。

**学生（预期，典型错误）**："老师，Cu₂S 里 S 只失 6e（到 +4）还是 8e（到 +6）？我分不清产物价态。"

**教师（追问/理答）**："看产物！产物是 H₂SO₄，S 是 +6，所以失 8e；若产物写成 SO₂ 才是 +4 失 5e。**先确定产物价态，再算失/得电子数**——这是多元素变价不踩坑的第一原则。配平前一定要先把产物里各元素价态标出来。"

- **NH₄NO₃ 自身氧化还原**：NH₄⁺ 中 N −3→0（失 3e），NO₃⁻ 中 N +5→0（得 5e），整体还伴随部分 O²⁻→O₂（失 4e 每 mol O₂）。标准分解：

2NH₄NO₃ = 2N₂↑ + O₂↑ + 4H₂O

核查电子：2 个 N(−3→0) 失 6e，2 个 N(+5→0) 得 10e，差额 4e 由 2O²⁻→O₂ 失 4e 补足，得失相等。自身 redox 的"归中到 N₂"是典型模型。

- **P + CuSO₄ + H₂O → Cu₃P + H₃PO₄（多产物变价）**：P 一部分被还原入 Cu₃P（P 0→−3 得 3e），一部分被氧化入 H₃PO₄（P 0→+5 失 5e），Cu +2→+1（得 1e）。经典配平：

11P₄ + 60CuSO₄ + 96H₂O = 20Cu₃P + 24H₃PO₄ + 60H₂SO₄

要点：先按"Cu₃P 整体得电子（3Cu 各得 1 + 1P 得 3 = 6e）"与"P 氧化失 5e"取 LCM，再补 H₂O 与 H₂SO₄。此类"一物多产物变价"是高难度配平，本课点到即止、重在方法。

**学生（预期，典型错误）**："FeS₂ 里 S 是 −1，我算成每个 S 失 5e 后是 +4，那俩 S 就是 10e，再加 Fe 的 1e 得 11e——对吗？"

**教师（追问/理答）**："完全正确。关键就是'乘原子个数'：FeS₂ 有 2 个 S，所以 S 一项是 2×5 = 10e，不是 5e。漏乘原子个数是多元素变价最常见的失分点。"

### 6.5 环节四：缺项配平（按介质补项 + 电荷守恒）

**教师**："给反应物、却空着缺项，要你判断补 H⁺、H₂O 还是 OH⁻、H₂O，怎么办？铁律先记住：**酸性介质只补 H⁺ 与 H₂O，产物不出现 OH⁻；碱性介质只补 OH⁻ 与 H₂O，产物不出现 H⁺。** 介质由实验事实决定，不能为配平方便乱加。"

**缺项配平两例（先用原子、再用电荷定缺项）**：

- 酸性（离子方程式）：_MnO₄⁻ + _Fe²⁺ + _ = _Mn²⁺ + _Fe³⁺ + _

先配变价：5Fe²⁺ + 1MnO₄⁻ → 5Fe³⁺ + 1Mn²⁺（电子 5 = 5）。左侧电荷 5×(+2) + 1×(−1) = +9，右侧 +5×(+3) + (+2) = +17。差 −8，酸性补 H⁺ 在左侧使电荷守恒：左侧加 8H⁺ → +9 + 8 = +17，与右相等。再由 H 定 H₂O：左侧 8H ⇒ 右侧 4H₂O。

完整式：

5Fe²⁺ + MnO₄⁻ + 8H⁺ = 5Fe³⁺ + Mn²⁺ + 4H₂O

- 碱性：_CrO₂⁻ + _H₂O₂ + _ = _CrO₄²⁻ + _

先配变价：2CrO₂⁻ + 3H₂O₂ → 2CrO₄²⁻（Cr +3→+6 失 3e ×2 = 6e；O 在 H₂O₂ 中 −1→−2 得 1e ×6 = 6e）。碱性补 OH⁻/H₂O：左侧加 2OH⁻，右侧补 4H₂O 平衡 H、O。

完整式：

2CrO₂⁻ + 3H₂O₂ + 2OH⁻ = 2CrO₄²⁻ + 4H₂O

**学生（预期，典型错误）**："老师，酸性里我补了 OH⁻ 行不行？看起来也能平。"

**教师（追问/理答）**："不行。酸性溶液中 OH⁻ 浓度极低，补 OH⁻ 是违背介质事实的。判缺项的第一依据是**介质**，第二才是电荷与原子。顺序：先看介质定'能补谁'→再配变价→最后用电荷定缺项系数。'酸不出 OH⁻、碱不出 H⁺'是硬约束。"

### 6.5.5 常见配平陷阱速查（5 条，课后贴笔记）

| # | 陷阱 | 典型误例 | 正解 |
|---|---|---|---|
| 1 | 先用原子配 H/O，再回头改变价系数 | 反复试错、系数互耦 | 先电子后原子：变价系数由 LCM 钉死 |
| 2 | 把"参加反应的总量"当"被氧化/还原量" | MnO₂+4HCl 算转移 4e⁻ | 看产物原样价态：仅 2HCl 被氧化，转 2e⁻ |
| 3 | 多元素变价漏乘原子个数 | FeS₂ 只算 1 个 S 失 5e | FeS₂ 含 2 个 S：失 1+2×5 = 11e；Cu₂S 失 2×1+8 = 10e |
| 4 | 缺项配平乱补介质离子 | 酸性里补 OH⁻、碱性里补 H⁺ | 酸只补 H⁺/H₂O，碱只补 OH⁻/H₂O |
| 5 | 陌生情境先背方程式再套 | 见 K₂FeO₄ 直接默写 | 先据氧化还原+物料推产物（Fe+3→+6、Cl 0→−1），再配平 |

> **配平自检清单（写完必查 4 项）**：① 变价元素升降总数是否相等（电子守恒）；② 原子是否全守恒（H、O 最后查）；③ 离子方程式电荷是否守恒；④ 介质是否自洽（酸无 OH⁻、碱无 H⁺）。四项全过才算配平完成。

### 6.6 环节五：陌生情境 + 电子守恒计算（收口）

**教师**："高考'无情境不命题'。看高铁酸钾 K₂FeO₄ 净水：Fe 在 K₂FeO₄ 中是 +6，有强氧化性（杀菌），被还原成 Fe³⁺，Fe³⁺ 水解生成 Fe(OH)₃ 胶体起絮凝——**氧化+絮凝双重净水**。写出其制备（以 Cl₂ 在碱性条件下氧化 Fe(OH)₃ 为例）并配平。"

> 制备式（先推产物：Fe(OH)₃ 中 Fe +3→+6 失 3e；Cl₂ 中 Cl 0→−1 得 1e ×2 = 2e；LCM 6 ⇒ 2Fe(OH)₃、3Cl₂）：

2Fe(OH)₃ + 3Cl₂ + 10KOH = 2K₂FeO₄ + 6KCl + 8H₂O

电子核查：Fe 失 3e⁻×2 = 6e⁻；Cl 得 1e⁻×6 = 6e⁻，守恒。

**其他陌生情境（给反应物+部分产物，练'先推产物再配平'）**：

- **ClO₂ 消毒**：ClO₂ 中 Cl +4，还原产物多为 Cl⁻（−1），得 5e⁻，高效低残留。氧化水中 Fe²⁺ 的离子方程式：

ClO₂ + 5Fe²⁺ + 4H⁺ = Cl⁻ + 5Fe³⁺ + 2H₂O

（Cl +4→−1 得 5e；Fe +2→+3 失 1e ×5，守恒）

- **SCR 脱硝**（氨还原氮氧化物）：

4NO + 4NH₃ + O₂ = 4N₂ + 6H₂O

（NH₃ 中 N −3→0 失 3e ×4 = 12e；NO 中 N +2→0 得 2e ×4 = 8e，另 O₂ 中 O 0→−2 得 4e，共 12e，守恒）

- **金属冶炼**：Fe₂O₃ + 3CO = 2Fe + 3CO₂（C +2→+4 失 2e ×3 = 6e；Fe +3→0 得 3e ×2 = 6e）。

**电子守恒计算（关系式法）**：

- 已知某反应转移 6 mol e⁻，氧化剂 KMnO₄（Mn +7→+2，每 mol 得 5e⁻），求被还原的 KMnO₄ 物质的量：n(KMnO₄) = 6/5 = 1.2 mol。
- **多步反应守恒法**：工业上用黄铁矿制 CuSO₄ 之类，若"起始物→中间物→目标物"各步均为氧化还原，可跨步直接建立"起始物失电子总数 = 终态得电子总数"的关系式，不必逐步算。例如 C 经一系列氧化最终全为 CO₂，则 n(C)×4 = 总转移电子数。
- **价态归中计算**：同一元素高价与低价相遇生成中间价（如 H₂S 与 SO₂ 归中生成 S），可直接用"高价降数 + 低价升数 = 中间价所需"列方程求比例。
- **与滴定挂钩的 precursor**：氧化还原滴定中 c(待测)×V(待测)×n(待测) 的电子 = c(标准)×V(标准)×n(标准) 的电子，即"电子守恒联系物质的量"的关系式，课后在 [[氧化还原反应方程式配平]] 中延伸。

**计算易错点（口述）**：Cu + 稀 HNO₃ 转移 1.2 mol e⁻ 时，由"每生成 1 mol NO 需 N +5→+2 得 3e⁻"得 n(NO)=1.2/3=0.4 mol、标况体积 8.96 L。关键是"每 mol 被还原产物对应多少 e⁻"这个系数别搞反——关系式法就是把电子守恒写成一道比例式，多步反应也这么跨步用。

### 6.7 配平与计算衔接精讲：归中反应 + 多步守恒（拔高）

**教师**："还有一种高频计算——**价态归中**：同一元素的高价与低价相遇，生成中间价态，电子得失在'同一元素内部'完成。例如 H₂S 与 SO₂ 归中生成 S：H₂S 中 S −2→0 失 2e，SO₂ 中 S +4→0 得 4e，LCM(2,4)=4 ⇒ 2H₂S、1SO₂，产物 3S。"

2H₂S + SO₂ = 3S↓ + 2H₂O

**学生（预期，典型错误）**："老师，归中反应是'高价降、低价升'都往中间靠，那生成物价态一定在二者之间吗？"

**教师（追问/理答）**："一定。归中产物价态必介于高价与低价之间（如 +4 与 −2 归中到 0），不能'跨过'——这就是**归中不交叉原则**。若你算出的产物价态高于高价或低于低价，必错。歧化则相反：中间价同时升、降（如 Cl₂ 歧化为 Cl⁻ 与 ClO₃⁻）。"

**多步反应守恒法（跨步建关系式，不逐步算）**：

**教师**："工业上 FeS₂ → SO₂ → SO₃ → H₂SO₄，三步全是氧化还原（后两步是 O₂ 氧化 S）。问 1 mol FeS₂ 最多制多少 mol H₂SO₄？不必逐步算转化率，直接建两条守恒链：① 物料：1 mol FeS₂ 含 2 mol S 原子 ⇒ 2 mol H₂SO₄；② 电子：FeS₂ 焙烧失 11 mol e⁻，这些 e⁻ 全被 O₂ 得去，与制酸量无关。所以答案就是 2 mol H₂SO₄。"

**关系式法实操 + 滴定 precursor（口述）**：关系式即"n(始物)×每 mol 失 e⁻数 = n(终物)×每 mol 得 e⁻数（或物料系数）"，跨步守恒可省 2–3 步中间计算。下章电化学与后续氧化还原滴定反复用到此式：KMnO₄ 氧化 Fe²⁺ 有 n(Fe²⁺)×1e = n(MnO₄⁻)×5e，即 c(Fe²⁺)·V(Fe²⁺)=5·c(MnO₄⁻)·V(MnO₄⁻)；今天先建立"电子守恒联系物质的量"的直觉。

> **计算四式（背熟）**：① 转移 e⁻总数 = Σn(氧化剂)×每 mol 得 e⁻ = Σn(还原剂)×每 mol 失 e⁻；② 氧化剂/还原剂物质的量比 = 每 mol 得、失 e⁻ 的反比；③ 多步反应直接建"起始失 e⁻ = 终态得 e⁻"关系式；④ 归中必遵守"不交叉原则"。

## 八、作业布置（三层，挑战有区分度）

### 必做（基础巩固，对应题 6 与标准配平）

1. **题 6 双线桥基础**：对 MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O 用双线桥标电子转移，并说明"4 个 HCl 中有几个被氧化、转移几 e⁻"。
2. 用化合价升降法四步配平，并写双线桥：
   - (a) MnO₂ + HCl(浓) → MnCl₂ + Cl₂↑ + H₂O（即题 6 标准形式）。
   - (b) Cu + H₂SO₄(浓) → CuSO₄ + SO₂↑ + H₂O（说明仅几个 H₂SO₄ 被还原）。
   - (c) FeS₂ + O₂ → Fe₂O₃ + SO₂（写出每 mol FeS₂ 失 11e 的推导）。

> **必做提示/解析**：
> - (1) 双线桥：Mn +4→+2（得 2e⁻×1），2 个 Cl⁻（−1）→Cl₂（0）共失 2e⁻；4 个 HCl 中仅 2 个 Cl 变价，转移 2e⁻。
> - (2a) 同(1)。(2b) Cu 0→+2 失 2e；1 个 H₂SO₄ 中 S +6→+4 得 2e；故仅 1 个 H₂SO₄ 被还原，配平见环节二示范②。(2c) 每 mol FeS₂：Fe 失 1e、2 个 S 各失 5e，共 11e；4FeS₂ 失 44e，11O₂ 得 44e，系数 4/11/2/8。

### 选做（进阶，多元素变价 + 缺项配平）

3. 多元素变价配平（写出电子守恒推导）：
   - (a) Cu₂S + HNO₃(稀) → Cu(NO₃)₂ + H₂SO₄ + NO↑ + H₂O。
   - (b) NH₄NO₃ 分解 → N₂↑ + O₂↑ + H₂O（标"自身氧化还原 + 部分 O 被氧化"）。
4. 缺项配平（先判介质，再用电荷守恒定缺项）：
   - (a) 酸性：_Cu + _HNO₃(稀) → _Cu(NO₃)₂ + _NO↑ + _ （补 H₂O）。
   - (b) 碱性：_Cl₂ + _KOH(热) → _KCl + _KClO₃ + _ （补 H₂O，说明歧化）。

> **选做提示/解析**：
> - (3a) 每 mol Cu₂S 失 10e（Cu 失 2×1、S −2→+6 失 8），每 mol 被还原 HNO₃ 得 3e，LCM 30 ⇒ 3Cu₂S、10NO；补酸性 NO₃⁻ 得 22HNO₃、8H₂O（见环节三推导）。
> - (3b) 2NH₄NO₃ = 2N₂↑ + O₂↑ + 4H₂O；2 个 N(−3→0) 失 6e，2 个 N(+5→0) 得 10e，差额 4e 由 2O²⁻→O₂ 失 4e 补足。
> - (4a) 3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（Cu 失 2e×3=6，N 得 3e×2=6）；酸性补 H₂O，N 被还原 2 个、起酸 6 个。
> - (4b) 3Cl₂ + 6KOH(热) = 5KCl + KClO₃ + 3H₂O；歧化：Cl 0→−1（得 1e×5）、Cl 0→+5（失 5e×1），5=5 守恒。

### 挑战（区分度，信息型 + 计算 + KMnO₄ 介质）

5. 信息型陌生方程式（先据氧化还原+物料推产物再配平，选 2 道）：
   - (a) K₂FeO₄ 制备：以 Cl₂ 在碱性条件下氧化 Fe(OH)₃ 制 K₂FeO₄，写出配平方程式并说明其"氧化杀菌 + Fe³⁺ 水解絮凝"双重净水原理。
   - (b) ClO₂ 消毒：写出 ClO₂ 氧化水中 Fe²⁺ 生成 Fe³⁺ 与 Cl⁻ 的离子方程式并配平。
   - (c) SCR 脱硝：写出 NH₃ 在 O₂ 存在下还原 NO 生成 N₂ 与 H₂O 的配平方程式。
6. 电子守恒计算大题（多步反应/归中，含关系式法）：
   - 已知 FeS₂ 焙烧生成的 SO₂ 全部用于制硫酸（4FeS₂+11O₂=2Fe₂O₃+8SO₂；SO₂→SO₃→H₂SO₄ 各步均 1:1 转化）。若起始有 1 mol FeS₂，用关系式法求：整个流程转移电子总物质的量，以及理论上可生成 H₂SO₄ 的物质的量。（提示：跨步直接建"FeS₂ 失电子总数 = 终态得电子总数 / 物料守恒"的关系式）
7. KMnO₄ 不同介质产物对比与配平：
   - 写出 KMnO₄ 在**酸性**、**中性/弱碱性**、**强碱性**三种介质中与 Fe²⁺（或 SO₃²⁻）反应的配平离子方程式，对比 Mn 的还原产物（Mn²⁺ / MnO₂ / MnO₄²⁻），说明介质如何影响产物价态。

> **挑战提示/解析**：
> - (5a) 制备式：2Fe(OH)₃ + 3Cl₂ + 10KOH = 2K₂FeO₄ + 6KCl + 8H₂O；Fe +3→+6 失 3e×2=6，Cl 得 1e×6=6。双重净水：K₂FeO₄ 强氧化性杀菌，还原产物 Fe³⁺ 水解成 Fe(OH)₃ 胶体絮凝。
> - (5b) ClO₂ + 5Fe²⁺ + 4H⁺ = Cl⁻ + 5Fe³⁺ + 2H₂O（Cl +4→−1 得 5e；Fe +2→+3 失 1e×5）。
> - (5c) 4NO + 4NH₃ + O₂ = 4N₂ + 6H₂O（NH₃ 中 N −3→0 失 3e×4=12；NO 中 N +2→0 得 2e×4=8，O₂ 得 4e，共 12）。
> - (6) 1 mol FeS₂ 焙烧失 11 mol e⁻（即流程总转移 11 mol e⁻）；物料：1 mol FeS₂ → 2 mol S(原子) → 2 mol H₂SO₄，故可生成 H₂SO₄ 2 mol。（关系式法：n(FeS₂)×11 = 总 e⁻；n(FeS₂)×2 = n(H₂SO₄)）
> - (7) 酸性：MnO₄⁻ + 5Fe²⁺ + 8H⁺ = Mn²⁺ + 5Fe³⁺ + 4H₂O；中性/弱碱：2MnO₄⁻ + 3Mn²⁺ + 2H₂O = 5MnO₂↓ + 4H⁺（或与 Fe²⁺ 在弱碱：2MnO₄⁻ + 6Fe²⁺ + 4H₂O = 2MnO₂ + 6Fe³⁺ + 8OH⁻，视体系）；强碱：MnO₄⁻ + e⁻ = MnO₄²⁻（如 2MnO₄⁻ + SO₃²⁻ + 2OH⁻ = 2MnO₄²⁻ + SO₄²⁻ + H₂O）。介质越碱，Mn 被还原的程度越小（价态越高）。
