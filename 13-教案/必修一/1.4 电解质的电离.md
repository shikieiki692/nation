# 教案：1.4 电解质的电离（必修第一册 第一章 物质及其变化）

> **课时元信息**：第 1 章 / 1.4 电解质的电离 / 第 4 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[物质分类与离子反应]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：从"宏观导电现象"钻进"微观离子"的第一课。建立**电离模型**——回答"溶液为什么能导电""什么样的化合物能电离""电离到什么程度"。本课时只做电离（导电本质 / 电解质与非电解质 / 强弱电解质与电离方程式），离子反应的本质与方程式书写留待下一课时 1.5。

---

## 一、课标对应

- **内容要求**：认识酸、碱、盐等电解质在水溶液中或熔融状态下能够电离；能用电离方程式表示某些酸、碱、盐的电离；能从宏观与微观相结合的视角分析与解决实际问题。
- **学业质量水平**：必修水平 2——能依据实验事实（导电性）判断物质是否电离，能从电离角度解释溶液导电能力的差异；能正确书写常见酸、碱、盐的电离方程式。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（由灯泡亮暗的宏观现象，追溯自由离子这一微观本质）；
  2. **证据推理与模型认知**（建立"电离"模型，用"化合物"前提与"电离程度"两把尺判定强弱）；
  3. **科学探究与创新意识**（用导电性对比实验与"蒸馏水渐加 NaCl"的读数变化，证明电离是自发过程）。

### 1.4 课标细目与课时落点对照

| 课标表述 | 本课对应落点 | 达成方式 |
|---|---|---|
| 电解质在水溶液或熔融状态下电离 | 导电性对比 5 组实验 | 预测 → 实测 → 追问本质 |
| 能用电离方程式表示电离 | 强/弱电解质电离方程式规范 | 板书示范 + 酸式盐、多元弱酸分步 |
| 宏观与微观结合分析 | "导电现象 → 自由离子"因果链 | 蒸馏水渐加 NaCl 的读数上升 |

## 二、学情分析（本课时）

**【课前诊断·5 处典型误解预判】**

- 学生常把"能导电"直接等同于"是电解质"（忘了**化合物**这一前提，Cu 是单质、食盐水是混合物，二者既不是电解质也不是非电解质）。
- 学生常把"溶液能导电"等同于"该物质自身电离"（实为 CO₂、SO₂、NH₃ 自身不电离，是其与水反应生成的 H₂CO₃、H₂SO₃、NH₃·H₂O 在电离，故 CO₂、SO₂、NH₃ 是非电解质）。
- 学生常把"难溶"当成"弱电解质"（实为 BaSO₄ 溶解的那一点点 100% 电离，是**强**电解质）。
- 学生常把"易溶"当成"强电解质"（实为 CH₃COOH 易溶但只部分电离，是弱电解质）。
- 学生常以为"通电后才电离"（实为电离是自发过程，通电只是让已有的离子定向移动）。

学生在初三接触过"溶液导电"的粗浅事实，但多为"盐酸能导电、蔗糖水不能"的现象记忆，未建立"自由移动的带电粒子"这一统一解释，更没有强弱电解质的定量视角。本课新难点有三：一是"化合物"前提的判定，学生极易被"能导电"这一表象带偏；二是"溶解度"与"电离程度"两个维度的区分（难溶≠弱、易溶≠强），这是本节最高频的考点陷阱；三是电离方程式的规范书写，尤其酸式盐（NaHCO₃ 的 HCO₃⁻ 不拆）与多元弱酸分步（H₃PO₄ 三步、H₂CO₃ 两步）。对策：用"导电性对比 5 组"实验制造现象冲突，用"向蒸馏水渐加 NaCl 粉末、读数持续上升"证明电离自发，用"BaSO₄ 难溶却是强电解质"的反例链强行区分两个维度。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过导电性对比实验与"蒸馏水渐加 NaCl"的读数变化，培养**宏观辨识与微观探析**素养：从灯泡亮暗的宏观现象追溯自由离子这一微观本质，破除"通电才电离"的迷思。
- 通过对"Cu 是电解质吗""食盐水是电解质吗""CO₂ 是电解质吗"三个连续追问，培养**证据推理与模型认知**素养：建立"先看是不是化合物、再看电离程度"的两级判定模型。
- 通过辨析"难溶≠弱、易溶≠强"的反例链，培养**科学探究与创新意识**素养：学会区分溶解度与电离程度两个独立维度。
- 通过规范书写强/弱电解质、酸式盐、多元弱酸的电离方程式，培养**宏观辨识与微观探析**素养：用符号准确表达微观粒子的存在形式。

### 3.2 学习目标（学生能……，可观测）

- 能**说明**导电的本质是"有自由移动的带电粒子"，并区分金属导电（自由电子）与溶液/熔融导电（自由离子）。
- 能**用"化合物"前提 + "电离程度"两把尺**判断给定物质是否为电解质、是强还是弱，对 Cu、食盐水、CO₂、SO₂、NH₃、BaSO₄、CH₃COOH 等给出正确判定并说明理由。
- 能**正确书写**常见强电解质（NaCl、H₂SO₄、NaOH、Ba(OH)₂）与弱电解质（CH₃COOH、NH₃·H₂O、H₂CO₃、H₃PO₄）的电离方程式，正确处理酸式盐（NaHSO₄ 拆出 H⁺、NaHCO₃/NaHSO₃ 酸式根不拆）与多元弱酸分步。
- 能**解释**"难溶≠弱电解质""易溶≠强电解质""电离是自发的、不是通电造成的"三条铁律。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

### 环节一：情境导入——从"导电"到"离子重组"

**【逐字稿】**

**教师**："两个生活问题。其一，长辈说'湿手别碰开关'，纯水不是绝缘体吗，危险从哪来？其二，海水晒盐得到的粗盐水，怎么把里面的 Ca²⁺、Mg²⁺、SO₄²⁻ 这些杂质'抓'出去变成精盐？"

**学生（预期）**："自来水不是纯水，里面有杂质能导电……""加试剂让杂质沉淀？"

**学生（预期，典型错误）**："是不是水本身通电后变成离子才导电？"

**教师（追问/理答）**："两个问题的答案都指向'看不见的离子'。先破除误区：不是'通电后'才产生能导电的粒子，而是某些物质**溶于水之前、没通电时**就以离子形式存在了。湿手触电，正是因为自来水中含 Na⁺、Cl⁻、Ca²⁺ 等自由离子，电阻骤降。而粗盐水净化，本质是让杂质离子和加入的离子结合成沉淀'离开'溶液——这是离子之间的重新组合，即离子反应。今天我们把'电离'与'离子反应'合成一条链讲透。"

### 环节二：电离模型——导电本质与电解质/非电解质

**【逐字稿】**

**教师**："桌上五组待测：NaCl 固体、蒸馏水、NaCl 溶液、蔗糖溶液、Cu 片。预测灯泡亮暗再实测。注意 NaCl 固体是干燥的，别被'盐'字骗了。"

**学生（预期）**："NaCl 固体不亮、蒸馏水几乎不亮、NaCl 溶液亮、蔗糖溶液不亮、Cu 片亮。"

**教师（追问/理答）**："两组'亮'本质一样吗？NaCl 溶液亮因 Na⁺、Cl⁻ 自由移动；Cu 亮因金属有自由电子。所以**导电本质 = 有自由移动的带电粒子**：金属靠电子，溶液/熔融靠离子。导电能力强弱 ∝ 单位体积内'离子浓度 × 离子电荷数'——同浓度下二价离子比一价贡献更大。那蔗糖溶液为什么不亮？"

**学生（预期）**："蔗糖在水里还是分子，没拆成离子。"

**教师（追问/理答）**："准确。现在看更妙的演示——" *（向蒸馏水中小量多次加 NaCl 粉末，电导读数从近 0 持续上升）* "读数变大说明电离是**自发过程**，通电只是让已有离子定向移动。下面给'能电离的化合物'命名。"

**教师**："定义：在**水溶液里或熔融状态下**能导电的**化合物**，叫电解质。三要素，谁最易忘？"

**学生（预期，典型错误）**："Cu 能导电，Cu 是电解质吧？""食盐水导电，食盐水是电解质！"

**教师（追问/理答）**："两个经典错答，根子在同一处——忘了'**化合物**'。Cu 是单质、食盐水是混合物（NaCl+水），它们**既不是电解质也不是非电解质**。判据第一步：先问'是不是化合物'，不是直接踢出局。"

**教师**："第二类坑：CO₂ 溶于水后溶液能导电，CO₂ 是电解质吗？"

**学生（预期，典型错误）**："能导电，应该是电解质。"

**教师（追问/理答）**："错。CO₂ 溶于水导电，是因它和水反应生成 H₂CO₃，是 H₂CO₃ 电离出 H⁺ 和 HCO₃⁻；CO₂ **自身**在水溶液里不电离。同理 SO₂ 靠 H₂SO₃、NH₃ 靠 NH₃·H₂O 电离。所以 CO₂、SO₂、NH₃ 都是**非电解质**，而 H₂CO₃、H₂SO₃、NH₃·H₂O 才是弱电解质。判据第二步：看'谁'电离，别被'溶液导电'带偏。"

**教师（制造冲突）**："BaSO₄ 难溶几乎不导电，它是不是非电解质？"

**学生（预期，典型错误）**："难溶，溶都溶不了，应不是电解质。"

**教师（追问/理答）**："这正是'难溶≠非电解质'。先记结论：BaSO₄ **是强电解质**——它溶解的那一点点，100% 电离。'溶不溶得出来'和'溶出来后电不电离'是两件事。"

### 环节三：强/弱电解质本质与电离方程式

**【逐字稿】**

**教师**："强电解质 = 在水里**完全电离**（用 =）；弱电解质 = **部分电离**（存在电离平衡，用 ⇌）。先破执念：强弱看'电离程度'，不看'溶解度'。三连比——"

**教师**："BaSO₄：难溶但溶解部分全电离→**强**；CH₃COOH：极易溶但只部分电离→**弱**；Ca(OH)₂：微溶但溶解部分全电离→**强**。所以'难溶=弱电解质'是错的。"

**学生（预期，典型错误）**："那 BaSO₄ 电离式用 '=' 还是 '⇌'？"

**教师（追问/理答）**："BaSO₄ 是强电解质，用 '='；但它难溶，整体写电离式意义不大。重点清单：NaCl、HCl、NaOH、BaSO₄、Ca(OH)₂、熔融 NaOH 全用 '='；CH₃COOH、NH₃·H₂O、H₂CO₃、H₃PO₄、Cu(OH)₂ 用 '⇌'。多元弱酸**分步**写，不能一步写完。"

**教师**："练手：H₃PO₄ 三元中强酸，写三步；H₂CO₃ 二元弱酸，写两步。"

**学生（预期）**："H₃PO₄ ⇌ H⁺ + H₂PO₄⁻；H₂PO₄⁻ ⇌ H⁺ + HPO₄²⁻；HPO₄²⁻ ⇌ H⁺ + PO₄³⁻。H₂CO₃ ⇌ H⁺ + HCO₃⁻；HCO₃⁻ ⇌ H⁺ + CO₃²⁻。"

**教师（追问/理答）**："对。多元弱碱（如 Cu(OH)₂）则一步写齐：Cu(OH)₂ ⇌ Cu²⁺ + 2OH⁻。再看酸式盐——这是易错高发区："

**教师**："NaHSO₄ 在水溶液完全电离成 Na⁺ + H⁺ + SO₄²⁻（HSO₄⁻ 强酸的酸式根，进一步电离）；NaHSO₃ = Na⁺ + HSO₃⁻（HSO₃⁻ 是弱酸的酸式根，**不拆**，保留 HSO₃⁻）；NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 弱酸酸式根不拆）。规律：**弱酸的酸式根一律不拆**，只有强酸的酸式根（HSO₄⁻ 在稀溶液中）才继续电离出 H⁺。"

**教师（抛反直觉）**："最后：浓 H₂SO₄ 为什么不导电？"

**学生（预期，典型错误）**："硫酸是强酸，应该导电啊。"

**教师（追问/理答）**："导电靠自由移动的离子。浓 H₂SO₄ 里水极少，几乎以 H₂SO₄ 分子态存在，电离被'渴死'；只有加水稀释成稀 H₂SO₄，才大量电离出 H⁺ 和 SO₄²⁻ 而导电。所以'强酸'≠'任何浓度都导电'，关键看有没有水让它电离——这也直接决定它写离子方程式时**浓的不拆、稀的拆**。"

### 易错点速记对照表（当堂投影，配逐字稿小结）

| 易错表述 | 正解 | 根源 |
|---|---|---|
| Cu 能导电 → Cu 是电解质 | Cu 是单质，既不是电解质也不是非电解质 | 忘"化合物"前提 |
| 食盐水导电 → 食盐水是电解质 | 食盐水是混合物（NaCl+水），既不是 | 忘"化合物"前提 |
| CO₂ 溶液导电 → CO₂ 是电解质 | CO₂ 自身不电离，是非电解质；H₂CO₃ 才是弱电解质 | 把"溶液导电"等同"该物质电离" |
| BaSO₄ 难溶 → 弱电解质 | BaSO₄ 溶解部分全电离，是强电解质 | 混淆溶解度与电离程度 |
| CH₃COOH 易溶 → 强电解质 | CH₃COOH 部分电离，是弱电解质 | 混淆溶解度与电离程度 |
| 浓 H₂SO₄ 是强酸 → 一定导电 | 浓 H₂SO₄ 分子态为主，不电离，不导电 | 忽略"水才能让它电离" |

**【逐字稿小结】**

**教师**："这张表贴在学案第一页。六行全是'电离判据'坑，核心一句话——**电解质先问'是不是化合物'，强弱只看'电离程度'不看'溶解度'**。记住：Cu 是单质、食盐水是混合物，连入场券都没有；BaSO₄ 难溶却是强电解质，因为它溶出来的那一点点全电离了；CH₃COOH 易溶却是弱电解质，因为它只电离了一小部分。下一课时我们拿这些离子做反应——离子反应的本质，就是让这些自由离子的浓度降下来。"

## 七、板书设计

```
**Part 1 本课逻辑主线（主板书）**——逻辑：导电现象→电离(钻进离子)→自由离子。

【A 电离】
- 导电本质=自由移动的带电粒子（金属→自由电子；溶液/熔融→自由离子）；导电能力 ∝ 离子浓度 × 离子所带电荷数
- 电解质=在水溶液中**或**熔融状态下能导电的**化合物**（前提：必须是化合物！Cu、食盐水既不是电解质也不是非电解质）
- 非电解质=两态均不能导电的化合物（蔗糖、酒精、CCl₄、CO₂、SO₂、NH₃）；关键：CO₂/SO₂/NH₃ 自身不电离→非电解质，其水溶液导电是因与水生成 H₂CO₃/NH₃·H₂O（才是弱电解质）电离
- 强电解质=完全电离（"="）：强酸/强碱/大多数盐（含难溶盐 BaSO₄ 溶解部分完全电离）、活泼金属氧化物（熔融导电）；弱电解质=部分电离（"⇌"）：弱酸/弱碱/水
- 铁律：难溶≠弱（BaSO₄ 强）、易溶≠强（CH₃COOH 弱）、"通电才电离"是错（阿伦尼乌斯：电离自发，通电前已有离子）
- 酸式盐：NaHSO₄=Na⁺+H⁺+SO₄²⁻（电离出 H⁺ 显酸）；NaHCO₃=Na⁺+HCO₃⁻（HCO₃⁻ 弱酸根不拆、部分电离 HCO₃⁻⇌H⁺+CO₃²⁻）；NaHSO₃=Na⁺+HSO₃⁻
- 多元弱酸分步：H₃PO₄⇌H⁺+H₂PO₄⁻⇌H⁺+HPO₄²⁻⇌H⁺+PO₄³⁻；H₂CO₃⇌H⁺+HCO₃⁻⇌H⁺+CO₃²⁻
- 浓 H₂SO₄ 分子态不导电、不拆；稀 H₂SO₄ 才拆
```

## 八、作业布置（三层，区分度）

> 分层说明：必做保底全体学生，选做面向中等及以上，挑战面向拔高与有志高考难题者；批改时按三层分别给反馈，错题回扣"易错点速记对照表"。

- **必做**（基础达标，覆盖电解质判定与电离方程式）：
  ① 判断下列物质是否为电解质，若是则指出强/弱：Cu、食盐水、CO₂、SO₂、NH₃、BaSO₄、CH₃COOH、NaOH、H₂SO₄、蔗糖。逐个说明理由（尤其注意"化合物"前提）。
  ② 写出下列物质溶于水的电离方程式：NaHSO₄、NaHCO₃、NaHSO₃、H₂CO₃（两步）、H₃PO₄（三步）、CH₃COOH、NH₃·H₂O。
  ③ 判断正误并说明理由：a. 浓 H₂SO₄ 是强酸所以一定导电；b. 难溶的物质一定是非电解质；c. 通电后才产生离子。

- **选做**（能力提升）：
  ① 向蒸馏水中逐量加入 NaCl 粉末，电导读数持续上升。请解释这一现象说明了什么（提示：电离是自发过程，通电只是让已有离子定向移动）。
  ② 已知某化合物 X 的水溶液能导电，设计一个实验方案判断 X 本身是电解质还是"与水反应后的产物是电解质"（提示：类比 CO₂ 与 H₂CO₃ 的关系，可用非水溶剂或检测溶液中的粒子种类）。
  ③ 比较同浓度的 NaCl 溶液与 CaCl₂ 溶液的导电能力强弱并说明理由（提示：导电能力 ∝ 离子浓度 × 离子所带电荷数）。

- **挑战**（拔高区分）：
  ① 已知 H₃PO₄ 是三元中强酸，其三步电离常数依次减小（K₁ ≫ K₂ ≫ K₃）。请解释"为何 NaH₂PO₄ 溶液显酸性而 Na₂HPO₄ 溶液显碱性"，并写出 H₂PO₄⁻ 的电离与水解方程式（提示：比较 K₂ 与对应水解常数的相对大小）。
  ② 熔融状态下 NaHSO₄ 只能电离出 Na⁺ 与 HSO₄⁻，而水溶液中能电离出 Na⁺、H⁺、SO₄²⁻。请解释这一差异，并据此判断熔融 NaHSO₄ 与 NaHCO₃（受热易分解）在电离行为上的不同。

---

**作业解析提示（供批改与讲评）**

- 必做①：Cu（单质，既不是）、食盐水（混合物，既不是）、CO₂/SO₂/NH₃（非电解质，自身不电离）、BaSO₄（强，溶解部分全电离）、CH₃COOH（弱）、NaOH（强）、H₂SO₄（强）、蔗糖（非电解质）。
- 必做②：NaHSO₄ = Na⁺ + H⁺ + SO₄²⁻；NaHCO₃ = Na⁺ + HCO₃⁻；NaHSO₃ = Na⁺ + HSO₃⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻，HCO₃⁻ ⇌ H⁺ + CO₃²⁻；H₃PO₄ ⇌ H⁺ + H₂PO₄⁻，H₂PO₄⁻ ⇌ H⁺ + HPO₄²⁻，HPO₄²⁻ ⇌ H⁺ + PO₄³⁻；CH₃COOH ⇌ CH₃COO⁻ + H⁺；NH₃·H₂O ⇌ NH₄⁺ + OH⁻。
- 必做③：a 错（浓硫酸分子态为主，不电离、不导电）；b 错（BaSO₄ 难溶但溶解部分全电离，是强电解质）；c 错（电离自发，通电前已有离子）。
- 选做①要点：读数上升说明加入的 NaCl 不断电离出自由离子，离子浓度增大，导电性增强；若需通电才电离，则不通电时不应有离子，与"加盐即导电"矛盾。
- 挑战①要点：H₂PO₄⁻ 的电离（K₂ ≈ 6.2×10⁻⁸）强于其水解（Kh = Kw/K₁ ≈ 10⁻¹⁴/7.1×10⁻³ ≈ 1.4×10⁻¹²），故显酸性；HPO₄²⁻ 的水解（Kh = Kw/K₂ ≈ 1.6×10⁻⁷）强于其电离（K₃ ≈ 4.8×10⁻¹³），故显碱性。
- 挑战②要点：熔融时无水的参与，HSO₄⁻ 内的共价键不断裂，只能电离出 Na⁺ 与 HSO₄⁻；水溶液中水分子的作用使 HSO₄⁻ 进一步电离出 H⁺。NaHCO₃ 受热分解为 Na₂CO₃、H₂O、CO₂，无法获得熔融态，故只讨论其水溶液行为。
