# 第二章 海水中的重要元素——钠和氯 · 知识体系与概念关联图

> 配套 10 课时教案使用。本章是元素化合物学习的开篇，不是孤立知识点的堆砌，而是围绕"**类别视角 × 价态视角**"双轴（承接第一章）与"**宏—微—符三重表征**"展开的一个体系，并用"**物质的量 n**"把定性研究推向定量。本图给出系统骨架、钠系/氯系转化网络、定量桥梁、双轴分类与第一章的打通、各课时站位与后续接口，供板书"体系关联站位图"衔接，也便于学生建立结构化认知。内容以 [[钠及其化合物]]、[[氯及其化合物]]、[[物质的量与气体计算]] 为据，竞赛衔接见 [[碱金属]]、[[卤素]]。

## 一、本章知识系统的"三层视角 + 双轴"

```
              钠和氯 · 元素化合物体系
   ┌──────────────────┬──────────────────┐
   │   宏观视角          │   微观视角          │
   │   现象 / 性质 / 用途  │   结构 / 粒子 / 电子  │
   └──────────────────┴──────────────────┘
           符号视角：化学方程式 / 离子方程式
   ┌──────────────────────────────────────────┐
   │   双轴分类（承接第一章"类别 × 价态"）         │
   │   轴① 类别视角：单质/氧化物/碱/盐/酸          │
   │   轴② 价态视角：Na 0→+1；Cl 0→−1/+1/+5/+7   │
   └──────────────────────────────────────────┘
   三重表征：宏观现象 ⇄ 微观粒子 ⇄ 符号表达
```

- **三层视角**：① 宏观——看得见的现象、性质与用途（钠"浮熔游响红"、Cl₂ 黄绿色、HClO 永久漂白）；② 微观——结构、粒子与电子（Na 最外层 1e 强还原、Cl 最外层 7e 强氧化、过氧根 O₂²⁻、氯水多粒子共存、电子转移）；③ 符号——化学/离子方程式表达。
- **双轴**：同一物质/反应可同时按"类别（它属于哪类化合物）"与"价态（元素处于什么化合价）"两个坐标定位，二者交叉预测性质（见第二节）。

## 二、钠系转化网络（文字 + 箭头，标注反应类型）

```
                 O₂(常温)            O₂(点燃)
                   │                    │
                   ▼                    ▼
        Na ──→ Na₂O              Na ──→ Na₂O₂
   (强还原)   (白, O−2)    (强还原)   (淡黄, O−1 过氧根)
        │                    │  │
        │ 与H₂O/CO₂           │ 2Na₂O₂+2H₂O→4NaOH+O₂↑  (歧化, redox)
        ▼                    │ 2Na₂O₂+2CO₂→2Na₂CO₃+O₂ (歧化, redox)
      NaOH                   ▼
        │               Na₂O₂ 作供氧剂(呼吸面具/潜艇)
        │
        │ 吸收CO₂
        ▼
   Na₂CO₃ ⇌ NaHCO₃
   (纯碱)    (小苏打)
    │  Na₂CO₃+CO₂+H₂O→2NaHCO₃ (非氧化还原)
    │  NaHCO₃+NaOH→Na₂CO₃+H₂O (非氧化还原)
    │  2NaHCO₃ →(△) Na₂CO₃+H₂O+CO₂↑ (非氧化还原/分解)
    ▼
   侯氏制碱：NaCl+NH₃+CO₂+H₂O→NaHCO₃↓+NH₄Cl →(△) Na₂CO₃
    │
    ▼
   焰色反应：Na 黄色、K 紫色(透蓝钴玻璃) —— 物理变化，非氧化还原
```

- 标注：**氧化还原**——Na 与 O₂/H₂O/CO₂、Na₂O₂ 歧化；**非氧化还原**——Na₂O/Na₂O₂ 生成 NaOH 的酸碱型、Na₂CO₃⇌NaHCO₃ 的复分解/分解。

## 三、氯系转化网络（文字 + 箭头）

```
                点燃
   Cl₂ ──────→ HCl (H₂+Cl₂→2HCl, 苍白色火焰)        [非氧化还原]
    │
    │ 与H₂O (可逆)
    ▼
   Cl₂ + H₂O ⇌ HCl + HClO
    │                │
    │                ├─ HClO：强氧化、永久漂白(可逆vs SO₂)
    │                └─ 久置：2HClO→(光照)2HCl+O₂↑ → 变稀盐酸
    │
    │ 与碱 (歧化, redox)
    ▼
   Cl₂ + 2NaOH → NaCl + NaClO + H₂O
    │                │
    │                └─ 84消毒液 = NaClO 溶液
    ▼
   Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O
                      │
                      └─ 漂白粉，有效成分 Ca(ClO)₂ (有效氯~35%)
    │
    │ Cl⁻ 检验：AgNO₃+稀HNO₃ → AgCl↓(白)/AgBr↓(淡黄)/AgI↓(黄)
    ▼
   卤素递变(氧化性)：F₂ > Cl₂ > Br₂ > I₂  (依次减弱)
   与H₂：冷暗爆炸 → 光照爆炸 → 加热 → 持续加热可逆
```

- 制备（上游）：实验室 MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O；工业 2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑（氯碱工业）；尾气 Cl₂ + 2NaOH → NaCl + NaClO + H₂O。

## 四、定量桥梁：物质的量 n

```
            宏观可称量                微观粒子数
         ┌──────────────┐         ┌──────────────┐
   质量 m │              │  N (粒子数)│              │
   体积 V │   枢纽 n      │← N/Nₐ →│  Nₐ≈6.022×10²³│
   (溶液) │   (mol)      │         │   mol⁻¹       │
         └──────────────┘         └──────────────┘
   核心关系：
      n = N / Nₐ = m / M = V / Vₘ = c · V
   四大量：n(mol) · M(g/mol) · Vₘ(22.4 L/mol, STP) · c(mol/L)
   稀释：c₁V₁ = c₂V₂      换算：c = 1000ρω / M      阿伏加德罗定律
```

- n 是"桥"：一端连宏观可称量（m、V 溶液），一端连微观粒子数（N），把前两节定性性质研究升级为定量研究。

## 五、双轴分类与第一章打通

```
            "类别 × 价态"二维图（同第一章骨架）
   价态轴 ↑
    +7  │                          HClO₄/Cl₂O₇
    +5  │            NaClO₃
    +1  │    HClO / NaClO           (Cl含氧酸盐)
     0  │ Na  Cl₂ ─────── 单质
    −1  │ NaCl / HCl / Ca(ClO)₂中Cl ── 最低价(只还原)
    −2  │ Na₂O / Na₂O₂中O
    −1  │ Na₂O₂中O(过氧根, 中间价→歧化)
     0  │ Na(单质, 强还原, 只氧化)
    ↓ 类别轴 → 单质 / 氧化物 / 碱 / 盐 / 酸
   规律：同价态横向变类别 = 非氧化还原(如 Na₂O→NaOH→Na₂CO₃)
         纵向变价态       = 氧化还原(如 Na→Na⁺、Cl₂→Cl⁻/ClO⁻)
```

- **两标签法（与第一章双轴一致）**：钠/氯的任一反应同时贴"是否离子反应""是否氧化还原"两个标签。
  - 离子反应 + 氧化还原：2Na + 2H₂O → 2NaOH + H₂↑、Cl₂ + H₂O ⇌ HCl + HClO（在水溶液中）。
  - 离子反应 + 非氧化还原：Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑（复分解）、NaHCO₃ + NaOH → Na₂CO₃ + H₂O。
  - 氧化还原 + 非离子：2Na + O₂ → Na₂O₂、2Na + Cl₂ → 2NaCl（固/气反应，无自由离子）。
  - Cl₂ 与碱的歧化（Cl₂ + 2NaOH → NaCl + NaClO + H₂O）承接第一章"歧化/归中"规律。

## 七、与后续知识系统的接口

- **钠/氯研究范式（双轴 + 宏微符）** → 后续"铁与金属材料""铝及其化合物""硫、氮及其化合物"的可迁移方法论；→ 必修二"物质结构·元素周期律"（碱金属、卤素族递变规律在此系统化，[[碱金属]]、[[卤素]] 深化）。
- **氯水 / 离子反应 / 氧化还原** → 选择性必修1《化学反应原理》水溶液中的离子反应与平衡（电离平衡、水解平衡、沉淀溶解平衡）；→ 选择性必修1 电化学（原电池、电解池，氯碱工业即电解应用）。
- **物质的量 n（计量桥梁）** → 选择性必修 滴定、产率、关系式计算、气体计算（PV = nRT、阿伏加德罗定律推论）的核心等量关系；→ 后续所有定量章节的计量前提。
- **第一章方法承接**：钠/氯研究沿用第一章"分类（类别视角）→ 预测性质 → 实验验证 → 用离子反应/氧化还原解释"；Na₂O₂ 与水/CO₂、Cl₂ 与碱是歧化反应（呼应 1.4 归中/歧化规律）；氯水多粒子共存是"离子反应 + 氧化还原"综合；"物质的量"是连接第一章"离子浓度"与后续定量计算的计量桥梁。
