# 教案：2.10 物质的量在化学计算中的应用（必修第一册 第二章 海水中的重要元素——钠和氯）

> **课时元信息**：第 2 章 / 2.10 物质的量在化学计算中的应用 / 第 10 课时 / 45 min / 新授课 / 高一基础班 + 综合提升
> 库内锚点：[[物质的量与气体计算]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：本章"定量综合提升课"——把先前分散学过的"四量"（n / Nₐ / M / Vₘ / c）统一为以 **n 为枢纽**的关系网，并向上对接化学方程式（系数即物质的量比）、守恒法、关系式法、Nₐ 陷阱系统归纳、过量计算，向下衔接第一章离子浓度 / 电子守恒与后续滴定、产率、电化学。本节是"定量观"的方法论收口课，也是高考高频薄弱点（Nₐ 陷阱、守恒选错、不会写多步关系式）的集中突破课。

## 一、课标对应

- **内容要求**：能认识物质的量在化学定量研究中的重要作用，能运用物质的量、摩尔质量、气体摩尔体积、物质的量浓度之间的相互关系进行简单计算；能结合化学方程式进行有关物质的量、质量、气体体积、物质的量浓度的计算；认识守恒思想（质量守恒、原子守恒、电子守恒、电荷守恒）与关系式法在化学计算中的价值。
- **学业质量水平**：必修水平 2——能基于物质的量建立宏观（质量、体积）与微观（粒子数）的定量联系，能选用合适的计量关系与守恒视角解决化学计算问题；能识别常见 Nₐ 陷阱，体会化学定量表达的严谨性。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（用 n 把可称量的宏观质量/体积与不可数的微观粒子数统一起来，落实"宏—微—符"三重表征）；
  2. **变化观念与平衡思想**（认识化学反应中"量"按比例、守恒、可逆地变化，建立定量动态观）；
  3. **证据推理与模型认知**（建立"关系网模型""守恒模型""关系式模型"，用模型统领多步计算）；
  4. **科学探究与创新意识**（在综合换算、方程式计算、多步关系式中自主选路径、验结果）；
  5. **科学态度与社会责任**（以 Nₐ 陷阱为例，养成"条件、状态、构成三查"的定量严谨态度；用环境检测、安全气囊真实情境体会计量的社会价值）。

## 二、学情分析（本课时）

**【课前诊断·5 处典型误解预判】**

学生已在前序课时分别建立四量概念：物质的量 n、阿伏加德罗常数 Nₐ（N = n·Nₐ）、摩尔质量 M（m = n·M）、气体摩尔体积 Vₘ（V = n·Vₘ，标况 22.4 L/mol）、物质的量浓度 c（c = n/V）。但"分开学、分开用"导致三个薄弱：一是**综合换算易乱**——面对"先给质量、再求粒子数、再求标况体积"的多跳链条常常漏掉 n 这个枢纽，或在 c = n/V 中把"溶液体积"误当"溶剂体积"；二是**Nₐ 陷阱 / 守恒 / 关系式是高考高频但学生普遍薄弱**——见到"状态/条件/构成"陷阱就错、不会主动判断标况与气态、不会数清分子内原子数；三是**方法层面不会选**——守恒法"该用哪种守恒"拿不准（电子守恒 vs 原子守恒 vs 电荷守恒混淆），多步反应不会抓关键元素写关系式，电子守恒在滴定/产率中的迁移不会用。典型误解：① "22.4 L 一定对应 1 mol"（忽略标况与气态双前提）；② "1 mol 物质都含 Nₐ 个原子"（混淆分子数与原子数、忽略单原子稀有气体）；③ "氧化还原电子转移数按系数直接数"（如 Na₂O₂ 与水误以为每 mol 转移 2 mol e⁻）；④ "多步反应逐步算"（不会用关系式一步到位）；⑤ "离子方程式配平只看原子不看电荷"（漏电荷守恒）。对策：以 n 为枢纽画一张"关系网"把四量钉死；用"四守恒 + 关系式"两套模型替代死算；把 Nₐ 陷阱做**六类系统归纳**（状态 / 条件 / 微粒构成 / 电子转移 / 水解电离 / 可逆平衡），逐类配"反例 + 判据"，并衔接第一章离子浓度与电子守恒、后续滴定与产率。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"画 n 为枢纽的关系网、把四量换算落成一张图"活动，培养**宏观辨识与微观探析**素养：体会 n 是联结宏观可称量质量/体积与微观不可数粒子数的唯一桥梁，落实"宏—微—符"三重表征。
- 通过"化学方程式系数即物质的量比""守恒法选对守恒视角""关系式法抓关键元素"的建模活动，培养**证据推理与模型认知**素养：建立关系网模型、四守恒模型、关系式模型，用模型统领多步定量问题。
- 通过辨析 Nₐ 六大类陷阱、在可逆/水解/电离情景下校正直觉，培养**变化观念与平衡思想**素养：认识化学反应中"量"受状态、条件、平衡、电离程度制约，建立定量严谨的动态观。
- 通过环境检测（SO₂/NOₓ 浓度）、汽车安全气囊（NaN₃→N₂ 用 PV=nRT 算质量）的真实情境计算，培养**科学态度与社会责任**素养：体会定量计量在公共安全与环境治理中的价值。
- 通过综合换算链"多跳反推"的探究，培养**科学探究与创新意识**素养：自主选路径、验单位、查陷阱，敢于处理跨章节综合题。

### 3.2 学习目标（学生能……，可观测）

- 能**画出以 n 为枢纽的关系网**（m ↔ n ↔ N ↔ V(气) ↔ c），在给定任意一量时正确反推其余量，且不混淆 Vₘ 的"标况 + 气态"双前提、c = n/V 中的 V 为溶液体积。
- 能**结合化学方程式计算**：明确"系数比 = 物质的量比"，对 2Na + 2H₂O = 2NaOH + H₂↑ 这类反应，由已知质量/物质的量正算或逆推气体体积、质量、溶液浓度。
- 能**针对问题选对守恒法**：质量守恒、原子守恒、电子守恒、电荷守恒各举一例；对氧化还原反应能正确数清电子转移物质的量（如 Na₂O₂ 与水每 mol 转移 1 mol e⁻、1 mol Fe 与 Cl₂ 转移 3 mol e⁻）。
- 能**写多步反应关系式**：用关键元素守恒把 NH₃→HNO₃、侯氏制碱（Na⁺→NaHCO₃→Na₂CO₃）、海水提镁（Mg²⁺→Mg）压缩为一步关系式并定量计算。
- 能**识别并归类 Nₐ 六大类陷阱**（状态/条件/微粒构成/电子转移/水解电离/可逆平衡），逐类给出"正确认知 + 反例 + 判据"，并衔接第一章离子浓度与电子守恒、后续滴定与产率。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 四、教学重难点

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | 以 n 为枢纽的四量关系网（m↔n↔N↔V(气)↔c） | 四量"分开学"导致不会综合跳转 | 让学生自画关系网，把 n 圈成枢纽，每条边标公式与单位 | 能就"给定质量反推标况体积/粒子数/浓度"连续换算不出错 |
| 重点 | 化学方程式系数 = 物质的量比 | 习惯按质量比硬算，忽略化学计量数含义 | 用 2Na+2H₂O=2NaOH+H₂↑ 同时做正向（给 Na 求 H₂）与逆向（给 H₂ 求需 Na） | 能由已知量正/逆推气体体积、质量、浓度 |
| 重点 | 四守恒模型（质量/原子/电子/电荷） | 不会选守恒视角，电子与原子守恒混淆 | 对比表：何时用原子守恒、何时必用电子守恒、何时用电荷守恒（离子方程式） | 对氧化还原题能正确选电子守恒、对离子方程式能补电荷守恒 |
| 重点 | 关系式法（关键元素守恒压缩多步） | 多步反应只会逐步算，易累积误差 | 抓"不变量元素"写关系式：NH₃~HNO₃、2NaCl~Na₂CO₃、Mg²⁺~Mg | 能就侯氏制碱、海水提镁写出关系式并算利用率/产量 |
| 难点 | Nₐ 陷阱六类系统归纳（状态/条件/构成/电子/水解电离/可逆） | 直觉化、零散记，遇上变式就错 | 六类逐张"正确认知 + 反例/判据"卡，强调"状态+条件+构成三查" | 能对 8–10 项判断题逐类命名陷阱并给正确值 |
| 难点 | 电子转移物质的量定量 | 按系数直接数或搞错歧化/归中 | 标价态升降，用"升价总数 = 降价总数 = 转移 e⁻ 数" | 对 Na₂O₂ 与水、Fe 与 Cl₂ 等正确给出每 mol 转移 e⁻ 数 |
| 难点 | 过量计算（限量反应物判定） | 不会用 n 比 vs 系数比判限量 | 用 n(实)/ν 比值最小者定限量，演示"谁先耗尽谁限量" | 能给双已知量反应判定限量并算产物 |
| 难点 | PV=nRT 非标况气体计算（安全气囊） | 只会 22.4 L/mol，不会用状态方程 | 由 PV=nRT 反推 m(NaN₃)；对比标况公式适用范围 | 能就气囊体积/压强/温度算所需 NaN₃ 质量 |

> 说明：本节为"定量综合提升课"，内容密度高；时间块以"Nₐ 陷阱归纳 + 关系式法 + 守恒选视角"为优先，确保安全气囊/环境检测仅作应用点睛。

**课前诊断小测（约 2 min，导入前快速自测，仅口答）**

1. 标况下 22.4 L 任何物质都含 Nₐ 个粒子吗？（否——须气态；H₂O/SO₃ 非气）
2. 1 mol O₂ 含 2Nₐ 个原子，对吗？（对；但 1 mol He 仅 Nₐ 原子）
3. 5.6 g Fe 与 Cl₂ 完全反应转移多少 mol e⁻？（0.1 mol Fe 转 0.3 mol e⁻）
4. 把 100 mL 1 mol/L NaCl 稀释到"加 100 mL 水"，终浓度是 0.5 mol/L 吗？（此处数值恰为 0.5，但理由须是"终体积 200 mL"而非"加水量"——故意设此易混点，正解 c=0.1×100/200=0.5）

> 诊断意图：暴露"状态/构成/电子/溶液体积"四类直觉错误，针对性导入关系网与 Nₐ 六类归纳。

**导入**

**教师**："同学们，前面我们分四次认识了四个'量'：Nₐ 把 n 连到粒子数，M 把 n 连到质量，Vₘ 把 n 连到气体体积，c 把 n 连到溶液浓度。可考试从来不单独考——它常给'质量'，问你'标况下体积'或'含多少原子'。请问：把所有量连起来的'枢纽'是谁？"

**学生（预期）**："是 n，物质的量！"

**教师（追问/理答）**："对，**n 是唯一枢纽**：m ↔ n ↔ N ↔ V(气) ↔ c，所有换算都经过 n。今天我们就把这张网钉死，再把它接到化学方程式、守恒、关系式，最后集中攻克高考最爱考的——阿伏加德罗常数 Nₐ 陷阱。"

**探究 1（关系网 + 与方程式结合）**

**教师**："先写关系网五条边：n = N/Nₐ = m/M = V/Vₘ(气,标况) = c·V(溶液)。注意 Vₘ 这条边有'双前提'——标况 + 气态；c 这边 V 是溶液体积不是溶剂体积。现在接入方程式：2Na + 2H₂O = 2NaOH + H₂↑，系数比就是物质的量比。给定 4.6 g Na（0.2 mol），生成 H₂ 多少？"

**学生（预期）**："Na 与 H₂ 系数比 2:1，所以 H₂ 是 0.1 mol；标况体积 2.24 L，质量 0.2 g。"

**教师（追问/理答）**："完全正确。这个'系数比=物质的量比'是化学方程式计算的命根子。逆向也会：若已知要收集 3.36 L（标况）H₂，需多少克 Na？3.36 L 即 0.15 mol H₂，反推需 0.3 mol Na = 6.9 g。注意——所有'质量↔体积↔粒子数'的跳转都必须先落到 n，别跳步。"

**探究 1.5（关系网综合跳转示范）**　（宏—微—符三重表征：宏观 m/V/c ⇄ 微观 N/粒子数 ⇄ 符号 n = N/Nₐ = m/M = V/Vₘ = c·V，统一借 n 中转）

**教师**："光会单跳不够，考试爱考'三连跳'。例：含 5.4 g H₂O 的样品，若把它等效为标况下气态（假设），体积是多少？再问：这些 H₂O 含多少 mol H 原子、多少个质子？走一遍网：5.4 g → n = 5.4/18 = 0.3 mol H₂O；标况气态体积 V = 0.3×22.4 = 6.72 L；H 原子 = 0.3×2 = 0.6 mol；1 个 H₂O 含 10 个质子（O 8 + 2H），故质子 = 0.3×10 = 3 mol，即 3Nₐ 个。再看 c=n/V 的 dilution 链：将 100 mL 2 mol/L NaCl 稀释至 500 mL，c₂ = c₁V₁/V₂ = 2×100/500 = 0.4 mol/L——注意 V 始终是**溶液体积**，是'加水至 500 mL'不是'加 500 mL 水'（若加 500 mL 水则终体积 600 mL，c=0.33 mol/L，错）。"

**学生（预期，典型错误）**："稀释是加 500 mL 水到原来的 100 mL 里？"

**教师（追问/理答）**："这是 c=n/V 头号坑。稀释公式 c₁V₁=c₂V₂ 里的 V₂ 是**最终溶液体积**。'稀释至 500 mL'意思是终体积 500 mL（加约 400 mL 水）；若理解成'加 500 mL 水'，终体积变成 600 mL，浓度算错。判据：容量瓶定容是'加水至刻度线'，永远把 V 当终体积。这条和第一章'配制一定物质的量浓度溶液'的操作完全呼应。"

**宏—微—符三重表征（综合跳转环节嵌入）**

| 表征层次 | 综合跳转示例（5.4 g H₂O） | 关键提醒 |
|---|---|---|
| 宏观 | m=5.4 g →（若气态）V≈6.72 L；稀释前后溶质质量守恒 | 体积随状态而变，质量不随状态变 |
| 微观 | N=0.3Nₐ 分子；含 0.6 mol H 原子、3 mol 质子 | 原子/质子数只与 n 与组成有关 |
| 符号 | n=m/M；V=n·Vₘ；c₁V₁=c₂V₂ | Vₘ 限标况气态；c 中 V 为溶液体积 |

**探究 2（守恒法）**

**教师**："守恒法有四兄弟，关键是'选对视角'。① 质量守恒——反应前后总质量不变；② 原子守恒——某种原子反应前后数目不变（配平本质）；③ 电子守恒——氧化还原中升价总数=降价总数=转移 e⁻ 数；④ 电荷守恒——离子方程式两边电荷代数和相等。先看电子守恒：Na₂O₂ 与水 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑，O 从 −1 一部分到 0（O₂）、一部分到 −2（OH⁻），每 2 mol Na₂O₂ 转移 2 mol e⁻，所以**每 1 mol Na₂O₂ 转移 1 mol e⁻**。再看 Fe 与 Cl₂：2Fe + 3Cl₂ = 2FeCl₃，Fe 从 0→+3，1 mol Fe 转移 3 mol e⁻。"

**学生（预期，典型错误）**："Na₂O₂ 与水，O₂ 有 2 个 O，所以每 mol Na₂O₂ 转移 2 mol e⁻？"

**教师（追问/理答）**："这正是坑。要数'价态变化'不是数'分子里的 O 数'。2 mol Na₂O₂ 才生成 1 mol O₂（2 个 O 从 −1 升到 0，共失 2e⁻），故 2 mol Na₂O₂ 对应转移 2 mol e⁻，归一就是 1 mol Na₂O₂ 转移 1 mol e⁻。判据：先标价→再算'升价总数=降价总数=转移 e⁻ 数'，绝不按系数硬数。电荷守恒示例：离子方程式 2Fe³⁺ + 3S²⁻ = 2FeS↓ + S↓ 之类先不展开；单看半反应 MnO₄⁻ + 8H⁺ + 5e⁻ = Mn²⁺ + 4H₂O，两边电荷：左 −1+8−5=+2，右 +2，守恒。写完整离子方程式时务必两边电荷代数和相等——这是第一章离子反应里'电荷守恒'的直接应用。"

**四守恒选视角决策表（投影，供学生归档）**

| 问题特征 | 该用哪种守恒 | 示例 |
|---|---|---|
| 反应前后总质量 / 总物质的量（非气体）不变 | 质量守恒 | 配平后左右总质量相等 |
| 某元素原子数目在反应前后不变（尤其多步） | 原子守恒 | 侯氏制碱 2NaCl~Na₂CO₃（Na 守恒） |
| 氧化还原、求转移电子数 / 配平升降 | 电子守恒 | Na₂O₂+H₂O、Fe+Cl₂、KMnO₄+HCl |
| 离子方程式、两边电荷代数和 | 电荷守恒 | MnO₄⁻+8H⁺+5e⁻=Mn²⁺+4H₂O；Fe³⁺/S²⁻ 反应 |
| 综合（既变价又变原子） | 电子 + 原子双守恒 | 氧化还原配平（电子守恒定系数、原子守恒补 H/O） |

**关键判据**：先判"是否氧化还原"——是则电子守恒必用；写离子方程式则电荷守恒必查；多步反应优先原子守恒压成关系式。绝不"见题乱套"。

**探究 3（关系式法 + 深度）**

**教师**："多步反应别逐步算，抓'关键元素守恒'压缩成一步关系式。三例：① 氨氧化制硝酸，N 全程守恒——NH₃ ~ HNO₃（1:1）；② 侯氏制碱：NaCl 饱和食盐水通 NH₃、CO₂ 得 NaHCO₃，焙烧得 Na₂CO₃，Na⁺ 守恒：2NaCl ~ 2NaHCO₃ ~ Na₂CO₃，即 2 mol NaCl 对应 1 mol Na₂CO₃（衔接 2.3 侯氏制碱）；③ 海水提镁：Mg²⁺ ~ MgCl₂ ~ Mg(OH)₂ ~ MgO ~ Mg，Mg 元素守恒，1 mol Mg²⁺ 对应 1 mol Mg。"

**学生（预期）**："所以侯氏制碱里 NaCl 的利用率，就看 Na⁺ 最终有多少进 Na₂CO₃？"

**教师（追问/理答）**："对。若 1 mol NaCl（理论全部转化），按 2NaCl~Na₂CO₃，应得 0.5 mol Na₂CO₃（53 g）；实际因母液带损 < 53 g，利用率 = 实际/理论。这就是'关系式法 + 原子守恒'在工业产率里的直接应用，后续滴定算纯度、电解算产率同此理。"

**探究 4（Nₐ 陷阱六类系统归纳，，高频核心）**

**教师**："下面集中攻克高考最高频的 Nₐ 陷阱。六类，记牢'状态 + 条件 + 构成三查'。① **状态**：标况下 H₂O（液）、SO₃（固，mp 16.8℃）、己烷（液）、CCl₄（液）、溴 Br₂（液）都不是气体，不能用 22.4 L/mol；② **条件**：常温常压（25℃，101.3 kPa）1 mol 气体约 24.5 L 非 22.4 L，'22.4 L ≠ 1 mol'除非同时满足标况+气态；③ **微粒构成**：稀有气体 He/Ne 单原子（1 mol He 含 Nₐ 个原子），共价分子 H₂O 每分子 3 原子、CH₄ 每分子 5 原子（1 mol H₂O 含 3Nₐ 原子），离子化合物 NaCl 含 Na⁺+Cl⁻ 共 2Nₐ 个离子，还要注意质子/电子数（1 mol H₂O 含 10 mol 质子/电子）；④ **电子转移**：如前述 Na₂O₂ 与水每 mol 转移 1 mol e⁻、1 mol Fe 与 Cl₂ 转移 3 mol e⁻、电解中电子按半反应数；⑤ **水解/电离**：弱电解质部分电离，1 mol CH₃COOH 含 H⁺ < 1 mol，盐类水解使粒子数变化（如 CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻，粒子数增多）；⑥ **可逆/化学平衡**：N₂ + 3H₂ ⇌ 2NH₃ 可逆，1 mol N₂ 与 3 mol H₂ 反应，NH₃ < 2 mol。"

**探究 5（过量计算 + 应用）**

**教师**："双已知量时先判限量：比较 n(实)/ν，比值最小者先耗尽、决定产物。例：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑，若给 Al 与 NaOH 都已知，谁 n/ν 小谁限量。应用点睛：环境监测中 SO₂/NOₓ 浓度用 c = n/V 表示（mg/m³ 或 ppm，可换算）；汽车安全气囊用 PV=nRT 反推：已知气囊体积 V、压强 P、温度 T，求 n(N₂)=PV/RT，再由 2NaN₃ = 2Na + 3N₂↑ 得 m(NaN₃)= (2/3)·n(N₂)·M(NaN₃)。标况才能用 22.4 L/mol，非标况必须用状态方程。"

**安全气囊 PV=nRT 数值示范（随探究 5 投影）**

某气囊设计要求充满 60 L、压强 1.2 atm（常温 25℃，即 298 K）的 N₂。求需 NaN₃ 质量。
列式：n(N₂) = PV/RT = (1.2 atm × 60 L) / (0.0821 L·atm·mol⁻¹·K⁻¹ × 298 K) ≈ 2.94 mol。
由 2NaN₃ = 2Na + 3N₂↑，n(NaN₃) = (2/3)·n(N₂) ≈ 1.96 mol。
m(NaN₃) = 1.96 mol × 65 g/mol ≈ 127 g。
**判据**：非标况下严禁用 22.4 L/mol，必须 PV=nRT；R 取 0.0821 时 P 用 atm、V 用 L。这体现"定量观"从标况特例走向通用状态方程，衔接后续气体定律与分压。

### 逐字稿①（Nₐ 陷阱辨析·状态）

**教师**："请判断：标准状况下 11.2 L H₂O 所含分子数是否为 0.5 Nₐ？"

**学生（预期，典型错误)**："11.2 L 除以 22.4 L/mol = 0.5 mol，所以分子数是 0.5 Nₐ。"

**教师（追问/理答）**："这是最经典的'状态'陷阱。22.4 L/mol 的第一个前提是**必须是气体**。标准状况（0℃、101.3 kPa）下 H₂O 是**液态**不是气态，它的体积由密度决定——18 g H₂O（1 mol）在标况下体积约 18 mL，远不是 22.4 L。所以'11.2 L H₂O'在标况下根本不是 0.5 mol，分子数远大于 0.5 Nₐ。判据：**先用'状态'卡一遍**——H₂O、SO₃、己烷、CCl₄、溴在标况都非气，凡它们出现，立刻封死 22.4 L/mol。记住口诀：Nₐ 题，先查状态，再查条件，后查构成。"

### 逐字稿②（关系式法·侯氏制碱）

**教师**："侯氏制碱里，1 mol NaCl 最终最多制得多少克 Na₂CO₃？请写关系式。"

**学生（预期，典型错误)**："NaCl 到 Na₂CO₃，Na 守恒，所以 1 mol NaCl 得 1 mol Na₂CO₃，106 g？"

**教师（追问/理答）**："注意 Na 的计量！Na₂CO₃ 含 2 个 Na⁺，Na⁺ 守恒应是 2NaCl ~ Na₂CO₃，即 2 mol NaCl 对应 1 mol Na₂CO₃。所以 1 mol NaCl 只对应 0.5 mol Na₂CO₃，质量 = 0.5 × 106 = **53 g**。判据：写关系式时盯住'含多原子的产物'——Na₂CO₃ 有 2 个 Na，必须 2NaCl 起步。这步关系式直接决定产率与原料利用率计算，后续滴定、电解产率同理：先抓关键元素，再数清它在产物里的'个数'。"

- **必做**（基础达标）：[[高中化学必修一-习题精选]] 题10（基础组）。
  ① 综合换算：把下列量互相换算（均须经 n）——5.4 g H₂O 含多少 mol 分子、多少个 H 原子、标况下若全为气态（假设）体积多少；0.5 mol CH₄ 的质量、分子数、标况体积、含多少 mol 原子。
  ② 与方程式计算：已知 2Na + 2H₂O = 2NaOH + H₂↑，若取 2.3 g Na 投入足量水，求生成 H₂ 的标况体积与质量，及所得 NaOH 溶液的物质的量浓度（设溶液体积 100 mL）。

- **选做**（能力提升）：
  ① 守恒法（电子/原子）：a. 用电子守恒配平并说明 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ 中每 mol Na₂O₂ 转移多少 mol e⁻；b. 配平 2Fe + 3Cl₂ = 2FeCl₃ 并说明 1 mol Fe 转移 e⁻ 数；c. 用原子守恒说明侯氏制碱 2NaCl~Na₂CO₃ 的来由。
  ② 关系式法：由关键元素守恒写出 NH₃→HNO₃、海水提镁 Mg²⁺→Mg 的关系式，并就"电解熔融 MgCl₂ 制得 2.4 g Mg，理论上需含 Mg²⁺ 多少 mol 的海水"列式计算。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① **Nₐ 陷阱归类大题**（8–10 项）：逐项判断正误并**点名陷阱类型 + 给正确值**。示例项：
    - 标况下 11.2 L H₂O 含 0.5 Nₐ 分子（状态陷阱，实际远大于）
    - 常温常压 22.4 L O₂ 含 Nₐ 个分子（条件陷阱，≈0.91 Nₐ）
    - 1 mol He 含 2 Nₐ 个原子（构成陷阱，单原子，仅 Nₐ）
    - 1 mol H₂O 含 3 Nₐ 个原子、10 Nₐ 个质子（构成，正确）
    - 1 mol NaCl 含 Nₐ 个离子（构成，应为 2Nₐ：Na⁺+Cl⁻）
    - 1 mol Na₂O₂ 与水反应转移 2 mol e⁻（电子陷阱，应为 1 mol）
    - 1 mol Fe 与 Cl₂ 完全反应转移 2 mol e⁻（电子，应为 3 mol）
    - 1 mol CH₃COOH 含 1 mol H⁺（电离陷阱，<1 mol）
    - 1 mol N₂ 与 3 mol H₂ 充分反应得 2 mol NH₃（可逆陷阱，<2 mol）
    - 标况下 11.2 L SO₃ 含 0.5 Nₐ 分子（状态+条件，SO₃ 标况为固）
  ② **多步关系式计算**：a. 侯氏制碱——以 1 mol NaCl 为起点（理论全部转化），用 2NaCl~Na₂CO₃ 求理论可得 Na₂CO₃ 质量（53 g），若实际得 45 g，求 NaCl 利用率；b. 海水提镁——从含 1 mol Mg²⁺ 的海水出发，经 MgCl₂→Mg(OH)₂→MgO→Mg，求理论可得 Mg 质量及若电解环节损失 10% 的实际产量。
  ③ **电子守恒综合**：已知 2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O，每 1 mol KMnO₄ 反应中转移多少 mol e⁻？若生成 0.5 mol Cl₂，被氧化的 HCl 为多少 mol？（提示：16 mol HCl 中仅 10 mol 被氧化为 Cl₂）。衔接后续滴定/产率中的电子守恒思路。

**作业评价要点（教师批阅参考）**

- **必做评分**：① 综合换算每小问单位与数值正确各 1 分（共约 8 分），要求书写经 n 的中间步骤；② 方程式计算：H₂ 体积 1.12 L、质量 0.1 g 各 1 分，c(NaOH)=1 mol/L 1 分，步骤经 n 1 分。
- **选做评分**：① 电子守恒三例各 2 分（配平+转移数说明）；② 关系式两条各 2 分，海水题列式与结果（0.1 mol）各 1 分。
- **挑战评分**：① 10 项每项正确判+命名陷阱+给值各 1 分（共 30 分），区分度由"点名陷阱类型"拉开；② 侯氏制碱 53 g 与利用率≈84.9% 各 3 分，海水提镁理论 24 g、实际 21.6 g 各 3 分；③ 电子守恒每问 3 分（KMnO₄ 转 5e⁻；被氧化 HCl 为 1 mol）。

**挑战题参考解答（教师备阅）**

- ① Nₐ 归类（要点）：标况 H₂O/SO₃ 非气（状态）；常温常压 22.4 L O₂ 实际 ≈0.91 Nₐ（条件）；He 单原子仅 Nₐ 原子（构成）；H₂O 3Nₐ 原子+10Nₐ 质子（构成，正确）；NaCl 含 2Nₐ 离子（构成）；Na₂O₂ 每 mol 转 1 mol e⁻（电子）；Fe 与 Cl₂ 每 mol 转 3 mol e⁻（电子）；CH₃COOH 弱电离 H⁺<1 mol（电离）；N₂+3H₂⇌2NH₃ 得 NH₃<2 mol（可逆）。
- ② 侯氏制碱：2NaCl ~ Na₂CO₃，1 mol NaCl → 0.5 mol Na₂CO₃ = 53 g；利用率 = 45/53 ≈ 84.9%。海水提镁：Mg²⁺ ~ Mg，1 mol Mg²⁺ → 1 mol Mg = 24 g；电解损 10% 后实际 = 24×0.9 = 21.6 g。
- ③ 电子守恒：Mn 从 +7→+2，每 mol KMnO₄ 转 5 mol e⁻；生成 0.5 mol Cl₂ 需转移 0.5×2 = 1 mol e⁻（Cl: −1→0），对应被氧化 HCl 为 1 mol（每 mol HCl 失 1e⁻ 成 1/2 Cl₂）。

**学法小结·概念地图（回扣大概念）**

```
         n 是枢纽（定量语言）
   ┌─────────────┬─────────────┐
 四量关系网      化学方程式计量      守恒/关系式
 m↔n↔N↔V↔c    系数=物质量比    质量/原子/电子/电荷
   │                 │              │
   └────────┬────────┴──────────────┘
            ↓
   Nₐ 六类陷阱（状态/条件/构成/电子/水解/可逆）← 严谨性试金石
            ↓
   应用：环境检测(c=n/V) · 安全气囊(PV=nRT)
            ↓
   后续：滴定/产率（电子守恒）· 电化学（电子守恒）· 离子平衡（电荷守恒）
```

> 一句话收口：本课把"四量、方程式、守恒、关系式、Nₐ 陷阱"用 n 串成一张网——n 是全书计量语言，Nₐ 陷阱是这张网的"严谨性质检关"，守恒与关系式是"多步直达"的捷径。

## 十、教学反思（课后填写，4 条 checklist）

- [ ] 学生能否独立画出"以 n 为枢纽"的关系网（m↔n↔N↔V↔c），并在综合换算中正确反推、不混淆 Vₘ 的"标况+气态"双前提与 c=n/V 中 V 是溶液体积？
