# 教案：2.9 一定物质的量浓度溶液的配制（必修第一册 第二章 海水中的重要元素——钠和氯）

> **课时元信息**：第 2 章 / 2.9 一定物质的量浓度溶液的配制 / 第 9 课时 / 45 min / 新授课 / 高一基础班
> 库内锚点：[[物质的量与气体计算]]　习题池：[[高中化学必修一-习题精选]]
> 本课定位：定量实验的核心操作技能课。本节课把第一章建立的"物质的量"概念与"宏观可称量 ⇄ 微观粒子"桥梁落到**真实实验操作**上——容量瓶的创造性设计与八步配制流程，是 c = n/V 这一关系式的"操作化实现"；误差分析全部从 c = n/V 出发推导，是"定量观"与"宏—微—符表征"的集中训练，也为后续滴定管操作、离子浓度计算、药剂配制等真实应用奠基。

---

## 一、课标对应

- **内容要求**：认识物质的量浓度在化学定量研究中的作用；学会配制一定物质的量浓度的溶液；能运用物质的量、摩尔质量、物质的量浓度之间的相互关系进行简单计算。
- **学业质量水平**：必修水平 2——能独立设计并完成一定物质的量浓度溶液的配制实验，规范使用容量瓶等仪器；能依据 c = n/V 对配制中的常见操作偏差进行误差归因，形成初步的定量实验素养。
- **核心素养落点**：
  1. **宏观辨识与微观探析**（从"称多少克、量多少毫升"的宏观操作，理解其背后对应"溶质的物质的量 n"这一微观粒子集合，落实 n、c、V 的宏—微—符对应）；
  2. **变化观念与平衡思想**（认识配制是一个"分步逼近目标浓度"的动态过程，定容、摇匀、装瓶各步条件影响最终平衡态浓度）；
  3. **证据推理与模型认知**（建立"c = n/V"误差分析模型，任何操作偏差都归约为 n 或 V 的偏移，再推 c 的偏移）；
  4. **科学探究与创新意识**（体会容量瓶"一条刻度线、一个温度"的仪器设计巧思，从实验需求反推仪器设计）；
  5. **科学态度与社会责任**（通过医院输液、药剂配制等情境，认识浓度精确控制的现实生命意义，养成严谨、不补缴、不臆改的实验习惯）。

### 1.1 课标细目与课时落点对照

| 课标表述 | 本课对应落点 | 达成方式 |
|---|---|---|

## 二、学情分析（本课时）

**【课前诊断·3 处典型误解预判】**

学生在初三已做过"粗略配制一定浓度溶液"（用量筒量水、用托盘天平称溶质、在烧杯里搅混），对"配溶液"有粗浅经验，但仅停留在"把东西混在一起"的层面，配出的浓度是"约数"而非"定值"。本课新难点有四：一是对**容量瓶**完全陌生——不知其为"梨形、一条标线、标温度、不能加热、不能作反应容器"，更不会**检漏**；二是八步流程中"冷却至室温""引流""洗涤 2–3 次""凹液面最低处与刻度线相切"等精细操作易漏步、错序；三是**误差分析无从下手**——学生习惯死记"俯视偏高仰视偏低"，但说不清为什么，更不会从 c = n/V 推导，遇到"未冷却""砝码油污""容量瓶原有水"等新情境就乱；四是**典型误解顽固**：① 摇匀后液面略降，误以为"水不够"再去补水（实则越补越稀）；② 定容时俯视/仰视后果分不清；③ 把容量瓶当烧杯用，在其内溶解、稀释、甚至作反应容器（会热胀、会污染、会损塞）。

此外，学生对"配套仪器全家福"（天平/量筒/烧杯/玻璃棒/胶头滴管/容量瓶各司其职）缺乏整体认知，常把玻璃棒只当"搅拌棒"、忽略其"引流"功能；对 c = n/V 中"V 是溶液体积而非溶剂体积"也易与第一章"加水 100 mL"的直觉混淆。对策：以"粗配 vs 精配"制造认知冲突，用容量瓶实物拆解结构、用仪器全家福厘清分工；误差分析**一律先写 c = n/V、再判 n 偏或 V 偏**，把记忆升级为推导；用"三个误区"前置为实验禁令。本节课也是学生建立**定量观**的第一次完整体验——过去化学多是"定性看现象"，今天第一次"用精度说话"，因此格外需要把"不补缴""平视""只定容"内化为实验本能，而非临时提醒。

本课在全书体系中承上启下：它承接第一章"离子反应"对**精确浓度**的需求（离子浓度计算、离子方程式计量都依赖 c 准确），也是学生第一次完整经历"概念（c = n/V）→ 公式 → 仪器（容量瓶）→ 操作（八步）→ 误差归因"的**定量实验闭环**；向下为后续"氧化还原反应"的定量、标准溶液与滴定管操作（同源定容精度）、乃至选择性必修的水溶液离子平衡奠基。

## 三、教学目标（学科核心素养统领）

### 3.1 核心素养目标（按 5 大素养写）

- 通过"粗配约数 → 容量瓶精配"的对比活动，培养**宏观辨识与微观探析**素养：建立"天平称取的克数 ↔ 溶质的物质的量 n ↔ 容量瓶定容的体积 V ↔ 浓度 c"的宏—微—符对应链。
- 通过逐字稿推导"定容俯视/仰视为何导致 c 偏低/偏高"，培养**证据推理与模型认知**素养：把一切误差归约为 c = n/V 中 n 或 V 的单因素偏移，形成可迁移的分析模型。
- 通过拆解容量瓶"一条标线、一个温度、梨形瓶颈"的设计，培养**科学探究与创新意识**素养：从"精确定容的需求"反推"为何这样设计仪器"，体会仪器设计的巧妙。
- 通过"NaOH 固体为何必须放烧杯称量（潮解 + 腐蚀玻璃塞）""未冷却转移会怎样"等安全与精度讨论，培养**科学态度与社会责任**素养：认识浓度精确控制关联医疗安全，养成规范、严谨、不补缴的实验习惯。
- 通过稀释定律 c₁V₁ = c₂V₂ 与"浓→稀"的真实应用，培养**变化观念与平衡思想**素养：认识溶液浓度可在"配制"与"稀释"两个方向相互转化。

### 3.2 学习目标（学生能……，可观测）

- 能**说出容量瓶的结构特征**（梨形、标线、标温度、规格 50/100/250/500 mL）与**独立完成检漏**（加水→塞紧→倒转→查漏→旋转瓶塞 180°→再倒转查），并说明"为何不能加热、不能作反应容器"。
- 能**按顺序复述并操作八步配制流程**：计算 → 称量(固体)/量取(液体) → 溶解（冷却至室温） → 转移（玻璃棒引流） → 洗涤（烧杯+玻璃棒 2–3 次，洗涤液转入） → 定容（胶头滴管逐滴至凹液面最低处与刻度线相切） → 摇匀 → 装瓶贴标。
- 能**用 c = n/V 推导**至少 8 种常见操作的误差（偏高/偏低/无影响），而非死记；特别能说明"摇匀后液面略降**不补缴**""容量瓶原有水**无影响**"的推导依据。
- 能**完成实例计算**：配制 0.1 mol/L NaCl 溶液 100 mL，m = 0.1 × 0.1 × 58.5 = 0.585 g；能写出 NaOH 固体称量的特殊操作（放烧杯、不垫纸）并说明两条理由。
- 能**应用稀释定律** c₁V₁ = c₂V₂ 解决"浓溶液稀释为稀溶液"的计算，并联系医院输液配制、药剂师基本功等真实情境。

> 脚注：旧三维目标框架（知识与技能 / 过程与方法 / 情感态度与价值观）已废止，本课目标统一以学科核心素养统领表述。

## 四、教学重难点

| 类型 | 内容 | 认知根源 | 突破策略 | 检验 |
|---|---|---|---|---|
| 重点 | 容量瓶的结构与检漏（梨形、标线、标温度、规格；加水→塞紧→倒转→查漏→旋转 180°→再倒转查） | 学生从未见过此仪器，易与量筒混淆（量筒无标线、无温度、不能精确定容） | 实物拆解 + 对比表（容量瓶 vs 量筒 vs 烧杯）；现场演示检漏动作 | 能独立检漏并说出三处与量筒的本质区别 |
| 重点 | 八步配制流程及关键细节（冷却、引流、洗涤 2–3 次、凹液面最低处相切、不补缴） | 初三粗配只"混在一起"，缺"分步逼近目标"的精细操作意识，易漏洗涤/未冷却 | 用"分步走"类比；把"洗涤液全部转入""冷却至室温"做成实验禁令卡 | 能默写八步且关键细节无遗漏；能现场演示定容动作 |
| 重点 | 误差分析模型 c = n/V（n 偏→c 偏，V 偏→c 反偏） | 学生死记"俯视高仰视低"，遇新情境不会推 | 逐字稿现场推导俯视/仰视；归纳"先写 c=n/V，再判 n 或 V 偏"的统一套路 | 能给"未冷却""砝码油污""容量瓶有水"等新操作正确归因 |
| 重点 | 稀释定律 c₁V₁ = c₂V₂ 与"浓→稀"应用 | 学生不知稀释时溶质守恒，易把"加水体积"误当"最终体积" | 用"溶质物质的量不变"讲守恒；强调先在烧杯混匀冷却再转移定容 | 能列式求母液体积并说明为何不在容量瓶内稀释 |
| 难点 | 俯视/仰视定容的视线—体积—浓度因果链 | 视线偏差对凹液面读数的影响方向易搞反 | 画"眼睛—液面—刻度线"侧视图，结合 c=n/V 推：仰视→多看水→V 大→c 低 | 能画侧视图并完整说出"仰视偏低、俯视偏高" |
| 难点 | "摇匀后液面略降不补缴""容量瓶原有水无影响"的反直觉点 | 直觉以为"液面降=水少"要去补；以为"瓶里有水会冲淡" | 用 c=n/V 析：降是因润湿瓶塞、n/V 未变，补缴只增 V→c 更低；原有水不改变 n 也不改变最终 V→无影响 | 能口述两点的 c=n/V 推导并解释物理原因 |
| 难点 | NaOH 固体称量放烧杯（潮解 + 腐蚀玻璃塞/纸片） | 学生习惯"纸垫天平称固体"，不知 NaOH 特殊 | 逐字稿讲潮解吸湿使称量不准、强碱腐蚀纸片与天平、且与玻璃塞黏结；对比 NaCl 可垫纸 | 能说出两条理由并正确演示 NaOH 称量操作 |
| 难点 | 玻璃棒"引流"角色易被忽略（只当搅拌棒） | 初三只见过搅拌，不知转移防洒靠引流 | 仪器全家福图示点明双角色 + 演示引流动作（玻棒轻抵瓶口内壁） | 转移时能主动用玻璃棒引流而非直接倾倒 |

## 五、教学媒体与素材

- 实物与演示：容量瓶（100 mL、250 mL 各若干）、托盘天平、量筒、烧杯、玻璃棒、胶头滴管、药匙、称量纸、小烧杯（装 NaOH 用）；检漏与定容动作现场演示。
- **仪器全家福与分工（板书/投影小图）**：
  - 托盘天平 / 电子天平：称取**固体**溶质质量；
  - 量筒：量取**液体**溶质或浓溶液体积（不标温度、不能精确定容）；
  - 烧杯：溶解、稀释、临时盛放（不能作最终定容容器）；
  - 玻璃棒：**搅拌**加速溶解 + **引流**防止转移洒出；
  - 胶头滴管：定容时**逐滴**加水至标线；
  - 容量瓶：**精确定容**到标线（只干这一件事）。
- 情境素材：医院输液袋标签（浓度精确到 mmol/L 的 Na⁺）、药剂师调剂台照片、实验室"配制 0.1000 mol/L NaCl 标准溶液"流程卡（文字引用，不实际嵌图）。
- 学案：① 八步流程填空卡（含"冷却至室温""洗涤 2–3 次""凹液面最低处相切""不补缴"提示位）；② 误差分析归因表（12 种操作，判偏高/偏低/无影响 + 写 c=n/V 推导）；③ 实例计算单（0.1 mol/L NaCl 100 mL、NaOH 稀释）；④ 误区禁令卡（摇匀不补缴 / 定容平视 / 容量瓶不作反应容器 / NaOH 放烧杯）。
- **实验记录单要素**（学生现场填写、教师巡视）：a. 所选容量瓶规格与检漏结果；b. 计算所得 m（或量取 V）；c. 关键节点勾选（已冷却 / 已引流 / 已洗涤 2–3 次 / 平视定容 / 未补缴）；d. 最终贴标内容（名称、浓度、日期、配制人）。
- **安全提示**：浓酸/浓碱稀释均须在通风处、遵循"酸入水"并冷却后转移；NaOH 称量须戴手套、勿直接接触皮肤与称量纸。
- 板书/投影：误差分析表（12 行）、俯视仰视侧视图、稀释定律 c₁V₁ = c₂V₂ 应用框。

**导入**

**教师**："同学们，初三我们配过'盐水'——用量筒量 100 mL 水，用天平称一勺盐，搅一搅。那种配法，浓度大概齐，叫'粗配'。但请大家看这张医院输液袋标签（投影）：0.9% 生理盐水，精确标注 154 mmol/L 的 Na⁺。如果配错一点，输进血管会出人命。今天我们要把'粗配'升级成'精配'——用一种专门仪器，让浓度精确到小数点后。这种仪器叫什么？它为什么能这么准？这就是本课：一定物质的量浓度溶液的配制。"

**教师**："顺带衔接一下第一章：第一章学离子反应时，我们写离子方程式要算'离子浓度'，浓度不准，后面的计量全错。所以今天配出的'精确浓度'，正是第一章离子反应的**计量前提**——这堂课，是把第一章的'概念'第一次变成实验室里'可操作的精度'。"

**学生（预期）**："用烧杯和量筒不行吗？""容量瓶？"

**教师（追问/理答）**："量筒能量出体积，但它只有刻度、没有'一条准到极致的线'，而且不标温度——温度一变体积就变，量筒量不准。精配需要一种'为定容而生'的仪器：容量瓶。它瓶肚大、瓶颈细，细颈上只有'一条标线'，瓶身还刻着'20 ℃'。为什么这样设计？下面拆开看。"

**误区前置清单（约 5 min，写在学案首页，动手前先亮坑）**

**教师**："动手前先把三个'坑'亮出来，免得你掉进去。**坑一**：你以前配溶液'搅搅就行'，今天不行——八步一步不能省，尤其洗涤和冷却；**坑二**：定容时你可能会'凑近看'，记住必须**平视**凹液面最低处，仰视偏低、俯视偏高；**坑三**：也是最常犯的——摇匀后液面降了，你手痒想去补水，**绝对不许**，补缴只会越稀。这三条，今天谁犯谁重做。"

**探究 1（容量瓶结构与检漏 + 仪器全家福）**

**教师**："先看实物。容量瓶是**梨形**的，细颈上有一条**标线**（环形刻度），瓶身刻着**使用温度**（通常 20 ℃）和**规格**（常见 50 mL、100 mL、250 mL、500 mL）。注意：它只有一个体积刻度，就是'一条线对应一个体积'，所以叫'量入式'精确定容仪器。它的使用第一步不是装东西，而是**检漏**——因为一旦漏水，前面全白做。"

**教师**："检漏五步走，跟我念并记：① 加水至标线附近 → ② 塞紧瓶塞 → ③ 用食指顶住瓶塞、另一只手托住瓶底，**倒转** → ④ 观察是否漏水 → ⑤ **旋转瓶塞 180°** 再倒转检查一次。为什么转 180°？因为瓶塞两端密合度可能不同，转一下才能确认'无论怎么塞都不漏'。"

**教师**："今天整套实验不是容量瓶'单打独斗'，而是'仪器全家福'各司其职（投影）：**天平**称固体质量、**量筒**量液体体积、**烧杯**负责溶解稀释、**玻璃棒**既搅拌又引流、**胶头滴管**定容时逐滴加水、**容量瓶**只管最后精确定容。特别记住玻璃棒的两个角色——溶解时搅拌、转移时引流，很多同学只记得搅拌，转移时手一抖就洒了。"

**学生（预期，典型错误）**："容量瓶能直接用来溶解固体吗？能加热吗？"

**教师（追问/理答）**："这三个'不能'是铁律：**不能加热**（热胀会永久变形、标线失效）；**不能作反应容器**（反应放热/产气会改变体积、还可能腐蚀）；**不能在瓶内直接溶解**（溶解常放热，须先在烧杯溶解冷却）。容量瓶只干一件事——'最后定容到这条线'。对比一下：量筒量任意体积、不标温度、不能精确定容；烧杯只混不量；容量瓶只定容一个体积、标温度。各司其职。"

**探究 2（八步流程）**

**教师**："精配流程我编成八步口诀，按顺序：**计算 → 称量(固体)/量取(液体) → 溶解（冷却至室温） → 转移（玻璃棒引流） → 洗涤（烧杯和玻璃棒 2–3 次，洗涤液转入） → 定容（胶头滴管逐滴至凹液面最低处与刻度线相切） → 摇匀 → 装瓶贴标**。几个致命细节：第一，溶解后**必须冷却至室温**再转移——NaOH 溶水放热，热的溶液体积胀大，若趁热定容，冷却后液面会低于标线，实际浓度偏高（后面误差分析细算）；第二，转移要用**玻璃棒引流**，别让液体顺着瓶壁流下洒了；第三，**洗涤 2–3 次**且洗涤液全部转入——烧杯壁和玻璃棒上沾着的溶质若不洗进去，n 就少了；第四，定容时先加蒸馏水到标线**附近**（约 1–2 cm），再换**胶头滴管逐滴**加，眼睛平视，让**凹液面最低处**恰好与标线相切；第五，摇匀后若液面略降，**绝对不补缴**。"

**学生（预期，典型错误）**："洗涤那么麻烦，不洗烧杯直接定容不行吗？引流为啥非用玻璃棒？"

**教师（追问/理答）**："不洗，烧杯壁和玻璃棒上沾的那层溶质就留在外面了——你算的是'全部溶质'的 n，实际进瓶的少了，n↓，c 偏低。所以'洗涤 2–3 次、洗涤液全转入'不是仪式，是**保证溶质全部进瓶**。引流同理：不用玻璃棒，液流会顺瓶壁溅出或挂壁，既损失溶质又难控制，定容体积都不准。这两步，缺一步 c 就偏。"

**学生（预期，典型错误）**："摇匀后液面降了一点，是不是该再补点水到线？"

**教师（追问/理答）**："这是第一大误区，我先按下不表，等误差分析用 c = n/V 算给你看——补缴只会越补越稀。先记住禁令：摇匀后液面降，**不补缴**。"

**精度禁令卡 + 价值落点（ 强化）**

**教师**："我把今天最容易翻车的几条写成'禁令卡'，贴实验台：① 摇匀后液面降——**不补缴**；② 定容视线——**必须平视**凹液面最低处；③ 容量瓶——**只定容、不加热、不作反应/稀释容器**；④ NaOH——**放烧杯快速称、不垫纸、不敞置**。这四条，错任何一条都会让前面白做。"

**教师**："再讲为什么较真。大家看输液袋上 154 mmol/L 的 Na⁺——那是药剂师用今天这套八步、用 c = n/V 一克一毫升配出来的。浓度差 1%，对婴儿、对肾衰病人可能就是危险。所以'不补缴''平视'不是较真，是**对生命的精度**。这也是化学人的社会责任。"

**探究 3（逐字稿①：定容俯视/仰视 → c=n/V 推导）**

**教师**："定容时眼睛怎么看？假设标线在这里（画侧视图：眼睛、凹液面、刻度线三者关系），如果你**仰视**——眼睛低于液面——你看到的'液面与标线相切'其实是液面已经**高于**真正标线，也就是说你多加了水。水的体积 V 偏大了。那浓度 c 怎么变？回忆定义 c = n/V。"

**学生（预期）**："c = n/V，V 变大，c 就……变小？所以仰视配出来的浓度偏低？"

**教师（追问/理答）**："完全正确。推导链是：**仰视 → 实际加水量 V 偏大 → c = n/V 中分母变大 → c 偏低**。反过来，**俯视**——眼睛高于液面——你以为切到线，其实液面还**低于**标线，水加少了，V 偏小，c = n/V 分母变小 → **c 偏高**。所以口诀：**仰视偏低、俯视偏高**，但关键是——你不是背出来的，是从 c = n/V 推出来的。任何误差，先写 c = n/V，再判 n 偏还是 V 偏，结论自然来。"

**学生（预期）**："那如果称 NaOH 时砝码上沾了油污呢？这也算 V 的问题吗？"

**教师（追问/理答）**："好，这就转到 n 的偏移。砝码油污 → 砝码实际质量比标示大 → 称得的溶质**看似称够、实际偏多** → 溶质的物质的量 n 偏大 → c = n/V 分子变大 → **c 偏高**。记住：偏差要么动 n（溶质多/少），要么动 V（水多/少），c = n/V 永远是你的最终裁判。"

**误差补充 + 逐字稿②：NaOH 为何放烧杯**

**教师**："再补三个高频坑，全是 c = n/V 一句话判完。① **容量瓶洗净后瓶里残留少量蒸馏水——无影响**：因为定容时本就要加水到标线，瓶里那点水不改变'最终加到标线'这个 V，也不改变溶质 n，c = n/V 纹丝不动。② **药品潮解**（如 NaOH 吸了游离水）：你称的'质量'里有一部分是水，实际溶质 n 偏小，c 偏低——所以潮解的药要快速称或折算。③ **摇匀后液面降再补水**：降是因部分溶液润湿瓶塞瓶颈，n 和 V 都没变；你一补水，V 凭空变大，c = n/V 反而更低。这三点，记住'先写 c=n/V'。"

**教师**："再看第二个易错操作：配制 NaOH 溶液，固体 NaOH 不能直接放称量纸、更不能放容量瓶，而必须放在**小烧杯**里称量。为什么这么特殊？NaCl 就可以垫纸称，NaOH 不行，两条硬理由。"

**学生（预期）**："NaOH 也是固体啊，垫纸不行吗？"

**教师（追问/理答）**："第一条：**潮解**。NaOH 固体在空气中极易吸收水蒸气而表面变潮、甚至流淌，叫'潮解'。若垫纸称，它吸水后质量一直在变，称不准；而且潮解液会渗进纸、黏住天平，污染且难清理。放烧杯里能隔绝空气、稳定称量。第二条：**强腐蚀性**。NaOH 是强碱，会腐蚀称量纸，更会和玻璃中的 SiO₂ 缓慢反应生成 Na₂SiO₃ 黏结——若直接放玻璃器皿敞口久置，瓶塞会黏死打不开。所以 NaOH 要**快速称、放烧杯、立即溶解**，不能久置、不能垫纸、不能敞口。对比 NaCl：不潮解、不腐蚀，垫纸称完全没问题。这就是'看物质性质决定操作'。"

**学生（预期）**："那稀释浓硫酸能也在容量瓶里做吗？"

**教师（追问/理答）**："不能——浓硫酸稀释放大量热，容量瓶严禁受热，而且稀释顺序（酸入水）本身就有喷溅风险，必须在烧杯里冷却后再转移。再次印证：容量瓶只定容、不作反应/稀释容器。"

**实例计算 + 稀释 + NaOH 实例 + 巩固小练**

**教师**："算一道实例：配制 0.1 mol/L 的 NaCl 溶液 100 mL，要称多少克？先算 n = c·V = 0.1 mol/L × 0.100 L = 0.010 mol；再算 m = n·M = 0.010 mol × 58.5 g/mol = 0.585 g。注意 V 要化成'升'再算。若用容量瓶规格只有 250 mL，就按 250 mL 重算 m。再看稀释：把浓溶液 c₁、V₁ 稀释成稀溶液 c₂、V₂，溶质的量守恒，c₁V₁ = c₂V₂。比如用 1.0 mol/L 的母液配 0.1 mol/L 100 mL，V₁ = c₂V₂ / c₁ = 0.1×100/1.0 = 10 mL——取 10 mL 母液，加水定容到 100 mL 即可。"

**教师**："再算一个 NaOH 实例加深：用 NaOH 固体配 0.2 mol/L 溶液 100 mL。n = 0.2 × 0.100 = 0.020 mol；m = n·M = 0.020 × 40.0 = 0.80 g（M(NaOH) = 40.0 g/mol）。注意 NaOH 要放烧杯快速称、溶解放热须冷却。若把 2.0 mol/L 的 NaOH 母液稀释成 0.2 mol/L 200 mL，则 V₁ = c₂V₂/c₁ = 0.2×200/2.0 = 20 mL——取 20 mL 母液于烧杯，加少量水混匀冷却，再转移定容到 200 mL。再次强调：稀释放热必须在烧杯进行，绝不在容量瓶内直接稀释。"

**教师**："巩固小练（口头）：① 若定容时水加超过标线，用胶头滴管吸出多余——c 偏高还是偏低？（吸出了部分含溶质溶液→n↓→c 偏低）② 量筒量取浓液时俯视读数——量到的实际体积偏少→n↓→c 偏低。③ 转移时洒出少量——n↓→c 偏低。都回到 c = n/V。"

**教师**："回扣大概念：**配制，就是 c = n/V 这个式子在实验室里的操作实现**。医院输液、药剂师调剂，本质都是这套 c = n/V 与 c₁V₁ = c₂V₂。"

**宏—微—符三重表征小结（随堂穿插）**

| 表征层面 | 配制中的对应 | 例子 |
|---|---|---|
| 宏观 | 称取质量、量取体积、凹液面与标线相切、摇匀后澄清 | 称 0.585 g NaCl、加水至 100 mL 标线 |
| 微观 | 溶质的物质的量 n（粒子集合）、溶液体积 V 决定粒子分散密度 | 0.010 mol Na⁺ 与 Cl⁻ 分散于 100 mL |

**随堂小结：核心口诀与易错速查**

| 易错直觉 | 正确认知 | 推导/判据 |
|---|---|---|
| 摇匀后液面降，再补水到线 | **不补缴**，补缴只增 V → c 更低 | c = n/V，n/V 未变，降因润湿瓶塞，补缴→V↑→c↓ |
| 定容随便看，差不多就行 | 必须**平视**凹液面最低处 | 仰视→V↑→c↓；俯视→V↓→c↑（c = n/V） |
| 容量瓶能加热/作反应容器 | **不能**，只用于定容 | 热胀变形、标线失效、腐蚀、产气改体积 |
| 容量瓶里原有水会冲淡 | **无影响** | 定容仍加到标线，最终 V 不变，n 不变→c 不变 |
| 溶解后趁热转移定容 | 须**冷却至室温** | 热胀→V 偏小→冷却后液面低于线→c↑ |
| NaOH 可垫纸称 | **放烧杯**快速称 | 潮解使质量变、腐蚀纸与玻璃塞 |
| 未洗涤烧杯玻璃棒无所谓 | 须洗涤 2–3 次转入 | 溶质残留→n↓→c↓ |
| 砝码沾油污无所谓 | 称多→n↑→c↑ | c = n/V，分子变大 |
| 定容超线吸出多余 | n↓→c 偏低 | 吸出含溶质溶液，n 减少 |
| 量筒量液俯视读数 | 量取偏少→n↓→c 偏低 | 实际体积小于读数 |

**核心口诀**：八步不能乱，冷却、引流、洗三遍；定容平视切凹线，摇匀降了不补缴；误差先写 c=n/V，n 偏 V 偏自然来；NaOH 放烧杯，容量瓶只定容。

## 八、作业布置

- **必做**（基础达标）：[[高中化学必修一-习题精选]] 题9（基础部分）。
  ① **步骤默写**：不看书本，按顺序默写出八步配制流程，并在"冷却至室温""洗涤 2–3 次""凹液面最低处相切""摇匀后不补缴"四处标注理由。
  ② **误差判断**：下列操作对配制 0.1 mol/L NaCl 溶液浓度的影响，判断"偏高 / 偏低 / 无影响"，并**用 c = n/V 写一句推导**：
    - 定容时仰视刻度线；
    - 转移后未洗涤烧杯和玻璃棒；
    - 容量瓶洗净后瓶内残留少量蒸馏水；
    - 称量 NaCl 时砝码生锈（实际质量偏大）；
    - 溶解后未冷却至室温即转移定容。

- **选做**（能力提升）：
  ① **实例计算**：配制 0.1 mol/L 的 NaCl 溶液 100 mL，计算所需 NaCl 质量（写出 n = c·V、m = n·M 完整过程，M(NaCl) = 58.5 g/mol）；若实验室只有 250 mL 容量瓶，需称多少克？
  ② **稀释应用**：用 2.0 mol/L 的 KCl 母液配制 0.5 mol/L 的 KCl 溶液 200 mL，需量取母液多少 mL？（用 c₁V₁ = c₂V₂ 列式）说明为何稀释不能在容量瓶内直接进行、而应先在烧杯混匀冷却再转移定容。

- **挑战**（接近高考中档偏难 / 初赛入门，高区分度）：
  ① **误差归类表（全 12 种操作）**：把以下操作逐一归入"n 偏移类"或"V 偏移类"，并给出 c 结果（偏高/偏低/无影响）与 c = n/V 推导；要求覆盖：仰视、俯视、未冷却、未洗涤、砝码油污、药品潮解、容量瓶有水、摇匀后补水、定容超过标线吸出、量筒量取液体时俯视读数、转移时洒出少量溶液、称量 NaOH 时放在纸上（潮解）。
  ② **综合归因题**：某同学配制 100 mL 0.1 mol/L 的 NaOH 溶液，操作如下——(a) NaOH 放在称量纸上称量；(b) 溶解后趁热转入容量瓶；(c) 定容时俯视刻度线；(d) 摇匀后发现液面低于标线，又滴加蒸馏水至标线。请逐项用 c = n/V 分析对 c 的影响，并判断最终浓度相对 0.1 mol/L 偏高还是偏低（或无法判定），说明推理链。
  ③ **真实情境**：医院需用无水 NaCl 配制 500 mL 0.154 mol/L 的生理盐水（即约 0.9%），计算所需 NaCl 质量；并说明若配制中"未洗涤烧杯"会对输液安全造成什么后果（从 c = n/V 与医疗精度角度答）。
