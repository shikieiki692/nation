# 第二章 海水中的重要元素——钠和氯 · 教材分析（人教版必修第一册 2019）

> 适用：高一必修第一册第二章备课。课标依据为《普通高中化学课程标准（2017 年版 2020 年修订）》"主题 2：常见的无机物及其应用"。条目以概要描述，[建议] 以本校教材与课标原文核对。内容以库内锚点页 [[钠及其化合物]]、[[氯及其化合物]]、[[物质的量与气体计算]] 为据，竞赛衔接级素材见 [[碱金属]]、[[卤素]]。

## 一、课标定位

- **内容要求（概要）**：能根据物质的组成、性质与元素的化合价，列举钠、氯等典型元素的代表性物质，预测其主要性质；认识碱金属（钠）、卤素（氯）等典型元素及其化合物的主要性质、制备方法和用途；认识物质的量及其单位摩尔，体会物质的量、摩尔质量、气体摩尔体积、物质的量浓度在化学定量研究中的作用，能进行简单的化学计算；感受实验、分类、价态预测在元素化合物研究中的功能。
- **学业要求（必修水平 1–2）**：能依据类别与价态列举钠、氯的代表物，并用离子反应、氧化还原概念对其常见反应分类；能描述、辨识钠系与氯系物质的重要性质与实验现象，用化学方程式、离子方程式正确表示主要反应；能从"类别 × 价态"角度预测性质、设计实验验证并解释现象；初步建立"宏观—微观—符号"三重表征思维；能运用物质的量进行基本计量与简单计算。

## 二、本章在课程体系中的地位

本章是**元素化合物学习的开篇**，也是初中化学通向高中元素化学的"第一块基石"，承担三重任务：

1. **建范式**：建立元素化合物的研究范式——以"类别视角 × 价态视角"双轴预测性质，用实验验证，用"宏观现象 / 微观粒子 / 符号表达"三重表征刻画物质转化（承接第一章的分类观、离子反应、氧化还原方法）。
2. **奠代表**：钠作为碱金属代表、氯作为卤族代表，其研究思路（单质→氧化物→盐，性质→用途）为后续"铁与金属材料""物质结构·元素周期律"提供可迁移的范例与方法论。
3. **搭桥梁**：物质的量作为"宏观可称量 ⇄ 微观粒子数"的桥梁，是全书的定量工具，是后续"水溶液中的离子反应与平衡""电化学"以及滴定、产率、关系式计算的计量前提。

后续（铁、铝、硫、氮、元素周期律、电化学、水溶液平衡）全部建立在本章提供的"双轴研究范式 + 定量计量"之上；钠、氯的方程式书写、氯水成分分析、n 相关计算更是历年必考点，必须从起始年级种下规范与深度的种子。

## 三、内容结构与逻辑主线

三节呈螺旋递进：先以两个代表性元素展开"定性研究范式"，再用"物质的量"把定性研究推向"定量"。

| 节 | 解决的核心问题 | 认识视角跃迁 |
|---|---|---|
| 第一节 钠及其化合物 | 碱金属代表元素有哪些典型性质与转化路径 | 元素化合物研究范式开篇：单质→氧化物→盐，落实"类别 × 价态"双轴与宏—微—符表征 |
| 第二节 氯及其化合物 | 卤素代表元素的性质、氯水本质与递变规律 | 单质→含氧酸/盐；引入卤素递变；是离子反应 + 氧化还原的综合演练 |
| 第三节 物质的量 | 如何把"性质研究"升级为"定量研究" | 引入计量桥梁 n，连通宏观可称量与微观粒子数，使前两节性质研究走向定量 |

**全章大概念**：用"类别 × 价态"双轴预测元素化合物性质，用实验探究验证，用宏—微—符三重表征刻画转化，用物质的量统摄定量规律。

## 四、各节内容深析（备课抓手）

**第一节 钠及其化合物（碱金属代表）**

- **钠单质**：活泼金属，最外层 1 个电子 → 强还原性；质软、密度 0.97 g/cm³（比水小、比煤油大、比 CCl₄ 小）、熔点 97.8 °C。
  - 与 O₂：常温 4Na + O₂ → 2Na₂O（白色）；点燃 2Na + O₂ → Na₂O₂（淡黄色）。
  - 与 H₂O：2Na + 2H₂O → 2NaOH + H₂↑，现象"浮、熔、游、响、红"（加酚酞变红）。
  - 与 CO₂：4Na + 3CO₂ → 2Na₂CO₃ + C；钠着火**禁**用 CO₂ 灭火器，须用干燥沙土覆盖。
  - 保存：煤油或石蜡油中，隔绝空气和水（不能存于 CCl₄，因密度 1.59 g/cm³ 大于钠，钠上浮无法浸没）。
  - 工业制备：电解熔融 NaCl，加 CaCl₂ 形成共晶将熔点降至约 600 °C：2NaCl(熔融) → 2Na + Cl₂↑。
- **钠的氧化物**：Na₂O（O 为 −2）/ Na₂O₂（O 为 −1，过氧根 O₂²⁻）。Na₂O₂ 与水、CO₂ 反应放出 O₂，属于**歧化反应**（O 从 −1 既降到 −2 又升到 0，Na₂O₂ 既是氧化剂又是还原剂）：2Na₂O₂ + 2H₂O → 4NaOH + O₂↑；2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂。用途：呼吸面具、潜艇供氧剂。
- **NaOH**：强碱，易潮解，不能干燥酸性气体（CO₂、SO₂、HCl）。
- **Na₂CO₃ 与 NaHCO₃**：Na₂CO₃ 溶解度较大、热稳定；NaHCO₃ 受热分解 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑。相互转化：Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃；NaHCO₃ + NaOH → Na₂CO₃ + H₂O。与酸：NaHCO₃ 反应更快。
- **侯氏制碱法**：NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl；2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑（NaCl 利用率由约 70% 提至 96% 以上，副产 NH₄Cl 化肥）。
- **焰色反应**：Na 黄色、K 紫色（透蓝色钴玻璃滤去 Na 黄光）；属**物理变化**，与阴离子无关。

**第二节 氯及其化合物（卤素代表）**

- **氯单质**：黄绿色、刺激性气味、密度比空气大、溶于水（1:2）；最外层 7 个电子 → 强氧化性（易得电子）。
  - 与金属：2Na + Cl₂ → 2NaCl；2Fe + 3Cl₂ → 2FeCl₃（**无论 Fe 是否过量，Cl₂ 均将 Fe 氧化到 +3**）；Cu + Cl₂ → CuCl₂。
  - 与非金属：H₂ + Cl₂ → 2HCl（苍白色火焰）。
  - 与水：Cl₂ + H₂O ⇌ HCl + HClO（可逆）。
  - 与碱（歧化）：Cl₂ + 2NaOH → NaCl + NaClO + H₂O。
- **氯水成分**：新制氯水含三分子（Cl₂、HClO、H₂O）与三离子（H⁺、Cl⁻、少量 ClO⁻ 与 OH⁻）；久置因 2HClO → 2HCl + O₂↑（光照）最终变为稀盐酸。
- **HClO 漂白**：强氧化性使有色物质永久褪色（**不可逆**），与 SO₂ 的可逆漂白不同；**干燥 Cl₂ 不漂白**干燥布条（需 HClO 参与）。
- **制备与安全**：实验室 MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O（须浓盐酸，变稀自动停止；KMnO₄ 与浓盐酸无需加热）；工业电解饱和食盐水（氯碱工业）2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑；Cl₂ 有毒，尾气用 NaOH 吸收。
- **漂白粉与 84**：2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O，有效成分 Ca(ClO)₂（工业品有效氯约 35%）；84 消毒液为 NaClO 溶液；须密封干燥保存（Ca(ClO)₂ + CO₂ + H₂O → CaCO₃ + 2HClO 致失效）。
- **卤素递变**：氧化性 F₂ > Cl₂ > Br₂ > I₂ 依次减弱；X⁻ 用 AgNO₃ + 稀 HNO₃ 检验（AgCl 白、AgBr 淡黄、AgI 黄，均不溶于稀 HNO₃）。

**第三节 物质的量（定量桥梁）**

- **四大量**：物质的量 n（单位 mol，Nₐ ≈ 6.022 × 10²³ mol⁻¹）、摩尔质量 M（g/mol，数值等于相对原子/分子质量）、气体摩尔体积 Vₘ（标准状况 0 °C/101.3 kPa 下约 22.4 L/mol）、物质的量浓度 c（mol/L，c = n / V）。
- **核心关系**：n = N / Nₐ = m / M = V / Vₘ = c · V。枢纽 n 一端连宏观可称量（m、V 溶液），一端连微观粒子数（N）。
- **稀释与换算**：c₁V₁ = c₂V₂；质量分数换算 c = 1000ρω / M；阿伏加德罗定律（同温同压同体积含同数分子）及推论。
- **实验**：配制一定物质的量浓度溶液（容量瓶：计算、称量、溶解冷却、引流转移、洗涤、定容、摇匀、检漏）。
- **易错前置**：22.4 L/mol 三前提（气体、标准状况、1 mol）；c = n / V 中 V 是溶液体积；Nₐ 陷阱（状态、分子构成、电子转移）。

| 实验探究与创新意识 | 钠与水/燃烧实验、Na₂CO₃/NaHCO₃ 鉴别、Cl₂ 制备与性质、氯水成分探究、一定浓度溶液配制 |

## 六、重难点与突破整体思路

- **重点**：钠与 O₂/H₂O 反应产物；Na₂O 与 Na₂O₂、Na₂CO₃ 与 NaHCO₃ 的对比与转化；Cl₂ 化学性质、氯水成分、HClO 漂白原理；物质的量四量与计算、溶液配制操作。
- **难点**：Na₂O₂ 与水/CO₂ 反应的歧化电子转移分析；氯水多粒子共存与"干燥 Cl₂ 不漂白"本质；22.4 L/mol 三前提的辨析；c = n / V 中 V 是溶液体积、离子浓度须乘离子个数；Nₐ 陷阱。
- **突破策略**："三阶转化训练"（宏观现象→微观模型→符号表达）；用价态数轴与"类别 × 价态"双轴把抽象规律可视化；对比教学（Na₂O/Na₂O₂、Na₂CO₃/NaHCO₃、HClO/SO₂ 漂白）；用反例制造认知冲突后重构（钠着火禁 CO₂、Fe 只到 +3、干燥 Cl₂ 不漂白）；用真实情境承载抽象概念。

## 七、教学建议

- **课时**：建议 10 课时——①金属钠 ②钠的氧化物 ③碳酸钠和碳酸氢钠 ④氯气的性质 ⑤氯气的制备与卤素 ⑥物质的量和摩尔质量 ⑦气体摩尔体积 ⑧物质的量浓度 ⑨一定物质的量浓度溶液的配制 ⑩计算综合。每课含"学情分析"小节、以学科核心素养统领、配必做/选做/挑战三层作业；落实库内锚点（03-知识点）与 [[高中化学必修一-习题精选]] 挂接。
- **强化实验与微观可视化**：多用粒子动画/价态数轴化解"看不见的离子、电子与歧化转移"。
- **教—学—评一致**：每节课明确素养落脚点与可观测评价点；衔接预警——钠/氯沿用第一章"分类→预测→实验→离子反应/氧化还原解释"双轴；"物质的量"是连接第一章"离子浓度"与后续滴定、产率、关系式计算的计量桥梁，须在 2.6 起显式点明。
- **章节复盘**：章末用"知识体系与概念关联图"做结构化复盘，把 10 课时连成一张网，避免知识点碎片化。
