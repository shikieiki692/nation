## 编写规范（必修一已落地，后续册次沿用）

- **目标表述**：核心素养统领（宏观辨识与微观探析 / 变化观念与平衡思想 / 证据推理与模型认知 / 科学探究与创新意识 / 科学态度与社会责任），不用旧「三维目标」。
- **必含要素**：教学设计意图、逐字稿（师生对话）、三层作业（基础/提高/拓展）、板书设计、教学反思。
- **公式书写**：优先 Unicode（H₂SO₄、Fe³⁺），**禁止半截 math**（如 $^{-1}$）。
- **链接**：库内锚点 `kp_links` + `exercise_source` 保留，便于与 [[03-知识点]] / [[04-题库]] 互通。

## 可视化与导出规范

- 概念图一律用 **Mermaid `.mmd` 源文件**保存（可版本管理、可重渲染），渲染出的 PNG 按 `chN-xx-名称.png` 命名放 `概念图PNG/`。
- 渲染后必须跑**遮挡检测**（节点/标签/连线四类），确保无相互遮挡。
- **引用双轨**：源稿 md 用语义名 `![[概念图PNG/chN-xx-名称.png]]`（可读、可解析）；导出用的 staging 副本用哈希名 `![[<sha256>.png]]`（文件在 `媒体仓库/`）。改 `.mmd` 后须按「重渲染 → refresh_diagrams.py 刷 staging 哈希 → build-all-handout-docx.py 重出 docx」顺序走；PNG 像素未变则哈希不变，staging 无需改动。
- **铁律：图必须回写源稿 md**。只把图塞进 docx 而不改 md，PNG 会变成无引用的孤儿，Obsidian 里看到的仍是旧 ASCII。阶段收尾时务必核对 `![[概念图PNG/` 引用数 == 实际 PNG 数。
- 导出三件套：`Word导出/`（docx）+ `Word导出/网页版/`（HTML，图片 base64 内嵌）+ `Word导出/PDF备用/`（PDF）。

## 课时粒度规范

- **一个课时 = 一个独立 md 文件**，命名 `N.M 课题.md`，可被单独检索、单独导出 docx、单独用于一次备课。
- **拆分依据看教学环节的自然边界**，不要按字数平均切。合订稿里"环节一 / 环节二 / 探究 1 / 探究 2"这类标题就是天然切点。
- **拆分必做的四件事**：① 每份新课时都要有完整的 11 节结构（不能只切教学过程）；② 课标、学情、目标、重难点必须按新课时定位**重写**，不能照抄合订版；③ 时间轴要重排到 45 min；④ 上下游引用（"承接 1.x""下一课时 1.y"）必须同步改。
- **原稿保留**：合订版改名为 `X 课题（合订版）.md` 留作底本，正文首行加一条拆分注记，内容一字不改。两套并存，不丢内容。
- **行尾统一 LF**：库内若发现 CRLF 文件（历史遗留），切块时剥离 `\r`，让新文件与全库一致。

> ⚠️ 已知外部缺陷：带内嵌图的 docx 在腾讯文档预览器可能报 **C14005**（已证为预览器转码问题）。遇到时改用网页版 HTML / PDF / PNG 查看，不要反复重出 docx。
