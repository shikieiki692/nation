## 第9题波尔模型（20分，占 $9\%$ ）

波尔模型是第一个成功的量子原子模型，它解释了氢原子光谱，在量子力学发展史上具有重要地位。1889年，里德伯通过分析大量氢原子光谱实验数据，提出了著名了里德伯公式： $\sigma \equiv \frac{1}{\lambda} = R\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$ 。其中 $\lambda$ 是波长， $n_1$ 和 $n_2$ 是主量子数， $R = 1.097 \times 10^7 m^{-1}$ 称为里德伯常数。1913年，波尔结合经典力学和氢原子光谱理论构建了原子的波尔模型。在波尔模型中，电子不能随意运动，只能在特定半径的轨道上绕原子核做匀速圆周运动。当电子从高能级轨道跃迁到低能级时，会辐射光子，其频率v由高低能级的能量差决定。（光子能量： $E_{\mathrm{hv}} = E_2 - E_1 = \mathrm{hv} = \mathrm{hc} / \lambda$ 。式中ν和λ分别是电磁波的频率和波长，c是真空光速，h是普朗克常数。）

9-4 波尔模型认为，电子在固定的轨道上绕原子核做匀速圆周运动。通过经典力学的方法，推导出了电子做匀速圆周运动的半径和速度之间的关系： $v=\sqrt{\frac{1}{4\pi\varepsilon_{0}}\frac{e^{2}}{mr}}$ 。其中 e 是电子的电荷量， $\varepsilon_{0}$ 是真空介电常数，m 是氢原子中电子的折合质量，v 和 r 分别是电子匀速圆周运动的速率和半径。

9-4-1 电子运动的角动量 L=mvr。证明电子运动的轨道频率 $v_{1}$ 关于角动量 L 有如下的关系式： $v_{1}=\frac{me^{4}}{32\pi^{3}\varepsilon_{0}^{2}L^{3}}$ 。（其中，轨道频率 $v_{1}$ 的定义是电子绕核一周所需时间的倒数）

9-4-2 为了解释角动量 L 和量子数 n 的关系（角动量量子化），波尔提出了“对应原理”：当量子数 n 非常大时，量子理论的结果必须与经典物理一致。具体来说：在经典物理理论中，电子做圆周运动时，因加速运动会以轨道频率辐射电磁波（轨道频率 $v_{1}$ 等于电子绕核一周所需时间的倒数）。在量子理论中，电子从 $n+1$ 能级跃迁到 n 能级时，辐射光子（电磁波）的频率 $v_{2}$ 由高低能级的能量差决定（在 n 非常大时， $\frac{1}{n^{2}} - \frac{1}{(n+1)^{2}} \approx \frac{2}{n^{3}}$ ）。已知里德伯常数 $R = \frac{e^{4} m}{8 \varepsilon_{0}^{2} c h^{3}}$ （式中各物理量的含义同上述其他公式）。请根据“对应原理”，推导角动量 L 和量子数 n 之间的关系。
