不知道您是否有这样的体验：深夜逛 B 站的时候总是被算法精确投喂大量的美食视频，令您回想起草草了事的晚餐和饥饿的身体。在这类视频中，您总能见到烤肉的身影。焦黄酥脆的表皮，吱吱作响的热油，浓郁醇厚的味道总是让您想给自己加餐。然而，您是否想过这些焦黄的物质是什么呢？

1912 年，法国科学家 L. C. Maillard 首次描述了这类反应——美拉德反应。在肉类、面包、咖啡等的烘烤中出现的这类反应通过复杂的机制生成了类黑色素聚合物，从而为您的食物显著带来丰富的口感并增添风味。

2013 年，S. Mundt 等人为了描述类黑色素物质的形成机制提出了以下反应机理：

$$
\mathrm{Gly} + \mathrm{Fru} \xrightarrow [ \text { slow } ]{k _ {1}} \mathrm{I} \xrightarrow [ \text { slow } ]{k _ {2}} \mathrm{M}
$$

其中 Gly 代表甘氨酸，Fru 代表果糖，I 代表未知的中间体，M 代表类黑色素产物。先前的机理研究表明：第一步反应对 Gly 是零级的；第二步反应对于 I 是一级的。下面我们来确定第一步反应对 Fru 的级数 $\alpha$ 和反应的速率常数 $k_{1}$ 和 $k_{2}$ 。

考虑中间体与亚硫酸氢钠 S(IV)的反应。该反应是不可逆的快反应：

$$
\mathrm{I} + \mathrm{S} (\mathrm{IV}) \xrightarrow [ \text { fast } ]{k _ {3}} \mathrm{DSH}
$$

产物 DSH（3,4-二脱氧-4-磺化己酮）在反应条件下是稳定的，并且不与体系中的其它物质发生反应。

亚硫酸氢钠可以与 Ellman 试剂(5,5-二硫代双-(二硝基苯甲酸))发生反应生成有色的化合物，该化合物的浓度可用分光光度法在波长为 412nm 处测定。产物 M 在波长为 470nm 处有吸收，吸光系数 $\varepsilon_{M} = 478 \, L mol^{-1} cm^{-1}$ 。体系中的其他物质在 UV-Vis 波段中均没有吸收。
