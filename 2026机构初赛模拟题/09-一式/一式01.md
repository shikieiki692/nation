## 第2题（11分，占9%）驱动蛋白——细胞中的纳米“火车”

1985年，还是博士生的Ronald Vale在研光乌贼神经元运输时发现：在一份只含有微管、ATP和细胞提取物混合物的对照样品中，微管竟然自己动了起来。经过半年纯化，他发现了一种全新的马达蛋白，命名为驱动蛋白(Kinesin)。驱动蛋白是一类体积微小但功能强大的ATP酶。它像一列忙碌的“火车”，在细胞内由微管蛋白组成的“轨道”——微管(Microtubule)上穿行，将各种营养物质运输到细胞的各个角落。驱动蛋白功能异常会导致遗传性痉挛性截瘫、渐冻症等疾病，也成为抗癌药物的靶点。因此，理解驱动蛋白如何结合微管、如何运动，不仅有理论意义，也有重要的医学价值。

2-1 结合平衡。驱动蛋白（P）与微管上的结合位点（Site）形成可逆结合：

$$
\mathrm{P} _ {\text { bound }} \rightleftharpoons \mathrm{P} _ {\text { free }} + \text { Site }
$$

单个驱动蛋白分子与相应位点的结合过程符合质量作用定律：

$$
K _ {d} = \frac {[ \mathrm{P} _ {\text { free }} ] [ \text { Site } ]}{[ \mathrm{P} _ {\text { bound }} ]}
$$

其中，[Site]为未结合的结合位点浓度， $\left[\mathrm{P}_{\mathrm{free}}\right]$ 为自由的驱动蛋白浓度， $\left[\mathrm{P}_{\mathrm{bound}}\right]$ 为已结合的驱动蛋白浓度， $K_{d}$ 为解离平衡常数。已知 $K_{d} = 5.00 \times 10^{-7} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ ， $\left[\mathrm{P}_{\mathrm{free}}\right] = 1.00 \times 10^{-7} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ ，微管上结合位点的总浓度 $\left[\mathrm{Site}\right]_{\mathrm{total}} = 1.00 \times 10^{-5} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ 。

2-1-2 计算平衡时结合到微管上的驱动蛋白浓度 $\left[\mathrm{P}_{\text {bound}}\right]$ 和结合位点的结合分数。

将Chatt配合物trans- $\mathrm{[W(N_3)_2(dppe)_2](dppe = Ph_2P(CH_2)_2PPh_2)}$ 与 $\mathrm{BBr}_2\mathrm{Dur}(\mathrm{Dur}$ 为2,3,5,6-四甲基苯基）在苯中反应，观察到有气体生成。随后加入 $\mathrm{Me}_3\mathrm{SiNTf}_2$ （Tf为三氟甲磺酰基），溶液由橙色变为深蓝色，结晶可得配合物盐A。将A与 $\mathrm{Me}_3\mathrm{SiN}_3$ 在室温下反应，溶液立即褪色，生成含有三个五元环的配合物盐B。而若将A与 $t\mathrm{BuB}\equiv N / \mathrm{Bu}$ 在室温下反应，溶液则由深蓝色变为红色，发生芳基迁移并生成含有更长无机链的配合物盐C。

## 第4题（15分，占 $11\%$ ）homologous series

在固体化学中，同源系列是指一类由同一结构操作反复作用生成的、结构高度相关的晶体家族。这类材料的化学式通常可以写作：

$$
\text { Host } (\text { Insertion }) _ {n}
$$

其中，n 为正整数，表示插入结构单元重复的次数。随着 n 的变化，晶体的结构参数（如晶胞尺寸、孔道面积）呈现规律性变化，从而实现对材料性能的连续调控

研究人员在探索Cs-Bi-S体系时，发现了一种新化合物X，其晶胞结构沿(001)方向的投影如下所示，其中大球为Cs，中球为Bi，小球为S。单品X射线衍射分析表明，X中 $\mathrm{Bi}^{3+}$ 与 $\mathbf{S}^2$ -形成八面体，这些八面体共边连接形成三维阴离子网络， $\mathrm{Cs^{+}}$ 填入网络中的一维矩形棱柱状孔道内，每个孔道中沿孔道方向排列着5条 $\mathrm{Cs^{+}}$ 链（每条链的横截面为 $1\times 1$ 个离子）。已知X的晶胞参数 $a = 3381~\mathrm{pm}$ ， $b = 1285~\mathrm{pm}$ ， $c = 411~\mathrm{pm}$ ， $a = \beta = \gamma = 90^{\circ}$ 。

进一步研究发现，X并非孤立相，而是属于某个同源系列Y。Y由三价金属离子M、碱金属离子A和硫族元素Q组成，涵盖了从 $n = 0$ 到 $\vec{n} \rightarrow \alpha$ 结构演化的全过程。当 $n = 0$ 时，成员结构为Q原子形成密堆积，M填入其中2/3的八面体空隙；而当 $n$ 为正整数时，各成员结构均呈现出“人字形”排列的矩形孔道，孔道中含有 $n$ 条碱金属离子链。
