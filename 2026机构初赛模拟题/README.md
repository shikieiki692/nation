## 三、使用与纪律

1. **原件不动**：本目录文件为 OCR 原件，拆题时**只读取用**，不在原地改写。
2. **图片随行**：每份 md 配一个同名 `_images/` 目录；题卡引用图片时必须先确认目标文件存在（台账中「断图」列为 0 才可直接引用）。
3. **⛔ 内部资料**：伽马等卷面原印「内部专用·请勿外传」，**仅供内部备考，不得进入任何对外发布物**。
4. **⚠️ 2ChO 查重**：2ChO 分册含第 37/38/39 届初赛解析，可能与 `05-真题库/` 重复，**拆卡前必须先查重**。
5. **合并本**：XeChem 杭州集训卷以 3 个合并本 OCR（`PDF合并_400-496`、`（已压缩）PDF合并_1-199`、`（已压缩）PDF合并_200-399`），分别覆盖卷二十四~二十六／十二~十八／十九~二十三；拆题时按合并本内的卷标题切分。
