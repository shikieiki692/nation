6-3 该酸在生命体循环中由草酰乙酸得来，并且在后续的过程中会依次转化为 C 和 D。D 是 X 的(2R,3S)异构体，X 的摩尔质量是 C 的 1.1 倍。画出 C 和 D 的结构，C 请画出酸性更强的那一个立体异构体。6-4 三氟乙酸盐对人体而言是剧毒的，因为它可以转化成一种物质，该物质可以占据酶催化 X 转化为 D 反应的活性位点。其动力学行为可以如下描述：

$$
\begin{array}{c} \mathrm{E} + \mathrm{S} \xrightarrow [ k _ {- 1} ]{k _ {1}} \mathrm{ES} \xrightarrow [ k _ {2} ]{k _ {2}} \mathrm{E} + \mathrm{P} \\ \mathrm{EI} \xrightarrow [ K _ {i} ]{K _ {i}} \mathrm{E} + \mathrm{I} \end{array}
$$

其中，E 为酶，S 为底物，P 为产物，ES 是酶与底物的复合物，I 为抑制剂，可以可逆地与酶结合，EI 解离的平衡常数为 $K_{i}$ 。

6-4-2 如果酶的总浓度为 $[\mathrm{E}]_0$ ，我们将会获得形式如下的速率方程：

$$
r = \frac {\mathrm{d} [ \mathrm{P} ]}{\mathrm{d} t} = \frac {A [ \mathrm{S} ]}{B + [ \mathrm{S} ]}
