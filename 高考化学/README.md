# 高考化学赛道

> **定位**：本目录是"高考化学"独立赛道，与全库的竞赛（CChO）体系**严格平行、互不污染**，但共享基础设施（11-模板/脚本/skills/媒体仓库）。
> **一句话**：以「一化儿高考必刷100讲」为模板，结合新教材与教师用书，打造覆盖**新课 + 一轮/二轮/三轮复习**、满足高考需求的完整讲义体系。

## 为什么是"库中库"

- **竞赛体系**（不动）：`03-知识点/`（929 KP）、`04-题库/`、`备课思路/`（五轮）、`02-考纲条目/`（CChO）
- **高考赛道**（本目录）：自建一套平行结构（考纲/知识点/题库/讲义/备课/提炼）
- **桥接点**（唯一的交叉）：高考 KP 底部加"竞赛延伸"链接；竞赛 KP 顶部加"高考落地"链接。除此之外不交叉。

## 三线课程体系

1. **新课线**：同步教材（必修1/2 + 选必1/2/3）。优先级：先做选必1/2/3——竞赛库在原理/结构/有机上素材最厚。
2. **一轮复习线**：按一化 **16 章 → 模块 → 类型** 逐章生产复习讲义（**核心产出**）。
3. **二轮专题 + 三轮冲刺**：8 大题型专题（工艺流程/实验综合/水溶液图像/电化学综合/有机合成推断/反应原理综合/元素推断/化学计算与用语）+ 套卷/答题规范。
