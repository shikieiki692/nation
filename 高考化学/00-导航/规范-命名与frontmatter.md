# 高考赛道 · 命名与 frontmatter 规范

> **用途**：本规范是高考赛道的硬边界，保证与竞赛体系（929 KP + 大量 alias）零冲突。任何写入 `高考化学/` 的文件都必须遵守。

## 一、命名空间

| 类型 | 规则 | 示例 |
|---|---|---|
| 知识点 KP | 文件名以 `高中-` 前缀 | `高中-氧化还原`、`高中-离子反应` |
| 讲义 | 前缀标明轮次 | `一轮-氧化还原反应.md`、`新课-选必一-反应热.md`、`二轮-化学工艺流程.md` |
| 题库题目 | 沿用竞赛题号风格但带 `GK-` | `题-GK-01-阿伏加德罗常数.md` |
| 考纲条目 | 按 5 本书编号 | `必修一-物质及其变化.md`、`选必一-水溶液中的离子反应与平衡.md` |

## 二、标签

- 赛道级标签：**`#高中化学`**（所有高考赛道文件必带）
- 用途标签：`#高考`（讲义/题库）、`#新课`/`#一轮`/`#二轮`/`#三轮`（讲义轮次）
- 禁止：把竞赛 Dataview 里的 `#化竞` 类标签加到高考文件；反之亦然

## 三、frontmatter 字段

```yaml
---
title: 高中-氧化还原反应
type: 知识点          # 与竞赛 KP 同 type，但路径隔离
level: 高考           # 赛道标志：高考 / 竞赛
syllabus: 新课标       # 考纲体系
book: 必修一          # 对应教材：必修一/必修二/选必一/选必二/选必三
stage: 一轮           # 新课 / 一轮 / 二轮 / 三轮
tags: [高中化学, 高考]
status: 已填充
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

## 四、深度分层（高考口径）

| 标记 | 含义 |
|---|---|
| 🌱 基础 | 必修要求，一轮必讲 |
| 🔥 进阶 | 高考中档/拉分题，二轮专题重点 |
| 🏆 拔高 | 压轴题/升维内容，可"竞赛延伸"到竞赛 KP |
| ★~★★★★★ | 一化式难度星级（★ 基础 ~ ★★★★★ 难题） |

## 五、与竞赛体系的桥接规则

> 桥接是**唯一允许**跨越赛道边界的引用，方向必须标注清楚。

- **高考 KP 底部**：
  `> 🔗 竞赛延伸：[[xxx]]（更深理论/更多机理，供升维学习）`
- **竞赛 KP 顶部**（只在确实存在高考落点时添加）：
  `> 📚 高考落地：[[高中-xxx]]（该知识点在高考中的考查方式）`
- **禁止**：竞赛 KP 引用高考讲义；高考讲义引用竞赛讲义正文（只允许在"🏆 拔高"栏链接竞赛 KP）

## 六、OCR/源资料规则

- 一化 OCR 源文件：**禁止全读**（压缩 OCR，体量大）。只读已提炼的章节摘要，或 `limit` 读取特定模块。
- 提炼文件命名：`一化-第X章-{章名}-提炼.md`，每章一份，放 `高考化学/06-资料提炼/一化/`。
