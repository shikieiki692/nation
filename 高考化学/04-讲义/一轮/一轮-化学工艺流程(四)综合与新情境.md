# 化学工艺流程（四）：综合与新情境

## §零 学习目标

1. 综合运用框架 + 元素套路解读陌生完整流程（读图析段）。
2. 掌握分步沉淀、母液离子浓度（Ksp）计算等跨环节综合设问。
3. 掌握产率、萃取率、转化率计算的元素守恒法。
4. 理解绿色化学（循环利用、废物资源化、能量梯级）与新型工艺（细菌冶金、配位浸取、盐湖提锂）的高考表达。

## §一 知识网络

```
综合流程 = 元素套路 I×II 的任意拼接
读图四步：
  ① 划段：原料→预处理→每步分离→产品/尾气/母液
  ② 标径：目标元素每段去向（滤液/滤渣/有机相/水相）
  ③ 设问归类：操作目的/方程式/pH/沉淀剂/计算/循环
  ④ 收尾：循环物质找"回头箭头+母液+再生酸碱"
计算双守：元素守恒（产率）+ Ksp 反推（浓度上限/沉淀完全）
新情境三件套：配位浸取(NH₃/CN⁻/Cl⁻)·微生物(细菌冶金)·绿色循环(CO₂捕集/盐湖提锂)
```

> [!tip] 核心方法
> 综合题 = 多个"单元"串成流水线，把陌生流程切成熟悉的段，一段问什么答什么；凡计算必先写守恒式，凡配平必先标化合价。

## §二 题型分类

### 类型Ⅰ 综合流程读图（陌生体系）

- **常规解**：先把流程按操作分段划线，再把每段的物相（渣/液/气/有机相）列出，最后逐问定位到段。
- **考场巧解**：陌生流程不怕——找「最熟悉的指令词」（调 pH、煅烧、反萃取、真空干燥）对应已背模板。

> **例题（2024 东北三省卷真题呈现，题号待回填）**：细菌冶金载金矿流程中：含 FeS₂ 的难处理金精矿经细菌氧化浸出。写出细菌氧化 FeS₂ 的离子方程式；浸出液加铁盐。回答：细菌冶金相对火法冶金的优势。
>
> **解析**：`4FeS₂ + 15O₂ + 2H₂O ═(细菌)═ 4Fe³⁺ + 8SO₄²⁻ + 4H⁺`（细菌作催化剂，常温常压）。优势：① 不产生 SO₂ 大气污染（硫转化 SO₄²⁻ 而非 SO₂）② 常温常压节能、设备无需耐高温 ③ 对低品位矿适用。浸金用 NaCN 配位：Au 被 O₂ 氧化再与 CN⁻ 配位形成 [Au(CN)₂]⁻（类比王水 Cl⁻ 配位），Zn 置换回收；`Na₂[Zn(CN)₄]+2H₂SO₄=ZnSO₄+4HCN+Na₂SO₄`，NaOH 中和 HCN→NaCN 循环。原卷考点「FeS₂ 细菌氧化/NaCN 配位浸金/Zn 置换」+ 铁盐水解 H₂SO₄（题号待回填）。

### 类型Ⅱ 分步沉淀与母液浓度（Ksp 综合）

- **常规解**：分步沉淀按 Ksp 由小到大先后轮到各自完全沉淀；母液离子浓度用「沉淀完全 c≤10⁻⁵」或给定沉淀率反推，再乘后续体积得剩余量。
- **考场巧解**：「母液中 Mg²⁺ 浓度」用沉淀完全判据 + 稀释效应两步；分步沉淀区间 = 前一离子完全沉淀与后一离子开始沉淀之间的 pH 窗口。

> **例题（2021 全国乙卷真题呈现，题号待回填）**：高钛炉渣回收钛铝镁工艺中：含铝固相经 (NH₄)₂SO₄ 高温焙烧生成 NH₄Al(SO₄)₂，尾气 NH₃ 返回循环；随后分步沉淀 Fe³⁺→Al³⁺→Mg²⁺。回答：分步沉淀各段调 pH 的对象依据；酸溶渣的成分是什么？
>
> **解析**：依据各氢氧化物 Ksp 不同，依次将 Fe³⁺（酸性较强区间沉淀）、Al³⁺、Mg²⁺（碱性较强区间沉淀）分步沉出，目标离子进入相应工序不损失。酸溶渣为 SiO₂ 与 CaSO₄（微溶，硫酸浸钙时残留）。原卷考点「NH₄Al(SO₄)₂ 生成 + 分步沉淀 + 母液 Mg²⁺ 浓度 Ksp 计算」（题号待回填）。

### 类型Ⅲ 产率 / 萃取率 / 转化率计算

- **常规解**：产率 = 实际 / 理论 ×100%；理论产量由**目标元素守恒**求；多步损失/引入逐项加和；萃取率 = 被萃取量 / 原始总量。
- **考场巧解**：先画元素流向图再代数，省去反复读题；单位统一（kg 直接用，g 换算 mol 时注意 M）。

> **例题（无卷别·自编，数值可验算）**：59 g NiO（M=75）经酸浸、除杂、蒸发结晶得 NiSO₄·7H₂O（M=281），实际析出 176.8 g 晶体，求产率。（假定 Ni 全部进入产品）
>
> **解析**：理论产量按 Ni 守恒：n(NiO)=59/75≈0.787 mol → 理论 m(NiSO₄·7H₂O)=0.787×281≈221.1 g。产率 = 实际/理论 ×100% = 176.8/221.1 ≈ 80%。

> **例题（无卷别·自编，数值可验算）**：100 mL 含 Zn²⁺ 0.10 mol/L 的水相与等体积萃取剂 HR 振荡分液，平衡时有机相中 Zn²⁺ 浓度为 0.08 mol/L（以有机相体积计）。求萃取率。
>
> **解析**：水相初始 n(Zn²⁺)=0.10×0.100=0.010 mol；有机相 n(Zn²⁺)=0.08×0.100=8.0×10⁻³ mol。萃取率 = 8.0×10⁻³/0.010 = 80%。

### 类型Ⅳ 新情境工艺（盐湖提锂 / CO₂ 资源化）

- **常规解**：新工艺仍套老骨架——盐湖卤水提锂：太阳能蒸发浓缩 → 除 Mg²⁺/Ca²⁺（加石灰/NaOH 或 Na₂CO₃）→ 吸附法/膜法富集 Li⁺ → 沉锂 Na₂CO₃（Li₂CO₃ 溶解度小）；CO₂ 捕集：碱性吸收液（如 KOH/乙醇胺）吸收 CO₂ → 加热/加压释放 CO₂ → 胺液循环。
- **考场巧解**：「循环物质」题先找「再生」——吸收剂再生返回、膜组件回用、母液回卤；「碳中和」话术 = 碳捕集 + 产品利用 + 能耗最小化。

> **例题（无卷别·自编，待真题库回收）**：某盐湖卤水含高浓度 Mg²⁺，提锂前需深度除镁。工业上用石灰乳先沉 Mg(OH)₂，再用 Na₂CO₃ 沉残余 Ca²⁺（石灰引入）。说明第一步用石灰乳而不用 NaOH 的理由。
>
> **解析**：石灰乳廉价易得且碱性适中，过量时生成 Ca(OH)₂ 沉淀不至于过度碱化；用 NaOH 成本高且引入 Na⁺ 增大后续沉锂时 Na₂CO₃ 用量控制难度（Li⁺ 与 Na⁺ 分离是难点）。沉锂用 Na₂CO₃ 热水洗涤（Li₂CO₃ 溶解度随温度升高减小，热水洗减少损失）。

### 类型Ⅴ 绿色化学与循环经济

- **常规解**：原子利用率 = 目标产物相对原子质量 / 反应物总相对原子质量；评价维度：① 原子经济性 ② 循环（母液/尾气/萃取剂再生）③ 能量（逆流换热/余热利用）④ 环保（SO₂ 回收、HCN 中和、尾气处理）。
- **考场巧解**：开卷答题模板「循环 + 节能 + 减排」三分句；看到尾气 NH₃/SO₂ 先答「回收循环利用」。

> **例题（无卷别·自编，待真题库回收）**：钒钛磁铁矿提钒尾渣含 Fe₂O₃ 等，工业将其配煤造球炼铁，铁水用于炼钢，炉渣制建材。从绿色化学角度评价此工艺。
>
> **解析**：① 资源综合利用——把「废渣」变成炼铁原料，实现元素梯级利用；② 减少堆存污染、土地占用；③ 炉渣制建材实现固废资源化；④ 冶炼余热与尾气回收（若有）体现能量与物质双重循环，符合循环经济理念。

## §三 易错辨析

> [!warning] 易错 1
> 综合流程「一段一问」，最忌全流程混答；先划段定位再作答。

> [!warning] 易错 2
> 产率/萃取率计算先写守恒关系（元素守恒/物料平衡），再代数据；遗失率、引入量逐项加和，不能只算一步。

> [!warning] 易错 3
> 萃取的「反萃取」是加酸使配位平衡逆移，萃取剂可循环；萃取本身是化学变化不是纯物理过程。

> [!warning] 易错 4
> 新情境中「配位浸取」仍需氧化剂（Au+CN⁻ 需 O₂；Cu+NH₃ 需 O₂/氧化剂），缺氧化剂反应不发生。

> [!warning] 易错 5
> 热水洗涤不一定减少损失：Li₂CO₃ 是溶解度随温度升高而减小（热水洗保收率），多数盐相反——先看温度-溶解度曲线再答。

## §四 进阶与升维

> 🏆 **拔高视角**：综合题的本质是「把高考套路当积木拼」：细菌冶金 = 氧化还原 + 配位 + 置换三块积木；高钛炉渣 = 盐类分解 + 分步沉淀 + Ksp 三块积木。竞赛层面这些工艺对应真实的化学反应工程（氧化焙烧热力学、溶剂萃取分配比、湿法冶金电势-pH 图），学有余力可借竞赛视角建立「单元操作」心智模型。

> 🔗 **竞赛延伸**：参见 [[03-知识点/分析化学/热重分析|热重分析]]（沉淀/盐类分解产物验证）、[[03-知识点/无机和结构化学/电解冶金|电解冶金]]（湿法电积与氧化物熔盐电解对照）、[[03-知识点/化学原理/电化学|电化学]]（阳极析氧/阴极沉积的实际电极反应）。
