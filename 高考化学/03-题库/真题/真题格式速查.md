# 高考真题库 · 格式速查

> 操作 `高考化学/03-题库/真题/` 下任何文件前，**必须先读本速查**（CLAUDE.md 题库规则的高考侧延伸）。
> 对应竞赛侧规范：`04-题库/教材习题/结构化学基础/题库格式速查.md`。

## 1. 收录范围

| 项 | 规则 |
|---|---|
| 年份 | **2021-2025**（新高考改革以来的代表性卷期） |
| 卷种 | 全国卷（甲/乙/新课标）+ 地方卷（见 [[真题索引]] 卷别清单） |
| 联考/模拟 | ⚠️ **非真题**（九省联考/东北三省联考/山东枣庄等）**不入真题库**，仅在 [[待回收题单]] 中标注「非真题·仅供对照」，L2 录入时单独分目录 `模拟/` |
| 粒度 | **按卷整卷入库**（每卷一个 md），题号锚点 `### 题号` 供讲义词链接 |

## 2. 命名规范

```
真题-{年份}-{卷别代码}.md
例：真题-2024-山东卷.md / 真题-2023-新课标卷.md / 真题-2022-全国甲卷.md
```

**卷别代码对照**（统一用全称，避免歧义）：

| 代码 | 说明 | 备注 |
|---|---|---|
| 全国甲卷 | 2021-2023 全国甲卷 | 2024 起并入新课标卷 |
| 全国乙卷 | 2021-2023 全国乙卷 | 2024 起并入新课标卷 |
| 新课标卷 | 2024-2025 新高考全国卷 | Ⅰ/Ⅱ 分设时注明 |
| 浙江1月/6月 | 浙江选考（每年两考） | 两期分开成卷 |
| 北京/上海/天津 | 直辖市自主命题 | 上海 2024 起等级考 |
| 山东/海南 | 3+3 新高考省 | 化学单科卷 |
| 广东/河北/湖南/湖北/江苏/辽宁/重庆/福建 | 3+1+2 新高考省 | 化学单科卷 |
| 安徽/江西/甘肃/贵州/广西/山西/河南/云南/四川/黑龙江/吉林/内蒙古/宁夏/青海/新疆/陕西/西藏 | 2024 起新课标卷省份 | 见年份矩阵 |

```markdown
---
title: 真题-2024-新课标卷
type: 真题卷
level: 高考
year: 2024
paper: 新课标卷
subject: 化学

status: 已录入待回填        # 🔲待收录 / 📥原文待录入 / ✅已入库 / ⏳回填中
collected: 2026-08-20
tags: [高中化学, 高考, 真题, 2024]
---

# 2024 新课标卷 · 化学

> 收录说明：本卷自 PDF 提取，选择题/大题逐题锚点如下。

## 一、选择题

### 题号 1
（题目原文或要点）
- **答案**：A
- **考点**：化学与生活
- **引用讲次**：[[一轮-化学与生活]] §X

### 题号 2
...
```

**锚点铁律**：每道题必须以 `### 题号 N` 为唯一锚点（`N`=卷面题号）。讲义词用 `[[真题-2024-新课标卷#题号 5]]` 精确引用。

## 4. 单题 frontmatter 模板（L2 按题拆分时用）

```markdown
---
type: 真题
level: 高考
year: 2024
paper: 新课标卷
qid: "2024-新课标卷-5"
kp: [高中-化学与生活]
difficulty: ★★        # 一化星级口径
answer: A
cited_by: "[[一轮-化学与生活]]"
tags: [高中化学, 高考, 真题]
---
```

## 5. 双向映射规则

- **讲义→真题**：讲义词 `### 高考链接回收清单` 表中「待回填」→ 填入 `[[真题-XXXX#题号 N]]`
- **真题→讲义**：每卷 md 中每题 `引用讲次` 字段反向记录
- **提炼→真题**：16 章提炼文件 `## 真题分布` 段为 L1 回填的**权威源**（含考点/数值），回填时逐条核对

## 6. 操作前必读（Token 红线）

1. 先读本速查 + [[真题索引]] + [[待回收题单]]
2. 回填 = 小修改，用 kb_edit 单锚点操作，禁止 Read 全文再 Write
3. L2 录入 PDF 时按卷分块读取，禁止一次全读大文件
4. 联考/模拟题禁止混入真题卷目录
