## 模块1 有机化合物的分类与命名（★★★）

### 1.1 有机物的分类

- **按碳骨架**：链状化合物 ↔ 环状化合物（脂环化合物 / 芳香化合物）
- **按官能团**：
  - 烃（只含 C、H）：烷烃、烯烃、炔烃、芳香烃 —— **苯环不是官能团**
  - 烃的衍生物：卤代烃 -X、醇 -OH、酚 -OH（直接连苯环）、醚 -O-、醛 -CHO、酮 -C(=O)-、羧酸 -COOH、酯 -COO-、胺 -NH₂、酰胺 -CONH₂、腈 -CN

**例1 分类判断 5 则（易错）**：
- 有机物必含 C，不一定含 H（如 CCl₄）
- 芳香烃 ⊂ 芳香族化合物（芳香族可含其他元素，如苯酚）；苯的同系物是芳香烃中只有 1 个苯环、侧链全为烷基者
- 酚 vs 醇：C₆H₅OH（酚，-OH 直接连苯环）≠ C₆H₅CH₂OH（苯甲醇，属醇）
- 含醛基不一定是醛：甲酸 HCOOH、甲酸甲酯 HCOOCH₃ 含 -CHO 片段但分别属羧酸、酯

**例2 同类判断**：答案 A（都为酚——含酚羟基的化合物归同类）
**例3 官能团识别**：
- DDT 替代物：羟基、醛基、脂环中的 C=C（非苯环）
- 心酮胺：醚键、酮羰基、亚氨基、羟基
- 阿斯巴甜：羧基、酯基、酰胺基、氨基

**例4 同系物 8 判断 + 总结**：同系物 = 结构相似 + 官能团种类与数目相同 + 通式相同；环烷烃（C₃H₆）与烷烃非同系物。

### 1.2 有机物的命名

- **烷烃习惯命名**：甲~癸（1~10）；"正/异/新"
- **系统命名**：选主链"最长""最多"→ 编号"近、简、小"→ 书写（先简单后复杂、相同合并）
- **烯烃/炔烃**：含双/三键最长链为主链、编号距不饱和键最近端；顺反异构
- **含官能团命名优先序**（口诀 **"羧酯和酰胺、醛醇酚和胺、三双后有苯、烷基卤硝基"**）：
  `-COOH > -COO- > -CONH₂ > -CHO > 醇-OH/酚-OH > -NH₂ > 三键/双键 > -Ph > 烷基 > -X > -NO₂`
- **二官能团**：称"某二醇"（不叫"二乙醇"）
- **芳香族命名**：卤素/硝基取代以苯为母体；-COOH/-CHO/-OH/-NH₂/双键三键以官能团为母体；二甲苯邻/间/对 = 1,2/1,3/1,4
- **聚合物/醚/酯/酰胺**：聚氯乙烯、二甲醚、2-甲氧基戊烷、对乙氧基苯酚、丙酸乙酯、乙酰胺、甲酰苯胺、N-甲基乙酰胺、N,N-二甲基甲酰胺（DMF）

**命名书写口诀**："阿阿逗，阿中短，中中无间隔"（编号小→大，逗号分隔数字、短线分隔数字与汉字，中间无间隔）

**类型Ⅰ 例1 命名判断 10 则**：2-乙基戊烷 ×（→3-甲基己烷）、2,4-二甲基-3-乙基戊烷 √、2-甲基-2-戊烯 √、2,3,4,4-四甲基己烷 √、3,3-二甲基-1-戊烯 √、4-甲基-2-戊炔 √、顺-3-甲基-2-戊烯 √、反式聚-1,3-丁二烯 √
**类型Ⅱ 例2 衍生物命名**：2-丁醇、2-乙基戊酸、2-溴环己醇、3-羟基丙醛、3,3-二甲基丁酸甲酯、3-甲基-2,5-己二醇、1,6-己二胺、3-氨基丁酸、N,N-二甲基甲酰胺
**类型Ⅲ 例3 芳香族命名**：苯乙烯、邻氯甲苯、2,4,6-三硝基甲苯（TNT）、对氨基苯酚、对甲基苯胺、苯甲酰胺、2-苯基-1-丙醇、3-苯基丙烯酸、苯甲酸甲酯、甲酸苯甲酯、对苯二甲醛

### 有机物分离提纯方法的选择依据与物理常数判据（蒸馏 / 萃取分液 / 重结晶） · 对接缺口#42

- **蒸馏/分馏**：依据**沸点差异**（通常沸点相差 $>30^\circ\mathrm{C}$ 且热稳定性好的互溶液体混合物，如乙醇与水、石油各馏分）。
- **萃取与分液**：依据**溶解度差异与互不相溶**（利用溶质在两种互不相溶溶剂中溶解度不同，将溶质富集转移，随后在分液漏斗中分液，如用 $\mathrm{CCl_4}$ 萃取溴水中的 $\mathrm{Br_2}$）。
- **重结晶**：依据**溶解度随温度变化的显著差异**（固体混合物在溶剂中加热溶解，冷却析出纯晶体，杂质在高温下不溶或在低温下仍溶解留在母液中，如苯甲酸提纯）。

## 模块2 实验式、分子式、分子结构的确定（★★★★）

### 2.1 测定流程与手段

| 测什么 | 手段 | 关键读法 |
|--------|------|----------|
| 实验式（最简式） | 李比希法（燃烧，测 CO₂/H₂O 质量） | 求出 C、H、O 原子个数最简整数比 |
| 分子式 | 质谱法 | 质荷比（m/z）最大值 = 相对分子质量；分子式 =（最简式）ₙ |
| 官能团/化学键 | 红外光谱 | 特征吸收峰 |
| H 原子种类/个数 | 核磁共振氢谱 | 峰数 = H 原子类型数；峰面积比 = H 原子个数比 |
| 键长键角/晶型 | X 射线衍射 | 晶体结构 |

**等效氢三原则**：①同一碳上的 H 等效；②同一碳所连甲基上的 H 等效；③对称位置的 H 等效。

**例1（2024·山东）青蒿素**：答案 C —— 相对分子质量由质谱（质荷比）测，核磁测的是 H 种类/个数。
**例2（2024·湖南）甲苯质谱**：质荷比最大 92 与 C₇H₈ 相对分子质量一致 → √。
**例3 三组峰**：答案 D（2,5-二甲基己烷，对称结构只有 3 种 H）。
**例4 7 判断**：含等效氢判断；"防弹衣单体核磁峰数与面积比"类说法注意逐个核对。
**例5（2024·浙江6月）有机物A推断**：质谱 60 → 分子式 C₃H₈O（或 C₂H₄O₂，需结合不饱和度）→ 4 种 H → CH₃CH₂CH₂OH。口诀 **"减氧、除碳、余氢"**（由相对分子质量拼分子式）。
**例6 扑热息痛结构表征（跨文件衔接）**：燃烧 + 质谱 → 实验式 C₈H₉NO₂；Ω = 5；NaHCO₃ 不冒泡（无 -COOH）、FeCl₃ 紫色（有酚羟基）、水解产物两性（含 -NH₂ 与酚羟基）→ 对位结构 HO-C₆H₅-NHCOCH₃。**注意：不能是 HO-C₆H₅-CONHCH₃**（其水解产物为 H₂N-C₆H₄-OH + CH₃COOH，两性要求判据在 _151-300.md 开头完整解析）。反思：**对称结构优先**。

### 甲烷与烷烃必修基础（正四面体成键模型 / 取代反应特征 / 物理性质递变） · 对接缺口#19

- **甲烷空间构型**：正四面体立体构型，$\mathrm{C-H}$ 键角 $109^\circ 28'$，极性键构成的非极性分子（4 个氢原子完全等价，二氯甲烷 $\mathrm{CH_2Cl_2}$ 只有 1 种结构直接证明其空间为四面体而非平面正方形）。
- **取代反应特征**：光照条件下与纯卤素单质（如 $\mathrm{Cl_2}$）发生分步链式自由基取代反应（反应产物为 $\mathrm{CH_3Cl, CH_2Cl_2, CHCl_3, CCl_4}$ 和 $\mathrm{HCl}$ 的混合物，生成 $\mathrm{HCl}$ 物质的量最多）。

### 烃的化工来源与综合利用（石油分馏/裂化/裂解与煤的干馏/气化/液化） · 对接缺口#44

- **石油的综合加工**：
  - **分馏（物理变化）**：按沸点不同将石油分离为石油气、汽油、煤油、柴油、重油等馏分；
  - **裂化（化学变化）**：在催化剂和加热条件下将长链烷烃断裂为短链烷烃和烯烃，目的为**提高轻质液体燃料（优质汽油）的产量**；
  - **裂解（化学变化，深度裂化）**：在更高温度下（$700\sim 800^\circ\mathrm{C}$）将烃类断裂为以**乙烯、丙烯、丁二烯**为主的小分子烯烃，是现代石油化工的基石原料。
- **煤的综合加工**：
  - **干馏（化学变化/焦化）**：隔绝空气加强热使煤分解，产物为焦炭、煤焦油（含苯/甲苯/酚类）、焦炉气（含 $\mathrm{H_2, CH_4, CO, C_2H_4}$）和粗氨水；
  - **气化与液化（化学变化）**：气化生成水煤气（$\mathrm{CO + H_2}$），间接或直接液化合成甲醇和人造液体燃料。

## 模块3 烃（★★★★★）

### 3.1 烷烃、烯烃、炔烃

- **通式**：烷烃 CₙH₂ₙ₊₂、烯烃 CₙH₂ₙ、炔烃 CₙH₂ₙ₋₂（CₙH₂ₙ 的烃**可能是环烷烃**）
- **物理性质**：C1~4 气态；沸点随碳数增而升、同碳数支链越多沸点越低（正戊烷>异戊烷>新戊烷）；密度均小于水；难溶于水
- **化学性质**：
  - **取代"断σ成σ"**：烷烃与卤素定量关系 -C-H ~ X₂ ~ HX；光照，与溴水不反应
  - **加成"断π成σ"**：烯/炔与 H₂、X₂、HX、H₂O、HCN
  - **马氏加成**：不对称烯烃 + HX，H 加到含氢多的不饱和碳（"亲上加亲、物以类聚"）；过氧化物存在时反马氏（H 加到含氢少的碳）
  - **乙炔加成链**：H₂(少量)→乙烯、H₂(足量)→乙烷；Br₂(少量)→1,2-二溴乙烯、Br₂(足量)→四溴乙烷；HCl→氯乙烯；H₂O→乙醛（烯醇重排）；HCN→丙烯腈
  - **异构化（重排）**：①同碳两个双键 → 三键（C=C=C→C≡C-C）；②烯醇重排：链端 C=C-OH → 醛，链中 → 酮；③环-2,4-己二烯酮 → 酚
  - **二烯烃加成**：1,2-加成 / 1,4-加成（共轭二烯，如 1,3-丁二烯 + Br₂）
  - **加聚反应**：书写注意半键所在碳位置，勿张冠李戴；丙烯→聚丙烯、乙炔→聚乙炔（导电高分子）
- **KMnO₄ 氧化规律（脂肪烃）**：
  - 烯烃：RCH=CH₂ → RCOOH + CO₂；RCH=CHR' → RCOOH + R'COOH；R₂C=CHR' → 酮 + R'COOH（**双键碳上有2H→CO₂、1H→羧基、无H→酮羰基**）
  - 炔烃：端位三键碳 → CO₂；链中三键碳 → 羧基
  - 烷烃：不褪色
- **燃烧现象**：烷烃火焰明亮；烯烃明亮带黑烟；炔烃（乙炔）很明亮带浓黑烟（燃烧法区分液态烷烃与苯）

**类型Ⅰ 例1 烷烃概念 9 判断**（要点）：
- CₙH₂ₙ₊₂ 一定是链状烷烃；CₙH₂ₙ 可能是环烷烃
- 烷烃 C 均 sp³ 杂化、全为 σ 键
- 甲烷 Cl₂ 取代得不到纯净 CCl₄（多产物混 HCl）
- **甲烷二氯代物只有一种 → 正四面体结构**（若平面正方形则邻/对两种）
- 与溴水不反应（区别乙烯）
**类型Ⅰ 例2 降冰片烯**：答案 D（降冰片烷一氯代物 3 种）；降冰片烯 C₇H₁₀ ≠ 甲苯 C₇H₈
**类型Ⅱ 例3 烯炔概念 8 判断**（要点）：
- 乙烯 5σ+1π
- 酸性 KMnO₄ 只可"鉴别"甲烷/乙烯，**不可除杂**（乙烯→CO₂ 引入新杂质）；**溴水既可鉴别也可除杂**；不能用溴的 CCl₄ 除杂（甲烷溶于 CCl₄ 损耗）
- 丙烯 -CH₃ 为 sp³
- 丙烯 + HBr 主要得 2-溴丙烷（马氏）
- C₃H₆ 可能是环丙烷（不褪色）
- 1mol 丙炔最多与 2mol Cl₂ 加成
- 聚丙烯无 C=C，不使 KMnO₄ 褪色
**类型Ⅱ 例4（2023·浙江6月）丙烯转化**：答案 B —— 丙烯 + Br₂ 光照 → 甲基上取代得 CH₂=CH-CH₂Br（B 给 CH₃CH=CHBr 错）；Y=C₃H₆Br₂ 与足量 KOH 醇溶液共热消去 → 丙炔；Z 链节 -CH(CH₃)-CH₂-。反思：**C—H 键稳定性 乙炔>乙烯>乙烷**（s 成分越多越牢固，乙烷 C—H 光照可取代）。
**类型Ⅲ 例5 共轭二烯**：2-甲基-1,3-丁二烯 + 足量 Br₂，二溴代物 **4 种**（1,2/3,4/1,4 加成；1,4 产物有顺反异构，考虑顺反）
**类型Ⅲ 例6（2024·九省联考）高分子循环利用**：答案 C —— b 生成 a 是加聚（大π键成苯环）；a 链节与 b 分子式相同、H 质量分数相同；共轭三烯二溴代物 4 种（1,2/3,4/1,4/1,6）
**类型Ⅳ 例7 KMnO₄ 氧化推断**：Mr=70 单烯烃 → C₅H₁₀；加 H₂ 得 3 个甲基的烷烃 → 3 种结构；能被氧化生成乙酸的烯烃为 CH₃-C(CH₃)=CH-CH₃ → **2-甲基-2-丁烯**

### 3.2 芳香烃（★★）

- **定义**：含苯环的烃。苯及同系物 CₙH₂ₙ₋₆（n≥6）；其他：苯乙烯、萘、蒽
- **苯的组成结构**：C₆H₆，Ω=4，平面正六边形、12 原子共面；sp² 杂化，键长均等（介于单双键之间），p 轨道垂直环面形成**大 π 键（Π₆⁶）**
- **苯的物理性质**：无色、特殊气味、比水小、不溶水、易挥发、有毒
  - 密度大于水的有机物：含硝基芳香族、酚类、卤代烃（**一氟/一氯代物仍小于水**）
- **苯的化学性质**：能取代（液溴/FeBr₃、浓硝酸/浓硫酸、浓硫酸磺化可逆、酰氯傅克酰基化、卤代烃傅克烷基化）、**难加成**（H₂/Ni→环己烷）、能燃烧（浓黑烟）；**不使酸性 KMnO₄ 褪色**
- **苯的重点实验**：
  - 证明液溴与苯是取代而非加成 → 检验 HBr 生成（石蕊变红或 AgNO₃ 酸化的 AgNO₃ 得 AgBr）；**HBr 中混 Br₂ 需 CCl₄ 洗气（相似相溶）**
  - 溴苯分离提纯：NaOH 洗涤 → 分液（溴苯在下层）→ 蒸馏
  - 硝基苯分离提纯：NaOH 洗涤 → 分液（下层）→ 蒸馏
- **苯的同系物（甲苯为例）**：
  - 加成：与 H₂（与苯类似）
  - 取代：硝化（浓硝酸+浓硫酸，一/二/三硝基，**硝基主要上邻、对位**）；光照 Cl₂ 取代烷基侧链（C₆H₅CH₃+Cl₂→光→C₆H₅CH₂Cl）
  - 氧化：**使酸性 KMnO₄ 褪色**（与苯环相连碳上有 H → 氧化成羧基）；C₇H₈+9O₂→点燃→7CO₂+4H₂O
  - 烷基给电子使苯环更易取代；苯环吸电子使烷基更活泼
- **定位效应**：邻、对位定位基（甲基、羟基、氨基等一般不含 π 键）；间位定位基（硝基、羧基、酰胺基、磺酸基等一般含 π 键）

**类型Ⅰ 例1 苯及同系物 8 判断**（要点）：
- 苯与溴水是萃取褪色，**取代需液溴+FeBr₃**
- 证明苯无单双键交替：**邻位**二溴代物只有一种（间位两种情况下都只有一种）
- C₆H₅CH₃ 与 C₆H₅C(CH₃)₃ 是同系物，但**后者与苯环直接相连的 C 无 H，不能使 KMnO₄ 褪色**
- 异丙苯光照 Cl₂ 取代烷基上 H，一氯代物 2 种（烷基上仅 2 种 H）
**类型Ⅰ 例2 C₆H₆ 多结构**：答案 D —— 只有苯全原子共面；2、3、5 含 C=C 能使溴的 CCl₄ 褪色且能与 H₂ 加成；4 不能加 H₂。反思：**羧基、酯基、酰胺基的 π 键不能与 H₂ 加成**
**类型Ⅱ 例3 芳香烃概念**：答案 D —— 联苯两苯环间单键可旋转，原子"可能"共面非"一定"；等质量 C₆H₅CH=CH₂ 与苯燃烧耗氧相同（最简式相同都是 CH）
**类型Ⅱ 例4（2022·辽宁）苯乙炔**：答案 C —— 苯乙炔分子中**最多 6 个原子共直线**（三键 4 原子共线 + 苯环对位 2 原子延伸），算共直线原子要补上氢、考虑苯环对位原子
**类型Ⅲ 例5 乙炔制备实验**：答案 D —— 电石+水：CaC₂+2H₂O→Ca(OH)₂+HC≡CH↑；**饱和食盐水减慢反应速率**；CuSO₄ 除 H₂S（CuSO₄+H₂S→H₂SO₄+CuS↓）；乙炔密度（26）与空气（28.8）相近，**不能用排空气法**，排水法收集
**类型Ⅲ 例6 溴苯制备实验**：答案 B —— 溴苯为无色液体，褐色来自溶有 Br₂；乙装置 CCl₄ 吸收挥发的 Br₂（相似相溶）以证明取代反应；甲装置长导管导气+冷凝回流

## 模块4 卤代烃（★★）

### 4.1 概念与性质

- **概念**：烃分子中 H 被卤素取代，通式 R—X，官能团为碳卤键 —C—X
- **物理性质**：卤代烃密度一般**大于水**（一氟代物、一氯代物除外）；不溶于水
- **化学性质**：
  - **水解（取代）**：NaOH 水溶液、加热。R-CH₂-X + NaOH →水△→ R-CH₂OH + NaX。**芳卤（卤直接连苯环）难水解**，需高温高压
  - **消去**：NaOH 醇溶液、加热。R-CH₂-CH₂-X + NaOH →乙醇△→ R-CH=CH₂ + NaX + H₂O。**必须有 β-H（且非苯环上 H）**；β-H 种类数决定烯烃种类数；二卤代烷消去可得炔烃（CH₂ClCH₂Cl + 2NaOH →乙醇△→ CH≡CH↑ + 2NaCl + 2H₂O）
- **卤素检验**：水解（NaOH水/△）→ **稀 HNO₃ 酸化（pH<7）** → AgNO₃ → 白 AgCl / 浅黄 AgBr / 黄 AgI。卤代烃非电解质，不能直接电离出 X⁻
- **制取**：①烷烃取代（产物杂，少用）；②烯/炔 + X₂ 加成；③烯 + HX 加成（**工业制氯乙烷用乙烯+HCl 而非乙烷+Cl₂**，产物纯净）；④苯 + Br₂/FeBr₃；⑤醇 + HX →△→ 卤代烃

**例1 判断 8 则**：只用水鉴别己烷/溴乙烷/酒精（√，分层上下与互溶）；除溴乙烷中 Br₂ 用 **Na₂SO₃/NaHSO₃ 还原**而非 NaOH（NaOH 使溴乙烷水解损耗）；氟氯代烷（氟利昂）紫外线分解的 Cl 原子催化破坏臭氧层（√）
**例2 消去只生成一种单烯烃**：答案 A（对称 β-H 等效，产物唯一）；无 β-H 者不能消去
**例3 卤素检验实验**：答案 BC —— A 未酸化，OH⁻ 与 Ag⁺ 生成 Ag₂O 干扰；D 中乙烯与乙醇都能使酸性 KMnO₄ 褪色，应先 NaOH 洗气或改溴的 CCl₄ 检验
**例4 由 CH₃CH₂CH₂Br 制丙-1,2-二醇**：答案 C —— **消去→加成→水解**（单一官能团→邻位双官能团，先消去再加成）
**例5 1,4-环己二醇合成**：消去（②）→加成（③）→消去（④）→1,4-加成（⑤，共轭二烯）→加 H₂（⑥）→水解（⑦）；环己烷二氯取代物 4 种

> 合成规律：增多官能团先消去再加成；消去用 NaOH 醇溶液加热（促进消去抑制水解）。

### 有机分子中基团相互影响的概念建构（苯环活化羟基/羟基活化苯环邻对位/烃基给电对酸性影响） · 对接缺口#43

- **基团相互影响的本质**：有机分子中相邻或共轭的原子团通过诱导效应和共轭效应互相改变各自的电子云密度与反应活性。
- **经典案例建构**：
  - **苯环对羟基的影响**：苯环大 $\pi$ 键与氧原子孤对电子共轭，使 $\mathrm{O-H}$ 键极性增强，苯酚羟基氢具有弱酸性（能与 $\mathrm{NaOH}$ 反应），而乙醇分子中乙基给电子使羟基显极弱酸性（不与 $\mathrm{NaOH}$ 反应）；
  - **羟基/氨基对苯环的影响**：酚羟基（$-\mathrm{OH}$）向苯环给电子，使苯环邻、对位电子云密度显著升高，苯酚与浓溴水反应无需催化剂即可发生三元取代生成 2,4,6-三溴苯酚白色沉淀（苯只能与液溴在 $\mathrm{FeBr_3}$ 催化下一步取代）；
  - **烃基对羧酸酸性的影响**：甲酸（$\mathrm{HCOOH}$）酸性强于乙酸（$\mathrm{CH_3COOH}$），因甲基给电子效应降低了羧基羟基极性；而三氟乙酸（$\mathrm{CF_3COOH}$）因强吸电子基团使酸性大幅增强。

## 模块5 醇和酚（★★★）

### 5.1 醇

- **概念**：-OH 连烃基（脂肪醇）或苯环侧链碳（芳香醇，C₆H₅CH₂OH）；饱和一元醇通式 CₙH₂ₙ₊₁OH；**-OH 直接连苯环的是酚，不是醇**
- **物理性质**：一元脂肪醇密度 < 水；沸点远高于相对分子质量相近的烷烃（**分子间氢键**）；低级醇（C≤3）与水互溶（羟基亲水基、烃基憎水基）
- **化学性质（乙醇为例）**：
  1. **与 Na 置换**：2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑
  2. **消去**：浓 H₂SO₄、170℃ → CH₂=CH₂↑ + H₂O（需 β-H，非苯环 H）
  3. **取代**：①与 HX →△→ C₂H₅X + H₂O；②分子间脱水成醚：2C₂H₅OH →浓H₂SO₄/140℃→ C₂H₅OC₂H₅ + H₂O；③酯化：**酸脱羟基、醇脱氢**
  4. **氧化**：①燃烧；②催化氧化（Cu/Ag、△，**“失氢”**）：2CH₃CH₂OH + O₂ →△/Cu→ 2CH₃CHO + 2H₂O；③酸性 K₂Cr₂O₇（**橙→灰绿**，酒驾检测）：CH₃CH₂OH → CH₃CHO → CH₃COOH；酸性 KMnO₄ 同样氧化成乙酸
- **氧化/消去规律（关键）**：
  - 催化氧化需 **α-H**：2 个 α-H（链端 -CH₂OH）→ 醛；1 个 α-H（-CH(OH)-）→ 酮；无 α-H 不能氧化
  - 酸性 KMnO₄/K₂Cr₂O₇：无 α-H 不能；1 个 α-H → 酮；2 个 α-H → 羧酸；3 个 α-H → CO₂
  - 消去需 **β-H**（非苯环 H）：CH₃OH、无 β-H 者不能消去；两种不等效 β-H 可得两种烯烃
- **卤代烃 vs 醇消去**：都需 β-H、断 β-C-H 键；卤代烃脱 HX（NaOH 醇溶液，NaOH 消耗 HX 促正移）、醇脱 H₂O（浓 H₂SO₄ 吸水促正移）

**例1 醇的用途**：答案 B —— 酒类标注的百分数为**体积分数**（消毒酒精 70%~75% 同）
**例2 判断 8 则**：乙醇（C₂H₆O）与乙醚（C₄H₁₀O）非同分异构体，乙醇与**甲醚**才是官能团异构；分子间脱水与酯化都是取代（断σ成σ）；溴乙烷与乙醇消去条件不同
**例3 乙醇实验**：答案 B —— 钠与乙醇、水均反应生成 H₂，**不能检验乙醇中是否有水**；加生石灰蒸馏可制无水乙醇
**例4 乙醇消去实验**：答案 A —— **三处错误**：浓硫酸倒入乙醇（大密度入小密度）；140℃应改 170℃；产物气体直接通酸性 KMnO₄ 会被乙醇蒸气与副产物 SO₂ 干扰，应先 NaOH 洗气
**例5 C₇H₁₆O 饱和一元醇**：C 消去得两种烯烃；D（链端）催化氧化成醛；B（无 α-H）不能氧化；A、C 催化氧化成酮（2 种）；能褪 KMnO₄ 的 3 种
**例6 C₅H₁₂O**：能与 Na 反应、氧化成醛、浓硫酸下成烯 → 含 -CH₂CH₂OH 或 -CH(CH₃)-CH₂OH 链端 + 丙基/异丙基等 → **3 种**（答案 A）

### 5.2 酚

- **苯酚**：-OH 直接连苯环；无色晶体，**露置空气变粉红色**；常温溶解度不大、>65℃ 与水混溶，易溶于酒精
- **弱酸性（石炭酸）**：C₆H₅OH ⇌ C₆H₅O⁻ + H⁺；酸性 **H₂CO₃ > C₆H₅OH > HCO₃⁻**；不能使指示剂变色；与 NaOH、Na₂CO₃ 反应（无论少量过量都生成 NaHCO₃），**不与 NaHCO₃ 反应、不能产生 CO₂**
- **与浓溴水**：2,4,6-三溴苯酚**白色沉淀**（羟基邻对位取代，无需催化剂）；苯与溴水是萃取不反应
- **显色反应**：FeCl₃ 溶液显**紫色**（酚类特征）
- **缩聚**：苯酚 + 甲醛 → 酚醛树脂（酸催化→线型，碱催化→网状）
- **氧化**：易被空气氧化、燃烧、被酸性 KMnO₄ 氧化
- **卤素单质总结**：Cl₂（气）光照取代烷基；Br₂（气）光照取代烷基 /（液）FeBr₃ 取代苯基 /（水溶液）C=C 加成、醛基氧化、酚邻对位取代 /（CCl₄）C=C 加成

**例1 判断 8 则**：**除去苯中苯酚用 NaOH 溶液+分液**（三溴苯酚溶于苯，不能用浓溴水除杂）；苯酚可与 Na₂CO₃ 反应（不能与 NaHCO₃）；苯酚有毒但稀溶液可作防腐消毒剂；皮肤沾苯酚用酒精冲洗
**例2 白藜芦醇**：答案 D —— 与浓溴水：2 个苯环的酚羟基邻对位取代（共 4H×2? 此处各占 1 个邻位 + C=C 加成）→ 6 mol Br₂；与 H₂：2 苯环 + 1 C=C → 7 mol H₂
**例3 苯酚弱酸性方程式**：答案 D（C₆H₅OH + Na₂CO₃ → C₆H₅ONa + NaHCO₃，由强制弱）
**例4 基团相互影响**：答案 ABCDEFG 全部正确（羟基活化苯环邻对位；苯环使酚羟基更活泼；甲基使苯环邻对位活化→TNT；苯环使甲基被 KMnO₄ 氧化；吸电子基 F/Cl 增强羧酸酸性：CF₃COOH > CCl₃COOH > CHCl₂COOH > CH₂ClCOOH > CH₃COOH）

## 模块6 醛和酮（★★★）

### 6.1 概念与性质

- **醛** RCHO（饱和一元醛 CₙH₂ₙO，n≥1）；**酮**（羰基连两个烃基，饱和一元酮 CₙH₂ₙO，n≥3）；丙醛与丙酮互为同分异构体
- **常见醛酮**：甲醛（蚁醛）HCHO 气体、刺激性气味、易溶于水；乙醛液体与水任意比互溶；丙酮液体特殊气味与水互溶；**甲醛是标况下唯一气态的烃的含氧衍生物**；福尔马林 = 35%~40% **甲醛**水溶液（浸制标本）
- **化学性质**：
  1. **氧化（醛基“得氧”）**：
     - 银镜反应：CH₃CHO + 2[Ag(NH₃)₂]OH →△→ CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O（口诀 **“醛银氨、一二三、醛基变成羧酸铵”**；试管 Ag 用稀硝酸洗）
     - 与新制 Cu(OH)₂：CH₃CHO + 2Cu(OH)₂ + NaOH →△→ CH₃COONa + Cu₂O↓ + 3H₂O（**NaOH 必须写**；生成砖红色 Cu₂O）
  2. **还原（加氢）**：RCHO + H₂ →催化剂△→ RCH₂OH；醛、酮可被 H₂、NaBH₄、LiAlH₄ 还原
  3. **羰基与极性分子加成**
- **醛的计算（高频）**：1 mol 醛基 ~ 2 mol Ag ~ 2 mol Cu(OH)₂ ~ 1 mol Cu₂O；**甲醛相当于 2 个醛基**：1 mol HCHO ~ 4 mol Ag（HCHO + 4[Ag(NH₃)₂]OH → (NH₄)₂CO₃ + 4Ag↓ + 6NH₃ + 2H₂O）；二元醛 1 mol ~ 4 mol Ag。原理：-CHO→-COOH 升高 2 价，Ag⁺/Cu(OH)₂ 各降 1 价
- **氧化反应总结表**：烷（燃烧，既又）、烯（O₃/Zn→醛酮；KMnO₄→酮酸CO₂，得氧/既又）、苯（燃烧）、甲苯（KMnO₄→苯甲酸）、醇（Cu/O₂ 失氢→醛酮；KMnO₄→酮酸）、醛（银氨/Cu(OH)₂ 得氧→羧酸）
- **连续氧化链**：醇 失H→ 醛 得O→ 酸（有机合成核心）

**例1 判断 8 则**：醛基是 -CHO 不是 -COH；甲醛是氢原子连醛基（HCHO），乙醛才是甲基连醛基；乙醛与环氧乙烷同分异构；丙醛与丙酮同分异构；丙烯醛所有原子**可能**共面（C 均 sp²，单键可旋转）

## 模块7 羧酸与羧酸衍生物（★★★★）

### 7.1 羧酸

- **通式**：饱和一元羧酸 CₙH₂ₙO₂（n≥1）/ R-COOH；官能团 -COOH
- **重要羧酸**：甲酸（蚁酸，**既有羧基又有醛基**→可银镜、与 H₂ 加成）、乙酸（醋酸，酸性>碳酸）、乙二酸（草酸，中强酸、还原剂使 KMnO₄ 褪色、K₁=5.4×10⁻²/K₂=5.4×10⁻⁵）、苯甲酸（安息香酸，易升华，钠盐防腐剂）
- **物理性质**：C≤4 羧酸与水互溶；**沸点比相应醇高**（羧酸分子间氢键更强）
- **化学性质**：①弱酸性 RCOOH⇌RCOO⁻+H⁺；②酯化（**酸脱羟基、醇脱氢**，可逆，浓 H₂SO₄ 催化+吸水）；③**羧基/酯基/酰胺基不能与 H₂ 加成**（醛基、酮羰基、氰基可）；④LiAlH₄ 还原羧酸→醇；⑤α-H 取代（→卤代酸→氨基酸/羟基酸）
- **羟基活性**：-COOH（Na/NaOH/Na₂CO₃/NaHCO₃ 全 √）、酚-OH（除 NaHCO₃ 外 √）、醇-OH（仅 Na √）；**只有 -COOH 能与碳酸盐/碳酸氢盐放 CO₂**
- **酸性比较实验**：醋酸>碳酸>苯酚（醋酸+Na₂CO₃ 产气→除醋酸蒸汽→苯酚钠变浑浊）
- **H₂ 加成定量**：C=C(1)、C≡C(2)、苯环(3)、醛基(1)、酮羰基(1)、氰基(2)；甲酸/甲酸酯/甲酰胺因含醛基可与 H₂ 加成
- **KMnO₄ 褪色口诀**：**"纯粉犬本系稀缺"**（醇/酚/醛/苯的同系物/烯/炔）；苯本身不褪色；与苯环相连碳无 H 不褪色

**例1 判断 7 则**：HCOOH 沸点>乙醇>丙烷（√）；HCOO- 是甲酸酯非羧基；石炭酸（苯酚）非羧酸；羧基不与 H₂ 加成；酯化断 C-O 与 O-H；酯化可逆（<1mol）；甲酸可银镜、乙酸不可
**例2 官能团反应计量**：答案 B —— 1mol 该物（-COOH+醇-OH+酚-OH）耗 Na 3mol、NaOH 2mol（酚+羧）、NaHCO₃ 1mol（仅羧基）；活泼性 羧基>酚>醇
**例3（2021·河北·双选）番木鳖酸**：答案 BC —— 1 个 -COOH→22.4L CO₂；Na:NaOH=6:1（非 5:1）；仅 1 个 C=C→1mol H₂（羧基不加 H₂）；可被 KMnO₄ 氧化
**例4 乙酸乙酯制备**：混合顺序乙醇→浓硫酸→乙酸（大密度入小密度、易挥发最后加）；饱和 Na₂CO₃ 中和乙酸/溶解乙醇/降低酯溶解度；导管口不浸入防倒吸；浓硫酸催化剂+吸水剂；酯在上层（密度<水）；分液分离
**例5 酯化反应机理**：②加成、④消去、⑤非消去（答案 B）；分析机理题从选项入手选步骤少的
**例6 草酸分解与 CO 检验**：B 装置冷凝草酸防草酸钙干扰 CO₂ 检验；CO 检验顺序 F(D 除 CO₂、G 干燥、H CuO、D 检验、I 排水收集)，现象 H 中黑变红、前 D 无现象、后 D 变浑浊；草酸酸性>碳酸（NaHCO₃ 冒泡）；二元酸证明：NaOH 滴定 n 比 1:2 或 KHC₂O₄ 溶液 pH<7

### 7.2 酯

- **通式** RCOOR'，官能团 -COO-；低级酯芳香液体、密度<水、难溶水
- **水解**：酸催化（可逆，生成酸+醇/酚）；碱催化（**不可逆**，生成羧酸盐+醇；碱中和羧酸促正移）；水解程度碱>酸
- **酯化 vs 水解**：断键相反（酯化酸脱羟基醇脱氢；水解单键断、碳氧成羧基、单氧成羟基）；均为取代反应
- **醇交换**（酯+醇交换烃氧基）、**氨解**（酯+胺→酰胺）
- **消耗 NaOH 总结**：直接——-COOH(1)、酚-OH(1)；间接——酯基(1或2)、C-X(1或2)、酰胺基(1)；**水解产物含酚羟基时 1 份官能团耗 2 份 NaOH**
- **Br₂ 总结**：气态光照取代烷基/液态 FeBr₃ 取代苯环/溴水取代酚邻对位/加成 C=C(溴水或 CCl₄)/氧化醛基

**例2（2024·浙江1月）酯水解历程**：答案 D —— OH⁻ 进攻酯基 C^δ+；吸电子基越多水解越快（FCH₂COOR>ClCH₂COOR，类比羧酸酸性）；醇中 O 全部来自原酯基 C-O 的 O，故与 ¹⁸OH⁻ 反应产物不变
**例3（2021·辽宁）小分子胶水**：答案 B —— 环内酚酯水解生成酚羟基+羧基→1mol 酯基耗 2mol NaOH；含苯环+C=C+单键相连→碳原子"可能"共面非"一定"
**例4 C₃H₆O₂ 四物质鉴别**：X=CH₃CH₂COOH（中和）、Y=CH₃CH(OH)CHO（羟基醛）、Z=HCOOCH₂CH₃（甲酸酯，水解+银镜）、W=CH₃COOCH₃。要点：**2 个 O 既能银镜又能水解→必含甲酸酯 H-C(=O)-O-**
**例5（2024·东北三省）自催化**：答案 C —— X 含酯基+酰胺基均水解；Y 亚氨基与 HCl 成盐溶于水；Z 全 sp²；自催化"慢快慢"（KMnO₄+草酸，Mn²⁺ 催化）
**例6（2024·山东）阿魏萜宁**：答案 B —— 酚羟基与 Na₂CO₃；醇羟基 3 种 β-H→消去产物 3 种（非 2）；酸水解产物均可缩聚（二元醇羟基/羧基+酚羟基→聚酯）；C=C 加成+酚邻位取代

### 7.3 油脂

- **结构**：高级脂肪酸甘油三酯，官能团酯基；软脂酸 C₁₅H₃₁COOH、硬脂酸 C₁₇H₃₅COOH、油酸 C₁₇H₃₃COOH（1 个 C=C）、亚油酸 C₁₇H₃₁COOH（2 个 C=C）
- **分类**：液态油（不饱和多）/固态脂肪（饱和多）；天然油脂是**混合物**无固定熔沸点
- **化学性质**：①氢化（硬化）：油+H₂→脂肪，属还原反应；②水解：酸（可逆）→高级脂肪酸+甘油、碱（皂化，不可逆）→高级脂肪酸盐+甘油
- **肥皂制取**：皂化→加食盐**盐析**（Na⁺ 同离子效应降低高级脂肪酸钠溶解度）→上层高级脂肪酸钠、下层甘油+食盐水
- **油脂/酯/矿物油**：油脂和酯可皂化，矿物油（烃）不能水解；鉴别加含酚酞 NaOH 加热，红色变浅且不再分层为油脂/酯

**例1 判断 9 则**：油脂是高级脂肪酸甘油酯（非高级脂肪酸）；油脂相对分子质量<10000 非高分子；矿物油是烃不是油脂；油脂/蛋白质水解产物均含电解质
**例2 地沟油 vs 矿物油**：答案 B —— 加足量 NaOH 共热，不分层为地沟油（皂化产物溶于水）；矿物油分层

### 7.4 胺与酰胺

- **胺**：R-NH₂（氨基）；碱性（N 孤电子对与 H⁺ 配位，类比 NH₃）；与羧酸取代生成酰胺；**胺不能水解**
- **酰胺**：R-CONH₂（酰胺基，C 为 sp²）；水解：酸→羧酸+**铵盐**（无氨气）、碱→羧酸盐+**氨气**；N,N-二甲基甲酰胺（DMF）是优良溶剂

**例1 判断 6 则**：胺不水解、酰胺水解；酰胺基碳 sp²；酸水解不逸出氨气（强酸不生成碱）
**例2（2024·甘肃）曲美托嗪**：答案 A —— I（酚羟基+羧基）→II（醚键+羧基）官能团不同，非同系物（虽相差 3CH₂）；II 含羧基与 NaHCO₃ 反应
**例3（2023·福建）CADD522**：答案 B —— 酰胺基可水解；**4 个手性碳**（非 2）；C=C 使 Br₂ 的 CCl₄ 褪色；sp²+sp³ 杂化

## 模块8 生物大分子

### 8.1 糖类

- **分类**：单糖（葡萄糖/果糖 C₆H₁₂O₆，不能水解）；二糖（蔗糖/麦芽糖 C₁₂H₂₂O₁₁，水解得 2 分子单糖）；多糖（淀粉/纤维素 (C₆H₁₀O₅)ₙ，天然高分子）
- **葡萄糖**：多羟基醛（五羟基己醛），与果糖（多羟基酮）互称同分异构体
- **还原糖**：含醛基或可互变出醛基的糖（葡萄糖、果糖、麦芽糖）能发生银镜反应/与新制 Cu(OH)₂ 反应；蔗糖、淀粉、纤维素非还原糖
- **判断奇偶性**：由分子式快速判断糖类结构（C 数、H:O 比例），苯环/羟基数目题用此先缩放分子式
- **淀粉水解检验三关键点**：①催化剂稀 H₂SO₄、加热；②水解后**先加 NaOH 中和至碱性**；③再加银氨溶液（水浴）或新制 Cu(OH)₂（加热）检验葡萄糖

**例1（2024·安徽）D-乙酰氨基葡萄糖**：答案 B —— 分子含醛基+氨基+羟基，可发生氧化、取代反应
**例2 还原糖判断**：葡萄糖/果糖/麦芽糖能发生银镜反应，蔗糖/淀粉/纤维素不能；单糖、二糖与多糖水解归属

### 8.2 蛋白质与核酸

- **α-氨基酸**：R-CH(NH₂)-COOH；**两性**（-NH₂ 与酸、-COOH 与碱反应成盐），可成内盐
- **成肽**：氨基酸间脱水缩合成 **肽键 -CO-NH-**；**二肽计数**：n 种氨基酸任取 2 个按序排列 → n + 2Cₙ² 种（3 种氨基酸 → C₃¹ + 2C₃² = **9** 种）
- **水解找氨基酸**："找接口断肽键（C-N 键），C 补 -OH、N 补 -H"，还原回氨基、羧基
- **盐析 vs 变性**：盐析（加浓 (NH₄)₂SO₄/Na₂SO₄）**可逆、物理变化**不破坏结构；变性（加热/强酸强碱/重金属盐/紫外线/甲醛）**不可逆、化学变化**
- **检验**：浓硝酸微热显黄色（蛋白质含苯环）；灼烧有烧焦羽毛气味
- **酶**：绝大多数是蛋白质；高效性、专一性、温和条件
- **核酸**：磷酸+戊糖+碱基 → 核苷酸 → 核酸；DNA 双螺旋，碱基对间靠**氢键**（A=T、G≡C，"爱舔鸡翅"）；RNA 含核糖、U 代替 T（A=U）

**例3 二肽种类**：3 种氨基酸任选 2 个排列 → 9 种二肽（顺序不同算不同）
**例4 水解找氨基酸**：断肽键、C 补羟 N 补氢，把多肽还原为氨基酸结构
**例5（2024·北京）核酸判断**：核酸可看作磷酸+戊糖+碱基结合而成 ✓；DNA 双链碱基对间靠氢键 ✓
**例6（2024·湖南）核酸片段**：答案 A —— DNA 与 RNA 戊糖（脱氧核糖/核糖）和碱基（T/U）组成不同，不可简单互相替换

## 模块9 合成高分子

### 9.1 概念与分类

- **单体 / 链节(重复结构单元) / 聚合度 n**（鲁科版定义不同：聚合度=反应掉的单体数；本书采用人教/苏教/沪科版定义）；聚合度越大，平均相对分子质量越大
- **加聚**：单体含不饱和键（C=C/C≡C），断 π 键，无小分子生成；产物无端基
- **缩聚**：双官能团单体脱去小分子（H₂O 等），产物**有端基**，链节含酯基/酰胺基/酚醛结构
- **线型高分子**（热塑性：加热先熔化再燃烧，如聚乙烯）；**网状高分子**（热固性：加热不熔化只燃烧，如酚醛树脂）；单体≥3 个接口 → 网状结构
- **加聚书写口诀**：单烯烃"断 π 键、键分两端、加括号写 n"；共轭二烯烃"单变双、双变单、破两头移中间"（1,4-加聚，注意顺反异构）；2 种单体"π 键打开中间相连"
- **缩聚书写**：端基必须写出；1 种单体脱去 (n-1) 个小分子、2 种单体脱去 (2n-1) 个（酸脱羟基醇脱氢）
- **聚合度计算**：加聚 M = 链节式量×n；缩聚 M = 链节式量×n + 端基小分子式量 = 单体式量×n − 端基小分子式量×(n−1) 或 (2n−1)
- **单体推断**：无端基、主链全碳 → 加聚（"半键回归"：单键变双键；主链双键"见双键 4 个碳、无双键 2 个碳"；双键以 = 为中心切 4 碳，其余隔一键断一键）；有端基、主链含 O/N（C-O、C-N、酚羟基）→ 缩聚（去中括号和 n 即单体；C-O 断开→羧酸+醇 C=O 补 -OH、O 加 H；C-N 断开→氨基酸或二酸+二胺；含酚羟基→苯酚+醛）

### 9.2 经典例题

**例1 加聚/缩聚方程式书写 6 则**：(1) 含 C=C 单体加聚，取代基（甲基/苯基）写主链；(2) 顺丁橡胶：1,3-丁二烯 1,4-加聚，顺式产物相同基团在双键同侧；(3) 双官能团氨基酸 → 缩聚成聚酰胺，1 种单体脱 (n-1) H₂O；(4) C₆H₅CH₂COOH（含羟基+羧基）→ 聚酯，(n-1) H₂O；(5) 涤纶（对苯二甲酸+乙二醇）缩聚，2 种单体脱 (2n-1) H₂O；(6) 苯酚+甲醛 → 酚醛树脂（线型），(n-1) H₂O
**例2 单体推断 6 则**：(1) 主链 2 碳无杂原子 → 丙烯酸乙酯 CH₂=CH-COOC₂H₅；(2) 主链含双键"见双键 4 碳" → CH₂=C(CH₃)-CH=CH₂ + CH₃-CH=CH₂ + CH₂=CH₂；(3) 三种单体共聚、链节含双键 → 每 2 碳断开向内闭合得 2-丁烯腈 CH₃CH=CHCN、苯乙炔 C₆H₅-C≡CH、苯乙烯；(4) H[O-R]ₙOH 一种单体缩聚 → 2-羟基丁酸 HO-CH(C₂H₅)-COOH；(5) 链节含 C(=O)-NH → 对苯二甲酸 HOOC-C₆H₅-COOH + 苯二胺 H₂N-C₆H₅-NH₂；(6) 链节含酚羟基 → 苯酚 + HCHO + 苯胺（先加成后缩聚，类似脲醛树脂）
**例3 聚合度（感光性高分子）**：链节 C₁₁H₁₀O₂ 式量 174，M=16530 → n = 16530/174 = **95**
**例4 聚合度（涤纶）**：链节 C₁₀H₈O₄ 式量 192，n=102 → M = 192×102 + 18（端基 H₂O）= **19602**
**例5（2024·河北）高分子材料判断**：答案 **B** —— 聚四氟乙烯 C-F 键长小键能大、C-C 非极性难断，热稳定性好不易分解；A 线型热塑性 ✓、C 尼龙 66 = 己二酸+己二胺缩聚 ✓、D 有机玻璃 = 聚甲基丙烯酸甲酯加聚 ✓
**例6（2024·全国甲卷）聚乳酸 PLA 回收**：答案 **C** —— MP 同分异构体含羧基仅**2 种**（C₄H₈O₂：羧基占 1C1O₂ 后剩 3 个饱和碳仅 C-C-C 一种骨架、2 种等效氢，羧基 2 个位置）；A PLA 为聚酯碱性水解降解 ✓、B MP 丙酸甲酯 ✓（酯名=酸名+醇名，断 C-O 补羟基/氢）、D MMA 加聚 ✓

## 模块10 原子共面、共线问题（★★★★）

### 10.1 常见简单分子结构记法

| 分子 | 杂化 | 构型 | 关键结论 |
|------|------|------|----------|
| 甲烷 | sp³ | 正四面体 | 有 sp³ 杂化 C/N → 所有原子不可能全部共面 |
| 氨气 | sp³ | 三角锥 | 同上 |
| 环己烷 | sp³ | 船式/椅式 | 非平面 |
| 乙烯 | sp² | 平面形 | (CH₃)₂C=C(CH₃)₂ 所有 C 一定共面 |
| 乙炔 | sp | 直线形 | CH₃-C≡C-CH₃ 所有 C 一定共线 |
| 苯 | sp² | 正六边形 | 与苯环直接相连的 C 一定与该苯环共面；对位 2C+2H 共线 |
| 甲醛 | sp² | 平面三角形 | 丙酮的 C、O 一定全共面 |

**面与面关系**：以 σ 键（单键）相连可旋转 → 所有原子**可能**全共面（如联苯至少 14 原子共面）；以 π 键相连不可旋转 → **一定**全共面（如萘、蒽、菲）；直线与平面共用 2 个原子 → 直线从属于该平面（如苯乙炔全共面）

### 10.2 判断方法

- **共线**：画出体现真实键角的结构式（补上省略的 H），直接数最多共线原子
- **共面"至少"**：一定共面的原子数（苯环骨架 + 与苯环直接相连原子及其延伸）
- **共面"最多"**：所有原子 − 一定不共面原子（"减法"：sp³ 杂化 C 减 2 个原子、sp³ N 减 1 个原子）
- 勿忘结构简式/键线式中省略的 H 原子

### 10.3 经典例题

**例1 所有原子可能共面**：答案 **D** —— 1,3-丁二烯（两个 C=C 平面靠 C-C 单键旋转可共面）；A 甲苯/B 乙烷/C 丙炔均含 sp³ 甲基排除
**例2 所有 C 不可能全共面**：答案 **D** —— 异丙基苯（"Y 形碳架"，最多 8 个碳共面）；对二甲苯 8C 一定共面 ✓、丙烷 3C 不共线但确定一平面 ✓、苯乙炔直线属平面 ✓
**例3 C₆H₅-CH=CH-C≡C-CH-CH₃ 综合填空**：(1) 全原子共面 ×（甲基 sp³）；(2) 全 C 共面 ×（Y 形碳架，1~4 号碳最多 3 个共面）；(3) 一定共线 4 个（苯环对位原子或三键轴上 4 个）；(4) 至少 12 个共面（苯环+直接相连原子）；(5) 最多 **21** 个（30−2−3−4：甲基 2H、3 号碳 2H+支链 H、4 号碳甲基 4 原子）
**【反思】**：审题区分：所有原子/所有碳原子；共线/共面；至少/最多；一定/可能/一定不

### 必修烷烃同分异构体系统书写（减碳对称法与等效氢判断） · 对接缺口#20

- **烷烃同分异构体书写规则（减碳对称法）**：主链由长到短，支链由整到散，位置由心到边，排布避免重排。
- **丁烷与戊烷标准异构**：
  - 丁烷（$\mathrm{C_4H_{10}}$，2种）：正丁烷（$\mathrm{CH_3CH_2CH_2CH_3}$，2种等效氢）、异丁烷（$\mathrm{CH(CH_3)_3}$，2种等效氢）；
  - 戊烷（$\mathrm{C_5H_{12}}$，3种）：正戊烷（3种等效氢）、异戊烷（$\mathrm{CH_3CH(CH_3)CH_2CH_3}$，4种等效氢）、新戊烷（$\mathrm{C(CH_3)_4}$，1种等效氢，一氯代物仅1种）。

## 模块11 同分异构体

### 11.1 不饱和度 Ω（★★）

- **定义**：与同碳数链状烷烃相比少的 H 原子数÷2（缺氢指数）；氧不影响 Ω；**卤原子当 H 看待**；**含氮化合物扣除 N 引入的 H**（Ω = [(2n+2)−(现有H−N数)]/2）
- **Ω 与结构**：1 = 1 双键/1 环；2 = 1 三键、2 双键、2 环或环+双键；4 = 苯环（≥4 一般有苯环）；**硝基 -NO₂ 的 Ω = 1**
- **环的特殊情况**：三个以上环共用两条以上边，数出的 Ω 要减 1（如降冰片 3 个环 Ω=2，C₇H₁₂）
- **运用**：①判分子式正误（数结构与算 Ω 对照）；②写分子式（数非 H 原子 → 数 Ω → 算 H，苯环多时直接数 H 更快）；③推同分异构体可能结构

**例1 异山梨醇 C₆H₈O₄**：由分子式算 Ω=3，但结构仅 2 个环 Ω=2 → 应为 C₆H₁₀O₄，答案 ×
**例2 写分子式**：C₁₁、N₁、O₃，4 个 π 键 Ω=4 → Ω=[(2×11+2)−(m−1)]/2=4，m=17 → C₁₁H₁₇NO₃
**例3 C₁₃H₂₀OCl₂**：Ω=(28−22)/2=**3**，芳香族化合物需苯环 Ω=4 → 不存在

### 11.2 同分异构体分类与书写顺序（★★★）

- **分类**：构造异构（碳架/位置/官能团异构）+ 立体异构（顺反、对映/手性）
- **书写顺序**：先官能团类型异构 → 再碳架异构 → 最后位置异构
- **官能团异构检索表**：CₙH₂ₙ（Ω1）烯烃/环烷烃；CₙH₂ₙ₋₂（Ω2）炔烃/二烯烃/环烯烃；CₙH₂ₙ₊₂O（Ω0）饱和一元醇/醚；CₙH₂ₙO（Ω1）饱和醛/酮/烯醇；CₙH₂ₙO₂（Ω1）饱和一元羧酸/酯/羟基醛
- **烷烃碳架书写五步**：主链由长到短 → 支链由整到散 → 位置由心到边（对称分析）→ 两个基"同、邻、间" → 取代基不能到端（甲基不上端、乙基不上 2 号）
- **常见数目**：烷烃异构数 C₄=2、C₅=3、C₆=5、C₇=9；烷基数（=等效氢数）C₃=2、C₄=4、C₅=8；烷基数 = 相同碳数一卤代物异构数
- **单烯烃**：需同时考虑环烷烃（类型异构）、双键位置异构、碳架异构（C≥4）、顺反异构

### 11.3 卤代烃与多卤代物

- **一卤代物数 = 等效氢数 = 烷基数**（C₃ 2、C₄ 4、C₅ 8）
- **二卤代物**：构建碳架→对称分析→两取代基按"同、邻、间"放入（链烃禁用定一移一易重复；稠环二卤代物用定一移一却极方便）；两取代基不同且连不对称碳有 2 种连接
- **常见数**：C₃H₆Br₂=4、C₃H₆BrCl=5、C₄H₈Cl₂=9、C₄H₈ClBr=12
- **多卤代物用"换元法"**：CₙHₐX_b 与 CₙH_bX_a 异构数相同（C₄HCl₉ ↔ C₄H₉Cl = 4）；熟记烷基数 1、1、2、4、8

**例1 常识辨析 6 则**：C₄H₁₀ 不一定纯净物 ×；C₃H₆ 使溴的CCl₄褪色必为丙烯 √；C₄H₈ 与 C₅H₁₀ 不一定是同系物 ×（烯/环烷）；C₆H₅COOH 与 C₆H₅OOCH 官能团异构 √；2-丁醇与 1-丁醇 位置异构 √；同分异构体化学性质可相似也可差异大 √（甲醚vs乙醇）
**例4 C₅H₁₀ 总异构数**：**10** —— 烯烃 5（戊烷三碳架：Ⅰ2 种+Ⅱ3 种+Ⅲ0 种，新戊烷碳架中心碳不能成双键）+ 环烷烃 5（环戊烷/甲基环丁烷/乙基环丙烷/1,1-二甲环丙烷/1,2-二甲环丙烷）；考虑顺反则 2-丁烯类有顺反

### 11.4 芳香族同分异构体（★★★★）

- **一取代**：只侧链异构（丁基 4 种侧链）；**二取代**：位置异构(邻间对 3) × 侧链异构；**苯环二取代物总数为 3 的倍数**
- **三取代结论（必记）**：三个相同取代基 = 3 种（1,2,3 / 1,2,4 / 1,3,5）；"两同一异" = 6 种；"三相异" = 10 种
- **四/五支链**：换元法（把 H 看作取代基）
- **例1 C₁₀H₁₄ 芳香烃 = 22**（一取代丁基4 + 二取代9 + 三取代两同一异6 + 四取代4甲基3）
- **例2 C₇H₆Cl₂ 芳香族 = 10**（一取代1 + 二取代3 + 三取代6）
- **稠环/联苯二氯代物（画对称轴+定一移一）**：萘 = 10、蒽 = 15（三组等效H 9+5+1）；联苯 = 12（单键可旋转，对侧上下对称）

### 11.5 烃的衍生物（★★★★）

- **醇/醚（插氧法）**：C₄H₁₀O = 7（醇4 + 醚3）；饱和一元醇数 = 烷基数
- **醛/酮（插C=O法）**：C₄H₈O 含羰基 = 3；饱和一元醛数 = 烷基数
- **羧酸/酯（分类组合法）**：R₁COOR₂ 中 R₁ 可为 H（甲酸酯），**R₂ 必不为 H**；不对称 C-C 插入 2 种、对称 1 种（插-C-C-法）
- **关键数**：C₄H₈O₂ 与NaOH反应 = 6（2酸+4酯）；C₅H₁₀O₂ = 13（4酸+9酯）；C₅H₈O₂ 含-COOH+C=C = 8

**例2 (2023·湖北) C₅H₁₂O 醇 = 7 种**；NMR 峰面积 9:2:1 → (CH₃)₃CCH₂OH（无其它碳）
**例4 C₅H₈O₂ 含羧基+碳碳双键 = 8 种**（2 种酸碳架 × 4 种烯位置）

### 11.6 限定条件下同分异构体（★★★★★）

**解题三步**：① 列组成算 Ω（与 C 饱和 H 数差 + 苯环4 + 双键1 + 环1）→ ② 提取官能团/结构信息 → ③ 组合讨论（结合芳香族取代基数结论）

**性质→官能团对应表（必记核心）**：
| 试剂/反应 | 指示官能团 |
|---|---|
| Na | -OH / -COOH |
| NaOH | COOH(1)、酚OH(1)、酯基(1)、酚酯(2)、酰胺(1)、卤代烃(1-2) |
| Na₂CO₃ | 酚OH / COOH（放CO₂则必含COOH） |
| NaHCO₃ | 仅 COOH |
| 溴水 | C=C(1Br₂)、C≡C(2Br₂)、醛基(1Br₂)、酚OH邻对位H |
| FeCl₃ 显色 | 苯酚（必含苯环） |
| 银镜/新制Cu(OH)₂ | 醛基（1醛基 : 2Ag；1醛基 : 1Cu₂O） |
| 水解后银镜 | 优先甲酸酯 HCOOR |
| H₂加成 | C=C(1)、C≡C(2)、醛酮羰基(1)；羧基/酯基/酰胺不反应 |

**NMR/等效氢**：峰数 = 等效氢种类数；面积比 3/6/9 → 甲基（6 = 2 对称甲基/同碳两甲基，9 = 叔丁基/3 对称甲基）；优先构造对称结构

**例 (2023·全国甲卷)**：苯环+硝基(-NO₂)+Cl 芳香类 = **16 种**；NMR 2:2:1:1 → 对位（对称）
**例 (2023·河北)**：3 组峰 3:2、含 C=O 无 OH、水解酸化后 FeCl₃ 显色 → 酚酯：CH₃O-C(=O)-O-C₆H₄-O-C(=O)-OCH₃（对位）。酚酯水解产物含酚羟基，是命题高频特征
**例 (2022·湖南)**：C₄H₆O 能银镜 + 具立体异构（顺反）= **5**（含醛基+双键 3 + 环醛 2）；NMR 4:1:1 → 环丙甲醛
**例 (2023·全国新课标)**：苯环+3 个甲基（C₁₀H₁₄O）+手性碳 = **9 种**；6 组峰 3:3:3:2:2:1
**例 (2022·浙江6月)**：含 N 环 + 3 种等效H + 含 N-H：四元环 2 + 五元环 2 = **4**；C₄H₁₁N 胺 = 8
**例 (含N/吡啶)**：酰胺 + F + Br 间位 = **19**；吡啶（含N芳环）6 种
**手性碳**：连 4 个不同原子/基团的 sp³ 碳；对映异构体通常不计数
**顺反异构条件**：双键两端各连两个不同基团（同侧顺、异侧反）
**芳胺碱性**：烃基推电子多→碱强：(C₂H₅)₂NH > C₂H₅NH₂ > CH₃NH₂ > NH₃；吸电子基（苯基/卤素/NO₂）→碱弱：NH₃ > 苯胺 > 对硝基苯胺

### 常见有机官能团检验的系统化实验方案（检验试剂 / 特征现象 / 伴随干扰排除） · 对接缺口#45

- **碳碳双键/三键**：酸性 $\mathrm{KMnO_4}$ 溶液（褪色）或溴的 $\mathrm{CCl_4}$ 溶液（褪色，排除醇/醛还原性干扰）；
- **卤代烃（$-\mathrm{X}$）**：先加 $\mathrm{NaOH}$ 水溶液加热水解，**必须先加过量稀 $\mathrm{HNO_3}$ 中和碱液酸化**，再滴加 $\mathrm{AgNO_3}$ 溶液（白色 $\mathrm{AgCl}$ / 浅黄色 $\mathrm{AgBr}$ / 黄色 $\mathrm{AgI}$）；
- **酚羟基**：滴加浓溴水（生成 2,4,6-三溴苯酚白色沉淀）或 $\mathrm{FeCl_3}$ 溶液（显特征紫色）；
- **醛基（$-\mathrm{CHO}$）**：银氨溶液（水浴加热生成光亮银镜）或新制 $\mathrm{Cu(OH)_2}$ 悬浊液（碱性条件下加热产生砖红色 $\mathrm{Cu_2O}$ 沉淀）；
- **羧基（$-\mathrm{COOH}$）**：加 $\mathrm{NaHCO_3}$ 溶液产生无色气体 $\mathrm{CO_2}$（排除酚羟基干扰，酚不与 $\mathrm{NaHCO_3}$ 反应）。

## 模块12 有机合成与推断（★★★★★）

> 全章命题主战场：信息给予题 + 高分子/药物的多步合成路线推断；解题核心是**官能团性质表 + 碳架变化 + 断键/机理识别**

### 12.1 必背：官能团性质速查

| 官能团 | 代表物 | 关键反应 |
|---|---|---|
| -C=C- / -C≡C- | 烯/炔 | 加成（H₂/X₂/HX/H₂O）、氧化（KMnO₄褪色）、加聚 |
| -X | 卤代烃 | NaOH水溶液→醇（取代）、NaOH醇溶液→烯（消去） |
| -OH | 醇 | 氧化（CuO/活O₂→醛酮）、酯化、与Na、消去（浓H₂SO₄） |
| -OH(酚) | 苯酚 | 弱酸性、FeCl₃显色、溴水白色沉淀、酯化（酚酯） |
| -CHO | 醛 | 银镜、新制Cu(OH)₂、卤仿？（羰基α-H） |

### 12.2 官能团引入与保护
| 欲引入 | 常用方法 |
|---|---|
| -OH | 烯烃水化、卤代烃水解、醛酮加氢、酯水解 |
| -X | 烷/芳烃光照卤代、烯加成HX、醇与SOCL₂或PX₃（不控制产物） |
| -CHO | 醛：烯臭氧化、醇氧化（轻柔氧化） |
| -COOH | 醛氧化、醇催化氧化、烯/苯环侧链KMnO₄氧化 |
| -COOR | 酯化（酸+醇，浓H₂SO₄催化） |
| -CONH- | 酰化（酸酐/酰氯 + 胺） |
| 保护 | 氨基保护（Boc、苄基）防止副反应：先成酰胺暂封，最后水解脱保护 |

**氧化还原判断**：断σ成π = 氧化（失H增O）；断π成σ = 还原（得H去O）。NaBH₄/LiAlH₄ 为"万能还原剂"（-NO₂→-NH₂、-COOH→-CH₂OH、-C=O→-CHOH）。NaClO 强氧化剂（醇失氢氧化）。

### 12.3 碳架变化（增减成环）
| 变化 | 手段 |
|---|---|
| 减链 | 裂化/裂解（烷→小分子）、烯/炔臭氧化、苯环侧链KMnO₄ |
| 增链 | HCN加成→氰基（可水解）、羟醛缩合（烯醛）、酚醛树脂（苯酚+甲醛）、脲醛树脂 |
| 成环 | 酯化（内酯）、D-A环加成、分子内缩合 |
| 傅克反应 | 烷基化（+RX）、酰基化（+RCOX），**定位效应**：邻对位定位基（-OH、-NH₂、-CH₃、-X），间位定位基（-NO₂、-SO₃H、-COOH） |

### 12.4 解题方法：条件→机理

- **试剂条件判断反应类型**：卤素光照→取代；卤素CCl₄→加成；NaOH水→取代，NaOH醇→消去；稀H₂SO₄→酯水解（配浓H₂SO₄→酯化/消去）；催化剂加压→加氢 |
- **三种不稳定结构自动重排**：① 同碳二羟基→羰基 ② 同碳二双键→三键 ③ 同碳羟基+双键→羰基（烯醇重排） |
- **信息反应必考识别**：羟醛缩合（"断双键、α补氢、β补氧"反推）、D-A反应（"断π键、断π间、半键回归"）、格氏试剂（RMgX 遇活泼氢H₂O/ROH/RNH₂/RC≡CH 会反应，溶剂不能含活泼氢） |
- **推断求解顺序**：算Ω→定官能团→推碳架→逐官能团填空→回代检验 |
- **逆合成分析（合成路线设计 · 目标分子倒推）**：有机合成两大任务 = 碳骨架构建（12.3 增减成环）+ 官能团转化（12.2 引入保护）；设计路线"倒着设计、正着合成"——① 切割目标分子（优先酯/酰胺键→羧酸+醇/胺；碳碳单键→逆推羟醛缩合/D-A/格氏增碳）② 逆推官能团来源（-OH←卤代烃水解/醛酮加氢/烯水化）③ 拆到常见原料（乙烯/乙醇/苯/乙炔）④ 正向复核每步产物与条件。路线评价：步骤少、产率高、条件温和、原子经济性高（绿色合成）。 |

### 12.5 例题真题精讲

**例1 (2024·全国甲卷) 白藜芦醇**：FeCl₃检验酚羟基（显紫色）；原料间苯二酚+对羟基苯甲醛 经"原料→..."；硝基苯经 Fe/H⁺ 还原成苯胺（信息）；启示：识别目标分子可按需拆成两半再连接（D-A/羟醛/酯化）

**例2 (2024·上海) 瑞格列奈**（抗糖尿病药，多官能团）：还原反应选择 NaBH₄（不反应其他断开）；茚三酮检测氨基酸（显蓝紫色）；流程中有酯化生成内酰胺环

**例3 (2022·全国乙卷) 左旋米那普伦**：E→F 环内酯生成（分子内脱水，加浓H₂SO₄）；SOCl₂ 使醇→氯代（保留手性？）；G→H 取代反应；注意溴原子引入后随位置判断取代/消去

**例4 瑞卡帕布（合成路线含氨基保护）**：NH₂ 先与 Boc 酸酐成酰胺封住，防止与酰氯副反应；合成羧酸也用 Boc 引入保护；验证策略：先看保护基再脱保护

**例5 羟醛缩合（信息题）**：两分子醛，α-H 被夺去成碳负离子，进攻另一分子羰基→β-羟醛，脱水成α,β-不饱和醛；反推口诀"断双键、α补氢、β补氧"（从产物醛往回：双键断开、α位补H（伊利）β位补O）

**例6 青蒿素中间体合成（信息）**：关键几步：环状过氧桥（物性/偏低，青蒿素含过氧链）；合成路线中出现中间体"羟醛缩合产物"（α,β-不饱和）：萜烯骨架经臭氧化→醛→羟醛缩合环化

**例7 D-A环加成（信息）**：共轭二烯+亲双烯体→六元环；产物结构=两片段拼合；反推口诀"断π键、断π间、半键回归"：把产物环上连着的两根双键断开，找回双键位置，环变成两个片段

**例8 格氏试剂（信息）**：RMgX 制取不能用含活泼氢溶剂（水/醇→立即反应生成烷烃）；格氏试剂是强碱+强亲核试剂，遇 -OH/NH₂/炔氢 先中和；反应：与醛酮加成→醇（增碳）

**例9 (2024·浙江1月) 氯硝西泮**：某种产物环节涉及氨解（-CN 或酯的水解、-COCl 与胺作用成酰胺）；例中有：① 硝基吸电子使苯胺碱性大幅降低（比较：NH₂ vs 苯环上有-NO₂）② 某步看似取代实为加成+消去两步 ③ 判断酸碱成盐（叔胺成盐后水溶性增强）

## 关键方程式速览（已覆盖部分）

1. 电石制乙炔：CaC₂ + 2H₂O → Ca(OH)₂ + HC≡CH↑
2. 乙炔 + HCl（催化剂/△）→ CH₂=CHCl（氯乙烯）
3. 乙炔 + H₂O（催化剂/△）→ CH₃CHO（乙醛）
4. 乙炔 + HCN（催化剂/△）→ CH₂=CH-CN（丙烯腈）
5. 丙烯加聚：nCH₂=CHCH₃ → 催化剂 → [-CH(CH₃)-CH₂-]ₙ
6. 乙炔加聚：nCH≡CH → 催化剂 → [-CH=CH-]ₙ（聚乙炔，导电）
7. 甲苯硝化（TNT）：C₆H₅CH₃ + 3HNO₃ →浓H₂SO₄△→ 2,4,6-(NO₂)₃C₆H₂CH₃ + 3H₂O
8. 甲苯侧链氯化：C₆H₅CH₃ + Cl₂ →光→ C₆H₅CH₂Cl + HCl
9. 甲苯燃烧：C₇H₈ + 9O₂ →点燃→ 7CO₂ + 4H₂O
10. 苯燃烧：2C₆H₆ + 15O₂ →点燃→ 12CO₂ + 6H₂O
11. CuSO₄ 除 H₂S：CuSO₄ + H₂S → H₂SO₄ + CuS↓

## 易错点与命题规律（已覆盖部分）

- **易错**：①苯与溴水是萃取不是取代（取代需液溴+FeBr₃）；②酸性 KMnO₄ 只能鉴别不能除杂乙烯（溴水可鉴别可除杂）；③CₙH₂ₙ 可能是环烷烃；④与苯环直接相连碳上无 H 则侧链不能被 KMnO₄ 氧化；⑤一氯代物计数要补全氢原子；⑥共直线原子数要算苯环对位延伸；⑦"羧基/酯基/酰胺基的 π 键不能加 H₂"；⑧质谱测相对分子质量、核磁测 H 种类与个数、红外测官能团——三者不混
- **命题规律**：有机推断常以"质谱+核磁+化学性质（NaHCO₃/FeCl₃/水解）+不饱和度"五联证据锁定结构；共轭二烯/共轭三烯的部分加成（1,2/1,4/1,6）是近两年新热点；苯环定位效应、KMnO₄ 氧化产物规律是推断题破题钥匙
