## 模块1 物质组成问题（★★）

**核心：把"数目计算"还原为"组成判断"**——每一个选项都在考某类物质的微观组成。

### 六大组成陷阱
| 陷阱 | 要点 | 典例 |
|------|------|------|
| 根 vs 基 | **根带电**：电子数=质子数±电荷数；**基不带电**：电子数=质子数 | 1 mol OH⁻（10Nₐ）vs 1 mol -OH（9Nₐ） |
| 稀有气体 | 单原子分子 | 1 mol 氦气 = 1Nₐ 原子 |
| 胶粒 | 胶粒是微粒聚集体，数目**小于**构成分子/离子数 | Fe(OH)₃ 胶粒 < Nₐ |
| 晶体组成 | 只有**分子晶体**由分子构成 | NaCl 晶体不含"NaCl 分子" |
| 溶液组成 | **勿忽略溶剂水**对分子/原子/电子/化学键的贡献 | 100 g 46% 乙醇溶液氧原子 = 乙醇 1Nₐ + 水 3Nₐ = **4Nₐ** |
| 浓度换算 | c 或 pH → 数目 **必须有体积**（N = c·V·Nₐ） | 1 mol/L NaCl 无体积 → 不可算 |

### 水电离的 H⁺/OH⁻ 计算
- 先判断溶质对水的电离是**抑制**（能电离出 H⁺/OH⁻ 的酸碱盐）还是**促进**（水解为主的盐）。
- 抑制 → 水电离离子为**隐性**离子：由另一离子浓度反推。酸性环境 OH⁻ 隐性：pH=5 的 HCl，c₍水₎H⁺ = c(OH⁻) = 10⁻⁹ mol/L。
- 促进 → 水电离离子为**显性**离子：CH₃COONH₄ 双水解促进且 pH=7，水电离 H⁺ **>** 10⁻⁷Nₐ（部分 H⁺ 藏在 CH₃COOH 羧基中）。
- **已知 pH 求 c(H⁺) 与温度无关；c(OH⁻) = K_w/c(H⁺) 与温度有关**。

### 混合物两招
- **极值法**：把总量假设为任一组分算极值；两极值相等则混合后该量恒定。例：80 g Cu₂S 与 CuO 混合（M 160/80，均 1Nₐ Cu 原子）→ Cu 原子恒为 Nₐ。**两极值不等 → 结果介于区间**。
- **通式法**：通式（最简式）相同即恒定。例：16 g O₂+O₃ 按 Oₙ 算 → O 原子 Nₐ。
  **常考通式组合**：①烯/环烷 CₙH₂ₙ；②NO₂/N₂O₄；③O₂/O₃；④葡萄糖/醋酸/甲醛 CₙH₂ₙOₙ；⑤Na₂O₂/Na₂O/Na₂S 求离子总数。
- 精典例：**甲苯 C₇H₈ + 丙三醇 C₃H₈O₃** 相对分子质量同为 92 且 H 数同为 8 → 9.2 g 混合恒含 0.8Nₐ H；丙烯+环丁烷（CₙH₂ₙ）7 g 恒含 1.5Nₐ 原子。

## 模块2 物质结构问题（★★★）

**核心：数化学键。** 方法：①写结构式防漏键；②认清极/非极性、σ/π 键分类；③有机物警惕同分异构体干扰。

### 化学键计数要点
- 苯：6 个 C-C σ + 6 个 C-H σ = **12Nₐ σ 键**（勿漏 C-H；苯环 C-C 是大 π 键，非单非双）。
- 链状烷烃 CₙH₂ₙ₊₂：共价键 = (2n+2) + (n-1) = **(3n+1)Nₐ**。
- CₙH₂ₙ（Ω=1）：烯烃 1 个 C=C 或环烷烃 0 个 → 碳碳双键 **Nₐ 或 0**。
- C₂H₆O：乙醇 7 个极性键 / 甲醚 8 个极性键 → 46 g 为 **7Nₐ 或 8Nₐ**（异构体干扰）。
- 丙烯醛：C=C 1 个 π + 醛基 1 个 π = 0.1 mol 含 **0.2Nₐ π 键**。
- **均摊法**：化学键数 = 原子数 ×（每个原子周围键数 × 1/2）。
  | 物质 | 键型 | 数目/1 mol |
  |------|------|-----------|
  | 金刚石 | C-C | 2Nₐ（C 连 4 键 ÷2） |
  | 白磷 P₄ | P-P | 6Nₐ（每分子 6 键） → 31 g=1.5Nₐ |
  | 环状 S₈ | S-S | 8 键 → 32 g=Nₐ |
  | 冰 | 氢键 | 2Nₐ（每水分子 4 氢键 ÷2） |
  | 晶体硅 | Si-Si | 2Nₐ |
  | SiC | Si-C | 4Nₐ（Si 均摊 2 + C 均摊 2） |
  | SiO₂ | Si-O | 4Nₐ（Si 2 + 2×O 1） |
  | 石墨 | C-C σ | 1.5Nₐ；六元环 0.5Nₐ（1 环 ~ 3 键 ~ 2 C） |
- 配位键：Cu(H₂O)₄²⁺ 配位键 4Nₐ；[Zn(CN)₄]²⁻ σ 键 = 4 配位 + 4 个 C≡N 内 σ = **8Nₐ**（配位键也是 σ 键）；NH₄F 晶体中 NH₄⁺ 共价键 4Nₐ（F⁻ 无共价键）；三肽（2 个肽键）0.1 mol → 0.2Nₐ。
- 陷阱：甲醇溶液含 O-H 键 **远大于** 0.1Nₐ（溶剂水也有 O-H）；键线式/结构简式要补全 C-H 键。

## 模块3 物理性质问题（★★★）

**核心：状态与电离条件决定"能否套公式"。**

### 气体摩尔体积铁律
- 标况（0°C、101 kPa）Vₘ = **22.4 L/mol**；常温常压（25°C、101 kPa）Vₘ = **24.5 L/mol**。
- **标况下非气体**（无机）：HF、Br₂、H₂O、SO₃、NO₂、N₂O₄。
- **标况下是气体**（有机）：碳原子数 ≤4 的烃；CH₃Cl；HCHO（甲醛）。
- 注意：CH₂Cl₂、CHCl₃、CCl₄ 标况均非气体；常温常压下非气体 → 标况下必非气体；标况液/固物质按 22.4 L 计 → 物质的量**远大于** 1 mol。

### 电离与溶液离子数
- 共价化合物电离依赖水；离子化合物电离依赖水或熔融。
- **电解质强弱**：强电解质完全电离、弱电解质部分电离。1 L 1 mol/L 盐酸无 HCl 分子；醋酸电离 H⁺ < Nₐ。
- **NaHSO₄ 三态离子数**：晶体（Na⁺+HSO₄⁻）2Nₐ；熔融 2Nₐ；**水溶液 3Nₐ**（HSO₄⁻ 再电离出 H⁺）。
- 已知**物质的量浓度 c** → 离子数与强弱、元数有关；已知 **pH** → 只与 c(H⁺) 有关，与强弱、元数无关。
- Ba(OH)₂ 1 L pH=13 → c(OH⁻)=0.1 mol/L（勿乘 2）。
- 溶解度：难溶盐放入水中 → 离子数**远小于** Nₐ（CaCO₃ 100 g 放 1 L 水中 Ca²⁺ ≪ Nₐ）。

### 反思三句
1. 已知 c → 与酸碱强弱/元数有关；已知 pH → 无关。
2. 已知 pH → c(H⁺) 与温度无关，c(OH⁻) 与温度有关。
3. "常温常压"≠不能算——给**质量**就能算；算不出精确值也能求范围。

## 模块4 化学性质问题（★★★★）

**核心：反应是否"完全转化"决定数目。** 四大分支：

### ① 可逆反应（反应物不能完全转化）
**常考可逆反应 14 条**：合成氨；2SO₂+O₂⇌2SO₃；CO₂+H₂O；SO₂+H₂O；NH₃+H₂O；Cl₂+H₂O⇌HClO+HCl；2NO₂⇌N₂O₄；I₂+H₂⇌2HI；PCl₃+Cl₂⇌PCl₅；2CrO₄²⁻+2H⁺⇌Cr₂O₇²⁻+H₂O；Fe³⁺+3SCN⁻⇌Fe(SCN)₃；酯化反应；酯的酸性水解；不彻底的盐类水解。
- **只给反应物量 → 无法算变化量/产量/剩余量**；已知产物量或变化量 → 可算。
- 前后气体计量数不变的可逆反应（I₂+H₂⇌2HI）：**分子总数守恒**。
- 例：1 mol 乙醇+1 mol 醋酸酯化 → 乙酸乙酯 < Nₐ；3 mol H₂+N₂ 充分反应电子转移 < 6Nₐ；2 mol SO₂+1 mol O₂ → 平衡时分子数介于 2Nₐ~3Nₐ。

### ② 氧化还原电子转移（歧化/归中）
- 转移电子数 = 得电子数 = 失电子数，**只看其中一项**。
- 注意关键字"得到/失去/被氧化/被还原"。
- **氧化剂/还原剂不单一 → 抓单一变量**（一般抓还原剂）：火法冶铜 Cu₂S+O₂ 抓 -2 价 S（6e⁻/1 mol O₂）；黑火药 S+2KNO₃+3C 抓 C（3 mol C → 12e⁻）；粗铜电解精炼阳极成分不单一不可算。
- **歧化**：Na₂O₂ +H₂O/CO₂，2 mol Na₂O₂～2Nₐ e⁻（1:1）；Na₂O₂+SO₂ 只作氧化剂 → 1 mol 转移 2Nₐ e⁻。
- **归中**：KClO₃+6HCl=KCl+3Cl₂+3H₂O，3Cl₂～5e⁻（生成 3 mol Cl₂ 转移 5Nₐ，非 6Nₐ）；KClO 是氧化剂得 1Nₐ。
- **以少定多**：Fe+Cl₂ 只生成 FeCl₃，1 mol Fe 对 1 mol Cl₂ → 按 Cl₂ 计 **2Nₐ**；FeI₂ 通 Cl₂ 同理按 Cl₂ 2Nₐ；**但 Na+HCl**：H⁺ 少但 Na 可与水反应 → 按 Na 计 2Nₐ。

### ③ 连续反应（勿漏后续步骤）
1. **2NO+O₂=2NO₂、2NO₂⇌N₂O₄**：2 mol NO+1 mol O₂ → 分子数介于 Nₐ~2Nₐ。
2. **CH₄+Cl₂ 光照多步取代**：每步计量数不变 → 1 mol CH₄+1 mol Cl₂ 分子总数恒 2Nₐ；CH₃Cl 分子数 < Nₐ。
3. Na 入水 + 铝箔：NaOH 再与 Al 反应放 H₂ → 气体 **>** 0.5Nₐ。
4. NH₃+O₂→NO 后过量 O₂ 再氧化 NO→NO₂ → NO < 0.4Nₐ。

### ④ 水解与离子数目变化
- 彻底双水解 → 某离子骤减；发生水解的离子数目减少；大多数水解使离子**总浓度不变或增大**。
- 出现等式/中性 → **电荷守恒**。例：NH₄Cl 溶液通氨至 pH=7 → c(NH₄⁺)=c(Cl⁻) → NH₄⁺ 数目 = Nₐ。

### ⑤ 量变引起质变（浓度/温度/物质的量/过量）
- **温度**：Na+O₂ 常温 Na₂O / 加热 Na₂O₂；Cl₂+OH⁻ 冷 ClO⁻ / 热 ClO₃⁻；Fe/Al 浓酸常温钝化、加热持续。
- **浓度**：MnO₂+浓盐酸（稀则不反应）；Cu+浓 H₂SO₄（稀不反应）；Zn 浓→SO₂ 稀→H₂；Cu 浓→NO₂ 稀→NO。
- **物质的量**：SO₂/CO₂/H₂S+碱 碱多正盐 碱少酸式盐；Fe+稀 HNO₃ 硝酸多 Fe³⁺ 少 Fe²⁺；FeI₂/FeBr₂ 通 Cl₂ "谁强谁优先"（Fe²⁺先被氧化，Br⁻ 未动）。变价金属与 Cl₂ 只生成高价氯化物（FeCl₃）；与 S 只生成低价硫化物（Cu₂S）。
- **过量判断**：氧化还原用得失电子极值；活泼金属+酸勿忽略水；只有相对关系无具体数据 → 只能定性不能精确。
- 例4 精典：Fe 纯 O₂ 燃烧 → Fe₃O₄ 8/3Nₐ；MnO₂ 足量浓盐酸 → 2Nₐ；**浓盐酸足量 MnO₂** → H⁺ 消耗+挥发使反应停止 <2Nₐ；0.1 L 18 mol/L 浓硫酸 + 足量 Cu → <1.8Nₐ；Cu+浓硝酸气体分子数**不确定**（浓度变产物变）但电子转移恒 2Nₐ；Zn+浓硫酸（浓稀皆反应）恒 2Nₐ；Fe+足量稀硝酸 3Nₐ。
