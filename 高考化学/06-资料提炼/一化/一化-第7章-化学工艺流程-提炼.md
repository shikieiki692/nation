## 模块 1　化学工艺流程的框架及其关键环节 ★★★

### 一、常考工艺流程的框架

**原料 → 预处理 → 核心反应 → 分离提纯 → 目标产物**（含循环物质、副产物处理）

### 二、原料预处理及其目的

| 操作 | 目的 |
|---|---|
| 粉碎/研磨 | 增大接触面积 → 加快反应速率、增大"目标元素"利用率 |
| 煅烧 | ①除有机物或碳 ②使成分分解 ③氧化某些物质 ④难溶硫化物→易溶氧化物（**涉化合价升高时考虑空气中 O₂**） |
| 酸溶/酸浸 | 一般酸（HCl/稀H₂SO₄）：溶解活泼金属、碱性氧化物、两性氧化物、碳酸盐；氧化性酸（HNO₃）：注意还原剂被氧化 |
| 碱洗（纯碱洗） | 除原料表面油污（酯类）——**矿物油（烃类）碱洗不掉，靠煅烧** |
| 碱溶/碱浸 | 溶解两性金属/氧化物、酸性氧化物（Al、Zn、Ga、Be、Si） |

> 增大酸浸/碱浸效率：适当升温、增大酸/碱浓度、原料粉碎、搅拌。

### 三、核心反应方程式的书写

1. **箭头定方向**：指入=反应物，指出=产物。用"化合价升降守恒+电荷守恒+原子守恒"推导副产物。
2. **复分解——"定1法"**：最复杂物质计量数定 1 → 按原子守恒配其他 → **H/O 不守恒时补 H₂O**（H₂O 位置不定，最后用 H 补、O 检查）。
   - **沉淀体系注意弱电解质后续反应**（HCO₃⁻ 沉淀时放 H⁺）：
     - Ni²⁺+HCO₃⁻：`Ni²⁺+2HCO₃⁻ = NiCO₃↓+CO₂↑+H₂O`（本质 Ni²⁺+HCO₃⁻=NiCO₃↓+H⁺，过量 HCO₃⁻ 耗 H⁺）
     - Ni²⁺+HCO₃⁻+NH₃·H₂O：`Ni²⁺+HCO₃⁻+NH₃·H₂O = NiCO₃↓+NH₄⁺+H₂O`
     - 若 Ksp(RCO₃)>Ksp[R(OH)₂]，用 NH₄HCO₃ 优于 NaHCO₃（NaHCO₃ 碱性更强会生成 R(OH)₂ 副产）
     - 碱式碳酸盐：`2Ni²⁺+2CO₃²⁻+H₂O = Ni₂(OH)₂CO₃↓+CO₂↑`（OH⁻ 来自水，H⁺ 被 CO₃²⁻ 消耗）
     - 黄钠铁矾：`Na⁺+3Fe³⁺+2SO₄²⁻+6H₂O+6CO₃²⁻ = NaFe₃(SO₄)₂(OH)₆↓+6HCO₃⁻`
3. **氧化还原**：参照第4章模块3+4。**流程中 O₂ 常被隐藏需自行判断**（如 Mn 升价必有 O₂ 参与）。

### 四、常见的盐类分解反应

1. **铵盐**：先分解成 NH₃+酸。酸也易分解→NH₃+H₂O+酸性氧化物（NH₄HCO₃）；酸有强氧化性→NH₃ 被氧化成 N₂：
   - `NH₄Cl ═(△)═ NH₃↑+HCl↑`
   - `NH₄HCO₃ ═(△)═ NH₃↑+CO₂↑+H₂O`
   - `3(NH₄)₂SO₄ ═(△)═ 4NH₃↑+N₂↑+3SO₂↑+6H₂O`
2. **草酸盐**（含结晶水）：分解生成金属氧化物+CO₂+CO（FeC₂O₄·2H₂O 热重等）。
3. **碳酸氢盐**：→碳酸盐+H₂O+CO₂；碳酸盐不稳→继续分解成金属氧化物+CO₂。
4. **结晶水硫酸盐**：先失水（可能分步）→再分解成金属氧化物+SO₃；金属氧化物有还原性则被 SO₃ 氧化（SO₃→SO₂）；SO₃ 高温自身可分解。
   - 审题看清"隔绝空气"还是"空气中"；热重曲线先推规律再用数据检验；并列/连续反应可加和。

### 五、追踪元素法分析流程

1. 明确需分析的元素种类（由原料决定）。
2. 明确目标元素（可能有多个目标产物）。
3. 对比起点终点：杂质元素 + 除杂方法。
4. 目标元素始终在主线上（过滤时在固体还是溶液？结晶时析出还是留在母液？分液在水相还是有机相？）。
5. **寻找可循环物质**：①流程回头箭头 ②加入物质与流出产物的交集 ③重结晶母液含较多溶质 ④电解后溶液再生酸/碱/O₂/H₂。

### 六、流程常见操作与考虑角度（答题模板）

| 操作 | 答题角度 |
|---|---|
| 分离提纯 | 过滤（固液）/分液（不互溶液体）/蒸馏（沸点差异大）/萃取（溶解度差异）/蒸发结晶（NaCl 类溶解度随温度变化小）/蒸发浓缩-冷却结晶（CuSO₄·5H₂O、KNO₃ 类）/趁热过滤（防降温析出杂质） |
| 气体氛围 | ①O₂/H₂O/CO₂ 是否参与反应 ②隔绝空气防氧化、水解、潮解 |
| 控制 pH | ①分离沉淀（结合开始/完全沉淀 pH 或 Ksp 计算）②促/抑水解 ③防副反应 ④防沉淀溶解 ⑤满足反应酸碱条件 ⑥萃取率与 pH（差值越大越易分离） |
| 加热 | ①加快速率 ②平衡向吸热方向移动 ③除热不稳定物质/逸气/气化 ④调 pH 除 Fe³⁺·Al³⁺ 时促水解完全、避免胶体 |
| 降温 | ①减慢速率 ②平衡向放热方向移动 ③高沸点物液化分离 ④降溶解度析晶 |
| 控制温度 | ①防副反应 ②催化剂最大活性（过高失活）③按图表选最佳转化率/选择性/产率 ④防 H₂O₂、NH₃·H₂O、NH₄Cl、NaHCO₃、HClO、HNO₃、KMnO₄ 等分解挥发 ⑤控溶解结晶 ⑥低碳环保优先 |
| 加入沉淀剂 | ①稀 H₂SO₄ 沉淀 Ba²⁺/Pb²⁺/Ca²⁺ ②F⁻ 沉淀 Ca²⁺/Mg²⁺（CaF₂/MgF₂）③S²⁻ 沉淀 Cu²⁺/Ag⁺/Pb²⁺/Co²⁺/Ni²⁺（硫化物）④CO₃²⁻ 沉淀 Ca²⁺/Ba²⁺ 或双水解成氢氧化物 ⑤HCO₃⁻"沉锰"MnCO₃ ⑥草酸盐沉淀 Ca²⁺/Co²⁺/Ni²⁺ ⑦Ksp 数据→沉淀转化 ⑧检验沉淀完全：取上层清液加沉淀剂观察 ⑨定量判断：算离子浓度与 10⁻⁵ mol/L 比较 |
| 加氧化/还原剂 | 由化合价升降判断，熟记常见氧化剂还原剂 |
| 洗涤晶体 | 水洗除表面水溶性杂质；**冰水洗**除杂质+防溶解损耗；有机溶剂洗除杂质+降低溶解度+易挥发利于干燥；沉淀洗涤法（加蒸馏水浸没→自然流下→重复2~3次）；检验洗净：取最后一次洗涤液加试剂 |
| 原子利用率 | 绿色化学（循环利用/废物处理/能量充分利用） |

### 模块1 六大题型要点

- **类型Ⅰ 复分解书写**：定1法 + 补 H₂O。例：`4H₃BO₃+2NaOH+3H₂O = Na₂B₄O₅(OH)₄·8H₂O`；`2NH₄HCO₃+FeSO₄ = Fe(OH)₂↓+(NH₄)₂SO₄+2CO₂↑`
- **类型Ⅱ 氧化还原书写**：隐含 O₂ + 化合价守恒。例：`2Li₂CO₃+4MnCO₃·Mn(OH)₂+3O₂ ═(900-1000℃)═ 4LiMn₂O₄+6CO₂↑+4H₂O`；`(NH₄)₂Cr₂O₇ ═(高温)═ N₂↑+Cr₂O₃+4H₂O`（逆向配平）
- **类型Ⅲ pH 范围计算**：pH=pKa 转换 `c(H⁺)=10⁻ᵃ`，由 Ksp 计算开始沉淀 pH；**多离子时最大值取"未沉淀离子开始沉淀 pH 的最小值"**；注意表格起始浓度与题目浓度是否一致；Al(OH)₃ 等两性在 pH≥9.6 重新溶解 → pH 上限受限
- **类型Ⅳ 温度调控**：双向作答——低于最佳温度速率慢；高于最佳温度物质挥发/分解（苯挥发、H₂O₂ 分解、NH₃ 逸出）
- **类型Ⅴ 萃取与反萃取**：反萃取加酸（`VO²⁺+H₂R ⇌ VOR+2H⁺`，加 H⁺ 逆向）；选强酸不选弱酸（CH₃COOH H⁺ 太低）；兼顾后续反应不引入杂质（避免 HCl 因 KClO₃ 氧化生成 Cl₂）
- **类型Ⅵ 重结晶**：溶解度受温度影响大→冷却结晶；小→蒸发结晶；目标量大且溶解度小→蒸发浓缩趁热过滤（除低温析出的杂质）

## 模块 2　常考元素的化工流程题 ★★★★★

> 化工流程 = 大型"分离、提纯"题，除杂最佳原则**"不增、不减"**。

### 一、各元素流程套路（内容提要）

#### 1. Al 元素
- **酸浸**：Al₂O₃ → Al³⁺ 进滤液 → 加碱性物调 pH → Al(OH)₃ 进滤渣
- **碱浸**：Al₂O₃ → [Al(OH)₄]⁻ 进滤液 → 加酸性物调 pH → Al(OH)₃ 进滤渣
- 调 pH 选较弱酸碱（不引入杂质可强酸碱但要控范围，pH 过低过高 Al(OH)₃ 都再溶解）；pH≤9.6（Al(OH)₃ 在 ≥9.6 溶解为 [Al(OH)₄]⁻）
- **多杂质调 pH 三原则**：最小值=溶解度大的杂质离子完全沉淀 pH；最大值=后续沉淀离子开始沉淀 pH 或 Al(OH)₃ 开始溶解 pH（取更小）

#### 2. Fe 元素
- 酸浸 Fe²⁺/Fe³⁺ 进滤液 → 加氧化剂（H₂O₂/空气/O₂）Fe²⁺→Fe³⁺ → 调 pH → Fe(OH)₃ 进滤渣
- **H₂O₂ 过量原因**：Fe³⁺ 催化 H₂O₂ 分解
- 目标是亚铁/铁盐时**防止 Fe 损失**：将 Fe³⁺ 还原成更难沉淀的 Fe²⁺
- 调 pH 碱性物优选目标金属对应的难溶氧化物/碱/碳酸盐（不引入杂质）；调 pH 后**加热**使 Fe(OH)₃ 胶体聚沉易过滤

#### 3. Si 元素
- SiO₂ 酸浸不溶 → 滤渣；碱浸/碱熔 → Na₂SiO₃ 进滤液（或难溶硅酸盐进滤渣）
- 可溶硅酸盐酸浸 → H₂SiO₃ 进滤渣
- SiO₂ 高温与碱/碱性氧化物/碳酸盐反应；`SiO₂+4HF = SiF₄↑+2H₂O`

#### 4. Ca、Mg 元素
- Ca²⁺/Mg²⁺ 完全沉淀为氢氧化物需 OH⁻ 浓度过高（共沉淀风险）→ 转 **CaF₂/MgF₂ 沉淀**
- Ksp(CaF₂)<Ksp(MgF₂)：算 c(F⁻) 最小浓度代入**较大 Ksp（MgF₂）**
- pH 不宜过低：H⁺ 与 F⁻ 生成 HF 使沉淀溶解平衡右移
- CaSO₄ 微溶 → 硫酸浸碳酸钙时部分 Ca 以 CaSO₄ 进滤渣

#### 5. Cu、Ag 元素
- 硫化物煅烧产生 SO₂ 污染 → 氧化剂/碱回收硫；用氧化剂酸浸时硫转 S 单质进滤渣
- 用**硫化物**沉淀 Cu²⁺/Ag⁺（硫化物溶解度极小）；阳离子选目标产物对应阳离子防引入杂质
- Cu、Ag 混合固体用电解分离（混合物作阳极）
- Ag⁺ 与浓度大的 Cl⁻ 形成可溶配离子 [AgCl₂]⁻ → 氯化物沉淀 Ag⁺ 时注意用量

#### 6. Co、Ni 元素
- Co/Ni 与 Fe 同族性质相似，常规沉淀难分离 → **萃取反萃取**（与有机溶剂配位能力随 pH 差异）
- 萃取：Mⁿ⁺+H₂R ⇌ MRₙ+nH⁺（化学变化，配位）；反萃取：加无机强酸（酸根与目标产物阴离子对应）
- 萃取目的是提纯（萃杂质）或富集（萃目标）；选 pH 使不同离子萃取率差值最大

#### 7. Na、K 元素
- 钠盐钾盐溶解度大难沉淀 → **重结晶**分离提纯
- 重结晶原理：溶解度受温度影响不同；提纯 KNO₃（溶解度随温度变化大）用蒸发浓缩-冷却结晶；提纯 NaCl 用蒸发结晶；趁热过滤用**减压过滤/抽滤**（快、固液分离好、利于干燥）

#### 8. 其他条件控制
- 抑制水解：加过量酸抑制弱碱阳离子水解、过量碱抑制弱酸阴离子水解；**HCl 气流中蒸发 MgCl₂/FeCl₃ 得无水盐酸盐**
- 温度：过低速率慢、过高挥发分解损失
- 增大气体浓度：加压/降温

#### 9. 产率计算
- **产率 = 实际产量/理论产量 ×100%**
- 用**元素守恒**（如 Mn 原子守恒）求理论产量；各工序损失率、引入量、沉淀率逐项累加

### 二、类型题要点（按元素归类）

#### 类型Ⅰ：ⅠA/ⅡA 族（Ba、Li）
- **BaTiO₃（2023全国甲）**：碳粉将难溶 BaSO₄ 还原为易溶 BaS（`Ca²⁺+S²⁻=CaS↓` 溶解度大制小）；酸化选 HCl（BaCl₂ 可溶，BaSO₄/Ba₃(PO₄)₂ 难溶）；直接酸浸不可行（BaS/CaS+酸→剧毒 H₂S，CaCl₂ 入产品）；草酸盐复分解定1法
- **锂辉石 Li₂CO₃**：`LiAlSi₂O₆+2CaO ═(煅烧)═ LiAlO₂+2CaSiO₃`；硫酸浸加少量硝酸=氧化 Fe²⁺→Fe³⁺；调 pH 5.2≤pH<8.3（Fe³⁺Al³⁺ 完全沉淀、Mn²⁺ 不沉淀）；`Mn²⁺+HCO₃⁻+NH₃·H₂O = MnCO₃↓+NH₄⁺+H₂O`；避免 Li⁺ 沉淀用 `Q<Ksp` 算 CO₃²⁻ 上限；Li₂CO₃ 溶解度随温度升高**减小**→80℃热洗；碳化-热解提纯

#### 类型Ⅱ：两性元素 Al、Zn、Ga、Be
- **BeO（Be 与 Al 对角线规则）**：`Be(OH)₂+2OH⁻ = [Be(OH)₄]²⁻`（类比 Al(OH)₃+OH⁻）；水解时**降低 pH 利于** Be(OH)₂ 析出（平衡左移）
- **GaN（Ga 与 Al 同族）**：`[Ga(OH)₄]⁻+CO₂ = Ga(OH)₃↓+HCO₃⁻`（过量 CO₂）；阴极 `[Ga(OH)₄]⁻+3e⁻ = Ga+4OH⁻`；K 计算用 c(OH⁻)
- **Zn 冶炼**：`2ZnS+O₂+4H⁺ = 2Zn²⁺+2S+2H₂O`（氧压酸浸回收 S）；Zn(OH)₂ 两性+溶于氨水（[Zn(NH₃)₄]²⁺，电解难还原→不能选 NaOH/氨水调 pH）；阳极放氧生酸；Ksp[Zn(OH)₂] 计算

#### 类型Ⅲ：Ti 元素（钛铁矿 FeTiO₃=FeO·TiO₂）
- 酸浸：`FeTiO₃+2H₂SO₄ = TiOSO₄+FeSO₄+2H₂O`（H₂SO₄）；`FeTiO₃+4HCl = TiOCl₂+FeCl₂+2H₂O`（HCl）
- TiO₂ 两性：溶热浓硫酸→TiOSO₄；熔融 NaOH→Na₂TiO₃→酸→TiO²⁺
- 水解：`TiO²⁺+(x+1)H₂O ═(加热)═ TiO₂·xH₂O↓+2H⁺`
- 制金属 Ti：TiO₂+C+Cl₂ 共热→TiCl₄ → Ar 气氛 Na/Mg 还原
- **高钛炉渣（2021全国乙）**：`Al₂O₃+4(NH₄)₂SO₄ ═(高温)═ 2NH₄Al(SO₄)₂+6NH₃↑+3H₂O↑`（尾气 NH₃ 循环）；分步沉淀 Fe³⁺→Al³⁺→Mg²⁺；母液 Mg²⁺ 用 Ksp 计算；酸溶选 H₂SO₄（酸性强难挥发），酸溶渣=SiO₂+CaSO₄

#### 类型Ⅳ：V 元素
- `2NH₄VO₃ ═(高温)═ V₂O₅+2NH₃↑+H₂O↑`；`V₂O₅+2H⁺ = 2VO₂⁺+H₂O`；`V₂O₅+6NaOH = 2Na₃VO₄+3H₂O`（两性偏酸）；VO₂⁺ 强酸性下遇 Fe²⁺/H₂C₂O₄ 还原为 VO²⁺
- **废钒渣**：V₂O₃ 需焙烧氧化（+3→+5）；Al₂O₃+CaO 焙烧→Ca(AlO₂)₂ 酸浸→Al(OH)₃ 滤渣；pH 决定 V 存在形态（VO₂⁺/VO₃⁻/V₂O₇⁴⁻/VO₄³⁻）；空气中煅烧 NH₄VO₃ NH₃ 被氧化成 N₂
- **石煤提钒（2024河北）**：价电子 3d³4s²；盐浸 `HCO₃⁻+OH⁻+Ca(VO₃)₂ ═(65~70℃)═ CaCO₃+H₂O+2VO₃⁻`；CO₂ 加压→HCO₃⁻ 浓度增大促反应；离子交换（VO₃⁻ 换 Cl⁻）洗脱液用 NaCl；沉钒 `VO₃⁻+NH₄⁺=NH₄VO₃↓`（碱性不利于沉钒）

#### 类型Ⅴ：Cr 元素（高频）
- **CrO₄²⁻(黄) ⇌ Cr₂O₇²⁻(橙)**：`2CrO₄²⁻+2H⁺ ⇌ Cr₂O₇²⁻+H₂O`（加酸右移变橙，加碱左移变黄；**不能用盐酸**——Cr₂O₇²⁻ 氧化 Cl⁻ 生成 Cl₂）
- Cr₂O₃/Cr(OH)₃ 两性：强酸→Cr³⁺；强碱→[Cr(OH)₄]⁻
- Cr₂O₇²⁻ 酸性强氧化：氧化 S²⁻/SO₃²⁻/I⁻/Fe²⁺/Br⁻/Cl⁻ 自身→Cr³⁺；**查酒驾 K₂Cr₂O₇**
- **铬铁矿流程套路（必背）**：FeCr₂O₄+Na₂CO₃+NaOH+O₂ 高温焙烧→Na₂CrO₄（碱性介质）→水浸（Fe₂O₃ 滤渣）→调 pH 除 Si/Al（Na₂SiO₃、Na[Al(OH)₄] 沉淀）→酸化 CrO₄²⁻→Cr₂O₇²⁻
- **Cr(OH)₃（2023辽宁）**：`Cr₂O₃+Na₂CO₃ ═(高温)═ 2NaCrO₂+CO₂↑`（类比 Al₂O₃）；滤渣=Fe₂O₃/Fe₃O₄（Fe(OH)₂ 在 O₂ 中不存在）；葡萄糖还原
- **铬钒渣（2023新课标）**：pH≈9 除硅磷（PO₄³⁻+H⁺→HPO₄²⁻ 不利于 MgNH₄PO₄ 沉淀；OH⁻ 多生成 Mg(OH)₂、NH₄⁺ 减少）；V₂O₅ 两性；`2Cr₂O₇²⁻+3S₂O₅²⁻+10H⁺ = 4Cr³⁺+6SO₄²⁻+5H₂O`

#### 类型Ⅵ：Mn 元素
- Mn²⁺ 氧化为 MnO₄⁻：过二硫酸铵/NaBiO₃（高温高酸度）
- MnO₂ 酸性强氧化剂：`MnO₂+4HCl(浓) ═(△)═ MnCl₂+Cl₂↑+2H₂O`；`MnO₂+2Fe²⁺+4H⁺ = Mn²⁺+2Fe³⁺+2H₂O`
- **KMnO₄ 还原产物三态**：酸性→Mn²⁺；中性/弱碱→MnO₂；强碱→MnO₄²⁻
- K₂MnO₄ 歧化：`3MnO₄²⁻+4H⁺ = 2MnO₄⁻+MnO₂↓+2H₂O`
- **KMnF₃（2024广西）**：葡萄糖还原 MnO₂→Mn²⁺；CaCO₃ 调 pH 5~6 只沉淀 Al³⁺；除 Fe²⁺Cu²⁺ 用 (NH₄)₂S（H₂S 不行——FeS 溶于酸；Zn 引入杂质）；`2Mn²⁺+3CO₃²⁻+2H₂O = Mn₂(OH)₂CO₃↓+2HCO₃⁻`（Na₂CO₃ 碱性强于 NaHCO₃ 副反应）；晶胞 KMnF₃ 紧邻数+密度
- **LiMn₂O₄（2023全国乙）**：`MnCO₃+H₂SO₄ = MnSO₄+H₂O+CO₂↑`；MnO₂ 氧化 Fe²⁺（H₂O₂ 被 Fe³⁺ 催化分解不宜用）；pH=4 时 c(Fe³⁺)=2.8×10⁻⁹（Ksp 计算）；石灰乳调 pH≈7 除 Al³⁺；BaS 除 Ni²⁺ 同时 BaSO₄↓；电解 `Mn²⁺+2H₂O ═(电解)═ H₂↑+MnO₂↓+2H⁺`（补 Mn(OH)₂ 稳 pH）；`2Li₂CO₃+8MnO₂ ═(煅烧)═ 4LiMn₂O₄+2CO₂↑+O₂↑`

#### 类型Ⅶ：Co、Ni 元素（含镍废液）
- 流程骨架：除 Cu（CuS 沉淀）→ H₂O₂ 氧化 Fe²⁺→Fe³⁺（`2Fe²⁺+H₂O₂+2H⁺ = 2Fe³⁺+2H₂O`）→ Ni(OH)₂ 调 pH 沉 Fe(OH)₃（不引入杂质）→ NiF₂ 除 Ca²⁺（Ksp 计算 F⁻ 最小浓度）→ P₂₀₄（HR）萃取 Zn（`2HR+Zn²⁺ ⇌ ZnR₂+2H⁺`，反萃用 H₂SO₄）→ 蒸发浓缩冷却结晶 NiSO₄·6H₂O
- 萃取率计算：由 H⁺ 浓度增量推算被萃 Zn²⁺ 量

#### 类型Ⅷ：Cu、Ag、Au 元素
- **细菌冶金载金矿（2024东北三省）**：`4FeS₂+15O₂+2H₂O ═(细菌)═ 4Fe³⁺+8SO₄²⁻+4H⁺`；"胆水"=CuSO₄；Fe(OH)₃ 胶体吸附 As 聚沉；细菌氧化优势=减少 SO₂、设备无需耐高温；NaCN 配位使 Au 氧化为 [Au(CN)₂]⁻（类比王水 Cl⁻ 配位）；Zn 置换 Au；`Na₂[Zn(CN)₄]+2H₂SO₄ = ZnSO₄+4HCN+Na₂SO₄`，NaOH 中和 HCN→NaCN 循环
- **氨法浸取铜包钢（2023河北）**：深蓝色 [Cu(NH₃)₄]Cl₂；浸取 `[Cu(NH₃)₄]Cl₂+Cu = 2[Cu(NH₃)₂]Cl`（Fe 不反应→滤渣）；氧化 `8NH₃+4[Cu(NH₃)₂]⁺+O₂+4H⁺ = 4[Cu(NH₃)₄]²⁺+2H₂O`；中和放热保温；`[Cu(NH₃)₂]⁺+2H⁺+Cl⁻ = CuCl↓+2NH₄⁺`；**真空干燥防 CuCl 被 O₂ 氧化**

## 关键方程式速览

### 模块1 方法论代表式
1. `4H₃BO₃+2NaOH+3H₂O = Na₂B₄O₅(OH)₄·8H₂O`（定1法+补H₂O）
2. `2NH₄HCO₃+FeSO₄ = Fe(OH)₂↓+(NH₄)₂SO₄+2CO₂↑`（沉铁）
3. `2Li₂CO₃+4MnCO₃·Mn(OH)₂+3O₂ ═(900-1000℃)═ 4LiMn₂O₄+6CO₂↑+4H₂O`（隐含O₂）
4. `(NH₄)₂Cr₂O₇ ═(高温)═ N₂↑+Cr₂O₃+4H₂O`（逆向配平）
5. `Ni²⁺+2HCO₃⁻ = NiCO₃↓+CO₂↑+H₂O`（HCO₃⁻ 沉淀体系）

### 模块2 元素流程关键式
6. `FeTiO₃+2H₂SO₄ = TiOSO₄+FeSO₄+2H₂O`（钛铁矿酸浸）
7. `TiO²⁺+(x+1)H₂O ═(加热)═ TiO₂·xH₂O↓+2H⁺`（钛水解）
8. `2NH₄VO₃ ═(高温)═ V₂O₅+2NH₃↑+H₂O↑`（偏钒酸铵分解）
9. `2CrO₄²⁻+2H⁺ ⇌ Cr₂O₇²⁻+H₂O`（铬酸盐转化，教材必背）
10. `Cr₂O₃+Na₂CO₃ ═(高温)═ 2NaCrO₂+CO₂↑`（铬铁矿焙烧类比）
11. `2Cr₂O₇²⁻+3S₂O₅²⁻+10H⁺ = 4Cr³⁺+6SO₄²⁻+5H₂O`（焦亚硫酸钠还原）
12. `MnO₂+2Fe²⁺+4H⁺ = Mn²⁺+2Fe³⁺+2H₂O`（MnO₂ 氧化）
13. `Mn²⁺+2H₂O ═(电解)═ H₂↑+MnO₂↓+2H⁺`（电解 MnSO₄）
14. `2Li₂CO₃+8MnO₂ ═(煅烧)═ 4LiMn₂O₄+2CO₂↑+O₂↑`
15. `4FeS₂+15O₂+2H₂O ═(细菌)═ 4Fe³⁺+8SO₄²⁻+4H⁺`（细菌冶金）
16. `[Cu(NH₃)₄]Cl₂+Cu = 2[Cu(NH₃)₂]Cl`（氨法浸铜）
17. `Na₂[Zn(CN)₄]+2H₂SO₄ = ZnSO₄+4HCN+Na₂SO₄`（强酸制弱酸）
18. `LiAlSi₂O₆+2CaO ═(煅烧)═ LiAlO₂+2CaSiO₃`（锂辉石煅烧）

## 易错点与命题规律

1. **"不增、不减"**：除杂试剂不得引入新杂质（硫化物阳离子选目标产物阳离子、反萃酸根对应目标阴离子、洗脱液选 NaCl）。
2. **隐含 O₂**：陌生氧化还原方程式中，金属升价常伴随空气中的 O₂ 参与（LiMn₂O₄、CrO₂⁻ 氧化）。
3. **pH 上限双重约束**：既要防目标离子沉淀，又要防两性氢氧化物（Al/Zn/Ga/Be）在碱性下重新溶解；多杂质时取各约束的**交集**。
4. **Ksp 计算陷阱**：表格"开始沉淀 pH"的起始浓度是否与题目一致；沉淀完全按 c≤10⁻⁵ mol/L；"完全除尽"用 Ksp 反推。
5. **H₂O₂ 用量**：Fe³⁺ 催化 H₂O₂ 分解 → 实际用量大于理论，成本高（常为"不宜用 H₂O₂ 替代"的考点）。
6. **CrO₄²⁻/Cr₂O₇²⁻ 转化**：酸化用 H₂SO₄ 不用 HCl（Cr₂O₇²⁻ 氧化 Cl⁻）。
7. **萃取 vs 反萃取**：萃取物理/化学（配位）两类；反萃加酸促平衡逆移。
8. **重结晶方向**：目标溶解度随温度变化大→蒸发浓缩冷却结晶；变化小→蒸发结晶；量大溶解度小→趁热过滤。
9. **KMnO₄ 还原产物三态**（酸→Mn²⁺/中弱碱→MnO₂/强碱→MnO₄²⁻）与介质联考。
10. **CuCl 防氧化**：真空干燥/还原氛围保存（亚铜化合物普遍怕 O₂）。
11. **产率/萃取率计算**：全程元素守恒 + 各步损失率/引入量逐项加和，单位统一（kg 直接用）。
12. **细菌/酶工艺温度**：不宜过高（杀死微生物/催化剂失活）也不宜过低（速率慢）。
