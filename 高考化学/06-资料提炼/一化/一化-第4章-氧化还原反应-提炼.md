## 模块 1　氧化还原反应及其相关概念 ★

### 内容提要

#### 1. 本质与特征
- **本质**：电子的转移（得失或偏移）。
- **特征**：元素化合价发生变化 —— 判断氧化还原反应的**核心判据**。

#### 2. 相关概念对照（必须滚瓜烂熟）

| 概念 | 得/失电子 | 化合价 | 被… | 生成物 | 性质 |
|---|---|---|---|---|---|
| 氧化剂 | 得 e⁻ | 降低 | 被还原 | 还原产物 | 氧化性 |
| 还原剂 | 失 e⁻ | 升高 | 被氧化 | 氧化产物 | 还原性 |

#### 3. 口诀
- 「升、失、氧化、还原剂、具有还原性；降、得、还原、氧化剂、具有氧化性」。
- 记忆情节「嬛嬛失声痒痒痒」：还原剂 → 具还原性 → 失 e⁻ → 化合价升高 → 被氧化 → 发生氧化反应 → 生成氧化产物。

#### 4. 氧化还原反应与四大基本反应类型的关系
| 命题 | 结论 |
|---|---|
| 置换反应一定是氧化还原反应 | ✅（单质→化合物，化合价必变） |
| 复分解反应可能是氧化还原反应 | ❌ 一定不是（阴阳离子互换，无变价） |
| 有单质参加的化合反应一定是氧化还原反应 | ✅ |
| 有单质生成的分解反应一定是氧化还原反应 | ✅ |
| 有单质参加或生成的化学反应一定是氧化还原反应 | ❌（**同素异形体转化**：单质→单质，无变价，如 3O₂ ⇌ 2O₃） |

> 记忆点：单质⇌化合物必伴随变价；单质→单质不一定变价。

#### 5. 电子转移表示法（一）——双线桥法
例：`MnO₂ + 4HCl(浓) --Δ--> MnCl₂ + Cl₂↑ + 2H₂O`
- 箭头连接反应前后**有化合价变化的同种元素**的原子，由反应物指向生成物，并注明「得到」/「失去」。
- 箭头方向**不代表**电子转移方向。
- 失去电子总数 = 得到电子总数。

#### 6. 电子转移表示法（二）——单线桥法
例：`3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O`
- 箭头从失电子元素原子指向得电子元素原子（起于化合价升高者，止于降低者）。
- 只标电子转移**总数**，不标「得到」「失去」（箭号方向已体现谁得失）。
- 线桥**不跨过「=」**。

### 题型

#### 类型Ⅰ　判断反应是否为氧化还原反应
**方法**：看化合价是否变化；置换一定是、复分解一定不是；能背常见生活/工艺反应。
- **例1**（选项综合，答案 **BEHI**）易错点逐项：
  - 小苏打作膨松剂/中和胃酸 → 非（受热分解、与 HCl 均无变价）
  - 苯酚露置变粉红 → 是（被空气氧化）
  - SO₂ 漂白纸浆 → 非（化合漂白，非氧化还原）
  - K₂Cr₂O₇ 加 NaOH 橙色→黄色 → 非（Cr₂O₇²⁻ ⇌ 2CrO₄²⁻ + 2H⁺，Cr 均为 +6）
  - 乙醛 + 新制 Cu(OH)₂ 砖红色沉淀 → 是
  - Na₂S 滴入 AgCl 浊液变黑 → 非（沉淀转化，复分解）
  - 饱和 NaCl 通 NH₃、CO₂ 析 NaHCO₃ → 非（侯氏制碱第一步）
  - 氯水光照 pH 降低 → 是（2HClO =光照= 2HCl + O₂↑）
  - 尾气催化转化 CO、NO → 是
- **例2**（古文，答案 **D**）：曾青得铁则化为铜（Fe+CuSO₄ 置换，是）；鬼火（PH₃ 燃烧 -3→+5，是）；丹砂烧之成水银（HgS 分解+化合，是）；青蒿榨汁（萃取，物理，非）。
- **反思**：不能忽视古文材料题，熟记其中常考物质俗名。

#### 类型Ⅱ　四大基本反应与氧化还原的关系判断
- **例3**（正误判断）答案：**√ × √ √ ×**，第(5)是陷阱——同素异形体转化（单质→单质）。

#### 类型Ⅲ　判断氧化反应/还原反应、氧化剂/还原剂、氧化产物/还原产物
**方法**：先标价，价升者失电子被氧化作还原剂（生成氧化产物），价降者反之。
- **例4**（2024·浙江6月选考，CH₃OH 除 NO₃⁻，答案 **C**）：
  - 无污染产物 X = N₂（不是 NO₂）；O₃ 是氧化剂，不可替换还原剂 CH₃OH。
  - CH₃OH 中 C 为 **-2** 价 → CO₂ 中 **+4**，升 6；NO₃⁻ 中 N **+5** → 0，降 5。
  - **氧化剂:还原剂 = 6:5**（此题求的是 NO₃⁻ 与 CH₃OH 物质的量比，只看 1 个 N 降 5，不乘 N₂ 的 2）。
  - 生成 1 mol CO₂ 失 6 mol e⁻；11.2 L CO₂（0.5 mol）→ 转移 3 mol e⁻ = **3Nₐ**。
  - ⭐**下角标铁律**：正向配平看反应物角标（Cr₂O₇²⁻→Cr³⁺ 每 1 个降 6）；逆向配平看产物角标。
- **例5**（2022·浙江6月选考，Na₂S₂O₃ + H₂SO₄，答案 **B**）：
  - Na₂S₂O₃ 中 2 个 +2 价 S：1 个→0 价 S（得 2e⁻，还原产物），1 个→+4 价 SO₂（失 2e⁻，氧化产物），**歧化**。
  - H₂SO₄ 中 H、S、O 均未变价，只作酸；氧化产物:还原产物 = 1:1。
  - **每 1 mol Na₂S₂O₃ 转移 2 mol e⁻**——歧化算转移电子只分析升或降**一方面**，切忌把升、降加和。

#### 类型Ⅳ　单线桥、双线桥标注正误判断
**方法**：双线桥看「是否同种元素跨接+得失电子数是否与变价原子数匹配」；单线桥还要看「箭头方向+变价原子个数」。
- **例6**（双线桥，答案 **C**）逐项：
  - A. Cl₂ + 2NaOH 歧化：应标得 1e⁻ / 失 1e⁻（不是 2e⁻，1 个 Cl₂ 中 1 个 Cl 得 1e⁻、1 个失 1e⁻）。
  - B. 5NH₄NO₃ → 4N₂ + 2HNO₃ + 9H₂O：**2 个 +5 价 N 不变价**；5 个 -3 价 N 各失 3e⁻，3 个 +5 价 N 各得 5e⁻。
  - C. 3Cu + 8HNO₃：**6 个 NO₃⁻ 不变价**；2 个 +5 价 N 各得 3e⁻ → 得 2×3e⁻ ✓。
  - D. KClO₃ + 6HCl：归中，+5 价 Cl → 0 价得 5e⁻，5 个 -1 价 Cl → 0 价各失 1e⁻，**1 个 -1 价 Cl 不变价 → KCl**。
- **例7**（单线桥，答案 **B**）逐项：
  - A. 2KClO₃：2 个 +5 价 Cl 得 6e⁻×2 = 12e⁻，应标 **12e⁻**。
  - B. 2FeCl₃ + 2KI：Fe³⁺ 得 1e⁻×2，I⁻ 失 1e⁻×2，箭头 I→Fe，标 **2e⁻** ✓。
  - C. 2F₂ + 2H₂O：箭头应 O→F，方向标反。
  - D. MnO₂ + 4HCl：**2 个 -1 价 Cl 不变价**，应标 2e⁻。
- **反思**：单线桥除了看箭头方向，还要数清到底几个原子在变价。

## 模块 2　氧化还原反应的规律 ★★★

### 内容提要

#### 一、氧化还原反应的分类及特征

| 分类 | 特征 | 实例 |
|---|---|---|
| 完全氧化还原反应 | 变价元素原子**全部**参加反应 | 4NH₃ + 5O₂ =催化剂/Δ= 4NO + 6H₂O |
| 部分氧化还原反应 | 变价元素原子**只有部分**参加 | MnO₂ + 4HCl(浓) =Δ= MnCl₂ + Cl₂↑ + 2H₂O |
| 歧化反应 | 同物质、同元素**同一价态**，反应后既升又降 | Cl₂ + 2NaOH = NaCl + NaClO + H₂O |
| 归中反应 | 同元素高、低两种价态向**中间靠拢但不交叉** | 2H₂S + SO₂ = 3S + 2H₂O |
| 自身氧化还原反应 | 氧化剂和还原剂为**同一反应物** | 2KMnO₄ =Δ= K₂MnO₄ + MnO₂ + O₂↑ |

- 注1：歧化反应**一定**是自身氧化还原，自身氧化还原**不一定**是歧化。
- 注2：歧化只发生在具有高低价态的**中间价态**元素上。F₂ 无歧化（氟电负性最大，无正化合价）。
- 注3：归中可以完全（5KI + KIO₃ + 3H₂SO₄ = 3I₂ + 3H₂O + 3K₂SO₄），也可以部分（KClO₃ + 6HCl = 3Cl₂↑ + KCl + 3H₂O）。

#### 二、氧化性、还原性强弱的判断与比较

**(1) 定义**：氧化性 = 得电子能力；还原性 = 失电子能力。
**(2) 强弱取决于得失电子的难易程度，与得失电子数目无关。**
　例：Al 失 3e⁻ 多于 Na 失 1e⁻，但金属活动性 Na > Al（更易失电子），故**还原性 Na > Al**。
**(3) 从元素价态看**：
- 最高价态——**只有氧化性**：FeO₄²⁻(+6 Fe)、HNO₃(+5 N)、浓 H₂SO₄(+6 S)、KMnO₄(+7 Mn)、K₂Cr₂O₇(+6 Cr)。
- 最低价态——**只有还原性**：金属单质、Cl⁻、Br⁻、I⁻、S²⁻ 等。
- 中间价态——**既有氧化性又有还原性**：H₂O₂、Fe²⁺、S、Cl₂、Br₂、I₂ 等。
- ⭐**中间价态体现哪种性质，取决于反应对象**：H₂O₂ 遇酸性 FeCl₂ 显氧化性→H₂O；遇酸性 FeCl₃ 既氧化又还原（被 Fe³⁺ 催化分解→H₂O+O₂）；遇酸性 KMnO₄ 显还原性→O₂。**不要经验主义地认为 H₂O₂ 只是「绿色氧化剂」，遇 LiCoO₂、KMnO₄ 时它可能是「绿色还原剂」**。

**(4) 依据反应原理（由强制弱）**：还原剂 + 氧化剂 = 氧化产物 + 还原产物
- 氧化性：**氧化剂 > 氧化产物**；还原性：**还原剂 > 还原产物**。
- ⚠️ 例外 i：电解反应不遵循（电解熔融 NaCl 不能说氧化性 NaCl > Cl₂）。
- ⚠️ 例外 ii：高温高压某些反应不遵循（高温 Na 制 K，不能说还原性 Na > K）。

**(5) 依据元素周期表/周期律**：
- 同主族非金属 上→下：非金属性减弱、单质氧化性减弱、阴离子还原性增强：`F₂ > Cl₂ > Br₂ > I₂`（氧化性递减），`F⁻ < Cl⁻ < Br⁻ < I⁻`（还原性递增）。
- 同主族金属 上→下：金属性增强、单质还原性增强、阳离子氧化性减弱：`Li < Na < K < Rb < Cs`（还原性递增），`Li⁺ > Na⁺ > K⁺ > Rb⁺ > Cs⁺`（氧化性递减）。
- 同周期主族 左→右：金属单质还原性减弱、非金属单质氧化性增强：`Na Mg Al | Si P S Cl₂`（左→右，单质还原性减弱、氧化性增强）。
- ⚠️ **非金属性 ≠ 氧化性**：非金属性研究气态基态原子的得电子能力；氧化性研究具体单质/化合物。N 非金属性很强，但 N₂ 氧化性弱——因为 N≡N 键能大，先断键难。

**(6) 依据被氧化（被还原）的程度**：
- 同还原剂被不同氧化剂氧化，**氧化产物价态高**者，该氧化剂氧化性强：`2Fe + 3Cl₂ =Δ= 2FeCl₃`，`Fe + S =Δ= FeS` ⇒ 氧化性 Cl₂ > S。
- 同氧化剂被不同还原剂还原，**还原产物价态低**者，该还原剂还原性强：`Cu + 2Fe³⁺ = Cu²⁺ + 2Fe²⁺`，`3Zn + 2Fe³⁺ = 3Zn²⁺ + 2Fe` ⇒ 还原性 Zn > Cu。

**(7) 依据电化学原理**：
- 原电池：金属还原性 **负极 > 正极**。两个例外——Fe-Cu 遇浓硝酸（Fe 钝化作正极、Cu 作负极）；Al-Mg 遇 NaOH（Al 作负极、Mg 作正极）。
- 电解：阴极先放电的阳离子氧化性强：`Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺(酸) > Pb²⁺ > Sn²⁺ > Zn²⁺ > Al³⁺ > Mg²⁺ > Na⁺ > Ca²⁺ > K⁺`。
- 阳极先放电的阴离子还原性强：`S²⁻ > SO₃²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻`（口诀「牛雅典秀绿箭」）。

#### 三、氧化还原反应的特殊规律

**(1) 归中规律：同种元素化合价升降可以靠拢，但不能交叉。**
例：KClO₃ + 6HCl = 3Cl₂↑ + KCl + 3H₂O
- 正确分析：+5 价 Cl 与 -1 价 Cl **都变成 0 价**；Cl₂ 既是氧化产物又是还原产物；每生成 3 mol Cl₂ 转移 **5Nₐ**。
- 错误分析：+5 价 Cl → KCl 中 -1 价、-1 价 Cl → Cl₂ 中 0 价（Cl 化合价交叉）❌。

**(2) 歧化规律——「邻价原则」**：绝大多数歧化反应，变价元素的化合价往**相邻价态**变化。
| 中间价态 | 方程式 |
|---|---|
| 过氧化物(-1 价 O) | 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑；2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂；2H₂O₂ =催化剂= 2H₂O + O₂↑ |
| Cl₂(0 价) | Cl₂ + H₂O ⇌ HCl + HClO；Cl₂ + 2NaOH = NaCl + NaClO + H₂O；2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O |
| NO₂(+4 价 N) | 2NO₂ + 2NaOH = NaNO₂ + NaNO₃ + H₂O |
| Cu₂O(+1 价 Cu) | Cu₂O + H₂SO₄ = Cu + CuSO₄ + H₂O |
| Na₂S₂O₃(+2 价 S) | Na₂S₂O₃ + H₂SO₄ = Na₂SO₄ + S↓ + SO₂↑ + H₂O |

- 例外一（**加热**打破邻价）：`3Cl₂ + 6NaOH =Δ= 5NaCl + NaClO₃ + 3H₂O`；`3S + 6NaOH =Δ= 2Na₂S + Na₂SO₃ + 3H₂O`。
- 例外二（**邻价产物极不稳定**，进一步歧化）：`3NO₂ + H₂O = NO + 2HNO₃`；`2S₂Cl₂ + 2H₂O = 4HCl + SO₂↑ + 3S↓`。

### 题型

#### 类型Ⅰ　依据反应原理判断氧化性、还原性强弱
**方法**：逐反应标出「氧化剂(↓)、还原剂(↑)、氧化产物(↑)、还原产物(↓)」，由「氧化剂>氧化产物、还原剂>还原产物」搭链条。
- **例1**（三个反应，答案 **C**）：氧化性 `XO₄⁻ > Z₂ > B₂ > A³⁺`；还原性 `A²⁺ > B⁻ > Z⁻ > X²⁺`。由「两个由强制弱必须同时满足」判断新反应 2A²⁺ + Z₂ 可自发。
- **例2**（转化关系图 Ce⁴⁺/Mn³⁺/Fe³⁺/I₂，答案 **D**）：由箭头写三个方程式，得氧化性 `Ce⁴⁺ > Mn³⁺ > Fe³⁺ > I₂`，还原性 `I⁻ > Fe²⁺ > Mn²⁺ > Ce³⁺`；写方程式还要检查化合价升降守恒、电荷守恒。

#### 类型Ⅱ　利用氧化性、还原性判断反应能否发生
**方法**：强氧化剂能制弱氧化剂（同时要满足还原性由强制弱）；**也要利用「无法发生」的反应反推强弱**。
- **例3**（氧化性 Co₂O₃ > Cl₂ > FeCl₃ > I₂，答案 **C**）：
  - FeCl₃ > I₂ 且 I⁻ > Fe²⁺ ⇒ Fe³⁺ 能氧化 I⁻ 生成 I₂ 使淀粉 KI 试纸变蓝 ✓。
  - **FeI₃ 不存在**：Fe³⁺ 与 I⁻ 不能大量共存。
  - **1 mol Co₂O₃ 被还原成 Co²⁺ 转移 2 mol e⁻**（2 个 +3 价 Co，注意角标）。
  - 还原性顺序 I⁻ > Fe²⁺ > Cl⁻ > Co²⁺，「谁强谁优先」。
- **例4**（Pb₃O₄，答案 **D**）：
  - Pb₃O₄ 可写为 2PbO·PbO₂；反应 I 中 NO₃⁻ 未参与 → 非氧化还原，+2 价 Pb : +4 价 Pb = **2:1**（类比 Fe₃O₄ 中 Fe²⁺:Fe³⁺ = 1:2）。
  - 反应 II 得 PbO₂ > MnO₄⁻；反应 I 知 HNO₃ < PbO₂。
  - 酸性条件下 KMnO₄ 可氧化 HCl 制 Cl₂ ⇒ MnO₄⁻ > Cl₂；又 PbO₂ > MnO₄⁻ ⇒ PbO₂ > Cl₂，故 Pb₃O₄ + 8HCl = 3PbCl₂ + 4H₂O + Cl₂↑ ✓。
  - 同族稳价规律：周期数越大，低价越稳定，高价有强氧化性（如 +5 价 Bi、+3 价 Tl）。
- **反思**：既利用「能发生」也利用「不能发生」的反应判断强弱。

#### 类型Ⅲ　利用强弱判断反应先后顺序（谁强谁优先）
**方法**：还原性强的先被氧化、氧化性强的先被还原；以物质的量比分段讨论。
- **例5**（FeBr₂ 溶液通 Cl₂，答案 **C**）：还原性 **Fe²⁺ > Br⁻**（必记）。
  - 设比值 r = n(Cl₂)/n(FeBr₂)：
    - r ≤ 1/2：只氧化 Fe²⁺（2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻）。
    - 1/2 < r < 3/2：Fe²⁺ 完全氧化，Br⁻ 部分氧化。
    - r ≥ 3/2：Fe²⁺ 和 Br⁻ 皆完全氧化（2Fe²⁺ + 4Br⁻ + 3Cl₂ = 2Br₂ + 2Fe³⁺ + 6Cl⁻）。
  - 分段验证：r = 0.4 ✓；r = 0.6 时设 FeBr₂ = 10 mol、Cl₂ = 6 mol，10 mol Fe²⁺ 耗 5 mol Cl₂，剩 1 mol Cl₂ 氧化 2 mol Br⁻ ⇒ 10Fe²⁺ + 2Br⁻ + 6Cl₂ = Br₂ + 12Cl⁻ + 10Fe³⁺ ✓；r = 1 应写 2Fe²⁺ + 2Br⁻ + 2Cl₂ = Br₂ + 2Fe³⁺ + 4Cl⁻（C 错）。
- **反思**（量变引起质变常考清单）：
  - **FeI₂ 与 Cl₂**：r ≤ 1 只氧化 I⁻；1 < r < 3/2 时 I⁻ 完全、Fe²⁺ 部分；r ≥ 3/2 皆完全。
  - **NH₄HSO₄ 与 NaOH**：r ≤ 1 只中和 H⁺；1 < r < 2 时 H⁺ + NH₄⁺；r ≥ 2 时 H⁺、NH₄⁺ 均反应。
  - **AlCl₃ 与 NaOH**：r ≤ 3 生成 Al(OH)₃；3 < r < 4 时 Al(OH)₃ 部分溶解；r ≥ 4 全溶为 [Al(OH)₄]⁻。
  - **Na[Al(OH)₄] 与 HCl**：r ≤ 1 生成 Al(OH)₃；1 < r < 4 时 Al(OH)₃ 部分溶解；r ≥ 4 全部 → Al³⁺。

#### 类型Ⅳ　设计实验验证氧化性、还原性强弱
- **例6**（Fe²⁺/Fe³⁺ 铁-石墨原电池）：
  - 电子由铁电极流向石墨 → Fe 为负极、石墨为正极；盐桥阳离子流向**正极（石墨）**（口诀「正正负负」）。
  - 负极 Fe − 2e⁻ = Fe²⁺；正极 Fe³⁺ + e⁻ = Fe²⁺。得失电子守恒：Fe²⁺ 增 0.02 mol/L ⇒ 石墨侧 Fe²⁺ 增 0.04，总 0.05 + 0.04 = **0.09 mol/L**。
  - 结论：**Fe³⁺ 氧化性 > Fe²⁺；Fe 还原性 > Fe²⁺**。

## 模块 3　氧化还原方程式配平 ★★★

### 内容提要

**一、化学方程式配平步骤（三步）**
1. 标变价、列变化、找最小公倍数、定系数——决定还原剂/氧化剂系数，同时配平产物的变价元素。
2. **未变价元素原子守恒**——部分氧化还原反应中既变价又不变价的元素，以及除 H、O 外的未变价元素。
3. **看 H 补水、用 O 检查**——H 原子守恒定 H₂O 的位置与个数，最后检查 O 守恒；若题目无 H 或 O，第二步即完成。

**二、离子方程式配平步骤（三步）**
1. 标变价、列变化、找倍数、定系数。
2. **电荷守恒**——酸性用 H⁺、碱性用 OH⁻ 调平；未明确酸碱时「水出酸或碱」（H⁺ 或 OH⁻ 写在方程式右侧）。
3. H 守恒定 H₂O、O 守恒检查。

**三、配平顺序总规则**
- 完全氧化还原反应、归中反应 → **正向配平**。
- 部分氧化还原反应、歧化反应 → **逆向配平**。
- **正向配平注意反应物角标，逆向配平注意生成物角标**（变价原子有角标时化合价变化要乘角标）。

**四、找倍数**
- 先找**最小公倍数**避免非最简比；计量数出现分数时最后整体扩倍成最简整数比。

**五、有机化合物配平三法**
- **平均值法**：将有机物 H、O 分别规定为 +1、-2 价，由正负化合价代数和为零求 C 的平均价态。
- **组成法**：多 1 个 O 或少 2 个 H → 化合价升 2（氧化）；多 2 个 H 或少 1 个 O → 化合价降 2（还原）。
- **燃烧法**（只含 C、H、O 且平均价态为分数时）：有机物与 O₂ 反应生成 CO₂、H₂O，有机物系数定为 1，仅按原子守恒配平，转移电子数 = O₂ 系数 × 4。

**六、有机物配平顺序**：有机物中 H 往往多于 O → **用 O 原子守恒定 H₂O**，最后用 H 原子守恒检查。

### 题型

#### 类型Ⅰ　完全氧化还原反应的配平（正向配平法）
- **例1**：`2MnO₄⁻ + 5NO₂⁻ + 6H⁺ = 2Mn²⁺ + 5NO₃⁻ + 3H₂O`（Mn 降 5、N 升 2 → 2:5；电荷守恒左补 6H⁺）。
- **例2**：`4NaIO₃ + 10NaHSO₃ = 2I₂ + 7Na₂SO₄ + 3H₂SO₄ + 2H₂O`（I 降 5、S 升 2 → 2:5；Na 守恒定 NaIO₃ = 4、NaHSO₃ = 10、Na₂SO₄ = 7）。
- **例3**：`2KMnO₄ + 10FeSO₄ + 8H₂SO₄ = K₂SO₄ + 2MnSO₄ + 5Fe₂(SO₄)₃ + 8H₂O`（升降守恒 2:10 使 Fe₂(SO₄)₃ 为整数；K、S 守恒定 K₂SO₄ = 1、H₂SO₄ = 8）。

#### 类型Ⅱ　部分氧化还原反应（逆向配平法）
- **例4**：`3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O`（逆向先定氧化产物 3、还原产物 2；Cu、N 守恒）。
- **例5**：`2NaNO₂ + 4HI = 2NO↑ + I₂ + 2NaI + 2H₂O`（逆向：NO = 2、I₂ = 1；Na、I 守恒定 NaNO₂ = 2、HI = 4）。
- **例6**：`3Fe₃O₄ + 28HNO₃ = 9Fe(NO₃)₃ + NO↑ + 14H₂O`（Fe₃O₄ 中 Fe 平均价 +8/3，降 1/3；N 升 3 → 产物比 9:1；Fe、N 守恒得 3、28）。

#### 类型Ⅲ　反应物含「角标」的完全氧化还原反应
- **例7**：`K₂Cr₂O₇ + 3H₂O₂ + 4H₂SO₄ = K₂SO₄ + Cr₂(SO₄)₃ + 3O₂↑ + 7H₂O`（K₂Cr₂O₇ 2 个 +6 Cr 共降 6；H₂O₂ 2 个 -1 O 共升 2 → 1:3）。
- **例8**：`10NaN₃ + 2KNO₃ = K₂O + 5Na₂O + 16N₂↑`（NaN₃ 中 N 均价 -1/3，3 个 N 都→0，NaN₃ 共升 1；KNO₃ 降 5 → 5:1，扩倍为 10:2 使 K₂O 系数为整数）。

#### 类型Ⅳ　同一反应物含多种变价元素
- **例9**：`15ClO₃⁻ + FeS₂ + 14H⁺ = 15ClO₂↑ + Fe³⁺ + 2SO₄²⁻ + 7H₂O`（FeS₂：Fe +2→+3 升 1、S -1→+6 升 7×2 = 14，**共升 15**；ClO₃⁻ 中 Cl +5→+4 降 1 → 15:1；电荷守恒左补 14H⁺）。
- **例10**：`2ClO₂ + 2CN⁻ + 4OH⁻ = 2CO₃²⁻ + N₂ + 2Cl⁻ + 2H₂O`（**CN⁻ 中 C、N 化合价判断**：电负性 N > C，N 取最低价 -3，则 C 为 +2；CN⁻ 共升 5（C +2→+4 升 2、N -3→0 升 3），ClO₂ 中 Cl +4→-1 降 5 → 1:1，扩倍使 N₂ 为整数）。

#### 类型Ⅴ　歧化反应的配平（逆向）
- **例11**：`3S + 6KOH = 2K₂S + K₂SO₃ + 3H₂O`（逆向：K₂S←S 升 2，K₂SO₃←S 降 4 → 2:1；S 守恒得 S = 3；K 守恒 KOH = 6）。
- **例12**：`2P₄ + 3Ba(OH)₂ + 6H₂O = 3Ba(H₂PO₂)₂ + 2PH₃↑`（逆向注意产物角标：Ba(H₂PO₂)₂ 中 2 个 +1 价 P → 0 价共降 2；PH₃ 中 -3 价 P → 0 价升 3 → 3:2；P 守恒 P₄ = 2）。
- **反思**：正向配平乘反应物角标，逆向配平乘生成物角标。

#### 类型Ⅵ　含有机化合物的配平
- **例13**：`CH₃CHO + 2Cu(OH)₂ + NaOH =Δ= CH₃COONa + Cu₂O↓ + 3H₂O`（醛基→羧基多 1 O，C 升 2；Cu(OH)₂→Cu₂O 降 1 → 1:2；**用 O 守恒补水，H 检查**）。
- **例14**：`2K₂Cr₂O₇ + 3CH₃CH₂OH + 8H₂SO₄ = 2Cr₂(SO₄)₃ + 3CH₃COOH + 2K₂SO₄ + 11H₂O`（—CH₂OH→—COOH 少 2 H 升 1、多 1 O 升 2，共升 4；K₂Cr₂O₇ 降 6 → 2:3；K、S 守恒）。
- **例15**：`C₆H₅CH₃ + 2KMnO₄ =Δ= C₆H₅COOK + 2MnO₂ + KOH + H₂O`（—CH₃→—COOH 少 2 H 多 2 O，C 升 6；KMnO₄→MnO₂ 降 3 → 1:2；—COOK 是 —COOH 与 KOH 中和产物，不算氧化还原）。

#### 类型Ⅶ　特殊技巧
- **例16**（零价法）：`Fe₃C + 22HNO₃ = 3Fe(NO₃)₃ + CO₂↑ + 13NO₂↑ + 11H₂O`（无法确定 Fe、C 化合价时假设均为 0：3 Fe 升 9、C 升 4，共升 13；HNO₃ 中 N +5→+4 降 1 → 1:13；N 守恒 22 = 3×3 + 13）。
- **例17**（设价消元法）：`4CuSCN + 7KIO₃ + 14HCl = 4CuSO₄ + 4HCN + 7ICl + 7KCl + 5H₂O`（假设 Cu 保持 +2、C、N 化合价共 -1 不变，则 S -1→+6 升 7；KIO₃ 中 I +5→+1 降 4 → 4:7；把复杂变价集中到 S 和 I 两种元素）。

## 模块 4　新情景下氧化还原反应方程式的书写 ★★★

### 内容提要

**一、书写步骤（五步法）**
1. 判断是否氧化还原反应；若是，立即**「写四样」**——氧化剂、还原剂、氧化产物、还原产物。
2. **「平四样」**：按配平三步先配平变价部分。
3. 补上含**未变价元素**的反应物/生成物（强酸性环境中金属元素产物一般以盐的形式存在）。
4. 溶液体系用 H⁺/OH⁻ 调平电荷。
5. 看 H 补 H₂O、用 O 检查；写上反应条件。

**二、书写关键——熟记常见氧化剂/还原剂及对应产物**

**1. 常见氧化剂及还原产物预测**

#### 类型Ⅰ　根据文字信息书写陌生方程式
**方法**：写四样→平四样→补未变价元素→电荷守恒→H/O 守恒。
- **例1**（LiCoO₂ 浸出）：`2LiCoO₂ + H₂O₂ + 3H₂SO₄ = Li₂SO₄ + 2CoSO₄ + O₂↑ + 4H₂O`。⭐H₂O₂ 产物判断是热点：Co +3→+2 降 ⇒ H₂O₂ 中 O 升 → 产物为 **O₂**。
- **例2**（Re + 稀硝酸）：`3Re + 4H⁺ + 7NO₃⁻ = 3ReO₄⁻ + 7NO↑ + 2H₂O`。稀硝酸还原产物 NO **必记**（题目不给）；HReO₄ 强酸拆为 H⁺ + ReO₄⁻。
- **例3**（Ni²⁺ + ClO⁻ 强碱）：`2Ni²⁺ + ClO⁻ + 4OH⁻ = 2NiOOH↓ + Cl⁻ + H₂O`。沉淀不拆；含氯氧化剂默认→Cl⁻。
- **例4**（二苯铬还原）：`2[(C₆H₆)₂Cr]⁺ + S₂O₄²⁻ + 4OH⁻ = 2(C₆H₆)₂Cr + 2SO₃²⁻ + 2H₂O`。电荷 +1→0 推出 Cr 降 1（不必细算 C、H 价）。
- **例5**（同一物质含两种变价元素）：`2FeO·Cr₂O₃ + 4Na₂CO₃ + 7NaNO₃ =高温= 4Na₂CrO₄ + Fe₂O₃ + 7NaNO₂ + 4CO₂↑`（Fe 升 1、Cr 升 3×2 = 6，共升 7；N +5→+3 降 2 → 2:7）。
- **例6**（三种物质变价）：`6FePO₄ + 3Li₂CO₃ + C₆H₁₂O₆ =高温= 9CO↑ + 6H₂O↑ + 6LiFePO₄`（由 n(Fe):n(Li) = 1:1 锁定 FePO₄:Li₂CO₃ = 2:1，再升降守恒）。

#### 类型Ⅱ　根据流程图书写陌生方程式
**方法**：读流程定位氧化剂/还原剂/产物（图、文字、已知信息综合推断）。
- **例7**（2024·安徽卷，Au 浸取）：`2Au + 8HCl + 3H₂O₂ = 2HAuCl₄ + 6H₂O`（Au 0→+3 升 3；H₂O₂→H₂O 降 2 → 2:3；Cl 守恒补 8 HCl）。
- **例8**（两性元素 Ga）：`GaAs + 2OH⁻ + 4H₂O = [Ga(OH)₄]⁻ + AsO₂⁻ + 3H₂↑`（类比 Al(OH)₃ 两性；As -3→+3 升 6，H₂ 中 H 降 1×2 ⇒ GaAs:H₂ = 1:3）。若按 NaAlO₂ 式教学则写 `GaAs + 2OH⁻ + 2H₂O = GaO₂⁻ + AsO₂⁻ + 3H₂↑`。
- **例9**（菱锰矿煅烧）：`2Li₂CO₃ + 8MnO₂ =高温= 4LiMn₂O₄ + 2CO₂↑ + O₂↑`。⭐正向配平不好判断哪个 -2 价 O 升价时，**改用逆向配平**常可迎刃而解。
- **例10**（黄铜矿）：`CuFeS₂ + 3Fe³⁺ + Cl⁻ = 4Fe²⁺ + CuCl + 2S`（难定 Cu、Fe 价时**假设 CuFeS₂ 中全部元素 0 价**简化配平）。

#### 类型Ⅲ　根据实验信息书写陌生方程式
- **例11**（NaClO₂ 制备）：
  - 装置 A：`2NaClO₃ + Na₂SO₃ + H₂SO₄ = 2ClO₂↑ + 2Na₂SO₄ + H₂O`（Cl +5→+4 降 1；S +4→+6 升 2 → 2:1）。
  - 装置 C：`2ClO₂ + H₂O₂ + 2NaOH = 2NaClO₂ + O₂ + 2H₂O`（Cl 降 ⇒ H₂O₂ 中 O 升为 O₂）。
- **例12**（MnCO₃ 制备）：
  - ①`MnO₂ + H₂C₂O₄ + 2H⁺ = 2CO₂↑ + Mn²⁺ + 2H₂O`（H₂C₂O₄ 氧化产物 CO₂ **必记**）。
  - ②`MnSO₄ + 2NH₄HCO₃ = MnCO₃↓ + CO₂↑ + H₂O + (NH₄)₂SO₄`——**沉锰离子方程式**（Mn²⁺ + 2HCO₃⁻ = MnCO₃↓ + CO₂↑ + H₂O）考查频率极高，需记忆，非氧化还原反应。

#### 类型Ⅳ　根据反应机理书写陌生方程式
**方法**：箭头指入循环图 = 反应物，箭头指出 = 生成物（含催化剂、略去的物质），先写计量数比再化简 + 补条件。
- **例13**（NH₃ 脱 NO，Fe³⁺ 催化）：`4NH₃ + 4NO + O₂ =催化剂= 4N₂ + 6H₂O`。
- **例14**（NaClO 氧化 NH₃ 除氨氮）：`2NH₃ + 3ClO⁻ = N₂ + 3H₂O + 3Cl⁻`（NaCl、H₂O 略去）。

## 模块 5　氧化还原反应的计算 ★★★

### 内容提要

核心：**电子得失守恒**（氧化剂得电子总数 = 还原剂失电子总数）。思维流程：
1. **确定两剂两产物**：找出氧化剂、还原剂及对应还原产物、氧化产物。
2. **判断电子得失数**：只关注化合价变化元素，忽略不变价元素，**注意化学式中变价元素的原子个数**。
　例：K₂Cr₂O₇ → Cr₂(SO₄)₃，2 个 +6 价 Cr → 2 个 +3 价 Cr 共得 6e⁻，故 1 mol K₂Cr₂O₇ 得 6 mol e⁻。
3. **列等式求解**：`n(氧化剂) × 每摩尔氧化剂得电子数 = n(还原剂) × 每摩尔还原剂失电子数`

### 题型

#### 类型Ⅰ　转移电子数计算
- **例1**（黄血盐制备）：Fe + 6HCN + 2K₂CO₃ = K₄Fe(CN)₆ + H₂↑ + 2CO₂↑ + 2H₂O。2 个 +1 价 H → H₂，关系式 **2e⁻ ~ 1H₂**；2.24 L H₂ = 0.1 mol ⇒ 转移 0.2 mol e⁻ = **0.2Nₐ**。技巧：把 H₂ 拆成 2 个 0 价 H、Na₂O₂ 拆成 2 个 -1 价 O 逐个看。
- **例2**（2023·湖南卷改编，雌黄 As₂S₃ 褪色，答案 3:7）：
  - 反应 I：S -2→+2，3 mol S 失 3×4 = 12 mol e⁻（As 不变）。
  - 反应 II：2 mol As +3→+5 失 4 mol，3 mol S -2→+6 失 24 mol，共 28 mol。
  - 氧化 1 mol As₂S₃ 转移电子数之比 **12:28 = 3:7**。
- **例3**（2024·东北三省卷，硫转化关系，答案 **D**）：
  - A. 11.2 L SO₂ = 0.5 mol，3 原子/分子 → 1.5Nₐ，错。
  - B. SO₃²⁻ 水解 ⇒ 数目 < 0.01Nₐ，错。
  - C. 反应① SO₂ + 2H₂S = 3S + 2H₂O，3.4 g H₂S = 0.1 mol ⇒ 0.15 mol S = 0.15Nₐ，错。
  - D. 反应② 3S + 6OH⁻ =Δ= SO₃²⁻ + 2S²⁻ + 3H₂O，还原产物 S²⁻，1 mol S⁰→S⁻² 转移 **2Nₐ**，对。

#### 类型Ⅱ　电子得失守恒（化合价升降守恒）计算
- **例4**（NaClO₂ 歧化制 ClO₂）：歧化中 `5NaClO₂ ~ 4ClO₂ ~ 1NaCl`（4 个失 1e⁻ 各→ClO₂，1 个得 4e⁻→Cl⁻）。每生成 1 mol ClO₂ 消耗 **1.25 mol NaClO₂**。⭐歧化计算把得电子方与失电子方并排看。
- **例5**（Cu + 浓硝酸混合气体 + O₂ 通水，答案 **A 60 mL**）：
  - N 元素起点终点均为 HNO₃，**过程净得失为零** ⇒ 整个反应可视为 Cu 失去的电子全部转移给 O₂。
  - n(Cu)×2 = n(O₂)×4 ⇒ n(Cu) = 1.68/22.4 × 2 = 0.15 mol；Cu²⁺ ~ 2NaOH ⇒ n(NaOH) = 0.3 mol ⇒ V = 0.3/5 = 0.06 L = **60 mL**。
  - 方法：反应链太长时，找「首尾元素」整体看电子得失。
- **例6**（Cu/Cu₂O + 稀硝酸 + NaOH，答案 **D**）：
  - 中性 ⇒ 溶质只有 NaNO₃ ⇒ n(NaNO₃) = 1 mol（Na 守恒）。
  - 沉淀 Cu(OH)₂ 39.2 g = 0.4 mol；设 Cu = x、Cu₂O = y：64x + 144y = 27.2、x + 2y = 0.4 ⇒ x = 0.2、y = 0.1（A 正确，2:1）。
  - B：3×n(NO) = 2×0.2 + 2×0.1 ⇒ n(NO) = 0.2；n(HNO₃) = n(NO) + n(NaNO₃) = 1.2 ⇒ c = 1.2/0.5 = **2.4 mol/L** ✓。
  - C：0.2 mol NO = 4.48 L ✓。
  - D：n(HNO₃ 剩余) = n(NaNO₃) − 2×n[Cu(NO₃)₂] = 1 − 0.8 = **0.2 mol**（不是 0.6）❌。

## 提炼要点速览（P2/P3 直接引用）

1. 判断依据只有一条：**化合价是否变化**。
2. 五类反应判定：完全/部分/歧化/归中/自身——注意歧化⊆自身氧化还原、F₂ 无歧化。
3. 强弱比较四法：反应原理（由强制弱 + 电解/高温例外）、周期表、反应程度、电化学；配位记忆放电顺序与口诀。
4. 配平三步：升失列变找倍数 → 未变价元素守恒（离子式用 H⁺/OH⁻ 调电荷）→ 看 H 补水用 O 检查；正逆方向按反应类型选；角标规矩「正向看反应物、逆向看产物」。
5. 有机物：平均值法/组成法/燃烧法；「多 O 升、少 H 升」；H 多 O 少时用 O 守恒定水。
6. 新情景书写核心：**「写四样」** + 熟背氧化剂/还原剂产物预测表（酸性 KMnO₄→Mn²⁺、稀硝酸→NO、含氯氧化剂→Cl⁻、负价 N→N₂、-2 价 S→S 等）。
7. 计算只认**电子得失守恒**；多步反应找首尾；歧化并排看得失；角标数清变价原子。
