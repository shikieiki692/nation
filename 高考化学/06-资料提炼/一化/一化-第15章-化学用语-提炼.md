## 模块1 常考化学用语(★★)

### 一、元素符号——四个位置四个数值

- 格式 `$_a^b R_e^c$`：a=质子数=核电荷数=原子序数；b=质量数=中子数+质子数≈相对原子质量；c=化合价（**先写符号再写数值**）；d=离子所带电荷数（**先写数值再写符号**）；R=元素符号。
- **核素符号必须标注质量数**（如 ¹⁸O、¹⁴C）。

### 二、电子式

- 离子化合物：含中括号 `[ ]` 并标电荷；共价化合物：无中括号。
- 用电子式表示形成过程：离子化合物有**弯曲的电子转移箭头**；共价化合物无箭头。

**易错微粒（类型I 例1，9 例）**：

| 微粒 | 易错点 |
|------|--------|
| HClO | 中心原子是 O（H—O—Cl），O 连 H 和 Cl |
| N₂H₄ | 每个 N 需补齐孤对电子 |
| CS₂ | 与 CO₂ 等电子体，双键结构 |
| -CH₃ 甲基 | 保留**单电子**（自由基） |
| [CH₃]⁻ | 阴离子套中括号 |
| NH₄Cl | 既有离子键（NH₄⁺·Cl⁻）又有共价键（N—H） |
| CaC₂ | 双碳之间**三对共用电子对**（C≡C⁻⁻） |
| Mg₃N₂ | 两个 Mg²⁺ 恰好使 N³⁻ 外层达到稳定 |
| 甲醛 | 由结构式推导电子式（羰基 C=O + 两个 C—H） |

### 三、四"式"辨析

- **结构式**：每条共用电子对画一条"一"。
- **结构简式**：省略部分 C—H 键（如 CH₃CH₂OH）。
- **键线式**：折线端点/拐点代表碳原子，氢省略。
- **电子排布式**：轨道能级顺序+电子数，如 O：1s²2s²2p⁴。

### 四、两"图"

- **原子结构示意图**：圆圈内写质子数，弧线分层标各层电子。
- **电子排布图**：方框（轨道）+ 箭头（自旋），遵守泡利不相容与洪特规则。

### 五、三"模型"

- **球棍模型**：棍=化学键，球=原子（缩小比例）。
- **空间填充模型**：按原子实际相对大小（范德华半径比例）。
- **VSEPR 模型**：含孤对电子的**完整价层构型**（如 NH₃ 为四面体）vs 空间结构（三角锥）——**VSEPR 是"填上孤对"的构型，空间结构是"挖掉孤对"后只看成键原子的形状**。

### 类型II 高考真题要点（可追溯，明细见表格）

- 例2 2024浙江1月：主链选择必须**最长**，2,4-二甲基己烷（误数会成 2,4-二甲基庚烷）。
- 例3 2024湖北：亚铜氨配离子中 Cu 为 **+1 价**而非 +2 价。
- 例4 2024东北三省：F₂ 为 p-p **σ 键**（沿键轴头碰头重叠）；核素符号须有质量数。
- 例5 2024山东：O₃ 为 **V 形**（中心 O 有孤对）；不存在 1p 轨道；π 键轨道镜面对称。
- 例6 2023湖南：HClO 中心原子为 **O**；NH₃ 的 VSEPR 模型是四面体（含孤对），空间结构才是三角锥。
