## 模块1 常见物质性质、原理的应用(★★)

### 一、常见无机物质的性质及其应用

**1-4 节（碱金属/碱土/B族 Al/碳族）要点**：
- **氢**：H₂ 作保护气/还原剂（还原金属氧化物）；**Li**：密度最小，锂电池负极；**Na**：制钠钾合金（快堆导热）、冶炼贵金属；**K**：钾肥。
- **Mg**：照明弹/信号弹（强白光）；**Ca**：干燥剂/牙膏摩擦剂。
- **Al**：铝热剂焊接、耐腐蚀、轻合金（飞机）。
- **碳族**：C 金刚石切割/石墨电极；**Si** 半导体→芯片/太阳能电池；**Ge** 半导体材料；**Pb** 铅蓄电池电极。

**5. 氮族**：

| 对象 | 性质 | 应用 |
|------|------|------|
| N | 蛋白质重要组成，植物三大营养元素（N、P、K） | 生物/自然/人工固氮：游离态→化合态 |
| N₂ | 化学性质稳定 | 保护气防止氧化 |
| 氮氧化物 | 与水作用产硝酸；汽车尾气光照反应 | 酸雨；光化学烟雾 |
| NH₃ | 液氨易汽化吸大量热；碱性和还原性 | 制冷剂；检验氯气管道漏气 |
| N₂H₄ | 强还原性、燃烧放热大、产物无毒 | 火箭/燃料电池高能燃料 |
| NaN₃ | 撞击生成大量氮气 | 汽车安全气囊 |
| 铵盐 | 水解弱酸性；铵根易被土壤吸附 | 除锈剂；化肥 |
| NaNO₂ | 微量能杀菌消毒；**剧毒** | 食品防腐剂；工业盐不可食用 |
| P | 水体 P 过多→藻类疯长 | 富营养化、赤潮、水华 |
| P₂O₅ | 易吸水 | 干燥剂（**不可干燥食品**） |

**6. 氧族**：

| 对象 | 性质 | 应用 |
|------|------|------|
| O₂ | 强氧化性（助燃） | 助燃剂；高压氧舱治 CO 中毒 |
| O₃ | 被氟利昂释放的 Cl 原子破坏 | 氯氟烃→臭氧层空洞 |
| H₂O₂ | 强氧化性、漂白性 | 伤口消毒；漂白纸张织物 |
| 过氧乙酸 | 强氧化性 | 环境杀菌消毒 |
| S | 易与汞结合 | 水银洒落撒硫粉 |
| SO₂ | 漂白、较强还原性、与水生成酸 | 漂白；果酒抗氧化剂；酸雨（pH<5.6） |
| 浓 H₂SO₄ | 吸水性、高沸点 | 干燥剂；制低沸点酸（盐酸、氢溴酸） |

**7. 卤素**：

| 对象 | 性质 | 应用 |
|------|------|------|
| HF | 与硅及其化合物反应生成 SiF₄ | 刻蚀玻璃、芯片 |
| Cl₂ | 与金属/粗硅/有机物反应；强氧化；与强碱生成次氯酸盐 | 冶 Ti、粗硅精炼、卤代烃、自来水消毒、制漂白粉/液 |
| ClO₂ | 强氧化性 | 自来水消毒 |
| HClO | 漂白性 | 漂白纸张织物 |
| CHCl₃ | 强溶有机物的能力 | 常用有机溶剂 |
| AgBr | 见光分解、光线变弱产物化合 | 变色眼镜 |
| AgI | 分解产生微小银粉 | 人工降雨 |
| 碘酒 | 杀菌消毒 | 伤口消毒 |

**8. 稀有气体**：He 密度小性质稳定→飞艇气球；Ne 放电橙红光→霓虹灯；Ar 性质稳定→冶炼保护气。

**9. 过渡金属**：

| 对象 | 性质 | 应用 |
|------|------|------|
| 钛合金 | 强度高、耐腐蚀 | 航空/航母/深潜器 |
| MnO₂ | 强氧化性 | 碱性锌锰干电池正极 |
| Fe | 加碳强度增大；与 Zn/Mg 相连减缓腐蚀（原电池正极）；外加电源负极连接；常温与浓硫酸浓硝酸钝化 | 建筑材料；牺牲阳极保护；外加电流保护；铁制容器储运浓硫酸浓硝酸 |
| Fe₃O₄/Fe₂O₃ | 磁性 / 红棕色 | 司南（指南针）；红色颜料 |
| FeCl₃ | 与 Cu 反应；使血浆聚沉；水解产 Fe(OH)₃ 胶体 | 腐蚀铜电路板；止血剂；净水 |
| 乳酸亚铁 | 溶于水 | 补铁（缺铁性贫血） |
| 七水硫酸亚铁 | 绿色 | 俗名绿矾 |
| K₂FeO₄ | 强氧化性 + 还原产物水解产生胶体 | 杀菌消毒 + 净水 |
| Co、Ni | 高价化合物强氧化；Ni 催化加氢 | 电池正极材料；加氢催化剂 |
| Cu | 良好导电；合金耐腐蚀 | 导体；青铜（铜锡）、黄铜（铜锌） |
| Cu(OH)₂ 新制 | 弱氧化性 | 检验还原性糖/醛基 |
| Cu²⁺（CuSO₄） | 重金属阳离子使蛋白质变性 | 泳池杀菌消毒 |
| Cu₂(OH)₂CO₃ | 不易氧化、难溶 | 铜绿、孔雀石（绿色颜料） |
| Zn | 强还原性 | 电池负极材料 |
| Ag | 良好导电/催化剂；与硫化物生成黑色 Ag₂S | 导线；催化氧化；除 Ag₂S 用铝+NaOH |

**10. 胶体**：

| 性质 | 应用 |
|------|------|
| 丁达尔效应 | 区别胶体和溶液 |
| 聚沉 | 三角洲形成；不同品牌墨水不混用；石膏点豆腐；FeCl₃ 止血；明矾/铁盐净水 |
| 电泳 | 静电除尘；蛋白质分离提纯 |
| 渗析 | 血液透析；分离胶体和溶液 |

### 二、常见有机物的性质及其应用

**1. 烃**：甲烷—清洁燃料/卤代烃制备/沼气（生物质能/可再生）；烷烃—燃气灶改烧气时调节空气量；乙烯—催熟剂、聚乙烯无毒可食品包装；乙炔—氧炔焰焊接切割、聚乙炔导电塑料；苯—有机溶剂。

**2. 卤代烃**：氯仿/CCl₄ 有机溶剂、CCl₄ 萃取剂；一氯乙烷液态冷冻麻醉；聚氯乙烯难降解→白色污染；聚四氟乙烯（塑料王）→不粘锅涂层/人造血浆；氟利昂→臭氧层空洞。

**3. 含氧衍生物**：甲醇剧毒（工业酒精不可食用）；乙醇 70~75% 医用酒精+燃料；乙二醇防冻液（任意比互溶降冰点）；甘油（丙三醇）吸湿→保湿霜；苯酚易溶于酒精（腐蚀用酒精擦洗）；甲醛 35~40% 福尔马林→标本防腐；醋酸→除水垢/调味/增香（酯化）；酯→香料/溶剂。

**4. 营养物质**：葡萄糖→低血糖急救/酒化酶→乙醇→乙酸（果酒果醋）；蔗糖→果糖+葡萄糖、麦芽糖→葡萄糖；多糖—纤维素不可消化（膳食纤维）、淀粉易水解、植物纤维吸水性（干燥剂/醋酸纤维素）；氨基酸→注氨基酸增抵抗力；谷氨酸钠→味精；蛋白质—灼烧气味鉴别化纤羊毛、加热变性（疫苗低温保存）、含苯基遇浓硝酸变黄、盐析分离提纯；油脂—植物油氢化→人造奶油、皂化反应制肥皂、防水解防氧化、反复加热产稠环芳烃有毒、地沟油制肥皂；阿司匹林（乙酰水杨酸）酸性→酸中毒注射 NaHCO₃ 解毒。

### 三、化学中的各种"剂"

- **助燃剂**：O₂、Cl₂、NO₂ 等氧化剂
- **阻燃剂**：Al(OH)₃、Mg(OH)₂
- **干燥剂**：无水 CaCl₂、碱石灰等
- **抗氧化剂**：还原性铁粉、VC
- **营养增强剂**：KIO₃、维生素、葡萄糖酸锌
- **防腐剂**：亚硝酸钠、苯甲酸钠
- **膨松剂**：NaHCO₃、NH₄HCO₃
- **止血剂**：FeCl₃
- **双吸剂**：铁粉、生石灰、C、NaCl
- **调味剂**：谷氨酸钠、食醋
- **泡沫灭火剂**：Al₂(SO₄)₃ + NaHCO₃
- **84 消毒剂**：NaClO

> 例 1(2024山东)：P₂O₅ 可作干燥剂但不能作食品干燥剂（与水生成腐蚀/有毒物质）→ 答案 D。
> 例 2(2024浙江6月)：煤的气化为化学变化（C+H₂O→CO+H₂）；与煤有关的转化全部为化学变化（气化/液化/燃烧/干馏）→ 答案 B。

## 模块2 化学与材料(★★★)

**一、金属材料**：纯金属 + 合金。合金特征：**熔点低于成分金属、硬度往往高于成分金属**；合金可含非金属（钢铁含 C）。

| 合金 | 组成 | 用途 |
|------|------|------|
| 碳素钢 | Fe、C | 低碳钢·钢管；中碳钢·铁轨车轮；高碳钢·刀具弹簧 |
| 不锈钢 | Fe、Cr、Ni | 医疗器械、餐具、地铁车体 |
| 硬铝 | Al、Cu、Mg、Mn、Si | 飞机、宇宙飞船 |
| 储氢合金 | Ti-Fe 或 La-Ni | 与 H₂ 结合成金属氢化物 |
| 钛合金 | 主要含 Ti | 深航潜水器 |
| 耐热合金 | Ni、C、Fe、Co | 飞机发动机叶片 |

注：稀土元素＝"冶金工业的维生素"。

**二、无机非金属材料**：
- 传统：陶瓷（黏土/铝硅酸盐）、水泥（黏土+石灰石+石膏调硬化速率）、玻璃（石灰石+纯碱+石英砂）。**有机玻璃=聚甲基丙烯酸甲酯（有机高分子）**；玻璃纤维是复合材料基体。
- 新型：**Si**（导电介于导体绝缘体之间→芯片/太阳能电池/半导体材料）；**SiO₂**（光全反射→光导纤维）；**SiC 金刚砂**（硬度高耐高温→磨料/耐高温结构材料）；碳纳米材料：富勒烯 C₆₀/C₇₀、碳纳米管、石墨烯（超级电容器/电池）。

**三、有机高分子材料**：纤维分类=天然纤维（棉麻丝毛）+ 化学纤维（再生纤维：粘胶/大豆蛋白纤维；合成纤维：六大纶）。

**四、复合材料**：基体（金属/非金属）+ 增强材料（玻璃纤维/硼纤维/芳纶纤维）；应用于航空航天。

> 例 1(2024天津)：珐琅彩颜料经高温烧制，属**无机化合物**（不是有机）→ 答案 D。
> 例 2(2024广东)：石英成分为 **SiO₂**（不是 SiC）→ 答案 C。

## 模块3 化学与资源开发利用(★★)

**一、能源分类**：常规（天然气/煤/石油）vs 新能源（太阳能/风能/地热能/核能/氢能）vs 可再生（风能/生物质能/潮汐能）。

**二、常规能源**：
- **天然气**：清洁燃料；高温裂解→H₂+焦炭；与水蒸气→合成气(CO、H₂)。
- **煤**：气化（C+H₂O→水煤气）；液化=直接液化（与H₂）+间接液化（先气化再 CO、H₂→甲醇），**气化/液化均为化学变化**；干馏=隔绝空气加强热（化学变化），产物：出炉煤气（焦炉气/粗氨水/粗苯）+煤焦油（苯系物/酚类/萘/沥青）+焦炭。
- **石油**：常压/减压蒸馏（沸点分离，各馏分均混合物）；催化裂化/裂解（长链→短链，**裂化得液态油，裂解得气态烯烃**）；催化重整（链状→环状）；液化石油气=丙烷/丙烯/丁烷/丁烯。

**三、海水资源**：淡化=蒸馏/电渗析/反渗透；提食盐=日光蒸发结晶；提溴（富集：低浓度 Br⁻ → SO₂ 水溶液吸收富集 Br₂）；提镁（电解熔融 MgCl₂）。

**四、各种"气"**：

| 气体 | 主要成分 |
|------|----------|
| 高炉煤气 | CO |
| 水煤气 | CO、H₂ |
| 焦炉气 | H₂、CO、CH₄、C₂H₄ |
| 液化石油气 | 丙烷/丙烯/丁烷/丁烯 |
| 裂解气 | 低碳烷烃、低碳烯烃 |
| 天然气/沼气 | CH₄ |

**五、各种"油"**（核心辨识）：除**甘油（醇，纯净物，易溶于水）**外均为**混合物**无固定熔沸点；植物油（不饱和酯）/动物油（饱和酯）/地沟油（植物油+动物油）/生物柴油（脂肪酸甲酯）均为酯；矿物油（石油）、轻质油、直馏汽油（烷烃）、裂化汽油（烷烃+烯烃）均为烃；煤焦油来自煤**干馏**（煤油与煤无关）。

> 例 1：冶炼方法匹配：Mg→电解熔融 MgCl₂（不可铝热）、Cu→湿法/火法/热还原（电解仅精炼）、Fe→焦炭/CO 热还原 ✓、Au→物理提炼 → 答案 C。
> 例 2：煤油来自石油**分馏**；气化/液化均化学变化；裂化≠裂解目的 → 答案 B。
> 例 3（海水）：金属钠=电解**熔融** NaCl；③→⑤目的富集溴；SO₂+Br₂ 离子方程式 SO₂+Br₂+2H₂O=2Br⁻+4H⁺+SO₄²⁻；除杂顺序 **BaCl₂→Na₂CO₃→NaOH→过滤→盐酸**（Na₂CO₃ 必须在 BaCl₂ 之后）→ 答案 B。

## 模块4 化学与环境保护(★)

**空气**：温室效应（CH₄、CO₂ 过多）；空气污染指数含 SO₂/NO₂/CO/O₃/可吸入颗粒物；PM2.5=直径≤2.5μm；雾霾主因=可吸入颗粒物+燃煤汽车尾气；碳中和=植树造林/节能减排/碳捕集封存抵消 CO₂ 排放。

**水体**：重金属污染（密度>4.5g·cm⁻³：Ba/Cu/Ag/Cr/Cd/Ni/Pb/Ti/Sn/Hg）；富营养化（N、P、K 过量→藻类疯长→溶解氧↓）；赤潮（海水红藻褐藻）；水华（淡水藻类）。

**固体**：白色污染=塑料难降解（可降解塑料如聚乳酸酯替代）；土壤酸化/碱化（酸性化肥硫酸铵/草木灰；草木灰碱化撒石膏）；废旧电池=有害垃圾。

**绿色化学**：从**源头**减少/消除污染（而非末端治理）；特征=原料无毒无害、反应选择性高副产物少；**原子经济利用率 100%**（原子全部转化为期望产物）。

> 例 1(2024海南)：人工合成杀虫剂有毒性对环境有影响 → 答案 B。
> 例 2（"十四五"）：生石灰吸收 SO₂ 减酸雨、**不能**吸收 CO₂；绿色化学=源头；废电池必回收；聚乳酸酯代替聚乙烯减白色污染 → 答案 D。

## 模块5 化学与传统文化(★★)

**一、常见俗名**：蓝矾/胆矾 CuSO₄·5H₂O；绿矾 FeSO₄·7H₂O；明矾 KAl(SO₄)₂·12H₂O；铜绿/孔雀石 Cu₂(OH)₂CO₃；水玻璃 Na₂SiO₃ 水溶液；黑火药 S+C+KNO₃；铁红 Fe₂O₃；磁性氧化铁/司南 Fe₃O₄；钡餐/重晶石 BaSO₄；石膏 CaSO₄；水晶/石英 SiO₂；苏打/纯碱 Na₂CO₃；小苏打 NaHCO₃；草木灰 K₂CO₃；石灰石/大理石 CaCO₃；熟石灰/消石灰 Ca(OH)₂；生石灰 CaO。

**二、常考中华文明**：陶瓷（黏土+釉料金属化合物高温氧化还原变色）；青铜（铜矿木炭热还原→粗铜→加铅锡熔炼）；造纸（斩竹漂塘→煮徨足火→舂臼→荡料入帘→覆帘压纸→透火焙干）；黑火药（S+2KNO₃+3C=K₂S+N₂↑+3CO₂↑）；酿酒（曲霉糖化→酵母发酵→蒸馏）。

> 例 1：乌金可燃烧且埋藏地底→煤炭 → 答案 B。
> 例 2：古籍中未涉及氧化还原的是 CaCO₃ 分解（非氧化还原）→ 答案 D。
> 例 3：麦芽糖水解产物仅葡萄糖；大理石穿石=CaCO₃+H₂O+CO₂ 非氧化还原；黑火药=硫磺+木炭+硝酸钾 ✓；氧化剂还原剂可大量共存（需引发条件）→ 答案 C。
> 例 4(2024广西)："白糖"主要成分是**蔗糖**（甘蔗榨汁）→ 答案 D。
