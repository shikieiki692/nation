### 一、物质的量与阿伏加德罗常数（概念建立与宏微观桥梁） · 对接缺口#4

- **概念建立**：物质的量（$n$，单位 $\mathrm{mol}$）是联系宏观可称量物质与微观不可见微粒（分子、原子、离子、电子等）的核心桥梁。
- **阿伏加德罗常数（$N_A$）**：$1\mathrm{mol}$ 任何微粒集体所含的微粒数与 $0.012\mathrm{kg}\ ^{12}\mathrm{C}$ 中所含碳原子数相同，基准值约为 $6.02\times 10^{23}\mathrm{mol^{-1}}$。
- **核心关系式**：$n = \frac{N}{N_A} = \frac{m}{M} = \frac{V}{V_m} = c \cdot V$（标准状况 $0^\circ\mathrm{C}, 101\mathrm{kPa}$ 下气体摩尔体积 $V_m \approx 22.4\mathrm{L\cdot mol^{-1}}$）。

### 容量瓶配制一定物质的量浓度溶液的实验步骤与系统误差分析 · 对接缺口#5

- **仪器与规格**：容量瓶（常用规格：$50\mathrm{mL}, 100\mathrm{mL}, 250\mathrm{mL}, 500\mathrm{mL}, 1000\mathrm{mL}$，标有温度、容积、刻度线；使用前必须**查漏**，严禁用于溶解、稀释、加热或长期存放溶液）。
- **实验八步曲**：①**计算**（固体质量或液体体积）；②**称量/量取**（托盘天平精确到 $0.1\mathrm{g}$，量筒精确到 $0.1\mathrm{mL}$）；③**溶解/稀释**（烧杯中进行，玻璃棒引流搅拌）；④**冷却**（必须恢复至室温，防止热胀冷缩导致体积偏差）；⑤**转移**（玻璃棒下端靠在容量瓶刻度线下方引流）；⑥**洗涤**（用蒸馏水洗涤烧杯内壁和玻璃棒 $2\sim 3$ 次，洗涤液全部注入容量瓶）；⑦**定容**（加水至距刻度线 $1\sim 2\mathrm{cm}$ 处，改用胶头滴管滴加至凹液面最低处与刻度线相切）；⑧**摇匀**（盖紧塞子，倒转摇匀，若液面低于刻度线**不可补加水**）。
- **误差分析公式**：依据 $c = \frac{n}{V} = \frac{m}{M \cdot V}$ 进行定性分析：
  - 使 $c$ 偏高的操作：砝码沾污/生锈；未冷却至室温即定容（体积偏小）；定容时俯视刻度线（液面低于刻度线，$V$ 偏小）。
  - 使 $c$ 偏低的操作：称量物置于右盘（用了游码）；烧杯与玻璃棒未洗涤；转移时有液体洒出；定容时仰视刻度线（$V$ 偏大）；摇匀后发现液面低于刻度线又补加水（$V$ 偏大）。
  - 对 $c$ 无影响的操作：容量瓶内壁在使用前有少量蒸馏水。

## 模块1 常用物理量及其换算(★★)

### 一、基本量关系与常数

- n = N/Nₐ = m/M = V/Vₘ = c·V。
- **Vₘ 的两个值**：标准状况（0℃,101kPa）22.4 L/mol；常温常压（25℃,101kPa）24.5 L/mol。22.4 L/mol 只对气体、且必须标况；水在标况是液体不能用。
- Nₐ 微观定义的坑：1mol 任何物质含 6.02×10²³ 个"微粒"，微粒需指明（分子/原子/离子/电子）。
- 判断"标况下 X L 气体含原子数"：先确认标况+气体，再数 1 分子含几个原子（如 O₃ 是 3）。

### 二、pV=nRT 五推论（同一容器/气体角度）

| 恒量 | 推论 |
|------|------|
| T、p 同 | V₁/V₂ = n₁/n₂（体积比=物质的量比） |
| T、V 同 | p₁/p₂ = n₁/n₂（压强比=物质的量比） |
| T、p 同 | ρ₁/ρ₂ = M₁/M₂（密度比=摩尔质量比） |
| T、V 同 | p 与 n 正比（恒温恒容充气） |
| 恒 T、p | 平均摩尔质量 M̄ = ρRT/p |

### 三、平均摩尔质量 M̄ 的求法

- 混合气体 M̄ = m总/n总 = M₁x₁+M₂x₂（x为物质的量分数）；也可用密度法 M̄=ρ·Vₘ（标况）=ρRT/p。
- 应用：同位素平均相对原子质量（Cl 35.5）、混合气判断、十字交叉法反推配比。

### 四、物质的量浓度

- cₓ = n/V = 1000ρω/M（ρ 单位 g/mL，ω 质量分数，M 摩尔质量）。**溶质微粒浓度**：c(离子) = c(溶质) × 组成比 × 单位电荷。
- 溶液稀释：c₁V₁=c₂V₂（溶质物质的量不变）。配溶液误差判断：定容前摇匀不补、仰视读数偏大（浓度偏小）等。

### 五、转化率、产率、纯度

- 转化率=已转化量/起始量×100%；产率=实际产量/理论产量×100%；纯度=样品中目标物质质量/样品总质量×100%。
- 链式反应（多步转化）用"关系式法"串联，中间产物消去，避免步步细算。

## 模块2 常用计算方法(★★)

### 一、守恒法（最优先）

- **电子守恒**：氧化还原中得电子总数=失电子总数。适用于：屡配平、多步氧化还原（如 HNO₃ 与金属）、求消耗氧化剂。
- **原子守恒**：反应前后某元素原子数不变（如用 N 守恒解 NO+NO₂+NaOH）。
- **电荷守恒**：溶液电中性即电荷浓度平衡（阳离子电荷浓度和=阴离子电荷浓度和），用于混合溶液中求未知离子浓度。
- 记忆锚点：**"电荷浓度=离子浓度×离子所带单位电荷"** 不是离子浓度直接相加。

### 二、差量法

- 利用反应前后固体质量差/气体体积差/压强差建立比例：Δm = 差量，按方程式系数比例列式。
- 适用：金属与酸置换（质量差 H₂）、CO₂ 通入石灰水（增重/失重）、Na₂O₂ 与 CO₂/H₂O（固体增重守恒式：增加质量=同物质的量的 CO 或 H₂）。

### 三、关系式法（多步反应的桥）

- 由方程式系数串联起"起始物→终产物"的物质的量关系，一步列式。如：制 H₂SO₄ 中 S→H₂SO₄（硫守恒）、KMnO₄ 滴定草酸：2MnO₄⁻~5C₂O₄²⁻。
- 2023重庆真题（例11）即 2MnO₄⁻~5C₂O₄²⁻~5Ca²⁺ 关系式计算 CaCl₂%。

### 四、十字交叉法

- 用于两组分平均量：M̄、平均密度、平均分子式。A 组分 n₁、B 组分 n₂，满足 (M̄−M_A)/(M_B−M̄)=n_B/n_A。
- 常在"混合烃平均相对分子质量""同位素原子比"中出现；注意交叉得到的比是物质的量比，不是质量比。

### 五、计算的"设 1 法"与有效数字

- 无具体量时可"设某个量为 1 mol / 100 g"，把百分数当质量直接除 M。求最简式、相对分子质量、质量分数尤其好用。
- 结果保留：分数/小数按题给精确度，恒重法（灼烧）题注意两次恒重法判断完全反应。

### 三、化学方程式中物质的量计算模型（计量数之比与过量计算） · 对接缺口#8

- **计量关系核心**：化学方程式中各物质的化学计量数之比等于各物质反应的**物质的量之比**（$n_1:n_2:n_3$），对于气体反应亦等于**同温同压下的体积之比**（$V_1:V_2:V_3$）。
- **解题步骤**：写方程式 $\to$ 列已知/未知量 $\to$ 上下单位一致、左右单位相当 $\to$ 建立比例式求解。
- **过量问题判定原则**：当两种反应物均给出量时，必须先按计量数之比判断谁完全反应（不足量/限量试剂），计算必须以**不足量**物质为基准。
