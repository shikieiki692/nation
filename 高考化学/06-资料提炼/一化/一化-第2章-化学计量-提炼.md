## 模块1 常用物理量及其换算(★★)

### 一、基本量关系与常数

- n = N/Nₐ = m/M = V/Vₘ = c·V。
- **Vₘ 的两个值**：标准状况（0℃,101kPa）22.4 L/mol；常温常压（25℃,101kPa）24.5 L/mol。22.4 L/mol 只对气体、且必须标况；水在标况是液体不能用。
- Nₐ 微观定义的坑：1mol 任何物质含 6.02×10²³ 个"微粒"，微粒需指明（分子/原子/离子/电子）。
- 判断"标况下 X L 气体含原子数"：先确认标况+气体，再数 1 分子含几个原子（如 O₃ 是 3）。

### 二、pV=nRT 五推论（同一容器/气体角度）

| 恒量 | 推论 |
|------|------|
| T、p 同 | V₁/V₂ = n₁/n₂（体积比=物质的量比） |
| T、V 同 | p₁/p₂ = n₁/n₂（压强比=物质的量比） |
| T、p 同 | ρ₁/ρ₂ = M₁/M₂（密度比=摩尔质量比） |
| T、V 同 | p 与 n 正比（恒温恒容充气） |
| 恒 T、p | 平均摩尔质量 M̄ = ρRT/p |

### 三、平均摩尔质量 M̄ 的求法

- 混合气体 M̄ = m总/n总 = M₁x₁+M₂x₂（x为物质的量分数）；也可用密度法 M̄=ρ·Vₘ（标况）=ρRT/p。
- 应用：同位素平均相对原子质量（Cl 35.5）、混合气判断、十字交叉法反推配比。

### 四、物质的量浓度

- cₓ = n/V = 1000ρω/M（ρ 单位 g/mL，ω 质量分数，M 摩尔质量）。**溶质微粒浓度**：c(离子) = c(溶质) × 组成比 × 单位电荷。
- 溶液稀释：c₁V₁=c₂V₂（溶质物质的量不变）。配溶液误差判断：定容前摇匀不补、仰视读数偏大（浓度偏小）等。

### 五、转化率、产率、纯度

- 转化率=已转化量/起始量×100%；产率=实际产量/理论产量×100%；纯度=样品中目标物质质量/样品总质量×100%。
- 链式反应（多步转化）用"关系式法"串联，中间产物消去，避免步步细算。

## 模块2 常用计算方法(★★)

### 一、守恒法（最优先）

- **电子守恒**：氧化还原中得电子总数=失电子总数。适用于：屡配平、多步氧化还原（如 HNO₃ 与金属）、求消耗氧化剂。
- **原子守恒**：反应前后某元素原子数不变（如用 N 守恒解 NO+NO₂+NaOH）。
- **电荷守恒**：溶液电中性即电荷浓度平衡（阳离子电荷浓度和=阴离子电荷浓度和），用于混合溶液中求未知离子浓度。
- 记忆锚点：**"电荷浓度=离子浓度×离子所带单位电荷"** 不是离子浓度直接相加。

### 二、差量法

- 利用反应前后固体质量差/气体体积差/压强差建立比例：Δm = 差量，按方程式系数比例列式。
- 适用：金属与酸置换（质量差 H₂）、CO₂ 通入石灰水（增重/失重）、Na₂O₂ 与 CO₂/H₂O（固体增重守恒式：增加质量=同物质的量的 CO 或 H₂）。

### 三、关系式法（多步反应的桥）

- 由方程式系数串联起"起始物→终产物"的物质的量关系，一步列式。如：制 H₂SO₄ 中 S→H₂SO₄（硫守恒）、KMnO₄ 滴定草酸：2MnO₄⁻~5C₂O₄²⁻。
- 2023重庆真题（例11）即 2MnO₄⁻~5C₂O₄²⁻~5Ca²⁺ 关系式计算 CaCl₂%。

### 四、十字交叉法

- 用于两组分平均量：M̄、平均密度、平均分子式。A 组分 n₁、B 组分 n₂，满足 (M̄−M_A)/(M_B−M̄)=n_B/n_A。
- 常在"混合烃平均相对分子质量""同位素原子比"中出现；注意交叉得到的比是物质的量比，不是质量比。

### 五、计算的"设 1 法"与有效数字

- 无具体量时可"设某个量为 1 mol / 100 g"，把百分数当质量直接除 M。求最简式、相对分子质量、质量分数尤其好用。
- 结果保留：分数/小数按题给精确度，恒重法（灼烧）题注意两次恒重法判断完全反应。
