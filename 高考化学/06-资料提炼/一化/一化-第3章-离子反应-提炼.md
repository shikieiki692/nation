## 模块1 电解质与电离(★★)

### 一、电解质六个"不一定"

1. 能导电的物质不一定是电解质（金属、石墨导电，是单质非电解质）。
2. 电解质不一定能导电（固态 NaCl、纯酸不导电，无自由移动离子）。
3. 导电的不一定是电解质溶液（SO₂、CO₂、NH₃ 溶于水导电，但导电的是生成物 H₂SO₃/H₂CO₃/NH₃·H₂O，SO₂ 等本身是非电解质）。
4. 强电解质一定是完全电离，但溶解度小的强电解质（如 CaCO₃、BaSO₄）导电能力弱。
5. 弱电解质的电离是可逆的（存在电离平衡），强电解质电离不可逆。
6. 电解质强弱与溶解性无必然关系：BaSO₄ 难溶是强电解质；CH₃COOH 易溶是弱电解质。

### 二、电荷浓度（导电性强弱的唯一核心判据）

- **电荷浓度=离子浓度×离子所带单位电荷**（不是离子浓度简单相加）。如 c(Mg²⁺)=0.1 mol/L → 电荷浓度 0.2 mol/L。
- 导电性强弱由电荷浓度决定，与电解质强弱、溶解度、离子所带电荷均有关。弱酸稀溶液电荷浓度小 → 导电性弱；乙醇非电解质几乎不电离 → 电导率≈0。
- 图像题三趋势：**A 型**（先降后升，如 Ba(OH)₂ 通 SO₂/加稀硫酸）；**B 型**（由弱增强，弱酸被中和成强电解质）；**C 型**（几乎不变，强电解质交换成等电荷浓度强电解质，如 HNO₃+AgCl↓）。滴加氨水到 HCl+CH₃COOH 混合液：先降（体积稀释为主）、再升（弱酸成盐）、后缓降（同离子效应+稀释）。

### 三、电离方程式书写

- 强电解质用"="，弱电解质与多元弱酸分步用"⇌"（H₂CO₃⇌H⁺+HCO₃⁻ 主、HCO₃⁻⇌H⁺+CO₃²⁻ 次）；不写沉淀/气体符号（电离在溶液中进行）。
- 酸式盐电离：NaHSO₄ 在水中 NaHSO₄=Na⁺+H⁺+SO₄²⁻；NaHCO₃=Na⁺+HCO₃⁻（HCO₃⁻ 不拆）。

## 模块2 与量有关的离子方程式(★★★)

### 一、五条"反应线"（按"少量定1，过量配合"拆解）

| 线 | 少量物质 | 典型例 |
|----|----------|--------|
| 铝线 | CO₂ 少量进偏铝酸盐 / OH⁻ 少量进铝盐 | CO₂(少)+2[Al(OH)₄]⁻=2Al(OH)₃↓+CO₃²⁻+H₂O；OH⁻(少)+Al³⁺=Al(OH)₃↓ |
| 碳线 | CO₂ 少量/过量进入碱 | CO₂(少)+2OH⁻=CO₃²⁻+H₂O；CO₂(过)+OH⁻=HCO₃⁻ |
| 硫线 | SO₂ 少量/过量 / H₂S 进入碱 | 同碳线逻辑；H₂S+OH⁻(少)=HS⁻+H₂O |
| 磷线 | 磷酸与碱逐步反应 | H₃PO₄+OH⁻ 分步生成 H₂PO₄⁻/HPO₄²⁻/PO₄³⁻ |
| 铁线 | Fe 与稀 HNO₃ 量的关系 | Fe(少)+4H⁺+NO₃⁻=Fe³⁺+NO↑+2H₂O；Fe(过)+产物变 Fe²⁺(3Fe+8H⁺+2NO₃⁻=3Fe²⁺+2NO↑+4H₂O) |

**配比复分解（定比型）**："以少定多"——不足量物质化学式中各离子配比=原方程式配比；足量物质按少量离子需求配。
- Ca(HCO₃)₂+NaOH：NaOH 少 → OH⁻+Ca²⁺+HCO₃⁻=CaCO₃↓+H₂O；NaOH 多 → 2OH⁻+Ca²⁺+2HCO₃⁻=CaCO₃↓+CO₃²⁻+2H₂O。
- NH₄HSO₄+NaOH：NaOH 少 → H⁺+OH⁻=H₂O；NaOH 多 → NH₄⁺+H⁺+2OH⁻=NH₃·H₂O+H₂O（先中和 H⁺ 后沉淀/碱 NH₄⁺）。
- 明矾 KAl(SO₄)₂·12H₂O+Ba(OH)₂：Al³⁺ 沉淀完全时 2Al³⁺+3SO₄²⁻+3Ba²⁺+6OH⁻=2Al(OH)₃↓+3BaSO₄↓；SO₄²⁻ 沉淀完全时 Al³⁺+2SO₄²⁻+2Ba²⁺+4OH⁻=[Al(OH)₄]⁻+2BaSO₄↓。

### 二、氧化还原配比（向定量方向迁移电子）

- FeBr₂+Cl₂：Cl₂ 少量只氧化 Fe²⁺（2Fe²⁺+Cl₂=2Fe³⁺+2Cl⁻）；Cl₂ 过量再氧化 Br⁻（2Fe²⁺+4Br⁻+3Cl₂=2Fe³⁺+2Br₂+6Cl⁻）；"还原性 Fe²⁺>Br⁻，先氧化还原性强者"。
- FeI₂+Cl₂：I⁻ 还原性强于 Fe²⁺，先氧化 I⁻。
- 交叉型（两个自身交叉）：NaClO+SO₂（+H₂O）=NaCl+H₂SO₄（Cl 降为 −1，S 升为 +6）；Na₂SO₃+Cl₂+H₂O=Na₂SO₄+2HCl；NaClO+Na₂SO₃=NaCl+Na₂SO₄。
- 归中/歧化注意：S₂O₃²⁻+2H⁺=S↓+SO₂↑+H₂O（歧化，不能共存）；SO₂ 与 Ca(ClO)₂ 反应产物取 CaSO₄ 与 CaCl₂。

## 模块3 七个注意（判断离子方程式正误）(★★★)

1. **铁在酸中的形态**：Fe 与稀盐酸/稀硫酸（非氧化性酸）生成 Fe²⁺，不能写成 Fe³⁺；Fe 与稀 HNO₃ 生成 Fe³⁺（酸性氧化性酸）；铁过量的 HNO₃ 才得 Fe²⁺。
2. **强酸拆分**：六大强酸——H₂SO₄、HCl、HNO₃、HBr、HI、HClO₄ 拆成离子；弱酸（HF、H₂S、H₂CO₃ 等）不拆。浓硫酸不拆（以分子形式写 SO₂ 类反应）。
3. **饱和 NaHCO₃ 不拆 / NaHSO₄ 拆**：NaHCO₃ 中 HCO₃⁻ 保留（弱酸的酸式根）；NaHSO₄ 在水中完全电离拆 H⁺+SO₄²⁻；其余酸式根（HS⁻、HCO₃⁻、HSO₃⁻、HPO₄²⁻ 等）一律保留。
4. **微溶物规则**：作为反应物且在澄清溶液中的微溶物拆（Ca(OH)₂ 澄清石灰水拆）；作为生成物的微溶物不拆写沉淀（CaSO₄、Ag₂SO₄、MgCO₃ 生成时写分子式）。
5. **氧化还原/水解/气体沉淀**：判断离子方程式前先检查氧化还原是否漏写（如 Fe²⁺+Cl₂ 必须写氧化产物 Fe³⁺）；注意 NH₄⁺ 与 OH⁻ 加热放 NH₃。
6. **量变引起质变（稀浓/温度）**：Cu+浓HNO₃→NO₂，稀HNO₃→NO；Zn+HNO₃ 过稀→更低价产物；MnO₂/浓盐酸需加热。
7. **守恒检查最后一道闸**：原子守恒+电荷守恒（反应物电荷总和=生成物电荷总和）必须同时满足。

**判断例要点**（原书例1-例7）：
- 例1 全 ×、例2 全 ×、例4 全 ×、例5 全 ×、例7 全 ×（各错在拆写/配平/量）。
- 例3 泡沫灭火器原理：3HCO₃⁻+Al³⁺=Al(OH)₃↓+3CO₂↑（HCO₃⁻ 与 Al³⁺ 双水解，正确）。
- 例6 答案为 (3)(5)(11)(12)(17)(18) √（其中 (18) 与[Al(OH)₄]⁻ 相关）；余 13 个 ×。

## 模块4 离子大量共存(★★)

### 一、共存的本质与判别五方面

本质：各离子相互不反应。**"大量共存"默认大量**——水中的少量 H⁺/OH⁻ 可共存，但大量 H⁺ 与 OH⁻ 不行。判别五方面：

1. **生成沉淀/微溶物**：F⁻ 与 Ca²⁺、Mg²⁺；Cl⁻/Br⁻/I⁻ 与 Ag⁺、Cu⁺；SO₄²⁻ 与 Ba²⁺、Pb²⁺（Ca²⁺、Ag⁺ 微溶）；CO₃²⁻/SO₃²⁻/PO₄³⁻/S²⁻/SiO₃²⁻ 与除 Na⁺、K⁺ 外绝大多数阳离子；OH⁻ 与除 Na⁺、K⁺、Ba²⁺ 外绝大多数阳离子（Ca²⁺ 微溶）。
2. **生成弱电解质**：H⁺ 与弱酸阴离子（CO₃²⁻、HCO₃⁻、SO₃²⁻、S²⁻、HS⁻、ClO⁻、F⁻、C₂O₄²⁻、PO₄³⁻…）及[Al(OH)₄]⁻；OH⁻ 与弱碱阳离子（Mg²⁺、Al³⁺、Fe³⁺、Fe²⁺、Cu²⁺、NH₄⁺）及弱酸酸式根。记忆：记少不记多——H⁺ 只与 ClO₄⁻、I⁻、Br⁻、Cl⁻、NO₃⁻、SO₄²⁻ 共存；OH⁻ 只与 Na⁺、K⁺、Ba²⁺ 共存。
3. **氧化还原**：表头口诀"牛牛雅典铁秀绿"=S²⁻/HS⁻、SO₃²⁻/HSO₃⁻、I⁻、Fe²⁺、Br⁻、Cl⁻（还原性由强到弱）；纵轴"铁蛋哥孟子"=Fe³⁺、NO₃⁻(H⁺)、Cr₂O₇²⁻(H⁺)、MnO₄⁻(H⁺)、ClO⁻（氧化性由弱到强）。交叉对×；注意 MnO₄⁻ 强酸性才强氧化、NO₃⁻ 需 H⁺ 才表现氧化性、ClO⁻ 强碱性还原性离子可共存。
4. **彻底双水解**："闺女儿谈谈妞妞"=SiO₃²⁻、[Al(OH)₄]⁻、CO₃²⁻、HCO₃⁻、S²⁻、HS⁻；"吕爹爱"=Al³⁺、Fe³⁺、NH₄⁺。Al³⁺ 与六种阴离子全√（双水解）；Fe³⁺ 除 S²⁻/HS⁻（氧化还原）外√；NH₄⁺ 只与 SiO₃²⁻、[Al(OH)₄]⁻ √，与 HCO₃⁻/CH₃COO⁻ 双水解微弱可共存。**关键辨析**：[Al(OH)₄]⁻+HCO₃⁻=Al(OH)₃↓+CO₃²⁻+H₂O（由强制弱，非双水解，无 CO₂）。
5. **配合反应**：Fe³⁺ 与 SCN⁻、CN⁻、（苯酚）C₆H₅O⁻ 生成配合物不能共存。

### 二、附加条件（审题陷阱）

- **有色离子**（按波长由长到短记忆）：Cr₂O₇²⁻ 橙、CrO₄²⁻/Fe³⁺/[Fe(CN)₆]³⁻/[CuCl₄]²⁻ 黄、Fe²⁺/Cr³⁺ 绿、Cu²⁺ 蓝、MnO₄⁻ 紫红。**"无色"溶液禁有色离子；"透明"溶液可有色**（透明≠无色）。
- **酸碱性条件**：pH、指示剂显色（酚酞<8.2 无色/>10 红；石蕊<5 红/>8 蓝；甲基橙<3.1 红/>4.4 黄——口诀"太实诚，怕饿咬你，我怕，三姨试试"）、c(H⁺)/c(OH⁻) 比值、加铝粉放 H₂（酸或碱均可）、c水(H⁺) 或 c水(OH⁻)≪10⁻⁷（酸或碱均被抑制）、含 Cr₂O₇²⁻/Fe³⁺/Al³⁺ 一般强酸、含 CrO₄²⁻/[Al(OH)₄]⁻ 一般强碱。
- **多元弱酸酸式根两性**：HCO₃⁻、HC₂O₄⁻、HSO₃⁻、HS⁻、H₂PO₄⁻、HPO₄²⁻ 与 H⁺、OH⁻ 均不共存。
- 其他：S₂O₃²⁻ 遇 H⁺ 歧化、遇强氧化剂（Fe³⁺、MnO₄⁻）氧化；Ag⁺ 与 NH₃·H₂O 配合成[Ag(NH₃)₂]⁺（银氨溶液内可共存）；胶体遇大量离子聚沉、遇酸中和。

### 三、判断策略（例1-29 题总结）

1. 先读清题干：**一定共存/一定不共存/可能共存**（三选）。
2. 把酸碱性翻译成 H⁺/OH⁻ 代入每个组合。
3. K⁺、Na⁺ 几乎不参与沉淀与弱电解质，默认可共存（但 [Fe(CN)₆]³⁻+Fe²⁺+K⁺ 形成蓝色沉淀例外）。
4. 强酸性+NO₃⁻=氧化性组合，遇 Fe²⁺/I⁻/S²⁻/SO₃²⁻ 必反应；强酸性才考虑 MnO₄⁻ 氧化；强碱性 NO₃⁻ 不氧化。
5. "加铝粉放 H₂"双解时，含 NO₃⁻ 的酸性溶液不产生 H₂（生成氮氧化物），含 Fe²⁺ 碱性不共存。
