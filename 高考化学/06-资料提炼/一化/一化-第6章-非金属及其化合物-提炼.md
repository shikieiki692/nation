## 模块 1　碳、硅及其化合物 ★★★

### 内容提要

#### 一、硅单质
- **存在**：自然界无游离态，主要以硅酸盐、二氧化硅形式存在（亲氧元素）。
- **物理性质**：灰黑色固体，熔点高、硬度大，导电性介于导体与绝缘体之间（半导体）。
- **化学性质**（常温不活泼，加热可与 O₂、Cl₂ 反应）：
  - 与 F₂：`Si + 2F₂ = SiF₄`（常温）
  - 与 HF：`Si + 4HF = SiF₄↑ + 2H₂↑`（常温）
  - 与 O₂：`Si + O₂ = SiO₂`（加热）
  - 与 Cl₂：`Si + 2Cl₂ = SiCl₄`（加热）
  - 与 NaOH：`Si + 2NaOH + H₂O = Na₂SiO₃ + 2H₂↑`（**无氧化剂也放 H₂**，Si 做还原剂，H₂O 做氧化剂）
- **工业制备**：`SiO₂ + 2C = Si + 2CO↑`（高温，粗硅）
- **用途**：半导体材料、太阳能电池、芯片。

#### 二、硅的制备与提纯（高频流程考点）
1. 粗硅：`SiO₂ + 2C ═(高温)═ Si(粗) + 2CO↑`
2. 提纯第一步：`Si + 2Cl₂ ═(加热)═ SiCl₄`（液态，易挥发）
3. 提纯第二步：`SiCl₄ + 2H₂ ═(高温)═ Si(纯) + 4HCl`
4. 西门子法改进：`SiHCl₃` 中间体（2022·全国乙卷考查）

#### 三、二氧化硅 SiO₂
- **结构**：原子晶体（正四面体空间网状结构），每个 Si 连 4 个 O，每个 O 连 2 个 Si。
- **物理性质**：熔点高、硬度大、难溶于水。
- **化学性质**（**酸性氧化物但常温只与 HF 反应**）：
  - 与 HF：`SiO₂ + 4HF = SiF₄↑ + 2H₂O`（玻璃雕刻、HF 不能用玻璃瓶装）
  - 与强碱：`SiO₂ + 2NaOH = Na₂SiO₃ + H₂O`（**NaOH 不能放玻璃塞试剂瓶**，用橡胶塞）
  - 与碱性氧化物（高温）：`SiO₂ + CaO ═(高温)═ CaSiO₃`
  - 与 Na₂CO₃（高温）：`SiO₂ + Na₂CO₃ ═(高温)═ Na₂SiO₃ + CO₂↑`（**高温下 SiO₂ 可"制"CO₂**，不违背强酸制弱酸，因 CO₂ 是气体逸出）
  - 与碳：`SiO₂ + 2C ═(高温)═ Si + 2CO↑`
- **用途**：光导纤维（光纤）、石英钟表、玛瑙、光学仪器。

#### 四、硅酸 H₂SiO₃
- **制备**（弱酸制更弱酸，不用 SiO₂ 直接与水）：`Na₂SiO₃ + 2HCl = H₂SiO₃↓ + 2NaCl`；`Na₂SiO₃ + CO₂ + H₂O = H₂SiO₃↓ + Na₂CO₃`（CO₂ 过量生成 NaHCO₃）
- **性质**：白色胶状沉淀，不溶于水，弱酸性（比碳酸弱），受热分解 `H₂SiO₃ ═(△)═ H₂O + SiO₂`。
- **用途**：硅胶干燥剂。

#### 五、硅酸盐
- **Na₂SiO₃**：俗名**水玻璃/泡花碱**，水溶液碱性，用作黏合剂、防火剂、防腐剂。
- **硅酸盐组成的表示**：用氧化物形式表示，如 Na₂SiO₃ = Na₂O·SiO₂，石棉 CaMg₃Si₄O₁₂ = CaO·3MgO·4SiO₂。
- **传统无机非金属材料**：陶瓷、玻璃、水泥（2024·甘肃卷考查陶瓷）。

#### 六、含硅新型材料
- 高纯硅：芯片、太阳能电池
- 二氧化硅：光导纤维
- 新型陶瓷（氮化硅 Si₃N₄、碳化硅 SiC）
- 硅钢（变压器铁芯）、硅橡胶

#### 七、碳的同素异形体
- 金刚石（原子晶体）、石墨（混合晶体，层内共价键、层间范德华力，能导电）、C₆₀（分子晶体）、石墨烯/石墨炔（单层碳原子，2023·北京卷：石墨炔为同素异形体）。
- 碳的化学性质（还原性）：`C + CO₂ ═(高温)═ 2CO`；`2C + SiO₂ ═(高温)═ Si + 2CO↑`。

#### 八、CO 与 CO₂
| 项目 | CO | CO₂ |
|---|---|---|
| 结构 | 含配位键，不成盐氧化物 | 直线形，酸性氧化物 |
| 物理 | 无色无味、有毒、难溶于水 | 无色、能溶于水（1:1体积比） |
| 化学 | 还原性：`2CO+O₂═2CO₂`、`CO+CuO═(△)Cu+CO₂`、`3CO+Fe₂O₃═(高温)2Fe+3CO₂`；与 NaOH 不反应 | 与碱：少量`CO₂+2NaOH═Na₂CO₃+H₂O`；过量`CO₂+NaOH═NaHCO₃`；`CO₂+Ca(OH)₂` 变浑又变清；与 Na₂O₂：`2CO₂+2Na₂O₂═2Na₂CO₃+O₂` |
| 检验 | 点燃后产物使澄清石灰水变浑 | 使澄清石灰水变浑（注意 CO₂ 干扰） |
| 用途 | 燃料、冶金还原剂 | 灭火、制汽水、人工降雨（干冰） |

#### 九、含碳酸（H₂CO₃ 及碳酸盐）
- H₂CO₃ 为二元弱酸，CO₃²⁻/HCO₃⁻ 与酸分步反应。
- 碳酸盐热稳定性：`CaCO₃ ═(高温)═ CaO + CO₂↑`；可溶性碳酸盐（Na₂CO₃）热稳定。
- 侯氏制碱法核心：`NaCl + NH₃ + CO₂ + H₂O = NaHCO₃↓ + NH₄Cl`，NaHCO₃ 溶解度小析出，再加热 `2NaHCO₃ ═(△)═ Na₂CO₃ + CO₂↑ + H₂O`。

### 类型例题要点
- 类型Ⅰ 基础常识判断：硅亲氧无游离态、SiO₂ 不与水/一般酸反应但能与 HF/强碱反应、光纤是 SiO₂ 不是 Si。
- 类型Ⅱ 正误判断：Na₂SiO₃ 水溶液俗称水玻璃、SiO₂ 原子晶体熔点高、碳族递变性（C 非金属性 > Si）。
- 类型Ⅲ 碳硅对比：CO₂ 与碱的"少量/过量"离子方程式；CO 还原性。
- 类型Ⅳ 侯氏制碱流程：NaCl 循环、NaHCO₃ 先析出（溶解度）。
- 类型Ⅴ 硅制备流程：粗硅→SiCl₄→高纯硅，中间体 SiHCl₃。
- 类型Ⅵ 实验：HF 刻玻璃（不能用玻璃瓶盛 HF）；CO₂ 除杂（饱和 NaHCO₃ 洗气）。
- 类型Ⅶ 元素推断：C/Si 位置、非金属性比较。

## 模块 2　卤素 ★★★★

### 内容提要

#### 第 1 节 氯气

##### 1. 氯气的物理性质
- 黄绿色、有刺激性气味的有毒气体，密度大于空气，能溶于水（1:2体积比），易液化。
- 实验室闻气体方法：手轻轻扇动。

##### 2. 氯气的化学性质（氧化性强，Cl⁻ 到 0 到 +1/+5/+7）
- 与金属：`2Na+Cl₂ ═(点燃)═ 2NaCl`；`2Fe+3Cl₂ ═(点燃)═ 2FeCl₃`（**Cl₂ 强氧化性直接氧化 Fe 到 +3**）；`Cu+Cl₂ ═(点燃)═ CuCl₂`（棕黄色烟）。
- 与非金属：`H₂+Cl₂ ═(点燃/光照)═ 2HCl`（光照爆炸；点燃安静燃烧，火焰苍白色，瓶口白雾）。
- 与水：`Cl₂+H₂O ⇌ HCl+HClO`（**可逆**）；次氯酸不稳定 `2HClO ═(光照)═ 2HCl+O₂↑`。
- 与碱：`Cl₂+2NaOH = NaCl+NaClO+H₂O`（尾气处理）；`Cl₂+2Ca(OH)₂ = Ca(ClO)₂+CaCl₂+2H₂O`（制漂白粉）；漂白粉有效成分 **Ca(ClO)₂**。
- 与还原性化合物：`Cl₂+2FeCl₂ = 2FeCl₃`、`Cl₂+2KI = 2KCl+I₂`、`Cl₂+SO₂+2H₂O = 2HCl+H₂SO₄`、`Cl₂+H₂S = 2HCl+S↓`、`Cl₂+Na₂SO₃+H₂O = Na₂SO₄+2HCl`。
- 与有机物：取代（CH₄+Cl₂）、加成（乙烯）。

##### 3. 氯水
- **成分**：三分子（Cl₂、H₂O、HClO）+ 三离子（H⁺、Cl⁻、ClO⁻）。加氯水体现不同微粒性质：
  - 使有色布条/品红褪色 → **HClO 漂白性**（氯水本身黄绿色）
  - 使石蕊先变红后褪色 → H⁺ 酸性 + HClO 漂白
  - 加 AgNO₃ 白沉淀 → Cl⁻
  - 加 Na₂CO₃ 冒泡 → H⁺
  - 加淀粉 KI 变蓝 → Cl₂ 氧化性（或 HClO）
- **久置氯水**：HClO 分解，最终为稀盐酸，失去漂白性。

##### 4. 氯的氧化物
- ClO₂：黄绿色气体，高效消毒剂（氧化性极强，消毒时 Cl 降到 Cl⁻，**还原产物 Cl⁻**）；`2KClO₃+4HCl(浓) = 2KCl+2ClO₂↑+Cl₂↑+2H₂O` 或 `2NaClO₂+Cl₂ = 2ClO₂+2NaCl`（2020·全国Ⅲ：KClO₃ 制备 ClO₂）。
- Cl₂O：次氯酸酐，酸性氧化物。

##### 5. 氯的含氧酸
| 酸 | 化学式 | 氯价 | 酸性 | 盐实例 |
|---|---|---|---|---|
| 次氯酸 | HClO | +1 | 弱酸 | NaClO（84消毒液主要成分） |
| 亚氯酸 | HClO₂ | +3 | 中强酸 | NaClO₂ |
| 氯酸 | HClO₃ | +5 | 强酸 | KClO₃ |
| 高氯酸 | HClO₄ | +7 | **最强无机酸** | KClO₄ |

##### 6. 氯的盐
- NaCl：食盐。电解熔融 NaCl：`2NaCl ═(电解)═ 2Na+Cl₂↑`；电解食盐水（氯碱工业）：`2NaCl+2H₂O ═(电解)═ 2NaOH+H₂↑+Cl₂↑`（2023·广东卷考查阳极 Cl₂ 检验）。
- 漂白粉/漂粉精：有效成分 Ca(ClO)₂，漂白原理：`Ca(ClO)₂+CO₂+H₂O = CaCO₃↓+2HClO`（**CO₂ 可以制 HClO，因为 HClO 比 H₂CO₃ 弱，但 CaCO₃ 沉淀使反应持续**）；久置失效 `Ca(ClO)₂+CO₂+H₂O = CaCO₃+2HClO` 后 HClO 分解。
- KClO₃：氯酸钾，氧化性强，制 O₂、制 ClO₂、火柴头成分。

##### 7. 氯气的制备
- **实验室**：`MnO₂+4HCl(浓) ═(△)═ MnCl₂+Cl₂↑+2H₂O`（必须浓盐酸、加热；用稀盐酸不反应，因为 MnO₂ 氧化性不足）。
  - 装置顺序：发生（圆底烧瓶+分液漏斗）→ 除杂（饱和食盐水除 HCl；浓硫酸除水）→ 收集（向上排空气法/排饱和食盐水）→ 尾气（NaOH）。
  - 净化时先除 HCl 再除水。
- **工业**：电解饱和食盐水（氯碱工业）。
- Deacon 工艺（2024·北京卷）：`4HCl+O₂ ═(CuCl₂催化,400℃)═ 2Cl₂+2H₂O`，CuCl₂ 在催化循环中"有-无-有"。

##### 8. 氯离子的检验
- 取待测液 → 加稀硝酸酸化 → 滴加 AgNO₃ 溶液 → 白色沉淀 → 证明含 Cl⁻。**必须酸化**（排除 CO₃²⁻ 干扰）。

#### 第 2 节 卤族元素（F、Cl、Br、I、At）

##### 1. 卤素单质递变规律（F₂→I₂）
| 项目 | F₂ | Cl₂ | Br₂ | I₂ |
|---|---|---|---|---|
| 色态 | 淡黄绿色气体 | 黄绿色气体 | 红棕色液体 | 紫黑色固体 |
| 溶解性 | 与水剧烈反应 | 1:2溶于水 | 微溶 | 微溶（碘易升华） |
| 氧化性 | 最强 | ↓ | | 最弱 |

- **卤素单质氧化性**：F₂ > Cl₂ > Br₂ > I₂，卤离子还原性：I⁻ > Br⁻ > Cl⁻ > F⁻。
- 置换规律：`Cl₂+2Br⁻ = 2Cl⁻+Br₂`、`Cl₂+2I⁻ = 2Cl⁻+I₂`、`Br₂+2I⁻ = 2Br⁻+I₂`。
- F₂ 特殊性：F⁻ 不能被氧化（F 无正价，无含氧酸正盐，HF 是弱酸且腐蚀玻璃）。

##### 2. 卤化氢
- HF：弱酸（氢键），沸点异常高，腐蚀玻璃，检验 Si 用 HF 刻玻璃。
- HCl、HBr、HI：强酸，沸点依次升高（范德华力）。
- 制备：HF 用 `CaF₂+H₂SO₄(浓) ═(△)═ CaSO₄+2HF↑`；HBr/HI 不能用浓硫酸（会被氧化），用**浓磷酸**：`NaBr+H₃PO₄ ═(△)═ NaH₂PO₄+HBr↑`（高沸点酸制低沸点酸）。

##### 3. 卤化银
| AgF | AgCl | AgBr | AgI |
|---|---|---|---|
| 溶于水 | 白色↓ | 淡黄色↓ | 黄色↓ |
| — | 见光分解，用于照相 | 感光材料 | 人工降雨 |

- 检验：AgCl 溶于氨水（配位），AgBr、AgI 不溶。
- `AgCl + 2NH₃ = [Ag(NH₃)₂]⁺ + Cl⁻`（用于提银）。

##### 4. 卤离子检验
- Cl⁻：AgNO₃+稀硝酸 → 白色沉淀。
- Br⁻：AgNO₃ → 淡黄色沉淀；或氯水+四氯化碳 → 橙红色（Br₂ 在 CCl₄ 中）。
- I⁻：AgNO₃ → 黄色沉淀；或氯水+淀粉 → 变蓝。
- 检验先后：先酸化排除 CO₃²⁻。

##### 5. 海水提溴、提碘（高频流程考点）
- **提溴**：浓缩海水 → 通 Cl₂ 置换 `Cl₂+2Br⁻ = 2Cl⁻+Br₂` → 吹出 → 用 SO₂ 吸收 `Br₂+SO₂+2H₂O = 2HBr+H₂SO₄` → 再通 Cl₂ 得高浓度 Br₂。**两次氧化富集**。
- **提碘**（2021·全国甲卷）：海带灰 → 水浸 → 酸化 → 加 H₂O₂ 氧化 `H₂O₂+2I⁻+2H⁺ = I₂+2H₂O` → 萃取（CCl₄/苯）→ 蒸馏。
- 碘的升华可分离 I₂ 与 NaCl。

##### 6. 卤素互化物与拟卤素
- 卤素互化物：IBr、ICl 等，性质类似卤素单质（氧化性）：`ICl+2NaOH = NaI+NaClO+H₂O` 等，其中正价卤素如 I 显 +1。
- 拟卤素：(CN)₂、SCN 等，类似卤素性质。

### 类型例题要点
- 类型Ⅰ 氯气制备与净化装置（先除 HCl 后除水；尾气 NaOH）。
- 类型Ⅱ 氯水成分多角度考查。
- 类型Ⅲ 漂白粉漂白与失效。
- 类型Ⅳ 电解食盐水（阳极 Cl₂ 检验）。
- 类型Ⅴ 海水提溴提碘流程。
- 类型Ⅵ 卤素互化物/拟卤素新情景。

## 模块 3　硫及其化合物 ★★★★

### 内容提要

#### 第 1 节 硫单质、硫的氧化物

##### 1. 硫单质
- **存在**：游离态（火山口）、化合态（硫化物、硫酸盐）。
- **物理性质**：黄色晶体，不溶于水，微溶于酒精，易溶于 CS₂。
- **化学性质**（弱氧化性 + 还原性）：
  - 与金属：`Fe+S ═(△)═ FeS`、`2Cu+S ═(△)═ Cu₂S`、`Hg+S = HgS`（**变价金属生成低价硫化物**，S 氧化性弱）、`2Na+S = Na₂S`。
  - 与非金属：`S+O₂ ═(点燃)═ SO₂`（蓝紫色火焰）、`S+H₂ ═(△)═ H₂S`。
  - 与强氧化剂：`S+2H₂SO₄(浓) ═(△)═ 3SO₂↑+2H₂O`、`S+6HNO₃(浓) ═(△)═ H₂SO₄+6NO₂↑+2H₂O`。
- **用途**：制黑火药（`S+2KNO₃+3C ═(点燃)═ K₂S+N₂↑+3CO₂↑`）、制硫酸、橡胶硫化。

##### 2. 二氧化硫 SO₂
- **物理**：无色有刺激性气味有毒气体，密度大于空气，易液化，易溶于水（1:40）。
- **化学**（S +4 价，既有氧化性又有还原性，主要以还原性为主）：
  - 酸性氧化物：`SO₂+H₂O ⇌ H₂SO₃`、`SO₂+2NaOH = Na₂SO₃+H₂O`、`SO₂+Ca(OH)₂`（少量/过量变浑又清）。
  - 还原性：`2SO₂+O₂ ═(催化/V₂O₅)═ 2SO₃`、`SO₂+X₂+2H₂O = H₂SO₄+2HX`（X=Cl/Br/I，**可使溴水/碘水褪色**）、`5SO₂+2MnO₄⁻+2H₂O = 2Mn²⁺+5SO₄²⁻+4H⁺`（**酸性 KMnO₄ 褪色证明 SO₂ 还原性**）。
  - 氧化性：`SO₂+2H₂S = 3S↓+2H₂O`（归中，生成黄色固体）。
  - **漂白性**：与有色物质结合生成不稳定无色物质（化合漂白），加热恢复原色；**能使品红褪色（加热复红）——SO₂ 漂白性的检验标志**；注意与 Cl₂（氧化漂白，不可逆）区别。
  - 注意：SO₂ 使溴水、KMnO₄、碘水褪色是**还原性**，不是漂白性（2023·全国甲卷）。
- **制备**：`Na₂SO₃+H₂SO₄(浓) = Na₂SO₄+SO₂↑+H₂O`（强酸制弱酸）；工业制硫酸：`4FeS₂+11O₂ ═(高温)═ 2Fe₂O₃+8SO₂`（沸腾炉）。
- **SO₂ 检验与尾气**：品红褪色再加热复红；NaOH 溶液吸收。

##### 3. 三氧化硫 SO₃
- 无色固体（标况下为固体，2023·全国甲卷：2.24L SO₃ 不是 0.1mol），熔点 16.8℃。
- 酸性氧化物：`SO₃+H₂O = H₂SO₄`（剧烈放热）、`SO₃+CaO = CaSO₄`、`SO₃+2NaOH = Na₂SO₄+H₂O`。

##### 4. 工业制硫酸（接触法/沸腾炉法）
1. 沸腾炉：`4FeS₂+11O₂ ═(高温)═ 2Fe₂O₃+8SO₂`
2. 接触室：`2SO₂+O₂ ⇌ 2SO₃`（400~500℃、V₂O₅ 催化剂、**放热反应**，降温提高转化率但降速率，400~500℃为平衡）
3. 吸收塔：`SO₃+H₂O = H₂SO₄`（用 98.3% 浓硫酸吸收 SO₃ 防止酸雾，不能用水直接吸收）

##### 5. 酸雨
- 硫酸型酸雨：`SO₂` → `H₂SO₃` → 被氧化 → `H₂SO₄`。
- 防治：燃煤脱硫（加石灰石/生石灰 `CaO+SO₂ = CaSO₃`、`2CaSO₃+O₂ = 2CaSO₄`）、尾气碱吸收、减少含硫燃料使用。
- 土壤酸化、水体酸化、腐蚀建筑。

#### 第 2 节 含硫的酸、盐

##### 1. 硫化氢 H₂S
- 无色有臭鸡蛋气味有毒气体，弱酸性（二元弱酸）。
- 还原性强：`2H₂S+O₂(不足) = 2S↓+2H₂O`（久置氢硫酸变浑浊）、`2H₂S+3O₂(足) = 2SO₂+2H₂O`；`H₂S+Cl₂ = 2HCl+S↓`；`H₂S+2Fe³⁺ = 2Fe²⁺+S↓+2H⁺`。
- **CuS 不溶于酸**（`H₂S+CuSO₄ = CuS↓+H₂SO₄`），用于除 H₂S。

##### 2. 亚硫酸 H₂SO₃
- 中强酸、二元弱酸、不稳定（`H₂SO₃ ═(△)═ SO₂↑+H₂O`）。
- 既有氧化性又有还原性（以还原性为主）。
- 还原性：`H₂SO₃+I₂+H₂O = H₂SO₄+2HI`、`2H₂SO₃+O₂ = 2H₂SO₄`（被空气氧化）。

##### 3. 浓硫酸（特性：吸水性、脱水性、强氧化性）
- **吸水性**：吸收游离水，用作干燥剂（干燥中性与酸性气体；**不能干燥碱性气体 NH₃、还原性气体 H₂S/HBr/HI**）。
- **脱水性**：按 2:1 夺取有机物中 H、O（蔗糖变黑，再膨胀）。
- **强氧化性**（S +6 价）：
  - 与金属：`Cu+2H₂SO₄(浓) ═(△)═ CuSO₄+SO₂↑+2H₂O`（体现酸性+氧化性）；**常温钝化 Fe、Al**（浓硫酸也钝化，与浓硝酸同）。
  - 与非金属：`C+2H₂SO₄(浓) ═(△)═ CO₂↑+2SO₂↑+2H₂O`。
  - 与还原性化合物：`H₂S+H₂SO₄(浓) = S↓+SO₂↑+2H₂O`、`2HBr+H₂SO₄(浓) ═(△)═ Br₂↑+SO₂↑+2H₂O`、`8HI+H₂SO₄(浓) ═(△)═ 4I₂+H₂S↑+4H₂O`。
- **稀释**：酸入水，不断搅拌。

##### 4. 硫化物与硫氢化物
- 金属硫化物溶解性规律：钾钠铵盐溶，K₂S、Na₂S 水解强碱；CuS、PbS、Ag₂S、HgS 等不溶于水也不溶于酸。
- Na₂S：水解 `S²⁻+H₂O ⇌ HS⁻+OH⁻`，溶液碱性。
- NaHS：酸式盐，电离与水解共存。

##### 5. 亚硫酸盐与亚硫酸氢盐
- Na₂SO₃：还原性，`Na₂SO₃+O₂ = Na₂SO₄`（久置变质）；`SO₃²⁻+Br₂+H₂O = SO₄²⁻+2Br⁻+2H⁺`。
- NaHSO₃：**电离程度 > 水解程度，溶液显酸性**；酸式盐与碱反应。

##### 6. 硫酸盐与硫酸氢盐
- 硫酸盐溶解性：BaSO₄（不溶于水不溶于酸，钡餐，**X 射线造影**）、CaSO₄（微溶）、Ag₂SO₄（微溶）、PbSO₄（不溶）。
- **BaSO₄ 检验 SO₄²⁻**：先加稀盐酸酸化排除 SO₃²⁻/CO₃²⁻ 干扰，再加 BaCl₂ → 白色沉淀。
- 硫酸氢钠 NaHSO₄：**强酸式盐**（水中完全电离 NaHSO₄ = Na⁺+H⁺+SO₄²⁻），溶液强酸性。

##### 7. 硫代硫酸盐
- Na₂S₂O₃（海波/大苏打）：`S₂O₃²⁻` 中硫平均 +2 价。
- 与酸：`S₂O₃²⁻+2H⁺ = S↓+SO₂↑+H₂O`（**歧化**，生成 S 和 SO₂，2023·广东卷）。
- 还原性（I₂ 滴定）：`2S₂O₃²⁻+I₂ = S₄O₆²⁻+2I⁻`（碘量法定量分析基础）。
- 银镜反应定影：`AgBr+2S₂O₃²⁻ = [Ag(S₂O₃)₂]³⁻+Br⁻`。

##### 8. 过二硫酸钠 Na₂S₂O₈
- S 平均 +7 价，强氧化剂（含 O—O 键，类似过氧化物）。

##### 9. 其他含硫化合物
- **SOCl₂（二氯亚砜/亚硫酰氯）**：S 为 +4，中心 S 为 sp³、三角锥形；水解 `SOCl₂+H₂O = SO₂↑+2HCl↑`；与足量 NaOH：`SOCl₂+4NaOH = Na₂SO₃+2NaCl+2H₂O`；强还原性，`SOCl₂+2Fe³⁺+3H₂O = SO₄²⁻+2Fe²⁺+6H⁺+2Cl⁻`；有机化学中制乙酰氯。
- **SO₂Cl₂（磺酰氯/硫酰氯）**：水解 `SO₂Cl₂+2H₂O = H₂SO₄+2HCl`。
- **Na₂S₂（过硫化钠）**：S 为 -1，与盐酸歧化 `Na₂S₂+2HCl = 2NaCl+S↓+H₂S↑`。

#### 硫的"价类二维图"与转化规律
- **邻价原则**：相邻价态间不发生氧化还原（浓硫酸可干燥 SO₂）。
- **跳跃原则**：强氧化剂/强还原剂 + 过量 → 跨价态跳跃（如 H₂S 直接被浓硝酸氧化到 H₂SO₄）。
- **连续氧化**：H₂S →(足量O₂) SO₂ →(O₂,V₂O₅) SO₃ →(H₂O) H₂SO₄；S → SO₂ → SO₃ → H₂SO₄。
- 同价转化靠酸碱（量变引起质变，少量/过量）。

### 类型例题要点
- 类型Ⅰ 基础常识正误判断：Na₂S 除 Hg²⁺；SO₂ 化合漂白非氧化；标况 SO₃ 固体；可逆反应不彻底；SO₂ 与 H₂O 化合反应 vs 与 H₂S 归中；浓硫酸与 C/Cu 酸性气体不同。
- 类型Ⅱ 硫循环示意图（海水 S 以 SO₄²⁻ 存在；煤加生石灰脱硫）。
- 类型Ⅲ 价类二维图（H₂S 还原性、NaHSO₃ 酸性、非金属性比较）。
- 类型Ⅳ 化工流程（FeS₂ 焙烧、接触室温度、尾气碱吸收）。
- 类型Ⅴ 实验（S₂O₃²⁻ 酸性歧化、Cu 与浓硫酸探究、焦亚硫酸钠制备、SOCl₂ 制备）。

## 模块 4　氮及其化合物 ★★★

### 内容提要

#### 第 1 节 氮气、氮的氧化物、氮的氢化物

##### 1. 氮气 N₂
- **存在**：游离态（大气中 N₂，约占78%）+ 化合态（蛋白质、硝酸盐、铵盐）。
- **结构**：`N≡N` 三键，键能大，化学性质稳定。
- **电子式**：N::N:（两侧各一对孤电子对，**勿漏**）；等电子体：CO、CN⁻、C₂²⁻。
- **化学性质**（0 价是稳价和中间价，弱氧化+弱还原）：
  - 与金属：`3Mg+N₂ ═(点燃)═ Mg₃N₂`
  - 与 H₂：`N₂+3H₂ ⇌(高温高压催化剂) 2NH₃`（合成氨，可逆）
  - 与 O₂：`N₂+O₂ ═(放电/高温)═ 2NO`（**只生成 NO**，不论 O₂ 多少）
- **用途**：合成氨原料、保护气（充氮保存食品）。

##### 2. 氮的固定
- 定义：游离态 N₂ → 氮的化合物。
- 三类：**高能固氮**（雷电 N₂+O₂→NO）、**生物固氮**（根瘤菌）、**人工固氮**（合成氨）。均为氧化还原反应（2023·全国甲卷元素推断、氮循环题）。

##### 3. 氮的氧化物
| 氧化物 | N₂O | NO | N₂O₃ | NO₂ | N₂O₄ | N₂O₅ |
|---|---|---|---|---|---|---|
| N 价 | +1 | +2 | +3 | +4 | +4 | +5 |
| 酸性氧化物？ | 否 | 否 | 是(HNO₂) | 否 | 否 | 是(HNO₃) |

- **NO**：无色无味有毒、难溶于水、密度与空气接近（**不能用排空气法收集，用排水法**）。
  - 还原性：`2NO+O₂ = 2NO₂`（无色变红棕，检验 NO 常用）；`NO+NO₂+2NaOH = 2NaNO₂+H₂O`（**亚硝酸盐**）；`4NO+3O₂+4NaOH = 4NaNO₃+2H₂O`。
  - 尾气：NO 不能直接用 NaOH 吸收，用酸性 KMnO₄：`5NO+3MnO₄⁻+4H⁺ = 3Mn²⁺+5NO₃⁻+2H₂O`，或 NO 与 O₂ 混合后通入 NaOH。
- **NO₂**：红棕色有刺激性气味有毒、易溶于水、密度大于空气（**向上排空气法收集**；高中常考红棕色气体还有 Br₂ 蒸气）。
  - 与水：`3NO₂+H₂O = 2HNO₃+NO`（**不是全转化为硝酸，通 O₂ 可完全吸收**：`4NO₂+O₂+2H₂O = 4HNO₃`）。
  - 与 NaOH：`2NO₂+2NaOH = NaNO₃+NaNO₂+H₂O`（歧化）；`NO₂+NO+2NaOH = 2NaNO₂+H₂O`。
  - 二聚：`2NO₂(红棕) ⇌ N₂O₄(无色)` ΔH<0（加热颜色加深，2023·北京卷）。
  - 氧化性：`2NO₂+4CO ═(催化剂/△)═ N₂+4CO₂`（汽车尾气处理）。
- **NOₓ 危害与治理**：光化学烟雾、硝酸型酸雨、臭氧空洞、与血红蛋白结合中毒；治理=新能源/碱吸收（转化为硝酸盐亚硝酸盐）/催化转化（NH₃ 或 CO 还原为 N₂）。

##### 4. 氨气 NH₃
- **电子式**：H:N:H（N 一对孤电子对），三角锥形。
- **物理**：无色刺激性气味、密度小于空气、**极易溶于水（1:700）**、易液化（液氨制冷剂）、分子间氢键。
- **化学**：
  - 碱性：`NH₃+H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺+OH⁻`；`NH₃+HCl = NH₄Cl`（蘸浓氨水与浓盐酸玻璃棒靠近生白烟；**挥发性的酸 HNO₃、醋酸也白烟，浓硫酸无白烟**）。
  - 配位：`AgCl+2NH₃ = [Ag(NH₃)₂]⁺+Cl⁻`；`AgOH+2NH₃ = [Ag(NH₃)₂]⁺+OH⁻`；`Cu(OH)₂+4NH₃ = [Cu(NH₃)₄]²⁺+2OH⁻`（**银氨溶液、铜氨溶液**）。
  - 强还原性：`8NH₃+3Cl₂ = N₂+6NH₄Cl`（浓氨水检验 Cl₂ 漏气）；`4NH₃+3O₂(纯) ═(点燃)═ 2N₂+6H₂O`；`4NH₃+5O₂ ═(催化剂/△)═ 4NO+6H₂O`（**工业制硝酸关键一步，铂催化**）；`8NH₃+6NO₂ ═(点燃)═ 7N₂+12H₂O`（**NH₃ 还原 NOₓ 脱硝**）。
- **氨水的化学式选择规律**：体现碱性写 NH₃·H₂O；配位反应写 NH₃；低温产物写 NH₃·H₂O、高温写 NH₃。
- **实验室制 NH₃**：
  - 原理1：`2NH₄Cl+Ca(OH)₂ ═(△)═ CaCl₂+2NH₃↑+2H₂O`（强碱制弱碱；铵盐选 NH₄Cl，碱选 Ca(OH)₂ 不用 NaOH——腐蚀玻璃；试管口略向下倾斜）。
  - 原理2：浓氨水滴入碱石灰：`CaO+NH₃·H₂O = NH₃↑+Ca(OH)₂`（CaO 与水放热）。
  - 干燥：**碱石灰**（不能用浓硫酸/无水 CaCl₂——CaCl₂ 与 NH₃ 生成 CaCl₂·8NH₃）。
  - 收集：向下排空气法或排 CCl₄。
  - 尾气：水或酸吸收，**防倒吸**（倒扣漏斗）。
- **喷泉实验**：原理=烧瓶内外压强差。
  - 组合：NH₃/HCl 用**水**引发；CO₂/SO₂/H₂S/Cl₂/NO₂ 用 **NaOH 溶液**引发（NO₂ 用水也可，但 NaOH 更完全）。
  - 引发方式多样：热毛巾/冷毛巾使气体膨胀或收缩接触液体；两种气体混合反应（`2H₂S+SO₂ = 3S↓+2H₂O`）导致气压降低。
  - 扩展：若气体完全溶解且为理想溶液，`φ`（体积分数）与物质的量浓度 c 关系：c = V/22.4（标况 NH₃ 溶于水）。

##### 5. 联氨 N₂H₄（肼）
- 电子式 H:N:N:H，与水形成氢键，互溶。
- 弱碱性：`N₂H₄+H₂O ⇌ N₂H₅⁺+OH⁻`；`N₂H₄+2HCl(足) = N₂H₆Cl₂`（二元碱）。
- 强还原性燃料：`N₂H₄+O₂(纯) ═(点燃)═ N₂+2H₂O`；与 N₂O₄ 组成火箭推进剂。

##### 6. 一水合氨 NH₃·H₂O
- 一元弱碱（Kb≈醋酸 Ka），浓溶液易挥发。
- 碱性：`NH₃·H₂O ⇌ NH₄⁺+OH⁻`；`CuSO₄+2NH₃·H₂O = Cu(OH)₂↓+(NH₄)₂SO₄`。
- 受热分解：`NH₃·H₂O ═(△)═ NH₃↑+H₂O`。

#### 第 2 节 含氮的酸和盐、磷及其化合物

##### 1. 含氮的酸
| 名称 | 叠氮酸 | 亚硝酸 | 硝酸 |
|---|---|---|---|
| 化学式 | HN₃ | HNO₂ | HNO₃ |
| 类别 | 弱酸（类醋酸） | 中强酸 | 强酸 |

- **亚硝酸 HNO₂**：中强酸（部分电离）；不稳定 `2HNO₂ = NO₂↑+NO↑+H₂O`；既有氧化性又有还原性。
- **硝酸 HNO₃**：
  - 物理：无色易挥发有刺激性气味，极易溶于水。
  - 化学：
    - 强氧化性——与金属：**Fe、Al 常温遇浓硝酸钝化**（致密氧化膜）；Fe 少量：`Fe+4HNO₃(稀) = Fe(NO₃)₃+NO↑+2H₂O`，Fe 过量：`3Fe+8HNO₃(稀) = 3Fe(NO₃)₂+2NO↑+4H₂O`；Cu：`Cu+4HNO₃(浓) = Cu(NO₃)₂+2NO₂↑+2H₂O`、`3Cu+8HNO₃(稀) = 3Cu(NO₃)₂+2NO↑+4H₂O`；Mg 与极稀硝酸：`4Mg+10HNO₃(稀) = 4Mg(NO₃)₂+NH₄NO₃+3H₂O`（**还原产物可为 NH₄NO₃**）。
    - 与非金属：`C+4HNO₃(浓) ═(△)═ CO₂↑+4NO₂↑+2H₂O`；`P+5HNO₃(浓) ═(△)═ H₃PO₄+5NO₂↑+H₂O`。
    - 与还原性化合物：`3Fe²⁺+NO₃⁻+4H⁺ = 3Fe³⁺+NO↑+2H₂O`（**NO₃⁻ 酸性条件下才显强氧化性**）。
    - 不稳定性：`4HNO₃ ═(光照/△)═ 4NO₂↑+O₂↑+2H₂O`（**棕色瓶避光保存**，久置浓硝酸变黄——溶有 NO₂）。
  - 规律：无特殊说明浓硝酸→NO₂、稀硝酸→NO；与金属反应部分氧化还原（体现酸性+氧化性）；活泼金属与硝酸不放 H₂。
  - **王水**：浓 HNO₃:浓 HCl = 1:3（体积比），能溶解 Pt、Au（硝酸氧化性+盐酸配位）：`Au+HNO₃+4HCl = NO↑+2H₂O+H[AuCl₄]`。
  - 工业制硝酸（氨氧化法）：①`N₂+3H₂ ⇌ 2NH₃` ②`4NH₃+5O₂ ═(催化/△)═ 4NO+6H₂O` ③`2NO+O₂ = 2NO₂` ④`4NO₂+O₂+2H₂O = 4HNO₃`。

##### 2. 含氮的盐
- **铵盐**：绝大多数易溶于水、溶于水吸热。
  - 与碱反应：`NH₄Cl+NaOH ═(△)═ NaCl+NH₃↑+H₂O`（NH₄⁺ 检验：加 NaOH 加热，湿润红色石蕊试纸变蓝）。
  - 受热分解规律：
    - 对应酸稳定且无氧化性 → NH₃+酸：`NH₄Cl ═(△)═ NH₃↑+HCl↑`
    - 对应酸不稳定且无氧化性 → NH₃+酸性氧化物+水：`NH₄HCO₃ ═(△)═ NH₃↑+CO₂↑+H₂O`、`NH₄HSO₃ ═(△)═ NH₃↑+SO₂↑+H₂O`
    - 对应酸有氧化性 → 产物含 N₂：`5NH₄NO₃ ═(△)═ 4N₂↑+2HNO₃+9H₂O`
  - 水解：`NH₄⁺+H₂O ⇌ NH₃·H₂O+H⁺`（酸性）。
- **叠氮酸盐**：`N₃⁻` 与 CO₂ 等电子体，sp 杂化直线形，含 Π₃⁴ 大π键；汽车安全气囊 `3NaN₃ ═(撞击)═ 4N₂↑+Na₃N`。
- **硝酸盐**：易溶、溶于水吸热；受热分解（金属越活泼越难分解）：`2AgNO₃ ═(△)═ 2Ag+2NO₂↑+O₂↑`（Ag 分解最易，其余活泼金属硝酸盐生成亚硝酸盐/氧化物+NO₂+O₂）；**硝酸盐热分解必放 O₂**（故 KNO₃ 作氧化剂制黑火药）。

##### 3. 氮的价类二维图（高频）
- 元素：NH₃(-3) → N₂(0) → NO(+2) → NO₂/N₂O₄(+4) → HNO₃(+5)；HNO₂(+3)；N₂O₅(+5)；N₂O₃(+3)。
- 转化关键：N₂→NO 放电固氮；NH₃→NO 催化氧化；NO→NO₂ 氧化；NO₂→HNO₃ 与水（+O₂ 完全吸收）；HNO₃→NO₂ 自身分解/被还原。
- 例：`N₂O₅+H₂O = 2HNO₃`（化合价不变，不须氧化剂）；`HNO₂` 既有氧化性又有还原性；`HNO₃→NO₂` 可自身分解。

##### 4. 磷及其化合物
- **磷单质**：红磷（稳定，安全火柴）、白磷 P₄（正四面体，键角60°，1mol P₄ 含 6mol P—P 键，**剧毒、易自燃、水中保存**）。`4P+5O₂ ═(点燃)═ 2P₂O₅`；`2P+3Cl₂ ═(点燃)═ 2PCl₃`。
- **磷的氧化物**：P₄O₆(P₂O₃)、P₄O₁₀(P₂O₅)，均为酸性氧化物；**P₂O₅ 是常用干燥剂但不能作食品干燥剂**（2024·山东卷）；P₂O₅ 吸水性强。
- **PH₃**：极强还原性，自燃（"鬼火"）：`2PH₃+4O₂ = P₂O₅+3H₂O`。
- **含磷的酸**：
  | 名称 | 次磷酸 | 亚磷酸 | 正磷酸 |
  |---|---|---|---|
  | 化学式 | H₃PO₂ | H₃PO₃ | H₃PO₄ |
  | 元数 | 一元酸 | 二元酸 | 三元酸 |
  - 非羟基氧越多酸性越强（H₃PO₄ 中强酸）。
  - 与足量 NaOH：NaH₂PO₂（正盐！H₃PO₂ 一元酸）、Na₂HPO₃、Na₃PO₄。
  - H₃PO₂、H₃PO₃ 是强还原性酸；H₃PO₄ 高沸点酸，**可制 HCl/HBr/HI**（高沸点酸制低沸点酸）。
- **含磷的盐**：磷酸盐只溶钾钠铵盐；NaH₂PO₄ 溶液酸性（H₂PO₄⁻ 电离>水解）、Na₂HPO₄ 溶液碱性（HPO₄²⁻ 水解>电离）；**含磷洗涤剂/化肥过量 → 水体富营养化**。
- **磷的氯化物**：PCl₃（三角锥形）、PCl₅（三角双锥形），均极易水解：`PCl₃+3H₂O = 3HCl+H₃PO₃`、`PCl₅+4H₂O = 5HCl+H₃PO₄`。

### 类型例题要点
- 类型Ⅰ 基础常识：NO₂/N₂O₄ 平衡颜色；喷泉实验验证 NH₃ 极易溶+碱性；氨水与 AgNO₃ 互滴现象不同；碱石灰干燥 NH₃；NH₃·H₂O 微粒数目小于 0.1N_A（氨水不完全以 NH₃·H₂O 存在）。
- 类型Ⅱ 阿伏加德罗常数：合成氨可逆转移电子<6N_A；NO+O₂ 生成 NO₂ 又二聚分子数<2N_A；1mol NO₂ 与 NaOH 歧化转移 0.5N_A；镁在空气中燃烧 N³⁻ 个数小于 2N_A（有 MgO 生成）。
- 类型Ⅲ 元素推断（WX₂ 为 NO₂/SO₂ 酸雨切入）。
- 类型Ⅳ 实验：喷泉实验组合判断；NO₂ 制取收集吸收转化。
- 类型Ⅴ 硝酸与金属（钝化、Fe²⁺ 检验顺序、[Fe(NO)]SO₄ 棕色）。
- 类型Ⅵ 化工流程（Na₂HPO₄·12H₂O 中和法、K 值比大小判断酸碱性）。

## 关键方程式速览

### 模块1 碳硅
1. `SiO₂+2C ═(高温)═ Si+2CO↑`（粗硅）
2. `Si+2Cl₂ ═(加热)═ SiCl₄`；`SiCl₄+2H₂ ═(高温)═ Si+4HCl`
3. `SiO₂+4HF = SiF₄↑+2H₂O`（刻玻璃）
4. `SiO₂+2NaOH = Na₂SiO₃+H₂O`（玻璃塞腐蚀）
5. `Na₂SiO₃+CO₂+H₂O = H₂SiO₃↓+Na₂CO₃`（CO₂ 过量→NaHCO₃）
6. `C+CO₂ ═(高温)═ 2CO`
7. `NaCl+NH₃+CO₂+H₂O = NaHCO₃↓+NH₄Cl`（侯氏制碱）

### 模块2 卤素
1. `2Fe+3Cl₂ ═(点燃)═ 2FeCl₃`；`Cu+Cl₂ ═(点燃)═ CuCl₂`
2. `H₂+Cl₂ ═(点燃)═ 2HCl`
3. `Cl₂+H₂O ⇌ HCl+HClO`；`2HClO ═(光照)═ 2HCl+O₂↑`
4. `Cl₂+2NaOH = NaCl+NaClO+H₂O`
5. `2Cl₂+2Ca(OH)₂ = Ca(ClO)₂+CaCl₂+2H₂O`（制漂白粉）
6. `MnO₂+4HCl(浓) ═(△)═ MnCl₂+Cl₂↑+2H₂O`
7. `Cl₂+2KI = 2KCl+I₂`；`Cl₂+SO₂+2H₂O = 2HCl+H₂SO₄`
8. `Br₂+SO₂+2H₂O = 2HBr+H₂SO₄`（提溴富集）
9. `H₂O₂+2I⁻+2H⁺ = I₂+2H₂O`（提碘氧化）
10. `2NaCl+2H₂O ═(电解)═ 2NaOH+H₂↑+Cl₂↑`（氯碱工业）

### 模块3 硫
1. `Fe+S ═(△)═ FeS`；`2Cu+S ═(△)═ Cu₂S`；`S+O₂ ═(点燃)═ SO₂`
2. `2SO₂+O₂ ⇌(V₂O₅,400-500℃) 2SO₃`；`SO₃+H₂O = H₂SO₄`
3. `4FeS₂+11O₂ ═(高温)═ 2Fe₂O₃+8SO₂`（沸腾炉）
4. `SO₂+2H₂S = 3S↓+2H₂O`（归中）
5. `SO₂+X₂+2H₂O = H₂SO₄+2HX`（X=Cl/Br/I，还原性）
6. `5SO₂+2MnO₄⁻+2H₂O = 2Mn²⁺+5SO₄²⁻+4H⁺`（还原性，KMnO₄ 褪色）
7. `Cu+2H₂SO₄(浓) ═(△)═ CuSO₄+SO₂↑+2H₂O`
8. `C+2H₂SO₄(浓) ═(△)═ CO₂↑+2SO₂↑+2H₂O`
9. `Na₂SO₃+H₂SO₄(浓) = Na₂SO₄+SO₂↑+H₂O`（SO₂ 制备）
10. `S₂O₃²⁻+2H⁺ = S↓+SO₂↑+H₂O`（硫代硫酸歧化）
11. `SOCl₂+H₂O = SO₂↑+2HCl↑`；`SOCl₂+4OH⁻ = SO₃²⁻+2Cl⁻+2H₂O`
12. `2H₂S+O₂(不足) = 2S↓+2H₂O`（氢硫酸变质）

### 模块4 氮
1. `N₂+3H₂ ⇌(高温高压催化剂) 2NH₃`（合成氨）
2. `N₂+O₂ ═(放电)═ 2NO`（高能固氮）
3. `3Mg+N₂ ═(点燃)═ Mg₃N₂`
4. `2NO+O₂ = 2NO₂`
5. `3NO₂+H₂O = 2HNO₃+NO`；`4NO₂+O₂+2H₂O = 4HNO₃`
6. `2NO₂+2NaOH = NaNO₃+NaNO₂+H₂O`；`NO+NO₂+2NaOH = 2NaNO₂+H₂O`
7. `2NO₂ ⇌ N₂O₄`（ΔH<0）
8. `4NH₃+5O₂ ═(催化/△)═ 4NO+6H₂O`（工业制硝酸关键）
9. `8NH₃+3Cl₂ = N₂+6NH₄Cl`；`8NH₃+6NO₂ ═(点燃)═ 7N₂+12H₂O`（脱硝）
10. `2NH₄Cl+Ca(OH)₂ ═(△)═ CaCl₂+2NH₃↑+2H₂O`（实验室制氨）
11. `AgCl+2NH₃ = [Ag(NH₃)₂]⁺+Cl⁻`；`Cu(OH)₂+4NH₃ = [Cu(NH₃)₄]²⁺+2OH⁻`
12. `Fe+4HNO₃(稀) = Fe(NO₃)₃+NO↑+2H₂O`；`Cu+4HNO₃(浓) = Cu(NO₃)₂+2NO₂↑+2H₂O`
13. `4HNO₃ ═(光照/△)═ 4NO₂↑+O₂↑+2H₂O`
14. `3Fe²⁺+NO₃⁻+4H⁺ = 3Fe³⁺+NO↑+2H₂O`
15. `4Mg+10HNO₃(稀) = 4Mg(NO₃)₂+NH₄NO₃+3H₂O`
16. `5NH₄NO₃ ═(△)═ 4N₂↑+2HNO₃+9H₂O`
17. `N₂H₄+O₂(纯) ═(点燃)═ N₂+2H₂O`（肼燃料）
18. `4P+5O₂ ═(点燃)═ 2P₂O₅`；`PCl₃+3H₂O = 3HCl+H₃PO₃`；`PCl₅+4H₂O = 5HCl+H₃PO₄`

## 易错点与命题规律

1. **"标况非气"陷阱**：SO₃、白磷、苯、HF 标况非气态，2.24L ≠ 0.1mol。
2. **漂白性 ≠ 还原性**：SO₂ 使品红/有色布条褪色=漂白（可逆）；使 KMnO₄/溴水/碘水褪色=还原性（不可逆）。
3. **"少量/过量"量变**：CO₂、SO₂ 与碱；Fe 与稀硝酸；AlCl₃ 与 NaOH——产物随量变。
4. **邻价不反应**：浓硫酸可干燥 SO₂（+4 与 +6 相邻）。
5. **钝化双雄**：Fe、Al 常温遇浓硫酸、浓硝酸均钝化；加热后氧化膜被破坏继续反应。
6. **NO 收集用排水法**（密度近空气且与 O₂ 反应）；**NO₂ 收集用向上排空气法**（与水反应）。
7. **铵盐分解三规律**：酸稳定无氧化性→NH₃+酸；酸不稳定无氧化性→NH₃+酸性氧化物+H₂O；酸有氧化性→N₂。
8. **检验顺序**：SO₄²⁻ 先盐酸酸化再 BaCl₂；Cl⁻ 先硝酸酸化再 AgNO₃；NH₄⁺ 加碱加热红色石蕊。
9. **硝酸还原产物**：浓→NO₂、稀→NO、极稀（Mg）→NH₄NO₃；N₂O₅ 酸酐、N₂O₃ 亚硝酸酐。
10. **催化剂判断"有无有"**：循环图中一开始有、中间消失、最后出现的物质是催化剂（Deacon、脱硫）。
