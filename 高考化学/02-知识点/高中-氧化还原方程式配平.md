# 高中-氧化还原方程式配平

> [!tip] 核心方法
> 配平三步走：**标变价、列变化、找最小公倍数、定系数** → **未变价元素原子守恒**（离子式用 H⁺/OH⁻ 调电荷）→ **看 H 补水、用 O 检查**。方向选择：完全/归中**正向**配、部分/歧化**逆向**配；角标规矩「正向看反应物、逆向看生成物」。

## 一、核心概念（是什么）

### 1. 化学方程式配平三步

1. **标变价、列变化、找最小公倍数、定系数**——决定还原剂/氧化剂系数，同时配平产物的变价元素。
2. **未变价元素原子守恒**——部分氧化还原中既变价又不变价的元素，以及除 H、O 外的未变价元素。
3. **看 H 补水、用 O 检查**——H 原子守恒定 H₂O 的位置与个数，最后检查 O 守恒；无 H/O 时第二步即完成。

### 2. 离子方程式配平三步

1. 标变价、列变化、找倍数、定系数。
2. **电荷守恒**——酸性环境补 H⁺、碱性环境补 OH⁻；未明确酸碱时「水出酸或碱」（H⁺/OH⁻ 写在方程式**右侧**）。
3. 看 H 补水、用 O 检查。

### 3. 配平方向与角标

| 反应类型 | 配平方向 |
|---|---|
| 完全氧化还原、归中 | 正向 |
| 部分氧化还原、歧化 | 逆向 |

- 正向配平**注意反应物角标**；逆向配平**注意生成物角标**（变价原子有角标时化合价变化要乘角标）。

### 4. 有机化合物配平三法

- **平均值法**：H 规定 +1、O 规定 −2，由正负化合价代数和为零求 C 的平均价态。
- **组成法**：多 1 个 O 或少 2 个 H → 价升 2（氧化）；多 2 个 H 或少 1 个 O → 价降 2（还原）。
- **燃烧法**（只含 C、H、O 且平均价态为分数）：有机物系数定 1，仅按原子守恒配平，转移电子数 = O₂ 系数 × 4。
- ⭐ 有机物 H 往往多于 O → **用 O 原子守恒定 H₂O，最后用 H 原子守恒检查**。

## 二、关键规律（典例速记）

| 类型 | 典例 |
|---|---|
| 完全·正向 | 2MnO₄⁻ + 5NO₂⁻ + 6H⁺ = 2Mn²⁺ + 5NO₃⁻ + 3H₂O（Mn 降 5、N 升 2） |
| 部分·逆向 | 3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（6 个 NO₃⁻ 不变价） |
| 角标·完全 | K₂Cr₂O₇ + 3H₂O₂ + 4H₂SO₄ = K₂SO₄ + Cr₂(SO₄)₃ + 3O₂↑ + 7H₂O（2 个 Cr 共降 6；2 个 O 共升 2） |
| 多变价元素 | 15ClO₃⁻ + FeS₂ + 14H⁺ = 15ClO₂↑ + Fe³⁺ + 2SO₄²⁻ + 7H₂O（FeS₂：Fe 升 1 + S 升 7×2 = 共升 15） |
| 歧化·逆向 | 3S + 6KOH = 2K₂S + K₂SO₃ + 3H₂O（S 升 2 与降 4 → 2:1，看生成物角标） |
| 有机物 | CH₃CHO + 2Cu(OH)₂ + NaOH =Δ= CH₃COONa + Cu₂O↓ + 3H₂O（醛基多 1 O 升 2；Cu 降 1 → 1:2，O 守恒补水） |

特殊技巧：**零价法**（Fe₃C + 22HNO₃：假设 Fe、C 均 0 价，3Fe 升 9 + C 升 4 = 13）；**设价消元法**（4CuSCN + 7KIO₃：假设复杂价态固定，把变价集中到 S 与 I）。

## 四、易错点

> [!warning] 易错
> ① 逆向配平忘乘产物角标（歧化 3S+6KOH 的 2 与 1 来自 K₂S/K₂SO₃ 角标）；② 电荷守恒漏补 H⁺/OH⁻（酸性补 H⁺ 记牢）；③ H₂O 定位错——先看 H 再查 O，H 多 O 少时用 O 守恒定水；④ 未变价元素（部分氧化还原的 HNO₃ 中有 6 个 NO₃⁻ 不变价）漏配；⑤ 系数不是最简整数比（分数系数扩倍）；⑥ 有机物「少 2 H = 降 2、多 1 O = 升 2」的符号记反。

## 五、方法点拨

> [!tip] 配平五查
> 查①变价（标全没标全）②原子守恒（含未变价元素）③电荷守恒（离子式）④状态（↑↓）⑤最简整数比。角标口诀：**正看反应物、逆看生成物、歧化并排看**。归中反应（KClO₃+6HCl）判定铁律：+5 与 −1 都靠向 0，**严禁交叉**（+5→−1、−1→0 是错误分析）。

## 六、常见题型

- **类型Ⅰ 完全氧化还原（正向配平）**：MnO₄⁻/NO₂⁻、KMnO₄+FeSO₄
- **类型Ⅱ 部分氧化还原（逆向配平）**：Cu+稀 HNO₃、NaNO₂+HI、Fe₃O₄+HNO₃（平均价 +8/3）
- **类型Ⅲ 角标/同反应物多变价**：K₂Cr₂O₇+H₂O₂、15ClO₃⁻+FeS₂、NaN₃
- **类型Ⅳ 歧化/归中配平**：3S+6KOH、2P₄+Ba(OH)₂、KClO₃+6HCl
- **类型Ⅴ 有机物配平**：CH₃CHO+Cu(OH)₂、C₆H₅CH₃+KMnO₄、Fe₃C 零价法
