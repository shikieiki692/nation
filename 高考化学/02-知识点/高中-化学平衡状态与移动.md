# 高中-化学平衡状态与移动

> 一句话定位：**平衡看「v正=v逆」**——会不会动，看条件改变瞬间谁强；往哪动，看勒夏特列「减弱不抵消」。判断到没到平衡，全库就一个词：**「变量不变」**。

## 一、核心概念（是什么）

- **可逆反应特征**：同时进行、同条件、反应物与生成物并存、转化率 < 100%。
- **化学平衡状态**：正逆反应速率相等，各组分浓度不再改变。
- **平衡特征「逆等动定变」**：可逆（逆）、等（v正=v逆）、动（动态平衡，v≠0）、定（浓度不变）、变（条件改变则破坏平衡）。
- **平衡本质**：v正 = v逆，不是「反应停止」。
- **移动本质**：条件改变瞬间 v正≠v逆 → 平衡移动；**「谁强显谁性」**——谁速率大向谁方向移动，直到重新相等。

## 二、关键规律/公式

### 平衡标志判据「变量不变」

| 判据 | 是标志的条件 | 反例/注意 |
|---|---|---|
| 本质法 v正=v逆 | 同物质直接比较；异物质按 **v正:v逆 = 计量数比** | 比值错即误判 |
| 某成分物质的量/浓度/百分含量 | 不变即标志 | 起始比例恰合时易误判 |
| 浓度**比例** | 瞬时比例不是；持续「非计量数比」是；「计量数比」不是 | 反产比恒成立，恒不是标志 |
| 总压 | 恒容且气体计量数不同才是 | 恒压体系不是；恒容计量数相同不是 |
| 气体密度 ρ | m总 或 V 为变量时 | 全是气体且恒容恒温 → ρ 恒不变，不是标志 |
| 平均摩尔质量 | m总 / n总 为变量时 | 气体计量数相同则不是 |
| 颜色 | 有**有色气体**参与时可作标志 | 恒压下稀释变色≠平衡破坏 |
| 绝热恒容 | **温度本身就是标志** | 不能套恒温经验 |

> 口诀：**判断前先问「这变量真的是变量吗？」**——气体计量数相同 → n总、ρ、M̄ 恒非变量。

### 影响平衡的因素

| 因素 | 移动方向 | 口诀 |
|---|---|---|
| 增大反应物浓度 | 正向 | 增c反→正移；减c产→正移（分离产物） |
| 增大压强 | 向气体分子数减少方向 | **大压小移** |
| 升高温度 | 向吸热方向 | **升呼吸**；降温→放热 |
| 催化剂 | **不移动**，只缩时 | — |
| 恒容通入稀有气体 | 不移动（浓度不变） | — |
| 恒温恒压通入惰性气体 | ≈ 减压，向气体增多方向 | **小压大移** |

- **勒夏特列原理**：改变影响平衡的一个条件，平衡向**减弱这种改变**的方向移动，但**不能抵消**。（例外：恒温恒容加入固体反应物 B(s) 时体系可完全抵消，因 B 浓度视为常数。）
- **转化率规律「大大等等小小」**：单反应物气体（如 aA(g)⇌bB(g)），平衡后加 A：
  - a > b（计量数之和减）→ 转化率**增大**；
  - a = b → **不变**；
  - a < b → **减小**。
- **竞争反应**：转化率与选择性分离——转化率看速率/平衡，选择性看催化剂；**产率 = 转化率 × 选择性**。

## 三、高考考查方式

- 题型：平衡标志正误判断（选择/填空）、平衡移动方向判断、加入惰性气体的经典陷阱、转化率比较、实验方案设计正误。
- 常见设问：
  - 「下列能说明达到平衡的是」（逐条鉴别）；
  - 「向恒容密闭容器通入稀有气体，平衡如何移动」；
  - 「升高温度/增大压强后各物质百分含量变化」；
  - 「多反应体系中转化率与选择性」。

## 四、易错点

> [!warning] 易错
> 1. 「变量不变」前先确认**它是变量**：气体计量数相等的恒容体系，n总/ρ/M̄ 自始至终不变，不是标志；
> 2. 浓度**比例**：达到平衡「计量数之比」恒成立，**不是**标志；「非计量数比」不变才是；
> 3. 恒容通 Ar：总压增大但各组分浓度不变 → 平衡**不移动**（经典陷阱）；
> 4. 恒温恒压通惰性：等同减压，平衡向气体分子数增多方向移动；
> 5. 催化剂不移动平衡；v正=v逆时速率不为 0；
> 6. 绝热恒容：**温度是变量**，温度不变即平衡标志（不能用恒温结论硬套）；
> 7. 勒夏特列「减弱不抵消」：转化率不是「全加回」，能量变化不是「等量缩放」。

## 五、方法点拨

> [!tip] 方法
> - **三步判平衡**：① 确认体系条件（恒温恒容/恒温恒压/恒容绝热三套不同）；② 列出可能的变量（n/浓度/百分含量/压强/ρ/M̄/T/颜色）；③ 逐项检查「是不是变量」再谈「变不变」。
> - **移动方向必看瞬间 v正/v逆 变化**：浓度变则瞬时跳变；温度变则正逆都变但吸热方向变得多。
> - **加压/减压**：只数**气体**计量数；有固体/液体不计数。
> - **转化率比较**：先判移动方向；再用「反应物增/减」与「计量数变化」结合「大大等等小小」。
> - **竞争反应**：题目同时给转化率与选择性两曲线时，两者趋势相反，抓「主要矛盾」分区间讨论。

## 六、常见题型

### 题型 1：平衡状态标志判断
- 识别特征：给一组说法判断能否说明已达平衡。
- 解题步骤：先确认体系条件 → 确认变量 → 看是否「不变」。
- 例题：2023·全国甲卷 平衡判定「变量不变」。（真题库待回收）

### 题型 2：平衡移动方向（浓度/压强/温度/催化剂）
- 识别特征：给一个条件改变，问移动方向或某组分含量变化。
- 解题步骤：写方程式数气体计量数 → 按口诀（大压小移/升呼吸）判方向。
- 例题：2024·浙江6月 平衡移动实验方案设计正误（浓度/压强/温度/催化剂）。（真题库待回收）

### 题型 3：惰性气体与压强变形
- 识别特征：通入稀有气体/恒压稀释，问移动。
- 解题步骤：**恒容→浓度不变不移动；恒压→等同减压小压大移**。
- 例题：2022·全国乙卷 H₂S 热分解，恒压 n(H₂S):n(Ar) 惰性气体减压。（真题库待回收）

### 题型 4：转化率与勒夏特列综合
- 识别特征：平衡后加某反应物或改条件，比较转化率大小。
- 解题步骤：判方向 + 「大大等等小小」+ 注意多反应时看选择性。
- 例题：2024·浙江6月 CO₂ 氧化乙烷制乙烯（转化率+选择性）。（真题库待回收）

### 题型 5：平衡后加料/分离（工业调控前置）
- 识别特征：合成氨/甲醇合成等工业反应，分离产物/循环原料。
- 解题步骤：减 c(产)→正移；增大廉价原料投料比→提高贵重原料转化率。

## 七、三级练习

- 🌱 基础：N₂+3H₂⇌2NH₃ 恒容密闭，判断「混合气体平均摩尔质量不变」能否作平衡标志。
- 🔥 进阶：恒温恒压下向 2NO₂⇌N₂O₄ 体系通入 N₂，分析颜色变化与平衡方向。
- 🏆 拔高：绝热恒容容器中正反应放热的可逆反应，解释「温度先升后稳」能否作为达到平衡的证据。
