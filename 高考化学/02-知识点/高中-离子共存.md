# 高中-离子共存

> [!tip] 核心方法
> 共存本质 = **各离子相互不反应**。"大量共存"默认大量。判别五方面：**沉淀/微溶、弱电解质、氧化还原、双水解、配合**。审题先翻译附加条件（颜色、酸碱性、加铝放氢、水电离受限）再审组合。口诀："记少不记多"。

## 一、核心概念（是什么）

### 1. 五方面判别

**① 生成沉淀/微溶物**：F⁻ 与 Ca²⁺/Mg²⁺；Cl⁻/Br⁻/I⁻ 与 Ag⁺/Cu⁺；SO₄²⁻ 与 Ba²⁺/Pb²⁺（Ca²⁺/Ag⁺ 微溶）；CO₃²⁻/SO₃²⁻/PO₄³⁻/S²⁻/SiO₃²⁻ 与除 Na⁺/K⁺ 外绝大多数阳离子；OH⁻ 与 Na⁺/K⁺/Ba²⁺ 外的绝大多阳离子。

**② 生成弱电解质**：H⁺ 与弱酸阴离子（CO₃²⁻、HCO₃⁻、SO₃²⁻、S²⁻、HS⁻、ClO⁻、F⁻、PO₄³⁻、[Al(OH)₄]⁻）；OH⁻ 与弱碱阳离子（Mg²⁺、Al³⁺、Fe³⁺、Fe²⁺、Cu²⁺、NH₄⁺）。
- **记少不记多**：H⁺ 只与 ClO₄⁻/I⁻/Br⁻/Cl⁻/NO₃⁻/SO₄²⁻ 共存；OH⁻ 只与 Na⁺/K⁺/Ba²⁺ 共存。

**③ 氧化还原**：
- 还原性梯队（由强到弱）：口诀 **"牛牛雅典铁秀绿"** = S²⁻/HS⁻、SO₃²⁻/HSO₃⁻、I⁻、Fe²⁺、Br⁻、Cl⁻。
- 氧化性梯队（由弱到强）：口诀 **"铁蛋哥孟子"** = Fe³⁺、NO₃⁻(H⁺)、Cr₂O₇²⁻(H⁺)、MnO₄⁻(H⁺)、ClO⁻。
- 交叉配对 → 反应不能共存。注意 MnO₄⁻ 强酸才强氧化、NO₃⁻ 需 H⁺、ClO⁻ 强碱下与还原性离子可共存。

**④ 彻底双水解**：
- 阴离子六"闺女儿谈谈妞妞"：SiO₃²⁻、[Al(OH)₄]⁻、CO₃²⁻、HCO₃⁻、S²⁻、HS⁻；阳离子三"吕爹爱"：Al³⁺、Fe³⁺、NH₄⁺。
- Al³⁺ 与六阴离子全√（双水解）；Fe³⁺ 除 S²⁻/HS⁻（氧化还原）外√；NH₄⁺ 只与 SiO₃²⁻/[Al(OH)₄]⁻ √，与 HCO₃⁻/CH₃COO⁻ 双水解微弱可共存。
- **关键辨析**：`[Al(OH)₄]⁻+HCO₃⁻=Al(OH)₃↓+CO₃²⁻+H₂O` 是由强制弱（Al(OH)₃ 碱性弱于 HCO₃⁻ 酸性），非双水解，无 CO₂。

**⑤ 配合反应**：Fe³⁺ 与 SCN⁻、CN⁻、C₆H₅O⁻ 生成配合物不能共存。

### 2. 附加条件（审题陷阱）

- **有色离子**（波长长→短）：Cr₂O₇²⁻ 橙、CrO₄²⁻/Fe³⁺ 黄、Fe²⁺/Cr³⁺ 绿、Cu²⁺ 蓝、MnO₄⁻ 紫红、[Fe(CN)₆]³⁻ 黄、[CuCl₄]²⁻ 黄。
- **"无色"禁有色；"透明"可有色**（透明≠无色）。
- **酸碱性翻译**：pH（酚酞<8.2 无色/>10 红；石蕊<5 红/>8 蓝；甲基橙<3.1 红/>4.4 黄）；c(H⁺)/c(OH⁻) 比值；加铝粉放 H₂（酸或碱均可）；c水(H⁺) 或 c水(OH⁻)≪10⁻⁷（酸或碱抑制水电离）。
- 含 Cr₂O₇²⁻/Fe³⁺/Al³⁺ → 一般强酸；含 CrO₄²⁻/[Al(OH)₄]⁻ → 一般强碱。
- **多元弱酸酸式根两性**：HCO₃⁻、HC₂O₄⁻、HSO₃⁻、HS⁻、H₂PO₄⁻、HPO₄²⁻ 与 H⁺、OH⁻ 均不共存。
- S₂O₃²⁻ 遇 H⁺ 歧化；Ag⁺ 与 NH₃·H₂O 配成 [Ag(NH₃)₂]⁺ 可共存于银氨溶液。

## 二、关键规律

- 判断策略三步：① 读题干"一定共存/一定不共存/可能共存"；② 把酸碱性转成 H⁺/OH⁻ 代入每组；③ K⁺/Na⁺ 默认可共存（例外：[Fe(CN)₆]³⁻+Fe²⁺ 蓝色沉淀含 K⁺）。
- 强酸性+NO₃⁻ = 氧化性组合，遇 Fe²⁺/I⁻/S²⁻/SO₃²⁻ 必反应；强碱性 NO₃⁻ 不氧化。
- "加铝粉放 H₂"双解：酸性无 NO₃⁻ 或碱性；含 NO₃⁻ 酸性溶液不放 H₂（生成氮氧化物）。

## 三、高考考查方式

- 题型：给定离子组判断共存、附加条件（无色/酸碱性/铝放氢）下的共存判断、选项组逐项排查。
- **真题分布（出处可追溯）**：
  - 2024·浙江1月选考：例3 能大量共存的离子组（答案 D：A H⁺+I⁻+NO₃⁻ 氧化还原×；B Fe³⁺+CN⁻ 配合×；C SiO₃²⁻+Ca²⁺ 沉淀×；D NH₄⁺ 与 CH₃COO⁻/HCO₃⁻ 双水解微弱可共存 √）

## 四、易错点

> [!warning] 易错
> ① "透明"≠"无色"：透明可有色离子；② 弱酸阴离子+弱碱阳离子不一定双水解，微弱者可共存（NH₄⁺+HCO₃⁻/CH₃COO⁻）；③ [Al(OH)₄]⁻+HCO₃⁻ 是强制弱非双水解（产物无 CO₂）；④ NO₃⁻ 无 H⁺ 不氧化；⑤ 酸式根两性共六个记忆不全；⑥ 忽略"大量"二字（微量 H⁺/OH⁻ 不算）。

## 五、方法点拨

> [!tip] 共存题"两遍扫描"
> 第一遍无脑扫：沉淀表/弱电解/双水解/配合——把确定反应的删掉；第二遍带条件：颜色/酸碱/加铝放氢逐组代入。K⁺/Na⁺ 永远活到第二遍。凡选项里有 NO₃⁻+H⁺ 出现还原性离子直接判死。

## 六、常见题型

- **类型Ⅰ 无附加条件共存**：五方面排查
- **类型Ⅱ 无色溶液共存**：先删有色离子
- **类型Ⅲ 酸碱性给定共存**：pH/指示剂翻译
- **类型Ⅳ 加铝放氢/水电离受限**：双解条件
- **类型Ⅴ 综合多选**：一定/可能/一定不共存
