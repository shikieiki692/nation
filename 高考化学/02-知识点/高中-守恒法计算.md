# 高中-守恒法计算

> [!tip] 核心方法
> 守恒法三兄弟：**电子守恒**（氧化还原得=失）、**原子守恒**（元素个数前后不变）、**电荷守恒**（溶液电中性）。三法免列复杂方程，直接列比例。差值法/关系式法/十字交叉是"免列方程"的另一半马。

## 一、核心概念（是什么）

### 1. 守恒法三兄弟

- **电子守恒**：氧化还原中得电子总数 = 失电子总数。适用于多步氧化还原（HNO₃ 与金属、KMnO₄ 滴定）、求消耗氧化剂。
- **原子守恒**：反应前后某元素原子数不变。如 N 守恒解 NO+NO₂+NaOH、S 守恒解 H₂SO₄ 制备。
- **电荷守恒**：溶液电中性，**电荷浓度 = 离子浓度 × 离子所带单位电荷**（不是离子浓度直接相加）。用于混合溶液求未知离子浓度。
- 例：c(Mg²⁺)=0.1 mol/L → 电荷浓度 0.2 mol/L。

### 2. 差量法

- 利用反应前后固体质量差/气体体积差/压强差建比例：按方程式系数比例列式。
- 典型：金属与酸置换（质量差放 H₂）、CO₂ 通石灰水（增/失重）、Na₂O₂ 与 CO₂/H₂O（固体增重 = 同物质的量的 CO/H₂ 质量）。

### 3. 关系式法（多步反应的桥）

- 由方程式系数串联"起始物→终产物"，一步列式：制 H₂SO₄ 用 S→H₂SO₄（硫守恒）；KMnO₄ 滴定草酸：**2MnO₄⁻ ~ 5C₂O₄²⁻**。
- 2023·重庆卷例11 即 `2MnO₄⁻ ~ 5C₂O₄²⁻ ~ 5Ca²⁺` 求 CaCl₂ 质量分数 66.6%。

### 4. 十字交叉法

- 两组分平均量（M̄/平均密度/平均分子式）：`(M̄−M_A)/(M_B−M̄) = n_B/n_A`。
- 常用于混合烃平均相对分子质量、同位素原子比。**注意交叉得到的是物质的量比，不是质量比**。

## 二、关键规律

| 方法 | 适用 | 口诀 |
|---|---|---|
| 电子守恒 | 氧化还原定量 | 得失守恒，一个等式 |
| 原子守恒 | 元素追踪 | 同元素数前后相等 |
| 电荷守恒 | 溶液浓度 | 电量=(浓度×电荷)之和 |
| 差量法 | 质量/体积差 | 差量对系数 |
| 关系式法 | 多步反应 | 头尾相连，中间消去 |
| 十字交叉 | 两组分平均 | 交叉得物质的量比 |

## 三、高考考查方式

- 题型：氧化还原定量、混合溶液未知浓度、产率/纯度链式计算、多步反应关系式。
- **真题分布（出处可追溯，待回填精确题号）**：
  - 2023·重庆卷：例11 KMnO₄ 滴定 CaCl₂（关系式法，66.6%）
  - 2024·上海卷节选：例12 石灰乳+Na₂CO₃ 除杂用量（0.04、0.14）
  - 2024·浙江1月选考：例5 灼烧恒重测 H₂S 纯度（99.0%）

## 四、易错点

> [!warning] 易错
> ① 电荷守恒是"电荷浓度"相加，先乘离子电荷再相加；② 十字交叉结果比是物质的量比，用前先确认求的是什么比；③ 关系式法必须每步系数换算无误（2MnO₄⁻~5C₂O₄²⁻ 来自 2:5 电子比）；④ 差量法 Δ 必须对应方程式同一系数轴；⑤ 氧化还原多个元素变价时逐元素定升价/降价总和（宁多写别漏）；⑥ 混合溶液未给体积时电荷守恒只能求浓度比。

## 五、方法点拨

> [!tip] 守恒法"先判类型"
> 见氧化还原找电子守恒；见元素追踪找原子守恒；见溶液离子浓度找电荷守恒；见质量增减找差量。**先定性判方法，再定量列式**——每次只在草稿上留一个等式。

## 六、常见题型

- **类型Ⅰ 电子守恒**：金属与酸/硝酸、歧化归中
- **类型Ⅱ 原子守恒**：N/S/C 元素追踪
- **类型Ⅲ 电荷守恒**：混合溶液离子浓度
- **类型Ⅳ 差量法**：固体增重/气体体积差
- **类型Ⅴ 关系式与十字交叉**：滴定链式 + 混合配比
