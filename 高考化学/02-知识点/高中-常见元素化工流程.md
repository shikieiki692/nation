# 常见元素化工流程

> [!tip] 核心方法
> 将陌生元素流程"翻译"成熟悉元素套路：**Al/Fe/Si/Ca·Mg 主族类**走"酸/碱浸 + 调 pH 沉淀"骨架；**Ti/V/Cr/Mn/Co/Ni 过渡类**走"氧化还原变价 + 萃取/氟化/硫化物分离"骨架；**Cu/Ag/Au 贵金属类**走"配位浸取 + 置换/还原"骨架。一切设问都可落到 Ksp 计算、氧化还原守恒与"不增、不减"上。

## 一、核心概念

化工流程 = 大型"分离、提纯"题，除杂最佳原则**"不增、不减"**。按元素归类记忆套路，面对陌生流程先判断元素类型再套骨架。

## 二、关键规律

### 1. 主族元素流程套路

- **Al（双路径）**：
  - 酸浸：Al₂O₃ → Al³⁺ 进滤液 → 加碱性物调 pH → Al(OH)₃ 进滤渣。
  - 碱浸：Al₂O₃ → [Al(OH)₄]⁻ 进滤液 → 加酸性物调 pH → Al(OH)₃ 进滤渣。
  - 调 pH 选较弱酸碱（不引入杂质）；**pH≤9.6**（Al(OH)₃ 在 ≥9.6 溶解为 [Al(OH)₄]⁻）。
  - **多杂质调 pH 三原则**：最小值 = 溶解度大的杂质离子完全沉淀 pH；最大值 = 后续沉淀离子开始沉淀 pH 或 Al(OH)₃ 开始溶解 pH（取更小）。
- **Fe**：酸浸 Fe²⁺/Fe³⁺ 进滤液 → 加氧化剂（H₂O₂/空气/O₂）Fe²⁺→Fe³⁺ → 调 pH → Fe(OH)₃ 进滤渣。**H₂O₂ 过量原因：Fe³⁺ 催化 H₂O₂ 分解**。目标是亚铁/铁盐时**防 Fe 损失**：将 Fe³⁺ 还原成更难沉淀的 Fe²⁺。调 pH 碱性物优选目标金属对应的难溶氧化物/碱/碳酸盐（不引入杂质）；调 pH 后**加热**使 Fe(OH)₃ 胶体聚沉易过滤。
- **Si**：SiO₂ 酸浸不溶→滤渣；碱浸/碱熔→Na₂SiO₃ 进滤液（或难溶硅酸盐进滤渣）；`SiO₂ + 4HF = SiF₄↑ + 2H₂O`。
- **Ca、Mg**：Ca²⁺/Mg²⁺ 氢氧化物完全沉淀需 OH⁻ 浓度过高（共沉淀风险）→ 转 **CaF₂/MgF₂ 沉淀**。Ksp(CaF₂) < Ksp(MgF₂)：算 c(F⁻) 最小浓度代入**较大 Ksp（MgF₂）**。pH 不宜过低：H⁺ 与 F⁻ 生成 HF 使沉淀溶解平衡右移。CaSO₄ 微溶 → 硫酸浸碳酸钙时部分 Ca 以 CaSO₄ 进滤渣。
- **Na、K**：钠盐钾盐溶解度大难沉淀 → **重结晶**分离提纯（KNO₃ 用蒸发浓缩-冷却结晶，NaCl 用蒸发结晶）。

### 2. 过渡元素流程套路

- **Cu、Ag**：硫化物沉淀 Cu²⁺/Ag⁺（溶解度极小）；阳离子选目标产物对应阳离子防引入杂质。Cu、Ag 混合固体用电解分离（混合物作阳极）。Ag⁺ 与浓度大的 Cl⁻ 形成可溶配离子 [AgCl₂]⁻ → 氯化物沉淀 Ag⁺ 时注意用量。硫化物煅烧产生 SO₂ 污染 → 氧化剂/碱回收硫；用氧化剂酸浸时硫转 S 单质进滤渣。
- **Co、Ni**：与 Fe 同族性质相似，常规沉淀难分离 → **萃取反萃取**（萃杂质或富集目标；选 pH 使不同离子萃取率差值最大）。萃取：`Mⁿ⁺ + nHR ⇌ MRₙ + nH⁺`（配位，化学变化）；反萃取：加无机强酸（酸根与目标产物阴离子对应）。
- **Ti**：钛铁矿 `FeTiO₃ + 2H₂SO₄ = TiOSO₄ + FeSO₄ + 2H₂O`；钛水解 `TiO²⁺ + (x+1)H₂O ═(加热)═ TiO₂·xH₂O↓ + 2H⁺`；制 Ti：TiO₂ + C + Cl₂ 共热 → TiCl₄ → Ar 气氛 Na/Mg 还原。
- **V**：`2NH₄VO₃ ═(高温)═ V₂O₅ + 2NH₃↑ + H₂O↑`；V₂O₅ 两性偏酸；VO₂⁺ 在强酸性下遇 Fe²⁺/H₂C₂O₄ 还原为 VO²⁺；pH 决定 V 存在形态（VO₂⁺/VO₃⁻/V₂O₇⁴⁻/VO₄³⁻）。
- **Cr（铬铁矿套路必背）**：FeCr₂O₄ + Na₂CO₃ + NaOH + O₂ 高温焙烧 → Na₂CrO₄ → 水浸（Fe₂O₃ 滤渣）→ 调 pH 除 Si/Al → 酸化 `2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O`。Cr₂O₇²⁻ 酸性强氧化（氧化 S²⁻/SO₃²⁻/I⁻/Fe²⁺/Br⁻/Cl⁻，自身→Cr³⁺）；**不能用盐酸酸化**。
- **Mn**：MnO₂ 酸性强氧化剂（`MnO₂ + 4HCl(浓) ═(△)═ MnCl₂ + Cl₂↑ + 2H₂O`；`MnO₂ + 2Fe²⁺ + 4H⁺ = Mn²⁺ + 2Fe³⁺ + 2H₂O`）。**KMnO₄ 还原产物三态**：酸性→Mn²⁺；中性/弱碱→MnO₂；强碱→MnO₄²⁻。K₂MnO₄ 歧化：`3MnO₄²⁻ + 4H⁺ = 2MnO₄⁻ + MnO₂↓ + 2H₂O`。电解沉锰：`Mn²⁺ + 2H₂O ═(电解)═ H₂↑ + MnO₂↓ + 2H⁺`。

### 3. 综合计算

- **产率 = 实际产量 / 理论产量 × 100%**；用**元素守恒**（如 Mn 原子守恒）求理论产量；各工序损失率、引入量、沉淀率逐项累加，单位统一。
- **萃取率计算**：由 H⁺ 浓度增量推算被萃取金属离子量。
- **Ksp 反推离子浓度**：沉淀完全按 c ≤ 10⁻⁵ mol/L；"完全除尽"用 Ksp 反推，比较与 10⁻⁵ 的大小。

## 三、高考考查方式

高频元素流程真题题源（2021-2025）：Ba/Li（主族 ⅠA/ⅡA）、Al/Zn/Ga/Be（两性）、Ti、V、Cr、Mn、Co/Ni、Cu/Ag/Au。设问方式：陌生方程式书写、沉淀剂与 pH 选择、萃取反萃取、Ksp 计算、产率/萃取率、防氧化防分解措施、循环物质判断。

## 四、易错点

> [!warning] 易错 1
> CrO₄²⁻/Cr₂O₇²⁻ 转化酸化用 H₂SO₄ 不用 HCl——Cr₂O₇²⁻ 氧化 Cl⁻ 生成 Cl₂（污染+耗酸+引入杂质）。

> [!warning] 易错 2
> 除杂沉淀剂阳离子必须选目标产物对应阳离子（沉 Cu²⁺ 用 CuS/H₂S 的"或不增"对象，沉 Ni²⁺ 用 NiF₂ 而非 NaF），违反即"增"杂质。

> [!warning] 易错 3
> pH 上限双重约束：既防目标离子沉淀，又防两性氢氧化物（Al/Zn/Ga/Be）碱性再溶解；多杂质取**交集**。

> [!warning] 易错 4
> Ksp 计算陷阱：表格"开始沉淀 pH"的起始浓度是否与题目一致；沉淀完全按 c≤10⁻⁵ mol/L。

> [!warning] 易错 5
> CuCl 及亚铜化合物普遍怕 O₂ → 真空干燥/还原氛围保存；细菌/酶工艺温度不宜过高（杀死微生物/催化剂失活）、不宜过低（速率慢）。

## 五、方法点拨

1. **先归类再套骨架**：看到流程先判断"主族 / 过渡 / 贵金属"，再套对应骨架，陌生元素（Be、Ga、V、Cr 等）用对角线规则/同族类比。
2. **$\ce{O2}$ 警觉**：金属升价常伴随空气中 O₂ 参与（LiMn₂O₄、CrO₂⁻ 氧化），写方程式先补 O₂ 再配平。
3. **沉淀剂优选表**：稀 H₂SO₄ 沉 Ba²⁺/Pb²⁺/Ca²⁺；F⁻ 沉 Ca²⁺/Mg²⁺；S²⁻ 沉 Cu²⁺/Ag⁺/Pb²⁺/Co²⁺/Ni²⁺；CO₃²⁻ 沉 Ca²⁺/Ba²⁺ 或双水解成氢氧化物；HCO₃⁻"沉锰"MnCO₃；草酸盐沉 Ca²⁺/Co²⁺/Ni²⁺。
4. **氧化剂还原剂选择**：由化合价升降判断；H₂O₂ 常因 Fe³⁺ 催化分解不宜替代；Zn 粉、葡萄糖、焦亚硫酸钠 Na₂S₂O₅ 是常见还原剂（`2Cr₂O₇²⁻ + 3S₂O₅²⁻ + 10H⁺ = 4Cr³⁺ + 6SO₄²⁻ + 5H₂O`）。

## 六、常见题型

### 类型Ⅰ ⅠA/ⅡA 族（Ba、Li）
- **BaTiO₃（2023 全国甲）**：碳粉还原 BaSO₄→BaS（`Ca²⁺ + S²⁻ = CaS↓` 溶解度大制小）；酸化选 HCl；草酸盐复分解定1法。
- **锂辉石 Li₂CO₃（模块2·例2）**：`LiAlSi₂O₆ + 2CaO ═(煅烧)═ LiAlO₂ + 2CaSiO₃`；调 pH 5.2≤pH<8.3；`Mn²⁺ + HCO₃⁻ + NH₃·H₂O = MnCO₃↓ + NH₄⁺ + H₂O`；Li₂CO₃ 溶解度随温度升高**减小**→80℃ 热洗；避免 Li⁺ 沉淀用 Q<Ksp 算 CO₃²⁻ 上限。

### 类型Ⅱ 两性元素 Al、Zn、Ga、Be
- **BeO**：`Be(OH)₂ + 2OH⁻ = [Be(OH)₄]²⁻`（对角线规则类比 Al）；水解时降低 pH 利于 Be(OH)₂ 析出。
- **GaN**：`[Ga(OH)₄]⁻ + CO₂ = Ga(OH)₃↓ + HCO₃⁻`（过量 CO₂）；阴极 `[Ga(OH)₄]⁻ + 3e⁻ = Ga + 4OH⁻`。
- **Zn**：`2ZnS + O₂ + 4H⁺ = 2Zn²⁺ + 2S + 2H₂O`（氧压酸浸回收 S）；Zn(OH)₂ 两性且溶于氨水（[Zn(NH₃)₄]²⁺ 电解难还原 → 不能选 NaOH/氨水调 pH）。

### 类型Ⅲ Ti 元素
- 高钛炉渣（2021 全国乙）：`Al₂O₃ + 4(NH₄)₂SO₄ ═(高温)═ 2NH₄Al(SO₄)₂ + 6NH₃↑ + 3H₂O↑`（尾气 NH₃ 循环）；分步沉淀 Fe³⁺→Al³⁺→Mg²⁺；酸溶渣 = SiO₂ + CaSO₄。

### 类型Ⅳ V 元素
- 石煤提钒（2024 河北）：价电子 3d³4s²；盐浸 `HCO₃⁻ + OH⁻ + Ca(VO₃)₂ ═(65~70℃)═ CaCO₃ + H₂O + 2VO₃⁻`；离子交换洗脱液用 NaCl；沉钒 `VO₃⁻ + NH₄⁺ = NH₄VO₃↓`（碱性不利于沉钒）。

### 类型Ⅴ Cr 元素（高频）
- 铬铁矿→红矾钠（2021 山东）：焙烧逆流；中和 pH 范围 4.5≤pH≤9.3。
- Cr(OH)₃（2023 辽宁）：`Cr₂O₃ + Na₂CO₃ ═(高温)═ 2NaCrO₂ + CO₂↑`（类比 Al₂O₃）；葡萄糖还原 CrO₄²⁻。
- 铬钒渣（2023 新课标）：pH≈9 除硅磷；`2Cr₂O₇²⁻ + 3S₂O₅²⁻ + 10H⁺ = 4Cr³⁺ + 6SO₄²⁻ + 5H₂O`。

### 类型Ⅵ Mn 元素
- LiMn₂O₄（2023 全国乙）：`MnCO₃ + H₂SO₄ = MnSO₄ + H₂O + CO₂↑`；MnO₂ 氧化 Fe²⁺；石灰乳调 pH≈7 除 Al³⁺；BaS 除 Ni²⁺ 同时 BaSO₄↓；`2Li₂CO₃ + 8MnO₂ ═(煅烧)═ 4LiMn₂O₄ + 2CO₂↑ + O₂↑`。
- KMnF₃（2024 广西）：葡萄糖还原 MnO₂→Mn²⁺；CaCO₃ 调 pH 5~6 只沉淀 Al³⁺；除 Fe²⁺/Cu²⁺ 用 (NH₄)₂S（H₂S 不行——FeS 溶于酸；Zn 引入杂质）。

### 类型Ⅶ Co、Ni 元素
- 含镍废液骨架：除 Cu（CuS）→ H₂O₂ 氧化 Fe²⁺→Fe³⁺ → Ni(OH)₂ 调 pH 沉 Fe(OH)₃ → NiF₂ 除 Ca²⁺ → P₂₀₄ 萃取 Zn（反萃用 H₂SO₄）→ 蒸发浓缩冷却结晶 NiSO₄·6H₂O。

### 类型Ⅷ Cu、Ag、Au 元素
- 细菌冶金载金矿（2024 东北三省）：`4FeS₂ + 15O₂ + 2H₂O ═(细菌)═ 4Fe³⁺ + 8SO₄²⁻ + 4H⁺`；Fe(OH)₃ 胶体吸附 As 聚沉；NaCN 配位浸金 [Au(CN)₂]⁻；Zn 置换 Au；`Na₂[Zn(CN)₄] + 2H₂SO₄ = ZnSO₄ + 4HCN + Na₂SO₄`，NaOH 中和 HCN→NaCN 循环。
- 氨法浸取铜包钢（2023 河北）：`[Cu(NH₃)₄]Cl₂ + Cu = 2[Cu(NH₃)₂]Cl`（Fe 不反应→滤渣）；`[Cu(NH₃)₂]⁺ + 2H⁺ + Cl⁻ = CuCl↓ + 2NH₄⁺`；真空干燥防 CuCl 氧化。
