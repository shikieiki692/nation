# 高中-氧化还原新情景书写与计算

> [!tip] 核心方法
> 新情景书写五步法：**写四样**（氧化剂、还原剂、氧化产物、还原产物）→ **平四样**（配平变价部分）→ **补未变价元素** → **H⁺/OH⁻ 调电荷** → **看 H 补水、用 O 检查 + 写条件**。计算只认一条：**电子得失守恒**（n氧化剂×每摩尔得 e⁻ = n还原剂×每摩尔失 e⁻）。

## 一、核心概念（是什么）

### 1. 书写五步法

1. 判断是否氧化还原；若是，立即**「写四样」**。
2. **「平四样」**：按配平三步先配平变价部分。
3. 补上含**未变价元素**的反应物/生成物（强酸性环境中金属元素产物一般以盐的形式存在）。
4. 溶液体系用 H⁺/OH⁻ 调平电荷。
5. 看 H 补 H₂O、用 O 检查；写上反应条件。

### 2. 常见氧化剂 → 还原产物预测表

| 氧化剂 | 还原产物 |
|---|---|
| KMnO₄ | Mn²⁺（强酸性）；MnO₂（中性附近）；MnO₄²⁻（强碱性） |
| MnO₂（酸性） | Mn²⁺ |
| K₂Cr₂O₇（酸性） | Cr³⁺ |
| 浓硝酸 | NO₂ |
| 稀硝酸 | NO |
| 浓硫酸（加热） | SO₂ |
| X₂（卤素单质） | X⁻ |
| H₂O₂ | H₂O（酸性）；OH⁻（碱性） |
| 含 Cl 氧化剂（NaClO/ClO₂ 等） | 题目无信息默认 Cl⁻ |
| Fe³⁺ | Fe²⁺ |
| PbO₂ | Pb²⁺ |

### 3. 常见还原剂 → 氧化产物预测表

| 还原剂 | 氧化产物 |
|---|---|
| Fe²⁺ | Fe³⁺（强酸性）；Fe(OH)₃（约 pH>3 水溶液） |
| Fe | 弱氧化剂 → Fe²⁺；强氧化剂 → Fe³⁺ |
| +4 价 S / +2 价 S（S₂O₃²⁻） | SO₄²⁻ |
| −2 价 S（H₂S/HS⁻/S²⁻） | 题目无信息默认 **S** |
| H₂C₂O₄/C₂O₄²⁻ | CO₂（酸性）；CO₃²⁻/HCO₃⁻（碱性） |
| H₂O₂ | O₂ |
| X⁻ 或 HX | 题目无信息默认 X₂ |
| CO / C | CO₂／CO₂(O₂ 足) 或 CO(O₂ 少) |
| 负价 N（NH₃/NH₄⁺/N₂H₄） | 题目无信息默认 N₂ |

### 4. 电子得失守恒计算

- 核心等式：`n(氧化剂) × 每摩尔氧化剂得电子数 = n(还原剂) × 每摩尔还原剂失电子数`。
- **只看变价元素**，忽略不变价元素；**注意化学式中变价元素的原子个数**（K₂Cr₂O₇→Cr₂(SO₄)₃：2 个 Cr 共得 6e⁻）。
- 多步反应找「首尾」（N 元素起点终点均为 HNO₃ 时过程净得失为零）。
- 歧化计算把得电子方与失电子方**并排看**：5NaClO₂ ~ 4ClO₂ ~ 1NaCl。

## 二、关键规律（典例速记）

| 情景 | 方程式（节选） |
|---|---|
| 文字·LiCoO₂ 浸出 | 2LiCoO₂ + H₂O₂ + 3H₂SO₄ = Li₂SO₄ + 2CoSO₄ + O₂↑ + 4H₂O（Co 降 ⇒ H₂O₂ 升为 O₂） |
| 文字·Re 稀硝酸 | 3Re + 4H⁺ + 7NO₃⁻ = 3ReO₄⁻ + 7NO↑ + 2H₂O（还原产物 NO 必记） |
| 文字·Ni²⁺+ClO⁻ 强碱 | 2Ni²⁺ + ClO⁻ + 4OH⁻ = 2NiOOH↓ + Cl⁻ + H₂O（沉淀不拆） |
| 流程·Au 浸取 | 2Au + 8HCl + 3H₂O₂ = 2HAuCl₄ + 6H₂O（Au 0→+3，H₂O₂→H₂O 降 2 → 2:3） |
| 流程·两性 GaAs | GaAs + 2OH⁻ + 4H₂O = [Ga(OH)₄]⁻ + AsO₂⁻ + 3H₂↑（类比 Al 两性） |
| 实验·ClO₂ 制备 | 2ClO₂ + H₂O₂ + 2NaOH = 2NaClO₂ + O₂ + 2H₂O（Cl 降 ⇒ O 升为 O₂） |
| 实验·沉锰 | Mn²⁺ + 2HCO₃⁻ = MnCO₃↓ + CO₂↑ + H₂O（非氧化还原，考频高） |
| 机理·除氨氮 | 2NH₃ + 3ClO⁻ = N₂ + 3H₂O + 3Cl⁻ |

## 三、高考考查方式

- 题型：文字/流程/实验/机理新情景书写、转移电子数、电子得失守恒综合计算、Nₐ 结合判断。
- **真题分布（出处可追溯）**：
  - 2024·安徽卷：流程图 Au 浸取方程式书写
  - 2023·湖南卷（改编）：雌黄 As₂S₃ 两种褪色反应转移电子比 3:7
  - 2024·东北三省卷：硫转化关系 + Nₐ 综合判断（0.5 mol SO₂、3.4 g H₂S、1 mol S→S²⁻ 转移 2Nₐ）
  - 其余为自编/真实来源标注待回收

## 四、易错点

> [!warning] 易错
> ① 稀硝酸还原产物写成 NO₂（浓硝酸才 NO₂）；② H₂O₂ 产物不看对象（遇氧化剂升为 O₂、遇还原剂降为 H₂O，LiCoO₂/ClO₂ 情景必判）；③ 角标漏乘（1 mol K₂Cr₂O₇ 得 6 mol e⁻，不是 3）；④ 电荷守恒缺 H⁺/OH⁻（酸性补 H⁺、碱性补 OH⁻）；⑤ 歧化转移电子加和（歧化只算升或降一方面）；⑥ 含氯氧化剂默认产物 Cl⁻（NaClO→Cl⁻ 而非 Cl₂）。

## 五、方法点拨

> [!tip] 写四样实操
> 先看高价/低价字眼定两剂（如「浸出」「氧化」「脱色」→ 氧化剂字眼；「还原」「沉出」→ 还原剂字眼）；产物预测表即背即用；写完四查：**元素价变对不对、电荷平不平、H₂O 补没补、条件写没写**（加热/催化剂/高温）。计算题三步：定两剂两产物 → 数清变价原子（乘角标）→ 列守恒等式。

## 六、常见题型

- **类型Ⅰ 文字信息书写**：五步法 + 产物预测表
- **类型Ⅱ 流程图书写**：读流程定氧化剂/还原剂/产物，补条件
- **类型Ⅲ 实验/机理书写**：装置情境、循环图中箭头指入=反应物
- **类型Ⅳ 转移电子数计算**：n×每摩尔得/失 e⁻，拆分子逐原子看
- **类型Ⅴ 电子得失守恒综合**：多步找首尾（Cu+硝酸+O₂ 通水）、歧化并排、Nₐ 结合判断
