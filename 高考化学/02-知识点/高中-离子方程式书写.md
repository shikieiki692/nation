# 高中-离子方程式书写

> [!tip] 核心方法
> 本章全部浓缩一句：**"量"决定"型"**。少量定1、过量配合少量；判断正误七字诀：**拆、配平、量、气沉弱、氧化还、水解、双遣**。电荷守恒+原子守恒永远最后一道闸。

## 一、核心概念（是什么）

### 1. 五条"反应线"（按"少量定1，过量配合"拆解）

| 线 | 少量物质 | 典型方程式 |
|---|---|---|
| 铝线 | CO₂ 少进偏铝酸盐 / OH⁻ 少进铝盐 | CO₂(少)+2[Al(OH)₄]⁻=2Al(OH)₃↓+CO₃²⁻+H₂O；OH⁻(少)+Al³⁺=Al(OH)₃↓ |
| 碳线 | CO₂ 少量/过量进碱 | CO₂(少)+2OH⁻=CO₃²⁻+H₂O；CO₂(过)+OH⁻=HCO₃⁻ |
| 硫线 | SO₂ 少量/过量 / H₂S 进碱 | 同碳线逻辑；H₂S+OH⁻(少)=HS⁻+H₂O |
| 磷线 | 磷酸与碱逐步 | H₃PO₄+OH⁻ 分步 H₂PO₄⁻/HPO₄²⁻/PO₄³⁻ |
| 铁线 | Fe 与稀 HNO₃ 的量 | Fe(少)+4H⁺+NO₃⁻=Fe³⁺+NO↑+2H₂O；Fe(过) 产物 Fe²⁺（3Fe+8H⁺+2NO₃⁻=3Fe²⁺+2NO↑+4H₂O） |

### 2. 配比复分解（定比型）

- **以少定多**：不足量物质各离子按原方程式配比；足量物质按少量离子需求配。
- Ca(HCO₃)₂+NaOH：NaOH 少 → `OH⁻+Ca²⁺+HCO₃⁻=CaCO₃↓+H₂O`；NaOH 多 → `2OH⁻+Ca²⁺+2HCO₃⁻=CaCO₃↓+CO₃²⁻+2H₂O`。
- NH₄HSO₄+NaOH：NaOH 少 → `H⁺+OH⁻=H₂O`；NaOH 多 → `NH₄⁺+H⁺+2OH⁻=NH₃·H₂O+H₂O`（先 H⁺ 后 NH₄⁺）。
- 明矾+Ba(OH)₂：Al³⁺ 完全沉淀 `2Al³⁺+3SO₄²⁻+3Ba²⁺+6OH⁻=2Al(OH)₃↓+3BaSO₄↓`；SO₄²⁻ 完全沉淀 `Al³⁺+2SO₄²⁻+2Ba²⁺+4OH⁻=[Al(OH)₄]⁻+2BaSO₄↓`。

### 3. 氧化还原配比（向定量方向迁移电子）

- FeBr₂+Cl₂：Cl₂ 少量只氧化 Fe²⁺（`2Fe²⁺+Cl₂=2Fe³⁺+2Cl⁻`）；过量再氧化 Br⁻。**还原性 Fe²⁺ > Br⁻，先氧化强者**。
- FeI₂+Cl₂：I⁻ 还原性强于 Fe²⁺，先氧化 I⁻。
- 交叉型：NaClO+SO₂+H₂O = NaCl+H₂SO₄（Cl 降 −1、S 升 +6）；Na₂SO₃+Cl₂+H₂O = Na₂SO₄+2HCl。
- S₂O₃²⁻+2H⁺=S↓+SO₂↑+H₂O（歧化，酸性中不共存）。

### 4. 七个注意（判断正误）

1. **铁在酸中形态**：稀盐酸/稀硫酸→Fe²⁺；稀 HNO₃→Fe³⁺（铁过量才 Fe²⁺）。
2. **强酸拆分**：六大强酸 H₂SO₄/HCl/HNO₃/HBr/HI/HClO₄ 拆；弱酸（HF/H₂S/H₂CO₃ 等）不拆；**浓硫酸不拆**。
3. **饱和 NaHCO₃ 不拆、NaHSO₄ 拆**：HS⁻/HCO₃⁻/HSO₃⁻/HPO₄²⁻ 等一律保留。
4. **微溶物规则**：做反应物且澄清（石灰水 Ca(OH)₂ 拆）；做生成物写分子式（CaSO₄/Ag₂SO₄/MgCO₃ 沉淀）。
5. **氧化还原检查**：Fe²⁺+Cl₂ 必须写产物 Fe³⁺；NH₄⁺ 与 OH⁻ 加热放 NH₃。
6. **量变引起质变**：Cu+浓 HNO₃→NO₂，稀 HNO₃→NO；MnO₂/浓盐酸需加热。
7. **守恒收尾**：原子守恒+电荷守恒同时满足。

## 二、关键规律

- 判断正误流程：**拆**（该拆的拆没拆）→**配平**（原子+电荷）→**量**（少量定1）→**气沉弱**（生成物状态）→**氧化还**（有没有迁移电子）→**水解**→**双遣**（双水解能不能共存）。
- 泡沫灭火器原理：`3HCO₃⁻+Al³⁺=Al(OH)₃↓+3CO₂↑`（双水解，书写正确）。

## 三、高考考查方式

- 题型：离子方程式正误判断、与量有关书写（少量/过量/定比）、氧化还原配比、流程填空。

## 四、易错点

> [!warning] 易错
> ① 拆写错误：浓硫酸不拆、饱和 NaHCO₃ 不拆、微溶物生成物不拆；② 量变：CO₂ 少量/过量产物不同（CO₃²⁻ vs HCO₃⁻）；③ 氧化还原漏写：Fe²⁺→Fe³⁺ 必须体现电子转移（4Fe²⁺+O₂+4H⁺=4Fe³⁺+2H₂O）；④ 守恒漏查（电荷不守恒必错）；⑤ 铁酸形态：稀硝酸 Fe³⁺ 但过量 Fe 变 Fe²⁺；⑥ 配比错：NH₄HSO₄ 少量 NaOH 只中和 H⁺。

## 五、方法点拨

> [!tip] 七字诀实操
> **拆**：强酸强碱可溶性盐拆开，弱/难溶/气体/单质/氧化物不拆。**配平**：先原子后电荷。**量**：少量定1（不足量按自身式量配）。**气沉弱**：检查箭头与生成物类别。**氧化还**：凡有电子迁移必写全氧化产物/还原产物。**水解**：相互促进的水解写全。**双遣**：观察双向约束（双沉淀/双气体）写完整。

## 六、常见题型

- **类型Ⅰ 正误判断**：七字诀逐条找错
- **类型Ⅱ 与量有关**：少量/过量产物选择
- **类型Ⅲ 定比配比**：Ca(HCO₃)₂/明矾/铵盐
- **类型Ⅳ 氧化还原配比**：FeBr₂/FeI₂ 与 Cl₂、交叉型
- **类型Ⅴ 综合书写**：工艺流程/实验中的离子方程式
