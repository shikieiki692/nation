> [!tip] 核心方法
> 铝及其化合物的总纲就是「**两性**」：Al、Al₂O₃、Al(OH)₃ 皆既能与强酸又能与强碱反应，但**与弱碱氨水、弱酸碳酸不反应**。
> 核心离子方程式四条：
> ① 2Al + 6H⁺ = 2Al³⁺ + 3H₂↑
> ② 2Al + 2OH⁻ + 6H₂O = 2[Al(OH)₄]⁻ + 3H₂↑（**水必须写**）
> ③ Al(OH)₃ + 3H⁺ = Al³⁺ + 3H₂O
> ④ Al(OH)₃ + OH⁻ = [Al(OH)₄]⁻

## 一、核心概念（是什么）

- **铝单质**：银白色轻金属，表面有致密 Al₂O₃ 氧化膜（耐腐蚀）；常温遇浓硫酸、浓硝酸**钝化**；铝在氧气中灼烧**不滴落**（氧化膜熔点高达 2050℃，兜住熔融铝）。
- **铝热反应**：2Al + Fe₂O₃ ≜(高温) Al₂O₃ + 2Fe，放出大量热，用于焊接钢轨、冶炼高熔点金属（V、Cr、Mn）。**不能用 MgO**（Mg 的金属性强于 Al，Al 不能置换 Mg；实际是 MgO 焓变不利于被铝还原）。
- **氧化铝 Al₂O₃**：两性氧化物；刚玉（天然 Al₂O₃、红宝石/蓝宝石含微量杂质离子）熔点极高，作耐火材料；是工业冶炼铝的原料。
- **氢氧化铝 Al(OH)₃**：两性氢氧化物，白色胶状沉淀，受热分解 2Al(OH)₃ ≜ Al₂O₃ + 3H₂O；能吸附色素的胶体。
- **明矾 KAl(SO₄)₂·12H₂O**：复盐，Al³⁺ 水解生成 Al(OH)₃ 胶体吸附水中悬浮杂质，净水是**物理性絮凝，非氧化还原**（不能杀菌消毒）。
- **硼（高考拓展）**：H₃BO₃ **一元弱酸**（不是三元酸），电离只供 1 个 H⁺；硼酸酸性强于碳酸，故能与 Na₂CO₃ 反应但只生成 NaHCO₃：4H₃BO₃ + Na₂CO₃ = Na[B(OH)₄]·2H₃BO₃ + CO₂↑ + H₂O（常考产物为 HCO₃⁻ 而非 CO₃²⁻）。
- **氢化物还原剂**：LiAlH₄、NaBH₄ 中 H 为 **-1 价**，作强还原剂（LiAlH₄ 与 NaH、LiH 同族类比）。

## 二、关键规律

1. **Al 与酸碱的反应主线**：
   - 与酸：2Al + 6H⁺ = 2Al³⁺ + 3H₂↑
   - 与强碱：2Al + 2OH⁻ + 6H₂O = 2[Al(OH)₄]⁻ + 3H₂↑——**H₂ 中的氢来自水**，氧化剂是 H₂O；此方程式氧化还原配平难点（Al 失 3e⁻×2，H₂O 得 2e⁻×3）。
   - 与盐溶液：不能在 CuSO₄ 溶液中置换 Cu（铝表面钝化膜 + 离子水解），Al 与 CuCl₂ 可置换。
2. **Al₂O₃ 两性**：
   Al₂O₃ + 6H⁺ = 2Al³⁺ + 3H₂O；Al₂O₃ + 2OH⁻ + 3H₂O = 2[Al(OH)₄]⁻（等号左边水来自 OH⁻ 配位）。
3. **Al(OH)₃ 的两性与制备**：
   - 实验室制备：Al³⁺ + 3NH₃·H₂O = Al(OH)₃↓ + 3NH₄⁺（用氨水而非 NaOH，防止 Al(OH)₃ 溶解；**Al(OH)₃ 不溶于氨水**，也不溶于弱酸碳酸）。
   - Na[Al(OH)₄] 与 Al³⁺ 不共存：Al³⁺ + 3[Al(OH)₄]⁻ = 4Al(OH)₃↓（互促水解/双水解）
4. **[Al(OH)₄]⁻（偏铝酸根）的滴加顺序两套现象**：
   | 操作 | 现象 |
   |------|------|
   | 向 AlCl₃ 溶液中滴加 NaOH | 先生成白色沉淀，后沉淀溶解（Al³⁺ → Al(OH)₃ → [Al(OH)₄]⁻） |
   | 向 NaOH 溶液中滴加 AlCl₃ | 先生成 [Al(OH)₄]⁻（无沉淀），后生成 Al(OH)₃ 沉淀 |
   由「相同操作顺序不同结果」命制图像题（沉淀量—滴液体积图）。
5. **铝的冶炼**：2Al₂O₃(熔融) ≜(电解,冰晶石) 4Al + 3O₂↑。
   - 必须加**冰晶石 Na₃AlF₆** 助熔（降低熔点，节能）；
   - **不能电解熔融 AlCl₃**（AlCl₃ 分子晶体，熔融不导电）；
   - 阳极 O²⁻ 失电子放 O₂，阳极材料需定期更换（O₂ 氧化石墨电极成 CO₂）。
6. **铝土矿冶炼流程**（典型流程题模板）：
   铝土矿（Al₂O₃ + Fe₂O₃ + SiO₂）→ 加 NaOH 碱溶（Al₂O₃ 溶出为 Na[Al(OH)₄]，Fe₂O₃、SiO₂ 为残渣）→ 滤液通 CO₂ 沉铝（得 Al(OH)₃，Na₂CO₃ 可循环）→ 灼烧得 Al₂O₃ → 电解。
   - **原理**：Al₂O₃ 两性可碱溶、SiO₂ 只与强碱反应沉淀成硅酸、Fe₂O₃ 碱性氧化物不溶于碱，实现分离。
7. **铝配合物与硼族拓展**：
   - 配位：[Al(OH)₄]⁻、[AlF₆]³⁻（氟铝酸钠/冰晶石即 Na₃AlF₆）。
   - 对角线规则：Be 与 Al 相似（Be(OH)₂ 两性，Be 与强碱反应放 H₂）。
   - 聚合氯化铝（净水剂）：Al₁₃ 聚合体，**Al:Cl 配比 13:32**（2023 上海卷考过，聚铝有效成分 [Al₁₃O₄(OH)₂₄(H₂O)₁₂]⁷⁺）。

## 四、易错点

> [!warning] 易错 1
> Al + NaOH 反应离子方程式**必须写 6H₂O**：2Al + 2OH⁻ + 6H₂O = 2[Al(OH)₄]⁻ + 3H₂↑。只写 2Al + 2OH⁻ + 2H₂O 是错的（氧不守恒）。

> [!warning] 易错 2
> Al(OH)₃ 的两性：与强酸强碱反应，但**不溶于氨水、不溶于碳酸/CO₂ 的水溶液**。制 Al(OH)₃ 用氨水，制 [Al(OH)₄]⁻ 用 NaOH。

> [!warning] 易错 3
> 明矾净水是物理过程（胶体吸附），**不是氧化还原**，也不能杀菌消毒。消毒才需要强氧化剂（Cl₂、O₃、高铁酸盐）。

> [!warning] 易错 4
> 工业制铝**不能电解熔融 AlCl₃**（分子晶体熔融不导电），必须电解熔融 Al₂O₃ + 冰晶石；冰晶石是助熔剂不是催化剂。

> [!warning] 易错 5
> 铝热反应不能用 MgO：Al 还原性弱于 Mg，无法把 Mg 置换出来；铝热剂常用 Fe₂O₃（或 Fe₃O₄），产物为熔融铁。

## 五、方法点拨

- **两性判断三步**：金属/氧化物/氢氧化物能否与强酸、强碱都反应 → 注意「弱酸弱碱不行」（Al(OH)₃ 不溶于 NH₃·H₂O、H₂CO₃）。
- **滴加顺序图像**：记忆「正滴（盐滴碱）先沉淀」「反滴（碱滴盐）先生成络离子」，图像斜率/拐点对应物质的量之比（Al³⁺:[OH⁻]）。
- **流程题的分离线**：碱溶除 Fe₂O₃、通 CO₂ 沉铝、循环母液，三步抓「两性」（Al₂O₃ 能碱溶）与「溶解度」（NaHCO₃ 循环）。
- **配平检查**：含水的氧化还原配平，写完先数 O 守恒再数电荷守恒。

## 六、常见题型

- **类型Ⅰ 铝单质**：铝热反应、钝化、灼烧不滴落、Al 与酸碱反应方程式。
- **类型Ⅱ Al₂O₃ / Al(OH)₃ 两性**：与强酸强碱/弱酸弱碱反应边界。
- **类型Ⅲ [Al(OH)₄]⁻ 滴加顺序**：两套现象、沉淀图像。
- **类型Ⅳ 冶炼与流程**：铝土矿提铝、电解（冰晶石、烟气净化、聚合氯化铝）。
- **类型Ⅴ 硼与对角线**：H₃BO₃ 一元酸、LiAlH₄/NaBH₄ 中 H 为 -1、Be-Al 对角。
