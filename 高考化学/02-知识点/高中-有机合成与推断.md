# 高中-有机合成与推断

> [!tip] 核心方法
> 推断求解顺序：**算 Ω → 定官能团 → 推碳架 → 逐官能团填空 → 回代检验**。合成题破题：**官能团引入/转化表 + 碳架变化（增减成环）+ 条件→机理识别**。

## 一、核心概念（是什么）

### 1. 官能团性质速查

| 官能团 | 关键反应 |
|---|---|
| C=C / C≡C | 加成（H₂/X₂/HX/H₂O）、氧化（KMnO₄ 褪色）、加聚 |
| -X | NaOH 水→醇（取代）、NaOH 醇→烯（消去） |
| -OH | 氧化（→醛酮）、酯化、与 Na、消去（浓 H₂SO₄） |
| -OH(酚) | 弱酸性、FeCl₃ 显色、溴水白色沉淀、酚酯 |
| -CHO | 银镜、新制 Cu(OH)₂ |
| -C(=O)- | 加氢（→仲醇）、不银镜 |
| -COOH | 酸性、酯化、与 NaHCO₃ 放 CO₂ |
| -COOR | 水解（酸/碱） |
| -CONH- | 水解（→酸+胺） |
| -NH₂ | 碱性（与酸成盐）、酰化（→酰胺） |

### 2. 官能团引入与保护

| 欲引入 | 常用方法 |
|---|---|
| -OH | 烯烃水化、卤代烃水解、醛酮加氢、酯水解 |
| -X | 光照卤代、烯加成 HX、醇 + SOCl₂/PX₃ |
| -CHO | 烯臭氧化、醇轻柔氧化 |
| -COOH | 醛氧化、醇氧化、苯环侧链 KMnO₄ |
| -COOR | 酯化（浓 H₂SO₄） |
| -CONH- | 酰化（酸酐/酰氯 + 胺） |
| 保护 | 氨基先用 Boc 封（成酰胺暂封），最后水解脱保护 |

### 3. 碳架变化

| 变化 | 手段 |
|---|---|
| 减链 | 裂化、烯/炔臭氧化、苯环侧链 KMnO₄ |
| 增链 | HCN 加成（→氰基可水解）、羟醛缩合、酚醛树脂、格氏试剂 |
| 成环 | 酯化（内酯）、D-A 环加成、分子内缩合 |
| 傅克 | 烷基化（+RX）、酰基化（+RCOX），注意定位效应 |

### 4. 条件→机理判断

- 卤素光照 → 取代；卤素 CCl₄ → 加成；NaOH 水 → 取代、NaOH 醇 → 消去；稀 H₂SO₄ → 酯水解；浓 H₂SO₄ → 酯化/消去；催化加压 → 加氢
- **三种不稳定结构自动重排**：① 同碳二羟基→羰基；② 同碳二双键→三键；③ 同碳羟基+双键→羰基（烯醇重排）
- **信息反应识别**：羟醛缩合（"断双键、α补氢、β补氧"反推）；D-A 反应（"断π键、断π间、半键回归"）；格氏试剂（**遇活泼氢会反应，溶剂不能含 H₂O/醇**）
- **氧化还原判断**：断 σ 成 π = 氧化；断 π 成 σ = 还原。NaBH₄/LiAlH₄ "万能还原剂"（-NO₂→-NH₂、-COOH→-CH₂OH、-C=O→-CHOH）

## 二、关键规律/公式

| 规律 | 内容 | 注意 |
|---|---|---|
| 推断五联证据 | 质谱+核磁+化学性质+不饱和度+燃烧 | 锁结构 |
| 官能团转化链 | 烃→卤代烃→醇→醛→酸→酯 | 氧化递进 |
| 溶剂条件 | 水=取代、醇△=消去 | 卤代烃双通道 |
| 保护-脱保护 | Boc 封氨基 → 反应 → 水解还原 | 防副反应 |

## 三、高考考查方式

- 题型：大题（合成路线推断/补全步骤/产物判断/同分异构/信息应用）
- 常见设问：中间体结构推断、反应类型、试剂条件选择、官能团名称、限定异构、信息反应应用（羟醛/D-A/格氏/还原）
- **真题分布（出处可追溯，待 `03-题库` 高考真题库建立后回填精确题号）**：
  - 2024·全国甲卷：白藜芦醇——FeCl₃ 检酚、硝基 Fe/H⁺ 还原（例1）
  - 2024·上海卷：瑞格列奈——NaBH₄ 还原、茚三酮检氨基酸（例2）
  - 2022·全国乙卷：左旋米那普伦——E→F 内酯环、SOCl₂ 氯代（例3）
  - 2024·浙江1月：氯硝西泮——硝基吸电子影响碱性强弱（例9）
  - 2024·辽宁卷：特戈拉赞——丙二酸二酯、烯醇重排（例10）
  - 2024·安徽卷：邻二甲苯 MnO₂ 氧化、NaBH₄
  - 2024·新课标卷：四氟咯草胺——K₂CO₃ 吸收 HBr 促取代、sp³ 碳 5

## 四、易错点

> [!warning] 易错
> ① 格氏试剂遇水/醇/胺/炔氢先反应——制取溶剂必须无水；② 羧基/酯基/酰胺基不加 H₂（配平 mol 数时漏算）；③ 烯醇重排"同碳羟基+双键→羰基"常被误判成取代；④ 信息反应只给结构不给名字——按"断键+补位"口诀反推，不凭名字猜；⑤ 保护基不写水解还原那一步，合成路线"断链"；⑥ 由环上取代判断定位效应（邻对位/间位基）错误导致产物写反。

## 五、方法点拨（蓝字注释风格）

> [!tip] 合成路线三段倒推
> 从目标分子倒着切：① 切在哪？——找目标中的"合成关节"（酯基/酰胺基=缩合产物、羟基=水解/还原产物、C=C=消去产物）；② 补上加氢/脱水逆反应还原成原料；③ 正着检查每步条件是否与官能团兼容（氧化剂不碰 C=C？还原剂不碰酯基？）。

## 六、常见题型

- **类型Ⅰ 官能团转化链**：烃→卤代烃→醇→醛→酸→酯，补中间体
- **类型Ⅱ 条件判断反应类型**：光照/催化剂/水/醇/酸/碱 六条件定反应
- **类型Ⅲ 羟醛缩合（信息）**："断双键、α补氢、β补氧"反推产物
- **类型Ⅳ D-A 环加成（信息）**："断π键、断π间、半键回归"拆分
- **类型Ⅴ 格氏试剂（信息）**：增碳 + 溶剂限制
- **类型Ⅵ 保护基策略**：氨基 Boc 保护 → 合成 → 水解脱保护
- **类型Ⅶ 综合推断大题**：五联证据定结构 + 全路线补全
