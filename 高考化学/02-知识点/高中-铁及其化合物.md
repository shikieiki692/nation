> [!tip] 核心方法
> 铁是变价金属，核心是「三价态图」：Fe⁰ → Fe²⁺ → Fe³⁺。
> ① 升价：Fe 遇弱氧化剂（H⁺、S、Cu²⁺、I₂）得 Fe²⁺，遇强氧化剂（Cl₂、稀 HNO₃）得 Fe³⁺；
> ② 降价：Fe³⁺ 遇 Fe、Cu、I⁻、S²⁻ 得 Fe²⁺/Fe⁰；
> ③ 检验：KSCN 变红 = Fe³⁺；再结合「先加 KSCN 不变红、再加氧化剂变红」判 Fe²⁺。

## 一、核心概念（是什么）

- **单质铁**：变价金属（+2/+3）；常温遇浓硫酸、浓硝酸**钝化**（故可用铁罐运输浓硫酸）；纯铁丝在 O₂ 中点燃生成 Fe₃O₄；红热铁与水蒸气： 3Fe + 4H₂O(g) ≜ Fe₃O₄ + 4H₂。
- **铁的氧化物**：FeO 黑色（+2）、Fe₂O₃ 红棕色（+3，俗称铁红，颜料/红色油漆）、Fe₃O₄ 黑色（+2/+3 混合，磁性，可写作 FeO·Fe₂O₃，铁在化合物中唯一的 +2/+3 共存且含 +2 价即溶于酸得二价三价混合）。
- **铁的氢氧化物**：Fe(OH)₂ 白色沉淀；Fe(OH)₃ 红褐色沉淀。
- **高铁酸盐 K₂FeO₄**：铁 +6 价，强氧化性（消毒杀菌），还原产物 Fe³⁺ 水解生成 Fe(OH)₃ 胶体（吸附净水），故称「一剂双效」。
- **铁盐/亚铁盐**：FeCl₃、FeSO₄（绿矾 FeSO₄·7H₂O）、Fe₂(SO₄)₃。

## 二、关键规律

1. **铁的氧化物与酸**：
   FeO + 2H⁺ = Fe²⁺ + H₂O；Fe₂O₃ + 6H⁺ = 2Fe³⁺ + 3H₂O；Fe₃O₄ + 8H⁺ = 2Fe³⁺ + Fe²⁺ + 4H₂O（记忆：磁性氧化物是 FeO·Fe₂O₃ 组成）。
2. **Fe(OH)₂ 制备三防**（防止氧化）：
   - ① 现配现用新制 FeSO₄（亚铁盐溶液易被空气氧化）；
   - ② 用煮沸除氧的蒸馏水配液；
   - ③ 长滴管**伸入液面以下**滴加 NaOH，并可用苯/煤油**液封**隔绝空气。
   现象：白色 → 灰绿色 → 红褐色 4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃。
3. **Fe²⁺/Fe³⁺ 相互转化**：
   - Fe²⁺ → Fe³⁺：加氧化剂 Cl₂、H₂O₂、KMnO₄(H⁺)、稀 HNO₃、O₂ 等。
   - Fe³⁺ → Fe²⁺：加还原剂 Fe、Cu、Zn、I⁻、S²⁻ 等。
   - **氧化性强弱**：Fe³⁺ > Cu²⁺ > Fe²⁺（故 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺，FeCl₃ 溶液可腐蚀电路板）。
   - **除杂**：FeCl₂ 中含 FeCl₃ → 加铁粉；FeCl₃ 中含 FeCl₂ → 通 Cl₂ 或滴氯水。
4. **Fe³⁺/Fe²⁺ 检验四法**：
   | 方法 | Fe³⁺ | Fe²⁺ |
   |------|------|------|
   | KSCN | 变红 | 不变红 |
   | 加 NaOH | 红褐色沉淀 | 白色→灰绿→红褐 |
   | 酸性 KMnO₄ | 不褪色（不反应） | 褪色（被还原） |
   | KSCN + 氯水 | 变红 | 先不变红、后变红（间接证明） |
   （Fe³⁺ 另可加苯酚显紫色。）
5. **铁与氧化性酸/盐**：
   - Fe（不足）与稀 HNO₃：Fe + 4HNO₃(稀) = Fe(NO₃)₃ + NO↑ + 2H₂O；
   - Fe（过量）与稀 HNO₃：先生成 Fe³⁺ 再被 Fe 还原为 Fe²⁺（3Fe + 8HNO₃ 稀 = 3Fe(NO₃)₂ + 2NO↑ + 4H₂O）。
6. **钴镍（锂电池材料视角）**：
   - 锂离子电池正极：LiCoO₂ + Li⁺ + e⁻ ⇌ Li₂CoO₂（充电反向）；
   - NiOOH 为镍基电池正极活性物质；
   - Fe³⁺/Co³⁺/Ni³⁺ 的氧化性与其高价态稳定性相关，试题常考「信息方程式书写」。

## 三、高考考查方式

- **选择题**：铁与水蒸气、钝化、FeCl₃ 腐蚀电路板、离子共存与检验（KSCN 法）。
- **计算/综合题**：热重曲线（2023 全国乙 FeC₂O₄·2H₂O 热重分析，x=4、y=1，题号待回填）；沉淀转化 K 值计算（2023 全国乙改编 Ag⁺/Fe³⁺ 体系 K≈3.3，答 B 偏小，题号待回填）；流程题中铁的价态与除杂（2023 重庆 Fe₃O₄ 流程 pH≤11、CaCl₂ 收率 66.6%，题号待回填）。
- **真题分布（可追溯）**：2023 全国乙卷热重、2023 全国乙卷改编 K 值判断、2023 重庆卷流程，题号均待回填。

## 四、易错点

> [!warning] 易错 1
> Fe₃O₄ 与酸反应既有 +2 又有 +3：Fe₃O₄ + 8H⁺ = Fe²⁺ + 2Fe³⁺ + 4H₂O，不能拆成「氧化铁 + 氧化亚铁」混写 s 倍。

> [!warning] 易错 2
> Fe 与稀 HNO₃ 反应铁过量得 Fe(NO₃)₂；写方程式先写 Fe³⁺ 再补「Fe + 2Fe³⁺ = 3Fe²⁺」合并，防止丢并。

> [!warning] 易错 3
> Fe²⁺ 检验要同时排除 Fe³⁺ 干扰：先加 KSCN 无现象再加氯水变红，且不能先加氯水（Fe²⁺ 全变 Fe³⁺ 就无法判原样品）。

> [!warning] 易错 4
> 钝化不是不反应：常温浓硫酸/硝酸使铁表面生成致密氧化膜阻止内部继续反应，加热或稀酸则正常反应。

> [!warning] 易错 5
> Fe(OH)₂ 制备必须隔绝 O₂；若用普通滴管悬空滴加、用未除氧的水，白色沉淀瞬间变灰绿，看不到白色。

## 五、方法点拨

- **价态地图**：考试中遇铁先定位价态，判断氧化剂/还原剂强弱决定产物（Fe²⁺ vs Fe³⁺）。
- **守恒链**：热重曲线题按「质量差 = 逸出气体质量」逐步算；终点残留物推 Fe₂O₃/FeO 等。
- **K 计算**：沉淀转化 K = Ksp(目标) / Ksp(起始) 或由平衡常数定义直接写（如 Fe³⁺ + Ag = Fe²⁺ + Ag⁺ 的 K 由两半反应 Nernst/能斯特关系得，高考用已知条件求）。
- **信息书写**：Co、Ni 电极方程式按「电子守恒 + 电荷守恒 + 物料守恒」三步配平。

## 六、常见题型

- **类型Ⅰ 铁单质**：钝化、水蒸气、与氧化性酸、点燃。
- **类型Ⅱ 氧化物与氢氧化物**：色态、与酸、Fe(OH)₂ 制备三防、受热分解。
- **类型Ⅲ 转化与检验**：Fe²⁺/Fe³⁺ 互变条件、KSCN/高锰酸钾检验。
- **类型Ⅳ 氧化还原综合**：Fe³⁺>Cu²⁺>Fe²⁺、腐蚀电路板、除杂。
- **类型Ⅴ 信息与计算**：热重曲线、锂电池材料（LiCoO₂、NiOOH）电极方程式书写。
