# 高中-氧化还原反应概念与规律

> [!tip] 核心方法
> 判断氧化还原只认一条铁律：**化合价是否变化**。记忆锁链「升、失、氧化、还原剂、具还原性；降、得、还原、氧化剂、具氧化性」+ 情节「嬛嬛失声痒痒痒」。配产物永远交给**电子守恒**收尾。

## 一、核心概念（是什么）

### 1. 本质与特征

- **本质**：电子的转移（得失或偏移）。
- **特征**：元素化合价发生变化——判断氧化还原反应的**核心判据**。

### 2. 相关概念对照（滚瓜烂熟）

| 概念 | 得/失电子 | 化合价 | 被… | 生成物 | 性质 |
|---|---|---|---|---|---|
| 氧化剂 | 得 e⁻ | 降低 | 被还原 | 还原产物 | 氧化性 |
| 还原剂 | 失 e⁻ | 升高 | 被氧化 | 氧化产物 | 还原性 |

### 3. 与四大基本反应类型的关系

| 命题 | 结论 |
|---|---|
| 置换反应一定是氧化还原反应 | ✅（单质→化合物，化合价必变） |
| 复分解反应可能是氧化还原反应 | ❌ 一定不是（阴阳离子互换，无变价） |
| 有单质参加的化合反应一定是氧化还原反应 | ✅ |
| 有单质生成的分解反应一定是氧化还原反应 | ✅ |
| 有单质参加或生成的化学反应一定是氧化还原反应 | ❌（**同素异形体转化** 单质→单质，如 3O₂ ⇌ 2O₃） |

### 4. 电子转移表示法

- **双线桥法**：箭头连接反应前后**有化合价变化的同种元素**，由反应物指向生成物，注明「得到/失去」；箭头方向**不代表**电子转移方向；得到总数 = 失去总数。
- **单线桥法**：箭头从失电子元素原子指向得电子元素原子（价升→价降）；只标电子转移**总数**，不标「得到/失去」；**不跨过「=」**。

## 二、关键规律

### 1. 五类氧化还原反应

| 分类 | 特征 | 实例 |
|---|---|---|
| 完全氧化还原 | 变价原子**全部**参加 | 4NH₃ + 5O₂ =催化剂/Δ= 4NO + 6H₂O |
| 部分氧化还原 | 变价原子**部分**参加 | MnO₂ + 4HCl(浓) =Δ= MnCl₂ + Cl₂↑ + 2H₂O |
| 歧化 | 同物质同元素同一价态，既升又降 | Cl₂ + 2NaOH = NaCl + NaClO + H₂O |
| 归中 | 高低两价态**向中间靠拢但不交叉** | 2H₂S + SO₂ = 3S + 2H₂O |
| 自身氧化还原 | 氧化剂与还原剂为**同一反应物** | 2KMnO₄ =Δ= K₂MnO₄ + MnO₂ + O₂↑ |

- 歧化**一定**是自身氧化还原，自身氧化还原**不一定**是歧化；歧化只发生在中间价态（F₂ 无歧化）。

### 2. 氧化性/还原性强弱比较四法

1. **反应原理（由强制弱）**：氧化剂 > 氧化产物；还原剂 > 还原产物。⚠️ 例外：电解反应、部分高温反应（高温 Na 制 K）不遵循。
2. **周期表/周期律**：同主族非金属自上而下单质氧化性减弱、阴离子还原性增强（F₂>Cl₂>Br₂>I₂；F⁻<Cl⁻<Br⁻<I⁻）；同周期左→右金属还原性减弱、非金属氧化性增强。⚠️ **非金属性 ≠ 氧化性**（N 非金属性强但 N₂ 因 N≡N 键能大而氧化性弱）。
3. **被氧化（还原）的程度**：同还原剂被不同氧化剂氧化，氧化产物价态高者氧化性强（Cl₂>S）；同氧化剂被不同还原剂还原，还原产物价态低者还原性强（Zn>Cu）。
4. **电化学**：原电池还原性负极>正极（浓硝酸 Fe-Cu：Fe 钝化现象、NaOH 中 Al-Mg 例外）；电解阴极先放电的阳离子氧化性强（Ag⁺>Fe³⁺>Cu²⁺>H⁺>…）；阳极先放电的阴离子还原性强（S²⁻>SO₃²⁻>I⁻>Br⁻>Cl⁻>OH⁻，口诀「牛雅典秀绿箭」）。

### 3. 价态与性质的对应

- 最高价态——**只有氧化性**（FeO₄²⁻/HNO₃/浓 H₂SO₄/KMnO₄/K₂Cr₂O₇）。
- 最低价态——**只有还原性**（金属单质、Cl⁻/Br⁻/I⁻/S²⁻）。
- 中间价态——**既有氧化性又有还原性**（H₂O₂、Fe²⁺、S、Cl₂、Br₂、I₂）。⭐ **体现哪面取决于对象**：H₂O₂ 遇酸性 FeCl₂ 显氧化性→H₂O；遇酸性 KMnO₄ 显还原性→O₂——**不要认为 H₂O₂ 只是「绿色氧化剂」**。

### 4. 先后顺序（谁强谁优先）

- **还原性 Fe²⁺ > Br⁻**：FeBr₂ + Cl₂，设 r = n(Cl₂)/n(FeBr₂)——r ≤ 1/2 只氧化 Fe²⁺；1/2 < r < 3/2 部分氧化 Br⁻；r ≥ 3/2 全氧化（2Fe²⁺+4Br⁻+3Cl₂ = 2Br₂+2Fe³⁺+6Cl⁻）。
- **还原性 I⁻ > Fe²⁺**：FeI₂ + Cl₂ 先氧化 I⁻。
- **FeI₃ 不存在**：Fe³⁺ 与 I⁻ 不能大量共存。

## 三、高考考查方式

- 题型：氧化还原判断（含古文材料）、四大反应关系、角色判断、双线桥/单线桥标注、强弱比较、先后顺序分段。
- **真题分布（出处可追溯）**：
  - 2024·浙江6月选考：CH₃OH 除 NO₃⁻——角色判断、物质的量比 6:5、转移电子 3Nₐ（0.5 mol CO₂）
  - 2022·浙江6月选考：Na₂S₂O₃ + H₂SO₄ 歧化——双剂判断、产物比 1:1、每 1 mol 转移 2 mol e⁻
  - 其余为自编判断/改编题，题号待题库回收

## 四、易错点

> [!warning] 易错
> ① 复分解一定不是氧化还原（阴阳离子互换无变价）；② 同素异形体转化是「有单质」却无变价的陷阱（3O₂⇌2O₃）；③ 歧化算转移电子只取升或降**单方面**，切忌加和；④ 角标陷阱：K₂Cr₂O₇→2Cr³⁺ 每 1 个降 6（看反应物角标）；⑤ H₂O₂ 遇强氧化剂作还原剂（产物 O₂），遇强还原剂作氧化剂（产物 H₂O/OH⁻）；⑥ FeI₃ 不存在（Fe³⁺+I⁻ 氧化还原）。

## 五、方法点拨

> [!tip] 判断四步走
> ① 标化合价（优先标变价元素）；② 看升/降（价升=失电子=还原剂，价降反之）；③ 定产物（氧化产物/还原产物与两剂对应）；④ 电子守恒验证（得 e⁻ 总数 = 失 e⁻ 总数）。古文题先翻译生活反应再套判据；常考俗名「曾青/鬼火/丹砂/青蒿」要熟。

## 六、常见题型

- **类型Ⅰ 判断是否为氧化还原**：化合价判据 + 四大关系表 + 古文/生活情景
- **类型Ⅱ 四大基本反应关系**：单质→单质例外辨析
- **类型Ⅲ 角色判断**：两剂两产物 + 物质的量比 + 转移电子数
- **类型Ⅳ 单/双线桥标注**：箭头方向、得失电子数、变价原子数匹配
- **类型Ⅴ 强弱比较与先后顺序**：搭链法 + 谁强谁优先分段（FeBr₂/FeI₂ 通 Cl₂）
