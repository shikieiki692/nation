# 高中-烃与卤代烃

> [!tip] 核心方法
> 反应类型三分类：**取代"断σ成σ"、加成"断π成σ"、消去"断σ成π"**。先判断键类型，再套条件（光照/催化剂/水/醇），考场不慌。

## 一、核心概念（是什么）

### 1. 烷烃、烯烃、炔烃

- **通式**：烷烃 CₙH₂ₙ₊₂、烯烃 CₙH₂ₙ、炔烃 CₙH₂ₙ₋₂；**CₙH₂ₙ 的烃可能是环烷烃**
- **物理**：C1~4 气态；沸点随碳数增而升、同碳数支链越多沸点越低；均小于水、难溶于水
- **化学**：
  - 取代"断σ成σ"：烷烃 + Cl₂ 光照，-C-H ~ X₂ ~ HX；与溴水不反应
  - 加成"断π成σ"：烯/炔与 H₂、X₂、HX、H₂O、HCN
  - **马氏加成**：不对称烯烃 + HX，H 加含氢多碳（"亲上加亲"）；过氧化物存在时反马氏
  - **乙炔加成链**：H₂ 少→乙烯、足→乙烷；Br₂ 少→1,2-二溴乙烯、足→四溴乙烷；HCl→氯乙烯；H₂O→乙醛（烯醇重排）；HCN→丙烯腈
  - **加聚**：书写注意半键所在碳位置；丙烯→聚丙烯、乙炔→聚乙炔
  - **二烯烃**：1,2-加成 / 1,4-加成（共轭二烯）；共轭三烯可 1,6-加成
- **KMnO₄ 氧化规律**：
  - 烯：RCH=CH₂ → RCOOH + CO₂；RCH=CHR' → 两羧酸；R₂C=CHR' → 酮 + 羧酸（**双键碳 2H→CO₂、1H→羧基、无H→酮羰基**）
  - 炔：端位三键碳 → CO₂；链中三键碳 → 羧基
  - 烷：不褪色

### 2. 苯及芳香烃

- **苯**：C₆H₆ Ω=4，平面正六边形 12 原子共面，sp²，大 π 键（Π₆⁶），键长均等
- **化学**：易取代（液溴/FeBr₃、浓硝酸/浓硫酸、磺化可逆、傅克）、难加成（H₂/Ni→环己烷）、能燃烧；**不使酸性 KMnO₄ 褪色**
- **苯 vs 溴水**：萃取褪色，取代需液溴 + FeBr₃
- **苯同系物（甲苯）**：硝化（邻对位优先）；光照 Cl₂ 取代**侧链**；**侧链被 KMnO₄ 氧化成 -COOH**（需苯环相连碳有 H）
- **定位效应**：邻/对位定位基（甲基、羟基、氨基等）；间位定位基（硝基、羧基、酰胺基等）
- **C—H 键稳定性**：乙炔 > 乙烯 > 乙烷（s 成分越多越牢固）

### 3. 卤代烃

- **水解（取代）**：NaOH 水溶液、加热 → 醇。芳卤（卤直接连苯环）难水解
- **消去**：NaOH 醇溶液、加热 → 烯。**必须有 β-H**；β-H 种类数决定烯烃种类数；二卤代烷消去可得炔烃
- **卤素检验**：水解 → **稀 HNO₃ 酸化** → AgNO₃ → 白/浅黄/黄；卤代烃非电解质，不能直接电离出 X⁻
- **制取**：烯 + X₂ 加成、烯 + HX（**工业氯乙烷用乙烯+HCl**）、醇 + HX、烷烃取代（产杂少用）

## 二、关键规律/公式

| 规律 | 内容 | 注意 |
|---|---|---|
| 通式对映 | 烷 CₙH₂ₙ₊₂ / 烯 CₙH₂ₙ / 炔 CₙH₂ₙ₋₂ | CₙH₂ₙ 可能环烷烃 |
| 取代定量 | -C-H ~ X₂ ~ HX | 光照；溴水不反应 |
| KMnO₄ 除杂 | 只可鉴别不可除杂（乙烯→CO₂ 新杂质） | 溴水可鉴别可除杂 |
| 苯取代 | 液溴+FeBr₃；硝化需浓硫酸 | 溴水只萃取 |
| 卤代烃转化 | 水△→醇 / 醇△→烯 | NaOH 条件决定方向 |

## 三、高考考查方式

- 题型：选择（概念/实验）、填空（转化路线中间体）
- 常见设问：鉴别与除杂试剂选取、KMnO₄/溴水现象、一氯代物计数、加成/消去产物判断、苯环定位
- **真题分布（出处可追溯，待 `03-题库` 高考真题库建立后回填精确题号）**：
  - 2023·浙江6月选考：丙烯转化（Br₂ 光照取代位、消去、加聚链节）（答案 B）
  - 2024·九省联考：高分子循环利用、共轭三烯二溴代物 4 种（答案 C）
  - 2022·辽宁卷：苯乙炔共直线原子、加成取代、溶解性（答案 C）

## 四、易错点

> [!warning] 易错
> ① 苯与溴水是萃取不是取代；② 酸性 KMnO₄ 只能鉴别不能除杂乙烯（溴水可二者）；③ CₙH₂ₙ 可能是环烷烃（不褪色）；④ 与苯环直接相连碳无 H，侧链不能被 KMnO₄ 氧化（如叔丁基苯）；⑤ 甲烷 Cl₂ 取代得不到纯净 CCl₄；⑥ 共轭二烯 1,4-加成产物注意顺反；⑦ 卤代烃检验必须酸化（防 Ag₂O 干扰）。

## 五、方法点拨（蓝字注释风格）

> [!tip] 烯烃被 KMnO₄ 氧化产物断面法
> 把 C=C 从中间切开：双键碳上有几个 H 就对应 CO₂（2 个 H）、羧酸（1 个 H）、酮（0 个 H）。例：CH₃-C(CH₃)=CH-CH₃ → 右侧 CH 成乙酸，左侧 C 无 H 成酮 → 2-甲基-2-丁烯。

## 六、常见题型

- **类型Ⅰ 烷烃概念判断**：甲烷二氯代物唯一 → 正四面体；CₙH₂ₙ₊₂ 全 σ 键
- **类型Ⅱ 烯炔概念与加成**：丙烯 + HBr 主产物（马氏）、丙炔最多 2 mol Cl₂、聚丙烯不褪色
- **类型Ⅲ 共轭二烯加成计数**：1,2/1,4/1,6 位点 + 顺反
- **类型Ⅳ KMnO₄ 氧化推断**：由氧化产物反推烯烃结构
- **类型Ⅴ 苯及同系物实验**：溴苯制备（CCl₄ 洗气证取代）、苯证明无单双键交替（邻位二溴代物唯一）
- **类型Ⅵ 卤代烃水解/消去/检验三步曲**：由卤代烃制二元醇（消去→加成→水解）
