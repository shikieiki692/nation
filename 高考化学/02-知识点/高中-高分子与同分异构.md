# 高中-高分子与同分异构

> [!tip] 核心方法
> 高分子两条路：**加聚无端基、缩聚有端基**；同分异构三把尺：**不饱和度 Ω 定类别、等效氢定对称、换元法定多卤代**；共面共线一实招：**sp³ 杂化碳是"共面破坏者"**。

## 一、核心概念（是什么）

### 1. 生物大分子

- **糖类**：单糖（葡萄糖/果糖 C₆H₁₂O₆）、二糖（蔗糖/麦芽糖 C₁₂H₂₂O₁₁）、多糖（淀粉/纤维素 (C₆H₁₀O₅)ₙ）
- **还原糖**：含醛基或可互变出醛基（葡萄糖、果糖、麦芽糖）可银镜/与 Cu(OH)₂；蔗糖、淀粉、纤维素非还原糖
- **淀粉水解检验三关键**：① 稀 H₂SO₄ 加热；② 水解后**先加 NaOH 中和至碱性**；③ 再加银氨或新制 Cu(OH)₂
- **α-氨基酸**：两性（-NH₂ 与酸、-COOH 与碱成盐）；成肽脱水缩合成**肽键 -CO-NH-**
- **二肽计数**：n 种氨基酸任取 2 个按序排列 → n + 2Cₙ²（3 种氨基酸 → 9 种）
- **水解找氨基酸**："找接口断肽键（C-N 键），C 补 -OH、N 补 -H"
- **盐析 vs 变性**：盐析（浓 (NH₄)₂SO₄）可逆物理变化；变性（加热/酸碱/重金属/UV/甲醛）不可逆化学变化
- **检验**：浓硝酸微热显黄（含苯环）、灼烧羽毛气味
- **核酸**：磷酸+戊糖+碱基→核苷酸→核酸；DNA 双螺旋碱基对间靠氢键（A=T、G≡C）；RNA 含核糖、U 代替 T

### 2. 合成高分子

- **术语**：单体 / 链节（重复结构单元）/ 聚合度 n
- **加聚**：单体含 C=C/C≡C，断 π 键，无小分子，**无端基**
- **缩聚**：双官能团单体脱小分子（H₂O），**有端基**，链节含酯基/酰胺基/酚醛结构
- **线型**（热塑性：加热先熔化再燃烧，如 PE）/ **网状**（热固性：加热不熔化只燃烧，如酚醛树脂；单体 ≥3 接口 → 网状）
- **书写口诀**：单烯烃"断 π 键、键分两端、加括号写 n"；共轭二烯"单变双、双变单、破两头移中间"（1,4-加聚注意顺反）；缩聚端基必须写出、1 种单体脱 (n-1) 个小分子、2 种脱 (2n-1) 个
- **聚合度计算**：加聚 M = 链节式量×n；缩聚 M = 链节式量×n + 端基 = 单体式量×n − 端基分子数×(n−1) 或 (2n−1)
- **单体推断**：无端基主链全碳→加聚（"半键回归"：单变双；主链双键"见双键 4 个碳、无双键 2 个碳"）；有端基主链含 O/N（C-O、C-N）→ 缩聚（去中括号和 n 即单体）

### 3. 原子共面共线

| 分子 | 杂化 | 关键结论 |
|------|------|----------|
| 甲烷/氨/环己烷 | sp³ | **所有原子不可能全共面** |
| 乙烯 | sp² | 平面形；(CH₃)₂C=C(CH₃)₂ 所有 C 一定共面 |
| 乙炔 | sp | 直线形；CH₃-C≡C-CH₃ 所有 C 一定共线 |
| 苯 | sp² | 12 原子共面；对位 2C+2H 共线 |
| 甲醛/丙酮 | sp² | 平面三角形；C、O 一定全共面 |

**面与面**：σ 键（单键）相连可旋转 → **可能**全共面；π 键相连不可旋转 → **一定**全共面；直线与平面共用 2 原子 → 直线从属于平面。

### 4. 同分异构体

- **不饱和度 Ω**：与同碳数链状烷烃相比少的 H 数÷2；氧不影响；卤当 H 看；**含 N 扣 N 引入的 H**；1=双键/环、2=三键或双环、4=苯环；**硝基 -NO₂ 的 Ω=1**；三环以上共边减 1
- **书写顺序**：先官能团类型异构 → 再碳架异构 → 最后位置异构
- **官能团异构检索表**：CₙH₂ₙ（Ω1）烯烃/环烷烃；CₙH₂ₙ₊₂O（Ω0）醇/醚；CₙH₂ₙO（Ω1）醛/酮/烯醇；CₙH₂ₙO₂（Ω1）羧酸/酯/羟基醛
- **常见数**：烷烃 C₄=2/C₅=3/C₆=5/C₇=9；烷基数 C₃=2/C₄=4/C₅=8；一卤代物数=等效氢数=烷基数；**多卤代用换元法**（C₄HCl₉ ↔ C₄H₉Cl = 4）
- **芳香族**：一取代看侧链；**苯环二取代 = 3 的倍数**；三相同 = 3、两同一异 = 6、三相异 = 10；四/五支链用换元
- **手性碳**：连 4 个不同原子/基团的 sp³ 碳；**顺反**：双键两端各连两个不同基团
- **性质→官能团对应表（必记）**：Na→醇/羧；NaOH→羧/酚/酯/酰胺/卤代烃；Na₂CO₃→酚/羧（放 CO₂ 必含羧）；NaHCO₃→仅羧；溴水→C=C/C≡C/醛基/酚邻对位；FeCl₃ 紫色→苯酚；银镜→醛基（1:2Ag）

## 二、关键规律/公式

| 规律 | 内容 | 注意 |
|---|---|---|
| 加聚 vs 缩聚 | 无端基 vs 有端基 | 链节是否含 O/N |
| 聚合度 | 加聚 M=链节×n；缩聚 M=单体×n−端基 | 缩聚要减（n−1）或（2n−1） |
| 共面破坏 | sp³ 杂化 C/N 令原子不全共面 | 减法计数 |
| Ω 判结构 | 1 双键/环、2 三键、4 苯环 | 硝基 Ω=1 |
| 芳香族二取代 | 总数为 3 的倍数 | 邻间对 × 侧链 |

## 三、高考考查方式

- 题型：选择（大分子/高分子/共面/异构数）、填空（限定条件异构）
- 常见设问：加聚缩聚判断与单体、聚合度计算、糖类蛋白质性质、最多/至少共面原子数、限定条件同分异构体条数（结合 NMR）
- **真题分布（出处可追溯，待 `03-题库` 高考真题库建立后回填精确题号）**：
  - 2024·安徽卷：D-乙酰氨基葡萄糖含醛基/氨基/羟基（答案 B）
  - 2024·北京卷：核酸结构判断（磷酸+戊糖+碱基、碱基对间氢键）（√）
  - 2024·湖南卷：DNA/RNA 戊糖与碱基组成不同（答案 A）
  - 2024·河北卷：聚四氟乙烯热稳定不易分解（答案 B）
  - 2024·全国甲卷：PLA 回收 MP 含羧基同分异构体仅 2 种（答案 C）
  - 2023·湖北卷：C₅H₁₂O 饱和一元醇 7 种，NMR 9:2:1
  - 2023·全国甲卷：硝基+Cl 芳香类 16 种，NMR 2:2:1:1
  - 2023·河北卷：酚酯水解 FeCl₃ 显色，NMR 3:2
  - 2022·湖南卷：C₄H₆O 银镜+顺反 5 种
  - 2023·新课标卷：C₁₀H₁₄O 苯环+3 甲基+手性碳 9 种
  - 2022·浙江6月：含 N 环+3 种 H+N-H 4 种

## 四、易错点

> [!warning] 易错
> ① 共直线原子要算苯环对位延伸 + 补上氢（苯乙炔最多 6 原子共线）；② CₙH₂ₙ 可能是环烷烃（不褪色）；③ 一氯代物计数必须补全氢；④ 缩聚端基别丢、"羧基酯基酰胺基不加氢"；⑤ 二肽计数按序排列区分顺序；⑥ 淀粉水解检验要先中和再检验（碱性条件）；⑦ 共面"最多"用减法（sp³ C 减 2 原子、sp³ N 减 1 原子）。

## 五、方法点拨（蓝字注释风格）

> [!tip] 同分异构三步法
> ① 列组成算 Ω（差 H 数 ÷2 + 条件限定官能团）；② 提取官能团信息（NaHCO₃→羧基、FeCl₃→酚、银镜→醛）；③ 组合讨论（芳香族用"3/6/10"基数、NMR 对对称）。例：酚酯水解后 FeCl₃ 显色 → 找"酚酯 + NMR 3:2" → 对位结构。

## 六、常见题型

- **类型Ⅰ 糖类/蛋白质/核酸判断**：还原糖、二肽计数、盐析变性、核酸组成
- **类型Ⅱ 加聚/缩聚单体与聚合度**：涤纶 M=192n+18、链节式量反推 n
- **类型Ⅲ 共面共线计数**：苯乙炔共线 6 原子、C₆H₅-CH=CH-C≡C- 最多 21 原子共面
- **类型Ⅳ 不饱和度与分子式**：异山梨醇 Ω 校验、由 Ω 写分子式
- **类型Ⅴ 限定条件异构**：三步法 + NMR 对称（芳香族 16/9/6/5 案例）
- **类型Ⅵ 多卤代换元**：C₄HCl₉ 与 C₄H₉Cl 同构（4 种）
