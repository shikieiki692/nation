# 化工流程框架与关键环节

> [!tip] 核心方法
> 化工流程 = 大型"分离提纯"题。总框架「原料 → 预处理 → 核心反应 → 分离提纯 → 目标产物」。**目标元素追踪法**：先明确目标元素及其去向（滤液/滤渣、沉淀/溶液、水相/有机相），对杂质元素套"不增、不减"原则，方程式的核心与循环物质随之水落石出。

## 一、核心概念

1. **流程总框架**：原料 → 预处理（粉碎/煅烧/酸浸/碱浸/碱洗）→ 核心反应 → 分离提纯（过滤/结晶/萃取/洗涤）→ 目标产物。含循环物质、副产物处理、尾气回收。
2. **除杂"不增、不减"**：除杂试剂不得引入新杂质，也不得消耗目标产物。
3. **目标元素追踪法**：目标元素始终在主线上——过滤时在固体还是溶液？结晶时析出还是留母液？分液在水相还是有机相？
4. **循环物质的四找法**：① 流程中的回头箭头；② 加入物质与流出产物的交集；③ 重结晶母液含较多溶质；④ 电解后溶液再生酸/碱/O₂/H₂。
5. **提高浸出效率四法**：适当升温、增大酸/碱浓度、原料粉碎、搅拌。

## 二、关键规律

### 1. 原料预处理（高频设问"该操作的目的"）

| 操作 | 目的 |
|---|---|
| 粉碎/研磨 | 增大接触面积 → 加快反应速率、增大目标元素利用率 |
| 煅烧/焙烧 | ① 除有机物或碳 ② 使成分分解 ③ 氧化某些物质 ④ 难溶硫化物 → 易溶氧化物（**涉化合价升高时考虑空气中 O₂**） |
| 酸溶/酸浸 | 一般酸溶活泼金属、碱性氧化物、两性氧化物、碳酸盐；氧化性酸（HNO₃）注意还原剂被氧化 |
| 碱洗（纯碱洗） | 除原料表面油污（酯类）——**矿物油（烃类）碱洗不掉，靠煅烧** |
| 碱溶/碱浸 | 溶解两性金属/氧化物、酸性氧化物（Al、Zn、Ga、Be、Si） |

### 2. 核心方程式书写

- **复分解"定1法"**：最复杂物质计量数定 1 → 按原子守恒配其他 → H/O 不守恒时补 H₂O（最后用 H 补、O 检查）。
- **沉淀体系注意弱电解质后续反应**（用 HCO₃⁻ 沉淀时放 H⁺）：
  - `Ni²⁺ + 2HCO₃⁻ = NiCO₃↓ + CO₂↑ + H₂O`
  - `Ni²⁺ + HCO₃⁻ + NH₃·H₂O = NiCO₃↓ + NH₄⁺ + H₂O`
  - 若 Ksp(RCO₃) > Ksp[R(OH)₂]，用 NH₄HCO₃ 优于 NaHCO₃（NaHCO₃ 碱性更强会生成 R(OH)₂ 副产）
  - 碱式碳酸盐：`2Ni²⁺ + 2CO₃²⁻ + H₂O = Ni₂(OH)₂CO₃↓ + CO₂↑`
  - 黄钠铁矾：`Na⁺ + 3Fe³⁺ + 2SO₄²⁻ + 6H₂O + 6CO₃²⁻ = NaFe₃(SO₄)₂(OH)₆↓ + 6HCO₃⁻`
- **氧化还原**：流程中 O₂ 常被隐藏需自行判断。用化合价升降守恒 + 电荷守恒 + 原子守恒推导副产物。

### 3. 分离提纯方法选择

| 情境 | 方法 |
|---|---|
| 固液分离 | 过滤（减压过滤/抽滤：快、固液分离好、利于干燥） |
| 不互溶液体 | 分液 |
| 沸点差异大 | 蒸馏 |
| 溶解度差异 | 萃取（反萃取：加酸促平衡逆移） |
| 溶解度受温度影响小（NaCl 类） | 蒸发结晶 |
| 溶解度受温度影响大（CuSO₄·5H₂O、KNO₃ 类） | 蒸发浓缩-冷却结晶 |
| 目标量大且溶解度小 | 蒸发浓缩趁热过滤（防降温析出杂质） |
| 洗涤晶体 | 水洗除水溶性杂质；**冰水洗**除杂质+防溶解损耗；有机溶剂洗除杂质+降低溶解度+易挥发利于干燥 |

### 4. 控制条件

- **控制 pH 六角度**：① 分离沉淀（结合开始/完全沉淀 pH 或 Ksp）② 促/抑水解 ③ 防副反应 ④ 防沉淀溶解 ⑤ 满足反应酸碱条件 ⑥ 萃取率与 pH（差值越大越易分离）。
- **加热四角度**：① 加快速率 ② 平衡向吸热方向移动 ③ 除热不稳定物质/逸气 ④ 调 pH 除 Fe³⁺/Al³⁺ 时促水解完全、避免胶体。
- **降温三角度**：减慢速率 / 平衡向放热方向移动 / 降溶解度析晶。
- **控温五角度**：防副反应 / 催化剂最佳活性（过高失活）/ 按图表选最佳转化率·选择性·产率 / 防 H₂O₂、NH₃·H₂O、NH₄Cl、NaHCO₃、HClO、HNO₃、KMnO₄ 等分解挥发 / 控溶解结晶。
- **气体氛围**：O₂/H₂O/CO₂ 是否参与反应；隔绝空气防氧化、水解、潮解。
- **抑制水解**：加过量酸抑制弱碱阳离子水解、过量碱抑制弱酸阴离子水解；**HCl 气流中蒸发 MgCl₂/FeCl₃ 得无水盐酸盐**。

### 5. 洗涤与检验

- 沉淀洗涤法：加蒸馏水浸没 → 自然流下 → 重复 2~3 次。
- 检验洗净：取**最后一次洗涤液**加试剂检验（禁取沉淀本身）。

## 三、高考考查方式

化学工艺流程为高考必考大题位置之一（2021-2025 新高考 1~2 道），设问集中在：

1. 预处理操作的目的与选择（粉碎/煅烧/酸浸/碱浸/碱洗）。
2. 核心反应方程式的书写（定1法复分解 / 氧化还原含隐含 O₂）。
3. 分离提纯方法选择（蒸发结晶 vs 冷却结晶 vs 趁热过滤、洗涤方式）。
4. 控制 pH 范围计算（Ksp 反推、开始/完全沉淀、两性上限交集）。
5. 循环物质与原子利用率的判断。
6. 温度/氛围调控的理由（双向作答）。
7. 产率、萃取率、浓度计算（元素守恒）。

## 四、易错点

> [!warning] 易错 1
> 碱洗≠除矿物油。碱洗只能除酯类油污（皂化）；矿物油（烃类）碱洗不掉，必须靠煅烧。

> [!warning] 易错 2
> 蒸发结晶与冷却结晶方向颠倒。溶解度随温度变化**小**→蒸发结晶；变化**大**→蒸发浓缩-冷却结晶。

> [!warning] 易错 3
> 趁热过滤的目的是**防降温析出杂质**（不是防目标产物），目标量大且溶解度小时采用。

> [!warning] 易错 4
> pH 上限受两性氢氧化物约束：Al(OH)₃/Zn(OH)₂/Ga(OH)₃/Be(OH)₂ 在碱性下重新溶解，pH 范围取各约束**交集**。

> [!warning] 易错 5
> 检验沉淀洗净取**最后一次洗涤液**，不能取沉淀本身；且现代绿色化学优先考虑循环利用。

## 五、方法点拨

1. **读流程三步**：先看原料与目标产物（起点终点对比定元素去向）→ 标目标元素在主线上每一步的去向 → 对杂质元素逐一找除杂操作。
2. **写方程式五步**：指入=反应物、指出=产物 → 定1法/化合价升降 → 配平 → 补 H₂O（H 补 O 查）→ 检查沉淀/气体箭头。
3. **pH 计算**：`c(H⁺) = 10⁻ᵖᴴ`，由 Ksp 算开始沉淀 pH；**多离子时最大值取"未沉淀离子开始沉淀 pH 的最小值"**；注意表格起始浓度与题目浓度是否一致。
4. **双向答题模板**：温度"低于最佳温度→速率慢；高于最佳温度→物质分解/挥发"，务必两条都写。

## 六、常见题型

### 类型Ⅰ 复分解方程式书写
- 定1法 + 补 H₂O。例：`4H₃BO₃ + 2NaOH + 3H₂O = Na₂B₄O₅(OH)₄·8H₂O`；`2NH₄HCO₃ + FeSO₄ = Fe(OH)₂↓ + (NH₄)₂SO₄ + 2CO₂↑`。

### 类型Ⅱ 氧化还原方程式书写
- 隐含 O₂ + 化合价守恒。例：`2Li₂CO₃ + 4MnCO₃·Mn(OH)₂ + 3O₂ ═(900-1000℃)═ 4LiMn₂O₄ + 6CO₂↑ + 4H₂O`；`(NH₄)₂Cr₂O₇ ═(高温)═ N₂↑ + Cr₂O₃ + 4H₂O`（逆向配平）。

### 类型Ⅲ pH 范围计算
- pH=pKa 转换，由 Ksp 算开始沉淀 pH；Al(OH)₃ 等两性在 pH≥9.6 重新溶解 → 上限受限；交集思想。

### 类型Ⅳ 温度调控
- 双向作答：低于最佳温度速率慢；高于最佳温度物质挥发/分解（苯挥发、H₂O₂ 分解、NH₃ 逸出、催化剂失活）。

### 类型Ⅴ 萃取与反萃取
- 反萃取加酸（`VO²⁺ + H₂R ⇌ VOR + 2H⁺`，加 H⁺ 逆向）；选强酸不选弱酸（CH₃COOH 的 H⁺ 太低）；兼顾后续反应不引入杂质（避免 HCl——因 KClO₃ 氧化生成 Cl₂）。

### 类型Ⅵ 重结晶与循环物质
- 溶解度受温度影响大→冷却结晶；小→蒸发结晶；目标量大且溶解度小→蒸发浓缩趁热过滤。循环物质四找法。
