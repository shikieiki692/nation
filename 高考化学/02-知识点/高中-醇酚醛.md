# 高中-醇酚醛

> [!tip] 核心方法
> **氧化失 H、还原得 H**。醇 失H→ 醛 得O→ 酸（连续氧化链）；醇氧化/消去分别看 **α-H** 和 **β-H**；酚的弱酸性用"H₂CO₃ > 苯酚 > HCO₃⁻"一列定死。

## 一、核心概念（是什么）

### 1. 醇

- **概念**：-OH 连烃基；饱和一元醇 CₙH₂ₙ₊₁OH；**-OH 直接连苯环的是酚**
- **物理**：一元脂肪醇密度 < 水；沸点远高于同分子量烷烃（**分子间氢键**）；低级醇（C≤3）与水互溶
- **化学性质（乙醇为例）**：
  1. 与 Na 置换：2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑
  2. 消去：浓 H₂SO₄ / 170℃ → CH₂=CH₂↑ + H₂O（需 **β-H**）
  3. 取代：与 HX → 卤代烃；140℃ 分子间脱水成醚；酯化（**酸脱羟基、醇脱氢**）
  4. 氧化：① 燃烧；② 催化氧化 Cu/Ag△（"失氢"）；③ K₂Cr₂O₇ 橙→灰绿（酒驾）；KMnO₄ 氧化成乙酸
- **氧化/消去规律（关键）**：
  - 催化氧化需 **α-H**：2 个 α-H（-CH₂OH）→ 醛；1 个 α-H（-CH(OH)-）→ 酮；无 α-H 不氧化
  - 强氧化剂：1 个 α-H → 酮；2 个 α-H → 羧酸；3 个 α-H → CO₂
  - 消去需 β-H（非苯环 H）：CH₃OH 不能消去；两种不等效 β-H 得两种烯烃

### 2. 酚

- **苯酚**：-OH 直接连苯环；露置空气变粉红色；常温溶解度不大、>65℃ 混溶
- **弱酸性**：H₂CO₃ > C₆H₅OH > HCO₃⁻；与 NaOH、Na₂CO₃ 反应（**均生成 NaHCO₃**），不与 NaHCO₃ 反应
- **浓溴水**：2,4,6-三溴苯酚白色沉淀（邻对位取代，无需催化剂）
- **FeCl₃ 显色**：紫色（酚类特征）
- **缩聚**：苯酚 + 甲醛 → 酚醛树脂（酸催化线型、碱催化网状）
- **卤素单质总结**：Cl₂ 气光照取代烷基；Br₂ 气光照烷基 / 液 FeBr₃ 苯环 / 水溶液 C=C 加成·醛基氧化·酚邻对位 / CCl₄ C=C 加成

### 3. 醛和酮

- **醛** RCHO（饱和一元醛 CₙH₂ₙO）；**酮**羰基连两个烃基（CₙH₂ₙO n≥3）；丙醛与丙酮同分异构
- **甲醛**：标况下唯一气态含氧衍生物；福尔马林 = 35%~40% 甲醛水溶液
- **化学**：
  1. 氧化"得氧"：银镜反应（口诀"醛银氨、一二三、醛基变成羧酸铵"）；新制 Cu(OH)₂（**NaOH 必须写**，砖红色 Cu₂O）
  2. 还原"加氢"：RCHO + H₂ → RCH₂OH；NaBH₄/LiAlH₄ 还原
  3. 羰基亲核加成
- **醛的计算（高频）**：1 mol 醛基 ~ 2 mol Ag ~ 1 mol Cu₂O；**甲醛相当于 2 个醛基**：1 mol HCHO ~ 4 mol Ag；二元醛 1 mol ~ 4 mol Ag

## 二、关键规律/公式

| 规律 | 内容 | 注意 |
|---|---|---|
| 连续氧化链 | 醇 失H→ 醛 得O→ 酸 | 合成核心 |
| 醇催化氧化 | α-H 2→醛 / 1→酮 / 0→不氧化 | 看 α-C 上 H 数 |
| 醇消去 | 需 β-H；β-H 种类数=烯烃数 | 无 β-H（甲醇）不消去 |
| 酚酸性 | H₂CO₃ > 苯酚 > HCO₃⁻ | 与 Na₂CO₃ 生成 NaHCO₃ |
| 银镜计量 | 1 醛基 : 2 Ag : 1 Cu₂O | 甲醛 = 2 醛基 |

## 三、高考考查方式

- 题型：选择（性质/现象/计量）、实验（银镜/消去）、推断中间体判断
- 常见设问：醇氧化产物判断、酚的检验（FeCl₃/浓溴水）、醛的银镜与 Cu(OH)₂ 计量、鉴别试剂选取
- **真题分布（出处可追溯，待 `03-题库` 高考真题库建立后回填精确题号）**：
  - 2024·浙江6月：有机物 A 推断（质谱 60 + 4 种 H → 丙醇）（答案 D）
  - 2024·全国甲卷：白藜芦醇 FeCl₃ 检酚（见合成推断章共用例）

## 四、易错点

> [!warning] 易错
> ① 醇催化氧化看 α-H、消去看 β-H，混用必错；② 酚与浓溴水生成沉淀、苯与溴水是萃取——"白色沉淀"是酚的关键证据；③ 苯酚与 Na₂CO₃ 生成 NaHCO₃ 不放 CO₂，与 NaHCO₃ 不反应；④ Cu(OH)₂ 检验醛基必须写 NaOH（碱性介质）；⑤ 甲醛银镜记 1:4（不是 1:2）；⑥ 钠与乙醇/水都放 H₂，不能验水。

## 五、方法点拨（蓝字注释风格）

> [!tip] "失氢得氧"判氧化还原
> 醇→醛酮=失 2H=氧化；醛→酸=得 1O=氧化；醛→醇=得 2H=还原（加 H₂）。有机氧化还原就是 H/O 的得失，与无机价态法脱钩。

## 六、常见题型

- **类型Ⅰ 醇的性质判断**：乙醇实验三错（浓硫酸倒入、140/170℃、产物未洗气）、酒驾检测
- **类型Ⅱ 醇氧化/消去产物**：C₇H₁₆O 饱和一元醇——哪个消去得两种烯、哪个氧化成酮/醛
- **类型Ⅲ 酚性质综合**：白藜芦醇定量（浓溴水/加氢 mol 数）、除苯中苯酚（NaOH 分液）
- **类型Ⅳ 醛的计算**：银镜/斐林试剂物质的量换算、甲醛双醛基陷阱
- **类型Ⅴ 鉴别与分离**：己烷/溴乙烷/酒精只用水分辨；苯酚/苯分离用 NaOH
