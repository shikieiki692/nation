# 高中-羧酸酯油脂

> [!tip] 核心方法
> 羧酸→酯→油脂是一条"酯化/水解"双向链：**酸脱羟基、醇脱氢**；酯水解酸催化可逆、碱催化不可逆；油脂=高级脂肪酸甘油三酯（可皂化），矿物油=烃（不可皂化）。

## 一、核心概念（是什么）

### 1. 羧酸

- **通式**：饱和一元羧酸 CₙH₂ₙO₂；官能团 -COOH
- **重要羧酸**：甲酸 HCOOH（**既有羧基又有醛基**→可银镜、加 H₂）；乙酸（酸性 > 碳酸）；乙二酸（草酸，还原剂、中强酸）；苯甲酸（易升华）
- **物理**：C≤4 与水互溶；**沸点比相应醇高**（羧酸分子间氢键更强）
- **化学**：① 弱酸性；② 酯化（**酸脱羟基、醇脱氢**，可逆，浓 H₂SO₄ 吸水）；③ **羧基/酯基/酰胺基不能与 H₂ 加成**（醛基/酮羰基/氰基可）；④ LiAlH₄ 还原→醇；⑤ α-H 取代
- **羟基活性**：-COOH（Na/NaOH/Na₂CO₃/NaHCO₃ 全 √）、酚-OH（除 NaHCO₃ 全 √）、醇-OH（仅 Na √）；**只有 -COOH 能与碳酸盐/碳酸氢盐放 CO₂**
- **KMnO₄ 褪色口诀"纯粉犬本系稀缺"**：醇/酚/醛/苯的同系物/烯/炔；苯本身不褪色

### 2. 酯

- **通式** RCOOR'；低级酯芳香液体、密度 < 水、难溶水
- **水解**：酸催化（可逆，酸+醇）；碱催化（不可逆，羧酸盐+醇；碱中和促正移）
- **消耗 NaOH 总结**：直接——-COOH(1)、酚-OH(1)；间接——酯基(1 或 2)、C-X(1 或 2)、酰胺基(1)；**水解产物含酚羟基时 1 份官能团耗 2 份 NaOH**
- **甲酸酯检测**：既能银镜又能水解 → 必含甲酸酯 H-C(=O)-O-

### 3. 油脂

- **结构**：高级脂肪酸甘油三酯（软脂酸 C₁₅H₃₁COOH / 硬脂酸 C₁₇H₃₅COOH / 油酸含 1 个 C=C / 亚油酸含 2 个 C=C）
- **分类**：液态油（不饱和多）/ 固态脂肪（饱和多）；天然油脂是混合物、无固定熔沸点
- **化学**：① 氢化（硬化，还原）；② 水解：酸（可逆）→ 高级脂肪酸+甘油，碱（皂化，不可逆）→ 高级脂肪酸盐+甘油
- **肥皂制取**：皂化 → 加食盐**盐析** → 上层高级脂肪酸钠 + 下层甘油+食盐水
- **油脂/酯 vs 矿物油**：油脂和酯可皂化，矿物油（烃）不能水解；加含酚酞 NaOH 加热，红色变浅且不分层为油脂/酯

### 4. 胺与酰胺

- **胺** R-NH₂：碱性（N 孤电子对配位）；与羧酸生成酰胺；**胺不能水解**
- **酰胺** R-CONH₂：水解——酸→羧酸+铵盐（无氨气）、碱→羧酸盐+氨气；DMF 是优良溶剂

## 二、关键规律/公式

| 规律 | 内容 | 注意 |
|---|---|---|
| 酯化机理 | 酸脱羟基、醇脱氢 | 可逆 |
| 酯水解 | 酸催化可逆 / 碱催化不可逆 | 碱中和羧酸促正移 |
| NaOH 计量 | 羧基 1、酚羟基 1、酯基 1-2 | 酚酯产物含酚羟基再 +1 |
| 羟基活性 | 羧>酚>醇（试剂覆盖度递减） | 只有羧基放 CO₂ |
| 银镜+水解 | 兼具 → 甲酸酯 HCOOR | 判断题关键 |
| 加氢定量 | C=C(1)/C≡C(2)/醛(1)/酮(1)/氰(2) | 羧/酯/酰胺不加氢 |

## 三、高考考查方式

- 题型：选择（性质/计量/鉴别）、实验（乙酸乙酯制备/草酸分解）、推断（官能团确定）
- 常见设问：耗 NaOH 计量、酯水解产物、银镜判断甲酸酯、皂化与盐析、羧酸酸性比较实验
- **真题分布（出处可追溯，待 `03-题库` 高考真题库建立后回填精确题号）**：

  - 2024·东北三省：乙酸甲酯自催化水解、NaOH 用量（答案 C）
  - 2024·山东卷：阿魏萜宁酯水解、官能团判断（答案 B）
  - 2024·甘肃卷：曲美托嗪官能团种类变化、非同系物（答案 A）
  - 2023·福建卷：CADD522 酰胺水解、4 个手性碳（答案 B）

## 四、易错点

> [!warning] 易错
> ① 羧基/酯基/酰胺基的 π 键**不能与 H₂ 加成**；② 酚酯水解 1 个酯基耗 2 份 NaOH（产物含酚羟基又耗 1 份）；③ 甲酸既有羧基又有醛基（可银镜、加 H₂）；④ 油脂是高级脂肪酸甘油酯（不是高级脂肪酸）；⑤ 矿物油是烃不是油脂；⑥ 皂化用盐析（加食盐），不是盐析去结晶水。

## 五、方法点拨（蓝字注释风格）

> [!tip] 酯水解断键"碳氧成羧基、单氧成羟基"
> 酯基 -COO- 水解：碳氧双键侧断 C-O，C 补 -OH 成羧酸，单键侧 O 得 H 成羟基（醇/酚）。标 ¹⁸O 追迹题从此原理出。

## 六、常见题型

- **类型Ⅰ 羧酸性质判断**：HCOOH 沸点排序、官能团计量（Na/NaOH/NaHCO₃ 各几 mol）
- **类型Ⅱ 酯化与水解机理**：断键位置、¹⁸O 追迹、醇交换
- **类型Ⅲ 乙酸乙酯制备实验**：混合顺序、饱和 Na₂CO₃ 三重作用、导管防倒吸
- **类型Ⅳ 银镜+水解双判**：C₃H₆O₂ 四种同分异构鉴别
- **类型Ⅴ 油脂与皂化**：地沟油 vs 矿物油鉴别（加 NaOH 共热不分层为地沟油）
- **类型Ⅵ 胺与酰胺水解**：酸水解无氨气、碱水解放氨气
