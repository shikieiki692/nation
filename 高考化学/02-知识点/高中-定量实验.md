# 高中-定量实验

> [!tip] 核心方法
> 定量实验 = **称量/量取精度 + 误差分析 + 关系式法计算**。一条主线：先样品处理（溶解/定容/稀释）→ 标准溶液标定 → 滴定/重量/量气法测含量 → 关系式换算。凡读数/精度/操作错位，全部落在误差方向上（偏大/偏小/无影响）。

## 一、核心概念（是什么）

### 1. 定量仪器规格与精度

| 仪器 | 规格选择 | 精度 | 误差方向口径 |
|---|---|---|---|
| 容量瓶 | 只能一次定容，配 500 mL 就选 500 mL | 0.01 mL（量入式） | 不加热不溶解 |
| 滴定管 | 酸式（玻璃）装酸性/氧化性；碱式（橡胶）装碱性 | 0.01 mL（量出式） | 0 刻度在上 |
| 量筒 | 选规格等于或略大于量取体积 | 0.1 mL（量出式） | 无 0 刻度 |
| 托盘天平 | 只能称到 0.1 g | 0.1 g | 左物右码 |

- **配制一定物质的量浓度**：计算→称量→溶解→冷却→转移（玻璃棒引流）→洗涤（2~3 次）→定容（胶头滴管）→摇匀→装瓶贴签。
- **误差口诀**：**俯视定容偏大、仰视定容偏小**（俯视：液面未到刻度就读，加水少，浓度大）；向烧杯转移时溶液未冷却→体积膨胀→定容时加水多→偏小；洗涤液不转移→溶质少→偏小。

### 2. 定量分析四法

- **中和滴定**：酸碱中和→终点变色 30 s 不褪。选指示剂：强酸滴强碱用甲基橙/酚酞均可，强碱滴强酸酚酞半滴误差。
- **氧化还原滴定**：KMnO₄ 自身作指示剂（紫红→无色/微红 30 s）；I₂ 用淀粉（蓝→无色，注意 Na₂S₂O₃ 标定碘）。KMnO₄ 用酸式滴定管（氧化橡胶）。
- **沉淀滴定**：银量法（AgNO₃ 标液滴定 Cl⁻，铬酸钾指示剂砖红终点）。
- **重量分析**：沉淀→过滤→洗涤→干燥→称量（恒重法）。含结晶水 x 的计算：
  - **胆矾 CuSO₄·xH₂O 公式：x = 80(m₂−m₃) / 9(m₃−m₁)**（2021·全国甲），m₁ 坩埚/m₂ 坩埚+样品/m₃ 坩埚+无水。
- **量气法（排水量气）**：读体积前**回温、恢复室温、调节液面齐平**（内外液面一致），防 CO₂ 可溶误差偏小。
- **元素分析**：有机物 C/H 燃烧法 → CO₂/H₂O 质量 → 最简式；配合质谱定分子式（2023·全国乙卷 C₄H₆O₄）。

### 3. 关系式法计算

- 滴定中的换算：如铁矿石 ω(Fe) = **33.6 cV / a %**（2024·安徽：Fe²⁺ 被 K₂Cr₂O₇ 或 KMnO₄ 滴定，根据电子守恒建立 n 关系式）。
- 钢中硫含量 = **0.192V/a**（2024·山东：SO₂ 吸收→滴定）。核心：**电子守恒/原子守恒先写关系式**。

## 二、关键规律

- 滴定操作：查漏→润洗（标液/待测液各润洗对应管）→注液排气泡→调零→滴定→终点（颜色变化 30 s）→读数两次取平均。
- **锥形瓶不润洗**（有水不影响溶质）；滴定管必须润洗（否则残留水稀释标液→消耗多→结果偏大）。
- 终点后 30 s 不褪色才可读数；半分钟后褪色是假终点。

## 三、高考考查方式

- 题型：配制操作正误、滴定误差分析方向、关系式计算、重量法结晶水公式。
- **真题分布（出处可追溯，待回填）**：
  - 2023·全国乙卷：有机物元素分析确定最简式 C₄H₆O₄
  - 2021·全国甲卷：胆矾 x = 80(m₂−m₃)/9(m₃−m₁)
  - 2024·安徽卷：铁矿石 ω(Fe) = 33.6cV/a%
  - 2024·山东卷：钢中硫 0.192V/a
  - 2022·重庆卷：红磷定量滴定（关系式）

## 四、易错点

> [!warning] 易错
> ① 滴定管 0 刻度在上而量筒无 0 刻度；② 锥形瓶不需润洗、滴定管必须润洗；③ KMnO₄ 用酸式滴定管（氧化橡胶）；④ 排水量气不"回温复压"读数偏大；⑤ 结晶水公式 m₁/m₂/m₃ 张冠李戴；⑥ 俯视/仰视定容误差方向记反（俯视读数偏大、实际浓度偏大？其实定容俯视 → 加水少 → 偏大，注意与"滴定俯视读数偏小"区分）；⑦ 称量 NaOH 必须放小烧杯/表面皿（吸湿腐蚀托盘）。

## 五、方法点拨

> [!tip] 误差分析三段法
> ① 该操作影响的是「溶质的量」还是「溶液的体积」；② 溶质多了/少了 → 浓度偏大/偏小；③ 体积多了/少了（定容）→ 反向调。滴定型误差同理换成「消耗标液体积」。

## 六、常见题型

- **类型Ⅰ 配制一定浓度溶液**：仪器选择+操作正误
- **类型Ⅱ 中和滴定**：指示剂/仪器/误差分析
- **类型Ⅲ 氧化还原滴定**：标定/自身指示剂/关系式
- **类型Ⅳ 重量分析**：恒重法/结晶水计算
- **类型Ⅴ 量气法**：回温复压读数/体积差换算
