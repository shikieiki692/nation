# 高中-化学计量与阿伏加德罗定律

> [!tip] 核心方法
> 化学计量用"摩尔尺子"量物质。三件套：**①单位先行**（mol/L、22.4 L/mol 有严格条件）；**②守恒优先**（电子/原子/电荷守恒解定量最省力）；**③差量/关系式免列方程**。所有计算先定"基准物质"，再列比例。

## 一、核心概念（是什么）

### 1. 基本量关系

- n = N/Nₐ = m/M = V/Vₘ = c·V。
- **Vₘ 的两个值**：标准状况（0℃、101 kPa）**22.4 L/mol**；常温常压（25℃、101 kPa）**24.5 L/mol**。22.4 L/mol 只对气体且必须标况；标况下水、HF、SO₃ 等非气体不可用。
- Nₐ ≈ 6.02×10²³ mol⁻¹，"微粒"需指明种类（分子/原子/离子/电子）。

### 2. pV=nRT 五推论

| 恒量 | 推论 |
|---|---|
| T、p 同 | V₁/V₂ = n₁/n₂（体积比=物质的量比） |
| T、V 同 | p₁/p₂ = n₁/n₂（压强比=物质的量比） |
| T、p 同 | ρ₁/ρ₂ = M₁/M₂（密度比=摩尔质量比） |
| T、V 同 | p 与 n 正比（恒温恒容充气） |
| 恒 T、p | 平均摩尔质量 M̄ = ρRT/p |

### 3. 平均摩尔质量 M̄

- M̄ = m总/n总 = M₁x₁ + M₂x₂（x 为物质的量分数）；标况下 M̄ = ρ·Vₘ。
- 应用：同位素平均相对原子质量（Cl 35.5）、混合气体判断、十字交叉反推配比。

### 4. 物质的量浓度

- c = 1000ρω/M（ρ 单位 g/mL，ω 质量分数，M 摩尔质量）。
- **溶质微粒浓度**：c(离子) = c(溶质)·组成比·单位电荷（如 0.1 mol/L MgCl₂ → c(Cl⁻)=0.2 mol/L）。
- 稀释：c₁V₁ = c₂V₂。

## 二、关键规律（转化率/产率/纯度 + 设 1 法）

- 转化率 = 已转化量/起始量×100%；产率 = 实际产量/理论产量×100%；纯度 = 目标物质质量/样品总质量×100%。
- 链式多步反应用**关系式法**串联中间产物，避免步步细算。
- 无具体量时**设 1 mol / 100 g**，把百分数当质量直接除 M——求最简式/相对分子质量/质量分数最省力。
- 结果保留按题给精确度；恒重法（灼烧）题注意两次称量恒定判据。

## 三、高考考查方式

- 题型：单位换算、平均摩尔质量、c=1000ρω/M 应用、转化率/产率、混合气体判断。
- **真题分布（出处可追溯，待回填精确题号）**：
  - 2024·浙江1月选考：例5 灼烧恒重法测 H₂S 产品纯度（99.0%）
  - 2022·重庆卷：例10 Hess 循环 ΔH（与盖斯定律衔接，答案 C +838 kJ·mol⁻¹，考点属第9章，本讲引用作关系式/摩尔质量素材）
  - 2023·重庆卷：例11 KMnO₄ 滴定法测 CaCl₂ 质量分数（66.6%，关系式法衔接第13章定量实验）
  - 2024·上海卷节选：例12 石灰乳+Na₂CO₃ 除杂用量计算（0.04、0.14）

## 四、易错点

> [!warning] 易错
> ① 22.4 L/mol 必须标况+气体双条件；② 常温常压 Vₘ 是 24.5 L/mol 不是 22.4；③ c=1000ρω/M 中 ρ 必须换算成 g/mL；④ 溶质微粒浓度要乘组成比（1 mol/L CaCl₂ 的 Cl⁻ 是 2 mol/L）；⑤ 十字交叉得到的是物质的量比不是质量比；⑥ 转化率≠产率≠纯度，三率互不替代。

## 五、方法点拨

> [!tip] 计算题"基准物质"三步
> ① 找"哪里给了具体量"（质量/体积/物质的量），把它定为基准；② 用关系式或守恒把目标量换算到基准；③ 列比例求解。凡"混合"先求 M̄ 用十字交叉。

## 六、常见题型

- **类型Ⅰ 基本量换算**：n/m/V/N 互推
- **类型Ⅱ 阿伏加德罗定律推论**：同温同压体积比
- **类型Ⅲ 平均摩尔质量**：混合气/同位素
- **类型Ⅳ 溶液浓度计算**：c=1000ρω/M 与稀释
- **类型Ⅴ 三率计算**：转化率/产率/纯度链式题
