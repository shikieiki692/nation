# 题型-氧化还原反应

## 一、题型定位

- 选择 1 题（概念/强弱/电子转移）+ 大题渗透（方程式配平、新情景书写、滴定计算），全卷覆盖。
- 难度★★★~★★★★，工具性最强题型。

## 二、考查内容

- 概念辨析（氧化剂/还原剂/产物判断）；氧化性强弱比较；电子转移计算（双线桥）。
- 方程式配平（缺项配平）；新情景陌生方程式书写（信息迁移）。
- 氧化还原滴定计算（n 守恒）。

## 三、解题框架

1. 概念题：标化合价 → 定升降 → 找对应
2. 强弱题：优先「强强反应生成弱弱」
3. 配平/书写：升价元素归线 → 得失守恒 → 电荷守恒 → 缺项补 H₂O/H⁺/OH⁻
4. 计算：电子守恒列等式
