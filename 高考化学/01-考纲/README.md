# 01-考纲 · 高考考纲

> **用途**：新课标（2017/2020 修订）高考化学考纲条目 + 高考题型清单。
> **状态**：待 P1 建设。现状竞赛考纲在 `02-考纲条目/`（CChO），本目录与之完全独立。

## 规划条目（按 5 本书 + 题型）

- 必修第一册：物质及其变化 / 海水中的重要元素——钠和氯 / 铁 金属材料 / 物质结构 元素周期律
- 必修第二册：化工生产中的重要非金属元素 / 化学反应与能量 / 有机化合物 / 化学与可持续发展
- 选必一 化学反应原理：反应热 / 速率与平衡 / 水溶液中的离子反应与平衡 / 电化学
- 选必二 物质结构与性质：原子结构 / 分子结构 / 晶体结构
- 选必三 有机化学基础：有机化合物组成结构 / 烃 / 烃的衍生物 / 生物大分子与合成高分子
- 高考题型：工艺流程 / 实验综合 / 化学计算（阿伏加德罗常数/化学用语）/ 化学与生活
