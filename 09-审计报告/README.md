# 09-审计报告·总览

> 全库体检、评估、诊断类**留痕产物**的存放处（约 370 条）。此目录是**只写归档**，不是工作区。

## 命名规范

```
2026-MM-DD-<主题>.md
```
日期一律用**实际产出日**，不是归档日。

## 子目录

| 目录 | 内容 |
|---|---|
| `auto-validation/` | `validate_kb.py` 等脚本的自动产出（每次全库跑覆盖同一份） |
| `归档/`、`归档首页/`、`会话交接归档/`、`_归档-历史快照/` | 历史留痕，**内容互不重叠**，勿合并 |
| `备份/` | `backup_media.py --zip` 的媒体仓库字节级备份 |

## 怎么看

1. **先看日期**，再按主题文件名定位。
2. `.csv` / `.jsonl` 多为**工作表**（人工核验用），不是结论。
3. 结论型报告以 `.md` 为主。

## 🚫 注意

- ⛔ **勿把本目录当待清理垃圾**——它是审计留痕，删掉等于丢失判断依据。
- ⛔ 报告中的**数字会过期**。当现状必须重跑命令，别照抄（详见[[2026-10-02-全库结构体检第二轮（结构向）]]的「两次自我纠错」）。
