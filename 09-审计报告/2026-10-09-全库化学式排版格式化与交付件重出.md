## 二、规则集（`volpost --fmt`，均列入 `ALWAYS`）

| 规则 | 作用 | 例 |
|:--|:--|:--|
| `fspace` | 去字母/数字与 `$` 之间的空格 | `CrF $_{6}$` → `CrF$_{6}$` |
| 🔴 `fbase` | **docx 空基底**⇒并入数学式基底 | `CrF$_{6}$` → `$\mathrm{CrF}_{6}$` |
| `fbase2` | 数字／右括号基底 | `10$^{-4}$` → `$10^{-4}$` |
| `fempty` | 块内空组上标/下标归位 | `X{}^{+}` → `X^{+}` |

- 🔴 `fbase` **空基底**根因：`CrF$_{6}$` 在 docx 生成 `<m:sSub><m:e></m:e>`（基底空）⇒ 渲染出**占位空隙**，**仅去空格不能解决**。
- 🛡 **`fbase` 守卫 `_ALKYL_PREFIX`**：`KO $^{t}$Bu` 的 `t` 属 `Bu`，后跟拉丁字母则**不并**（防误合并）。
- 🛡 **`fbase2` 字符类须含 `A-Za-z`**：否则 `10$^{-4}$` 被拆成 `1$0^{-4}$`（首轮实错，已修）。
- 🛡 **`fempty` 带基底锚**：同位素记法 `${}^{10}Be$` 左侧是 `$`（数学起始）⇒ 锚不匹配 ⇒ 天然不误伤。
- 判据工具：`build_volX_zhenti.py` 输出字段 **`空基=`** 必须为 0。

## 四、安全性

1. **语义不变**：每条规则断言「可见字符指纹不变」（`fspace/fbase/fbase2/fempty` 只动 `$ { } \mathrm` 与空白）⇒ 不改变文字内容。
2. **幂等**：全部文件复跑规则输出不变（dry-run 0）。
3. **备份**：写盘前逐文件备份（`volmd_bak_formula/`、`card_bak_globalfmt/`）。
4. **不影响池**：`vol_poolchk` 7 卷全部 **掉池 0**（真实池 1895＝元素与分析 317／结构化学 733／化学原理 845）。
5. **渲染闸门**：`render_gate --regression` 全量 786 份 ⇒ **24 份报「oMath 倒退」**。
   逐份核查＝**均只有 oMath 计数下降，无字面 `$` 增加、无转换失败**；`--changed` full 模式 **24/24 PASS**。
   根因＝**讲义管线把 `X$_{a}^{b}$` 折叠为 Unicode 下标**（`build-all-handout-docx.py` 的「simple script payloads → unicode」规则）：
   `fspace` 去掉「字母与 `$` 间空格」后，原本带空格的空基底数学块（不折叠）变成可折叠形态 ⇒ oMath 计数下降。
   ⇒ 判为**启发式误报**，按本库惯例登记 `11-模板/scripts/render_gate_allowlist.txt`（24 条，含逐份计数与理由）。
   ⚠️ 交付件侧无此问题：交付 docx 由 `build_volX_zhenti.py` 产出，X 卷实测 **空基底 0**、oMath 518。
