## 三、修法（已执行）

| 类型 | 修法 | 风险 |
|---|---|---|
| D 图紧贴 | `]]![[` / `]] ![[` → `]]\n\n![[`（各图独立成段） | 低：纯插空行，路径不动 |
| H 行尾孤立 `#` | 删行尾孤立 `#`（H1 标题行尾 / H2 图引用行尾） | 低：仅删 3 个 `#` |

**统一约束**（已全部满足）：
1. 图片语法 `![[…]]` **内部绝不可插换行**；
2. 修复后须验「图片引用数守恒」「题目总数不变」；
3. 涉及红区 → **已获用户显式授权**；
4. 改后已重跑全消费端（套卷/习题书/讲义）并过双闸门。

### ⛔ 明确**不做**的改动（反例，勿再试）

| 反例 | 原因 |
|---|---|
| 拆「文字/选项标签 + 图」同行 | **图文混排是主流写法**（39届 7 文件实测：混排 54 行 vs 纯图 10 行）；选项标签 `A![[图]]` 有意与图同行，拆行会撕碎选项排版（v1/v2 两次踩坑） |
| 拆 `# 题-086：![[图]]` 这类标题行 | 同上；`题-086` 属「无适用修复」文件，脚本已 `SKIP` |
| `A 标题行含图` 313 处 | 经复核属正常写法，**不属缺陷**，保留原样 |

## 三·附、断言方法（九轮教训固化）

⚠️ **存在多个「必然假 FAIL」的诱人断言**，务必避开：

| ❌ 错误断言 | 为何假 FAIL |
|---|---|
| 全局去空白后比字符串 | 会把「A行尾 + B行首」粘成假差异（`]]#` + `## 4.2.4` → `]]###4.2.4`） |
| 非纯图行逐行比较 | 拆行必然改变行数/行内容 → 无解 |
| `norm()` 把 FM 分隔行 `---` 当内容 | FM 误判差异 → 必须**剔除 FM** 或逐字节比 FM |

✅ **正确不变量 `canon()`**：
```python
canon = lambda t: WS.sub("", IMG.sub("<IMG>", t))   # 图→<IMG> 折叠，再删全部空白
```
因变换只「插空白 / 删 3 个 `#`」，故 `canon(新) == canon(按声明删 # 后的旧)` 必然成立。

✅ **终极独立核验（字符多重集 Counter）**：
```
Counter(NEW去空白) == Counter(OLD去空白) - {'#': 3}   且 NEW 不得多出任何字符
```
实测：第一批 `OLD-NEW == {'#': 3}`、`NEW-OLD == {}`；第二批 `OLD-NEW == NEW-OLD == {}`（纯插空行）。
