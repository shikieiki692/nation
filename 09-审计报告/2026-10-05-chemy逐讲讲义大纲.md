### 3. 讲义要点与思路方法

- **密度公式三向互推（必背）**：ρ = Z·M/(N_A·V)。三个变量（ρ、M、V 或 ρ、Z、a）中给两个求第三个；单位换算是最大失分点：a 用 pm ⇒ V 用 pm³ ⇒ 1 pm³ = 10⁻³⁰ cm³。
- **Z 值三步法**：① 列出所有不等价位置及其晶胞内计数权重；② 求和得晶胞内原子总数；③ 除以化学式中的原子数 ⇒ Z。**只数「一套等效点系」**，题目常提示「所有 X 原子只有一套等效点系」。
- **键长计算含根号**：正交晶系 d = √[(Δx·a)² + (Δy·b)² + (Δz·c)²]；非正交须先算夹角余弦。对称等价位置（±x, ±y, ±z）的最短距离要**逐对核验**，不能只算一组。
- **衍射消光判点阵**：面心立方：h,k,l 全奇或全偶；体心立方：h+k+l 全奇；简单立方：无条件。题目给衍射峰条件即问点阵，这是最快的反推路径。
- **相变题的结构对比**：同物质两种晶型（如结构 I 面心立方 vs 结构 II 体心四方）⇒ 问「I 与 II 的密度比」时用 Z 与 V 分别算即可，不必重建结构。

### 3. 讲义要点与思路方法

- **「画箭头」三步法**：① 从题给试剂判断电子从哪里来（亲核/亲电/自由基）；② 断键时成键与断键必须**同时发生在相邻原子**；③ 每一步只断一根 σ 键或只形成一根 π 键。绝大多数「机理题」的失分都源于第二步违反。
- **竞争路径判据表**：把 E1/E2/SN1/SN2 排成一张表：底物级数（伯/仲/叔）、溶剂极性、碱强度、温度、产物件数。学生不必记表，只需会**查表的三条轴**。
- **中间体稳定性标尺**：苄位/烯丙位 > 叔 > 仲 > 伯 > 甲基；给电子基（烷氧基、硅）稳定碳正离子。重排题的核心就是「先生成最稳正离子，再看有没有更稳的迁移去向」。
- **周环反应的热/光对照**：热反应走基态（4n+2 对旋、4n 顺旋）；光激发走第一激发态，规则**恰好互换**。本库 99 张题考 49 号码（周环），是全库最热的选择性考点之一。

| 方法点 | 讲法与题目里的典型套路 |
|:--|:--|
| Curtin–Hammett 原理 | 两个快速互变中间体（能量差 < 8~10 kJ/mol）时，产物比由**过渡态之差**决定，而非中间体丰度。题目常给 k₁:k₂ 直接求主产物。 |
| 端基效应／异头碳效应 | α-氟羰基、异头基上的吸电子基改变 n(O)→σ*(C–X) 超共轭的平衡，从而锁定优势构象；糖苷键水解速率的差异即源于此。 |
| 邻基参与（NPG） | 邻位带孤对/π 的基团先成环再开环 ⇒ **构型保持**且速率反常加快。用来解释「为什么这个底物比同型快得多且构型没变」。 |
| Bent 规则 | Lewis 酸加合物中键角偏离 120°/109.5° 的方向，可反推杂化态与电负性差异；题目给键角数据反推结构即用此。 |
| 非对映选择性模型 | Evans/Felkin–Anh/Cram 模型：由既有辅基（adjacent stereocenter）的构型，预测新手性中心的构型。 |

### 3. 讲义要点与思路方法

- **特征反应反向索引**：把「现象 → 元素/离子」做成闭式表（黄色焰色⇒Na；与水放出刺鼻气体⇒NH₄⁺；蓝色沉淀且不溶于氨⇒Cu²⁺；KSCN 变红⇒Fe³⁺）。考试时**先查表再推**。
- **氧化态阶梯法**：把元素排成「最低—中间—最高」价态阶梯 → 判断歧化（中间价）与逆歧化（相邻价）的方向；与 Latimer/Pourbaix 图配合使用。
- **方程式书写三查**：① 介质（酸/碱）② 守恒（原子 + 电荷 + 电子）③ 有无副产物（气体/沉淀/水）。化英社/chemy 的方程题几乎都设「介质判断」陷阱。
- **非整比与混合价态的处理**：遇「缺陷」「氧空位」「混合价」先写通式（A₁₋ₓBO₃₋ᵧ），再由电荷守恒解 x、y，而不是先猜具体化合物。

### 3. 讲义要点与思路方法

- **三步判磁法**：① 由题干定 d 电子数（金属价态）；② 由配体强弱＋金属周期第几行判 Δ 相对大小；③ 与配体场强比较得高/低自旋，算 n 与 μ。**先写 d 电子数再动笔算磁矩**，可避免绝大多数算错。
- **光谱化学序列**：I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < NO₃⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < py < NH₃ < en < NO₂⁻ < CN⁻ < CO。题目给「某配合物是低自旋」即可反推配体位置。
- **Jahn–Teller 判据**：电子组态为 egⁿ（n=1,2）或 t₂g 的不均匀占据 ⇒ 发生 Jahn–Teller 畸变（八面体沿一键轴伸缩）。用于解释「为什么该配合物是四方而非正八面」。
- **稳定常数的条件修正**：K′ = K / (α_M α_L)。副反应系数 α 直接来自「其他配体/沉淀/酸效应」——这是「同一 K 在不同条件下结果不同」的唯一解释框架。

### 3. 讲义要点与思路方法

- **Nernst 三件套**：① 电极电势只与「电极中还原态/氧化态的活度比」有关；② 纯固体、纯液体的活度取 1；③ 配平时**电子数必须与电极电势对应**（同一反应全过程中 n 不变）。
- **多重平衡加减法**：把目标反应的 ΔG° 或 lnK 表示为若干已知反应的线性组合 ⇒ 直接加减 lnK。比“先写方程再算”快得多，也少错。
- **分布分数（分布系数）**：多元酸/多元配位/多相平衡统一用分布分数处理：各物种浓度 = 分布分数 × 总浓度。**先算分布分数，再套总浓度**，比逐个列方程稳。
- **级数判别三法**：① 变初浓度法（观察速率倍数）；② 作图法（log r 对 log c 的斜率）；③ 半衰期公式（t½ 与 c⁰ⁿ 相关性）。
- **Clapeyron 形式选择**：固液/气液相变用 ΔH 与 ΔV；气液两相理想近似下 Dq·(1/T₂−1/T₁) = −R/ΔH·ln(p₂/p₁)。注意符号与 ΔH 的符号一致。

### 3. 讲义要点与思路方法

- **逆合成三问**：每一步问：① 目标分子的哪个键**最容易断开**且断开后两片都是已知物？② 是否是**命名反应**的产物？③ 是否存在**立体选择性风险**（新中心）？三问顺序固定，就能把「想不到路线」变成「逐项排查」。

### 3. 讲义要点与思路方法

- **NMR 三步读图法**：① 数信号 → 等于化学环境数（先判对称性）；② 数积分 → 每组 H 数；③ 看裂分 → n+1 规则定相邻碳上 H 数。**先数信号可解决 80% 的定构题**。
- **对称性先于读数**：判分子对称面/轴（同分异构存在）→ 高等价 H 合并 → 信号数少于积分数。题里常给「某谱图含 5 个信号」反推结构。
- **同位素峰一眼定卤素**：出现 M/M+2 ≈ 3:1 ⇒ 含一个 Cl；≈ 1:1 ⇒ 含一个 Br；M+4 约 1:3:1 ⇒ 含 2 个 Cl 或 Cl+Br。
- **IR 判羰基的对称性敏感**：对称/反对称伸缩 ⇒ 环大小与构型的信息；羰基峰数与配位数、聚合物链结构相关（题-CM-15-05 用 CaCl₂ 推断吸收峰数即此）。
