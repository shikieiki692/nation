## 三、核心结论

### ✅ 大量"缺口"实为名称变体，已被现有 KP 覆盖

抽样验证的高频目标几乎全部有近义 KP：

| REDLINK | 实际覆盖 KP |
|:---|:---|
| 推断技术 | 元素推断、化学式推断 |
| 偶合常数 | NMR谱学、¹H NMR、动态NMR |
| C-C键形成 | 偶联反应、Negishi/Stille/Suzuki偶联 |
| 气液平衡 / 三相点 / 组分数 | 相图与相平衡、相律与相图 |
| IR光谱 | 红外光谱、分子光谱 |
| 玻尔模型 | Bohr模型计算 |
| 姜泰勒效应 | Jahn-Teller效应 |
| 配平 | 氧化还原反应方程式配平 + 题型页 |
| 轨道对称性 | 分子对称性初步、对称性与配位构型 |
| 等瓣类似 | 等瓣相似 |
| 真实气体 | van der Waals方程、范德华力 |
| 结构鉴定 | 异构与结构表征、有机波谱分析 |

**结论**：引用源用了不同名称（常见于题库题目、提炼页、模板），但内容已存在。

### ⚠️ 真缺口 ~525 个，但多数不值得建 KP

真缺口集中在两类：
- **具体化合物/物质名**（阿司匹林、草酸钙、1,3-丁二烯、氮气、醋酸等）：竞赛题中作为载体出现，一般不构成独立知识点
- **方法/题型类**（多步合成、机理辨析、碱的选择、单位换算等）：属解题策略，应由题型页/专题页承载，而非 KP

### 🟢 值得评估建 KP 的少量候选

以下为跨来源高频引用、且真无近义 KP 的候选（**仅建议级，需用户确认**）：
- 波粒二象性
- 德拜-休克尔理论
- n+1规则 / 磁等价 / 化学等价（NMR 基础概念）
- 不饱和度公式
- 单线态氧
- 波谱联合解析

## 四、建议（不盲目建 KP）

1. **优先补别名，而非建新 KP**：对高频 REDLINK，在现有近义 KP 的 `aliases` 中补上 REDLINK 名称 → 断链即自动消除（validate 按 title/aliases 解析）
2. **题型/方法类目标**：挂到题型页或专题页，不建 KP
3. **具体物质类**：保留为纯文本引用，不建 KP
4. **少量高价值候选**：列清单供用户决策是否建 KP（约 8-10 个）
