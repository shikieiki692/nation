## 一、扫描口径（重要，勿重蹈覆辙）

**扫描范围**：全库 `.md` 中形如 `[[04-课件/学生讲义/...]]` 的**路径链**。

**必须排除的噪声**（否则数字虚高数十倍）：

| 噪声类型 | 示例（以反引号书写，避免自造红链） | 说明 |
|:---|:---|:---|
| 短链（标签式） | `[[氧化还原]]`、`[[杂化轨道]]` | 全库 basename 匹配；不匹配即「未创建页面」，非断链 |
| 占位符 | `[[04-课件/学生讲义/<讲义文件名>]]` | 模板中的人造占位，非真实链接 |
| 正则元字符 | `[[source]]`、`[[wikilink]]` | 文档中作为**示例文本**出现 |

> **教训**：[[2026-09-12-剩余三条遗留线评估]] 已记录 —— 校验 Obsidian 链接必须区分短链「`[[名]]`」（全库匹配）与路径链「`[[路径/名]]`」（精确匹配）。对短链做路径拼接校验会大量误报。

## 五、执行约定

1. **禁止 `git add -A` / `git add .` / `git commit -a`**；逐文件白名单 add。
2. 改前先跑本清单的扫描脚本，**确认目标物理存在**再改（防再次「改一半」）。
3. 改后复扫，要求：本层断链 = 0，且**新增断链 = 0**。
4. 涉及 `_归档` 路径的修改，须在 commit message 注明「指向归档区的链接修复」。
5. B 桶须先解决归口问题再动手。
