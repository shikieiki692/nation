## 一、★ 最大发现：git 临时索引堆积 1.00 GB

`.workbuddy/tmp/` 下有 70 个 `index_*` 文件，每个 **16.7 MB**，合计 **1.00 GB**。

**定性依据**：文件魔数为 `DIRC`——这是 git 索引文件（`.git/index`）的标准格式。

**成因**：项目铁律要求每次 commit 用隔离索引避免与并行会话撞车：

```
export GIT_INDEX_FILE=.workbuddy/tmp/index_*.$$
git read-tree HEAD
```

用完**从不清理**，于是每个会话留一个 16.7 MB 的全库索引副本。

**安全性核验**（执行前已确认）：
- 真实 `.git/index` 独立存在（18.4 MB），不受影响
- 无 `.git/index.lock`，无 MERGE_HEAD / rebase 进行中
- 最新的 `index_*` 也是 9 小时前写入

**处置**：按决议删除 3 天前的。清理后剩余 **7 个 / 0.12 GB**。

> ⚠️ 数字更正：选项里我写「67 个」是按「1–7 天档」估算的，实际 **>3 天的只有 14 个**（其余 56 个是 1–3 天内，且部分在执行期间被其他会话清掉）。已删除 14 个，约 234 MB。
