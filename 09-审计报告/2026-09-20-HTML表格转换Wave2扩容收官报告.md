## 一、本轮三项优化

### ① colspan 支持（原先一律拒绝，过保守）

**策略**：跨列单元格内容放**首列**、后续 N-1 列留空（左对齐展开）。

**对照实验**（左对齐 vs 居中）：左对齐明显更优——组标题落在组首列，视觉位置与原排版一致。

| 样例 | 效果 |
|:---|:---|
| clayden 溶剂表（`colspan=2` × 3 组） | 三组标题「质子极性溶剂/非质子极性溶剂/非极性溶剂」完美还原 |
| 中级无机化学 `$M_L$ $M_S$` 矩阵 | `colspan=4` 空行正确变空行（视觉分隔） |
| 人教版 `电负性,键长,键能数据`（`colspan=6`） | 全宽标题首列 + 余空 |

**仍拒绝 `rowspan`**（391 表）：Markdown 无纵向合并，不可保真。

全库可转数 **588 → 662**（+74）。

### ② 新增判据 halfwrap（半包检测）

逐单元格检查 `$` 配对，奇数即「半包」（如 `\( X_2 + 2NaOH = ...$`，OCR 常见）。
**理由**：转成 pipe table 后会打乱后续单元格的 `$` 配对。
本批命中 1 处（一化必刷100讲上册卤素表）。

### ③ ⭐ 修正四口径「行数守恒」公式缺陷

原公式只减「单行表数」→ **多行 HTML 表被算漏**：

```python
# ❌ 错：单行表数 = sum(1 for it in good if "\n" not in it["original"])
# ✅ 对：old_lines = sum(it["original"].count("\n") + 1 for it in good)
expect = orig_lines - old_lines + gen_lines
```

实测：`3-晶体结构.md` 一处 7 行原表被误算 → 报 14906 vs 期望 14914。
**这是计算公式错，不是文件坏** —— 修正后全部通过。
