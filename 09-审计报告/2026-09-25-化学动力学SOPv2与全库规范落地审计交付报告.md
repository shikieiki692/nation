## 二、 全库规范落实：6 大核心规则文件修改明细

为了确保后续对话、其他 Agent 能够无缝继承并严格执行本轮标准，已对知识库内 6 个最高权威规范与排版管线文件进行了实盘固化：

1. **`AGENTS.md`（根目录，所有 Agent 系统级前置注入规则）**
   - **修改位置**：文件头补充标准 Frontmatter；在 `## Word 讲义写作入口` 新增 3 项硬约束：

## 三、 四大机检闸门复核验证命令（可直接运行复测）

可以在终端运行以下命令，验证交付物是否 100% 达标：

### 1. 静态元数据与格式一致性检查（Gate 1）
```powershell
python -X utf8 11-模板/scripts/validate_kb.py --changed "AGENTS.md" "04-课件/学生讲义/3-物理化学/化学动力学-超级充实版（自学完整）.md" "04-课件/学生讲义/学生专用版/3-物理化学/化学动力学-超级充实版（学生专用版）.md"
```
**预期输出**：`✅ 受检: 3 文件 | 🔴 Error: 0 | 🟡 Warning: 0`

### 2. 数学公式渲染断言（Gate 2）
```powershell
python -X utf8 11-模板/scripts/render_gate.py --changed "04-课件/学生讲义/3-物理化学/化学动力学-超级充实版（自学完整）.md" "04-课件/学生讲义/学生专用版/3-物理化学/化学动力学-超级充实版（学生专用版）.md"
```
**预期输出**：
- 自学版：1618 oMath，✅
- 学生版：975 oMath，✅
- `RENDER_GATE=PASS`

### 3. Word 文档重新编译（Gate 3）
```powershell
python -X utf8 11-模板/scripts/build-all-handout-docx.py --file "化学动力学-超级充实版（自学完整）"
python -X utf8 11-模板/scripts/build-all-handout-docx.py --file "化学动力学-超级充实版（学生专用版）"
```
**预期输出**：`Done. 1 converted, 0 errors.`

### 4. Word 排版细节断言（Gate 4：三线表 + 首行缩进 21pt）
```powershell
python -X utf8 -c "
import docx
doc = docx.Document('06-学生侧材料/讲义/3-物理化学/化学动力学-超级充实版（自学完整）.docx')
indented = sum(1 for p in doc.paragraphs if p.paragraph_format.first_line_indent and p.paragraph_format.first_line_indent.pt > 20)
print('总段落数:', len(doc.paragraphs))
print('首行缩进 2 字符 (21pt) 段落数:', indented)
print('三线表格数:', len(doc.tables))
assert indented >= 340, '首行缩进段落数未达预期'
assert len(doc.tables) == 7, '表格数未达预期'
print('✅ 排版断言 100% 通过！')
"
```
