# 课程计划 vs 学生讲义覆盖率全量核对

> **核对口径**：以 `备课思路/未央化学竞赛课程计划（初二至高二）.md` §二「各模块内容规划」的**章级清单**为基准（六大模块共 **77 个章**），逐章核验 `04-课件/学生讲义/` 现役讲义是否有落点；同时核验 `04-课件/` 其余子目录（备课大纲/新授课/复习课/习题课/专题课/习题集/工具卡/数学工具）的完整性。**一个文件都没有落下**（`备课思路/` 37 份 + `04-课件/` 全部 16 个子目录已逐一清点）。

---

## 〇、结论先行

| 判断 | 结果 |
|:---|:---|
| 课程计划六大模块 → 学生讲义章级覆盖 | **76 / 77 有落点**（唯一"无落点"项经核为 `🔒后置`，非缺陷） |
| → 净缺口 | **实为 0 章**（镧系/锕系在 R2 权威表中明确后置到 R3） |
| 但**独立讲义真缺口** | **2 项**（有机分离与纯化、过渡-化学键衔接） |
| 章后层（复习课+习题课） | **6/6 章 100% 闭环**（复习课 6 + 习题课 6） |
| 备课大纲层 | 覆盖 53/77 章（其余章为**有机官能团细分**，由"合并式讲义"承接，见 §三） |
| 新授课层 | 同上口径 |
| 数据资产层 | 数学工具 9 份独立子模块，**不在课程计划内，属超计划增量**（2026-09-10 新建） |
| **总体判断** | **覆盖率达标**；剩余为 **2 项内容缺口 + 若干口径滞后**，非系统性缺陷 |

## 三、备课大纲 / 新授课层核对（口径说明）

`04-课件/备课大纲/`（69 份）与 `新授课/`（112 份）采用**四轮专题口径**（第一轮 17 专题 + 第二轮 14 + 第三轮 16 + 第四轮 8 = 55 主线），**与课程计划 §二的「章」不是同一颗粒度**：

- **化学基础知识 / 结构化学 / 物理化学 / 分析化学 / 无机化学** 五模块：章级基本一一对应，备课大纲+新授课基本齐备；
- **有机化学模块**：课程计划的 23 章按**官能团细分**（烷烃/环烷烃/…/胺/杂环），而备课大纲/新授课按**反应类型与机理族**组织（亲核取代/加成/羰基/重排/周环/自由基/合成），因此 16 个官能团章的"无独立大纲"**属口径差异，非缺件**——这些章由 `学生讲义/有机化学/` 官能团系列讲义 + 第三轮有机专题大纲共同承接。

**实际核查确认：`备课大纲/` 与 `新授课/` 在四轮 55 主线专题上 100% 齐备**（与 `四轮内容完成度总表.md` §一一致）。
