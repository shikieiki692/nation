## 一 发现并修复：全库**唯一**一处 FM 解析失败（P1）

对全库 **16,115 个有 frontmatter 的 md** 做严格解析（ruamel YAML 1.2 safe ＋ 拒重复键，与 `jsyaml_verify.js` 同后端）：

| 结果 | 数 |
|:--|--:|
| 解析通过 | 16,114 |
| **解析失败（会 THROW）** | **1** |

**缺陷**：`09-审计报告/2026-10-07-换卡候选回源核验结论.md`

```yaml
title: "换卡候选回源核验结论（15 张 A 类"须换卡"）"   # ← 内层 " 未转义
```

⇒ js-yaml 会 **THROW ⇒ Obsidian 里该页 FM 失效**。

**修法**：外层改单引号（值内含双引号时最稳）——

```yaml
title: '换卡候选回源核验结论（15 张 A 类"须换卡"）'
```

**复验**：strict 解析通过，`title`/`type`/`tags` 取值正确 ✅

> 🔴 **判据**：FM 值**内嵌裸双引号**（外层已用双引号包裹）⇒ 必 THROW。全库仅此 1 处（同批扫「值含 ` #`」「裸 `: `」「保留字符开头」⇒ **均 0 真缺陷**，48 处「注释截断」实为**合法行尾注释**）。

## 二 `09-审计报告` 的 type 同义异写归一（30 文件）

该目录 type 分布原为：`审计报告` 242 ／ `审计` 25 ／ `audit` 3 —— **同一目录三种写法**。

**判据**：`审计`／`audit` 是 `审计报告` 的**简写/英文同义写法**（零争议）；无 type 的按内容补。

| `审计` → `审计报告` | 22 | `2026-09-17-周坤网课资料真缺图清单.md` 等 |
| `audit` → `审计报告` | 2 | `2026-09-13-线3剩余项可行性评估.md` 等 |

- **归档目录**（`_归档-历史快照/`、`归档/`、`会话交接归档/`）＝ **保真豁免**，共 15 个；

## 三 🆕 新增常驻体检器 `11-模板/scripts/metadata_audit.py`

这几轮反复手写「扫 type / 扫 role / 扫无 FM / 扫值隐患」的脚本 —— 已**固化为一支只读体检器**：

```
python 11-模板/scripts/metadata_audit.py                      # 全库摘要
python 11-模板/scripts/metadata_audit.py --scope 00-首页      # 限目录
python 11-模板/scripts/metadata_audit.py --report <输出.md>   # 落报告
```

**四维判据**（全部有出处）：
1. **FM 解析失败**（P1，退出码 1）—— ruamel YAML 1.2 strict；
2. **系统层 type 非规范** —— 规范＝`Frontmatter角色词表.md` §二（**仅限** `00-首页`／`02-数据库`／`10-索引与统计` 三个「整目录系统层」；`06-学生侧材料`／`备课思路` 是**混合目录**，内容型 type 属各域自有体系，不判）；
3. **系统页 role 缺失/漂移** —— 规范＝同文件 §三（**仅限 `00-首页`**，因为只有它有「系统页角色索引」消费方；其余目录常用**领域专属 role**，属合法）；
4. **FM 值内嵌裸引号** —— 会 THROW 的写法。

> ⚠️ **判据修正记录**：初版把 `06-学生侧材料`／`备课思路` 列入 SYS_SCOPE、并把 role 检查铺到全库 ⇒ 报出 **21 个「type 非规范」＋5 个「role 漂移」全是假阳性**（内容型 type／领域 role）。**已收窄**。这是本轮我自己的一处误判。
