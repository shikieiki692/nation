## 六、修复方案（已在 Mortimer 第 3 版验证）

```python
# 形态①：相邻数字间空格
P1 = re.compile(r'(?<![\d.])\d(?: \d){1,}')
# 形态②：小数点被空格包围
P2 = re.compile(r'(\d)\s*\.\s+(\d)')   # -> r'\1.\2'
```

**防误伤**（不动）：

- 块级公式内单字母序列 `n R T` / `b x` / `{r l}` —— 变量相乘与 array 列格式，渲染等价
- `\quad` / `\ ` / `&` 分隔的数字 —— 非纯空格分隔
- 单位与文字间的正常空格

**建议顺序**：①教材与提炼（被反复引用，收益最高）→ ②学生侧材料与课件 → ③题库/真题（红区，需专项排期 + 六步闸门复跑）
