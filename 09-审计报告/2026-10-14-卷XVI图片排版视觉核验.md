## 二、修复：图片放大（排版美观）

| 项 | 内容 |
|:--|:--|
| 根因 | 同 XVII：构建器 `CAP_ORG` 按朝向定尺寸后 `apply_dpi_cap` **只缩不放** ⇒ 源 px 小的图排得偏小 |
| 做法 | 把卷 XVII 的补丁**通用化**为 **`vol_img_upscale.py`**（`--vol` 指定卷）；在**保证 ≥150dpi** 下放大到 `min(dpi上限, CAP_ORG×1.35, **12cm**)`；**幂等** |
| 🔴 过程 bug | 首版缩放比取 `max(宽比, 高比)` ⇒ 按高度放大时会**溢出宽度目标**（实测 8.40cm 的图被放到 14.82cm）；改为 `min(...)` 后 land 图统一 **11.34cm** |
| 登记 | `vol_meta_XVI.json::post_patches` ⇒ 与既有 `xvi_tbl_color_fix.py` 一并**自动串行执行**（重建必跑） |
| 效果 | 学生版 **16 张**、答案版 **42 张**放大；目检 p1/p3/p6/p12：图更大更清晰、版面更舒展 |

## 三、目检误判的记录（重要）

目检 p6 时我把 `$\left(\mathrm{M}=\mathrm{Fe}^{2+}/\mathrm{Zn}^{2+}\right)$` 读成渲染成了 `M = F e²/Z n²`，一度判为「化学式被当变量相乘」的渲染缺陷。

**渲染实测（pandoc → OMML 可见文本）证伪**：

| 输入 | OMML 可见文本 |
|:--|:--|
| `\left(\mathrm{M}=\mathrm{Fe}^{2+}/\mathrm{Zn}^{2+}\right)` | **`M=Fe2+/Zn2+`** ✓ |
| `M = Fe^{2+}/Zn^{2+}`（裸写） | `M=Fe2+/Zn2+` ✓ |
| `\mathbf{R} = \mathbf{M}\mathbf{e}` | `R=Me` ✓ |

⇒ **XVI 无该缺陷**；`\mathbf{}` 系源卡**代号风格**（`R=Me`、化合物 A、`n₀`、`r_c` 等 8–9 处），非错误。
**教训：小字距图上的目检结论，须用渲染实测复核后才可定性。**
