## 一、评估口径与方法（为什么这样判）

合并评估最大的坑是**误把"概念相关"当成"概念重复"**。初版用「标题 2-gram Jaccard + 传递闭包」聚类，把整个有机反应网络（"亲核加成""羰基化学"等总论词作别名经中间页传递）连成 n=32 的假簇。修正后的判定信号：

| 信号 | 含义 | 可信度 | 处置 |
|------|------|--------|------|
| **exact-dup** | 两页 title 归一后完全相同 | 铁证 | **L1 直接合并** |
| **双向别名同义** | A 的 alias 含 B 的 title 且 B 的 alias 含 A 的 title | 铁证（人工互认同义） | **L1 直接合并** |
| 单向别名命中 | A 的 alias 含 B 的 title（A 自认是 B 的别名） | 多数为**别名误标**，少数为真同义 | L2 → 人工筛 |
| contains / near | 标题包含或 2-gram 相似 | 多数为**总分/同类**误报 | L2 → 人工筛 |
| 跨桶别名命中 | 决赛深化页 alias 含基础概念页 title | 几乎全是**别名误标** | 卫生清理 |

结论：**高置信合并只认 exact + 双向别名**；单向/contains/near 一律降级为"待人工确认候选"或"alias 卫生问题"，绝不自动并。

## 五、P3 — 不应合并，但需清理的"别名卫生"问题（本轮最大发现）

**现象**：大量**总论/母概念页**的 `aliases` 字段把**子概念或相关概念页**当成了自己的别名。这既不触发断链，也非真重复，但会污染别名索引、误导链接解析。

**典型误标页（应把子概念从 aliases 移到 related）**：

| 母概念页 | 误标为 alias 的子概念（举例） |
|----------|-------------------------------|
| `无机和结构化学/化学键` | σ键、π键、共价键、离子键、金属键、键能、键长 |
| `有机化学/炔烃` | Birch还原、Lindlar催化剂、亲核加成、亲电加成 |
| `有机化学/醛酮` | Cannizzaro反应、Wittig反应、亲核加成 |
| `有机化学/胺的化学` | Cope消除、Gabriel合成、Hofmann消除 |
| `有机化学/周环反应` | σ迁移反应、电环化反应（应为子类/related） |
| `有机化学/协同反应` | 周环反应 |
| `决赛要求/…/主客体化学` | 冠醚、分子识别、环糊精（应为实例/related） |
| `无机和结构化学/磷及其化合物` | 磷、磷化学（互指，见 P1 #10） |
| `无机和结构化学/氢和稀有气体` | 氢、稀有气体（独立元素页） |
| `无机和结构化学/碳族和硼族元素` | 主族元素化学、硼族元素、碳族元素 |

**跨桶同类（38 对）**：决赛深化页把基础概念当 alias，如
- `决赛要求/…/化学动力学深化` alias 含 `Arrhenius方程`、`反应级数`
- `决赛要求/…/熵变计算` alias 含 `标准摩尔熵`
- `决赛要求/…/理想气体混合物与化学势` alias 含 `化学势`
- `决赛要求/…/d轨道分裂` alias 含 `晶体场理论`

→ 这些深化页的 alias 应仅保留其专属别名，基础概念页 title 改入 `related`。

**清理方式**：写脚本扫"母页 alias 命中其他 KP 的 title（且该子页不是母页的同义缩写）"→ 自动从母页 aliases 移除并追加到 related（需排除 P1 真同义组）。**建议作为独立专项批量执行，执行前逐类抽样核对。**

## 七、合并操作机制建议

- **真重复合并**：被并页 `status: deprecated` + `superseded_by: "[[保留页路径]]"`；保留页 `aliases` 追加被并页 title/原 alias；被并页独有正文并入保留页（先 `git` 快照再改）。
- **别名清理**：母页 aliases 去掉子概念 → 子概念加 `related`。**绝不反向**把子概念内容删掉。
- **标题冲突**（如溶液）：改名索引页，不用 deprecated（索引页仍有导航价值）。
- 批量脚本要**排除 P1 的 17 组真同义**，避免把真同义当误标清掉。

1. **先做 P1（17 组）**：低风险、高置信，直接合并，预计可消 ~25 个冗余 KP。
2. **再做 P3 别名清理**：独立专项，脚本批量 + 抽样核对，消 ~100+ 处 alias 误标（不删页，只挪 related）。
3. **P2 暂不处理**：等你确认"元素 vs 其化合物"是否要合并。
4. **附带清洗**：引号(152+31)、脏 alias(13) 可并入 P3 专项。

> 所有合并/清理均**不改库结构、不删文件**，用 `deprecated+superseded_by` 与 alias 归一实现，链接零丢失。
