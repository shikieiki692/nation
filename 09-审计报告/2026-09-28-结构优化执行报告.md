## 四、★ P0 修复：一个会让文件在 Obsidian 中消失的故障

归一化后做全量 YAML 校验（13,356 个有 FM 的文件），发现 **1 个损坏**：

`03-知识点/有机化学/1,3-偶极环加成.md`

**根因**：`aliases` 中有一项以 `[` 开头：

```yaml
aliases:
  - 1,3-dipolar cycloaddition
  - 1,3-偶极环加成反应
  - [3+2]环加成      ← YAML 解析为 flow sequence → 报错
```

按项目铁律，js-yaml 遇此类结构会抛错，**导致该文件在 Obsidian 中直接消失**。

**修复**：加引号 → `- "[3+2]环加成"`

**顺带发现同类隐患**：`tags` 中 `1,3-偶极环加成` 未加引号，被 YAML 拆成 `1` 和 `3-偶极环加成` 两个元素（不报错但数据错误）。一并加引号修复。

**复验**：全库 13,356 个有 FM 的文件，**YAML 损坏 0**；`validate_kb.py` 0 Error 0 Warning。

> 这不是本轮改动造成的（属既有问题），但正是"改完必须全量校验"才暴露出来。
