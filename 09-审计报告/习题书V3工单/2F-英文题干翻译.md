# 工单 2F：Clayden/ABOC 英文题干中文化

## 任务

清单中每个文件是有机化学题（Clayden 有机化学 / ABOC 转录），`## 题目` 区是纯英文。为每题题干补**中文翻译**，保留英文原文对照。

## 格式（严格遵守）

在 `## 题目` 区内、英文原文之前插入中文译文，用加粗标记分隔：

```markdown
## 题目

**【中文】**<中文译文，完整通顺，化学术语准确>

**【原文】**<原英文题干，逐字保留不动>
```

- 若题目区含小问列表（(a)(b)(c) 或 1. 2. 3.），译文保留相同的小问编号结构。
- 题目区中的 `![[...]]` 图片引用、表格、`$...$` 公式保持原位不动；译文里提到结构式/图时说"见图"即可，不要复制图片引用。
- 化学名词规范：人名反应保留英文并附中文（如 "Diels–Alder 反应"），化合物名用中文系统命名或通用名，首次出现可括注英文。
- 公式/符号（如 pKa、δH、J/Hz）保持原样不译。

## 约束

- 只动 `## 题目` 区；frontmatter、参考答案区一律不动。
- 用 Edit 插入，不要整文件重写。
- 个别文件若题干其实已经含中文（误报），跳过并记入报告。

## 输出

报告：已翻译 N / 跳过误报 N / 异常 N（附文件名）。
