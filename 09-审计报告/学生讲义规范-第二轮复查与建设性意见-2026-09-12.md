## 一、纠正第一轮的错误（自我纠错）

### 1.1 `syllabus_codes` 定性错误

第一轮报告称 `syllabus_codes` 是「模板 v5.3 独有字段，覆盖率 0/73，证明模板失效」。**这个论据是错的。**

实测该字段在全库 **3411 个文件**中使用，分布：

| 一级目录 | 文件数 | 位置 |
|:---|---:|:---|
| `04-题库` | **3093** | frontmatter |
| `07-资料提炼` | 136 | frontmatter |
| `02-考纲条目` | 72 | 正文/注释 |
| `04-专题与题型` | 53 | frontmatter |
| 其他（11-模板 / 00-首页 / 03-知识点 / 04-课件） | 57 | — |
| **讲义（73 份）** | **0** | — |

**修正后的结论**：`syllabus_codes` 是**题库线与专题页的核心字段**（3093 处），不是模板臆造。
真实问题是——**模板 v5.3 把题库线的字段误列为讲义必填字段**，说明该模板的 schema 是从别的文档类型搬来的，没有针对讲义设计。
"SOP 是讲义实际权威"的结论**仍然成立**（依据是 `source_book`/`chapter`/`serve_rounds`/`serve_topics`/`difficulty_level`/`has_images` 92–97% 覆盖率），但论据已更换。已同步修正模板 §0.3a 的表述。

### 1.2 方法学踩坑（已复现）

第一轮用 `grep -rl "🌱\|🔥\|🏆"` 得出"全库 0 命中"，**是假阴性**——bash 内联非 ASCII 正则会 mojibake。
本轮改用 Python 扫描，实测 emoji 真实存量见 §三。**教训已固化：含 emoji/非 ASCII 的正则必须写成 .py 再跑。**

### 4.1 三条硬结论

**(1) 不存在"73 份都不守规范"，而是五条线按不同批次各自成型。**
规范是"一刀切"的，库是"分批长出来的"。用统一覆盖率衡量，必然得出"规范失效"的错觉。

**(2) 元素与分析线（13 份）是完成度最高的，应被认定为实际母版。**
深度分层 92% / 轮次划分 92% / 主线导航 92% / 小结 92% / 延伸阅读 100% / 参考答案 100% / `sources`+`problems` 100%。
而规范钦定的 S2 样板是**原子结构**（属结构化学线：`sources` 5%、`problems` 5%、小结 21%、参考答案 63%）。
→ **样板选错了。** 这不是"补原子结构"能解决的，是**该改认样板**。详见决策点 D9。

**(3) 有机化学线（19 份）是独立的"第二规范"。**
典型例题 84%、练习题 100%、速查 100%——教教学内容很完整；但 `sources`/`problems`/`exercise_count`/`template_version` **全为 0**，小结/延伸阅读/主线导航 0%。
它不是"不合格"，是**按另一套规范做的**（大概率是批次作业，未走 SOP 的元数据要求）。

**(4) 数学工具线（9 份）是"第三规范"且被规范完全遗漏。**
深度分层/轮次划分/主线导航/小结/延伸阅读/`sources` 全 0%——但练习题 78%、速查 100%、易错 67%。
它自有完整骨架（学习目标→正文→速查→练习→答案），只是与 v5.3 骨架不同。规范体系表里**根本没有它的位置**。

**(5) 化学原理线的窟窿是 3 份讲义"练习题有、答案没有"。**
> **数字更正（2026-09-12 复核）**：本节原写"参考答案仅 18%（2/11）"，系正则只匹配"参考答案"、
> 漏掉了写成"**练习题答案**"的 5 份所致。**实测为 8/11（73%）有答案节**，缺答案的只有 3 份：

## 六、建设性意见

### 6.1 规范结构：从"一份模板管全部"改为"一总 + N 线"

现状是一份 v5.3 模板试图管 5 条差异极大的线，结果每条线各自漂移。建议：

```
总纲（唯一权威）
  00-首页/讲义生产SOP与双向映射规范      → schema + 统一口径（已落地）

分线骨架（各线一份，挂在总纲下）
  化学原理线    → 补参考答案（当前仅 18%）为第一优先
  元素与分析线  → 认定为母版线，反写其实际做法为 S2 标准
  结构化学线    → 补 sources/problems/exercise_count（当前 5%）
  有机化学线    → 承认其现有骨架，只补元数据字段 + 清正文 ⭐
  数学工具线    → 单独立骨架（工具卡型），不套 v5.3
```

**核心建议：不要再试图把 73 份拉回同一个骨架，而是承认五条线、各给各的骨架，只对「总纲口径」强制统一。**

### 6.2 优先级建议（按教学影响排序，而非按规范整齐度）

| 优先 | 事项 | 理由 |
|:---:|:---|:---|
| **P0** ✅ | ~~化学原理线补**参考答案**~~ **【2026-09-13 已闭环】** | 学生有题无答案，无法自检，是唯一直接影响学习效果的缺陷。实为 2 份（非 3 份），已全部补齐，线内 11/11 有答案 |
| **P0** ✅ | ~~改认**元素与分析线**为 S2 样板~~ **【2026-09-12 已落地】** | 完成度 92%，见 §七 D9；已同步改 `内容结构规划` §3.1/§十 与 `模板-学生讲义` 参考表 |
| P1 | 有机线清正文 ⭐（766 处）+ 补元数据 | 存量最大，但只影响观感与检索，不影响学习。**D10 已拍板：只做 P0，存量不动** |
| P1 | 结构化学线补 `sources`/`problems`/`exercise_count`（5% → 100%） | 影响双向映射与题目溯源。同上，登记欠账待大修带过 |
| P2 | 数学工具线独立骨架 + 纳入体系表 | 规范里现在完全没它的位置 |
| P2 | 管线冲突处置（D8） | 影响全部 81 份产物的观感。**D8 已拍板：保持仿宋，规范已校准** |

### 6.3 建议写进规范的"防漂移"机制

1. **规范文件里的每个"实测值"必须标注日期与脚本名**，否则下次又会被当成事实。
2. **自检清单与正文主体同等维护**——本轮漏改全部发生在文件末尾清单里。
3. **被引用的子规范（如 `模板-习题三级分类`）改口径时必须同步**，建议在 SOP §四.1 维护一份"口径辐射文件清单"。
