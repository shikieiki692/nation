# 机构模拟题卡 · 原文（PDF）核验报告

> 以**视觉能力逐页比对**题卡内容。重点核验用户提出的「手写答案识别不出」问题。

### ✅ 2.1 题面：与 PDF 原文一致

**GChO1 第 1 题**逐项比对：

| 项 | PDF 原文 | 题卡 | 结论 |
|:--|:--|:--|:--|
| 题号分值 | 第 1 题（10 分） | 同 | ✅ |

| 数据表 | At 750 K；LiOH/Li/H₂O/O₂；ΔH、S° | 同（完整含负号） | ✅ |
| 小问 | Q1(2') Q2(3') Q3(2') Q4(3') | 同 | ✅ |

→ **题面转录准确，无截断、无缺漏。**

### ✅ 2.2 图片：与源同哈希，一致性成立

题卡图片是从源 `<卷>_images/<sha256>.jpg` **按同名复制**，哈希相同即同一文件；
且入库时逐条校验过「磁盘可解析」，当前仅 17 处 / 5 张真缺失（源 `_images` 无对应文件）。
→ **图片未见张冠李戴。**

### 🔴 2.3 答案初判：256 张卡「答案实为题面」（**后经复检修正为 59 张，见 二·补2**）

**核验实例（GChO13 手写解析稿）**：

PDF `ZCHEM-GChO13解析手稿.pdf` 第 1 页为**真手写稿**（红笔批注＋手写方程式），如：

```
1-1  2CuS + 10CN⁻ → 2Cu(CN)₃²⁻ + (CN)₂ + 2S²⁻
1-2  Pb₃O₄ + 8HOAc → 2Pb(OAc)₂ + Pb(OAc)₄ + 4H₂O
1-3  Co(OAc)₂ + 2NaHS + Na₂S₂O₄ + ... → CoS₂O₃↓ + ...
```

而题卡 `题-GChO-13-01` 的「参考答案」内容是：

```
1-1 CuS 隔绝空气下可溶于无氧的 NaCN 溶液，写出溶解反应的方程式。
1-2 铅丹与冰醋酸作用，产物之一是有机化学中常见的氧化剂，写出反应的方程式。
...
```

→ **答案段＝题面印刷文字**。原因：**MinerU 对手写体识别失效**，
手写稿 PDF 里印刷的题干被 OCR 出来，手写答案整体丢失，于是「答案」退化为题干复读。

**全库检测（判据：答案中「不在题面里的新信息」占比 < 15%）**：

| 机构 | 检出 | 占比 |
|:--|--:|--:|
| 质心GChO | 82 | 11.5% |
| 化英社 | 49 | 13.1% |
| XeChem | 44 | 21.7% |
| 汇智 | 20 | 6.2% |
| 清北营 | 19 | 6.4% |
| chemy | 11 | 7.6% |
| 伽马 | 10 | 5.0% |
| 质心UChO | 10 | 7.1% |
| 一式 | 5 | 5.7% |
| 北京夏令营 | 5 | 7.7% |
| 壹尖培优 | 1 | 0.7% |
| **合计** | **256** | **9.0%** |

> 另注：XeChem／chemy 的「答案版式」是「题干重排＋评分」而**无实质答案文字**（结构式答案在图里），检出属同类。

### ⚠️ 2.4 判据自证（避免误报）

首轮用 `Jaccard > 0.5` 粗判据检出 **1,197 张（41.9%）**，逐层目检后确认**过度检出**
（答案中引用题目原文属正常写法）。改用「**新信息占比 < 15%**」后收敛至 **256 张**，抽样目检均为真问题。

### ⚠️ 2.5 核验过程中的一次误读（自我更正）

清北营第 3 题 PDF 第 2 页公式，我在 **95 DPI 渲染图**上读成 `φ(H₂)=1+1.20×10⁻²P(H₂)`，
一度判定题卡 `10⁻³` 有误；**改用 `pdftotext` 提取文字层复核，原文实为 `10-3`，题卡正确**。
→ **纪律：数值核验优先用文字层（`pdftotext`），视觉读图须用高 DPI（≥200）**，低分辨率缩略图易误读上标。

### 🔴 2.6 确凿证据：手写稿 PDF「文字层 = 0」

`ZCHEM-GChO13解析手稿.pdf` 用 `pdftotext` 提取**全篇 0 字符**（纯图像，无文字层）。
即：该卷答案的**唯一信息来源是 OCR**，而 MinerU 对手写体识别失效 → 只能输出印刷题干，
手写答案（`2CuS+10CN⁻→2Cu(CN)₃²⁻+…`）**整体丢失**。**256 张判定成立。**

## 二·补2 🔴 第二轮复检：初判 256 张中 **138 张系误标**（已撤销）

### 复检动因

对 `题-GChO-13-01` 深挖时发现：其答案段**前 14 行是题干复读，但后部有真答案**——

```
1-1. 2CuS + 10CN⁻ → 2Cu(CN)₄³⁻ + (CN)₂ + 2S²⁻ (2分)
1-4. 3H₂SeO₃ + 6H⁺ + 7SCN⁻ → 3Se(SCN)₂ + 5H₂O + HCN + HSO₄⁻ (2分)
1-5. A. SbOCl / Sb₂O₃·SbCl₃ (0.5分)
```

**这正是 PDF 手写稿上的答案** → 说明 **MinerU 实际部分识别出了手写**（以 LaTeX 形式，质量差但有内容）。
我初判时**只看了答案段前部**，误判为「无答案」。

### 三档判据（全库 2,852 张重跑）

指标：① 句子级新信息占比 `r`（逐句与题面比对，相似度<0.6 记为新）
② 评分标记数 `s`（`（N分）`）③ 题面外化学方程式数 `e`（`→ ⟶ ⇌ \rightarrow` 等）

| 档 | 判定 | 张数 |
|:--|:--|--:|
| **有答案** | r≥0.3 或 s≥2 或 e≥1 | **2,031** |
| 存疑 | 其余 | **123** |
| 题干复读 | r≤0.05 且 s=0 且 e=0 | **70** |
| 无答案文件 | 卡内标「⛔ 答案缺失」 | 628 |

### 标注修正（已执行）

| 动作 | 张数 |
|:--|--:|
| **撤销标注**（判为有答案，恢复 OCR 原文） | **138** |
| 改标注「⚠️ 答案存疑」 | 59 |
| 保留「⛔ 答案需人工录入」 | 59 |
| 合计 | 256 |

### ⚠️ 判据迭代记录（三次，均因自证不足）

1. `Jaccard > 0.5` → 1,197 张（**过度检出**，答案引用题干属正常）
2. `3-gram 新信息 < 15%` → 256 张（**仍不精准**：漏检 GChO13-01，且未看答案段后部）
3. 句子级三档（本版）→ 有答案 2,031／存疑 123／复读 70（**抽样目检吻合**）

**教训：判据必须目检自证，且不能只看片段——要通读答案段全文。**
