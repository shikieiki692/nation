# 修复对 Word 管线的影响：验证报告

> 日期：2026-09-19
> 前置问题：「开始吧，不会影响后续的 word 管线吧」
> **结论：不影响，且方向与管线完全一致。**

## 一、⭐ 核心发现：管线里已有同款逻辑

`11-模板/scripts/build-all-handout-docx.py` 第 **1479 行** 存在：

```python
def _convert_html_tables(text: str) -> str:
    """把源里的 <table>...</table> 转成 Markdown pipe table。

    pandoc 输出 docx 时不会把 raw HTML table 落成 Word 表格，只把单元格文字逐个
    摊成独立段落——习题书 1-热力学「大豆发热量」表就是这样散成十几段的。转成
    pipe table 后才会生成真正的 Word 表格。
    ...
    保守条件（不满足则原样放过）：无 colspan/rowspan、无 <img>、列数 1..8
    """
```

调用点：第 **1614 行** `text = _convert_html_tables(text)` —— 在 **Preprocess 阶段（渲染前动态转换）**。

**这与我本轮提议的修复方向完全一致**，且其注释对「pandoc 不把 HTML 表格落成 Word 表格」的判断，
与我隔离实测的 `w:tbl = 0` **完全吻合**。

## 二、作用域比对：零重叠

| 项 | 值 | 来源 |
|---|---|---|
| 管线源目录 | `04-课件/学生讲义` | `build-all-handout-docx.py` 第 62 行 `HANDOUT_SRC` |
| 管线输出 | `06-学生侧材料/讲义` | 第 65 行 `HANDOUT_OUT` |
| **本轮修复目标** | `06-外部资料导入/` + `mineru/` + `mineru02/` | 可行性评估确定的**无主区** |

→ **两个集合无交集。管线不消费我改的文件。**

## 三、三项实验验证

| 实验 | 方法 | 结果 |
|---|---|---|
| **① 等价性** | 直接 `exec` 管线的 `_convert_html_tables`，喂 HTML 表 / MD 表 | 管线会把 HTML 表转成 Markdown 表；MD 表原样通过 |
| **② 幂等性** | `conv(conv(x)) == conv(x)` | ✅ True —— 跑两次结果一致，不累积误差 |
| **③ 合并单元格** | 喂 `colspan` 表给管线函数 | ✅ **管线原样跳过（不转）** —— 与我的评估判断一致 |

**实验 ③ 的意义**：证明「合并单元格不处理」不是我方判断的保守，**是管线自身的既有约定**。
双方口径一致，不存在冲突。

## 四、若将来有交集会怎样（正向）

**假设**：某天 `06-外部资料导入/` 的文件被 `04-课件/学生讲义` 引用并导出 Word。

| 情形 | 管线行为 | 结果 |
|---|---|---|
| 源仍是 HTML 表 | 管线 `_convert_html_tables` 转 → Word 表格 | ✅ 可用 |
| **源已转成 Markdown 表**（本次修复） | 管线检测不到 `<table>`，**跳过转换** | ✅ **同样可用，且少一道转换，结果更可控** |

→ **提前转好不但无害，反而更稳**（源即最终形态，不依赖渲染时转换）。

## 五、细则差异（已确认无冲突）

| 项 | 管线产出 | 我方产出 | 影响 |
|---|---|---|---|
| 分隔行写法 | `\| --- \| --- \|`（带空格） | `\|---\|---\|`（无空格） | ⚠️ **无影响**（Markdown 两种写法等价，渲染结果相同） |

实测对比：
```
管线：'| A | $x_1$ |\n| --- | --- |\n| B | $y_2$ |'
我方：'| A | $x_1$ |\n|---|---|\n| B | $y_2$ |'
```
两者均为合法 GFM 表格，pandoc 与 markdown-it 均等价解析。
**为减少差异，我方转换器统一采用管线的带空格写法**（后续实现时遵循）。

## 六、最终结论

| 问题 | 答案 |
|---|---|
| 会影响 Word 管线吗？ | **不会** |
| 为什么？ | 作用域零重叠（管线只跑 `04-课件/学生讲义`）+ 管线自身就是同款转换逻辑 |
| 方向冲突吗？ | **不冲突，完全一致** —— 管线在渲染时转，我在源里转 |
| 有正面影响吗？ | 有：源即最终形态，将来若被引用导出，省一道转换且更可控 |
| 合并单元格怎么办？ | 管线自己也不转（第 1479 行保守条件），与我的评估一致 → **登记人工批** |
