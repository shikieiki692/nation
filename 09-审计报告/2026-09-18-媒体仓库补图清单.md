# 媒体仓库补图清单（第一轮组卷扩池）

## 背景

`gen_r1.py::imgs_ok()` 判定题内图引用 `![[xxx]]` 必须落在仓库根或 `媒体仓库/`；
第一轮组卷盘点到 **35 题 / 85 个引用**因图在库内他处而被拒收（占合格池 1.8%）。
诊断为**零真缺**——85 个引用的 basename 全库均可命中（去重后 **81 张**），
且引用本身是**纯 basename**（无子路径），因此**只需复制、不需改任何 md**。

## 操作

- 脚本：`.workbuddy/tmp/rescue_imgs.py --write`（输入 `img_plan.json`，含 SHA-256 校验、
  目标已存在则比对一致后跳过、内容不一致**不覆盖**并告警、失败重试 4 次）
- 结果：**复制 81 / 失败 0 / 冲突 0 / 零命中 0**，总体积 2.36 MB
- 效果：合格池 **1,970 → 2,005（+35）**，「图不在媒体仓库」拒收 **35 → 0**；
  未用余量 798 → 833（基础档 59 → 64、进阶 304 → 320、挑战 435 → 449）
