## 六、本轮沉淀的方法论（4 条）

### 1. 大 pack 推送的分批法
- **先算体积**：`git rev-list --objects <base>..<commit>` + `git cat-file --batch-check=%(objectsize)`
- **分批推**：`git push origin <commit>:master` 逐批快进
- **本次实测**：15 笔中**第 10 笔单 commit 占 106 MB**（102 份 docx），其余 14 笔共 20 MB

### 2. `Everything up-to-date` 是误导
- 它出现在 push 失败后，易被误读为"已最新"
- **唯一可信判据**：`git ls-remote origin master`

### 3. Obsidian 链接校验必须区分短链与路径链
- **短链** `[[文件名]]` → 全库匹配，**不能做路径拼接校验**（会误报）
- **路径链** `[[路径/文件名]]` → 可按路径校验
- 本次踩坑：脚本对短链 `[[过渡-化学键衔接]]` 做路径拼接 → 误报 1 个断链

### 4. 迁移判定三步法
1. `os.path.getmtime` 抛异常 = 物理不存在（非内容删除）
2. `git status` 无对应 `??` 新增 = 迁到 git 看不见处
3. `git check-ignore -v <候选>` + `find <候选>/ -name "*.jpg" | wc -l` = 定位真实去向
