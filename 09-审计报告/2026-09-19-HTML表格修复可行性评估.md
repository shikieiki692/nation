## 一、转换成功率实测

### 1.1 复杂度分类（2,515 行有效样本）

| 类别 | 行数 | 占比 | 可自动转换 |
|---|---|---|---|
| **CLEAN**（无合并/无嵌套/无实体） | **1,771** | **70.4%** | ✅ 是 |
| `span`（含 colspan/rowspan） | 424 | 16.9% | ❌ 否 |
| `nested`（td 内有 `<img>`/`<br>` 等） | 110 | 4.4% | ⚠️ 部分 |
| `entity`（含 `&#x27;` `&lt;` 等） | 76 | 3.0% | ⚠️ 先解码 |
| `span+nested` | 69 | 2.7% | ❌ 否 |
| `span+entity` | 34 | 1.4% | ❌ 否 |
| `nested+entity` | 23 | 0.9% | ⚠️ 部分 |
| `span+nested+entity` | 8 | 0.3% | ❌ 否 |

**合并单元格合计 424 行**（colspan 379 / rowspan 389，部分同行并存）。

### 1.2 转换器实测（`.workbuddy/tmp/_convert_test.js`）

**CLEAN 表（BP 速率表）转换结果**：

```markdown
| Temperature, °C | $[BBr_3], \mathrm{mol}\cdot\mathrm{L}^{-1}$ | ... |
|---|---|---|
| 800 | $2.25×10^{-6}$ | ... |
```

- KaTeX 渲染 **11 个** ｜ 残留 `$` **0 个** → ✅ **成功**

**对照：带 rowspan 的表**

```
原始：<td rowspan="2" colspan="2"></td><td colspan="4"> $[CH_3CH_2OH]_0$ </td>
转换：|  | $[CH_3CH_2OH]_0$ |  |  |  |
```

⚠️ **rowspan/colspan 信息丢失**，跨列表头（`$[CH_3CH_2OH]_0$` 跨 4 列）无法表达 → **版式语义损坏**。
这是 Markdown 表格的**原生限制**（不支持合并单元格），无法通过转换器弥补。

## 三、⭐ 意外发现：HTML 表格在 Word 里根本不是表格

**隔离实测**（`.workbuddy/tmp/_pandoc_isolate.py`）：

| 输入 | `w:tbl`（Word 表格数） | `m:oMath` 公式数 | 内容 |
|---|---|---|---|
| **HTML 表格** | **0** ❌ | 2 ✅ | 文本存在，但**表格结构丢失**（拍平为段落） |
| **Markdown 表格** | **1** ✅ | 2 ✅ | 结构完整，公式在单元格内 |

**含义**：现在的 HTML 表格，**导出 Word 后表格结构完全消失**——表头、行、列全部拍平成一段文字。
这解释了为什么 Word 产物看起来是「一坨」。

→ **修复的收益因此翻倍**：不止修好 Obsidian 渲染，**同时让 Word 恢复真正的表格结构**。

## 四、可行性判定与建议

### 4.1 判定

| 结论 | 说明 |
|---|---|
| ✅ **技术可行** | CLEAN 70.4% 可自动转换，零残留，已实测验证 |
| ⚠️ **不完备** | 29.6% 含合并单元格等，Markdown 表格无法保真 |
| 🔴 **影响面大** | 272 文件被引用、79 有 docx、116 在红线区 |
| ✅ **收益明确** | 一改双修（Obsidian 渲染 + Word 表格结构） |

### 4.2 建议路线（保守逐级推进）

**第 1 步：无主区 CLEAN 子集**（建议先做）
- 范围：`06-外部资料导入/` + `mineru/` + `mineru02/` 中的 CLEAN 行
- 理由：无主区可放手自动处理，**零撞车风险**；先验证转换器可靠性
- 规模：需先算（下一步脚本给出）

**第 2 步：跨线分发**
- 其余按责任线分发（题库线活跃避让、课件线活跃避让）

**第 3 步：合并单元格行**
- 登记为**人工批**，逐表核对（改则破版，不可自动）

### 4.3 转换器必备设计（安全要求）

1. **只处理 CLEAN 表**：命中 `colspan`/`rowspan`/`<img`/`&` 一律**跳过并登记**
2. **渲染自证**：每表转完**实跑 markdown-it**，确认 `残留 $ == 0` 且 `KaTeX > 0` 才落盘
3. **行数守恒**：单行 HTML → 多行 Markdown，需断言**表格行数/单元格数守恒**
4. **备份 + 四口径验证**（沿用 `·`→`\cdot` 那套：位点守恒、字符级 diff）
5. **不碰红线**：`04-题库/`、`05-真题库/`、`_归档/` 显式排除
