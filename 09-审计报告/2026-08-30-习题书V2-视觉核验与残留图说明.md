# 习题书 V2 视觉核验与残留图说明

> 本报告针对“合并版正式成书”（1500 题）做完图片视觉核验，并量化了合并后仍残留的跨题重复图，供后续优化参考。

## 一、核验结论：22 张待判图全部为真实化学图

正式成书已按“推荐合并版”生成（1500 题 / 1887 图 / 媒体缺失 0 / 风险行 0 / HTML 表 0）。对合并版教师版按“**同一张图是否出现在不同题块**”统计：

### 2.1 跨章残留用“归属题”判定，不能盲删（重点修正）

> **重要更正**：查询 `source-map.jsonl` + 逐题读源文件后确认，这部分“跨章出现”的图**绝大多数不是误挂到无关题目，而是同一道大题被拆到不同章节所造成的“重复引用”**。直接按“跨章=误挂”删图会破坏真实题目。

**归因机制（以 25 届初赛第 1 题为例）**：`题-025-1` 是同一道大题（15 分），含 5 个小问，因 `subject_module`/`submodule` 不同，正式成书时**保持拆分**，被路由进 3 个不同章节（化学原理/结构化学/元素与分析）。每个小问源文件都带一个从原卷页复制来的 `## 题目图示与结构参考` 块，内含**相同的图组**；而该图组的每张图实际上只属于其中某个小问（如 FSN/F₃SN 属于 1-3、双核铝金属有机属于 1-4）。因此同一张图会随该大题的小问被复制到多处——这是**“同一道大题拆分 + 原卷页图组复制”**造成的重复，不是跨题误挂。

**正确做法（逐张判定归属，再删非归属处的引用）**，与 27 届初赛同页图簇试点一致：
1. 逐张读该图所属大题的各小问题干，确定该图**真正归属的小问**；
2. 只在该归属小问保留 `![[哈希.jpg]]`，其余小问的同类“题目图示与结构参考”复制引用删除（保留媒体文件）；
3. 若确认某图确属某几道互不相同的小问独立使用（非复制），则保留。

**已实测**：87 张跨题重复图中，**4 张**的多个出现块映射到同一源题组（如 `题-026-2`、`题-026-6` 的 3 张），属“一张图在一个被拆散的大题里重复”的高置信场景；其余属于跨多个**不同**源题组的真实跨题复用或原卷页图组复制，需逐张读题确认，**不可批量盲删**。

### 2.2 同章跨题残留（73 张，268 引用）

多数是同一大卷/同主题在章节内多题复用同一图（合理复用），少数可能是同章内一道被拆散大题的小问仍复制了同一图组。建议：优先处理 2.1 中“同一源题组”的那 4 张（高置信清理）；其余 69 张（跨不同源题组）与 2.2 留作“逐张读题干判归属”的章节级复核，**不批量删除**。

> 完整逐块清单（含每个块的文件/章/题号/源题组）：`09-审计报告/2026-08-30-习题书V2-合并版跨题图残留.csv`（87 行），含 `chapter_count`、`group_count`、`groups`（源题组）、`blocks_with_sources`（块→源题映射），可直接筛 `chapter_count>1`、`group_count=1`。

## 四、建议后续优化顺序

1. **不做“跨章即删”**。先用 `audit_cross_question_images.js` 产出的 `groups`（源题组）+ `blocks_with_sources` 定位：同源题组、跨章出现的（`group_count=1`）属“被拆散大题的重复引用”，优先逐张读小问题干定归属，删非归属处、保留归属处。
2. **跨不同源题组的**（`group_count>1`）：逐张读各源题题干，判断是“同卷多题共用一图（合理）”还是“原卷页图组复制（误挂）”，确认后才改，保留媒体文件。
3. 每批清理后重跑 `audit_exercise_book.py`，确认 `questions=1500`、媒体缺失 0、风险行 0 不倒退。
4. 全部清理后全量重出 Word（教师版/学生版），再跑 `gate_exercise_books.py` + `validate_docx_structure.py`。
