## 二、逐条详情

### 1. 题-056-5(2)：结论错误 🔴

**位置**：`04-题库/教材习题/上海中学竞赛课程/题-056-上海中学-化学动力学基础-习题1.md`

**题面**：一级平行反应，$E_{a1}=108.8$、$E_{a2}=83.68\ \mathrm{kJ\,mol^{-1}}$，$A_1=A_2=10^{13}\ \mathrm{s^{-1}}$。问"能否通过提高温度使 $k_1>k_2$"。

**源答案**：可以，当温度足够高时。

**反证**：

$$\frac{k_1}{k_2}=\frac{A_1}{A_2}\exp\!\left(-\frac{\Delta E_a}{RT}\right)=1\times\exp\!\left(-\frac{25120}{RT}\right)$$

$T>0$ 时指数恒负 → $k_1/k_2<1$ **恒成立**；$T\to\infty$ 时趋近 1（**从下方**）。

| $T$/K | $k_1/k_2$ |
|:--:|:--:|
| 300 | $4.23\times10^{-5}$ |
| 1000 | $4.87\times10^{-2}$ |
| $10^4$ | $0.739$ |
| $10^6$ | $0.997$ |

**建议答案**：不能。因 $A_1=A_2$ 而 $E_{a1}>E_{a2}$，$k_1/k_2$ 的上限是 $A_1/A_2=1$，升温只能使比值趋近 1，永远无法超过。要使 $k_1>k_2$ 必须有 $A_1>A_2$ 或改变 $E_a$ 次序（如换催化剂）。

### 2. 题-395 10-1：吸附焓数值错误 🔴

**位置**：`04-题库/教材习题/化学能力测试/题-395-化学能力测试-Ch6B-10-Langmuir吸附与多相催化.md`

**题面**：180 K、350 kPa 与 240 K、1.02 MPa 吸附量相同，求 $\Delta_{ad}H^\theta_m$。

**源答案**：$-9.06\ \mathrm{kJ\,mol^{-1}}$（题库校勘注已指出应为 $-6.4$，但未改正文）

**复算**：

$$\left(\frac{1}{180}-\frac{1}{240}\right)^{-1}=720\ \mathrm{K} \qquad \ln\frac{350}{1020}=-1.0696$$
$$\Delta_{ad}H = 8.314\times720\times(-1.0696) = -6.403\times10^{3}\ \mathrm{J\,mol^{-1}} = \mathbf{-6.40\ kJ\,mol^{-1}}$$

**反推**：若答案为 $-9.06$，需 $\ln(p_1/p_2)=-1.5135$ → $p_1/p_2=0.220$，与题面 $350/1020=0.343$ 不符。

**建议**：正文改为 $-6.40\ \mathrm{kJ\,mol^{-1}}$（该题库校勘注正确，应落实）。

### 3. 题-028决-6：相数概念错误 🔴

**位置**：`04-题库/真题/第28届决赛/理论/题-028决-6-多相平衡NaHCO3.md`

**源答案**："相数 $\phi=5$（3 个固相 + $\mathrm{CO_2/H_2O}$ 气相混合物 + $\mathrm{NH_3}$ 气体）"

**问题**：气体混合物**是一个相**，不能按组分拆开计数。$\mathrm{CO_2}$、$\mathrm{H_2O}$、$\mathrm{NH_3}$ 同属气相。

**应为**：$\phi = 3(\text{固}) + 1(\text{气}) = \mathbf{4}$

**连带问题**：该答案后续又写"若三固共存……则 $f=0$"，与前面按 $f=K-\phi+2$ 算出的结果矛盾，需一并理顺。

**附带**：该题干**未给出**计算 $\mathrm{pNH_3}$ 所需的平衡常数，"6-1 根据给定温度下的平衡常数可求得"属于数据缺失，建议补全题面或标注"数据见原卷附表"。

### 4. 题-赵鑫光-电化学-习22：答非所问 🔴

**位置**：`04-题库/教材习题/赵鑫光/题-赵鑫光-电化学-习22.md`

**题面**（原书逐字）：电解镍盐溶液 $[\mathrm{Ni^{2+}}]=0.10\ \mathrm{mol/L}$，阴极上恰好镍析出而不析氢时最小 pH=0.95，$E^\ominus(\mathrm{Ni^{2+}/Ni})=-0.2363\ \mathrm{V}$，**求氢在镍上的超电势**。

**现答案**：为"提炼版"，内容是电解 $\mathrm{NiSO_4}$ 的总反应、理论分解电压 1.48 V、实际电压 1.68 V——**与所问无关**。

**正确解**：

$$E(\mathrm{Ni^{2+}/Ni}) = -0.2363 + \frac{0.05916}{2}\lg(0.10) = -0.2659\ \mathrm{V}$$
$$E(\mathrm{H^+/H_2}) = -0.05916\times0.95 = -0.0562\ \mathrm{V}$$
$$\eta_{\mathrm{H_2}} = E(\mathrm{H^+/H_2}) - E(\mathrm{Ni^{2+}/Ni}) = -0.0562-(-0.2659) = \mathbf{0.210\ V}$$

（与文献"氢在 Ni 上超电势 0.2–0.3 V"一致）

**建议**：按上述替换参考答案，并补反向校验（$\eta=0$ 时只能析氢、镀不出镍）。

### 5. 题-34决理-1-5-1：数据与答案不符 🔴

**位置**：`04-题库/真题/第34届决赛/理论/题-34决理-1-5-1-过氧化氢酶动力学.md`

**数据表**（5 组）：$1/[S]_0$ = 0.1/0.2/0.5/1.0/2.0，$1/v_0$ = 0.110/0.140/0.220/0.350/0.600

**源答案**：$V_{max}=10.0$、$K_m=1.0$（5-1-1）；竞争性抑制、$K_i=0.1$（5-1-2）

**复算**（标准 OLS，$y=ax+b$）：

$$a=0.2570 \qquad b=0.0887$$
$$V_{max}=1/b=11.3 \qquad K_m=a\cdot V_{max}=2.90$$

**反证**：若 $V_{max}=10$、$K_m=1$，则 $1/v_0=0.1(1/[S]_0)+0.1$，5 点应为 0.11/0.12/0.15/0.20/0.30 —— 只有第 1 点与所给数据相符，其余全部偏离。

**5-1-2 亦有问题**：加抑制剂后回归，截距由 0.0887 → 0.1587（**变了**），斜率 0.257 → 0.722。纯竞争性抑制应**截距不变**，故此判据不成立（实测更接近**混合型**抑制）。

**建议**：核对原卷数据与官方答案；本讲已因该题不可靠而**弃用**。

### 6. 题-056-3：内部不自洽 🟠

**位置**：同题-056，第 3 题（$40^\circ\mathrm{C}$ $\mathrm{N_2O_5}$ 一级分解）

**源答案**：$k=3.26\times10^{-5}\ \mathrm{s^{-1}}$，$t_{1/2}=21260\ \mathrm{s}=5.9\ \mathrm{h}$，$c_0=3.07\times10^{-3}\ \mathrm{mol/L}$

**校验**：

- $\dfrac{0.693}{3.26\times10^{-5}} = 2.13\times10^{5}\ \mathrm{s} \neq 21260\ \mathrm{s}$（差 10 倍）
- 按 $t_{1/2}=21260$ 反推 $k=3.26\times10^{-5}\ \mathrm{s^{-1}}$ ✓（说明 $t_{1/2}$ 与 $k$ 中**有一个的幂次写错**）
- 按题面 $v/v_0=e^{-kt}$，$t=3600\ \mathrm{s}$、$v/v_0=0.326$ → $k=3.11\times10^{-4}\ \mathrm{s^{-1}}$，与两者均不符
- $c_0=v_0/k$ 亦随之连锁偏差

**建议**：以原书为准重核三个数值的幂次，并统一到题面数据。

### 7. 题-37决理-2-3：温度标签笔误 🟡

**位置**：`04-题库/真题/第37届决赛/理论/第二场/题-37决理-2-3-甲酸的分解.md`

**问题**：题面数据表温度列为 **200 / 230 / 260 / 280 °C**，参考答案表却写 **210 / 240 / 260 / 280 °C**。

**判定**：四个 $\mathrm{p}K_a$ 数值（3.80 / 4.00 / 4.60 / 4.90）与**按题面温度**计算的结果**完全吻合**（$\mathrm{p}K_a=2(\lg k_1-\lg k_2)$）：

| $T$/°C | $\lg k_1$ | $\lg k_2$ | $\mathrm{p}K_a$ |
|:--:|:--:|:--:|:--:|
| 200 | $-3.71$ | $-5.61$ | $3.80$ |
| 230 | $-2.75$ | $-4.75$ | $4.00$ |
| 260 | $-1.91$ | $-4.21$ | $4.60$ |
| 280 | $-1.20$ | $-3.65$ | $4.90$ |

→ 数值正确，**仅答案表的温度标签写错**。建议改为 200/230/260/280。

### 8. 题-037-7-1(3)：模型口径差异（非错误，建议加注）🟡

**位置**：`04-题库/真题/第37届初赛/题-037-7-1-磷脂双层膜离子通透性.md`

**源答案**：回归 $D=2.6998(1/\eta)+0.0086$，$r=99.59\%$，$d=159$ nm

**标准 OLS 复算**：$a=2.624$、$b=0.0125$、$r=99.84\%$，$d\approx164$ nm

**判定**：源答案内部自洽（$d=k_BT/3\pi a$ 与斜率 2.6998 匹配），但与标准最小二乘差约 **3%**。差异来自模型选择：强制过原点 $y=kx$ 得 $a=2.752$（$d\approx156$ nm）；单组数据直接算散布在 141–162 nm。

**建议**：**保留 159 nm 作为评分答案**，但补一条注：拟合方法（是否含截距、是否加权）会带来百分之几的差异，属数据处理的固有属性。
