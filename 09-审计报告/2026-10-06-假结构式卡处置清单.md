# 假结构式卡处置清单（2026-10-06）

## 一、问题定义

`04-题库/2026机构初赛模拟题/` 的**题卡答案区**里，有若干 `\begin{array}{...}` 块，
其内容**不是数学对齐公式**，而是 **OCR 从结构式图里抓出的「竖直相邻标签」或 ASCII 键线骨架**：

- 纯骨架行：单独成行的 `|`、`/`
- 行首/行尾骨架：`|\quad\text{Si}`、`(\text{Et}_2\text{O})\text{Cl}_2\text{Al}/`

⇒ 渲染后 `|` `/` 会**印成字面字符**，卷面出现 `X:Si[AlCl2(OEt2)]4 AlCl2(OEt2)| Si(Et2O)Cl2Al/…` 这类乱码。

**判据**（`build_org.has_fake_struct`，已在组卷器实现并生效）：

```python
ARR_FAKE = re.compile(r'\\begin\{array\}(?:\{[^}]*\})?(.*?)\\end\{array\}', re.S)
# 逐「行」（按 \\ 切）判：① 整行仅由 | / 组成；② 行首是 | 或 / 且长度<60；③ 行尾是 | 或 / 且长度<60 且含中英文
# ⚠️ 只认 | 与 /，不认 \ —— 否则 \downarrow / \mu / \hline 等命令会被误判
```

## 三、两类处置路径

**A. 图冗余 ⇒ 删 array**（首选，零风险）
若该 array 对应的**结构式图已在卡内**（同表相邻单元格或紧邻段落），则 array 是 OCR 的**重复抓取**，
删除即可（卡片常已自行标注「见配图」）。

**B. 真内容 ⇒ 回原 PDF 提取**（本次已验证的方法）
若 array **承载了图上没有的信息**，则从源 PDF **渲染该区域**并**阈值去水印**，替换为图：

```python
# ① 用 page.get_text("dict") 取散标签坐标，锚定「本题号 → 下一题号」的 y 区间
# ② 渲染
pm = page.get_pixmap(clip=pymupdf.Rect(x0, y_top, x1, y_bot), dpi=400)
# ③ 阈值去浅灰水印（水印是浅灰墨，线条是黑）
Image.open(...).convert("L").point(lambda v: 255 if v > 185 else 0)
# ④ 存 机构/images/<sha256>.png，把源卡那一行换成 `**N-M** ![[<hash>.png]]`
#    断言：图引用 +1、array 数 −N、题面区逐字节不变
```

**已完成样板**：`题-QBY-17-02` 的 `2-2-1`（十字骨架结构式，从源 PDF 第 3 页 `y∈[318,383]` 提取，阈值 185 去水印）。
