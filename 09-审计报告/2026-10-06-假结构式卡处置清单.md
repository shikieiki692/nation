# 假结构式卡处置清单（2026-10-06，已办结）

## 一、问题定义

`04-题库/2026机构初赛模拟题/` 的题卡里，有若干 `\begin{array}{...}` 块，
其内容**不是数学对齐公式**，而是 **OCR 从结构式图里抓出的「竖直相邻标签」或 ASCII 键线骨架**：

- 纯骨架行：单独成行的 `|`、`/`
- 行首/行尾骨架：`|\quad\text{Si}`、`(\text{Et}_2\text{O})\text{Cl}_2\text{Al}/`
- `\backslash`／`/` 画的孤对电子与键线

**🔴🔴 渲染机理（2026-10-06 实测）**：pandoc/texmath 对 `\begin{array}`
**不生成 `m:eqArr`**（实测 `eqArr=0`），而是把整个 array **压平成单行 `m:t`** ⇒
`|` `/` `\` 全部**印成字面字符**。例：

| 源 | 渲染结果 |
|:--|:--|
| `\left[\begin{array}{c}\text{O}\\|\ \text{NH}\end{array}\right]_{2n}` | `O\|NH2n` |
| `\xrightarrow[...]{\mathrm{HO}\begin{array}{c}\mathrm{Me}\\|\ \mathrm{CF}_3\end{array}}` | `B1→HOMe\|CF3CF3D` |
| `\begin{array}{c}-\text{O}\\|\ \text{O-Ag-O}\end{array}` | `−O\|O−Ag−O\|O−Ag−O−` |

⇒ 必须**回源 PDF 提取结构/反应式图**，或（图冗余时）**删 array**。

**判据**（`build_org.has_fake_struct`）：

```python
ARR_FAKE = re.compile(r'\\begin\{array\}(?:\{[^}]*\})?(.*?)\\end\{array\}', re.S)
# 逐「行」（按 \\ 切）判：① 整行仅由 | / 组成；② 行首是 | 或 / 且长度<60；
#                        ③ 行尾是 | 或 / 且长度<60 且含中英文
# ⚠️ 只认 | 与 /，不认 \ —— 否则 \downarrow / \mu / \hline 等命令会被误判
```

**🔴 闸门覆盖范围修正（本次）**：原闸**只查答案区**（`has_fake_struct(rawa)`），
实测漏掉**题面区**的 2 张（`化英社-HYS-01-08`、`XeChem-XeC-19-02`）。
⇒ 已改为 **`has_fake_struct(rawa) or has_fake_struct(rawq)`**（题面＋答案双区）。

## 三、两类处置路径（判据）

**A. 图冗余 ⇒ 删 array**（零风险）
若该 array 对应结构**已在卡内**（相邻单元格/紧邻段落有图），则 array 是 OCR 重复抓取，删除即可。
- 判据：把 array 的标签（如 `L_n Nl-Ar / Cl`）与卡内相邻图的**裸眼比对**——本次 `e55cd7fe` 图与该 array 完全同构。

**B. 真内容 ⇒ 回原 PDF 提取**（本次主力方法）
```python
# ① 用 page.get_text()/get_text("dict") 取锚点文字坐标（题号、分值、（N分）等）
# ② 渲染「锚点 → 下锚点」之间区域
pm = page.get_pixmap(clip=pymupdf.Rect(x0, y_top, x1, y_bot), dpi=300~400)
# ③ 阈值去浅灰水印（水印是浅灰墨，线条是黑）——阈值 185~205，逐图试
Image.open(...).convert("L").point(lambda v: 255 if v > 200 else 0).crop(bbox)
# ④ 存 机构/images/<sha256>.png，把源卡那一行/那一块换成 `![[<hash>.png]]`
```
**断言（缺一不可）**：图引用 +1 或 +N／array 数 −N／**题面区逐字节不变**／FM 逐字节不变（C7 例外）。

**🔴🔴 正则跨区陷阱（本轮踩到）**：用 `\$\$\s*\\mathrm\{B\}.*?\\mathrm\{D\}\s*\$\$` 这类
「首尾锚点 + 非贪婪」正则，会**从题面区一路跨到答案区**（实测吞掉 1592 字符、含 `## 参考答案`）。
⇒ **一律改用「先 find 锚点 → rfind/find 定位 `$$` 边界 → 按索引替换」**，并保留 `## 参考答案` 区界断言。

**🔴 写盘断言长度坑**：`t2[j:j+8] == "\n\n> ⛔ 本"` 会失败（切片 8 字符 vs 字符串 7 字符）
⇒ 用 `startswith`，不要比切片长度。
