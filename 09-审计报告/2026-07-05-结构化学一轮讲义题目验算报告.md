## ❌ 需要修正的错误（共6处）

### 错误1：原子结构 — 第3题 [普化原理11-3]（~第864行/答案第1003行）

**题目**：计算氢原子 n=4→n=3 跃迁的频率和波长

**文件给出的错误答案**：ΔE = 1.122 eV，ν = 2.72×10¹⁴ Hz，λ = 1103 nm

**正确答案**：
- ΔE = 13.6 × (1/3² - 1/4²) = 13.6 × 7/144 ≈ **0.661 eV**
- ν = 0.661 × 1.602×10⁻¹⁹ / 6.626×10⁻³⁴ ≈ **1.59×10¹⁴ Hz**
- λ = 3×10⁸ / 1.59×10¹⁴ ≈ **1887 nm**（远红外区）

> 注：1.122 eV 实际对应的是 n=4→n=2（Balmer Hβ线），而非 n=4→n=3。

### 错误2：元素周期律 — 练习2 第(2)小题（~第630行答案区）

**题目**：比较 Sc 和 Ca 的原子半径

**文件错误答案**：Sc > Ca

**正确答案**：**Ca > Sc**
- Ca 金属半径 ≈ 197 pm，Sc 金属半径 ≈ 162 pm
- 同周期从左到右原子半径递减是基本规律，Ca（ⅡA族）在 Sc（ⅢB族）左侧，半径更大

### 错误3：元素周期律 — 练习5（~第650行答案区）

**题目**：B(2s²2p¹)、C(2s²2p²)、N(2s²2p³)、O(2s²2p⁴) 中哪个 I₁ 最大/最小？

**文件错误答案**：O 的 I₁ 最小

**正确答案**：四个元素中 **B 的 I₁ 最小**（801 kJ/mol），O 的 I₁ = 1314 kJ/mol 远大于 B
- 正确说法：N 的 I₁ 最大（1402，半满稳定），B 的 I₁ 最小（801）
- O 的 I₁ 比 N 小（配对排斥效应），但 O 仍远大于 B 和 C

### 错误4：元素周期律 — 练习11(b) Slater计算（~第710行答案区）

**题目**：计算 P 的 3p 电子的有效核电荷 Z*

**文件错误**：σ = 1.00×2 + 0.85×8 + 0.35×3 = **11.45**（算术错误！）

**正确计算**：
- σ = 2.00 + 6.80 + 1.05 = **9.85**（即使按文件的分组方式）
- Z* = 15 - 9.85 = **5.15**
- 若按标准 Slater 分组（同组4个电子）：σ = 2.00 + 6.80 + 1.40 = 10.20，Z* = **4.80**

### 错误5：元素周期律 — 练习14 NO焓估算（~第745行答案区）

**文件错误**（三处）：
1. **Pauling公式单位错误**：Δ = 9(Δχ)² = 1.44 kJ/mol，但 Pauling 原始公式中 Δ 的单位是 **kcal/mol**，换算后应为 1.44 × 4.184 ≈ 6.0 kJ/mol
2. **均值类型错误**：应使用几何平均 √(D(N₂)×D(O₂)) ≈ 686 kJ/mol，而非算术平均 722 kJ/mol
3. **中间算术错误**：½(946+498) = **722**，不是文件写的 627

**正确答案**：D(NO) ≈ √(946×498) + 6.0 ≈ 692 kJ/mol；ΔH ≈ 1444 - 2×692 = **+60 kJ/mol**（Pauling公式对 NO 这类自由基分子本身偏差较大，实验值约 +180 kJ/mol）

### 错误6：晶体学与晶体 — 例5（~第848行/答案第1158行）

**题目**：立方晶系，a = 543 pm，F格子，"每个晶胞含4个原子"，密度 2.33 g/cm³，求摩尔质量

**文件答案**：M ≈ 28.1 g/mol → 硅（Si）

**问题**：Si 具有金刚石结构，晶胞含 **8个原子**（面心立方点阵 + 2原子基元），而非题目给出的4个
- 用 Z=4 计算：M = 56.2 g/mol（不合理）
- 用 Z=8 计算：M = 28.1 g/mol → Si ✓

> **修正建议**：将题目中"每个晶胞含4个原子"改为"每个晶胞含8个原子"
