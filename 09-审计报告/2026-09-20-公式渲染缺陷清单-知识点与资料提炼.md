## 修正记录（2026-09-20 稍晚，提交 `fe833786f`）

上节把 `\text` 内套命令写成「**`md_sanitize` 尚未覆盖此形态**（已知缺口）」——
**该缺口已补，且此形态的全库残留已归零**。同时本轮又实测确认了**两类**新缺陷。逐条更正：

### 一、`\text{…\cmd{…}…}`（文本命令嵌套）—— 已覆盖，残留 **0**

**实测依据**（逐例跑 pandoc + 管线真实方言，非推测）：

| 写法 | 结果 |
|:--|:--|
| `$\text{中文}$` | ✅ |
| `$\text{中\textbf{X}}$` | ❌ Could not convert，**整个公式不渲染** |
| **`$\text{中}\textbf{X}$`** | ✅ ← **修法依据：把内层命令提出 `\text{}`** |
| `$\text{中\mathrm{X}}$` | ❌（所以**不限 `\textbf`**，任何命令都坏） |
| `$\mathrm{中\textbf{X}}$` | ✅ ← **故规则必须锚定外层是 `\text`**，泛化到所有命令会误伤 |

规则入 `md_sanitize.fix_text_inner_cmd()`；顺带把既有的 `\text{\text{X}}` 压平规则**泛化**
（补「内层前后可有文本」「内层可带空白」，并改为迭代）。
全库复扫：**残留 0 处**。

### 二、新类：`\r` 家族断行 —— 与「`\t` → 真 TAB」是孪生形态

**机制**：导入把 `\r`（反斜杠 + r）当转义解析 ⇒ 变成真换行，
`\rm` / `\rho` / `\rightleftharpoons` 等**以 r 开头**的命令被从中间劈开：

```
原： … $\rm B(SH)_3$ |
坏： … $  /换行/  m B(SH)_3$ |
```

后果：上一行以**未闭合的 `$`** 收尾（数学域断裂）；**Markdown 表格行也被劈成两行**。

⭐ **还原统一是插入 `\r`** —— 污染永远只吃掉命令开头的 `\` 和 `r`；残尾只用于**识别**。

**三重护栏**（实测踩过才加的）：残尾 `m` **本身极弱** —— `$$` 块里的
`m v r = nh/2π`（Bohr 公式）、`m_{S} = 1, S = 1`（量子数）、中文散文 `m 为质量`
都以 `m ` 开头且**完全合法**。故要求：
① 上一行以 `$` 收尾且 `$` 计数为**奇数**（必是行内数学域被劈断）；
② 本行含 `$` 且以已知残尾 + 边界字符开头；
③ **级联吞并**后续残尾行（一行可含 2 个 `\rm` → 被劈成 3 行），最终 `$` 必须配平才落盘。
