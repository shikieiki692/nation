# Chemy 站点 id 校核器固化（2026-10-15 20:4x）

> 来源＝[[09-审计报告/2026-10-15-遗留项活化核验]] 提及的「方法学只活在报告叙述里」问题；owner「也可以吧」批准固化。

## 一 做了什么

把本轮散在 `.workbuddy/tmp/` 的 7 个一次性脚本（`chemy_site_id_verify / _within_set / _global_rank / _deep / _dset / _fix`、`chemy_find`）收敛为常驻工具：

**`.workbuddy/scripts/chemy_site_id_audit.py`** ＋ 白名单 **`.workbuddy/scripts/siteid_keep.json`**

```bash
python .workbuddy/scripts/chemy_site_id_audit.py --all            # 全量校核
python .workbuddy/scripts/chemy_site_id_audit.py --all --strict   # 非白名单异常 ⇒ 退出码 1
python .workbuddy/scripts/chemy_site_id_audit.py --all --report   # 落明细 CSV
```

**与旧法的关键差别**：站点 id **从卡正文的来源行读**（`> 来源：Chemy- 项目（…）\`chemy⟨届⟩-⟨套⟩-⟨题⟩\``），
**不再依赖 `2026-10-14-chemy卡级分桶.csv` 快照** ⇒ 覆盖 **1,908** 张（旧法只覆盖 CSV 里的 A/D 类 **996** 张）。
