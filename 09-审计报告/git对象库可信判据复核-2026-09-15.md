# git 对象库可信判据复核（2026-09-15）

> **结论先行**：**通过**。全覆盖 157,063 个可达对象 + 分层抽样 800 个（逐对象 `git cat-file -e`）
> **不可读合计 = 0**；108 个 pack **畸形/异常候选 = 0**。HEAD 与 `origin/master` 同为 `430353157`，无待推。

本仓库 `fsck` **不可信**（畸形 pack 的 `.idx` 空登记会让它漏报缺失，09-13 已定论），
因此唯一判据是 `git cat-file -e`。promisor 未取消时 `fsck` 还会制造"假绿"，本次已先确认
`remote.origin.promisor` / `remote.origin.partialclonefilter` **均未设置**。

## 二、复核方法（两级交叉验证）

1. **全覆盖判定**：`git rev-list --objects --all` 取全部可达对象，整批喂给
   `git cat-file --batch-check`（单进程、带 `--buffer`）。对不存在的对象该命令输出
   `<sha> missing` → 这是**全覆盖**判定，比抽样更强。
2. **分层抽样逐对象校验**：按 `commit` : `tree` : `blob` = **25% : 25% : 50%** 分层抽样
   （`seed=20260915`，计划 200 / 200 / 400 = **800** 个），对每个 SHA 单独跑
   `git cat-file -e`（逐对象子进程），与第 1 步交叉验证。
