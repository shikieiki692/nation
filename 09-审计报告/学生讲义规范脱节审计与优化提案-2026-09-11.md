## 二、四层断裂（核心诊断）

### L1 · 权威源双头：SOP 定义 schema，模板被指认为权威

`11-模板/README.md` 与 `模板-学生讲义.md` 均声明「**以 `学生讲义模板（v1.2 填充式）`（v5.3）为唯一权威**」。但实测 73 份讲义真正在用的 frontmatter 字段，几乎全部只定义在另一份文件里：

→ **产物服从的是 SOP，不是模板。规范层的"唯一权威"指认是错的。**

### L2 · 钦定样板自身不合规：规范是死的，样板才是活的

`学生讲义内容结构规划` §十 指定 `原子结构-超级充实版（自学完整）` 为**当前最成熟的 S2 样板**，全库照抄。实测该样板的 `##` 级结构：

```
学习目标 → 一、原子结构模型的发展 → 二、核外电子运动状态的描述
→ 三、基态原子核外电子排布 → 四、规律与方法
→ 五、典型例题 → 六、本节总结·速查 → 七、练习题 → 八、参考答案 → 九、延伸阅读
```

对照 v5.3 骨架（`模板-学生讲义.md` §标准结构序列 / `排版规范` §十）：

| v5.3 要求的节 | 样板是否有 | 全库实测覆盖率 |
|:---|:---:|---:|
| 认知冲突（3-4 条，每讲必设） | ❌ 无 | **4/73 (5%)** |
| 本讲小结 | ❌ 无（用"本节总结·速查"替代） | **19/73 (26%)** |
| 附：易错清单（≥3 条） | ❌ 无 | **2/73 (3%)** |
| 本讲速查 | △ 写作"本节总结·速查" | 17/73 (23%) |
| 典型例题 | ✅ 有（但编号为"五"而非"四"） | 35/73 (48%) |
| 延伸阅读 | △ 作正文节而非附录 | 24/73 (33%) |

**判定**：样板缺的三节，全库覆盖率恰好就是 5% / 26% / 3%。**规范不是被违反，是被样板架空了**——照样板写就一定不合规。
同理，SOP §八验收清单要求「易错清单 ≥3 条」，实测仅 2 份存在该字样 → **SOP 自己的验收清单对 97% 存量讲义不成立**。

### L3 · 体系表只覆盖 20%：`内容结构规划` §六 仍停留在"第一轮 15 讲"

`学生讲义内容结构规划`（**updated 2026-06-29**）§六 定义的第一轮 15 讲为：
气体与溶液 / 方程式书写专项 / 原子结构基础 / 分子结构基础 / 晶体学和晶体结构基础 / 配合物基础 / 有机分子结构初探 / 热力学初步 / 化学动力学初步 / 化学平衡 / 酸碱理论 / 沉淀溶解平衡 / 电化学 / 溶液与相图 / 定量化学分析入门。

## 五、优化提案：把一份"大而全模板"拆成三层

### 5.1 目标结构

```
A 层 · 硬约束（机器可校验，目标 100%）
   ├─ frontmatter schema 唯一化（以 SOP §四 为准，废模板独有字段）
   ├─ 图片：64 位哈希名、无 alt（脚本已能查）
   ├─ 无半截 math（已有 handout_fix_half_math.py）
   ├─ 题量下限（一个口径，见 D1）
   └─ stage 四态真正启用（或正式砍成两态）
   → 落到 11-模板/scripts/ 做成一个闸门脚本，进 CI

B 层 · 结构骨架（按讲义类型分档，不再一刀切）
   ├─ 主线讲次型（化学原理/结构化学主干）：全骨架
   ├─ 专项工具型（方程式书写、数学工具）：免 认知冲突/易错清单
   ├─ 桥梁收束型（物化综合计算、真题模拟拆解）：免 认知冲突
   └─ 工具卡型（数学工具各讲）：独立轻量骨架
   → 解决"规范要求 5% 覆盖率"的荒诞

C 层 · 样板
   └─ 重选或修补：原子结构补齐 认知冲突/本讲小结/易错清单，
      或改认 分子结构基础 / 配位化合物基础（模板索引评为 ★★★★★）为新样板
```
