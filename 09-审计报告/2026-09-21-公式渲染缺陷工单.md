## 四、怎么用这张工单

1. **先看「建议不修」的域** —— 那是原始 OCR 存档，修存档不如重新导入；
   把它们当作「导入质量」的观测值，**不要排进工作队列**。
2. **再从 P0/P1 往下做**，每改完一批就**复跑**（见文开头命令）刷新本表；
   份数下降即进度，新出现的项即回归。
3. ⚠️ **本批没有任何一份能被机械净化**（实测：`sanitize()` 改动量为 0）
   —— **全部得回原书/原式校正**。这不是「工具不够好」：
   这些缺陷的形态是「**公式本身被 OCR 打乱**」（多括号 `[\mathrm{L}}]`、
   缺下划线 `nH2O`、无效宏、串行 `\cdot L^{-1}H_3BO_3`），写不出可靠规则 ——
   强写规则就会重演「按形状猜」的错误（本工单的「可净化」列**已被这个错误坑过一次**）。
4. ⛔ **不许**为了「清零」把 `$` 删掉或把公式改成纯文本：那会把「渲染失败」
   变成「静默的内容丢失」，后者更坏。改不动就标存疑，不要假装修好。

## 五、本工单的边界（如实说明）

- 分组是**启发式**：依据是 texmath 报错片段（截断 90 字符），**不是**对源文件的二次解析；
  原因原文列保留在明细里，人工可复核/改判。
- **重型域默认不跑**：`04-题库/`（6020 份 ≈ 1 小时）未纳入本次体检；

### 🔴 一处**管线根治**（改一处、多份转绿）

**关掉 pandoc 默认开启的 `superscript` / `subscript`**（`PANDOC_EXTENSIONS` 末尾加 `-superscript-subscript`）。

机制（实测）：pandoc 的 markdown **默认**把正文里的 `^…^` / `~…~` 配成一对，
而本库正文大量书写「漏了 `$` 的 LaTeX 碎片」（**数学域外 `^` 1111 处 / `~` 8100 处**），于是：

1. **`^` 跨 `$` 配对** ⇒ `$` 配对整体位移 ⇒ 数学域不再被识别 ⇒ Word 出字面 `$`。
   受害件 `03-知识点/分析化学/氧化还原滴定.md` —— **零改 md 一个字即转绿**。
2. **`~` 被吞**（静默内容损坏，闸门测不到）：`条件：70~80℃，0.5~1 M H+` 原先渲成
   `条件：7080℃，0.51 M H+`（区间号消失、"80℃，0.5" 变下标）。**对教学材料是误导性错误。**

安全性（逐条实测，非推断）：全库有意的 `^词^` 上标 **0** 处、`~下标~` **0** 处（全扫描）；
`-subscript` 影响**单调**（只可能把被吞文本还原，不会新增 `$` 失效）；
回归：`^` 风险集（= 全部 **214** 份含域外 `^` 的文件）**全量**跑闸门 **5 → 5 无新增**；
`~` 风险集抽样 40 份零回归。

顺带修一处**工具缺陷**：`render_gate.py` 原先**本地硬编码**方言串，与管线漂移后会让
「改前/改后同一结果」（本批实测白跑一轮）。改为用 **AST 从管线源码读取**（不 import、无副作用）。

## 修复进展（2026-09-21 第四批 · 格式线）

### 又一处**根因**：`_parse_species()` 早退分支 —— 带电物种丢下标

这是本会话第三处「改一处、多份改善」的管线根因，也是**唯一一处改善量最多、却完全
不出现在闸门失败清单里**的缺陷（因为它只让公式**渲染得不对**，不让它**渲染不出来**）。

**病灶**（`build-all-handout-docx.py::_parse_species`）：

```python
if '^' in species or _has_explicit_subscript(species):
    s = _re.sub(r'\^' + _script_arg, r'^{\1}', species)
    s = _re.sub(r'_' + _script_arg, r'_{\1}', s)
    return s          # ← 规范化完 `^`/`_` 就返回，跳过了「裸数字补下标」
```

于是**凡是带电荷或带显式下标的物种，其余裸数字一律丢下标**：

| 源（md 里写的是 mhchem） | 转出 LaTeX | 应然 |
|:--|:--|:--|
| `\ce{MnO4^-}` | `MnO4^{-}` | `MnO_{4}^{-}` |
| `\ce{CO3^{2-}}` | `CO3^{2-}` | `CO_{3}^{2-}` |
| `\ce{[Cr(H2O)6]^{3+}}` | `[Cr(H2O)6]^{3+}` | `[Cr(H_{2}O)_{6}]^{3+}` |
| `\ce{Li_xC6}` | `Li_{x}C6` | `Li_{x}C_{6}` |

**库内自相矛盾**是判定它是缺陷、而非风格选择的铁证：同一个 `MnO4`，
`\ce{MnO4}`（无电荷）转出 `MnO_{4}`（有下标），`\ce{MnO4^-}`（带电荷）却转出 `MnO4`（无下标）；
而库内手写的 `\mathrm{MnO_4^{-}}` 一直是有下标的。

- **规模**：**455 处 / 101 份文件**（`03-知识点/有机化学` 43 份最多）。
- **修法**：早退分支末尾改 `_mask_cmds(s)`（补裸数字下标）。
- 连带修一处同族问题：**裸电荷正负号落在上标之外**（`Cr2O7^2-` → `Cr2O7^{2}-`，44 处）。
  🔴 该修法的负向先行断言不可省：全库另有 `R^1-X` / `R^2-CONHR^1` / `Ar^1-N=N-Ar^2`
  等**上标标号 + 连接号** 26 处，少了 `(?![A-Za-z0-9])`，`^1-` 会被并成 `^{1-}`、
  把连接号吞进上标。**这已是本会话第四次「按形状猜」被同类问题拦下**，故列为反向用例。
- 新增 `_mask_cmds()`：先掩码 LaTeX 命令再套下标规则，防 `\cdot5H2O` 的系数 5 被
  下标到命令上（`\cdot_{5}`）。实测全库「命令紧接数字」形态 = **0 处**，故纯防复发。

**自证中抓到并修掉一个我自己引入的回归**：`_mask_cmds` 初版在「无命令」时写成
`return s`，把常规分支的裸数字下标也一并跳过 ⇒ `PCl3` / `2H2O` / `H2O` 全丢下标。
**靠「实测校准」（先跑一遍真实输出、再写期望）发现**，已由单测的常规范式用例锁定。

**验证**：
- `test_ce_converter.py` 扩到 **28 项**（含 3 条 `R^n-` 反向用例、1 条命令尾数字反向用例、
  3 条常规范式防回归用例）→ 28/28 PASS。
- 受影响 **105 份**文件跑渲染闸门 → **PASS 105 / 失败 0**（无渲染回归）。
- 前后对照（HEAD 版管线 vs 本版）：`MnO4^{-}` sSub=1 → `MnO_{4}^{-}` sSub=2（OMML 里
  是 `sSubSup` 组合）；`[Cr(H2O)6]^{3+}` sSub 0 → 2；`R^1-CHO`、`PCl3` **逐字不变**。

> 确认 `old == new`，不是第四批引入的）。

### ① 多位数下标只吃第一位

规则 `([A-Za-z\)}])(\d)` 用了**单字符** `\d`，`H12` 被切成 `H_{1}2`。
全库 **36 处 / 15 份**：`\ce{C6H12O}` → `C_{6}H_{1}2O`、`C10H8`、`P4O10`、
`C21H53NO10`、`C12H22O11`；同族还有 `^{288}115`（同位素记号）→ `^{288}_{1}15`。
修法：`\d` → `\d+`。改后 `C6H12O6` → `C_{6}H_{12}O_{6}`、`^{288}115` → `^{288}_{115}`。

### ② 无箭头分支里，单独的 `+` / `-` 被当成带电荷物种

无箭头的 `\ce{}` 走 `s.split()`，`+` 也被当物种送进 `_parse_species`；
其 `charge_match = ([+\-])$` 会命中，base 为空串 ⇒ 产出 **`^{+}`**。
全库：无箭头 `\ce{}` 里的 ` + ` **113 处 / 34 份**（`\ce{SiF4 + 2F-}` → `SiF_{4} ^{+} 2F^{-}`）；
单独 `-` **15 处 / 6 份**（`\ce{NH4+ - NH3}` 缓冲对、`\ce{R3P^+ - CHR2^-}` 键号 → `^{-}`）。
修法：`parsed = [p if p in ('+', '-') else _parse_species(p) for p in parts if p]`。
箭头分支本就用 `\s\+\s` 做分隔符，不受影响。
**判据确认**：单独 `-` 在库里**逐条看过上下文**，全部是键号 / 分隔符（不是电荷），
故与 `+` 同等对待 —— 这是本会话第五次「先看全部实例再定规则」。

### 明确**排除**的一处（不改）

`[A-Za-z]\d[+\-]$` 形态 131 处，抽样全是 `MnO4-` / `ClO4-` / `HSO4-` 这类**阴离子**
（数字是真下标、电荷只是 `-`），现有处理 `MnO_{4}^{-}` 本就正确 ⇒ **无第三处缺陷**。

### 验证

- `test_ce_converter.py` 扩到 **37 项**（新增 ⑤多位数下标 ×5、⑥分隔符 ×4）→ 37/37 PASS。
- 受影响 **321 份**文件跑渲染闸门 → **PASS 321 / 失败 0**。
- 第四批修好的 14 项（`MnO4^-`、`R^1-X`、`\cdot5H2O`、常规式…）本轮**逐条复测仍全对**。

|:--|--:|--:|

## 修复进展（2026-09-21 第六批 · 格式线）

> 本批做两件事：补一类新缺陷（箭头标注），以及**把「渲染不对」从「靠临时换维度发现」
> 变成「闸门常驻判据」** —— 这是对前几批最要紧的收口。

### 一、新缺陷类 ⑭：箭头标注 `->[…]` 丢下标

`_preprocess_ce_in_math` 的 `_arrow_label()` 原先只在这一种情形下补下标：

```python
if _re.fullmatch(r'[A-Za-z0-9+\-.\s]+', body):   # ← 「无标点」才处理
    return _parse_species(body)
return body                                      # ← 带标点的一律原样返回 ⇒ 丢下标
```

全库 **370 个箭头标注中 129 个含「字母+数字」**，其中约 120 个因带 `/` `,` `(` `)`
而未补下标：

| 源 | 改前 | 改后 |
|:--|:--|:--|
| `->[Zn/H2O]` | `Zn/H2O` | `Zn/H_{2}O` |
| `->[H2O2, NaOH]` | `H2O2, NaOH` | `H_{2}O_{2}, NaOH` |
| `->[Pd(0)/Et3N]` | `Pd(0)/Et3N` | `Pd(0)/Et_{3}N` |
| `->[1) Hg(OOCCH3)_2, H_2O]` | 原样 | `1) Hg(OOCCH_{3})_{2}, H_{2}O` |
| `->[Pd(PPh3)4]` | `Pd(PPh3)4` | `Pd(PPh_{3})_{4}` |

**修法（单调）**：末行改 `return _parse_species(body)`（它只做「脚本规范化 + 裸数字补下标 +
裸电荷并组」，标点原样穿过）。**A/B 实测：52 种标注 / 96 处变化，逐条看过全部是改善。**

⚠️ **仍未动**：9 个**含中文**的标注（`->[Et2O 或 THF]`、`->[H2SO4, 氧化剂]`、
`->[Jones试剂 (CrO3/H2SO4, 丙酮)]` …）。它们现在被整体包进 `\text{}`（直立文本，
下标在里面出不来）。要修得先把标签切成「数学段 + 中文段」（`Et_{2}O \text{ 或 }THF`），
但那会改变**所有**中文标注的观感（直立 → 斜体）⇒ **属待定口径，请拍板**：
条件标签该用**直立体**（现状）还是**数学体**？

### 二、`_{…}` 之后的数字不再被下标（缺陷类 ⑮）

新增 `_SUBG_RE` 掩码「已成组的显式下标」，使 `\ce{S_N2}` → `S_{N}2`
（**`2` 是全尺寸**，反应类型记法），此前产出 `S_{N}_{2}`。
🔴 **只掩码 `_{…}`、不掩码 `^{…}`** —— 同位素 `^{288}115` 的 `115` **要**下标
（应成 `^{288}_{115}`）。全库该形态 7 处。

### 三、⭐ 把「渲染不对」做成闸门常驻判据（本批最关键）

前五批修的都是「渲染**失败**」，A 栏能查；而第四/五批修的**「渲染不对」全靠临时
换维度才发现** —— 这不可持续。本批把它做成 `render_gate.py` 的 **B 栏签名**：

```python
# B 欄是「签名 → 计数」字典，天然支持「只报新增」的回归比较；做成签名即自动进钩子。
n_ce = ce_invariant_violations(bh, text)
if n_ce:
    probs["ce{} 渲染不变量违例（数字丢下标 / 分隔符被抬）"] = n_ce
```

两条不变量（**判据独立于转换器实现**，只看「源 vs 转换结果」，不复刻规则）：
- **C1 下标守恒**：源里深度 0（不在 `{}` 内）的 ASCII「字母+数字串」必须成 `_{数字串}`；
- **C2 分隔符守恒**：源里 ` + ` / ` - ` 必须原样保留（不得变 `^{+}` / `^{-}`）。

两处**与管线同口径的豁免**：① `_{…}`（或裸 `_x`）之后的数字不要求下标（`S_N2` 的 `2`）；
② 箭头标注里含中文的走 `\text{}`，不计（即上面的待定口径）。

**效果**：全库 **2651 份 md / 4570 个 `\ce{}` 块 → 违例 0** ⇒ 新签名不误伤既有文件，
**只在新引入缺陷时响**。从此「渲染不对」这一类有了常驻哨兵，不必再靠人肉换维度。

### 四、🔴 自证盲区：我写死过一次闸门（如实报备）

给不变量写自证时，样例用了 `\ce{MnO4^-}`（**里面没有 LaTeX 命令**）→ 全绿。
但函数「跳过命令」分支漏了 `k += 1`（**反斜杠本身不是字母** ⇒ 内层 `while` 一步不走
⇒ **死循环**）：`--help` 正常、单文件正常，**一到含 `\cmd` 的 `\ce{}` 就整只闸门挂死**
（`timeout` 退出码 124、**无任何输出**，比报错更难查）。
已修 + 加**进度护栏** `i = j if j > i else i + 1`（宁可漏检，绝不挂死）。
自证样例补「`\ce{}` 内含命令」与整份真实文件两例，落库
`.workbuddy/scripts/test_ce_invariant.py`（6 项）。
**教训**：自证样例必须覆盖「你刚写的那个 `if` 的另一半」；工具里任何 `while` 都要护栏。

### 验证

- 单测：`test_ce_converter.py` **45 项** / `test_ce_invariant.py` **6 项** /
  `test_md_sanitize.py` 11 项 → **全通过**。
- 受影响 **321 份**跑渲染闸门（含新签名）→ **PASS 321 / 失败 0**。
- 全库 `\ce{}` A/B（HEAD vs 本版）：4570 块中 94 块变化，逐条核对全部是改善。
- 全库不变量普查：**2651 份 md，违例 0 份 / 0 条**。

## 修复进展（2026-09-21 第七批 · 格式线）

> 本批补掉上一批留下的**尾巴**（9 个中文标注 + 内嵌 `\text{}` 的标注），
> 并把上一批的验证做实：**产线最后一段没被闸门覆盖的环节，现在也验证过了**。

### 一、箭头标注 `_arrow_label` 统一化

改前是**三条互斥的早退分支**，每一类都有一批标注永远补不上下标：

| 形态 | 改前行为 | 后果 |
|:--|:--|:--|
| 含 `\text{` | **整条原样返回** | `->[\text{1) } CH3OK]` 的 `CH3` 永不补下标 |
| 含中文 | 整段包 `\text{}` | `->[Et2O 或 THF]` 的 `2` 出不来（`\text{}` 里没有下标） |
| 其余带标点 | 原样返回 | 上一批已修（约 120 处） |

改后为**单一流程**：
1. 剥外层 `$`；
2. **剥掉「整段恰好被一对花括号包住」的外壳** —— mhchem 里 `{…}` 只作分组
   （`->[{MnO2}]`、`->[{浓H2SO4}]`）。原先把 `{}` 一起包进 `\text{}`，产出畸形串
   `\text{{浓H}_{2}\text{SO}_{4}\text{}}`；
3. 已有 `\text{…}` 的片段**摘出保护**（不重包、不改），但其**外部**仍走 `_parse_species`
   补下标 ⇒ `\text{1) } CH3OK` → `\text{1) } CH_{3}OK`；
4. 纯命令标注（`\Delta`、`h\nu`）原样返回 —— 判据**收紧**为「把命令与分隔符都摘掉后
   什么都不剩」，否则 `\Delta,\,-N2` 会因首字符是 `\` 被误判、白丢 `N_{2}` 的下标；
5. **含中文的**补完下标后，把「非脚本片段」逐一包 `\text{}` ⇒ **观感仍是直立**
   （与改前完全一致），下标却回来了：`\text{Et}_{2}\text{O 或 THF}`。

**验证（两重）**：
- **A/B 全量**：4570 个 `\ce{}` 块中 **23 块变化 / 21 种**，逐条核对；
- **保守量判据**：剥掉结构符号（`{ } _ ^ $` 空格）与命令名后比对**骨架** ——
  23 块**骨架逐字相同**，命令集**只多不少**（只多 `\text`）⇒ **零内容增删**。

### 二、闸门判据收紧：标注**不再豁免**

第六批把箭头标注排除在「渲染不变量」之外（当时含中文的标注整体在 `\text{}` 里、
下标故意出不来）。标注统一化后**豁免已过时**，故整条 `\ce{…}`（含 `->[…]`）全部参与
C1（下标守恒）/ C2（分隔符守恒）。
**实测全库 2651 份 / 4570 块 → 违例 0** ⇒ 判据更强、且不误伤既有文件。
自证补一条「模拟『中文标注不下标』应被检出」的用例（现 7 项）。

### 三、补上「产线最后一段」的验证：后处理内容守恒
