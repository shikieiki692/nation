## 三、污染源分类清单（已全部归零）

| # | 污染源 | 表现 | 修法 |
|:--:|:--|:--|:--|
| 1 | `\ce` 转换器破坏希腊字母 | `C_\beta` → `C_{\}beta` | `_script_arg` 优先匹配完整 LaTeX 命令 |
| 2 | `\ce` 箭头标注二次包裹 | `\text{\text{…}}`、嵌套花括号截断 | `_arrow_label` 幂等 + `\x00N\x00` 占位符保护 |
| 3 | 反引号包裹数学 | `` `$…$` `` → code span，pandoc 不转 | 全库清除（含 `` `[A](t)` `` 含方括号变体） |
| 4 | 代码块里写公式 | ASCII/Unicode 原样输出 | 改 `$$…$$` / `aligned` / 编号列表 |
| 5 | 代码块里写 Markdown | `**加粗**` 明文、Step 被并成一段 | 转有序列表 + 补列表前空行 |
| 6 | 引用块内 `> ```mermaid` | 围栏失效，Obsidian 与 pandoc 都不识别 | 改流程链/编号列表；**脚本预检正则已加 `> ` 前缀容忍** |
| 7 | 定界符内侧空格 | `$ \ln x $` pandoc 不认 | 去内侧空格 |
| 8 | 半截公式 / 裸上下标 | `^{2}`、`_{i}` 未被 `$` 包裹 | 词级补 `$`（有 3 个陷阱，见下） |
| 9 | 正文 ASCII 反应箭头 | `--[H₂O₂]-->` | 改 Unicode `—(条件)→` |
| 10 | pandoc 不支持的命令 | `\textbf`、`\displaylines` | 去 `\textbf`；`\displaylines` 改 `aligned` |

### 词级补 `$` 的三个陷阱

1. 词边界 **不能含 `[` / `]` / `(` / `)`**，否则产生 `$4x^{2}/$($1-x$)^{2}` 这类半截公式。
2. 带列表前缀的 `- $$…$$` 会让 mask 失效，导致公式内再套 `$`（曾使 A 类从 4 涨到 47）。撤销用 `re.compile(r"\$\$(?!\$)(.*?)(?<!\$)\$\$")`。
3. 同一词内多个 `^{}` 会重复包裹 → 需 `done` 区间 + `if "$" in word: continue`。

## 七、关键教训

**连续 3 轮都「以为修完」，下一轮严格复检又查出几十处。** 根因：每轮 QA 只覆盖当时已知的维度，每扩一个维度就暴露一类新问题——

```
A/B 类公式泄漏
  → MD 残留 / HTML 注释
    → 代码块里写公式
      → 代码块里写 Markdown
        → 正文 ASCII 反应箭头
```

**收官前必须换维度再查一轮，不能只重跑同一套脚本。** 本报告的「产物陈旧性」「全库 `$` 奇偶」「等宽段普查」三项即为此新增。
