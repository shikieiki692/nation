## 一、触发与结论摘要

用户指出的问题：**「易错提醒／理解要点／深入思考」部分内容多余**，且
「写讲义不是乱写的，必须要有规范，参考教材和考纲，必须有意义，不是无效堆叠」。

实测结论（与"很多余"的印象部分不同，如实报告）：

| 判定 | 条数 | 占比 |
|:--|--:|--:|
| **A 保留**（有实义） | **196** | **91.2%** |
| **B 复述**（教材定义／正文结论的重新表述，零增量） | **5** | 2.3% |
| **C 薄壳**（只有一句口号或提问，脱离上下文不可解读） | **2** | 0.9% |
| **D 错位**（非教学内容被塞进教学板块名目下） | **1** | 0.5% |
| **E 空泛**（通篇不含化学信息） | **1** | 0.5% |
| **F 边缘**（有内容但应精简／加锚点） | 10 | 4.7% |

⇒ **绝大多数板块是有实义的**（口诀有记忆价值、真辨析、本质解释、操作判据、带反例）。
**真正需处理的只有 9 条（4.2%）**，且 **5 条集中在《气体基础》一份**（12 条里 5 条不合格）。

**但用户的诉求成立，只是环节不在"内容好坏"，而在"机制"**：见 §二 ——
**模板把「必写 × 每小节 × 一句话概括」写成了硬性要求，与语言规范的「禁止转述」直接冲突**，
这个冲突才是"凑数"的结构性来源，必须消除。

### 2.1 根因：三份规范互相冲突

| 规范 | 原文规定 | 后果 |
|:--|:--|:--|
| `11-模板/学生讲义模板（v1.2 填充式）.md` §1.1 | 学习闭环七环节：**「⑦ 理解要点 + 易错提醒（必写）」** | 把"写不写"变成硬性检查项 |
| 同上 §1.2⑦ | **「每个小节末尾**用 callout 给出」；内容＝**「本节最核心的 1~2 条规律，用一句话概括」** | **必写 × 每小节 + 一句话** ⇒ 结构性催生填充与复述 |
| `11-模板/讲义语言规范.md` §1.5 | 提示块内「出现**正文已有结论的转述（未新增信息）一律删除**」 | 与前两行**直接矛盾** |
| 同上 §2.1(b) | 「内容为正文结论的强调复述 → 删除」 | 同上 |
| 同上 §2.3 | 正式 callout 单讲总数 ≤ ⌈正文行数/100⌉ 且 ≤12 个 | 有密度上限，但与"每小节必写"冲突 |
| `11-模板/学生讲义内容结构规划.md` §7.3 | 「**数量只作参考，不作机械 KPI**」；「判断标准不是'字数够没够'」 | 第三套口径 |
| 同上 §七（S1 骨架） | 「认知冲突与易错清单**降为可选**（新建建议写，存量不补）」 | 与模板的"必写"**相反** |

**三份规范给出三种口径**：必写／禁止转述／可选。
写作时自然优先服从"检查项"（模板），于是产出复述与薄壳 —— **这不是写手不认真，是规范本身在互相抵消。**

> 「原骨架把认知冲突／易错清单列为必写，实测覆盖率仅 5%／3%，强制要求一个 97% 存量不满足的项等于规范失效」。

### 3.3 反面参照：同一批里做得好的

为免"一刀切砍板块"，列出**同批实测的优质板块**（应作为正例写进规范）：

- 《有效数字与误差分析》「深入思考：为什么用 $n-1$ 而不是 $n$？」——给自由度解释，是**真"为什么"**
- 《数学工具-第1讲》「深入思考：为什么一级反应的 c–t 图越来越平却永远不碰到横轴？」——指数衰减
- 《第八讲原子结构（三）》「深入思考：4s 先于 3d 是学生最容易困惑处 → 钻穿效应 + 酒店大堂类比」
- 《数学工具-第1讲》「易错提醒：分子是 ln(k₂/k₁)，分母是 1/T₂ − 1/T₁，下标顺序必须一致；写成 (1/T₁ − 1/T₂) 会得到负的活化能」——**判据 + 反例 + 自检**
- 《沉淀溶解平衡》「易错提醒：'Ksp 小则溶解度小'只对同类型沉淀成立，跨类型必须换算为 s」——真陷阱
- 《数学工具-第2讲》「易错提醒：2.303 陷阱」——把 lg/ln 混用这个具体错误点名

**共同特征**：给出**具体对象 + 判据 + 反例或量级**，而不是"再强调一遍结论"。

## 四、规范草案：板块准入四条

> 定位：作为 `11-模板/讲义语言规范.md` §1.5 的**扩展**（"转述清除"的判据细化），
> 并**同时**修订 `学生讲义模板（v1.2 填充式）` 的 §1.1/§1.2⑦ 与 `学生讲义内容结构规划.md` §7.3，消除冲突。

### 4.1 准入四条（全部满足才可写；缺一即删或改）

1. **具体性**：必须落到具体化学对象（物种、条件、数值、判据、反例），不得是"要重视／要注意"式空话。
2. **增量性**：不得与同一命题单元的正文逐字或换词重复（**这是既有 §1.5 的现成规则，本次将其判据具体化**）。
3. **锚点性**：可追溯到 ① 教材出处（按模板 §1.2② 的 `（参考教材《…》第X版 §X.X）` 格式），
   或 ② 考纲条目（**复用既有 `§码` 注册表格式**，见 `11-模板/讲义学习目标考纲锚点规范.md`），
   或 ③ 真题考点。**三者皆挂不上的，一律不写。**
4. **可操作性**：写成"判据 / 反例 / 自检"中至少一种，能让学生在考场里**执行**，而不只是"知道"。

### 4.2 判定树（写前自问，按序）

```
这一条能不能在正文里就地讲清？
 ├─ 能 → 不另开板块，在正文权威表述处加粗关键词（§1.5 既有规定）
 └─ 不能 → 它回答的是哪一类？
      ├─ 学生真的会这么错？ → 否 ⇒ 删（伪易错）
      ├─ 给的是"为什么"（机制/来源）？ → 是 ⇒ 深入思考，合格
      ├─ 给的是判据/反例/自检？ → 是 ⇒ 易错提醒，合格
      ├─ 只是把结论换个说法？ → 是 ⇒ 删（复述）
      └─ 属深度边界/考纲要求？ → 是 ⇒ 移位至学习目标区或深度分层表
```

### 4.3 🔴 新增维度：**轮次依赖**（本次实测新增，此前规范未提）

同一条板块在不同轮次的**有效性不同**：

| 例 | S1 基础班 | 第三轮冲刺班 |
|:--|:--|:--|
| 「升温有利于**吸热方向**」 | 必要（首次建立判据） | **冗余**（应删） |
| 「22.4 L/mol 只在标准状况成立」 | 必要 | 可压缩为一行 |
| 「2.303 陷阱（lg/ln 混用）」 | — | **必要**（此轮才大量用 ln） |

⇒ 规范须要求：板块**标注适用轮次**（可复用本库既有的 `serve_rounds` 字段口径），
或按轮次差异化删除。**"多不多余"不能脱离轮次判断** —— 这也是不能一刀切砍板块的理由。

### 4.4 密度与配比（承接 §2.3，不作 KPI）

- 密度上限沿用 `讲义语言规范.md` §2.3：单讲 ≤ ⌈正文行数/100⌉ 且 ≤12 个；连续 200 行 ≤3 个。
- **删除**模板 §1.1 的"⑦ 必写"与"每个小节末尾"两条 —— 改为「**按需，满足准入四条才写**」。
- **保留**结构规划 §7.3「数量只作参考，不作机械 KPI」为唯一数量口径。

### 4.5 机检线索（只缩圈，不终审）
