## 二、🔴 全库内嵌图缺失修复（2,970 → 6）

**问题**：早先切卡只处理 `![](images/…)` 形式的图片引用，**漏了表格内嵌的 `<img src="images/…">`** → 大量图未复制。

| 项 | 数值 |
|:--|--:|
| 图引用总数（两种形式） | 20,637 |
| **修复前缺失** | **2,970 条 / 486 张卡** |
| 按机构（卡数） | 清北营 136／汇智 79／壹尖培优 75／质心GChO 59／化英社 48／一式 25／伽马 19／chemy 17／质心UChO 16／方圆 7／北京夏令营 4／XeChem 1 |
| **已从源 `_images/` 按 hash 找回并复制** | **2,942 张** |
| 修复后缺失 | **6 条 / 2 卡**（伽马，源 `_images/` 无对应文件，不可恢复） |

> 🔴 **判据升级（已写入技能）**：图片完整性 QA **必须同时扫 `![](...)` 与 `<img src="...">` 两种引用**，否则会漏掉全部表格内嵌图。

## 三、CM-17 第 5/6/7 题重建（+2 卡）

**问题**：源 OCR（MinerU）把**第 5/6/7 题内容混排错序、题面标题丢失**——
第 6 题（细胞膜刚度）的正文被插在第 5 题的 `5-2-2` 与 `5-2-3` 之间；第 7 题各小问散落在第 5 题块尾。后果：

- CM-17 只有 **8 卡**（缺题 6、7）
- 第 5 题卡本身也**缺 5-3-1~5-3-5、5-4**（散失/错位）
- 第 5 题卡内混入题 6/7 正文，含被 OCR 成 `\mathrm{O}` 矩阵的 DMPC/DHPC 结构图（垃圾公式块）

**核验方法**：源 PDF `第40届chemy初赛模拟17试题.pdf` 为**纯扫描无文字层**（`pdftotext` = 0 字符），且**整页为一张扫描图**（`pdfimages -list` 仅页图 + 二维码）→ 改用 `pdftoppm` 渲染 + `PIL` 旋转 90° 后**逐页视觉核验**。

**重建依据**：`第40届chemy初赛模拟17答案.md` 的**各题顺序完好**（题 1/2/4/5/6/7/8/9/10 齐全），且**含题面复述 + 评分细则 + 配图**，故以它为准重建。

**结果**：

| 卡 | 结果 |
|:--|:--|
| `题-CM-17-05` | 题面重排（补回 5-3-1~5-3-5、5-4），清除混入的题 6/7 正文与垃圾公式块 |
| `题-CM-17-06` | **新建**（细胞膜及其刚度测量，17 分） |
| `题-CM-17-07` | **新建**（超分子自组装的选择性，29 分） |

- CM-17 补齐 **1~10 共 10 卡**；三卡均附 **源 PDF 题面页（第 4、5 页）** 供逐字核验。
- 每卡标注：「⚠️ 源 OCR 将第 5/6/7 题内容混排错序，本卡正文据源 PDF 与源答案文件重排」。
- **chemy 146 → 148；全库 2,900 → 2,902。**
