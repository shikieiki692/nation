## 一、证伪过程（三次修正）

### 1.1 第一次核验：错误的方法 → 得出「51/6978 命中，疑似大量丢失」

- 方法：扫 `媒体仓库/` 顶层文件名，比对被删图片 basename。
- 结果：命中 51，未命中 6927。
- **方法缺陷**：只扫了 `媒体仓库` 一层。该目录仅 11,089 文件（4 个子目录），容量上根本装不下 7,000 张图，此路不通。

### 1.2 第二次核验：全盘 basename → 「7068/7068 命中，零丢失」

- 方法：`os.walk` 全库建 basename 索引，再比对。
- 结果：**命中的 7068 项，未命中 0**。
- 结论：内容**确实存在**，是**迁移**而非删除。

### 1.3 第三次核验：追踪状态 → **发现致命问题**

- 方法：对每个 D 项，找出其实体现存位置，检查该位置是否在 `git ls-files` 中。
- 结果：

| 去向 | 数量 | 性质 |

| 新位置**已被 git 追踪** | **60** | ✅ 提交 D 安全 |
| 新位置在 `06-外部资料导入/`（未被忽略，但**未 add**） | **6997** | ⚠️ 必须先 add |
| 新位置在 `.workbuddy/backups/`（**被 .gitignore 忽略**） | **11** | ❌ 不可提交 |

## 四、修正后的提交方案

### ❌ 错误做法（原结论）

```bash
git add -A && git commit -m "教材迁移"   # 单边删除：旧删掉、新没进 → 7004 文件从版本库消失
```

### ✅ 正确做法：四步走

**Step 1 — 先让新位置入库**（关键前置）

```bash
git add "06-外部资料导入/一化 高中化学"
git add "06-外部资料导入/人教版教材"
git add "06-外部资料导入/结构化学基础"
git add "06-外部资料导入/"*.md   # 视需要
```

**Step 2 — 暂存删除**（只针对已确认迁移的四条）

```bash
git add -u "一化 高中化学" "（教师用）人教版高中化学课本" \
           "人教版高中化学课本" "结构化学基础"
```

**Step 3 — 提交前验证**（`git diff --cached --numstat` 应 A/D 成对）

**Step 4 — 提交**

> 用 `git add <具体路径>` 逐条 add，**严禁 `git add -A` / `git add .`**。
