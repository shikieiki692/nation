# 第一轮套卷 · 版式结构缺陷清单

> 范围：`04-课件/习题集/第一轮·竞赛教材版/`（31 份 md）+ `第一轮·综合套卷/`（25 份 md）。
> 起点：用户提出「套卷有很多无关和无用信息」后的**第六轮换维度复查**（前五轮已清 `> ` 引用行台账、
> 技术元信息行、题号交叉引用、答案区冗余前缀）。
> **性质：本轮扫出的是「版式结构缺陷」，不是「无用信息」** —— 改动涉及内容重组，风险较高，
> 故按用户拍板**先出清单、暂不改动**。

## 一、缺陷统计

| 类型 | 数量 | 说明 |
|---|---:|---|
| D 图紧贴无分隔（`]]![[` × ≥2） | 14 | 连续多图挤在一行，中间无空格/换行 |
| C 图夹在加粗语法内（`**文字![[图]]**`） | 1 | 图被 `**…**` 包住，渲染时图与加粗文字粘结 |
| E 步骤挤行含图 | 1 | 多个步骤编号挤一行，中间还插了图片 |
| **合计** | **16** | 涉及 3 个文件 |

## 三、典型样例

### 1. [C 图夹在加粗内] `第一轮结构·3-分子结构（教师版）.md` L558
```
**（攫 H 路径的产物）。![[6462c33a…jpg]]**原…
```
问题：`**` 未在文字后闭合即插入图片，末尾又出现 `**原` → 图片被吞进加粗段，且加粗不闭合。

### 2. [E 步骤挤行含图] `第一轮结构·3-分子结构（教师版）.md` L501
```
1. **7.1**：从产物逆推——B 与水生成 $\mathrm{N_2} + \mathrm{O_2}$（10:1）→ 推测 $\mathrm{N_5^+}$ 2. $\mathrm{A…
```
问题：`1.` `2.` `3.` 多个解题步骤挤在**同一行**，Markdown 无法识别为有序列表。

### 3. [D 图紧贴无分隔] `第一轮原理·5-化学平衡（教师版）.md` L771
```
**12H-NEC 立体异构体（6.3.3 剩余 8 种）![[04cd54c1…]]![[dc8b1517…]]…（共 8 张）
```
问题：一个小标题后紧跟 8 张图，全部同一行、无换行 → Word 导出后图会全挤在一段内。

### 4. [D 图紧贴无分隔] `第一轮结构·3-分子结构（教师版）.md` L684 / L693
```
1. 从投影图中原子与边框线的遮挡关系确定原子位置2. 晶胞内原子计数…3. Xe 化合价 = …
```
问题：步骤编号**无换行**（`位置2.` `计数3.`），列表结构丢失。

## 四、建议修法（待拍板后执行）

| 类型 | 修法 | 风险 |
|---|---|---|
| D 图紧贴 | 在 `]]![[` 之间插入 `\n\n`（各图独立成段） | 低：纯换行插入，不动内容 |
| C 图夹加粗 | 把图片移出 `**…**`，拆为 `**文字**\n\n![[图]]` | 低-中：需判断加粗边界 |
| E 步骤挤行 | 在 `数字.` 前插入换行使其成为有序列表 | 中：需避开公式/小数（`.5` 等）误切 |

**统一约束**：修改源为 `gen_r1.py::load()` 的 `q`/`a` 处理**还是**生成后置处理，需先定；
且改后必须复跑「题数 1,440 不变 / 配图引用数不变（346+360 相关）/ 双闸门 / docx 重出」全套验收。

## 五、未纳入清单的「假阳性」（已甄别，勿改）

| 现象 | 判定 |
|---|---|
| 题干正文与 `![[图]]` 同行（如 `**5.2.2** 写出化合物 A 的组成。![[…]]`） | 正常排版，**非缺陷** |
| 公式内数字间空格（`9. 9 9 \mathrm{mol}`） | 源题 OCR 产物，属**内容**而非版式，另行评估 |
| `见原卷` / `（依赖图片）` | 题干本身设计，**保留** |
