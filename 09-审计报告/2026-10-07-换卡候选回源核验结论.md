# 换卡候选回源核验结论（2026-10-07）

> **用途**：本线唯一遗留之一 —— A 类中 **15 张「须换卡」**（12 真交错 ＋ 2 仅题干回显 ＋ 1 假结构式）的
> **池内替代候选**（表见 `2026-10-07-A类待换卡替代建议.md`），逐张按 SOP ⓪ **回源视觉三元核验**。
>
> **铁律**：每一张候选卡都必须【对照原 PDF】核验「题目／图片／答案」三元；只信 OCR 中间产物一律判不合格。
>
> **方法**：① 候选卡按**完整文件名**解析（规避卡 ID 撞车）→ ② `source_file` 定位原 PDF（L0/L1，**可达 15/15**）→
> ③ 文字层可用的走 `fitz` **文字层精比对**（8-gram 覆盖）；扫描件**渲染后逐页目视**；④ 答案另核其**答案载体**（答案册/合订/裁图）。

## 三、结论与建议

1. **15 张候选题面回源全部吻合（15/15）** ⇒ 换卡源侧可行，**不存在"换上去也是坏卡"的普遍性风险**。
2. **两个必须处理的点**：
   - 🔴 **候选撞车**：#2（HYS-02-03-理想溶液）与 #6（HYS-02-07-万物始于分离）**首选候选同为 `题-HYS-02-03-钴氧体系…`** ⇒ 只能给一张；另一张须改选候选 **#2**（`题-QBY-02-02-易拉罐装可口可乐…`）。
   - ⚠️ **#4 答案偏弱**：候选 `题-HYS-01-06-下图是一种含Co…` 的答案是**源级 OCR 残缺**（6-1/6-2 无解答、含题面回显）⇒ 建议改选候选 **#2 `题-HYS-03-01-早期主族金属元素M…`**，或接受"裁图载部分解答"现状。
3. **可直接执行换卡的 13/15 张**（#1,#2,#3,#5,#7,#8,#9,#10,#11,#12,#13,#14,#15），另 2 张（#4/#6）先定改选方案。
4. 换卡**不改池规模**（一换一），换完后相关卷（如后续 XII+）按新池重出；**替换本身需 owner 拍板**（本报告只做候选核验，不执行替换）。

## 四、附：核验工具与可复现路径

| 工具 | 用途 |
|:--|:--|
| `resolve_swap_cand.py` | 解析替代建议 → 候选卡真实路径 + `source_file`（按完整文件名，避 ID 撞车） |
| `verify_text.py` | 文字层 PDF 的「卡 vs PDF」8-gram 覆盖精比对 |
| `pdf_contact.py` / `render_pages.py` | 扫描件缩略图拼版 / 单页渲染（`fitz`） |
| `aq.py` | 答案实质度（题面/答案长、回显比、非回显实质字） |
| `card_dump.py` | 卡 frontmatter＋题面/答案正文＋图片清单导出 |

> ⚠️ 判据坑（本轮新增）：**分节正则的结束前瞻不可用 `^##[ \t]*\S`**——它会误匹配 `###` 小标题，把题面截成空。
> 正解按 `[## 题目, ## 参考答案/答案)`、`[## 参考答案/答案, ## 知识点映射)` 界定。
> 另：候选清单文件经 Windows 换行落盘后含 `\r`，`$(cat)` 传入会污染参数 ⇒ 读入须 `.strip()`/`tr -d '\r'`。
