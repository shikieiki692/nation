# 习题书 Word 排版污染治理（2026-09-13）

## 一、起因

反馈：热力学一章两处格式错乱。

1. `1.61 NaCl生成热玻恩哈伯循环` 的公式在 Word 里以 `$$...$$` LaTeX 源码整段印出。
2. `1.1` 大豆发热量题的表格散成十几段纯文本，且 `质量分数 w_b/(` 后缺 `%`。

## 二、根因（3 类，均在导出管线，非题库内容）

| # | 根因 | 机制 | 影响面 |
|---|------|------|--------|
| R1 | **尺寸前缀 `\Big` 漏剥** | `build-all-handout-docx.py` 4b4 步只清了带 `l/r` 的 `\Bigl/\Bigr/\bigl/\bigr`，裸 `\Big` 漏网 → texmath 拒绝转换 → pandoc 回退成 TeX 源码 | 2 处（教师版+学生版同一题） |
| R2 | **raw HTML 表格不落 Word 表** | 源里是 `<table><tr><td>…`，pandoc 输出 docx 时只把单元格文字逐个摊成段落，不生成 `w:tbl` | 102 处 / 32 个源文件 |
| R3 | **texmath 不支持的宏** | `\atop`、`\xrightleftharpoons[a]{b}`、`\textcircled{}`、`\longrightleftharpoons`、math 内 HTML 实体 `&gt;`、math 内裸 `#`/`%` | 18 处 |

补充：`$w_b/(%)$` 里的 `%` 是 LaTeX 注释符，会把 `)$` 一起吃掉导致 `$` 未闭合，所以百分号在 Word 里凭空消失。

## 三、修复（全部落在 `11-模板/scripts/build-all-handout-docx.py`，未触碰 04-题库）

| 步骤 | 内容 |
|------|------|
| 0-pre（新增） | `_convert_html_tables()`：`<table>` → Markdown pipe table。保守条件：无 colspan/rowspan、无 `<br>`/图片、列数 1–8，不满足原样放过 |
| 4b4（改） | 尺寸前缀正则补齐 `Big/bigg/Bigm/bigm`，并加 `(?![a-zA-Z])` 守卫，避免误伤 `\bigcirc`/`\bigcup` |
| 4b7（新增） | `\textcircled{X}` → `\text{X}` |
| 4b8（新增） | `\xrightleftharpoons[下]{上}` → `\underset{下}{\overset{上}{\rightleftharpoons}}`。**必须用平衡括号扫描**——`\{([^{}]*)\}` 一遇 `\mathrm{p}K` 的内层 `{` 就整体失配（实测） |
| 4b8b（新增） | `\longrightleftharpoons` → `\rightleftharpoons` |
| 4b9（新增） | `\atop` → `\substack{A \\ B}` |
| 4b10（新增） | `_map_math_spans()`：只在 `$…$`/`$$…$$` 内反转义 HTML 实体，并把裸 `%`、`#` 转义为 `\%`、`\#` |

配套新增辅助函数：`_map_math_spans()`（行内 `$` 不允许跨行，避免误吞整段）、`_convert_html_tables()`。

### 5.4 玻恩-哈伯循环图语义不完整（内容问题）

源 `04-题库/教材习题/一分册能力测试/题-068-一分册测试-Ch4A-10-NaCl生成热玻恩哈伯循环.md` 里，循环图被拆成两个 `$$` 块：

- 块 1 只有「顶部横箭头 + 左右两个竖箭头」两行，**缺底部横箭头那一行**；
- 块 2 是 `Na(g)+Cl(g) →ΔH₂→ Na⁺(g)+Cl⁻(g) →ΔH₃→ NaCl(g)`，本应是循环的底边。

Word 里公式不再泄漏后，这个"图缺一条边"会变得更显眼。另 `NaCl(S)` 大写 S 应为小写 `s`，`(1 / 2)Cl_{2}` 建议改 `\frac{1}{2}`。
