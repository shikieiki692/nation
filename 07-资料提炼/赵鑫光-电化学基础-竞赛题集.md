## 例题 (10道)

### 例1 离子电子法配平 [初赛]

**(1) 酸性条件下 KMnO₄ 与 K₂SO₃ 反应**

$$2\text{KMnO}_4 + 5\text{K}_2\text{SO}_3 + 3\text{H}_2\text{SO}_4 = 2\text{MnSO}_4 + 6\text{K}_2\text{SO}_4 + 3\text{H}_2\text{O}$$

**配平思路：**

- 氧化半反应：$\text{SO}_3^{2-} - 2e^- \rightarrow \text{SO}_4^{2-}$
- 还原半反应：$\text{MnO}_4^- + 8\text{H}^+ + 5e^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}$
- 得失电子守恒：氧化×5 + 还原×2，消去电子

**(2) 热 NaOH 中 Cl₂ 的歧化**

$$3\text{Cl}_2 + 6\text{NaOH} = \text{NaClO}_3 + 5\text{NaCl} + 3\text{H}_2\text{O}$$

**配平思路：**

- 氧化半反应：$\text{Cl}_2 - 10e^- \rightarrow 2\text{ClO}_3^-$
- 还原半反应：$\text{Cl}_2 + 2e^- \rightarrow 2\text{Cl}^-$
- 得失电子守恒：氧化×1 + 还原×5

### 例2 Latimer 电位图计算 [决赛]

已知某元素在酸性溶液中的 Latimer 电位图：

$$E_1° = 0.535\text{V}, \quad E_2° = 0.76\text{V}, \quad E_3° = 0.52\text{V}$$

利用公式计算相邻电对之间的标准电极电势关系。对于不相邻电对，可用：

$$E°(B/D) = \frac{n_1 E_1° + n_2 E_2°}{n_1 + n_2}$$

其中 $n_1$、$n_2$ 分别为两步转移的电子数。

**关键点：** Latimer图中若某电对的 E° 右侧大于左侧，则该中间态可发生歧化反应。

### 例3 硫铁矿氧化 [初赛]

黄铁矿（FeS₂）在酸性溶液中被溶解氧氧化的5步反应：

$$\text{FeS}_2 \xrightarrow{O_2} \text{Fe}^{2+} + \text{S}_2\text{O}_3^{2-} \rightarrow \text{SO}_4^{2-} \rightarrow \cdots$$

最终产物为 Fe³⁺ 和 SO₄²⁻。

**Fe₂(SO₄)₃ 循环使用原理：**

- Fe³⁺ 作为氧化剂将 FeS₂ 氧化，自身被还原为 Fe²⁺
- Fe²⁺ 再被 O₂ 氧化再生为 Fe³⁺
- 总反应：$4\text{FeS}_2 + 15\text{O}_2 + 2\text{H}_2\text{O} = 2\text{Fe}_2(\text{SO}_4)_3 + 2\text{H}_2\text{SO}_4$

Fe₂(SO₄)₃ 起催化剂作用，构成自催化循环。

### 例4 原电池电极反应 (8种电池) [初赛]

**(1) Pt, H₂ | HCl | KCl | Hg₂Cl₂, Hg（甘汞电极）**

$$\text{负极：} \text{H}_2 - 2e^- \rightarrow 2\text{H}^+$$
$$\text{正极：} \text{Hg}_2\text{Cl}_2 + 2e^- \rightarrow 2\text{Hg} + 2\text{Cl}^-$$

**(2) Cu | Cu²⁺ || I⁻ | CuI, Cu**

$$\text{负极：} \text{Cu} - e^- \rightarrow \text{Cu}^+$$
$$\text{正极：} \text{Cu}^{2+} + e^- + \text{I}^- \rightarrow \text{CuI} \downarrow$$

**(3) CuI 电极**

利用 CuI/Cu 电对的电极电势，结合 Ksp(CuI) 计算实际电势。

**(4) Fe 浓差电池**

两极均为 Fe 电极，分别浸于不同浓度的 Fe²⁺ 溶液中：

$$E = E° + \frac{RT}{nF}\ln\frac{c_1(\text{Fe}^{2+})}{c_2(\text{Fe}^{2+})}$$

**(5) 锂离子电池**

$$\text{负极：} \text{LiC}_6 - e^- \rightarrow \text{Li}^+ + \text{C}_6$$
$$\text{正极：} \text{Li}_{1-x}\text{CoO}_2 + x\text{Li}^+ + xe^- \rightarrow \text{LiCoO}_2$$

**(6) 固体氧化物燃料电池（丙烷）**

$$\text{阳极：} \text{C}_3\text{H}_8 + 10\text{O}^{2-} - 20e^- \rightarrow 3\text{CO}_2 + 4\text{H}_2\text{O}$$
$$\text{阴极：} 5\text{O}_2 + 20e^- \rightarrow 10\text{O}^{2-}$$

**(7) 熔融碳酸盐燃料电池（甲醇）**

$$\text{阳极：} \text{CH}_3\text{OH} + 3\text{CO}_3^{2-} - 6e^- \rightarrow 4\text{CO}_2 + 2\text{H}_2\text{O}$$
$$\text{阴极：} \frac{3}{2}\text{O}_2 + 6e^- + 3\text{CO}_2 \rightarrow 3\text{CO}_3^{2-}$$

**(8) Ni-MH 电池**

$$\text{负极：} \text{MH} + \text{OH}^- - e^- \rightarrow \text{M} + \text{H}_2\text{O}$$
$$\text{正极：} \text{NiOOH} + \text{H}_2\text{O} + e^- \rightarrow \text{Ni(OH)}_2 + \text{OH}^-$$

### 例5 铀电位图与歧化 [决赛]

UO₂⁺ 在溶液中可发生歧化反应：

$$2\text{UO}_2^+ + 4\text{H}^+ \rightarrow \text{U}^{4+} + \text{UO}_2^{2+} + 2\text{H}_2\text{O}$$

歧化平衡常数：

$$K = 5.67 \times 10^{-52}$$

**分析：** K 极小说明 UO₂⁺ 在热力学上极难歧化，这与铀的电位图中相邻电对的 E° 差值密切相关。根据歧化条件：

$$E°_{\text{右}} < E°_{\text{左}} \implies \text{可歧化}$$

$$\lg K = \frac{n(E°_{\text{右}} - E°_{\text{左}})}{0.0592}$$

### 例6 铜电位图 [决赛]

**(1) Cu⁺ 歧化**

$$2\text{Cu}^+ \rightarrow \text{Cu} + \text{Cu}^{2+}$$

$$K = 2.8 \times 10^{12}$$

K >> 1，歧化反应强烈自发进行。

**(2) CuI 沉淀的影响**

$$K_{sp}(\text{CuI}) = 5.01 \times 10^{-12}$$

由于 CuI 极难溶，Cu⁺ 被 I⁻ 大量沉淀后，Cu²⁺/Cu⁺ 电对的电势显著降低：

$$E°(\text{Cu}^{2+}/\text{CuI}) = E°(\text{Cu}^{2+}/\text{Cu}^+) + 0.0592\lg\frac{1}{K_{sp}}$$

**(3) 2Cu²⁺ + 4I⁻ 的平衡**

$$2\text{Cu}^{2+} + 4\text{I}^- \rightleftharpoons 2\text{CuI} \downarrow + \text{I}_2$$

$$K = 7.61 \times 10^9$$

**关键结论：** I⁻ 既能还原 Cu²⁺，又能通过沉淀 Cu⁺ 推动反应正向进行，两者协同使平衡常数极大。

### 例7 金的氰化提炼 [决赛]

$$4\text{Au} + \text{O}_2 + 8\text{CN}^- + 2\text{H}_2\text{O} = 4[\text{Au(CN)}_2]^- + 4\text{OH}^-$$

$$\Delta G° = -405.62\text{ kJ}$$

**热力学驱动力分析：**

- Au³⁺/Au 标准电势 +1.50V，Au 极难被氧化
- 形成 [Au(CN)₂]⁻ 配合物后，Au⁺ 浓度极低
- 电极电势降低为 $E°(\text{Au}^+/\text{Au}) = 0.68\text{V}$（配合后）
- O₂ 作为氧化剂提供足够驱动力

$$E°_{\text{cell}} = E°(\text{O}_2/\text{OH}^-) - E°([\text{Au(CN)}_2]^-/\text{Au}) > 0$$

### 例9 MnO₄⁻ + Fe²⁺ 原电池 [初赛]

$$\text{MnO}_4^- + 5\text{Fe}^{2+} + 8\text{H}^+ \rightarrow \text{Mn}^{2+} + 5\text{Fe}^{3+} + 4\text{H}_2\text{O}$$

**(1) 标准电动势**

$$E° = E°(\text{MnO}_4^-/\text{Mn}^{2+}) - E°(\text{Fe}^{3+}/\text{Fe}^{2+}) = 1.51 - 0.77 = 0.74\text{V}$$

**(2) 标准平衡常数**

$$\lg K° = \frac{nE°}{0.0592} = \frac{5 \times 0.74}{0.0592} = 62.5$$

$$K° = 3.98 \times 10^{62}$$

**(3) pH = 2 时的实际电势**

$$E = E° + \frac{0.0592}{5}\lg\frac{[\text{MnO}_4^-][\text{H}^+]^8}{[\text{Mn}^{2+}]}$$

$$E = 1.51 + \frac{0.0592}{5}\lg(10^{-2})^8 = 1.51 - 0.189 = 1.32\text{V}$$

实际电池电动势 $E = 1.32 - 0.77 = 0.55\text{V}$

> **注意：** 题给 E = 0.69V 可能对应不同浓度条件，实际计算需根据具体浓度值。

### 例10 Cu-Ag 原电池 + H₂S [决赛]

**初始状态：**

$$\text{Cu} | \text{Cu}^{2+} (1\text{M}) || \text{Ag}^+ (1\text{M}) | \text{Ag}$$

$$E = E°(\text{Ag}^+/\text{Ag}) - E°(\text{Cu}^{2+}/\text{Cu}) = 0.80 - 0.34 = 0.46\text{V}$$

（题给初始值 0.453V，与标准值接近）

**通入 H₂S 后：**

Cu²⁺ + H₂S → CuS↓ + 2H⁺，Cu²⁺ 浓度骤降。

$$[\text{Cu}^{2+}] = \frac{K_{sp}(\text{CuS})}{[\text{S}^{2-}]} = 6.72 \times 10^{-14}\text{ mol/L}$$

$$E(\text{Cu}^{2+}/\text{Cu}) = 0.34 + \frac{0.0592}{2}\lg(6.72 \times 10^{-14}) = 0.34 - 0.393 = -0.053\text{V}$$

$$E_{\text{cell}} = 0.80 - (-0.053) = 0.853\text{V}$$

（题给终态值 0.833V，差异来自具体计算精度）

**结论：** H₂S 通过沉淀 Cu²⁺ 使 Cu 电极电势大幅下降，电池电动势从 0.453V 升至 0.833V。
