### 例1 活化能与温度敏感性 [初赛]

**标签**：[活化能, Arrhenius方程]

**题目**：在298 K时，反应A和反应B的活化能分别为 $E_a(\text{A}) = 50$ kJ/mol，$E_a(\text{B}) = 55$ kJ/mol。假设两反应的频率因子 $A$ 相同。
(1) 分别计算298 K时两反应的速率常数之比 $k_\text{A}/k_\text{B}$。
(2) 当温度升至308 K（升高10 K）时，计算两反应速率常数分别增大的倍数。
(3) 说明活化能相差仅5 kJ/mol为何会导致速率对温度敏感性的显著差异。

**答案**：

(1) 由Arrhenius方程 $k = A e^{-E_a / RT}$：

$$\frac{k_\text{A}}{k_\text{B}} = \frac{e^{-E_a(\text{A})/RT}}{e^{-E_a(\text{B})/RT}} = e^{(E_a(\text{B}) - E_a(\text{A}))/RT}$$

$$= e^{5000 / (8.314 \times 298)} = e^{2.018} = 7.53$$

反应A比反应B快约7.5倍。

(2) 温度升高10 K（298 K → 308 K），速率常数增大的倍数：

$$\frac{k(308)}{k(298)} = e^{\frac{E_a}{R}\left(\frac{1}{298} - \frac{1}{308}\right)} = e^{\frac{E_a}{R} \cdot \frac{10}{298 \times 308}}$$

对于反应A（$E_a = 50$ kJ/mol）：

$$\frac{k_\text{A}(308)}{k_\text{A}(298)} = e^{\frac{50000}{8.314} \times \frac{10}{298 \times 308}} = e^{0.6597} = 1.93$$

对于反应B（$E_a = 55$ kJ/mol）：

$$\frac{k_\text{B}(308)}{k_\text{B}(298)} = e^{\frac{55000}{8.314} \times \frac{10}{298 \times 308}} = e^{0.7257} = 2.07$$

(3) 活化能越大，速率常数对温度的敏感性越高。这是因为 $\ln k$ 对 $T$ 的关系式中，$E_a$ 出现在指数位置作为乘因子，使 $\Delta E_a = 5$ kJ/mol 的差异在升温时被指数放大。反应B的活化能更高，升高10 K后加速更明显（2.07倍 > 1.93倍），在更高温度区间这种差异更加显著。

### 例2 抗生素一级动力学 [初赛]

**标签**：[一级反应, 半衰期]

**题目**：某抗生素在人体内按一级动力学分解，速率常数 $k = 0.09629$ h⁻¹。
(1) 计算该抗生素的半衰期 $t_{1/2}$。
(2) 若初始血药浓度为 $c_0 = 8.0$ mg/mL，给药后5小时血药浓度为多少？
(3) 若有效最低浓度为2.0 mg/mL，该药物的有效作用时间约为多少？

**答案**：

(1) 一级反应半衰期公式：

$$t_{1/2} = \frac{\ln 2}{k} = \frac{0.6931}{0.09629} = 7.199 \text{ h} \approx 7.2 \text{ h}$$

(2) 一级动力学浓度-时间关系：$c = c_0 e^{-kt}$

$$c(5) = 8.0 \times e^{-0.09629 \times 5} = 8.0 \times e^{-0.4815} = 8.0 \times 0.6179 = 4.94 \text{ mg/mL}$$

(3) 当 $c = 2.0$ mg/mL 时：

$$t = \frac{\ln(c_0/c)}{k} = \frac{\ln(8.0/2.0)}{0.09629} = \frac{\ln 4}{0.09629} = \frac{1.3863}{0.09629} = 14.40 \text{ h}$$

即给药后约14.4小时内血药浓度高于2.0 mg/mL。

### 例3 HAc电离（0.1M与0.001M的pH和电离度）[初赛]

**标签**：[弱酸电离, 电离度]

**题目**：计算下列醋酸（HAc，$K_a = 1.75 \times 10^{-5}$）溶液的pH和电离度 $\alpha$：
(1) 0.10 mol/L HAc
(2) 0.0010 mol/L HAc

**答案**：

(1) 0.10 mol/L HAc：

检验近似条件：$c/K_a = 0.10 / (1.75 \times 10^{-5}) = 5714 > 400$，可近似。

$$[\text{H}^+] = \sqrt{K_a \cdot c} = \sqrt{1.75 \times 10^{-5} \times 0.10} = \sqrt{1.75 \times 10^{-6}} = 1.32 \times 10^{-3} \text{ mol/L}$$

$$\text{pH} = -\lg(1.32 \times 10^{-3}) = 2.88$$

$$\alpha = \frac{[\text{H}^+]}{c} = \frac{1.32 \times 10^{-3}}{0.10} = 1.32\%$$

(2) 0.0010 mol/L HAc：

检验近似条件：$c/K_a = 0.0010 / (1.75 \times 10^{-5}) = 57.1 < 400$，不可近似，须精确求解。

$$K_a = \frac{x^2}{c - x} \implies 1.75 \times 10^{-5} = \frac{x^2}{0.0010 - x}$$

解一元二次方程：$x^2 + 1.75 \times 10^{-5} x - 1.75 \times 10^{-8} = 0$

$$x = \frac{-1.75 \times 10^{-5} + \sqrt{(1.75 \times 10^{-5})^2 + 4 \times 1.75 \times 10^{-8}}}{2} = \frac{-1.75 \times 10^{-5} + 2.671 \times 10^{-4}}{2}$$

$$[\text{H}^+] = 1.248 \times 10^{-4} \text{ mol/L}$$

$$\text{pH} = -\lg(1.248 \times 10^{-4}) = 3.90$$

$$\alpha = \frac{1.248 \times 10^{-4}}{1.0 \times 10^{-3}} = 12.5\%$$

**结论**：浓度稀释100倍（0.10→0.0010 mol/L），$\alpha$ 从1.32%增大到12.5%，体现了稀释定律——稀释促进弱电解质电离。

### 例4 H₃PO₄ + NaOH 缓冲溶液（pH = 7.50）[初赛]

**标签**：[缓冲溶液, pH计算]

**题目**：以H₃PO₄和NaOH配制pH = 7.50的缓冲溶液。已知H₃PO₄的三级电离常数：$K_{a1} = 7.52 \times 10^{-3}$，$K_{a2} = 6.23 \times 10^{-8}$，$K_{a3} = 2.2 \times 10^{-13}$。
(1) 在pH = 7.50时，$[\text{HPO}_4^{2-}]/[\text{H}_2\text{PO}_4^-]$ 的比值为多少？
(2) 若配制1.00 L pH = 7.50的缓冲液，要求总浓度 $c(\text{H}_2\text{PO}_4^-) + c(\text{HPO}_4^{2-}) = 0.100$ mol/L，需称取多少克NaH₂PO₄·2H₂O（M = 156 g/mol）？需加入多少毫升1.00 mol/L NaOH？

**答案**：

(1) pH = 7.50时主要涉及第二步电离：

$$\text{pH} = \text{p}K_{a2} + \lg\frac{[\text{HPO}_4^{2-}]}{[\text{H}_2\text{PO}_4^-]}$$

$$7.50 = -\lg(6.23 \times 10^{-8}) + \lg\frac{[\text{HPO}_4^{2-}]}{[\text{H}_2\text{PO}_4^-]}$$

$$7.50 = 7.21 + \lg\frac{[\text{HPO}_4^{2-}]}{[\text{H}_2\text{PO}_4^-]}$$

$$\lg\frac{[\text{HPO}_4^{2-}]}{[\text{H}_2\text{PO}_4^-]} = 0.29$$

$$\frac{[\text{HPO}_4^{2-}]}{[\text{H}_2\text{PO}_4^-]} = 10^{0.29} = 1.95$$

(2) 设 $[\text{H}_2\text{PO}_4^-] = x$，$[\text{HPO}_4^{2-}] = 1.95x$

$x + 1.95x = 0.100$，解得 $x = 0.0339$ mol/L

$[\text{H}_2\text{PO}_4^-] = 0.0339$ mol/L，$[\text{HPO}_4^{2-}] = 0.0661$ mol/L

需NaH₂PO₄·2H₂O的总量：$0.100 \times 1.00 = 0.100$ mol

质量：$0.100 \times 156 = 15.6$ g

加入NaOH将部分H₂PO₄⁻转化为HPO₄²⁻：需NaOH = $0.0661 \times 1.00 = 0.0661$ mol

NaOH体积：$0.0661 / 1.00 = 66.1$ mL

### 例5 NaH₂PO₄/NH₄H₂PO₄混合溶液pH [决赛]

**标签**：[两性物质, pH计算]

**题目**：计算0.10 mol/L NaH₂PO₄和0.10 mol/L NH₄H₂PO₄混合溶液的pH。（已知 $K_{a1}(\text{H}_3\text{PO}_4) = 7.52 \times 10^{-3}$，$K_{a2}(\text{H}_3\text{PO}_4) = 6.23 \times 10^{-8}$，$K_a(\text{NH}_4^+) = 5.62 \times 10^{-10}$）

**答案**：

H₂PO₄⁻是两性物质，既能电离（给出H⁺）又能水解（接受H⁺）。在NaH₂PO₄ + NH₄H₂PO₄的混合溶液中，H₂PO₄⁻电离给出H⁺受 $K_{a2}$ 控制，而NH₄⁺也提供H⁺。

对于H₂PO₄⁻的pH，当浓度较大且酸碱反应方向一致时，可用近似公式：

$$[\text{H}^+] = \sqrt{K_{a1} \cdot K_{a2}}$$

这个公式适用于H₂PO₄⁻作为两性物质占主导的体系。代入：

$$[\text{H}^+] = \sqrt{7.52 \times 10^{-3} \times 6.23 \times 10^{-8}} = \sqrt{4.685 \times 10^{-10}} = 2.16 \times 10^{-5} \text{ mol/L}$$

$$\text{pH} = -\lg(2.16 \times 10^{-5}) = 4.67$$

**说明**：$\text{p}K_{a1} = 2.12$，$\text{p}K_{a2} = 7.21$，所以 $\text{pH} = (\text{p}K_{a1} + \text{p}K_{a2})/2 = (2.12 + 7.21)/2 = 4.67$。NH₄⁺的电离（$K_a = 5.62 \times 10^{-10}$）远小于 $K_{a2}$，对pH影响可忽略。

### 例6 BaSO₄沉淀判断（离子积Q与Ksp比较）[初赛]

**标签**：[沉淀, 离子积]

**题目**：在298K时，将等体积的0.010 mol/L BaCl₂溶液和0.010 mol/L Na₂SO₄溶液混合。
(1) 计算混合瞬间的离子积 $Q$。
(2) 已知 $K_{sp}(\text{BaSO}_4) = 1.1 \times 10^{-10}$（298K），判断是否有沉淀生成。
(3) 计算混合后溶液中 $\text{Ba}^{2+}$ 的残余浓度。

**答案**：

(1) 等体积混合后浓度各减半：

$[\text{Ba}^{2+}] = 0.010/2 = 5.0 \times 10^{-3}$ mol/L

$[\text{SO}_4^{2-}] = 0.010/2 = 5.0 \times 10^{-3}$ mol/L

$$Q = [\text{Ba}^{2+}][\text{SO}_4^{2-}] = (5.0 \times 10^{-3})^2 = 2.5 \times 10^{-5}$$

(2) $Q = 2.5 \times 10^{-5} \gg K_{sp} = 1.1 \times 10^{-10}$

**结论**：$Q > K_{sp}$，有BaSO₄沉淀析出。

(3) 由于 $K_{sp}$ 极小，沉淀几乎完全。设残余 $[\text{Ba}^{2+}] = s$：

$[\text{SO}_4^{2-}]$ 的减少量 ≈ 初始量（因沉淀近乎完全），但Ba²⁺和SO₄²⁻初始等量且化学计量比为1:1，所以沉淀后两者浓度近似相等：

$$s = \sqrt{K_{sp}} = \sqrt{1.1 \times 10^{-10}} = 1.05 \times 10^{-5} \text{ mol/L}$$

残余 $\text{Ba}^{2+}$ 浓度约为 $1.05 \times 10^{-5}$ mol/L，沉淀效率高达99.8%。

### 例7 AgCl沉淀洗涤损失与NH₄Cl抑制 [决赛]

**标签**：[沉淀洗涤, 同离子效应]

**题目**：在298K下用蒸馏水洗涤AgCl沉淀，每次用水200 mL，共洗3次。已知 $K_{sp}(\text{AgCl}) = 1.77 \times 10^{-10}$。
(1) 计算每次洗涤后溶解损失的AgCl质量。（M(AgCl) = 143.5 g/mol）
(2) 若改用0.10 mol/L NH₄Cl溶液洗涤，每次损失的AgCl质量为多少？
(3) 说明用NH₄Cl溶液洗涤的优势。

**答案**：

(1) 用蒸馏水洗涤：

$[\text{Ag}^+] = [\text{Cl}^-] = s$，$K_{sp} = s^2$

$$s = \sqrt{K_{sp}} = \sqrt{1.77 \times 10^{-10}} = 1.33 \times 10^{-5} \text{ mol/L}$$

每次洗涤200 mL，损失的AgCl质量：

$$\Delta m = s \times V \times M = 1.33 \times 10^{-5} \times 0.200 \times 143.5 = 3.82 \times 10^{-4} \text{ g} = 0.382 \text{ mg}$$

3次洗涤总损失：$3 \times 0.382 = 1.15$ mg

(2) 用0.10 mol/L NH₄Cl洗涤（同离子效应）：

设AgCl溶解度为 $s'$，则 $[\text{Ag}^+] = s'$，$[\text{Cl}^-] = 0.10 + s' \approx 0.10$ mol/L（因 $s'$ 极小）

$$K_{sp} = [\text{Ag}^+][\text{Cl}^-] = s' \times 0.10$$

$$s' = \frac{1.77 \times 10^{-10}}{0.10} = 1.77 \times 10^{-9} \text{ mol/L}$$

每次洗涤损失：

$$\Delta m' = 1.77 \times 10^{-9} \times 0.200 \times 143.5 = 5.08 \times 10^{-8} \text{ g} = 0.051 \text{ μg}$$

(3) NH₄Cl提供的Cl⁻通过同离子效应将AgCl溶解度降低了约7500倍（从 $1.33 \times 10^{-5}$ 降至 $1.77 \times 10^{-9}$ mol/L），洗涤损失可忽略不计。但须注意，洗涤后沉淀中残留的NH₄Cl会在后续灼烧时分解挥发，不会引入永久杂质。

### 例8 PbS溶解度（S²⁻水解影响）[决赛]

**标签**：[溶解度, 水解]

**题目**：计算PbS在纯水中的实际溶解度。已知 $K_{sp}(\text{PbS}) = 8.0 \times 10^{-28}$，S²⁻的水解常数 $K_{h1} = K_w/K_{a2}(\text{H}_2\text{S}) = 1.0 \times 10^{-14}/(1.3 \times 10^{-13}) = 0.077$，$K_{h2} = K_w/K_{a1}(\text{H}_2\text{S}) = 1.0 \times 10^{-14}/(1.0 \times 10^{-7}) = 1.0 \times 10^{-7}$。

**答案**：

PbS溶解平衡：$\text{PbS} \rightleftharpoons \text{Pb}^{2+} + \text{S}^{2-}$

S²⁻在水中发生强烈水解：

$\text{S}^{2-} + \text{H}_2\text{O} \rightleftharpoons \text{HS}^- + \text{OH}^-$，$K_{h1} = 0.077$

$\text{HS}^- + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{S} + \text{OH}^-$，$K_{h2} = 1.0 \times 10^{-7}$

由于 $K_{h1}$ 较大，S²⁻水解程度极高。设溶解度为 $s$：

$$[\text{Pb}^{2+}] = s$$

根据物料守恒：$[\text{S}^{2-}] + [\text{HS}^-] + [\text{H}_2\text{S}] = s$

由于 $K_{h1} = 0.077$ 较大，S²⁻大部分转化为HS⁻和H₂S。在近中性溶液中，设 $[\text{S}^{2-}] = y$，则：

$$[\text{HS}^-] \approx \frac{K_{h1}[\text{H}_2\text{O}]}{[\text{OH}^-]} \cdot y \approx K_{h1} \cdot y / [\text{OH}^-]$$

实际上，由于 $K_{h1}$ 较大，直接利用：

$$s = [\text{Pb}^{2+}] = s, \quad K_{sp} = s \cdot [\text{S}^{2-}]$$

需要考虑S²⁻的分步水解比例。设总硫浓度为 $s$，在纯水中 $[\text{OH}^-] \approx \sqrt{K_{h1} \cdot s}$（主要由第一步水解产生），最终利用逐级逼近法或简化估算：

由于水解极强，实际 $[\text{S}^{2-}]$ 远小于 $s$。近似认为大部分硫以HS⁻形式存在，则：

$$K_{sp} = s \cdot [\text{S}^{2-}]$$

利用平衡关系：$[\text{S}^{2-}] = \frac{s \cdot K_{a2}}{K_{a2} + [\text{H}^+]}$ 在中性附近 $[\text{H}^+] \approx 10^{-7}$，而 $K_{a2} \approx 1.3 \times 10^{-13}$，故 $[\text{S}^{2-}] \approx s \cdot K_{a2}/[\text{H}^+] = s \times 1.3 \times 10^{-6}$

$$K_{sp} = s \times s \times 1.3 \times 10^{-6}$$

$$s = \sqrt{\frac{K_{sp}}{1.3 \times 10^{-6}}} = \sqrt{\frac{8.0 \times 10^{-28}}{1.3 \times 10^{-6}}} = \sqrt{6.15 \times 10^{-22}} = 7.8 \times 10^{-11} \text{ mol/L}$$

**对比**：若不考虑水解，$s_0 = \sqrt{K_{sp}} = 2.83 \times 10^{-14}$ mol/L。考虑水解后溶解度增大约2760倍，说明S²⁻水解对PbS溶解度有重大影响。

### 例9 Mg(OH)₂缓冲液沉淀控制 [决赛]

**标签**：[沉淀控制, pH调节]

**题目**：在0.10 mol/L NH₃-NH₄Cl缓冲溶液（pH = 9.25）中，Mg²⁺的初始浓度为0.010 mol/L。判断是否有Mg(OH)₂沉淀生成。若要使Mg²⁺沉淀完全（残余浓度 ≤ 1.0 × 10⁻⁵ mol/L），溶液pH至少应调至多少？（已知 $K_{sp}[\text{Mg(OH)}_2] = 5.61 \times 10^{-12}$，$K_b(\text{NH}_3) = 1.76 \times 10^{-5}$）

**答案**：

(1) pH = 9.25时：

$$[\text{H}^+] = 10^{-9.25} = 5.62 \times 10^{-10} \text{ mol/L}$$

$$[\text{OH}^-] = K_w / [\text{H}^+] = 1.0 \times 10^{-14} / 5.62 \times 10^{-10} = 1.78 \times 10^{-5} \text{ mol/L}$$

离子积：

$$Q = [\text{Mg}^{2+}][\text{OH}^-]^2 = 0.010 \times (1.78 \times 10^{-5})^2 = 3.17 \times 10^{-12}$$

$Q = 3.17 \times 10^{-12} < K_{sp} = 5.61 \times 10^{-12}$

**结论**：pH = 9.25时，$Q < K_{sp}$，无Mg(OH)₂沉淀生成。

(2) 要使 $[\text{Mg}^{2+}] \leq 1.0 \times 10^{-5}$ mol/L，需满足：

$$[\text{OH}^-]^2 \geq \frac{K_{sp}}{[\text{Mg}^{2+}]} = \frac{5.61 \times 10^{-12}}{1.0 \times 10^{-5}} = 5.61 \times 10^{-7}$$

$$[\text{OH}^-] \geq 7.49 \times 10^{-4} \text{ mol/L}$$

$$[\text{H}^+] \leq \frac{1.0 \times 10^{-14}}{7.49 \times 10^{-4}} = 1.34 \times 10^{-11} \text{ mol/L}$$

$$\text{pH} \geq 10.87$$

即溶液pH至少需调至10.87，才能使Mg²⁺沉淀完全。在pH 9.25的缓冲液中无法实现定量沉淀，需改用NaOH等更强碱来提高pH。

### 例10 PbS/ZnS分步沉淀 [决赛]

**标签**：[分步沉淀, Ksp差异]

**题目**：溶液中Pb²⁺和Zn²⁺的浓度均为0.10 mol/L。通过控制溶液pH通入H₂S气体实现分步沉淀。已知 $K_{sp}(\text{PbS}) = 8.0 \times 10^{-28}$，$K_{sp}(\text{ZnS}) = 2.0 \times 10^{-22}$，$\text{H}_2\text{S}$ 的 $K_{a1} = 1.0 \times 10^{-7}$，$K_{a2} = 1.3 \times 10^{-13}$。在饱和H₂S溶液中（约0.10 mol/L），计算：
(1) PbS开始沉淀所需的最小S²⁻浓度。
(2) PbS开始沉淀时对应的溶液pH。
(3) 要使PbS完全沉淀（残余Pb²⁺ ≤ 1.0 × 10⁻⁵ mol/L）而Zn²⁺不沉淀，溶液pH应控制在什么范围？

**答案**：

(1) PbS开始沉淀条件：

$$[\text{S}^{2-}] \geq \frac{K_{sp}(\text{PbS})}{[\text{Pb}^{2+}]} = \frac{8.0 \times 10^{-28}}{0.10} = 8.0 \times 10^{-27} \text{ mol/L}$$

(2) H₂S二级电离给出S²⁻：

$$[\text{S}^{2-}] = \frac{K_{a1} \cdot K_{a2} \cdot [\text{H}_2\text{S}]}{[\text{H}^+]^2}$$

代入 $[\text{S}^{2-}] = 8.0 \times 10^{-27}$，$[\text{H}_2\text{S}] = 0.10$：

$$[\text{H}^+]^2 = \frac{K_{a1} \cdot K_{a2} \cdot [\text{H}_2\text{S}]}{[\text{S}^{2-}]} = \frac{1.0 \times 10^{-7} \times 1.3 \times 10^{-13} \times 0.10}{8.0 \times 10^{-27}} = \frac{1.3 \times 10^{-21}}{8.0 \times 10^{-27}} = 1.625 \times 10^{5}$$

$$[\text{H}^+] = 403 \text{ mol/L}$$

此结果不合理（说明PbS在极酸条件下即可沉淀）。实际上计算表明PbS极难溶，即使在强酸性条件下 $[\text{S}^{2-}]$ 极低也足以使PbS沉淀。

重新审视：正确的思路是PbS在任何合理的pH下都会沉淀，关键是让Zn²⁺不沉淀。

Zn²⁺开始沉淀所需S²⁻浓度：

$$[\text{S}^{2-}]_{\text{Zn}} = \frac{K_{sp}(\text{ZnS})}{[\text{Zn}^{2+}]} = \frac{2.0 \times 10^{-22}}{0.10} = 2.0 \times 10^{-21} \text{ mol/L}$$

ZnS开始沉淀时的pH：

$$[\text{H}^+]^2 = \frac{1.0 \times 10^{-7} \times 1.3 \times 10^{-13} \times 0.10}{2.0 \times 10^{-21}} = 6.5 \times 10^{-1}$$

$$[\text{H}^+] = 0.806 \text{ mol/L}$$

$$\text{pH} = -\lg(0.806) = 0.09$$

这表明ZnS在pH > 0.09时开始沉淀，而PbS在更低的S²⁻浓度就沉淀了。

(3) 要使PbS完全沉淀（$[\text{Pb}^{2+}] \leq 1.0 \times 10^{-5}$ mol/L）所需S²⁻：

$$[\text{S}^{2-}] \geq \frac{8.0 \times 10^{-28}}{1.0 \times 10^{-5}} = 8.0 \times 10^{-23} \text{ mol/L}$$

要使Zn²⁺不沉淀：

$$[\text{S}^{2-}] < \frac{2.0 \times 10^{-22}}{0.10} = 2.0 \times 10^{-21} \text{ mol/L}$$

即需要 $8.0 \times 10^{-23} < [\text{S}^{2-}] < 2.0 \times 10^{-21}$ mol/L。

对应的pH范围：由 $[\text{S}^{2-}] = \frac{K_{a1} K_{a2} [\text{H}_2\text{S}]}{[\text{H}^+]^2}$：

PbS完全沉淀的上限pH：

$$[\text{H}^+]_{\max}^2 = \frac{1.3 \times 10^{-21}}{8.0 \times 10^{-23}} = 16.25 \implies [\text{H}^+]_{\max} = 4.03 \implies \text{pH}_{\min} = -0.61$$

ZnS开始沉淀的pH：

$$[\text{H}^+]_{\min}^2 = \frac{1.3 \times 10^{-21}}{2.0 \times 10^{-21}} = 0.65 \implies [\text{H}^+]_{\min} = 0.806 \implies \text{pH}_{\max} = 0.09$$

**结论**：理论上pH ≤ 0.09时PbS完全沉淀而Zn²⁺不沉淀。考虑到实际操作的安全裕度，**pH应控制在 ≤ 1.33**（此时ZnS不沉淀而PbS完全沉淀），这与教材给出的分步沉淀条件一致。

### 机理例1：碘与氢气反应机理证明 [决赛]

**题目**：关于碘和氢的反应，实验证明分两步进行，其机理涉及碘分子和碘原子的快速平衡（$\mathrm{I}_{2} \rightleftharpoons 2\mathrm{I}$），和两个碘原子和一个氢分子间的有效碰撞的控制步骤（$\mathrm{H}_{2}+2\mathrm{I} \rightarrow 2\mathrm{HI}$）。试证明从这个机理所得到的速率方程式恰同按 $\mathrm{I}_{2}$ 和 $\mathrm{H}_{2}$ 直接反应的机理（即 $\mathrm{I}_{2}+\mathrm{H}_{2}=2\mathrm{HI}$）所得的速率方程式相同。

**解**：

碘和氢的反应式为 $\mathrm{H}_{2}+\mathrm{I}_{2}=2\mathrm{HI}$，速率方程式 $v=k[\mathrm{H}_{2}][\mathrm{I}_{2}]$，表现为二级反应。根据题意，反应历程是：

① $\mathrm{I}_{2} \rightarrow \mathrm{I}+\mathrm{I}$（快）$v_{1}=k_{1}[\mathrm{I}_{2}]$

② $\mathrm{H}_{2}+2\mathrm{I} \rightarrow 2\mathrm{HI}$（慢）$v_{2}=k_{2}[\mathrm{H}_{2}][\mathrm{I}]^{2}$

整个反应过程由慢反应决定反应速率：

③ $v=k_{2}[\mathrm{H}_{2}][\mathrm{I}]^{2}$

根据反应①可知，达平衡时 $K=\frac{[\mathrm{I}]^{2}}{[\mathrm{I}_{2}]}$；则

④ $[\mathrm{I}]^{2}=K[\mathrm{I}_{2}]$

以④代入③式得 $v=k_{2}K[\mathrm{H}_{2}][\mathrm{I}_{2}]$。在一定温度下，$k_{2}$ 和 $K$ 均为常数，令 $k'=k_{2}K$；则 $v=k'[\mathrm{H}_{2}][\mathrm{I}_{2}]$。

结论：从上述反应机理所得到的速率方程式恰同按 $\mathrm{I}_{2}$ 和 $\mathrm{H}_{2}$ 直接反应的机理所得的速率方程式相同，但两者的反应历程是不同的。

### 机理例2：光气分解反应速率证明 [决赛]

**题目**：已知反应 $\mathrm{COCl}_{2}=\mathrm{CO}+\mathrm{Cl}_{2}$ 的反应历程为：① $\mathrm{Cl}_{2} \rightleftharpoons 2\mathrm{Cl}$（快速平衡）；② $\mathrm{Cl}+\mathrm{COCl}_{2} \rightarrow \mathrm{CO}+\mathrm{Cl}_{3}$（慢）；③ $\mathrm{Cl}_{3} \rightleftharpoons \mathrm{Cl}_{2}+\mathrm{Cl}$（快速平衡）。试证明反应的速率为：$\frac{\mathrm{d}[\mathrm{CO}]}{\mathrm{dt}} = k[\mathrm{COCl}_{2}][\mathrm{Cl}_{2}]^{1/2}$

**解**：

因为反应速率取决于最慢的一步，所以由(2)式得：$\frac{\mathrm{d}[\mathrm{CO}]}{\mathrm{dt}} = k_{2}[\mathrm{Cl}][\mathrm{COCl}_{2}]$

由(1)式的平衡得 $K=\frac{[\mathrm{Cl}]^{2}}{[\mathrm{Cl}_{2}]}$，则 $[\mathrm{Cl}]=(K[\mathrm{Cl}_{2}])^{1/2}$，代入上式中：

$$\frac{\mathrm{d}[\mathrm{CO}]}{\mathrm{dt}} = k_{2}(K[\mathrm{Cl}_{2}])^{1/2}[\mathrm{COCl}_{2}] = k[\mathrm{COCl}_{2}][\mathrm{Cl}_{2}]^{1/2}$$

### 机理例3：设计符合速率方程的反应机理 [决赛]

**题目**：已知反应 $\mathrm{CO}+\mathrm{Cl}_{2} \rightarrow \mathrm{COCl}_{2}$ 的速率定律为 $\frac{\mathrm{d}[\mathrm{COCl}_{2}]}{\mathrm{dt}}=k[\mathrm{CO}][\mathrm{Cl}_{2}]^{3/2}$，其中最慢的一步为：$\mathrm{COCl}+\mathrm{Cl}_{2} \rightarrow \mathrm{COCl}_{2}+\mathrm{Cl}$。试设计一个符合上述速率定律的反应机理。

**解**：

设反应机理为：① $\mathrm{Cl}_{2} \rightarrow 2\mathrm{Cl}$（快）；② $\mathrm{CO}+\mathrm{Cl} \rightarrow \mathrm{COCl}$（快）；③ $\mathrm{COCl}+\mathrm{Cl}_{2} \rightarrow \mathrm{COCl}_{2}+\mathrm{Cl}$（慢）

由①得 $K_{1}=\frac{[\mathrm{Cl}]^{2}}{[\mathrm{Cl}_{2}]}$，$[\mathrm{Cl}]=(K_{1}[\mathrm{Cl}_{2}])^{1/2}$

由②得 $K_{2}=\frac{[\mathrm{COCl}]}{[\mathrm{CO}][\mathrm{Cl}]}$，$[\mathrm{COCl}]=K_{2}[\mathrm{CO}][\mathrm{Cl}]$

$$\frac{\mathrm{d}[\mathrm{COCl}_{2}]}{\mathrm{dt}} = k_{3}[\mathrm{COCl}][\mathrm{Cl}_{2}] = k_{3}K_{2}(K_{1}[\mathrm{Cl}_{2}])^{1/2}[\mathrm{CO}][\mathrm{Cl}_{2}] = k[\mathrm{CO}][\mathrm{Cl}_{2}]^{3/2}$$

### 机理例4：臭氧热分解反应速率方程 [决赛]

**题目**：臭氧热分解反应机理是：$(1)\mathrm{O}_{3}=\mathrm{O}_{2}+\mathrm{O}$（快）；$(2)\mathrm{O}+\mathrm{O}_{3}=2\mathrm{O}_{2}$（慢）。试写出该反应的速率方程式。

**解**：

该反应的速率方程式决定于慢反应的第(2)步，则 $v=k_{2}[\mathrm{O}][\mathrm{O}_{3}]$

由反应(1)的平衡得 $[\mathrm{O}]=K_{1}\frac{[\mathrm{O}_{3}]}{[\mathrm{O}_{2}]}$，代入上式：

$$v = k_{2}K_{1}[\mathrm{O}_{3}]\frac{[\mathrm{O}_{3}]}{[\mathrm{O}_{2}]} = k[\mathrm{O}_{3}]^{2}[\mathrm{O}_{2}]^{-1} \quad (k=k_{2}K_{1})$$

### 机理例5：H₂+Cl₂反应的稳态处理法 [决赛]

**题目**：化学反应 $\mathrm{H}_{2}(\mathrm{g})+\mathrm{Cl}_{2}(\mathrm{g}) \longrightarrow 2\mathrm{HCl}(\mathrm{g})$ 经历的反应过程为：$\mathrm{Cl}_{2}+\mathrm{M} \longrightarrow 2\mathrm{Cl}\cdot+\mathrm{M}$；$\mathrm{Cl}\cdot+\mathrm{H}_{2} \longrightarrow \mathrm{HCl}+\mathrm{H}\cdot$；$\mathrm{H}\cdot+\mathrm{Cl}_{2} \longrightarrow \mathrm{HCl}+\mathrm{Cl}\cdot$；$2\mathrm{Cl}\cdot+\mathrm{M} \longrightarrow \mathrm{Cl}_{2}+\mathrm{M}$。试用稳态处理法导出该反应的速率方程式。

**解**：

由给出的反应机理，可写出 HCl 的生成速率：

$$\frac{\mathrm{d}[\mathrm{HCl}]}{\mathrm{dt}} = k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] + k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] \tag{①}$$

由于自由基都很活泼，寿命很短，当反应达到稳定状态后，假定 $\frac{\mathrm{d}[\mathrm{Cl}\cdot]}{\mathrm{dt}}=0$，$\frac{\mathrm{d}[\mathrm{H}\cdot]}{\mathrm{dt}}=0$。

$$\frac{\mathrm{d}[\mathrm{Cl}\cdot]}{\mathrm{dt}} = 2k_{1}[\mathrm{Cl}_{2}][\mathrm{M}] - k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] + k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] - 2k_{-1}[\mathrm{Cl}\cdot]^{2}[\mathrm{M}] = 0 \tag{②}$$

$$\frac{\mathrm{d}[\mathrm{H}\cdot]}{\mathrm{dt}} = k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] - k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] = 0 \tag{③}$$

比较式②和式③，得 $[\mathrm{Cl}\cdot]=\left(\frac{k_{1}}{k_{-1}}[\mathrm{Cl}_{2}]\right)^{1/2}$ ④

将③和④式代入①式得：

$$\frac{\mathrm{d}[\mathrm{HCl}]}{\mathrm{dt}} = 2k_{2}\left(\frac{k_{1}}{k_{-1}}\right)^{1/2}\cdot[\mathrm{Cl}_{2}]^{1/2}\cdot[\mathrm{H}_{2}] = k[\mathrm{Cl}_{2}]^{1/2}\cdot[\mathrm{H}_{2}]$$

### 机理例6：H₂+Br₂反应速率方程推导 [决赛]

**题目**：对于反应 $\mathrm{H}_{2}(\mathrm{g})+\mathrm{Br}_{2}(\mathrm{g}) \longrightarrow 2\mathrm{HBr}(\mathrm{g})$，已知其反应机理如下：① $\mathrm{Br}_{2} \rightleftharpoons 2\mathrm{Br}$（快）；② $\mathrm{Br}+\mathrm{H}_{2} = \mathrm{HBr}+\mathrm{H}$（慢）；③ $\mathrm{H}+\mathrm{Br}_{2} = \mathrm{HBr}+\mathrm{Br}$（快）。试推出该反应的速率方程式。

**解**：

在反应机理中，第二步反应是慢反应，整个反应速率由它控制，所以 $v=k_{2}[\mathrm{Br}][\mathrm{H}_{2}]$

由第一步反应快速达到平衡，得 $[\mathrm{Br}]=(K_{1}[\mathrm{Br}_{2}])^{1/2}$

代入上式：$v = k_{2}K_{1}^{1/2}[\mathrm{Br}_{2}]^{1/2}[\mathrm{H}_{2}] = k[\mathrm{H}_{2}][\mathrm{Br}_{2}]^{1/2}$

### 机理例7：光气制备反应机理分析 [决赛]

**题目**：光气的制备反应为：$\mathrm{CO}(\mathrm{g})+\mathrm{Cl}_{2}(\mathrm{g})=\mathrm{COCl}_{2}(\mathrm{g})$，实验测得速率方程为 $\frac{\mathrm{d}[\mathrm{COCl}_{2}]}{\mathrm{dt}} = k[\mathrm{CO}][\mathrm{Cl}_{2}]^{3/2}$。其可能的反应机理为：① $\mathrm{Cl}_{2} \rightleftharpoons 2\mathrm{Cl}\cdot$（快平衡）；② $\mathrm{Cl}\cdot+\mathrm{CO} \rightleftharpoons \mathrm{COCl}\cdot$（快平衡）；③ $\mathrm{COCl}\cdot+\mathrm{Cl}_{2} \rightarrow \mathrm{COCl}_{2}+\mathrm{Cl}\cdot$（慢反应）。(1) 试说明这一机理与速率方程相符合；(2) 指出 $k$ 与机理中速率常数的关系。

**解**：

(1) 第三步是慢反应：$v = k_{3}[\mathrm{COCl}\cdot][\mathrm{Cl}_{2}]$

第一步平衡：$[\mathrm{Cl}\cdot] = \left(\frac{k_{1}}{k_{-1}}[\mathrm{Cl}_{2}]\right)^{1/2}$

第二步平衡：$[\mathrm{COCl}\cdot] = \frac{k_{2}}{k_{-2}}[\mathrm{Cl}\cdot][\mathrm{CO}]$

代入得：$v = k_{3}\left(\frac{k_{1}}{k_{-1}}\right)^{1/2}\frac{k_{2}}{k_{-2}}[\mathrm{CO}][\mathrm{Cl}_{2}]^{3/2} = k[\mathrm{CO}][\mathrm{Cl}_{2}]^{3/2}$ ✓

(2) $k=k_{3}\left(\frac{k_{1}}{k_{-1}}\right)^{1/2}\frac{k_{2}}{k_{-2}}$

### 机理例8：Fe²⁺被Cl₂氧化的机理判断 [决赛]

**题目**：$\mathrm{Fe}^{2+}$ 在水溶液中被 $\mathrm{Cl}_{2}$ 氧化，总反应式为 $2\mathrm{Fe}^{2+}+\mathrm{Cl}_{2} \longrightarrow 2\mathrm{Fe}^{3+}+2\mathrm{Cl}^{-}$。实验证明：当 $\mathrm{Fe}^{3+}$ 和 $\mathrm{Cl}^{-}$ 浓度增加时，总反应速率下降，试论证下列两种机理中哪一种符合实验事实？

(1) $\mathrm{Fe}^{2+}+\mathrm{Cl}_{2} \rightarrow \mathrm{Fe}^{3+}+\mathrm{Cl}^{-}+\mathrm{Cl}$（快平衡）→ $\mathrm{Fe}^{2+}+\mathrm{Cl} \rightarrow \mathrm{Fe}^{3+}+\mathrm{Cl}^{-}$（慢）

(2) $\mathrm{Fe}^{2+}+\mathrm{Cl}_{2} \rightarrow \mathrm{Fe}(\mathrm{IV})+2\mathrm{Cl}^{-}$（快平衡）→ $\mathrm{Fe}(\mathrm{IV})+\mathrm{Fe}^{2+} \rightarrow 2\mathrm{Fe}^{3+}$（慢）

**解**：

**按机理(1)**：$v=k_{2}[\mathrm{Fe}^{2+}][\mathrm{Cl}]$，由第一步平衡 $[\mathrm{Cl}]=\frac{k_{1}}{k_{1}'}\cdot\frac{[\mathrm{Fe}^{2+}][\mathrm{Cl}_{2}]}{[\mathrm{Fe}^{3+}][\mathrm{Cl}^{-}]}$

$$v = k_{2}\cdot\frac{k_{1}}{k_{1}'}\cdot\frac{[\mathrm{Fe}^{2+}]^{2}[\mathrm{Cl}_{2}]}{[\mathrm{Fe}^{3+}][\mathrm{Cl}^{-}]}$$

随 $\mathrm{Fe}^{3+}$ 和 $\mathrm{Cl}^{-}$ 浓度增加，速率下降 ✓

**按机理(2)**：$v=k_{4}[\mathrm{Fe}(\mathrm{IV})][\mathrm{Fe}^{2+}]$，由第一步平衡 $[\mathrm{Fe}(\mathrm{IV})]=\frac{k_{3}}{k_{3}'}\cdot\frac{[\mathrm{Fe}^{2+}][\mathrm{Cl}_{2}]}{[\mathrm{Cl}^{-}]^{2}}$

$$v = k_{4}\frac{k_{3}}{k_{3}'}\cdot\frac{[\mathrm{Fe}^{2+}]^{2}[\mathrm{Cl}_{2}]}{[\mathrm{Cl}^{-}]^{2}}$$

不能得出速率随 $\mathrm{Fe}^{3+}$ 浓度增加而下降的结论 ✗

**结论**：机理(1)能符合实验观测事实。

### 机理例9：NO与O₂反应的平衡态与稳态近似对比 [决赛]

**题目**：已知 $2\mathrm{NO}+\mathrm{O}_{2}=2\mathrm{NO}_{2}$ 的反应历程如下：$\mathrm{NO}+\mathrm{NO} \rightleftharpoons \mathrm{N}_{2}\mathrm{O}_{2}$（快）；$\mathrm{N}_{2}\mathrm{O}_{2}+\mathrm{O}_{2} \rightarrow 2\mathrm{NO}_{2}$（慢）。试分别用平衡态近似法和稳态近似法推导出反应的总速率方程。

**解**：

**平衡态近似法**：$v=k_{3}[\mathrm{N}_{2}\mathrm{O}_{2}][\mathrm{O}_{2}]$，第一步平衡 $[\mathrm{N}_{2}\mathrm{O}_{2}]=K_{1}[\mathrm{NO}]^{2}$

$$v = k_{3}K_{1}[\mathrm{NO}]^{2}[\mathrm{O}_{2}] = k[\mathrm{NO}]^{2}[\mathrm{O}_{2}]$$

**稳态近似法**：$\frac{\mathrm{d}[\mathrm{N}_{2}\mathrm{O}_{2}]}{\mathrm{dt}} = k_{1}[\mathrm{NO}]^{2} - k_{2}[\mathrm{N}_{2}\mathrm{O}_{2}] - k_{3}[\mathrm{N}_{2}\mathrm{O}_{2}][\mathrm{O}_{2}] = 0$

则 $[\mathrm{N}_{2}\mathrm{O}_{2}]=\frac{k_{1}[\mathrm{NO}]^{2}}{k_{2}+k_{3}[\mathrm{O}_{2}]}$

$$\frac{\mathrm{d}[\mathrm{NO}_{2}]}{\mathrm{dt}} = \frac{k_{1}k_{3}[\mathrm{NO}]^{2}[\mathrm{O}_{2}]}{k_{2}+k_{3}[\mathrm{O}_{2}]}$$

由于 $k_{3}[\mathrm{O}_{2}] \ll k_{2}$，故 $\frac{\mathrm{d}[\mathrm{NO}_{2}]}{\mathrm{dt}} \approx \frac{k_{1}k_{3}}{k_{2}}[\mathrm{NO}]^{2}[\mathrm{O}_{2}] = k[\mathrm{NO}]^{2}[\mathrm{O}_{2}]$

两种方法导出的结果基本上相同。

### 机理例10：乙醛热分解链式反应稳态法推导 [决赛]

**题目**：已知乙醛的热分解反应 $\mathrm{CH}_{3}\mathrm{CHO} \longrightarrow \mathrm{CH}_{4}+\mathrm{CO}$ 是链式反应：链引发 $\mathrm{CH}_{3}\mathrm{CHO} \xrightarrow{k_{1}} \mathrm{CH}_{3}\cdot+\mathrm{CHO}\cdot$；链传递 $\mathrm{CH}_{3}\cdot+\mathrm{CH}_{3}\mathrm{CHO} \xrightarrow{k_{2}} \mathrm{CH}_{4}+\mathrm{CH}_{3}\mathrm{CO}\cdot$；$\mathrm{CH}_{3}\mathrm{CO}\cdot \xrightarrow{k_{3}} \mathrm{CH}_{3}\cdot+\mathrm{CO}$；链终止 $\mathrm{CH}_{3}\cdot+\mathrm{CH}_{3}\cdot \xrightarrow{k_{4}} \mathrm{CH}_{3}\mathrm{CH}_{3}$。试用稳态法推导出 $\mathrm{CH}_{4}$ 生成速率。

**解**：

$\frac{\mathrm{d}[\mathrm{CH}_{4}]}{\mathrm{dt}} = k_{2}[\mathrm{CH}_{3}\cdot][\mathrm{CH}_{3}\mathrm{CHO}]$ ①

稳态条件：$\frac{\mathrm{d}[\mathrm{CH}_{3}\cdot]}{\mathrm{dt}} = k_{1}[\mathrm{CH}_{3}\mathrm{CHO}] - k_{2}[\mathrm{CH}_{3}\cdot][\mathrm{CH}_{3}\mathrm{CHO}] + k_{3}[\mathrm{CH}_{3}\mathrm{CO}\cdot] - 2k_{4}[\mathrm{CH}_{3}\cdot]^{2} = 0$ ②

代入①：$\frac{\mathrm{d}[\mathrm{CH}_{4}]}{\mathrm{dt}} = k_{2}\left(\frac{k_{1}}{2k_{4}}\right)^{1/2}[\mathrm{CH}_{3}\mathrm{CHO}]^{3/2} = k[\mathrm{CH}_{3}\mathrm{CHO}]^{3/2}$

### 机理例13：可逆基元反应稳态近似法 [决赛]

**题目**：某反应机理如下：① $\mathrm{A}+\mathrm{B} \underset{k_{1}'}{\overset{k_{1}}{\rightleftharpoons}} \mathrm{C}+\mathrm{D}$；② $\mathrm{C}+\mathrm{E} \xrightarrow{k_{2}} \mathrm{F}$。试以稳定态近似法导出反应的速率方程式，并讨论在什么情况下有 $\frac{\mathrm{d}[\mathrm{F}]}{\mathrm{dt}} = k\frac{[\mathrm{A}][\mathrm{B}][\mathrm{E}]}{[\mathrm{D}]}$ 和 $\frac{\mathrm{d}[\mathrm{F}]}{\mathrm{dt}} = k'[\mathrm{A}][\mathrm{B}]$。

**解**：

C 是中间产物，稳态近似：$k_{1}[\mathrm{A}][\mathrm{B}] = k_{1}'[\mathrm{C}][\mathrm{D}] + k_{2}[\mathrm{C}][\mathrm{E}]$

则 $[\mathrm{C}]=\frac{k_{1}[\mathrm{A}][\mathrm{B}]}{k_{1}'[\mathrm{D}]+k_{2}[\mathrm{E}]}$

$$\frac{\mathrm{d}[\mathrm{F}]}{\mathrm{dt}} = k_{2}[\mathrm{C}][\mathrm{E}] = \frac{k_{1}k_{2}[\mathrm{A}][\mathrm{B}][\mathrm{E}]}{k_{1}'[\mathrm{D}]+k_{2}[\mathrm{E}]}$$

当 $k_{1}'[\mathrm{D}] \gg k_{2}[\mathrm{E}]$ 时：$\frac{\mathrm{d}[\mathrm{F}]}{\mathrm{dt}} = k\frac{[\mathrm{A}][\mathrm{B}][\mathrm{E}]}{[\mathrm{D}]} \quad (k=\frac{k_{1}k_{2}}{k_{1}'})$

当 $k_{1}'[\mathrm{D}] \ll k_{2}[\mathrm{E}]$ 时：$\frac{\mathrm{d}[\mathrm{F}]}{\mathrm{dt}} = k'[\mathrm{A}][\mathrm{B}] \quad (k'=k_{1})$

**练习31.** 对于反应 $2\text{A} + \text{B} \rightarrow \text{C}$，利用初始速率法确定速率方程。实验数据如下：

| 实验 | $[\text{A}]_0$/mol·L⁻¹ | $[\text{B}]_0$/mol·L⁻¹ | $v_0$/mol·L⁻¹·s⁻¹ |
|:---|:---|:---|:---|
| 1 | 0.10 | 0.10 | 2.0 × 10⁻³ |
| 2 | 0.20 | 0.10 | 8.0 × 10⁻³ |
| 3 | 0.10 | 0.20 | 4.0 × 10⁻³ |

(1) 确定速率方程 $v = k[\text{A}]^m[\text{B}]^n$ 中的 $m$、$n$ 值。
(2) 计算速率常数 $k$。
(3) 当 $[\text{A}] = 0.30$ mol/L，$[\text{B}] = 0.15$ mol/L 时，初始速率为多少？

$$\frac{v_2}{v_1} = \left(\frac{[\text{A}]_2}{[\text{A}]_1}\right)^m \implies \frac{8.0 \times 10^{-3}}{2.0 \times 10^{-3}} = \left(\frac{0.20}{0.10}\right)^m \implies 4 = 2^m \implies m = 2$$

$$\frac{v_3}{v_1} = \left(\frac{[\text{B}]_3}{[\text{B}]_1}\right)^n \implies \frac{4.0 \times 10^{-3}}{2.0 \times 10^{-3}} = \left(\frac{0.20}{0.10}\right)^n \implies 2 = 2^n \implies n = 1$$

速率方程：$v = k[\text{A}]^2[\text{B}]$

(2) 由实验1数据：

$$k = \frac{v}{[\text{A}]^2[\text{B}]} = \frac{2.0 \times 10^{-3}}{(0.10)^2 \times 0.10} = \frac{2.0 \times 10^{-3}}{1.0 \times 10^{-3}} = 2.0 \text{ L}^2\text{·mol}^{-2}\text{·s}^{-1}$$

(3) $v = 2.0 \times (0.30)^2 \times 0.15 = 2.0 \times 0.090 \times 0.15 = 2.7 \times 10^{-2}$ mol·L⁻¹·s⁻¹

**练习32.** 某反应A → 产物，初始浓度 $c_0 = 1.00$ mol/L，不同时刻浓度如下：

| $t$/min | 0 | 10 | 20 | 30 | 40 |
|:---|:---|:---|:---|:---|:---|
| $c$/mol·L⁻¹ | 1.00 | 0.75 | 0.56 | 0.42 | 0.32 |

判断反应级数并求速率常数。

**答案**：

**一级检验**（$\ln c$ vs $t$ 应为直线）：

| $t$/min | 0 | 10 | 20 | 30 | 40 |
|:---|:---|:---|:---|:---|:---|
| $\ln c$ | 0 | -0.2877 | -0.5798 | -0.8675 | -1.1394 |

相邻间隔的 $\Delta(\ln c)$：-0.2877, -0.2921, -0.2877, -0.2719

近似等间隔，说明反应为一级。

$$k = -\frac{\Delta \ln c}{\Delta t} \approx \frac{0.2877}{10} = 0.0288 \text{ min}^{-1}$$

验证：$t = 40$ min时，$c = 1.00 \times e^{-0.0288 \times 40} = e^{-1.152} = 0.316$，与实验值0.32吻合。

**练习33.** 对于连续反应 $\text{A} \xrightarrow{k_1} \text{B} \xrightarrow{k_2} \text{C}$，其中 $k_1 = 0.10$ min⁻¹，$k_2 = 0.05$ min⁻¹，$[\text{A}]_0 = 1.0$ mol/L，$[\text{B}]_0 = [\text{C}]_0 = 0$。
(1) 写出中间体B的浓度随时间变化的表达式。
(2) 计算B达到最大浓度的时间和最大浓度值。

**答案**：

(1) A的一级衰减：$[\text{A}] = [\text{A}]_0 e^{-k_1 t}$

B的浓度方程（B由A生成、自身衰减）：

$$[\text{B}] = \frac{k_1 [\text{A}]_0}{k_2 - k_1}(e^{-k_1 t} - e^{-k_2 t})$$

代入数值（$k_1 = 0.10$，$k_2 = 0.05$，$k_2 < k_1$）：

$$[\text{B}] = \frac{0.10 \times 1.0}{0.05 - 0.10}(e^{-0.10t} - e^{-0.05t}) = -2.0(e^{-0.10t} - e^{-0.05t})$$

$$[\text{B}] = 2.0(e^{-0.05t} - e^{-0.10t})$$

(2) B最大浓度时 $d[\text{B}]/dt = 0$：

$$k_1 e^{-k_1 t_{\max}} = k_2 e^{-k_2 t_{\max}}$$

$$\frac{k_1}{k_2} = e^{(k_1 - k_2)t_{\max}}$$

$$t_{\max} = \frac{\ln(k_1/k_2)}{k_1 - k_2} = \frac{\ln(0.10/0.05)}{0.10 - 0.05} = \frac{0.6931}{0.05} = 13.86 \text{ min}$$

$$[\text{B}]_{\max} = 2.0(e^{-0.05 \times 13.86} - e^{-0.10 \times 13.86}) = 2.0(e^{-0.693} - e^{-1.386}) = 2.0(0.500 - 0.250) = 0.50 \text{ mol/L}$$

**练习35.** 对于链反应 $\text{H}_2 + \text{Br}_2 \rightarrow 2\text{HBr}$，其机理为：

传播：$\text{Br·} + \text{H}_2 \xrightarrow{k_p} \text{HBr} + \text{H·}$

$\text{H·} + \text{Br}_2 \xrightarrow{k_p'} \text{HBr} + \text{Br·}$

终止：$2\text{Br·} \xrightarrow{k_t} \text{Br}_2$

$$k_p[\text{Br·}][\text{H}_2] = k_p'[\text{H·}][\text{Br}_2]$$

$$v = 2k_p\sqrt{\frac{k_i}{k_t}} \cdot [\text{H}_2][\text{Br}_2]^{1/2}$$

### Section F：非选择题——Arrhenius计算（3题，练习36-38）

(2) 计算400 K时的速率常数。

$$\ln(16.0) = \frac{E_a}{8.314} \times \frac{50}{300 \times 350}$$

$$2.7726 = \frac{E_a}{8.314} \times 4.762 \times 10^{-4}$$

$$E_a = \frac{2.7726 \times 8.314}{4.762 \times 10^{-4}} = \frac{23.05}{4.762 \times 10^{-4}} = 48400 \text{ J/mol} = 48.4 \text{ kJ/mol}$$

(2) 由350 K数据计算400 K时的 $k$：

$$\ln\frac{k(400)}{k(350)} = \frac{48400}{8.314}\left(\frac{1}{350} - \frac{1}{400}\right) = 5821 \times 3.571 \times 10^{-4} = 2.079$$

$$\frac{k(400)}{k(350)} = e^{2.079} = 7.99$$

$$k(400) = 4.8 \times 10^{-2} \times 7.99 = 0.384 \text{ s}^{-1}$$

**练习40.** 在800 K时，反应 $\text{CO(g)} + \text{H}_2\text{O(g)} \rightleftharpoons \text{CO}_2\text{(g)} + \text{H}_2\text{(g)}$ 的 $K_c = 1.0$。将2.0 mol CO和3.0 mol H₂O置于10.0 L容器中加热至800 K。

(2) 若在平衡体系中再加入1.0 mol H₂O，重新计算平衡移动后各组分浓度。
(3) 说明H₂O的加入对CO转化率的影响。

$$x^2 = (0.20-x)(0.30-x) = 0.06 - 0.50x + x^2$$

CO₃²⁻分步水解：

**第一步水解**（主反应）：$\text{CO}_3^{2-} + \text{H}_2\text{O} \rightleftharpoons \text{HCO}_3^- + \text{OH}^-$

$$K_{h1} = \frac{K_w}{K_{a2}} = \frac{1.0 \times 10^{-14}}{5.6 \times 10^{-11}} = 1.79 \times 10^{-4}$$

设水解度为 $x$：

$$1.79 \times 10^{-4} = \frac{x^2}{0.10 - x} \approx \frac{x^2}{0.10}$$

$$x = \sqrt{1.79 \times 10^{-5}} = 4.23 \times 10^{-3} \text{ mol/L}$$

**第二步水解**（次要）：$\text{HCO}_3^- + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3 + \text{OH}^-$

$$K_{h2} = \frac{K_w}{K_{a1}} = \frac{1.0 \times 10^{-14}}{4.3 \times 10^{-7}} = 2.33 \times 10^{-8}$$

因 $K_{h2}$ 很小，第二步水解可忽略。

各物种平衡浓度：

| 物种 | 浓度/mol·L⁻¹ |
|:---|:---|
| $[\text{CO}_3^{2-}]$ | $0.10 - 4.23 \times 10^{-3} \approx 0.096$ |
| $[\text{HCO}_3^-]$ | $4.23 \times 10^{-3}$ |
| $[\text{OH}^-]$ | $4.23 \times 10^{-3}$ |
| $[\text{H}^+]$ | $K_w/[\text{OH}^-] = 2.36 \times 10^{-12}$ |
| $[\text{H}_2\text{CO}_3]$ | $K_{h2}[\text{HCO}_3^-]/[\text{OH}^-] \approx K_{h2} \approx 2.3 \times 10^{-8}$ |

pH = 14 - pOH = 14 - 2.37 = 11.63

---

**练习42.** 在298 K时，向含有0.010 mol/L Ca²⁺和0.010 mol/L Fe³⁺的混合溶液中，逐滴加入NaOH使pH缓慢升高。
(1) 计算Ca(OH)₂和Fe(OH)₃开始沉淀的pH。
(2) 计算Fe³⁺沉淀完全（残余 ≤ 1.0 × 10⁻⁵ mol/L）时的pH。
(3) 说明能否通过控制pH实现Ca²⁺与Fe³⁺的分离。

已知：$K_{sp}[\text{Ca(OH)}_2] = 5.5 \times 10^{-6}$，$K_{sp}[\text{Fe(OH)}_3] = 2.8 \times 10^{-39}$

**答案**：

(1) Ca(OH)₂开始沉淀：

$$[\text{OH}^-] = \sqrt{\frac{K_{sp}}{[\text{Ca}^{2+}]}} = \sqrt{\frac{5.5 \times 10^{-6}}{0.010}} = \sqrt{5.5 \times 10^{-4}} = 2.35 \times 10^{-2} \text{ mol/L}$$

$$\text{pOH} = 1.63, \quad \text{pH} = 12.37$$

Fe(OH)₃开始沉淀：

$$[\text{OH}^-] = \left(\frac{K_{sp}}{[\text{Fe}^{3+}]}\right)^{1/3} = \left(\frac{2.8 \times 10^{-39}}{0.010}\right)^{1/3} = (2.8 \times 10^{-37})^{1/3} = 6.54 \times 10^{-13} \text{ mol/L}$$

$$[\text{H}^+] = \frac{1.0 \times 10^{-14}}{6.54 \times 10^{-13}} = 0.0153 \text{ mol/L}$$

$$\text{pH} = 1.81$$

(2) Fe³⁺沉淀完全时：

$$[\text{OH}^-] = \left(\frac{2.8 \times 10^{-39}}{1.0 \times 10^{-5}}\right)^{1/3} = (2.8 \times 10^{-34})^{1/3} = 6.54 \times 10^{-12} \text{ mol/L}$$

$$\text{pOH} = 11.18, \quad \text{pH} = 2.82$$

(3) **分离方案可行**。Fe³⁺在pH = 1.81开始沉淀，pH = 2.82沉淀完全；而Ca²⁺要到pH = 12.37才开始沉淀。因此只需将pH调至3~4之间，即可使Fe³⁺定量沉淀而Ca²⁺完全留在溶液中。

**练习43.** 在298 K时，向含0.10 mol/L Ba²⁺的溶液中加入等体积的0.10 mol/L Na₂SO₄溶液（混合后各浓度减半为0.050 mol/L）。
(1) 计算BaSO₄的沉淀量（每升混合溶液沉淀多少克BaSO₄）。
(2) 若在混合前先向Na₂SO₄溶液中加入HCl使pH = 1.0，混合后Ba²⁺的沉淀量是否改变？
(3) 若改为向Na₂SO₄中加入0.050 mol/L EDTA，混合后Ba²⁺的沉淀量如何变化？

已知：$K_{sp}(\text{BaSO}_4) = 1.1 \times 10^{-10}$，$M(\text{BaSO}_4) = 233$ g/mol

**答案**：

(1) 混合后初始浓度：$[\text{Ba}^{2+}]_0 = [\text{SO}_4^{2-}]_0 = 0.050$ mol/L

因 $K_{sp}$ 极小，沉淀近乎完全。设残余浓度为 $s$：

$$s = \sqrt{K_{sp}} = \sqrt{1.1 \times 10^{-10}} = 1.05 \times 10^{-5} \text{ mol/L}$$

沉淀的Ba²⁺：$0.050 - 1.05 \times 10^{-5} \approx 0.050$ mol/L

沉淀BaSO₄质量：$0.050 \times 233 = 11.65$ g/L ≈ 11.7 g/L

(2) 加HCl使pH = 1.0，$[\text{H}^+] = 0.10$ mol/L。

SO₄²⁻ + H⁺ ⇌ HSO₄⁻，$K = 1/K_{a2}(\text{H}_2\text{SO}_4) = 1/(1.2 \times 10^{-2}) = 83.3$

H₂SO₄的第二步电离常数较大（$K_{a2} = 1.2 \times 10^{-2}$），在pH = 1.0时，SO₄²⁻部分转化为HSO₄⁻：

$$\frac{[\text{SO}_4^{2-}]}{[\text{HSO}_4^-]} = \frac{K_{a2}}{[\text{H}^+]} = \frac{1.2 \times 10^{-2}}{0.10} = 0.12$$

$$[\text{SO}_4^{2-}] = \frac{0.12}{1.12} \times 0.050 = 5.36 \times 10^{-3} \text{ mol/L}$$

游离SO₄²⁻浓度降低，BaSO₄溶解度增大，沉淀量略有减少。

具体计算：$[\text{Ba}^{2+}] = \sqrt{K_{sp}/[\text{SO}_4^{2-}]}$ 不适用（因Ba²⁺大量过量）。实际 $[\text{Ba}^{2+}]$ 仍约0.050 mol/L：

$$[\text{SO}_4^{2-}]_{eq} = K_{sp}/[\text{Ba}^{2+}] = 1.1 \times 10^{-10}/0.050 = 2.2 \times 10^{-9}$$

但总硫酸根守恒（包括HSO₄⁻）决定实际游离SO₄²⁻浓度。在pH 1.0时大量SO₄²⁻变为HSO₄⁻，但BaSO₄沉淀会"拉动"平衡。最终沉淀量几乎不受影响，因为 $K_{sp}$ 太小，即使部分SO₄²⁻被质子化，沉淀效率仍接近100%。

**结论**：pH = 1.0对BaSO₄沉淀量几乎无影响。

(3) 加入0.050 mol/L EDTA后：

EDTA与Ba²⁺形成稳定配合物：$\text{Ba}^{2+} + \text{EDTA}^{4-} \rightleftharpoons [\text{Ba(EDTA)}]^{2-}$，$K_f \approx 10^{7.8}$

EDTA浓度等于初始Ba²⁺浓度（0.050 mol/L），混合后为0.025 mol/L。Ba²⁺被EDTA强烈络合，游离 $[\text{Ba}^{2+}]$ 大幅降低：

$$[\text{Ba}^{2+}]_{free} = \frac{[\text{Ba(EDTA)}^{2-}]}{K_f \cdot [\text{EDTA}^{4-}]} \approx \frac{0.025}{10^{7.8} \times \text{微量}} \approx 10^{-10} \text{ mol/L}$$

$Q = [\text{Ba}^{2+}][\text{SO}_4^{2-}] \approx 10^{-10} \times 0.050 = 5 \times 10^{-12} < K_{sp}$

**结论**：EDTA络合了大量Ba²⁺，使游离 $[\text{Ba}^{2+}]$ 极低，BaSO₄不再沉淀或沉淀量极少。这说明络合剂可以通过降低游离金属离子浓度来阻止沉淀生成。
