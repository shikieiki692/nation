## 备注

1. **跳过原因（均为原书答案缺失）**：
   - 第 7 题（半导体元素 A~K 推断）：答案区「◎第7题(11分)」标题下为空白，且该范围无结构图可佐证；本线推演主链 A=Sn/B=SnCl₄/D=H₂SnO₃/E=SnH₄/F=SnMe₄/G=Me₃SnCl/H=SnS₂/I=SnS₃²⁻ 与题面自洽，但 K（橘红色固体，SnCl₂ 还原 Me₃SnCl 产物）无法独立确认，按纪律整题跳过，待回源。
   - 第 8 题（Pseudopelletierine 转化 A~G）：答案区「◎第8题(7分)」标题下空白，无图；A~G 需逐步画出七种结构，无原书对照风险高，跳过待回源。
2. **9-1 答案缺失补注**：原书 9-1(2分) 答案栏空白。9-甲酰基芴烯醇式使五元环恢复全共轭芳香体系，K 大于 1，选 a。题卡中已显式标注「非原书转录」。
3. **校勘（径改，均有验算）**：
   - 1-2 原书产物写 S₂O₃⁻，电荷不守恒（左 −8/右 −7），径改为 S₂O₃²⁻。
   - 2-1 原书 PbF₂ 溶解度算式把立方根整体漏写（S 写成 Ksp×(1/Ka)² 的线性式得 0.0831）。正确按 S³α² = Ksp（[F⁻]=2Sα）计算：α=6.26×10⁻³，S=(3.30×10⁻⁸/(4×6.26×10⁻³)²)^⅓ = 0.0594 mol·L⁻¹；溶解度结论（PbF₂ 大于 PbCl₂）不变。
   - 4-3 原书把返滴定消耗「10.90 mL」换算成 0.100 0×0.001 090×5（浓度重复相乘，10.90 mL×0.100 0 mol·L⁻¹ 已是 1.090×10⁻³ mol），致总电子量 0.025 54 与 HCOOH 0.191 0 mol·L⁻¹ 偏低。按电子守恒复算：总给电子能力 25.00＋5.45＝30.45 mmol，扣 Fe²⁺ 5.00、扣乙二醇 12.90 后 HCOOH＝(30.45−5.00−12.90)/2＝6.275 mmol，即 0.313 8 mol·L⁻¹（乙二醇 0.064 50 mol·L⁻¹ 不受影响，与书一致）。
   - 3-1 原书算式 OCR 乱码（Kp 0.1899/0.1877 并存、「4.658×10⁴」等），题卡按正确过程重写：Kp°=0.1877，x=2.582×10⁴ Pa，总压 9.852×10⁴ Pa。
   - 3-2 原书方程 −RTln(1.936×10⁻⁴·T)＝6.599×10⁴−207.4T 完整，但未给出终解（文本截断）。本线补解 T≈285 K，题卡已标注「非原书转录」。
4. **题面 OCR 缺陷照录**：2-4-2「λ 与 B」应为「A 与 B」；10-2 第 3 小题编号「10-2.9」应为「10-2-3」。题卡中已按文意转写并注。
