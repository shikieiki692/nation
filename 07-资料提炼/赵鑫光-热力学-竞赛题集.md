### 例1 H₂+O₂→H₂O(g) ΔH与ΔU [决赛]

**题目**：2mol H₂和1mol O₂，在373K和101.3kPa下反应生成2mol水蒸气，放出483.7kJ的热量。求生成1mol水蒸气时的ΔH和ΔU。

**答案**：
恒压反应：$\Delta H = Q_p = -483.7/2 = -241.9$ kJ/mol

气体物质的量变化：$\Delta n = 2 - 3 = -1$ mol

膨胀功：$p\Delta V = \Delta nRT = (-1) \times 8.314 \times 373 = -3.1$ kJ

生成1mol H₂O(g)：$p\Delta V = -3.1/2 = -1.55$ kJ/mol

$\Delta U = \Delta H - p\Delta V = -241.9 - (-1.55) = -240.35$ kJ/mol

### 例2 NaCl/AgCl溶解ΔG [决赛]

**题目**：计算298K时NaCl和AgCl溶解过程的$\Delta G_{\text{溶}}^{\ominus}$，并对其溶解性进行合理的解释。

| | NaCl | AgCl |
|:---|:---:|:---:|
| $\Delta H_{\text{溶}}^{\ominus}$ (kJ/mol) | 3.620 | 65.50 |
| $\Delta S_{\text{溶}}^{\ominus}$ (J/(mol·K)) | 42.76 | 33.56 |

**答案**：
NaCl：$\Delta G_{\text{溶}}^{\ominus} = 3.620 - 298 \times 42.76/1000 = -9.122$ kJ/mol（自发）

AgCl：$\Delta G_{\text{溶}}^{\ominus} = 65.50 - 298 \times 33.56/1000 = +55.50$ kJ/mol（不自发）

两者$\Delta S_{\text{溶}}^{\ominus} > 0, \Delta H_{\text{溶}}^{\ominus} > 0$。NaCl溶解过程熵变项的贡献使$\Delta G_{\text{溶}}^{\ominus}$为负，虽然吸热但仍自发。AgCl溶解过程中熵变的贡献不足以使$\Delta G_{\text{溶}}^{\ominus}$为负，故难溶。

### 例3 Li+冰→LiOH [决赛]

**题目**：将10g金属锂置于100g 0℃的冰块上，确定100℃时由溶液中沉淀的氢氧化锂一水合物的质量。

反应：$2\text{Li}(s) + 2\text{H}_2\text{O}(l) = 2\text{LiOH}(s) + \text{H}_2(g)$，$\Delta H = -398.2$ kJ/mol

已知：冰的熔化热330 kJ/kg，水的比热4.200 kJ/(kg·K)，水的汽化热2300 kJ/kg，LiOH的比热49.58 J/(mol·K)，100℃时一水合LiOH溶解度19.1g

**答案**：
反应放热：$Q = 10/7/2 \times 398.2 = 284.43$ kJ
消耗水：$m_1 = 10/7 \times 18 = 25.71$ g
生成LiOH：$m_2 = 10/7 \times 24 = 34.28$ g（$n_2 = 1.43$ mol）

热量分配：熔冰33 kJ；水升温31.20 kJ；LiOH升温7.09 kJ
剩余热量：$Q_4 = 284.43 - 33 - 31.2 - 7.09 = 213.14$ kJ
可蒸发水量：$213.14/2300 \times 1000 = 92.7$ g，而所剩水量仅74.29 g

**结论**：产物中为氢氧化锂固体而无一水合物。

### 例4 Mg₃N₂盖斯定律 [决赛]

**题目**：金属镁粉在纯氮气中加热得到Mg₃N₂和Mg的混合物，含氮18.73%。通过三组量热实验数据，求$\Delta_f G_m^{\ominus}(\text{Mg}_3\text{N}_2(s))$。

已知$\Delta_f G_m^{\ominus}(\text{NH}_3(g)) = -46.1$ kJ/mol，水的饱和蒸气压23.0 mmHg，水的摩尔蒸发热43.93 kJ/mol

**答案**：
设计热化学循环：① = 3×③ + 2×④ + 2×⑤ - ②

$\Delta_f H_m^{\ominus}(\text{Mg}_3\text{N}_2(s)) = 3 \times (-468.5) + 2 \times (-87.9) + 2 \times (-46.1) - (-1192.7) = -480.8$ kJ/mol

由$\Delta_f G_m^{\ominus} = \Delta_f H_m^{\ominus} - T\Delta_f S_m^{\ominus}$，结合熵数据求得$\Delta_f G_m^{\ominus}(\text{Mg}_3\text{N}_2(s)) \approx -410$ kJ/mol。

### 例5 Al₂O₃碳还原 [决赛]

**题目**：计算以下两个反应的$\Delta H^{\ominus}$、$\Delta G_{298}^{\ominus}$和$\Delta S^{\ominus}$，讨论焦炭还原炼制铝的可能性。

**答案**：

**结论**：焦炭还原Al₂O₃的转换温度 $T = 2171.47/0.63506 = 3419$ K，工业上很难实现。

### 例6 辛烷合成Kp [决赛]

**题目**：在298K下，由C(石墨)和H₂(g)生成正辛烷C₈H₁₈(g)的反应，已知：

$$\Delta H_{m1}^{\ominus} = -5512.4 \text{ kJ/mol (辛烷燃烧)}$$
$$\Delta H_{m2}^{\ominus} = -393.5 \text{ kJ/mol (C燃烧)}$$
$$\Delta H_{m3}^{\ominus} = -285.8 \text{ kJ/mol (H₂燃烧)}$$

正辛烷、H₂、C的标准熵：463.7, 130.6, 5.694 J/(K·mol)

(1) 求$K_p^{\ominus}$；(2) 增压是否有利？(3) 升温是否有利？(4) 平衡摩尔分数能否达到0.1？(5) 摩尔分数达到0.5需要多大压力？

**答案**：
$\Delta_r H_m^{\ominus} = -207.8$ kJ/mol，$\Delta_r S_m^{\ominus} = -757.25$ J/(mol·K)
$\Delta_r G_m^{\ominus} = -207.8 - 298 \times (-0.75725) = 17.861$ kJ/mol

$K_p^{\ominus} = \exp(-\Delta_r G_m^{\ominus}/RT) = 7.40 \times 10^{-4}$

(2) $\Delta n = -8$，增压有利于正辛烷生成
(3) $\Delta_r H_m^{\ominus} < 0$，升温不利于生成
(4) $Q_p = 0.1/0.9^9 = 0.258 \gg K_p^{\ominus}$，不能达到0.1
(5) 需要$p/p^{\ominus} = 4.925$，即约499 kPa

### 例7 Cu电解精炼阳极泥 [决赛]

**题目**：铜电解精练中生成阳极泥（铜粉），是由于电解质溶液中发生$2\text{Cu}^+ = \text{Cu} + \text{Cu}^{2+}$。

已知：$E^{\ominus}(\text{Cu}^{2+}/\text{Cu}) = +0.340$ V，$E^{\ominus}(\text{Cu}^{2+}/\text{Cu}^+) = +0.167$ V

(1) 计算平衡时$[\text{Cu}^+]^2/[\text{Cu}^{2+}]$；(2) 说明阳极泥生成原因。

**答案**：
设计两个可逆电池，利用$\Delta G = -nFE$：

反应：$\text{Cu}^{2+} + \text{Cu} = 2\text{Cu}^+$
$\Delta G_m^{\ominus} = 33.38$ kJ/mol

$[\text{Cu}^+]^2/[\text{Cu}^{2+}] = 1.41 \times 10^{-6}$

在Cu存在下，与Cu²⁺平衡的Cu⁺浓度很低。当Cu⁺浓度超过该比值，Cu⁺从过饱和状态游离出来，生成金属铜粉沉入槽底成为阳极泥。

### 例8 葡萄糖生物氧化 [决赛]

**题目**：葡萄糖完全氧化：$\text{C}_6\text{H}_{12}\text{O}_6(s) + 6\text{O}_2(g) = 6\text{CO}_2(g) + 6\text{H}_2\text{O}(l)$

(1) 1kg葡萄糖最多提供多少热量？
(2) 设计成燃料电池，理论标准电动势1.24V，1kg葡萄糖最多做多少功？
(3) 电能与热能是否相等？
(4) 人体作为热机，1kg葡萄糖热能有多少可转为机械功？推断人体能量转换机理。

**答案**：
(1) $\Delta_r H_m^{\ominus} = -2816$ kJ/mol，1kg葡萄糖放热$1.56 \times 10^4$ kJ
(2) 电子数$12 \times 2 = 24$ mol，$W^{\ominus} = 24 \times 96500 \times 1.24 = 2871.8$ kJ/mol，1kg做功$1.595 \times 10^4$ kJ
(3) 不相等，差值由熵变因素所致
(4) 热机效率$\eta = 17/310$，$W = 8.55 \times 10^2$ kJ，仅能维持血液循环。人体能量转换以电化学过程为主。

### 例9 TiC晶格能Born-Haber [决赛]

**题目**：
(1) 已知$r(\text{Ti}^{4+}) = 74.5$ pm，$r(\text{C}^{4-}) = 141.5$ pm，判断TiC晶体结构。
(2) 计算反应$\text{TiO}_2 + 3\text{C} = \text{TiC} + 2\text{CO}$的焓变。
(3) 用Born-Haber循环计算KCl的晶格能。

**答案**：
(1) $r_+/r_- = 74.5/141.5 = 0.527$，配位数6，取NaCl型（立方面心）结构。

(2) 利用盖斯定律：$\Delta H^{\ominus} = 3 \times (-110.5) - (-870.7) = 539.2$ kJ/mol

(3) Born-Haber循环：
$U = \Delta_{sub}H + \Delta_{IE}H + \frac{1}{2}\Delta_d H + \Delta_{EA}H - \Delta_f H$
$U = 89 + 425 + 122 + (-355) - (-438) = 719$ kJ/mol

### 例10 Ni(OH)₂分解 [决赛]

**题目**：25℃时电池Pt, H₂(g, p°) | KOH(1.00 mol/L) | Ni(OH)₂(s), Ni(s)的电动势为0.108V。

(1) 写出电极反应及电池反应；
(2) 氢氧电池$E^{\ominus} = 1.229$ V，求氧电极标准电极电势；
(3) 计算反应$\text{Ni(OH)}_2(s) = \text{Ni}(s) + \frac{1}{2}\text{O}_2(g) + \text{H}_2\text{O}(l)$的$K^{\ominus}$，判断在干燥空气中能否自动进行。

**答案**：
(1) 正极：$\text{Ni(OH)}_2(s) + 2e^- = \text{Ni}(s) + 2\text{OH}^-(aq)$
负极：$\text{H}_2(g) + 2\text{OH}^-(aq) - 2e^- = 2\text{H}_2\text{O}(l)$
电池反应：$\text{Ni(OH)}_2(s) + \text{H}_2(g) = \text{Ni}(s) + 2\text{H}_2\text{O}(l)$

(2) $E^{\ominus}(\text{OH}^-/\text{H}_2) = -0.827$ V，$E^{\ominus}(\text{O}_2/\text{OH}^-) = +0.402$ V

(3) $\Delta_r G_m^{\ominus} = 216.35$ kJ/mol，$K_p^{\ominus} = 1.24 \times 10^{-38}$

在干燥空气中$p(\text{O}_2) = 0.21p^{\ominus}$，$Q_p = 0.46 > K_p^{\ominus}$，$\Delta_r G_m > 0$，不能自动进行。

### 例11 Cu/CuI/HI/H₂平衡 [决赛]

**题目**：25℃时Cu(s)、CuI(s)、HI(aq)、H₂(101.325kPa)在水溶液中建立化学平衡。HI完全电离，离子活度系数为1。已知$K_{sp}(\text{CuI}) = 5.0 \times 10^{-12}$，$E^{\ominus}(\text{Cu}^{2+}/\text{Cu}) = 0.337$ V，$[\text{Cu}^{2+}]/[\text{Cu}^+]^2 = 1.19 \times 10^6$ L/mol。

(1) 写出化学方程式，计算$K_1$和平衡时$[\text{I}^-]$；
(2) 设计可逆电池，求$E^{\ominus}(\text{CuI/Cu})$和$E^{\ominus}(\text{Cu}^+/\text{Cu})$。

**答案**：
(1) 平衡体系：$\text{Cu}(s) + \text{H}^+(aq) + \text{I}^-(aq) \rightleftharpoons \text{CuI}(s) + \frac{1}{2}\text{H}_2(g)$

通过电化学循环计算：$K = 3.64 \times 10^2$

$[\text{I}^-] = 0.0524$ mol/L

(2) 设计电池：Cu(s) | CuI(s) | HI(aq) | H₂(101.325kPa) | Pt

$E^{\ominus}(\text{Cu}^+/\text{Cu}) = 0.517$ V

$E^{\ominus}(\text{CuI/Cu}) = -0.151$ V

### 非选择题（23题）

**16.** 过去曾用HCl制Cl₂：$4\text{HCl}(g) + \text{O}_2(g) = 2\text{H}_2\text{O}(g) + 2\text{Cl}_2(g)$，$\Delta_r H_m^{\ominus} = -92$ kJ/mol

温度低于800K时反应正向进行，产率可达70%；温度高于850K时反应逆向进行。试解释反应能逆向进行的原因。

**答案**：
