### 例3：Pt(NH₃)₂Cl₂推断与异构体

**某配合物组成为Pt(NH₃)₂Cl₂，为电中性分子。已知Pt²⁺为d⁸构型。**

**(1) 推断其几何构型和杂化方式。**
**(2) 画出所有可能的几何异构体，并判断哪些是可区分的。**
**(3) 是否存在旋光异构？**

**解：**

**(1)** Pt²⁺为d⁸，在强场（NH₃和Cl⁻均为较强场配体）下采用dsp²杂化，几何构型为**平面四方形**。

**(2)** 平面四方形的MA₂B₂型配合物有**2种**几何异构体：

```
    NH₃                NH₃
     |                  |
Pt─Cl               Pt─Pt（此处为顺式）
     |                  |
    Cl                NH₃  → 实际应画为：

顺式（cis）：           反式（trans）：
  NH₃   Cl               NH₃   NH₃
    \  /                    \  /
     Pt                      Pt
    /  \                    /  \
  Cl   NH₃               Cl   Cl
```

- **顺式（cis-）**：相同配体在相邻位置，分子有偶极矩
- **反式（trans-）**：相同配体在对位，分子无偶极矩（对称性高）

**(3)** 平面四方形配合物不存在旋光异构（无手性），因为分子平面本身就是一个对称面。

### 例4：Pt配合物元素分析

**某Pt配合物A（分子量≈500）进行元素分析：Pt 40.1%, Cl 23.5%, N 12.3%, H 4.2%。将A溶于水后加入过量AgNO₃，生成白色沉淀B，经称量B中Ag占50.3%。**

**(1) 确定A的化学式。**
**(2) 写出B的化学式。**
**(3) 将A溶于王水，经处理得到产物C，C再经还原得到D，D可被氧化为K₂[PtCl₆]。写出C、D的化学式。**

**解：**

**(1)** 设分子式为PtₐClₓN_yH_z，由元素分析：
- n(Pt) = 40.1/195.1 ≈ 0.2056 mol → 取a = 1
- n(Cl) = 23.5/35.5 ≈ 0.6620 mol → x ≈ 3.2 → 取3或4
- n(N) = 12.3/14.0 ≈ 0.8786 mol → y ≈ 4.3 → 取4
- n(H) = 4.2/1.0 ≈ 4.2 mol → z ≈ 20

考虑到AgNO₃沉淀实验：设A中有y个Cl⁻可沉淀，
AgCl的分子量 = 143.3，若B为yAgCl，y×143.3 / A分子量中的Cl贡献。

综合推算：化学式为 **[PtCl₄(NH₃)₂]**（分子量 = 195.1 + 4×35.5 + 2×17 = 375.1）
或更准确地：**[PtCl₂(NH₃)₄]Cl₂** → 分子量 ≈ 500

验证：[PtCl₂(NH₃)₄]Cl₂ 中，外界有2个Cl⁻可被AgNO₃沉淀。

**(2)** B = **2AgCl**

**(3)** A溶于王水，Pt被氧化为Pt⁴⁺：
- C = **H₂[PtCl₆]**（六氯合铂(IV)酸）
- 还原D = **H₂[PtCl₄]**（四氯合铂(II)酸）
- 氧化：H₂[PtCl₄] → K₂[PtCl₆]

### 例5：RuL₂(SCN)₂光电化学电池

**配合物RuL₂(SCN)₂（L = 4,4'-二羧酸-2,2'-联吡啶）是染料敏化太阳能电池的核心染料分子。**

**(1) 给出该配合物中Ru的氧化态和d电子数。**
**(2) 画出可能的几何异构体。**
**(3) 说明该配合物为何能吸收可见光。**

**解：**

**(1)** SCN⁻带-1电荷（以S配位），两个SCN⁻共-2；L为中性配体。
总电荷：0，故Ru的氧化态为 **Ru²⁺**，d电子数为 **6**（Ru为第44号元素，[Kr]4d⁷5s¹，Ru²⁺为4d⁶）。

**(2)** 该配合物为六配位八面体构型，属于MA₄B₂型。可能的异构体：
- **顺式（cis-）**：两个SCN⁻相邻
- **反式（trans-）**：两个SCN⁻对位

**(3)** 该配合物为d⁶低自旋构型（Ru²⁺在强场下），d-d跃迁能量落入可见光区。此外，配体L的大π共轭体系可发生π→π\*跃迁和金属到配体的电荷转移（MLCT），MLCT跃迁是主要的可见光吸收来源。

### 例6：AlH₃[N(C₂H₅)₃]₂三角双锥

**AlH₃[N(C₂H₅)₃]₂中Al的配位数和空间构型是什么？Al的杂化方式是什么？**

**解：**

- AlH₃[N(C₂H₅)₃]₂中Al与3个H和2个N配位，配位数 = **5**
- 电子对数 = (3 + 2) = 5对（Al提供3个价电子，3个H各提供1个，2个N各提供1个配位电子对）
- 5对电子排斥 → **三角双锥**构型
- 杂化方式：**sp³d**杂化
- N(C₂H₅)₃为三角锥形分子，作为σ配体通过N的孤对电子与Al配位

### 例7：CrCl₃·6H₂O水合异构体

**CrCl₃·6H₂O有三种水合异构体A、B、C。A为紫色，溶于水后加AgNO₃立即产生3mol AgCl沉淀；B为浅绿色，溶于水后加AgNO₃产生2mol AgCl沉淀；C为暗绿色，溶于水后加AgNO₃产生1mol AgCl沉淀。**

**(1) 写出A、B、C的结构简式。**
**(2) 用离子交换实验验证各异构体。**

**解：**

三种异构体的差异在于内界和外界中Cl⁻和H₂O的分配：

| 异构体 | 颜色 | AgCl数 | 结构简式 | 外界离子 |
|:---:|:---:|:---:|:---|:---|
| A | 紫色 | 3 | `[Cr(H₂O)₆]Cl₃` | 3Cl⁻ |
| B | 浅绿色 | 2 | `[CrCl(H₂O)₅]Cl₂·H₂O` | 2Cl⁻ + 1H₂O |
| C | 暗绿色 | 1 | `[CrCl₂(H₂O)₄]Cl·2H₂O` | 1Cl⁻ + 2H₂O |

**验证：**
- A中Cr³⁺周围全为H₂O，外界3个Cl⁻，加AgNO₃产生3mol AgCl
- B中有1个Cl⁻在内界，外界2个Cl⁻，产生2mol AgCl
- C中有2个Cl⁻在内界，外界1个Cl⁻，产生1mol AgCl

阳离子交换树脂可以分离这些异构体：[Cr(H₂O)₆]³⁺、[CrCl(H₂O)₅]²⁺、[CrCl₂(H₂O)₄]⁺的电荷不同，在离子交换柱上保留时间不同。

### 例8：Ni配合物磁性（平面四方vs四面体）

**NiCl₄²⁻为顺磁性（磁矩μ ≈ 3.5 BM），而Ni(CN)₄²⁻为反磁性。解释这两个配合物的结构差异。**

**解：**

Ni²⁺为d⁸构型。

**(1) NiCl₄²⁻：** Cl⁻为弱场配体 → 四面体构型 → 采用sp³杂化
- 四面体d⁸：2个未成对电子 → μ ≈ 2.83 BM（实测3.5 BM，略偏高因轨道贡献）
- **顺磁性**

**(2) Ni(CN)₄²⁻：** CN⁻为强场配体 → 平面四方形 → 采用dsp²杂化
- 平面四方d⁸：所有电子配对 → 无未成对电子
- **反磁性**

**结论：** 配体场强决定几何构型。弱场配体形成四面体（顺磁），强场配体形成平面四方形（反磁）。

### 例9：Cr₂(CH₃COO)₄(H₂O)₂双核配合物

**醋酸铬(II)二水合物Cr₂(CH₃COO)₄(H₂O)₂是一种双核配合物。**

**(1) 画出该配合物的结构。**
**(2) 说明Cr—Cr键的键级。**
**(3) 该配合物的磁性如何？**

**解：**

**(1)** 结构为**桨轮型（paddlewheel）**：
- 两个Cr²⁺由4个CH₃COO⁻桥联
- 每个Cr²⁺再与1个H₂O端基配位
- Cr—Cr轴向距离约2.36 Å

```
         H₂O      H₂O
          |        |
    ┌─────Cr──────Cr─────┐
    │  O=C-O    O=C-O  │
    │  |     /\    |  │
    CH₃   CH₃   CH₃   CH₃
    （4个醋酸根桥联两个Cr）
```

**(2)** Cr²⁺为d⁴构型。两个Cr²⁺之间形成**σ²π⁴δ²**键，键级 = **4**（四重键）。

**(3)** 4个Cr—Cr成键电子全部配对 → 配合物为**抗磁性**（无未成对电子）。这与Cr₂(CH₃COO)₄(H₂O)₂的实测结果一致。

### 例10：MA₄B₂和MA₃B₃几何异构体

**分别指出MA₄B₂和MA₃B₃型八面体配合物的几何异构体数目。**

**解：**

**(1) MA₄B₂型（八面体）：**
- **2种**几何异构体：顺式（cis-）和反式（trans-）
- 顺式：两个B相邻（夹角90°）
- 反式：两个B对位（夹角180°）

**(2) MA₃B₃型（八面体）：**
- **2种**几何异构体：面式（fac-）和经式（mer-）
- 面式（facial）：3个B占据八面体的一个三角面
- 经式（meridional）：3个B占据八面体的一个子午面（形成T字形）

```
面式（fac）：         经式（mer）：
    B                     B
   /|\                    |
  B B B                   B
 （一个面上）         （一个子午面上）
```

### 例11：照相定影（配位平衡）

**照相定影过程中，用Na₂S₂O₃溶液处理底片，将未曝光的AgBr溶解。已知：**

- AgBr的Ksp = 5.0 × 10⁻¹³
- [Ag(S₂O₃)₂]³⁻的Kf = 2.8 × 10¹³

**(1) 写出定影过程的离子方程式。**
**(2) 计算AgBr在1.0 mol/L Na₂S₂O₃溶液中的溶解度。**

**解：**

**(1)** 定影反应的离子方程式：

$$\text{AgBr} + 2\text{S}_2\text{O}_3^{2-} \rightleftharpoons [\text{Ag(S}_2\text{O}_3)_2]^{3-} + \text{Br}^-$$

总反应的平衡常数：

$$K = K_{sp} \times K_f = 5.0 \times 10^{-13} \times 2.8 \times 10^{13} = 14$$

**(2)** 设AgBr的溶解度为s mol/L：

$$K = \frac{[\text{Ag(S}_2\text{O}_3)_2^{3-}][\text{Br}^-]}{[\text{S}_2\text{O}_3^{2-}]^2}$$

$$14 = \frac{s \times s}{(1.0 - 2s)^2}$$

由于K不大，2s << 1.0，近似得：

$$14 \approx \frac{s^2}{1.0}$$

$$s \approx \sqrt{14} \approx 3.74 \text{ mol/L}$$

精确求解：s ≈ **3.2 mol/L**（考虑Na₂S₂O₃的消耗后修正）

### 例12：CFT计算（CFSE/磁矩/高低自旋）

**计算以下配合物的晶体场稳定化能（CFSE）、未成对电子数和磁矩（μ）：**

(1) [Fe(H₂O)₆]²⁺
(2) [Fe(CN)₆]⁴⁻
(3) [Co(NH₃)₆]³⁺
(4) [CoF₆]³⁻

已知：△o（弱场）≈ 10000 cm⁻¹，△o（强场）≈ 20000 cm⁻¹
电子成对能P ≈ 15000 cm⁻¹

**解：**

**(1) [Fe(H₂O)₆]²⁺：** Fe²⁺为d⁶，H₂O为弱场 → **高自旋**
- 电子排布：t₂g⁴eg²
- CFSE = 4×(-0.4△o) + 2×(+0.6△o) = -0.4△o = **-4000 cm⁻¹**
- 未成对电子数 = **4**
- μ = √(4×6) = **4.90 BM**

**(2) [Fe(CN)₆]⁴⁻：** Fe²⁺为d⁶，CN⁻为强场 → **低自旋**
- 电子排布：t₂g⁶eg⁰
- CFSE = 6×(-0.4△o) + 3P = -2.4△o + 3P = **-48000 + 45000 = -3000 cm⁻¹**（考虑成对能后）
- 未成对电子数 = **0**
- μ = **0 BM**（抗磁性）

**(3) [Co(NH₃)₆]³⁺：** Co³⁺为d⁶，NH₃为强场 → **低自旋**
- 电子排布：t₂g⁶eg⁰
- CFSE = 6×(-0.4△o) + 3P = **-48000 + 45000 = -3000 cm⁻¹**
- 未成对电子数 = **0**
- μ = **0 BM**

**(4) [CoF₆]³⁻：** Co³⁺为d⁶，F⁻为弱场 → **高自旋**
- 电子排布：t₂g⁴eg²
- CFSE = 4×(-0.4△o) + 2×(+0.6△o) = -0.4△o = **-4000 cm⁻¹**
- 未成对电子数 = **4**
- μ = **4.90 BM**

### 例13：CFT解释电极电势（Cr²⁺→Cr³⁺）

**利用晶体场理论解释为什么[Cr(H₂O)₆]²⁺容易被氧化为[Cr(H₂O)₆]³⁺。**

**解：**

**(1)** Cr²⁺为d⁴构型，[Cr(H₂O)₆]²⁺中H₂O为弱场：
- 高自旋：t₂g³eg¹
- CFSE = 3×(-0.4△o) + 1×(+0.6△o) = -0.6△o

**(2)** Cr³⁺为d³构型，[Cr(H₂O)₆]³⁺中：
- 无论强弱场：t₂g³eg⁰
- CFSE = 3×(-0.4△o) = -1.2△o

**(3)** 氧化反应：[Cr(H₂O)₆]²⁺ → [Cr(H₂O)₆]³⁺ + e⁻

**CFSE变化：** ΔCFSE = (-1.2△o) - (-0.6△o) = **-0.6△o**

即氧化后CFSE增加了0.6△o，体系更加稳定。因此从晶体场稳定化能角度看，Cr²⁺→Cr³⁺的氧化是有利的，[Cr(H₂O)₆]²⁺是强还原剂。

**标准电极电势：** E°(Cr³⁺/Cr²⁺) = **-0.41 V**（很负，说明Cr²⁺极易被氧化）

### 例14：(EtPh₂P)₂NiBr₂光谱与磁性

**配合物(EtPh₂P)₂NiBr₂（Et = 乙基，Ph = 苯基）在室温下磁矩为3.2 BM。**

**(1) 判断该配合物的几何构型。**
**(2) 预测其颜色。**

**解：**

**(1)** μ = 3.2 BM
- 若为四面体d⁸：2个未成对电子，μ = √(2×4) = 2.83 BM
- 若为平面四方d⁸：0个未成对电子，μ = 0 BM
- 若为扭曲四面体d⁸：可能略大于2.83 BM（轨道贡献）

μ = 3.2 BM > 2.83 BM，但远小于纯高自旋的值。
**结论：四面体构型**（略有扭曲）。配体EtPh₂P体积较大，迫使配合物采取四面体构型而非平面四方形。

**(2)** 四面体d⁸配合物有d-d跃迁，能量落入可见光区，配合物通常呈**黄橙色至棕色**。

### 例15：VO(吡啶-2-甲酸根)₂四方锥

**VO(吡啶-2-甲酸根)₂（简称VO(pic)₂）具有四方锥构型，VO²⁺轴沿z轴。**

**(1) 写出VO²⁺的电子构型。**
**(2) 画出d轨道分裂图。**
**(3) 预测d-d跃迁的数目。**

**解：**

**(1)** V为23号元素，V⁴⁺（VO²⁺中V为+4价）的电子构型为 **[Ar]3d¹**，d电子数 = **1**。

**(2)** 四方锥场中d轨道分裂（VO²⁺轴沿z轴）：

```
        d_x²-y²  （能量最高）
    
    d_xy
    
        d_z²
    
    d_xz, d_yz  （能量最低）
```

由于V=O键的强轴向场，d_z²能量较低，d_x²-y²能量最高。

**(3)** d¹构型只有**1个**d-d跃迁：从最低的d_xz/d_yz轨道跃迁到d_xy轨道。在UV-Vis光谱中表现为一个吸收带（约600-800 nm区域）。

**(2) 碳酰肼作为锅炉水添加剂还有哪些作用？**

### 例19：Lewis酸碱（BCl₃>BF₃>SiF₄）

**比较Lewis酸性强弱：BCl₃ > BF₃ > SiF₄，解释原因。**

**解：**

Lewis酸性 = 接受电子对的能力

**(1) BCl₃ vs BF₃：**
- 两者均为BF₃型（平面三角形，B为sp²杂化）
- B—Cl键长大于B—F键长
- F的2p轨道与B的2p轨道形成较好的pπ-pπ反馈键（F→B），**降低了B的缺电子性**
- Cl的3p轨道与B的2p轨道大小不匹配，pπ-pπ反馈较弱
- 因此 **BCl₃的Lewis酸性 > BF₃**

**(2) BCl₃ vs SiF₄：**
- BCl₃中B为sp²杂化，有一个空的p轨道，**容易接受电子对**
- SiF₄中Si为sp³杂化，**没有空的低能轨道**（3d轨道能量太高）
- SiF₄的Lewis酸性很弱（需要先从四面体变为三角双锥才能接受配体）

**结论：** BCl₃ > BF₃ > SiF₄

### 例20：Ag(NH₃)₂⁺配位平衡计算

**已知：**
- Ag⁺ + 2NH₃ ⇌ [Ag(NH₃)₂]⁺，Kf = 1.7 × 10⁷
- AgCl的Ksp = 1.8 × 10⁻¹⁰

**(1) 计算AgCl在6.0 mol/L NH₃中的溶解度。**
**(2) 若向上述溶液中加入HCl使pH = 7，是否会有AgCl沉淀？**

**解：**

**(1)** 溶解平衡：

$$\text{AgCl} + 2\text{NH}_3 \rightleftharpoons [\text{Ag(NH}_3)_2]^+ + \text{Cl}^-$$

$$K = K_{sp} \times K_f = 1.8 \times 10^{-10} \times 1.7 \times 10^7 = 3.06 \times 10^{-3}$$

设溶解度为s mol/L：
$$K = \frac{s^2}{(6.0 - 2s)^2} \approx \frac{s^2}{36}$$

$$s^2 = 3.06 \times 10^{-3} \times 36 = 0.11$$

$$s \approx 0.33 \text{ mol/L}$$

**(2)** pH = 7时，NH₃转化为NH₄⁺（pKa = 9.25）：
- [NH₃] / [NH₄⁺] = 10^(pH-pKa) = 10^(7-9.25) = 10^(-2.25) ≈ 0.0056
- 自由NH₃浓度大大降低

此时游离Ag⁺浓度升高，Q = [Ag⁺][Cl⁻] 可能超过Ksp，**会有AgCl沉淀生成**。

### 综合题6

**解释为什么[Co(NH₃)₆]³⁺是低自旋配合物，而[CoF₆]³⁻是高自旋配合物。**

**解：**

Co³⁺为d⁶构型。

**[Co(NH₃)₆]³⁺：** NH₃为强场配体（光谱化学序列中位于中上位），产生较大的分裂能△o。当△o > P（成对能）时，电子优先填充低能t₂g轨道，形成低自旋构型：t₂g⁶eg⁰。

**[CoF₆]³⁻：** F⁻为弱场配体，分裂能△o较小。当△o < P时，电子优先占据高能eg轨道（保持最大自旋），形成高自旋构型：t₂g⁴eg²。

**定量分析：**
- Co³⁺的P ≈ 17000 cm⁻¹
- [Co(NH₃)₆]³⁺的△o ≈ 23000 cm⁻¹ > P → 低自旋
- [CoF₆]³⁻的△o ≈ 13000 cm⁻¹ < P → 高自旋

**比较以下配合物的稳定性并解释原因：**

- Co²⁺(d⁷)在NH₃场下仍有eg电子，CFSE较小

### 综合题11

**用价键理论解释为什么[Co(NH₃)₆]³⁺为内轨型配合物，而[CoF₆]³⁻为外轨型配合物。**

**解：**

**[Co(NH₃)₆]³⁺：**

**[CoF₆]³⁻：**
- Co³⁺为d⁶，电子排布：3d⁶
- F⁻为弱场配体，不能使d电子重排
- 使用外层的4d轨道参与杂化：sp³d²杂化
- **外轨型**，CFSE小，较不稳定

### 综合题14

**解释配位化合物中的π键类型：σ键、反馈π键（dπ-pπ），并举例说明。**

**解：**

**σ配键：**
- 配体提供孤对电子到金属的空轨道（配位键）
- 例：NH₃中的N孤对电子→Fe³⁺的空d轨道

**反馈π键（dπ-pπ）：**
- 金属的充满dπ轨道→配体的空π\*轨道
- 例：Fe(CO)₅中，Fe的dxy、dxz、dyz电子→CO的π\*轨道
- 作用：增强M-L键，削弱C≡O键（CO伸缩振动频率降低）

**π给体键：**
- 配体充满的p轨道→金属的空d轨道
- 例：F⁻的p轨道→Fe³⁺的空d轨道
- 作用：减小△o，为弱场配体

### 综合题15

**计算在pH = 10.0的缓冲溶液中，AgCl在0.10 mol/L NH₃中的溶解度。**

**已知：** Ksp(AgCl) = 1.8×10⁻¹⁰，Kf([Ag(NH₃)₂]⁺) = 1.7×10⁷，NH₃的Kb = 1.8×10⁻⁵

**解：**

pH = 10.0时，[H⁺] = 10⁻¹⁰，[OH⁻] = 10⁻⁴

NH₃ + H₂O ⇌ NH₄⁺ + OH⁻，Kb = 1.8×10⁻⁵

设[NH₃] = 0.10 - x ≈ 0.10（近似），则[NH₄⁺] ≈ [OH⁻] = 10⁻⁴

实际[NH₃] ≈ 0.10 mol/L（pH = 10接近pKa = 9.25，NH₃占主导）

溶解反应：
AgCl + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻

K = Ksp × Kf = 1.8×10⁻¹⁰ × 1.7×10⁷ = 3.06×10⁻³

设溶解度为s：
K = s² / (0.10 - 2s)² ≈ s² / 0.01

s² = 3.06×10⁻³ × 0.01 = 3.06×10⁻⁵

s ≈ 5.5×10⁻³ mol/L

### 综合题18

**合成路线：从K₂PtCl₄出发，设计合成顺铂（cis-[Pt(NH₃)₂Cl₂]）。**

**解：**

**合成路线（Dhara法）：**

第一步：K₂PtCl₄ + 2KI → K₂[PtI₄] + 2KCl

第二步：K₂[PtI₄] + 2NH₃ → cis-[Pt(NH₃)₂I₂] + 2KI

第三步：cis-[Pt(NH₃)₂I₂] + 2AgNO₃ → cis-[Pt(NH₃)₂(H₂O)₂]²⁺ + 2AgI↓
- AgI沉淀，I⁻被H₂O取代

第四步：cis-[Pt(NH₃)₂(H₂O)₂]²⁺ + 2KCl → cis-[Pt(NH₃)₂Cl₂] + 2H₂O
- Cl⁻取代H₂O

**关键：** 利用I⁻的强反位效应控制立体化学，确保两个NH₃处于顺式位置。

### 综合题19

**解释金属-金属键（M-M键）的形成条件和特点，以[Re₂Cl₈]²⁻为例。**

**解：**

**[Re₂Cl₈]²⁻的结构特点：**

**(1)** 两个Re³⁺（d⁴）通过**四重键**连接：Re≡≡≡Re
- 1个σ键 + 2个π键 + 1个δ键 = 四重键
- Re-Re距离 = 2.24 Å（很短）

**(2)** 几何特征：**重叠式构象**（eclipsed）
- 两组Cl-Re-Cl平面平行
- 只有重叠式构象才能形成δ键

**(3)** 键级计算：每个Re³⁺有4个d电子
- σ键：2个电子（1对）
- π键：4个电子（2对）
- δ键：2个电子（1对）
- 总键级 = 4

**(4)** 形成条件：
- 金属原子有足够多的价电子
- 金属原子半径较小（有利于d轨道重叠）
- 氧化态适中（太高则价电子不足）

### 综合题20

**解释配合物的热力学稳定性与动力学惰性的区别，举例说明。**

**解：**

**热力学稳定性（thermodynamic stability）：**
- 指配合物在平衡状态下的稳定程度
- 用Kf（稳定常数）衡量
- 例：[Co(NH₃)₆]³⁺的Kf = 10³⁵，热力学非常稳定
- 但[Co(NH₃)₆]³⁺的配体交换速率极慢（动力学惰性）

**动力学惰性（kinetic inertness）：**
- 指配合物配体交换反应的速率
- 用交换速率常数k衡量
- 例：[Co(NH₃)₆]³⁺是**惰性**的（配体交换半衰期约数小时）
- 而[Cu(NH₃)₄]²⁺是**活性**的（配体交换在纳秒级完成）

**影响因素：**
- d³和低自旋d⁶构型通常为惰性（如Cr³⁺、Co³⁺配合物）
- d⁰、d¹⁰、高自旋d⁵通常为活性
- 晶体场活化能（CFAE）影响动力学惰性

### 综合题21

**解释为什么[Fe(H₂O)₆]²⁺呈浅绿色，而[Fe(H₂O)₆]³⁺呈淡紫色。**

**解：**

**[Fe(H₂O)₆]²⁺（浅绿色）：**
- Fe²⁺为d⁶高自旋：t₂g⁴eg²
- 允许的d-d跃迁：t₂g → eg（吸收红光~1000 nm）
- 但实际颜色由多个跃迁贡献，吸收峰在红光区，透过光呈绿色
- 摩尔吸光系数小（d-d跃迁禁阻），颜色浅

**[Fe(H₂O)₆]³⁺（淡紫色）：**
- Fe³⁺为d⁵高自旋：t₂g³eg²
- 从对称性角度，d-d跃迁严格禁阻（Laporte禁阻）
- 实际颜色来自：
  - 弱的d-d跃迁（~300 nm）
  - 配体到金属的电荷转移（LMCT）在紫外区
- 淡紫色是由极弱的d-d跃迁吸收绿光产生的

**注意：** Fe³⁺溶液常因水解产物[Fe(OH)(H₂O)₅]²⁺等而显黄色，纯[Fe(H₂O)₆]³⁺是淡紫色的。

### 综合题22

**比较以下配合物的配体交换速率，从快到慢排序，并解释：**

(1) [Cr(H₂O)₆]³⁺
(2) [Cu(H₂O)₆]²⁺
(3) [Fe(H₂O)₆]²⁺
(4) [Co(NH₃)₆]³⁺

**解：**

**配体交换速率从快到慢：**
[Cu(H₂O)₆]²⁺ >> [Fe(H₂O)₆]²⁺ >> [Cr(H₂O)₆]³⁺ ≈ [Co(NH₃)₆]³⁺

**解释：**

(1) [Cu(H₂O)₆]²⁺：d⁹构型，Jahn-Teller畸变使轴向配体弱结合，交换速率极快（~10⁹ s⁻¹），**活性**配合物。

(2) [Fe(H₂O)₆]²⁺：d⁶高自旋，无特别的稳定化能障碍，交换较快（~10⁶ s⁻¹），**活性**配合物。

(3) [Cr(H₂O)₆]³⁺：d³构型，t₂g³为半满稳定构型，晶体场活化能大，交换慢（~10⁻⁶ s⁻¹），**惰性**配合物。

(4) [Co(NH₃)₆]³⁺：d⁶低自旋t₂g⁶，CFSE大，配体交换需要断裂稳定的低自旋构型，交换极慢（~10⁻⁶ s⁻¹），**惰性**配合物。

### 综合题23

**解释以下配合物的光谱化学序列现象：为什么I⁻是弱场配体，而CN⁻是强场配体？**

**解：**

**I⁻（弱场）：**
- 碘离子半径大，电荷密度低
- 主要通过σ键与金属结合
- 有充满的p轨道，可以向金属的d轨道提供电子（π给体）
- π给体作用**减小**了d轨道分裂能（Δo）
- 因此I⁻为弱场配体

**CN⁻（强场）：**
- 碳原子有空的π\*反键轨道
- 金属的dπ电子可以反馈到CN⁻的π\*轨道（反馈π键）
- 反馈π键**增大**了d轨道分裂能（Δo）
- CN⁻既是σ给体，又是π接受体
- 因此CN⁻为强场配体

**总结：**
- 弱场配体（如I⁻）：σ给体 + π给体 → 小Δo
- 强场配体（如CN⁻）：σ给体 + π接受体 → 大Δo
- 这就是光谱化学序列的本质：π给体 < 纯σ给体 < π接受体
