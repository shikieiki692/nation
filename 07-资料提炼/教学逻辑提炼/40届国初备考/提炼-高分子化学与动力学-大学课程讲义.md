## 二、教学逻辑链

1. **先立方法，再跑一遍完整推导，最后做对照**。讲义没有按「先讲自由基、再讲离子」的教科书写法，而是先给**近似处理三法**（决速步选取 / 稳态近似 / 平衡假设），再用自由基聚合把这套方法**跑满一遍**（引发 → 增长 → 终止 → 总速率 → 动力学链长），最后用离子聚合做**同类对照**。这条顺序本身就是解题顺序。
2. **自由基聚合的三个假设是全讲的骨架**：① **等活性理论**（链自由基活性与链长无关，k_p1 = k_p2 = … = k_p）；② **稳态假设**（R_i = R_t）；③ **聚合度很大**（R_i ≪ R_p，故 R ≈ R_p）。三个假设依次把 [M·] 消掉、把 R_i 换成可测量，最后落到 R_p = k_p(fk_d/k_t)^(1/2)[I]^(1/2)[M]。
3. **离子聚合用「对照」组织**，四个维度两两对举：单体 / 引发剂 / 动力学特征 / 影响因素。讲义的写法是「阴离子讲完立刻讲阳离子」，把易混点（**四字特征**、**温度效应方向**）钉死在对照里。
4. **例题紧贴考点**。5 道期末题恰好覆盖：聚合度计算（考点 2）、引发剂用量与速率（考点 2）、特征填空（考点 1/3）、嵌段共聚顺序（考点 3）、综合控制方法（考点 5）——是「一考点一题」的配置。

## 三、方法论核心（可迁移的做题框架）

### 3.1 两把钥匙：稳态近似 vs 平衡假设

这是全讲义**最具迁移价值**的一节，判据可一句话区分：

| 方法 | 适用对象 | 数学形式 | 判据 |
|:--|:--|:--|:--|
| **稳态近似** | 活泼**中间产物**（自由基、自由基离子、原子） | 令其 **dc/dt = 0**（净生成为零） | 中间体**不断被消耗**，浓度低且近似恒定 |
| **平衡假设** | **快速平衡**的对峙步 | 令正逆速率相等 k₁[X] = k₋₁[Y] | 该步**可逆且快**，后续有**决速慢步** |
| 决速步选取 | 多步机理中的最慢一步 | 总速率 = 决速步速率 | 各步速率常数差**数量级**（k_min） |

**操作纪律**（源文明确列出）：
- 复杂反应**先拆成基元反应**，再按质量作用定律写各步速率式；
- **有几个中间产物，就至少列几个稳态方程**；
- 结果中**不应出现中间产物**——出现即说明方程数不够或消元未完成；
- 消元技巧：**整体消去**（多式相加）或**逐步代入**，选择「参与步骤少的反应物」所列的方程最省事；
- 未特别说明时，**箭头默认单向**，不能随意按可逆处理。

### 3.2 自由基聚合总速率的标准推导（三假设串联）

1. **引发**：I →(k_d) 2R·（慢、吸热、活化能高），R· + M →(k_i) RM·（快、放热、活化能低）⇒ 引发速率只取决于引发剂分解：**R_i = 2fk_d[I]**（f 为引发剂效率，0.6~0.8，源自诱导分解与笼蔽效应）。
2. **增长**：等活性理论 ⇒ **R_p = k_p[M][M·]**（[M·] 为各级自由基浓度总和）。
3. **终止**：偶合／歧化 ⇒ **R_t = 2k_t[M·]²**。
4. **稳态**：R_i = R_t ⇒ **[M·] = (fk_d[I]/k_t)^(1/2)**（源文该式 OCR 有误，按守恒复核）。
5. **聚合度很大**：R ≈ R_p ⇒ **R_p = k_p(fk_d/k_t)^(1/2)[I]^(1/2)[M]**，即**对引发剂浓度呈 1/2 级、对单体呈 1 级**。

**偏离讨论（考点延伸）**：对 [I] 的 1/2 级是**双基终止**的结果；若存在凝胶效应／沉淀聚合导致**单基终止**，级数在 0.5~1 之间。对 [M] 的 1 级在**引发效率低**时变为 3/2 级（R_i 也依赖 [M]）。

### 3.3 阴／阳离子聚合对照（考点密集区）

| 维度 | 阴离子聚合 | 阳离子聚合 |
|:--|:--|:--|
| 单体 | 需**共轭吸电子取代基**（卤代烯不行） | 更少，一般仅**异丁烯与烷基乙烯基醚** |
| 引发剂 | 碱金属（电子直接／间接转移）、有机金属（KNH₂、丁基锂、格氏）、亲核试剂（胺、膦） | 质子酸、**Lewis 酸＋共引发剂**、其他阳离子盐（I₂、高氯酸盐） |
| **动力学特征** | 快引发、**慢增长**、**无终止**、**无链转移** | 快引发、**快增长**、**易转移**、**难终止** |
| 动力学方程 | 一级：ln([M]₀/[M]) = k_p[C]t | 复杂（引发与增长均极快，不满足 [活性种] = [引发剂]） |
| 聚合度 | X̄ₙ = n([M]₀−[M])/[C] | 1/X̄ₙ = k_t/(k_p[M]) + C_M + C_S[S]/[M] |
| 温度效应 | 升温 ⇒ 速率↑、分子量↓、立构规整性↓ | **低温高速**（低温抑制链转移，保聚合度；丁基橡胶 −100 °C 合成） |
| 自动加速现象 | **无**（无双基终止） | **无** |
| 微观构型 | 头尾相连（单体插入离子对增长） | 头尾相连 |

**三条可直接背的推论**：
- 阴离子「无终止」的原因：末端同为阴离子**相互排斥**、体系无 H⁺ 可夺取、夺取链上 H⁻ 需高能量（**主要原因**）⇒ 这也是它能做**活性聚合**的原因。
- **n 的含义**：碱金属（萘钠）引发产生**双阴离子活性中心**，一分子引发剂 → 一条链的两个端 ⇒ 聚合度公式带系数 2（`n = 2`）；丁基锂等单端引发则 n = 1。
- **嵌段共聚顺序按「强碱制弱碱」**：先聚合 pK_a 大的单体，再用其活性链引发 pK_a 小的单体。
