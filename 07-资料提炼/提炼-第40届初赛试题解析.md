## 五、审题趋势分析

1. **「国决考点下放」特征明显**：第4题（TEM 图像统计 + 单电子断键）、第6题（量子限域 + 浸润热法）、第7题（NRR + PCET）、第9题（CO₂ 自由基光催化）、第10题（反芳香性 + 自旋多重度）均属传统决赛甚至更高层次内容，今年出现在初赛。
2. **物理化学计算占比大幅提升**：第2题（Stokes-Einstein + 竞争动力学）、第4题（键焓 + 级数判定）、第6题（表面热力学 + 量子估算）构成主要失分区。
3. **「真实科研情境」成为常态**：生物正交化学（2）、钙钛矿量子点（6）、电催化氮还原（7）、CO₂ 资源化（9）都是当下研究热点，题干长、信息密度高、需现场学习。
4. **作图题比重大**：第9题（41 张图）、第8题（结构式辨析）、第10题（11 张图）、第4题（15 张图）高度依赖结构式作图，对空间想象与规范表达要求高；**分值上与计算题不相上下**。
5. **定量与定性并重**：第3题（滴定计算）、第5题（晶胞参数计算）、第6题（多步估算）要求扎实的定量功底；第8题、第10题又高度依赖概念辨析的精确性（如"写错一个得 0 分"）。
6. **知识覆盖面广**：10 题横跨元素、结构、物化、分析、有机五大板块，无明显死角。

> **对新一届备赛的提示**：单靠"背元素 + 刷有机"已不足以应对；**物化（表面/量子/电化学）** 与 **作答规范（结构式作图）** 是新的胜负手。
