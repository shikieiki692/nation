# 必修1 第三章 铁 金属材料 — 教师用书提炼

## 一、课标学业要求

第二章学习了典型金属钠和典型非金属氯，本章继续学习铁及其化合物。钠和氯是典型主族元素，而铁是副族元素。这些典型元素化合物知识既为已学理论提供感性材料，也为第四章物质结构和元素周期律打下基础。

### 学业要求（完整提取）

1. 能依据物质类别和元素价态列举铁元素的典型代表物。能利用离子反应、氧化还原反应等概念对铁及其化合物的相关反应进行分类和分析说明。

2. 能列举、描述、辨识铁及其化合物重要的物理、化学性质及实验现象。能用化学方程式、离子方程式正确表示铁及其化合物的主要化学性质。

3. 能从物质类别、元素价态的角度，依据复分解反应和氧化还原反应原理，预测铁及其化合物的化学性质和变化，设计实验进行初步验证，并能分析、解释有关实验现象。

4. 能利用铁及其化合物的性质和反应，设计常见含铁物质制备、分离、提纯、检验等简单任务的方案。能从物质类别和元素价态变化的视角说明物质的转化路径。

5. 能说明常见金属材料对社会发展的价值及对环境的影响。能有意识地运用所学知识或寻求相关证据参与有关金属材料的社会性议题的讨论。

### 课时建议

- 第一节 铁及其化合物：3课时
- 第二节 金属材料：2课时
- 全章复习：1课时

## 二、知识拓展

### 1. 铁的发现与冶炼史

公元前2500年人类已发现和使用铁（陨铁），古埃及人称铁为"天石"。约公元前2000年发明铁矿石冶炼。我国在公元前7世纪至前6世纪的春秋时代已发明冶炼生铁技术，春秋末期已出现炼钢技术。铁的拉丁语是 ferrum，元素符号 Fe。

### 2. 铁的存在与性质

铁是地壳中最丰富的元素之一，含量 $4.75\%$，在金属中仅次于铝。常见化合价为 $+2$ 和 $+3$。纯铁较软，有良好延展性和导热性，能导电，能被磁化又可去磁。

铁的重要化学性质：
- 纯铁在空气中不易起变化，含杂质的铁在潮湿空气里逐渐生锈
- 铁红热时能与水反应生成氢气
- 铁易溶于稀酸，但在浓硫酸或浓硝酸中因钝化而不能溶解
- 铁加热时能与卤素、硫、磷、硅等非金属反应，但不与氮直接反应
- 铁是生命过程必需元素，是血红蛋白的主要成分

### 4. 铁的合金——生铁与钢

**生铁：** 含碳量 $2\%\sim4.3\%$，还含硅、锰及少量硫、磷，可铸不可锻。
- 炼钢生铁（白口铁）：碳以碳化铁形态存在，质硬而脆
- 铸造生铁（灰口铁）：碳以片状石墨形态存在，有良好切削、耐磨和铸造性能
- 球墨铸铁：石墨从片状变为球状，某些性能接近钢

**钢：** 含碳量 $0.03\%\sim2\%$，坚硬有韧性，可锻打、压延、铸造。
- 碳素钢：含碳量 < 0.3%（低碳钢）、0.3%\sim0.6%（中碳钢）、> 0.6%（高碳钢）
- 合金钢（特种钢）：钨钢、锰钢（硬度大）；锰硅钢（韧性好）；钼钢（抗高温）；镍铬钢（不锈钢，抗腐蚀）

**超级钢：** 2017年我国成功研制的超级钢，强度远超普通钢材。

### 5. 铝及铝合金

铝是地壳中含量最高的金属元素（接近 $8\%$），密度只有钢铁的 $1/3$。超音速飞机约 $70\%$ 由铝及其合金构成。

铝的两性特征：铝既能与稀酸（盐酸或硫酸）反应，也能与强碱溶液反应生成盐和氢气。放入冷的浓硝酸或浓硫酸中会被钝化。

铝热法：利用铝的强还原性从金属氧化物中夺取氧，如 $\mathrm{Cr}_{2}\mathrm{O}_{3}+2\mathrm{Al}\xlongequal{\text{高温}}\mathrm{Al}_{2}\mathrm{O}_{3}+2\mathrm{Cr}$。

**$\mathrm{Al}_{2}\mathrm{O}_{3}$ 的两性：** 典型两性氧化物，既可溶于酸也可溶于碱。自然界 $\alpha$ 型氧化铝称为刚玉（硬度仅次于金刚石），混有杂质可成为宝石（红宝石含 $\mathrm{Cr}^{3+}$，蓝宝石含 $\mathrm{Ti}^{3+}$ 和 $\mathrm{Fe}^{2+}$、$\mathrm{Fe}^{3+}$）。

**$\mathrm{Al(OH)}_{3}$ 的两性：** 典型两性氢氧化物，既能溶于强酸生成铝盐，又能溶于强碱生成偏铝酸盐。氢氧化铝凝胶可中和胃酸、保护溃疡面。

### 6. 金属材料的发展

材料发展史：石器时代→青铜器时代→铁器时代。新型金属材料包括高温合金、形状记忆合金、储氢合金、永磁合金、非晶态合金等。

金属材料的基本特性：高强度、优良塑性和韧性、耐热耐寒、可铸造锻造冲压焊接、良好的导电导热性和铁磁性。

## 三、教学策略精华

### 1. 铁及其化合物的教学线索

教材按照"铁单质→铁的氧化物→铁的氢氧化物→铁盐和亚铁盐"的顺序编排。教学核心是从氧化还原反应和离子反应的视角，强化铁元素不同价态间的转化关系，构建"铁三角"模型。

**铁三角转化关系：**
$$\mathrm{Fe}\xrightleftharpoons[\text{氧化}]{\text{还原}}\mathrm{Fe}^{2+}\xrightleftharpoons[\text{还原}]{\text{氧化}}\mathrm{Fe}^{3+}$$

### 2. 铁单质的教学策略

教材通过"思考与讨论"引导学生复习初中已学铁的性质，从氧化还原角度分析：
- 铁与弱氧化剂（如 $\mathrm{H}^{+}$、$\mathrm{Cu}^{2+}$）反应生成 $\mathrm{Fe}^{2+}$
- 铁与强氧化剂（如 $\mathrm{Cl}_{2}$）反应生成 $\mathrm{Fe}^{3+}$

铁与水蒸气反应：$3\mathrm{Fe}+4\mathrm{H}_{2}\mathrm{O(g)}\xlongequal{\text{高温}}\mathrm{Fe}_{3}\mathrm{O}_{4}+4\mathrm{H}_{2}$。教材通过钢铁生产的真实情境引入——"炽热的铁水注入模具前，模具必须充分干燥，不得留有水"。

### 3. 铁的化合物教学策略

**环节1：以补铁剂为真实情境。** 通过阅读硫酸亚铁片说明书获取信息，预测性质，设计实验验证。关键信息：每片含硫酸亚铁 $0.3\;\mathrm{g}$，着色剂为氧化铁；维生素C与本品同服有利于吸收。

**环节2：$\mathrm{Fe(OH)}_{2}$ 的制备。** 通过实验3-1呈现 $\mathrm{Fe(OH)}_{2}$ 白色沉淀迅速变灰绿色最终变红褐色的事实，引导学生提出假设——$\mathrm{Fe}^{2+}$ 具有还原性，为后续制备方法的学习埋下伏笔。

制备 $\mathrm{Fe(OH)}_{2}$ 的三种关键措施：
1. 新制 $\mathrm{FeSO}_{4}$ 溶液中加入少量铁粉
2. 将 $\mathrm{NaOH}$ 溶液煮沸减少溶解氧
3. 胶头滴管伸入液面以下操作

**环节3：$\mathrm{Fe}^{3+}$ 的检验与转化。** 通过实验3-2和实验3-3，建立 $\mathrm{Fe}^{2+}$ 和 $\mathrm{Fe}^{3+}$ 相互转化的完整认知。

### 4. 金属材料的教学策略

建议开展多种形式的学生活动：
- 以"身边的金属材料""建筑业中的金属材料"为主题的社会调查
- 以"金属材料能否被新型材料替代"为话题的课堂辩论
- 以"我国稀土金属资源的开发与利用"为主题的科技小论文

### 5. 物质的量在化学方程式计算中的应用

教学设计从宏观（质量关系）和微观（微粒数目）两个角度引入：
- 化学计量数之比 = 物质的量之比
- 例题示范后，通过变式练习巩固（如 $56\;\mathrm{g}$ 铁屑与足量 $2\;\mathrm{mol/L}$ 硫酸反应的计算）
- 教学中应把握要求，**不要过度强化计算**

### 6. 教学案例精华——黑木耳中铁元素含量的测定

**教学目标：** 从定性检验到定量测定黑木耳中铁元素，建立物质特性决定检验方法的认识模型。

**教学过程六环节：**
- 环节一：情境引入——"黑木耳补铁"是否属实
- 环节二：定性检验——浸泡液无铁→灼烧→加酸溶解→用铁氰化钾检验 $\mathrm{Fe}^{2+}$（蓝色沉淀）、硫氰化钾检验 $\mathrm{Fe}^{3+}$（红色溶液）
- 环节三：测质量——氢氧化钠沉淀法（发现白色浑浊为氢氧化钙干扰）和还原法（引入铁元素干扰）
- 环节四：测体积——酸性高锰酸钾滴定法（发现还原性杂质干扰）
- 环节五：测浓度——目视比色法→色度计测量法（标准曲线法）
- 环节六：总结提升——特性→检验、性质→转化、守恒→定量测定

**核心方法论：** 特性 $\rightarrow$ 物质检验；物质性质 $\rightarrow$ 物质转化；元素守恒 $\rightarrow$ 定量测定。最终结论：黑木耳中铁元素含量 $12.4\;\mathrm{mg}/100\;\mathrm{g}$，实事求是，不要以讹传讹。

## 四、实验要点

### 铁的化合物实验

**【实验3-1】铁的氢氧化物的制备：**
- 向 $\mathrm{FeCl}_{3}$ 溶液滴入 $\mathrm{NaOH}$ 溶液 → 红褐色沉淀
- 向 $\mathrm{FeSO}_{4}$ 溶液滴入 $\mathrm{NaOH}$ 溶液 → 白色絮状沉淀迅速变灰绿色，最终变红褐色
- **改进方法：** 将吸有 $\mathrm{NaOH}$ 溶液的长滴管伸入 $\mathrm{FeSO}_{4}$ 溶液液面下挤出；或向 $\mathrm{FeSO}_{4}$ 溶液中加入少量煤油隔绝空气
- **实验作用：** ①帮助辨识 $\mathrm{Fe(OH)}_{3}$ 和 $\mathrm{Fe(OH)}_{2}$；②为 $\mathrm{Fe}^{2+}$ 还原性提供实验证据

**【实验3-2】$\mathrm{Fe}^{3+}$ 的检验：**
- 向 $\mathrm{FeCl}_{3}$ 溶液滴入 KSCN 溶液 → 溶液呈红色
- 向 $\mathrm{FeCl}_{2}$ 溶液滴入 KSCN 溶液 → 无明显变化
- **注意：** $\mathrm{FeCl}_{2}$ 溶液必须用新配制的，并加铁粉还原
- 可与"检验食品中的铁元素"活动合并进行

**【实验3-3】$\mathrm{Fe}^{2+}$ 和 $\mathrm{Fe}^{3+}$ 的相互转化：**
- $2\;\mathrm{mL}\;\mathrm{FeCl}_{3}$ 溶液加入少量铁粉 → 黄色变浅绿色 → KSCN无变化 → 再滴入氯水变红色
- **关键控制：** 氯水不宜过量，否则会氧化 $\mathrm{SCN}^{-}$ 使红色褪去
- **可拓展：** $\mathrm{Fe}^{3+}$ 与 $\mathrm{Cu}$、$\mathrm{SO}_{2}$ 的反应；$\mathrm{Fe}^{2+}$ 与双氧水、酸性 $\mathrm{KMnO}_{4}$ 的反应

**铁与水蒸气反应实验：**
- 试管底部塞湿棉花，右侧放还原铁粉，蒸发皿中放肥皂水
- 试管口应低于试管底部
- 先加热湿棉花，再加热铁粉
- 待蒸发皿中产生足够气泡，用燃着火柴点燃，可听到爆鸣声

### 铝的实验

**【实验3-4】铝与盐酸反应：**
- 盐酸浓度应稍大（如 $6\;\mathrm{mol/L}$），铝片不宜太纯
- 所用试管应细而长
- 加带导气管的单孔塞，点燃生成的气体
- 现象：铝片表面大量气泡，试管壁发热，点燃可观察到淡蓝色火焰

**【实验3-5】铝与氢氧化钠溶液反应：**
- $\mathrm{NaOH}$ 溶液浓度应稍大（如 $30\%$），**戴防护手套防腐蚀**
- 铝片砂纸打磨后应快速放入 $\mathrm{NaOH}$ 溶液中（氧化膜很快再生）
- 也可先将铝丝放入盐酸中反应除氧化膜，冲洗后放入 $\mathrm{NaOH}$ 溶液，对比更明显
- 现象：打磨过的铝片立即剧烈反应；未打磨的刚开始较慢后逐渐加快
- **安全注意：** 检验氢气时务必注意安全

### 覆铜板制作图案的探究

- 工业上通常用 $30\%$ 的 $\mathrm{FeCl}_{3}$ 溶液作腐蚀液，腐蚀速率较慢时可水浴加热
- 腐蚀液配制：向 $10\;\mathrm{g}\;\mathrm{FeCl}_{3}$ 中加 $2\;\mathrm{mL}$ 浓盐酸和 $3\;\mathrm{mL}$ 水，搅拌均匀后用水慢慢稀释至 $100\;\mathrm{mL}$
- 可进一步探究"从印刷电路板废液中回收铜，并再生 $\mathrm{FeCl}_{3}$ 溶液"，体现绿色化学理念
- 废液处理：加入适量铁粉与 $\mathrm{Cu}^{2+}$ 反应回收铜，再加氯水等氧化剂实现 $\mathrm{FeCl}_{3}$ 再生

### 碳酸钠与碳酸氢钠的对比实验

**溶解性对比：** 等质量 $\mathrm{Na}_{2}\mathrm{CO}_{3}$ 和 $\mathrm{NaHCO}_{3}$ 溶于等体积水中——碳酸钠全部溶解，碳酸氢钠未能全部溶解。（20$^{\circ}\mathrm{C}$ 时 $\mathrm{Na}_{2}\mathrm{CO}_{3}$ 溶解度 $21.5\;\mathrm{g}$，$\mathrm{NaHCO}_{3}$ 溶解度 $9.60\;\mathrm{g}$）

**碱性强弱对比：** 同浓度（$0.3\;\mathrm{mol/L}$）两种溶液，碳酸钠溶液 pH 为 $10.5$，碳酸氢钠溶液 pH 为 $8.4$。控制变量：溶质的物质的量浓度必须相同。

**与酸反应对比：** 利用压强传感器测量等体积等浓度过量 $\mathrm{HCl}$ 分别与等物质的量 $\mathrm{Na}_{2}\mathrm{CO}_{3}$、$\mathrm{NaHCO}_{3}$ 固体反应产生的 $\mathrm{CO}_{2}$ 压强曲线——碳酸氢钠反应更快（曲线斜率更大）。

缓慢滴加盐酸时碳酸钠的分步反应：
- $\mathrm{CO}_{3}^{2-}+\mathrm{H}^{+}=\mathrm{HCO}_{3}^{-}$（最初无明显现象）
- $\mathrm{HCO}_{3}^{-}+\mathrm{H}^{+}=\mathrm{H}_{2}\mathrm{O}+\mathrm{CO}_{2}\uparrow$（后有气泡产生）
