# 第一章 原子结构与性质 — 教师用书提炼

## 课标学业要求

1. 能说明微观粒子的运动状态与宏观物体运动特点的差异。
2. 能从基态与激发态说明核外电子在一定条件下会发生跃迁产生原子光谱。
3. 能结合能量最低原理、泡利不相容原理、洪特规则书写1~36号元素基态原子的核外电子排布式和轨道表示式，并说明含义。
4. 能从原子价电子数目和价层电子排布的角度解释元素周期表的分区、周期和族的划分。能列举元素周期律（表）的应用。
5. 能说出元素电离能、电负性的含义，能描述主族元素第一电离能、电负性变化的一般规律，能从电子排布的角度对这一规律进行解释。能说明电负性大小与原子在化合物中吸引电子能力的关系，能利用电负性判断元素的金属性与非金属性的强弱。
6. 能简要说明核外电子运动规律的理论探究对研究元素性质及其变化规律的意义。

**课时建议**：第一节 原子结构 4课时；第二节 原子结构与元素的性质 3课时；全章复习 2课时。

## 知识拓展

### 1. 原子模型发展史（竞赛级素材）

- **德谟克利特（公元前460-370）**：提出万物由不可再分的微粒（原子）构成，无实验基础但具有划时代意义。
- **道尔顿原子论（1803年）**：物质由极微小、不可再分的原子构成；同种元素原子性质相同，不同元素原子性质不同；不同元素原子以整数比结合形成化合物。结束了元素说与原子说的隔离，是化学史中又一里程碑。
- **汤姆生梅子布丁模型（1897年）**：通过阴极射线实验发现电子，提出原子包含带正电和带负电粒子的模型。
- **卢瑟福α粒子散射实验（1911年）**：大部分α粒子穿过金箔，少部分大角度偏转甚至被反射，证明原子的正电荷和绝大部分质量集中于很小的原子核。
- **玻尔原子模型（1913年）**：电子只能在特定的量子化轨道上运动，轨道有固定能量；电子在轨道间跃迁时释放或吸收能量，成功解释了氢原子光谱。
- **现代原子模型（1935年）**：中子和质子构成原子核，电子分布在核外空间形成"电子云"。

### 2. 构造原理的深层理解

- 构造原理是**经验规律**，不是理论推导的结果。它是在分析大量元素基态原子电子排布式的基础上抽象出来的，而这些电子排布式基于光谱事实。
- 构造原理表达的是**新增电子填入能级的顺序**，并非能级能量高低的顺序。
- **能级交错现象**（如K、Ca的最外层为4s而非3d）源于光谱学事实。
- **不符合构造原理的特例**：Cr（3d⁵4s¹）和Cu（3d¹⁰4s¹）因半充满/全充满稳定结构；更复杂的Nb、Ru、Rh、W等既不遵守构造原理，也不能用洪特规则特例解释。教材明确说"构造原理是被理想化了的"。
- **屏蔽效应与钻穿效应**：电子间排斥力使有效核电荷降低（Z* = Z - σ）；不同能级电子穿透内层的能力不同，影响能量排序。这两个效应是能级交错的理论解释。

### 3. 原子光谱的应用

- **原子发射光谱**：激发态原子不稳定，在10⁻⁸~10⁻¹⁰ s内跃迁回低能态，以光的形式释放多余能量。
- **原子吸收光谱**：基态原子吸收特定波长的光跃迁到高能态。一般条件下基态原子数远多于激发态原子数，故原子吸收光谱灵敏度更高。
- **定量分析基础**：吸光度A与基态原子浓度c成正比（A = kcL），低浓度时呈直线关系，可作工作曲线。
- **X射线荧光分析**：高能X射线照射样品，激发特征X射线，谱线波长与核电荷数一一对应，可用于定性和定量分析。
- **电子探针**：聚焦电子束激发微区（μm³量级），测定特征X射线进行微区成分分析，与电子显微镜结合可研究材料显微不均匀性。

### 4. 电子云与概率密度

- 电子云图中的小点不是电子本身，而是电子在核外空间出现的**概率密度**的形象表述。小点越密，概率密度越大。
- 电子云图是**概率密度分布图**（ρ = P/V），不是概率分布图。概率密度在均匀分布的微小区域内保持恒定。
- s电子云轮廓图为球形，p电子云为哑铃形（pₓ、pᵧ、p_z三个相互垂直的轨道）。

### 5. 元素周期系的远景

- 原子序数大于83的元素都是放射性元素，92之后全部为人工合成元素。
- 物理学家预测周期系最后可能出现原子序数为175的元素。
- 第八、九周期都将有50种元素（超长周期），电子将填充5g和6g能级。g能级最多容纳18个电子。

## 教学策略精华

### 1. 能层与能级教学

- **类比法**："能层是楼层，能级是楼梯的阶梯。"
- 充分利用学生已有的电子层知识，在复习能层基础上引入能级，围绕教材【思考与讨论】展开讨论。
- 建议安排学生课前收集原子结构理论发展史资料，课上交流讨论，体会科学理论逐步完善的过程。

### 2. 基态与激发态、原子光谱教学

- **创设情境**：播放焰火、霓虹灯、激光等光现象视频，从电子跃迁角度认识光的产生。
- **关键辨析**：发射光谱（暗背景+彩色亮线）与吸收光谱（彩色亮背景+暗线），同种元素的两种光谱中特征谱线位置相同。
- **实际应用**：历史上许多元素通过原子光谱发现；现代化学利用特征谱线鉴定元素。
- **研究性学习**：可基于教材【科学史话】和【资料卡片】，布置光谱知识的小组研究课题。

### 3. 构造原理与电子排布式教学

- 教学中只要求学生把构造原理作为结论应用，不要求深入解释。
- 按周期由易到难书写：前三周期重点培养书写规范和速度；第四周期注意能级交错、书写顺序（能层低的写在左边）和Cr/Cu的特殊性。
- **体验活动**：准备标有能级的盒子和乒乓球（不同颜色代表自旋方向），学生按学号顺序投入，模拟电子排布过程。

### 4. 电子云与原子轨道教学

- **体验活动**：便签纸上画圆圈，在圈内点90个点、圈外点10个点，模拟s电子云轮廓图的形成过程（圆圈 = 90%概率范围的轮廓）。
- 强调电子云是**三维空间图像**，不是二维平面图形。
- 用课件动态展示s轨道和p轨道在三维坐标系中的取向分布。

### 5. 元素周期表教学

- **紧扣构造原理**解释元素周期表的基本结构（每个周期的元素数、族的划分）。
- **科学史资源**：门捷列夫1869年发现元素周期律（按相对原子质量排列）；莫塞莱1913年证明原子序数=核电荷数。
- 周期表的分区：s区（ns¹⁻²）、d区（(n-1)d¹⁻⁹ns¹⁻²）、ds区（(n-1)d¹⁰ns¹⁻²）、p区、f区。

### 6. 电离能与电负性教学

- **电离能反常解释**：Be(2s²全满) > B(2p¹易失)；N(2p³半满稳定) > O(2p⁴成对电子排斥)。
- **电负性判据**：金属元素一般<1.8，非金属一般>1.8，"类金属"在1.8左右。
- **第一电离能与电负性的异同**：同主族趋势一致（从上到下均减小），同周期总体趋势一致但第一电离能有反常而电负性没有。

## 实验要点

### 气球模型实验（VSEPR教学核心）

1. **基本操作**：将相同大小的气球用橡皮筋捆扎在一起——2个气球自然成直线形，3个成正三角形，4个成正四面体形。
2. **教学目的**：以"气球空间互斥"类比"价层电子对互斥"，直观理解VSEPR模型。
3. **进阶操作**：用不同大小的气球模拟孤电子对（大气球）和成键电子对（小气球），解释NH₃和H₂O的键角小于CH₄的原因。
4. **关键数据**：CH₄键角109°28'，NH₃键角107°，H₂O键角105°。孤电子对占据更大空间，排斥力：孤-孤 > 孤-成 > 成-成。

### Fe²⁺/Fe³⁺电子排布教学案例

- 以FeCl₃与KSCN显色实验引入，提问Fe²⁺和Fe³⁺的电子排布差异。
- **关键点**：失电子顺序为先失最外层ns电子，再失(n-1)d电子。Fe²⁺为[Ar]3d⁶，Fe³⁺为[Ar]3d⁵（3d半充满更稳定）。
- **电离能数据应用**：Na的I₁远小于I₂（易失1个电子形成Na⁺）；Mg的I₂与I₁相差不多但I₃突增（易失2个电子形成Mg²⁺）。

### 晶体导热性各向异性实验

- 教材未编排但建议补充：在云母片和玻璃片上用蜡粘火柴棒，用酒精灯加热，观察火柴棒脱落顺序，验证晶体的各向异性。
