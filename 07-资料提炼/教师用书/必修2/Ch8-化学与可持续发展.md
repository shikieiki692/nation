# 必修2 第八章 化学与可持续发展 -- 教师用书提炼

## 1. 课标学业要求

1. 以金属矿物、海水资源的开发利用为例，认识化学在实现无机化合物转化中的作用和贡献。

2. 认识煤、石油和天然气等化石燃料综合利用的方法和意义，了解化学在开发利用自然资源中的重要作用。

3. 以化肥、农药的合理施用，合理用药，安全使用食品添加剂为例，认识化学在发展工农业生产、创建良好生态和健康生活等方面的作用。在化学品使用、食品与药品安全等方面树立自觉遵守有关法律、法规的意识。

4. 能列举和分析大气、水体和土壤的常见污染物及其防治措施，认识化学在治理污染和保护环境中的重要作用，树立"绿色化学"的观念。

## 2. 教材分析要点

本章教学内容围绕"化学与可持续发展"核心主题，从三个方面展开：

1. **自然资源开发利用：** 以金属矿物、海水、化石燃料为例，了解化学在资源开发中的地位和伴随的环境问题。
2. **化学品合理使用：** 以化肥农药、合理用药、食品添加剂为例，认识化学品的重要作用和安全使用。
3. **环境保护与绿色化学：** 树立"绿色化学""原子经济""循环经济"等观念。

教材按照**产品源于自然、归于自然**的物质转化过程安排内容：资源利用→生产→使用消费→环境保护，呈现化学品生命周期的完整链条。

**编写特点：**
- 突出学科核心素养，科学教育与人文教育融合
- 注重基础性，坚持选择性，反映时代性
- 更新呈现方式，促进从被动接受向主动多样化学习转变

## 3. 知识拓展

### 3.1 海水资源开发利用

**海水淡化三种方法：**
- **蒸馏法：** 加热海水汽化再冷凝，最早工业化应用，产水纯度高
- **电渗析法：** 利用电场使离子向电极集中，电极间离子浓度下降制淡水
- **离子交换法：** 离子交换剂中的可交换基团与海水中离子交换

**海水提溴工艺流程：**
1. 将氯气通入预先酸化的浓缩海水中
2. 通入空气将溴单质吹出
3. 溴蒸气与吸收塔中 $\mathrm{SO}_{2}$ 反应
4. 在蒸馏塔中用 $\mathrm{Cl}_{2}$ 将 $\mathrm{HBr}$ 氧化得溴单质
5. 利用沸点差异获得溴蒸气，冷凝得液溴

关键反应：
$$2\mathrm{Br}^{-} + \mathrm{Cl}_{2} = 2\mathrm{Cl}^{-} + \mathrm{Br}_{2}$$
$$\mathrm{Br}_{2} + \mathrm{SO}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{H}^{+} + 2\mathrm{Br}^{-} + \mathrm{SO}_{4}^{2-}$$

**海水提镁：** 海水→加石灰乳沉淀 $\mathrm{Mg(OH)}_{2}$→加盐酸得 $\mathrm{MgCl}_{2}$→电解熔融 $\mathrm{MgCl}_{2}$ 得金属镁。

**从海水中提取物质需考虑的普遍性问题：**
1. 原料的分离提纯及富集原理
2. 加入辅料的来源和成本
3. 除去副产物的操作
4. 中间产物的循环利用
5. 对环境的保护

### 3.2 金属矿物的开发利用

**铝的冶炼：** 电解熔融 $\mathrm{Al}_{2}\mathrm{O}_{3}$（加入冰晶石降低熔点）。

**铝的回收：** 回收铝制品比从矿石中提取铝节省大量能源（仅需电解能量的约3%）。

**金属活动性顺序在资源开发中的应用：** 位于活动性顺序前面的金属其化合物更稳定，冶炼难度更大（需更强的还原条件）。

### 3.3 化石燃料的综合利用

- **煤的干馏：** 隔绝空气加强热，得焦炭、煤焦油、焦炉气等
- **石油的分馏：** 利用沸点不同分离各组分
- **石油的裂化和裂解：** 大分子烃断裂为小分子烃
- **天然气：** 主要成分 $\mathrm{CH}_{4}$，可用作燃料和化工原料

### 3.4 化学品的合理使用

**化肥合理施用：** 不同土壤和作物选择合适肥料，过量施用导致土壤退化和水体富营养化。

**农药合理使用：** 有效防治病虫害，但过量使用污染环境，需开发高效低毒农药。

**食品添加剂：**
- 定义：为改善食品品质和色、香、味，以及防腐、保鲜和加工工艺需要而加入的人工合成或天然物质
- 种类：着色剂、增味剂、膨松剂、凝固剂、防腐剂、抗氧化剂、营养强化剂等
- 使用要求：在规定范围内合理使用对人体健康无不良影响，需严格按照《食品安全国家标准 食品添加剂使用标准》执行
- 辩证认识：没有"垃圾食品"，只有不合理的饮食搭配

### 3.5 环境保护与绿色化学

**大气污染物：** $\mathrm{SO}_{2}、\mathrm{NO}_{x}、\mathrm{CO}、$ 颗粒物等。酸雨（pH<5.6）主要由 $\mathrm{SO}_{2}$ 和 $\mathrm{NO}_{x}$ 引起。

**水体污染物：** 重金属离子、有机物、营养元素（N、P）等。

**土壤污染物：** 重金属、农药残留、塑料废弃物等。

**绿色化学的核心理念：**
- **原子经济性：** 反应物中的原子全部转化为目标产物
- **减少废物排放：** 从源头预防污染而非末端治理
- **循环经济：** 资源→产品→再生资源的循环模式

## 4. 教学策略精华

### 4.1 资源开发利用——以海水为例

**情境引入：** 海洋图片+地球海陆面积比例→认识海水资源的广泛性和多样性。

**小组课题汇报模式：** 分组负责海水淡化、循环冷却水、海水制盐、海水提溴、海水提镁等专题，课前自主查阅资料，课堂交流共享。

**核心问题驱动：** 对比海水提溴和提镁的工艺流程，归纳从海水中提取物质的普遍性问题。

**素养落实：** 宏观辨识（分类认识物质多样性）→ 模型认知（建立提取工艺的一般模型）→ 科学探究（设计探究方案）→ 社会责任（可持续发展原则）。

### 4.2 化学品的合理使用——以食品添加剂为例

**课前准备：** 分7组（着色剂、膨松剂、凝固剂、防腐剂、抗氧化剂、营养强化剂、社会调查），周末调查食品标签。

**课堂活动五环节：** 阅读（看食品配料表）→ 交流（小组内）→ 展示（各组向全班）→ 辩论（食品添加剂的利与弊）→ 学以致用（学会选购食品）。

**辩论设计：** 正方"食品添加剂必不可少"vs 反方"应回归自然不用添加剂"，引导辩证思维。

**课后实践：** 制作豆腐——了解胶体和蛋白质性质，体会食品添加剂的实际应用。

### 4.3 环境保护与绿色化学

**教学要点：**
- 化学与环境监测
- "三废"治理
- 生物质资源开发
- 化学与药物设计、合成
- 人工光合作用
- "绿色化学"的原理

**情感目标：** 培养科学决策意识、创新精神与实践能力，学会辩证全面地看待人类和自然协调发展中遇到的问题。

### 4.4 教学案例要点——海水资源开发利用（湖北夷陵中学李欣）

**五环节教学流程：**
1. 认识海水资源的广泛性和多样性
2. 体验海水资源综合利用的一般方法（课题汇报）
3. 初探从海水中提取物质的工艺流程（对比提溴和提镁）
4. 展望海水资源开发与可持续发展
5. 学有所获，学有所感

**板书核心：**
- 海水淡化（蒸馏法、电渗析法、离子交换法）
- 海水提溴：$\mathrm{Cl}_{2}$ 氧化 $\mathrm{Br}^{-}$ → 吹出 → $\mathrm{SO}_{2}$ 吸收 → 再氧化
- 海水提镁
- 从海水中提取物质需考虑的5个普遍性问题

### 4.5 教学案例要点——食品添加剂（湖北葛洲坝中学刘杰、胡智灵）

**分组与任务分配：**
- 糖果饮料组（着色剂）
- 面包饼干组（膨松剂）
- 豆腐果冻组（凝固剂）
- 肉制品组（防腐剂）
- 罐头组（抗氧化剂）
- 牛奶食盐组（营养强化剂）
- 社会活动组（调查公众对食品添加剂的认识和态度，录制视频）

### 4.6 教学案例要点——豆腐的制作（湖北宜昌一中徐海波等）

**基于"互联网+"的翻转课堂：** 三个大环节——任务驱动（布置课前任务）→ 实践探究（周末制作豆腐）→ 课堂展示（组内研讨→组际循环→典型展示→教师点评→总结提高）。

**化学原理：** 胶体的性质（豆浆是胶体，加入电解质——石膏使胶体聚沉）、蛋白质的变性。

## 5. 实验要点

### 研究与实践：豆腐的制作

- 需要家长知晓并签字监督安全
- 化学药品（如石膏）必须是食品添加剂级，大型超市有售
- 仪器可就地取材使用家庭替代品
- 研究报告建议包含：标题、关键词、摘要、知识背景、方案设计与改进、操作要点、数据资料分析、研究结论与心得体会

### 安全注意事项

- 化石燃料相关实验注意通风和防火
- 海水提溴实验中 $\mathrm{Cl}_{2}、\mathrm{SO}_{2}、\mathrm{Br}_{2}$ 均有毒，需在通风橱中操作
- 金属冶炼相关实验注意高温安全
- 食品添加剂相关实践注意食品安全和卫生
