# 必修2 第七章 有机化合物 -- 教师用书提炼

## 1. 课标学业要求

1. 能辨识常见有机化合物分子中的碳骨架和官能团，概括其分子中碳原子的成键类型。能描述甲烷、乙烯、乙炔的分子结构特征，并能搭建甲烷和乙烷的立体模型，能写出了丁烷和戊烷的同分异构体。

2. 能描述乙烯、乙醇、乙酸的主要化学性质及相应性质实验的现象，能书写相关的化学方程式，能利用这些物质的主要性质进行鉴别。能预测简单有机化合物的某些性质，并进行实验验证。

3. 能列举合成高分子、油脂、糖类、蛋白质等有机化合物在生产、生活中的重要应用，并结合这些物质的主要性质进行简单说明。

4. 能列举事实说明有机化学在生产、生活中的应用价值及其对推动社会发展的贡献。从有机化合物及其性质的角度对有关能源、材料、饮食、健康、环境等实际问题进行分析、讨论和评价。能从材料组成的角度对生活中常见的材料进行分类，根据需求选择和使用适当的材料，解释使用注意事项。能妥善保存、科学合理地使用常见有机化学品。

## 2. 知识拓展

### 2.1 人们对甲烷分子结构的认识过程

甲烷是最简单的有机化合物，人类认识其分子结构花了上百年时间：

- **1808年 道尔顿：** 用图式表示甲烷为一个碳原子和两个氢原子结合（受当时分析方法限制，但体现了原子论，是最早的结构式）。
- **贝采利乌斯：** 将元素符号引入有机化学。
- **凯库勒：** 提出碳原子是四价、碳原子本身可以互相连接的观点。
- **布特列洛夫：** 化学结构理论——分子的化学性质取决于组成单元的性质、数量和化学结构，原子间能相互影响。
- **1874年 范托夫和勒贝尔：** 各自提出碳原子具有**四面体结构**的假说，开辟了立体化学的新篇章。X射线衍射进一步证明甲烷的正四面体结构。

### 2.2 乙醇的工业制法

**(1) 发酵法：** 淀粉经水解为葡萄糖，再经酵母菌发酵得乙醇。

$$2(\mathrm{C}_{6}\mathrm{H}_{10}\mathrm{O}_{5})_{n} \xrightarrow{\mathrm{H}_{2}\mathrm{O}} n\mathrm{C}_{12}\mathrm{H}_{22}\mathrm{O}_{11} \xrightarrow{\mathrm{H}_{2}\mathrm{O}} 2n\mathrm{C}_{6}\mathrm{H}_{12}\mathrm{O}_{6}$$

$$\mathrm{C}_{6}\mathrm{H}_{12}\mathrm{O}_{6} \xrightarrow{\text{酶}} 2\mathrm{CH}_{3}\mathrm{CH}_{2}\mathrm{OH} + 2\mathrm{CO}_{2}\uparrow$$

发酵液含乙醇6%~10%，精馏后得95%工业乙醇。

**(2) 乙烯水合法（工业主流）：**

$$\mathrm{CH}_{2}=\mathrm{CH}_{2} + \mathrm{H}_{2}\mathrm{O} \xrightarrow[\triangle]{\text{催化剂}} \mathrm{CH}_{3}\mathrm{CH}_{2}\mathrm{OH}$$

条件：磷酸/硅藻土催化剂，260~290℃，约7 MPa，乙烯单程转化率仅5%左右，大量乙烯需循环。

### 2.3 无水乙醇的制取

普通乙醇含95.57%乙醇和4.43%水（共沸物，沸点78.15℃），不能用普通蒸馏法分离。

- **实验室法：** 加生石灰（CaO）加热回流除水，蒸馏得99.5%无水乙醇。再加金属镁处理得绝对乙醇。
- **工业法：** 加苯蒸馏——先蒸出苯-乙醇-水三元恒沸物（64.9℃），再蒸出苯-乙醇二元混合物（68.3℃），最后蒸出无水乙醇（78.5℃）。近年也用强酸性阳离子交换树脂。

### 2.4 乙醇的生理作用

乙醇不需消化直接扩散进入血液。代谢过程主要在肝脏：乙醇 →（乙醇脱氢酶）→ 乙醛（有害）→（乙醛脱氢酶）→ 乙酸（唯一有营养价值的代谢产物）。代谢速率有限，饮酒速率超过代谢速率时器官中积蓄导致中毒。

### 2.5 淀粉和碘的显色机理

直链淀粉遇碘呈蓝色，支链淀粉遇碘呈紫红色。机理：碘分子嵌入淀粉螺旋体的轴心部位形成**包合物**。颜色与聚合度有关——聚合度200~980时呈蓝色，支链上平均聚合度20~28时呈紫色。加热蓝色消失是解吸作用。

### 2.6 "垃圾食品"的科学辨析

陈君石院士观点："垃圾食品"不是科学定义，食物本身没有"垃圾"与"健康"之分，关键在于**食物搭配是否合理**。每100g烤鸭的能量是汉堡的1.5倍、脂肪是2倍多，但不应因此将传统中国菜也列入"垃圾食品"名单。应参照《中国居民膳食指南》做到食物多样化。

### 2.7 棕榈油

饱和脂肪含量高，稳定性好，耐高温烹炸。相同面积土地棕榈油产量约为菜籽油的10倍，价格低廉，是世界消费量最大的植物油品种。

## 3. 教学策略精华

### 3.1 认识有机化合物——碳原子成键特点

**核心方法：模型拼插法（螺旋上升式活动串）**

**活动1（1个C）：** 拼插含1个碳原子的碳氢化合物→体会碳原子与4个氢原子成键。再加1个Cl→碳原子可与多种原子成键。

**活动2（2个C）：** 拼插含2个碳原子的碳氢化合物→发现碳碳单键、双键、三键。体会"先碳骨架，再补氢"的搭建思路。

**活动3（3~4个C）：** 拼插碳骨架→发现链状（直链、支链）和环状。给4个C骨架补氢书写分子式→初识**同分异构现象**。

**关键结论：** 碳原子成键特点——4个共价键、碳碳单/双/三键、链状/环状骨架、同分异构→有机物种类繁多。

### 3.2 乙醇与乙酸——官能团与性质的关系

**结构分析路径：** 分子结构 → 化学键 → 官能团 → 性质。

**乙醇关键反应分析：**

| 反应 | 断裂键 | 形成键 | 官能团变化 | 反应类型 |
|------|--------|--------|------------|----------|
| 与钠反应 | O—H | H—H | —OH → —ONa | 取代（置换） |
| 催化氧化 | O—H和C—H | C=O | —OH → —CHO | 氧化 |

**核心观念：** 官能团是决定有机物化学特性的原子或原子团。以乙醇的结构和性质为基本模型，认识含羟基有机化合物的通性。

**催化氧化实验现象：** 铜丝灼烧变黑（CuO）→插入乙醇恢复红色（Cu）→反复操作闻到乙醛气味。铜丝起催化作用。

### 3.3 教学原则

- 不涉及烷烃系统命名和苯/芳香烃的性质
- 对代表性有机物着重化学性质，对复杂有机物从应用角度突出
- 立足基本知识，渗透"结构决定性质"的观念
- 通过"方法导引""整理与提升"建立碳骨架和官能团两个辨识视角

### 3.4 有机化合物教学案例要点（北京回民学校丁芬）

**五环节设计：** 引出课题（感受有机物种类繁多）→ 原子成键数目探究（活动1）→ 碳原子间成键方式探究（活动2）→ 碳骨架连接方式探究（活动3）→ 呼应引言小结。

**板书设计核心：** 有机化合物中碳原子的成键特点——碳四价、碳碳连接方式、碳骨架多样性、同分异构。

### 3.5 乙醇教学案例要点（北京十一学校孙京）

**设计思路：** 从乙醇的分子结构分析其性质和变化，认识官能团与性质的关系。

**探究链条：** 乙醇在生活中的应用 → 搭建分子结构模型 → 探究乙醇与钠的反应 → 探究乙醇的催化氧化 → 分析羟基与乙醇性质的关系 → 总结提高。

## 4. 实验要点

### 实验活动8：搭建球棍模型认识有机化合物分子结构的特点

- 用球棍模型搭建甲烷、乙烷、丁烷等分子
- 体会碳原子的正四面体结构和碳链的连接方式
- 比较正丁烷和异丁烷的球棍模型，初步认识同分异构现象

### 实验活动9：乙醇、乙酸的主要性质

**乙醇与钠反应：**
- 钠先沉入液底（乙醇密度比钠小）→有气体放出→钠慢慢浮起→最后消失
- 对比：不如水与钠反应剧烈→乙醇羟基不如水中羟基活泼

**乙醇的催化氧化：**
- 铜丝灼烧变黑→插入乙醇恢复红色→反复操作闻到乙醛气味
- 注意铜丝的催化作用——反应前后不变

**乙酸的性质：**
- 与碳酸钠反应产生气泡（酸性强于碳酸）
- 酯化反应：乙酸 + 乙醇 → 乙酸乙酯（浓硫酸催化，加热）
- 注意：导管口不能伸入饱和碳酸钠溶液液面以下（防倒吸）
- 乙酸乙酯有水果香味
