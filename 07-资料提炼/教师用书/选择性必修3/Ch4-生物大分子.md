## 课标学业要求

1. 能说明单糖的组成和结构特点，能综合运用相关知识分析单糖的主要化学性质。
2. 能说明二糖和多糖的组成和结构特点，能综合运用相关知识分析二糖和多糖的主要化学性质。
3. 能辨识氨基酸中的氨基和羧基，能说明氨基酸的主要化学性质，能写出氨基酸之间发生缩合反应的化学方程式。
4. 能辨识蛋白质中的肽键，能说明蛋白质的主要结构特点和化学性质。
5. 能说明核酸的组成和结构特点，能说出核酸的生物功能。

## 知识拓展

### 葡萄糖的环状结构

D-葡萄糖在水溶液中存在变旋现象：
- α-D-吡喃葡萄糖（36.4%，比旋光度+112°→平衡）
- β-D-吡喃葡萄糖（63.6%，比旋光度+18.7°→平衡）
- 链状葡萄糖含量极少
- 平衡比旋光度+52.7°

开链→环状：第5号C上的-OH与醛基发生分子内半缩醛反应，醛基碳由sp²→sp³杂化，由非手性→手性碳。新生成的半缩醛羟基（苷羟基）在空间两种取向→α型和β型（差向异构体）。

链式结构无法解释：①只能与一分子醇形成半缩醛；②不与NaHSO₃反应；③红外无羰基信号；④核磁无醛基质子吸收。

霍沃思透视式写法：六元环氧原子在后方，左侧基团写上方，右侧写下方；D型羟甲基在上方，α型苷羟基与羟甲基异侧，β型同侧。

### 单糖的差向异构化与还原性

碱性条件下，D-葡萄糖、D-甘露糖、D-果糖通过烯二醇中间体相互转化：
- C-2上H受羰基和羟基双重影响→碱催化质子化→烯醇式中间体
- 烯醇式不稳定→异构化重排→C-2构型不同→D-葡萄糖与D-甘露糖互变（差向异构化）
- C-2上OH重排→D-葡萄糖/甘露糖↔D-果糖（醛糖↔酮糖转化）

**还原糖判断**：果糖在碱性条件下可烯醇化，烯醇化速率比葡萄糖大→果糖也是还原糖，且与托伦/费林/本尼迪克特试剂反应比葡萄糖更活泼。

### 蔗糖的甜味理论

甜味物质分子中存在距离约0.3nm的两个能形成氢键的基团，与舌上相应结构作用→神经信号→甜味感。蔗糖和糖精的甜味基团结构不同但满足此空间距离要求。

### 秸秆制燃料乙醇

木质纤维素→预处理→纤维素水解为葡萄糖、半纤维素水解为木糖→发酵→蒸馏脱水→燃料乙醇。瓶颈：纤维素酶成本高，单位产品耗能大。

### 氨基酸的用途

- **食品工业**：谷氨酸单钠盐（味精）、半胱氨酸（抗氧化剂）、赖氨酸（营养强化剂）
- **医药工业**：氨基酸注射液、甘氨酸（胃液抑制剂）、生物活性肽激素
- 生物体中氨基酸→合成蛋白质；食品工业中改善风味、延长保质期

### 蛋白质的显色反应

1. **双缩脲反应**：蛋白质+碱+少量CuSO₄→紫红色配合物。多肽中肽键（-CO-NH-）与双缩脲结构相似，肽键越多颜色越深。
2. **黄色蛋白反应**：某些蛋白质+浓HNO₃→黄色（含苯环的蛋白质），加氨→橙色。
3. **茚三酮反应**：蛋白质+茚三酮→蓝/紫/紫红色。可用于氨基酸和蛋白质的层析及定量测定。

### 核酸的性质

- 糖苷键和磷酯键在酸性条件或酶催化下水解
- 含磷酸基→酸性；含氮杂环→可结合质子
- 碱基中共轭双键强烈吸收紫外光→可用紫外分光光度法定性定量
- DNA变性（氢键断裂）→复性（链重新缔合）→性质恢复
- 戊糖单元可发生显色反应

### 吴蕴初——中国化工先驱

1891-1953，创办天厨味精厂、天原电化厂（中国第一家氯碱厂）、天利氮气厂（中国第一家合成氨/硝酸厂）、天盛陶器厂。抗战期间内迁企业支援后方。设公益基金委员会培养化工人才。

## 教学策略精华

### 一、糖类——多官能团有机化合物的代表

**葡萄糖结构探究**：
1. 分子式C₆H₁₂O₆→不饱和度=1→可能含一个C=O
2. 实验验证：银镜反应和Cu(OH)₂→证明含醛基
3. 多羟基有机化合物遇新制Cu(OH)₂→绛蓝色配合物→证明含多个羟基
4. 结构简式：CH₂OH-CHOH-CHOH-CHOH-CHOH-CHO

**还原糖与非还原糖的探究**：
- 葡萄糖：还原糖（含游离醛基）
- 麦芽糖：还原糖
- 蔗糖：非还原糖（无游离醛基）
- 淀粉、纤维素：非还原糖
- 注意：市售白糖含少量葡萄糖杂质，需用化学纯以上蔗糖试剂

**单糖→二糖→多糖转化关系**：
- 淀粉/纤维素 →[酸/酶, 水解] → 葡萄糖
- 葡萄糖 →[酶] → 乙醇 + CO₂
- 淀粉与纤维素水解条件差异：淀粉易水解（稀酸即可），纤维素需较浓酸（70%~80% H₂SO₄）

**纤维素水解实验要点**：
- 浓H₂SO₄浓度70%~80%，不能太多否则脱水炭化
- 水浴加热或小火微热，得亮棕色溶液后冷却
- 稀释无絮状沉淀→水解完全
- 用较浓NaOH中和水解液

### 二、蛋白质——从氨基酸到空间结构

**氨基酸教学**：
1. 结构特点：同时含-NH₂和-COOH→两性
2. 与酸反应（-NH₂）：R-CH(NH₂)-COOH + HCl → R-CH(NH₃Cl)-COOH
3. 与碱反应（-COOH）：R-CH(NH₂)-COOH + NaOH → R-CH(NH₂)-COONa + H₂O
4. 成肽反应（缩合）：氨基酸间-NH₂与-COOH脱水→肽键（-CO-NH-）
5. 两个氨基酸→二肽，多个→多肽→蛋白质

**蛋白质结构层次**：
- 一级结构：氨基酸排列顺序（共价键/肽键）
- 二级结构：α-螺旋、β-折叠（氢键）
- 三级结构：三维空间构象（多种作用力）
- 四级结构：多肽链组合（氢键等）

**蛋白质的性质与结构变化**：
| 性质 | 变化的结构层次 | 条件 |
|-----|-------------|------|
| 盐析 | 三级结构（可逆） | 浓无机盐溶液 |
| 变性 | 三级及以上（不可逆） | 加热、强酸碱、重金属盐、紫外线 |
| 水解 | 一级结构（肽键断裂） | 酸/碱/酶催化 |

**人工合成结晶牛胰岛素**（1965年）：中国科学家首次人工合成具有生物活性的蛋白质，一级结构→空间结构→生物活性。

### 三、核酸——化学与生命科学的交汇

**组成分析**（水解法）：
核酸 →[水解] → 核苷酸 →[水解] → 核苷 + 磷酸
核苷 →[水解] → 戊糖 + 碱基

**DNA vs RNA**：
| | DNA | RNA |
|---|-----|-----|
| 戊糖 | 脱氧核糖 | 核糖 |
| 碱基 | A、T、G、C | A、U、G、C |
| 结构 | 双螺旋 | 通常单链 |

**DNA双螺旋结构**：
- 两条多聚核苷酸链反向平行
- 磷酸和脱氧核糖交替连接→外侧骨架
- 碱基内侧，通过氢键互补配对：A-T（2个氢键）、G-C（3个氢键）
- 碱基配对原理：分子间距离减小→能量降低→结构稳定

**核苷酸链的形成**：
- 碱基与戊糖1号C相连（氨基与羟基脱水缩合）→核苷
- 戊糖5号C上-OH与磷酸酯化→核苷酸
- 核苷酸间磷酸二酯键连接→多聚核苷酸链

## 实验要点

### 实验4-1：葡萄糖的还原性

- 银氨溶液和Cu(OH)₂必须现用现制
- 试管须洁净（NaOH溶液清洗→水洗）
- 加入新制Cu(OH)₂可观察到绛蓝色溶液（多羟基配合物）→证明含多个羟基
- 银镜可用少量硝酸去除

### 实验4-2：纤维素的水解

- 浓H₂SO₄ 70%~80%，量以恰好溶解脱脂棉为准
- 水浴加热→亮棕色溶液→冷却
- 稀释无絮状沉淀→水解完全
- 较浓NaOH中和→加银氨溶液或新制Cu(OH)₂检验葡萄糖
- 对比淀粉水解（稀酸即可），认识二者结构差异

### 糖类的性质（实验活动3）

**还原性检验**：
- 葡萄糖：银镜反应√，Cu(OH)₂√
- 蔗糖：均不反应（非还原糖）
- 麦芽糖：均反应（还原糖）
- 淀粉：均不反应（非还原糖）

**水解检验**：
- 淀粉水解→加碘水（蓝色褪去）+加银氨溶液（银镜）
- 蔗糖水解→加银氨溶液（银镜）
- 检验水解产物前需先中和催化剂（酸）
