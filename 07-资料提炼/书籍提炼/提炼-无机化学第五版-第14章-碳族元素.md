## 三、教学逻辑锚点

> 与 Zchem 第二轮深化「主族元素的结构化学I」一致：**C 的杂化与大π键 → Si 的结构化学与工业化学 → 重元素惰性电子对递进**，结构主线贯穿全章。

- **主线**：结构决定性质的范式——C 同素异形体（sp³/sp² 杂化）→ CO/CO₂/CO₃²⁻ 大π键 → 硅酸盐 O/Si 比结构 → Sn/Pb 惰性电子对。每族元素用「结构」串起。
- **铺垫顺序**：碳单质（同素异形体 + 还原性）→ 碳的含氧化合物（CO/CO₂/碳酸盐，大π键密度最高）→ 碳化物 → 硅（生产纯化 → SiO₂ → 硅酸盐 → 硅烷 → 卤化物）→ 锗锡铅（单质 → 化合物收尾）。
- **结论出现时机**：「C 的还原性随温度变化的 Ellingham 图」在 14.1.1，为 14.2.1 硅的冶炼（SiO₂+C）和全章金属冶炼做铺垫；「惰性电子对效应」在 14.3.1 用 Pb 引到极致（Pb(Ⅳ) 强氧化性），呼应 Ch13 Tl。
- **竞赛抓手**：CO 的配位能力与吸收检测、CO₃²⁻/CO₂ 大π键、碳酸盐热稳定性离子极化解释、硅酸盐 O/Si 比判断结构、Pb₃O₄ 双价态、SnCl₂ 的还原性与配制、CCl₄ 不水解 vs SiCl₄ 强烈水解——均为高频考点。

## 四、核心内容提炼

### 4.1 碳单质及其化合物

#### (1) 碳的同素异形体（14.1.1）
- **金刚石**：sp³ 杂化，三维正四面体网络，原子晶体，硬度最大，不导电。
- **石墨**：sp² 杂化，六方层状，层内大π键（Πⁿₙ）导电，层间范德华力易滑动（润滑剂）；是碳最稳定形态。
- **碳原子簇 / 富勒烯**：C₆₀（截角二十面体，32 面体，60 个顶点），C₇₀、C₇₆ 等；sp² 与弯曲 π 键；C₆₀ 可加氢（C₆₀H₆₀）、卤代（C₆₀F₆₀）。
- **化学性质**：常温极稳定（C—C、C≡C 键能大）；高温还原性——碳是冶金还原剂，产物随温度变（高温得 CO，低温得 CO₂）。

#### (2) 碳的还原性与艾林罕姆图（Ellingham 图）
- **艾林罕姆图**：纵轴 ΔfG°(氧化物)，横轴 T；金属氧化物的 ΔfG°—T 线越靠下越稳定。C 还原金属氧化物的原理：**2C + O₂ → 2CO 线斜率（ΔS>0）向下**，高温下低于多数金属氧化物线 → C 高温可还原这些金属。
- 用 C 还原不同氧化物所需温度：CuO/Ag₂O 低温即可，SiO₂/Al₂O₃/TiO₂ 需很高温度（习题 14-8(10)）。
- **反应耦合**：2C + O₂ → 2CO 放热少但熵增，与 SiO₂ + 2C → Si + 2CO 耦合，总反应 ΔG 更负 → 冶炼可行。
- 熔沸点处曲线斜率突变：金属（或氧化物）熔化/沸腾消耗热量，ΔfG°—T 线斜率改变（习题 14-8(10)③）。

#### (3) 一氧化碳 CO（14.1.2）
- **结构**：C≡O 三键（1 个 σ + 2 个 π，其中一个为配位键），C 端孤对 → 强配位能力。
- **制备**：
```
HCOOH 浓H₂SO₄ △ → CO↑ + H₂O
H₂C₂O₄ 浓H₂SO₄ △ → CO↑ + CO₂↑ + H₂O（需 NaOH 除 CO₂）
```
- **工业**：发生炉煤气（C + 不足空气）：CO 25%、CO₂ 4%、N₂ 70%；水煤气（C + H₂O(g) 高温）：CO 40%、H₂ 50%、CO₂ 5%。
- **性质**：可燃、剧毒（与血红蛋白配位）；还原性（炼铁 CO + FeO → Fe + CO₂）；配位（Fe(CO)₅ 羰基铁，Ni(CO)₄ 羰基镍——金属提纯）。
- **检测与吸收**：PdCl₂ 溶液变黑（CO + PdCl₂ + H₂O → Pd↓ + CO₂ + 2HCl）；CuCl 的盐酸/氨水溶液吸收 CO（CuCl(CO)·2H₂O）。

#### (4) 二氧化碳 CO₂
- **结构**：直线形 O=C=O，两套 Π₃⁴ 大π键（S=2）；无极性；干冰（分子晶体）直接升华。
- **性质**：酸性氧化物；弱氧化性（Mg + CO₂ ==点燃== 2MgO + C）。
- **碳酸 H₂CO₃**：二元弱酸，K₁°=4.45×10⁻⁷，K₂°=4.69×10⁻¹¹；只存在于水溶液中。
- **CO₃²⁻**：平面三角形，中心 C sp²，一套 Π₄⁶ 大π键。

#### (5) 碳酸盐
- **溶解性规律**：碱金属（除 Li₂CO₃）及铵盐可溶；其余碳酸盐难溶。
- **双沉淀剂本质**：Na₂CO₃ 溶液中 CO₃²⁻ 水解产生 OH⁻ → 对弱碱金属离子（Mg²⁺、Al³⁺、Fe³⁺、Cu²⁺）沉淀生成碱式盐/氢氧化物：
```
2Cu²⁺ + 2CO₃²⁻ + 2H₂O → Cu(OH)₂·CuCO₃↓（碱式碳酸铜）
2Fe³⁺ + 3CO₃²⁻ + 3H₂O → 2Fe(OH)₃↓ + 3CO₂↑
```
- **热稳定性**（离子极化观点）：正离子极化力越大，碳酸盐越易分解；碳酸 > 酸式盐 > 正盐；同族 MCO₃ 稳定性随半径增大而增大（MgCO₃ < CaCO₃ < SrCO₃ < BaCO₃）；碱金属碳酸盐最稳定（高温不分解）。
- Na₂CO₃ 沉淀剂选择（习题 14-6）：制备 MgCO₃ 需用 NaHCO₃（避免 Mg²⁺ 水解生成碱式盐），制备 BaCO₃ 用 Na₂CO₃（BaCO₃ 溶解度极小、不水解）。

#### (6) 碳化物（14.1.3）
- **离子型碳化物**：水解生成碳氢化合物——
```
CaC₂ + 2H₂O → C₂H₂↑ + Ca(OH)₂
Mg₂C₃ + 4H₂O → 2Mg(OH)₂ + C₃H₄↑（丙炔）
Al₄C₃ + 12H₂O → 4Al(OH)₃↓ + 3CH₄↑
```
- **间充型碳化物**：过渡金属（W、Ti、Fe）+ 小 C 原子填入金属晶格空隙 → 高硬度高熔点（硬质合金 WC、TiC）。
- **共价型碳化物**：B₄C、SiC（金刚砂，硬度近金刚石）。

### 4.2 硅单质及其化合物

#### (1) 单质硅（14.2.1）
- **半导体**：高纯硅（掺杂 B/P 控制导电类型）是电子工业基础。
- **化学性质**：常温不活泼（表面 SiO₂ 氧化膜）；与碱反应放出 H₂；与 HF+HNO₃（氧化性酸 + 络合酸）反应：
```
Si + 2NaOH + H₂O ==△== Na₂SiO₃ + 2H₂↑
3Si + 4HNO₃ + 18HF → 3H₂[SiF₆] + 4NO↑ + 8H₂O
```
- 高温：Si + O₂ → SiO₂；Si + C ==高温== SiC；Si + 2Cl₂ ==高温== SiCl₄。
- **生产与提纯**（三阶段）：
```
粗硅：SiO₂ + 2C ==1800℃电炉== Si + 2CO↑
氯化：Si + 2Cl₂ ==400℃== SiCl₄（或 SiHCl₃ 三氯氢硅）→ 精馏提纯
还原：SiCl₄ + 2H₂ ==高温== Si + 4HCl（→ 再区熔提纯）
```
- **区域熔融**：利用杂质在固/液相分配差异，反复区熔得高纯硅。

#### (2) 二氧化硅 SiO₂（14.2.2）
- **结构**：原子晶体，SiO₄ 四面体无限连接，熔点极高（>1600℃）——对比 CO₂ 分子晶体（习题 14-8(6)）。
- **化学性质**（弱酸性，不溶于水；只与 HF、强碱反应）：
```
SiO₂ + 4HF → SiF₄↑ + 2H₂O
SiO₂ + 6HF → H₂[SiF₆] + 2H₂O（过量 HF）
SiO₂ + 2NaOH ==熔融/热== Na₂SiO₃ + H₂O（玻璃被碱腐蚀）
```
- 与碱性氧化物共熔制玻璃：SiO₂ + Na₂CO₃ ==高温== Na₂SiO₃ + CO₂↑。
- **变色硅胶**：硅胶 SiO₂·xH₂O 干燥剂；加 CoCl₂ 指示——干燥蓝色，吸水变粉红（CoCl₂·6H₂O）。

#### (3) 硅酸与硅酸盐
- **硅酸**：xSiO₂·yH₂O，偏硅酸 H₂SiO₃ / 原硅酸 H₄SiO₄（弱酸，K₁≈10⁻¹⁰）；由可溶硅酸盐 + 酸制得。
- **水玻璃**：Na₂SiO₃ 水溶液（Na₂O·nSiO₂），粘合剂、防火剂。
- **水中花园**：Ni(NO₃)₂ 等盐投入 Na₂SiO₃ 溶液，生成半透膜硅酸盐沉淀，水渗入胀破再沉淀 → 彩色"花园"。
- **硅酸根聚合（O/Si 比判结构，核心考点）**：

| 结构类型 | 结构单元 | O/Si 比 | 实例 |
|:--|:--|:--|:--|
| 孤立单聚 | SiO₄⁴⁻ | 1:4 | 橄榄石 |
| 双四面体 | Si₂O₇⁶⁻ | 2:7 | |
| 链状 | (SiO₃)ₙ²ⁿ⁻ | 1:3 | 辉石/石棉 |
| 层状（片状） | (Si₂O₅)ₙ²ⁿ⁻ | 1:2.5 | 云母/滑石 |
| 三维网络 | SiO₂ | 1:2 | 石英/长石 |

- **分子筛（沸石）**：铝硅酸盐（AlO₄⁻ + SiO₄ 骨架），有规则孔道/孔穴；A 型（3A/4A/5A 按孔径），β 笼、α 笼结构，硅铝比 1:1；ZSM-5 高硅分子筛（择形催化）。硅铝比提高 → 酸性增强（Al 取代 Si 产生负电荷 → 需质子/阳离子平衡）（习题 14-8(5)）。

#### (4) 硅烷（14.2.3）
- **制备**：SiO₂ + 4Mg ==高温== Mg₂Si + 2MgO；Mg₂Si + 4HCl ==水溶液== SiH₄↑ + 2MgCl₂。
- **性质**：剧烈还原性、空气中自燃（SiH₄ + 2O₂ → SiO₂ + 2H₂O）；强还原性使 KMnO₄ 褪色；水解（碱性）SiH₄ + (n+2)H₂O → SiO₂·nH₂O + 4H₂↑。
- **对比**（习题 14-9）：热稳定性 CH₄ > SiH₄ > BH₆ 系列（Si—H 键弱、还原性强）；硅烷还原性 > 烷烃。

#### (5) 硅的卤化物（14.2.4）
- **SiCl₄**：共价液体，发烟，**强烈水解**（经 sp³d 五配位中间体）：
```
SiCl₄ + 4H₂O → H₄SiO₄ + 4HCl（白烟）
```
- **对比**：CCl₄ 不水解（C 无 3d 轨道、已饱和、且 C—Cl 键能大），BCl₃/SiCl₄ 强烈水解（B、Si 有空轨道接受配位、易成五配位中间体）→ 习题 14-8(4) 经典对比。
- **SiF₄ 与氟硅酸**：SiF₄ + 2HF → H₂[SiF₆]（强酸，酸根 SiF₆²⁻ 八面体）。

### 4.3 锗、锡、铅

#### (1) 单质（14.3.1）
- **存在**：Ge 稀有分散（锗石矿 Cu₂S·FeS·GeS₂）；锡石 SnO₂；方铅矿 PbS。
- **锡疫**：白锡 <13.2℃ 缓慢变灰锡（粉末状，锡器冬天崩碎）；逆向变回需加热。
- **+4/+2 稳定性递变**：Ge(Ⅳ) > Sn(Ⅳ) > Pb(Ⅳ)（Pb(Ⅳ) 强氧化性）；Ge(Ⅱ) < Sn(Ⅱ) < Pb(Ⅱ)（Pb(Ⅱ) 稳定）。惰性电子对效应随族向下增强。
- **与酸/碱反应**：
```
Ge + 浓HNO₃ → 水合GeO₂（β-锗酸）
Sn + 2HCl(浓) ==△== SnCl₂ + H₂↑
3Sn + 8HNO₃(极稀) → 3Sn(NO₃)₂ + 2NO↑ + 4H₂O
3Sn + 4HNO₃(浓) → 3SnO₂↓(β-锡酸) + 4NO↑ + 2H₂O
Sn + 2OH⁻ + 4H₂O ==△== [Sn(OH)₆]²⁻ + 2H₂↑
Pb + 2HCl(稀) → PbCl₂↓（钝化，阻止反应）
Pb + 4HCl(浓) → H₂[PbCl₄] + H₂↑
Pb + OH⁻ + 2H₂O → [Pb(OH)₃]⁻ + H₂↑
Pb + 4HNO₃(浓) → Pb(NO₃)₂ + 2NO₂↑ + 2H₂O（只到+2）
Pb + 3H₂SO₄(浓) → Pb(HSO₄)₂ + SO₂↑ + 2H₂O
```
- **Pb 不溶于稀 HCl/H₂SO₄** 的解释（习题 14-8(9)）：虽 E°(Pb²⁺/Pb) < 0，但产物 PbCl₂/PbSO₄ 难溶覆盖表面钝化；浓盐酸靠配位（H₂[PbCl₄]）、浓硫酸靠加热与生成可溶酸式盐、稀硝酸靠氧化溶解。
- **提取冶炼**：GeS₂ 焙烧 → GeO₂ → GeCl₄ 精馏 → 高纯水解 → 350℃ H₂ 还原得高纯 Ge；SnO₂ + 2C ==△== Sn + 2CO；2PbS + 3O₂ ==焙烧== 2PbO + 2SO₂；PbO + C ==△== Pb + CO。

#### (2) 锗、锡、铅的化合物（14.3.2）
- **含氧化合物**：
  - MO 偏碱性（PbO 黄，密陀僧/铅黄），MO₂ 偏酸性（GeO₂ 弱酸、SnO₂、PbO₂）。
  - **PbO₂ 强氧化性**：
```
[Pb(OH)₃]⁻ + ClO⁻ → PbO₂↓(棕黑) + Cl⁻ + OH⁻ + H₂O
5PbO₂ + 2Mn²⁺ + 4H⁺ → 5Pb²⁺ + 2MnO₄⁻ + 2H₂O（鉴定 Mn²⁺）
PbO₂ + 4HCl → PbCl₂ + Cl₂↑ + 2H₂O
```
  - **Pb₃O₄（铅丹）**= 2PbO·PbO₂；Pb₂O₃ = PbO·PbO₂。Pb₃O₄ + HNO₃ → PbO₂↓ + Pb(NO₃)₂（验证双价态：Pb(Ⅳ) 强氧化性 + Pb²⁺ 与 CrO₄²⁻ 生成黄色 PbCrO₄）。
  - **锡酸 α/β 型**：α-锡酸 SnO₂·xH₂O（SnCl₄ 碱水解，活泼，溶浓 HCl/碱，久置/加热 → β 型）；β-锡酸（Sn + 浓 HNO₃ 制得，惰性，不溶浓 HCl/KOH）——溶解度/活性差异。
  - **Sn(Ⅱ) 还原性与亚锡酸**：
```
2HgCl₂ + SnCl₂ + 2HCl → Hg₂Cl₂↓(白) + H₂SnCl₆；SnCl₂ 过量 → Hg(黑)
3[Sn(OH)₃]⁻ + 2Bi³⁺ + 9OH⁻ → 3[Sn(OH)₆]²⁻ + 2Bi↓(黑)（碱性还原性更强）
```
  - **酸碱递变**：H₂GeO₃ 酸性最强（K₁°≈10⁻⁹，强于 H₂SiO₃——第四周期反常），Pb(OH)₂ 碱性最强；Ge²⁺ 还原性 > Sn²⁺ > Pb²⁺。
- **卤化物**：
  - Pb(Ⅳ) 强氧化性 → PbI₄、PbBr₄ 不能稳定存在。
  - **SnCl₂ 水解 + 配制**：SnCl₂ + H₂O ⇌ Sn(OH)Cl↓ + H⁺ + Cl⁻ → 配制时加盐酸抑制水解 + 加 Sn 粒还原 Sn(Ⅳ)（Sn + Sn⁴⁺ → 2Sn²⁺）防氧化。
  - **SnCl₄**：无色共价液体，极易水解发烟（制备 Sn + 2Cl₂ ==△== SnCl₄，全程防水）。
  - **PbCl₂**：冷水溶解度小、热水易溶；与浓 Cl⁻ 生成 [PbCl₄]²⁻ 配离子（Cl⁻ 不能将 Pb²⁺ 沉淀完全）。
- **硫化物**：
  - GeS/GeS₂ 微溶于水；SnS 灰、SnS₂ 黄、PbS 黑（均需较浓盐酸才溶）。
  - **两性 + 硫代酸盐**：
```
3SnS₂ + 6NaOH → Na₂SnO₃ + 2Na₂SnS₃ + 3H₂O（酸性硫化物溶于碱）
SnS₂ + Na₂S → Na₂SnS₃（硫代锡酸钠；含氧酸盐 O→S 取代）
GeS₂ + Na₂S → Na₂GeS₃
SnS + Na₂S₂ → SnS₂ + Na₂S（过硫化钠氧化低价硫化物）
```
  - **硫代酸盐遇酸分解**：Na₂SnS₃ + 2H⁺ → SnS₂↓ + H₂S↑（习题 14-6(5) SnCl₄ + Na₂S 沉淀溶解再沉淀的解释）。

## 七、教材例题与常见错误

### 精选例题
1. **MgCO₃ 与 BaCO₃ 沉淀剂选择**（习题14-6）：Mg²⁺ 用 NaHCO₃（避免碱式盐），Ba²⁺ 用 Na₂CO₃——考查 CO₃²⁻ 水解与沉淀溶解度。
2. **CCl₄ 不水解 vs BCl₃/SiCl₄ 强烈水解**（习题14-8(4)）：C 无空轨道、无 d 轨道、C—Cl 键能大；B/Si 有空轨道可形成五配位中间体。
3. **Pb₃O₄ 双价态验证**（习题14-5(2)）：HNO₃ 处理 → PbO₂↓ + Pb(NO₃)₂；PbO₂ + 盐酸 → Cl₂（氧化性）；Pb²⁺ + CrO₄²⁻ → PbCrO₄ 黄。
4. **CO 除杂与检测**（习题14-5(4)(5)）：CO₂ 中 CO → CuCl 吸收或催化氧化；H₂ 中 CO → 用 PdCl₂ 或碱液吸收（回答时注意 H₂ 不与 CuCl 络合）。
5. **SnCl₄ + Na₂S 沉淀溶解再沉淀**（习题14-6(5)）：SnS₂↓ 黄 → 过量 Na₂S 溶成 Na₂SnS₃ → 稀盐酸重新析出 SnS₂——硫代酸盐遇酸分解。

### 常见错误
| 错误认知 | 正确结论 |
|:--|:--|
| 高温用 C 还原氧化物都生成 CO₂ | 高温 C 过量生成 CO（2C+O₂→2CO），温度越高 CO 越稳定 |
| CCl₄ 与 SiCl₄ 水解行为相同 | CCl₄ 不水解；SiCl₄ 强烈水解（sp³d 中间体） |
| 所有碳酸盐沉淀剂都选 Na₂CO₃ | 对易水解金属离子（Mg²⁺/Fe³⁺/Cu²⁺）生成碱式盐/氢氧化物，应选 NaHCO₃ |
| Sn(Ⅱ) 与 Pb(Ⅱ) 还原性相同 | Ge²⁺>Sn²⁺>Pb²⁺；碱性亚锡酸还原性比 Sn²⁺ 更强 |
| Pb 活泼金属（E°<0）应溶于稀酸 | PbCl₂/PbSO₄ 难溶钝化，Pb 不溶于稀 HCl/稀 H₂SO₄ |
| α/β-锡酸只是结晶水不同 | α 活泼可溶、β 惰性难溶，制备方式不同（SnCl₄ 水解 vs Sn+浓 HNO₃） |
| 硅酸是强酸 | H₂SiO₃ 弱酸（K₁≈10⁻¹⁰）；H₂GeO₃ 比 H₂SiO₃ 强（第四周期反常） |
