# 提炼-上海中学竞赛课程-第一分册-晶体学基础

> 来源：上海中学竞赛课程·化学·第1分册·第六讲 晶体学基础

## 内容概要

本讲从晶体的基本性质（自范性、各向异性、对称性、均一性）出发，系统介绍点阵理论——结构基元与点阵的概念、平面点阵和空间点阵的划分、14种布拉维格子，然后讲解利用等同点系确定结构基元的方法，最后详细讨论晶胞中原子数的计算（均摊法）和空间利用率的计算。

---

## 核心知识点

### 1. 晶体的基本性质

- **自范性**：适宜条件下自发呈现封闭的、规则的凸多面体外形
- **各向异性**：沿不同方向原子排列周期性和疏密程度不同→物理性质有差异
- **对称性**：理想外形和内部结构都有对称性
- **均一性**：同一晶体各个部分性质相同

### 2. 点阵理论

- **结构基元**：晶体中周期性变化的具体内容，需同时满足四个条件——化学组成相同、空间结构相同、排列取向相同、周围环境相同
- **点阵**：从结构基元抽象出来的几何点的无限阵列，按周期性规律在空间排布
- **晶体结构 = 点阵 + 结构基元**
- **案例**：伸展的聚乙烯链中，-CH₂-CH₂-组成一个结构基元（而非-CH₂-），因为相邻两个-CH₂-取向不同

### 3. 点阵单位

- **平面点阵**：
  - 可划分为并置的平行四边形（平面格子）
  - 素格子（平均含1个点阵点）vs 复格子（平均>1个）
  - 正当平面单位：对称性一致→直角尽可能多→面积尽可能小
  - 5种型式：正方形、六方、矩形、带心矩形（唯一复格子）、平行四边形
- **空间点阵**：
  - 可划分为并置的平行六面体（空间格子）
  - 顶点贡献1/8，面心贡献1/2，体心贡献1
  - **14种布拉维格子**（7种形状）：P（简单）、I（体心）、F（面心）、A/B/C（底心）

### 4. 等同点系确定结构基元

- **等同点系**：一组点，从各点出发沿指定方向观察，彼此看到的物质环境和几何环境都相同
- **拆分规则**：先拆不同原子→相同原子可能需拆分→直到各点系排布方式相同为止
- **案例**：CsCl晶体中，Cl⁻和Cs⁺分属两个等同点系（沿同一方向观察物质环境不同），各按简单立方排列，结构基元为{Cs⁺, Cl⁻}
- **金刚石**：C原子分属两个等同点系，每个按面心立方排列，结构基元为2个C原子

### 5. 晶胞中原子数的计算（均摊法）

- **规则**：顶点原子×1/8，棱上原子×1/4，面上原子×1/2，体内原子×1
- **应用**：
  - 金刚石晶胞：8×(1/8)+6×(1/2)+4=8个C原子
  - 面心立方：8×(1/8)+6×(1/2)=4个原子
  - 体心立方：8×(1/8)+1=2个原子

## 竞赛要点

1. **结构基元的正确辨认**：竞赛中常给出晶体结构图要求判断结构基元，关键是利用等同点系方法
2. **布拉维格子的判断**：给定晶体结构图，判断属于14种布拉维格子中的哪一种
3. **晶胞原子数的计算**：竞赛中常给出复杂晶体结构（如合金、超导材料），需要准确运用均摊法
4. **空间利用率计算**：如金刚石空间利用率仅34.01%（8r=√3a），说明共价晶体堆积效率低
5. **等同点系与晶体点阵的关系**：从等同点系可直接看出晶体的点阵类型

## 例题与习题

### 典型例题

**例1**：判断聚乙烯链中结构基元是什么。

**解题思路**：-CH₂-CH₂-是一个结构基元，而非-CH₂-。因为相邻两个-CH₂-虽然组成和结构相同，但取向不同、周围环境不同。

**例2**：CsCl晶体中，判断点阵类型和结构基元。

**解题思路**：Cl⁻和Cs⁺分属两个等同点系，各按简单立方排列→点阵为简单立方点阵，结构基元为{Cs⁺, Cl⁻}。

### 本讲习题覆盖方向

- 结构基元的判断
- 点阵类型识别
- 晶胞中原子数的均摊法计算
- 空间利用率的计算
- 14种布拉维格子的区分
- 等同点系的拆分与应用
