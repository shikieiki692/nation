## 内容概要

本讲按「芳香性判据 → 五元杂环 → 六元杂环 → 稠环杂环」的层次展开。结构部分用休克尔规则判定呋喃、噻吩、吡咯（$\Pi_5^6$）与吡啶（$\Pi_6^6$）的芳香性，并给出两条关键排序：**芳香性强弱**苯 > 噻吩 > 吡咯 > 呋喃，**亲电取代活性**吡咯 > 呋喃 > 噻吩 > 苯。化学性质部分以「中间体碳正离子/氮负离子的共振稳定性」为统一判据，解释五元杂环的 $\alpha$-定位、吡啶的 $\beta$-亲电取代与 2,4-亲核取代、喹啉/异喹啉的 5,8-与 2,4-/1-位选择性，以及吲哚的 3-位选择性；并收录吡咯氮上氢的弱酸性（$\mathrm{p}K_a \approx 17.5$）、吡啶侧链 $\alpha-H$ 的酸性（与甲基酮相当）两个关键数值。合成方法收录 Hantzsch 合成吡啶、Skraup 合成喹啉与 Fischer 吲哚合成。

## 核心知识点

### 1. 杂环的结构与芳香性
| 杂环 | 电子体系 | 亲电取代活性 | 关键结论 |
|---|---|---|---|
| 苯 | $\Pi_6^6$ | 基准 | 芳香性最强，取代活性最低 |
| 噻吩 | $\Pi_5^6$ | 略高于苯 | 硫的电负性与碳最接近 → 五元杂环中芳香性最强 |
| 吡咯 | $\Pi_5^6$ | 远高于苯 | 氮贡献 2 个 p 电子，环上电子云密度高于苯 |
| 呋喃 | $\Pi_5^6$ | 五元杂环中最高 | 氧电负性最大 → 芳香性最弱、活性最高 |

- 五元杂环：4 个碳各提供 1 个 p 电子 + 杂原子提供 2 个 p 电子 → $\Pi_5^6$，符合休克尔规则（$4n+2$，$n=1$）
- **芳香性次序**：苯 > 噻吩 > 吡咯 > 呋喃（判据：杂原子与碳电负性相近程度）
- **亲电取代活性次序**：吡咯 > 呋喃 > 噻吩 > 苯（电子云密度越高越易）
- 吡啶：6 个原子各提供 1 个 p 电子 → $\Pi_6^6$；氮电负性大于碳 → 环上电子云密度低于苯，亲电取代活性与**硝基苯**相似
- **碱性强弱次序**：脂肪胺 > 吡啶 > 苯胺 > 吡咯
  - 吡啶氮的孤对电子**不参与**共轭 → 显碱性；吡咯氮的孤对电子**参与**共轭 → 几乎无碱性

### 2. 五元杂环的化学性质

#### 2.1 亲电取代的定位（$\alpha$-位优先）
- 亲电试剂进攻 $\alpha$-位的中间体碳正离子比进攻 $\beta$-位的**共振式更多、更稳定** → 取代主要发生在 $\alpha$-位
- 因活性太高易副反应，须采用**温和亲电试剂**，避免强酸、强氧化剂：
  | 反应 | 试剂要点 |
  |---|---|
  | 磺化 | 吡咯、呋喃**不能用浓硫酸**，用吡啶–$\mathrm{SO_3}$ 加合物，磺化产物较稳定、可酸化得磺酸；噻吩可用硫酸直接磺化 |
  | 硝化 | 用**硝酸乙酰酯** $\mathrm{CH_3COONO_2}$（乙酸酐 + 硝酸制得）避免氧化；呋喃生成 2,5-加成产物，用吡啶除去乙酸后得 2-硝基呋喃 |
  | 卤代 | 不需催化剂且很强烈，须低温 + 溶剂稀释控制单取代 |
  | 傅-克酰基化 | 呋喃用 $\mathrm{BF_3}$、噻吩用 $\mathrm{ZnCl_2}$ 作催化剂；吡咯可直接用酸酐 |
- **取代基定位效应**（由中间体共振稳定性推出，须记牢）：
  - $\beta$-位有第二类（吸电子）取代基 → 后续基团进**不相邻**的 $\alpha$-位；$\beta$-位有第一类（给电子）取代基 → 进**相邻**的 $\alpha$-位
  - 吡咯、噻吩的 $\alpha$-位有第二类取代基 → 进不相邻的 $\beta$-位；$\alpha$-位有第一类取代基 → 进**另一 $\alpha$-位**
  - **呋喃是例外**：无论 $\alpha$-位是何种定位基，后续基团均进**另一 $\alpha$-位**

#### 2.2 加成与吡咯的特殊反应
- 呋喃、吡咯催化氢化得饱和杂环；噻吩含硫会使一般催化剂中毒，须用特殊催化剂
- 呋喃易与亲双烯体发生 **Diels-Alder 反应**（呋喃兼作双烯体）
- **吡咯氮上氢的弱酸性**：$\mathrm{p}K_a \approx 17.5$，**比醇强、比酚弱** → 可与格氏试剂、强碱反应生成吡咯盐，该盐可继续转化

### 3. 吡啶的化学性质

#### 3.1 亲电取代（$\beta$-位）
- 只有进攻 $\beta$-位才能避免出现「**氮原子带正电荷**」的共振式 → 亲电取代发生在 $\beta$-位（与硝基苯同为间位定位）
- 条件强烈、产率不高；**吡啶不能发生傅-克反应**

#### 3.2 亲核取代（2-位、4-位）
- 氮的吸电子作用使环上电子云密度降低 → 有利于亲核取代
- 进攻 2-位或 4-位可形成**特别稳定的氮负离子八隅体**（负电荷落在电负性大的氮上）→ 亲核取代主要发生在 2、4-位
- 有好的离去基团（卤素）时：与氨、醇钠等顺利取代
- **无**好的离去基团时需强亲核试剂：
  - **齐齐巴宾（Chichibabin）反应**：吡啶 + 氨基钠，在甲苯或 N,N-二甲基苯胺中加热，再水解 → 2-氨基吡啶
  - 与强碱性烷基锂/芳基锂反应可直接烃基化

#### 3.3 侧链 $\alpha-H$ 的反应
- **2,4,6-位**烷基吡啶的侧链 $\alpha-H$ 具酸性，**强度与甲基酮的 $\alpha-H$ 相当**
- 判据同样来自共振：2、4（及 6）-位甲基脱 $\alpha-H$ 后负电荷可落在氮上 → 形成**特别稳定的氮负离子**；3-位无此共振 → 不显酸性
- 故 2,4,6-位烷基吡啶在强碱催化下可与苯甲醛等发生缩合（如 2-甲基吡啶 + $\mathrm{PhCHO} \xrightarrow{\mathrm{ZnCl_2}, \triangle}$ 2-苯乙烯基吡啶）

#### 3.4 氧化、还原与 Hantzsch 合成
- **氧化**：吡啶抗氧化性比苯强，一般只氧化侧链 → 吡啶甲酸；常用作 $\mathrm{CrO_3}$ 的溶剂
- **N-氧化物**：与 30% $\mathrm{H_2O_2}$/乙酸（加热）作用得吡啶 N-氧化物；**N-氧化物易进行亲电取代且主要发生在 $\gamma$-位**（与吡啶本身相反）
- **还原**：加热加压 $\mathrm{H_2/Ni}$ → 六氢吡啶（**哌啶**），具一般二级胺碱性，**比吡啶强**
- **Hantzsch（汉奇）合成法**：2 分子 $\beta$-羰基酸酯 + 1 分子醛 + 1 分子氨缩合 → 吡啶及其衍生物

### 4. 喹啉、异喹啉的化学性质
- 可视作**苯并吡啶**；吡啶环电子云密度低于苯环 → 亲电取代发生在**苯环**上，且主要在 **5,8-位**（进攻 5,8-位产生 2 个共振式，进攻 6,7-位只有 1 个）
- **亲核取代**：喹啉在杂环 **2,4-位**，异喹啉在 **1-位**
- **侧链 $\alpha-H$**：喹啉 2,4-位侧链、异喹啉 1-位侧链有活泼 $\alpha-H$ → 可缩合、可亲核取代
- **氧化**：苯环被破坏而**吡啶环保持不变**
- **还原**：**吡啶环先被还原**（与氧化的选择性相反）
- **Skraup（斯克劳普）合成法**：苯胺 + 甘油 + 硫酸 + 硝基苯 → 喹啉
  - 反应放热且越来越剧烈，须加硫酸亚铁、硼酸等缓和剂；硝基苯被还原为苯胺可循环使用
  - **取代基定位规律**（高频）：
    | 苯胺环取代位置 | 喹啉取代位置 |
    |---|---|
    | 对位 | 6-取代 |
    | 邻位 | 8-取代 |
    | 间位（给电子基） | 在给电子基对位关环 → 7-取代 |
    | 间位（吸电子基） | 在吸电子基邻位关环 → 5-取代 |
  - 用 $\mathrm{R{-}CH{=}CH{-}CHO}$ 代替甘油 → **2-取代**喹啉；用 $\mathrm{CH_2{=}CHCOR}$ 代替甘油 → **4-取代**喹啉

### 5. 吲哚的化学性质
- 吲哚即**苯并吡咯**，具芳香性；杂环电子云密度高于苯环 → 亲电取代发生在杂环上，且**主要在 3-位**
- 判据：进攻 **3-位**时可产生**两个含完整苯环**的共振式，进攻 2-位只有**一个** → 3-位中间体更稳定
- **Fischer 吲哚合成**（例 6 给出）：醛、酮、酮酸、酮酸酯或二酮的**芳基取代腙**在 $\mathrm{ZnCl_2}$、三聚磷酸或 $\mathrm{BCl_3}$ 等路易斯酸催化下加热 → 吲哚（先肼基对羰基亲核加成、脱水成腙，再在酸催化下重排关环）

## 竞赛要点

1. **一切定位都回到「写出共振式数一数」**：$\alpha$ vs $\beta$（五元环）、$\beta$ vs $\alpha/\gamma$（吡啶亲电）、2,4 vs 3（吡啶亲核）、5,8 vs 6,7（喹啉）、3 vs 2（吲哚）—— 五道定位题统一判据，不要零散记忆
2. **判断中间体是否「特别稳定」的两个信号**：负电荷能否落在电负性大的氮上（形成氮负离子八隅体）；共振式是否保留了完整苯环
3. **吡啶 N-氧化物的定位翻转是常考陷阱**：吡啶本身亲电取代在 $\beta$，N-氧化物在 $\gamma$
4. **吡啶的氧化/还原选择性相反**：氧化只动侧链（环不动，可作 $\mathrm{CrO_3}$ 溶剂），还原先动吡啶环；喹啉则是氧化先破苯环、还原先动吡啶环
5. **三条合成路线的「原料—取代位置」对应表**：Hantzsch（$\beta$-羰基酸酯 + 醛 + 氨 → 吡啶）、Skraup（苯胺 + 甘油 → 喹啉，取代位置由苯胺环决定）、Fischer（芳腙 + 路易斯酸 → 吲哚）
6. **五元杂环必须用温和试剂**：吡咯、呋喃不能用浓硫酸/强氧化剂；硝化用硝酸乙酰酯、磺化用吡啶–$\mathrm{SO_3}$ 加合物 —— 这是「活性高反而受限」的典型案例
7. **呋喃的定位与加成双重特殊性**：定位规则是例外（永远进另一 $\alpha$），且能作双烯体发生 Diels-Alder

## 例题与习题

### 典型例题

**例1**：比较碱性强弱。
> 解：(1) 两个氮的孤对电子均不参与共轭者碱性更强（吡啶型 > 双环共轭型）。(2) 邻位甲基**空间阻碍**氮与 $\mathrm{H^+}$ 结合 → 后者强。(3) 共轭酸有两个**能量相同的共振式**且正电荷主要在氮上、满足八隅体者碱性更强。(4) 氧电负性大于硫 → 前者强。**核心：碱性 = 孤对电子可及性 × 共轭酸稳定性。**

**例2**：比较酸性强弱。判据统一为「共轭碱的负电荷能否分散到电负性较大的氮原子上 / 能否保留完整苯环」——吡咯（负电荷可分散到氮）> 相应碳负离子型；稠环中能保留完整苯环的共轭碱更稳定。

**例3**：$\mathrm{A(C_6H_9N)}$ 不溶于酸，$\mathrm{H_2/Pd}$ 加氢得 $\mathrm{B(C_6H_{13}N)}$（溶于酸）；B 与等量 $\mathrm{CH_3I}$ 得 C，C 经 $\mathrm{Ag_2O/H_2O}$ 共热得 $\mathrm{D(C_7H_{15}N)}$，D 经彻底甲基化和霍夫曼降解得 **2-甲基-1,3-丁二烯**。推测 A~D。
> 解：A 不溶于酸 + B 溶于酸 → A 含**吡咯环**（孤对电子参与共轭、几乎无碱性），加氢后共轭破坏、四氢吡咯显碱性。B 与**等量** $\mathrm{CH_3I}$ 后即可霍夫曼降解 → B 为$3^{\circ}$ 胺 → A 为 N-取代吡咯。由降解片段 2-甲基-1,3-丁二烯反推另一甲基在 **$\beta$-位** → A 为 1,3-二甲基吡咯（N-甲基-3-甲基吡咯）。**钥匙：用「不溶于酸」一步锁定吡咯环。**

**例4**（1886，拉登堡）：2-甲基吡啶 + 乙醛/NaOH 得 $\mathrm{A(C_8H_9N)}$，A 加热加压催化氢化得毒芹碱 $\mathrm{B(C_8H_{17}N)}$。推测 A、B。
> 解：2-甲基吡啶侧链 $\alpha-H$ 酸性与甲基酮相当 → 强碱下形成碳负离子，对乙醛亲核加成后脱水（类羟醛缩合）→ A 为 2-丙-1-烯基吡啶；A 加 4 分子 $\mathrm{H_2}$ → B 为 2-丙基哌啶（毒芹碱骨架）。

**例5**（2012 年全国初赛试题）：喹啉酸（2,3-吡啶二羧酸）在 185–190 ℃ 释放 $\mathrm{CO_2}$ 转化为烟酸。
> 解：(1) 2-位羧基酸性更强（氮的吸电子作用更显著），与显碱性的氮发生**分子内酸碱反应**形成偶极离子，且 2-位羧基的氧负离子与 3-位羧基的氢形成氢键 → 能量最低构型为内盐。(2) 以偶极离子存在的化合物，其一级电离指「所有碱性位点已质子化的型体」再电离。(3) 2-位碳电子云密度降低更多 → **先脱 2-位羧基** → 烟酸 = 3-吡啶甲酸。**考点：氨基酸型偶极离子 + 分子内氢键 + 脱羧位置选择性。**

**例6**（2003 年全国决赛试题，Fischer 吲哚合成）：以对氨基苯甲醚为原料合成褪黑素，写出 A–I。
> 解：氨基 → 肼基须先重氮化（$\mathrm{NaNO_2/HCl}$），再还原（$\mathrm{Na_2S_2O_3/NaOH}$ 或 $\mathrm{SnCl_2/HCl}$ 或饱和 $\mathrm{NaHSO_3}$ + HCl + NaOH）得芳肼；与 $\mathrm{CH_3COCH_2CH_2CH_2COOH}$ 型酮酸生成芳腙，经**三聚磷酸加热**关环得吲哚乙酸骨架，再脱羧、最后用乙酸酐乙酰化氨基。**要点：Fischer 合成全链「重氮化—还原成肼—成腙—路易斯酸关环」。**

### 本讲习题要点
- **反应式书写**：吡啶侧链 $\alpha-H$ 缩合（$\mathrm{ZnCl_2}$）、吡啶 N-氧化物硝化（$\mathrm{HNO_3/H_2SO_4}$ 后 $\mathrm{PCl_3}$）、吡啶 + $\mathrm{PhLi}$、N-甲基吲哚/吡咯盐的亲电取代、$\mathrm{CHCl_3/KOH}$ 的卡宾扩环（吡咯 → 吡啶）
- **合成设计**：以苯甲醛为原料合成苯酚类（经吡啶/哌啶路线）；以 2-甲基吡啶 + ≤4 碳有机物合成 $\mathrm{C_{10}H_{10}N}$
- **均三嗪专题**：2,4,6-三氯均三嗪水解 → 三聚氰酸 → 异氰脲酸（酮式互变异构体）→ 三钠盐 + $\mathrm{Cl_2}$ → 三氯异氰尿酸（净水消毒剂），要求写单体结构、命名与方程式
- **机理推断**：氧化吡啶与溴乙烷反应产物 A 及随后的 NaOH 处理（A、B、C 与无机物 D、E 的推测，须判断两步反应类型）
- **含真题**：1886 拉登堡题、2003 年全国决赛（Fischer 吲哚合成 / 褪黑素）、2012 年全国初赛（喹啉酸）
