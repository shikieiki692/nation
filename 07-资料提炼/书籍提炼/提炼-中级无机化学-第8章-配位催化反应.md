## 二、教学逻辑锚点

**主线：从"计量反应"到"催化循环"——催化 = 计量反应基元的闭环运转。**

1. **配位不饱和是催化的前提**：RhH(CO)(PPh₃)₃ 在 25℃ 即可催化加氢甲酰化，而 IrH(CO)(PPh₃)₃ 不能——同一副族同构型化合物，只因 Rh 中心更易解离配体提供空位。这一对比是全章的"题眼"：催化活性来自"金属上出现空配位点的能力"。
2. **四个计量反应基元**（8.1）：
   - 配体解离取代（产生空位，Tolman 锥角定量位阻）；
   - 氧化加成/还原消除（氧化态 ±2、配位数 ±2，正逆成对，d⁸/d¹⁰ 金属专属）；
   - 插入/迁移（不饱和配体进入 M—R 键，¹⁴C 标记证明 CO 插入是烷基迁移）；
   - 配体修饰（配位后配体被亲核/亲电试剂活化）。
3. **催化循环 = 基元的闭环组合**（8.2）：金属回到起始态、催化剂不被消耗。工业实例构成"基元→循环→应用"的完整链条：异构化（M-H+烯烃）、氢化（OA+H₂→插入→RE）、氢硅化/氢氰化、加氢甲酰化、Ziegler-Natta 聚合、Wacker 氧化、Monsanto 乙酸合成。

**教学展开顺序建议**：配位不饱和概念 → 配体解离取代（Tolman 锥角）→ 氧化加成/还原消除（4 机理）→ 插入/迁移（CO 插入）→ 配体修饰 → 均相催化循环定义 → Wilkinson 氢化（最清晰循环）→ Wacker（双金属协同）→ 加氢甲酰化/Monsanto（动力学证据）→ Ziegler-Natta（多相）。

## 四、知识点提取

### 4.1 化学计量反应总览（8.1 引论）

- **配位不饱和（coordinative unsaturation）**：金属中心电子数 <18e、可提供空配位点，是催化循环的启动条件。
- 对比实例：RhH(CO)(PPh₃)₃ 与 IrH(CO)(PPh₃)₃ 同为 d⁸ 16e，但 Rh 化合物 25℃ 即催化烯烃加氢甲酰化；Ir 化合物需更高温度才释放配体。同族第二过渡系 M—L 键更强、解离更难。

### 4.2 配体解离取代（8.1.1）

- **离解机理（D）**：Ni(CO)₄ + CO\* → Ni(CO)₃(CO\*) + CO；速率 r = k[Ni(CO)₄]（与进入配体浓度无关，一级，慢步为 M—L 断裂）。
- **离解+缔合双路径**：Mo(CO)₆ 的取代 r = k₁ + k₂[L]，k₁ 为离解路径、k₂[L] 为缔合（S_N2 型）路径。
- **Tolman 锥角（表 8.1）**——膦配体空间位阻的定量标尺（θ，顶点在金属中心）：

| 配体 | θ/° | | 配体 | θ/° |
|------|----|----|------|----|
| PH₃ | 87 | | PPh₃ | 145 |
| PF₃ | 104 | | P(o-C₆H₄CH₃)₃ | 194 |
| P(OMe)₃ | 107 | | P(C₆F₅)₃ | 184 |
| PMe₃ | 118 | | | |

- 锥角越大 → 空间位阻越大 → 配体解离越容易（习题 8.3 直接考察：大锥角膦的反位配合物与 CO 的取代速率最快）。

### 4.3 氧化加成与还原消除（8.1.2）

- **定义**：氧化加成（OA）= A—B 断裂、两个 M—A/M—B 形成，金属氧化态 +2、配位数 +2、电子数 +2；还原消除（RE）为其严格逆过程。
- **质子化是特殊"氧化加成"**：Fe(CO)₅ + H⁺ → [FeH(CO)₅]⁺（Fe 0 → +II），H⁺ 接受金属一对 d 电子。
- **适合 OA 的金属**：d⁸（Pt²⁺、Ir⁺、Rh⁺）与 d¹⁰（Pd⁰、Pt⁰、Ni⁰）——低价、富电子、有可氧化电子对。经典实例：反-IrCl(CO)(PPh₃)₂ + HCl → 八面体 18e（Ir(I) → Ir(III)）。
- **可氧化加成的分子（表 8.3）**：H₂、HX、X₂、R—X、RCO—X、RSO₂—X、O₂、R₃Si—H、R₃Ge—H、R₃Sn—H、R—SH 等——键能过高者（如 N₂ 941 kJ/mol）几乎不发生 OA。
- **4 种机理**：
  1. **离子机理**：A—B 先异裂为 A⁻/B⁺（或离子对），再分步加成（强极性键，如 H⁺/HCl 型）。
  2. **S_N2 机理**：亲核金属背攻中心碳，立体化学反转（R—X 型，构型翻转）。
  3. **自由基机理**：A—B 均裂产生自由基，分步转移（Pt⁰ 与 R—X，常有 CIDNP/自由基捕获证据）。
  4. **一步协同**：三中心过渡态，A—B 断键与 M—A/M—B 成键同步，保留立体化学（H₂、Si—H 等非极性键，cis 加成）。
- **RE 条件**：两个配体必须处于 **cis** 位；金属高氧化态；配体可形成稳定 A—B 键；配位饱和（>16e）推动 RE 释放空位。

### 4.4 插入/迁移反应（8.1.3）

- **CO 插入 = 烷基迁移**：M—CH₃ + CO → M—C(=O)CH₃。¹⁴C 标记证明：进入产物的是**顺位已配位的 CO**，而非外加 CO——烷基迁移到顺式 CO 上，空出配位点后外加 CO 补位。
- **中间体**：五配位（16e 或 18e 中间体取决于起始构型）；配体促进（加 PPh₃ 加速，因形成五配位中间体）。
- **多重插入**：W(CH₃)₆ 与 CO 反应可逐步插入多个 CO，生成多酰基物种（W(COCH₃) 系列）。
- 烯烃配位后也可插入 M—H/M—C（详见 8.2.1 异构化、8.2.2 氢化的循环步骤）。

### 4.5 配体修饰（8.1.4）

- **亲核进攻配位 CO**：OH⁻ + Fe(CO)₅ → [Fe(CO)₄COOH]⁻（金属羧基负离子）。配位 CO 比自由 CO 更亲电（π 反馈转移电荷密度）。
- **亲核进攻配位 NO**：OH⁻ + [Fe(CN)₅NO]²⁻ → [Fe(CN)₅NO₂]⁴⁻ + H⁺（亚硝酰 → 硝基）。
- **亲核进攻配位烯烃**：RO⁻ + [Ir(CO)₃(PPh₃)₂]⁺ → 烷氧基配合物——Wacker 反应的分步模型（见 8.2.6）。
- **H⁻ 还原配体（亲核加氢）**：
  - η⁵-C₅H₅ → η⁴-C₅H₆（环戊二烯基接受 H⁻）；
  - η⁶-C₆H₆ → η⁵-C₆H₇（环己二烯基）；
  - 三苯甲基正离子 (C₆H₅)₃C⁺ 可**夺 H⁻**：η⁵-C₅H₅(CO)₂Fe—CHRCH₂R' → [η⁵-C₅H₅(CO)₂Fe(η²-H₂C=CHR)]⁺ + CH(C₆H₅)₃——烷基 σ 键转烯烃 π 键。
- **环金属化（cyclometalation）**：三芳基膦配体时 H 从芳基邻位转移到金属 → 消去 HX → 环金属配合物。例 Ir(PPh₃)₃Cl 受热消 HCl 生成环金属化产物（分子内 C—H 活化）。
- **配位分子氧**：O—O 键长与可逆性关联——完全 OA 生成 O₂²⁻（O—O 近单键长，不可逆）；温和氧化加成生成可逆加成物（类氧合血红蛋白，O—O 较短）。
  - (Ph₃P)₂Pt(O₂) + CO₂ → 过氧碳酸配合物；
  - IrCl(CO)(O₂)(PPh₃)₂ 氧化 SO₂ → 硫酸根配合物（¹⁸O 示踪证实 O 来源）。
  - 配位 O₂ 反应活性大于游离 O₂：配位削弱 O—O 键且活化。

### 4.6 催化循环总论（8.2 引论）

- **均相催化**：在溶液中，催化剂前体迅速进入一系列平衡，真正概念是**催化循环中的中间体**而非单一"催化剂分子"。
- **催化循环特征**：循环终止时金属回到起始态；由反应物 A 经中间体 B 生成产物 C（图 8.4，I/II 两个循环）。
- 循环中每一步都是 8.1 的计量反应类型（配体解离/配位、OA/RE、插入、配体修饰），只是被组织成闭环。

### 4.7 异构化（8.2.1）

- **烯烃双键迁移**：第 8–10 族金属氢配合物催化 1-烯烃 → 顺/反-2-烯烃混合物（热力学稳定产物）。
- **机理**：① LₙMH + RCH=CH₂ 配位；② H 从金属迁移到烯烃 β-碳 → 金属烷基；③ **β-氢消除**（逆反应）消去烯烃。四中心环状过渡态。
- **马氏/反马氏决定能否异构化**：
  - 反马氏加成 → 一级烷基（仅 1 个 β-C）→ β-H 消除只能回到原烯烃 → **无异构化**；
  - 马氏加成 → 二级烷基（2 个 β-C）→ 可消除 CH₃ 侧 H 回原烯烃，也可消除 CH₂R 侧 H 得 2-烯烃 → **异构化**。
- 例：RhH(CO)(PPh₃)₃ + C₂F₄ → Rh(CF₂CF₂H)(CO)(PPh₃)₂（H 结合到 β-C，四中心过渡态证据）。
- RuHCl(CO)(PPh₃)₃ 催化二烷基马来酸酯顺/反异构化（图 8.5）。

### 4.8 氢化反应（8.2.2）

- **Wilkinson 催化剂 RhCl(PPh₃)₃** 在苯/苯-乙醇中室温氢化烯烃、炔烃（图 8.6 循环）：
  1. H₂ 氧化加成（Rh(I) → Rh(III) 二氢化物 A）；
  2. 膦解离 → 五配位、产生空位；
  3. 烯烃配位（B）；
  4. 烯烃插入 M—H → 烷基配合物（C）；
  5. 还原消除烷烃，重新配位膦 → 催化剂再生。
- **选择性**：氢化速率取决于还原位点基团性质，可选择性还原多个 C=C 中的一个（分子内化学选择性）。
- 其他体系：RhCl₃(py)₃ + NaBH₄/DMF；也适用于 C≡C、C=O、—N=N—、—CN。
- **对映选择性氢化（不对称催化里程碑）**：手性膦配体 DiPAMP 与 Rh 配合物催化前手性（prochiral）烯烃 R'CH=C(NHR₂)CO₂H 还原，合成 L-多巴（抗帕金森药物），光学纯度 >95%（Knowles，2001 诺贝尔奖）。

### 4.9 烯烃的其他催化加成（8.2.3）

- **氢硅化（hydrosilylation）**：RCH=CH₂ + HSiR₃ → RCH₂CH₂SiR₃。催化剂：六氯铂酸（Speier）、Co/Rh/Pd/Ni 膦配合物。
  - 机理关键：Si—H 对金属的**氧化加成**生成配位饱和六配位中间体（反-IrCl(CO)(PPh₃)₂ + HSiR₃ → IrHCl(CO)(PPh₃)₂SiR₃）；随后 M—H 与烯烃加成、烷基与 SiR₃ 还原消除。
- **氢氰化（hydrocyanation）**：Ni 亚磷酸酯配合物催化 HCN 对烯烃加成，生产**己二腈**（尼龙 66 前体），Lewis 酸共催化。
  - NiL₄ + HCN → NiH(CN)L₂ + 2L（L = P(OR)₃）；
  - 循环：烯烃配位 → 插入 Ni—H → 还原消除腈 → 再氧化加成 HCN 再生 NiH(CN)L₂。
  - 该循环串联氧化加成、加成、插入、还原消除，是"基元闭环"的又一范例。

### 4.10 加氢甲酰化（8.2.4）

- **总反应**：RCH=CH₂ + H₂ + CO → RCH₂CH₂CHO（端基双键加 H + 甲酰基 HCO，产物比原料多 1 C 的醛）；醛可再氢化为醇。
- **钴催化**：Co₂(CO)₈ + H₂ → 2HCo(CO)₄ → 失 CO → HCo(CO)₃（活性物种）；15℃、2×10⁷ Pa（200 atm）得 C₇–C₉ 醇，直链:支链 = 3:1；副反应把烯烃还原为烷烃（无实用价值）。
- **铑催化（优越）**：RhH(CO)(PPh₃)₃，25℃、1 atm 即有活性，产物只有醛。循环（图 8.9，起始物 A = RhH(CO)₂(PPh₃)₂）：
  1. 烯烃加成到 A → 六配位烯烃配合物；
  2. 烯烃插入 Rh—H → 烷基配合物 B；
  3. CO 迁移插入 Rh—C → 酰基配合物 C；
  4. H₂ 氧化加成 → 二氢化酰基配合物 D（**唯一改变 Rh 氧化态的一步，很可能是决速步**）；
  5. 醛还原消除 → 产物醛 + E，E 与 CO 加成再生 A。
- **高浓度 PPh₃ → 直链醛**：PPh₃ 抑制膦解离形成单膦配合物，迫使烯烃进攻二膦配合物（反马氏加成 → 直链）。

### 4.11 Ziegler-Natta 聚合（8.2.5）

- **体系**：TiCl₄ + Al(C₂H₅)₃，烃溶剂、常压，乙烯聚合；可推广至苯乙烯、丁二烯、环戊二烯/1,4-己二烯共聚（合成橡胶）；VOCl₃ 可替代 TiCl₄（更有效）。
- **多相催化**：活性物为**纤维状 TiCl₃**（TiCl₄ 被烷基铝原位还原；也可预先制备 TiCl₃）。
- **烷基铝双重作用**：① 还原 TiCl₄ → TiCl₃；② 在 TiCl₃ 表面以烷基取代氯（形成 Ti—C 活性位）。
- **机理（图 8.10）**：乙烯配位到 Ti 表面空位 → 烷基迁移到配位乙烯（链增长）→ 新空位再配位乙烯 → 循环。

### 4.12 Wacker 过程（8.2.6）

- **计量反应**：C₂H₄ + PdCl₂ + H₂O → CH₃CHO + Pd + 2HCl。
- **催化化改造（三反应耦合）**：
  - Pd 再氧化：Pd + 2CuCl₂ → PdCl₂ + 2CuCl（可能经氯桥**内球电子转移**）；
  - Cu 再生：2CuCl + 2HCl + ½O₂ → 2CuCl₂ + H₂O；
  - 总反应：C₂H₄ + ½O₂ → CH₃CHO（Pd 浓度可很低，定量进行）。
- **机理**（Cl⁻ > 0.2 mol·L⁻¹ 时 Pd 以 [PdCl₄]²⁻ 存在）：
  1. [PdCl₄]²⁻ + C₂H₄ → [PdCl₃(C₂H₄)]⁻ + Cl⁻（快）；
  2. 水解配位：+ H₂O → [PdCl₂(H₂O)(C₂H₄)] + Cl⁻；
  3. **水亲核进攻配位烯烃** → Cl—Pd—CH₂CH₂OH（羟烷基配体，即 8.1.4 配体修饰的实例）；
  4. β-H 消除/质子转移 → 乙醛 + Pd⁰。
- **底物扩展**：末端烯烃 → 醛（乙烯 → 乙醛），其他烯烃 → **酮**（丙烯 → 丙酮）；可于醋酸/乙烯醋酸酯/醇等非水介质中进行。

### 4.13 羰基化反应——Monsanto 乙酸合成（8.2.7）

- **总反应**：CH₃OH + CO → CH₃COOH；催化剂 RhI₂(CO)₂⁻ + I⁻ 促进；年产乙酸上百万吨。早期用碘化钴高温高压，1960s 后用铑温和条件。
- **催化循环（图 8.12）**：
  ① CH₃I 氧化加成到 Rh(I)（Rh(I) → Rh(III)）；② CO 迁移插入 Rh—CH₃ → 酰基 Rh 中间体；③ CO 配位补充空位；④ 还原消除 CH₃COI（乙酰碘）；⑤ CH₃COI + H₂O → CH₃COOH + HI；⑥ HI + CH₃OH → CH₃I + H₂O（再生 CH₃I）。
- **动力学与光谱证据**：
  (i) 对 Rh 一级；(ii) 对 CH₃I 一级；(iii) 与 CO 压力无关（>3×10⁵ Pa）；速率方程 **r = k[Rh][CH₃I]**——证明**决速步 = CH₃I 氧化加成**，CO 配位快速可逆；(iv) IR 证实中间体 cis-[Rh(CO)₂I₂]⁻。

### 4.14 前沿方向（8.2.7 末）

- 绿色氧化剂（O₂/空气替代化学氧化剂）、绿色溶剂；选择性氧化；**双氮功能化**（N₂ 直接转化）；固体/气体燃料 → 液体燃料；不对称催化（手性配体金属催化剂，现代合成与药物化学核心）。

## 十五、踩坑回流

- **Tolman 锥角方向性**：锥角大 = 位阻大 = 解离快 = 取代速率快（习题 8.3），与直觉"配体大反应慢"相反——快在"空位产生"环节。
- **CO 插入方向**：是**烷基迁移到顺位 CO**（¹⁴C 证明），不是 CO 迁移到烷基；讲授时箭头方向勿画反。
- **加氢甲酰化决速步**：Rh 循环中唯一氧化态改变步是 H₂ 氧化加成（很可能决速）；CO 迁移插入不是决速步。
- **Monsanto 速率与 CO 无关**：不是"CO 不参与"，而是 CO 配位为快速可逆平衡；决速步是 CH₃I 氧化加成（r = k[Rh][CH₃I]）。
- **Wacker 区域选择性**：末端烯烃 → 醛/甲基酮（马氏），非末端 → 酮；水进攻配位烯烃是亲核进攻（8.1.4 配体修饰的应用）。
- **OA 立体化学判据**：协同 → cis 加成（保留构型）；S_N2 → 反转；自由基 → 外消旋——做题时先判机理再判立体。
