# Clayden 第9章：使用有机金属试剂构建C-C键 资料提炼

---

## 一、核心概念与定义

### 1.1 有机金属化合物的定义
- **有机金属（organometallic）**：含有碳-金属（C-M）共价键的化合物。（见 [[有机金属试剂]]）
- **核心例子**：[[有机锂试剂|有机锂]]（RLi）、[[Grignard试剂|格氏试剂]]（RMgX，卤化烷基镁）、[[有机锌试剂|有机锌]]（RZnX）。
- **重要性**：有机金属试剂是构建 C-C 键最重要的方式之一。在保幼激素合成中，16 根 C-C 键有 7 根由有机金属形成；某酶抑制剂合成中，20 根 C-C 键有 8 根由有机金属形成。

### 1.2 C-M 键的极性
- **电负性差异**：金属电负性 < 碳（C: 2.5, Li: 1.0, Na: 0.9, Mg: 1.3, Al: 1.6）。
- **极化方向**：电子密度偏向碳端 → 碳带部分负电荷（[[碳负离子|碳阴离子]]特征） → 碳成为亲核中心。
- **MO 解释（以 MeLi 为例）**：
  - 充满的 C-Li σ 轨道能量接近碳的 sp³ 轨道（而非锂的 2s 轨道）。
  - 碳 sp³ 对 σ 键贡献更大 → σ 键在碳上有更大的系数 → 反应发生在碳上。
  - 但 MeLi 不是真正的离子化合物 Me⁻Li⁺，仅在机理图中有时用 Me⁻ 表示。

### 1.3 有机金属的碱性
- **极强碱**：甲烷 pKa ≈ 50，苯 pKa ≈ 43 → 有机金属的共轭酸极弱 → 平衡极度偏向烷烃/芳烃一侧。
- **与水反应**：高度放热，快速将 RLi/RMgX 质子化为烷烃 → 必须完全隔绝水分。
- **丁基锂（BuLi）的碱性**：最强碱之一，几乎可以使任何 C-H 去质子化 → 可用于制取其他有机锂试剂。

### 1.4 有机金属的亲核性
- 有机金属面对亲电的羰基，扮演亲核试剂角色。
- C-M σ 轨道 HOMO → C=O π* LUMO → 新 C-C σ 键 + π 键断裂 → 氧负离子质子化（后处理）。

## 二、格氏试剂（Grignard Reagents, RMgX）

### 2.1 制备
- **反应**：卤代烃（R-X, X = I, Br, Cl）+ Mg⁰ → [[Grignard试剂|RMgX]]（卤化烷基镁）
- **溶剂**：醚类（Et₂O 或 THF），Mg(II) 倾向于四面体结构，与两分子醚配位。
- **机理**：Mg 对 C-X 键的氧化插入（oxidative insertion），Mg(0) → Mg(II)。可能涉及自由基中间体。
- **引发**：Mg 表面通常有 MgO 氧化膜 → 需碘/I₂(CH₂)₂或超声波去除 → 一旦有格氏试剂形成，催化后续反应。
- **底物范围**：烷基、芳基、烯丙基、酰基均可。**限制**：R 上不能包含与格氏试剂反应的官能团（如醛基），但缩醛可作为保护基。

### 2.2 格氏试剂的结构
- **真实结构**：以二聚体、四聚体或六聚体形式存在，常与溶剂分子配位（这也是 BuLi 能溶于烃类的原因）。
- **书中简化**：用单体结构表示。

### 2.3 与亲电试剂的反应
- **与 CO₂ 反应**：RMgX + CO₂ → RCOO⁻MgX²⁺ → 酸性后处理 → RCOOH（羧酸，多一个碳）。
  - 实验：向 RMgX 的 THF/Et₂O 溶液中加入固态 CO₂ 或通入干燥 CO₂ 气流。
  - 注意：CO₂ 加成降低氧化态一级。
- **与甲醛反应**：RMgX + CH₂O → RCH₂O⁻ → 伯醇（多一个碳）。
- **与其他醛反应**：RMgX + R'CHO → R'CH(O⁻)R → 仲醇。
- **与酮反应**：RMgX + R'COR'' → R'R''C(O⁻)R → 叔醇。

## 三、有机锂试剂（Organolithium, RLi）

### 3.1 制备
- **反应**：卤代烃（R-X, X = Br, Cl）+ 2 Li → [[有机锂试剂|RLi]] + LiX
- **机理**：Li(0) → Li(I) 氧化插入，每步需要两个 Li 原子。
- **与格氏试剂的区别**：Li 不与卤素相连（卤素被第二个 Li 带走成为 LiX）；可用烃类溶剂（戊烷、己烷）。

### 3.2 比格氏试剂更强的碱性
- RLi 碱性 > RMgX（锂正电性弱于镁，更不稳定的碳阴离子 → 更强碱性）。
- 应用：可将炔烃去质子化（炔烃 pKa ≈ 25）→ 炔基锂。

### 3.3 卤素-金属交换（Halogen-Metal Exchange, 锂卤交换）
- **反应**：R'Li + R-X → R-Li + R'X（锂与卤素互换位置）。
- **驱动力**：pKa 差异。苯（pKa ≈ 43）比丁烷（pKa ≈ 50）酸性更强 → 苯基配合物更稳定 → 反应向生成 PhLi 方向进行。
- **适用**：芳基锂、烯基锂的制备；溴代物和碘代物比氯代物反应更快。
- **限制**：由于转金属反应，格氏试剂/有机锂不能直接与卤代烃偶联（会产生三种偶联产物混合物）。

## 四、炔基有机金属

### 4.1 炔烃的去质子化
- **酸性来源**：sp 杂化碳的 C-H 键（50% s 成分 → 电子更靠近核 → 更稳定）。
- **炔烃 pKa ≈ 25**：可用 NaNH₂（氨基钠）、BuLi、EtMgBr 去质子化。
- **产物**：炔基钠（离子盐，极性溶剂）、炔基锂（共价性更大，非极性溶剂）、炔基镁。

### 4.2 炔基有机金属的加成
- 炔基锂/炔基镁可加成到羰基 → 生成含炔基的醇。
- **应用**：
  - 红霉内酯 A（erythronolide A）合成的起始步骤。
  - 合金欢醇（farnesol）合成的倒数第二步。
  - 乙炔基雌甾二醇（口服避孕药活性成分）：炔基锂 + 雌酮。

### 4.3 三键的稳定性与酸性对比
| 化合物 | 杂化 | 性质 | pKa |
|:---|:---|:---|:---|
| N₂（氮气） | sp | 孤对在 sp → 无碱性、无亲核性 | — |
| HCN | sp | N 上孤对无碱性；C-H 可去质子 | ≈10 |
| 腈 R-CN | sp | 无亲核性、无碱性 | — |
| 炔烃 R-C≡C-H | sp | 烃中酸性最强 | ≈25 |

## 五、转金属反应与有机锌

### 5.1 转金属反应（Transmetalation）
- **定义**：用正电性较弱的金属盐处理有机金属 → 生成新的有机金属。
- **反应**：RMgX + ZnBr₂ → RZnBr + MgBr₂。
- **驱动力**：更正电性的金属（Mg/Li）以离子盐形式进入溶液，较不活泼的金属（Zn）带走烷基。

### 5.2 有机锌（RZnX）的特点
- **活性较低**：比 RLi/RMgX 更温和 → 与强亲电试剂（如酰氯）反应更可控。（见 [[有机锌试剂]]）
- **合成应用**：根岸英一（E. Negishi）发展有机锌化学，获2010年诺贝尔化学奖。

### 5.3 有机金属的"软化"
- 现代方法：将亚铜盐（如 CuI）随 RLi 或 RMgX 一同加入（见 [[铜锂试剂]]）。
- 用途：使有机金属对卤代烃的取代可行；用于共轭加成（Chapter 22 详述）。

## 六、用有机金属构建 C-C 键的产物总结

### 6.1 对不同亲电试剂的加成产物
| 亲电试剂 | 有机金属加成产物 | 氧化态变化 |
|:---|:---|:---|
| CO₂ | 羧酸 RCOOH（多一个碳） | 不变（碳中心） |
| 甲醛 CH₂O | 伯醇 RCH₂OH（多一个碳） | 降低一级 |
| 醛 R'CHO | 仲醇 R'CH(OH)R | 降低一级 |
| 酮 R'COR'' | 叔醇 R'R''C(OH)R | 降低一级 |

### 6.2 仲醇合成的灵活性
- 同一仲醇可由不同路线合成：
  - **路线 A**：格氏试剂 A + 醛 B
  - **路线 B**：格氏试剂 B + 醛 A
  - **路线 C**：酮还原（NaBH₄）
- 选择依据：原料可得性、产率、成本。如米酵菌酸（bongkrekic acid）合成中使用两种不同路线制取相似的仲醇。

### 6.3 叔醇合成的灵活性
- 三组分中的任一组分可来自有机金属，另外两组分为醛/酮。
- 如橙花叔醇（nerolidol）合成中，有三种原则上可行的路线，选择取决于试剂可购得性。

## 七、醇的氧化——从有机金属加成到氧化还原循环

### 7.1 Cr(VI) 氧化剂
| 试剂 | 全称 | 特点 |
|:---|:---|:---|
| CrO₃ | 三氧化铬 | 铬酸的酸酐，遇水生成铬酸 |
| Collins 试剂 | CrO₃·吡啶₂ | 不稳定，少用 |
| PDC | 重铬酸吡啶鎓 | 可溶于有机溶剂，常用 |
| PCC | 氯铬酸吡啶鎓 | 可溶于有机溶剂，最常用 |

### 7.2 氧化产物
- **伯醇** → 醛（PCC 控制）→ 羧酸（强氧化剂如 NaClO 过度氧化）
- **仲醇** → 酮
- **叔醇** → 无法氧化（除非断裂 C-C 键）

### 7.3 Cr(VI) 氧化机理
1. Cr(VI) 与醇形成 Cr(VI) 酯
2. 环状消除：移去一个 H 原子/质子（从 OH）+ 移去第二个 H 及其电子（从 C-H，即"负氢"）
3. Cr(VI) → Cr(IV) → 进一步反应 → Cr(III)（绿色）
- 关键：从 C-H 上移去 H⁻ 意味着同时移去一个质子和一对电子 → 氧化剂完成此过程。

### 7.4 氧化还原循环的合成意义
- 醛/酮 + 有机金属 → 醇 → 氧化 → 醛/酮 → 再与有机金属 → ...
- 通过氧化还原循环，可以灵活构建分子骨架。

## 九、关键结论与规则

### 9.1 有机金属试剂操作要点
| 要点 | 说明 |
|:---|:---|
| 溶剂 | 非质子溶剂（Et₂O, THF, 烃类） |
| 气氛 | 惰性气体（N₂/Ar），RLi/RMgX 也与 O₂ 反应 |
| 后处理 | 反应完成后加 H₂O 或 NH₄Cl(aq) 质子化 |
| 禁忌 | 绝对无水（水会质子化试剂 → 烷烃） |
| 引发 | 格氏试剂需碘/超声波去除 MgO 氧化膜 |

### 9.2 有机金属碱性排序
- RLi > RMgX >> 其他有机金属
- BuLi 是最强碱之一，几乎可以使任何 C-H 去质子化
- pKa 驱动反应方向（卤素-金属交换中，pKa 更小的碳阴离子更稳定 → 反应方向）

### 9.3 制取有机金属的五种方法
1. Mg 对卤代烃的氧化插入 → 格氏试剂
2. Li 对卤代烃的氧化插入 → 有机锂
3. 炔烃的去质子化 → 炔基有机金属
4. 卤素-金属交换（锂卤交换）→ 芳基锂/烯基锂
5. 转金属反应 → 有机锌等

### 9.4 C-C 键构建的核心反应
- **CO₂ 加成**：有机金属 + CO₂ → 羧酸（多一个碳）
- **甲醛加成**：有机金属 + CH₂O → 伯醇（多一个碳）
- **醛加成**：有机金属 + RCHO → 仲醇
- **酮加成**：有机金属 + RCOR' → 叔醇

### 9.5 氧化还原循环
- 醇的氧化（Cr(VI): PCC/PDC）→ 醛/酮 → 再与有机金属加成 → 醇
- 伯醇 → 醛（PCC 控制）或 羧酸（强氧化剂）
- 仲醇 → 酮
- 叔醇 → 不可氧化

### 9.6 有机金属直接偶联的限制
- 格氏试剂/有机锂不能直接与卤代烃偶联（转金属反应导致三种产物混合物）。
- 唯一例外：炔基金属（因炔基碳阴离子更稳定，不发生交换）。
- 直接偶联需要过渡金属催化（Heck, Suzuki 等，Chapter 40 详述）。

## 十三、竞赛题型线索

### 13.1 产物预测型
- 给定有机金属（RMgX 或 RLi）+ 亲电试剂（CO₂、CH₂O、RCHO、RCOR'），预测加成产物（酸、伯醇、仲醇、叔醇）。
- 给定醇产物，逆推可能的有机金属 + 羰基组合。

### 13.2 机理书写型
- 书写 Mg 对 C-X 键氧化插入的机理（可能涉及自由基中间体）。
- 书写有机金属对羰基加成的两步机理（亲核进攻 + 质子化后处理）。
- 书写 Cr(VI) 氧化醇的环状机理（Cr(VI) 酯 + 环状消除）。
- 书写卤素-金属交换的箭头（BuLi 对 Br 的亲核进攻）。

### 13.3 反应活性判断型
- 比较 RLi 与 RMgX 的碱性/亲核性差异及原因。
- 判断卤素-金属交换的方向（pKa 驱动）。
- 比较不同氧化剂（PCC vs 强氧化剂）对伯醇的氧化选择性。

### 13.4 合成设计型
- **逆合成切断**：目标醇 → 切断 C-C 键 → 识别有机金属 + 醛/酮。
- 仲醇合成的路线选择（灵活性与可得性）。
- 从简单原料出发，通过有机金属加成 + 氧化循环构建复杂分子骨架。

### 13.5 条件选择型
- 格氏试剂制备：为什么需要醚溶剂？为什么需要引发？为什么必须无水？
- 有机锂 vs 格氏试剂：何时选择哪一个？（碱性差异、溶解性差异）
- PCC vs 强氧化剂：如何控制伯醇停留在醛阶段？

### 13.6 官能团兼容性型
- 判断哪些官能团在有机金属试剂上可兼容（如缩醛保护醛基）。
- 判断哪些官能团会干扰有机金属反应（如含活泼 H 的官能团）。
