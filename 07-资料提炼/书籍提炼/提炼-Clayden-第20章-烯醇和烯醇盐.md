# Clayden 第20章：烯醇和烯醇盐的形成和反应 资料提炼

---

## 一、核心概念与定义

### 1.1 烯醇（Enol）与烯醇盐（Enolate）
- **[[烯醇]]**：含有 C=C 双键且双键碳上直接连有 OH 基的化合物（"烯-醇"）。
- **烯醇盐**：烯醇的共轭碱，通过失去 O-H 质子生成；也可由羰基化合物直接失去 α-H 生成。
- **酮式-烯醇式[[互变异构]]**：羰基化合物与其烯醇式之间的动态平衡，通过分子内质子转移实现。平衡中质子从 C 转移到 O，双键同时迁移。
- **关键区别**：互变异构（tautomerism）是两个不同结构之间的真实平衡，用平衡箭头表示；而离域（resonance）是电子的移动，两种共振式是同一物种的不同描述。

### 1.2 烯醇化的本质
- 烯醇化是电子转移过程：C-H 键断裂、O-H 键形成、C=C 双键迁移。
- pH 不变：质子被碳失去、被氧获得，净结果为零。
- 即使烯醇式占比极小（通常 10⁻⁵~10⁻⁶），烯醇化仍在持续进行——这是理解烯醇化学的关键。

### 1.3 为什么简单醛酮以酮式为主？
- **键能分析**：C=O（720 kJ/mol）+ C-H（440 kJ/mol）= 1160 kJ/mol > C=C（620 kJ/mol）+ O-H（500 kJ/mol）= 1120 kJ/mol。
- 酮式比烯醇式约稳定 40 kJ/mol，导致平衡常数 K ≈ 10⁻⁶。
- **特殊例外**：1,3-二羰基化合物因共轭稳定化，烯醇式含量可高达 33%~100%。

## 二、烯醇化的机理

### 2.1 酸催化烯醇化
- **机理**（两步）：
  1. 羰基氧被质子化 → 生成氧鎓离子（oxocarbenium ion）
  2. α-碳失去质子 → 形成烯醇
- **特征**：酸在最后一步再生（催化循环）；中间体为中性烯醇。
- **区域选择性**：生成多取代烯醇（热力学控制）——酸催化下先在氧上质子化，过渡态中羰基部分带正电，烷基给电子有利于多取代侧。

### 2.2 碱催化烯醇化
- **机理**（两步）：
  1. 碱夺取 α-氢 → 形成烯醇盐阴离子
  2. 氧原子被水质子化 → 形成烯醇
- **特征**：碱在最后一步再生（催化循环）；中间体为烯醇盐阴离子。
- **区域选择性**：生成少取代烯醇盐（动力学控制）——碱催化下去质子步骤的过渡态中羰基部分带负电，少取代侧位阻小、反应快。

### 2.3 质子去氘交换证据
- 将羰基化合物溶于 D₂O 中，α-氢被氘取代——证明烯醇化持续进行。
- 机理：烯醇化 → 氧上得 D → 逆烯醇化时碳上得 D 而非 H。
- 可重复进行，最终所有 α-H 均被 D 取代。

## 三、动力学稳定与热力学稳定的烯醇

### 3.1 动力学稳定的烯醇
- **原理**：在严格无酸碱条件下制备的烯醇，因无法催化互变异构，寿命大幅延长。
- **实例**：乙烯醇（vinyl alcohol）——900°C 高温裂解 1,2-乙二醇制备，寿命足以记录 NMR 光谱，但最终缓慢转变为乙醛。
- **空间位阻稳定**：双苯基取代基包裹烯醇碳，阻止质子试剂接近。

### 3.2 热力学稳定的烯醇：1,3-二羰基化合物
- **稳定化因素**：
  1. **共轭**：烯醇的 C=C 与第二个 C=O 共轭，形成 O=C-C=C-OH 离域体系
  2. **分子内氢键**：如乙酰丙酮（acetylacetone）形成六元环分子内氢键
- **实例**：
  - 双甲酮（dimedone）：烯醇式在 CDCl₃ 中占 33%
  - 乙酰丙酮：烯醇式在 CDCl₃ 中占 80%（共轭 + 分子内氢键）
  - 维生素 C（抗坏血酸）：完全以烯二醇形式存在，具有酸性
  - 苯酚：极端情况——完全以烯醇（芳香醇）形式存在

### 3.3 双甲酮的特殊性
- NMR 显示两个不同的 CH₂ 基（a 和 b）表现为等价信号——这是两个等价烯醇式快速互变异构（质子转移）的结果，而非离域。
- 互变异构（质子移动）与离域（电子移动）的本质区别。

## 四、烯醇化的后果

### 4.1 β,γ-不饱和羰基的共轭异构化
- β,γ-不饱和羰基化合物在痕量酸碱存在下，通过烯醇化/烯醇盐中间体迅速转变为更稳定的 α,β-共轭异构体。

### 4.2 α-立体中心的外消旋
- **核心规律**：羰基 α-位的立体中心（含氢）在烯醇化条件下会外消旋化。
- **原因**：烯醇为平面型（sp² 杂化），不具有手性；逆烯醇化时可从平面两侧等概率质子化。
- **应用**：β-酮酯的外消旋；布洛芬（ibuprofen）在人体内通过烯醇化外消旋。
- **保护策略**：α-氨基酸在碱中以羧酸阴离子形式存在（不烯醇化）；酸中氨基被质子化（-NH₃⁺ 抑制烯醇化）。

## 五、烯醇的α-卤代反应

### 5.1 酸催化卤代
- **机理**：
  1. 酸催化烯醇化 → 生成烯醇
  2. 烯醇的亲核碳进攻 Br₂ → 生成 α-溴代酮
- **特点**：
  - 可用 Lewis 酸（如 AlCl₃）催化
  - 烯醇比苯环更活泼——溴代优先发生在 α 位
  - 可控制在单卤代（仅加 1 当量卤素）
- **区域选择性**：酸催化倾向于多取代侧（热力学烯醇）
- **酸促卤代能单取代的原因**：引入的卤原子吸电子 → 使氧更难质子化（第一步减慢）→ 同时阻碍同侧再次烯醇化

### 5.2 碱催化卤代（卤仿反应）
- **特点**：碱促卤代不能停留在单卤代——每次卤代使剩余 α-H 酸性增强 → 更易烯醇化 → 连续卤代直至三卤代。
- **卤仿反应机理**（以 CH₃COCH₃ + Br₂/NaOH 为例）：
  1. 碱催化烯醇化 → 烯醇盐 → 进攻 Br₂ → 单溴代
  2. 溴代酮酸性增强 → 更快烯醇化 → 二溴代
  3. 继续 → 三溴代（CBr₃⁻ 可作为离去基团）
  4. OH⁻ 进攻 C=O → 四面体中间体 → CBr₃⁻ 离去 → 羧酸 + CHBr₃
  5. 质子交换 → 最终产物：羧酸根 + 三溴甲烷（溴仿）
- **碘仿反应**：CH₃CO- 基团的定性检测（黄色 CHI₃ 沉淀）
- **底物要求**：必须含有 CH₃CO- 基团（甲基酮）才能发生卤仿反应

### 5.3 卤代反应的区域选择性总结
| 条件 | 动力学/热力学 | 倾向性 | 原因 |
|:---|:---|:---|:---|
| 酸催化 | 热力学 | 多取代侧 | 过渡态带正电，烷基给电子稳定 |
| 碱催化 | 动力学 | 少取代侧 | 过渡态带负电，位阻小反应快 |

## 六、烯醇的亚硝化反应

### 6.1 亚硝化机理
- 亚硝酸（HNO₂）在 HCl 中生成 NO⁺（亚硝酰离子，nitrosonium ion）
- NO⁺ 进攻烯醇的亲核碳 → 生成亚硝基化合物
- 亚硝基化合物互变异构为稳定的肟（oxime）
- 肟水解 → 生成第二个酮（α-二酮）

### 6.2 区域选择性
- 酸催化下，亚硝化倾向于多取代侧（与酸催化卤代相同机理）
- 可用于在羰基邻位引入第二个羰基

## 七、稳定烯醇等价物

### 7.1 烯醇锂（Lithium Enolate）
- **制备**：用 LDA（二异丙基氨基锂）在 -78°C 处理羰基化合物
- **LDA 的优势**：
  - pKa(i-Pr₂NH) ≈ 35 >> pKa(α-H) ≈ 20-25 → 定量去质子
  - 大位阻叔胺 → 仅作碱，不进攻羰基（BuLi 会进攻羰基！）
- **应用**：Chapters 25-26 中烯醇锂的烷基化、Aldol 反应等

### 7.2 烯醇硅醚（Silyl Enol Ether）
- **制备方法**：
  1. 烯醇盐 + Me₃SiCl → 烯醇硅醚（硅亲电试剂进攻氧，Si-O 键强）
  2. 羰基化合物 + Me₃SiCl + Et₃N → 直接制备（利用中性烯醇微量存在）
- **特点**：比烯醇锂稳定、反应性适中、可分离纯化
- **逆转化**：MeLi 进攻硅 → 得烯醇锂 + Me₄Si
- **应用**：选择性制备特定区域异构的烯醇等价物

### 7.3 烯醇硅醚的反应
- **α-卤代**：与 Br₂ 反应 → α-溴代酮（避免碱促多卤代问题）
- **α-巯基化**：与 PhSCl 反应 → α-苯硫基酮
- **机理**：亲电试剂进攻 α-碳 → 卤离子/硫离子离去 → 硅基被亲核试剂移除

## 八、烯醇与烯醇盐的 O-反应 vs C-反应

### 8.1 软硬理论解释
- **氧上**：硬亲核位点（电荷控制），与硬亲电试剂反应
  - 试剂：Me₃SiCl、Me₃O⁺（Meerwein 盐）、AcCl
  - 产物：烯醇醚、烯醇硅醚、烯醇酯
- **碳上**：软亲核位点（轨道控制），与软亲电试剂反应
  - 试剂：烷基卤、羰基化合物（Aldol）
  - 产物：C-烷基化、C-酰基化产物（Chapter 25）

### 8.2 烯醇醚的制备
- 烯醇盐 + Me₃O⁺BF₄⁻（Meerwein 盐）→ 烯醇醚
- 烯醇盐 + Me₂SO₄（硫酸二甲酯）→ 烯醇醚
- 需在非质子极性溶剂（如 DMSO）中进行

### 8.3 烯醇醚的水解
- 烯醇醚在稀酸水溶液中迅速水解回羰基化合物（与普通醚截然不同）
- **机理**：氧孤对电子协助碳质子化 → 生成氧鎓离子 → 水进攻 → 羰基化合物
- **烯醇硅醚水解**：碳质子化后，水直接进攻硅（Si-O 亲和力强）→ 醛 + 二硅氧烷

## 九、烯醇化的应用总结

### 9.1 烯醇化导致的后果（一览表）

| 后果 | 机理 | 应用/注意 |
|:---|:---|:---|
| 质子交换（D₂O 中氘代） | 烯醇化-逆烯醇化 | 证明烯醇存在；标记合成 |
| 双键迁移（共轭化） | 烯醇化 | β,γ-不饱和 → α,β-不饱和 |
| 外消旋化 | 烯醇化（平面烯醇） | α-手性中心不稳定 |
| α-官能化 | 烯醇/烯醇盐 + 亲电试剂 | 卤代、亚硝化、烷基化 |
| 多卤代/卤仿反应 | 碱促连续烯醇化 | 碱促卤代的陷阱 |

### 9.2 烯醇化学在合成中的中心地位
- 烯醇/烯醇盐是"双重性格"分子：酮式为亲电性，烯醇式/烯醇盐为亲核性。
- Chapter 25-26 的核心：烯醇盐的 C-C 键构筑（Aldol 反应、烷基化等）。
- 稳定烯醇等价物（LDA/烯醇锂/烯醇硅醚）使定量、选择性烯醇化成为可能。

## 十、竞赛题型与解题策略

### 10.1 产物预测型
- **酸促 vs 碱促卤代**：判断产物是单卤代（酸）还是多卤代/卤仿（碱）。
- **区域选择性**：不对称酮在酸性下多取代侧卤代，碱性下少取代侧卤代。

### 10.2 机理书写型
- **酸催化烯醇化**：氧质子化 → α-去质子 → 烯醇。
- **碱催化烯醇化**：α-去质子 → 烯醇盐 → 氧质子化。
- **卤仿反应**：连续卤代 → OH⁻ 进攻 → CBr₃⁻ 离去 → 羧酸 + CHX₃。

### 10.3 稳定性判断型
- **哪些羰基化合物能形成稳定烯醇？**
  - 1,3-二羰基（共轭 + 分子内氢键）
  - 酚（芳香性极端稳定化）
  - 动力学稳定（无酸碱条件、空间位阻）
- **哪些不能烯醇化？**
  - 无 α-H 的羰基化合物（如 PhCOCPh₃、新戊醛）

### 10.4 烯醇等价物选择型
- **LDA/烯醇锂**：需要定量、动力学去质子（少取代侧）。
- **烯醇硅醚**：需要稳定、可分离的烯醇等价物；或需要多取代区域选择性。
- **MeLi 与 BuLi 的区别**：BuLi 进攻羰基（亲核性），MeLi 进攻硅（硅亲核）。

### 10.5 合成设计型
- **α-单卤代**：酸促 + 1 当量 Br₂（控制条件）。
- **α-双官能化**：烯醇硅醚路线（选择性）。
- **甲基酮的鉴定**：碘仿反应（黄色 CHI₃ 沉淀）。

### 10.6 竞赛高频考点清单
1. 烯醇化的酸催化 vs 碱催化机理——区域选择性差异（多取代 vs 少取代）
2. 卤仿反应的条件与机理——甲基酮的鉴定
3. 1,3-二羰基化合物的稳定烯醇——共轭与分子内氢键
4. LDA 定量去质子——烯醇锂的制备（-78°C、非亲核强碱）
5. 烯醇硅醚的制备与反应——α-官能化的选择性方法
6. 软硬亲核位点——O-反应 vs C-反应的控制
7. 外消旋化——α-手性中心在烯醇化条件下的不稳定性
8. 烯醇醚水解——与普通醚反应性的巨大差异

## 十五、摘录的原始段落（附页码/位置标记）

### 15.1 关于烯醇化的本质（lines 2009-2010）
> "我们在羰基化学上花费了悬河泻水之篇幅，但我们认为这是值得的...大多数羰基化合物，可以以两种形态存在——一种亲电的和一种亲核的。羰基化合物的亲电形态就是它们本身，而亲核形态被称作烯醇。"

### 15.2 关于酮式-烯醇式平衡（lines 2049-2053）
> "像环己酮、丙酮这类简单的羰基化合物，在通常条件下都只有痕量的烯醇式存在。这平衡完全趋向于酮式的形成...这是因为一根 C=C 双键加一根 O-H 单键 (稍稍) 不如一根 C=O 双键加一根 C-H 单键稳定。"

### 15.3 关于酸碱催化烯醇化（lines 2085-2103）
> "在酸催化反应中，分子首先会在羰基氧上被质子化，第二步则是在 C 上失去质子...碱催化反应中，C-H 质子首先被碱去除，然后在第二步中又有质子添加到氧原子上。"

### 15.4 关于烯醇盐的软硬亲核性（lines 2125-2145）
> "在烯醇阴离子中，氧原子最多的负电荷，而碳原子则分布有最多的 HOMO. 因此我们可以期待，以电荷和静电吸引为主导因素的反应发生在氧上，而以轨道相互作用为主导因素的反应发生在邻位碳上。"

### 15.5 关于1,3-二羰基化合物的稳定烯醇（lines 2275-2280）
> "这类化合物很多都可以形成大量的烯醇，有些甚至可以在极性溶剂中完全烯醇化...主要原因是两个羰基独特的（1,3）排列，使烯醇式中存在共轭。"

### 15.6 关于酸促卤代的区域选择性（lines 2484-2507）
> "酸促卤代的大多数中间体都是带正电的...α 位溴原子的存在还减缓了第二步...碱促卤代倾向于发生在甲基，取代较少的一侧上；而酸促的反应首先发生在多取代的一侧。"

### 15.7 关于卤仿反应（lines 2464-2472）
> "当三溴代酮的生成时 CBr₃⁻ 的碳阴离子被三个溴原子所稳定，可以作为离去基团离去...这一反应通常被称作'碘仿'反应。"

### 15.8 关于LDA制备烯醇锂（lines 2553-2563）
> "用更强的碱会改变这种情况，烯醇会定量地由羰基化合物生成...这种碱通常是 LDA（二异丙基氨基锂）...LDA 是叔胺，因此它不会作为亲核试剂进攻羰基，只会用作碱。"

## 十六、存疑或待验证之处

1. **酸促溴代的区域选择性解释**：文中用过渡态电荷分布解释（正电荷在过渡态中富集 → 烷基给电子稳定 → 多取代侧优先进攻），这一解释是否在竞赛中需要掌握？
2. **双甲酮烯醇式中两个 CH₂ 的等价性**：文中说这是互变异构而非离域的结果——如何用 NMR 实验区分两者？
3. **烯醇硅醚的两种制备机理**：文中说"两种机理都可能是正确的"——竞赛中是否需要判断具体走哪条机理？
4. **BuLi vs MeLi 对羰基/硅的不同反应性**：是否所有锂试剂都需要区分亲核性（BuLi）和硅亲核性（MeLi）？
5. **外消旋化的速率**：文中提到氨基酸在酸中不外消旋、N-乙酰化后才外消旋——竞赛中如何判断一个α-手性中心是否会外消旋？
