# Clayden 第23章：化学选择性和保护基 资料提炼

---

## 一、核心概念与定义

### 1.1 选择性（Selectivity）三分类
- **[[化学选择性]]（Chemoselectivity）**：分子中多个官能团，哪个会参与反应？
- **区域选择性（Regioselectivity）**：反应在官能团的哪个位置发生？（Ch24详述）
- **立体选择性（Stereoselectivity）**：产物的立体化学如何？（Ch32, 33, 41详述）

### 1.2 动力学化学选择性
- 由于一处反应比其他处快而引起的选择性。
- 例：NH₂比OH亲核性强 → 4-氨基苯酚在碱性下仅NH₂被酰化（扑热息痛合成）。
- 酮比酯对格氏试剂更活泼 → 可在酯存在下选择性与酮反应。

### 1.3 热力学化学选择性
- 在可逆反应条件下，产物是更稳定的一个（不一定是生成快的一个）。
- 例：酸性下酰胺水解为酯（胺质子化使酯移出平衡）；碱性下酯水解为酰胺（酰胺更稳定）。

### 1.4 保护基（Protecting Group）
- **定义**：暂时将一个官能团转化为在特定反应条件下不活泼的形式，反应后再脱除恢复原官能团。
- **核心要求**：
  1. 上保护和脱保护都应高产率。
  2. 保护基在目标反应条件下稳定。
  3. 脱保护条件温和，不破坏分子其他部分。
  4. 上保护应有化学选择性（只保护目标基团）。

### 1.5 正交保护（Orthogonal Protection）
- 两种或多种保护基可在不同条件下分别脱除，互不干扰。
- 例：Cbz（H₂/Pd或HBr脱除）+ Boc（酸脱除）→ 正交保护体系。
- 肽合成中的核心概念：N端保护基和C端保护基需正交。

## 二、还原反应的化学选择性

### 2.1 羰基还原剂概览

#### 硼氢化钠（NaBH₄）
- **选择性**：还原醛、酮 → 醇；不还原酯、酰胺、酸。
- **条件**：质子溶剂（EtOH/MeOH）或Lewis酸（Li⁺、Mg²⁺）存在。
- **机理**：负氢从硼转移到羰基碳，氧负离子质子化得醇。
- **Luche还原**：NaBH₄ + CeCl₃ → 选择性还原α,β-不饱和羰基化合物的C=O（不还原C=C）。

#### 氢化铝锂（LiAlH₄）
- **选择性**：还原几乎所有羰基（醛、酮、酯、酰胺、酸、环氧化物）。
- **条件**：无水THF或乙醚，后处理需小心（遇水着火）。
- **酯还原机理**：负氢加成 → 四面体中间体 → 烷氧基离去 → 醛 → 再还原 → 醇。
- **酰胺还原机理**：负氢加成 → 四面体中间体 → 失去与Al配位的氧 → 亚铵离子 → 再还原 → 胺。

#### 硼烷（BH₃）
- **选择性**：还原羧酸和酰胺 → 醇/胺；不还原酯、酰氯（或很慢）。
- **原因**：硼烷是Lewis酸，优先与富电子羰基（酸、酰胺）络合。
- **羧酸还原**：先形成三酰基硼烷 → 负氢转移 → 醛 → 醇。
- **与LiAlH₄互补**：BH₃还原酸/酰胺，LiAlH₄还原酯。

#### 二异丁基氢化铝（DIBAL/DIBALH）
- **选择性**：低温（-70°C）下将酯还原为醛（不继续还原到醇）。
- **关键**：低温下四面体中间体稳定，水处理时才坍塌为醛。
- **最佳应用**：内酯 → 内半缩醛（lactol）；腈 → 醛。

#### 还原剂选择总结
| 还原剂 | 醛/酮 | 酯 | 酰胺 | 羧酸 | 酰氯 |
|:---|:---:|:---:|:---:|:---:|:---:|
| NaBH₄ | ✓ | - | - | - | - |
| LiAlH₄ | ✓ | ✓ | ✓ | ✓ | ✓ |
| BH₃ | - | - | ✓ | ✓ | - |
| DIBAL | ✓ | →醛 | →醛 | - | - |

### 2.2 催化氢化

#### 基本原理
- **试剂**：H₂ + 金属催化剂（Pd/C、PtO₂、Raney Ni、Rh、Ru）。
- **机理**：H₂在金属表面化学吸附 → H-H键断裂 → 烯烃与金属成键 → 氢原子转移到烯烃。
- **立体化学**：syn加成（两个H从同一侧加成）。

#### 选择性还原
- **烯烃 → 烷烃**：Pd/C或PtO₂催化，最常用。
- **α,β-不饱和羰基化合物**：催化氢化优先还原C=C（不还原C=O）。
- **苯环 → 环己烷**：Pt、Rh或Ni催化（Pd效果较差）。
- **炔烃 → 烯烃**：Lindlar催化剂（Pd/CaCO₃ + Pb + 喹啉），选择性停留在顺式烯烃。

#### Lindlar催化剂
- 铅使钯催化剂中毒 → 活性降低 → 烯烃产物不再继续氢化。
- Pd/BaSO₄ + 喹啉也可用。
- 产物为顺式（Z）烯烃（与Birch还原的反式互补）。

#### Rosenmund反应
- 酰氯 + H₂/Pd-BaSO₄ → 醛（C-Cl键氢解）。
- 喹啉中和产生的HCl，控制催化剂活性。

### 2.3 氢解（Hydrogenolysis）
- **定义**：C-O或C-N σ键的断裂（与C=C π键氢化不同）。
- **苄基氢解**：苄醇、苄醚、苄胺在Pd/C + H₂下容易断裂C-O/C-N键。
- **苄基是优秀的保护基**：酸性/碱性下稳定，Pd/C + H₂温和脱除。

### 2.4 溶解金属还原

#### Birch还原
- **试剂**：碱金属（Li/Na）在液氨中 + 质子源（EtOH）。
- **机理**：溶剂化电子 → 芳环LUMO → 自由基阴离子 → 质子化 → 自由基 → 再得电子 → 阴离子 → 质子化 → 1,4-环己二烯。
- **区域选择性**：
  - 吸电子基（如CO₂H）：本位/对位还原。
  - 给电子基（如OMe）：邻位/间位还原。
- **炔烃Birch还原**：得到反式（E）烯烃（与Lindlar互补）。

#### Wolff-Kishner还原
- **用途**：C=O → CH₂（羰基完全去除）。
- **机理**：腙 → 强碱加热 → 失去N₂ → 烷基阴离子 → 质子化。
- **条件**：NH₂NH₂, KOH, 高温（或黄鸣龙改良：二甘醇溶剂）。

#### Clemmensen还原
- **用途**：C=O → CH₂（酸性条件）。
- **试剂**：Zn(Hg) + 浓HCl。
- **机理**：溶解金属还原，金属释放电子还原C=O。

#### 硫缩醛/Raney Ni脱羰基
- 醛酮 → 硫缩醛（二硫醇 + Lewis酸）→ Raney Ni还原 → 烷烃。

### 2.5 氧化反应的化学选择性

#### 醇的氧化
- **Cr(VI)氧化剂**（Jones氧化、PCC、PDC）：醇 → 醛/酮。
  - Jones氧化（水溶液）：伯醇 → 醛 → 羧酸（过度氧化）。
  - PCC/DCM（无水）：伯醇 → 醛（停在醛阶段）。
- **TPAP/NMO**：温和催化氧化，醇 → 醛。
- **Dess-Martin高碘烷**：极温和，敏感底物适用。
- **Swern氧化**：DMSO + (COCl)₂ + Et₃N → 醇 → 醛。

#### 氧化剂选择性分类
| 对C=C化学选择性 | 对醇/羰基化学选择性 |
|:---|:---|
| 过酸（m-CPBA）| Cr(VI)化合物 |
| OsO₄ | Mn(VII)化合物 |
| O₃ | 高氧化态卤素/N/S化合物 |

## 三、保护基化学

### 3.1 羰基保护——缩醛/缩酮

#### 二氧戊环（Dioxolane）
- **保护对象**：醛、酮。
- **上保护**：二醇（乙二醇）+ 酸催化 → 五元环缩醛。
- **脱保护**：酸性水溶液（H⁺, H₂O）。
- **稳定性**：对碱、亲核试剂、还原剂稳定。
- **应用**：保护酮不受格氏试剂进攻。

### 3.2 羟基保护

#### 三烷基硅基醚（R₃Si-OR'）
- **代表**：TBDMS（叔丁基二甲基硅基，t-BuMe₂Si-）。
- **上保护**：R₃SiCl + 碱（咪唑）。
- **脱保护**：H⁺/H₂O 或 F⁻（TBAF, Bu₄NF）。
- **硅对F、O、Cl有强亲和性** → F⁻是特异性脱硅试剂。
- **稳定性系列**：TMS（最不稳定，MeOH可脱）< TBDMS < TIPS < TBS（最稳定，需HF）。

#### 四氢吡喃基（THP）
- **保护对象**：醇（OH）。
- **上保护**：二氢吡喃（烯醇醚）+ 酸催化。
- **脱保护**：酸性水溶液（本质是缩醛水解）。
- **稳定性**：对碱稳定；对酸敏感（第二个O的孤对电子是"阿喀琉斯之踵"）。
- **注意**：THP引入额外手性中心 → 可能产生非对映体混合物。

#### 苄醚（OBn）
- **保护对象**：醇（OH）。
- **上保护**：NaH + BnBr（苄溴）。
- **脱保护**：H₂/Pd/C（氢解）或 HBr。
- **稳定性**：对酸、碱、大多数亲核试剂都稳定。
- **阿喀琉斯之踵**：芳环 → Pd催化氢解断裂苄基C-O键。

#### 甲醚（ArOMe）
- **保护对象**：酚（ArOH）。
- **上保护**：NaH + MeI 或 (MeO)₂SO₂。
- **脱保护**：BBr₃、HBr、HI 或 Me₃SiI。
- **酚醚比烷基醚容易脱除**：ArO⁻是比RO⁻更好的离去基团。

### 3.3 羧基保护——叔丁酯

#### 叔丁酯（CO₂t-Bu）
- **上保护**：羧酸 + 异丁烯 + H⁺。
- **脱保护**：强酸（TFA或HCl/DCM）。
- **稳定性**：对亲核试剂、碱性水解稳定（空阻大）。
- **脱保护机理**：SN1机理，叔丁基阳离子离去（不同于普通酯的亲核水解）。

### 3.4 氨基保护

#### Cbz基（苄氧羰基，-OCOBn）
- **上保护**：氯甲酸苄酯（BnOCOCl）+ 碱。
- **脱保护**：HBr/AcOH 或 H₂/Pd/C。
- **本质**：氨基甲酸酯（carbamate），氮孤对电子与羰基共轭 → 不再亲核。
- **苄基"阿喀琉斯之踵"**：与苄醚相同的脱保护条件。

#### Boc基（叔丁氧羰基，-OCOt-Bu）
- **上保护**：Boc₂O（酸酐）+ 碱。
- **脱保护**：酸性水溶液（3M HCl 或 TFA/DCM）。
- **脱保护机理**：质子化 → 叔丁基阳离子离去 → 脱羧 → 胺。
- **稳定性**：碱性下极稳定（羰基空阻大，OH⁻无法进攻）。

#### Fmoc基（芴甲氧羰基）
- **上保护**：Fmoc-Cl。
- **脱保护**：碱性条件（如哌啶/DMF）。
- **脱保护机理**：碱移除酸性H（pKa~25）→ 芳香性阴离子 → β-消除 → 胺 + 二苯并富烯。
- **与Boc正交**：Boc酸脱，Fmoc碱脱。

### 3.5 保护基总结表

| 保护基 | 保护对象 | 稳定条件 | 上保护方法 | 脱保护方法 |
|:---|:---|:---|:---|:---|
| 缩醛（二氧戊环）| 酮、醛 | 亲核试剂、碱 | 乙二醇, H⁺催化 | H⁺, H₂O |
| TBDMS（三烷基硅基）| 醇OH | 亲核试剂、C/N碱 | R₃SiCl, 咪唑 | H⁺/H₂O 或 F⁻(TBAF) |
| THP（四氢吡喃基）| 醇OH | 强碱 | 二氢吡喃, H⁺催化 | H⁺, H₂O |
| 苄醚（OBn）| 醇OH | 几乎任何条件 | NaH, BnBr | H₂/Pd/C 或 HBr |
| 甲醚（ArOMe）| 酚OH | 碱 | NaH, MeI | BBr₃, HBr, HI |
| 叔丁酯（CO₂t-Bu）| 羧酸 | 亲核试剂、碱 | 异丁烯, H⁺ | 强酸（TFA）|
| Cbz（-OCOBn）| 胺 | 亲电试剂 | BnOCOCl, 碱 | HBr/AcOH 或 H₂/Pd |
| Boc（-OCOt-Bu）| 胺 | 亲电试剂、碱 | Boc₂O, 碱 | H⁺, H₂O（酸）|
| Fmoc | 胺 | 亲电试剂、酸 | Fmoc-Cl | 碱（哌啶）|

## 四、肽合成中的保护基策略

### 4.1 肽合成的核心问题
- 氨基酸同时含NH₂和CO₂H → 未保护时会自缩合（生成二酮哌嗪）或交叉偶联产物混杂。
- **解决方案**：N端用碱脱除的保护基，C端用酸脱除的保护基 → 正交保护。

### 4.2 C端保护
- **乙酯**：简单，但可能与胺亲核试剂反应（仅在NH₂被保护时稳定）。
- **叔丁酯**：空阻大，对亲核试剂极稳定；酸性下SN1脱除。

### 4.3 N端保护与脱保护循环
- **Cbz保护**：BnOCOCl + 碱 → 氨基甲酸酯 → HBr/AcOH或H₂/Pd脱除。
- **Boc保护**：Boc₂O + 碱 → 氨基甲酸酯 → 3M HCl或TFA脱除。
- **Fmoc保护**：Fmoc-Cl → 氨基甲酸酯 → 碱（哌啶）脱除。

### 4.4 羧基活化
- 酰氯太活泼（外消旋化、二酮哌嗪）。
- **对硝基苯酚酯**或**2,4,6-三氯苯酚酯**：酚氧基阴离子是好的离去基团，选择性与胺反应。

### 4.5 催产素合成实例
- 九肽：H₂N-Cys-Tyr-Ile-Gln-Asn-Cys-Pro-Leu-Gly-CONH₂。
- 逐步偶联：每个氨基酸通过Cbz保护的对硝基苯酚酯引入 → 酸性脱保护 → 下一轮偶联。

### 4.6 阿斯巴甜的意外发现
- 胃泌素C端四肽合成中，AspPhe单甲酯尝起来是蔗糖200倍甜度。
- 天冬氨酸侧链羧基用苄醚保护 → Cbz和苄醚可同时氢解脱除。

## 五、关键结论与规则

### 5.1 化学选择性核心规则
1. NH₂比OH亲核性强 → 碱性下优先酰化NH₂。
2. 酮比酯对亲核试剂更活泼 → 可在酯存在下选择性加成酮。
3. NaBH₄只还原醛/酮，LiAlH₄还原几乎所有羰基。
4. BH₃选择性还原羧酸和酰胺（与LiAlH₄互补）。
5. 催化氢化优先还原C=C而非C=O。

### 5.2 保护基核心规则
1. 保护基必须有"阿喀琉斯之踵"——特定条件下可脱除。
2. 正交保护：不同保护基在不同条件下脱除，互不干扰。
3. 硅基醚对F⁻特异性敏感（Si-F键极强）。
4. 苄基保护基的弱点是芳环（Pd催化氢解）。
5. 缩醛/缩酮对碱稳定，对酸敏感。

### 5.3 肽合成保护基策略
1. N端：碱脱除保护基（Fmoc）或酸脱除保护基（Boc/Cbz）。
2. C端：酯保护（乙酯或叔丁酯）。
3. 羧基活化：用酚酯（非酰氯）避免外消旋化。
4. 侧链官能团：选择与主链保护基正交的保护方式。
