# Clayden 第10章：羰基上的亲核取代 资料提炼

---

## 一、核心概念与定义

### 1.1 亲核加成-消除机理（Nucleophilic Acyl Substitution）
- **核心框架**：羧酸衍生物 RCOX 的[[酰基亲核取代|亲核取代]]经历两步——① 亲核试剂 Y⁻ 进攻羰基碳形成**四面体[[中间体]]**（tetrahedral intermediate）；② 四面体中间体坍塌，离去基团 X⁻ 离去，重新形成 C=O。
- **sp² → sp³ → sp²**：羰基碳从平面三角形（sp²）变为四面体（sp³），再回到平面三角形。
- **与醛酮加成的区别**：醛酮没有好的离去基团，加成后停留在四面体产物（如醇）；羧酸衍生物有离去基团，加成后中间体坍塌给出取代产物。

### 1.2 离去基团（Leaving Groups）
- **定义**：Cl⁻、RO⁻、RCO₂⁻ 等可以带着负电荷从分子中排出的阴离子。
- **离去能力判据**：HX 的 pKa 越小 → X⁻ 越稳定 → 离去能力越强。
- **离去能力排序**：
  | 羧酸衍生物 | 离去基团 X⁻ | 共轭酸 HX | pKa | 离去能力 |
  |:---|:---|:---|:---|:---|
  | [[酰卤]] | Cl⁻ | HCl | <0 | 极好 |
  | [[酸酐]] | RCOO⁻ | RCO₂H | ~5 | 好 |
  | 酯 | RO⁻ | ROH | ~15 | 差 |
  | 酰胺 | NH₂⁻ | NH₃ | ~25 | 非常差 |
  | 酮 | R⁻ | RH | >40 | 不能离去 |

### 1.3 四面体中间体（Tetrahedral Intermediate）
- **结构特征**：亲核试剂加成到三角型（sp²）羰基碳上，碳变为四面体型（sp³）。
- **不稳定性**：四面体中间体通常不稳定——重新形成 C=O 双键释放的能量（键能 ~720 kJ/mol）弥补了断裂两根 C-O 单键（每根 ~350 kJ/mol）的损失。
- **Bender 实验证据**（1951）：用 ¹⁸O 标记的酯 RCOX 与水反应，回收的未反应原料中 ¹⁸O 标记明显减少——证明形成了四面体中间体，使两个氧原子可以通过质子转移而"交换位置"。

### 1.4 羧酸衍生物的活性排序
- **活性从高到低**：酰卤 > 酸酐 > 酯 > 酰胺
- **活性差异来源**：
  - **离去基团的离去能力**：顶端衍生物有最好的离去基团。
  - **羰基碳的亲电性（离域化效应）**：
    - 酰氯：Cl 吸电子诱导效应增强，几乎无离域化 → 羰基碳极亲电。
    - 酸酐：中等离域化。
    - 酯：氧孤对电子与 C=O π\* 共轭 → 中等离域化 → 亲电性降低。
    - 酰胺：氮孤对电子（p 轨道）与 C=O π\* 强共轭 → 最大离域化 → 羰基碳最不亲电。
- **IR 证据**：羰基伸缩频率反映 C=O 键强度（键越强，频率越高）：
  - 酰氯 > 酸酐 > 酯 > 酰胺
  - 酸酐有两个频率（对称/不对称伸缩）
  - 羧酸根阴离子频率最低（完全离域，负电荷分散在两个氧上）

### 1.5 亲核性与离去能力的关系
- **反向关系**：好的离去基团 = 差的亲核试剂；差的离去基团 = 好的亲核试剂。
- **pKa 指导**：AH 的 pKa 越大 → A⁻ 是越好的亲核试剂（对于羰基进攻而言）。
- **中性 vs 带电亲核试剂**：阴离子比中性化合物亲核性更强；但氨（pKa ~10）本身就是好的亲核试剂，不需要去质子化；羧酸（pKa ~5）即使去质子化仍然很差。

## 二、重要反应与机理

### 2.1 酰卤与醇成酯——碱催化亲核酰基取代

#### 反应特征
- **反应物**：[[酰卤|酰氯]] + 醇 + 碱（吡啶）
- **产物**：酯 + HCl（被吡啶中和）
- **吡啶的双重角色**：① 碱——移去醇上质子；② 亲核催化剂——吡啶先进攻酰氯生成高活性 N-酰基吡啶鎓中间体，再被醇进攻得酯。

#### 机理（以乙酰氯 + 环己醇为例）
1. 醇（被吡啶去质子后更强亲核）进攻酰氯的羰基碳 → 四面体中间体
2. 四面体中间体坍塌，Cl⁻ 离去（最好的离去基团） → 酯产物
- 注意：吡啶在过程中被质子化，需一当量吡啶；实际常在吡啶作溶剂中进行。

### 2.2 酸酐与醇成酯

#### 反应特征
- **反应物**：[[酸酐]] + 醇 + 碱（吡啶）
- **产物**：酯 + 羧酸（被吡啶中和）
- **机理**：与酰氯类似——亲核加成 → 四面体中间体 → RCOO⁻ 离去 → 酯

#### 活性对比
- 酸酐活性低于酰卤（离去基团 RCOO⁻ 比 Cl⁻ 差），但仍足够活泼与醇反应。
- 酰氯在低温下与水反应剧烈；酸酐可在室温下与醇缓慢反应。

### 2.3 酰卤与胺成酰胺

#### 反应特征
- **反应物**：[[酰卤|酰氯]] + 胺（2 当量，或 + NaOH）
- **产物**：酰胺 + HCl（被第二当量胺中和）

#### 机理
1. 胺（强亲核试剂）进攻酰氯羰基 → 四面体中间体
2. 去质子化（第二当量胺或碱）
3. Cl⁻ 离去 → 酰胺

#### Schotten-Baumann 方法
- **问题**：NaOH 也会进攻酰氯得羧酸。
- **解决**：两相体系（有机层：胺 + 酰氯；水层：NaOH）→ 酰氯只与胺反应，HCl 被水层中和。

### 2.4 酯的氨解（Aminolysis）
- **反应物**：酯 + 胺（NH₃ 或 RNH₂）
- **产物**：酰胺 + 醇（ROH）
- **为什么可行**：NH₂⁻ 是极差的离去基团（pKa ~25），而 RO⁻ 是更好的离去基团（pKa ~15）→ 四面体中间体优先失去 RO⁻ → 得酰胺。
- **逆反应不可行**：酰胺 + 醇 → 酯 反应不发生，因为 NH₂⁻ 比 RO⁻ 差得多。

### 2.5 Fischer 酯化（酸催化）

#### 反应特征
- **反应物**：羧酸 + 醇 + 酸催化剂（HCl 或 H₂SO₄）
- **产物**：酯 + 水（见 [[酯化反应]]）
- **可逆性**：每一步都处于平衡中，总平衡常数 ≈1。

#### 酸催化的两个关键作用
1. **增强亲电性**：质子化羰基氧 → 碳更正电性 → 即使弱亲核试剂（如醇）也能进攻。
2. **改善离去能力**：质子化四面体中间体的 OH → 变为 H₂O（好离去基团）→ 取代 HO⁻（差离去基团）。

#### 平衡控制策略
- **加入过量醇或羧酸**（通常在醇溶液中反应）
- **移除水**：脱水剂（浓 H₂SO₄、分子筛）或蒸馏出水
- **产率数据**：乳酸 + 3 equiv EtOH + 干燥 HCl → 68-72% 产率

#### 应用选择
- 少量复杂分子：用酰氯/酸酐 + 吨啶（避免酸破坏底物）
- 大量简单酯：用羧酸 + H₂SO₄ + 醇（更便宜）

### 2.6 酯的水解

#### 酸催化水解（可逆）
- **反应物**：酯 + H₂O + H⁺
- **机理**：与 Fischer 酯化完全互逆——酯质子化 → 水进攻 → 四面体中间体 → 醇离去 → 羧酸
- **¹⁸O 标记证据**：
  - 酯"烷氧"氧上的 ¹⁸O → 醇产物中
  - 用 ¹⁸OH₂ 水解 → ¹⁸O 在羧酸中，不在醇中
  - 这些结果排除了饱和碳上的 Sₙ 取代机理

#### 碱催化水解（不可逆，皂化 Saponification）
- **反应物**：酯 + NaOH（至少 1 当量）
- **产物**：羧酸盐 + 醇
- **不可逆原因**：生成的羧酸根阴离子在碱性下无法被亲核进攻（没有好的离去基团）。
- **机理**：OH⁻ 进攻酯羰基 → 四面体中间体 → RO⁻ 离去 → 羧酸根（去质子化不可逆）
- **工业应用**：椰子油（肉蔻酸甘油三酯）→ NaOH 水解 → 肉蔻酸钠（肥皂）

### 2.7 酯交换反应（Transesterification）
- **定义**：一种醇的酯转化为另一种醇的酯。
- **条件**：酸催化，过量新醇（或蒸馏出低沸点醇）。
- **工业应用**：涤纶（Terylene/Dacron）——对苯二甲酸二乙酯 + 乙二醇 + H⁺ → 聚酯 + MeOH（蒸馏除去）。

### 2.8 酰胺的水解

#### 酸催化水解
- **条件**：剧烈——70% H₂SO₄，100°C，3 小时。
- **特殊之处**：酰胺碱性较强（质子化 pKa ~-1），但质子化发生在**羰基氧**上（而非氮上），因为氧上质子化可保持离域化阳离子的稳定。
- **机理**：
  1. 羰基氧质子化 → 碳更亲电
  2. 水进攻 → 四面体中间体
  3. 氮质子化（氮碱性 > 氧） → NH₃ 成为好离去基团
  4. NH₃ 离去 → 羧酸（NH₃ 再质子化为 NH₄⁺，不再亲核）
- 注意：反应消耗 1 当量酸，酸不是催化剂了。

#### 碱催化水解
- **条件**：浓 NaOH 热溶液，长时间。
- **机理**：OH⁻ 进攻 → 四面体中间体 → 双阴离子（额外 OH⁻ 使中间体去质子） → NH₂⁻ 离去（唯一可行选择，O²⁻ 不会离去）。
- **仲胺/叔胺**：更难水解——需更浓碱、更高温度；叔丁醇钾（pKa ~18）可室温下完成。

### 2.9 腈的水解
- **关系**：腈 RCN 可视为伯酰胺脱水产物，两者可相互转化。
- **酸催化水解**：
  1. 腈质子化 → 水进攻 → 伯酰胺
  2. 酰胺继续水解 → 羧酸 + NH₃
- **合成应用**：苯甲醛 → NaCN/HCl → 氰醇 → H₃O⁺ → 扁桃酸（mandelic acid，杏仁提取物成分）

### 2.10 酰氯的制备

#### 由 SOCl₂（亚硫酰氯）
- **反应**：RCO₂H + SOCl₂ → RCOCl + SO₂↑ + HCl↑
- **机理**：
  1. 羧酸氧进攻 SOCl₂ 的硫 → 不稳定中间体
  2. Cl⁻ 进攻中间体 → 四面体中间体
  3. 坍塌 → 酰氯 + SO₂ + HCl
- **不可逆驱动力**：SO₂ 和 HCl 均为气体，离开反应混合物。

#### 由 PCl₅（五氯化磷）
- **反应**：RCO₂H + PCl₅ → RCOCl + POCl₃ + HCl
- **机理**类似 SOCl₂，但驱动力是**稳定的 P=O 双键**形成。

### 2.11 由酯制取酮——问题与解决

#### 问题：过加成
- 酯 + 1 equiv RMgX → 酮（期望产物），但酮比酯更活泼 → 酮 + 第二分子 RMgX → 叔醇（副产物）。
- 因此酯与格氏试剂/有机锂反应直接得到叔醇（含两个相同 R 基）。

#### 解决方案一：使起始原料更活泼
- 用**酰氯**代替酯 → 与格氏试剂反应可停在酮阶段。
- 更好：用**有机铜试剂**（格氏试剂经转金属得到）→ 活性不足以加成酮，但能与酰氯反应。

#### 解决方案二：使中间体更稳定（非坍塌性四面体中间体）
- **Weinreb 酰胺**（N-甲氧基-N-甲基酰胺）：有机金属加成后，Mg²⁺ 与两个氧螯合 → 四面体中间体稳定 → 直到加酸淬灭才坍塌得酮。
- **羧酸锂**：有机锂加成 → 双阴离子（无离去基团） → 酸淬灭得酮。
- **DMF（二甲基甲酰胺）**：有机锂加成 → 酰胺四面体中间体稳定 → 酸淬灭得**醛**（向亲电体添加 CHO 基团的有用方法）。
- **腈**：有机金属加成 → 亚胺阴离子（不亲电） → 酸水解得酮。

### 2.12 机理简写法（d-double-headed arrow）
- 将四面体中间体的形成与坍塌合并表示在同一结构中，用双头箭头（d-arrow）简写。
- **仅作简写**：不能代替对真正机理的理解，不能写成一步反应。

## 三、关键结论与规则

### 3.1 反应能否发生的三条件
1. X⁻ 必须是比 Y⁻ 更好的离去基团（否则逆反应占优）
2. Y⁻ 的亲核性必须足以进攻 RCOX
3. RCOX 的亲电性必须足以与 Y⁻ 反应

### 3.2 羧酸衍生物活性排序
```
酰卤（最高活性）> 酸酐 > 酯 > 酰胺（最低活性）
```
- 实验证据：酰氯低温下与水反应剧烈；酰胺需 10% NaOH 或浓 HCl，封管 100°C 回流过夜。

### 3.3 酸催化的双重作用
| 作用 | 机制 |
|:---|:---|
| 增强亲电性 | 质子化 C=O → 碳更正电性 → 弱亲核试剂也能进攻 |
| 改善离去能力 | 质子化 OH → H₂O（好离去基团）取代 HO⁻（差离去基团） |

### 3.4 碱性条件下羧酸不发生取代
- 去质子化 → 羧酸根阴离子（完全不亲电） → 任何亲核试剂无法进攻
- 因此碱性水解酯是不可逆的（产物羧酸根不能回去）

### 3.5 离域化程度与反应性
- 离域化越大 → C=O 键越弱 → 亲电性越低 → 反应性越差
- 离域化排序：酰氯（最小）< 酸酐 < 酯 < 酰胺 < 羧酸根（最大）
- **注意**：键强度并不直接指示活性——溶剂化和极化对反应性有决定性影响。

### 3.6 三种由醇成酯的方法
| 方法 | 试剂 | 适用场景 |
|:---|:---|:---|
| 酰氯法 | RCOCl + ROH + 吡啶 | 少量复杂酯 |
| 酸酐法 | (RCO)₂O + ROH + 吡啶 | 中等规模 |
| Fischer 酯化 | RCO₂H + ROH + H⁺ | 大量简单酯 |

### 3.7 叔醇合成法
- 酯 R¹CO₂R + 2 equiv R²Li 或 R²MgBr → 含两个相同 R² 的叔醇 R¹R²₂COH

## 七、待深化或新创建的个体知识点

1. **四面体中间体** —— 目前无独立 KP，建议创建，涵盖 Bender 实验证据、稳定性判据、质子交换机制。
2. **离去能力与 pKa** —— 建议独立 KP，系统化"共轭酸 pKa 越小 → 离去基团越好"的概念及其在羰基取代中的应用。
3. **羧酸衍生物活性排序** —— 建议独立 KP，整合 IR 频率、离域化程度、水解条件差异。
4. **Fischer 酯化** —— 建议独立 KP，包含酸催化双重作用、平衡控制策略、应用选择。
5. **Weinreb 酰胺合成** —— 化学竞赛高频考点，建议独立 KP，涵盖螯合稳定化机理。
6. **酯的碱性水解（皂化）** —— 建议独立 KP，强调不可逆性及其与酸催化水解的对比。
7. **DMF → 醛合成** —— 向亲核试剂上引入 CHO 基团的实用方法，建议独立 KP。
8. **机理简写法（d-箭头）** —— 可作为有机化学机理书写规范的子点。

## 八、摘录的原始段落（附位置标记）

### 8.1 关于离去基团（lines 490-500）
> "离去基团指 Cl⁻、RO⁻、RCO₂⁻ 等可以带着负电荷被从分子中排出的阴离子。"
> "如果起始羰基本来就包含一个潜在的离去基团，那么它可以直接脱去自己的离去基团。"

### 8.2 关于四面体中间体（lines 538-544）
> "我们称由此类反应形成的不稳定中间体为四面体中间体（tetrahedral intermediate），因为羰基中心的三角型（sp²）碳原子变为了四面体型（sp³）碳原子。"

### 8.3 关于 pKa 指导离去能力（lines 597-607）
> "如果我们用离去基团共轭酸的 pKa（Chapter 8）作为指引。如果离去基团是 X⁻，那么 HX 的 pKa 越小，X⁻ 的离去性越好/离去能力越强。"

### 8.4 关于亲核性（lines 675-681）
> "好的亲核试剂是差的离去基团。稳定的阴离子会是好的离去基团，但也是差的亲核试剂。弱酸的阴离子（HA 具有高 pKa）是差的离去基团，但也是对于羰基好的亲核试剂。"

### 8.5 关于活性排序（lines 697-701）
> "我们可以按活性的'等级'列出常见的羧酸衍生物，其中最活泼的位于顶部，最不活泼的位于底部。每种情形中的亲核试剂都相同（水），产物也都为羧酸，但亲电试剂由非常活泼变化到非常不活泼。"

### 8.6 关于离域化与活性（lines 707-715）
> "酰胺对于亲核试剂的活性最低，这是因为它们表现出了最大程度的离域化。在酰胺中，氮上的孤对电子会被与羰基 π\* 轨道的重叠所稳定。"

### 8.7 关于酸催化的双重作用（lines 767-769）
> "酸催化通过给羰基氧质子化增强了羰基的亲电性。酸催化通过给四面体中间体上的羟基质子化增强了它的离去能力。"

### 8.8 关于碱性条件下羧酸不反应（lines 731-739）
> "一旦羧酸被去质子，取代反应就被完全阻止了，几乎没有亲核试剂能够进攻羧酸根阴离子。"

### 8.9 关于酰胺碱性与质子化位点（lines 873-874）
> "酰胺碱性强的原因的确来源于氮上的孤对电子，但具体来说，是因为氮上的孤对电子离域到羰基中……由于在氮上质子化会破坏使酰胺稳定的离域化体系，因此酰胺的质子化往往发生在羰基氧上。"

### 8.10 关于过加成问题（lines 981-987）
> "得到酮后，其他的格氏试剂就会面临选择。它既可以进攻酯原料，也可以进攻新形成的酮。酮比酯更加亲电，因此格氏试剂更愿意与酮反应。"

## 九、竞赛题型线索

### 9.1 产物预测型
- 给定酰氯/酸酐/酯 + 亲核试剂（ROH、RNH₂、OH⁻），预测取代产物。
- 判断 Fischer 酯化的平衡方向（给定浓度条件）。
- 预测 ¹⁸O 标记实验的产物分布。

### 9.2 机理书写型
- 书写酰氯 + 醇/胺的完整亲核酰基取代机理（含四面体中间体）。
- 书写 Fischer 酯化/水解的酸催化机理。
- 书写碱催化酯水解（皂化）的完整机理。
- 书写 SOCl₂ 或 PCl₅ 制酰氯的机理。
- 区分酸催化与碱催化机理的关键差异。

### 9.3 反应活性判断型
- 比较不同羧酸衍生物的水解活性（给定 IR 频率或离域化信息）。
- 比较不同离去基团的离去能力（给定 pKa）。
- 判断哪些反应可逆、哪些不可逆。
- 比较胺 vs 醇与酸酐的反应活性。

### 9.4 合成设计型
- 设计从羧酸出发合成酰胺/酯/酸酐的路线（先制酰氯，再向下转化）。
- 设计从酯出发制取酮的路线（Weinreb 酰胺策略）。
- 设计从腈出发制取酮/羧酸的路线。
- 酯化反应的平衡控制策略设计。

### 9.5 实验设计型
- 设计 ¹⁸O 标记实验验证四面体中间体。
- 设计 Schotten-Baumann 两相体系的反应条件。
- 设计选择性水解（区分分子中不同酯基的活性）。

### 9.6 概念辨析型
- 离域化越大 → C=O 键越弱 → 但反应性越低（反直觉！）。
- 键强度不等于反应活性——溶剂化和极化的影响。
- 酰胺质子化在氧上而非氮上的原因。

### 9.7 综合应用型
- 涤纶纤维合成路线分析（酯交换反应）。
- 扁桃酸全合成设计（氰醇路线）。
- 大环内酯天然产物中酮的制备（Weinreb 酰胺）。
