## 内容概要

本讲是第四分册的终讲，把「生物有机化学」的两大基本物质——糖与氨基酸——按**构型判定 → 结构表示 → 反应性质 → 合成与降解**的同一套逻辑组织。糖部分以甘油醛为构型基准，梳理费歇尔投影式与哈沃斯式的互写（基团交换 → 向右平放 → 向内成环三步），用 α/β 端基构型与 e/a 键判据解释 $\beta$-D-吡喃葡萄糖更稳定；反应部分覆盖糖的碱催化转化、还原、五类氧化（银氨/斐林/班氏、溴水、稀硝酸、浓硝酸、高碘酸）、成脎，以及 **Kiliani 氰化增碳**与 **Ruff / Wohl 降级**四条改变碳链长度的路线。氨基酸部分从偶极离子与等电点公式 $\mathrm{pI} = (\mathrm{p}K_1 + \mathrm{p}K_2)/2$ 出发，讨论茚三酮显色与 Strecker、Gabriel、Hell-Volhard-Zelinski、乙酰氨基丙二酸酯四条合成路线，并说明外消旋体的拆分原理。

## 核心知识点

### 1. 糖的结构与构型判定
- **D/L 判据**：糖的结构可视为在甘油醛的 —CHO 与手性碳之间插入若干 —CHOH；**倒数第一个手性碳**（即编号最大的手性碳）上 —OH 在右为 D-型、在左为 L-型
- **天然糖均为 D-型**
- 费歇尔投影式书写示例：
  - D-葡萄糖 = (2R,3S,4R,5R)-2,3,4,5,6-五羟基己醛
  - D-果糖 = (3S,4R,5R)-1,3,4,5,6-五羟基-2-己酮
- 简写约定：以「$\triangle$」代表 —CHO、短横线代表 —OH、长横线代表 —$\mathrm{CH_2OH}$
- **糖的分类**：单糖（不可再水解，如葡萄糖、果糖）／寡糖（2–10 个单糖失水，如蔗糖、麦芽糖）／多糖（>10 个单糖失水，如淀粉、纤维素）
- 糖是多羟基醛或多羟基酮 → 能成五元/六元环状半缩醛（半缩酮）时**主要以环状存在**，用哈沃斯式表示

### 2. 链状 → 哈沃斯式的三步与 α/β 判定
- 三步：**基团交换 → 向右平放 → 向内成环**
- 新生成的端基 —OH 与 —$\mathrm{CH_2OH}$：
  | 相对位置 | 构型 |
  |---|---|
  | 同侧 | $\beta$-D-吡喃葡萄糖 |
  | 异侧 | $\alpha$-D-吡喃葡萄糖 |
- 二者是**不同的化合物**（端基异构体，即变旋异构体）
- **稳定性判据（构象分析）**：$\beta$-D-吡喃葡萄糖中所有大基团均在 **e 键**；$\alpha$-D-吡喃葡萄糖中有一个 —OH 在 **a 键** → **$\beta$ 型更稳定**

### 3. 糖苷
- 环状半缩醛的端基 —OH 还可与醇发生缩醛反应 → 产物称**苷（甙）**
- 结构分两部分：**糖的残基**（糖的部分）+ **配基**（非糖部分）
- 天然产物中葡萄糖很少游离存在，多以糖苷形式存在；糖苷在盐酸中加热分解（实质是**醚的分解**）→ 糖的残基部分得相应糖，配基部分得相应**苷元**

### 4. 单糖的化学性质

#### 4.1 糖的转化与还原
- **碱催化互变**：醛糖 ⇌ 酮糖（经烯二醇中间体）→ 因此**酮糖也会被银氨溶液、斐林试剂氧化**
- 醛糖可催化氢化或被 $\mathrm{NaBH_4}$ 还原为**糖醇**

#### 4.2 氧化反应（五类，鉴别价值最高的部分）
| 氧化剂 | 产物 | 鉴别意义 |
|---|---|---|
| 银氨溶液 / 斐林试剂 / 班氏试剂 | 糖酸 | 醛糖与**酮糖**均可反应 → 能反应的称**还原性糖** |
| **溴水** | 糖酸 | 醛糖可、**酮糖不能** → **鉴别醛糖与酮糖**（工业上改进为 $\mathrm{CaBr_2/CaCO_3}$ 电解氧化直接得葡萄糖酸钙） |
| 稀 $\mathrm{HNO_3}$ | 糖**二**酸 | 醛糖：醛基与羟甲基均被氧化为 —COOH；酮糖如果糖：羰基与羟甲基间 C—C 断裂 |
| 浓 $\mathrm{HNO_3}$ | 碳链断裂 | $2^{\circ}$ 醇也被氧化，故键断裂 |
| $\mathrm{HIO_4}$ | 邻二醇/邻羟基醛酮处断键 | **每断一个 C—C 消耗 1 mol $\mathrm{HIO_4}$**，断键碳上各加一个 —OH（糖结构推断的定量工具） |

#### 4.3 成脎反应
- 醛糖、酮糖均与**苯肼**缩合生成**糖脎**（黄色结晶）
- 不同糖形成的脎**晶形不同** → 可借晶形鉴别糖

#### 4.4 改变碳链长度（结构推断的两组利器）
- **增碳 —— Kiliani 氰化增碳法**：醛糖 + HCN → 羟基腈（多一个 CHOH）→ 水解得内酯 → 钠汞齐还原为醛基 → 得比原醛糖**多一个碳**的醛糖
- **降碳**：
  - **Ruff 降级**：醛糖氧化成糖酸 → 制成钙盐 → 铁盐 + $\mathrm{H_2O_2}$ 处理 → 得少一个碳的醛糖
  - **Wohl 降级**：醛糖 + 羟胺 → 糖肟 → 脱水成腈 → 脱去 HCN → 得少一个碳的醛糖
- **联合用法（本讲例题主线）**：逐级降级 + 氧化，通过**测定产物是否具有旋光性**反推糖的构型 —— 增碳得不到旋光活性的产物说明分子具对称面，反之则不对称

### 5. 氨基酸的化学性质

#### 5.1 偶极离子与等电点
- 氨基酸同时含 —NH₂ 与 —COOH → 以**偶极离子（内盐）**形式存在：$\mathrm{H_3N^+CHRCOO^-}$
  - 由此解释：不挥发、高熔点（实为熔融即分解）
- 平衡体系：$\mathrm{A \rightleftharpoons C + H^+}$（$K_1$，即 $\mathrm{H_3N^+CHRCOOH \rightleftharpoons H_3N^+CHRCOO^- + H^+}$）与 $\mathrm{C \rightleftharpoons B + H^+}$（$K_2$）
- **等电点定义**：在电场中正、负离子迁移恰好抵消、无净迁移时的 pH
- **等电点公式推导**：
  $$K_1 = \frac{[C][\mathrm{H^+}]}{[A]},\quad K_2 = \frac{[B][\mathrm{H^+}]}{[C]}$$
  两式相乘取负对数，并代入 $[A]=[B]$ 的等电点条件：
  $$\mathrm{p}K_1 + \mathrm{p}K_2 = -2\lg[\mathrm{H^+}] = 2\mathrm{pH} \;\Longrightarrow\; \boxed{\mathrm{pI} = \frac{\mathrm{p}K_1 + \mathrm{p}K_2}{2}}$$
- 甘氨酸：$\mathrm{p}K_1 = 2.35$、$\mathrm{p}K_2 = 9.78$ → $\mathrm{pI} = 6.065$
- **pH 与迁移方向**：
  | 条件 | 行为 |
  |---|---|
  | pH < pI | 偶极离子结合质子带**正**电 → 向**负极**移动，溶解度增大 |
  | pH > pI | 偶极离子失去质子带**负**电 → 向**正极**移动，溶解度增大 |
  | pH = pI | 溶解度**最小**，偶极离子浓度**最大** |

#### 5.2 茚三酮反应
- 茚三酮两侧羰基的吸电子效应使中间羰基易与水加成 → 生成**水合茚三酮**
- 具有**游离氨基**的氨基酸与水合茚三酮反应生成紫色物质 **Ruhemann 紫** → 鉴定氨基酸最简便的方法
- **脯氨酸只有亚氨基** → 与水合茚三酮反应得**黄色**产物

### 6. 氨基酸的合成（四条路线）
| 方法 | 试剂/步骤 | 要点 |
|---|---|---|
| **Strecker 法** | 醛 + HCN + 氨 → $\alpha$-氨基腈 → 水解 | 最直接的 $\alpha$-氨基酸合成 |
| **Gabriel 法** | 邻苯二甲酰亚胺盐 + $\alpha$-卤代酸酯 → 水解 | 为便于后处理，最后可用**肼解**代替酸/碱水解 |
| **Hell-Volhard-Zelinski 法** | 羧酸 $\alpha$-溴代 → 与氨反应 | 反应需**加压** |
| **乙酰氨基取代的丙二酸酯法** | 乙酰氨基丙二酸酯烷基化后水解 | **目前最常用** |

- 共同问题：上述方法所得 $\alpha$-氨基酸均为**外消旋体**，须用天然手性生物碱拆分
- **外消旋酸/碱的拆分原理**：外消旋酸（或碱）与旋光纯的碱（或酸）成盐 → 生成两种**非对映体**盐 → 利用**溶解度差异**分离

## 竞赛要点

1. **D/L 判据只看倒数第一个手性碳**，不要从 C2 往下数错；命名与构型（R/S）是两套独立系统，须能互相换算（如 D-葡萄糖 = 2R,3S,4R,5R）
2. **醛糖 vs 酮糖的鉴别唯一可靠手段是溴水**：银氨/斐林/班氏对二者都氧化（因为碱催化下可互变），不能用来区分
3. **$\mathrm{HIO_4}$ 消耗量是定量推断的核心**：每断一个 C—C 消耗 1 mol，邻二醇或邻羟基醛酮结构断键；配合「三乙酸酯生成」可反推分子中有几个 —OH，从而定位亚甲基
4. **降级 + 氧化 + 测旋光是糖结构推断的标准三件套**：
   - 氧化产物**无旋光** → 分子有对称面（两端取代基相同）
   - 降级后仍能到 L-甘油醛 → 骨架为 L 系
   - 「—CHO 与 —$\mathrm{CH_2OH}$ 交换后结构不变」是判定**对称糖**（如 D-赤藓糖型）的强条件
5. **增碳与降碳会改变手性中心数目**：Kiliani 法引入新手性碳 → 得一对非对映体（本讲例题即用「还原后是否有旋光」区分）
6. **等电点公式要会自己推**：$\mathrm{pI} = (\mathrm{p}K_1 + \mathrm{p}K_2)/2$ 只适用于**中性氨基酸**（侧链无可电离基团）；酸性/碱性氨基酸须取相应两侧的 $\mathrm{p}K$ 平均
7. **氨基酸型内盐的普适性**：任何「既有酸性基团、又有可质子化碱性位点」的分子都可能以内盐存在并显示异常高熔点 —— 2003 全国初赛的 Roundup（草甘膦）题即为此类，且其一级电离须定义在「所有碱性位点已质子化的型体」上
8. **生物大分子的常识题**（2000 / 2003 初赛）：蛋白质 + 甲醛变性、DNA 三种基本组分（磷酸、脱氧核糖、碱基）、碱基排列顺序存储遗传信息、双螺旋内主要作用力是氢键 —— 属纯记忆型考法

## 例题与习题

### 典型例题

**例1**：A 是五碳醛糖，氧化为糖二酸 B 后**无旋光性**；A 降级为四碳醛糖 C，C 氧化所得糖二酸 D **有旋光性**；C 再降级则生成 **L-甘油醛**。推测 A、B、C、D。
> 解：由最终到 L-甘油醛确定 A 为 L 系骨架。B 无旋光 → B 有对称面，故 A 只有两种可能（2 位与 4 位 —OH 同侧的对称型）。分别降级后氧化，只有「得到有旋光性 D」的那一支符合 → 唯一确定 A、B、C、D。**方法：先由「无旋光」筛对称结构，再用降级产物旋光性二选一。**

**例2**（2003 年全国初赛试题）：除草剂 Roundup（草甘膦）无色晶体、熔点高达 200 ℃，$pK_1$ 0.8、$pK_2$ 2.3、$pK_3$ 6.0、$pK_4$ 11.0。
> 解：(1) 结构相当于氨基酸 → 以**内盐（偶极离子）**存在于晶体中（羧基与磷羟基中酸性更强的那个先与亚氨基反应），解释高熔点。(2) 200–230 ℃ 先熔后固化得**双聚体 A**：两分子交叉进行亚氨基对羧基碳的亲核进攻生成**酰胺键**。(3) 一级电离定义在「亚氨基已质子化的型体」上；用分布系数 $\delta_{(1)}$ 计算各 pH 下的主要型体 → 植物韧皮液（pH 8）主要型体为 (3)，细胞内液（pH 5–6）为 (2) 与 (3)。(4) 要测 $pK_1$ 须先把亚氨基完全质子化 → 用 Roundup 的**强酸盐**。**考点：氨基酸型内盐的判断 + 多元酸分布系数计算。**

**例3**：某 D-型糖 $\mathrm{A(C_5H_{10}O_4)}$，$\mathrm{Br_2/H_2O}$ 氧化得 $\mathrm{B(C_5H_{10}O_5)}$；稀 $\mathrm{HNO_3}$ 氧化得**无旋光性**的 C；A 与 $\mathrm{Ac_2O}$ 生成**三乙酸酯** D；1 mol A 消耗 **2 mol $\mathrm{HIO_4}$**。推测 A、B、C、D。
> 解：$\mathrm{Br_2/H_2O}$ 只把醛基氧化为羧基 → 得五碳骨架。分子仅 4 个氧而能生成**三乙酸酯** → 有 3 个 —OH，说明 **3-位或 4-位是亚甲基**（无羟基）。稀硝酸氧化产物 C 无旋光 → 两端对称，且 3-位为亚甲基 → C 为 2-羟基戊二酸型对称二酸。回推得 A（3-脱氧-D-五醛糖）、B（对应糖酸）、D（三乙酸酯）。**三个条件（酯化数、$\mathrm{HIO_4}$ 消耗量、氧化产物旋光性）协同定位。**

**例4**：某 D-型**非还原性**糖 $\mathrm{A(C_7H_{14}O_6)}$，无旋光现象；稀盐酸水解得还原性糖 $\mathrm{B(C_6H_{12}O_6)}$；B 经稀硝酸氧化得**非光学活性**二元酸 $\mathrm{C(C_6H_{10}O_8)}$；B 经 Ruff 降级得 $\mathrm{D(C_5H_{10}O_5)}$，D 氧化得**有光学活性**的 $\mathrm{E(C_5H_8O_7)}$；A 经 $\mathrm{(CH_3O)_2SO_2{-}NaOH}$、稀盐酸、热浓 $\mathrm{HNO_3}$ 处理后得 **2,3-二甲氧基丁二酸 + 2-甲氧基丙二酸**。
> 解：A 非还原性 → 是**糖苷**（端基被保护）；无旋光 → 分子对称。水解得 B（己醛糖）。B 氧化得非光学活性二酸 → B 对称（半乳糖型/阿洛糖型）。再结合 D 氧化得**有**旋光活性的 E，二选一定出 B = **D-半乳糖**，D = D-来苏糖，E = 对应五碳二酸。最后由甲基化-水解碎片「2,3-二甲氧基丁二酸 + 2-甲氧基丙二酸」确定 A 为 **B 的甲基糖苷**，并定位苷键位置与环型（吡喃/呋喃）。**方法：甲基化-水解碎片法是判定糖苷键位置的标准手段。**

### 本讲习题要点
- **构型式书写题**：糖的 $\mathrm{HIO_4}$ 氧化断键产物、甲基化糖苷、磷酸酯化产物的构型式（要求标构型）
- **合成题**：以邻苯二甲酰亚胺钾 + $\alpha$-溴代丙二酸二乙酯 + 苄氯合成 **(±)-苯丙氨酸**（Gabriel 法 + 丙二酸酯法组合）
- **降级-氧化链推断题（4 道以上，本讲主线）**：由「还原后/氧化后是否有旋光」「降级后到哪一种甘油醛」「—CHO 与 —$\mathrm{CH_2OH}$ 交换后是否不变」三组条件唯一确定糖的结构，如 $\mathrm{C_6H_{12}O_5}$（C-3 为 S 构型）+ $\mathrm{HIO_4}$ 消耗 2 mol 的推断题
- **增碳链推断题**：由 D-己醛糖经 Kiliani 法得两个庚醛糖 B、C，再用 $\mathrm{NaBH_4}$ 还原后旋光性差异区分 B、C
- **生物大分子常识题（含真题）**：2000 年全国初赛（蛋白质 + 甲醛 → 应用与食品安全）、2003 年全国初赛（DNA 双螺旋三组分与碱基存储）、2002 年全国初赛（离子液体溶解纤维素：$\mathrm{[C_4mim]Cl}$ 结构简式、溶解性差异的氢键与摩尔分数解释、聚合度与摩尔分数估算）
