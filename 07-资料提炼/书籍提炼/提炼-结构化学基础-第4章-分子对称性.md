## 三、核心内容提炼

### 3.1 对称操作和对称元素（4.1）

**五类点对称操作**：

| 对称操作 | 对称元素 | 记号 | 说明 |
|----------|----------|------|------|
| 旋转 | 旋转轴 | $C_n$ | 基转角α=360°/n |
| 反映 | 镜面 | σ | σᵥ(含主轴)/σₕ(⊥主轴)/σd(平分C₂) |
| 反演 | 对称中心 | i | 所有坐标取反 |
| 旋转反映 | 映轴 | $S_n$ | 先转360°/n再对σₕ反映 |
| 旋转反演 | 反轴 | $I_n$ | 先转360°/n再对i反演 |

**Schönflies记号与习惯记号的关系**：$S_n$ 和 $I_n$ 的关系较复杂：
- n为奇数：$I_n$ 等价于 $C_{ni}$ 点群
- n为偶数但非4的倍数：$I_n$ 等价于 $C_{n/2,h}$
- n为4的倍数：$I_n$ 等价于 $S_n$

**重要等价关系**：$I_1 = i$（对称中心），$I_2 = σ$（镜面）。

### 3.2 群论基础（4.2）

**群的四个条件**：
1. 封闭性：AB = C，C必在群中
2. 主操作：存在恒等元E
3. 逆操作：每个A有逆A⁻¹
4. 结合律：A(BC) = (AB)C

**对称元素组合规则**：
1. 两个C₂轴夹角2π/2n → 交点出现Cₙ轴
2. 两个镜面夹角2π/2n → 交线为Cₙ轴
3. 偶次轴⊥镜面 → 出现对称中心i

### 3.3 点群分类与判别（4.3）——**核心技能**

**10类点群**：

| 类型 | 特征 | 典型分子 |
|------|------|----------|
| $C_n$ | 只有Cₙ | H₂O₂(C₂) |
| $C_{nh}$ | Cₙ + σₕ | 反式H₂O₂(C₂ₕ) |
| $C_{nv}$ | Cₙ + n个σᵥ | H₂O(C₂ᵥ), NH₃(C₃ᵥ) |
| $S_n$ | 只有Iₙ轴 | 1,3,5,7-四甲基环辛四烯(S₄) |
| $D_n$ | Cₙ + ⊥的n个C₂ | — |
| $D_{nh}$ | Dₙ + σₕ | BF₃(D₃ₕ), 苯(D₆ₕ), XeF₄(D₄ₕ) |
| $D_{nd}$ | Dₙ + n个σd | 丙二烯(D₂d), 乙烷交叉式(D₃d) |
| $T_d$ | 4C₃ + 3I₄ + 6σd | CH₄, 金刚石 |
| $O_h$ | 3C₄ + 4C₃ + 6C₂ + 3σₕ + 6σd + i | SF₆, 立方体 |
| $I_h$ | 6C₅ + 10C₃ + 15C₂ + 15σ + i | C₆₀(足球烯) |

**点群判别流程**：

```
有无多个高次轴？
├── 有6个C₅ → I/Ih
├── 有3个C₄ → O/Oh
├── 有4个C₃ → T/Td/Th
└── 无多个高次轴
    有无Cₙ(n≥2)？
    ├── 有
    │   有无⊥Cₙ的n个C₂？
    │   ├── 有 → Dₙ类
    │   │   ├── +σₕ → Dₙₕ
    │   │   ├── +σd → Dₙd
    │   │   └── 无 → Dₙ
    │   └── 无 → Cₙ类
    │       ├── +σₕ → Cₙₕ
    │       ├── +σᵥ → Cₙᵥ
    │       └── 无 → Cₙ
    └── 无
        有无Iₙ？
        ├── 有 → Sₙ(n为4的倍数)或Cₙᵢ
        └── 无 → C₁(无对称性)或Cs(只有σ)或Ci(只有i)
```

### 3.4 偶极矩与对称性（4.4）

**核心规则**：只有属于 $C_n$ 和 $C_{nv}$ 点群的分子才有永久偶极矩。

**推论**：
- 有对称中心i → 无偶极矩
- 有σₕ → 无偶极矩
- Dₙ/Dₙₕ/Dₙd/T/O/I → 无偶极矩

**键矩矢量加和**：多原子分子的偶极矩≈各键矩的矢量和。

**极化率**：$\mu_{诱} = \alpha E$，可通过折射率计算。

### 3.5 旋光性与手性（4.5）

**判断规则**：
- 有反轴$I_n$（包括$i = I_1$和$σ = I_2$）→ **无旋光性**
- 无任何反轴 → **可能有旋光性**

简化：无σ、无i、无$I_{4n}$ → 手性分子

**所有螺旋形分子**都无反轴对称性，都可能旋光。

### 3.6 群的表示与特征标表（4.6）

**核心概念**：
- **可约表示**：可通过相似变换对角方块化的矩阵群
- **不可约表示**：无法进一步约化的矩阵群
- **特征标**：矩阵的迹（对角元之和），在相似变换中不变

**不可约表示的性质**：
1. 数目 = 群中类的数目
2. 维数的平方和 = 群的阶
3. 特征标之间满足正交性和归一性

**特征标表应用**（振动光谱判断）：
1. 红外活性：振动的对称类型与x/y/z之一相同
2. Raman活性：振动的对称类型与x²/y²/z²/xy等二次方之一相同

## 五、典型例题与常见错误

### 5.1 高频考点

| 题号 | 内容 | 核心考点 |
|------|------|----------|
| 4.1-4.2 | 写对称元素 | 基本识别能力 |
| 4.5-4.10 | 判别点群 | 流程图应用 |
| 4.11-4.13 | 偶极矩判断 | Cₙ/Cₙᵥ规则 |
| 4.16-4.18 | 旋光性判断 | σ/i/I₄ₙ检查 |

### 5.2 常见错误

1. **T_d vs O_h混淆**：T_d有4个C₃（体对角线）+3个I₄；O_h有3个C₄+4个C₃+对称中心
2. **Dₙₕ中i的有无**：Cₙ为偶数轴时有i，奇数轴时无i
3. **σᵥ/σₕ/σd区分**：σᵥ含主轴、σₕ⊥主轴、σd平分C₂轴夹角
4. **Sₙ vs Iₙ混淆**：Sₙ是映轴（先转后反映），Iₙ是反轴（先转后反演）
5. **手性判断简化**：不是"有不对称碳就一定手性"，要看整体对称性
