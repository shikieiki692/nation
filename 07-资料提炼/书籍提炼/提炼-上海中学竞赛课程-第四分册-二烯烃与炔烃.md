# 提炼-上海中学竞赛课程-第四分册-二烯烃与炔烃

> 来源：上海中学竞赛课程·化学·第4分册·第五讲 二烯烃与炔烃
> 提炼日期：2026-07-08

---

## 一、内容概要

本讲介绍了二烯烃的分类（联烯、孤立二烯、共轭二烯）与共轭二烯的特殊反应（1,2-加成与1,4-加成、Diels-Alder反应），以及炔烃的结构特点（sp杂化、端炔氢酸性）和化学性质（端炔氢反应、亲电加成、亲核加成、还原反应）。重点为共轭效应的应用、Diels-Alder反应的规则和炔烃的特殊反应性。

## 二、核心知识点

### 2.1 二烯烃的分类与结构
- **联烯**：两个C=C共用一个碳原子（累积二烯）
- **孤立二烯**：两个C=C相隔两个以上碳原子
- **共轭二烯**：两个C=C被一个C-C单键隔开，形成π-π共轭体系
- **共轭效应**：电子离域使C₂-C₃间具有部分双键性质，整体电子云密度加大，亲电加成活性提高

### 2.2 共轭二烯的亲电加成
- 以1,3-丁二烯 + HCl为例
- 生成烯丙基型碳正离子（共振稳定化）→ 分别在C₂和C₄上接受Cl⁻
- **1,2-加成**（动力学控制）：低温有利，产物为3-氯-1-丁烯
- **1,4-加成**（热力学控制）：高温有利，产物为1-氯-2-丁烯（多取代烯烃更稳定）
- 能量图分析：1,2-加成过渡态能垒低（动力学），1,4-加成产物能量低（热力学）

### 2.3 Diels-Alder反应（双烯合成）
- **定义**：共轭二烯（双烯体）+ 含C=C或C≡C的不饱和化合物（亲双烯体）→ 六元环烯烃
- **特征**：1,4-环加成，通过环状过渡态的协同反应，立体专一的顺式加成
- **立体化学**：亲双烯体的顺反关系在产物中保持不变
- **电子效应**：双烯体上有给电子基团 + 亲双烯体上有吸电子基团 → 有利反应
- **区域选择性**：
  - 1-取代双烯体 + 单取代亲双烯体 → 邻位产物为主
  - 2-取代双烯体 → 对位产物为主
- **内型/外型选择性**：
  - 亲双烯体吸电子基团与C=C共轭时 → 内型（endo）产物为主（次级轨道作用）
  - 无共轭关系时 → 外型（exo）产物为主
- **可逆性**：高温下可发生逆Diels-Alder反应

### 2.4 炔烃结构
- sp杂化碳原子电负性较大 → 炔碳-氢键共用电子对偏向碳 → 端炔氢有酸性（pKₐ ≈ 25）
- sp碳电负性 > sp²碳 → 叁键电子与sp碳结合更紧密 → 炔烃亲电加成活性比烯烃低

### 2.5 炔烃化学性质

#### 端炔氢反应
- 端炔 + NaNH₂/液氨 → 炔钠（RC≡CNa）
- 炔钠是重要亲核试剂：
  - 亲核取代：RC≡C⁻ + R'CH₂X → RC≡CCH₂R + NaX
  - 亲核加成：RC≡C⁻ + R'C(=O)R'' → RC≡C-C(OH)(R')R''
- 端炔与银氨溶液/亚铜氨溶液 → 金属炔化物（鉴别端炔）

#### 亲电加成
- 与HX加成：需Hg²⁺催化，遵循马氏规则
- 与X₂加成：比烯烃困难，需催化剂
- 与H₂O加成（Hg²⁺催化）→ 烯醇式 → 互变为酮

#### 亲核加成
- 炔烃可与醇、胺等亲核试剂加成（烯烃一般不能）

#### 还原反应
- Lindlar催化剂（Pd-CaCO₃/PbO）+ H₂ → 顺式烯烃（部分还原）
- Na/液氨 → 反式烯烃（Birch还原条件）

## 三、竞赛要点

1. **1,2-加成 vs 1,4-加成的温度控制**：低温→动力学产物（1,2-），高温→热力学产物（1,4-），这是竞赛经典考点
2. **Diels-Alder反应的区域选择性和立体选择性**：需掌握endo/exo规则和区域选择性规则
3. **Diels-Alder逆反应**：高温可逆，利用此反应可合成特定双烯体
4. **端炔氢酸性应用**：pKₐ ≈ 25，可用NaNH₂去质子化，进而进行碳链增长（亲核取代）
5. **炔烃还原的选择性**：Lindlar→顺式；Na/NH₃→反式，这是合成特定构型烯烃的重要方法
6. **炔烃亲电加成活性低于烯烃**：sp杂化碳电负性大，电子束缚紧，不易给出电子给亲电试剂

## 四、例题与习题

### 典型例题

**例1**：1,3-丁二烯与1 mol HBr在-80°C和40°C反应，分别得到什么产物？
> 解：-80°C（低温）→ 动力学控制→1,2-加成产物为主（CH₃CHBrCH=CH₂，3-溴-1-丁烯）；40°C（高温）→ 热力学控制→1,4-加成产物为主（CH₃CH=CHCH₂Br，1-溴-2-丁烯，多取代烯烃更稳定）。

**例2**：写出环戊二烯与马来酸酐的Diels-Alder反应产物结构。
> 解：环戊二烯为双烯体，马来酸酐为亲双烯体（含吸电子基团的C=C）。产物为二环[2.2.1]庚-5-烯-2,3-二甲酸酐（内型产物为主）。

**例3**：如何从丙炔制备顺-2-丁烯和反-2-丁烯？
> 解：丙炔 + NaNH₂ → CH₃C≡CNa；CH₃C≡CNa + CH₃I → CH₃C≡CCH₃（2-丁炔）；Lindlar催化剂+H₂ → 顺-2-丁烯；Na/液氨 → 反-2-丁烯。

### 竞赛训练要点
- 练习判断Diels-Alder反应产物的endo/exo选择性
- 练习1,2-和1,4-加成产物的预测
- 利用端炔钠进行碳链增长的合成设计
- 利用炔烃选择性还原合成特定构型烯烃
