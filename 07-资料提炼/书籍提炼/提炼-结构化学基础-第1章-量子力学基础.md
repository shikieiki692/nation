## 三、核心内容提炼

### 3.1 微观粒子的运动特征

**波粒二象性的两个核心公式：**

$$E = h\nu \qquad p = h/\lambda$$

其中h=6.626×10⁻³⁴ Js，将波性（ν,λ）和粒性（E,p）统一。

**光电效应方程：**

$$h\nu = W + E_k = h\nu_0 + \frac{1}{2}mv^2$$

- W为脱出功，ν₀为临阈频率
- 光电子动能与入射光频率成线性关系（斜率=h）
- 实验测定h的方法：作Eₖ-ν图，斜率即h

**de Broglie关系式：**

$$\lambda = h/mv = h/p$$

实物微粒也具有波动性。用加速电压V加速电子时，$\lambda = h/\sqrt{2meV}$。

**不确定度关系：**

$$\Delta x \cdot \Delta p_x \geqslant h$$

- 宏观物体：h可视为零→经典力学适用
- 微观粒子：h不能视为零→量子力学必须
- **竞赛重要应用**：判断某体系是否适用经典力学；估算粒子位置或速度的不确定度

### 3.2 量子力学基本假设

**假设I（波函数）**：体系状态用ψ(x,y,z,t)描述；定态波函数ψ(x,y,z)不含时间。ψ*ψdτ为体积元dτ中电子出现的概率。品优波函数须满足：单值、连续、平方可积（有限）。

**假设II（算符）**：可观测物理量A对应线性自轭算符 $\hat{A}$。

关键算符：
- 动量算符：$\hat{p}_x = -\frac{ih}{2\pi}\frac{\partial}{\partial x}$
- Hamilton算符（能量算符）：$\hat{H} = -\frac{h^2}{8\pi^2 m}\nabla^2 + \hat{V}$

**假设III（Schrödinger方程）**：$\hat{H}\psi = E\psi$，这是量子力学核心方程。解此方程→得ψₙ和Eₙ。本征函数组正交归一：

$$\int\psi_i^*\psi_i\mathrm{d}\tau = 1 \quad (\text{归一}) \qquad \int\psi_i^*\psi_j\mathrm{d}\tau = 0 \ (i\neq j) \quad (\text{正交})$$

**假设IV（态叠加原理）**：$\psi = \sum c_i\psi_i$，物理量A的平均值 $\langle a\rangle = \int\psi^*\hat{A}\psi\mathrm{d}\tau$

**假设V（Pauli原理）**：同一轨道最多容纳两个自旋相反的电子。全波函数对电子坐标交换必须反对称。

### 3.3 箱中粒子（势箱模型）

**一维势箱**（V=0, 0<x<l）的解：

$$\psi_n(x) = \sqrt{\frac{2}{l}}\sin\frac{n\pi x}{l}, \qquad E_n = \frac{n^2h^2}{8ml^2} \qquad (n=1,2,3,\ldots)$$

**五个量子效应：**
1. 粒子可存在多种运动状态ψᵢ
2. **能量量子化**——E∝n²，能量不连续
3. **存在零点能**——n=1时E₁=h²/8ml²≠0
4. 粒子按概率分布，不存在运动轨道
5. 波函数有节点（ψ=0处），节点越多能量越高

**三维势箱**（a×b×c）：

$$E = \frac{h^2}{8m}\left(\frac{n_x^2}{a^2}+\frac{n_y^2}{b^2}+\frac{n_z^2}{c^2}\right)$$

当a=b=c时，不同(nx,ny,nz)组合可能对应相同能量→**简并态**。

**量子力学处理微观体系的一般步骤**：
1. 写出势能函数V和H算符及Schrödinger方程
2. 解方程，用边界条件求ψₙ和Eₙ
3. 描绘ψₙ和|ψₙ|²图形
4. 求各物理量数值
5. 联系实际应用

**隧道效应**：势垒有限时，粒子穿透势垒的概率不为零→扫描隧道显微镜(STM)原理。

### 3.4 势箱模型的重要应用（竞赛高频）

**共轭分子的π电子处理**：
- 将共轭π电子视为一维势箱中粒子
- 箱长l的估算：烯基（—CH=CH—）平均长度约248 pm，两端需加延伸
- π电子数的确定：每个烯基贡献2个π电子，加上端基孤对/电荷修正
- 最高占据→最低空轨道的能级差→吸收光波长

**苯的环形势箱模型**：

$$E_n = \frac{n^2h^2}{8\pi^2 mR^2}, \quad n=0, \pm1, \pm2, \ldots$$

n=0非简并，|n|≥1二重简并。苯的UV吸收可用此模型近似解释。

## 五、典型例题与常见错误

### 典型例题

**例1（必做·基础）**：光电效应——已知Na的光电效应数据，作Eₖ-ν图求h、W和ν₀。
- **要点**：斜率法求h，截距法求ν₀

**例2（必做·应用）**：de Broglie波长计算——给定粒子质量和速度/动能，求λ。
- **要点**：$\lambda=h/mv$ 或 $\lambda=h/\sqrt{2mE_k}$，单位换算是关键（eV→J）

**例3（重要·竞赛）**：共轭体系光谱——用一维势箱模型估算花菁染料/多烯的吸收波长。
- **要点**：①确定π电子数→②确定HOMO(n)和LUMO(n+1)→③ΔE=Eₙ₊₁-Eₙ→④λ=hc/ΔE

**例4（重要·竞赛）**：苯的环形势箱——用圆环势箱模型估算苯的UV吸收波长。
- **要点**：环形量子数n=0(非简并),±1(二重简并)，6个π电子填n=0,±1

### 常见错误

| 错误 | 说明 |
|------|------|
| **π电子数算错** | 忘记端基原子的孤对电子贡献或电荷修正。花菁染料的通式分析是典型陷阱 |
| **HOMO→LUMO判断错** | 如共轭离子10个π电子→填到n=5，HOMO是n=5，LUMO是n=6，而非n=4→5 |
| **不确定度关系方向搞反** | Δx·Δpx≥h中，Δx大→Δpx小（位置确定则动量不确定），不是Δx大→Δpx大 |
| **势箱长度估算** | 共轭体系两端需考虑延伸（约各加一个键长），不直接等于几何长度 |
| **单位换算错误** | eV→J（×1.602×10⁻¹⁹）、nm→m（×10⁻⁹）、pm→m（×10⁻¹²）频繁出错 |
