## 二、教学逻辑锚点

**主线：三类"有机金属/类羰基"化合物的统一逻辑——σ-给予/π-反馈键（synergic）与 18e 规则。**

本章按"M—C 键类型"组织：
1. **金属烷基（M—C 单键）**：最基础的有机金属键，离子型 vs 共价型，主族烷基的多中心键（Li₄/Al₂ 桥）是本段独特内容。
2. **金属羰基（M—CO）**：全章重心。CO 作为典型 π-酸配体，σ 给予 + π 反馈协同；18e 规则在羰基化学中大放异彩；νCO 谱学是"反馈键强度"的直接证据（等电子体系列 2066→1462 cm⁻¹）。
3. **类羰基（N₂/NO/CN⁻/RNC）**：都是 CO 的等电子体，σ/π 配键强弱差异构成一条完整的"π-接受性光谱"（CN⁻ < RNC < CO < NO）。

**教学展开顺序建议**：CO 电子结构 → σ-π 协同配键 → 18e 规则验证（单核/双核）→ νCO 谱学定量反馈键 → 类羰基等电子体横向对比 → 金属烷基作为反面对照（M—C 单键、多中心键）。

## 四、知识点提取

### 4.1 金属烷基化合物（6.1）

**定义与分类**
- 金属有机化合物 = 含 M—C 键的化合物（狭义）。
- 两类：**离子型**（如 Na⁺C₅H₅⁻，Na—C 键高度极化）与**共价型**（烷基化合物）。

**结构特征**
- 主族金属烷基的结构反常（缺电子多中心键）：
  - Li₄(CH₃)₄：**四聚体**，Li 四面体，甲基桥连（桥甲基多中心键）。
  - Al₂(CH₃)₆：**二聚体**，两个桥甲基形成 **3c-2e 桥键**（三中心两电子）。
  - Be/Mg(CH₃)₂：**多聚体**。
  - Zn/Cd/Hg(CH₃)₂：线形单体（共价 M—C）。
- M—C 键为 2c-2e 共价键；桥甲基为多中心缺电子键。
- M—C 键比 C—C 键弱、极性更强，对空气/水敏感。

**合成方法（4 法）**
1. 金属 + 卤代烃直接反应：RMgX（Grignard）、RLi、RAI（需无水无氧）。
2. 金属置换：R₂Hg + 2Li → 2RLi + Hg。
3. 复分解：金属卤化物 + 烷基金属试剂（亲核取代）。
4. 加成：M—H + 烯烃/炔烃 → M—C（氢金属化）。

**应用**
- **负碳离子试剂**：RLi、RMgX、烷基铝（有机合成亲核试剂）。
- **Ziegler-Natta 催化剂**：烷基铝 + TiCl₄ 催化烯烃聚合。
- **抗爆剂**：Pb(C₂H₅)₄（四乙基铅）。
- **半导体前驱体**：MOCVD（Ga(CH₃)₃、Al(CH₃)₃）。

### 4.2 金属羰基化合物（6.2）

**（1）分类与典型结构**

单核羰基（表 6.1）：

| 化合物 | 几何构型 | 电子数 | 备注 |
|--------|---------|--------|------|
| V(CO)₆ | Oₕ 八面体 | 17e | 顺磁，18e 规则例外 |
| Cr/Mo/W(CO)₆ | Oₕ 八面体 | 18e | 经典 |
| Fe/Ru/Os(CO)₅ | D₃ₕ 三角双锥 | 18e | |
| Ni(CO)₄ | T₄ 四面体 | 18e | Mond 法 |

双核羰基（表 6.2）：

| 化合物 | 结构 | M—M 键 | 桥 CO |
|--------|------|--------|-------|
| Mn₂(CO)₁₀ | D₄ₕ，无桥 | Mn—Mn 293 pm | 无 |
| Fe₂(CO)₉ | 三桥 | | 3 个 μ2-CO |
| Co₂(CO)₈ | 两桥 | | 2 个 μ2-CO |

- **18e 规则**：金属羰基化合物绝大多数满足（EAN），V(CO)₆ 17e 是典型例外。
- **经典 vs 非经典羰基阳离子**：
  - 经典：中性/负电荷、低氧化态，如 Fe(CO)₅、[Co(CO)₄]⁻。
  - 非经典阳离子：正电荷高氧化态，σ 给予为主、反馈弱甚至无：
    - [Au(CO)₂]⁺ **14e**、[Pt(CO)₄]²⁺ **16e**（16e 例外）、[Ir(CO)₆]³⁺ 18e、[Hg(CO)₂]²⁺。
  - 意义：证明 **16e/14e 也能稳定**，并非只有 18e。
- 羰基衍生物：C₆₀·M(CO)₅（富勒烯配位）。

**（2）制备方法（4 法）**
1. 金属 + CO 直接化合：Ni + CO 25℃/常压；Fe + CO 150℃/10 MPa；Co、Ru 需更高压。
2. **还原法**：用 CO 还原金属盐/氧化物，如 OsO₄ + CO → Os(CO)₅（CO 既是配体又是还原剂）。
3. 羰基**阴离子**：M(CO)₆ + 碱/还原剂（如 Na、NaBH₄、OH⁻）→ [M(CO)₅]²⁻ 等（断裂 M—C 或歧化）。
4. 羰基**阳离子**：M(CO)₆ + 强 Lewis 酸（AlCl₃、BF₃）夺 CO → [M(CO)₆]²⁺ 等（AlCl₃ 先配位 CO 活化）。

**（3）结构与化学键**
- CO 电子结构：KK(3σ)²(4σ)²(1π)⁴(5σ)²；**5σ（C 端孤对）作为 σ 给予体** → 金属。
- **σ-π 配键（synergic）**：C→M σ 给予 + M→CO dπ→π* 反馈，**协同效应**：σ 给予增强 M 反馈，反馈又增强 CO 的 σ 接受。
- 共振式：M—C≡O⁺ ↔ M=C=O（反馈键使 CO 键级从 3 降至 ~2.4-2.8）。
- CO 配位方式（图 6.3）：
  - **端基 μ1-CO**：M—C≡O 直线，最常见。
  - **边桥 μ2-CO**：桥连两个金属（M₂CO）。
  - **半桥**：不对称桥（一个 M—C 短、一个长）。
  - **面桥 μ3-CO**：桥连三个金属（M₃CO，三帽）。
  - **侧基 η²-CO**：C、O 都参与配位（少见，富电子金属）。

**（4）红外谱学（νCO）——反馈键强度的直接证据**
- 自由 CO：νCO = **2143 cm⁻¹**。
- **经典羰基（反馈键 → νCO 下降）**，等电子体系列（负电荷 ↑ → 反馈 ↑ → νCO ↓）：
  - Ni(CO)₄ 2066 → [Co(CO)₄]⁻ 1890 → [Fe(CO)₄]²⁻ 1790 → [Mn(CO)₄]³⁻ 1670 → [Cr(CO)₄]⁴⁻ 1462。
- **非经典羰基阳离子（σ 为主、无反馈 → νCO 反而高于自由 CO）**：
  - [Au(CO)₂]⁺ 2235、[Hg(CO)₂]²⁺ 2280、[Pt(CO)₄]²⁺ 2261、[Ir(CO)₆]³⁺ 2295（均 > 2143）。
- **桥基 vs 端基**：桥式 CO 的 νCO 显著下降。Co₂(CO)₈ 端基 2050、桥基 1858 cm⁻¹。
- **流变性**：变温 NMR 显示 Co₂(CO)₈ 端基/桥基 CO 快速互换。
- ESCA O 1s 结合能可佐证配位方式。

### 4.3 类金属羰基化合物（6.3）——CO 的等电子体家族

| 配体 | 与 CO 关系 | σ 给予 | π 接受 | 配位要点 |
|------|-----------|--------|--------|---------|
| N₂ | 等电子体 | 弱 | 弱 | 端基 M—N≡N；首个 [Ru(N₂)(NH₃)₅]²⁺；固氮模型 |
| NO⁺ | 等电子体 | 强 | **强于 CO** | 线形 NO⁺（3e）vs 弯曲 NO⁻（1e）；d⁶ 线形 / d⁸ 弯曲 |
| CN⁻ | 等电子体 | 强（主） | 弱 | M—C≡N 端基、μ-CN 桥；普鲁士蓝 |
| RNC | 等电子体 | 强（主） | 弱于 CO | M—C≡NR；Ni(CNR)₄ ν~2033 |

- **π-接受性顺序：CN⁻ < RNC < CO < NO**。
- **双氮配合物（6.3.1）**：
  - 首个双氮配合物 [Ru(N₂)(NH₃)₅]²⁺（Allen & Senoff，1965）。
  - N₂ 端基配位（M—N≡N，端基 M—N ~210 pm）；也有侧基/端桥基/侧桥基。
  - 配位后 N≡N 键长 112 pm（自由 N₂ 109.8 pm）略拉长；νNN 从自由 2331 cm⁻¹ 降至 1900-2100。
  - M—N₂ 配位弱于 M—CO（N₂ σ 给予和 π 接受都弱）。
  - 意义：生物固氮（固氮酶）的化学模型。
- **亚硝酰配合物（6.3.2）**：
  - NO 为 11 电子自由基；NO⁺ 与 CO 等电子。
  - **NO 是比 CO 更强的 π 酸**（NO 的 π* 能量更低）。
  - 线形 NO（NO⁺，3e 供体）vs 弯曲 NO（NO⁻，1e 供体）。
  - **d 电子判据**：低自旋 d⁶ → 线形；d⁸ → 弯曲。例 [Co(NH₃)₅(NO)]²⁺（Co³⁺ d⁶）线形。
  - νNO：自由 NO 1876 cm⁻¹；线形 1800-1900、弯曲 1500-1700。
  - 配位模式转换（线形↔弯曲）使电子数变化 2，可触发缔合取代活化。
- **氰基配合物（6.3.3）**：
  - CN⁻ 以 σ 给予为主、π 接受弱（负电荷使 π* 升高）。
  - 端基 M—C≡N（或 M—N≡C）与边桥 μ-CN（C、N 各连一金属）。
  - 普鲁士蓝 KFe[Fe(CN)₆]：Fe²⁺—C≡N—Fe³⁺ 桥联。
- **异氰配合物（6.3.4）**：
  - RNC 与 CO 类似，σ 给予为主、π 接受弱于 CO。
  - Ni(CNR)₄ 中 ν~2033 cm⁻¹。
  - 应用：萃取分离、催化。

## 十一、六A抽料

- **Ask**：为什么 V(CO)₆ 是 17e 仍稳定？（顺磁、π 反馈补偿）
- **Analyze**：等电子体系列 νCO 递减 = 负电荷增加 → dπ 轨道能升 → 反馈增强 → CO 键级下降。
- **Apply**：由 νCO 判断配体 π-酸性相对强弱（非经典阳离子 νCO>2143 → 无反馈）。
- **Aware**：桥式 CO 的 νCO 显著低于端基（Co₂(CO)₈ 2050/1858）。
- **Assess**：18e 规则对羰基最适用，但 16e（Pt²⁺、Au⁺）与 17e（V(CO)₆）例外须辨识。
- **Act**：授课时用"一条 νCO 数轴"串起反馈键理论，直观性强。

- 非经典羰基阳离子 νCO 反升（>2143）是新手最易错点：反馈键才是 νCO 下降主因，缺反馈时 σ 极化使 νCO 上升。
- NO 计数在"离子法=NO⁺ 2e / 中性法=NO· 3e"之间易混：讲授时固定用 Feltham-Enemark {MNO}ⁿ 或明示计数体系。
- 桥式 CO 电子计数：每个桥 CO 对单金属中心贡献 1e（而非 2e），计算双核总电子时须按"总电子数"处理。
