## 一、群论简化分子轨道计算的数理基石

1. **久期行列式的对称性方块对角化**：
   分子轨道的精确计算需要求解 $n \times n$ 阶久期行列式 $|\mathbf{H} - E\mathbf{S}| = 0$。根据群表示理论，当基函数选用不同不可约表示的基时，不同对称性基函数之间的 Hamiltonian 矩阵元和重叠积分严格为零：
   $$\int \psi_i^{(\Gamma_a)*} \hat{H} \psi_j^{(\Gamma_b)} \mathrm{d}\tau = 0,\quad \int \psi_i^{(\Gamma_a)*} \psi_j^{(\Gamma_b)} \mathrm{d}\tau = 0\quad (\Gamma_a \neq \Gamma_b)$$
   因此，将基函数转化为**对称适应线性组合（Symmetry Adapted Linear Combinations, SALC）**后，巨大的 $n \times n$ 行列式自动分裂为互不耦合的小型对角子块：
   $$|\mathbf{H} - E\mathbf{S}| = |\mathbf{H}_{A_1} - E\mathbf{S}_{A_1}| \times |\mathbf{H}_{B_1} - E\mathbf{S}_{B_1}| \times \dots = 0$$
2. **投影算符（Projection Operator）的标准构造公式**：
   设点群阶数为 $h$，不可约表示 $\Gamma$ 的维数为 $l_\Gamma$（特征标表中恒等操作 $E$ 的特征标），其投影算符定义为：
   $$\hat{P}^{(\Gamma)} = \dfrac{l_\Gamma}{h} \sum_{R} \chi^{(\Gamma)}(R)^* \cdot \hat{R}$$
   将该算符作用于任意一个初始基轨道 $\phi_1$（如某个端基氢原子的 $1s$ 轨道），即可直接滤出具有 $\Gamma$ 对称性的配体群轨道（LGO）。

## 二、经典分子微观轨道与 SALC 精密构造

### 1. 水分子（$\mathrm{H_2O}$，点群 $C_{2v}$）

- **坐标系设定**：分子处于 $yz$ 平面，主轴 $C_2$ 为 $z$ 轴，垂直分子平面的对称面为 $\sigma_v(xz)$，包含分子平面的对称面为 $\sigma_v'(yz)$。
- **中心原子轨道的不可约表示归属**：
  查 $C_{2v}$ 特征标表：
  - 氧原子 $2s$ 与 $2p_z$ 具有 $A_1$ 全对称性；
  - 氧原子 $2p_y$ 具有 $B_2$ 对称性；
  - 氧原子 $2p_x$ 垂直于分子平面，具有 $B_1$ 对称性。
- **配体氢原子 $1s$ 轨道的 LGO 构造**：
  以两氢原子基函数 $(\phi_1, \phi_2)$ 为基，在各操作下不移动原子的数目给出可约表示特征标：
  $\Gamma_{\mathrm{H}} = (2, 0, 0, 2)$。
  约化为两个一维不可约表示：$\Gamma_{\mathrm{H}} = A_1 + B_2$。
  利用投影算符精确作用：
  $$\psi(A_1) = \dfrac{1}{\sqrt{2}}(\phi_1 + \phi_2),\quad \psi(B_2) = \dfrac{1}{\sqrt{2}}(\phi_1 - \phi_2)$$
- **成键配对与能级分布**：
  - $A_1$ 对称性：氧的 $2s$ 和 $2p_z$ 共同与配体 $\psi(A_1)$ 发生 3 轨道相互作用，生成强成键轨道 $2a_1$、弱成键/孤对性质的 $3a_1$，以及高能量反键轨道 $4a_1^*$；
  - $B_2$ 对称性：氧的 $2p_y$ 与配体 $\psi(B_2)$ 对称匹配，生成成键轨道 $1b_2$ 与反键轨道 $2b_2^*$；
  - $B_1$ 对称性：氧的 $2p_x$ 垂直平面，配体中不存在任何 $B_1$ 对称性轨道，故 $2p_x$ **完全不参与成键，作为严格的非键孤对电子轨道（$1b_1$）**。
- **价电子排布与宏观性质验证**：
  8 个价电子填入 4 个已占轨道：$(2a_1)^2 (1b_2)^2 (3a_1)^2 (1b_1)^2$。
  - $2a_1$ 和 $1b_2$ 提供 $\mathrm{O-H}$ 成键网络；
  - $3a_1$（富碳/氧混合杂化取向）与 $1b_1$（纯 $2p_x$）构成了氧原子上的两对孤对电子，这一图像被紫外光电子能谱（UPS）的四个分立电离峰（$12.6\ \mathrm{eV}, 14.7\ \mathrm{eV}, 18.5\ \mathrm{eV}, 32.2\ \mathrm{eV}$）完美证实！

## 三、杂化轨道的严格数理构建与 Coulson 键角关系式

1. **杂化轨道的数学定义与矩阵表达**：
   $n$ 个中心原子杂化轨道 $\psi_i$ 由一组原始原子轨道 $\phi_j$ 经正交酉变换构成：
   $$\psi_i = \sum_{j} c_{ij} \phi_j \quad (i, j = 1, 2, \dots, n)$$
   满足严格的**正交归一化条件**：
   $$\sum_{j} c_{ij}^2 = 1\quad (\text{单个杂化轨道自身归一}),\quad \sum_{j} c_{ij} c_{kj} = 0\quad (i \neq k,\ \text{不同杂化轨道间空间正交})$$
2. **等性与不等性杂化的 $s-p$ 轨道成分（Coulson 公式）**：
   将等效的杂化轨道写为：
   $$\psi_i = \dfrac{1}{\sqrt{1 + \lambda^2}} \phi_s + \dfrac{\lambda}{\sqrt{1 + \lambda^2}} \phi_{p_i}$$
   式中 $\lambda^2$ 称为杂化指数（如 $sp^3$ 杂化 $\lambda^2 = 3$）。
   设任意两个杂化轨道 $\psi_i$ 与 $\psi_j$ 之间的空间夹角为 $\theta_{ij}$，将其代入正交条件 $\int \psi_i \psi_j \mathrm{d}\tau = 0$：
   $$\dfrac{1}{1 + \lambda^2} + \dfrac{\lambda^2}{1 + \lambda^2} \cos\theta_{ij} = 0 \implies 1 + \lambda^2 \cos\theta_{ij} = 0$$
   由此严格导出**现代结构化学核心公式——Coulson 关系式**：
   $$\cos\theta_{ij} = -\dfrac{1}{\lambda^2} = -\dfrac{s\%}{p\%}$$
   - **对于等性 $sp^3$ 杂化**：$\lambda^2 = 3 \implies \cos\theta = -\dfrac{1}{3} \implies \theta = 109^\circ 28'$（严格正四面体）；
   - **对于等性 $sp^2$ 杂化**：$\lambda^2 = 2 \implies \cos\theta = -\dfrac{1}{2} \implies \theta = 120^\circ$（严格平面正三角）；
   - **对于水分子中成键杂化轨道**：实验测得键角 $\theta = 104.5^\circ$，代入 Coulson 公式：
     $$\lambda^2 = -\dfrac{1}{\cos(104.5^\circ)} = -\dfrac{1}{-0.2504} \approx 4.0$$
     表明水分子中氧原子参与形成 $\mathrm{O-H}$ 键的杂化轨道并非等性 $sp^3$，而是**高 $p$ 成分的不等性 $sp^4$ 杂化**；由轨道总成分守恒可知，容纳孤对电子的杂化轨道必然富集更高的 $s$ 成分（接近 $sp^2$），从而完美解释了孤对电子更紧贴原子核、静电推斥更强的物理本质。

## 四、分子振动模式与红外/拉曼光谱选择定则

1. **分子正规振动模式数**：
   $N$ 个原子构成的非线性分子有 $3N - 6$ 个独立振动自由度（线性分子为 $3N - 5$ 个）。
2. **红外与拉曼光谱的群论判据**：
   - **红外活性（IR Active）**：振动过程中分子必须伴随**偶极矩的动态变化**。在群论中，若某个振动模式的不可约表示与偶极矩算符（即平移矢量 $x, y, z$）的不可约表示基相同，则该模式为红外活性；
   - **拉曼活性（Raman Active）**：振动过程中分子必须伴随**极化率椭球的动态变化**。在群论中，若某个振动模式的不可约表示与极化率张量分量（即二阶张量 $x^2, y^2, z^2, xy, yz, xz$）的不可约表示基相同，则该模式为拉曼活性。
3. **互斥规则（Rule of Mutual Exclusion）**：
   **对于具有对称中心（$i$）的分子（如反式二氯乙烯、$\mathrm{CO_2, SF_6, C_6H_6}$），所有全对称或偶对称（$g$ 表示）的振动模式只有拉曼活性；所有奇对称（$u$ 表示）的振动模式只有红外活性，二者绝不重叠！** 若红外与拉曼光谱出现相同的谱峰，可断言该分子必无对称中心。
