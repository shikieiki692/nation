# 提炼-中级无机化学-第2章-配位立体化学

- 来源：[[中级无机化学/中级无机化学_1-199.md]]
- 提炼日期：2026-08-15
- 提炼人：Claudian（KB Agent）

## 一、来源信息
- 书名/出处：《中级无机化学》（北京大学出版社）
- 章节：第2章 配位化学基础和配位立体化学（§2.1–2.5，含习题2.1–2.10）
- 作者：项斯芬、姚光庆
- 出版信息：2003.11
- 注：本章是全书**配位化学主干章**，从"配体是什么"（分类）→"配体怎么摆"（几何构型与配位数）→"怎么区分异构体"（异构现象+群论判据）→"怎么合成"（含模板合成）→"上升到超分子"（识别与自组装）。与《结构化学基础》Ch6（配位场）互补：本书侧重**立体化学全谱系**（配位数 2→12 的构型-点群对应）与**异构体的实验表征**（IR/Raman 谱带数判 fac/mer、手性拆分），并为 R4 超分子专题（决赛13/14/15）提供完整素材链。

## 二、📐 教学逻辑锚点

### 2.1 原文讲解顺序
- **先讲什么**：配体分类（§2.1 按齿合度：单齿→螯合→大环→穴合；按成键特点：Werner 经典配体 vs 非经典 π 酸配体）。从"最常见的配体长什么样"切入。
- **后讲什么**：按配位数逐级展开几何构型（§2.2 配位数 2→12，每级给典型实例+点群）→ 异构现象（§2.3 几何/旋光/键合/电离/溶剂合/配位）→ 合成方法（§2.4 水溶液/非水/模板）→ 超分子化学（§2.5 识别+自组装）。
- **为什么这样排**：**结构描述→性质区分→制备方法→前沿延伸**的四段式。先建立"配位数-构型"直觉（结构决定一切），再用异构体说明"结构细节影响性质"（顺铂 vs 反铂），最后用超分子把"配位键的哲学"推广到非共价作用。与全书"先基础后前沿"总逻辑一致。

### 2.2 铺垫与结论出现时机
- **切入前置**：无需前置，§2.1 从 F⁻/Cl⁻/NH₃ 等熟知的简单配体开始。
- **铺垫段落**：§2.1 的"拓扑束缚力"排序（单齿<螯合<大环<穴合）为 §2.5 超分子"识别强度"埋下伏笔；§2.2 的 CFSE 判断构型为第3章（配位场理论）做概念铺垫（此处先引用表 2.3 的 CFSE 数值，§3 再讲来源）。
- **核心结论何时出现**：① §2.2.4 的 Jahn-Teller 畸变（Cu²⁺/Cr²⁺ 拉长八面体）是结构-电子组态关联的核心；② §2.3.1 的 fac/mer 群论判据（C₃ᵥ vs C₂ᵥ → IR 谱带数 2 vs 3）是"用对称性解决异构体表征"的典范；③ §2.5 的"配位<螯合<大环<穴合"束缚力顺序是全章概念收敛点。
- **一笔带过/暂时跳过**：① 表 2.3 CFSE 的具体计算来源（第3章详述）；② 模板合成的有机化学细节（只需知道"金属作模板稳定中间体/引导定向反应"）；③ 各种高配位数化合物的完整实例清单（竞赛只需记住典型构型+点群+1-2 个代表例）。
- **教学风格**：**实例驱动**——几乎每个构型/异构类型都配具体化合物（Cu(NH₃)₄²⁺、顺铂、Co(en)₃³⁺、[Co(NH₃)₅ONO]²⁺…），适合直接抽作课堂例题。

## 五、数据/图表资产

- **表2.2 常见配体汇总**：名称/化学式/缩写/齿合度（en 2、dien 3、trien/nta 4、EDTA 6、ox/acac/bipy/phen 2）
- **图2.1 配位能力示意**：单齿配位 < 螯合作用 < 大环作用 < 穴合作用（拓扑束缚力递增）
- **表2.3 CFSE（-Δ₀ 单位）**：弱场/强场 × 平面四方/四面体 的 dⁿ 数值；d⁸ 强场平面四方差值最大（2.08）
- **表2.4 五配位化合物**：VF₅(d⁰,三角双锥)、TiF₅²⁻(d¹,四方锥)、Fe(CO)₅(d⁸,三角双锥)、CuCl₅³⁻(d⁹,三角双锥)、InCl₅²⁻(d¹⁰,四方锥)
- **八面体畸变图组**：Oₕ → 四角畸变 D₄ₕ（拉长/压扁）→ 三角畸变 D₃ₕ（三棱柱）vs D₃ₕ 三棱柱；Jahn-Teller：d⁹ Cu²⁺、d⁴ 高自旋 Cr²⁺、低自旋 d⁷
- **CuF₂ 数据**：4×193pm（赤道）+ 2×227pm（轴向，拉长八面体）；K₂CuF₄ 压扁：4×208 + 2×195
- **表2.4高配位稀土**：Eu(dpm)₃(py)₂ 四方反棱柱 D₄ₕ→D₄d；RE(NO₃)₃·3DMSO 三帽三棱柱 D₃ₕ；(NH₄)₂Ce(NO₃)₆ 二十面体 Iₕ（12配位）
- **顺/反-Pt(NH₃)₂Cl₂**：顺式 C₂ᵥ 极性（顺铂抗癌）；反式 D₂ₕ 无极性（无活性）
- **fac/mer 群论判据**：面式 C₃ᵥ → Γ(Rh–X)=A₁+E → 2 个 IR+Raman 带；经式 C₂ᵥ → Γ=2A₁+B → 3 个带
- **NO₂ 键合异构**：[Co(NH₃)₅NO₂]²⁺ 硝基（黄色，N配位）vs [Co(NH₃)₅ONO]²⁺ 亚硝酸根（红色，O配位）；¹⁸O 标记 Taube 证实
- **HSAB 协同（symbiosis）**：硬 Co(NH₃)₅³⁺ → NCS 的 N 端；软 Co(CN)₅³⁻ → SCN 的 S 端
- **表2.8 冠醚-离子匹配**：12-c-4(120~150pm, Li⁺120)；15-c-5(170~190, Na⁺190)；18-c-6(260~320, K⁺266)；21-c-7(340~430, Rb⁺296)；24-c-8(>400, Cs⁺334)
- **表2.9 穴醚选择常数(logK)**：[2.1.1]→Li⁺5.5；[2.2.1]→Na⁺5.40；[2.2.2]→K⁺5.4/Ba²⁺9.5；[3.2.2]→K⁺/Rb⁺/Cs⁺最强
- **18-c-6 数据**：K⁺ logK=6.06（最佳），Na⁺4.32、Rb⁺5.32、Cs⁺4.44
