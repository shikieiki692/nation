## 三、教学逻辑锚点

> 与 Zchem 第二轮深化「主族元素的结构化学I」一致：**N 的成键与氧化还原 → P 的结构与含氧酸 → As/Sb/Bi 惰性电子对递进**，三大板块层层递进。

- **主线**：氮族成键特征与氧化还原贯穿全章——N 无 d 轨道（不能五共价、配位数≤4）→ P 有 d 轨道（sp³d/sp³d²、d-p π 配键）→ Bi 惰性电子对（+3 稳定、Bi(V) 强氧化）。
- **铺垫顺序**：单质（N₂ 惰性 / P₄ 张力）→ 氢化物（碱性递变 NH₃>N₂H₄>NH₂OH；PH₃ 碱性极弱但配位强）→ 含氧酸（N: HNO₂/HNO₃ 氧化性；P: H₃PO₂/H₃PO₃/H₃PO₄ 一元二元三元）→ 卤化物（水解规律）→ As/Sb/Bi 惰性电子对收尾。
- **结论出现时机**：「N₂ 三键 946kJ/mol 最稳定双原子分子」章首，解释氮的惰性与合成氨条件；「硝酸还原产物随金属活泼性/酸浓度变化」中段，是全章氧化还原核心；「Bi(V) 氧化 Mn²⁺」章末，呼应惰性电子对并连接 Ch21 分析。
- **竞赛抓手**：硝酸与金属反应产物判断、HNO₂ 氧化性>HNO₃ 的原因、磷的含氧酸一元二元三元（看 P 上 H 还是 OH）、PH₃ vs NH₃ 配位差异、马氏/古氏试砷法、As₂S₃/Sb₂S₃ 硫代酸盐——均为高频考点。

## 四、核心内容提炼

### 4.1 氮的单质

- **结构**：N≡N 三键（1σ+2π），键长 109.77 pm，键级 3；分子轨道式 KK(σ2s)²(σ2s*)²(π2py)²(π2pz)²(σ2px)²；解离能 946 kJ/mol → **已知双原子分子中最稳定**。
- **化学惰性**：常温极不活泼，用作保护气；放电时 N₂+O₂→2NO（雷雨固氮）。
- **离子型氮化物**：仅与电离能小的ⅠA/ⅡA 金属——6Li+N₂==△==2Li₃N（黑）；3Mg+N₂==△==Mg₃N₂（黄）。
- **制备**：
```
工业：分馏液态空气（除 O₂/水）
实验室：NH₄Cl+NaNO₂ ==△== NaCl+2H₂O+N₂↑（最常用）
(NH₄)₂Cr₂O₇ ==△== N₂↑+Cr₂O₃+4H₂O
8NH₃+3Br₂(aq) = N₂↑+6NH₄Br ； 2NH₃+3CuO ==△== N₂↑+3Cu+3H₂O
```

### 4.2 氮的氢化物

#### (1) 氨 NH₃
- **结构**：sp³ 不等性杂化，三角锥，∠HNH=106°42′，μ=1.47D，强极性/强配位能力；N 上孤对。
- **制备**：工业哈伯法（30-70MPa，400-450℃，Fe 粉催化；25℃ 时 K°=7.5×10²，放热熵减→低温高压有利）；实验室 2NH₄Cl+Ca(OH)₂==△==CaCl₂+2NH₃↑+2H₂O；Mg₃N₂+6H₂O→3Mg(OH)₂+2NH₃。
- **物理性质**：水中溶解度最大气体之一（0℃ 1176 体积/20℃ 775 体积）；液氨自耦解离 2NH₃⇌NH₄⁺+NH₂⁻（K=1.9×10⁻³³）；碱金属液氨溶液含**氨合电子** e(NH₃)ₙ⁻（蓝色、强还原剂），久置放 H₂ 得 NaNH₂。
- **四类反应**（竞赛分类框架）：
  - **配位（加合）**：[Ag(NH₃)₂]⁺/[Cu(NH₃)₄]²⁺；H₃N:→BF₃；水中 NH₃·H₂O（**无 NH₄OH 分子**），Kb=1.8×10⁻⁵，0.10mol/L 仅 1.34% 解离。
  - **取代**：3Mg+2NH₃==△==Mg₃N₂+3H₂；[Ag(NH₃)₂]⁺ 久置→爆炸性 Ag₃N/Ag₂NH（实验后及时处理）。
  - **氨解**（类水解）：4NH₃+COCl₂→CO(NH₂)₂+2NH₄Cl；4NH₃+SOCl₂→SO(NH₂)₂+2NH₄Cl；2NH₃+HgCl₂→Hg(NH₂)Cl↓+NH₄Cl。
  - **氧化**：4NH₃+3O₂==点燃==2N₂+6H₂O；4NH₃+5O₂==Pt 燃烧==4NO+6H₂O（制硝酸第一步）；2NH₃+3Br₂→N₂+6HBr。
- **铵盐**：
  - NH₄⁺ 类 K⁺（半径 143pm vs K⁺138pm）→ 与钾盐类质同晶，沉淀剂相同。
  - 热分解规律：**非氧化性酸铵盐**→NH₃+酸（NH₄HCO₃→NH₃+CO₂+H₂O；NH₄Cl→NH₃+HCl；若酸非挥发性则 NH₃ 逸出留酸）；**氧化性酸铵盐**→NH₄⁺ 被氧化、产物复杂（NH₄NO₃→N₂O+H₂O，高温→N₂+O₂；NH₄ClO₄、(NH₄)₂Cr₂O₇→N₂+Cr₂O₃）。
- **用途**：制硝酸/铵盐化肥/尿素/制冷剂。

#### (2) 联氨 N₂H₄（肼）
- **制备**：2NH₃+ClO⁻→N₂H₄+Cl⁻+H₂O；CO(NH₂)₂+NaClO+2NaOH→N₂H₄+NaCl+Na₂CO₃+H₂O。
- **结构**：sp³，每 N 一对孤对；N 氧化数 -2；偶极矩大（1.75D）→**顺式构象**；N—N 144.9pm 单键。
- **碱性**：二元弱碱，K₁=8.7×10⁻⁷、K₂=1.9×10⁻¹⁴（弱于 NH₃，因第二 N 的吸电子诱导效应）。
- **氧化还原**：动力学稳定/热力学不稳定（催化剂分解 N₂+2H₂ 或 N₂+4NH₃）；作**强还原剂**（氧化剂路径速率慢无实际意义）：N₂H₄+2X₂→4HX+N₂；4AgBr+N₂H₄→4Ag+N₂+4HBr；与 O₂/NO₂/H₂O₂ 放热→N₂+H₂O → **火箭推进剂**。
- 双功能配体（单核/桥联双核）。

#### (3) 羟胺 NH₂OH
- 白色固体（熔点 33.1℃），N 氧化数 -1；-OH 吸电子> -NH₂ → 碱性/配位能力比联氨弱（K=8.7×10⁻⁹）。
- **还原剂**（不给体系引入杂质）：2NH₂OH+2AgBr→2Ag+N₂+2HBr+2H₂O；2NH₂OH+4AgBr→4Ag+N₂O+4HBr+H₂O。

#### (4) 叠氮化氢 HN₃
- 结构：3 个 N 直线，N1 sp² 不等性杂化，N2 sp，N1-N2 124.5pm、N2-N3 113.4pm，含离域 **Π₃⁴**；N 平均氧化数 -1/3。
- 酸性 Kₐ=2.4×10⁻⁵（近醋酸）；N₃⁻ 类卤离子（AgN₃/Pb(N₃)₂ 难溶）；Pb(N₃)₂==△==Pb+3N₂ 作引爆剂。
- 制备：N₂H₄+HNO₂→HN₃+2H₂O；NaN₃ 由 NaNO₃+3NaNH₂ 或 N₂O+2NaNH₂ 制得。

### 4.3 氮的含氧化合物

#### (1) 氮的氧化物（5 种）
- **N₂O**：NH₄NO₃==250℃==N₂O+2H₂O；与 N₃⁻ 等电子（直线形，2 个 Π₃⁴），N-N 112.8pm/N-O 118.4pm；ΔfH°=+81.6kJ/mol 不稳定；助燃、牙科麻醉剂。
- **NO**：3Cu+8HNO₃(稀)→3Cu(NO₃)₂+2NO↑+4H₂O；有单电子→**顺磁**，低温二聚 N₂O₂（顺式）；配位能力（[Fe(NO)]²⁺ 棕色）；空气中立即→NO₂；失电子成 NO⁺（NOCl/NOClO₄）；**生物信使**。
- **N₂O₃**：NO+NO₂==低温==N₂O₃；液态淡蓝/固态蓝；气态不稳定分解；是亚硝酸酐。
- **NO₂ / N₂O₄**：2Pb(NO₃)₂==△==2PbO+4NO₂↑+O₂↑；棕色（NO₂）⇌无色（N₂O₄）；NO₂ sp² V 形（∠ONO=134.1°），**Π₃⁴**，单电子→易聚合；中间价态歧化：3NO₂+H₂O→2HNO₃+NO；2NO₂+2OH⁻→NO₃⁻+NO₂⁻+H₂O。
- **N₂O₅**：6HNO₃+P₂O₅→3N₂O₅+2H₃PO₄；2NO₂+O₃→N₂O₅+O₂；硝酸酸酐；**固态为离子晶体 NO₂⁺NO₃⁻**；强氧化剂。

#### (2) 亚硝酸及其盐
- **制备**：NaNO₂+H₂SO₄→HNO₂+NaHSO₄；NO₂+NO+H₂O==冰水==2HNO₂；Pb+NaNO₃==高温==PbO+NaNO₂（工业）；2NaNO₃==△==2NaNO₂+O₂。
- **结构**：HNO₂ sp² 不等性杂化，**反式稳定**；NO₂⁻ V 形（∠ONO=115.4°），**Π₃⁴**。
- **性质**：弱酸 Kₐ=7.2×10⁻⁴；**既有氧化性又有还原性**（歧化中间态）：
```
5HNO₂+2MnO₄⁻+H⁺ → 5NO₃⁻+2Mn²⁺+3H₂O（还原性，定量）
2HNO₂+2I⁻+2H⁺ → 2NO↑+I₂+2H₂O（氧化性，定量）
3HNO₂ → HNO₃+2NO↑+H₂O（室温歧化）
```
- **关键结论**：同浓度 **HNO₂ 氧化性强于 HNO₃**——因 HNO₂ 是弱酸以分子存在，H⁺ 极化使其不稳定，易分解得还原产物。
- 酸性强时 HNO₂+H⁺→NO⁺+H₂O（亚硝酰离子，经 INO 中间体氧化 I⁻）。
- **盐**：ⅠA/ⅡA 亚硝酸盐稳定（NaNO₂ 284℃ 熔化不分解）；AgNO₂ 浅黄微溶、>140℃ 分解；NO₂⁻ 强配位→K₃[Co(NO₂)₆] 黄色沉淀（**鉴定 Co²⁺**）。

#### (3) 硝酸及其盐
- **制备**：①氨催化氧化法（1000℃，Pt-Rh 网）：4NH₃+5O₂→4NO+6H₂O→2NO+O₂→2NO₂→3NO₂+H₂O→2HNO₃+NO；②NaNO₃+H₂SO₄(浓)→NaHSO₄+HNO₃（蒸馏，只能利用 1 个 H⁺，第二步需 500℃ 高温硝酸分解）。
- **结构**：HNO₃ sp² 等性杂化，平面，分子内氢键，端基 O 与 N 间 **Π₃⁴**；NO₃⁻ 平面正三角，**Π₄⁶**（对称性高→硝酸盐稳定）。
- **氧化性规律**（竞赛核心）：**金属越活泼、硝酸越稀 → 还原产物 N 氧化数越低**：
```
Cu+4HNO₃(浓)→Cu(NO₃)₂+2NO₂+2H₂O
3Cu+8HNO₃(稀)→3Cu(NO₃)₂+2NO+4H₂O
4Zn+10HNO₃(较稀)→4Zn(NO₃)₂+N₂O+5H₂O
4Zn+10HNO₃(极稀)→4Zn(NO₃)₂+NH₄NO₃+3H₂O
```
  - 酸性金属（Sn/Sb/Mo/W）→ 含氧酸或水合氧化物：3Sn+4HNO₃(浓)→3SnO₂+4NO+2H₂O；非金属→高价含氧酸：S→H₂SO₄、P→H₃PO₄。
  - **钝化**：Fe/Al/Cr 遇冷浓硝酸表面致密氧化膜（铝制容器装浓硝酸）。
  - **NO₂ 催化**：4HNO₃ 光/热分解产生 NO₂ 自催化（Cu+浓 HNO₃ 先慢后快；加 NaNO₂ 加速）——发烟硝酸氧化性更强的原因。
- **王水**（浓 HCl:HNO₃=3:1）：Au+HNO₃+4HCl→H[AuCl₄]+NO+2H₂O；3Pt+4HNO₃+18HCl→3H₂[PtCl₆]+4NO+8H₂O。**本质是 Cl⁻ 配位（[AuCl₄]⁻/[PtCl₆]²⁻）增强金属还原能力**（E°(Au³⁺/Au)=1.498V vs [AuCl₄]⁻ 1.002V），不是 NOCl/Cl₂ 氧化。
- **硝酸盐热分解规律**（离子极化）：
  - 活泼金属（Na/K 等，极化力弱）→亚硝酸盐+O₂：2NaNO₃→2NaNO₂+O₂。
  - 中等活泼（Mg~Cu，含 Li/Be）→氧化物+NO₂+O₂：2Pb(NO₃)₂→2PbO+4NO₂+O₂。
  - 不活泼（Cu 后）→单质+NO₂+O₂：2AgNO₃→2Ag+2NO₂+O₂。
  - 阳离子有还原性→被氧化：NH₄NO₃→N₂O+H₂O（>300℃→N₂+O₂）；Mn(NO₃)₂→MnO₂+2NO₂。
  - 带结晶水→水解：Mg(NO₃)₂·6H₂O→Mg(OH)NO₃+HNO₃+5H₂O。
- **鉴别**：亚硝酸盐有还原性（与浓 HNO₃ 产生 NO₂）而硝酸盐无；**棕色环实验**——FeSO₄+NO₃⁻+浓 H₂SO₄ → [Fe(NO)(H₂O)₅]²⁺ 棕色环。

### 4.4 氮的卤化物

- **NCl₃**：黄色油状液，90℃ 以上或受震爆炸（2NCl₃→N₂+3Cl₂）；水解 NCl₃+3H₂O→NH₃+3HClO（N 有孤对，水 H 端先进攻；产物不同于 SiCl₄ 水解）。
- **NF₃**：无色气体，稳定（F 半径小空间有利）；4NH₃+3F₂==Cu==NF₃+3NH₄F；遇水汽火花爆炸。
- NBr₃/NI₃ 不稳定（Cl/Br/I 半径大空间效应不利）——**解释 NX₃ 稳定性随卤素半径增大而降低**。

### 4.5 磷的单质及氢化物

#### (1) 单质磷
- **制备**：2Ca₃(PO₄)₂+6SiO₂+10C==电弧炉 1100-1450℃==6CaSiO₃+P₄+10CO（加 SiO₂ 降低温度）。
- **同素异形体**：
  - **白磷**：P₄ 正四面体，∠PPP=60°（远小于 p 轨道 90°）→**键张力大、键能仅 201kJ/mol**→高活性；燃点 40℃、暗处发光（磷光）；剧毒（0.1g 致死）；保存在水中。
  - **红磷**：白磷密闭加热，P₄ 断一键成链状大分子；稳定不自然；安全火柴。
  - **黑磷**：高压下白磷加热；热力学最稳定；片层状、有导电性。
  - 结构衍生：P₄O₆/P₄O₁₀/P₄S₃/P₄S₇/P₄S₁₀ 均以 P₄ 为骨架。
- **化学性质**：
  - 水中歧化极慢（可保存）；碱性歧化：4P+3NaOH+3H₂O==△==3NaH₂PO₂+PH₃。
  - 3P+5HNO₃(浓)+2H₂O==△==3H₃PO₄+5NO（浓硝酸氧化）。
  - 还原性：2P+5CuSO₄+8H₂O→5Cu+2H₃PO₄+5H₂SO₄；11P+15CuSO₄+24H₂O→5Cu₃P+6H₃PO₄+15H₂SO₄（可生成磷化物）。

#### (2) 磷化氢 PH₃
- **制备**：Ca₃P₂+6H₂O→3Ca(OH)₂+2PH₃；PH₄I+NaOH→NaI+H₂O+PH₃（类铵盐）；白磷热碱歧化。
- **性质**：三角锥，**键角 93.3°**（远小于 NH₃），大蒜味剧毒；碱性极弱（Kb≈10⁻²⁸），PH₄⁺ 水溶液中不存在，PH₃ 能从酸性溶液逸出。
- **配位悖论**：与过渡金属配位能力 **PH₃≫NH₃**（P 空 d 轨道接受金属 d 电子形成**反馈 π 键**）——[PtCl₂(PR₃)₂]、[Cr(CO)₃(PH₃)₃]；但与 H⁺ 结合能力 NH₃>PH₃（H⁺ 无 d 电子可反馈且 P 半径大）。
- **强还原剂**：PH₃+CuSO₄→Cu↓（经 Cu₂SO₄，再与 PH₃ 生成 Cu₃P）；50℃ 与 O₂→H₃PO₄；混入 P₂H₄（联膦）自燃。

### 4.6 磷的含氧化合物

#### (1) 磷的含氧酸总览
- 重要含氧酸及氧化数：H₃PO₂ 次磷酸(+1)、H₃PO₃ 亚磷酸(+3)、H₃PO₄ 正磷酸(+5)、H₄P₂O₇ 焦磷酸(+5)、HPO₃ 偏磷酸(+5)、H₄P₂O₆ 连二磷酸(+4)、H₄P₂O₈ 过二磷酸(+6)。
- **酸性强弱**：(HPO₃)ₙ > H₄P₂O₇ > H₃PO₂ > H₃PO₃ > H₃PO₄（聚合度↑酸性↑；但 H₃PO₂/H₃PO₃ 强于 H₃PO₄ 反常规，因 P 上直接连 H 无氧吸电子）。
- **结构核心**：P 均为 sp³ 杂化；P=O 由 σ 配键 + **d-p π 配键**（P 3d 空轨道接受 O 2p 孤对）构成——H₂SO₄/HClO₄/H₃PO₂ 等含氧酸都有。

#### (2) 磷酸及其盐
- 制备：Ca₃(PO₄)₂+3H₂SO₄→3CaSO₄+2H₃PO₄（肥酸）；白磷+浓硝酸；P₄O₁₀+H₂O。
- 三元中强酸：K₁=7.11×10⁻³、K₂=6.34×10⁻⁸、K₃=4.8×10⁻¹³；**酸/碱中几乎无氧化性**。
- 黏稠（氢键）、高沸点；加热脱水：2H₃PO₄→H₂O+H₄P₂O₇（焦磷酸，四元酸）；nH₃PO₄→nH₂O+(HPO₃)ₙ（偏磷酸）；链状多磷酸通式 Hₙ₊₂PₙO₃ₙ₊₁、环状偏磷酸 (HPO₃)ₙ。
- **磷酸盐水解**：Na₃PO₄ 强碱性（pH>12）、Na₂HPO₄ 弱碱性（pH9-10）、NaH₂PO₄ 弱酸性（pH4-5）。
- **溶解性**：+2 价及高价金属磷酸盐难溶，磷酸二氢盐一般可溶（**二氢>一氢>正盐**）。
- **鉴定**：①AgNO₃——正磷酸盐 Ag₃PO₄ 黄色、偏/焦磷酸盐白色；②磷钼酸铵黄沉 (NH₄)₃PMo₁₂O₄₀·6H₂O（鉴定 PO₄³⁻）；③MgNH₄PO₄ 白色晶状；④偏磷酸盐使蛋白凝聚（鉴偏磷酸盐）。
- 多磷酸盐（Na₅P₃O₁₀ 三聚磷酸钠）配位 Ca²⁺/Mg²⁺/Fe²⁺ → 软水剂、锅炉水处理；格氏盐（磷酸盐玻璃体）无固定熔点、溶解大。

#### (3) 次磷酸 H₃PO₂ / 亚磷酸 H₃PO₃
- **H₃PO₂**：**一元**中强酸（K=5.9×10⁻²），只 1 个-OH，P 上连 2 个 H；强还原剂（化学镀镍）：H₃PO₂+I₂+H₂O→H₃PO₃+2HI；H₃PO₂+4Ag⁺+2H₂O→4Ag+H₃PO₄+4H⁺；易歧化。
- **H₃PO₃**：**二元**中强酸（K₁=3.7×10⁻²、K₂=2.1×10⁻⁷），2 个-OH+1 个 P—H；由 P₄O₆+6H₂O 或 PCl₃+3H₂O 制得；强还原剂（H₃PO₃+I₂→H₃PO₄+2HI；H₃PO₃+2Ag⁺+H₂O→2Ag+H₃PO₄+2H⁺）；歧化 4H₃PO₃==△==3H₃PO₄+PH₃。

#### (4) 磷的氧化物 / 卤化物 / 硫化物
- **P₄O₆（三氧化二磷）**：白磷不足空气；冷水→H₃PO₃；热水歧化→PH₃+3H₃PO₄。
- **P₄O₁₀（五氧化二磷）**：6 桥基 O+4 端基 O（端基 P=O 含 d-p π 配键）；**最强干燥剂**；与水：P₄O₁₀+2H₂O→4HPO₃、+4H₂O→2H₄P₂O₇、煮沸 HNO₃ 下→4H₃PO₄。
- **PX₃**：三角锥 sp³；水解 PCl₃+3H₂O→H₃PO₃+3HCl（浓 HCl 中也不能抑制——两种水解机理，第一步 O 端攻空 d 轨道+H 端攻孤对轨道）；醇解→亚磷酸酯；2PCl₃+O₂→2POCl₃。
- **PX₅**：气态三角双锥 sp³d；稳定性 PF₅>PCl₅>PBr₅；**固态 PCl₅=[PCl₄]⁺[PCl₆]⁻、PBr₅=[PBr₄]⁺Br⁻**（离子晶体，P 配位数可达 6=sp³d²）；水解 PCl₅+4H₂O→H₃PO₄+5HCl；少量水→POCl₃。
- **P₄S₃/P₄S₅/P₄S₇/P₄S₁₀**：以 P₄ 为骨架；P₄S₁₀ 类似 P₄O₁₀；P₄S₃ 制安全火柴。

### 4.7 砷、锑、铋

- **通性**：18 电子构型→软酸、亲硫元素（硫化物矿）；As³⁺ 极少（强酸中），Sb³⁺/Bi³⁺ 易水解为 SbO⁺/BiO⁺；多为共价型化合物。
- **冶炼**：硫化物矿煅烧→氧化物→C 还原（Sb₂S₃+9O₂→2Sb₂O₃+6SO₂；Sb₂O₃+3C→2Sb+3CO；Bi₂O₃+3C→2Bi+3CO）；也可 Fe 粉直接还原 Sb₂S₃+3Fe→2Sb+3FeS。
- **单质**：灰砷 α-As 皱褶层状、616℃ 升华；α-Sb 银白金属、α-Bi；Bi 熔点 244℃ 液态温区宽→低熔点合金（保险丝）；与 ⅢA 族成 GaAs/GaSb 等**Ⅲ-Ⅴ 族半导体**；与硝酸：As→H₃AsO₃（稀）或 H₃AsO₄（浓）；Bi 只能→Bi(NO₃)₃（惰性电子对，+3 封顶）。

#### (1) 氢化物（MH₃）
- 热稳定性：NH₃>PH₃>AsH₃>SbH₃>BiH₃（BiH₃ -45℃ 即分解）；都是强还原剂、可自燃、剧毒。
- AsH₃（胂，大蒜味）制备：Na₃As+3H₂O；As₂O₃+6Zn+12HCl→2AsH₃+6ZnCl₂+3H₂O。
- **马氏试砷法**：AsH₃==△==2As+3H₂（管壁黑亮"砷镜"）；5NaClO+2As+3H₂O→2H₃AsO₄+5NaCl（溶镜）。
- **古氏试砷法**：2AsH₃+12AgNO₃+3H₂O→As₂O₃+12HNO₃+12Ag（更灵敏）。
- 锑镜：2SbH₃→2Sb+3H₂。

#### (2) 含氧化合物
- **+3 氧化物**：As₂O₃ 两性偏酸（砒霜，致死 0.1g）、Sb₂O₃ 两性、Bi₂O₃ 碱性（只溶酸→Bi³⁺/BiO⁺）；As₂O₃ 在 3mol/L HCl 溶解度最小（稀酸中酸性、浓酸中弱碱生成 [AsCl₄]⁻）。
- H₃AsO₃ 弱酸（K₁=5.13×10⁻¹⁰）；+3 砷/锑是较强还原剂：NaH₂AsO₃+4NaOH+I₂→Na₃AsO₄+2NaI+3H₂O（**弱碱中 I₂ 定量氧化 As(Ⅲ)**）。
- **+5 氧化物**：M₂O₅ 均为酸性，酸性 As>Sb>Bi；H₃AsO₄ 三元酸（K₁=5.50×10⁻³，类磷酸）；H[Sb(OH)₆] 一元弱酸（K=4×10⁻⁵，Sb 配位数 6 八面体）；Bi₂O₅ 未分离（Bi(V) 太不稳定），但 **NaBiO₃ 已制得**（棕黄微溶）。
- **氧化还原**：As(V)/Sb(V)/Bi(V) 酸性才有氧化性：H₃AsO₄+2HI→H₃AsO₃+I₂+H₂O（分析化学用）；**Bi(V) 最强**：2Mn²⁺+5BiO₃⁻+14H⁺→2MnO₄⁻+5Bi³⁺+7H₂O（**鉴定 Mn²⁺**，溶液变紫）。Bi(V) 强氧化性=惰性电子对效应。

#### (3) 卤化物
- 水解能力：PCl₃>AsCl₃>SbCl₃>BiCl₃（随 M³⁺ 半径增大碱性增强）；AsCl₃+3H₂O→H₃AsO₃+3HCl；SbCl₃+H₂O→SbOCl↓+2HCl；BiCl₃+H₂O→BiOCl↓+2HCl；**配制 SbX₃/BiX₃ 必须溶于相应酸**。
- 五卤化物：AsF₅ 气体、SbF₅ 液体、BiF₅ 固体；AsCl₅ -50℃ 分解、SbCl₅>140℃ 分解（惰性电子对+氧化性限制 +5 卤化物稳定性）。

#### (4) 硫化物（亲硫元素，颜色-酸碱-溶解性三段式）
- 颜色：黄色 As₂S₃/As₂S₅、橙色 Sb₂S₃/Sb₂S₅、黑色 Bi₂S₃；As₄S₄ 雄黄、As₂S₃ 雌黄。
- **酸碱-溶解递变**（竞赛框架）：As₂S₃/As₂S₅ 酸性（溶 Na₂S/NaOH，不溶浓 HCl）→ Sb₂S₃ 两性、Sb₂S₅ 两性偏酸（溶 Na₂S 也溶浓 HCl）→ Bi₂S₃ 碱性（溶 4mol/L HCl 不溶碱）。
```
As₂S₃+3Na₂S→2Na₃AsS₃（硫代亚砷酸钠）
As₂S₅+3Na₂S→2Na₃AsS₄（硫代砷酸钠）
As₂S₃+6NaOH→Na₃AsO₃+Na₃AsS₃+3H₂O
As₂S₃+2Na₂S₂→As₂S₅+2Na₂S（过硫化钠氧化）
Sb₂S₃+12HCl(浓)→2H₃SbCl₆+3H₂S
Bi₂S₃+6HCl→2BiCl₃+3H₂S
```
- **硫代酸盐遇酸分解**（只在中/碱性存在）：2Na₃AsS₃+6HCl→As₂S₃↓+3H₂S+6NaCl（用此法可制较纯 As₂S₅/Sb₂S₅）。

## 七、教材例题与常见错误

### 精选例题
1. **硝酸还原产物判断**（习题15-2/15-3）：Cu+浓 HNO₃→NO₂、Cu+稀→NO、Zn+极稀→NH₄NO₃——金属活泼性与酸浓度双重影响，配平重点。
2. **PCl₅ 固态结构**（教材15.7.1）：气态三角双锥 sp³d，固态 [PCl₄]⁺[PCl₆]⁻ 离子晶体——P 配位数可达 6（N 不行，无 d 轨道）。
3. **H₃PO₂/H₃PO₃/H₃PO₄ 酸碱元数**（习题15-8(7)）：看 P 上连 -OH 数（1/2/3 个），非 H 原子总数；H₃PO₃ 中一个 H 直接连 P 不电离。
4. **PH₃ 配位悖论**（习题15-8(10)）：与过渡金属 PH₃>NH₃（反馈 π 键）、与 H⁺ NH₃>PH₃（无 d 电子反馈且 P 半径大）——两条线不矛盾。
5. **NO₂ 磁性测 Π₃⁴ vs Π₃³**（习题15-8(8)）：NO₂ 有单电子→顺磁，若 Π₃³（3 电子）则无单电子抗磁，可用磁性判断——但需排除 N₂O₄ 二聚干扰。
6. **SbCl₃/BiCl₃ 配制**（习题15-8(6)）：溶于相应酸抑制水解，稀释析出 SbOCl/BiOCl 白沉。

### 常见错误
| 错误认知 | 正确结论 |
|:--|:--|
| N 可形成 5 个共价键（如 NCl₅） | N 无 d 轨道，最高配位数 4，无双五卤化物 |
| 硝酸氧化性强弱与 HNO₂ 相同 | HNO₂ 氧化性>HNO₃（HNO₂ 不稳定易分解） |
| 王水靠 NOCl/Cl₂ 氧化 Au | 本质是 Cl⁻ 配位增强金属还原能力 |
| H₃PO₃ 是三元酸 | 二元酸（2 个-OH+1 个 P—H），H₃PO₂ 一元 |
| 磷含氧酸氧化数越高酸性越强 | (HPO₃)ₙ>H₄P₂O₇>H₃PO₂>H₃PO₃>H₃PO₄，H₃PO₂ 反超 |
| 所有硫化物都溶盐酸 | As₂S₃/As₂S₅ 酸性不溶浓 HCl；Bi₂S₃ 碱性不溶碱 |
| Bi 金属性强→Bi(V) 常见 | 惰性电子对→Bi(Ⅲ) 稳定、Bi(V) 强氧化剂（BiO₃⁻ 检 Mn²⁺） |
| PH₃ 配位能力比 NH₃ 弱（同为氢化物） | 对过渡金属 PH₃≫NH₃（反馈 π 键） |
