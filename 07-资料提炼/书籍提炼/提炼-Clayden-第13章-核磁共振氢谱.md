# Clayden 第13章：¹H NMR 核磁共振氢谱 资料提炼

---

## 一、核心概念与定义

### 1.1 [[¹H NMR]] 与 ¹³C NMR 的关键区别

| 特征 | ¹H NMR | ¹³C NMR |
|:---|:---|:---|
| 同位素丰度 | 99.985%（主要同位素）| 1.1%（次要同位素）|
| 定量性 | **定量的**：峰面积 = 质子数目 | 非定量：峰强与碳数无关 |
| 化学位移范围 | ~10 ppm | ~200 ppm |
| 偶合信息 | 质子间偶合可揭示连接方式 | ¹³C间偶合极难观测 |
| 核自旋量子数 I | 1/2（2个能级）| 1/2（2个能级）|

- **"质子 NMR"与"¹H NMR"可互换使用**：化学家常用"质子"专指氢原子核。
- ¹H NMR 是确定有机分子结构**最重要的单一技术**。

![](clayden 有机化学/Clayden中文版_211-405_images/a66bd02664f28e41783b6a236fb6da87a5f616c07e5351f7d4e90cfd5cd0f7d3.jpg)

### 1.2 化学位移 (Chemical Shift) 原理回顾

- **屏蔽与去屏蔽**：原子核周围电子在外加磁场中产生感应磁场（与外加磁场方向相反）→ 屏蔽核。
- 电子密度高 → 屏蔽强 → δ小（高场/右移）；电子密度低 → 去屏蔽 → δ大（低场/左移）。
- **参考标准**：四甲基硅烷 TMS, Si(CH₃)₄，δ = 0 ppm。硅比碳更正电性 → 甲基碳富电子 → 共振频率低于大多数有机物。
- **¹H NMR刻度仅需~10 ppm范围**（¹³C需200 ppm），因为氢核外仅有2个电子，分布可变范围远小于碳的8个价电子。

$$
\delta = \frac{\text{频率(Hz)} - \text{TMS的频率(Hz)}}{\text{TMS的频率(MHz)}}
$$

### 1.3 积分 (Integration) —— 定量分析

- **峰下面积 ∝ 质子数目**。通过计算机积分（阶梯线）测量。
- **例：醋酸 CH₃CO₂H**
  - δ 2.0 ppm：3H（甲基）
  - δ 11.2 ppm：1H（酸性OH）
  - 积分比 = 3:1，与分子式C₂H₄O₂一致
- **例：1,4-二甲氧基苯 C₈H₁₀O₂**
  - 芳香信号（δ 5–10 ppm）: 4H
  - 甲氧基信号（δ 3–4 ppm）: 6H
  - 积分比 = 2:3

![](clayden 有机化学/Clayden中文版_211-405_images/0d274b90fca1fb2c64026f612d1038e937556040103c9feebcf52bd806c7e53c.jpg)

- **溶剂峰问题**：¹H NMR通常在氘代氯仿（CDCl₃）中记录。CDCl₃中残留的CHCl₃在 δ 7.25 ppm 处产生小峰。常用氘代溶剂还有D₂O、CD₃OD、C₆D₆。

## 二、¹H NMR 化学位移详解

### 2.1 饱和碳上质子的化学位移

#### 基础规律
- **CH₃**: ~0.9 ppm（最简单的甲基）
- **CH₂**: ~1.3 ppm（比CH₃低场~0.4 ppm）
- **CH**: ~1.7 ppm（再低场~0.4 ppm）
- 每将一个H替换为C（碳电负性2.5 > 氢2.2），导致向低场位移约0.4 ppm

![](clayden 有机化学/Clayden中文版_211-405_images/db0a8d9399cc992ad8e1fcae44abf9b9b843b7875756159aa65b8f0e6dd943cc.jpg)

#### 取代基电负性效应

甲基上连接的取代基电负性越强，质子化学位移越大（去屏蔽越强）：

![](clayden 有机化学/Clayden中文版_211-405_images/cf1e3f237e67b76b65cfadd286cba7b40d7c4b26a892c3918bd36b3b7862a2fe.jpg)

**关键经验规则**：
- 普通官能团：将甲基由1.0 ppm移至~2.0 ppm
- 强吸电子基团（NO₂、OCOR、F）：将甲基移至~3.0 ppm

#### 甲基化学位移估算速查表

| 取代基类型 | 估算位移 | 示例 |
|:---|:---|:---|
| R-CH₃（纯烷基）| ~0.9 ppm | 丙烷 |
| R-C(=O)-CH₃（酮）| ~2.1 ppm | 丙酮 |
| R-O-CH₃（醚/酯）| ~3.3–4.0 ppm | 甲醇 |
| R-NO₂-CH₃（硝基）| ~3.4–4.3 ppm | 硝基甲烷 |
| R-NH₂-CH₃（胺）| ~2.2–2.4 ppm | 甲胺 |
| R-C(=O)O-CH₃（甲酯）| ~3.6–3.7 ppm | 乙酸甲酯 |

#### 甲基的结构信息价值
- **绕σ键快速旋转**：使同一CH₃上三个H等价，同一C(CH₃)₃上三个甲基等价 → 时间平均化
- **绕C=C双键不旋转**：双键两端的甲基不等价（顺/反异构）
- **绕酰胺N-CO键旋转受阻**：DMF中N上的两个甲基不等价（δ 2.89和2.98 ppm）
- **笼式结构**：阻碍旋转，使CH₂上的两个H不等价（如桃金娘醛，δ 0.74和1.33 ppm）

![](clayden 有机化学/Clayden中文版_211-405_images/7c41520fe92cc0965ee7cdb335d63ae42fe94ec1d582b66f71a9c24ae70865f6.jpg)

### 2.2 估算化学位移的系统方法

**基础值**：CH₃ = 0.9 ppm；CH₂ = 1.3 ppm；CH = 1.7 ppm

**取代基增量（可累加）**：

| 取代基 | 增量 (ppm) | 说明 |
|:---|:---|:---|
| 普通官能团（C=O、苯基等）| +1.0 | |
| 氧、卤素 | +2.0 | |
| 强吸电子基（NO₂、OCOR、F）| +3.0 | |

![](clayden 有机化学/Clayden中文版_211-405_images/fa2ece335dba43c8fada1fce1f01b5be7289aba2e7a272e8ec3816ee2b3959b7.jpg)

**应用示例：酮酯**
- CH₃-CO-：估算 0.9 + 1.0 = ~1.9 ppm（实测2.14 ppm）
- CH₃-O-：估算 0.9 + 3.0 = ~3.9 ppm（实测3.61 ppm）
- -CH₂-CO-O-：估算 1.3 + 1.0 + 1.0 = ~3.3 ppm（与实测吻合）

![](clayden 有机化学/Clayden中文版_211-405_images/16eaef34a4890a5563796aade3ce0e1b30e923fb24af74e42feb2ce2e92d03f5.jpg)

### 2.3 ¹H NMR 化学位移区域划分（详细版）

![](clayden 有机化学/Clayden中文版_211-405_images/fefe8728b5876fb8d824593cdbe4900ce2b24a7d242242f1453d1b0b8beb3ede.jpg)

| 化学位移 (ppm) | 质子类型 | 说明 |
|:---|:---|:---|
| 0–1.0 | R-CH₃ | 烷基甲基，最高场 |
| 1.0–2.0 | R-CH₂-R, R-CH-R | 亚甲基、次甲基 |
| 1.5–2.5 | C=C-CH（烯丙位）| 去屏蔽 |
| 2.0–2.5 | C=O-CH（羰基α位）| |
| 3.3–4.0 | C-O-H（连氧碳上H）| 被去屏蔽 |
| 2.2–3.0 | C-N-H（连氮碳上H）| |
| 4.5–6.5 | C=C-H（烯烃）| 不饱和区 |
| 6.5–8.0 | Ar-H（芳烃）| 芳香区 |
| 9–10 | CHO（醛基）| 最低场 |
| 10–12 | CO₂H（羧酸）| |
| 变化大 | OH, NH, SH | 受交换影响 |

### 2.4 烯烃区域与苯区域的区分

烯烃和苯的碳在¹³C NMR中信号几乎相同（1.3 ppm差异，<200 ppm尺度的1%），但在¹H NMR中信号非常不同（1.6 ppm差异 = 10 ppm尺度的16%）。

**苯环的环电流效应 (Ring Current Effect)**：
- 苯是芳香的 → 6个π电子围绕整个环离域
- 外磁场在离域电子中建立环电流
- 环电流产生定域磁场：**环内部与外加磁场相反（屏蔽），环外部加强外加磁场（去屏蔽）**
- 碳在环本身，不受影响；**环外的氢感受到更强的有效磁场 → 大的去屏蔽 → 较大的δ**

![](clayden 有机化学/Clayden中文版_211-405_images/ee439a28770027e3e6a73fa498afe067b1203fe88d3dbf22dc62e8f66f976292.jpg)

**环蕃与轮烯的验证**：
- [7]-对环蕃：苯环上H在7.07 ppm（去屏蔽），桥链中间CH₂在**-0.6 ppm**（被环电流屏蔽到负值！）
- [18]-轮烯（18个π电子，芳香）：环外H在9.28 ppm（强去屏蔽），**环内H在-2.9 ppm**（强屏蔽）

![](clayden 有机化学/Clayden中文版_211-405_images/81fb5e8e21b0e70d7db1d294adb6a53e810858258dbb199f9ecd1a7bd48dd5a6.jpg)

### 2.5 芳环取代基效应

#### 吸电子基团（通过共轭）
位移增大（去屏蔽增强）：**NO₂ > C=O > CN > CF₃**

![](clayden 有机化学/Clayden中文版_211-405_images/30705e0e57701e64ae788e70bbdef3f82d152af0412af85dec5744d3c879329e.jpg)

#### 给电子基团
- **烷基**：弱诱导给体，影响较小
- **-NH₂, -OH, -OR**：孤对电子通过共轭给电子到环上 → **环上H被屏蔽**（δ减小）；但N原子本身变得正电性 → N上的甲基去屏蔽
- 卤素：诱导吸电子 vs 孤对电子共轭给电子，几乎平衡

![](clayden 有机化学/Clayden中文版_211-405_images/0e3de956a9193f8ee89277b28789642f925a4c4b84ac23720f94ff1529191069.jpg)

### 2.6 富电子与缺电子烯烃

- **吸电子基团**（如-CO-）：从双键移去电子 → β位H去屏蔽（δ增大）
- **给电子基团**（如-OR）：共轭给电子到双键 → β位H被屏蔽（δ减小），同时诱导效应使α位H去屏蔽

**实例对比**：
- 硝基烯烃（缺电子）：β位H极度去屏蔽
- 烯胺（富电子）：β位H被屏蔽
- 两者相同位置质子位移差近3 ppm！

![](clayden 有机化学/Clayden中文版_211-405_images/59062bd980faf8e7d8e7c7fe70cb580dfe64bf122170fd8d5896dec8328ef8a9.jpg)

### 2.7 醛基质子与吡啶

- **醛基H**：直接连在最吸电子的C=O上 → 在9–10 ppm区域共振（CH质子中最大位移）
- DMF的CHO：因酰胺离域提供额外屏蔽，比普通醛去屏蔽少
- **吡啶**：C2-H在~8.5 ppm（类似醛，与杂原子相连的sp²碳上H）；C4-H因共轭缺电子而低场

![](clayden 有机化学/Clayden中文版_211-405_images/795001b1ae2ca8af9a200076ca31d62b2a21d3f3593c88a4579a67ed4dd0ee81.jpg)

### 2.8 杂原子上质子的化学位移

#### OH质子位移与酸性的关系
- 酸性越强 → O-H键越极化 → 越接近裸露H⁺（无屏蔽电子）→ δ越大
- 醇OH：~2 ppm；酚OH：~5 ppm；羧酸OH：~11 ppm

![](clayden 有机化学/Clayden中文版_211-405_images/e77becb73ef122ee90c3d1518f26b12781137e15438148209fca1b5c69f190a8.jpg)

#### NH质子位移总结

| NH类型 | δ (ppm) | 说明 |
|:---|:---|:---|
| R-NH₂（脂肪胺）| 0.5–3 | 变化大 |
| Ar-NH₂（芳香胺）| 3–5 | |
| R-CONH₂（酰胺）| 5–8 | 酸性，低场 |
| 吡咯NH | ~10 | 芳香性使NH有酸性 |

![](clayden 有机化学/Clayden中文版_211-405_images/c7aaff97a86232c75a99888c1989851dd8d9f824138e4ef8ade1124897aba466.jpg)

#### 杂原子间的快速质子交换
- O-H、N-H、S-H质子之间的交换**极其快速**
- 在D₂O中：所有可交换H被D取代 → 形成HOD（δ ~4.8 ppm）
- 在CDCl₃中：OH和NH峰通常比CH峰**更宽**（因痕量水的交换）
- EDTA的二盐：快速交换使所有CH₂CO基等价，所有可交换H给出相同δ

**重要原理**：
> 杂原子（尤其是O、N和S）之间的质子交换与其他化学反应相比是非常快速的过程，通常导致¹H NMR光谱中平均化的峰。

![](clayden 有机化学/Clayden中文版_211-405_images/917ccb2618b6ba955f2bbee51f16e46bbe5a904cf877fa08170d5b1b1a1064e0.jpg)

## 三、偶合常数 (Coupling Constant, J)

### 3.1 偶合的本质

- **邻近质子间的磁相互作用** → 使信号裂分为多重峰
- **偶合是一种沿键效应 (through-bond effect)**，不是沿空间效应
- 两个相互偶合的质子的多重峰具有**相同的J值**

### 3.2 偶合的三种理解方式

**方式1：磁场叠加**
- HA感受到两个略有不同的磁场：B₀ + HX的磁场 和 B₀ - HX的磁场 → 两个共振频率 → 双重峰

![](clayden 有机化学/Clayden中文版_211-405_images/1c0b6cd6bea1b3c08d5fe755c22f8f835330618f9e91b95f68316588beeff5ab.jpg)

**方式2：能级分裂**
- 单个核：2个能级 → 1个跃迁 → 1条线
- 两个相互作用的核：4个能级 → HA有2个略有不同的跃迁 → 2条线

![](clayden 有机化学/Clayden中文版_211-405_images/33793bf14ae2cf44a47f9bc29c1e495c971d219a856427cb7517ca805eef48cc.jpg)

**方式3：逐步裂分**
- HA被HX裂分为双重峰 → 每条线再被其他邻居进一步裂分

### 3.3 n+1规则与杨辉三角 (Pascal's Triangle)

**n+1规则**：n个等价邻近氢将目标信号裂分为 **n+1** 个峰，强度符合杨辉三角。

| 等价邻近H数(n) | 峰数(n+1) | 强度模式 | 名称 |
|:---|:---|:---|:---|
| 0 | 1 | 1 | 单重峰 (s) |
| 1 | 2 | 1:1 | 双重峰 (d) |
| 2 | 3 | 1:2:1 | 三重峰 (t) |
| 3 | 4 | 1:3:3:1 | 四重峰 (q) |
| 4 | 5 | 1:4:6:4:1 | 五重峰 |
| 5 | 6 | 1:5:10:10:5:1 | 六重峰 |
| 6 | 7 | 1:6:15:20:15:6:1 | 七重峰 |

![](clayden 有机化学/Clayden中文版_211-405_images/7e0473e89a1241085bb0791f10ec6c49d9f01639cb6f9fd022539402b7520e04.jpg)

**经典示例**：
- **乙基 CH₃CH₂X**：CH₂（2H）被3个CH₃-H裂分为四重峰；CH₃（3H）被2个CH₂-H裂分为三重峰
- **异丙基 (CH₃)₂CHX**：CH₃（6H）被1个CH-H裂分为双重峰；CH（1H）被6个CH₃-H裂分为七重峰

### 3.4 信号描述规范

信号的完整描述格式：**δH 化学位移 (积分数, 峰形, J值, 归属)**

例如：δH 7.5 (1H, d, J 4 Hz, HA) 和 5.8 (1H, d, J 4 Hz, HX)

| 缩写 | 含义 | 说明 |
|:---|:---|:---|
| s | 单重峰 (singlet) | |
| d | 双重峰 (doublet) | 两条等高线 |
| t | 三重峰 (triplet) | 1:2:1 |
| q | 四重峰 (quartet) | 1:3:3:1 |
| dt | 双重三重峰 | 其他组合：dd, dq, tt等 |
| m | 多重峰 (multiplet) | 复杂或重叠的信号 |

### 3.5 不同偶合常数的裂分——双重双重峰 (dd)

当一个质子与两个**不同的**邻近氢偶合（J值不同）时，产生双重双重峰（dd）：

- 首先被一个邻居裂分为双重峰（间隔=大J）
- 然后每条线再被另一个邻居裂分（间隔=小J）
- 结果：四条等强的线

**菊酸示例**：HA被HX（J=8 Hz）和HM（J=5.5 Hz）裂分为dd

![](clayden 有机化学/Clayden中文版_211-405_images/08f63b79771849ffd1b1559b66e6d8133d94e39662b78e2ba4530e9182a452da.jpg)

### 3.6 偶合常数的影响因素

#### 三个关键因素

| 因素 | 影响 | 说明 |
|:---|:---|:---|
| 沿键距离 | 键越短 → J越大 | 双键（~1.34Å）比单键（~1.54Å）短 → J更大 |
| C-H键间角度 | 角度越大 → J越大 | Karplus关系：180° > 60° > 0° |
| 电负性取代基 | 电负性↑ → J↓ | 吸电子弱化了经由C-H键的交流 |

#### 偶合类型与典型J值速查表

| 偶合类型 | 符号 | 键数 | 典型J值 (Hz) |
|:---|:---|:---|:---|
| **偕偶** (geminal) | ²J | 2根键 | 饱和：10–16；不饱和：0–3 |
| **邻偶** (vicinal, 饱和) | ³J | 3根键 | 6–8（自由旋转平均） |
| **邻偶** (烯烃, 顺式) | ³J | 3根键 | 10–12 |
| **邻偶** (烯烃, 反式) | ³J | 3根键 | 14–18 |
| **邻偶** (芳香) | ³J | 3根键 | 6–10 |
| **长程偶合** (间位) | ⁴J | 4根键 | 1–3 |
| **长程偶合** (烯丙型) | ⁴J | 4根键 | 1–3 |

![](clayden 有机化学/Clayden中文版_211-405_images/2a8c79bfa59114cdb3a81a1f4472f057d64e39f4a15667b1a8af3bfb2374f067.jpg)

### 3.7 偶合常数与构型/构象的关系

#### 烯烃构型判断
- **顺式烯烃**: J ≈ 10–12 Hz
- **反式烯烃**: J ≈ 14–18 Hz
- 反式偶合 > 顺式偶合，因为反式C-H键更平行 → 更好的沿键交流

**氯代酸实例**：
- 顺式氯代丙烯酸：J = 10 Hz
- 反式氯代丙烯酸：J = 15 Hz

![](clayden 有机化学/Clayden中文版_211-405_images/3d93d007682d1cd82ec7bdbfd12ebfebe234fba9fc9e030430571ad5fd598067.jpg)

#### 烯丙型偶合与W-偶合
- 四键偶合（⁴J）通常观察不到
- **例外**：当轨道排列成"W"形时可观察到，称为**W-偶合**
- 芳环间位偶合和烯烃烯丙型偶合均属此类
- J值通常很小：1–3 Hz

![](clayden 有机化学/Clayden中文版_211-405_images/5551e55a30c5c8cbf335c849c09996e3d73691d4a0578d901c83f360346d99ab.jpg)

### 3.8 偕偶 (Geminal Coupling)

- 同一碳上两个**不等价**氢之间的偶合（²J）
- **不饱和体系**（双键上CH₂）：J很小（0–3 Hz）
- **饱和体系**（如桃金娘醛的桥CH₂）：J较大（10–16 Hz）
- 只有当CH₂上的两个氢不同时才可观测

![](clayden 有机化学/Clayden中文版_211-405_images/4b69e4282c6c16eb03b3966ab69198802461e06e4a79b2bd801779fbc13b2fce4.jpg)

### 3.9 单取代烯烃（乙烯基）的特征偶合

三个不等价的乙烯基质子形成特征性的裂分模式：
- **反式偶合** (J ≈ 16 Hz)：最大
- **顺式偶合** (J ≈ 10 Hz)：中等
- **偕偶** (J ≈ 4 Hz)：最小

**丙烯酸乙酯示例**：红色H（5.60 ppm, dd, J=16, 4 Hz），绿色H（6.40 ppm, dd, J=10, 4 Hz），橙色H（6.11 ppm, dd, J=16, 10 Hz）

![](clayden 有机化学/Clayden中文版_211-405_images/19a9875b7207e687dea85d6c1a65df6816ce2ca1f3667b740134a9e9117f46ac.jpg)

### 3.10 电负性对偶合常数的影响

电负性取代基从C-H键上吸电子 → 弱化了经由该键的交流 → J减小

**对比**：
- 普通烯烃反式J = 17 Hz
- 烯醇醚反式J = 13 Hz（氧的电负性降低了J）

![](clayden 有机化学/Clayden中文版_211-405_images/79398e13e02b8988330d4d7acaf6ac68111e290d90055dbf5d0434fac52cadaf.jpg)

## 四、相似质子间的偶合——AB体系

### 4.1 从AX到A₂的渐变

- **AX体系**：Δδ >> J → 两个标准的1:1双重峰
- **AB体系**：Δδ ≈ J → 双重峰畸变（内线增强，外线减弱）
- **A₂体系**：Δδ = 0 → 单一单重峰

**关键参数**：Δδ（两个质子化学位移差）与J（偶合常数）的比值

| Δδ/J | 体系类型 | 峰形 |
|:---|:---|:---|
| >> 1 | AX | 标准双重峰 |
| ≈ 1 | AB | 畸变双重峰（"带屋顶"）|
| = 0 | A₂ | 单重峰 |

![](clayden 有机化学/Clayden中文版_211-405_images/31accf6c2bd1cae2ec8549f0f6f4682a4c0dde20e847c264068a2f56aa18a4a5.jpg)

### 4.2 AB体系的特征

- **"带屋顶"效应**：畸变的双重峰总是"指向"与它偶合的质子方向
- **实用技巧**：内线比外线高 → 这是AB体系的标志
- **注意**：不要将AB体系误称为"AB四重峰"——四重峰是与3个等价H偶合的1:3:3:1模式

![](clayden 有机化学/Clayden中文版_211-405_images/dc36842b91ca025334728429378128fa49add8a865da36284f3f2f76ade8594d.jpg)

### 4.3 仪器频率的影响

- 化学位移δ（ppm）在不同仪器上**保持不变**
- 偶合常数J（Hz）在不同仪器上**保持不变**
- 但在ppm尺度上，J的"外观"随仪器频率改变：90 MHz上1 ppm = 90 Hz；300 MHz上1 ppm = 300 Hz
- **高场仪器**（如500 MHz）可更好地区分化学位移相近的质子

![](clayden 有机化学/Clayden中文版_211-405_images/7d2b8822eb7f547f76990bf8f267649b2a06abcb3f6db99c638ac1d20d97689a.jpg)

## 五、复杂NMR谱解析策略

### 5.1 解析的一般步骤

1. **计算不饱和度（DBE）**：从分子式判断环/双键/三键数目
2. **观察积分**：确定各类质子的数目比
3. **识别溶剂峰和杂质峰**：CDCl₃在7.25 ppm，H₂O在~1.5 ppm（CDCl₃中）
4. **识别特征区域信号**：
   - 9–10 ppm → 醛基H
   - 6.5–8.5 ppm → 芳香H或烯烃H
   - 3–4 ppm → 与O相连的C上H
   - 0.9–2.5 ppm → 烷基H
5. **分析裂分模式**：用n+1规则和偶合常数确定邻接关系
6. **匹配化学位移与预期值**：利用增量法验证

### 5.2 2-庚酮的完整解析示例

- 绿色H（C1-H₂）：δ 2.4 ppm, 2H, t, J=7 Hz → 与两个红色H偶合
- 红色H（C3-H₂）：δ 2.1 ppm, 2H, 五重峰, J=7 Hz → 与相邻4个H偶合
- 棕色H（C4-H₂, C5-H₂）：δ 1.6 ppm, 4H, 多重峰 → 重叠
- 橙色H（C7-H₃）：δ 0.9 ppm, 3H, t, J=7 Hz → 末端甲基

![](clayden 有机化学/Clayden中文版_211-405_images/1d8880cb6c0a4a19a2107d6c8ef47be0546bb030659b097d6f80ad2773afb85a.jpg)

### 5.3 ABX体系的解析

ABX体系是常见的复杂裂分模式：
- **AB部分**：两个化学位移相近的质子相互偶合（大J），形成畸变的双重峰对
- **X部分**：远处的质子与AB之一偶合
- 解析关键是先识别AB部分（畸变双重峰对，相同的大J值），再找出X

## 九、竞赛题型线索

### 9.1 化学位移归属型
- 利用增量法估算化学位移，验证结构假设
- 利用环电流效应区分芳烃和烯烃质子
- 利用OH化学位移判断酸性强弱（醇 vs 酚 vs 羧酸）
- 利用醛基H的特征位移（9–10 ppm）快速识别醛

### 9.2 偶合分析型
- 由n+1规则反推邻近氢的数目
- 由J值判断烯烃构型（顺式~10 Hz vs 反式~16 Hz）
- 由偕偶判断CH₂上两个H是否等价（可旋转 vs 受阻）
- 由长程偶合（W-偶合）判断空间排列

### 9.3 积分定量型
- 由积分比确定各类质子的数目
- 结合分子式和积分确定结构片段
- 注意：积分是面积而非高度（宽峰可能高度低但面积大）

### 9.4 动态NMR与交换型
- 判断OH/NH质子是否发生快速交换
- 利用D₂O交换实验确认可交换H（峰消失）
- 变温NMR观察构象翻转速率（慢交换 → 两组峰；快交换 → 一组平均峰）

### 9.5 综合波谱解析型
- ¹H NMR + ¹³C NMR + IR + MS联合鉴定
- 利用偶合网络构建分子骨架
- 利用化学位移区域缩小可能的官能团范围
- 利用积分确定各片段的比例

## 十、存疑或待验证之处

1. **¹H NMR刻度范围的解释**：文中说"氢原子核周围只有两个电子"，更准确地说是¹H核外总共只有2个电子（1s²），而¹³C有6个价电子。化学位移范围的差异根本上源于屏蔽电子数目的差异。

2. **CH₂和CH比CH₃化学位移高约0.4 ppm的解释**：文中归因于碳的电负性（C 2.5 > H 2.2），但更完整的解释还需考虑杂化效应和各向异性效应。

3. **吡啶C2-H在醛区域的原因**：文中说"因为氮比碳的电负性更大"，但更准确地说是C2同时受到氮的诱导吸电子和环电流去屏蔽的双重效应。

4. **D₂O中OH/NH峰消失的机制**：不仅是D取代H，还涉及快速化学交换使H从溶剂D₂O中获取D。在极纯的干燥样品中，OH峰可能可观测。

5. **AB体系的"屋顶效应"**：文中强调不要称为"AB四重峰"，这是正确的。AB体系的四条线间距不等（内线间距 < 外线间距），与真正四重峰的等间距有本质区别。

6. **偶合常数的"沿键"性质**：文中用顺/反式偶合的差异证明偶合是沿键而非沿空间的。但需注意，某些特殊情况（如氢键桥连）中确实存在通过空间的偶合（through-space coupling），只是非常罕见。

7. **增量法的局限性**：文中承认这种估算"不可避免是过度简化的"，实际化学位移还受各向异性效应、氢键、溶剂效应等因素影响，竞赛中遇到偏差较大的情况需考虑这些因素。
