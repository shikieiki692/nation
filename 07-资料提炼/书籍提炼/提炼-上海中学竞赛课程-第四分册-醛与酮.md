# 提炼-上海中学竞赛课程-第四分册-醛与酮

## 内容概要

本讲以羰基的结构特征为起点，系统展开醛、酮的化学。结构部分说明羰基碳为 $sp^{2}$ 杂化、羰基为极性基团，并揭示 $\alpha-H$ 的酸性（$\mathrm{p}K_a \approx 20$）与烯醇式互变异构，由此引出「碳负离子—烯醇式」两条产生碳负离子的路径（碱性条件生成碳负离子后转烯醇式稳定；酸性条件先生成烯醇式再转碳负离子）。反应部分依次讨论：亲核加成（含碳/氮/氧/硫四类亲核试剂，含克拉姆规则与烯胺化学）、$\alpha,\beta$-不饱和醛酮的 3,4-/1,2-/1,4-加成（Michael 加成）、$\alpha-H$ 的卤代与羟醛缩合、羰基的两类还原（还原为羟基 5 法、还原为亚甲基 3 法）、醛与酮的氧化（含 Baeyer-Villiger 反应），以及法沃尔斯基重排、二苯乙醇酸重排、康尼扎罗反应、维蒂希反应等其他重要反应。

## 核心知识点

### 1. 羰基的结构与反应活性
- 羰基碳 $sp^{2}$ 杂化，与氧形成 $\sigma + \pi$ 双键；羰基为极性基团，碳端带部分正电荷，易受亲核试剂进攻
- 亲核加成后碳由 $sp^{2}$ 转为 $sp^{3}$，平面结构转变为四面体结构 → **空间效应**显著影响加成
- 碳上连吸电子基团 → 碳正电性提高 → 有利于亲核加成
- **亲核加成活性顺序**：$\mathrm{HCHO > RCHO > RCOR'}$
- $\alpha-H$ 酸性 $\mathrm{p}K_a \approx 20$；烯醇式/酮式互变异构可逆；$\alpha-C$ 为手性碳时可经互变异构**外消旋化**
- 碳负离子生成路径：**碱**夺 $\alpha-H$ → 负电荷共振转移到氧（烯醇式负离子），遇正电中心时氧上负电荷回形成 $\mathrm{C=O}$，碳负离子复现参与反应；**酸**先质子化羰基 → 生成烯醇式 → 再转碳负离子

### 2. 醛、酮的物理性质
- 醛酮分子间不能形成氢键，沸点低于相对分子质量相近的羧酸和醇；但羰基极性增强分子间吸引力，沸点**高于**同碳数的烃和醚
- 常温下甲醛为气体（沸点 $-19.5^{\circ}\mathrm{C}$），其余醛、酮为液体或固体
- 低级醛酮（甲醛、乙醛、丙醛、丙酮）与水混溶（羰基氧与水形成氢键），随相对分子质量增大溶解度下降
- 脂肪族醛酮相对密度 < 1，芳香族醛酮 > 1

### 3. 亲核加成反应

#### 3.1 立体化学——克拉姆（Cram）规则
- 亲核试剂可从羰基平面两侧进攻，生成一对对映体；若 $\alpha-C$ 上连有体积不同的三个基团（L 大、M 中、S 小），两侧空间阻碍不同 → 具有空间选择性
- 构象取 **R(H) 与 L 重叠式**，原因是亲核试剂带正电部分（如金属）与羰基氧络合使氧端位阻增大，故 $\alpha-C$ 上最大基团 L 应与羰基**反式**
- **克拉姆规则**：亲核试剂主要从体积较小的基团 S 一侧进攻羰基
- 适用范围：$\alpha-C$ 为手性碳的醛、酮与**含碳、氧、硫**亲核试剂的加成

#### 3.2 含碳亲核试剂
- **有机金属化合物**（$\mathrm{RMgX}$、$\mathrm{RLi}$、$\mathrm{CH{\equiv}CNa}$）：强亲核试剂，加成后水解得醇，是制备醇的重要方法；酮两侧烃基体积太大时反应困难，改用有机锂试剂
- **氰化氢**：与弱亲核试剂 HCN 加成得 $\alpha$-羟基腈；反应可逆，加少量碱可迅速建立平衡；产物在**酸中稳定**、碱中会分解回醛酮与 HCN（蒸馏前必须除碱）
- $\alpha$-羟基腈水解成 $\alpha$-羟基酸，进一步失水生成 $\alpha,\beta$-不饱和酸

#### 3.3 含氮亲核试剂
| 试剂 | 产物 | 要点 |
|---|---|---|
| $\mathrm{NH_3}$ / $1^{\circ}$ 胺 | 亚胺 | 加成产物不稳定，需不断移去水；稀酸加热可水解回醛酮（保护羰基法之一）；脂肪族亚胺不稳定，一般不用氨制备 |
| $\mathrm{HCHO + NH_3}$ | 六亚甲基四胺（乌洛托品） | 熔点 260 ℃，用于合成树脂与炸药 |
| $2^{\circ}$ 胺 | 烯胺 | 氮上无氢，脱水时只能脱邻碳上的氢 → 生成烯胺 |
| $\mathrm{H_2N{-}X}$ | 腙 / 苯腙 / 缩胺脲 | X = $\mathrm{NH_2}$、$\mathrm{NHC_6H_5}$、$\mathrm{NHCONH_2}$；产物多为棕黄色固体，易结晶、有固定熔点 → **鉴别醛酮** |
| 2,4-二硝基苯肼 | 2,4-二硝基苯腙 | 相对分子质量大、熔点高、易析出，鉴别最灵敏，称**羰基试剂** |
| $\mathrm{NH_2OH}$ | 肟 | 有 Z、E 异构体，一般 E 型较稳定 |

- **烯胺化学**：烯胺经共振可在羰基 $\alpha-C$ 上产生碳负离子 → 作为亲核试剂与卤代烃发生 $\mathrm{S_N2}$ 烷基化，再酸性水解得 $\alpha$-烷基化的酮
- 烯胺的碳碳双键位置：$\alpha-C$ 上连**吸电子基**时，双键生成在羰基碳与该 $\alpha-C$ 之间（负电荷被稳定）；连**推电子基**（烃基）时，因立体位阻使有取代基的 $\alpha-C$ 不共轭、无取代基的易共轭 → 碳负离子主要生成在**无取代基**的 $\alpha-C$ 上
- **贝克曼（Beckmann）重排**：酸性条件下肟的羟基与**反式**位置基团对调形成烯醇式，再转酮式生成酰胺；工业上环己酮肟重排为己内酰胺，开环聚合得尼龙-6

#### 3.4 含氧亲核试剂
- 与水在酸性条件下加成；平衡一般利于反应物，但高活性醛（甲醛、三氯乙醛）利于生成物
- 与醇在酸（HCl、对甲苯磺酸）催化下加成得**半缩醛（酮）**，进一步得**缩醛（酮）**：可用于保护羰基；平衡右移需移去水；半缩醛一般不稳定，缩醛在稀酸中加热可水解回醛酮
- 空间阻碍大的酮难反应，改用高活性试剂**原甲酸三乙酯** $\mathrm{HC(OC_2H_5)_3}$

#### 3.5 含硫亲核试剂
- 与饱和 $\mathrm{NaHSO_3}$ 溶液加成，产物可沉淀析出；适用于**醛、甲基酮、≤8 个碳的环酮**（其他酮位阻大难加成）；加 HCl 或 $\mathrm{Na_2CO_3}$ 又可分解回醛酮
- 硫醇亲核性比醇强，加成生成**缩硫醛（酮）**，可在雷尼镍催化下加氢把原羰基还原为亚甲基

### 4. $\alpha,\beta$-不饱和醛酮的反应
以 $-\mathrm{C{=}C{-}C{=}O}$ 为例，可发生 **1,2-加成**（碳氧双键亲核加成）、**3,4-加成**（碳碳双键亲电加成）、**1,4-加成**（共轭加成）
- **3,4-加成**：与卤素、次卤酸加成，及室温催化氢化
- **1,2-加成**：小的、强的亲核试剂（甲基格氏试剂、甲基锂）进攻时为主；$\alpha,\beta$-不饱和**醛**因羰基旁氢位阻小，与烃基锂、格氏试剂反应亦以 1,2-加成为主
- **1,4-共轭加成**：$\mathrm{NH_3}$ 及其衍生物、HX、$\mathrm{H_2SO_4}$、HCN 等质子酸、$\mathrm{H_2O}$ 或 ROH（酸催化）为主；格氏试剂在**亲核试剂较大或羰基旁基团较大**时为主；**二烃基铜锂**体积大，主要 1,4-加成
- **迈克尔（Michael）加成**：能形成亲核碳负离子的试剂与 $\alpha,\beta$-不饱和醛酮、酯、腈、硝基化合物在碱性条件下发生 1,4-共轭加成
  - 常用碱：三乙胺、氢氧化钠、乙醇钠、氨基钠
  - 不对称酮：加成主要发生在**多取代**的 $\alpha-C$ 上（强碱下生成热力学控制的烯醇式负离子，多取代更稳定）

### 5. $\alpha-H$ 的反应

#### 5.1 卤代
- 酸或碱催化下 $\alpha-H$ 被卤素取代；反应一旦开始即产生酸 → **自催化**
- **酸催化**：取代基越多的 $\alpha-C$ 上氢越易卤代（超共轭效应大，烯醇更稳定）；卤原子吸电子使羰基氧电子云降低、质子化变难 → **可控在一卤代**
- **碱催化**：取代基越少的 $\alpha-C$ 上氢越易卤代（酸性强）；卤原子吸电子使同碳氢酸性更强 → 反应持续至该 $\alpha-C$ 上氢**全部取代**；碱除催化外还需中和生成的酸，用量须超过醛酮
- **卤仿反应**：甲基酮类甲基上氢全被卤代后，三卤甲基强吸电子使羰基碳易受碱进攻、碳碳键断裂生成卤仿：
  $$\mathrm{RCOCH_3 + 3X_2 + 4NaOH \longrightarrow RCOONa + CHX_3 + 3NaX + 3H_2O}$$
  凡能**被次卤酸氧化成甲基酮**的化合物（如 $\mathrm{CH_3CH_2OH}$）也能发生卤仿反应；碘仿为不溶于碱液的**黄色沉淀** → 用于鉴别

#### 5.2 羟醛缩合
- 有 $\alpha-H$ 的醛酮在稀碱液中缩合生成 $\beta$-羟基醛酮；酸、碱条件下均可进行
- $\beta$-羟基醛酮在酸或碱中加热脱水生成 $\alpha,\beta$-不饱和醛酮（双键与羰基共轭，比一般醇更易脱水）
- 酮也可缩合，但平衡偏向反应物，产率较低
- **分子内羟醛缩合**：二羰基化合物在稀碱中分子内缩合，因熵增有利而产率高于分子间缩合；有多种成环选择时优先成较稳定的**五、六元环**
- **交叉羟醛缩合**：两种不同醛得 4 种产物，合成意义不大；若一种醛有 $\alpha-H$、另一种无（甲醛、苯甲醛），可得**单一产物**且产率较高。醛与酮也可交叉缩合
- 不对称酮：**碱催化**缩合优先发生在取代**较少**的 $\alpha-C$，**酸催化**发生在取代**较多**的 $\alpha-C$

### 6. 还原反应

#### 6.1 羰基还原为羟基（5 法）
| 方法 | 试剂/条件 | 要点 |
|---|---|---|
| 催化加氢 | $\mathrm{H_2/Ni}$、$\mathrm{Pt}$ | $\alpha,\beta$-不饱和醛酮通常**先还原碳碳双键**，再还原羰基 |
| 氢化物还原 | $\mathrm{LiAlH_4}$（醚中）、$\mathrm{NaBH_4}$（醇中） | 负氢进攻羰基碳；$\mathrm{LiAlH_4}$ 可还原醛酮、羧酸及其衍生物，$\mathrm{NaBH_4}$ 只还原醛酮和酰卤、**不还原酯基** |
| 乙硼烷 | $\mathrm{B_2H_6}$ | $\alpha,\beta$-不饱和醛酮**先还原羰基**，再还原碳碳双键（与催化加氢顺序相反） |
| 麦尔外因-彭杜尔夫 | 异丙醇铝 | 沃氏氧化的逆反应 |
| 双分子还原 | Mg-Hg 等 | 偶联成频哪醇 |

#### 6.2 羰基还原为亚甲基（3 法）
- **克莱门森还原**：$\mathrm{Zn{-}Hg}$ + 浓盐酸回流
- **沃尔夫-基希涅尔-黄鸣龙还原**：$\mathrm{H_2NNH_2}$ + KOH，在一缩二乙二醇中加热
- **缩硫醇氢解**：羰基 + 硫醇生成缩硫醛（酮），再经雷尼镍催化氢解 —— **中性条件**下还原羰基为亚甲基的方法

### 7. 氧化反应
- **醛的氧化**：空气中即可被氧化；强氧化剂 $\mathrm{KMnO_4}$、$\mathrm{K_2Cr_2O_7}$、溴水均能把醛氧化成酸
  - 弱氧化剂（检验醛基）：**银氨溶液**、**斐林试剂**（$\mathrm{CuSO_4}$ + NaOH + 酒石酸钾钠）、**班氏试剂**（$\mathrm{CuSO_4}$ + NaOH + 柠檬酸钠）；后两者**不能氧化芳香醛**
- **酮的氧化**：酮一般不易氧化；酸性 $\mathrm{KMnO_4}$ 加热使羰基与 $\alpha-C$ 间碳碳键断裂生成酸（一般酮产物为多种羧酸混合物，意义不大）
- **贝耶尔-维林格（Baeyer-Villiger）反应**：酮与过氧酸作用，在羰基与旁边烃基间插入一个氧形成酯
  - 基团迁移能力顺序：$3^{\circ} > 2^{\circ} > 1^{\circ}$；迁移碳原子若有手性则**手性保持不变**

### 8. 其他反应
- **法沃尔斯基（Favorskii）重排**：$\alpha$-卤代酮在醇钠、NaOH、氨基钠作用下失去卤原子，重排成相同碳数的羧酸酯、羧酸或酰胺；**环状 $\alpha$-卤代酮**在醇钠作用下发生**缩环**，生成少一个环碳原子的环烷甲酸酯
- **二苯乙醇酸重排**：二苯乙二酮在约 70% NaOH 中加热重排成二苯乙醇酸
- **康尼扎罗（Cannizzaro）反应**：**无 $\alpha-H$** 的醛在浓碱中歧化，一分子被氧化成酸、另一分子被还原成醇
  $$2\mathrm{PhCHO} \xrightarrow{\mathrm{OH^-}} \mathrm{PhCH_2OH} + \mathrm{PhCOO^-}$$
  苯甲醛与甲醛共存时，因**甲醛还原性最强**被氧化成甲酸盐，苯甲醛被还原成苯甲醇
- **维蒂希（Wittig）反应**：磷叶立德（维蒂希试剂）由卤代烃制备（卤代烃可为甲基卤、伯卤、仲卤，**不能为叔卤**，无 $\alpha-H$）；醛酮与维蒂希试剂作用脱去三苯基氧磷生成烯烃
- **硫叶立德**与醛酮反应，生成**环氧化物**

## 竞赛要点

1. **克拉姆规则的适用边界**：只适用于 $\alpha-C$ 为手性碳的醛酮 + 含碳/氧/硫亲核试剂；判题先看底物是否有手性 $\alpha-C$，再看构象取「R(H) 与 L 重叠式」的理由（金属与羰基氧络合）
2. **烯胺碳负离子位置的判据**：$\alpha-C$ 上吸电子基 → 双键在羰基碳与该碳之间；推电子基（烃基）→ 负电荷在无取代基的 $\alpha-C$ 上（立体位阻破坏共轭）
3. **1,2- vs 1,4-加成的选择**：试剂越小越强 → 1,2；试剂体积大（二烃基铜锂）或羰基旁位阻大 → 1,4；质子酸、$\mathrm{H_2O}$/ROH 酸催化 → 1,4。$\alpha,\beta$-不饱和醛偏 1,2
4. **卤代产物的条件依赖**：酸催化可得一卤代物，碱催化会一卤到底并转入卤仿反应 — 同一底物两种条件产物完全不同
5. **还原剂选择性与加成顺序**：$\mathrm{NaBH_4}$ 不还原酯基（与 $\mathrm{LiAlH_4}$ 的区别）；$\alpha,\beta$-不饱和醛酮催化加氢先还原 C=C，$\mathrm{B_2H_6}$ 先还原 C=O
6. **歧化与缩合的分水岭是有无 $\alpha-H$**：无 $\alpha-H$ 的醛走 Cannizzaro；有 $\alpha-H$ 的醛走羟醛缩合。甲醛在 Cannizzaro 中必被氧化
7. **重排类反应的鉴别价值**：Beckmann 重排只发生**反式**基团迁移（同步给出肟的构型信息）；Baeyer-Villiger 用迁移能力 $3^{\circ}>2^{\circ}>1^{\circ}$ 预测产物；Favorskii 是**缩环**的经典手段

## 例题与习题

### 典型例题

**例1**：比较环丁酮（A）、环戊酮（B）、环己酮（C）与 $\mathrm{NaBH_4}$ 反应的活泼性次序。
> 解：环丁酮分子内张力大，还原后 $sp^{2}$ 碳变饱和、张力解除最多 → 活性最大；环戊酮的还原过渡态是重叠构象、存在扭转张力 → 活性最小；环己酮还原产物为稳定的椅式构象 → 居中。
> **答案：A > C > B**。

**例2**：A 和 B 分子式均为 $\mathrm{C_8H_{14}O}$。A 能发生碘仿反应而 B 不能；B 能发生银镜反应而 A 不能。A、B 经臭氧化分解均得到 2-丁酮和 C，C 既能发生碘仿反应又能发生银镜反应。写出 A、B、C 的结构简式。
> 解：臭氧化产物为 2-丁酮（$\mathrm{C_4}$）+ C，A、B 均为 $\mathrm{C_8}$ → C 为 $\mathrm{C_4}$。C 有甲基酮基（碘仿）+ 醛基（银镜），余下一碳作亚甲基桥 → **C = $\mathrm{CH_3COCH_2CHO}$**。
> 将 C 的醛基碳与 2-丁酮的羰基碳以 C=C 相连得 **A**（能碘仿）；将 C 的羰基碳与 2-丁酮的羰基碳以 C=C 相连得 **B**（能银镜）。

**例3**（第 27 届中国化学奥林匹克初赛试题）：$\alpha,\beta$-不饱和羰基化合物与 $(n\mathrm{-C_5H_{11}})_2\mathrm{CuLi}$ 反应，写出合理带电荷中间体 A 及产物 B。
> 解：二烃基铜锂体积较大 → 对 $\alpha,\beta$-不饱和醛酮发生 **1,4-共轭加成**，生成烯醇负离子（A）；随后加水质子化得 $\beta$-烷基取代的饱和酮（B）。

**例4**（2010 年全国初赛试题）：对羟基苯甲醛与间羟基苯甲醛在相同条件下反应，前者只得一种产物、后者得两种，简述原因。
> 解：苯环上的烷氧基对**间位**比对**对位**有更强的吸电子诱导效应和更弱的给电子共轭效应 → 间位醛基碳比对位醛基碳有更强的正电性、亲电性更高。在 $\mathrm{K_2CO_3}$ 弱碱条件下，**间位**羟基苯甲醛可与溶剂丙酮发生羟醛缩合，而对位羟基苯甲醛不能。

### 本讲习题要点
- 完成反应式：羟醛缩合（含交叉缩合与分子内缩合成环）、烯胺烷基化、格氏试剂/有机锂加成、硫叶立德/维蒂希反应、缩硫醛水解、Mg-Hg 双分子还原、$\mathrm{HIO_4}$ 氧化邻二醇
- 由臭氧化分解产物反推不饱和醛酮的碳架与官能团位置（多次出现：$\mathrm{C_7H_{12}O}$ / $\mathrm{C_8H_{14}O}$ 类推断题）
- 综合推断题中串联多个人名反应：烯胺（四氢吡咯）+ 迈克尔加成 + Mg-MgI₂ 分子内频哪醇偶联 + $\mathrm{HIO_4}$ 裂解
- 含真题：第 27 届初赛（二烃基铜锂 1,4-加成）、2010 全国初赛（卤代烃 + 对/间羟基苯甲醛缩合对比、灰黄霉素合成中手性碳构型与同分异构体计数）、第 28 届初赛（异靛蓝合成）、第 47 届 IChO 预备题（臭氧化反向推断、松露香气物 X 的定量计算）、第 40 届 IChO 试题
- 合成设计：以 ≤4 个碳有机物为原料合成含缩醛/多羟基的环状醚骨架；以苯及 ≤2 个碳有机物合成 $\mathrm{C_6H_5COCH_3}$
