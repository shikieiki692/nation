# Clayden 第28章：逆合成分析 资料提炼

---

## 一、核心概念与定义

### 1.1 逆合成分析（Retrosynthetic Analysis）
- **定义**：从目标分子（target molecule, TM）出发，逆向分析至可购买的起始原料的过程。
- **逆合成箭头**：双线开尾箭头 ⇏，表示"可由某物制得"（逻辑上的"隐含 implies"箭头）。
- **核心思想**：合成计划由产品开始，逆向分析直到起始原料，因为产品是固定、不可改变的。
- **发明者**：E.J. Corey（哈佛大学），因此也称为Corey逆合成理论。

### 1.2 切断（Disconnection）
- **定义**：想象的键的断裂过程，对应于一个真实反应的逆过程。
- **波浪线**：用波浪线（wiggly line）标明切断的位点。
- **关键原则**：切断必须对应于已知、可靠的反应。

### 1.3 合成子（Synthon）
- **定义**：切断得到的被理想化的碎片，具有极性标记（"+"或"-"）。
- **给体合成子（Donor synthon, d）**：带负电性极化的碎片，符号为"d"。
- **受体合成子（Acceptor synthon, a）**：带正电性极化的碎片，符号为"a"。
- **合成等价物（Synthetic equivalent）**：对应于合成子的实际试剂。
- **示例**：酰基合成子 MeCO⁺ 的等价物可以是酰氯或酸酐。

### 1.4 官能团互变（FGI, Functional Group Interconversion）
- **定义**：不切断任何键，将一个官能团转化为另一个官能团的逆合成操作。
- **目的**：辅助切断过程，因为下一步反应所需的活泼官能团（酰氯、卤原子）并不一定要在化合物被进一步切断时仍然存在。
- **常见FGI**：氧化、还原、取代三类反应。
- **示例**：酰氯 → 羧酸（FGI），再切断为更简单的碎片。

### 1.5 合成术语总结表

| 术语 | 定义 |
|:---|:---|
| 目标分子（TM） | 待合成的分子 |
| 逆合成分析/逆合成 | 在思想上将分子分解为起始原料的过程 |
| 逆合成箭头 | 开尾式箭头 ⇏，表示合成反应的逆过程 |
| 切断 | 想象的键的断裂过程，对应于一个真实反应的逆过程 |
| 合成子 | 切断得到的被理想化的碎片 |
| 试剂 | 合成中所用的真实化合物，也许是合成子的等价物 |

## 二、切断的五条准则

### 准则1：切断必须对应于已知、可靠的反应
- 最重要的准则。
- 在设计逆合成时，每个切断都应对应一个已知的、产率良好的正向反应。
- 例：酰胺 → 切断C-N键 → 酰氯 + 胺（标准方法）。

### 准则2：对于由两个连接在杂原子上的片段构成的化合物，在杂原子旁切断
- 适用于酯、酰胺、醚、胺、缩醛、硫醚等。
- 这些化合物都可通过取代反应制取。
- 例：硫醚杀螨醚 → 在S-C(烷基)一侧切断（而非S-芳基一侧）。

### 准则3：避免化学选择性问题
- 考虑可替代的切断方式，选择能避免化学选择性问题的路线。
- 通常意味着"先切断活泼基团"——在逆合成中将活泼基团的引入放在合成后期。

### 准则4：尽可能运用双官能团切断
- 双官能团切断（two-group disconnection）比单官能团切断更有效地减少目标分子的复杂性。
- 两个官能团之间的关系（1,2-、1,3-、1,5-）决定了可使用的切断策略。

### 准则5：转化为氧基官能团以方便C-C切断
- 氧基官能团（醇、醛、酮、酯、酸）具有通用性——容易在彼此间通过氧化还原或取代反应相互转化。
- 面对目标分子中一个不寻常的官能团，最好的选择是将其转化为相同氧化程度的氧基官能团。

## 三、C-X切断（杂原子切断）

### 3.1 醚的切断
- 在C-O键的烷基一侧切断（而非芳基一侧），因为芳环上的亲核取代不可靠。
- 合成子：烷氧基阴离子 + 卤代烷。
- 例：除草剂2,4-D → 苯酚钠 + α-卤代乙酸。

### 3.2 胺的切断
- **直接烷基化的问题**：产物通常比起始原料更活泼，有多次烷基化（多烷基化）的危险。
- **解决方案1——酰胺FGI**：胺 → 酰胺（FGI）→ 切断C-N → 酰氯 + 胺 → 还原酰胺得胺。
- **解决方案2——还原胺化FGI**：胺 → 亚胺（或肟）→ 切断C=N → 醛/酮 + 胺 → 还原得胺。
- 还原胺化试剂：NaCNBH₃或催化氢化（温和条件下亚胺还原快于酮还原）。

### 3.3 硫醚的切断
- 在S-C(烷基)一侧切断，对应于硫醇盐对卤代烷的SN2反应。
- 例：氯杀螨 → 硫醇钠 + 氯代烷。

### 3.4 酯的切断
- 切断羰基和酯化基团之间的C-O键。
- 合成子：羧酸（或酰氯/酸酐） + 醇。

## 四、C-C切断

### 4.1 炔烃的C-C切断
- 炔烃的烷基化是可靠的反应，可在三键旁边切断。
- 炔烃作为合成中间体尤其有价值：可还原为顺式双键（Lindlar催化氢化）或反式双键（Na/NH₃）。
- 对于含有孤立双键的目标分子，将FGI为炔烃通常是个好主意。

### 4.2 1,2 C-C切断（烯醇盐烷基化）
- 在羰基邻位（α-位）形成新C-C键。
- 可用试剂：酯/酮的烯醇盐 + 卤代烷；丙二酸酯/乙酰乙酸酯。
- 丙二酸酯（缩苹果酸酯）是控制羰基烯醇化的重要方法：先烷基化再脱羧。

### 4.3 1,1 C-C切断（格氏试剂对羰基加成）
- 用碳亲核试剂（格氏试剂）与亲电的官能团（羰基）反应。
- 适用于含羟基的叔醇——特别是含两个相同基团的叔醇（用2当量格氏试剂 + 酯）。
- 注意：格氏试剂对酮会继续加成，因此酮的1,1-切断通常不可靠。

## 五、双官能团C-C切断

### 5.1 1,3-双官能团化合物（核心！）

#### 1,3-二氧基化合物：羟醛反应
- 目标分子中出现1,3-关系（β-羟基羰基或α,β-不饱和羰基）→ 想到羟醛反应！
- 切断：d² 合成子（烯醇盐等价物） + a¹ 合成子（醛/酮）。
- α,β-不饱和羰基化合物：先FGI为β-羟基羰基化合物，再切断。
- 例：姜酚、奥沙那胺中间体、胡萝卜素中间体。

#### 1,3-二氧基化合物：Claisen酯缩合
- 1,3-二酮 → 切断对应于Claisen缩合反应。
- 合成子仍为 d² + a¹，但a¹上升到酯氧化程度。
- 例：他扎朵林起始原料。

#### 3-氨基酮/醇：Mannich反应或腈的羟醛反应
- 含1,3-关系的N和O → 用Mannich反应直接引入胺。
- 或用腈的羟醛反应 + 还原腈得胺。
- 例：文拉法辛（抗抑郁药）、氯丁替诺（止咳药）。

### 5.2 1,5-双官能团化合物
- 目标分子中出现1,5-关系 → 想到[[Michael加成]]（共轭加成）！
- 切断：d² 合成子（烯醇盐） + a³ 合成子（α,β-不饱和羰基化合物）。
- 例：罗谷亚胺。

### 5.3 1,2-双官能团化合物
- 可用环氧作为a²合成子（1,2-切断）。
- 对烯烃的亲电加成（双羟基化、环氧化、溴化）也可制取1,2-双官能化化合物。
- 例：非那二醇。

### 5.4 1,4-双官能团化合物
- 需要极性反转的合成子（d¹或a³策略，或a¹+d³策略）。
- 常用极性反转试剂：α-溴代羰基化合物、氰根离子。
- 苯与环状酸酐的Friedel-Crafts酰基化可避免极性反转。

## 六、合成子分类体系

### 6.1 给体/受体编号规则
- **数字**表示给体或受体位点与官能团的相对位置。
- **a（受体）**：奇数编号（a¹, a², a³, a⁴）。
- **d（给体）**：偶数编号（d², d³）。
- 注意：d¹和a²为"非天然"反应性，需要极性反转试剂。

### 6.2 常见合成子与等价物

| 合成子 | 类型 | 等价试剂 | 对应反应 |
|:---|:---|:---|:---|
| a¹（醛/酮碳） | 受体 | 醛、酮 | 格氏加成、羟醛反应 |
| d²（烯醇盐α-碳） | 给体 | 烯醇盐、烯胺、丙二酸酯、乙酰乙酸酯 | 羟醛反应、烷基化 |
| a³（β-碳，Michael受体） | 受体 | α,β-不饱和羰基化合物 | Michael加成 |
| a²（环氧碳） | 受体 | 环氧乙烷 | 1,2-双官能化 |
| d¹（极性反转） | 给体 | 氰根CN⁻、二噻烷、硫缩醛 | 1,2-双官能化 |
| a⁴（极性反转） | 受体 | α-溴代羰基化合物 | 1,4-双官能化 |

### 6.3 自然反应性与极性反转（Umpolung）
- **自然反应性**：羰基化合物中，a和d的属性沿碳链交替变化（a¹-d²-a³-d⁴...）。
- **极性反转（Umpolung）**：将合成子的天然反应性颠倒。
  - d¹合成子：碳酰基碳变为亲核的（如二噻烷、硫缩醛、氰根）。
  - a²合成子：羰基α-碳变为亲电的（如α-卤代羰基化合物）。
- **意义**：极性反转试剂是1,2-和1,4-双官能化化合物合成的关键。

## 七、经典逆合成案例

### 7.1 驱虫剂（酰胺）
- TM含酯基 → 切断C-O键 → 醇 + 酰氯。

### 7.2 丁酰肼（农药）
- TM含酰胺 → 切断C-N键 → 酸酐 + 二甲基肼。
- 注意：酰氯不稳定会环化为酸酐，直接用酸酐更合理。

### 7.3 奥福宁（降压药）
- TM含酰胺+胺 → 先用FGI将酰氯转为羧酸 → 切断为2-氨基苯甲酸 + 4-氯吡啶。
- 避免了在酰氯存在下构筑胺的化学选择性问题。

### 7.4 普萘洛尔（β-受体阻滞药）
- TM含1,2-氨基醇 → 1,2-diX切断 → 环氧 + 胺。
- 第二步切断 → 1-萘酚 + 环氧氯丙烷。

### 7.5 胡萝卜素前体
- TM含α,β-不饱和酮 → 1,3-切断 → 乙酰乙酸酯（d²） + 酮（a¹）。

### 7.6 多匹可明（镇静剂）
- TM含缩醛 → FGI去除缩醛 → 1,3-二醇 → 二酯 → α,β-不饱和酯 → 杂环醛 + 丙二酸酯。
- 使用双官能团切断，仅四步合成路线。

## 八、可用的起始原料

- **经验法则**：至多含六个碳原子和一个官能团（醇、醛、酮、酸、胺、双键、卤代烃）的化合物通常是可购买的。
- 直链化合物可买到的至多含约八个碳原子。
- 供应商目录（如Aldrich、TCI、Acros）是评估合成路线的重要工具。
- 常见双官能团起始原料：丙二酸酯、乙酰乙酸酯、1,3-二羰基化合物等。

## 九、关键结论与规则

### 9.1 逆合成分析核心逻辑
1. 从目标分子逆向思考，切断至可购买的起始原料。
2. 每个切断必须对应一个已知的、可靠的正向反应。
3. 优先使用双官能团切断——更有效地减少分子复杂性。
4. 避免化学选择性问题——将活泼基团的引入放在合成后期。
5. 利用官能团互变（FGI）辅助切断——将官能团转化为氧基形态。

### 9.2 双官能团关系速查表

| 官能团关系 | 切断策略 | 对应反应 |
|:---|:---|:---|
| 1,2-关系（C-X） | 1,2-diX切断 | 环氧开环、α-卤代羰基 |
| 1,3-关系（C=O） | 1,3-diO切断 | 羟醛反应（d² + a¹） |
| 1,3-关系（N,O） | Mannich反应 | 胺 + 甲醛 + 酮 |
| 1,3-关系（C=O,C=O） | Claisen缩合 | 酯 + 酯 |
| 1,5-关系（C=O） | 1,5-diCO切断 | Michael加成（d² + a³） |
| 1,2-关系（C-C） | 1,2 C-C切断 | 烯醇盐烷基化 |
| 1,1-关系（C-C,OH） | 1,1 C-C切断 | 格氏试剂 + 酮/酯 |

### 9.3 合成子极性反转速查

| 非天然合成子 | 极性反转试剂 | 应用 |
|:---|:---|:---|
| d¹（碳酰基碳变亲核） | CN⁻、二噻烷、硫缩醛 | 1,2-双官能化 |
| a²（α-碳变亲电） | α-卤代羰基化合物、环氧 | 1,2-双官能化 |
| d³（β-碳变亲核） | 烯丙基硅、烯丙基锡 | 1,4-双官能化 |
| a⁴（γ-碳变亲电） | α-溴代羰基化合物 | 1,4-双官能化 |

## 十四、摘录的原始段落（附页码/位置标记）

### 14.1 关于逆合成的定义（line 3524）
> "合成计划由产品开始，逆向分析直到产物，因为产品是固定、不可改变的。这个过程被称为逆合成 (retrosynthesis)，计划合成目标分子的艺术被称为[[逆合成分析]] (retrosynthetic analysis)."

### 14.2 关于合成子（line 3574）
> "我们称这种被理性化的试剂为合成子 (synthons). 合成子是具有有关联的极性 (通过 "+" 或 "-" 表示) 的碎片，它们代表我们在正向合成中将要使用的试剂。"

### 14.3 关于切断准则1（line 3598）
> "我们已经提到，切断必须对应于已知的、可靠的反应，这是在进行逆合成时，需要牢记的最重要的事情。"

### 14.4 关于FGI（line 3672）
> "官能团相互转化通常辅助着切断过程，因为下一步反应所需的活泼官能团（酰氯，卤原子）并不一定要在化合物被进一步切断时仍然存在。"

### 14.5 关于双官能团切断（line 3760）
> "这类切断过程被称作双官能团切断 (two-group disconnections)，您应当时刻瞭望着使用它们的机会，因为它们是回到简单起始原料的有效方法。"

### 14.6 关于极性反转（line 4290）
> "这样的合成子被用德文命名为极性反转的（umpolung，意为 'inverse polarity'），由于它们的天然反应性是颠倒的，极性反转的试剂便成为了 1,2- 和 1,4- 双官能化化合物合成的关键。"

### 14.7 关于可用起始原料（line 4024）
> "一条很好的经验法则是：至多包含六个碳原子和一个官能团(醇、醛、酮、酸、胺、双键，或卤代烃）的化合物通常是可用的。"

### 14.8 关于逆合成的总结（line 4344）
> "一个分子最好的合成路线不能被精确地预测。逆合成分析使您可以提出多种得到目标分子的策略，通过彻底的文献搜索和实验，您便能逐个削减这些可能的方法，并得到最容易成功的一个。"
