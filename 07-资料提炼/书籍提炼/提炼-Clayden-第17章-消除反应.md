# Clayden 第17章：消除反应 资料提炼

---

## 一、核心概念与定义

### 1.1 [[消除反应]]（Elimination）
- **定义**：从有机分子中脱去两个原子或基团（通常是 HX），在分子内形成π键（C=C 或 C≡C）的反应。
- **通式**：底物（通常含离去基团 X）+ 碱 → 烯烃 + HX 的共轭碱 + HX。
- **与取代反应的关系**：消除与亲核取代（SN1/SN2）在几乎完全相同的反应物体系下竞争，两者共享同一底物和试剂。
- **分类依据**：按机理分为 E1（单分子消除）、E2（双分子消除）、E1cB（共轭碱单分子消除）。

### 1.2 为什么碱促进消除而非取代？
- 带有离去基团的分子有两个亲电位点：**连接离去基团的碳**（取代）和**β-碳上的氢**（消除）。
- 亲核试剂碱性越强 → 越倾向于进攻质子 → 消除占优。
- 强碱使消除反应参与决速步（碱出现在速率方程中），而弱碱不影响 SN1 速率。
- **软硬理论解释**：C-X σ* 是软亲电位点（适合软亲核试剂 → SN2）；C-H σ* 是硬亲电位点（适合硬亲核试剂 → 消除）。

### 1.3 三个重要的消除机理（连续谱）
- **E1**：离去基团先离开 → 碳正离子 → 再脱质子。两步，决速步不含碱。
- **E2**：碱夺取质子与离去基团离去**协同**进行。一步，决速步含碱。
- **[[E1cb机理]]**：碱先夺取质子 → 阴离子中间体 → 再失去离去基团。两步，决速步含阴离子。
- 三者构成一个**连续谱**，区别在于质子脱除与离去基团离开的时间关系。

## 二、[[E2反应]]消除——双分子消除机理

### 2.1 基本机理
- **通式**：B⁻ + R-CH₂-CH₂-X → R-CH=CH₂ + BH + X⁻
- **决速步**：碱参与的双分子反应，速率方程为 `速率 = k[碱][底物]`
- **特征**：协同机理——C-H 键断裂、C=C π 键形成、C-X 键断裂**同时发生**。

### 2.2 [[反式共平面]]（Anti-Periplanar）过渡态
- **核心要求**：H 和 X 必须处于**反叠式（anti-periplanar）构象**——即 C-H 和 C-X 键彼此平行（二面角 180°）。
- **轨道解释**：C-H σ 键与 C-X σ* 反键轨道需要最大重叠 → 必须共平面。
- **反叠式 vs 顺叠式**：反叠式构象更稳定（交叉式 vs 重叠式），且轨道平行程度最佳。
- **Newman 投影式**中看最为直观：H 和 X 互为反式排列。
- **E2 消除是立体专一性的**：不同非对映异构体 → 不同几何结构的烯烃。

### 2.3 E2 的立体选择性与立体专一性
- **立体选择性（Stereoselective）**：反应有选择地主要生成两种可能的立体异构体之一（动力学或热力学控制）。
- **立体专一性（Stereospecific）**：起始物的立体化学**直接决定**产物的立体化学，没有选择余地。
- **关键区别**：立体专一性不是"立体选择性更强"——两者在机理层面有本质区别。
- **E2 的典型例子**：(2R,3S)-和(2S,3S)-非对映异构体分别得到 E 型和 Z 型烯烃。

### 2.4 E2 立体化学的竞赛判断
1. 画出反应物的**椅式构象**（环己烷体系）或 **Newman 投影式**（链状体系）。
2. 找到 H 和 X **反叠式**的构象。
3. 该构象中其余基团的排列方式 → 决定产物烯烃的 E/Z 构型。

## 三、[[E1反应]]消除——单分子消除机理

### 3.1 基本机理
- **第一步（决速步）**：离去基团离开，生成碳正离子中间体。`速率 = k[底物]`（与碱浓度无关）。
- **第二步**：弱碱（如溶剂分子）夺取碳正离子β位的质子 → 形成烯烃。
- **碳正离子特征**：空 p 轨道为平面型（sp² 杂化），碱从平面两侧均可进攻。

### 3.2 E1 适用的底物
- 只有能生成**稳定碳正离子**的底物才能进行 E1：叔烷基、烯丙基、苄基卤代烃。
- **仲卤代烃**可能通过 E1 消除。
- **伯卤代烃**不能进行 E1（伯碳正离子太不稳定），只能走 E2。

### 3.3 E1 的立体与区域选择性
- **立体选择性**：倾向于生成 E 型烯烃（空阻小、更稳定）。
- **区域选择性**：倾向于生成**多取代**烯烃（Zaitsev 产物）。
- **解释**：碳正离子中间体的空 p 轨道与 C-H/C-C σ 键相互作用 → 更多取代基 → 更稳定。
- **过渡态理论**：形成多取代烯烃的过渡态中含有更多取代的"半双键" → 更稳定 → 速率更快。
- **可逆性**：E1 可能是可逆的（烯烃被酸重新质子化），受热力学控制。

### 3.4 E1 底物的限制
- **Bredt 规则**：桥头碳不能形成平面碳正离子 → 桥头位置不能进行 E1 消除。
- **原因**：双环结构阻止桥头碳转变为平面型，迫使空轨道为 sp³ 而非 p 轨道（能量更高）。

## 四、[[E1cb反应]]消除——共轭碱单分子消除

### 4.1 基本机理
- **第一步**：碱夺取β位质子 → 生成碳负离子（阴离子中间体）。此步是快速平衡。
- **第二步（决速步）**：阴离子中间体失去离去基团 → 形成烯烃。
- **速率方程**：`速率 = k[底物][碱]`（碱出现在速率方程中，但不是因为参与决速步，而是因为阴离子浓度由碱浓度决定）。

### 4.2 E1cB 发生的条件
- **关键前提**：β-氢必须有**酸性**——需要阴离子稳定基（anion-stabilizing group）的存在。
- 常见阴离子稳定基：羰基（C=O）、硝基（NO₂）、氰基（CN）、苯环等。
- **产物特征**：烯烃通常与羰基共轭——这是判断 E1cB 最可靠的标志。

### 4.3 E1cB 的实例
- **Fmoc 保护基脱除**：环戊二烯基阴离子（芳香性稳定）→ E1cB 消除 → 失去 CO₂ → 胺。
- **β-卤代羰基化合物**：酸性质子 + 好离去基团 → E1cB 极易进行。
- **烯酮缩醛的制备**：t-BuOK 从溴乙醛消除 HBr → 烯酮缩醛。
- **MsCl 与醇的反应**：甲磺酰氯先经 E1cB 消除生成硫酰烯（sulfene），再与醇加成。

### 4.4 E1cB 的立体化学
- 中间体阴离子为平面型 → 起始物立体化学不影响产物。
- 区域选择性明确：双键在酸性质子与离去基团之间形成。
- 立体选择性：通常得到 E 型烯烃（位阻较小）。

## 五、E1/E2/E1cb 对比总表

| 特征 | E1 | E2 | E1cB |
|:---|:---|:---|:---|
| **决速步** | 第一步（底物解离） | 单步协同 | 第二步（阴离子消去） |
| **碱是否参与决速步** | 否 | 是 | 否（但影响阴离子浓度） |
| **速率方程** | k[底物] | k[碱][底物] | k[底物][碱]（间接） |
| **中间体** | 碳正离子 | 无（协同过渡态） | 碳负离子（阴离子） |
| **底物要求** | 能生成稳定碳正离子（叔/烯丙基/苄基） | 几乎所有含 β-H 的底物 | β-H 有酸性（有阴离子稳定基） |
| **碱的要求** | 弱碱即可 | 强碱 | 中等碱（取决于酸性） |
| **离去基团离开时间** | 先离开 | 同时 | 后离开 |
| **立体电子效应** | 碳正离子平面两侧均可进攻 | **反叠式过渡态** | 平面型阴离子，无特殊构象要求 |
| **区域选择性** | Zaitsev（多取代烯烃） | 取决于碱（见下） | 明确（酸性 H 与离去基团之间） |
| **立体选择性** | 弱（E 型优先） | 强（立体专一性） | 中等（E 型优先） |
| **可逆性** | 可能可逆（热力学控制） | 不可逆（动力学控制） | 不可逆 |

## 六、Zaitsev 规则与 Hofmann 规则

### 6.1 [[Zaitsev规则]]（扎伊采夫规则）
- **定义**：消除反应倾向于生成**取代基更多**的烯烃（多取代烯烃）。
- **适用范围**：E1 消除、以及使用**小位阻碱**（如 NaOEt、NaOH）的 E2 消除。
- **热力学解释**：多取代烯烃更稳定（更多 C-C/C-H σ 键与 π* 反键轨道相互作用 → 超共轭稳定化）。
- **动力学解释**：生成多取代烯烃的过渡态中含有更多取代的"半双键" → 更稳定 → 速率更快。
- **烯烃稳定性顺序**：四取代 > 三取代 > 二取代 > 一取代（但需注意空阻效应——四取代可能不如三取代稳定）。

### 6.2 Hofmann 规则（霍夫曼规则）
- **定义**：消除反应倾向于生成**取代基更少**的烯烃（少取代烯烃）。
- **适用范围**：使用**大位阻碱**（如 t-BuOK、DBU）的 E2 消除。
- **位阻解释**：大位阻碱难以接近环上/多取代侧的氢原子 → 优先进攻位阻较小的伯氢。
- **酸性解释**：少取代碳上的氢原子酸性更强（叔丁基阴离子碱性 > 甲基阴离子碱性 → 反之叔丁烷酸性 < 甲烷酸性）。
- **实例**：同一底物，用 NaOEt → Zaitsev 产物；用 t-BuOK → Hofmann 产物。

### 6.3 两种规则的本质联系
- **都是动力学控制**：区别在于碱的位阻决定了它进攻哪个β-氢。
- **碱的位阻是关键变量**：小碱 → 进攻位阻较小的质子 → 可能到达多取代侧 → Zaitsev；大碱 → 只能到达最暴露的质子 → Hofmann。
- **记住原因比记住名字更重要**：理解烯烃稳定性和碱的位阻即可。

## 七、消除与取代的竞争

### 7.1 影响消除/取代选择性的因素

#### 碱性（最重要的因素）
- **强碱** → 消除占优（碱参与消除的决速步）。
- **弱碱/好的亲核试剂** → 取代占优（亲核试剂不参与 SN1 决速步，但不影响 SN2 速率）。

#### 位阻
- **大位阻碱/亲核试剂** → 消除占优（难以到达碳原子进行取代，但可到达暴露的β-氢）。
- **叔丁氧基阴离子（t-BuOK）**：典型的大位阻碱，促进消除。
- **DBU**：1,8-二氮杂双环-[5.4.0]-7-十一碳烯，强碱（脒鎓离子 pKa ≈ 12.5）且体积大，是理想的 E2 试剂。

#### 温度
- **高温 → 消除占优**：消除反应 ΔS > 取代反应（2 个分子 → 3 个分子 vs 2 → 2）。
- **ΔG = ΔH - TΔS**：高温下 TΔS 项更大 → ΔG 更负 → 消除更有利。
- 实际操作：大多数消除反应在室温或更高温度下进行。

#### 底物结构
- **甲基卤**：不能消除（无β-H），只能取代。
- **伯碳**：无阻碍时 SN2；有阻碍或大碱时 E2。
- **仲碳**：弱碱 → SN2；强碱 → E2。
- **叔碳**：弱碱/弱亲核试剂 → SN1/E1；强碱 → E2。

### 7.2 竞赛中的消除/取代判断流程

```
底物 + 试剂 → ?
│
├─ 试剂是强碱？
│   ├─ 是 → 消除（E2 或 E1cB）
│   └─ 否 → 取代（SN1 或 SN2）或 E1
│
├─ 底物是叔碳？
│   ├─ 是 + 强碱 → E2
│   ├─ 是 + 弱碱 → SN1/E1
│   └─ 否 → SN2 或 E2（取决于碱的位阻）
│
├─ β-位有阴离子稳定基？
│   ├─ 是 → E1cB
│   └─ 否 → E1 或 E2
│
└─ 高温？
    ├─ 是 → 消除倾向增大
    └─ 否 → 取代倾向增大
```

## 八、立体电子效应在消除中的作用

### 8.1 E2 的反叠式要求——最严格的立体电子效应
- **轨道重叠要求**：C-H σ 键与 C-X σ* 反键轨道必须平行（反叠式构象）。
- **违反反叠式 → 反应极慢或不发生**。
- **环己烷体系的特殊性**：C-H 和 C-X 都必须处于**直立键（axial）**。
  - 平伏键的 C-X 只能与 C-C 键处于反叠式，**不能**参与 E2 消除。
  - 构象锁定的环己烷：直立键离去基团 → 快速 E2；平伏键离去基团 → 极慢或需全直立构象。

### 8.2 E2 构象锁定的实例（竞赛高频考点）
- **非对映异构体 A**：氯原子在主要构象中处于直立键 → 快速 E2 → 两种烯烃（3:1 比例）。
- **非对映异构体 B**：氯原子在主要构象中处于平伏键 → 只能通过极高能的全直立构象反应 → 极慢，得到单一烯烃。
- **速率差异**：两种非对映异构体速率可差 10 倍以上。

### 8.3 E1 中的立体电子效应
- 碳正离子的空 p 轨道与 C-H/C-C σ 键的超共轭 → 稳定碳正离子。
- 消除时，π 键只能在空 p 轨道与 C-H 键**平行**时形成。
- 两种可消除的构象 → 位阻较小者 → E 型烯烃（立体选择性）。

### 8.4 E1cB 中的立体电子效应
- 阴离子中间体为平面型 → 无构象限制。
- 立体化学仅由产物位阻决定 → 通常得到 E 型烯烃。

### 8.5 Bredt 规则——桥头碳的立体电子效应限制
- **内容**：双环化合物中，桥头碳不能形成双键（不能是烯烃的一部分）。
- **原因**：桥头碳无法转变为平面型，迫使 C=C π 键扭曲 → 极不稳定。
- **与 SN1 的类比**：与桥头碳正离子无法形成平面型是同一原因。

## 九、重要反应实例与应用

### 9.1 常用 E2 消除碱
- **t-BuOK（叔丁醇钾）**：大位阻强碱（pKa of t-BuOH ≈ 18），促进 E2，常用于 Hofmann 消除。
- **DBU**：强碱性脒类碱，稠环结构使其体积大，不易做亲核试剂。
- **LDA（二异丙基氨基锂）**：极强碱（i-Pr₂NH pKa ≈ 35），大位阻，常用于烯基卤代烃的 E2 消除。
- **NaOEt/EtONa**：较小的碱，通常得到 Zaitsev 产物。

### 9.2 离去基团的选择
- **卤素（Cl, Br, I）**：最常用的离去基团（E2 和 E1 均可）。
- **对甲苯磺酸酯（OTs）/甲磺酸酯（OMs）**：由醇经磺酰化制备，是优秀的离去基团。
  - 醇 → OTs（TsCl/吡啶）→ E2 消除。
  - 醇 → OMs（MsCl/Et₃N）→ 一锅法消除。
- **OH⁻ 绝不作为 E2 反应的离去基团**——强碱会夺去 OH 的质子而非使其离去。
- **季铵盐**：胺可作为离去基团（E1 或 E2 均可）。

### 9.3 E2 制备烯烃
- 二溴代物 + t-BuOK → 双烯（两步连续 E2）。
- 叔丁基溴 + 浓 NaOH → 异丁烯（经典 E2 实例）。
- 环己基氯的 E2 消除 → 环己烯。

### 9.4 E2 制备炔烃
- **乙烯基卤的 E2 消除**：Z 型乙烯基溴（H 和 Br 反式）→ 快速 E2 → 炔烃。
- E 型乙烯基溴（H 和 Br 顺叠式）→ 不能 E2 → 不反应或极慢。
- **1,2-二溴烷烃 → 炔烃**：三当量 R₂NLi 处理 → 第一次 E2 得乙烯基卤 → 第二次 E2 得炔烃 → 第三当量质子化炔烃。

### 9.5 E1 消除制备烯烃
- **酸催化醇脱水**：叔醇在 H₂SO₄ 或 H₃PO₄ 中 → E1 消除 → 烯烃。
- **环己醇 → 环己烯**：磷酸催化，E1 消除。
- **叔醇经 Grignard 加成后的 E1 消除**：有机金属 + 羰基 → 叔醇 → 酸催化 E1 → 取代环己烯。

### 9.6 E1cB 消除的隐蔽出现
- **酰氯 + 碱 + 胺 → 酰胺**：看似 SN，实际是 E1cB → 烯酮 → 胺加成。
- **MsCl + 醇 + Et₃N → 甲磺酸酯**：MsCl 先 E1cB → 硫酰烯 → 醇加成。
- **Fmoc 保护基脱除**：环戊二烯基阴离子的芳香性稳定 → E1cB → 失 CO₂。
- **β-卤代羰基化合物**：酸性质子 + 好离去基团 → E1cB 极快。

### 9.7 羰基化学中的消除
- 酯酸催化水解的最后一步涉及 ROH 的 E1 消除（C=O π 键形成）。
- 烯胺的制备：亚胺的 E1 消除脱水。

## 十、竞赛题型与解题策略

### 10.1 产物预测型
- **给定底物和条件**：判断产物是烯烃还是取代产物，以及烯烃的 E/Z 和区域异构体。
- **关键判据**：碱的强度和位阻、底物的碳级、温度。

### 10.2 机理判断型
- **判断 E1 还是 E2**：底物能否生成稳定碳正离子？碱是否强？
- **判断 E2 还是 E1cB**：β-氢是否有酸性？产物烯烃是否与羰基共轭？
- **OH⁻ 不能做 E2 离去基团**——若产物中 OH 作为离去基团消失，必为 E1cB。

### 10.3 立体化学型
- **E2 立体专一性**：不同非对映异构体 → 不同 E/Z 烯烃。
- **环己烷 E2**：C-H 和 C-X 必须都是直立键 → 构象分析是关键。
- **Bredt 规则**：桥头位置不能消除。

### 10.4 区域选择性型
- **Zaitsev vs Hofmann**：小碱 → 多取代（Zaitsev）；大碱 → 少取代（Hofmann）。
- **E1cB 区域选择性**：双键在酸性质子与离去基团之间。

### 10.5 合成设计型
- **醇 → 烯烃的路线选择**：
  - 叔醇 → 酸催化 E1（H₂SO₄/H₃PO₄）。
  - 伯/仲醇 → 先磺酰化（TsCl/MsCl）→ 再 E2（t-BuOK/DBU）。
- **二烯的制备**：二溴代物 + t-BuOK → 两步 E2。
- **炔烃的制备**：1,2-二溴烷烃 + 3 当量 R₂NLi → E2 烯基卤 → E2 炔烃。

### 10.6 条件选择型
- **t-BuOK vs NaOEt**：选择 Hofmann 还是 Zaitsev 产物。
- **高温 vs 低温**：高温促进消除。
- **酸性 vs 碱性条件**：酸性 → E1；碱性 → E2 或 E1cB。

### 10.7 竞赛高频考点清单
1. E2 反叠式过渡态——画 Newman 投影式判断产物 E/Z。
2. 环己烷 E2——直立键要求——构象锁定的影响。
3. Zaitsev vs Hofmann——碱的位阻决定区域选择性。
4. 消除 vs 取代竞争——碱性、位阻、温度的综合判断。
5. E1cB 的隐蔽出现——酰氯 + 碱、MsCl + 醇、Fmoc 脱除。
6. Bredt 规则——桥头位置的限制。
7. 从醇制备烯烃的路线设计——磺酰化 + E2 或酸催化 E1。
8. 烯基卤 E2 制备炔烃——立体电子效应的直接应用。

## 八、摘录的原始段落（附页码/位置标记）

### 8.1 关于消除与取代的竞争（lines 330-338）
> "叔丁基溴发生消除反应，是由于亲核试剂的碱性。强碱通常是好的亲核试剂。氢氧根，作为好的亲核试剂，并不对取代反应的速率产生影响...而作为好的碱，它却对消除反应的速率产生了贡献，因为它参与了消除反应的决速步。"

### 8.2 关于碱性与选择性（lines 388-389）
> "带有离去基团的分子会在两个不同类的亲电位点被进攻：连接离去基团的碳原子，或与该碳相邻的碳上的氢原子。进攻碳原子导致取代反应，进攻氢原子导致消除反应。一般来说，'亲核试剂'的碱性越强，越容易进攻质子。"

### 8.3 关于温度的影响（lines 408-418）
> "两个分子通过消除反应产生了三个分子...而在取代反应中，则是两个分子产生了两个新分子。因此两个反应过程的熵变不同：消除反应的 ΔS 高于取代反应...在高温下，ΔS 越正，反应越利于正向进行。"

### 8.4 关于 E2 机理（lines 440-448）
> "在 E2 消除中，离去基团的离去与质子的去除是协同的 (concerted)...E2 描述的是决速步是包含碱参与的双分子反应 (2) 的消除反应 (E)。"

### 8.5 关于 E2 的反叠式要求（lines 649-659）
> "新的 π 键在 C-H σ 键和 C-X σ* 反键轨道重叠时形成。最好的重叠，要求这两个轨道处于同一个平面上...其中一种是 H 和 X 处于反叠式 (反式共平面) 的构象，另一种则是它们处于顺叠式 (顺式共平面) 的构象。其中反叠式比顺叠式稳定。"

### 8.6 关于立体选择性与立体专一性的区别（lines 681-686）
> "立体选择性反应可以由于在反应进程中存在的选择，有倾向地得到某一产物...立体专一性反应直接地由反应机理和起始物的立体化学，单一地得到某一异构体。没有选择的余地。"

### 8.7 关于环己烷 E2（lines 693-707）
> "取代环己烷的两个取代基如果想要彼此平行，那么它们必须都处于直立键。一个平伏的 C-X 键只可能与 C-C 键处于反叠式，并因此不能参与消除反应。"

### 8.8 关于 Zaitsev 与 Hofmann（lines 749-757）
> "传统上，这两个相反的倾向性——生成少取代烯烃还是多取代烯烃——分别被称作扎伊采夫规则 (Saytsev's rule) 和 Hofmann 规则 (Hofmann's rule)...记住它们的名字意义并不大——更重要的是理解烯烃生成的倾向性的原因。"

### 8.9 关于 E1cB 的判断（lines 793-794）
> "判断一个消除反应是否为 E1cB 机理最可靠的办法，是观察产物烯烃是否与一个羰基共轭，如果是这样，那么机理有可能就是 E1cB。"

### 8.10 关于 E1/E2/E1cB 连续谱（lines 828-832）
> "我们可以将 E1cB 机理和其他消除机理，从离去基团和质子相对的离去时间的方面展开考虑...E1 就会在刻度的其中一侧：离去基团在第一步离去，而质子在第二步被夺去。在 E2 反应中，这两件事同时发生...而在 E1cB 反应中，质子在离去基团离去前被夺去。"

### 8.11 关于烯烃稳定性（lines 892-900）
> "共轭——任何可以与烯烃共轭的事物都可以稳定它...取代基——烷基通过弱的 σ-共轭稳定系统，因此更多烷基取代的烯烃更好...空阻效应——由于烯烃是平面型的，较大的，尤其是有带支链的取代基 syn 排列时，烯烃变得不稳定。"

### 8.12 关于 Bredt 规则（lines 539-541）
> "平面桥头碳阳离子的不现实，也意味着桥头碳上双键的生成几乎不可能。这一规则被称为 Bredt 规则 (Bredt's rule)...Bredt 规则仅仅是对平面桥头碳引起的张力的总结。"

## 九、竞赛题型线索

### 9.1 产物预测型
- 给定底物 + 碱 → 预测消除产物（E/Z、区域异构体）。
- 给定底物 + 条件 → 判断消除 vs 取代产物。
- 给定非对映异构体底物 → 预测 E2 产物的立体化学。

### 9.2 机理判断型
- 根据速率方程判断 E1/E2/E1cB。
- 根据底物结构判断能否进行 E1（碳正离子稳定性）。
- 根据产物是否与羰基共轭判断 E1cB。
- OH⁻ 不能做 E2 离去基团的判断。

### 9.3 立体化学型
- 画 Newman 投影式 → 找反叠式构象 → 判断 E/Z。
- 环己烷构象分析 → 直立键/平伏键判断 → E2 可行性。
- Bredt 规则的应用（桥头位置能否消除）。

### 9.4 区域选择性型
- 小碱 vs 大碱 → Zaitsev vs Hofmann。
- E1cB 区域选择性（酸性 H 与离去基团之间）。
- E1 区域选择性（多取代烯烃优先的过渡态解释）。

### 9.5 合成设计型
- 醇 → 烯烃的路线：酸催化 E1 或磺酰化 + E2。
- 烯烃 → 双烯：二溴代物 + 两步 E2。
- 烯基卤 → 炔烃：E2 消除。
- 利用 E1cB 合成与羰基共轭的烯烃。

### 9.6 条件选择型
- t-BuOK vs NaOE → Hofmann vs Zaitsev。
- 高温 vs 低温 → 消除 vs 取代。
- 酸性条件（E1）vs 碱性条件（E2/E1cB）的选择。

## 十、存疑或待验证之处

1. **E1cB 速率方程的推导**：文中说碱出现在速率方程中是因为阴离子浓度由碱浓度决定，而非直接参与决速步——这种"间接依赖"在竞赛中如何判断？
2. **四取代烯烃的稳定性**：文中提到"四取代烯烃通常比三取代烯烃不稳定"（空阻效应），这与一般认知中"多取代更稳定"如何调和？
3. **E1 的可逆性**：文中提到 E1 消除可能是可逆的（烯烃被酸重新质子化），在竞赛中如何判断一个 E1 反应是动力学还是热力学控制？
4. **E1cB 与 E2 的边界**：当 β-氢有一定酸性但不特别强时，如何判断是 E2 还是 E1cB？
5. **DBU 的碱性定量数据**：文中提到 DBU 的脒鎓离子 pKa ≈ 12.5，但在不同文献中数据有差异，竞赛中应以哪个为准？
6. **构象锁定环己烷的 E2 速率差异**：文中说两种非对映异构体速率差 10 倍，这个定量关系在竞赛中是否需要记忆？
7. **Fmoc 脱除的机理细节**：文中将 Fmoc 脱除归类为 E1cB，但实际可能涉及多种竞争机理——竞赛中应如何表述？
