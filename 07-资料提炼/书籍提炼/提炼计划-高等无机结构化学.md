# 《高等无机结构化学》（第3版）提炼计划与竞赛映射总表

> **书名**：高等无机结构化学（第三版）  
> **作者**：麦松威、周公度、李伟基 著（北京大学出版社）  
> **物理位置**：`mineru/03-教材书籍/高等无机结构化学（第3版麦松威）/`  
> **核心定位**：化学竞赛高阶（全国初赛一等奖、冬令营全国决赛与国家集训队）微观结构理论、空间群、配位场与多面体团簇最高权威参考书。

## 一、全书 16 章与竞赛讲义映射矩阵

| 章节 | 章节名称 | 核心知识点与数理内涵 | 对接竞赛讲义/考纲条目 | 优先级 |
| :---: | :--- | :--- | :--- | :---: |
| **第1章** | 量子理论导论 | 薛定谔方程严格求解、一维/三维势箱、势垒贯穿与隧道效应 | Target 1《原子结构》深化 | P2 |
| **第2章** | 原子的电子结构 | 光谱项（$L-S$ 与 $j-j$ 耦合）、Hund 规则定量解释、电负性光谱标度、相对论效应微观机制 | Target 1《原子结构》+ Target 2《元素周期律》 | P2 |
| **第3章** | 分子中的共价键 | 变分法、离域 $\pi$ 键、Walsh 构型规则（$\mathrm{AH_2, AH_3}$ 构型演化）、光电子能谱（PES）与 MO 验证 | **Target 3《分子结构基础》** | **P0** (即刻提炼) |
| **第4章** | 固体中的化学键 | 紧束缚近似、能带理论（$k$ 空间色散关系）、Peierls 不稳定性、固相导电性 | Target 5《晶体学与晶体结构》 | P1 |
| **第5章** | 分子间作用与超分子 | 氢键势能函数、二氢键（$\mathrm{M-H\cdots H-X}$）、卤键与次级键、超分子主客体识别与自组装拓扑 | Target 10《超分子化学》 | P1 |
| **第6章** | 对称性与群论基础 | Schoenflies 记号、232 个对称操作、32 个晶体学点群、特征标表结构与大正交定理 | **Target 4《分子结构补充（点群与对称性）》** | **P0** (即刻提炼) |
| **第7章** | 群论在分子结构中的应用 | 杂化轨道系数矩阵的数理构建、对称适应线性组合（SALC）投影算符、分子振动光谱（红外/拉曼）模式分析与直积分解 | **Target 3《分子结构基础》** + **Target 4《分子结构补充》** | **P0** (即刻提炼) |
| **第8章** | 配位化合物中的化学键 | 晶体场分裂能 $10Dq$、配位场分子轨道（$\sigma$ 与 $\pi$ 作用）、Tanabe-Sugano 能级图、Jahn-Teller 协同畸变 | Target 7《配位化合物基础》 + Target 8《配合物深化》 | P0 |
| **第9章** | 晶体的对称群 | 230 个空间群微观构造、平移对称元素（滑移面、螺旋轴）、等效点系与 Wyckoff 记号、粉末 XRD 消光系统 | Target 5《晶体学与晶体结构》 + Target 6《晶体结构深化》 | P0 |
| **第10章** | 无机晶体与晶体材料 | 紧密堆积空隙率推导、配位多面体连接规则（Pauling 规则）、钙钛矿/尖晶石超导与巨磁阻材料 | Target 6《晶体结构深化》 | P0 |
| **第11章** | 氢的结构化学 | 储氢合金微观晶格位点、多中心多电子氢化物键合模型 | 元素化学-氢与碱金属 | P2 |
| **第12章** | 硼的结构化学 | Wade-Mingos 骨架电子对多面体规则（闭式/巢式/网式/联式）、碳硼烷拓扑等瓣分析 | 元素化学-硼族专题 + 决赛02 | P1 |
| **第13章** | 碳和硅的结构化学 | 富勒烯（$I_h\ \mathrm{C_{60}}$）与碳纳米管拓扑、石墨烯狄拉克锥、硅酸盐网络阴离子缩合度分析 | 元素化学-碳族专题 | P1 |
| **第14章** | 氮和磷的结构化学 | 多聚磷酸盐链/环/网拓扑、磷腈衍生物无机高分子立体构型 | 元素化学-氮族专题 | P2 |
| **第15章** | 氧和硫的结构化学 | Keggin 与 Dawson 型多金属氧酸盐（POMs）簇结构、多硫阴离子构象 | 元素化学-氧族专题 | P1 |
| **第16章** | 金属-金属键与过渡金属簇 | 四重键（$\sigma+2\pi+\delta$）与五重键键级、三角/八面体多核金属簇、金属有机框架（MOFs）节点化学 | 决赛03-团簇化学与前沿结构 | P1 |
