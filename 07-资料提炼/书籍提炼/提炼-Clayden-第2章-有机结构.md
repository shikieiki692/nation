# 提炼：Clayden 第2章——有机结构（Organic Structure）

---

## 一、核心概念与定义

### 1.1 碳氢骨架（Hydrocarbon Framework/Skeleton）
- **定义**：有机分子中由碳原子构成的链或环，作为官能团的"支撑骨架"。
- **类比**：如同骨骼支撑内脏，碳骨架支撑官能团并允许其参与化学反应。
- **三种基本形态**：
  - **链（chain）**：线性排列，如脂肪酸的锯齿碳链
  - **环（ring）**：闭合环状，如苯环、环己烷
  - **支链（branched）**：链上有分支，如异丁基

![](clayden 有机化学/Clayden中文版_11-210_images/325cd55b5546fd814fdd8ff2b02b715b727f7d7e230d685f887b332c0157c5c4.jpg) — 链状碳骨架

![](clayden 有机化学/Clayden中文版_11-210_images/20d6453617272f3eeab2e222b118f5573988ed40ed619ad4f1056f639775ad7d.jpg) — 环状碳骨架

![](clayden 有机化学/Clayden中文版_11-210_images/ee7a6fa5e1864afdddb198c770c63e595df1849003499631c3ed88b996cd3507.jpg) — 带分支的碳骨架

### 1.2 官能团（Functional Group）
- **定义**：分子中决定化学和生物学性质的小部分结构。大多数性质由[[官能团]]决定，而非碳骨架的长度或排列方式。
- **核心原则**：同一个官能团在不同分子中作用方式基本相同——这正是有机化学可以系统化的原因。
- **与碳骨架的关系**：碳骨架本身几乎不发生化学反应（烷烃几乎"惰性"，只能燃烧），反应性完全来自官能团。

### 1.3 杂原子（Heteroatom）
- **定义**：有机分子中除 C 和 H 之外的任何原子（O, N, S, P, Si, 卤素等）。
- **意义**：官能团本质上是碳骨架与杂原子的组合，或碳骨架不饱和度的变化（C=C, C≡C）。

### 1.4 饱和与不饱和
- **饱和（saturated）**：碳原子与四个原子成键，无进一步成键能力（烷烃）。
- **不饱和（unsaturated）**：碳原子与三个或更少原子成键，有进一步反应潜力（烯烃、炔烃）。

### 1.5 伯/仲/叔/季碳分类

![](clayden 有机化学/Clayden中文版_11-210_images/47b7b344ed3f32e1e6be1e6a446ba0d9c8a190d559774df6bbd09d35e26a4028.jpg) — 伯碳(1°)、仲碳(2°)、叔碳(3°)、季碳(4°)的定义

- **伯碳（primary, 1°）**：只与一个其他碳原子相连
- **仲碳（secondary, 2°）**：与两个其他碳原子相连
- **叔碳（tertiary, 3°）**：与三个其他碳原子相连
- **季碳（quaternary, 4°）**：与四个其他碳原子相连

### 1.6 有机元素符号（Organic Element Symbols）
- 常用缩写作为化学交流的"速记"：

| 符号 | 名称 | 结构 | 备注 |
|:---:|:---:|:---:|:---|
| Me | 甲基 methyl | –CH₃ | |
| Et | 乙基 ethyl | –CH₂CH₃ | |
| Pr / n-Pr | 丙基 propyl | –CH₂CH₂CH₃ | |
| Bu / n-Bu | 丁基 butyl | –(CH₂)₃CH₃ | |
| i-Pr | 异丙基 isopropyl | (CH₃)₂CH– | 注意与 n-Pr 不同 |
| i-Bu | 异丁基 isobutyl | (CH₃)₂CHCH₂– | |
| s-Bu | 仲丁基 sec-butyl | CH₃CH₂CH(CH₃)– | |
| t-Bu | 叔丁基 tert-butyl | (CH₃)₃C– | |
| Ph | 苯基 phenyl | C₆H₅– | |
| Ar | 芳基 aryl | 取代苯环 | Ph的"万能卡" |
| Bn | 苄基 benzyl | C₆H₅CH₂– | 注意与 Ph 区分 |

### 2.3 按氧化程度分类（Oxidation Level）

**核心概念**：携带官能团的碳原子与杂原子成键的数量决定氧化程度。同一氧化程度内的官能团可以互相转化（不需要氧化剂/还原剂），不同氧化程度间转化则需要。

| 氧化程度 | 碳与杂原子成键数 | 包含的官能团 |
|:---:|:---:|:---|
| 烷烃氧化程度 | 0 | 烷烃 C–H, C–C |
| 醇氧化程度 | 1 | 醇 R–OH, 醚 R–O–R, 卤代烃 R–X |
| 醛氧化程度 | 2 | 醛 R–CHO, 酮 R–CO–R, 缩醛 R–C(OR')₂, 二卤代 R–CX₂ |
| 羧酸氧化程度 | 3 | 羧酸 R–CO₂H, 酯 R–CO₂R, 酰胺 R–CONH₂, 腈 R–CN, 酰卤 R–COX |
| CO₂氧化程度 | 4 | CO₂, 碳酸酯, 四卤化碳 CCl₄ |

![](clayden 有机化学/Clayden中文版_11-210_images/c03f7e226104967218ab5512dc40e03f97a10e9b3b40fcad38decbd381a17caf.jpg) — 羧酸氧化程度

![](clayden 有机化学/Clayden中文版_11-210_images/b9cf719814bbd2fcd5ad3ec3c75a6c5b4984760f423ce1241fdd1f23134d77bc.jpg) — 醇氧化程度

![](clayden 有机化学/Clayden中文版_11-210_images/85873077eea6f8b0ed42b765c28ac57cf54d2051c2f22cb2555475dee29b485b.jpg) — CO₂氧化程度

- **烯烃和炔烃的归属**：烯烃可由醇脱水制得（不需氧化还原），归入醇氧化程度；炔烃水合得醛/酮，归入醛氧化程度。

## 三、关键结论与规则

### 3.1 绘制有机结构的三条准则

| 准则 | 内容 | 原因 |
|:---:|:---|:---|
| 准则1 | **将碳链画成锯齿状** | 反映真实键角（[[sp3杂化|sp³]]碳109°，[[sp2杂化|sp²]]碳120°在平面上的投影） |
| 准则2 | **省略碳上的氢原子和C–H键** | 简洁，且可从碳的四价推知氢的位置 |
| 准则3 | **省略大写字母C，仅用折点代表碳原子** | 突出官能团，淡化碳骨架 |

- **例外**：当 C 或 H 是官能团的一部分时需明确写出（如 –CHO、–CO₂H）。
- **形式电荷**：建议用圆圈标注（如 O⁻），防止遗忘。

### 3.2 立体化学的纸面表示

![](clayden 有机化学/Clayden中文版_11-210_images/5c4a01c9bc6ad4c9aabf873488fd0e4f55ff8cdc00f7bf05a7909580639a1d0e.jpg) — 楔形键立体化学表示：实楔朝向前方，虚楔朝向后方

- **实楔形键（solid wedge）**：朝向纸面前方（指向观察者）
- **虚楔形键（cross-hatched wedge）**：朝向纸面后方（远离观察者）
- **普通直线键**：在纸平面内
- **惯例**：碳链放在平面上，分支/取代基朝向或背离观察者

### 3.3 IUPAC系统命名法规则

**系统名称三要素**：碳氢骨架名称 + 官能团名称 + 位置编号

#### 碳骨架命名（烷烃）

| 碳数 | 名称 | 英文 | 环状 |
|:---:|:---:|:---:|:---:|
| 1 | 甲烷 | methane | — |
| 2 | 乙烷 | ethane | — |
| 3 | 丙烷 | propane | 环丙烷 cyclopropane |
| 4 | 丁烷 | butane | 环丁烷 cyclobutane |
| 5 | 戊烷 | pentane | 环戊烷 cyclopentane |
| 6 | 己烷 | hexane | 环己烷 cyclohexane |
| 7 | 庚烷 | heptane | 环庚烷 cycloheptane |
| 8 | 辛烷 | octane | 环辛烷 cyclooctane |
| 9 | 壬烷 | nonane | 环壬烷 cyclononane |
| 10 | 癸烷 | decane | 环癸烷 cyclodecane |

- **环状化合物**：前缀 "环 cyclo-" + 对应碳数烷烃名称

#### 官能团作为后缀（决定母体名称）

| 官能团 | 后缀 | 示例 |
|:---:|:---:|:---|
| –CO₂H | -oic acid | 乙酸 ethanoic acid (acetic acid) |
| –CHO | -al | 乙醛 ethanal (acetaldehyde) |
| C=O (酮) | -one | 丙酮 propanone (acetone) |
| –OH | -ol | 乙醇 ethanol |
| –NH₂ | -amine | 甲胺 methanamine |
| C≡C | -yne | 乙炔 ethyne |
| C=C | -ene | 乙烯 ethene |
| –CN | -nitrile | 戊腈 pentanenitrile (BuCN) |

#### 官能团作为前缀

| 官能团 | 前缀 | 示例 |
|:---:|:---:|:---|
| –X (卤素) | fluoro-, chloro-, bromo-, iodo- | 氯乙烷 chloroethane |
| –NO₂ | nitro- | 硝基苯 nitrobenzene |
| –OR | alkoxy- | 甲氧基methane (甲醚) |

#### 编号规则
- 从离官能团最近的一端开始编号
- 多个相同官能团用倍数词头：di-（二）、tri-（三）、tetra-（四）
- 环状化合物从带官能团的碳开始编号
- 中文命名中，后缀官能团编号在碳骨架名称前面

#### 苯环取代的邻间对命名
- **邻（ortho, o-）**：1,2-二取代
- **间（meta, m-）**：1,3-二取代
- **对（para, p-）**：1,4-二取代

## 八、摘录的原始段落

### 段落1：官能团的定义（line ~1402）
> "相比于杂原子(O, N, S, P, Si...)，有机化学并不十分注重碳原子的个数和排列方式。我们将分子中比较看重的这一小部分称为一个官能团(functional group)，因为实际上分子的大多数性质都是由它们决定的。"

### 段落2：碳骨架的类比（line ~1418）
> "我们可以把碳原子组成的链或环想象成分子的骨架。就像我们的骨头支撑着内脏正常工作并彼此交互一样，分子骨架的作用也是支撑官能团，并允许它们参与化学反应。"

### 段落3：氧化程度的判断（line ~1981）
> "如果两种官能团间的转化，只需要简单试剂，不需要还原剂(或氧化剂)，我们就称携带它们的碳原子有相同的氧化程度(oxidation level)。"

### 段落4：系统命名法的本质（line ~2023）
> "国际纯粹与应用化学联合会发展了一套系统命名法，这是一套可以给予任意一个化合物一个唯一的名称的规则，这种名称可以直接地从其化学结构上推导出来。反过来，从系统名称也可以推出一个分子的结构。"

### 段落5：俗名与系统名的取舍（line ~2084）
> "在实践上，除了最简单的分子外，其他任何物种完整的系统名称都太过笨拙，因而难以用于日常化学演讲。因此有很多替代方法出现了，大多数基于俗称和系统名称的混合。"

### 段落6：烯丙基 vs 乙烯基（line ~2121）
> "烯丙基和乙烯基是不同的，乙烯基指的是直接与双键 C=C 碳原子相连，而烯丙基指的是与 C=C 双键相邻的碳相连。这种区别极其体现于化学反应上：经典的烯丙基化合物非常活泼，而乙烯基化合物相当不活泼。"

### 段落7：命名建议六要点（line ~2226）
> "先画出结构，然后再考虑名称。熟记官能团的名称。学习和使用一些化学家常用的简单化合物的名称。在演讲中，用'那个酸'来称呼，与此同时要指向结构图。掌握系统命名法的基本原则。找一个笔记本记下您将来会遇到的首字母缩略词、俗称、结构等。"

## 十、存疑或待验证之处

1. **氧化态 vs 氧化程度**：原文提到"氧化程度由碳与杂原子的成键数决定，而氧化态则由碳所有的成键数决定"，但同时注释"这个说法或许有一些问题"。竞赛中一般使用氧化程度概念，不涉及形式氧化态的精确计算。

2. **烯烃/炔烃的氧化程度归属**：原文将烯烃归入醇氧化程度（因脱水可互相转化），炔烃归入醛氧化程度（因水合得醛/酮）。这一分类在合成设计中实用，但需注意脱水/水合并非总能直接实现。

3. **IUPAC命名中的细节差异**：中英文命名在编号位置上有差异（中文命名中后缀官能团编号在碳骨架名称前面），竞赛答题需注意中英文规则的统一。

4. **缩酮（ketal）概念**：原文注释提到"旧教材常用缩酮指中心碳连接的另两个基团均为烷基的缩醛，本书并无此概念"。竞赛中可能遇到此术语，需注意缩酮是缩醛的子集。

5. **士的宁的IUPAC命名**：原文展示了IUPAC和Chemical Abstracts两套不同的系统命名，说明复杂分子命名可能存在争议。竞赛中一般不涉及此类复杂命名。

6. **"有机元素"符号的使用范围**：原文强调缩写符号只能用于端基基团（如不能将赖氨酸的5碳链缩写为Bu），但实际竞赛中此规则有时被忽略，需根据上下文判断。
