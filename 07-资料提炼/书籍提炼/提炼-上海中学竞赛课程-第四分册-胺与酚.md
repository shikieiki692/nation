# 提炼-上海中学竞赛课程-第四分册-胺与酚

> 来源：上海中学竞赛课程·化学·第4分册·第九讲 胺与酚
> 提炼日期：2026-07-08

---

## 一、内容概要

本讲介绍了胺的结构、碱性分类（伯/仲/叔胺、季铵盐）、胺的化学性质（烷基化、酰基化、兴斯堡反应、与亚硝酸反应、重氮化反应），以及酚的酸性、亲电取代反应。重点为芳香重氮盐的取代反应与偶联反应，以及胺级别的鉴别方法。

## 二、核心知识点

### 2.1 胺的结构与碱性
- 氮原子sp³杂化，一对孤对电子占据sp³轨道
- **分类**：RNH₂（1°胺）、R₂NH（2°胺）、R₃N（3°胺）、R₄N⁺X⁻（季铵盐）
- **碱性影响因素**：
  - 给电子基团→氮上电子云密度↑→碱性↑
  - 基团体积大→空间位阻→碱性↓
  - 芳香胺：p-π共轭使氮上电子云密度↓→碱性远弱于脂肪胺
  - 苯环邻/对位有给电子基团→碱性↑
- **氮上氢的酸性**：仅比烷烃氢略强→其共轭碱碱性很强
  - LDA（二异丙基氨基锂）：位阻极大的强碱

### 2.2 酚的酸性
- 酸性：羧酸 > 碳酸 > 酚 > 水 > 醇
- 苯环连给电子基→酸性减弱
- 苯环连吸电子基→酸性增强
- 例：对硝基苯酚 pKₐ=7.15，苯酚 pKₐ=10.0

### 2.3 胺的物理性质
- 1°、2°胺可形成分子间氢键（弱于醇）→沸点介于非极性化合物与醇之间
- C₁~C₄脂肪胺与水互溶，C₅以上微溶

### 2.4 胺的化学性质

#### 烷基化
- NH₃ → 1°胺 → 2°胺 → 3°胺 → 季铵盐（逐步烷基化，难以控制在一步）
- 不用叔卤代烃（→消除为主）

#### 酰基化
- 胺 + 酰氯/酸酐 → 酰胺
- **兴斯堡(Hinsberg)反应**（对甲苯磺酰氯/TsCl）：
  - 1°胺 → 磺酰胺（N上有H，可溶于碱）
  - 2°胺 → 磺酰胺（N上无H，不溶于碱也不溶于酸）
  - 3°胺 → 不反应（生成的盐水解回3°胺）
  - 可用于鉴别三种级别胺

#### 与亚硝酸反应
- **脂肪族1°胺** + NaNO₂/HCl（0~5°C）→ 重氮盐 → 不稳定 → 立即分解放N₂ → 碳正离子 → 醇
- **芳香族1°胺** + NaNO₂/HCl（0~5°C）→ 芳香重氮盐（较稳定）
- **2°胺** + HNO₂ → N-亚硝基胺（黄色油状）
- **3°胺** + HNO₂（脂肪族）→ 不反应；（芳香族）→ C-亚硝基化

#### 蒂芬欧-捷姆扬诺夫反应
- 1-氨甲基环烷醇 + HNO₂ → 增加一个碳的环酮
- 经重氮化→碳正离子→扩环重排

### 2.5 芳香重氮盐的反应

#### 取代反应（桑德迈尔反应等）
- ArN₂⁺ + CuCl → ArCl + N₂（桑德迈尔反应）
- ArN₂⁺ + CuBr → ArBr + N₂
- ArN₂⁺ + CuCN → ArCN + N₂（引入氰基）
- ArN₂⁺ + H₃PO₂ → ArH + N₂ + H₃PO₃（脱氨基还原）
- ArN₂⁺ + KI → ArI + N₂
- **合成应用**：可将-NH₂转化为-X、-CN、-H等多种基团

#### 偶联反应
- 重氮盐正离子为弱亲电试剂，可与活化苯环发生亲电取代
- **与芳香胺偶联**：弱酸性介质（酸性太强→-NH₂质子化→钝化）
- **与酚偶联**：弱碱性介质（碱性太强→重氮氢氧化物→无活性）
- 产物为偶氮化合物（有色，可用于染料）

### 2.6 芳香胺的亲电取代
- **硝化**：先乙酰化保护-NH₂→硝化→水解（防止-NH₂被氧化）
- **卤代**：氨基活化作用很强→直接与溴水生成2,4,6-三溴苯胺
  - 乙酰化保护后→主要得对位卤代产物
- **磺化**：加热脱水重排→对氨基苯磺酸（以内盐形式存在）
- **酰基化**：先保护-NH₂→苯环酰基化→脱保护
- **维尔斯迈尔(Vilsmeier)反应**：N,N-二甲基苯胺 + DMF + POCl₃ → 对位甲酰化

## 三、竞赛要点

1. **兴斯堡反应鉴别胺的级别**：这是竞赛经典考点，需准确描述1°、2°、3°胺与TsCl反应的现象差异
2. **芳香重氮盐的合成应用**：通过重氮盐可实现-NH₂到多种官能团的转化，是有机合成的重要工具
3. **偶联反应的介质条件**：胺偶联在弱酸性，酚偶联在弱碱性，需理解原因
4. **胺的碱性比较**：综合考虑电子效应和空间效应，注意脂肪胺与芳香胺的巨大差异
5. **氨基保护策略**：硝化、卤代、酰基化中先乙酰化保护-NH₂，是竞赛合成题的重要考点
6. **蒂芬欧-捷姆扬诺夫反应**：扩环合成环酮的特殊方法

## 四、例题与习题

### 典型例题

**例1**：如何用兴斯堡反应鉴别CH₃NH₂、(CH₃)₂NH、(CH₃)₃N？
> 解：分别加入TsCl/NaOH溶液。(1)CH₃NH₂（1°胺）→产物溶于NaOH（N上H有酸性）；(2)(CH₃)₂NH（2°胺）→产物不溶于NaOH（N上无H），也不溶于酸；(3)(CH₃)₃N（3°胺）→不反应，加酸溶解。

**例2**：设计从苯胺合成对溴苯胺的路线。
> 解：苯胺→乙酰化（保护-NH₂）→乙酰苯胺→溴代（对位为主）→对溴乙酰苯胺→水解→对溴苯胺。直接溴代得2,4,6-三溴苯胺（多取代）。

**例3**：写出苯胺→重氮盐→对甲基偶氮苯的反应条件。
> 解：苯胺 + NaNO₂/HCl（0~5°C）→PhN₂⁺Cl⁻；PhN₂⁺Cl⁻ + 甲苯（弱酸性介质）→对甲基偶氮苯（Ph-N=N-C₆H₄-CH₃，偶氮基进入甲基的对位，因为甲基为邻对位定位基）。

### 竞赛训练要点
- 练习利用兴斯堡反应鉴别不同级别胺
- 设计利用重氮盐进行官能团转化的合成路线
- 比较不同胺和酚的碱性/酸性强弱
- 掌握氨基保护-去保护策略在合成中的应用
- 练习偶联反应产物的预测
