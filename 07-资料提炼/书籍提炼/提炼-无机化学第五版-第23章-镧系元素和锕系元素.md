**本章定位**：f 区元素 + 核化学。镧系收缩是贯穿全书的重要结构规律；稀土分离提纯与用途是情境化题目素材；核化学为原子结构专题补充。竞赛重点：镧系收缩的后果、氧化数规律（全空/半满/全满稳定性）、稀土分离方法、U 的氧化态电势图。

## 三、教学逻辑锚点

1. **镧系收缩是纲**：4f 屏蔽差 → 半径缓缩 → 三大后果（①第三过渡系≈第二过渡系性质相似 ②镧系彼此相似难分离 ③离子半径收缩更显著）——串起 Ch20/21/22 中 Zr-Hf、Nb-Ta、Mo-W、Ru-Os、Rh-Ir、Pd-Pt 的相似性。
2. **氧化数 = 稳定构型驱动**：4f⁰（La³⁺）、4f⁷（Gd³⁺）、4f¹⁴（Lu³⁺）最稳定；Ce/Tb 多失一电子趋近稳定 → +4；Eu/Yb 少失一电子 → +2。与 d 区高氧化态逻辑呼应。
3. **颜色 = f-f 跃迁**：f^x 与 f^14-x 颜色相近（镜像），La³⁺/Lu³⁺/Ce³⁺/Yb³⁺ 无色；Ce⁴⁺ 橙红是电荷迁移。对比 Ch22 中 d-d 跃迁与电荷迁移。
4. **分离 = 性质微差放大**：复盐溶解度→分组；氧化态突变（Ce→+4、Eu→+2）→ 选择性分离；萃取/离子交换 → 工业。是"元素相似性"最经典的工艺应对。
5. **锕系 vs 镧系**：5f 轨道成键强 → 高价态多、共价性强；Ac/Th/Pa/U 曾被误认为 ⅢB~ⅥB。
6. **核化学三律**：衰变（自发）、裂变（重核分裂+临界质量）、聚变（轻核聚合+高温）——链接能量与元素合成。

## 四、核心内容提炼

### 23.1 镧系元素（La 57 ~ Lu 71，用 Ln 表示）

#### 1. 基本性质与镧系收缩
- 核内每加一质子 → 一个电子进入 4f 轨道；**4f 对核电荷屏蔽大** → 有效核电荷增加缓慢 → 最外层电子受核引力缓慢增加 → 原子/离子半径缓慢减小。**La→Lu 原子半径累积递减约 9 pm = 镧系收缩**。
- 收缩后果：①镧系后的第三过渡系与第二过渡系半径/化学性质相近，分离困难；②镧系元素间半径相近、性质相似、易共生、难分离；③**离子半径收缩比原子半径更显著**。
- **氧化数**：+3 最常见最稳定（I₁+I₂+I₃ 之和小的根本原因）；Ce/Pr/Tb 有 +4；Sm/Eu/Yb 有 +2。
  - La³⁺(4f⁰)、Gd³⁺(4f⁷)、Lu³⁺(4f¹⁴) = 全空/半满/全满稳定。
  - Ce（比 La 多 1 个 4f）、Tb（比 Gd 多 1 个）→ 再失 1e⁻ 成稳定构型 → +4。
  - Eu（比 Gd 少 1 个）、Yb（比 Lu 少 1 个）→ 少失 1e⁻ 成稳定构型 → +2。
- **M³⁺ 颜色（f-f 跃迁）**：f⁰/f¹⁴ 无跃迁无色（La³⁺/Lu³⁺）；f¹/f¹³ 吸收在红外区无色（Ce³⁺/Yb³⁺）；f²/f¹² 绿（Pr³⁺/Tm³⁺）；f³f⁴f⁵/f¹⁰f¹¹ 浅红黄；f⁶f⁷f⁸ 紫外吸收无色或带粉红。**f^x 与 f^14-x 颜色相同/相近（镜像规律）**。
- 电荷迁移：高氧化态金属 + 还原性配体 → 配体到金属电荷迁移，如 f⁰ 的 Ce⁴⁺ 橙红。
- 磁性：f¹~f¹³ 原子/离子均顺磁（未成对电子）。
- 应用举例：掺 Nd₂O₃ 玻璃红、Pr₂O₃ 玻璃绿（随光源变色）。

#### 2. 金属单质
- 银白、软、延展好、抗拉强度低。
- 化学活泼：次于ⅠA/ⅡA，**比 Al 活泼**；金属性随原子序数增大基本减弱 → La 最活泼。
- 缓慢氧化 → 隔绝空气保存。与 O₂：`4Ln+3O₂=2Ln₂O₃`；Ce→CeO₂；Pr/Tb → 非化学计量 Pr₆O₁₁/Tb₄O₇（H₂ 可还原为 Ln₂O₃）。
- 加热与多数非金属化合（三卤化物）；冷水缓慢、热水较快置换氢；易溶稀酸、不溶于碱。

#### 3. 氢化物（过渡型）
- 介于离子型与间充型之间的过渡型氢化物；`LnHₓ`（0<x≤3）。
- LnH₂（除 YbH₂/EuH₂）为金属导体：可写 Ln³⁺(e⁻)(H⁻)₂（自由电子）；接近 LnH₃ 为半导体：Ln³⁺(H⁻)₃（无自由电子）。
- **LaNi₅ 储氢合金**：1 g 几个大气压下吸 >100 mL H₂，减压即放（衔接 Ch18 储氢材料）。

#### 4. 氧化物与氢氧化物
- Ln₂O₃（+3 最常见）：难溶水/碱，易溶强酸；酸中溶解性随离子半径减小而减弱，**随灼烧温度升高而减弱**。Y₂O₃ 极易溶盐酸（高温熔融后仍溶）。
- **+4 氧化物强氧化性**：E°(Ce⁴⁺/Ce³⁺)=1.72V、E°(Pr⁴⁺/Pr³⁺)=3.2V、E°(Tb⁴⁺/Tb³⁺)=3.1V。
  - `2CeO₂+8HCl=2CeCl₃+4H₂O+Cl₂↑`（氧化 Cl⁻）
  - PrO₂ 只能存在于固体，还能氧化水放 O₂：`4PrO₂+6H₂O=4Pr(OH)₃+O₂↑`
  - `2Tb₄O₇+24HCl=8TbCl₃+12H₂O+O₂↑`（Tb(IV) 氧化水）
- **Ln(OH)₃**：碱性与碱土金属氢氧化物相近；碱性随原子序数递减；Yb(OH)₃/Lu(OH)₃（半径小、φ 大）高压浓 NaOH 共热 → Na₃[Yb(OH)₆]/Na₃[Lu(OH)₆]（羟基酸盐，体现两性趋势）。溶解度远小于碱土氢氧化物，随原子序数递减。
- Ln(OH)₃ 加热 → LnO(OH) → Ln₂O₃。

#### 5. 盐类
- **氯化物**：易溶水、潮解、溶解度随温度显著升高；水合氯化物受热脱水水解 → `LnCl₃·nH₂O = LnOCl + 2HCl↑ + (n-1)H₂O`（需 HCl 气氛保护脱水）；氧化氯化法加碳热力学耦合 `Ln₂O₃+3C+3Cl₂=2LnCl₃+3CO`；**最佳方法是金属直接氯化**。
- **含氧酸盐**：硫酸盐溶解度规律——按 Ce→Pr→Nd→Sm→Eu 递减、按 Gd→Tb→Dy→Ho→Er→Tm→Yb→Lu 递增；硝酸盐受热 → 碱式硝酸盐 → 氧化物；**草酸盐难溶水也难溶稀酸 → 用于与多种金属离子分离**（Ln₂(C₂O₄)₃·nH₂O 从稀酸析出）；草酸盐灼烧经碳酸盐中间产物 → 氧化物。
- 硫酸盐/硝酸盐能与碱金属（或碱土金属/铵）形成复盐，复盐溶解度差异大 → 分离用。

#### 6. 配位化合物
- Ln³⁺ 电荷高 → 配位能力强于碱土金属；**典型硬酸** → 易与 F/O 配位原子成键（羧酸、β-二酮等含氧化合物）；与软碱 N/S/Cl/Br/I 配位差（仅在适当极性非水介质可得含氮配合物）；稳定配合物多为螯合物。
- **半径大、外层空轨道多 → 配位数大，6~12**。
- 配合物形成对稀土分离提取极重要。

#### 7. 稀土分离提纯
- **稀土元素（RE）= 镧系 15 种 + Sc + Y 共 17 种**。铈组（轻稀土）：La Ce Pr Nd Pm Sm Eu；钇组（重稀土）：Gd-Lu + Y + Sc。
- 发现史：1794 加多林"钇土"；1803"铈土"；1879 镱土/钪土；1945 Pm 于铀裂变产物（1965 天然高品位铀矿中发现）。
- **地壳丰度：Ce 最高 6.8×10⁻³%（比 Cu 高）**；其次 Nd/La/Y；Lu/Tm 也比 Ag/Hg 高；仅 Pm 痕量 → **"稀土不稀"但分散难分**。独居石最重要稀土磷酸盐矿物；我国稀土储量世界第一。
- 与非稀土分离：选矿 → 氯化法/硫酸法/NaOH 法。独居石 + NaOH → `REPO₄+3NaOH=RE(OH)₃↓+Na₃PO₄`；调节 pH 溶稀土氢氧化物，pH=4.5 煮沸 1h 沉 Th/U/Fe。
- **① 化学法**（溶解度微差重结晶）：硫酸复盐分三组——难溶 La/Ce/Pr/Nd/Sm、微溶 Eu/Gd/Tb/Dy、可溶 Ho/Er/Tm/Yb/Lu/Y；硝酸盐 + NH₄NO₃ 复盐溶解度差异重结晶。**Ce 分离靠价态突变**：`2Ce(OH)₃+Cl₂+2OH⁻=2Ce(OH)₄+2Cl⁻`，Ce(OH)₄ 碱性弱，pH=3 沉淀而其余 RE(III) 溶解。**Eu 分离靠还原**：`2Eu³⁺+Zn=2Eu²⁺+Zn²⁺`，氨水沉 RE(OH)₃ 而 Eu²⁺ 留溶液。
- **② 萃取法**（工业主力，单稀土纯度>99%）：中性络合萃取（磷酸三丁酯 TBP，萃硝酸盐）、酸性络合萃取（羧酸/酸性磷酯，置换 H⁺ 配位）、离子缔合萃取（季铵盐，形成 (R₄N)ₙLn(NO₃)₃₊ₙ）。
- **③ 离子交换法**：阳离子树脂交换（`3[RSO₃H]+Ln³⁺=(RSO₃)₃Ln+3H⁺`），结合力强居柱上部；淋洗液反复交换/淋洗分离。

#### 8. 稀土用途
- **发光材料**：荧光（激发停止发射即停）vs 磷光（持续）。红粉：YVO₄:Eu³⁺ → Y₂O₃:Eu³⁺ / Y₂O₂S:Eu³⁺（亮度高色彩纯，彩电唯一红粉）；日光灯粉、CT 探测器含稀土。**上转换材料**：磷光 hν'>hν，红外→可见光，军事夜视。
- **永磁材料**：一代 SmCo₅（70s 商品化）→ 二代 Sm₂Co₁₇ → 三代 **Nd₂Fe₁₄B**（廉铁代钴，80s）；用于聚焦环/电机转子/无摩擦磁轴承等。

### 23.2 锕系元素（Ac 89 ~ Lr 103）

#### 1. 基本性质与氧化态
- **只有 Ac/Th/Pa/U 4 种存在于自然界**（Ac/Pa 痕量）；Th 地壳 1.2×10⁻³%（略少于 Pb，与 La/Ce 共生磷酸盐矿物）；U 2.4×10⁻⁴%（略多于 Sn，U₃O₈ 于沥青铀矿）。**全部放射性**；银白金属，熔点/密度稍高于镧系。
- 氧化态：5f 轨道可参与成键 → 形成较稳定高价态（Pa/U/Np/Pu/Am 水溶液多种氧化态）；**从 Cm 开始稳定 +3**（5f 与 6d 能量差变大，5f 不易成键）。**5f 轨道比 4f 成键能力强 → 锕系化合物共价性更强**。
- Ac(+3)、Th(+4)、Pa(+5)、U(+6) 各自价电子全用成键 → 历史上曾误认为 ⅢB~ⅥB 第七周期元素。
- 表 23-2 常见氧化数：U +3/+4/+5/+6（+6 最稳）；Np/Pu +3~+7；Am +3~+6（+2 固相）。

#### 2. 铀及其化合物
- 软银白活泼金属，密度与金相近，最稳定 +6；溶液 U(VI) 以 **UO₂²⁺ 铀氧根**存在（黄绿荧光，水解）。
- 制备：`UF₄+2Mg 700℃= U+2MgF₂`（活泼金属还原）。
- 化学活泼：粉末空气自燃（甚至水中）；氧化产物 UO₂/U₃O₈；加热与非金属 → US₂/UH₃/UN/UClₓ。
- 水蒸气：`7U+6H₂O(g) 250℃= 3UO₂+4UH₃`；溶硝酸 `U+2HNO₃+2H₂O=UO₂(NO₃)₂+3H₂↑`（结晶亮黄 UO₂(NO₃)₂·6H₂O）；溶盐酸 `2U+6HCl=2UCl₃+3H₂↑`；碱+H₂O₂ → 过铀酸盐。
- **氧化物**：UO₂ 棕（核动力堆燃料，制 UF₄ 原料；H₂ 还原高价氧化物制得，隔绝空气溶强酸 → 绿色 U(IV) 盐）；U₃O₈ 黑/暗绿橄榄绿**最稳定**（`6UO₃ >500℃= 2U₃O₈+O₂`）；UO₃ 橙黄两性（`2UO₂(NO₃)₂·6H₂O 300-370℃= 2UO₃+4NO₂+O₂+12H₂O`；`UO₃+2HNO₃=UO₂(NO₃)₂+H₂O`）。
- 重铀酸盐：`2UO₂(NO₃)₂+6NH₃+3H₂O=(NH₄)₂U₂O₇↓+4NH₄NO₃`（亮黄，灼烧→UO₃）；Na₂U₂O₇·6H₂O（脱水 → **铀黄**）。
- **卤化物**：UBr₃ 红；UCl₃/UF₄/UCl₄/UCl₆ 绿；UF₅ 淡蓝；UF₆ 白；UBr₄/UBr₅/UCl₅ 棕；UF₃/UI₃/UI₄ 黑。**UF₆ 最重要**：正八面体、56.5℃ 升华；`UF₄+F₂ 300℃= UF₆`；干燥空气稳定，潮湿水解 HF（不能用玻璃器皿）；`2UF₆+14NaOH=Na₂U₂O₇+12NaF+7H₂O`。
- **原子能**：²³⁵U 丰度 0.720%；基于 ²³⁵UF₆/²³⁸UF₆ 蒸气扩散速率差分离。

#### 3. 钍及其化合物
- 灰白活泼金属，密度与铅相近，加工性好；最稳定 +4；块状稳定、粉状不稳定；加热与非金属 → ThO₂/ThH₃/ThN/ThC。
- 稀硝酸缓慢、浓硝酸钝化；熔融 NaOH 不反应、熔融 KHSO₄ 反应快。
- Th⁴⁺ 固体/溶液均可（[Th(H₂O)ₙ]⁴⁺）；+NaOH → 白 Th(OH)₄。
- **ThO₂：白色，熔点 3350℃，熔点最高的氧化物**；高温灼烧后仅缓慢溶于硝酸+HF 混合酸。
- 用途：²³²Th（天然丰度 100%）+ 中子 → ²³³Th → 两次 β 衰变 → **²³³U 核裂变材料**（解决 ²³⁵U 不足）。

#### 4. 超铀元素与核化学
- **历史**：1896 贝克勒放射性 → 1919 卢瑟福 α 轰 N→O（`¹⁴₇N+⁴₂He=¹⁷₈O+¹₁H` 首次元素嬗变）→ 1932 查德维克中子（`⁹₄Be+⁴₂He=¹²₆C+¹₀n`）→ 1934 约里奥·居里人工放射性（`²⁷₁₃Al+⁴₂He=³⁰₁₅P+¹₀n`，³⁰P → ³⁰Si + 正电子）→ 1938 哈恩核裂变 → 1940 超铀 Np → 1961 Lr（表 23-3 全程）。
- **核衰变**：α/β/γ 三种；半衰期从几秒到几十亿年；原子序数 >83 均放射性。
- **核裂变**：重核受粒子轰击分裂为两碎片；²³⁵U + 慢中子 → 两碎片（Z 21~67）+ 2~3 中子 + 能量；**1 mol ²³⁵U 裂变 ≈ 2.1×10¹³ J ≈ 10000 t 煤**。**临界质量**：超过则中子被其他核俘获 → 爆炸性链式反应（原子弹：两小块各小于临界质量，合并超临界引爆）；反应堆用镉棒吸收中子维持增殖倍数 ≈1。
- **核聚变**：轻核聚合放能；`²₁H+²₁H=³₂He+¹₀n`（3.25 MeV）；`²₁H+²₁H=³₁H+¹₁H`（4.00）；`³₁H+²₁H=⁴₂He+¹₀n`（17.6）；`³₂He+²₁H=⁴₂He+¹₁H`（18.3）；**6 ²H = 2 ⁴He + 2 ¹H + 2 n，43.15 MeV**（平均每 ²H 约 7.2 MeV）。需要 ~10⁸℃（太阳热核反应）；人工实现仅氢弹/加速器高能粒子碰撞。
- **人造元素与幻数**：118 个位置填满；**幻数 2,8,20,28,50,82,126**；²⁰⁸Pb（Z=82,N=126）特别稳定；推测质子幻数 114/164、中子幻数 184/196/228/272/318 → Z=114、N=184 可能稳定。半衰期随原子序数迅速缩短（104 号最长 65s；107 号 2×10⁻³s）。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **23-2/23-3**：CeO₂+HCl、Tb₄O₇+HCl、Eu³⁺+Zn、U+HNO₃、UF₆+NaOH 等配平。
- **23-5(1)**：稀土离子与其他金属离子分离（草酸盐法）。
- **23-5(2)**：化学法分离 Ce³⁺（氧化 Ce(OH)₄ 沉淀）。
- **23-5(3)**：²³⁵U/²³⁸U 分离原理（UF₆ 扩散速率差）。
- **23-5(4)**：鉴别 LaCl₃ vs ZnCl₂（草酸盐难溶性/沉淀性质）。
- **23-7(1)**：预言 119 号元素性质（周期表位置、与水反应、氧化物、卤化物稳定性、晶体类型）。
- **23-7(2)**：Z=114、N=184 核素推断（位置/相对原子质量/价层构型/相似元素——Pb 类）。
- **23-7(3)**：铀化合物连环推断（U→UO₂→UF₄→UF₆→Na₂U₂O₇→UO₃→U₃O₈ 全链）。
- **23-8(4)**：La³⁺/Gd³⁺/Lu³⁺ 无色 vs Pr³⁺/Sm³⁺ 有色（f-f 跃迁）。
- **23-8(7)**：U 元素电势图 → 最稳定氧化态/歧化/空气稳定性分析。

### 常见错误模式
1. **镧系收缩方向**：是半径"缓慢减小"不是增大；4f 屏蔽大导致有效核电荷增加慢。
2. **氧化数归因**：Eu/Yb 的 +2 与 Ce/Tb 的 +4 都源于"趋近 f⁰/f⁷/f¹⁴"，不要与 d 区混淆。
3. **+4 氧化物氧化性**：PrO₂/Tb₄O₇ 氧化水放 O₂（不是只氧化 Cl⁻）；E°(Pr⁴⁺/Pr³⁺)=3.2V 极高。
4. **Ln(OH)₃ 碱性**：随原子序数递减；Yb(OH)₃/Lu(OH)₃ 高压浓 NaOH 可溶（不是强两性）。
5. **水合氯化物脱水**：必须 HCl 气氛（防 LnOCl 水解），类比 MgCl₂·6H₂O 等。
6. **草酸盐**：难溶水+难溶稀酸 → 分离依据；灼烧经碳酸盐（Lегкие中间产物）再成氧化物。
7. **UO₂²⁺ 命名**：铀氧根/铀酰，不是简单 U(VI) 阳离子；黄绿荧光。
8. **UF₆**：潮湿水解 HF，不能用玻璃容器；正八面体。
9. **核聚变 vs 裂变**：聚变是轻核合成、需 10⁸℃；裂变是重核分裂、需临界质量。
10. **幻数**：2,8,20,28,50,82,126（质子/中子双幻数 ²⁰⁸Pb 最稳）。
