# Clayden 第6章：对羰基的亲核加成 资料提炼

---

## 一、核心概念与定义

### 1.1 羰基的结构与反应性
- **C=O 双键组成**：σ 键（sp²-sp² 头碰头重叠）+ π 键（肩并肩 p 轨道重叠）。
- **平面构型**：sp² 杂化 → 整个羰基平面三角形，碳上取代基键角 ≈120°。
- **π 键极化**：氧电负性（3.5）> 碳（2.5）→ π 电子偏向氧 → 碳带部分正电 → [[亲核体与亲电体|亲核进攻位点]]。
- **π* 反键轨道极化**：方向相反，碳端占比更大 → 亲核试剂 HOMO 与 π* LUMO 相互作用 → 电子流入碳端 → π 键断裂 → π 电子转移到氧上。

### 1.2 亲核加成的通用机理
- **两步过程**：① 亲核试剂进攻碳原子（形成新 C-C σ 键，断开 C=O π 键）；② 氧负离子质子化。（见 [[亲核加成]]）
- **轨道解释**：亲核试剂 HOMO（sp、sp³、B-H σ、M-C σ 等）→ 羰基 π* LUMO → 新 σ 键形成 + π 键断裂。
- **sp² → sp³ 转变**：羰基碳由平面三角形变为四面体。

### 1.3 Bürgi-Dunitz 轨道角
- **定义**：亲核试剂从 C=O 键的 107° 方向进攻（而非垂直于羰基平面）。
- **原因**：π* 轨道因波节存在，碳端已偏离平面 → 沿 HOMO 大轨道方向进攻 → HOMO-π* 最大重叠，HOMO-π 最小排斥。
- **意义**：空阻对 Bürgi-Dunitz 轨迹的阻碍会大幅降低加成速率（醛比酮活泼的另一原因）。

### 1.4 空间效应与电子效应
- **空间效应（Steric Effects）**：取代基大小影响反应性。sp²→sp³ 使键角从 120° 降至 109°，大取代基间排斥增加 → 醛（H 很小）比酮更易加成。
- **电子效应**：
  - **诱导效应**：σ 键极化（如卤素吸电子 → 羰基更极化 → 碳更正 → 更活泼）。
  - **共轭效应**：π 键中电子分布（下一章详述，见 [[共轭效应]]）。

## 二、重要反应与机理

### 2.1 氰根对醛酮的加成——氰醇形成

#### 反应特征
- **反应物**：[[醛酮]]/酮 + NaCN（或 HCN/NaCN 缓冲液）
- **产物**：氰醇（cyanohydrin），R₂C(OH)CN
- **机理**：CN⁻ 的 sp 杂化碳 HOMO → C=O π* → 新 C-C 键 + π 键断裂 → 氧负离子质子化
- **可逆性**：氰醇可水解回醛/酮（碱催化更完全）

#### 影响平衡的因素
- **空间因素**：醛比酮平衡常数更大（sp²→sp³ 键角减小对大取代基不利）
- **电子因素**：吸电子基 → 羰基更活泼 → 平衡偏向产物
- **环张力**：环丙酮/环丁酮加成释放环张力 → 特别活泼

#### 合成应用
- 药物中间体：5-HT₃ 受体拮抗剂（化疗止吐药）的合成起始步
- 天然产物：杀虫剂氯氰菊酯的组成部分
- 转化为 α-羟基酸（CN 水解）或 α-氨基醇（CN 还原）
- 亚硫酸氢钠法：先形成亚硫酸氢盐加合物 → 再与 NaCN 反应 → 安全制备氰醇（避免 HCN 释放）

### 2.2 硼氢化钠还原——"负氢"亲核进攻

#### 核心概念
- **真正的 H⁻ 不可行**：NaH 中 H⁻ 电荷密度过高，只能做碱（1s 轨道太小，无法与 π* 重叠）。
- **"负氢转移"**：NaBH₄ 中 B-H σ 键的电子对作为亲核体，氢带着一对电子转移到碳上（并非真正 H⁻）。
- **BH₄⁻ 结构**：四面体 BH₄⁻，与 CH₄ 等电子体，但带负电荷（硼少一个质子）。
- **箭头要点**：箭头从 B-H 键出发（而非从负电荷），否则会得到不可能的五价 B(V)。

#### NaBH₄ 特征
- **选择性**：还原醛/酮，不还原酯/酰胺/硝基/卤代烷
- **活性差异**：苯甲醛还原速率比乙酰苯快 400 倍（空阻效应）
- **条件**：可在水/醇中使用（弱负氢供体）
- **产物**：醛 → 伯醇；酮 → 仲醇

#### LiAlH₄ 对比
- 更强的负氢供体，活性更高
- **危险性**：剧烈与水反应，放热产生易燃 H₂
- **条件**：必须无水操作（干燥惰性气氛，-78°C，Et₂O 或 THF 溶剂）
- NaBH₄ 不能还原的酯/酰胺，LiAlH₄ 可还原

### 2.3 有机金属试剂加成——构建 C-C 键

#### 有机锂试剂（RLi）
- **结构**：C-Li 键高度极化（C 2.5, Li 1.0）→ 碳为亲核位点（见 [[有机锂试剂]]）
- **反应**：R-Li + [[醛酮|醛]] → 仲醇；R-Li + [[醛酮|酮]] → 叔醇
- **条件**：低温（-78°C），非质子溶剂（Et₂O/THF），惰性气氛（N₂/Ar）
- **后处理（Work-up）**：反应完成后加 H₂O 或 NH₄Cl 水溶液质子化
- **关键**：必须无水！水会质子化 RLi → 烷烃（破坏试剂）

#### 格氏试剂（RMgX）
- **制备**：卤代烃 + Mg 金属（"旋转的"反应）（见 [[Grignard试剂]]）
- **反应**：与有机锂类似，加成到 C=O → 醇
- **历史**：Victor Grignard 发现，1912 年诺贝尔化学奖
- **重要性**：有机锂和格氏试剂是构建 C-C 键最重要的反应之一

### 2.4 水的加成——水合反应

#### 基本特征
- **反应物**：醛/酮 + H₂O
- **产物**：水合物（hydrate），即 1,1-二醇
- **机理**：中性 H₂O 亲核进攻 C=O（水的氧孤对电子为 HOMO）→ 质子转移
- **NMR 证据**：甲醛水溶液中 ¹³C NMR 信号在 83 ppm（sp³ 碳），非 150-200 ppm（C=O）

#### 平衡与结构因素
- **简单醛**：部分水合（如甲醛几乎完全水合）
- **简单酮**：几乎不水合（空阻大）
- **加速水合的因素**：
  - 吸电子基（如 CCl₃-）→ 诱导效应使碳更正电性
  - 小环酮（环丙酮/环丁酮）→ 释放环张力（sp²→sp³ 键角更接近 60°）
- **六氟丙酮**：最易水合的羰基化合物（强吸电子）

#### 甲醛特殊性
- 无取代基 → 空阻极小 → sp²→sp³ 键角变化对两个 H 影响微弱 → 极易水合
- 水溶液中基本不含 CH₂O 单体
- 无水条件：用多聚甲醛（paraformaldehyde）加热解聚

### 2.5 醇的加成——半缩醛形成

#### 反应特征
- **反应物**：醛 + ROH（通常为醇）
- **产物**：[[半缩醛]]（hemiacetal），R₂C(OR)(OH)
- **机理**：与水合相同，只是 ROH 替代 HOH
- **可逆性**：酸催化下可继续反应变为[[缩醛]]（acetal）—— Chapter 11 详述

#### 环状半缩醛（内半缩醛/Lactol）
- **分子内反应**：当 OH 与 C=O 在同一分子内时，分子内加成更利
- **环大小影响**：五元/六元环无张力 → 稳定 → 常见
- **糖化学**：葡萄糖主要以六元环半缩醛存在（>99%）；核糖以五元环半缩醛存在

### 2.6 酸和碱催化半缩醛/水合物形成

#### 酸催化机理
1. 羰基孤对电子质子化 → 碳更正电性 → 更易受亲核进攻
2. 亲核试剂加成
3. 去质子化
- **酸在反应结束时再生** → 真正的催化剂

#### 碱催化机理
1. 碱（OH⁻）去质子化醇 → 生成烷氧基阴离子 → 亲核性更强
2. 烷氧基阴离子加成到 C=O
3. 碱在最后一步再生
- **碱在反应结束时再生** → 真正的催化剂

#### 核心结论
- 酸催化：使羰基更亲电
- 碱催化：使亲核试剂更亲核
- 缩醛只能在酸中形成，不能在碱中形成

### 2.7 亚硫酸氢钠加成

#### 反应特征
- **反应物**：醛/酮 + NaHSO₃（亚硫酸氢钠）
- **亲核位点**：硫原子孤对电子（S 为第三周期元素，有 d 轨道）
- **产物**：亚硫酸氢盐加合物（bisulfite addition compound），通常为晶体

#### 用途
1. **纯化醛**：液态醛 → 晶体加合物 → 重结晶 → 酸/碱水解回收纯醛
2. **水溶性**：加合物水溶性好 → 药物化学中的重要策略（如达普松的水溶性前药制备）

#### 亚硫酸氢盐路线制备氰醇
- 丙酮 + NaHSO₃ → 亚硫酸氢盐加合物 → + NaCN → 氰醇（产率 70%）
- 优势：避免 HCN 释放（安全）

## 三、关键结论与规则

### 3.1 羰基亲核加成的通用规律
1. 亲核试剂从 Bürgi-Dunitz 角（107°）进攻碳原子
2. HOMO(LuMO) 相互作用 → 新 C-C 键 + π 键断裂
3. sp² 碳 → sp³ 碳（平面 → 四面体）
4. 所有反应均为可逆（平衡受结构因素控制）

### 3.2 醛 vs 酮的反应性差异
| 因素 | 醛 | 酮 |
|:---|:---|:---|
| 空间位阻 | H 很小，空阻小 | 两个烷基，空阻大 |
| 键角变化影响 | 120°→109° 影响小 | 120°→109° 大取代基排斥大 |
| 平衡常数 | 较大（偏向产物） | 较小（偏向反应物） |
| 反应活性 | 更高 | 较低 |

### 3.3 羰基反应活性排序（水合平衡常数）
- 最活泼：六氟丙酮（强吸电子）> 环丙酮/环丁酮（环张力）> 三氯乙醛 > 甲醛 > 其他醛
- 最不活泼：大位阻酮（如二叔丁基酮）

### 3.4 有机金属试剂操作要点
| 要点 | 说明 |
|:---|:---|
| 溶剂 | 非质子溶剂（Et₂O, THF） |
| 温度 | 低温（-78°C 常用） |
| 气氛 | 惰性气体（N₂/Ar），因 RLi/RMgX 也与 O₂ 反应 |
| 后处理 | 反应完成后加 H₂O 或 NH₄Cl(aq) |
| 禁忌 | 绝对无水（水会质子化试剂 → 烷烃） |

### 3.5 催化剂总结
- **酸催化**：质子化 C=O → 碳更正电性 → 加速亲核进攻
- **碱催化**：去质子化亲核试剂 → 亲核性更强 → 加速加成
- 两种催化剂均在反应结束时再生

## 八、摘录的原始段落（附页码/位置标记）

### 8.1 关于羰基的 MO 解释（lines 4362-4408）
> "羰基，出现于醛、酮以及很多其他化合物中，它无疑是有机化学中最重要的官能团。"
> "反应分两个步骤进行：首先是氰根的亲核进攻，接着是阴离子的质子化。事实上，这是所有羰基亲核加成的普遍特征。"
> "未填充的 π* 反键轨道所偏向的方向与之相反，在碳原子的一端有更大的占比。"
> "当我们的亲核试剂接近碳原子时，它 HOMO 上的孤对电子就开始与 LUMO（π* 反键轨道）相互作用并形成一个新的 σ 键。填充一根共价键的反键轨道会断裂该键。"

### 8.2 关于 Bürgi-Dunitz 角（lines 4450-4464）
> "亲核试剂不是从垂直于羰基平面的方向进攻，而是从 C=O 键的 107° 处进攻——也就是新键形成的角度。"
> "这种对进攻角度的要求被称为 Bürgi-Dunitz 轨道角，以通过美妙的晶体学方法揭示这一特点的两位科学家命名。"
> "更好的理解是由于波节的存在，碳原子上的 π* 轨道无法与相邻轨道保持平行，因此原子轨道本身已经成了一定的角度。"

### 8.3 关于空间效应（lines 4434-4438）
> "随着羰基碳原子从 sp² 变化到 sp³，其键角从 120° 左右变化到 109° 左右——也就是说，产物中两个取代基靠得更近。"
> "空间位阻（并不是'阻碍'）是烷基取代基上，占据充满轨道的电子之间排斥的结果。"

### 8.4 关于"负氢"不可行（lines 4466-4472）
> "负氢离子的亲核进攻，是一个几乎未知的反应。它充满的 1s 轨道，有与 H-X 键 σ 轨道中氢原子的贡献——理想的大小，但相比于 C=O 基的 LUMO（π*）2p 轨道中碳较分散的轨道的贡献，就太小了。"

### 8.5 关于 NaBH₄ 的选择性（lines 4508-4510）
> "硼氢化钠并不会与活性较弱的羰基化合物，例如酯或酰胺反应：如果一个分子同时包含醛基和酯基，那么仅醛基会被还原。"

### 8.6 关于有机金属试剂操作（lines 4526-4530）
> "'2. H₂O'的意思是，仅当 MeLi 已经反应完，才能加入水。在 MeLi（或其他有机金属试剂）对羰基的加成反应中，必须不能有水的存在，因为水会非常快速地通过将有机金属试剂质子化为烷烃来摧毁它们。"
> "反应结束后，水，或稀酸，或氯化铵的加入，被称为后处理（work-up）。"

### 8.7 关于水合平衡（lines 4578-4607）
> "有利或无利于水合物形成的相同结构因素，在确定羰基对于其他亲核试剂，无论反应可逆与否的情况下都是重要的。"
> "六氟丙酮大概是最易水合的羰基化合物！"
> "环丙酮——三元环酮——也同样会显著程度地水解，但这是不同的原因所致。"

### 8.8 关于酸碱催化（lines 4647-4681）
> "酸催化剂通过使羰基更亲电而工作；碱催化剂通过亲核试剂更亲核而工作；两种催化剂都在反应结束时重新生成。"
> "在酸中，第一步是羰基孤对电子的质子化，随之带上的正电荷使之更加亲电，因此加成反应变快。"
> "在碱性溶液中的第一步是乙醇被氢氧根的去质子化，通过使乙醇更加亲核，而加速加成反应。"

### 8.9 关于亚硫酸氢钠（lines 4686-4700）
> "反应通过硫的孤对电子对羰基的亲核进攻发生。它们通常是晶体，因此可以通过重结晶来纯化液态的醛。"
> "NaHSO₃ 的结构相当有趣。它是一种硫(IV)化合物的氧阴离子。作为第三周期元素，硫可具有多于八个电子——S 或 P 不像 B 或 O，它们可以成四、五、或六根键。"

## 九、竞赛题型线索

### 9.1 产物预测型
- 给定醛/酮 + 亲核试剂（CN⁻、RMgX、RLi、NaBH₄、H₂O、ROH、NaHSO₃），预测加成产物。
- 预测水合平衡的位置（给定取代基类型判断）。

### 9.2 机理书写型
- 书写羰基亲核加成的两步机理（亲核进攻 + 质子化）。
- 区分酸催化与碱催化机理的差异。
- 书写 NaBH₄ 还原的箭头（从 B-H 键出发，不是从负电荷）。
- 书写格氏试剂加成 + 后处理的完整过程。

### 9.3 反应活性判断型
- 比较不同醛/酮对亲核加成的活性（空间 + 电子因素）。
- 比较 NaBH₄ vs LiAlH₄ 的活性与选择性。
- 判断哪些羰基化合物会被水合（平衡常数）。

### 9.4 合成设计型
- 逆合成分析：目标醇 → 切断 C-C 键 → 识别格氏试剂 + 醛/酮。
- 氰醇路线：醛/酮 → 氰醇 → α-羟基酸（水解）或 α-氨基醇（还原）。
- 亚硫酸氢钠纯化策略：液态醛 → 晶体加合物 → 重结晶 → 回收纯醛。

### 9.5 立体化学型
- Bürgi-Dunitz 角对立体选择性的影响（Chapter 33 中更详细）。
- 环状半缩醛的构象分析（葡萄糖的椅式构象）。

### 9.6 条件选择型
- 有机金属试剂：为什么必须无水、低温、惰性气氛？
- NaBH₄ vs LiAlH₄：何时用哪个？（选择性 vs 活性）
- 酸催化 vs 碱催化：缩醛只能在酸中形成。
