# 提炼-傅献彩物理化学-动力学与复杂反应计算

> **模块定位**：对标中国化学奥林匹克初赛与决赛“化学动力学与计算建模”核心考点（考纲域码：`基础-12`、`决赛-07`）。本提炼全面浓缩南京大学傅献彩《物理化学》（第六版下册）第 11~12 章关于复杂反应解析解、拟稳态近似判据、弛豫动力学、原盐效应、支链爆炸、酶动力学与化学振荡非线性建模的数理内核与高频题型。

## 一、 经典复杂反应动力学解析与极值推导

### 1. 对峙反应（Reversible Reactions）
对于对峙反应 $A \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} B$，若初始浓度为 $c_A(0) = a, c_B(0) = 0$：
- 设任一时刻 $t$ 生成 $B$ 的浓度为 $x$，平衡转化量为 $x_e$；
- 速率微分方程：
  $$\frac{\mathrm{d}x}{\mathrm{d}t} = k_1(a - x) - k_{-1}x$$
- 平衡时 $\frac{\mathrm{d}x}{\mathrm{d}t} = 0 \implies k_1(a - x_e) = k_{-1}x_e \implies K_c = \frac{k_1}{k_{-1}} = \frac{x_e}{a - x_e}$；
- 整理得：
  $$\frac{\mathrm{d}x}{\mathrm{d}t} = (k_1 + k_{-1})(x_e - x)$$
- 分离变量积分得标准一阶对峙速率积分方程：
  $$\ln\frac{x_e}{x_e - x} = (k_1 + k_{-1})t \iff x = x_e\left[1 - \mathrm{e}^{-(k_1 + k_{-1})t}\right]$$
- **动力学特征**：表观速率常数等于正、逆反应速率常数之和 $k_{\mathrm{obs}} = k_1 + k_{-1}$。

### 2. 平行反应（Parallel Reactions）
对于反应物 $A$ 经两条单分子路径平行转化：
$$A \xrightarrow{k_1} B, \quad A \xrightarrow{k_2} C$$
- 微分方程：
  $$-\frac{\mathrm{d}c_A}{\mathrm{d}t} = (k_1 + k_2)c_A \implies c_A(t) = c_{A,0}\mathrm{e}^{-(k_1 + k_2)t}$$
- 各产物浓度演化：
  $$c_B(t) = \frac{k_1}{k_1 + k_2}c_{A,0}\left[1 - \mathrm{e}^{-(k_1 + k_2)t}\right], \quad c_C(t) = \frac{k_2}{k_1 + k_2}c_{A,0}\left[1 - \mathrm{e}^{-(k_1 + k_2)t}\right]$$
- **选择性原理**：在任何时刻，产物浓度之比严格恒等于速率常数之比：
  $$\frac{c_B(t)}{c_C(t)} = \frac{k_1}{k_2} = \frac{A_1}{A_2}\exp\left(-\frac{E_{a,1} - E_{a,2}}{RT}\right)$$
- 若 $E_{a,1} > E_{a,2}$，升高温度有利于主产物 $B$ 的生成；若 $E_{a,1} < E_{a,2}$，降低温度或选择特异性催化剂可提高产物 $B$ 的选择性。

### 3. 连续反应（Consecutive Reactions）与中间体极值分析
对于 $A \xrightarrow{k_1} B \xrightarrow{k_2} C$（一级连串反应），设 $t=0$ 时 $c_A = c_{A,0}, c_B = 0, c_C = 0$：
- 速率微分方程组：
  $$\frac{\mathrm{d}c_A}{\mathrm{d}t} = -k_1 c_A$$
  $$\frac{\mathrm{d}c_B}{\mathrm{d}t} = k_1 c_A - k_2 c_B$$
  $$\frac{\mathrm{d}c_C}{\mathrm{d}t} = k_2 c_B$$
- 各物种浓度随时间精确积分解析解：
  $$c_A(t) = c_{A,0}\mathrm{e}^{-k_1 t}$$
  $$c_B(t) = \frac{k_1 c_{A,0}}{k_2 - k_1}\left(\mathrm{e}^{-k_1 t} - \mathrm{e}^{-k_2 t}\right) \quad (k_1 \neq k_2)$$
  $$c_C(t) = c_{A,0}\left[1 - \frac{k_2}{k_2 - k_1}\mathrm{e}^{-k_1 t} + \frac{k_1}{k_2 - k_1}\mathrm{e}^{-k_2 t}\right]$$
- **中间体 $B$ 浓度极大值 $c_{B,\max}$ 与极值时间 $t_{\max}$**：
  令 $\frac{\mathrm{d}c_B}{\mathrm{d}t} = 0 \iff k_1 \mathrm{e}^{-k_1 t_{\max}} = k_2 \mathrm{e}^{-k_2 t_{\max}}$，两边取对数解得：
  $$t_{\max} = \frac{\ln(k_1 / k_2)}{k_1 - k_2}$$
  代入 $c_B(t)$ 表达式，得到中间体最大产率：
  $$c_{B,\max} = c_{A,0}\left(\frac{k_1}{k_2}\right)^{\frac{k_2}{k_1 - k_2}} = c_{A,0}\left(\frac{k_2}{k_1}\right)^{\frac{k_1}{k_2 - k_1}}$$
- **两种动力学极限情形**：
  1. 若 $k_1 \ll k_2$（第一步决速步）：$\mathrm{e}^{-k_2 t}$ 迅速衰减，$c_B(t) \approx \frac{k_1}{k_2}c_{A,0}\mathrm{e}^{-k_1 t} \ll c_A(t)$，中间体浓度极低且平缓，总速率完全由第一步控制；
  2. 若 $k_1 \gg k_2$（第二步决速步）：$A$ 瞬间全转化为 $B$，$t_{\max} \approx 0$，总反应表现为 $B$ 转化为 $C$ 的简单一级反应。

## 二、 复杂反应近似处理方法与适用判据

### 1. 拟稳态近似法（Quasi-Steady-State Approximation, QSSA）
- **核心假定**：高活性中间体（自由基、活化配合物、反应性络合物）在诱导期（Induction Period）过后，其生成速率与消耗速率几乎平衡，其浓度随时间的变化率远小于其生成速率或消耗速率：
  $$\frac{\mathrm{d}[I]}{\mathrm{d}t} \approx 0$$
- **适用严格判据**：
  中间体的消耗特征速率常数远大于生成特征速率，且其瞬时浓度与其母体相比为极小量：$[I] \ll [A]$，$\tau_{\mathrm{intermediate}} \ll \tau_{\mathrm{reaction}}$。

### 2. 平衡假设法（Pre-Equilibrium Approximation, PEA）
- **核心假定**：基元反应链的前置步骤为极快对峙反应，且后续消耗中间体的步骤极其缓慢（决速步 RDS），因此前置对峙对体系可视为维持热力学动平衡：
  $$A + B \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} I \xrightarrow{k_2} P \quad (k_{-1} \gg k_2)$$
- 快速求得 $[I] = \frac{k_1}{k_{-1}}[A][B] = K_c [A][B]$，总速率 $r = k_2 [I] = k_2 K_c [A][B]$。
- **误差边界与过渡统一**：
  若用全稳态法推导，总速率为 $r = \frac{k_1 k_2 [A][B]}{k_{-1} + k_2}$。当 $k_{-1} \gg k_2$ 时，分母中 $k_2$ 可忽略，退化为平衡假设表达式；若 $k_2 \gg k_{-1}$，则第一步转化为不可逆决速步。稳态近似具有更普适的数理包容度。

## 三、 弛豫动力学与超快反应微扰解析

对于极快可逆反应（如酸碱中和 $\mathrm{H}^+ + \mathrm{OH}^- \rightleftharpoons \mathrm{H}_2\mathrm{O}$、络合解离），常规流动法难以测定其毫秒至皮秒级动力学，必须采用微扰弛豫法（温度跳跃 T-jump、压力跳跃 P-jump、电场跳跃 E-jump）。

### 1. 一级对峙弛豫微分方程
对于 $A \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} B$，受到微小温度跃变后，原平衡打破，向新平衡位置移动。
- 设新平衡时浓度为 $\bar{c}_A, \bar{c}_B$，在时刻 $t$ 偏离新平衡位置的扰动量为 $x$：
  $$c_A(t) = \bar{c}_A + x, \quad c_B(t) = \bar{c}_B - x$$
- 速率微分方程：
  $$\frac{\mathrm{d}(\bar{c}_B - x)}{\mathrm{d}t} = k_1(\bar{c}_A + x) - k_{-1}(\bar{c}_B - x)$$
  $$-\frac{\mathrm{d}x}{\mathrm{d}t} = (k_1\bar{c}_A - k_{-1}\bar{c}_B) + (k_1 + k_{-1})x$$
- 新平衡位置满足 $k_1\bar{c}_A = k_{-1}\bar{c}_B$，故第一项为零，微分方程简化为：
  $$\frac{\mathrm{d}x}{\mathrm{d}t} = -(k_1 + k_{-1})x = -\frac{1}{\tau} x$$
- 积分得指数弛豫衰减定律：
  $$x(t) = x_0 \mathrm{e}^{-t/\tau}$$
- **弛豫时间定义**：
  $$\tau = \frac{1}{k_1 + k_{-1}}$$
  通过实验测出不同平衡条件下的 $\tau$ 与平衡常数 $K_c = k_1 / k_{-1}$ 联立，即可分别解出极快反应的 $k_1$ 与 $k_{-1}$。

### 2. 双分子对峙弛豫体系
对于 $A + B \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} C$：
- 设 $c_A = \bar{c}_A + x, c_B = \bar{c}_B + x, c_C = \bar{c}_C - x$；
- 展开保留一次项（忽略二次扰动微小项 $x^2 \approx 0$）：
  $$-\frac{\mathrm{d}x}{\mathrm{d}t} = k_1(\bar{c}_A + x)(\bar{c}_B + x) - k_{-1}(\bar{c}_C - x) \approx [k_1(\bar{c}_A + \bar{c}_B) + k_{-1}]x$$
- **双分子弛豫时间公式**：
  $$\frac{1}{\tau} = k_1(\bar{c}_A + \bar{c}_B) + k_{-1}$$
  以 $\frac{1}{\tau}$ 对 $(\bar{c}_A + \bar{c}_B)$ 作图，得一直线，斜率即为正向双分子反应速率常数 $k_1$，截距即为单分子逆反应速率常数 $k_{-1}$。

## 四、 溶液反应动力学：原盐效应与遇合扩散理论

### 1. 初级盐效应（Primary Salt Effect）
根据过渡态理论（Eyring 方程）与强电解质溶液 Debye-Hückel 极限公式：
$$A^{z_A} + B^{z_B} \rightleftharpoons [X^\ddagger]^{z_A + z_B} \xrightarrow{k^\ddagger} \text{产物}$$
- 过渡态理论推导得表观速率常数与活度系数的关系：
  $$k = k_0 \frac{\gamma_A \gamma_B}{\gamma_{\ddagger}}$$
- 代入常温稀水溶液中 Debye-Hückel 极限公式 $\lg \gamma_i = -0.509 z_i^2 \sqrt{I}$：
  $$\lg \frac{k}{k_0} = \lg \gamma_A + \lg \gamma_B - \lg \gamma_{\ddagger} = -0.509 \sqrt{I}\left[z_A^2 + z_B^2 - (z_A + z_B)^2\right]$$
  化简展开得著名的 **Brønsted-Bjerrum 公式**：
  $$\lg k = \lg k_0 + 2 \times 0.509 z_A z_B \sqrt{I} \approx \lg k_0 + 1.02 z_A z_B \sqrt{I}$$
- **判据规律**：
  - 同号离子反应（$z_A z_B > 0$）：增加离子强度 $I$，活化络合物电荷更密集、水化溶剂化更稳定，反应速率常数**显著增加**（正盐效应）；
  - 异号离子反应（$z_A z_B < 0$）：增加离子强度 $I$，反应速率常数**下降**（负盐效应）；
  - 中性分子参与反应（$z_A z_B = 0$）：表观速率常数对离子强度不敏感（斜率接近 0）。

### 2. 次级盐效应（Secondary Salt Effect）
若反应是由弱酸弱碱电离出的产物（如 $\mathrm{H}^+$ 或 $\mathrm{OH}^-$）催化，外加惰性强电解质改变了溶液的离子强度 $I$，进而改变弱电解质的电离度或活度，导致实际催化剂浓度改变而引起的速率变化，称为次级盐效应。

### 3. 扩散控制反应与遇合对模型（Diffusion-Controlled Reactions）
当溶液中基元反应活化能极小（$E_a < 15\ \mathrm{kJ\cdot mol^{-1}}$）时，分子碰撞即反应，反应速率完全由反应物在溶剂中的扩散速率决定。
- 根据 Smoluchowski 公式与 Stokes-Einstein 扩散定律：
  $$k_d = 4\pi (D_A + D_B) r_{AB} N_A$$
- 若近似将分子视为等半径球体 $r_A \approx r_B = r$，扩散系数 $D = \frac{k_B T}{6\pi \eta r}$：
  $$k_d = \frac{8 R T}{3 \eta}$$
  在 $298\ \mathrm{K}$ 水溶液（$\eta \approx 10^{-3}\ \mathrm{Pa\cdot s}$）中，$k_d \approx 7 \times 10^9\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$。若测得溶液双分子速率常数达到 $10^9 \sim 10^{10}\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$ 数量级，即可断定反应进入扩散控制极限。

## 五、 链反应机理与支链爆炸边界微分判据

### 1. 自由基支链反应机制与速率方程
以氢氧爆炸反应为例，典型机理包含：
- **链引发**：产生初始自由基，速率为 $v_0$；
- **链传递与分支**：一个自由基参与反应生成 $\alpha$ 个新自由基（若 $\alpha > 1$，则为支链反应；若 $\alpha = 1$，则为直链反应）；设分支速率为 $f[R]$；
- **链销毁/终止**：气相三体碰撞终止或反应器器壁吸附销毁，设销毁速率为 $g[R]$。
- 体系活性自由基浓度微分平衡方程：
  $$\frac{\mathrm{d}[R]}{\mathrm{d}t} = v_0 + (f - g)[R]$$
- 积分得自由基浓度随时间演化：
  $$[R](t) = \frac{v_0}{g - f}\left[1 - \mathrm{e}^{-(g - f)t}\right] \quad (g > f)$$
- **爆炸临界判据**：
  1. 若 $g > f$（销毁速率大于分支速率）：随着反应进行，$[R]$ 趋向恒定稳态值 $[R]_{\mathrm{st}} = \frac{v_0}{g - f}$，反应平稳进行，无爆炸；
  2. 若 $f \ge g$（分支速率大于或等于销毁速率）：$\frac{\mathrm{d}[R]}{\mathrm{d}t} > 0$，自由基数量随时间呈雪崩式几何级数暴涨，诱导期后直接引发**支链爆炸（Branching-Chain Explosion）**。

### 2. 爆炸半岛（Explosion Peninsula）三界限成因
- **第一爆炸界限（低压下限）**：低压下分子平均自由程大，自由基扩散碰撞器壁并发生器壁吸附终止占主导。当压力增大到分子碰撞几率增加、气相支链反应几率超过器壁销毁几率时，发生爆炸。
- **第二爆炸界限（高压上限）**：当系统总压力进一步增大时，气相三体碰撞终止几率（如 $\mathrm{H}\cdot + \mathrm{O}_2 + M \to \mathrm{HO}_2\cdot + M$，$\mathrm{HO}_2\cdot$ 活性极低，不再参与快速链分支）随压力平方 $p^2$ 骤增，三体销毁速率超过气相分支速率，爆炸熄灭。
- **第三爆炸界限（高压热爆炸）**：压力极高时，反应放出的巨大热量无法通过器壁及时散失，体系温度急剧升高使热反应速率呈指数级暴增，转化为**热爆炸（Thermal Explosion）**。

## 六、 酶催化反应动力学与多相催化建模

### 1. 米氏方程（Michaelis-Menten Equation）严密推导
经典单底物酶催化机理：
$$E + S \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} ES \xrightarrow{k_2} E + P$$
- 设总酶浓度为 $[E]_0 = [E] + [ES]$，底物浓度 $[S] \gg [E]_0$。
- 对中间体络合物 $ES$ 应用稳态近似：
  $$\frac{\mathrm{d}[ES]}{\mathrm{d}t} = k_1 [E][S] - (k_{-1} + k_2)[ES] = 0$$
  $$k_1 ([E]_0 - [ES])[S] = (k_{-1} + k_2)[ES]$$
- 解出中间体稳态浓度：
  $$[ES] = \frac{[E]_0 [S]}{\frac{k_{-1} + k_2}{k_1} + [S]} = \frac{[E]_0 [S]}{K_M + [S]}$$
  其中定义 **米氏常数** $K_M = \frac{k_{-1} + k_2}{k_1}$。
- 最终产物生成速率：
  $$r = k_2 [ES] = \frac{k_2 [E]_0 [S]}{K_M + [S]} = \frac{V_{\max} [S]}{K_M + [S]}$$
- **参数极限分析**：
  - 当 $[S] \ll K_M$ 时：$r \approx \frac{V_{\max}}{K_M}[S]$，对底物表现为一级反应，$\frac{k_2}{K_M} = \frac{k_{\mathrm{cat}}}{K_M}$ 为催化特异性常数；
  - 当 $[S] \gg K_M$ 时：$r \approx V_{\max} = k_2 [E]_0$，酶全被底物饱和，对底物表现为零级反应；
  - 当 $r = \frac{1}{2}V_{\max}$ 时：$[S] = K_M$，米氏常数在数值上严格等于反应速率达到最大值一半时的底物浓度。

### 2. 酶动力学实验数据线性化处理方法
1. **Lineweaver-Burk 双倒数作图法**：
   $$\frac{1}{r} = \frac{K_M}{V_{\max}}\frac{1}{[S]} + \frac{1}{V_{\max}}$$
   - $\frac{1}{r}$ 对 $\frac{1}{[S]}$ 作图，斜率为 $\frac{K_M}{V_{\max}}$，截距为 $\frac{1}{V_{\max}}$，横轴截距为 $-\frac{1}{K_M}$。
2. **Eadie-Hofstee 作图法**：
   $$r = -K_M \frac{r}{[S]} + V_{\max}$$
   - $r$ 对 $\frac{r}{[S]}$ 作图，斜率为 $-K_M$，纵截距为 $V_{\max}$（数据权重分布优于双倒数法）。

### 3. 多相催化：Langmuir-Hinshelwood 与 Eley-Rideal 机理
气-固催化中，反应物必须先发生化学吸附：
1. **Langmuir-Hinshelwood 机理（双分子吸附历程）**：
   $$A(\text{ads}) + B(\text{ads}) \xrightarrow{k} \text{产物}$$
   - 设两气体竞争同一固体表面的均匀活性位，吸附平衡常数分别为 $K_A, K_B$：
     $$\theta_A = \frac{K_A p_A}{1 + K_A p_A + K_B p_B}, \quad \theta_B = \frac{K_B p_B}{1 + K_A p_A + K_B p_B}$$
   - 反应速率由两吸附分子相互碰撞决速：
     $$r = k \theta_A \theta_B = \frac{k K_A K_B p_A p_B}{(1 + K_A p_A + K_B p_B)^2}$$
   - **分压极大值行为**：若固定 $p_B$，随 $p_A$ 增加，速率先增大后减小；当 $p_A$ 过大时，$A$ 几乎将活性位占满，导致 $B$ 无法吸附，速率反向趋向于零。
2. **Eley-Rideal 机理（气相碰撞历程）**：
   $$A(\text{ads}) + B(\text{g}) \xrightarrow{k} \text{产物}$$
   $$r = k \theta_A p_B = \frac{k K_A p_A p_B}{1 + K_A p_A}$$
   - 若 $p_A$ 极大（饱和吸附 $\theta_A \approx 1$），则速率退化为关于 $B$ 的一级反应：$r = k p_B$。

## 七、 非线性化学动力学：自催化、化学振荡与极限环

### 1. 自催化反应（Autocatalytic Reactions）
反应产物本身即可充当该反应的催化剂：
$$A + X \xrightarrow{k} 2X$$
- 设初始 $c_A(0) = a, c_X(0) = x_0$，任一时刻 $c_X(t) = x$：
  $$\frac{\mathrm{d}x}{\mathrm{d}t} = k(a + x_0 - x)x$$
- 反应初期的诱导期速率极慢，随后随产物 $X$ 的积累呈 S 形急剧加速，直到反应物 $A$ 消耗殆尽。

### 2. Lotka-Volterra 周期振荡模型
$$A + X \xrightarrow{k_1} 2X, \quad X + Y \xrightarrow{k_2} 2Y, \quad Y \xrightarrow{k_3} P$$
- 敞开系统中维持反应物 $A$ 恒定供给，$P$ 恒定排出。
- 微分方程组：
  $$\frac{\mathrm{d}[X]}{\mathrm{d}t} = k_1 [A][X] - k_2 [X][Y]$$
  $$\frac{\mathrm{d}[Y]}{\mathrm{d}t} = k_2 [X][Y] - k_3 [Y]$$
- 在相平面 $[X]-[Y]$ 上表现为围绕非平凡不动点的一族闭合轨道曲线，各组分浓度随时间呈现周期性交替升降。

### 3. Belousov-Zhabotinsky (BZ) 振荡与 Oregonator 模型
BZ 振荡是典型的在远离热力学平衡态的敞开系统中自发形成的耗散结构（Dissipative Structure）。
- 催化剂离子在不同氧化态之间周期性循环转变（如 $\mathrm{Ce}^{3+} \rightleftharpoons \mathrm{Ce}^{4+}$ 或邻菲啰啉铁电对亚铁/铁红蓝交替），伴随着中间体 $\mathrm{HBrO}_2$ 与 $\mathrm{Br}^-$ 的脉冲式浓度变化；
- **极限环（Limit Cycle）**：在相平面轨迹上，无论初始浓度偏离多大，系统的动力学轨线在时间 $t \to \infty$ 时最终都会不可逆地汇聚并锁定在唯一的封闭轨道上（吸引子）。
