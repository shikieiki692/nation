# 提炼-上海中学竞赛课程-第二分册-滴定分析

> 来源：上海中学竞赛课程·化学·第2分册·第十讲 滴定分析（原书约 1700 行，行2324-4029）
> 提炼日期：2026-09-16

## 内容概要

本讲分两大块。前半是定量分析的「数据基础」：误差（系统误差四类来源、偶然误差、过失误差）、准确度与精密度（绝对/相对误差、平均偏差、标准偏差与 RSD）、二者的关系，以及提高准确度的三组方法与有效数字的概念、修约规则（四舍六入五成双）与运算规则。后半是滴定分析法：定义与术语（化学计量点、滴定终点、终点误差）、四类分类、四个基本条件、四种滴定方式、标准溶液与基准物质、配制与标定；随后讨论酸碱指示剂的变色原理与变色范围 $\mathrm{pH} = \mathrm{pK}_{HIn} \pm 1$，以及温度、用量、滴定顺序、混合指示剂四类影响因素；最后按类型讨论滴定曲线与指示剂选择（强酸强碱、强碱滴弱酸、强酸滴弱碱、多元酸），给出 $cK_a \geqslant 10^{-8}$ 的准确滴定判据。

## 核心知识点

### 1. 误差的分类

- 误差 = 分析结果 − 真实值；偏差 = 分析结果 − 平均值
- **系统误差**（可定误差）：有固定方向与大小，同条件下重复出现，四类来源：

| 来源 | 典型成因 |
|:---|:---|
| 方法误差 | 反应不完全或有副反应、指示剂不合适、干扰离子、滴定终点与化学计量点不符 |
| 仪器误差 | 天平两臂不等长、砝码不准或生锈、容量仪器刻度不准 |
| 试剂误差 | 试剂或蒸馏水中含微量杂质或干扰物质 |
| 操作误差 | 滴定管读数偏高/偏低、对终点颜色判断总偏深或偏浅 |

- **偶然误差**（随机误差）：由温度、湿度、气压微小变化等引起，难以察觉和控制，但服从统计规律 → **增加平行测定次数**可减小
- **过失误差**：粗心或违章操作（溶液溅失、加错试剂、读错刻度）→ 查明原因后弃去该次结果

### 2. 准确度与精密度

- 绝对误差 $E = X - T$；相对误差 $RE = E/T \times 100\%$
- 被测定的量大时相对误差小，故用**相对误差**表示准确度更确切（同为 −0.0002 g 的绝对误差，1.9564 g 样品对应 −0.01%、0.1952 g 样品对应 −0.1%）
- 精密度指标：

$$\bar{d} = \frac{\sum_{i=1}^{n}|x_i - \bar{x}|}{n}, \quad \bar{d}_r = \frac{\bar{d}}{\bar{x}}\times100\%, \quad s = \sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}}, \quad RSD = \frac{s}{\bar{x}}\times100\%$$

- **平均偏差的缺陷**：小偏差占多数会把结果拉小、大偏差得不到反映 → 标准偏差更适用（甲乙两组平均偏差同为 0.25，标准偏差 0.31 vs 0.39）
- **准确度与精密度的关系**：精密度高的准确度不一定高；**精密度是确保准确度的先决条件**；只有消除系统误差后，才可用精密度同时表达准确度
  - 四人分析同一试样的四种典型情形：准确度精密度俱佳 / 精密度高而准确度低 / 二者俱差 / 平均值接近真值但精密度差（凑巧）

### 3. 提高分析结果准确度的方法

- **选择合适的分析方法**：常量组分用重量分析法或滴定分析法；微量、痕量组分用仪器分析法
- **减小测量误差**（增大被测物总量以减小相对误差）：
  - 滴定管两次读数最大误差 ±0.02 mL，要求相对误差 ≤ 0.1% → 滴定液体积应 ≥ 20 mL
  - 万分之一天平称量误差 ±0.0002 g，要求 ≤ 0.1% → 称样量 ≥ 0.2 g
- **减小偶然误差**：增加平行测定次数
- **消除系统误差**：
  - **对照试验**：以已知含量的标准试样与未知样品平行测定，由差值校正；可减免方法误差、检验试剂失效与仪器误差
  - **空白试验**：以溶剂代替样品同法分析，从结果中减去空白值，消除溶剂与器皿带入的杂质
  - **校准仪器**：砝码、移液管、滴定管、容量瓶等，并应用校正值；同一操作过程使用同一仪器可使仪器误差相互抵消

### 4. 有效数字

**(1) 位数判断要点**

- 数字中间的 0 都是有效数字；前面的 0 只起定位作用；后面的 0 依情况而定（25.00 mL 为四位）
- 变换单位时位数不变（10.00 mL = 0.010 00 L）
- 非测量所得数字（倍数、分数）视为无限多位
- **对数数据的位数只取决于小数部分**：pH = 11.02 对应 $[H^+] = 9.6\times10^{-12}$，有效数字是**两位**而非四位
- 首位数字 ≥ 8 时可多算一位（9.66 可认为四位）

**(2) 修约规则**

1. **四舍六入五成双（尾留双）**：被修约数 ≤4 舍、≥6 入；=5 且后面无数字或均为 0 时，看 5 前面是偶数则舍、奇数则进
   - 1.05 → 1.0（0 以偶数计）、0.15 → 0.2、0.25 → 0.2
   - 5 后面还有不为 0 的数字时一律进 1：1.0501 → 1.1、2.351 → 2.4
2. **只允许一次修约到所需位数**，不能分次：2.1346 → 2.13（不能先 2.135 再 2.14）
3. 大量数据运算时可先多保留一位（不修约），运算后再修约
4. 修约标准偏差时，结果应使准确度/精密度的估计值**变得更差**：$s = 0.113$ 取两位宜为 0.12，取一位宜为 0.2

**(3) 运算规则**

| 运算 | 依据 | 实例 |
|:---|:---|:---|
| 加减法 | 以小数点后位数最少（绝对误差最大）的数据为准 | $12.61 + 0.57 + 0.01 = 13.19$ |
| 乘除法 | 以有效数字位数最少（相对误差最大）的数据为准 | $0.0121 \times 25.6 \times 1.06 = 0.328$ |
| 对数 | 对数位数（首数除外）与真数有效数字相同 | $[H^+] = 1.3\times10^{-3}$ → pH = 2.89 |

- 表示准确度或精密度时，一般取一位有效数字，最多两位
- 记录规范：万分之一天平必须记到小数点后四位（16.5500 g 不能写作 16.55 g）；滴定管读数必须记到后二位（20.00 mL）

### 5. 滴定分析法的基本概念与条件

- **化学计量点**（等量点/等当点）：标准溶液与被测物按化学计量关系恰好完全反应
- **滴定终点**：指示剂发生颜色变化的转变点（实际测得值）
- **终点误差**（滴定误差）：终点与化学计量点不符造成的误差，取决于反应完全程度与指示剂选择
- 特点：适用于含量 > 1% 的常量组分；仪器简单、操作简便快速、准确度较高，相对误差一般 < 0.2%
- 四类分类：

| 类型 | 基础反应 | 典型应用 |
|:---|:---|:---|
| 酸碱滴定（中和滴定） | $H^+ + OH^- = H_2O$ | 测酸/碱及酸碱性物质 |
| 沉淀滴定 | 沉淀反应 | AgNO₃ 测卤化物、硫氰酸盐 |
| 配位滴定 | 络合反应 | EDTA 测金属离子，$M^{2+} + Y^{4-} = MY^{2-}$ |
| 氧化还原滴定 | 氧化还原反应 | 高锰酸钾法、重铬酸钾法、碘量法 |

- **四个基本条件**：① 反应完全（定量完成程度 ≥ 99.9%，无副反应）② 反应速度快（慢反应需加热或加催化剂）③ 选择性高（杂质须分离或掩蔽）④ 有适宜指示剂或可靠方法确定终点

### 6. 四种滴定方式

| 方式 | 适用情形 | 实例 |
|:---|:---|:---|
| 直接滴定 | 反应符合四个基本条件 | NaOH 滴 HAc、KMnO₄ 滴 Fe²⁺ |
| 返滴定 | 反应慢、反应物难溶或无合适指示剂 | 过量 HCl 溶解 ZnO，再用 NaOH 滴剩余 HCl |
| 置换滴定 | 反应有副反应、无确定计量关系 | K₂Cr₂O₇ 酸性氧化 KI 定量生成 I₂，再用 Na₂S₂O₃ 滴 I₂ |
| 间接滴定 | 被测物不与标准溶液直接反应 | 硼酸与多元醇生成配合酸（$K_a \approx 10^{-6}$）再用 NaOH 滴定 |

> 后三种方式的引入大幅拓展了滴定分析的适用范围。

### 7. 标准溶液与基准物质

- 浓度表示：
  - 物质的量浓度 $c_B = n_B/V_B$
  - **滴定度**两种：① 每 mL 标准溶液所含溶质质量，如 $T_{NaOH} = 0.004000$ g/mL；② 每 mL 标准溶液相当于被测物的质量，如 $T_{NaOH/HCl} = 0.003646$ g/mL（应用更广）
  - 由滴定度直接求质量：$m_{Fe} = T_{KMnO_4/Fe}\cdot V = 0.005800 \times 18.00 = 0.1044$ g
- 配制方法：
  - **直接法**：准确称取基准物质 → 溶解 → 定容，由质量和体积求准确浓度
  - **间接法（标定法）**：先配近似浓度，再用基准物质或标准溶液标定
- **基准物质四条件**：① 纯度高（≥ 99.9%）② 组成恒定（含结晶水者亦须与化学式相符）③ 性质稳定（不吸 CO₂/H₂O、不被 O₂ 氧化、加热干燥不分解）④ 摩尔质量较大（称取量大，可减小称量相对误差）
  - 常用：无水 Na₂CO₃、硼砂 Na₂B₄O₇·10H₂O、邻苯二甲酸氢钾、草酸 H₂C₂O₄·2H₂O、纯 Zn/Cu
  - 不能直接法配制：NaOH（吸 CO₂ 和 H₂O）、KMnO₄（见光分解）、Na₂S₂O₃·5H₂O（不易提纯）
- 标定方法：**基准物质标定法**（多次称量法、移液管法）、**标准溶液比较法**（后者精度不及前者）
- 规定：平行标定 3~4 次，相对平均偏差 ≤ 0.2%；AgNO₃、KMnO₄ 存棕色瓶避光；NaOH、Na₂S₂O₃ 放置 2~3 个月后需重新标定

### 8. 酸碱指示剂

**(1) 变色原理与变色范围**

指示剂为结构复杂的有机弱酸（HIn）或有机弱碱，电离后生成与分子颜色不同的离子：

$$\mathrm{HIn} \rightleftharpoons \mathrm{H^+} + \mathrm{In^-} \qquad \text{（酸式色）(碱式色）}$$

$$\mathrm{pH} = \mathrm{p}K_{HIn} - \lg\frac{[\mathrm{HIn}]}{[\mathrm{In^-}]}$$

- 人眼须一种型体浓度超过另一种 **10 倍**以上才能辨认 → 变色范围 $\mathrm{pH} = \mathrm{p}K_{HIn} \pm 1$（理论约 2 个 pH 单位）
- **理论变色点**：$[\mathrm{HIn}] = [\mathrm{In^-}]$ 时 $\mathrm{pH} = \mathrm{p}K_{HIn}$
- 实际变色范围因人眼对颜色敏感度不同而与理论略有偏差：甲基红理论 4.1~6.1、实测 4.4~6.2

**(2) 常用指示剂**

| 指示剂 | 变色范围 pH | 酸色 → 碱色 | $\mathrm{p}K_{HIn}$ |
|:---|:---|:---|:---|
| 百里酚蓝 | 1.2~2.8 | 红 → 黄 | 1.65 |
| 甲基橙 | 3.1~4.4 | 红 → 黄 | 3.45 |
| 甲基红 | 4.4~6.2 | 红 → 黄 | 5.1 |
| 溴百里酚蓝 | 6.2~7.6 | 黄 → 蓝 | 7.3 |
| 酚酞 | 8.0~10.0 | 无 → 红 | 9.1 |
| 百里酚酞 | 9.4~10.6 | 无 → 蓝 | 10.0 |

**(3) 影响因素**

- **温度**：改变 $K_{HIn}$ → 变色范围移动（甲基橙 18℃ 3.1~4.4，100℃ 2.5~3.7）
- **用量**：过多则颜色深、变色不敏锐且消耗滴定液；过少不易观察。25 mL 试液加 1~2 滴
- **滴定顺序**：肉眼观察显色比褪色容易 → 碱滴酸用**甲基红**、酸滴碱用**甲基橙**
- **混合指示剂**：变色范围窄、变色敏锐。① 多种指示剂混合利用颜色互补；② 指示剂 + 惰性染料（甲基橙 + 靛蓝：pH ≥ 4.4 绿、pH = 4.0 浅灰、pH ≤ 3.1 紫）

### 9. 滴定曲线与指示剂选择

**(1) 强酸（碱）滴定强碱（酸）**（0.1000 mol/L NaOH 滴 20.00 mL 0.1000 mol/L HCl）

- 四阶段 pH：滴定前 1.00 → 计量点前按剩余 HCl 计（19.98 mL → pH 4.30）→ 计量点 7.00 → 计量点后按过量 NaOH 计（20.02 mL → pH 9.70）
- **突跃范围**：化学计量点前后 ±0.1% 范围内 pH 的变化 = **4.30 ~ 9.70**（仅差约 1 滴，pH 跃 5.40 个单位）
- 指示剂选择依据：**凡变色点落在突跃范围内的均可**（酚酞、甲基红、甲基橙）
- 浓度影响：1.0 / 0.1 / 0.01 mol/L 对应突跃 3.3~10.7 / 4.3~9.7 / 5.3~8.7 → 浓度越大突跃越大、可选择的指示剂越多；常用 0.1~1 mol/L
- 反向滴定（HCl 滴 NaOH）pH 方向相反，甲基橙不再适合

**(2) 强碱滴定弱酸**（0.1000 mol/L NaOH 滴 0.1000 mol/L HAc，$K_a = 1.8\times10^{-5}$）

- 滴定前：$[\mathrm{H^+}] = \sqrt{K_a c} = 1.34\times10^{-3}$ mol/L → pH = 2.87（起点比同浓度强酸高）
- 计量点前：构成 HAc-NaAc 缓冲体系，$\mathrm{pH} = \mathrm{pK}_a - \lg([HAc]/[Ac^-])$（19.98 mL → pH 7.70）
- 计量点：生成 NaAc，$[\mathrm{OH^-}] = \sqrt{K_b c} = \sqrt{(K_w/K_a)\times0.05000} = 5.27\times10^{-6}$ mol/L → pH = 8.72（体积加倍、浓度减半）
- **突跃范围 7.70 ~ 9.70（弱碱性区）** → 只能选碱性区变色的指示剂（酚酞、百里酚蓝）；甲基橙、甲基红不可用
- **准确滴定判据**：$cK_a \geqslant 10^{-8}$。$K_a \leqslant 10^{-9}$ 时已无明显突跃；HCN（$K_a \approx 10^{-10}$）即使 1 mol/L 也不能按常规方法滴定

**(3) 强酸滴定弱碱**（0.1000 mol/L HCl 滴 0.1000 mol/L 氨水）

- 曲线形状与强碱滴弱酸相似但 pH 方向相反
- 化学计量点 pH = 5.28，**突跃范围 6.30 ~ 4.30（酸性区）** → 选甲基橙、溴甲酚绿
- 判据：$cK_b \geqslant 10^{-8}$

**(4) 多元酸（碱）的滴定**（0.1000 mol/L NaOH 滴 0.1000 mol/L H₃PO₄）

- 多元酸分步电离、分步中和，可看作不同强度一元酸的混合物，按每级 $cK_a \geqslant 10^{-8}$ 单独判断

| 级次 | $K_a$ | $cK_a$ | 能否滴定 | 计量点 pH | 指示剂 |
|:---|:---|:---|:---|:---|:---|
| 第一级 | $7.5\times10^{-3}$ | $7.5\times10^{-4} > 10^{-8}$ | 能 | 4.66 | 甲基橙 |
| 第二级 | $6.3\times10^{-8}$ | $\approx 10^{-8}$ | 勉强能 | 9.94 | 酚酞 |
| 第三级 | $4.4\times10^{-13}$ | $\ll 10^{-8}$ | 不能 | 无明显突跃 | — |

## 竞赛要点

1. **准确度 ≠ 精密度**——精密度是准确度的**先决条件**，但精密度高不代表准确（存在系统误差时结果可靠但偏离真值）
2. **两类误差的消除手段不同**：系统误差靠对照试验/空白试验/校准仪器，偶然误差靠增加测定次数
3. **有效数字的对数规则**（pH、pK、lgK 只看小数部分位数）与**一次修约规则**是高频失分点
4. **四舍六入五成双**须熟练，且修约标准偏差时要「更差化」
5. **指示剂选择看突跃不看颜色**——变色点须落在突跃范围内，且须注意突跃落在酸性区还是碱性区
6. **$cK_a \geqslant 10^{-8}$（$cK_b \geqslant 10^{-8}$）是弱酸/弱碱能否准确滴定的黄金判据**；多元酸按每级单独判断，可据此判断「几个突跃」
7. **返滴定与置换滴定**是扩展滴定适用范围的两把钥匙——难溶物、慢反应、无确定计量关系的反应都靠它们
8. 基准物质四条件中「**摩尔质量较大**」常被忽略：目的是增大称样量以减小称量相对误差

## 例题与习题

### 典型例题

**例1**（精密度指标计算）：某标准溶液五次标定结果为 0.1022、0.1029、0.1025、0.1020、0.1027 mol/L，求各项指标。

- 平均值 $\bar{x} = 0.1025$ mol/L；平均偏差 $\bar{d} = 0.0003$ mol/L；相对平均偏差 = 0.29%
- 标准偏差 $s = \sqrt{\dfrac{(0.0003)^2+(0.0004)^2+(0.0000)^2+(0.0005)^2+(0.0002)^2}{5-1}} = 0.0004$ mol/L
- 相对标准偏差 RSD = 0.39%

**例2**（有效数字运算）：求 0.0121、25.64、1.05782 三数之积。

- 0.0121 有效数字位数最少（三位，相对误差 ±0.8% 最大）→ 其余修约为三位：$0.0121 \times 25.6 \times 1.06 = 0.328$

**例3**（测量误差的定量控制）：使用万分之一天平使相对误差 ≤ 0.1%，最少称样量是多少？

- $m = 0.0002/0.001 = 0.2$ g（滴定管同理：±0.02 mL ÷ 0.1% → 体积 ≥ 20 mL）

**例4**（指示剂选择）：0.1000 mol/L NaOH 滴定 0.1000 mol/L HAc，突跃范围 7.70~9.70，应选何种指示剂？

- 突跃落在弱碱性区 → 选酚酞（8.0~10.0）或百里酚蓝；甲基橙、甲基红在酸性区变色，不可用

### 本讲习题要点

- 误差分类与来源判定（系统误差四种 / 偶然误差 / 过失误差）
- 绝对误差、相对误差、平均偏差、标准偏差、RSD 的计算与比较
- 有效数字位数判断、修约（四舍六入五成双、一次修约）、加减/乘除/对数运算法则
- 减小测量误差的定量估算（滴定体积 ≥ 20 mL、称样量 ≥ 0.2 g）
- 四种滴定方式的选择（直接/返滴定/置换/间接）与滴定度计算
- 基准物质条件判断、标准溶液配制（直接法/间接法）与标定方法
- 指示剂变色范围计算（$\mathrm{pH} = \mathrm{pK}_{HIn} \pm 1$）与四类影响因素
- 四类酸碱滴定曲线的 pH 计算、突跃范围确定与指示剂选择
- 由 $cK_a$（$cK_b$）判据判断弱酸、弱碱及多元酸各级能否被准确滴定
