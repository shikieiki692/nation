# Clayden 第18章：光谱法综述 资料提炼

---

## 一、核心概念与定义

### 1.1 本章的三个目标

1. 回顾 Ch3 和 Ch13 中学习的确定结构的方法，稍作延伸并考虑它们之间的关系
2. 展示如何将多种光谱方法结合起来，确定未知分子的结构
3. 提供实用的数据表格，用于确定未知结构

- 本章主要的数据表格在结尾（pp. 423-425），阅读正文时应同时查阅
- 本章是将光谱分析法视为整体进行回顾的两章之一（另一章为 Ch31，涉及立体化学信息）

### 1.2 羰基化合物的两大类

| 类别 | 代表化合物 | 羰基 ¹³C 化学位移 (ppm) |
|:---|:---|:---|
| **醛和酮** | RCHO, R¹COR² | 191–208 |
| **羧酸及其衍生物** | RCO₂H, RCOCl, RCO₂COR, RCONH₂ | 164–180 |

- 两组区域**不重叠**，¹³C NMR 是区分它们的最可靠方法
- 酮酸的光谱分配因此很简单

![](clayden 有机化学/Clayden中文版_402-600_images/1850fe36e96727eb1410102bd3eddc5b66f5b64946a621a1e46d7549dc43a7ce.jpg)

### 1.3 羰基化合物分类与化学活性的关系

| 化合物类型 | 相对活性 | 羰基 ¹³C 位移 (ppm) |
|:---|:---|:---|
| 酰氯 RCOCl | 最活泼 | 165–170 |
| 酸酐 RCO₂COR | 很活泼 | 165–170 |
| 酯 R¹CO₂R² | 稳定 | 165–175 |
| 酰胺 RCONH₂ | 稳定 | 165–175 |
| 羧酸 RCO₂H | 稳定 | 170–185 |

- ¹³C NMR 可靠地将羧酸衍生物作为一个整体与醛酮区分
- 但**无法区分**各类羧酸衍生物之间（位移差异仅几 ppm，与化学活性无对应关系）

## 二、¹³C NMR 区分醛酮与羧酸衍生物

### 2.1 醛酮的特征

- 醛和酮的 C=O 位移均在 ~200 ppm 处共振
- 醛的 ¹³C 位移比酮略小，但差异太近，**不太可靠**
- **最可靠的区分方法**：醛在 [[¹H NMR]] 中 δ 9–10 ppm 有特征性的 CHO 质子信号
- **建议策略**：先通过碳 NMR 区分醛酮和羧酸衍生物，再通过质子 NMR 区分醛和酮

![](clayden 有机化学/Clayden中文版_402-600_images/769c60b7ed5195b5ce802328123d292e79a54d92b9b4dde726bbbd4b6929323f.jpg)

### 2.2 实例：香草醛与视黄醛

- 香草醛（香草荚来源）：δ_C 195–205 ppm（醛）
- 视黄醛（视觉中顺/反异构化产生神经冲动）：δ_C 195–205 ppm（醛）
- 酮类香味化合物：(-)-香芹酮（留兰香油70%）、覆盆子酮
- 覆盆子酮中与 OH 相连的芳香碳在 154.3 ppm，不干扰酮信号（208.8 ppm）

![](clayden 有机化学/Clayden中文版_402-600_images/fb236fdf6de880a865013b98207fe9294882d38e8d358fc04f77864a61b3a8e8.jpg)

### 2.3 羧酸衍生物的实例

- 硫辛酸（含 S-S 键，用于氧化还原反应）
- 莽草酸（生物体内苯环化合物的形成中间体）
- 水杨酸醋酸酯（阿司匹林）
- 布洛芬（止痛药）
- 甲基丙烯酸甲酯（生产亚克力/Perspex 的单体）
- 四肽（含末端羧基和三个酰氨基，四种氨基酸均为 Ala，但碳 NMR 检测到四种不同的 C=O 信号）

![](clayden 有机化学/Clayden中文版_402-600_images/c52c3fc642487dabb4c69987b2d54bf37befe1591258c71a9a2ba88d5d8315bf.jpg)

## 三、红外光谱区分羧酸衍生物

### 3.1 C=O 伸缩频率的决定因素

**三个关键因素**：

1. **共轭效应**：将电子给进 π* 轨道 → 键长变长、强度减弱 → 频率降低
2. **诱导吸电子效应**：使 π 键更短更强 → 频率升高
3. **环张力**：小环导致轨道角度偏离理想 → 频率升高

### 3.2 各类羧酸衍生物的 C=O 伸缩频率

| 官能团 | C=O 伸缩频率 (cm⁻¹) | 频率改变量 (cm⁻¹) | 主导效应 |
|:---|:---|:---|:---|
| 酰氯 | 1800 | +85 | 强诱导吸电子 |
| 酸酐 | 1765, 1815 | +50, +100 | 诱导 > 共轭 |
| 酯 | 1745 | +30 | 诱导稍强于共轭 |
| 醛 | 1730 | +15 | H 弱诱导 |
| 酮 | 1715 (基准) | 0 | — |
| 共轭 C=C | 1685 | -30 | π-π 共轭 |
| 芳基 | 1685 | -30 | π-π 共轭 |
| 酰胺 | 1630 | -85 | N 强共轭给电子 |

![](clayden 有机化学/Clayden中文版_402-600_images/d7c536d0439c31b9859d34edf2b5d4833ad84005545193d55b90.jpg)

### 3.3 取代基对 C=O 伸缩频率的效应总结

![](clayden 有机化学/Clayden中文版_402-600_images/a158e5dbbec9f3b37ce570c52ef6a1c26a65b4f2d16e85b7c1ac268f5399108a.jpg)

- 氯：弱的孤电子给体（3p 轨道与碳 2p 轨道交叉重叠）+ 强吸电子体 → 高频吸收
- 酸酐：氧在两个 C=O 间，诱导强但共轭弱（孤对电子给向两个方向）
- 酰胺：氮电负性比氧小，是强得多的电子给体 → 主要受共轭影响

### 3.4 共轭对 C=C 伸缩的影响

![](clayden 有机化学/Clayden中文版_402-600_images/2c20b67e6c1ef37d59b59bd174849f5bb96fa80058bd57be7adb5da46a43cc3b.jpg)

**共轭 vs 非共轭不饱和醛的光谱差异**：
- IR：C=O 伸缩频率降低 ~40 cm⁻¹，C=C 伸缩强度改变
- ¹³C NMR：共轭烯醛的 C3 从烯烃区域移到羰基区域（缺电子）
- ¹H NMR：共轭烯烃中质子向低场移动（尤其是 C3 上的质子）

![](clayden 有机化学/Clayden中文版_402-600_images/f6260d187fa7bb09c4a75cb8cbf7114a8abfa8225082f8ccb5b15b526bdfb329.jpg)

## 四、环张力对 C=O 伸缩频率的影响

### 4.1 小环的 s/p 轨道成分变化

- 只有至少六元环状酮可在羰基处达到完美 120° 角
- 四元环：键角 90°，张力 30°；五元环张力稍小；三元环最大
- **核心原理**：键角越小，环上键的 p 成分越多（→ s⁰·⁸p³·²），与氧成 σ 键的 s 成分增多 → 键更短更强 → 频率升高

![](clayden 有机化学/Clayden中文版_402-600_images/392982d6d097b8dfd4dc23a924c0de2bf0ca3f0536ea56de4bcf87ebc4327ecc.jpg)

![](clayden 有机化学/Clayden中文版_402-600_images/456a9063ddfccf2816f924bd493c1b6976fe40781829f679c301424253bb4029.jpg)

### 4.2 内酰胺的 C=O 伸缩频率

| 内酰胺类型 | C=O 伸缩频率 (cm⁻¹) |
|:---|:---|
| 六元环内酰胺（无张力） | 1680 |
| β-内酰胺（四元环，盘尼西林） | 1715 |

![](clayden 有机化学/Clayden中文版_402-600_images/e5c742d01f25d4a3201745d679c36b8d119d28f7e07d29fb383b85f2eb476619.jpg)

### 4.3 C=O 伸缩频率的简单计算方法

**基准：饱和酮 1715 cm⁻¹**

| 效应 | 基团 | C=O 伸缩频率 (cm⁻¹) | 频率改变量 (cm⁻¹) |
|:---|:---|:---|:---|
| **诱导效应** | Cl | 1800 | +85 |
| | OCOR | 1765, 1815 | +50, +100 |
| | OR | 1745 | +30 |
| | H | 1730 | +15 |
| **共轭** | C=C | 1685 | -30 |
| | 芳基 | 1685 | -30 |
| | NH₂ | 1630 | -85 |
| **环张力** | 五元环 | 1745 | +30 |
| | 四元环 | 1780 | +65 |
| | 三元环 | 1815 | +100 |

![](clayden 有机化学/Clayden中文版_402-600_images/2644c833c9afb7240050ed56966a8d7958ed787337112fecad1c02a118dd672b.jpg)

**应用示例：五元共轭不饱和内酯**
- 酯基 +30 cm⁻¹，双键 -30 cm⁻¹，五元环 +30 cm⁻¹
- 前两个抵消，净 +30 cm⁻¹ → 1715 + 30 = 1745 cm⁻¹（实测 1740-1760 cm⁻¹，吻合）

![](clayden 有机化学/Clayden中文版_402-600_images/ca555e3710a43c579cf1426eccab227381fc407a596338bdafe5f840d393ec1a.jpg)

## 五、小环与炔烃的 NMR 光谱

### 5.1 三元环的异常化学位移

- 环丙烷上的 H 在 δ 0–1 ppm（甚至可能负值），远低于预期的 1.3 ppm
- 原因：环上键的 p 成分增多 → 环外 C-H 键 s 成分增多 → 键更短、屏蔽更大

### 5.2 炔烃的 NMR 光谱

- 炔烃 C-H 质子 δ 2.0–2.5 ppm（介于烯烃 ~5.5 ppm 和饱和碳之间）
- 原因：sp 杂化（50% s 成分）→ 屏蔽增强
- 但炔烃的感应电流产生的圆筒形屏蔽区也起到作用（质子在圆筒内部）
- 炔烃碳 δ_C 60–80 ppm（达不到烯烃区域）
- C≡C-H 伸缩频率 ~3300 cm⁻¹（非常强的 C-H 键）

![](clayden 有机化学/Clayden中文版_402-600_images/d1eb69225fad2a23fb573dbd7b46f20d61191a1d7d5e278da3535028aeb54704.jpg)

![](clayden 有机化学/Clayden中文版_402-600_images/ed007f180d330933dda4fba509bb5bb62a415a68cae7d0ca242efda56d796d37.jpg)

### 5.3 炔烃的长程偶合

- 炔烃中常观察到 ⁴J_HH 较小偶合（~2 Hz）
- 实例：3-甲氧基-1-丙炔中炔烃质子为三重峰（与 OCH₂ 偶合）
- 1,3-丁二炔与甲醇碱催化加成产物：Z 烯烃两端质子 J = 6.5 Hz（顺式），长程偶合 ⁴J = 2.5 Hz

![](clayden 有机化学/Clayden中文版_402-600_images/bfc84dfbcc70ea7a30c192df14bf2942d1e73ab281ab9845347b886edf7a9bf0.jpg)

|:---|:---|:---|
| 双直立 (a,a) | 10–12 | 轨道完美平行 |

## 七、不同核之间的偶合——异核偶合

### 7.1 ¹⁹F 和 ³¹P 的偶合

- ¹⁹F 和 ³¹P 天然丰度接近 100%，自旋 I = 1/2
- 与几乎所有邻近碳、氢原子发生偶合
- ¹J 偶合常数极大（如 ¹J_PH = 693 Hz），²J/³J 也显著

**实例：亚磷酸二甲酯**
- ¹H NMR：1H 双重峰，J_PH = 693 Hz（P-H 键）→ 确认 P(V) 结构

**实例：Wittig 试剂**
- 甲基在 δ_C 10.6 ppm，¹J_PC = 57 Hz
- ¹H NMR：A₃P 体系，质子为双重峰，磷谱为四重峰

![](clayden 有机化学/Clayden中文版_402-600_images/5752a1c843db9843ff4eeacea36d777bd65079ca70a2b12283f139315ac34464.jpg)

### 7.2 碳 NMR 谱图中的 F 偶合

**氟苯的 ¹³C NMR**：
- 本位碳（直接连 F）：¹J_CF ≈ 250 Hz
- 所有环碳都与 F 偶合，随距离增加 J 值衰减

![](clayden 有机化学/Clayden中文版_402-600_images/60ac6b8bce73b8806bc6588d1be2fe9fa0c6b56353f50bc85c6ae6e80154e9fe.jpg)

**三氟乙酸**：
- CF₃ 碳：¹J_CF = 283 Hz（四重峰），高度低场
- 羰基碳：²J_CF = 43 Hz（四重峰）

![](clayden 有机化学/Clayden中文版_402-600_images/ccf0359bfe1fb341d0e5f3a218ef11f22b722474c813691a2f56d3bdaec7211e.jpg)

### 7.3 ¹³C 伴线与质子去偶

- ¹³C 伴线 (satellites)：因 1.1% ¹³C 丰度产生的微弱双重峰
- 为什么碳谱看不到与质子的偶合？因为 ¹J_CH 太大（~125 Hz），会使信号严重重叠
- 标准 ¹³C NMR 在质子去偶条件下记录（用次级 RF 源照射整个质子光谱）
- ¹³C 伴线在强峰两边 ~0.5% 峰高处可见

![](clayden 有机化学/Clayden中文版_402-600_images/4dac4e4ac40f24e37db9e297c49dbbae55a86d76ebc9d6af9c7b43d1dd33598c.jpg)

## 八、光谱法鉴定产物实例

### 8.1 羟胺对烯基酮加成产物的鉴定

- 羟胺 (NH₂OH) 与烯基酮加成，产物分子式 C₆H₁₁NO
- 两种可能结构：直接加成到 C=O（形成肟）或共轭加成
- **光谱证据**：IR 无 NH 伸缩；¹H NMR 无烯烃质子，但在 2.63 ppm 有 CH₂ 基
- **结论**：只有共轭加成产物（环状异噁唑啉）符合数据

![](clayden 有机化学/Clayden中文版_402-600_images/3ae7d416c2ee81ca22282f5472c3d2858f6ea3f470f2e59f7dd4886ad8082d74.jpg)

### 8.2 烯酮二聚体的鉴定

- 丙酮高温裂解 → 甲烷 + 烯酮（CH₂=C=O）
- 烯酮二聚体 (C₄H₄O₂) 的结构争议
- **光谱证据**：三种质子（非一种），存在烯丙型偶合，C=O 在 185 ppm（羧酸衍生物区域，非酮），全部四个碳不同
- **结论**：环状酯结构（而非更对称的二酮结构）

![](clayden 有机化学/Clayden中文版_402-600_images/831936c497cd9051a8fbdf779aa813e9d1a72c2747c8028d35cd1e2c8a29ad9a.jpg)

### 8.3 烯酮单体的鉴定

- 烯酮二聚体臭氧解 → 缩苹果酸环状酸酐（四元环酸酐）
- IR：两条 C=O 带均在高频（估算 1715 + 50 + 65 = 1830 cm⁻¹）
- ¹H NMR：δ 4.12 ppm 2H 单重峰（CH₂ 被两个 C=O 去屏蔽）
- ¹³C NMR：C=O 在 160 ppm（羧酸衍生物），CH₂ 在低场

![](clayden 有机化学/Clayden中文版_402-600_images/e9e7cfcbbdba282be7ccf03c4f0b103f5c41a2aa493e81d15feddfca092eff7c.jpg)

![](clayden 有机化学/Clayden中文版_402-600_images/ebc023d14a940dd85b46b887782da365a7e5f5ef57db13eb4ac35ff7550aec65.jpg)

![](clayden 有机化学/Clayden中文版_402-600_images/e70ccf5e42f3c676387eb2d645627b0d210637fd12a1e9c3643aee139c662541.jpg)

### 8.4 立方烷与四面体烷的光谱鉴定

**立方烷 (C₈H₈)**：
- MS：分子离子 m/z = 104
- IR：仅 3000 cm⁻¹ 的 CH 伸缩
- ¹H NMR：δ 4.0 ppm 单重峰（8H 等价）
- ¹³C NMR：δ 47.3 ppm 单线（8C 等价）

**四面体烷 (t-BuC)₄ vs 环丁二烯 (t-BuC)₄**：
- 两者 MS、IR、¹H NMR 均相同
- ¹³C NMR 区分：四面体烷仅有饱和碳；环丁二烯在 152.7 ppm 有不饱和碳信号
- 三环酮光照 → 四面体烷；加热 → 异构化为环丁二烯

![](clayden 有机化学/Clayden中文版_402-600_images/f4233b889517264113f87614e6ff582d584eaba7294e3afd8b087c28be1a3e7c.jpg)

![](clayden 有机化学/Clayden中文版_402-600_images/867f17aff9e24343271e438027ba84e308467653ab592e48d74822e0b9c1f34d.jpg)

### 8.5 袖斑蝶性信息素的结构鉴定

- 来源：特立尼达蝴蝶（中美长袖斑蝶）的性信息素
- 仅获微量（6 mg），可完成 MS 和 IR
- MS：m/z 135（奇数 → 可能含 N），组成 C₈H₉ON
- IR：1680 cm⁻¹（C=O）
- ¹H NMR：无醛质子，仅一个甲基，一对三重峰（-CH₂CH₂- 连接两个吸电子基团），双峰（芳环质子）
- 吡咯环质子的偶合模式和化学位移（6.09, 6.69 ppm，J = 2.5 Hz）→ 确定取代位置

### 9.3 质子位移 vs 碳位移的比较

- 质子位移通常能很好地符合化学性质的理解，且具有可加和性
- 碳位移受 α 和 β 位取代基的复杂影响，不能简单加和
- 例如：CN 基使甲基碳向高场位移 (-6.6 ppm)，但使 β 碳向低场位移 (+14.4 ppm)

## 十二、竞赛题型线索

### 12.1 光谱综合解析型
- 给定 MS、IR、¹H NMR、¹³C NMR 数据，推导未知化合物结构
- 利用 C=O 伸缩频率估算值与实测值的对比验证结构假设
- 利用偶合常数和裂分模式构建分子骨架

### 12.2 羰基化合物分类型
- 利用 ¹³C NMR 区分醛酮（~200 ppm）和羧酸衍生物（~175 ppm）
- 利用 IR C=O 伸缩频率区分各类羧酸衍生物
- 利用 ¹H NMR 醛基质子（9–10 ppm）区分醛和酮

### 12.3 异核偶合型
- 利用 ¹J_PH 判断 P-H 键的存在（亚磷酸 vs 磷酸结构）
- 利用 ¹J_CF 判断 C-F 键的数量和位置
- 利用 ³¹P NMR 判断磷的化学环境

### 12.4 结构鉴定实例型
- 天然产物的微量光谱鉴定（利用有限数据逐步缩小范围）
- 高度对称分子的光谱简化（立方烷、四面体烷）
- 反应中间体的光谱检测（烯酮、碳阳离子）

## 十三、存疑或待验证之处

1. **¹³C 伴线的实际观测**：文中说"在基线垂直放大时可见"，实际操作中需要很高的信噪比和放大倍数。

2. **碳位移的不规则性**：CN 基使甲基碳向高场位移但使 β 碳向低场位移，这一"不规则"现象的深层原因涉及磁各向异性和超共轭效应，文中未充分展开。

3. **烯酮二聚体结构的历史争议**：文中提到酯结构和二酮结构之争，最终通过多种光谱手段解决。这是一个经典的光谱鉴定案例。

4. **环丁二烯的反芳香性**：文中说"4n 而非 4n+2"是反芳香性的判据，但更准确的说法是 Hückel 规则要求 4n+2 个 π 电子的平面环状共轭体系才具有芳香性。

5. **炔烃化学位移的双重解释**：s 成分增多导致屏蔽增强和圆筒形感应电流的屏蔽效应同时存在，文中两者都提到了但未量化各自的贡献。
