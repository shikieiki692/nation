## 三、核心内容提炼

### 3.1 化学键概述

化学键四面体：共价键、离子键、金属键、次级键。实际物质中常含多种键型（如石墨：层内σ键+离域π键，层间π…π和范德华力）。

### 3.2 H₂⁺的结构和共价键本质

**变分法处理H₂⁺**：

选线性变分函数 $\psi = c_a\psi_a + c_b\psi_b$，解出：

$$\psi_1 = \frac{1}{\sqrt{2+2S}}(\psi_a+\psi_b) \quad (\text{成键}), \qquad \psi_2 = \frac{1}{\sqrt{2-2S}}(\psi_a-\psi_b) \quad (\text{反键})$$

**三个关键积分**：
- **α（库仑积分）**：≈H原子1s能量
- **β（交换积分）**：<0，是使E₁降低的主因（**核心**）
- **S（重叠积分）**：0<S<1，与核间距有关

**共价键本质**：ψ₁²中多出2ψ_aψ_b项→核间电子云密度增加→同时受两核吸引→体系能量降低→成键。

### 3.3 分子轨道理论（考纲10.5核心）

**MO理论要点**：
- 分子中每个电子在核和其余电子的平均势场中运动
- 分子轨道由原子轨道线性组合（LCAO）得到
- **三条件**：①能级相近 ②对称性匹配 ③轨道最大重叠
- 轨道数目守恒，能量改变（一升一降）
- 电子按Pauli/能量最低/Hund规则填充

**轨道分类**：
| 类型 | 对键轴对称性 | 节面数 |
|------|------------|--------|
| σ | 圆柱对称 | 0 |
| π | 含键轴平面为节面 | 1 |
| δ | 含键轴两平面为节面 | 2 |

**键级** = (成键电子数 - 反键电子数) / 2

**第二周期双原子分子MO能级**：

**情况A（O₂, F₂）——2s-2p能级差大，无混杂**：

$$\sigma_{2s} < \sigma^*_{2s} < \sigma_{2p_z} < \pi_{2p_x}=\pi_{2p_y} < \pi^*_{2p_x}=\pi^*_{2p_y} < \sigma^*_{2p_z}$$

**情况B（B₂, C₂, N₂）——2s-2p能级差小，s-p混杂**：

$$1\sigma_g < 1\sigma_u < 1\pi_u(×2) < 2\sigma_g < 1\pi_g(×2) < 2\sigma_u$$

s-p混杂结果：1σu为弱反键，2σg为弱成键。下标改用g/u（中心对称/反对称）。

**关键实例**：

| 分子 | 电子组态 | 键级 | 未成对电子 | 磁性 |
|------|---------|------|-----------|------|
| H₂ | (σ₁ₛ)² | 1 | 0 | 反磁 |
| He₂⁺ | (σ₁ₛ)²(σ₁ₛ\*)¹ | 0.5 | 1 | 顺磁 |
| B₂ | ...(1πu)² | 1 | 2 | **顺磁**（s-p混杂关键证据） |
| N₂ | ...(1πu)⁴(2σg)² | 3 | 0 | 反磁 |
| O₂ | ...(π\*)² | 2 | 2 | **顺磁** |
| F₂ | ...(π\*)⁴ | 1 | 0 | 反磁 |
| CO | 与N₂等电子 | 3 | 0 | 反磁 |

**异核双原子分子**：g/u不再适用，按顺序标σ和π。CO与N₂等电子（10个价电子），键级3。

### 3.4 价键理论

- 未成对电子自旋相反配对成键
- 共价键饱和性（配对后不能再配对）
- 共价键方向性（沿最大重叠方向）
- 配位键：孤对电子→空轨道（A→B）

**MO vs VB比较**：
- VB：定域轨道，适合基态结构/几何构型
- MO：离域轨道，适合光谱/激发态/磁性

### 3.5 分子光谱（了解层）

**转动光谱**（远红外/微波）：
- 刚性转子：$E_R = J(J+1)\frac{h^2}{8\pi^2 I}$，选律ΔJ=±1
- 转动常数 $B = h/(8\pi^2 Ic)$
- 由光谱→求I→求核间距r

**振动光谱**（红外）：
- 简谐振子：$E_v = (v+1/2)h\nu$，选律Δv=±1
- 零点能 $E_0 = h\nu/2$
- Morse势能→非谐性修正
- **力常数** $k = 4\pi^2c^2\tilde{\nu}_e^2\mu$，k越大→键越强
- **红外活性**：振动伴随偶极矩变化

## 五、典型例题与常见错误

### 典型例题

**例1（必做）**：写出O₂、N₂、CO的分子轨道电子排布→判断键级和磁性
- O₂：(σ₂ₛ)²(σ₂ₛ\*)²(σ₂ₚz)²(π₂ₚ)⁴(π₂ₚ\*)²→键级2，2个未成对电子，顺磁
- N₂：含s-p混杂→(1σg)²(1σu)²(1πu)⁴(2σg)²→键级3，反磁

**例2（竞赛）**：B₂为何顺磁？→s-p混杂使1πu低于2σg→(1πu)²有2个未成对电子

**例3（了解）**：由CO的IR光谱振动波数求力常数→判断键强度

### 常见错误

| 错误 | 说明 |
|------|------|
| **s-p混杂条件搞混** | B₂/C₂/N₂有混杂（2s-2p近），O₂/F₂无混杂（2s-2p远） |
| **键级公式记错** | 是(成键-反键)/2，不是(成键-反键) |
| **O₂顺磁性不能用Lewis结构解释** | 这是MO理论的重大胜利，Lewis结构无法解释 |
| **CO的MO等电子体判断** | CO与N₂等电子（都是10个价电子），但CO有极性 |
| **红外活性判断** | 同核双原子（H₂/N₂/O₂）无红外活性（无偶极矩变化），CO₂有不对称伸缩振动有活性 |
