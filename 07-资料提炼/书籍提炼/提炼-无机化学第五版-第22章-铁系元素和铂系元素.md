## 三、教学逻辑锚点

1. **Fe(II)/Fe(III) 为主线**：还原性（Fe²⁺）与氧化性（Fe³⁺）互为镜像，中间是配合物稳定化调控——邻二氮菲把 Fe³⁺/Fe²⁺ 电对从 0.77V 抬到 1.15V（Fe²⁺ 配物更稳定）。
2. **Co(II)→Co(III) 配合物氧化**：Co³⁺ 水合不稳定（1.92V），配 NH₃ 后骤降（0.108V）→ 空气中 O₂ 即可氧化 [Co(NH₃)₆]²⁺。配位稳定化改变氧化还原方向的经典证明。
3. **Ni 平面正方形 vs 四面体**：d⁸ 四配位两种极端——[Ni(CN)₄]²⁻（强场 dsp² 平面）vs [NiCl₄]²⁻/[Ni(NH₃)₄]²⁺（弱场 sp³ 四面体），配体场强决定构型。
4. **18 电子规则串联羰基配合物**：Fe(CO)₅、Ni(CO)₄、Co₂(CO)₈、Os₂(CO)₉ 全部 18e⁻ 稳定；[Co(CO)₄] 单核 17e⁻ 不稳定 → 二聚。竞赛金属有机入门钥匙。
5. **铂系 = 配位化学博物馆**：氯铂酸、蔡斯盐（金属-烯烃反馈键）、顺铂（抗癌）、PdCl₂+CO 鉴定——稀有金属惰性单质 + 丰富配位化学的对照。
6. **过渡金属通性收束**：22.3 一节是全章乃至全书的总结——半径/镧系收缩、间充式氢化物、氧化物酸碱性、颜色来源（d-d/电荷迁移）、M—M 键。

## 四、核心内容提炼

### 22.1 铁系元素（Fe、Co、Ni）

**价层构型** 3d⁶⁻⁸4s²；稳定氧化态：Fe +2/+3（不稳定 +6）、Co +2、Ni +2。元素电势图：
- 酸性：Fe³⁺ ─0.771→ Fe²⁺ ─(-0.44)→ Fe；Co³⁺ ─1.92→ Co²⁺ ─(-0.227)→ Co
- 碱性：Co(OH)₃ + e⁻ = Co(OH)₂ + OH⁻，E°=0.17V

#### 1. 存在与单质
- 铁地壳 4.1%（第 4 位）：赤铁矿 Fe₂O₃、磁铁矿 Fe₃O₄、褐铁矿 2Fe₂O₃·3H₂O、菱铁矿 FeCO₃；黄铁矿 FeS₂ 硫高不宜炼铁（制 H₂SO₄ 原料）。钴：砷钴矿 CoAs₂、辉钴矿 CoAsS、硫钴矿 Co₃S₄。镍：硅镁镍矿、镍黄铁矿 (Ni,Fe)₉S₈、红砷镍矿 NiAs、辉砷镍矿 NiAsS（我国硫化物镍储量世界第二）。
- 物理：Fe 灰（纯银白）、Co 灰、Ni 白；均有强磁性（磁性材料）；Fe/Ni 延展好，Co 硬而脆；Fe→Co→Ni 半径略减、密度略增、熔点降。
- **活泼性 Fe > Co > Ni**；纯铁/钴/镍在空气和纯水中稳定，含杂质铁潮湿空气锈蚀（电化学：Fe=Fe²⁺+2e⁻；O₂+2H₂O+4e⁻=4OH⁻；4Fe(OH)₂+O₂=2Fe₂O₃+4H₂O）→ 铁锈 Fe₂O₃·nH₂O。浓硝酸钝化（致密氧化膜）。
- 高温：红热与 S/Cl₂/Br₂ 剧烈；200-300℃ 与卤素 → FeF₃/FeCl₃/FeBr₃，但 **FeI₃ 不存在**（Fe³⁺ 氧化 I⁻）；赤热与水蒸气 → Fe₂O₃+H₂。Co 与 F₂ → CoF₃，与其他卤素只得 Co(II)。Ni 与 F₂ 生成保护膜。
- 铁系难与强碱反应；**镍最稳定，可作熔融强碱坩埚**。微细镍粉吸氢 935 倍自身体积。
- 高纯铁：H₂ 还原高纯 Fe₂O₃ 或 [Fe(CO)₅] 热分解。Co 提取：C/Al 高温还原 + 电解纯化。Ni：羰基法（[Ni(CO)₄] 热分解）得高纯镍。

#### 2. 简单化合物
**铁**：
- 氧化物：FeO 黑（隔绝空气热解 FeC₂O₄ 制得，活性高能自燃）、Fe₂O₃ 红棕、**Fe₃O₄ = Fe(FeO₂)₂ 铁酸亚铁**（含 Fe(II)/Fe(III)）：`Fe₃O₄ + 8HCl = FeCl₂ + 2FeCl₃ + 4H₂O`。
- 氢氧化物：无氧下 Fe²⁺+碱 → 白绿 Fe(OH)₂ → 空气迅速灰蓝绿（Fe(II)/Fe(III) 氢氧化物混合物）→ 棕红 Fe(OH)₃。Fe(OH)₂ 微溶浓 NaOH，但不称两性。
- 亚铁盐：Fe²⁺ 遇 O₂/Br₂/HNO₃ 易氧化；**莫尔盐** FeSO₄·(NH₄)₂SO₄·6H₂O（浅蓝绿，空气中稳定，氧化还原滴定还原剂）；**绿矾** FeSO₄·7H₂O（蓝绿，铁屑+稀硫酸）。
- Fe³⁺ 水解：强酸盐溶水得淡紫 [Fe(H₂O)₆]³⁺ → 水解黄色 [Fe(OH)(H₂O)₅]²⁺ → 二聚体 [Fe₂(OH)₂(H₂O)₈]⁴⁺ → 棕色 β-FeO(OH) 胶体 → Fe₂O₃·nH₂O 沉淀。遇 Na₂CO₃/Na₂S 均得 Fe(OH)₃（水解表现）。FeCl₃ 处理污水（pH6-7 胶体 FeO(OH) 吸附悬浮物/重金属/磷酸盐）。
- 铁铵矾 NH₄Fe(SO₄)₂·12H₂O（鞣革）；无水 FeCl₃ 棕黑（500-700℃ 铁屑+Cl₂），熔点 307.6℃ 可升华，400℃ 以下气态二聚体 Fe₂Cl₆，750℃ 单聚，真空>500℃ 分解 FeCl₂+Cl₂。
- **Fe³⁺ 中等氧化剂**：氧化 KI/H₂S/SO₂/Sn²⁺；刻蚀电路板 `2Fe³⁺+Cu=2Fe²⁺+Cu²⁺`。
- **高铁酸盐 FeO₄²⁻**（紫色）：强碱中氧化 `2Fe(OH)₃+3Cl₂+10OH⁻=2FeO₄²⁻+6Cl⁻+8H₂O`；Ba²⁺ → 红棕 BaFeO₄；酸性极强氧化不稳定 `4FeO₄²⁻+20H⁺=4Fe³⁺+3O₂↑+10H₂O`。

**钴**：
- 氧化物：CoO 灰（蓝色染料）、Co₃O₄ 黑（Co(II)/Co(III)）。
- Co(OH)₂：先生成**蓝色不稳定**，放置/加热 → 粉红稳定；**两性**：溶稀 HCl（`Co(OH)₂+2HCl=CoCl₂+2H₂O`）与浓 NaOH（`Co(OH)₂+2NaOH=Na₂[Co(OH)₄]`）。
- **Co(OH)₂ 碱中/空气中易氧化 → Co(OH)₃**；Co(OH)₃ 与 Co₃O₄ 中 Co(III) 酸性氧化性强：`Co₃O₄+8HCl=3CoCl₂+Cl₂↑+4H₂O`；`2Co(OH)₃+6HCl=2CoCl₂+Cl₂↑+6H₂O`。原因：Co³⁺/Co²⁺ E°=1.92V（酸）vs Co(OH)₃/Co(OH)₂ E°=0.17V（碱）。
- Co²⁺ 无水盐颜色：CoF₂ 红、CoCl₂ 蓝、CoBr₂ 绿、CoI₂ 黑；水合盐粉红。**CoCl₂ 水合变色指示剂**（硅胶干燥指示剂、变色花）。铝板氧化层 + 极稀 Co(NO₃)₂ 灼烧 → 蓝 Co(AlO₂)₂ 偏铝酸钴。
- Co³⁺ 水溶液不能稳定存在（氧化水 `4Co³⁺+2H₂O=4Co²⁺+4H⁺+O₂`）；可氧化 Mn²⁺→MnO₄⁻。市售 +3 价钴试剂仅 CoF₃；电解氧化 Co(II) 得蓝色 Co₂(SO₄)₃·18H₂O（含 [Co(H₂O)₆]³⁺，干态稳定）。

**镍**：
- NiO 绿、Ni(OH)₂ 绿。NiO(OH)（黑）：`2Ni²⁺+Br₂+6OH⁻=2NiO(OH)↓+2Br⁻+2H₂O`；组成同水合 Ni₂O₃，Ni +3，极强氧化剂：`2NiO(OH)+6HCl=2NiCl₂+Cl₂↑+4H₂O`。Ni³⁺ 水中不能存在。
- **氧化性对比**：Fe(OH)₂、Co(OH)₂ 易被空气 O₂ 氧化；**Ni(OH)₂ 不被空气氧化**（需 Br₂ 等强氧化剂碱性介质，现配现用）。
- Ni²⁺ 水合盐绿色（NiCl₂·6H₂O/NiSO₄·7H₂O/Ni(NO₃)₂·6H₂O），用于电镀。

**氨水行为差异**：Fe(OH)₂/Fe(OH)₃ 不溶氨水（无氨配物，Fe²⁺/Fe³⁺ + 氨水 → 氢氧化物沉淀）；**Co(OH)₂/Ni(OH)₂ 易溶氨水生成配位化合物**（有 NH₄Cl 时溶解度增大）。
- 硫化物：FeS、Fe₂S₃、CoS、NiS 均黑色难溶，溶于稀盐酸。

#### 3. 配位化合物
**铁**：
- 卤：Fe³⁺+Cl⁻ → 黄 [FeCl₄]⁻、[FeCl₄(H₂O)₂]⁻（FeCl₃·6H₂O 实为反式 [Fe(H₂O)₄Cl₂]Cl·2H₂O）。**F⁻ 作 Fe³⁺ 掩蔽剂**：[FeF₅(H₂O)]²⁻ 无色稳定常数大（消除颜色干扰+阻止反应）。
- **SCN⁻ 鉴定 Fe³⁺**：红色 [Fe(SCN)ₙ]³⁻ⁿ（n=1~6），主成分 [Fe(SCN)(H₂O)₅]²⁺，浓度大深红。
- 氰配合物：黄血盐 K₄[Fe(CN)₆]·3H₂O（Fe²⁺+过量 CN⁻；低毒因 K≈1×10³⁵）；赤血盐 K₃[Fe(CN)₆]（黄血盐 + Cl₂ 氧化；K≈1×10⁴²）。**黄血盐遇 Fe³⁺、赤血盐遇 Fe²⁺ 均生成蓝色 Fe₄^III[Fe^II(CN)₆]₃（普鲁士蓝/滕氏蓝），结构完全相同**。可溶性普鲁士蓝 K[Fe^IIIFe^II(CN)₆]：Fe(III)/Fe(II) 交替排列于正六面体顶点，CN⁻ 位于棱上（C→Fe(II)，N→Fe(III)），K⁺ 居空穴。普鲁士蓝/滕氏蓝结构：顶点一个 Fe(II) 被水分子替代，同时 3 个 CN⁻ 也被 H₂O 替代。晒蓝图技术基于此。
- 草酸：K₃[Fe(C₂O₄)₃]·3H₂O 绿色，C₂O₄²⁻ 双齿，具光学活性（旋光异构）；见光分解 `2K₃[Fe(C₂O₄)₃] 光= 2FeC₂O₄ + 2CO₂↑ + 3K₂C₂O₄`（感光化学基础）。
- 磷酸：Fe³⁺+H₃PO₄ → 无色 [Fe(HPO₄)₃]³⁻、[Fe(PO₄)₃]⁶⁻（黄色褪去）。
- **邻二氮菲 (phen)**：[Fe(phen)₃]²⁺ 红色（氧化 → 蓝 [Fe(phen)₃]³⁺），**氧化还原指示剂**。Fe²⁺ 配物比 Fe³⁺ 配物稳定：[Fe(phen)₃]³⁺/²⁺ E°=1.15V > [Fe(H₂O)₆]³⁺/²⁺ 0.77V。
- **棕色环实验**：[Fe(NO)(H₂O)₅]²⁺ 棕色。磁矩 3.8μB → 3 个单电子全属 Fe → d⁷ Fe⁺；配位时 NO 反键 2π* 电子转移给中心 Fe²⁺ → Fe⁺ + NO⁺（NO⁺ 与 CO 等电子体）；NO⁺ 提供 5σ 电子成 σ 配键，同时以空 2π* 接受 Fe⁺ 的 d 电子成反馈 π 键。
- **二茂铁 [Fe(C₅H₅)₂]**：夹心式橙黄固体；气态重叠式、固态交错式（室温非规则）；Fe(II) 夹于两茂环间，C—C 与 Fe—C 键长分别相等；**Fe 空 d 轨道与茂环 5 个 p 轨道重叠形成非定域 π 配位键**；无未成对电子（抗磁）。1951 年合成，1973 Nobel（Wilkinson/Fischer）。用途：汽油抗震剂、橡胶/硅树脂熟化剂、紫外线吸收剂、火箭燃料添加剂。
- 羰基：单核 [Fe(CO)₅]、双核 [Fe₂(CO)₉]；热稳定性差，热解制高纯金属粉。

**钴**：
- **八面体 6 配位 Co(II) 粉红～紫，四面体 4 配位 Co(II) 蓝色**（区分配位环境）。平衡：[Co(H₂O)₆]²⁺（粉红）+4Cl⁻ ⇌ [CoCl₄]²⁻（蓝）+6H₂O——加热/加浓 HCl 变蓝，冷却复原。
- [Co(SCN)₄]²⁻ 蓝色，K≈1.0×10³（较小，水相不明显）；乙醚/戊醇萃取提高灵敏度 → **鉴定 Co²⁺**。不溶水蓝 Hg[Co(SCN)₄] 作磁矩校正标准物。
- 钴氨：Co²⁺+适量氨水 → 蓝绿沉淀；过量 → 黄 [Co(NH₃)₆]²⁺；空气中 O₂ 慢氧化 → 橙黄 [Co(NH₃)₆]³⁺。`[Co(NH₃)₆]³⁺+e⁻=[Co(NH₃)₆]²⁺` E°=0.108V（配位后 Co(III) 大稳）。**Co(III) 配物多为 Co(II) 配物氧化制备**（间接法）。
- K₃[Co(NO₂)₆] 黄色微溶 → Na₃[Co(NO₂)₆] 沉淀 K⁺（钾的鉴定/分离）。

**镍**：
- [Ni(H₂O)₆]²⁺ 绿色；+氨水 → 绿 Ni(OH)₂ 沉淀 → 过量溶 → 蓝 [Ni(NH₃)₆]²⁺；[Ni(en)₃]²⁺ 紫色。
- 氰：Ni(CN)₂ 绿沉淀 → [Ni(CN)₄]²⁻ 黄色（**正方形 dsp²**）→ 过量 CN⁻ → [Ni(CN)₅]³⁻ 红色（四角锥/三角双锥两种）。
- **丁二酮肟鉴定 Ni²⁺**：鲜红色二丁二酮肟合镍螯合物沉淀。
- Ni(III)：紫色 K₃[NiF₆]（氧化水，拉长八面体 [NiF₆]³⁻）；黑色五配位 [NiBr₃(PEt₃)₂]（三角双锥）。
- 羰基：[Ni(CO)₄] 单核无色液体（最早发现），sp³ 杂化正四面体；**Ni 3d⁸4s² 共 10e⁻ + 4 CO × 2 = 18e⁻ 满 9 条价层轨道 → 满足 18 电子规则**。热分解制高纯镍。Co 单核 [Co(CO)₄] 17e⁻ 不稳定；双核 **Co₂(CO)₈** 含端羰基 + 桥羰基（酮式）+ Co—Co 键；每个 Co 6 配位：强场 CO 下 3d⁷4s² 重排 3d⁸4s¹，d²sp³ 不等性杂化（3 空 + 3 单电子轨道）；3 空轨道接 3 端羰基、2 单电子轨道接 2 桥羰基、1 条成 Co—Co。价层 9+6（端）+2（桥）+1（M—M）=18e⁻。

**生物配位化合物**：
- **血红素（Hb）**：Fe²⁺ + 卟啉衍生物大环配位化合物；O₂ 疏松结合于 Fe²⁺（高氧分压结合、低分压解离），不氧化 Fe²⁺。**CO 是强场配体，与 Hb 亲和力远大于 O₂ → HbCO 丧失运 O₂/CO₂ 机能 = 一氧化碳中毒**。
- **维生素 B₁₂**：钴 + 咕啉配位化合物；治恶性贫血。无机钴盐有毒（甲状腺肿、进行性心衰），不能替代 B₁₂。

### 22.2 铂系元素（Ru、Rh、Pd、Os、Ir、Pt）

**价层构型**：正常排布 Os 5d⁶6s²、Ir 5d⁷6s²；特殊排布 Ru 4d⁷5s¹、Rh 4d⁸5s¹、**Pd 4d¹⁰5s⁰**、Pt 5d⁹6s¹。d 轨道更扩展，参与成键更强，更多氧化态（OsO₄ 中 Os +8）。半径相差不大（镧系收缩）。

#### 1. 单质
- 除 Os 发蓝、Pt 灰外均银白；Ru/Os 硬脆，其余有延展性。铂坩埚处理 HF 反应；铂铑合金热电偶；铱合金笔尖。
- 高熔点（最低 Pd 也 1554.8℃）；**Os/Ir/Pt 密度>20 g/cm³，锇是密度最大金属**。
- **惰性**：常温不与卤素/氧/硫反应；Pd 溶硝酸/热浓硫酸；Pt 不溶硝酸溶王水 → H₂[PtCl₆]；Ru/Rh/Os/Ir 对王水惰性。与碱+KNO₃/KClO₃/Na₂O₂ 共熔可氧化。

#### 2. 简单化合物
- **氧化物**：RuO₂ 灰黑（1000℃ Ru+O₂）；Rh₂O₃ 暗灰；PdO 绿黑；OsO₄ 黄（Os+O₂）；IrO₂ 棕；PtO₂ 近黑（PtCl₄+碱 → 两性水合二氧化物 → 加热脱水）。**RuO₄ 制取两步**：Ru+Na₂O₂ 共熔 → Na₂RuO₄；酸性 +NaClO₃ 氧化 → RuO₄。RuO₄ 黄针状（熔点 25.4℃、沸点 40℃），易挥发极毒，氧化盐酸；180℃ 爆炸分解 `RuO₄ 加热= RuO₂+O₂`。OsO₄ 黄剧毒（熔点 40.6℃、沸点 131.2℃），有机合成氧化剂。**RuO₄/OsO₄ 共价四面体，微溶水、易溶 CCl₄，挥发性用于分离 Ru/Os**。
- **卤化物**（表 22-1）：氟化物最多且氧化数最高；OsF₇ 唯一七卤；除 Pd 外均有六/五氟化物，全部有四氟化物。高价氟化物稳定，其他卤素偏低价。Ru/Rh/Ir 稳定 +3（三卤化物）；Pt +4/+2；Pd +2。**PtF₆ 最强氧化剂之一**：氧化 O₂ → O₂⁺[PtF₆]⁻、Xe → Xe[PtF₆]（链接 Ch18 Bartlett 实验）。铂系五氟化物均为四聚体（4 个 MF₆ 八面体共用顶点 F 成环）。**α-PdCl₂ 链状（类 CuCl₂，四配位平面正方形）；β-PdCl₂ 以 Pd₆Cl₁₂ 结构单元（6 Pd 八面体，顶点外切平面 4 Cl）**。**PdCl₂ 鉴定 CO**：`PdCl₂+CO+H₂O=Pd↓+CO₂+2HCl`（黑色沉淀，灵敏）。

#### 3. 配位化合物
- **氯铂酸 H₂[PtCl₆]·6H₂O**（王水溶铂后蒸发，橙黄吸湿）；钾盐/铵盐难溶（K₂[PtCl₆]、NH₄ 盐），钠盐可溶。H₂[PtCl₆]+KNO₃ 灼烧 → PtO₂。H₂[PdCl₆]/H₂[PtCl₆] 均 d²sp³ 八面体；Pd(IV)/Pt(IV) 有氧化性：SO₂/H₂C₂O₄ 还原为低价态酸 `H₂[PdCl₆]+SO₂+2H₂O=H₂[PdCl₄]+H₂SO₄+2HCl`；乙醛还原 `K₂[PtCl₆]+CH₃CHO+H₂O=K₂[PtCl₄]+CH₃COOH+2HCl`；甲酸钠还原为铂黑 `Na₂[PtCl₆]+2HCOONa=Pt↓+4NaCl+2HCl+2CO₂`。
- **蔡斯盐 K[Pt(C₂H₄)Cl₃]**：[Pt(C₂H₄)Cl₃]⁻ 平面正方形（Pt dsp² 杂化）；3 个 Cl⁻ 占 3 顶点，第 4 顶点为乙烯（C—C 垂直正方形平面）；乙烯 π 成键轨道对配入 Pt dsp²（第 4 配位键），Pt 的 d 轨道向乙烯空 π* 反馈 → **反馈键活化乙烯 C—C**（首个金属-烯烃配合物）。
- **顺铂 [PtCl₂(NH₃)₂]**（顺式，抗癌）；[PdCl₂(NH₃)₂]/[PtCl₂(NH₃)₂] 均有顺反异构、反磁。Pt(II) d⁸ 四配位平面四边形最多。
- **羰基配合物**：[Pd(CO)₄]、[Ru(CO)₅]、[Os(CO)₅]（单核）；[Rh₂(CO)₈]、[Os₂(CO)₉]（双核）。**[Os₂(CO)₉]**：每 Os 八面体 6 配位，端羰基 4 + 桥羰基 1 + Os—Os 键；价层 8+8（端）+1（桥）+1（M—M）=18e⁻ → 稳定，Os 零氧化态。**[Ru(CO)₄]²⁻、[Os(CO)₄]²⁻** 将金属稳定在 -2 氧化态（负氧化态实例）。

### 22.3 过渡金属元素小结

- **半径**：同周期从左到右缓减；同族上到下略增但远小于主族；**镧系收缩 → 第三过渡系半径≈第二过渡系 → 第三系第一电离能大得多**。
- **物理**：d 电子参与成键 → 金属键强 → 熔沸点高、硬度大、密度大。Ta/W/Re/Os 熔点 >3000℃（W 最高约 3414℃）；Cr/Mn/Mo/Ru/W/Ta/Re/Os 莫氏硬度 >6（**Cr 硬度 9，仅次于金刚石**）；Re/Os/Ir/Pt 密度 >20（**Os 最大 22.587**）。
- **氧化态**：d 电子参与反应 → 多变氧化态；最高 +3（ⅢB Sc/Y/La）到 +8（Ⅷ Ru/Os）。**低氧化态是第一过渡系特点，最高氧化态在最底部高周期元素**（与主族相反）。
- **氢化物**：间充式/金属型氢化物（H 原子钻进金属晶格空隙，保持金属晶格+自由电子），非整比化合物 LaH₂.₇₆、ZrH₁.₉₈。
- **氧化物酸碱性**：最高价氧化物碱性从左到右递减（Sc₂O₃ 碱 → TiO₂ 两性 → CrO₃ 酸酐 → Mn₂O₇ 强酸酐）；同副族同价态下到上碱性增强；同一元素高价氧化物酸性强、低价碱性强（Mn₂O₇ vs MnO）。
- **酸根形式**：高价过渡金属显酸性 → VO₃⁻、CrO₄²⁻、Cr₂O₇²⁻、MoO₄²⁻、WO₄²⁻、MnO₄²⁻ 等；含氧酸强度 H₂CrO₄ K₁=0.18、HTcO₄ K₁=0.5、**HReO₄ K₁=17.8**（最强）、HMnO₄/H₂MnO₄ 也强。
- **氧化性**：V(V)/Cr(VI)/Mn(VII) 强氧化：E°(VO₂⁺/VO²⁺)=0.991V、E°(Cr₂O₇²⁻/Cr³⁺)=1.36V、E°(MnO₄⁻/Mn²⁺)=1.51V。
- **颜色来源**：① d-d 跃迁（d 轨道有电子未充满）→ 互补色：V²⁺(d³)紫、V³⁺(d²)绿、[Co(H₂O)₆]²⁺(d⁷)粉红、[Ni(H₂O)₆]²⁺(d⁸)绿；② **电荷迁移**（d⁰/d¹⁰ 也能有色）：CrO₄²⁻ 黄、MnO₄⁻ 紫、NbCl₅ 黄（d⁰），AgBr 浅黄、AgI 黄、HgI₂ 红（d¹⁰）。
- **配位化合物**：空 d 轨道易成稳定配位化合物（[Zn(CN)₄]²⁻ 低品位金矿提金、维生素 B₁₂、血红素、催化剂）。
- **金属-金属键**：高周期过渡金属易形成 M—M 键（Co₂(CO)₈、Os₂(CO)₉）与 M—M 多重键（[Re₂Cl₈]²⁻ 四重键）。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **22-2/22-3**：Fe/Co/Ni/Pt/Ru 反应配平（Fe³⁺+Cu、FeO₄²⁻+H⁺、Co³⁺+Mn²⁺、NiO(OH)+HCl、Pt 系还原等 30 条）。
- **22-4(2)**：Co → CoCl₂ → [Co(NH₃)₆]Cl₃（钴氨合成，配位+氧化）。
- **22-4(3)**：粗镍 → 高纯镍（羰基法）。
- **22-4(4)**：Ru → Na₂RuO₄ → RuO₄ 两步法。
- **22-5(1)**：MnO₂/PbO₂/Fe₃O₄ 三瓶黑粉鉴别。
- **22-5(2)**：Fe³⁺/Co²⁺/Ni²⁺ 混合鉴别（SCN⁻/丁二酮肟/SCN⁻ 萃取）。
- **22-5(5)**：Al³⁺、Cr³⁺、Fe³⁺、Ni²⁺ 分离；Fe²⁺、Co²⁺、Zn²⁺、Cu²⁺ 分离。
- **22-6**：FeSO₄+碘水+NaHCO₃、Fe³⁺+SCN⁻+SnCl₂、CoCl₂+NaOH 久置+盐酸、[Co(NH₃)₆]SO₄+稀 HCl、FeCl₃+H₂S 无沉淀（氧化还原非复分解）。
- **22-7(1)-(5)**：铁/钴/镍推理判断（含 22-7(3) 淡绿晶体 → NH₃+白沉淀→灰绿→红棕→KI 褐→KMnO₄ 紫等连环推断）。
- **22-8(4)**：黄血盐可直接制、赤血盐不能由 FeCl₃+KCN 直制（Fe³⁺ 氧化 CN⁻）。
- **22-8(5)**：Ni(II) 四面体 vs Pt(II) 平面四边形（d⁸ 强场/弱场）。
- **22-8(6)**：Co²⁺ 鉴定用浓 NH₄SCN + 丙酮萃取（K 小提高显色；Fe³⁺ 干扰用 F⁻ 掩蔽）。
- **22-8(8)**：[Ni(CO)₄] 与 [Ni(CN)₄]²⁻ 均抗磁但结构不同（sp³ 四面体 vs dsp² 平面）。
- **22-8(9)**：配位化合物稳定性比较。

### 常见错误模式
1. **Fe₃O₄ 写法**：写 Fe₂O₃·FeO 不严谨，应为 Fe(FeO₂)₂ 铁酸亚铁。
2. **Fe²⁺/Fe³⁺ + 氨水**：得氢氧化物沉淀，不生成氨配物；只有 Co²⁺/Ni²⁺ 生成氨配物。
3. **Fe³⁺ 遇 Na₂CO₃/Na₂S**：均得 Fe(OH)₃，不是 Fe₂(CO₃)₃/Fe₂S₃。
4. **Co(OH)₂ 颜色**：初生蓝、久置/加热粉红；两性（浓 NaOH）。
5. **Co(III) 氧化性分介质**：酸性 1.92V 氧化 Cl⁻；碱性 0.17V 不能。
6. **普鲁士蓝/滕氏蓝**：结构相同，不是两种物质。
7. **邻二氮菲**：Fe²⁺ 配物比 Fe³⁺ 配物稳定 → E° 从 0.77 升至 1.15V。
8. **[Ni(CO)₄] vs [Ni(CN)₄]²⁻**：均抗磁，但前者 sp³ 正四面体、后者 dsp² 平面正方形。
9. **蔡斯盐构型**：dsp² 平面正方形，乙烯 C—C 垂直平面，有反馈键。
10. **RuO₄/OsO₄**：四面体共价、剧毒、易挥发（CCl₄ 萃取分离），不是离子型。
11. **Pt 溶王水产物**：H₂[PtCl₆]（配位酸），不是简单盐。
12. **18 电子计数**：桥羰基只贡献 1e⁻（单齿配位），M—M 键各贡献 1e⁻。
