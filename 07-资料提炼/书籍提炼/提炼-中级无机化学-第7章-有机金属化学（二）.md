## 二、教学逻辑锚点

**主线：碳配体的"给电子类型"谱系——σ 给予（Ch6 烷基）→ σ+π 接受（Ch6 羰基）→ π 给予（本章）。**

1. **不饱和烃配体（烯/炔）**：π 电子作为给体，Dewar-Chatt-Duncanson（DCD）σ-π 协同模型；配位后 C=C/C≡C 键长增长、键频下降——"反直觉"结构证据（双键被削弱）。
2. **环多烯（Cp 为核心）**：离域 π 给体，夹心化合物；金属茂 MO 能级解释 18e 稳定性（二茂铁）与 19e/20e/15e/16e 系列差异。
3. **卡宾/卡拜（M=C/M≡C）**：多重键，Fischer vs Schrock 两类（电子结构/亲电亲核/合成路线截然不同）。
4. **等瓣相似**：理论升华——把主族碎片（CH₃/CH₂/CH）与过渡金属碎片（MLₙ）用前线轨道类比联通，是"无机-有机筑桥"的 Nobel 级思想。
5. **超分子**：分子间作用力自组装（配位键/次级键/氢键/π 键/离子）。

**教学顺序建议**：烯烃配合物（Zeise 盐，DCD 模型）→ 环戊二烯（夹心化合物，18e）→ 卡宾/卡拜（Fischer/Schrock）→ 等瓣相似（升华）→ 超分子（拓展）。

## 四、知识点提取

### 4.1 金属—不饱和烃化合物（7.1）

**（1）金属—烯烃配合物（7.1.1）**
- **Zeise 盐** K[PtCl₃(C₂H₄)]·H₂O：1827 年 William Zeise 制得（PtCl₄/PtCl₂ 乙醇回流 + KCl/HCl），13 年后才被承认；现代用 K₂PtCl₄ + C₂H₄（稀盐酸）。
- 结构：[PtCl₃(C₂H₄)]⁻ 平面四方，d⁸ Pt(II)；C=C 键与 PtCl₃ 平面近垂直（84°）。
- 乙烯配位后几何变化：
  - C=C 键长 133.7 → 137 pm（增长）；
  - νC=C 1623 → 1526 cm⁻¹（下降）；
  - H 原子远离金属向后弯折，弯折角 α（两 H-C-H 平面法线夹角）32.5°。
- **Dewar-Chatt-Duncanson（DCD）模型**：C₂H₄ 充满 π 轨道 → M σ 给予（σ 键）+ M dπ → C₂H₄ 空 π* 反馈（π 反馈键）= σ-π 配键。
  - 协同效应：σ 给予降低 C=C 电子密度、π 反馈将电子填入反键轨道，两者都削弱 C=C 键。
  - 实际计算：Zeise 盐中 σ 键成分比 π 反馈重要得多。
- 几何类型：三角形 Ni(PPh₃)₂(C₂H₄)、平面四方 [PtCl₃(C₂H₄)]⁻、三角双锥 Fe(CO)₄(C₂H₄)。
- 乙烯桥配合物：[(η⁵-C₅H₅)₂Zr(Et)]₂(μ-C₂H₄)、[Zr₂X₆(PEt₃)₄](μ-C₂H₄)；桥乙烯 C-C 可长达 156 pm；边桥乙烯基（μ-HC=CH₂，Os₃ 簇）。

**（2）金属—炔烃配合物（7.1.2）**
- 与乙烯类似，但炔有第二组垂直 π/π* 轨道 → 增强 M-炔相互作用。
- 结构：R-C≡C-R 弯折（如 [PtMe(PMe₂Ph)₂(MeC≡CMe)]⁺ C≡C 122pm 几乎不变；Ni(Me₃CNC)₂(PhC≡CPh) C≡C 129.1pm vs 自由 119pm；PtClMe(AsMe₃)₂(F₃C-C≡C-CF₃) C≡C 132pm）。
- 炔可成桥（Os₂(CO)₈(μ-HC≡CH)）、与羰基反应成环（成环反应生成新配体）。

### 4.2 金属—环多烯化合物（7.2）

**（1）概述**
- 环多烯含 2π、6π、10π 电子体系（图 7.10），如 C₃H₃⁺（2π）、C₅H₅⁻/C₆H₆（6π）、C₈H₈²⁻（10π）。
- 夹心化合物（sandwich）：两个平行环夹金属。
- 数目最多最重要的是**环戊二烯配合物**。

**（2）制备（7.2.1）**
- 环戊二烯为弱酸 pKₐ≈20，与强碱生成 C₅H₅⁻ 盐。
- 3 法：
  1. Na/NaH + C₅H₆（THF）→ NaCp，再与金属卤化物/羰基化物反应（最常用）：2NaCp + FeCl₂ → Cp₂Fe + 2NaCl。
  2. 强有机碱（过量 Et₂NH）中和 HCl：2C₅H₆ + CoCl₂ + 2Et₂NH → Cp₂Co + 2Et₂NH₂Cl。
  3. 直接反应：C₅H₆(g) + Mg → Cp₂Mg + H₂；C₁₀H₁₂（双环戊二烯）+ 2Fe(CO)₅ → [CpFe(CO)₂]₂。

**（3）立体结构（7.2.2）**
- 离子型（K/Rb/Cs；Sr/Ba）vs 共价型（Be/Ca；第一过渡系除 Mn 外）。
- **hapto（ηⁿ）命名**：η¹（monohapto，σ 型，1 个 C）；η⁵（pentahapto，π 型，5 个 C）。
- (C₅H₅)₂M 型：
  - 覆盖式 eclipsed（D₅ₕ）vs 交错式 staggered（D₅ₕ 环转 36°，D₅ₙ）。
  - 二茂铁气相平衡构型为**覆盖式**；Cp 环转动势垒极低（3.8 kJ/mol），室温晶体中环不规则。
  - 二茂铁 C-C 140.3 pm、Fe-C 204.5 pm。
  - Cp₂Pb/Sn/Ge：两环**不平行**。
  - Cp₂Be：气相不对称夹心（Be 到两环 147.2/190.3 pm）；固相"滑动"（η⁵ + η¹）。
- (C₅H₅)₄M 型：Ti/Hf = (η⁵)₂(η¹)₂；Zr = (η⁵)₃(η¹)。
- (C₅H₅)ₓML_y 混合配体：如 (η⁵-C₅Me₅)₃ThH、[η⁵-C₅Me₅]₂Ru₂C₆₀。
- 聚合物：[(C₅H₅)(C₅H₄)NbH]₂ 二聚体、(C₅H₅In)_n 无限链、[(C₅H₅)₂Pb]_n；桥基 μ-(η⁵:η⁵-C₅H₅) 等。

**（4）电子结构与化学键（7.2.3）**
- 金属茂 MO 能级图（图 7.19）：每个 Cp 提供 a + e₁ + e₂ 三组 π 轨道；M-Cp 强成键来自 **e₁g**（M d_xz/d_yz 与 Cp π 重叠）。
- **二茂铁 18e 最稳定**：Cp⁻ 各 6e（12e）+ Fe(II) 6e = 18e；9 个成键/非键 MO 全满、10 个反键全空 → 封闭壳层；加热 500℃、浓盐酸煮沸不分解。
- 系列稳定性：Cp₂V 15e、Cp₂Cr 16e（顺磁，2 未成对）、Cp₂Mn 17e（离子型）、**Cp₂Fe 18e（最稳定）**、Cp₂Co 19e（易氧化为 [Cp₂Co]⁺，与 Cp₂Fe 等电子）、Cp₂Ni 20e。
- 反应性：Friedel-Crafts 酰基化、丁基锂金属化、磺化。

### 4.3 金属—卡宾和卡拜化合物（7.3）

**（1）三类 M-C 键总览（表 7.2）**
| 配体 | 通式 | 键 | 实例 |
|------|------|-----|------|
| 烷基 | -CR₃ | M-C 单键 | H₃C-Zn-CH₃ |
| 卡宾 | =CR₂ | M=C 双键 | (CO)₅W=C(OMe)Ph |
| 卡拜 | ≡CR | M≡C 叁键 | Br(CO)₄Cr≡CPh |

- 自由卡宾 CR₂：C 形式氧化态 +2，仅 6 价电子；单重态（孤对占 sp²，空 p）vs 三重态（自旋平行分占 sp² 和 p）。

**（2）卡宾：Fischer vs Schrock（表 7.3）**
| 特征 | Fischer 型 | Schrock 型 |
|------|-----------|-----------|
| 典型金属 | d 区中后过渡金属 Cr(0)/W(0)/Fe(0) | 前过渡金属 Ti(IV)/Ta(V) |
| 其他配体 | 强 π 接受体（CO） | σ/π 给予体（烷基、Cp、Cl） |
| 卡宾 R 基 | 至少一电负性杂原子 O/N | H、烷基或芳基 |
| 电子计数 | 18e | 10~18e |
| 卡宾碳电荷 | δ+（亲电） | δ-（亲核） |
| 成键 | dπ(M)→pπ(C) 反馈（类 CO 但弱） | CR₂²⁻ 四电子给予体（σ+π） |

- 电子结构根源：后过渡金属 dπ 轨道能量低（图 7.21a）→ 反馈给 pπ(C)；前过渡金属 dπ 高（图 7.21b）→ 电子转移至 pπ(C) 形成 CR₂²⁻，金属氧化态 +2。
- **合成**：Fischer 型 = 羰基配体亲核进攻（W(CO)₆ + LiR → 卡宾，1964 Fischer & Maasböl；氨基化物→含 N 卡宾）；Schrock 型 = 烷基脱质子（Cp₂TaMe₃ + Ph₃C⁺BF₄⁻ → [Cp₂TaMe₂]⁺ + NaOMe → Cp₂(Me)Ta=CH₂）。
- **反应**：Fischer 卡宾碳亲电（受亲核进攻：胺、有机锂）；Schrock 卡宾碳亲核（受亲电进攻：AlMe₃、HCl 质子化→烷基）。两类无截然分界。
- 结构证据：Cr=CR₂ 204 pm vs Cr-C 单键 ~220 pm；Ta=CH₂ 202.6 pm vs Ta-CH₃ 224.6 pm。
- 催化应用：Pd 卡宾催化 Heck 反应；Rh(I)/Ru(II) 卡宾催化烯烃加氢/氢化硅烷化；W 卡宾催化炔聚合。

**（3）卡拜（7.3.2）**
- 通式 LₙM≡CR，R = H/烷基/芳基/SiMe₃/NEt₂/PMe₂/SPh/Cl。
- Fischer 型：低氧化态、π 接受体配体，如 X(CO)₄M≡CR（M=Cr/Mo/W）；Schrock 型：高氧化态、给体配体，如 (Me)₃W≡CMe（次烷基配合物 alkylidyne）。
- M≡C 叁键 = 1σ + 2π；卡拜碳 sp 杂化（一对孤对 + 两个简并 p 轨道各 1 电子）。
- 结构证据：Cr≡C 168 pm（短于卡宾 204 pm）。
- **合成**：Fischer 型 = 卡宾 + Lewis 酸（(CO)₅Cr=C(OMe)Ph + BCl₃ → [(CO)₅Cr≡CPh]⁺）；Schrock 型 = 卡宾脱质子。
- 极性：中性卡拜 M≡C 极性方向为 M≡C，亲核剂攻金属、亲电剂攻卡拜碳。

### 4.4 等瓣相似模型（7.4）

- **分子片（fragment）**：MLₙ 是构成有机金属化合物的结构单元（M(CO)₅、M(CO)₄、M(CO)₃、M-Cp、M-烯/炔）。
- 八面体 MLₙ：金属 d²sp³ 杂化，留下 t₂g 三轨道 + 指向缺顶方向的 1~3 个杂化轨道 = 前线轨道。
- **等瓣相似定义**：两分子片前线轨道（数目、对称性、能量、形状、电子数）相似 → 等瓣（isolobal）。符号 ⟶₀（双箭头下半瓣）。
- **经典对应**：
  - d⁷-ML₅（Mn(CO)₅）⇌ CH₃·（可二聚/共聚：Mn₂(CO)₁₀、CH₃-Mn(CO)₅）
  - d⁸-ML₄（Fe(CO)₄）⇌ :CH₂（可二聚/三聚：乙烯、环丙烷类似物）
  - d⁹-ML₃（Co(CO)₃）⇌ CH（可四聚：立方烷类似物）
- **应用**：
  - 预示合成：[Rh(CO)(η⁵-C₅Me₅)]₂（CH₂ 二聚体类似物）、(H₂C)[CpRh(CO)]₂、(η⁵-C₅Me₅)Cu-PPh₃、(CO)₅Cr[CpRh(CO)]₂。
  - 预示结构：HRe₃(CO)₁₂Sn(CH₃)₂（经 SnR₂⇌CR₂⇌CH₂⇌Fe(CO)₄⇌Re(CO)₄⁻ 链）、Os₅(CO)₁₉（经 CH₂⇌Os(CO)₄）。
- **局限性**：等瓣建造的化合物不一定稳定（(OC)₄Fe=Fe(CO)₄ 仅低温观测到）；不能预示羰基桥接方式（Fe₃(CO)₁₂ 实际含 2 个 μ₂-CO）。

### 4.5 超分子有机金属化合物（7.5）

- 自组装作用力 5 类：
  1. **配位键**（dative bond，Lewis 酸碱）：[MeZnNPh₂]₂、[MeZnSBuᵗ]₅、双类立方烷 Zn 簇。
  2. **次级键**（secondary bond，弱于共价强于范德华）：Sb⋯Sb 364.5 pm（共价 286.2 pm）、Hg⋯Cl 336.2 pm、Sn⋯Cl 324/326 pm。
  3. **氢键**：羧基 O-H⋯O（(C₅H₄COOH)₂Fe 二聚体）、C-H⋯O 弱氢键（羰基 O 参与，键角 ~140°）。
  4. **π 键相互作用**：CpM 聚合体（CpNa 线形链、CpK 锯齿链）、Be⋯C≡C。
  5. **离子间相互作用**：[Li(tmeda)]₂[Ph₂MgPh₂MgPh₂]、[LiC(OEt)=CH₂]₄ 立方体。
- 主客体超分子：
  - 有机金属作**主体**：(邻-C₆F₄Hg)₃ 三聚体识别卤离子（Br⁻ 与 6 个 Hg 配位）；有机汞/锡大环类冠醚识别 F⁻/Cl⁻/Br⁻。
  - 含二茂铁冠醚：识别 Rb⁺>K⁺>Cs⁺>Na⁺；可逆单电子氧化还原；阴离子识别（H₂PO₄⁻）。
  - 有机金属作**客体**：二茂铁+环糊精（α-CD 1:2、β/γ-CD 1:1）；Cr(CO)₆/Mo(CO)₆/W(CO)₆ 组装入分子筛。

## 十五、踩坑回流

- Zeise 盐"σ 键比 π 反馈更重要"是 DCD 模型的常见认知偏差——反馈削弱 C=C，但 σ 键是主成分。
- 卡宾计数：Fischer 型视为卡宾碳给 2e（类似 CO）；Schrock 型 CR₂²⁻ 四电子给予体——不能用同一套计数。
- 等瓣相似不等价于等电子：CH₂ 与 Fe(CO)₄ 总电子数不同，但前线轨道相似。
- 二茂铁气相是覆盖式而非交错式——教材与部分参考书表述需注意（晶体中因低转动势垒而无序）。
