## 一、氢分子离子（$\mathrm{H_2^+}$）的变分法微观本质

1. **变分法处理单电子体系**：
   选用线性组合试探波函数 $\psi = c_1 \phi_A + c_2 \phi_B$（$\phi_A, \phi_B$ 分别为两核基态 $1s$ 轨道）。
   能量期望值为 $E = \dfrac{\int \psi^* \hat{H} \psi \mathrm{d}\tau}{\int \psi^* \psi \mathrm{d}\tau} = \dfrac{c_1^2 H_{AA} + c_2^2 H_{BB} + 2c_1 c_2 H_{AB}}{c_1^2 S_{AA} + c_2^2 S_{BB} + 2c_1 c_2 S_{AB}}$。
   由极值条件 $\dfrac{\partial E}{\partial c_1} = 0, \dfrac{\partial E}{\partial c_2} = 0$，导出久期方程组与久期行列式：
   $$\begin{vmatrix} H_{AA} - E & H_{AB} - ES \\ H_{BA} - E & H_{BB} - ES \end{vmatrix} = 0$$
   其中：
   - 库仑积分 $H_{AA} = H_{BB} = \alpha = \int \phi_A^* \hat{H} \phi_A \mathrm{d}\tau$（物理上代表电子处于孤立原子轨道时的有效能量，为负值）；
   - 共振积分（交换积分）$H_{AB} = H_{BA} = \beta = \int \phi_A^* \hat{H} \phi_B \mathrm{d}\tau$（代表电子在两核间共享离域引发的相互作用能，在平衡核间距下为强负值）；
   - 重叠积分 $S = S_{AB} = \int \phi_A^* \phi_B \mathrm{d}\tau$（介于 $0 < S < 1$ 之间）。
2. **能量本征值与反键不稳定性强于成键稳定性**：
   严格解得成键轨道 $\sigma_g 1s$ 与反键轨道 $\sigma_u^* 1s$ 的能量本征值：
   $$E_+ = \dfrac{\alpha + \beta}{1 + S},\quad E_- = \dfrac{\alpha - \beta}{1 - S}$$
   相对解离基准 $\alpha$，成键轨道的稳定化能为 $\Delta E_+ = E_+ - \alpha = \dfrac{\beta - \alpha S}{1 + S} < 0$；
   反键轨道的去稳定化能为 $\Delta E_- = E_- - \alpha = -\dfrac{\beta - \alpha S}{1 - S} > 0$。
   因 $0 < S < 1$，分母 $(1 - S) < (1 + S)$，故：
   $$|\Delta E_-| > |\Delta E_+|$$
   **竞赛核心铁律**：**反键轨道的反键推斥效应永远大于成键轨道的成键稳定效应**。因此，当成键轨道与反键轨道均被充满电子时（如 $\mathrm{He_2}$ 体系填入 $2$ 个成键与 $2$ 个反键电子），总能量必定高于两个孤立原子之和，无法形成稳定共价键。

## 二、MO 理论与 VB 理论的深层哲学对比与等同性

1. **分子轨道理论（MO）**：
   以单电子轨道近似为起点，将电子完全视为离域在多核势场中的粒子。
   基态 $\mathrm{H_2}$ 波函数为：
   $$\Psi_{\mathrm{MO}} = \psi_+ (1) \psi_+ (2) = [\phi_A(1) + \phi_B(1)] [\phi_A(2) + \phi_B(2)]$$
   展开后包含四项：
   $$\Psi_{\mathrm{MO}} = \underbrace{\phi_A(1)\phi_B(2) + \phi_B(1)\phi_A(2)}_{\text{共价结构项 } \mathrm{H-H} (50\%)} + \underbrace{\phi_A(1)\phi_A(2) + \phi_B(1)\phi_B(2)}_{\text{离子结构项 } \mathrm{H^+ H^-} / \mathrm{H^- H^+} (50\%)}$$
   **局限性**：高估了离子结构项的贡献（在平衡核间距下离子态比例偏高，解离极限下导致错误预测解离为 $50\%\ \mathrm{H + H}$ 与 $50\%\ \mathrm{H^+ + H^-}$）。
2. **价键理论（VB）**：
   Heitler-London 模型认为电子主要局域于各自原子轨道，通过自旋配对降低势能。
   基态 $\mathrm{H_2}$ 波函数纯共价形式为：
   $$\Psi_{\mathrm{VB}} = \phi_A(1)\phi_B(2) + \phi_B(1)\phi_A(2)$$
   **局限性**：完全忽略了离子结构的贡献，且难以解释顺磁性（如 $\mathrm{O_2}$ 分子的双未成对电子）。
3. **等价性与组态相互作用（CI）校正**：
   在 MO 理论中引入双电子激发反键组态 $\Psi(\sigma_u^{*2})$ 进行组态相互作用（CI）：
   $$\Psi_{\mathrm{CI}} = c_1 \Psi(\sigma_g^2) - c_2 \Psi(\sigma_u^{*2})$$
   恰好能将过高的离子项系数降低，与引入共价-离子共振杂化（$\Psi_{\mathrm{VB-ionic}} = \Psi_{\mathrm{cov}} + \lambda \Psi_{\mathrm{ion}}$）的现代价键理论在数学上**完全等价收敛于同一个真实电子状态**。

## 三、双原子分子 MO 能级交错与反常机理

1. **同核双原子分子 $2s-2p_z$ 混杂效应**：
   - 第二周期前部（$\mathrm{Li_2, Be_2, B_2, C_2, N_2}$）：$\Delta E_{2s-2p}$ 较小，同属 $\sigma_g$ 对称性的 $2s$ 与 $2p_z$ 轨道发生强相互作用，导致 $\sigma_g 2s$ 能级进一步下沉，而 $\sigma_g 2p_z$ 能级剧烈上抬，**最终翻转高于 $\pi_u 2p$ 能级**。能级顺序为：
     $$\sigma_g 2s < \sigma_u^* 2s < \pi_u 2p_x = \pi_u 2p_y < \sigma_g 2p_z < \pi_g^* 2p_x = \pi_g^* 2p_y < \sigma_u^* 2p_z$$
     由此决定了 $\mathrm{B_2}$（顺磁性，$\pi_u^2$ 两个单电子）与 $\mathrm{C_2}$（反磁性，$\pi_u^4$ 纯双键且均为 $\pi$ 键）的特征性质。
   - 第二周期后部（$\mathrm{O_2, F_2}$）：随着有效核电荷增加，$2s$ 与 $2p$ 轨道能量差显著拉大（$\Delta E > 15\ \mathrm{eV}$），对称性相同的轨道无法有效混杂，维持“正常”能级顺序：
     $$\sigma_g 2s < \sigma_u^* 2s < \sigma_g 2p_z < \pi_u 2p_x = \pi_u 2p_y < \pi_g^* 2p_x = \pi_g^* 2p_y < \sigma_u^* 2p_z$$
     使得 $\mathrm{O_2}$ 基态填入 12 个价电子后，最后两个电子依据 Hund 规则分占两个简并的 $\pi_g^*$ 反键轨道，完美解释了基态氧气分子的顺磁性与三线态特征。
2. **典型异核双原子分子：一氧化碳（$\mathrm{CO}$）微观 MO 架构**：
   - 氧的电负性远高于碳，氧的 $2s, 2p$ 轨道能量均低于碳；
   - 最高已占轨道（HOMO）为微弱反键或非键性质的 $\sigma$ 轨道（$5\sigma$），其电子云空间分布主要集中在碳原子端（碳端拥有高突出的孤对电子），因此 $\mathrm{CO}$ 作为经典 Lewis 碱时，**严格通过碳端向过渡金属空 $d$ 轨道提供 $\sigma$ 配键**；
   - 最低未占轨道（LUMO）为成对简并的 $\pi^*$ 反键轨道（$2\pi^*$），其空轨道主要集中在碳原子端，恰好与过渡金属填充的 $d$ 轨道对称性匹配，形成极强烈的 $d \to \pi^*$ 反馈 $\pi$ 键；
   - **偶极矩佯谬**：尽管氧电负性大，但由于 $5\sigma$ 孤对电子在碳端高度凸出离域，实验测得 $\mathrm{CO}$ 的偶极矩极小（$0.112\ \mathrm{D}$），且偶极方向微弱指向碳负极（$^{\delta-}\mathrm{C\equiv O}^{\delta+}$）。

## 四、Walsh 构型原理与三原子分子几何构型演化

1. **Walsh 规则核心概念**：
   分子平衡构型取决于所有已占分子轨道单电子能量之和 $\sum_i n_i \varepsilon_i$ 随键角变动时的总极小值。
2. **$\mathrm{AH_2}$ 型分子（直线型 $D_{\infty h} \leftrightarrow$ 角型 $C_{2v}$）演化相关图**：
   - 直线型对称群为 $D_{\infty h}$，轨道标号为 $2\sigma_g, 1\sigma_u, 1\pi_u$；
   - 当键角自 $180^\circ$ 弯曲为折线型时，群对称性降为 $C_{2v}$：
     - $1\sigma_u \to 1b_2$（反键性质增加，能量随弯曲上升）；
     - $1\pi_u$ 轨道简并消除，分裂为 $1b_1$（垂直分子平面，能量不变）和 $2a_1$（由于混入中心原子的 $s$ 轨道成分，沿键角弯曲方向重叠急剧增大，**能量剧烈下降**）；
   - **结论法则**：
     - 4 价电子体系（如 $\mathrm{BeH_2}$）：电子填至 $1\sigma_u$（对应 $1b_2$），由于 $1b_2$ 在弯曲时能量上升，体系维持**严格直线型**（$180^\circ$）；
     - 6~8 价电子体系（如 $\mathrm{H_2O}$ 拥有 8 个价电子）：电子填入急剧下降的 $2a_1$ 轨道，克服了 $1b_2$ 的上升，使总能量在弯曲状态达到极小值，故 $\mathrm{H_2O}$ 稳定呈现**角形折线结构**（$104.5^\circ$）。

## 五、HMO 休克尔分子轨道理论核心框架

1. **基本近似假定**：
   - $\sigma-\pi$ 分离假定：假定平面对称体系中 $\pi$ 电子在固定的 $\sigma$ 骨架有效势场中独立运动；
   - 忽略非相邻原子共振积分：$H_{rs} = \beta$（当 $r, s$ 相邻），$H_{rs} = 0$（当 $r, s$ 不相邻）；
   - 忽略所有重叠积分：$S_{rs} = \delta_{rs}$（归一且彼此正交）。
2. **丁二烯（$\mathrm{C_4H_6}$）四中心四电子体系求解范例**：
   令 $x = \dfrac{\alpha - E}{\beta}$，其久期行列式为：
   $$\begin{vmatrix} x & 1 & 0 & 0 \\ 1 & x & 1 & 0 \\ 0 & 1 & x & 1 \\ 0 & 0 & 1 & x \end{vmatrix} = 0 \implies x^4 - 3x^2 + 1 = 0$$
   解得根：$x = \pm \dfrac{\sqrt{5}+1}{2} = \pm 1.618,\quad x = \pm \dfrac{\sqrt{5}-1}{2} = \pm 0.618$。
   能级序列为：
   $$\varepsilon_1 = \alpha + 1.618\beta,\quad \varepsilon_2 = \alpha + 0.618\beta,\quad \varepsilon_3 = \alpha - 0.618\beta,\quad \varepsilon_4 = \alpha - 1.618\beta$$
   4 个 $\pi$ 电子填入两个成键轨道，体系 $\pi$ 电子总能量：
   $$E_\pi = 2(\alpha + 1.618\beta) + 2(\alpha + 0.618\beta) = 4\alpha + 4.472\beta$$
   两个孤立乙烯分子的 $\pi$ 电子能量为 $2 \times (2\alpha + 2\beta) = 4\alpha + 4\beta$。
   由此推导共轭离域能（Delocalization Energy）：
   $$\Delta E_{\text{deloc}} = (4\alpha + 4.472\beta) - (4\alpha + 4\beta) = 0.472\beta \approx -0.472 \times 75\ \mathrm{kJ\cdot mol^{-1}} \approx -35.4\ \mathrm{kJ\cdot mol^{-1}}$$
   严密证明了丁二烯共轭体系因 $\pi$ 电子离域而获得的额外热力学稳定性。
