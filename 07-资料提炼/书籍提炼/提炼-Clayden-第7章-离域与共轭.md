# 提炼：Clayden 第7章——离域与共轭（Delocalization and Conjugation）

---

## 一、核心概念与定义

### 1.1 共轭（Conjugation）的定义
- **共轭双键**：两根双键仅由一根单键隔开时，称为共轭的（conjugated）。（见 [[共轭效应]]）
- **共轭体系的性质**：共轭双键与孤立双键具有不同的物理性质（如键长）和化学性质（如反应活性）。
- **共轭的要求**：
  - 必须由一根且仅一根单键隔开两根双键
  - 由两根单键隔开的双键**不共轭**（如花生四烯酸中的孤立双键）
  - 未被隔开的双键（如丙二烯）也**不共轭**（两根 π 键正交，无法重叠）

### 1.2 离域（Delocalization）的定义
- **离域**：电子并非定域（localized）在两个特定原子之间，而是分散在多个原子之上。（见 [[离域效应]]）
- **共轭 vs 离域**：共轭描述双键连接成单一 π 体系的方式；离域描述电子的行为。
- **类比**：苯中 π 电子分散在全部六个碳原子上，而非定域在交替的双键中。

### 1.3 描述离域化的方法
- **离域化箭头（delocalization arrow）**：由单线和两端箭头组成的双头箭头，连接同一分子的不同定域表达式。（与 [[共振论]] 的概念密切相关）
- **弯曲箭头**：可用于展示同一分子两种极限结构之间的转换，但并非表示电子"移动"。
- **注意**：离域化箭头 ≠ 平衡箭头。平衡中至少有一根 σ 键改变位置；离域中无 σ 键变化。

## 二、乙烯的结构——起点

### 2.1 乙烯的电子结构
- 两个 sp² 杂化的碳原子，一根 σ 键连接
- 每个碳上剩余的 p 轨道侧面重叠形成 π 键
- π 键中电子可贡献给亲电试剂，使烯烃可做亲核试剂

![](clayden 有机化学/Clayden中文版_11-210_images/f6ab37ecdeb9babdf7f8f07c6eb62bb00007f5ab359f2f7d350b0b599728e4d5.jpg) — 乙烯的分子轨道示意图

### 2.2 成键轨道与反键轨道
- 两个 p 轨道组合 → 一个成键轨道 (π) + 一个反键轨道 (π*)
- 同相结合 → 成键轨道；异相结合 → 反键轨道
- 更高能的轨道具有更多的波节（node）

## 三、苯的结构——离域的经典范例

### 3.1 凯库勒结构的困境
- 苯分子式 C₆H₆，凯库勒提出交替单双键结构
- 问题：1,2-二取代苯只有一种，不存在两种凯库勒结构对应的异构体
- 凯库勒错误地提出"快速平衡（共振）"假说

![](clayden 有机化学/Clayden中文版_11-210_images/b9f3b6f1798e61d4ec9a687ee21f776757a60783158d9feaa39e862be5658f1f.jpg) — 两种凯库勒结构实际是同一化合物

### 3.2 分子轨道解释
- 六个 p 轨道同时重叠，形成六条[[分子轨道理论|分子轨道]]
- 电子在分子平面上下方形成环形电子密度
- **苯不在两种凯库勒结构间共振**——电子等同分布在所有碳原子上

![](clayden 有机化学/Clayden中文版_11-210_images/1aca0a51d617066f01b82f0cc74e7bb4c3230924fcc6b5c4af7584044891599c.jpg) — 苯的分子轨道（环形电子密度）

### 3.3 苯的实验证据
- 电子衍射：平面正六边形，所有 C-C 键长相同（139.5 pm）
- 键长介于 C-C 单键（154.1 pm）和 C=C 双键（133.7 pm）之间
- NMR：质子化学位移一致，证实环状电子离域

![](clayden 有机化学/Clayden中文版_11-210_images/bbbd243368a83556e1c41aad9568a37d8c8f6cae743e8f791774f233415a2154.jpg) — 苯分子的电子衍射图像

## 四、不成环的共轭体系——己三烯与丁二烯

### 4.1 己三烯的结构
- 三根双键、六个电子，但无环
- 两个异构体（顺式/反式）均为平面结构
- 中心双键比两端双键稍长，单键比"常规"单键稍短
- 键长偏离经典值的原因：六个 p 轨道结合产生分子轨道

![](clayden 有机化学/Clayden中文版_11-210_images/036a67ec056f7f5b67903e1eaa074fa929498e10e6dc89ce32a2264d9a2af03a.jpg) — 己三烯的平面结构与键长

![](clayden 有机化学/Clayden中文版_11-210_images/2fda78afd654f35104945d674642050c8c010aeb714ebf8cee8e9f6f547f480c.jpg) — 反己三烯的分子轨道

### 4.2 丁二烯的分子轨道（重点）
- 四个 p 轨道结合 → 四条分子轨道 ψ₁–ψ₄
- **ψ₁**：最低能成键轨道，无波节，所有碳间均为成键作用（净成键 = 3）
- **ψ₂**：次低能，一个波节，C1-C2 和 C3-C4 成键，C2-C3 反键（净成键 = 1）
- **ψ₃**：未占据，净反键 = -1
- **ψ₄**：未占据，净反键 = -3
- 四个电子填入 ψ₁ 和 ψ₂（HOMO 和 LUMO 分别为 ψ₂ 和 ψ₃）（见 [[前线轨道理论]]）

![](clayden 有机化学/Clayden中文版_11-210_images/30d4c6692076cbd83cae5df6d403e302ea4890633903af45b332205d0b95aec9.jpg) — 丁二烯 ψ₁ 和 ψ₂ 的形成

![](clayden 有机化学/Clayden中文版_11-210_images/d7ac7980bfa7eb3e29c890c46c2c71f4a4f839d7517fd115c963d8b70d0b12c3.jpg) — 丁二烯的分子轨道能级图

### 4.3 共轭对反应性的影响
- **热力学更稳定**：共轭丁二烯的总 π 能量低于两个孤立双键
- **HOMO 更高**：丁二烯 HOMO 能量高于乙烯 HOMO → 对亲电试剂更活泼
- **LUMO 更低**：丁二烯 LUMO 能量低于乙烯 LUMO → 对亲核试剂也更活泼
- **结论**：共轭使分子更稳定，但同时使亲电和亲核反应都更活泼

![](clayden 有机化学/Clayden中文版_11-210_images/09f9b7bc37566ba8ff139a09a78cd614d1b973604c6e4d774dfd0ae7b2f596c5.jpg) — 共轭的稳定化与反应活性增强

## 五、紫外可见光谱——共轭的光谱学证据

### 5.1 π → π* 跃迁
- HOMO→LUMO 的能量差决定吸收光波长：$E = hc/\lambda$
- 丁二烯吸收波长（215 nm）长于乙烯（185 nm），因共轭使 HOMO-LUMO 间隙变小
- **一般规律**：共轭程度越高，HOMO-LUMO 间隙越小，吸收波长越长

### 5.2 颜色与共轭的关系
- 少于八根共轭双键的化合物通常只吸收紫外光
- 共轭体系足够大时，吸收进入可见光区，化合物呈现颜色
- **番茄红素（lycopene）**：11 根共轭双键，吸收 ~470 nm 蓝绿色光 → 番茄呈红色
- **靛蓝（indigo）**：利用 n→π* 跃迁产色，被染在牛仔裤上

![](clayden 有机化学/Clayden中文版_11-210_images/be31f0af08823cef5072ab6abbf39204df4770943b3e5f20bc582aa6cd2a30e3.jpg) — 番茄红素的结构

## 六、烯丙基体系——三原子的离域

### 6.1 烯丙基阴离子（Allyl Anion）
- 丙烯用强碱去质子 → sp³ 碳变为 sp²，产生含孤对电子的 p 轨道
- 三条 p 轨道结合 → 三条分子轨道：
  - **ψ₁（成键）**：所有轨道同相重叠，净成键 = +1
  - **ψ₂（非键）**：中心原子位于波节上，无电子密度，净成键 = 0
  - **ψ₃（反键）**：所有轨道异相重叠，净成键 = -2
- 四个电子填入 ψ₁ 和 ψ₂
- **电荷分布**：端碳携带更多电子密度，中心碳较少（ψ₂ 中中心碳在波节上）

![](clayden 有机化学/Clayden中文版_11-210_images/c82ebfcd2e5578309b1d2a8e1ee890711a0de5eb5465b56ebc27ea40cc328d19.jpg) — 烯丙基阴离子的形成与轨道

![](clayden 有机化学/Clayden中文版_11-210_images/985416c9a97015590241ea35e65d903603ac07d4e29ea8196c8a9c36c95000a5.jpg) — 三条分子轨道的形状

![](clayden 有机化学/Clayden中文版_11-210_images/ab83ae5f19dd39d894316a1e2a0f3b2077e500dce329783160d2535e44ecb194.jpg) — 弯曲箭头表达电荷离域

### 6.2 烯丙基阴离子的 NMR 证据
- ¹³C NMR：中心碳 147 ppm，两端碳均 51 ppm
- 两端碳相同 → 证实离域
- 端碳化学位移在双键碳与饱和碳阴离子之间 → 负电荷主要在端碳

![](clayden 有机化学/Clayden中文版_11-210_images/a7b4cef04cee0c82ace8cc40bc1161464df514b473a427ed9f03cdf6bb289921.jpg) — 烯丙基阴离子的 ¹³C NMR 数据

### 6.3 烯丙基阳离子（Allyl Cation）
- 烯丙基溴异裂 C-Br → 烯丙基阳离子 + Br⁻
- 同样三条分子轨道，但仅两个电子填入 ψ₁
- **电荷分布**：正电荷集中在两端碳（ψ₁ 中两端系数更大）
- 共轭导致稳定化——两个电子能量降低

![](clayden 有机化学/Clayden中文版_11-210_images/540b95a13e41aae2a2c70a7e5a8328b8ab6424d78533a20d1e15a63435ffc4cb.jpg) — 烯丙基阳离子的形成

![](clayden 有机化学/Clayden中文版_11-210_images/588580b5c2b9db368c42697f85e0c7fd0708055eca51c5ee20fadda661772c2a.jpg) — 烯丙基阳离子的能级图

### 6.4 烯丙型阳离子的 NMR 证据
- 低温 ¹³C NMR（-80°C）显示对称面存在
- 端碳 224 ppm（强去屏蔽），中心碳 142 ppm
- 证实电荷分散在两个端碳上

## 七、三原子离域的常见结构

### 7.1 羧酸根阴离子（Carboxylate）
- 烯丙基阴离子的等电子体：两个氧原子替代两个碳原子
- 两根 C-O 键长相同（136 pm），介于 C=O（123 pm）和 C-O（143 pm）之间
- 负电荷等同分散在两个氧原子上

![](clayden 有机化学/Clayden中文版_11-210_images/151c8ddb8a4563d1a5c2ebcc99b7a7d9d71f9039c0f9fb3b634aa6795bd50351.jpg) — 羧酸根阴离子的离域结构

### 7.2 硝基（Nitro Group）
- 与羧酸根阴离子等电子体
- 两种表达方式：形式电荷式 vs 配位键式（后者应避免）
- 两根 N-O 键等价，不可画成两根双键（氮无足够轨道）

![](clayden 有机化学/Clayden中文版_11-210_images/e2ec1a9f14480b582ddfa8943d9a1765e6176513f92a4bda355750064f901d73.jpg) — 硝基的两种表达方式

### 7.3 酰胺基（Amide）
- **结构特征**：氮的孤对电子与羰基 π 键共轭，氮必须 sp² 杂化
- **平面形**：包括连在 C 和 N 上的 R 基第一个碳
- **C-N 键部分双键特征**：键长 135 pm（介于 149 pm 单键和 127 pm 双键之间）
- **旋转受阻**：DMF 绕 C-N 键旋转能垒 88 kJ/mol（vs 单键 ~3 kJ/mol）
- **亲电进攻位点是氧**：因氧比氮更富电子
- **对反应性的影响**：酰胺 C=O 是活性最低的羰基之一；酰胺氮难以质子化

![](clayden 有机化学/Clayden中文版_11-210_images/c64721a072d61f5e484d56dbfb1900473733aadeec4ab1ef8b4d23e96069409f.jpg) — 酰胺基的离域

![](clayden 有机化学/Clayden中文版_11-210_images/47764d3e7cf5e852c6988f9ad182911fdf3158034cbc2690edf729506ccd04a9.jpg) — 酰胺基的平面结构

### 7.4 蛋白质中的酰胺
- 氨基酸通过肽键（酰胺键）连接 → 肽 → 多肽 → 蛋白质
- 酰胺单元的平面刚性为蛋白质结构提供稳定性

## 八、芳香性（Aromaticity）

### 8.1 苯的特殊稳定性——氢化热证据
- 环己烯氢化热：120 kJ/mol → 预测苯氢化热 = 360 kJ/mol
- **实际苯氢化热**：208 kJ/mol → 差值 ~150 kJ/mol 为额外稳定性
- 环辛四烯氢化热：410 kJ/mol ≈ 4 × 100（无额外稳定化）

![](clayden 有机化学/Clayden中文版_11-210_images/495b4e9b7bd79298978b03fa5492e40207b4368fb87a2952d1481cfd4389909e.jpg) — 苯的氢化热比较

### 8.2 环辛四烯——非芳香性对照
- 八个 π 电子，但不是平面结构（浴缸形/tub）
- 交替的 C-C 键长（146.2 pm 和 133.4 pm）→ 孤立双键
- 与溴反应得加成产物（烯烃行为），不是取代产物

![](clayden 有机化学/Clayden中文版_11-210_images/dbc778befd1e9f5e8480bb8838aec2ee2577682d1af7bf60a7dba638e9b93bb7.jpg) — 环辛四烯的浴缸形结构

### 8.3 电子数改变的效果
- **环辛四烯双阳离子**（6 个 π 电子）：平面形，所有 C-C 键长相同 → 芳香性
- **环辛四烯双阴离子**（10 个 π 电子）：平面形，所有 C-C 键长相同 → 芳香性
- **关键**：重点不在共轭原子数，而在 π 体系中的电子数

![](clayden 有机化学/Clayden中文版_11-210_images/e8ad606af3da8fc457037639edd03aede520b02baa4bdcc7cceca4b81b9d0167.jpg) — 环辛四烯双阳离子的平面结构

### 8.4 苯的六条 π 分子轨道
- 六条 p 轨道环状排列 → 六条[[分子轨道理论|分子轨道]]（正六边形能级布局）
- **ψ₁**：最低能，无波节
- **ψ₂（二重简并）**：一个波节
- **ψ₃（二重简并）**：两个波节
- **ψ₄**：最高能，三个波节
- 六个电子完美填入 ψ₁ 和 ψ₂（三条成键轨道全满）→ 闭壳层结构

## 九、Hückel 规则——判断芳香性的标准

### 9.1 Hückel 规则的内容
- **芳香（aromatic）**：平面形、完全共轭的单环体系具有 (4n+2) 个 π 电子（n = 0, 1, 2, ...）
- **反芳香（anti-aromatic）**：具有 4n 个 π 电子的类似体系（通常通过非平面化避免）
- **非芳香（non-aromatic）**：既不满足芳香也不满足反芳香条件的体系

### 9.2 Hückel 规则的应用实例
- **苯 [6] 轮烯**：6 个 π 电子（4×1+2）→ 芳香
- **环辛四烯 [8] 轮烯**：8 个 π 电子（4×2）→ 非芳香（非平面）
- **[10] 轮烯**：10 个 π 电子（4×2+2），但全顺式时内角 144° 远大于 120°，张力过大 → 非芳香
- **[18] 轮烯**：18 个 π 电子（4×4+2），反-反-顺排列使键角可为 120° → 芳香

![](clayden 有机化学/Clayden中文版_11-210_images/2176c5b3711b279ce82065edd8814b76870f61417bd3b714e1e096ea34034a2b.jpg) — 全顺-[10]轮烯的张力问题

![](clayden 有机化学/Clayden中文版_11-210_images/41b32d4cc610680b67575051b2fbb4b280024bcdd6adb7339dfacd1f46bb05f7.jpg) — [18]轮烯的平面芳香结构

### 9.3 闭壳层与稳定性的关系
- 闭壳层（closed shell）：所有成键轨道被完全占据
- **苯**：6 个 π 电子，三条成键轨道全满 → 闭壳层 → 极其稳定
- **平面环辛四烯**：8 个 π 电子，六个填入成键轨道，两个必须进入简并非键轨道（洪特规则各一个）→ 无闭壳层 → 不稳定

![](clayden 有机化学/Clayden中文版_11-210_images/2ffb76044439893ae4b2b5f46d1b248e151ee4331f85689bf6020e3f4383b7ad.jpg) — 苯的闭壳层 vs 环辛四烯的开放壳层

### 9.4 芳香阴离子与阳离子
- **环戊二烯阴离子**：去质子后 6 个 π 电子 → 芳香，所有键长相同
- **环庚三烯阳离子**：6 个 π 电子 → 芳香
- **原理**：中性环辛四烯得失电子后均可达到 (4n+2) 电子数 → 变平面、芳香

![](clayden 有机化学/Clayden中文版_11-210_images/7605e3dc9117aa816d3d64549a983447783a550e497642682b909cca7cd5f81e.jpg) — 环戊二烯阴离子的芳香性

## 十、杂环芳香化合物

### 10.1 吡啶（Pyridine）
- 氮替换苯中一个 CH → 六个 π 电子（三根双键贡献）
- 氮的孤对电子在 sp² 轨道中（不在 π 体系中），不参与芳香性
- 保持苯的芳香性和稳定性

### 10.2 吡咯（Pyrrole）
- 氮的孤对电子贡献到 π 体系 → 六个 π 电子
- 双键仅贡献四个电子，氮孤对贡献两个 → 满足 Hückel 规则
- 吡咯中氮不易碱化（孤对电子已参与芳香体系）

![](clayden 有机化学/Clayden中文版_11-210_images/0e363af416d92451239c039c56fc952dda1d43814db6ca6bd8028251f7b57e76.jpg) — 吡啶与吡咯的芳香结构

### 10.3 重要提示
- 大多数芳香体系都是杂环（含 N、O、S 等杂原子）
- 超过 50% 的有机化合物包含芳杂环
- 芳杂环化学详见 Clayden Chapter 29–30

## 十五、存疑或待验证之处

1. **"共振"术语的使用**：本章明确避免使用"共振"一词，但国内教材仍广泛使用。竞赛答题时需注意表述一致性。
2. **[10]轮烯的芳香性争议**：全顺式[10]轮烯因张力非芳香，但1,6-亚甲桥基[10]轮烯表现芳香性——竞赛中对"张力导致非平面"的判断需具体分析。
3. **杂环芳香性的 π 电子计数**：吡咯中氮孤对是否贡献电子、吡啶中氮孤对是否参与芳香——这是常见考点，需准确区分。
4. **萘的芳香性强弱**：萘有 10 个 π 电子但芳香性弱于苯，稠环体系的芳香性判断规则较为复杂。
5. **环辛四烯双阳离子/双阴离子的稳定性**：平面化是否完全消除角张力？实际分子中仍存在一定的环张力。
