# Clayden 第29章：芳杂环 1 -- 反应 资料提炼

---

## 一、核心概念与芳香杂环概览

### 1.1 芳杂环的定义
- 将苯环中的一个或多个碳原子替换为杂原子（N、O、S）所得的芳香体系。
- 五元和六元环的芳杂环有成千上万种，大多数有机化合物（约三分之二）属于这一类别。

### 1.2 芳杂环与药物
- 奎宁（quinine）：含喹啉环，用于预防和治疗疟疾。
- 安替比林（antipyrine, 1887）：第一种合成药物，含吡唑环。
- 磺胺吡啶（sulfapyridine, 1938）：第一种有效抗生素，含吡啶环。
- 泰胃美（Tagamet, 1970s）：抗溃疡药物，含咪唑环。
- 万艾可（Viagra, 1997）：治疗阳痿，含嘧啶-吡唑稠环。

### 1.3 杂环中氮原子的两种角色
- **类吡啶氮（pyridine-like）**：孤对电子在环平面的sp²轨道中，不参与离域。表现为碱性、亲核性。
- **类吡咯氮（pyrrole-like）**：孤对电子在p轨道中，参与芳香离域。不表现为碱性。

### 1.4 命名法要点
- "-ine（啶、嗪）"结尾 → 氮杂环（吡啶pyridine、吡咯pyrrole等）。
- "-ole（唑）"结尾 → 五元杂环（吡唑pyrazole、咪唑imidazole等）。
- "azo-（氮杂）" → 含氮。
- "pyr-"（吡）→ 通常指六元环（例外：吡咯pyrrole是五元环）。
- 噻吩（thiophene）= 硫杂五元环；呋喃（furan）= 氧杂五元环。

## 二、吡啶（Pyridine）的反应性

### 2.1 吡啶的电子结构
- 苯中一个CH被N替换 → 吡啶。氮是三价的，没有N-H键，孤对电子占据环平面的sp²轨道。
- 氮的电负性降低了所有π轨道的能量：
  - HOMO较低 → 亲核性较弱（面对亲电试剂不如苯活泼）。
  - LUMO较低 → 亲电性较强（面对亲核试剂比苯活泼）。

### 2.2 吡啶是弱碱
- 共轭酸pKa = 5.5（吡啶鎓离子酸性与羧酸相像）。
- 氮的孤对电子不能离域到环中（在与环p轨道正交的sp²轨道中）。
- 吡啶常被用作酰基化反应的亲核催化剂。

### 2.3 吡啶N-氧化物（Pyridine N-oxide）
- **制备**：吡啶 + m-CPBA 或 H₂O₂/AcOH → 吡啶N-氧化物。
- **性质**：氧上的电子离域在吡啶环中，升高HOMO → 使环面对亲电试剂活泼。
- **亲电取代**：发生在4号位（远离带正电的氮）。
- **脱氧**：(MeO)₃P 或 PCl₃ 还原脱氧（P=O键极稳定驱动反应）。
- **亲核取代**：N-氧化物可活化2,4-位的亲核取代（O可转化为离去基团）。

### 2.4 吡啶的亲电取代——困难
- **规则：吡啶不发生简单的亲电取代反应。**
- 原因：氮使环缺电子；亲电试剂还会进攻氮，使环更不活泼。
- **例外**：只有当吡啶含有给电子取代基（NH₂、OMe）时才能发生。
- 活化基的邻位/对位被选择性取代。
- **实例**：氟吡汀起始原料的硝化——双重活化的吡啶（MeO + NH₂）。

### 2.5 吡啶的亲核取代——容易
- 氮降低LUMO → 2-和4-位的卤素容易被亲核试剂取代。
- 机理类似羰基亲核取代：加成-消除（四面体中间体）。
- 2-和4-氯代吡啶相当于"酰氯"，2-甲氧基吡啶相当于"酯"。
- **实例**：氟吡汀（flupirtine）的合成。

### 2.6 吡啶酮（Pyridone）
- 2-羟基吡啶 ↔ 2-吡啶酮互变异构：倾向于"酰胺"式（C=O强键提供稳定性）。
- 吡啶酮可与POCl₃反应转化为氯代吡啶（类似羧酸→酰氯）。
- 4-吡啶酮有类似行为；3-羟基吡啶仅以"酚"式存在（不能互变为"酰胺"式）。

### 2.7 吡啶作为催化剂和试剂
- **亲核催化**：吡啶氮进攻亲电试剂（如Br₂）→ N-溴代吡啶鎓离子 → 与苯反应。
- **三溴化吡啶鎓**：吡啶与Br₃⁻的盐，稳定的晶体替代液溴。
- **PCC和PDC**：吡啶与CrO₃的配合物，用于醇的氧化。
  - PCC（氯铬酸吡啶鎓）：伯醇→醛（避免过度氧化）。
  - PDC（重铬酸吡啶鎓盐）：类似用途。

### 2.8 联吡啶（Bipy, 2,2'-bipyridyl）
- 吡啶的二聚体，双齿配体，偏爱Fe(II)。
- 由吡啶在FeCl₂·4H₂O存在下高温高压反应制得（可能经自由基机理）。

## 三、吡咯（Pyrrole）的反应性

### 3.1 吡咯的电子结构
- 苯中一个CH=CH被N替换 → 吡咯。氮的孤对电子放入p轨道参与离域。
- 六个π电子：四个来自双键 + 两个来自氮孤对电子。
- 所有位点都几乎同样地富电子（HOMO在2号位有较大系数）。

### 3.2 吡咯的酸碱性
- **不是碱**：pKa（共轭酸）≈ -4，质子化发生在碳上而非氮上。
- **NH酸性**：pKa = 16.5（与醇相当），比饱和胺（吡咯烷pKa≈35）酸性强10²³倍。
- 强酸（H₂SO₄）会使吡咯聚合——质子化在碳上，引发聚合。

### 3.3 吡咯的亲电取代——极其容易
- **规则：吡咯几乎太容易发生亲电取代。**
- 与Br₂反应不需要Lewis酸，且全部四个空位都会被取代。
- **区域选择性**：优先在2号位（和5号位）反应。
  - 原因：2号位反应的中间体是线形共轭体系（更稳定），3号位反应的中间体是交叉共轭的。
  - 2和5位被阻塞时，才在3（或4）位反应。

### 3.4 控制吡咯的单取代
- **Vilsmeier反应**：N,N-二甲基酰胺 + POCl₃ → 碳亲电试剂（无需强酸或Lewis酸）。
  - DMF + POCl₃ → 甲酰基（CHO）引入（替代Friedel-Crafts甲酰化）。
- **Mannich反应**：吡咯 + 甲醛 + 胺 → 2-位氨甲基化产物。
  - 托美汀（tolmetin）和氯吡酸（clopirac）的合成。
- **阻塞策略**：用酯基阻塞2,5-位 → 亲电取代在3位 → 酯水解+脱羧恢复2位。

### 3.5 吡咯的脱羧
- 吡咯-2-羧酸加热脱羧 → 亲电试剂是质子（由羧酸本身提供）。
- 逆向的Friedel-Crafts反应。

### 3.6 吡咯的氮阴离子
- NaH或其他碱可使吡咯去质子化 → 吡咯阴离子。
- 阴离子中氮含两对孤电子：一对离域在环中（在p轨道），另一对定域在sp²轨道（新的HOMO）。
- 亲电试剂进攻氮（sp²轨道上的孤电子）。
- **实例**：N-Boc吡咯的制备（DMAP做碱+亲核催化剂）。

### 3.7 吡咯的亲核取代
- 相对稀少，需要吸电子基（NO₂、C=O、SO₂R）活化。
- **实例**：酮咯酸（ketorolac）的分子内亲核取代（烯醇盐进攻，亚磺酸根离去）。

## 四、呋喃（Furan）的反应性

### 4.1 呋喃的亲电取代
- 比苯活泼，但不如吡咯。
- 区域选择性：优先2号位（和5号位）。
- **Friedel-Crafts酰基化**：用醋酸酐 + 弱Lewis酸（如BF₃）。
- 酮产物被钝化后，可在5号位进一步硝化。

### 4.2 呋喃的酸敏性——重要！
- 呋喃的[[芳香性]]比吡咯弱。
- 如果有形成稳定键（如C-O单键）的希望，倾向于加成而非取代。
- **在甲醇中与Br₂反应**：不发生溴代，而是发生1,4-加成→开环→得到"马来醛"（顺丁烯二醛）的等价物。
- **酸性水解**：呋喃 → 1,4-二羰基化合物（可逆反应）。

### 4.3 呋喃的Diels-Alder反应
- 呋喃尤其适合Diels-Alder反应（作为双烯体）。
- 由于双烯体是芳香性的，反应是可逆的，得到热力学产物（外型加合物）。

### 4.4 呋喃的开环
- 酸催化水解 → 1,4-二羰基化合物。
- 糠醛（2-呋喃甲醛）是廉价起始原料（早餐麦片工业副产物）。

### 4.5 呋喃的锂化反应
- 杂原子相邻的C-H基可被正丁基锂选择性锂化。
- 锂化物可与多种亲电试剂反应。
- 产物水解得1,4-二酮；碱中分子内羟醛环化得环戊烯酮。

## 五、噻吩（Thiophene）的反应性

### 5.1 噻吩的亲电取代
- 活性最差的五元杂环（硫的3p轨道与碳的2p轨道重叠不好）。
- 活性与苯相当。
- Friedel-Crafts酰基化在2和5号位发生。

### 5.2 噻吩的开环
- Raney Ni脱硫还原：不仅去除硫，还还原环中双键 → 饱和烷基链。
- Friedel-Crafts酰基化后脱硫 → 1,6-二酮。

### 5.3 噻吩的Diels-Alder反应
- [[芳香性]]阻止噻吩直接参与Diels-Alder反应。
- **解决方案**：氧化为噻吩砜（破坏芳香性）→ 可发生Diels-Alder反应。
- 与炔烃反应后失去SO₂ → 取代苯衍生物。

### 5.4 噻吩的锂化反应
- 与呋喃类似：杂原子相邻的C-H基可选择性锂化。
- 锂化物与亲电试剂反应 → 功能化噻吩。

## 六、五元杂环活性比较

| 性质 | 吡咯 | 呋喃 | 噻吩 |
|:---|:---:|:---:|:---:|
| 亲电取代活性 | 最高 | 中等 | 最低（≈苯） |
| 给电子能力 | N最强 | O次之 | S最差 |
| 2,5-位选择性 | 强 | 强 | 强 |
| 酸敏感性 | 聚合 | 加成/开环 | 相对稳定 |
| Diels-Alder | 可（需活化） | 很好 | 需氧化为砜 |
| 碱性 | 无（pKa~-4） | 无 | 无 |
| NH酸性 | pKa=16.5 | 无 | 无 |

## 七、含多个氮的五元杂环

### 7.1 咪唑（Imidazole）
- **结构**：一个类吡咯氮 + 一个类吡啶氮，1,3-关系。
- **碱性**：pKa（共轭酸）≈ 7（中性水中50%质子化）——比吡啶和吡咯都强。
  - 原因：阳离子和阴离子都在两个氮间平等地分享电荷，完美对称，异常稳定。
- **酸性**：pKa = 14.5（比吡咯强）。
- **互变异构**：室温下快速互变，不能拆分。
- **应用**：
  - 催化硅基化反应（选择性保护伯醇）。
  - 碳酰二咪唑（CDI）：双亲电试剂，替代有毒的光气。
  - 组氨酸中的咪唑基：酶催化中的酸/碱/亲核催化剂。
  - 甲硝唑（metronidazole）：2-甲基咪唑硝化→N-烷基化。

### 7.2 三唑（Triazole）
- **1,2,3-三唑**：两个互变体等价；去质子得同一阴离子。
- **1,2,4-三唑**：更重要的异构体，是现代杀真菌剂和抗真菌药物的基础。
  - 碱性比咪唑弱（额外类吡啶氮诱导吸电子），但酸性强。
  - 阴离子易制取（NaHCO₃即可）。
- **氟康唑（fluconazole）**：辉瑞抗真菌药物，含两个三唑环。

### 7.3 四唑（Tetrazole）
- 环上仅一个碳原子，pKa ≈ 5（与羧酸相当）。
- 阴离子在全部四个氮原子中离域。
- 可替代药物中的羧酸（CO₂H → 四唑），保持活性。
- **实例**：吲哚美辛的四唑类似物。

### 7.4 含N-N/N=N键的危险性
- 重氮甲烷（CH₂N₂）、叠氮化物（RN₃）易爆。
- 重氮四唑（CN₆）极度危险，分解产生碳原子。

## 八、苯并杂环

### 8.1 吲哚（Indole）
- **结构**：苯环 + 吡咯环稠合，10电子芳香体系。
- **重要性**：色氨酸的组成部分；吲哚生物碱（士的宁、LSD）的骨架。
- **亲电取代**：倾向于**3号位**（与吡咯的2号位不同！）。
  - 原因：3号位反应保留苯环芳香性（仅扰乱五元环的烯胺体系）。
  - 2号位反应会严重干扰苯环芳香性。
- **Vilsmeier反应**：吲哚在3号位甲酰化（与吡咯类似但区域选择性不同）。
- **Mannich反应**：吲哚在3号位发生（与吡咯、呋喃一样好）。
- **实例**：舒马普坦（sumatriptan，抗偏头痛）、昂丹司琼（ondansetron，止吐剂）。

### 8.2 喹啉（Quinoline）
- **结构**：苯环稠合吡啶环（氮与苯环相邻）。
- **亲电取代**：倾向于苯环上（5-位和8-位），给出混合物。
- **亲核取代**：倾向于吡啶环上。
- **实例**：奎宁（quinine，抗疟疾药物）。

### 8.3 异喹啉（Isoquinoline）
- **结构**：苯环稠合吡啶环（氮在另一位置）。
- **亲电取代**：硝化在5号位（产率72%）。
- **实例**：异喹啉生物碱（罂粟碱papaverine）。

### 8.4 喹啉N-氧化物
- 可在吡啶环上发生亲核取代。
- 酰基化试剂处理 → 2号位亲核取代产物。

### 8.5 中氮茚/吲嗪（Indolizine）
- 氮在环连接处（类吡咯氮），十电子体系。
- 亲电取代在五元环上发生。

## 九、含氮和氧/硫的五元杂环

### 9.1 噁唑（Oxazole）和异噁唑（Isoxazole）
- 噁唑：咪唑的氧类似物（O替换NH）。
- 异噁唑：O-N键较弱，不稳定。
- 异噁唑的N-O键可被还原剂切断 → 不稳定的亚胺-烯醇 → 酮 + 胺。

### 9.2 噻唑（Thiazole）和异噻唑（Isothiazole）
- 噻唑：咪唑的硫类似物。
- 异噻唑：S-N键较弱。

### 9.3 噻二唑
- 1,2,5-噻二唑：噻吗洛尔（timolol）的一部分（β-阻断剂）。

## 十、稠环杂环的反应性规则总结

### 10.1 五元杂环（吡咯、呋喃、噻吩）
1. 亲电取代极其容易（吡咯>呋喃>噻吩）。
2. 区域选择性：优先2,5-位（3,4-位被阻塞时才反应）。
3. 呋喃酸敏性强，可发生加成/开环。
4. 噻吩可通过氧化为砜参与Diels-Alder反应。
5. 亲核取代需吸电子基活化。

### 10.2 六元杂环（吡啶）
1. 亲电取代困难（氮使环缺电子）。
2. 亲核取代容易（2,4-位）。
3. N-氧化物可同时活化亲电和亲核取代。
4. 活化基（NH₂、OMe）使亲电取代成为可能。

### 10.3 苯并杂环
1. 亲电取代倾向于苯环（喹啉/异喹啉）或五元环（吲哚）。
2. 吲哚亲电取代在3号位（非2号位）。
3. 亲核取代倾向于吡啶环（喹啉/异喹啉）。

### 10.4 多氮杂环
1. 含两个类吡啶氮的六元环（哒嗪、嘧啶、吡嗪）：几乎无碱性，化学性质主要涉及亲核进攻。
2. 咪唑：异常强的碱（pKa≈7），源于两个氮的协同效应。
3. 三唑/四唑：酸性随氮原子增多而增强。

## 十五、摘录的原始段落（附页码/位置标记）

### 15.1 关于芳杂环的重要性（line 4423）
> "苯在其环状共轭体系中含有六个电子，因而是芳香的。我们由它例外的稳定性得知它的芳香性。"

### 15.2 关于吡啶的亲电取代（line 4540）
> "吡啶上的芳香亲电取代反应不是一个有用的反应。环本身就是不活泼的，并且亲电试剂还会进攻氮，使环更加不活泼。请避免使用简单吡啶上的硝化、磺化、卤代，及 Friedel-Crafts 反应。"

### 15.3 关于吡啶的亲核取代（line 4544）
> "氮原子通过降低 π 体系 LUMO 的能量，使吡啶面对亲核取代反应更加活泼，尤其是在其 2 号和 4 号位。"

### 15.4 关于吡咯的酸性（line 4713）
> "吡咯充当碱的 pKa 大约为 -4，低于 pH -4 时会在碳上发生质子化。与之相比，NH 质子 (pKa 16.5) 可以被相比于移去一般仲胺的质子弱得多的碱移去。"

### 15.5 关于吡咯的亲电取代（line 4701）
> "对于吡咯，几乎一切上述情况都是相反的。它比苯环容易得多地发生亲电取代反应——几乎太容易了——但亲核取代反应则更加困难。"

### 15.6 关于呋喃的Diels-Alder（line 4879）
> "呋喃尤其适合进行 Diels-Alder 反应，由于双烯体是芳香性的，因而反应是可逆的，并且得到热力学产物，外型加合物。"

### 15.7 关于咪唑的碱性（line 4923）
> "咪唑是一个比吡咯和吡啶都强的碱——咪唑鎓离子的 pKa 几乎正好为 7，也就意味着中性水中会有 50% 的咪唑被质子化。"

### 15.8 关于吲哚的3-位选择性（line 5029）
> "许多方面，吲哚的化学性质都是一个活泼的吡咯环，和一个相对不活泼的、靠在一边的苯环的性质——比如，亲电取代往往都会发生在吡咯环上。但吲哚和吡咯在一个重要方面有所不同。在吲哚中，几乎所有试剂的亲电取代都倾向于在3号位发生。"

### 15.9 关于四唑的酸性（line 4999）
> "它们的酸性相当强：失去 NH 形成阴离子的 pKa 大约为 5，基本上与羧酸等同。阴离子在全部四个氮原子中离域（同样也在碳原子上），四个氮原子完成了两个氧原子的工作。"

### 15.10 关于叶酸与药物（line 5238）
> "磺胺药物 (sulfa drugs)，例如磺胺甲氧哒嗪 或磺胺甲噁唑，都能模拟对氨基苯甲酸，并抑制二氢叶酸合成酶。它们的磺酰胺部分，都各自含有一种新的杂环体系。"
