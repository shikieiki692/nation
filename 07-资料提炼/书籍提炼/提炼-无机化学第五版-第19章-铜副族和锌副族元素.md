**本章定位**：从主族进入 ds 区过渡金属的第一章。核心思维是**18 电子构型与 8 电子构型的差异**导致的活性、颜色、配位、极化性质全面不同；同时 Cu⁺/Hg₂²⁺ 的歧化-逆歧化是氧化还原平衡的应用典范。

## 三、教学逻辑锚点

1. **与ⅠA/ⅡA对比**：铜副族 vs 碱金属、锌副族 vs 碱土金属——同 ns 电子数但次外层 18e⁻ vs 8e⁻ → 活性/颜色/配位全面不同。这是理解 ds 区的总钥匙。
2. **活泼性反转**：Zn 电离能比 Cu 大却远比 Cu 活泼（原子化热决定性）；铜副族自身 Cu>Ag>Au 且与碱金属趋势相反。能量分解（原子化热+电离能+水合热）是理解电极电势的通用方法。
3. **歧化-逆歧化的平衡思维**：Cu⁺ 酸中歧化（K=1.4×10⁶）但可用沉淀/配位剂稳住 Cu(I)；Hg₂²⁺ 酸中稳定（逆歧化 K=88.9）但沉淀/配位剂可促歧化。**同一平衡原理、相反方向**。
4. **软硬酸碱在分析中的应用**：Ag⁺ 是软酸，亲 S²⁻/CN⁻/I⁻，故 Ag 对 H₂S 敏感、卤化银溶解度递减、AgI 溶 KCN——串起提金、定影、分离全流程。
5. **颜色来源三分法**：d¹⁰（Cu⁺/Ag⁺/Zn²⁺/Hg²⁺）无 d-d 跃迁 → 无色/电荷迁移显色；d⁹（Cu²⁺）有 d-d 跃迁 → 蓝色；Hg(II) 18e⁻ 强极化 → 深色。

## 四、核心内容提炼

### 19.1 铜副族元素（ⅠB）

**价层构型** (n-1)d¹⁰ns¹。常见氧化态：Cu +1/+2、Ag +1、Au +1/+3。

#### 1. 与碱金属对比（贯穿全章）
- 外层：ⅠB 与 ⅠA 同 ns¹；ⅡB 与 ⅡA 同 ns²。
- 次外层：ds 区 18e⁻ vs 主族 8e⁻ → 单质和化合物性质显著不同。
- 例：Cu 第一电离能 745.5、第二 1957.9 kJ/mol（d、s 能量相近可再失 d 电子 → 变价）；Na 第一 495.8、第二 4562.4（3s 与 2p 能量差大，只能 +1）。

#### 2. 存在形态
- 自然单质：Cu/Ag/Au 均可单质存在（货币金属）。
- Cu：辉铜矿 Cu₂S、黄铜矿 CuFeS₂（Cu₂S·Fe₂S₃）、赤铜矿 Cu₂O、黑铜矿 CuO、孔雀石 CuCO₃·Cu(OH)₂、胆矾 CuSO₄·5H₂O；地壳 5.0×10⁻³%。
- Ag：闪银矿 Ag₂S（与方铅矿共存），铜精炼阳极泥。
- Au：自然金（岩脉金/冲积金）、海水中极微。

#### 3. 单质物理性质
- 重金属、金属光泽（Cu 红、Ag 银白、Au 黄）。
- 导电导热最佳：**Ag 首位、Cu 次之**。
- 延展性极好：1 g 金可拉 3 km 丝、压 0.0001 mm 箔。
- 合金：黄铜（Cu-Zn；特种黄铜加 Pb/Al）、青铜（Cu-Sn；特殊青铜 Cu-Al/Si）、白铜（Cu-Ni 13%~15%）。

#### 4. 单质化学性质
- **活泼性**：Cu>Ag>Au，随原子序数递减（与碱金属相反）——d 轨道屏蔽弱，核电荷吸引力增大；全能量看 Cu→Au 由原子化热+电离能+水合热决定，趋势仍递减（Ag 第一电离能 731.0 比 Cu 小，但总能量更不利）。
- **铜绿**：`2Cu + O₂ + H₂O + CO₂ = Cu(OH)₂·CuCO₃`（防护膜）。
- **Ag 对 H₂S 敏感**：`4Ag + 2H₂S + O₂ = 2Ag₂S + 2H₂O`（黑膜）——Ag⁺ 软酸 + S²⁻ 软碱稳定。
- **酸的反应**：
  - 均不与稀盐酸/稀硫酸放氢。
  - 有 O₂ 时缓溶：`2Cu + 2H₂SO₄(稀) + O₂ = 2CuSO₄ + 2H₂O`。
  - 硝酸/热浓硫酸：
    - `Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O`
    - `3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O`
    - `Cu + 2H₂SO₄(浓) △= CuSO₄ + SO₂↑ + 2H₂O`
  - **Au 只溶于王水**：`Au + HNO₃ + 4HCl = HAuCl₄ + NO↑ + 2H₂O`（Cl⁻ 配位降低 Au³⁺/Au 电势）。
- **配体作用（竞赛重点）**：
  - 强配体 CN⁻ 直接放氢：`2Cu + 8CN⁻ + 2H₂O = 2[Cu(CN)₄]³⁻ + 2OH⁻ + H₂↑`
  - 弱配体需 O₂：`2Cu + 8NH₃ + O₂ + 2H₂O = 2[Cu(NH₃)₄]²⁺ + 4OH⁻`
  - 银金 CN⁻+O₂ 氧化溶解：`4M + 8CN⁻ + 2H₂O + O₂ = 4[M(CN)₂]⁻ + 4OH⁻`（M=Ag, Au）
- **生物**：铜蓝蛋白（亚铁氧化酶，Fe 代谢）；鲎蓝血（铜蛋白输 O₂）。

#### 5. 提取
**铜冶炼（黄铜矿）流程**：
1. 浮选（亲硫端结合矿粒+憎水烃基插气泡）→ 富集 15%~20% 精矿。
2. 焙烧：`2CuFeS₂ + O₂ = Cu₂S + 2FeS + SO₂`；`2FeS + 3O₂ = 2FeO + 2SO₂`。
3. 反射炉 1000℃：`FeO + SiO₂ = FeSiO₃`（熔渣浮上层）；Cu₂S+FeS 共熔=**冰铜**（沉下层）。
4. 转炉：`2Cu₂S + 3O₂ = 2Cu₂O + 2SO₂`；`2Cu₂O + Cu₂S = 6Cu + SO₂↑`（自还原）→ 粗铜 98%。
5. 电解精炼（CuSO₄+H₂SO₄ 电解液）：阳极粗铜溶解、阴极纯铜 99.95%；**阳极泥**（Au/Ag/Pt/Se）提贵金属原料。

**银提取（氰化法）**：`4Ag + 8NaCN + 2H₂O + O₂ = 4Na[Ag(CN)₂] + 4NaOH`；`Ag₂S + 4NaCN = 2Na[Ag(CN)₂] + Na₂S`；Zn 置换：`2[Ag(CN)₂]⁻ + Zn = [Zn(CN)₄]²⁻ + 2Ag`。

**金提取**：
- 汞齐法（Hg 溶金→蒸馏，污染严重已禁用）。
- 氰化法：`4Au + 8NaCN + 2H₂O + O₂ = 4Na[Au(CN)₂] + 4NaOH`；Zn 还原或电解。
- 金精制电解：纯度 99.95%~99.98%。

#### 6. Cu(I) 化合物
- **Cu₂O**：红色（晶粒大小颜色变化）；斐林试剂检验醛基/糖尿病尿糖（`2[Cu(OH)₄]²⁻ + CH₂OH(CHOH)₄CHO → Cu₂O↓ + ...`）；实验室 `4CuO 高温= 2Cu₂O + O₂`；弱碱性、不溶于水，溶于稀酸立即歧化：`Cu₂O + 2H⁺ = Cu + Cu²⁺ + H₂O`；溶氨水得无色 `[Cu(NH₃)₂]⁺`；1235℃ 熔化不分解；半导体、红色染料。
- **CuOH**：极不稳定脱水→Cu₂O。
- **CuCl/CuBr/CuI**：白色，Ksp 依次减小（1.72×10⁻⁷ / 6.27×10⁻⁹ / 1.27×10⁻¹²）。
  - `2Cu²⁺ + 4I⁻ = 2CuI↓ + I₂`（I⁻ 既是还原剂又是沉淀剂）。
  - `Cu²⁺ + Cu + 4Cl⁻ △= 2[CuCl₂]⁻`，稀释→`CuCl↓ + Cl⁻`。
  - CuCl 不溶硫酸/稀硝酸，溶氨水/浓盐酸/碱金属氯化物（[Cu(NH₃)₂]⁺、[CuCl₂]⁻~[CuCl₄]³⁻）。
- **Cu₂S**：黑色；只溶热浓硝酸或 CN⁻：`3Cu₂S + 16HNO₃(浓) △= 6Cu(NO₃)₂ + 3S + 4NO + 8H₂O`；`Cu₂S + 4CN⁻ = 2[Cu(CN)₂]⁻ + S²⁻`。
- **Cu(I) 配位**：d¹⁰ 无 d-d 跃迁，颜色靠电荷迁移。`[Cu(NH₃)₂]⁺` 吸 O₂（气体净化）：`4[Cu(NH₃)₂]⁺ + O₂ + 8NH₃ + 2H₂O = 4[Cu(NH₃)₄]²⁺ + 4OH⁻`；醋酸二氨合铜(I) 吸收合成氨原料气中 CO（加压降温吸、减压加热放，可循环）。

#### 7. Cu(II) 化合物
- **CuO**：黑色碱性；`2Cu(NO₃)₂ △= 2CuO + 4NO₂ + O₂`；>1000℃ 分解为 Cu₂O；高温氧化性。
- **Cu(OH)₂**：浅蓝绿；80℃ 脱水成 CuO（比碱金属氢氧化物稳定性差）；铵离子存在时溶氨水：`Cu(OH)₂ + 4NH₃ = [Cu(NH₃)₄]²⁺ + 2OH⁻`；略两性：溶酸、溶过量浓碱 `Na₂[Cu(OH)₄]`。
- **CuCl₂**：无水黄棕色，**无限长链聚合物**（Cu 在 4 个 Cl 正方形中心）；浓溶液黄色 `[CuCl₄]²⁻`、稀溶液浅蓝 `[Cu(H₂O)₄]²⁺`、混合黄绿/绿色；溶乙醇/丙酮（共价性强）；`CuCl₂·2H₂O △= Cu(OH)₂·CuCl₂ + 2HCl + 2H₂O`（脱水须 HCl 气流保护）；`2CuCl₂ △= 2CuCl + Cl₂`。
- **CuSO₄·5H₂O（胆矾）**：4 个 H₂O 配位 + 1 个 H₂O 氢键连 SO₄²⁻（环境不同 → 脱水温度不同）；无水 CuSO₄ 白色吸水变蓝（检验微量水分/干燥剂）；650℃ 分解；波尔多液（CuSO₄+石灰乳）杀虫。
- **Cu(II) 配位**：d⁹ 顺磁、d-d 跃迁有色；正方形 4 配位为主（[CuCl₄]²⁻、[Cu(H₂O)₄]²⁺、[Cu(NH₃)₄]²⁺）；**缩二脲试验**：Cu²⁺+肽键化合物在 NaOH 中呈紫色（检验蛋白质）。

#### 8. Cu(I)/Cu(II) 互变（歧化核心）
- **歧化**：`2Cu⁺(aq) = Cu²⁺(aq) + Cu↓`，298 K `K=1.4×10⁶`（水合热 Cu²⁺ 2121 ≫ Cu⁺ 582 kJ/mol 所致）。例：`Cu₂O + H₂SO₄(稀) = Cu + CuSO₄ + H₂O`。
- **稳定 Cu(I) 的条件**：必须有沉淀剂或络合剂降低 Cu⁺ 浓度。
  - 沉淀：`Cu²⁺ + Cu + 2Cl⁻ = 2CuCl`（Cu 还原、Cl⁻ 沉淀）。
  - 还原+沉淀：`2Cu²⁺ + 4CN⁻ = 2CuCN↓ + (CN)₂↑`；过量 KCN → `[Cu(CN)ₓ]¹⁻ˣ`（x=2~4）。
  - 机理：Cu⁺ 浓度降低 → E(Cu⁺/Cu) 降、E(Cu²⁺/Cu⁺) 升 → 反歧化变有利。
- **Cu(III)**：`5K + CuCl₂ + 3F₂ △= K₃[CuF₆] + 2KCl`；`2CuO + 2KO₂ △= 2KCuO₂ + O₂`。

#### 9. 银的化合物
- **Ag₂O**：棕黑色（AgOH 极不稳定，须低于 -45℃ 乙醇中制）；300℃ 分解为单质（vs Cu₂O 稳定）；碱性比 Cu₂O 强；溶氨水 `Ag₂O + 4NH₃ + H₂O = 2[Ag(NH₃)₂]⁺ + 2OH⁻`。
- **卤化银**：AgF 离子型可溶；AgCl/AgBr/AgI 难溶，溶解度递减、颜色加深。感光：`2AgBr =hv= 2Ag + Br₂`（显影氢醌、定影 Na₂S₂O₃）。溶解平衡：`AgX + (n-1)X⁻ = [AgXₙ]⁽ⁿ⁻¹⁾⁻`（n=2,3,4）；沉淀 Ag⁺ 时卤离子必须适量（否则配位溶解，K 例：AgCl=Ag⁺+Cl⁻ Ksp 1.8×10⁻¹⁰、Ag⁺+2Cl⁻=[AgCl₂]⁻ 稳 1.1×10⁵、AgCl+Cl⁻=[AgCl₂]⁻ 2.0×10⁻⁵）。
- **Ag₂S**：黑色，溶热浓硝酸或 CN⁻。
- **AgNO₃**：`2AgNO₃ 光照/440℃ = 2Ag + 2NO₂ + O₂`（棕色瓶保存）；制 AgBr；消毒防腐。热稳定性：Cu(NO₃)₂ < AgNO₃（Cu(II) 反极化强）。
- **Ag(I) 氧化性**：氧化 N₂H₄/NH₂OH→N₂；`4Ag⁺ + H₂PO₂⁻ + 2H₂O = 4Ag + H₃PO₄ + 3H⁺`；碱性中 `2Ag⁺ + Mn²⁺ + 4OH⁻ = 2Ag + MnO(OH)₂↓ + H₂O`。Ag⁺ 不歧化。
- **Ag 配位**：d¹⁰ 无色直线形 2 配位为主：`[Ag(CN)₂]⁻`、`[Ag(NH₃)₂]⁺`、`[Ag(S₂O₃)₂]³⁻`。
  - **稳定常数序列（关键数据）**：K 稳 [AgCl₂]⁻ 1.1×10⁵ < [Ag(NH₃)₂]⁺ 1.1×10⁷ < [Ag(S₂O₃)₂]³⁻ 2.9×10¹³ < [Ag(CN)₂]⁻ 1.3×10²¹。
  - 应用：AgCl 溶氨水、AgBr 溶 Na₂S₂O₃、AgI 溶 KCN（层层递进，用于分离）。
  - 银镜反应：`2[Ag(NH₃)₂]⁺ + RCHO + 3OH⁻ = 2Ag + RCOO⁻ + 4NH₃ + 2H₂O`（鉴定醛、镀银）。

#### 10. 金的化合物
- **AuCl₃**：200℃ 与 Cl₂ 化合，红色反磁固体；固态/气态均为**二聚体**（氯桥、8 原子共平面）；`AuCl₃ + HCl = H[AuCl₄]`（同理 AuBr₃→[AuBr₄]⁻）。
- **Au₂O₃**：棕色；Mg(OH)₂ 沉淀 [AuCl₄]⁻ 得 Au(OH)₃ → 140℃ 脱水。
- **Au(I) 歧化**：`3Au⁺ = Au³⁺ + 2Au`，`K=7.3×10⁹`（比 Cu⁺ 歧化更彻底）。
- **热分解**：AuCl₃ 160℃ → AuCl + Cl₂；更高 → Au。

### 19.2 锌副族元素（ⅡB）

**价层构型** (n-1)d¹⁰ns²。常见氧化态：Zn/Cd +2；Hg +2 和稳定 +1（Hg₂²⁺）。

#### 1. 单质物理性质
- **熔沸点低**：d 全充满不参与金属键，原子半径大 → 金属键弱。
- **汞**：唯一室温液态金属；气态单原子分子；-20~300℃ 膨胀均匀不润湿玻璃（温度计）；熔点全金属最低。
- 汞蒸气毒：空气允许量 0.1 mg/m³；洒落覆盖**硫黄粉**（HgS）；储存盖 10% NaCl 减少挥发。
- **汞齐**：汞溶金属（液/固态）；钠汞齐温和还原剂；冶金提金银。

#### 2. 单质化学性质
- 活泼性 Zn>Cd>Hg（与ⅡA 相反）；但 **ⅡB > ⅠB**。
- **Zn vs Cu 活泼性反转**（经典能量分析）：Zn 第一电离能 906.4 ≫ Cu 745.5，但 E°(Zn²⁺/Zn)=-0.76 V < E°(Cu²⁺/Cu)=0.34 V。解释：(I₁+I₂) 二者相近、水合热相近，**Zn 原子化热小** → 总焓变 Zn 更有利 → Zn 活泼。
- 加热与 O₂：`2Hg + O₂ △= 2HgO`（红色）；Zn 潮湿空气：`4Zn + 2O₂ + CO₂ + 3H₂O = ZnCO₃·3Zn(OH)₂`。
- 与 S：Hg+S 研磨即 HgS（液态接触面大）；Zn/Cd 需加热。
- 与 Cl₂：过量 Cl₂ → HgCl₂；过量 Hg → Hg₂Cl₂（甘汞）。
- 与酸：
  - Zn/Cd 溶稀酸放氢；纯 Zn+酸慢（H⁺ 在 Zn 极放电动力学慢），加 Cu²⁺ 分两步加速（Zn+Cu²⁺=Zn²⁺+Cu；Cu+2H⁺=Cu²⁺+H₂）。
  - Hg 不与稀盐酸/稀硫酸；与氧化性酸：`Hg + 2H₂SO₄(浓) △= HgSO₄ + SO₂ + 2H₂O`；汞过量冷稀硝酸：`6Hg + 8HNO₃(冷) = 3Hg₂(NO₃)₂ + 2NO + 4H₂O`。
  - `Hg + 4HI = H₂[HgI₄] + H₂↑`（[HgI₄]²⁻ 稳定常数大）。
- 两性：仅 Zn 与酸碱都反应——`Zn + 2NaOH + 2H₂O = Na₂[Zn(OH)₄] + H₂↑`；溶氨水 `Zn + 4NH₃ + 2H₂O = [Zn(NH₃)₄]²⁺ + H₂ + 2OH⁻`。

#### 3. 提取
- **锌**：闪锌矿浮选（40%~60% ZnS）→ 焙烧 `2ZnS + 3O₂ = 2ZnO + 2SO₂` → 火法 `ZnO + CO 高温= Zn(g) + CO₂` 蒸馏（98%）→ 精馏 99.9%；或**湿法**：焙砂稀 H₂SO₄ 浸取 → 调 pH 除 Fe/As/Sb → Zn 粉置换 Cd/Cu → ZnSO₄ 电解（Al 阴、Pb 阳）99.99%。
- **镉**：炼锌副产品；沸点 767℃ < Zn 907℃，加热分段蒸馏蒸出粗镉；HCl 溶解 + Zn 置换。
- **汞**：`HgS + O₂ 灼烧= Hg + SO₂`；湿法 `HgS + Na₂S(浓) = Na₂HgS₂` 电解得 Hg。

#### 4. 锌镉化合物
- **ZnO（锌白）**：白色加热变黄（冷却复原）；硫化锌型结构；**两性**氧化物。**CdO**：NaCl 型；碱性；制备方法不同颜色不同。
- 氢氧化物：
  - `Zn(OH)₂` 两性：溶强酸、溶强碱 `[Zn(OH)₄]²⁻`；`Cd(OH)₂` 偏碱，仅热浓强碱缓溶 `Na₂[Cd(OH)₄]`。
  - 分解：Zn(OH)₂ 900℃ 分解完全；Cd(OH)₂ 200℃ 分解完全。
  - 铵离子存在时 Zn(OH)₂/Cd(OH)₂ 溶氨水形成配离子，**Al(OH)₃ 不溶** → 分离 Al³⁺/Zn²⁺/Cd²⁺。
- **硫化物**：ZnS 白色、CdS 黄色（镉黄），均难溶。ZnS 溶 0.1 M HCl、不溶醋酸；CdS 不溶稀酸溶浓酸 → **控制酸度通 H₂S 分离 Zn²⁺/Cd²⁺**。`ZnSO₄ + BaS = ZnS·BaSO₄↓`（**锌钡白/立德粉**，优良白色颜料）。
- **ZnCl₂**：18e⁻ 构型强极化 → 显著共价性（熔沸点低、熔融导电差、溶乙醇）。易潮解、溶解度极大（有机脱水剂）；水解酸性 `Zn²⁺ + H₂O = Zn(OH)⁺ + H⁺`，故蒸干/加热水合物得碱式盐 `ZnCl₂·H₂O △= Zn(OH)Cl + HCl`；无水盐用 `ZnCl₂·H₂O + SOCl₂ △= ZnCl₂ + SO₂ + 2HCl`（连接 Ch16 酰氯）。浓溶液 `ZnCl₂ + H₂O = H[ZnCl₂(OH)]`（**熟镪水**）能溶金属氧化物（`FeO + 2H[ZnCl₂(OH)] = Fe[ZnCl₂(OH)]₂ + H₂O`）→ 焊接除锈。

#### 5. 汞的化合物
**（1）汞(I) 亚汞化合物**
- Hg 以 **Hg₂²⁺ 双聚体**存在：`Cl—Hg—Hg—Cl` 直线形；6s¹ 成对 → **反磁性**（单 Hg⁺ 不存在）。
- **Hg₂Cl₂（甘汞）**：白色难溶，低毒，甘汞电极。见光分解 `Hg₂Cl₂ =hv= HgCl₂ + Hg`（棕色瓶）；制备 `HgCl₂ + Hg 研磨= Hg₂Cl₂`。
- 与氨水：`Hg₂Cl₂ + 2NH₃ = Hg(NH₂)Cl(白) + Hg(黑) + NH₄Cl` → **灰色**；用于与 AgCl 分离（Hg₂²⁺ 与 Ag⁺ 分离）。
- 与 KI：`Hg₂²⁺ + 2I⁻ = Hg₂I₂↓(黄)`；过量 KI 歧化 `Hg₂I₂ + 2KI = K₂[HgI₄] + Hg`。

**（2）汞(II) 化合物**
- **HgO**：黄/红（晶粒大小），链状结构 Hg 线形配位；`Hg²⁺ + 2OH⁻ = HgO↓ + H₂O`（Hg(OH)₂ 不存在）；300℃ 分解；HgS 灼烧得 Hg 而非 HgO（vs ZnS→ZnO），说明 HgO 稳定性差。
- **HgS**：黑色（辰砂红）；386℃ 晶型转变黑→红；**溶解度最小硫化物**；溶过量 Na₂S 或浓 KI：`HgS + Na₂S(浓) = Na₂[HgS₂]`；`HgS + 2H⁺ + 4I⁻ = [HgI₄]²⁻ + H₂S↑`；溶王水：`3HgS + 8H⁺ + 2NO₃⁻ + 12Cl⁻ = 3[HgCl₄]²⁻ + 3S + 2NO + 4H₂O`。
- **HgCl₂（升汞）**：白色针状；直线形共价分子、易升华、剧毒、消毒剂。水中微解离（K₁=3.2×10⁻⁶、K₂=1.8×10⁻⁷）；水解 `HgCl₂ + H₂O = Hg(OH)Cl + HCl`；与氨水 `HgCl₂ + 2NH₃ = Hg(NH₂)Cl↓(白) + NH₄Cl`。
  - **氧化性（惰性电子对相关）**：`2HgCl₂ + Sn²⁺ + 4Cl⁻ = Hg₂Cl₂↓(白) + [SnCl₆]²⁻`；SnCl₂ 过量继续还原 `Hg₂Cl₂ + Sn²⁺ + 4Cl⁻ = 2Hg + [SnCl₆]²⁻`（沉淀变黑）——鉴定 Hg(II)/Sn(II)。
- **HgI₂**：红色；`Hg²⁺ + 2I⁻ = HgI₂↓(红)`；过量 KI → 无色 `[HgI₄]²⁻`。
  - **奈斯勒试剂** = K₂[HgI₄] 碱性溶液：`2[HgI₄]²⁻ + NH₄⁺ + 4OH⁻ = [Hg₂O·NH₂]I↓(红棕) + 7I⁻ + 3H₂O`（检验微量 NH₄⁺）。
- **Hg(II) 颜色**：18e⁻ 强极化、易变形 → 电荷迁移深色。

**（3）汞(I)/汞(II) 互变（逆歧化核心）**
- 电势图（酸）：`Hg²⁺ →0.911→ Hg₂²⁺ →0.796→ Hg`。
- **逆歧化**：`Hg + Hg²⁺ = Hg₂²⁺`，`K=88.9`（酸中 Hg₂²⁺ 稳定，Hg²⁺ 基本可转化）。
- **促歧化条件**：降低 Hg²⁺ 浓度（沉淀剂或络合剂）：
  - `Hg₂²⁺ + 2OH⁻ = HgO↓ + Hg↓ + H₂O`
  - `Hg₂²⁺ + H₂S = HgS↓ + Hg↓ + 2H⁺`
  - `Hg₂²⁺ + 4CN⁻ = [Hg(CN)₄]²⁻ + Hg`；`Hg₂²⁺ + 4I⁻ = [HgI₄]²⁻ + Hg`
  - **结论**：Hg₂²⁺ 遇 OH⁻/H₂S 得不到亚汞沉淀，产物是 Hg(II) 沉淀 + 黑 Hg。

### 本章小结（竞赛要点）
- **颜色**：d⁹ Cu²⁺ 蓝（d-d）；d¹⁰ Cu⁺/Ag⁺/Zn²⁺ 无色（电荷迁移）；Hg(II) 深色（极化电荷迁移）；AgX 颜色 Cl<Br<I 加深（电荷迁移能隙减小）。
- **歧化判据**：中间氧化态 E右>E左 → 歧化；反之为逆歧化。Cu⁺ 歧化 vs Hg₂²⁺ 逆歧化是标准案例。
- **软硬酸碱**：Ag⁺/Hg²⁺ 软酸亲软碱（S²⁻/CN⁻/I⁻/S₂O₃²⁻）→ 提金、定影、硫化沉淀、分离全链解释。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **19-4**：Cu(I)/Cu(II) 稳定性比较及 Cu(II)→Cu(I) 转化条件。
- **19-5**：电解精炼铜——Ag/Au/Pt 为何沉阳极泥，Ni/Fe/Zn 为何溶解却不沉积。
- **19-6(2)**：稀释 CuCl₂ 浓溶液颜色黄→绿→蓝。
- **19-6(4)**：Fe 使 Cu²⁺ 还原、Cu 使 Fe³⁺ 还原（电势位次）。
- **19-6(11)**：Hg₂(NO₃)₂ + KI 先黄后黑最后无色。
- **19-6(12)**：Hg(NO₃)₂ + KI 先红后无色。
- **19-7**：推理判断题 4 组（Cu 系 / Ag 硫代硫酸盐系 / Cu₂O 系 / ZnS 系）。
- **19-8(9)**：Ag 不能溶 HCl 却能溶 HI（[HgI₄]²⁻/[AgI₂]⁻ 配位 + 氧化性）。
- **19-8(10)**：氰化法提金合理性（数据计算）。
- **19-8(11)**：Cu/Zn 活泼性矛盾的能量分析。
- **19-8(12)**：Hg 电势图歧化判断 + K=88.9 计算。

### 常见错误模式
1. **Cu⁺ 稳定性误判**：气相/固体 Cu(I) 稳定，但水溶液 Cu⁺ 歧化（水合热差异）；必须区分介质。
2. **AgX 溶解性次序**：AgF 可溶（离子型），不是所有卤化银都难溶；溶解度 AgCl>AgBr>AgI。
3. **Hg 不存在 Hg⁺**：亚汞一定是 Hg₂²⁺（金属-金属键），误写 Hg⁺ 错误；遇 OH⁻/H₂S 得 Hg(II)+Hg 而非亚汞沉淀。
4. **Zn vs Cu 活泼性**：用第一电离能判断方向反了；须用原子化热+水合热总能量。
5. **汞齐不是化合物**：是"溶液"（溶质金属溶于 Hg）。
6. **王水溶金**：本质是 Cl⁻ 配位降低 Au³⁺/Au 电势，不是硝酸"更浓"。
7. **Cu₂O 与酸**：溶于稀酸歧化（Cu+Cu²⁺），不是生成 Cu(I) 盐；只有存在沉淀/配位剂才得 Cu(I)。
8. **奈斯勒试剂**：碱性 K₂[HgI₄]，不是 HgCl₂；检验 NH₄⁺。
9. **热稳定性**：HgO < CdO < ZnO；HgS 灼烧得 Hg 而非 HgO。
