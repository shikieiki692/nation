## 三、教学逻辑锚点

> 与 Zchem 第二轮深化「主族元素的结构化学I」一致：**活泼金属的还原性 → 四类氧化物 → 氢氧化物碱性判据 → 盐类系统（溶解性/热稳定性/工业制碱）→ Li-Mg 对角线收尾**。

- **主线**：活泼性贯穿全章——金属单质的强还原性（决定制备只能熔盐电解/热还原）→ 与 O₂ 生成四类氧化物（氧化态 -2/-1/-½/-⅓ 的渐进）→ 氢氧化物的碱性（离子势 φ 定量判据）→ 盐的溶解性/热稳定性（离子极化理论）→ 锂的特殊性（对角线规则收尾）。
- **铺垫顺序**：单质（物理/化学/制备）→ 含氧化合物（氧化物四类 → 氢氧化物）→ 盐类（溶解性 → 结晶水合与复盐 → 热稳定性 → 重要盐类 → Li 特殊性）。
- **结论出现时机**：「碱金属/碱土金属不能在水溶液中制备」在 12.1.3，引出熔盐电解与热还原两条制备路线；「离子势 φ 判据」在 12.2.2，是全章酸碱定性的工具；「含氧酸盐热稳定性与极化」在 12.3.3，为 Ch14 碳酸盐热稳定性（离子极化定量）埋下伏笔；「Li-Mg 对角线」在 12.3.5，呼应 Ch13 Be-Al、B-Si。
- **竞赛抓手**：焰色反应、离子势 φ 判据数据表、四类氧化物制备矩阵、Na₂O₂ 熔矿剂氧化性、隔膜法/离子膜法对比、氨碱法/联合制碱法对比、光卤石/明矾复盐、含氧酸盐热分解三段规律、Li-Mg 对角线——均为高频考点。

## 四、核心内容提炼

### 4.1 金属单质

#### (1) 物理性质（12.1.1）
- **碱金属**：银白色金属光泽（除钡为银黄色），导电性/延展性好；熔点低（除锂外均 <100℃），**铯熔点最低**（与镓同为手中可熔化的两种金属）；沸点比熔点高 700℃ 以上；质软（莫氏硬度 <1，可小刀切割）；轻金属——Li/Na/K 密度比水小，**锂是最轻金属（密度约为水的一半）**。
- **碱土金属**：有 2 个电子参与成键 → 金属键比碱金属强 → 熔点、沸点、硬度、密度均比碱金属高得多。

#### (2) 化学性质（12.1.2）
- **活泼性**：同族从 Li→Cs、Be→Ba 依次增强；均有强还原性，与许多非金属直接化合生成离子型化合物。
- **与水反应**（速率差异三因素）：
  - Na/K 剧烈（熔点低 → 反应热使金属熔为液态有利于反应，H₂ 可闪燃爆炸；氢氧化物溶解度大不阻碍）；K 甚至起火。
  - Li/Ca/Sr/Ba 温和（熔点较高不易熔化；氢氧化物溶解度小覆盖表面阻碍接触）。
  - Be/Mg 表面致密氧化膜保护，常温稳定；Mg 与热水缓慢反应，Be 与水蒸气也不反应。
- **与 H₂**：碱金属及 Ca/Sr/Ba 直接化合生成离子型氢化物：`H₂ + Ca =150~300℃= CaH₂`（灰色离子晶体，强还原剂）。
- **溶于液氨**（溶剂化电子体系）：
  - `Na + 2NH₃(l) = Na⁺(NH₃) + e⁻(NH₃)`——蓝色导电溶液，**顺磁性**，溶剂化电子极强还原剂，可在低温使用。
  - 久置/催化：`2Na + 2NH₃(l) = 2NaNH₂ + H₂↑`（蒸干得白色氨基钠）。
- **非水/熔融还原**（不能在水溶液中作还原剂 → 用于制备稀有金属/贵金属）：
  - `NbCl₅ + 5Na =共熔= Nb + 5NaCl`
  - `ZrO₂ + 2Ca =共熔= Zr + 2CaO`
  - `TiCl₄ + 2Mg =共熔= Ti + 2MgCl₂`
- **焰色反应**：高温使物质原子化，电子激发→跃迁回低能级→发射特征波长。颜色：**Li 深红 / Na 黄 / K 紫 / Rb 紫红 / Cs 蓝 / Ca 橙红 / Sr 洋红 / Ba 绿**。K/Sr/Ba 硝酸盐与 KClO₄、硫黄、镁粉、松香混合制信号弹和烟花。

#### (3) 金属单质的制备（12.1.3）
- 活泼金属不可能以单质存在于自然界，**不能从水溶液中制备**；方法为**熔盐电解法 + 热还原法**。
- **熔盐电解法**（Li/Na 及 Be/Mg/Ca/Sr/Ba）：
  - **钠**：NaCl+CaCl₂ 混合熔盐电解，石墨阳极+铸钢阴极+隔膜。`2NaCl(l) =电解= 2Na(l) + Cl₂(g)`。**CaCl₂ 助熔剂**使熔点由 800.7℃ 降至 ~500℃（实际操作约 580℃），降能耗、减 Na 挥发、降低 Na 在熔盐中溶解度利于分离。产物 105~110℃ 过滤除 Ca。
  - Be 电解熔融 BeCl₂（BeCl₂ 共价性强，加 CaCl₂/碱金属氯化物增导电）；Mg 750℃ 电解熔融 MgCl₂；Ca/Sr/Ba 电解熔融氯化物。
- **热还原法**（K/Rb/Cs/Be）：
  - **钾**：`Na(l) + KCl(l) =850℃= NaCl(l) + K(g)`——**K 沸点 759℃ < Na 沸点 883℃**，850℃ 时 K 呈气态逸出推动反应向右；冷凝+分馏得 99.99% K。
  - Rb/Cs：Ca 在 750℃ 还原其氯化物；Be：Mg 在约 1300℃ 还原 BeF₂。

### 4.2 含氧化合物

#### (1) 氧化物（12.2.1）——四类体系
- **分类**：普通氧化物 M₂O/MO、过氧化物 M₂O₂（含 [O—O]²⁻）、超氧化物 MO₂（含 O₂⁻）、臭氧化物 MO₃（含 O₃⁻）。除 Be 外均能形成过氧化物；Na/K/Rb/Cs/Ca 能生成超氧化物。
- **充足空气中燃烧的主产物**：
  - Li/Be/Mg/Ca/Sr → 普通氧化物（Li₂O/BeO/MgO/CaO/SrO）
  - Na/Ba → 过氧化物（Na₂O₂/BaO₂）
  - K/Rb/Cs → 超氧化物（KO₂/RbO₂/CsO₂）
  - 臭氧化物：干燥氢氧化物粉末 + O₃ → MO₃。
- **普通氧化物**：
  - 颜色递变：Li₂O 白 / Na₂O 白 / K₂O 灰 / Rb₂O 黄棕 / Cs₂O 黄橙（碱金属从上到下加深）；碱土金属全白。
  - 制备（Li 以外碱金属难由直接燃烧制）：`2Na + Na₂O₂ =真空= 2Na₂O`；`10K + 2KNO₃ =真空= 6K₂O + N₂↑`；`3NaN₃ + NaNO₂ =真空= 2Na₂O + 5N₂↑`；碱土金属由碳酸盐/氢氧化物/硝酸盐/硫酸盐热分解。
  - 热稳定性同族从上到下降低；碱土金属离子半径小正电荷高 → 晶格能大 → 熔点远高于碱金属。
  - 与水反应放热：`Na₂O + H₂O = 2NaOH`（ΔrH°=-151.6 kJ/mol）；`CaO + H₂O = Ca(OH)₂`（ΔrH°=-64.5 kJ/mol）；**煅烧过的 BeO/MgO 极难与水反应**，熔点高 → 耐火材料；轻质 MgO 作橡胶/塑料/纸张补强填料。
- **过氧化物**（最重要 Na₂O₂/CaO₂/BaO₂）：
  - 工业制 Na₂O₂ 两步法：`4Na + O₂ =180~200℃= 2Na₂O` → `2Na₂O + O₂ =300~400℃= 2Na₂O₂`（黄色粉末）。
  - 与水/稀酸生成 H₂O₂：`Na₂O₂ + 2H₂O = H₂O₂ + 2NaOH`；`Na₂O₂ + H₂SO₄ = H₂O₂ + Na₂SO₄`；`BaO₂ + H₂SO₄ = H₂O₂ + BaSO₄↓`（**实验室制 H₂O₂**）。
  - 与 CO₂ 放 O₂：`2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂`——防毒面具/潜水艇用 Na₂O₂，宇航舱用较轻的 Li₂O₂。
  - **氧化性/熔矿剂**：`Fe₂O₃ + 3Na₂O₂ =共熔= 2Na₂FeO₄ + Na₂O`；`Cr₂O₃ + 3Na₂O₂ =共熔= 2Na₂CrO₄ + Na₂O`。
  - **还原性**（遇强氧化剂）：`5Na₂O₂ + 2MnO₄⁻ + 16H⁺ = 5O₂↑ + 2Mn²⁺ + 10Na⁺ + 8H₂O`。
  - 热稳定性：Li₂O₂ 195℃ 以上分解，Na₂O₂ ≥675℃（无氧时）；碱土金属过氧化物 MgO₂→BaO₂ 稳定性递增，但不如碱金属。
- **超氧化物**：
  - O₂⁻ 结构：σ 键 + 一个三电子 π 键，键级 1.5，含单电子 → **顺磁性**。半径大的阳离子超氧化物稳定（KO₂/RbO₂/CsO₂/Sr(O₂)₂/Ba(O₂)₂），NaO₂ 稳定性差（450℃/15 MPa 才能制纯）。
  - 熔点递变：KO₂ 380℃ / RbO₂ 412℃ / CsO₂ 432℃。
  - 与水/CO₂ 均放 O₂：`2KO₂ + 2H₂O = O₂↑ + H₂O₂ + 2KOH`；`4KO₂ + 2CO₂ = 2K₂CO₃ + 3O₂`（**氧气源**）；高温分解 `4KO₂ =高温= 2K₂O + 3O₂↑`。
- **臭氧化物**：`6KOH + 4O₃ = 4KO₃ + 2KOH·H₂O + O₂`，液氨重结晶得橘红色 KO₃；缓慢分解 `2KO₃ = 2KO₂ + O₂`；遇水 `4KO₃ + 2H₂O = 4KOH + 5O₂↑`。

#### (2) 氢氧化物（12.2.2）
- **溶解性**：碱金属氢氧化物均易溶（NaOH 15℃ 达 26.4 mol/L；LiOH 5.3 稍小）；碱土金属溶解度小且**从上到下增大**——Be(OH)₂ 8×10⁻⁶ / Mg(OH)₂ 5×10⁻⁴ / Ca(OH)₂ 1.8×10⁻² / Sr(OH)₂ 6.7×10⁻² / Ba(OH)₂ 2×10⁻¹（20℃）。
- **碱性 + 离子势 φ 判据**（核心考点）：
  - φ = z/r（电荷/离子半径）。φ 大 → M—O—H 酸式解离（MO⁻ + H⁺）显酸性；φ 小 → 碱式解离（M⁺ + OH⁻）显碱性；两者相当则两性。
  - 经验公式（r 单位 pm）：**√φ < 0.22 碱性；0.22 < √φ < 0.32 两性；√φ > 0.32 酸性**。
  - 数据：LiOH 0.13 / NaOH 0.10 / KOH 0.085 / RbOH 0.081 / CsOH 0.077（全碱性）；Be(OH)₂ 0.27（两性）/ Mg(OH)₂ 0.17 / Ca(OH)₂ 0.14 / Sr(OH)₂ 0.13 / Ba(OH)₂ 0.12（碱性）。
  - φ 越大 → 离子水合放热越多、离子在溶液中移动越慢（**Li⁺ < Na⁺ < K⁺ 移动速率**）。
  - 注意：经验方法，粗略；还与电子层结构等因素有关。
- **Be(OH)₂ 两性**：溶强碱生成 [Be(OH)₄]²⁻。
- **氢氧化钠**（烧碱/火碱/苛性碱）：
  - 强腐蚀，侵蚀玻璃（与 SiO₂ → Na₂SiO₃），**不用磨口玻璃瓶**；工业熔融试样用铁制容器，实验室用银/镍坩埚。
  - 吸收 CO₂ → Na₂CO₃ 使不纯；**配制不含 Na₂CO₃ 的 NaOH 溶液**：先配饱和 NaOH（Na₂CO₃ 在饱和 NaOH 中溶解度极小析出）→ 取上清液 + 用煮沸除 CO₂ 后冷却的水稀释。
  - 工业制 NaOH = 电解 NaCl 水溶液：**隔膜法**（石墨阳极/铁网阴极/石棉隔膜；阳极 Cl₂，阴极 H₂+OH⁻，产物 NaCl+NaOH 混合液蒸发浓缩析 NaCl）；**离子膜法**（阳离子交换膜只许 Na⁺ 通过、OH⁻ 难通过；阳极室 NaCl 溶液，阴极室水；阳极 Cl₂，Na⁺ 过膜入阴极室，阴极 H₂+NaOH）——投资少能耗低，较先进。

### 4.3 盐类

#### (1) 盐的溶解性（12.3.1）
- **碱金属盐**：除锂外均为离子型、大部分易溶；**锂的弱酸盐难溶**（LiF/Li₂CO₃/Li₃PO₄），强酸盐易溶。
- **碱金属难溶/微溶盐**（鉴定用）：
  - Na⁺：醋酸铀酰锌钠 NaZn(UO₂)₃(Ac)₉·9H₂O（淡黄结晶，鉴定 Na⁺）；Na[Sb(OH)₆]、NaUO₂AsO₄ 等。
  - K⁺：**六硝基合钴(Ⅲ)酸钠钾** K₂Na[Co(NO₂)₆]（黄色沉淀，鉴定 K⁺）；KClO₄/KIO₄/K₂[PtCl₆]/K₂[PtF₆]/K₂[SiF₆]/酒石酸氢钾 KHC₄H₄O₆。
  - Rb/Cs 类似（高氯酸盐/高碘酸盐/氯铂酸盐等难溶）。
- **碱土金属盐**：
  - 与 -1 价阴离子（除 F⁻）的盐一般易溶（氯化物/溴化物/碘化物/硝酸盐/氯酸盐/醋酸盐/酸式碳酸盐/酸式草酸盐/磷酸二氢盐）——电荷数低、晶格能小。
  - 与多电荷阴离子的盐难溶（碳酸盐/磷酸盐/草酸盐）。**硫酸盐/铬酸盐**：BeSO₄/MgSO₄ 易溶，CaSO₄/SrSO₄/BaSO₄ 难溶；BeCrO₄/MgCrO₄ 易溶，Ca/Sr/Ba 难溶。
  - 解释：复杂阴离子半径大，与半径大的阳离子结合才可避免阴离子直接接触、减小斥力、保证晶格能较大 → **半径大的阳离子与复杂阴离子形成的盐溶解度小**。
- 溶解过程 = 晶格破坏 + 离子水合；离子电荷越高、半径越小 → 水合放热越多越有利溶解。

#### (2) 盐的结晶水合与复盐（12.3.2）
- 阳离子电荷越高、半径越小 → 对水分子引力越大 → 结晶水合盐倾向越大。
- **碱金属**：卤化物一般不带结晶水；硝酸盐只有 LiNO₃ 带（LiNO₃·H₂O/LiNO₃·3H₂O）；硫酸盐只有 Li₂SO₄·H₂O、Na₂SO₄·10H₂O；碳酸盐除 Li₂CO₃ 外均带结晶水（Na₂CO₃·1/7/10H₂O、K₂CO₃·1/5H₂O 等）。
- **实验室用钾盐不用钠盐**：钾盐不易潮解（KI/KMnO₄/KClO₃/K₂Cr₂O₇）；**黑火药/炸药用 KNO₃/KClO₄ 而不用 NaNO₃/NaClO₄**（吸湿性差异）；钾盐价格较高。
- **碱土金属**：带结晶水趋势更大——MgCl₂·6H₂O、CaCl₂·6H₂O、MgSO₄·7H₂O、CaSO₄·2H₂O、BaCl₂·2H₂O；无水 CaCl₂ 是重要干燥剂；Na₂SO₄·10H₂O 熔化热大 → **储热材料**。
- **复盐**（除 Li 外均能形成，溶解度一般比简单盐小）：
  - 光卤石 KCl·MgCl₂·6H₂O（通式 MCl·MgCl₂·6H₂O，M=K/Rb/Cs）
  - 软钾镁矾 K₂SO₄·MgCl₂·6H₂O（通式 M₂SO₄·MgCl₂·6H₂O）
  - 明矾 K₂SO₄·Al₂(SO₄)₃·24H₂O、铬钾矾 K₂SO₄·Cr₂(SO₄)₃·24H₂O（通式 M(I)₂SO₄·M(III)₂(SO₄)₃·24H₂O）。

#### (3) 含氧酸盐的热稳定性（12.3.3）
- **硝酸盐热分解**（极化能力分界）：
  - Li⁺ 及碱土金属离子极化能力强 → 分解为**金属氧化物 + NO₂ + O₂**：`4LiNO₃ =△= 2Li₂O + 4NO₂↑ + O₂↑`；`2Mg(NO₃)₂ =△= 2MgO + 4NO₂↑ + O₂↑`。
  - 其他碱金属（Na/K 等）→ **亚硝酸盐 + O₂**：`2NaNO₃ =500℃= 2NaNO₂ + O₂↑`；更高温（800℃）→ 氧化物+N₂+O₂：`4NaNO₃ =800℃= 2Na₂O + 2N₂↑ + 5O₂↑`。
- **碳酸盐热稳定性**（离子极化定量）：阳离子电荷越高、半径越小、极化能力越强 → 含氧酸盐越不稳定、分解温度越低。碱金属含氧酸盐热稳定性 > 碱土金属：**MgCO₃ 540℃ / CaCO₃ 900℃ / BaCO₃ 1360℃**；Li₂CO₃ 700℃ 分解，Na₂CO₃/K₂CO₃ 1000℃ 基本不分解。分解产物金属氧化物+CO₂：`Li₂CO₃ =△= Li₂O + CO₂↑`；`MgCO₃ =△= MgO + CO₂↑`。
- **卤化物 ΔfH 规律**（表12-4）：MF 从 LiF→RbF ΔfH 逐渐增大（放热减小）；MCl/MBr/MI 从 Li→Rb ΔfH 逐渐减小（放热增大）；同一金属 F→I 放热依次减小。

#### (4) 重要盐类简介（12.3.4）
- **卤化物**（最重要 NaCl/MgCl₂/CaCl₂）：
  - NaCl 食盐：重要化工原料（→Na/NaOH/Cl₂/Na₂CO₃/HCl）；食品/石油/纺织/融雪剂。
  - MgCl₂ 卤水：使蛋白质凝固（豆制品）；融雪剂。**水合盐脱水水解得不到无水盐**：`MgCl₂·6H₂O =△= Mg(OH)Cl + HCl↑ + 5H₂O` → `Mg(OH)Cl =△= MgO + HCl↑`。无水 MgCl₂ 由 Mg+Cl₂ 直接化合，或 HCl 气氛中加热水合盐。
  - CaCl₂ 干燥剂：CaCl₂·6H₂O 脱水制（含少量 CaO 杂质）；与冰混合可作 -50℃ 低温冷冻剂。MgCl₂/BaCl₂ 有毒。
  - **BeX₂ 共价性强**、熔沸点低易升华；水合卤化物脱水时水解。**无水 BeCl₂ 固态链状（Be sp³）**；气态存在二聚体 (BeCl₂)₂（Be sp²）；>747℃ 单分子存在。
- **碳酸盐**（最重要 Na₂CO₃）：
  - Na₂CO₃ 苏打/纯碱，市售 Na₂CO₃·10H₂O 易风化。
  - **氨碱法（索尔维，1862）**：饱和食盐水吸 NH₃ → 通 CO₂：`NH₃+CO₂+H₂O = NH₄HCO₃`；`NH₄HCO₃+NaCl = NaHCO₃↓ + NH₄Cl`（NaHCO₃ 溶解度小析出）；`2NaHCO₃ =△= Na₂CO₃ + CO₂↑ + H₂O`。CO₂ 由煅烧石灰石制；CaO 消化成石灰乳回收氨：`2NH₄Cl + Ca(OH)₂ = 2NH₃↑ + CaCl₂ + 2H₂O`（氨循环）；副产物 CaCl₂。
  - **联合制碱法（侯德榜，1942）**：与合成氨工业结合，CO₂ 来自合成氨原料气 CO 转化；低温 NH₄Cl 溶解度小，向母液加 NaCl 粉末借同离子效应使 **NH₄Cl 析出（氮肥）**。保留氨碱法优点，提高 NaCl 利用率，省去煅烧石灰石步骤。
  - NaHCO₃ 小苏打，加热脱水 → Na₂CO₃；CaCO₃ 石灰石高温分解 → CaO+CO₂。
- **硫酸盐**：Na₂SO₄ 元明粉；Na₂SO₄·10H₂O 芒硝（储热材料）。CaSO₄·2H₂O 生石膏，120℃ 脱水 → CaSO₄·0.5H₂O 熟石膏（与水混合变硬膨胀 → 模型/塑像/装修）。BaSO₄ 重晶石：溶解度小、毒性低、吸收 X 射线 → **钡餐**；`BaSO₄ + 4C =高温= BaS + 4CO↑` → `BaS + 2HCl = BaCl₂ + H₂S↑`（制其他钡盐）。
- **硝酸盐和卤素含氧酸盐**：KNO₃ 化肥（补 N/K）、有氧化性易爆 → 制炸药；KClO₃ 强氧化剂 → 炸药；Ca(ClO)₂ 漂白剂。

#### (5) 锂的特殊性（12.3.5，Li-Mg 对角线）
- **O₂ 中燃烧**：Li 主产物 Li₂O（其他碱金属 → 过/超氧化物）；Mg 主产物 MgO。
- **溶解性**：LiOH/Mg(OH)₂ 溶解度小；Li/Mg 的氟化物、碳酸盐、磷酸盐均难溶（NaF 溶解度约 LiF 的 10 倍，Na₃PO₄ 约 Li₃PO₄ 的 200 倍）。
- **硝酸盐热分解**：LiNO₃/Mg(NO₃)₂ → 氧化物+NO₂+O₂（其他碱金属 → 亚硝酸盐+O₂）。
- **与 N₂ 反应**：Li/Mg 都能直接与 N₂ 化合：`6Li + N₂ =△= 2Li₃N`；`3Mg + N₂ =△= Mg₃N₂`（其他碱金属不能）。
- **原因**：Li 与 Mg 处于周期表斜对角线，**离子电荷与半径比值相近（离子势相近）** → 性质相似；同理 Be-Al、B-Si。

## 七、教材例题与常见错误

### 精选例题
1. **氨碱法与联合制碱法对比**（习题12-4(3)、12-5(1)）：索尔维法副产 CaCl₂ 难利用；侯德榜法与合成氨结合、低温同离子效应析 NH₄Cl 作肥料、提高 NaCl 利用率。→ 工业流程核心题。
2. **配制不含 Na₂CO₃ 的 NaOH 溶液**（习题12-4(4)）：饱和 NaOH 中 Na₂CO₃ 溶解度极小析出 → 取上清液用煮沸除 CO₂ 的水稀释。
3. **Be(OH)₂ 与 Mg(OH)₂ 鉴别**（习题12-5(1)①）：加过量 NaOH——Be(OH)₂ 溶（两性）成 [Be(OH)₄]²⁻，Mg(OH)₂ 不溶。
4. **NaNO₃ 混 MgSO₄ 加热出棕 NO₂**（习题12-6(4)）：Mg²⁺ 极化能力强 → 使硝酸盐分解为氧化物+NO₂+O₂，而纯 NaNO₃ 只生成 NaNO₂+O₂ 无棕色气体。
5. **碱土金属推断**（习题12-7(1)）：橙红火焰 → Ca；燃烧产物 CaO+Ca₃N₂ 与水反应放 NH₃（石蕊变蓝）；CO₂ 通入 → CaCO₃ 白沉。
6. **LiI 与 CsF 研磨预测**（习题12-8(5)）：卤化物 ΔfH 规律（LiF 放热最大、CsI 放热最小）→ `LiI + CsF = LiF + CsI`（生成热差驱动）。
7. **BeCl₂ 三态成键**（习题12-8(9)(12)）：固态链状（Be sp³）；气态 <747℃ 二聚 (BeCl₂)₂（Be sp²，氯桥）；>747℃ 单分子；熔盐中 + NaCl 形成 [BeCl₄]²⁻ 等导电离子。
8. **黑火药用 KNO₃ 不用 NaNO₃**（习题12-8(2)）：KNO₃ 吸湿性小，NaNO₃ 易潮解。

### 常见错误
| 错误认知 | 正确结论 |
|:--|:--|
| Na₂O₂ 可由 Na 燃烧一步制得 | 两步：180~200℃ 先生成 Na₂O，300~400℃ 再氧化为 Na₂O₂ |
| 碱金属在空气中燃烧都生成普通氧化物 | 只有 Li 主产物是 Li₂O；Na→Na₂O₂，K/Rb/Cs→超氧化物 |
| 碱金属都能与 N₂ 直接化合 | 只有 Li（及 Mg）；Na/K/Rb/Cs 不能 |
| MgCl₂·6H₂O 加热可得无水 MgCl₂ | 水解生成 Mg(OH)Cl+HCl↑，得不到无水盐 |
| 所有碱金属盐都易溶于水 | LiF/Li₂CO₃/Li₃PO₄ 难溶；K/Rb/Cs 有特定难溶盐（KClO₄/K₂[PtCl₆] 等） |
| 氨碱法与联合制碱法原理不同 | 原理相同，联合制碱法仅结合合成氨、回收 NH₄Cl、提高 NaCl 利用率 |
| 碱土金属氢氧化物都难溶 | 溶解度从上到下增大，Ba(OH)₂ 达 0.2 mol/L（20℃） |
| φ 判据只看电荷数 | φ=z/r，同时考虑电荷与半径；且为粗略经验方法 |
| 碱金属水溶液可作还原剂 | 因与水激烈反应，只能作非水/熔融体系还原剂 |
