# 提炼-上海中学竞赛课程-第四分册-醇、醚与环氧化物

> 来源：上海中学竞赛课程·化学·第4分册·第八讲 醇、醚与环氧化物
> 提炼日期：2026-07-08

---

## 一、内容概要

本讲介绍了醇的结构与化学性质（羟基氢酸性、醇转化为卤代烃的各种方法及立体化学、脱水成烯、氧化反应、频哪醇重排、高碘酸/四乙酸铅氧化邻二醇），醚的合成与性质（Williamson合成、环氧化物开环），以及醇和醚的物理性质。重点为醇转化为卤代烃的多种方法及其立体化学差异，以及频哪醇重排机理。

## 二、核心知识点

### 2.1 醇的结构与物理性质
- 官能团-OH：氧的吸电子作用→羟基氢有酸性，α-H有活泼性
- 烷基给电子→氧有弱碱性和亲核性
- 分子间氢键→醇沸点高于醚
- C₁~C₃醇与水互溶，C₄醇溶解度约8%，高级醇不溶

### 2.2 醇的化学性质

#### 羟基氢的酸性
- 醇酸性比水弱，但可与Na、K、Mg、Al等活泼金属反应放H₂
- 2ROH + 2Na → 2RONa + H₂↑
- 醇可与CaCl₂形成配合物CaCl₂·4C₂H₅OH（故不能用无水CaCl₂干燥醇）

#### 醇→卤代烃
**(1) 与HX反应**
- 羟基质子化→H₂O（好离去基团）→S_N1或S_N2
- **烯丙基型/苄基型/叔醇/仲醇** → S_N1机理（可能重排/外消旋化）
- **伯醇** → S_N2机理
- HX活性：HI > HBr > HCl
- 醇活性：烯丙基型/苄基型/叔 > 仲 > 伯 < 甲醇
- **Lucas试剂**（ZnCl₂/浓HCl）：鉴别C₆以下醇（叔醇立即浑浊，仲醇稍加热，伯醇需长时间加热）

**(2) 与PX₃反应**
- 伯/仲醇 → S_N2 → 构型翻转
- 叔醇 → S_N1 → 外消旋化
- Cl⁻亲核性弱→反应主要生成亚磷酸酯，不适合制备氯代烃

**(3) 与SOCl₂反应**
- 无吡啶：构型保持（Cl⁻从正面进攻碳正离子中间体）
- 有吡啶：构型翻转（"自由"Cl⁻从背面S_N2进攻）

#### 醇与浓H₂SO₄脱水成烯
- 按E1机理进行（质子化→碳正离子→失β-H）
- 遵循扎伊采夫规则

#### 醇的氧化
- **CrO₃/H₂SO₄（Jones试剂）**：伯醇→羧酸，仲醇→酮
- **PCC（氯铬酸吡啶盐）**：伯醇→醛（不继续氧化），仲醇→酮
- **新制MnO₂**：选择性氧化β-碳上连C=C的醇（不影响C=C）
- **沃氏氧化**（异丙醇铝/丙酮）：仲醇→酮（选择性好，条件温和）
  - 逆向即Meerwein-Ponndorf还原：酮→仲醇（异丙醇铝/异丙醇）

#### 多元醇的反应

**(1) 频哪醇重排**
- 邻二醇 + H⁺ → 重排为酮
- 机理：质子化一个-OH → 离去H₂O → 碳正离子 → 基团迁移（反式共平面）→ 失H⁺→酮
- 迁移能力：能提供电子稳定正电荷较多的基团优先迁移
- β-卤代醇在Ag⁺作用下也可发生类似重排

**(2) 高碘酸/四乙酸铅氧化**
- H₅IO₆或Pb(OAc)₄将邻二醇C-C键断裂→醛/酮/甲酸
- 判断方法：羟基碳间键断裂，各加-OH再失水→产物

### 2.3 醚的合成与性质

#### Williamson合成
- 醇钠 + 卤代烃 → 醚（S_N2反应）
- 需伯卤代烃（叔卤代烃→消除为主）
- 不对称醚的合成：选较小烷基为醇钠，较大烷基为卤代烃

#### 环氧化物
- 环氧化物（三元环醚）张力大，易开环
- 碱性条件：亲核试剂进攻位阻小的碳（S_N2）
- 酸性条件：亲核试剂进攻碳正离子性更强的碳

## 三、竞赛要点

1. **醇→卤代烃的立体化学控制**：SOCl₂（有/无吡啶）和PX₃可分别实现构型保持、翻转和外消旋化，是竞赛高频考点
2. **频哪醇重排的基团迁移选择**：需掌握反式共平面要求和基团迁移能力排序
3. **醇氧化的条件选择**：Jones→羧酸，PCC→醛，MnO₂→选择性氧化烯丙醇，沃氏→仲醇选择性氧化
4. **Lucas试剂的适用范围**：仅适用于C₆以下醇，需理解原理和局限性
5. **环氧化物开环的方向选择**：碱性→位阻控制；酸性→电子效应控制
6. **邻二醇的高碘酸氧化**：可用于推断邻二醇的结构

## 四、例题与习题

### 典型例题

**例1**：(R)-2-丁醇分别与(a)SOCl₂、(b)SOCl₂/吡啶、(c)PBr₃反应，产物构型分别是什么？
> 解：(a)SOCl₂无吡啶→构型保持(R)-2-溴丁烷；(b)SOCl₂/吡啶→构型翻转(S)-2-溴丁烷；(c)PBr₃→S_N2构型翻转(S)-2-溴丁烷。

**例2**：写出频哪醇(CH₃)₂C(OH)-C(OH)(CH₃)₂在H₂SO₄作用下的重排产物和机理。
> 解：质子化一个-OH → 失H₂O → 生成叔碳正离子 → 甲基1,2-迁移 → 新碳正离子 → 失H⁺ → 频哪酮(CH₃)₃C-CO-CH₃。

**例3**：如何用Williamson合成法制备乙基叔丁基醚？
> 解：不能用(CH₃)₃CONa + CH₃CH₂Br（可以）或CH₃CH₂ONa + (CH₃)₃CBr（不行，叔卤→消除）。正确方法：(CH₃)₃CONa + CH₃CH₂Br → (CH₃)₃C-O-CH₂CH₃ + NaBr。

### 竞赛训练要点
- 练习判断醇→卤代烃反应的立体化学结果
- 练习频哪醇重排的产物预测
- 利用不同氧化条件实现醇的选择性氧化
- 设计Williamson合成法制备不对称醚
- 利用高碘酸氧化推断邻二醇结构
