# 提炼-上海中学竞赛课程-第二分册-离子反应

> 来源：上海中学竞赛课程·化学·第2分册·第九讲 离子反应（原书约 800 行，行1519-2323）
> 提炼日期：2026-09-16

---

## 内容概要

本讲是对酸碱、沉淀、配位、氧化还原四类平衡的「离子视角」整合。先按反应类型分述：酸碱反应（质子理论下的酸碱与两性物质，用 $K_a$/$K_b$ 判断方向）、水解反应（狭义盐类水解与广义水解七类，含双水解「完全/不完全」的定量判据与离子势 $\phi = Z/r$ 判断氢氧化物酸碱性）、沉淀反应（离子型盐溶解度规律与晶格能/水合热的权衡、分步沉淀）、配位反应（$K_{稳}$ 驱动的多重平衡竞争）、氧化还原反应（能斯特方程、元素电势图、溶液酸碱性的影响）；再给出离子反应的实质（复分解向离子浓度减小方向进行，配位与氧化还原**不遵循**此规律）；最后系统讨论离子共存与离子方程式书写，含相对量、反应条件与隐含因素三类高频陷阱。

---

## 核心知识点

### 1. 离子反应的类型与特点

- 定义：反应中有离子参加或有离子生成；默认水溶液，也可为液氨、液态 $SO_2$ 等
- 特点：反应速率快、相应离子间的反应不易受其他离子干扰

### 2. 酸碱反应（质子理论）

- 酸：给出质子；碱：接受质子；两性物质：既可给出又可接受（$HCO_3^-$、$HS^-$、$HC_2O_4^-$）
- 方向由 $K_a$/$K_b$ 计算平衡常数判断：

| 反应 | $K$ 计算式 | 数值 | 结论 |
|:---|:---|:---|:---|
| $CH_3COO^- + H^+$ | $1/K_a(CH_3COOH)$ | $5.9\times10^{4}$ | 正向完全（强酸制弱酸） |
| $CH_3COO^- + HCO_3^-$ | $K_{a2}(H_2CO_3)/K_a(CH_3COOH)$ | $3.3\times10^{-6}$ | 正向几乎不反应 |
| $NH_4^+ + CO_3^{2-} + H_2O$ | $K_w/[K_b(NH_3\cdot H_2O)\cdot K_{a2}(H_2CO_3)]$ | 10.5 | 正向，一定程度双水解 |
| $HSO_3^- + HCO_3^-$ | $K_{a2}(H_2SO_3)/K_{a1}(H_2CO_3)$ | 0.23 | 正向但不完全（0.1 mol/L 时 $x = 0.032$） |

- 金属氢氧化物两种离解方式：碱式 $MOH = M^+ + OH^-$、酸式 $MOH = MO^- + H^+$
- **离子势** $\phi = Z/r$（Z 为电荷密度）：$\sqrt{\phi} < 2.2$ 显碱性、$2.2 \sim 3.2$ 显两性、$> 3.2$ 显酸性
  - 同族离子构型相同，$\sqrt{\phi}$ 主要取决于离子半径：LiOH 1.2 → CsOH 0.77（碱性增强）；$Be(OH)_2$ 2.54 → $Ba(OH)_2$ 1.22

### 3. 水解反应

**(1) 狭义水解（盐类水解 = 酸碱反应）**

| 反应 | $K$ | 结论 |
|:---|:---|:---|
| $CH_3COO^- + H_2O$ | $K_w/K_a = 5.9\times10^{-10}$ | 极不完全（「水解微弱」的由来） |
| $Fe^{3+} + 3H_2O$ | $K_w^3/K_{sp}(Fe(OH)_3) = 3.6\times10^{-4}$ | 不完全但已明显得多 |
| $NH_4^+ + CH_3COO^-$ | $K_w/[K_b\cdot K_a] = 3.5\times10^{-5}$ | 互促水解但仍大量共存 |
| $Al^{3+} + 3ClO^-$ | $K_w^3/[K_{sp}(Al(OH)_3)K_a^3(HClO)] = 1.2\times10^{14}$ | **彻底的双水解** |

- 水解能力强的离子：正离子 $Al^{3+}$、$Fe^{2+}$、$Fe^{3+}$ 及过渡金属高价正离子；负离子 $CO_3^{2-}$、$HCO_3^-$、$AlO_2^-$、$S^{2-}$
- **不完全双水解**：仍写 $\rightleftharpoons$，不标气体沉淀，离子可大量共存（如 $NH_4^+$ 与 $CH_3COO^-$、$HCO_3^-$）
- **完全双水解**：必须写「$=$」，标气体和沉淀，离子不能大量共存
  - 正离子 $Al^{3+}$、$Fe^{3+}$；负离子 $CO_3^{2-}$、$HCO_3^-$、$S^{2-}$、$HS^-$、$AlO_2^-$
- 提示：能否双水解应**用 K 计算**判断；部分正负离子（如 $Fe^{3+}$ 与 $S^{2-}$、$Fe^{3+}$ 与 $SO_3^{2-}$）还会同时发生氧化还原

**(2) 广义水解七类**

1. 生成碱式盐：$SnCl_2 + H_2O = Sn(OH)Cl + HCl$、$BiCl_3 + H_2O = BiOCl + 2HCl$
2. 生成含氧酸：$BCl_3 + 3H_2O = H_3BO_3 + 3HCl$、$PCl_3 + 4H_2O = H_3PO_4 + 5HCl$
3. 金属碳化物水解：$CaC_2 + 2H_2O = Ca(OH)_2 + C_2H_2\uparrow$、$Al_4C_3 + 12H_2O = 4Al(OH)_3 + 3CH_4\uparrow$
4. 聚合与配位水解：$3SiF_4 + 4H_2O = H_4SiO_4 + 2H_2SiF_6$；$Fe^{3+} \to [Fe(OH)]^{2+} \to [Fe_2(OH)_2]^{4+}$
5. 氧化还原水解：$2XeF_2 + 2H_2O = 2Xe\uparrow + O_2\uparrow + 4HF$
6. 歧化水解：$3BrF_3 + 6H_2O = 2HBrO_3 + HBr + 9HF$、$6XeF_4 + 12H_2O = 2XeO_3 + 4Xe\uparrow + 3O_2\uparrow + 24HF$
7. 有机物水解：卤代烃、酯、羧酸衍生物（本讲不展开）

### 4. 沉淀反应

- 离子型盐溶解度规律：
  1. 正离子半径越大、电荷越小 → 易溶
  2. 负离子半径较大（$SO_4^{2-}$、$I^-$、$CrO_4^{2-}$）→ 溶解度随金属原子序数增大而**减小**
  3. 负离子半径较小（$F^-$、$OH^-$）→ 溶解度随金属原子序数增大而**增大**
- 热力学解释：$\Delta H = U + \Delta H_w$（晶格能 + 水合热）
  - 正负离子半径相近 → **晶格能 U 主导**（LiF 为碱金属氟化物中溶解度最小）
  - 负离子半径远大于正离子 → **水合热 $\Delta H_w$ 主导**（$LiClO_4 \gg NaClO_4 \gg K/Rb/CsClO_4$）
- 大正离子需大负离子作沉淀剂（$Na[Sb(OH)_6]$、$K_3[Co(NO_2)_6]$、$K_2[PtCl_6]$ 均难溶）
- 多种离子共存时由 $K_{sp}$ 判断沉淀先后与分步沉淀

### 5. 配位反应

- 由 $K_{稳}$ 判断方向，可与沉淀平衡组成多重平衡竞争
- 经典 $Ag^+$ 争夺链（A~G 推断题）：

$$AgCl \to [Ag(NH_3)_2]^+ \to AgBr \to [Ag(S_2O_3)_2]^{3-} \to AgI \to [Ag(CN)_2]^- \to Ag_2S$$

- 争夺 $Ag^+$ 能力次序：$Cl^- < NH_3 < Br^- < S_2O_3^{2-} < I^- < CN^- < S^{2-}$
- 多重平衡常数：以 $2[Ag(CN)_2]^- + S^{2-} \rightleftharpoons Ag_2S\downarrow + 4CN^-$ 为例，
  $K_{总} = \dfrac{1}{K_{稳}^2 \cdot K_{sp}} = \dfrac{1}{(1.3\times10^{21})^2 \times 1.1\times10^{-49}} = 5.4\times10^{6}$
- 应用：定影用 $Na_2S_2O_3$ 而非氨水溶解 AgBr；用 $S^{2-}$ 从废定影液/废电镀液富集回收 Ag

### 6. 氧化还原反应（离子视角）

- 方向与程度用能斯特方程判断。例：$Pb^{2+} + Sn \rightleftharpoons Pb + Sn^{2+}$（$\varphi^\theta(Pb^{2+}/Pb) = -0.1262$ V、$\varphi^\theta(Sn^{2+}/Sn) = -0.1375$ V）
  - 两者均为 0.10 mol/L：$E = 0.0113$ V > 0 正向，$K = 2.4$（不完全，平衡后 $[Pb^{2+}] = 0.059$、$[Sn^{2+}] = 0.141$）
  - $Pb^{2+}$ 0.10 / $Sn^{2+}$ 1.0 mol/L：$E = -0.0183$ V < 0 逆向
- 歧化/归中：$A \xrightarrow{\varphi_左^\theta} B \xrightarrow{\varphi_右^\theta} C$
  - $\varphi_左^\theta > \varphi_右^\theta$ → 归中 $A + C = 2B$
  - $\varphi_左^\theta < \varphi_右^\theta$ → 歧化 $2B = A + C$
- 溶液酸碱性的影响：$MnO_4^-$ 强酸 → $Mn^{2+}$（1.507 V）、中性/弱碱 → $MnO_2$（0.595 V）、强碱 → $MnO_4^{2-}$（0.558 V）
  - 例：酸性下 $\varphi(Fe^{3+}/Fe^{2+}) = 0.771$ V > $\varphi(I_2/I^-) = 0.5355$ V → $2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$（$K = 9.27\times10^{7}$）
  - 碱性下 $\varphi(I_2/I^-) = 0.5355$ V > $\varphi(Fe(OH)_3/Fe(OH)_2) = -0.56$ V → $2Fe(OH)_2 + I_2 + 2OH^- = 2Fe(OH)_3 + 2I^-$

### 7. 复杂离子反应：热力学不能单独决定产物

| 体系 | 双水解 $K$ | 氧化还原 $K$ | 实际结果 |
|:---|:---|:---|:---|
| $Fe^{3+}$ + $S^{2-}$ | $1.05\times10^{53}$ | $6.74\times10^{77}$ | 以**氧化还原**为主，且随滴加顺序改变历程 |
| $Fe^{3+}$ + $SO_3^{2-}$ | $1.87\times10^{20}$ | $1.83\times10^{20}$ | **两者同时发生** |

- $Fe^{3+}$ + $SO_3^{2-}$ 实验证据：加 HCl 酸化的 $BaCl_2$ 有白色沉淀（有 $SO_4^{2-}$，证明氧化还原）；光束照射有光亮通路（$Fe(OH)_3$ 胶体，证明双水解）；品红褪色（有 $SO_2$）
- 结论：热力学只给趋势，实际产物还取决于试剂的**用量、添加顺序、动力学因素与实验现象**

### 8. 非水体系中的自耦电离

| 溶剂 | 自耦电离 | 类比水溶液 | 要点 |
|:---|:---|:---|:---|
| 液氨 | $2NH_3 \rightleftharpoons NH_4^+ + NH_2^-$ | $H_2O$ / $H_3O^+$ / $OH^-$ | 碱性比水强 → 水中弱酸在液氨中多为强酸（乙酸） |
| 液态 $SO_2$ | $2SO_2 \rightleftharpoons SO^{2+} + SO_3^{2-}$ | — | 可发生溶剂分解、中和、复分解、氧化还原、配位反应 |
| 液态 $BrF_3$ | $2BrF_3 \rightleftharpoons BrF_2^+ + BrF_4^-$ | — | $SbF_5$ 显一元强酸、KF 显一元碱 |
| 无水 HF | $3HF \rightleftharpoons H_2F^+ + HF_2^-$ | — | $HNO_3$、$HClO_4$ 在 HF 中反而显**碱性** |

- 液氨中 $2NH_4Cl + Ca(NH_2)_2 = CaCl_2 + 4NH_3$ 相当于水中的酸碱中和
- 金属-液氨溶液：$M + (x+y)NH_3 = M(NH_3)_y^+ + [e(NH_3)_x]^-$；稀溶液呈亮蓝色（氨化电子的吸收带，约 $1500\ \mathrm{cm^{-1}}$），氨化电子还原性极强，可制备低氧化态化合物与原子簇（$NaPb_2$、$Na_4Pb_9$、$KP_5$）

### 9. 离子反应的实质

- **复分解反应**（酸碱、水解、沉淀）：向溶液中离子浓度减小的方向进行，条件是生成难溶、难电离或易挥发物质
  - 经典示例（1990 年全国联赛初赛）：四物质在水中/液氨中的溶解度不同 → 水中 $2AgNO_3 + BaCl_2 = 2AgCl\downarrow + Ba(NO_3)_2$；液氨中 $2AgCl + Ba(NO_3)_2 = BaCl_2\downarrow + 2AgNO_3$
  - 侯氏制碱法第②步 $NH_4HCO_3 + NaCl = NH_4Cl + NaHCO_3\downarrow$ 亦基于此原理（$NaHCO_3$ 溶解度最小）
  - **例外**：$Cu^{2+} + H_2S = CuS\downarrow + 2H^+$（$K = 1.5\times10^{14}$，离子浓度反而增加，因 $K_{sp}(CuS) = 6.3\times10^{-36}$ 极小）
- **配位反应与氧化还原反应不遵循**该规律：
  - $[Pb(CH_3COO)_4]^{2-} + Y^{2-} \to PbY + 4CH_3COO^-$，$K_{总} = 3.7\times10^9$
  - $2Fe^{3+} + H_2S = 2Fe^{2+} + S\downarrow + 2H^+$，$E^\theta = 0.629$ V，$K^\theta = 1.9\times10^{21}$

### 10. 离子共存

- 三类不能共存的反应：复分解（酸碱/沉淀/水解）、氧化还原、配位
- 常见氧化性离子：$MnO_4^-$、$ClO^-$、$Cr_2O_7^{2-}$、$Fe^{3+}$、$NO_3^-(H^+)$
- 常见还原性离子：$S^{2-}(HS^-)$、$SO_3^{2-}(HSO_3^-)$、$I^-$、$Fe^{2+}$
- 注意介质酸碱性：$MnO_4^-$ 在强酸/中性或弱碱/强碱中产物不同；$NO_3^-$ 在酸性不强时可与 $Fe^{2+}$ 共存
- 审题附加与隐含条件：溶液无色则不存在 $MnO_4^-$、$Fe^{3+}$、$Fe^{2+}$、$Cu^{2+}$ 等有色离子；「一定能」与「可能能」措辞不可混

### 11. 离子方程式书写

**(1) 拆分原则**：可溶于水的强电解质写离子形式，其他（含难溶强电解质）写化学式；固体间反应、浓 $H_2SO_4$ 与固体反应**不写**离子方程式

**(2) 四个易错点**

1. 酸式盐的弱酸酸根**不拆**（$HSO_4^-$ 除外）：$NaHCO_3 + NaOH$ 应写 $HCO_3^- + OH^- = H_2O + CO_3^{2-}$
2. 微溶物：作反应物且澄清写离子形式、浑浊写化学式；作生成物通常写化学式
3. 同时满足质量守恒与**电荷守恒**：$Fe + 2Fe^{3+} = 3Fe^{2+}$
4. 约简系数不得破坏关系量：$Ba^{2+} + 2OH^- + 2H^+ + SO_4^{2-} = BaSO_4\downarrow + 2H_2O$ 不能约成 1:1:1

**(3) 相对量的影响**

1. 产物与过量物继续反应：$Ag^+$ 加**过量**氨水的总式为 $Ag^+ + 2NH_3\cdot H_2O = [Ag(NH_3)_2]^+ + 2H_2O$
2. 滴加顺序：$AlCl_3$ 滴入 NaOH 与 NaOH 滴入 $AlCl_3$ 的方程式不同
3. 反应先后：$FeBr_2$/$FeI_2$ 通 $Cl_2$，按还原性 $I^- > Fe^{2+} > Br^-$ 依次反应
4. 酸式盐与另一反应物的量比：$NaHCO_3$ 与少量/过量澄清石灰水

**(4) 反应条件的影响**

- 温度：$Cl_2$ 与冷 NaOH 生成 $ClO^-$，与浓热 NaOH 生成 $ClO_3^-$
- 浓度：Cu 与浓 $HNO_3$ 先生成 $NO_2$、随浓度降低继而生成 NO
- 酸碱强弱：苯酚钠通 $CO_2$（少量/过量均得 $HCO_3^-$）与通 $SO_2$（少量得 $SO_3^{2-}$、过量得 $HSO_3^-$）
- 溶解度：$NaH_2PO_4$ 与 $Ca(OH)_2$ 按 8:5 反应，先生成更难溶的 $Ca_3(PO_4)_2$ 再生成 $CaHPO_4$
- 氧化还原性强弱：4 mol $FeBr_2$ 通 3 mol $Cl_2$，$Cl_2$ 先氧化 $Fe^{2+}$ 再氧化部分 $Br^-$

**(5) 隐含因素**

- $Fe(OH)_2$ 溶于足量稀 $HNO_3$：$3Fe(OH)_2 + 10H^+ + NO_3^- = 3Fe^{3+} + NO\uparrow + 8H_2O$（隐含继续氧化）
- $SO_2$ 通入 $BaCl_2$ 不反应，通入 $Ba(NO_3)_2$ 则反应（隐含 $NO_3^-$ 在酸性下氧化 +4 价 S）

## 竞赛要点

1. **「双水解」不等于「完全双水解」**——是否彻底必须用 K 计算判断，两类对应完全不同的离子方程式写法
2. **离子势 $\sqrt{\phi}$ 的三档判据**（2.2 / 3.2）是判断氢氧化物酸碱性的定量工具
3. **复分解的「离子浓度减小」规律有两个著名例外**：$CuS$ 类极难溶沉淀、以及配位反应与氧化还原反应
4. **多重平衡竞争**统一按 $K_{总}$ = 各步常数按化学计量幂次乘除计算，判断竞争方向
5. **$Fe^{3+}$ + $SO_3^{2-}$ 是「热力学不能决定产物」的典型**——必须结合实验现象、用量与滴加顺序
6. **非水体系**用「自耦电离 + 类比水溶液」框架理解，但溶剂碱性强弱会改变酸碱强弱关系（水中弱酸在液氨中可为强酸）
7. 离子方程式高频陷阱集中在**相对量、滴加顺序、反应先后、隐含氧化还原**四处

## 例题与习题

### 典型例题

**例1**（分步沉淀）：向含 0.05 mol/L $Fe^{3+}$ 和 0.1 mol/L $Mg^{2+}$ 的混合液中逐滴加入 NaOH，判断沉淀先后与能否分步沉淀。已知 $K_{sp}(Fe(OH)_3) = 2.8\times10^{-39}$、$K_{sp}(Mg(OH)_2) = 1.9\times10^{-13}$。

- $Fe^{3+}$ 开始沉淀：$[OH^-] = \sqrt[3]{2.8\times10^{-39}/0.05} = 3.8\times10^{-13}$ → pH = 1.58
- $Mg^{2+}$ 开始沉淀：$[OH^-] = \sqrt{1.9\times10^{-13}/0.1} = 1.4\times10^{-6}$ → pH = 8.14
- $Fe^{3+}$ 完全沉淀（取 $1.0\times10^{-5}$ mol/L）时 $[OH^-] = 6.5\times10^{-12}$，此时 $Q(Mg) = 4.3\times10^{-24} \ll K_{sp}$ → **可以分步沉淀**

**例2**（配位-沉淀多重平衡）：$Ag^+$ 溶液的连续转化推断（A~G）与 $K_{总}$ 计算。

- 转化链：AgCl → $[Ag(NH_3)_2]Cl$ → AgBr → $Na_3[Ag(S_2O_3)_2]$ → AgI → $K[Ag(CN)_2]$ → $Ag_2S$
- 争夺 $Ag^+$ 能力：$Cl^- < NH_3 < Br^- < S_2O_3^{2-} < I^- < CN^- < S^{2-}$
- 以生成 $Ag_2S$ 一步为例：$K_{总} = 1/(K_{稳}^2 K_{sp}) = 5.4\times10^{6} \gg 1$，正向完全

**例3**（溶液酸碱性对氧化还原的影响）：判断酸性、碱性溶液中 $I_2/I^-$ 与 $Fe^{3+}/Fe^{2+}$ 混合体系可能发生的反应。

- 酸性：$\varphi^\theta(Fe^{3+}/Fe^{2+}) = 0.771$ V > $\varphi^\theta(I_2/I^-) = 0.5355$ V → $2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$（$K^\theta = 9.27\times10^{7}$）
- 碱性：$\varphi^\theta(I_2/I^-)$ > $\varphi^\theta(Fe(OH)_3/Fe(OH)_2) = -0.56$ V → $2Fe(OH)_2 + I_2 + 2OH^- = 2Fe(OH)_3 + 2I^-$

**例4**（非水体系——1990 年全国联赛初赛）：给出 $AgNO_3$、$Ba(NO_3)_2$、AgCl、$BaCl_2$ 在水与液氨中的溶解度表，写出两种溶剂中的复分解反应方程式。

- 水中向生成 AgCl 方向：$2AgNO_3 + BaCl_2 = 2AgCl\downarrow + Ba(NO_3)_2$
- 液氨中向生成 $BaCl_2$ 方向：$2AgCl + Ba(NO_3)_2 = BaCl_2\downarrow + 2AgNO_3$

### 本讲习题要点

- 用 $K_a$/$K_b$/$K_w$/$K_{sp}$/$K_{稳}$ 计算各类型离子反应的 K，判断方向与完全程度
- 判断双水解是否完全，并据此选择 $\rightleftharpoons$ 或 $=$ 与是否标气体沉淀
- 分步沉淀的定量计算（开始沉淀 pH、完全沉淀 pH 与干扰判断）
- 多重平衡竞争（沉淀 vs 配位）的 $K_{总}$ 计算与转化链推断
- 由元素电势图判断歧化/归中；溶液酸碱性改变氧化还原产物
- 离子共存判断（含颜色、酸碱性、措辞等隐含条件）
- 离子方程式书写（相对量、滴加顺序、反应先后、温度/浓度/酸碱性/溶解度影响、隐含因素）
- 非水体系（液氨、液态 $SO_2$、$BrF_3$、无水 HF）反应的类比书写
