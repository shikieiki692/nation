# Clayden 第21章：芳香亲电取代 资料提炼

---

## 一、核心概念与定义

### 1.1 芳香亲电取代（Electrophilic Aromatic Substitution, EAS）
- **定义**：芳香化合物与亲电试剂反应，苯环上的一个氢被亲电基团取代的反应。
- **通式**：Ar-H + E⁺ → Ar-E + H⁺
- **本质**：芳香化合物是亲核试剂（π电子丰富），但因[[芳香性]]的高度稳定性，它只与非常活泼的（通常是阳离子的）亲电试剂反应。

### 1.2 苯的芳香性
- **结构特征**：平面正六边形，6个 sp² 碳，所有 C-C 键长 1.39 Å（介于 C-C 1.47 Å 和 C=C 1.33 Å 之间）。
- **芳香性来源**：6个 π 电子占据三个成键分子轨道，提供约 140 kJ/mol 的额外稳定化能。
- **NMR 证据**：所有氢等价，δ_H = 7.2 ppm（位于离域 π 体系的屏蔽区）。

### 1.3 芳香亲电取代 vs 烯烃亲电加成
| 特征 | 芳香亲电取代 | 烯烃亲电加成 |
|:---|:---|:---|
| 中间体 | σ 络合物（Wheland 中体） | 碳正离子/溴鎓离子 |
| 最终步骤 | 失去 H⁺（恢复芳香性） | 亲核试剂加成 |
| 产物 | 取代产物（保留 π 体系） | 加成产物（π 体系消失） |
| 催化剂 | 通常需要 Lewis 酸 | 通常不需要 |

### 1.4 芳香化合物与烯醇的类比
- [[苯酚]]是"芳香烯醇"——完全以烯醇式存在（芳香性极端稳定化）。
- 苯酚的亲电取代与烯醇的 α-卤代在机理上类似（电子通过 π 体系传递到亲电位点）。

## 二、芳香亲电取代的一般机理

### 2.1 两阶段机理
1. **慢步骤（决速步）**：亲电试剂 E⁺ 进攻苯环 π 体系 → 生成 [[σ络合物|σ 络合物]]（阳离子中间体）
2. **快步骤**：碱（如 X⁻、H₂O 等）夺取 sp³ 碳上的 H⁺ → 恢复芳香性 → 产物

### 2.2 σ 络合物（Wheland 中间体）
- **结构**：环上有一个 sp³ 杂化的碳原子（承载 H 和 E），环不再是芳香性体系。
- **离域**：正电荷在两个邻位和一个对位离域（各带 1/3 正电荷）。
- **不稳定**：因芳香性丧失而能量高，比起始物和产物都不稳定。
- **共振结构**：三种极限共振式（正电荷分别在 C2、C4、C6）。

### 2.3 Hammond 假说的应用
- 由于第一步是高能吸热过程（芳香性丧失），过渡态结构与 σ 络合物（高能中间体）相近。
- 因此分析 σ 络合物的稳定性 → 可预测反应速率和定位效应。

### 2.4 σ 络合物的实验证据
- 在超强酸（FSO₃H/SbF₅，-120°C）中，苯可被质子化生成 σ 络合物，其 ¹H 和 ¹³C NMR 可被记录。
- 电荷分布与共振式预测高度吻合。

## 三、苯的经典亲电取代反应

### 3.1 硝化反应（Nitration）
- **试剂**：浓 HNO₃ + 浓 H₂SO₄（混酸）
- **亲电试剂**：NO₂⁺（硝酰离子，nitrosonium ion）——直线型，与 CO₂ 等电子，sp 杂化氮
- **机理**：
  1. H₂SO₄ 质子化 HNO₃ → NO₂⁺ + H₂O
  2. 苯的 π 体系进攻 NO₂⁺ → σ 络合物
  3. 失去 H⁺ → 硝基苯（PhNO₂）
- **特点**：产物硝基是强钝化基、间位定位基 → 反应在单取代后停止。

### 3.2 卤化反应（Halogenation）
- **试剂**：X₂ + Lewis 酸（AlCl₃、FeBr₃ 或 Fe 粉）
- **亲电试剂**：X⁺（卤素阳离子）——由 X₂ 与 Lewis 酸配位极化产生
- **机理**：
  1. X₂ + AlCl₃ → X⁺···AlCl₃⁻（极化复合物）
  2. 苯进攻 X⁺ → σ 络合物
  3. 失去 H⁺ → 卤苯（PhX）+ HX
- **对比**：烯烃直接与 Br₂ 反应（加成），苯需要 Lewis 酸催化才能反应（取代）。

### 3.3 磺化反应（Sulfonation）
- **试剂**：浓 H₂SO₄ 或 发烟硫酸（H₂SO₄ + SO₃）
- **亲电试剂**：SO₃ 或 SO₃H⁺（质子化的 SO₃）
- **机理**：
  1. H₂SO₄ 自身质子化 → SO₃H⁺
  2. 苯进攻 SO₃H⁺ → σ 络合物
  3. 失去 H⁺ → 苯磺酸（PhSO₃H）
- **特点**：反应可逆（在 Chapter 24 中利用）；产物为强酸。

### 3.4 Friedel-Crafts 烷基化（Alkylation）
- **试剂**：RCl + Lewis 酸（通常为 AlCl₃）
- **亲电试剂**：R⁺（碳正离子）
- **机理**：
  1. AlCl₃ + RCl → R⁺ + AlCl₄⁻
  2. 苯进攻 R⁺ → σ 络合物
  3. 失去 H⁺ → 烷基苯（ArR）
- **问题**：
  1. **多取代**：产物比原料更活泼 → 混合物
  2. **重排**：伯碳正离子重排为仲/叔碳正离子（如 n-PrCl → i-PrPh）

### 3.5 Friedel-Crafts 酰基化（Acylation）
- **试剂**：RCOCl + Lewis 酸（通常为 AlCl₃，需 >1 当量）
- **亲电试剂**：RC≡O⁺（酰基鎓离子，acylium ion）——氧的孤对电子稳定碳正离子
- **机理**：
  1. AlCl₃ + RCOCl → RCO⁺ + AlCl₄⁻
  2. 苯进攻 RCO⁺ → σ 络合物
  3. 失去 H⁺ → 芳基酮（ArCOR）
- **优势**：
  1. 产物酰基是钝化基 → 不发生多取代（单取代干净停止）
  2. 酰基鎓离子稳定 → 不发生重排
  3. 酮可还原为烷基 → 间接实现正烷基苯的合成（Clemmensen 还原：Zn(Hg)/HCl）

## 四、定位效应——取代基对反应位置的影响

### 4.1 邻对位定位基（Ortho, Para-Directing）
- **类型**：含孤对电子的杂原子（-OH, -NH₂, -OR, -NHCOR）和烷基（-R）
- **活化作用**：
  - -NR₂, -OR：强活化（共轭给电子，孤对电子与 π 体系共轭）→ 仅邻对位
  - 烷基：弱活化（σ 共轭/超共轭）→ 大部分邻对位，少量间位
- **定位原理**：
  - 共轭给电子使邻位和对位的电子密度最高 → HOMO 轨道系数最大 → 亲电进攻优先
  - σ 络合物中，邻/对位进攻时正电荷可离域到连接取代基的碳上（叔碳 → 更稳定）

### 4.2 间位定位基（Meta-Directing）
- **类型**：吸电子基（-NO₂, -CN, -COR, -SO₃H, -CF₃, -NR₃⁺）
- **钝化作用**：使环的电子密度降低 → 与亲电试剂反应变慢
- **定位原理**：
  - 邻/对位进攻时，正电荷必须离域到连接吸电子基的碳上 → 不稳定（正电荷与吸电子基排斥）
  - 间位进攻时，正电荷不经过连接碳 → 相对更稳定
- **本质**：缺电子环"被迫"反应时，选择最不坏的路径（间位）。

### 4.3 卤素的特殊性——钝化但邻对位定位
- **矛盾现象**：卤苯比苯反应慢（钝化），但产物主要在邻对位（邻对位定位）。
- **解释**：卤素有两种相反的效应：
  1. **诱导吸电子**：F、Cl、Br、I 电负性大 → 从环吸取 σ 电子 → 钝化
  2. **共轭给电子**：卤素的孤对电子与 π 体系共轭 → 但因 p 轨道大小不匹配（除 F 外），共轭较弱
- **综合结果**：共轭给电子弱于诱导吸电子 → 净效果为钝化；但共轭效应仍选择性地给邻/对位电子 → 邻对位定位。
- **各卤素差异**：
  - F：2p-2p 重叠好但轨道能级低 → 氟苯对位选择性最高（86%）
  - Cl、Br：3p/4p-2p 重叠差 → 活性最低
  - I：5p 重叠最差但电负性低 → 活性居中

## 五、定位效应总结表

| 电子效应 | 取代基 | 活化/钝化 | 定位 |
|:---|:---|:---|:---|
| 共轭给电子 | -NR₂, -OR | 很活化 | 仅邻对位 |
| 诱导给电子 | 烷基（-R） | 活化 | 大部分邻对位，少量间位 |
| 共轭给电子 + 诱导吸电子 | F, Cl, Br, I | 钝化 | 绝大部分对位 + 少量邻位 |
| 诱导吸电子 | -CF₃, -NR₃⁺ | 钝化 | 仅间位 |
| 共轭吸电子 | -NO₂, -CN, -COR, -SO₃H | 很钝化 | 仅间位 |

## 六、苯酚和苯胺的亲电取代

### 6.1 苯酚的反应性
- **比苯活泼得多**：OH 基的孤对电子共轭给电子 → π 体系电子密度大幅增加。
- **溴代**：室温、无催化剂即可迅速反应 → 2,4,6-三溴苯酚（白色沉淀）。
- **硝化**：需用稀 HNO₃（避免氧化）→ 邻/对硝基苯酚。
- **分子内氢键**：邻硝基苯酚沸点低（可水蒸气蒸馏），对硝基苯酚沸点高。
- **定位效应**：OH 是强邻对位定位基、活化基。

### 6.2 苯胺的反应性
- **比苯酚更强的活化**：N 电负性小于 O → 孤对电子能量更高 → 与 π 体系作用更强。
- **溴代**：极剧烈，迅速给出 2,4,6-三溴苯胺（需控制条件才能单取代）。
- **控制单取代策略**：乙酰化氨基 → 酰苯胺（氮孤对电子与羰基共轭 → 减弱给电子能力）→ 溴代（主要在对位）→ 水解恢复氨基。
- **NMe₂ vs OMe 的活化能力**：N,N-二甲苯胺溴代速率是苯甲醚的 10⁵ 倍。

### 6.3 Kolbe-Schmitt 反应
- 苯酚钠 + CO₂ → 水杨酸（2-羟基苯甲酸）→ 阿司匹林前体。
- O⁻ 是强邻对位定位基；Na⁺ 的配位作用将 CO₂ 送至邻位。

## 七、烷基苯的亲电取代

### 7.1 甲苯的反应性
- **比苯快 4000 倍**：甲基的 σ 共轭（超共轭）给电子 → π 体系能量升高。
- **定位**：邻对位为主（因正电荷在邻/对位进攻时可离域到叔碳上）。
- **NMR 证据**：邻/对位质子化学位移减小（电子密度增加）。

### 7.2 磺化与对甲苯磺酸
- 甲苯磺化 → 混合物（邻/对甲苯磺酸）
- 对甲苯磺酸（TsOH/PTSA）：固体强酸，替代硫酸的温和催化剂
- 对甲苯磺酰氯（TsCl）：制备对甲苯磺酸酯（好的离去基团）的试剂

---

## 八、吸电子基的间位定位

### 8.1 诱导吸电子基
- **-NR₃⁺（三甲铵基）**：四面体型氮，无孤对电子可共轭 → 纯诱导吸电子
  - 硝化比苯慢 10⁷ 倍，产物几乎全在间位
- **-CF₃（三氟甲基）**：三个高电负性 F 使 C-F 键强烈极化
  - 硝化几乎定量得到间位产物

### 8.2 共轭吸电子基
- **-NO₂（硝基）**：与 π 体系共轭，强烈吸取电子 → 间位定位、很钝化
  - 硝基苯的硝化需发烟 HNO₃ + 100°C → 间二硝基苯
  - 硝基苯的溴代需 Fe 催化剂 + 高温 → 间溴硝基苯
- **-COR, -CN, -SO₃H**：类似的共轭吸电子 → 间位定位

### 8.3 NMR 证据
- 硝基苯、苯甲醛、苯甲酸甲酯、苯磺酸甲酯、苯甲腈：所有质子化学位移均大于苯（δ > 7.26）
- 间位质子位移最小 → 电子密度相对最高 → 间位进攻最有利

## 九、多取代基的合作与竞争

### 9.1 合作定位
- 当两个取代基的定位效应指向相同位置时 → 高度区域选择性。
- **实例**：对羟基苯甲醛的溴代 → OH 基定位邻位，醛基定位间位 → 两种效应合作，两个邻位（C2、C6）均被溴代。

### 9.2 竞争定位
- 当两个取代基指向不同位置时 → 强活化基"胜出"。
- **竞争强度**：活化基 > 钝化基 > 弱活化基（烷基）
- **实例**：
  - BHT 抗氧化剂合成：对甲酚 + t-Bu⁺ → OH 基（强活化）的邻位被烷基化
  - 酰苯胺衍生物的溴代：-NHCOMe（活化）支配甲基（弱活化）的定位

### 9.3 多取代基选择性的判断流程
1. **电子效应优先**：任何活化基 > 任何钝化基
2. **活化强度排序**：-NR₂ > -OR > -NHCOR > -R
3. **位阻效应其次**：邻位拥挤时偏向对位
4. **排除位阻大的位置**：三取代相连的位点通常不利

## 十、Friedel-Crafts 反应的限制与解决方案

### 10.1 烷基化的问题
1. **多取代**：产物比原料更活泼 → 混合物
2. **重排**：伯碳正离子 → 仲/叔碳正离子（氢迁移或甲基迁移）
3. **仅适用于能形成稳定碳正离子的底物**

### 10.2 酰基化的优势
1. **单取代**：产物酰基钝化环 → 不发生多取代
2. **不重排**：酰基鎓离子稳定 → 保持碳骨架
3. **灵活性**：R 可以是任意基团（包括伯烷基前体）

### 10.3 酰基化→还原路线
- 芳香酮（ArCOR）→ Clemmensen 还原（Zn(Hg)/HCl）→ 烷基苯（ArCH₂R）
- 此路线可实现正烷基苯的合成（直接烷基化会重排）

### 10.4 酰基化的注意事项
- AlCl₃ 需要 >1 当量（因产物酮的氧会配位 AlCl₃）
- 硝基苯对 Friedel-Crafts 惰性（太钝化）→ 常用作溶剂

## 十一、硝基化学的合成应用

### 11.1 硝化→还原→重氮化策略
1. **硝化**：在间位引入硝基（间位定位基）
2. **还原**：NO₂ → NH₂（Sn/HCl 或 H₂/Pd/C）
3. **重氮化**：NH₂ → N₂⁺（NaNO₂/HCl）
4. **取代**：N₂⁺ 被各种亲核试剂取代（-OH, -CN, -Br, -I 等）

### 11.2 策略价值
- 硝基是间位定位基 → 可在间位引入含氮/氧官能团
- 还原后氨基变为邻对位定位基 → 可继续在邻/对位引入取代基
- 重氮化提供多种官能团转化途径

## 十二、竞赛题型与解题策略

### 12.1 产物预测型
- **给定底物 + 试剂**：判断取代位置（邻/对位 vs 间位）和取代次数。
- **关键判据**：已有取代基的定位效应、活化/钝化程度、位阻因素。

### 12.2 定位效应判断型
- **判断定位类型**：画出 σ 络合物的共振结构，分析正电荷是否经过连接取代基的碳。
- **判断活化/钝化**：比较取代苯与苯的反应速率。
- **卤素的特殊性**：钝化但邻对位定位——两种相反效应的综合。

### 12.3 多取代基选择性型
- **合作 vs 竞争**：两个取代基指向相同还是不同位置。
- **强度排序**：强活化基支配弱活化基；活化基支配钝化基。
- **位阻因素**：电子效应确定候选位点后，位阻排除拥挤位点。

### 12.4 Friedel-Crafts 反应设计型
- **直接烷基化的问题**：多取代 + 重排 → 选择酰基化-还原路线。
- **正烷基苯的合成**：酰基化 + Clemmensen 还原。
- **底物适用性**：强钝化底物（如硝基苯）不能进行 Friedel-Crafts。

### 12.5 合成路线设计型
- **间位取代氨基化合物**：硝化 → 还原
- **邻/对位取代氨基化合物**：先还原（氨基）→ 乙酰化保护 → 定位引入取代基 → 脱保护
- **多取代苯的合成**：考虑每步引入取代基的定位效应

### 12.6 竞赛高频考点清单
1. σ 络合物的共振结构——正电荷在邻/对位离域
2. 邻/对位 vs 间位定位——σ 络合物稳定性分析
3. 卤素的特殊性——钝化但邻对位定位的双重效应
4. Friedel-Crafts 烷基化 vs 酰基化——多取代与重排问题
5. 多取代基的竞争定位——活化强度排序
6. 苯酚/苯胺的高反应性——孤对电子共轭给电子
7. 硝基化学的合成应用——间位引入氨基的策略
8. 对甲苯磺酸（TsOH）——固体强酸催化剂的制备与应用

## 十七、摘录的原始段落（附页码/位置标记）

### 17.1 关于苯的不活泼性（lines 2862-2866）
> "苯十分不活泼——它只与非常活泼（通常是阳离子的）亲电试剂反应。它给出取代产物，而非加成产物。"

### 17.2 关于σ 络合物（lines 2880-2884）
> "阳离子中间体，当然与起始原料、产物相比，都是不稳定的。但它归根结底被离域所稳定...很重要的一点是，虽然这个阳离子是离域的，但它并不具有芳香性。"

### 17.3 关于苯酚的反应性（lines 2999-3009）
> "酚与苯截然不同：不需要 Lewis 酸的催化，反应也能很迅速地发生...这种区别的原因在于苯酚的烯醇性质。氧非键轨道上孤电子对的参与，使苯上原本低能的成键轨道成为更高能的 HOMO。"

### 17.4 关于定位效应（lines 3031-3037）
> "我们称 OH 基对亲电试剂有邻对位定位作用...我们可以通过观察弯曲箭头，或者观察分子轨道来理解这一现象。HOMO 轨道系数的分布是交替的（alternate），就像烯丙基阴离子在两端而不是中间有较大的系数。"

### 17.5 关于烷基的活化（lines 3148-3156）
> "甲基通过共轭，微弱地贡献电子...C-H σ 键中的一根可以以相似的方式与 π 体系相互作用——这一相互作用被称作 σ 共轭。亲电试剂进攻烷基苯后，正电荷落在带有烷基的碳上，这个碳是叔碳，因此所生成的碳阳离子更稳定。"

### 17.6 关于吸电子基的间位定位（lines 3236-3240）
> "亲电试剂如果进攻邻位或者对位...在中间体中，与 CF₃ 相连的碳原子就得带有正电荷，这对于吸电子基是不稳定的，因此会使这一中间体高能。换种方式思考：缺电子环会相当不愿意和亲电试剂反应，但如果它必须这样做，那么它会选择糟糕的结果中最不糟糕的一个——即间位取代。"

### 17.7 关于卤素的特殊性（lines 3320-3328）
> "所有卤苯都比苯本身反应得慢...卤素存在两种相反的效应：通过共轭的给电子效应和通过诱导的吸电子效应。卤素有三对孤电子，其中的一个可能会像苯酚、苯胺中的一样与环共轭，然而这种共轭远比不上苯酚和苯胺中的好。"

### 17.8 关于 Friedel-Crafts 酰基化的优势（lines 3420-3440）
> "酰基化的产物是一个酮：向芳环引入的是一个钝化基、吸电子基，而且羰基能与环共轭。因此产物比起始原料更加不活泼，反应会干净地停留在一次酰化。"

### 17.9 关于多取代基的竞争（lines 3350-3378）
> "两个或多个取代基的定位效应可能一同工作，或彼此对抗...对于电子效应，通常来说，任何活化效应都比钝化效应更为重要。"
