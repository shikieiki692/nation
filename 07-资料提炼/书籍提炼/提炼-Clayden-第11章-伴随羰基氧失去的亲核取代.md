# Clayden 第11章：伴随羰基氧失去的羰基亲核取代 资料提炼

---

## 一、核心概念与定义

### 1.1 本章反应的本质——"羰基氧的取代"
- **Ch10 的回顾**：亲核试剂进攻羰基 → 四面体中间体 → 离去基团离去 → 重新形成羰基（总体为取代反应，离去基团是 Cl、OR、NH₂ 等）。
- **本章的核心区别**：不再有离去基团，取而代之的是 **整个羰基氧原子被其他原子（N、O、C）替换**。
- **共同机理模式**：亲核试剂进攻 C=O → 四面体中间体 → 脱水（失去 H₂O）→ 新的 C=X 双键（X = N、O、C）。
- **酸催化的必要性**：脱水步骤需要将 OH 转化为好的离去基团（H₂O），因此必须有酸催化。
- **与 Ch6 加成反应的对比**：Ch6 中亲核加成停留在四面体产物（如醇），而本章中四面体中间体不稳定，进一步脱水。

### 1.2 缩醛（Acetal）与半缩醛（Hemiacetal）
- **缩醛**：同一碳原子上连有两个 OR 基团的化合物，R₂C(OR')₂。
- **半缩醛**：同一碳原子上连有一个 OH 和一个 OR 的化合物，R₂C(OH)(OR')，是缩醛形成的中间体。
- **环状缩醛（二氧戊环，dioxolane）**：由乙二醇与[[醛酮]]缩合形成的五元环缩醛，比非环状缩醛更稳定、更容易制取。
- **天然缩醛**：糖类（葡萄糖的环状半缩醛、麦芽糖的缩醛、淀粉和纤维素的多缩醛）。

### 1.3 亚胺（Imine）及其衍生物
- **亚胺**：C=N 双键化合物，由伯胺与醛/酮缩合而成，R₂C=NR'。
- **半胺缩醛（Hemiaminal）**：C 上同时连有 OH 和 NR' 的中间体，是亚胺形成的四面体中间体。
- **亚铵离子（Iminium ion）**：C=N⁺ 结构，是质子化的亚胺，高度亲电。
- **肟（Oxime）**：C=N-OH，由羟胺 + 羰基化合物形成，稳定可分离。
- **腙（Hydrazone）**：C=N-NH₂，由肼 + 羰基化合物形成。
- **缩氨基脲（Semicarbazone）**：C=N-NHCONH₂，由缩氨基脲 + 羰基化合物形成。
- **席夫碱（Schiff base）**：亚胺的另一名称，特指 N 上连有芳基或烷基的亚胺。

### 1.4 烯胺（Enamine）
- **定义**：C=C-N 结构，双键与氮相邻，由 **仲胺** + 醛/酮 缩合而成。
- **与亚胺的区别**：伯胺 → 亚胺（C=NR'），仲胺 → 烯胺（C=C-NR'₂），因为仲胺形成的亚铵离子无 N-H 可失去，只能失去 α-H。
- **烯胺与亚胺互变**：伯胺形成的烯胺与亚胺互为互变异构体（类似烯醇-酮互变）。

### 1.5 Wittig 反应
- **定义**：磷叶立德（phosphonium ylide, R₃P=CR₂）与醛/酮反应，C=O 被 C=C 替换。
- **关键驱动力**：P=O 键极强（575 kJ/mol），反应不可逆。
- **氧磷丁环（Oxaphosphetane）**：四元环中间体，由叶立德碳负离子进攻羰基后，氧负离子进攻磷正离子关环形成。
- **Wittig 试剂的制备**：膦（如 PPh₃）+ 卤代烃 → 鏻盐 → 强碱（BuLi、NaH）去质子 → 磷叶立德。

## 二、重要反应与机理

### 2.1 半缩醛的形成与平衡

#### 反应式
RCHO + R'OH ⇌ RCH(OH)(OR') （半缩醛）

#### 机理要点
- **酸催化**：质子化 C=O → 增强亲电性 → 醇进攻 → 半缩醛。
- **碱催化**：碱从 ROH 夺取质子 → 生成 RO⁻ → 更强的亲核试剂进攻 C=O。
- **平衡常数**：大多数半缩醛不稳定（K ≈ 0.5），仅当 [ROH] 极大（做溶剂）或为环状半缩醛时有利。
- **环状半缩醛例外**：分子内 OH 与 C=O 同在一个分子中，熵效应有利，可稳定存在（如葡萄糖）。

### 2.2 缩醛的形成（全机理）

#### 总反应式
RCHO + 2 R'OH → RCH(OR')₂ + H₂O （酸催化，可逆）

#### 完整机理（四步）
1. **质子化**：C=O 被质子化，增强亲电性。
2. **醇加成**：第一分子 ROH 进攻，形成半缩醛（经历锌离子/oxonium ion 中间体）。
3. **质子化 OH → 脱水**：半缩醛的 OH 被质子化 → 离去 H₂O → 形成锌离子（oxonium ion，R₂C=O⁺R）。
4. **第二分子醇加成**：ROH 进攻锌离子 → 去质子 → 缩醛。

#### 关键中间体——锌离子（Oxonium Ion）
- 连有三根键的带正电氧原子，具有π键（R₂C=O⁺R），是强亲电试剂。
- 类似于亚铵离子（R₂C=NR₂⁺），但 **锌离子无 N-H 可失去，只能被亲核试剂进攻**。

#### 制取条件
- **平衡常数小**（K = 0.0125，醛；更小，酮），需推动平衡：
  - 使用过量醇
  - 蒸馏除水（Dean Stark 分水器）
  - 分子筛（沸石）吸水
  - 催化剂：对甲苯磺酸（TsOH）、干燥 HCl 气体

### 2.3 缩醛的水解

- **条件**：仅酸催化水解，**对碱完全稳定**。
- **机理**：缩醛形成反应的逆反应。
- **保护基意义**：缩醛在碱性/亲核条件下（如 Grignard 试剂、LiAlH₄）稳定，仅酸性条件水解 → 选择性保护羰基。

### 2.4 环状缩醛（二氧戊环）的形成

- **试剂**：乙二醇（HOCH₂CH₂OH）+ 醛/酮 + 酸催化（TsOH）。
- **优势**：
  - 比非环状缩醛更稳定（熵效应：分子内进攻更快）。
  - 即使酮也能顺利形成环状缩醛。
  - 第二个锌离子形成时，分子内 OH 立即关环，水无法竞争进攻。
- **除水方法**：Dean Stark 分水器（甲苯共沸蒸水）、分子筛。

### 2.5 亚胺的形成

#### 总反应式
R₂C=O + R'NH₂ → R₂C=NR' + H₂O （酸催化，可逆）

#### 完整机理
1. **胺进攻 C=O**（无需酸催化）：胺是好的亲核试剂，直接进攻 → 半胺缩醛（hemiaminal）。
2. **酸催化脱水**：OH 被质子化 → 离去 H₂O → 亚铵离子（iminium ion）。
3. **去质子**：亚铵离子失去 N-H 质子 → 亚胺（C=NR'）。

#### pH 依赖性（关键！）
- **最佳 pH ≈ 4-6**（与生物反应类似）。
- pH 过低：胺被质子化为 NH₃⁺，亲核性丧失 → 第一步变慢。
- pH 过高：[H⁺] 不足，脱水步骤（第二步）变慢。
- 这是典型的"钟形曲线"——酸太多或太少都不利。

#### 平衡与稳定性
- 大多数亚胺不稳定（K 小），需除水驱动平衡。
- 仅当 C=N 连有芳基时，亚胺才足够稳定可分离。
- 由 NH₃ 形成的亚胺极不稳定（如 CH₂=NH 在 -80°C 以上分解）。

### 2.6 稳定亚胺衍生物

- **肟**（C=N-OH）、**腙**（C=N-NH₂）、**缩氨基脲**（C=N-NHCONH₂）：N 上连有吸电子基团，通过离域稳定 C=N 双键（降低碳上正电荷，升高 LUMO 能量）。
- **历史用途**：结晶固体，用于鉴别挥发性醛/酮（测熔点），NMR 时代前的重要分析手段。

### 2.7 亚铵离子的亲电反应——还原胺化

#### 还原胺化（Reductive Amination）
- **原理**：醛/酮 + 胺 → 亚铵离子 → 选择性还原 → 胺。
- **还原剂选择**：
  - **Na(CN)BH₃**（氰基硼氢化钠）：选择性还原亚铵离子，不还原羰基化合物。
  - **NaBH(OAc)₃**（三乙酰氧基硼氢化钠）：更安全，避免释放 HCN。
  - **催化氢化**（H₂/Pd）：可在羰基存在下还原亚胺（通常不还原 C=O）。
- **一锅法**：亚胺形成与还原在同一容器中进行（亚铵离子原位生成、原位还原）。
- **用途**：制取伯胺、仲胺（比烷基化法更好，避免多烷基化）。

#### 生物中的还原胺化
- **丙氨酸合成**：丙酮酸 + 吡哆胺（维生素 B₆ 衍生物）→ 席夫碱 → 异构化 → 水解 → 丙氨酸 + 吡哆醛。
- 自然界在 Na(CN)BH₃ 发明前就进行了亿万年的还原胺化反应。

### 2.8 LiAlH₄ 还原酰胺为胺

- **机理**：LiAlH₄ 进攻酰胺 C=O → 四面体中间体 → 坍塌为亚铵离子 → 进一步还原为胺。
- **与还原胺化的联系**：酰胺还原产生的亚铵离子与还原胺化中的亚铵离子相同。

### 2.9 Strecker 合成法——氨基酸的制备

- **反应**：醛 + NH₃ + HCN → α-氨基腈 → 水解 → α-氨基酸。
- **机理关键**：CN⁻ 进攻亚铵离子（比进攻羰基更快）。
- **实例**：苯甲醛 → 苯基甘氨酸（非蛋白质氨基酸）。

### 2.10 Wittig 反应

#### 试剂制备
1. PPh₃ + RCH₂X → [Ph₃P-CH₂R]⁺ X⁻ （鏻盐，[[SN2反应]]）
2. [Ph₃P-CH₂R]⁺ + BuLi → Ph₃P=CHR （磷叶立德）

#### 反应式
R₂C=O + Ph₃P=CR'₂ → R₂C=CR'₂ + Ph₃P=O

#### 完整机理
1. **亲核进攻**：叶立德的碳负离子部分进攻 C=O → 形成 betaine 中间体（或直接关环）。
2. **关环**：氧负离子进攻磷正离子 → 氧磷丁环（oxaphosphetane，四元环）。
3. **开环消除**：四元环以顺式消除方式坍塌 → 烯烃 + Ph₃P=O。

#### 立体化学
- 不稳定叶立德（R = 烷基）→ 主要生成 **Z-烯烃**（顺式）。
- 稳定叶立德（R = EWG，如 CO₂R、CN）→ 主要生成 **E-烯烃**（反式）。
- 立体选择性来源于氧磷丁环形成和开环的立体化学。

#### 特殊优势
- P=O 键极强（575 kJ/mol），反应不可逆，无需控制平衡。
- 位置专一性：双键恰好形成在原来 C=O 的位置（优于消除反应的区域选择性）。

## 三、关键结论与规则

### 3.1 本章反应的统一机理模式
1. 亲核试剂（ROH、R'NH₂、叶立德 C⁻）进攻 C=O → 四面体中间体。
2. 四面体中间体不稳定 → 脱水（需要酸催化将 OH 变为好的离去基团）。
3. 形成新的 C=X 双键（X = O、N、C）。

### 3.2 酸催化的双刃剑
- **醛/酮 + 醇**：酸催化增强 C=O 亲电性，促进醇进攻；但同时使醇质子化。
- **醛/酮 + 胺**：第一步不需要酸（胺已是好的亲核试剂），但第二步脱水需要酸 → **最佳 pH 4-6**。
- **缩醛形成**：必须酸催化（碱无法催化脱水步骤）。
- **缩醛水解**：仅酸催化，对碱稳定 → 保护基的基础。

### 3.3 缩醛作为保护基的核心规则
- 缩醛在碱性、亲核性条件下稳定（Grignard、LiAlH₄、NaBH₄、NaOH 均不进攻）。
- 仅酸性条件（稀 HCl、TsOH）水解 → 脱保护。
- 环状缩醛（二氧戊环）比非环状缩醛更稳定、更易制取。

### 3.4 亚胺与烯胺的选择规律
| 胺的类型 | 产物 | 说明 |
|:---:|:---:|:---|
| 伯胺 R'NH₂ | 亚胺 R₂C=NR' | N 上有 H 可失去 |
| 仲胺 R'₂NH | 烯胺 R₂C=CR-NR'₂ | N 上无 H，失去 α-H |
| 氨 NH₃ | 亚胺 R₂C=NH | 极不稳定，仅溶液中检测 |

### 3.5 还原胺化的选择性
- Na(CN)BH₃ 或 NaBH(OAc)₃：**仅还原亚铵离子**，不还原醛/酮 → 一锅法可行。
- 催化氢化：可还原 C=N（亚胺），但通常不还原 C=O → 另一种选择性还原方式。

### 3.6 Wittig 反应的要点
1. 叶立德碳负离子 + 醛/酮 → 烯烃，双键位置精确。
2. P=O 键（575 kJ/mol）驱动反应不可逆。
3. 氧磷丁环四元环中间体。
4. 立体化学：不稳定叶立德 → Z-烯烃；稳定叶立德 → E-烯烃。

### 3.7 与 Ch6 加成反应的对比

| 特征 | Ch6 加成 | 本章取代 |
|:---|:---|:---|
| 产物 | 四面体醇/半缩醛 | C=X 双键化合物 |
| 是否脱水 | 否 | 是（酸催化） |
| 平衡 | 常有利 | 通常需除水推动 |
| 羰基命运 | C=O 保留为 OH | C=O 完全消失 |

## 八、摘录的原始段落（附页码/位置标记）

### 8.1 关于本章的核心思想（lines 1159–1176）
> "亲核试剂对羰基的加成，可以使得羰基中的三角型碳原子变为四面体型。"
> "在本章中，您将会遇到另一类取代反应。羰基不会有离去基团失去，取而代之的是羰基氧的失去。"

### 8.2 关于酸碱催化半缩醛（lines 1207–1223）
> "酸催化剂奏效的方式是提高羰基的亲电性。另一方面，碱催化剂则通过增强醇的亲核性而奏效，方式是在 OH 进攻 C=O 基前移去它的质子。"
> "您可以看出来，为什么半缩醛是不稳定的：它们本质上是包含离去基团的四面体中间体。"

### 8.3 关于锌离子的必要性（lines 1283–1289）
> "当您自己写出缩醛形成的反应的机理时，我们希望您不要忘记了锌离子的存在！它确实很容易被忘记，但真实机理肯定不是通过醇直接取代水实现的。"

### 8.4 关于缩醛的平衡常数（lines 1293–1297）
> "缩醛的形成比酯的形成更为困难：因为酸与醇在酸催化下成酯的平衡常数通常大约是1，而醛与醇在酸催化下成缩醛的平衡常数 K = 0.0125，对于酮，这个数值将更低。"

### 8.5 关于缩醛的保护基作用（lines 1357–1363）
> "缩醛对碱和碱性亲核试剂，如格氏试剂是稳定的，因此我们不再担心活性问题了。一旦格氏试剂与亲电试剂反应过后，我们还可以通过稀酸将缩醛水解，重新拿回酮。在这里，缩醛的作用是保护酮不被格氏试剂进攻，这便是被用作了保护基。"

### 8.6 关于亚胺形成的 pH 依赖性（lines 1425–1429）
> "亚胺的形成在大约 pH 4-6 时最快：pH 过低会导致更多的胺被质子化以降低第一步反应的速率，pH 过高会导致质子的浓度太低无法在脱水步骤中将 OH 质子化为离去基团。亚胺的形成反应很像是生物反应：在近于中性时反应得最快。"

### 8.7 关于稳定亚胺（lines 1457–1465）
> "氮原子与负电性基团相连的亚胺通常是稳定的：包括肟，腙和缩氨基脲。这些化合物比亚胺稳定，因为它们的负电性取代基可以参与亚胺双键的离域。离域减少了碳原子上的正电荷分布并升高了 LUMO 的能量。"

### 8.8 关于亚铵离子与锌离子的差异（lines 1477–1489）
> "由于亚铵离子包含可以失去的质子，而锌离子没有，于是它们分道扬镳了。锌离子会扮演亲电试剂，被另一分子的醇加成，变为缩醛。"
> "如果有合适的亲核试剂存在，那么亚铵离子也会被说服，充当锌离子那样亲电试剂的角色。"

### 8.9 关于烯胺的形成（lines 1491–1509）
> "它的机理与由伯胺形成亚胺的机理，直到亚铵离子形成前都是相同的。但此亚铵离子没有能够失去的 N-H 质子，因此它会失去与 C=N 相邻的一个 C-H 质子并得到烯胺。"
> "醛或酮与伯胺形成亚胺。醛或酮与仲胺形成烯胺。二者都需要酸催化并需要除水。"

### 8.10 关于还原胺化（lines 1527–1533）
> "亚胺 (或亚铵离子) 的还原是制取胺的实用方法。由羰基化合物到胺的整个过程被称为还原胺化反应。事实上，这是少数制取仲胺的成功方法之一。这应当是您制取胺的首选方法。"

### 8.11 关于 Wittig 反应（lines 1599–1633）
> "Wittig 反应是羰基化合物与一种被称为磷叶立德的物种之间的反应。"
> "P=O 键的键能为 575 kJ mol⁻¹，它是化学中最强的双键之一，Wittig 反应也正因此是不可逆的，它是被这根 P=O 键的形成所驱使的。"

### 8.12 关于小结的机理统一性（lines 1635–1643）
> "您应当对写出任何涉及对羰基亲核进攻的反应合理的机理感到自信。"

## 九、竞赛题型线索

### 9.1 产物预测型
- 给定醛/酮 + 醇（或二醇）+ 酸催化 → 预测缩醛/环状缩醛产物。
- 给定醛/酮 + 伯胺 → 预测亚胺产物（注意 E/Z 异构）。
- 给定醛/酮 + 仲胺 → 预测烯胺产物。
- 给定醛/酮 + 磷叶立德 → 预测 Wittig 烯烃产物。

### 9.2 机理书写型
- 书写缩醛形成的完整机理（含锌离子中间体），常考。
- 书写亚胺形成的完整机理（含亚铵离子中间体），常考。
- 书写 Wittig 反应机理（叶立德进攻 → 氧磷丁环 → 烯烃 + Ph₃P=O）。
- 书写还原胺化机理（亚胺形成 + Na(CN)BH₃ 还原亚铵离子）。

### 9.3 保护基策略型
- 设计合成路线：如何在保留酮的同时让 Grignard 试剂反应？→ 用缩醛保护。
- 判断缩醛在不同条件下的稳定性（酸性 vs 碱性）。
- 设计去保护条件（稀酸水解）。

### 9.4 pH 与反应速率型
- 亚胺形成的 pH-速率钟形曲线分析。
- 解释为何亚胺形成在 pH 4-6 最快。
- 解释为何胺的加入可能减缓（而非加速）亚胺形成。

### 9.5 立体化学型
- Wittig 反应中不稳定叶立德 vs 稳定叶立德对 E/Z 选择性的影响。
- 亚胺的 E/Z 异构体（肟的异构体可分离，普通亚胺快速互变）。
- 缩醛形成中的立体化学保持。

### 9.6 合成设计型
- 利用 Strecker 合成法从醛制取 α-氨基酸。
- 利用还原胺化从酮制取仲胺（避免多烷基化问题）。
- 利用 Wittig 反应在特定位置引入双键（位置专一性优于消除法）。
- 利用 LiAlH₄ 还原酰胺为胺。

### 9.7 选择性反应型
- Na(CN)BH₃ 的化学选择性：还原亚铵离子而不还原醛/酮。
- 催化氢化的选择性：还原 C=N 而不还原 C=O。
- 缩醛 vs 半缩醛 vs 非环状缩醛的稳定性差异。

## 十、存疑或待验证之处

1. **亚胺 E/Z 异构体的互变速率**：文中说"通常在室温下就会快速地相互转化"，但具体能垒数据未给出，且不同亚胺差异可能很大。
2. **Wittig 反应的 E/Z 选择性规律**：文中仅简要提及"不稳定叶立德→Z，稳定叶立德→E"，但 Ch27 的详细讨论中可能有更多例外和细节。
3. **稳定叶立德的定义边界**：哪些基团算"稳定"？酯基、氰基、酮基是否都属于？文中未给出系统分类。
4. **氧磷丁环的形成方式**：文中提到 betaine 中间体可直接关环或经 betaine，现代研究认为大多数 Wittig 反应中氧磷丁环是直接形成的（[2+2] 环加成），但书中未明确讨论。
5. **NaBH(OAc)₃ 的选择性机理**：为何它比 Na(CN)BH₃ 更选择性地还原亚铵离子？是否与硼上的配体空间位阻有关？
6. **生物体还原胺化的酶催化细节**：文中提到吡哆胺路线，但未讨论酶如何实现高对映选择性。
7. **Dean Stark 分水器的使用限制**：文中说甲苯共沸蒸水，但对其他溶剂体系（如 DMF、DMSO）是否适用未讨论。
