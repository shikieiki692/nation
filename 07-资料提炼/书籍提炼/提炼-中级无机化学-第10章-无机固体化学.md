# 提炼-中级无机化学-第10章-无机固体化学

## 一、来源信息

- 教材：中级无机化学（项斯芬/姚光庆）第10章「无机固体化学」，正文 L2359-2956，习题 10.1-10.11
- 章节结构：10.1 无限排列固体中的化学键（能带）→ 10.2 固体中的缺陷（分类/扩散/非整比）→ 10.3 重要固体结构（三维/层状/Chevrel/一维/无定形）→ 10.4 功能性质（导电/超导/磁性/发光）→ 10.5 制备方法
- 定位：把 Ch2-4 配合物/分子视角扩展到「无限固体」；与 Ch9 金属原子簇共享 Chevrel 相；是 R4 无机结构线收束章，同时是决赛物理化学「固体物理性质」的化学侧补充

## 二、📐 教学逻辑锚点

**作者讲解顺序**：
1. 键合模型先行：从 H₂/H₃/H₄ → H_n 线性链引出能带（MO 理论的极限），再推广到多轨道/三维
2. 缺陷其次：热力学（G=H-TS）→ 点缺陷（Schottky/Frenkel/色心）→ 扩展缺陷（剪刀面）→ 扩散 → 非整比
3. 结构谱系：三维 → 层状/嵌入 → Chevrel 相（接 Ch9）→ 一维 → 无定形
4. 功能性质：导电（固体电解质）→ 超导 → 磁性 → 发光
5. 制备方法收尾：固相/助熔剂/水热/CVD/溶胶-凝胶

**铺垫与结论时机**：
- **能带是本章"第一性原理时刻"**：n→∞ 时 MO 能级趋近连续 → 能带 → 费米能级 → 导体/半导体/绝缘体三分类。教学保留「H₂→H₃→H₄→H_n」递进，不必从晶格振动讲起
- **缺陷是"功能性质的总开关"**：非整比（FeO/WO₃₋ₓ）→ 半导体；氧空位 → 固体电解质；色心 → 发光材料。以「缺陷决定性质」贯穿 10.2-10.4
- **超导是"前沿兴奋点"**：汞 4.2K → Nb₃Ge 23K → YBa₂Cu₃O₇₋ₓ 95K（突破液氮 77K）→ BCS 理论。历史线本身就是好故事
- **一维固体 Krogmann 盐是"结构-性质联动范本"**：Pt-Pt 348pm 绝缘 → 部分氧化 Pt-Pt 288pm 青铜色导体，一张表（表10.1）讲清电子结构如何被氧化态调控

## 四、知识点提取清单

### 10.1 能带理论（L2359-2460）
1. **能带形成**：n 个原子轨道 → n 个 MO；n→∞ 时能级趋近连续 → 能带。H_n 线性链为最简单一维模型（单轨道→单能带）
2. **引申两点**：①原子有多种价轨道 → 多种能带（如碱金属 s/p 带，能隙大可分离、能隙小可重叠）；②一维→三维
3. **费米能级**：T=0 时最高被占能级；N 原子 N/2 能级被占（半充满带）→ 费米能级接近带中心
4. **态密度 DOS**：每能量单位中的能级数；能带中心最大、边缘最小；带隙内 DOS=0
5. **带隙**：上一能带最高能量与下一能带最低能量之差；MoS₂ 能隙小 → 本征半导体
6. **金属**：最高占据能带未充满；电导随温度升高**降低**（热振动破坏能带结构均匀性）——金属判据
7. **绝缘体**：大带隙（NaCl、金刚石、Si、B₂O₃）；热激发/电场均不能产生净电子流
8. **半导体**：σ = C·e^(−E/kT)（E≈带隙一半）；电导随温度升高**增加**（与金属相反）
9. **掺杂半导体**：n型（As 掺 Si——施主杂质带接近导带，电子热激发导电）；p型（Ga 掺 Si——受主杂质带，满带电子跳入留下正空穴导电）

### 10.2 缺陷与扩散（L2460-2560）
10. **缺陷热力学**：G = H − TS；引入缺陷增 H 也增 TS，存在热力学稳定缺陷浓度平衡点；温度↑→缺陷浓度↑
11. **Schottky 缺陷**（空位）：离子固体等量阴阳离子空位对，保持电中性；TiO 室温空位多 → 实测密度比完美晶体低 >10%
12. **Frenkel 缺陷**（间隙）：原子从正常位移到间隙位；不改变组成与密度（需谱学/电学/XRD 检测）；开放结构且金属离子无配位择优时易形成；纤锌矿 ZnS 有倾向
13. **色心**：碱金属卤化物在碱金属蒸气中加热 → 卤离子空位俘获电子 → 吸收可见光显色；NaCl 在 Na 蒸气中加热 → F 色心紫色
14. **扩展缺陷/剪刀面**：点缺陷聚集 → 一维线缺陷/二维面缺陷；WO₃ 实际组成 WO₃~WO₂.₉，WO₆ 八面体共顶→部分共边（每形成一共边单元减少一 O）；高分辨电镜可观察
15. **扩散**：D = D₀·e^(−E/RT)（Arrhenius）；温度高→缺陷浓度大+跳动能垒易越；固体电解质电导与缺陷移动正相关

### 10.2.3 非化学整比性（L2560-2580）
16. **FeO**：实际 Fe₀.₉₀O~Fe₀.₉₆O（岩盐结构）；阳离子空位 + 部分 Fe(II)→Fe(III) 平衡电荷
17. **WO₃₋ₓ**（2.9<n<3）：非由简单氧空位，而是剪刀面/堆垛缺陷适应氧不足
18. **过渡金属氢化物**：NbH₀.₇、ZrH₁.₆、LuH₂.₂（H 占金属间隙），整比 MH₁/MH₂/MH₃ 几乎未合成

### 10.3 重要固体结构（L2580-2720）
19. **三维离子型**：NaCl/ZnS（立方+六方）/CaF₂/金红石；三元复合氧化物：尖晶石 MgAl₂O₄/钛铁矿 FeTiO₃/钙钛矿 CaTiO₃
20. **金刚石结构** = 立方 ZnS 中 Zn/S 全被 C 取代；四面体共顶三维网络；Si/Ge/GaAs/CdS 同构
21. **层状结构**：层内共价、层间范德华；石墨；MoS₂（Mo 在 S 三棱柱中心，WS₂/MoSe₂ 同）、TiS₂/ZrS₂（M 在 S 八面体中心）
22. **嵌入反应**：物种插入层间形成嵌入化合物（产物通常非整比）；碱金属嵌入石墨转移电子成阳离子；MoX₂ 插层 Na（MS₂+xNa→Na_xMS₂，x=0.4~0.7）与反插层（LiVS₂+½I₂→VS₂+LiI）；金属茂 Co/Cr 可插入、Cp₂Fe 氧化电位高不能；**Li 电池原型**：Li 阳极 + MS₂ 阴极 + 非质子极性溶剂 → >2V
23. **Chevrel 相** [M₆X₈]：Mo₆ 八面体 + 8 个面桥 μ₃-S 组成 [Mo₆S₈] 单元；PbMo₆S₈（Pb 作插入离子）呈 CsCl 型关系；超导 14K 且高临界磁场；KMo₃S₃/KFe₃Te₃ 中 M₆ 八面体共面成一维 Chevrel 相
24. **一维固体**：平面配合物堆垛（[Pt(CN)₄]²⁻ 平面交错 45°）；K₂Pt(CN)₄·3H₂O 白色绝缘（Pt-Pt 348pm）；部分氧化 → K₂Pt(CN)₄Br₀.₃·3H₂O 青铜色导体（Pt 价态 +2.3、Pt-Pt 288pm、电导 4~830 S/cm）；Krogmann 盐；导带由 Pt 5d_z² 轨道重叠形成；<150K 导电锐减
25. **无定形固体**：陶瓷（1000-2000℃ 焙烧；硅酸盐/铁氧体/磨料 Al₂O₃/SiC/B₄C；高温结构陶瓷补强 SiC/Si₃N₄/Al₂O₃）；玻璃（过冷液体；T_f 凝固点→T_g 玻璃化温度；熔融 SiO₂ 高 T_g 难制；软玻璃 Na₂O/CaO 降 T_g；pyrex 硬质玻璃 B₂O₃）

### 10.4 功能性质（L2720-2910）
26. **固体电解质要求**：(i) 大量可移动离子 (ii) 大量空位 (iii) 空位能垒小 (iv) 阴离子骨架有开放通道或柔软可极化
27. **β-氧化铝**：Na₁₊ₓAl₁₁O₁₇₊ₓ/₂，γ-Al₂O₃ 刚层 + Na⁺/O²⁻ 薄层（Na⁺ 易流动）；Na/S 电池候选
28. **NASICON**：Na₃Zr₂PSi₂O₁₂，ZrO₆ 八面体 + PO₄/SiO₄ 四面体共顶框架，Na⁺ 通道网络、仅部分占据
29. **软骨架**：AgI、HgAg₂I₄、RbAg₄I₅（晶格能小，Ag⁺ 易流动）
30. **超导**：T_c 临界温度；Meissner 效应（完全抗磁性）；汞 4.2K（1911 发现）；Nb₃Ge 23K（1986 前最高）；Chevrel 相 ~15K 高 H_c；BaLaCuO 35K（1987 Bednorz/Müller 突破）；**YBCO 1-2-3 相** YBa₂Cu₃O₇₋ₓ（x~0.2）T_c=95K（>液氮 77K）；类钙钛矿层状，Cu 混合价（+2/+3），CuO₅ 四方锥 + CuO₄ 平面四方链；TlBa₂Ca₂Cu₃O₁₀ 122K
31. **BCS 理论**（Bardeen/Cooper/Schrieffer，1972 诺奖）：Cooper 电子对——电子使晶格形变吸引第二电子；电子对不易被散射；低温才能存在
32. **协同磁性**：离子磁矩间相互作用（反铁磁为主）→ 铁磁（磁畴、Curie 温度 T_c 以上转顺磁）/反铁磁（Neel 温度 T_N 反平行）/亚铁磁（两类离子磁矩不同不完全抵消）；磁滞回线：硬铁磁体（永磁）、软铁磁体（变压器磁心）；铁氧体 MFe₂O₄ 反尖晶石（Fe³⁺ 在 Td 位）
33. **发光**：基质+激活剂（Ag⁺/Eu²⁺/Eu³⁺/Ce³⁺/Tb³⁺/Mn²⁺）；ZnS:Ag⁺ 蓝光阴极射线荧光粉（CdS 取代调红/绿）；Sb³⁺→Mn²⁺ 能量传递（卤磷酸盐荧光灯粉）；稀土三基色（Eu²⁺ 蓝 5d-4f 宽带、Eu³⁺ 红 4f-4f 线状谱、Ce³⁺/Tb³⁺ 绿）；BaBrF:Eu²⁺ 光激励存储 X 射线成像

### 10.5 制备方法（L2910-2956）
34. **高温固相反应**：CoO+Fe₂O₃→CoFe₂O₄（1200℃ 多次研磨焙烧）；前驱物法（草酸钴铁共沉淀 → 700℃/3h）；YBCO 共沉淀碳酸盐 + 控氧分压
35. **助熔剂法**：不参与净化学变化、增流动性；Li₂SO₄/Na₂SO₄ 低共熔（LiFe₅O₈ 800℃ 一步，水浸除）；NaOH/NaNH₂ 制 BN；BaF₂ 助熔制 YAG（无需除去）
36. **水热法**：<400℃ 密封反应釜（图10.24）；立方 ZnS（300-500℃ 避免高温相变）；石英单晶（300℃/70bar）；分子筛/γ-Fe₂O₃/CrO₂；气凝胶（超临界除溶剂，孔隙>95%）；溶剂热法（非水溶剂）
37. **CVD/MOCVD**：挥发性前驱物受热沉积；高纯硅（SiHCl₃+H₂→1400K 高纯 Si）；Ⅲ-V 半导体（GaAs/GaN LED，带隙决定发光颜色）；表 10.2 薄膜应用（AlN/Si₃N₄/SnO₂ 气体传感器/TiC 耐磨/TiN 润滑/WO₃ 电色）
38. **溶胶-凝胶法**：温和软化学；醇盐（正硅酸乙酯）水解聚合 → 凝胶 → 干凝胶/气凝胶；可制热力学不稳定多元氧化物 CaO·4SiO₂/CaO·8SiO₂；超细球形粉末/薄膜

## 六、可提取资产清单

- **能带三分类速判**：最高占据带是否充满 + 带隙大小 → 导体/半导体/绝缘体；金属温度依赖「负」、半导体「正」
- **掺杂四步判型**：掺入元素价电子 vs 基质 → 施主（n型）/受主（p型）
- **缺陷两分法**：Schottky（空位对、密度降）/Frenkel（间隙+空位、密度不变）
- **非整比三典型**：FeO（阳离子空位 p型）/WO₃₋ₓ（剪刀面）/金属氢化物（间隙 H）
- **固体电解质判据**：离子多/空位多/能垒小/通道或柔软
- **超导时间线**：汞 4.2K → Nb₃Ge 23K → Chevrel 15K → YBCO 95K → 122K；Meissner 效应 + BCS Cooper 对
- **制备方法对照表**：温度窗口 + 适用产物（固相高温/助熔剂低共熔/水热<400℃/CVD 薄膜/溶胶凝胶软化学）

## 十五、踩坑回流

- 金属导电温度依赖「负」是常考点，学生易按「温度高电子运动快→导电好」误判——本质是热振动破坏能带均匀性
- Frenkel 缺陷不改变组成和密度（原子移到间隙而非消失），不能用密度法检测
- FeO 非整比写作 Fe₀.₉₀O（铁不足）而非 FeO₀.₉₀（氧不足）——阳离子空位 + Fe(III) 补偿
- YBCO「1-2-3」指 Y:Ba:Cu=1:2:3（YBa₂Cu₃），Cu 混合价态（+2/+3）是超导关键，勿写成 CuO₆ 八面体全占位
- 嵌入反应必有电子转移（碱金属成阳离子），且产物通常非整比——与简单物理吸附区分
