## 三、核心内容提炼

### 3.1 Bohr模型与氢原子（铺垫层）

**Bohr模型核心公式：**
- 电子轨道半径：$r = n^2 h^2 \varepsilon_0 / \pi m e^2$，n=1时 $a_0 = 52.92$ pm（Bohr半径）
- 能量公式：$E_n = -13.595 Z^2/n^2$ (eV)
- Rydberg常数：$R_H = 109678$ cm⁻¹

**Bohr模型的局限**：不能处理多电子原子、不涉及波性、不能描述原子的球体结构。但其能量公式形式在量子力学中保留。

### 3.2 氢原子的量子力学处理

**Schrödinger方程**（球极坐标）：

$$\left(-\frac{h^2}{8\pi^2\mu}\nabla^2 - \frac{Ze^2}{4\pi\varepsilon_0 r}\right)\psi = E\psi$$

**变数分离**：$\psi(r,\theta,\phi) = R(r)\cdot\Theta(\theta)\cdot\Phi(\phi)$

解方程自然引出三个量子数n, l, m，边界条件限制其取值。

### 3.3 四个量子数

| 量子数 | 符号 | 取值规则 | 决定的物理量 |
|--------|------|---------|------------|
| 主量子数 | n | 1,2,3,… | 能量 $E_n=-13.6Z^2/n^2$ eV |
| 角量子数 | l | 0,1,2,…,n-1 | 轨道角动量 $\|M\|=\sqrt{l(l+1)}\,h/2\pi$ |
| 磁量子数 | m | 0,±1,…,±l | 角动量z分量 $M_z=mh/2\pi$ |
| 自旋磁量子数 | ms | +1/2, -1/2 | 自旋z分量 $M_{sz}=m_s h/2\pi$ |

**角动量-磁矩关系**：$\mu = -\frac{e}{2m_e}M$，Bohr磁子 $\beta_e = 9.274\times10^{-24}$ J/T。

**自旋磁矩**：$|\mu_s| = g_e\sqrt{s(s+1)}\beta_e$，$g_e=2.00232$。

### 3.4 原子轨道图形

| 图形 | 物理意义 | 竞赛用途 |
|------|---------|---------|
| ψ-r图 | ns态波函数随r的变化 | 节面数=n-1 |
| 径向分布图(r²R²-r) | 球壳层中找到电子的概率 | n-l-1个节点；主峰位置→能级 |
| 等值线图 | ψ在空间截面的等值线 | 理解轨道全貌 |
| 轮廓图 | ψ的正/负等值面 | **最常用**：判断重叠成键 |

**关键规律**：n相同l不同时，l小的轨道钻穿能力强（近核区概率大），能量降低→解释4s<3d。

### 3.5 多电子原子与电子排布

**中心力场法**：引入屏蔽常数σᵢ，$E_i=-13.6(Z-\sigma_i)^2/n^2$ eV

**屏蔽效应vs钻穿效应**：
- 屏蔽：外层电子被内层电子屏蔽→有效核电荷降低→能级升高
- 钻穿：l小的电子钻到近核区概率大→感受到更大核电荷→能级降低
- 两者共同决定：**能级不仅取决于n，还取决于l**

**电子排布三规则**：
1. Pauli原理：每个轨道最多2个电子（自旋相反）
2. 能量最低原理：电子优先填入低能级轨道
3. Hund规则：简并轨道先单占（自旋平行），再配对

**填充顺序**：1s → 2s → 2p → 3s → 3p → **4s → 3d** → 4p → 5s → 4d → 5p → **6s → 4f → 5d** → 6p → 7s → …

**注意不规则排布**：Cr=[Ar]3d⁵4s¹, Cu=[Ar]3d¹⁰4s¹（半满/全满稳定）

### 3.6 元素周期性质

**第一电离能I₁**：
- 同周期主族：大致随Z增加而增大
- 同族：随Z增加而减小
- 极大值：稀有气体；极小值：碱金属
- 特例：B<Be（2p开始填，钻穿效应）、N>O（p³半满稳定）

**电负性**：
- 右上角大，左下角小
- ≈2.0作为金属/非金属近似分界
- 第二周期：Li(1.0)起每增1个Z，电负性约增0.5，至F(4.0)
- 电负性差大→离子键为主；相近→共价键

**相对论效应**（了解）：第六周期6s²惰性电子对效应（Tl⁺/Pb²⁺/Bi³⁺稳定）

### 3.7 原子光谱项（决赛重点）

**光谱项符号**：$^{2S+1}L$

其中L=0,1,2,3,…用S,P,D,F,…表示；2S+1为自旋多重度。

**光谱支项**：$^{2S+1}L_J$

**L-S耦合法**（轻原子Z<40）：
1. 求各电子ml的和→L；求各电子ms的和→S
2. J=|L-S|,|L-S|+1,…,L+S

**np²组态推导示例**：
- $m_L$可取值：2,1,0,-1,-2 → L=0(S),1(P),2(D)
- 光谱项：¹S, ¹D, ³P
- 光谱支项：¹S₀, ¹D₂, ³P₂, ³P₁, ³P₀
- 基态（Hund规则）：³P₀（S最大→L最大→J最小对于半满以下）

**常见原子基态光谱支项**：

| 原子 | 组态 | 基态光谱支项 |
|------|------|------------|
| H | 1s¹ | ²S₁/₂ |
| C | 2p² | ³P₀ |
| N | 2p³ | ⁴S₃/₂ |
| O | 2p⁴ | ³P₂ |
| Ne | 2p⁶ | ¹S₀ |

**选律**（定性了解）：ΔS=0, ΔL=0,±1, ΔJ=0,±1（0↛0除外）

## 五、典型例题与常见错误

### 典型例题

**例1（必做）**：氢原子光谱Balmer系4条谱线→归纳Rydberg公式求R和n₁,n₂
- **要点**：利用比值法消去R，求出n₁=2，n₂=3,4,5,6

**例2（必做）**：给定原子/离子的基态电子组态→写出光谱项和光谱支项
- **要点**：列出所有ml和ms→求L和S→组合得光谱项→用Hund规则定基态J

**例3（竞赛）**：由屏蔽常数σ估算轨道能→解释4s<3d的原因
- **要点**：Slater规则计算σ→$E=-13.6(Z_{eff})^2/n^2$ →比较不同n,l的能级

### 常见错误

| 错误 | 说明 |
|------|------|
| **l的取值范围搞错** | l取0到n-1，不是1到n。l=0对应s轨道，l=1对应p |
| **Hund规则J值选错** | 半满以下J=|L-S|，半满及以上J=L+S。C(2p²)基态是³P₀不是³P₂ |
| **不规则排布记错** | Cr是3d⁵4s¹（不是3d⁴4s²），Cu是3d¹⁰4s¹（不是3d⁹4s²） |
| **电离能反常不理解** | B<Be（2p₁/₂<2s钻穿）；N>O（p³半满稳定，失去一个反而破坏半满） |
| **光谱项多重态数算错** | 2S+1而非2L+1。np²的³P中2S+1=3（S=1），不是5 |
