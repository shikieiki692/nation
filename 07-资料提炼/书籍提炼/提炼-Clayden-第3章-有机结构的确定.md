# Clayden 第3章：有机结构的确定 资料提炼

---

## 一、核心概念与定义

### 1.1 光谱法概述
- **定义**：[[有机波谱分析]]利用电磁辐射（射线/波）与分子的相互作用来确定分子结构的方法。
- **三种主要光谱方法**：

| 射线/波类型 | 光谱法 | 能告诉我们什么 |
|:---|:---|:---|
| X射线被原子散射 | X-射线晶体学（测量散射图案） | 键长和键角（分子形状） |
| 无线电波使原子核共振 | 核磁共振（NMR） | 碳氢骨架的连接和对称性 |
| 红外波使键振动 | [[红外光谱]]（IR） | 分子中的官能团 |

- **[[质谱|质谱法]]**（Mass Spectrometry）：与其他光谱法不同，测量的是质量而非能量吸收。
- **综合解析流程**：质谱（分子量+原子组成）→ ¹³C NMR（碳骨架）→ IR（官能团）→ [[¹H NMR]]（H原子细节）。

### 1.2 质谱法（Mass Spectrometry, MS）
- **原理**：将中性分子转化为带电离子，按质荷比（m/z）分离检测。
- **三个组成部分**：
  1. 汽化并离子化为带电离子束的部分
  2. 按质荷比分离粒子束的部分
  3. 检测离子的部分
- **三种主要离子化方式**：
  - **电子轰击（EI）**：高能电子击离分子中结合较弱的电子 → 产生自由基阳离子（radical cations）。问题：碎片化严重。
  - **化学电离（CI）**：将气体（如NH₃）与底物混合，通过质子转移得到M+1或M+18。
  - **电喷雾（ES）**：底物以气溶胶形态离子化，通常观察到M+1和M+23（Na⁺加合物），阴离子为M-1。

### 1.3 核磁共振法（NMR）
- **原理**：某些原子核（如¹H、¹³C）具有自旋（spin），在磁场中取向不同能级。用无线电波频率的电磁辐射将原子核从低能态翻转到高能态，检测弛豫释放的能量。
- **核自旋量子数 I**：能级数目 = 2I+1。¹H: I=1/2（2个能级）；¹²C: I=0（无NMR信号）；¹³C: I=1/2（2个能级）。
- **屏蔽与去屏蔽**：原子核周围电子在磁场中产生感应磁场，与外加磁场方向相反 → 屏蔽（shielding）。电子密度高 → 屏蔽强 → 化学位移小（高场区）。电子密度低 → 去屏蔽（deshielded）→ 化学位移大（低场区）。
- **化学位移 δ（ppm）**：

$$
\delta = \frac{\text{频率(Hz)} - \text{TMS的频率(Hz)}}{\text{TMS的频率(MHz)}}
$$

- **标准样品**：四甲基硅烷（TMS, Si(CH₃)₄），δ = 0 ppm。硅比碳更正电性 → 四个甲基碳富电子 → 共振频率低于大多数有机物。

### 1.4 ¹³C NMR 光谱
- **四大区域**：
  - **饱和碳原子**：0–50 ppm
  - **连氧的饱和碳原子**：50–100 ppm
  - **不饱和碳原子（C=C, 芳碳）**：100–150 ppm
  - **连氧的不饱和碳原子（C=O）**：150–200+ ppm
- **注意**：¹³C NMR中信号强度通常无意义（由光谱记录方式决定）。
- **对称性影响**：等价碳原子给出同一个信号（如己二酸6个碳只有3个峰）。

### 1.5 ¹H NMR 光谱
- **刻度范围**：仅约 0–10 ppm（远小于¹³C的0–200 ppm），因为氢原子核旁仅有2个电子，可能的分布变化比碳的8个电子少得多。
- **两大区域**：
  - **与饱和碳成键的H**：0–5 ppm（屏蔽较强）
  - **与不饱和碳成键的H（烯烃、芳烃、羰基）**：5–10 ppm（屏蔽较弱）
  - 氧原子的吸电子效应使信号向低场移动（δ增大）。
- **重要特征**：
  - 信号数目 = 不等价H原子的种类数
  - 与O或N相连的质子在¹H NMR中通常不可见（交换过快）
  - 峰面积比 = 各类H原子的数目比
  - 化学位移可区分H所处的化学环境

### 1.6 红外光谱法（IR）
- **原理**：检测化学键的伸缩（stretch）和弯曲（bend）振动。所需能量对应红外区波长。
- **胡克定律**：

$$
\nu = \frac{1}{2\pi c}\sqrt{\frac{f}{\mu}}
$$

其中 ν 为频率，f 为力常数（键强度），μ 为约化质量。**键越强、原子越轻，振动频率越高。**

- **约化质量**：μ = m₁m₂/(m₁+m₂)。H的加入使约化质量大幅降低 → X-H键频率远高于其他键。

- **四大区域**：

| 区域 | 波数范围 (cm⁻¹) | 归属 |
|:---|:---|:---|
| X-H 伸缩区 | 4000–2500 | C-H, N-H, O-H 伸缩 |
| 三键区 | 2500–2000 | C≡C, C≡N 伸缩 |
| 双键区 | 2000–1500 | C=O, C=C, NO₂ 伸缩 |
| 单键区（指纹区）| < 1500 | C-C, C-N, C-O 等；分子指纹特征 |

- **吸收强度取决于偶极矩变化**：偶极矩变化大 → 吸收强。C=O伸缩通常是IR中最强的峰。
- **吸收宽度取决于氢键**：强氢键 → 宽峰（如羧酸的O-H）。

## 二、重要反应与机理（波谱解析方法论）

### 2.1 结构确定的一般策略
1. **质谱**：确定分子量和原子组成（高分辨率质谱可精确到五位小数）。
2. **¹³C NMR**：确定碳骨架——信号数目（对称性）、化学位移区域（碳的类型）。
3. **IR**：确定官能团——OH、C=O、NH₂、NO₂、C≡N等的特征吸收。
4. **¹H NMR**：确定氢原子的种类、数目和化学环境——最终区分结构异构体。

### 2.2 综合解析实例：工业乳化剂
- **分子式**：C₄H₁₁NO（高分辨质谱确定，M+H=90，奇数分子量→含奇数个N）
- **¹³C NMR**：3个峰 → 有2个等价碳；一个连氧饱和碳，两个普通饱和碳。
- **IR**：宽峰OH + 两个锐利NH₂峰 → 含C-OH和C-NH₂。
- **¹H NMR**：仅2个峰（δ 3.3和1.1 ppm）→ δ 3.3处的信号被去屏蔽 → 与氧相邻的H。
- **结论**：2-氨基-2-甲基-1-丙醇（结构A，非结构B）。

### 2.3 综合解析实例：反应产物鉴定
- **情境**：丙烯醛 + HBr + 乙二醇 → 无色液体混合物X
- **质谱**：M=181, 179（两个分子离子，典型溴代物）→ HBr加成。
- **高分辨质谱**：C₅H₉BrO₂，1个DBE。
- **¹³C NMR**：丙烯醛的C=O和C=C消失；产物有4个信号（5个碳，1个等价）→ 一个C-O-C-O-C片段。
- **IR**：无OH、无C=O、无C=C → 醚键。在1128 cm⁻¹处找到C-O伸缩。
- **结论**：乙二醇与丙烯醛的缩醛产物（含环状缩醛）。

## 三、关键结论与规则

### 3.1 质谱关键规则

#### 氮规则（Nitrogen Rule）
> 对于仅含C, H, N, O, S的分子：分子量为奇数 → 含奇数个N原子；分子量为偶数 → 含偶数个N或无N。

#### 同位素峰识别
| 元素 | 同位素 | 近似比例 | 质谱特征 |
|:---|:---|:---|:---|
| 碳 | ¹²C, ¹³C | 98.9:1.1 | M+1峰高度 = 1.1% × 碳原子数 |
| 氯 | ³⁵Cl, ³⁷Cl | 3:1 | M与M+2峰比3:1 |
| 溴 | ⁷⁹Br, ⁸¹Br | 1:1 | M与M+2峰等高 |

- **多卤素**：2个Cl → M:M+2:M+4 = 9:6:1；2个Br → M:M+2:M+4 = 1:2:1。

#### 高分辨率质谱
- 通过精确分子量（五位小数）确定原子组成。例如MW≈114的化合物：
  - C₆H₁₀O₂: 114.06808
  - C₆H₁₄N₂: 114.11569
  - **C₇H₁₄O: 114.10446** ← 与观察值114.1039匹配（误差仅5 ppm）
  - C₈H₁₈: 114.14084

### 3.2 ¹³C NMR 化学位移速查表

| 碳的类型 | δ 范围 (ppm) | 屏蔽程度 |
|:---|:---|:---|
| 饱和C（R-CH₃, R-CH₂-R等）| 0–50 | 强屏蔽（高场） |
| 连氧饱和C（C-O）| 50–100 | 中等去屏蔽 |
| 不饱和C（C=C, 芳碳）| 100–150 | 弱屏蔽 |
| 羰基C（C=O）| 150–220 | 强去屏蔽（低场） |
| 简单酮C=O | ~206–210 | 最低场 |
| 酯/酸/酰胺C=O | ~165–175 | 较低场 |

**注意**：与氧相连的不饱和碳（如芳碳-OC）可出现在150 ppm附近，接近C=O区域，但不是羰基碳。

### 3.3 ¹H NMR 化学位移速查表

| H的类型 | δ 范围 (ppm) | 说明 |
|:---|:---|:---|
| R-CH₃（烷基甲基）| 0.8–1.0 | 最高场 |
| R-CH₂-R | 1.2–1.4 | |
| 烯丙位H（C=C-CH）| 1.6–2.2 | |
| 与O相连的C上的H（C-O-H）| 3.3–4.0 | 被去屏蔽 |
| 与N相连的C上的H（C-N-H）| 2.2–3.0 | |
| 烯烃H（C=C-H）| 4.5–6.5 | 不饱和区 |
| 芳烃H（Ar-H）| 6.5–8.0 | |
| 醛基H（CHO）| 9–10 | |
| 羧酸H（CO₂H）| 10–12 | |
| O-H, N-H | 变化大 | 通常不可见（交换快） |

### 3.4 IR 特征频率速查表

#### X-H 伸缩区（4000–2500 cm⁻¹）

| 键 | 约化质量 μ | IR频率 (cm⁻¹) | 键强度 (kJ/mol) | 峰形特征 |
|:---|:---|:---|:---|:---|
| C-H | 0.92 | 2900–3200 | 440 | 锐利 |
| N-H | 0.93 | 3300–3400 | 450 | 锐利（单峰或双峰）|
| O-H（无氢键）| 0.94 | 3500–3600 | 500 | 锐利 |
| O-H（有氢键）| — | 2900–3500 | — | **宽峰**（醇~3300，羧酸V型宽峰）|
| 末端炔C-H（sp）| — | ~3300 | — | 锐利强峰（sp轨道→键更强）|

**NH₂的双峰**：对称伸缩（较低频）+ 反对称伸缩（较高频）。

#### 三键区（2500–2000 cm⁻¹）

| 官能团 | 频率 (cm⁻¹) | 说明 |
|:---|:---|:---|
| C≡N（腈）| ~2250 | 中等强度 |
| C≡C（炔烃）| ~2100 | 弱到中等 |

**此区域通常为空白**——看到此区域有峰即可确定含三键。

#### 双键区（2000–1500 cm⁻¹）——最重要的区域

| 官能团 | 频率 (cm⁻¹) | 强度 | 说明 |
|:---|:---|:---|:---|
| C=O（羰基）| 1650–1900 | **强** | IR中最强的峰之一 |
| C=C（烯烃）| ~1640 | 弱 | 对称烯烃可能无吸收 |
| NO₂（反对称伸缩）| >1500 | 强 | |
| NO₂（对称伸缩）| ~1300 | 强 | |
| 芳环C=C | 1500–1600 | 中等 | 通常2-3个峰 |

**NO₂给出两个峰的原因**：与NH₂类似，存在对称和反对称伸缩振动。

#### 单键区/指纹区（< 1500 cm⁻¹）
- C-O伸缩：~1100 cm⁻¹（强，因为C-O极性大）
- CH₂弯曲：1440–1470 cm⁻¹
- CH₃弯曲：~1380 cm⁻¹
- NH₂弯曲：1550–1650 cm⁻¹
- C-D伸缩：~700 cm⁻¹

### 3.5 双键等价物（DBE）计算

$$
\text{DBE} = \frac{(2n + 2) - H + N}{2}
$$

其中 n = 碳原子数，H = 氢原子数，N = 氮原子数。氧和硫不影响计算。

| DBE值 | 含义 |
|:---|:---|
| 1 | 一个环或一根双键 |
| 2 | 两个双键/一个三键/一个环+一个双键等 |
| 4 | **苯环**（3个双键+1个环）|
| ≥4 且 H很少 | 怀疑含芳环 |

**快速判断**：H原子数 << C原子数 → 高DBE → 可能含芳环。

### 3.6 X-射线晶体学的局限性
- 需要样品为晶体（液体或非晶态固体不行）。
- 不能"看到"H原子（太轻，不衍射X射线）。
- 不能区分原子序数相近的原子（如O和N）——diazonamide A的结构误判即为著名案例。

## 八、摘录的原始段落（附页码/位置标记）

### 8.1 光谱法的意义（lines 2297–2299）
> "您如果认为现代有机化学最重要的进步是能够快速地，精准地确定分子的结构的话，那么您非常正确。一言以蔽之：光谱法赋予了我们这个能力。"

### 8.2 质谱法的本质（lines 2367–2369）
> "质谱法与其他形式的光谱法不同，这是由于它测量的是质量而不是能量的吸收。"
> "NMR不会真的将分子断裂为碎片，但它将分子视作了连接在一起的碳氢碎片。"

### 8.3 自由基阳离子（lines 2407–2411）
> "大多数分子中的电子都是全部成对的，而自由基包含未成对电子。带有负电荷的分子是阴离子，带有正电荷的分子是阳离子。自由基阳离子和自由基阴离子仅仅表示的是既带电荷，又包含未成对电子的物种。"

### 8.4 氮规则（lines 2486–2488）
> "分子量为奇数的分子必定含有奇数个数的氮原子。分子量为偶数的分子必定含有偶数个数的氮原子，或不含氮原子。"

### 8.5 屏蔽与化学位移（lines 2559–2578）
> "每个原子核都被电子环绕，在磁场中，它们都会产生微小的电流。这些电流会产生它们自己的磁场——感应磁场，这些磁场会与我们施加的磁场方向相反。我们称这些电子在外加磁场中屏蔽了原子核。如果一个¹³C原子和另一个¹³C原子的电子分布不同，那么它们的原子核感受到的局部磁场也是不同的，因此对应的共振频率就也不同了。"

### 8.6 化学位移的描述（lines 2631–2637）
> "化学位移的刻度由零（TMS共振的位置）向左发展，和通常的横坐标取法是相反的。我们建议您用'大的'或'小的'描述化学位移δ，用'高的'或'低的'描述磁场以避免混淆。"

### 8.7 IR吸收强度（lines 2892–2896）
> "当键伸缩时，IR吸收的强度随偶极矩的变化而变化。如果键完美地对称，那么偶极矩便不会有变化，因而也就没有IR吸收。C=O伸缩通常是IR光谱中最强的峰。"

### 8.8 DBE计算（lines 2958–2962）
> "每形成一个环，或一根双键，分子都需要失去两个氢原子。因此（任何种类的）双键和环被称为双键等价物。"

### 8.9 光谱法的综合运用（lines 3070–3072）
> "认识到结构被指派，不是因为一些理论性原因或者说因为反应'应该'给出某种特定产物而给出的，它们是通过光谱上的证据被指派的。"

## 九、竞赛题型线索

### 9.1 分子式确定型
- 给定高分辨质谱数据（精确分子量），确定分子式。
- 利用氮规则判断是否含氮及氮原子数。
- 利用同位素峰（M:M+2）判断是否含Cl/Br及数目。
- 计算DBE，推断不饱和度和可能的结构类型。

### 9.2 结构推断型（综合波谱解析）
- **经典题型**：给出分子式 + ¹³C NMR峰数和化学位移 + IR特征峰 + ¹H NMR信息 → 推断结构。
- **关键步骤**：
  1. 由分子式计算DBE → 判断环/双键/三键数目
  2. 由¹³C NMR信号数判断对称性 → 等价碳的数目
  3. 由¹³C化学位移区域判断碳的类型
  4. 由IR判断官能团（OH? C=O? NH₂? NO₂?）
  5. 由¹H NMR判断H的种类、数目和化学环境
  6. 组合所有信息，排除不合理结构

### 9.3 同位素峰分析型
- 由M+2峰的相对高度判断含卤素种类和数目。
- 由M+1峰高度估算碳原子数。
- 二氯取代物的9:6:1三峰模式。
- 二溴取代物的1:2:1三峰模式。

### 9.4 化学位移归属型
- 判断¹³C NMR中各峰属于哪种类型的碳。
- 判断¹H NMR中各峰对应哪种化学环境的H。
- 利用对称性解释信号数目少于原子数目的现象。

### 9.5 官能团识别型
- 由IR特征频率判断官能团（C=O在~1700，OH在3300宽峰，NH₂在3300双峰等）。
- 区分醇OH（宽峰~3300）和羧酸OH（V型宽峰~2500-3300）。
- 末端炔C-H在~3300的锐利峰易与N-H混淆。

### 9.6 反应产物鉴定型
- 给定反应条件和起始原料 → 通过MS确定产物分子量变化 → NMR和IR确定产物结构。
- 注意：产物分子量 - 起始原料分子量 = 加成/脱除的基团。

## 十、存疑或待验证之处

1. **¹³C NMR信号强度**：文中说"信号强度通常无关紧要"，这是因为¹³C NMR通常不做定量积分（与¹H NMR不同）。实际原因是弛豫时间差异和NOE效应，竞赛中如遇定量¹³C需注意。
2. **与O/N相连的H在¹H NMR中"不可见"**：文中说"看不到连在O或N上的质子是很正常的"，原因是化学交换（exchange）过快导致峰变宽消失。在极纯样品或低温下可能可见，竞赛中需注意例外。
3. **化学位移边界的武断性**：文中承认50 ppm作为饱和C和连氧饱和C的分界是"武断的"，实际中有些碳的化学位移可能处于边界附近（如环氧化合物的碳在~48-50 ppm）。
4. **高分辨质谱的ppm误差**：文中给出的例子中，C₇H₁₄O的误差为5 ppm，而其他组合的误差达100+ ppm。竞赛中若给出精确分子量，应直接查表或计算对比。
5. **IR中"峰"与"谷"的术语混用**：IR谱图的纵坐标为透过率（transmission），吸收最大值在谱图上表现为"谷"，但化学家习惯称其为"峰（peaks）"——这是一种约定俗成的混用。
6. **末端炔C-H的特殊频率**：文中解释为sp轨道含更多s成分→键更强→频率更高。但仅凭约化质量无法解释（C-H和C-D的差异才是约化质量主导的典型例子）。
7. **BHT的对称面**：文中提到BHT有一个垂直于苯平面的对称面，使得15个碳只给出7个信号。需注意这种对称性分析是解决NMR题目的关键步骤。
