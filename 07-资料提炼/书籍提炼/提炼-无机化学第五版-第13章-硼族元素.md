## 三、教学逻辑锚点

> 与 Zchem 第二轮深化「主族元素的结构化学I」一致：**B 的结构化学 → Al 的两性与工业化学 → 重元素惰性电子对递进**，不平均铺开。

- **主线**：缺电子化学贯穿全章——B₁₂ 单元、硼烷 3c-2e、硼酸缺电子成酸、BX₃ 大π键、AlCl₃ 二聚，是理解全章的钥匙。
- **铺垫顺序**：单质（结构决定硬度/惰性）→ 氢化物（缺电子键型）→ 含氧化合物（亲氧性/酸根结构）→ 卤化物（Lewis 酸）→ 金属性递变（Tl 惰性电子对收尾）。
- **结论出现时机**：「硼是唯一非金属、亲氧元素」出现在章首，为后续 B₂O₃/硼酸/硼砂的稳定性做铺垫；「Tl⁺ 最常见」在章末，呼应惰性电子对效应并连接 Ch14(碳族)/Ch17(卤素) 的重元素。
- **竞赛抓手**：B₂H₆ 三中心二电子键、硼酸一元弱酸（加多元醇酸性增强）、BF₃ vs AlCl₃ 聚合差异、Tl(Ⅲ) 强氧化性——均为高频考点。

## 四、核心内容提炼

### 4.1 硼单质及其化合物

#### (1) 硼单质
- **结构**：基本结构单元 **B₁₂ 正二十面体**（12 个 B 占顶点），最常见晶型 **α-菱形硼**；B₁₂ 单元间以三中心二电子键连接 → 硬度接近金刚石、导电差但电导率随温度升高而增大。
- **化学性质**：常温只与 F₂ 化合；燃烧生成 B₂O₃（B—O 键能极大 → **亲氧元素**）；赤热与水蒸气 → H₃BO₃+H₂；高温与 N₂/S/X₂ 反应（生成 BN、B₂S₃、BCl₃）；与金属生成硼化物（LiB₄、CaB₆、AlB₁₂ 等，高硬度高熔点）；不与非氧化性酸作用，但溶于热浓硝酸/浓硫酸；抗沸腾 NaOH，但强氧化剂存在下共熔得偏硼酸盐。
- **制取**：硼砂 + H₂SO₄ → H₃BO₃ → 脱水 B₂O₃ → Mg 还原得粗硼（95-98%）；H₂ 还原 BBr₃（钽丝）；**BI₃ 在灼热钽丝上分解得 99.95% α-菱形硼**。

```
2B + 3F₂ = 2BF₃ ； 4B + 3O₂ ==燃烧== 2B₂O₃
2B + N₂ ==高温== 2BN ； B + 3HNO₃(浓) ==△== H₃BO₃ + 3NO₂↑
Na₂B₄O₇ + H₂SO₄ + 5H₂O = 4H₃BO₃ + Na₂SO₄
B₂O₃ + 3Mg ==高温== 2B + 3MgO
2BI₃ ==Ta,727℃== 2B + 3I₂
```

#### (2) 硼氢化合物（硼烷）
- **乙硼烷 B₂H₆**（最简单的硼烷，非 BH₃）：缺电子化合物（12 个价电子 < 烷烃所需的 14 个）。
- **制备**：① Mg₃B₂ + H₃PO₄ → 硼烷混合物 → B₂H₆；② BCl₃ + H₂ 无声放电；③ **3LiAlH₄ + 4BCl₃（乙醚中）→ 2B₂H₆**（不能有水）。
- **性质**：还原性极强，空气中自燃（ΔrH = -2167.3 kJ/mol）；被 Cl₂ 氧化；**极易水解** B₂H₆+6H₂O→2H₃BO₃+6H₂；与 CH₃OH → B(OCH₃)₃；剧毒。
- **结构**：B₂H₆ 中 6 个 H 有两种环境——4 个端位（正常 B—H σ 键，BH₂ 平面）+ 2 个桥位（**三中心二电子键 3c-2e / 氢桥键**）。每个 B sp³ 杂化（3 条单电子轨道 + 1 条空轨道），桥 H 的 1s 与两侧 B 轨道重叠成键，两平面互相垂直。
- **B₁₀H₁₄（癸硼烷-14）** 含 5 种键型：B—H、B—B（经典 2c-2e）+ 氢桥键、开式硼桥键、闭式硼桥键（3c-2e）；骨架为**缺两个相邻顶点的正二十面体**（开口笼形）。
- **BN / 无机苯**：
  - B₂H₆ + NH₃（873K）→ 六方氮化硼 BN（"白石墨"，石墨等电子体，层状，绝缘体）；高压高温 → 立方 BN（类金刚石硬度）。
  - B₂H₆ + NH₃（180℃）→ **硼氮六环 B₃N₃H₆（"无机苯"）**，与苯等电子体，平面六边形。
- **硼氢化钠 NaBH₄**：4NaH + B(OCH₃)₃ ==油液,250℃== NaBH₄ + 3NaOCH₃；白色离子型化合物，重要还原剂；LiBH₄ 与水激烈反应 LiBH₄+2H₂O→LiBO₂+4H₂。

#### (3) 硼的含氧化合物
- **B₂O₃**：硼酸酐，难结晶（玻璃态）；溶于水 → H₃BO₃（可作吸水剂）；水汽不足时 → 挥发性偏硼酸 B₃O₃(OH)₃（简记 HBO₂）；酸性氧化物，与金属氧化物共熔成**偏硼酸盐熔珠**（硼砂珠实验：Cu²⁺蓝、Fe³⁺黄、MnO 紫、NiO 绿）。
- **硼酸 H₃BO₃ / B(OH)₃**：
  - 结构：B sp² 杂化平面三角形，单元间靠**氢键**连成层状（可作润滑剂）。
  - **一元弱酸本质**（竞赛核心）：B 有空 p 轨道，接受 OH⁻ 孤对 → [B(OH)₄]⁻（sp³ 正四面体），破坏水的解离 → 显酸性。Ka° = 5.81×10⁻¹⁰。
  - **加多元醇（乙二醇/甘油）酸性增强**：生成稳定硼酸酯，平衡右移（Ka 增大上万倍）——鉴定硼酸的方法之一。
  - 遇强酸显碱性：B(OH)₃ + H₃PO₄ = BPO₄ + 3H₂O。
  - 与乙醇浓硫酸酯化 → 硼酸三乙酯，**点燃绿色火焰**（鉴定硼酸）。
- **硼砂 Na₂[B₄O₅(OH)₄]·8H₂O**（常写作 Na₂B₄O₇·10H₂O）：
  - 酸根 [B₄O₅(OH)₄]²⁻ 由 2 个 BO₃ + 2 个 BO₄ 单元共用顶角氧连接。
  - 水解生成等物质的量 H₃BO₃ 和 [B(OH)₄]⁻ → **缓冲溶液，pH=9.24**。
  - 受热 400℃ 失水成 Na₂B₄O₇；用于焊接除锈、玻璃纤维原料。
- **过硼酸钠 Na₂[B₂(O₂)₂(OH)₄]**：洗衣粉增白剂，含 -O-O- 过氧链（与 Ch21 CrO₅ 过氧链呼应）。
- 硼酸盐均由 **BO₃ 三角形 + BO₄ 四面体**两种基本单元连接而成（环三聚 KBO₂、四聚偏硼酸根等）。

#### (4) 硼的卤化物
- **BX₃**：sp² 三角形；B 缺电子，X 的 p 轨道与 B 空 p 轨道形成**大π键 Π₄⁶**（解释 B—F 键长比半径和小）。
- **Lewis 酸性次序反常**：BI₃ > BBr₃ > BCl₃ > BF₃（一般），原因是大π键形成难度（F 的 2p 与 B 2p 重叠好，破坏难）；**但**对弱碱（如 CO）时为 BF₃ > BCl₃ > BBr₃ > BI₃。→ **Lewis 酸性顺序随碱而变**。
- BF₃ + NH₃ = H₃N→BF₃；BF₃ 水解 → H₃BO₃ + HF，再 +BF₃ → H[BF₄]（氟硼酸盐稳定）；BCl₃ 强烈水解 → H₃BO₃ + HCl。
- B₂Cl₄ 存在平面（固）与非平面（气/液）两种构象。

### 4.2 铝单质及其化合物

#### (1) 铝的提取冶炼（拜耳法 + 电解）
- 铝土矿 Al₂O₃·nH₂O 碱浸（加压煮沸）→ Na[Al(OH)₄] → 通 CO₂ 沉 Al(OH)₃ → 焙烧得纯 Al₂O₃ → **熔融冰晶石 Na₃[AlF₆] 中 950℃ 电解**。
- 电解铝纯度 98-99%，杂质 Si/Fe/Ga。

#### (2) 铝单质性质
- E°(Al³⁺/Al) = -1.676 V（活泼），但**表面致密氧化膜钝化**（耐冷浓硝酸/浓硫酸；NaCl 缓慢腐蚀氧化膜）。
- **铝热反应**：2Al + Fe₂O₃ ==镁条引燃== 2Fe + Al₂O₃（>3000℃，焊接铁轨）；可还原 Cr₂O₃ 等稳定氧化物。
- **两性**：与 HCl → AlCl₃+H₂；与 NaOH → Na[Al(OH)₄]+H₂。
- 高温与 S 反应；不与 H₂ 直接化合；(AlH₃)ₙ 白色聚合物（乙醚中 LiH+AlCl₃ 制得）；LiH 过量 → **LiAlH₄**（重要还原剂）。

#### (3) 铝的含氧化合物
- **Al₂O₃ 两晶型**：α-Al₂O₃（刚玉，硬度仅次于金刚石，不溶于酸/碱；含过渡金属杂质 → 宝石）；γ-Al₂O₃（化学活泼，两性，溶于酸碱；受强热转 α）。
- **Al(OH)₃ 两性**：溶于强酸/强碱（AlCl₃ 或 Na[Al(OH)₄]）；**不溶于过量氨水**（鉴别要点）；铝酸钠脱水产物 NaAlO₂（偏铝酸钠）。

#### (4) 铝的三卤化物
- AlF₃ 离子型；AlCl₃/AlBr₃/AlI₃ 共价型，**气相二聚**。
- **AlCl₃ 二聚（3c-4e 氯桥键）**：Al sp³ 杂化有 1 条空轨道，桥 Cl 提供 3 个电子（1 单电子 + 1 孤对）→ 三中心四电子键。原因：Al、Cl 半径大，不能像 BF₃ 形成大π键 → 通过二聚解决缺电子。
- 遇 Lewis 碱二聚体解离，单分子作 Lewis 酸；**强烈水解，水溶液不能结晶无水盐**（无水 AlCl₃ 用 Cl₂ 氧化金属 Al 高温制备）；易溶于乙醚等有机溶剂。

#### (5) 铍和铝的相似性（对角线规则 Be—Al）
- 单质：均易钝化（冷浓硝酸）；均两性金属（溶于强碱放 H₂）。
- 卤化物：BeCl₂、AlCl₃ 均共价、易升华、气态桥连二聚（BeCl₂ 二聚 Be 为 sp² 三角形；AlCl₃ 二聚 Al 为 sp³ 四面体）；水合卤化物加热均水解（BeCl₂·4H₂O→Be(OH)Cl；AlCl₃·6H₂O→Al(OH)₂Cl）。
- 氢氧化物：Be(OH)₂、Al(OH)₃ 均难溶、均两性；其他碱土金属氢氧化物不溶于强碱。

### 4.3 镓、铟、铊

#### (1) 单质
- 稀有分散元素，多共生于 Zn/Ge/Al 矿或闪锌矿；**镓熔点 29.76℃**（掌心熔化，沸点 2229℃，熔沸点差最大 → 高温温度计）。
- 与稀酸/非氧化性酸反应：Ga/In → +3，Tl → **+1**（Tl + 稀 H₂SO₄ → Tl₂SO₄+H₂）；浓硝酸中 Tl 也只到 +1。
- Ga 有两性（溶强碱放 H₂，类 Al）；In、Tl 金属性强无此反应。
- 门捷列夫预言"类铝"镓的故事（密度预测 5.9-6.0 验证 5.91）。

#### (2) 化合物
- M(OH)₃ 稳定性 Ga>In>Tl，Tl(OH)₃ 几乎不能存在（TlCl₃+强碱直接得 Tl₂O₃）。
- **Ga(OH)₃ 酸性比 Al(OH)₃ 强**（第四周期反常）：Ga(OH)₃ 可溶弱碱氨水，Al(OH)₃ 不溶 → 鉴别。
- **惰性电子对效应（Tl 核心）**：Tl 电子构型 [Xe]4f¹⁴5d¹⁰6s²6p¹，6s² 难失去 → Tl(I) 最常见；Tl(Ⅲ) 强氧化性（E°(Tl³⁺/Tl⁺)=1.252 V），可氧化 Fe²⁺、SO₂、KI（Tl(NO₃)₃+3KI→3KNO₃+TlI↓+I₂↓）。
- TlBr₃/TlI₃ 难存在（Tl(Ⅲ) 强氧化性氧化 Br⁻/I⁻）；TlCl₃ 受热分解 TlCl+Cl₂。
- TlCl 溶解度小（溶于 H₂SO₄ 生成 TlHSO₄），Tl₂S 蓝黑色沉淀；卤化铊见光分解。
- Tl(I)→Tl(Ⅲ) 可被 Cl₂/H₂O₂ 氧化（3TlNO₃+3Cl₂→Tl(NO₃)₃+2TlCl₃）。
- Ga(I)/In(I) 还原性很强，极少见。
- M(OH)₃ Ksp 数量级 10⁻⁴⁴~10⁻³⁴（比 Al(OH)₃ 还难溶）。

## 七、教材例题与常见错误

### 精选例题
1. **硼酸加甘油酸性增强**（习题13-6(4)）：解释 [B(OH)₄]⁻ 与多元醇成稳定酯 → 平衡右移 c(H⁺)↑，pH 6→5。→ 考查硼酸缺电子 Lewis 酸本质。
2. **BF₃ 单聚 vs AlCl₃ 二聚**（习题13-8(9)）：BF₃ 靠大π键 Π₄⁶ 补足八隅体；AlCl₃ 半径大不能成 π 键 → 3c-4e 氯桥二聚。
3. **AlCl₃ 溶于苯 vs 乙醚**（习题13-8(13)）：苯中保持 (AlCl₃)₂；乙醚中解离成单分子与 O(C₂H₅)₂ 配位 → 产物 AlCl₃·O(C₂H₅)₂（含一个 Al 原子）。
4. **Tl(NO₃)₃ + KI → TlI↓ + I₂↓**：Tl(Ⅲ) 强氧化性将 I⁻ 氧化，同时 Tl⁺ 与 I⁻ 沉淀——双考查。

### 常见错误
| 错误认知 | 正确结论 |
|:--|:--|
| BX₃ 路易斯酸性 BF₃ 最强 | 一般次序 BI₃>BBr₃>BCl₃>BF₃；随碱改变 |
| 硼酸是一元酸，因含 3 个 OH | 一元酸的本质是缺电子接受 OH⁻（Lewis 酸） |
| Al(OH)₃ 溶于过量氨水 | 不溶；Al(OH)₃ 只溶强酸强碱 |
| Tl 金属活泼 → Tl(Ⅲ) 常见 | 惰性电子对 → Tl(I) 常见，Tl(Ⅲ) 强氧化剂 |
| GaCl₂ 有 +2 价 | 实际 Ga[GaCl₄]（Ga⁺ 与 Ga³⁺，抗磁性）——习题13-8(14) |
