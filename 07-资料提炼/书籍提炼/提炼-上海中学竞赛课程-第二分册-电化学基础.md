# 提炼-上海中学竞赛课程-第二分册-电化学基础

> 来源：上海中学竞赛课程·化学·第2分册·第八讲 电化学基础（原书约 1470 行，行52-1518）
> 提炼日期：2026-09-16

---

## 内容概要

本讲从氧化还原的电子转移出发，建立电化学的两条主线：一是以「电极电势」衡量物质氧化还原能力的相对强弱，二是用热力学量把电极电势与平衡常数打通。先讨论原电池的组成（两个半电池、盐桥、外电路）、四类常用电极与电池符号的书写规范；再由双电层理论引入电极电势，定义标准氢电极并介绍甘汞、银-氯化银、玻璃三类参比电极；随后系统给出能斯特方程，及其在浓度、酸碱性、生成难溶物、生成弱电解质、生成配合物五种情形下对电极电势的影响；最后讨论电极电势的四类应用（$\Delta_rG_m$ 与 $E$、$K^\theta$ 与 $E^\theta$、判断方向与程度、由 $E^\theta$ 反求 $K_{sp}$ 与 $K_{稳}$），并介绍元素电势图与 $\varphi$-pH 图。

## 核心知识点

### 1. 原电池与电对

- 原电池：利用自发氧化还原反应将化学能转变为电能的装置；电解池则相反
- 组成：两个半电池（电极）＋盐桥＋外电路导线＋检流计
- 盐桥（U 型管内琼脂固定的饱和 KCl）：沟通电流通路、保持电荷平衡、**消除液接电位**；亦可用多孔隔膜代替
- 电对书写：氧化型在左、还原型在右，短斜线分隔，如 $Cu^{2+}/Cu$、$Zn^{2+}/Zn$
- 铜锌原电池（丹尼尔电池）：$E = \varphi(Cu^{2+}/Cu) - \varphi(Zn^{2+}/Zn) = 1.10\ \mathrm{V}$

### 2. 四类常用电极

| 类型 | 通式 | 举例 | 电极反应 |
|:---|:---|:---|:---|
| 金属-金属离子电极 | $M \mid M^{n+}$ | $Zn \mid Zn^{2+}$ | $M^{n+} + ne^- \rightleftharpoons M$ |
| 气体-离子电极 | $Pt \mid X_2 \mid X^{n-}$ | $Pt \mid H_2 \mid H^+$ | $2H^+ + 2e^- \rightleftharpoons H_2$ |
| 金属-难溶盐（氧化物）-负离子电极 | $M \mid MX(s) \mid X^{n-}$ | $Ag \mid AgCl(s) \mid Cl^-$ | $AgCl + e^- \rightleftharpoons Ag + Cl^-$ |
| 氧化还原电极 | $Pt \mid Ox, Red$ | $Pt \mid Fe^{2+}, Fe^{3+}$ | $Fe^{3+} + e^- \rightleftharpoons Fe^{2+}$ |

> 气体电极须用惰性电极（Pt、石墨）作导体，惰性电极只吸附气体与传递电子，不参与反应。参比电极多取第三类（电势稳定、易制备）。

### 3. 电池符号书写规范

- 负极写在左、正极写在右，极性用 (+) (−) 标注
- 「$\mid$」表示半电池内两相界面，「$\parallel$」表示盐桥
- 气体须注明分压；有惰性电极须标明；同一溶液中两种离子用逗号分隔
- 例：$(-)\mathrm{Zn(s)} \mid \mathrm{Zn^{2+}}(c_1) \parallel \mathrm{Cu^{2+}}(c_2) \mid \mathrm{Cu(s)}(+)$

### 4. 电极电势与标准电极电势

- **双电层理论**（能斯特 1889）：金属溶解倾向 $M \rightleftharpoons M^{n+}(aq) + ne^-$ 与沉积倾向同时存在，两向速率相等时建立动态平衡，在金属与溶液间形成电势差
- 电极电势 $\varphi(M^{n+}/M)$ 的大小取决于金属本性、离子浓度、温度与介质；外界条件一定时只取决于金属本性
- **标准电极电势** $\varphi^\theta$：气体分压 $p^\theta = 100$ kPa、溶液浓度 $1\ \mathrm{mol\cdot L^{-1}}$、298.15 K
- 单个电极电势绝对值不可测 → IUPAC 规定标准氢电极 SHE $\varphi^\theta(H^+/H_2) = 0.000\ \mathrm{V}$，其余为相对值
- 电动势：$E = \varphi_+ - \varphi_-$，标准态下 $E^\theta = \varphi_+^\theta - \varphi_-^\theta$

### 5. 三类参比电极

| 电极 | 电极反应 | 电势 |
|:---|:---|:---|
| 饱和甘汞电极（SCE） | $Hg_2Cl_2(s) + 2e^- \rightleftharpoons 2Hg(l) + 2Cl^-$ | $\varphi_{SCE} = 0.242\ \mathrm{V}$ |
| 标准甘汞电极（1.00 mol/L KCl） | 同上 | $\varphi^\theta = 0.286\ \mathrm{V}$ |
| 银-氯化银电极 | $AgCl + e^- \rightleftharpoons Ag + Cl^-$ | 视 KCl 浓度而定 |

- 甘汞电极电势不随溶液 pH 变化，在一定温度与浓度下为定值
- 玻璃电极为常用 H⁺ 指示电极，电势随待测溶液 pH 改变

### 6. 使用标准电极电势的要点

1. 均为相对 $\varphi^\theta(H^+/H_2) = 0$ 的相对值；温度影响不大可参照使用，非标准态须用能斯特方程
2. $\varphi^\theta$ 越高，氧化型物质氧化能力越强、还原型越弱；反之亦然
3. 电极电势是**强度性质**：与物质的量无关，与电极反应书写方向无关（$Fe^{3+}+e^-$ 与 $2Fe^{3+}+2e^-$ 同为 0.771 V，不是 2 倍）
4. 酸表/碱表选择：反应中有 $H^+$ 查酸表、有 $OH^-$ 查碱表；两者均无时按物质存在状态判断（如 $S/S^{2-}$ 查碱表）
5. 同一物质在不同电对中角色可不同（$Fe^{2+}$ 在 $Fe^{3+}/Fe^{2+}$ 中是还原型，在 $Fe^{2+}/Fe$ 中是氧化型）
6. $\varphi^\theta$ 是热力学数据，**与反应速率无关**：$\varphi^\theta(Ca^{2+}/Ca) < \varphi^\theta(Na^+/Na)$，但 Na 与水反应更激烈

### 7. 能斯特方程

对电极反应 $a\,Ox + ne^- \rightleftharpoons b\,Red$：

$$\varphi(Ox/Red) = \varphi^\theta(Ox/Red) + \frac{RT}{nF}\ln\frac{c^a(Ox)}{c^b(Red)}$$

298.15 K 时：

$$\varphi(Ox/Red) = \varphi^\theta(Ox/Red) + \frac{0.0592}{n}\lg\frac{c^a(Ox)}{c^b(Red)}$$

应用要点：
- 纯固体、纯液体的浓度视为 1，**不出现在方程中**（如 Pb、AgCl、Hg、Br₂）
- 气体用相对分压 $p/p^\theta$ 表示
- $H^+$、$OH^-$、$Cl^-$ 等介质：处于氧化型一侧写入分子，处于还原型一侧写入分母

### 8. 五种因素对电极电势的影响

| 因素 | 实例 | 结果 |
|:---|:---|:---|
| 浓度 | 氧化型浓度增大 | $\varphi$ 增大（一般影响不大，系数大时显著） |
| 酸碱性 | $MnO_4^-/Mn^{2+}$，pH = 6 | 1.507 V → **0.939 V**（含氧酸根氧化性随酸度增大而增强） |
| 生成难溶物 | $Ag^+/Ag$ 加 NaCl 生成 AgCl | 0.7996 V → **0.2223 V** |
| 生成弱电解质 | 氢电极加 NaAc 生成 HAc | $\varphi = -0.0592\,\mathrm{pH} = -0.282\ \mathrm{V}$ |
| 生成配合物 | $Cu^{2+}/Cu$ 加氨水生成 $[Cu(NH_3)_4]^{2+}$ | 0.340 V → **0.392 V** |

> 配合物影响规律：试剂结合氧化型 → $\varphi$ 降低；结合还原型 → $\varphi$ 升高；两者都结合 → 按 $K_{稳}$ 大小判断。

### 9. 电极电势的四类应用

- **$\Delta_rG_m$ 与 $E$**：$\Delta_rG_m = -nFE$，$\Delta_rG_m^\theta = -nFE^\theta$
- **$K^\theta$ 与 $E^\theta$**：$\ln K^\theta = nFE^\theta/RT$；298.15 K 时 $\lg K^\theta = \dfrac{nE^\theta}{0.0592}$
- **判断方向**：$E > 0$ 正向自发、$E < 0$ 逆向自发、$E = 0$ 达平衡。近似判据：$E^\theta > +0.3\ \mathrm{V}$ 正向、$E^\theta < -0.3\ \mathrm{V}$ 逆向、$-0.3 \sim +0.3\ \mathrm{V}$ 之间须用 $E$ 判断
- **判断程度**：$K^\theta > 6\times10^{6}$ 视为进行完全；$K^\theta < 2\times10^{-7}$ 视为正向趋势极小
- **反求常数**：设计原电池使电池反应为目标平衡的逆反应，由 $E^\theta$ 求 $K_{sp}$、$K_{稳}$、$K_a$、$K_w$

### 10. 元素电势图（Latimer 图）

- 将同一元素各氧化数物种按氧化数由高到低排列，线上标各电对 $\varphi^\theta$
- **歧化判据**：三物种 $A \xrightarrow{\varphi_左^\theta} B \xrightarrow{\varphi_右^\theta} C$，若 $\varphi_右^\theta > \varphi_左^\theta$ 则 B 歧化（如 $2Cu^+ = Cu + Cu^{2+}$）
- **归中判据**：$\varphi_右^\theta < \varphi_左^\theta$ 则 A 与 C 归中生成 B（如 $2Fe^{3+} + Fe = 3Fe^{2+}$）
- **未知电对计算**：$\varphi_x^\theta = \dfrac{z_1\varphi_1^\theta + z_2\varphi_2^\theta + z_3\varphi_3^\theta}{z_x}$，其中 $z_x = z_1 + z_2 + z_3$
- 氧化性强弱与氧化数高低无必然关系（$HClO_4$ 中 Cl 为 +7，其相关电对 $\varphi^\theta$ 并非最大）
- 介质影响：氯的含氧酸在酸性介质的 $\varphi^\theta$ 显著高于碱性介质；制备高氧化态物种宜在碱性介质中进行

### 11. $\varphi$-pH 图（Pourbaix 图）

- 水的两条边界线（$p_{O_2} = p_{H_2} = 100$ kPa）：
  - 氧线：$\varphi(O_2/H_2O) = 1.229 - 0.0592\,\mathrm{pH}$
  - 氢线：$\varphi(H^+/H_2) = -0.0592\,\mathrm{pH}$
- 三区：氧线以上析出 $O_2$；氢线以下析出 $H_2$；两线之间为水的稳定区
- 三类线段：与 pH 无关的水平线（只有电子参加）、只与 pH 有关的垂直线（无电子的化学平衡）、两者都有的斜线（斜率 $-0.0592h/n$）
- 应用：判断物种在水中的稳定区间。例：$Fe$ 处于氢线下方可置换水中 $H^+$；$\varphi^\theta(Fe^{3+}/Fe^{2+})$ 低于氧线，故 $Fe^{2+}$ 可被空气中 $O_2$ 氧化

## 竞赛要点

1. **强度性质**：$\varphi^\theta$ 与物质数量无关、与反应书写方向无关——最常见的陷阱是把系数当倍数
2. **热力学 ≠ 动力学**：$\varphi^\theta$ 只能判断能否发生，不能说明快慢（「$E$ 越大速率越快」是错的）
3. **酸表/碱表选择**是本讲高频失分点，须按 $H^+$/$OH^-$ 是否出现及物种存在状态判断
4. **非标准态方向判断必须用 $E$**：浓度可改变反应方向（$MnO_2$ + 浓盐酸制氯气即典型例）
5. **由 $E^\theta$ 反求 $K_{sp}$/$K_{稳}$** 的一般套路：先设计电池使电池反应为目标平衡的逆反应，再 $\lg K^\theta = nE^\theta/0.0592$，最后取倒数（$K_{sp}$）或直接得（$K_{稳}$）
6. **歧化/归中判据**只看左右两段 $\varphi^\theta$ 的大小关系，与绝对值无关

## 例题与习题

### 典型例题

**例1**（酸碱性对电极电势的影响）：已知 $\varphi^\theta(MnO_4^-/Mn^{2+}) = 1.507\ \mathrm{V}$，且 $c(MnO_4^-) = c(Mn^{2+}) = 1\ \mathrm{mol\cdot L^{-1}}$，求 298.15 K、pH = 6 时的电极电势。

- 解：$\varphi = 1.507 + \dfrac{0.0592}{5}\lg c^8(H^+) = 1.507 - \dfrac{0.0592\times8}{5}\times6 = 0.939\ \mathrm{V}$
- 结论：酸性减弱使 $MnO_4^-$ 氧化能力大幅下降

**例2**（由 $E^\theta$ 求 $K_{sp}$）：已知 $\varphi^\theta(Pb^{2+}/Pb) = -0.1262\ \mathrm{V}$、$\varphi^\theta(PbSO_4/Pb) = -0.3588\ \mathrm{V}$，求 298.15 K 时 $PbSO_4$ 的 $K_{sp}$。

- 解：$E^\theta = -0.1262 - (-0.3588) = 0.2326\ \mathrm{V}$，$\lg K^\theta = \dfrac{2\times0.2326}{0.0592} = 7.86$，$K^\theta = 7.24\times10^{7}$
- $K_{sp} = 1/K^\theta = 1.38\times10^{-8}$

**例3**（浓度改变反应方向）：$\varphi^\theta(MnO_2/Mn^{2+}) = 1.224\ \mathrm{V}$、$\varphi^\theta(Cl_2/Cl^-) = 1.358\ \mathrm{V}$，判断标准态与 $[H^+] = [Cl^-] = 12\ \mathrm{mol\cdot L^{-1}}$ 两种条件下能否用 $MnO_2$ 与盐酸制备 $Cl_2$。

- 标准态：$E^\theta = 1.224 - 1.358 = -0.134\ \mathrm{V} < 0$，反应逆向，**不能**
- 浓盐酸：$\varphi(MnO_2/Mn^{2+}) = 1.224 + \dfrac{0.0592}{2}\lg 12^4 = 1.342\ \mathrm{V}$，$\varphi(Cl_2/Cl^-) = 1.358 + \dfrac{0.0592}{2}\lg\dfrac{1}{12^2} = 1.294\ \mathrm{V}$，$E = 0.048\ \mathrm{V} > 0$，**可以**

### 本讲习题要点

- 由给定氧化还原反应设计原电池、写出正负极反应与电池符号、判断电极类型
- 选择酸表/碱表读取 $\varphi^\theta$
- 能斯特方程五类影响因素的计算（浓度、酸碱性、难溶物、弱电解质、配合物）
- 由 $E^\theta$ 计算 $\Delta_rG_m^\theta$、$K^\theta$、$K_{sp}$、$K_{稳}$、$K_a$、$K_w$
- 元素电势图判断歧化/归中、由已知电对计算未知 $\varphi^\theta$
- 水的 $\varphi$-pH 图与金属-水系稳定区判读
