# 提炼-上海中学竞赛课程-第二分册-气体

> 来源：上海中学竞赛课程·化学·第2分册·第一讲 气体（原书约 540 行，行167-704）

## 内容概要

本讲系统阐述气体的基本性质与定量描述方法。从气体的扩散性和可压缩性出发，引入理想气体模型，推导理想气体状态方程 pV=nRT，给出相对密度、摩尔质量的求算方法。随后介绍范德瓦尔斯方程对理想模型的修正，从分子运动论角度推导气体压强公式并关联温度与分子平均动能。最后讨论混合气体的道尔顿分压定律、阿玛加分体积定律以及格拉罕姆扩散定律及其应用（如铀同位素分离）。

---

## 核心知识点

### 1. 理想气体状态方程
$$pV = nRT$$
- R = 8.314 J·mol⁻¹·K⁻¹ = 8.314 kPa·dm³·mol⁻¹·K⁻¹
- 变形：$\rho = \frac{pM}{RT}$，用于求气体密度与摩尔质量
- 二态关系：$\frac{p_1 V_1}{T_1} = \frac{p_2 V_2}{T_2}$

### 2. 相对密度与摩尔质量
$$D = \frac{M_1}{M_2} \implies M_1 = D \cdot M_2$$
- $M_1 = 2D(\mathrm{H}_2)$ 或 $M_1 = 29D(\text{空气})$

### 3. 范德瓦尔斯方程（对理想气体的修正）
$$\left(p + a\frac{n^2}{V^2}\right)(V - nb) = nRT$$
- $V_{id} = V_{实} - nb$：扣除分子本身体积
- $p_{id} = p_{实} + a\frac{n^2}{V^2}$：修正分子间引力导致的压强降低
- a、b 为范德瓦尔斯常数，由实验确定

### 4. 分子运动论推导
$$pV = \frac{2}{3}N\bar{E}_K, \quad \bar{E}_K = \frac{3}{2}kT$$
- 玻尔兹曼常数 $k = R/N_A = 1.381 \times 10^{-23}$ J·K⁻¹

### 5. 道尔顿分压定律
$$p_{总} = p_A + p_B + p_C$$
- $p_A = p_{总} \cdot x_A$（分压 = 总压 × 摩尔分数）

### 6. 阿玛加分体积定律
$$V_{总} = V_A + V_B + V_C$$
- 摩尔分数等于体积分数：$x_A = V_A / V_{总}$

### 7. 格拉罕姆扩散定律
$$\frac{\bar{u}_1}{\bar{u}_2} = \sqrt{\frac{\rho_2}{\rho_1}} = \sqrt{\frac{M_2}{M_1}}$$
- 应用：测定未知气体摩尔质量；分离同位素（如 ²³⁵U/²³⁸U 以 UF₆ 形式扩散分离）

## 竞赛要点

1. **理想气体适用条件**：温度 > 500 K 或压强 < 101.3 kPa 时，实际气体近似为理想气体
2. **范德瓦尔斯方程的物理意义**：体积修正项 nb 反映分子自身体积，压强修正项 $an^2/V^2$ 反映分子间引力
3. **混合气体计算技巧**：利用分压定律和摩尔分数快速求算各组分分压
4. **格拉罕姆定律的推导**：从 $pV = \frac{m}{3}N\bar{u}^2$ 出发，在等压条件下 $\bar{u} \propto 1/\sqrt{\rho}$
5. **道尔顿定律与阿玛加定律的区别**：分压定律关注压强，分体积定律关注体积，二者在理想气体中等价
6. **非理想气体行为**：高压低温下偏离理想行为，范德瓦尔斯方程能定性解释偏差方向

## 例题与习题

### 典型例题

**例1**：已知某气体对 H₂ 的相对密度为 14，求该气体的摩尔质量。
- 解：$M = 2 \times 14 = 28$ g·mol⁻¹（可能为 N₂ 或 CO）

**例2**：混合气体中 N₂ 的摩尔分数为 0.75，总压为 200 kPa，求 N₂ 的分压。
- 解：$p(\mathrm{N}_2) = 200 \times 0.75 = 150$ kPa

### 本讲习题要点
- 利用理想气体状态方程进行 p-V-T-n 的互算
- 利用相对密度求未知气体的摩尔质量
- 混合气体的分压、分体积计算
- 范德瓦尔斯方程的定性分析
- 格拉罕姆定律在同位素分离中的应用
