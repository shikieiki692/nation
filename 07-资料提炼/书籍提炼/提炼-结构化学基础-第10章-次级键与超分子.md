## 三、核心内容提炼

### 3.1 键价理论

**核心公式**：

$$S_{ij} = \exp[(R_0-r_{ij})/B] \quad \text{或} \quad S_{ij} = (r_{ij}/R_0)^{-N}$$

**键价和规则**：每个原子所连诸键的键价之和 = 该原子的原子价。

**应用示例**：
- PO₄³⁻：P—O键价1.25×4=5=P的原子价 ✅
- 冰中O—H…O：O—H键价0.8，H…O键价0.2，O的键价和=2，H的键价和=1 ✅

### 3.2 氢键（考纲11.1核心）

**通式**：X—H…Y（X和Y通常为F、O、N、Cl等高电负性原子）

**几何特征**：
- 大多数不对称（H靠近X，远离Y）
- ∠XHY通常<180°，越接近180°氢键越强
- 对称氢键（r₁=r₂）是最强氢键
- R(X…Y)远小于范德华半径和

**强度分级**：

| 类型 | 键能 | 特征 | 实例 |
|------|------|------|------|
| 强氢键 | >50 kJ/mol | 共价性占优势 | 对称F—H—F(212 kJ/mol) |
| 中强氢键 | 15-50 kJ/mol | 静电性占优势 | O—H…O(25 kJ/mol,冰) |
| 弱氢键 | <15 kJ/mol | 弱静电作用 | C—H…O |

**冰和水的氢键**：
- 冰-Ih：每个H₂O形成4个O—H…O氢键（四面体排布）→结构空旷→密度0.917 g/cm³ < 水
- 冰→水：约15%氢键断裂→堆积变密→4°C密度最大
- 甲烷水合物：8CH₄·46H₂O

**氢键对物质性质的影响**：
1. **溶解性**：能形成氢键的溶质溶于水（ROH/RCOOH/R₂CO等），不能的溶于有机溶剂（"相似相溶"）
2. **熔沸点**：有氢键的物质（H₂O/NH₃/HF）熔沸点高于同族氢化物
3. **黏度**：多羟基化合物（甘油/浓硫酸）因分子间氢键网络→高黏度

**生命物质中的氢键**：
- 蛋白质：α-螺旋链/β-折叠片由氢键稳定（二/三/四级结构）
- DNA：A…T 2个氢键，G…C 3个氢键→双螺旋结构→遗传信息传递

**新型氢键**（了解）：π氢键(X—H…π)、金属氢键(X—H…M)、二氢键(X—H…H—Y)

### 3.3 非氢键型次级键

判断标准：原子间距介于共价半径和与范德华半径和之间。

典型实例：
- I₂晶体：I---I 350 pm（共价和267 pm < 350 < 范德华和430 pm）
- (NO)₂：N---N 218 pm（共价和150 pm < 218 < 范德华和300 pm）
- 亲金作用：Auᴵ---Auᴵ（2.5-3.5 Å）

### 3.4 范德华力（考纲11.1核心）

**三种组分**：

| 类型 | 作用本质 | 能量公式特征 | 普遍性 |
|------|---------|-------------|--------|
| 静电力 | 偶极-偶极 | ∝μ₁²μ₂²/r⁶T | 极性分子 |
| 诱导力 | 偶极-诱导偶极 | ∝α₂μ₁²/r⁶ | 极性+非极性 |
| 色散力 | 诱导偶极-诱导偶极 | ∝α₁α₂/r⁶ | **所有分子** |

**关键结论**：
- 色散力普遍存在，且通常是分子间力的主要贡献
- r⁻⁶依赖→距离越近越强
- 极化率α越大→色散力越大→沸点越高（同系物中分子量增大→α增大→沸点升高）
- 范德华半径：非键原子的"有效接触半径"，用于判断分子间距离和次级键

## 五、典型例题与常见错误

### 典型例题

**例1（必做）**：比较H₂O、H₂S、H₂Se的沸点，用氢键解释
- H₂O因O—H…O氢键→沸点远高于H₂S和H₂Se
- H₂S和H₂Se无氢键，沸点随分子量增大（色散力增大）而升高

**例2（必做）**：解释为什么乙醇与水混溶而己烷不溶于水
- 乙醇的O—H可与水形成氢键→"相似相溶"
- 己烷不能形成氢键→疏水

**例3（竞赛）**：DNA碱基配对中A…T和G…C的氢键数目
- A-T：2个N—H…O和N—H…N氢键
- G-C：3个氢键（含N—H…O和N—H…N）

### 常见错误

| 错误 | 说明 |
|------|------|
| **沸点比较只看分子量** | HF/H₂O/NH₃因氢键沸点异常高，不能只看分子量 |
| **色散力忽视** | 非极性分子间只有色散力，但色散力是所有分子间力的共同组分 |
| **氢键方向性** | 氢键有方向性要求（X—H尽量指向Y的孤对电子），不是任意方向 |
| **分子内vs分子间氢键** | 分子内氢键（如邻硝基苯酚）反而降低沸点/溶解度，与分子间氢键效果不同 |
| **冰密度低于水** | 氢键四面体排布使冰结构空旷→密度低，这是反常膨胀的原因 |
