**本章定位**：两大"氧化还原明星"——Cr 与 Mn 的多变氧化态，是竞赛氧化还原计算与配平的富矿。同时 Cr(III)/Al(III) 相似性与差异是"对角线规则+过渡金属"的经典对比。

## 三、教学逻辑锚点

1. **Cr/Al 相似性与分离**：Cr(III) 与 Al(III) 电荷/半径相近 → 两性氢氧化物、相同结晶水数、水合异构类比；但 Cr(III) 碱性中可氧化为可溶 Cr(VI)，Al 不行 → 分离方案。过渡金属与主族元素的"同中有异"。
2. **Cr(VI) 的酸碱-聚合-氧化三位一体**：CrO₄²⁻⇌Cr₂O₇²⁻ 平衡（K=10¹⁴）+ 酸酐 CrO₃ + 强氧化性，一条线串起洗液、定量铁、过氧化铬。
3. **KMnO₄ 介质决定产物**：酸→Mn²⁺、碱→MnO₄²⁻、中性→MnO₂——氧化还原产物判断的"介质优先"原则，也是配平训练核心。
4. **Mn(II) 还原性酸碱反差**：碱中 E°=-0.05 V（易被 O₂ 氧化，测溶解氧），酸中需 S₂O₈²⁻/NaBiO₃/PbO₂ 强氧化剂才氧化——介质改变反应方向的极端案例。
5. **四重键里程碑**：[Re₂Cl₈]²⁻ 的 σ+2π+δ 键（1964 Cotton），金属-金属多重键的教科书范例，衔接竞赛"金属簇合物"专题。
6. **同族高氧化态稳定性**：第一过渡系 Mn(+7) 强氧化性 vs 第二三过渡系 Tc/Re(+7) 稳定——d 轨道扩展使高氧化态稳定。

## 四、核心内容提炼

### 21.1 铬副族元素（ⅥB：Cr、Mo、W）

**价层构型** Cr/Mo (n-1)d⁵ns¹；W 5d⁴6s²。最高氧化态 +6。
**Cr vs Mo/W 差异**：Cr 可形成 Cr(II)/Cr(III) 阳离子、Cr(VI) 氧化性很强；Mo/W 的 +6 稳定（Cr 是强氧化剂中心，Mo/W 是稳定酸根中心）。

#### 1. 存在与铬单质
- Cr 地壳 1×10⁻²%（丰度高但矿贫乏）；矿物：铬铁矿 FeCr₂O₄（FeO·Cr₂O₃）、铬铅矿 PbCrO₄、铬赭石矿 Cr₂O₃。Mo 1.5×10⁻⁴%：辉钼矿 MoS₂、钼钨钙矿 Ca(Mo,W)O₄、钼铅矿 PbMoO₄（我国第 2）。W 1×10⁻⁴%：白钨矿 CaWO₄、黑钨矿 (Fe,Mn)WO₄（我国占世界 75%）。
- **铬是硬度最高金属（莫氏 9）**；熔点 1907℃、沸点 2671℃；室温稳定耐腐蚀 → 不锈钢、镀铬；高纯铬抗稀硫酸，硝酸/王水钝化（表面致密氧化膜）；高温与 X₂/O₂/N₂/S/C 化合生成 Cr(III) 化合物。
- 与酸：`Cr + 2HCl = CrCl₂ + H₂↑`（蓝色 Cr(II)）；`4CrCl₂ + 4HCl + O₂ = 4CrCl₃ + 2H₂O`（Cr(II) 强还原，空气即氧化为绿色 Cr(III)）。
- 提取：焦炭还原得铬铁合金 `FeCr₂O₄ + 4C 高温= Fe + 2Cr + 4CO`；纯铬路线：`4FeCr₂O₄ + 8Na₂CO₃ + 7O₂ 高温= 2Fe₂O₃ + 8Na₂CrO₄ + 8CO₂` → 水浸 Na₂CrO₄ → 酸化得 Na₂Cr₂O₇ → `Na₂Cr₂O₇ + 2C 高温= Cr₂O₃ + Na₂CO₃ + CO` → **铝热法** `Cr₂O₃ + 2Al 点燃= 2Cr + Al₂O₃` 或硅还原、电解铬钾矾。

#### 2. Cr(III) 化合物
- **Cr₂O₃（铬绿）**：深绿，难溶；两性（类 γ-Al₂O₃）：溶酸 `Cr₂O₃ + 3H₂SO₄ = Cr₂(SO₄)₃ + 3H₂O`；溶强碱 `Cr₂O₃ + 2NaOH + 3H₂O = 2Na[Cr(OH)₄]`（可写 NaCrO₂）。高温灼烧后惰性（类 α-Al₂O₃），需 `K₂S₂O₇` 或 `KHSO₄` 共熔转化为可溶盐。
- **Cr(OH)₃**：灰蓝色，两性（溶酸碱）；Ksp=6.3×10⁻³¹。加 NaOH 时沉淀与 [Cr(OH)₄]⁻ 同时生成 → 呈蓝绿/灰绿误认。
- **Cr(III) 盐结晶水与铝盐相同**：CrCl₃·6H₂O、Cr₂(SO₄)₃·18H₂O、铬钾矾 K₂SO₄·Cr₂(SO₄)₃·24H₂O。
- **CrCl₃·6H₂O 三种水合异构体**：`[Cr(H₂O)₆]Cl₃` 紫、`[Cr(H₂O)₅Cl]Cl₂·H₂O` 浅绿、`[Cr(H₂O)₄Cl₂]Cl·2H₂O` 深绿。
- **NH₃ 逐级取代变色**：紫→浅红→橙红→橙黄→黄（NH₃ 配体场强于 H₂O → Δ₀ 增大 → 吸收波长变短）。但 [Cr(NH₃)₆]³⁺ 只能液氨中生成，水中 Cr(OH)₃ 难溶氨水。
- **Al³⁺/Cr³⁺ 分离**：不用氨水配位法，而是碱性氧化 Cr(III)→CrO₄²⁻ 可溶，酸化溶 Al(OH)₃，再加 Ba²⁺ 沉 BaCrO₄：`Al(OH)₃ + 3H⁺ = Al³⁺ + 3H₂O`；`CrO₄²⁻ + Ba²⁺ = BaCrO₄↓`。
- **Cr³⁺ 水解**：高电荷阳离子水解 → 遇 Na₂S/Na₂CO₃ 得 Cr(OH)₃ 沉淀（非 Cr₂S₃/Cr₂(CO₃)₃）。
- **Cr(III) 还原性（碱强酸弱）**：
  - 碱中强还原：`CrO₄²⁻ + 4H₂O + 3e⁻ = Cr(OH)₃ + 5OH⁻` E°=-0.13 V；被 H₂O₂/I₂ 氧化：`2[Cr(OH)₄]⁻ + 3H₂O₂ + 2OH⁻ = 2CrO₄²⁻ + 8H₂O`。
  - 酸中弱：`Cr₂O₇²⁻ + 14H⁺ + 6e⁻ = 2Cr³⁺ + 7H₂O` E°=1.36 V；需 PbO₂/BiO₃⁻ 等强氧化剂；固体 `4Cr₂O₃ + 16KClO₃ 共熔= 8K₂CrO₄ + 14ClO₂ + Cl₂`。

#### 3. Cr(VI) 化合物
**存在形式与颜色**：CrO₄²⁻ 黄 / Cr₂O₇²⁻ 橙 / CrO₃ 红 / CrO₂Cl₂ 深红。
- **酸碱平衡**：`2CrO₄²⁻ + 2H⁺ = Cr₂O₇²⁻ + H₂O`，K=1.0×10¹⁴；中性/碱性 CrO₄²⁻；pH=5 基本 Cr₂O₇²⁻；浓 H₂SO₄ → 红色 CrO₃。重铬酸根为两个 CrO₄ 四面体共顶点氧。
- **铬酸洗液**：`K₂Cr₂O₇ + 2H₂SO₄(浓) = 2KHSO₄ + 2CrO₃ + H₂O`（CrO₃ 强氧化 + H₂SO₄ 强酸）；Cr(VI) 致癌污染，已少用（王水等替代须现配）。
- **CrO₂Cl₂（铬氧根氯化物）**：深红液体，易挥发如溴；`K₂Cr₂O₇ + 4KCl + 3H₂SO₄(浓) △= 2CrO₂Cl₂ + 3K₂SO₄ + 3H₂O`；水解 `2CrO₂Cl₂ + 3H₂O = H₂Cr₂O₇ + 4HCl`；钢铁分析加热挥发除铬干扰。
- 酸性：H₂CrO₄ K₁=0.18、K₂=3.3×10⁻⁷；CrO₃ 是 H₂CrO₄ 和 H₂Cr₂O₇ 的酸酐。
- **强氧化性**（酸中）：氧化 HBr/HI/H₂S/H₂SO₃；加热氧化浓 HCl；**定量测铁**：`Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ = 2Cr³⁺ + 6Fe³⁺ + 7H₂O`。
- 分解：`(NH₄)₂Cr₂O₇(s) △= N₂↑ + Cr₂O₃ + 4H₂O`（火山实验）；`4CrO₃ △= 2Cr₂O₃ + 3O₂↑`。
- **难溶铬酸盐**：Ag₂CrO₄ 砖红（1.1×10⁻¹²）、PbCrO₄ 黄（2.8×10⁻¹³）、BaCrO₄ 黄（1.2×10⁻¹⁰）、SrCrO₄ 黄（2.2×10⁻⁵）；碱金属/铵/镁盐可溶。重铬酸盐溶解度大 → 不会生成重铬酸盐沉淀；向 Cr₂O₇²⁻ 加 Ba²⁺/Pb²⁺/Ag⁺ 平衡移向铬酸盐沉淀：`2Ba²⁺ + Cr₂O₇²⁻ + H₂O = 2BaCrO₄↓ + 2H⁺`。
- **沉淀转化**：PbCrO₄ 溶硝酸/强碱；盐酸/硫酸中转化 PbCl₂/PbSO₄；Ag₂CrO₄ 在 HCl/NaOH 中转 AgCl/Ag₂O；BaCrO₄ 在硫酸中转 BaSO₄。
- **过氧化铬 CrO₅**（蓝色）：`K₂Cr₂O₇ + 4H₂O₂ + H₂SO₄(稀) = 2CrO₅ + 5H₂O + K₂SO₄`；CrO₅=CrO(O₂)₂，**Cr 化合价 +6 但形式氧化数 +10**（过氧链 O₂²⁻）；不稳定 `4CrO₅ + 12H⁺ = 4Cr³⁺ + 6H₂O + 7O₂`；乙醚/戊醇萃取蓝色（界面分解慢）——鉴定 Cr(VI) 或 H₂O₂。
- **重铬酸钾生产**（红矾）：铬铁矿 + 纯碱铁坩埚空气加热 → `4Fe(CrO₂)₂ + 8Na₂CO₃ + 7O₂ = 8Na₂CrO₄ + 2Fe₂O₃ + 8CO₂`；水浸滤 Fe₂O₃ → 加酸 `2Na₂CrO₄ + 2H⁺ = Na₂Cr₂O₇ + 2Na⁺ + H₂O`；加 KCl `Na₂Cr₂O₇ + 2KCl = K₂Cr₂O₇ + 2NaCl`（**NaCl 溶解度不随温度变，K₂Cr₂O₇ 溶解度随温度显著增大** → 趁热滤 NaCl，降温析 K₂Cr₂O₇ 橙晶）。

#### 4. 钼和钨
- 镧系收缩 → Mo/W 极相似，但差异比 Zr/Hf、Nb/Ta 大，分离不困难；最稳定 +6。
- 高熔点银白金属；**W 熔点最高**用作灯丝。
- 提取：Mo——辉钼矿灼烧 `2MoS₂ + 7O₂ = 2MoO₃ + 4SO₂`；溶氨水 → 钼酸铵 → 分解 → 纯 MoO₃ → H₂/Al/C 还原。W——黑钨矿 + Na₂CO₃ 共熔 → 钨酸钠；HCl 酸化 → H₂WO₄；脱水 → WO₃；Al/H₂ 还原。
- **MoO₃ 浅黄 / WO₃ 黄**；溶碱 → MO₄²⁻；强酸 → 钼酸 H₂MoO₄·H₂O 白 / 钨酸 H₂WO₄·xH₂O 黄。
- **同多酸**：同种简单含氧酸脱水缩合（V/Cr/Mo/W/B/Si/P/As 易形成）；酸度增大缩合度增大。Mo：pH<6 → 七钼酸根 `Mo₇O₂₄⁶⁻`（仲钼酸根）；更高酸度 → `Mo₈O₂₆⁴⁻`、`Mo₃₆O₁₁₂⁸⁻`（36 钼）。
- **杂多酸**：不同元素含氧酸脱水缩合，是特殊配位化合物（P/Si 为中心原子，多钼/多钨酸根为配体），固体酸。
  - 磷钼酸铵黄色沉淀鉴定 PO₄³⁻：`H₃PO₄ + 12(NH₄)₂MoO₄ + 21HNO₃ = (NH₄)₃PO₄·12MoO₃↓ + 21NH₄NO₃ + 12H₂O`，即 (NH₄)₃[PMo₁₂O₄₀]。
  - **Keggin 结构** [PMo₁₂O₄₀]³⁻（1933）：Mo₃O₁₃ 单元 4 个呈四面体分布围 P，P 处于 O 四配位四面体环境，P:Mo=1:12。
  - **Anderson 结构** [TeMo₆O₂₄]⁶⁻：Te:Mo=1:6，Te 处于 O 六配位八面体环境。
- 钼生物功能：醛氧化酶、硝酸还原酶、亚硫酸盐氧化酶、黄嘌呤氧化酶、豆科固氮酶均含钼；大脑必需微量元素之一。

### 21.2 锰副族元素（ⅦB：Mn、Tc、Re）

**价层构型** (n-1)d⁵ns²；最高氧化态 +7。
- **本族规律**：Mn 氧化态范围最宽、+2 最稳定常见；Tc/Re 的 +7 最稳定（仅微弱氧化性），+2 及以下不常见且强还原。**自上而下高氧化态稳定性递增、低氧化态稳定性递减**。
- 存在：软锰矿 MnO₂、黑锰矿 Mn₃O₄、方锰矿 MnO、MnCO₃；**锰结核**（海洋，含 Mn/Fe/Cu/Ni/Co）。Tc 第一种人造元素（1937 氘核轰击 Mo），全部同位素放射性。Re 最后发现非人造金属（1925），4×10⁻⁸% 稀有分散，辉钼矿痕量。

#### 1. 锰单质
- 铝热还原：`3MnO₂ + 4Al 点燃= 3Mn + 2Al₂O₃`；`3Mn₃O₄ + 8Al 点燃= 9Mn + 4Al₂O₃`。
- 活泼金属溶冷稀酸 `Mn + 2HCl = MnCl₂ + H₂`；加热与空气 → Mn₃O₄；**与热水作用生成 Mn(OH)₂ 放氢（类镁）**；钢添加剂脱氧脱硫。

#### 2. Mn(II) 化合物
- **易溶盐**：MnSO₄/MnCl₂/Mn(NO₃)₂。Mn²⁺ 5 个 d 电子平行自旋、d-d 跃迁概率小 → 颜色浅；浓溶液粉红、稀近无色；水合盐粉红/玫瑰色，无水盐白。
- **难溶盐**（易溶强酸）：MnCO₃ 白（2.3×10⁻¹¹）、Mn(OH)₂ 白（1.9×10⁻¹³）、α-MnS 绿（2.5×10⁻¹³）、MnC₂O₄ 白（1.7×10⁻⁷）。MnS 三晶型：α 绿最稳定、β/γ 红；粉红水合物慢慢转绿色 α；溶弱酸（HAc），**不能在酸性溶液中沉淀**。
- **还原性（碱强酸弱）**：
  - 碱中：E°(MnO₂/Mn(OH)₂)=-0.05 V < E°(O₂/OH⁻)=0.40 V → `2Mn(OH)₂ + O₂ = 2MnO(OH)₂`（棕黑）——**水质分析测溶解氧**；MnS/MnCO₃/MnC₂O₄ 在空气中氧化成 MnO(OH)₂。
  - 酸中：E°(MnO₄⁻/Mn²⁺)=1.51 V，需 (NH₄)₂S₂O₈（Ag⁺ 催化）/NaBiO₃/PbO₂/H₅IO₆ 强氧化剂 → 紫色 MnO₄⁻（**鉴定 Mn²⁺**）：`2Mn²⁺ + 5BiO₃⁻ + 14H⁺ = 2MnO₄⁻ + 5Bi³⁺ + 7H₂O`。注意 Mn²⁺ 过量会与 MnO₄⁻ 反应生成 MnO₂：`3Mn²⁺ + 2MnO₄⁻ + 2H₂O = 5MnO₂↓ + 4H⁺`（鉴定时 Mn²⁺ 不宜过量）。
- 热分解（酸根有氧化性则 Mn(II) 被氧化）：`Mn(NO₃)₂ △= MnO₂ + 2NO₂`；`Mn(ClO₄)₂ △= MnO₂ + Cl₂ + 3O₂`。
- **配位**：d⁵ 弱场高自旋八面体 CFSE=0；[Mn(H₂O)₆]²⁺ 极浅粉红；[MnX₄]²⁻（Cl/Br/I，乙醇中）黄色四面体高自旋 CFSE=0；强场 CN⁻：蓝紫 [Mn(CN)₆]⁴⁻ 低自旋（CFSE=2Δ-2P），易氧化为棕红 [Mn(CN)₆]³⁻。

#### 3. Mn(III) 化合物
- 氧化性强、易歧化：`MnO₂ →0.95→ Mn³⁺ →1.51→ Mn²⁺`。
- 代表：紫红 Mn(CH₃COO)₃·3H₂O；紫红 MnF₃（MnF₂+F₂）；黑 Mn₂O₃（MnO₂ 低于 800℃ 加热）。配位：棕红 [Mn(CN)₆]³⁻、紫 [Mn(PO₄)₂]³⁻。

#### 4. Mn(IV) 化合物（MnO₂）
- 最稳定，不溶水/稀酸碱，酸碱中均不歧化；两性。
- 酸性：`MnO₂ + 2NaOH △= Na₂MnO₃ + H₂O`（亚锰酸盐）。
- 碱性：室温浓 HCl → 土黄 MnCl₄。
- 中间氧化态双重性：氧化剂 E°(MnO₂/Mn²⁺)=1.22 V（氧化 I⁻/Fe²⁺；`MnO₂ + 4HCl(浓) △= MnCl₂ + Cl₂ + 2H₂O` 实验室制 Cl₂）；还原剂 E°(MnO₄²⁻/MnO₂)=0.60 V（`3MnO₂ + 6KOH + KClO₃ 共熔= 3K₂MnO₄ + KCl + 3H₂O`）。
- 浓 H₂SO₄：`4MnO₂ + 6H₂SO₄(浓) △= 2Mn₂(SO₄)₃ + 6H₂O + O₂`（Mn³⁺ 紫红）；升温 `2Mn₂(SO₄)₃ + 2H₂O = 4MnSO₄ + O₂ + 2H₂SO₄`。

#### 5. Mn(VI) 化合物（K₂MnO₄）
- 深绿晶体，190℃ 分解；强碱（pH>14）中稳定。
- 酸碱均歧化：`3MnO₄²⁻ + 4H⁺ = 2MnO₄⁻ + MnO₂↓ + 2H₂O`；`3MnO₄²⁻ + 2H₂O = 2MnO₄⁻ + MnO₂↓ + 4OH⁻`。绿色溶液加水稀释 → 紫色 + 棕黑沉淀（演示实验）。

#### 6. Mn(VII) 化合物（KMnO₄）
- 紫黑晶体；水溶液颜色随浓度：粉红→红→紫红→紫→紫黑。
- **强氧化性——介质决定产物**：强酸→Mn²⁺、强碱→MnO₄²⁻、近中性→MnO₂。例（与 S(IV)）：
  - 酸性：`2MnO₄⁻ + 5H₂SO₃ = 2Mn²⁺ + 5SO₄²⁻ + 4H⁺ + 3H₂O`
  - 中性：`2MnO₄⁻ + H₂O + 3SO₃²⁻ = 2MnO₂↓ + 3SO₄²⁻ + 2OH⁻`
  - 碱性：`2MnO₄⁻ + 2OH⁻ + SO₃²⁻ = 2MnO₄²⁻ + SO₄²⁻ + H₂O`
- 酸中强氧化剂：氧化 Cl⁻（制 Cl₂，但价高少用）、Cr³⁺、I₂。
- **定量应用**：标定草酸 `2MnO₄⁻ + 6H⁺ + 5H₂C₂O₄ = 2Mn²⁺ + 10CO₂ + 8H₂O`；测 Fe²⁺ `MnO₄⁻ + 8H⁺ + 5Fe²⁺ = Mn²⁺ + 5Fe³⁺ + 4H₂O`；**自身指示剂**（过量 MnO₄⁻ 显红）。
- **不稳定性**：酸中分解 `4MnO₄⁻ + 4H⁺ = 4MnO₂ + 3O₂ + 2H₂O`；碱中 `4MnO₄⁻ + 4OH⁻ = 4MnO₄²⁻ + O₂ + 2H₂O`；**光催化分解 → 棕色瓶，标准液用前标定**。
- 固相分解：`2KMnO₄(s) 200℃= K₂MnO₄ + MnO₂ + O₂`。
- Mn₂O₇：`2KMnO₄ + H₂SO₄(浓) 低温= Mn₂O₇ + K₂SO₄ + H₂O`（暗绿油状，遇有机物燃烧、受热爆炸、常温放 O₂ 变 MnO₂）。
- **制备**：软锰矿 + KClO₃ + KOH 共熔 → K₂MnO₄ → 氯气氧化 `2MnO₄²⁻ + Cl₂ = 2MnO₄⁻ + 2Cl⁻` 或**电解**（阳极 MnO₄²⁻→MnO₄⁻；KOH 可循环）。

#### 7. Mn 低价配位化合物
- K₅[Mn(CN)₆]（+1）；CO 配体体系：金黄色 [Mn₂(CO)₁₀]（LiAlH₄ 还原 MnI₂ 高压 CO，Mn 0 价）；Na[Mn(CO)₅]（钠汞齐还原，Mn -1）；无色液 [Mn(CO)₅H]（H₃PO₄ 处理）；[Mn(CO)₅Cl]（Cl₂ 氧化，Mn +1）。

#### 8. Tc/Re
- Re：密度 20.8 g/cm³（次于 Os/Ir/Pt）；熔点 3185℃（仅次于 W）；钨丝掺 Re 延长寿命 5 倍；火箭/卫星外壳、高温热电偶（2000℃）、反应堆衬套；化学极稳定（HF 不蚀），替代铂作催化剂（石油氢化、醇脱氢）。
- Tc/Re 水溶液仅 TcO₄⁻/ReO₄⁻。
- Re 氧化物：Re₂O₇ 黄（熔点 300℃）；ReO₃ 红金属光泽（400℃ 分解）；Re₂O₅ 蓝不稳定歧化；ReO₂ 灰稳定（900℃ 歧化）。
- Re 卤化物：ReF₇ 黄 48.3℃（+7）；ReF₆ 黄液 18.5℃；ReCl₆ 红绿 29℃（氯化物最高 +6）；ReBr₅ 棕 110℃ 分解（+5）；ReI₃ 黑室温分解。

#### 9. [Re₂Cl₈]²⁻ 与四重键（1964 Cotton）
- 蓝色抗磁性；**Re-Re 键长 224 pm < 金属中 271.4 pm**。
- 结构：2 个 ReCl₄ 正方形（Re 用 dsp² 杂化），Cl 排斥使 Re 略靠拢。
- **四重键组成**：d_z² 头碰头 σ 键 + d_yz、d_xz 肩并肩 π 键 ×2 + **d_xy 面对面 δ 键**。δ 键：在 ReCl₄ 平面内面对面重叠，对通过键轴中点且垂直键轴的平面具有对称性——确立金属原子簇（金属-金属多重键）概念。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **21-4**：铬铁矿→K₂Cr₂O₇；软锰矿→KMnO₄；辉钼矿→Mo；黑钨矿→W 全流程。
- **21-5(1)**：分离 Cr³⁺/Al³⁺、Cr³⁺/Mn²⁺、Mn²⁺/Cu²⁺。
- **21-5(4)**：(NH₄)₂S₂O₈/PbO₂/NaBiO₃ 鉴定 Mn²⁺。
- **21-6(2)**：CrCl₃·6H₂O 溶液绿→煮沸→蓝紫（水合异构转化）。
- **21-6(3)**：[Cr(H₂O)₆]³⁺ 中 NH₃ 逐级取代颜色变化。
- **21-6(4)**：Mn(OH)₂ 白→棕黑→酸不溶→H₂O₂ 溶解。
- **21-7(1)-(4)**：Cr/Mn 推理判断四组。
- **21-8(3)**：Cr(II) 除 N₂ 中痕量 O₂。
- **21-8(4)**：K₂Cr₂O₇ 能否氧化 1M/12M HCl 计算（E° 相等 → 浓度）。
- **21-8(6)**：溶解氧测定全链 + O₂:Na₂S₂O₃ 物质的量比。
- **21-8(7)**：五个实验现象+方程式（CrCl₃+NaOH、K₂CrO₄+H₂O₂+硫酸、MnCl₂+NaOH+H₂O₂、Na₂SO₃+KMnO₄ 三种介质、K₂MnO₄+水）。

### 常见错误模式
1. **Cr³⁺ 遇 Na₂S/Na₂CO₃**：得 Cr(OH)₃ 而非 Cr₂S₃/Cr₂(CO₃)₃（高电荷水解）。
2. **KMnO₄ 产物不看介质**：中性/碱性不能写 Mn²⁺；酸性不能写 MnO₂/MnO₄²⁻。
3. **Mn²⁺ 鉴定 Mn²⁺ 过量**：过量 Mn²⁺ 与 MnO₄⁻ 生成 MnO₂，紫色被掩盖。
4. **CrO₅ 氧化数**：Cr 化合价 +6，但形式氧化数为 +10（过氧链）。
5. **CrO₄²⁻⇌Cr₂O₇²⁻**：加酸向橙，加碱向黄；沉淀 Ba²⁺ 时是 BaCrO₄（铬酸盐）不是重铬酸盐。
6. **[Re₂Cl₈]²⁻ 键**：四重键 = σ+2π+δ，缺一不可；δ 键是 d_xy 面对面。
7. **MnO₂ 两性**：既有酸性（+碱→MnO₃²⁻）又有碱性（+浓 HCl→MnCl₄/Cl₂）。
8. **MnO₄²⁻ 稳定性**：只在强碱中稳定，稀释/酸化即歧化。
