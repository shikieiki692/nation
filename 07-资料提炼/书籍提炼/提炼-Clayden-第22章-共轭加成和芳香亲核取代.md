# Clayden 第22章：共轭加成和芳香亲核取代 资料提炼

---

## 一、核心概念与定义

### 1.1 共轭加成（Conjugate Addition / Michael Addition）
- **定义**：亲核试剂进攻与吸电子基团（如C=O、CN、NO₂）共轭的烯烃的β碳，而非直接进攻羰基碳的加成反应。
- **别名**：1,4-加成、[[Michael加成]]（迈克尔加成）。
- **适用底物**：α,β-不饱和羰基化合物（Michael受体），包括烯醛（enal）、烯酮（enone）、不饱和酸、酯、酰胺、腈、硝基化合物。
- **核心特征**：亲核试剂加成到C=C双键上，羰基保留。

### 1.2 α,β-不饱和羰基化合物
- **命名**：α碳 = 与C=O相邻的碳；β碳 = 沿链再下一个碳。
- **常见类别**：
  - α,β-不饱和醛（烯基醛，enal）
  - α,β-不饱和酮（烯基酮，enone）
  - α,β-不饱和酸、酯、酰胺
- **极化特征**：共轭使C=C双键极化，β碳带部分正电荷，成为亲电位点。
- **光谱证据**：IR中C=O从1715 cm⁻¹红移到1675 cm⁻¹，C=C从1650 cm⁻¹红移到1615 cm⁻¹且强度增加；¹³C NMR中β碳化学位移降至约140 ppm。

### 1.3 1,2-加成 vs 1,4-加成选择性
- **1,2-加成（直接加成）**：亲核试剂进攻羰基碳，产物保留C=C双键。
- **1,4-加成（共轭加成）**：亲核试剂进攻β碳，产物保留C=O双键。
- **控制因素**：
  - 反应条件（动力学vs热力学控制）
  - 底物结构（羰基活性、β碳空阻）
  - 亲核试剂性质（硬/软分类）

### 1.4 芳香亲核取代（Nucleophilic Aromatic Substitution, SNAr）
- **定义**：亲核试剂取代芳环上离去基团的反应，通常需要芳环上有吸电子活化基团。
- **三种机理**：
  - 加成-消除机理（SNAr，经Meisenheimer复合物）
  - 消除-加成机理（经苯炔中间体）
  - SN1机理（经重氮盐）

### 1.5 Meisenheimer复合物
- **定义**：芳香亲核取代加成-消除机理中的阴离子中间体，由亲核试剂加成到芳环上形成，负电荷离域在环上五个sp²碳原子上。
- **特征**：sp³杂化的碳原子（亲核试剂进攻的碳）打破了芳香性，负电荷主要分布在进攻位点的邻位和对位。

### 1.6 苯炔（Benzyne）
- **定义**：一种极不活泼的中间体，含有一个位于苯环中的"三键"——一根正常的芳环π键 + 一根由两个环外sp²轨道侧面重叠形成的异常π键。
- **形成**：强碱先移除离去基团邻位的质子，然后离去基团离去。
- **反应**：苯炔具有亲电性，可被亲核试剂进攻，进攻发生在三键两侧（消除-加成机理）。

## 二、重要反应与机理

### 2.1 Michael共轭加成

#### 一般机理
1. 亲核试剂（Nu⁻）进攻α,β-不饱和羰基化合物的β碳（LUMO最大轨道系数处）。
2. 生成烯醇盐中间体（负电荷离域在α碳和氧之间）。
3. 烯醇盐质子化（从溶剂获取质子）→ 产物为饱和羰基化合物。

#### 轨道解释（FMO理论）
- 丙烯醛的LUMO中，最大轨道系数位于β碳 → 亲核试剂优先进攻β碳。
- 第二大轨道系数位于羰基碳 → 也可发生1,2-加成（取决于条件）。

#### 亲核试剂范围
- 氰离子（CN⁻）、胺（R₂NH）、醇（ROH）、硫醇（RSH）、卤离子（Br⁻、Cl⁻）、有机铜试剂（R₂CuLi）等。

#### 烯醇盐/烯醇中间体
- 共轭加成的直接产物是烯醇盐，需质子化才能得到最终产物。
- 质子化通常在质子溶剂（醇、水）中进行。
- 碱催化条件下，催化量的碱即可（碱消耗后由烯醇盐再生）。

### 2.2 1,2- vs 1,4-加成选择性

#### 动力学控制 vs 热力学控制
- **动力学产物（1,2-加成）**：低温、短时间 → 生成快（C=O上静电吸引更大）。
- **热力学产物（1,4-加成）**：高温、长时间 → 更稳定（C=O π键比C=C π键更强，共轭加成保留C=O）。
- **实例**：氰离子 + 烯基酮 → 低温得氰醇（1,2-加成），加热得共轭加成产物。

#### 底物结构影响
- **活泼C=O（醛、酰氯）**：倾向直接加成（1,2-加成）。
- **不活泼C=O（酰胺、酯）**：倾向共轭加成（1,4-加成）。
- **β碳空阻大**：不利于共轭加成。

#### 硬/软亲核试剂理论
- **硬亲核试剂**（F⁻、OH⁻、RO⁻、NH₃、RMgBr、RLi）：电荷控制，倾向进攻较硬的羰基碳（1,2-加成）。
- **软亲核试剂**（I⁻、RS⁻、RSe⁻、RSH、R₃P、烯烃）：轨道控制，倾向进攻较软的β碳（1,4-加成）。
- **分界线**：N₃⁻、CN⁻、Br⁻ 居中。

#### 铜盐促进共轭加成
- 格氏试剂（硬）通常进攻C=O → 1,2-加成。
- 加入催化量CuCl → 转金属生成有机铜试剂（软）→ 共轭加成。
- **铜酸锂（R₂CuLi）**：由2当量RLi + 1当量CuBr在-78°C制备，对α,β-不饱和酮专一性共轭加成。
- **TMSCl促进**：CuLi加成 + TMSCl → 烯醇硅醚 → 水解回酮。

#### 总结表
| 因素 | 有利于共轭加成 | 有利于直接加成 |
|:---|:---|:---|
| 反应条件 | 高温、长时间（热力学控制） | 低温、短时间（动力学控制） |
| C=O活性 | 不活泼（酰胺、酯） | 活泼（醛、酰氯） |
| β碳空阻 | 无空阻 | 有空阻 |
| 亲核试剂 | 软（硫醇、有机铜） | 硬（有机锂、格氏试剂） |

### 2.3 共轭取代（Conjugate Substitution）
- 当β碳上带有离去基团（如Cl）时，共轭加成转变为共轭取代（加成-消除机理）。
- **机理**：亲核加成 → 烯醇中间体 → 消除离去基团 → 恢复双键。
- **插烯（Vinylogous）行为**：共轭双键充当电子桥，使远处官能团化学性质与直接相连类似。

### 2.4 亲核环氧化
- **试剂**：氢过氧根（HO₂⁻），由H₂O₂ + NaOH生成。
- **机理**：共轭加成 → E1cB消除失去OH⁻ → 环氧产物。
- **与m-CPBA对比**：
  - m-CPBA：一步协同，立体专一性（顺式烯烃→顺式环氧）。
  - 亲核环氧化：两步，中间体可旋转 → 通常得更稳定的反式环氧。
- **适用底物**：α,β-不饱和羰基化合物和其他缺电子烯烃（亲电环氧化剂不起作用的底物）。

### 2.5 不饱和腈和硝基化合物的共轭加成
- **丙烯腈**：氰基是不活泼的亲电位点，亲核试剂专一进攻C=C。
- **氰乙基化**：胺 + 丙烯腈 → 氨基腈（工业重要反应）。
- **硝基烯烃**：NO₂吸电子性约为C=O的两倍，共轭加成非常可靠。

### 2.6 芳香亲核取代——加成-消除机理（SNAr）

#### 基本条件
- 芳环上需有吸电子活化基团（NO₂、COR、CN、SO₂R等），位于离去基团的邻位和/或对位。
- 离去基团通常为卤素（F > Cl > Br > I，氟因诱导效应加速决速步）。
- 亲核试剂：基于O、N或CN的亲核试剂。

#### 机理步骤
1. **加成**（决速步，慢）：亲核试剂加成到芳环上，形成[[Meisenheimer复合物]]（阴离子中间体，芳香性暂时丧失）。
2. **消除**（快）：离去基团离去，恢复芳香性。

#### 氟的特殊活性
- [[SNAr]]中氟代化合物反应最快（比Cl/Br快10²-10³倍）。
- **原因**：决速步是加成步骤，氟的强电负性通过诱导效应稳定阴离子中间体，加速加成。氟离子的离去性（影响消除步骤）不影响总速率。

#### 阴离子稳定基团活性比较
- NO₂（最好）> SO₂R（18倍慢）> CN（32倍慢）> COR（80倍慢）
- 硝基可通过芳香亲电取代（硝化）引入到卤素邻对位。

#### Meisenheimer复合物的证据
- ¹³C NMR显示：阴离子中间体的邻位和对位碳化学位移大幅移向高场（电子密度增高），而间位变化很小。
- 阳离子（Wheland中间体）的邻对位碳则移向低场。
- 两种离子的邻对位碳化学位移相差约100 ppm。

#### 选择性取代实例
- 硝基邻位的氯被取代，间位的氯保留（负电荷不能推到间位硝基上）。

### 2.7 芳香亲核取代——SN1机理（重氮盐）

#### 重氮化反应
- **试剂**：NO⁺（由NaNO₂ + HCl在0-5°C生成）。
- **机理**：ArNH₂ + NO⁺ → ArN₂⁺ + H₂O。
- **稳定性**：芳基重氮盐在0-5°C稳定；烷基重氮盐立即分解。

#### 芳基重氮盐的取代
- **水解**：ArN₂⁺ + H₂O → ArOH + N₂ + H⁺（制备苯酚）。
- **Sandmeyer反应**：Cu(I)盐催化 → ArCl、ArBr、ArCN。
- **KI**：ArN₂⁺ + KI → ArI。
- **一般流程**：ArH → ArNO₂（硝化）→ ArNH₂（还原）→ ArN₂⁺（重氮化）→ ArZ（亲核取代）。

#### 药物合成应用
- 百里胺（thymoxamine）合成：利用重氮化-水解引入第二个羟基，实现区域选择性。

### 2.8 芳香亲核取代——消除-加成机理（苯炔）

#### 苯炔的形成
1. 强碱（如NaNH₂）移除离去基团邻位的质子 → 芳基阴离子。
2. 离去基团（如Br⁻）消除 → 苯炔（异常三键）。
3. 亲核试剂加成到苯炔三键上 → 产物。

#### 苯炔的结构
- 一根正常的π键（芳环的一部分）+ 一根异常的π键（两个环外sp²轨道侧面重叠）。
- 异常π键很脆弱 → 苯炔极不稳定、高活性。

#### 区域选择性
- 三键两侧原则上都可被进攻。
- **吸电子基（如OMe）**：通过诱导效应，亲核试剂倾向于在靠近吸电子基的位置生成阴离子（但空阻效应也起作用）。
- **给电子基**：产物中亲核试剂在间位（远离给电子基的位置）。

#### 证据
- 苯炔可被D-A反应捕获（如蒽 + 苯炔 → 笼状结构）。
- 质谱中可观察到苯炔二聚体（m/z 152）和苯炔本身（m/z 76）。
- 由邻氯芳基醚经苯炔机理得到间位取代产物（不符合直接取代预期）。

## 三、关键结论与规则

### 3.1 共轭加成核心规则
1. 与C=O共轭的C=C双键是亲电的（β碳带部分正电荷）。
2. 共轭加成是生成烯醇盐的另一种方式。
3. 产物保留C=O π键（比C=C π键更强）→ 共轭加成是热力学有利的。
4. 软亲核试剂（如硫醇）是共轭加成的最佳选择。

### 3.2 芳香亲核取代核心规则
1. sp²碳上不发生SN2反应（背面进攻被芳环阻挡）。
2. SN1需要极好的离去基团（如N₂⁺）。
3. 加成-消除机理需要吸电子活化基团在离去基团的邻对位。
4. 氟在SNAr中因诱导效应加速决速步（非离去性好）。
5. 苯炔机理适用于无活化基团的芳基卤（需强碱条件）。

### 3.3 软硬酸碱理论在共轭加成中的应用
- 硬亲核试剂 → 硬亲电中心（C=O碳）→ 1,2-加成。
- 软亲核试剂 → 软亲电中心（β碳）→ 1,4-加成。
- 有机铜比格氏试剂更软（Cu电负性1.9 > Mg电负性1.3，C-Cu键极化少）。
