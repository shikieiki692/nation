## 三、教学逻辑锚点

1. **钝化与活性反差**：Ti E°(Ti²⁺/Ti)=-1.628 V、V E°(V²⁺/V)=-1.175 V 都是活泼金属，但常温惰性、高温却极活泼（Ti 是唯一可在氮气中燃烧的金属）——金属钝化膜的化学理解。
2. **同族相似与分离**：镧系收缩 → Zr/Hf 原子半径几乎相同 → 性质极相似、分离极难；Nb/Ta 同理。分离方法（分步结晶→离子交换→溶剂萃取）是竞赛"分离提纯"考点的标准素材。
3. **钒的氧化态彩虹**：VO₂⁺(黄)/VO²⁺(蓝)/V³⁺(绿)/V²⁺(紫)——氧化还原滴定全程变色，配合 KMnO₄ 滴定与 Zn 还原，是元素电势图最直观的实践。
4. **高价态水解共性**：Ti⁴⁺ 电荷高半径小 → 强电场 → 水解成 TiO²⁺ 钛氧根（连接 [[钛氧双键]]）；V(V) 在水溶液随 pH 聚合形成多酸（连接 [[钒的多酸]]）。
5. **工业流程思维**：钛的冶炼全链（硫酸浸取→水解→煅烧→氯化→镁还原）体现"富集→转化→还原"的冶金学通法。

## 四、核心内容提炼

### 20.1 钛副族元素（ⅣB：Ti、Zr、Hf）

**价层构型** (n-1)d²ns²。最稳定氧化态 +4，其次 +3，+2 少见；特定条件出现 0/-1。

#### 1. 存在与丰度
- Ti：地壳 0.56%，列第 9 位（过渡金属中仅次于 Fe），但分散难提故曾称"稀有金属"；矿物：金红石 TiO₂、钛铁矿 FeTiO₃、钙钛矿 CaTiO₃、榍石 CaTiSiO₃。
- Zr：0.0190%（超过 Cu/Zn/Sn/Ni/Pb），锆石 ZrSiO₄、斜锆石 ZrO₂。
- Hf：3.3×10⁻⁴%，与锆混生；**镧系收缩**使 Zr/Hf 化学性质极相似，分离比镧系还难。

#### 2. 钛单质
**物理性质**：灰金属；熔点 1670℃；密度 4.506 g/cm³（≈钢的 57%），强度硬度近钢——兼具钢的强度与铝的轻；纯钛塑性好（韧性>纯铁 2 倍）。
**化学性质**：
- 热力学活泼（E°(Ti²⁺/Ti)=-1.628 V）但常温被致密钝化氧化物膜保护，不与 X₂/O₂/H₂O/强酸碱/王水反应。
- 热浓酸：`2Ti + 6HCl(浓) △= 2TiCl₃ + 3H₂↑`（紫色 Ti³⁺）；`2Ti + 3H₂SO₄(浓) △= Ti₂(SO₄)₃ + 3H₂↑`。
- 热 HF（配位促溶）：`Ti + 6HF(aq) △= [TiF₆]²⁻ + 2H⁺ + 2H₂↑`。
- 硝酸使氧化膜完善 → 不反应；也不与热碱反应。
- **高温活泼**：`Ti + O₂ = TiO₂`；`3Ti + 2N₂ = Ti₃N₄`（唯一可在氮气氛燃烧的金属）；`Ti + 2Cl₂ = TiCl₄`；>300℃ 与 H₂ → TiH₂（灰色，1000℃ 完全脱氢，纯氢供源）。
**用途**：
- 钛合金：钛钢（坚韧弹性）；**钛镍 NT 合金**（形状记忆，管接头/天线）；**钛铌合金**（<4K 超导，高场磁体）；**钛铁合金**（吸氢储氢）。
- 医疗：不磁化、无毒、与人体组织相容 → 人造关节/接骨。
- 抗阻尼强 → 音叉、扬声器振动膜。

#### 3. 金属钛的提炼（工业流程）
1. 钛铁矿粉（磁选富集）+ 浓 H₂SO₄ 150~200℃：`FeTiO₃ + 3H₂SO₄ = Ti(SO₄)₂ + FeSO₄ + 3H₂O`（加 Fe 屑防 Fe²⁺ 氧化）。
2. 低温结晶析出 FeSO₄·7H₂O 分离；稀释加热使 Ti(SO₄)₂ 水解 → TiOSO₄ → 沉淀偏钛酸 H₂TiO₃。
3. 煅烧：`H₂TiO₃ 煅烧= TiO₂ + H₂O`。
4. 氯化（加焦炭热力学耦合）：`TiO₂ + 2Cl₂ + 2C △= TiCl₄ + 2CO`。
5. **镁还原**（Ar 气）：`TiCl₄(g) + 2Mg(l) 800℃= Ti + 2MgCl₂(l)`；水浸去盐 → 海绵钛 → 惰性气氛熔炼。
6. 新法（Nature 2000）：熔融 CaCl₂ 电解，石墨阳极、TiO₂ 压片阴极 → 海绵钛，降本。
7. 实验室：`TiO₂ + 2CaH₂ 900℃= Ti + 2CaO + 2H₂↑`（钼容器，H₂ 气氛/真空）。

#### 4. 二氧化钛
- 金红石：红/桃红色，Ti 6 配位八面体；含 Fe/Nb/Ta/Sn/Cr/V 杂质变黑。无水 TiO₂ 白色粉末（**钛白粉**），熔点 1912℃。
- **两性但酸碱均弱**：
  - 不溶水/稀酸；热浓 H₂SO₄：`TiO₂ + 2H₂SO₄(浓) △= Ti(SO₄)₂ + 2H₂O`；但实际因 Ti⁴⁺ 强电场水解，析出 `TiOSO₄`（钛氧根 TiO²⁺）。
  - 不溶稀碱；共熔：`TiO₂ + MgO = MgTiO₃`；`TiO₂ + BaCO₃ = BaTiO₃ + CO₂↑`（**BaTiO₃ 压电效应**、高介电常数 → 微型电容）。
- 用途：
  - 白色涂料之王（折射率高/着色力强/遮盖力大/化学稳定/无毒），优于锌白 ZnO、锌钡白 ZnS·BaSO₄。
  - **n 型半导体**：光激发产生电子-空穴 → 太阳能电池。
  - **光催化**：电子俘获 O₂ → 超氧阴离子；空穴氧化 H₂O/OH⁻ → 氢氧自由基 → 分解有机物（排气净化/水处理/防污，"环境友好催化剂"）。
- 制备：浓 H₂SO₄ 处理钛铁矿；`TiCl₄ + O₂ 高温= TiO₂ + 2Cl₂`。

#### 5. 钛酸及其盐
- **α-钛酸** Ti(OH)₄/H₄TiO₄：低温生成，活性大，溶酸碱。
- **β-钛酸**：煮沸水解生成，不活泼，不溶酸碱（强酸也不能抑制水解）：`Ti(SO₄)₂ + 4H₂O 煮沸= Ti(OH)₄↓ + 2H₂SO₄`。
- Ti(Ⅳ) 水合物实为 TiO₂·nH₂O；极化强 → 水溶液只得水解产物 TiOSO₄/TiO(NO₃)₂。
- **H₂O₂ 显色（鉴定）**：酸性橙、pH8 黄、强碱无色；浓 H₂SO₄ 中红色 Ti(O₂)SO₄——用于 Ti(Ⅳ) 或 H₂O₂ 比色。

#### 6. 四氯化钛
- TiX₄：TiF₄ 离子型（熔点 377℃），TiCl₄（-24.12℃ 无色液体）、TiBr₄（38.3℃）、TiI₄（155℃）共价型（熔点随共价性/分子量变化）。
- **极易水解冒白烟**：`TiCl₄ + 2H₂O = TiO₂↓ + 4HCl`（烟幕弹原理）；盐酸中部分水解：`TiCl₄ + H₂O = TiOCl₂↓ + 2HCl`。
- 浓盐酸成酸：`TiCl₄ + 2HCl(浓) = H₂[TiCl₆]`；加 NH₄⁺ 析出黄色 (NH₄)₂[TiCl₆]。
- 与醚/酮/胺加合；**齐格勒-纳塔催化剂**（(C₂H₅)₃Al + TiCl₄ → 烯烃定向聚合）。
- 制备须严格防潮：通 CO₂ 排干水汽，尾气装干燥管。

#### 7. 三氯化钛
- 紫色晶体 [Ti(H₂O)₆]Cl₃；乙醚萃取得绿色 [Ti(H₂O)₅Cl]Cl₂·H₂O——**水合异构**。
- **强还原性**：E°(TiO²⁺+2H⁺+e⁻=Ti³⁺+H₂O)=0.100 V < E°(Sn⁴⁺/Sn²⁺)=0.151 V → Ti(Ⅲ) 还原性比 Sn(Ⅱ) 强；极易被空气/水氧化，须乙醚/苯液封+棕色瓶。
- **分析应用**：Al 还原：`3TiO²⁺ + 6H⁺ + Al = 3Ti³⁺ + Al³⁺ + 3H₂O`；Fe³⁺ 滴定 + KSCN 指示（终点红色 K₃[Fe(SCN)₆]）；还原羟胺：`2NH₂OH + 2Ti₂(SO₄)₃ + 2H₂O = (NH₄)₂SO₄ + 4TiOSO₄ + H₂SO₄`。
- 制备：`2TiCl₄ + H₂ 800℃= 2TiCl₃ + 2HCl`；`3TiCl₄ + Ti 600℃= 4TiCl₃`；Zn + TiCl₄ 盐酸液还原。

#### 8. 锆和铪
- 性质：Zr/Hf 高温活泼，生成 MO₂/MC/MN/MB/MB₂/MX₄；锆粉吸 H₂/O₂/N₂/CO/CO₂；Zr 合金耐蚀高强度 → 热中子反应堆芯材料；Hf 只溶浓硫酸（年腐蚀 2~12 μm，耐蚀材料）。
- `Zr + 4KOH 共熔= K₄ZrO₄ + 2H₂↑`。
- **ZrO₂**：熔点高/热膨胀系数低/电阻率高 → 坩埚炉膛；立方 ZrO₂ 折射率近金刚石、莫氏硬度 8.5 → 首饰代钻；高温处理 ZrO₂ 除 HF 外不溶其他酸。
- 可溶锆盐 ZrOCl₂ 水解 → 锆酸 ZrO₂·xH₂O + 2HCl（比钛酸弱，两性）。
- **Zr/Hf 分离**：
  - 经典：K₂[HfF₆] 与 K₂[ZrF₆] 在氢氟酸中溶解度微差 → 反复重结晶。
  - 制备：`ZrSiO₄ + K₂[SiF₆] 高温= K₂[ZrF₆] + 2SiO₂`。
  - 现代：**离子交换法**（强碱型酚醛阴离子树脂吸附 [MF₆]²⁻，HF+HCl 淋洗先后分离）；**溶剂萃取法**（磷酸三丁酯/三辛胺-甲基异丁基酮，Zr 配位强先入有机相）。

### 20.2 钒副族元素（ⅤB：V、Nb、Ta）

**价层构型** (n-1)d³ns² 或 (n-1)d⁴ns¹。最高氧化态 +5；V 可 +5/+4/+3/+2（+5 最稳，+4 次之，+3/+2 不稳定）；Ta 主要 +5。配位化合物中可 -1/0/+1。

#### 1. 存在与冶炼
- V：地壳 0.0160%；绿硫钒石 VS₄、钒铅矿 Pb₅(VO₄)₃Cl。Nb 2.0×10⁻³%、Ta 3×10⁻⁴%（我国 Nb 储量第 2、Ta 储量第 1）；铌铁矿 (Fe,Mn)Nb₂O₆、钽铁矿 (Fe,Mn)Ta₂O₆。
- 冶炼（钢铁副产）：钒渣 FeO·V₂O₃ + NaCl/Na₂CO₃ 氧化焙烧 → 可溶 NaVO₃；水浸 → 调 pH 2~3 析出红色多钒酸盐 → 700℃ 熔融 → 工业 V₂O₅；还原：C 会生成难处理 VC，硅铁+石灰除 SiO₂，主要用 Fe 高温还原（作合金钢添加剂）。

#### 2. 钒单质
- 灰白、体心立方、熔点 1910℃（高于 Ti）；钒钢：强度大/弹性好/抗磨损/抗冲击。
- 活泼金属（E°(V²⁺/V)=-1.175 V）但钝化膜保护：不反应空气/水/碱/非氧化性酸（除 HF）。
- HF 配位：`2V + 12HF(aq) = 2H₃[VF₆] + 3H₂↑`。
- 氧化性酸：`V + 8HNO₃ = V(NO₃)₄ + 4NO₂↑ + 4H₂O`；溶熔融强碱。
- 高温：`4V + 5O₂ 660℃= 2V₂O₅`（低氧化态：VO 绿色、V₂O₃ 黑色、VO₂ 蓝黑）；`V + 2Cl₂ = VCl₄`（VF₅ 无色液、VCl₄ 红色液、VBr₃ 黑绿固体）。

#### 3. 钒的氧化物
| 氧化物 | 颜色/状态 | 酸碱性 | 关键反应 |
|--------|----------|--------|---------|
| V₂O₅ | 黄棕粉末，有毒微溶 | 两性（酸性为主） | `V₂O₅+6NaOH=2Na₃VO₄+3H₂O`；`V₂O₅+H₂SO₄(稀)=(VO₂)₂SO₄+H₂O`；`V₂O₅+6HCl(浓)=2VOCl₂+Cl₂+3H₂O`（氧化性） |
| VO₂ | 蓝黑 | 两性 | 溶酸→蓝色 VO²⁺；溶碱→VO₄⁴⁻ |
| V₂O₃ | 黑色 | 微碱 | 溶硝酸/HF，不溶其他酸；`V₂O₅+2H₂ △=V₂O₃+2H₂O` |
| VO | 灰黑 NaCl 型 | 碱性 | 强还原剂制得 |

- 制备：`2NH₄VO₃ >400℃= V₂O₅ + 2NH₃ + H₂O`；`2VOCl₃ + 3H₂O = V₂O₅↓ + 6HCl`。
- V(II) 氧化：`6VSO₄ + 2KMnO₄ + H₂O = 2V₂(SO₄)₃ + V₂O₃↓ + 2MnO₂↓ + 2KOH`。

#### 4. 钒的含氧酸盐（多酸核心）
- 酸根种类：正钒酸根 VO₄³⁻、偏 VO₃⁻、二聚 V₂O₇⁴⁻、多聚 VₙO₃ₙ₊₁⁽ⁿ⁺²⁾⁻。
- **pH 依赖聚合**（关键规律）：浓度低时单聚；pH>13 单聚 VO₄³⁻；pH 降低 → 二聚/四聚/五聚聚合度升高；pH=2 析出红色 V₂O₅；pH≤1 淡黄色 VO₂⁺。
- **特征颜色**：VO₂⁺ 黄 / VO²⁺ 蓝 / V³⁺ 绿 / V²⁺ 紫（竞赛常考）。
- H₂O₂：碱性-弱酸性黄色二过氧钒酸根 [VO₂(O₂)₂]³⁻；强酸红棕 [V(O₂)₂]⁺。
- 还原剂（H₂S/SO₂/Fe²⁺/HCOOH/H₂C₂O₄）→ 蓝色 VO²⁺：`2H₃VO₄ + H₂S + 4H⁺ = 2VO²⁺ + 6H₂O + S↓`；`2H₃VO₄ + HCOOH + 4H⁺ = 2VO²⁺ + CO₂ + 6H₂O`。
- 活泼金属（Zn/Al）→ 紫色 V²⁺：`2VO₂⁺ + 3Zn + 8H⁺ = 2V²⁺ + 3Zn²⁺ + 4H₂O`（黄→蓝→绿→紫）。
- **KMnO₄ 滴定 V²⁺**（颜色全程可观察）：`5V²⁺ + MnO₄⁻ + 8H⁺ = 5V³⁺ + Mn²⁺ + 4H₂O`；`5V³⁺ + MnO₄⁻ + H₂O = 5VO²⁺ + Mn²⁺ + 2H⁺`；`5VO²⁺ + MnO₄⁻ + H₂O = 5VO₂⁺ + Mn²⁺ + 2H⁺`。

#### 5. 钒的卤化物
- 五卤中**只有 VF₅ 能稳定存在**（无色液）；+2~+4 卤化物均已知（VF₄ 绿、VF₃ 黄绿、VCl₄ 红液、VCl₃ 红紫）；碘化物最不稳定；同氧化态卤素越重越不稳定。
- 歧化/热分解：`2VCl₃ △= VCl₄ + VCl₂`；`2VCl₄ △= 2VCl₃ + Cl₂↑`。
- 全部吸潮水解，水解趋势随氧化态升高而增加。

#### 6. 铌和钽
- Nb/Ta 灰高熔点金属（Ta 熔点 3017℃，仅次于 W）；Nb 塑性高、可锻可压、焊接好、耐蚀；Ta 坚硬难熔。
- 室温化学稳定（Ta 甚至不与王水反应）；溶 HF 或 HF-HNO₃ 混酸。
- 高温：`4Nb + 5O₂ = 2Nb₂O₅`；`4Ta + 5O₂ = 2Ta₂O₅`；300~350℃ + Cl₂ → NbCl₅/TaCl₅（黄色）。
- `3TaCl₅ + Ta₂O₅ 高温= 5TaOCl₃`。
- **Nb₂O₅**：白粉，两性，难溶；1200℃ H₂ → 纯 NbO：`Nb₂O₅ + 3H₂ 1200℃= 2NbO + 3H₂O`；C/Ca/Mg/Al 高温还原得含氧化物杂质 Nb。
- **Ta₂O₅**：白粉，两性，比 Nb₂O₅ 更稳定，2500℃/5×10⁵ Pa 仍不被 H₂ 还原；C 还原 1100℃：`Ta₂O₅ + 3C = 2TaO + 3CO↑`。
- 五卤化物均易升华、易水解；含氧酸具多酸形式。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **20-4**：用 Fe²⁺/Sn²⁺/Zn 还原 0.1 M VO₂⁺ 的终产物预测（电势图应用）。
- **20-5**：Zn-Hg 齐还原 V(V)→V(Ⅱ)、Nb(V)→Nb(Ⅳ)、不能还原 Ta——解释及意义。
- **20-6(1)(3)(4)**：Ti 溶热浓 HCl 紫色；Zn 还原 V(V) 黄→蓝→绿→紫；KMnO₄ 滴定 V²⁺ 颜色变化。
- **20-6(5)**：V₂O₅ 溶热浓盐酸黄色→变蓝+放气（Cl₂）。
- **20-7(1)(2)**：推理判断题（Ti 系：TiCl₄→TiO₂→TiCl₃→CuCl；V 系：NH₄VO₃→V₂O₅→NH₃→VO₂⁺/草酸→Zn 还原）。
- **20-8(2)**：TiO₂ 含量测定流程（Al 还原 + Fe³⁺/KSCN 滴定）。
- **20-8(5)**：TiX₄ 熔点规律解释（离子型 vs 共价型）。
- **20-8(6)**：VF₅ 存在而 VCl₅ 不存在；Nb/Ta 的 MCl₅ 存在。
- **20-8(7)**：V 电势图四问（溶解态/歧化/V³⁺/V 反应）。
- **20-8(8)**：[Ti(H₂O)₆]²⁺/⁴⁺/³⁺、[Zr(H₂O)₆]²⁺ 水溶液稳定性。

### 常见错误模式
1. **Ti/V 活性误判**：E° 负值=热力学活泼，但常温钝化膜保护；"不活泼"是动力学惰性不是热力学稳定。
2. **V₂O₅ 溶解产物**：碱中 Na₃VO₄ 而非"偏钒酸钠"单产物；酸中 (VO₂)₂SO₄ 含 VO₂⁺。
3. **钒的 pH 规律记反**：pH 越大聚合度越低（单聚），pH 越小聚合度越高（多聚→沉淀→VO₂⁺）。
4. **Ti(Ⅳ) 水溶液产物**：从水溶液得不到 Ti(SO₄)₂ 正盐，只能得 TiOSO₄（水解）。
5. **Zr/Hf 分离**：不是化学性质不同，而是"太相似"，用溶解度微差/离子交换/萃取。
6. **VF₅ vs VCl₅**：V 只有 VF₅ 稳定（V(V) 氧化性强，Cl⁻ 被氧化）；Nb/Ta 因半径大+氧化性弱有 MCl₅。
7. **TiCl₃ 保存**：强还原性，须液封+棕色瓶；用 Fe³⁺ 滴定 Ti³⁺ 时注意隔绝空气。
8. **TiX₄ 熔点序**：TiF₄ 离子型熔点最高（377℃），共价型随分子量增大熔点升高（Cl<Br<I），TiCl₄ 常温液态。
