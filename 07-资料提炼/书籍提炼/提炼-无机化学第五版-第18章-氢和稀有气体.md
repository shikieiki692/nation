## 四、核心内容提炼

### 18.1 氢

#### 1. 氢在周期表中的位置
- **ⅠA 说**：价电子构型 ns¹，能失去 1e⁻ 成 H⁺（但 H 电离能 1312 kJ/mol 远大于碱金属，且仅 1 个电子无 p 轨道）。
- **ⅦA 说**：电子层排布 1s¹，得到 1e⁻ 成 H⁻，与卤素相似（但 H 缺 p 轨道、缺 d 轨道，不能像卤素形成高价）。
- **ⅦA 说证据**：H 与碱金属形成 NaH（类 NaF），与非金属形成共价氢化物（类卤化氢）。
- **ⅣA 说**：H 电离能与 C 相近，与碳形成 CH₄ 等大量共价化合物。
- **结论**：H 是周期表中的一个特殊元素，不与任何一族完全相似。

#### 2. 氢的元素电势图（酸性/碱性介质）
```
酸性: H⁺ --0.000--> H₂ --(-2.25)--> H⁻
碱性: H₂O --(-0.828)--> H₂ --(-2.25)--> H⁻
```
- H₂ 到 H⁻ 的 -2.25 V 说明 H⁻ 是很强的还原剂。
- H₂ 在中性水中氧化还原稳定，但作为还原剂可还原许多氧化物。

#### 3. 氢的五种成键方式
| 成键类型 | 电子转移/共用 | 代表化合物 | 说明 |
|---------|--------------|-----------|------|
| 失电子 → H⁺ | H → H⁺ + e⁻ | H₂O/H₃O⁺/HCl | 水溶液中不存在游离质子，以 H₃O⁺ 存在 |
| 得电子 → H⁻ | H + e⁻ → H⁻ | NaH/LiH/CaH₂ | 碱金属/碱土金属高温下形成 |
| 共价键 | 电子对共用 | CH₄/NH₃/H₂O/HCl | 大多数氢化物 |
| 氢桥键（3c-2e） | 缺电子桥键 | B₂H₆ | H 连接两个 B，三中心两电子 |
| 氢桥配位键 | 桥式配位 | [Cr₂H(CO)₁₀]⁻ | H 桥连两个金属中心 |
| 金属型氢化物 | 电子气/间隙 | ZrH₁.₃₀/LaH₂.₈₇/PdH₀.₈ | 过渡金属吸藏 H 原子 |

#### 4. 氢键（补充说明）
- 氢键不是化学键，键能介于化学键与范德华力之间。
- 生物大分子：蛋白质肽键中羰基 O 与氨基 H 形成氢键（维持二级结构）；DNA 双螺旋靠互补碱基间氢键。
- 常见氢键：F—H···F（最强）、O—H···O、N—H···N。

#### 5. 氢的同位素与氢气性质
- **同位素**：氕 ¹H、氘 ²H（D）、氚 ³H（T，β⁻ 衰变→³He，半衰期 12.26 年）。D 含量 0.015%，T 天然极少（核反应产物）。
- **H₂ 分子**：键长 74 pm，键能 435.78 kJ/mol（介于单键 300-400 与双键 600 之间，用 1 个 σ 键描述）；熔点 -259.2℃、沸点 -252.879℃（20 K）。
- **化学活性**：
  - 常温与 F₂ 暗处反应（-250℃ 亦可）；与 O₂ 按 2:1 爆炸（空气中 6-67% 为爆炸范围），燃烧热 285.8 kJ/mol。
  - 高温与活泼金属：`H₂ + 2Na ==380℃== 2NaH`
  - 与 CO 合成甲醇：`CO + 2H₂ ==ZnO-Cr₂O₃== CH₃OH`
  - **原子氢（活性 H）** 还原性更强：`As + 3H → AsH₃`；`CuCl₂ + 2H → Cu + 2HCl`；`BaSO₄ + 8H → BaS + 4H₂O`（原子氢焰 4000℃）。

#### 6. 氢气制备
| 方法 | 条件/原理 | 备注 |
|------|----------|------|
| 实验室 | Zn + 稀盐酸/稀硫酸 | 含 PH₃/AsH₃/H₂S 杂质需纯化 |
| 电解水 | 25% NaOH（或 KOH）溶液 | 纯度高 |
| 氯碱工业 | 电解饱和食盐水副产 | 工业主要来源 |
| 天然气裂解 | CH₄ + H₂O → CO + 3H₂ | 转化制氢 |
| 水煤气法 | C + H₂O ==1000℃== CO + H₂；CO + H₂O ==Fe₂O₃ 450℃== CO₂ + H₂ | 变换反应 |

#### 7. 氢气用途
- 合成氨原料（哈伯法）。
- 金属氧化物/氯化物还原：`WO₃ + 3H₂ → W + 3H₂O`；`TiCl₄ + 2H₂ → Ti + 4HCl`（冶金）。
- 氢氧焰 3000℃ 切割焊接；原子氢焰 4000℃。
- 液态氢作火箭燃料；充气球（部分替代 He）。

#### 8. 氢化物三类
**（1）离子型（盐型）氢化物**
- 组成：碱金属/碱土金属（除 Be）+ H⁻。
- 典型：NaH、LiH（熔点 692℃）、BaH₂（1200℃）。
- **强还原性**：
  - `NaH + H₂O → H₂ + NaOH`（H⁻ 与水中 H⁺ 结合成 H₂）
  - `2CO₂ + BaH₂ ==△== 2CO + Ba(OH)₂`（连 CO₂ 都还原）
- **复合氢化物（重要）**：
  - `LiH + B₂H₆ → 2LiBH₄`
  - `4LiH + AlCl₃ → LiAlH₄ + 3LiCl`
  - `LiAlH₄ + 4H₂O → Al(OH)₃ + LiOH + 4H₂`（遇水猛烈放氢）
  - 用途：LiAlH₄/LiBH₄ 是有机化学中强还原剂（连接有机 KP：负氢转移）。
- 其他用途：`TiCl₄ + 4NaH → Ti + 4NaCl + 2H₂`；`UO₂ + CaH₂ → U + Ca(OH)₂`。

**（2）分子型（共价）氢化物**
- 组成：p 区元素 + H。
- 酸碱性：酸性（HCl/H₂S/HF）、碱性（NH₃）、中性（CH₄）。
- 水解：`SiH₄ + 4H₂O → SiO₂·nH₂O + 4H₂`（硼烷同）。
- 还原性：同族自上而下增强（如 HI > HBr > HCl > HF）。

**（3）金属型（间充）氢化物**
- 组成：d 区/f 区金属 + H。
- 特征：保持金属光泽导电性；整比（CrH₂/NiH/CuH/ZnH₂）与非整比（PdH₀.₈）。
- **Pd-Ag 合金膜扩散**可制超高纯氢（H 透过合金膜，杂质截留）。
- **储氢材料**（连接 [[储氢材料]] KP）：过渡金属/稀土合金吸藏 H₂，如 LaNi₅。

### 18.2 稀有气体

#### 1. 发现史
| 年份 | 元素 | 发现者/方式 |
|------|------|------------|
| 1868 | He | 日全食光谱（日冕黄线）→ 1895 地球上发现 |
| 1785/1894 | Ar | 卡文迪许残留气体 → Rayleigh/Ramsay |
| 1898 | Ne/Kr/Xe | Ramsay 液态空气分馏 |
| 1900 | Rn | 镭衰变产物 |

- 命名：希腊语 "inert gas"（惰性气体）/ "rare gas"（稀有气体）/ "noble gas"（贵族气体）。

#### 2. Bartlett 里程碑（1962）
- **关键对比**：Xe 第一电离能 1170 kJ/mol vs O₂ 第一电离能 1165 kJ/mol。
- 既然 O₂ 可被 PtF₆ 氧化成 [O₂]⁺[PtF₆]⁻，Xe 也应能——**合成出 Xe[PtF₆]**（橙黄色固体）。
- 意义：打破"零族无化合物"观念，开创稀有气体化学。

#### 3. 液态空气分馏与提纯
- 液态空气分馏：-196℃ N₂（先馏出）、-186℃ Ar、-183℃ O₂。
- 除杂：红热 Cu 丝除 O₂、灼热 Mg 粉除 N₂（生成 Mg₃N₂）。

#### 4. 各元素特性
| 元素 | 特性 |
|------|------|
| He | 最难液化（沸点最低 4.2K），2.2 K 以下超流（粘滞性近零），常压不固化；替代 H₂ 充气球（不燃） |
| Ne | 霓虹灯橙红色 |
| Ar | 焊接/冶炼惰性保护气（钛冶炼） |
| Kr/Xe | 氙灯"人造小太阳"；同位素医学应用 |
| Rn | 放射性（²²²Rn 半衰期 3.82 天，²²⁶Ra 衰变产物），致癌关注 |

#### 5. 氙的氟化物
**制备条件矩阵（关键考点）**：

| 产物 | 条件 | 配比 | 结构/杂化 |
|------|------|------|-----------|
| XeF₂ | 1000℃ | Xe 过量 | sp³d 直线形 |
| XeF₄ | 600℃ | Xe:F₂ = 1:5 | sp³d² 正方形 |
| XeF₆ | 300℃，6.18×10⁶ Pa | Xe:F₂ = 1:20 | sp³d³ 扭曲八面体 |

- 反应器：Ni 容器，表面 NiF₂ 保护层防腐蚀。
- 日光下玻璃管中 Xe + F₂ 可缓慢生成 XeF₂。
- **XeF₆ 不能用玻璃/石英容器**：`2XeF₆ + SiO₂ → 2XeOF₄ + SiF₄`。

**水解反应（差异考点）**：
- `XeF₂ + H₂O → Xe + ½O₂ + 2HF`（歧化回单质）
- `6XeF₄ + 12H₂O → 2XeO₃ + 4Xe + 24HF + 3O₂`（不完全水解，同时歧化）
- `XeF₆ + 3H₂O → XeO₃ + 6HF`（完全水解得三氧化氙）
- `XeF₆ + H₂O → XeOF₄ + 2HF`（部分水解得氙酰氟）

**强氧化性**：
- `XeF₂(aq) + 2I⁻ → Xe + I₂ + 2F⁻`
- `XeF₂ + H₂ → Xe + 2HF`
- `XeF₂ + H₂O₂ → Xe + 2HF + O₂`
- 可氧化 Cl⁻→Cl₂、Ce(Ⅲ)→Ce(Ⅳ)、Co(Ⅱ)→Co(Ⅲ)。

**温和氟化剂**：
- `XeF₄ + Pt → Xe + PtF₄`
- `XeF₂ + IF₅ → IF₇ + Xe`
- `XeF₄ + 2SF₄ → 2SF₆ + Xe`

#### 6. 氙的含氧化合物
- **XeO₃**：无色液体（分子态），强氧化性——氧化 Fe²⁺、NH₃、Br⁻、HCl、Mn²⁺、醇/酸（→CO₂）。
- **高氙酸盐**：`XeO₃ + 4NaOH + O₃ + 6H₂O → Na₄XeO₆·8H₂O + O₂`（臭氧氧化）。
- **XeO₄**：`Na₄XeO₆ + 2H₂SO₄ → XeO₄ + 2Na₂SO₄ + 2H₂O`；XeO₄ 极不稳定，**爆炸分解** `XeO₄ → Xe + 2O₂`。
- Xe—N、Xe—C 键化合物存在但不稳定。

#### 7. 其他稀有气体化合物
- **KrF₂**：90 K 低温放电合成；线形分子；**氧化性比 F₂ 更强**（最强氟化剂之一）。
- **RnF₂**：存在，Rn 具放射性研究受限。

#### 8. 稀有气体化合物结构
- **VSEPR**：XeF₂（sp³d，直线形，3 对孤对在赤道）；XeF₄（sp³d²，正方形，2 对孤对相对）；XeF₆（sp³d³，扭曲八面体，孤对位置不定）。
- **分子轨道（XeF₂）**：Xe 的 5pₓ 与两个 F 的 2pₓ 组合 → 3 条 MO（成键/非键/反键），净键级 = 1。np→nd 激发电子参与杂化。
- 习题 18-1 延伸：XeOF₄（sp³d²，四方锥）、XeO₃F₂（sp³d，三角双锥）——**需从 XeF₆ 水解角度推出**。

### 18.3 主族元素总结（全主族收口）

#### 1. 非金属单质三类型
| 类型 | 代表 | 说明 |
|------|------|------|
| 小分子 | 稀有气体（单原子）、F₂/Cl₂/O₂/H₂（双原子） | 分子间范德华力 |
| 多原子分子 | P₄/As₄/S₈/Se₈ | 环/簇结构 |
| 大分子 | 晶体硼/硅/金刚石、石墨（层状） | 共价网络 |

#### 2. 非金属单质化学性质
- 不与非氧化性酸反应；与碱歧化：`Cl₂/S/P + NaOH → 歧化`。
- `Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂`（硅在碱中放氢）。

#### 3. 氢化物递变三规律
| 性质 | 同周期（左→右） | 同族（上→下） |
|------|---------------|--------------|
| 热稳定性 | 增强 | 减弱 |
| 还原性 | 减弱 | 增强 |
| 酸性 | 增强 | 增强 |

#### 4. 含氧酸强度定量判据
- **离子势判据**（中心离子）：
  - √φ < 0.22 → 碱性（如 NaOH）
  - 0.22 < √φ < 0.32 → 两性（如 Al(OH)₃）
  - √φ > 0.32 → 酸性（如 H₂SO₄）
  - 其中 φ = 电荷/半径。
- **鲍林公式**：`K₁ = 10^(5n-7)`，n = 非羟基氧原子数。
  - 通式 ROₙ(OH)ᵧ；n 越大酸性越强。
  - 例：HClO₄（n=3）强酸；H₂SO₄（n=2）强酸；H₃PO₄（n=1）中强酸；H₄SiO₄（n=0）弱酸。

#### 5. 含氧酸盐热稳定性
- **总序**：硝酸盐/卤酸盐（最不稳）< 碳酸盐/硫酸盐（居中）< 磷酸盐/硅酸盐（最稳）。
- **阳离子影响**（极化/反极化）：
  - 电荷高、半径小 → 盐越不稳定（如 MgCO₃ 540℃ < CaCO₃ 900℃ < BaCO₃ 1360℃）。
  - Li₂CO₃ 700℃ 分解（Li⁺ 半径特小）；CdCO₃ 500℃ 分解（18 电子构型极化强）。
  - MgSO₄ 895℃ vs MgCO₃ 540℃——**硫酸盐比碳酸盐稳定**（S(VI) 抗反极化）。
- **熵效应解释硅酸盐最稳**：`CaCO₃ → CaO + CO₂↑` 放出气体熵增大，有利分解；硅酸盐分解无气体，熵增小，故极稳定。

#### 6. 含氧酸氧化还原五规律
1. 同周期最高价含氧酸氧化性**左→右增强**（H₂SiO₄ < H₃PO₄ < H₂SO₄ < HClO₄）。
2. 同元素**低价含氧酸氧化性 > 高价**：HClO > HClO₃ > HClO₄；HNO₂ > HNO₃；H₂SO₃ > H₂SO₄。
3. **盐 < 酸**（酸的氧化性强于对应盐）。
4. **浓酸 > 稀酸**。
5. **pH 影响**：H⁺ 在氧化型一侧，酸性增强则氧化性增强（如 MnO₄⁻/Cr₂O₇²⁻ 在酸中氧化性大增）。

#### 7. 溶解性：阴阳离子半径匹配
- 阴阳离子**半径相近** → 晶格能大 → 难溶（BaSO₄）。
- **半径差大** → 易溶：`NaClO₄ > KClO₄ > RbClO₄`（阳离子越大越难溶）。
- 电荷高 → 难溶（碱土草酸盐/碳酸盐/磷酸盐）。

#### 8. 主族金属通性
- 物理：三种堆积方式；原子化热越高金属键越强、熔点越高；Al 导电导热最佳；Sb/Bi 脆。
- 化学：失电子还原性；与金属/水/酸/碱反应规律；钝化（Al/Be 冷浓 HNO₃）；PbSO₄/PbCl₂ 覆盖阻碍反应。
- **两性金属**：Be/Al/Ga/In/Sn 与酸碱都反应。
- **高价态**：GeO₂/SnO₂/PbO₂/Sb₂O₅/Bi₂O₅ 酸性氧化物；GeS₂/SnS₂/Sb₂S₅ 溶于 NaOH/Na₂S（硫代酸盐）。
- **惰性电子对效应**：6s² 电子对难失，故 Tl(Ⅲ)/Pb(Ⅳ)/Bi(Ⅴ) 强氧化性（连接 Ch19 起过渡金属对比）。

#### 9. 次级周期性（重点难点）
- **第二周期**：N/O/F 电子亲和能反常（比第三周期小）；NH₃/H₂O/HF 因氢键沸点反常高；**对角线规则** Li-Mg、Be-Al、B-Si（第二周期与右下第三周期元素相似）。
- **第四周期**：Ga 半径 135 pm < Al 143.1 pm（3d¹⁰ 屏蔽差、有效核电荷大）；Ga(OH)₃ 溶于氨水而 Al(OH)₃ 不溶；H₂GeO₃ 酸性比硅酸强；**H₂SeO₄/HBrO₃/HBrO₄ 氧化性反常增强**。
- **第六周期**：惰性电子对效应最显著；PbO₂/NaBiO₃ 强氧化剂（如 PbO₂ 氧化 Mn²⁺→MnO₄⁻）。
- **本质**：2p/3d/4f 轨道第一次填满，有效核电荷与半径出现"跳跃式"变化。

## 七、教材例题与常见错误

### 教材习题精选（用于审计/练习录入）
- **18-1**：XeF₂、XeOF₄、XeO₃F₂ 中心原子杂化方式与空间构型（答案：sp³d 直线 / sp³d² 四方锥 / sp³d 三角双锥）。
- **18-2**：用 MO 理论比较 HeH、HeH⁺、He₂⁺、He₂ 的稳定性（键级：1、1/2、1/2、0）。
- **18-3**：将 BaH₂、SiH₄、NH₃、AsH₃、PdH₀.₉、HI 分类为离子型/分子型/金属型氢化物。
- **18-4（拓展）**：稀有气体化合物的水解产物书写。

### 常见错误模式
1. **XeF₄ 水解产物误写**：不能写成单一产物，实际为 `2XeO₃ + 4Xe + 24HF + 3O₂` 的不完全水解歧化（6XeF₄+12H₂O）。
2. **氢化物分类混淆**：NaH 是离子型不是共价；PdH₀.₉ 是金属型非整比；HI 是分子型但强酸性。
3. **鲍林公式误用**：n 是**非羟基氧**数，不是总氧数；通式须先化为 ROₙ(OH)ᵧ。
4. **含氧酸氧化性次序记反**：HClO > HClO₃ > HClO₄（低价强于高价）；H₂SeO₄ 反常强于 H₂SO₄。
5. **热稳定性序误判**：硫酸盐 > 碳酸盐（S(VI) 抗反极化）；硅酸盐最稳（熵效应）。
6. **XeF₂ 构型**：sp³d 但只有 2 个 F 成键，3 对孤对在赤道 → 直线形；误写成 V 形。
7. **KrF₂ 氧化性**：氧化性强于 F₂（注意是"强于"不是"弱于"）。
