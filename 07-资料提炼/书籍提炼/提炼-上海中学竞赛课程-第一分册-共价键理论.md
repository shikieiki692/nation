# 提炼-上海中学竞赛课程-第一分册-共价键理论

> 来源：上海中学竞赛课程·化学·第1分册·第四讲 共价键理论

## 内容概要

本讲从经典共价键理论（路易斯理论、路易斯结构式书写与形式电荷）出发，详细讨论缺电子化合物、富电子化合物和奇电子化合物的特殊处理方法，然后依次介绍价键理论（杂化轨道：sp、sp²、sp³、sp³d、sp³d²）、配位键、σ键与π键，以及分子轨道理论（同核和异核双原子分子的分子轨道能级图）。本讲是理解分子结构与性质的核心理论基础。

---

## 核心知识点

### 1. 路易斯理论与路易斯结构式

- **八隅体规则**：原子通过共用电子对达到稀有气体电子构型（H为2电子，其余为8电子）
- **路易斯结构式书写步骤**：
  1. 判断中心原子（电负性小、半径大）和配位原子（电负性大、半径小）
  2. 计算共价键数 = (n₀ - nᵥ)/2，孤对电子数 = (nᵥ - 2×键数)/2（n₀为八电子构型电子总数，nᵥ为价电子代数和）
  3. 写出各种可能结构
  4. 计算形式电荷 QF = 价电子数 - 成键数 - 孤电子数
- **稳定性判据**：形式电荷尽可能小；避免相邻原子同号形式电荷
- **共振结构**：N₂O有两个等价的路易斯结构式，实际结构为两者的共振杂化体

### 2. 特殊类型化合物

- **缺电子化合物**（如BF₃、BeCl₂）：中心原子周围电子数<8，计算时修正n₀
- **富电子化合物**（如SF₆、PCl₅、XeF₆）：中心原子周围电子数>8，需修正中心原子电子构型
- **正常化合物**（如PCl₃、CO₂）：n=8，n为中心原子价电子数+配位原子达8电子所缺电子数
- **奇电子化合物**（如NO₂）：价电子总数为奇数，不符合八隅体规则
- **判断公式**：n = 中心原子价电子数 + 配位原子达8电子所缺电子数之和；n<8为缺电子，n=8为正常，n>8为富电子

### 3. 杂化轨道理论

- **sp杂化**：直线形，180°（如BeCl₂、CO₂、HCN）
- **sp²杂化**：平面三角形，120°（如BF₃、C₂H₄、HCHO）
- **sp³杂化**：四面体形，109.5°（如CH₄）；有孤对电子则压缩键角（NH₃三角锥107°，H₂O V形104.5°）
- **sp³d杂化**：三角双锥形（如PCl₅）；孤对电子占据赤道位置（如SF₄变形四面体、ClF₃ T形、XeF₂直线形）
- **sp³d²杂化**：正八面体形（如SF₆）；孤对电子导致变形（如BrF₅四方锥、XeF₄平面正方形）

### 4. σ键与π键

- **σ键**：头对头重叠，沿键轴可自由旋转，电子云集中于键轴
- **π键**：肩并肩重叠，不能自由旋转，电子云分布于键轴上下
- **判断**：单键=1σ；双键=1σ+1π；三键=1σ+2π

### 5. 分子轨道理论

- **核心思想**：原子轨道线性组合成分子轨道（LCAO），成键轨道能量降低，反键轨道能量升高（标*）
- **同核双原子分子**：
  - N₂及之前：σ1s²σ*1s²σ2s²σ*2s²π2p⁴σ2p²（键级=3）
  - O₂及之后：σ1s²σ*1s²σ2s²σ*2s²σ2p²π2p⁴π*2p²（键级=2，有2个未成对电子→顺磁性）
- **键级** = (成键电子数 - 反键电子数) / 2
- **磁性判断**：有未成对电子→顺磁性（如O₂）；全部成对→逆磁性（如N₂）

## 竞赛要点

1. **路易斯结构式的快速书写**：竞赛中需要快速判断中心原子、计算共价键数和形式电荷，特别是处理富电子化合物（如XeF₂、XeF₄、XeF₆）
2. **VSEPR与分子构型的精确判断**：孤对电子数决定分子构型（如SF₄为变形四面体而非三角双锥），竞赛常考非常规构型
3. **杂化方式的灵活判断**：不能仅凭分子式判断，需结合路易斯结构式确定孤对电子数；同一元素不同氧化态杂化方式不同
4. **分子轨道能级图的绘制与键级计算**：O₂的顺磁性是分子轨道理论的经典成功案例，也是竞赛高频考点
5. **σ键与π键的判断**：共轭体系中π键的离域效应是竞赛进阶内容

## 例题与习题

### 典型例题

**例1**：写出N₂O的路易斯结构式，计算形式电荷，判断稳定性。

**解题思路**：共价键数=(3×8-2×5-6)/2=4，孤对电子数=4。三种可能结构中，结构Ⅰ和Ⅱ形式电荷较小且无同号相邻，互为共振结构式；结构Ⅲ相邻原子同号形式电荷，不稳定。

**例2**：判断PCl₅中P的杂化方式和分子构型。

**解题思路**：P有5个价电子，与5个Cl形成5个σ键，无孤对电子→sp³d杂化→三角双锥形。
