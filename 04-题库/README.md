## 🆕 新题入库规范（2026-08-31 评估结论）

### 问题：新题目应该"单独归类管理"还是"直接并入现有题库"？

| 维度 | 方案 A：单独归类（先进暂存区） | 方案 B：直接并入现有题库 |
|:---|:---|:---|
| 质量闸门 | ✅ 先审查后入库，问题题不会污染正式区 | ❌ 未审即入，历史教训（53 处纯题号标题、汇智 17 处缺题引用、批量 YAML 损坏）均为"生成后直入"欠下的债 |
| 可用性 | ❌ 审核前不可进成书/检索（需多一步迁移） | ✅ 满足 `pack: 模块习题集` + `subject_module` 即被构建收集，立即可用 |
| 与正式区互引 | ❌ 暂存题无法被正式题稳定引用 | ✅ 同库互引自然 |
| 批量支持 | ✅ 整批转录题集中审查、集中迁移 | ❌ 批量直入易带格式/命名问题 |
| 维护成本 | 多一套目录 + 迁移动作 | 无第二套体系，最简 |
| 现有设施 | `10-待审核区/` 工作流（P0/P1/P2 分级）已设计好、当前为空，零成本复用 | —— |

### 建议：分层入库制（A+B 结合，入库即合格）

1. **默认走待审核区**（复用 `10-待审核区/` 的 P1 流程）：AI 生成题、批量转录题、未核验新题 → 命名 `待审-题目-{名称}-{日期}.md` → 审核（fidelity 标注 + 六字段 + 命名 + 来源核验）→ 迁移并入 `04-题库` 对应子库，并在工作日志记录迁移
2. **小额已核验题直接入库**（P0）：人工确认过的单题/少量题，直接进正式区（保留 `fidelity: 原书逐字` 标注）
3. **入库门槛（不满足先回待审区）**：
   - 文件名带主题词（**禁止纯题号/编号当标题**，对应历史 53 处 `## 1.3 05-07` 教训）
   - `fidelity` 字段必填（🟢原书逐字 / 🟡原书改写 / 🔵自编）
   - `cross_references` 只指向**存在的**文件（对应汇智 17 处缺题引用教训）
   - `pack`/`subject_module` 正确（决定是否进成书）
   - YAML 通过 `audit_question_bank` / `scan_source_integrity` 检查
4. **与构建天然隔离**：暂存区在 `10-待审核区/`（不在 `04-题库/`），构建的 `gather_questions` 扫描不到——新题在审核期间不会意外进成书/Word，无需改构建
5. **质量优先原则**（用户决策 2026-08-31）：不做难度分级，按题目质量（fidelity 标签 + 来源 + 勘误记录）区分筛选；难度字段保留但不再重标定

**核心逻辑**：质量闸门前置（入库即合格）> 事后返工。一次审查到位，胜过批量入库后逐个修。

> 用户决策：**宁可题目数量少，也要保证每道题的质量与训练价值。** 数量不作为维护目标。

   - 与化学竞赛考纲完全无关（`syllabus_related` + 02-考纲条目词表判定）
   - 篇幅过短（正文去标记后 < 60 字且无图）
   - 缺乏解析（答案为占位符或近似空）
2. **降级而非删除**：不达标题执行 `pack: 模块习题集` → `章节练习` 并追加 `demoted` 标记（用 `demote_questions.py`），可随时恢复；降级记录登记于 `07-资料提炼/习题书剔除清单.json`
3. **入书门槛**（提升用 `promote_questions.py`，缺必填字段自动拦截）：`fidelity`/`submodule`/`source`/`subject_module`/`exam_stage` 五字段齐备 + `type: 题目`（例题也写 `type: 题目`，用 `question_type: 例题` 区分）+ 分类可命中
4. **分类以质量为先**：分类审计用 `audit_book_classification.py`（重放构建管线交叉验证），分类修复后按 fidelity 优先排序（🟢逐字 > 🟡改写 > 🔵自编）
5. **元数据缺失≠低质量**：无 `syllabus_codes` 等元数据的题先登记待补（如 `07-资料提炼/习题书-待补syllabus元数据清单.md`），不因元数据缺失而降级
