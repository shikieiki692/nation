# 题库按用途分类说明

> **本页定位**：回答「题库按用途分几类、每类用什么源、后续怎么排」的**单一事实源**。
> **上游**：[[04-题库/题库架构总览]]（字段规范与目录地图）、[[04-题库/习题集体系总纲]]（分层策略与历史决策）。
> **本页与上游的分工**：上游回答「体系长什么样」；本页回答「**每次出卷时，我该从哪一类里、按什么来源口径取题**」——即**用途 → 来源策略**的映射。
> **效力**：本页 §三《组卷来源策略》为**用户 2026-09-19 拍板口径**，此后新建/重构任何卷册按此执行。

## 〇、一句话结论

**题库按用途分四层，但「分几类」的问题只在前三层有确定答案；第四层（成品）才是你日常实际拿到手的东西。**

| 层 | 回答的问题 | 归属由什么决定 | 现状规模 |
|:--|:--|:--|--:|
| 第 0 层 · 仓储 | 这一题**是什么** | 来源（目录） | 5,689 题 |
| 第 1 层 · pack 分层 | 怎么**用** | `pack` 字段 | 4 层 |
| 第 2 层 · 三模块视图 | 给**谁**做 | `teaching_level` 字段 | 3 视图 |
| 第 3 层 · 成品载体 | 实际**发什么** | 卷册文件 | 5 类 / 301 份 Word |

> ⚠️ **层与层是同源多视角，不是文件夹互斥**。同一道题在四层里各持一个属性，**文件永不搬家**。这是理解本页的前提，也是「找不到『测试题』文件夹」的原因——它压根不该是文件夹。

## 二、术语澄清：为什么你「搞不清状况」

「习题集 / 测试题 / 练习题」这三个词之所以怎么摆都对不上，是因为**它们分属三个不同维度**：

| 词 | 它其实是 | 所在维度 | 官方字段值 |
|:--|:--|:--|:--|
| **习题集** | 一个**视图名**（课内档） | 第 2 层 | `teaching_level ∈ {基础, 巩固}` |
| **测试题** | 视图名（竞赛档）**＋** 一类成品卷 | 第 2 层 ＋ 第 3 层 | `teaching_level=竞赛` ＋ ③④ 卷 |
| **练习题** | **不是类别**，是口语统称 | 无 | `pack=章节练习` |
| **习题书** | 视图名（拔高档）**＋** 一类成书 | 第 2 层 ＋ 第 3 层 | `teaching_level=拓展` |
| **考核卷** | 一类成品卷（09-16 新增形态） | 第 3 层 | 无字段，卷册文件 |

**一句话**：①②是「习题集」的两种落地（随堂 / 成书）；③④是「测试题」的两种落地（单科卷 / 成套卷）；「练习题」是①②的口语统称。

## 三、⭐ 组卷来源策略（用户 2026-09-19 拍板，本页核心）

### 3.1 三条原则原文

> **用户原话**：「课堂和课后习题，主要用普通大学教材和一些竞赛教材；测试题和拔高练习题（竞赛导向），主要用竞赛教辅和教材和一些模拟题或者老真题；测试卷（竞赛），主要用竞赛教辅，竞赛模拟题和机构题和真题。」

整理成表：

| 用途层 | 对应成品 | 主用来源 | 允许来源 | 禁用来源 |
|:--|:--|:--|:--|:--|
| **① 课堂·课后习题** | 随堂习题集 | 普通大学教材课后习题、竞赛教材 | 教材例题、自编章节题 | 真题、机构模拟（可少量点缀） |
| **② 拔高练习·竞赛导向** | 习题书（拓展） | 竞赛教辅、竞赛教材 | 模拟题、老真题 | 纯大学教材课后题（d≤3 部分） |
| **③ 测试卷·竞赛** | 阶段测试卷、考核卷 | 竞赛教辅、竞赛模拟题、机构题、真题 | 竞赛教材高档题 | 大学教材课后习题、自编题 |

### 3.2 ⚠️ 与现有体系的结构性冲突（必须先看清）

**若把上面三条直接翻译成「改 `teaching_level`」，需要改 3,186 题 = 全库 56.0%**。逐项拆解：

| 现状 | 按新原则应改为 | 题数 |
|:--|:--|--:|
| 竞赛教材 · 竞赛档 | → 拓展 | 881 |
| 教材课后习题 · 竞赛档 | → 基础/巩固 | 443 |
| 教材课后习题 · 拓展档 | → 基础/巩固 | 421 |
| 竞赛教辅 · 无字段（二分册逐题） | → 拓展/竞赛 | 356 |
| 竞赛教材 · 巩固档 | → 拓展 | 268 |
| 自编章节题 · 拓展档 | → 基础/巩固 | 148 |
| 竞赛教材 · 基础档 | → 拓展 | 141 |
| 竞赛教辅 · 巩固档 | → 拓展/竞赛 | 134 |
| 真题（省级）· 巩固档 | → 竞赛 | 119 |
| 真题（省级）· 拓展档 | → 竞赛 | 88 |
| 真题 · 巩固档 | → 竞赛 | 55 |
| 其余零散 | | ~92 |
| **合计** | | **3,186** |

**冲突根因**：`teaching_level` 的语义是「**教学阶段 / 难度档位**」，来源的语义是「**考试指向性**」——两者是**正交维度**（《习题集体系总纲》已明示「来源 ≠ 难度」）。**把来源强行写进 teaching_level，等于用一个字段表达两件事**，会同时破坏两个维度。

**已存在的三处内部矛盾**（现状已不自洽，新原则会放大）：
1. 竞赛档中有 **443 题**是大学教材课后习题（占竞赛档 20.6%）——违反《总纲》规范第 3 条「评测层只入 A/B 类，C 类禁入」。
2. 拓展档（习题书档）中有 **578 题**属低指向性源（B-/C），占 39.0%——这正是你说的「习题书内容太多」的**量化证据**。
3. 基础+巩固档中有 **789 题**（46.3%）是竞赛导向源——与「课堂课后主要用大学教材」相悖。

### 3.3 ✅ 建议方案：不动 `teaching_level`，新增「组卷来源策略」维度

**核心主张：三条原则是「出卷时的取材规则」，不是「题目自身的属性」，因此不应写进题目字段，而应写进「卷的组卷规范」。**

| 对比项 | 方案 A：改字段（不推荐） | **方案 B：组卷策略表（推荐）** |
|:--|:--|:--|
| 改动量 | 3,186 题改 `teaching_level` | **0 题** |
| 是否破坏现有维度 | 是（来源/难度混为一谈） | 否 |
| 是否可回滚 | 难 | 仅改卷册 |
| 与《总纲》第 3 条关系 | 冲突 | 兼容（互为细化） |
| 落地成本 | 高（需全库重评 + 闸门复跑） | 低（写入组卷规范即可） |

**方案 B 的具体落地**：把 §3.1 表转写为**组卷器的取材过滤器**，写入 [[04-题库/组卷工作台]]：

```
卷型 = 随堂习题集  → filter: source_category ∈ {教材课后习题, 其他类型·教材例题, 其他类型·自编章节题}
                                 ∧ source_grade ∈ {C, B-}
卷型 = 习题书/拔高 → filter: source_category ∈ {竞赛导向·竞赛教辅, 竞赛导向·竞赛教材}
                                 ∧ source_grade ∈ {A, A-, B+, B}
卷型 = 阶段测试/考核卷 → filter: source_category ∈ {竞赛导向·竞赛教辅, 竞赛导向·真题, 竞赛导向·真题（省级）}
                                 ∧ source_grade ∈ {A, A-}
```

> **这样做的收益**：同一道题可以**既进随堂练习又进测试卷**（形态互补，题源必然重叠），而不需要在「它到底属于哪一类」上做二选一。这正是《总纲》「五种载体形式分工」的本意。

### 3.4 三原则的可行域验证（数据支撑）

按 §3.1 圈定来源后，**实际可用题量**：

| 用途 | 圈定来源 | 可用题量 |
|:--|:--|--:|
| ① 课堂·课后 | 大学教材课后习题 ＋ 教材例题 | **1,660** |
| ② 拔高练习 | 竞赛教辅 ＋ 竞赛教材 | **3,091** |
| ②+ 拔高练习（含老真题） | ＋ 真题 ＋ 省级真题 | **3,737** |
| ③ 测试卷 | 竞赛教辅 ＋ 真题 ＋ 省级真题 | **2,159** |

**结论：三条原则的来源池全部充足**（最小池 2,159 题，足够支撑多轮出卷）。原则本身**可行**，问题只在「用哪个字段承载」。

> ⚠️ **注意重号**：②③ 的池子有重叠（竞赛教辅同时供给拔高与测试）——这是**设计如此**，因为同一道竞赛教辅题既可作拔高练习、也可作测试卷。**不存在「一题只能属一类」的约束**。

## 四、习题书瘦身专项（你说「内容太多」的解法）

### 4.1 问题量化

| 指标 | 实测值 |
|:--|--:|
| 习题书档（拓展）总题数 | 1,483 |
| 其中低指向性源（B-/C：大学教材/自编/改编） | **578（39.0%）** |
| 其中 d≤3（难度不足） | 19 题 |
| 已入书（32 章正式版） | 1,930 题（2026-09-07 扩池后） |
| 来源索引字节 | 244,000（`来源索引.md`） |

**「太多」的两个成因**：
1. **来源不纯**：39% 是 B-/C 类源，与「习题书＝拔高」定位不符；
2. **体量激增**：09-07 扩池纳入一分册/二分册 d≥4 共 377 题后，从 1,553 → 1,930。

### 4.2 三个可选方案

| 方案 | 做法 | 影响 | 建议 |
|:--|:--|:--|:--|
| **T-1 源过滤** | 剔除书内 C 类源（大学教材课后题） | 约减 500+ 题；书更纯 | ⭐ **推荐**（与你的原则②一致） |
| T-2 难度过滤 | 剔除 d≤3 题 | 仅减 19 题，**无效** | 不推荐 |
| T-3 分册拆分 | 四篇各自独立成书（已有目录结构） | 不减量，但**降低单本厚度** | ⭐ 可选（治「厚」不治「多」） |
| T-4 保持现状 | 扩池是 09-07 决策 | 不动 | 需你确认是否推翻该决策 |

> ⚠️ **T-1 的取舍**：习题书里那些大学教材题的**价值**在于「打基础」；剔除后书会变「纯竞赛向」。若你认为习题书应兼顾基础，则保留——**这是教学判断，需你拍板**。
>
> ⚠️ **不要「先删后写」**：任何剔除都走 `07-资料提炼/习题书剔除清单.json`（降级不删除），沿用 09-01 既定机制。
