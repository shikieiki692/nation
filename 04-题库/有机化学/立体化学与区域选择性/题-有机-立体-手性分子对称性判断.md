# 手性分子判断与对称性分析

## 题目

判断以下分子是否具有手性（旋光性），说明判断依据：

（1）反式-1,2-二甲基环丙烷
（2）顺式-1,2-二甲基环丙烷
（3）meso-2,3-二溴丁烷
（4）(R,R)-酒石酸
（5）联苯（无邻位取代基）
（6）6,6'-二硝基联苯-2,2'-二甲酸

## 参考答案

**判断标准**：分子既无对称面（σ）也无对称中心（i），则一定具有手性（旋光性）。

| 化合物 | 对称面 | 对称中心 | 手性 | 理由 |
|--------|--------|----------|------|------|
| 反式-1,2-二甲基环丙烷 | 无 | 有 | 无手性 | 存在对称中心 |
| 顺式-1,2-二甲基环丙烷 | 有 | 无 | 无手性 | 存在对称面 |
| meso-2,3-二溴丁烷 | 有 | 无 | 无手性 | 分子内有对称面（内消旋体） |
| (R,R)-酒石酸 | 无 | 无 | 有手性 | 无对称面和对称中心 |
| 联苯（无邻位取代） | 有 | 无 | 无手性 | 单键自由旋转，无阻转异构 |
| 6,6'-二硝基联苯-2,2'-二甲酸 | 无 | 无 | 有手性 | 邻位大位阻基团阻止旋转，产生阻转异构 |

## 解题思路

1. **对称面判定**：找一个平面使分子两半互为镜像
2. **对称中心判定**：找一个点使每个原子都能通过该点找到等价原子
3. **内消旋体**：含多个手性中心但整体有对称面/对称中心，无旋光性
4. **阻转异构**：联苯类化合物邻位有大基团时，单键旋转受阻，可产生手性
5. 构象改变可影响对称性，但室温下快速互变的构象按平均对称性判断
