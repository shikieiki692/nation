# 自由基反应机理与卤代选择性

## 题目

（1）写出甲烷氯化反应的完整自由基机理（链引发、链增长、链终止各写出至少一步）。

（2）比较正丙烷在溴化和氯化条件下的主要产物分布，解释选择性差异。

（3）异丁烷溴化的主要产物是什么？为什么？

（4）判断以下反应是否为自由基机理：
   - a. $\ce{CH2=CH2 + HBr ->}$（无过氧化物）
   - b. $\ce{CH2=CH2 + HBr ->}$（有过氧化物）
   - c. $\ce{CH3CH=CH2 + NBS ->}$（光照）

## 参考答案

### （1）甲烷氯化自由基机理

**链引发**：
$$\ce{Cl2 ->[h\nu] 2Cl\cdot}$$

**链增长**：
$$\ce{Cl\cdot + CH4 -> HCl + CH3\cdot}$$
$$\ce{CH3\cdot + Cl2 -> CH3Cl + Cl\cdot}$$

**链终止**：
$$\ce{Cl\cdot + Cl\cdot -> Cl2}$$
$$\ce{CH3\cdot + Cl\cdot -> CH3Cl}$$
$$\ce{CH3\cdot + CH3\cdot -> C2H6}$$

### （2）正丙烷卤代产物分布

| 卤素 | 一级碳产物 | 二级碳产物 | 选择性比 |
|------|-----------|-----------|----------|
| 氯化 | 40% | 60% | 1:4（概率校正后约1:4） |
| 溴化 | ~2% | ~98% | 1:80 |

**选择性差异原因**：
- 溴化反应的过渡态更"产物like"，自由基中间体更稳定
- 溴原子活性低，选择性高，优先夺取更稳定的二级碳氢
- 氯原子活性高，选择性低，产物分布接近概率统计

### （3）异丁烷溴化

主要产物：$\ce{(CH3)3CBr}$（2-溴-2-甲基丙烷）

原因：三级碳自由基最稳定（超共轭效应），溴化选择性极高，几乎只在三级碳上取代。

### （4）自由基机理判断

| 反应 | 条件 | 是否自由基机理 | 判断依据 |
|------|------|----------------|----------|
| a | 无过氧化物 | 否（离子型机理） | 碳正离子中间体，马氏加成 |
| b | 有过氧化物 | 是 | ROOR引发自由基，反马氏加成 |
| c | NBS/光照 | 是 | NBS提供低浓度Br₂，光照引发自由基 |

## 解题思路

1. **识别自由基条件**：光照（hν）、过氧化物（ROOR）、高温
2. **链引发**：均裂产生初始自由基（如Cl₂→2Cl·）
3. **链增长**：自由基与分子反应，生成产物和新自由基
4. **链终止**：两个自由基结合，终止链反应
5. **选择性**：溴化>氯化，三级碳>二级碳>一级碳
