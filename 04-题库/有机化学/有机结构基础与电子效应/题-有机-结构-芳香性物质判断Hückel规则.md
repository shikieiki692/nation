# 芳香性物质判断

## 题目

判断以下分子是否具有芳香性，并说明理由：

（1）苯（$\ce{C6H6}$）
（2）环丁二烯（$\ce{C4H4}$）
（3）环戊二烯负离子（$\ce{C5H5^-}$）
（4）环庚三烯正离子（$\ce{C7H7^+}$，tropylium ion）
（5）环辛四烯二负离子（$\ce{C8H8^{2-}}$）
（6）1,3-环己二烯

## 参考答案

**芳香性判定三要素**：必须同时满足以下三个条件才具有芳香性——
1. 环状结构（cyclic）
2. 所有提供p轨道的原子共平面（coplanar）
3. 具有 $4n+2$ 个 $\pi$ 电子（Hückel规则）

| 化合物 | 环状 | 共平面 | π电子数 | 判断 | 理由 |
|--------|------|--------|---------|------|------|
| 苯 | 是 | 是 | 6（$n=1$） | 芳香性 | 完全满足三要素 |
| 环丁二烯 | 是 | 是 | 4（$n=1$，反芳香性） | 反芳香性 | 4n个π电子，能量极高 |
| 环戊二烯负离子 | 是 | 是 | 6（$n=1$） | 芳香性 | 负电荷贡献2个π电子，共6个 |
| 环庚三烯正离子 | 是 | 是 | 6（$n=1$） | 芳香性 | 正电荷使碳缺电子，形成6π体系 |
| 环辛四烯二负离子 | 是 | 是 | 10（$n=2$） | 芳香性 | 二负离子提供2个额外π电子 |
| 1,3-环己二烯 | 是 | 是 | 4 | 非芳香性 | 不是连续共轭体系，sp³碳打断共轭 |

## 解题思路

1. 首先确认是否为环状结构
2. 检查是否所有原子共平面（sp²或sp杂化才可能共平面）
3. 计算π电子数：每个双键贡献2个π电子，负电荷贡献2个π电子，正电荷不贡献
4. 应用Hückel规则：$4n+2$ 为芳香性，$4n$ 为反芳香性
5. 反芳香性体系能量极高，实际很少见，分子往往通过扭曲为非平面来避免反芳香性（变为非芳香性）
