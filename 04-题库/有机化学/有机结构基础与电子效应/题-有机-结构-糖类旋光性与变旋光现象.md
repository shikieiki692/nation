# 糖类结构与旋光性计算

## 题目

（1）D-葡萄糖的α型比旋光度[α]D = +112.2°，β型[α]D = +18.7°，平衡混合液[α]D = +52.6°。计算平衡时α型和β型的比例。

（2）解释为什么D-葡萄糖在水溶液中会发生变旋光现象。

（3）画出α-D-吡喃葡萄糖和β-D-吡喃葡萄糖的Haworth投影式，标出两者的区别。

## 参考答案

### （1）旋光度计算

设α型比例为x，则β型比例为(1-x)

$$112.2x + 18.7(1-x) = 52.6$$
$$112.2x + 18.7 - 18.7x = 52.6$$
$$93.5x = 33.9$$
$$x = 0.36$$

**平衡组成**：α型 36%，β型 64%

### （2）变旋光现象原因

D-葡萄糖在水溶液中通过开链式结构发生α/β互变：
- α-D-吡喃葡萄糖 ⇌ 开链式（醛式） ⇌ β-D-吡喃葡萄糖
- 平衡建立过程中旋光度随时间变化
- 最终达到平衡旋光度[α]D = +52.6°

### （3）Haworth投影式区别

**α-D-吡喃葡萄糖**：
- 半缩醛羟基（C1-OH）与C5-CH₂OH处于**异侧**
- 约占平衡的36%

**β-D-吡喃葡萄糖**：
- 半缩醛羟基（C1-OH）与C5-CH₂OH处于**同侧**
- 约占平衡的64%（更稳定）

**β型更稳定的原因**：
- β型中所有取代基都处于平伏键位置
- 1,3-二直立键相互作用较少

## 解题思路

1. 用加权平均公式计算旋光度
2. 理解变旋光现象的机理（开链式中间体）
3. 区分α和β异头物的结构差异
4. 了解糖的环状结构形成机制
