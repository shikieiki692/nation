# 氨基酸等电点计算与电泳分析

## 题目

（1）甘氨酸的pKa1 = 2.34（羧基），pKa2 = 9.69（氨基），计算其等电点pI。

（2）赖氨酸的pKa1 = 2.18（羧基），pKa2 = 8.5（氨基），pKa3 = 10.53（侧链氨基），计算其等电点pI。

（3）在pH = 9.5的缓冲液中进行电泳，甘氨酸和赖氨酸分别向哪个方向移动？

（4）谷氨酸的pKa1 = 2.19（羧基），pKa2 = 4.25（侧链羧基），pKa3 = 9.67（氨基），计算其pI。

## 参考答案

### （1）甘氨酸pI计算

甘氨酸有两个可解离基团，pI取两个pKa的平均值：
$$\ce{pI = (pKa1 + pKa2) / 2 = (2.34 + 9.69) / 2 = 6.01}$$

### （2）赖氨酸pI计算

赖氨酸有三个可解离基团（碱性氨基酸），pI取两个碱性pKa的平均值：
$$\ce{pI = (pKa2 + pKa3) / 2 = (8.5 + 10.53) / 2 = 9.52}$$

### （3）电泳方向判断

| 氨基酸 | pI | pH=9.5时带电 | 电泳方向 |
|--------|-----|-------------|----------|
| 甘氨酸 | 6.01 | pH > pI，带负电（COO⁻） | 向阳极（+）移动 |
| 赖氨酸 | 9.52 | pH < pI，带正电（NH₃⁺） | 向阴极（-）移动 |

### （4）谷氨酸pI计算

谷氨酸是酸性氨基酸（有两个羧基），pI取两个羧基pKa的平均值：
$$\ce{pI = (pKa1 + pKa2) / 2 = (2.19 + 4.25) / 2 = 3.22}$$

**规则**：
- 酸性氨基酸（Asp, Glu）：pI = (pKa1 + pKa2)/2（两个羧基）
- 碱性氨基酸（Lys, Arg, His）：pI = (pKa2 + pKa3)/2（两个氨基）
- 中性氨基酸：pI = (pKa1 + pKa2)/2

## 解题思路

1. 确定氨基酸的可解离基团类型（羧基、氨基、侧链）
2. 按pKa从小到大排列
3. 判断是酸性、碱性还是中性氨基酸
4. 应用对应的pI计算公式
5. pH > pI时带负电，pH < pI时带正电
