# 逆合成分析进阶：多步合成设计

> **来源**：Zchem有机反应合成与机理 下册L2
> **难度**：⭐⭐⭐⭐⭐
> **题目类型**：例题

## 题目

多步合成设计需要综合运用逆合成分析和各种反应类型。

**题目**：
1. 对一个六步合成路线进行逆合成分析（每步选择一种代表性的反应类型）
2. 在多步合成中，为什么某些步骤需要在特定顺序下进行？
3. 合成策略中，什么是"汇聚式合成"与"线性合成"？各自的优缺点是什么？
4. 保护基策略在多步合成中的引入时机如何确定？

## 参考答案

### 1. 六步路线的逆合成示例

以“含 α,β-不饱和酯和远端羟基的目标分子”为例，六步路线及其逆合成回推可写成：

1. 目标分子的 HWE 切断：α,β-不饱和酯 ← 醛 + 膦酸酯（碳-碳键形成）。
2. 醛的 FGI 回推：醛 ← 伯醇（Swern/PCC 氧化的逆反应）。
3. 伯醇的来源：酯或内酯经还原（LiAlH₄ 或 DIBAL-H 路线）得到（还原/官能团转化）。
4. 酯的逆合成切断：酯 ← 酰氯 + 醇或羧酸酯化（缩合）。
5. 醇骨架的格氏/有机锂切断：碳-碳键形成把片段连成骨架。
6. 末端用 TBS 等保护基标记并最后脱保护（保护/脱保护步骤）。

以上只作示范，真实路线需按目标分子重新选切断；每一步的评判标准是“切断后片段能否由常见试剂买到或制备”。

### 2. 为什么某些步骤必须特定顺序

多步合成的顺序由官能团兼容性、氧化态安全和立体化学共同决定。先引入的官能团会一直存在于后续步骤中，若与后面的强碱、强还原剂或亲电试剂不兼容，就会破坏已构建的骨架；相反，某些敏感基团需要在最后阶段才出现。一般原则是把兼容性差的基团延后生成或提前保护，把强效试剂安排在分子还较简单时使用，立体中心建立后再避免可能消旋、消除或重排的剧烈条件。

### 3. 汇聚式合成与线性合成

- 线性合成：从起点 A 出发，依次连接得到 B、C、D…… 直至目标。优点是规划简单、逻辑清晰；缺点是总产率按各步产率连乘，步骤越多损失越大，且后期某一步失败会浪费前面积累的产物。
- 汇聚式合成：分别制备两个或两个以上片段，在路线后期通过一步关键偶联合并。优点是各片段可以平行推进，最长线性步骤短，总收率通常更高；缺点是需要更早考虑片段端位官能团匹配、保护基方案和后期偶联的选择性，规划难度更大。

### 4. 保护基引入时机

保护基应在“该官能团即将干扰下一步反应”之前引入，而不是一开始就全部保护：过早保护增加步骤与废料，过晚保护则可能让副反应破坏分子。判断标准包括后续试剂的酸碱性、氧化还原性、亲电/亲核性以及立体化学要求。选用多个保护基时要保证它们互相正交，并且按需要“够用即脱”：能避免干扰后尽早脱除，或在汇聚式合成中于偶联前统一调整。
