# 烯烃复分解反应

## 题目

**(1)** 什么是烯烃复分解反应（olefin metathesis）？写出反应通式。

**(2)** 列举三种类型的烯烃复分解反应（RCM、CM、ROMP），写出每种的反应方程式和典型应用。

**(3)** Grubbs 催化剂是什么？为什么它在全合成中如此重要？

## 参考答案

### (1) 烯烃复分解反应

**定义**：两个烯烃在金属卡宾催化剂作用下，**交换双键两侧的亚烷基片段**，生成新的烯烃。

**反应通式**：

$$\text{R}_1\text{CH=CHR}_2 + \text{R}_3\text{CH=CHR}_4 \xrightarrow{\text{催化剂}} \text{R}_1\text{CH=CHR}_3 + \text{R}_2\text{CH=CHR}_4$$

**机理**：金属卡宾（M=CHR）与烯烃形成 [2+2] 环加成 → 四元环中间体 → 逆 [2+2] 环加成 → 新烯烃 + 新金属卡宾。

### (2) 三种类型的复分解

**A. RCM（关环复分解，Ring-Closing Metathesis）**

```
二烯烃 → 环烯烃 + 小分子烯烃（如乙烯）

CH₂=CH-(CH₂)ₙ-CH=CH₂ → 环-(CH₂)ₙ + CH₂=CH₂
```

**应用**：构建中大环（8-20元环），传统方法困难。

**B. CM（交叉复分解，Cross Metathesis）**

```
R-CH=CH₂ + R'-CH=CH₂ → R-CH=CH-R' + CH₂=CH₂
```

**应用**：两种烯烃的偶联，替代 Wittig 反应。

**C. ROMP（开环易位聚合，Ring-Opening Metathesis Polymerization）**

```
环烯烃 → 高分子聚合物

环戊烯 → 聚戊烯（含 C=C 主链）
```

**应用**：制备功能高分子材料。

### (3) Grubbs 催化剂

**结构**：钌卡宾配合物（Ru=CHPh），含 N-杂环卡宾（NHC）配体。

**第一代 Grubbs**：(PCy₃)₂Cl₂Ru=CHPh
**第二代 Grubbs**：(IMes)(PCy₃)Cl₂Ru=CHPh（NHC 配体替换一个 PCy₃）

**为什么重要**：
1. **空气稳定**：可以在空气中操作（不像 Schrock 催化剂对空气敏感）
2. **官能团兼容性好**：耐受醇、醛、酸、胺等多种官能团
3. **催化效率高**：TON（转化数）可达 >10⁶
4. **条件温和**：室温即可反应

**2005年诺贝尔化学奖**：Yves Chauvin、Robert Grubbs、Richard Schrock 因烯烃复分解反应获奖。

### 复分解反应在全合成中的应用

| 全合成目标 | RCM 步骤 | 意义 |
|:---|:---|:---|
| Epothilone A | 14元环 RCM | 关键大环构建 |
| Prostaglandin | CM 偶联 | 侧链连接 |
| 大环内酯类抗生素 | RCM | 大环内酯骨架 |

> 💡 **识别信号**：看到目标分子含大环 → 考虑 RCM；看到两个烯烃需要偶联 → 考虑 CM。
