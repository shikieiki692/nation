# 卡宾的生成与单线态三线态

## 题目

**(1)** 列举三种生成卡宾（:CH₂ 或取代卡宾）的方法，写出每种方法的反应方程式。

**(2)** 比较单线态卡宾（singlet carbene）和三线态卡宾（triplet carbene）在电子结构、反应性和立体化学结果上的差异。

**(3)** 二氯卡宾 :CCl₂ 与顺式-2-丁烯反应的主要产物是什么？与三线态卡宾反应的产物有何不同？用立体化学结果判断卡宾的自旋态。

## 参考答案

### (1) 卡宾的三种生成方法

**方法一：α-消除（1,1-消除）**
$$\text{CHCl}_3 + \text{NaOH} \rightarrow :\text{CCl}_2 + \text{NaCl} + \text{H}_2\text{O}$$

氯仿在强碱作用下发生 α-消除，生成二氯卡宾。

**方法二：重氮化合物光解/热解**
$$\text{CH}_2\text{N}_2 \xrightarrow{h\nu \text{ 或 } \Delta} :\text{CH}_2 + \text{N}_2$$

重氮甲烷在光照或加热下失去 N₂，生成亚甲基卡宾。

**方法三：酮的光解（Norrish Type I）**
$$\text{R-CO-R'} \xrightarrow{h\nu} \text{R-CO-R'}^* \rightarrow \text{R· + R'·}$$

酰基自由基脱 CO 后生成卡宾（较少见但理论重要）。

### (2) 单线态 vs 三线态卡宾

| 特征 | 单线态卡宾 | 三线态卡宾 |
|:---|:---|:---|
| **电子排布** | 两个电子成对在同一轨道，另一空轨道 | 两个电子分占两个轨道，自旋平行 |
| **自旋态** | S = 0 | S = 1 |
| **几何构型** | 弯曲（~100-110°） | 弯曲或线性 |
| **反应性** | 一步协同加成 | 分步自由基加成 |
| **立体化学** | **保持烯烃构型**（顺式→顺式） | **丧失立体化学**（顺式→顺反混合物） |
| **寿命** | 极短（~ns） | 较长（~μs） |
| **典型来源** | 重氮化合物光解 | 二卤甲烷+碱 |

### (3) 二氯卡宾与顺式-2-丁烯的反应

**单线态 :CCl₂ 的反应**：

```
顺式-2-丁烯 + :CCl₂(singlet) → 顺式-1,2-二甲基-3,3-二氯环丙烷
```

产物保持烯烃的顺式构型（一步协同 [2+1] 环加成）。

**三线态 :CCl₂ 的反应**：

```
顺式-2-丁烯 + :CCl₂(triplet) → 顺式 + 反式-1,2-二甲基-3,3-二氯环丙烷
```

产物为顺式和反式的混合物（分步自由基机理，中间体有单键旋转机会）。

### 立体化学判据

| 实验结果 | 判断的卡宾自旋态 |
|:---|:---|
| 产物保持烯烃构型 | **单线态** |
| 产物丧失立体化学（顺反混合） | **三线态** |

> 💡 **记忆要点**：单线态 = 协同 = 保持构型；三线态 = 分步 = 丧失构型。这与周环反应（协同→立体专一）和自由基反应（分步→立体选择性差）的规律一致。
