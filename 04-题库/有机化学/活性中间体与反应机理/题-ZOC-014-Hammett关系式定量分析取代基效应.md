# Hammett关系式定量分析取代基效应

> **来源**：Zchem有机反应合成与机理 上册L3
> **难度**：⭐⭐⭐⭐⭐
> **题目类型**：例题

## 题目

Hammett关系式 $\log(k_X/k_H) = \rho\sigma$ 定量描述取代基电子效应对反应速率的影响。

**题目**：
1. 定义Hammett关系式中的取代基常数 $\sigma$ 和反应常数 $\rho$
2. 为什么Hammett关系式仅适用于间位和对位取代基，不适用于邻位和脂肪族取代基？
3. 某芳环亲核取代反应测得 $\rho = +4.9$。解释该 $\rho$ 值的含义：
   - 过渡态与底物相比，电荷密度如何变化？
   - 决速步是亲核进攻还是离去基团离去？
4. 若某反应在EDG（给电子基）存在时 $\rho = -4.4$，在EWG（吸电子基）存在时 $\rho > 1$，说明这暗示了什么？

## 参考答案

### 1. σ 与 ρ 的定义

Hammett 关系式为：

$$\log\frac{k_X}{k_H} = \rho\sigma$$

σ 是取代基常数，反映取代基的电子效应，以苯甲酸电离为参考：$\sigma = pK_a(\mathrm{H}) - pK_a(\mathrm{X})$。吸电子基（EWG）使苯甲酸酸性增强，σ > 0；给电子基（EDG）使酸性减弱，σ < 0；氢为基准，σ = 0。

ρ 是反应常数，等于 Hammett 图的斜率，衡量反应对取代基电子效应的敏感程度：|ρ| 越大说明过渡态电荷变化越显著。ρ > 0 表示过渡态比原料富电子（负电荷增加），吸电子基加速反应；ρ < 0 表示过渡态比原料缺电子（正电荷增加），给电子基加速反应。

### 2. 仅适用于间位和对位的原因

邻位取代基紧邻反应中心，位阻效应与电子效应叠加，还会形成分子内氢键或场效应，破坏了 Hammett 关系的线性基础；脂肪族取代基与反应中心之间没有刚性的共轭或诱导传递骨架，电性传递弱且伴随随机位阻，难以用统一 σ 值描述。间位主要指通过诱导效应传递电子，对位还可通过共轭效应传递，电子效应单一、线性好，故 Hammett 关系只适用于间位和对位取代芳烃。

### 3. ρ = +4.9 的含义

ρ = +4.9 明显为正且大于 4，说明：

- 吸电子基显著加速反应，过渡态电荷密度高于原料，反应过程中负电荷在芳环上发展并离域；
- 负电荷与苯环共轭、能被吸电子基有效稳定（ρ > 4 即电荷离域到芳环的典型特征）；
- 决速步是亲核试剂的进攻（形成 Meisenheimer 络合物），而非离去基团离去。若离去基团离去为决速步，过渡态更接近缺电子的原料，应测得负 ρ。

### 4. EDG 与 EWG 两组 ρ 值的含义

同一反应在不同取代基下测得 EDG 时 ρ = -4.4、EWG 时 ρ > 1，说明取代基改变了反应的机理：

- EWG 存在时 ρ > 1，过渡态富电子，负电荷由亲核进攻产生并被芳环分散，符合经典 SNAr（先加成后消除）机理；
- EDG 存在时 ρ = -4.4，过渡态严重缺电子，正电荷与芳环直接共轭，反应改走电子转移（自由基或电荷转移）途径，给电子基能显著稳定带正电荷的过渡态。

因此取代基不仅是调节反应快慢的因素，还可能主导反应路径的选择；用 Hammett 分析时必须同时看 ρ 的符号、大小和取代基范围。
