# 动力学与热力学产物预测

## 题目

**(1)** 2-甲基环己酮在不同条件下与 LDA/MeI 反应，分别得到什么产物？

- **(a)** LDA, -78°C, THF, 30 min → 然后加 MeI
- **(b)** LDA, -78°C, THF → 然后升温至 25°C, 2h → 然后加 MeI

**(2)** HCl 加成到 1-苯基丙炔（Ph-C≡C-CH₃）时，动力学产物和热力学产物分别是什么？在什么条件下可以得到热力学产物？

**(3)** 什么是"不可逆条件"和"可逆条件"？各举一个有机反应的例子。

## 参考答案

### (1) 2-甲基环己酮的烷基化

**(a) LDA, -78°C（动力学条件）**：

LDA 在 -78°C 下夺取**位阻最小的 α-H** → 生成**动力学烯醇盐**（取代较少的烯醇盐）。

```
2-甲基环己酮 → LDA/-78°C → 动力学烯醇盐（C6 位去质子）→ MeI → 2,6-二甲基环己酮
```

**(b) LDA, -78°C → 升温至 25°C（热力学条件）**：

升温后，烯醇盐发生**可逆去质子/再质子化** → 平衡移动到**更稳定的烯醇盐**（取代更多的烯醇盐）。

```
2-甲基环己酮 → LDA/-78°C → 升温25°C/2h → 热力学烯醇盐（C2 位去质子）→ MeI → 2,2-二甲基环己酮
```

### (2) HCl加成到苯基丙炔

**动力学产物**：HCl 加到 C1（靠近苯基的碳）→ 生成**反式烯烃**（通过氯鎓离子中间体，anti 加成）。

**热力学产物**：HCl 加到 C2 → 生成**共轭烯烃**（Ph-CH=CCl-CH₃，与苯环共轭）。

**条件控制**：
- **低温/短时间** → 动力学产物（反式烯烃）
- **高温/长时间/Al₂O₃ 催化** → 热力学产物（共轭烯烃）

### (3) 不可逆 vs 可逆条件

| 类型 | 特征 | 例子 |
|:---|:---|:---|
| **不可逆条件** | 去质子后不可逆 → 动力学控制 | LDA/-78°C（强碱、低温） |
| **可逆条件** | 去质子/再质子化可逆 → 热力学控制 | NaOEt/EtOH/室温（弱碱、质子溶剂） |

**有机反应中的例子**：

**不可逆**：LDA 在 -78°C 下夺取酮的 α-H → 只能夺取位阻最小的 H → 动力学烯醇盐

**可逆**：NaOEt 在 EtOH 中夺取酮的 α-H → 可逆平衡 → 热力学更稳定的烯醇盐

### 动力学vs热力学控制的判断框架

```
判断条件：
  1. 碱的强度
     - 强碱（LDA, t-BuOK）→ 不可逆 → 动力学
     - 弱碱（NaOEt, NaOH）→ 可逆 → 热力学
  2. 温度
     - 低温（-78°C）→ 动力学
     - 高温（室温或加热）→ 热力学
  3. 溶剂
     - 非质子溶剂（THF, DMSO）→ 不可逆
     - 质子溶剂（EtOH, H₂O）→ 可逆
  4. 时间
     - 短时间 → 动力学
     - 长时间 → 热力学
```

> 💡 **核心原则**：动力学 = 快 → 少取代烯醇盐/少取代烯烃；热力学 = 稳定 → 多取代烯醇盐/多取代烯烃。
