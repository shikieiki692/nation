# 题-XES-021：C9H12结构推断

> **来源**：学而思有机化学基础 第7讲 炔烃
> **难度**：⭐⭐⭐⭐
> **教学层级**：中难

---

## 题目

习题 9. 化合物 A（ $C_{9}H_{12}$ ）用钯催化剂催化氢化吸收 3 当量 $H_{2}$ 生成 B（ $C_{9}H_{18}$ ）。臭氧化时，化合物 A 生成产物之一是被鉴定为环己酮的酮。用 $NH_{3}$ 中的 $NaNH_{2}$ 处理，之后加入碘甲烷时，化合物 A 生成新的烃，C（ $C_{10}H_{14}$ ）。A、B 和 C 的结构是什么？

---

## 参考答案

**推断链**：

1. A（$C_9H_{12}$）不饱和度 $\Omega=\frac{2\times9+2-12}{2}=4$。Pd 催化氢化吸收 3 当量 $\mathrm{H_2}$ → 含 3 个可还原 π 键，剩余 1 个不饱和度为环；B（$C_9H_{18}$）为单环饱和烃。
2. 臭氧化产物之一是环己酮 → 环为己烷环，且环上带**环外双键**（环外 =CHR 臭氧化时环碳变羰基，得环己酮）。
3. $\mathrm{NaNH_2/NH_3}$ 处理后再加 $\mathrm{CH_3I}$ 多得一个 $\mathrm{CH_2}$（C₁₀H₁₄）→ A 含**端炔** $\mathrm{-C{\equiv}CH}$（炔氢被夺去后甲基化）。
4. 组合验证：不饱和度 4 = 环(1) + C=C(1) + C≡C(2) ✓；3 当量 $\mathrm{H_2}$ = 双键(1) + 叁键(2) ✓。

**结构**：

- **A**：环己烷经环外双键连接 $\mathrm{-CH-C{\equiv}CH}$，即（2-丙炔亚基）环己烷 $\mathrm{C_6H_{10}{=}CH{-}C{\equiv}CH}$
- **B**：**丙基环己烷** $\mathrm{C_6H_{11}{-}CH_2CH_2CH_3}$（A 的双键、叁键全部加氢）
- **C**：A 的端炔甲基化产物 $\mathrm{C_6H_{10}{=}CH{-}C{\equiv}C{-}CH_3}$

验证：A 臭氧化时环外双键断裂 → 环己酮 + $\mathrm{OHC{-}C{\equiv}CH}$ ✓；A + 3$\mathrm{H_2}$ → $C_9H_{18}$ ✓；A $\xrightarrow{\mathrm{NaNH_2}}\xrightarrow{\mathrm{CH_3I}}$ C（净加 CH₂）✓。
