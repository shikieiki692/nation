# 烯烃加成反应立体化学

## 题目

预测以下反应的产物，并说明立体化学特征：

（1）$\ce{CH3CH=CH2 + Br2/CCl4 ->}$ 产物（立体化学）

（2）$\ce{CH3CH=CH2 + 1) Hg(OAc)2/H2O 2) NaBH4 ->}$ 产物

（3）$\ce{CH3CH=CH2 + 1) BH3·THF 2) H2O2/OH- ->}$ 产物

（4）顺-2-丁烯 + $\ce{Br2/CCl4}$ → 产物

（5）反-2-丁烯 + $\ce{Br2/CCl4}$ → 产物

## 参考答案

### （1）丙烯 + Br₂

**产物**：$\ce{CH3CHBrCH2Br}$（1,2-二溴丙烷）

**立体化学**：反式加成（anti addition）

**机理**：
1. Br₂与双键形成溴鎓离子（三元环正离子）
2. Br⁻从溴鎓离子背面进攻
3. 两个溴原子处于反式位置

### （2）丙烯羟汞化-脱汞反应

**产物**：$\ce{CH3CH(OH)CH3}$（2-丙醇，马氏产物）

**特点**：
- 区域选择性：遵循马氏规则（OH加在取代多的碳上）
- 立体化学：反式加成
- 无碳正离子重排

### （3）丙烯硼氢化-氧化反应

**产物**：$\ce{CH3CH2CH2OH}$（1-丙醇，反马氏产物）

**特点**：
- 区域选择性：反马氏（B加在位阻小的碳上，OH取代B的位置）
- 立体化学：顺式加成（syn addition）
- 无重排

### （4）顺-2-丁烯 + Br₂

**产物**：(2R,3R)-2,3-二溴丁烷 + (2S,3S)-2,3-二溴丁烷（外消旋体）

**立体化学**：反式加成得到外消旋体

### （5）反-2-丁烯 + Br₂

**产物**：(2R,3S)-2,3-二溴丁烷（内消旋体）

**立体化学**：反式加成得到内消旋体

## 解题思路

1. **溴鎓离子机理**：Br₂加成→三元环中间体→背面进攻→反式产物
2. **羟汞化**：Hg(OAc)₂形成三元环→H₂O进攻→NaBH₄脱汞→马氏产物
3. **硼氢化**：BH₃顺式加成→H₂O₂/OH⁻氧化→反马氏产物
4. **立体化学**：反式加成的立体结果取决于底物的顺/反构型
5. **产物类型**：反式加成+顺式烯烃→外消旋体；反式加成+反式烯烃→内消旋体
