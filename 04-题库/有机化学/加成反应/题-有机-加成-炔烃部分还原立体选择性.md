# 炔烃部分还原立体选择性

## 题目

**(1)** 2-丁炔（CH₃C≡CCH₃）分别用以下两种方法还原，产物各是什么？

- **(a)** H₂ / Lindlar 催化剂
- **(b)** Na / NH₃(l)

**(2)** 解释为什么两种方法给出不同的立体化学产物。

**(3)** 如果需要从 2-丁炔出发制备 (Z)-2-丁烯和 (E)-2-丁烯，应分别选择哪种方法？


![[cis-complex.jpg]]

## 参考答案

### (1) 两种还原方法的产物

**(a) Lindlar 催化还原**：

$$\text{CH}_3\text{C≡CCH}_3 + \text{H}_2 \xrightarrow{\text{Lindlar cat.}} \text{(Z)-2-丁烯}$$

产物为 **顺式烯烃（Z-构型）**。

**(b) Na/NH₃ 还原**：

$$\text{CH}_3\text{C≡CCH}_3 + \text{Na} \xrightarrow{\text{NH}_3(l)} \text{(E)-2-丁烯}$$

产物为 **反式烯烃（E-构型）**。

### (2) 立体化学差异的原因

**Lindlar 催化还原（顺式加成）**：

- H₂ 在催化剂表面**同步加成**到炔烃的同一面
- 两个 H 原子从**同一侧**加到 C≡C 上
- → **syn 加成** → 顺式烯烃

```
    H   H
     \ /
      C=C        ← 顺式（Z）
     / \
   CH₃ CH₃
```

**Na/NH₃ 还原（反式加成）**：

- Na 提供电子 → 炔烃接受电子形成**自由基阴离子中间体**
- 中间体中最稳定的构象是**反式**（两个甲基尽量远离）
- 质子化后保持反式构型
- → **anti 加成** → 反式烯烃

```
   CH₃    H
      \  /
       C=C        ← 反式（E）
      /  \
     H   CH₃
```

### (3) 合成选择

| 目标产物 | 方法 | 原因 |
|:---|:---|:---|
| **(Z)-2-丁烯** | H₂ / Lindlar | syn 加成 → 顺式 |
| **(E)-2-丁烯** | Na / NH₃(l) | anti 加成 → 反式 |

### 炔烃还原方法总结

| 方法 | 试剂 | 产物 | 立体化学 |
|:---|:---|:---|:---|
| **Lindlar 催化** | H₂ / Lindlar cat. | **顺式烯烃** | syn 加成 |
| **Na/NH₃** | Na / 液 NH₃ | **反式烯烃** | anti 加成 |
| **完全还原** | H₂ / Pd/C | 烷烃 | — |

> 💡 **记忆技巧**：Lindlar = "L" = "Left side" = 同侧加成 = 顺式；Na/NH₃ = "N" = "New side" = 反式。
