# 霍夫曼消除反应应用

## 题目

（1）写出以下化合物经霍夫曼消除后的烯烃产物：
   丁胺（$\ce{CH3CH2CH2CH2NH2}$）先与过量$\ce{CH3I}$反应，再用$\ce{Ag2O/H2O}$处理，最后加热。

（2）解释为什么霍夫曼消除主要生成取代最少的烯烃（霍夫曼产物）。

（3）在环己烷体系中，霍夫曼消除对β-H的立体化学有什么要求？

## 参考答案

### （1）丁胺的霍夫曼消除

**第一步**：彻底甲基化
$$\ce{CH3CH2CH2CH2NH2 + excess CH3I -> CH3CH2CH2CH2N+(CH3)3 I-}$$

**第二步**：离子交换
$$\ce{CH3CH2CH2CH2N+(CH3)3 I- + Ag2O/H2O -> CH3CH2CH2CH2N+(CH3)3 OH- + AgI}$$

**第三步**：E2消除（加热）
$$\ce{CH3CH2CH2CH2N+(CH3)3 OH- ->[\Delta] CH2=CHCH2CH3 + N(CH3)3 + H2O}$$

产物：1-丁烯（霍夫曼产物，取代最少的烯烃）

### （2）霍夫曼产物选择性原因

1. **位阻效应**：季铵盐的氮正离子（$\ce{-N+(CH3)3}$）体积很大
2. **动力学控制**：大位阻碱（OH⁻）优先进攻位阻最小的β-H
3. **过渡态**：β-H的可及性决定反应速率
4. **碱的位阻**：OH⁻虽然是小位阻碱，但底物的季铵盐位阻极大，综合效应导致霍夫曼产物为主

### （3）环己烷体系的立体要求

E2消除必须满足**反式共平面**（anti-periplanar）要求：
- β-H和离去基团（$\ce{-N+(CH3)3}$）必须处于反式位置
- 在环己烷中，两个基团都必须处于**直立键**（axial）位置
- 三取代氮的大位阻会使环上消除较困难，需要加热促进

## 解题思路

1. **彻底甲基化**：胺与过量碘甲烷反应，生成季铵盐
2. **离子交换**：Ag₂O提供OH⁻取代I⁻
3. **E2消除**：OH⁻进攻β-H，反式共平面消除
4. **产物判断**：用纽曼投影分析过渡态，优先消除位阻最小的β-H
5. **环状体系**：必须满足直立键-直立键的反式共平面要求
