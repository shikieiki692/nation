# Wagner-Meerwein重排同位素标记追踪

## 题目

**(1)** 新戊基溴（(CH₃)₃CCH₂Br）在乙醇中发生溶剂解反应。画出反应机理，并预测产物。为什么新戊基溴的 SN2 反应活性极低？

**(2)** 如果将新戊基溴中标记了 ¹⁴C 的碳原子标在 CH₂ 上（即 (CH₃)₃C-¹⁴CH₂Br），反应后 ¹⁴C 出现在产物的什么位置？

**(3)** Wagner-Meerwein 重排的驱动力是什么？什么条件下重排更容易发生？

## 参考答案

### (1) 新戊基溴的溶剂解

**SN2 活性极低的原因**：新戊基溴的 α-碳（CH₂）被三个甲基包围，**空间位阻极大**，亲核试剂无法从背面接近。

**溶剂解机理（SN1 路径）**：

1. **慢步骤**：C-Br 异裂 → 新戊基碳正离子 (CH₃)₃C-CH₂⁺
2. 碳正离子极不稳定（一级碳正离子）→ 立即发生 **1,2-甲基迁移**（Wagner-Meerwein 重排）
3. 迁移后形成更稳定的三级碳正离子：(CH₃)₂C⁺-CH₂CH₃
4. **乙醇捕获** → (CH₃)₂C(OEt)-CH₂CH₃

**产物**：2-甲氧基-2-甲基丁烷（三级碳正离子的溶剂解产物）

### (2) ¹⁴C 标记追踪

```
(CH₃)₃C-¹⁴CH₂Br 
    → (CH₃)₃C-¹⁴CH₂⁺ （一级碳正离子）
    → 1,2-甲基迁移：
       CH₃ 从 C3 迁移到 ¹⁴C（C4）
    → (CH₃)₂C⁺-¹⁴CH₂-CH₃
    → (CH₃)₂C(OEt)-¹⁴CH₂-CH₃
```

**¹⁴C 出现在产物的 CH₂ 位置**（即原来的一级碳正离子的碳，现在是三级碳正离子的 β-碳）。

迁移的甲基从原来的叔碳迁移到了标记的 CH₂ 上。

### (3) 重排的驱动力

**驱动力：碳正离子稳定性提升**

$$\text{一级碳正离子} \xrightarrow{\text{1,2-迁移}} \text{三级碳正离子}$$

$$\text{不稳定} \rightarrow \text{稳定}$$

**更容易发生重排的条件**：
- 生成的碳正离子不稳定（一级 > 二级）→ 重排驱动力大
- 迁移基团的迁移能力强（芳基 > 烷基 > H）
- 反应温度高（提供重排所需活化能）
- SN1 条件（弱亲核试剂、极性溶剂）→ 碳正离子有足够寿命重排

### Wagner-Meerwein 重排总结

| 要素 | 内容 |
|:---|:---|
| 本质 | 1,2-迁移（碳正离子重排） |
| 迁移基团 | 烷基、芳基或 H |
| 驱动力 | 碳正离子稳定性提升 |
| 常见场景 | 醇脱水、卤代烃溶剂解、萜类化合物重排 |

> ⚠️ **易错点**：Wagner-Meerwein 重排是**碳正离子重排**（1,2-迁移），不要与 [3,3]-σ 迁移（Cope/Claisen）混淆。
