# 频哪醇重排反应机理

## 题目

写出以下频哪醇重排反应的完整机理，并预测主要产物：

（1）$\ce{(CH3)2C(OH)-C(OH)(CH3)2 + H+ ->}$ 产物

（2）$\ce{PhC(OH)(CH3)-C(OH)(CH3)2 + H+ ->}$ 产物

（3）$\ce{(CH3)2C(OH)-C(OH)(CH3)Ph + H+ ->}$ 产物


![[wagner-meerwein.png]]

## 参考答案

### 反应机理（以底物1为例）

**步骤1**：质子化羟基
$$\ce{(CH3)2C(OH)-C(OH)(CH3)2 + H+ -> (CH3)2C(OH2+)-C(OH)(CH3)2}$$

**步骤2**：脱水形成碳正离子
$$\ce{(CH3)2C(OH2+)-C(OH)(CH3)2 -> (CH3)2C+-C(OH)(CH3)2 + H2O}$$

**步骤3**：邻位羟基的σ键迁移（关键步骤）
$$\ce{(CH3)2C+-C(OH)(CH3)2 -> (CH3)2C(OH)-C+(CH3)2}$$

**步骤4**：脱质子形成酮
$$\ce{(CH3)2C(OH)-C+(CH3)2 -> (CH3)2C=O + (CH3)2C=O}$$

最终产物：$\ce{(CH3)2C=O}$（丙酮）

### 底物2的主要产物

由于苯基（Ph）比甲基更能稳定碳正离子（通过共轭效应），迁移优先顺序为：苯基 > 甲基

主要产物：$\ce{PhC(=O)CH(CH3)2}$（苯基异丙基酮）

### 底物3的主要产物

迁移规则：能更好稳定正电荷的基团优先迁移

主要产物：$\ce{PhC(=O)C(CH3)3}$

## 解题思路

1. **反应条件**：邻二醇在酸性条件下发生重排
2. **驱动力**：生成更稳定的碳正离子（通过基团迁移）
3. **迁移规则一**：能更好稳定正电荷的基团优先迁移（与普通碳正离子重排相反）
   - 苯基 > 甲基（苯基可通过共轭效应分散正电荷）
4. **迁移规则二**：满足反式共平面迁移速率更快
5. **环状体系**：六元环中只有反式双直立键位置的基团才能有效迁移
