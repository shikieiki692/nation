# Favorskii重排缩环反应

## 题目

**(1)** 2-氯环己酮在 NaOMe/MeOH 中反应，得到甲基环戊烷羧酸酯。写出反应机理，并解释为什么六元环变成了五元环。

**(2)** 如果 2-氯环己酮中标记了 ¹⁴C 在 C1（羰基碳），产物中 ¹⁴C 出现在什么位置？

**(3)** Favorskii 重排与普通的碱性水解（消除 HCl）有什么本质区别？

## 参考答案

### (1) Favorskii 重排机理

**2-氯环己酮 → 甲基环戊烷羧酸酯**（六元环缩为五元环）

**机理步骤**：

1. **碱夺取 α-H**：MeO⁻ 夺取 C6 上的 α-H，形成烯醇负离子
2. **分子内 SN2**：C6 负离子从背面进攻 C-Cl，形成**环丙酮中间体**（三元环）
3. **MeOH 进攻环丙酮**：MeOH 从位阻较小的方向进攻环丙酮的 C=O
4. **开环**：三元环张力释放，开环得到五元环产物

```
六元环（2-氯环己酮）
    → 烯醇负离子
    → 环丙酮中间体（三元环嵌入六元环）
    → MeOH 进攻 C=O
    → 三元环开环 → 五元环 + COOMe
```

**缩环原因**：环丙酮中间体的形成消耗了原来六元环中的两个碳，开环后环缩小一个碳。

### (2) ¹⁴C 标记追踪

```
¹⁴C 在 C1（羰基碳）
    → 环丙酮中间体：¹⁴C 成为环丙酮的 C=O
    → MeOH 进攻 ¹⁴C=O
    → ¹⁴C 成为酯羰基碳（COOMe 中的 ¹⁴C）
```

**¹⁴C 出现在产物的酯羰基碳上**。

### (3) Favorskii 重排 vs 碱性水解

| 特征 | Favorskii 重排 | 碱性水解（E2消除） |
|:---|:---|:---|
| 关键中间体 | **环丙酮**（三元环） | 无环状中间体 |
| 产物 | **缩环**的羧酸/酯 | 烯酮或α,β-不饱和酮 |
| 碳骨架 | **改变**（环缩小） | **不变** |
| 适用条件 | α-卤代酮 + 强碱 | α-卤代酮 + 强碱 |

> 💡 **识别信号**：看到 α-卤代酮 + 强碱 → 产物环缩小 → 考虑 Favorskii 重排。
