# 酰基转化完整链路网络

## 题目

**(1)** 将下列羧酸衍生物按酰基化活性从高到低排序：

$$\text{酰氯} \quad \text{酸酐} \quad \text{酯} \quad \text{酰胺}$$

**(2)** 写出羧酸到酰氯、酰氯到酸酐、酸酐到酯、酯到酰胺的转化条件。

**(3)** 为什么酰氯不能直接一步转化为酰胺（需要控制条件）？在合成中如何实现"酰氯→酰胺"的高选择性？

## 参考答案

### (1) 酰基化活性排序

$$\text{酰氯} > \text{酸酐} > \text{酯} > \text{酰胺}$$

**活性由高到低**：

| 衍生物 | 活性 | 离去基团 | pKa（共轭酸） |
|:---|:---:|:---|:---:|
| **酰氯 RCOCl** | 最高 | Cl⁻ | -7 |
| **酸酐 (RCO)₂O** | 高 | RCOO⁻ | 4.8 |
| **酯 RCOOR'** | 中等 | R'O⁻ | 16 |
| **酰胺 RCONH₂** | 最低 | NH₂⁻ | 38 |

**规律**：离去基团的碱性越弱（共轭酸 pKa 越低）→ 离去能力越强 → 酰基化活性越高。

### (2) 转化条件

```
羧酸 → 酰氯：SOCl₂ 或 (COCl)₂ 或 PCl₅
酰氯 → 酸酐：RCOONa（羧酸盐）+ 酰氯
酸酐 → 酯：ROH + 碱（如 Py）
酯 → 酰胺：NH₃ 或 RNH₂（加热）
```

**完整链路**：

```
        SOCl₂
羧酸 ──────────→ 酰氯
        ↑              │
   RCOONa          RCOONa
        │              ↓
        └──── 酸酐 ←───┘
                  │
              ROH/碱
                  ↓
                 酯
                  │
              NH₃/Δ
                  ↓
                酰胺
```

### (3) 酰氯→酰胺的选择性控制

**问题**：酰氯太活泼，与胺反应剧烈，可能产生双酰化或副反应。

**解决方案**：

1. **控制温度**：低温（0°C）下缓慢加入胺 → 单酰化为主
2. **使用碱**：加入 Et₃N 或 NaOH 吸收生成的 HCl → 推动反应
3. **Schotten-Baumann 条件**：酰氯 + 胺在 NaOH/H₂O 中反应 → 高选择性
4. **使用酸酐代替酰氯**：酸酐活性适中，选择性更好

### 酰基转化的通用规律

**亲核酰基取代（NAS）**：

$$\text{R-CO-L} + \text{Nu}^- \rightarrow \text{R-CO-Nu} + \text{L}^-$$

**活性高的可以转化为活性低的**，反过来不行：

```
酰氯 → 酸酐 → 酯 → 酰胺 ✓（活性递减方向）
酰胺 → 酯 → 酸酐 → 酰氯 ✗（需要特殊试剂）
```

> 💡 **记忆口诀**：酰氯是"万能酰基化试剂"——可以从酰氯制备任何其他衍生物，但反过来不行。
