# 选择性还原场景判断

## 题目

**(1)** 将下列还原剂按还原能力从强到弱排序，并说明每种还原剂的特征选择性：

LiAlH₄、NaBH₄、DIBAL-H、Red-Al (NaAlH₂(OCH₂CH₂OCH₃)₂)

**(2)** 某分子同时含有酯基（-COOMe）和酮羰基（C=O），如何用 DIBAL-H 在 -78°C 下选择性还原酯基而不还原酮？

**(3)** 某分子同时含有酰胺（-CONR₂）和酯（-COOR'），用 Red-Al 还原时哪个先被还原？为什么？

## 参考答案

### (1) 还原剂排序与选择性

| 还原剂 | 还原能力 | 选择性特征 |
|:---|:---:|:---|
| **LiAlH₄** | **最强** | 还原几乎所有羰基（醛/酮/酯/酰胺/酸） |
| **Red-Al** | 强 | 还原酰胺 > 酯 > 醛/酮（酰胺选择性） |
| **DIBAL-H** | 中等 | -78°C：酯→醛（停在醛）；室温：酯→醇 |
| **NaBH₄** | **最弱** | 只还原醛/酮，不还原酯/酰胺/酸 |

**排序**：LiAlH₄ > Red-Al > DIBAL-H > NaBH₄

### (2) DIBAL-H选择性还原酯

**关键条件**：
- **温度**：-78°C（干冰/丙酮浴）
- **当量**：1.0 eq DIBAL-H
- **溶剂**：CH₂Cl₂ 或甲苯

**机理**：
1. DIBAL-H 的 Al 与酯的羰基氧配位 → 形成四面体中间体
2. 在 -78°C 下，中间体**稳定**，不进一步还原
3. 淬灭（加水/甲醇）→ 释放醛

```
R-COOMe + DIBAL-H (-78°C) → [四面体中间体] → R-CHO（停在醛）
```

**为什么酮不被还原**：DIBAL-H 在 -78°C 下对酮的还原速率远慢于对酯的还原速率（酯的羰基更缺电子，更易被亲核进攻）。

### (3) Red-Al对酰胺vs酯的选择性

**Red-Al 优先还原酰胺**，原因：

1. **酰胺的 C=O 更缺电子**：N 的给电子效应使酰胺的 C=O 极化程度适中，但 Al 的 Lewis 酸性可以与 N 配位 → 活化酰胺
2. **Red-Al 的 Al 与酰胺 N 配位** → 形成六元环过渡态 → 选择性还原酰胺
3. **酯的还原需要更高活化能** → 在酰胺存在时被抑制

```
Red-Al (1.0 eq) → 酰胺先还原为胺
Red-Al (2.0 eq) → 酰胺 + 酯都被还原
```

### 选择性还原的通用策略

| 场景 | 策略 |
|:---|:---|
| 酯→醛（停在醛） | DIBAL-H, -78°C, 1.0 eq |
| 酯→醇 | LiAlH₄ 或 NaBH₄（慢） |
| 酮→醇（不影响酯） | NaBH₄, 0°C |
| 酰胺→胺 | LiAlH₄ 或 Red-Al |
| 酰胺选择性（不影响酯） | Red-Al, 1.0 eq, 0°C |
| 醛选择性（不影响酮） | NaBH₄/CeCl₃ (Luche还原) |

> 💡 **核心原则**：选择性还原 = 选择合适的还原剂 + 控制温度 + 控制当量。
