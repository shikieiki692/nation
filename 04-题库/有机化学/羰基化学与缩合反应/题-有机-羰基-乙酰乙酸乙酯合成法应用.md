# 乙酰乙酸乙酯合成法应用

## 题目

（1）用乙酰乙酸乙酯合成法合成2-丁酮（甲乙酮），写出完整反应路线。

（2）用乙酰乙酸乙酯合成法合成环丙基甲基酮，写出反应路线。

（3）比较乙酰乙酸乙酯合成法与直接丙酮烷基化的优缺点。


![[base-catalysed-aldol.svg]]

## 参考答案

### （1）合成2-丁酮

**反应路线**：
$$\ce{CH3COCH2COOC2H5 ->[NaOEt] CH3COCHCOOC2H5^- Na+}$$
$$\ce{->[CH3I] CH3COCH(CH3)COOC2H5}$$
$$\ce{->[稀NaOH, \Delta] CH3COCH2CH3 + CO2 + C2H5OH}$$

**关键步骤**：
1. 醇钠拔氢形成烯醇负离子
2. 与碘甲烷发生SN2取代
3. 稀碱水解酯基
4. 酸化加热脱羧得目标产物

### （2）合成环丙基甲基酮

**反应路线**：
$$\ce{CH3COCH2COOC2H5 ->[NaOEt] CH3COCHCOOC2H5^- Na+}$$
$$\ce{->[BrCH2CH2Br, 1:1] 环丙基取代乙酰乙酸乙酯}$$
$$\ce{->[稀NaOH, \Delta] 环丙基甲基酮}$$

**注意事项**：
- 乙酰乙酸乙酯：二卤代烃 = 1:1
- 必须分步加碱（不能形成二负离子）
- 先形成单负离子与一卤代端反应，再拔第二个氢完成环化
- 适用范围：n=2-5（三元环至六元环）

### （3）两种方法比较

| 方面 | 乙酰乙酸乙酯合成法 | 直接丙酮烷基化 |
|------|---------------------|----------------|
| 碱强度 | 较弱碱（醇钠） | 强碱（如LDA） |
| 反应条件 | 温和 | 苛刻（低温） |
| 选择性 | 好（单烷基化为主） | 差（多烷基化副产物） |
| 产率 | 较高 | 较低 |
| 步骤 | 多步（烷基化→水解→脱羧） | 少步 |

## 解题思路

1. 乙酰乙酸乙酯的α-H酸性更强（pKa≈11），比丙酮（pKa≈19）更易形成烯醇负离子
2. 可作为丙酮等价物使用
3. 稀碱水解→酮式水解（得取代丙酮）
4. 浓碱水解→酸式水解（得取代乙酸）
5. 脱羧是关键步骤，通过六元环过渡态进行
