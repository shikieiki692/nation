# 酰胺水解与Hofmann降解

## 题目

（1）写出乙酰胺在酸性和碱性条件下水解的反应方程式。

（2）写出苯甲酰胺在Br₂/NaOH作用下发生Hofmann降解的反应方程式和机理。

（3）比较酰胺水解和Hofmann降解的产物差异。

## 参考答案

### （1）乙酰胺水解

**酸性水解**：
$$\ce{CH3CONH2 + H3O+ -> CH3COOH + NH4+}$$

**碱性水解**：
$$\ce{CH3CONH2 + NaOH -> CH3COONa + NH3}$$

**产物**：乙酸（或乙酸钠）+ 氨（或铵盐）

### （2）Hofmann降解

**反应方程式**：
$$\ce{C6H5CONH2 + Br2 + 4NaOH -> C6H5NH2 + Na2CO3 + 2NaBr + 2H2O}$$

**反应机理**：

**步骤1**：碱拔氢形成N-溴代酰胺
$$\ce{C6H5CONH2 + Br2 + NaOH -> C6H5CONHBr + NaBr + H2O}$$

**步骤2**：碱拔氢形成氮负离子
$$\ce{C6H5CONHBr + NaOH -> C6H5CONBr- Na+ + H2O}$$

**步骤3**：重排（Hofmann重排）
$$\ce{C6H5CONBr- -> C6H5N=C=O + Br-}$$

**步骤4**：异氰酸酯水解
$$\ce{C6H5N=C=O + H2O -> C6H5NHCOOH -> C6H5NH2 + CO2}$$

**产物**：苯胺（比原料少一个碳）

### （3）两种反应比较

| 方面 | 酰胺水解 | Hofmann降解 |
|------|----------|-------------|
| 产物 | 羧酸 + 氨 | 伯胺（少一个碳） |
| 条件 | 酸/碱 + 加热 | Br₂ + NaOH |
| 碳数变化 | 不变 | 减少一个碳 |
| 应用 | 制备羧酸 | 制备伯胺 |

**Hofmann降解价值**：
- 从酰胺制备少一个碳的伯胺
- 反应条件温和，产率高
- 是制备伯胺的重要方法

## 解题思路

1. 酰胺水解：酸或碱催化，得羧酸
2. Hofmann降解：Br₂/NaOH，得少一个碳的伯胺
3. 关键步骤：N-溴代酰胺重排
4. 产物碳数变化是主要区别
