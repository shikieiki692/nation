# Cannizzaro歧化反应机理

## 题目

（1）写出苯甲醛在浓NaOH水溶液中发生Cannizzaro反应的完整机理。

（2）为什么只有无α-氢的醛才能发生Cannizzaro反应？

（3）预测甲醛和苯甲醛在NaOH水溶液中的交叉Cannizzaro反应产物。

## 参考答案

### （1）苯甲醛Cannizzaro反应机理

**反应方程式**：
$$\ce{2C6H5CHO + NaOH -> C6H5CH2OH + C6H5COONa}$$

**反应机理**：

**步骤1**：OH⁻亲核进攻羰基碳
$$\ce{C6H5CHO + OH- -> C6H5CH(OH)O-}$$

**步骤2**：氢负离子转移（关键步骤）
$$\ce{C6H5CH(OH)O- + C6H5CHO -> C6H5CH2O- + C6H5COO-}$$

**步骤3**：质子转移
$$\ce{C6H5CH2O- + H2O -> C6H5CH2OH + OH-}$$

### （2）反应条件解释

**为什么需要无α-氢**：
- 有α-氢的醛在碱性条件下会发生Aldol缩合（竞争反应）
- 无α-氢的醛无法发生Aldol缩合，只能发生Cannizzaro反应
- 典型底物：苯甲醛、三氯乙醛、甲醛

**反应本质**：歧化反应（disproportionation）
- 一分子醛被氧化为羧酸（氧化数升高）
- 一分子醛被还原为醇（氧化数降低）

### （3）交叉Cannizzaro反应

**反应**：甲醛 + 苯甲醛 + NaOH → 甲醇 + 苯甲酸钠

**选择性**：
- 甲醛更活泼（位阻小），优先被氧化为甲酸
- 苯甲醛被还原为苯甲醇

**产物**：$\ce{HCOONa + C6H5CH2OH}$

## 解题思路

1. 识别无α-氢的醛（苯甲醛、三氯乙醛等）
2. 碱性条件是必要条件
3. 氢负转移是关键步骤（类似LiAlH₄的还原）
4. 交叉反应中，更活泼的醛优先被氧化
