# 硝基还原与芳香胺制备

## 题目

（1）写出硝基苯还原为苯胺的反应方程式，列出至少两种还原方法。

（2）当分子中同时含有硝基和羰基时，如何选择性地只还原硝基？

（3）设计一条从苯合成间溴苯胺的路线。

## 参考答案

### （1）硝基苯还原为苯胺

**方法一：金属/酸还原**
$$\ce{C6H5NO2 + 3Sn + 7HCl -> C6H5NH3+Cl- + 3SnCl2 + 2H2O}$$
$$\ce{C6H5NH3+Cl- + NaOH -> C6H5NH2 + NaCl + H2O}$$

**方法二：催化氢化**
$$\ce{C6H5NO2 + 3H2 ->[Pd/C or Raney Ni] C6H5NH2 + 2H2O}$$

**方法三：铁粉还原**
$$\ce{C6H5NO2 + 3Fe + 6HCl -> C6H5NH2 + 3FeCl2 + 2H2O}$$

### （2）选择性还原硝基

**问题**：催化氢化（H₂/Pd）会同时还原硝基和羰基

**解决方案**：
- 使用ZnCl₂/H⁺或SnCl₂/H⁺条件
- 这些试剂选择性还原硝基，不影响羰基

**机理**：金属/酸体系是化学还原剂，对硝基有选择性，不还原羰基

### （3）合成间溴苯胺

**路线**：
$$\ce{C6H6 ->[HNO3/H2SO4] C6H5NO2}$$
$$\ce{->[Fe/HCl] C6H5NH2}$$
$$\ce{->[Ac2O] C6H5NHCOCH3}$$
$$\ce{->[Br2/FeBr3] 间-BrC6H4NHCOCH3}$$
$$\ce{->[H3O+, \Delta] 间-BrC6H4NH2}$$

**解释**：
- 氨基是强致活基（邻对位定位），直接溴化会得多溴代产物
- 需先用乙酰基保护氨基
- 乙酰氨基是中等致活基，可控制单溴代
- 最后水解去保护得目标产物

## 解题思路

1. 硝基还原是制备芳香胺的重要方法
2. 金属/酸还原选择性好，适用于含敏感基团的底物
3. 催化氢化效率高，但选择性较差
4. 氨基保护策略：乙酰化→取代→水解
5. 定位基效应：氨基是强致活基，需保护以控制反应
