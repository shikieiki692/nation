# 等效氢判断与化学位移分析

> **来源**：Zchem有机反应合成与机理 上册L2
> **难度**：⭐⭐⭐⭐
> **题目类型**：例题

## 题目

核磁共振氢谱中，等效氢产生相同的信号。判断等效氢的常用方法是Replacement Test。

**题目**：
1. 解释Replacement Test的原理：将目标氢原子替换为氘原子后，若生成的分子A和B满足什么条件，则H1和H2等效？
2. 说明以下化学位移范围对应的氢类型：
   - ~0.9 ppm
   - ~2.3 ppm
   - 4.5-6.5 ppm
   - 7-8 ppm
   - ~10 ppm
   - 10-12 ppm
3. 苯环的环电流效应导致环内侧氢和环外侧氢的化学位移差值可达7 ppm。解释该现象
4. CDCl₃溶剂中残留的CHCl₃在7.26 ppm处出现单峰，说明该峰的来源和识别方法

## 参考答案

### 1. Replacement Test 原理

分别把 H1、H2 换成氘后比较所得分子：

- 若两种产物完全相同 → H1、H2 为 **homotopic（全同/等价）**；
- 若两种产物互为**对映体** → H1、H2 为 **enantiotopic（对映异位/等价）**；
- 若两种产物互为**非对映体** → H1、H2 为非等价的 **diastereotopic（非对映异位）**。

前两种情况中 H1、H2 化学等价，在非手性环境中 NMR 信号相同；第三种情况在普通条件下也不等价。

### 2. 化学位移范围

| δ / ppm | 主要氢类型 |
|:---|:---|
| ~0.9 | 烷基（如 CH₃、长链亚甲基末端） |
| ~2.3 | 羰基或芳环 α 位氢（如 Ar–CH₃、RCO–CH₃、苄基 CH₂） |
| 4.5–6.5 | 烯氢（=CH），也包含部分端炔或杂原子取代的 CH |
| 7–8 | 芳环氢（Ar–H） |
| ~10 | 醛基氢（–CHO） |
| 10–12 | 羧基氢（–COOH），常因交换变宽 |

### 3. 苯环环电流效应

苯环在外磁场中产生 π 电子环流，环电流感应出次级磁场：环**外侧**（周边氢所在处）次级磁场与外磁场同向，被**去屏蔽**、化学位移移向低场（约 7–8 ppm）；环**内侧**/环中心区域次级磁场与外磁场反向，被**屏蔽**、化学位移移向高场。因此环内、环外质子化学位移差值可超过 7 ppm，是芳香性环电流的典型证据。

### 4. 残留 CHCl₃ 峰

- 来源：CDCl₃ 溶剂中含少量未完全氘代的 CHCl₃ 杂质，其唯一氢给出单峰。
- 识别：δ 7.26 ppm 附近单峰，峰高与溶剂纯度有关；与样品芳氢可通过峰形、位置及 ¹³C 卫星峰区分；换用其他氘代溶剂或提高纯度可消除。
