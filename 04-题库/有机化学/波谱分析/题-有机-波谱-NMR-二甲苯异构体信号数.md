# 二甲苯异构体的¹H NMR信号数比较

## 题目

对二甲苯、邻二甲苯和间二甲苯分别有几组 ¹H NMR 信号？画出每种异构体的对称元素，并标明各组氢的化学位移区域。

## 参考答案

### 对二甲苯（1,4-二甲苯）

**对称元素**：两个对称面（σv 和 σh），一个 C₂ 轴

```
    CH₃       CH₃
     |         |
  H--C--H   H--C--H
     ‖         ‖
  H--C---------C--H
     |         |
  H--C---------C--H
     ‖         ‖
  H--C--H   H--C--H
```

**信号数：2 组**
- **CH₃ H**（6H，单峰，~2.3 ppm）— 两个甲基完全对称
- **芳 H**（4H，单峰，~7.1 ppm）— 四个芳氢完全对称

### 邻二甲苯（1,2-二甲苯）

**对称元素**：一个对称面（σ，通过 C1-C2 键中点垂直于环面）

```
    CH₃   CH₃
     |     |
  H--C₁---C₂--H
     ‖     ‖
  H--C₆---C₃--H
     |     |
  H--C₅---C₄--H
```

**信号数：3 组**
- **CH₃ H**（6H，单峰，~2.3 ppm）
- **芳 H₃/H₆**（2H，~7.1 ppm）— 对称面上对称
- **芳 H₄/H₅**（2H，~7.2 ppm）— 对称面上对称

> H₃ 与 H₆ 等价，H₄ 与 H₅ 等价，但 H₃/H₄ 不等价。

### 间二甲苯（1,3-二甲苯）

**对称元素**：一个对称面（σ，通过 C2 和 C5）

```
    CH₃       CH₃
     |         |
  H--C₁---C₂---C₃--H
     ‖     |     ‖
  H--C₆---C₅---C₄--H
```

**信号数：4 组**
- **CH₃ H**（6H，单峰，~2.3 ppm）
- **H₂**（1H，单峰或窄多重峰，~7.0 ppm）— 位于两个甲基之间，独特环境
- **H₄/H₆**（2H，~7.1 ppm）— 对称面等价
- **H₅**（1H，~7.2 ppm）— 独特环境

### 汇总对比

| 异构体 | 对称元素 | ¹H NMR 信号数 |
|:---|:---|:---:|
| 对二甲苯 | 2个对称面 + C₂ | **2** |
| 邻二甲苯 | 1个对称面 | **3** |
| 间二甲苯 | 1个对称面 | **4** |

> 💡 **规律**：对称性越高 → 等价氢组数越少 → NMR 信号数越少。对二甲苯对称性最高，信号最少。

> ⚠️ **注意**：以上分析基于快速旋转的甲基。实际谱图中，芳氢可能因偶合出现多重峰，但信号**组数**不变。
