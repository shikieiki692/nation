### 真题双仓分工（2026-09-02 定）

真题**故意存两份、不合并**，两者是「筛子」的两端而非重复收录：

| 仓 | 路径 | 角色 | 格式特征 |
|---|---|---|---|
| 仓储层 | `04-题库/真题/`（687） | 按届次归档的**原始入库**，追求全 | 与普通题同构：答案折叠在 `<details>` 内，六字段齐全 |
| 交付层 | `05-真题库/`（63） | 已精做过解析的**讲评用题**，追求深 | 一题一文件；答案**不折叠**，正文为 `## 题目` + `## 解析`（含 分析/解答/反思 三段）；独有 `year` / `type_tag` / `related_notes` 字段 |

- **检索时合并看**：`02-数据库/题库.base` 的「真题（双仓合并）」视图同时拉两边。
- **上浮通道**：`04-题库/真题/` 里写好三段解析的题，可上浮到 `05-真题库/`，用 `cross_references` 双向互链。
- ⚠️ 不要为了「统一格式」把 687 个批量迁到 05-真题库——大部分题没有解析可写，会产出 600+ 空壳。
| 习题书源稿 | `04-课件/习题集/习题书-{学生版,教师版}/` | 68 | 构建产物，勿手改 |
| 随堂习题集 | `04-课件/习题集/第一轮化学原理-*.md` | 9 | 8 卷 407 题 + 总索引（手编） |
| Word 成品 | `00-首页/题组Word/习题书/` | docx×99 | 教师版33/学生版33/打印版33 |
| 审核区 | `10-待审核区/` | 1 | 仅 README，当前无积压 |

## 三、frontmatter 字段规范（题目文件必读）

| 字段 | 取值规范 | 说明 |
|---|---|---|
| `type` | **题目**（唯一合法题目类型） | ⚠️ 例题也写 `type: 题目`，用 `question_type: 例题` 区分——`type: 例题` 不被任何管线识别（例9.5/Ch09 批次踩坑） |
| `pack` | `模块习题集` / `章节练习` / `综合模拟卷`(决赛真题) / `预赛专项` | 入书门槛：模块习题集 + subject_module 齐备 |
| `subject_module` | `化学原理` / `结构化学` / `有机化学` / `元素与分析`（四篇之一，**单行标量**） | 构建路由的第一道闸，缺了或写成 YAML 列表都进不了 pool。**校验器 QB_ENUM 四个受约束字段之一** |
| `source_subject` | **来源教材科目**，16 值（如 `无机和结构化学`/`物理化学`/`综合`） | 2026-09-02 由 `subject` 改名消歧。**不校验收敛**，与 `subject_module` 分工并存——两者值不同是设计意图（全库 1,906 处），勿“修正”成一致 |
| `teaching_level` | `基础` / `巩固` / `拓展` / `竞赛`（**4 档**） | 2026-09-02 由 14 种收敛而来（`入门`→基础、`强化`/`挑战`→拓展、`拔高`/`提高`/`进阶`/`决赛`/`高级`/`竞赛决赛`/`竞赛深化`→竞赛、`竞赛拔高`→竞赛）。**不校验**，按 4 档写 |
| `module` | 章/主题级中文值 | 分类线索之一，但以 subject_module + 文件路径优先 |
| `submodule` | 主题词（标量） | 分类精确层依据；⚠️ 勿从文件名机械截取（“螺吡喃机械力变色”曾错标“机械力化学”） |
| `status` | `已补全答案` / `已填充` / `deprecated` | **deprecated=已废弃**，构建跳过（现已有日志），须写 `superseded_by` 指明取代文件 |
| `fidelity` | `原书逐字` / `原书改写` / `自编` | 成书章内排序依据（逐字>改写>自编） |
| `syllabus_codes` | 整数数组，码表 = `02-考纲条目` 各条目 frontmatter 的 `syllabus_code`（基础要求 1–56） | 质量审计“考纲相关”判定依据 |
| `question_type` | 列表，8 种原子题型 `选择`/`填空`/`简答`/`计算`/`推断`/`作图`/`机理`/`方程式书写` + 角色值 `例题`/`综合` | 2026-09-02 B2b 批量补标，覆盖 4.7% → **29.4%**。仍缺 2,970 条，见下方「题型补标」说明 |
| `knowledge_points` | **只放能解析到 `03-知识点/` 的 wikilink** | 六字段之一，**不允许为空**；断链会被 `validate_kb` 判 warning、`audit_question_bank` 判 P1 |
| `concepts` | 纯文本数组（**不写 `[[ ]]`**） | 2026-09-02 新增：比知识点更细的概念标签（如「极弱酸强化」「计量点pH计算」）。**不参与断链校验**，只用于检索。与 `knowledge_points` 的分工见下方说明 |
| `used_in` | 文本数组，记录该题被哪些卷/讲义用过 | 组卷脚本自动回填；`题库.base` 的「未用过的题」视图依赖它 |

> **`knowledge_points` vs `concepts`（2026-09-02 拆分）**：
> 原先题目把「气体体积」「离子对效应」「玻尔兹曼常数」这类**比知识点更细的概念**也写成 `［［双链］］`，
> 而 `03-知识点/` 只有 948 个文件，导致 1,590 条红链——不是写错，是**粒度错配**。
> 现按能否解析自动拆分：解析得到的留在 `knowledge_points`（继续可校验、维系知识图谱）；
> 解析不到的剥离 `[[]]` 移入 `concepts`（纯标签，可检索、不告警）。信息零丢失。
> 拆分脚本：`.workbuddy/scripts/split_kp_concepts.py`。

### `question_type` 的两个维度（2026-09-02 B2b 定）

| 维度 | 取值 | 判定依据 |
|---|---|---|
| **作答形式** | `选择` / `填空` | 客观信号：选项行 `A. B. C. D.`、下划线/空格占位 `____` |
| **内容题型** | `计算` / `推断` / `作图` / `机理` / `方程式书写` / `简答` | 题干动词 + 宾语 |

两者**并存不互斥**，组卷时按哪个维度筛都能命中：

```
求 pH 的选择题          → [选择, 计算]
「配平下列方程式 (1)____」 → [填空, 方程式书写]
「画出 A 的结构简式____」 → [填空, 作图]
```

**三条语义裁定**（用户 2026-09-02 拍板，勿再改）：

1. **「画出 A 的结构式 / 结构简式 / 构型」统称 `作图`**，不拆给 `推断`。
   理由：从作答动作看「要画图」就是一类。实测作图档 164 条里 114 条是画结构、
   只有 10 条是画装置图/相图/能级图，拆开会让 `作图` 缩到 26 条失去意义。
2. **`简答` 不参与自动推断**。它是「没识别出题型」的委婉说法，不是真标签；
   脚本里归 T3 档只统计不写，避免把 542 条题草率盖上「简答」。
3. **一题多问的真题大题留空不猜**。含 `7-1/7-2/7-3`、`(1)(2)(3)`、`10.1/10.2`
   等 ≥3 个小问的干，单一标签必然失真（701 条）。例外：若各小问题型**同质**
   （如「计算下列溶液的 pH：(1)…(2)…(3)…」三问全是计算），则按该题型写（25 条）。

**补标入口**：`02-数据库/题库.base` → 「题型待标注（按目录批量补）」：
按 `所在目录` 排序，同目录的题高度同质，可一次标几十道。
「题型待标注·真题优先」单独列出 254 条真题。
剩余 2,970 条中 71% 集中在 `04-题库/教材习题`（结构化学 972 / 有机 962）。

推断脚本：`.workbuddy/scripts/infer_question_type.py`（`--write` 才落盘，幂等）。

## 七、架构规则（踩坑沉淀）

1. **一个题目 = 一个 md = type:题目**。合集/题组文件（type:题组）只做浏览整理，不进习题书；若要入书必须拆成单题文件。
2. **deprecated 必须写 superseded_by**，且取代文件必须真实存在、pack=模块习题集——否则取代链断裂=题目静默消失（例6.5/13.4/14.8 事故）。构建现已对 deprecated 打日志。
3. **subject_module 是路由第一闸**：必须是四篇之一的单行标量。submodule 不得从文件名机械截取。
4. **同一道题可出现在多载体**（习题书整大题 vs 习题集取小问 vs 测试卷）：设计互补，不是重复收录。
5. **数字以本页为准**；构建脚本自动回写 `04-课件/习题集/README.md`，手工改动其他文档数字前先跑构建对账。
