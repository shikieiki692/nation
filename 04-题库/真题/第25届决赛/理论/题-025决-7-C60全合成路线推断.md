# 题-025决-7：C₆₀全合成路线推断

## 题目

> [!note] 来源
> 第25届中国化学奥林匹克（决赛）第7题（18分）。题面合成路线图已回源核验并嵌入。

2002 年，Scott 等人首次完成了 $\mathrm{C_{60}}$ 的化学全合成，该成果为今后合成更多和更丰富的 $\mathrm{C_{60}}$ 衍生物带来了可能。下面是其全合成的路线（无机产物及副产物已略去）：

![[5bb357e7c8ab81ece52231d8dfd9db4fa6b3d85e671715c32c20d37767a2691d.jpg]]

7-1 写出上述合成路线中 a、b、c 和 d 所对应的试剂或反应条件；

7-2 画出上述合成路线中中间体 A～I 的结构简式；

7-3 写出中间体 J 的对称元素；

7-4 给出从中间体 I 到 J 的反应机理。

## 参考答案

### 7-1

- a：格氏试剂制备；为只在 Br 端生成格氏试剂，应使用 Mg/无水乙醚。
- b：乙醛。
- c：酸化，使加成所得醇镁转化为醇。
- d：2-萘甲醛；该步为 Wittig 反应。

## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 格氏反应 | 选择性制备 Br 端格氏试剂 |
| 醇的生成与转化 | 乙醛加成、酸化、溴代 |
| Wittig 反应 | 构建碳碳双键 |
| NBS/KCN 转化 | G 的官能团构建 |
| Friedel-Crafts 酰基化 | 分子内关环形成 I |
| 分子对称性 | J 的 $C_3$ 轴与对称面 |

## 解题思路

1. 先由题面路线中已知的邻二氯苯衍生物、PBr₃、PPh₃/EtOLi、NBS/KCN、AlCl₃、TiCl₄ 等条件识别各步反应类型。
2. a～c 推断时注意二卤代芳烃选择性制备溴端格氏试剂所需的无水乙醚条件。
3. d 与 E 通过 Wittig 反应形成 F 中的双键。
4. G→H→I 分别对应腈基转化、酰氯形成及分子内 Friedel-Crafts 酰基化。
5. I→J 为三聚成环；源文对机理图的可靠性有明确评注，答题时应区分“参考答案图示”和“原始文献更合理的 aldol cyclotrimerization 描述”。
