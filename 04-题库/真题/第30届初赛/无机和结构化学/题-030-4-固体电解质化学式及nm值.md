固体电解质以其在电池、传感器等装置中的广泛应用而备受关注。现有一种由正离子 $A^{n+}$、$B^{m+}$ 和负离子 $X^{-}$ 组成的无机固体电解质，该物质 50.7 ℃ 以上形成无序结构（高温相），50.7 ℃ 以下变为有序结构（低温相），二者结构示意见下图。图中，浅色球为负离子；高温相中的深色球为正离子或空位；低温相中的大深色球为 $A^{n+}$ 离子，小深色球为 $B^{m+}$ 离子。

高温相

低温相

推出这种电解质的化学式，写出 n 和 m 的值。

温度变化会导致晶体在立方晶系和四方晶系之间转换，上述哪种晶相属于立方晶系？

![[808e161d8fb206a0e535e0d992cd1087b40ae82dddf5deed9a18fb18904492de.jpg]]

写出负离子的堆积方式及形成的空隙类型。指出正离子占据的空隙类型及占有率。

高温相具有良好的离子导电性，这源于哪种离子的迁移？简述导电性与结构的关系。

## 参考答案

**（1）**
- **化学式**：$A_2BX_4$
- **n = 1**，**m = 2**





本题的主要考点为晶体结构，考查立方晶系和四方晶系的概念、对晶胞示意图的理解和识图能力、晶体空隙及其对导电性的影响等知识。

高温相中深色球代表的是统计平均分布的未知比例的阳离子及空隙，只能从低温相的晶胞着手分析。从题中低温相晶体结构图可以看出，低温相晶体中，阴离子浅色球以立方最密堆积形式排列，共8个 $X^{-}$；阳离子填充在四面体空隙中，共4个 $A^{n+}$、2个 $B^{m+}$。故化合物的最简式为 $A_{2}BX_{4}$。

如题所述，X 为 -1 价阴离子，根据晶体电荷守恒，整数 n、m 满足 $2n + m = 4$。故 n = 1, m = 2。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 晶胞分析 | 从低温相晶胞图统计各离子数目 |
| 立方最密堆积 | 阴离子X⁻呈ccp排列，产生八面体和四面体空隙 |
| 电荷守恒 | 化合物整体电中性：2n + m = 4 |
| 化学式推导 | 根据晶胞中离子数目比确定最简式 |
| 高温相/低温相 | 高温相为无序结构，低温相为有序结构 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 从高温相着手分析 | 高温相阳离子和空位统计平均分布，无法确定比例 |
| 离子数目统计错误 | 需仔细数清晶胞中各离子的位置（顶点、棱心、面心、体内） |
| 忽略n、m为正整数的限制 | 2n+m=4的正整数解只有n=1,m=2和n=2,m=0（后者舍去） |
| 未验证电荷守恒 | 推导后应检验化学式是否满足电中性 |

**（2）**
**高温相**属于立方晶系。





高温相的两种阳离子和空隙平均分布，可从统计学意义上视为等同的。高温相的晶胞为立方 ZnS 型，故高温相为立方晶系。也可通过立方晶系与四方晶系的区别来判断：立方晶系比四方晶系的对称性更高，晶胞的 4 条体对角线分别是 4 根三重旋转轴 $(4C_{3})$。观察晶体结构图可知，高温相满足这一条件。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 立方晶系特征 | 具有4个三重旋转轴（沿体对角线方向） |
| 四方晶系特征 | 只有1个四重旋转轴，无4个三重轴 |
| 对称性比较 | 立方晶系对称性高于四方晶系 |
| 立方ZnS型结构 | 高温相为闪锌矿型结构，属于立方晶系 |
| 统计平均分布 | 高温相中阳离子和空位统计平均，提高对称性 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 认为低温相是立方晶系 | 低温相阳离子有序排列，对称性降低 |
| 混淆立方与四方的判断标准 | 关键看是否具有4个C₃轴 |
| 仅从晶胞形状判断 | 需从对称元素角度严格判断 |
| 忽略统计平均化的影响 | 高温相无序分布使对称性升高 |

**（3）**
- **负离子堆积方式**：立方最密堆积（ccp，ABCABC...堆积）
- **形成的空隙类型**：八面体空隙和四面体空隙
- **正离子占据的空隙类型**：四面体空隙
- **正离子对空隙的占有率**：$3/8 = 37.5\%$





晶体中阴离子堆积方式如图 4.1。晶体由不同颜色标明的 A、B 和 C 三种堆积层以 …ABCABC… 的形式堆积，故阴离子呈立方最密堆积。阴离子的堆积产生了两种空隙：八面体空隙和四面体空隙。八面体空隙位于棱心和体心，共 4 处；四面体空隙位于晶胞的 $(\pm1/4, \pm1/4, \pm1/4)$，共 8 处，正离子占据的是四面体空隙。

图 4.1 的立方体骨架中包含 4 个 X 负离子，其间存在 8 个四面体空隙，而 3 个正离子占据了其中的 3 个空隙，故正离子对空隙的占有率为 37.5%。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 立方最密堆积 | ccp，堆积序列为ABCABC... |
| 八面体空隙 | 位于棱心和体心位置 |
| 四面体空隙 | 位于(±1/4, ±1/4, ±1/4)位置 |
| 空隙数目比 | ccp中：四面体空隙数=2×原子数，八面体空隙数=原子数 |
| 空隙占有率 | 被占据空隙数/总空隙数 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 写成六方最密堆积 | 应为立方最密堆积（ccp） |
| 空隙类型遗漏 | 需同时写出八面体和四面体两种空隙 |
| 空隙数目计算错误 | 4个X⁻对应8个四面体空隙、4个八面体空隙 |
| 占有率计算错误 | 3个正离子/8个四面体空隙=37.5% |
| 混淆正离子占据的空隙类型 | 正离子占据四面体空隙而非八面体空隙 |

**（4）**
源于 **$A^{+}$ 离子**的迁移。





离子导电是在外加电场作用下，介质中的阴阳离子发生定向迁移的现象。该现象通常发生于熔融盐及电解质溶液中。通常离子晶体难以导电，将其加热至熔点附近才会引起电导率的上升。但是，少数晶体在相对较低的温度下即可获得较高的电导率，这种现象一般是晶体内存在空隙且至少一种离子可以在其间较为自由地运动引起的，它使晶体产生了离子导电性，这也就是常说的固体电解质的工作原理。体积较大的阴离子通常不易运动，构成刚性的晶格骨架，阳离子在阴离子的空隙间迁移产生离子导电性，如本题中的阳离子在晶体中存在的大量的四面体空隙间迁移从而导电，这类阳离子迁移导电的晶体被称为阳离子固体电解质。

在低温时，该晶体中的离子热运动的动能不足，无法跨越在四面体空隙间迁移的能垒，所以两种阳离子处于固定的位置上。而温度升高时，离子的热运动动能较高，容易跨过能垒，造成四面体空隙中 $A$、$B$ 阳离子分布的统计平均化，形成了新的相，即发生了低温相到高温相的相变。二者的电荷数分别为 +1 和 +2，可以对迁移的活化能和速率造成明显的差异：电荷数较低的原子在晶体静电场中四面体空隙处和三角形空隙处的势能差更低，即迁移能垒更低。而题目中没有强调 $A^{+}$ 和 $B^{2+}$ 的离子半径差异有多大，与电荷数相比并不是迁移速率的主要影响因素。综上所述，$A^{+}$ 更容易迁移。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 固体电解质原理 | 阳离子在阴离子骨架的空隙间迁移导电 |
| 阳离子迁移 | 体积较小的阳离子比阴离子更易迁移 |
| 能垒与温度 | 低温时动能不足，高温时可跨越迁移能垒 |
| 电荷数影响 | +1价离子比+2价离子迁移能垒更低 |
| 相变与导电性 | 相变后阳离子统计平均分布，导电性突增 |
| Ag₂HgI₄ | 类似结构的经典固体电解质，50.7℃相变 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 认为两种阳离子都迁移 | 实验表明主要是A⁺迁移，B²⁺迁移贡献很小 |
| 认为阴离子迁移 | 阴离子体积大，构成刚性骨架，不易迁移 |
| 忽略电荷数对迁移的影响 | +1价离子迁移能垒低于+2价离子 |
| 未联系相变解释导电性 | 需说明低温相→高温相的相变使阳离子可自由迁移 |
| 混淆热力学与动力学 | 相变是热力学平衡问题，迁移优先性是动力学问题 |
