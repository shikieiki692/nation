## 参考答案

**（1）**
![[mineru/02-真题解析/30届初赛试题解析_images/fe9ddf047af67199ed14673ac6f8143dfe6eebeb11a3e47dca4e4dcfc9bdc3c8.jpg]]

**B 为 N-羟乙基乙酰胺（N-(2-羟乙基)乙酰胺）**





本小题中，底物氨基乙醇含有羟基和氨基两个官能团，均可与乙酸酐发生反应（醇解和胺解）。一般来说，氨基氮原子的亲核性强于羟基氧原子，会优先发生胺解；然而，在盐酸中发生的却是醇解反应。这是由于具有碱性的氨基会被盐酸质子化，生成铵盐从而失去亲核性。因此，反应物中仅有的亲核基团羟基便与乙酸酐发生酰基碳上的亲核取代反应，得到化合物 A。

而在碱性条件 $(\mathrm{K}_2\mathrm{CO}_3)$ 下则不存在上述问题，因而得到的产物 B 就是乙酸酐的胺解产物：N-羟乙基乙酰胺。这里，题目已经明确提示 B 是非环状的，也就排除了羟基和氨基都发生亲核进攻而生成了 B' 这种可能。

![[mineru/02-真题解析/30届初赛试题解析_images/c33109fba7423befd1b93b18eb8d6b3adee73a3665e762f359c8501ff19f4cf1.jpg]]  
B'（环状副产物，非题目所求）

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 胺解 vs 醇解 | 氨基亲核性强于羟基，通常优先发生胺解 |
| 酸碱条件影响 | 酸使氨基质子化失去亲核性，碱中氨基保持亲核性 |
| 乙酸酐反应 | 与胺反应生成酰胺，与醇反应生成酯 |
| 选择性控制 | 通过pH调控氨基和羟基的反应选择性 |

**（2）**
在盐酸中，氨基乙醇的氨基被质子化生成铵盐，失去亲核性，而羟基保持亲核性，因此乙酸酐与羟基发生醇解反应生成酯（化合物A）。

在碳酸钾碱性条件下，氨基未被质子化，保持较强的亲核性，而氨基的亲核性强于羟基，因此乙酸酐优先与氨基发生胺解反应生成酰胺（化合物B）。





本小题中，底物氨基乙醇含有羟基和氨基两个官能团，均可与乙酸酐发生反应（醇解和胺解）。一般来说，氨基氮原子的亲核性强于羟基氧原子，会优先发生胺解；然而，在盐酸中发生的却是醇解反应。这是由于具有碱性的氨基会被盐酸质子化，生成铵盐从而失去亲核性。因此，反应物中仅有的亲核基团羟基便与乙酸酐发生酰基碳上的亲核取代反应，得到化合物 A。

而在碱性条件 $(\mathrm{K}_2\mathrm{CO}_3)$ 下则不存在上述问题，因而得到的产物 B 就是乙酸酐的胺解产物。

**知识拓展：**

为什么在 9-1 中，乙酸酐可以出现在一个水相反应中呢？其实，乙酸酐于水相中反应在合成酰胺中是一个成熟的应用。主要的原因在于胺、醇和水三者竞争时，亲核性呈现一个递减的序列。比如乙酰苯胺的合成，一般的做法是先将苯胺做成盐酸盐水溶液，然后加入等物质的量的乙酸钠水溶液和乙酸酐。因为反应物都溶于水，该反应为均相反应。此反应中，乙酸钠的加入十分重要，它可将苯胺盐酸盐中和，释放出亲核性远强于水的氨基，从而降低乙酸酐水解的概率。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 氨基质子化 | HCl使-NH₂→-NH₃⁺，失去亲核性 |
| 亲核性顺序 | 游离氨基 > 羟基 > 水 |
| 酸碱调控选择性 | 酸性条件保护氨基，碱性条件活化氨基 |
| 乙酸酐醇解 | 与醇反应生成酯和乙酸 |
| 乙酸酐胺解 | 与胺反应生成酰胺和乙酸 |

## 🔗 同大题小问

**（3）**
化合物 A（酯）在碱性条件下经历分子内重排转化为 B（酰胺）。首先，氨基（被碱中和后重新具有孤对电子）对酯羰基进行亲核加成，形成一个稳定的五元环中间体（四面体中间体）。随后该中间体裂解，C-O 键断裂，C-N 键保留，生成热力学上更稳定的酰胺 B。





A 如何在碱性条件下转化为 B？首先，可以排除酯先水解后形成酰胺的想法：水解得到的羧酸负离子亲电性非常弱，无法接受氨基的亲核进攻。故此反应应该经历分子内重排过程。

观察产物，最后氮原子取代了氧原子与羰基碳相连，因此在过程中的某一步，必有 C-N 键形成、C-O 键断裂。在铵正离子被碱中和后，氮原子重新具有孤对电子，可以通过亲核加成的方式与羰基碳相连，而形成的恰好是一个稳定的五元环。

我们迫切想知道的中间体结构，原来就是之前想到的 B'（五元环状中间体）。这启发我们，做题的时候多想开去一些，是有益无害的，竞赛考查的要点之一就是同学们的发散性思维。

上已述及两点动力学上的原因，现在还剩最后一个问题：为什么四面体中间体 B' 裂解后主要得到 B？由于 A 经过 B' 得到 B 是一个可逆的平衡，所以平衡偏向于生成 B 应该是一个热力学上的原因。最简单的想法便是酰胺在热力学上比酯更稳定，这反映在前者更不容易受到亲核进攻。更深层的原因是氮原子给电子能力强于氧原子，导致酰基碳亲核性减弱。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 分子内重排 | 不是简单的水解后再酰胺化 |
| 五元环中间体 | 氨基对酯羰基亲核加成形成稳定的五元环四面体中间体 |
| 酰胺 vs 酯稳定性 | 酰胺热力学上比酯更稳定，平衡偏向酰胺 |
| 亲核加成-消除 | 四面体中间体裂解时C-O键断、C-N键留 |
| 热力学控制 | 最终产物由热力学稳定性决定 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 认为先水解再酰胺化 | 羧酸负离子亲电性太弱，无法被氨基进攻 |
| 未提及五元环中间体 | 五元环中间体的形成是反应的关键步骤 |
| 只从动力学解释 | 最终产物是热力学控制的结果 |
| 未解释为何裂解得B而非A | 酰胺比酯更稳定，平衡偏向B |

首先我们要捋清该同学所期望发生的反应的历程。第一步，二级醇进攻二氯亚砜中的硫原子，得到 ROSOCl 和氯化氢。由于反应发生在非质子溶剂乙醚中，体系中的 HCl 本该无法电离出氯离子；但由于吡啶的存在，发生酸碱中和生成 pyH⁺ 和 Cl⁻。第二步，游离的 Cl⁻ 与 ROSOCl 发生 Sₙ2 反应，得到构型翻转的卤代烃。

事实上，反应得到另一个同分异构体，那么某步反应机理势必发生了变化。由于反应物只有羟基一个亲核位点，所以第一步机理发生变化的可能性不大，因此反应会经历化合物 D。而在第二步中，则有如下图所示两个亲电位点可供游离的氯离子进攻（分别用虚线和实线表示）。用实线标明的反应历程叫作"$S_N2'$ 反应"，这样反应就得到了实际产物 E。在官方答案中，还给出了 E 的绝对构型（不作具体要求）。

**知识拓展：**

9-2-1 中涉及的 "$S_N2'$ 反应"，事实上是不太常见的。只有在像乙醚这样的惰性溶剂中，较"软"的亲核试剂对离去基团所在位置空间位阻较大的底物发生进攻时，才能在与 $S_N2$ 的竞争中胜出。显然，在此反应中氯离子从双键处进攻，空间位阻会更小。

下面用 $\tau$ 键模型就9-2-1答案中新生成手性中心的构型作简单解释。该模型认为，碳碳双键是由两个 $\mathrm{sp}^3$ 杂化碳中间形成的两个 $\tau$ 键组成的。在该模型的处理方式下，$\mathrm{S_N2'}$ 反应可以看作是 $\mathrm{S_N2}$ 和 E2 的组合。由于两者都有反式的立体化学要求，所以氯离子将从原来羟基所在的 syn 面进攻得到目标产物。

## 🔗 同大题小问

**（6）**
该反应发生的是 E2 消除。E2 消除对质子和离去基团有反式共平面的立体化学要求，而生成 J 所需的 β-H 与离去基团 -OSOCl 在分子的任何构象中都无法满足反式共平面的要求，因此不能生成 J。





由于质子的酸性和吡啶的碱性不够强，不可能发生 E1cb 消除；惰性溶剂中又很难发生 E1 消除，所以这里发生的是 E2 消除。E2 消除对质子和离去基团有反式共平面的立体化学要求，因此不能生成 J。

E2 消除的立体化学要求：
- 被消除的 H 和离去基团必须在同一平面上且处于反式（anti-periplanar）构象
- 这种构象使过渡态中形成的 p 轨道能够有效重叠
- 如果分子中不存在满足反式共平面要求的构象，则该消除路径被禁止

在底物 F 中，生成 G 和 H 所需的 β-H 可以满足反式共平面要求，而生成 J 所需的 β-H 由于空间构型限制，无法与 -OSOCl 处于反式共平面位置，因此 J 不能生成。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| E2消除机理 | 协同的一步消除，要求反式共平面 |
| 反式共平面要求 | H和离去基团需处于anti-periplanar构象 |
| 构象分析 | 分子需采取特定构象才能满足E2要求 |
| 消除反应选择性 | 立体化学限制决定哪些产物可以生成 |
| E1/E1cb排除 | 条件不支持E1或E1cb机理 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 只说"空间位阻" | 需明确指出反式共平面的立体化学要求 |
| 认为是热力学不稳定 | 是动力学上无法形成所需过渡态 |
| 混淆E1和E2 | 该条件下是E2消除，有严格立体化学要求 |
| 未解释为何G和H可以得到 | 它们的β-H可以满足反式共平面要求 |
| 忽略构象分析 | 需分析分子中H和OSOCl的相对位置 |
