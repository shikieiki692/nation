# 第 2 题 Co 的配合物 (27 分)

Co 配合物因其氧化数、配体和结构的不同而呈现出丰富的磁性和催化特性。

2.1 直线形过渡金属配合物在分子磁体的研究中备受关注, 其能量状态几乎不受 Jahn-Teller 畸变的影响。2018 年, 科学家报道了一例二配位的单分子磁体 Co(II) 配合物 Co(C(SiMe₂ ONaph)₃ )₂ , 其中 HONaph 为 α-萘酚, C-Co-C 位于同一条直线上。理论计算表明, 该配合物中 Co 的 d 轨道裂分为三组能级, 从低到高电子的分布几率为 42.8%、41.2% 和 16.0%。

## 考点抽象

> 这道题的表面是"两例钴配合物的结构与反应"，本质是**以 d 轨道分裂与成键轨道分析为骨架、以氮桥联双核钴催化合成氨循环为主线的配位化学综合题**——从直线形单分子磁体的非常规晶体场，到 Co–N–Co 的 σ/π 成键，再到 H₂/氢给体活化桥联 N 的完整催化循环。

## 解题思路

1. **直线形场先分组能级**：C–Co–C 沿 z 轴 → d_z² 直对配体能量最高，d_xz/d_yz 次之，d_x²−y²/d_xy 能量最低；再按三组布居几率 42.8%/41.2%/16.0% 排布 d⁷ 电子，复核 dx²−y²/xy 同面 4 电子排斥大的解释。
2. **氧化数按电荷与配体逐项清点**：A、B 中桥联 N 与胍基/叠氮配体电荷代入，Co 均为 +3；后续 C、D、E、F 的价态变化沿"H₂ 加合 → 去质子化 → 重配"链条逐一核对电荷守恒。
3. **催化循环首尾闭合**：A + H₂ → C（加氢），C 与 LutHCl 反应放 NH₃ 得 D，D + NaN₃ 回到 A——画 C/D 结构时先定"哪个 N 上加了几个 H"，再核对与 A/B 的骨架关系。
4. **σ/π 成键按对称性匹配轨道**：Co–N–Co 取 x 轴 → σ 键用 Co 3d_x²−y²（沿 x 极大）与 N 2s/2p_x；π 键两套：3d_xy–2p_y 与 3d_xz–2p_z——轨道名称必须与坐标定义一致。
5. **溶剂激活看产物守恒**：B 经吡啶激活与 H₂ 反应放 N₂ 与副产物（NaN₃/N₂ 或苯），由"F + H₂ → E + N₂ + 吡啶"与"B → F"两步的小分子清单反推中间体 F 的组成。

## 易错分析

- 常见错误 1：2.1.1 按八面体场习惯把 d_x²−y²/d_xy 画成高能级——直线形二配位场的能级顺序完全不同，错一处即 0 分。
- 常见错误 2：2.2.1 漏数胍基配体的形式电荷或把桥联 N 当 −3 价重复计算，Co 氧化数写错（"有错就不得分"）。
- 常见错误 3：2.2.4 σ 键误用 d_z²（那是沿 Co–N₃ 方向的轨道）——坐标轴一旦指定，轨道名必须跟着坐标走。
- 常见错误 4：2.2.5/2.2.6 忘写小分子副产物（NaN₃、N₂、苯、吡啶），或 C/D/E/F 结构式中把加氢位置画在配体而非桥联 N 上。
