# 4-4，本小题总共4分

首先可以计算每个氨基酸在 pH = 7.40 条件下带电荷数（可忽略水的电离的影响，和形成多肽对侧链 pKa 的影响），由 $\mathrm { p H } = \mathrm { p } K _ { \mathrm { a } } + \mathrm { l g } { \frac { \mathrm { [ B a s e ] } } { \mathrm { [ A c i d ] } } }$ （或者配分函数），可得电荷数

$\cdot$ 1+10PH-pK （H、R、K的正电荷数）或 $\mathrm { ( D , ~ E , ~ C ) }$ 1+10PKa-pH 的负电荷数）。计算可知在保留小数点后两位有效数字的前提下，精氨酸(R)、赖氨酸(K)、天冬氨酸(D)与谷氨酸(E)分别为 $+ 1 . 0 0 \mathrm { { \ : \ : + 1 . 0 0 \mathrm { { \ : \ : - 1 . 0 0 \mathrm { { \ : \ : - 1 . 0 0 } } } } } }$ ，所以它们的数量将不改变总电荷数的小数点后两位。因此，组氨酸与半胱氨酸的数量决定了总电荷数的小数点后两位。

计算可知每个组氨酸平均带电荷数为+0.042，每个半胱氨酸平均带电荷数为−0.15，总数为12的条件下各可能的组合产生的小数点后两位（总电荷是负电荷的情况下，组氨酸的数目大于5 个）如下：

因为总电荷数为−7.88，因此可知，组氨酸 $\pmb { n } _ { \mathbf { H } }$ 与半胱氨酸 $\pmb { n } _ { \mathbf { C } }$ 分别为 10 与 2。

根据组氨酸 $\pmb { n } _ { \mathbf { H } }$ 与半胱氨酸 $\pmb { n } _ { \mathbf { C } }$ 的值，以及赖氨酸数目为 20个，天冬氨酸数目为 18个，谷氨酸数目为16个，总电荷数的计算：

$$

> 这道题的表面是"GFP 发色团改造与电荷计算"，本质是**"共轭结构决定光谱"＋"Henderson-Hasselbalch 决定残基电荷"两条线的生物有机综合题**——Tyr→His 蓝移、π-π 堆积红移、酰胺共轭放走 Fe²⁺，最后用小数点后两位的电荷指纹解出 nR/nH/nC。

## 知识点映射

- **直接 KP**：[[绿色荧光蛋白]]、[[发色团]]、[[氨基酸与等电点]]
- **间接 KP**：共轭与能隙（吸收红移/蓝移）、Henderson-Hasselbalch 式（氨基酸侧链电荷）、配位能力与共轭的关联
- **跨学科连接**：GFP 是 2008 诺贝尔化学奖主题；红色荧光蛋白发色团（胆绿素）由血红素氧化开裂生成——蛋白质工程与配位化学在发色团上交汇。

## 解题思路

1. **4-1 突变即"换芳环"**：酪氨酸（对羟基苯基）换成组氨酸（咪唑环），发色团共轭体系变小/杂原子改变能隙 → 吸收蓝移——画结构只改芳环部分，肽链骨架不动。
2. **4-2 红移答"π-π 堆积"**：上方叠加的 Tyr 与原发色团 π-π 堆积使电子离域范围扩大、能隙变小 → 吸收红移——一句话给分，关键是"离域扩大→能隙减小"的因果链。
3. **4-3 从"配位能力变化"找 Fe²⁺ 离去原因**：氧化把与 Fe 配位的氨基/酰胺结构改成酰胺（N 孤对进入羰基共轭）→ 供电子/配位能力下降 → Fe²⁺ 失去锚定位点而离去。
4. **4-4 分两层解电荷方程**：第一层算各残基平均电荷（R/K/D/E 均为 ±1.00，不影响小数两位；H +0.042、C −0.15）；第二层用 nH+nC=12、nH>5 枚举组合，总电荷 −7.88 的小数部分（0.88）锁定 nH=10、nC=2；整数部分解 nR=6。
5. **数值自检**：20+6−18−16=−8，加 0.042×10−0.15×2=+0.12 → −7.88 ✓——先整数骨架后小数微调的解题次序一目了然。

## 易错分析

- 常见错误 1：4-1 画结构时连肽链一起重画或漏掉咪唑环 N 的位置——只替换芳环部分。
- 常见错误 2：4-2 只答"红移"不给机理（π-π 堆积/离域扩大/能隙变小三要素）。
- 常见错误 3：4-4 忽略"R/K/D/E 电荷恰为 ±1.00、只有 H/C 贡献小数位"这一关键筛选，对 12 个残基做无谓的全枚举——先算平均电荷再缩小搜索空间是本题的解题智慧。
- 常见错误 4：枚举组合时忘掉 nH>5 与 nH+nC=12 双约束，或整数方程正负号写反（正电荷−负电荷=总电荷）。
