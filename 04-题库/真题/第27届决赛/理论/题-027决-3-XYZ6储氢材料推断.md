## 题目

**第3题（13分）**

X、Y、Z 均为非金属元素（X 的原子序数小于 Y 的原子序数），三者形成多种化合物。其中化学式为 $\mathrm{XYZ_6}$ 的化合物被认为是潜在的储氢材料，氢的质量分数达 19.6%。

1. 推断 X、Y、Z 分别是什么元素，写出 $\mathrm{XYZ_6}$ 的化学式。

2. 下图示出 $\mathrm{XYZ_6}$ 及相关化合物的生成与转化的流程图：其中实线箭头表示在一定条件下的转化过程，虚线仅表示分子式的关联关系；由 A 和 B 制备 $\mathrm{XYZ_6}$ 的过程中给出了所有反应物和产物，而其他过程仅给出所有反应物及其参与反应的计量系数的比例。B 和 D 的结构中均含有正四面体构型的负离子基团，E、F 和 G 均为六元环结构。根据图中的关系与所述条件，写出化合物 A、B、C、D、E、F、G、H 和 I 的化学式；画出 D 和 G 的结构简式。

## 参考答案

### 1. 元素推断

设 $\mathrm{XYZ_6}$ 的相对分子质量为 $M$，氢的质量分数为 19.6%。

- 若 X 或 Y 为氢元素，则 $M = 1.008/0.196 = 5.14$，$\mathrm{XYZ_6}$ 的相对分子质量过小，没有合理的化合物。**所以 Z 为氢元素**。
- $\mathrm{XYZ_6}$ 的相对分子质量：$M = 6 \times 1.008/0.196 \approx 30.86$。
- X、Y 均为非金属元素且 X 的原子序数小于 Y，枚举可得：$M(\mathrm B) + M(\mathrm N) = 10.81 + 14.01 = 24.82$，恰好 $24.82 + 6 \times 1.008 = 30.87 \approx 30.86$。

**X = B（硼），Y = N（氮），Z = H（氢），化学式 $\mathrm{XYZ_6} = \mathrm{BNH_6}$，即氨硼烷 $\mathrm{NH_3BH_3}$（$\mathrm{H_3N\to BH_3}$）**

验证：$M(\mathrm{NH_3BH_3}) = 14.01 + 10.81 + 6 \times 1.008 = 30.87$，$w(\mathrm H) = \dfrac{6 \times 1.008}{30.87} \approx 19.6\%$ ✓

### 2. 流程图推断

| 化合物 | 化学式 | 说明 |
|--------|--------|------|
| A | $\mathrm{NH_4Cl}$ | 氯化铵 |
| B | $\mathrm{LiBH_4}$ | 硼氢化锂（含正四面体 $\mathrm{BH_4^-}$） |
| C | $\mathrm{[BH_2(NH_3)_2]Cl}$ | 二氨二氢硼氯化物 |
| D | $\mathrm{[BH_2(NH_3)_2][BH_4]}$ | 含正四面体 $\mathrm{BH_4^-}$ |
| E | $\mathrm{B_3N_3H_3Cl_3}$ | 六元环硼氮化合物 |
| F | $\mathrm{B_3N_3H_6}$ | 无机苯（硼氮苯），六元环 |
| G | $\mathrm{B_3N_3H_9Cl_3}$ | F 与 HCl 的加成产物，六元环 |
| H | $\mathrm{B_2H_6}$ | 乙硼烷 |
| I | $\mathrm{BNH_3F_3}$ | 三氟化硼氨合物 |

**关键反应关系**（由 A 和 B 制备 $\mathrm{XYZ_6}$ 及流程图推理）：

- $\mathrm{NH_4Cl + LiBH_4 \longrightarrow NH_3BH_3 + H_2 + LiCl}$（即 A + B → XYZ₆ + H₂ + LiCl）
- $\mathrm{3NH_4Cl + 3BCl_3 \longrightarrow B_3N_3H_3Cl_3 + 9HCl}$（A 与 BCl₃ 缩合生成 E）
- $\mathrm{3NH_3BH_3 \longrightarrow B_3N_3H_6 + 6H_2}$（XYZ₆ 缩聚生成无机苯 F）
- $\mathrm{B_3N_3H_6 + 3HCl \longrightarrow B_3N_3H_9Cl_3}$（F 与 HCl 对 B=N 双键加成：N 电负性大于 B，故 B 连 Cl、N 连 H）
- $\mathrm{NH_3BH_3 + BF_3 \longrightarrow BNH_3F_3 + BH_3}$（强 Lewis 酸 BF₃ 置换弱 Lewis 酸 BH₃），$\mathrm{2BH_3 \longrightarrow B_2H_6}$（H）
- $\mathrm{B_2H_6 + 2NH_3 \longrightarrow [BH_2(NH_3)_2][BH_4]}$（生成 D）
- $\mathrm{2NH_4Cl + LiBH_4 \longrightarrow [BH_2(NH_3)_2]Cl + LiCl + 2H_2}$（生成 C）

**D 和 G 的结构简式**（文字描述）：
- D：阳离子 $[\mathrm{H_2B(NH_3)_2}]^+$ 与阴离子 $\mathrm{BH_4^-}$ 构成离子化合物（B 为中心，2 个 H、2 个 $\mathrm{NH_3}$ 配位）。
- G：$\mathrm{B_3N_3}$ 六元环，环上每个 B 连 1 个 Cl，每个 N 连 2 个 H（由 F 的三个 B=N 双键各加成一分子 HCl 得到）。

## 解题思路

### 第1步：元素推断
- 氢含量 19.6% 是关键线索：若 X 或 Y 为 H，则 $M = 1.008/0.196 = 5.14$，$\mathrm{XYZ_6}$ 的相对分子质量不可能这么小 → 排除，**Z 必为氢**。
- $M(\mathrm{XYZ_6}) = 6 \times 1.008/0.196 = 30.86$。
- X、Y 为非金属元素，X 的原子序数小于 Y，原子量之和 $\approx 30.86 - 6.05 = 24.8$。枚举：B(10.81) + N(14.01) = 24.82 ✓ → X = B，Y = N。
- 化学式 $\mathrm{NH_3BH_3}$（氨硼烷，$\mathrm{H_3N\to BH_3}$），验证 $w(\mathrm H) = 19.6\%$ ✓。

### 第2步：流程推断
- B、D 含正四面体负离子：在 B/N/H 体系中，四面体负离子只能是 $\mathrm{BH_4^-}$（B 为 LiBH₄，D 为 $[\mathrm{BH_2(NH_3)_2}][\mathrm{BH_4}]$）。
- $\mathrm{XYZ_6}$（$\mathrm{NH_3BH_3}$）缩聚 → F = $\mathrm{B_3N_3H_6}$（无机苯）；F + 3HCl → G = $\mathrm{B_3N_3H_9Cl_3}$。
- A + B → $\mathrm{NH_3BH_3}$ + H₂ + LiCl：B = $\mathrm{LiBH_4}$，A = $\mathrm{NH_4Cl}$。
- A 与 BCl₃ 缩合 → E = $\mathrm{B_3N_3H_3Cl_3}$。
- $\mathrm{NH_3BH_3}$ 与 BF₃：强 Lewis 酸 BF₃ 置换弱 Lewis 酸 BH₃ → I = $\mathrm{BNH_3F_3}$，BH₃ 双聚 → H = $\mathrm{B_2H_6}$。
- $\mathrm{B_2H_6 + 2NH_3}$ → D；$\mathrm{2NH_4Cl + LiBH_4}$ → C = $[\mathrm{BH_2(NH_3)_2}]\mathrm{Cl}$。

## 考点抽象

### 核心考点
1. **元素质量分数推断法**：由氢含量反推化学式组成（先判断 Z = H，再由相对分子质量枚举 X、Y）。
2. **氨硼烷（Lewis 酸碱加合物）**：$\mathrm{NH_3}$ 的孤对电子提供给 $\mathrm{BH_3}$，形成 $\mathrm{H_3N\to BH_3}$，是经典储氢材料。
3. **正四面体负离子**：$\mathrm{BH_4^-}$（以及等电子体 $\mathrm{BF_4^-}$、$\mathrm{AlH_4^-}$）均为四面体构型。
4. **硼氮六元环**：$\mathrm{B_3N_3H_6}$（无机苯）是苯的等电子体，可缩聚/加合生成一系列衍生物。

### 方法论
- 质量分数 → 摩尔质量 → 元素组成
- 结构类型（四面体/六元环）限制可能的化合物
- Lewis 酸碱加合与置换贯穿整个推断过程

## 变式拓展

### 变式1：其他储氢材料推断
- 若某硼氮氢化物储氢材料中 $w(\mathrm H)$ 已知，如何由质量分数判断氢的位置（Z = H）并反推元素组成？可推广到 $\mathrm{NaBH_4}$、$\mathrm{LiAlH_4}$ 等金属氢化物。

### 变式2：无机苯衍生物
- $\mathrm{B_3N_3H_6}$（无机苯）与 HCl 加成的区域选择性：由于 N 电负性大于 B，B 与 Cl 结合、N 与 H 结合，生成 $\mathrm{B_3N_3H_9Cl_3}$。

### 变式3：四面体负离子推广
- $\mathrm{BH_4^-}$、$\mathrm{BF_4^-}$、$\mathrm{AlH_4^-}$ 均为四面体；$\mathrm{SiF_6^{2-}}$ 是八面体（超价化合物）。注意区分配位数与构型。

## 易错分析

1. **H 含量计算**：误将 Z 当作 F 等较重元素（如写成 $\mathrm{BF_3NH_3}$），导致 $w(\mathrm H)$ 远小于 19.6%。正确做法是先判断 Z = H，再由相对分子质量枚举 X、Y。
2. **无机苯 vs 有机苯**：$\mathrm{B_3N_3H_6}$ 的 B-N 键长不完全相等（不同于苯的完全等长 C-C 键），是"不完全芳香性"。
3. **四面体负离子识别**：$\mathrm{BH_4^-}$ 和 $\mathrm{BF_4^-}$ 都是四面体；$\mathrm{SiF_6^{2-}}$ 是八面体（超价化合物）。容易混淆配位数与构型。
4. **流程图推断**：B、D 的 $\mathrm{BH_4^-}$ 是唯一能同时满足"四面体负离子"与元素组成的基团，需以此为锚点展开推断。
