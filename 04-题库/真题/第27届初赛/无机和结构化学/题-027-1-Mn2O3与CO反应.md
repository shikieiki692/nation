## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第1题(12分) 第(1-1)小问

写出下列化学反应的方程式：

加热时，三氧化二锰与一氧化碳反应产生四氧化三锰。

将 KCN 加入到过量的 $\mathrm{CuSO}_{4}$ 水溶液中。

在碱性溶液中，$\mathrm{Cr}_{2}\mathrm{O}_{3}$ 和 $\mathrm{K}_{3}\mathrm{Fe(CN)}_{6}$ 反应。

在碱性条件下，$\mathrm{Zn(CN)_{4}^{2-}}$ 和甲醛反应。

$\mathrm{Fe(OH)_{2}}$ 在常温无氧条件下转化为 $\mathrm{Fe}_{3}\mathrm{O}_{4}$。

将 $\mathrm{NaNO}_{3}$ 粉末小心加到熔融的 $\mathrm{NaNH}_{2}$ 中，生成 $\mathrm{NaN}_{3}$（没有水生成）。

## 参考答案

**（1）**
$$3\mathrm{Mn}_{2}\mathrm{O}_{3} + \mathrm{CO} = 2\mathrm{Mn}_{3}\mathrm{O}_{4} + \mathrm{CO}_{2}$$

该反应与氧化铁的部分还原反应类似。Mn₂O₃中Mn为+3价，Mn₃O₄中Mn为+8/3价（混合价态），CO被氧化为CO₂。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 锰的氧化物 | Mn₂O₃（+3）、Mn₃O₄（混合价态+2/+3） |
| CO的还原性 | CO → CO₂，碳从+2升至+4 |
| 方程式配平 | 需注意Mn的非整数氧化态变化 |

## 解题思路

1. 明确反应物：Mn₂O₃ + CO；产物：Mn₃O₄ + CO₂
2. Mn₂O₃中Mn为+3价，Mn₃O₄可视为MnO·Mn₂O₃（Mn为+2和+3混合价态）
3. CO → CO₂ 失去2e⁻
4. 2个Mn从+3降到+8/3（平均），需配平得 3:1:2:1

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| Mn₃O₄价态 | 不是简单的+4/3，而是+2和+3混合，平均+8/3 |
| 配平比例 | 正确比例为3:1→2:1，不是1:1 |

**（2）**
$$4\mathrm{CN}^{-} + 2\mathrm{Cu}^{2+} = 2\mathrm{CuCN} \downarrow + (\mathrm{CN})_{2} \uparrow$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 配位平衡对电势的影响 | CN⁻使Cu²⁺/Cu⁺电势降低 |
| Cu(I)的稳定性 | CN⁻存在下Cu(I)稳定 |
| 氧化还原 | Cu²⁺氧化CN⁻为(CN)₂ |

## 解题思路

1. Cu²⁺与CN⁻的反应：Cu²⁺为氧化剂，CN⁻为还原剂
2. CN⁻使Cu²⁺/Cu⁺电极电势降低，Cu²⁺能氧化CN⁻
3. 生成Cu(I)氰化物。注意Cu²⁺过量 → 产物为CuCN（而非更高配位的配合物）
4. CN⁻被氧化为(CN)₂气体

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 产物选择 | Cu²⁺过量时得CuCN，CN⁻过量时得Cu(CN)₂⁻等 |
| CN⁻的双重角色 | 既是配体又是还原剂 |
| (CN)₂ | 剧毒气体，注意书写↑符号 |

**（3）**
$$\mathrm{Cr}_{2}\mathrm{O}_{3} + 6\mathrm{Fe(CN)}_{6}^{3-} + 10\mathrm{OH}^{-} = 2\mathrm{CrO}_{4}^{2-} + 6\mathrm{Fe(CN)}_{6}^{4-} + 5\mathrm{H}_{2}\mathrm{O}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 酸碱性对氧化还原的影响 | 碱性条件有利于Cr(III)→Cr(VI) |
| 配位稳定化 | CN⁻稳定Fe(II)和Fe(III) |
| 重铬酸根的逆向反应 | 酸性中Cr₂O₇²⁻氧化Fe²⁺，碱性中逆向 |

## 解题思路

1. 酸性中经典反应：Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O
2. 此题条件倒置：碱性 + 配位CN⁻ → 逆向反应有利
3. Cr₂O₃（Cr为+3）被氧化为CrO₄²⁻（Cr为+6）
4. Fe(CN)₆³⁻（Fe为+3）被还原为Fe(CN)₆⁴⁻（Fe为+2）

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 反应方向 | 与酸性条件下的经典反应方向相反 |
| 配合物写法 | 保持配合物整体书写，不要拆开 |
| OH⁻配平 | 碱性介质用OH⁻配平电荷和原子 |

**（4）**
$$\mathrm{Zn(CN)}_{4}^{2-} + 4\mathrm{HCHO} + 4\mathrm{H}_{2}\mathrm{O} = 4\mathrm{HOCH}_{2}\mathrm{CN} + \mathrm{Zn(OH)}_{4}^{2-}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 掩蔽剂的解蔽 | EDTA滴定中Zn²⁺的掩蔽/解蔽 |
| 亲核加成 | CN⁻亲核进攻HCHO形成氰醇 |
| 软硬酸碱交换 | CN⁻（软碱）+ HCHO ↔ OH⁻（硬碱）+ Zn²⁺ |

## 解题思路

1. Zn(CN)₄²⁻ 存在解离平衡：Zn(CN)₄²⁻ ⇌ Zn²⁺ + 4CN⁻
2. CN⁻是优良的亲核试剂，亲核进攻HCHO生成HOCH₂CN（氰醇）
3. 氰醇的稳定常数远大于Zn(CN)₄²⁻，推动平衡右移
4. 释放的OH⁻与Zn²⁺配位形成Zn(OH)₄²⁻
5. 本质：软碱CN⁻与软酸HCHO选择性结合，硬碱OH⁻与交界酸Zn²⁺结合

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 反应来源 | 来自分析化学"掩蔽剂的解蔽"，非课本常见反应 |
| 氰醇生成 | CN⁻ + HCHO + H₂O → HOCH₂CN + OH⁻ |
| 配合物转化 | Zn(CN)₄²⁻ → Zn(OH)₄²⁻，配体完全替换 |
| 难度定位 | 此题为"高手过招"级别的区分题 |

**（5）**
$$3\mathrm{Fe(OH)}_{2} = \mathrm{Fe}_{3}\mathrm{O}_{4} + \mathrm{H}_{2} \uparrow + 2\mathrm{H}_{2}\mathrm{O}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 铁的氧化态变化 | Fe(II) → Fe(II)+Fe(III)混合 |
| 氧化剂判断 | 无氧条件下H⁺为氧化剂 |
| Fe₃O₄结构 | FeO·Fe₂O₃，混合价态 |

## 解题思路

1. Fe(OH)₂中Fe为+2价，Fe₃O₄中Fe为+2和+3混合（平均+8/3）
2. 无氧条件下无外部氧化剂，O已在最低价(-2)
3. 唯一可能的氧化剂是H⁺（来自水）
4. Fe(II)部分被H⁺氧化，放出H₂

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 氧化剂选择 | 不能写O₂参与（题目明确无氧） |
| H₂来源 | H⁺被还原为H₂，不是分解水 |
| 配平 | 3Fe(OH)₂ → Fe₃O₄ + H₂ + 2H₂O |

**（6）**
$$\mathrm{NaNO}_{3} + 3\mathrm{NaNH}_{2} = \mathrm{NaN}_{3} + \mathrm{NH}_{3} \uparrow + 3\mathrm{NaOH}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 叠氮化物制备 | 工业制备NaN₃的方法之一 |
| 非水体系反应 | 熔融态反应，无水生成 |
| 氮的氧化态变化 | N(+5) + N(-3) → N(-1/3) |

## 解题思路

1. 反应物：NaNO₃（N为+5）+ NaNH₂（N为-3）
2. 产物：NaN₃（N平均为-1/3）
3. 注意约束条件：没有水生成
4. 副产物推断：NaNH₂中的H和O结合 → NaOH，多余的N和H → NH₃

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 水的约束 | 题目明确"没有水生成"，不能写H₂O |
| 副产物 | NH₃和NaOH，不是H₂O |
| 配平 | 1:3:1:1:3 |
