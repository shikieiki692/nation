## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第3题(11分) 第(3-1)小问

白色固体 A，熔点 182℃，摩尔质量 76.12 g mol⁻¹，可代替氰化物用于提炼金的新工艺。A 的合成方法有：(1) 142℃下加热硫氰酸铵；(2) CS₂与氨反应；(3) CaCN₂和(NH₄)₂S水溶液反应（放出氨气）。画出 A 的结构式。

分别写出合成 A 的方法（2）、（3）中的化学反应方程式。

常温下，A 在水溶液中可发生异构化反应，部分转化成 B。画出 B 的结构式。

酸性溶液中，A 在氧化剂（如 Fe³⁺、H₂O₂ 和 O₂）存在下能溶解金，形成 sp 杂化的 Au(I) 配合物。写出 A 在硫酸铁存在下溶解金的离子方程式。

A 和 Au(I) 形成的配合物中配位原子是什么？

在提炼金时，A 可被氧化成 C：2A → C + 2e⁻；C 能提高金的溶解速率。画出 C 的结构式。写出 C 和 Au 反应的方程式。

## 参考答案

**（1）**
**A = 硫脲（Thiourea），CS(NH₂)₂**

结构式：

H₂N—C(=S)—NH₂

推断依据：硫氰酸铵（NH₄SCN，M=76.12）加热异构化→硫脲，摩尔质量相同，无气体放出。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 硫脲 | 重要工业试剂，代替CN⁻提金 |
| 异构化 | NH₄SCN → SC(NH₂)₂ |
| 结构推断 | 由合成方法和摩尔质量推导 |

## 解题思路

1. 加热硫氰酸铵（76.12 g/mol）→ A（76.12 g/mol）：无气体放出，同分异构
2. CS₂ + NH₃ → 含C、S、N、H的化合物
3. CaCN₂ + (NH₄)₂S → 同样含C、S、N、H
4. 化学式CSN₂H₄，排除其他异构体 → 硫脲最稳定

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 异构体选择 | NH₄SCN是盐，硫脲是共价分子 |
| 摩尔质量 | 76.12恰好等于CSN₂H₄ |
| 与尿素类比 | SC(NH₂)₂类似OC(NH₂)₂ |

**（2）**
**方法（2）** CS₂与氨反应：

$$\mathrm{CS}_{2} + 3\mathrm{NH}_{3} = \mathrm{CSN}_{2}\mathrm{H}_{4} + \mathrm{NH}_{4}\mathrm{HS}$$

或写为：

$$\mathrm{CS}_{2} + 4\mathrm{NH}_{3} = \mathrm{CSN}_{2}\mathrm{H}_{4} + (\mathrm{NH}_{4})_{2}\mathrm{S}$$

**方法（3）** CaCN₂与(NH₄)₂S反应：

$$\mathrm{CaCN}_{2} + (\mathrm{NH}_{4})_{2}\mathrm{S} + 2\mathrm{H}_{2}\mathrm{O} = \mathrm{CSN}_{2}\mathrm{H}_{4} + \mathrm{Ca(OH)}_{2} + 2\mathrm{NH}_{3} \uparrow$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 硫脲工业合成 | 两种经典路线 |
| 氨解反应 | CS₂的氨解 |
| 水解反应 | CaCN₂的水解 |

## 解题思路

1. 方法(2)：CS₂中C-S键被NH₃亲核进攻，逐步氨解
2. 方法(3)：CaCN₂水解释放NH₂-，与S²⁻结合形成硫脲

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 副产物 | 方法(2)生成NH₄HS或(NH₄)₂S |
| 水的参与 | 方法(3)需要水参与反应 |
| NH₃放出 | 方法(3)有NH₃气体放出 |

**（3）**
**B = 巯基异氰酸铵（异硫氰酸铵，NH₄SCN）** 或其共价形式 **HS-C≡N**

硫脲（A）与异硫氰酸（B）之间存在互变异构平衡：

$$\mathrm{H}_{2}\mathrm{N}-\mathrm{CS}-\mathrm{NH}_{2} \rightleftharpoons \mathrm{HS}-\mathrm{C}{\equiv}\mathrm{N} + \mathrm{NH}_{3}$$

但在水溶液中的异构化更准确地说是：

$$\mathrm{SC(NH}_{2})_{2} \rightleftharpoons \mathrm{NH}_{4}\mathrm{SCN}$$

B 的结构为 $\mathrm{HS}-\mathrm{C}{\equiv}\mathrm{N}$（或离子形式 $\mathrm{NH}_{4}^{+} + \mathrm{NCS}^{-}$）。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 互变异构 | 硫脲⇌异硫氰酸 |
| 酸碱平衡 | 巯基有弱酸性 |
| 异构化 | 可逆反应，部分转化 |

## 解题思路

1. A = 硫脲 SC(NH₂)₂
2. 类似酮-烯醇互变异构，硫脲可异构化
3. N上的H迁移到S上 → 巯基 + 氰基
4. B含-SH和-C≡N基团

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 不是NH₄SCN | B是异构化产物，不是起始物 |
| 互变异构 | 类似酮-烯醇互变，而非分解 |
| 部分转化 | 平衡反应，不完全转化 |

**（4）**
$$\mathrm{Au} + \mathrm{Fe}^{3+} + 2\mathrm{CS(NH}_{2})_{2} = \mathrm{Fe}^{2+} + \mathrm{Au[CS(NH}_{2})_{2}]_{2}^{+}$$

考虑酸性环境，也可写为：

$$\mathrm{Au} + \mathrm{Fe}^{3+} + 2\mathrm{CSN}_{2}\mathrm{H}_{5}^{+} = \mathrm{Fe}^{2+} + \mathrm{Au[CS(NH}_{2})_{2}]_{2}^{+} + 2\mathrm{H}^{+}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| Au(I)配合物 | sp杂化→二配位 |
| 硫脲配位 | 通过S原子配位 |
| 软硬酸碱 | Au⁺(软酸)+S(软碱) |

## 解题思路

1. Au → Au⁺（被Fe³⁺氧化），失去1e⁻
2. Au⁺为18e⁻型软酸，与软碱S配位
3. sp杂化→2配位→Au[SC(NH₂)₂]₂⁺
4. Fe³⁺ + e⁻ → Fe²⁺（氧化剂）

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 配位数 | sp杂化只能2配位 |
| 配位原子 | S（不是N），符合软硬酸碱 |
| 氧化态 | Au(I)，不是Au(III) |

**（5）**
配位原子是 **S（硫原子）**。

理由：Au⁺是典型的18e⁻型化合物，属于**软酸**。硫脲中有两类配位原子：N（较硬）和S（较软）。根据**软硬酸碱理论**（软亲软），软酸Au⁺优先与软碱S配位。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 软硬酸碱理论 | 软酸-软碱优先结合 |
| Au⁺电子构型 | 18e⁻，典型软酸 |
| 两可配体 | 硫脲可经S或N配位 |

## 解题思路

1. Au⁺为18e⁻构型 → 极化率大 → 软酸
2. 硫脲中S（3p）比N（2p）极化率大 → S更软
3. 软酸+软碱 → S配位

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| N vs S | 不是N配位，而是S配位 |
| 两可配体 | 硫脲是经典的S/N两可配体 |
| 理论依据 | 软硬酸碱理论，不是简单的电负性 |

**（6）**
**C = 硫脲氧化偶联产物（formamidine disulfide，二硫化双甲脒）**

$$\mathrm{C}_{2}\mathrm{S}_{2}\mathrm{N}_{4}\mathrm{H}_{8}^{2+}$$

结构：两分子硫脲通过S-S键偶联：

$$[\mathrm{H}_{2}\mathrm{N}{-}\mathrm{CS}{-}\mathrm{S}{-}\mathrm{CS}{-}\mathrm{NH}_{2}]^{2+} \text{（质子化形式）}$$

C与Au反应：

$$\mathrm{C}_{2}\mathrm{S}_{2}\mathrm{N}_{4}\mathrm{H}_{8}^{2+} + 2\mathrm{CS(NH}_{2})_{2} + 2\mathrm{Au} = 2\mathrm{Au[CS(NH}_{2})_{2}]_{2}^{+}$$





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 氧化偶联 | S-S键形成（类比半胱氨酸） |
| 二硫键 | 蛋白质中常见的交联方式 |
| 再生循环 | C可重新氧化Au，加速溶解 |

## 解题思路

1. 2A - 2e⁻ → C，即两分子硫脲失去2个电子
2. 可能偶联位点：S-S、N-N、C-C
3. N-N键（类似联氨）还原性太强，排除
4. S-S键偶联最合理（类比蛋白质中半胱氨酸→胱氨酸）
5. C是强氧化剂，可再氧化Au → 再生硫脲配合物

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 偶联位点 | S-S键（不是N-N或C-C） |
| 生物类比 | 类似蛋白质中二硫键形成 |
| 催化循环 | C氧化Au后再生硫脲，循环使用 |
