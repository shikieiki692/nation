## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第5题(10分) 第(5-1)小问

$\mathrm{M}_{3}\mathrm{XY}$ 呈反钙钛矿结构。反应消耗 0.93 g M 可获得 0.50 L A₂ 气体（25℃，100 kPa）。计算 M 的摩尔质量。

【第5题共享题干】$\mathrm{M}_3\mathrm{XY}$ 呈反钙钛矿结构，是一种良好的离子导体。M 为金属元素，X 和 Y 为非金属元素，三者均为短周期元素且原子序数 $Z(\mathrm{X}) < Z(\mathrm{M}) < Z(\mathrm{Y})$。$\mathrm{M}_3\mathrm{XY}$ 可由 M 和 X、M 和 Y 的二元化合物在约 500 K、3 MPa 的惰性气氛中反应得到。为避免采用高压条件，研究者发展了常压下的合成反应：

$$\mathrm{M} + \mathrm{MXA} + \mathrm{MY} \longrightarrow \mathrm{M}_3\mathrm{XY} + 1/2\mathrm{A}_2(\mathrm{g})$$

其中 $\mathrm{A}_2$ 无色无味。反应消耗 0.93 g M 可获得 0.50 L $\mathrm{A}_2$ 气体（25 ℃，100 kPa）。（摩尔气体常数 R = 8.314 kPa·L·mol⁻¹·K⁻¹）

A、M、X、Y 各是什么？

写出 $\mathrm{M}_{3}\mathrm{XY}$（即 $\mathrm{Na}_{3}\mathrm{OCl}$）发生水解的方程式。

$\mathrm{M}_{3}\mathrm{XY}$ 晶体属于立方晶系，若以 X 为正当晶胞的顶点，写出 M 和 Y 的坐标以及该晶体的最小重复单位。

## 参考答案

**（1）**
$$n(\mathrm{A}_{2}) = \frac{pV}{RT} = \frac{100 \times 0.50}{8.314 \times 298.15} = 0.02017 \text{ mol}$$

由方程式 M + MXA + MY → M₃XY + ½A₂：

消耗2 mol M产生1 mol A₂，故 n(M) = 2n(A₂) = 0.04034 mol

$$M(\mathrm{M}) = \frac{0.93}{0.04034} = 23.05 \text{ g/mol}$$

**M ≈ 23 g/mol（Na）**





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 理想气体方程 | pV = nRT |
| 化学计量 | 方程式中M与A₂的比例 |
| 反钙钛矿 | M₃XY型结构 |

## 解题思路

1. 由pV=nRT计算A₂物质的量
2. 由方程式确定M与A₂的计量比（2:1）
3. 由质量和物质的量得摩尔质量

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 温度单位 | 25℃ = 298.15 K |
| 计量比 | 2M → ½A₂，即M:A₂ = 2:1 |
| 单位 | R = 8.314 kPa·L/(mol·K) |

**（2）**
- **M = Na**（钠，M≈23 g/mol）
- **X = O**（氧，Z=8 < Z(Na)=11）
- **Y = Cl**（氯，Z=17 > Z(Na)=11）
- **A = H**（氢，形成A₂=H₂，无色无味）

验证：
- Z(X) < Z(M) < Z(Y)：8 < 11 < 17 ✓
- M₃XY = Na₃OCl（反钙钛矿结构）✓
- MXA = NaOH，MY = NaCl ✓
- A₂ = H₂（无色无味）✓





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 元素推断 | 由摩尔质量和原子序数关系确定 |
| 反钙钛矿 | Na₃OCl为典型反钙钛矿 |

## 解题思路

1. M = Na（由5-1得M≈23）
2. Z(X) < 11 < Z(Y)，均为短周期非金属
3. Y与Na 1:1结合 → NaCl → Y = Cl
4. X与Na、Cl形成Na₃XCl → X = O
5. A形成双原子分子 → A₂ = H₂

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 原子序数约束 | 必须满足Z(X)<Z(M)<Z(Y) |
| MY比例 | 1:1 → NaCl（不是Na₂O等） |
| A₂性质 | 无色无味 → H₂（不是O₂或Cl₂） |

**（3）**
$$\mathrm{Na}_{3}\mathrm{OCl} + \mathrm{H}_{2}\mathrm{O} = 2\mathrm{NaOH} + \mathrm{NaCl}$$

Na₃OCl可看作 Na₂O·NaCl，其中Na₂O部分与水反应生成NaOH，NaCl不水解。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 氧化物水解 | Na₂O + H₂O → 2NaOH |
| 复合氧化物 | Na₃OCl = Na₂O + NaCl |
| 水解方程式 | 配平原子和电荷 |

## 解题思路

1. Na₃OCl = Na₂O·NaCl（概念性拆分）
2. Na₂O + H₂O → 2NaOH
3. NaCl保留不变
4. 合并：Na₃OCl + H₂O → 2NaOH + NaCl

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 拆分方式 | Na₂O·NaCl（不是3Na + O + Cl） |
| NaCl不水解 | NaCl是中性盐，不参与水解 |
| 配平 | 1:1:2:1 |

**（4）**
以 **X（O）为顶点**：

- **M（Na）坐标**：(½,0,0)、(0,½,0)、(0,0,½) — 面心位置的3个Na
- **Y（Cl）坐标**：(½,½,½) — 体心位置

**最小重复单位**：一个晶胞，即 **Na₃OCl**（1个O在顶点 + 3个Na在面心 + 1个Cl在体心）。

对照钙钛矿CaTiO₃：
- 钙钛矿中Ca在顶点(12配位)，Ti在体心(6配位)
- 反钙钛矿中阴阳离子位置互换：Cl⁻(大)代替Ca²⁺在体心，O²⁻(小)在顶点





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 反钙钛矿结构 | 阴阳离子位置互换 |
| 分数坐标 | 立方晶系中的原子位置 |
| 晶胞 | 最小重复单位 |

## 解题思路

1. 钙钛矿CaTiO₃：Ca顶点，Ti体心，O面心
2. 反钙钛矿要求阴阳离子互换
3. Cl⁻半径 > O²⁻半径 → Cl⁻占Ca位（体心），O²⁻占顶点
4. Na⁺占面心位置（3个）

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| "反"的含义 | 阴阳离子位置互换（不是简单的"反对"） |
| 半径判据 | Cl⁻(大)→Ca位，O²⁻(小)→Ti位 |
| 坐标写法 | (½,0,0)等面心位置不要遗漏 |
