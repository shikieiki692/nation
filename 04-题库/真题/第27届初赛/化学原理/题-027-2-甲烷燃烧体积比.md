## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第2题(23分) 第(2-8)小问

甲烷在汽车发动机中平稳、完全燃烧。甲烷与空气按一定比例混合，氧气的利用率为 85%，计算汽车尾气中 $\mathrm{O}_{2}$、$\mathrm{CO}_{2}$、$\mathrm{H}_{2}\mathrm{O}$ 和 $\mathrm{N}_{2}$ 的体积比。（空气中 $\mathrm{O}_{2}$ 和 $\mathrm{N}_{2}$ 体积比按 21:79 计；设尾气中 $\mathrm{CO}_{2}$ 的体积为1。）

$\mathrm{Bi}_{2}\mathrm{Cl}_{8}^{2-}$ 离子中铋原子的配位数为5，配体呈四角锥形分布，画出该离子的结构并指出Bi原子的杂化轨道类型。

在液氨中，$E^{\ominus}(\mathrm{Na}^{+}/\mathrm{Na})=-1.89\ \mathrm{V}$，$E^{\ominus}(\mathrm{Mg}^{2+}/\mathrm{Mg})=-1.74\ \mathrm{V}$，但可以发生 Mg 置换 Na 的反应：$\mathrm{Mg}+2\mathrm{NaI}=\mathrm{MgI}_{2}+2\mathrm{Na}$。指出原因。

将 Pb 加到氨基钠的液氨溶液中，先生成白色沉淀 $\mathrm{Na}_{4}\mathrm{Pb}$，随后转化为 $\mathrm{Na}_{4}\mathrm{Pb}_{9}$（绿色）而溶解。在此溶液中插入两块铅电极，通直流电，当 1.0 mol 电子通过电解槽时，在哪个电极（阴极或阳极）上沉积出铅？写出沉积铅的量。

某金属氧化物的晶体结构中，小球代表金属原子，大球代表氧原子。写出金属原子的配位数（m）和氧原子的配位数（n）。

写出晶胞中金属原子数（p）和氧原子数（q）。

写出该金属氧化物的化学式（金属用 M 表示）。

向含 $\left[cis-\mathrm{Co}(\mathrm{NH}_{3})_{4}(\mathrm{H}_{2}\mathrm{O})_{2}\right]^{3+}$ 的溶液中加入氨水，析出含 $\left\{\mathrm{Co}\left[\mathrm{Co}(\mathrm{NH}_{3})_{4}(\mathrm{OH})_{2}\right]_{3}\right\}^{6+}$ 的难溶盐。该离子以羟基为桥键的多核配离子，具有手性。画出其结构。

向 $\mathrm{K}_{2}\mathrm{Cr}_{2}\mathrm{O}_{7}$ 和 NaCl 的混合物中加入浓硫酸制得化合物 X（154.9 g mol⁻¹）。X 为暗红色液体，沸点 117℃，有强刺激性臭味，遇水冒白烟，遇硫燃烧。X 分子有两个相互垂直的镜面，两镜面的交线为二重旋转轴。写出 X 的化学式并画出其结构式。

实验得到一种含钯化合物 $\mathrm{Pd}[\mathrm{C}_{x}\mathrm{H}_{y}\mathrm{N}_{z}](\mathrm{ClO}_{4})_{2}$，该化合物中 C 和 H 的质量分数分别为 30.15% 和 5.06%。将此化合物转化为硫氰酸盐 $\mathrm{Pd}[\mathrm{C}_{x}\mathrm{H}_{y}\mathrm{N}_{z}](\mathrm{SCN})_{2}$，则 C 和 H 的质量分数分别为 40.46% 和 5.94%。通过计算确定其组成。

## 参考答案

**（1）**
$$\mathrm{CH}_{4} + 2\mathrm{O}_{2} = \mathrm{CO}_{2} + 2\mathrm{H}_{2}\mathrm{O}$$

设CH₄ = 1体积：
- 需O₂ = 2体积，利用率85% → 实际供O₂ = 2/0.85 = 2.353体积
- 剩余O₂ = 2.353 - 2 = 0.353体积
- 空气中N₂ = 2.353 × 79/21 = 8.860体积
- 产CO₂ = 1，产H₂O = 2

以CO₂=1为基准：

**O₂:CO₂:H₂O:N₂ = 0.35:1:2:8.86**





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 燃烧方程式 | CH₄完全燃烧 |
| 利用率计算 | 实际需氧量 = 理论量/利用率 |
| 空气组成 | O₂:N₂ = 21:79 |

## 解题思路

1. 写出燃烧方程式，确定理论需氧量
2. 利用率85% → 实际供氧 = 理论/0.85
3. 剩余O₂ = 供氧 - 消耗
4. N₂随空气进入，不参与反应
5. 统一以CO₂=1为基准

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 利用率方向 | 85%利用率 → 需更多空气（不是更少） |
| N₂计算 | 从空气来，与O₂的21:79关系 |
| H₂O状态 | 常温下为液态，但尾气中通常按气态计 |

**（2）**
2个Bi原子配位数均为5，共有8个Cl，因此必定有2个Cl为共用桥联配体。

**杂化轨道**：Bi为第15族元素，最外层5个电子。形成6个杂化轨道（1个空轨道 + 1个孤对电子轨道 + 4个成键轨道对应四角锥），故为 **sp³d² 杂化**。

结构示意：两个Bi通过2个Cl桥联，每个Bi额外连接3个端基Cl，形成两个四角锥配位环境。存在顺反两种异构体。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 配位数 | Bi配位数=5，8个Cl中2个共用 |
| 杂化轨道 | sp³d²（含1个孤对电子和1个空轨道） |
| 桥联配合物 | 两个Cl作桥联配体 |
| 几何构型 | 四角锥形，有顺反异构 |

## 解题思路

1. 2个Bi + 8个Cl → 每个Bi需5个配位原子
2. 若无桥联：2×5=10个Cl位，但只有8个Cl → 有2个Cl桥联
3. 每个Bi：2个桥联Cl + 3个端基Cl = 5配位
4. Bi为15族，6个杂化轨道 = sp³d²

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 桥联数 | 8-Cl中2个必须是桥联的，否则配位数不够 |
| 杂化类型 | sp³d²（不是sp³d，因为含孤对电子占一个轨道） |
| 顺反异构 | 两个端基Cl可位于同侧或异侧 |

**（3）**
虽然标准电极电势 Na < Mg（即Na更活泼），但此反应在液氨中进行，$\mathrm{MgI}_{2}$ 在液氨中为**难溶物**，沉淀的生成降低了溶液中 $\mathrm{Mg}^{2+}$ 的有效浓度，根据能斯特方程，$\mathrm{Mg}^{2+}/\mathrm{Mg}$ 的实际电极电势显著降低，使得 $E(\mathrm{MgI}_{2}/\mathrm{Mg}) < E(\mathrm{NaI}/\mathrm{Na})$，反应方向逆转。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 非水溶剂效应 | 液氨中溶解度不同于水溶液 |
| 能斯特方程 | 难溶物降低离子浓度，改变电极电势 |
| 溶度积 | MgI₂在液氨中难溶 |

## 解题思路

1. 水溶液中Na⁺/Na电势低于Mg²⁺/Mg → Na更活泼
2. 但在液氨中MgI₂是难溶物
3. 难溶物使[Mg²⁺]大幅降低 → 能斯特方程 → E(Mg²⁺/Mg)降低
4. 实际电势反转 → Mg能置换Na

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 溶剂背景 | 必须强调是液氨而非水溶液 |
| MgI₂溶解度 | 在液氨中难溶是关键，不能套用水溶液经验 |
| 能斯特方程 | 难溶物→低[M²⁺]→低电极电势 |

**（4）**
$\mathrm{Na}_{4}\mathrm{Pb}_{9}$ 中 Pb 存在形式为 $\mathrm{Pb}_{9}^{4-}$，Pb处于**负氧化态**。要变为Pb单质需**失电子**发生氧化反应，故在**阳极**沉积。

$$\mathrm{Pb}_{9}^{4-} - 4\mathrm{e}^{-} = 9\mathrm{Pb}$$

每9 mol Pb失4 mol电子，故1 mol电子能氧化产生 **9/4 = 2.25 mol Pb**。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| Zintl相 | Na₄Pb₉为Zintl相化合物 |
| 负氧化态金属 | Pb₉⁴⁻中Pb为负价 |
| 电解沉积 | 阳极氧化沉积 |

## 解题思路

1. Pb₉⁴⁻中Pb为负氧化态（4-/9 ≈ -0.44）
2. 负氧化态→零价：失电子→氧化反应→阳极
3. 电子计量：9Pb ~ 4e⁻ → 1.0 mol e⁻ → 2.25 mol Pb

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 电极判断 | 负氧化态→氧化→阳极（不是阴极） |
| 计量比 | 9Pb对应4e⁻，不是1:1 |

**（5）**
**m = 4**（金属原子配位数），**n = 4**（氧原子配位数）。

金属原子M均为四配位（平面四方配位），晶胞内氧原子为四面体四配位，棱上的氧同样为四配位。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 配位数判断 | 从晶胞图直接读取 |
| 平面四方配位 | M的配位几何 |
| 四面体配位 | O的配位几何 |

## 解题思路

1. 观察晶胞图中每个M周围最近邻的O数目 → 4
2. 观察每个O周围最近邻的M数目 → 4
3. M为平面四方配位，O为四面体配位

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 棱上原子 | 棱上氧原子需考虑共享 |
| 配位几何 | M为平面四方，O为四面体 |

## 🔗 同大题小问

**（6）**
**p = 4**（金属原子），**q = 4**（氧原子）。

- 金属原子M：4个在面上（4 × 1/2）+ 2个在晶胞内 = **4**
- 氧原子O：8个在棱上（8 × 1/4）+ 2个在晶胞内 = **4**





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 均摊法 | 面×1/2，棱×1/4，顶×1/8 |
| 晶胞计数 | 需区分面、棱、体内位置 |

## 解题思路

1. M原子：4个在面心位置 → 4 × 1/2 = 2；2个在晶胞内 → 2；总计 p = 4
2. O原子：8个在棱上 → 8 × 1/4 = 2；2个在晶胞内 → 2；总计 q = 4

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 位置判断 | 需仔细区分面心、棱、体内 |
| 均摊系数 | 面=1/2，棱=1/4（不是1/8） |

## 🔗 同大题小问

**（8）**
三个 $\left[cis-\mathrm{Co}(\mathrm{NH}_{3})_{4}(\mathrm{OH})_{2}\right]$ 单元相当于双齿配体，各以两个OH⁻与中心Co桥连。三个双齿配体围绕中心Co形成**三脚架（propeller）型结构**，必然具有手性（类似三叶螺旋桨）。

结构要点：
- 中心Co配位6个来自三个配体单元的OH
- 每个外围Co各自配位4个NH₃和2个OH（其中OH与中心Co桥联）
- 整体呈C₃对称性，有Δ和Λ两种对映体





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 多核配合物 | 羟基桥联多核钴配合物 |
| 手性判据 | 三脚架型配位→C₃对称→手性 |
| 立体化学 | Δ/Λ对映体 |

## 解题思路

1. 离子组成：1个中心Co + 3个外围Co(OH)₂(NH₃)₄
2. 每个外围单元提供2个OH桥联到中心Co
3. 3个双齿配体=6个配位点→中心Co配位数=6
4. 三脚架排列→螺旋手性

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 桥联方式 | OH是桥联配体，连接中心和外围Co |
| 手性来源 | 三脚架排列（不是中心Co的手性碳） |
| 配位数 | 中心Co=6，外围Co=6（各自完整） |

**（9）**
**X = CrO₂Cl₂（铬酰氯）**

M = 52.00 + 2×16.00 + 2×35.45 = **154.9 g/mol** ✓

结构：四面体构型（类AB₂C₂型），两个O和两个Cl围绕Cr呈四面体分布。两个相互垂直的镜面 + 二重旋转轴 = C₂ᵥ对称性。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 铬酰氯 | CrO₂Cl₂，强氧化性 |
| 分子对称性 | C₂ᵥ点群，2σ + C₂ |
| 元素推断 | 由制备方法+物理性质推断 |

## 解题思路

1. K₂Cr₂O₇ + NaCl + H₂SO₄ → 含Cr的化合物
2. 暗红色液体，强氧化性（遇硫燃烧）→ Cr(VI)化合物
3. M = 154.9 → CrO₂Cl₂（154.9）✓
4. 四面体AB₂C₂型：2σ（分别含Cr-O和Cr-Cl键）+ C₂轴
5. 遇水冒白烟：CrO₂Cl₂ + H₂O → CrO₃ + 2HCl↑

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 摩尔质量验证 | 154.9恰好等于CrO₂Cl₂ |
| 对称性 | C₂ᵥ点群，不是D₂ₕ |
| 遇水反应 | 产生HCl白烟，不是Cl₂ |

**（10）**
**Pd[C₁₄H₂₈N₄](ClO₄)₂**

计算过程：
1. 由ClO₄⁻化合物：C/H摩尔比 = (30.15/12.01):(5.06/1.008) = 1:2 → y = 2x
2. 由SCN⁻化合物：(x+2)/y = (40.46/12.01)/(5.94/1.008) → 解得 x ≈ 14, y = 28
3. 由分子量计算z：z = [14×12.01/30.15% - (106.4+12.01×4+1.008×28+2×99.45)]/14.01 ≈ 4





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 元素分析 | 质量分数→摩尔比 |
| 联立方程 | 两个化合物的数据联立求解 |
| 配合物组成 | Pd + 配体 + 反离子 |

## 解题思路

1. 第一个化合物C:H = 1:2 → y = 2x
2. 第二个化合物含额外2个C（来自SCN⁻），故(x+2)/y = 已知比
3. 代入y=2x → 解出x和y
4. 由第一个化合物的总分子量 → 求出z

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| SCN⁻贡献 | 转化后C增加2个（2个SCN⁻） |
| Pd原子量 | 使用106.4 |
| ClO₄⁻分子量 | 99.45 |
