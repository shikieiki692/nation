## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第8题(10分) 第(8-1)小问

画出HBr对烯烃加成反应中合理的带电荷中间体和产物的结构简式。

$(n\text{-C}_{5}\mathrm{H}_{11})_{2}\mathrm{CuLi}$ 对 α,β-不饱和酮的加成，然后加水。画出中间体3和产物4。

画出 CH₃SeCl 与烯烃反应的中间体5和产物6的结构简式。

$\mathrm{CH}_{3}\mathrm{CH}_{2}\mathrm{C}{\equiv}\mathrm{CH}$ 与 Br₂/H₂O 反应，画出中间体7、8和产物9、10。

## 参考答案

**（1）**
**中间体1**：三级碳正离子（H⁺优先加到含H多的碳上，形成更稳定的碳正离子）

**产物2**：马氏加成产物（Br⁻进攻碳正离子）

机理：
1. 烯烃 + H⁺ → 三级碳正离子（马氏规则本质：优先形成更稳定碳正离子）
2. 碳正离子 + Br⁻ → 加成产物





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 马氏规则 | H加在含H多的碳上 |
| 碳正离子稳定性 | 3° > 2° > 1° |
| 亲电加成 | HBr对烯烃的亲电加成 |

## 解题思路

1. H⁺是亲电试剂，首先进攻双键
2. 优先形成更稳定的碳正离子（三级 > 二级 > 一级）
3. Br⁻随后进攻碳正离子

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 碳正离子级别 | 必须是更稳定的那个（三级优先） |
| 加成方向 | 遵循马氏规则 |
| 中间体 | 碳正离子（不是自由基） |

**（2）**
**中间体3**：1,4-加成（共轭加成）产生的烯醇负离子

**产物4**：水解后得到饱和酮（烷基加在β-碳上）

烷基铜锂（Gilman试剂）是**空间位阻大、亲核性较软**的有机金属试剂，对于α,β-不饱和羰基化合物只能发生**1,4-加成**（共轭加成），而不是1,2-加成。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| Gilman试剂 | R₂CuLi，软亲核试剂 |
| 1,4-加成 | 共轭加成，发生在β-碳 |
| 硬软酸碱 | 软亲核试剂→1,4-加成 |

## 解题思路

1. R₂CuLi中R⁻为软亲核试剂
2. α,β-不饱和羰基中β-碳为软亲电位点
3. 软亲软→1,4-加成
4. 加水后烯醇→酮（互变异构）

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 加成位置 | 1,4-（不是1,2-） |
| Gilman试剂特点 | 软亲核试剂→共轭加成 |
| 水的作用 | 提供质子，使烯醇→酮 |

**（3）**
**中间体5**：硒鎓离子三元环（类溴鎓离子）

**产物6**：反式加成产物（Cl⁻从背面进攻开环）

机理：
1. CH₃SeCl中Se带部分正电荷，类似BrCl中的Br
2. 烯烃亲核进攻Se，Cl⁻离去
3. 形成硒鎓离子三元环（类似溴鎓离子）
4. Cl⁻反式进攻开环→反式加成产物

可将 CH₃SeCl 类比为 BrCl 来理解。





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 硒鎓离子 | 类似溴鎓离子的三元环中间体 |
| 类比法 | CH₃SeCl ≈ BrCl |
| 反式加成 | Cl⁻从背面进攻 |

## 解题思路

1. Se-Cl键比C-Se键更容易断裂
2. Cl⁻离去后Se带正电→亲电性
3. 烯烃进攻Se→三元环（硒鎓离子）
4. Cl⁻反式进攻→反式开环

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 类比对象 | CH₃SeCl可类比BrCl |
| 断键位置 | Se-Cl（不是C-Se） |
| 立体化学 | 反式加成（anti-addition） |

**（4）**
**中间体7**：溴鎓离子（三元环正离子）

**中间体8**：H₂O开环后的烯醇

**产物9**：烯醇异构化后的酮（2-丁酮）

**产物10**：进一步加成的二溴产物

机理：
1. 炔与Br₂加成→溴鎓离子（中间体7）
2. H₂O开环→烯醇（中间体8）
3. 烯醇异构化→酮（产物9，互变异构）
4. 类似炔的羟汞化反应





## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 炔烃亲电加成 | Br₂加成到三键 |
| 溴鎓离子 | 三元环中间体 |
| 烯醇互变异构 | 烯醇→酮 |

## 解题思路

1. Br₂对炔加成→溴鎓离子
2. H₂O作为亲核试剂开环
3. 生成的烯醇不稳定→互变异构为酮
4. 类比炔的羟汞化-脱汞反应

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 烯醇→酮 | 互变异构是关键步骤 |
| 产物选择 | 主产物为酮（不是醇） |
| 类比 | 类似炔的羟汞化反应 |
