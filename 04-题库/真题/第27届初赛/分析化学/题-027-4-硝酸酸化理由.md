## 题目

> **来源**：第27届中国化学奥林匹克（初赛）第4题(7分) 第(4-1)小问

简述配制硝酸汞溶液时必须用硝酸酸化的理由。

称取 1.713 g Hg(NO₃)₂·xH₂O，配制成 500 mL 溶液作为滴定剂。取 20.00 mL 0.0100 mol/L NaCl 标准溶液，用上述硝酸汞溶液滴定至紫色，消耗 10.20 mL。推断该硝酸汞水合物样品的化学式。

取 0.500 mL 血清，加去离子水、HNO₃ 和指示剂，用硝酸汞溶液滴定至终点，消耗 1.53 mL。以十倍于血清样品体积的水为试样进行空白实验，消耗硝酸汞溶液 0.80 mL。计算该血清样品中氯离子的浓度（mg/100 mL）。

## 参考答案

**（1）**
$\mathrm{Hg}^{2+}$ 为18e⁻结构，变形性大，在中性水溶液中会强烈**水解**生成 $\mathrm{Hg(OH)NO}_{3}$ 等碱式盐沉淀。加入硝酸可以**抑制Hg²⁺的水解**，保持汞以游离离子形式存在于溶液中。

$$\mathrm{Hg}^{2+} + \mathrm{H}_{2}\mathrm{O} \rightleftharpoons \mathrm{Hg(OH)}^{+} + \mathrm{H}^{+}$$

加酸使平衡左移。

## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| Hg²⁺水解 | 18e⁻构型，极化力强 |
| 酸化抑制水解 | 勒夏特列原理 |
| 滴定液配制 | 标准溶液的配制要求 |

## 解题思路

1. Hg²⁺为18e⁻构型→高极化率→易水解
2. 水解产物Hg(OH)NO₃影响滴定
3. 加HNO₃→[H⁺]增大→抑制水解

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 原因 | 是抑制水解，不是防止氧化 |
| 酸的选择 | 必须用HNO₃（不能用HCl，会生成HgCl₂沉淀） |

**（2）**
**Hg(NO₃)₂·1.4H₂O**

计算过程：
- 计量关系：1 Hg²⁺ ~ 2 Cl⁻
- c(Hg(NO₃)₂) = ½ × (20.00/10.20) × 0.0100 = 9.80×10⁻³ mol/L
- n(Hg(NO₃)₂) = 9.80×10⁻³ × 0.500 = 4.90 mmol
- M = 1713/4.90 = 350 g/mol
- x = (350 - 324.6)/18.00 ≈ 1.4

## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 汞量法 | Hg²⁺ + 2Cl⁻ → HgCl₂ |
| 滴定计算 | 标准溶液浓度→物质的量→摩尔质量 |
| 水合物组成 | 由摩尔质量差确定结晶水 |

## 解题思路

1. 由NaCl标准溶液标定Hg(NO₃)₂浓度
2. 由浓度和体积得物质的量
3. 由质量和物质的量得摩尔质量
4. 减去无水Hg(NO₃)₂的M → 结晶水

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 计量比 | Hg²⁺:Cl⁻ = 1:2（不是1:1） |
| 摩尔质量 | Hg(NO₃)₂ = 324.6 |
| x值 | 1.4不是整数，样品可能不均匀 |

**（3）**
**201 mg/100 mL**

计算过程：
- 空白校正：实际消耗 = 1.53 - 0.80×0.1 = **1.45 mL**（空白用5mL水但样品用0.5mL水，需按比例校正）
- c(Cl⁻) = 2 × c(Hg(NO₃)₂) × V(Hg)/V(样品)
- c(Cl⁻) = 2 × 9.80×10⁻³ × 1.45/0.500 = 5.68×10⁻² mol/L
- 换算：5.68×10⁻² × 35.45 × 1000/10 = 201 mg/100 mL

## 知识点映射

| 知识点 | 对应内容 |
|:---|:---|
| 空白实验 | 校正指示剂消耗的金属离子 |
| 浓度换算 | mol/L → mg/100 mL |
| 临床分析 | 血清氯离子正常范围 |

## 解题思路

1. 空白实验校正指示剂（二苯卡巴腙）消耗的Hg²⁺
2. 空白用5mL水（10倍体积），消耗0.80mL → 0.5mL样品对应空白消耗0.08mL
3. 实际V = 1.53 - 0.08 = 1.45 mL
4. 计算浓度并换算单位

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 空白校正 | 样品消耗需扣除空白，但需按体积比例折算 |
| 体积比例 | 空白用5mL水，样品用0.5mL → 10倍关系 |
| 单位换算 | mol/L → mg/100mL需乘以M和换算因子 |
