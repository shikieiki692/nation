# 亲电加成-碳正离子重排与3,3-二甲基-1-丁烯+HBr反应

## 题目

3,3-二甲基-1-丁烯 $(\mathrm{CH_3})_3\mathrm{CCH=CH_2}$ 与 $\mathrm{HBr}$ 反应，得到两种主要产物 A 和 B，其中 A 为正常的马氏加成产物，B 为经过碳正离子重排的产物。

(1) 写出 A 和 B 的结构式。

(2) 分别画出生成 A 和 B 的完整机理，标出每一步中碳正离子的结构变化。

(3) 某实验中 B 的比例随温度升高而增加。提出至少三种可能原因，并说明为什么不能仅凭温度变化就断言反应已转为热力学控制。

(4) 若改用 3,3-二甲基-1-丁烯与 $\mathrm{HI}$ 反应，产物组成与 $\mathrm{HBr}$ 相比可能怎样变化？请比较亲核捕获、重排、离子对和溶剂效应，并说明仅凭卤素身份能否唯一预测产物比例。

## 解析

### 分析

1. 正常加成：H⁺ 加在=CH₂上 → 生成 2° 碳正离子 → Br⁻ 捕获 → 产物 A。
2. 但此 2° 碳正离子邻位有一个叔碳（C(CH₃)₃），可发生**甲基的 1,2-迁移（Wagner-Meerwein 重排）**，将 2° 碳正离子重排为更稳定的 3° 碳正离子 → Br⁻ 捕获 → 产物 B。
3. 温度变化可能同时影响碳正离子生成、1,2-迁移、卤离子捕获和后续异构化，不能只用“热力学更稳定”概括。
4. HI 与 HBr 的产物组成需要综合卤离子亲核捕获、重排速率、离子对/溶剂化等因素判断。

### 解答

**(1) 产物结构**

**产物 A**（正常马氏加成）：$\mathrm{(CH_3)_3CCHBrCH_3}$（2-溴-3,3-二甲基丁烷）

**产物 B**（重排产物）：$\mathrm{(CH_3)_2CBrCH(CH_3)_2}$（2-溴-2,3-二甲基丁烷）

**(2) 机理**

**生成 A 的路径**：

$$\mathrm{(CH_3)_3CCH=CH_2 + H^+ \longrightarrow (CH_3)_3C\mathop{CH}\limits^{+}CH_3}$$

（2° 碳正离子，邻位有叔丁基）

$$\mathrm{(CH_3)_3C\mathop{CH}\limits^{+}CH_3 + Br^- \longrightarrow (CH_3)_3CCHBrCH_3}$$

**生成 B 的路径（重排路径）**：

初始生成的 2° 碳正离子 $\mathrm{(CH_3)_3C\mathop{CH}\limits^{+}CH_3}$ 发生**甲基 1,2-迁移**（其中一个 CH₃ 从 C3 迁移到 C2⁺）：

$$\mathrm{(CH_3)_3C\mathop{CH}\limits^{+}CH_3 \longrightarrow (CH_3)_2\mathop{C}\limits^{+}CH(CH_3)_2}$$

重排后得到更稳定的 3° 碳正离子。然后：

$$\mathrm{(CH_3)_2\mathop{C}\limits^{+}CH(CH_3)_2 + Br^- \longrightarrow (CH_3)_2CBrCH(CH_3)_2}$$

**(3) 温度效应的可能解释**

实验中 B 比例随温度升高而增加，至少有以下可能原因：

1. 1,2-甲基迁移相对于卤离子捕获的相对速率随温度改变，高温使重排路径竞争得更充分。
2. 碳正离子生成步骤、离子对解离和后续捕获的活化能不同，升温会改变各路径的相对通量。
3. 产物 A 或 B 可能发生二次异构化/回转，升温改变最终可观测组成。
4. 若存在可逆步骤，升温也可能改变平衡组成，但必须有独立证据确认体系达到热力学平衡。

因此，单凭“B 随温度增加”不能直接断言高温就是热力学控制；需要知道各步骤的速率、可逆性和产物稳定性。

**(4) HI 与 HBr 的比较**

需要比较的因素包括：

- 卤离子对碳正离子/离子对的亲核捕获速率；
- 1,2-甲基迁移相对于捕获的速率；
- 离子对紧密程度、卤离子解离和溶剂化；
- 产物是否发生二次异构化以及反应温度、浓度和溶剂。

在相同溶剂、浓度和温度下，若 $\mathrm{I^-}$ 的捕获明显快于迁移，B 可能减少；但 $\mathrm{I^-}$ 的亲核性、可极化性和离子对效应也会改变重排与捕获的竞争，且 HI 与 HBr 的酸性、溶剂化不同。因此不能仅凭“卤素不同”断言 $\mathrm{HI}$ 一定降低 B；必须结合具体条件和实验数据判断。

### 反思

碳正离子重排是亲电加成中最容易出错的考点。关键判断点：生成的碳正离子邻位是否有能迁移的基团（$\mathrm{H}$、$\mathrm{CH_3}$、$\mathrm{Ph}$ 等）且重排后是否得到更稳定的碳正离子；迁移基团应写成 H、CH₃、Ph 或“1,2-氢迁移、1,2-甲基迁移”，不能写成 $\mathrm{H^-}$、$\mathrm{CH_3^-}$、$\mathrm{Ph^-}$。迁移驱动力通常是生成更稳定的碳正离子，但具体产物分布还要考虑捕获、离子对和可逆性。
