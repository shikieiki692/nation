# Beckmann重排-环己酮肟经酸催化生成己内酰胺

## 题目

环己酮肟在浓 $\mathrm{H_2SO_4}$ 或 $\mathrm{PCl_5}$ 作用下发生 Beckmann 重排，生成己内酰胺——尼龙 6 的单体。

(1) 写出环己酮肟的结构式，并讨论其 $\mathrm{C=N}$ 两侧为同一环的等价碳链时，是否真正存在可区分的 E/Z（或 syn/anti）几何异构体。若用不对称酮肟讨论迁移选择性，应如何描述几何构型？

(2) 写出 Beckmann 重排的完整机理，画出关键步骤中基团迁移的立体电子效应。

(3) 工业上利用 Beckmann 重排年产数百万吨己内酰胺。简述在工业催化方面的主要进展（从传统的浓硫酸法到现代催化方法）。

(4) 若使用不对称酮的肟（如苯乙酮肟 $\mathrm{PhC(=NOH)CH_3}$）进行 Beckmann 重排：分别预测单一 E 异构体和单一 Z 异构体中迁移的基团及产物；若得到的是几何异构体混合物，说明还需要哪些信息才能判断产物比例。

## 解析

### 分析

1. Beckmann 重排中，与肟羟基（经质子化后为 $\mathrm{-OH_2^+}$）处于 anti 关系的碳基团发生 1,2-迁移，同时 $\mathrm{H_2O}$ 离去，生成腈鎓离子。
2. 立体化学关键：迁移基团必须与离去基团处于适当 anti 取向；不对称酮肟的几何构型决定哪一个基团迁移。
3. 工业应用：从传统浓硫酸催化到现代固体酸/分子筛催化。
4. 对几何异构体混合物，产物比例不能仅凭“芳基优先于烷基”判断，还要知道 E/Z 比例、异构化、迁移速率和中间体捕获/水解速率。

### 解答

**(1) 环己酮肟的几何异构问题**

环己酮肟的 $\mathrm{C=N}$ 两侧是同一个环的两个 α-碳链。虽然可以把 $\mathrm{OH}$ 放在 $\mathrm{C=N}$ 的任一侧并用 E/Z 或 syn/anti 标记，但由于环己酮的两个 α-碳及其相连碳链在拓扑上等价，这两种画法并不对应可分离、可区分的几何异构体，因此不应把它们描述成两种真正不同的 E/Z 异构体。

对不对称酮肟（例如苯乙酮肟）才需要明确 E/Z 或 syn/anti：必须写清 $\mathrm{OH}$ 相对于 $\mathrm{C=N}$ 两侧 $\mathrm{Ph}$ 与 $\mathrm{CH_3}$ 的空间关系。Beckmann 重排中迁移的是与离去基团 anti 的碳基团。

**(2) 完整机理**

**步骤 1**：肟的 OH 质子化（活化离去基团）

$$\mathrm{\!-\!C=N\!-\!OH + H^+ \longrightarrow \!-\!C=N\!-\!OH_2^+}$$

**步骤 2**：水离去，并且与 $\mathrm{OH_2^+}$ 处于 anti 的碳基团发生 1,2-迁移

$$\mathrm{R^1R^2C=N^+-OH_2 \longrightarrow [R^1R^2C^+-N] \longrightarrow R^1R^2C=NH^+}$$

核心步中离去的是 $\mathrm{H_2O}$，不是 $\mathrm{N_2}$。质子化羟基后，与离去基团 anti 的碳基团带着一对电子迁移到缺电子氮；水离去生成腈鎓离子。迁移与 C-N 键重组可协同但异步。

**步骤 3**：水解（或与水反应）

对环己酮肟：迁移后生成的腈鎓离子 $\mathrm{-C(=NH^+)-}$ 加水 → 酰胺，随后环化得到 ε-己内酰胺。

$$\mathrm{-\!C(=NH^+)\!-\! + H_2O \longrightarrow \!-\!C(=O)\!-\!NH\!-\! + H^+}$$

最终产物：己内酰胺（ε-己内酰胺，七元环内酰胺）。

**(3) 工业催化进展**

**传统法（浓硫酸法）**：
- 环己酮肟 + 发烟硫酸 → 己内酰胺
- 产生大量低价值的硫酸铵副产物（每吨己内酰胺约 2-3 吨硫酸铵）
- 腐蚀性强，设备要求高

**现代催化方法**：
- **气相 Beckmann 重排**：使用固体酸催化剂（如高硅 MFI 型分子筛、B-MFI 等），环己酮肟在气相通过催化剂床层发生重排
- 代表性的催化剂：高硅 ZSM-5（Si/Al 比极高）或全硅沸石 Silicalite-1，其弱酸性位点足够催化重排但不会导致深度副反应
- 优点：无硫酸铵副产物、连续操作、环境友好
- **Sumitomo 工艺**（已工业化）：使用流化床反应器 + 高硅 MFI 分子筛催化剂

**(4) 不对称酮肟的迁移选择性**

苯乙酮肟 $\mathrm{PhC(=NOH)CH_3}$：先明确几何构型，再按 anti 迁移规则预测。

- 若某单一几何异构体中 $\mathrm{Ph}$ 与 $\mathrm{OH}$ 反式（anti），则 **Ph 迁移** → $\mathrm{CH_3CONHPh}$（乙酰苯胺）。
- 若某单一几何异构体中 $\mathrm{CH_3}$ 与 $\mathrm{OH}$ 反式（anti），则 **CH₃ 迁移** → $\mathrm{PhCONHCH_3}$（N-甲基苯甲酰胺）。

若起始物是 E/Z 混合物，不能仅凭“芳基一定优先迁移”判断产物比例；还需要 E/Z 组成、肟在反应条件下的异构化、不同几何异构体的迁移速率以及腈鎓离子加水/捕获速率。

### 反思

Beckmann 重排的三要素：(1) **几何构型决定迁移基团**（与 $\mathrm{OH_2^+}$ 离去基团 anti 的碳基团迁移）；(2) **水离去伴随 1,2-迁移**（协同/异步过程不得写成 $\mathrm{N_2}$ 离去）；(3) **混合物比例需综合考虑异构化和动力学**。与 Beckmann 重排类似的缺电子氮相关重排还有 Curtius、Hofmann、Schmidt 等，但具体中间体和离去基团不能混写。
