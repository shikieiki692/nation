# Hofmann消除-季铵碱热消除生成烯烃

## 题目

某二级胺经充分甲基化（$\mathrm{CH_3I}$ 过量 + $\mathrm{Ag_2O/H_2O}$）转化为季铵碱，加热至 150°C 发生消除反应。已知该二级胺来源于下列底物的转化，请分别给出最终烯烃产物的结构式；若区域选择性不能保证唯一产物，应列出主要可能异构体并说明选择性依据：

| 底物 | 最终烯烃产物（可列主要/可能异构体） |
|:---|:---|
| (a) 哌啶（六氢吡啶） | ？ |
| (b) 2-甲基哌啶 | ？ |
| (c) N,N-二甲基环己胺 | ？ |

(1) Hofmann 消除的区域选择性规则（Hofmann 规则）与 Zaitsev 规则截然相反。请总结 Hofmann 规则的内容，并解释为什么季铵碱的热消除遵循 Hofmann 规则。

(2) 该消除反应的立体化学要求是什么？画出哌啶衍生的季铵碱发生消除时的反式共平面构象。

(3) 对比 E2 消除（如 2-溴丁烷 + KOH/EtOH）与 Hofmann 消除的异同，填表比较两者的底物、碱、区域选择性、C-H/C-LG 断裂程度和立体化学要求。

## 解析

### 分析

1. Hofmann 消除是季铵碱（$\mathrm{R_4N^+OH^-}$）在加热下的消除反应，生成烯烃 + 叔胺 + 水。
2. Hofmann 规则：季铵碱消除优先生成**取代最少的烯烃**（与 Zaitsev 规则相反）。
3. Hofmann 消除同样要求**反式共平面**消除。
4. 环状季铵碱消除时断裂一个 N-C(环) 键并在相邻 C-C 位形成双键；例如 N,N-二甲基哌啶鎓可开环生成末端烯烃。

### 解答

**(1) 各底物的最终烯烃产物**

**(a) 哌啶 → 季铵碱 → 消除**

哌啶 → $\mathrm{CH_3I}$ 充分甲基化 → N,N-二甲基哌啶鎓碘化物 → $\mathrm{Ag_2O/H_2O}$ → 季铵碱 → 加热消除。

哌啶的季铵碱有两个不同的 β-H：

消除产物：$\mathrm{CH_2=CHCH_2CH_2CH_2N(CH_3)_2}$（N,N-二甲基-4-戊烯-1-胺）

注意：环打开，在取代较少的一端生成双键（Hofmann 规则）。两个 β-碳等同时，得到对称产物。

**(b) 2-甲基哌啶 → 季铵碱 → 消除**

2-甲基哌啶形成的 N,N-二甲基-2-甲基哌啶鎓可在两个区域开环，得到两种可能烯烃：

- Hofmann 倾向的较少取代端烯：$\mathrm{CH_2=CHCH_2CH_2CH(CH_3)N(CH_3)_2}$
- 另一路径的内部烯烃：$\mathrm{CH_3CH=CHCH_2CH_2CH_2N(CH_3)_2}$

不能不加条件地只写一种产物；区域选择性取决于可接近的 β-H、反式共平面构象、位阻以及碱/温度条件。

**(c) N,N-二甲基环己胺 → 季铵碱 → 消除**

N,N-二甲基环己胺的氮在环外，充分甲基化得到环己基三甲基铵。其 Hofmann 消除断裂 N-环己基键并从相邻环碳消除 β-H，生成：

- **环己烯**
- **三甲胺** $\mathrm{N(CH_3)_3}$
- **水** $\mathrm{H_2O}$

不能写成开环的 $\mathrm{N,N}$-二甲基-5-己烯-1-胺。

**Hofmann 规则**：季铵碱的热消除优先生成取代最少的烯烃（即双键碳上连接的烷基数尽可能少）。

**原因**：季铵碱的消除属于 E2，但由于 $\mathrm{N(CH_3)_3^+}$ 是强吸电子、体积大且难离去的基团，过渡态中 C-H 断裂较早，β-碳具有较高负电荷特征。较少取代的 β-碳更能稳定这种负电荷特征，因此较少取代烯烃路径占优；$\mathrm{N(CH_3)_3^+}$ 的 -I 效应也提高 β-H 的酸性。

**(2) 立体化学要求**

Hofmann 消除同样要求被消除的 H 和 $\mathrm{N(CH_3)_3^+}$ 成**反式共平面**（二面角 ≈ 180°）。

以哌啶衍生的季铵碱为例（环己烷构象）：

在椅式构象中，$\mathrm{N(CH_3)_3^+}$ 占据直立键（a 键），只有与其处于反式共平面的 a 键 β-H 才能被消除。

**(3) E2 消除 vs Hofmann 消除对比**

| 特征 | E2 消除（卤代烷 + KOH） | Hofmann 消除（季铵碱加热） |
|:---|:---|:---|
| 底物 | 卤代烷 | 季铵碱 $\mathrm{R_4N^+OH^-}$ |
| 离去基团 | $\mathrm{Br^-}$、$\mathrm{Cl^-}$ 等 | $\mathrm{N(CH_3)_3}$（中性叔胺） |
| 碱 | 外加碱（OH⁻、EtO⁻等） | $\mathrm{OH^-}$（季铵碱的反离子） |
| 区域选择性 | **Zaitsev 规则**（取代最多的烯烃） | **Hofmann 规则**（取代最少的烯烃） |
| 过渡态特征 | 协同 E2；C-H 与 C-Br 断裂程度相对接近 | 协同 E2；C-H 断裂较早、C-N 断裂较晚，β-碳负电荷特征更强 |
| 立体化学 | 反式共平面 | 反式共平面 |

### 反思

Hofmann 消除与普通 E2 消除最本质的区别在于**区域选择性通常相反**——普通小位阻强碱条件下常得 Zaitsev 产物，而季铵碱热消除常得 Hofmann（较少取代）产物。原因是季铵碱 E2 过渡态中 C-H 断裂较早、C-N 断裂较晚，β-碳负电荷特征较强；普通 E2 过渡态不能说成“具有碳正离子特征”。具体题目还要结合 β-H 可接近性、反式共平面要求和碱/温度条件判断。
