# 题-浙江21-单选-22-卡尔费休法测水

卡尔-费休法是测定有机溶剂中的微量水含量的经典方法。所用试剂由碘、二氧化硫、吡啶（C₅H₅N，有机碱，与 H⁺ 反应生成 C₅H₅NH⁺）和无水甲醇按一定比例配制而成。该试剂与待测溶剂中的水反应后，产物的含量用库仑滴定法来测定。下列说法错误的是
- A. 该方法的原理是利用碘与二氧化硫反应，离子方程式为：I₂ + SO₂ + 2 H₂O → 2 H⁺ + SO₄²⁻ + 2 HI
- B. 加入吡啶的作用是中和产生的酸，促进反应进行完全
- C. 加入甲醇可以进一步稳定产物，生成 C₅H₅NHSO₄CH₃
- D. 总反应可表示为：I₂ + SO₂ + H₂O + 3 C₅H₅N + CH₃OH → C₅H₅NHSO₄CH₃ + 2 C₅H₅NHI
