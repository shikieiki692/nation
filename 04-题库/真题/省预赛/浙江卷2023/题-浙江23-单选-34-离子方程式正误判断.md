# 题-浙江23-单选-34-离子方程式正误判断

以下反应离子方程式中，选项正确的是
- A. 将数滴 0.1 mol L⁻¹ HCl 溶液缓缓滴入至 1 mol L⁻¹ 50 mL Na₃PO₄ 溶液中，且不断搅拌：3 H⁺ + PO₄³⁻ → H₃PO₄
- B. 将 1 mol L⁻¹ NaAlO₂ 溶液和 1.5 mol L⁻¹ 的 HCl 溶液等体积互相均匀混合：6 AlO₂⁻ + 9 H⁺ + 3 H₂O → 5 Al(OH)₃ + Al³⁺
- C. 向 1 mol L⁻¹ 明矾溶液 50 mL 中滴入数滴 0.1 mol L⁻¹ Ba(OH)₂ 溶液：Al³⁺ + 2 SO₄²⁻ + 2 Ba²⁺ + 3 OH⁻ → Al(OH)₃ + 2 BaSO₄
- D. 将少量 SO₂ 气体通入 NaClO 溶液中：SO₂ + H₂O + ClO⁻ → SO₄²⁻ + Cl⁻ + 2 H⁺
