# 题-浙江22-多选-62-离子方程式正误

下列有关化学反应的离子方程式，书写不正确的是
- A. Na₂O₂ 与 H₂¹⁸O 反应：2 Na₂O₂ + 2 H₂¹⁸O → 4 Na⁺ + 4 OH⁻ + ¹⁸O₂↑
- B. 向 FeBr₂ 溶液中通入等物质的量的 Cl₂：2 Fe²⁺ + 2 Br⁻ + 2 Cl₂ → 2 Fe³⁺ + Br₂ + 4 Cl⁻
- C. 往 Cu(NO₃)₂ 溶液中通入过量 H₂S：Cu²⁺ + H₂S → CuS↓ + 2 H⁺
- D. 向 KAl(SO₄)₂ 溶液中加入少量 Ba(OH)₂ 溶液：2 Al³⁺ + 3 SO₄²⁻ + 3 Ba²⁺ + 6 OH⁻ → 2 Al(OH)₃↓ + 3 BaSO₄↓
