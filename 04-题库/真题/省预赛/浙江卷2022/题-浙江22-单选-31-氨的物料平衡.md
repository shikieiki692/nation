# 题-浙江22-单选-31-氨的物料平衡

- A. [NH₃] + [NH₄⁺] + [Ag(NH₃)⁺] + [Ag(NH₃)₂⁺] = 0.20 mol L⁻¹
- B. [NH₃] + [NH₄⁺] + 2[Ag(NH₃)₂⁺] = 0.20 mol L⁻¹
- C. [NH₃] + [NH₄⁺] + [Ag(NH₃)⁺] + 2[Ag(NH₃)₂⁺] = 0.20 mol L⁻¹
- D. [Ag(NH₃)⁺] + [Ag(NH₃)₂⁺] = 0.20 mol L⁻¹
