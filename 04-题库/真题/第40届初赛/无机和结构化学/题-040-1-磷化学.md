## 题目

> 来源：[[07-资料提炼/提炼-第40届初赛试题解析]]（原始文件：[[40届初赛/第40届化学奥林匹克初赛答案11144113321211]]）

**第1题 磷化学（19 分，7%）**

磷氢化物 $\mathrm{PH}_{3}$ 是半导体产业常用的磷源前驱体，其纯度要求在 $99.9999\%$ 以上，主要用于生长含磷的 III-V 族半导体外延层（InP、GaP、InGaP 等）。研究表明，$\mathrm{PH}_{3}$ 不仅能与有机化合物反应构建 P–C 和 P–OC 键，还能与主族元素形成相应的化合物。

**1.1** $\mathrm{PH_3}$ 常用磷化钙水解或白磷与热的 KOH 水溶液反应制备，白磷中 $25\%$ 的磷转化为 $\mathrm{PH_3}$。分别写出这两种制备方法的反应方程式。

**1.2** 在乙醇溶液中，$\mathrm{PH_3}$ 可被过量的 $\mathrm{I_2}$ 氧化，写出此化学反应方程式。

**1.3** 在盐酸溶液中，$\mathrm{PH_3}$ 与甲醛反应，生成一种被广泛用于防燃布料的化合物 THPC。THPC 在过量 NaOH 作用下，生成等摩尔数的氢气、甲醛和氯化钠。分别写出这两个反应的反应方程式。

**1.4** 通常，$\mathrm{PH_3}$ 中常含有易自燃的杂质 $\mathrm{P_2H_4}$。彻底去除 $\mathrm{P_2H_4}$ 后，就可以大幅抑制其自燃。$\mathrm{P_2H_4}$ 不稳定，可通过加热或催化剂下经歧化反应转化为 $\mathrm{PH_3}$，写出此反应方程式。

**1.5** $\mathrm{PH_3}$ 能与第三主族的 Lewis 酸形成配合物，其成键能力不仅受 $\sigma$ 配键的影响，也受 $\pi$ 反馈键的影响。

**1.5.1** 与 $\mathrm{PR_3}$ 相比，(a) 形成 $\sigma$ 配位键的能力 $\mathrm{PH_3}$ ____ $\mathrm{PR_3}$，(b) 形成 $\pi$ 反馈键的能力 $\mathrm{PH_3}$ ____ $\mathrm{PR_3}$。（填写大于、小于、等于或无法判断）

**1.5.2** $\mathrm{PH_3}$ 与 $\mathrm{Bu_3Ga}$ 反应生成一个含磷镓键的六元环分子，画出此分子的结构式。

**1.6** $\mathrm{PH_3}$ 与第四主族元素的二芳基化合物 $\mathrm{GeAr_2}$（$\mathrm{Ar=C_6H_3}$-2,6($\mathrm{C_6H_2}$-2,4,6-$\mathrm{Me_3}$)$_2$）反应，首先通过对 P–H 键的活化生成了氧化加成的产物 (a)；研究表明，还有一个含有一个四元环的、芳基消除的产物 (b)。分别画出产物 (a) 和 (b) 的结构式。

$$\mathrm{Ca_3P_2 + 6H_2O \longrightarrow 2PH_3 + 3Ca(OH)_2}$$

$$\mathrm{P_4 + 3KOH + 3H_2O \longrightarrow PH_3 + 3KH_2PO_2}$$

（2 分；产物 1 分，配平 1 分，反应物写成 P 不给分）

**1.2**（共 2 分）下列任一种均得分：

$$4\mathrm{I_2} + \mathrm{PH_3} + 4\mathrm{CH_3CH_2OH} \longrightarrow (\mathrm{HO})_3\mathrm{PO} + 4\mathrm{CH_3CH_2I} + 4\mathrm{HI}$$

## 知识点映射

| 知识点 | 关联程度 | 说明 |
|:---|:---:|:---|
| $\mathrm{PH_3}$ 制备 | 直接 | 磷化钙水解（复分解）、白磷碱歧化（氧化还原） |
| $\mathrm{PH_3}$ 还原性 | 直接 | 被 $\mathrm{I_2}$ 氧化为磷酸/磷酸酯，$\mathrm{I_2}$ 还原为 $\mathrm{C_2H_5I}$ |
| THPC | 直接 | $\mathrm{PH_3}$ 与甲醛在 HCl 中生成季鏻盐；碱解出 $\mathrm{H_2}$ |
| $\mathrm{P_2H_4}$ 歧化 | 直接 | 不稳定，转化为 $\mathrm{PH_3}$ 与 $\mathrm{P_4}$/P |
| $\sigma$ 配键 / $\pi$ 反馈键 | 直接 | $\mathrm{PH_3}$ 与 $\mathrm{PR_3}$ 成键能力差异 |
| 氧化加成 / 芳基消除 | 直接 | 主族元素化合物对 P–H 键的活化 |

## 解题思路

1. **1.1 两条路线分属不同反应类型**：磷化钙水解是复分解（$\mathrm{P^{3-}}$ 质子化）；白磷与热碱则是**歧化**——$\mathrm{P_4}$ 中 P(0) 一部分被氧化为 $\mathrm{KH_2PO_2}$ 中的 P(+1)，一部分被还原为 $\mathrm{PH_3}$ 中的 P(−3)。题给"25% 的磷转化为 $\mathrm{PH_3}$"正对应这一歧化计量。
2. **1.2 溶剂参与**：乙醇既作溶剂又作反应物，$\mathrm{I_2}$ 氧化 $\mathrm{PH_3}$ 的产物可以是磷酸或磷酸三乙酯，$\mathrm{I_2}$ 被还原为 $\mathrm{C_2H_5I}$ 与/或 $\mathrm{HI}$，故有多组等价写法。
3. **1.3 抓住"防燃布料"线索**：THPC 即四羟甲基氯化鏻，是棉织物阻燃整理的经典试剂。碱解产物已由题面给出（等摩尔 $\mathrm{H_2}$、$\mathrm{HCHO}$、$\mathrm{NaCl}$），据此配平。
4. **1.5.1 电性决定**：$\mathrm{PR_3}$ 中 R 为推电子基，P 上电子云密度更高 → $\sigma$ 给电子能力 $\mathrm{PR_3}>\mathrm{PH_3}$；而 $\mathrm{PH_3}$ 的 $\sigma^\*$（P–H）轨道能量更低、更易接受金属反馈电子 → $\pi$ 反馈能力 $\mathrm{PH_3}>\mathrm{PR_3}$。
5. **1.6 类比过渡金属化学**：氧化加成与还原消除本是过渡金属基元反应，此处迁移到主族 Ge 化合物，是"主族元素模拟过渡金属行为"的前沿情境。

## 易错分析

- **1.1** 白磷路线误写成 $\mathrm{P}$ 而非 $\mathrm{P_4}$（明确不给分）；漏写"白磷中 25% 转化为 $\mathrm{PH_3}$"所对应的歧化计量。
- **1.2** 忘记乙醇参与反应，只写 $\mathrm{PH_3 + I_2}$ 的无机产物；或漏配平 $\mathrm{HI}$/$\mathrm{H_2O}$。
- **1.3** THPC 结构写成 $(\mathrm{HOCH_2})_4\mathrm{PCl}$ 时未注意磷为**四配位季鏻阳离子**（$\mathrm{P^+}$ 与 $\mathrm{Cl^-}$）。
- **1.4** 歧化产物写成 $\mathrm{P_4H_2}$ 等其他磷氢化物；或配平错误（$6\mathrm{P_2H_4}$ 对应 $8\mathrm{PH_3}+\mathrm{P_4}$）。
- **1.5.1** 把 $\sigma$ 配键与 $\pi$ 反馈键的方向搞反——记住"$\mathrm{PH_3}$ 是**弱 $\sigma$ 给体、强 $\pi$ 受体**"。
- **1.6** 形式电荷标错（明确不得分）；四元环画成三元或五元。
