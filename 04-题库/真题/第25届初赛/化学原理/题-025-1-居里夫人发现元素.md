## 题目

> **来源**：第25届中国化学奥林匹克（初赛）第1题(15分) 第(1-1)小问

2011 年是国际化学年, 是居里夫人获得诺贝尔化学奖 100 周年。居里夫人发现的两种化学元素的元素符号和中文名称分别是 \_\_\_\_ 和 \_\_\_\_。

向 $\mathrm{TiOSO}_{4}$ 水溶液中加入锌粒，反应后溶液变为紫色。在清液中滴加适量的 $\mathrm{CuCl}_{2}$ 水溶液，产生白色沉淀。生成白色沉淀的离子方程式是 \_\_\_\_ 。继续滴加 $\mathrm{CuCl}_{2}$ 水溶液，白色沉淀消失，其离子方程式是 \_\_\_\_ 。

已知 $E^{\ominus}(\mathrm{FeO}_{4}^{2-}/\mathrm{Fe}^{3+})=2.20\ \mathrm{V},\ E^{\ominus}(\mathrm{FeO}_{4}^{2-}/\mathrm{Fe}(\mathrm{OH})_{3})=0.72\ \mathrm{V}$ 。

① 写出氯气和三氯化铁反应形成高铁酸根的离子方程式。

② 写出高铁酸钾在酸性水溶液中分解的离子方程式。

③ 用高铁酸钾与镁等组成碱性电池，写出该电池的电极反应。

20世纪60年代维也纳大学V. Gutmann研究小组报道，三原子分子A可由 $\mathrm{SF}_4$ 和 $\mathrm{NH}_3$ 反应合成；A被 $\mathrm{AgF_2}$ 氧化得到沸点为 $27^{\circ}\mathrm{C}$ 的三元化合物B。A和B分子中的中心原子与同种端位原子的核间距几乎相等；B分子有一根三重轴和3个镜面。画出A和B的结构式(明确示出单键和重键，不在纸面上的键用楔形键表示，非键合电子不必标出）。

画出 $\mathrm{Al}_{2}(n\text{-}\mathrm{C}_{4}\mathrm{H}_{9})_{4}\mathrm{H}_{2}$ 和 $\mathrm{Mg}[\mathrm{Al}(\mathrm{CH}_3)_4]_2$ 的结构简式。

## 参考答案

**（1）**
钋（Po）和镭（Ra）。

1898年居里夫妇先后发现了钋(Po)和镭(Ra)两种放射性元素。





## 知识点映射

- 化学史
- 钋(Po)、镭(Ra)的发现

## 解题思路

本题考查化学基本常识。需要了解重要化学史事件：居里夫人于1898年发现钋和镭两种放射性元素。

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 元素符号拼写 | Po（钋）不要写成 Pa（镤） |
| 发现顺序 | 先发现钋(Po)，后发现镭(Ra) |

**（2）**
$$
\mathrm{Ti}^{3+} + \mathrm{Cu}^{2+} + \mathrm{Cl}^{-} + \mathrm{H_2O} = \mathrm{TiO}^{2+} + 2\mathrm{H}^{+} + \mathrm{CuCl} \downarrow
$$

$$
\mathrm{CuCl} + \mathrm{Cl}^{-} = \mathrm{CuCl_2^{-}}
$$

**分析**：Zn将Ti(IV)还原为Ti(III)（紫色）。Ti(III)作为还原剂将Cu(II)还原为Cu(I)，在Cl⁻存在下生成白色CuCl沉淀。继续加入CuCl₂，Cl⁻浓度升高，通过配位效应使CuCl溶解形成CuCl₂⁻。





## 知识点映射

- Ti氧化还原
- CuCl沉淀与同离子效应
- 配位效应对溶解度的影响

## 解题思路

1. Zn还原TiO²⁺为Ti³⁺（紫色）
2. Ti³⁺还原Cu²⁺为Cu⁺，与Cl⁻生成CuCl白色沉淀
3. 过量Cl⁻通过配位效应溶解CuCl：CuCl + Cl⁻ → CuCl₂⁻

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 沉淀溶解原因 | 是配位效应而非盐效应；Cl⁻与Cu⁺配位使平衡正移 |
| CuCl₂水解干扰 | CuCl₂水解产物为蓝色沉淀，与题目白色不符，排除水解 |
| 氧化态判断 | Cu在水中可能为+1或+2，需根据产物颜色判断为Cu(I) |

**（3）**
① 碱性条件下Cl₂氧化Fe³⁺：

$$
2\mathrm{Fe}^{3+} + 3\mathrm{Cl}_2 + 16\mathrm{OH}^{-} = 2\mathrm{FeO}_4^{2-} + 6\mathrm{Cl}^{-} + 8\mathrm{H}_2\mathrm{O}
$$

> Cl₂/Cl⁻电极电势介于0.72～2.20V之间，只能在碱性条件下（Eθ=0.72V）氧化Fe³⁺。

② 酸性条件下高铁酸根氧化水：

$$
4\mathrm{FeO}_4^{2-} + 20\mathrm{H}^{+} = 4\mathrm{Fe}^{3+} + 3\mathrm{O}_2 + 10\mathrm{H}_2\mathrm{O}
$$

③ 碱性电池电极反应：

$$
\text{正极: } \mathrm{FeO}_4^{2-} + 4\mathrm{H}_2\mathrm{O} + 3\mathrm{e}^{-} = \mathrm{Fe(OH)}_3 + 5\mathrm{OH}^{-}
$$

$$
\text{负极: } \mathrm{Mg} + 2\mathrm{OH}^{-} - 2\mathrm{e}^{-} = \mathrm{Mg(OH)}_2
$$





## 知识点映射

- [[铁]]
- [[电极电势]]
- 碱性条件下氧化还原

## 解题思路

1. 高铁酸根在酸性条件下Eθ=2.20V（强氧化性），碱性条件下Eθ=0.72V（惰性）
2. Cl₂只能在碱性条件下氧化Fe³⁺→FeO₄²⁻
3. 酸性条件下FeO₄²⁻氧化H₂O生成O₂
4. 碱性电池中：FeO₄²⁻在正极被还原为Fe(OH)₃，Mg在负极被氧化为Mg(OH)₂

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 反应条件选择 | ①必须在碱性条件下，酸性条件下Cl₂无法氧化Fe³⁺到Fe(VI) |
| 电极反应配平 | 碱性条件下用OH⁻和H₂O配平，不要用H⁺ |
| 正负极电子数 | 正负极反应得失电子数不必相等（各自独立配平即可） |

**（4）**
**A = SNF**：S为中心原子，与N形成双键，与F形成单键，结构为 $\mathrm{F\text{-}S=N}$（弯曲形，VSEPR为三角形，孤对电子一对）。

**B = SNF₃**：S为中心原子，N和三个F为配位原子，$\mathrm{C_{3v}}$ 对称性（三重轴+3个镜面），S与N形成双键，S与三个F形成单键。





## 知识点映射

- [[VSEPR理论]]
- [[等电子体]]
- SF₄的反应性
- AgF₂的氟化作用

## 解题思路

1. 三原子分子A只可能是三种元素组成（两种元素无法满足题设）
2. 由反应物推断A含S、N、F三种元素 → A = SNF
3. AgF₂为氟化试剂，将A氟化为B = SNF₃
4. B有一根三重轴+3个镜面 → $\mathrm{C_{3v}}$ 对称 → S在中心，N与3个F等价
5. 用VSEPR验证：SNF₃中S有4个σ键+0孤对 → 四面体 → 满足$\mathrm{C_{3v}}$

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| A的组成推断 | 不要漏掉"三原子"限制，两种元素无法形成合适结构 |
| B的对称性 | 三重轴+3个镜面 = $\mathrm{C_{3v}}$，排除$\mathrm{C_{2v}}$等可能 |
| 中心原子判断 | S在中心而非N（N的配位数通常不超过3） |

**（5）**
**$\mathrm{Al}_{2}(n\text{-}\mathrm{C}_{4}\mathrm{H}_{9})_{4}\mathrm{H}_{2}$**：类比乙硼烷 $\mathrm{B_2H_6}$ 结构。正丁基负离子仅有一对孤对电子，类比H⁻，故该分子相当于"Al₂H₆"→ 乙硼烷型结构。两个Al通过两个H形成三中心二电子桥键，每个Al再连接两个正丁基。

**$\mathrm{Mg}[\mathrm{Al}(\mathrm{CH}_3)_4]_2$**：类比Mg[AlH₄]₂。每个[Al(CH₃)₄]⁻（类比[AlH₄]⁻）提供两个CH₃与Mg形成桥键，Mg达到四配位四面体结构。Al与Mg均为sp³杂化。





## 知识点映射

- [[等电子体]]
- Lewis结构
- 乙硼烷结构
- 桥键与三中心二电子键

## 解题思路

1. 正丁基负离子C₄H₉⁻有一对孤对电子 → 类比H⁻
2. Al₂(C₄H₉)₄H₂ → 类比Al₂H₆ → 类比B₂H₆（乙硼烷）
3. Mg[Al(CH₃)₄]₂ → 类比Mg[AlH₄]₂ → CH₃桥连Mg与Al

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 等电子体类比 | 不是简单数原子数，而是看电子对数和成键模式 |
| 桥键类型 | Al-H-Al为三中心二电子键，不是普通的两中心二电子键 |
| Mg配位数 | Mg需要达到四配位（四面体），每个[Al(CH₃)₄]提供2个CH₃ |
