## 题目

> **来源**：第25届中国化学奥林匹克（初赛）第2题(11分) 第(2-1)小问

画出 2,4-戊二酮的钠盐与 $\mathrm{Mn}^{3+}$ 形成的电中性配合物的结构式(配体用 O-O 表示)。

已知该配合物的磁矩为 4.9 玻尔磁子, 配合物中 Mn 的未成对电子数为 \_\_\_\_。

回答：该化合物有无手性？为什么？

画出 2,4-戊二酮负离子的结构简式(须明确示出其共轭部分)，写出其中离域 $\pi$ 键的表示符号。

橙黄色固体配合物A的名称是三氯化六氨合钴（Ⅲ），是将二氯化钴、浓氨水、氯化铵和过氧化氢混合，以活性炭为催化剂合成的。机理研究发现，反应过程中首先得到 $\mathrm{Co(NH_{3})_{6}^{2+}}$ 离子；随后发生配体取代反应，得到以新配体为桥键的双核离子 $B^{4+}$；接着发生桥键断裂，同时两个中心原子分别将一个电子传递到均裂后的新配体上，得到两个 $C^{2+}$ 离子；最后 $C^{2+}$ 离子在活性炭表面上发生配体取代反应，并与氯离子结合形成固体配合物A。写出合成配合物A的总反应方程式；画出 $B^{4+}$ 和 $C^{2+}$ 离子的结构式。

## 参考答案

**（1）**
Mn(acac)₃为八面体结构，Mn(III)在中心，三个双齿配体acac⁻以O,O'方式配位。$\mathrm{M(AA)_3}$ 型配合物不存在几何异构体，仅存在一对旋光异构体（Δ和Λ构型）。





## 知识点映射

- [[八面体配合物]]
- [[旋光异构]]
- M(AA)₃型配合物

## 解题思路

1. 2,4-戊二酮钠盐 = Na(acac)，acac⁻为双齿配体
2. Mn³⁺与3个acac⁻形成电中性配合物Mn(acac)₃
3. M(AA)₃型：三个双齿配体→八面体→仅旋光异构（Δ/Λ）

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 几何异构体 | M(AA)₃型无几何异构体，只有旋光异构 |
| 配体表示 | 题目要求用O-O表示配体，不需要画出完整结构 |

**（2）**
根据磁矩简易计算公式 $\mu = \sqrt{n(n+2)}\mu_{\mathrm{B}}$：

$$4.9 = \sqrt{n(n+2)}$$

解得 $n = 4$（未成对电子数为4）。





## 知识点映射

- 磁矩公式
- 未成对电子数

## 解题思路

1. 使用公式 $\mu = \sqrt{n(n+2)}\mu_{\mathrm{B}}$
2. 代入 $\mu = 4.9$：$4.9^2 = n(n+2)$ → $24.01 = n^2 + 2n$
3. 解方程得 $n = 4$

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 公式记忆 | 注意是 $\sqrt{n(n+2)}$ 而非 $\sqrt{n(n-2)}$ |
| 单位 | 玻尔磁子 $\mu_B$ 为单位，结果不需额外标注 |

**（3）**
该配合物**有手性**。

**理由**：Mn(acac)₃不存在对称面和对称中心（第二类对称元素），只有旋转轴（C₃轴），因此具有手性。

**判据**：若分子存在对称面或对称中心，则一定没有手性；反之，若不存在第二类对称元素，则具有手性。





## 知识点映射

- 手性判据
- 对称面·对称中心
- 旋光异构

## 解题思路

1. 手性判据：检查是否存在对称面(σ)或对称中心(i)
2. M(AA)₃型配合物只有旋转轴，无σ和i
3. 简便方法：在纸上画出分子的镜面对称体，与原分子对比

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 手性≠旋光 | 手性是结构特征，旋光是物理性质；有手性一定有旋光性 |
| 判据选择 | 简单分子用对称面/对称中心判据即可，不需检查所有对称元素 |

**（4）**
2,4-戊二酮负离子（acac⁻）中，三个碳原子和两个氧原子均为sp²杂化，各提供一个垂直于分子平面的p轨道，加上负电荷的电子，共6个电子参与离域。

离域π键表示符号：$\pi_5^6$（5个原子，6个电子）





## 知识点映射

- [[离域π键]]
- sp²杂化
- 共轭体系

## 解题思路

1. 找出所有非sp³杂化的原子：3个C + 2个O = 5个原子
2. 每个原子提供1个p轨道和若干电子
3. 总电子数：3×1(C) + 2×1(O) + 1(负电荷) = 6
4. 表示为 $\pi_5^6$

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 电子计数 | 别忘了负电荷贡献的1个电子 |
| 杂化判断 | 参与离域的原子必须是sp²杂化（有垂直p轨道） |
| 符号格式 | $\pi_n^m$，n为原子数，m为电子数 |

**（5）**
**总反应方程式**：

$$
2\mathrm{CoCl_2} + 10\mathrm{NH_3} + 2\mathrm{NH_4Cl} + \mathrm{H_2O_2} = 2\mathrm{Co(NH_3)_6Cl_3} + 2\mathrm{H_2O}
$$

**B⁴⁺结构**：两个Co(II)通过H₂O₂的过氧键(-O-O-)桥连，每个Co仍保留5个NH₃配体。

**C²⁺结构**：过氧键均裂后，每个Co被氧化为Co(III)，配位一个OH⁻和5个NH₃。





## 知识点映射

- Co配位化学
- 过氧键均裂
- 活性炭催化
- 配体取代反应

## 解题思路

1. Co(II)氨配离子 → H₂O₂桥连双核B⁴⁺ → 过氧键均裂 → Co(III)的C²⁺
2. H₂O₂作为配体取代2个NH₃ → 桥键连接两个Co
3. 过氧键均裂：O-O断裂，每个O获得1个电子→OH⁻
4. Co(II)→Co(III)：每个Co失去1个电子给O
5. 最后NH₃取代OH⁻ → [Co(NH₃)₆]³⁺

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| B⁴⁺电荷 | 两个Co(II)=+4，H₂O₂中性，电荷守恒 |
| 均裂vs异裂 | 过氧键是均裂（对称断裂），不是异裂 |
| 活性炭作用 | 催化最后一步配体取代，无活性炭产物不同 |
