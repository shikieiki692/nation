## 题目

> **来源**：第25届中国化学奥林匹克（初赛）第8题(10分) 第(8-1)小问

维生素 A 分子的不饱和度为 \_\_\_\_。

芳香化合物 C 是 β-紫罗兰酮的同分异构体，C 经催化氢解生成芳香化合物 D, D 的 ¹H NMR 图谱中只有一个单峰。画出 C 的结构简式。

画出中间体 B 的结构简式。

以上由 β-紫罗兰酮合成中间体 B 的过程中，(2)、(3)、(4)、(6) 反应分别属于什么反应类型（反应类型表述须具体，例如取代反应必须指明是亲电取代、亲核取代还是自由基取代）。

## 参考答案

**（1）**
**6**。

维生素A（C₂₀H₃₀O）的不饱和度计算：

$$
\text{不饱和度} = \text{碳数} + 1 - \frac{\text{氢数}}{2} = 20 + 1 - \frac{30}{2} = 6
$$

（氧原子在计算时不计入）





## 知识点映射

- 不饱和度公式

## 解题思路

1. 不饱和度 = C + 1 - H/2（忽略O）
2. 卤素当H算，N要减去
3. 或计数法：双键+1，叁键+2，环+1

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| O的处理 | 含氧有机物计算不饱和度时忽略O |
| 公式选择 | 卤素当H，N要减去，O忽略 |

**（2）**
**D = 六甲苯**（C₆(CH₃)₆）：苯环上每个碳都有甲基取代，且全部相同 → NMR只有一个单峰。

**C = 甲基苄基醚的衍生物**：C比D多1个碳，催化氢解（H₂断裂C-O键）得到D。C含有苯环和-OCH₃基团。

> 关键：催化氢解中H₂不仅能加成，还能与-O-发生自由基取代反应。





## 知识点映射

- [[同分异构]]
- 催化氢解
- NMR分析

## 解题思路

1. D只有一个NMR单峰 → 所有H等价 → D = 六甲苯
2. D催化氢解得到 → C含苯环+1个额外碳
3. C催化氢解→D → C含可被H₂断裂的键（如C-O）
4. 克服思维定式：H₂不仅是加成试剂，也是自由基取代试剂

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| H₂的多重角色 | H₂可以加成也可以自由基取代（断裂C-O等） |
| 六甲苯推断 | NMR单峰+芳香化合物+碳数限制→六甲苯 |
| 碳数守恒 | C比D只少1个碳，说明氢解只断裂了一个键 |

**（3）**
B是由前一步烯醇经过互变异构得到的酮式产物。含有α-H的羰基可以发生烯醇互变，在大多数情况下酮式比烯醇式更稳定。

烯醇羟基碳的α位得到一个氢，羟基失去氢并与碳形成双键 → 得到酮式结构B。





## 知识点映射

- [[烯醇互变]]
- 酮式-烯醇式平衡

## 解题思路

1. 前一步产物为烯醇式（含有C=C-OH）
2. 烯醇互变：α-H转移→形成C=O
3. 酮式通常比烯醇式稳定

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 互变方向 | 题目明确说"B由烯醇互变得到"→酮式 |
| α-H位置 | 必须是羰基α位的H才能参与互变 |

**（4）**
| 步骤 | 反应类型 | 说明 |
|:---:|:---|:---|
| (2) | 亲核加成反应 | 乙酸甲酯负离子与羰基的加成 |
| (3) | 分子内亲核取代反应 | 氧负离子进攻分子内α位的Cl |
| (4) | 水解反应 | 酯基在碱性条件下转变为羧酸钠 |
| (6) | 脱羧反应 | 羧基脱去CO₂ |





## 知识点映射

- [[亲核加成]]
- [[亲核取代]]
- 脱羧反应
- 酯水解

## 解题思路

1. (2) 碳负离子进攻羰基→亲核加成
2. (3) O⁻进攻α-C上的Cl→分子内SN2
3. (4) 酯的碱性水解→皂化反应
4. (6) -COOH→-H + CO₂↑→脱羧

## 易错分析

| 易错点 | 说明 |
|:---|:---|
| 具体性要求 | 必须写"亲核"取代，不能只写"取代" |
| (3)是分子内 | 分子内反应比分子间更快（熵效应） |
| (4)不是消除 | 碱性条件下酯→羧酸盐是水解 |
