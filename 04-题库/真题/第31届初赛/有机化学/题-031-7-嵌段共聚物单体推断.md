## 题目

> **小问关联**：本文件为第(7-1)小问；其余小问见 [[题-031-7-嵌段共聚物单体推断]]、[[题-031-7-嵌段共聚物单体推断]]

嵌段共聚物指由不同聚合物链段连接而成的聚合物。若其同时拥有亲水链段和疏水链段，会形成内部为疏水链段、外部为亲水链段的核-壳组装体（如胶束）。下图所示为一种 ABA 型嵌段共聚物，该嵌段共聚物在水中可以形成胶束并包载药物分子，在氧化或还原的条件刺激下，实现药物的可控释放。

![[mineru/02-真题解析/31届初赛试题解析_images/c92cdb7c3cdd3acedc3a4f800a318213c2a54fc74145c454ce3b665a6a037d55.jpg]]
ABA型三嵌段共聚物

7-1 该共聚物的合成方法如下：先使单体 X 与稍过量单体 Y 在无水溶剂中进行加成聚合反应，形成中部的聚氨酯链段，随后加入过量乙二醇单甲醚 $\mathrm{CH}_{3}(\mathrm{OCH}_{2}\mathrm{CH}_{2})_{n}\mathrm{OH}$ 进行封端。写出单体 X 与 Y 的结构式。

7-2 在氧化还原条件下二硫键可发生断裂，采用 R-S-S-R 简式，写出其断键后的氧化产物 O 和还原产物 R。

7-3 该嵌段共聚物所形成的胶束可以包载下图中哪种抗癌药物？简述理由。

![[mineru/02-真题解析/31届初赛试题解析_images/31504fb559e7683f0b1f0fa2fa42e29f335615fa0f9558bfb97600952b35e6e0.jpg]]

## 参考答案

**（1）**
7-1 观察图中共聚物的结构：两端为聚乙二醇单甲醚，中间为聚氨酯。将聚氨酯从 C-O 处切断，得到两个合成子醇负离子和酰基正离子（稍过量），醇负离子可以倒推为二醇 X。乍一看，酰基正离子可以倒推为酸 $ArNHCO_{2}H$ 或者酰氯 ArNHCOCl，也符合我们平时对于羧酸酯键的合成方法。但由于题目中要求的聚合方式为"加成聚合"，而醇与羧酸或酰氯的反应属于"缩合聚合"（因为会生成小分子 $H_{2}O$ 或 HCl），故应另寻他法。结合基本的有机知识，能与醇发生加成聚合的官能团仅为异氰酸酯，故另一个单体 Y 如下图所示。请同学们自己写出正向反应的方程式。

正向的反应过程为醇对异氰酸酯的亲核加成与互变异构。

![[mineru/02-真题解析/31届初赛试题解析_images/b98862e702e0bde713a200f273d367338261e4ce01279ec4c9002301d8c60fd3.jpg]]




- X：二醇（具体结构取决于聚氨酯链段中的二醇单元）
- Y：异氰酸酯 $ArN=C=O$





本题考查高分子合成中单体的推断。关键思路：
1. 共聚物中间为聚氨酯链段
2. 聚氨酯由二醇与异氰酸酯加成聚合得到
3. 题目要求"加成聚合"，排除了缩合聚合（酯化、酰氯化）
4. 能与醇加成聚合的官能团只有异氰酸酯
5. X为二醇，Y为异氰酸酯

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 聚氨酯合成 | 二醇与异氰酸酯的加成聚合 |
| 加成聚合 vs 缩合聚合 | 加成聚合无小分子生成 |
| 异氰酸酯化学 | 异氰酸酯与醇的亲核加成 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| Y推断为羧酸或酰氯 | 这些属于缩合聚合，会生成小分子 |
| 忽略"加成聚合"条件 | 题目明确要求加成聚合 |
| 切断位置错误 | 应从C-O处切断聚氨酯链段 |

**（2）**
7-2 二硫键是一个活泼的化学键，其中硫的氧化数为 -1，发生氧化还原反应时伴随着 S-S 键的断裂，氧化产物为磺酸 R-SO₃H，还原产物为硫醇 R-SH。

写出二硫键 R-S-S-R 被 $H_{2}O_{2}$ 氧化与被 $H_{2}$ 还原的配平的反应方程式。




- 氧化产物 O：R-SO₃H（磺酸）
- 还原产物 R：R-SH（硫醇）





本题考查二硫键的氧化还原反应。关键要点：
1. 二硫键中S的氧化数为-1
2. 氧化时S-S键断裂，S被氧化为+6，生成磺酸
3. 还原时S-S键断裂，S被还原为-2，生成硫醇

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 二硫键氧化 | S(-1)被氧化为S(+6)，生成磺酸 |
| 二硫键还原 | S(-1)被还原为S(-2)，生成硫醇 |
| 氧化数变化 | 氧化：-1→+6；还原：-1→-2 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 氧化产物写成亚磺酸 | 完全氧化产物为磺酸R-SO₃H |
| 还原产物写成硫化物 | 还原产物为硫醇R-SH |
| 忽略S-S键断裂 | 氧化还原伴随S-S键断裂 |

**（3）**
7-3题目中已经提示共聚物内部是疏水段，因此药物若想被包裹(疏水相互作用),也需要有疏水性。题图中右边的盐酸阿霉素是亲水的铵盐，而左边的紫杉醇是含有大量芳基的疏水化合物。故答案是紫杉醇。





本题考查胶束包载药物的原理。关键思路：
1. 胶束内部为疏水链段
2. 药物通过疏水相互作用被包载在胶束内部
3. 因此药物需要具有疏水性
4. 紫杉醇含大量芳基，疏水性强
5. 盐酸阿霉素为铵盐，亲水性强

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 胶束结构 | 内部疏水，外部亲水 |
| 疏水相互作用 | 疏水药物被包载在胶束内部 |
| 药物性质 | 紫杉醇疏水，阿霉素亲水 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 选择阿霉素 | 阿霉素为铵盐，亲水，不能被疏水胶束包载 |
| 理由不充分 | 需说明紫杉醇的疏水性和阿霉素的亲水性 |
