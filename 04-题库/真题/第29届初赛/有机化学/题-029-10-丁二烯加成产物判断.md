## 题目

> **来源**：[[07-资料提炼/提炼-第29届初赛试题解析|第29届初赛第10题]]（原始文件：[[mineru/02-真题解析/29届初赛试题解析]]）

当溴与 1,3-丁二烯在环己烷溶液中发生加成反应时，会得到两个产物 A 和 B（不考虑立体化学）。在 $-15^{\circ}C$ 时 A 和 B 的比例为 62:38；而在 $25^{\circ}C$ 时 A 和 B 的比例为 12:88。

画出化合物 A 和 B 的结构简式；并确定哪个为热力学稳定产物，哪个为动力学产物。

在室温下，A 可以缓慢地转化为 B。画出此转换过程的反应势能示意图和中间体的结构简式。

根据以上的研究结果，确定以下反应的产物：

## 参考答案

**（1）**
A 为 **1,2-加成产物**（动力学产物），B 为 **1,4-加成产物**（热力学稳定产物）。





溴与 1,3-丁二烯在环己烷溶液中发生加成反应时，会得到两个产物：1,2-加成产物和 1,4-加成产物。其反应机理如下：

![[mineru/02-真题解析/29届初赛试题解析_images/b3ddf18ba5d84068cc550a7d003da2e4ec37de3a49ce002d1f9c07af6d6cdc52.jpg]]

1,4-加成产物更加稳定，但是反应的活化能较 1,2-加成产物更高。在这个反应中，1,2-加成产物是动力学产物，而 1,4-加成产物是热力学稳定产物。在较低温度时，反应的活化能不容易克服，动力学产物比例相对较高；而高温时，活化能容易克服，更易生成热力学稳定产物。因此 A 是动力学产物，为 1,2-加成产物；B 是热力学稳定产物，为 1,4-加成产物。同时，从 10-2 的 "A 可以缓慢地转化为 B" 也可以看出 A 是动力学产物，B 是热力学稳定产物。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 1,2-加成 | Br₂加成在相邻的两个碳上，生成动力学产物 |
| 1,4-加成 | Br₂加成在1,4位，生成更稳定的热力学产物 |
| 动力学控制 | 低温有利于动力学产物（活化能低） |
| 热力学控制 | 高温有利于热力学产物（产物更稳定） |
| 烯丙基正离子 | 加成反应的中间体为烯丙基正离子 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| A和B对应关系错误 | 低温比例高的A是动力学产物（1,2-加成），高温比例高的B是热力学产物（1,4-加成） |
| 忽略温度影响 | 温度是判断动力学/热力学产物的关键 |
| 混淆产物稳定性 | 1,4-加成产物更稳定（共轭体系），但活化能更高 |
| 未考虑烯丙基正离子 | 中间体为烯丙基正离子，可发生1,2或1,4加成 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 势能高低画反 | A（动力学产物）势能高于B（热力学产物） |
| 中间体能量位置错误 | 中间体能量应高于A和B |
| 活化能大小错误 | A→中间体的活化能应低于中间体→B |
| 忽略中间体结构 | 中间体为烯丙基正离子，需画出其结构 |

**（3）**
在不考虑手性的情况下，该反应的产物只有 3 个：

![[mineru/02-真题解析/29届初赛试题解析_images/2d92b2d2a707633d2eeca28059e6024847e29b2c98d87e7865cb751bdd67a76b.jpg]]





不对称的 1,3-二烯和氯化氢的加成反应要稍微复杂一点，但是其原理并没有改变，只需在原有的基础上多考虑一个马氏规则（本质是正离子的稳定性）即可。其反应历程如下图所示：

![[mineru/02-真题解析/29届初赛试题解析_images/5552f15e72d485466dd700e7f54726d326052c59fccee8ed67550d91d9c2a088.jpg]]

从结果可以看出，产物 2 和 3 是 1,2-加成产物，产物 1 和 4 是 1,4-加成产物。这里我们还要注意到产物 1 和产物 2 是同一个化合物，因此在不考虑手性的情况下该反应的产物只有 3 个。

除此之外，甲基取代对反应结果也会产生一定的影响。甲基有给电子能力，这导致有甲基取代的双键的电子云密度更高，和 $\mathrm{H}^{+}$ 结合更快，因此中间体 b 的比例会略高于 a。有些同学提出：a 是次要中间体，那么化合物 1 和 2 应该和反马氏规则的产物一样被忽略。在这里需要注意：并不是所有的次要产物都应该被忽略，这要视该次要产物的含量甚至是重要性而定。本题中，我们可以通过已学的知识来简单判断一下：马氏产物中间体是一个烯丙基正离子，我们知道烯丙基正离子的稳定性远大于普通碳正离子，所以产物几乎都是马氏产物，或者说几乎没有反马氏产物；甲基是一个给电子基团，但只是一个比较弱的给电子基团，它并不能显著提高双键的电子云密度，因此 a 的比例低于 b，但也仅仅是略低于 b，产物 1 和 2 自然也就不能忽略。

## 知识点映射

| 知识点 | 说明 |
|:---|:---|
| 马氏规则 | H⁺优先加成到电子云密度更高的双键碳上 |
| 1,2-加成 | 动力学产物，H和Cl加成在相邻碳上 |
| 1,4-加成 | 热力学产物，H和Cl加成在1,4位 |
| 烯丙基正离子 | 加成反应的中间体，可发生1,2或1,4加成 |
| 区域选择性 | 甲基的给电子效应影响加成位置的选择性 |

## 易错分析

| 常见错误 | 正确思路 |
|:---|:---|
| 忽略产物1和2是同一化合物 | 1和2是同一化合物，产物总数为3个 |
| 忽略次要产物 | 次要产物a的比例虽低，但不能完全忽略 |
| 混淆马氏和反马氏产物 | 甲基是弱给电子基，主要产物仍为马氏产物 |
| 未考虑1,4-加成 | 除1,2-加成外，还需考虑1,4-加成产物 |
| 立体化学考虑过多 | 题目要求不考虑立体化学 |
