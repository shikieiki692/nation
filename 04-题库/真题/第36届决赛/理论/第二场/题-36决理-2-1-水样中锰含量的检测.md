# 第 1 题 水样中锰含量的检测 (6 分)

⽔源洁净事关⼈⺠的⽣命健康。重⾦属离⼦、微⽣物含量等多种指标是⽔质考察的重点，锰含量就是其中⼀项。我国⽣活饮⽤⽔卫⽣标准规定锰含量不得超过0.1 mg L−1。锰含量常⽤分光光度法检测，实验过程如下：向⽔样中加⼊甲醛肟溶液，再加⼊适量氢氧化钠，放置20分钟，若⽔样中含锰（通常为 $\mathrm { M n ^ { 2 + } }$ ，其配合物⼏乎⽆⾊），会产⽣棕⾊配合物（锰离⼦与甲醛肟配⽐为1:6），测量其吸光度。

1-1 甲醛肟(CH2NOH)可以由盐酸羟胺与甲醛按1:1在⽔溶液中制得，写出反应⽅程式。  
1-2 写出棕⾊配合物形成的化学反应⽅程式。  
1-3 利⽤此⽅法测定浓度为 $8 . 0 0 { \times } 1 0 ^ { - 5 } \mathrm { m o l { \cdot } L ^ { - 1 } }$ 的标液，⽐⾊⽫宽1 cm，吸光度为0.880。从⽔源地取样，将1 L⽔样浓缩⾄10 mL，若采⽤⽰差分光光度法，以 $1 . 6 0 \times 1 0 ^ { - 4 } \mathrm { m o l } \mathrm { L } ^ { - 1 }$ 锰标液作参⽐，测得样品的吸光度为0.200，计算⽔样中锰的含量，判断此⽔样是否合格。

## 参考答案

水源洁净事关人民的生命健康。重金属离子、微生物含量等多种指标是水质考察的重点，锰含量就是其中一项。我国生活饮用水卫生标准规定锰含量不得超过 $0 . 1 \mathrm { ~ m g ~ L ^ { - 1 } }$ 。锰含量常用分光光度法检测，实验过程如下：向水样中加入甲醛肟溶液，再加入适量氢氧化钠，放置 20 分钟，若水样中含锰(通常为$\mathrm { M n } ^ { 2 + }$ ，其配合物几乎无色)，会产生棕色配合物(锰离子与甲醛肟配比为 1:6），测量其吸光度。

1-1 甲醛肟 $\mathsf { \Gamma } ( { \mathrm { C H } } _ { 2 } { \mathrm { N O H } } )$ 可以由盐酸羟胺与甲醛按 1:1在水溶液中制得，写出反应方程式。  
1-2 写出棕色配合物形成的化学反应方程式。  
1-3 利用此方法测定浓度为 $8 . 0 0 { \times } 1 0 ^ { - 5 } \mathrm { m o l \ L } ^ { - 1 }$ 的锰标液，比色皿宽 1 cm，吸光度为 0.880。从水源地取样，将 1 L 水样浓缩至 10 mL，若采用示差分光光度法，以 $1 . 6 0 { \times } 1 0 ^ { - 4 } ~ \mathrm { m o l ~ L } ^ { - 1 }$ 锰标液作参比，测得样品的吸光度为 0.200，计算水样中锰的含量，判断此水样是否合格。

## 考点抽象

> 这道题的表面是"饮用水锰含量检测"，本质是**"显色反应书写＋朗伯-比尔定标＋示差法扩量程"的光度分析三段式**——甲醛肟配方程式、Mn(Ⅱ) 碱性显色配位、示差参比把高浓度读回线性区间，最后与 0.1 mg/L 国标对判。

---

## 知识点映射

- **直接 KP**：[[分光光度法]]、[[配合物]]、[[配位化学]]
- **间接 KP**：Lambert-Beer 定律（A=εbc）、示差法原理（ΔA=εbΔc）、缩合/肟化反应
- **跨学科连接**：甲醛肟光度法是水质锰检测的标准方法——示差分光光度法是"把 A>1 的浓样品拉回可测区"的通用工程手段。

---

## 解题思路

1. **1-1 按"羟胺与醛缩合脱水"写**：HCHO+NH₂OH·HCl→CH₂NOH+HCl+H₂O——肟化是 C=N 形成＋脱一分子水，HCl 是羟胺的盐形式带来的副产物。
2. **1-2 显色要"氧化＋配位"双步**：碱性条件下 O₂ 把部分 Mn(Ⅱ) 氧化、与 6 分子甲醛肟脱质子配位成 [Mn(CH₂NO)₆]²⁻ 棕色配合物——2Mn²⁺+O₂+8OH⁻+12CH₂NOH→2[Mn(CH₂NO)₆]²⁻+10H₂O，电子/电荷双守恒核对。
3. **1-3 先标定 ε 再用示差反推**：标液 A=0.880 定 ε=1.10×10⁴ L·mol⁻¹·cm⁻¹；示差读数 ΔA=εb(c_x−c_s) → Δc=1.82×10⁻⁵ → c_x=1.78×10⁻⁴ mol/L。
4. **浓缩倍数回乘**：1 L→10 mL 浓缩 100 倍 → 原水样 9.77×10⁻² mg/L<0.1 mg/L → 合格——每一步单位换算（mol/L→mg/L×54.94）都要落笔。
5. **示差法的选择逻辑**：普通法对 c≈1.8×10⁻⁴ mol/L 样品 A≈2 超出线性区，用 c_s=1.6×10⁻⁴ 作参比"重设零点"——读数小、精度高，这是本题用示差的理由。

## 变式拓展

- 若标液吸光度也超过 1.0，ε 的标定要怎么设计（缩短比色皿/稀释）？误差如何传递到最终结果？
- 1-2 若无 O₂ 参与反应，配合物还能生成吗——从 Mn 的价态与配合物电荷（2−）反推氧化必要性。
- 本题与 36 决 1-4 尿碘的"光度信号"同族——对比"平衡信号（A∝c）"与"动力学信号（斜率∝c）"两种读出的适用浓度区间。

---

## 易错分析

- 常见错误 1：1-1 漏 HCl 或 H₂O——羟胺盐酸盐的 Cl 去向与脱水数目都是方程式给分点。
- 常见错误 2：1-2 配位数写错（题给 1:6）或漏 O₂/OH⁻ 的氧化计量——棕色配合物电荷 2− 是配平的硬约束。
- 常见错误 3：1-3 忘了"示差"的 Δc 要加回 c_s（得到 c_x），或漏浓缩 100 倍回乘——两处都会差两个量级。
- 常见错误 4：有效数字不符（本题要求 3 位，9.8×10⁻² 亦可）或忘记与 0.1 mg/L 国标比较下"合格"结论。
