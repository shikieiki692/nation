# 第 6 题 金属M及其变化 (9 分)

6-1 ⾦属M的硝酸盐与1,3,5-均苯三甲酸（简写为 $\mathrm { H _ { 3 } B T C }$ ，分⼦量为210.14）按特定⽐例在⼄⼆醇和⽔的混合体系中于 $1 8 0 ~ ^ { \circ } \mathrm { C }$ 下反应 12 ⼩时，得到⼀种具有“孔笼—孔道”结构的⾦属有机⻣架材料 Y，密度 $\dot { } \rho _ { } = 0 . 9 6 \mathrm { g }$ $\mathrm { c m } ^ { - 3 } .$ 。单晶 X 射线衍射分析表明，Y 属于⽴⽅晶系，其三维⻣架结构主体由 M 和 $\mathrm { ( B T C ) ^ { 3 } }$ −组成，呈电中性，结构中带有⽔分⼦。元素分析表明，Y中含M，C，O和H四种元素，且M与C的原⼦⽐为1:6。热重-质谱联合分析结果显⽰，样品在 $1 0 0 { \sim } 2 0 0 \ ^ { \circ } \mathrm { C }$ 区间失重8.21%，对应于化学式中3个⽔分⼦的脱除，⽽主体⻣架结构依然保持；继续加热到 $3 5 0 ~ ^ { \circ } \mathrm { C }$ 失重63.7%，之后⽆明显失重，残渣为⾦属氧化物 $\mathbf { M O } _ { \circ }$ 。通过计算确认M是何种⾦属，写出Y的化学式。  
6-2 将⾦属M加⼊到⾜量的浓硫酸中，微热⽚刻即有⿊⾊物质A⽣成，之后A逐渐转变为灰⽩⾊物质B。该灰⽩⾊物质⽤过量氨⽔充分处理，过滤后，向滤液中通⼊ $\mathrm { S O _ { 2 } }$ ⾄微酸性，⽣成⽩⾊沉淀C（反应1）。元素分析结果，N 含量 8.65 %，S 含量 19.6%，H 含量 2.49 %。测试分析发现，C 的结构中负离⼦呈三⻆锥形，磁性测量显⽰抗磁性。C与⾜量 $\mathrm { H _ { 2 } S O _ { 4 } }$ 混合并加热，可⽣成超细粉末态M（反应2）。  
6-2-1 写出A，B，C的化学式。  
6-2-2 写出反应1和反应2的⽅程式。

## 参考答案

6-1 金属 M 的硝酸盐与 1,3,5-均苯三甲酸（简写为 $\mathrm{H_3BTC}$）按特定比例在乙二醇和水的混合体系中于 $180\ ^\circ\mathrm{C}$ 下反应 12 小时，得到一种具有“孔笼—孔道”结构的金属有机骨架材料 Y，密度 $\rho = 0.96\ \mathrm{g\ cm^{-3}}$。单晶 X 射线衍射分析表明，Y 属于立方晶系，其三维骨架结构主体由 M 和 $\mathrm{(BTC)^{3-}}$ 组成，呈电中性，结构中带有水分子。元素分析表明，Y 中含 M、C、O 和 H 四种元素，且 M 与 C 的原子比为 1:6。热重-质谱联合分析结果显示，样品在 100~200 °C 区间失重 8.21%，对应于化学式中 3 个水分子的脱除，而主体骨架结构依然保持；继续加热到 350 °C 失重 63.7%，之后无明显失重，残渣为金属氧化物 MO。通过计算确认 M 是何种金属，写出 Y 的化学式。
6-2 将金属M加入到足量的浓硫酸中，微热片刻即有黑色物质A生成，之后A逐渐转变为灰白色物质B。该灰白色物质用过量氨水充分处理，过滤后，向滤液中通入 $\mathrm { S O } _ { 2 }$ 至微酸性，生成白色沉淀 C（反应 1）。元素分析结果，N含量 8.65 %，S含量 19.6 %, H含量 2.49 %。测试分析发现，C的结构中负离子呈三角锥形，磁性测量显示抗磁性。C与足量 $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ 混合并加热，可生成超细粉末态 M（反应 2）。

6-2-1 写出 A, B, C 的化学式。

## 考点抽象

> 这道题的表面是"金属 M 的两条身份线索"，本质是**热重-元素分析联算（MOF 化学式）＋硫化物-亚硫酸盐定性链（Cu 的特征反应）双轨破案**——M=Cu，Y 就是著名 MOF 材料 HKUST-1（Cu₃(BTC)₂·3H₂O）。

---

## 知识点映射

- **直接 KP**：[[MOF材料]]、[[铜]]、[[氧化态]]
- **间接 KP**：[[配位化学]]、热重分析（TG）与失重归属、元素分析定组成、铜的歧化/反歧化（Cu⁺ 稳定化）
- **跨学科连接**：HKUST-1 是气体吸附与催化的基准 MOF；Cu(NH₄)SO₃（Cu⁺ 歧化平衡）与"黑色 CuO→灰白 CuSO₄"是铜化学的经典定性链。

---

## 解题思路

1. **热重两段各自锁定一个量**：失重 8.21%=3H₂O → Y 式量 M=3×18.0/8.21%=657.7；残渣 MO 的总占比 36.3% → n(A+16)/657.7=0.363 → A=238.7/n−16。
2. **n 试探法定金属**：n=1~5 逐一代入，n=3 得 A=63.6 与 Cu（63.55）吻合，且与后段"浓硫酸/氨水/SO₂"的铜化学链互证——单靠一组数据不定论，两条线索交叉验证。
3. **Y 的化学式组装**：M:C=1:6 且骨架电中性 → Cu₃(BTC)₂·3H₂O（3×Cu²⁺ 对 2×BTC³⁻），密度 0.96 g/cm³ 可再核晶胞。
4. **6-2 按"现象→价态"走定性链**：Cu＋浓硫酸微热先出黑色 CuO（A）后被过量酸转成灰白 CuSO₄（B）；B 溶于氨水成 Cu(NH₃)₄²⁺，SO₂ 通至微酸性把 Cu(II) 还原并沉淀出 Cu(NH₄)SO₃（C，白色、抗磁性→Cu⁺ d¹⁰、SO₃²⁻ 三角锥）——每个现象都对应一次价态变化。
5. **反应 2 是歧化的逆写**：CuNH₄SO₃＋H₂SO₄ 加热 → Cu（超细粉末）＋CuSO₄＋SO₂——Cu⁺ 在酸性下歧化，2Cu⁺→Cu²⁺+Cu⁰，与反应 1 恰好互逆（条件驱动方向）。

---

## 变式拓展

- 若把 H₃BTC 换成对苯二甲酸（H₂BDC），n(MO) 与失重百分比的关系如何变——MOF 化学式与残渣计量的通用联立式。
- 反应 1 中 SO₂ 的量为何是 3 mol（对 2 mol Cu）——用"还原 Cu(II)＋把 SO₂ 氧化到 S(IV)?"的电子账本重推一遍。
- 本题"残渣 MO 反推金属"与 35 决理-1-1"晶胞密度推 BGO 组成"同构——总结"由热重/密度反推组成"的两类联立。

---

## 易错分析

- 常见错误 1：n 试探只试 n=1、2 就下结论或漏掉"与后段反应互证"——Rh(103.4) 恰好接近 n=2 但与 6-2 的铜化学矛盾，题面明示此路不通。
- 常见错误 2：Y 的化学式写成 Cu₃(BTC)₂（漏 3H₂O）或 Cu(BTC)——失重 8.21% 与 3 个水的对应是硬约束。
- 常见错误 3：6-2-1 的 A 写成 Cu₂S/CuS 虽被认可，但 B 必须是 CuSO₄（灰白色）而非 Cu₂S——把"灰白"当 Cu₂S 黑色会连坐 C 的判断。
- 常见错误 4：反应 1/2 方程漏 (NH₄)₂SO₄ 副产物或 CuNH₄SO₃ 的沉淀符号——官方对离子式写法（HSO₄⁻）有明确的宽容与不宽容边界。
