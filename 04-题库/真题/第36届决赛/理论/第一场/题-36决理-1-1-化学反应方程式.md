# 第 1 题 化学反应方程式 (10 分)

1-1 常温下，等物质的量的[ $\mathrm { H N } ( \mathrm { C H } _ { 3 } ) _ { 3 } ] \mathrm { C l }$ 与 $\mathrm { L i B H _ { 4 } }$ 在四氢呋喃中反应。  
1-2 将氨⽓通⼊ $\mathrm { S _ { 2 } C l _ { 2 } }$ 中得到⼀种淡⻩⾊固体 $\mathrm { S 4 N _ { 4 } }$ 和⼀种具有环状分⼦结构的单质。  
1-3 六羰基钼与醋酸在氮⽓流中加热反应得到⼀种⻩⾊针状晶体和两种还原性⽓体，其中⻩⾊针状晶体是合成其它 ${ \mathrm { M o } } { - } { \mathrm { M o } }$ 化合物的优良起始物。  
1-4 单质硒与热的硝酸银溶液反应⽣成⿊⾊沉淀，且反应后溶液显强酸性。  
1-5 橙⻩⾊固体 $\mathrm { X e [ P t F _ { 6 } ] }$ 遇⽔迅速反应，有⽓体放出。

---

## 参考答案

1-1 常温下，等物质的量的 $\mathrm{[HN(CH_3)_3]Cl}$ 与 $\mathrm{LiBH_4}$ 在四氢呋喃中反应。  
1-2 将氨气通入 $S_{2}Cl_{2}$ 中得到一种淡黄色固体 $S_{4}N_{4}$ 和一种具有环状分子结构的单质。  
1-3 六羰基钼与醋酸在氮气流中加热反应得到一种黄色针状晶体和两种还原性气体，其中黄色针状晶体是合成其它 Mo-Mo 化合物的优良起始物。  
1-4 单质硒与热的硝酸银溶液反应生成黑色沉淀，且反应后溶液显强酸性。  
1-5 橙黄色固体 $Xe[PtF_{6}]$ 遇水迅速反应，有气体放出。

```txt
说明：1）每个正确的方程式 2 分
2）反应物、产物正确，但未配平 扣 1 分
3）无需写沉淀、气体符号，“→”或“=”均可
```

1-1 $\mathrm{[HN(CH_3)_3]Cl + LiBH_4 = H_2 + H_3BN(CH_3)_3 + LiCl}$ 1-2 $6\mathrm{S}_2\mathrm{Cl}_2 + 16\mathrm{NH}_3 = \mathrm{S}_4\mathrm{N}_4 + \mathrm{S}_8 + 12\mathrm{NH}_4\mathrm{Cl}$ 1-3 $2\mathrm{Mo(CO)}_6 + 4\mathrm{CH}_3\mathrm{COOH} = [\mathrm{Mo}_2(\mathrm{CH}_3\mathrm{COO})_4] + 2\mathrm{H}_2 + 12\mathrm{CO}$ 1-4 $3\mathrm{Se} + 4\mathrm{AgNO}_3 + 3\mathrm{H}_2\mathrm{O} = 2\mathrm{Ag}_2\mathrm{Se} + \mathrm{H}_2\mathrm{SeO}_3 + 4\mathrm{HNO}_3$ 1-5 $2\mathrm{Xe}[\mathrm{PtF}_6] + 6\mathrm{H}_2\mathrm{O} = 2\mathrm{Xe} + \mathrm{O}_2 + 2\mathrm{PtO}_2 + 12\mathrm{HF}$

## 考点抽象

> 这道题的表面是"五个互不相干的方程式书写"，本质是**每小问各藏一个"非常规产物识别"的元素化学陷阱题**——BH₄⁻ 是还原剂也是配体、S₄N₄ 伴生 S₈、Mo(CO)₆ 被羧酸氧化出 Mo≡Mo、硒既当还原剂又歧化、Xe[PtF₆] 水解氧化水——判产物靠"氧化还原账本＋已知结构先例"。

## 解题思路

1. **1-1 按"硼氢键既给氢又接骨架"写**：[HN(CH₃)₃]⁺ 的 N–H 被 BH₄⁻ 还原放 H₂，同时 BH₃ 与 N 配位成 H₃B·N(CH₃)₃，Li⁺ 配 Cl⁻——"还原＋路易斯酸碱"双职能是硼氢化物反应的通用分析框架。
2. **1-2 从"淡黄色固体"识 S₄N₄**：S₂Cl₂ 被 NH₃ 氨解脱 HCl 成环；副产"环状单质"即 S₈——由 S 守恒 12 个 S 分成 S₄N₄＋S₈（3:4 计量核对 6S₂Cl₂）。
3. **1-3 认出二聚醋酸钼的黄色针状晶体**：Mo(CO)₆ 与醋酸回流生成 [Mo₂(OAc)₄]（Mo-Mo 四重键），配体置换释放 CO、"两个还原性气体"中另一个是羧酸脱氢的 H₂——金属羰基被质子酸氧化是制低价金属羧酸盐的标准路径。
4. **1-4 硒的歧化氧化写全酸**：Se(0) 既有 −2（Ag₂Se 黑色沉淀）又有 +4（H₂SeO₃），溶液强酸性来自 HNO₃——歧化方向由 Ag⁺ 沉淀驱动，电子账本 3Se 失 4e 与 Ag⁺ 得 e 配平。
5. **1-5 Xe[PtF₆] 水解按"强氧化剂氧化水"写**：Xe⁺ 被还原成 Xe、PtF₆⁻ 中 Pt(IV→?) 产物 PtO₂，水被氧化放 O₂、F⁻ 质子化成 HF——稀有气体阳离子的水解几乎都走"氧化水＋氟转氢氟酸"路线。

## 易错分析

- 常见错误 1：1-1 漏 H₂（只写配位产物）或把 H₃BN(CH₃)₃ 写成离子型 [BH₄]⁻ 盐——等物质的量条件下 N–H 恰好被定量还原，配比是配平的钥匙。
- 常见错误 2：1-2 忘写 S₈ 或配平时 NH₄Cl 系数错（12）——S/N/Cl/H 四元素守恒逐项核。
- 常见错误 3：1-3 把"黄色针状晶体"猜成 MoO₃ 类氧化物——"合成 Mo-Mo 化合物的优良起始物"明指 [Mo₂(OAc)₄]；H₂ 气体最易漏。
- 常见错误 4：1-4 产物写成 Ag₂Se＋H₂SeO₄（Se +6）或漏 HNO₃——强酸性提示硝酸根未变价，Se 歧化到 +4 而非 +6；1-5 的 O₂ 与 PtO₂ 双产物常漏其一。
