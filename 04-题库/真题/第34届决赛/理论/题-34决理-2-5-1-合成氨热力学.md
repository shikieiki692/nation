# 第 5 题 合成氨热力学 (10 分)

5-1 合成氨反应：$\frac{1}{2}N_{2}(g) + \frac{3}{2}H_{2}(g) \rightarrow NH_{3}(g)$

已知 298.15 K 时：
- $\Delta_{\text{f}}H_{\text{m}}^{\ominus}(NH_{3}) = -45.90$ kJ/mol
- $S_{\text{m}}^{\ominus}(N_{2}) = 191.6$ J/(K·mol)
- $S_{\text{m}}^{\ominus}(H_{2}) = 130.7$ J/(K·mol)
- $S_{\text{m}}^{\ominus}(NH_{3}) = 192.8$ J/(K·mol)

## 问题

5-1 计算 298.15 K 时合成氨反应的 $\Delta_{\text{r}}G_{\text{m}}^{\ominus}$ 和 $K^{\ominus}$。

## 参考答案

**答案**：
$$
\Delta_{\text{r}}G_{\text{m}}^{\ominus} = -16.4 \text{ kJ/mol}
$$
$$
K^{\ominus} = 772
$$

**解析**：
1. 计算 $\Delta_{\text{r}}H_{\text{m}}^{\ominus}$：
   $$
   \Delta_{\text{r}}H_{\text{m}}^{\ominus} = \Delta_{\text{f}}H_{\text{m}}^{\ominus}(NH_{3}) = -45.90 \text{ kJ/mol}
   $$

2. 计算 $\Delta_{\text{r}}S_{\text{m}}^{\ominus}$：
   $$
   \Delta_{\text{r}}S_{\text{m}}^{\ominus} = S_{\text{m}}^{\ominus}(NH_{3}) - \frac{1}{2}S_{\text{m}}^{\ominus}(N_{2}) - \frac{3}{2}S_{\text{m}}^{\ominus}(H_{2})
   $$
   $$
   = 192.8 - \frac{1}{2} \times 191.6 - \frac{3}{2} \times 130.7 = -99.4 \text{ J/(K·mol)}
   $$

3. 计算 $\Delta_{\text{r}}G_{\text{m}}^{\ominus}$：
   $$
   \Delta_{\text{r}}G_{\text{m}}^{\ominus} = \Delta_{\text{r}}H_{\text{m}}^{\ominus} - T\Delta_{\text{r}}S_{\text{m}}^{\ominus}
   $$
   $$
   = -45.90 - 298.15 \times (-99.4 \times 10^{-3}) = -16.4 \text{ kJ/mol}
   $$

4. 计算 $K^{\ominus}$：
   $$
   \ln K^{\ominus} = -\frac{\Delta_{\text{r}}G_{\text{m}}^{\ominus}}{RT} = \frac{16.4 \times 10^{3}}{8.314 \times 298.15} = 6.62
   $$
   $$
   K^{\ominus} = e^{6.62} = 772
   $$

## 解题思路

### Step 1: 计算反应焓变
```
合成氨反应：
½N₂ + ³⁄₂H₂ → NH₃

ΔrH°m = ΔfH°m(NH₃) = -45.90 kJ/mol
```

### Step 2: 计算反应熵变
```
ΔrS°m = S°m(NH₃) - ½S°m(N₂) - ³⁄₂S°m(H₂)
       = 192.8 - ½×191.6 - ³⁄₂×130.7
       = -99.4 J/(K·mol)
```

### Step 3: 计算 Gibbs 自由能变
```
ΔrG°m = ΔrH°m - TΔrS°m
       = -45.90 - 298.15×(-99.4×10⁻³)
       = -16.4 kJ/mol
```

### Step 4: 计算平衡常数
```
ln K° = -ΔrG°m / RT
       = 16.4×10³ / (8.314×298.15)
       = 6.62

K° = e⁶·⁶² = 772
```

## 变式拓展

1. **如果改变温度**：
   - 使用 van't Hoff 方程计算不同温度的 K
   - 高温不利于合成氨

2. **如果改变压力**：
   - 压力不影响 K，但影响平衡组成
   - 高压有利于合成氨

## 易错分析

### 常见错误 1：熵变计算错误
- **错误**：忽略化学计量数
- **正确**：必须考虑 ½ 和 ³⁄₂ 的系数
- **教训**：熵变计算要正确配平

### 常见错误 2：单位换算错误
- **错误**：kJ 和 J 混用
- **正确**：ΔH 用 kJ，ΔS 用 J/(K·mol)
- **教训**：单位要统一

### 常见错误 3：平衡常数计算错误
- **错误**：使用 log 而不是 ln
- **正确**：ΔG = -RT ln K
- **教训**：注意对数的底数
