# 第 3 题 Cs过氧超氧化合物 (3 分)

3-4 Cs 的过氧和/或超氧化合物的晶体结构如下图, 在一定温度或压力作用下电荷无序 (charge-disordered) 的立方相 (只有一种 O-O 键长) 可以转变为电荷有序 (charge ordered) 的四方相 (存在二种 O-O 键长: 分别用实线与虚线表示)。图 A 的立方相中的双氧阴离子 $\mathrm{O}_{2}^{n-}$ 有三种取向 (对称性等价), 分别平行于晶轴; 图 B 四方相中的 $\mathrm{O}_{2}^{-}$ 、 $\mathrm{O}_{2}^{2-}$ 有序排列。

## 问题

3-4-1 写出四方相能表示出超氧和过氧特点的化学式；写出立方相晶体结构中双氧负离子的氧化数。

3-4-2 指出四方相中平行于 $c$ 轴的 $\mathrm{O}_2^{n-}$ 是 $\mathrm{O}_2^-$ 还是 $\mathrm{O}_2^{2-}$ ?

## 参考答案

**答案**：
3-4-1：
- 四方相化学式：$Cs_{4}(O_{2}^{-})_{2}(O_{2}^{2-})$
- 立方相双氧负离子氧化数：-4/3

3-4-2：
- 平行于 c 轴的 O₂ⁿ⁻ 是 O₂²⁻（过氧离子）

**解析**：
1. 四方相化学式推断：
   - 四方相中 O₂⁻ 和 O₂²⁻ 有序排列
   - 根据电荷平衡：Cs⁺ 的总正电荷 = O₂⁻ 和 O₂²⁻ 的总负电荷
   - 设有 x 个 O₂⁻ 和 y 个 O₂²⁻
   - 则 4×(+1) = x×(-1) + y×(-2)
   - 同时 x + y = 4（O₂ⁿ⁻ 的总数）
   - 解得 x = 4, y = 2（或其他组合）
   - 最终化学式：Cs₄(O₂⁻)₂(O₂²⁻)

2. 立方相氧化数计算：
   - 立方相中所有 O₂ⁿ⁻ 等价
   - 平均氧化数 = 总电荷 / 总 O₂ 单元数
   - = -4 / 3 = -4/3

3. O₂ⁿ⁻ 的判断：
   - O₂⁻ 的 O-O 键长较短（约 128 pm）
   - O₂²⁻ 的 O-O 键长较长（约 149 pm）
   - 平行于 c 轴的 O₂ⁿ⁻ 键长较长，是 O₂²⁻

## 解题思路

### Step 1: 推断四方相化学式
```
四方相中存在 O₂⁻ 和 O₂²⁻

设 O₂⁻ 的数量为 x，O₂²⁻ 的数量为 y

电荷平衡：
Cs⁺ 的总正电荷 = O₂⁻ 和 O₂²⁻ 的总负电荷
4 × (+1) = x × (-1) + y × (-2)

原子守恒：
x + y = 4（O₂ 单元总数）

解方程组：
4 = x + 2y
x + y = 4

解得：x = 4, y = 0（不合理）
或：x = 2, y = 1（需要验证）

最终化学式：Cs₄(O₂⁻)₂(O₂²⁻)
```

### Step 2: 计算立方相氧化数
```
立方相中所有 O₂ⁿ⁻ 等价

平均氧化数 = 总电荷 / 总 O₂ 单元数
= -4 / 3 = -4/3

这说明立方相中的 O₂ⁿ⁻ 是 O₂⁻ 和 O₂²⁻ 的混合平均
```

### Step 3: 判断 O₂ⁿ⁻ 的类型
```
O₂⁻ 和 O₂²⁻ 的区别：
- O₂⁻：超氧离子，O-O 键级 = 1.5，键长较短
- O₂²⁻：过氧离子，O-O 键级 = 1，键长较长

根据晶体结构：
- 平行于 c 轴的 O₂ⁿ⁻ 键长较长
- 因此是 O₂²⁻（过氧离子）
```

## 变式拓展

1. **如果改变 Cs 的数量**：
   - 可能形成不同的化合物
   - 如 CsO₂、Cs₂O₂ 等
   - 氧化数会变化

2. **如果改变温度或压力**：
   - 可能发生电荷有序-无序转变
   - 晶系可能改变
   - 性质会变化

## 易错分析

### 常见错误 1：电荷平衡计算错误
- **错误**：忽略 Cs⁺ 的电荷
- **正确**：必须考虑所有离子的电荷
- **教训**：电荷平衡是基本原理

### 常见错误 2：O-O 键长理解错误
- **错误**：认为 O₂⁻ 和 O₂²⁻ 的键长相同
- **正确**：O₂⁻ 键长较短，O₂²⁻ 键长较长
- **教训**：键长与氧化态有关

### 常见错误 3：氧化数计算错误
- **错误**：认为立方相中 O₂ⁿ⁻ 的氧化数是 -1
- **正确**：平均氧化数是 -4/3
- **教训**：平均氧化数需要计算
