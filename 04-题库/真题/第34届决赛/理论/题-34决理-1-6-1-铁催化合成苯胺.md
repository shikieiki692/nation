# 第 6 题 铁催化合成苯胺 (10 分)

6-1 苯胺是一种重要的有机化工原料，传统合成方法使用贵金属催化剂。近年来，研究者开发了使用廉价铁催化剂合成苯胺的新方法。

某研究小组开发了一种铁催化剂，能够催化硝基苯还原为苯胺。反应条件为：1 mol% FeCl₃，2 equiv Zn，4 equiv NH₄Cl，MeOH 溶剂，80°C，12 h。

## 问题

6-1-1 写出该反应的化学方程式。

6-1-2 画出可能的催化循环机理。

6-1-3 如果将 FeCl₃ 换成 FeCl₂，反应速率如何变化？解释原因。

## 参考答案

**答案**：
6-1-1：
反应方程式：
C₆H₅NO₂ + 3Zn + 6NH₄Cl → C₆H₅NH₂ + 3ZnCl₂ + 6NH₃ + 2H₂O

（或简化为：C₆H₅NO₂ + 6[H] → C₆H₅NH₂ + 2H₂O，其中 [H] 由 Zn/NH₄Cl 体系提供）

6-1-2：
催化循环机理：
```
Fe³⁺ + e⁻ → Fe²⁺（还原）
Fe²⁺ + C₆H₅NO₂ → Fe³⁺ + C₆H₅NO（单电子转移）
C₆H₅NO + 2[H] → C₆H₅NHOH（还原）
C₆H₅NHOH + [H] → C₆H₅NH₂ + H₂O（还原）
```

6-1-3：
如果换成 FeCl₂：
- 反应速率可能降低
- Fe²⁺ 的还原能力比 Fe³⁺ 弱
- 需要更长的诱导期
- 催化效率可能降低

**解析**：
6-1-1：
硝基苯还原为苯胺的总反应：
C₆H₅NO₂ + 6[H] → C₆H₅NH₂ + 2H₂O

还原剂：Zn/NH₄Cl 体系提供 [H]

6-1-2：
催化循环包括：
1. Fe³⁺ 被 Zn 还原为 Fe²⁺
2. Fe²⁺ 与硝基苯发生单电子转移
3. 生成的自由基中间体被还原
4. 最终得到苯胺
5. Fe²⁺ 被氧化回 Fe³⁺

6-1-3：
Fe²⁺ vs Fe³⁺ 的区别：
- Fe³⁺/Fe²⁺ 电对的标准电极电势较高
- Fe³⁺ 更容易被还原，启动催化循环
- Fe²⁺ 需要先被氧化，诱导期更长

## 解题思路

### Step 1: 写出反应方程式
```
硝基苯还原为苯胺：
C₆H₅NO₂ → C₆H₅NH₂

需要还原 6 个电子（N 从 +3 价到 -3 价）

还原剂：Zn/NH₄Cl 体系
Zn → Zn²⁺ + 2e⁻

总反应：
C₆H₅NO₂ + 3Zn + 6NH₄Cl → C₆H₅NH₂ + 3ZnCl₂ + 6NH₃ + 2H₂O
```

### Step 2: 画出催化循环机理
```
催化循环步骤：
1. Fe³⁺ + e⁻（来自 Zn）→ Fe²⁺
2. Fe²⁺ + C₆H₅NO₂ → [Fe³⁺-C₆H₅NO₂]•（单电子转移）
3. [Fe³⁺-C₆H₅NO₂]• → Fe³⁺ + C₆H₅NO•（自由基）
4. C₆H₅NO• + 2[H] → C₆H₅NHOH
5. C₆H₅NHOH + [H] → C₆H₅NH₂ + H₂O

Fe³⁺ 在循环中再生
```

### Step 3: 比较 Fe³⁺ 和 Fe²⁺ 的活性
```
Fe³⁺ 的优势：
- 更高的氧化态，更容易接受电子
- 与硝基苯的亲电作用更强
- 启动催化循环更快

Fe²⁺ 的劣势：
- 较低的氧化态，需要先被氧化
- 诱导期更长
- 催化效率可能降低
```

## 易错分析

### 常见错误 1：反应方程式配平错误
- **错误**：忽略 NH₄Cl 的作用
- **正确**：NH₄Cl 提供质子和氯离子
- **教训**：配平时要考虑所有反应物

### 常见错误 2：催化循环理解错误
- **错误**：认为 Fe²⁺ 是活性物种
- **正确**：Fe³⁺ 是启动催化循环的关键
- **教训**：催化循环的起始物种很重要

### 常见错误 3：催化剂活性判断错误
- **错误**：认为 Fe²⁺ 比 Fe³⁺ 更活泼
- **正确**：Fe³⁺ 的氧化能力更强
- **教训**：催化剂的活性取决于其电子结构
