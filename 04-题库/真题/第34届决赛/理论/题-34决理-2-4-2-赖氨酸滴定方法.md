# 第 4 题 赖氨酸滴定方法 (6 分)

4-2 实验室现有 $0.10 \, mol \cdot L^{-1}$ NaOH 溶液、 $0.10 \, mol \cdot L^{-1}$ HCl 溶液、草酸基准物质、邻苯二甲酸氢钾基准物质、三(羟甲基)氨基甲烷基准物质（简称 Tris）、碳酸钠基准物质，以及酚酞、甲基橙和甲基红等三种指示剂。欲用酸碱滴定法测定某化学纯赖氨酸试样的含量。

## 问题

4-2-1 指出合适的滴定剂并简要说明理由，写出滴定反应化学方程式。

4-2-2 计算滴定终点时溶液 pH，根据计算结果选择最佳指示剂。

4-2-3 假设所选滴定剂的消耗量 25 mL，通过计算所需基准物质的质量及其称量的相对误差确定最佳基准物质。

4-2-4 假设实验中准确称取 $m \mathrm{~g}$ 赖氨酸试样，滴定至终点时消耗 $V \mathrm{~mL}$ 浓度为 $c \mathrm{~mol} \cdot \mathrm{L}^{-1}$ 的所选滴定剂标准溶液，写出该试样中赖氨酸质量分数的计算式。

## 参考答案

**答案**：
4-2-1：
- 滴定剂：HCl 标准溶液。
- 理由：赖氨酸为碱性氨基酸；由 $K_{\mathrm b}=K_{\mathrm w}/K_{\mathrm a}$ 判断，只有一个可被准确滴定的碱性解离步骤，滴定产物主要为 $\mathrm{HA^{+}}$。
- 反应：$\mathrm{A+HCl\rightarrow HA^{+}\cdot Cl^{-}}$，或 $\mathrm{C_6H_{14}N_2O_2+HCl\rightarrow [C_6H_{15}N_2O_2]^{+}\cdot Cl^{-}}$。

4-2-2：
- 计量点 $\mathrm{pH}=\frac{1}{2}(\mathrm{p}K_{\mathrm{a1}}+\mathrm{p}K_{\mathrm{a2}})=\frac{1}{2}(2.18+8.95)=5.56$。
- 最佳指示剂：甲基红。

4-2-3：
- 可用于标定 HCl 的基准物质：Tris 和 $\mathrm{Na_2CO_3}$。
- $m(\mathrm{Tris})=0.10\times25\times10^{-3}\times121.14=0.30\ \mathrm g$；以 $\pm0.2\ \mathrm{mg}$ 天平称量误差计，相对误差约 $\pm0.07\%$。
- $m(\mathrm{Na_2CO_3})=\frac{0.10\times25\times10^{-3}\times105.99}{2}=0.13\ \mathrm g$；相对误差约 $\pm0.2\%$。
- 从称量误差看，最佳基准物质为 Tris。

4-2-4：
$$
w=\frac{cVM}{1000m}
$$
若以百分数表示，则 $w=\frac{cVM}{10m}\%$；其中 $V$ 的单位为 mL。

**解析**：
赖氨酸用 HCl 标准溶液滴定，只有一个滴定突跃，计量点产物为 $\mathrm{HA^{+}}$，故终点 pH 由 $\mathrm{p}K_{\mathrm{a1}}$ 与 $\mathrm{p}K_{\mathrm{a2}}$ 决定，为 5.56，选甲基红。标定 HCl 时，Tris 与 $\mathrm{Na_2CO_3}$ 均可作为基准物质；在题给消耗量下 Tris 的称样量更大，称量相对误差更小，因此更优。

## 解题思路

### Step 4-2-1: 选择滴定剂
```
赖氨酸为碱性氨基酸，用 HCl 标准溶液滴定。
由 Kb = Kw/Ka 判断，只能形成一个滴定突跃，终点产物为 HA+。
反应：A + HCl → HA+·Cl−
```

### Step 4-2-2: 选择指示剂
```
计量点 pH = 1/2(pKa1 + pKa2)
             = 1/2(2.18 + 8.95)
             = 5.56

甲基红变色范围约 4.4-6.2，覆盖 5.56，故选择甲基红。
```

### Step 4-2-3: 选择基准物质
```
可标定 HCl 的基准物质：Tris、Na2CO3。

Tris：m = 0.10×25×10^-3×121.14 = 0.30 g，称量相对误差约 ±0.07%。
Na2CO3：m = 0.10×25×10^-3×105.99/2 = 0.13 g，称量相对误差约 ±0.2%。

结论：Tris 的称量相对误差更小，为最佳基准物质。
```

### Step 4-2-4: 质量分数计算
```
n(Lys) = n(HCl) = c×V×10^-3 mol
m(Lys) = n×M
w = cVM/(1000m)

若写成百分数：w = cVM/(10m)%，其中 V 的单位为 mL。
```

## 变式拓展

1. **如果用 NaOH 滴定**：
   - 需要先将赖氨酸转化为酸式
   - 操作更复杂

2. **如果改变指示剂**：
   - 酚酞变色范围约 8.2-10.0，远离本题计量点 pH 5.56，不适合
   - 甲基橙虽可覆盖酸性区，但变色不如甲基红贴近计量点

## 易错分析

### 常见错误 1：滴定剂选择错误
- **错误**：认为应该用 NaOH 滴定
- **正确**：应该用 HCl 滴定
- **教训**：碱性氨基酸用酸滴定

### 常见错误 2：指示剂选择错误
- **错误**：选择酚酞
- **正确**：选择甲基红
- **教训**：指示剂要匹配终点 pH

### 常见错误 3：基准物质选择错误
- **错误**：选择草酸
- **正确**：选择 Tris
- **教训**：基准物质要适合滴定剂
