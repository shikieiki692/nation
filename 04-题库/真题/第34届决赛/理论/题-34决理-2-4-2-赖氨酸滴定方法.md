# 第 4 题 赖氨酸滴定方法 (6 分)

4-2 实验室现有 $0.10 \, mol \cdot L^{-1}$ NaOH 溶液、 $0.10 \, mol \cdot L^{-1}$ HCl 溶液、草酸基准物质、邻苯二甲酸氢钾基准物质、三(羟甲基)氨基甲烷基准物质（简称 Tris）、碳酸钠基准物质，以及酚酞、甲基橙和甲基红等三种指示剂。欲用酸碱滴定法测定某化学纯赖氨酸试样的含量。

## 问题

4-2-1 指出合适的滴定剂并简要说明理由，写出滴定反应化学方程式。

4-2-2 计算滴定终点时溶液 pH，根据计算结果选择最佳指示剂。

4-2-3 假设所选滴定剂的消耗量 25 mL，通过计算所需基准物质的质量及其称量的相对误差确定最佳基准物质。

4-2-4 假设实验中准确称取 $m \mathrm{~g}$ 赖氨酸试样，滴定至终点时消耗 $V \mathrm{~mL}$ 浓度为 $c \mathrm{~mol} \cdot \mathrm{L}^{-1}$ 的所选滴定剂标准溶液，写出该试样中赖氨酸质量分数的计算式。

## 参考答案

**答案**：
4-2-1：
- 滴定剂：HCl 标准溶液
- 理由：赖氨酸是碱性氨基酸，用酸滴定
- 反应：Lys + HCl → LysH⁺Cl⁻

4-2-2：
- 滴定终点 pH ≈ 5.3
- 最佳指示剂：甲基红

4-2-3：
- 最佳基准物质：Tris
- 质量：约 0.3 g
- 相对误差较小

4-2-4：
$$
w = \frac{c \times V \times M_{\text{Lys}}}{m \times 1000}
$$

**解析**：
4-2-1：
滴定剂选择：
- 赖氨酸是碱性氨基酸
- 应该用酸滴定
- HCl 是强酸，适合作滴定剂

4-2-2：
终点 pH 计算：
- 滴定到第二等当点
- pH ≈ (pKa₂ + pKa₃) / 2 = 9.72
- 但实际滴定可能到第一等当点
- 需要具体计算

4-2-3：
基准物质选择：
- Tris 是合适的基准物质
- 摩尔质量适中
- 称量误差小

4-2-4：
质量分数计算：
- n(Lys) = n(HCl) = c × V × 10⁻³ mol
- m(Lys) = n × M
- w = m(Lys) / m(样品)

## 解题思路

### Step 4-2-1: 选择滴定剂
```
赖氨酸的性质：
- 碱性氨基酸
- 含有两个氨基
- 可以与酸反应

滴定剂选择：
- HCl 标准溶液
- 强酸，适合滴定碱
- 反应：Lys + HCl → LysH⁺Cl⁻
```

### Step 4-2-2: 选择指示剂
```
终点 pH 计算：
- 第一等当点：pH ≈ (pKa₁ + pKa₂) / 2 = 5.57
- 第二等当点：pH ≈ (pKa₂ + pKa₃) / 2 = 9.72

指示剂选择：
- 甲基红：变色范围 4.4-6.2
- 适合第一等当点

结论：选择甲基红
```

### Step 4-2-3: 选择基准物质
```
基准物质要求：
- 纯度高
- 稳定
- 摩尔质量适中

Tris 的优点：
- 摩尔质量 = 121.14 g/mol
- 稳定
- 称量误差小

质量计算：
m = c × V × M = 0.10 × 25 × 10⁻³ × 121.14 = 0.303 g
```

### Step 4-2-4: 质量分数计算
```
计算公式：
n(Lys) = n(HCl) = c × V × 10⁻³ mol
m(Lys) = n × M_Lys
w = m(Lys) / m(样品) × 100%
```

## 易错分析

### 常见错误 1：滴定剂选择错误
- **错误**：认为应该用 NaOH 滴定
- **正确**：应该用 HCl 滴定
- **教训**：碱性氨基酸用酸滴定

### 常见错误 2：指示剂选择错误
- **错误**：选择酚酞
- **正确**：选择甲基红
- **教训**：指示剂要匹配终点 pH

### 常见错误 3：基准物质选择错误
- **错误**：选择草酸
- **正确**：选择 Tris
- **教训**：基准物质要适合滴定剂
