# 第 5 题 过氧化氢酶动力学 (10 分)

5-1 过氧化氢酶（catalase）是一种广泛存在于生物体内的抗氧化酶，能够高效催化 H₂O₂ 的分解反应。某研究小组在 25°C、pH 7.0 的条件下，研究了过氧化氢酶催化 H₂O₂ 分解的动力学，得到了以下数据：

| [S]₀ (mmol/L) | 1/[S]₀ (L/mmol) | v₀ (mmol/(L·min)) | 1/v₀ (L·min/mmol) |
|---|---|---|---|
| 10.0 | 0.100 | 9.09 | 0.110 |
| 5.0 | 0.200 | 7.14 | 0.140 |
| 2.0 | 0.500 | 4.55 | 0.220 |
| 1.0 | 1.000 | 2.86 | 0.350 |
| 0.5 | 2.000 | 1.67 | 0.600 |

## 问题

5-1-1 用 Lineweaver-Burk 双倒数作图法，求出 Km 和 Vmax。

5-1-2 如果在反应体系中加入 0.1 mmol/L 的抑制剂 I，实验数据变为：

| [S]₀ (mmol/L) | v₀ (mmol/(L·min)) |
|---|---|
| 10.0 | 5.00 |
| 5.0 | 3.33 |
| 2.0 | 1.82 |
| 1.0 | 1.11 |
| 0.5 | 0.63 |

判断抑制类型，并求出抑制常数 Ki。

## 参考答案

**答案**：
5-1-1：
- Vmax = 10.0 mmol/(L·min)
- Km = 1.0 mmol/L

5-1-2：
- 抑制类型：竞争性抑制
- Ki = 0.1 mmol/L

**解析**：
5-1-1：
Lineweaver-Burk 方程：
1/v₀ = (Km/Vmax) × (1/[S]₀) + 1/Vmax

从数据作图，斜率 = Km/Vmax，截距 = 1/Vmax

通过线性回归：
- 截距 = 0.100 L·min/mmol → Vmax = 10.0 mmol/(L·min)
- 斜率 = 0.100 L/mmol → Km = 1.0 mmol/L

5-1-2：
加入抑制剂后的 Lineweaver-Burk 方程：
1/v₀ = (Km/Vmax)(1 + [I]/Ki) × (1/[S]₀) + 1/Vmax

从数据作图，斜率增加，截距不变 → 竞争性抑制

斜率变化：0.200 → 0.200 × (1 + 0.1/Ki)
解得：Ki = 0.1 mmol/L

## 解题思路

### Step 1: Lineweaver-Burk 作图
```
Lineweaver-Burk 方程：
1/v₀ = (Km/Vmax) × (1/[S]₀) + 1/Vmax

这是 y = mx + c 的形式：
- y = 1/v₀
- x = 1/[S]₀
- 斜率 m = Km/Vmax
- 截距 c = 1/Vmax
```

### Step 2: 求 Km 和 Vmax
```
从数据计算：
- 截距 c = 0.100 L·min/mmol
- Vmax = 1/c = 10.0 mmol/(L·min)

- 斜率 m = 0.100 L/mmol
- Km = m × Vmax = 0.100 × 10.0 = 1.0 mmol/L
```

### Step 3: 判断抑制类型
```
加入抑制剂后的变化：
- 截距不变 → Vmax 不变
- 斜率增加 → 表观 Km 增加

结论：竞争性抑制

竞争性抑制的特点：
- 抑制剂与底物竞争酶的活性位点
- Vmax 不变
- 表观 Km 增加
```

### Step 4: 求抑制常数 Ki
```
竞争性抑制的 Lineweaver-Burk 方程：
1/v₀ = (Km/Vmax)(1 + [I]/Ki) × (1/[S]₀) + 1/Vmax

斜率变化：
0.200 = 0.100 × (1 + 0.1/Ki)

解得：Ki = 0.1 mmol/L
```

## 变式拓展

1. **如果是非竞争性抑制**：
   - Vmax 降低
   - Km 不变
   - Lineweaver-Burk 图交于 x 轴

2. **如果是反竞争性抑制**：
   - Vmax 降低
   - Km 降低
   - Lineweaver-Burk 图平行

## 易错分析

### 常见错误 1：作图方法错误
- **错误**：用 v₀ 对 [S]₀ 作图
- **正确**：用 1/v₀ 对 1/[S]₀ 作图
- **教训**：Lineweaver-Burk 是双倒数作图

### 常见错误 2：抑制类型判断错误
- **错误**：认为 Vmax 降低是竞争性抑制
- **正确**：竞争性抑制 Vmax 不变
- **教训**：不同抑制类型有不同的特征

### 常见错误 3：Ki 计算错误
- **错误**：忽略 [I] 的浓度
- **正确**：必须考虑抑制剂浓度
- **教训**：Ki 计算要准确
