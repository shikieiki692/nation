# 第 3 题 MOF溶剂分子推断 (6 分)

3-2 已知 MOF-X 的密度为 1.153 g·cm⁻³ ; MOF-X 的晶胞参数如下: a = 2566.90 pm, V = 1.69132×10 $^{10}$ pm³ , Z = 8; 含氯量为 2.42%。推断一个正当晶胞中溶剂分子的数目与种类。

## 问题

推断一个正当晶胞中溶剂分子的数目与种类。

## 参考答案

**答案**：
溶剂分子：
- 8 个 DMF（N,N-二甲基甲酰胺）
- 1 个氯苯

一个正当晶胞中：
- 64 个 DMF
- 8 个氯苯

**解析**：
计算过程：
1. 由密度计算晶胞质量：
   $$m = \rho \times V = 1.153 \times 1.69132 \times 10^{-23} = 1.95 \times 10^{-23} \text{ g}$$

2. 计算式量：
   $$M = m \times N_A / Z = 1.95 \times 10^{-23} \times 6.022 \times 10^{23} / 8 = 1467.4 \text{ g/mol}$$

3. 减去 MOF-5 的式量：
   $$M_{\text{溶剂}} = 1467.4 - 769.9 = 697.5 \text{ g/mol}$$

4. 由含氯量确定氯苯：
   - 假设有 1 个氯苯（M = 112.55）
   - 剩余质量 = 697.5 - 112.55 = 584.95
   - DMF 数量 = 584.95 / 73.08 = 8.0

5. 验证：1464.9 ≈ 1467.4 ✓

## 解题思路

### Step 1: 计算晶胞质量
```
密度公式：
ρ = m / V

已知：
- ρ = 1.153 g/cm³
- V = 1.69132×10¹⁰ pm³ = 1.69132×10⁻²³ cm³

计算：
m = ρ × V = 1.153 × 1.69132×10⁻²³ = 1.95×10⁻²³ g
```

### Step 2: 计算式量
```
式量公式：
M = m × N_A / Z

已知：
- N_A = 6.022×10²³ mol⁻¹
- Z = 8

计算：
M = 1.95×10⁻²³ × 6.022×10²³ / 8 = 1467.4 g/mol
```

### Step 3: 确定溶剂组成
```
MOF-5 式量：
Zn₄O(BDC)₃ = 769.9 g/mol

溶剂式量：
M_溶剂 = 1467.4 - 769.9 = 697.5 g/mol

由含氯量确定氯苯：
- 假设 1 个氯苯（M = 112.55）
- 剩余 = 697.5 - 112.55 = 584.95
- DMF 数量 = 584.95 / 73.08 = 8.0

结论：8 个 DMF + 1 个氯苯
```

## 易错分析

### 常见错误 1：单位换算错误
- **错误**：pm³ 和 cm³ 换算错误
- **正确**：1 pm = 10⁻¹⁰ cm
- **教训**：单位换算要仔细

### 常见错误 2：式量计算错误
- **错误**：忘记除以 Z
- **正确**：M = m × N_A / Z
- **教训**：晶胞中有 Z 个分子

### 常见错误 3：溶剂识别错误
- **错误**：认为所有溶剂都是 DMF
- **正确**：含氯量表明有氯苯
- **教训**：元素分析数据很重要
