# 第 5 题 非理想气体与平衡常数 (1 分)

5-5 解释为什么在高压下 $K_p$ 不是常数。

## 问题

解释为什么在高压下 $K_p$ 不是常数。

## 参考答案

**答案**：
在高压下，$K_p$ 不是常数的原因：
- 气体不是理想气体
- 不同压力下的气体因分子间作用力不同而表现出对理想气体不同程度的偏离
- 使 $K_p$ 不是常数

**解析**：
1. 理想气体假设：
   - 分子间无作用力
   - 分子本身无体积
   - 低压下近似成立

2. 高压下的偏离：
   - 分子间作用力显著
   - 分子体积不能忽略
   - 气体行为偏离理想气体

3. 对平衡常数的影响：
   - $K_p$ 是用分压表示的平衡常数
   - 理想气体：$K_p$ 只与温度有关
   - 非理想气体：$K_p$ 与压力有关

4. 解决方法：
   - 使用逸度代替分压
   - $K_f$（逸度平衡常数）才是真正的常数

## 解题思路

### Step 1: 回顾理想气体假设
```
理想气体的特点：
- 分子间无作用力
- 分子本身无体积
- PV = nRT 严格成立
- 低压下近似成立
```

### Step 2: 分析高压下的偏离
```
高压下的情况：
- 分子间距离减小
- 分子间作用力显著
- 分子体积不能忽略
- 气体行为偏离理想气体
```

### Step 3: 解释 Kp 的变化
```
Kp 的定义：
Kp = ∏(p_i)^ν_i

对于理想气体：
- Kp 只与温度有关
- 与压力无关

对于非理想气体：
- Kp 与压力有关
- 不是真正的常数
```

### Step 4: 提出解决方法
```
解决方法：
- 使用逸度代替分压
- 逸度 f = γ × p
- γ 是逸度系数
- Kf（逸度平衡常数）才是真正的常数
```

## 易错分析

### 常见错误 1：Kp 定义理解错误
- **错误**：认为 Kp 总是常数
- **正确**：Kp 只对理想气体是常数
- **教训**：Kp 的适用条件要清楚

### 常见错误 2：非理想性原因理解错误
- **错误**：认为是温度影响
- **正确**：是分子间作用力和分子体积
- **教训**：非理想性来自分子间作用力

### 常见错误 3：逸度概念理解错误
- **错误**：认为逸度就是分压
- **正确**：逸度是校正后的分压
- **教训**：逸度是有效压力
