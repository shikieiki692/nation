# 第 4 题 赖氨酸等电点与分布 (4 分)

赖氨酸又名 2,6-二氨基己酸（简写 Lys， $C_{6}H_{14}N_{2}O_{2}$ ），是一种人体必需氨基酸，在水溶液中有 4 种分布形式（用 $H_{2}A^{2+}$ ， $HA^{+}$ ，A 和 A-表示）。

## 问题

4-1 根据该曲线，计算赖氨酸的等电点 $\mathrm{pI}$ 以及 $\mathrm{pH} = 9.60$ 时赖氨酸4种分布形式的平衡浓度。

## 参考答案

**答案**：
等电点：
$$
\mathrm{pI} = 1 / 2 \left(\mathrm{pK} _ {\mathrm{a} 2} + \mathrm{pK} _ {\mathrm{a} 3}\right) = 1 / 2 (8. 9 5 + 1 0. 5 0) = 9. 7 2
$$

pH = 9.60 时的分布：
- $[H_{2}A^{2+}] = 0$ mol/L
- $[HA^{+}] = 0.059$ mol/L
- $[A] = 0.26$ mol/L
- $[A^{-}] = 0.032$ mol/L

**解析**：
1. 等电点计算：
   - 赖氨酸是二元碱
   - pKa₁ = 2.18, pKa₂ = 8.95, pKa₃ = 10.50
   - pI = (pKa₂ + pKa₃) / 2 = 9.72

2. 分布分数计算：
   - 使用分布分数公式
   - pH = 9.60 时，主要形式是 A 和 HA⁺

3. 浓度计算：
   - 总浓度 c = 0.345 mol/L
   - 各形式浓度 = 分布分数 × 总浓度

## 解题思路

### Step 1: 确定 pKa 值
```
从滴定曲线确定：
- pKa₁ = 2.18（α-COOH）
- pKa₂ = 8.95（α-NH₃⁺）
- pKa₃ = 10.50（ε-NH₃⁺）
```

### Step 2: 计算等电点
```
等电点公式：
pI = (pKa₂ + pKa₃) / 2

计算：
pI = (8.95 + 10.50) / 2 = 9.72
```

### Step 3: 计算分布分数
```
pH = 9.60 时：
- [H⁺] = 10⁻⁹·⁶⁰

分布分数：
δ(H₂A²⁺) ≈ 0
δ(HA⁺) = 1.7 × 10⁻¹
δ(A) = 7.4 × 10⁻¹
δ(A⁻) = 9.3 × 10⁻²
```

### Step 4: 计算浓度
```
总浓度：
c = 0.345 mol/L

各形式浓度：
[H₂A²⁺] = 0 mol/L
[HA⁺] = 0.059 mol/L
[A] = 0.26 mol/L
[A⁻] = 0.032 mol/L
```

## 易错分析

### 常见错误 1：等电点公式错误
- **错误**：认为 pI = (pKa₁ + pKa₂) / 2
- **正确**：pI = (pKa₂ + pKa₃) / 2
- **教训**：赖氨酸是碱性氨基酸

### 常见错误 2：分布分数计算错误
- **错误**：忽略某些形式
- **正确**：必须考虑所有4种形式
- **教训**：多元酸碱分布要完整

### 常见错误 3：浓度计算错误
- **错误**：忘记乘以总浓度
- **正确**：浓度 = 分布分数 × 总浓度
- **教训**：分布分数是比例，不是浓度
