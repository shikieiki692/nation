# 第 4 题 Al燃烧最高温度 (4 分)

4-2 在 298.15 K 和 100 kPa 下，将超细铝粉与空气（设空气中氧气和氮气的摩尔分数分别为 0.200 和 0.800）混合后装入特定装置中进行点火燃烧试验，火焰温度可超过 2500 K。收集燃烧试验中全部组分，冷却至室温，测得固体中各组分（忽略其他组成形式）的质量分数为：Al, 0.100; Al₂O₃, 0.700; AlN, 0.200。若燃烧试验中氧气刚好耗尽，求体系可能达到的最高温度。

## 问题

求体系可能达到的最高温度。

## 参考答案

**答案**：
最高温度 T > 2790 K

**解析**：
1. 计算各物质的量：
- 以 100 g 固体为基准
- Al: 10.00/26.98 = 0.371 mol
- Al₂O₃: 70.00/101.96 = 0.686 mol
- AlN: 20.00/40.98 = 0.488 mol

2. 计算消耗的 Al：
- Al 总量 = 0.371 + 0.686×2 + 0.488 = 2.231 mol

3. 计算消耗的 O₂ 和 N₂：
- 消耗 O₂: 0.686×2×3/4 = 1.029 mol
- 消耗 N₂: 0.488 mol

4. 计算空气组成：
- 引入 N₂: 1.029×4 = 4.116 mol
- 剩余 N₂: 4.116 - 0.244 = 3.872 mol

5. 确定最高温度：
- 假设 T > 2790 K
- 此时 Al 为气态，Al₂O₃ 为液态，AlN 为气态
- 通过热平衡计算验证

## 解题思路

### Step 1: 确定反应体系
```
燃烧反应：
Al + O₂ → Al₂O₃
Al + N₂ → AlN

已知产物组成：
- Al: 10.00%
- Al₂O₃: 70.00%
- AlN: 20.00%
```

### Step 2: 计算各物质的量
```
以 100 g 固体为基准：
- n(Al) = 10.00/26.98 = 0.371 mol
- n(Al₂O₃) = 70.00/101.96 = 0.686 mol
- n(AlN) = 20.00/40.98 = 0.488 mol

总 Al 量：
n(Al)total = 0.371 + 0.686×2 + 0.488 = 2.231 mol
```

### Step 3: 计算消耗的 O₂ 和 N₂
```
消耗 O₂：
n(O₂)consumed = 0.686×2×3/4 = 1.029 mol

消耗 N₂：
n(N₂)consumed = 0.488 mol

空气组成：
n(N₂)introduced = 1.029×4 = 4.116 mol
n(N₂)remaining = 4.116 - 0.244 = 3.872 mol
```

### Step 4: 确定最高温度
```
假设 T > 2790 K：
- Al 为气态（沸点 2790 K）
- Al₂O₃ 为液态（沸点 3253 K）
- AlN 为气态（易升华）

通过热平衡计算验证假设
```

## 变式拓展

1. **如果氧气不完全耗尽**：
   - 产物组成会变化
   - 最高温度会降低

2. **如果使用纯氧**：
   - 燃烧更剧烈
   - 最高温度会升高

## 易错分析

### 常见错误 1：物态判断错误
- **错误**：认为所有产物都是气态
- **正确**：Al₂O₃ 在 2790 K 时为液态
- **教训**：必须根据温度判断物态

### 常见错误 2：摩尔质量计算错误
- **错误**：Al₂O₃ 的摩尔质量计算错误
- **正确**：Al₂O₃ = 2×26.98 + 3×16.00 = 101.96 g/mol
- **教训**：摩尔质量要仔细计算

### 常见错误 3：化学计量错误
- **错误**：O₂ 和 N₂ 的比例错误
- **正确**：空气中 O₂:N₂ = 1:4
- **教训**：化学计量要准确
