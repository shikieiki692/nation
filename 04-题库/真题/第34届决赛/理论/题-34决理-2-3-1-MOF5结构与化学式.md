# 第 3 题 MOF5结构与化学式 (2 分)

金属-有机框架材料（MOFs）是近20年来研究十分热门的领域，在储气、分离、催化、沙漠地区富集水分等功能材料领域具有重要潜在应用意义。MOFs是三维配位聚合物，典型的MOFs材料有MOF-5和HKUST-1。

## 问题

3-1 MOF-5 的晶体结构如上图所示，写出 MOF-5 的化学式。

## 参考答案

**答案**：
MOF-5 的化学式：
$$
\mathrm{C}_{24}\mathrm{H}_{12}\mathrm{O}_{13}\mathrm{Zn}_{4}
$$
或
$$
\mathrm{Zn}_{4}\mathrm{O}(\mathrm{BDC})_{3}
$$

**解析**：
MOF-5 的结构：
- 金属节点：Zn₄O 簇
- 有机配体：对苯二甲酸（BDC）
- 三维多孔结构

化学式推断：
- Zn₄O 簇：4个 Zn 和 1个 O
- BDC：C₆H₄(COO)₂
- 3个 BDC 配体
- 总化学式：Zn₄O(BDC)₃

## 解题思路

### Step 1: 分析 MOF-5 结构
```
MOF-5 的结构特点：
- 金属节点：Zn₄O 簇
- 有机配体：BDC（对苯二甲酸）
- 三维网络结构
- 高孔隙率
```

### Step 2: 推断化学式
```
Zn₄O 簇：
- 4 个 Zn 原子
- 1 个 O 原子
- 形成四面体簇

BDC 配体：
- C₆H₄(COO)₂
- 双齿配体
- 连接 Zn₄O 簇

化学式：
- 1 个 Zn₄O 簇
- 3 个 BDC 配体
- Zn₄O(BDC)₃
```

### Step 3: 验证化学式
```
原子计数：
- Zn：4 个
- O：1 + 3×2 = 7 个（BDC 有 2 个羧基）
- C：3×6 = 18 个
- H：3×4 = 12 个

总化学式：
C₁₈H₁₂O₇Zn₄
或简写为 Zn₄O(BDC)₃
```

## 易错分析

### 常见错误 1：金属簇结构理解错误
- **错误**：认为是单个 Zn 原子
- **正确**：是 Zn₄O 簇
- **教训**：MOF 的金属节点通常是簇

### 常见错误 2：配体连接方式错误
- **错误**：认为 BDC 是单齿配体
- **正确**：BDC 是双齿配体
- **教训**：羧酸配体通常是双齿

### 常见错误 3：化学式计数错误
- **错误**：忽略 O 原子的来源
- **正确**：Zn₄O 簇中有一个 O
- **教训**：化学式计数要仔细
