# 第 3 题 MOF5稳定性 (2 分)

3-3 MOF-5 具有可以容纳直径为 1510 pm 球状分子的孔洞, 孔洞的体积约占晶体总体积的 55%; 通过加热等手段完全除去溶剂分子的 MOF-5 能稳定存在。按照堆积理论这样的结构很不稳定,但实验发现如此高孔隙率的 MOF-5 却能稳定存在, 说明原因。

## 问题

解释 MOF-5 能稳定存在的原因。

## 参考答案

**答案**：
MOF-5 能稳定存在的原因：
- 框架结构中 Zn-O 键是共价配键
- Zn₄O₁₃ 构造单元刚性
- 不是离子化合物

**解析**：
稳定性分析：
1. 共价键强度：
   - Zn-O 键是共价配键
   - 键能较高
   - 框架结构稳定

2. 构造单元刚性：
   - Zn₄O₁₃ 构造单元是刚性的
   - 不容易变形
   - 保持框架结构

3. 与离子化合物的区别：
   - 离子化合物靠静电作用
   - 容易被溶剂溶解
   - MOF-5 靠共价键连接
   - 不容易被破坏

## 解题思路

### Step 1: 分析 MOF-5 的结构
```
MOF-5 的结构特点：
- 高孔隙率（55%）
- 大孔径（1510 pm）
- 除去溶剂后稳定
```

### Step 2: 分析稳定性原因
```
稳定性来源：
1. Zn-O 键是共价配键
   - 不是离子键
   - 键能高
   - 不容易断裂

2. Zn₄O₁₃ 构造单元刚性
   - 结构刚性
   - 不容易变形
   - 保持框架

3. 三维网络结构
   - 交联度高
   - 结构稳定
```

### Step 3: 与离子化合物比较
```
离子化合物：
- 靠静电作用
- 容易被溶剂溶解
- 不稳定

MOF-5：
- 靠共价键连接
- 不容易被破坏
- 稳定
```

## 变式拓展

1. **如果改变金属**：
   - 不同金属的键能不同
   - 稳定性可能变化

2. **如果改变有机配体**：
   - 不同配体的刚性不同
   - 可能影响稳定性

## 易错分析

### 常见错误 1：稳定性原因理解错误
- **错误**：认为是氢键作用
- **正确**：是共价配键作用
- **教训**：MOF 的稳定性来自共价键

### 常见错误 2：与离子化合物混淆
- **错误**：认为 MOF 是离子化合物
- **正确**：MOF 是共价化合物
- **教训**：MOF 的结构是共价网络

### 常见错误 3：刚性理解错误
- **错误**：认为框架是柔性的
- **正确**：Zn₄O₁₃ 构造单元是刚性的
- **教训**：刚性是稳定性的重要来源
