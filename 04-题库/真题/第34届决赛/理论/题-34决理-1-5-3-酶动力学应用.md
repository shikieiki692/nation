# 第 5 题 酶动力学应用 (6 分)

5-3 在药物研发中，常需要评价抑制剂的效力。某研究小组测定了三种抑制剂对过氧化氢酶的抑制效果，得到了以下数据：

| 抑制剂 | IC₅₀ (mmol/L) | Ki (mmol/L) | 抑制类型 |
|---|---|---|---|
| I₁ | 0.50 | 0.10 | 竞争性 |
| I₂ | 1.00 | 0.50 | 非竞争性 |
| I₃ | 0.25 | 0.05 | 竞争性 |

已知 Km = 1.0 mmol/L，Vmax = 10.0 mmol/(L·min)。

## 问题

5-3-1 计算当 [S] = 2.0 mmol/L 时，加入 0.5 mmol/L 的 I₁ 后的反应速率。

5-3-2 比较三种抑制剂的抑制效率，哪个最有效？

5-3-3 如果要设计一个竞争性抑制剂，使其在 [S] = Km 时抑制率达到 90%，需要满足什么条件？

## 参考答案

**答案**：
5-3-1：
- 无抑制剂时：v₀ = 6.67 mmol/(L·min)
- 加入 I₁ 后：v₀ = 2.50 mmol/(L·min)
- 抑制率：62.5%

5-3-2：
- 抑制效率：I₃ > I₁ > I₂
- I₃ 最有效（Ki 最小）

5-3-3：
- 需要满足：[I]/Ki ≥ 8，即 Ki ≤ [I]/8（若取 [I] = 0.5 mmol/L，则 Ki ≤ 0.0625 mmol/L）
- 计算过程见解析

**解析**：
5-3-1：
无抑制剂时：
v₀ = Vmax × [S] / (Km + [S])
   = 10.0 × 2.0 / (1.0 + 2.0)
   = 6.67 mmol/(L·min)

加入竞争性抑制剂 I₁：
v₀ = Vmax × [S] / (Km(1 + [I]/Ki) + [S])
   = 10.0 × 2.0 / (1.0 × (1 + 0.5/0.1) + 2.0)
   = 20.0 / (1.0 × 6 + 2.0)
   = 20.0 / 8.0
   = 2.50 mmol/(L·min)

（竞争性抑制：v = Vmax[S]/(Km(1+[I]/Ki)+[S]) = 20.0/(6.0+2.0) = 2.50 mmol/(L·min)）

5-3-2：
抑制效率比较：
- I₁：Ki = 0.10 mmol/L
- I₂：Ki = 0.50 mmol/L
- I₃：Ki = 0.05 mmol/L

Ki 越小，抑制效率越高
因此：I₃ > I₁ > I₂

5-3-3：
竞争性抑制剂在 [S] = Km 时的抑制率：
抑制率 = 1 - v_inhibited/v_uninhibited

v_uninhibited = Vmax × Km / (Km + Km) = Vmax/2

v_inhibited = Vmax × Km / (Km(1 + [I]/Ki) + Km)
            = Vmax / (2 + [I]/Ki)

抑制率 = 1 - 1/(2 + [I]/Ki) = 0.9

解得：[I]/Ki = 8，即 Ki = [I]/8。
若取 [I] = 0.5 mmol/L，则 Ki = 0.0625 mmol/L。

（此即竞争性抑制器的设计条件：当 [S] = Km 时，抑制率 = 1 − 1/(2+[I]/Ki)）

## 解题思路

### Step 1: 计算抑制后的反应速率
```
无抑制剂时的反应速率：
v₀ = Vmax × [S] / (Km + [S])
   = 10.0 × 2.0 / (1.0 + 2.0)
   = 6.67 mmol/(L·min)

加入竞争性抑制剂后的反应速率：
v₀ = Vmax × [S] / (Km(1 + [I]/Ki) + [S])
   = 10.0 × 2.0 / (1.0 × (1 + 0.5/0.1) + 2.0)
   = 20.0 / (1.0 × 6 + 2.0)
   = 20.0 / 8.0
   = 2.50 mmol/(L·min)
```

### Step 2: 比较抑制效率
```
抑制效率通常用 Ki 值比较：
- Ki 越小，抑制效率越高
- I₃：Ki = 0.05 mmol/L（最有效）
- I₁：Ki = 0.10 mmol/L
- I₂：Ki = 0.50 mmol/L（最弱）
```

### Step 3: 设计抑制剂
```
目标：在 [S] = Km 时抑制率达到 90%

竞争性抑制的抑制率：
抑制率 = 1 - v_inhibited/v_uninhibited

v_uninhibited = Vmax/2（当 [S] = Km）

v_inhibited = Vmax / (2 + [I]/Ki)

0.9 = 1 - 1/(2 + [I]/Ki)

解得：Ki = [I]/8

如果 [I] = 0.5 mmol/L，则 Ki = 0.0625 mmol/L
```

## 易错分析

### 常见错误 1：抑制率计算错误
- **错误**：直接用 v_inhibited/v_uninhibited
- **正确**：抑制率 = 1 - v_inhibited/v_uninherited
- **教训**：抑制率的定义要清楚

### 常见错误 2：Ki 比较错误
- **错误**：认为 Ki 越大抑制效率越高
- **正确**：Ki 越小抑制效率越高
- **教训**：Ki 的物理意义要理解

### 常见错误 3：抑制剂设计错误
- **错误**：忽略 [I] 的浓度
- **正确**：必须考虑抑制剂的使用浓度
- **教训**：设计时要考虑实际应用条件
