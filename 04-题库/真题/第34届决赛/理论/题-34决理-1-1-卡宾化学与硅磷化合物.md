# 第 1 题 卡宾化学与硅磷化合物 (14 分)

具有 $\mathrm{R}_{2} \mathrm{C}$ : 形式的有机中间体称为卡宾, M. Driess 等报道了基于咕吨骨架的双 X 卡宾 1 和 $\mathbf{Y}_{4}$ 进行反应, 首次分离得到双 X 卡宾稳定的零价 $\mathbf{Y}_{2}$ 加合物 2。单晶 X 射线衍射实验测定显示, 2 中 Y-Y 键长为 $223.69 \mathrm{pm}$ , 两个 X-Y 键长分别为 $213.07 \mathrm{pm}$ 和 $212.63 \mathrm{pm}$ , C-O-C 键角为 $121.1^{\circ}$ 。已知某些原子的共价单键半径 (pm) 为: B, 82; C, 77; N, 75; O, 73; F, 72; Al, 118; Si, 117; P, 106; S, 102; Cl, 99。

## 问题

1-1 工业上利用直接还原的方法将 Y 矿中的 Y 元素转化为单质 $Y_{4}$ 。写出 X 和 Y 元素并画出 $Y_{4}$ 的几何构型，描述 $Y_{4}$ 中的 Y-Y 化学键形状。

## 参考答案

**答案**：
X = Si, Y = P

$Y_{4}$ 即 $P_{4}$，几何构型为正四面体，Y-Y 化学键为弯键。

**解析**：
1. 通过共价单键半径计算验证：
   - X-Y 键长理论值 = r(X) + r(Y)
   - 若 X=Si (117 pm), Y=P (106 pm)，则理论键长 = 223 pm
   - 实测 X-Y 键长 = 213.07 pm 和 212.63 pm，接近理论值
   - Y-Y 键长 = 223.69 pm，接近 2×106 = 212 pm（考虑弯键效应）

2. $P_{4}$ 的结构：
   - 4个P原子位于正四面体的四个顶点
   - 每个P原子与其他3个P原子成键
   - P-P-P 键角为 60°，远小于正常 sp³ 杂化的 109.5°
   - 因此 P-P 键为弯键（bent bond），具有较大张力

## 解题思路

### Step 1: 元素推断
```
已知数据：
- X-Y 键长：213.07 pm 和 212.63 pm
- Y-Y 键长：223.69 pm
- 共价单键半径：Si=117 pm, P=106 pm

计算验证：
- Si-P 键长理论值 = 117 + 106 = 223 pm
- P-P 键长理论值 = 2 × 106 = 212 pm

结论：
- X = Si, Y = P
- 实测值与理论值接近，验证推断正确
```

### Step 2: $P_{4}$ 的几何构型
```
$P_{4}$ 的结构特征：
- 4个P原子位于正四面体顶点
- 每个P原子与其他3个P原子成键
- P-P-P 键角 = 60°

几何构型：正四面体
```

### Step 3: Y-Y 化学键形状
```
弯键（bent bond）的形成：
- 正常 sp³ 杂化：键角 109.5°
- $P_{4}$ 中：键角 60°，严重偏离
- 电子云重叠不在两核连线上
- 形成弯曲的化学键

弯键的特点：
- 键能较低，分子张力大
- 化学活性高
- 是 $P_{4}$ 高反应活性的原因之一
```

## 变式拓展

1. **如果 Y 是 As 元素**：
   - $As_{4}$ 也具有类似结构
   - As-As 键长更长（约 244 pm）
   - 分子张力更大

2. **如果 X 是 Ge 元素**：
   - Ge 的共价半径更大（约 122 pm）
   - Ge-Y 键长会更长
   - 可能影响卡宾稳定性

## 易错分析

### 常见错误 1：元素推断错误
- **错误**：认为 X 是 C 或 N
- **正确**：X 必须是 Si，因为键长数据匹配
- **教训**：必须用数据验证推断

### 常见错误 2：$P_{4}$ 结构理解错误
- **错误**：认为 $P_{4}$ 是平面结构
- **正确**：$P_{4}$ 是正四面体结构
- **教训**：P 原子采用 sp³ 杂化

### 常见错误 3：弯键概念混淆
- **错误**：认为弯键是弱键
- **正确**：弯键是正常的共价键，只是电子云弯曲
- **教训**：弯键不等于弱键

### 常见错误 4：键角理解错误
- **错误**：认为 P-P-P 键角应该是 109.5°
- **正确**：$P_{4}$ 中键角是 60°，这是结构决定的
- **教训**：分子几何构型决定键角
