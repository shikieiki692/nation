## 考点抽象

> 这道题的表面是**酰胺转化与环化**，本质是**强碱诱导的环化反应**——需要理解 n-BuLi 和 LDA 的去质子化作用以及环化反应的机理。

**核心能力拆解**：
- **强碱去质子化**：n-BuLi 和 LDA 的作用
- **环化反应**：酰胺的分子内环化
- **酸催化**：TsOH 促进的环化

## 解题思路

### Step 1: 分析 n-BuLi 的作用
```
n-BuLi 的性质：
- 正丁基锂
- 强碱
- 亲核试剂

与酰胺的作用：
- 夺取酸性 H
- 形成锂化的酰胺（化合物2）
```

### Step 2: 分析化合物2到3的转化
```
化合物2进一步反应：
- 可能发生分子内环化
- 形成环状结构
- 得到化合物3
```

### Step 3: 分析 LDA 的作用
```
LDA 的性质：
- 二异丙基氨基锂
- 强碱
- 位阻大，选择性好

与化合物3的作用：
- 夺取酸性 H
- 形成化合物4
```

### Step 4: 分析 TsOH 的作用
```
TsOH 的性质：
- 对甲苯磺酸
- 强酸
- 促进环化或重排

与化合物4的作用：
- 促进环化
- 得到最终产物5
```

## 易错分析

### 常见错误 1：n-BuLi 作用理解错误
- **错误**：认为 n-BuLi 是亲核试剂
- **正确**：n-BuLi 是强碱，主要作用是去质子化
- **教训**：n-BuLi 的碱性比亲核性更重要

### 常见错误 2：LDA 作用理解错误
- **错误**：认为 LDA 是亲核试剂
- **正确**：LDA 是强碱，位阻大
- **教训**：LDA 的选择性来自位阻

### 常见错误 3：TsOH 作用理解错误
- **错误**：认为 TsOH 是氧化剂
- **正确**：TsOH 是酸催化剂
- **教训**：TsOH 的作用是催化环化
