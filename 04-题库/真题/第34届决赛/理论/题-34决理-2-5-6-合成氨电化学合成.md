# 第 5 题 合成氨电化学合成 (1 分)

5-6 写出电化学合成氨的电极反应式。

## 问题

写出电化学合成氨的阳极和阴极反应式。

## 参考答案

**答案**：
阳极反应：
$$
12OH^{-} \rightarrow 6H_{2}O + 3O_{2} + 12e^{-}
$$

阴极反应：
$$
N_{2} + 6H_{2}O + 6e^{-} \rightarrow 2NH_{3} + 6OH^{-}
$$

**解析**：
电化学合成氨的原理：
1. 阳极：OH⁻ 氧化生成 O₂
2. 阴极：N₂ 还原生成 NH₃
3. 总反应：2N₂ + 6H₂O → 4NH₃ + 3O₂

阳极反应：
- OH⁻ 失去电子
- 生成 O₂ 和 H₂O
- 12OH⁻ → 6H₂O + 3O₂ + 12e⁻

阴极反应：
- N₂ 得到电子
- 与 H₂O 反应生成 NH₃
- N₂ + 6H₂O + 6e⁻ → 2NH₃ + 6OH⁻

## 解题思路

### Step 1: 分析电化学合成氨的原理
```
电化学合成氨：
- 利用电能驱动化学反应
- 阳极：氧化反应
- 阴极：还原反应
- N₂ 在阴极被还原为 NH₃
```

### Step 2: 写出阳极反应
```
阳极：氧化反应
- OH⁻ 被氧化
- 生成 O₂ 和 H₂O
- 12OH⁻ → 6H₂O + 3O₂ + 12e⁻
```

### Step 3: 写出阴极反应
```
阴极：还原反应
- N₂ 被还原
- 与 H₂O 反应生成 NH₃
- N₂ + 6H₂O + 6e⁻ → 2NH₃ + 6OH⁻
```

### Step 4: 验证总反应
```
总反应：
阳极：12OH⁻ → 6H₂O + 3O₂ + 12e⁻
阴极：2N₂ + 12H₂O + 12e⁻ → 4NH₃ + 12OH⁻

总反应：2N₂ + 6H₂O → 4NH₃ + 3O₂
```

## 易错分析

### 常见错误 1：电极反应写反
- **错误**：将阳极和阴极反应写反
- **正确**：阳极是氧化，阴极是还原
- **教训**：阳极失电子，阴极得电子

### 常见错误 2：电子数不平衡
- **错误**：阳极和阴极电子数不相等
- **正确**：阳极失去的电子 = 阴极得到的电子
- **教训**：电荷守恒必须满足

### 常见错误 3：产物判断错误
- **错误**：认为阴极生成 N₂H₄
- **正确**：阴极生成 NH₃
- **教训**：N₂ 还原的产物是 NH₃
