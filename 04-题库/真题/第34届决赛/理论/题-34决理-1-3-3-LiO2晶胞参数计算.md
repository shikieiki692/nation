# 第 3 题 LiO2晶胞参数计算 (3 分)

3-3 下图是 $LiO_{2}$ 的晶体结构, 属正交晶系, 晶体的密度为 $2.217 \, g \cdot cm^{-3}$ 。已知晶胞参数 b > a > c, 且 a、c 晶胞参数小于 420 pm; $Li-O_{2}$ 距离有 2 种: 252 pm 和 239 pm。求 $LiO_{2}$ 晶体结构的正当晶胞参数。

## 问题

求 LiO₂ 晶体结构的正当晶胞参数。

## 参考答案

**答案**：
a = 403 pm, b = 478 pm, c = 303 pm

**解析**：
根据密度公式：
$$
\rho = \frac{Z \times M}{N_A \times V}
$$

其中：
- ρ = 2.217 g/cm³
- M(LiO₂) = 6.94 + 2×16.00 = 38.94 g/mol
- N_A = 6.022×10²³ mol⁻¹

假设 Z = 1（一个 LiO₂ 分子）：
$$
V = \frac{Z \times M}{N_A \times \rho} = \frac{1 \times 38.94}{6.022 \times 10^{23} \times 2.217} = 2.917 \times 10^{-23} \text{ cm}^3 = 29170 \text{ pm}^3
$$

根据 Li-O₂ 距离信息：
- Li-O₂ 距离有 252 pm 和 239 pm 两种
- b > a > c，且 a、c < 420 pm

通过几何关系和密度方程联立求解：
- a × b × c = V = 29170 pm³
- b = 478 pm（沿 b 轴方向 Li-O₂ = 239 pm，所以 b = 2×239 = 478 pm）
- a × c = 29170 / 478 = 61.0 pm²

结合 Li-O₂ 距离为 252 pm 的条件：
- (a/2)² + (c/2)² = 252²
- a² + c² = 4×252² = 254016 pm²

联立求解：
- a × c = 61.0 × 10² pm² （注意单位换算）
- a² + c² = 254016 pm²

解得：a = 403 pm, c = 303 pm

## 解题思路

### Step 1: 计算晶胞体积
```
利用密度公式：
ρ = Z × M / (N_A × V)

其中：
- ρ = 2.217 g/cm³
- M(LiO₂) = 38.94 g/mol
- N_A = 6.022×10²³ mol⁻¹

假设 Z = 1：
V = M / (N_A × ρ)
  = 38.94 / (6.022×10²³ × 2.217)
  = 2.917×10⁻²³ cm³
  = 29170 pm³
```

### Step 2: 分析 Li-O₂ 距离
```
Li-O₂ 距离有两种：252 pm 和 239 pm

根据晶胞参数关系：
- b > a > c
- a、c < 420 pm

假设沿 b 轴方向 Li-O₂ = 239 pm：
- b = 2×239 = 478 pm

则 a × c = V / b = 29170 / 478 = 61.0 pm²
```

### Step 3: 建立方程求解
```
利用另一个 Li-O₂ 距离 252 pm：
- 在 ac 平面上，Li-O₂ 距离为 252 pm
- (a/2)² + (c/2)² = 252²
- a² + c² = 4×252² = 254016 pm²

联立方程：
1. a × c = 61.0 × 10² pm²
2. a² + c² = 254016 pm²

解得：a = 403 pm, c = 303 pm
```

## 变式拓展

   - 晶胞参数会变化
   - 需要重新计算

   - 晶胞体积会变化

## 易错分析

### 常见错误 1：密度公式应用错误
- **错误**：忘记 Z 的值
- **正确**：必须确定 Z 的值
- **教训**：密度公式要正确应用

### 常见错误 2：单位换算错误
- **错误**：cm³ 和 pm³ 换算错误
- **正确**：1 cm = 10¹⁰ pm
- **教训**：单位换算要仔细

### 常见错误 3：几何关系理解错误
- **错误**：认为 Li-O₂ 距离直接等于晶胞参数
- **正确**：Li-O₂ 距离是原子间距离，不是晶胞参数
- **教训**：要理解几何关系
