# 第 3 题 超氧离子分子轨道 (3 分)

双氧阴离子指超氧离子和过氧离子等。含有超氧离子的化合物是氧分子的单电子还原产物，广泛存在于自然界中。

## 问题

3-1 利用分子轨道理论写出单线态 $\mathrm{O}_{2}$ 和三线态 $\mathrm{O}_{2}$ 的电子排布；写出 $\mathrm{O}_{2}$ -激发态的电子排布；比较单线态与三线态 $\mathrm{O}_{2}$ 的能量高低。

## 参考答案

**答案**：
1. 三线态 O₂（基态）：
   - 电子排布：(σ₁ₛ)²(σ₁ₛ\*)²(σ₂ₛ)²(σ₂ₛ\*)²(σ₂ₚ)²(π₂ₚ)⁴(π₂ₚ\*)²
   - π₂ₚ\* 轨道上有 2 个未成对电子
   - 自旋多重度 = 2×2+1 = 3（三重态）

2. 单线态 O₂（激发态）：
   - 电子排布：(σ₁ₛ)²(σ₁ₛ\*)²(σ₂ₛ)²(σ₂ₛ\*)²(σ₂ₚ)²(π₂ₚ)⁴(π₂ₚ\*)²
   - π₂ₚ\* 轨道上的 2 个电子配对
   - 自旋多重度 = 2×0+1 = 1（单重态）

3. O₂⁻ 激发态：
   - 电子排布：(σ₁ₛ)²(σ₁ₛ\*)²(σ₂ₛ)²(σ₂ₛ\*)²(σ₂ₚ)²(π₂ₚ)⁴(π₂ₚ\*)³
   - 比基态多一个电子在 π₂ₚ\* 轨道

4. 能量比较：
   - 单线态 O₂ 能量 > 三线态 O₂ 能量
   - 三线态是基态，更稳定

**解析**：
- O₂ 的分子轨道排布遵循能量最低原理
- π₂ₚ\* 是反键轨道，填充电子会削弱化学键
- 单线态 O₂ 中电子配对，需要克服电子排斥能
- 三线态 O₂ 中电子分占不同轨道，符合 Hund 规则

## 考点抽象

> 这道题的表面是**超氧离子分子轨道**，本质是**分子轨道理论的应用**——需要理解 O₂ 的电子排布和磁性。

**核心能力拆解**：

- **自旋多重度**：单重态和三重态的区别
- **Hund 规则**：电子在简并轨道中的排布

## 解题思路

### Step 1: 确定 O₂ 的分子轨道能级
```
O₂ 的分子轨道能级顺序：
σ₁s < σ₁s* < σ₂s < σ₂s* < σ₂p < π₂p < π₂p* < σ₂p*

注意：对于 O₂，σ₂p 能量低于 π₂p
```

### Step 2: 填充电子
```
O₂ 有 16 个电子：
- σ₁s² (2)
- σ₁s*² (2)
- σ₂s² (2)
- σ₂s*² (2)
- σ₂p² (2)
- π₂p⁴ (4)
- π₂p*² (2)

总计：16 个电子 ✓
```

### Step 3: 分析未成对电子
```
三线态 O₂（基态）：
- π₂p* 轨道上有 2 个电子
- 根据 Hund 规则，电子分占不同轨道
- 有 2 个未成对电子
- 顺磁性

单线态 O₂（激发态）：
- π₂p* 轨道上的 2 个电子配对
- 没有未成对电子
- 抗磁性
```

## 变式拓展

1. **如果考虑 O₂⁻**：
   - 多一个电子在 π₂ₚ\* 轨道
   - 有 1 个未成对电子
   - 顺磁性

2. **如果考虑 O₂²⁻**：
   - π₂ₚ\* 轨道完全填满
   - 没有未成对电子
   - 抗磁性

## 易错分析

### 常见错误 1：能级顺序错误
- **错误**：认为 π₂ₚ 能量低于 σ₂ₚ
- **正确**：对于 O₂，σ₂ₚ 能量低于 π₂ₚ
- **教训**：不同原子的分子轨道能级不同

### 常见错误 2：Hund 规则应用错误
- **错误**：认为电子会配对填充
- **正确**：简并轨道中电子优先分占
- **教训**：Hund 规则很重要

### 常见错误 3：自旋多重度计算错误
- **错误**：认为单线态能量更低
- **正确**：三线态是基态，能量更低
- **教训**：基态是最稳定的状态
