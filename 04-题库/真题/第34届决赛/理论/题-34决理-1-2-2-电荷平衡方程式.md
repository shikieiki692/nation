# 第 2 题 电荷平衡方程式 (2 分)

2-2 写出传感器微池内溶液的电荷平衡方程式。

## 问题

写出传感器微池内溶液的电荷平衡方程式。

## 参考答案

**答案**：
$$
[ \mathrm{Na} ^ {+} ] + [ \mathrm{H} ^ {+} ] = [ \mathrm{HCO} _ {3} ^ {-} ] + 2 [ \mathrm{CO} _ {3} ^ {2 -} ] + [ \mathrm{HIn} ^ {-} ] + 2 [ \mathrm{In} ^ {2 -} ] + [ \mathrm{OH} ^ {-} ]
$$

**解析**：
溶液中存在的离子：
- 阳离子：Na⁺, H⁺
- 阴离子：HCO₃⁻, CO₃²⁻, HIn⁻, In²⁻, OH⁻

电荷平衡原则：
- 溶液电中性
- 正电荷总数 = 负电荷总数

各离子的电荷贡献：
- Na⁺：+1
- H⁺：+1
- HCO₃⁻：-1
- CO₃²⁻：-2（所以系数为2）
- HIn⁻：-1
- In²⁻：-2（所以系数为2）
- OH⁻：-1

## 考点抽象

> 这道题的表面是**电荷平衡方程式**，本质是**溶液电中性原理的应用**——需要根据溶液中存在的所有离子写出电荷平衡方程式。

**核心能力拆解**：

## 解题思路

### Step 1: 识别溶液中的离子
```
传感器微液池中的物质：
- NaHIn（指示剂）→ Na⁺ + HIn⁻
- NaOH → Na⁺ + OH⁻
- CO₂ 进入后形成：
  - H₂CO₃ → H⁺ + HCO₃⁻
  - HCO₃⁻ → H⁺ + CO₃²⁻
- 水的解离：
  - H₂O → H⁺ + OH⁻

存在的离子：
- 阳离子：Na⁺, H⁺
- 阴离子：HCO₃⁻, CO₃²⁻, HIn⁻, In²⁻, OH⁻
```

### Step 2: 写出电荷平衡方程式
```
电荷平衡原则：
溶液中所有正电荷的总浓度等于所有负电荷的总浓度。

方程式：
[Na⁺] + [H⁺] = [HCO₃⁻] + 2[CO₃²⁻] + [HIn⁻] + 2[In²⁻] + [OH⁻]

注意：
- CO₃²⁻ 带 2 个负电荷，系数为 2
- In²⁻ 带 2 个负电荷，系数为 2
```

## 变式拓展

1. **如果溶液中还有其他离子**：
   - 如 K⁺、Cl⁻ 等
   - 需要在方程式中加入相应项

2. **如果指示剂有不同的解离形式**：
   - 如 H₂In ⇌ H⁺ + HIn⁻
   - 需要考虑 H₂In 的浓度

## 易错分析

### 常见错误 1：遗漏离子
- **错误**：忘记 OH⁻ 或 H⁺
- **正确**：必须考虑所有存在的离子
- **教训**：溶液电中性是普遍原理

### 常见错误 2：电荷系数错误
- **错误**：CO₃²⁻ 的系数写成 1
- **正确**：CO₃²⁻ 带 2 个负电荷，系数为 2
- **教训**：必须考虑离子的电荷数

### 常见错误 3：物种形式错误
- **错误**：将 HIn⁻ 写成 HIn
- **正确**：HIn⁻ 是离子形式
- **教训**：注意物种的存在形式
