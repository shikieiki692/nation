# 第 3 题 超氧化物晶体结构 (4 分)

3-2 下列三个图 A、B、C 是 Na 或 K 的超氧化合物的晶体结构示意图（大球表示金属原子，小球表示氧原子），写出每个晶体结构的结构基元和点阵。已知 $NaO_{2}$ 属于立方晶系， $KO_{2}$ 属于四方晶系。

## 问题

写出每个晶体结构的结构基元和点阵。

![[715112cca430eb3f8b6021ed85acb270b14aadb75e692b517799e6d4949017fa.jpg]]

## 参考答案

**答案**：
A（NaO₂，立方晶系）：
- 结构基元：Na⁺ 和 O₂⁻
- 点阵：简单立方点阵

B（KO₂，四方晶系）：
- 结构基元：K⁺ 和 O₂⁻
- 点阵：体心四方点阵

C（可能是 CsO₂）：
- 结构基元：Cs⁺ 和 O₂⁻
- 点阵：需要根据具体结构判断

**解析**：
1. NaO₂ 的结构：
   - 立方晶系
   - Na⁺ 和 O₂⁻ 交替排列
   - 简单立方点阵

2. KO₂ 的结构：
   - 四方晶系
   - K⁺ 和 O₂⁻ 交替排列
   - 体心四方点阵

3. 结构基元的确定：
   - 结构基元是晶体中重复的最小单元
   - 包含一个阳离子和一个阴离子

## 考点抽象

> 这道题的表面是**超氧化物晶体结构**，本质是**晶体结构分析**——需要根据晶体结构图确定结构基元和点阵类型。

**核心能力拆解**：
- **晶体结构识别**：从结构图中识别原子排列
- **结构基元确定**：找出重复的最小单元
- **点阵类型判断**：确定晶系和点阵类型

## 解题思路

### Step 1: 分析 A 的结构
```
A 是 NaO₂ 的晶体结构：
- 立方晶系
- Na⁺ 和 O₂⁻ 交替排列
- 每个 Na⁺ 周围有 6 个 O₂⁻
- 每个 O₂⁻ 周围有 6 个 Na⁺

结构基元：Na⁺ + O₂⁻
点阵类型：简单立方点阵
```

### Step 2: 分析 B 的结构
```
B 是 KO₂ 的晶体结构：
- 四方晶系
- K⁺ 和 O₂⁻ 交替排列
- 体心位置有一个原子

结构基元：K⁺ + O₂⁻
点阵类型：体心四方点阵
```

### Step 3: 分析 C 的结构
```
C 可能是 CsO₂ 的结构：
- 需要根据具体结构判断
- 结构基元：Cs⁺ + O₂⁻
- 点阵类型：需要分析
```

## 变式拓展

1. **如果改变金属离子**：
   - 不同金属离子半径不同
   - 晶体结构可能变化
   - 点阵类型可能改变

2. **如果改变温度或压力**：
   - 可能发生相变
   - 晶系可能改变
   - 需要重新分析

3. **与往届真题的关联**：

## 易错分析

### 常见错误 1：结构基元确定错误
- **错误**：认为结构基元只包含一个原子
- **正确**：结构基元包含一个阳离子和一个阴离子
- **教训**：结构基元是重复的最小单元

### 常见错误 2：点阵类型判断错误
- **错误**：认为所有立方晶系都是简单立方
- **正确**：需要根据原子位置判断
- **教训**：点阵类型由原子排列决定

### 常见错误 3：晶系判断错误
- **错误**：混淆立方和四方晶系
- **正确**：根据晶胞参数判断
- **教训**：晶系由晶胞参数决定
