# 第 7 题 选择题综合 (14 分)

7-1 下面 3 种共轭二烯与丙烯腈发生 Diels-Alder 反应速率最快的是____。

7-2 下面 2 种内酰胺在碱性条件下水解的反应速率较快的是____。

7-3 如下二烯烃与间氯过氧苯甲酸（mCPBA）发生环氧化反应的主要产物是____。

（以下省略具体题目内容，共14道选择题）

## 参考答案

**答案**：
7-1：B（富电子二烯反应最快）
7-2：A（张力较大的内酰胺水解更快）
7-3：C（立体选择性环氧化）
...（其他题目答案略）

**解析**：
7-1：
- Diels-Alder 反应是 [4+2] 环加成
- 二烯体富电子有利于反应
- 取代基的电子效应影响反应速率

7-2：
- 内酰胺水解是亲核加成-消除机理
- 张力较大的内酰胺更容易水解
- 环张力是主要影响因素

7-3：
- mCPBA 环氧化是立体选择性反应
- 从位阻较小的一侧进攻
- 得到主要产物

## 解题思路

### 7-1: Diels-Alder 反应速率
```
Diels-Alder 反应特点：
- [4+2] 环加成
- 二烯体 + 亲双烯体
- 立体专一性

影响因素：
- 二烯体的电子密度
- 亲双烯体的电子密度
- 立体位阻

富电子二烯反应最快
```

### 7-2: 内酰胺水解速率
```
内酰胺水解机理：
- 亲核加成-消除
- OH⁻ 进攻羰基碳
- 形成四面体中间体

影响因素：
- 环张力
- 取代基效应
- 溶剂效应

张力较大的内酰胺水解更快
```

### 7-3: 环氧化反应
```
mCPBA 环氧化：
- 协同机理
- 立体选择性
- 从位阻较小的一侧进攻

产物：
- 保持烯烃的构型
- 得到环氧化物
```

## 易错分析

### 常见错误 1：Diels-Alder 反应理解错误
- **错误**：认为是 [2+2] 环加成
- **正确**：是 [4+2] 环加成
- **教训**：必须分析反应的立体电子效应

### 常见错误 2：内酰胺水解理解错误
- **错误**：认为是消除反应
- **正确**：是亲核加成-消除
- **教训**：水解机理要正确

### 常见错误 3：环氧化立体化学错误
- **错误**：认为产物是消旋的
- **正确**：环氧化是立体选择性的
- **教训**：mCPBA 环氧化保持构型
