# 题-CM-48-08-脂类物质的氧化是油脂保存过程

## 题目

### 第 8 题 自由基氧化（15 分，占 8%）

脂类物质的氧化是油脂保存过程中广泛存在的问题。 亚油酸乙酯 （记为RH） 的氧化过程属於自由基氧化反应， 其中H代表最可能发生氧化反应的氢原子。 反应方程式如下：

$$
\mathbf { RH } + \mathbf { O } _{ 2 } \to \mathbf { ROOH }
$$

8-1 亚油酸的学名是(9Z,12Z)-9,12-十八碳二烯酸， 画出亚油酸乙酯的结构式， 并用 “…” 标记最可能发生自由基氧化反应的氢原子。

8-2 实验测得反应的速率方程如下：

$$
