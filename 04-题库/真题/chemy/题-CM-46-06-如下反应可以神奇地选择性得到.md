## 6-1 共 5 分

速率方程为

$$
r = k _{\mathrm{obs}} [ \text { alkenylTT } ] [ i - \mathrm{Pr} _{2} \mathrm{NEt} ] (2 \text { 分 })
$$

由于 PhNHMe 浓度与反应速率无关，可知在[alkenylTT] = 0.0917 M, $[i-Pr_{2}NEt] = 0.4587$ M 时，r = 1.5619 mM/min。（1 分）

因此表观速率常数为

$$
k _{\mathrm{obs}} = r / [ \text { alkenylTT } ] [ i - \mathrm{Pr} _{2} \mathrm{NEt} ] = 3.7 \times 10^{- 2} \mathrm{M} ^{- 1} \min ^{- 1} (2 \text { 分 })
$$

6-2 共 6 分

![](images/aeb663a14e9ba77195ae88b9b4230b62c85285d0d75a3d2fa2b2f1f95f5dd63d.jpg)

每步基元反应均不可逆。

每步基元反应 1 分，可逆性判断共 2 分，答错/少答/多答一处扣 1 分。

认为最后一步质子转移可逆亦可。

6-3 共 3 分

反应的决速步为第一步去质子。（2分）

控制区域选择性的步骤为第一步去质子。（1 分）

6-4 共 3 分

双键转移：在产物中低能 $\pi(\mathrm{C}-\mathrm{C})$ 与 $\sigma^{*}(\mathrm{C}-\mathrm{S}^{+})$ 的负超共轭强于底物中 $\sigma(\mathrm{C}-\mathrm{C})$ 与 $\sigma^{*}(\mathrm{C}-\mathrm{S}^{+})$ 的负超共轭。（2 分）

认为依靠第三步亲核取代反应不可逆性驱动亦可得分。

亲核进攻：C-N 键强于 C-S $^{+}$ 键。（1 分）
