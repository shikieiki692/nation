## 参考答案

4-1 (共3分）

由布拉格公式 $2 \mathrm { d } \sin \theta = n \lambda$ e (010) 晶面对应 $\mathcal { A } _{ ( 010 ) }$ 及 $\scriptstyle \mathbf { n } = 1$
$b = d _{ 010 } ) = \lambda / ( 2 \sin \theta ) = 0.9153 ~ \mathrm { nm }$ 1分则 $V_{\text{晶胞}}=abc\sin\beta=1.830\ \mathrm{nm^3}$ 1分由 $\nu _{ r o c e } = 0.91125 \mathrm { nm } ^{ 3 } ,$ . 则 $\nu _{ \mathrm { { as } } } / V _{ \mathrm { { \eta mete } } } = 2.01 \approx 2$
二者常温常压下密度近似相同， $\rho = \frac { z M } { N _{ A } V }$
则 $Z r o c e = Z _{ \pi e } / 2 = 42$ e 即纤维红磷正当晶胞中含42个磷原子。 1分或者： $Z _{ \mathrm { \# eten } } = Z _{ \mathrm { \# ea } / 2 , 01 } = 41.8 ~ \mathrm { \simeq } 12$ 也对。
