# 题-CM-48-05-向含有少量酚酞指示剂的水溶液

## 题目

### 第 5 题 甲醛时钟（13 分，占 7%）

向含有少量酚酞指示剂的水溶液中加入亚硫酸钠 ( $\mathbf { \ Na } _{ 2 } \mathbf { SO } _{ 3 } )$ )、 亚硫酸氢钠（$\mathrm{NaHSO_3}$） 和甲醛(HCHO)。 经过一段时间后， 溶液由无色突变为紫红色。 发生该颜色突变所需的时间由上述三种试剂的初始浓度决定， 因此， 该体系被称为 “甲醛时钟”。

注： 本题中温度为 $298.15 \mathrm { ~ K ~ }$ . 溶液充分混匀， 不考虑甲醛的水合反应。 解题时可采取的近似原则为： 如果 $x > 50 y$ . 则 $x + y$ 可近似为 $_ x$ 。

5-1 在中性水溶液中， 甲醛可以与亚硫酸氢根 ($\mathrm{HSO_3^-}$) 或亚硫酸根 ( $\mathrm{SO_3^{2-}}$ ） 发生反应， 生成一种酸性和碱性都很弱的一价负离子。 分别写出甲醛与亚硫酸氢根反应、 甲醛与亚硫酸根反应生成该一价负离子的离子方程式。

5-2 亚硫酸的第一级酸电离反应平衡常数 $K_a(\mathrm{H_2SO_3})=1.2\times10^{-2}\ \mathrm{mol\cdot dm^{-3}}$。为了计算亚硫酸的第二级酸电离反应平衡常数 $K_2(\mathrm{HSO_3^-})$，将 $1.0\times10^{-3}\ \mathrm{mol}\ \mathrm{NaHSO_3}$ 和 $1.0\times10^{-3}\ \mathrm{mol}\ \mathrm{Na_2SO_3}$ 溶于水并定容至 $1.0\ \mathrm{dm^3}$，测得该溶液 pH 值为 5.36。

5-2-1 列出上述溶液的物料平衡方程式 （亚硫酸的各形态） 与电荷平衡方程式。

5-2-2 计算上述溶液的亚硫酸根平衡浓度[$\mathrm{SO_3^{2-}}$]与亚硫酸氢根平衡浓度[$\mathrm{HSO_3^-}$]。
5-2-3 计算 $K_2(\mathrm{HSO_3^-})$。

5-3 甲醛与亚硫酸氢根反应的速率常数 $k(\mathrm{HSO_3^-})=4.5\times10^{-3}\ \mathrm{dm^3\cdot mol^{-1}\cdot s^{-1}}$，甲醛与亚硫酸根反应的速率常数 $k(\mathrm{SO_3^{2-}})=54\ \mathrm{dm^3\cdot mol^{-1}\cdot s^{-1}}$。酸碱电离和酸碱中和反应的速率很大，可认为是瞬时反应。某个甲醛时钟体系的各组分初始浓度分别为：甲醛 $0.10\ \mathrm{mol\cdot dm^{-3}}$、亚硫酸氢钠 $a=0.10\ \mathrm{mol\cdot dm^{-3}}$、亚硫酸钠 $c(\mathrm{Na_2SO_3})=0.010\ \mathrm{mol\cdot dm^{-3}}$。

5-3-1 该甲醛时钟初期阶段 （溶液 $\mathrm{pH} \leq 8.20$ ) 的甲醛消耗速率 $\nu ( { \mathrm { HCHO } } )$ 与甲醛平衡浓度[HCHO]近似成正比， 即经过合理近似后， $\nu ( { \mathrm { HCHO } } ) = a [ { \mathrm { HCHO } } ]$ . 其中 $a$ 为常量。 列出 $a$ 的计算式并算出 $a$ 的数值。

5-3-2 该甲醛时钟初期阶段的 $\mathrm{pH}$ 值随时间 $^{ \prime }$ 近似线性增加， 即经过合理近似后， $\mathrm{dpH}/\mathrm{d}t=b$ . 其中 $b$ 为常量。 列出 $b$ 的计算式并算出 $b$ 的数值。

微分公式 （其中 $m$ 为常数， $^ c \Theta$ 为标准浓度 $1.0 ~ \mathrm { mol } \cdot \mathrm { d } \mathrm { m } ^{ - 3 }$ ):

$$
\frac{\mathrm{d}\left(m[\mathrm{H^+}]\right)}{\mathrm{d}t}=\frac{m\,\mathrm{d}[\mathrm{H^+}]}{\mathrm{d}t}
$$

$$
\frac{\mathrm{d}\mathrm{pH}}{\mathrm{d}t}=\frac{\mathrm{d}\left[-\lg\left([\mathrm{H^+}]/c^\ominus\right)\right]}{\mathrm{d}t}=-\frac{1}{\ln 10\cdot[\mathrm{H^+}]}\frac{\mathrm{d}[\mathrm{H^+}]}{\mathrm{d}t}
$$

5-3-3 已知存在下列平衡 （其中 $\mathrm{A^-}$ 为甲醛与亚硫酸氢根或亚硫酸根的反应产物）：

$$
\begin{array}{r} \mathrm{A^-(aq)} \rightleftharpoons \mathrm{HCHO(aq)} + \mathrm{HSO_3^-(aq)} \end{array}
$$

该反应的经验平衡常数 $K(\mathrm{A^-})=1.2\times10^{-7}\ \mathrm{mol\cdot dm^{-3}}$。该甲醛时钟达到颜色突变点时，溶液计算此时的 [HCHO]。

## 参考答案

5-1 （共2分） 该一价负离子为：$\mathrm{HOCH_2SO_3^-}$
甲醛与亚硫酸氢根的反应方程式为：$\mathrm{HCHO}+\mathrm{HSO_3^-}\rightarrow\mathrm{HOCH_2SO_3^-}$（1分）
甲醛与亚硫酸根的反应方程式为：$\mathrm{HCHO}+\mathrm{SO_3^{2-}}\rightarrow\mathrm{^-OCH_2SO_3^-}$ $\mathrm{H_2O}+\mathrm{^-OCH_2SO_3^-}\rightarrow\mathrm{HOCH_2SO_3^-}+\mathrm{HO^-}$（1分）
注1： 甲醛与亚硫酸根的反应合写为下列一步， 也可得分：$\mathrm { HCHO } + \mathrm { SO _{ 3 } ^{ 2 - } } + \mathrm { H _{ 2 } O }  \mathrm { HOCH _{ 2 } SO _{ 3 } ^{ - } } + \mathrm { HO ^{ - } }$
注2： 上述所有方程式写成 $\mathrm{Na}$ 盐的形式也可得分

5-2-1 （共2分）

物料守恒：$\mathrm{[H_2SO_3]+[HSO_3^-]+[SO_3^{2-}]=c(NaHSO_3)+c(Na_2SO_3)}$（1分）

电荷守恒：$\mathrm{[H^+]+[Na^+]=[OH^-]+[HSO_3^-]+2\times[SO_3^{2-}]}$（1分）

注1：将其中 $c(\mathrm{NaHSO_3})+c(\mathrm{Na_2SO_3})$ 表示为数值 $1.0\times10^{-3}\ \mathrm{mol\cdot dm^{-3}}$ 或 $1.01\times10^{-3}\ \mathrm{mol\cdot dm^{-3}}$，也可得分；

注2： 写出下列近似后的平衡，也可得分，但需写出近似处理的依据：$[\mathrm{HSO_3^-}]\gg[\mathrm{SO_3^{2-}}]$，所以：$\mathrm{[HSO_3^-]+[SO_3^{2-}]=c(NaHSO_3)+c(Na_2SO_3)}$；$[\mathrm{H^+}]\gg[\mathrm{OH^-}]$，所以：$\mathrm{[H^+]+[Na^+]=[HSO_3^-]+2\times[SO_3^{2-}]}$

5-2-2 (共2分）

$[\mathrm{SO_3^{2-}}]=1.4\times10^{-5}\ \mathrm{mol\cdot dm^{-3}}$（1分）$[\mathrm{HSO_3^-}]=1.0\times10^{-3}\ \mathrm{mol\cdot dm^{-3}}$（1分）

注：$[\mathrm{SO_3^{2-}}]$算成 $1.3\times10^{-5}$ 或 $1.5\times10^{-5}\ \mathrm{mol\cdot dm^{-3}}$，也可得分，但有效数字必须是两位

5-2-3 (1分）

$\mathrm { Ka } ( \mathrm { HSO _{ 3 } ^{ - } } ) = 6.2 \times 10^{ - 8 } ~ \mathrm { mol } \cdot \mathrm { dm } ^{ - 3 }$ (1分）算成 $6.1\times10^{-8}$ 或 $6.3\times10^{-8}$ mol·dm⁻³, 也可得分， 但有效数字必须是两位

5-3-1 （共2分）

甲醛消耗总速率：$\nu(\mathrm{HCHO})=k(\mathrm{SO_3^{2-}})\mathrm{c}(\mathrm{Na_2SO_3})[\mathrm{HCHO}]$

$a=k(\mathrm{SO_3^{2-}})\mathrm{c}(\mathrm{Na_2SO_3})$（1分）

带入数值计算 $a=0.54\ \mathrm{s^{-1}}$ （1分）

注1： $a=0.54\ \mathrm{s^{-1}}$ . 不带 $\mathrm{s^{-1}}$ 单位也可得分；
注2：数值运算结果 0.54 算成 0.53 或 0.55，也可得分，但有效数字必须是两位

注3：答案写上负号，表示消耗，也可得分；

5-3-2 (共2分）

$\dfrac{\mathrm{dpH}}{\mathrm{d}t}=k(\mathrm{SO_3^{2-}})\,c(\mathrm{Na_2SO_3})/\ln 10$
$b=k(\mathrm{SO_3^{2-}})\,c(\mathrm{Na_2SO_3})/\ln 10$ (1分）
带入数值计算 $\mathbf { b } = 0.23 \ \mathrm { s } ^{ - 1 }$ (1分）
注1： $\mathbf { b } = \mathbf { 0.23 \ s ^{ - 1 } }$ ，不带 $\mathrm{s^{-1}}$ 单位也可得分：
注2： 数值运算结果 0.23 算成0.22或0.24, 也可得分， 但有效数字必须是两位

5-3-3 (2分）

$[\mathrm{HCHO}]=1.2\times10^{-4}\ \mathrm{mol\cdot dm^{-3}}$（2分）

注： 算成 $1.1\times10^{-4}$ 或 $1.3 \times 10^{ - 4 }$ mol·dm⁻³, 也可得分， 但有效数字必须是两位
