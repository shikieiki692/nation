## 7-2-5-1 共9分

Z-P1 的极性较大，因而会较先洗脱出来，从而可知 Peak 1 对应 Z-P1；而 E-P1 正好相反，因此 Peak 2 对应 E-P1。（1 分）

由面积比，

$$
[ Z ] = 100 \mu \mathrm{M} \times 192536 / (192536 + 22068) = 89.717 \mu \mathrm{M} (\text {1分})
$$

同理，

$$
[ E ] = 100 \mu \mathrm{M} \times 22068 / (192536 + 22068) = 10.283 \mu \mathrm{M} (\text {1分})
$$

在撤去光源后 Z-P1 向 E-P1 的转化过程浓度关系符合一级反应动力学特征，从而

$$
k = \ln 2 / t _{1 / 2} = 1.53 \times 10^{- 3} \mathrm{min} ^{- 1} = 2.56 \times 10^{- 5} \mathrm{s} ^{- 1} (1 \text {分})
$$

因此有

$$
n (\text { photon }) _{\text { absorb }} = k \times [ Z ] \times V = 4.59 \times 10^{- 12} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (1 \text { 分 })
$$

根据吸光度与透光率的关系 $A = -\lg T$ ，有

$$
\mathrm{T} = 10^{\wedge} (- \varepsilon d [ E ]) = 0.75267
$$

从而

$$
n (\text { photon }) _{\text { theoretical }} = n (\text { photon }) _{\text { absorb }} / (1 - \mathrm{T}) = 1.85 \times 10^{- 11} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (2 \text { 分 })
$$

而根据功率，

$$
n (\text { photon }) _{\text { actual }} = \mathrm{W} \lambda / (h c _{0} N _{\mathrm{A}}) = 7.47 \times 10^{- 8} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (1 \text { 分 })
$$

因此

$$
I = n (\text { photon }) _{\text { theoretical }} / n (\text { photon }) _{\text { actual }} \times 100 \% = 0.025 \% \quad (1 \text { 分 })
$$

本问不要求有效数字。若计算时 k 取 $0.002 \, min^{-1}$ 得到 $I = 0.033\%$ , 整体扣 2 分。

Z-P1 的极性较大，因而会较先洗脱出来，从而可知 Peak 1 对应 Z-P1；而 E-P1 正好相反，因此 Peak 2 对应 E-P1。（1 分）

由面积比，

$$
[ Z ] = 100 \mu \mathrm{M} \times 192536 / (192536 + 22068) = 89.717 \mu \mathrm{M} (\text {1分})
$$

同理，

$$
[ E ] = 100 \mu \mathrm{M} \times 22068 / (192536 + 22068) = 10.283 \mu \mathrm{M} (\text {1分})
$$

在撤去光源后 Z-P1 向 E-P1 的转化过程浓度关系符合一级反应动力学特征，从而

$$
k = \ln 2 / t _{1 / 2} = 1.53 \times 10^{- 3} \mathrm{min} ^{- 1} = 2.56 \times 10^{- 5} \mathrm{s} ^{- 1} (1 \text {分})
$$

因此有

$$
n (\text { photon }) _{\text { absorb }} = k \times [ Z ] \times V = 4.59 \times 10^{- 12} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (1 \text { 分 })
$$

根据吸光度与透光率的关系 $A = -\lg T$ ，有

$$
\mathrm{T} = 10^{\wedge} (- \varepsilon d [ E ]) = 0.75267
$$

从而

$$
n (\text { photon }) _{\text { theoretical }} = n (\text { photon }) _{\text { absorb }} / (1 - \mathrm{T}) = 1.85 \times 10^{- 11} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (2 \text { 分 })
$$

而根据功率，

$$
n (\text { photon }) _{\text { actual }} = \mathrm{W} \lambda / (h c _{0} N _{\mathrm{A}}) = 7.47 \times 10^{- 8} \mathrm{mol} \cdot \mathrm{s} ^{- 1} (1 \text { 分 })
$$

因此

$$
I = n (\text { photon }) _{\text { theoretical }} / n (\text { photon }) _{\text { actual }} \times 100 \% = 0.025 \% \quad (1 \text { 分 })
$$

本问不要求有效数字。若计算时 k 取 $0.002 \, min^{-1}$ 得到 $I = 0.033\%$ , 整体扣 2 分。
