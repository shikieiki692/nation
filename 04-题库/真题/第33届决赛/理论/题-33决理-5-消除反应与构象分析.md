# 第 5 题 消除反应与构象分析 (20 分)

在碱性条件下，化合物A和B中有一个发生消除反应生成C。

## 问题

(1) 指出发生消除反应生成C的是哪一个化合物_____。简述理由_________。

(2) 在同样的反应条件下，另一个化合物发生消除反应生成D，D可使酸性KMnO4溶液褪色，但不与LiAlH4发生反应。画出D的结构简式__________。

(3) 画出化合物B的优势构象_______；用*标记处化合物B中的不对称碳原子，并说明R、S构型________。

## 参考答案

**答案**：
(1) 化合物A发生消除反应生成C
理由：从构象分析，A中H与Br处于反式共平面的位置，可以发生E2消除；B中H和Br处于顺式，不能发生E2消除

(2) 化合物D的结构：环烯烃（消除后形成双键）

(3) 化合物B的优势构象：Newman投影式表示
不对称碳原子的R/S构型：需要根据CIP规则判断

**解析**：
(1) E2消除的立体化学要求：
- H和Br必须处于反式共平面（anti-periplanar）
- 这样才能形成有效的轨道重叠
- 化合物A满足这个要求
- 化合物B中H和Br是顺式，不满足E2消除的立体化学要求

(2) 化合物D的性质分析：
- 可使酸性KMnO4褪色：说明有双键（烯烃）
- 不与LiAlH4反应：说明没有可还原的官能团（如羰基）
- 结论：D是环烯烃

(3) 构象分析：
- 优势构象是能量最低的构象
- 需要考虑立体位阻和电子效应
- 不对称碳原子的构型需要根据CIP规则判断

## 解题思路

### Step 1: E2消除的立体化学要求
```
E2消除的必要条件：
- H和Br必须处于反式共平面（anti-periplanar）
- 这样H-C-C-Br的二面角为180°
- 形成有效的σ*轨道重叠

化合物A：
- H和Br处于反式位置
- 满足E2消除的立体化学要求
- 可以发生消除反应

化合物B：
- H和Br处于顺式位置
- 不满足E2消除的立体化学要求
- 不能发生E2消除
```

### Step 2: 化合物D的结构推断
```
性质分析：
1. 使酸性KMnO4褪色 → 有双键（烯烃）
2. 不与LiAlH4反应 → 没有可还原的官能团

结论：
- D是环烯烃
- 消除反应形成C=C双键
- 没有羰基等可还原基团
```

### Step 3: 构象分析与R/S构型
```
优势构象判断：
- 考虑立体位阻（大基团处于对位交叉式）
- 考虑电子效应（偶极-偶极相互作用）
- 选择能量最低的构象

R/S构型判断：
1. 确定不对称碳原子
2. 按CIP规则排列四个基团的优先级
3. 观察从最低优先级到最高优先级的排列方向
4. 顺时针为R，逆时针为S
```

## 变式拓展

1. **如果改变碱的强度**：
   - 强碱（如t-BuOK）：E2消除为主
   - 弱碱（如EtOH）：E1消除为主
   - 产物的区域选择性不同

2. **如果改变离去基团**：
   - 用I代替Br：离去能力更强
   - 反应速率更快
   - 可能改变产物分布

## 易错分析

### 常见错误 1：E2消除立体化学要求错误
- **错误**：认为H和Br可以是任意空间位置
- **正确**：必须是反式共平面
- **教训**：E2消除有严格的立体电子效应要求

### 常见错误 2：优势构象判断错误
- **错误**：只考虑立体位阻，忽略电子效应
- **正确**：需要综合考虑立体位阻和电子效应
- **教训**：构象分析需要全面考虑各种因素

### 常见错误 3：R/S构型判断错误
- **错误**：基团优先级排列错误
- **正确**：必须严格按照CIP规则
- **教训**：R/S构型判断需要仔细分析

### 常见错误 4：产物结构推断错误
- **错误**：认为消除产物总是烯烃
- **正确**：需要根据具体反应条件判断
- **教训**：不同条件下可能有不同的消除方式

### 常见错误 5：反应机理混淆
- **错误**：认为E1和E2消除的立体化学要求相同
- **正确**：E1消除没有立体化学要求
- **教训**：必须区分E1和E2消除的机理
