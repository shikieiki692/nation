# 第 7 题 变压吸附制氧机 (15 分)

目前家用小型制氧机大多以变压吸附方式工作，其原理是以空气为原料，在加压时吸附剂将空气中大部分氮气吸附，氧气和未被吸附的少量氮气被收集起来，得到富氧空气。被吸附的氮气在减压条件下通过尾气管排至大气。某小型家用常压制氧机的标称参数为额定功率100W，输出富氧空气中氧气浓度91%(体积分数)，输出富氧空气流量为1.8L·min-1，工作温度为25°C。以空气进气量10mol为对象，计算达到分离效果所需要的最小能量以及该家用制氧机的能量效率_______、______。空气由体积分数为20%的氧气和80%的氮气组成，排出的尾气中只有氮气。所有气体均视作理想气体。

## 参考答案

**答案**：
(1) 最小能量：13 kJ
(2) 能量效率：7.1%

**解析**：
(1) 熵变计算：
- 空气组成：O2 20%，N2 80%
- 进气量：10 mol（2 mol O2，8 mol N2）
- 富氧空气：O2浓度91%，流量1.8 L/min
- 尾气：纯N2

计算过程：
- 富氧空气中：n(O2)/[n(O2)+n(N2)] = 91%
- O2 全部进入富氧空气：n(O2) = 2 mol
- 富氧空气中 n(N2)：2/(2+x) = 0.91 → x ≈ 0.2 mol
- 富氧空气总量：2.2 mol
- 尾气（纯N2）：8 − 0.2 = 7.8 mol

熵变：
ΔS = n(N2,尾气)Rln(n(N2,尾气)/n(空气)) + n(富氧)Rln(n(富氧)/n(空气))

代入数据：
ΔS = 7.8×8.314×ln(7.8/10) + 2.2×8.314×ln(2.2/10)
ΔS = -43.8 J·K^-1

Gibbs自由能变化：
ΔG = -TΔS = -(25+273.15)×(-43.8) = 13 kJ

(2) 能量效率计算：
- 富氧空气体积：V = nRT/p = 2.2 × 8.314 × 298.15 / 100000 = 0.0545 m³ ≈ 55 L
- 机器运转时间：t = V/(流量) = 55L / 1.8L/min = 30.6 min = 1833 s
- 供给总能量：Q = 功率×时间 = 100W × 1833s = 183 kJ
- 能量效率：η = W/Q = 13kJ / 183kJ = 7.1%

## 解题思路

### Step 1: 物料守恒计算
```
进气组成：
- 总量：10 mol
- O2：10 × 20% = 2 mol
- N2：10 × 80% = 8 mol

富氧空气组成：
- O2浓度：91%（体积分数）
- 流量：1.8 L/min

设富氧空气中：
- O2：x mol
- N2：y mol

O2 全部进入富氧空气（尾气为纯N2）：
x = 2 mol
x/(x+y) = 0.91 → y = 2×(1-0.91)/0.91 ≈ 0.2 mol

物料守恒：
n(N2,尾气) = 8 - 0.2 = 7.8 mol

结论：
- 富氧空气：2.2 mol（2 mol O2 + 0.2 mol N2）
- 尾气（纯N2）：7.8 mol
```

### Step 2: 熵变计算
```
理想气体分离的熵变（将两个产物股流视为整体）：

对于N2（尾气，7.8 mol）：
ΔS(N2,尾气) = 7.8 × 8.314 × ln(7.8/10)

对于富氧空气（O2+N2，共2.2 mol）：
ΔS(富氧) = 2.2 × 8.314 × ln(2.2/10)

总熵变：
ΔS = ΔS(N2,尾气) + ΔS(富氧)
ΔS = 7.8×8.314×ln(7.8/10) + 2.2×8.314×ln(2.2/10)
ΔS = -43.8 J·K^-1
```

### Step 3: Gibbs自由能计算
```
最小能量 = ΔG = -TΔS
T = 25°C = 298.15 K
ΔG = -298.15 × (-43.8) = 13 kJ
```

### Step 4: 能量效率计算
```
分离 10 mol 空气所得富氧空气（2.2 mol）在 1 atm、298.15 K 下的体积：
V = nRT/p = 2.2 × 8.314 × 298.15 / 100000 = 0.0545 m³ ≈ 55 L

机器运转时间（按富氧空气流量 1.8 L/min 计）：
t = 55 / 1.8 = 30.6 min = 1833 s

供给总能量：
Q = 功率 × 时间 = 100 W × 1833 s = 183 kJ

能量效率：
η = W_min/Q = 13 kJ / 183 kJ = 7.1%
```

## 变式拓展

1. **如果改变氧气浓度要求**：
   - 更高浓度（如95%）：需要更多能量
   - 更低浓度（如80%）：需要较少能量
   - 能量效率会变化

2. **如果改变吸附材料**：
   - 不同吸附剂的选择性不同
   - 可能改变能量效率
   - 影响设备成本

## 易错分析

### 常见错误 1：物料守恒计算错误
- **错误**：把富氧空气中 O2 的物质的量当作 9.1 mol（误以为富氧空气总量为 10 mol）
- **正确**：输入 10 mol 空气中 O2 只有 2 mol，O2 全部进入富氧空气；富氧空气中 N2 仅为 0.2 mol，尾气为 7.8 mol 纯 N2
- **教训**：物料守恒必须从输入组成出发，不能凭空放大 O2 的量

### 常见错误 2：熵变公式应用错误
- **错误**：直接把富氧空气中 O2 和 N2 分开各算一项 ln(V/V总)
- **正确**：按官方标准解法，把富氧空气作为一个整体股流计算熵变；也可以拆分计算但须注意分压关系
- **教训**：混合物的熵变需要明确"股流"的划分方式

### 常见错误 3：温度单位错误
- **错误**：直接用25°C计算
- **正确**：必须用开尔文温度（298.15 K）
- **教训**：热力学计算必须用绝对温度

### 常见错误 4：能量效率定义错误
- **错误**：认为能量效率是100%
- **正确**：实际效率远低于100%
- **教训**：实际过程总有能量损失

### 常见错误 5：理想气体假设误用
- **错误**：认为实际气体也适用
- **正确**：题目明确说明所有气体均视作理想气体
- **教训**：必须注意假设条件
