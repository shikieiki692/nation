# 第 4 题 石硫合剂的制备与性质 (20 分)

制备石硫合剂(一种常用农药)的方法如下：先在反应器内加水使石灰消解，然后加足水量，在搅拌下把硫磺粉慢慢倒入。升温熬煮，使硫发生歧化反应。滤去固体渣滓得到粘稠状深棕色透明碱性液体成品。

## 问题

(1) 写出生成产品的歧化反应的化学反应方程式___________。

(2) 说明固体渣滓的成分(假定水和生石灰皆为纯品)_________。

(3) 写出呈现深棕色物质的化学式__________。

(4) 通常采用下述路线进行石硫合剂成品中有效活性物种的含量分析。写出A、B和C所代表的物种的化学式________、________、________。

(5) 我国科技工作者首创用石硫合剂提取黄金的新工艺，其原理类似于氰化法提金，不同的是过程中不需要通入空气。写出石硫合剂浸金过程中氧化剂的化学式_________，指出形成的Au(I)配离子中的配位原子________。

## 参考答案

**答案**：
(1) 3Ca(OH)2 + (2m+2)S = 2CaSm + CaS2O3 + 3H2O
(2) 反应完的硫单质、空气中的CO2参与反应形成的碳酸钙以及歧化反应生成的石膏(CaSO4·nH2O)
(3) S2-m（多硫化物离子）
(4) A=BaS2O3, B=ZnS+S, C=NaCH3SO4（硫酸甲酯钠）
(5) 氧化剂=S2-m, 配位原子=S

**解析**：
(1) 歧化反应机理：
- Ca(OH)2与S反应生成CaS和CaSO3
- CaS继续与S反应生成多硫化物CaSm
- CaSO3继续与S反应生成CaS2O3（硫代硫酸钙）
- 部分CaSO4形成石膏沉淀

(2) 固体渣滓包括：
- 未反应的硫单质
- CO2与Ca(OH)2反应生成的CaCO3
- 歧化反应生成的CaSO4·nH2O（石膏）

(3) 深棕色物质是多硫化物离子S2-m
- 多硫化物具有深棕色
- m值越大，颜色越深

(4) 含量分析路线：
- BaS2O3：硫代硫酸钡沉淀
- ZnS+S：硫化锌和硫的混合物
- NaCH3SO4：硫酸甲酯钠（甲醛与亚硫酸钠反应产物）

(5) 浸金原理：
- S2-m作为氧化剂（类似O2在氰化法中的作用）
- Au(I)与S形成配离子[Au(S2-m)n]^(1-2n)
- 配位原子是S（软碱与软酸Au(I)配位）

## 解题思路

### Step 1: 歧化反应方程式
```
反应物：Ca(OH)2 + S
产物：CaSm + CaS2O3 + H2O

配平思路：
- S发生歧化：部分被氧化（→S2O3^2-），部分被还原（→S^2-）
- 氧化态变化：S(0) → S(+2) in S2O3^2-，S(0) → S(-2) in S^2-
- 根据电子守恒配平

最终方程式：
3Ca(OH)2 + (2m+2)S = 2CaSm + CaS2O3 + 3H2O
```

### Step 2: 固体渣滓成分
```
可能的固体：
1. 未反应的硫单质（过量加入）
2. CaCO3（空气中CO2与Ca(OH)2反应）
3. CaSO4·nH2O（歧化反应副产物）

注意：题目假设水和生石灰皆为纯品
```

### Step 3: 深棕色物质
```
多硫化物离子S2-m：
- S原子通过S-S键连接
- 形成链状结构[S-S-S-...-S]^2-
- 具有深棕色（颜色随m增大而加深）
- 是石硫合剂的有效成分
```

### Step 4: 含量分析路线
```
分析步骤：
1. 加入BaCl2 → BaS2O3沉淀（硫代硫酸钡）
2. 加入ZnSO4 → ZnS沉淀 + S沉淀
3. 加入甲醛 → NaCH3SO4（硫酸甲酯钠）

这些步骤用于定量分析不同形态的硫
```

### Step 5: 浸金原理
```
氰化法提金：4Au + 8CN^- + O2 + 2H2O → 4[Au(CN)2]^- + 4OH^-
石硫合剂法：Au + S2-m → [Au(S2-m)n]^(1-2n)

关键区别：
- 氰化法需要O2作为氧化剂
- 石硫合剂法用S2-m作为氧化剂
- Au(I)是软酸，S^2-是软碱，形成稳定配离子
```

## 变式拓展

1. **如果把Ca(OH)2换成NaOH**：
   - 形成Na2S、Na2S2O3等
   - 溶解度不同，反应条件不同
   - 可能形成不同的多硫化物

2. **如果改变S的用量**：
   - S过量：多硫化物m值增大
   - S不足：产物主要是CaS和CaSO3
   - 影响石硫合剂的活性

3. **与往届真题的关联**：

## 易错分析

### 常见错误 1：歧化反应方程式配平错误
- **错误**：认为产物只有CaS和CaSO3
- **正确**：CaS会继续与S反应生成CaSm
- **教训**：多硫化物的形成是连续过程

### 常见错误 2：固体渣滓成分遗漏
- **错误**：只考虑未反应的硫
- **正确**：还应考虑CaCO3和CaSO4·nH2O
- **教训**：必须考虑所有可能的固体产物

### 常见错误 3：多硫化物结构理解错误
- **错误**：认为S2-m是简单的S^2-离子
- **正确**：S2-m是多硫链状结构
- **教训**：多硫化物的结构决定其性质

### 常见错误 4：浸金机理混淆
- **错误**：认为石硫合剂法与氰化法完全相同
- **正确**：氧化剂不同（S2-m vs O2）
- **教训**：必须理解两种方法的本质区别

### 常见错误 5：配位原子判断错误
- **错误**：认为Au(I)与N配位
- **正确**：Au(I)是软酸，与软碱S配位
- **教训**：软硬酸碱理论指导配位选择
