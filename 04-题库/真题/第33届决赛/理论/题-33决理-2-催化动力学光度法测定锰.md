# 第 2 题 催化动力学光度法测定锰 (20 分)

在Mn(II)的催化下，某有机染料(CR)溶液被氧化剂(OX)氧化褪色。在一定的pH条件下该反应具有较高的灵敏度和选择性，据此可建立催化动力学光度法以测定水样中的痕量锰。催化反应示意如下：

CR(蓝色) + OX → 褪色产物（Mn(II)催化）

CR褪色反应的速率方程为：-d[CR]/dt = k[CR]^α[OX]^β[Mn(II)]^γ

已知体系中无Mn(II)时褪色反应不发生。反应过程中，氧化剂大大过量。

## 问题

(1) 固定溶液中Mn(II)的浓度，改变CR溶液的初始浓度，测得溶液在6.0min和9.0min时的吸光度，部分数据见表2-1，推求α的值_________。

表2-1
| cCR(mol·L-1) | A(t=6.0min) | A(t=9.0min) |
|---|---|---|
| 2.0×10-6 | 0.274 | 0.111 |
| 2.2×10-6 | 0.333 | 0.135 |
| 2.4×10-6 | 0.482 | 0.195 |
| 2.6×10-6 | 0.669 | 0.271 |

(2) 实验表明，γ=1。推出固定时间间隔Δt时，相邻两时刻的吸光度比值与Mn(II)浓度之间的定量关系式_________。

(3) 固定CR起始浓度及Mn(II)的浓度，分别测定了363.15K和373.15K下体系在t=8.0min和10.0min时的吸光度。实验结果见表2-2，据此求算反应的表观活化能_________。

表2-2
| T(K) | A(t=8.0min) | A(t=10.0min) |
|---|---|---|
| 363.15 | 0.686 | 0.490 |
| 373.15 | 0.240 | 0.090 |

## 参考答案

**答案**：
(1) α=1
(2) ln(A_t/A_{t+Δt}) = k[Mn(II)]·Δt
(3) Ea=121 kJ·mol-1

**解析**：
(1) 根据Lambert-Beer定律：A=εlcCR，即吸光度与浓度cCR成正比。结合表2-1中的数据，发现有如下规律：A(9.0min)/A(6.0min)=0.405，CR初始浓度不同，但在相同时间内CR消耗的比例相同，可判断此反应对于CR而言是一级反应，即α=1。

(2) 推导浓度方程，应从速率方程着手：
-d[CR]/dt = k[CR][Mn(II)]
积分得：ln([CR]t/[CR]0) = -k[Mn(II)]t
由A=εl[CR]，得：ln(At/A0) = -k[Mn(II)]t
因此：ln(At/A_{t+Δt}) = k[Mn(II)]·Δt

(3) 当Mn(II)浓度也是定值时，有ln(At/A_{t+Δt})=k'·Δt，代入表2-2数据，可得k'363.15=0.168min-1，k'373.15=0.490min-1，则ln(k'373.15/k'363.15)=Ea/R×(1/363.15-1/373.15)，解得Ea=121kJ·mol-1。

## 解题思路

### Step 1: 判断反应级数α
```
关键观察：
- 不同初始浓度的CR，在相同时间内消耗比例相同
- A(9.0min)/A(6.0min) = 0.405（恒定值）

结论：
- 一级反应的特征：半衰期与初始浓度无关
- 相同时间内消耗比例相同 → 一级反应
- 因此α=1
```

### Step 2: 推导吸光度与Mn(II)浓度的关系
```
速率方程：-d[CR]/dt = k[CR][Mn(II)]
积分：ln([CR]t/[CR]0) = -k[Mn(II)]t

由Lambert-Beer定律：A=εl[CR]
代入得：ln(At/A0) = -k[Mn(II)]t

固定时间间隔Δt：
ln(At/A_{t+Δt}) = k[Mn(II)]·Δt
```

### Step 3: 计算活化能
```
Arrhenius方程：k = A·exp(-Ea/RT)
对数形式：ln(k2/k1) = Ea/R×(1/T1-1/T2)

实验数据：
T1=363.15K, k'1=0.168min-1
T2=373.15K, k'2=0.490min-1

计算：
ln(0.490/0.168) = Ea/8.314×(1/363.15-1/373.15)
1.058 = Ea/8.314×7.4×10-5
Ea = 121 kJ·mol-1
```

## 变式拓展

1. **如果反应对Mn(II)是零级**：
   - 催化剂浓度不影响速率
   - 无法用于痕量锰的测定
   - 催化机理不同

2. **如果改变温度范围**：
   - 更高温度可能改变反应机理
   - 活化能可能变化
   - 需要考虑催化剂失活

## 易错分析

### 常见错误 1：反应级数判断错误
- **错误**：认为消耗比例相同就是零级反应
- **正确**：一级反应的特征是半衰期恒定
- **教训**：必须理解不同级数反应的动力学特征

### 常见错误 2：积分速率方程推导错误
- **错误**：直接使用微分方程而不积分
- **正确**：必须积分得到浓度-时间关系
- **教训**：实验测量的是浓度随时间变化，需要积分形式

### 常见错误 3：Arrhenius方程应用错误
- **错误**：忘记对数形式中的温度倒数
- **正确**：ln(k2/k1) = Ea/R×(1/T1-1/T2)
- **教训**：Arrhenius方程有多种变形，必须正确使用

### 常见错误 4：单位换算错误
- **错误**：直接用min-1计算活化能
- **正确**：应该用s-1（国际单位制）
- **教训**：活化能计算必须用标准单位

### 常见错误 5：催化机理理解错误
- **错误**：认为Mn(II)是反应物
- **正确**：Mn(II)是催化剂，反应前后浓度不变
- **教训**：催化剂参与反应但不消耗
