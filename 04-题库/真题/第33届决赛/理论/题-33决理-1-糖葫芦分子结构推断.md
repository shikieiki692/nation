# 第 1 题 糖葫芦分子结构推断 (20 分)

图1-1示出了一种结构有趣的"糖葫芦"分子。其中A、B、C和D四种元素位于同一族的相邻周期，B的电负性大于D。C可分别与A、B、D形成二元化合物，C和E可形成易挥发的化合物CE3，CE3在工业上可用于漂白和杀菌。A和E可形成化合物AE3(bp，76°C)，AE3的完全水解产物之一X是塑料件镀金属的常用还原剂。A、C和E可形成含有六元环的化合物A3C3E6。在氯仿中，D和E可结合两个甲基形成化合物DE3Me2。

## 问题

(1) 写出A、B、C、D和E代表的元素_____、_____、______、____、_____。

(2) 写出"糖葫芦"分子中A和C的杂化轨道________。

(3) 画出处于最高氧化态的A与元素E形成的分子结构图，写出该分子的对称元素(具体类型)______。

(4) 画出DE3Me2的所有可能的立体异构体__________。

(5) 指出X属于______元酸，写出弱酸介质中硫酸镍被其还原的反应方程________。

## 参考答案

**答案**：
(1) A=P, B=As, C=N, D=Sb, E=Cl
(2) A为sp2杂化，C为sp3杂化
(3) 分子结构：PCl5（三角双锥），对称元素：4个镜面，1个C3轴，3个C2轴
(4) SbCl3Me2的立体异构体：顺式和反式两种
(5) X是H3PO3，二元酸；NiSO4 + H2O + H3PO3 → Ni + H3PO4 + H2SO4

**解析**：
此题推断可以从氧化态出发，A和C均能与E形成XY3型化合物，且AE3的水解产物之一具有还原性，可以推断A、B、C和D都是第VA族元素。C可分别与A、B、D形成二元化合物，所以C是N元素。根据AE3和CE3的性质可以推断A是P元素，E是Cl元素。由于B的电负性大于D，所以B、D分别是As、Sb元素。

## 解题思路

### Step 1: 元素推断
```
关键线索：
1. A、B、C、D四种元素位于同一族的相邻周期 → 第VA族
2. B的电负性大于D → B在D上方
3. C可与A、B、D形成二元化合物 → C是N（最轻的非金属）
4. CE3易挥发，用于漂白杀菌 → E=Cl（形成NCl3）
5. AE3沸点76°C，水解产物有还原性 → A=P（形成PCl3，水解生成H3PO3）
6. B、D分别是As、Sb（电负性As>Sb）
```

### Step 2: 杂化轨道判断
```
A=P在A3C3E6中：
- P形成3个P-N键
- 还有1对孤对电子
- 杂化类型：sp2

C=N在A3C3E6中：
- N形成3个N-P键
- 还有1对孤对电子
- 杂化类型：sp3
```

### Step 3: 分子对称性分析
```
最高氧化态的A与E形成的分子：PCl5
- 几何构型：三角双锥
- 对称元素：
  - 1个C3轴（通过赤道面）
  - 3个C2轴（通过轴向原子）
  - 4个镜面（3个包含轴向原子，1个赤道面）
```

### Step 4: 立体异构分析
```
DE3Me2 = SbCl3Me2
- 中心原子Sb：5个价电子
- 配体：3个Cl + 2个Me
- 几何构型：三角双锥
- 立体异构：
  - 顺式：两个Me在赤道面相邻位置
  - 反式：两个Me在赤道面相对位置
```

### Step 5: 酸性和氧化还原
```
X = H3PO3（亚磷酸）
- 结构：H-P(=O)(OH)2
- 酸性：二元酸（只有2个可电离的H）
- 氧化还原：H3PO3可被氧化为H3PO4
- 与NiSO4反应：Ni2+被还原为Ni0
```

## 变式拓展

1. **如果把E换成F**：
   - 形成NF3、PF3等化合物
   - 氧化性更强，水解反应不同
   - 可能形成更强的酸

2. **如果把A换成As**：
   - 形成AsCl3等化合物
   - 氧化性比PCl3弱
   - 水解产物不同

3. **与往届真题的关联**：

## 易错分析

### 常见错误 1：元素推断错误
- **错误**：认为A是N元素
- **正确**：A应该是P元素（因为AE3沸点76°C，不是气体）
- **教训**：物理性质（沸点）是重要的推断线索

### 常见错误 2：杂化轨道判断错误
- **错误**：认为P在PCl5中是sp3d杂化
- **正确**：在A3C3E6中，P是sp2杂化
- **教训**：必须根据具体化合物判断杂化类型

### 常见错误 3：对称元素遗漏
- **错误**：只写出C3轴，忽略C2轴和镜面
- **正确**：PCl5有完整的对称元素
- **教训**：三角双锥有丰富的对称性

### 常见错误 4：立体异构分析不全
- **错误**：只写出一种异构体
- **正确**：应该有顺式和反式两种
- **教训**：三角双锥可以有多种异构方式

### 常见错误 5：酸性判断错误
- **错误**：认为H3PO3是三元酸
- **正确**：H3PO3是二元酸（结构决定）
- **教训**：含氧酸的酸性取决于可电离的H数量
