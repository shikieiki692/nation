# 第 6 题 银硫簇合物结构 (25 分)

金属簇合物是含有金属-金属键、具有精确组成的一类物质，常表现出优美的化学结构和独特的光物理性能。

图6-1-a示出一种电中性银硫簇(简记为Ag12S6)的结构，包含12个银原子和6个硫原子(图中未区分原子大小)。6个银原子位于同一平面(称为赤道面)，形成正六边形，彼此之间不成键。赤道面上、下方各有3个银原子，皆呈正三角形排布，彼此之间形成Ag-Ag键，并分别与赤道面上的两个银原子形成Ag-Ag键。6个硫原子的位置如图所示。

## 问题

(1) 计算Ag12S6中Ag-Ag键的个数________。

(2) 计算Ag12S6中三角形面的个数___________。

(3) Ag12S6的硫原子来自于叔丁巯基，银为正一价。在Ag12S6上还连接有若干个CF3COO-，计算CF3COO-的个数__________。

(4) 聚集诱导发光(AIE)现象是一种由中国科学家首先发现的光致发光现象。具有AIE特性的有机分子在聚集状态下表现出远强于分散状态的光致发光性能。四苯乙烯(TPE)是一种典型的AIE分子。将TPE完全溶解于乙醇中，分别取等量的该溶液加入到等体积的水和甲苯中，判断哪一个体系的光致发光较强并简要解释原因__________。

(5) 利用上述Ag12S6和图6-1-b所示的TPPE配体组装，得到一种晶体框架材料ZZU(图6-1-c)。ZZU中，每个Ag12S6连接6个TPPE，每个TPPE连接4个Ag12S6。ZZU属于立方晶系，正当晶胞参数a=4.209mm，密度为0.618g·cm-3。ZZU沿着晶轴方向的投影如图6-2所示，在图6-2中用粗虚线画出ZZU正当晶胞的投影________。计算每个正当晶胞中Ag12S6和TPPE的数目_______、________。

## 参考答案

**答案**：
(1) 18个Ag-Ag键
(2) 32个三角形面
(3) 6个CF3COO-
(4) 在水中，TPE处于聚集态，具有较强的光致发光性能
(5) 晶胞中Ag12S6数目=8个，TPPE数目=12个

**解析**：
(1) Ag-Ag键计算：
- 赤道平面上方：3个银原子之间形成3个Ag-Ag键
- 赤道平面上方与赤道面：3×2=6个Ag-Ag键
- 赤道平面下方：3个银原子之间形成3个Ag-Ag键
- 赤道平面下方与赤道面：3×2=6个Ag-Ag键
- 总计：3+6+3+6=18个Ag-Ag键

(2) 三角形面计算：
- Ag-Ag-Ag三角形：8个
- Ag-Ag-S三角形：4×6=24个
- 总计：32个三角形面

(3) 电荷平衡：
- 叔丁巯基(S-t-Bu)：-1价
- 银(Ag)：+1价
- 整个簇呈电中性
- 因此需要6个CF3COO-（-1价）来平衡电荷

(4) AIE现象解释：
- TPE在乙醇中完全溶解（分子状态）
- 加入水中：TPE溶解度降低，聚集态，AIE效应增强
- 加入甲苯中：TPE仍溶解（有机溶剂），分子态，发光弱
- 结论：水中的光致发光较强

(5) 晶胞计算：
- 组成：(Ag12S6)(TPPE)1.5(C4H9)6(CF3COO)6
- 分子量：3648.79 g/mol
- 晶胞体积：(4.209×10^-7 cm)^3 = 7.457×10^-20 cm^3
- 晶胞质量：0.618 g/cm^3 × 7.457×10^-20 cm^3 = 4.61×10^-20 g
- 晶胞中分子数：4.61×10^-20 g ÷ (3648.79 g/mol ÷ 6.022×10^23 mol^-1) = 7.6≈8
- 因此Ag12S6数目=8个，TPPE数目=8×1.5=12个

## 解题思路

### Step 1: Ag-Ag键计算
```
结构分析：
- 赤道面：6个Ag原子，形成正六边形，彼此不成键
- 赤道面上方：3个Ag原子，呈正三角形
- 赤道面下方：3个Ag原子，呈正三角形

键数计算：
- 上方三角形内：3个Ag-Ag键
- 上方与赤道面：3×2=6个Ag-Ag键
- 下方三角形内：3个Ag-Ag键
- 下方与赤道面：3×2=6个Ag-Ag键
- 总计：3+6+3+6=18个Ag-Ag键
```

### Step 2: 三角形面计算
```
面数计算：
- Ag-Ag-Ag三角形：
  - 上方三角形：1个
  - 下方三角形：1个
  - 赤道面与上方：3个
  - 赤道面与下方：3个
  - 小计：8个

- Ag-Ag-S三角形：
  - 每个S原子与4个Ag原子形成4个三角形
  - 6个S原子：6×4=24个
  - 小计：24个

- 总计：8+24=32个三角形面
```

### Step 3: 电荷平衡
```
电荷分析：
- Ag12S6簇：中性
- 叔丁巯基(S-t-Bu)：-1价
- Ag：+1价
- 需要CF3COO-（-1价）平衡电荷

计算：
- 12个Ag(+1)：+12
- 6个S(-2)：-12（假设S为-2价）
- 簇整体电中性
- 需要6个CF3COO-（-1价）来平衡
```

### Step 4: AIE现象解释
```
TPE的溶解性：
- 在乙醇中：完全溶解（分子态）
- 在甲苯中：完全溶解（有机溶剂）
- 在水中：溶解度低，聚集态

AIE效应：
- 分子态：发光弱（分子内运动耗散能量）
- 聚集态：发光强（限制分子内运动）
- 结论：水中光致发光较强
```

### Step 5: 晶胞计算
```
晶胞参数：
- a=4.209 mm = 4.209×10^-7 cm
- ρ=0.618 g/cm^3

晶胞体积：
V = a^3 = (4.209×10^-7)^3 = 7.457×10^-20 cm^3

晶胞质量：
m = ρV = 0.618 × 7.457×10^-20 = 4.61×10^-20 g

分子量计算：
(Ag12S6)(TPPE)1.5(C4H9)6(CF3COO)6
= 12×107.87 + 6×32.07 + 1.5×(分子量TPPE) + 6×57.11 + 6×113.01
≈ 3648.79 g/mol

分子数计算：
n = m × N_A / M = 4.61×10^-20 × 6.022×10^23 / 3648.79 ≈ 7.6 ≈ 8

因此：
- Ag12S6数目：8个
- TPPE数目：8×1.5=12个
```

## 变式拓展

1. **如果改变金属中心**：
   - 用Cu代替Ag：形成Cu-S簇合物
   - 金属-金属键强度不同
   - 可能有不同的光物理性质

2. **如果改变配体**：
   - 用不同取代基的硫醇
   - 影响簇合物的稳定性和溶解性
   - 可能改变AIE性质

3. **与往届真题的关联**：

   - 类似第37届决赛的配位化学

## 易错分析

### 常见错误 1：Ag-Ag键计数错误
- **错误**：忽略赤道面与上下层之间的键
- **正确**：需要考虑所有可能的Ag-Ag键
- **教训**：必须仔细分析三维结构

### 常见错误 2：三角形面计数错误
- **错误**：只计算Ag-Ag-Ag三角形
- **正确**：还应计算Ag-Ag-S三角形
- **教训**：多面体的面数需要全面考虑

### 常见错误 3：电荷平衡错误
- **错误**：忽略叔丁巯基的电荷
- **正确**：S-t-Bu是-1价配体
- **教训**：必须考虑所有配体的电荷贡献

### 常见错误 4：AIE机理理解错误
- **错误**：认为聚集态发光弱
- **正确**：聚集态限制分子内运动，发光增强
- **教训**：AIE是特殊的发光现象

### 常见错误 5：晶胞计算错误
- **错误**：单位换算错误（mm→cm）
- **正确**：必须统一单位
- **教训**：晶胞参数计算需要仔细
