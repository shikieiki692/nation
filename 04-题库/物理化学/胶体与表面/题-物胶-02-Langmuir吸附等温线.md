# 题-物胶-02：Langmuir 吸附等温线计算

## 题目

某气体在固体表面的 Langmuir 吸附常数 $b = 0.50$ kPa⁻¹，饱和吸附量 $V_m = 40$ cm³。求压力 $p = 2.0$ kPa 时的覆盖率 $\theta$ 与吸附量 $V$；并解释 Langmuir 吸附的三条基本假设。

## 参考答案

Langmuir 等温式：

$$\theta = \frac{bp}{1+bp} = \frac{0.50\times 2.0}{1+0.50\times 2.0} = \frac{1.0}{2.0} = 0.50$$

$$V = \theta V_m = 0.50\times 40 = 20\ \mathrm{cm^3}$$

**Langmuir 三条假设**：① 单分子层吸附；② 表面均匀、各吸附位等价；③ 吸附分子间无相互作用。

**答案**：$\theta = 0.50$，$V = 20$ cm³。

> **核心辨析**：$p$ 很小时 $\theta \approx bp$（线性段），$p$ 很大时 $\theta \to 1$（饱和平台）。将等温式改写为 $\dfrac{p}{V} = \dfrac{1}{bV_m} + \dfrac{p}{V_m}$，作 $p/V$–$p$ 直线可由截距与斜率求出 $b$、$V_m$。

- 易错点：$b$ 单位与 $p$ 单位匹配；$V$ 与 $V_m$ 同单位；高压下偏离（多层吸附用 BET）
