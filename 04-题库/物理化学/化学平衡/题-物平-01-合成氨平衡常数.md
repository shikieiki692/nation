# 题-物平-01：合成氨平衡常数与转化率

## 题目

某温度下，把 1.0 mol N₂ 和 3.0 mol H₂ 放入 1.0 L 密闭容器发生 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，平衡时测得 NH₃ 为 0.80 mol。求：(1) 该温度下 $K_c$；(2) N₂ 的转化率；(3) 平衡后再充入 1.0 mol NH₃，$Q$ 与 $K$ 的关系如何，平衡向哪边移动？

## 参考答案

**(1)** 平衡浓度：

$$[\mathrm{N_2}] = 1.0 - 0.40 = 0.60,\quad [\mathrm{H_2}] = 3.0 - 1.20 = 1.80,\quad [\mathrm{NH_3}] = 0.80\ \mathrm{mol/L}$$

$$K_c = \frac{[\mathrm{NH_3}]^2}{[\mathrm{N_2}][\mathrm{H_2}]^3} = \frac{0.80^2}{0.60\times 1.80^3} = \frac{0.64}{3.499} = 0.18$$

**(2)** N₂ 转化率：

$$\alpha = \frac{0.40}{1.0}\times 100\% = 40\%$$

**(3)** 充入 1.0 mol NH₃ 后，瞬时 $[\mathrm{NH_3}] = 1.80$，$[\mathrm{N_2}]=0.60$，$[\mathrm{H_2}]=1.80$：

$$Q = \frac{1.80^2}{0.60\times 1.80^3} = \frac{3.24}{3.499} = 0.93 > K_c$$

$Q > K$，反应逆向移动（NH₃ 分解）。

**答案**：$K_c = 0.18$；转化率 40%；$Q = 0.93 > K$，逆向移动。

> **核心辨析**：$K$ 只随温度变，浓度改变只改变 $Q$ 与 $K$ 的相对大小判断移动方向。
