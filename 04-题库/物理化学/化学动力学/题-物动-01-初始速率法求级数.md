# 题-物动-01：初始速率法求反应级数

## 题目

某反应 $2\mathrm{A + B \rightarrow}$ 产物，测得三组初始速率：

| [A]₀/(mol·L⁻¹) | [B]₀/(mol·L⁻¹) | v₀/(mol·L⁻¹·s⁻¹) |
|:---:|:---:|:---:|
| 0.10 | 0.10 | 0.020 |
| 0.20 | 0.10 | 0.080 |
| 0.10 | 0.20 | 0.020 |

求对 A、B 各自的分级数、速率方程与速率常数 $k$。

## 参考答案

**对 A 的级数**（保持 [B] 不变，比较第1、2组）：[A] 加倍 → $v$ 变为 4 倍 → $\alpha = 2$。

**对 B 的级数**（保持 [A] 不变，比较第1、3组）：[B] 加倍 → $v$ 不变 → $\beta = 0$。

**速率方程**：$v = k[\mathrm{A}]^2[\mathrm{B}]^0 = k[\mathrm{A}]^2$

**速率常数**：$k = \dfrac{v_0}{[\mathrm{A}]_0^2} = \dfrac{0.020}{0.10^2} = 2.0\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$

**答案**：$\alpha = 2$，$\beta = 0$；$v = k[\mathrm{A}]^2$；$k = 2.0$ L·mol⁻¹·s⁻¹。

> **核心辨析**：初始速率法通过"单变量加倍"分离各组分级数。B 为零级说明 B 不出现在速率决定步——这类信息能反推反应机理。
