### 第 1 题（7 分）生物相容性的金属

> 来源：化英社 第40届化英社化学奥林匹克（决赛）模拟3（清晰） 第 1 题｜难度 ⭐⭐⭐⭐

高周期过渡金属 M 具有很好的生物相容性，常用于制备电子元件和医疗器械。其单质具有极高的抗腐蚀性能，不溶于沸腾的王水，但在热浓 KOH 溶液中迅速溶解，将溶液加热浓缩可以析出带结晶水的六核化合物 A·17H₂O，A·17H₂O 中 ω(O) = 28.67%。将 M 的最高价氯化物 B 溶于甲醇，缓慢滴入 30% 过氧化氢，并分批次加入 RbOH，冷却至 5°C 析出晶体 C，C 的阴离子中 M 为典型的三角十二面体配位。将 C 溶于 0.2 M RbOH 溶液，并加入少量 Na₃VO₄ 催化反应，观察到溶液变色，有气泡冒出。用大量热 NaOH 溶液溶解上一步析出的晶体并重结晶，使阳离子全部替换为 Na，最终产物 D 中阴离子与 A·17H₂O 相同，但结晶水数目相差 2 个，D 中 ω(O) = 29.50%。将 B 溶于 CCl₄，鼓入 Cl₂O 可析出含氧量为 5.28% 的氮氧化物晶体 E。

1-1 分别写出生成 A·17H₂O 和 E 化学反应方程式。

1-2 画出 A 和 C 中阴离子结构。

1-3 氯氧化物 E 具有独特的结构，其中的金属 M 均为 6 配位，通过共用 O 和 Cl 原子形成双一维链状结构，其中 M-O-M 键角约 $180^{\circ}$ ，据此画出 E 的结构。

1-4 将 E、Te 和 $TeCl_{4}$ 在氩气氛下离子液体中混合加热，得到新离子化合物 F。F 的阳离子为包含 $[Te_{6}]$ 六元环的无限链状结构，可以描述为 $[Te-Te-Te_{6}]_{n}^{2n+}$ ：阴离子中含氧 4.72%，不含 Te 且具有 $C_{4}$ 轴。画出阳离子的结构并给出其中 Te 的杂化形式，写出合成 F 的反应方程式。1-5 将 E 和单质 M 混合加热得到氯化物 G，G 和 2 当量四氢噻吩（THT）可以形成加合物 H，其中 M 为 6 配位。将 H 溶于苯并用等当量钠汞齐还原得到双核的 I，反应时 THT 未被还原，两个 M 原子为共面八面体配位，不包含 $C_{3}$ 轴但具有镜面对称性，已知 I 为抗磁性，写出生成 I 的化学方程式，画出 I 的结构并判断是否符合 EAN 规则。

1-6 将等当量的 I 与 $\mathrm{Ph}_{2} \mathrm{PCH}_{2} \mathrm{CH}_{2} \mathrm{PPh}_{2}$ 发生配体取代反应可得到 J，从化学式与最简式的数量关系看，J 为形式上的二聚体，其中所有 P 原子均参与配位，画出 J 的结构。

1-7 将 B 的一个 Cl 替换成 $Cp^{*}$ 得到 K，2 分子 K 与 4 分子的 $PhSiH_{3}$ 反应，释放 1 分子的 $H_{2}$ 与 4 分子 $PhSiH_{2}Cl$ 得到 L，L 与偶氮苯（Ph-N=N-Ph）反应会先释放等当量 $H_{2}$ 得到中间体 N，再进一步裂解得到 O。已知 N 和 O 均为 16e 结构，画出 L、N、O 的结构。

### 第 2 题（11 分）碳族元素需要得到或失去四个电

### 第 7 题（7 分）铬掺杂的氟磷酸钙

铬掺杂的氟磷酸钙 （ $\mathrm { Cr }$ :FAP） 可以作为一种激光材料，为了测定其中铬的氧化态， 采用如下分析方法：

步骤一： 将一定量 $\mathrm { Fe ( NH _{ 4 } ) _{ 2 } ( SO _{ 4 } ) _{ 2 } { \cdot } 6 H _{ 2 } O }$ 溶于 $2.0 \mathrm { mol / LHClO _{ 4 } }$ 中， 制得 $\mathrm { Fe } ^{ 2 + }$ 标准溶液。 取 $\mathrm { Fe } ^{ 2 + }$ 标准溶液$10.00 \mathrm { mL }$ ，用 $5.59 \mathrm { mmol / LK _{ 2 } Cr _{ 2 } O _{ 7 } }$ 溶液进行滴定， 使用 $\mathrm { \mathbf { P } \mathrm { t } }$ 电极和 $\mathrm { Ag | AgCl }$ 电极确定终点， 消耗 $\mathrm { K } _{ 2 } \mathrm { Cr } _{ 2 } \mathrm { O } _{ 7 }$ 溶液 $0.829 \mathrm { mL }$ 。

步骤二： 将 $0.4375 \mathrm { g }$ 粗磨的 $\mathrm { Cr }$ :FAP 晶体溶于 $10 \mathrm { ml } 2.9 \mathrm { mol } / \mathrm { L } \mathrm { HClO } _{ 4 }$ 中， 在 $100^{ \circ } \mathrm { C }$ 下磁力搅拌 10 分钟。冷却至 $20^{ \circ } \mathrm { C }$ ， 用 $\mathrm { Fe } ^{ 2 + }$ 标准溶液滴定， 消耗 $\mathrm { Fe } ^{ 2 + }$ 标准溶液 $0.498 \mathrm { mL }$ 。

步骤三： 将 $0.1566 \mathrm { g }$ 粗磨的 $\mathrm { Cr }$ :FAP 晶体溶于 $10 \mathrm { ml } 2.9 \mathrm { mol } / \mathrm { LHClO } _{ 4 }$ 中， 在 $100^{ \circ } \mathrm { C }$ 下磁力搅拌 10 分钟，冷却至 $20^{ \circ } \mathrm { C }$ 。 加入 $100 \mu \mathrm { L } 0.5 \mathrm { mol / LAgNO } _{ 3 }$ 溶液和 $0.20 \mathrm { g }$ 固体 $\mathrm { ( NH _{ 4 } ) _{ 2 } S _{ 2 } O _{ 8 } }$ ， 待充分反应后， 将溶液煮沸30 分钟， 冷却， 用 $20 ~ \mathrm { ml }$ 去离子水稀释， 然后用上述标准 $\mathrm { Fe } ^{ 2 + }$ 滴定， 消耗 $\mathrm { Fe } ^{ 2 + }$ 标准溶液 $0.703 ~ \mathrm { mL }$ 。

由反应方程式可知 $1\ \mathrm{Cr_2O_7^{2-}} \sim 6\ \mathrm{Fe^{2+}}$，$\mathrm{Fe^{2+}}$ 标准溶液的浓度为

$$c(\mathrm{Fe^{2+}}) = \frac{6 \times c(\mathrm{Cr_2O_7^{2-}}) \times V(\mathrm{Cr_2O_7^{2-}})}{V(\mathrm{Fe^{2+}})} = \frac{6 \times 5.59 \times 0.829}{10.00} = 2.78\ \mathrm{mmol/L} = 2.78 \times 10^{-3}\ \mathrm{mol/L}$$（2 分）

$$\mathrm{Cr^{n+} + (n-3)Fe^{2+} = Cr^{3+} + (n-3)Fe^{3+}}$$（2 分）

$$\mathrm{Cr_2O_7^{2-} + 6Fe^{2+} + 14H^+ = 6Fe^{3+} + 2Cr^{3+} + 7H_2O}$$（不得分也不扣分）

$$n_1(\mathrm{Cr^{n+}}) = \frac{c_1(\mathrm{Fe^{2+}}) \times V_1(\mathrm{Fe^{2+}})}{n-3} = \frac{2.78 \times 0.498}{n-3}\ (\mu\mathrm{mol})$$（1 分）

$$\frac{2.78 \times 0.498}{(n-3) \times 0.4375} = \frac{2.78 \times 0.703}{3 \times 0.1566}$$

### 第 9 题（12 分）晶体缺陷

> 来源：清北营 2026年清北营暑假高二班-11 第 2 题｜难度 ⭐⭐⭐⭐

离子晶体在绝对零度时为完美晶格结构，温度高于 0 K 时，晶格原子的热振动会使部分原子脱离平衡格位，形成本征点缺陷，这类由热运动产生的缺陷称为热缺陷。热缺陷主要分为两类：

肖特基缺陷：原子离开体内格位后迁移至晶体表面，在晶体内部留下等量的正离子空位与负离子空位，整体保持电中性。该缺陷在碱金属卤化物、碱土金属氧化物等 NaCl 型结构晶体中最为常见。

弗伦克尔缺陷：原子离开正常格位后进入晶格间隙位置，形成等量的空位与间隙原子，晶体总原子数、总体积与化学计量比均保持不变。该缺陷常见于正离子半径远小于负离子、晶格间隙空间较大的晶体（如AgBr、 $\mathrm{CaF_2}$ 等）。

从热力学角度看，缺陷的形成需要破坏晶格化学键，使系统焓升高 $\Delta H > 0$ ，不利于缺陷自发形成；但空位/间隙原子的随机分布会大幅增加系统的微观状态数，使组态熵升高 $\Delta S > 0$ ，有利于缺陷自发形成。在一定温度下，系统吉布斯自由能达到极小值时，缺陷浓度达到热力学平衡浓度。

可能用到的相关数学公式:

玻尔兹曼熵公式： $S = k_{B} \ln \Omega$ ，其中 $k_{B}$ 为玻尔兹曼常数， $\Omega$ 为系统微观状态数；

斯特林近似：当粒子数 N 极大时， $\ln N! \approx N \ln N - N;$

热力学平衡判据：恒温恒压下，系统吉布斯自由能对缺陷数的一阶导数为0时，系统达到平衡；

晶体线热膨胀系数 $\alpha$ 定义为： $\alpha = \frac{1}{a_0}\cdot \frac{\mathrm{d}a}{\mathrm{d}T}$ ，常温下体积膨胀系数近似为 $3\alpha$ 。

**9-4-2** $N_F = \sqrt{N \cdot N'} \cdot \exp\left(-\frac{\Delta H_F}{2RT}\right)$ 组态熵变: $\Delta S = k_B \ln \Omega = k_B \left[ \ln \frac{N!}{N_F!(N - N_F)!} + \ln \frac{N'!}{N_F!(N' - N_F)!} \right]$ 代入斯特林近似化简后,对  $N_F$  求导得: $\frac{d(\Delta S)}{dN_F} = k_B \cdot \ln\left(\frac{(N - N_F)(N' - N_F)}{N_F^2}\right)$ 平衡时  $\frac{d\Delta G}{dN_F} = \frac{\Delta H_F}{N_A} - T \frac{d\Delta S}{dN_F} = 0$ ,代入稀缺近似  $N - N_F \approx N$ , $N' - N_F \approx N'$ ,整理得: $\ln \frac{NN'}{N_F^2} = \frac{\Delta H_F}{RT}$  $N_F^2 = NN' \cdot \exp\left(-\frac{\Delta H_F}{RT}\right)$ 开方后即得: $N_F = \sqrt{N \cdot N'} \cdot \exp\left(-\frac{\Delta H_F}{2RT}\right)$

### 第 13 题（13 分）随机中的动热力学

> 来源：化英社 化英社2026第40届决赛物化专题2 第 6 题｜难度 ⭐⭐⭐⭐

在噪声中偏向，于随机里定轨

在化学中，意识到微观上的过程本质上都是“随机的”，宏观上的定向移动蕴含在这些随机之中。热涨落随时存在，但是在偏力的作用下，随机的运动背后也蕴含着一定的偏向。在随机的世界中产生秩序，是数学、物理、化学共同的美感。

第1部分 简单的模型：一维偏随机游走

先展示一个极具生物背景的模型：假定一个蛋白在一条无限长的链上运动，运动的过程是随机的（蛋白有可能往左走，也有可能往右走。往左走概率为 $p_{\cdot}$ ，往右走概率为 $p_{+}$ ）。每次移动的距离 $a = 8 \mathrm{~nm}$ 。蛋白质运动的起点记为0，使用数轴描述蛋白的位置，记蛋白往右走时位置坐标为正值。

数学知识:

1. 期望的定义

对于随机变量 $X$ ，其期望如下，其中 $P(X = x_{i})$ 为 $X = x_{i}$ 的概率：

$$
[ X ] = \sum x _ {i} P (X = x _ {i})
$$

2. 期望的线性性质

$$
\left[ \sum \alpha X _ {i} \right] = \sum \alpha [ X _ {i} ]
$$

第2部分 化学动力学中的类似：Kramers模型

Langevin 方程给出了粒子运动的动力学方程，下面展现了一维的 Langevin 方程。 $\dot{x}$ 表示速度， $\dot{x}$ 表示加速度， $V(x)$ 是粒子在不同位置的势能， $\beta$ 是阻尼系数，与溶剂的粘度有关， $F_{rand}$ 给出了溶剂对体系给予的随机的力（注意力、速度和加速度均为矢量）：

$$
m \ddot {x} = - \frac {d V (\dot {x})}{d x} - \beta m \dot {x} + F _ {r a n d}
$$

13-3 下列说法正确的是:

(a) $\mathrm{d}V(x)/\mathrm{d}x$ 起到的作用相当于偏随机游走模型中的偏力。

(b) $\beta m\dot{x}$ 表征了溶剂与粒子运动之间的“摩擦”，与温度无关。

(c) $F_{rand}$ 的期望值为0。

(d) $F_{rand}$ 数值的期望值是温度的函数。

传统的过渡态理论给出了一个经典的关系式:

$$
k _ {T S T} = \frac {k _ {B} T}{h} e ^ {- \frac {\Delta G _ {\mathrm{m}} ^ {2}}{R T}}
$$

其中， $k_{TST}$ 为反应的速率常数， $k_{B}$ 是玻尔兹曼常数，h 是普朗克常数， $\Delta G_{m}^{\star}$ 为反应的活化吉布斯自由能。Kramers 指出，在化学反应中，粒子时时刻刻受到环境的作用，可以视作在势能面上的偏随机游走。基于 Langevin 方程，经过了复杂的数学推导，得到了 Kramers 模型。Kramers 模型对艾林公式引入了修正因子 $\kappa_{KR}$ ，有：

$$
k = k _ {T S T} \kappa_ {K R}
$$

其中 $\kappa_{KR}$ 以以下方法计算，对于已知的反应势能面，有以下图示：

![[b86d37ebb05e7ce1684b4032d68cd7d9a84e048b89293ebacca329728dc9b339.jpg]]

若将势阱底部与过渡态处的势能面形状均近似为二次函数（即运动方式近似于简振或“虚简振”），则有这两者附近的势能关于位置的函数为：

$$
V _ {0} (x) = \frac {1}{2} m \omega_ {0} ^ {2} (x - x _ {0}) ^ {2}
$$

$$
V ^ {*} (x) = E _ {0} - \frac {1}{2} m \omega^ {* 2} (x - x ^ {*}) ^ {2}
$$

在此种近似下 $\kappa_{KR}$ 的表达式为：

$$
\kappa_ {K R} = \sqrt {1 + \left(\frac {\beta}{2 \omega^ {*}}\right) ^ {2}} - \frac {\beta}{2 \omega^ {*}}
$$

其中 $\beta$ 是一个与扩散有关的常数，其测定根据的是以下方程：

$$
D = \frac {k _ {B} T}{m \beta}
$$

以上的式子中，m为质量或（有必要的话）约化质量。

由于它位置的特殊性，关于它的传说也不绝于耳，甚至因为其位于金的下方，有用其代表化学竞赛国家集训队的“錀牌”之说。虽然目前已知最长寿的錀同位素半衰期仅 3.6 s，难以设计有效的性质实验，但可以通过计算化学手段预测其部分性质。

15-1 1994 年，第一种錀的同位素 $^{272}\mathrm{Rg}$ 在德国被合成，具体方法为使用 $^{64}\mathrm{Ni}$ 轰击 $^{209}\mathrm{Bi}$ 靶。写出核反应方程式。

15-2 超重元素最特别的性质就是其较强的相对论效应。研究表明，在价层轨道附近，相对论效应强度与 $Z^{2}$ 成正比。对于考虑相对论效应前后轨道能量 $\varepsilon$ 的变化，提出了拟合公式：

$$

### 第 16 题（9 分）硝酸根的探测

> 来源：伽马 伽马化学2026年暑期模拟5 第 5 题｜难度 ⭐⭐⭐⭐

可以用 $NO_{3}^{-}$ 离子选择电极监测乳品厂生产的副产品乳清中的 $NO_{3}^{-}$ 的含量。乳清中的 $NO_{3}^{-}$ 离子的浓度一般在65 mg·$\mathrm{L}^{-1}$ 左右。

16-1 右图给出的是硝酸根离子选择电极的校准曲线。这是在适当的酸度和Cl⁻离子浓度为 $2.6 \times 10^{-3} \, mol \cdot L^{-1}$ 的条件下配制的 $NO_{3}^{-}$ 离子的系列标准溶液中测得的。问在上述条件下用离子选择电极监测乳清中的 $NO_{3}^{-}$ 是否可行？

![[5d3810809a183c6724604f9e935814e17149b40273a3fa7584b3a90066cf3dd5.jpg]]

16-2 $NO_{3}^{-}$ 离子和共存的干扰离子给出的电极响应可以用电位选择性系数（可简称为选择性系数）反映出其相关性。其定义为：在相同测试条件下，能使电极

产生相同电位响应的被测离子活度与干扰离子活度的比值。在本题中，认为离子活度等于其浓度。已知 $Cl^{-}$ ， $SO_{4}^{2-}$ ， $ClO_{4}^{-}$ 对 $NO_{3}^{-}$ 测定的选择性系数分别表示为：

$$
\begin{array}{r l}   \mathrm {K_ {NO_ {3} ^ {-} ,Cl^ {-}} = \frac {[NO_ {3} ^ {-} ]}{[Cl^ {-} ]} = 4.9\times 10^ {- 2}} \\   \mathrm {K_ {NO_ {3} ^ {-} ,SO_ {4} ^ {2 - }} = \frac {[NO_ {3} ^ {-} ]}{[SO_ {4} ^ {2 - } ]} = 4.1\times 10^ {- 5}} \\   \mathrm {K_ {NO_ {3} ^ {-} ,ClO_ {4} ^ {-}} = \frac {[NO_ {3} ^ {-} ]}{[ClO_ {4} ^ {-} ]} = 1.0\times 10^ {- 3}} \end{array}
$$

16-2-1 当乳清中 $NO_{3}^{-}$ 的含量为 $1.4 \times 10^{-3} \, mol \cdot L^{-1}$ ， $Cl^{-}$ 的含量为 $1.6 \times 10^{-2} \, mol \cdot L^{-1}$ 时，为使得 $NO_{3}^{-}$ 测定误差小于 1%，计算分析应当选用下列哪种物质来消除 $Cl^{-}$ 离子的干扰？

$$
\mathrm {A.AgNO_ {3} \quad B.Ag_ {2} SO_ {4} \quad C.AgClO_ {4}}
$$

16-2-2 计算 1 L 预测样品溶液中至少需要加入该银盐的质量。

16-3 用上述方法在 298 K 下测定 $NO_{3}^{-}$ 离子的浓度，取 $25.00 \, cm^{3}$ 样品溶液，测得电极电势为 E = -160.0 mV。加入 $1.00 \, cm^{3}$ $0.100 \, mol \cdot L^{-1} \, NO_{3}^{-}$ 的标准溶液后，电位变为 -130.0 mV。计算乳清中的 $NO_{3}^{-}$ 的浓度。所涉及的氧化还原半反应是一个单电子变化过程，n = 1。

16-4 $\mathrm{AcO}^{-}$ 离子对 $\mathrm{NO}_{3}^{-}$ 测定的电位选择系数为 $\mathrm{K_{NO_{3}^{-},AcO^{-}}}=2.7\times10^{-3}$ 。假如在第二问的样品溶液中加入 $\mathrm{AgOAc}$ 来消除 $\mathrm{Cl}^{-}$ 的干扰，为使测定 $\mathrm{NO}_{3}^{-}$ 的误差小于 $1\%$ ，求溶液允许的 $\mathrm{pH}$ 值的上限。

参考数据:

$$
\mathrm{K} _ {\mathrm{sp}} (\mathrm{AgCl}) = 3.2 \times 10 ^ {- 10}, \mathrm{K} _ {\mathrm{sp}} (\mathrm{Ag} _ {2} \mathrm{SO} _ {4}) = 8.0 \times 10 ^ {- 5}
$$

$$
\mathrm{K} _ {\mathrm{sp}} (\mathrm{AgOAc}) = 8.0 \times 10 ^ {- 3}, \mathrm{K} _ {\mathrm{a}} (\mathrm{AcOH}) = 1.7 \times 10 ^ {- 5}
$$

#### 答案

16-1(1 分)测量浓度在图中量程之内，可行。

16-2-1(4 分) $AgNO_{3}$ 会引入额外的硝酸根，不能选。

由数据可知 $K_{NO_{3}^{-},Cl^{-}} > K_{NO_{3}^{-},ClO_{4}^{-}} > K_{NO_{3}^{-},SO_{4}^{2-}}$ 氯离子对硝酸根的测定影响是最大的，故理论上将氯离子全部置换除去可以减小离子的干扰。(1分)

选择 $Ag_{2}SO_{4}$ 时， $\left[SO_{4}^{2-}\right] = 0.80 \times 10^{-2} \, mol \cdot L^{-1}$ ，影响为：

$$
\frac {0.80 \times 10 ^ {- 2} \times 4.1 \times 10 ^ {- 5}}{1.4 \times 10 ^ {- 3}} = 2.3 \times 10 ^ {- 4}\tag{1 分}
$$

选择 $\mathrm{AgClO_4}$ 时， $[\mathrm{ClO}_4^-] = 1.6 \times 10^{-2} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ ，影响为：

$$
\frac {1.6 \times 10 ^ {- 2} \times 1.0 \times 10 ^ {- 3}}{1.4 \times 10 ^ {- 3}} = 0.01\tag{1 分}
$$

选用 $AgClO_{4}$ 始终无法使误差小于 1%，故选择 $Ag_{2}SO_{4}$ (1 分)。

16-2-2(2分)

$$
\begin{array}{r l} \frac {4.9 \times 10 ^ {- 2} \times (1.6 \times 10 ^ {- 2} - 2 x) + 4.1 \times 10 ^ {- 5} \times x}{1.4 \times 10 ^ {- 3}}   = 0.01, x = 7.9 \times 10 ^ {- 3} \mathrm{mol} \bullet \mathrm{L} ^ {- 1} \\ \mathrm{m}   = 7.9 \times 10 ^ {- 3} \times 311.87 = 2.5 \mathrm{g} \end{array}
$$

16-3(2 分)

$$
\Delta \mathrm{E} = \frac {\mathrm{RT}}{\mathrm{nF}} \ln \frac {[ \mathrm{NO} _ {3} ^ {-} ] _ {\mathrm{t}}}{[ \mathrm{NO} _ {3} ^ {-} ] _ {0}} = 0.0257 \ln \frac {25.00 \mathrm{c} + 0.100}{26.00 \mathrm{c}} = 0.0300 \quad \mathrm{c} = 1.7 \times 10 ^ {- 5} \mathrm{mol} \bullet \mathrm{L} ^ {- 1}
$$

16-4(2 分)最后允许存在的醋酸根浓度为:

$$
\begin{array}{r l}   c (\mathrm {AcO^ {-}}) = \frac {1.4 \times 10 ^ {- 3} \times 0.01}{2.7 \times 10 ^ {- 3}} = 5.2 \times 10 ^ {- 3} \mathrm{mol} \bullet \mathrm{L} ^ {- 1} \\   c (\mathrm{AcOH}) = 1.6 \times 10 ^ {- 2} - 5.2 \times 10 ^ {- 3} = 1.1 \times 10 ^ {- 2} \mathrm{mol} \bullet \mathrm{L} ^ {- 1} \\   [ \mathrm{H} ^ {+} ] = \frac {1.7 \times 10 ^ {- 5} \times 1.1 \times 10 ^ {- 2}}{5.2 \times 10 ^ {- 3}} = 3.5 \times 10 ^ {- 5} \mathrm{mol} \bullet \mathrm{L} ^ {- 1}, \mathrm{pH} <   4.45 \end{array}
$$

> —— 解析 ——
>
> **考点**：硝酸根离子选择电极的干扰与定量（主锚 [[Nernst方程]]、[[条件电势]]、[[容量分析计算]]；配套 [[沉淀溶解平衡]]、[[分布分数]]、[[准确度]]）
>
> **思路**：四段：① 校准曲线量程判断可行性；② **电位选择性系数**判干扰并选银盐（Ag₂SO₄，不能用 AgNO₃/AgClO₄）；③ **标准加入法**由 ΔE 求 c；④ AcO⁻ 干扰下的 pH 上限（用 AcOH/AcO⁻ 缓冲与 K_sp）。判据核心＝**误差＝ΣK·c_干扰/c_被测＋Nernst 增量法**。
>
> **16-1**：答案（1 分）：**可行**——乳清中 NO₃⁻ 约 65 mg/L 落在校准曲线量程之内。**判据直引**：[[分光光度法]]/[[滴定曲线]]（工作曲线量程判据）；题目给定 Cl⁻ 2.6×10⁻³ mol/L 的条件。
>
> **16-2-1**：答案（共 4 分）：**AgNO₃ 会引入额外的硝酸根，不能选**（1 分）；由 K 值大小（Cl⁻ 4.9×10⁻²＞ClO₄⁻ 1.0×10⁻³＞SO₄²⁻ 4.1×10⁻⁵）可知 Cl⁻ 干扰最大 ⇒ 用银盐把 Cl⁻ 沉淀除去（1 分）；选择 **Ag₂SO₄** 时SO₄²⁻ 影响＝(0.80×10⁻²×4.1×10⁻⁵)/1.4×10⁻³＝**2.3×10⁻⁴**（1 分）；选择 AgClO₄ 时影响＝(1.6×10⁻²×1.0×10⁻³)/1.4×10⁻³＝**0.01**（＞1% 不合格）（1 分）⇒ **选 Ag₂SO₄**（1 分）。**判据直引**：[[条件电势]]/电位选择性系数的误差公式（误差＝K_{i,j}·c_j/c_i）。
>
> **16-2-2**：**分步推导（数值，2 分）**：4.9×10⁻²×(1.6×10⁻²−2x)＋4.1×10⁻⁵·x)/1.4×10⁻³＝0.01 ⇒ 解得 x＝**7.9×10⁻³ mol/L** ⇒ m＝x×311.87（Ag₂SO₄ Mr）＝**2.5 g**。**关键**：Ag₂SO₄ 每 mol 提供 2 mol Ag⁺ ⇒ 沉淀 Cl⁻ 的消耗写作 2x。
>
> **16-3**：**分步推导（数值，2 分）**：ΔE＝(RT/nF)ln([NO₃⁻]_t/[NO₃⁻]₀)＝0.0257×ln[(25.00c＋0.100)/(26.00c)]＝0.0300 ⇒ c＝**1.7×10⁻⁵ mol/L**。**判据直引**：[[Nernst方程]]（标准加入法的 ΔE 与浓度比关系）。
>
> **16-4**：**分步推导（数值，2 分）**：允许的 c(AcO⁻)＝1.4×10⁻³×0.01/2.7×10⁻³＝**5.2×10⁻³ mol/L**；c(AcOH)＝1.6×10⁻²−5.2×10⁻³＝1.1×10⁻² mol/L；[H⁺]＝K_a·c(AcOH)/c(AcO⁻)＝**3.5×10⁻⁵ mol/L** ⇒ **pH＜4.45**。**判据直引**：[[亨德森-哈塞尔巴赫方程]]（缓冲对 pH 计算）＋[[沉淀溶解平衡]]（K_sp 约束）。
>
> **易错**：① 16-2-1 选 AgNO₃（引入 NO₃⁻ 使测定偏高）；② 16-2-2 把 Ag₂SO₄ 提供的 Ag⁺ 写成 1:1（须 **2x**）；③ 16-3 用 10 为底的对数（方程应为 ln，0.0257＝2.303RT/F 已折算）；④ 16-4 忘把 c(AcO⁻) 从总醋酸根中扣除（c(AcOH)＝总量−c(AcO⁻)）。
>
> **举一反三**：① [[题-HZ-04-05-临床研究表明某些细菌的致病性]]（同考 [[条件电势]]：离子选择电极/选择性系数）；② [[题-UChO-01-02-为分别测定巴黎绿中及三价砷的]]（同考 [[条件电势]]：干扰与选择性判据）；③ [[题-BJLY-04-无机综合-08-光合作用是自然界最重要的过程]]（同考 [[Nernst方程]]：电位与浓度）；④ [[题-2ChO-06-02-指南针Compass是一种简]]（同考 [[Nernst方程]]：电化学定量分析）。
>
