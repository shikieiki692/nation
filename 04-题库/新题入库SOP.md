# 新题入库 SOP

> **用途**：Agent 导入新题到 04-题库 时的标准作业流程。
> **适用场景**：A. 从已有来源补充少量题 ｜ B. 从新来源整批入库 ｜ C. 导入自编/改编题
> **前置条件**：OCR 源文件已存在于知识库中（或自编题有明确来源说明）
> **耗时**：少量题（≤10 题）约 15 分钟；整批（>50 题）需分批处理

---

## 一、入库前检查（必做）

### 1.1 确认目标库位

| 判断 | 目标目录 |
|:--|:--|
| 来自已有教材/讲义？ | `04-题库/教材习题/{来源名}/` |
| 来自竞赛真题？ | `04-题库/真题/第{N}届{初赛|决赛}/` |
| 来自自编/改编？ | `04-题库/教学改编题/` 或 `04-题库/经典例题/` |
| 来自普通化学原理？ | `04-题库/化学原理/Ch{XX}-{章名}/` |

**已有来源命名规范速查**：

| 来源库 | 文件名格式 | 示例 |
|:--|:--|:--|
| 化学竞赛初赛讲义 | `题-{三位序号}-初赛讲义-{子模块}-习题{章}.{题号}.md` | `题-001-初赛讲义-分子结构-习题3.2.md` |
| ABOC | `题-{三位序号}-ABOC-Ch{章}-{题号}-{描述}.md` | `题-038-ABOC-Ch2-2.8-1-写出反应产物.md` |
| Clayden | `题-{三位序号}-Clayden-Ch{章}-P{页}-{描述}.md` | `题-262-Clayden-Ch6-P1-硼氢化钠还原.md` |
| 上海中学 | `题-{三位序号}-上海中学-{子模块}-习题{题号}.md` | `题-001-上海中学-卤族元素-习题1.md` |
| 赵鑫光 | `题-赵鑫光-{分册}-{例|习|综|选}{序号}.md` | `题-赵鑫光-分子-习10.md` |
| 汇智 | `题-汇智-{类别}-{题号}.md` | `题-汇智-晶体结构-5.md` |
| 化学原理 | `{章两位}-{题号两位}.md` | `02-01.md` |
| 真题 | `题-{届三位}{初|决}-{大题}-{小问}-{描述}.md` | `题-039-9-3-NAI环化.md` |

### 1.2 查重

```python
# 用题目核心内容的关键词搜索全库，确认非重复
# 方法：取题干中最独特的 10-15 个连续汉字，grep 全库
```

- 如果找到完全相同的题 → **不入库**，在已有文件的 `cross_references` 中添加来源标注
- 如果找到相似但不同的题 → 正常入库，在 `cross_references` 中互链

### 1.3 OCR 源文件确认

- 确认原书 OCR 文件在知识库中（`06-外部资料导入/` 或根目录 OCR 目录）
- 如果 OCR 不存在 → 先完成 OCR 导入，再入库题目

## 二、文件创建

### 2.1 文件命名

按目标库的命名规范（见 1.1 表格）。序号规则：
- 已有来源 → 接续最大序号 +1
- 新来源 → 从 001 开始

### 2.2 Frontmatter 模板

```yaml
---
title: "{文件名去.md}"
type: 题目
submodule: {子模块名}            # 如：分子结构 / 化学平衡 / 有机合成
exam_stage: 初赛                 # 初赛 / 决赛 / 省预赛
subject: 无机和结构化学           # 化学原理 / 无机和结构化学 / 有机化学 / 元素化学
difficulty: 3                    # 1-5
teaching_level: 巩固              # 入门 / 巩固 / 拓展 / 竞赛拔高
fidelity: 原书逐字               # 原书逐字 / 原书改写 / 自编
syllabus_codes: ["{考纲编号}"]
knowledge_points: ["[[KP1]]", "[[KP2]]"]
tags: [化竞, {来源标签}, {主题标签}]
created: {今天日期}
updated: {今天日期}
source: {来源描述}
source_file: "[[OCR文件路径]]"
module: {细分模块}               # 可选，与 submodule 相同或更细
subject_module: {四大模块}       # 化学原理 / 结构化学 / 有机化学 / 元素与分析
pack: {包}                       # 章节练习 / 模块习题集 / 综合模拟卷 / 预赛专项
status: 已填充
---
```

**六字段必填**（缺失会导致组卷系统无法检索）：

| 字段 | 取值范围 | 分配规则 |
|:--|:--|:--|
| `fidelity` | 原书逐字 / 原书改写 / 自编 | 逐字转录=逐字；基于原书改写=改写；无原书=自编 |
| `difficulty` | 1-5 | 1=入门 2=基础 3=巩固 4=较难 5=竞赛难 |
| `exam_stage` | 初赛 / 决赛 / 省预赛 | 按题目来源考试级别 |
| `subject_module` | 化学原理 / 结构化学 / 有机化学 / 元素与分析 | 按 KP 和内容归属 |
| `pack` | 章节练习 / 模块习题集 / 综合模拟卷 / 预赛专项 | 真题初赛→模块集，决赛→模拟卷，省预赛→预赛，非真题 d≤3→章节练习，d≥4→模块集 |
| `knowledge_points` | KP wikilink 列表 | 至少 1 个，建议 2-3 个 |

### 2.3 正文格式（汇智习题风格）

```markdown
# {文件名去 .md}

（题干正文——逐字转录自 OCR，保留原始公式和图片引用）

<details>
<summary>📖 查看答案</summary>

（答案与解析——逐字转录或标注"原书未提供解答"）

</details>
```

**格式规则**：
- 题干在前、答案在后
- 答案用 `<details>` 折叠（Obsidian 自动折叠，Word 导出可切换）
- 图片引用统一用 `![[哈希文件名.jpg]]`（图片文件必须在 `媒体仓库/` 中）
- 公式用 `$...$` 或 `$$...$$` LaTeX 格式
- 不要用 HTML 标签（`<table>` 除外，Obsidian 可渲染）

---

## 三、图片处理

1. OCR 图片在 `06-外部资料导入/{来源}/xxx_images/` 中
2. 复制到 `媒体仓库/`（保持哈希原名）
3. 题目文件中用 `![[哈希文件名.jpg]]` 引用

---

## 四、特殊字段

### 4.1 承接式题目

如果题干含"由上题/根据(1)/与题 X.X 相比/此外（承接语义）"：

```yaml
depends_on: ["[[前驱文件名]]"]
```

并在题目节顶部加：
```markdown
> ⚠️ **承接前题**：本题题干承接 [[前驱文件名]]，需先阅读其题干与设定。
```

### 4.2 跨库同题

如果与其他库中的题目为同题：
```yaml
cross_references: ["[[其他库中的文件名]]"]
```

### 4.3 自编/改编题

```yaml
fidelity: 自编
source_note: 自编补充题（原书无对应题号）
```

## 五、入库后检查

### 5.1 逐文件检查
- [ ] frontmatter 六字段齐全（fidelity/difficulty/exam_stage/subject_module/pack/knowledge_points）
- [ ] 无 BOM（文件首 3 字节非 ef bb bf）
- [ ] YAML 可解析（无格式错误）
- [ ] 题干与 OCR 一致（逐字比对）
- [ ] 图片引用有效（文件在媒体仓库中）

### 5.2 批量检查
```bash
python 11-模板/scripts/validate_kb.py --quick
```
预期：0 error / 0 warning

### 5.3 模块习题集更新
```bash
python 11-模板/scripts/gen_module_set.py {模块名} "模块习题集-{模块名}.md"
```
新题自动出现在对应模块集中。

## 七、常见错误与预防

| 错误 | 原因 | 预防 |
|:--|:--|:--|
| 文件有 BOM | 写文件时编码含 BOM | 用 `encoding="utf-8"`（非 utf-8-sig）写入 |
| YAML 解析失败 | tags/cross_references 格式错误 | tags 用 `[a, b]` 行内格式；cross_references 用 `["[[链接]]"]` |
| 图片断链 | 图片未复制到媒体仓库 | 先复制再引用 |
| 题干与 OCR 不一致 | 提炼时改写 | fidelity 标为"原书改写"并加保真声明 |
| 重复入库 | 未查重 | 入库前 grep 题干关键句 |
| 序号冲突 | 同目录已有同编号文件 | 接续最大序号 +1 |
| 承接题缺前驱 | 拆分时未合并依赖小问 | 检查 depends_on 并合并或标注 |

## 八、习题书成书兼容规则

> 目标：让新题进入四篇 31 章习题书时，不需要再返工清理格式。源文件正文只保留四类正式块：**完整题目 / 完整解析 / 来源 / 知识点**；教师注释放 frontmatter 或 HTML 注释。

### 8.0 入库前置字段

- `pack` 必须为 `模块习题集`（生成器只收集该 pack 的题目进四篇习题书）。
- `subject_module` 必须是四篇之一：`化学原理 / 结构化学 / 有机化学 / 元素与分析`。
- `submodule` 用生成器能识别的章节关键词（如 `化学反应速率`、`晶体结构`），确保路由到正确章节。

### 8.1 教学块不进成书

- 不写 `小问关联 / 关联小问 / 得分点 / 读题定位 / 关键转换 / 计算要点 / 错误表 / 课堂提问表 / 易错分析 / 解题思路 / 相关图片 / 知识点映射` 等正文块。
- 不写 `### 🔗 同大题小问` 与 dataview 代码块；同大题关联放 frontmatter `cross_references`。
- 提示类内容如需保留，放 `<!-- 教师注 -->`，不要用 `> 💡 / > ⚠️` 进正文。

### 8.2 图片

- 只用 `![[物理哈希名.jpg]]`，不写 `<img src="images/...">`、不用行内多图、不把图片放进表格单元格。
- 图片必须独立成段，并在题干/答案语义块内；教学块图片若确需保留，归入题干或答案。

### 8.3 表格

- 用 Markdown pipe table；无 `colspan/rowspan`，列数不超过 8。
- 含合并单元格或超宽表：拆成多个小表或改纵向版式。
- 不写 HTML `<table>`。

### 8.4 公式

- 裸下标必须进数学模式：`$K_p$`、`$c_\mathrm{A}$`、`$O_h$`，不要写 `K_p` 正文。
- 标准态用 `θ` / `\theta`，不用 `°` / `\circ`；温度/角度单位里的 `°` 保留。
- 不用 texmath 不友好宏：`\xlongequal`、`\AA`、`\Biggl`；反键星号写成 `π\*`。
- 不把 `\\` 翻倍（OCR 转写残留），`\begin{aligned}` 行分隔用单个 `\\`。

### 8.5 入库后门禁

```bash
python 11-模板/scripts/gate_exercise_books.py
```

预期：audit / precheck / tables / docx-structure 全部 PASS；WARN 只允许出现在 `09-审计报告/2026-08-30-习题书V2-预检WARN允许清单.md`。
