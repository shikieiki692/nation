# 初赛模拟卷系列规范

> **一句话**：初赛模拟卷是**独立于专项卷 / 习题书 / 讲义的单独一套**，只收**模拟卷类题目**，不含真题；
> 允许复用他处已用的题，但**系列内各卷之间零重复**；难度以初赛为主，可含决赛难度。

---

## 一、系列定位：与题库其他模块的区别

| 维度 | 初赛模拟卷系列 | 专项卷（一分册/二分册专项卷 I~XII） | 习题书 | 讲义 |
|---|---|---|---|---|
| **产物位置** | `04-题库/初赛模拟卷N（非有机·答案版\|学生版）.md` | `04-题库/一分册专项卷N.md` 等 | `04-课件/习题集/习题书-*` | `04-课件/学生讲义/` |
| **题目来源** | **只收模拟卷类**（全真模拟卷、章后能力测试卷） | 教材分册配套 | 成书章节 | 讲义自编 |
| **是否含真题** | ❌ **不含**（`04-题库/真题/**` 一律排除） | 可含 | 可含 | 可含 |
| **有机题** | ❌ 全排除 | 按分册 | 按书 | 按讲 |
| **卷内结构** | 元素 / 结构 / 原理 三段，16 题 | 按专题 | 按章 | 按讲 |
| **版本** | 答案版 ＋ 学生版（双份） | 单份 | 单份 | 单份 |
| **是否回溯 used_in** | ✅ 回填（判「系列内零重复」） | 回填 | 回填 | 不回填 |
| **Word 产物** | `00-首页/题组Word/初赛模拟卷/` | `00-首页/题组Word/专项卷/` | `00-首页/题组Word/习题书/` | `06-学生侧材料/讲义/` |

**区分用的关键字段**（组卷时按此筛选）：
`source_category`、`source_grade`、`exam_stage`、`subject_module`、`fidelity`、`used_in` 中是否含「初赛模拟卷」。

### 不合格（排除）

- ❌ **真题**：`04-题库/真题/**`（省预赛、第 33~40 届初赛/决赛）—— 用户明确「初赛模拟卷不含真题」
- ❌ **真题改编题**：出现真题标记的题，如「2013年全国决赛」「2011年联考」「2009科大自招」。

  🔴 **真题标注有三类写法，只认年份式会漏掉后两类**（2026-09-22 实测漏进 1 道真真题）：

  | 类型 | 实例 |
  |---|---|
  | ① 年份式 | 「2013年全国决赛」「2011年联考」「2009科大自招」（正则须容 «全国|省|市»） |
  | ② **届次式** | 「**第28届中国化学奥林匹克初赛试题**」「第24届全国决赛试题」「第25届…江苏赛区选拔赛暨夏令营试题」 |
  | ③ **国际届次** | 「第 36 届国际竞赛试题」「（根据国际第 15 届化学竞赛试题改编）」 |

  🔴 **判据要查五处**：`basename` / `source` / FM `title` / 正文 H1 / **题面正文首段**。
  漏掉第五处是实测事故根因——某题 H1 干净如常（`题-051-7：合成氨原料气…`），
  而「（第28届中国化学奥林匹克初赛试题）」写在题面第一句。

  判为**不是**真题的三类情形（勿误杀）：正文「原题Y」而 Y 是题内物质编号；
  校勘注里的查重说明；已注明「与第N届某题同题，按 SOP 移除小问（题面与答案）」且确已移除。
- ❌ **有机章节题**：`subject_module` 与 `source` 会打架（丙酮溴化动力学判为「化学原理」，但 source
  写着「第9章 有机化学·B卷」）⇒ **只看 module 会把有机章的题放进卷**。须同时检查 source/H1 是否含「有机化学」。
- ❌ **练习集卡**：一张卡里含 ≥8 个 `**N.**` 独立小问的（如「上海中学-化学动力学基础-习题1」实为
  16 道各带一套数据的独立小题），当一道大题既不成立也不好排分。
- ❌ **答案指针式源**：`二分册能力测试/逐题/` 356 张只写「本题答案见『源卷』的参考答案区…不复制卷内
  OCR 答案」，**无真答案文本** ⇒ 不能直接出答案版（必须回源卷人工校）。判据见 §九·4。
- ❌ 有机化学题（全系列一律 0 题）
- ❌ 带风险标记的题：存疑 / 待回源 / 待补 / 缺图 / 答案缺失 / TODO 等

## 三、复用规则（关键，容易搞错）

> **题卡允许被多个成品复用**（`used_in` 是累积台账，不是当前占用）。
> 唯一硬约束是：**同一题不能在同一系列的多卷里重复出现。**

| 情形 | 是否可用 |
|---|:--:|
| `used_in: []`（没人用过） | ✅ |
| 已被专项卷 / 习题书 / 讲义用过 | ✅ **可以复用** |
| 已被**初赛模拟卷 I/II/III** 用过 | ❌ 排除（系列内零重复） |

**判据**：`used_in` 中是否包含字符串「初赛模拟卷」，而不是「是否非空」。
用「`used_in` 为空」当筛选条件会**误杀**大量可复用的题（实测少算 270 题）。

## 四、难度口径

- 主体：**初赛难度**
- **可含决赛难度** —— 用户明确「需要收集初赛模拟题甚至决赛难度的题目」
- 不出省预赛及以下难度的题
- 每题卷面标注难度星级（`⭐⭐⭐⭐` / `⭐⭐⭐⭐⭐`）

### 🔴 `exam_stage` 字段不可信，别拿它当判据（2026-09-22 实测）

用户质疑「你确定这是决赛难度？」后核查，发现该字段在多源上自相矛盾：

| 证据 | 说明 |
|---|---|
| 上海中学**第2分册** | 「决赛」30 题**全是 d4**；而**同分册「初赛」题里有 10 道 d5** —— 决赛比初赛还简单 |
| 上海中学第2分册内容 | 溶液和胶体、化学热力学基础、化学平衡、电化学基础 —— 都是**基础讲** |
| 汇智竞赛题目 | 「决赛」4 题难度 **d3**，而「初赛」131 题也是 d3 —— 同一难度两种考段 |

**更直接的证伪**：成卷里 2 道标「决赛」的题，内容分别是
「Ca(OH)₂ 通 CO₂ 沉淀是否消失」与「NaNO₃/KNO₃/NaCl/KCl 四盐分级结晶」——**初中竞赛级**。

⇒ **纪律**：

1. 组卷筛选**不用** `exam_stage` 过滤，只用 `difficulty`（≥⭐⭐⭐⭐）＋ 人工目检
2. **卷面不写「决赛难度 N 题」**，只报难度星级分布（已在 build 脚本里改掉）
3. 要找真决赛题，只能靠**内容人工判定**，或来源本身明确（如真题库的决赛卷）

> 因此上一版「决赛难度储备 8 题」的说法作废：**本系列至今尚未真正纳入经核实的决赛难度题。**

## 七、已记录的两个坑（别再踩）

1. **判断「某书是否入库」以章目内容为准，不能靠书名/目录名**。
   第三分册题卡 `source` 写作「化学竞赛能力测试·第N章」，不带「分册」二字 ⇒ `grep "第三分册"` 恒为 0，
   曾据此误判「第三分册未入库」。
   同理 `06-外部资料导入/OCR/` 下曾有目录名挂错：原「竞赛教程第三分册OCR源」装的其实是第一分册能力测试，
   **已于 2026-09-22 重命名为 `竞赛教程第一分册测试`**，与 `竞赛教程第二分册测试` 对齐。
   ⚠️ 因此**第三分册的 OCR 源不在名含「第三分册」的目录下**，而在 `化学能力测试OCR源/`
   （对应题库 `教材习题/化学能力测试` 180 题）。找素材时按这个对应关系走。

2. **二分册能力测试的答案是「指针式」**：`逐题/` 下 356 份题卡只写「本题答案见源卷参考答案区」，
   不复制答案文本；源答案存在 OCR 损坏与跨题粘连。
   ⇒ 从该源选题出**答案版**时，必须回 `卷-NN-*.md` 源卷人工校，不能直接引用逐题卡。

3. **跨源选题时题号会撞**：`教材习题/北斗40` 与 `教材习题/北斗学友` **各有各的 `题-001…` 编号体系**，
   同一号码指向完全不同的题（例：两边的 `题-013` 分别是「镉模板大环（有机）」与「蒸汽过程热力学」）。
   ⇒ 组装脚本必须带**「题卡目录」参数**显式指定，不能只按号码 `glob`。
   ⇒ 选题清单里也要写清来源目录。

4. **北斗学友卡自带「`## 第 N 题（…）`」源标题行**，其 `#` 级别**高于**卷内 `### 第 N 题`，
   直接拼进卷内会**破坏标题层级**（卷面出现比题号更大的标题）。
   ⇒ 组装时必须剥掉源卡自带标题行（卷 V 已在 `clean()` 加规则）；卷 I~IV 的北斗40 卡无此问题。

5. **反斜杠统计必须用 `.py` 脚本文件跑**：在 bash 双引号里写 `re.finditer(r'\\\\')`，
   `\\\\` 会被 shell 吞成 `\\`，正则随之退化为**匹配单反斜杠** ——
   实测因此把 408 处 LaTeX 命令误报成「408 处双反斜杠」。
   ⇒ 凡含反斜杠/非 ASCII 的核验，一律 Write 成 `.py` 再执行。

## 八、成卷后的收尾（必做）

1. 回填题卡 `used_in`（16 张／卷）：写作单元素列表，值为「初赛模拟卷N（非有机）」加双方括号
   （N 为卷号罗马数字，如卷三即「初赛模拟卷III（非有机）」）
2. 生成 Word（答案版＋学生版）→ `00-首页/题组Word/初赛模拟卷/`
3. 校验：OMML 公式守恒（`oMathPara == 显示域`、`oMath − oMathPara == 行内域`）、
   media 数 == md 图数、`°` 数守恒、正文无 LaTeX 残留
4. soffice 渲染 PDF 逐页目验公式

## 九、多源组卷的技术要点（卷 VI 起启用，2026-09-22）

来源从 1~2 家扩到 8 家后，北斗专用组装脚本不再够用。以下是必须守住的几条：

### 1. 通用抽取器：各源题卡骨架不一致

| 差异点 | 表现 |
|---|---|
| H1 写法 | `# 题-078-一分册测试-…` / `# 题-039-3：FeₓO晶体…` / `# BaO 溶解热与…` / `# HChO晶-06 KMgF₃…` |
| 题面节 | 有的有 `## 题目`，有的正文直接在 H1 后 |
| 答案节 | `## 参考答案` / `## 参考答案:` / `## 解答` / **无标题的 `<details>` 折叠块** |
| 尾部元数据 | `## 知识点映射` / `## 相关题目` / `## 解析要点` / `## 解题思路` / `## 关联` |

⇒ 抽取规则：**题面 = H1 → 首个答案起点**（答案起点 = 答案节标题 **或** `<details>` 折叠块；
化学能力测试 150/180 张的答案就在无标题 details 里，漏判会把答案整个吞进题面）。
答案 = 答案起点 → 首个尾部元数据节。`<details>/<summary>` 外壳要剥（Word 无折叠语义）。

### 2. 小问编号：源前缀必须**卡内实测**，且投票后要**回查**

四类写法：`**N-M**`（一分册测试/化学能力测试/HChO/0407）、裸 `N-M`、`(N)`（上海中学/教程一分册）、
圈码 `①`（条件编号，勿动）。

- 前缀从**卡内**投票得出（不是文件名！——北斗那次吃过「文件名序位 06 而卡内实为 7-x」的亏）
- ⚠️ **投票后必须回查该前缀是否真存在**：只看 Counter 会把 `(2026-09-18)` 这类日期、
  wikilink 路径里的数字串投成前缀（实测「上海中学-化学动力学基础-习题1」投出 P=9，卡内却一个 `9-M` 都没有）
- 只改 `P-M` / `**P-M**`，**不碰 `(N)` 与 `①`**（避免误伤化学式 `1-1 型电解质`、`1-0.2804×2`）
- 核验：逐题断言「小题标签前缀 == 卷内题号」，并把三类噪声排除后再看
  （`<!-- 校勘注 -->`、`2026-09-18` 日期、wikilink 路径「…／题-025决-1-4-…」）——否则核验被假阳性淹没

### 3. 题面残留源题序号（两种形态都要剥）

- **加粗型** `**2.**`（上海中学卡）：`vote_prefix` 返回 None（卡内无 `N-M`）时也要剥
- **裸号型** `9.`（教程一分册卡）：比加粗型更危险，**小问编号也长这样**
  （卷 VIII 第 1 题题面就以「1. 推出 A~E…」开头）⇒ 判据取「首行序号 ≠ 1 **且** 文内存在从 1 起的小问」

### 4. 答案形态判据：**不要用「指针句式」匹配**

两次翻车的教训：
- 纯指针卡写「> 本题答案见 [[XX卷]]…」（「本题」二字挡住了 `^>\s*答案` 式正则）
- 有答案卡末尾写「> 答案见『…』」作溯源（句式正则反而把它剔干净了）

**稳健判据 = 剔除 `>` 引用块后还剩多少正文 ≥ 15 字**（指针/元信息全在引用块里）。
更粗的字数判据会把 100+ 字的指针说明误判成答案（二分册实测误判 154 题）。

### 5. `$$` 块内夹空行 → pandoc 直接放弃识别

源卡常写作 `$$\n\n公式\n\n$$`，pandoc 的 `tex_math_dollars` 遇空行不再当显示数学，
整块降级成 `{2}{2}{5}(){4}` 碎片 + 字面 `$$`（实测卷 VIII 第 8 题三块）。
⇒ **在 md 源**上归一（`$$` 前后紧跟的空行吃掉）。只在 docx 管线里修会造成
「md 与 docx 两个口径不一致」，反而更难排查。

### 6. 图片引用形态：除纯哈希外还要查畸形/路径式

初赛讲义目录实测 8 处 `![]路径)`（**缺左括号**），Obsidian 与 pandoc 都不认，Word 里印出整条路径。
⇒ 组卷前扫 `!\[\](?!\()`，核对媒体仓库后改回纯哈希；顺便修源卡（这是源卡缺陷，不是组卷引入）。

### 7. 选题必须**固化**（`vol_plan.json`）

🔴 **本轮回填 `used_in` 时踩到的真坑**：`pick` 依赖 pool，而 pool 以「`used_in` 含『初赛模拟卷』」
排除候选 —— **回填这个动作本身就会改变 pool**，导致重跑时那 48 张被自己排除、选题整体漂移
（156 分漂到 146 分，且旧标记留在卡上 → `used_in` 与实际成卷不符）。
⇒ 首次挑选后立即把 `(路径, 模块, 分值)` 固化成 `vol_plan.json`，之后一律照 plan 组装。

### 8. 校验基准：以 **pandoc 第三方口径**为准，别信自写正则

自写 `$` 正则与 pandoc 的 `$` 规则总差 ±1（卷 VI 实测 396 vs 395），
而 **pandoc 与 docx 两个独立口径一致** ⇒ 用 `pandoc --mathml` 数 `<math display="block|inline">`
作为基准，与 docx 的 `oMathPara` / `oMath−oMathPara` 对比。

> ⚠️ pandoc 转 HTML 会报一批 `Could not convert TeX math … rendering as TeX`（卷 VI 27 条），
> 但 **docx（OMML）路径与 HTML/MathML 路径支持面不同，docx 实际全部转换成功**
> （坐实方法：在 docx 的 `<m:t>` 里检索公式特征串）。**不要据此判 docx 有缺陷**，
> 真正的判据是「docx 正文反斜杠 0 / 字面 `$` 0 / 含 `$` 而无公式的段落 0」。
