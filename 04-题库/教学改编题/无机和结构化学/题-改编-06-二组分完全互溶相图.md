# 题-改编-06-二组分完全互溶相图

## 题目

苯（A）和甲苯（B）形成理想溶液，沸点分别为 80.1°C 和 110.6°C。在 1 atm 下，其沸点-组成图（$T$-$x$ 图）中：

- 当 $x_B = 0.50$（甲苯的摩尔分数）时，泡点温度约为 92°C，露点温度约为 95°C。
- 在 92°C 时，液相组成 $x_B^L = 0.50$，与之平衡的气相组成 $x_B^V = 0.33$。

(a) 画出苯-甲苯体系的 $T$-$x$ 相图（沸点-组成图），标注液相线和气相线，以及各相区。

(b) 对于 $x_B = 0.50$ 的混合物，在进行简单蒸馏时，第一滴馏出物的组成是什么？随着蒸馏进行，馏出物组成如何变化？

(c) 要通过精馏获得 99% 以上的纯苯，需要什么条件？从相图角度说明原因。

## 参考答案

**(a) 沸点-组成图：**

```
T(°C)
110.6|B(纯)
     |    气相线
     |   /    \
     |  / 气相  \
  95 | ·--------·  露点
     |/    V+L   \
  92 | ·--------·  泡点
     |  \  液相  /
     |   \    /
  80.1|A(纯)
     +--+--------+--
     0  0.33 0.50  1.0  x_B
```

- 上方区域（气相线以上）：V（气相/蒸气）
- 下方区域（液相线以下）：L（液相）
- 气相线与液相线之间：L + V（气液两相共存）
- 液相线（泡点线）：液体开始沸腾的温度连线
- 气相线（露点线）：蒸气开始凝结的温度连线

注意：对于理想溶液，气相线在液相线上方（低温侧为液相），且气相线偏向低沸点组分（苯）一侧。

**(b) 简单蒸馏分析：**

对于 $x_B = 0.50$ 的混合物：

- 在泡点（约 92°C）开始沸腾时，产生的第一滴蒸气组成为 $x_B^V = 0.33$（富苯）。
- 即第一滴馏出物中苯的摩尔分数为 $1 - 0.33 = 0.67$，比原料中苯含量（0.50）更高。
- 随着蒸馏进行：苯优先蒸出 → 液相中苯含量减少 → 液相组成沿液相线向右（高 B 方向）移动 → 沸点升高 → 产生的蒸气中苯含量也逐渐降低。
- 因此，馏出物中苯含量逐渐降低，后期馏出物更富甲苯。

**(c) 精馏条件：**

要获得 99% 以上的纯苯，需要**精馏（分馏）**而非简单蒸馏：

- 精馏塔需要足够的**理论塔板数**（理论板数），使得气液多次接触达到平衡。
- 从相图看：每次气液平衡，气相中苯的含量都比液相高（$x_B^V < x_B^L$，即苯富集于气相）。通过足够多的平衡级（塔板），可以将苯含量逐步提高到 99% 以上。
- 塔顶需要回流（冷凝液部分回流至塔内），以维持塔内气液平衡接触。
- 理论上，对于理想溶液，只要塔板数足够多，可以获得任意纯度的产品。

## 解题思路

1. 沸点-组成图（$T$-$x$ 图）与凝固点-组成图结构类似，但方向相反：低沸点组分在低温侧。
2. 简单蒸馏的规律：蒸气总是富集低沸点组分（苯），这就是蒸馏分离的原理。
3. 关键结论：简单蒸馏只能部分分离，要获得高纯度产品必须使用精馏。
4. 易错点：在 $T$-$x$ 图中，气相线在上方（高温侧），液相线在下方（低温侧），这与凝固点图相反。
