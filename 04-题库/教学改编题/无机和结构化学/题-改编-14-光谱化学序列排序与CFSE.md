# 题-改编-14-光谱化学序列排序与CFSE

## 题目

已知以下配体的光谱化学序列（由弱到强）：

$$\text{I}^- < \text{Br}^- < \text{Cl}^- < \text{F}^- < \text{OH}^- < \text{H}_2\text{O} < \text{NH}_3 < \text{en} < \text{NO}_2^- < \text{CN}^-$$

(a) 请将以下配体按场强由弱到强排序：$\text{SCN}^-$、$\text{NH}_3$、$\text{CN}^-$、$\text{Cl}^-$、$\text{H}_2\text{O}$。已知 $\text{SCN}^-$（以 S 配位）位于 $\text{Br}^-$ 与 $\text{Cl}^-$ 之间。

(b) 对于 $d^6$ 构型的 Co$^{3+}$ 离子，分别计算在弱场配体 $\text{H}_2\text{O}$ 和强场配体 $\text{NH}_3$ 场中的 CFSE（晶体场稳定化能），假设 $\Delta_o(\text{H}_2\text{O}) = 18{,}600\ \text{cm}^{-1}$，$\Delta_o(\text{NH}_3) = 22{,}900\ \text{cm}^{-1}$，电子成对能 $P = 21{,}000\ \text{cm}^{-1}$。判断两种情况下的自旋态。

(c) 实验测得 [Co(H₂O)₆]³⁺ 为高自旋（磁矩约 5.0 B.M.），而 [Co(NH₃)₆]³⁺ 为低自旋（磁矩约 0 B.M.）。请解释这一现象，并说明光谱化学序列在此判断中的作用。

## 参考答案

**(a) 排序（由弱到强）：**

$$\text{Cl}^- < \text{SCN}^- < \text{H}_2\text{O} < \text{NH}_3 < \text{CN}^-$$

SCN⁻（以 S 配位）位于 Br⁻ 与 Cl⁻ 之间，故排在 Cl⁻ 之后、H₂O 之前。

**(b) CFSE 计算：**

对于 Co³⁺（$d^6$）：

- 在 H₂O 场中：$\Delta_o = 18{,}600\ \text{cm}^{-1} < P = 21{,}000\ \text{cm}^{-1}$，为**高自旋**
  - 电子排布：$t_{2g}^4 e_g^2$
  - CFSE $= 4 \times (-0.4\Delta_o) + 2 \times (0.6\Delta_o) = -1.6\Delta_o + 1.2\Delta_o = -0.4\Delta_o$
  - CFSE $= -0.4 \times 18{,}600 = -7{,}440\ \text{cm}^{-1}$
  - 加上成对能修正：额外 0 对（与自由离子相同电子排布的成对数）
  - 实际 CFSE $= -7{,}440\ \text{cm}^{-1}$

- 在 NH₃ 场中：$\Delta_o = 22{,}900\ \text{cm}^{-1} > P = 21{,}000\ \text{cm}^{-1}$，为**低自旋**
  - 电子排布：$t_{2g}^6 e_g^0$
  - CFSE $= 6 \times (-0.4\Delta_o) + 0 \times (0.6\Delta_o) = -2.4\Delta_o$
  - CFSE $= -2.4 \times 22{,}900 = -54{,}960\ \text{cm}^{-1}$
  - 需要减去因低自旋多出的成对能：相比自由离子多 2 对，即 $-2P$
  - 实际 CFSE $= -54{,}960 + 2 \times 21{,}000 = -54{,}960 + 42{,}000 = -12{,}960\ \text{cm}^{-1}$

**(c) 解释：**

- H₂O 在光谱化学序列中位于中间偏弱的位置，对 Co³⁺ 产生的 $\Delta_o$ 不足以克服电子成对能 $P$，因此采取高自旋排布，有 4 个未成对电子。
- NH₃ 场强较高，$\Delta_o > P$，迫使电子优先成对填入 $t_{2g}$ 轨道，形成低自旋排布，所有电子成对，磁矩为零。
- 光谱化学序列的核心作用在于：通过比较 $\Delta_o$（取决于配体在序列中的位置）与 $P$（取决于金属离子本身），判断配合物的自旋态。

## 解题思路

1. 首先熟记光谱化学序列，注意 SCN⁻ 以 S 配位时属于弱场配体。
2. 判断高/低自旋的关键是比较 $\Delta_o$ 与 $P$ 的大小：$\Delta_o < P$ 为高自旋，$\Delta_o > P$ 为低自旋。
3. CFSE 的计算要注意：高自旋和低自旋情况下 $t_{2g}$ 和 $e_g$ 的电子数不同，直接影响 CFSE 值。
4. 易错点：低自旋情况下的 CFSE 需要额外考虑成对能修正，不能只用 $-2.4\Delta_o$ 就结束。
