# 题-改编-08-摩尔电导率与离子迁移

## 题目

在 25°C 时，以下是部分电解质的极限摩尔电导率 $\Lambda_m^{\infty}$：

| 离子 | $\lambda^{\infty}$ (S·cm²·mol⁻¹) |
|:---:|:---:|
| H⁺ | 349.8 |
| Na⁺ | 50.1 |
| K⁺ | 73.5 |
| Cl⁻ | 76.3 |
| CH₃COO⁻ | 40.9 |
| OH⁻ | 198.0 |
| ½SO₄²⁻ | 80.0 |

(a) 利用 Kohlrausch 独立迁移定律，计算以下电解质的极限摩尔电导率：

- HCl、NaOH、CH₃COOH、NaCl

(b) 已知 0.100 mol/L CH₃COOH 溶液的电导率 $\kappa = 5.24 \times 10^{-3}\ \text{S/cm}$，计算其摩尔电导率 $\Lambda_m$，并进一步计算该浓度下 CH₃COOH 的电离度 $\alpha$ 和电离平衡常数 $K_a$。

(c) 解释为什么弱电解质的 $\Lambda_m$ 随浓度降低而急剧增大，而强电解质的变化较平缓。

## 参考答案

**(a) 极限摩尔电导率（Kohlrausch 定律）：**

$\Lambda_m^{\infty} = \nu_+ \lambda_+^{\infty} + \nu_- \lambda_-^{\infty}$

- HCl：$\Lambda_m^{\infty} = 349.8 + 76.3 = 426.1\ \text{S·cm}^2\text{·mol}^{-1}$
- NaOH：$\Lambda_m^{\infty} = 50.1 + 198.0 = 248.1\ \text{S·cm}^2\text{·mol}^{-1}$
- CH₃COOH：$\Lambda_m^{\infty} = 349.8 + 40.9 = 390.7\ \text{S·cm}^2\text{·mol}^{-1}$
- NaCl：$\Lambda_m^{\infty} = 50.1 + 76.3 = 126.4\ \text{S·cm}^2\text{·mol}^{-1}$

**(b) CH₃COOH 电离度计算：**

摩尔电导率：

$$\Lambda_m = \frac{\kappa}{c} = \frac{5.24 \times 10^{-3}}{0.100 \times 10^{-3}} = \frac{5.24 \times 10^{-3}}{1.00 \times 10^{-4}} = 52.4\ \text{S·cm}^2\text{·mol}^{-1}$$

注意单位换算：$c = 0.100\ \text{mol/L} = 0.100 \times 10^{-3}\ \text{mol/cm}^3 = 1.00 \times 10^{-4}\ \text{mol/cm}^3$

电离度：

$$\alpha = \frac{\Lambda_m}{\Lambda_m^{\infty}} = \frac{52.4}{390.7} = 0.134 = 13.4\%$$

电离平衡常数（Ostwald 稀释定律）：

$$K_a = \frac{c\alpha^2}{1 - \alpha} = \frac{0.100 \times (0.134)^2}{1 - 0.134} = \frac{0.100 \times 0.0180}{0.866} = \frac{0.00180}{0.866} = 2.08 \times 10^{-3}$$

（文献值 $K_a = 1.75 \times 10^{-3}$，数量级一致，偏差来自实验数据的近似性。）

**(c) $\Lambda_m$ 随浓度变化的解释：**

- **强电解质**（如 NaCl、HCl）：在溶液中完全电离，$\Lambda_m$ 随浓度降低而缓慢增大。这主要是因为浓度降低时，离子间相互作用减弱（离子氛松弛效应和电泳效应减小），离子迁移速率略增。

- **弱电解质**（如 CH₃COOH）：在溶液中仅部分电离。浓度降低时，电离度 $\alpha$ 显著增大（稀释促进电离），导致溶液中离子数目急剧增加，$\Lambda_m$ 因此急剧增大。当浓度趋近于零时，$\alpha \rightarrow 1$，$\Lambda_m \rightarrow \Lambda_m^{\infty}$。

- 本质上：强电解质的 $\Lambda_m$ 变化反映的是离子间相互作用的变化（次要效应），而弱电解质的 $\Lambda_m$ 变化主要反映电离度的变化（主要效应）。

## 解题思路

1. Kohlrausch 定律是计算极限摩尔电导率的基础：$\Lambda_m^{\infty}$ 等于正、负离子极限摩尔电导率之和。
2. 摩尔电导率 $\Lambda_m = \kappa / c$，注意单位一致：$\kappa$ 用 S/cm，$c$ 用 mol/cm³。
3. 电离度 $\alpha = \Lambda_m / \Lambda_m^{\infty}$，这是弱电解质电离度的实验测定方法（电导法）。
4. 易错点：单位换算是最常见的错误来源。$c$（mol/L）→ mol/cm³ 需要除以 $10^3$。
