### 基础回顾（第1–15题）

**第1题**：(a) 二氯·四氨合钴(III)氯化物，Co(III)，配位数6；(b) 六氯合铂(IV)酸钾，Pt(IV)，配位数6；(c) 五羰基合铁(0)，Fe(0)，配位数5；(d) 六氟合铝(III)酸钠，Al(III)，配位数6；(e) 四氨合铜(II)硫酸盐，Cu(II)，配位数4。

**第2题**：(a) $\mathrm{K_3[Fe(CN)_6]}$；(b) $\mathrm{[Co(H_2O)(NH_3)_5]_2(SO_4)_3}$；(c) $\mathrm{[Cu(en)_2]^{2+}}$；(d) $\mathrm{Ni(CO)_4}$；(e) $\mathrm{Fe(C_5H_5)_2}$。

**第3题**：(a) 内界$\mathrm{[CoCl(NH_3)_5]^{2+}}$，外界$\mathrm{Cl^-}$(2个)；$\mathrm{[CoCl(NH_3)_5]Cl_2 \rightarrow [CoCl(NH_3)_5]^{2+} + 2Cl^-}$。(b) 内界$\mathrm{[Fe(CN)_6]^{3-}}$，外界$\mathrm{K^+}$(3个)；$\mathrm{K_3[Fe(CN)_6] \rightarrow 3K^+ + [Fe(CN)_6]^{3-}}$。(c) 无外界，$\mathrm{[Pt(NH_3)_2Cl_2]}$为中性分子，不电离。

**第4题**：(a) 配位原子：N、O、3个Cl；配位数=1+1+3=5。(b) 配位原子：6个O（C₂O₄²⁻为双齿配体，每个提供2个O）；配位数=3×2=6。(c) 配位原子：4个N（en为双齿配体，每个提供2个N）；配位数=2×2=4。(d) 配位原子：4个O；配位数=4。

**第5题**：(b)正确——配位数是直接与中心原子（离子）成键的配位原子的个数，不是配体的个数（如EDTA为1个配体但配位数为6）。(a)错误——配位数是配位原子数，不等于配体数。(c)错误——配位数可以是奇数或偶数（如配位数5、7都存在）。(d)错误——配位数与氧化数无直接关系。

**第6题**：(a) $\mathrm{Ni(CO)_4}$；(b) $\mathrm{Na_3[AlF_6]}$（冰晶石）；(c) $\mathrm{[Cu(en)_2]SO_4}$；(d) $\mathrm{[IrCl_3(PMe_3)_3]}$。

**第7题**：(a) Zn²⁺为$d^{10}$，无CFSE偏好，$sp^3$杂化→四面体；(b) Ni²⁺为$d^8$，CN⁻为强场配体→dsp²杂化→平面正方形（获得额外CFSE）；(c) $d^8$强场配体→dsp²杂化→平面正方形（CFSE更大）；$d^{10}$→$sp^3$杂化→四面体（无CFSE偏好）。

**第8题**：MA₃B₃型八面体配合物有**2种**几何异构体：面式（fac-）：3个B占据八面体的一个三角面（相邻，彼此夹角均为90°）。经式（mer-）：3个B占据八面体的一个子午面（两个B在对位，第三个B与它们垂直）。fac和mer互为几何异构体，fac对称性更高（有C₃轴）。

**第9题**：两者均为Fe²⁺($d^6$)配合物。\n[Fe(CN)₆]⁴⁻：CN⁻为强场配体（△ₒ > P）→低自旋，t₂g⁶eg⁰，所有电子成对，未成对电子数=0，μ=0 BM（反磁性）。\n[Fe(H₂O)₆]²⁺：H₂O为弱场配体（△ₒ < P）→高自旋，t₂g⁴eg²，4个未成对电子，μ=√(4×6)=4.90 BM（顺磁性）。\n\n| | | [Fe(CN)₆]⁴⁻ | [Fe(H₂O)₆]²⁺ |\n|:---|:---|:---:|:---:|\n| d电子数 | | 6 | 6 |\n| 场的相对强弱 | | 强场 | 弱场 |\n| 电子排布 | | t₂g⁶eg⁰ | t₂g⁴eg² |\n| 未成对电子数 | | 0 | 4 |\n| 磁矩(BM) | | 0（反磁性） | 4.90（顺磁性） |

**第10题**：Rh配位数为4（1个Cl + 3个PPh₃），dsp²杂化→平面四方形。Rh为Rh(I)，4d⁸电子构型。结构：Rh在中心，Cl和3个PPh₃在四方形四个顶点。

**第11题**：[RhCl(PPh₃)₃]：配位数4（1个Cl + 3个PPh₃），dsp²杂化。[IrCl(CO)(PPh₃)₂]：配位数4（1个Cl + 1个CO + 2个PPh₃），dsp²杂化。两者均为平面四方形，中心金属为d⁸构型。

**第12题**：(a) 螯合物是由多齿配体与中心离子形成的含环配合物；(b) 螯合效应指螯合物比类似单齿配体形成的配合物更稳定（主要由熵增驱动）；(c) 五元环和六元环的键角接近正常键角（109.5°），环张力最小，因此最稳定。

**第13题**：(a) Cu²⁺(Irving-Williams序列中Cu²⁺>Zn²⁺)，且Jahn-Teller效应增强稳定性；(b) $\mathrm{[Fe(CN)_6]^{3-}}$的$\beta_6$更大（$\lg\beta_6$=42 vs 35）：Fe³⁺电荷高于Fe²⁺→与CN⁻的静电引力和共价作用更强→配合物更稳定；同时$d^5$低自旋态的交换能贡献也增强了稳定性。；(c) Co³⁺配合物远比Co²⁺稳定，因为Co³⁺(d⁶低自旋)CFSE大且电荷高。

**第27题**：(a) 硝基N配位：$\mathrm{M-NO_2}$；亚硝酸根O配位：$\mathrm{M-ONO}$。(b) $\mathrm{Co^{3+}}$为硬酸，N为较硬碱→N配位更稳定。(c) 键合异构。

**第28题**：(a) AgBr + 2S₂O₃²⁻ ⇌ [Ag(S₂O₃)₂]³⁻ + Br⁻。K = Ksp × Kf = 5.0×10⁻¹³ × 2.8×10¹³ = 14。(b) 设溶解度为s mol/L：K = s²/(1.0-2s)² ≈ s²/1.0 → s ≈ √14 ≈ 3.7 mol/L（精确解约3.2 mol/L）。(c) 溶解度显著降低。K = s²/(0.01-2s)²，分母变小→要保持K=14→s必须减小。说明定影液中Na₂S₂O₃浓度对定影效果至关重要，浓度过低会导致AgBr无法充分溶解。

**第29题**：$\beta_4 = \frac{[Cu(NH_3)_4^{2+}]}{[Cu^{2+}][NH_3]^4}$。设$[Cu^{2+}] = x$，则$[Cu(NH_3)_4^{2+}] \approx 0.10 - x \approx 0.10$，$[NH_3] \approx 0.10$（因$\beta_4$极大，配体消耗可忽略）。$x = 0.10/(1.1 \times 10^{13} \times 0.10^4) = 9.1 \times 10^{-11}$ mol/L。

**第30题**：(a) Fe²⁺为d⁶，H₂O弱场→高自旋：t₂g⁴eg²，CFSE = 4×(-0.4Δₒ)+2×(+0.6Δₒ) = -0.4Δₒ，4个未成对电子。(b) Fe²⁺为d⁶，CN⁻强场→低自旋：t₂g⁶eg⁰，CFSE = -2.4Δₒ（不计成对能）或-2.4Δₒ+3P（计成对能），0个未成对电子。(c) Co³⁺为d⁶，NH₃强场→低自旋：t₂g⁶eg⁰，CFSE = -2.4Δₒ，0个未成对电子。(d) Co³⁺为d⁶，F⁻弱场→高自旋：t₂g⁴eg²，CFSE = -0.4Δₒ，4个未成对电子。

**第31题**：JT效应：电子简并的非线性分子发生几何畸变消除简并。(a) $d^9$：$e_g$上有简并→大畸变；(b) $d^1$：$t_{2g}$上简并→小畸变；(c) $d^3$：$t_{2g}^3$无简并→无畸变；(d) $d^4$高自旋：$t_{2g}^3 e_g^1$→$e_g$简并→大畸变。

**第32题**：(a) AgCl溶解反应：AgCl + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻。K = Ksp × Kf = 1.8×10⁻¹⁰ × 1.7×10⁷ = 3.06×10⁻³。设溶解度为s：K = s²/(6.0-2s)² ≈ s²/36 → s² = 0.11 → s ≈ 0.33 mol/L。(b) pH=7时，NH₃转化为NH₄⁺（pKa=9.25）：[NH₃]/[NH₄⁺] = 10^(7-9.25) ≈ 0.0056，游离NH₃浓度大大降低。此时[Ag⁺]升高，Q = [Ag⁺][Cl⁻] 可能超过Ksp，**会有AgCl沉淀生成**。

### 教材习题精选（第74–78题）

**第74题**：等体积混合后初始浓度：$c(en)_0 = 1.00$ mol/L，$c(Ni^{2+})_0 = 0.100$ mol/L。en过量→$[en] \approx 1.00 - 3 \times 0.100 = 0.70$ mol/L（消耗3个en/Ni²⁺）。$\beta_3 = 2.14 \times 10^{18} = [Ni(en)_3^{2+}]/([Ni^{2+}][en]^3)$。$[Ni^{2+}] = 0.100/(2.14 \times 10^{18} \times 0.70^3) = 0.100/(2.14 \times 10^{18} \times 0.343) = 1.36 \times 10^{-19}$ mol/L。

**第75题**：(1) $\beta_4(Cu) = 1.9 \times 10^4 \times 3.9 \times 10^3 \times 1.0 \times 10^3 \times 1.5 \times 10^3 = 1.1 \times 10^{14}$；$\beta_4(Zn) = 2.0 \times 10^2 \times 5.3 \times 10^2 \times 2.0 \times 10^2 \times 1.1 \times 10^2 = 2.3 \times 10^{9}$。(2) Cu²⁺>Zn²⁺因为：Cu²⁺在Irving-Williams序列中位于Zn²⁺之前，Jahn-Teller效应和较高有效核电荷使Cu²⁺配合物更稳定。(3) Irving-Williams序列预测$Ni^{2+} > Cu^{2+} > Zn^{2+}$...实际上Cu²⁺>Ni²⁺，序列正确。

**第76题**：$E^\ominus([Fe(CN)_6]^{3-}/[Fe(CN)_6]^{4-}) = E^\ominus(Fe^{3+}/Fe^{2+}) + 0.059\lg\frac{K_{稳}(Fe^{2+})}{K_{稳}(Fe^{3+})} = 0.771 + 0.059 \times (35-42) = 0.771 - 0.413 = 0.358$ V。

**第77题**：$[Ag^+] = [Ag(NH_3)_2^+]/(\beta_2 \times [NH_3]^2) = 0.10/(1.7 \times 10^7 \times 0.10^2) = 5.9 \times 10^{-7}$ mol/L。$Q = [Ag^+][Cl^-] = 5.9 \times 10^{-7} \times 0.010 = 5.9 \times 10^{-9}$ > $K_{sp}(AgCl) = 1.8 \times 10^{-10}$→产生AgCl沉淀。

**第78题**：$K'_\text{稳} = K_\text{稳} \times \alpha(NH_3)^4$，其中$\alpha(NH_3)$为游离NH₃占总氨的比例（受pH影响）。pH=10时$\alpha(NH_3) \approx 1$（$NH_4^+$的$pK_a = 9.25$，pH=10时大部分为$NH_3$）→$K'_\text{稳} \approx K_\text{稳}$。

### 决赛真题精选（第79–83题）

**第79题**：(1) Cu⁺：$[Ar]3d^{10}$；Cu²⁺：$[Ar]3d^9$。(2) Cu⁺倾向配位数2（直线形）或4（四面体），$d^{10}$无CFSE偏好；Cu²⁺倾向配位数4（平面正方形）或6（八面体，拉长）。
(3) $\mathrm{[Cu(NH_3)_4]^{2+}}$中NH₃场强>H₂O→$\Delta_o$增大→吸收蓝移→呈现更深蓝色（补色原理）。(4) Cu⁺$d^{10}$无d-d跃迁→无色；Cu²⁺$d^9$有d-d跃迁→有色。

**第80题**：(1) 三者电势：$Fe^{3+}/Fe^{2+}$(0.77V) < $[Fe(phen)_3]^{3+}/[Fe(phen)_3]^{2+}$(1.12V)。phen配合物电势更高→phen稳定化Fe²⁺更多→Fe³⁺态相对不稳定。CN⁻配合物电势0.36V<0.77V→CN⁻稳定化Fe³⁺更多。
(2) $[Fe(CN)_6]^{3-}$的Fe³⁺态最稳定；$[Fe(phen)_3]^{2+}$的Fe²⁺态最稳定。
(3) $E^\ominus = 1.12 - 0.36 = 0.76$ V。$\lg K = nE^\ominus/0.059 = 1 \times 0.76/0.059 = 12.9$。$K = 10^{12.9} \approx 8 \times 10^{12}$。

**第81题**：(1) CO有空的$\pi^*$反键轨道→可接受金属d电子的反馈$\pi$键→极强配体场。(2) 三角双锥，Fe(0)，$dsp^3$杂化。(3) Fe(0)有8e + 5×2 = 18e ✓。(4) CO配位激活不饱和烃→插入反应→催化加氢、Fischer-Tropsch合成等。

**第82题**：(1) $d^6$低自旋：$t_{2g}^6 e_g^0$。(2) $\mathrm{[Co(NH_3)_6]^{3+}}$。(3) 磁矩从0变为约4.9$\mu_B$（高自旋$d^6$，4个未成对电子）。(4) F⁻为弱场配体→$\Delta_o$ < P→高自旋→$t_{2g}^4 e_g^2$→4个未成对电子。

**第83题**：(1) Si原子半径大，3d轨道能量高→难以形成稳定配位键。(2) 例：硅烷基配体（如$\mathrm{SiH_3^-}$）可与金属形成$\sigma$配位。(3) Si为较硬碱→倾向与硬酸（高氧化态金属如Ti⁴⁺、Zr⁴⁺）结合。

**第84题**：Mn(acac)₃为八面体结构，Mn(III)在中心，三个双齿配体acac⁻以O,O'方式配位。M(AA)₃型配合物不存在几何异构体，仅存在一对旋光异构体（Δ和Λ构型）。

**第85题**：根据磁矩简易计算公式$\mu = \sqrt{n(n+2)}\mu_B$：$4.9 = \sqrt{n(n+2)}$，解得$n = 4$（未成对电子数为4）。

**第86题**：该配合物**有手性**。Mn(acac)₃不存在对称面和对称中心（第二类对称元素），只有旋转轴（C₃轴），因此具有手性。判据：若分子存在对称面或对称中心，则一定没有手性；反之，若不存在第二类对称元素，则具有手性。

**第87题**：trans-[Co(en)₂Cl₂]⁺：八面体结构，两个Cl处于反式位置（trans），两个乙二胺(en)为双齿配体。立体异构体：A⁺的两个异构体互为**旋光异构体**（Δ和Λ构型），因为trans构型无几何异构体，但有旋光异构。

**第88题**：$\mathrm{MbO_2}$呈抗磁性→强场低自旋。Fe为+2价（$d^6$），电子均配对。价电子排布为：$t_{2g}^6 e_g^0$。

**第89题**：氨分子与$\mathrm{Zn^{2+}}$形成配合物后，N原子上的孤对电子与$\mathrm{Zn^{2+}}$成键，原来的孤对电子与成键电子对间的作用变成了成键电子对间的相互作用，排斥力减弱，故H-N-H键角变大。H-N成键电子对和$\mathrm{Zn^{2+}}$-N成键电子对的排斥力与H-N成键电子对间的排斥力十分接近，所以键角为$109.5°$。

**第90题**：(1) 由元素分析得C:H:N质量分数→摩尔比C:H:N = 32.1:24.2:6.0，与$n = 2$（32:24:6）吻合，故**$n = 2$**。(2) Ru(II)为$4d^6$构型，抗磁性说明电子成对占据3个4d轨道，中心钌原子为**$d^2sp^3$杂化**，配合物呈八面体构型。

**第91题**：V为+3价，价电子组态为$3d^2$。在正常情况下三棱柱构型的$V^{3+}$应该有两个单电子，但$[\mathrm{V_2(edt)_4}]^{2-}$是抗磁性的，最可能的原因是两个钒之间形成金属-金属双键，使单电子相互成对，呈现抗磁性。

**第92题**：根据电中性原则，$\mathrm{CsAuCl_3}$中Au的表观氧化数应为+2，但$\mathrm{Au(II)}$价层有1个单电子，与抗磁性不符。因此表观的$\mathrm{Au(II)}$实际上是等物质的量的$\mathrm{Au(III)}$与$\mathrm{Au(I)}$的加权平均。Au(III) $5d^8 \rightarrow dsp^2$，对应**四配位平面四方形**；Au(I) $5d^{10} \rightarrow sp$，对应**二配位直线形**。

**第93题**：B中Cr的氧化数为+5，价电子组态为**$d^1$**；C中Cr的氧化数为+3，价电子组态为**$d^3$**；D中Cr的氧化数为+3，价电子组态为**$d^3$**。
