# 题-改编-14-光谱化学序列与配合物磁性

## 题目

Fe²⁺（$d^6$）可以形成多种八面体配合物。已知 Fe²⁺ 的电子成对能 $P = 17{,}600\ \text{cm}^{-1}$。

(a) 以下配合物中，哪些为高自旋，哪些为低自旋？通过比较 $\Delta_o$ 与 $P$ 进行判断。

| 配合物 | $\Delta_o$ (cm⁻¹) |
|:---:|:---:|
| [Fe(H₂O)₆]²⁺ | 10,400 |
| [Fe(CN)₆]⁴⁻ | 33,000 |
| [Fe(en)₃]²⁺ | ~11,900 |
| [Fe(NH₃)₆]²⁺ | ~10,100 |

(b) 对于每个配合物，画出 $t_{2g}$ 和 $e_g$ 轨道的电子排布图（用 ↑↓ 符号表示）。

(c) 计算每个配合物的 CFSE（晶体场稳定化能），并解释为什么 [Fe(CN)₆]⁴⁻ 特别稳定。

![[media/光谱化学序列配体排序图.关系图.png]]

## 参考答案

**(a) 自旋态判断：**

判断标准：$\Delta_o < P$ → 高自旋；$\Delta_o > P$ → 低自旋

| 配合物 | $\Delta_o$ (cm⁻¹) | 与 $P$ 比较 | 自旋态 |
|:---:|:---:|:---:|:---:|
| [Fe(H₂O)₆]²⁺ | 10,400 | $< P$ | 高自旋 |
| [Fe(CN)₆]⁴⁻ | 33,000 | $> P$ | 低自旋 |
| [Fe(en)₃]²⁺ | ~11,900 | $< P$ | 高自旋 |
| [Fe(NH₃)₆]²⁺ | ~10,100 | $< P$ | 高自旋 |

**(b) 电子排布图：**

- 高自旋（$t_{2g}^4 e_g^2$）：
  - $t_{2g}$: ↑↓  ↑  ↑ （4 个电子，1 对 + 2 个单电子）
  - $e_g$: ↑  ↑ （2 个单电子）
  - 共 4 个未成对电子

- 低自旋（$t_{2g}^6 e_g^0$）：
  - $t_{2g}$: ↑↓  ↑↓  ↑↓ （6 个电子，3 对）
  - $e_g$: （空）
  - 共 0 个未成对电子

**(c) CFSE 计算：**

- [Fe(H₂O)₆]²⁺（高自旋）：
  CFSE $= 4(-0.4 \times 10{,}400) + 2(0.6 \times 10{,}400) = -16{,}640 + 12{,}480 = -4{,}160\ \text{cm}^{-1}$

- [Fe(CN)₆]⁴⁻（低自旋）：
  CFSE $= 6(-0.4 \times 33{,}000) + 0 = -79{,}200\ \text{cm}^{-1}$
  减去多出的成对能修正：$-79{,}200 + 2 \times 17{,}600 = -79{,}200 + 35{,}200 = -44{,}000\ \text{cm}^{-1}$

- [Fe(en)₃]²⁺（高自旋）：
  CFSE $= 4(-0.4 \times 11{,}900) + 2(0.6 \times 11{,}900) = -19{,}040 + 14{,}280 = -4{,}760\ \text{cm}^{-1}$

- [Fe(NH₃)₆]²⁺（高自旋）：
  CFSE $= 4(-0.4 \times 10{,}100) + 2(0.6 \times 10{,}100) = -16{,}160 + 12{,}120 = -4{,}040\ \text{cm}^{-1}$

[Fe(CN)₆]⁴⁻ 特别稳定的原因：CN⁻ 是光谱化学序列中最强的配体之一，具有 π 受体性质，能与金属形成反馈 π 键，大幅增加 $\Delta_o$。这不仅使其获得极高的 CFSE（-44,000 cm⁻¹，远超其他配合物），还使其具有低自旋的惰性电子构型（$t_{2g}^6$，所有轨道全充满），从热力学和动力学两方面都极为稳定。

## 解题思路

1. 核心判断：比较 $\Delta_o$ 与 $P$ 的大小关系是判断高/低自旋的关键。
2. CFSE 计算中，高自旋和低自旋的电子排布不同，直接导致 CFSE 值差异巨大。
3. 低自旋情况的 CFSE 需要加上成对能修正项，因为低自旋排布比自由离子多了额外的电子对。
4. CN⁻ 的特殊稳定性来自两方面：高的 $\Delta_o$（强场配体）+ π 反馈键（协同效应），这是光谱化学序列高端配体的典型特征。
