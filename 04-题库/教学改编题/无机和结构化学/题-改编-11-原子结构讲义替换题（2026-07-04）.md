# 原子结构讲义替换题（2026-07-04）

> 说明：本页存放自 [[原子结构-超级充实版（自学完整）]] 中替换下来的改编题。主讲义对应位置已改回可核对来源的原题版本；这些改编题单独保留，供后续二次编题或分层训练时调用。

## 题目

### 原讲义第17题

**原标签**：[初赛讲义改编]

**题目**：(a) 用 Slater 规则计算 Na 的 3s 和 3p 电子的 $Z^*$；(b) 解释 Na 的 $I_1$ 远低于 Mg；(c) 计算 Ti（$Z=22$）3d 电子的 $Z^*$（$\sigma = 18.00$）。

**原讲义答案**：(a) Na: 3s 电子 $\sigma = 1.00\times2 + 0.85\times8 = 8.80$，$Z^* = 11-8.80 = 2.20$；3p 电子同 $Z^*=2.20$。(b) Na 的 $I_1$ < Mg：Na 失去 3s$^1$ 即达稳定构型，Mg 的 3s$^2$ 全满更难失。(c) Ti 3d: $\sigma = 18\times1.00 = 18.00$，$Z^* = 22-18 = 4.00$。

### 原讲义第18题

**原标签**：[普化原理11-24改编]

**题目**：利用电离能和电子亲和能判断：$\mathrm{Na(g) + F(g) \to Na^+(g) + F^-(g)}$ 在标准状态下能否自发进行？

**原讲义答案**：$\mathrm{Na(g)+F(g)\to Na^+ + F^-}$：$\Delta E = I_1(\mathrm{Na}) - EA(\mathrm{F}) = 496 - 328 = +168\ \mathrm{kJ\ mol^{-1}} > 0$，因此 **不能自发**。

### 原讲义第20题

**原标签**：[普化原理11-4改编]

**题目**：波长 300 nm 紫外光照射金属钠（功函数 $3.7\times10^{-19}$ J），计算光电子最大动能。

**原讲义答案**：$E_{\text{photon}} = hc/\lambda = 6.626\times10^{-34}\times3\times10^8/(300\times10^{-9}) = 6.63\times10^{-19}$ J。$E_k = E_{\text{photon}} - W = 6.63\times10^{-19} - 3.7\times10^{-19} = 2.9\times10^{-19}$ J，约为 **1.8 eV**。

### 原讲义第21题

**原标签**：[初赛讲义改编]

**题目**：某元素 X：最高能级组 7 个电子，3 个未成对电子，$I_1$ 比相邻元素都高。(a) 推断 X 并写电子排布；(b) 计算 3p 电子 $Z^*$；(c) 比较 X 与同族上一周期元素 $I_1$。

**原讲义答案**：“最高能级组 7 个电子 + 3 个未成对 + $I_1$ 比相邻高”这一条件组在常见元素中难以完全满足。原讲义取最接近的解读：元素为 **P**（[Ne]3s$^2$3p$^3$），最高能级组 5 个电子，3 个未成对，$I_1$ 高于相邻的 Si 和 S。(b) P 的 3p 电子：$\sigma = 1.00\times2+0.85\times8+0.35\times3 = 11.45$，$Z^* = 15-11.45 = 3.55$。(c) P 的 $I_1$(1012) > As(947)：同族向下 $n$ 增大，半径增大，$Z^*$ 虽增大但不足以抵消距离效应，因此 $I_1$ 降低。

### 原讲义第22题

**原标签**：[普化原理11-18改编]

**题目**：完成量子数→轨道符号→角度分布特征对应表：(a) $(2,1,0)$；(b) $(3,2,-1)$；(c) $(4,3,+3)$。

**原讲义答案**：(a) $n=2,l=1,m=0$ → **2p$_0$**（或 2p$_z$），角度分布沿 z 轴呈哑铃形；(b) $n=3,l=2,m=-1$ → **3d$_{-1}$**（3d$_{xz}$ 或 3d$_{yz}$），四瓣形分布在坐标平面内；(c) $n=4,l=3,m=+3$ → **4f$_{+3}$**（4f$_{x(x^2-3y^2)}$），沿特定方向的复杂花瓣形。
