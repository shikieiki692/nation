# 题-改编-15-Cl元素推断与含氧酸氧化性

## 题目

某元素 X 满足以下条件：

1. X 的简单氢化物 HₘX 在常温下为气体，其水溶液呈弱酸性  
2. X 的含氧酸 HₙXO₄（$n \leq 2$）是强氧化剂  
3. X 的电负性在同周期主族元素中仅次于 F 和 O  
4. X 在地壳中的丰度位居第几位（按质量分数）

(a) 推断 X 是什么元素  
(b) 写出 X 的基态电子排布式  
(c) 写出 X 的常见氧化态，并指出每种氧化态对应的代表化合物  
(d) 解释 HₘX 水溶液呈弱酸性的原因

## 参考答案

- X 为 Cl
- 基态电子排布为 $[\mathrm{Ne}]\,3s^2\,3p^5$
- 常见氧化态包括 $-1$、$+1$、$+3$、$+5$、$+7$
- 弱酸性讨论对应 HClO 等含氧酸体系
