# 题-改编-12-C3F4-SO4-XeF2结构与杂化

## 题目

画出以下分子/离子的 Lewis 结构式，标明形式电荷，并指出中心原子的杂化方式和分子几何构型：

(a) $\mathrm{C_3F_4}$（全氟环丙烯）
(b) $\mathrm{SO_4^{2-}}$
(c) $\mathrm{XeF_2}$

## 参考答案

- $\mathrm{C_3F_4}$：三元碳环，其中一个 C=C 双键。环上每个 C 连接 F；双键 C 为 $sp^2$，单键 C 为 $sp^3$
- $\mathrm{SO_4^{2-}}$：S 为 $sp^3$ 杂化，正四面体，4 个 S-O 键等价
- $\mathrm{XeF_2}$：Xe 常记作 $sp^3d$ 杂化，直线形，3 对孤对电子占赤道位
