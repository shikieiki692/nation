# 题-改编-14-颜色与光谱化学序列解释

## 题目

实验观察到以下 Ti³⁺（$d^1$）配合物的吸收峰波长：

| 配合物 | 最大吸收波长 $\lambda_{\max}$ (nm) |
|:---:|:---:|
| [Ti(H₂O)₆]³⁺ | 492 |
| [Ti(NH₃)₆]³⁺ | ~440（估计值） |
| [TiF₆]³⁻ | ~530（估计值） |

(a) 解释为什么这三个配合物呈现不同颜色，用晶体场理论说明吸收光与分裂能 $\Delta_o$ 的关系。

(b) 根据吸收峰波长计算每个配合物的 $\Delta_o$（单位 cm⁻¹），并验证这些值是否与光谱化学序列一致。

(c) 已知光谱化学序列中 $\text{F}^- < \text{H}_2\text{O} < \text{NH}_3$，请解释为什么 $\Delta_o$ 随配体场强增大而增大（从分子轨道理论角度简要说明）。

## 参考答案

**(a) 颜色产生原理：**

Ti³⁺ 为 $d^1$ 构型，唯一电子位于 $t_{2g}$ 轨道。吸收可见光后，电子从 $t_{2g}$ 跃迁至 $e_g$ 轨道，跃迁能量恰好等于 $\Delta_o$。由于配合物吸收特定波长的光，我们看到的是其互补色。不同配体产生不同的 $\Delta_o$，导致吸收波长不同，颜色也不同。

**(b) $\Delta_o$ 计算：**

利用 $E = h\nu = \frac{hc}{\lambda}$，以及 $1\ \text{cm}^{-1} = 1.986 \times 10^{-23}\ \text{J}$，更方便的换算为：

$$\Delta_o\ (\text{cm}^{-1}) = \frac{10^7}{\lambda\ (\text{nm})}$$

- [Ti(H₂O)₆]³⁺：$\Delta_o = \frac{10^7}{492} = 20{,}325\ \text{cm}^{-1}$
- [Ti(NH₃)₆]³⁺：$\Delta_o = \frac{10^7}{440} = 22{,}727\ \text{cm}^{-1}$
- [TiF₆]³⁻：$\Delta_o = \frac{10^7}{530} = 18{,}868\ \text{cm}^{-1}$

排序：$\Delta_o(\text{F}^-) < \Delta_o(\text{H}_2\text{O}) < \Delta_o(\text{NH}_3)$

这与光谱化学序列 $\text{F}^- < \text{H}_2\text{O} < \text{NH}_3$ 完全一致。

**(c) 分子轨道理论解释：**

- F⁻ 和 H₂O 主要作为 σ 给体，对 $e_g$ 轨道的排斥使 $e_g$ 升高。
- NH₃ 除了 σ 给体能力更强之外，还有一定的 π 给体（或弱 π 相互作用），进一步拉大 $t_{2g}$ 与 $e_g$ 之间的能隙。
- CN⁻ 等强场配体还有 π 受体作用，能降低 $t_{2g}$ 能量，使 $\Delta_o$ 更大。
- 总之，配体的 σ 给体能力越强、π 受体能力越强，$\Delta_o$ 越大，在光谱化学序列中位置越靠后。

## 解题思路

1. 对于 $d^1$ 体系，$\Delta_o$ 可直接从吸收峰波长计算，这是最简单的情况。
2. 记住公式 $\Delta_o\ (\text{cm}^{-1}) = 10^7 / \lambda\ (\text{nm})$，可以快速进行 nm ↔ cm⁻¹ 的换算。
3. 颜色的本质是选择性吸收——配合物呈现的颜色是被吸收光的互补色。
4. 从分子轨道理论角度理解光谱化学序列：σ 给体 → $e_g$ 升高；π 给体 → $t_{2g}$ 升高（$\Delta_o$ 减小）；π 受体 → $t_{2g}$ 降低（$\Delta_o$ 增大）。
