# 题-改编-08-离子强度与活度系数综合计算

## 题目

(a) 计算以下混合溶液在 25°C 时的离子强度：

- 0.01 mol/kg NaCl + 0.02 mol/kg MgCl₂

(b) 对于上述混合溶液，利用 Debye-Hückel 极限公式分别计算 Na⁺、Mg²⁺ 和 Cl⁻ 的单离子活度系数。

已知 Debye-Hückel 极限公式对单离子的形式为：

$$\log_{10} \gamma_i = -A z_i^2 \sqrt{I}$$

其中 $A = 0.509\ (\text{mol}^{-1/2} \cdot \text{kg}^{1/2})$。

(c) 计算该溶液中 MgCl₂ 的平均活度系数 $\gamma_{\pm}(\text{MgCl}_2)$，并与相同浓度（0.02 mol/kg）的纯 MgCl₂ 溶液的平均活度系数进行比较。

## 参考答案

**(a) 离子强度计算：**

溶液中各离子浓度：
- $m_{Na^+} = 0.01$ mol/kg，$z = +1$
- $m_{Mg^{2+}} = 0.02$ mol/kg，$z = +2$
- $m_{Cl^-} = 0.01 + 2 \times 0.02 = 0.05$ mol/kg，$z = -1$

$$I = \frac{1}{2} \sum m_i z_i^2 = \frac{1}{2} (0.01 \times 1^2 + 0.02 \times 2^2 + 0.05 \times 1^2)$$

$$I = \frac{1}{2} (0.01 + 0.08 + 0.05) = \frac{1}{2} \times 0.14 = 0.070\ \text{mol/kg}$$

**(b) 单离子活度系数：**

$$\sqrt{I} = \sqrt{0.070} = 0.2646$$

- Na⁺（$z = +1$）：
  $$\log_{10} \gamma_{Na^+} = -0.509 \times 1^2 \times 0.2646 = -0.1347$$
  $$\gamma_{Na^+} = 10^{-0.1347} = 0.734$$

- Mg²⁺（$z = +2$）：
  $$\log_{10} \gamma_{Mg^{2+}} = -0.509 \times 2^2 \times 0.2646 = -0.5389$$
  $$\gamma_{Mg^{2+}} = 10^{-0.5389} = 0.289$$

- Cl⁻（$z = -1$）：
  $$\log_{10} \gamma_{Cl^-} = -0.509 \times 1^2 \times 0.2646 = -0.1347$$
  $$\gamma_{Cl^-} = 10^{-0.1347} = 0.734$$

**(c) MgCl₂ 的平均活度系数：**

对于 MgCl₂（$\nu_+ = 1$，$\nu_- = 2$，$\nu = 3$）：

$$\gamma_{\pm} = (\gamma_{Mg^{2+}}^1 \cdot \gamma_{Cl^-}^2)^{1/3} = (0.289 \times 0.734^2)^{1/3}$$

$$= (0.289 \times 0.5388)^{1/3} = (0.1557)^{1/3} = 0.538$$

纯 MgCl₂ 溶液（0.02 mol/kg）的离子强度：

$$I_{pure} = \frac{1}{2} (0.02 \times 4 + 0.04 \times 1) = \frac{1}{2} \times 0.12 = 0.060\ \text{mol/kg}$$

$$\log_{10} \gamma_{\pm, pure} = -0.509 \times |2 \times 1| \times \sqrt{0.060} = -0.509 \times 2 \times 0.2449 = -0.2493$$

$$\gamma_{\pm, pure} = 10^{-0.2493} = 0.563$$

**比较：** 混合溶液中 $\gamma_{\pm}(\text{MgCl}_2) = 0.538$，纯溶液中 $\gamma_{\pm} = 0.563$。混合溶液中由于 NaCl 的加入增加了离子强度（从 0.060 增至 0.070），使得 MgCl₂ 的平均活度系数更低。

## 解题思路

1. 混合电解质溶液中，离子强度是所有离子的贡献之和，不能只算目标电解质。
2. 单离子活度系数只能通过理论公式估算（无法直接实验测量），平均活度系数才可实验测定。
3. 平均活度系数的定义：$\gamma_{\pm} = (\gamma_+^{\nu_+} \cdot \gamma_-^{\nu_-})^{1/\nu}$。
4. 易错点：Cl⁻ 的浓度来自两种盐的贡献之和（NaCl 提供 0.01，MgCl₂ 提供 0.04），计算时不要遗漏。
