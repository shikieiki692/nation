# 题-改编-07-稳态近似推导速率方程

## 题目

气相反应 $\text{2NO} + \text{O}_2 \rightarrow \text{2NO}_2$ 的实验速率方程为：

$$v = k[\text{NO}]^2[\text{O}_2]$$

有人提出以下反应机理：

(1) $\text{2NO} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \text{N}_2\text{O}_2$（快平衡）

(2) $\text{N}_2\text{O}_2 + \text{O}_2 \overset{k_2}{\rightarrow} \text{2NO}_2$（慢步骤）

(a) 分别用**预平衡近似**和**稳态近似**推导该反应的速率方程。

(b) 比较两种近似方法得到的结果，说明在什么条件下两者等价。

(c) 如果反应机理改为：

(1) $\text{NO} + \text{O}_2 \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \text{NO}_3$（快平衡）

(2) $\text{NO}_3 + \text{NO} \overset{k_2}{\rightarrow} \text{2NO}_2$（慢步骤）

请用稳态近似推导速率方程，并与实验速率方程比较。

## 参考答案

**(a) 两种近似方法推导：**

**预平衡近似：**

假设步骤 (1) 达到快速平衡：

$$K_1 = \frac{[\text{N}_2\text{O}_2]}{[\text{NO}]^2} = \frac{k_1}{k_{-1}}$$

$$[\text{N}_2\text{O}_2] = \frac{k_1}{k_{-1}} [\text{NO}]^2$$

反应速率由慢步骤 (2) 决定：

$$v = k_2 [\text{N}_2\text{O}_2][\text{O}_2] = k_2 \cdot \frac{k_1}{k_{-1}} [\text{NO}]^2 [\text{O}_2]$$

$$v = \frac{k_1 k_2}{k_{-1}} [\text{NO}]^2 [\text{O}_2]$$

令 $k = \frac{k_1 k_2}{k_{-1}}$，则 $v = k[\text{NO}]^2[\text{O}_2]$ ✓

**稳态近似：**

对中间体 N₂O₂ 应用稳态条件：

$$\frac{d[\text{N}_2\text{O}_2]}{dt} = k_1[\text{NO}]^2 - k_{-1}[\text{N}_2\text{O}_2] - k_2[\text{N}_2\text{O}_2][\text{O}_2] = 0$$

解出 $[\text{N}_2\text{O}_2]$：

$$[\text{N}_2\text{O}_2] = \frac{k_1[\text{NO}]^2}{k_{-1} + k_2[\text{O}_2]}$$

反应速率：

$$v = k_2[\text{N}_2\text{O}_2][\text{O}_2] = \frac{k_1 k_2 [\text{NO}]^2 [\text{O}_2]}{k_{-1} + k_2[\text{O}_2]}$$

**(b) 两种近似的等价条件：**

稳态近似结果：

$$v = \frac{k_1 k_2 [\text{NO}]^2 [\text{O}_2]}{k_{-1} + k_2[\text{O}_2]}$$

当 $k_{-1} \gg k_2[\text{O}_2]$ 时（即 N₂O₂ 的分解速率远大于与 O₂ 反应的速率），分母近似为 $k_{-1}$：

$$v \approx \frac{k_1 k_2}{k_{-1}} [\text{NO}]^2 [\text{O}_2]$$

这与预平衡近似的结果一致。

等价条件：**中间体的逆反应速率远大于其消耗于后续步骤的速率**，即快平衡假设成立。

**(c) 另一机理的稳态近似推导：**

对中间体 NO₃ 应用稳态条件：

$$\frac{d[\text{NO}_3]}{dt} = k_1[\text{NO}][\text{O}_2] - k_{-1}[\text{NO}_3] - k_2[\text{NO}_3][\text{NO}] = 0$$

$$[\text{NO}_3] = \frac{k_1[\text{NO}][\text{O}_2]}{k_{-1} + k_2[\text{NO}]}$$

反应速率：

$$v = k_2[\text{NO}_3][\text{NO}] = \frac{k_1 k_2 [\text{NO}]^2 [\text{O}_2]}{k_{-1} + k_2[\text{NO}]}$$

当 $k_{-1} \gg k_2[\text{NO}]$ 时，$v \approx \frac{k_1 k_2}{k_{-1}} [\text{NO}]^2 [\text{O}_2]$，与实验速率方程一致。

当 $k_2[\text{NO}] \gg k_{-1}$ 时，$v \approx k_1[\text{NO}][\text{O}_2]$，与实验不符。

因此，此机理只有在预平衡假设成立时才能解释实验速率方程。

## 解题思路

1. **预平衡近似**适用于快平衡 + 慢后续步骤的机理：先用平衡常数表达中间体浓度，再代入速率方程。
2. **稳态近似**更一般化：假设中间体的净生成速率为零，求解中间体浓度。适用于活泼中间体浓度很低的情况。
3. 预平衡近似是稳态近似的特例（当 $k_{-1} \gg k_2[\text{底物}]$ 时）。
4. 易错点：稳态近似得到的速率方程分母中包含浓度项，这使得表观反应级数可能随浓度变化，不再严格符合整数级数。
