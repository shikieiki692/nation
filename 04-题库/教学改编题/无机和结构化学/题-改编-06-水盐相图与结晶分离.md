# 题-改编-06-水盐相图与结晶分离

## 题目

NaCl-H₂O 二组分体系的相关数据如下：

- NaCl 的熔点：801°C
- 水的冰点：0°C
- NaCl·2H₂O 的不一致熔点：0.15°C（在此温度下分解为 NaCl 固体和溶液）
- NaCl/含盐固相在水中的饱和浓度曲线（简化）：

| 温度 (°C) | 溶解度 (g NaCl / 100 g H₂O) |
|:---:|:---:|
| -21.1 | 30.4（共晶点） |
| -10 | 35.2 |
| 0 | 35.7 |
| 20 | 36.0 |
| 100 | 39.8 |

数据核对注：共晶温度 $-21.1\,^\circ\mathrm{C}$ 对应 $23.3\ \mathrm{wt\%\ NaCl}$，换算为 $30.4\ \mathrm{g\ NaCl}/100\ \mathrm{g\ H_2O}$。低温区与冰共存的含盐固相应写作 $\mathrm{NaCl\cdot 2H_2O(s)}$；无水 $\mathrm{NaCl(s)}$ 只在 $0.15\,^\circ\mathrm{C}$ 以上的狭窄区域稳定。

(a) 画出 NaCl-H₂O 体系在低温区（-30°C 到 10°C）的相图示意图，标注各相区。

(b) 有一杯含有 10 g NaCl 和 100 g 水的溶液，从 20°C 开始冷却。描述冷却过程中各阶段发生的变化，说明在什么温度开始析出什么固体。

(c) 利用相图解释为什么撒盐可以融雪，但当温度低于 -21.1°C 时撒盐效果变差。

（本题不依赖外部图片；按表中数据和下述示意相图即可完整作答。）

## 参考答案

**(a) 低温区相图示意：**

```
T(°C)
 10  |                    L + NaCl(s)
 0.15|----------------□---------------
  0  |               / | L + NaCl·2H₂O(s)
     |              /  |
-21.1|-------------*-------------------
     |   冰 + NaCl·2H₂O(s)
-30  |---------------------------------
     +--------------------------------
       0      30.4     w(NaCl)/(g/100 g H₂O)
```

各相区标注：
- 共晶线以上、液相线以上：L（均匀溶液）
- 左侧（冰的液相线与共晶线之间）：L + 冰（冰与溶液共存）
- 右侧（$0.15\,^\circ\mathrm{C}$ 以下、溶解度曲线与共晶线之间）：L + NaCl·2H₂O(s)
- 右侧（$0.15\,^\circ\mathrm{C}$ 以上的窄区）：L + NaCl(s)
- 共晶线以下：冰 + NaCl·2H₂O(s)（两固体共存）

共晶点：$-21.1\,^\circ\mathrm{C}$，$30.4\ \mathrm{g\ NaCl}/100\ \mathrm{g\ H_2O}$（即 $23.3\ \mathrm{wt\%\ NaCl}$）。

**(b) 冷却过程描述：**

含有 10 g NaCl / 100 g H₂O 的溶液（质量分数约 9.1%）：

1. **20°C → 约 -0.6°C（单相冷却）**：溶液为均匀液相，温度持续下降。此阶段溶解度远高于实际浓度，无固体析出；冰点可按稀溶液凝固点降低估算，精确值需冰的液相线数据。

2. **约 -0.6°C（冰的析出开始）**：当温度降至该组成对应的冰的液相线时，开始析出冰晶。此时剩余溶液的 NaCl 浓度升高。

3. **约 -0.6°C → -21.1°C（冰持续析出）**：随着冰的析出，溶液中 NaCl 浓度不断升高（沿液相线向共晶点移动），温度继续下降。

4. **-21.1°C（共晶反应）**：剩余溶液达到共晶组成 $30.4\ \mathrm{g\ NaCl}/100\ \mathrm{g\ H_2O}$（$23.3\ \mathrm{wt\%\ NaCl}$），此时冰与 $\mathrm{NaCl\cdot 2H_2O}$ 同时析出，温度保持恒定，直到所有溶液凝固。

5. **-21.1°C 以下**：全部为冰和 $\mathrm{NaCl\cdot 2H_2O}$ 固体混合物，温度继续下降。

**(c) 撒盐融雪的相图解释：**

- 当温度高于 -21.1°C 时（如 0°C 附近），路面上的冰与加入的 NaCl 形成的溶液体系处于 "L + 冰" 两相区。NaCl 溶入冰表面的薄层水中，形成低共熔溶液，其冰点低于 0°C。这使得冰在当前温度下可以融化（从热力学角度看，固相冰变得不稳定）。

- 当温度低于 -21.1°C 时，即使加入 NaCl，所能形成的最低液相线温度仍为 -21.1°C（共晶温度）。在更低的温度下，冰与 $\mathrm{NaCl\cdot 2H_2O}$ 是稳定固相，溶液无法维持液态，因此撒盐不再能有效融雪。

- 此外，低温下 NaCl 的溶解速率也大大降低，进一步削弱了融雪效果。

## 解题思路

1. 水盐相图的关键点：共晶点（最低共熔点）决定了撒盐融雪的最低有效温度。
2. 冷却过程中，溶液组成沿液相线移动，这是因为固体析出后剩余溶液的浓度不断变化。
3. 共晶反应 $L \rightarrow \text{冰} + \mathrm{NaCl\cdot 2H_2O(s)}$ 是恒温过程，因为此时自由度 $F = C - P + 1 = 2 - 3 + 1 = 0$。
4. 实际应用中的关键数值：NaCl-H₂O 共晶温度 -21.1°C，这就是普通食盐融雪的理论极限。
