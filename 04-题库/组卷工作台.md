# 组卷工作台

> **用途**：基于 `fidelity / difficulty / exam_stage / knowledge_points` 四大字段精准选题。
> 全库 4,655 题元数据完备度：fidelity 100% ｜ difficulty 100% ｜ exam_stage 100% ｜ knowledge_points 85%
> **组卷三步**：改参数 → 预览选题 → 复制链接到试卷文件。

## 一、快速选题器（改顶部参数即可）

```dataviewjs
// ══════════ 组卷参数（改这里） ══════════
const FIDELITY = "原书逐字";   // "原书逐字" / "自编" / "" 不限
const DIFF_MIN = 3;            // 难度下限 1-5
const DIFF_MAX = 5;            // 难度上限
const STAGE    = "初赛";       // "初赛" / "决赛" / "省预赛" / "" 不限
const KP       = "";           // 知识点关键词（如"晶胞"），"" 不限
const PACK     = "";           // "章节练习" / "模块习题集" / "综合模拟卷" / "预赛专项" / "" 不限
const MODULE   = "";           // "化学原理" / "结构化学" / "有机化学" / "元素与分析" / "" 不限
const LIMIT    = 25;           // 最多显示
// ════════════════════════════════════════

let pages = dv.pages('"04-题库"').where(p => {
  if (p.type !== "题目") return false;
  if (p.status === "deprecated") return false;
  if (FIDELITY && p.fidelity !== FIDELITY) return false;
  const d = Number(p.difficulty);
  if (d < DIFF_MIN || d > DIFF_MAX) return false;
  if (STAGE && p.exam_stage !== STAGE) return false;
  if (PACK && p.pack !== PACK) return false;
  if (MODULE && p.subject_module !== MODULE) return false;
  if (KP) {
    const kps = (p.knowledge_points || []).join(" ");
    if (!kps.includes(KP)) return false;
  }
  return true;
}).sort(p => p.difficulty, "asc").limit(LIMIT);

dv.header(4, `🎯 符合条件：${pages.length} 题`);
dv.table(["题目", "难度", "阶段", "保真", "知识点"],
  pages.map(p => [
    p.file.link,
    p.difficulty,
    p.exam_stage,
    p.fidelity,
    (p.knowledge_points || []).slice(0, 3).join(" ")
  ]));
```

## 二、预设卷型（点开即用）

### 卷型 A：真题原题卷
- 过滤：`fidelity = 原书逐字` + `exam_stage = 初赛/决赛`
- 用途：竞赛真题训练、模考
- 注意：先查 `depends_on`——承接式题目需连同前驱一起出

### 卷型 B：知识点专项卷
- 过滤：`KP = 目标知识点` + 难度梯度 2→5 排列
- 用途：薄弱点强化；建议 60% 中低档 + 40% 高档

### 卷型 C：综合模拟卷（跨库混编）
- 组成建议：真题 60% + 教材习题 30% + 自编/改编 10%
- 难度梯度：题 1-3 用 difficulty 2-3（热身）、题 4-7 用 3-4（主体）、题 8-10 用 4-5（拔高）
- 来源分散：同一来源不超过 3 题

### 卷型 D：保真对照卷（教研用）
- `fidelity = 原书逐字` 与 `自编` 对照排版，用于审校改写题质量

## 三、组卷规范

1. **答案分离**：试卷文件只放题干，答案区单独一节置底（或引用题目文件的 `## 参考答案`）
2. **依赖检查**：选题含 `depends_on` 字段的承接式题目时，**必须连同前驱一起出卷**（题目节顶部有 ⚠️ 提示）
3. **梯度公式**：n 题卷建议难度分布 2:5:3（易:中:难），均分 = 目标难度 ±0.3
4. **保真标注**：原书逐字题保留原貌不改写；自编题可自由修改
5. **知识点覆盖**：综合卷建议覆盖 ≥5 个一级知识点
