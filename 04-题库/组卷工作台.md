# 组卷工作台

> **用途**：按条件筛选 → 按梯度成卷 → 回填 `used_in` 形成闭环。
> **三种用法**：①「快速筛选器」人工挑 ②「智能组卷器」自动成卷 ③「已用题回看」查重。

---

## 零、字段底数（2026-09-02 实测，4,182 题）

| 字段 | 覆盖 | 能否用于组卷 |
|---|---|---|
| `fidelity` / `difficulty` / `teaching_level` / `source` | 100% | ✅ 随便用 |
| `subject_module` / `pack` / `exam_stage` | ~100% | ✅ 可用 |
| `year` | 901（21.5%） | ⚠️ 仅真题有意义 |
| `question_type` | 1,212（29.0%） | ⚠️ 筛了会漏掉 71%，**建议只做展示不筛选** |
| `used_in` | 344（8.2%） | ✅ 用于排除已用题（**值是 wikilink**，如 `"[[结构化学阶段测试卷]]"`） |
| `depends_on` | **4** | ❌ 太少，承接题只能人工看（题面顶部有 ⚠️ 提示） |

> ⚠️ **`used_in` 是 wikilink 不是纯文本**：现有 344 条全部指向 4 份阶段测试卷，写法是
> `used_in: "[[结构化学阶段测试卷]]"`。好处是试卷文件里能看到反向链接（Backlinks 面板直接跳回题目）。
> 代价是 dataview 把它解析成 **Link 对象**，没有 `.length`——查询里写 `p.used_in.length` 会静默判空失败。
> 本页三个代码块都已改用 `hasUsed()` 判空，新增查询时照抄。

> ⚠️ **来源归一化（重要）**：`source` 有 1,228 个去重值，其中 1,083 个只出现一次，
> 同一本书被拆成多种写法——「赵鑫光《…笔记》」+「…第2章」+「…第3章」…共 7 个来源、482 题；
> 「普通化学原理（第4版）习题解析」和「…（忠实转录）」是同一本书。
> 不归一化，「同来源限流 ≤3」会形同虚设。下方 `srcKey()` 负责归一，改限流规则时先看它。

## 一、快速筛选器（人工挑选用）

```dataviewjs
// ══════════ 筛选参数（改这里） ══════════
const SCOPE    = "both";   // "04"=04-题库 / "05"=05-真题库 / "both"
const MODULE   = "";       // 化学原理 / 结构化学 / 有机化学 / 元素与分析 / "" 不限
const STAGE    = "";       // 初赛 / 决赛 / 省预赛 / "" 不限
const PACK     = "";       // 章节练习 / 模块习题集 / 综合模拟卷 / 预赛专项 / "" 不限
const LEVEL    = "";       // 基础 / 巩固 / 拓展 / 竞赛 / "" 不限
const QTYPE    = "";       // 题型，如"计算"/"选择"；⚠️ 仅 29% 覆盖，慎用作筛选
const FIDELITY = "";       // 原书逐字 / 原书改写 / 自编 / "" 不限
const DIFF_MIN = 3, DIFF_MAX = 5;
const EXCLUDE_USED = true; // 排除已出过卷的题
const LIMIT    = 40;
// ════════════════════════════════════════

// ══════════ 工具函数（三个代码块各存一份，dataviewjs 之间不共享作用域）══════════
// ① used_in 在本库是 wikilink（如 "[[结构化学阶段测试卷]]"），dataview 解析成 Link 对象，
//    没有 .length —— 直接判 p.used_in.length 会让 EXCLUDE_USED 对全部 345 条静默失效。
const hasUsed = u => u != null && (Array.isArray(u) ? u.length > 0 : true);
// ② difficulty 有 9 条例外写法（"3-5"、"4-5"、"3  # 1-5"），Number() 得 NaN 会被静默丢掉。
//    统一取第一个整数（区间的下界），保证这些题还能进池。
const diffNum = d => { const m = String(d ?? "").match(/\d+/); return m ? Number(m[0]) : NaN; };
// ③ exam_stage 允许 "/" 多值（如 "初赛/决赛"），精确 !== 会漏。
const stageHit = (v, want) => String(v ?? "").split("/").some(x => x.trim() === want);

const SRC = SCOPE === "04" ? '"04-题库"'
          : SCOPE === "05" ? '"05-真题库"'
          : '"04-题库" or "05-真题库"';

const pool = dv.pages(SRC).where(p => {
  if (p.type !== "题目" && p.type !== "真题") return false;
  if (p.status === "deprecated") return false;
  if (EXCLUDE_USED && hasUsed(p.used_in)) return false;
  if (MODULE   && p.subject_module !== MODULE) return false;
  if (STAGE    && !stageHit(p.exam_stage, STAGE)) return false;
  if (PACK     && p.pack !== PACK) return false;
  if (LEVEL    && p.teaching_level !== LEVEL) return false;
  if (FIDELITY && p.fidelity !== FIDELITY) return false;
  const d = diffNum(p.difficulty);
  if (!(d >= DIFF_MIN && d <= DIFF_MAX)) return false;
  if (QTYPE) {
    const qt = Array.isArray(p.question_type) ? p.question_type
             : (p.question_type ? [p.question_type] : []);
    if (!qt.includes(QTYPE)) return false;
  }
  return true;
}).sort(p => diffNum(p.difficulty), "asc").array();

dv.header(4, `🎯 符合条件：${Math.min(pool.length, LIMIT)} / ${pool.length} 题`);
dv.table(["题目", "难度", "层次", "题型", "模块", "来源"],
  pool.slice(0, LIMIT).map(p => [
    p.file.link,
    p.difficulty,
    p.teaching_level,
    (Array.isArray(p.question_type) ? p.question_type.join("/")
     : p.question_type) || "—",
    p.subject_module,
    String(p.source || "").slice(0, 22)
  ]));
```

## 二、智能组卷器（自动成卷）

> 按**难度梯度**分配名额 → **同来源限流** → **模块配额** → 随机抽取（固定种子可复现）。

```dataviewjs
// ══════════ 一、硬筛选 ══════════
const SCOPE    = "both";
const MODULE   = "";       // "" 不限
const STAGE    = "初赛";
const PACK     = "";
const LEVEL    = "";
const FIDELITY = "";
const DIFF_MIN = 1, DIFF_MAX = 5;
const EXCLUDE_USED = true;

// ══════════ 二、成卷参数 ══════════
const TOTAL   = 10;        // 总题数
const GRADIENT = [0.2, 0.5, 0.3];   // 易(d≤2) : 中(d=3) : 难(d≥4)，见 §五 梯度公式
const QUOTA   = {};        // 模块配额上限，如 {化学原理:3, 有机化学:4}；{} 不限
const MAX_PER_SOURCE = 3;  // 同一本书最多几题
const SEED    = 20260902;  // 随机种子：同一个种子 = 同一份卷子，改数字换一版

// ══════════ 三、工具函数 ══════════
// 来源归一化：把「赵鑫光《…笔记》第3章」「…（忠实转录）」「…·第2分册」「…-1」
// 全部收敛到书名，否则限流会被同一本书的不同写法绕过。
function srcKey(s) {
  let k = String(s || "").trim();
  k = k.replace(/[（(]忠实转录[)）]/g, "");
  k = k.replace(/[·•]\s*第\s*\d+\s*[讲章][\s\S]*$/, "");
  k = k.replace(/第\s*[\d一二三四五六七八九十]+\s*[章节讲篇][\s\S]*$/, "");
  k = k.replace(/[·•]\s*第\s*[\d一二三四五六七八九十]+\s*[分册卷][\s\S]*$/, "");
  k = k.replace(/-\s*\d{1,2}\s*$/, "");
  k = k.replace(/[\s·•、,，\-—]+$/, "");
  return k.trim() || "(未知来源)";
}
// mulberry32：小而稳的可复现随机数
function mkRand(seed) {
  let a = seed >>> 0;
  return function () {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
const rand = mkRand(SEED);

// used_in 是 wikilink → Link 对象无 .length，必须这样判空（详见 §一 工具函数注释）
const hasUsed = u => u != null && (Array.isArray(u) ? u.length > 0 : true);
// difficulty 例外写法（"3-5" 等）取第一个整数；exam_stage 允许 "/" 多值
const diffNum = d => { const m = String(d ?? "").match(/\d+/); return m ? Number(m[0]) : NaN; };
const stageHit = (v, want) => String(v ?? "").split("/").some(x => x.trim() === want);

// ══════════ 四、筛选与分档 ══════════
const SRC = SCOPE === "04" ? '"04-题库"'
          : SCOPE === "05" ? '"05-真题库"'
          : '"04-题库" or "05-真题库"';

const pool = dv.pages(SRC).where(p => {
  if (p.type !== "题目" && p.type !== "真题") return false;
  if (p.status === "deprecated") return false;
  if (EXCLUDE_USED && hasUsed(p.used_in)) return false;
  if (MODULE   && p.subject_module !== MODULE) return false;
  if (STAGE    && !stageHit(p.exam_stage, STAGE)) return false;
  if (PACK     && p.pack !== PACK) return false;
  if (LEVEL    && p.teaching_level !== LEVEL) return false;
  if (FIDELITY && p.fidelity !== FIDELITY) return false;
  const d = diffNum(p.difficulty);
  return d >= DIFF_MIN && d <= DIFF_MAX;
}).array();

const bands = [
  { name: "易", list: pool.filter(p => diffNum(p.difficulty) <= 2) },
  { name: "中", list: pool.filter(p => diffNum(p.difficulty) === 3) },
  { name: "难", list: pool.filter(p => diffNum(p.difficulty) >= 4) },
];
// 名额分配：按比例取整，余数补给候选最多的档，保证合计 = TOTAL
let quotaN = GRADIENT.map(g => Math.floor(TOTAL * g));
let rest = TOTAL - quotaN.reduce((a, b) => a + b, 0);
const bySupply = bands.map((b, i) => i).sort((i, j) => bands[j].list.length - bands[i].list.length);
for (let k = 0; rest > 0; k++, rest--) quotaN[bySupply[k % 3]]++;
bands.forEach((b, i) => b.target = quotaN[i]);

// ══════════ 五、抽取（限流 + 配额）════════
const usedSrc = new Map(), usedMod = new Map();
function pick(band) {
  const rest = band.list.slice();
  const out = [];
  while (out.length < band.target && rest.length) {
    const i = Math.floor(rand() * rest.length);
    const p = rest.splice(i, 1)[0];
    const k = srcKey(p.source);
    const m = p.subject_module || "(未标模块)";
    if (MAX_PER_SOURCE > 0 && (usedSrc.get(k) || 0) >= MAX_PER_SOURCE) continue;
    if (QUOTA[m] !== undefined && (usedMod.get(m) || 0) >= QUOTA[m]) continue;
    usedSrc.set(k, (usedSrc.get(k) || 0) + 1);
    usedMod.set(m, (usedMod.get(m) || 0) + 1);
    out.push(p);
  }
  return out;
}
// 供应最紧的档先挑，避免易档把配额吃光后难档无题可选
bands.sort((a, b) => (a.list.length - a.target) - (b.list.length - b.target));
const picked = [];
bands.forEach(b => { b.got = pick(b); picked.push(...b.got); });
const order = { "易": 0, "中": 1, "难": 2 };
picked.sort((a, b) => diffNum(a.difficulty) - diffNum(b.difficulty));

// ══════════ 六、输出 ══════════
const avg = picked.reduce((s, p) => s + diffNum(p.difficulty), 0) / (picked.length || 1);
dv.header(4, `📝 成卷 ${picked.length}/${TOTAL} 题 ｜ 均难度 ${avg.toFixed(2)} ｜ 种子 ${SEED}`);
dv.table(["#", "题目", "难度", "题型", "模块", "来源(归一)"],
  picked.map((p, i) => [
    i + 1, p.file.link, p.difficulty,
    (Array.isArray(p.question_type) ? p.question_type.join("/") : p.question_type) || "—",
    p.subject_module, srcKey(p.source).slice(0, 20)
  ]));

// 诊断：哪一档没凑够、来源是否超标
const diag = bands.map(b =>
  `  ${b.name}档：目标 ${b.target}／实得 ${b.got.length}（候选 ${b.list.length}）` +
  (b.got.length < b.target ? " ⚠️ 候选不足" : ""));
dv.paragraph("**分档诊断**\n" + diag.join("\n"));
const topSrc = [...usedSrc.entries()].sort((a, b) => b[1] - a[1]).slice(0, 5);
dv.paragraph("**来源分布**（前 5）：" +
  topSrc.map(([k, v]) => `${k.slice(0, 18)}×${v}`).join(" ｜ "));
dv.paragraph(`**复制清单**（粘到试卷文件后跑 mark_used.py 回填）：\n` +
  picked.map((p, i) => `${i + 1}. ${p.file.link}`).join("\n"));
```

## 三、已用题回看（查重）

```dataviewjs
// 按 used_in 分组，看哪些题已经出过、出在哪
// ⚠️ used_in 是 wikilink（Link 对象，没有 .length），判空必须用 hasUsed，不能写 .length
const hasUsed = u => u != null && (Array.isArray(u) ? u.length > 0 : true);
const diffNum = d => { const m = String(d ?? "").match(/\d+/); return m ? Number(m[0]) : NaN; };
const used = dv.pages('"04-题库" or "05-真题库"')
  .where(p => (p.type === "题目" || p.type === "真题") && hasUsed(p.used_in))
  .array();

const byPaper = new Map();
for (const p of used) {
  const tags = Array.isArray(p.used_in) ? p.used_in : [p.used_in];
  for (const t of tags) {
    const k = String(t);
    if (!byPaper.has(k)) byPaper.set(k, []);
    byPaper.get(k).push(p);
  }
}
dv.header(4, `♻️ 已用 ${used.length} 题，分布在 ${byPaper.size} 份卷`);
dv.table(["卷/用途", "题数", "平均难度", "题目"],
  [...byPaper.entries()].sort((a, b) => b[1].length - a[1].length).map(([k, ps]) => [
    k,
    ps.length,
    (ps.reduce((s, p) => s + diffNum(p.difficulty), 0) / ps.length).toFixed(1),
    ps.slice(0, 6).map(p => p.file.link).join(" ")
  ]));
```

## 四、预设卷型

### 卷型 A：真题原题卷
- 参数：`STAGE = 初赛` 或 `决赛`，`FIDELITY = 原书逐字`，`MAX_PER_SOURCE = 0`（真题不限来源）
- 用途：竞赛真题训练、模考
- ⚠️ 承接式题目（`depends_on`）全库只有 4 个，脚本管不了——出题前看题面顶部是否有 ⚠️ 提示

### 卷型 B：知识点专项卷
- 参数：`MODULE` 指定模块 + 默认梯度 `[0.3, 0.5, 0.2]`（专项卷偏重中低档）
- 用途：薄弱点强化

### 卷型 C：综合模拟卷（跨库混编）
- 参数：`QUOTA = {化学原理:3, 有机化学:3, 结构化学:2, 元素与分析:2}`，`TOTAL = 10`
- 梯度：`[0.2, 0.5, 0.3]`，来源限流 `MAX_PER_SOURCE = 3`

### 卷型 D：保真对照卷（教研用）
- `FIDELITY = 原书逐字` 与 `自编` 各跑一次，对照排版审校改写题质量

## 五、组卷规范

1. **答案分离**：试卷文件只放题干，答案区单独一节置底（或引用题目文件的 `## 参考答案`）
2. **依赖检查**：含 `depends_on` 的承接题**必须连同前驱一起出卷**（题面顶部有 ⚠️ 提示）
3. **梯度公式**：n 题卷难度分布 2:5:3（易:中:难），均分 = 目标难度 ±0.3
   —— 对应 `GRADIENT = [0.2, 0.5, 0.3]`
4. **保真标注**：原书逐字题保留原貌不改写；自编题可自由修改
5. **知识点覆盖**：综合卷建议覆盖 ≥5 个一级知识点
6. **来源分散**：同一来源不超过 3 题（由 `MAX_PER_SOURCE` 强制，来源已归一化）

### 出卷后回填 `used_in`（闭环的关键一步）

不回填，`EXCLUDE_USED` 就是摆设。试卷文件写好题目链接后：

```bash
# 1) 先 dry-run（默认就是 dry-run，不写盘）
python .workbuddy/scripts/mark_used.py --paper "06-讲义输出/2026秋期中卷.md"

# 2) 确认无误后加 --write 落盘
python .workbuddy/scripts/mark_used.py --paper "06-讲义输出/2026秋期中卷.md" --write
```

- `--tag` **可省略**：省略时默认取试卷文件名去掉扩展名（如 `2026秋期中卷.md` → `【2026秋期中卷】`），
  保证 `used_in` 与试卷文件严格对得上——这是双向链接能跳回去的前提，所以一般不用手动指定。
  （下文示例一律用全角方括号，避免被校验器当成断链。）
- 脚本扫试卷里的 wikilink，只认 `04-题库` / `05-真题库` 下的题目文件，其余（知识点、图片）自动跳过。
- 已带该 tag 的题跳过，一题用过多次则写成数组：`used_in: ["【A卷】", "【B卷】"]`。
- 行级原地改值，不重新序列化 YAML，**严格保留原行尾**（本库是混合行尾）。

## 七、字段维护

- 新题入库必须带 `fidelity / difficulty / exam_stage / knowledge_points` 四字段
- `question_type` 覆盖 **29.4%**（2026-09-02 B2b 批量补标，1,212 / 4,182）。剩余 2,970 条在
  `02-数据库/题库.base` → 「题型待标注（按目录批量补）」，按所在目录排序后可批量标（同目录同质）。
  ⚠️ 补标前先看字段语义：形式（选择/填空）与内容（计算/推断/作图/机理/方程式书写）**两个维度并存**，
  画结构题归「作图」、多问题干留空——规则见 `04-题库/题库架构总览.md` §三 与 SOP §2.2c
- 归一化规则验证脚本：`.workbuddy/scripts/check_source_norm.py`（改 `srcKey()` 后跑一遍看 TOP 来源规模）
