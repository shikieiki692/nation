# 题库来源分级规范

> **本页定位**：回答「**同一道题，按来源看它算几等**」的**单一事实源**。
> **上游**：[[04-题库/题库按用途分类说明]]（用途四层／组卷来源策略）、[[04-题库/题库架构总览]]（字段规范）。
> **效力**：本页 §二 五档定义与 §四 目录映射，为**用户 2026-09-28 拍板口径**（三项决策均取推荐项），此后新增/重估来源按此执行。
> **字段**：`source_tier`（FM，取值 `1`–`5`，整数）。

---

## 〇、一句话结论

**来源等级是一条独立的「时效 × 权威」轴**，与已有的两条来源轴**正交**：

| 字段 | 维度 | 回答 | 取值 |
|:--|:--|:--|:--|
| `source_category` | 类型 | 这是**什么性质**的源 | 竞赛导向·真题 / 竞赛导向·竞赛教辅 / 教材课后习题 / … |
| `source_grade` | 质量 | 这题**编得好不好** | A / A- / B+ / B / B- / C |
| **`source_tier`** | **等级** | 这题**多新、多权威**（组卷取材优先级） | **1 / 2 / 3 / 4 / 5** |

> ⛔ **禁把三者互推**。真题可以是 C 级（编排差），教材课后题可以是 A 级（编排好）；tier 只说「新不新、是不是真考过」。

## 一、用户口径原文（2026-09-28）

> 「按照来源给题库划分等级：**近10年初赛决赛真题 ＞ 日期新的初赛决赛模拟题 ＞ 老真题和老模拟题（能力测试和北斗40套等）＞ 决赛教辅（如赵鑫光、汇智结构卷、初赛讲义等）＞ 普通教材课后习题（无机化学、普化原理等）**。」

**三项落地决策（2026-09-28 拍板，均取推荐项）**：

| # | 决策点 | 定案 |
|:--|:--|:--|
| 1 | 落地方式 | **新增 `source_tier` 字段，全库回填**；`source_grade` 原样保留（正交轴，不动） |
| 2 | 分界口径 | **近10年真题 = 第 31 届（2017）起**（至第 40 届 2026）；**新模拟题 = 2024–2026** |
| 3 | 北斗 2025/2026 | **文件原地不动**（`04-题库/教材习题/北斗学友/`），**仅重新定级为 tier 2** |
| 4 | **省预赛真题**（2026-09-28 追定） | **tier 4**，与竞赛教辅同档——**理由：内容简单**（用户口径）；v1.0 曾暂列 tier 1，已改判 |

## 三、与既有字段的关系（正交，禁合并）

| 关系 | 说明 |
|:--|:--|
| vs `source_grade` | **不替换、不改写**。grade 是编排质量，tier 是来源等级。同一天然可「tier1 ＋ grade C」（老编排的真题） |
| vs `source_category` | **不替换**。category 是性质（真题/教辅/教材），tier 是等级。真题必然 tier1/3，但教材类可能 tier4 或 tier5 |
| vs `teaching_level` | **彻底无关**。teaching_level 是教学阶段（基础/巩固/拓展/竞赛），禁按 tier 反推（[[04-题库/习题集体系总纲]]「来源 ≠ 难度」） |
| vs `pack` | **不替代**。pack 是用途（章节练习/模块习题集/预赛专项/综合模拟卷） |

## 五、边界说明与已决判断

> 以下是本规范落地时**主动做出的判断**，如与预期不符可直接改本表并重跑回填脚本。

1. **省预赛真题 → tier 4（2026-09-28 追定）**。用户口径：「**预赛的优先级和竞赛教辅位置一样，因为内容简单**」。故 `真题/省预赛/**`（浙江 2021/2022/2023 ＋ 江苏，共 306 题）由 v1.0 的 tier 1 **改判 tier 4**——它是真题，但**难度与指向性等同竞赛教辅**，不再按「真题高于模拟题」处理。
2. **北斗学友 → tier 2（用户已拍板）**，**北斗40 → tier 3**。两者同属北斗学友机构，但年份差 5–10 年，故分档。
3. **「自编章节题／教学改编」→ tier 4**。其素材来自竞赛教辅/课程（学而思、Zchem、质心直播课），按素材档位归 tier 4；**若后续认为自编应更低，整桶改判即可**。
4. **`05-真题库/`（41 题，策略级真题精品）未在本次回填范围**——属红线目录，未改动。其对应档位应为 **tier 1**，登记于本页待批。
5. **`_待人工复核-空壳与重复卡/`、`_归档/` 未打标**（非活跃卡）。

## 六、组卷口径建议（非强制，供组卷器取用）

按用途**取源优先级**（与 [[04-题库/题库按用途分类说明]] §三 的来源策略叠加使用，本表只管**取源的等级下限**）：

| 卷型 | tier 建议 |
|:--|:--|
| 综合模拟卷／阶段测试卷（竞赛·限时） | 优先 **tier 1–2**；tier 3 可用；tier 4 少量 |
| 习题书（拓展·拔高） | **tier 2–4** 为主 |
| 随堂习题集（课内） | **tier 5** 为主 ＋ tier 4 |
| 预赛专项 | **tier 4**（省预赛真题，与竞赛教辅同档） |

> ⚠️ 上表是**取材偏好**，不是硬闸门；`pack` 的既有硬规则（省预赛→预赛专项、决赛真题→综合模拟卷）仍优先。

## 七、维护规则

1. **新增来源**：在 §四 表登记一行（路径 → tier），并在 `04-题库/README.md` 题源登记总表补 tier 列。
2. **回填脚本**：`.workbuddy/tmp/tier_map.py`（映射）／`tier_apply.py`（写盘，幂等：已存在 `source_tier` 则跳过）。
3. **校验**：`scan_dup.py`（顶层重复键 + tier 取值域）＋ `.workbuddy/tmp/yaml_strict.py`（ruamel 严格解析，禁重复键）。
4. **变更记录**：改 tier 定义或映射后，须重跑全库回填＋两道校验，并在本页 `version` 加注。
