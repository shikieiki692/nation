## 1-1-1 通过计算推断 C 的化学式。

分解温度较低，且阴离子与酸反应放出气体，说明 C 中有可能含有 $CO_{3}^{2-}$ （1 分）

此时, 假定加酸消解时产生的气体全部是 $\mathrm{CO}_{2}$ , 由体积可以得到:

$$
n (\mathrm{CO} _ {2}) = 101.325 \times 0.112 / 8.314 \times 298 \mathrm{mol} = 4.58 \mathrm{mmol(1分)}
$$

$$
1.013 \mathrm{g} \text {   的   } \mathbf {C} \text {   加热失重   } 1.013 \times 0.2805 \mathrm{g} = 0.2841 \mathrm{g}
$$

除去 $CO_{2}$ 的剩余质量： $m=0.2841g-4.58\times10^{-3}\times44.01g=0.0825g$

考虑到许多金属的碳酸盐矿物多以碱式碳酸盐的形式存在假定剩余质量对应的失重是水，则：

$$
n (\mathrm{H} _ {2} \mathrm{O}) = 0.0825 \div 18.016 \times 10 ^ {3} \mathrm{mmol} = 4.58 \mathrm{mmol}
$$

因此，C 的化学式为 $\mathrm{M}_{2}(\mathrm{OH})_{2}\mathrm{CO}_{3}$ （1 分），结合失重数据，可得 M 为 Cu 因此 C 的化学式为 $\mathrm{Cu}_{2}(\mathrm{OH})_{2}\mathrm{CO}_{3}$ （2 分）
（本题共5分）

\begin{array}{l l} {\mathrm {A: C u _ {2} O}} & {\mathrm {B: CuO}} \\ {\mathrm{(共1分，有错不得分)}} \end{array}

每秒钟燃烧的 C 摩尔数为: $n = 111 / 12.01 \mathrm{~mol} = 9.242 \mathrm{~mol}$

$$
\mathrm{完全燃烧时,} n (\mathrm{O} _ {2}) = n (\mathrm{C}) = 9.242 \mathrm{mol}
$$

因此空气分子摩尔是 $n = 9.242 / 21\% \mathrm{mol} = 44.01 \mathrm{~mol}$ （1分）

因此进气量为 $44.01 \times 8.314 \times 298 / 101.325 \mathrm{~L} = 1076 \mathrm{~L}$ （2分）

$$
\text {   进气口处气流量应当为   } 1076 \mathrm{L/s}
