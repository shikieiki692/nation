### 第 5 题 元素推断与方程式书写（20 分，占 12%）

元素 X 的名称来自希腊神话中满月女神塞勒涅的名字，其单质有多种同素异形体。1972年，K.Seppelt 在意图制备含 X 的一种未知化合物“M”时，意外发现了无色晶状化合物 HA。这是一种四元化合物，X 的质量分数为 41.35%。HA 是一种一元强酸，强氧化剂和强氟化剂。

在水中不稳定，水解生成 HF 与一种以溶解金著称的氧化性酸 B，B 与金反应可以得到二元酸 C（反应 1），并且 B 也可被除 HF 外的浓氢卤酸还原为 C（反应 2）。

5-1-1 给出 X 的元素名称，HA、B 和 C 的化学式以及题中有关 B 的两个反应（以 HY 表示氢卤酸）。

5-1-2 HA 的酸根 A 有与氟离子极其相似的特性，可以与正氧化态的卤素形成化合物 YA 或 YA $_{3}$ ，可以看做“卤素互化物”。例如，可以用 HgA $_{2}$ 与 ClF 相互作用制得 ClA。这种黄色挥发性液体在潮湿空气中水解释放一种气体，过程中无价态变化（反应 3）。写出反应 3 的方程式。

## 参考答案

元素 X 的名称来自希腊神话中满月女神塞勒涅的名字，其单质有多种同素异形体。1972年，K.Seppelt 在意图制备含 X 的一种未知化合物“M”时，意外发现了无色晶状化合物 HA。这是一种四元化合物，X 的质量分数为 41.35%。HA 是一种一元强酸，强氧化剂和强氟化剂。在水中不稳定，水解生成 HF 与一种以溶解金著称的氧化性酸 B，B 与金反应可以得到二元酸 C（反应 1），并且 B 也可被除 HF 外的浓氢卤酸还原为 C（反应 2）。5-1-1 给出 X 的元素名称，HA、B 和 C 的化学式以及题中有关 B 的两个反应（以 HY 表示氢卤酸）。

<table><tr><td>X</td><td>HA</td><td>B</td><td>C</td></tr><tr><td>硒</td><td> $HOSeF_5$ </td><td> $H_2SeO_4$ </td><td> $H_2SeO_3$ </td></tr></table>

(各 1 分，共 4 分)

反应 1: $6 \mathrm{H}_{2} \mathrm{SeO}_{4} + 2 \mathrm{Au} = \mathrm{Au}_{2}(\mathrm{SeO}_{4})_{3} + 3 \mathrm{H}_{2} \mathrm{SeO}_{3} + 3 \mathrm{H}_{2} \mathrm{O}$ （若以 $\mathrm{Au}_{2}(\mathrm{SeO}_{3})_{2}(\mathrm{SeO}_{4})_{3}$ 配平也可得分）

反应 2: $H_{2}SeO_{4} + 2HY = H_{2}SeO_{3} + Y_{2} + H_{2}O$

(各2分，共4分)

5-1-2 HA 的酸根 A 有与氟离子极其相似的特性，可以与正氧化态的卤素形成化合物 YA 或 YA $_{3}$ ，可以看做“卤素互化物”。例如，可以用 HgA $_{2}$ 与 ClF 相互作用制得 ClA。这种黄色挥发性液体在潮湿空气中水解释放一种气体，过程中无价态变化（反应 3）。写出反应 3 的方程式。

$$
2 \mathrm{ClSeOF} _ {5} + \mathrm{H} _ {2} \mathrm{O} = \mathrm{Cl} _ {2} \mathrm{O} + 2 \mathrm{HOSeF} _ {5}
$$

(2 分, 若给出完全水解的产物也得分)

5-2 与模仿氟离子的 A 相比，低价 X 的衍生物则更偏向传统的拟卤素，相关化合物会生成各式各样的酸。 $\mathbf{X}_{2}(\mathrm{CN})_{2}$ 可以水解成三种酸（反应 4），也可以受热发生歧化反应，生成等物质的量的 G 和 H（反应 5），H 中 X 的质量分数为 81.99%。G 水解歧化的产物是两种酸与 H（反应 6）。CsXCN 可以与 $\mathbf{X}_{2}(\mathrm{CN})_{2}$ 发生类似 $I_{2}$ 的反应（反应 7）。J 的结构与 H 非常相似，是四元化合物，可由反应 6 中生成的酸 C 与 HSCN 反应得到（反应 8），产物中存在两种酸，均不含 X。J 既有氧化性又有还原性，可用于有机反应中引入硫氰基（-SCN）。写出反应 4-8 的化学方程式。

反应 4: $2 \mathrm{Se}_{2}(\mathrm{CN})_{2} + 3 \mathrm{H}_{2} \mathrm{O} = \mathrm{HCN} + \mathrm{H}_{2} \mathrm{SeO}_{3} + 3 \mathrm{HSeCN}$

反应 5: $2\mathrm{Se}_{2}(\mathrm{CN})_{2}=\mathrm{Se}(\mathrm{CN})_{2}+\mathrm{Se}(\mathrm{SeCN})_{2}$

反应 6: $5 \mathrm{Se}(\mathrm{CN})_{2} + 6 \mathrm{H}_{2} \mathrm{O} = 2 \mathrm{H}_{2} \mathrm{SeO}_{3} + 8 \mathrm{HCN} + \mathrm{Se}(\mathrm{SeCN})_{2}$

反应 7: CsSeCN + Se₂(CN)₂ = Cs[SeCN]₃

反应 8: $3 \mathrm{H}_{2} \mathrm{SeO}_{3} + 7 \mathrm{HSCN} = 3 \mathrm{Se}(\mathrm{SCN})_{2} + 5 \mathrm{H}_{2} \mathrm{O} + \mathrm{HCN} + \mathrm{H}_{2} \mathrm{SO}_{4}$
