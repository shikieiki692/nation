### 第 4 题 六方 $AlB_{2}$ 结构（14 分，占 10%）

$\mathrm{AlB}_{2}$ 属于六方晶系，Al原子层内按最密堆积排列，B原子层内呈石墨型排列，可视为Al原子处于B原子的六棱柱空隙中。

4-1 根据以上信息，画出 $AlB_{2}$ 晶胞沿 c 轴的投影图。

4-2 $\mathrm{Yb}_{2} \mathrm{PdGe}_{3}$ 是具有 $\mathrm{AlB}_{2}$ 结构的超导体, 其中 Yb 对应 Al, Pd 和 Ge 对应 B。在 Pd 和 Ge 形成的类石墨层平面内, 可将一个六元环结构的 $[\mathrm{Ge}_{6}]$ 原子团视为密堆积的单体, 一个原子团在该层中的位置记为 A; Pd 原子占据投影上与密堆积中 B 空和 C 空重合的位置。

4-2-1 不考虑 Yb 原子，同层中分别有几种 Pd 和 Ge 原子？说明其配位原子数量和种类。

4-2-2 说明 Yb 原子的配位原子数量和种类。

4-2-3 根据以上信息，画出 $Yb_{2}PdGe_{3}$ 晶胞沿 c 轴的投影图。

4-3 $\mathrm{Yb}_{2} \mathrm{PdGe}_{3}$ 晶体的晶胞参数如下: $a = 8.468 \mathrm{~Å}, c = 4.075 \mathrm{~Å}; \alpha = \beta = 90^{\circ}, \gamma = 120^{\circ}$

4-3-1 计算该晶体的密度。

4-3-2 该晶体中 $l_{(\mathrm{Ge - Ge})} = 2.44\text{Å}$ ，计算Ge原子与相邻的Pd原子间的距离。
