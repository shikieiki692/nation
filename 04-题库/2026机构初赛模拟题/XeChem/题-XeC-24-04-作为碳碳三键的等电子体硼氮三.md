# 题-XeC-24-04-作为碳碳三键的等电子体硼氮三

## 题目

### 第 4 题 硼氮炔的衍生物（23 分，占 12%）

作为碳碳三键的等电子体，硼氮三键长期以来因其高度极化导致的内在不稳定性而缺乏充分研究。首个稳定的硼氮炔 $C_{6}F_{5}B\equiv N'Bu$ 由 Paetzold 于 1979 年报道，然而此后数十年间，学界对该领域鲜有系统探索。2020 年以来，山东大学孔令兵课题组围绕硼氮炔衍生物的结构、性质与反应性发表了一系列研究。本题将以这些成果为基础展开讨论。

## 4-1 当硼氮炔参与共轭体系：BNN-1,3-偶极体的合成与反应

研究人员首先使用联氨衍生物和卤代硼烷缩合得到中间产物A，再将A与3当量的氮杂环卡宾NHC发生反应，企图得到电荷分离的硼氮炔衍生物B、物种B组成为

$\mathrm{B}_2\mathrm{N}_2\mathrm{Dpp}_2\mathrm{NHC}$ 。然而，单晶X射线衍射分析表明，最终产物并非所期待的硼氮炔结构，而是含有稠环结构的C。

![](images/f0d12a5fe41ed8862a365f865c808c27bc42b44615ac497c1625ef84833e22fb.jpg)

4-1-1 为什么在从 A 合成 B 的过程中要加入 3 当量的氮杂环卡宾 NHC 进行反应？

4-1-2 进一步研究发现，C 是由 B 发生一步分子内反应而得到的，已知 C 的分子式与 B 一致，且新增添两个环系。画出 A-C 的结构。

4-1-3 试分析由 B 生成 C 反应的驱动力。

4-1-4 为分离稳定的硼氮炔产物，研究人员将含硼底物 $\mathrm{DppBBr_2}$ 更换为 $\mathrm{Mes}^*\mathrm{BBr}_2$ （ $\mathrm{Mes}^* = 2,4,6-$ 三叔丁基苯基），然后重复上述合成步骤，成功分离了室温稳定的1,3-偶极体D。D可在甲苯中与两分子 $\mathrm{CO_2}$ 发生反应，得到 $C_{2h}$ 点群的产物E，画出E的结构。

## 4-2 从偶极体到硼宾合成子：让我们减少一当量 NHC

对以上体系的进一步研究带来了新的惊喜。当使用 $\mathrm{Mes}^*$ 作为取代基时，在合成的第二步将NHC的用量减少至2当量，可以分离得到稳定且具有对称结构的产物F。有趣的是，F的反应性和D截然不同。

$$
\text { TMSNHNHTMS } \xrightarrow [ 2) \mathrm{NHC(2eq.)} , \text { toluene,   r.t. } ]{1) \mathrm{Mes*BBr} _ {2} (2 \text { eq. }) , \text { toulene,   r.t. }} F \xrightarrow [ - N _ {2} , \text { r.t. } ]{50 ^ {\circ} \mathrm{C}} G
$$

4-2-1 在 $50^{\circ}\mathrm{C}$ 的加热下，F 会发生一步分子内的碳氢键活化，得到含有五元环的产物 G。画出 F 和 G 的结构。

4-2-2 由于硼端的高度亲电性，F 可以作为硼宾合成子和具有亲核性的试剂发生反应。将 F 与 2 当量的由 $^{15}\mathrm{N}$ 标记的苯甲腈在室温下混合，体系立即涌出气泡，经检测成分均为 $^{14}\mathrm{N}_{2}$ 。后续分离得到的产物 H 中含有一个 $4\pi$ 的平面六元环。画出 H 的结构，解释 H 可以稳定存在的原因。
