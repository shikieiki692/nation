# 题-XeC-17-03-第14族元素在生产生活中发挥

## 题目

### 第 3 题 负价碳族元素配合物的合成与反应（19 分，占 11%）

第 14 族元素在生产生活中发挥重要的作用, 它们是生命的基础、是半导体工业的支柱、也是人类最早使用的金属之一。近日, 来自德国的科研团队在室温下成功制备了含有 Si、Ge、Sn、Pb 四负离子 ( $E^{4-}$ ) 的配合物, 本题将考察该配合物的合成与反应。

3-1 为合成含 $\mathrm{E}^{+}$ 的配合物, 研究人员首先合成了一种四电子还原剂 $\mathbf{X}$ (即在做还原剂时 $1 \mathrm{~mol} \mathbf{X}$ 可以转移 $4 \mathrm{~mol}$ 电子, $\mathbf{X}$ 的化学式为 $\mathrm{Na}_{2}(\mathrm{MgBDI})_{2}$ ), 画出 $\mathbf{X}$ 的结构。

![](images/595d10d519144c6d0d6252d0c227bb9cd7b1249848a4735f57e7a52e91f9b50c.jpg)

3-2-1 配合物 X 具有极强的亲核能力，写出 X 与 "BuBr 反应的方程式，Mg 上的螯合取代基可以简写为 BDI。

3-2-2 X 与合成 X 的底物(BDI)Mg-I 可以发生与 3-2-1 类似的反应, 得到化合物 Y。Y 中含两个 Mg, 但二者配位数并不相同, 画出 Y 的结构。提示: 注意体现两种配位数的 Mg 的配位立体化学。

3-3 $\mathrm{E}(\mathrm{Cp}^{*})_{2}$ (E = Si, Ge, Sn, Pb, $\mathrm{Cp}^{*} = \mathrm{C}_{5}\mathrm{Me}_{5}$ ) 分别与 X 反应，可以得到对应的目标负价碳族元素配合物 A-Si、A-Ge、A-Sn、A-Pb。反应过程中，先发生了一次四电子还原得到配合物 Z，Z 再进一步与 X 反应，1:1 的生成 Y 和 A。画出 Z 和 A 的结构，其中的碳族元素用 E 表示即可。

3-4-1 A 具有极强碱性，A-Si、A-Ge 中的 $E^{4+}$ 可以夺取螯合配体中 Ar 基团邻位- $CHEt_{2}$ 取代基上的氢形成碳负离子中间体，碳负离子进攻 BDI 中的 C=N 双键，可得配合物 B。画出 B 的结构，其中的碳族元素用 E 表示即可，不要求立体化学。

3-4-2 A 具有极亲核性，A-Sn 与 MeI 反应可以直接生成 SnMe $_{4}$ ，写出反应的方程式。

3-4-3 A 具有极还原性, A-Sn 与 $\mathrm{N}_{2} \mathrm{O}$ 反应可以发生八电子氧化还原得到 C, C 的分子量比 A 大 64, 画出 C 的结构。
