# 题-XeC-25-05-移液枪活塞式移液器是现代化学

## 题目

### 第 5 题 移液枪的使用（23 分，占 14%）

移液枪（活塞式移液器）是现代化学实验室中常用的量器，用于转移指定体积的液体，具有移液体积精确、可调等优势。

5-1 常见移液枪的结构示意图如右图所示。将聚四氟乙烯管嘴与移液枪安装在一起。旋转移液枪旋钮可在标定量程内调节移取体积，枪身会显示当前示数。活塞具有一浅一深两个停点：按到第一停点后，将管嘴末端浸入液面，松开活塞，内活塞将上移恢复原位，管嘴在大气压作用下吸入指定体积液体；需排出液体时，按活塞至第二停点，两停点之间的行程可使排液充分。

## 5-1-1 移液枪属于：(a) 量入式量器 (b) 量出式量器

5-1-2 分别用移液枪装同一规格管嘴，在相同示数下竖直吸取纯水和浓硫酸，管嘴内吸取的纯水体积为 $V_{1}$ ，浓硫酸体积为 $V_{2}$ 。其关系满足：(a) $V_{1} < V_{2}$ (b) $V_{1} = V_{2}$ (c) $V_{1} > V_{2}$

5-1-3 相同示数，移液枪整体倾斜 $30^{\circ}$ 吸取纯水，管嘴内纯水体积为 $V_{3}$ 。其和 $V_{1}$ 关系满足：(a) $V_{1} < V_{3}$ (b) $V_{1} = V_{3}$ (c) $V_{1} > V_{3}$

5-1-4 移液枪吸取二氯甲烷（DCM）后，管嘴悬空时有 DCM 从中滴落；将管嘴内 DCM 排出，不拆管嘴再次吸取 DCM，滴落现象缓解。解释滴落现象出现与缓解的原因。

5-1-5 使用新换管嘴吸取纯水后充分排出（称为“润洗”），排出体积 $V_{4}$ 的水；不换管嘴，再次吸取纯水并充分排出体积 $V_{5}$ 的水。解释 $V_{4} < V_{5}$ 的原因。

1）稀释所得工作液浓度 $c_{1} = c_{0}V_{1} / (V_{1} + V_{2}) = c_{0} / (1 + V_{2} / V_{1})$ 加减法误差传递 $s[1 + V_2 / V_1]^2 = s[V_2 / V_1]^2$ 乘除法误差传递 $s[V_2 / V_1]^2 /(V_2 / V_1)^2 = s_{V1}^2 /V_1^2 +s_{V2}^2 /V_2^2 = (0.1 / 2.0)^2 +(3 / 998)^2\approx (0.1 / 2.0)^2 =$ $2.5\times 10^{-3}$ 乘除法误差传递 $s_{c1}^{2} / c_{1}^{2} = s_{c0}^{2} / c_{0}^{2} + s[1 + V_{2} / V_{1}]^{2} / (1 + V_{2} / V_{1})^{2}$ $= s_{c0}^{2} / c_{0}^{2} + s[V_{2} / V_{1}]^{2} / (V_{2} / V_{1})^{2}\times [V_{2} / (V_{1} + V_{2})]^{2}$ $= (0.5 / 100.0)^{2} + 2.5\times 10^{-3}\times [998 / (2.0 + 998)]^{2}$ $= 2.53\times 10^{-3}$ 工作液浓度相对不确定度 $s_{c1} / c_1 = (2.5\times 10^{-3})^{1 / 2} = 0.05 = 5\%$ （误差传递公式+过程，或说明近似方法，2分：结果1分）

如果写为 $s_{c1}^2 / c_1^2 = (\approx) s_{c0}^2 / c_0^2 + s_{V1}^2 / V_1^2 + s[V_1 + V_2]^2 / (V_1 + V_2)^2 \approx s_{V1}^2 / V_1^2$ ，第一步实际上作了 $V_1 << V_2$ 近似，即 $c_1 \approx c_0 V_1 / V_2$ 。这在(1)中是合理近似，但(2)中会因重复考虑同一变量误差导致结果错误。如不确定误差传递方法，可通过求偏导验证依赖关系。

(2) 第一次稀释后浓度 $c_1 = c_0 V_1 / (V_1 + V_2)$ 第二次稀释后浓度 $c_2 = c_1 V_3 / (V_3 + V_4) = c_0 \times [V_1 / (V_1 + V_2)] \times [V_3 / (V_3 + V_4)]$ 简记为 $c_0 k_1 k_2$ 同(1)的算法，浓度比值项的相对不确定度平方分别为 $s_{k1}^2 / k_1^2 = s[V_2 / V_1]^2 / (V_2 / V_1)^2 \times [V_2 / (V_1 + V_2)]^2$ $= (s_{V1}^2 / V_1^2 + s_{V2}^2 / V_2^2) \times [V_2 / (V_1 + V_2)]^2$

$$
