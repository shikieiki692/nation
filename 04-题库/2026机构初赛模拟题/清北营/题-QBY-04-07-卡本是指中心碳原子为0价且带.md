# 题-QBY-04-07-卡本是指中心碳原子为0价且带

## 题目

### 第 7 题（34 分，占 14%）硅卡本的合成与反应性

卡本是指中心碳原子为 0 价且带有两对孤对电子的一类化合物，同样硅也可以形成类似的结构，称为硅卡本。

7-12020 年，来自德国的化学家合成了一种基于碳硼烷结构的硅卡本，并研究了其独特的单电子氧化还原性质。

7-1-1 该硅卡本可以通过如下的反应路线合成，已知底物 A 与硅卡本 C 中均含闭式 1,2-碳硼烷结构，而底物的还原产物 B 中含有一个巢式 1,3-碳硼烷阴离子，该阴离子在原结构基础上重排形成了六元环开口，且碳硼烷部分不含 C-C 键，其中 Si 的质量分数为 4.27%。给出 B、C 的结构。

![](images/8d8fc7825595688abfd53b5e35bdb602c9897291f458d555b8c38107251567b6.jpg)

7-1-2 进一步地，硅卡本 C 也可被 KC $_{10}$ H $_{8}$ 在 THF 中还原得到含有巢式碳硼烷骨架的二聚产物 D。已知 D 中存在一根 Si-Si 单键且 C 中的某根单键在 D 中被还原，其中 Si 的质量分数为 8.29%。给出 D 的化学式并画出其结构。

7-1-3 同时，研究人员发现 C 的单电子还原过程经历了复杂的电子转移历程，而后也通过 DFT 计算的方式推测了可能存在的反应中间体。C 先与 $KC_{10}H_{8}$ 发生一步单电子转移将 C 中的一个含氮配体还原生成中间体 E1，再发生第一次分子内单电子转移将某根单键还原得到单电子离域的中间体 E2，而后发生第二次分子内单电子转移生成硅自由基阴离子 E3，而后 E3 二聚得到产物。

7-1-3-1 给出 E1、E2 和 E3 的相对能量高低。

7-1-3-2 给出 E1、E2 和 E3 的结构。（注意标明单电子位置）

7-22024 年，来自台湾和新加坡的一课题组合成了硅卡宾配体稳定的具有四元螺环结构的双硅卡本 G，同时在反应过程中发现了一些意料之外的产物。研究人员将底物 F 与 $(\mathrm{PMe}_{3})_{2}\mathrm{SiCl}_{4}$ 及 $\mathrm{KC}_{8}$ 反应得到了三种产物 G、H 和 I。

![](images/fbab83566e49aece8e6457ad290972aa3d1be14c24557823ccb8756ca1b51e51.jpg)

7-2-1 反应的引发步骤为 $\left(\mathrm{PMe}_{3}\right)_{2}\mathrm{SiCl}_{4}$ 被 $KC_{8}$ 还原生成的硅卡本 J 插入底物 F 中的 Si-Si 键生成硅卡宾中间体 Int1，给出引发总反应的方程式。（含 N 配体可用 L 简写）

7-2-2 Int1 可通过如下三种反应路径得到三种产物:

1）Int1 再插入一分子底物 F 中的 Si-Si 键得到中间体 Int2，Int2 与两分子 J 反应得到双硅卡本产物 G。

2）Int1 直接二聚得到具有一个对称中心的产物 H，H 中不存在 Si=Si 双键；

3）Int1 再插入一分子底物 F 中的 Si-Si 键得到中间体 Int2，Int2 发生一步重排生成四元环产物 I，I 中若忽略配体取向含有一个镜面且其中一个含氮配体由双齿变为了单齿；

给出产物 G、H 和 I 的结构。

7-2-3 通过对 I 的 Si-NMR 谱分析，得到了 $\delta = -163.2$ ，-97.4，58.8，101.7 的四个峰，将这四个化学位移与 I 中不同化学环境的硅一一对应。
