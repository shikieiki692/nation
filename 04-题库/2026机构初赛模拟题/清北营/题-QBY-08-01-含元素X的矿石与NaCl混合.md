# 题-QBY-08-01-含元素X的矿石与NaCl混合

## 题目

### 第 1 题（19分，占 $6\%$ ）

含元素 X 的矿石与 NaCl 混合，在空气中加热至 $850^{\circ}$ C，可以得到 1:1 型盐 A。A 溶于水后调 pH 至 2 左右会析出砖红色沉淀，其为氧化物 B 的水合物。与 A 具有相同阴离子的铵盐 C 在 $500^{\circ}$ C 下分解也可以得到橙黄色粉末 B（反应 1）。将 B 溶于浓 NaOH 水溶液中可以得到无色溶液（反应 2），用盐酸不断酸化时可以观察到溶液颜色变为橙红色，而后析出沉淀，再然后沉淀溶解、溶液变为浅黄色，其中的显色物质是盐 D。进一步的研究表明，在不断酸化的过程中产生了多种含 X 阴离子，如 E、F、G，三者 X 的质量分数分别为 47.6%、50.1%、53.2%。将干燥的氯气流通过加热到 $600-800^{\circ}$ C 的 B，可以得到黄色的 H（反应 3）。
