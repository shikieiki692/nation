## 参考答案

在本题中, 你可能需要以下数据: (本题不考虑题给条件下 $\mathrm{AgOH}$ 的生成) $\mathrm{NH}_{4}^{+}: \mathrm{pK}_{3} = 9.25, \mathrm{Mg(OH)}_{2}: \mathrm{pK}_{\mathrm{sp}} = 11.25 \quad \mathrm{Ag(NH}_{3})_{2}^{+}: \lg \beta_{2} = 7.04$

5-1-1 向 1L 0.1mol/L 的 $NH_{3}\cdot H_{2}O$ 中加入 $1.5g\ Mg(NO_{3})_{2}$ ，通过计算说明此时是否会生成 $\mathrm{Mg(OH)}_{2}$ 沉淀，若会生成沉淀，计算生成沉淀的质量；若不会生成沉淀，计算此时溶液的 pH。

5-1-1 $c_{Mg(NO_3)_2,0} = \frac{1.5}{148.33 \times 1} = 0.0101(mol/L)$ 先列出加入 Mg(NO₃)₂ 后的电荷守恒式: $2[Mg^{2+}] \neq [NH_4^+] + [H^+] = [OH^-] \neq [NO_3^-]$ ;
若不会生成沉淀, 此时有 [Mg²⁺] = 2[NO₃⁻], 则有 [NH₄⁺] + [H⁺] = [OH⁻],
即 $\frac{c_0[H^+]}{K_a + [H^+]} + [H^+] = \frac{K_w}{[H^+]}$ , 解得 [H⁺] = 7.55 × 10⁻¹² mol/L, 此时有 Q = [Mg²⁺][OH⁻]² = 1.77 × 10⁻⁸ > K\_sp(Mg(OH)₂);
因此会生成 Mg(OH)₂ 沉淀。
则 $2\frac{K_{sp}[H^+]^2}{K_w^2} + \frac{c_0[H^+]}{K_a + [H^+]} + [H^+] = \frac{K_w}{[H^+]} + [NO_3^-]$ , 解得 [H⁺] = 1.27 × 10⁻¹⁰ mol/L; 则有 [Mg²⁺] = $\frac{K_{sp}[H^+]^2}{K_w^2} = 9.13 \times 10^{-4}(mol/L)$ ;
因此沉淀质量为 (0.0101 - 9.13 × 10⁻⁴) × 58.326 = 0.537 g。

5-1-2 向 $1\mathrm{L}0.1\mathrm{mol} / \mathrm{L}$ 的 $\mathrm{NH_3\cdot H_2O}$ 加入 $1.5\mathrm{gAgNO_3}$ ，通过计算给出此时溶液的 $\mathsf{pH}$ 值与 $\mathrm{Ag(NH_3)_2^+}$ 的浓度。

5-1-2 $c_{AgNO_{3},0} \equiv \frac{1.5}{169.91 \times 1} = 8.83 \times 10^{-3} (mol/L)$ 列出加入 AgNO₃ 后的电荷守恒式与物料守恒式: $[Ag^{+}] + [Ag(NH_{3})_{2}^{+}] + [NH_{4}^{+}] + [H^{+}] = [OH^{-}] + [NO_{3}^{-}]$ ; $2[Ag(NH_{3})_{2}^{+}] + [NH_{4}^{+}] + [NH_{3}] = c_{0}$ ; $[Ag^{+}] + [Ag(NH_{3})_{2}^{+}] = c_{AgNO_{3},0}$ ;
设 $[Ag^{+}] = x mol/L$ , $[H^{+}] = y mol/L$ , $[NH_{3}] = z mol/L$ 则有 $\left\{\begin{aligned}&x+\beta_{2}xz^{2}+\frac{yz}{K_{a}}+y=\frac{K_{w}}{y}+c_{AgNO_{3},0}\\&2\beta_{2}xz^{2}+\frac{yz}{K_{a}}+z=c_{0}\\&x+\beta_{2}\ddot{x}z^{2}=c_{AgNO_{3},0}\end{aligned}\right.$
