# 题-QBY-11-01-化学式形如的盐多种多样常常让

## 题目

### 第 1 题（19 分，占 9%）硫的含氧酸盐

化学式形如 $Na_{2}S_{2}O_{x}$ 的盐多种多样，常常让化学学习者们晕头转向。小叶搜集了多种硫的含氧酸盐的化学性质，希望大家做得开心。

1-1 硫代硫酸钠 $Na_{2}S_{2}O_{3}$ 俗称海波，高温隔绝空气加热分解时先生成两种固体 A 和 B（反应一），B 中 S 质量分数为 77.71%，B 再分解生成 C 和 D，D 的熔点较低，写出反应一的化学方程式，并解释硫代硫酸钠能解(CN)中毒的原因（不超过 20 字）

1-2 连二亚硫酸钠 $Na_{2}S_{2}O_{4}$ 俗称保险粉，具有极强的还原性。与 $CuSO_{4}$ 溶液反应生成红色沉淀（反应二）。NaOH 溶液中分解产生 C、E（反应三）。写出反应二、三的化学方程式。

1-3 焦亚硫酸钠 $Na_{2}S_{2}O_{5}$ 具有非对称结构, 画出其结构式, 标出其中 S 的价态。其与水发生可逆反应生成 F, 写出 F 的化学式。

1-4 连二硫酸钠 $Na_{2}S_{2}O_{6}$ 中 S 呈正五价，其制备是利用 $MnO_{2}$ 氧化 $SO_{2}$ ，再用 $Na_{2}CO_{3}$ 沉淀，写出总反应方程式。

1-5 焦硫酸钠 $Na_{2}S_{2}O_{7}$ 由 $NaHSO_{4}$ 加热脱水制得。其对应的焦硫酸与硼酸反应能得到一种超强酸，该超强酸阴离子中 B 的质量分数 2.71%。写出反应离子方程式。

1-6 过二硫酸钠 $Na_{2}S_{2}O_{8}$ 具有超强的氧化性，然而其反应往往较为缓慢，需加入 $Ag^{+}$ 催化，写出银离子催化过二硫酸根氧化草酸根过程的可能机理（不需要写链终止）。已知每一步反应都是单电子转移，反应过程中产生两种高活性自由基中间体。

## 参考答案


**1-1** 反应一: $4Na_{2}S_{2}O_{3} == 3Na_{2}SO_{4} + Na_{2}S_{5}$ 原因: $Na_{2}S_{2}O_{3}$ 提供S原子与(CN) $^{-}$ 反应生成无毒的(SCN) $^{-}$ A:  $Na_{2}SO_{4}$ ,B:  $Na_{2}S_{5}$ ,C: $Na_{2}S$ ,D:S。

**1-2** 连二亚硫酸钠 $Na_{2}S_{2}O_{4}$ 俗称保险粉,具有极强的还原性。与 $CuSO_{4}$ 溶液反应生成红色沉淀(反应二)。NaOH溶液中分解产生C、E(反应三)。写出反应二、三的化学方程式。

**1-2** 反应二: $Na_{2}S_{2}O_{4} + CuSO_{4} == Cu + Na_{2}SO_{4} + 2SO_{2}$ 反应三: $3Na_{2}S_{2}O_{4} + 6NaOH == 5Na_{2}SO_{3} + Na_{2}S + 3H_{2}O$ 前面推出C为 $Na_{2}S$ ,碱性歧化考虑价态+4,产物之一 $Na_{2}SO_{3}$ 。 $Na_{2}S_{2}O_{4}$ 在遇水或加热下分解都会产生 $Na_{2}S_{2}O_{3}$ (以及以 $SO_{2}$ 、 $SO_{3}^{2-}$ 等存在的S(IV)),并引发副反应。

**1-3** 焦亚硫酸钠 $Na_{2}S_{2}O_{5}$ 具有非对称结构,画出其结构式,标出其中S的价态。其与水发生可逆反应生成F,写出F的化学式。

**1-5** 焦硫酸钠 $Na_{2}S_{2}O_{7}$ 由 $NaHSO_{4}$ 加热脱水制得。其对应的焦硫酸与硼酸反应能得到一种超强酸,该超强酸阴离子中B的质量分数2.71%。写出反应离子方程式。

**1-5** $B(OH)_{3} + 3H_{2}S_{2}O_{7} == H_{3}SO_{4}^{+} + [B(HSO_{4})_{4}]^{-} + H_{2}SO_{4}$

**1-6** 过二硫酸钠 $Na_{2}S_{2}O_{8}$ 具有超强的氧化性,然而其反应往往较为缓慢,需加入 $Ag^{+}$ 催化,写出银离子催化过二硫酸根氧化草酸根过程的可能机理(不需要写链终止)。已知每一步反应都是单电子转移,反应过程中产生两种高活性自由基中间体。

**1-6** 机理: $Ag^{+} + S_{2}O_{8}^{2-} \rightarrow Ag^{2+} + SO_{4}^{2-} + SO_{4}^{·-}$ (引发) $Ag^{2+} + C_{2}O_{4}^{2-} \rightarrow Ag^{+} + CO_{2} + CO_{2}^{·-}$  $S_{2}O_{8}^{2-} + CO_{2}^{·-} \rightarrow CO_{2} + SO_{4}^{2-} + SO_{4}^{·-}$  $Ag^{+} + SO_{4}^{·-} \rightarrow Ag^{2+} + SO_{4}^{2-}$  $C_{2}O_{4}^{2-} + SO_{4}^{·-} \rightarrow CO_{2} + CO_{2}^{·-} + SO_{4}^{2-}$ 任写四个即可,但需包含第一个反应
