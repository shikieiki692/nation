## 参考答案

将金属锶与 $\mathrm{C}_{60}$ 按照一定比例混合之后升温至 $450^{\circ}\mathrm{C}$ 以上，可以得到最简式为 $\mathrm{SrC}_x$ 的晶体，属立方晶系。其结构可以视为 $\mathrm{C}_{60}$ 进行体心立方堆积（取向相同）， $\mathrm{Sr}$ 填入其中一半的四面体空隙。

7-1 写出 $C_{60}$ 所属点群。已知 $C_{60}$ 中每个 C 原子形成 3 个碳碳键，通过计算给出其具有的五边形、六边形数目。（欧拉公式：顶点数 + 面数 = 极数 + 2）

7-1 点群： $l_{h}$ 。
因为每个 C 均为 3 配位，一个棱由 2 个 C 连接而得，所以共有 $60 \times 3 \div 2 = 90$ 条棱。设有 x 个五边形，y 个六边形。由于一条棱为两个面相并而得，故 $5x + 6y = 90 \times 2$ 。由欧拉定理， $60 + x + y = 90 + 2$ 。
联立解得 $x=12,y=20$ 故具有12个五边形，20个六边形。

容易得出 $C$ 的 $x$ 坐标是0.5， $y$ 坐标是 $0.5 - 1.431 \div (2 \times 11.21) = 0.4362$ 。 $z$ 坐标满足距离条件： $11.21 \sqrt{(1 - z)^2 + (0.4362 - 0.2426)^2} = 3.015$

解得z=0.8133。故C坐标为(0.5,0.4362,0.8133)。
