# 题-QBY-04-02-分子笼在手性催化分子识别等方

## 题目

### 第 2 题（33 分，占 16%）分子笼协同非共价相互作用催化

分子笼在手性催化、分子识别等方面具有广泛的应用及深远的应用前景，通过构建功能化大环和分子笼，利用多重非共价作用可发展高效识别和超分子催化体系。

近日，中国科学院化学研究所王其强研究员团队发展了利用缺电性分子笼催化促进了酸酐的高选择性去对称化反应。

![](images/f8ceb3ed74d2c0d3ffd9b6a4518c4d51f1ec99129dabe07b8ced76d5e4e3b0af.jpg)

一种常见的分子笼C可通过两种有机原料A（三元化合物，碳的质量分数为 $57.14\%$ ）和B（三元化合物，碳的质量分数为 $19.54\%$ ）以物质的量之比2:3在DIPEA的作用下于THF中回流得到，且A、B、C中均含有三重旋转轴与六元芳环。而分子笼C可在DIPEA的存在下与大过量的奎宁衍生物L在THF中回流得到此反应使用的催化剂X1。

2-1 通过计算给出 A、B、C 的化学式并画出结构，同时给出 C 的点群。

2-2 合成的分子笼 C 可以与不同分子或离子通过多样的分子/离子间非共价相互作用结合，在其中 C 中的缺电子芳环所形成的 $\pi$ -hole 起到了重要作用：

2-2-1 画出一分子 C 与 $H_{2}O$ 、 $Br^{-}$ 形成的复合物 $C\cdot Br^{-}\cdot H_{2}O$ （C1）的结构，并给出 C1 中的非共价作用名称。

(C1 中存在 1 个未参与非共价相互作用的芳环)

2-2-2 画出复合物 $2 \mathrm{C} \cdot$ acetone（C2）与 $\mathrm{C} \cdot \mathrm{PDS}^{2-}$ （C3）（ $\mathrm{H}_{2} \mathrm{PDS}$ 的结构如下图所示）的结构；（提示：C3 中仅有 1 个磺酸基团参与了与 C 分子 $\pi$ -hole 的作用）

![](images/956b832c4e256850ea1d360ddb97409d307bc414e5fe3be8ac0b06f3452cfd29.jpg)
$\mathrm{H}_{2} \mathrm{PDS}$

2-2-3 有趣的是, 由于 $\mathrm{PDS}^{2-}$ 中两个磺酸基团的存在, C3 阴离子可自组装形成一维无限长链, 该结构由 $\mathrm{PDS}^{2-}$ 连接 C 分子二聚体构成双链, 此长链堆积形成层状结构。已知形成的一维无限长链中 C 分子与 C 分子间、C 分子与 $\mathrm{PDS}^{2-}$ 间均存在非共价相互作用, 且最小重复单元为 2 个 C3 阴离子, 给出该一维无限长链的结构并给出存在的非共价相互作用名称。

## 2-3 给出 X1 的结构。

2-4 若在合成分子笼 C 的体系中加入与 B 等当量的苯酚则可得到不含笼状骨架但当向反应体系中加入与 B 等当量的苯酚则可得到不含笼状骨架但同样具有催化性能的前体分子 D, D 亦可在过量 L 的作用下与 DIPEA 在 THF 中回流合成催化剂 X2，给出 X2 的结构。

2-5 在题干反应中, 酸酐中的 2 个羰基氧参与形成的非共价相互作用成为了催化过程中的关键角色, 仔细观察 L 分子上的相关基团, 给出在反应过程中 MeOH 亲核进攻一步的过渡态, 要求明确示出过渡态中存在的两种非共价相互作用。

2-6 比较 X1 与 X2 在作为同一反应的催化剂时，产物的对映体过量值（ee）大小，并解释原因。
