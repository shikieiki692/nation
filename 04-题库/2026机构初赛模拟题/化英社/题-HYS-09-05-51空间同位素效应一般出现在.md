设 $\Delta=9.03,\quad\delta=0.184,\quad1,1.3.3-$ 四甲基环己烷平伏甲基位移为x，则直立甲基化学位移为 $x+\Delta$ ，氘代后甲基1化学位移为 $x + (\Delta -\delta) / 2$ ，甲基2化学位移为 $x + (\Delta +\delta) / 2$ （1分）
$$
y (x + \Delta) + (1 - y) x = x + (\Delta + \delta) / 2 (1 \text {分})
$$
$$
\text { 解得 } y = (\Delta + \delta) / 2 \Delta , (1 - y) = (\Delta - \delta) / 2 \Delta (1 \text { 分 })
$$
