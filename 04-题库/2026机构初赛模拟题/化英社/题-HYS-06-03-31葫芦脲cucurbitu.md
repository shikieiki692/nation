# 题-HYS-06-03-31葫芦脲cucurbitu

## 题目

### 第 3 题 葫芦脲 Cucurbiturll 的转子结构（31分，占 $15\%$ ）

3-1 葫芦脲(cucurbituril)是一个分子式为 $\left(\mathrm{C}_{6}\mathrm{H}_{6}\mathrm{N}_{4}\mathrm{O}_{2}\right)_{6}$ 的六聚大环化合物，其形状类似葫芦，具有理论上的 $D_{6h}$ 对称性，可通过以下反应控制条件以制备：

![](images/643f00f90d020598f43e1f87f71d1c93938ce47b354aad7196035bc55a114dea.jpg)

3-1-1 画出葫芦脉结构。

3-1-2 葫芦脲作为大环空穴配体，可与二质子化的 N, N' -双(4-吡啶甲基)-1, 4-二氨基丁烷等比例结合，形成转子结构。其中葫芦脲配体结构可作如下图所示的简化，由此表示出转子结构，并说明其稳定性来源，要求指出其中两种主要的作用力。

![](images/a3deca6f2e4e293ab982df23e6da31bf2f6a2a04c675cea758d2693bdc9a64f3.jpg)

3-2 转子结构（本问中的转子结构可作如下图的简化）可与不同试剂反应，作为配体和过渡金属结合，形成多种多样的配位物种。

![](images/9eac82be676e7f570aac97dfbd008d607f8cf991e3d1199aa92768690d64929c.jpg)

3-2-1 转子与 $\mathrm{Ag(CH_3C_6H_4SO_3)}$ 反应生成链形结构 I, 与 $\mathrm{Cu(NO_3)_2}$ 在水中反应生成链形结构 II。已知链形结构 I、II 类似, II 中 Cu 为五配位, 且不含硝酸根和羟基配体。画出 I、II 结构, 注意电荷。

3-2-2 转子与 $\mathrm{AgNO}_{3}$ 反应, 生成了高对称二维网络结构, 其中金属与转子的比例为 $2: 3$ , 且结构中 $\mathrm{Ag}$ 为四配位。通过画图表示出二维网络结构, 不要求电荷。

3-2-3 转子与 $\mathrm{Pt(en)(NO_3)_2}$ 等比例反应形成了三核的“分子项链”，画出其阳离子结构，注意电荷。

3-3 转子结构单元中的 4-吡啶甲基可用其他功能团置换，以改变它的性质。

3-3-1 用 4-氰苄基置换 4-吡啶甲基后得到新的转子, 化学式为 $\mathrm{C}_{56} \mathrm{H}_{60} \mathrm{~N}_{28} \mathrm{O}_{12}^{2+}$ 。 $0.065 \mathrm{mmol}$ 新转子与 $0.3 \mathrm{mmol}$ 某种含结晶水的硝酸盐在 $5 \mathrm{ml}$ 水和 $0.007 \mathrm{mmol} \mathrm{NEt}_{3}$ 存在下混合, 密封在不锈钢容器中, 保持 $150^{\circ} \mathrm{C}$ 加热反应三天, 冷却至室温, 得到 $80 \mathrm{mg}$ 淡黄色晶体 $\mathbf{X}$ 。3-3-1-1 已知硝酸盐中镧系元素 Ln 的质量分数为 $36.53 \%$ ，直接给出硝酸盐化学式。

3-3-1-2 元素分析表明，X 中部分元素质量分数（理论值）如下：C 38.94%，H 4.435%，N 22.71%，Ln 6.133%。已知在 X 的制备反应前后转子的结构发生了变化，而 X 为含结晶水的 1:6 型盐，其中阳离子不含硝酸根，且骨架结构与 3-2-2 中二维网络阳离子类似。通过计算与推导，给出 X 的化学式。

3-3-2 用 3-氰苄基置换 4-吡啶甲基后得到新的转子, 化学式为 $\mathrm{C}_{56} \mathrm{H}_{60} \mathrm{~N}_{28} \mathrm{O}_{12}^{2+}$ 。将 3-3-1 涉及的反应中的转子替换, 其他条件不变, 则可制得大块无色晶体 $\mathbf{Y}$ 。

3-3-2-1 元素分析表明，Y 中部分元素含量（理论值）如下：N 22.12%，O 29.00%。已知在反应过程中转子结构发生了同样的变化，且 Y 中同样含有结晶水。不同的是 Y 中阴阳离子均含两种，其中两种阳离子数目相等，且其中一种在组成上与 X 的阳离子相同，另一种不含 Ln；两种阴离子数目也相等，一种阴离子为氢氧根，另一种为硝酸根。通过计算与推导，给出 Y 的化学式。
