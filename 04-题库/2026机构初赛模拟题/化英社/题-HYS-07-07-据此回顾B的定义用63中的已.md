## 参考答案

基于扭曲分子内电荷转移（TICT）的荧光探针因其灵敏度和特异性，在化学传感领域至关重要。这些探针与目标分析物相互作用时会发生构象变化，从而产生可测量的荧光响应。它们的发射特性具有环境依赖性，这使其成为检测溶剂极性、微粘度和特定化学物种变化的理想选择。

7.1.1 与一般的荧光分子相似，DMABN 也可以吸光跃迁，得到激发态 LE。观察基团的电子效应，用 DMABN 的一种共振式近似表达 LE 的结构。

![](images/65d4499999da14dacec1e95e8d22b08f2762adc9c8c9c70fd2bea3366f63d2de.jpg)
(1 分)

7.1.2 然面，TICT 的特别之处在于，除了常见的去激发途径，LE 还可以保持电子激发态不变，仅仅发生构象的转变。简单的考虑下，相当于与另一种极限结构 T1 在激发态下达成平衡。结合 7.1.1，分析两种激发态共轭体系的大小，思考电子效应对极性的影响，分别指出极性溶剂与非极性溶剂中哪种结构更稳定。分析电子基态的平衡，将双重荧光的波长（350 nm、500 nm）分别归属于两种激发态。

$$
\text { 极性: } \mathrm{TI} _ {1} \text { 非极性: } \mathrm{LE} _ {0} 350 \mathrm{nm}; \mathrm{LE} _ {1} 500 \mathrm{nm}; \mathrm{TI} (\text { 共 } 2 \text { 分,每组全对得 } 1 \text { 分 })
$$

Ⅱ中没有共轭体系，电荷分离更显著，极性溶剂中稳定

7.1.3 思考常见的非辐射衰变的方式，结合激发态的构象，比较两种波长的荧光的量子产率大小。

350 nm 大于 500 nm（1 分）

7.2 实际上，量子产率更小的一方在应用中往往表现为荧光强度很小，即荧光淬灭。于是，利用上述量子产率的对比，就可以通过荧光存在与否判断 TICT 是否发生。反之，通过观察 TICT 可以反馈体系的特定信息，最终会转换为荧光信号。以此，构建用于检测环境或生物环境中重要物质的探针。
