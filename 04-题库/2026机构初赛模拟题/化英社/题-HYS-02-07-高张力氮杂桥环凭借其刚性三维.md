7-2 英国布里斯托大学 Varinder K. Aggarwal 团队开发了一种高张力氮杂双环[2.1.0]戊烷和氮杂双环[3.1.0]己烷的立体选择性锂化策略。研究发现两种桥环的锂化位点受动力学控制均为二号碳原子 exo 位置，这一性质也决定了两者后续的官能团化反应的高立体选择性。

![](images/c990dcacc9b1032f92440dacc8c67960b33beac33e6eeac6877b73725d4545b8.jpg)

7-2-1 由于[2.1.0]环和[3.1.0]环骨架的不同，二者在开环位点上有所差别。将二者的锂化产物与二苯甲酮反应后，经历不同的处理得到了两种截然不同的产物。

$$
\begin{array}{r l} & \text {   X   } \xrightarrow [ \text {   then   } H _ {2} O (1.5 \text { eq}) ]{\text {   二苯甲酮   (1.5 eq)   }} \xrightarrow [ \text {   then   } T s _ {2} O (2.0 \text { eq}) ]{\text {   LiBr   (ex)   }} \xrightarrow [ \text {   rt,   } 15 \text { min} ]{\text {   K } _ {2} \text { CO } _ {3} (2.0 \text { eq)   }} \\ & \text {   Y   } \xrightarrow [ \text {   then   } H _ {2} O (1.5 \text { eq}) ]{\text {   二苯甲酮   (1.5 eq)   }} \xrightarrow [ \text {   -40 °C,   } 5 \text { min} ]{\text {   Ts } _ {2} \text { O   (2.0 eq)   }} \xrightarrow [ \text {   MeCN,   rt,   } 48 \text { h} ]{\text {   2,6-lutidine   (2.0 eq)   }} \\ & \text {   F   } \end{array}
$$

已知两条路线在第二步反应中 $\mathrm{Ts}_2\mathrm{O}$ 都实际只有一当量参与反应并且都只结合了N原子，第一条路线在LiBr处理时发生了开环。画出F和G的结构式，已知F具有不同于底物X的高张力并环结构，注意相对立体化学。
