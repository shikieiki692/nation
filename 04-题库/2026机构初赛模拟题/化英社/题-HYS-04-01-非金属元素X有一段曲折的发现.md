# 题-HYS-04-01-非金属元素X有一段曲折的发现

## 题目

### 第 1 题 超凡脱俗的脸灰元素（21分，占 $11\%$ ）

非金属元素 X 有一段曲折的发现史, 最戏剧的是最早发现元素 X 的科学家忘记将其命名。单质 X 的晶体具有金属光泽, 地球形成早期, X 单质与一种短周期元素 Y 的单质反应生成了一种无色挥发性化合物 A 并逸散至大气中。工业上使用 $\mathrm{Na}_{2} \mathrm{~S}_{3}$ 溶液氧化浸取单质 X 的富集物得到钠盐 P 溶液 (反应 1), P 仅含三种元素, 其中 Na 的质量分数为 $17.04 \%$ 。往 P 溶液中加入过量无机还原性钠盐 Q (分子量小于 $140 \mathrm{~g} / \mathrm{mol}$ ) 溶液, 可得到 X 单质、硫代硫酸钠和另外一种含硫产物 (反应 2)。将单质 X 与一种丰度相近的有色贵金属 N 混合后在常压下微热可生成 B, 有学者因其鹤立鸡群的表观氧化态提出该化合物为合金, 晶体 B 的晶胞参数为: $a = 16.83 \mathrm{~Å}$ , $b = 8.87 \mathrm{~Å}$ , $c = 4.54 \mathrm{~Å}$ , $\alpha = \beta = \gamma = 90^{\circ}$ , 密度 $\rho = 8.86 \mathrm{~g} / \mathrm{cm}^{3}$ , 其正当晶胞沿 c 轴投影图如下 (其中不存在原子遮挡情况):

![](images/00345938e7a2eb86adb70edc561065dea48cd318845236856f46b2463d6c66ac.jpg)

1-1 直接写出 X、N、A、B 的化学式，并写出反应 1、反应 2 的化学方程式。

1-2-1 X 单质对人类毒性较低，但其化合物常有刺激性气味且有毒。若在空气中加热 X 单质，会生成有腐烂气息的烟尘 C。若将 X 与足量 $Cl_{2}$ 反应得到 D。暴露在弥散有微量 X 的环境中一段时间后，人的呼吸会带有大蒜般腐烂的气息，其原因是人体环境内产生了含 X 的有机化合物 E。元素分析表明 E 含碳 15.23%，含氢 3.81%。理论上 D 的单体并不稳定，其能稳定存在要归功于晶体 D 中存在较高对称性的独立的四聚体结构，其中没有二配位的 Cl 原子。据此写出 C\~E 的化学式，并画出 D 的四聚体结构。

1-2-2 若用有机配体取代 D 中的 Cl 则无法形成稳定多聚结构，最终会发生歧化。将对三氟甲基苯基锂（简写为 ArLi）与 D 反应，得到 F、G、LiCl 及少量副产物 H。F 中 X 满足八隅律，而 G 和 H 中 X 均处于最高价态。可能的反应历程为 ArLi 与 D 反应生成无氯一价阴离子 I 与电中性中间体 J 和 K，而 I、J、K 中 X 的价态均与 D 相同，K 中 X 的质量分数为 26.11%。I 与 J 发生亲核取代生成不含氯的 L，随后 L 发生歧化分解得到了 F 与 G，可看作发生了一步芳基迁移。I 与 K 发生类似过程生成中间体 M，M 歧化时迁移 Cl 分解得到 F 与 H，而 H 可与一分子 ArLi 反应生成 G。据此写出 F\~M 的结构简式。
