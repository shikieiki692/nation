# 题-HYS-13-03-2026年是北京大学化学与分

## 题目

### 第 3 题萃取理论与平衡计算（18分，占 $10\%$ ）

2026年是北京大学化学与分子工程学院建院32周年，北大化院院史上所取得的最崇高的科研成就之一是“中国稀土之父”徐光宪先生提出的稀土串级萃取理论。本题将对萃取理论进行粗浅的探讨。

以下问题中，原料水溶液中两稀土离子 X、Y 的浓度比例均为 1:1，且 X 在水和有机溶剂中的分配系数 $k_{\mathrm{X}} = [\mathrm{X}]_{\mathrm{aq}} / [\mathrm{X}]_{\mathrm{solv}} = 4.0$ ，Y 在水和有机溶剂中的分配系数 $k_{\mathrm{Y}} = 0.25$ 。3-1 对于普通的萃取体系，首先先在原料水溶液中加入纯净新鲜的等体积有机溶剂萃取，达平衡后分离有机相，对剩余水相不断重复这一操作，可提高水相中 [X]/[Y] 的比例。3-1-1 设为得到 [X]/[Y] ≥ 99 的水溶液所需要的最少萃取次数为 n，计算 n 的数值。

## 3-1-2 试计算获得上述溶液过程中 X 的损失率。

3-2 可以发现，X 的损失率较高。降低损失率的最直接方法是，对每次萃取剩余的有机相再用水洗萃取富集。现设计如下流程：对于 n 次萃取所剩下的 n 份有机溶液分别编号为 1\~n，向第 1 份中加入等量的水，达平衡后将水相转移至第 2 份有机溶液，达平衡后再将水相转移至下一份有机溶液，直到 n 份有机溶液全部被水洗一次。收集水相，与 3-1 中萃取所得的水溶液合并。计算合并之后的水溶液中 [X]/[Y] 比例，判断是否还满足 [X]/[Y] ≥ 99 的要求。若满足要求，计算 X 收率的增量。

## 参考答案

第 3 题 萃取理论与平衡计算（18 分，占 10%）
设第 n 次萃取后水相中 X 的浓度为  $[X]_{n,aq}$ ，有机相中 X 的浓度为  $[X]_{n,solv}$
由题目条件可知  $[X]_{0,aq} = [Y]_{0,aq} = c_{0}$ ， $[X]_{0,solv} = [Y]_{0,solv} = 0$ （1 分）
有递推公式：
[ [X]_{n-1,aq} = [X]_{n,aq} + [X]_{n,solv}, \quad \frac{[X]_{n,aq}}{[X]_{n,solv}} = k_{X} = 4, \quad [X]_{n,aq} = 0.8 [X]_{n-1,aq} ] （1 分）
[ [Y]_{n-1,aq} = [Y]_{n,aq} + [Y]_{n,solv}, \quad \frac{[Y]_{n,aq}}{[Y]_{n,solv}} = k_{Y} = 0.25, \quad [Y]_{n,aq} = 0.2 [Y]_{n-1,aq} ] （1 分）
[ \frac{[X]_{n,aq}}{[Y]_{n,aq}} = 4 \times \frac{[X]_{n-1,aq}}{[Y]_{n-1,aq}} = 4^{n} \frac{[X]_{0,aq}}{[Y]_{0,aq}} = 4^{n} ] （1 分）
若要求
[ \frac{[X]_{n,aq}}{[Y]_{n,aq}} \geq 99 ] ，则 n = 4（2 分）
（共 6 分）
所得的水溶液中有 $[\mathrm{X}]_{\mathrm{n,aq}} = \left(\frac{k_{\mathrm{X}}}{k_{\mathrm{X}} + 1}\right)^{\mathrm{n}}[\mathrm{X}]_{0,\mathrm{aq}}$ （2分）损失率为 $(1 - 0.8^{4})\times 100\% = 59.0\%$ （1分）（共3分）
