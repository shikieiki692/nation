# 题-HYS-01-01-本题可能用到氨基酸相关的缩写

## 题目

### 第 1 题元素化学（21分，占8%）

本题可能用到氨基酸相关的缩写，以下是一张氨基酸表：

![](images/25a3f62b5e7e911c3895a822346b3196adbaeea89676c506b67a1f0110084799.jpg)

X 是一种昂贵的金属元素。从其铂系元素单质矿制备 X 单质的提纯过程如下：先用硝酸和王水先后提取其中的重金属，接下来用 $NaHSO_{4}$ 共熔并用水提浸，得到 X 的硫酸盐 A。加入氢氧化钠沉淀后再用浓盐酸溶解，得到配合物 B。若用乙酸溶解加碱所得的沉淀，则会生成化合物 C。若将 B 的溶液在蒸气浴上蒸发直到不再有盐酸气味，将得到三水合盐 D。向 B 的溶液中加入亚硝酸钠，再加入氯化铵，沉淀出不含结晶水的配合物 E。E 用盐酸溶解后蒸干，剩余固体用氢气还原，就得到了较纯的 X 单质。

已知 A\~E 中除 C 外，X 的价态均相同，而 C 中 X 的价态相对更低。E 由两种高对称性离子组成，且其中 X 的质量分数为 23.76%。

1-1 给出 A\~E 的化学式，并给出 E 中阴离子所属的点群。

1-2 X 的配合物被用于多肽的修饰。

注意：对于水和氯等较弱的配体，质谱的电离过程通常会使之解离，因此体现不出其带来的分子量增大。

1-2-1 化合物 D 被用于选择性修饰多肽中的酪氨酸。酪氨酸的结构如下左图:

![](images/3510e7f1a7d7b927c58b3543b121fc66be97f04946e15b5116052612db6e2ad7.jpg)

向序列中含有酪氨酸的多肽中加入 D 和如上右图的试剂。从质谱上看，出现了电荷数相同而分子量增高 289 的峰。画出酪氨酸所受到的修饰，已知其中 Rh 满足 EAN 规则。提示：酪氨酸之所以可被专一地修饰，是因为其苯环可以作为配体配位。

1-2-2 以上的修饰在遇到以下试剂之一时会被不可逆地脱去，请选出这一种试剂。可选的试剂有：邻二氮菲、双氧水、谷胱甘肽（其结构如下所示）、二甲亚砜。

![](images/fe477d39276c91275ed04e1db09d192f5d7cf87940a65f45849fa15329f19820.jpg)

1-3 另一种常用于修饰的试剂为 C。向含有序列为 Ile-Gln-Asp-Gln-Tyr-Asn-Asp-His-Lys 的肽段（从 N 端到 C 端，即 Ile 保留- $NH_{2}$ ，Lys 保留- $CO_{2}H$ ）的水溶液中加入 C，得到了从质谱上看分子量增加约 320 的产物，其保留了 C 的基本结构，在此基础上 X 的配位数更高。

1-3-1 画出产物的结构，其中不参与反应的氨基酸可以简写。

1-3-2 提出 1-3-1 中产物一个可能的应用。
