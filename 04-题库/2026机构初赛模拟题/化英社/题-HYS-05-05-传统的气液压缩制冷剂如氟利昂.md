# 题-HYS-05-05-传统的气液压缩制冷剂如氟利昂

## 题目

### 第 5 题 新型制冷机的设计（17 分，占 11%）

传统的气液压缩制冷剂（如氟利昂）具有极高的全球变暖潜能值。本题将描述一种潜在的绿色替代方案，该设想的核心是利用压力调控某种盐 X 的溶解与析出，通过相变的吸放热实现高效热传递。设想中的制冷剂对应的循环过程分为如下 A\~D 四步：

A（绝热加压）：快速加压使溶液过饱和，部分盐结晶。温度由 $T_{0}$ 升至 $T_{h}$

B（等压散热）：保持高压，启动散热器，将系统冷却回初始温度 $T_{0}$ 。

C（绝热减压）：快速减压使晶体溶解。系统温度由 $T_{0}$ 降至 $T_{l}$ 。

D（等压吸热）：保持常压，接触被冷却对象，系统吸热并升温至 $T_{0}$ ，完成循环。

5-1 根据循环内容，说明适合于该过程的化合物 X 需要满足以下何种条件：

(a) 溶解吸热 (b) 溶解放热 (c) 溶解过程总体积增大 (d) 溶解过程总体积减小

5-2 设想一台基于 X 水溶液的压热制冷机，该制冷剂工作时，步骤 A 的理论最大析出量为 0.25 kg，而实际体系只有最大析出量的 90% 发生了结晶。步骤 B 中，恒压降温会使得过饱和溶液中的晶体进一步析出，A、B 两步总共析出 0.30 kg 固体。步骤 C 中溶解非常彻底，没有固体剩余。该制冷剂的工质总质量为 $m_{total} = 1.0 \, kg$ ，泵送流体及压缩过程消耗的总机械功为 $W_{in} = 15.0 \, kJ/每循环$ 。

设 $\mathbf{X}$ 的物性参数如下：溶解焓 $\Delta H_{sol} = 24.0\mathrm{kJ / mol}$ ，分子量为 $100\mathrm{g / mol}$ ，溶液比热容 $C_{p,aq} = 2.80\mathrm{kJ / (kg\cdot K)}$ ，固相比热容 $C_{p,s} = 1.65\mathrm{kJ / (kg\cdot K)}$ 。本题计算时近似认为液体本身不可压缩，溶解焓变和比热容不随温度变化，并忽略管道热损失。

5-2-1 设 $T_{0}=298\ K$ ，计算系统的最高温度 $T_{h}$ 和最低温度 $T_{l}$ 分别是多少。

5-2-2 计算在一个完整循环中：向高温热源（散热器）释放的总热量 $Q_{H}$ 和从低温热源（被冷却物体）吸收的总制冷量 $Q_{C}$ 。

5-2-3 计算该制冷循环的制冷系数 COP（ $COP = \frac{\text{获得的制冷量}Q_{C}}{\text{输入的总功}W_{\text{net}}}$ ）5-3 要想实现如上的设想，关键在于寻找符合 5-1 中要求的材料。
