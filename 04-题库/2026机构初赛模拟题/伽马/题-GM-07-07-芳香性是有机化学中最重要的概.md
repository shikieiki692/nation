# 题-GM-07-07-芳香性是有机化学中最重要的概

### 第 七 题(14 分，14%)芳香性

芳香性是有机化学中最重要的概念之一，根据休克尔规则，具有 $(4n+2)$ 个 $\pi$ 电子的环共轭平面系统是芳香族化合物。

7-1 判断下列化合物否有芳香性

![](images/c1536fd0564f9ae86149667b15af32ecc31edac7cdbb0158c0e4620d94972a3d.jpg)

7-2 今天，芳香性的定义已经获得了更广泛的范围，这个概念也扩展到了无机系统。在 2011 年，人们就通过以下反应获得了 Si 的四元环芳香正离子 $\left[\mathrm{Si}_{6} \mathrm{R}_{4} \mathrm{Cl}_{2}\right]$ (R 为化合物 B 中的二齿配体)。离子 C 结构中 Si 四元环上相对的没有杂原子配体的两个 Si 原子接收化合物 B 的配位。离子 D 为二聚体，请画出离子 C 和离子 D 的结构，并写出此 $\pi$ 体系表示符号。分别指出 Si 的价态。
