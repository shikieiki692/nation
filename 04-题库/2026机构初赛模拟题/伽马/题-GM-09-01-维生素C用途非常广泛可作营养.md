### 第 一 题（19分，占 $9\%$ ）维生素知识速递

1-1-2 作为营养补充剂，其可被制成口服维生素 C 片，常用温水冲服。若直接含化，酸度较高，有时会使舌头有灼烧感。假设将一片维生素 C 片规格为 100 mg 的维生素 C 片静置在舌头上含化，口腔内液体视作纯水，忽略维生素 C 进入液相时带来的体积变化。当维生素 C 片溶解速度骤降并稳定在一个极低值，试计算已形成的维生素 C 溶液 pH。（溶解度：400 g/1000 mL H₂O, pK₁ = 4.17, pK₂ = 11.57）

1-1-3 植物组织中存在维生素 C 氧化酶，能使维生素 C 氧化而失活为二酮古洛糖酸，因此经过干燥、研磨或久存的水果和蔬菜，维生素 C 的含量会大幅度降低。结合该物质的命名，试画出二酮古洛糖酸的结构式。（忽略立体化学）

1-3 维生素 $B_{2}$ 又叫核黄素，是机体中一些重要的氧化还原酶的辅基，它的两个性质是造成其损失的主要原因：（1）可被光破坏；（2）在碱溶液中加热可被破坏。

维生素 $D_{2}$ 是植物来源的高等动物生命必需营养素，无色晶体，溶于脂肪，脂溶剂及有机溶媒中，化学性质稳定。

维生素 E 可以促进机体的脂质代谢，亦可增强细胞的抗氧化能力，光照下遇空气易被氧化而呈现暗红色。

维生素 H 是合成维生素 C 的必要物质之一，微溶于水和乙醇，较易溶于热水和稀碱液，不溶于其他常见的有机溶剂。

维生素 K 有叶绿醌生物活性，具有凝血作用，其中维生素 $K_{1}$ 为天然存在的脂溶性分子，而维生素 $K_{3}$ 为人工合成的水溶性分子。
