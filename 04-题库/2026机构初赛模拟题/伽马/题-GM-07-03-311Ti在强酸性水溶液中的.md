# 题-GM-07-03-311Ti在强酸性水溶液中的

## 题目

### 第 三 题(11 分，6%)Ti 的配位化学

3-1-1 Ti 在强酸性水溶液中的存在形式为 $TiO^{2+}$ ，通常使用比色法测定其含量，向其中加入过量的 $H_{2}O_{2}$ 使所有 Ti 转化为 $Ti_{2}O_{5}^{2+}$ 红色离子，请画出此离子的真实存在形式，所有 Ti 都是 6 配位。

3-1-2 当少量氟存在时，会影响 Ti 的存在形式，可提前加入 $BeCl_{2}$ 可避免前者的干扰，写出离子方程式。

3-2 在四乙氧基钛的四聚体 $\left[\mathrm{Ti}(\mathrm{OEt})_4\right]_4$ 中，有两种化学环境不同的钛原子以及两个成四根键的氧原子。画出该络合物的结构示意图。

3-3 Ti 的碳化物 TiC，由于其极硬，极其抗腐蚀，高熔点等特点，广泛用于制造切割工具和磨料等。已知半径 $r(Ti^{4+}) = 74.5 \, pm$ ， $r(C^{4-}) = 141.5 \, pm$ ，TiC 晶体可能取哪种结构。

3-4 若将 $\mathrm{TiCl}_{4}$ 用 $\mathrm{NaC}_{5}\mathrm{H}_{5}$ 处理后再经过 $\mathrm{NaNp}$ 还原后，可得到一种双核的抗磁性配合物，其中 $\mathrm{Ti}$ 的质量分数为 $26.89\%$ ，且有着氢桥结构，画出该配合物结构，并计算 $\mathrm{Ti}$ 的外层电子数。

3-5 有这样一种钛的多核配合物 $\mathbf{A}[\mathrm{Ti}_{3}(\mathrm{C}_{5}(\mathrm{CH}_{3})_{5})_{3}(\mathrm{NH})_{3}\mathrm{N}]$ 。A 能与三氯化钪反应，得到具有立方体结构的配合物 $\mathbf{B}[\mathrm{ScTi}_{3}(\mathrm{C}_{5}(\mathrm{CH}_{3})_{5})_{3}(\mathrm{NH})_{3}\mathrm{N}]$ 。若 A 与 Sc[N(SiMe $_3$ ) $_2$ ]\_3 在甲苯中反应，则得到 C[ScTi $_6$ (C $_5$ (CH $_3$ ) $_5$ ) $_6$ (NH) $_3$ N $_5]$ 。B 和 C 中钪的配位数均为 6。

3-5-1 请画出 A, B, C 的结构。

3-5-2 写出制备 C 的化学反应方程式。
