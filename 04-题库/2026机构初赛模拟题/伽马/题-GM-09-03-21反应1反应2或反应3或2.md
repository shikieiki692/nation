# 题-GM-09-03-21反应1反应2或反应3或2

## 题目

### 第 3 题，请大家在本题中注意练习有效数字的相关知识。

2-1
反应 1:  $Ag^{+} + Cl^{-} = AgCl$
反应 2:  $2Cu^{2+} + 4I^{-} = 2CuI + I_{2}$
或:  $2Cu^{2+} + 5I^{-} = 2CuI + I_{3}^{-}$
反应 3:  $I_{2} + 2S_{2}O_{3}^{2-} = 2I^{-} + S_{4}O_{6}^{2-}$
或:  $I_{3}^{-} + 2S_{2}O_{3}^{2-} = 3I^{-} + S_{4}O_{6}^{2-}$

2-2
根据上述反应的计量关系，有：
 $n(\mathrm{Cl}^{-}) = n(\mathrm{Ag}^{+}) = 0.1036 \times 19.52 \times 250.0 / 25.00 = 20.22 (\mathrm{mmol})$ $n(\mathrm{Cu}^{2+}) = n(\mathrm{S}_{2}\mathrm{O}_{3}^{2-}) = 0.0286 \times 17.65 \times 250.0 / 25.00 = 5.055 (\mathrm{mmol})$ $n(\mathrm{Cl}^{-}) / n(\mathrm{Cu}^{2+}) = x + 2 = 20.22 / 5.055 = 4.000 = 4 - x = 2$
1.4026 g 晶体 A 中，水的含量：
 $m(\mathrm{H}_{2}\mathrm{O}) = 1.4026 \, \mathrm{g} - 5.055 \times 10^{-3} \, mol \times 2 \times 53.49 \, g \, mol^{-1} - 5.055 \times 10^{-3} \, mol \times 134.5 \, g \, mol^{-1} = 0.1816 \, g$ $n(\mathrm{H}_{2}\mathrm{O}) = 0.1816 \, \mathrm{g} / (18.01 \, \mathrm{g} \, \mathrm{mol}^{-1}) = 0.01008 \, \mathrm{mol}$ $y = 0.01008 \, mol / (5.055 \times 10^{-3} \, mol) = 1.990 = 2$
