4.1 分别计算给出混合液中 $Pr^{3+}$ 与 $Nd^{3+}$ 的浓度。

解答：（本问共6分）

由朗伯-比尔定律， $A=\varepsilon dc$ ，得两种配合物在各波长下的摩尔消光系数

波长 1: $\varepsilon(\mathrm{PrL},1)=74.8\ \mathrm{L}/(\mathrm{mol}\ \mathrm{cm})$ ， $\varepsilon(\mathrm{NdL},1)=28.6\ \mathrm{L}/(\mathrm{mol}\ \mathrm{cm})$ 波长 2: $\varepsilon(\mathrm{PrL},2)=34.8\ \mathrm{L}/(\mathrm{mol}\ \mathrm{cm})$ ， $\varepsilon(\mathrm{NdL},2)=40.4\ \mathrm{L}/(\mathrm{mol}\ \mathrm{cm})$

2 分，算对一个波长下的即可

由 PrL 与 NdL 的浓度可列方程组:

$$
\begin{array}{l} \varepsilon (\mathrm{PrL}, 1) [ \mathrm{PrL} ] + \varepsilon (\mathrm{NdL}, 1) [ \mathrm{NdL} ] = \mathrm{A} _ {1} \\ \varepsilon (\mathrm{PrL}, 2) [ \mathrm{PrL} ] + \varepsilon (\mathrm{NdL}, 2) [ \mathrm{NdL} ] = \mathrm{A} _ {2} \end{array}
$$

代入数据得

$$
\begin{array}{l} 74.8 [ \mathrm{PrL} ] + 28.6 [ \mathrm{NdL} ] = 0.819 \\ 34.8 [ \mathrm{PrL} ] + 40.4 [ \mathrm{NdL} ] = 0.414 \end{array}
$$

解得 $[PrL]=9.22\ mmol/L$ ， $[NdL]=3.72\ mmol/L$ 答案4分，每个2分

4.2 分离 Pr 和 Nd 常用萃取的方法，当萃取体系达到平衡时，被萃取物在有机相的总浓度与水相中总浓度之比称为分配比 D，定义二组分 A、B 的分离系数 $\beta_{A/B}=D_{A}/D_{B}$ 。

4.2.1 设形成的配合物进入有机相的量可忽略，试计算加入过量的 L 配合后，可以将分离系数 $\beta_{Pr/Nd}$ 提高到原来的多少倍。

解答：（本问共6分）
未配合时： $D_{\mathrm{Pr},0} = [\mathrm{Pr}]_{\mathrm{o}} / [\mathrm{Pr}]_{\mathrm{w}}$ ， $D_{\mathrm{Nd},0} = [\mathrm{Nd}]_{\mathrm{o}} / [\mathrm{Nd}]_{\mathrm{w}}$ 从而， $\beta_{\mathrm{Pr/Nd},0} = [\mathrm{Pr}]_{\mathrm{o}}[\mathrm{Nd}]_{\mathrm{w}} / ([\mathrm{Nd}]_{\mathrm{o}}[\mathrm{Pr}]_{\mathrm{w})}$ （1） 1分
加入配体后，
由稳定常数： $K_{\mathrm{Pr}} = [\mathrm{PrL}] / [\mathrm{Pr}][\mathrm{L}]$ ， $K_{\mathrm{Nd}} = [\mathrm{NdL}] / [\mathrm{Nd}][\mathrm{L}]$ $D_{\mathrm{Pr},1} = [\mathrm{Pr}]_{\mathrm{o}} / (\mathrm{[Pr]_{w} + [PrL]_{w}})$ ， $D_{\mathrm{Nd},1} = [\mathrm{Nd}]_{\mathrm{o}} / (\mathrm{[Nd]_{w} + [NdL]_{w}})$ 从而， $\beta_{\mathrm{Pr/Nd}} = [\mathrm{Pr}]_{\mathrm{o}}([\mathrm{Nd}]_{\mathrm{w} + [\mathrm{NdL}]_{\mathrm{w}}}) / [[\mathrm{Nd}]_{\mathrm{o}}([\mathrm{Pr}]_{\mathrm{w} + [\mathrm{PrL}]_{\mathrm{w}}})]$ （2） 1分
（1）与（2）两式相除 $\beta_{\mathrm{Pr/Nd}}/\beta_{\mathrm{Pr/Nd},0} = [\mathrm{Pr}]_{\mathrm{w}}([\mathrm{Nd}]_{\mathrm{w} + [\mathrm{NdL}]_{\mathrm{w}}}) / [[\mathrm{Nd}]_{\mathrm{w}}([\mathrm{Pr}]_{\mathrm{w} + [\mathrm{PrL}]_{\mathrm{w}}})]$ $= (1+K_{\mathrm{Nd}})/(1+K_{\mathrm{Pr}})$ 2分
代入数据得， $\beta_{\mathrm{Pr/Nd}}/\beta_{\mathrm{Pr/Nd},0}\approx K_{\mathrm{Nd}}/K_{\mathrm{Pr}}=3.39$ 答案2分
得即提高到原来的3.39倍

4.2.2 实际上形成的配合物进入有机相的量不可忽略，在上一问的基础上，讨论分离系数 $\beta_{\mathrm{Pr / Nd}}$ 提高倍数 $F$ 与配体浓度[L]的关系。随着[L]的增大， $F$ （）。a）是单调变化的 b）会先减后增 c）会先增后减 d）存在最大值 e）以上均无法判断

解答：（本问共3分）
e）以上均无法判断
由题意得， $D_{\mathrm{Pr},1} = ([\mathrm{Pr}]_{\mathrm{o}} + D_{\mathrm{PrL}}K_{\mathrm{Pr}}[\mathrm{Pr}]_{\mathrm{w}}[\mathrm{L}]) / ([\mathrm{Pr}]_{\mathrm{w}} + [\mathrm{PrL}]_{\mathrm{w}})$ $=(D_{\mathrm{Pr},0}+D_{\mathrm{PrL}}K_{\mathrm{Pr}}[\mathrm{L}])/(1+K_{\mathrm{Pr}}[\mathrm{L}])$ 同样有 $D_{\mathrm{Nd},1}=(D_{\mathrm{Nd},0}+D_{\mathrm{NdL}}K_{\mathrm{Nd}}[\mathrm{L}])/(1+K_{\mathrm{Nd}}[\mathrm{L}])$ 因此，提高倍数 $F=[D_{\mathrm{Nd},0}(D_{\mathrm{Pr},0}+D_{\mathrm{PrL}}K_{\mathrm{Pr}}[\mathrm{L}])(1+K_{\mathrm{Nd}}[\mathrm{L}])]/[D_{\mathrm{Pr},0}(D_{\mathrm{Nd},0}+D_{\mathrm{NdL}}K_{\mathrm{Nd}}[\mathrm{L}])(1+K_{\mathrm{Pr}}[\mathrm{L}])]$ 忽略常数项，F 为含[L]的两个二次多项式之比。每个趋势都有可能，故无法判断。
