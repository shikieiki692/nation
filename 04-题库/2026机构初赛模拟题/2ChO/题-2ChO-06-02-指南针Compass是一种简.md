# 题-2ChO-06-02-指南针Compass是一种简

## 题目

### 第 2 题 分子指南针 (35 分, 13%)

指南针(Compass)是一种简单而强大的装置，其最重要的部件是一个可自由旋转的磁化指针，以此感知地球磁场。在分子水平上，可以通过利用基团间非共价作用力、动力学行为来模拟这种宏观指南针的机械功能。

一种分子指南针利用了柱[5]醌(P5Q)的氧化还原行为，在其中引入具有极性基团的客体分子，这些极性基团的偶极矩可作为“指针”，在氧化还原过程中响应电场变化、重新定向，从而调控远端醌单元之间的电子通信。

![](images/08c48a403d22ff914e3773f14a67cc3be696074ec22f96bc71f516bcca236c47.jpg)

2.1 柱[5]醌电化学行为与分子指南针合成。对苯醌单体Q在非质子溶液中可经历两步单电子还原。将5个醌单元由亚甲基相连成环后，即构成柱[5]醌(P5Q)，它具有更加复杂的电化学行为。

2.1.1 分别画出对苯醌单体 Q 两步单电子还原的产物 Q $^{-}$ 与 Q $^{2-}$ 的最稳定共振式。

2.1.2 柱[5]醌中醌单元的氧化还原顺序受到空间电荷分布调控。已知 P5Q 的还原模式为 “2-1-2”（参考下图），且每个醌单元均只发生单电子还原。试仿照下图，画出 P5Q-2 与 P5Q-3 的结构，其中白色圆圈表示醌单体，黑色圆圈表示单电子还原后的醌单体。

![](images/e1d30e445af1257ff7525913c13533d36ec1139cc9ac29a7cb792e9e839b7315.jpg)

2.1.3 一种含有酰胺 “指针” 的分子指南针 Q-Rot-A 的合成路线如下，该分子指南针可视作超分子，其中酰胺 “指针” 为客体分子（注意产物中的化学键的透视关系）。分别画出中间产物 A、B 的结构。

![](images/5448db4f28ce26508a1d0883092a75e74957e409999cdcc6f88b5c7a998e1c7d.jpg)

2.2 结构表征与手性分析。由于 2,5-取代基的不对称性，理论上 P5Q 型结构存在多个阻转异构体。其中每个单元的平面手性(Planar Chirality)规定如图。

![](images/b2bc26e7c6d8281fdc9952774f779dce53afd8692ebbe349959ad18f9b58e706.jpg)

2.2.1 直接写出 P5Q 型结构理论上存在多少个阻转异构体。

2.2.2 测试 ${}^{1}$ H-NMR 表明，A 与 Q-Rot-A 的 P5Q 骨架中，5 组亚甲基氢原子均表现为单峰，说明二者的平面环表观上均为全同，即 $(R_{\mathrm{p}}, R_{\mathrm{p}}, R_{\mathrm{p}}, R_{\mathrm{p}}, R_{\mathrm{p}})$ 或 $(S_{\mathrm{p}}, S_{\mathrm{p}}, S_{\mathrm{p}}, S_{\mathrm{p}}, S_{\mathrm{p}})$ 。但二者表观全同构型的原因却不同，试结合平面环旋转能垒差异，分别解释二者表观全同构型的原因。提示：NMR 测定存在一定的时间尺度。

2.2.3 对于 B，其 ${}^{1}$ H-NMR 数据表明，亚甲基氢原子发生了位移与裂分，其部分谱图及氢原子对应关系如下所示（括号下方数字表示峰积分面积，最下方刻度数字表示位移）。下列构型中，符合谱图积分面积信息的是：（）。

2.3.1 已知平台电流 i 可以用 Cottrell 方程描述:

$$
i = n F A C \sqrt {\frac {D}{\pi t}}
$$

其中 n 为累计转移的电子数，A 为电极表面积，C 为物质浓度，D 为物质的扩散系数。控制电极表面积、浓度和时间均保持一致，测得相同条件下对苯醌 Q 完全还原对应的平台电流 $i_{Q} = 132.6 \mu A$ ，Q 的扩散系数为 $2.42 \times 10^{-5} cm^{2} s^{-1}$ ，Q-Rot-A 扩散系数为 $1.17 \times 10^{-5} cm^{2} s^{-1}$ 。通过计算，判断 Q-Rot-A 的电化学还原模式（如 P5Q 的还原模式为 “2-1-2”）。

2.3.2 已知体系中 Q-Rot-A 各氧化态的总浓度 $C=1.02 \times 10^{-2} \, mol \, L^{-1}$ 。当外加扫描电位 E 为 -0.50 V 时，体系达到平衡，试计算此时室温下 Q-Rot-A 单电子还原产物 Q-Rot-A 的浓度。（可将表中电极电势视为标准电极电势）

2.3.3 研究表明，Q-Rot-A 与 P5Q 的电化学行为差异与客体分子（“指针”）的结构密切相关。参考下图模型，指出客体分子中“正极( $\delta+$ )”“负极( $\delta-$ )”分别对应什么基团。

2.3.4 事实上，“指针”与 P5Q 之间的非共价相互作用实现了“电子通信”的效果。已知 Q-Rot-A 第一个还原电位(-0.16 V)显著高于 P5Q 的第一个还原电位(-0.39 V)，试解释原因。

2.3.5 已知 Q-Rot-A 中，2 个 “指针” 的取向大致如下图所示。请预测相比于没有指针的 P5Q $^{-}$ ，Q-Rot-A $^{-}$ 中 Q2 号苯醌基团的还原电势将会升高还是降低，并简述理由。
