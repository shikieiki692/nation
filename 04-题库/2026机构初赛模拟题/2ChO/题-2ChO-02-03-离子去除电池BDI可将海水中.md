# 题-2ChO-02-03-离子去除电池BDI可将海水中

## 题目

### 第 3 题 双离子去除电池(20 分)

离子去除电池（BDI）可将海水中的阳离子和阴离子嵌入类似于锂离子电池的晶相中，并转化储存在阴极和阳极内，实现高效的海水淡化，表现出高离子去除能力和高充电效率。研究表明，以 $NaBi_{3}O_{4}Cl_{2}$ 为电极可以同时去除海水中的 $Na^{+}$ 和 $Cl^{-}$ 。

![](images/120db186668aadd87c5a1eb68954b68e29c2497080510901c7be634b291eaade.jpg)

3-1 如图为 $NaBi_{3}O_{4}Cl_{2}$ 电极首次放电、充放电循环示意图（其中物质 X 未知）。写出 $NaBi_{3}O_{4}Cl_{2}$ 电极在海水中首次放电的电极反应方程式。

3-2 电极理论容量是衡量电池性能的重要性能指标之一。已知电极理论容量=总放电电量/原电极材料质量。

3-2-1 计算 $NaBi_{3}O_{4}Cl_{2}$ 电极的电极理论容量（以 $mAh\cdot g^{-1}$ 为单位）。

3-2-2 已知物质 X 还原为 Bi 时的电极理论容量约为 $309 \, mAh \cdot g^{-1}$ ，试推断 X 的化学式。

3-2-3 写出充电时 $NaBi_{3}O_{4}Cl_{2}$ 电极上发生的电极反应方程式。

3-3 为了建构完整的电池，选用 $\mathrm{NaTi_{2}(PO_{4})_{3}@C}$ 作为另一侧电极。

3-3-1 写出海水淡化过程中， $\mathrm{NaTi}_{2}(\mathrm{PO}_{4})_{3}@\mathrm{C}$ 电极作为阴极还是阳极。

3-3-2 写出海水淡化过程中， $\mathrm{NaTi_{2}(PO_{4})_{3}@C}$ 电极上发生的电极反应方程式。

## 参考答案


![](images/7bbca9256e92b976168dcf93b75c872441726606b768a5d7789673cfcbe45a93.jpg)

3-1 如图为 $\mathrm{NaBi}_3\mathrm{O}_4\mathrm{Cl}_2$ 电极首次放电、充放电循环示意图（其中物质X未知）。写出 $\mathrm{NaBi}_3\mathrm{O}_4\mathrm{Cl}_2$ 电极在海水中首次放电的电极反应方程式。




3-3 为了建构完整的电池，选用 $\mathrm{NaTi}_{2}(\mathrm{PO}_{4})_{3}@\mathrm{C}$ 作为另一侧电极。







**3-1** $NaBi_{3}O_{4}Cl_{2} + 4H_{2}O + 9e^{-} = Na^{+} + 3Bi + 2Cl^{-} + 8OH^{-}$ (2分) $NaBi_{3}O_{4}Cl_{2} + 4x \cdot H_{2}O + 9x \cdot e^{-} = (1-x) \cdot NaBi_{3}O_{4}Cl_{2} + x \cdot Na^{+} + 3x \cdot Bi + 2x \cdot Cl^{-} + 8x \cdot OH^{-}$ (2分) $NaBi_{3}O_{4}Cl_{2} + 8H^{+} + 9e^{-} = Na^{+} + 3Bi + 2Cl^{-} + 4H_{2}O$ (1分)

**3-2-1共4分** 对于1mol  $NaBi_{3}O_{4}Cl_{2}$ 电极:放电电量 $Q = n \times N_{A} \times e = n \times F = 9 \times 96485$  C =  $8.684 \times 10^{5}$  C =  $2.412 \times 10^{5}$  mAh(2分)算出 $8.684 \times 10^{5}$  C或 $2.412 \times 10^{5}$  mAh任意一个结果即可给分。电极质量 $M = (22.99 + 3 \times 209 + 4 \times 16 + 2 \times 35.45)g = 784.9$  g(1分)电极理论容量 $C_{理论} = Q / M = 2.412 \times 10^{5}$  mAh ÷  $784.9$  g =  $307$  mAh·g−1(1分,不要求有效数字)

**3-2-2共6分** 假设X中含有1个Bi: $C_{理论} = (3 \times 96485 \div 3600 \times 1000) \div M = 309$  mAh·g−1(2分)解得 $M = 260$  g·mol−1(2分)恰好对应一个Bi、一个Cl、一个O。因此物质X的化学式为BiOCl(2分)若最终推出化学式为 $Bi(OH)_{3}$ ,则不得最终答案分,中间步骤仍可正常给分。

**3-2-3共4分** $Na^{+} + 3Bi + 2Cl^{-} + 4H_{2}O - 9e^{-} = NaBi_{3}O_{4}Cl_{2} + 8H^{+}$ (2分) $Na^{+} + 3Bi + 2Cl^{-} + 8OH^{-} - 9e^{-} = NaBi_{3}O_{4}Cl_{2} + 4H_{2}O$ (1分) $Bi + Cl^{-} + H_{2}O - 3e^{-} = BiOCl + 2H^{+}$ (2分) $Bi + Cl^{-} + 2OH^{-} - 3e^{-} = BiOCl + H_{2}O$ (1分)若3-2-2中BiOCl推断错误,则该方程式不得分。若将上面两个方程式合并写,则得到: $3xBi + yNa^{+} + (3x-y)Cl^{-} + (3x+y)H_{2}O - 9xe^{-} = yNaBi_{3}O_{4}Cl_{2} + (3x - 3y)BiOCl + (6x + 2y)H^{+}$ (4分)若选手选择合并写,但自己代入了x、y的特值,只得2分。

**3-3-1** 阴极(2分)

**3-3-2** $NaTi_{2}(PO_{4})_{3}@C + 2Na^{+} + 2e^{-} = Na_{3}Ti_{2}(PO_{4})_{3}@C$ (2分) $NaTi_{2}(PO_{4})_{3}@C + xNa^{+} + xe^{-} = Na_{(1+x)}Ti_{2}(PO_{4})_{3}@C$ (2分)@C不要求写出。
