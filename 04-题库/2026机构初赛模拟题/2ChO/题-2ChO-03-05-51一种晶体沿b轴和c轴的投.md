## 参考答案

5-1 一种晶体沿 b 轴和 c 轴的投影图分别如下图所示，其中大黑球为 A，白球为 B，小黑球为 O。

![](images/9d2b3eb68f5cbe979f73633cf6c155cd648c50f0ed0bbc91f34d57bfea433c48.jpg)

5-1-1 写出 A 和 B 的配位多面体名称。

A: 三角十二面体（只写“十二面体”亦可）

B: 四面体（写“变形四面体”亦可，写“正四面体”不扣分，下同）

对于此类根据复杂投影图判断配位多面体形状的问题，要想直接看清楚中心原子周围的配位环境是比较困难的。此时不妨想象出或者画出四面体、八面体、十二面体等结构的投影图，代入题目的投影图中，看看是否符合即可。注意在立体结构中同一种键的键长应当是相似的，所以投影中如果某根键比较短的话，意味着其连接的原子不在同一投影平面上，这在很多情况下会帮助到我们对晶体三维结构的想象。

先来看比较简单的 B，也就是白球，在投影图中，每个白球连接了两根长键和一根短键，可以想象出两根长键应当是在同一投影平面内的，短键则是指向纸面外的，这与我们熟悉的四面体的投影是比较像的，那么将四面体的投影代入，就可以想到剩下的一根键应当被指向纸面外的短键遮挡了。也就是说，认为 B 周围的 O 原子排成四面体是合理的。

而对于 A 原子，其周围的情况比较复杂。四面体、八面体的配位数肯定不够，而加帽棱柱、四方反棱柱等投影比较简单的结构也对不上，于是可以尝试三角十二面体。如下左图所示，我们可以将三角十二面体的八个顶点按照高度从上到下分成四组。其中第一组和第三组的延伸方向垂直纸面，第二组和第四组则是平行纸面；第一组和第四组的组内两顶点比较接近，而第二组和第三组各自组内的两个顶点距离较远。

![](images/f6ecf0866f3bf5593625f4e9cb43911be6e4ad54d64ca6f80d14ff4cd7f7cee4.jpg)

据此我们就可以想象出它的一种投影图，如上右图所示，这和题目两种投影中的情况都是相似的。5-1-2 根据上一问得到的配位数，写出晶体的化学式。

$\mathrm{ABO}_{4}$

上一问已经得到了 A 和 B 配位多面体的情况，那么为了得到完整的化学式，还需要 O 周围的配位情况。沿 c 轴投影中位于中部的两个 O 原子是比较清晰的。根据上一小问的分析，这个 O 所连的 A-O 键是较长的 A-O 键，所连的 B-O 键也是较长的 B-O 键。也就是说，这三根键都在投影平面内，不存在前后延伸重叠的情况。再去观察其它 O 原子，也都符合这种情况，所以 O 的配位数应当为 3。结合我们对晶体的想象，A 和 B 的数量应当相同，也就是平均配位数为 6，所以 A 和 B 的总数应为 O 的一半，也就是化学式为 $ABO_{4}$ 。

或者，如果我们能注意到每个O原子都连接且仅连接一个B，就可以直接得到B和O的个数比就是1:4，也就是说我们可以把这个晶体看作是等量的A与 $[\mathrm{BO}_4]$ 共同排列得到的。

5-1-3 写出晶体的点阵形式。

底心正交

首先可以直接判断出，在 b 和 c 方向上应不存在四重轴。对于 a 方向，需要更多的想象来判断不存在四重轴。不妨直接在发现 c 方向不存在四重轴之后就排除其为四方晶体的可能，因为四方晶体的四重轴按照规范应处于 c 方向。

对于正交晶体，则有体心、面心、底心、简单四种可能。从 c 轴投影中，任选一个原子，沿对角线方向平移 1/2 单位发现并无对应原子，所以可排除体心和面心的情况；再看 b 轴，选择一个原子沿对角线平移 1/2 单位，发现有周围键连方向一致对应原子，并且根据上一问的长短键方法可以判断出处于同一平面，因此可知该晶体在此平面内存在底心。

事实上，这是一种 $\mathrm{CaSO_4}$ 晶体，如果对于上述描述仍感到费解，可自行结合三维晶胞图进行理解。

![](images/577d635e79826b4794221b32ad530025f53d36f60f51b5a72722c9ca938ae0a7.jpg)

5-2 现有一种由 X 和 O 两种元素组成的理想六方晶体。晶胞中三个 X 原子的坐标分别为 $(1/2, 1/2, 0)$ 、 $(0, 1/2, 1/3)$ 、 $(1/2, 0, 2/3)$ 。晶胞中可看作含有沿 c 方向延伸的 X-O-X-O 螺旋长链。例如，面对 c 轴观察，以 a = 1/3，b = 2/3 的直线为轴，将 $(1/2, 1/2, 0)$ 处的 X 原子顺时针旋转 $120^{\circ}$ ，再上升 1/3 的 c 轴长度，位置即变为 $(0, 1/2, 1/3)$ ；将 $(0, 1/2, 1/3)$ 处的 X 原子顺时针旋转 $120^{\circ}$ ，再上升 1/3 的 c 轴长度，位置即变为 $(1/2, 1, 2/3)$ ；将 $(1/2, 1, 2/3)$ 处的 X 原子顺时针旋转 $120^{\circ}$ ，再上升 1/3 的 c 轴长度，位置即变为 $(1/2, 1/2, 1)$ ，即回到 $(1/2, 1/2, 0)$ 。如下图所示（图中的数字表示 X 原子的 c 轴坐标）：

![](images/7e25f4e85f01789b25856763efcccc6ae478fed782acd0cd6b7c38f8182ad6c7.jpg)

5-2-1 我们将上面的这种螺旋方向称为左旋；相应地，如果沿 c 轴方向上升的过程中旋转方向为逆时针则称为右旋。晶胞中还有一个螺旋长链，螺旋轴所在位置为 a=2/3，b=1/3。指出此长链的螺旋方向为左旋还是右旋。

左旋

根据晶胞的平移对称性，1/3 高度上的原子对面，也就是右侧面上的原子高度也应为 1/3，同理下侧面上的原子高度为 2/3。我们顺次连接 $0 \rightarrow 1/3 \rightarrow 2/3 \rightarrow 0$ ，发现旋转方向实际上和题图中的方向是一致的，因此也为左旋。

5-2-2 不难发现这些螺旋长链通过共用X原子拼接在一起，形成了三维的晶体结构。将X有规律地改为C原子和D原子，就可近似看作 $\mathrm{CDO}_x$ 的晶体。指出 $x$ 的值，以及一个 $\mathrm{CDO}_x$ 晶胞中化学式的个数。

x 的值为 4

晶胞中化学式的个数为3

上一问中我们画出的每一个圈（或者简化为正三角形）即为一条化学式为[XO]螺旋长链。不难发现，每个X原子都会被两条链共用，而O不会，因此整体化学式为 $\mathrm{XO}_2$ ，当X换为相同数量的C与D后，则应为 $\mathrm{CDO}_4$ 。

原来每个晶胞中有3个X，也就是有3个 $\mathrm{XO}_2$ 化学式。现在原晶胞则只剩下1.5个 $\mathrm{CDO}_4$ 化学式，但是晶胞中显然不会有半个原子，所以 $\mathrm{CDO_x}$ 的晶胞c方向长度应变成原来的两倍，也就是螺旋长链的排布改为-C(0)-D(1/6)-C(1/3)-D(1/2)-C(2/3)-D(5/6)-C(0)-，那么化学式个数仍然为3。

5-3 由 C、D、O 三种元素组成的另一种晶体属于体心立方点阵，化学式仍为 CDOx，晶胞参数为：a = b = 433 pm, c = 664 pm。C 原子占据顶点和体心，一个 D 原子的分数坐标为 (0.50, 0, 0.75)。

5-3-1 写出晶胞中另一个 D 原子的分数坐标。

(0, 0.50, 0.25)

这并不难，因为此晶体属于体心四方点阵（题目中不慎写成立方了，不过从紧跟着给出了四方的坐标，希望没有影响各位的答案的同时，为对各位做题过程中造成的困扰致歉），所以一个D原子的三个坐标值同加0.50后对1求余即可得到另一个等价D原子的坐标。

5-3-2 只考虑 C 和 D 原子，指出 C 周围的 D 排列成何种多面体，D 周围的 C 又排列成何种多面体。

写“均为四面体”也可得2分

这个晶体并不复杂，至此最简单的方法应当是画出C和D在晶胞中的位置：

![](images/0d73608e3ea992ddf4e4c2ce15a4c6f19e28f4f8cdaec6b2c5a4f3eced5b2366.jpg)

不难看出，两者周围的原子均排成四面体。

5-3-3 晶胞中一个 O 原子的分数坐标为(0.138, 0.260, 0.131)，请分别计算其与最近的 C 原子 $d_{O-C}$ 和 D 原子之间的距离 $d_{O-D}$ 。

$$
d _ {0 - \mathrm{c}} = \sqrt {[ (0.138 - 0) \times 433 ] ^ {2} + [ (0.260 - 0) \times 433 ] ^ {2} + [ (0.131 - 0) \times 644 ] ^ {2}} \mathrm{pm} = 154 \mathrm{pm}
$$

$$
d _ {0 - D} = \sqrt {[ (0.138 - 0) \times 433 ] ^ {2} + [ (0.260 - 0.50) \times 433 ] ^ {2} + [ (0.131 - 0.25) \times 644 ] ^ {2}} p m = 144 p m
$$

从刚才画出的晶胞图中可以大致看出这个O原子的位置，不难发现最近的C原子就在(0,0,0)处，而最近的D原子就在(0,0.50,0.25)处。利用空间勾股定理列式计算即可分别得到两个距离。
5-3-4现已知C和D一个属于第二周期，一个属于第三周期。指出何者是第二周期的元素。

D

从上一问算得的距离即可看出，O-D 距离比 O-C 更短，因此 D 原子的半径更小，应为第二周期元素。事实上，5-2 和 5-3 中的晶体是两种 $\mathrm{BPO_4}$ 晶体：
