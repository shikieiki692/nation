# 题-YJ-01-01-在标准液的标定实验的操作过程

## 题目

### 第 1 题 (16 分, 10%) $Na_{2}S_{2}O_{3}$ 标准液标定实验的失败与探究

在“ $Na_{2}S_{2}O_{3}$ 标准液的标定”实验的操作过程中，某学生因使用了未经稀释的 $Na_{2}S_{2}O_{3}$ 溶液意外在滴定环节产生大量淡黄色沉淀；学生们经过自主探究，重现了实验现象。

本次实验中，首先准确称取 $0.12 \, g \, K_{2}Cr_{2}O_{7}$ 制成溶液；加入 $8 \, mL \, 6 \, mol/L$ 的 HCl 溶液和 $1.00 \, g \, KI$ ，并稀释至 $100 \, mL$ ；使用 $Na_{2}S_{2}O_{3}$ 溶液进行碘量法测定，临近终点时加入 $2 \, mL$ 淀粉溶液指示剂，并滴定至终点；借此标定 $Na_{2}S_{2}O_{3}$ 溶液的浓度。

原实验设计中，计划用 0.1 mol/L 的 $Na_{2}S_{2}O_{3}$ 溶液进行标定；由于经验不足，小组成员没有注意到实验室提供的 $Na_{2}S_{2}O_{3}$ 溶液为 1.0 mol/L，未进行稀释，并使用此浓度溶液进行滴定操作。开始滴加时，反应溶液显示正常的棕黄色；滴加至 2 mL 左右，溶液棕黄色消失；继续滴加，溶液中产生浑浊，颜色变为乳白色至淡黄色；滴加至 25 mL 时，滴定中止，在清洗实验器皿时发现此体系在杯底形成了淡黄色细沙状的沉淀。

1-1 按原实验设计，写出测定原理的化学方程式（2个）。假设最终滴定消耗 $Na_{2}S_{2}O_{3}$ 溶液的体积为 V mL，计算其浓度的标定值。

1-2 通过理论分析，写出实验失败产生淡黄色沉淀和酸性气体的反应方程式。

1-3 标定好的 $Na_{2}S_{2}O_{3}$ 溶液可用于测定水体溶解氧（DO），DO 是评价水质的重要指标，通常采用 Winkler 法进行测定。其分析流程如下：向水样中加入硫酸锰溶液和碱性 KI 溶液（含 NaOH），反应生成 $\mathrm{MnO(OH)_{2}}$ 沉淀，实现氧的固定；加入硫酸使溶液酸化，沉淀溶解并与 KI 反应定量生成碘；用 $Na_{2}S_{2}O_{3}$ 标准溶液滴定生成的碘，以淀粉为指示剂，滴定至蓝色恰好消失为终点。现取某水样 100.00 mL，按上述流程操作，滴定消耗 0.01000 mol/L $Na_{2}S_{2}O_{3}$ 标准溶液标准液 8.50 mL。

1-3-1 写出沉淀生成和定量生成碘的反应方程式。

1-3-2 计算该水样中溶解氧的浓度（单位：mg/L）。

1-4 实际上，小组成员进行文献调研验证，发现体系内 $Na_{2}S_{2}O_{3}$ 分解的物质基本留在溶液内，主要是各种 S 单质和多硫酸钠：S 单质占总硫的 17%，包括 $S_{n} (n = 6-17)$ 等；其中， $S_{8}$ 为主要产物，占 S 单质高达 90%；多硫酸钠占总硫的 83%，链长度由 4-40 个硫原子不等。多硫酸钠长链形成胶束，将单质 S 包裹在其内，形成胶粒；此结构可用“硫球”模型表示。

利用 Von Weimarn 提出定性判断沉淀结晶颗粒大小的经验公式：分散度= $K\cdot(C_{Q}-s)/s$ 式中， $C_{Q}$ 为加入沉淀剂瞬间沉淀物质的浓度，s 为开始沉淀时沉淀物质的溶解度；K 为正常数，取 K=1。假设每个胶粒所包含的硫单质全部为 $S_{8}$ ，且每个胶粒只包含一个 $S_{8}$ 分子。 $S_{8}$ 分子的溶解度为 $1.9\times10^{-8}$ mol/kg，溶液的密度近似为纯水的密度。若失败的实验中过量的 $Na_{2}S_{2}O_{3}$ 均分解，估算体系中 $S_{8}$ 分子的分散度。

## 参考答案

1-1 $\mathrm{Cr_2O_7^{2 - } + 14H^+ + 6I^- \rightarrow 2Cr^{3 + } + 3I_2 + 7H_2O}$ （1分） $\mathrm{I}_2 + 2\mathrm{S}_2\mathrm{O}_3^{2 - }\rightarrow 2\mathrm{I}^{-} + \mathrm{S}_4\mathrm{O}_6^{2 - }$ （1分）由 $\mathrm{K}_2\mathrm{Cr}_2\mathrm{O}_7\sim 3\mathrm{I}_2\sim 6\mathrm{Na}_2\mathrm{S}_2\mathrm{O}_3$ ，有 $c = (6\times 0.12 / 294.18) / (V / 1000) = 2.45 / V$ (mol/L）（2分）
1-2 $\mathrm{S}_2\mathrm{O}_3^{2 - } + 2\mathrm{H}^+ \rightarrow \mathrm{S} + \mathrm{SO}_2 + \mathrm{H}_2\mathrm{O}$ （2分）
1-3-1 $2\mathrm{Mn}^{2 + } + \mathrm{O}_2 + 4\mathrm{OH}^{-}\rightarrow 2\mathrm{MnO(OH)}_2$ （1分） $\mathrm{MnO(OH)_2 + 2I^{-} + 4H^{+}\rightarrow Mn^{2 + } + I_2 + 3H_2O}$ （1分）
1-3-2由电子守恒 $1\mathrm{mol}\mathrm{O}_2$ 对应 $4\mathrm{molNa_2S_2O_3}$ $n = 0.01000\times 8.50\times 10^{-3} / 4 = 2.125\times 10^{-5}(\mathrm{mol})$ DO浓度 $= 6.80~\mathrm{mg / L}$ （2分）
1-4过量的 $\mathrm{Na_2S_2O_3}$ 均转化，硫原子总浓度为： $2\times (25 - 2.45) / (100 + 25) = 0.36(\mathrm{mol / L})$ （2分）对应 $\mathbf{S}_8$ 浓度为： $0.36\times 17\% \times 90\% /8 = 6.9\times 10^{-3}(\mathrm{mol / L})$ （1分）溶液的密度近似为纯水，S8浓度为 $6.9\times 10^{-3}\mathrm{mol / kg}$ （1分）沉淀的分散度 $= K\cdot (C_{\mathrm{Q}} - s) / s = 1\times (6.9\times 10^{-3} - 1.9\times 10^{-8}) / 1.9\times 10^{-8} = 3.6\times 10^{5}$ （2分）

> **解析**（据源答案整理）：考查碘量法原理与实验异常探究。要点：滴定基于 Cr₂O₇²⁻~3I₂~6S₂O₃²⁻ 的计量关系；淡黄色沉淀源于 S₂O₃²⁻ 在酸性条件下分解（S₂O₃²⁻ + 2H⁺ → S↓ + SO₂ + H₂O）；末问由硫原子守恒与溶度积估算 S₈ 浓度及沉淀分散度（≈3.6×10⁵）。
