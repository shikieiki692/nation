# 题-YJ-08-01-粉色固体A在C下加热生成蓝色

## 题目

### 第 1 题 过渡金属推断（24分，占 $12\%$ ）

粉色固体 A 在 $200^{\circ}$ C 下加热，生成蓝色粉末 B 和某种气体，固体部分失重约 30%。B 与过量氨水反应生成棕黄色溶液 C（反应 1），C 在碱性条件下与双氧水反应得到 D（反应 2），D 与盐酸反应，放出氯气并生成溶液 E（反应 3），E 与 $HgCl_{2}$ 和 KSCN 反应得到天蓝色沉淀 F（反应 4），F 是一种 1:1 型盐。加热 E 的溶液可以得到粉红色沉淀 G（反应 5），过滤后灼烧 G 得到黑色的氧化物 H，化合物 A\~G 均含同一种过渡金属元素 X。其中化合物 B 中 X 元素质量分数为 35.53%，含有两个结晶水，化合物 C 中 X 元素质量分数为 25.40%。

1-1 推断元素 X 的名称及 A\~H 的化学式（所有化合物均为中性，含结晶水需注明）。

1-2 写出反应 1\~5 的化学反应方程式。

1-3 X 元素与 Al 元素组成的混合氧化物 $XAl_{2}O_{4}$ 是典型的尖晶石型结构，其中氧元素做立方最密堆积，X 原子填充由氧形成的四面体空隙，Al 原子填充由氧形成的八面体空隙，据此分别写出 X 和 Al 的填隙率。

## 参考答案

<table><tr><td>1-1共14分</td><td>由粉色固体等信息可知中心元素为钴(2分,写Co不得分)E与HgCl2和KSCN的反应是标准的Co的检验反应,B应为某种Co盐,C为含有6个NH3配位的Co盐,那么根据质量分数,得A: CoCl2·6H2O(2分)B: CoCl2·2H2O(2分)C: [Co(NH3)6]Cl2(2分)D: [Co(NH3)6]Cl3(1分)E: CoCl2(写H2CoCl4也可得分,1分)F: Co[Hg(SCN)4](写Hg[Co(SCN)4]也可得分,2分)G: Co(OH)2(1分)H: CoO(1分)</td></tr><tr><td>1-2共6分</td><td>反应1: CoCl2·2H2O + 6NH3== [Co(NH3)6]Cl2 + 2H2O(1分)反应2: 2[Co(NH3)6]2++H2O2== 2[Co(NH3)6]3++2OH-(1分)反应3: 2[Co(NH3)6]3++ 12H++ 2Cl-= 2Co2++ 12NH4++ Cl2(2分)反应4: CoCl2+ HgCl2+ 4KSCN== Co[Hg(SCN)4]+ 4KCl(1分)反应5: CoCl2+ 2H2O== Co(OH)2+ 2HCl(1分)</td></tr><tr><td>1-3共4分</td><td>Co: 12.5%; Al: 50%(各2分)</td></tr></table>
