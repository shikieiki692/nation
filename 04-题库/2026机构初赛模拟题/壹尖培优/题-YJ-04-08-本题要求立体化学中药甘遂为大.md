# 题-YJ-04-08-本题要求立体化学中药甘遂为大

## 题目

### 第 8 题 The FiRST Eye（29分，占 $15\%$ ）

（本题要求立体化学）中药甘遂为大戟科大戟属植物，味苦；性寒，可泻水逐肿，消肿散结。其主要活性成分为一类二萜化合物，具有抗病毒与抗癌功效。2016年从甘遂根中分离的化合物Euphorikanin A具有新颖的碳骨架，合成难度较高。以下是Euphorikanin A的结构：

![](images/10ca38e96e4c03742b74a45abaa925096040e597b2256946fe92074a68bf9350.jpg)

8-1 标出 Euphorikanin A 中所有三级手性碳的绝对构型。

8-2 根据之前测定的另一种骨架相似的二萜化合物（一个著名的例子是 Ingenol）的结构，研究人员提出了一种可能的生源合成路线来解释 Euphorikanin A 的形成。从某一关键中间体（如下所示）开始，经过几步得到 Euphorikanin A:

![](images/681453ab9952b3a44c90524719972c543c99d153ea7335799cd8af98be8f0a57.jpg)

已知生成 $M_{2}$ 的步骤中一个羟基被氧化为酮， $M_{2}$ 不含桥环， $M_{3}$ 有三元环， $M_{4}$ 有桥环。画出 $M_{1} \sim M_{4}$ 的结构。

8-3 在 2021 年，著名的合成大师 Erick M. Carreira 及其团队首次完成了 Euphorikanin A 的对映选择性合成。

8-3-1 对映选择性合成的一个重要策略是利用手性确定的天然产物（手性池）。完成反应。

$$
\xrightarrow [ \text {2)   LDA,   TMSCI} ]{\text {1)   O } _ {3} , \text {MeOH}} \quad \mathrm{X} \quad \xrightarrow [ \text {2)   AcOH,   120°C} ]{\text {1)   SnCl} _ {4}} \quad \mathrm{Y}
$$

8-3-2-1 该课题组的合成思路是先构建内酯结构，然而在第一次尝试合成时由于一处立体化学错误无法形成内酯。部分反应路线如下，画出 A～C 的结构。（PMB：对甲氧基苄基）

$$
\text { TBSO } \xrightarrow {\text { OPMB }} \text { A } \xrightarrow [ \text { Et } _ {3} \text { N } ]{\text { DDQ }} \text { A } \xrightarrow [ \text { NaH } ]{(\text { EtO }) _ {2} \text { P(O)CH } _ {2} \text { CO } _ {2} \text { Et }} \text { B } \xrightarrow [ \text { SmI } _ {2} ]{\text { Sml } _ {2}} \text { C }
$$

8-3-2-2 随后，通过更换试剂成功合成了中间产物 E。将 $(\mathrm{EtO})_{2}\mathrm{P}(\mathrm{O})\mathrm{CH}_{2}\mathrm{CO}_{2}\mathrm{Et}$ 换为 Still-Gennari 试剂 $(\mathrm{CF}_{3}\mathrm{CH}_{2}\mathrm{O})_{2}\mathrm{P}(\mathrm{O})\mathrm{CH}_{2}\mathrm{CO}_{2}\mathrm{Et}$ 即可。部分反应路线如下，画出 D、E 的结构。已知 B 和 D 分子式相同，结构相似。

$$
\mathrm{A} \xrightarrow [ \text {KHMDS} ]{\left(\mathrm{CF} _ {3} \mathrm{CH} _ {2} \mathrm{O}\right) _ {2} \mathrm{P} (\mathrm{O}) \mathrm{CH} _ {2} \mathrm{CO} _ {2} \mathrm{Et}} \quad \mathrm{D} \xrightarrow [ \text {(C} _ {27} \mathrm{H} _ {46} \mathrm{O} _ {3} \mathrm{S} _ {2} \mathrm{Si)} ]{\mathrm{SmI} _ {2}} \quad \mathrm{E}
$$

8-3-2-3 试简要解释 B 和 D 在与 SmI₂ 反应时的差异。提示：Sm 可以被中间体螯合。
