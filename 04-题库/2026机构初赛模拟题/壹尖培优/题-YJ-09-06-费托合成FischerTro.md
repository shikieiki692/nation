# 题-YJ-09-06-费托合成FischerTro

## 题目

### 第 6 题 三钴碳化物簇（26分，占 $13\%$ ）

费托合成（Fischer-Tropsch process）又称 F-T 合成，是以 CO 和 $H_{2}$ 的混合气体为原料在催化剂（通常是 Fe, Co 等金属）和适当条件下合成以液态的烃或碳氢化合物的工艺过程。在反应过程中，CO 被还原裂解，在催化剂表面形成 $C^{4-}$ ， $CH^{3-}$ ， $CH_{2}^{2-}$ 和 $CH_{3}^{-}$ 等组分。研究这些碳化物在催化剂表面的结合形式有助于理解催化机理并提高反应效率。

6-1 写出 F-T 过程生成 $C_{n}H_{2n+2}$ 的反应方程式。

6-2 画出 $\mathrm{Co}_{3}(\mathrm{CO})_{9}(\mathrm{CH})$ 的结构。已知该簇合物有一根穿过 C 原子的三重轴。

近日，哈佛大学的研究人员合成了一种三钴碳化物簇 X 以进一步研究 F-T 反应。

## 6-3 配体 $F,TBSLH_{6}$ 的合成

阅读下面的合成路线，回答问题。

![](images/a6c6af33b2ad760a995b15a57f82bd6969b5284b47b72bd5df067c4681cbf4f5.jpg)

$$
\mathbf {Q} \xrightarrow [ \begin{array}{c} \text {THF, -33°C} \\ 2 \text {h} \end{array} ]{\text {^nBuLi(3.1 eq.)}} \xrightarrow [ \begin{array}{c} \text {THF, -33°C} \\ 3 \text {h} \end{array} ]{\text {TBSCl(3.5 eq.)}} \mathrm {^F,TBSL H _ {6}}
$$

6-3-1 画出中间产物 P 和 Q 的结构。

6-3-2 画出配体 $F,TBSLH_{6}$ 的结构。

6-4 目标配合物 $\mathbf{X}$ 的合成

阅读下面的合成路线，回答问题。其中 $NC_{5}H_{5}$ 为吡啶，X'与 X 仅在电荷上有区别。

$$
\begin{array}{c} \mathrm {F,TBS L H _ {6}} \xrightarrow [ \text {THF, 120°C} ]{\mathrm {Co(NTMS_ {2}) _ {2} (3.00 eq.)}} \mathrm{A} \xrightarrow [ \text {toluene / THF, frozen} ]{\mathrm {Ph_ {2} MePCH_ {2} (1.10 eq.)}} \mathrm{B} \xrightarrow [ \text {THF, -78°C} ]{\mathrm {KN(TMS) _ {2} (1.10 eq.)}} \\ \mathrm{C} \xrightarrow [ \text {THF, 130°C} ]{\mathrm {BEt_ {3} (1.50 eq.)}} \mathrm {X ^ {\prime}} \xrightarrow [ \text {THF, -108°C} ]{\mathrm {[ Cp_ {2} Fe]PF_ {6} (1.00 eq.)}} \mathrm{X} \end{array}
$$

6-4-1 产物 X 的化学式可以写作 $^{(F,TBSL)}Co_{3}(CH)$ ，其中的 Co 原子均为四配位且没有 Co-Co 键。与 $Co_{3}(CO)_{9}(CH)$ 相同，X 也有一根穿过 C 原子的三重轴。据此，画出 X 的结构。

6-4-2 与 X 相比，A，B 和 C 的结构则要耐人寻味得多。三者中均含有一个三配位的 Co 和两个四配位的 Co，并且 A 和 B 中同时对两个 Co 配位的 N 原子均有四个，而 C 中只有三个。A 到 B、B 到 C 均发生了一次配体交换，且 A 到 B 还生成了一分子吡啶。根据上述信息画出 A，B 和 C 的结构。

6-4-3 写出 C 到 X' 的反应方程式。其中 $BEt_{3}$ 与 C 理论上是等当量的。

有机部分缩写注释：

Me，甲基；Et，乙基；Pr，丙基；Bu，丁基；Ph，苯基；Ac，乙酰基；Ts，对甲苯磺酰基；Cy，环己基；mCPBA，间氯过氧苯甲酸；DMSO，二甲亚砜；LDA，二异丙基氨基锂；THF，四氢呋喃；AIBN，偶氮二异丁腈；DBU，1,8-二氮杂双环[5.4.0]十一烯。
