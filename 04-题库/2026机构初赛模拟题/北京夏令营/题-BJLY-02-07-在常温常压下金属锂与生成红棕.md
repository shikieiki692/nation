# 题-BJLY-1785491436-07-在常温常压下金属锂与生成红棕

## 题目

### 第 7 题（13分）

在常温常压下金属锂与 $N_{2}(g)$ ，生成红棕色的离子化合物 $\alpha-Li_{3}N$ ，该晶体性。X-射线分析确定， $\alpha-Li_{3}N$ 晶体是由 $Li_{2}N$ 平面层和非密置的锂离子层交替叠加而有良好的导电成，其中 $Li_{2}N$ 平面层中的锂离子如同六方石墨层中的 C 原子。 $N_{3}$ 处于六元环中心，N-N 间的距离为 364.8pm。已知 $N_{3}$ 和 $Li^{+}$ 离子的半径分别为 146pm 和 59pm。

1. 试说明晶体导电的两大主要原因是什么？通过计算说明 $\alpha$ -Li $_3$ N 晶体导电的原因。

2. 假如 $\mathrm{N}_3$ 作六方最密堆积，试在六方晶胞中画出 $\mathrm{Li}_3\mathrm{N}$ 晶体中锂离子所占的位置和分数坐标。并回答这种结构能否导电，简述理由。

3. 金属锂在高温下与二氧化钛反应，可以生成多种晶型的 $\mathrm{LiTi_2O_4}$ ，其中有尖晶石型 $\mathrm{LiTi_2O_4}$ ，请在下面两张 $\mathrm{O}_2$ 离子密置单层上画出 $\mathrm{Li(○)}$ 和 $\mathrm{Ti(●)}$ 的投影位置。左图中只画 Ti 的投影位置，右图中画 Li 和 Ti 的共同投影位置。

4. 若不计其它离子，给出以锂离子为顶点的最小单位图。

5. $LiTi_{2}O_{4}$ 可以作锂离子二次电池的正极材料，其负极材料是石墨(Cn)，锂离子电池在工作前必须长时间充电，试写出充电时阳、阴极的电极反应式，放电时正负极的电极反应式以及电池反应方程式。
