# 题-BJLY-1785602414-03-钨的氮化物因具有优异的化学机

## 题目

### 第 3 题（20分）

钨的氮化物因具有优异的化学、机械和热学性能而受到科学家的重视。然而，在钨晶格中掺入氮在大气压力下是热力学不利的，因此制备钨的氮化物具有一定的困难，需要较苛刻的条件。最近，科学家通过高温高压下由钨酸钠与氮化硼反应，脱除氮气，得到A、B、C等氮化物。A属立方晶系，在A的立方晶胞中，氮原子占据所有棱心和体心的位置，而钨原子占据所有面心的位置。B属六方晶系，其结构可看做氮原子做简单六方堆积，钨原子填入一半的三棱柱空隙中。

## 3-1 写出 A 和 B 的化学式。

3-2 分别写出 A 和 B 中氮原子和钨原子的配位数。

研究表明，氮化物 A、B 是由氮化物 C 脱氮气得到的。C 属六方晶系，氮原子的堆积方式为...AAABBBAAABBB...，其中 A、B 都是密置单层，钨原子占据一半的三棱柱空隙。如果氮原子层上下同时接触钨原子，则沿着 c 轴方向，这两层钨原子的投影重合。此晶体平行于 c 轴的方向有不穿过任何原子的三重旋转轴。

3-3 写出 C 的化学式，及每个正当晶胞中原子的种类和个数。

3-4 写出 C 的每个正当晶胞中，由氮堆积形成的八面体空隙和四面体空隙的个数。

3-5 指出 C 中 W 配位多面体之间的连接方式。

3-6 沿着 C 的晶胞 c 轴方向，画一条同时含有钨和氮原子的直线，标出直线上的原子排列（无需考虑原子间距离，直线上总原子数不少于 10 个。钨、氮分别用 $\Delta$ 、 $\square$ 表示）。

3-7 已知 C 的晶胞参数 $a = 289 \mathrm{pm}$ , $c = 1529 \mathrm{pm}$ , 钨氮键键长 $d = 216 \mathrm{pm}$ , 计算空层上下的两层氮原子的层间距。
