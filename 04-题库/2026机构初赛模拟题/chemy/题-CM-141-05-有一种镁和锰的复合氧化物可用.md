# 题-CM-141-05-有一种镁和锰的复合氧化物可用

## 题目

### 第 5 题（12 分）

有一种镁和锰的复合氧化物，可用作电池的电极材料。结构测定表明，该复合氧化物的晶体属四方晶系，右图为该晶体的结构示意图：其中，深色四面体中心均为镁原子，位于晶胞的顶点、侧面面上以及内部；浅色八面体中心均为锰原子；多面体的顶点(小球)均为氧原子，所有氧原子化学环境相同且均邻接4个金属原子。晶胞参数 $a = 572.7\mathrm{pm}$ ， $c = 928.4\mathrm{pm}$ 。

![](images/67ab06d28105bcbeba366145da0868fa45a9faae3b18f0a620d5d0f04a29da04.jpg)

5-1 分别写出晶胞中镁原子的数目 x 和锰原子的数目 y；写出该晶体的化学式。

5-2 写出晶胞中所有镁原子的坐标参数。

5-3 计算晶体密度。

5-4 在晶胞中，若一个氧原子的坐标参数为(0, 1/4, 1/8)，计算 Mg-O 键长和 Mn-O 键长。

5-5 将该晶体用作可逆充放电的电池正极材料，在充电时，其中一种金属离子从晶格中脱除，同时晶体转变为立方晶系(晶胞参数 $a = 803.0 \, pm$ )。指出发生脱除是哪种金属离子；说明金属离子脱除前后晶系不同的原因。

## 参考答案

5-1 镁原子的数目 x = 4（0.5 分） 锰原子的数目 y = 8（0.5 分）
化学式为  $MgMn_{2}O_{4}$ （1 分）

5-2 (0, 0, 0) (1/2, 0, 1/4) (1/2, 1/2, 1/2) (0, 1/2, 3/4)（2 分）
0, 0, 0)  (0, 0, 0.5, 0.5, 0)  (0.5, 0.5, 0.5)（1 分）每错写、多写、或少写1 个，扣1 分；扣完为止。5-3 写出与顶点硅原子相连的所有其他

全部写对才可得分。漏写、多写或有错的，不得分。

5-3 计算晶体密度。

5-3  $D = ZM / N_{A}V$ $= 4 \times (24.31 + 2 \times 54.94 + 4 \times 16.00) \, \text{g mol}^{-1} / (6.022 \times 10^{23} \, \text{mol}^{-1} \times (572.7 \, \text{pm})^{2} \times 928.4 \, \text{pm}) = 4.323 \, \text{g cm}^{-3}$ （2 分）

5-4  $d(\text{Mg-O}) = [(\frac{1}{4} \times 572.7 \, \text{pm})^{2} + (\frac{1}{8} \times 928.4 \, \text{pm})^{2}]^{1/2} = 184.3 \, \text{pm}$ （1 分）

 $d_{1}(\text{Mn-O}) = \frac{\sqrt{2}}{4} \times 572.7 \, \text{pm} = 202.5 \, \text{pm}$ （1 分）

 $d_{2}(\text{Mn-O}) = \frac{1}{4} \times 928.4 \, \text{pm} = 232.1 \, \text{pm}$ （1 分）

5-5 脱除的是  $Mg^{2+}$  离子（1 分）
金属离子脱除前，Mn 为 +3 氧化态，其价电子组态为  $t_{2g}^{3}e_{g}^{1}$ ，电子在  $e_{g}$  轨道上不对称填充，出现姜-泰勒畸变， $[MnO_{6}]$  八面体沿晶胞 c 轴拉长，使晶体不再具有立方晶系的对称性(或不再具有沿 4 条体对角线方向的三次对称轴)；金属离子脱除后，Mn 为 +4 氧化态，价电子组态变为  $t_{2g}^{3}e_{g}^{0}$ ，电子在  $t_{2g}$  和  $e_{g}$  轨道均对称填充，无姜-泰勒畸变， $[MnO_{6}]$  八面体中的 Mn-O 键等长，晶体恢复立方晶系对称性。（2 分）
