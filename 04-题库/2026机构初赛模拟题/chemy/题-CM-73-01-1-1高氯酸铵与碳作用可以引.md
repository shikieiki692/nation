# 题-CM-73-01-1-1高氯酸铵与碳作用可以引

## 题目

### 第 1 题（8 分）

1-1 高氯酸铵与碳作用可以引起爆炸，产物中N 和Cl 均以最低价存在，没有固体残留。1-2 将碱式碳酸铜、碳酸钡、钇氧化物混合后在空气流中于某温度下处理，可得到一种特殊材料 $\mathrm { YBa _{ 2 } Cu _{ 3 } O _{ 7 - \delta } }$ 。
1-3 向硫酸、焦磷酸酸化后的硫酸锰(II)溶液中注入少量的高锰酸钾溶液，得到一深红色溶液。
1-4 将苯基溴化镁与三苯氧砷于非水溶剂中作用，随后反应体系分相，生成物均不在液相中。

## 参考答案

1-1 高氯酸铵与碳作用可以引起爆炸，产物中 N 和 Cl 均以最低价存在，没有固体残留。

1-1  $NH_{4}ClO_{4} + 4C = NH_{3} + HCl + 4CO$ (2分)产物写成 $CO_{2}$ 配平也可得分。
1-2 将碱式碳酸铜、碳酸钡、钇氧化物混合后在空气流中于某温度下处理,可得到一种特殊材料 $YBa_{2}Cu_{3}O_{7-\delta}$ 。
1-2  $6Cu_{2}(OH)_{2}CO_{3} + 8BaCO_{3} + 2Y_{2}O_{3} + (1-2\delta)O_{2} \rightarrow YBa_{2}Cu_{3}O_{7-\delta} + 14CO_{2} + 6H_{2}O$ (2分)
1-3 向硫酸、焦磷酸酸化后的硫酸锰(II)溶液中注入少量的高锰酸钾溶液,得到一深红色溶液。
1-2  $40Mn^{2+} + MnO_{4}^{-} + 15H_{4}P_{2}O_{7} \rightarrow 5Mn(H_{2}P_{2}O_{7})_{3}^{3-} + 22H^{+} + 4H_{2}O$ (2分)
1-4 将苯基溴化镁与三苯氧砷于非水溶剂中作用,随后反应体系分相,生成物均不在液相中。
1-4  $OAs(C_{6}H_{5})_{3} + BrMgC_{6}H_{5} \rightarrow MgO + [As(C_{6}H_{5})_{4}]Br$ (2分)
