# 题-CM-73-01-1-1高氯酸铵与碳作用可以引

## 题目

### 第 1 题（8 分）

1-1 高氯酸铵与碳作用可以引起爆炸，产物中N 和Cl 均以最低价存在，没有固体残留。1-2 将碱式碳酸铜、碳酸钡、钇氧化物混合后在空气流中于某温度下处理，可得到一种特殊材料 $\mathrm { YBa _{ 2 } Cu _{ 3 } O _{ 7 - \delta } }$ 。
1-3 向硫酸、焦磷酸酸化后的硫酸锰(II)溶液中注入少量的高锰酸钾溶液，得到一深红色溶液。
1-4 将苯基溴化镁与三苯氧砷于非水溶剂中作用，随后反应体系分相，生成物均不在液相中。
