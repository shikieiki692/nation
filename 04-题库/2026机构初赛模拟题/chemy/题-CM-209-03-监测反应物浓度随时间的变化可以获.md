# 题-CM-209-03-监测反应物浓度随时间的变化可以获

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-18-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（28 分，占 12%）

监测反应物浓度随时间的变化可以获得对应反应的动力学特性，进一步还可转化得到热力学参数，这有助于反应的改进和催化剂的设计。而要实现实时的浓度监测，紫外-可见光谱便是一个很好的表征手段，利用特征波长处吸光度的变化可研究物种之间的转化。将 K<sub>2</sub>S<sub>2</sub>O<sub>8</sub>、KI、Na<sub>2</sub>S<sub>2</sub>O<sub>3 </sub>在反应体系中混合(各物种初始浓度为[K<sub>2</sub>S<sub>2</sub>O<sub>8</sub>]<sub>0</sub> = 50 mM，[I<sup>-</sup>]<sub>0</sub> = 500 μM，[Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>]<sub>0</sub> = 100 μM)、并开始计时，每隔一定时间采集一张紫外-可见光谱，体系在 352 nm处吸光度随时间的变化示于下图，该波长处的吸光度主要由含碘物种 X 贡献。

![](images/dbd9c2c26188389e39e029170cfdd901cd72a9ca59c0f830a380b7ea527c08ec.jpg)

**3-1** 结合反应条件和元素知识，给出 X 的化学式，并用两个离子方程式解释在 a 点(370 s)前体系吸光度几乎为零的原因。

**3-2** S<sub>2</sub>O<sub>8</sub><sup>2-</sup>与 I<sup>-</sup>的氧化还原对于两反应物均为一级反应，因此 S<sub>2</sub>O<sub>8</sub><sup>2-</sup>的消耗速率可表示为：

-d[S<sub>2</sub>O<sub>8</sub><sup>2-</sup>] / dt = k[S<sub>2</sub>O<sub>8</sub><sup>2-</sup>][I<sup>-</sup>]根据已有信息做合理假设，计算速率常数。

**3-3** 吸光度监测表明，体系在 459 nm 处的吸光度随时间先几乎为零后逐渐增加，这对应另一个含碘物种 Y，X 和 Y 在溶液中可以快速转化、时刻处于平衡(该过程不涉及 S<sub>2</sub>O<sub>8</sub><sup>2-</sup>)，根据实验测得 b 点的吸光度数值(实验测量值为 0.459，光程为 1 cm)可转化得到 Y 转化为 X 平衡反应的平衡常数 K。

**3-3-1** 在 b 点时近似满足 d[X] / dt = 0，结合平衡常数表达式和物料守恒关系的微分式，计算K 的具体数值。在计算时需同时考虑两物种对吸光度的贡献，X 在 352 nm 处的摩尔吸光系数为 2.76 × 10<sup>4</sup> L·mol<sup>-1</sup>·cm<sup>-1</sup>，Y 在对应波长处的摩尔吸光系数为 189 L·mol<sup>-1</sup>·cm<sup>-1</sup>；可能用到的公式：

d(xy) / dt = x·dy / dt + y·dx / dt d(x / y) / dt = [y·dx / dt – x · dy / dt] / y<sup>2</sup>

**3-3-2** 有人认为可忽略Y在352 nm处的吸光度贡献，这会对平衡常数造成多大的相对误差？

**3-3-3** 在实验后期，可以观察到 352 nm 处的吸光度随时间下降、459 nm 处的吸光度随时间上升，而介于二者之间某一波长处的吸光度随时间几乎不发生变化，这一现象说明实验后期主要发生的是什么过程？

## 参考答案

![](images/dbd9c2c26188389e39e029170cfdd901cd72a9ca59c0f830a380b7ea527c08ec.jpg)

**3-1** X 的化学式：I<sub>3</sub><sup>-</sup>（2 分），在 a 点前 I<sub>3</sub><sup>-</sup>一经生成便马上会与 S<sub>2</sub>O<sub>3</sub><sup>2-</sup>反应消耗，方程式如下（各 2 分，共 4 分）：

S<sub>2</sub>O<sub>8</sub><sup>2-</sup> + 3I<sup>-</sup> = I<sub>3</sub><sup>-</sup> + 2SO<sub>4</sub><sup>2-</sup>

I<sub>3</sub><sup>-</sup> + 2S<sub>2</sub>O<sub>3</sub><sup>2-</sup> = 3I<sup>-</sup> + S<sub>4</sub>O<sub>6</sub><sup>2-</sup>

**3-2** 在 a 点前，由于 S<sub>2</sub>O<sub>8</sub><sup>2-</sup>大过量，可认为其浓度始终等于初始浓度，又由于无 I<sub>2</sub>或 I<sub>3</sub><sup>-</sup>的净生成，可认为[I<sup>-</sup>]始终为初始浓度，因此反应速率表达式可写作：

r = k[S<sub>2</sub>O<sub>8</sub><sup>2-</sup>]<sub>0</sub>[I<sup>-</sup>]<sub>0</sub>（假设正确得 2 分）而每消耗 1 当量 S<sub>2</sub>O<sub>8</sub><sup>2-</sup>，就对应消耗 2 当量 S<sub>2</sub>O<sub>3</sub><sup>2-</sup>，因此根据 S<sub>2</sub>O<sub>3</sub><sup>2-</sup>被完全消耗经历的时间为 370 s 可得：

370 s = [S<sub>2</sub>O<sub>3</sub><sup>2-</sup>] / 2r（列式正确得 2 分）代入解得 k = 5.4 × 10<sup>-3</sup> L·mol<sup>-1</sup>·s<sup>-1</sup>（2 分）。

**3-3-1** 根据平衡常数表达式：[I<sub>3</sub><sup>-</sup>] = K [I<sub>2</sub>][I<sup>-</sup>]，求微分可得：

0 = d[I<sub>3</sub><sup>-</sup>] / dt = K[I<sub>2</sub>]·d[I<sup>-</sup>] / dt + K[I<sup>-</sup>]·d[I<sub>2</sub>] / dt（2 分）又根据 I 的物料守恒[I<sup>-</sup>]<sub>0</sub> = [I<sup>-</sup>] + 2[I<sub>2</sub>] + 3[I<sub>3</sub><sup>-</sup>]，求微分可得：

0 = d[I<sup>-</sup>] / dt + 2 d[I<sub>2</sub>] / dt + 3 d[I<sub>3</sub><sup>-</sup>] / dt = d[I<sup>-</sup>] / dt + 2 d[I<sub>2</sub>] / dt（2 分）因此结合上述二式可得[I<sup>-</sup>] = 2[I<sub>2</sub>]（2 分），根据 b 点的吸光度值可写出下列方程（2 分）：

[I<sup>-</sup>]<sub>0</sub> = 500 μM = [I<sup>-</sup>] + 2[I<sub>2</sub>] + 3[I<sub>3</sub><sup>-</sup>]

A = 0.459 = 2.76 × 10<sup>4</sup> L·mol<sup>-1</sup>·cm<sup>-1</sup> · [I<sub>3</sub><sup>-</sup>] · 1 cm + 189 L·mol<sup>-1</sup>·cm<sup>-1</sup> · [I<sub>2</sub>] · 1 cm解得[I<sub>2</sub>] = 113.1 μM，[I<sub>3</sub><sup>-</sup>] = 15.9 μM，因此对应的平衡常数为 622（2 分）。

**3-3-2** 若忽略 I<sub>2</sub>在 352 nm 处的吸光度贡献，可直接根据吸光度求得[I<sub>3</sub><sup>-</sup>] = 16.6 μM，则对应的[I<sub>2</sub>] = 112.6 μM（2 分），求得平衡常数为 655，相对误差是 5.3%（2 分）。

**3-3-3** 说明主要发生的是 I<sub>3</sub><sup>-</sup>进一步被 S<sub>2</sub>O<sub>8</sub><sup>2-</sup>氧化得到 I<sub>2</sub>（2 分）。
