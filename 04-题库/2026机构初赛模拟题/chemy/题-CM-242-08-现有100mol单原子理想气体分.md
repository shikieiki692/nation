# 题-CM-242-08-现有100mol单原子理想气体分

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-6-8`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 8 题（10 分）

现有 1.00 mol 单原子理想气体，分别经历以下路径，从状态 A (p<sub>A</sub> = 101.3 kPa，V<sub>A</sub> = 24.0 L)变化至状态 B (p<sub>B</sub> = 75.0 kPa，V<sub>B</sub> = 50.0 L)。分别计算每种路径下的 ΔH、ΔU、Q、W：路径 1：先经历等温可逆膨胀，再经历恒容升温；路径 2：先经历绝热可逆膨胀，再经历恒容升温。

## 参考答案

根据 pV = nRT，求得 A 和 B 状态的温度 T 分别为：T<sub>A</sub> = 292.4 K；T<sub>B</sub> = 451.0 K路径 1：ΔH<sub>1</sub> = nC<sub>p,m</sub>ΔT = 1.00 mol × 2.5 × 8.314 J·mol<sup>-1</sup>·K<sup>-1</sup> × (451.0 K – 292.4 K) = 3.30 kJ（1 分）ΔU<sub>1</sub> = nC<sub>V,m</sub>ΔT = 1.00 mol × 1.5 × 8.314 J·mol<sup>-1</sup>·K<sup>-1</sup> × (451.0 K – 292.4 K) = 1.98 kJ（1 分）经历等温可逆膨胀后，V<sub>1</sub> = V<sub>B</sub> = 50.0 L；p<sub>1</sub> = p<sub>A</sub>V<sub>A</sub> / V<sub>1</sub> = 101.3 kPa × 24.0 L / 50.0 L = 48.6 kPa W<sub>11</sub> = nRT ln(p<sub>1</sub>/p<sub>A</sub>) = 101.3 kPa × 24.0 L × ln (48.6 kPa / 101.3 kPa) = –1.79 kJ恒容升温的 W<sub>12</sub> = 0，故 W<sub>1</sub> = W<sub>11</sub> + W<sub>12</sub> = –1.79 kJ（1.5 分）Q<sub>1</sub> = ΔU<sub>1</sub> – W<sub>1</sub> = 3.77 kJ（1.5 分）路径 2：由于 H 和 U 都是状态函数，故：ΔH<sub>2</sub> = ΔH<sub>1</sub> = 3.30 kJ（1 分）；ΔU<sub>2</sub> = ΔU<sub>1</sub> = 1.98 kJ（1 分）单原子理想气体绝热可逆膨胀，γ = 5/3；则：p<sub>2</sub> = p<sub>A</sub>V<sub>A</sub><sup>γ</sup> / V<sub>1</sub><sup>γ</sup> = 101.3 kPa × (24.0 L)<sup>5/3</sup> / (50.0 L)<sup>5/3</sup> = 29.8 kPa此时的温度为：T<sub>2</sub> = p<sub>2</sub>V<sub>2</sub>/nR = 179.2 K恒容升温的热效应为：Q<sub>22</sub> = nC<sub>V,m</sub>ΔT = 1.00 mol × 1.5 × 8.314 J·mol<sup>-1</sup>·K<sup>-1</sup> × (451.0 K – 179.2 K) = 3.39 kJ绝热可逆膨胀 Q<sub>21</sub> = 0 故：Q<sub>2</sub> = Q<sub>21</sub> + Q<sub>22</sub> = 3.39 kJ（1.5 分）W<sub>2</sub> = ΔU<sub>2</sub> – Q<sub>2</sub> = – 1.41 kJ（1.5 分）不要求有效数字。使用其他合理解法，得到相同答案的，也可得分。
