# 题-CM-68-05-将水合盐置于流动的氧气氛中加

## 题目

### 第 5 题（10 分）

将水合盐 $\mathbf { A } ( \mathrm { MX _{ n } } { \cdot } \mathrm { H } _{ 2 } \mathrm { O } )$ 置于流动的氧气氛中加热，升温速率为 $5^{ \circ } \mathrm { C } \cdot \mathrm { min } ^{ - 1 }$ 。约 $5 \mathrm { min }$ 后质量开始减少，约 $90 \mathrm { min }$ 后得到化合物B，此时失重 $43.33 \%$ ；再过约 $90 \mathrm { min }$ ， 得到白色固体 C 并放出无色无味气体。另取试样在 $\Nu _{ 2 }$ 中加强热，失重 $68.17 \%$ ，残余固体为C。在加热过程中，金属离子未发生氧化还原反应。
在N2 中加强热，失重68.17%，残余固

5-1 通过计算确定A、B 和C 的化学式。

![](images/6f941f502abe445c1098f9a3910c651962bb755a68a46d0cf5720f9896662978.jpg)

5-2 分步写出 $\pmb { \mathsf { A } }$ 在氧气气氛中热分解的方程式。

5-3 将A 的无水物置于空气中在 $160^{ \circ } \mathrm { C }$ 加热分解，仅有两种产物生成， 固体产物只有B。写出化学反应方程式。

## 参考答案

## 第5题（10分）

![](images/821c8f59a57b75202d86bf427072feb84b1961f1ce159e2e62709e68a096b7ff.jpg)

5-1无色无味气体为 $\mathrm{CO}_{2}$，设B的化学式为 $\mathrm{M(CO_3)_{n / 2}}$，C的化学式为 $\mathrm{MO}_{\mathrm{n / 2}}$，设M的原子量为 $x$，则有：

$\frac{1-0.4333}{1-0.6817}=\frac{x+12.01+3\times16.00}{x+16.00}$ (1分)
当 n=2 时，上式有合理解 x=40.40 (1分)
故 M 为 Ca (1分)
故 B 为 CaCO₃ (1分)，C 为 CaO (1分)
求得 A 的分子量为 176.2，进而计算得到 M(X)=59 g/mol；X 为乙酸根离子。
故 A 为 Ca(CH₃COO)₂·H₂O (1分)

5-2 Ca(CH₃COO)₂·H₂O = Ca(CH₃COO)₂ + H₂O (1分)
Ca(CH₃COO)₂ + 4O₂ = CaCO₃ + 3CO₂ + 3H₂O (1分)
CaCO₃ = CaO + CO₂ (1分)

5-3 Ca(CH₃COO)₂ = CaCO₃ + (CH₃)₂CO (1分)
用石灰来中和木材干馏所得的木醋液，制成乙酸钙，进而加热分解，是生产有机溶剂丙酮的古老方法。
