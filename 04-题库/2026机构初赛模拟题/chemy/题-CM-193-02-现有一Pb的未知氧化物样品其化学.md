# 题-CM-193-02-现有一Pb的未知氧化物样品其化学

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-2-2`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（18 分，占 7%）

现有一 Pb 的未知氧化物样品，其化学式可写成[xPbO·PbO<sub>2</sub>]，可采用碘量法和配位滴定法测定其组成。实验步骤如下：准确称取 0.01400 g 干燥好的样品，置于 250 mL 锥形瓶中；加入1:1 的醋酸-醋酸钠溶液 10 mL（反应 1），再加入 0.2 mol/L KI 溶液 1~2 mL 充分溶解（反应

2），使溶液呈透明橙红色；加 0.5 mL 2 %淀粉溶液，用 0.01000 mol/L Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>标准溶液滴定至溶液由蓝色刚好退去为止（反应 3），此时所用去的 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>溶液的体积为 4.031 mL；再加入二甲酚橙 3~4 滴，用 0.01000 mol/L EDTA 标准溶液滴定溶液，由紫色变为亮黄色时即为终点（反应 4），此时所消耗的 EDTA 溶液的体积为 6.045 mL。

**2-1** 写出反应 1~4 的方程式。（提示：反应 1 中的系数可用 x 表示）

**2-2** 通过计算确定 x 的值，并计算该样品中未知氧化物的质量分数。（要求有效数字）

**2-3** 用 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>标准溶液滴定时需控制溶液的 pH 为中性或弱碱性，解释其原因。

## 参考答案

**2-1**（各 2 分，共 8 分）反应 1：[xPbO·PbO<sub>2</sub>] + (2x+4)CH<sub>3</sub>COOH = xPb(CH<sub>3</sub>COO)<sub>2</sub> + Pb(CH<sub>3</sub>COO)<sub>4</sub> + (x+2)H<sub>2</sub>O若认为 Pb(II)以 Pb(CH<sub>3</sub>COO)<sub>3</sub><sup>-</sup>形式存在，配平，也得分。若反应产物写为 PbO<sub>2</sub>，不扣分。反应 2：Pb(CH<sub>3</sub>COO)<sub>4 </sub>+ 2KI = Pb(CH<sub>3</sub>COO)<sub>2 </sub>+ I<sub>2</sub> +2CH<sub>3</sub>COOK产物写 KI<sub>3</sub>，配平，也得分。若反应 1 中的产物写为 PbO<sub>2</sub>，反应 2 用 PbO<sub>2</sub>参加反应，不扣分。反应 3：I<sub>2</sub> + 2S<sub>2</sub>O<sub>3</sub><sup>2-</sup> = 2I<sup>-</sup> + S<sub>4</sub>O<sub>6</sub><sup>2- </sup>反应物写 I<sub>3</sub><sup>-</sup>，配平，也得分。反应 4：Pb(CH<sub>3</sub>COO)<sub>2 </sub>+ EDTA<sup>4-</sup> = Pb(EDTA)<sup>2-</sup> + 2CH<sub>3</sub>COO<sup>-</sup>反应物写 H<sub>2</sub>EDTA<sup>2-</sup>，配平，也得分.

**2-2**（共 6 分）根据上述反应的计量关系，有：n(Pb)<sub>总</sub> = n(EDTA) = 0.01000×6.045×10<sup>-3</sup> = 6.045×10<sup>-5</sup>(mol)（1 分）n(Pb(IV)) = 0.5n(S<sub>2</sub>O<sub>3</sub><sup>2-</sup>) = 0.5×0.01000×4.031×10<sup>-3</sup> = 2.016×10<sup>-5</sup>(mol)（1 分）则有 n(Pb)<sub>总</sub>/n(Pb(IV)) = x+1 = (6.045×10<sup>-5</sup>) / (2.016×10<sup>-5</sup>) = 2.999 = 3（1 分）故 x = 2（1 分），该氧化物样品的化学式为 Pb<sub>3</sub>O<sub>4</sub>。则 n(Pb<sub>3</sub>O<sub>4</sub>) = n(Pb)<sub>总</sub>/3 = 2.015×10<sup>-5</sup>(mol)（1 分）故 w(Pb<sub>3</sub>O<sub>4</sub>) = (2.015×10<sup>-5</sup>×685.6/0.01400)×100 % = 98.68 %（1 分）质量分数的有效数字必须为 4 位，若有效数字错误扣 1 分。

**2-3**（共 4 分）若体系过酸，S<sub>2</sub>O<sub>3</sub><sup>2-</sup>可能发生歧化反应，分解为 S 和 SO<sub>2</sub>（2 分）；若体系过碱，I<sub>2</sub>可能发生歧化（1 分），且 I<sub>2</sub>和 S<sub>2</sub>O<sub>3</sub><sup>2-</sup>的反应不会定量的产生 S<sub>4</sub>O<sub>6</sub><sup>2-</sup>，而是可能产生 SO<sub>4</sub><sup>2-</sup>等副产物（1 分）。
