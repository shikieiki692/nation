# 题-CM-173-02-Tr-COF

## 题目

### 第 2 题

第 2 题（11 分， 占比 $11 \%$ ） 共价有机框架材料共价有机框架材料(COFs)是材料学研究的热点之一。大多数 COFs 由二维平面层垂直堆积(AA 堆积)而成，具有一定大小的孔穴通道，有良好的吸附、催化等性能。下面为其中一种具有三重旋转轴的Tr-COF 的合成与应用。

![](images/c9408bf4528205b7160e1efd745792d362a3f1ea4de2bb50e310841502ccda88.jpg)
Tr-COF

2-1 已知 $\pmb { x }$ 为一种小分子， 指出 $\mathtt { a } : \mathtt { b } : \mathtt { c }$ 的值。

2-2 已知 Tr-COF 的孔径大小(外接圆半径)为 $1000 ~ \mathrm { pm }$ ， 层间距为 $357 ~ \mathrm { pm }$ ， 计算 Tr-COF 的密度。

2-3 向 Tr-COF 中添加 $\mathrm { FeCl } _{ 3 }$ ，一定条件下生成 Fe SAS/Tr-COF，其中所有Fe 化学环境相同，且均为四方锥5 配位， 每个晶胞中有3 个Fe 原子，测得每个 Fe 原子磁矩为 $1.73 \mathrm { B } . \mathrm { M } .$ 。

2-3-1 定性画出Fe 的 d 轨道分裂情况并填充电子。

2-3-2 在 N 1s XPS 中， 光电子动能更高的亚胺峰来自 Fe SAS/Tr-COF 还是 Tr-COF？

2-3-3 已知 Fe-N 键键长为 $192 ~ \mathrm { pm }$ ， Cl-Cl 最短距离为 $311 ~ \mathrm { pm }$ 。 不考虑四方锥配位中键角上的畸变， 计算Cl-N 的最短距离。

2-3-4 Fe SAS/Tr-COF 可以催化 $\mathrm { CO } _{ 2 }$ 光还原为CO， 其第一步是催化剂活性位点在光照下产生激子(电子-空穴对)。 指出 “电子”和“空穴” 的产生位点。

## 参考答案

2-1 a:b:c=2:3:6（1分）

2-2 画出二维晶胞（相邻四个大空穴中心为顶点的平行四边形），计算晶胞参数：

$$
a = b = 1000 \times 3^{0.5} = 1732 \mathrm{pm}
$$

题干已说明 Tr-COF 为 AA 堆积，故 c 即层间距 357 pm。

每个晶胞的分子式为 $C_{78}H_{42}N_{12}$ ， $M = 1147.236 \, g \cdot mol^{-1}$

因此 Tr-COF 的密度为 $\rho = ZM / N_{A} V = 2.06 \, g \cdot cm^{-3}$ （2 分）

2-3-1 2 分，分裂、电子各 1 分， $d_{z^{2}}$ 和 $d_{xy}$ 的能级顺序颠倒也得分。

![](images/678116cd0afc987a323c0170b62dc7e1ccf4f0ec5444861c16f25c8e67853a69.jpg)

2-3-2 Tr-COF（1 分，孤对电子配位后对内层电子的斥力减小）

2-3-3 先计算 Fe-C1 键键长： $d(\mathrm{Fe}-\mathrm{Cl})=2^{0.5}d_{\mathrm{Cl}-\mathrm{Cl}}/2=220\ \mathrm{pm}$ （1 分），再由勾股定理计算 Cl-N 最短距离： $d=(220^{2}+192^{2})^{0.5}\ \mathrm{pm}=292\ \mathrm{pm}$ （1 分）。

2-3-4 “电子”：Fe（1 分）；“空穴”：萘环（1 分）。萘环答成苯环不得分
