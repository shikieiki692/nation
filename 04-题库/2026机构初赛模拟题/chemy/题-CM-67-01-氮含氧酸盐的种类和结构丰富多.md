# 题-CM-67-01-氮含氧酸盐的种类和结构丰富多

## 题目

### 第 1 题（10 分）

氮含氧酸盐的种类和结构丰富多彩。在乙醇钠的乙醇溶液中由羟胺与正丙醇硝酸酯反应，可制得Angeli 盐，其化学式为 $\mathrm { Na } _{ 2 } \mathrm { N } _{ 2 } \mathrm { O } _{ 3 }$ 。
1-1 写出生成 Angeli 盐的化学反应方程式。
1-2 Angeli 盐阴离子 $\mathrm { N } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 }$ -中含有氮氮双键， 画出其 Lewis 结构式(注意标明形式电荷)并指出每个氮原子的杂化方式。
1-3 将Angeli 盐溶于醋酸-醋酸钠缓冲溶液中并滴入过量溴水， Angeli 盐被彻底氧化； 但若将溴水换成碘水， 则氮只能被氧化为 $+ 3$ 氧化态。 分别写出这两个反应的化学反应方程式。
