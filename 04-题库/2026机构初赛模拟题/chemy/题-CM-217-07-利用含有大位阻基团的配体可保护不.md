# 题-CM-217-07-利用含有大位阻基团的配体可保护不

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-7-7`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 7 题（11 分）

利用含有大位阻基团的配体可保护不稳定的结构。将配体 L(结构如下图)溶于四氢呋喃(THF)，加入金属钠，搅拌反应 2 h；将混合物缓慢加入到 CrCl<sub>3</sub>(THF)<sub>3</sub>(记为 A)的 THF 悬浊液中，室温搅拌反应 5 h，分离出 THF 并用戊烷萃取、浓缩、结晶，得到绿色晶体 B。将 B溶于乙醚，加入还原剂 KC<sub>8</sub>，搅拌过夜；分离出固体产物，将其用乙醚重结晶，得到红色晶体 C。

对 B 和 C 进行了一系列的表征：

(1)<sub> </sub>元素分析表明，B 中各元素的含量(质量分数)分别为 C, 67.41; H, 7.74; N, 6.07；C 中各元素的含量(质量分数)分别为 C, 72.70; H, 8.91; N, 6.54。

(2)<sub> </sub>结构测定表明，B 为双核配合物，Cr 与配体形成平面结构，Cr 原子的间距为 343 pm。C 为双核配合物，Cr 原子的间距为 180 pm；同时，C 中配体 L 的 C-C 键的长度缩短至 135 pm。

(3)<sub> </sub>磁性测定表明，B 呈现反铁磁性，C 呈现抗磁性。

![](images/ce124d6d19b599caba5d28adb87e16d49efa707acfe1fefa91ae01c9dffccd60.jpg)

**7-1** 通过计算和推导，确定 B 和 C 的化学式。

**7-2** 写出 A 中 Cr 的氧化态及其价电子在八面体场中的组态。

**7-3** 画出 B 的结构示意图(配体 L 可简化)。

**7-4** 写出 C 中 Cr 的氧化态并说明判断理由(提示：乙烯中碳碳键长为 134 pm)。

**7-5** 画出 C 的结构示意图(配体 L 可简化)，说明 C 呈现抗磁性的原因。

## 参考答案

**7-1** 根据元素质量分数之比可得，B 和 C 中的有机配体仅为 L（1 分），无 THF 结晶或配

位。

设有 1 个 L 配体，则 B 的分子量为：14.01 × 2 ÷ 0.0607 = 461.6，为 CrClL；（0.5 分）

设有 1 个 L 配体，则 C 的分子量为：14.01 × 2 ÷ 0.0654 = 428.4，为 CrL；（0.5 分）

又因为 B 和 C 都是双核配合物，所以 B 为(CrClL)<sub>2</sub>（0.5 分），C 为(CrL)<sub>2</sub>（0.5 分）。

**7-2** 氧化态：+3（1 分）

价电子组态：t<sub>2g</sub><sup>3</sup>e<sub>g</sub><sup>0</sup>（1 分）
