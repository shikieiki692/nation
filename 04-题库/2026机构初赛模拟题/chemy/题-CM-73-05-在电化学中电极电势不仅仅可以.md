# 题-CM-73-05-在电化学中电极电势不仅仅可以

## 题目

### 第 5 题（8 分）

在电化学中， 电极电势不仅仅可以用于氧化还原反应， 也可以用于非氧化还原反应， 例如：溶度积、 配合物的稳定常数等等。

5-1 核装置可能泄露 $\mathrm { Pu }$ 废料是个严重的环境问题，请根据下列电位数据计算当 $\mathsf { pH }$ 最大为何值时， $\mathrm { Pu } ^{ 4 + }$ 的浓度可以达到 $1 \mathrm { mol { \cdot } L ^{ - 1 } }$ 。

$$
\mathrm { Pu ^{ 4 + } ( aq ) } + 4 \mathrm { e ^{ - } = Pu ( s ) } \qquad \mathrm { E ^{ \ominus } = - 1.28 V }
\mathrm { Pu ( OH ) _{ 4 } + 4 e ^{ - } = Pu ( s ) + 4 OH ^{ - } ( aq ) } \qquad \mathrm { E ^{ e } = - 2.06 V }
$$

5-2 肠肝菌素(Ent)是某些细菌分泌的，能从环境中将 Fe 分离出来的一种特殊配体。形成[Fe(III)(Ent)]的平衡常数 $K = 1.00 \times 10^{ 52 } \mathrm { mol ^{ - 1 } } { \cdot } \mathrm { dm ^{ - 3 } }$ ， 试计算：在中性条件下， 可否通过还原至 $\mathrm { Fe ( II ) }$ 的方法将Fe 从 $[ \mathrm { Fe ( III ) ( Ent ) } ]$ 中提取出来。

Hint： 细菌利用的最强的还原剂为 $\mathrm { H } _{ 2 }$ ， $\mathrm { Fe ( III ) }$ 到 $\mathrm { Fe ( II ) }$ 的标准电极电位为 $0.77 \mathrm { V }$ 。

## 参考答案

## 第5题（8分）

5-1 $\mathrm{Pu(OH)_4(s) = Pu^{4 + }(aq) + 4OH^{-}(aq)}$ $\mathrm{E}^{\ominus} = -2.03 + 1.28 = -0.78\mathrm{V}$ （1分）
-nEF=-RTlnKsp（1分）
$\ln K_{\mathrm{sp}} = \frac{4\times -0.78\times F}{R\times 298} = -121.5$ $K_{\mathrm{sp}} = 1.72\times 10^{-53}$ （1分）
令 $\mathrm{Pu^{4 + } = 1 mol\cdot L^{-1}}$ ，则：
$[\mathrm{H^{+}}] = \frac{Kw}{\sqrt[4]{Ksp}} = 0.155\mathrm{mol}\cdot \mathrm{L}^{-1}\quad \mathrm{pH} = 0.81$ （1分）

5-2 由能斯特方程 $E = E^{\Theta} + \frac{0.0592}{n} \times \lg \frac{[\text{氧化态}]}{[\text{还原态}] }$，得（1分）
$E_{H} = -0.4144 \, \text{V}$ （1分）
$E_{Fe} = -2.3084 \, \text{V}$ （1分）
$H_{2} + 2[Fe(III)(Ent)] = 2Fe(II) + 2Ent + H^{+} \quad E^{\Theta} = -1.894 \, \text{V} &lt; 0 \, \text{V}$
因此不可提取（1分）
做出其他合理假设，得出合理结论的，也可得满分。
