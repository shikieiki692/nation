# 题-CM-61-04-金属与硝酸反应的产物非常复杂

## 题目

### 第 4 题（12 分）

金属与硝酸反应的产物非常复杂，其成分与金属的种类和硝酸的浓度关系很大。 Acworth 曾测定过金属铜与不同浓度硝酸的反应产物：将少量金属铜溶于浓度为 $4.5 \mathrm { mol } { \cdot } \mathrm { L } ^{ - 1 }$ 硝酸中，收集所有放出的气体，并待其与硝酸溶液达到平衡；此时收集到的气体为三种无色含氮气体的混合物。取 $398.6 ~ \mathrm { mL }$ 该混合气体，加入过量氢氧化钠溶液并通入氧气，充分反应后，用焦性没食子酸溶液充分吸收多余的氧气，测得剩余气体的体积为 $20.4 \mathrm { mL }$ ；向其中通入氧气至总体积为 $51.9 \mathrm { mL }$ ，再通入氢气至总体积为 $217.0 \mathrm { mL }$ ，使用电火花引爆，剩余气体的体积为$105.5 \mathrm { mL }$ 。 以上体积均在同一温度和压力下测得，水蒸气的分压可忽略不计。

4-1 铜溶于 $4.5 \ \mathrm { mol { \cdot } L ^{ - 1 } }$ 硝酸收集到的三种无色含氮气体是什么？分别写出生成三种气体的化学反应方程式。

4-2 分别计算放出气体中三种气体的摩尔百分含量。

## 参考答案

## 第4题（12分）

4-1 是 NO、 $N_{2}O$ 、 $N_{2}$ 。(各 1 分)
 $3Cu + 8HNO_{3} = 3Cu(NO_{3})_{2} + 2NO + 4H_{2}O$ （1 分）
 $4Cu + 10HNO_{3} = 4Cu(NO_{3})_{2} + N_{2}O + 5H_{2}O$ （1 分）
 $5Cu + 12HNO_{3} = 5Cu(NO_{3})_{2} + N_{2} + 6H_{2}O$ （1 分）

4-2 $\omega (\mathrm{NO}) = (398.6\mathrm{mL} - 20.4\mathrm{mL}) / 398.6\mathrm{mL} = 94.88\%$ （2分）$\omega (\mathrm{N}_2\mathrm{O}) = [217.0\mathrm{mL} - (51.9\mathrm{mL} - 20.4\mathrm{mL})\times 3 - 105.5\mathrm{mL}] / 398.6\mathrm{mL} = 4.26\%$ （2分）$\omega (\mathrm{N}_2) = 1 - \omega (\mathrm{N}_2\mathrm{O}) - \omega (\mathrm{NO}) = 0.86\%$ （2分）不要求有效数字。
