# 题-CM-146-05-将溶于乙醇中并加入Htopc

## 题目

### 第 5 题（12 分）

将 $MnCl_{2}\cdot4H_{2}O$ 溶于乙醇中，并加入 Htopca(一种羧酸衍生物，分子式为 $C_{5}H_{6}N_{2}O_{3}$ ) 的水溶液，在 $80^{\circ}C$ 下混合搅拌 2 h 后过滤，滤液在室温下缓慢蒸发，溶液中析出一种黄色块状晶体 X。对 X 在氮气气氛下进行热重分析实验表明：在 $65\sim120^{\circ}C$ 下 X 失重 21.09%，对应于失去所有结晶水和结构水；继续加热至 $250^{\circ}C$ ，失重 36.98%；继续加热至 $850^{\circ}C$ ，再失重 14.04%，后续固体质量不再发生变化。对残留固体化学分析表明：固体中含有两种物质，混合物中 Mn 的质量分数为 46.17%。对第二次失重放出的混合气体进行分析，混合气体中含有三种气体分子，其中含碳元素的气体仅有丙炔；将该混合气体冷却后用溴水充分吸收，剩余气体质量为原气体质量的 37.94%，且剩余气体在空气中会由无色变为红棕色。已知 X 为单核 Mn 配合物，在热重分析的过程中 Mn 没有发生氧化态的改变。
式为C5H6N2O3)的水溶液，在80 ℃下混合

5-1 通过计算与推理，确定第二次失重气体的种类与比例。

5-2 推出黄色块状晶体 X 的化学式。

5-3 写出以下反应的化学反应方程式(要求系数比为最简整数比):

(1) 写出生成黄色晶体 X 的化学方程式;

(2) 写出第二步和第三步失重的总反应方程式;

(3) 写出 “剩余气体” 在空气中由无色变为红棕色的化学方程式。

## 参考答案

5-1 由于剩余气体在空气中会由无色变为红棕色，结合 Htopca 中含有氮元素，推测剩余气体中包含 NO；由于气体首先经历了冷却，因此推测冷却前还可能包含  $H_{2}O$ 。因此混合气体的组成很可能是丙炔+NO +  $H_{2}O$ ，或者是丙炔+NO + 一种其他气体。由于剩余气体质量为原气体的 37.94%，假设全部为 NO，则有：
 $Mr(\text{剩余 }1)=(14.01+16.00)/0.3794-(14.01+16.00)=49.09\left(\mathrm{g}\mathrm{~mol}^{-1}\right)$ （1 分）再减去一分子丙炔的相对分子质量后可得：
 $Mr(\text{剩余 }2)=49.09-40.06=9.03\left(\mathrm{g}\mathrm{~mol}^{-1}\right)$ ，恰好对应于  $0.5H_{2}O$ ，符合预测故第二次失重气体为  $2C_{3}H_{4}+2NO+H_{2}O$ （2 分）

5-2（共5分）
由于 Mn 在过程中没有发生变价，因此残余固体中 Mn 应为对应价态的氧化物，即 MnO。
结合质量分数，有  $Mr(\text{剩余}) = 54.94 / 0.4617 - 54.94 - 16 = 48.06 \, (\text{g mol}^{-1})$ ，发现恰好为 4 个碳的相对质量，故残余固体的分子组成为  $MnO + 4C$ （1 分）
故 X 的相对质量  $Mr = 119.00 / (1 - 0.2109 - 0.3698 - 0.1404) = 426.66 \, (\text{g mol}^{-1})$ （1 分）
第一次失重  $M = 426.66 \times 0.2109 = 89.98 \, (\text{g mol}^{-1})$ ，对应于  $5H_{2}O$ （1 分）
第二次失重  $M = 426.66 \times 0.3698 = 157.78 \, (\text{g mol}^{-1})$ ，对应于  $2C_{3}H_{4} + 2NO + H_{2}O$
第三次失重  $M = 426.66 \times 0.1404 = 59.90 \, (\text{g mol}^{-1})$ ，对应于 2NO（1 分）
因此 X 的分子式为  $MnC_{10}H_{10}N_{4}O_{6}\cdot5H_{2}O$ ，即  $\mathrm{Mn}(\mathrm{topca})_{2}(\mathrm{H}_{2}\mathrm{O})_{5}$ （1 分）

5-3 (1) $\mathrm{MnCl}_2\cdot 4\mathrm{H}_2\mathrm{O} + 2\mathrm{Htopca} + \mathrm{H}_2\mathrm{O} = \mathrm{Mn}(\mathrm{topca})_2(\mathrm{H}_2\mathrm{O})_5 + 2\mathrm{HCl}$ （2分）(2) $\mathrm{Mn}(\mathrm{topca})_2 = 2\mathrm{C}_3\mathrm{H}_4 + 4\mathrm{NO} + \mathrm{H}_2\mathrm{O} + \mathrm{MnO} + 4\mathrm{C}$ （1分）(3) $2\mathrm{NO} + \mathrm{O}_2 = 2\mathrm{NO}_2$ （1分）
