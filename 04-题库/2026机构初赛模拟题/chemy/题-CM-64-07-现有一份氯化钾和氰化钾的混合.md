# 题-CM-64-07-现有一份氯化钾和氰化钾的混合

## 题目

### 第 7 题（6 分）

现有一份氯化钾和氰化钾的混合溶液，采用电位滴定法测定其中氯化钾和氰化钾的浓度。移

取 $25.00 ~ \mathrm { mL }$ 该混合溶液， 向其中插入银电极和双盐桥甘汞电极， 用浓度为 $0.1050 ~ \mathrm { mol / L }$ 硝酸银溶液滴定，得到的电位曲线在 $3.87 \mathrm { mL }$ ， $7.74 \mathrm { mL }$ 和 $18.34 \mathrm { mL }$ 处各有一处突跃。7-1 依次写出三次突跃前发生的化学反应方程式。
7-2 计算混合溶液中氯化钾和氯化银的浓度。

## 参考答案

## 第7题（6分）



**7-1** $Ag^{+} + 2CN^{-} = Ag(CN)_{2}^{-}$  $Ag(CN)_{2}^{-} + Ag^{+} = 2AgCN$  $Ag^{+} + Cl^{-} = AgCl$ (共3分,每式1分,顺序错误不得分)

**7-2** 计算混合溶液中氯化钾和氯化银的浓度。

**7-2** $c(KCN) = 3.25 \times 10^{-2} \text{ mol/L (1.5 分)}$  $c(KCl) = 4.45 \times 10^{-2} \text{ mol/L (1.5 分)}$
