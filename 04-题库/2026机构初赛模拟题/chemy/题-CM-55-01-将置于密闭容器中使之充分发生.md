# 题-CM-55-01-将置于密闭容器中使之充分发生

## 题目

### 第 1 题（6 分）

将 $192 \, mg \, ^{226}Ra$ 置于密闭容器中使之充分发生 $\alpha$ -衰变，反应进行 83 天，测得生成 He 的体积在 $298.2 \, K$ ， $101.3 \, kPa$ 下为 $7.46 \, mm^{3}$ 。已知 $^{226}Ra$ 发生 $\alpha$ -衰变得到的新核素会因半衰期极短而很快继续衰变，得到的最终产物为 $^{214}Pb$ 。
产物为214Pb。1-1 请写出226Ra 衰变为214Pb 的总

1-1 请写出 ${}^{226}Ra$ 衰变为 ${}^{214}Pb$ 的总反应方程式。

1-2 请计算 ${}^{226}Ra$ 的半衰期(提示：可近似认为 ${}^{226}Ra$ 的原子量等于其质量数)。

## 参考答案

第 1 题（6 分）

Ra 的总量为： $n _{ 0 } ( \mathrm { Ra } ) = m _{ 0 } / M = 8.50 \times 10^{ - 4 } \mathrm { mol }$ （1 分）
由 $\ln \{ n _{ 0 } ( \mathrm { Ra } ) / [ n _{ 0 } ( \mathrm { Ra } ) - n ^{ \prime } ( \mathrm { Ra } ) ] \} = k t$ 得： $k = 1.45 \times 10^{ - 6 } \mathrm { d }$ （1 分）
$t _{ 1 / 2 } = 1 { \bmod { } } / k = 4.79 \times 10^{ 5 } \mathrm { d }$ （1 分）
