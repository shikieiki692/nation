# 题-CM-58-05-实验室用如下方法测定朱砂样品

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy32-9-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（12 分）

实验室用如下方法测定朱砂样品中硫化汞的含量:

(1) 称取干燥好的基准氯化钠 $3.2643 \mathrm{~g}$ , 溶于水, 稀释至 $500 \mathrm{~mL}$ 。

（2）移取 25.00 mL 氯化钠溶液，加入 50.00 mL 硝酸银溶液，5 mL 硝酸和 10 滴指示剂，用 $NH_{4}SCN$ 溶液滴定至终点，消耗 23.97 mL。

（3）移取 25.00 mL 硝酸银溶液，加 5 mL 硝酸和 10 滴指示剂，用 $NH_{4}SCN$ 溶液滴定至终点，消耗 26.26 mL。

（4）称取朱砂样品 0.2846 g，加入 10 mL 硫酸和 1.5 g 硝酸钾加热溶解，待冷却后逐滴加入 $10 \, g \cdot L^{-1}$ 高锰酸钾溶液至粉红色，并煮沸至无色。

（5）加指示剂 10 滴，并用上述硫氰酸铵溶液滴定至终点，消耗 22.83 mL。

5-1 计算样品中硫化汞的含量。

5-2 写出溶解朱砂样品的化学反应方程式。

5-3 写出逐滴加入高锰酸钾溶液时发生的化学反应方程式。

5-4 写出将粉红色溶液煮沸至无色的化学反应方程式。

5-5 指出（2）中用的指示剂是什么。

## 参考答案

> 📄 校勘（2026-10-15）：答案区 OCR 吞值已按源件答案合集（第 32 届 Chemy 题目合集答案 PDF）回补 1 处（补充批次）。

第 5 题 （12 分）

5-1 $c(\mathrm{NaCl}) = 0.1117 \mathrm{mol} \cdot \mathrm{L}^{-1}$ （1 分）$c(\mathrm{NH}_{4}\mathrm{SCN}) = 0.09781 \mathrm{mol} \cdot \mathrm{L}^{-1}$ （2 分）$\omega(\mathrm{HgS}) = 91.27\%$ （2 分）

5-2 $\mathrm { HgS } + 3 \mathrm { H } _{ 2 } \mathrm { SO } _{ 4 } + 2 \mathrm { KNO } _{ 3 } = 2 \mathrm { NO } _{ 2 } + \mathrm { HgSO } _{ 4 } + 2 \mathrm { H } _{ 2 } \mathrm { O }$ + S + 2KHSO4 （2 分）还原产物写 NO 也可得分， 硫酸氢钾写硫酸钾亦可。

5-3 $5\mathrm{S} + 6\mathrm{MnO}_4^{-} + 8\mathrm{H}^{+} = 6\mathrm{Mn}^{2+} + 5\mathrm{SO}_4^{2-} + 4\mathrm{H}_2\mathrm{O}$ （2 分）

5-4 $4\mathrm{MnO}_4^{-} + 12\mathrm{H}^{+} = 4\mathrm{Mn}^{2+} + 5\mathrm{O}_2 + 6\mathrm{H}_2\mathrm{O}$ （2 分）

5-5 硫酸铁铵 （三氯化铁、 硝酸铁等铁盐也正确）（1 分）
