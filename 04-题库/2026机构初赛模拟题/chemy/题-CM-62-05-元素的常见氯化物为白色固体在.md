# 题-CM-62-05-元素的常见氯化物为白色固体在

## 题目

### 第 5 题（10 分）

元素 $\pmb { x }$ 的常见氯化物 $\pmb { \mathsf { A } }$ 为白色固体， 在室温下以二聚体的形式存在。A 空气中暴露会水解发烟。将 $\pmb { \mathsf { A } }$ 与 $\pmb { x }$ 单质按摩尔比混合加热反应，或将 $\pmb { x }$ 单质与 $\mathrm { Hg } \mathrm { Cl } _{ 2 }$ 反应，可制得抗磁性化合物B，B 与氯化四甲基铵在有机溶剂中反应，可析出盐C；C 的阴离子双核阴离子，具有$C _{ 3 }$ 轴。元素 $\pmb { \ Y }$ 的氧化物D 为白色粉末，曾被用作投毒争夺遗产，因此又被称为“遗产粉”，但 D 同样有抗白血病的活性，将含 $\yen 46.0 \%$ 的矿石 E 隔绝空气热解，得到 Y 单质和黑色残渣F；将F 投入盐酸中，放出臭鸡蛋味气体 $\pmb { 6 }$ 。将 $\pmb { x }$ 、Y 单质分别放置在一真空石英管的两侧，逐渐升温，可在 $\pmb { x }$ 单质一侧生成具有独特的电学性质的闪锌矿型材料H，H 中含 $\times 48.2 \%$ 。

5-1 请写出 $\pmb { \mathsf { A } } \sim \pmb { \mathsf { H } }$ 的化学式。
5-2 化合物B 和C 中 $\pmb { x }$ 元素氧化态是否相同？简要说明之。
5-3 画出C 阴离子镜面最多的构象结构。

## 参考答案

第5题（10分）

<table><tr><td colspan="2">5-1 A GaCl3(或 Ga2Cl6)</td><td>B GaCl2</td><td>C [N(CH3)4]2[Ga2Cl6]</td><td>D As2O3</td></tr><tr><td>E FeAsS</td><td>F FeS</td><td>G H2S</td><td>H GaAs(每个1分)</td><td></td></tr></table>



**5-2** B的结构可描述为 $[Ga]^{+}[GaCl_{4}]^{-}$ ,为+1和+3氧化态;而C中Ga(II)单电子配对形成Ga-Ga金属键,从而得到稳定的+2氧化态。(1分)

指出区别并稍作描述,即可得分。
