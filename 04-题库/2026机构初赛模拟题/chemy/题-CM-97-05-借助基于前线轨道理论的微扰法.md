# 题-CM-97-05-借助基于前线轨道理论的微扰法

## 题目

### 第 5 题（12 分）

借助基于前线轨道理论的微扰法，我们可以通过分析简单分子片段的作用模式，解读一些复杂分子的结构。

最经典的微扰分析是，在化学反应的过程中，分子通过某种方式使得部分原子相互靠近，进而使得某些分子轨道的能级发生同相或异相重叠，进而发生能级的改变。例如，己三烯若脱氢变成苯的过程中，若仅考虑两端自由基连接成键的过程， $\pi$ 分子轨道同时也会受到微扰，其中 $\Psi_{1}$ 、 $\Psi_{3}$ 与 $\Psi_{5}$ 连接过程中同相重叠，能量降低，而 $\Psi_{2}$ 、 $\Psi_{4}$ 与 $\Psi_{6}$ 在重叠过程中异相重叠，能量升高。环己三烯在变为苯的过程中， $\pi$ -HOMO 能量降低，总能量也降低，因此体系更加稳定。微扰分析的另一个经典例子是，CN-的 HOMO 为 $\sigma$ 型轨道，主要位于 C 上，次要位于 N 上，因此，CN-更倾向于由 C 端外侧与亲电试剂成键，形成直线型 HCN 结构。

5-1 请利用微扰法解释 $SOCl_{2}$ 与 $S_{2}Cl_{2}$ 的结构差异。

5-2 某些具有不寻常多中心键的结构也能够以此解释。

5-2-1 试分析 $I_{2}^{+}$ 的聚合方式。

5-2-2 根据你的分析，预测 $S_{2}I_{4}^{2+}$ 的结构。

5-2-3 $\mathrm{S}_2\mathrm{I}_4^{2+}$ 存在一种可能的经典结构，若 $\mathrm{S}_2$ 与 $\mathrm{I}_2$ 的电离能相似，解释为何该经典结构没有形成。

5-3 $S_{4}N_{4}$ 可以视为通过平面结构的畸变形成了闭壳层稳定结构。

5-3-1 若仅考虑几个高能轨道的畸变, 试分析畸变前后分子中前线轨道(HOMO 与 LUMO)的作用方式, 画图示出哪个轨道在畸变过程中发生了何种有效重叠。

5-3-2 画出作用前后的轨道能级相关图。(类似于分子轨道-原子轨道的能级相关图)
