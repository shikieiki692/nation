# 题-CM-146-07-钼的某种三元化合物X的晶体结

## 题目

### 第 7 题（10 分）

钼的某种三元化合物 X 的晶体结构如下图所示。X 中包含 Mo、Br、O 三种元素，其中最小的球代表氧。X 的晶胞参数为 a = b = 1136 pm，c = 395 pm， $\alpha = \beta = \gamma = 90^{\circ}$ 。

![](images/491d42284959386d158e808dbc99d3cbfdffee0b9dff9ba559e07278e4b1b6f4.jpg)

7-1 写出 X 的化学式。

7-2 指出 X 晶体的点阵型式和结构基元。

7-3 已知其中一个氧原子的坐标为(0.1099, 0.1099, 0.5000)，写出晶体中其余氧原子的坐标。

7-4 钼单质的晶体密度为 $10.2 \, g/cm^{3}$ ，属于体心立方点阵。

7-4-1 计算钼单质晶体中 Mo-Mo 的最小距离。

7-4-2 假设 X 晶体中 Mo-O-Mo 键角为 $180^{\circ}$ ，试通过计算说明 X 中是否存在 Mo-Mo 键。

7-5 指出 X 晶体的特征对称元素。

有机化学中可能用到的缩写：DCM: 二氯甲烷；2,6-lutidine: 2,6-二甲基吡啶；NBS: N-溴代琥珀酰亚胺；NIS: N-碘代琥珀酰亚胺；TFAA: 三氟乙酸酐；DMAP: 对二甲氨基吡啶；DMF: N,N-二甲基甲酰胺。
