# 题-CM-48-01-11掺杂一些特定元素的铜氧化

## 题目

### 第 1 题 铜的配位化学（11 分，占 6%）

1-1 掺杂一些特定元素的铜氧化物常被用作高温超导材料， 铜锶铜氧一 $\scriptstyle \mathrm{La}_{2-x}\mathrm{Sr}_x\mathrm{CuO}_4$ (LSCO) 的单胞结构如右图所示， 具有典型的钙钛矿结构。 己知 $c$ 轴方向上 $\mathbf { Cu - O }$ 之间的距离大於 $\mathrm{Cu\!-\!O}$ 轴和 $b$ 轴方向上 $\mathrm{Cu\!-\!O}$ 之间的距离， 画出 LSCO中 $\mathbf { Cu ^{ 2 + } } d$ 轨道的简并和电子填充情况。

![](images/fc1b63e972a21745c2aca37bdaf580637899ef11a0958b42e0aed7359fe87393.jpg)

1-2 过渡金属离子M（ $\mathbf { M } = \mathbf { C } \mathbf { u } ^{ 2 \ast }$ 或 $\mathrm{Zn^{2+}}$ ) 可与席夫碱H2L 反应生成单核配合物 ML, ML 又可作为配体通过 $\mu _{ 2 }$ -酚氧桥联其他 M形成多核配合物。 L2-的结构如下图所示：

![](images/95f73068868e432292883a6fd8095b862d0beab8c61c290c7290547278203ae4.jpg)

1-2-1 已知高氯酸铜与ZnL 反应形成多核配合物 $[\mathrm{Cu(ZnL)_n}](\mathrm{ClO_4})_2$ i 其中的配离子存在一对旋光异构$\#$ . 画出该配离子的结构。

1-2-2 计算上述配离子的理论磁矩 （玻尔磁子用 $\mu _{ 0 }$ 表示）。

1-3 两个平面型 $\mathrm{Cu(\mu\text{-}OH)_2Cu}$ 双核铜簇骼单元 （结构如下图所示） 可通过四个 $\mathrm{Cu\!-\!O(H)}$ 键形成立方烷型 $\mathbf { Cu } _{ 4 } ( \mu _{ 3 } .01 ) _{ 4 }$ 四核铜簇骼单元 $\mathbf { A }$ . 也可通过 ${ \bf c _{ u - O ( H ) } }$ 键二聚形成阶梯型 $\mathrm{Cu_4}(\mu_2\text{-}\mathrm{OH})_2(\mu_3\text{-}\mathrm{OH})_2$ 四核铜簇骼单元B。 以上述两种方式继续组装， 可以得到具有更多核数的簇骼单元。

![](images/c50665bc4f2bed2d7f618e977cbe6b05965b6fc1bc1a40cd7c7cdba58682a7d0.jpg)

1-3-1 画出A和B的结构。

1-3-2 以碱式碳酸铜、 2,2'-联吡啶 (bpy) 与己二酸 - $\mathbf { \tilde { C } _{ 6 } H _{ 10 } O _{ 4 } } .$ ) 反应， 可以得到含有阶梯型六核铜簇骼单元的配合物 $\mathrm { [ Cu _{ 6 } ( OH ) _{ 6 } ( bpy ) _{ 6 } ( H _{ 2 } O ) _{ 2 } ] ( C _{ 6 } H _{ 8 } O _{ 4 } ) _{ 3 } \cdot 23 H _{ 2 } O }$ 其中的配离子呈中心对称， 每个铜离子均处于 $\mathbf { CuN _{ 2 } O _{ 3 } }$ 四方锥配位环境中。 画出该配离子的结构。 （用 $\vartriangle { \ v { N } } \sqrt { \ v { S } }$ 代表bpy配体）
