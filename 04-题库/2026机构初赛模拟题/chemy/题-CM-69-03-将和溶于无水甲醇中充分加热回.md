# 题-CM-69-03-将和溶于无水甲醇中充分加热回

## 题目

### 第 3 题（10 分）

将 $\mathrm { { Ni ( CO ) _{ 4 } } }$ 和 $\mathrm { P } ( \mathrm { C } _{ 2 } \mathrm { H } _{ 4 } \mathrm { CN } ) _{ 3 }$ 溶于无水甲醇中， 充分加热回流反应，得到一种橙色晶体。该晶体为四核配合物，其化学式为 $\mathrm { Ni _{ 4 } ( CO ) _{ \boldsymbol { x } } [ P ( C _{ 2 } H _{ 4 } CN ) _{ 3 } ] _{ \boldsymbol { y } } }$ ，其中碳和氢的质量分数分别为 $42.91 \%$ 和 $4.12 \%$ 。

3-1 请通过计算确定该配合物中 $x$ 和 $y$ 的数值。
3-2 设此配合物满足EAN 规则，镍仅有一种化学环境，请画出其结构示意图。
3-3 配体 $\mathrm { P } ( \mathrm { C } _{ 2 } \mathrm { H } _{ 4 } \mathrm { CN } ) _{ 3 }$ 可以以一种有毒气体为原料，通过一步反应直接制备，无小分子产物
生成。 写出反应方程式。
3-4 该反应伴随着副反应， 使得烧瓶内壁有银白色铁磁性固体析出。 写出反应方程式。

## 参考答案

第3题（10分）

3-1 由 $M = 58.69 \times 4 + 28.01x + 193.2y$ $12.01(x + 9y) = M \times 42.91\%$ $1.008 \times 12y = M \times 4.12\%$
解得 $x = 6, y = 4$ （共3分）

(3 分)
![](images/9e3cb1a12bb061582003ef99f5d59c4a06f4517e1fe2e7c6252d64d7ad8f8d83.jpg)

$$
\mathrm{PH} _ {3} + 3 \mathrm{CH} _ {2} = \mathrm{CHCN} = \mathrm{P} (\mathrm{C} _ {2} \mathrm{H} _ {4} \mathrm{CN}) _ {3} (2 \text {分})
\mathrm{Ni} (\mathrm{CO}) _ {4} = \mathrm{Ni} + 4 \mathrm{CO}
\mathrm{Ni} _ {4} (\mathrm{CO}) _ {6} \left(\mathrm{P} \left(\mathrm{C} _ {2} \mathrm{H} _ {4} \mathrm{CN}\right) _ {3}\right) _ {4}
$$
