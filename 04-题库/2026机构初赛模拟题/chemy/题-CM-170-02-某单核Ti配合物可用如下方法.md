# 题-CM-170-02-某单核Ti配合物可用如下方法

## 题目

### 第 2 题 15 分， $11 \%$

某单核Ti 配合物可用如下方法制备：

![](images/bf12b927ac4fea9d030977ca838f8bef12e52703ee10872eb2d1ecacdf214490.jpg)

2-1-1 经测量得 $\pmb { x }$ 在 $300 \mathrm { K }$ 时的实际磁矩为 $2.72 \mu _{ \mathrm { B } }$ ， 据此判断Ti 的氧化态画出 X 的结构(不要求形式电荷， 下同)。
得X 在300 K 时的实际磁矩为2.72 μB，据此

2-1-2 把 1 中的 Tl 换成 K 与 ${ \mathrm { TiCl } } _{ 3 } ( { \mathrm { THF } } ) _{ 3 }$ 反应依然可以得到 A。众所周知Tl 盐有着很强的毒
性，那么为何还是要使用1 来制备A？
由于其特殊的氧化态，X 具有特别的反应性：

![](images/8a7fa2a3a96dededf7a2db5cc9ba9747e00646bd255fe34fd33e4a8283ebb471.jpg)

2-2 画出反应的产物B、 C、 D 的结构。

2-3 有趣的是， 若在 `{ \bf N } _{ 2 }` 气氛中在THF 溶剂里用 $\mathrm { KC } _{ 8 }$ 去还原 A， 可得到含Cl 的配合物E。E同样可以在相同条件下同 $\mathrm { N } _{ 2 } \mathrm { O }$ 反应， 生成 B 与 $\mathbf { N } _{ 2 }$ 。E 中 N 元素的质量分数为 $18.83 \%$ ， 画出E 的结构。

## 第2题（13分， $11\%$ ）

![](images/3ba1b57b48e945405dabd32c68b46c74f1a4483e64dfb1dd81616809e04bdb8c.jpg)

2-1-1 理论磁矩的计算公式 $\mu = \sqrt{n(n+2)}$ （1分）

将 $n=1,2,3,\ldots$ 依次代入发现 n=1 时， $\mu=1.73\mu_{B}$ ; n=2 时， $\mu=2.83\mu_{B}$ ; n=3 时， $\mu=3.87\mu_{B}\ldots$

可以发现 n = 2 时最接近实际值，所以 Ti 的氧化态为 +2 价（1 分）

X 的结构如下:

![](images/34e1a43a79655e9faacef54568291181fa38df66c69cb53cdec3c08c4509aea6.jpg)

2-1-2 1 与 $TiCl_{3}(THF)_{3}$ 反应生成 A 的同时生成了难溶的 TlCl 推动了平衡，能够进一步提高产率（1 分）

事实上用钾盐反应生成 A 的产率很低，T1 的半径与 K 相似，同时又可以形成难溶于 THF 的 T1Cl(KCl 在 THF 里也有一定溶解度)，这两点或许是使用 1 作为反应底物的最重要原因。
