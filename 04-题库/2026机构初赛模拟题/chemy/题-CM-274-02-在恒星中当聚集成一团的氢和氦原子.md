# 题-CM-274-02-在恒星中当聚集成一团的氢和氦原子

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-4-2`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（8 分）

在恒星中，当聚集成一团的氢和氦原子的温度达到 10<sup>7</sup> K 时，就会发生一连串的热核反应。其中一个反应是四个质子聚合为一个氦核的反应，总反应为 4<sup>1</sup>H = <sup>4</sup>He + 2e<sup>+</sup> + 2ν<sub>e</sub>，这个反应经过了 <sup>2</sup>H、<sup>3</sup>He 两个中间体，最后一步为两个 <sup>3</sup>He 的核反应。已知：A(<sup>1</sup>H) = 1.007825，A(<sup>2</sup>H) = 2.01410，A(<sup>3</sup>He) = 3.01603，A(<sup>4</sup>He) = 4.002603，A(e) = 0.000549。c = 2.9979 × 10<sup>8</sup> m·s<sup>-1</sup>，e = 1.6022 × 10<sup>-19</sup> C，N<sub>A</sub> = 6.0221 × 10<sup>23</sup>，h = 6.626 × 10<sup>-34</sup> J·s。

**2-1** 写出三步的核反应方程式，已知电子中微子伴随着正电子生成。

**2-2** 假设两个电子中微子各带走了 0.25 MeV 的能量，其余能量以辐射的形式放出，求出总反应辐射的总能量。

**2-3** 在某些恒星中，这一反应可以被碳、氮、氧三种元素的同位素循环催化。已知：催化循环的第一步和最后一步分别为 <sup>12</sup>C 与质子的反应和 <sup>15</sup>N 与质子的反应，第二步和第五步是两

![](images/8bc9983a5a729c0d49a6f34062062cd6e3c8b8fd5bbe334e4c44aa1b5446b1d1.jpg)

**2-3-2** 你认为什么样的恒星中会存在这种催化循环，说明理由。

**2-4** 如果一对正负电子发生湮灭，会放出的能量是多少？如果能量通过一对光子放出，光子的波长是多少？

## 参考答案

**2-1** <sup>1</sup>H + <sup>1</sup>H = <sup>2</sup>H + e<sup>+</sup> + ν<sub>e</sub>（0.5 分）

<sup>2</sup>H + <sup>1</sup>H = <sup>3</sup>He（0.5 分）

<sup>3</sup>He + <sup>3</sup>He = <sup>4</sup>He + 2<sup>1</sup>H（0.5 分）

![](images/ea4c7d3455bca0c6c070471e83dbb9d873a8236cc19bee02bf56580f932e2200.jpg)

注意：只有总反应需要考虑中微子带走的能量，因为计算的是各步反应的能量变化，而不

是辐射的能量。

**2-3-1** <sup>12</sup>C + <sup>1</sup>H → <sup>13</sup>N

<sup>13</sup>N → <sup>13</sup>C + e<sup>+</sup> + ν<sub>e</sub>

<sup>13</sup>C + <sup>1</sup>H → <sup>14</sup>N

<sup>14</sup>N + <sup>1</sup>H → <sup>15</sup>O

<sup>15</sup>O → <sup>15</sup>N + e<sup>+</sup> + ν<sub>e</sub>

<sup>15</sup>N + <sup>1</sup>H → <sup>12</sup>C + <sup>4</sup>He（2 分）

**2-3-2** 通过旧恒星残留下的元素形成的恒星，这样的恒星中存在较多的较重元素(例如太

阳)（1 分）

**2-4** ΔE = 1.023 MeV（1 分）

波长为 2.42 pm（1 分）
