# 题-CM-62-03-金属与硫能形成多种多样的团簇

## 题目

### 第 3 题（7 分）

金属与硫能形成多种多样的团簇结构，这些团簇以其特殊的结构和性质而备受无机合成化学家关注。第一个成功合成的银硫属团簇的化合物是 $( \mathrm { H _{ 3 } O ) _{ 2 } Ag _{ 10 } ( PyS ) _{ 8 } ( HPyS ) _{ 4 } ( Hmba ) _{ 4 } \cdot 2 H _{ 2 } O }$ ，其中存在 $[ \mathrm { Ag _{ 10 } ( PyS ) _{ 8 } ( HPyS ) _{ 4 } ( Hmba ) _{ 4 } } ] ^{ 2 - }$ 银硫属阴离子团簇 $( \mathrm { Py } \mathrm { S } ^{ - }$ 为吡啶-4-硫醇盐， $\mathrm { { HPyS } }$ 为1H-吡啶-4-硫酮， $\mathrm { \ H _{ 2 } mba }$ 为2-巯基苯甲酸)。该团簇中， $\mathbf { A } \mathbf { g }$ 和 S 通过共价键构建出类似于立方 $Z \mathrm { nS }$ 网络的“超四面体”结构， 整个团簇中具有一根 $S _{ 4 }$ 轴。

3-1 银硫属团簇相比于其他金属硫团簇而言较难合成， 为什么？ 指出可能的原因。

3-2 比较 $\mathrm { PhS ^{ - } }$ 、 PhSH、 $\mathrm { Py } \mathrm { S } ^{ - }$ 和 $\mathrm { { HPyS } }$ 与 $\mathbf { A } \mathbf { g } ^{ + }$ 配位的能力。

3-3 在 $[ \mathrm { Ag _{ 10 } ( PyS ) _{ 8 } ( HPyS ) _{ 4 } ( Hmba ) _{ 4 } } ] ^{ 2 - }$ 中， $\mathbf { A } \mathbf { g }$ 有几种化学环境？ 说明各化学环境的 Ag 的配位情况及其数目比。

## 参考答案

## 第3题（7分）

3-3 Ag 有三种化学环境（1 分）。
不妨用 S1、S2 和 S3 分别代表  $PyS^{-}$ 、HPyS 和  $Hmba^{-}$ ，则三种环境分别为：
 $2S1 + S3$ ;  $2S2 + 2S3$ ;  $2S1 + 2S2$ （2 分）
数量比为 2:1:2（1 分）
S2 和 S3 交换位置也可得分。
