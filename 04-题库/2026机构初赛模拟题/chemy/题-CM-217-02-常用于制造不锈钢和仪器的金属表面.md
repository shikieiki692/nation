# 题-CM-217-02-常用于制造不锈钢和仪器的金属表面

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-7-2`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（8 分）

![](images/a4dc6f726a311c86bcf76a63dbffe5cac06a08f21daa6de159b03a5ff70e841a.jpg)

常用于制造不锈钢和仪器的金属表面镀铬。工业上制备铬单质从铬铁矿(FeCr<sub>2</sub>O<sub>4</sub>)出发，将其与碳酸钠的混合物在空气中强加热，其中铁转化成三氧化二铁(反应 1)。将反应后的固体残渣用水浸取，酸化，析出含铬的钠盐。使该盐与碳在高温下共热还原为铬氧化物，同时生成一种盐并放出气体(反应 2)。最后，用金属铝点燃处理便可得较纯的铬(反应 3)。

对于与铬同族的钼的提取，通常是以辉钼矿作为原料，在氧气下焙烧(反应 4)，所得产物用氨水浸出，使钼转移至溶液中；或者，使辉钼矿在氧气气氛中与苛性钠溶液反应，也可使钼转移到溶液中(反应 5)，该过程中硫也氧化而进入溶液。随后将氨水浸出的溶液酸化，析出一种阴离子含有七个钼的同多酸盐(反应 6)，之后经焙解、氢气还原，便可得较纯的金属钼。

写出反应 1~反应 6 的方程式(要求系数比为最简整数比)。

## 参考答案

方程式 1：4FeCr<sub>2</sub>O<sub>4</sub> + 8Na<sub>2</sub>CO<sub>3</sub> + 7O<sub>2</sub> = 2Fe<sub>2</sub>O<sub>3</sub> + 8Na<sub>2</sub>CrO<sub>4</sub> + 8CO<sub>2</sub>（1.5 分）

方程式 2：Na<sub>2</sub>Cr<sub>2</sub>O<sub>7</sub> + 2C = Cr<sub>2</sub>O<sub>3</sub> + Na<sub>2</sub>CO<sub>3</sub> + CO（1.5 分）

产物写 CO<sub>2</sub>，配平，可得 1 分。

方程式 3：Cr<sub>2</sub>O<sub>3</sub> + 2Al = 2Cr + Al<sub>2</sub>O<sub>3</sub>（1 分）

方程式 4：2MoS<sub>2</sub> + 7O<sub>2</sub> = 2MoO<sub>3</sub> + 4SO<sub>2</sub>（1 分）<sub> </sub>

方程式 5：2MoS<sub>2</sub> + 9O<sub>2</sub> + 12NaOH = 2Na<sub>2</sub>MoO<sub>4 </sub>+ 4Na<sub>2</sub>SO<sub>4</sub> + 6H<sub>2</sub>O（1.5 分）

氧化产物写 Na<sub>2</sub>SO<sub>3</sub>，不得分。

方程式 6：7MoO<sub>4</sub><sup>2-</sup> + 8H<sup>+</sup> + 6NH<sub>4</sub><sup>+</sup> = (NH<sub>4</sub>)<sub>6</sub>Mo<sub>7</sub>O<sub>24</sub> + 4H<sub>2</sub>O（1.5 分）
