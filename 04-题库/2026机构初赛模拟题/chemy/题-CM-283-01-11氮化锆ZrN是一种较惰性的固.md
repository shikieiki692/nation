# 题-CM-283-01-11氮化锆ZrN是一种较惰性的固

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-13-1`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（10 分）

**1-1** 氮化锆(ZrN)是一种较惰性的固体材料，但可溶于热的浓硫酸生成 Zr(SO4)2，溶解过程中放出单质气体。

**1-2** 在氮气气氛下，将 B<sub>2</sub>O<sub>3</sub>和 CaB<sub>6</sub>的混合固体共热，仅生成了两种二元化合物，其中一种可用作耐磨损材料。

**1-3** 用 0.1 mol/L 稀盐酸处理 Tb<sub>4</sub>O<sub>7</sub>，可制得纯净的 TbO<sub>2</sub>。

**1-4** 将磁铁矿投入过量的 K<sub>2</sub>Cr<sub>2</sub>O<sub>7</sub>-H<sub>2</sub>SO<sub>4</sub>溶液中使之溶解。

**1-5** 在碱性溶液中，硫化镍与一氧化碳以摩尔比 1:5 定量反应。

## 参考答案

**1-1** 2ZrN + 3H<sub>2</sub>SO<sub>4</sub> + 2H<sub>2</sub>O = 2ZrOSO<sub>4</sub> + H<sub>2</sub> + (NH<sub>4</sub>)<sub>2</sub>SO<sub>4</sub>（2 分）

**1-2** 3CaB<sub>6</sub> + B<sub>2</sub>O<sub>3</sub> + 10N<sub>2</sub> = 3CaO + 20BN（2 分）

**1-3** Tb<sub>4</sub>O<sub>7</sub> + 6HCl = 2TbCl<sub>3</sub> + 2TbO<sub>2</sub> + 3H<sub>2</sub>O（2 分）

**1-4** 2K<sub>2</sub>Cr<sub>2</sub>O<sub>7</sub> + 36Fe<sub>3</sub>O<sub>4</sub> + 62H<sub>2</sub>SO<sub>4</sub> = 2K<sub>2</sub>SO<sub>4</sub> + 18Fe<sub>2</sub>(SO<sub>4</sub>)<sub>3</sub> + 2Cr<sub>2</sub>(SO<sub>4</sub>)<sub>3</sub> + 31H<sub>2</sub>O（2 分）

**1-5** NiS + 5CO + 4OH<sup>−</sup> = Ni(CO)<sub>4</sub> + CO<sub>3</sub><sup>2−</sup> + S<sup>2−</sup> + 2 H<sub>2</sub>O（2 分）
