# 题-CM-210-02-采用电解法可测定阿伏伽德罗常数N

## 题目

### 第 2 题（17 分，占 None%）

采用电解法可测定阿伏伽德罗常数 N<sub>A</sub>与气体常数 R 的大小，步骤如下所示：

(1) 洗净一支 50 mL 酸式滴定管，把滴定管倒夹在滴定管夹上，打开活塞，控干管内的水；

![](images/5f6310260938bc8df3804543acaa8b82a59a1e27a65b63e311b847d5969e82c5.jpg)

对应的滴定管刻度为 21.90 mL。 <sup>8-电阻箱，9-开关，10-恒压电源 </sup>

**2-1** 填写(1)-(3)中的数字或文字。

**2-2** 已知电解过程中的温度始终为 294.15 K，此时溶液的饱和蒸汽压为 2487.7 Pa，大气压为102180 Pa，电解溶液的密度按 1.00 g/cm<sup>3</sup>计。视产生的气体为理想气体，通过计算与分析，给出上述实验测定的 N<sub>A</sub>与 R 的值。

**2-3** 回答下列有关步骤 1~3 中操作的问题：

**2-3-1** 步骤 1 能否改为：用 25 mL 容量瓶取 25.00 mL 去离子水后，将容量瓶中的水全部倒入 50 mL 滴定管中？解释原因。

**2-3-2** 若没有进行步骤 2 中的操作，则测得的 N<sub>A</sub>( )，R( )。(a) 偏大； (b) 偏小； (c) 不变。

**2-3-3** 若没有进行步骤 3 中的操作，则测得的 N<sub>A</sub>( )，R( )。(a) 偏大； (b) 偏小； (c) 不变。

## 参考答案

**2-1** (1)：3.25；(2)：阴；(3)：阳（各 1 分，共 3 分）

**2-2**（共 8 分）由电解前后铜片的质量，可知电解后析出的 Cu 的物质的量 n(Cu)为：

n(Cu) = Δm(Cu)/M(Cu) = (20.6143 - 20.4561) / 63.55 = 2.489×10<sup>-3</sup> mol

由电解电流 I = 190 mA，电解时间 t = 2539 s，可知电解过程中转移的电子数 N(e<sup>-</sup>)为：

N(e<sup>-</sup>) = It/e = (0.190 × 2539) / (1.60×10<sup>-19</sup>) = 3.01×10<sup>21</sup>在阴极发生的反应为：Cu<sup>2+</sup> + 2e<sup>-</sup> = Cu（1 分），故上述实验测得的 N<sub>A</sub>的值为：

N<sub>A</sub> = N(e<sup>-</sup>)/2n(Cu) = (3.01×10<sup>21</sup>) / (2×2.489×10<sup>-3</sup>) = 6.05×10<sup>23 </sup>mol<sup>-1</sup>（3 分）电解过程中产生的 O<sub>2</sub>的压力 p(O<sub>2</sub>)为：

p(O<sub>2</sub>) = p(大气) - p(蒸汽压) - ρgh = 102180 - 2487.7 -(1.00×9.80×29.2×10) = 9.683×10<sup>4</sup> Pa（1

分）电解过程中产生气体的体积 V 为：

V = V(总) + V(无刻度) - V(末) = 50.00 + 3.25 - 21.90 = 31.35 mL（1 分）在阳极发生的反应为：2H<sub>2</sub>O - 4e<sup>- </sup>=<sup> </sup>O<sub>2</sub> + 4H<sup>+</sup>（1 分），则产生的氧气的物质的量 n(O<sub>2</sub>)为：

n(O<sub>2</sub>) = n(Cu)/2 = (2.489×10<sup>-3</sup>) / 2 = 1.245×10<sup>-3</sup>mol根据理想气体状态方程 p(O<sub>2</sub>)V = n(O<sub>2</sub>)RT，可知上述实验测得的 R 的值为：R = p(O<sub>2</sub>)V/n(O<sub>2</sub>)T = (9.683×10<sup>4</sup>×31.35×10<sup>-3</sup>) / (1.245×10<sup>-3</sup>×294.15) = 8.291 J·K<sup>-1</sup>·mol<sup>-1</sup>（1 分）N<sub>A</sub>的有效数字应为三位，R 的有效数字为三位或四位皆可，有效数字不正确共扣 1 分。

**2-3-1** 不能（1 分）；容量瓶是量入式仪器，量出体积不准确（1 分）

**2-3-2** (a)，(a)（各 1 分，共 2 分）

**2-3-3** (c)，(a)（各 1 分，共 2 分）
