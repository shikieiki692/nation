# 题-CM-165-02-顾名思义超酸是一类酸度极强的

第 2 题（21 分， 占比 14 \% ） 超酸体系中的新奇物种

顾名思义，超酸是一类酸度极强的酸，其共轭碱往往具有电荷高度分散的特征， 因此与质子亲和力弱。

2-1 超酸中的质子往往都不是裸露的。以HF/SbF5 体系为例，已分离出了化学式为 \mathrm { H } _{ 3 } \mathrm { Sb } _{ 2 } \mathrm { F } _{ 13 } (未表示出组成)的化合物，其结构可视为阴阳离子通过氢键 ( 1 \ \mathrm { mol } \ \mathrm { H } _{ 3 } \mathrm { Sb } _{ 2 } \mathrm { F } _{ 13 } 中含有 3 ~ \mathrm { mol } 氢键)形成了一维长链，阴阳离子均具有对称中心。 画出一维长链的示意图。

2-2 衡量超酸酸性的一般方法是向超酸中加入一种弱碱性的指示分子(B)， 通过光谱等手段检测 \mathrm { HB ^{ + } } 与B 的浓度比，进而得到Hammett 酸度 H _{ 0 } ( K _{ \mathrm { HB ^{ + } } } 为HB+的酸解离常数，是已知量)：

$$
H _{ 0 } = \mathrm { p } K _{ \mathrm { HB ^{ + } } } - \mathrm { lg } ( \mathrm { [ HB ^{ + } ] / \left[ B \right] ) }
$$

2-2-1 以吸光光度法为例，假设 B 的分析浓度为 c _{ 0 } ， \mathrm { HB ^{ + } } 和B 的摩尔消光系数分别为 \varepsilon ( \mathrm { HB ^{ + } } ) 和 \varepsilon ( \mathbf { B } ) ， 实验所用光路光程为 l，用上述参数及实验测得吸光度 A 表示 H _{ 0 } 。

$$
[ \mathrm{HB} ^{+} ] = [ A - \varepsilon (\mathrm{B}) c _{0} l ] / [ \varepsilon (\mathrm{HB} ^{+}) l - \varepsilon (\mathrm{B}) l ] \quad [ \mathrm{B} ] = [ A - \varepsilon (\mathrm{HB} ^{+}) c _{0} l ] / [ \varepsilon (\mathrm{B}) l - \varepsilon (\mathrm{HB} ^{+}) l ]
H _{0} = \mathrm{p} K _{\mathrm{HB} ^{+}} - \lg [ A - \varepsilon (\mathrm{B}) c _{0} l / \varepsilon (\mathrm{HB} ^{+}) c _{0} l - A ]
$$
