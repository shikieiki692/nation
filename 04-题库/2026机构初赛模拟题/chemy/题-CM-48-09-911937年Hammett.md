### 第 9 题 取代基效应（16 分，占 8%）

9-1 1937年， Hammett 发现苯甲酸在水中的解离平衡受到其间位 $( m - )$ 或对位 [] $\rho$ ) 取代基 $\pmb { x }$ 的影响（平衡常数为 $\kappa _{ \mathrm { x } }$ )。为了定量衡量取代基效应， Hammett 定义了取代基常数 ${ \pmb \sigma } _{ \pmb X }$ . 如下图中公式所示。若 $\sigma_{\mathrm{X}}$ 小于0， 说明取代基为给电子基团： 若 ${ \pmb \sigma } _{ \pmb X }$ 大于0， 说明取代基为吸电子基团。 ${ \pmb \sigma } _{ \pmb X }$ 绝对值的大小表示取代基给电子或吸电子能力的强弱。

$$
x \xrightarrow [ ] { 0 } \int \limits _{ 0 } ^{ 0 } d t + H _{ 2 } 0 \xrightarrow [ 25^{ 0 } C ] { K _{ x } } x \xrightarrow [ ] { 0 } \int \limits _{ 0 } ^{ 1 } d t + H _{ 3 } 0^{ + }
$$

$$
\sigma _{ \mathrm { X } } = \log { \frac { K _{ \mathrm { X } } } { K _{ \mathrm { H } } } }
$$
