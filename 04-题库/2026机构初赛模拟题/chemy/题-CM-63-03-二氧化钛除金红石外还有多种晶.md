# 题-CM-63-03-二氧化钛除金红石外还有多种晶

## 题目

### 第 3 题（10 分）

二氧化钛除金红石外还有多种晶型， 如锐钛矿、板钛矿等。锐钛矿为四方晶系的晶体，在低温下稳定，在 $800^{ \circ } \mathrm { C }$
稳定，在800°C 以上转化为金红石。下图为锐钛矿的晶胞示意图：

3-1 指出晶胞中所含钛原子的数目 $x$ 和氧原子的数目 $y _{ i }$ 。
3-2 指出钛原子的配位数 $\mathbf { \nabla } _{ m }$ 和氧原子的配位数 $n$ 。
3-3 该晶体中，钛有几种化学环境？氧有几种化学环境？
3-4 在上述晶体中，两种Ti-O 键长分别为 $d _{ 1 } ( \mathrm { Ti - O } ) = 187.4 ~ \mathrm { pm }$ ， $d _{ 2 } ( \mathrm { Ti - O } ) = 192.3 ~ \mathrm { pm }$ ， Ti-O-
Ti 键角为 $151.80^{ \circ }$ ，晶胞参数 $a = 373.0 \mathrm { pm }$ 。
3-4-1 键长为 $187.4 \mathrm { pm }$ 的 Ti-O 键是哪些 Ti-O 键？
3-4-2 计算该晶体的晶胞参数 $\boldsymbol { c }$ 。
3-4-3 计算该晶体的密度。
3-5 以下关于锐钛矿与金红石的比较， 正确的说法有： (金红石的密度为 $4.25 ~ \mathrm { g } / \mathrm { cm } ^{ 3 } )$ (d)
a)高压条件有利于锐钛矿向金红石转化；

b)金红石转化为锐钛矿是吸热反应；
c)用相同波长的X 射线穿过等厚度的锐钛矿和金红石， 金红石对X 射线的吸收比例更大。

## 参考答案

第3题（10分）

![](images/50a973e15d3a96b05e7ebb28c2ea4ecc91fcae3fe8968b040133d6feaa03f14a.jpg)


3-1 x = 4 y = 8（每个 0.5 分）

3-2 m = 6 n = 3（每个 0.5 分）

3-3 1 种化学环境的 Ti 和 1 种化学环境的 O（每个 1 分）

3-4-1 是在 c 轴方向的 Ti-O 键（1 分）

3-4-2  $c = 4 \times 187.4 \text{ pm} + 4 \times 192.3 \text{ pm} \times \cos(151.8/2) = 937.0 \text{ pm}$ （1 分）

3-4-3  $d = ZM/VN_{A} = 4.07 \, g \cdot cm^{-3}$ （2 分）

3-5 a)、c)（2 分，有错误不得分）
