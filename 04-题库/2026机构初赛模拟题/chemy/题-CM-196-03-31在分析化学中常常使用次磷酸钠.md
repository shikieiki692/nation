# 题-CM-196-03-31在分析化学中常常使用次磷酸钠

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-5-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（26 分，占 14%）

**3-1** 在分析化学中，常常使用次磷酸钠还原碘量法对 Sn 元素定量分析，其基本方法为：将含 Sn 单质的合金溶于含有过量过氧化氢的盐酸中(反应 1)，待合金完全溶解后加热溶液(反应 2)；随后在 N<sub>2 </sub>保护下，以少量氯化亚汞为催化剂，加入过量的 NaH<sub>2</sub>PO<sub>2</sub>·H<sub>2</sub>O(反应 3)；冷却后以淀粉为指示剂，用碘标准溶液滴定(反应 4)，即可测得合金中 Sn 的质量分数。在这一过程中使用的碘标准溶液一般使用碘酸钾和碘化钾在酸性溶液中反应进行配置(反应 5)，并使用硫代硫酸钠标准溶液进行标定(反应 6)。

**3-1-1** 写出反应 1 ~ 反应 6 的化学方程式。

**3-1-2** 在上述测定过程中，过量的次磷酸钠并不会影响滴定结果，解释原因。

**3-1-3** 有人认为，也可以使用 EDTA 直接滴定法代替还原碘量法对 Sn 元素进行定量分析，你是否同意这一看法？说明理由。

**3-2** 科研人员合成了一种特殊的含 Sn、Se 的材料，可以实现热致变色。其合成方法为：将定量的锡单质、硒单质、醋酸银、尿素以及 N(CH<sub>3</sub>)<sub>3</sub>·HCl 混合，向其中加入 N<sub>2</sub>H<sub>4</sub>·H<sub>2</sub>O，封管加热 24 h，最终以 70 %左右的产率得到了金红色 3 : 1 型铵盐 X。X 中 Sn 的氧化态为+4。元素分析表明，X 中不含碳元素和氧元素，部分元素的质量分数为：Ag 9.38; N 3.65; H 1.05 (%)。X 射线衍射分析表明，在 100 K 下 X 为四方晶系，部分晶体学数据如下：a = 821.55 pm；c = 1341.34 pm；ρ = 4.218 g/cm<sup>3</sup>。

**3-2-1** 通过计算与推导，推出 X 的化学式。

## 参考答案

**3-1-1**（共 8 分）反应 1：Sn + 6HCl + 2H<sub>2</sub>O<sub>2</sub> → H<sub>2</sub>SnCl<sub>6</sub> + 4H<sub>2</sub>O（2 分）反应 2：2H<sub>2</sub>O<sub>2</sub> → 2H<sub>2</sub>O + O<sub>2</sub>（1 分）反应 3：H<sub>2</sub>SnCl<sub>6</sub> + NaH<sub>2</sub>PO<sub>2</sub>·H<sub>2</sub>O → SnCl<sub>2</sub> + H<sub>3</sub>PO<sub>3</sub> + 3HCl + NaCl（2 分）反应 4：SnCl<sub>2</sub> + I<sub>2</sub> +2HCl → SnCl<sub>4</sub> + 2HI（1 分）反应 5：IO<sub>3</sub><sup>-</sup> + 5I<sup>-</sup> + 6H<sup>+</sup> → 3I<sub>2</sub> + 3H<sub>2</sub>O（1 分）反应 6：2S<sub>2</sub>O<sub>3</sub><sup>2-</sup> + I<sub>2</sub> → 2I<sup>-</sup> + S<sub>4</sub>O<sub>6</sub><sup>2-</sup>（1 分）

**3-1-2** NaH<sub>2</sub>PO<sub>2</sub>在热时是强还原剂，冷时失去还原性能。（2 分）

**3-1-3** 不同意（1 分）。Sn(IV)易水解（1 分），无法直接用 EDTA 滴定法进行测定。若理由回答 EDTA 滴定时其他金属离子会对 Sn 的测定产生干扰，也可以。

**3-2-1**（共 5 分）由晶体学数据可知：ZM = ρN<sub>A</sub>V = 2299.65 g/mol（1 分）带入质量分数，可得一个晶胞内含有 2 个 Ag、6 个 N、24 个 H。对应化学式为(NH<sub>4</sub>)<sub>6</sub>Ag<sub>2</sub>Sn<sub>x</sub>Se<sub>y</sub>（1 分）由于 Sn 为+4 氧化态，故 Se 只能为-2 氧化态，即可解得 x = 6，y = 16。故 X 的化学式为(NH<sub>4</sub>)<sub>3</sub>AgSn<sub>3</sub>Se<sub>8</sub>（3 分）
