$$
\mathrm { X + DM \mathrm { - } \mathrm { \beta \mathrm { - } CD }  \mathrm { X \cdot DM \mathrm { - } \mathrm { \beta \mathrm { - } CD } } }
$$

在 $25^{ \circ } \mathrm { C }$ 下， 用溶解了一定量DM- $\cdot \beta$ -CD 的乙腈-水(40:60)混合溶剂作为流动相， 使用 $\mathrm { C } _{ 18 }$ 色谱柱作为固定相， 通过色谱法测定以上包合反应的平衡常数 $K _{ f \circ }$ 。色谱柱的固定相对X 有一定的吸附作用， 而不对 DM- $\cdot \beta$ -CD 和 X·DM- $\cdot \beta$ -CD 发生作用。当将X 注入色谱柱时， $\mathrm { \Delta } \mathrm { X }$ 很快在流动相 $( \mathrm { m } )$ 和固定相(s)之间达成平衡：

## 参考答案

第5题（10分）


$$
\mathrm{X} (\text {流动相}) \rightleftharpoons \mathrm{X} (\text {固定相}) K = [ \mathrm{X} ] _ {\mathrm{s}} / [ \mathrm{X} ] _ {\mathrm{m}}
$$

5-1 在固定相和流动相中的 X 的含量比为定值，设该值为  $k_{0}$ ，则有：
 $t_{R}/t_{0}=(1+k_{0}+K_{f,1}[DM-CD])/(1+K_{f,1}[DM-CD])$ （2分）
将[DM-CD]、 $t_{0}$  和  $t_{R}$  分别代入上式，联立求得： $k_{0}=5.33; K_{f,1}=22.2\ L\cdot mol^{-1}$ （2分）

5-2 将[DM-CD]=0 和  $k_{0}=5.33$  代入上式，求得： $t_{R,0}=6.90\ min$ （2分）

5-3 由  $\ln(K_{2}/K_{1})=\Delta H/R(1/T_{1}-1/T_{2})$  得：
 $\Delta H=-10\ kJ\cdot mol^{-1}$ （2分）
由  $\Delta H-T\Delta S=-RT\ln K$  得：
 $\Delta S=-8\ J\cdot mol^{-1}\cdot K^{-1}$ （2分）
不要求有效数字。
