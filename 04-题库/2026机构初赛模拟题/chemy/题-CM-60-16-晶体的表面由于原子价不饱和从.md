# 题-CM-60-16-晶体的表面由于原子价不饱和从

## 题目

### 第 16 题 本题是一道涉及晶体表面能的题目。通过本题的解答，读者能对金刚石的表面性质以及共价晶体表面能的计算产生一些了解。（10 分）

晶体的表面由于原子价不饱和，从而具有表面能。分子或离子晶体表面能的计算较为困难，而共价晶体的计算则相对容易。以金刚石为例，已知金刚石中碳碳键长为 154.5 pm，金刚石中碳碳键能为 82.60 kcal·mol $^{-1}$ 。

16-1 计算分子或离子晶体表面能的困难何在？

16-2 画出金刚石的正当晶胞，并标出垂直于（111）面的化学键。

16-3 计算金刚石的密度和（111）晶面的面间距。

16-4 假设一块金刚石被从平行于（111）面的方向截断，所有断裂的键能（何种键会断？）化作新生成表面的表面能，试计算金刚石（111）面的表面能（J·m $^{-2}$ ）。

## 参考答案

16-1 分子晶体和离子晶体中的作用力 （范氏力和静电力） 都是长程相互作用， 力的作用范围不止最邻近的原子，故难以计算。（1 分）

16-2 红色线是垂直于 （111） 面的键： （晶胞2 分， 化学键完全标对 1 分）

16-3 $\rho = { \frac { Z M } { N _{ A } { ( { \frac { 4 } { \sqrt { 3 } } } d ) } ^{ 3 } } } = 3.512 { \mathrm { ~ g } } \cdot { \mathrm { cm } } ^{ - 3 }$ （2 分）， $d _{ 111 } = \frac { a } { \sqrt { 3 } } = 206.0 ~ \mathrm { pm }$ （2 分）

$\cdot$ 的111 面上方有垂直于 （111） 面的化学键 $\cdot$ 根， 总键能 10.39 J， 故表面能为总键能的一半 $\cdot$ 。 （2 分）
