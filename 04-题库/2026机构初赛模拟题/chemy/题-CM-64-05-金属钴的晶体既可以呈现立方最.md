# 题-CM-64-05-金属钴的晶体既可以呈现立方最

## 题目

### 第 5 题（11 分）

金属钴的晶体既可以呈现立方最密堆积结构，也可以呈现六方最密堆积结构。室温下，六方最密堆积的金属钴相对更稳定。但金属钴的纳米粒子却呈现与之不同的性质。将少量${ \mathrm { Co } } ( \mathrm { OH } ) _{ 2 }$ 溶于乙二醇溶液，然后转移至高压反应釜中加热，按1 : 1 的摩尔比反应，可制得金属钴纳米粒子。X-射线衍射表明，此法制得的纳米粒子中，钴做立方最密堆积而非六方最密堆积。

5-1 写出制备金属钴纳米粒子的化学反应方程式(副产物为一常见有机酸)。

5-2 以下两张图示出了不同晶型的金属钴纳米粒子最稳定时的形貌：

![](images/9cda6771ab220b0ed2beb9c44da169a5e53c370335114c55e47036261b738363.jpg)

5-2-1 以上 $\pmb { x }$ 和 $\pmb { \ Y }$ 两张图中， 哪张代表六方最密堆积， 哪张代表立方最密堆积？

5-2-2 分别指出钴纳米粒子表面a、b、c 和 ${ \bf d }$ 上钴原子的配位数。

5-3 钴原子半径为 $r = 126 \mathrm { pm }$ ， 设有一钴纳米粒子中钴做立方最密堆积，其体积 $V = 54 \mathrm { nm } ^{ 3 }$ ，估算其中所含钴原子的数目。

5-4 理论预测和实验结果表明，在该实验条件下得到的钴纳米粒子，立方最密堆积结构比六方最密堆积结构更加稳定，这与宏观尺度下二者的稳定性顺序恰好相反。请给出合理的解释。

## 参考答案

## 第5题（11分）

$$
5 - 1 \mathrm{Co} (\mathrm{OH}) _ {2} + \mathrm{HOCH} _ {2} \mathrm{CH} _ {2} \mathrm{OH} = \mathrm{Co} + \mathrm{CH} _ {3} \mathrm{COOH} + 2 \mathrm{H} _ {2} \mathrm{O} (2 \text {分})
$$

![](images/c24d1d745224952b7618027a4720c0449c17caaf8c16fc8861d63bb91a8b0b9f.jpg)

![](images/02694abc1bd5df188a760b8364b15f0e04083c5dec808e8ef2adf0f61ccd81fa.jpg)

5-2-1 Y 为六方最密堆积（1 分），X 为立方最密堆积（1 分）

5-2-2 分别是 8、7、9、9（3 分）

写错一个扣 1 分，写错 3 个以上不得分。

5-3 一个晶胞的体积 $V = a^3 = (2\sqrt{2} r)^3 = 4.53 \times 10^7 \mathrm{pm}^3$ 原子数 $N = 4V / V_0 = 4.77 \times 10^3$ （2分，其他计算方法亦可得分）

5-4 与宏观尺度的钴相比，钴纳米粒子具有巨大的比表面积，因此其表面能不能忽略。实验条件下，钴做六方最密堆积形成晶粒的表面能相对更大，因此导致了立方最密堆积结构更加稳定。（2分，只要答出表面能或表面效应即可得满分）
