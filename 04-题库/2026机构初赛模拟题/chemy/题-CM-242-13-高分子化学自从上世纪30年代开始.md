# 题-CM-242-13-高分子化学自从上世纪30年代开始

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-6-13`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 13 题（12 分）

高分子化学自从上世纪 30 年代开始被广泛承认以来，已经连续不断地发展了 80 多年。由于各种高分子的性能相对于传统材料有着不可比拟的优势，化学界也一直在对其经行了许多研究。其中，衡量各种高分子的两个重要参数就是平均分子量以及聚合度。

![](images/61b159bd7f387d9de95c235eab1056bb25b1ee8cd0d70b7176d3798652a2ce39.jpg)

合度 X<sub>n </sub>为该高分子中含有的 P 或者 Q 的结构单元的数目。假设将等当量的 R<sub>1</sub>COOH 和R<sub>2</sub>CH<sub>2</sub>OH 投入封闭体系中反应，且该反应平衡常数 K ≈ 4，且最终仅生成了一种在溶液相中的聚合物。试通过计算得出聚合物的 X<sub>n</sub>为多少。

![](images/c5985a710796b5de8af49b8250cb846c35b0fe1eff046bdf0baf0b9b27ca3961.jpg)

## 参考答案

![](images/2633c65d4581c4a4a93512d1e4bd1bc790feed5818d26c45a00066688215b605.jpg)

有 x<sub>A1</sub> = n<sub>A1</sub> / ( n<sub>A</sub> + n<sub>B</sub> ) = ( n<sub>A1</sub> / n<sub>A</sub> ) × ( n<sub>A</sub> / ( n<sub>A</sub> + n<sub>B</sub> ) ) = x<sub>A</sub> × ( n<sub>A</sub> / ( n<sub>A</sub> + n<sub>B</sub> ) )

![](images/8350e28cbb8e8f28a3ac85f37702504d4115c791666fe5756de5c03be2ba2b3e.jpg)

**13-1-2** B（2 分）

**13-2** 由题，得( [R<sub>1</sub>COOCH<sub>2</sub>R<sub>2</sub>][H<sub>2</sub>O] ) / ( [R<sub>1</sub>COOH][R<sub>2</sub>CH<sub>2</sub>OH] ) = K假设初始时酸和醇的浓度均为 c<sub>0</sub>，反应达到平衡时体系中酯的浓度为 c，则有[R<sub>1</sub>COOCH<sub>2</sub>R<sub>2</sub>] = [H<sub>2</sub>O] = c，[R<sub>1</sub>COOH] = [R<sub>2</sub>CH<sub>2</sub>OH] = c<sub>0</sub> – c即 c<sup>2</sup> / ( c<sub>0</sub> – c )<sup>2</sup> = K，解得 c = 2/3c<sub>0</sub>（1 分）显然，体系中( c<sub>acid</sub> + c<sub>alcohol</sub> ) = 2c<sub>0</sub>，所以每个聚合物中酯基的“浓度”为 2c<sub>0</sub> – 2 ( 1 – 2/3 )c<sub>0</sub> = 4/3c<sub>0</sub>（1 分）故 X<sub>n</sub> = ( 4/3c<sub>0</sub> ) / c + 1 = ( 4/3c<sub>0</sub> ) / ( 2/3c<sub>0</sub> ) + 1 = 3所以高聚物的 X<sub>n</sub> = 3（2 分）
