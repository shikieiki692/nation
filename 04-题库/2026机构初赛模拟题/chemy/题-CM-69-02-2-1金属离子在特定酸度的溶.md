# 题-CM-69-02-2-1金属离子在特定酸度的溶

## 题目

### 第 2 题（11 分）

2-1 金属离子在特定酸度的溶液中水解可得到多核配离子， 如 $\mathrm { Bi } _{ 6 } ( \mathrm { OH } ) _{ 12 } { } ^{ 6 + }$ 和 $\mathrm { Pb } _{ 6 } \mathrm { O } ( \mathrm { OH } ) _{ 6 } { } ^{ 4 + }$ 即为两种经水解得到的六核阳离子，但它们的结构却有很大区别。 $\mathrm { Bi } _{ 6 } ( \mathrm { OH } ) _{ 12 } { } ^{ 6 + }$ 与 ${ \mathrm { SF } } _{ 6 }$ 具有相同的对称性，同种原子的化学环境完全相同； 而 $\mathrm { Pb } _{ 6 } \mathrm { O } ( \mathrm { OH } ) _{ 6 } { } ^{ 4 + }$ 与 $\mathrm { H } _{ 2 } \mathrm { O }$ 具有相同的对称性，6 个铅形成三个四面体， 氧均为四配位。 画出 $\mathrm { Pb } _{ 6 } \mathrm { O } ( \mathrm { OH } ) _{ 6 } { } ^{ 4 + }$ 和 $\mathrm { Bi } _{ 6 } ( \mathrm { OH } ) _{ 12 } { } ^{ 6 + }$ 的结构。

2-2 除了碳元素以外，许多无机元素也能形成芳香性的离子， 例如 ${ \bf S } _{ 4 } { } ^{ 2 + }$ 即是一种具有芳香性的离子。

🎉🙌

2-2-2 图2 为该阳离子的 $\pi$ 分子轨道示意图， 请指出 1 \~ 4 中何者为其 HOMO 轨道， 何者为其 LUMO 轨道？

2-3 在制备 Zintl 化合物时， 半径适宜的粒子有可能被包合在 Zintl 多面体内部。 例如将 Na、Sn 和 $\mathrm { Ca }$ 的单质熔融反应，得到一种化学式为 $\mathrm { Na _{ 10 } [ CaSn _{ 12 } ] }$ 的钠盐，其阴离子 $\begin{array} { r } { [ \mathrm { CaSn } _{ 12 } ] ^{ 10 \cdot } } \end{array}$ -具有与甲烷相同的对称性， Sn 原子均满足八隅律。 请画出 $ { [ \mathrm { CaSn } _{ 12 } ] } ^{ 10 }$ -的结构示意图。
