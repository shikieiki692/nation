# 题-CM-142-06-蛋白质具有丰富的层次结构正是

## 题目

### 第 6 题（9 分）

蛋白质具有丰富的层次结构，正是这复杂而微妙的结构赋予了蛋白质许多功能，诸如催化、运输、信息传递等等，使得其在生化医药等领域有着广泛且重要的应用。对于化学家来说，如能人工合成出蛋白质的类似物，将扩大生物大分子的结构范围，并在蛋白质修饰等方面可以进行更加精确的控制。2021年，Marcus Weck课题组合成了能够模拟蛋白质二级与三级结构的聚异腈高分子，相关成果发表于MRC上。注：PMDETA为五甲基二亚乙基三胺。

![](images/24ddb2b6989b3f06fa97840bdcd7b0b2cb3ce7bbb52c7d4acabbb65c952d15ae.jpg)

6-1 画出聚合物 A、B、C 的结构，无需明确 C 的端基结构。

6-2 C 的某一链段可以盘曲成 $\beta$ 螺旋的类似结构，该链段形成的螺旋结构具有很高的翻转能垒，即使在强极性质子溶剂中也不会解旋。指出是哪一链段，并解释为何该螺旋结构具有如此高的稳定性。

6-3 C 的两个链段还进一步发生了折叠。然而，如果把 B 到 C 一步加入的单体换为以下化合物，则折叠无法发生：

![](images/d8f78baf67abc29371b4226c197f513044b5139c83177581ed0bc5f5c2e3f5a0.jpg)

据此指出发生折叠的分子间作用力，并比较更换单体后两个聚合物的玻璃态转化温度。

6-2 聚异腈嵌段（1 分）

因为聚异腈嵌段侧链上的酰胺基团可以彼此形成链间氢键，维持螺旋结构（1 分）

聚异腈嵌段主链上的碳原子均为 $sp^{2}$ 杂化，具有一定刚性，因此具有很高的翻转能垒（1 分）6-3 C 的两个链段还进一步发生了折叠。然而，如果把 B 到 C 一步加入的单体换为以下化合物，则折叠无法发生：
