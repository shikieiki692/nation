# 题-CM-174-01-砷的历史与化学

## 题目

### 第 01 题 砷的历史与化学（18 分）

元素砷被人类发现利用的历史十分悠久，在古代中国就已经将砷的化合物用作颜料和药物， 古代炼丹术中更有五金八石三黄之说，其中三黄指的就是雄黄 $\mathrm { ( As _{ 4 } S _{ 4 } ) }$ 、 雌黄(As2S3)、 硫磺(S)。

1-1 东晋葛洪在 《抱朴子》中记载过与砷相关的实验： “取雌黄雄黄烧下，其中铜铸以为器覆之……百日此器皆生赤乳， 长数分。”这里描述的是哪种物理变化？

1-2 西方化学家普遍认为单质砷是德国的A. Magnus 于 1250 年，用雌黄和肥皂共热得到的。但是，在古代中国就已经可能分离出了单质砷。唐代孙思邈的 《太清丹经要诀》中提到“伏雄雌二黄用锡法”，原文是：“雄黄十两，末之。锡三两。……入坩埚中火之……寒之开，其色似金。”通过模拟实验，可以肯定孙思邈必然通过此法制得过相当纯净的升华砷， 但是他只注意到醒目的金黄色产物，没有意识到单质砷的生成。写出其中发生反应的方程式。

1-3 雄黄存在两种异构体 A 和 B， $\mathsf { \pmb A }$ 中所有 As 原子化学环境相同， B 中有三种化学环境的 As。 画出 A 和B 的结构。

1-4 雌黄易溶于碳酸钠溶液中， 生成两种盐， 写出化学反应方程式。

1-5 巴黎绿 $\mathrm { ( [ Cu ( CH _{ 3 } COO ) _{ 2 } { \cdot } 3 Cu ( AsO _{ 2 } ) _{ 2 } ] ) }$ 是风靡 19 世纪的鲜艳的绿色含砷颜料。 巴黎绿中 $\mathbf { AsO } _{ 2 } \cdot$ 以三聚体形式存在， 画出其结构。

1-6 马氏试砷法是一种高灵敏度的砷检测方法，通常需要将 As 先转化为 $\mathrm { As } _{ 2 } \mathrm { O } _{ 3 }$ ，再进行检出。首先用盐酸和锌粉还原 $\mathrm { As } _{ 2 } \mathrm { O } _{ 3 }$ ，产生一种具有大蒜味的三角锥形气体分子（反应 1）。将该气体通入石英管并加热，发现在石英管内壁沉积出现亮黑色金属光泽物质（反应 2），Sb 也可以发生类似反应。为了区分 As 和Sb，需将碱性次氯酸钠溶液加入到沉积有亮黑色金属光泽物质的石英管中，发现亮黑色物质溶解 （反应3），Sb 不发生此反应。写出上述化学反应的方程式。
