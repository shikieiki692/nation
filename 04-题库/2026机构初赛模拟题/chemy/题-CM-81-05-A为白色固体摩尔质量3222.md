# 题-CM-81-05-A为白色固体摩尔质量3222

## 题目

### 第 5 题（10 分）

A 为白色固体，摩尔质量 322.2 g/mol，可溶于水，有毒，加热至 120°C 以上失水，加热至 250°C 以上分解。将稀硫酸与 A 的水溶液混合时，析出白色沉淀 B；将 B 滤出，可得到 C 的溶液。C 为强酸，也是一种较强的氧化剂；C 溶液在浓度大于 40% 时会发生爆炸式歧化反应，生成水、酸 D 并放出 E、F、G 等气体。E 为黄色气体，也可由二元含氧酸 H(pK $_{a1}$ = 1.3; pK $_{a2}$ = 4.3) 还原 C 的溶液得到；E 与 O $_{3}$ 反应，可得到红色液体 I 和气体 G；I 溶于水仅生成 C 和 D(摩尔比 1:1)。将气体 F 通过潮湿的碳酸钠表面，可得到气体 J，J 溶于水得到弱酸 K(pK $_{a}$ = 7.5)；K 见光分解，得到气体 G 等产物。

5-1 写出 $A \sim K$ 的化学式。

5-2 写出气体 F 与潮湿的碳酸钠反应生成 J 的化学反应方程式。

5-3 C 浓溶液的爆炸性分解可看作两个平行进行的分解反应：第一个分解反应产生气体 E；第二个分解反应产生气体 F 和 G(摩尔比 2:3)。写出这两个平行反应的方程式。

## 参考答案

第5题（10分）

5-1 写出 A\~K 的化学式。

$$
5 - 22 \mathrm{Cl} _{2} + 2 \mathrm{Na} _{2} \mathrm{CO} _{3} + \mathrm{H} _{2} \mathrm{O} = 2 \mathrm{NaHCO} _{3} + 2 \mathrm{NaCl} + \mathrm{Cl} _{2} \mathrm{O} (2 \text {分})
5 - 38 \mathrm{HClO} _{3} = 4 \mathrm{HClO} _{4} + 2 \mathrm{Cl} _{2} + 3 \mathrm{O} _{2} + 2 \mathrm{H} _{2} \mathrm{O} (1 \text {分})
3 \mathrm{HClO} _{3} = \mathrm{HClO} _{4} + 2 \mathrm{ClO} _{2} + \mathrm{H} _{2} \mathrm{O} (1 \text {分})
$$
