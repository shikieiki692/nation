# 题-CM-225-06-过渡金属复合氧化物具有丰富多彩的

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-19-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（14 分）

过渡金属复合氧化物具有丰富多彩的结构；通过向复合氧化物中引入阴离子空位或其他阴离子替代氧离子，可以改变其物理性质。例如，将 Sr<sub>2</sub>V<sub>2</sub>O<sub>7 </sub>置于 H<sub>2 </sub>气氛下加热还原，可制得A，A 具有钙钛矿结构。用 CaH<sub>2</sub>与 A 进一步加热反应可以使得 A 晶胞中位于(0, 0, 1/2)的氧原子被氢原子置换，生成 B 并放出气体。

**6-1** 分别写出 A 和 B 的化学式以及生成 A 和 B 的反应方程式。

**6-2** 在 B 中，钒原子的晶体场分裂如下；补全其中的电子。

![](images/e3c3dafcd3c8b722967eb460c65a655779045e441b08b3829aa1cd6733f28dcc.jpg)![](images/6b2cec228a8214325174aa52e0c947fbe2f77019e7b5883f6f216da8b61d63c2.jpg)![](images/29e4c90d0c14849024d9399499d80bc2f0de3917a0f8aa4c14ec1148e2592e97.jpg)![](images/df7e32d63456825f290049260fb64de6db27e803ade48f2cba7c0e5c5f4993ac.jpg)

**6-3** 磁性测定表明，A 在室温下为反铁磁性。一般认为，该种性质的产生是因为金属原子和氧原子通过 π 对称性的轨道重叠形成了无限结构。在下图中补全这些轨道的重叠示意图。

![](images/0bc65eccafd00bd47b689cba4d343142b7e73a580472a6d867cd1207e29b6269.jpg)

**6-4** 虽然 B 在室温下也为反铁磁性，但研究表明，B 的磁学性质更接近于二维磁性材料。从轨道重叠的角度解释 B 的磁学性质接近于二维材料的原因。

**6-5** 类似地，利用 Sr<sub>2</sub>VO<sub>4 </sub>和 CaH<sub>2</sub>作用可制得 C，利用 Sr<sub>3</sub>V<sub>2</sub>O<sub>7 </sub>和 CaH<sub>2</sub>作用可制得 D；C和 D 中氢原子所连接的钒原子的种类和数目与 B 中相同，钒原子的氧化态也与 B 中相同。写出 C 和 D 的化学式。

**6-6** 然而，C 和 D 在室温下都是顺磁性(而非反铁磁性)的，从晶体结构的角度说明原因。

## 参考答案

**6-1** A：SrVO<sub>3</sub>（1 分） B：SrVO<sub>2</sub>H（1 分）Sr<sub>2</sub>V<sub>2</sub>O<sub>7</sub> + H<sub>2</sub> = 2SrVO<sub>3</sub> + H<sub>2</sub>O（1 分）2SrVO<sub>3</sub> + 2CaH<sub>2</sub> = 2SrVO<sub>2</sub>H + 2CaO + H<sub>2</sub>（1 分）

**6-2** 参考图形如下：

![](images/31d823946bfa8adfda1334be30517ad4f2dba2ab9b06b2f29209c7aec07fdecf.jpg)![](images/282d015d264512880d5ce6c76c011c483584a7f91bc6a4fbdb34ffcbefd87096.jpg)![](images/227b684a493aea7479f84fae8f103079d6198832d20c42a57a53a78f5af475cb.jpg)

**6-3** 参考图形如下：

![](images/e4c937561203143b8365e57791b73e53e1677645b2b9b7dc2fecf2da28308e7c.jpg)

**6-4** 在 xy 平面上，B 与 SrVO<sub>3</sub>结构相近，具有相似的性质（1 分）；但是在沿 z 轴方向，由于氢原子的 s 轨道无法与金属原子的 3d 轨道对称性匹配，无法形成有效的 π 轨道作用，因此在 z 方向无法形成有效的反铁磁耦合。（1 分）

![](images/145352dcd62baee79ed13f836ee7973886fd054b33ca85bb9411242c52bd9409.jpg)

**6-5** C：Sr<sub>2</sub>VO<sub>3</sub>H D：Sr<sub>3</sub>V<sub>2</sub>O<sub>5</sub>H<sub>2 </sub>（各 1 分）

**6-6** 因为 C 和 D 的氧原子数目更多，相对于 B 是更低维（2 分）的磁性材料，反铁磁耦合作用更弱，需要更低的温度才能体现出反铁磁性。实际上，C 在文献中被归为一维磁性材料，D 被归为 1.5 维磁性材料，有兴趣的选手可参考其结构：
