# 题-CM-196-06-在人们早期的认知中水与火土气并列

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-5-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（18 分，占 10%）

在人们早期的认知中，水与火、土、气并列为“四大元素”。这类认知导致 Cavendish 虽然在1766 年分离出 H<sub>2 </sub>并通过其与空气的结合得到了水，但他依然坚持认为水是元素，而 H<sub>2 </sub>这一“易燃气体”则为当时盛行的“燃素学说”中的“燃素”。到了 1783 年，Lavoisier 在复现Cavendish 结果的基础上额外发现将水通过烧红的铁筒能再次得到 H<sub>2</sub>，因此他认为水并非元素，而将该“易燃气体”命名为 Hydrogen，意为“生成水的物质”。

**6-1** 写出 Lavoisier 得到 H<sub>2</sub>的反应方程式。

**6-2** 虽然氢很早就被人们认知，但它的结构及同位素直到 20 世纪原子结构理论及实验条件相对成熟后才被探究。

**6-2-2** 在 1934 年，Ernest Rutherford、Mark Oliphant 和 Paul Harteck 利用 D<sub>3</sub>PO<sub>4</sub>和(ND<sub>4</sub>)<sub>2</sub>SO<sub>4</sub>得到了一种具有放射性的核素，该核素半衰期为 12.43 年，主要发生 β 衰变，反应放出 18.6 keV。写出上述过程涉及的核反应方程式，计算该核素的衰变常数(以 s<sup>-1</sup>为单位)以及衰变后损失的质量。

**6-3** 由于 H 核仅有一个质子，其理应具有优良的还原剂潜力。Schlesinger 与其合作者在 1940年及 1947 年分别制备了两种化合物 A 和 B，A 含氢 10.66 %，B 含氢 10.62 % (均为质量分数)。A 和 B 一共含有 3 种金属元素、2 种非金属元素，它们的结构相似，化学性质类似，制备方法也类似，均是优良的还原剂。B 的还原性比 A 更强，但 A 除了它们的一般制备方法外，还可以从氧化物出发制备。通过计算与推理，直接写出 A 和 B 的化学式。

## 参考答案

**6-1** 3Fe + 4H<sub>2</sub>O → Fe<sub>3</sub>O<sub>4</sub> + 4H<sub>2</sub>（2 分）写成 2Fe + 3H<sub>2</sub>O → Fe<sub>2</sub>O<sub>3</sub> + 3H<sub>2</sub>也可以。

**6-2-1**λ(Lyman-α) = [R<sub>H</sub>(1 / n<sub>1</sub><sup>2</sup> – 1 / (n<sub>1</sub> + 1)<sup>2</sup>)]<sup>-1</sup> = 121.5 nm（2 分）λ(Balmer-α) = [R<sub>H</sub>(1 / n<sub>1</sub><sup>2</sup> – 1 / (n<sub>1</sub> + 1)<sup>2</sup>)]<sup>-1</sup> = 656.3 nm（2 分）

**6-2-2**核反应方程式：<sup>2</sup><sub>1</sub>H + n → <sup>3</sup><sub>1</sub>H（1 分）；<sup>3</sup><sub>1</sub>H → <sup>3</sup><sub>2</sub>He + e（1 分）由一级反应动力学，k = ln2 / t<sub>1/2</sub> = 1.768×10<sup>-9</sup> s<sup>-1</sup>（1 分）由能量守恒定律 E = mc<sup>2</sup>，Δm = ΔE / c<sup>2</sup> = 3.32×10<sup>-32</sup> kg（1 分）

**6-2-3**第一电离能(H<sub>2</sub> → H<sub>2</sub><sup>+</sup> + e)：ΔH = ΔH<sub>2</sub> – ΔH<sub>3</sub> + ΔH<sub>4</sub> = 1489 kJ·mol<sup>-1</sup>（2 分）键焓(H<sub>2</sub> → H + H)：ΔH = ΔH<sub>2</sub> – ΔH<sub>1</sub> = 433 kJ·mol<sup>-1</sup>（2 分）

**6-3** A：NaBH<sub>4</sub>；B：LiAlH<sub>4</sub>（各 2 分）
