4-6 中间相 V 相的结构一直以来存在着争议，不同文献对该结构有着不同的看法。有人认为，V 相为正交晶系，其素晶胞的晶胞参数为 $a = 5.021 \, \mathrm{mathring A}$ ， $b = 4.925 \, \mathrm{mathring A}$ ， $c = 3.237 \, \mathrm{mathring A}$ ， $\alpha = 72.613^\circ$ ， $\beta = 69.417^\circ$ ， $\gamma = 37.970^\circ$ 。判断该晶体正当晶胞的点阵形式；计算其正当晶胞的晶胞参数。

## 4-6 面心正交

在右图中，我们取出了一个面心正交晶胞的素晶胞
$a = 5.021 \text{ Å, } b = 4.925 \text{ Å, } c = 3.237 \text{ Å}$ $\alpha = 72.613^{\circ}, \beta = 69.417^{\circ}, \gamma = 37.970^{\circ}$
设面心正交晶胞的晶胞参数为 $a', b', c'$
则由几何关系，$a'^2 + b'^2 = 2c^2$
同理可以列出：$a'^2 + c'^2 = 2b^2$，$b'^2 + c'^2 = 2a^2$
解得 $a' = 4.366 \text{ Å, } b' = 7.781 \text{ Å, } c' = 8.831 \text{ Å}$ $D = ZM / N_A V = 4.574 \text{ g/cm}^{-3}$
晶体密度也可以由如下三斜晶胞体积计算公式求得，
$(V / abc)^2 = 1 - \cos^2 \alpha - \cos^2 \beta - \cos^2 \gamma + 2\cos \alpha \cos \beta \cos \gamma$
