# 题-CM-84-01-1-1用氧化的硫酸溶液

## 题目

### 第 1 题（8 分）

1-1 用 $PbO_{2}$ 氧化 $MnSO_{4}$ 的硫酸溶液。

1-2 向亚硝酸钾溶液中加入乙酸，混合均匀后加入硝酸钴(II)静置过夜，得到一黄色固体。

1-3 往 $SnCl_{2}$ 的盐酸溶液中通入 $SO_{2}$ ，生成了一种金黄色沉淀。

1-4 在盐酸介质中，TII 和 $KIO_{3}$ 可以按 1:1 的计量比反应，反应生成 $TlCl_{3}$ 和一种卤素互化物。

## 参考答案

1 用CaO 与H2、Mg 单质共热，制备一种常用生氢剂。

**1-1** $5PbO_{2} + 2Mn^{2+} + 5SO_{4}^{2-} + 4H^{+} = 2MnO_{4}^{-} + 5PbSO_{4} + 2H_{2}O$ (2分)

**1-2** 向亚硝酸钾溶液中加入乙酸,混合均匀后加入硝酸钴(II)静置过夜,得到一黄色固体。

**1-2** $Co^{2+} + 3K^{+} + 7NO_{2}^{-} + 2HAc = K_{3}[Co(NO_{2})_{6}] + NO + H_{2}O + 2Ac^{-}$ (2分)

**1-3** 往  $SnCl_{2}$  的盐酸溶液中通入  $SO_{2}$ ,生成了一种金黄色沉淀。

**1-3** $6SnCl_{2} + 2SO_{2} + 8HCl = 5SnCl_{4} + SnS_{2} + 4H_{2}O$ (2分)

**1-4** 在盐酸介质中,TII和 $KIO_{3}$ 可以按1:1的计量比反应,反应生成 $TlCl_{3}$ 和一种卤素互化物。

**1-4** $TlI + KIO_{3} + 6HCl = TlCl_{3} + 2ICl + KCl + 3H_{2}O$ (2分)
