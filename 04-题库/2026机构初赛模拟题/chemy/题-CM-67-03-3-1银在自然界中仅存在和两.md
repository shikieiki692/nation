# 题-CM-67-03-3-1银在自然界中仅存在和两

## 题目

### 第 3 题（10 分）

3-1 银在自然界中仅存在 $^{ 107 } \mathrm { Ag }$ 和 $^{ 109 } \mathrm { Ag }$ 两种核素，其同位素丰度分别为和 $51.839 \%$ 和$48.161 \%$ ， 其余核素均为人工合成的不稳定核。为精确测定银的原子量，采用高分辨率质谱仪测得质量差 $m ( ^{ 12 } \mathrm { Cs } ^{ 1 } \mathrm { H } _{ 11 } { } ^{ + } ) - m ( ^{ 107 } \mathrm { Ag } ^{ + } ) = 180986.4 \mu \mathrm { u } ; m ( ^{ 12 } \mathrm { Cs } ^{ 1 } \mathrm { H } _{ 13 } { } ^{ + } ) - m ( ^{ 109 } \mathrm { Ag } ^{ + } ) = 196972.1 \mu \mathrm { u } \mathrm { . }$ 。已知 $^{ 12 } \mathrm { C }$ 的原子量为12， $^ 1 \mathrm { H }$ 的原子量为 1.007825029。

3-1-1 核素 $^{ 108 } \mathrm { Ag }$ 极不稳定，其存在两种衰变方式；这两种衰变方式放出的粒子互为反粒子。
请分别写出两种衰变的反应方程式。

3-1-2 请计算银的精确原子量。

3-2 一级胺在酸性条件下能与亚硝酸根离子反应， 放出 $\Nu _{ 2 }$ 并生成醇。将一级胺 $\mathrm { C } _{ n } \mathrm { H } _{ 2 n + 1 } \mathrm { NH } _{ 2 }$ 和 $\mathrm { C } _{ n + 1 } \mathrm { H } _{ 2 n + 3 } \mathrm { NH } _{ 2 }$ 的混合物 $3.33 \mathrm { g }$ 与 ${ \mathrm { NaNO } } _{ 2 }$ 混合并用盐酸酸化，放出的 $\Nu _{ 2 }$ 经干燥后在 $27.2^{ \circ } \mathrm { C }$ ，$101.3 \mathrm { ~ kPa }$ 下的体积为 $1.480 \mathrm { ~ L ~ }$ 。 通过计算和推理确定 $n$ 的值和混合物中两种胺的质量分数。
放出的N2经干燥后在27.2°C，101.3 kPa 下的体积为1.480 L。通

## 参考答案

## 第3题（10分）

3-1-1  $^{108}Ag = ^{108}Cd + e^{-}$  （1 分）
 $^{108}Ag = ^{108}Pd + e^{+}$  （1 分）

3-1-2  $Ar(^{107}Ag)=12\times8+1.007825029\times11-0.180986=106.9050889$ （1分）
 $Ar(^{109}Ag)=12\times8+1.007825029\times13=108.9047533$ （1分）
 $M=x(^{107}Ag)Ar(^{107}Ag)+x(^{109}Ag)Ar(^{109}Ag)=107.8682$ （2分）
答 107.8681 或 107.868 也可得满分。本题的有效数字受到数据处理方法的影响较大，答出 6～8 位有效数字均可得分，但不应答 5 位有效数字。因为  $x(^{107}Ag)Ar(^{107}Ag)$  精确到小数点后 4 位， $x(^{109}Ag)Ar(^{109}Ag)$  精确到小数点后 4 位，二者相加应该同样得到小数点后 4 位。在此笔者想说明的是，直接取算式中最少的有效数字位数作为最终结果的有效数字位数在有些时候是不可靠的。例如，用 0.1000 mol/L AgNO3 溶液滴定 Cl-，消耗 20.03 mL，空白实验消耗 0.03 mL。若列出总算式，为  $0.1000\ mol/L\times(20.03-0.03)\ mL$ ，这里最终结果显然应该是 4 为有效数字而不是 0.03 mL 的 1 位有效数字。
有兴趣的同学可自行思考本题为什么可以得到更精确的有效数字位数，但这种数据处理方法已经超过竞赛基本要求，在本题中不做评分点。

3-2 一级胺在酸性条件下能与亚硝酸根离子反应，放出 $N_{2}$ 并生成醇。将一级胺 $C_{n}H_{2n+1}NH_{2}$ 将(DMPDA)PtSO $_{4}$ 溶液与Ba(AM)溶液混合，室温搅拌3 h，滤去生成的硫酸钡沉淀，蒸发结晶，析出一种白色晶体Pt(DMPDA)(AM) $\cdot$ xH $_{2}$ O。晶体衍射表明，Pt(DMPDA)(AM) $\cdot$ xH $_{2}$ O属四方晶系，晶胞参数a=b=1361.4 pm，c=845.1 pm，密度D=2.016 g/cm $^{3}$ ，Z=4。(AM为2-烯丙基丙二酸根离子；DMPDA为2,2-二甲基-1,3-丙二胺)
