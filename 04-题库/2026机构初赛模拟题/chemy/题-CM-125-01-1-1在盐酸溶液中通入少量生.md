# 题-CM-125-01-1-1在盐酸溶液中通入少量生

## 题目

### 第 1 题（8 分）

1-1 在盐酸溶液中， $\mathrm{Pb(II)}$ 通入少量 $\mathrm{H}_2\mathrm{S}$ 生成红色沉淀，其中含铅 $80.10\%$ 。

1-2 溴与氟化银的热水溶液作用时，以 7:1 的比例生成 AgBr 与 AgBrO $_{3}$ 。

1-3 硫酰氯与五氯化磷反应，生成三种物质。

1-4 $PbS_{2}O_{3}$ 与过量 $Na_{2}S_{2}O_{3}$ 共热反应生成三种物质，其物质的量之比为 1:3:4。

## 参考答案

<table><tr><td>1-1  $2PbCl_{4}^{2-} + H_{2}S = Pb_{2}SCl_{2} + 2H^{+} + 6Cl^{-}$ (2分,写 $PbCl_{3}^{-}$ 也得分)</td></tr><tr><td>1-2 溴与氟化银的热水溶液作用时,以7:1的比例生成AgBr与 $AgBrO_{3}$ 。</td></tr><tr><td>1-2  $8Br_{2} + 16AgF + 8H_{2}O = 14AgBr + 2AgBrO_{3} + 16HF + O_{2}$ (2分)</td></tr><tr><td>1-3 硫酰氯与五氯化磷反应,生成三种物质。</td></tr><tr><td>1-3  $SO_{2}Cl_{2} + PCl_{5} = SOCl_{2} + POCl_{3} + Cl_{2}$ (2分)</td></tr><tr><td>1-4  $PbS_{2}O_{3}$ 与过量 $Na_{2}S_{2}O_{3}$ 共热反应生成三种物质,其物质的量之比为1:3:4。</td></tr><tr><td>1-4  $PbS_{2}O_{3} + 3Na_{2}S_{2}O_{3} = PbS + 3Na_{2}SO_{4} + 4S$ (2分)</td></tr></table>
