# 题-CM-233-03-将元素X的单质与氯气反应的产物冷

## 题目

### 第 3 题（26 分，占 10.0%）

将元素 X 的单质与氯气反应的产物冷却、提纯可以得到化合物 A。

**3-1** 将 A 与 CsCl 在 650°C、高压下封管反应 2 天可以得到紫色晶体 B。B 的晶体结构可采

取以下描述：将钙钛矿中密置单层的 Ca 替换为 Cs、O 替换为 Cl 得到 B 中密置单层，该

密置单层的排列方式为…ABACBCABACBC…；其中，X 填入仅由 Cl 构成的八面体空隙

且[XCl<sub>6</sub>]八面体间仅通过共面连接。（提示：请仔细考虑 NaCl 晶体与 NiAs 晶体的堆积方式

与其中配位多面体连接关系的关联）

**3-1-1** 画出 B 中密置单层的示意图并框出二维晶胞，指出 B 所属的晶系。

**3-1-2** 已知 B 的晶胞具有对称中心，以大写字母 A、B、C 表示 Cs 原子和 Cl 原子共同形成

的密置单层的排布，小写字母 a，b，c 表示 X 原子密堆积层的排布，用□表示空位层，右

下角标代表单层占有率，仿照示例，写出 B 的堆积方式。

示例：…Ac<sub>1/2</sub>Ba<sub>1/2</sub>Cb<sub>1/2</sub>Ac<sub>1/2</sub>Ba<sub>1/2</sub>Cb<sub>1/2</sub>…<sub> </sub>

**3-1-3** 写出 B 晶胞的组成。

**3-1-4** 已知 B 晶胞参数为 a = 0.729 nm，c = 1.817 nm，B 中最近的 X-X 间距为 0.318 nm，

其中一个 X 原子的分数坐标为(2/3，1/3，0.3375)，写出晶胞中所有 X 原子的坐标参数。

**3-1-5** 已知 B 晶体的密度为 3.27 g/cm<sup>3</sup>，通过计算和推导，给出 X 的元素符号。

**3-2** 化合物 A 常用作合成 X 的复杂配合物的前体，例如三乙三胺(trien)衍生类配体与 X 形

成的配合物 D。

![](images/0a6de07b407a7b37747dd608c80abd06b4f0659b43871581113eacbd6a98e153.jpg)

**3-2-1** 若将 THF 视为球形配体，则 D 具有 C<sub>3</sub>轴。画出 D 的结构。

**3-2-2** 当 R = HIPT（结构如下）时，记配合物 D 为 D<sub>1</sub>，其具有较特殊的反应活性。已知以

下四种配合物中中心金属的氧化态各不相同，分别画出 E、F、G 的结构，有机基团可省

略表达。

**3-2-3** 当 R = TMS（三甲基硅基）时，记配合物 D 为 D<sub>2</sub>。用过量 Na 在 THF 中还原 D<sub>2</sub>可

以得到含有两个金属原子的配合物 H。H 中的金属原子均为四配位，而其中的 N 原子有两
