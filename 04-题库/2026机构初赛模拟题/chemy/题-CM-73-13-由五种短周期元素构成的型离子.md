# 题-CM-73-13-由五种短周期元素构成的型离子

## 题目

### 第 13 题 晶体的对称性与离子的对称性

由五种短周期元素构成的 $3 : 1$ 型离子化合物A 属于立方晶系，其中阴离子B 和阳离子C的对称性均较高，B 的对称性跟乙烷相同，而C 的对称性跟 $\mathrm { BF } _{ 3 }$ 相同。如果将B 和C 均抽象成一个小球(需要考虑朝向)， 则其晶体结构可看为阴离子B 作简单立方堆积。已知阴离子B 由元素 $\pmb { x }$ 、Y 构成， ${ \pmb X } _{ x } { \pmb Y } _{ y }$ 与 $\mathrm { SiO } _{ 2 }$ 的结构极为类似，离子化合物 $\pmb { \mathsf { A } }$ 中 $\omega ( { \pmb X } ) = \quad$ $5.44 \%$ ， $\omega ( \mathsf { Y } ) = 40.1 \%$ 。离子化合物A 中的三次轴与C 中的三次旋转轴取向不同，但与B中的三次旋转轴取向相同。 以B 的中心原子作为晶胞顶点时，某个 $\pmb { \mathsf { A } }$ 的中心原子的坐标为(0.250, 0.792, 0.000)。

13-1 写出离子化合物 $\pmb { \mathsf { A } }$ 的分子式。

13-2 画出阴离子B 和阳离子C 的结构。

13-3 判断离子化合物 $\pmb { \mathsf { A } }$ 的点阵。

13-4 写出离子化合物A 中的五种原子分别有多少种化学环境。

13-5 用波长为 $155.2 \mathrm { pm }$ 的 X-ray 测定离子化合物A 的晶体结构， 得到的最小衍射角为$4.314^{ \circ }$ ， 通过计算求出离子化合物A 的密度。
