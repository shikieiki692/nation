# 题-CM-64-06-钠盐为白色晶体在无氧条件下稳

## 题目

### 第 6 题（11 分）

钠盐 $\pmb { \mathsf { A } }$ 为白色晶体， 在无氧条件下稳定， 遇热或酸分解。A 在无氧条件下加热至 $463 \mathrm { ~ K ~ }$ 发生分解，生成B、C 和气体D(摩尔比1:1:1)。B 可作为纺织、造纸工业的脱氯剂；适量B 与$\mathrm { AgNO } _{ 3 }$ 溶液反应先生成白色沉淀E，静置可得黑色沉淀F，而过量B 与 $\mathrm { AgNO } _{ 3 }$ 溶液反应无明显反应现象。C 与浓硫酸或浓磷酸反应也可放出气体D；D 有刺激性气味，可溶于水；将D 通入B 的溶液中一段时间，可析出结晶物G；在近中性溶液中，C 与红色氯化物H 按 2:1的计量比反应，也可制得G； $\pmb { 6 }$ 在NaOH 溶液中分解，又得回B 和C 的混合溶液。将B 的水溶液与H 按2:1 的计量比反应， 可得到盐I；I 在 NaOH 溶液中分解，则又得到B 的溶液。

6-1 写出 $\mathsf { \pmb { A } } \sim \mathsf { \pmb { I } }$ 的化学式。
6-2 写出过量B 与 ${ \bf A g N O } _{ 3 }$ 溶液反应的化学反应方程式。
6-3 写出 I 在 NaOH 溶液中分解的化学反应方程式。

## 参考答案

第6题（11分）



**6-1** $Na_{2}S_{2}O_{4}$   $Na_{2}S_{2}O_{3}$   $Na_{2}SO_{3}$   $SO_{2}$   $Ag_{2}S_{2}O_{3}$   $Ag_{2}S$   $Na_{2}S_{3}O_{6}$   $SCl_{2}$   $Na_{2}S_{5}O_{6}$ (每个1分)

**6-2** 写出过量 B 与  $AgNO_{3}$  溶液反应的化学反应方程式。

**6-2** $Ag^{+} + 2S_{2}O_{3}^{2-} = [Ag(S_{2}O_{3})_{2}]^{3-}$ (1分)

**6-3** 写出 I 在 NaOH 溶液中分解的化学反应方程式。

**6-3** $2Na_{2}S_{5}O_{6} + 6NaOH = 5Na_{2}S_{2}O_{3} + 3H_{2}O$ (1分)
