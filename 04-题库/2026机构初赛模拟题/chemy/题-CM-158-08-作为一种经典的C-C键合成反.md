# 题-CM-158-08-作为一种经典的C-C键合成反

## 题目

### 第 8 题 22 分， $12 \%$

作为一种经典的 C-C 键合成反应， Baylis-Hillman 反应因为其 “极性反转” 的特点为人所熟知，现在普遍认为该反应具有如下机理：

![](images/76fed70cda785de3f4a568bab5c3aa570323e2204016f4ad7e39201eee901478.jpg)

8-1-1 已知上述途径的第一步是一个快平衡， 消除DABCO(即 A)一步是快反应， 而质子转移是十分快速的。运用平衡近似法， 用[A]、 [B]、[D]表示该反应的速率方程。

8-1-2 当反应体系的醛D 过量时，P 会进一步与D 反应生成副产物 I，画出 I 的结构式。然而该机理无法解释如副产物 I 的生成等诸多问题，于是提出了新的机理。这一新的机理使得 Baylis-Hillman 反应的许多问题得到了解释。如下是底物在 DMSO 等偶极溶剂中的反应

![](images/32101e356b7e7c45c87066d6f0b47ebc6be3cc113e8012c5e6c916d62d5c91d3.jpg)

8-2 已知 C、E、F、H 都是十分活泼的中间体， 通过稳态近似法推导出产物 P 生成的反应速率方程式 $r = \mathrm { d } [ \pmb { \mathsf { P } } ] / \mathrm { d } t$ 。

而当反应底物 D 的芳环上带有缺电子基团时， 实验人员通过大量的数据拟合得到了如下的速率方程：

$$
r = k _{ \mathrm { obs } } [ \pmb { \mathsf { A } } ] [ \pmb { \mathsf { B } } ] [ \pmb { \mathsf { D } } ] ^{ 2 }
$$

8-3-1 判断反应的决速步， 并求出该条件下反应的表观速率常数 $k _{ \mathrm { { obs } } }$ 的表达式。

8-3-2 该溶剂条件下F 到 $\boldsymbol { \mathsf { H } }$ 一步经历了六元环过渡态 ${ \mathsf K } ^{ \ddag }$ ， 画出该过渡态。

8-3-3 若在体系中加入适量质子溶剂(如 $\mathrm { H } _{ 2 } \mathrm { O }$ 、 MeOH 等)， 反应的速率会明显加快； 而质子溶剂过量时，反应速率的增加会趋于减缓。 已知加入质子溶剂前后各底物的级数不变，解释出现上述现象的原因。

## 参考答案

第8题（22分，12%）

![](images/17c0af991906cb0e034ad19b911e6105db2fd853850c3d1b61139f4f38d7edf1.jpg)

8-1-1 由题意可知反应的第二步为决速步，于是有：

$r = \mathrm{d}[\mathbf{P}] / \mathrm{d}t = r_{2} = k_{2}[\mathbf{C}][\mathbf{D}]$ (a) （1分）

而第一步为一快平衡，故由平衡近似法可得：

$[\mathbf{C}] = K_{1}[\mathbf{A}][\mathbf{B}]$ (b) (1分）

将上式代入原速率方程就得到了速率方程的表达式:

$r = d[P]/dt = r_{2} = K_{1}k_{2}[A][B][D]$ (c) （1分）

8-2 观察反应历程可以得到： $r = \mathrm{d}[\mathbf{P}] / \mathrm{d}t = r_{5} - r_{-5}$ (1)

首先对 H 进行稳态近似:

$$
\begin{array}{r l} & \mathrm{d} [ \mathbf {H} ] / \mathrm{d} t = r _{4} + r _{- 5} - r _{5} = 0 \\ & r = \mathrm{d} [ \mathbf {P} ] / \mathrm{d} t = r _{4} = k _{4} [ \mathbf {F} ] \end{array}
$$

(3)

为了知道[F]，我们先后对中间体 C、E、F 进行稳态近似。

对 $\mathbf{C}$ 进行稳态近似有：

$$
\begin{array}{r l} & {\mathrm{d} [ \mathbf {C} ] / \mathrm{d} t = k _{1} [ \mathbf {A} ] [ \mathbf {B} ] + k _{- 2} [ \mathbf {E} ] - k _{- 1} [ \mathbf {C} ] - k _{- 2} [ \mathbf {C} ] [ \mathbf {D} ] = 0 \quad (4) \quad (1 \text {分})} \\ & {\quad [ \mathbf {C} ] = (k _{1} [ \mathbf {A} ] [ \mathbf {B} ] + k _{- 2} [ \mathbf {E} ]) / (k _{- 1} + k _{2} [ \mathbf {D} ]) \quad (5) \quad (1 \text {分})} \end{array}
$$

同理，对 E、F 进行稳态近似得：

$$
\begin{array}{r l} & {\left[ \mathbf {E} \right] = (k _{2} [ \mathbf {C} ] [ \mathbf {D} ] + k _{- 3} [ \mathbf {F} ]) / (k _{- 2} + k _{3} [ \mathbf {D} ]) \quad (6) \quad (1 \text {分})} \\ & {\quad [ \mathbf {F} ] = k _{3} [ \mathbf {E} ] [ \mathbf {D} ] / (k _{4} + k _{- 3}) \quad (7) \quad (1 \text {分})} \end{array}
$$

由(5)、(6)、(7)式可得:

$$
[ \mathbf {E} ] = k _{1} k _{2} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] / \left\{\left[ \left(k _{4} k _{3} k _{2} [ \mathbf {D} ] ^{2} + k _{- 1} k _{3} k _{4} [ \mathbf {D} ]\right) / \left(k _{4} + k _{- 3}\right) \right] + k _{- 1} k _{- 2} \right\} 
[ \mathbf {F} ] = k _{1} k _{2} k _{3} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] ^{2} / (k _{4} k _{3} k _{2} [ \mathbf {D} ] ^{2} + k _{- 1} k _{3} k _{4} [ \mathbf {D} ] + k _{- 1} k _{- 2} k _{- 3} + k _{- 1} k _{- 2} k _{4}) 
r = k _{4} [ \mathbf {F} ] = k _{1} k _{2} k _{3} k _{4} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] ^{2} / (k _{4} k _{3} k _{2} [ \mathbf {D} ] ^{2} + k _{- 1} k _{3} k _{4} [ \mathbf {D} ] + k _{- 1} k _{- 2} k _{- 3} + k _{- 1} k _{- 2} k _{4})
r = k _{\mathrm{obs}} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] ^{2}
$$

8-3-1 当 D 为活泼醛时 $k_{2}$ 和 $k_{3} \gg k_{4}$ 导致第四步成为反应的决速步（1 分）
将式(10)稍事变形：

$$
r = k _{1} k _{2} k _{3} k _{4} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] ^{2} / \left[ k _{4} \left(k _{3} k _{2} [ \mathbf {D} ] ^{2} + k _{- 1} k _{3} [ \mathbf {D} ] + k _{- 1} k _{- 2}\right) + k _{- 1} k _{- 2} k _{- 3} \right] 
$$

可以看到当反应的第四步为决速步时，可以忽略下划线项(即含 $k_{4}$ 项)得到题干所述方程：

$$
r = k _{1} k _{2} k _{3} k _{4} [ \mathbf {A} ] [ \mathbf {B} ] [ \mathbf {D} ] ^{2} / k _{- 1} k _{- 2} k _{- 3} \quad (12) \quad (1 \text {分})
$$

故得到了 $k_{obs}$ 的表达式： $k_{obs}=k_{1}k_{2}k_{3}k_{4}/k_{-1}k_{-2}k_{-3}$ (13) （1 分）

![](images/6d6fffa29fa044abe53610f1f669d3437335a3140fa9ab41798a02423bf87895.jpg)

（4 分，过渡态必须包括结构简式，将要形成或断裂的键用虚线表示；必须有方括号和过渡态符号“‡”，过渡态符号须位于方括号的右上方。缺少虚线键，方括号，电荷符号以及过渡态符号，少画其中一个扣 1 分，扣完为止）

8-3-3 质子溶剂通过与 $K^{\ddagger}$ 形成分子间氢键稳定了过渡态，从而降低了反应的活化能，这使得反应速率明显加快（1 分）

而质子溶剂过量则会导致质子溶剂与 D 形成加合物使得反应速率的增加趋于减缓（1 分）
