# 题-CM-105-08-二元氯化物沸点为在气相中主要

## 题目

### 第 8 题（12 分）

二元氯化物 $MCl_{n}$ (沸点为 $315^{\circ}C$ ) 在气相中主要以二聚体 $M_{2}Cl_{2n}$ 存在。而其在高温下存在如下平衡：
氯化物MCln(沸点为315℃)在气相中主要以二聚体M2Cl2n 存在。而

$$
\mathbf {M} _{2} \mathrm{Cl} _{2 n} (\mathrm{g}) \rightleftarrows 2 \mathbf {M} \mathrm{Cl} _{n} (\mathrm{g}) \quad K ^{\ominus}
$$

在 $8p^{\Theta}$ ，900 K 下研究该体系，测得此时气体密度为 $20.98 \, kg/m^{3}$ 。已知如下热力学数据，忽略压强 p 对焓变与熵变的影响，并近似各物种的等压摩尔热容皆为常数。试通过计算 900 K 下分解反应的平衡常数 $K^{\Theta}$ 以求出 M 的化学式，并画出 $M_{2}Cl_{2n}$ 的结构。

## 参考答案

## 第8题（12分）


由基尔霍夫定律 $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\Theta}(T_2) = \Delta_{\mathrm{r}}H_{\mathrm{m}}^{\Theta}(T_1) + \Delta C_{p,\mathrm{m}}(T_2 - T_1)$ 将上述数据进行线性回归，得：$\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\Theta}(T) = 119.3 - 0.01670T(\mathrm{kJ / mol})$ （1分）故 $\Delta C_{p,\mathrm{m}} = -16.70\mathrm{J}\cdot \mathrm{mol}^{-1}\cdot \mathrm{K}^{-1}$ （0.5分）而等压条件下 $\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta}$ 随温度 $T$ 的变化有： $\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta}(T_2) = \Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta}(T_1) + \Delta C_{p,\mathrm{m}}\ln (T_2 / T_1)$ （0.5分）代入数据得： $\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta}(900\mathrm{K}) = \Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta}(298\mathrm{K}) + \Delta C_{p,\mathrm{m}}\ln (900 / 298)$ $= 160.6 - 16.70\ln (900 / 298)$ $= 142.1\mathrm{J}\cdot \mathrm{mol}^{-1}\cdot \mathrm{K}^{-1}$ （1分）故反应的 $\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\Theta} = \Delta_{\mathrm{r}}H_{\mathrm{m}}^{\Theta} - T\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\Theta} = 104.2 - 900\times 142.1 / 1000 = -23.7\mathrm{kJ}\cdot \mathrm{mol}^{-1}$ （1分）$K^{\Theta} = \exp (-\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\Theta} / RT) = \exp [23.7\times 1000 / (900\times 8.314)] = 23.8$ （1分）已知总压 $p = 8p^{\Theta}$，而 $K^{\Theta} = K_x\times (p / p^{\Theta})^{\Sigma v(\mathbf{B})}$ 。故设 $x(\mathbf{MCl}_n) = x$；$x(\mathbf{M}_2\mathbf{Cl}_{2n}) = 1 - x$ 可得：$8x^{2} / (1 - x) = 23.8$ 解之 $x = 0.790\rightarrow x(\mathbf{MCl}_n) = 0.790;x(\mathbf{M}_2\mathbf{Cl}_{2n}) = 0.210$ （2分）而由理想气体状态方程 $pM = \rho RT$ （0.5分）可得气体平均摩尔质量 $M$ 有：$M = \rho RT / p = 20.98\times 8.314\times 900 / 800 = 196.2$ （1分）而 $M = x(\mathbf{MCl}_n)\times (M_\mathbf{M} + 35.45n) + 2x(\mathbf{M}_2\mathbf{Cl}_{2n})\times (M_\mathbf{M} + 35.45n)$ 代入数据化简可得如下函数：$M_\mathbf{M} = -35.45n + 196.2 / (0.790 + 2\times 0.210)$ （0.5分）列表：
n 1 2 3 4 5 …$M_\mathbf{M}$ 126.7 91.25 55.80 20.35 -15.1 …显然 $n = 3$ 时有唯一合理解 $\mathbf{M} = \mathbf{Fe}$ （1分）
然n = 3 时有唯一合理解M = Fe（1 分）M2Cl2n 的结构：（2 分）共12 分，求解Kϴ5 分，过


$$
\mathbf {M} _{2} \mathrm{Cl} _{2 n}
$$

![](images/876219ad278c1077229fbf13693413926d74a90e2d33fe1721d5f7e8864cda80.jpg)

共 12 分，求解 $K^{\Theta}5$ 分，过程合理并正确求解即可得到全分（即使用答案方法/用 G-H 公式求出对应 $\Delta_{r}G_{m}^{\ominus}$ /用范特霍夫等温式求出 K 皆可）；元素推导 5 分； $Fe_{2}Cl_{6}$ 的结构 2 分。
