# 题-CM-229-06-C60Cu2OHL在吡啶存在的条

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-2-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（14 分，占 11.0%）

C<sub>60</sub>、Cu<sub>2</sub>O、HL 在吡啶存在的条件下于氯苯中共热可制得一种有半导体性质的深黑色固体。

![](images/ea0d3404bd7ef9de90719afbb7d130733d07767b8934eb43974fe00176a822c4.jpg)

**6-1** 研究表明，在该固体中，C<sub>60</sub>仅用相对的 2 个六边形面对铜进行配位，每个六边形面结

合三个铜，铜之间通过桥连配体形成具有一根三重旋转轴和四个镜面的[Cu<sub>6</sub>]单元。单元内的

铜通过 2 种桥连配体连接，其中一种为 Cl<sup>-</sup>，单元间通过 C<sub>60</sub>连接形成一维链。

**6-1-1** 该固体中 Cu 的理论质量分数为 16.68%，N 的理论质量分数为 7.36%。该固体加热至

200℃时失重 14.8%（理论数值），1 个化学式对应失去 3 个共结晶的氯苯分子。结合结构描

述及计算推出该固体的化学式。

**6-1-2** 画出[Cu<sub>6</sub>]单元的结构示意图，可适当简化。

**6-2** 晶体中一维链沿 c 轴平行排布，但相邻的 2 条一维链中 C<sub>60</sub>中心的 c 坐标并不相同。该

晶胞的晶胞参数 a = b = 2245.69 pm，c = 2659.70 pm，α = β = 90°，γ = 120°。

**6-2-1** 同一条一维链中 C<sub>60 </sub>中心的最短距离为 1329.8 pm，相邻链间 C<sub>60 </sub>中心距离为 1370.2

pm 和 1570.7 pm。结合计算指出晶胞中所含化学式的数目，并计算该晶体的密度。

**6-2-2** 指出该晶体所属晶系及点阵形式。（提示：无需考虑氯苯分子的位置）

## 参考答案

**6-1-1** 根据题意，设 1 个化学式对应的式量为 M，则有：

M = 3 × M<sub>r</sub>(C<sub>6</sub>H<sub>5</sub>Cl) / 14.8% = 2281.4 g·mol<sup>-1</sup>（1 分）

那么，1 个化学式中 Cu 原子和 N 原子的数量为：

n(Cu) = M × 16.68% / 63.55 g·mol<sup>-1</sup> = 6

n(N) = M × 7.36% / 14.01 g·mol<sup>-1</sup> = 12（1 分）

N 仅可能来自于 L<sup>-</sup>，因此有 6 个 L<sup>-</sup>。

则理论式量 M <sub>理</sub>为：M <sub>理</sub> = 6M<sub>r</sub>(Cu) / 16.68% = 2286.0 g·mol<sup>-1</sup>

则剩余式量 M <sub>剩</sub>为：

M <sub>剩</sub> = M <sub>理</sub> – 6M<sub>r</sub>(Cu) – 6M<sub>r</sub>(L<sup>-</sup>) – 3M<sub>r</sub>(C<sub>6</sub>H<sub>5</sub>Cl) = 756.6 g·mol<sup>-1</sup> = M<sub>r</sub>(C<sub>60</sub>) + M<sub>r</sub>(Cl)（1 分）

因此化学式为 Cu<sub>6</sub>(C<sub>60</sub>)L<sub>6</sub>Cl·3C<sub>6</sub>H<sub>5</sub>Cl（1 分）

**6-1-2**

![](images/26721b80f7b28b2c7bb170cfd183a96a968296863d9952341c3b55fea5128ecc.jpg)

**6-2-1** 根据题意，c = 2d，说明每条一维链有 2 个化学式在晶胞内。（1 分）

而(1370.2 pm)<sup>2</sup> = (2245.69 pm)<sup>2</sup> / 3 + (d / 3)<sup>2</sup>且(1570.7 pm)<sup>2</sup> = (2245.69 pm)<sup>2</sup> / 3 + (d × 2 / 3)<sup>2</sup>，

说明有 3 种不同的链。（1 分）

综上所述，所含化学式数目为 Z = 6。（1 分，其他合理方法也可得 3 分）

ρ = ZM / N<sub>A</sub>a<sup>2</sup>c·sin120° = 1.960 g·cm<sup>-3</sup>（2 分，不要求有效数字）

**6-2-2** 晶系：三方晶系 点阵形式：R 心六方（2 分）
