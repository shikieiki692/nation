# 题-CM-160-05-Struvite是一种优质肥

## 题目

### 第 5 题

第 5 题 （10 分，占 $8 \%$ ） 肥料的真容

Struvite 是一种优质肥料。晶体中含有三种离子： 四面体的 A、B 和重原子排列呈八面体的C，其比例为 1:1:1。其属于正交晶系，晶胞参数为 $\mathrm { a { = } 6.9550 \mathrm{mathring A} }$ ， $\mathrm { b } { = } 6.1420 \mathrm { ~ \mathrm{mathring A} }$ ，c=11.2180 Å。下图为该晶体的投影图， 已忽略H 原子。

![](images/d59b9f3a32275afec8849f678226dadad0c467e875103ae43b646c04c11ace47.jpg)

将 Struvite 加热至 $100^{ \circ } \mathrm { C }$ ， 会失重 $44.05 \%$ ， 进一步加热会再失重 $10.61 \%$ ， 得到稳定化合物 `\textsf { \textbf { X } } _{ \mathrm { ~ \sf ~ X ~ } }` 中含非金属元素 $\yen 27.83 \%$ 。
重10.61%，得到稳定化合物X。X 中含非金属元素Y 27.83%。

5-1 根据上述数据， 结合晶体信息， 推出A，B，C， $\pmb { x }$ 的化学式与 Struvite 的主要成分 （不要求区分A 和B 离子）

5-2 写出加热时发生的化学反应方程式。

5-3 根据晶胞参数， 计算晶体的理论密度。

## 参考答案

$$
\frac {18.016 * 6}{0.4405} * (1 - 0.4405 - 0.1061) * 0.2783 = 30.97 \mathrm{g/mol} \text {故} \mathbf {Y} \text {为P(1分)}
$$
