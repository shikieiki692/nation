# 题-CM-81-01-1-1化合物在高于的温度下便

## 题目

### 第 1 题（10 分）

1-1 化合物 $\left[Xe_{2}F_{3}\right]\left[AuF_{6}\right]$ 在高于 $60^{\circ}C$ 的温度下便会分解，产物仅为三种化合物。

1-2 硫酸铅的碱式盐 $\left(\mathrm{PbSO}_{4}\cdot2\mathrm{PbO}\right)$ 与硫化铅混合高温熔炼可制备铅单质。

1-3 用 $SnCl_{2}$ 的浓盐酸溶液还原雌黄，可以得到雄黄。

1-4 在硝酸溶液中，用高锰酸钾氧化二氧化碲，可以制得原碲酸。

1-5 将 $ClO_{2}SO_{3}F$ 与 $S_{2}O_{6}F_{2}$ 在 $-50^{\circ}C$ 下投入 Ge 粉中，唯一产物是一种 2:1 型盐。

## 参考答案

1-1  $[Xe_{2}F_{3}][AuF_{6}] = XeF_{2} + XeF_{4} + AuF_{3}$  （2分）

1-2  $PbSO_{4}\cdot2PbO + 2PbS = 5Pb + 3SO_{2}$  （2分）

1-3  $2As_{2}S_{3} + 2SnCl_{2} + 4HCl = As_{4}S_{4} + 2SnCl_{4} + 2H_{2}S$  （2分）

化合物写成其他合理形式，如  $As_{2}S_{3}$  写成  $As_{4}S_{6}$ ， $SnCl_{4}$  写成  $H_{2}SnCl_{6}$  亦可。

1-4  $5TeO_{2} + 2KMnO_{4} + 6HNO_{3} + 12H_{2}O = 5H_{6}TeO_{6} + 2KNO_{3} + 2Mn(NO_{3})_{2}$  （2分）

1-5  $2ClO_{2}SO_{3}F + 2S_{2}O_{6}F_{2} + Ge = (ClO_{2})_{2}[Ge(SO_{3}F)_{6}]$  （2分）
