# 题-CM-251-06-下图为加氢甲酰化的动力学模型催化

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-21-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（12 分）

下图为加氢甲酰化的动力学模型：

![](images/aafc180bd1862f711eeb0c868ae5c37db40bdae4fd4f5743a973ba6dea91ad65.jpg)

催化循环中各转化过程分别为：S 与 CO 可逆结合生成 A，反应的平衡常数为 K<sub>1</sub>；A 与烯烃反应得到 B，平衡常数为 K<sub>2</sub>；B 可异构化为 C，C 又可异构化为 D，异构化的平衡常数分别为 K<sub>3</sub>和 K<sub>4</sub>；D 与 CO 可逆结合得到 F，平衡常数为 K<sub>5</sub>，另一方面，D 也可与 H<sub>2</sub>反应得到E，正反应速率常数为 k<sub>1</sub>，逆反应的速率常数为 k<sub>-1</sub>；E 快速脱除一分子产物 P(在图中未示出)，同时得到 S，此步速率常数为 k<sub>2</sub>；S 还会与 PPh<sub>3</sub>可逆反应得到无催化活性的 G，其平衡常数为 K<sub>6</sub>。

**6-1** 给出 C、D、F、P 的结构。

**6-2** 已知 A、B、C 的浓度相对于其它含 Rh 物种来说可忽略，使用合理的近似推导反应速率(r = d[P] / dt)与烯烃浓度[Aly]、三苯基膦浓度[Pho]、一氧化碳浓度[CO]、氢气浓度[H<sub>2</sub>]及含 Rh 物种总浓度[Rh]的关系。

**6-3** 根据 6-2 导出的速率方程，回答下列问题：

**6-3-1** 反应速率关于[Rh]的浓度级数是否与其他物种有关？若无关，给出级数大小。

**6-3-2** 分别讨论在 CO 分压较大与较小时，反应速率关于[CO]的级数为多少？

**6-3-3** 分别讨论在 H<sub>2</sub>分压较大与较小时，反应速率关于[H<sub>2</sub>]的级数为多少？

## 参考答案

**6-1** 各 0.5 分，共 2 分。

![](images/303fc75be15f667279d30e65e6a8c158259765da2664159d1baaad6cbd0360f7.jpg)

**6-2** 对[D][F][G]进行平衡态假设，有：[D] = K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>[S][CO][Aly] [F] = K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>K<sub>5</sub>[S][CO]<sup>2</sup>[Aly] [G] = K<sub>6</sub>[S][Pho]（1 分）对[E]进行稳态近似可得：d[E] / dt = k<sub>1</sub>[D][H<sub>2</sub>] – (k<sub>-1</sub> + k<sub>2</sub>)[E] = 0则[E] = k<sub>1</sub>[D][H<sub>2</sub>] / (k<sub>-1</sub> + k<sub>2</sub>)（1 分）在忽略 A、B、C 后，根据含 Rh 物种列出物料守恒关系式：[Rh] = [S] + [D] + [E] + [F] + [G]（1 分）则代入各物种浓度关系式可得，S 浓度的表达式为：

[S] = [Rh] / {1 + K<sub>6</sub>[Pho] + [1 + K<sub>5</sub>[CO] + k<sub>1</sub>[H<sub>2</sub>] / (k<sub>-1</sub> + k<sub>2</sub>)]K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>[CO][Aly]}（2 分）而反应速率的表达式为：r = d[P] / dt = k<sub>1</sub>k<sub>2</sub>[D][H<sub>2</sub>] / (k<sub>-1</sub> + k<sub>-2</sub>) = k<sub>1</sub>k<sub>2</sub>K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>[S][CO][Aly][H<sub>2</sub>] / (k<sub>-1</sub> + k<sub>-2</sub>)因此代入[S]可得：r = k<sub>1</sub>k<sub>2</sub>K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>[H<sub>2</sub>][Aly][CO][Rh] / (k<sub>-1</sub> + k<sub>-2</sub>){1 + K<sub>6</sub>[Pho] + [1 + K<sub>5</sub>[CO] + k<sub>1</sub>[H<sub>2</sub>] / (k<sub>-1</sub> + k<sub>2</sub>)]K<sub>1</sub>K<sub>2</sub>K<sub>3</sub>K<sub>4</sub>[CO][Aly]}（2 分）

**6-3-1** 无关（0.5 分），为 1 级（0.5 分）。

**6-3-2** -1 级（0.5 分），0 级或 1 级（0.5 分）。

**6-3-3** 0 级（0.5 分），1 级（0.5 分）。
