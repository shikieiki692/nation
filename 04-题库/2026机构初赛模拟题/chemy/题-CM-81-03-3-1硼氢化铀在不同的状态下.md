# 题-CM-81-03-3-1硼氢化铀在不同的状态下

## 题目

### 第 3 题（13 分）

3-1硼氢化铀 $\mathrm{[U(BH_4)_4]}$ 在不同的状态下具有不同的结构。在气态时，铀的配位原子数为12；在晶体中时，铀的配位原子数为14。分别指出两种情况下，配位原子数为1和2的氢的数目比。

3-2 单核阴离子 $\left[\mathrm{Te}\left(\mathrm{S}_2\mathrm{COC}_2\mathrm{H}_5\right)_3\right]^{-}$ 的结构符合 VSEPR 理论的预测结果，其中 Te 为 5 配位。画出其结构，根据 VSEPR 理论指出其中 Te 的杂化方式。

3-3 W(CO) $_{3}$ (PCy $_{3}$ ) $_{2}$ (P $_{4}$ )和 RhCl(PPh $_{3}$ ) $_{2}$ (P $_{4}$ )均是由[P $_{4}$ ]基团与金属配位形成的化合物(Cy 为环己基)。在 W(CO) $_{3}$ (PCy $_{3}$ ) $_{2}$ (P $_{4}$ )中，磷有三种环境，其数目比为 1:2:3；在 RhCl(PPh $_{3}$ ) $_{2}$ (P $_{4}$ )中，磷也有三种环境，其数目比为 1:1:1。分别画出 W(CO) $_{3}$ (PCy $_{3}$ ) $_{2}$ (P $_{4}$ )和 RhCl(PPh $_{3}$ ) $_{2}$ (P $_{4}$ )的结构。

3-4 高分子化合物 A 是一种多糖，是植物细胞壁的主要结构成分，广泛存在于自然界中。常温下，A 不溶于水，也不溶于酒精、乙醚、丙酮、苯等有机溶剂。A 不能被人体吸收，但具有良好的清理肠道的作用，可以用来治疗糖尿病、治疗便秘、降低血压等，对人体健康有多种多样的益处。

3-4-1 A 是什么物质？写出其名称。

3-4-2 以下关于 A 和淀粉的结构差异中，描述正确的是：

a)淀粉是无支链的高分子化合物，而 A 是有大量支链的高分子化合物；

b)构成淀粉的结构单元只有葡萄糖，而构成A的结构单元是葡萄糖和果糖；

c) 构成淀粉和 A 的结构单元都是葡萄糖，但是缩合形成 A 和淀粉时使用的羟基不同；

d)构成淀粉和 A 的结构单元都是葡萄糖，但是 1 号碳原子的手性有差异。

以纯净的 A 为原料，以硫酸为催化剂，加入过量的醋酸酐，充分反应；然后加入适量水进行水解，可制得高分子化合物 B。B 常供药用，可作为缓释和控释包衣材料。

3-4-3 以最简式计，每摩尔 A 最多与几摩尔醋酸酐反应？

3-4-4 A 具有一定的吸湿性，经醋酸酐处理后为 B 后，其吸湿性如何变化？简述原因。
