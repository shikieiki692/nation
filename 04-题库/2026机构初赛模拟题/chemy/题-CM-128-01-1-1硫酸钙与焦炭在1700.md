# 题-CM-128-01-1-1硫酸钙与焦炭在1700

## 题目

### 第 1 题（16 分）

1-1 硫酸钙与焦炭在 1700 K 下发生反应，产物中有 2 种还原性气体。然而，若使用硫酸钠与焦炭在高温下发生反应，产物中却只有 1 种还原性气体。分别写出反应方程式。

1-2 $\mathrm{SCl}_2$ 与 $\mathrm{NaF}$ 在加热条件下反应得到3种二元化合物，其中一种产物可作为有机物的氟化试剂。

1-3 在大过量的 $AsF_{5}$ 存在下， $Cs_{2}[NiF_{6}]$ 与 $ClF_{5}$ 发生反应，产生 3 种盐，其中一种阳离子是八面体构型。

1-4 在 470 K 下， $B_{10}H_{14}$ 与 $Br_{2}$ 反应，产物中有 2 种元素组成相同的 $D_{3h}$ 中性分子，它们的摩尔数相同。

1-5 向沸腾的钨酸钠溶液中缓慢滴入硫酸镍溶液并加入过二硫酸钠溶液，生成杂多酸盐 $Na_{8}[NiW_{6}O_{24}]$ 。

## 参考答案

1-1 $\mathrm{CaSO_4 + C = CaO + CO + SO_2}$ (2分)
$\mathrm{Na_2SO_4 + 4C = Na_2S + 4CO}$ (2分)
1-2 $3\mathrm{SCl}_2 + 4\mathrm{NaF} = 4\mathrm{NaCl} + \mathrm{S}_2\mathrm{Cl}_2 + \mathrm{SF}_4$ (3分)
1-3 $\mathrm{Cs_2[NiF_6] + ClF_5 + 5AsF_5 = [ClF_6][AsF_6] + Ni[AsF_6]_2 + 2Cs[AsF_6]}$ (3分)
1-4 $\mathrm{B_{10}H_{14} + 13Br_2 = B_9Br_9 + BBr_3 + 14HBr}$ (3分)
1-5 $6\mathrm{WO}_4^{2-} + \mathrm{Ni}^{2+} + \mathrm{S}_2\mathrm{O}_8^{2-} = [\mathrm{NiW}_6\mathrm{O}_{24}]^8 - 2\mathrm{SO}_4^{2-}$ (3分)
