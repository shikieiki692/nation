# 题-CM-127-05-在常压下由于碳半径小以及大键

## 题目

### 第 5 题（8 分）

在常压下，由于碳半径小以及大 $\pi$ 键的缘故，碳酸盐的结构常与硅酸盐等差别较大。但是在高压下，碳酸根也可呈现出奇特的性质。

5-1 在高压下，一些碳酸钙的晶型中含有无限长链的阴离子，请画出该离子的结构示意图。5-2 同样在高压下，加热 $\mathrm{FeCO_3}$ 时，由于铁可变价，故而会导致化学组成可发生改变，从而导致了更丰富的性质。将碳酸亚铁于常温下加热时，仅会生成铁氧化物；但在 $100\mathrm{GPa}$ 左右时，加热可以首先得到 $\mathbf{A}(\omega_{\mathrm{Fe}} = 49.49\%)$ ，随后继续加热， $\mathbf{A}$ 与碳单质重新反应生成 $\mathbf{B}(\omega_{\mathrm{Fe}} = 46.60\%)$ 和铁单质。两者的阴离子中分别含有1个及4个碳原子， $\mathbf{B}$ 中铁碳比为 $1:1$ 。

5-2-1 请写出两者中分别包含的阴离子。

5-2-2 写出 A 转化为 B 的反应方程式。

5-3 $\mathrm{SrCO_3}$ 与 $\mathrm{SrO}$ 在高温高压下可以化合，随压力不同而具有两种晶型，在较低压力(\~7 GPa)下得到正交晶系的 $\mathbf{C}(a = 9.9919\mathrm{mathring A}, b = 7.1491\mathrm{mathring A}, c = 6.8422\mathrm{mathring A}, \rho = 4.82\mathrm{g}\cdot \mathrm{cm}^{-3})$ ，而在较高压力(\~20 GPa)下则能得到四方晶系的畸变反钙钛矿型产物 $(a = 6.4904\mathrm{mathring A}, c = 9.7150\mathrm{mathring A})$ ，下图示出了该晶体单层结构沿 $c$ 轴投影图。请写出具有其结构特点的结构简式(无需标明电荷)，并计算四方晶系晶体的理论密度。
