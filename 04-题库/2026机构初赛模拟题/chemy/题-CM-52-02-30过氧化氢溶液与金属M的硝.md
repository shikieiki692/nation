# 题-CM-52-02-30过氧化氢溶液与金属M的硝

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy32-3-2`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（10 分）

30%过氧化氢溶液与金属 M 的硝酸盐溶液反应，析出一种组成为 $MO_{4}\cdot2H_{2}O$ 的化合物。将 1.000 g 纯净的 $MO_{4}\cdot2H_{2}O$ 在 800 °C 下充分加热分解，得到 0.830 g 灰绿色的氧化物粉末 X，产生的混合气体在 101.3 kPa，423 K 下的密度为 $0.620\ g\cdot L^{-1}$ 。已知基态 M 原子中含有 4 个单电子。

2-1 通过计算和推理，确定 M 的元素符号和氧化物粉末 X 的化学式。

2-2 写出 $MO_{4}\cdot2H_{2}O$ 在 $800^{\circ}C$ 下分解的反应方程式。

2-3 指出 $MO_{4}\cdot2H_{2}O$ 中 M 的氧化数。

2-4 将 $(\mathrm{NH}_{4})_{2}\mathrm{M}_{2}\mathrm{O}_{7}$ 加热至 $800^{\circ}C$ 分解也能得到氧化物粉末 X，并有单质气体生成。写出化学反应方程式。

第 2 题 （10 分）

2-1 由 $p M = \rho R T$ 得：混合气体的平均摩尔质量为：
$M = \rho R T / \ p = 0.620 \ { \mathrm { g } } { \cdot } { \mathrm { L } } ^{ - 1 } \times 8.314 \ { \mathrm { J } } { \cdot } { \mathrm { mol } } ^{ - 1 } { \cdot } { \mathrm { K } } ^{ - 1 } \times 423 \ { \mathrm { K } } / \ 101.3 \ { \mathrm { kPa } } = 21.5 \ { \mathrm { g } } { \cdot } { \mathrm { mol } } ^{ - 1 }$ （1 分）设氧化物粉末 $\mathsf { \pmb X }$ 的化学式为 $\mathrm { MO } _{ x }$ ， 则分解产生的氧气与水的物质的量之比为 $( 2 - 0.5 x ) : 2$ $[ ( 2 - 0.5 x ) \times 32.00 \ \mathrm { g } \cdot \mathrm { mol } ^ { - 1 } + 2 \times 18.02 \ \mathrm { g } \cdot \mathrm { mol } ^ { - 1 } ] / [ 2 + ( 2 - 0.5 x ) ] = 21.5 \ \mathrm { g } \cdot \mathrm { mol } ^ { - 1 }$ （1 分）解得 $x = 2.67$ ，即 $\mathsf { X }$ 的化学式为 $\mathrm { M } _{ 3 } \mathrm { O } _{ 8 }$ （0.5 分）
设 $\mathrm { M }$ 的原子量为 $A$ ，则：
1.000 g / [A + 16.00 × 4 + 18.02 × 2] = 0.830 g / [A + 16.00 × 8/3] （1 分）
解得A = 237（0.5 分）。对比元素周期表可知，M 为U（1 分），X 的化学式为U3O8。2-2 写出MO4·2H2O 在800 °C 下分解的反应方程式。2-2 3UO4·2H2O = U3O8 + 2O2 + 6H2O（2 分）2-3 指出MO4·2H2O 中M 的氧化数。2-3 +6（1 分）2-4 将(NH4)2M2O7 加热至800°C 分解也能得到氧化物粉末X，并有单质气体生成。写出化学反应方程式。2-4 9(NH4)2U2O7 = 6U3O8 + 2N2 + 14NH3 + 15H2O（2 分）
