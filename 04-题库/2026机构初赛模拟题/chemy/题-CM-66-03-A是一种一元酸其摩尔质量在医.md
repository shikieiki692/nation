# 题-CM-66-03-A是一种一元酸其摩尔质量在医

## 题目

### 第 3 题（9 分）

A 是一种一元酸， 其摩尔质量 $90.07 ~ \mathrm { g / mol }$ ， $K _{ \mathrm { a } } \Theta = 1.4 \times 10^{ - 4 }$ 。 $\mathsf { \pmb A }$ 在医药方面被用作载体剂、助溶剂等；同时 $\pmb { \mathsf { A } }$ 有很强的防腐保鲜功效， 在食品制作中也被广泛利用。 $\mathsf { \pmb A }$ 的聚合物可在人体内自动降解，因此可作手术缝线使用。 $\pmb { \mathsf { A } }$ 是人体代谢过程中的一种重要中间产物，当A进入血液时，血液中的 $\mathrm { H } _{ 2 } \mathrm { CO } _{ 3 } { - } \mathrm { HCO } _{ 3 } \cdot$ 缓冲对可将其快速除去，进而维持体液pH 基本恒定。

3-1 指出 $\pmb { \mathsf { A } }$ 是什么化合物， 并画出 $\pmb { \mathsf { A } }$ 的 Lewis 结构式。

3-2 已知 $\mathrm { H } _{ 2 } \mathrm { CO } _{ 3 }$ 的 $\mathsf { p } K _{ \mathsf { a } 1 } = 6.37$ ， $\mathsf { p } K _{ \mathrm { a } 2 } = 10.25$ 。 计算血液中的 $\mathrm { H } _{ 2 } \mathrm { CO } _{ 3 } { - } \mathrm { HCO } _{ 3 } \cdot$ 缓冲对与酸A 反应的平衡常数。

3-3 血液中 $c ( \mathrm { H } _{ 2 } \mathrm { CO } _{ 3 } ) = 2.5 \times 10^{ - 3 } \mathrm { mol } { \cdot } \mathrm { L } ^{ - 1 }$ ， $c ( \mathrm { HCO _{ 3 } \mathrm { ^{ - } } } ) = 2.7 \times 10^{ - 2 } \mathrm { mol \cdot L ^{ - 1 } }$ 。 计算血液的 pH。

3-4 画出 $\pmb { \mathsf { A } }$ 的聚合物的结构简式。

## 参考答案

(2 分, 不标出孤对电子不得分)

$$
3 - 2 K ^ {\Theta} = \frac {\left[ H _ {2} C O _ {3} \right] \left[ L a c ^ {-} \right]}{\left[ H L a c \right] \left[ H C O _ {3} ^ {-} \right]} = \frac {K _ {a} ^ {\Theta} (H L a c)}{K _ {a 1} ^ {\Theta} \left(H C O _ {3} ^ {-}\right)} = \frac {1 . 4 * 1 0 ^ {- 4}}{1 0 ^ {- 6 . 3 7}} = 3 4 4 (2 \text {分})
3 - 3 \mathrm{pH} = \mathrm{p} K _ {a 1} ^ {\theta} \left(H C O _ {3} ^ {-}\right) + l g \frac {\left[ H C O _ {3} ^ {-} \right]}{\left[ H _ {2} C O _ {3} \right]} = 6. 3 7 + l g \frac {2 . 7 \times 1 0 ^ {- 2}}{2 . 5 \times 1 0 ^ {- 3}} = 7. 4 0 (2 \text {分})
$$
