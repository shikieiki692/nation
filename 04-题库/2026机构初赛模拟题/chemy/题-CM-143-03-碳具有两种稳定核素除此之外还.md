# 题-CM-143-03-碳具有两种稳定核素除此之外还

## 题目

### 第 3 题（9 分）

碳具有 ${}^{12}C$ 、 ${}^{13}C$ 两种稳定核素；除此之外，还有多种不稳定核素。

3-1 碳的核素 ${}^{11}$ C 是人造核素，它具有 2 种衰变方式(速率常数分别为 $k_{1}=3.402\times10^{-2}\min^{-1}$ 和 $k_{2}=6.4\times10^{-5}\min^{-1}$ )，衰变产生的核素均为 ${}^{11}$ B。

3-1-1 分别写出 2 种衰变方式的核反应方程式(标出各物种的质量数和电荷数; 不要求顺序)。
3-1-2 计算 ${}^{11}C$ 的半衰期。

3-2 同种元素的不同核素形成的分子，其物理性质和化学性质往往有微小的差异。在 73.2 K 下，测定 ${}^{12}$ CO 和 ${}^{13}$ CO 的混合液体上方的蒸气压，当液体中 ${}^{13}$ CO 的含量为 55.25% 时，测得混合液体上方的平衡蒸汽压为 253.5 mmHg；当液体中 ${}^{13}$ CO 的含量（摩尔分数，下同）为 86.02% 时，测得混合液体上方的平衡蒸汽压为 252.8 mmHg。(提示：氧同位素对体系的影响忽略不计)

3-2-1 计算反应 ${}^{12}\mathrm{CO}(\mathrm{l}) + {}^{13}\mathrm{CO}(\mathrm{g}) \rightarrow {}^{13}\mathrm{CO}(\mathrm{l}) + {}^{12}\mathrm{CO}(\mathrm{g})$ 的平衡常数 $K^{\ominus}$ 和 $\Delta_{r}G_{m}^{\ominus}$ 。

3-2-2 如何从含有少量 ${}^{13}CO$ 的 CO 中富集 ${}^{13}CO$ ？提出可行的工业生产方法。

## 参考答案

第3题（9分）碳的同位素
碳具有 $^{12}$ C、 $^{13}$ C两种稳定核素；除此之外，还有多种不稳定核素。
3-1 碳的核素  $^{11}$ C 是人造核素，它具有2种衰变方式(速率常数分别为  $k_{1}=3.402\times10^{-2}\min^{-1}$  和  $k_{2}=6.4\times10^{-5}\min^{-1}$ )，衰变产生的核素均为  $^{11}$ B。
3-1-1 分别写出2种衰变方式的核反应方程式(标出各物种的质量数和电荷数；不要求顺序)。
3-1-2 计算  $^{11}$ C 的半衰期。

3-1-1  $^{11}_{6}$ C →  $^{11}_{5}$ B +  $^{0}_{1}$ e⁺（1分）
 $^{11}_{6}$ C +  $^{0}_{-1}$ e →  $^{11}_{5}$ B（1分）
3-1-2 总反应速率常数为： $k=k_{1}+k_{2}=3.408\times10^{-2}\min^{-1}$ （1分）
半衰期  $t_{1/2}=\ln2/k=20.34\min$ （1分）

3-2 同种元素的不同核素形成的分子，其物理性质和化学性质往往有微小的差异。在73.2K下，测定  $^{12}$ CO 和  $^{13}$ CO 的混合液体上方的蒸气压，当液体中  $^{13}$ CO 的含量为55.25%时，测得混合液体上方的平衡蒸汽压为253.5 mmHg；当液体中  $^{13}$ CO 的含量（摩尔分数，下同）为86.02%时，测得混合液体上方的平衡蒸汽压为252.8 mmHg。(提示：氧同位素对体系的影响忽略不计)
3-2-1 计算反应  $^{12}$ CO(l) +  $^{13}$ CO(g) →  $^{13}$ CO(l) +  $^{12}$ CO(g) 的平衡常数 K° 和 ΔrGm°。
3-2-2 如何从含有少量  $^{13}$ CO 的 CO 中富集  $^{13}$ CO？提出可行的工业生产方法。

3-2-1 设  $^{12}$ CO(g)、 $^{13}$ CO(g) 蒸气压分别为 x 和 y，则：
(1 - 0.5525)x + 0.5525y = 253.5 mmHg
(1 - 0.8602)x + 0.8602y = 252.8 mmHg
解得：x = 254.76 mmHg（1分） y = 252.48 mmHg （1分）
K° = x / y = 1.0090（1分）
ΔrGm° = -RTlnK° = -5.5 J/mol（1分）
少保留1位有效数字，结果算出-5 J/mol或-6 J/mol，也可以。
3-2-2 可以通过精馏（1分）的方式，将液态的CO连续地加入精馏塔内，通过气、液两相回流，使得  $^{12}$ CO 不断从液相往气相中转移，而  $^{13}$ CO 更多保留在液相中，最终可在塔底获得含有较多量  $^{13}$ CO 的液体。
