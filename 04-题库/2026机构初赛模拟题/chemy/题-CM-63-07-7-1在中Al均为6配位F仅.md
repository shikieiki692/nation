# 题-CM-63-07-7-1在中Al均为6配位F仅

## 题目

### 第 7 题（10 分）

7-1 在 $\mathrm { Al } _{ 7 } \mathrm { F } _{ 30 } { } ^{ 9 \cdot }$ 中， Al 均为 6 配位，F 仅做边桥基配体或为端基配体， 指出桥基氟与端基氟的个数比。 该阴离子呈现出与交叉式乙烷相同的对称性， 画出该阴离子的结构示意图。

7-2 在特殊的条件下，铝能形成低价的卤化物。将AlBr 溶于甲苯和四氢呋喃(THF)的混合溶剂中， 浓缩结晶， 可析出最简式为 $\mathrm { Al } _{ 5 } \mathrm { Br } _{ 7 }$ ·5THF 的化合物，其中铝原子之间依靠Al-Al 键相连， 所有的铝原子均满足8 电子结构。

7-2-1 每摩尔 $\mathrm { Al } _{ 5 } \mathrm { Br } _{ 7 } { \cdot } 5 \mathrm { THF }$ 中存在多少 Al-Al 键？

7-2-2 X-射线衍射表明， $\mathrm { Al } _{ 5 } \mathrm { Br } _{ 7 } { \cdot } 5 \mathrm { THF }$ 在晶体中仅存在数量比为1 : 1 的两种粒子，一种为 $+ 1$ 价阳离子，其中 Al 有 3 种化学环境；另一种为-1 价阴离子，其中 Al 有 2 种化学环境；阴阳离子中均有一个铝原子与四个铝原子成键。 分别画出阴阳离子的结构式。

7-2-3 为解释该低价卤化物特殊结构的生成，人们认为， 该结构是由铝(I)对某种氧化态的铝发生亲核进攻而得到的。被亲核进攻的铝的氧化态是多少？
