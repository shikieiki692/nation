# 题-CM-244-06-MgCu2一种经典的拉维斯相其晶

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-9-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（11 分）

MgCu<sub>2</sub>一种经典的拉维斯相，其晶体结构如下图所示。其中 A (黑球)表示 Mg 原子，B (白球)表示 Cu 原子。

![](images/fcb92fc5b527233d1ef326e8196cfb59f01a35b8a23aa10c02ec45eeb65a2918.jpg)

金属间化合物 XY<sub>2</sub>可以看作一种六方 MgCu<sub>2</sub>，其中 X 原子从立方金刚石的结构变为了六方金刚石，而 Y 原子同样形成了[Y<sub>4</sub>]四面体单元，并且[Y<sub>4</sub>]四面体以共顶点和共面的方式互相连接。以下示出了 XY<sub>2</sub>晶胞的部分原子：

![](images/3f2e808a37cca69fef419c6d138109293cc0e6b28fe1be1649e8aee39f7cb88d.jpg)

**6-1** 补全晶胞中的所有原子。

**6-2** 指出 Y 原子对 X 原子的配位数，并写出 X 周围的 Y 组成的多面体的名称。

**6-3** 假设 6-2 中的多面体是半正多面体（即各边长均相等的多面体），计算理想情况下晶胞参数 c/a 的值。

![](images/d5293b50e276126292b463134eaa2c20a082db0483e5695b93dbceb1ecad50b7.jpg)

比次外层电子数少 6。通过计算写出 XY<sub>2</sub>的化学式 (提示：如果没有做出 6-3，可以使用 6- 5 的数据进行计算本题)。

**6-5** 事实上 6-2 中的多面体并非完美的半正多面体。在实际的晶体中，晶胞参数 c = 780.0 pm，其中一个 Y 原子的分数坐标为(0.8300, 0.1700, 0.2500)，计算该原子到晶胞顶点的最短距离。

## 参考答案

**6-1**（2 分）

可参考第 33 届中国化学奥林匹克(初赛)试题第 6 题图，不必示出 Y 原子之间的连线。

**6-2** 配位数：12（1 分）；多面体：截角四面体（1 分）。

**6-3**（共 2 分）

晶胞参数 a 即为截角四面体中正六边形的直径，c 为两个截角四面体的高度。

![](images/92a3adac9bb404542879825ab73e9aee37ccdbb34a76c738be06f8b52a354d30.jpg)

轴率 c / a = (4√6d/3) / 2d = 2√6/3 ≈ 1.633（1 分）

直接使用 6-5 中数据，得到 c / a = 780.0 / 478.0 = 1.632 的，不得分。除此之外用合理方法

得到相同答案的也得满分。

**6-4**（共 3 分）

![](images/2cd2a593409d0b8242ca4c23316de833ffae63085719998ef10ff0201409cd2b.jpg)

（1 分）

通过列举可知满足电子结构且原子量合适的 X 只有 Mg、Ca、Sr、Ba 和一部分镧系元素

（1 分）

试验可得只有当 X = Mg 时有合理的 Y = Zn，因此其化学式为 MgZn<sub>2</sub>（1 分）

若用 c = 780.0 pm 算出正确的答案，也可得满分。
