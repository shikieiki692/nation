# 题-CM-72-01-1-1氟化氢和氯化氢可以由氟

## 题目

### 第 1 题（14 分）

1-1 氟化氢和氯化氢可以由氟化钙、 氯化钠分别与浓硫酸反应制得， 但溴化氢、 碘化氢却无法如此制备，为什么？

1-2 硫离子为无色离子， 但在空气中久置的硫化钠溶液会变为深红色， 请解释原因。

1-3 钙、锶、 钡均为碱土金属， 它们与水反应的剧烈程度逐渐增大， 请解释原因。

1-4 在 CO 气氛中， SbF5 存在下，用 $\mathrm { XeF } _{ 2 }$ 氧化 ${ \mathrm { Fe } } ( \mathrm { CO } ) _{ 5 }$ ， 可制得化学式为 $[ \mathrm { Fe ( CO ) } _{ 6 } ] ^{ 2 + }$ 的阳离子，其呈现八面体构型。请指出该配合物中心原子的氧化态、价电子组态和杂化方式，并预测该配合物的磁属性。

1-5 在固态， $\mathrm { { SnCl } } _{ 2 }$ 呈现以氯桥键连接的一维长链结构， Sn 原子的配位数为 3。 请画出固态$\mathrm { SnCl } _{ 2 }$ 的结构， 用 VSEPR 理论预测 $\mathrm { Sn }$ 的杂化方式。

## 参考答案

<table><tr><td>1-1 浓硫酸有强氧化性,会氧化溴化氢和碘化氢,所以只能用三溴化磷、三碘化磷水解的办法来制备溴化氢和碘化氢。(2分)</td></tr><tr><td>1-2 硫离子为无色离子,但在空气中久置的硫化钠溶液会变为深红色,请解释原因。</td></tr><tr><td>1-2 因为空气中的氧气氧化部分硫离子成为硫单质,然后再形成多硫化物所致。(2分)</td></tr><tr><td>1-3 钙、锶、钡均为碱土金属,它们与水反应的剧烈程度逐渐增大,请解释原因。</td></tr><tr><td>1-3 从Ca到Ba金属的活泼型增大: $M(OH)_2$ 的溶解度增大,故反应剧烈程度增大。(2分)答出一点即可得满分,其他合理答案(从动力学角度解释)均可得分。若答“从Ca到Ba还原性增强”或“电极电势更负”等热力学原因,不得分。</td></tr><tr><td>1-4 在CO气氛中, $SbF_5$ 存在下,用 $XeF_2$ 氧化 $Fe(CO)_5$ ,可制得化学式为 $[Fe(CO)_6]^{2+}$ 的阳离子,其呈现八面体构型。请指出该配合物中心原子的氧化态、价电子组态和杂化方式,并预测该配合物的磁属性。</td></tr><tr><td>1-4 氧化态+2(1分)价电子组态 $d^6$ (或答 $t_{2g}{}^6 e_g{}^0$ )(1分)杂化方式 $d^2 sp^3$ (1分)抗磁性(1分)</td></tr><tr><td>1-5 在固态, $SnCl_2$ 呈现以氯桥键连接的一维长链结构,Sn原子的配位数为3。请画出固态 $SnCl_2$ 的结构,用VSEPR理论预测Sn的杂化方式。</td></tr><tr><td>1-5<img src="images/9c1920bd1f09a280466ce2fcce7822eec82f7fedfd97f229137ea9913956d4b4.jpg"/>(3分) $sp^3$ (1分)</td></tr></table>
