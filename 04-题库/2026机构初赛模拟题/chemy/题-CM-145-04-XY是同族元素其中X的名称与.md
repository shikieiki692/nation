# 题-CM-145-04-XY是同族元素其中X的名称与

## 题目

### 第 4 题（14 分）

X、Y 是同族元素，其中 X 的名称与月亮有关，Y 的名称与地球有关，二者具有相似的化学性质。X 的二氧化物 A 在有机化学中有广泛应用，其水溶液可被二氧化硫还原生成 X 的单质(反应 1)；A 可与 H 反应得到离子 B 和离子 C(反应 2)，B 比 C 多一个 X 原子。X 的氯化物 D 与 NH₃ 反应会得到一种易爆物质 E(反应 3)。D 与 A 反应可得到 F，F 与 Cu 单质反应，产物包括 A 和 G(反应 4)，F 亦可与过量 S 单质反应(反应 5)，产物除 A 和 G 外，还有与 G 结构相似的 I。含 Y 57.01% 的 Z²-与亚硫酸根反应，生成 Y 的单质以及含氧阴离子 H(反应 6，除 H 外其它产物未指出)。H 的钠盐是分析化学中的一种常用试剂，与 I₂ 反应转化为 C。推出 A～I 以及 Z²-的化学式，并写出反应 1～6 的方程式。

## 参考答案

化学式各 0.5 分，共 5 分。

A SeO₂ B SeS₄O₆²⁻ C S₄O₆²⁻ D SeCl₄ E Se₄N₄
F SeOCl₂ G Se₂Cl₂ H S₂O₃²⁻ I S₂Cl₂ Z²⁻ TeS₃²⁻

反应 1: SeO₂ + 2SO₂ + 2H₂O = 2H₂SO₄ + Se (1 分)

反应 2: 4H⁺ + SeO₂ + 4S₂O₃²⁻ = S₄O₆²⁻ + SeS₄O₆²⁻ + 2H₂O (2 分)

反应 3: 12SeCl₄ + 64NH₃ = 3Se₄N₄ + 2N₂ + 48NH₄Cl (1 分)

反应 4: 3Cu + 4SeOCl₂ = 3CuCl₂ + 2SeO₂ + Se₂Cl₂ (2 分)

反应 5: 6S + 4SeOCl₂ = 3S₂Cl₂ + 2SeO₂ + Se₂Cl₂ (2 分)

反应 6: TeS₃²⁻ + 2SO₃²⁻ = 2S₂O₃²⁻ + S²⁻ + Te (1 分)
