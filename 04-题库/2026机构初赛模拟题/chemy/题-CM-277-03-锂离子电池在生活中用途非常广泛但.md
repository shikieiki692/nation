# 题-CM-277-03-锂离子电池在生活中用途非常广泛但

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-7-3`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（7 分）

锂离子电池在生活中用途非常广泛。但由于锂资源具有储量有限，成本较高等缺点，钠离子电池逐渐取代锂离子电池进入科学家的视野。如以 Na<sub>x</sub>C 为负极，Na<sub>1-x</sub>MnO<sub>2 </sub>为正极，以氟磷酸钠的碳酸乙烯酯或碳酸二甲酯溶液为电解质，构成了一种钠离子电池。

**3-1** 写出电池放电时正负极的电极反应方程式和总反应方程式。

**3-2** 正极材料 Na<sub>1-x</sub>MnO<sub>2</sub>的结构可描述为，锰和氧通过[MnO<sub>6</sub>]八面体共棱连接形成二维层状结构，Na<sup>+</sup>填在层间。请据此分析钠离子电池过度充电对正极材料产生的影响。

**3-3** 普鲁士蓝类化合物（如 NaFe[Fe(CN)<sub>6</sub>]）也可作为钠离子电池的电极材料，简述原因。

**3-4** 与锂离子电池不同，钠离子电池一般不采用石墨作为负极，简述理由。

## 参考答案

**3-1** 负极：Na<sub>x</sub>C → C + xNa<sup>+</sup> +xe<sup>-</sup>（1分）

正极：Na<sub>1-x</sub>MnO<sub>2</sub> + xNa<sup>+</sup> + xe<sup>-</sup> → NaMnO<sub>2</sub>（1分）

总： Na<sub>1-x</sub>MnO<sub>2 </sub>+ Na<sub>x</sub>C → NaMnO<sub>2</sub> + C（1分）

写成其他合理形式，如Na<sub>x-y</sub>C等并配平，也可得分。

**3-2** 钠离子电池过度充电，使得 x变大，填在层间的钠离子数目减少，导致 MnO<sub>6</sub>层间发

生作用，发生相变，形成无序的三维结构，进而损害正极材料的性能。（1分）

**3-3**

普鲁士蓝类化合物中铁和氰形成三维骨架，具有大孔隧道结构，可允许Na<sup>+</sup>进出；（1分

）铁的价态可以发生变化。（1分）

**3-4**

与锂离子相比，钠离子与石墨层间的作用力较小。且钠离子半径较大，与石墨的层间距

不匹配。（1分，答出一点即可得分。）
