# 题-CM-67-04-将DMPDA溶液与溶液混合室

## 题目

### 第 4 题（10 分）

将(DMPDA) $\mathrm { PtSO _{ 4 } }$ 溶液与 ${ \mathrm { Ba } } ( { \mathrm { AM } } )$ 溶液混合， 室温搅拌 $3 \mathrm { h }$ ， 滤去生成的硫酸钡沉淀， 蒸发结晶，析出一种白色晶体 $\mathrm { Pt ( DMPDA ) } ( \mathrm { AM } ) { \cdot } x \mathrm { H } _{ 2 } \mathrm { O }$ 。 晶体衍射表明， $\mathrm { Pt } ( \mathrm { DMPDA } ) ( \mathrm { AM } ) { \cdot } x \mathrm { H } _{ 2 } \mathrm { O }$ 属四方晶系， 晶胞参数 $a = b = 1361.4 \mathrm { pm }$ ， $c = 845.1 \mathrm { pm }$ ， 密度 $D = 2.016 { \mathrm { g } } / { \mathrm { cm } } ^{ 3 }$ ， $Z = 4$ 。

(AM 为2-烯丙基丙二酸根离子； DMPDA 为 2,2-二甲基-1,3-丙二胺)

4-1 通过计算和推演， 求出该晶体化学式中 $x$ 的数值。

4-2 将上述晶体脱水后可得到平面四方配合物Pt(DMPDA)(AM)。 在固体中该化合物以 $\pmb { \mathsf { X } } _{ 1 }$ 的形式存在；将该固体溶于甲醇中，则该化合物部分异构化 $\pmb { \chi } _{ 2 }$ 并达成平衡；若向该甲醇溶液中加入大量水， 则其几乎全部异构化为 ${ \pmb X } _{ 2 }$ 。

4-2-1 画出 $\pmb { \mathsf { X } } _{ 1 }$ 和 $\pmb { \chi } _{ 2 }$ 的结构示意图。

4-2-2 解释向 Pt(DMPDA)(AM)的甲醇溶液中加入水时 $\pmb { \mathsf { X } } _{ 1 }$ 异构化为 $\pmb { \chi } _{ 2 }$ 的原因。
水时X1 异构化为X2 的原

4-2-3 若将 Pt(DMPDA)(AM)的甲醇溶液加热， 则 $\pmb { \chi } _{ 1 }$ 和 $\pmb { X } _{ 2 }$ 之间的平衡如何移动？ 解释原因。

## 参考答案

4-2-3 向生成  $X_{1}$  的方向移动（1 分）。
因为  $X_{1}$  异构化为  $X_{2}$  的过程为放热反应（1 分）。 $X_{2}$  的溶剂化更强烈，因此  $X_{1}$  转化成  $X_{2}$  是放热的。
</div>

和  $C_{n+1}H_{2n+3}NH_{2}$  的混合物 3.33 g 与  $NaNO_{2}$  混合并用盐酸酸化，放出的  $N_{2}$  经干燥后在 27.2℃，101.3 kPa 下的体积为 1.480 L。通过计算和推理确定 n 的值和混合物中两种胺的质量分数。

3-2 两种胺的总量为 x = pV/RT = 0.06004 mol（1 分）

平均摩尔质量 M = m / x = 55.46 g/mol，介于  $C_{2}H_{5}NH_{2}$  和  $C_{3}H_{7}NH_{2}$  之间，故 n = 2（1 分）

再由：

 $m\omega(\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{NH}_{2}) / M(\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{NH}_{2}) + m\omega(\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{NH}_{2}) / M(\mathrm{C}_{3}\mathrm{H}_{7}\mathrm{NH}_{2}) = x$ （0.5 分）

 $\omega(\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{NH}_{2}) + \omega(\mathrm{C}_{3}\mathrm{H}_{7}\mathrm{NH}_{2}) = 1$ （0.5 分）

得到： $\omega(\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{NH}_{2}) = 21.1\%$ ;  $\omega(\mathrm{C}_{3}\mathrm{H}_{7}\mathrm{NH}_{2}) = 78.8\%$ （1 分）

不要求有效数字。
