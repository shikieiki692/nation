# 题-CM-73-03-在近中性的溶液中过二硫酸根离

## 题目

### 第 3 题（12 分）

在近中性的溶液中，过二硫酸根离子和硫代硫酸根离子间能发生氧化还原反应，其速率方程可表示为：

$$
r = k _{ \mathrm { obs } } [ c ( \mathrm { S } _{ 2 } \mathrm { O _{ 8 } } ^{ 2 \mathrm { - } } ) ] ^{ x } [ c ( \mathrm { S } _{ 2 } \mathrm { O _{ 3 } } ^{ 2 \mathrm { - } } ) ] ^{ y }
$$

有人提出该反应的关键步骤机理如下：

$$
\mathrm { S } _{ 2 } \mathrm { O } _{ 8 } { } ^{ 2 - }  2 \mathrm { SO } _{ 4 } { } ^{ - }
\mathrm { SO } _{ 4 } { \cdot } ^{ - } + \mathrm { H } _{ 2 } \mathrm { O }  \mathrm { HSO } _{ 4 } { \cdot } + \mathrm { OH } ^{ . }
\mathrm { OH ^{ \cdot } + S _{ 2 } O _{ 3 } ^{ 2 - }  OH ^{ - } + S _{ 2 } O _{ 3 } ^{ - } \uparrow }
\mathrm { S } _{ 2 } \mathrm { O } _{ 3 } \cdot ^{ - } + \mathrm { S } _{ 2 } \mathrm { O } _{ 8 } ^{ 2 - } \longrightarrow \mathrm { S } _{ 3 } \mathrm { O } _{ 7 } ^{ 2 - } + \mathrm { SO } _{ 4 } \cdot ^{ - }
\mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { \cdot } ^{ - } + \mathrm { SO } _{ 4 } { \cdot } ^{ - }  \mathrm { S } _{ 3 } \mathrm { O } _{ 7 } { } ^{ 2 - }
\mathrm { S } _{ 3 } \mathrm { O } _{ 7 } { } ^{ 2 - } + \mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 - } \longrightarrow \mathrm { S } _{ 4 } \mathrm { O } _{ 6 } { } ^{ 2 - } + \mathrm { SO } _{ 4 } { } ^{ 2 - }
$$

以上 6 步反应(视为基元反应)的速率常数分别为 $k _{ 1 } , ~ k _{ 2 } , ~ k _{ 3 } , ~ k _{ 4 } , ~ k _{ 5 } , ~ k _{ 6 \circ }$

3-1 写出总反应的化学反应方程式。
3-2 根据以上机理，利用稳态近似法，推出速率方程中 $x , y$ 的值及表观速率常数 $k _{ \mathrm { { obs } } }$ 的表达式。(提示：体系中出现的自由基和 $\mathrm { S } _{ 3 } \mathrm { O } _{ 7 } { } ^{ 2 }$ -均是活泼的中间体)
3-3 为验证上述机理，用水浴控制反应体系的温度恒定，测定离子浓度随时间的变化。 实验开始时，两种离子的初始浓度分别为 $c _{ 0 } ( \mathrm { S } _{ 2 } \mathrm { O } _{ 8 } { } ^{ 2 - } ) = 0.400 \mathrm { mol / L }$ 和 $c _{ 0 } ( \mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 - } ) = 2.27 \times 10^{ - 2 } \mathrm { mol / L }$ ；当 $t = 20.0 \ \mathrm { min }$ 时，测得 $c ( \mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 - } ) = 1.63 \times 10^{ - 2 } \mathrm { mol / L }$ 。 忽略离子活度的影响，请根据以上实验结果计算：
3-3-1 表观速率常数 kobs。
3-3-2 $t = 30.0 \ \mathrm { min }$ 时硫代硫酸根的浓度 $c ( \mathsf { S } _{ 2 } \mathbf { O } _{ 3 } { } ^{ 2 - } )$ 。

## 参考答案

## 第3题（12分）


$$
\mathrm{S} _ {2} \mathrm{O} _ {8} ^ {2 -} \rightarrow 2 \mathrm{SO} _ {4} ^ {\cdot -}
$$

3-2 $\mathrm{SO}_4\cdot^-$ ，OH·， $\mathrm{S}_2\mathrm{O}_3\cdot^-$ 都是不稳定的中间体，根据稳态近似：
$\mathrm{dc(SO_4\cdot^-) / dt = 2r_1 + r_4 - r_2 - r_5 = 0}$ （1分）
$\mathrm{dc(OH\cdot) / dt = r_2 - r_3 = 0}$ （1分）
$\mathrm{dc(S_2O_3\cdot^-) / dt = r_3 - r_4 - r_5 = 0}$ （1分）
$\mathrm{dc(S_3O_7^{2 - }) / dt = r_4 + r_5 - r_6 = 0}$ （1分）
以上四式联立，整理可得：
$k_{4}c(S_{2}O_{3}\cdot)^{2} + k_{1}c(S_{2}O_{3}\cdot^{\prime}) - k_{1}k_{2} / k_{5} = 0$ （1分）
解得： $c(\mathrm{S}_2\mathrm{O}_3\cdot^{\prime}) = [-k_1 + (k_1^2 +4k_1k_2k_4 / k_5)^{1 / 2}] / 2k_4$ （舍去负解）
以 $\mathrm{S}_2\mathrm{O}_8^{2 - }$ 的消耗速率表示总反应速率，则：
$r = -\mathrm{dc(S_2O_8^{2 - }) / dt = k_1c(S_2O_8^{2 - }) + k_4c(S_2O_3\cdot^-)c(S_2O_8^{2 - })}$ （1分）
$= 1 / 2[k_{1} + (k_{1}^{2} + 4k_{1}k_{2}k_{4} / k_{5})^{1 / 2}]c(S_{2}O_{8}^{2 - })$
考虑到 $k_{1}$ 为链引发，速率常数极小，故上式可近似为：
$r = (k_{1}k_{2}k_{4} / k_{5})^{1 / 2}c(S_{2}O_{8}^{2 - })$
即 $x = 1$ ， $y = 0$ （1分）
$k_\mathrm{obs} = (k_1k_2k_4 / k_5)^{1 / 2}$ （1分）

3-3-1 由于 $c_{0}(\mathrm{S}_{2}\mathrm{O}_{8}^{2-}) &gt;&gt; c_{0}(\mathrm{S}_{2}\mathrm{O}_{3}^{2-})$，故该反应在实验条件下为准零级反应（1分）。进而极易求出：$k_{\mathrm{obs}} = 0.0040 \min^{-1}$（1分）


3-3-2 当  $t = 30.0 \, min$  时， $c(\mathrm{S}_{2}\mathrm{O}_{3}^{2-}) = 1.31 \times 10^{-2} \, \text{mol/L}$  （1 分）

得出是准零级反应的结论，或者是按零级反应进行计算，即可得 1 分，5-3 两个结果各 1 分。
