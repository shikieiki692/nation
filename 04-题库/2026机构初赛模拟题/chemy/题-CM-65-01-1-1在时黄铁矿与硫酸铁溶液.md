# 题-CM-65-01-1-1在时黄铁矿与硫酸铁溶液

## 题目

### 第 1 题（12 分）

1-1 在 $90^{ \circ } \mathrm { C }$ 时，黄铁矿与硫酸铁溶液反应， 无任何气体或单质生成。
$1-2 \mathrm{CrO}_{3}$ 与 $\mathrm { Cl } _{ 2 } \mathrm { O } _{ 7 }$ 发生化合反应生成一种红色液体。
1-3 将氯化铅悬浮于浓盐酸中，在冰水浴冷却下通入氯气并加入吡啶，析出鲜黄色沉淀。1-4 高压下， Ba4Li2Si6 与氯化氢气体反应，固体产物为 $\mathrm { BasSi } _{ 46 }$ 和两种氯化物， 没有其他含Si 产物。
1-5 在含有少量碘化钾的饱和氢氧化钡溶液中滴入高锰酸钾溶液，生成两种钡盐沉淀，其中一种为暗绿色，另一种为正高碘酸钡。
1-6 将铜片投入到 $200^{ \circ } \mathrm { C }$ 的热硫酸中，充分反应放出气体； 反应后的溶液用乙醇和乙醚(1 :1)的混合液或甲醇析晶可得到抗磁性白色固体。
