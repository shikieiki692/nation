# 题-CM-233-05-51判断以下三个有关绝热过程的论

## 题目

### 第 5 题（25 分，占 11.0%）

**5-1** 判断以下三个有关绝热过程的论断的正误并解释。（若正确需给出证明，若错误需给出

反例）

**5-1-1** 绝热等容过程中系统的内能一定保持不变。

**5-1-2** 现有一个被多孔塞隔开成两个室的绝热钢筒，筒的两端各有一个活塞，两端的活塞外

压均恒定不变；使气体从左室通过多孔塞进入右室，则该气体的焓一定保持不变。

**5-1-3** 绝热可逆过程中系统的熵一定保持不变。

**5-2** 现有一体积为1 L且抽成真空的绝热容器，其左端有一个不导热的无摩擦、无重量活塞，

暂被销钉固定；其右端表面有一个足够小的小孔，可以认为在小孔处只能发生物质交换而不

能传递热量。由于氦气的性质接近理想气体，本小题中可近似将氦气视做理想气体考虑。

**5-2-1** 将该容器放置在温度为 273.15 K，压强为 10𝑝°的氦气气氛中，氦气迅速进入容器内

直至内外压强平衡，试求出内外压强平衡时气体的温度 T<sub>1</sub>。

**5-2-2** 随后，在不改变内部气体状态的情况下关闭小孔并将容器左端的销钉撤去，使得活

## 参考答案

**5-1-1** 错误（1 分）；由热力学第一定律，ΔU = Q + W = Q + W <sub>体积</sub> + W <sub>非体积</sub>，绝热等容过程

Q = 0，W <sub>体积</sub> = 0，但 W <sub>非体积</sub>不一定为 0（1 分），故仅需构造一个包含电阻丝和绝热箱的系

统，当外界输入电功，由于电阻丝位于绝热箱内部仅二者之间存在热交换，系统发生了一

个绝热等容过程，但系统的总内能 ΔU > 0（1 分）。

**5-1-2** 正确（1 分）；由于钢筒两个室均为绝热，因此有 ΔU = Q + W = W，而两端外压均不

变，故 W<sub>1</sub> = -p<sub>1</sub>V<sub>1</sub>，W<sub>2</sub> = p<sub>2</sub>V<sub>2</sub>（1 分），ΔU = W<sub>2</sub> - W<sub>1</sub> = p<sub>2</sub>V<sub>2</sub> - p<sub>1</sub>V<sub>1</sub>，推知 U<sub>1</sub> + p<sub>1</sub>V<sub>1</sub> = U<sub>2</sub> +

p<sub>2</sub>V<sub>2</sub>；由焓的定义式 H = U + pV 可知 H<sub>2</sub> = H<sub>1</sub>（1 分），也即 ΔH =0。

![](images/7ab91c4aeac882f6bb167d04222b12fd9a58442bc43bdaa1315138fcb327f3bb.jpg)

ΔS = 0（1 分）。
