# 第 3 题 （16 分， 占 $10 \%$ ） 氢键复合物

尿素和草酸都是经典的氢键给体受体物种，被广泛用于晶体工程当中。

3-1 尿素与草酸在 $80^{ \circ } \mathrm { C }$ 的水溶液中可以 2:1 结合形成一种共晶。其晶体结构可以看作多个尿素-草酸通过氢键形成的平面网状结构堆叠而成。

3-1-1 已知尿素与草酸 2:1 地结合形成了一种近似直线型的单体 A， 画出A 的结构。

3-1-2 A 可以通过尿素间的氢键聚合形成无限长链结构 B， 画出B 的结构示意图。
3-1-3 B 通过氢键即可得到上述平面网状结构。在 B 中标出氢键的给体与受体。

3-2 除草酸外， 尿素还可以与其他二羧酸形成类似的共晶结构。在异丙醇溶剂中，二酸 C（分子量 $< 200$ ） 可以与尿素形成 2:1 型复合物。这个复合物为单斜晶系，晶胞参数如下： $a = 563.7 \mathrm { pm }$ ; $b = 824.3 \mathrm { pm } ; c = 1225.8 \mathrm { pm } , \beta = 96.90^{ \circ }$ 。已知该晶胞的理论密度为 1.740$\mathrm { { g } / \mathrm { { mol } } }$ 。 通过计算，给出二酸 C 的化学式。
