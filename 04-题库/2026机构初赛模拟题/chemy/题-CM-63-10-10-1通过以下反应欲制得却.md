# 题-CM-63-10-10-1通过以下反应欲制得却

## 题目

### 第 10 题（14 分）

10-1 通过以下反应欲制得 $\pmb { \mathsf { x } }$ ， 却得到 $\pmb { x }$ 和Y 两种产物， 其产率分别为 $11 \%$ 和 $43 \%$ ：

Si(CH3)3 CsF, THF +      Y Ph OH X 室温
OSO2CF3 12 h 11% 43%

画出 $\pmb { x }$ 和 $\mathbf { Y } ( \mathbf { C } _{ 19 } \mathrm { H } _{ 24 } \mathbf { O } _{ 2 } )$ 的结构简式。

10-2 人们进行了以下反应：

Si(CH3)3 CsF, MeCNPh 室温OSO2CF3 24 h该反应得到了多种产物， 其化学式和产率列于下表：

![](images/62a83b327f37720181b8b78afa9838037f3401ee52e5905d2a5a283fea162c07.jpg)

10-2-1 化合物 A 为三环化合物， 生成 A 的反应具有高度的区域选择性。 画出 A 的结构简式，并解释该反应具有高度区域选择性的原因。
10-2-2 化合物B 具有顺反异构体， 画出B 的结构简式。

10-2-3 已知 C 含三个六元环， 其 $\mathrm { ^ 1 H }$ -NMR 谱为： δ 8.93(2H), 8.12(2H), 7.88(2H), 7.82(2H),
7.71(2H)。 画出 C、 D、E 的结构简式， 并提出生成 C 和D 的可能的反应历程。
