# 题-CM-62-02-2-1化学式为的碘VII的化

2-1 化学式为 $\mathrm { H } _{ 7 } \mathrm { I } _{ 3 } \mathrm { O } _{ 14 }$ 的碘(VII)的化合物中仅含两种粒子：一种是正高碘酸 $\mathrm { ( H _{ 5 } IO _{ 6 } ) }$ ；另一种是由 $\left[ \mathrm { IO } _{ 6 } \right]$ 八面体共棱连接形成的一维链。该物质中氧仅以端基氧、桥氧和羟基氧的形式存在。请据此判断：1 摩尔 $\mathrm { H } _{ 7 } \mathrm { I } _{ 3 } \mathrm { O } _{ 14 }$ 中有几摩尔桥氧和几摩尔配位数为1 的氧？1 摩尔 $\mathrm { H } _{ 7 } \mathrm { I } _{ 3 } \mathrm { O } _{ 14 }$ 充分水解，至少需要几摩尔水？

2-3 由于Xe 的第一电离能 $( 12.13 \mathrm { eV } )$ 与 $\mathrm { O } _{ 2 }$ 的第一电离能 $( 12.2 \mathrm { eV } )$ 近似，科学家令Xe 与${ \mathrm { O } } _{ 2 } { \mathrm { BF } } _{ 4 }$ 在 $163 \mathrm { K }$ 下反应，欲制备Xe 的盐 $\mathrm { XeBF _{ 4 } }$ ，却得到了一种白色固体 $\pmb { \mathsf { A } }$ 。红外光谱显示，A 分子中含有Xe-B 键和 $\mathbf { X } \mathrm { e } { \cdot } \mathbf { F }$ 键。将 $1 \mathrm { mol } \mathsf { A }$ 在 $\mathbf { N } _{ 2 }$ 气氛中加热到 $243 \mathrm { K }$ 时完全分解，产生 $1 \mathrm { mol } \mathrm { Xe }$ 和一种常见的Lewis 酸。

Xe-F 键。将1 mol A 在N2 气氛中加热到243 K 时完全分解，产生1 mol Xe

## 参考答案

2-4-1 n(HPO₄²⁻) = 1 mmol，故所得溶液为 0.1 mol·L⁻¹ HCl 与 H₃PO₄ 的混合溶液。
H₃PO₄ = H⁺ + H₂PO₄⁻
0.1 - x 0.1 + x x
Kₐ = x(0.1 + x)/(0.1 - x) （1 分）
解得 x = 6.6 × 10⁻³ mol·L⁻¹, [H⁺] = 0.11 mol·L⁻¹
pH = 0.97（1 分）

2-4-2
V = 25 mL 时，为缓冲溶液，pH = pKₐ₂ = 7.26（1 分）
V = 30 mL 时，溶液为 Na₂HPO₄ 溶液，c = 0.025 mol·L⁻¹, Kₐ₃ = 4.4 × 10⁻¹³ ，不能用最简式（1 分）
[H⁺] = (Kₐ₂(Kₐ₃c + K_w)/c)¹/² = 2.1 × 10⁻¹³ mol·L⁻¹（1 分）
pH = 9.67（1 分）
