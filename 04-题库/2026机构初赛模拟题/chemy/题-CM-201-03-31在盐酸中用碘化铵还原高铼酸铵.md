# 题-CM-201-03-31在盐酸中用碘化铵还原高铼酸铵

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-10-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（18 分，占 10%）

**3-1** 在盐酸中，用碘化铵还原高铼酸铵，产生 Re(IV)的八面体氯配合物。

**3-2** 在 CH<sub>2</sub>Cl<sub>2</sub>中，PCl<sub>3</sub>、AlCl<sub>3</sub>和((CH<sub>3</sub>)<sub>3</sub>Si)<sub>2</sub>Se 反应，产生一种 1:1 型盐，其阳离子有 7 个原子，与 P<sub>4</sub>S<sub>3</sub>结构类似。

**3-3** 利用过量的 BrF<sub>5</sub>与钾长石(KAlSi<sub>3</sub>O<sub>8</sub>)反应，定量放出单质气体；还原产物为 BrF<sub>3</sub>。

**3-4** 在氧气气氛中，Pr<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·10H<sub>2</sub>O 加热分解，剩余固体产物为 Pr<sub>6</sub>O<sub>11</sub>。

**3-5** 向浓度为 2.4 mol/L 的 Na<sub>2</sub>S 溶液中滴加少量酸性 KMnO<sub>4</sub>溶液，产生肉红色沉淀。

**3-6** 在 3 bar 的 CO 气压下，[N(C<sub>2</sub>H<sub>5</sub>)<sub>4</sub>][Ta(CO)<sub>6</sub>]与 Ag[Al(OC(CF<sub>3</sub>)<sub>3</sub>)<sub>4</sub>]反应，产物中有 2 种1:1 型盐；在含 Ta 的盐中 Ta 为单帽八面体配位。

## 参考答案

**3-1**（3 分）2NH<sub>4</sub>ReO<sub>4</sub> + 6NH<sub>4</sub>I + 16HCl → 2(NH<sub>4</sub>)<sub>2</sub>ReCl<sub>6</sub> + 3I<sub>2</sub> + 4NH<sub>4</sub>Cl + 8H<sub>2</sub>O

还原产物写成 NH<sub>4</sub>I<sub>3</sub>，配平，也可以；

氧化产物写 ICl，配平，也可以；

反应写离子方程式，也可以。

方程式未配平，不得分。

**3-2**（3 分）3PCl<sub>3</sub> + AlCl<sub>3</sub> + 4((CH<sub>3</sub>)<sub>3</sub>Si)<sub>2</sub>Se → [P<sub>3</sub>Se<sub>4</sub>][AlCl<sub>4</sub>] + 8(CH<sub>3</sub>)<sub>3</sub>SiCl

阴离子写 Al<sub>2</sub>Cl<sub>7</sub><sup>-</sup>，也可以；

所有反应物和产物写对，但是未配平，得 1 分。

**3-3**（3 分）KAlSi<sub>3</sub>O<sub>8</sub> + 8BrF<sub>5</sub> → KF + AlF<sub>3</sub> + 3SiF<sub>4</sub> + 8BrF<sub>3</sub> + 4O<sub>2</sub>

产物写成 K<sub>3</sub>AlF<sub>6</sub> + AlF<sub>3</sub>，或 K<sub>2</sub>SiF<sub>6</sub> + SiF<sub>4</sub>等合理答案，也可以

所有反应物和产物写对，但是未配平，得 1 分。

**3-4**（3 分）6Pr<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·10H<sub>2</sub>O + 11O<sub>2</sub> → 2Pr<sub>6</sub>O<sub>11</sub> + 36CO<sub>2</sub> + 60H<sub>2</sub>O

如果写成：3Pr<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·10H<sub>2</sub>O + O<sub>2</sub> → Pr<sub>6</sub>O<sub>11</sub> + 9CO + 9CO<sub>2</sub> + 30H<sub>2</sub>O，可得 2 分

方程式未配平，不得分。

**3-5**（3 分）2MnO<sub>4</sub><sup>-</sup> + 7S<sup>2-</sup> + 16H<sup>+</sup> → 2MnS + 5S + 8H<sub>2</sub>O；(x – 1)S + S<sup>2-</sup> → S<sub>x</sub><sup>2-</sup>

或：(2x – 2)MnO<sub>4</sub><sup>-</sup> + (7x – 2)S<sup>2-</sup> + (16x – 16)H<sup>+</sup> → (2x – 2)MnS + 5S<sub>x</sub><sup>2-</sup> + (8x – 8)H<sub>2</sub>O

考虑到 S<sup>2-</sup>的水解较强，将 S<sup>2-</sup>写成 HS<sup>-</sup>，不扣分。

不写(x – 1)S + S<sup>2-</sup> → S<sub>x</sub><sup>2-</sup>，也可以。

所有反应物和产物写对，但是未配平，得 1 分。

**3-6**（3 分）[NEt<sub>4</sub>][Ta(CO)<sub>6</sub>] + 2Ag[Al(OC(CF<sub>3</sub>)<sub>3</sub>)<sub>4</sub>] + CO → [Ta(CO)<sub>7</sub>][Al(OC(CF<sub>3</sub>)<sub>3</sub>)<sub>4</sub>] + 2Ag

+ [NEt<sub>4</sub>][Al(OC(CF<sub>3</sub>)<sub>3</sub>)<sub>4</sub>]

所有反应物和产物写对，但是未配平，得 1 分。
