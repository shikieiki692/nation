# 题-CM-236-01-二元酸H2L在生命体中广泛分布且

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-14-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（32 分，占 13.0%）

二元酸 H<sub>2</sub>L 在生命体中广泛分布，且在不同的生命体中发挥着不同的功能。有很多植物中

富含 H<sub>2</sub>L，但过量摄入 H<sub>2</sub>L 容易导致结石的发生。在分析化学中，H<sub>2</sub>L 也是一种重要的基

准试剂。

写出 H<sub>2</sub>L 的化学式，并写出与结石相关的物质的化学式。

**1-2** H<sub>2</sub>L 的工业合成：写出下面描述的过程涉及的所有反应方程式

**1-2-1** CO 与 NaOH 在加压下反应得到盐 a，此后 a 在高温下脱氢得到 Na<sub>2</sub>L。

**1-2-2** 在催化剂的存在下，葡萄糖被硝酸氧化。产生的无色气体与氧气反应再生硝酸。

**1-2-3** CO 与 BuONO 反应得到中间产物 b，b 水解得到 H<sub>2</sub>L。

**1-3** X 是一种黄色的沉淀，可以由摩尔盐与 H<sub>2</sub>L 复分解得到。在晶体中，X 中的金属元素

为 6 配位，八面体共棱连接形成无限长链。

**1-3-1** 写出 X 的化学式，画出晶体中 X 的结构。

**1-3-2** X 晶体中各长链间存在特殊的相互作用，写出相互作用的名称以及每个晶胞中该相

互作用的个数。已知 Z = 2。

**1-4** L<sup>2-</sup>可以与很多种金属形成络合物，它们有各异的性质与用途。其中钾盐 A 是一种翠绿

色单斜晶体，在蓝晒工艺中有重要的应用价值，在有机反应中有时也被用作催化剂。电导

实验表明，A 是一种 3 : 1 型的盐。在 N<sub>2</sub>气氛中加热该固体，其失重曲线如下（提示：所

有失重数据均相对于初始状态的质量）：在 100 ℃失重 11.0%（反应 1）；在 280 ℃进一步

失重，直到 350 ℃质量稳定（反应 2），对应失重 8.96%；在 435 ℃进一步失重 14.7%（反

应 3）；在 450-580 ℃失重 8.51%（反应 4）。已知 A 的晶胞参数：a = 774.2 pm，b =

1991.7pm，c = 1034.6pm，β = 107.8°,理论密度：2.148 g/cm<sup>3</sup>。

**1-4-1** 通过计算，写出一个晶胞中结晶水的个数，并给出 A 的化学式，画出 A 中八面体阴

离子的结构。

**1-4-2** 写出反应 2~反应 4 涉及的反应方程式。

**1-5** 深绿色晶体 B 与 A 的化学组成只有中心金属的差异。在空气中加热该固体，其失重曲

线如下：在 100 ℃失重 11.1%，在 300-450℃失重 30.8%（反应 5），在 600 ℃失重 4.11%，

生成黄色固体（反应 6）。写出 B 的化学式，并写出反应 5 和反应 6 的方程式。

**1-6** 化合物 C 与 A 的化学组成也只有中心金属的差异。在 N<sub>2</sub>气氛中加热的失重曲线如

下：在 100-300 ℃失重 11.7%，在 500 ℃失重 32.5%。更高温度下，会进一步发生失重（反

应 7）。写出反应 7 的方程式。

## 参考答案

**1-1** H<sub>2</sub>C<sub>2</sub>O<sub>4</sub>（1 分）CaC<sub>2</sub>O<sub>4</sub>（1 分）

**1-2-1** NaOH + CO== HCOONa（1 分） 2HCOONa == Na<sub>2</sub>C<sub>2</sub>O<sub>4 </sub>+ H<sub>2 </sub>（1 分）

**1-2-2** C<sub>6</sub>H<sub>12</sub>O<sub>6 </sub>+ 6 HNO<sub>3 </sub>== 3 H<sub>2</sub>C<sub>2</sub>O<sub>4 </sub>+ 6 NO + 6 H<sub>2</sub>O（2 分）

4NO + 3O<sub>2</sub> + 2H<sub>2</sub>O == 4HNO<sub>3</sub>（1 分）

**1-2-3** 2CO + 2BuONO == Bu<sub>2</sub>C<sub>2</sub>O<sub>4</sub> + 2 NO（1 分）

Bu<sub>2</sub>C<sub>2</sub>O<sub>4</sub> + 2 H<sub>2</sub>O == 2 BuOH + H<sub>2</sub>C<sub>2</sub>O<sub>4</sub>（1 分）

**1-3-1** 化学式：FeC<sub>2</sub>O<sub>4</sub>·2H<sub>2</sub>O（1 分）；结构：

![](images/20646933121b81d32656ef8b76929888958e4ea955e751515e4975683f091a30.jpg)

**1-3-2** 氢键（1 分）8 个（1 分）

**1-4-1** 理论密度 ρ = ZM / N<sub>A</sub>V = x × 18.016 g·mol<sup>-1</sup> / (0.11 × N<sub>A</sub> × abcsinβ) = 2.148 g·cm<sup>-3</sup>，解

得 x = 12。（公式 1 分，结果 1 分）

根据题目条件，其化学式应为 K<sub>3</sub>M(C<sub>2</sub>O<sub>4</sub>)<sub>n</sub>·yH<sub>2</sub>O，其中 y 是 12 的因数。且满足下式：

18.016y / (39.10 × 3 + M + 88.02n + 18.016y) = 11.0%

可以求得 M = 55.93g/mol，对应 Fe 元素，其中 n = y = 3。（过程 2 分）

A 的化学式：K<sub>3</sub>Fe(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>-3H<sub>2</sub>O（1 分）；八面体阴离子的结构为：

![](images/46baba3bef3fee46cbe7eb40a93534c9848ded87e73950f74028978a81b2b9e0.jpg)

**1-4-2** 2K<sub>3</sub>Fe(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub> = 3K<sub>2</sub>C<sub>2</sub>O<sub>4</sub> + 2FeC<sub>2</sub>O<sub>4</sub> + 2CO<sub>2</sub>（2 分）

FeC<sub>2</sub>O<sub>4</sub> = FeO + CO<sub>2</sub> + CO（1 分）

K<sub>2</sub>C<sub>2</sub>O<sub>4</sub> = K<sub>2</sub>CO<sub>3</sub> + CO（1 分）

**1-5** 化学式：K<sub>3</sub>Cr(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>-3H<sub>2</sub>O（1 分）

反应 5：2K<sub>3</sub>Cr(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub> = 3K<sub>2</sub>CO<sub>3</sub> + Cr<sub>2</sub>O<sub>3</sub> + 3CO<sub>2</sub> + 6CO（2 分）

反应 6：4K<sub>2</sub>CO<sub>3</sub> + 2Cr<sub>2</sub>O<sub>3</sub> + 3O<sub>2</sub> = 4K<sub>2</sub>CrO<sub>4</sub> + 4CO<sub>2</sub>（2 分）

**1-6** K<sub>2</sub>CO<sub>3</sub> + Al<sub>2</sub>O<sub>3</sub> = KAlO<sub>2</sub> + CO<sub>2</sub>（2 分）
