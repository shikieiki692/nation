# 题-CM-198-03-Ca3N2与CrN反应可得到混合

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-7-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（24 分，占 14%）

Ca<sub>3</sub>N<sub>2</sub>与 CrN 反应可得到混合氮化物 X，X 属于正交晶系，晶胞参数为：a = 850.3 pm，b = 1028.4 pm，c = 503.4 pm。其中 Ca、N 的排布情况与 NaCl 类似，可视作两个变形六面体沿a 轴方向共面连接形成下图所示单元，每个单元中的两个六面体再分别沿 c 轴通过共面的方式无限延伸形成无限链状结构；链间不直接相连，而是通过与[CrN<sub>3</sub>]单元共用 N 原子形成无限三维结构。X 中[CrN<sub>3</sub>]单元垂直于 c 轴排布，Cr 中心为平面三角形构型，有 2 种取向，每个[CrN<sub>3</sub>]单元中均有一根 Cr-N 键与 b 轴平行。

![](images/bc881ba6ac4c9cd3507a4fdc7f77f80e6e758abe13d4cf8fb2ad682f6843b494.jpg)

**3-1** 该晶体中所有 N 原子均参与对 Cr 配位，结合题意说明 N 原子的配位情况(对于配位环境不同的 N 原子需分别说明配位数及配位原子)。

**3-2** 给出 X 的化学式，并指出该晶体的点阵型式及结构基元。

**3-3** 根据晶体衍射结果，该晶体中部分 N 原子的坐标为：(0.500, 0.624, 0.750)，(0.808, 0.371, 0.750)；与 b 轴平行的 Cr-N 键键长为 186.3 pm。据此计算该晶体中 N-Cr-N 键角的大小。

**3-4** 根据 3-3 的计算结果，预测该晶体中 Cr 的 d 轨道会被分裂为几组。计算表明，Cr 中心的 3d<sub>z2</sub>轨道能量低于 3d<sub>yz</sub>轨道(x、y、z 坐标轴方向分别对应于晶体的 a、b、c 轴)，指出主要原因。

**3-5** 用 Sr<sub>2</sub>N 和 Cr 在 1050 °C 下反应可得到 X 的锶类似物 Y，但 X 射线近边吸收光谱表明，Y 中 Cr 的氧化态与 X 不同，Cr 中心无单电子，据此写出能表达 Y 组成的结构简式。(注：X 射线衍射表明 Y 中无 N-N 键)

## 参考答案

**3-1** 第一种 N 原子：配位数为 5，配位原子为 1 个 Cr、4 个 Ca；第二种 N 原子：配位数为6，配位原子为 1 个 Cr、5 个 Ca。（各 3 分，共 6 分）

**3-2** 化学式：Ca<sub>3</sub>CrN<sub>3</sub>；点阵型式：底心正交（答作 C 心正交也得分）；结构基元：2 个 Ca<sub>3</sub>CrN<sub>3</sub>。（各 2 分，共 6 分）

**3-3** 根据点阵的平移对称性，与(0.808, 0.371, 0.750)位置处 N 原子空间环境相同的 N 原子坐标为(0.308, 0.871, 0.750)。假设晶体中一个 Cr 原子的坐标为 x，则根据与 b 轴平行的 Cr-N 键键长可得：

186.3 pm = (x – 0.624) × 1028.4 pm代入解得 x = 0.805，因此该 Cr 原子的坐标为(0.500, 0.805, 0.750)。（2 分）下面再结合坐标计算键角：θ = arctan[(0.871 – 0.805)b / (0.500 – 0.308)a] + 90° = 113°（2 分）由于 Cr 为平面三角形配位，另一种 N-Cr-N 键角为：360° - 113° × 2 = 134°（2 分）

**3-4** Cr 的 d 轨道会被分裂为五组。（2 分）3d<sub>z2</sub>轨道能量低于 3d<sub>yz</sub>轨道的主要原因：Cr<sup>3+</sup>的3d<sub>yz</sub>轨道与 N<sup>3-</sup>的 2p<sub>z</sub>轨道之间有 π 相互作用，导致 3d<sub>yz</sub>轨道能量抬升。（2 分）

**3-5** (Sr<sup>2+</sup>)<sub>3</sub>(Cr<sup>4+</sup>)(N<sup>3-</sup>)<sub>3</sub>(e<sup>-</sup>)（2 分）
