# 题-CM-162-02-将在真空的熔融石英管中混合反

## 题目

### 第 2 题

第 2 题（20 分， 占 $13 \%$ ） Re 的多核配合物

将 $0.3 { \mathrm { ~ g ~ ReI } } _{ 3 }$ ， $0.207 \ \mathrm { g } \mathrm { KCN }$ ， $0.066 \ \mathrm { g } \mathrm { As } _{ 2 } \mathrm { S } _{ 3 }$ 在真空的熔融石英管中混合反应后溶解于热水中过滤蒸发得到 $0.145 \mathrm { g }$ 深红色产物 $\pmb { \mathsf { A } }$ 。 $\pmb { \mathsf { A } }$ 为Re 的四核配合物，Re 为 $+ 4$ 氧化态，其阴离子含有 $[ \mathrm { Re } ] _{ 4 }$ 四面体骨架结构。对 $\pmb { \mathsf { A } }$ 进行元素分析表明：C 9.19 , $\mathrm { ~ H ~ } 0.70$ , $\textrm { N } 10.71$ , S 4.09 (质量分数， $\%$ )。 $\pmb { \mathsf { A } }$ 的晶体结构表征显示其为单斜晶系， $Z = 4$ ， $a = 1.099 \mathrm { nm }$ , $b = 1.876 \mathrm { nm }$ , $c = 1.635$ nm , $\beta = 72.49^{ \circ }$ ，晶体密度为 $3.241 \ \mathrm { g } \ / \ \mathrm { cm } ^{ - 3 }$ 。 热重分析表明其第一阶段会失重 $4.02 \%$ ， 对应失去全部结晶水。

2-1 写出 Re 元素的电子组态。

2-2 通过计算与推理， 推出 $\pmb { \mathsf { A } }$ 的化学式。

2-3 画出 $\pmb { \mathsf { A } }$ 中阴离子的结构简式。

$2 - 4 A$ 在过氧化氢水溶液中会发生一系列反应，首先得到与 $\pmb { \mathsf { A } }$ 结构类似的四核配合物 B，B是一种 $4 : 1$ 型盐，随着B 的生成溶液中会逐渐积累剧毒物质 $\pmb { x }$ 。若此时对体系进行加热处理，B 最终转化为配合物C。C 的配合物阴离子化学式为 $\mathrm { [ Re _{ 3 } S _{ 2 } O _{ 4 } C _{ 9 } N _{ 9 } ] ^{ 5 - } }$ ，含有3 种不同的桥连配体。

2-4-1 写出 $\pmb { x }$ 的化学式。

2-4-2 分别画出B 和C 对应的配合物阴离子的结构。

2-2（共8分，过程分应根据实际情况酌情调整）

由晶体密度及晶胞参数计算得 $M(\mathbf{A}) = 1569 \, \text{g/mol}$ （1 分）

因此 A 中含有的结晶水个数 $n = M(\mathbf{A}) \times 0.0402 / 18.016 = 3.5$ （2 分）

由 C、N、S 的质量分数可得： $n(\mathrm{C})=12,\quad n(\mathrm{N})=12,\quad n(\mathrm{S})=2$ （2 分）

因此配合物中含有 12 个 CN $^{-}$ 以及 2 个 S $^{2-}$ ，结合四核配合物的信息，可知剩余的分子量 M=384.8 g/mol。由于 Re 为 +4 氧化态，即该过程中发生了氧化还原反应，因此可推测 A 中存在 As $^{3-}$ ，故剩余分子量对应 6 个 K $^{+}$ 和 2 个 As $^{3-}$ （1 分）

故 A 的化学式为 $K_{6}[\{Re_{4}As_{2}S_{2}\}(CN)_{12}]\cdot3.5H_{2}O$ （2 分）
