# 题-CM-160-02-今有如下反应

## 题目

### 第 2 题

第 2 题（7 分，占 $5 \%$ ） 反应平衡

今有如下反应：

$$
\mathrm { ~ A ~ } + \mathrm { ~ B ~ }  \mathrm { ~ AB ~ }
$$

2-1 写出该反应平衡常数与 AB 的解离度的关系。 已知 AB 的初始浓度为c。

而对于类似的反应： $\mathrm { ~ A ~ } + \mathrm { ~ A ~ }  \mathrm { ~ A } _{ 2 }$

2-2 写出该反应平衡常数与 $\mathbf { A } _{ 2 }$ 的解离度的关系。 已知 $\mathbf { A } _{ 2 }$ 的初始浓度为c。

2-3 上面两个反应的平衡常数表达式给小明同学带来了疑惑。小明同学想知道，对于一些双分子反应，如果在不改变反应焓的情况下使得两个反应物可以区分，是否会导致平衡常数改变？ 为此， 聪明的他设计了如下的一个思维实验。

现有一定浓度的单体 A，和一定浓度的同位素标记的单体 B， 同位素标记不影响它们的二聚反应。单体 A 和单体B 可以反应聚合：

假定初始状态下 A 和 B 的浓度均为 $\mathbf { c } _{ 0 }$ ， 请自行假定变量， 给出反应 1 的平衡常数与反应 2的平衡常数的比值。

## 参考答案

第 2 题（7 分，占 5%）反应平衡

今有如下反应:

$$
\mathrm{A} + \mathrm{B} \rightleftharpoons \mathrm{AB}
$$

2-1 K = $\frac{(1-\alpha)}{c\alpha^{2}}$ (1 分)

而对于类似的反应:

$$
\mathrm{A} + \mathrm{A} \rightleftharpoons \mathrm{A} _{2}
2 - 2 \mathrm{K} = \frac {(1 - \alpha)}{4 \mathrm{c} ^{2}} (1 \text {分})
\begin{array}{l}\mathrm{A} + \mathrm{B} \rightleftharpoons \mathrm{AB} (\text {反应1})\\\mathrm{A} + \mathrm{A} \rightleftharpoons \mathrm{A} _{2} (\text {反应2})\\\mathrm{B} + \mathrm{B} \rightleftharpoons \mathrm{B} _{2} (\text {反应3})\end{array}
$$

2-3 由于各反应均处在热力学平衡，故存在一个隐藏的反应：

$$
2 \mathrm{AB} \rightleftharpoons \mathrm{A} _{2} + \mathrm{B} _{2}
$$

从统计上，该反应的平衡常数为 0.25。（1 分）

从而可以知道： $[\mathrm{AB}] = 2[\mathrm{A}_2] = 2[\mathrm{B}_2]$ （2分）

假定现 $[\mathrm{A}_2],[\mathrm{B}_2]$ 的浓度均为 $\alpha c_0$ ，则[AB]的浓度为 $2\alpha c_0$ [A],[B]的浓度为 $(2 - 4\alpha)c_0$ 反应1的平衡常数：

$$
\mathrm{K} = \frac {\alpha}{2 (1 - 2 \alpha) ^{2} c _{0}}
\mathrm{K} = \frac {\alpha}{4 (1 - 2 \alpha) ^{2} c _{0}}
$$

因此，反应 1 与反应 2 的平衡常数不相等，其比值为 2。（2 分）
