# 题-CM-56-07-高锰酸根离子在强碱性条件溶液

## 题目

### 第 7 题（4 分）

高锰酸根离子在强碱性条件溶液中的还原产物通常为锰酸根离子，但若有过量的沉淀剂存在下，锰酸根离子即会被沉淀。如将少量2-丁烯酸溶液滴入到含有过量硝酸钡的强碱性高锰酸钾溶液中，即可得到锰酸钡沉淀，该过程中每个2-丁烯酸分子失去10个电子。请写出这一过程的离子反应方程式。

## 参考答案

第 7 题（4 分）

$\mathrm { C _{ 4 } H _{ 6 } O _{ 2 } + 10 MnO _{ 4 } ^{ - } + 15 OH ^{ - } + 12 Ba ^{ 2 + } = 10 BaMnO _{ 4 } + CH _{ 3 } COO ^{ - } + 2 BaCO _{ 3 } + 9 H _{ 2 } O }$ （4 分）底物写 $\cdot$ 并配平， 不扣分。
氧化产物中C(IV)写成 $\cdot$ ，扣1 分， 写成 $\cdot$ ， 扣2 分；
写成CO32-，扣1 分，写成CO2，扣2 分；氧化产物中CH3COO-写成CH3COOH，扣1 分

氧化产物中 $\mathrm { CH } _{ 3 } \mathrm { COO ^{ - } }$ 写成 $\mathrm { CH _{ 3 } COOH }$ ， 扣1 分。
写其他氧化产物或其他方程式不得分。
