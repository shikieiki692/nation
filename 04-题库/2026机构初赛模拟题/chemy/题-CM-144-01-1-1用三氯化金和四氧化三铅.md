# 题-CM-144-01-1-1用三氯化金和四氧化三铅

## 题目

### 第 1 题（8 分）

1-1 用三氯化金和四氧化三铅在较高温度下加热，得到金单质并放出无色气体。

1-2 氨气和次氯酸钠反应，产物中包含一种能作为火箭燃料的化合物。

1-3 $\mathrm{Na_{2}Se(S_{2}O_{3})_{2}}$ 的水溶液被 $Br_{2}$ 氧化，产物中 Se 的价态为 +4 价。

1-4 锂辉石 $\left(\mathrm{Li}_{2} \mathrm{Al}_{2} \mathrm{Si}_{4} \mathrm{O}_{12}\right)$ 与碳酸钙、氯化铵混合煅烧，生成含硅 $24.18 \%$ (质量分数)的化合物。

## 参考答案

1-1  $2AuCl_{3} + Pb_{3}O_{4} = 3PbCl_{2} + 2Au + 2O_{2}$  （2分）
1-2  $2NH_{3} + NaOCl = N_{2}H_{4} + NaCl + H_{2}O$  （2分）
1-3  $\mathrm{Na}_{2}\mathrm{Se}(\mathrm{S}_{2}\mathrm{O}_{3})_{2} + 9\mathrm{Br}_{2} + 13\mathrm{H}_{2}\mathrm{O} = \mathrm{H}_{2}\mathrm{SeO}_{3} + 2\mathrm{NaHSO}_{4} + 2\mathrm{H}_{2}\mathrm{SO}_{4} + 18\mathrm{HBr}$  （2分）
写成  $\mathrm{Na}_{2}\mathrm{Se}(\mathrm{S}_{2}\mathrm{O}_{3})_{2} + 9\mathrm{Br}_{2} + 13\mathrm{H}_{2}\mathrm{O} = \mathrm{H}_{2}\mathrm{SeO}_{3} + 4\mathrm{H}_{2}\mathrm{SO}_{4} + 16\mathrm{HBr} + 2\mathrm{NaBr}$  亦可
1-4  $Li_{2}Al_{2}Si_{4}O_{12} + 4CaCO_{3} + 2NH_{4}Cl = 2LiCl + 4CaSiO_{3} + 2NH_{3} + 4CO_{2} + Al_{2}O_{3} + H_{2}O$
（2分）
1）方程式正确且合乎要求，得满分。
2）方程式须配平且系数为最简整数比，否则不得分。
3）反应物和生成物之间可以用箭头、等号均可。
4）如果将要求的化学方程式写为离子反应式且书写正确，不扣分。反之依然。
