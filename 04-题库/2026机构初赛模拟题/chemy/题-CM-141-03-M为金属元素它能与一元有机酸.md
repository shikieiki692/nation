# 题-CM-141-03-M为金属元素它能与一元有机酸

## 题目

### 第 3 题（8 分）

M 为金属元素，它能与一元有机酸 HX 形成盐 $MX_{2} \cdot nH_{2}O$ (n 为整数个)。对该盐进行了如下热重分析实验(数据均为实验值):

(1) $MX_{2}\cdot nH_{2}O$ 在氮气中加热至 $180^{\circ}C$ ，失重 14.2%，对应失去所有结晶水；继续加热至 $280^{\circ}C$ ，

$$

400^{\circ} \mathrm{C}

(2) $MX_{2}\cdot nH_{2}O$ 在空气中加热至 $400^{\circ}C$ 以上，冷却后剩余固体为氧化物 Y，质量为原质量的 58.7%。
体为金属M，质量为原质量的54.8%。(2) MX2·nH2O 在空气中加热至400°C 以上

3-1 通过计算，推出 M 是何种金属元素，推出盐 $MX_{2} \cdot nH_{2}O$ 和 Y 各是何种物质。(提示：Y 中金属与氧原子的数目比为简单整数比)

3-2 推出在氮气中 $280^{\circ}$ C 下失重所得固体产物的化学式；写出从 $180^{\circ}$ C 加热至 $280^{\circ}$ C(第二步失重)发生的反应方程式(要求系数比为最简整数比)。

## 参考答案

## 第 3 题（8 分）推断未知物质

再失重 13.4%; 继续加热至 400°C 以上, 冷却后剩余固体为金属 M, 质量为原质量的 54.8%。

3-1 设结晶水的数目为 n，，M 的摩尔质量为 x g/mol，则：18.02n : x = 14.2 : 54.8（1 分）
当 n = 1 时，x = 69.5 为 Ga（氧化态不符，舍去）
当 n = 2 时，x = 139 为 La（氧化态不符，舍去）或 Ba
当 n = 3 时，x = 208.6 为 Bi（氧化态不符，舍去）或 Pb
结合氧化物数据，设氧化物 Y 的化学式为 MOₙ，则：
(x + 16.00n) : x = 58.7 : 54.8
当 M 为 Ba 时，解得 n = 0.60，不合理，舍去；
当 M 为 Pb 时，解得 n = 0.92 ≈ 1，对应 PbO；
因此，金属 M 为 Pb（1 分），Y 为 PbO（1 分）
酸根离子摩尔质量为：(207.2 ÷ 0.548 - 207.2 - 3 × 18.02) / 2 = 58.4 (g/mol)（1 分）
有机酸常为羧酸，-COO⁻的式量为 44；因此 58.4 对应于乙酸根，HX 为乙酸
MX₂·nH₂O 为 Pb(CH₃COO)₂·3H₂O（1 分）

3-2 在氮气中 280℃ 下失重所得固体产物的摩尔质量为：
(207.2 + 2 × 59.06 + 3 × 18.02) × (1 - 0.142 - 0.134) = 274.7 (g/mol)（1 分）
该摩尔质量对应于 1 个 Pb 原子，1 个醋酸根离子和 0.5 个氧原子；
因此，固体产物化学式为 Pb₂O(CH₃COO)₂（1 分）
