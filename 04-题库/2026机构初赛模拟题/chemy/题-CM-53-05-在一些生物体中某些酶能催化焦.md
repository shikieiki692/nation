# 题-CM-53-05-在一些生物体中某些酶能催化焦

## 题目

### 第 5 题（8 分）

在一些生物体中，某些酶能催化焦磷酸根离子 $\left(\mathrm{P}_{2}\mathrm{O}_{7}^{4-}\right)$ 水解为磷酸一氢根离子 $\left(\mathrm{HPO}_{4}^{-}\right)$ 的反应，但却不能催化焦磷酸氢根离子直接水解的反应。人们通过实验测定了酶催化 $P_{2}O_{7}^{4-}$ 水解的速率，证明了该反应在形式上满足一级反应的规律。实验测得，在pH=7.00，温度为25℃下，该反应的表观速率常数 $k_{7}=1.0\times10^{-3}s^{-1}$ 。

5-1 请根据实验结果判断，以下两种说法中哪种说法是合理的？简述判断理由。

a)实验条件下，酶的浓度远远大于焦磷酸根离子的浓度。

b)实验条件下，焦磷酸根离子的浓度远远大于酶的浓度。

5-2 已知焦磷酸的 $pK_{a,3}=6.12$ ， $pK_{a,4}=8.95$ ，请据此计算 pH=8.00，温度为 $25^{\circ}C$ 下，该反应的表观速率常数 $k_{8}$ 。

## 参考答案

# 第 5 题（8 分）

5-1 a 是合理的 （1 分）。若焦磷酸根浓度远大于酶的浓度， 则所有的酶几乎都被焦磷酸根离子结合，反应速率几乎不受焦磷酸根离子浓度的影响。（1 分）从酶促反应动力学方程， 或生物体内本身酶浓度极低等其他合理角度讨论， 也可酌情给分。

5-2

根据 $-$ （2 分）可求得： 当 $\mathrm { pH } = 7.00$ 时： $a _{ 7 } ( \mathrm { P } _{ 2 } \mathrm { O } _{ 7 } { } ^{ 4 - } ) = 0.00979$ （1 分）故真正的速率常数为： $-$ （1 分）同理可求得，当 $\cdot$ 时， $\_$ （1 分）故： $k _{ 8 } = k \alpha _{ 8 } ( \mathrm { P } _{ 2 } \mathrm { O } _{ 7 } { } ^{ 4 - } ) / \alpha _{ 7 } ( \mathrm { P } _{ 2 } \mathrm { O } _{ 7 } { } ^{ 4 - } ) = 1.0 \times 10^{ - 2 } ~ \mathrm { s } ^{ - 1 }$ （1 分）
