# 题-CM-52-01-1-1迄今为止人类已经发现了

## 题目

### 第 1 题（8 分）

1-1 迄今为止，人类已经发现了 118 种元素，完全填满了元素周期表的前七个周期。但是元素的名称却不只有 118 种，源于很多元素不只有一个名称，比如对于 104 号元素 Rf，有两个竞争关系的实验室分别将其命名为 Rutherfordium 和 Kurchatovium，并为此持续争论了约 30 年。一般元素命名时总有一些依据，请写出至少三种命名依据（不考虑 IUPAC 建议的系统命名），每种至少举出一个例子。

1-2 2009 年 10 月合成的 117 号元素，是元素周期系发展的一个里程碑。它的合成意味着元素周期表的第七周期被填满。117 号元素是用 ${}^{249}Bk$ 轰击 ${}^{48}Ca$ 靶合成的，总共得到 6 个 117 号原子。其中一个经过 p 次 $\alpha$ 衰变得到 ${}^{270}Db$ ，随后继续裂变；另外五个原子经过 q 次 $\alpha$ 衰变得到 ${}^{281}Rg$ 后再次发生裂变。2016 年召开的工作会议，决定用 Ts 作为 117 号元素符号，请指出 p 和 q 的值，并写出得到 117 号元素的核反应方程式。

1-3 氢元素在元素周期表中的位置是一个极具争议的话题。例如，有人主张将氢元素放在第一周期第 17 纵列的位置。请简要说明这种主张有何道理。

## 参考答案

# 第 1 题（8 分）

1-1 根据元素的性质：如锇，意为“恶臭”；氯，意为“黄绿色”；氡，意为“射线”。根据科学家的名字：如钔，门捷列夫； $\cdot$ ，卢瑟福；锿，爱因斯坦。
根据地名：如铪，哈弗尼亚，是哥本哈根的古称；镆，莫斯科；铼，指莱茵河；铕，欧洲；镅，美洲；钋，波兰，发现者居里夫人的祖国。
根据神话传说或者天体：如碲，地球；硒，月亮；氦，太阳；铈，谷神星；铀，天王星；镎，海王星；钚，冥王星。
（每条1 分，每个依据和对应例子都正确即可得分， 其他合理答案亦可得分）

1-2 $p = 6$ （0.5 分）， $q = 3$ （0.5 分）${ } ^{ 249 } \mathrm { Bk } + { } ^{ 48 } \mathrm { Ca } \rightarrow { } ^{ 294 } \mathrm { Ts } + 3 \mathrm { n }$ （1 分）$-$ （1 分）二式合并写也可得分。

1-3 因为氢原子可获得一个电子进而达到和稀有气体相同的稳定电子排布。（2 分）意思对即可。
