# 题-CM-67-07-聚丙烯是由丙烯聚合而制得的一

## 题目

### 第 7 题（10 分）

聚丙烯是由丙烯聚合而制得的一种热塑性树脂。根据甲基排列位置的不同，聚丙烯可分为等规聚丙烯、间规聚丙烯和无规聚丙烯三种。甲基排列在分子主链同一侧的聚丙烯为等规聚丙烯，甲基无序排列在分子主链两侧的聚丙烯为无规聚丙烯，甲基交替排列在分子主链两侧的聚丙烯为间规聚丙烯。以下是一种聚丙烯的晶体结构沿 $\scriptstyle { \mathbf { \alpha } } _{ c }$ 轴方向的投影图，其中的球均表示碳原子，球旁边的分数表示该碳原子在 $\scriptstyle { \boldsymbol { c } }$ 轴方向的坐标；氢原子未在图中示出。

![](images/f893f383fd0ba20d363feec376b1172abf3bb714af2d20bd781db50a782eb7f3.jpg)

7-1 上述三种聚丙烯中，何者不具有固定的熔点？ 该聚丙烯晶体属于这三种聚丙烯中的哪种类型？

7-2 以上聚丙烯的晶胞中含有多少个碳原子？
7-3 该聚丙烯晶体有无 $C _{ 3 }$ 轴？有无镜面？有无对称中心？。
7-4 聚乙烯在晶体中也呈现出规整的长链结构，请简要描述聚乙烯和该聚丙烯的长链结构的差异，并对该差异的产生给出合理的解释。

## 参考答案

## 第7题（10分）

![](images/690d371962d78f669856ddcfac96da3ef4aa1e8af129e6fe9d0e5e1cf16532d1.jpg)



**7-1** 无规聚丙烯(1分)等规聚丙烯(1分)

**7-2** 以上聚丙烯的晶胞中含有多少个碳原子?

**7-2** 54个(2分)

**7-3** 该聚丙烯晶体有无 $C_3$ 轴?有无镜面?有无对称中心?。

**7-3** 有;无;无(每个1分)但是该晶体没有手性。因为该晶体中具有垂直于 $2a+b$ 的滑移面。显然,经反映之后进行平移能与原来重合,也可以说明经反映操作之后的晶体与原晶体是同一晶体,即该晶体无手性。这已超过初赛基本要求,在此仅做补充知识,不做本模拟考试要求。

**7-4** 聚乙烯在晶体中也呈现出规整的长链结构,请简要描述聚乙烯和该聚丙烯的长链结构的差异,并对该差异的产生给出合理的解释。

**7-4** 聚乙烯为锯齿形长链结构,该聚丙烯为具有 $3_1$ 螺旋轴的长链结构。(1分)聚乙烯中单键两侧的烷基采取对交叉构象,这样既减少了烷基之间的排斥力(1分),又有利于晶体的堆积;若全同聚丙烯链采取这种构象,则侧链甲基之间距离较近(1分),排斥力较大,因此全同聚丙烯在晶体中采取螺旋结构以减少甲基之间的斥力。
