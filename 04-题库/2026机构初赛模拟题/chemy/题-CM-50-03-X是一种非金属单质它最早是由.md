# 题-CM-50-03-X是一种非金属单质它最早是由

## 题目

### 第 3 题（9 分）

X 是一种非金属单质，它最早是由德国修道会学者和炼金家 Magnus 用其硫化物矿石与肥皂水加热制得的。在空气中直接加热 X 的单质，或令 X 的单质与浓硫酸反应，均可制得一种具有大蒜气味的固体 A；A 与干燥的氯化氢气流反应得到化合物 B，B 常温下为无色液体；在 $-105^{\circ}C$ 、紫外线照射下，B 与液氯反应，得到淡黄色固体 C，C 不稳定，在 $-50^{\circ}C$ 以上会分解；B 与 $LiAlH_{4}$ 作用，得到剧毒气体 D，D 易自燃；若将 X 湿润后用臭氧氧化，可制得化合物 E，向冷的 E 溶液中加入浓盐酸，再通入气体 F，可制得得到黄色固体 G。将 G 置于沸水中水解，则得到硫单质、F 和 H，H 经加热脱水又得回 A。请写出 X 的元素符号及 A 到 H 的化学式。
定，在-50°C 以上会分解；B 与LiAlH4 作用

## 参考答案

第 3 题（9 分）

X：As  A： $\mathrm { As } _{ 2 } \mathrm { O } _{ 3 }$ B： AsCl3 C： AsCl5 D： AsH3E： $\mathrm { H } _{ 3 } \mathrm { AsO } _{ 4 }$ F： $\mathrm { H } _{ 2 } \mathrm { S }$ G： ${ \mathrm { As } } _{ 2 } { \mathrm { S } } _{ 5 }$ H： $\mathrm { As ( OH ) } _{ 3 }$ （每个1 分）
