# 题-CM-165-04-4-1的制备思路与前人报道的

## 题目

### 第 4 题

第 4 题（18 分， 占比 $12 \%$ ） 一种阴离子的发现对星际物质的探索能辅助人们理解从小分子到复杂生物大分子的演化过程，除 CO、 $\mathrm { CO } _{ 2 }$ 、$\mathrm { NH } _{ 3 }$ 等简单气体化合物外，还有一些含 C、N、O 元素的分子或离子通常被认为是合成氨基酸或核酸所经历的中间体。然而，一种简单小分子——氰烯酮还尚未在星际介质中检测到，近日， 研究人员通过化学方法顺利制得了其对应的阴离子 $\pmb { x }$ 。

4-1 $\pmb { x }$ 的制备思路与前人报道的烯酮衍生物的制备相同： 向 $\operatorname { K } [ \operatorname { N C C P } ( \operatorname { C } _{ 6 } \mathrm { H } _{ 5 } ) _{ 3 } ]$ 的四氢呋喃溶液中加入过量18-冠-6 $( M _{ \mathrm { r } } = 264.312 ~ \mathrm { g { \cdot mol ^{ - 1 } } ) }$ ，并通入CO， 经过滤、 洗涤、干燥可得到最终产物。结合制备条件， 画出 $\pmb { x }$ 的三个合理共振式。

4-2 晶体衍射显示， 4-1 中得到的 $\pmb { x }$ 为直线型(结果 1)； 而若将 18-冠-6 换为[2, 2, 2]穴醚， 晶体衍射则显示 $\pmb { x }$ 的构型更偏向于 $\mathrm { \Delta V }$ 字型(结果2)。 选出下列选项中正确的说法：

(a) 结果 1 更能反映游离 $\pmb { x }$ 的构型；
(b) 结果2 更能反映游离 $\pmb { x }$ 的构型；
(c) 根据实验结果，不同构型 $\pmb { x }$ 之间的转化能垒可能较低；
(d) 若将18-冠-6 换为 15-冠-5，投料等条件不变，所得阳离子中 $\mathrm { K ^{ + } }$ 的配位数为 5。

$4 - 3 x$ 的结构决定了其反应活性，计算表明， 由于杂原子与 $\mathrm { K } ^{ + }$ 存在相互作用， 4-1 中得到的$\pmb { x }$ 负电荷在碳端电子云密度更大。
