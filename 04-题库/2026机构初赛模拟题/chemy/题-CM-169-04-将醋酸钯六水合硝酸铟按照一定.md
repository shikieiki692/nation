# 题-CM-169-04-将醋酸钯六水合硝酸铟按照一定

## 题目

### 第 4 题

第 4 题（18 分， 占 10 \% ） 多氧金属簇

将醋酸钯 ，六水合硝酸铟按照一定比例溶解在 0.5 \mathrm { mol / L } 的醋酸钾溶液中， 加热至 50^{ \circ } \mathrm { C } 反应2 \mathrm { h } ，冷却至室温后结晶出一种深红色块状晶体A，其阴离子化学式为 `\mathrm { \small { [ InPd _{ 12 } O _{ 8 } ( CH _{ 3 } COO ) _{ 16 } ] ^{ 5 - } } }` ，具有较高的对称性。
溶解在0.5 mol/L 的醋酸钾溶液中，加热至50 ℃反应2 h，冷却至

4-1 该阴离子可看作 `\mathrm { \small { [ InO _{ 8 } Pd _{ 4 } ( CH _{ 3 } COO ) _{ 8 } ] } }` 片段和 \mathrm { [ Pd _{ 4 } O _{ 4 } ( CH _{ 3 } COO ) _{ 4 } ] } 片段共用氧原子连接而成，其中 `\mathrm { \small { [ InO _{ 8 } Pd _{ 4 } ( CH _{ 3 } COO ) _{ 8 } ] } }` 中 In 为立方体配位，两个结构片段中 Pd 均为四配位。分别画出这两个结构片段的结构（配体可适当简写，注意表示出 Pd 的配位几何结构）。

4-2 取 0.009 \mathrm { mmol } \mathsf { A } 溶解在 \mathrm { pH } = 7 的磷酸盐缓冲溶液中， 加热反应， 冷却后得到 10 ~ \mathrm { mg } 深红色针状结晶B。 元素分析表明，B 中部分元素质量分数（理论值） 分别为： \mathrm { Na } ~ 8.43 \% , In4.01 \% , \mathrm { Pd } 42.71 \% , P 7.03 \% 。 已知 B 是一种水合钠盐，B 的阴离子中含有四种配体， 包括一个OH-和一个 \mathrm { HPO } _{ 4 } { } ^{ 2 - } ， 其余配体均不含氢元素。

4-2-1 通过计算和分析确定 B 的化学式。

4-2-2 画出 B 的阴离子的结构， 仅需示出Pd 和 In 的相对位置即可。

## 4-2-1 共 8 分

B 中 $n(\mathrm{Pd}):n(\mathrm{In})=(42.71\%/106.4):(4.01\%/114.8)=11.5$

假设 B 中含有 23 个 Pd，则有 $M_{B} = 23 \times 106.4 \, g/mol \div 42.71\% = 5729.8 \, g/mol$ 且由质量分数可知 B 中有 13 个 P，21 个 Na（得出各元素之间的比例 1 分）

B 是一种水合钠盐，阳离子应为 Na^{+} 。现考虑阴离子组成，阴离子中含有四种配体，由于该体系显然不涉及氧化还原过程，磷元素只能以磷酸根/磷酸氢根的形式存在，由于提示给出只含一个 HPO_{4}^{2-} ，其他 12 个磷只能以 PO_{4}^{3-} 的形式存在。（指出存在 PO_{4}^{3-} 配体 1 分）剩下一种不含氢的配体大概率为 O^{2-} （指出存在 O^{2-} 配体 1 分）

假设 B 的化学式为 \mathrm{Na}_{21}[\mathrm{In}_{2}\mathrm{Pd}_{23}\mathrm{O}_{m}(\mathrm{OH})(\mathrm{PO}_{4})_{12}(\mathrm{HPO}_{4})]\cdot n\mathrm{H}_{2}\mathrm{O} （设出 B 的化学式 1 分）
由 M_{B}=5729.8=21\times22.99+2\times114.8+23\times106.4+16.00\ m+17.008+12\times94.97+95.978+18.016\ n （1分），则有 16.00\ m+18.02\ n=1317.6 （1分）

考虑价态，尝试令 m=17，代入上式求解，可得 n=58。

综上所述：B 的化学式为 \mathrm{Na}_{21}[\mathrm{In}_{2}\mathrm{Pd}_{23}\mathrm{O}_{17}(\mathrm{OH})(\mathrm{PO}_{4})_{12}(\mathrm{HPO}_{4})]\cdot58\mathrm{H}_{2}\mathrm{O} （2 分）

若采用其他计算方法，过程合理且结果正确也可得满分。
