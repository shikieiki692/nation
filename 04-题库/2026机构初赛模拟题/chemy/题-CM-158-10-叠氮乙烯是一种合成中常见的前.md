# 题-CM-158-10-叠氮乙烯是一种合成中常见的前

## 题目

### 第 10 题 14 分， $5 \%$

叠氮乙烯是一种合成中常见的前体， 现有制备方法如下：

$$
R _{ 1 } = H \frac { A g _{ 2 } C O _{ 3 } } { T M S N _{ 3 } } = _{ R _{ 1 } } \downarrow _{ N _{ 3 } }
$$
