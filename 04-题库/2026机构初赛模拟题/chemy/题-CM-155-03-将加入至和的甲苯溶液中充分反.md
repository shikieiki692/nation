# 题-CM-155-03-将加入至和的甲苯溶液中充分反

## 题目

### 第 3 题 16 分， 占比 $10 \%$

将 $\mathrm { Ph } _{ 2 } \mathrm { PCl }$ 加入至 $\mathrm { Ph } _{ 2 } \mathrm { POH }$ 和 `{ \bf N } ( { \bf C } _{ 2 } { \bf H } _{ 5 } ) _{ 3 }` 的甲苯溶液中充分反应， 过滤出无色晶体后滤液中含有 $\pmb { x }$ 分子， $\pmb { x }$ 中磷的化学环境不同。

3-1 结合对反应条件的分析， 写出无色晶体的化学式， 并画出 $\pmb { x }$ 的结构。

3-2 研究表明 ， $\pmb { x }$ 与其异构体 $\pmb { \gamma }$ 可相互转化， 游离的 $\pmb { x }$ 较 $\pmb { \ Y }$ 更加稳定， 但在一些配合物中则可能发生逆转。 据此完成如下问题：

3-2-1 Au(tht)Cl(tht 为四氢噻吩)与 $\pmb { x }$ 反应可得到配合物 A， 研究表明 A 中存在一种特殊的相互作用， 画出A 的结构， 注意示出特殊的相互作用。

3-2-2 将三氯化钇和 $\pmb { x }$ 晶体溶于四氢呋喃中，混合反应(理论计量比为 $\mathbf { 1 } : \mathbf { 1 } \dot { }$ )可得到电中性单核配合物 B，B 中钇为六配位。写出 B 的结构简式；B 有几种异构体(包括本身，考虑立体异构)？

3-2-3 将 $\mathrm { Ph } _{ 2 } \mathrm { PCl }$ 、 [Cu(NCCH3)4]PF6、K[OPPh2]按 `\textcircled{1}` : 1 : 1 的比例混合反应可得到一种 1 : 1 型盐 C。C 的三核配合物阳离子具有一根 $C _{ 3 }$ 轴，Cu 周围有 2 种配体，其配位数与典型的 $\mathrm { cu }$ 的单核配合物相同。 书写得到C 的反应方程式，并画出 C 阳离子的结构。

3-2-4 若将 3-2-3 中的 $( \mathrm { C } _{ 6 } \mathrm { H } _{ 5 } ) _{ 2 } \mathrm { PCl }$ 换为 $( \mathrm { C } _{ 6 } \mathrm { H } _{ 5 } ) _{ 2 } \mathrm { PBr }$ 、 $( \mathrm { C _{ 6 } H _{ 5 } } ) _{ 2 } \mathrm { PI } _{ 3 }$ ，所得产物分别记作 D 和E。研究表明，C、D、E 在接受波长为 $365 \mathrm { nm }$ 的紫外光照射后都可发射出磷光。磷光是一种光致发光现象，处于高能级的电子发生回落所释放的能量以光子形式放出便可能产生磷光，这部分能量还可能以其它非辐射的形式散失，晶格的振动、溶液中含有的杂质、发光团原子序数较大的元素都可能促进非辐射过程的进行。结合以上信息和所学知识，选出下列选项中正确的说法：

(a) C、D、E 发出的磷光的波长小于 $365 \mathrm { nm }$ ；
(b) C、D、E 发出的磷光在低温下相较于高温更容易观测到；
(c) 相比之下C 的磷光寿命最短。
