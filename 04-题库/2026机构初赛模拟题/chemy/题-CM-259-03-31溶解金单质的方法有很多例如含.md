# 题-CM-259-03-31溶解金单质的方法有很多例如含

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy35-19-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（12 分）

**3-1** 溶解金单质的方法有很多；例如，含有四氨合铜(II)离子、硫代硫酸根离子的氨溶液在有氧条件下可溶解金单质。

**3-1-1** 有人提出，该反应分为两步进行：第一步反应中，生成以硫代硫酸根离子为配体的Au(I)和 Cu(I)的络离子；第二步反应中，Cu(I)的络离子被氧气氧化，又得到四氨合铜(II)离子和硫代硫酸根离子。分别写出两步反应的离子反应方程式(要求系数为最简整数比)。

**3-1-2** 该反应在 40°C 时对金单质有较好的浸出率；若温度过高，则四氨合铜(II)离子可能转化为硫化铜沉淀。写出离子反应方程式(要求系数为最简整数比)。

**3-2** 通过以下方法制备了三种不同的氯的氟氧化物，写出化学反应方程式(要求系数为最简整数比)：

**3-2-1** 向 HF-SbF<sub>5</sub>体系中加入高氯酸钾固体，产物中氯取 sp<sup>3</sup>杂化；

**3-2-2** 在 20°C 时，使二氟化银与二氧化氯作用，产物中氯的氧化数为+5，取 sp<sup>3</sup>杂化；

**3-2-3** 在低温下，Cl<sub>2</sub>O 与氟气作用，得到两种产物：一种产物中氯的氧化数为+5，取 sp<sup>3</sup>d 杂化；另一产物是一种 1:1 型卤素互化物。

## 参考答案

**3-1-1** Au + Cu(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> + 4S<sub>2</sub>O<sub>3</sub><sup>2-</sup> = [Au(S<sub>2</sub>O<sub>3</sub>)<sub>2</sub>]<sup>3-</sup> + [Cu(S<sub>2</sub>O<sub>3</sub>)<sub>2</sub>]<sup>3-</sup> + 4NH<sub>3</sub>（2 分）4[Cu(S<sub>2</sub>O<sub>3</sub>)<sub>2</sub>]<sup>3-</sup> + O<sub>2</sub> + 16NH<sub>3</sub> + 2H<sub>2</sub>O = 4Cu(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> + 8S<sub>2</sub>O<sub>3</sub><sup>2-</sup> + 4OH<sup>-</sup>（2 分）[Cu(S<sub>2</sub>O<sub>3</sub>)<sub>2</sub>]<sup>3-</sup>写成[Cu(S<sub>2</sub>O<sub>3</sub>)<sub>3</sub>]<sup>5-</sup>，配平，也可得分。

**3-1-2** Cu(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> + S<sub>2</sub>O<sub>3</sub><sup>2-</sup> + H<sub>2</sub>O = CuS + SO<sub>4</sub><sup>2-</sup> + 2NH<sub>3</sub> + 2NH<sub>4</sub><sup>+</sup>（2 分）

**3-2-1** KClO<sub>4</sub> + 2HF + SbF<sub>5</sub> = FClO<sub>3</sub> + KSbF<sub>6</sub> + H<sub>2</sub>O（2 分）或：KClO<sub>4</sub> + 3HF + 2SbF<sub>5</sub> = FClO<sub>3</sub> + KSbF<sub>6</sub> + (H<sub>3</sub>O)SbF<sub>6</sub>

**3-2-2** AgF<sub>2</sub> + ClO<sub>2</sub> = ClO<sub>2</sub>F + AgF（2 分）

**3-2-3** Cl<sub>2</sub>O + 2F<sub>2</sub> = ClF + ClOF<sub>3</sub>（2 分）
