# 题-CM-210-09-在有机合成中使不同自由基间选择性

## 题目

### 第 9 题（22 分，占 None%）

在有机合成中，使不同自由基间选择性的发生交叉偶联极具挑战性，这是由于在自由基反应中，自由基的浓度通常极低，不同的自由基间很难相遇而发生交叉偶联。然而，如果两种自由基 A 与 B 具有明显不同的自反应速率常数，且 A 与 B 以相等的速率生成，便有可能高选择性的得到 A 与 B 相互偶联的产物。尤其是当 A 为动力学稳定性很高的持久性自由基(以PR 表示)、B 为动力学稳定性较低的瞬态自由基(以 TR 表示)时，PR-TR 偶联产物便有可能成为反应的主产物，该现象即被称作持久自由基效应。

**9-1** 假设 PR 与 TR 以相等的速率 r<sub>0</sub>生成，忽略 PR 自身偶联的反应，认为反应①：PR+TR→P<sub>1</sub>与反应②：2TR→P<sub>2</sub>的速率常数均为 k，回答以下问题：

**9-1-1** 为什么可以假设反应①与②具有相同的速率常数？解释其原因。

**9-1-2** 假设 TR 的生成速率与消耗速率相等。通过计算，指出随着反应进行，体系中 PR 是在逐渐积累还是逐渐消耗？积累/消耗速率是多少？(用 k 和 TR 的稳态浓度[TR]表示)

**9-2** 将下列反应的底物加热至高温后再迅速淬灭，体系中主要存在(a)、(b)与(c)三个物种(不考虑溶剂)。根据持久自由基效应，选出其中最多的物种：( )。

## 参考答案

**9-1-1** 反应①与②的能垒均极低，反应速率由扩散控制（1 分，答出由扩散控制即可得分）

**9-1-2**（共 3 分）由于 TR 的生成速率与消耗速率相等，则 r<sub>0</sub> = k[PR][TR] + 2k[TR]<sup>2</sup>（1 分）PR 的生成速率为 r<sub>0</sub>，消耗速率为 k[PR][TR]，则可知 PR 的生成速率大于消耗速率因此体系中 PR 在逐渐积累（1 分），积累速率为 2k[TR]<sup>2</sup>（1 分）
