# 题-CM-65-04-将一定量的记为溶于二氯乙烷溶

## 题目

### 第 4 题（9 分）

将一定量的 $\mathrm { [ PtCl _{ 2 } ( C _{ 2 } H _{ 4 } ) ] _{ 2 } }$ (记为 $\pmb { \mathsf { A } } )$ 溶于二氯乙烷溶剂中， 加入一定量的甲醇(记为S)， 二聚体部分解聚为单体 $\mathrm { [ PtCl _{ 2 } ( C _{ 2 } H _{ 4 } ) ( CH _{ 3 } OH ) ] }$ (记为 B)， 达到平衡：

为测定该反应的平衡常数 $K _{ \mathrm { S } }$ ，利用分光光度法， 使用厚度 $b = 1.00 \mathrm { cm }$ 的吸收池， 在 $\lambda =$ $244 \mathrm { nm }$ 处测定平衡时体系的吸光度 $A$ 。以下为几组实验数据， 化合物 $\pmb { \mathsf { A } }$ 和甲醇的初始浓度以及平衡时溶液的吸光度已列在表中。

已知B 的摩尔吸光系数 $\varepsilon _{ \mathrm { B } } = 2.90 \times 10^{ 3 } \mathrm { L } { \cdot } \mathrm { mol } ^{ - 1 } { \cdot } \mathrm { cm } ^{ - 1 }$ ， 该波长下甲醇和二氯乙烷的吸收可忽略不计。

![](images/902d646527ca647fa9b24e48dd2e00df498f705e5ebeb4bae9f8a3e8c1cb7d12.jpg)

4-1 计算 $\mathsf { \pmb A }$ 的摩尔吸光系数εA。

4-2 计算反应的平衡常数 $K _{ \mathrm { S } }$ 。

4-3 计算实验3 中溶液的吸光度 $\mathbf { \nabla } _{ A _{ 3 } }$ 。

(提示： 多组分体系中吸光度等于各组分吸光度之和， 即 $A = \varepsilon _{ 1 } b c _{ 1 } + \varepsilon _{ 2 } b c _{ 2 } + . . . + \varepsilon _{ n } b c _{ n } )$
