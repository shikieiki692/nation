# 题-CM-160-08-8-1已知下列键能的数据

## 题目

### 第 8 题

第 8 题（9 分， 占 $8 \%$ ） 有机化学原理

8-1 已知下列键能的数据：

Me-Br $\mathrm { BE } = 70 \mathrm { kcal / mol }$ $\mathbf { Me } _{ 3 } \mathbf { C } \mathbf { - Br }$ $\begin{array} { c c } { { { \mathrm { BE } } = 63 \ \mathrm { kcal / mol } } } & { { \qquad \Delta _{ 1 } = 7 \ \mathrm { kcal / mol } } } \\ { { { \mathrm { BE } } = 91 \ \mathrm { kcal / mol } } } & { { \qquad \Delta _{ 2 } = 13 \ \mathrm { kcal / mol } } } \end{array}$ Me-H $\mathrm { BE } = 104 \mathrm { kcal / mol }$ $\mathbf { Me } _{ 3 } \mathbf { C } \mathbf { - } \mathbf { H }$

下列列举了对上述现象的可能主要影响因素，说明各种因素导致的 $\Delta _{ 1 }$ ， $\Delta _{ 2 }$ 的相对大小应该是怎样的， 由此说明下列说法中最合理的是哪一个。

氢自由基的能量高 B. $\mathbf { Me } _{ 3 } \mathbf { C }$ 中的超共轭效应 $\mathrm { C . Me _{ 3 } C }$ 中的空助效应

8-2 异戊二烯和丁烯酮反应， 可以得到两对对映体。当反应在水中反应时比无溶剂相比，有一对对映体的比例显著升高。 预测哪种产物的比例会升高并说明原因。

## 参考答案

Me-Br BE = 70 kcal/mol Me₃C-Br BE = 63 kcal/mol Δ₁ = 7 kcal/mol
Me-H BE = 104 kcal/mol Me₃C-H BE = 91 kcal/mol Δ₂ = 13 kcal/mol

8-1 本题共6分
A. 从热力学上解释了BE的差别，但是不能解释 $\Delta_{1},\Delta_{2}$ 的相对大小（1分）
B. 由于 $\mathrm{Me}_3\mathrm{C}$ 具有较大的超共轭稳定化作用（1分），这个稳定化作用不仅是对自由基的，在底物中对C-Br键也有明显强于C-H键的超共轭。（1分）因此， $\mathrm{Me}_3\mathrm{C}-\mathrm{Br}$ 的底物稳定性增强，从而键能削弱程度相较于 $\mathrm{Me}_3\mathrm{C}-\mathrm{H}$ 更小。（1分）
于Me3C-H 更小。（1 分）C. Me3C 的空助效应使得Me3CBr 更容易解离，使得Δ1 应该大于Δ2。（1 分）所

C. $\mathrm{Me}_3\mathrm{C}$ 的空助效应使得 $\mathrm{Me}_3\mathrm{CBr}$ 更容易解离，使得 $\Delta_{1}$ 应该大于 $\Delta_{2}$ 。（1分）
所以，最合理的应为B（1分）

8-2 本题共3分
