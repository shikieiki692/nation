# 题-CM-223-01-11α氮化硼被应用于半导体工业可

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-13-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（10 分）

**1-1** α-氮化硼被应用于半导体工业，可利用化学气相沉积法制备。氨和三氯化硼在 1000 K 下反应，可生成 α-氮化硼。

**1-2** 乙酸铅与次氯酸钠的碱性溶液反应可生成一种褐色固体，书写离子反应方程式。

**1-3** 向四羰基合钴酸钾的水溶液中通入一氧化氮气体，可制得一种电中性配合物（其中钴满足十八电子规则），反应同时产生两种可燃气体。

**1-4** 在 80℃时，向硫酸锌和硫酸亚铁的混合溶液中加入过量的草酸钠溶液（反应 1），分离出沉淀、干燥后在空气中热解，主要经历两步失重：在 212℃附近失重 19.68%，对应失去六个结晶水；在 303℃附近失重 36.43%，得到一种多孔纳米材料，该材料是一种复合氧化物（反应 2）。写出反应 1~反应 2 的化学方程式。

## 参考答案

**1-1** NH<sub>3</sub> + BCl<sub>3</sub> = BN + 3HCl（2 分）

**1-2** ClO<sup>-</sup> + Pb(CH<sub>3</sub>COO)<sub>2</sub> + 2OH<sup>-</sup> = PbO<sub>2</sub> + Cl<sup>-</sup> + 2CH<sub>3</sub>COO<sup>-</sup> + H<sub>2</sub>O（2 分）写作 2ClO<sup>-</sup> + Pb(CH<sub>3</sub>COO)<sub>2</sub> + H<sub>2</sub>O = PbO<sub>2</sub> + 2CH<sub>3</sub>COO<sup>-</sup> + 2HClO + Cl<sup>-</sup>也得分

**1-3** 2KCo(CO)<sub>4</sub> + 2NO + 2H<sub>2</sub>O = 2Co(NO)(CO)<sub>3</sub> + 2CO + H<sub>2</sub> + 2KOH

反应 1：Zn<sup>2+</sup> + 2Fe<sup>2+</sup> + 3C<sub>2</sub>O<sub>4</sub><sup>2-</sup> + 6H<sub>2</sub>O = ZnFe<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·6H<sub>2</sub>O（2 分）反应 2：ZnFe<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub> = ZnFe<sub>2</sub>O<sub>4</sub> + 4CO + 2CO<sub>2</sub>（2 分）
