# 题-CM-72-04-是一种二元弱酸摩尔质量可以作

## 题目

### 第 4 题（10 分）

$\mathrm { H } _{ 2 } \pmb { \mathrm { X } }$ 是一种二元弱酸， 摩尔质量 $90 \mathrm { g / mol }$ ， 可以作为漂白剂、 还原剂、 媒染剂等， 也可以用作洗去铁锈。将少量纯净的 $\mathrm { Fe } _{ 2 } \mathrm { O } _{ 3 }$ 放入 $\mathrm { H } _{ 2 } \mathbf { X }$ 的水溶液中，充分反应后，加入适量KOH 固体，小心地蒸发浓缩，析出一种翠绿色晶体 $\pmb { \mathsf { A } }$ 。X-射线衍射实验证明，A 是一种钾盐，其阴离子呈现 $D _{ 3 }$ 对称性；热重分析数据表明， $\pmb { \mathsf { A } }$ 在 $0 \sim 650 ~ ^{ \circ } \mathrm { C }$ 范围内存在四个失重峰： $99^{ \circ } \mathrm { C }$ ，失重$10.71 \%$ ； $287^{ \circ } \mathrm { C }$ ， 失重 $8.90 \%$ ； $435^{ \circ } \mathrm { C }$ ， 失重 $14.85 \%$ ； $450 \sim 580 ~ ^{ \circ } \mathrm { C }$ ， 失重 $8.83 \%$ 。

4-1 写出 $\pmb { \mathsf { A } }$ 的化学式。

4-2 分别写出 $\pmb { \mathsf { A } }$ 各步分解的化学反应方程式。

## 参考答案

## 第4题（10分）

4-1 写出 A 的化学式。

4-1  $K_{3}[Fe(C_{2}O_{4})_{3}]\cdot3H_{2}O$  （2分）

4-2  $K_{3}[Fe(C_{2}O_{4})_{3}]\cdot3H_{2}O = K_{3}[Fe(C_{2}O_{4})_{3}] + 3H_{2}O$ $2K_{3}[Fe(C_{2}O_{4})_{3}] = 2K_{2}[Fe(C_{2}O_{4})_{2}] + K_{2}C_{2}O_{4} + 2CO_{2}$ $K_{2}[Fe(C_{2}O_{4})_{2}] = FeO + K_{2}C_{2}O_{4} + CO_{2} + CO$ $K_{2}C_{2}O_{4} = K_{2}CO_{3} + CO$

（8分，每式2分。 $K_{2}[Fe(C_{2}O_{4})_{2}]$  写成  $K_{2}C_{2}O_{4} + FeC_{2}O_{4}$  或其他合理形式，也可得分）
