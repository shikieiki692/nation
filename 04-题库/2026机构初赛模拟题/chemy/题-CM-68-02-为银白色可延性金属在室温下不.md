# 题-CM-68-02-为银白色可延性金属在室温下不

## 题目

### 第 2 题（12 分）

$M$ 为银白色可延性金属，在室温下不溶于稀盐酸、稀硝酸， 但加热反应可迅速产生气体。M的氧化物A 为白色固体，难溶于水，具有两性。在 $1000^{ \circ } \mathrm { C }$ 下，用 $\mathrm { Cl } _{ 2 }$ 处理 $\pmb { \mathsf { A } }$ 与炭黑的混合物，可制得化合物 B，B 在常温下为无色液体；将 B 与金属 $\boldsymbol { \mathsf { M } }$ 密封加热至 $600^{ \circ } \mathrm { C }$ ， 生成紫色固体 C；将C 置于真空反应管的一端， 加热至 $450^{ \circ } \mathrm { C }$ ， 生成黑色固体 $\pmb { \mathsf { D } }$ ；将反应管的另一端保温于- ${ } - 78^{ \circ } \mathrm { C }$ ， 得到化合物B。

2-1 请写出 M 的元素符号和 $A \sim 0$ 的化学式。

2-2 回答如下问题：

2-2-1 为何M 在室温下与稀硝酸无明显反应现象？

2-2-2 A 和碳酸盐E 按反应当量比熔融混合共热， 反应失重 $15.88 \%$ ， 得到复合氧化物F；F属立方晶系，氧原子占据晶胞的面心位置，M 占据晶胞的体心位置，另一金属占据晶胞的的顶点位置。写出E 和F 的化学式。

2-2-3 A 的水合物可由 B 加到冰冷水中制得； 也可由 $\boldsymbol { \mathsf { M } }$ 溶于硫酸， 加热煮沸并放置制得。这两种方法制得的A 的水合物， 何者易溶于碱溶液， 何者难溶于碱溶液？

2-2-4 用环戊二烯钠处理 B，然后用钠还原， 可制得 $M$ 的二茂配合物 “ $\mathbf { M } ( \mathrm { C } _{ 5 } \mathrm { H } _{ 5 } ) _{ 2 } ^{ \prime \prime }$ ， 该配合物实际上是以两个氢桥键相连接的反磁性二聚体。 画出该二聚体的结构示意图。

2-2-5 在液氨溶剂中B 与甲醇反应， 生成四核络合物 $[ \bf M _{ 4 } ( \mathrm { OCH { _ 3 } } ) _{ 10 } ( \mu ^{ 2 } \mathrm { - OCH _{ 3 } } ) _{ 4 } ( \mu ^{ 3 } \mathrm { - OCH _{ 3 } } ) _{ 2 } ]$ ， 请写出该反应的化学反应方程式， 画出产物的结构示意图。
