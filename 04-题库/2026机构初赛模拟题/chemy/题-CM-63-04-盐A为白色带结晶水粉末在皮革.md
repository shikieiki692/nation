# 题-CM-63-04-盐A为白色带结晶水粉末在皮革

## 题目

### 第 4 题（9 分）

盐 A 为白色带结晶水粉末， 在皮革工业、 印染行业中具有重要的作用。将 $ { 1.260 \mathrm { ~ g ~ } }$ 盐 A 置于 $\mathbf { N } _{ 2 }$ 气氛中加热至 $150^{ \circ } \mathrm { C }$ ， 失重 $34.6 \%$ 得到 B，对应于失去所有结晶水；对 B 继续进行加热至恒重，放出摩尔比 $1 : 1$ 的两种气体的混合物，其密度为 $0.61 \ \mathrm { g / L } \ ( 298.15 \mathrm { K } , 100 \mathrm { kPa } )$ ；剩余固体为白色粉末C，质量为 $0.642 \ \mathrm { g }$ 。A、B、C 溶于水所得到的溶液均具有一定的碱性。
用。将1.260 g 盐A 置于N2 气氛中加热至150°C，失重34.6

4-1 通过计算和推理确定放出气体的成分和 $\pmb { \mathsf { A } }$ 的化学式。

4-2 写出B 和C 的化学式。

4-3 若该反应在空气气氛中进行， 则生成C 所需的温度是更高还是更低？解释原因。

## 参考答案

## 第4题（9分）

4-1 混合气体的摩尔质量为：
 $M = \rho RT / p = 15.0 \, g/mol$ （1 分），故混合气体中必有  $H_{2}$ （1 分）；
又因两种气体摩尔比为 1:1，故另一气体摩尔质量为 28 g/mol，为 CO（1 分）；
 $n(\mathrm{H}_{2})=n(\mathrm{CO})=[1.260\mathrm{g}\times(1-0.346)-0.642\mathrm{g}]/[2\times15.0\mathrm{g}/\mathrm{mol}]=6.07\times10^{-3}\mathrm{mol}$
结晶水的摩尔数为  $n(\mathrm{H}_{2}\mathrm{O})=1.260\mathrm{g}\times0.346/18.0\mathrm{g}/\mathrm{mol}=2.42\times10^{-2}\mathrm{mol}$ （0.5 分）
