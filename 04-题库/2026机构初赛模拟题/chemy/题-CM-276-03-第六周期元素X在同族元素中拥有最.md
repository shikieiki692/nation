# 题-CM-276-03-第六周期元素X在同族元素中拥有最

## 题目

### 第 3 题（15 分）

第六周期元素 X 在同族元素中拥有最大的电负性，且存在负氧化态的化合物。X 的单质为化学性质稳定的金属，不溶于硫酸、盐酸，但溶于盐酸与硝酸按一定比例混合的溶液，形成带有一个负电荷的配合物离子 XA<sub>n</sub><sup>-</sup>，其中 X 原子为 4 配位。XA<sub>n</sub><sup>-</sup>可以作为 X 与硫醇阴离子、膦配体等形成的各种原子簇合物的原料，这些原子簇在催化、电化学等领域都有广泛的应用。

**3-1** 写出 X 代表的元素，画出 XA<sub>n</sub><sup>-</sup>的结构式并标明 X 的杂化形式。

**3-2** 用 XA<sub>n</sub><sup>-</sup>、X 的第五周期同族元素 Y 的乙酸盐、硫醇(HSR)、过量硼氢化钠等于四氢呋喃中反应，可以得到 BA<sub>4</sub><sup>-</sup>与阴离子[X<sub>22</sub>Y<sub>3</sub>(SR)<sub>18</sub>]<sup>-</sup>。写出该反应的方程式。

**3-3** 用硫醇、硼氢化钠等与 XA<sub>n</sub><sup>-</sup>反应得到一种 X 原子簇阴离子[X<sub>25</sub>(SR)<sub>18</sub>]<sup>n-</sup>。它的结构可以以如下方式描述：该阴离子含有 I<sub>h</sub>对称性的正二十面体 X<sub>13</sub>核心，外层包含 6 个 X<sub>2</sub>(SR)<sub>3</sub>单元，这些单元中 X、S 均共面。6 个单元分别分布在 X<sub>13</sub>核心的三条两两正交的 C<sub>2</sub>轴上，且一个单元内两个 X 原子间的连线与同一 C<sub>2</sub>轴上 X<sub>13</sub>核心的棱异面正交。整个阴离子有对称中心。

**3-3-1** 将内层的 X<sub>13</sub>核心视作一层，外层的若干 X<sub>2</sub>S<sub>3</sub>单元视作一层，请分层表达该阴离子的结构，无需表示出 R 基。

**3-3-2** 写出该阴离子中[X<sub>25</sub>S<sub>18</sub>]簇所属的点群。

**3-4** 原子簇[X<sub>25</sub>(SR)<sub>5</sub>(PPh<sub>3</sub>)<sub>10</sub>Cl<sub>2</sub>]<sup>2+</sup>和 X<sub>25</sub>(SR)<sub>11</sub>中，簇核心结构均基于两个共用顶点的二十面体构建，两原子簇对应所属点群分别为 D<sub>5h</sub>与 D<sub>5d</sub>。

**3-4-1** 已知 X 在其中只形成、且在空间位置合适的情况下一定会形成三中心键。画出这两种

簇核心的异构体的结构。

**3-4-2** 指出两种原子簇中哪一个更缺电子，并说明其缺电子性对核心结构的影响。
