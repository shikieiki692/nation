# 题-CM-101-08-如下所示利用蒎烯氧化物的水解

## 题目

### 第 8 题（11 分）

如下所示，利用蒎烯氧化物的水解反应制备索布瑞醇。反应温度不同时，可得到索布瑞醇不同的异构体。当温度为 $20^{\circ}$ C 时，反应仅得到光活性的 trans-索布瑞醇；当温度为 $100^{\circ}$ C 时，反应得到外消旋的 trans-索布瑞醇和 cis-索布瑞醇。

![](images/a76d4f9ec2ca81ea3725c29ecd722ee4399b4b6d6f0d4ff052e629d4a8406c25.jpg)

8-1 写出 $20^{\circ}C$ 时，反应得到的光活性 trans-索布瑞醇中不对称碳原子的构型 $(R/S)$ 。

8-2 画出 $20^{\circ}$ C 下由蒎烯氧化物生成光活性的 trans-索布瑞醇的所有关键中间体。

8-3 解释 $100^{\circ}$ C 下反应生成外消旋的 trans-索布瑞醇和 cis-索布瑞醇的原因；画出反应关键中间体的共振式。

8-4 若反应在 $H_{2}^{18}O$ 中进行，在答题纸的附图中分别圈出不同温度下产物中 ${}^{18}O$ 的位置。

8-5 20°C 下的反应还有两种化学式为 $C_{10}H_{16}O$ 的副产物醇生成，画出它们的结构简式。

8-3 温度较高时，水能将光活性的 trans-索布瑞醇的羟基质子化，然后脱除水分子形成内消旋（或左右对称）的烯丙基型的碳正离子。水分子从碳正离子的两侧进攻的可能性相同，因此生成外消旋产物；水分子可以从碳正离子的上方或下方进攻，因此得到 trans 和 cis 两种产物。（2 分）
