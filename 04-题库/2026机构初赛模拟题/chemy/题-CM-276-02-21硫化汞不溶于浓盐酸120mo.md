# 题-CM-276-02-21硫化汞不溶于浓盐酸120mo

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-6-2`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（11 分）

**2-1** 硫化汞不溶于浓盐酸(12.0 mol·L<sup>-1</sup>)，可溶于浓硝酸(16.0 mol·L<sup>-1</sup>)，易溶于王水(浓硝酸与浓盐酸以体积比 1 : 3 配制而成)，写出溶解反应的化学方程式并通过计算说明硫化汞在不同体系中溶解性的差异。

**2-2** 稀硝酸和稀盐酸的混合物也可以溶解硫化汞，假设硫化汞的溶解度达到 10.0 g·L<sup>-1</sup>，且平衡时[Cl<sup>-</sup>] = 1.5 mol·L<sup>-1</sup>，计算混合物中硝酸和盐酸的浓度。已知：HgS 的溶度积 K<sub>sp</sub> = 1.6 × 10<sup>-52</sup>，H<sub>2</sub>S 的电离常数 pK<sub>a1,2</sub> = 7.05, 12.92。

![](images/61db119baefd1f052025b2ca2577a73bceb228134984b00fcf827333177374cb.jpg)

## 参考答案

**2-1**（1）硫化汞与盐酸反应：

不发生氧化还原：HgS + 2H<sup>+</sup> + 4Cl<sup>-</sup> = HgCl<sub>4</sub><sup>2-</sup> +H<sub>2</sub>S（0.5分）

K = K<sub>sp</sub>·β<sub>4</sub>·(K<sub>a1</sub>·K<sub>a2</sub>)<sup>-1</sup> = 1.8 × 10<sup>-16</sup>（0.5分）

可以得到平衡时[Hg<sup>2+</sup>] = 2.3 × 10<sup>-5</sup> mol·L<sup>-1</sup>，不溶解（0.5分）

（2）硫化汞与硝酸反应有两种情况：

不发生氧化还原：HgS + 2H<sup>+</sup> = Hg<sup>2+</sup> + H<sub>2</sub>S（0.5分）

K = K<sub>sp</sub>·(K<sub>a1</sub>·K<sub>a2</sub>)<sup>-1</sup> = 1.5 × 10<sup>-32</sup>（0.5分）

可以得到平衡时[Hg<sup>2+</sup>] = 2.0 × 10<sup>-15</sup> mol·L<sup>-1</sup>，不溶解（0.5分）

发生氧化还原：3HgS + 8H<sup>+</sup> + 2NO<sub>3</sub><sup>-</sup> = 3Hg<sup>2+</sup> + 3S + 2NO + 4H<sub>2</sub>O（0.5分）

![](images/96b651c45b809a2019458a11d94c3626005f24473c16dc07d4322392741ef34e.jpg)

可以得到平衡时[Hg<sup>2+</sup>] = 0.57 mol·L<sup>-1</sup>，可溶解（0.5分）

（3）硫化汞与王水反应：

王水中各离子的浓度：[H<sup>+</sup>] = 13.0 mol·L<sup>-1</sup>，[NO<sub>3</sub><sup>-</sup>] = 4.0 mol·L<sup>-1</sup>，[Cl<sup>-</sup>] = 9.0 mol·L<sup>-1</sup>

发生氧化还原：3HgS + 8H<sup>+</sup> + 2NO<sub>3</sub><sup>-</sup> + 12Cl<sup>-</sup> = 3HgCl<sub>4</sub><sup>2-</sup> + 3S + 2NO + 4H<sub>2</sub>O（0.5分）

φ(S/HgS) = 0.637 V，E = 0.320 V，K = exp(nFE/RT) = 2.7 × 10<sup>32</sup>（1分）

可以看出反应进行得非常彻底，易溶解（1分）

**2-2** 首先根据溶解度计算出汞离子的平衡浓度浓度：[HgCl<sub>4</sub><sup>2-</sup>] = 4.3 × 10<sup>-2</sup> mol·L<sup>-1</sup>（1分）

![](images/610f8dff3b2e7f3adc0124c97e204a36eb7c0c5c07e6711fbb81cd03896935f2.jpg)

其中c(HCl) = [Cl<sup>-</sup>] + 4[HgCl<sub>4</sub><sup>2-</sup>]，c(HNO<sub>3</sub>) = [NO<sub>3</sub><sup>-</sup>] + 2/3[HgCl<sub>4</sub><sup>2-</sup>]

所以[H<sup>+</sup>] = [Cl<sup>-</sup>] + [NO<sub>3</sub><sup>-</sup>] + 2[HgCl<sub>4</sub><sup>2-</sup>]（1分）

又根据平衡关系，有[H<sup>+</sup>]<sup>8</sup>·[NO<sub>3</sub><sup>-</sup>]<sup>2</sup>·[Cl<sup>-</sup>]<sup>12</sup> = [HgCl<sub>4</sub><sup>2-</sup>]<sup>3</sup>/K

联立上述方程，解得c(HCl) + c(HNO<sub>3</sub>) = 1.70 mol·L<sup>-1</sup>，[NO<sub>3</sub><sup>-</sup>] = 0（1分）

故c(HNO<sub>3</sub>) = 2/3[HgCl<sub>4</sub><sup>2-</sup>] = 0.03 mol·L<sup>-1</sup>，c(HCl) = 1.67 mol·L<sup>-1</sup>（1分）

注意：硝酸根作为氧化剂，在溶解过程中被完全消耗。
