化物CoO；继续加热至360°C，则产物转化为Co3O4。A 在氩气气氛中加热至360°C 总失重60.9%。3-1 通

3-1 A 总失重 $59.3 \%$ ， $\mathrm { CoO }$ 占 $40.7 \%$ ， 则有：
$M(\mathbf{A}) = (58.93 + 16.00) \ \mathrm { g/mol } / 40.7 \% = 184.1 \ \mathrm { g/mol }$ （1 分）
其中结晶水的数目为： $y = 184.1 \times 19.3 \% / 18.02 \ \mathrm { g \ mol } ^ { - 1 } = 1.97 \approx 2$ （1 分）
由： $58.93 + 2 \times M(\mathbf{X}) + 2 \times 18.02 = 184.1$
求得： $M ( \mathbf { X } ) = 44.6 ~ \mathrm { g { \cdot mol^{ - 1 } } }$ （0.5 分）
产生的气体为 $\mathrm { CO } _{ 2 }$ ， 因此 HX 应为有机酸， HCOO-的式量为 45， 与 44.6 接近， 因此 HX
为 HCOOH。 （1 分）
综上， A 的化学式为 $\mathrm { Co } ( \mathrm { HCOO } ) _{ 2 } \cdot 2 \mathrm { H } _{ 2 } \mathrm { O }$ （0.5 分）

3-2 $6 \mathrm { Co } ( \mathrm { HCOO } ) _{ 2 } \cdot 2 \mathrm { H } _{ 2 } \mathrm { O } + 7 \mathrm { O } _{ 2 } \rightarrow 2 \mathrm { Co } _{ 3 } \mathrm { O } _{ 4 } + 18 \mathrm { H } _{ 2 } \mathrm { O } + 12 \mathrm { CO } _{ 2 }$ （2 分）

氩气中总失重 60.9% ，大于空气中的总失重 59.3% ， 故必有金属Co 产生；因此产物为Co 和CoO 的混合物（1 分）
设失重后总组成为 $\mathrm { CoO } _{ x }$ ， 则 $M(\mathrm { CoO } _{ x }) = 185.0 \times ( 1 - 60.9 \% ) = 72.3 \ \mathrm { g } \cdot \mathrm { mol } ^ { - 1 }$ （1 分）设Co 的摩尔分数为 $a$ ， CoO 的摩尔分数为 $( 1 - a )$ ， 则：
$58.93 \times a + ( 58.93 + 16.00 ) \times ( 1 - a ) = 72.3$ （1 分）
解得 $a = 0.16$
所以Co 的摩尔分数为0.16（0.5 分）， CoO 的摩尔分数为 0.84 （0.5 分）。
