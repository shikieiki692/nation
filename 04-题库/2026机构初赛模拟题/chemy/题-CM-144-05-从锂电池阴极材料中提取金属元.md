# 题-CM-144-05-从锂电池阴极材料中提取金属元

## 题目

### 第 5 题（12 分）

从锂电池阴极材料中提取金属元素是获取锰单质的重要途径之一。比较传统的获得锰单质的方法是将 $LiMn_{2}O_{4}$ 固体用过氧化氢的硫酸溶液溶解，锰在该过程中被还原为 Mn(II)(反应 1)，之后通过电化学的手段即可获得锰单质。这种传统的方法需要使用高浓度的无机酸，条件相对来说比较剧烈。因此，另一种提取锰元素的方法是在 $120^{\circ}C$ 下用柠檬酸(3-羧基-3-羟基戊二酸)水溶液处理 $LiMn_{2}O_{4}$ 固体，随着时间的变化，反应体系从一开始的黑色浑浊液转化为无色透明溶液 (反应 2)，一段时间后又变为白色浑浊液 (反应 3)，过滤后得到白色固体 X。XRD 表明 X 为 Mn 的单核配合物，且 X 中 Mn 元素的质量分数为 20.88%。以 $LiMn_{2}O_{4}$ 为原料还可以制备特定晶型的二氧化锰。将 $LiMn_{2}O_{4}$ 固体与 $0.5\ mol/L\ H_{2}SO_{4}$ 混合，室温下磁搅拌 3 h 即可得到 λ 晶型的 $MnO_{2}$ (反应 4)。

5-1 写出反应 1\~反应 4 的离子方程式。

5-2 已知 X 中 Mn 为四配位，含有一个六元环和一个五元环，画出 X 的结构。

5-3 X 射线光电子能谱(XPS)是一种利用能量较高的软 X 射线作为激发源，通过探测非键的内层电子，从而确定未知化合物的元素组成、氧化态等性质。下图为化合物 X 的部分 XPS 谱图，横坐标表示电子结合能(从对应轨道中电离出一个电子所需要的能量，可通过单电子原子轨道能来衡量)。指出图中 A-D 四个峰的归属，已知它们分别对应于 Mn 的 3s 轨道，Mn 的 2p 轨道，C 的 1s 轨道和 O 的 1s 轨道。

## 第 5 题（12 分）锰的化合物

5-1 反应 1: $2\mathrm{LiMn_2O_4 + 3H_2O_2 + 10H^+ = 4Mn^{2+} + 2Li^+ + 8H_2O + 3O_2}$ (2 分)
反应 2: $6\mathrm{LiMn_2O_4 + 30H^+ + C_6H_8O_7 = 6Li^+ + 12Mn^{2+} + 19H_2O + 6CO_2}$ (2 分)
反应 3: $\mathrm{Mn^{2+} + H_2O + C_6H_6O_7^{2-} = Mn(C_6H_6O_7)H_2O}$ (1 分)
反应 4: $2\mathrm{LiMn_2O_4 + 4H^+ = Mn^{2+} + 3MnO_2 + 2Li^+ + 2H_2O}$ (2 分)
