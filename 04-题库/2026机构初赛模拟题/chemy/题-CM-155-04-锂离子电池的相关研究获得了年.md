# 题-CM-155-04-锂离子电池的相关研究获得了年

## 题目

### 第 4 题

# 第 4 题 （23 分， 占比 $16 \%$ ） 锂离子电池

锂离子电池的相关研究获得了 $2019$ 年的诺贝尔化学奖。 为获得高能量密度、 长循环寿命的锂离子电池， 世界各地的研究人员进行了诸多尝试与探索。

电极材料的探索 金属卤化物是锂离子电池的一种理想电极材料。由于此类卤化物在液体电解质的溶解性一般较好，此类锂离子电池一般采用固体电解质。据此，研究人员设计了一种将 $\mathrm { Li _{ 6 } PS _{ 5 } Cl }$ 作为固体电解质、两极分别为 $\mathrm { \Delta VCl _{ 3 } }$ -Li3InCl6-C 和 Li 金属的锂离子电池。

4-1 指出该电池的正负极，并写出该电池放电时的电极反应方程式 $\mathrm { ( VCl _{ 3 } }$ 对应的产物用$\mathrm { Li } _{ x } \mathrm { VCl } _{ 3 }$ 表示)。

4-2 在 $\mathrm { \Delta VCl _{ 3 } }$ 晶体中， 氯作六方最密堆积， 钒隔层填充 （一层填充钒原子，相邻的一层不填充钒原子） 部分八面体空隙， 形成了层状结构。该晶体的晶胞参数为 $a = b = 601.2 \ \mathrm { pm }$ ， $c =$ 1734 pm， $\alpha = \beta = 90^{ \circ }$ ， $\gamma = 120^{ \circ }$ 。在一个晶胞内， 任意两层钒原子沿 $\boldsymbol { \mathscr { c } }$ 轴的投影不完全重合。

4-2-1 指出填充钒原子的一层中钒原子所占八面体空隙的比例。

4-2-2 结合计算， 指出该晶体所属晶系、 点阵型式及结构基元。

4-2-3 然而 $\mathrm { LiVCl } _{ 3 }$ 的晶体结构与 $\mathrm { \Delta VCl _{ 3 } }$ 有所不同。 其中氯原子作立方最密堆积，钒和锂交替填充 （即一层填钒原子，一层填锂原子） 部分八面体空隙。 指出 $\mathrm { [ VCl _{ 6 } ] }$ 八面体和 $\mathrm { [ LiCl _{ 6 } ] }$ 八面体之间的连接关系。

容器 1：加入 $\mathrm { K _{ 3 } Fe ( CN ) _{ 6 } \mathrm { - K _{ 4 } Fe ( CN ) _{ 6 } } }$ 混合溶液， 再向溶液中加入 LiFePO4 颗粒并使其分散在溶液中；

## 参考答案

4-1 电极指认共 1 分，电极反应方程式全部答对得 2 分。

正极： $VCl_{3}-Li_{3}InCl_{6}-C$ $VCl_{3}+x\ Li^{+}+xe^{-}=Li_{x}VCl_{3}$

负极：Li 金属 $Li = Li^{+} + e^{-}$

4-2-1 比例：2/3。（2分）

4-2-2

假设氯原子形成的是正八面体，则正八面体的边长为：

$$
h = 601.2 \mathrm{pm} / 3^{0.5} = 347.1 \mathrm{pm}
$$

单层的层间距为:

$$
d = 6^{0.5} \times h / 3 = 283.4 \mathrm{pm} (2 \text {分})
$$

而 c 约等于 6d，故一个晶胞中有 6 层。（1 分）

再结合 “任意两层钒原子沿 c 轴的投影不完全重合” 可知:

4-2-3 共棱连接、共顶点连接。(2 分)

![](images/6124e8ae76be78c59aec3c5b7357bd7599157aea341c292313d248f721fec889.jpg)

4-3 在 x 较小时， $VCl_{3}$ 和 $Li_{x}VCl_{3}$ 结构基本一致，发生的仅是 $Li^{+}$ 的嵌入和脱出，此时对应 1 个电势平台；在 x 较大时， $Li_{x}VCl_{3}$ 的晶体结构发生了较大改变（或答氯原子的堆积方式改变，整体骨架改变），相应地电极电势也不同，因此会出现第 2 个平台。（2 分）

![](images/58ab4f4098bf30ab051fa9071db973dc0ba82a225cb9626788d053cc15ad6a3d.jpg)


4-4 电极判断 1 分，电极反应方程式全部答对得 1 分，共 2 分。

容器 1 对应的电极为正极。

正极： $\mathrm{Fe(CN)}_6^{3-} + \mathrm{e}^- = \mathrm{Fe(CN)}_6^{4-}$

负极： $2S^{2-}=S_{2}^{2-}+2e^{-}$

4-5 能通过离子的化学式： $Li^{+}$ （1 分）

在容器 1 中： $\mathrm{Fe(CN)_6^{3-} + LiFePO_4 = Fe(CN)_6^{4-} + FePO_4 + Li^+}$ （2 分）

在容器 2 中： $2S^{2-} + LiTi_{2}(PO_{4})_{3} + 2Li^{+} = Li_{3}Ti_{2}(PO_{4})_{3} + S_{2}^{2-}$ （2 分）

4-6 可能生成了多硫阴离子。(1 分)
