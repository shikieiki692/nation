# 题-CM-195-01-在水溶液中选择性结合阴离子的分子

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-4-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（15 分，占 10%）

在水溶液中，选择性结合阴离子的分子受体为生化药物以及工业应用带来了发展机会。虽然已经发现许多合成分子可以有效地在有机溶剂中结合阴离子，但是在水溶液中的阴离子结合仍然面临着挑战。

**1-1** 分析为何在水相中比在有机溶剂中，水溶液中的 SO<sub>4</sub><sup>2-</sup>结合更加困难。

**1-2** 下图所示反应所得得到了一种属于 C<sub>3v</sub>点群的阴离子 Y，其中共形成了 12 根氢键，画出Y 的结构，注意示出所有的氢键。

![](images/a60f7d63f9d8a2bd4c642e08c33d1d40d5c377a5bd6115069cf101f089545979.jpg)

**1-3** 近期还合成出了一种中性笼状分子 X，可以在水溶液中有效地选择性地结合 SO<sub>4</sub><sup>2-</sup>。

**1-3-1** 该中性笼状分子 X 的合成路线如下，画出 A、X 的结构。

![](images/6014bc0fbcd2e96b9fee1d1949103bfa2a91d51293f719b80c25b1789e8b7d7c.jpg)

**1-3-2** 分别写出制备条件中(<sup>n</sup>Bu<sub>4</sub>N)<sub>2</sub>SO<sub>4</sub>和过量 BaCl<sub>2</sub>的作用。

**1-3-3** 若将(<sup>n</sup>Bu<sub>4</sub>N)<sub>2</sub>SO<sub>4</sub>换为 <sup>n</sup>Bu<sub>4</sub>NCl，其他条件不变，X 的产率会如何变化（变大或变小）。

**1-3-4** 在自然界的 SO<sub>4</sub><sup>2-</sup>受体蛋白中具有低极性的微环境，受此启发，研究人员猜测受体 X 在低极性环境下对硫酸根有更强的亲和性。研究人员设计了实验来验证猜想。

(1) 在 9 : 1 H<sub>2</sub>O/D<sub>2</sub>O 中，利用 Na<sub>2</sub>SO<sub>4</sub>对 X 进行滴定测得亲和性常数 K<sub>0</sub> = 66 M<sup>-1</sup>；

(2) 在 9 : 1 H<sub>2</sub>O/D<sub>2</sub>O 中，有 CTAB(十六烷基三甲基溴化铵)胶束存在下，利用 Na<sub>2</sub>SO<sub>4</sub>对 X进行滴定测得亲和性常数 K<sub>app</sub> = 990 M<sup>-1</sup>，下图简要表示了在滴定过程中 X 从水相迁移进入胶束的过程。

![](images/45025493bc5546dbe617c804b62a2301b2bb3929d039893b941293a1be9dc1b7.jpg)

需要指出的是，在形成 SO<sub>4</sub><sup>2-</sup>包合物前 X 主要在胶束外，且胶束表面正电荷与硫酸根的静电吸引会导致胶束表面的硫酸根浓度较溶液体相更大，实验(2)中所求的 K<sub>app </sub>是表观亲和性常数，而 X 在胶束中对硫酸根的固有亲和性常数 K<sub>intr </sub>与之代表的含义不同，对应的平衡反应式如下：

X(aq) + SO<sub>4</sub><sup>2-</sup>(aq) = X·SO<sub>4</sub><sup>2-</sup>(micelles) K<sub>app</sub>

X(micelles) + SO<sub>4</sub><sup>2-</sup>(surface) = X·SO<sub>4</sub><sup>2-</sup>(micelles) K<sub>intr</sub>其中[X(micelles)]是基于溶液体积而非基于胶束体积的、位于胶束内的笼 X 浓度，k = [X(micelles)] / [X(aq)] = 0.00223，[SO<sub>4</sub><sup>2-</sup>(surface)] / [SO<sub>4</sub><sup>2-</sup>(aq)] = exp(-zFΦ<sub>0</sub> / RT)，其中 z 为所涉及的离子的电荷数(注意正负)，Φ<sub>0</sub>为胶束表面电势(此处为 43.5 mV)，据此计算 298 K 时K<sub>intr</sub>的值。

## 参考答案

**1-1** 由于在水溶液中，SO<sub>4</sub><sup>2-</sup>被溶剂化（1 分）。分子要与其结合，需要破坏溶剂笼，需要额外吸热。

![](images/af5956844587b8588c8fbc2b39439c247c130d4e8b542721915cc6605bdd419f.jpg)

**1-3-1**

![](images/e78824161458e0c9c50ea94f52d8efaf7c34ea03f385c161c244fde7a6215635.jpg)

**1-3-2** TBA<sub>2</sub>SO<sub>4</sub>：硫酸根作为模板，促进笼状结构的生成（生成 X·SO<sub>4</sub><sup>2-</sup>）。（1 分）过量 BaCl<sub>2</sub>：除去 X·SO<sub>4</sub><sup>2-</sup>中的 SO<sub>4</sub><sup>2-</sup>。（1 分）

**1-3-3** 变小。（2 分）

![](images/d04c795748f1285053dbebcd6421ced356d674a21e00f54363c2b3e33ca38ff1.jpg)

**1-3-4** [SO<sub>4</sub><sup>2-</sup>(surface)] / [SO<sub>4</sub><sup>2-</sup>(aq)] = exp(-zFΦ<sub>0</sub> / RT) = 29.6（1 分）K<sub>app</sub> / K<sub>intr</sub> = [X(micelles)][SO<sub>4</sub><sup>2-</sup>(surface)] / [X(aq)][SO<sub>4</sub><sup>2-</sup>(aq)] = kexp(-zFΦ<sub>0</sub> / RT)（1 分）因此代入数据可得 K<sub>intr</sub> = 1.5 × 10<sup>4</sup> M<sup>-1</sup>（1 分）
