# 题-CM-172-03-3-1芳基重氮盐是合成卤代芳

## 题目

### 第 3 题 芳胺及其转化 （16 分， 占 $7 \%$

3-1 芳基重氮盐是合成卤代芳烃的重要原料，它一般是由芳胺与 $\mathrm { NaNO } _{ 2 }$ 在弱酸性条件下反应得到的。 然而芳基重氮盐有致癌性，并且在干燥或者较高温度时有爆炸的风险。

3-1-1 写出苯胺与 ${ \mathrm { NaNO } } _{ 2 }$ 在酸性条件下反应得到苯基重氮盐的离子反应方程式。

3-1-2 过量的 `{ \tt N a N O } _{ 2 }` 可以通过氨基磺酸 $( \mathsf { p } K _{ \mathrm { a } } = 1 )$ )淬灭， 写出离子反应方程式。

3-1-3 在 $\mathrm { pH } = 5 \sim 6$ 时， 苯基重氮盐会与水反应得到一种极易爆炸的分子； 画出其结构。

3-2 近来报导了一种利用硝酸盐氧化芳胺从而实现卤代的策略。在芳胺的乙腈溶液中加入硝酸盐、 $\mathrm { I } _{ 2 }$ 和含硫还原剂， 回流反应， 得到卤代芳胺：

NO3 (2 eq.), |2 (1 I2 (1 eq.)NH2 Na2S2O3.5H2O (1 eq.)EtO2C CH₃CN, reflux EtO₂C人们提出： $\left| \mathrm { NO } _{ 3 } \right.$ -被单电子还原为 $+ 4$ 氧化态，然后歧化得到阳离子 A，A 与芳胺反应可以原位得到低浓度的芳基重氮正离子，后者原位卤代即可转化为卤代烃。由于 $\mathrm { NO } _{ 3 } .$ -的动力学惰性很强，体系中实际发生的过程可能是：反应先生成含有 4 个硫原子的阴离子 B；B 歧化得到 $\mathrm { \Delta S _{ 8 } }$ 、 $\mathrm { SO } _{ 4 } { } ^{ 2 }$ -和 C(其中 ${ \mathrm { SO } } _{ 4 } { } ^{ 2 \cdot }$ -和 C 的摩尔数相同)，C 在室温下为气体； $\underline { { \pmb { c } } }$ 将 $\mathsf { NO } _{ 3 }$ -还原，从而进行接下来的步骤(不考虑芳胺的各种副反应)。

3-2-1 写出 A、B、C 的化学式以及由硝酸根转化为A 的过程中经历的含氮物种。

3-2-2 写出生成 B 的离子反应方程式以及 B 歧化为C 的离子反应方程式。

## 参考答案

3-1（共7分）

$$
3 - 1 - 1 \mathrm{C} _{6} \mathrm{H} _{5} \mathrm{NH} _{2} + \mathrm{NO} _{2} ^{-} + 2 \mathrm{H} ^{+} \rightarrow \mathrm{C} _{6} \mathrm{H} _{5} \mathrm{N} _{2} ^{+} + 2 \mathrm{H} _{2} \mathrm{O} (2 \text {分})
$$

苯胺质子化、亚硝酸写分子形式，都可以得分

$$
3 - 1 - 2 \mathrm{H} _{2} \mathrm{NSO} _{3} ^{-} + \mathrm{HNO} _{2} = \mathrm{N} _{2} + \mathrm{SO} _{4} ^{2 -} + \mathrm{H} _{2} \mathrm{O} + \mathrm{H} ^{+} (2 \text {分})
$$

亚硝酸写成 $H^{+}$ 和 $NO_{2}^{-}$ ，也可以；氨基磺酸写成分子形式，也可以
