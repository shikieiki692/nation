# 题-CM-291-06-在甲醇溶剂中邻苯二硒酚二钠与环戊

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-21-6`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（17 分）

在甲醇溶剂中，邻苯二硒酚二钠与环戊二烯基钴配合物[Co(η<sup>5</sup>-C<sub>5</sub>H<sub>5</sub>)I<sub>2</sub>(CO)]于 0°C 混合反应，搅拌下升至室温，析出深棕色固体；将此固体滤出，干燥、洗涤后，用己烷重结晶，得到深紫色配合物晶体。

X-射线衍射表明，在该深紫色配合物晶体中存在二聚体配合物分子 A<sub>2</sub>；晶体属单斜晶系，晶胞参数 a = 933.5 pm，b = 1164.8 pm，c = 1021.8 pm，β = 111.49°；晶胞内有 2 个二聚体分子 A<sub>2</sub>；晶体密度 D = 2.30 g/cm<sup>3</sup>。

![](images/2ae1bf838fd05b59e5544b4bfb693af79dc87387409a6d4e5420200334083c40.jpg)

<sup>1</sup>H-NMR 谱在 δ = 4.55 ppm 和 δ = 5.65 ppm 处有明显的单峰，对应于环戊二烯基上的氢原子。在分析浓度 c(A) = 0.0100 mol/L (= [A] + 2[A<sub>2</sub>]) 时，在 298 K 下，两峰的峰面积比为A<sub>4.55</sub> : A<sub>5.65</sub> : = 37.1；在 323 K 下，两峰的峰面积比为 A<sub>4.55</sub> : A<sub>5.65</sub> = 9.2。

**6-1** 通过计算，推出配合物 A<sub>2</sub>的化学式。

**6-2** 写出制备配合物 A<sub>2</sub>的化学反应方程式。

**6-3** 分别画出 A 和 A<sub>2</sub>的结构简式。

**6-4** 配合物 A<sub>2</sub>解聚为 A 的反应是吸热反应还是放热反应？

**6-5** 在 δ = 4.55 ppm 处和 δ = 5.65 ppm 处的峰何者对应 A 的环戊二烯基，何者对应 A<sub>2</sub>的环戊二烯基？

![](images/0e99061d91422b41f09753c20963a5cdd5c65b7b62e9d103c0e49d532a4db00c.jpg)

## 参考答案

**6-1** M = DN<sub>A</sub>V/Z = 716 g/mol（2 分）因此 A 的摩尔质量为 358 g/mol；钴、邻苯二硒酚双负离子、环戊二烯负离子的摩尔质量分别为 58.9 g/mol、233.5 g/mol 和 65.1 g/mol，相加恰为 358 g/mol。故 A<sub>2</sub>的化学式为 Co<sub>2</sub>(C<sub>6</sub>H<sub>4</sub>Se<sub>2</sub>)<sub>2</sub>(C<sub>5</sub>H<sub>5</sub>)<sub>2</sub>（1 分）。

**6-2** 2C<sub>6</sub>H<sub>4</sub>Se<sub>2</sub>Na<sub>2</sub> + 2[Co(η<sup>5</sup>-C<sub>5</sub>H<sub>5</sub>)I<sub>2</sub>(CO)] = Co<sub>2</sub>(C<sub>6</sub>H<sub>4</sub>Se<sub>2</sub>)<sub>2</sub>(C<sub>5</sub>H<sub>5</sub>)<sub>2</sub> + 4NaI + 2CO（2 分）

**6-4** 吸热反应（1 分）

**6-5** 在 δ = 4.55 ppm 处的峰对应于 A<sub>2</sub>；在 δ = 5.65 ppm 处的峰对应于 A（1 分）。A<sub>2</sub>解离为A 是 Co-Se 键异裂的吸热反应；升高温度时，A<sub>2</sub>减少，A 增加。升高温度时，δ = 4.55 ppm处峰面积减小，δ = 5.65 ppm 处峰面积增加，因此在 δ = 4.55 ppm 处的峰对应于 A<sub>2</sub>；在 δ = 5.65 ppm 处的峰对应于 A。

**6-6** 298 K 时，有：2[A<sub>2</sub>] + [A] = 0.0100 mol/L (10[A<sub>2</sub>]) / (5[A]) = 37.1联立以上二式，解得：[A] = 2.62 × 10<sup>-4</sup> mol/L；[A<sub>2</sub>] = 4.87 × 10<sup>-3</sup> mol/L（1 分）
