# 题-CM-54-01-1-1将碱式铬酸铜溶于稀硫酸

## 题目

### 第 1 题 写出以下反应的化学反应方程式（8 分）

1-1 将碱式铬酸铜 $\left[\mathrm{CuCrO}_{4} \cdot 2 \mathrm{Cu(OH)}_{2}\right]$ 溶于稀硫酸中。

1-2 在有水存在下，二氧化硫和二氧化碲按 2:1 的化学计量比反应。

1-3 向硫酸铜和四碘合汞(Ⅱ)酸钾的混合溶液中通入二氧化硫，析出一种红色固体。

1-4 小心地令叠氮化亚汞与过量氨水反应，产物之一是一种含汞 87.75% 的黄色汞盐沉淀。

# 第 1 题（8 分）

![](images/20c5b45918ca5496e33d96d40b8d4350baee6f97a7e9b18c5706de97d2ebaebc.jpg)

1-1 $2\mathrm { CuCrO } _{ 4 } \cdot 2 \mathrm { Cu(OH) } _{ 2 } + 10 \mathrm { H } ^ { + } = 6 \mathrm { Cu } ^ { 2 + } + \mathrm { Cr } _{ 2 } \mathrm { O } _{ 7 } ^ { 2 - } + 9 \mathrm { H } _{ 2 } \mathrm { O }$ （2 分）

1-2 $2 \mathrm { SO } _{ 2 } + \mathrm { TeO } _{ 2 } + 2 \mathrm { H } _{ 2 } \mathrm { O } = 2 \mathrm { H } _{ 2 } \mathrm { SO } _{ 4 } + \mathrm { Te }$ （2 分）

1-3 $2 \mathrm { CuSO } _{ 4 } + \mathrm { K } _{ 2 } \mathrm { HgI } _{ 4 } + \mathrm { SO } _{ 2 } + 2 \mathrm { H } _{ 2 } \mathrm { O } = \mathrm { Cu } _{ 2 } \mathrm { HgI } _{ 4 } + \mathrm { K } _{ 2 } \mathrm { SO } _{ 4 } + 2 \mathrm { H } _{ 2 } \mathrm { SO } _{ 4 }$ （2 分）
写 $\mathrm { KHSO } _{ 4 }$ 配平也可。

1-4 $2 \mathrm { Hg } _{ 2 } ( \mathrm { N } _{ 3 } ) _{ 2 } + 4 \mathrm { NH } _{ 3 } = 2 \mathrm { Hg } + [ \mathrm { Hg } _{ 2 } \mathrm { N } ] \mathrm { N } _{ 3 } + 3 \mathrm { NH } _{ 4 } \mathrm { N } _{ 3 }$ （2 分）$\mathrm { NH } _{ 3 }$ 写成一水合氨也可得分； 若产物 $[ \mathrm { Hg } _{ 2 } \mathrm { N } ] \mathrm { N } _{ 3 }$ 写成最简式 $\mathrm { HgN } _{ 2 }$ ， 只得1 分。
