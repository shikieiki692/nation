# 题-CM-158-05-超强酸superacid这一

## 题目

### 第 5 题 17 分， $8 \%$

超强酸(superacid)这一术语由 James Bryant Conant 于 1927 年提出，用于表示比纯硫酸更强的酸。除了常见的氟磺酸和三氟甲磺酸外，具有笼形核心的 A 也为超强酸。在乙二醇二甲醚中用过量的 ICl 处理 $\mathrm { Cs ^{ + } CB _{ 11 } H _{ 12 } }$ -可以以很好的产率得到阴离子 B-，该阴离子中硼的质量分数为 $13.24 \%$ 。 $\mathrm { CPh 3^{ + } \mathbf { B } ^{ - } }$ -在甲苯中与 $^{ i } \mathrm { Pr } _{ 3 } \mathrm { SiH }$ 作用， 可以得到浅黄色微晶 C，C 与无水的液态氯化氢反应则可以得到超强酸A。

5-1 结合计算推出 B-的化学式并写出 A 和C 的分子式。

5-2 画出所有具有最高对称性的B-的可能结构， 并指出它们属于何种点群。

5-3 课题组还制备了 C 的其他两种类似物， 即 C 中的卤素原子可以为氯或溴或碘。研究发现 C 中阴阳离子之间有着较强的相互作用， 示出这种相互作用，并将这三种类似物按照相互作用的大小进行排序。 (三种类似物分别记为 $\pmb { \mathsf { c } } _{ \mathrm { { Cl } } }$ 、 $\pmb { \mathsf { c } } _{ \mathrm { Br } }$ 、 CI)

5-4 课题组亦制备了 $\pmb { A }$ 的其他两种类似物， 给出三种类似物的酸性大小排序。 (三种类似物分别记为 $\pmb { \mathsf { A } } _{ \mathrm { Cl } }$ 、 $\pmb { \mathsf { A } } _{ \mathrm { Br } }$ 、 AI)

## 参考答案

第5题（17分，8%）

5-1 由题意，B⁻中必然含有 C、B、I 元素，还可能含有 H 元素
从最简单情况开始考虑，考虑碳硼烷骨架保持不变，即 B⁻中仍含有 11 个 B 由 B 的质量分数为 13.24%，B⁻的摩尔质量为 $898.1 \, g \cdot mol^{-1}$ （2 分）
除去 1 个 C，11 个 B，剩余 $767.2 \, g \cdot mol^{-1}$ ，对应 6 个 I、6 个 H

因此，B的化学式为 $\mathrm{CB_{11}H_6I_6^-}$ （2分） $\mathbf{A}\mathrm{H}[\mathrm{CB}_{11}\mathrm{H}_6\mathrm{I}_6]$ （1分） $\mathbf{C}\mathrm{i - Pr}_3\mathrm{Si}[\mathrm{CB}_{11}\mathrm{H}_6\mathrm{I}_6]$ （1分）
