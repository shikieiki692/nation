# 题-CM-68-04-4-1反应在两容器均为下达到

## 题目

### 第 4 题

4-1 反应在两容器均为 $T _{ 1 } = 298.2 \ : \mathrm { K }$ 下达到平衡， 玻璃管中的液滴未发生移动， 已知反应$2 \mathrm { NO } _{ 2 } ( \mathrm { g } ) = \mathrm { N } _{ 2 } \mathrm { O } _{ 4 } ( \mathrm { g } )$ 的 $\Delta _{ \mathrm { r } } H _{ \mathrm { m } } \Theta = - 55.3 \mathrm { kJ } { \cdot } \mathrm { mol } ^{ - 1 }$ ， $\Delta S _{ \mathrm { m } } { \Theta } = - \ 175.8 \ \mathrm { J } { \cdot } \mathrm { mol } ^{ - 1 } { \cdot } \mathrm { K } ^{ - 1 }$ ， 请计算A 中 $\mathrm { NO } _{ 2 }$ 和 $\mathrm { N } _{ 2 } \mathrm { O } _{ 4 }$ 的分压。

4-2 向B 中加入合成氨反应催化剂， 并将两容器均升高温度至 $T _{ 2 }$ ， 此时A 中的 $\mathrm { N } _{ 2 } \mathrm { O } _{ 4 }$ 几乎完全解离，平衡后玻璃管中的液滴仍在原来的位置， 已知反应 $2 \mathrm { NH } _{ 3 } ( \mathbf { g } ) = \mathrm { N } _{ 2 } ( \mathbf { g } ) + 3 \mathrm { H } _{ 2 } ( \mathbf { g } )$ 的$\Delta _{ \mathrm { r } } H _{ \mathrm { m } }  { } ^{ \ominus } = 91.8 \mathrm { kJ } { \cdot } \mathrm { mol } ^{ - 1 }$ ， $\Delta S _{ \mathrm { m } } { } ^{ \ominus } = 198.1 \ \mathrm { J } { \cdot } \mathrm { mol } ^{ - 1 } { \cdot } \mathrm { K } ^{ - 1 }$ ； 计算温度 $T _{ 2 }$ 。

## 参考答案

第4题（12分）

![](images/c3d38f1e55f75720c13ec2e06ecbdd8e1ebd975bbe61fd9f6db7844c62fc8af1.jpg)

如图所示，有两个容积均为 1.00 L 的刚性容器，中间用一细玻璃管相连，玻璃管内有惰性的红色液滴。向 A 容器中通入一定量的 $NO_{2}$ ，向 B 容器中通入 $4.00 \times 10^{-2} \, mol$ 的 $NH_{3}$ 。设化学反应的焓变和熵变不随温度变化。(提示：对于纯气体参与的反应，化学反应的标准摩尔吉布斯自由能变与平衡常数的关系可表示为 $\Delta_{r} G_{m}^{\ominus} = -RT \ln K_{p}^{\ominus}$ )

4-2 由于平衡后液滴位置不变，故两侧的分压相同，气体的摩尔浓度也相同：
 $c_{B}=c_{A}=\left[p\left(\mathrm{NO}_{2}\right)+2p\left(\mathrm{N}_{2}\mathrm{O}_{4}\right)\right]/RT=6.30\times10^{-2}\mathrm{mol/L}$  （1分）
 $c_{0}(NH_{3})=4.00\times10^{-2}\mathrm{mol/L}$ ，设转化浓度为x，则：
 $4.00\times10^{-2}\mathrm{mol}-2x+x+3x=6.30\times10^{-2}\mathrm{mol/L}$
解得： $x=1.15\times10^{-2}\mathrm{mol/L}$ （1分）
故右侧容器中各气体的平衡浓度为：
 $c(NH_{3})=1.70\times10^{-2}\mathrm{mol/L}$ ;  $c(N_{2})=5.525\times10^{-3}\mathrm{mol/L}$ ;  $c(H_{2})=1.725\times10^{-2}\mathrm{mol/L}$ （1分）
则由  $\Delta_{r}G_{m}^{\ominus}=\Delta_{r}H_{m}^{\ominus}-T\Delta S_{m}^{\ominus}=-RT\ln K_{p}^{\ominus}$  得：
91.8 kJ·mol $^{-1}$  - 198.1 J·mol $^{-1}$ ·K $^{-1}$  × T $_{2}$  = -8.314 J/(mol·K) × T $_{2}$  × ln $\frac{[c(N_{2})/RT_{2}][c(H_{2})/RT_{2}]^{3}}{[c(NH_{3})/RT_{2}]^{2}}$ （2分）
解得：T $_{2}$  = 463 K（1分）
使用其他方法得到同样结果也可得分。
