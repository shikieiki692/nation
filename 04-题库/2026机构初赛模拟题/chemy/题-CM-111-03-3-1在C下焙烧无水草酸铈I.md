# 题-CM-111-03-3-1在C下焙烧无水草酸铈I

## 题目

### 第 3 题（11 分）

3-1 在 $600^{\circ}$ C 下焙烧无水草酸铈(III)，放出摩尔数不相等的两种气体；残余固体产物是一种简单整比氧化物。

3-2 向沸腾的硫单质中通入 $CO_{2}$ ，生成两种极性三原子分子。

3-3 $\mathrm{N}_2\mathrm{O}$ 与钠的液氨溶液作用，发生两步反应：先生成 $\mathrm{NaNH_2}$ ， $\mathrm{NaNH_2}$ 再与 $\mathrm{N}_2\mathrm{O}$ 缩合。总反应中 $\mathrm{N}_2\mathrm{O}$ 与 Na 计量比为 3:4。钠的液氨溶液用 Na 和 $\mathrm{NH_3}$ 表示，分别写出这两步反应的方程式。

3-4 以氯酸水溶液处理银粉，并过滤掉生成的固体，可制得氯酸银的水溶液。

3-5 $AgNO_{2}$ 饱和水溶液缓慢分解，产生无色气体。

## 参考答案

<table><tr><td>3-1  $Ce_{2}(C_{2}O_{4})_{3} = 2CeO_{2} + 4CO + 2CO_{2}$ (2分)</td></tr><tr><td>3-2 向沸腾的硫单质中通入 $CO_{2}$ ,生成两种极性三原子分子。</td></tr><tr><td>3-2  $2CO_{2} + 3S = 2COS + SO_{2}$ (2分)硫单质写成 $S_{8}$ ,或COS写成CSO,均可得分;若 $SO_{2}$ 写成 $S_{2}O$ ,不得分。</td></tr><tr><td>3-3  $N_{2}O$ 与钠的液氨溶液作用,发生两步反应:先生成 $NaNH_{2}$ , $NaNH_{2}$ 再与 $N_{2}O$ 缩合。总反应中 $N_{2}O$ 与Na计量比为3:4。钠的液氨溶液用Na和 $NH_{3}$ 表示,分别写出这两步反应的方程式。</td></tr><tr><td>3-3  $N_{2}O + 2Na + NH_{3} = N_{2} + NaOH + NaNH_{2}$ (1.5分) $2NaNH_{2} + N_{2}O = NaN_{3} + NaOH + NH_{3}$ (1.5分)</td></tr><tr><td>3-4 以氯酸水溶液处理银粉,并过滤掉生成的固体,可制得氯酸银的水溶液。</td></tr><tr><td>3-4  $6HClO_{3} + 6Ag = 5AgClO_{3} + AgCl + 3H_{2}O$ (2分)</td></tr><tr><td>3-5  $AgNO_{2}$ 饱和水溶液缓慢分解,产生无色气体。</td></tr><tr><td>3-5  $2AgNO_{2} = Ag + AgNO_{3} + NO$ (2分)</td></tr></table>
