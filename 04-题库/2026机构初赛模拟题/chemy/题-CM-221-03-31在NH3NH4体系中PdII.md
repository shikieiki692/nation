# 题-CM-221-03-31在NH3NH4体系中PdII

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-11-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（11 分）

**3-1** 在 NH<sub>3</sub>-NH<sub>4</sub><sup>+</sup>体系中，Pd(II)主要是以四氨合物的形体存在。若向该体系中通入乙烯，则得到 2-甲基吡啶等产物并有黑色固体析出(反应 1)。若体系中还有 Cu(II)存在，则该黑色固体又可被溶解，还原产物中 Cu 取 sp 杂化方式(反应 2)。若被空气氧化，则 Cu(I)又转化为Cu(II)(反应 3)。写出反应 1~反应 3 的离子反应方程式和总反应的方程式。

**3-2** 在不同的 pH 下，硫脲的氧化产物不尽相同：在酸性介质中，碘水与硫脲定量反应，生成 1 : 2 型盐(反应 4)；但若体系为碱性，则碘水与硫脲的反应产物为尿素以及硫酸根等(反应

5)。写出反应 4、反应 5 两反应的离子反应方程式。

**3-3** 在过氧化氢存在下，硫酸钴溶液与含大量草酸钾的溶液反应，生成含有 2 个羟桥的六配位双核配离子并以三水合钾盐的形式析出(反应 6)；若将该钾盐投入稀硫酸中，则其迅速分解并放出气体(反应 7)。写出反应 6 和反应 7 的化学反应方程式。

## 参考答案

**3-1** 3CH<sub>2</sub>=CH<sub>2</sub> + 4Pd(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> = C<sub>5</sub>H<sub>4</sub>(CH<sub>3</sub>)N + 4Pd + 8NH<sub>4</sub><sup>+</sup> +7NH<sub>3</sub>（1 分）

Pd + 2Cu(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> = Pd(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> + 2Cu(NH<sub>3</sub>)<sub>2</sub><sup>+</sup>（1 分）

4Cu(NH<sub>3</sub>)<sub>2</sub><sup>+</sup> + O<sub>2</sub> + 4NH<sub>4</sub><sup>+</sup> + 4NH<sub>3</sub> = 4Cu(NH<sub>3</sub>)<sub>4</sub><sup>2+</sup> + 2H<sub>2</sub>O（1 分）

总反应：3CH<sub>2</sub>=CH<sub>2</sub> + NH<sub>3</sub> + 2O<sub>2</sub> = C<sub>5</sub>H<sub>4</sub>(CH<sub>3</sub>)N + 4H<sub>2</sub>O（1 分）

只要反应式中写出了 H<sup>+</sup>或 OH<sup>-</sup>，就不得分。

**3-2** 2(H<sub>2</sub>N)<sub>2</sub>CS + I<sub>2</sub> = [(H<sub>2</sub>N)<sub>2</sub>CSSC(NH<sub>2</sub>)<sub>2</sub>]<sup>2+</sup> + 2I<sup>-</sup>（1.5 分）

(H<sub>2</sub>N)<sub>2</sub>CS + 4I<sub>2</sub> + 10OH<sup>-</sup> = (H<sub>2</sub>N)<sub>2</sub>CO + SO<sub>4</sub><sup>2-</sup> + 5H<sub>2</sub>O + 8I<sup>-</sup>（1.5 分）

**3-3** 2CoSO<sub>4</sub> + H<sub>2</sub>O<sub>2</sub> + 4K<sub>2</sub>C<sub>2</sub>O<sub>4</sub> + 3H<sub>2</sub>O = K<sub>4</sub>[(C<sub>2</sub>O<sub>4</sub>)<sub>2</sub>Co(OH)<sub>2</sub>Co(C<sub>2</sub>O<sub>4</sub>)<sub>2</sub>]·3H<sub>2</sub>O + 2K<sub>2</sub>SO<sub>4</sub>（2 分）

K<sub>4</sub>[(C<sub>2</sub>O<sub>4</sub>)<sub>2</sub>Co(OH)<sub>2</sub>Co(C<sub>2</sub>O<sub>4</sub>)<sub>2</sub>]·3H<sub>2</sub>O + 4H<sub>2</sub>SO<sub>4</sub> = 2K<sub>2</sub>SO<sub>4</sub> + 2CoSO<sub>4</sub> + 3H<sub>2</sub>C<sub>2</sub>O<sub>4</sub> + 2CO<sub>2</sub> + 5H<sub>2</sub>O（2

分）
