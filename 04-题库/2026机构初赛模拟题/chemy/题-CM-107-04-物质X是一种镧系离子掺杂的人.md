# 题-CM-107-04-物质X是一种镧系离子掺杂的人

## 题目

### 第 4 题（13 分）

物质 X 是一种镧系离子掺杂的人工氧化物矿石晶体，也是应用最早激光器必需晶体之一。在需要高功率、高能量激光的场合，X 的晶体至今仍是首选的激光工作物质。合成 X 的方法有很多，下列给出的是实验室合成 X 性质的简要步骤，试根据所给条件回答下列问题：

合成 X 需要的主要原料有 A、B、C 三种。其中 A、B 为同种简单无机酸的盐(含整数结晶水)；C 原为氧化物，但因久置少量吸水为非整比的水合氧化物；A、B、C 三者含有的金属离子氧化数相同。B 的水溶液滴加 NaOH 至过量，产生白色沉淀后溶解；而 A 经同样操作，白色沉淀不能溶解；C 在常温、自然光下呈现浅蓝紫色，且不溶于水。A、B、C 三者中氧的质量分数分别为 62.66%、76.77%、16.36%。

称取 22.6 g A 和 37.5 g B，溶解后得到混合溶液；称取 C 的粉末 0.184 g，在坩埚中加热至恒重，理论失重 2.81%。此时，一边向上述混合溶液中缓缓滴加氨水并不断搅拌，一边缓缓滴入上述热处理过的 C 粉末的悬浊液，直至 pH 值为 8～9，整个过程大约持续 60 min。完成此过程后，将所得体系离心，弃去上层清液并抽滤所得沉淀，得到沉淀 S。

将 S 置入 $80^{\circ}$ C 烘箱中 12 h 至无可检出水分残留，再经隔绝水分进行二次研磨、翻炒，用 $800^{\circ}$ C 高温炉灼烧 2 h。然后，将产物转移至铱金坩埚内，电加热至 $1900 \sim 2000^{\circ}$ C，投入小颗 X 晶体作为晶核，然后重复此电热-结晶流程一次，即可得到合格的产物 X，在自然光下呈现漂亮的浅紫红色。对 X 进行晶体结构分析，发现 X 晶胞属于 $O_{h}$ 群，每个晶胞中含有 8 个 X 分子式，且晶胞参数 a = 1.20 nm。

4-1 请根据计算，写出 A、B、C 的化学式。

4-2-1 X 可看作是 C 中的金属离子对一整比化合物进行了掺杂，写出未掺杂的 X 的化学式。

4-2-2 掺杂离子替换了原本哪种离子的位置？

4-2-3 假设金属离子没有损失，计算此次合成中掺杂原子的比例。

4-2-4 计算 X 的密度。

4-3 试回答为何电热-结晶前需要多次进行加热处理？

4-4 基于 X 的激光器可以产生单色性极好的 1064 nm 光。这样的波长位于光谱上何种区域？发射的一个光子携带有多少能量？

## 参考答案

第4题（13分）

4-1 考虑到掺杂的 C 含稀土，金属价态最可能为+3
考虑 A 和 B 的阴离子，考虑到阳离子为+3 价，且易溶于水而不水解，应为强酸酸根
又注意到 A、B 氧质量分数很高，应为含氧强酸酸根，常见为硝酸根
设分子式为 M(NO₃)₃·xH₂O, ω₀ = (x + 9)·16.00 / (186.03 + Mₘ + 18.02x)
分别代入 A、B 数据，枚举得 A 为 Y(NO₃)₃·6H₂O, B 为 Al(NO₃)₃·9H₂O（每个 1.5 分）
设 C 分子式为 N₂O₃·yH₂O
ω₀ = (y + 3)·16.00 / (48.00 + 2Mₙ + 18.02y) = 0.1636
ωH₂O = 18.02y / (48.00 + 2Mₙ + 18.02y) = 0.0281
解得 y = 0.54, Mₙ = 144, 为 Nd
故 C 为 Nd₂O₃·0.54H₂O（2 分）

4-2-1 Y₃Al₅O₁₂（1 分）

4-2-2 Nd³⁺替换了 Y³⁺（1 分）

4-2-3 投入 Y 0.0590 mol, Nd 1.06×10⁻³ mol
比例为 100% × 1.06×10⁻³ / 0.0600 = 1.77%（1 分）

4-2-4 计算 X 的密度。

4-2-4 化学式为 Nd₀.₀₅₃₁Y₂.₉₄₆₉Al₅O₁₂，式量 596.6（1 分）
ρ = ZM / VNA = 4.59 g·cm⁻³（1 分）

4-3 电加热熔化前，由于粉体较为细小，表面积较大，可能吸附杂质，加热可以使吸附的杂质脱吸附（1 分）

4-4 位于(近)红外区（1 分）
E = hv = hc / λ = 1.867×10⁻¹⁹ J（1 分）

4-5 该激光人眼不可见，但又处于红外光区能量最强的位置
