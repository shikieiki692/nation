# 题-CM-170-05-分4下图为二元合金LaxNi

## 题目

### 第 5 题 5 分， $4 \%$

分，4%）下图为二元合金LaxNiy 的

下图为二元合金 $\mathrm { La } _{ x } \mathrm { Ni } _{ y }$ 的晶体结构，大球为La 原子， 小球为Ni 原子。

![](images/a8353236f8897da339feb9dde786666c9f0ae773aded2d45aef982f04a8517bd.jpg)

5-1 写出该合金的化学式。
5-2 晶胞中 Ni – Ni 键长为 2.512 Å， 晶体密度 $\rho = 8.51 \mathrm { g } \cdot \mathrm { cm } ^{ - 3 }$ ， 求晶胞参数 $\scriptstyle { c }$ 。

## 参考答案

第5题（5分，4%）

![](images/1744e96eee599c6ecdbeb9704d7ad2f798e398c5df508351bcddf7658e7cd069.jpg)

![](images/5d93c66a521bcd4a71eb2edde679a1ed578077f5d2486c2a0e15abf820bb16ae.jpg)

5-1 该合金化学式为 $La_{2}Ni_{7}$ （2 分）

5-2 晶胞参数 $a = 2d(\text{Ni} - \text{Ni}) = 2 \times 251.2 \, \text{pm} = 502.4 \, \text{pm}$ （1 分）

$$
c = \frac {Z M}{\mathrm{N} _{\mathrm{A}} \rho a ^{2} \sin \gamma} = \frac {4 \times (138.9 \times 2 + 58.69 \times 7)}{6.022 \times 10^{23} \times 8.51 \times 10^{- 30} \times 502.4^{2} \times \sin 120^{\circ}} = 2.459 (\mathrm{nm}) (2 \text {分})
$$
