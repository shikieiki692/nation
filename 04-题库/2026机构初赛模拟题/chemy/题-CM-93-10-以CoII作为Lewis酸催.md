# 题-CM-93-10-以CoII作为Lewis酸催

## 题目

### 第 10 题（10 分）

以 Co(II)作为 Lewis 酸催化了呋喃-2-甲醛与过量化合物 A 的羟醛缩合反应。反应得到了多种产物：

$$
\text {   } \text {   } + \text {   A   } \xrightarrow [ 110^{\circ} \text { C,   2   h } ]{\text {   CoCl } _{2} \cdot 6 \text { H } _{2} \text { O   ,   CaCl } _{2}} \text {   B   } + \text {   C   } + \text {   D   }
$$

10-1 化合物 A 为二酮化合物，其化学式为 $C_{5}H_{8}O_{2}$ ， $pK_{a}=9$ 。画出 A 的结构简式。

10-2 画出 B \~ D 的结构简式。

10-3 化合物 B 在以下条件下被氢化还原，主产物 E 的化学式为 $C_{10}H_{22}$ 。画出 E 的结构简式。

$$
\mathrm{B} \xrightarrow [ 190^{\circ} \mathrm{C} , 12 \mathrm{h} ]{\mathrm{Pd/NbOPO} _{4} , 4 \mathrm{MPaH} _{2} , \text {环己烷}} \mathrm{E}
$$

10-4 将化合物 D 在与 10-3 相同的条件下被氢化还原，画出主产物 F 的结构简式。

10-5 在 10-4 的反应中还有两种化学式为 $C_{13}H_{26}$ 的副产物 G 和 H 生成，画出 G 和 H 的结构简式。
