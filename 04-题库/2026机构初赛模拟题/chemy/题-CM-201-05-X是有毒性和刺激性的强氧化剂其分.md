# 题-CM-201-05-X是有毒性和刺激性的强氧化剂其分

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-10-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（22 分，占 10%）

X 是有毒性和刺激性的强氧化剂，其分子中有 4 个原子。X 在常温常压下是气体，低于12°C 转变为液体。人们首次制备 X 是通过电解液态的 NaCl/HF 混合物得到的，X 在阳极生成(电极反应 1)。现在，人们多在气相下由单质直接在 200~300°C 反应制备 X。X 能与一些路易斯酸作用 X 与 BF<sub>3</sub>作用，唯一产物是一种 1:1 型盐(反应 2)。控制比例，将 X 与氨(反应 3)或联氨(反应 4)混合，反应放出大量的热而引起燃烧或爆炸；反应产物均为 3 种双原子分子(其中有 2 种是单质)。该混合物体系可用作火箭高能推进剂。X 与氟气在光照下反应，生成 A；A 也可由 CsCl 与氟气直接加热反应得到。以 A 和(或)X出发，可以得到多种多样结构的离子。例如，A 与 Cs<sub>2</sub>NiF<sub>6</sub>以及五氟化砷作用，得到 3 种产物(反应 5)；其中一种产物 Y 的阳离子为正八面体型阳离子；3 种产物的阴离子相同；Y在 110°C 以上又分解得回 A(反应 6)。再如，X 与 CsF 在 0°C 以下反应，产物是 1:1 型盐Z，Z 的式量为 429.3；Z 的阴离子(的理想模型)具有三次对称轴。。

**5-1** 写出 X、Y、Z 的化学式。

**5-2** 写出电极反应 1 的电极反应方程式以及反应 2~6 的化学反应方程式。

**5-3** 画出 X 分子以及盐 Z 的阴离子的结构。

## 参考答案

**5-1**（共 5 分）

X：ClF<sub>3</sub>（1 分） Y：[ClF<sub>6</sub>][AsF<sub>6</sub>]（2 分） Z：Cs[Cl<sub>3</sub>F<sub>10</sub>]（2 分）

**5-2**（共 12 分，各 2 分）

反应 1：Cl<sup>-</sup> + 3HF – 4e<sup>-</sup> → ClF<sub>3</sub> + 3H<sup>+</sup>（2 分）

反应 2：ClF<sub>3</sub> + BF<sub>3</sub> → [ClF<sub>2</sub>][BF<sub>4</sub>]（2 分）

反应 3：2NH<sub>3</sub> + 2ClF<sub>3</sub> → N<sub>2</sub> + 6HF + Cl<sub>2</sub>（2 分）

反应 4：3N<sub>2</sub>H<sub>4</sub> + 4ClF<sub>3</sub> → 3N<sub>2</sub> + 12HF + 2Cl<sub>2</sub>（2 分）

反应 5：Cs<sub>2</sub>NiF<sub>6</sub> + 5AsF<sub>5</sub> + ClF<sub>5</sub> → 2CsAsF<sub>6</sub> + [ClF<sub>6</sub>][AsF<sub>6</sub>] + Ni[AsF<sub>6</sub>]<sub>2</sub>（2 分）

反应 6：[ClF<sub>6</sub>][AsF<sub>6</sub>] → ClF<sub>5</sub> + AsF<sub>5</sub> + F<sub>2</sub>（2 分）
