# 题-CM-147-06-一类金属配合物可起到类似酸的

## 题目

### 第 6 题（15 分）

一类金属配合物可起到类似“酸”的作用，用于氯仿中一些有机胺的性质测定及含量测定。6-1在氯仿中， $cis-Pt(Me_{2}SO)_{2}Cl_{2}$ 与 $H_{2}L$ 按计量比1:2反应可得到A(化学式为 $Pt(H_{2}L)_{2}Cl_{2}$ ); $cis-Pt(Me_{2}SO)_{2}Cl_{2}$ 与 $H_{2}L$ 按计量比1:1在 $NaHCO_{3}$ 存在的条件下反应则先得到中间产物X，X与另一当量 $H_{2}L$ 反应可得到B。A与过量 $NaHCO_{3}$ 反应可得到C，1mol C中含有2mol 氢键。C也可由B进一步与 $NaHCO_{3}$ 反应得到。写出B的化学式(有机配体可简写)，并画出C的结构。

![](images/cf4741fccd008a6a6d2a2f3080d0758083b67bb8946f7018e00e5f9a88e5738e.jpg)

6-2 通过金属配合物实现“酸”碱滴定的原理是：在氯仿中，B 可与碱发生反应，在向 B 的氯仿溶液中逐渐加入碱的过程中，体系吸光度有一定的变化规律，据此可得出碱的浓度。向 $2000 \mu L$ 待测十二烷基伯胺(可简写为 $RNH_{2}$ ) 的氯仿溶液中逐渐滴加浓度为 $3.00 \times 10^{-4} mol \cdot L^{-1}(c_{0})$ 的 B 溶液，测定体系的吸光度(波长：515 nm)。

6-2-1 写出滴定反应方程式(含铂物种可用 6-1 中的字母简化表示)，体系中的吸光物种仅为含 Pt 配合物，采取合理近似，推导以下两种情况时体系吸光度 A 的表达式。(表达式中可包含 B 的初始浓度 $c_{0}$ 、 $RNH_{2}$ 的初始浓度 $c(\mathrm{RNH}_{2})$ 、加入 B 的体积 V、体系中各吸光物种的摩尔吸光系数及光程 l，其余需代入具体数值)

情况 1: 加入 B 的量远小于碱的量; 情况 2: 加入 B 的量远大于碱的量。

6-2-2 加入不同体积 B 时体系对 515 nm 波长的光的吸光度见下表:

选取合适的数据、计算待测十二烷基伯胺的浓度。

6-3 选出下列选项中正确的说法:

(a) B 相较于 C 的摩尔吸光系数更大;

(b) 被滴定试剂为吡啶时滴定过程中体系吸光度的突变较被滴定剂为 1-己胺时更明显；

(c) 上述过程不能在醇等极性较大的质子溶剂中进行。

## 6-2-1 滴定反应方程式: $\mathbf{B} + \mathrm{RNH}_{2} = \mathbf{C} + \mathrm{RNH}_{3} \mathrm{Cl}$ (1 分)

吸光物质为 B 和 C，假设摩尔吸光系数分别为 $\varepsilon_{B}$ 和 $\varepsilon_{C}$ ，则有：
体系的吸光度 $A = \varepsilon_{B}[B]l + \varepsilon_{C}[C]l$ $c = c_{0}V_{\mathrm{add}}/(V_{\mathrm{add}} + 2000\mu\mathrm{L}) = [B] + [C]$ 对于情况1，可忽略 B，故 c = [C] $A = \varepsilon_{C}[C]l = \varepsilon_{C}c_{0}V_{\mathrm{add}}l/(V_{\mathrm{add}} + 2000\mu\mathrm{L})$ （1分）
对于情况2，可认为所有 $RNH_{2}$ 反应完全，故 $c = [C] + [B]_{add}$ （1分） $A = \varepsilon_{B}[B]l + \varepsilon_{C}[C]l$ 其中 $[B]=c_{0}V_{\mathrm{add}}/(V_{\mathrm{add}}+2000\mu\mathrm{L})-c(\mathrm{RNH}_{2})\times2000\mu\mathrm{L}/(V_{\mathrm{add}}+2000\mu\mathrm{L})$ $[C]=c(RNH_{2})\times2000\mu L/(V_{\mathrm{add}}+2000\mu L)$ （1分） $A=\varepsilon_{C}c(RNH_{2})\times2000\mu Ll/(V_{\mathrm{add}}+2000\mu L)+\varepsilon_{B}l[c_{0}V_{\mathrm{add}}/(V_{\mathrm{add}}+2000\mu L)-c(RNH_{2})\times2000\mu L/(V_{\mathrm{add}}+2000\mu L)]$ 化简得 $A=[\varepsilon_{B}c_{0}-(\varepsilon_{C}-\varepsilon_{B})c(RNH_{2})]V_{\mathrm{add}}l/(V_{\mathrm{add}}+2000\mu L)+(\varepsilon_{C}-\varepsilon_{B})c(RNH_{2})l$ （1分）

6-2-2 对数据进行整理:

首先对前三组数据进行回归，求得 $A = 0.9716 V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) + 3.050 \times 10^{-3}$ （1 分）
若对前四组数据进行回归，求得 $A = 0.9802 V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) + 2.519 \times 10^{-3}$ ，也得分再对后三组数据进行回归，求得 $A = 3.795 V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) - 0.6037$ （1 分）
若对后四组数据进行回归，求得 $A = 3.791 V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) - 0.6024$ ，也得分
若对后五组数据进行回归，求得 $A = 3.773 V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) - 0.5962$ ，也得分
联立可得计量点时 $V_{add} = 547.4 \mu L$ （1 分，范围在 $544.2 \sim 549.0 \mu L$ 均得分）

因此十二烷基伯胺的浓度为 $c = c_{0} V_{\mathrm{add}} / (V_{\mathrm{add}} + 2000 \mu \mathrm{L}) = 8.211 \times 10^{-5} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ （1 分，与之接近也得分）
