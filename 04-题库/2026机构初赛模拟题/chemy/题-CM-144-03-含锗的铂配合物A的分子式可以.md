# 题-CM-144-03-含锗的铂配合物A的分子式可以

## 题目

### 第 3 题（10 分）

含锗的铂配合物 A 的分子式可以表示为 $\mathrm{Pt(HGePh_{2})_{2}(Me_{2}PCH_{2}CH_{2}PMe_{2})}$ 。其中 Pt 为四配位，含有两根 Pt-Ge 键。A 可以与等当量的 $H_{2}GePh_{2}$ 反应得到化合物 B，同时生成两当量的氢气；B 可以继续与等当量的 $H_{2}GePh_{2}$ 反应得到化合物 C。研究表明，B 到 C 的反应历程如下： $H_{2}GePh_{2}$ 与 B 发生形式上的 Ge-Ge 键插入反应得到 D，该过程断开了一根 Ge-Ge 键的同时形成了一根新的 Ge-Ge 键；之后 D 发生分子内的氢迁移得到 E，该过程有一根 Pt-H 键和一根新的 $\pi$ 键的形成；E 接着发生分子内的重排得到 F，F 放出一分子氢气后转化为 C。A-F 均只含有一个 Pt 原子，且 Pt 均为四配位；D 中四个 Ge 原子化学环境均不同。

3-1 画出 A-F 的结构图。

3-2 以 C 为原料，可以实现 X 的制备。C 与过量的 PhGeH₃ 反应，得到含有四个 Ge 原子的分子 X，同时生成与 A 结构类似的化合物 G，G 的分子量比 A 小 152.2。画出 X 和 G 的结构图。
