# 题-CM-62-09-螺旋桨烷Propellane

## 题目

### 第 9 题（10 分）

螺旋桨烷(Propellanes)是一种独特的烃类化合物，由于特殊的结构如螺旋桨一般具有一根三重轴所以将其命名为螺旋桨烷，该类化合物在材料化学、天然产物和药物化学中有着较为广泛的应用。

9-1 化合物 A 是最小的螺旋桨烷， 分子式为 ${ \mathrm { C } } { \bar { \mathrm { sH } } } _{ 6 }$ ， 其中所有氢原子的化学环境相同。A 具有较高的反应活性，在中性条件下可通过自由基历程进行以下反应。 画出化合物 A 的结构简式。A 的燃烧热相较于A 的其他同分异构体而言更大， 解释原因。

9-2 以下是化合物D 的合成路线(提示： ex 表示过量)：

(ex), hv P4O10 1) Br2 1) PhLi (ex) H3PO4 B 2) DMSO, NaBr, Na2HPO4 / KH PO4 2) H3PO4

9-2-1 化合物D 的 $\mathrm { ^ 1 H }$ -NMR 谱为： δ 7.14 (12H), 7.05 (12H)。 画出 B、 C、 D 的结构简式。9-2-2 化合物 B 经一步反应可得到化学式为 $\mathrm { C } _{ 23 } \mathrm { H } _{ 18 }$ 的螺旋桨烷 E。 画出 E 的结构简式， 给出反应所需条件a。
