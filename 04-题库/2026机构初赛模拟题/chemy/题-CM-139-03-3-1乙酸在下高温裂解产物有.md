# 题-CM-139-03-3-1乙酸在下高温裂解产物有

## 题目

### 第 3 题（10 分）

3-1 乙酸在 $916\mathrm{K}$ 下高温裂解，产物有乙烯酮以及3种二元化合物。

3-1-1 这些产物是通过 2 个平行进行的反应生成的，分别写出这 2 个平行反应的方程式。

3-1-2 在 916 K 下，以上两反应都是一级反应；生成乙烯酮的反应的半衰期为 0.149 s，另一反应的半衰期为 0.185 s。计算(1)反应掉 99.0% 的醋酸所需要消耗的时间；(2)生成的乙烯酮与反应掉的乙酸的摩尔比。

3-1-3 若以上两个一级反应的速率常数随温度的关系均满足下式:

$$
\ln k = \frac {E _{\mathrm{a}}}{R T} + C
$$

回答醋酸的消耗速率常数与温度的关系是否仍满足上式？简述理由。

3-2 在乙酸的蒸气中存在由 2 根氢键形成的二聚体，每根氢键的键能为 32.0 kJ/mol。在 318 K 下，乙酸二聚的平衡常数 $K_{p}^{\ominus}=37.3$ 。室温(298 K)下，乙酸的饱和蒸汽压为 16.8 kPa。计算其中有多少分压是由二聚体导致的。

## 参考答案

3-1-1  $CH_{3}COOH \rightarrow CH_{2}=C=O+H_{2}O$  （1分）
 $CH_{3}COOH \rightarrow CH_{4} + CO_{2}$  （1分）

3-1-2 总反应速率常数  $k = k_{1} + k_{2} = \ln 2 / k_{1} + \ln 2 / t_{2} = 8.397 \, s^{-1}$  （0.5 分）
有  $\ln(100/1)=kt$  （0.5 分） 得：t=0.548s（0.5分）
由于二平行反应的速率之比恒为定值  $k_{1}/k_{2}$  （0.5 分），故产物的摩尔比也恒为定值。故：
 $x = n_{1} / (n_{1} + n_{2}) = k_{1} / (k_{1} + k_{2}) = t_{2} / (t_{2} + t_{1})$  （0.5 分）
= 55.4%（0.5 分）

$$
\ln k = - \frac {E _{\mathrm{a}}}{R T} + C
$$

3-1-3 不一定满足（1 分）
根据  $\ln k_{1} = -E_{a1} / RT + C_{1}$ ， $\ln k_{2} = -E_{a2} / RT + C_{2}$ ；二式相加得  $\ln(k_{1}k_{2}) = -(E_{a1} + E_{a2}) / RT + (C_{1} + C_{2})$
由此可见，与 T 的倒数呈线性关系的是  $\ln(k_{1}k_{2})$ ；而  $\ln(k)$  实际上是  $\ln(k_{1}+k_{2})$ ，它与  $\ln(k_{1}k_{2})$  不一定是直线关系，因此也不与 T 的倒数呈线性关系。（1 分）


3-2 二聚反应的焓变为： $\Delta_{r}H_{m} = -32.0\ kJ/mol \times 2 = -64.0\ kJ/mol$

根据  $\ln(K_{2}/K_{1}) = (\Delta_{r}H_{m}/R)(1/T_{1} - 1/T_{2})$

求得在 298 K 下： $K_{p}^{\circ}(298\mathrm{K}) = 194$ （1 分）

联立：

 $p(\mathrm{CH}_{3}\mathrm{COOH}) + p((\mathrm{CH}_{3}\mathrm{COOH})_{2}) = 16.8\ \mathrm{kPa}$ （0.5 分）

 $100\ \mathrm{kPa} \times p((\mathrm{CH}_{3}\mathrm{COOH})_{2}) / p^{2}(\mathrm{CH}_{3}\mathrm{COOH}) = 194$ （0.5 分）

解得： $p((\mathrm{CH}_{3}\mathrm{COOH})_{2}) = 14.1\ \mathrm{kPa}$ （1 分）
