# 题-CM-219-01-11HgC2与盐酸反应有辛辣气味

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-9-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（9 分）

**1-1** HgC<sub>2</sub>与盐酸反应，有辛辣气味产生。

**1-2** 在乙醇和水的混合溶液中，硝酸银与碘仿加热反应，生成一种无色有毒气体。

**1-3** NH<sub>4</sub>O<sub>3</sub>不稳定易分解，生成一种常见的铵盐。

**1-4** 液氨中，Se 单质可以和 AgCN 按 11 : 6 发生反应，将 Ag<sup>+</sup>完全沉淀。该反应只生成 3 种含 Se 物质，其中一种产物中存在 S<sub>4</sub>轴。

## 参考答案

**1-1** HgC<sub>2</sub> + 2HCl + H<sub>2</sub>O = HgCl<sub>2</sub> + CH<sub>3</sub>CHO（3 分）

**1-2** 3AgNO<sub>3</sub> + CHI<sub>3</sub> + H<sub>2</sub>O = 3AgI + 3HNO<sub>3</sub> + CO（2 分）

**1-3** 4NH<sub>4</sub>O<sub>3</sub> = 2NH<sub>4</sub>NO<sub>3</sub> + 4H<sub>2</sub>O + O<sub>2</sub>（2 分）

**1-4** 22Se + 12AgCN + 16NH<sub>3</sub> = 6Ag<sub>2</sub>Se + Se<sub>4</sub>N<sub>4</sub> + 12NH<sub>4</sub>SeCN（2 分）
