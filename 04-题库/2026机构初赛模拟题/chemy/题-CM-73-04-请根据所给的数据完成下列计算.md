# 题-CM-73-04-请根据所给的数据完成下列计算

## 题目

### 第 4 题（13 分）

请根据所给的数据完成下列计算：

4-1 考虑水的电离和 $\mathrm { CrO } _{ 4 } { } ^{ 2 }$ -的水解， 请计算在纯水中 ${ \mathrm { Pb } } { \mathrm { Cr } } { \mathrm { O } } _{ 4 }$ 的溶解度。
4-2 请计算在 $0.500 \mathrm { mol / L }$ 的醋酸中 $\mathrm { PbCrO _{ 4 } }$ 的溶解度。
4-3 请计算使 $\mathrm { PbCrO } _{ 4 }$ 的溶解度达到 $5.00 \times 10^{ - 5 } \mathrm { mol / L }$ 所需的 HAc 的浓度。
有关数据： $\mathrm { p } K _{ \mathrm { a } } ( \mathrm { HAc } ) = 4.74$ ， $\mathrm { p } K _{ \mathrm { a } } ( \mathrm { HCrO } _{ 4 } ) = 6.50$ ， $\log \beta ( \mathrm { PbAc ^{ + } } ) = 2.68$ ， $\log \beta ( \mathrm { PbAc } _{ 2 } ) = 4.08$ ，$K _{ \mathrm { sp } } ( \mathrm { PbCl } _{ 2 } ) = 1.61 \times 10^{ - 5 }$ ， $K _{ \mathrm { sp } } ( \mathrm { PbCrO 4 } ) = 2.80 \times 10^{ - 13 }$ ， 在本题中不考虑铬酸根的二聚。

## 参考答案

第4题（13分）

4-1 由题意，设 $\left[\mathrm{Pb}^{2+}\right] = x\ \mathrm{mol/L}$，$\left[\mathrm{H}^{+}\right] = y\ \mathrm{mol/L}$
列电荷守恒式得 $2\left[\mathrm{Pb}^{2+}\right] + \left[\mathrm{H}^{+}\right] = \left[\mathrm{OH}^{-}\right] + \left[\mathrm{HCrO}_{4}^{-}\right] + 2\left[\mathrm{CrO}_{4}^{2-}\right]$（1分）
在该体系中 $\mathrm{H}_{2}\mathrm{CrO}_{4}$ 浓度可近似忽略不计因此列物料守恒式得 $\left[\mathrm{Pb}^{2+}\right] = \left[\mathrm{HCrO}_{4}^{-}\right] + \left[\mathrm{CrO}_{4}^{2-}\right]$（1分）
列方程得：$x = \frac{2.80 \times 10^{-13}}{x} \times (1 + \frac{y}{10^{-6.50}})$（1分）$2x + y = \frac{10^{-14}}{y} + \frac{2.80 \times 10^{-13}}{x} \times (2 + \frac{y}{10^{-6.50}})$解得 $\left\{\begin{aligned}x &amp;= 5.79 \times 10^{-7}\\ y &amp;= 6.29 \times 10^{-8}\end{aligned}\right.$（1分）

4-2 0.5 mol/L HAc 中 $\left[\mathrm{H}^{+}\right] = \left[\mathrm{Ac}^{-}\right] = 2.94 \times 10^{-3}$ (1 分)

$\mathrm{PbCrO_4 + 2HAc \rightarrow Pb(Ac)_2 + HCrO_4^- + H^+}$ $K = 3.21 \times 10^{-12}$

由于解离程度过小，可以假设 $[\mathrm{H}^{+}]$ 和 $[\mathrm{HAc}]$ 没有发生变化（1 分）

列电荷守恒式得：

$2[\mathrm{Pb}^{2+}] + [\mathrm{H}^{+}] + [\mathrm{PbAc}^{+}] = [\mathrm{OH}^{-}] + [\mathrm{Ac}^{-}] + [\mathrm{HCrO}_4^{-}] + 2[\mathrm{CrO}_4^{2-}]$ (1 分)

解得 $x = 2.76 \times 10^{-5}$

则 $[\mathrm{Pb}^{2+}] = 2.76 \times 10^{-5} \mathrm{~mol/L}, [\mathrm{PbAc}^{+}] = 3.88 \times 10^{-5} \mathrm{~mol/L}, [\mathrm{PbAc}_2] = 2.87 \times 10^{-6} \mathrm{~mol/L}$ (1 分)

因此溶解度 $s = [\mathrm{Pb}^{2+}] + [\mathrm{PbAc}^{+}] + [\mathrm{PbAc}_2] = 8.24 \times 10^{-5} \mathrm{~mol/L}$ (1 分)

本题完全可以采取与 4-3 相同的方法进行计算，所得到的结果也是正确的。


4-3 由上问数据可知，在该条件下，乙酸根的消耗可以忽略不计（1分）
由题意列关系式得 $\left[HCrO_{4}^{-}\right]+\left[CrO_{4}^{-}\right]=5.00\times10^{-5}$ $\left[Pb^{2+}\right]+\left[PbAc^{+}\right]+\left[PbAc_{2}\right]=5.00\times10^{-5}$ （1分）
因此设 $\left[Pb^{2+}\right]=x\ mol/L,\left[H^{+}\right]=\left[Ac^{-}\right]=y\ mol/L$ ，根据题意列方程得
 $\left\{\begin{aligned}&amp;\frac{2.80\times10^{-13}}{x}\times(1+\frac{y}{10^{-6.5}})=5.00\times10^{-5}\\&amp;x\times(1+10^{2.68}y+10^{4.08}y^{2})=5.00\times10^{-5}\end{aligned}\right.$  (1分)
解得 $\left\{\begin{aligned}&amp;x=2.80\times10^{-5}\\ &amp;y=1.58\times10^{-3}\end{aligned}\right.$ （1分）
