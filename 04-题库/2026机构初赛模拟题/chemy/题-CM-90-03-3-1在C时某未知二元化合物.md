# 题-CM-90-03-3-1在C时某未知二元化合物

## 题目

### 第 3 题（11 分）

3-1 在 $0^{\circ}$ C 时，某未知二元化合物在水中的溶解度为 22.0 g / 100 mL，其饱和水溶液中含氧 81.8%。推出此未知二元化合物的化学式。

3-2 同周期相邻两种金属元素组成了一种合金。 $25^{\circ}$ C，101 kPa 下，将 1.200 g 该合金投入足量稀盐酸中，放出 1.404 L 气体，无固体残留。通过计算确定该合金的元素组成及质量分数。

3-3 金属 X 在自然界中唯一存在的核素为 ${}^{232}X$ 。 ${}^{232}X$ 经 m 次 $\alpha$ 衰变和 n 次 $\beta$ 衰变生成 ${}^{220}Rn$ ; ${}^{220}Rn$ 经 m 次 $\alpha$ 衰变和 n 次 $\beta$ 衰变生成 Pb。分别写出 ${}^{232}X$ 生成 ${}^{220}Rn$ 和 ${}^{220}Rn$ 生成 Pb 的核反应方程式(核素需示出核电荷数和质量数)。

3-4 2019 年诺贝尔化学奖授予了 John Goodenough 等人，以表彰他们在锂离子电池研发领域作出的贡献。以 $Li_{1-x}FePO_{4}$ 和 $Li_{x}C_{6}$ 为电极，以 $LiClO_{4}$ 的有机溶剂溶液为电解质，构成了锂离子电池。分别写出正极和负极放电反应的电极反应方程式。

## 参考答案

## 第3题（11分）

3-1 若二元化合物不含氧，则饱和水溶液中氧的质量分数应为：
 $\left[(100\times16.00/18.02)/(100+22.0)\right]=0.729$
因此该二元化合物为氧化物（1分）
设该氧化物为  $XO_{n}$ ，X 的原子量为 x，则：
 $\frac{(100+22)\times0.818-100\times16.00/18.02}{22.0}=\frac{x}{x+16.00n}$ （1分）
将 n=1,2,3……代入得，当 n=2 时，x=32，为 S
因此二元化合物的化学式为  $SO_{2}$ （1 分）

3-2 放出气体为  $H_{2}$ ，其摩尔数为：
 $n(\mathrm{H}_{2}) = pV / RT = 101 \, \mathrm{kPa} \times 1.404 \, \mathrm{L} / (8.314 \, \mathrm{J} \, \mathrm{mol}^{-1} \, \mathrm{K}^{-1} \times 298 \, \mathrm{K}) = 0.05724 \, \mathrm{mol}$ （1分）
对于反应  $M + xH^{+} = M^{x+} + x/2H_{2}$ ，有： $xn(M)/2 = n(H_{2})$
则： $M(M)/x = m/2n(H_{2}) = 1.200 \, \mathrm{g} / (2 \times 0.05724 \, \mathrm{mol}) = 10.48 \, \mathrm{g/mol}$
计算短周期所有金属的  $M(M)/x:$ $M(\mathrm{Li})/x = 6.941 \quad M(\mathrm{Be})/x = 4.506 \quad M(\mathrm{Na})/x = 22.99 \quad M(\mathrm{Mg})/x = 12.16 \quad M(\mathrm{Al})/x = 8.994$
第四周期以后的金属的  $M(M)/x$  均大于 10.48 g/mol，可以排除
因此两种金属为 Mg 和 Al（1 分）
联立：
 $m(\mathrm{Mg})/M(\mathrm{Mg}) + 3m(\mathrm{Al})/2M(\mathrm{Al}) = 0.05724 \, \mathrm{mol}$ $m(\mathrm{Mg}) + m(\mathrm{Al}) = 1.200 \, \mathrm{g}$
解得： $m(\mathrm{Mg}) = 0.655 \, \mathrm{g}; m(\mathrm{Al}) = 0.545 \, \mathrm{g}$
用质量分数表示为： $\omega(\mathrm{Mg}) = 54.6\%; \omega(\mathrm{Al}) = 45.4\%$ （2 分）

3-3  ${}^{232}_{90}Th \rightarrow {}^{220}_{86}Rn + 3_{2}^{4}He + 2_{-1}^{0}e$  (1分)
 ${}^{220}_{86}Rn \rightarrow {}^{208}_{82}Pb + 3_{2}^{4}He + 2_{-1}^{0}e$  (1分)
