$3As_{2}O_{3} + 2ClO_{3}^{-} + 9H_{2}O^{-} = 6H_{3}AsO_{4} + 2Cl^{-}$ （2分） $2H_{3}AsO_{4} + N_{2}H_{6}^{2+} = 2H_{3}AsO_{3} + N_{2} + 2H^{+} + 2H_{2}O$ （2分） $H_{3}AsO_{3} + 3H^{+} + 3Cl^{-} = AsCl_{3} + 2H_{2}O$ （1分） $AsCl_{3} + 2H_{2}O = H_{3}AsO_{3} + 3H^{+} + 3Cl^{-}$ （1分） $BrO_{3}^{-} + 3H_{3}AsO_{3} = 3H_{3}AsO_{4} + Br^{-}$ （2分）
