### 第 4 题 分子玻璃 （14 分， 占 $8 \%$

分子玻璃是一类分子量较大并具有一定的聚合物特性的小分子化合物；它们在室温下为玻璃态态。近期，科学家研发出了一种具有脱氢苯并[12]轮烯([12]DBA，结构式如下左图；答题时其结构可简化为下右图)衍生结构的分子玻璃， 具有独特的介电性能与荧光效应。

## 第4题（18分，占 $10\%$ ）非水体系的平衡计算

在纯非质子有机溶剂中，乙酸除了解离平衡外，还存在其他平衡，反应式如下表所示(记 $\mathrm{CH}_3\mathrm{COOH}$ 为HA)。通过NMR滴定、分光光度法和ITC等多种手段，测定得到了各个反应平衡常数：

<table><tr><td>反应</td><td>乙腈中的平衡常数</td></tr><tr><td> $A^{-} + H^{+} = HA$ </td><td> $\log K_{0} = 22.23$ </td></tr><tr><td> $2HA = (HA)_{2}$ </td><td> $\log K_{1} = 3.83$ </td></tr><tr><td> $HA + A^{-} = HA \cdot A^{-}$ </td><td> $\log K_{2} = 4.40$ </td></tr></table>

固定乙腈溶液中 $\mathrm{[TBA]^{+}A^{-}([TBA]^{+}}$ ：四正丁基铵）浓度 $c = 2.5\times 10^{-3}\mathrm{mol}\cdot \mathrm{L}^{-1}$ ，通过改变HA的浓度以得到不同溶液。为便于表达，记 $\mathrm{HA\cdot A^{-}}$ 为 $\mathrm{HA}_{2}^{-}$ ，记初始HA浓度与[TBA]A浓度之比为 $n$ （总有 $0 < n < 2$ )，记 $\% [\mathrm{X}]$ 表示与物种X相当的醋酸浓度占醋酸分析浓度的百分比，计算结果保留3位有效数字。

4-1 某溶液平衡后 $\% [\mathrm{HA}_{2}^{-}]$ 与 $\% [\mathrm{A}^{-}]$ 相等，推导 $n$ 的表达式并求出值。

4-1 即有 $2[HA_{2}^{-}]=[A^{-}]$

代入平衡有： $2K_{2}[HA][A^{-}] = [A^{-}]$ ，则 $[HA] = 1 / 2K_{2}$

CBE: $[H^{+}]+[TBA^{+}]=[A^{-}]+[HA_{2}^{-}]$

代入各个平衡，有： $[HA]/K_{0}[A^{-}]+c=1.5[A^{-}]$

解得 $[A^{-}]=2c/3$ （2分）

$$
c _{0} = [ \mathrm{HA} ] + [ \mathrm{A} ^{-} ] + 2 [ (\mathrm{HA}) _{2} ] + 2 [ \mathrm{HA} _{2} ^{-} ] = [ \mathrm{HA} ] + 2 [ \mathrm{A} ^{-} ] + 2 K _{1} [ \mathrm{HA} ] ^{2} = 4 c / 3 + (K _{1} + K _{2}) / 2 K _{2} ^{2}
c _{0} = c _{\mathrm{HA}} + c _{[ \mathrm{TBA} ] \mathrm{A}} = (n + 1) c
n = 1 / 3 + \left(K _{1} + K _{2}\right) / 2 K _{2} ^{2} c = 0.343 (3 \text {分})
$$

4-2 某溶液平衡后 $\%[(HA)_2]$ 和 $\%[HA]$ 相等，推导 $n$ 的表达式并求出值。

4-2 即有 $[\mathrm{HA}] = 2[(\mathrm{HA})_2]$

代入平衡有： $[\mathrm{HA}] = 2K_{1}[\mathrm{HA}]^{2}$ ，则 $[\mathrm{HA}] = 1 / 2K_{1}$

$$
\mathrm{CBE}: \left[ \mathrm{H} ^{+} \right] + \left[ \mathrm{TBA} ^{+} \right] = \left[ \mathrm{A} ^{-} \right] + \left[ \mathrm{HA} _{2} ^{-} \right]
$$

代入各个平衡，有： $[\mathrm{HA}] / K_0[\mathrm{A}^- ] + c = [\mathrm{A}^- ](1 + K_2 / 2K_1)$

解得 $[A^{-}]=2K_{1}c/(2K_{1}+K_{2})$ （2分）

$$
c _{0} = [ \mathrm{HA} ] + [ \mathrm{A} ^{-} ] + 2 [ (\mathrm{HA}) _{2} ] + 2 [ \mathrm{HA} _{2} ^{-} ] = 1 / K _{1} + 2 (K _{1} + K _{2}) c / (2 K _{1} + K _{2}) = (n + 1) c
n = 1 / c K _{1} + K _{2} / (2 K _{1} + K _{2}) = 0.709 \text {(3分)}
$$

4-3 某溶液平衡后\%[HA]和\%[A⁻]相等，计算 n 的值。

4-3 即有 $[\mathrm{HA}] = [\mathrm{A}^{-}]$

CBE: $[H^{+}]+[TBA^{+}]=[A^{-}]+[HA_{2}^{-}]$

代入各个平衡，有： $[\mathrm{HA}] / K_0[\mathrm{A}^- ] + c = [\mathrm{A}^- ] + K_2[\mathrm{A}^- ]^2$

解得 $[A^{-}]=2.96\times10^{-4}\ mol\cdot L^{-1}=[HA]$ （2分）

$$
c _{0} = [ \mathrm{HA} ] + [ \mathrm{A} ^{-} ] + 2 [ (\mathrm{HA}) _{2} ] + 2 [ \mathrm{HA} _{2} ^{-} ] = 2 [ \mathrm{A} ^{-} ] + 2 (K _{1} + K _{2}) [ \mathrm{A} ^{-} ] ^{2} = 6.19 \times 10^{- 3} \mathrm{mol} \cdot \mathrm{L} ^{- 1}
$$

$n=c_{0}/c-1=1.47$ (3分)

4-4 根据以上计算，指出 $0 < n < 2$ 的部分中所有 $[\mathrm{X}]$ 最大的物种以及此时 $n$ 的范围。

4-4 $0 < n \leq 0.373\% [A^{-}]$ 最大， $0.373 < n < 2\% [HA_{2}^{-}]$ 最大（3 分，指出临界值得 1 分，正确指出物种得 2 分）
