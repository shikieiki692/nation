# 题-CM-61-01-X-射线衍射表明抗磁性粉红色

## 题目

### 第 1 题（9 分）

X-射线衍射表明，抗磁性粉红色钾盐 $\mathrm { K } _{ 2 } \mathrm { Mo ( SO _{ 4 } ) } _{ 2 }$ 的阴离子为双核配离子，其中硫酸根离子为桥连配体，钼原子的核间距为 $211 \ \mathrm { pm }$ 。若将此复盐进行重结晶，则可制得化学式为$\mathrm { K _{ 3 } Mo _{ 2 } ( SO _{ 4 } ) _{ 4 } } { \cdot } 3.5 \mathrm { H _{ 2 } O }$ 的钾盐，该复盐的阴离子仍保持了 $\mathrm { K } _{ 2 } \mathrm { Mo ( SO _{ 4 } ) } _{ 2 }$ 阴离子的结构， 但整个阴离子的电荷数却有所不同。
1-1 画出 $\mathrm { K } _{ 2 } \mathrm { Mo ( SO _{ 4 } ) } _{ 2 }$ 中双核配离子的结构示意图。
1-2 为解释 $\mathrm { K } _{ 2 } \mathrm { Mo ( SO _{ 4 } ) } _{ 2 }$ 阴离子中钼原子间较小的核间距，人们认为， 钼原子之间形成了很强的化学键。请指出钼原子之间成键的种类和数目。
1-3 钾盐 $\mathrm { K _{ 3 } Mo _{ 2 } ( SO _{ 4 } ) _{ 4 } } { \cdot } 3.5 \mathrm { H _{ 2 } O }$ 的阴离子呈现顺磁性还是抗磁性？
1-4 与 $\mathrm { K } _{ 2 } \mathrm { Mo ( SO _{ 4 } ) } _{ 2 }$ 的阴离子相比， 钾盐 $\mathrm { K _{ 3 } Mo _{ 2 } ( SO _{ 4 } ) _{ 4 } } { \cdot } 3.5 \mathrm { H _{ 2 } O }$ 的阴离子中，钼原子的核间距更大还是更小？ 请解释原因。
