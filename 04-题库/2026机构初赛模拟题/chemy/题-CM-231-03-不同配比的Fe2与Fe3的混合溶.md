# 题-CM-231-03-不同配比的Fe2与Fe3的混合溶

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-5-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（15 分，占 8.0%）

不同配比的 Fe(+2)与 Fe(+3)的混合溶液在加入不同量的碱（如 NaOH）后会以不同的形态存

在。下图中横坐标(X)为 Fe(+3)的物质的量与总铁物质的量之比，纵坐标(R)表示加入碱的物

质的量（以 OH<sup>-</sup>记）与总铁物质的量之比，据图 1 可预测不同条件下铁的存在形态。

![](images/ff1af8e1315aaa177bfa7197d1182dae8b2e1c3e0ea20d10c64c4fe4722b3256.jpg)

图 1

**3-1** GR 为铁的碱式硫酸盐（不考虑结晶水），据图推测 A、B、C 及 GR 的化学式。注：B

点坐标为(2/3, 8/3)，GR 对应横坐标为 1/3。

**3-2** 图 2 为取不同 x、R 时体系 pH 的变化图。观察曲线可知，x ≤ 0.2 时在 E<sub>1</sub>、E<sub>2</sub>点间有一

平台，平台上有一转折点 E<sup>*</sup>（此时对应的 R 记作 R<sup>*</sup>）。分析表明：R<sup>*</sup> < R < 2 阶段 pH 变化

趋势与仅含 Fe(+2)（即 x = 0）的情况类似，说明此阶段主要生成氢氧化亚铁；R < R<sup>*</sup>阶段

对应于 GR 的生成。数据分析表明，R<sup>*</sup>与 x 之间大致满足线性关系，关系式为 R<sup>*</sup> = 7x，说

明 GR 的生成需要稍过量 OH<sup>-</sup>的存在。

![](images/d71619e3ba6d9a84eded56c3f4c9ec7990a76ddab26afc141fdd633477210de0.jpg)

图 2

写出 R<sup>*</sup> < R < 2 阶段发生的离子反应方程式。

**3-3** 3-2 中的结论可用于进一步分析 GR 的生成条件。若初始溶液中仅含 FeSO<sub>4</sub>和 NaOH，

二者反应后通空气，通过部分氧化可制得 GR。

**3-3-1** 上述过程可借助图 1 进行理解，若将空气氧化过程在图 1 中表示，则会得到一条 R

随 x 线性变化的直线，计算对应直线的斜率并据此说明仅借助空气氧化能否将 GR 完全转

化为 Fe<sub>3</sub>O<sub>4</sub>。

**3-3-2** 若初始溶液中 R = 5/3（从(0, 5/3)点处出发），氧化过程大致分为 3 个步骤：首先体系

中生成了 GR（反应 1）；继续通入空气，GR 被部分氧化为 FeOOH，该过程体系的 pH 几

乎不变（反应 2）；最后溶液中残留的铁物种部分转化为 FeOOH，溶液 pH 有所下降（反应

3）。写出反应 1 ~ 反应 3 发生的离子方程式。

## 参考答案

**3-1** 各 1 分，共 4 分。

A Fe(OH)<sub>2</sub> B Fe<sub>3</sub>O<sub>4</sub> C Fe(OH)<sub>3</sub>或 FeOOH 或 Fe<sub>2</sub>O<sub>3</sub>·xH<sub>2</sub>O GR Fe<sub>6</sub>(OH)<sub>12</sub>SO<sub>4</sub>

![](images/d71619e3ba6d9a84eded56c3f4c9ec7990a76ddab26afc141fdd633477210de0.jpg)

**3-2** Fe<sup>2+</sup> + 2OH<sup>-</sup> = Fe(OH)<sub>2</sub>（2 分）

**3-3-1** 每氧化 1 mol Fe(+2)产生 1 mol OH<sup>-</sup>，因此斜率为 1。（1 分）

而连接 GR 和 Fe<sub>3</sub>O<sub>4</sub>两点的直线斜率不为 1，因此不能完全转化。（1 分）

**3-3-2**

反应 1：10Fe(OH)<sub>2</sub> + 2Fe<sup>2+</sup> + 2SO<sub>4</sub><sup>2-</sup> + O<sub>2</sub> + 2H<sub>2</sub>O = 2Fe<sub>6</sub>(OH)<sub>12</sub>SO<sub>4</sub>（2 分）

反应 2：4Fe<sub>6</sub>(OH)<sub>12</sub>SO<sub>4</sub> + 3O<sub>2</sub> = 20FeOOH + 4SO<sub>4</sub><sup>2-</sup> + 4Fe<sup>2+</sup> + 14H<sub>2</sub>O（3 分）

反应 3：12Fe<sup>2+</sup> + 3O<sub>2</sub> + 2H<sub>2</sub>O = 4FeOOH + 8Fe<sup>3+</sup>（2 分）
