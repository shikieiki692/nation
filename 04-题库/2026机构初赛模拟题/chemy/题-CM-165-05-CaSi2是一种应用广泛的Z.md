# 题-CM-165-05-CaSi2是一种应用广泛的Z

## 题目

### 第 5 题

# 第 5 题 （20 分， 占比 $12 \%$ ） $\mathbf { CaSi } _{ 2 }$ 的结构

CaSi2 是一种应用广泛的 Zintl 相化合物， 其结构中硅通过共价键形成了二维片层，钙填在层间。由于钙和硅的相对位置不同， $\mathrm { eaSi } _{ 2 }$ 存在丰富多彩的结构变体，这些结构变体的密度相近， 但由于 Ca 和 Si 的配位环境不同可能在其它方面体现出不同性质。

5-1 $\mathrm { CaSi } _{ 2 }$ 可由单质按计量比直接混合熔融制得， 也可以由二氧化硅、电石、炭在 $1800^{ \circ } \mathrm { C }$ 下反应制得(反应 1)。在制备过程中还会伴随着介稳相 $\mathrm { { Ca } _{ 14 } \mathrm { { Si } _{ 19 } } }$ 的生成，其在浓硝酸处理过程中会发生转化，多晶 X 射线衍射表明产物之一是 Si 单质(反应 2)。CaSi2 在钢铁工业中可用作脱氧剂，在高温下可被 $\mathrm { O } _{ 2 }$ 氧化(反应 3)。写出反应 $1 \sim$ 反应 $3$ 的化学方程式。

5-2 最简单的一种变体属于三方晶系，其正当晶胞的部分晶胞参数为： $a = b = 385.0 \mathrm { pm }$ ， $c =$ $520.0 \ \mathrm { pm }$ 。 已知其中 Si-Si 键长为 $245.4 \mathrm { pm }$ ，Ca 和 Si 沿 $z$ 轴投影不重合， 据此计算以 Ca 为顶点时所有 Si 的分数坐标， 并写出该晶体的点阵形式。

5-3 其它的结构变体可视作在 5-2 的基础上部分钙和硅沿 $x$ 、 $y$ 方向发生相对位移而得，若将 $z$ 坐标相同的原子视作一堆积层(钙的堆积层用A, B, C 表示，Si 的堆积层用a, b, c 表示)，各变体均有其特定的堆积方式。在对一系列已发现的结构进行总结后，研究人员提出了稳定$\mathrm { CaSi } _{ 2 }$ 变体需满足的三条经验规则：

规则一： 相邻堆积层沿 $z$ 轴投影必须不同， 例如堆积方式为 Aa 的两层是不稳定的；

规则二：为避免硅孤对电子的排斥，位于钙堆积层两侧的硅堆积层沿 $z$ 轴投影必须不同；

规则三：若两个邻近的钙堆积层沿 $z$ 轴投影不同， 其间的硅堆积层采取最大化 Ca-Si 之间次级作用的堆积方式更加稳定，例如AbaB 的堆积方式较 AbcB 的堆积方式更稳定；若两个邻近的钙堆积层沿 $z$ 轴投影相同则无需满足， 例如AbcA 也是能稳定存在的。

5-3-1 一种变体(记作 $\pmb { \mathrm { x } }$ )的部分晶胞参数为： $a = b = 384.5 \mathrm { pm } , \enspace c = 1591.4 \mathrm { pm }$ ， 写出其堆积方式(至少示出一个堆积周期)， 并指出 $\pmb { x }$ 的结构基元。
