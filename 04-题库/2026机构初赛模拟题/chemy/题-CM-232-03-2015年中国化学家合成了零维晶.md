# 题-CM-232-03-2015年中国化学家合成了零维晶

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-7-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（14 分，占 10.0%）

2015 年，中国化学家合成了零维晶体 X。在手套箱中混合 x mmol BaSe、y mmol As<sub>2</sub>Se<sub>3</sub>和

0.125 mmol of Ga<sub>2</sub>Se<sub>3</sub>，装入石英管中高真空封管，加热至 900℃。反应数十个小时后逐渐冷

却至 350℃，得到了黑色晶体 X。X 为正交晶系，沿 b 方向的晶体结构投影如下图所示（蓝

色四面体顶点的小红球也是 Se 原子）：

![](images/6c08c859892440a792f70630959841c0f7d6f66a07dda5b9a196d86621d24a94.jpg)

晶胞参数为 a = 12.632 Å，b = 8.9726 Å，c = 9.2029 Å。

**3-1** 观察晶体结构图，请写出 X 的化学式，并解释为什么 X 是零维晶体。

**3-2** 反应若是化学计量的，请给出 x 和 y 的值。

**3-3** 已知 Ba 被 8 个 Se 配位，指出 Ba、Ga 和 As 的配位多面体。

**3-4** 给出 X 的点阵形式，计算其密度。

## 参考答案

![](images/c6284960002966b2127de4a6ed699c334550f2bddcd9b4d0d14ccdb21f51e790.jpg)

**3-1** Ba<sub>2</sub>GaAsSe<sub>5</sub>（2 分）因为所有的[GaAsSe<sub>5</sub>]<sup>4-</sup>阴离子都是孤立的（2 分）相比之下不属于

一维（链状）、二维（片状）或三维（网状）结构。

**3-2** x = 0.5（2 分）y = 0.125（1 分）

**3-3** 双加帽三棱柱（2 分）四面体（1 分）角锥型（1 分，或答 AsSe<sub>3</sub>形成四面体）

示意图：

![](images/3bdf743f25941d8fbeb0e0fbcc285761a45ae4dd050372af1efa99c797f02585.jpg)

**3-4** 简单正交（1 分）

ρ = ZM/abcN<sub>A</sub> = 4×814.09/(12.632×8.9726×9.2029×10<sup>-24</sup>×6.022×10<sup>23</sup>) = 5.184 g·cm<sup>-3</sup>（2 分）
