# 题-CM-72-03-3-1现有晶体欲将其用溶液处

## 题目

### 第 3 题（11 分）

3-1 现有 $9.8 \ : \mathrm { g } \mathrm { BaSO } _{ 4 }$ 晶体， 欲将其用 $\mathrm { Na } _{ 2 } \mathrm { CO } _{ 3 }$ 溶液处理使其转化为 ${ \bf B a C O } _{ 3 }$ ， 再用盐酸处理即可制得可溶性钡盐 $\mathrm { BaCl } _{ 2 }$ 。 每次用 $100 \ \mathrm { mL } \ 1.0 \mathrm { mol { \cdot } L ^{ - 1 } }$ 的 $\mathrm { Na } _{ 2 } \mathrm { CO } _{ 3 }$ 处理 $\mathrm { BaSO _{ 4 } }$ ， 请计算最少处理几次可以使得 $\mathrm { BaSO _{ 4 } }$ 完全转化。 已知 $K _{ \mathrm { sp } } ( \mathrm { BaSO 4 } ) { = } 1.1 { \times } 10^{ - 10 }$ ， $K _{ \mathrm { sp } } ( \mathrm { BaCO _{ 3 } } ) { = } 5.1 { \times } 10^{ - 9 }$ 。

3-2 若将 $0.10 \ \mathrm { g \ AgCl }$ 完全溶于 $100 ~ \mathrm { mL }$ 氨水中， 计算所需氨水的最低浓度。 已知 $K _{ \mathrm { sp } } ( \mathrm { AgCl } )$ $= 1.8 \times 10^{ - 10 }$ ， $\mathrm { lg } \beta _{ 2 } ( \mathrm { Ag ( NH _{ 3 } ) _{ 2 } } ^{ + } ) = 7.05 ,$ 。

3-3 向 3-2 的溶液中插入 $\mathbf { A } \mathbf { g }$ 电极作为电池的一极，以饱和甘汞电极 $( \mathrm { Hg } , \mathrm { Hg } _{ 2 } \mathrm { Cl } _{ 2 } | \mathrm { KCl } )$ 为另一极。判断组成的原电池的正负极，计算原电池的电极电势。 已知 $25^{ \circ } \mathrm { C }$ 下饱和甘汞电极的电极电势为 $0.241 \mathrm { V }$ ， $\varphi _{ A } ^{ \theta } ( \mathrm { Ag ^{ + } } ) { = } 0.800 \mathrm { V }$ 。

## 参考答案

## 第3题（11分）


3-1 对于反应  $BaSO_{4} + CO_{3}^{2-} = BaCO_{3} + SO_{4}^{2-}$ $K = K_{\mathrm{sp}}(\mathrm{BaSO}_{4}) / K_{\mathrm{sp}}(\mathrm{BaCO}_{3}) = 0.021$ （1 分）

$K = x / (1 - x)$

解得  $x = 0.021 \, mol \cdot L^{-1}$ （1 分）

$m = M V c = 0.50 \, g$ （1 分）

$N = 9.8 / 0.50 = 20$ （1 分）

3-2  $[Cl^{-}] = m / M V = 7.0 \times 10^{-3} \, mol \cdot L^{-1}$ （1 分）

$[\mathrm{Ag}^{+}] = K_{\mathrm{sp}} / [\mathrm{Cl}^{-}] = 2.6 \times 10^{-8} \, mol \cdot L^{-1} &lt;&lt; [\mathrm{Cl}^{-}]$

故  $[\mathrm{Ag}(\mathrm{NH}_{3})_{2}^{+}] = [\mathrm{Cl}^{-}] = 7.0 \times 10^{-3} \, mol \cdot L^{-1}$ （1 分）

$[\mathrm{NH}_{3}] = ([\mathrm{Ag}(\mathrm{NH}_{3})_{2}^{+}] / [\mathrm{Ag}^{+}] \beta_{2})^{1/2} = 0.16 \, mol \cdot L^{-1}$ （1 分）

$c(\mathrm{NH}_{3}) = [\mathrm{NH}_{3}] + 2[\mathrm{Ag}(\mathrm{NH}_{3})_{2}^{+}] = 0.17 \, mol \cdot L^{-1}$ （1 分）

3-3

$\varphi_{A} (\mathrm{Ag}^{+}) = \varphi_{A}^{\theta} (\mathrm{Ag}^{+}) + 0.0591 \lg [\mathrm{Ag}^{+}] = 0.352 \, V &gt; 0.241 \, V$

故 Ag 电极为原电池正极（1 分）

$E = \varphi_{+} - \varphi_{-} = 0.111 \, V$ （2 分）
