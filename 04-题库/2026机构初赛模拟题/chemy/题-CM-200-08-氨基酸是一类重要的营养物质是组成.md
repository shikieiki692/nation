**8-3** 在研究蛋白质的早期，人们就发现不同的蛋白质和肽在水中所带的电性并不相同，这成为电泳法分离它们的重要理论根据。假设现在有两个四肽，分别为(1)H<sub>2</sub>N-E-M-C-H-COOH 和(2)H<sub>2</sub>N-K-I-N-Y-COOH (氨基和羧基分别指示两端氨基酸的未形成肽键的游离氨基和羧基)。假设不同氨基酸的 α-氨基(对应的盐的形式)的 pK<sub>a</sub>均近似为 9.50，α-羧基的 pK<sub>a</sub>均近似为 2.15；各侧链 pK<sub>a</sub>分别为：Y 10.46，C 8.37，K 10.54，H 6.04，E 4.07。在此基础上，设形成多肽并不改变各基团在水中的电离能力，请计算它们的等电点 pI(即分子净电荷为 0 时的 pH 值)。根据你的计算结果，分别判断在 pH = 7.00 时，(1)和(2)电泳时是向正极移动还是向负极移动？

（1）对(1)的计算（共 4 分）：

对(1)，首先粗略估计其等电点 pI：

pH 范围 0-2.15 2.15-4.07 4.07-6.04 6.04-8.37 8.37-9.50 9.50-14

H-羧基 0 -1 -1 -1 -1 -1

E-羧基 0 0 -1 -1 -1 -1

H-咪唑基 +1 +1 +1 0 0 0

C-巯基 0 0 0 0 -1 -1

E-氨基 +1 +1 +1 +1 +1 0

电荷总和 +2 +1 0 -1 -2 -3

因此等电点 pI = (4.07 + 6.04) / 2 = 5.05（3 分）

pI 算出在 5.03 ~ 5.07 之间的，均可得分。

pH = 7.0 时，(1)带负电，移向正极；（1 分）
