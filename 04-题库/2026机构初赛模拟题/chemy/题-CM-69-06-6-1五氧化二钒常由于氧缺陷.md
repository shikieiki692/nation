# 题-CM-69-06-6-1五氧化二钒常由于氧缺陷

## 题目

### 第 6 题（14 分）

6-1 五氧化二钒常由于氧缺陷而形成 $\mathrm { V } _{ 2 } \mathrm { O } _{ 5 - x }$ 。 为测定其中 $x$ 的值，取 $1.7653 \mathrm { ~ g ~ V } _{ 2 } \mathrm { O } _{ 5 - x }$ 溶于硫酸， 用 $0.1100 \ \mathrm { mol } \ \mathrm { L } ^{ - 1 } \mathrm { Ce } ( \mathrm { ClO } _{ 4 } ) _{ 4 }$ 滴定， 消耗 $25.03 ~ \mathrm { mL }$ 。 请计算该氧化物的组成。

6-2 铜在自然界中仅以 $^{ 63 } \mathrm { Cu }$ 和 $^{ 65 } \mathrm { Cu }$ 的形式存在，其原子量分别为62.930 和 64.928， 而铜的原子量为 63.546。 为测定尿液中铜的含量， 现配置一份仅含 $^{ 65 } \mathrm { Cu }$ 的稀释剂，其中 $^{ 65 } \mathrm { Cu }$ 的浓度为 $1.00 \mu \mathrm { g / mL }$ 。 向 $3.00 \mathrm { mL }$ 尿液中加入 $1.00 \mathrm { mL }$ 上述稀释剂， 然后除去其他杂质离子，用质谱仪测得该混合溶液中 $n ( ^{ 63 } \mathrm { Cu } ) { : } n ( ^{ 65 } \mathrm { Cu } ) = 0.6616 \mathrm { _ s }$ 。
份仅含65Cu 的稀释剂，其中65Cu 的浓度为1.00 μg/mL。向3.00 mL 尿液中加入1.00 mL 上

${ \bf 6 - 2 - 1 } ^{ 64 } \mathrm { Cu }$ 是极不稳定的核素，在自然界中不存在， 只能通过人工合成得到。 $^{ 64 } \mathrm { Cu }$ 有两种衰变方式： 它既可以发生 $\beta$ 衰变， 也可发生电子俘获。 写出这两个反应的核反应方程式。

6-2-2 计算自然界中 $^{ 63 } \mathrm { Cu }$ 和 $^{ 65 } \mathrm { Cu }$ 的同位素丰度。

6-2-3 计算尿液中铜的含量(以 $\mu \mathrm { g / mL }$ 计)。

## 参考答案

## 第6题（14分）

6-1  $V_{2}O_{5-x} + 2xCe^{4+} + (2-2x)H^{+} = 2VO_{2}^{+} + 2xCe^{3+} + (1-x)H_{2}O$  （1分）
由  $n(e)=\frac{1.7653\ g\times2x}{50.94\times2+16.00\times(5-x)}=0.1100\ mol\ L^{-1}\times25.03\ mL$  （3分）
解得 x = 0.14（1 分）



**6-2-1** $^{64}\text{Cu} = ^{64}\text{Zn} + \text{e}$ (1分) $^{64}\text{Cu} + \text{e} = ^{64}\text{Ni}$ (1分)

**6-2-2** 计算自然界中 $^{63}\text{Cu}$ 和 $^{65}\text{Cu}$ 的同位素丰度。

**6-2-1** 由 $62.930A(^{63}\text{Cu}) + 64.928A(^{65}\text{Cu}) = 63.546$ (0.5分)



![](images/eece40ff041eceb75ec4f92aa076378809c37a2ea3da0a0f48a2b21228780f16.jpg)

6-2-3 加入  ${}^{65}$ Cu 的量为:
 $n(^{65}\mathrm{Cu})=1.00\mu\mathrm{g}/\mathrm{mL}\times1.00\mathrm{~mL}/(64.928\mathrm{~g}/\mathrm{mol})=1.540\times10^{-8}\mathrm{~mol}(1\text{分})$
设原尿液中含铜的摩尔数为  $n_{0}$ ，则有：
 $\frac{0.6917n_{0}}{0.3083n_{0}+1.540\times10^{-8}\mathrm{~mol/L}}=0.6616(2\text{分})$
解得： $n_{0}=2.087\times10^{-8}\mathrm{~mol}(1\text{分})$
铜的含量为：
 $m = 63.546 \, g/mol \times 2.087 \times 10^{-8} \, mol / 3.00 \, mL = 0.442 \, \mu g/mL (1\text{分})$
保留两位有效数字也可得分。
