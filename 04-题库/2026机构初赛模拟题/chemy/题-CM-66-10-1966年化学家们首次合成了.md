# 题-CM-66-10-1966年化学家们首次合成了

## 题目

### 第 10 题（12 分）

1966 年，化学家们首次合成了 Corannulene(心环烯)， Corannulene 具有碗形的稠环结构，被认为是首个具有非平面芳香性的分子。 Corannulene 的分子式为 $\mathrm { C } _{ 20 } \mathrm { H } _{ 10 }$ ， 属于 $C _{ 5 \mathrm { v } }$ 点群，核磁共振氢谱显示分子中只有一种氢原子。由于Corannulene 独特的结构和对于芳香性理论研究的重要意义，激起了大量化学家对该分子的兴趣。 2012 年，J.S.Siegel 以纯有机的方法实现了对 Corannulene 的千克量级合成， 可以说为 Corannulene 的制备画上了一个句号，其合成路线如下：

![](images/16e3b3936e16cedcf6dd00b8daabb3b74082b1770ca33c0005a3d962a1b8787c.jpg)

10-2 在操作过程中，D1 和D2 难以直接分离，而是通过加入GirardsReagent(结构如右图)帮助分离，指出通过什么实验操作将二者分离，简述 D1 和 D2 难以直接分离的原因，并说明为何加入 GirardsReagent 能够帮助二者分离。
