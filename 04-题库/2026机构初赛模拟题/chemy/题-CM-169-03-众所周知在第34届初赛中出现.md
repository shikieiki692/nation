# 第 3 题（17 分， 占 $9 \%$ ） 想起四重氢键

众所周知， 在第34 届初赛中出现了令人震撼的通过四重氢键构建的聚合物。 小波为了让你回忆起被四重氢键支配的恐惧， 向你介绍了一系列具有四重氢键的结构。

3-1 2022 年，有课题组报道了由四重氢键形成的分子镊子。分子镊子是一种开放的、具有空腔的U 型分子结构，在超分子化学中具有很高的应用潜力。而由氢键组装而成的分子镊子则更富有灵活性， 受到了广泛关注。

3-1-1 以下单体A 能通过四重氢键形成首尾相连的环状四聚体 B （此处以简图表示）。在答题卡中圈出所有参与形成四重氢键的原子。

![](images/7bdc30ba08db470f9e64d9316dce9a9115f9ba22436bc996fe8fce700d75ef4b.jpg)

3-1-2 向上述四聚体B 中加入四当量化合物C（结构如下图所示），四聚体即发生解聚产生两分子二聚体D。D 具有分子镊子的U 型结构，各部分间由四重氢键相连。 画出 D 中所有四重氢键的结构 （无关部分可适当省略）。

![](images/4f0ed25ad202fc8b6e9e04bced2e76155d1ce1860c8d26582edd09819e93951e.jpg)

3-2 2020 年， 研究人员发现了一个光控自组装的化合物 G1 （结构如下图所示） $\mathsf { \pmb { G } } _{ 1 }$ 在$365 \mathrm { nm }$ 的光照下发生异构化反应，产生其几何异构体 $\overline { { \mathsf { G } _{ 2 } } }$ 。研究人员观察到， $\mathsf { \pmb { G } } _{ 1 }$ 无法发生二聚，而 $\mathsf { \pmb { G } } _{ 2 }$ 可以发生二聚，该现象与氢键的形成密切相关。

![](images/dfbc3d8fc544ba9fbb972fdc7b3e769b09c5c2d85ed65f61c55cb76672927941.jpg)

$\pmb { 3 - 2 - 1 } \in _{ 1 }$ 无法发生二聚的主要原因是因为 $\pmb { 6 } _{ 1 }$ 中存在大量的分子内氢键“锁住”了其构象。画出 $\mathsf { \pmb { G } } _{ 1 }$ 的结构，表示出其所有的分子内氢键。
$3 - 2 - 2 G _{ 2 }$ 则可正常通过分子间氢键形成二聚体。画出 $\mathsf { \pmb { G } } _{ 2 }$ 二聚体的结构， 表示出所有分子内氢键与分子间氢键。

$3 - 2 - 3 G _{ 2 }$ 的互变异构体 $\pmb { G } _{ 3 }$ 也可通过分子间氢键形成二聚体。已知 $\pmb { G } _{ 3 }$ 中存在一个嘧啶(1,3-二氮杂苯)环， 画出 $\pmb { G } _{ 3 }$ 二聚体的结构， 表示出所有分子内氢键与分子间氢键。
