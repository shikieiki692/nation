# 题-CM-64-02-硼氮阴离子与镧能形成丰富多彩

## 题目

### 第 2 题（10 分）

硼氮阴离子与镧能形成丰富多彩的结构。将 $\mathrm { LaCl } _{ 3 }$ 、 $\mathrm { Li } _{ 3 } \mathrm { BN } _{ 2 }$ 和 $\mathrm { Li } _{ 3 } \mathrm { N }$ 按一定比例在高温混合反应，得到最简式为 $\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 5 }$ 的盐； 但若向反应体系中加入一定量的 Li， 则得到化学式为$\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 4 }$ 的盐。 $\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 5 }$ 中的阴离子有A、B、C 三种，其比例为1:1:1；其中 A 和 B 均与 $\mathrm { BF } _{ 3 }$ 具有相同的对称性，而C 为简单阴离子。 $\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 4 }$ 中的阴离子有D、E 两种，其中D 与草酸根离子互为等电子体。这两种镧盐中， 镧均呈现 $+ 3$ 氧化态。
呈现+3 氧化态。2-1 画出Li3BN2 中阴离子[BN2]3

2-1 画出 $\mathrm { Li } _{ 3 } \mathrm { BN } _{ 2 }$ 中阴离子 $\mathrm { [ BN } _{ 2 } ] ^{ 3 }$ -的 Lewis 结构式。

2-2 分别写出能体现 $\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 5 }$ 和 $\mathrm { La } _{ 3 } \mathrm { B } _{ 2 } \mathrm { N } _{ 4 }$ 结构特点的化学式。

2-3 画出阴离子A、 B、 $D$ 的结构示意图。
