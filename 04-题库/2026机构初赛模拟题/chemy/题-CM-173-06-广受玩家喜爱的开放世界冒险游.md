# 题-CM-173-06-广受玩家喜爱的开放世界冒险游

## 题目

### 第 6 题 10 分， $8 \%$

广受玩家喜爱的开放世界冒险游戏《原神》中有一种矿物“夜泊石”，其在三次元世界里的原型是常见氟化物矿物——萤石。其主要成分为氟化钙，其次是碳酸钙、硫酸钙、二氧化硅、氧化铁、氧化铝等。下面对一份萤石样品进行分析：
准确称取 $0.2503 \ \mathrm { g }$ 萤石样品，置于 $100 ~ \mathrm { mL }$ 烧杯（记作烧杯1）中，加入 $10 \mathrm { mL } 100 \mathrm { g } \mathrm { L } ^{ - 1 }$ 的乙酸溶液，盖上表面皿，水浴加热 $30 \mathrm { min }$ （每隔 $5 { \sim } 7 \mathrm { min }$ 用玻璃棒搅拌一次）。取下烧杯，用致密滤纸并加少许纸浆过滤，滤液收集于 $400 ~ \mathrm { mL }$ 烧杯（记作烧杯 2）中。用 ${ \leqslant } 20 ~ \mathrm { mL }$ 热水洗涤烧杯及残渣数次，然后将滤纸和残渣全部转入烧杯 1。

400 mL 烧杯（记作烧杯2）中。用≤20 mL 热水

将烧杯2 中溶液用水稀释至约 $250 \mathrm { mL }$ ，加 $3 \mathrm { mL }$ 三乙醇胺（ $1 { + } 2$ ）及适量的甲基百里香酚蓝指示剂，搅拌下加入 $200 \ \mathrm { g } \mathrm { L } ^{ - 1 }$ 的KOH 溶液至出现稳定的蓝色后再过量 $3 \mathrm { mL }$ ，然后用$0.01514 ~ \mathrm { mol } ~ \mathrm { L } ^{ - 1 }$ 的 EDTA 标准溶液滴定至蓝色消失，记录消耗 EDTA 体积 $V _{ 1 } { = } 11.67 ~ \mathrm { mL }$ 。6-1 计算氟化钙在 $100 \ \mathrm { g \ L ^{ - 1 } }$ 乙酸中的溶解度（以 mol·L-1 记）。可供参考的数据：乙酸$\mathrm { p } K _{ \mathrm { a } } { = } 4.74$ ， $K _{ \mathrm { sp } } ( \mathrm { CaF } _{ 2 } ) { = } 2.7 { \times } 10^{ - 11 }$ ， $\mathrm { HF } \ p K _{ \mathrm { a } } ^{ \ , } { = } 3.18$ 。
在烧杯1 中加入 $10 \mathrm { mL } 50 \mathrm { g } \mathrm { L } ^{ - 1 }$ 硼酸溶液和 $10 ~ \mathrm { mL }$ 浓硫酸，盖上表面皿，加热煮沸 20min。 用快速滤纸过滤，滤液收集于 $250 ~ \mathrm { mL }$ 容量瓶中。滤纸上的不溶残渣，用热水洗涤8\~10 次，将溶液冷却至室温，加水稀释至标线，摇匀。 吸取 $50 ~ \mathrm { mL }$ 溶液放入 $400 ~ \mathrm { mL }$ 烧杯（记作烧杯 3）中，用水稀释至约 $\widehat { 250 } \mathrm { mL }$ ， 加 $5 \mathrm { mL }$ 三乙醇胺（ $1 { + } 2$ ）及适量的甲基百里香酚蓝指示剂，在搅拌下加入 $200 \mathrm { gL ^{ - 1 } }$ 的 KOH 溶液至出现稳定的蓝色后再过量 $3 \mathrm { mL }$ ，用 $0.01514 \mathrm { mol } \mathrm { L } ^{ \mathrm { - 1 } } \mathrm { EDTA }$ 标准溶液滴定至蓝色消失，记录消耗 EDTA 体积 $V _{ 2 } { = } 36.70 ~ \mathrm { mL }$ 。

6-2 写出加入硼酸和浓硫酸后烧杯 1 中发生反应的方程式。

6-3 计算该样品中的 $\mathrm { CaF } _{ 2 }$ 含量 $( \%$ ） 及总Ca 含量 $( \% )$ ）。

## 参考答案

## 第6题（10分，8%）

6-1 HAc 物质的量浓度:

$$
c (\mathrm{HAc}) = \frac {100}{60.052} = 1.67 \mathrm{molL} ^{- 1}
$$

CBE:

$$
2 \left[ \mathrm{Ca} ^{2 +} \right] + \left[ \mathrm{H} ^{+} \right] = \left[ \mathrm{F} ^{-} \right] + \left[ \mathrm{OH} ^{-} \right] + \left[ \mathrm{Ac} ^{-} \right]
\text {即:} 2 s _{0} + \left[ \mathrm{H} ^{+} \right] = \frac {10^{- \mathrm{p} K _{\mathrm{a}} ^{\prime}}}{10^{- \mathrm{p} K _{\mathrm{a}} ^{\prime}} + \left[ \mathrm{H} ^{+} \right]} \times 2 s _{0} + \frac {K _{\mathrm{w}}}{\left[ \mathrm{H} ^{+} \right]} + \frac {10^{- \mathrm{p} K _{\mathrm{a}}}}{10^{- \mathrm{p} K _{\mathrm{a}} + \left[ \mathrm{H} ^{+} \right]}} \times 1.67 (1 \text {分})
$$

溶解平衡：

$$
[ \mathrm{Ca} ^{2 +} ] [ \mathrm{F} ^{-} ] ^{2} = K _{\mathrm{sp}} (\mathrm{CaF} _{2})
\text { 即: } \left(\frac {10^{- p K _{\mathrm{a}} ^{\prime}}}{10^{- p K _{\mathrm{a}} ^{\prime}} + [ \mathrm{H} ^{+} ]}\right) ^{2} \times 4 s _{0} ^{3} = K _{\mathrm{sp}} (\mathrm{CaF} _{2}) (1 \text { 分 }) \text { 解得: } s _{0} = 7.78 \times 10^{- 4} \mathrm{molL} ^{- 1} 。 (2 \text { 分 })
6 - 24 \mathrm{CaF} _{2} + 2 \mathrm{B} (\mathrm{OH}) _{3} + 12 \mathrm{H} _{2} \mathrm{SO} _{4} = = \mathrm{Ca} (\mathrm{BF} _{4}) _{2} + 3 \mathrm{Ca} (\mathrm{HSO} _{4}) _{2} + 6 \mathrm{H} _{3} \mathrm{OHSO} _{4} (2 \text {分})
$$

对产物水的存在形式不做要求。产生 $CaSO_{4}$ 也得分。

$$
3 \mathrm{CaF} _{2} + 2 \mathrm{B} (\mathrm{OH}) _{3} + 6 \mathrm{H} _{2} \mathrm{SO} _{4} = = 3 \mathrm{Ca} (\mathrm{HSO} _{4}) _{2} + 2 \mathrm{BF} _{3} + 6 \mathrm{H} _{2} \mathrm{O} \text {   也可得满分。   }
$$

6-3 EDTA 对 Ca 的滴定度:

$$
T _{\mathrm{Ca}} = 0.01514 \times 40.08 = 0.6068 \mathrm{mg} \mathrm{mL} ^{- 1}
$$

$CaF_{2}$ 含量:

$$
\omega_{\mathrm{CaF} _{2}} = \frac {5 T _{\mathrm{Ca}} V _{2} \times \frac {78.08}{40.08} + s _{0} V _{0} M}{1000 m} \times 100 \% = \frac {5 \times 0.6068 \times 36.70 \times \frac {78.08}{40.08} + 7.78 \times 10^{- 4} \times 10 \times 78.08}{1000 \times 0.2503} \times 100 \% = 86.91 \% (\text {2分})
$$

认为 $CaF_{2}$ 溶解损失少从而忽略的需给出说明，否则酌情扣除过程分。

总 Ca 含量:

$$
\omega_{\mathrm{Ca}} = \frac {T _{\mathrm{Ca}} (V _{1} + 5 V _{2})}{1000 m} \times 100 \% = \frac {0.6068 \times (11.67 + 5 \times 36.70)}{1000 \times 0.2503} \times 100 \% = 47.31 \% (\text{2分})
$$
