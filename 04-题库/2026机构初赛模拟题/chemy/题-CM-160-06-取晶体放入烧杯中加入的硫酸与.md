# 题-CM-160-06-取晶体放入烧杯中加入的硫酸与

## 题目

### 第 6 题

第 6 题（17 分， 占 $10 \%$ ） 配合物的合成与分析配合物 $\pmb { x }$ 是一种翠绿色的单斜晶体。某同学通过如下步骤进行了合成与分析。

取 $( \mathrm { NH _{ 4 } } ) _{ 2 } \mathrm { Fe } ( \mathrm { SO _{ 4 } } ) _{ 2 } { \cdot } 6 \mathrm { H } _{ 2 } \mathrm { O }$ 晶体 $6.04 ~ \mathrm { g }$ ， 放入 $250 ~ \mathrm { mL }$ 烧杯中， 加入 $1 \mathrm { mol / L }$ 的硫酸 $1 ~ \mathrm { mL }$ 与 20mL 水加热溶解。再称取 $5.00 \mathrm { g }$ 草酸，加入 $40 \mathrm { mL }$ 水微热搅拌，溶解后取 $22 { \mathrm { mL } }$ 倒入上述溶液中，加热，微沸 `\widehat { \sf s m i n }` ， 得到黄色的沉淀 A。用热的蒸馏水洗涤该沉淀， 再将该沉淀加入$15 \mathrm { mL }$ 饱和草酸钾溶液，水浴加热至 $40^{ \circ } \mathrm { C }$ ，用滴管慢慢加入 $6 \%$ 的过氧化氢溶液至过量（反应1），此时体系变为棕褐色，说明产生了氢氧化物 $\pmb { \mathsf { B } } _{ \circ }$ 在此之后，加热至沸腾，发现有气泡冒出（反应2）。再取适量的草酸溶液，逐滴滴入上述溶液中，不断搅拌，直到沉淀完全溶解为透明的绿色溶液为止（反应3）。冷却后，缓慢加入无水乙醇，结晶， 冷却， 抽滤，洗涤，得到产物X。

加热至40℃，用滴管慢慢加入6%的过氧

6-1 写出 A、B、 $\pmb { x }$ 的化学式， 已知X 中含 Fe 质量分数为 $11.37 \%$ 。

6-2 写出反应 1\~3 的方程式。 已知反应 可以用A 作为起始产物， 且部分Fe 元素已经转化为目标配合物， 但尚未析出晶体。

6-3 某同学在实验时不慎加入了过量的无水乙醇，发现分离后的产物颜色明显偏浅。他将产物用沸水溶解后冷却结晶如愿得到了理想的翠绿色晶体。试分析产物颜色偏浅的原因。

## 参考答案

6-1 $FeC_{2}O_{4}$ （1分） $\mathrm{Fe(OH)_{3}}$ （1分） $\mathrm{K_{3}Fe(C_{2}O_{4})_{3}-3H_{2}O}$ （2分）

$$
\begin{array}{r l} & 6 - 26 \mathrm{FeC} _{2} \mathrm{O} _{4} + 6 \mathrm{K} _{2} \mathrm{C} _{2} \mathrm{O} _{4} + 3 \mathrm{H} _{2} \mathrm{O} _{2} = = 2 \mathrm{Fe(OH)} _{3} + 4 \mathrm{K} _{3} \mathrm{Fe(C} _{2} \mathrm{O} _{4}) _{3} (2 \text {分}) \\ & 2 \mathrm{H} _{2} \mathrm{O} _{2} = = 2 \mathrm{H} _{2} \mathrm{O} + \mathrm{O} _{2} (1 \text {分}) 2 \mathrm{Fe(OH)} _{3} + 3 \mathrm{H} _{2} \mathrm{C} _{2} \mathrm{O} _{4} + 3 \mathrm{K} _{2} \mathrm{C} _{2} \mathrm{O} _{4} = = 2 \mathrm{K} _{3} \mathrm{Fe(C} _{2} \mathrm{O} _{4}) _{3} + 6 \mathrm{H} _{2} \mathrm{O} (1 \text {分}) \end{array}
$$

6-4-1 $c(\mathrm{KMnO}_{4})=\frac{cV*2}{5V}=0.02014\mathrm{mol/L}$ （1分）

6-4-2 $\omega = \frac{cV*5M}{6m}$ (1分)，求得三组的质量分数分别为： $98.68\%$ ， $99.43\%$ ， $98.96\%$ （2分）
