# 题-CM-65-05-5-1金属硫化物具有丰富多彩

## 题目

### 第 5 题（10 分）

5-1 金属硫化物具有丰富多彩的结构。 $\mathrm { CoS } _{ 2 }$ 、 $\mathrm { GeS } _{ 2 }$ 、 $\mathrm { Pd } \mathrm { S } _{ 2 }$ 和 $\mathrm { SnS } _{ 2 }$ 均是化学式形如 ${ \mathrm { MS } } _{ 2 }$ 的物质， 请分别将它们的结构与以下描述相对应。

5-1-1 阴离子做六方最密堆积， 金属离子填充一半的八面体空隙。

5-1-2 金属离子为四面体配位， 四面体间通过共顶点连接形成三维无限结构。

5-1-3 阴离子占据立方晶胞的顶点和面心， 金属离子占据立方晶胞的体心和棱心。

5-1-4 金属离子为平面四方配位， 阴离子与金属离子形成二维层状结构。

5-2 金属硼氢化物常可用作储氢材料。右图是一种被氨分子配体稳定的金属硼氢化物的晶体结构示意图，图中八面体的中心代表金属A 原子，八面体的顶点代表氨分子配体，M-N 键可自由旋转；四面体的中心代表硼原子，四面体的顶点代表氢原子。该晶体属立方晶系，晶胞参数 $a = 1071.4 \mathrm { pm }$ ， 密度 $D = 1.014 \mathrm { g } / \mathrm { cm } ^{ 3 }$ 。

![](images/4d6b3108b5bab0b44928a861b658479e225d433ecb59413d02448fdefcf89f19.jpg)

5-2-1 写出该晶体的化学式。

5-2-2 通过计算确定金属 $\pmb { \mathsf { A } }$ 的元素符号。

5-2-3 该晶体的对称性与萤石晶体的对称性是否相同？

## 参考答案

第5题（10分）

5-2-1 $\mathbf{A}(\mathrm{NH}_3)_6(\mathrm{BH}_4)_2$ (2分)
5-2-2 $M = DN_{\mathrm{A}}V / Z = 187.7\mathrm{g / mol}$ (2分)减去2个 $\mathrm{BH}_4$ 和6个 $\mathrm{NH}_3$ ，得 $M_{\mathrm{A}} = 55.83\mathrm{g / mol}$ ，为Fe（1分）
5-2-3 相同（1分）
