# 题-CM-169-05-近年来高压下的新研究成果时有

## 题目

### 第 5 题

# 第 5 题（26 分， 占 $12 \%$ ） 高压化学

近年来, 高压下的新研究成果时有报道。研究表明， 在高压下物质的组成、结构、化学反应都可能不同于常压。譬如，氢在常压下不是金属，但在高压下分子氢会变为金属氢，具有导电性；我们熟知的二氧化碳也会在高压下由分子晶体转变为类似于二氧化硅的原子晶体。本题主要研究高压下原子、分子和晶体的特殊性质或结构。

5-1 高压下的原子 在高压下，所有原子轨道的能量均随压强的增加而增加。 但是，较低主量子数和较高角量子数轨道能量增加的幅度明显低于较高主量子数和较低角量子数的轨道。根据以上信息，从价电子排布的角度，解释Ni 在高压下成为绝缘体的原因。

5-2 高压下的分子 实验发现，高压下分子晶体可能发生相变，譬如 $\Nu _{ 2 }$ 在一定的压力下会部分地转化为为如下图所示的共价晶体。使用热力学基本关系式 $\mathrm { d } G = V \mathrm { d } p  S \mathrm { d } T$ 解释其原因（假设加压过程中温度不发生变化）。

![](images/2b8f62cc643f60c0b790157293bc829aa721ad3f98e7b761d16e5950edc382dd.jpg)

5-3 高压下的晶体 在高压下，金属元素 $\pmb { \mathsf { A } }$ 可以和非金属元素 B 形成一种晶体X。已知该晶体为四方晶系，晶胞参数 $a = 435.5 \mathrm { pm }$ , $c = 1370 \mathrm { pm }$ 。 在晶体中， $\pmb { \mathsf { A } }$ 和B 形成一维无限链状结构，且 A 原子为直线型配位。晶胞沿 $\boldsymbol { \mathscr { c } }$ 轴的投影图如下所示，其中浅色球为A，深色球为B。

![](images/5b65eacbc2634d787e5e910d3ec73f9a3555f91b64a6aeeda8137759b3a2dc0f.jpg)

5-3-1 已知在晶胞中，A 原子占据晶胞的所有顶点和面心，其中一个 B 原子的坐标为(0.250,0.250,0.153)。据此写出晶胞中所有 $\pmb { \mathsf { A } }$ 原子和 $B$ 原子的坐标，并写出该晶体的化学式（用A 和 B 表示）。
5-3-2 计算晶体中最短的A-A 距离，最短的A-B 距离及 A-B-A 键角的大小。
5-3-3 已知 $\pmb { \mathsf { A } }$ 单质为面心立方结构，晶胞参数 $a = 407.6 \ \mathrm { pm }$ ， $\pmb { \mathsf { A } }$ 的范德华半径比金属半径大约 30 pm， 据此判断晶体 $\pmb { x }$ 中是否存在金属-金属相互作用。
5-3-4 已知该晶体密度 $\rho = 8.274 ~ \mathrm { g } / \mathrm { cm } ^{ 3 }$ ， 通过计算推断出A 和 B 的元素符号。

## 参考答案

5-1 随着压力的增加，4s 轨道的能量比 3d 轨道的能量上升得快（1 分）。因此，在某一压力下，3d 轨道的能量就会低于 4s 轨道的能量，导致 4s 轨道上的电子跃迁至 3d 轨道，此时核外电子排布为 $3d^{10}4s^{0}$ （1 分）。此时导带和满带之间的禁带很宽，故 Ni 在高压下成为绝缘体（1 分，结合电子能带理论简要说明即可）。

5-3-2 共6分

$$
d _{(\mathbf {A} - \mathbf {A})} = \frac {\sqrt {2}}{2} a = 307.9 \mathrm{pm(2分)}
d _{(\mathbf {A} - \mathbf {B})} = [ 2 \times (0.250 a) ^{2} + (0.153 c) ^{2} ] ^{0.5} = 260.1 \mathrm{pm} (2 \text {分})
\angle_{\mathbf {A} - \mathbf {B} - \mathbf {A}} = 2 \times \sin^{- 1} [ 307.9 / (2 \times 260.1) ] = 72.6^{\circ} (2 \text {分})

## 5-3-3 共 3 分

该单质中金属半径 $r = 0.5 \, d_{(\mathbf{A}-\mathbf{A})} = \frac{\sqrt{2}}{4} \, a = 144.1 \, \text{pm}$ （1 分），则 A 的范德华半径约为 174 pm（1 分）；X 中 A-A 之间最短的距离为 307.9 pm，小于 A 范德华半径的二倍，因此存在金属-金属相互作用（1 分）

$$
M _{\mathbf {X}} = \rho \mathrm{N} _{\mathrm{A}} V / Z = \frac {8.274 \times 6.022 \times 10^{23} \times 4.355^{2} \times 13.71}{4 \times 10^{24}} \mathrm{g/mol} = 323.9 \mathrm{g/mol(2分)}
$$

考虑到 A 原子为直线型配位，经尝试可知：X 为 AuI，

因此 A 的元素符号为 Au（1 分），B 的元素符号为 I（1 分）。
