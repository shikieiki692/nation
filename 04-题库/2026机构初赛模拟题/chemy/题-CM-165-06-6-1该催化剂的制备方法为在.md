# 题-CM-165-06-6-1该催化剂的制备方法为在

## 题目

### 第 6 题

第 6 题 （19 分， 占比 $12 \%$ ） 水氧化反应催化剂的设计在自然界中，光合作用系统II (简写为光系统II)可以高效催化水氧化反应，其作用机制如下图所示，从图中可以看出，光系统 II 的关键结构是 $\mathrm { { Mn _{ 4 } CaO _{ 5 } } }$ ， 在反应过程中之前步骤生成的 $\mathrm { P 680 } ^{ + }$ (氧化形态的一种叶绿素，由 $\mathbf { P } _{ 680 }$ 在光照条件下激发失去电子得到)将 $\mathrm { Mn } _{ 4 } \mathrm { CaO } _{ 5 }$ 簇中的 Mn 分步氧化，得到的高价 Mn 再将 $\mathrm { H } _{ 2 } \mathrm { O }$ 氧化得到 $\mathrm { O } _{ 2 }$ 。仿照此思路，有研究人员设计了一种催化水氧化反应的多核铁簇催化剂。

![](images/4be41eee9ab70e5792dc5c10f3634ed29240965901c9928e33c02770c3384a5c.jpg)

6-1 该催化剂的制备方法为： 在空气气氛下，向 HL(结构示于下图)的甲醇溶液中加入等量的 NaOH 水溶液，再加入 $\mathrm { FeSO 4 } \cdot 7 \mathrm { H } _{ 2 } \mathrm { O }$ ， 充分反应后过滤除去不溶物，再向滤液中加入适量的 $\mathrm { NaBF _{ 4 } }$ 水溶液， 反应后经分离操作可得到橙色催化剂晶体。

![](images/00a5a4a57fc46d4ad0522b92540429d7b8c327ae4c03e9f977045784c5c16415.jpg)
