# 题-CM-96-02-通过以下方法分离铂铱合金中的

## 题目

### 第 2 题（9 分）

通过以下方法分离铂铱合金中的铂和铱。将铂铱合金与大量锡单质于 $1000^{\circ}\mathrm{C}$ 共熔，生成新的合金；然后铸成片状，用盐酸溶解(反应1)，得到溶液和小颗粒合金残渣；弃去溶液，将残渣用王水处理，铂转化为 $\mathrm{PtCl}_6^{2-}$ (反应2)，铱转化为 $\mathrm{IrCl}_6^{2-}$ ；经上述过程后，仍有少量大颗粒铱无法溶解；将其在苛性钠存在下用过氧化钠熔融处理，使之转化为 $\mathrm{Na_2IrO_4}$ (反应3)；然后用水溶解，并用盐酸处理， $\mathrm{IrO_4}^{2-}$ 转化为 $\mathrm{IrCl}_6^{2-}$ (反应4)；用 $10\%$ 的 $\mathrm{NaOH}$ 溶液将 $\mathrm{PtCl}_6^{2-}$ 和 $\mathrm{IrCl}_6^{2-}$ 的混合溶液调至近中性，加入大过量的水合肼，析出黑色铂粉(反应5)，而铱仍留在溶液中；用氯化铵将铱转化为 $(\mathrm{NH}_4)_2\mathrm{IrCl}_6$ 沉淀；在氢气气氛中，将沉淀加热至 $1000^{\circ}\mathrm{C}$ (反应6)，即得到铱粉。

分别写出反应 1\~6 的方程式(要求系数为最简整数比)。

## 参考答案

第2题（9分）

反应 1: Sn + 2HCl = SnCl₂ + H₂
反应 2: 3Pt + 4HNO₃ + 18HCl = 3H₂PtCl₆ + 4NO + 8H₂O
反应 3: Ir + 3Na₂O₂ = Na₂IrO₄ + 2Na₂O
反应 4: IrO₄²⁻ + 8H⁺ + 8Cl⁻ = IrCl₆²⁻ + Cl₂ + 4H₂O
反应 5: PtCl₆²⁻ + 5N₂H₄ = Pt + 6Cl⁻ + N₂ + 4N₂H₅⁺
反应 6: (NH₄)₂IrCl₆ + 2H₂ = 2NH₃ + 4HCl + Ir（每式 1.5 分）
