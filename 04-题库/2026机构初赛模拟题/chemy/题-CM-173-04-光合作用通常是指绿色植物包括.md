# 题-CM-173-04-光合作用通常是指绿色植物包括

## 题目

### 第 4 题

第 4 题（13 分， 占比 $11 \%$ ） 生产者的奥秘

光合作用，通常是指绿色植物（包括藻类）吸收光能，把二氧化碳和水合成富能有机物，同时释放氧气的过程。其主要包括光反应、暗反应两个阶段，涉及光吸收、电子传递、光合磷酸化、碳同化等重要反应步骤，对实现自然界的能量转换、维持大气的碳-氧平衡具有重要意义。

4-1 20 世纪 30 年代， van Niel 对细菌光合作用进行比较研究后， 提出了一个较为一般的光合作用过程表达式：

光CO2 2H2A $C H _{ 2 } O$ 2A + H2O氢受体 氢供体 还原态受体 氧化态供体

据此， 分别写出葡萄糖为产物时， 绿色植物利用 $\mathrm { H } _{ 2 } \mathrm { O }$ ， 硫细菌利用 $\mathrm { H } _{ 2 } \mathrm { S }$ 或 $\mathrm { SO } _{ 3 } { } ^{ 2 - }$ ， 非硫细菌利用异丙醇进行光合作用的反应式。

4-2 暗反应中的还原剂NADPH 和供能物质 ATP 全部由光反应合成。其中非循环光合磷酸化过程的总反应式为：

$$
2 \mathrm { NADP ^{ + } } + 3 \mathrm { ADP } + 3 \mathrm { Pi } = \mathrm { O } _{ 2 } + 2 \mathrm { NADPH } + 2 \mathrm { H } ^{ + } + 3 \mathrm { ATP } + \mathrm { H } _{ 2 } \mathrm { O }
$$

光的作用是激活电子，驱动 $_ \mathrm { H _{ 2 } O }$ 到 $\mathrm { \Delta NADP ^{ + } }$ 的电子转移。机理研究表明， 每驱动 1 个电子需要2 个光子的参与。假定每个光子的能量被吸收后只能被利用约 $40 \%$ 。计算 $\mathrm { pH } = 7$ 时每消耗 $1 \mathrm { molNADP ^{ + } }$ 至少应输入多少光能，以及所吸收光的波长和颜色。可供参考的数据： $E ^{ \circ } ( \mathrm { O } _{ 2 }$ $/ \mathrm { \ H } _{ 2 } \mathrm { O } ) = + 1.23 \mathrm { \ V }$ ， $E ^{ \circ } ( \mathrm { NADP ^{ + } } \ / \ \mathrm { NADPH } ) = - 0.32 \ \mathrm { V }$ ；水解 1 mol ATP 放出 $30.53 ~ \mathrm { kJ }$ 能量；$E ^{ \circ } ^{ , } ( \mathrm { NADP ^{ + } } / \mathrm { NADPH } )$ 为生物化学标准态 $\mathrm { ( pH = 7.00 }$ ， $\begin{array} { r } { T = 298 \mathrm { K } , } \end{array}$ )下的电极电势。

## 参考答案

$$
\begin{array}{c c c} \mathrm{CO} _{2} & + & 2 \mathrm{H} _{2} \mathrm{A} \\ \text {氢受体} & & \text {氢供体} \end{array} \xrightarrow {\text {光}} \begin{array}{c c c} \mathrm{CH} _{2} \mathrm{O} & + & 2 \mathrm{A} \\ & & + & \mathrm{H} _{2} \mathrm{O} \end{array}
$$

4-1 各 1 分，共 4 分。

$$
\begin{array}{l} 6 \mathrm{CO} _{2} + 6 \mathrm{H} _{2} \mathrm{O} = \mathrm{C} _{6} \mathrm{H} _{12} \mathrm{O} _{6} + 6 \mathrm{O} _{2} \\ 6 \mathrm{CO} _{2} + 12 \mathrm{H} _{2} \mathrm{S} = \mathrm{C} _{6} \mathrm{H} _{12} \mathrm{O} _{6} + 12 \mathrm{S} + 6 \mathrm{H} _{2} \mathrm{O} \\ 6 \mathrm{CO} _{2} + 12 \mathrm{SO} _{3} ^{2 -} + 6 \mathrm{H} _{2} \mathrm{O} = \mathrm{C} _{6} \mathrm{H} _{12} \mathrm{O} _{6} + 12 \mathrm{SO} _{4} ^{2 -} \\ 6 \mathrm{CO} _{2} + 12 \mathrm{CH} _{3} \mathrm{CH(OH)CH} _{3} = \mathrm{C} _{6} \mathrm{H} _{12} \mathrm{O} _{6} + 12 \mathrm{CH} _{3} \mathrm{COCH} _{3} + 6 \mathrm{H} _{2} \mathrm{O} \end{array}
$$

4-2 生物化学中的标准态指 pH = 7，将 $E_{O_{2}/H_{2}O}^{0}$ 换成生物化学标准态 $E_{O_{2}/H_{2}O}^{0'}$

$$
E _{\mathrm{O} _{2} / \mathrm{H} _{2} \mathrm{O}} ^{0^{\prime}} = E _{\mathrm{O} _{2} / \mathrm{H} _{2} \mathrm{O}} ^{0} + \frac {R T}{n F} \ln p _{\mathrm{O} _{2}} [ \mathrm{H} ^{+} ] ^{4} = 1.23 + \frac {8.314 \times 298}{4 \times 96485} \ln (10^{- 7}) ^{4} = 0.816 \mathrm{V(1分)}
$$

无 ATP 合成过程的 NADP $^{+}$ 氧化水过程的标准吉布斯自由能变:

$$
E ^{0^{\prime}} = - 0.32 - 0.816 = - 1.136 \mathrm{V}
\Delta G ^{0^{\prime}} = - n F E ^{0^{\prime}} = - 2 \times (- 1.136) \times 96485 \times 10^{- 3} = 219.2 \mathrm{kJ} (\mathrm{molNADP} ^{+}) ^{- 1} (1 \text {分})
$$

题干中反应总的自由能变，和需要输入的光能：

$$
\Delta G _{t o t} ^{0^{\prime}} = 219.2 + 30.53 \times 1.5 = 265.0 \mathrm{kJ} (\mathrm{molNADP} ^{+}) ^{- 1}
E _{t o t} = \frac {265.0}{40 \%} = 662.5 \mathrm{kJ} (\mathrm{molNADP} ^{+}) ^{- 1} (2 \text {分})
$$

光的波长： $\lambda = \frac{nhcN_{\mathrm{A}}}{E_{tot}} = \frac{4\times 6.626\times 10^{-34}\times 2.998\times 10^{8}\times 6.022\times 10^{23}}{662.5\times 10^{3}}\times 10^{9} = 722.2\mathrm{nm}$ （1分），属于红光。

根据高中生物知识，叶绿素吸收红光和蓝紫光。

$$
E = \frac {m _{l} ^{2} h ^{2}}{8 \pi^{2} m r ^{2}}, m _{l} = 0, \pm 1, \pm 2, \dots
$$

4-3-2 将 18 个电子填入环形势箱能级中，HOMO 对应 $m_{l} = \pm 4$ ，LUMO 对应 $m_{l} = \pm 5$ （1 分）。联立可得：

$$
\Delta E = \frac {h c}{\lambda} = \frac {(5^{2} - 4^{2}) h ^{2}}{8 \pi^{2} m r ^{2}}
\sqrt {\frac {(5^{2} - 4^{2}) h \lambda}{8 \pi^{2} m c}} = 441 \mathrm{pm(1分)}
d = 2 r = 882 \mathrm{pm(1分)}
$$

若用题目给定数据 $\lambda = 662 \, nm$ ，同样算法可得到 d = 856 pm，也可得满分。
