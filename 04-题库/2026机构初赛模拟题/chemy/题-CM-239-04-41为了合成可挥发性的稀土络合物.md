# 题-CM-239-04-41为了合成可挥发性的稀土络合物

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-1-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（16 分）

**4-1** 为了合成可挥发性的稀土络合物，科学家制备了一种双金属醇盐 X。X 是通过 LaCl<sub>3</sub>和KAl(O<sup>i</sup>Pr)<sub>4</sub>在苯溶剂中以 1 : 3 的摩尔比反应得到。

**4-1-1** 写出制备化合物 X 的反应方程式。

**4-1-2** 已知 X 中所有 Al 的化学环境相同，画出 X 的结构。

**4-2** 近日，某科学家团队发现了一种具有特殊磁性的化合物，其晶体结构如下图所示。图中原子球从小到大依次代表 Se、La、Cs，其中 Cs 和 La 均填在 Se 构成的八面体空隙中。已知部分晶胞参数如下：α = β = 90°，γ = 120°。

![](images/787808283c9802724fe4f5a6d56c379b03db8a98306fed40a46b9951227f6dd6.jpg)

**4-2-1** 写出该晶体的结构基元与点阵型式。

**4-2-2** 已知其中一个 Se 原子的坐标为(0.6667,0.3333,0.0646)，写出其他 Se 原子的坐标。

**4-2-3** 已知晶体中所有的 Se-La 键键长相等，且 d(Se-La) = 3.035 Å，图中标出的 Se-La-Se 的键角为 94.31°。据此计算晶胞参数 a 和 c。

**4-2-4** 计算该晶体的密度。

**4-3** Yb 的配合物 配体 M 是一种常用的双齿配体，其结构如下图所示。Yb 作为一种镧系金属元素，其能与 M 形成稳定的配合物。配合物 Li(THF)M(记为 A)与 YbCl<sub>3</sub>以 1:1 的比例反应得到单核配合物 B，B 与 <sup>i</sup>Pr<sub>2</sub>NLi 在甲苯溶剂中反应得到双核配合物 C。已知 B 和 C 中Yb 均为 5 配位，B 中不含有 THF 配体，C 中 Yb 只有一种化学环境。

![](images/412335328967214f57895db37e6b0ee97a1746e016a5eb0c0e0effca98127099.jpg)

**4-3-1** 写出能体现结构特点的配合物 B 和 C 的分子式。

**4-3-2** 令人惊讶的是，配合物 B 与 <sup>i</sup>Pr<sub>2</sub>NLi 在 THF 溶剂中会得到双核配合物 D，D 在甲苯溶剂中反应会进一步转化为 C。已知 D 中只有一个 Yb 原子，画出 D 的结构。

**4-3-3** 解释为何配合物 B 与 <sup>i</sup>Pr<sub>2</sub>NLi 的反应在甲苯溶剂中生成配合物 C，而在四氢呋喃溶剂中却生成配合物 D。
