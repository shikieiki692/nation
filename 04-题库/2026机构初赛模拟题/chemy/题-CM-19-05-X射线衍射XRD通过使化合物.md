# 题-CM-19-05-X射线衍射XRD通过使化合物

## 题目

### 第 5 题 X-射线衍射乌龙 (占 13%)

X-射线衍射(XRD)通过使化合物的晶体样本衍射 X-射线得到衍射图案，并依此推断出原子精确的空间分布，堪称最强大的确定结构方式。然而，晶体结构无序常会给结构确定造成困难。但即使不存在无序，X-射线衍射仍非万无一失，原因如下：

(1) 氢原子散射能力弱，X-射线衍射通常无法确定氢原子的位置；

(2) 原子序数相近的原子具有相近的散射能力，X-射线衍射难以对其作出明确区分。

多数情况下，这些问题并不影响结构确定，但有时却会因此而推得错误的化学式，从而产生乌龙事件。5-1 在 1947 年，有人声称通过以下方式合成了四甲基铂，通过燃烧分析确定其化学式，并通过 X 射线衍射确定了其结构。

(1) 在氮气气氛下，以无苯己烷作为溶剂，使钠与二甲基汞发生反应得到黑色悬浮液。

(2) 加入三甲基碘化铂，在室温下搅拌 24 h。

(3) 依此加入正戊醇、乙醇、水进行处理。

(4) 分离出 ① 层，用 ② 干燥、过滤后蒸发至干。

(5) 向残留物中加入石油醚，静置 30 min 后将混合物过滤并缓慢浓缩，得到无色(白色)固体。

5-1-1 分别写出(1)、(2)中预期发生的反应的方程式。
5-1-2 将①补充完整，并从以下选项中选出最合理的一项填入②。
(a) $Na_{2}SO_{4}$ (b) $CuSO_{4}$ (c) $\mathrm{Mg(ClO_{4})_{2}}$ (d) 活性炭

5-1-3 通过 X-射线衍射发现得到的“四甲基铂”为四聚体结构，若忽略畸变则具有高对称性。作者也认为这一结构“似乎不太合理”，但随后又表示“这是唯一的可能”，并提出四中心二电子键进行解释。然而，作者在文章的实验部分还发现“与其他 M(CH₃)₄ 型化合物不同，Pt(CH₃)₄ 是一种结晶性物质，其在有机溶剂中的溶解度也低于其他 M(CH₃)₄ 型化合物”。这一系列问题在 1967 年重新被研究，由于“四甲基铂”受热易发生爆炸，研究人员对原文献中的燃烧分析可靠性产生了怀疑，重新进行燃烧分析后得到的数据为 C 14.33%, H 4.08%（质量分数）；据此推测，“四甲基铂”中除 Pt、C、H 元素外，还有氧(O)元素。结合以上信息，写出“四甲基铂”的真实化学式，并画出其四聚体的真实结构。

5-2 在 1991 年，有人声称将汽化得到的“裸”钴原子与五甲基环戊二烯(Cp\*H)反应，分离出中性产物 A、B、C，其中 B 与 C 使用了 X-射线衍射确定结构。

5-2-1 A 的分子式为 $\mathrm{CoC}_{20}\mathrm{H}_{31}$ ，满足 EAN 规则，无 Co-H 键；B 的式量为 523.5，画出 A、B 的结构。

5-2-2 C 也是一种新奇的产物，其中 Co-Co 键的键级通过 X 射线衍射确定的 Co-Co 间距离判断。然而，作者通过 ${}^{1}$ H NMR 光谱发现 C 呈顺磁性，与预期不符，但并没有怀疑 X 射线衍射确定的结构，以 “三线态的可能存在” 进行解释。后续的研究测得 C 的磁矩为 $1.8 \mu B$ ，计算 C 中未成对电子的个数。

5-2-3 化合物 C 奇怪的性质与奇特的结构使有研究人员在 1992 年重新进行了研究，原文献的质谱测定以 C 的分解告终。而研究人员经过尝试，使用极温和的电离条件（样品温度 $50^{\circ}C$ ，电子能量 10 eV）成功进行了 C 的质谱测定，发现其基峰为 m/z = 391。结合以上信息，画出 C 的真实结构。

5-2-4 研究人员发现原文献中 C 的 ${}^{1}$ H NMR 光谱与通过其他方式合成的 C 不符，而与另一种配合物 D 高度吻合，随后发现 D 为原反应产物混合物分离出 A 后的主要成分，但在原文献中并未被发现。D 的质谱的基峰出现在 m/z = 586 处，画出 D 的结构。

5-3-2 产物 E 的结构明显是不合理的，作者在文章标题中称这一结构“前所未有”。但事实上，问题出在了 X-射线衍射。仔细思考由 D 生成 E 的可能机理，画出产物 E 的真实结构。
