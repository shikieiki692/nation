# 题-CM-62-04-将和置于预先抽真空的特制5L

## 题目

### 第 4 题（11 分）

将 $0.100 { \mathrm { mol } } \mathrm { H } _{ 2 }$ 和 $0.100 \mathrm { molCl } _{ 2 }$ 置于预先抽真空的特制 5 L 密闭容器， 加热至 $2000 \mathrm { K }$ ， 体系达到平衡， 总压强为 6.70 bar $( 1 ~ \mathrm { bar } = 100 ~ \mathrm { kPa } )$ 。 体系中存在如下反应关系：

$\mathrm { Cl } _{ 2 } ( \mathbf { g } ) = 2 \mathrm { Cl } ( \mathbf { g } )$ $K _{ p 1 } = 0.576$ $\mathrm { H } _{ 2 } ( \mathrm { g } ) + \mathrm { Cl } _{ 2 } ( \mathrm { g } ) = 2 \mathrm { HCl } ( \mathrm { g } )$ $K _{ p 2 }$ $\mathrm { HCl } ( \mathbf { g } ) = \mathrm { H } ( \mathbf { g } ) + \mathrm { Cl } ( \mathbf { g } )$ $K _{ p 3 } = 2.23 { \times } 10^{ - 6 }$ $\mathrm { H } _{ 2 } ( \mathbf { g } ) = 2 \mathrm { H } ( \mathbf { g } )$ $K _{ p 4 }$

为使处理过程简洁方便，计算中务必使用如下约定符号！在平衡表达式中默认各分压项均除以标准分压。

![](images/07c1311f41898c8d6e96ed3af77950735b6c414259105abd982b4c8c86516f2d.jpg)
4-2-1 计算 $2000 \mathrm { K }$ 体系中 $\mathrm { H } _{ 2 } ( \mathbf { g } )$ 和 $\mathrm { Cl } _{ 2 } ( \mathbf { g } )$ 未分解时容器的总压。4-2-2 计算 $2000 \mathrm { K }$ 体系中所有物种的平衡压力(结果保留三位有效数字)。4-2-3 计算 $K _{ p 2 }$ 。4-2-4 计算 $K _{ p 4 }$ 。
3 计算Kp2。4-2-4 计算Kp4。

## 参考答案

4-2-1  $p_{0}=n_{0}RT/V=0.2\times8.314\times2000\div5\times10^{3}$ Pa=6.65 bar（2分）

4-2-2 由反应平衡可知 $x_{2}^{2}=0.576 x_{1} \cdots(1)$ (0.5 分), $x_{2}y_{2}=2.23 \times 10^{-6} z \cdots(2)$ (0.5 分)
由物料守恒可知 $2 x_{1}+x_{2}=2 y_{1}+y_{2} \cdots(3)$ (0.5 分)
由压强变化可知 $p_{t}-p_{0}=0.5 x_{2}+0.5 y_{2} \cdots(4)$ (0.5 分)
由体系总压可知 $x_{1}+x_{2}+y_{1}+y_{2}+z=p_{t} \cdots(5)$ (0.5 分)
由(1)可知 $x_{1}=x_{2}^{2}/0.576 \cdots(6)$
由(4)可知 $y_{2}=2(p_{t}-p_{0})-x_{2} \cdots(7)$
将(7)代入(2)可知 $z=x_{2}[2(p_{t}-p_{0})-x_{2}]/(2.23 \times 10^{-6}) \cdots(8)$ (0.5 分)
将(6)和(7)代入(3)可知 $y_{1}=x_{2}^{2}/0.576+x_{2}-(p_{t}-p_{0}) \cdots(9)$ (0.5 分)
将(6)(7)(8)(9)代入(5)得到方程 $2 x_{2}^{2}/0.576+(p_{t}-p_{0})+x_{2}[2(p_{t}-p_{0})-x_{2}]/(2.23 \times 10^{-6})=p_{t}$ (1 分)
代入数据解得 $x_{2}=0.0974$ bar (0.5 分)
则 $x_{1}=0.0165$ bar (0.5 分), $y_{1}=0.0651$ bar (0.5 分), $y_{2}=1.51 \times 10^{-4}$ bar (0.5 分), $z=6.62$



bar(0.5分)通过其他合理方法处理数据,得到合理结果的也可得分。

**4-2-3** 计算 $K_{p2}$ 。

**4-2-3** $K_{p2} = z^{2}/(x_{1}y_{1}) = 4.08 \times 10^{5}$ (1分)

**4-2-4** 计算 $K_{p4}$ 。

**4-2-4** $K_{p4} = K_{p2}K_{p3}^{2}/K_{p1} = 3.52 \times 10^{-7}$ (1分)
