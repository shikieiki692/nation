# 题-CM-62-04-将和置于预先抽真空的特制5L

## 题目

### 第 4 题（11 分）

将 $0.100 { \mathrm { mol } } \mathrm { H } _{ 2 }$ 和 $0.100 \mathrm { molCl } _{ 2 }$ 置于预先抽真空的特制 5 L 密闭容器， 加热至 $2000 \mathrm { K }$ ， 体系达到平衡， 总压强为 6.70 bar $( 1 ~ \mathrm { bar } = 100 ~ \mathrm { kPa } )$ 。 体系中存在如下反应关系：

$\mathrm { Cl } _{ 2 } ( \mathbf { g } ) = 2 \mathrm { Cl } ( \mathbf { g } )$ $K _{ p 1 } = 0.576$ $\mathrm { H } _{ 2 } ( \mathrm { g } ) + \mathrm { Cl } _{ 2 } ( \mathrm { g } ) = 2 \mathrm { HCl } ( \mathrm { g } )$ $K _{ p 2 }$ $\mathrm { HCl } ( \mathbf { g } ) = \mathrm { H } ( \mathbf { g } ) + \mathrm { Cl } ( \mathbf { g } )$ $K _{ p 3 } = 2.23 { \times } 10^{ - 6 }$ $\mathrm { H } _{ 2 } ( \mathbf { g } ) = 2 \mathrm { H } ( \mathbf { g } )$ $K _{ p 4 }$

为使处理过程简洁方便，计算中务必使用如下约定符号！在平衡表达式中默认各分压项均除以标准分压。

![](images/07c1311f41898c8d6e96ed3af77950735b6c414259105abd982b4c8c86516f2d.jpg)
4-2-1 计算 $2000 \mathrm { K }$ 体系中 $\mathrm { H } _{ 2 } ( \mathbf { g } )$ 和 $\mathrm { Cl } _{ 2 } ( \mathbf { g } )$ 未分解时容器的总压。4-2-2 计算 $2000 \mathrm { K }$ 体系中所有物种的平衡压力(结果保留三位有效数字)。4-2-3 计算 $K _{ p 2 }$ 。4-2-4 计算 $K _{ p 4 }$ 。
3 计算Kp2。4-2-4 计算Kp4。
