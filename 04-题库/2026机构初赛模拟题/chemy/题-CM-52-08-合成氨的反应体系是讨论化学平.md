# 题-CM-52-08-合成氨的反应体系是讨论化学平

## 题目

### 第 8 题（10 分）

合成氨的反应体系是讨论化学平衡时的常用反应体系，该反应式如下所示：

$$
\mathrm{N} _{2} (\mathrm{g}) + 3 \mathrm{H} _{2} (\mathrm{g}) = 2 \mathrm{NH} _{3} (\mathrm{g})
$$

$400^{\circ}\mathrm{C}$ 下，该反应 $K_{p} = 3.19 \times 10^{-4}$ 。现有一体积可变的恒压密闭容器，用活塞维持其总压恒定为 $4.408\mathrm{bar}(1\mathrm{bar} = 100\mathrm{kPa})$ 。在 $400^{\circ}\mathrm{C}$ 下，向其中通入 $3.00\mathrm{mol}$ 的 $\mathrm{H}_{2}$ 和 $1.00\mathrm{mol}$ 的 $\mathrm{N}_{2}$ ，

并加入催化剂使该反应得以进行并达到平衡。

8-1 合成氨反应是吸热反应还是放热反应，是熵增反应还是熵减反应？

8-2 请计算平衡时的容器体积和各种气体的分压大小。

8-3 若保持恒温恒压，向平衡后的体系中通入少量氢气，试从 $Q_{p}$ 和 $K_{p}$ 的角度讨论此时平衡移动的方向(无须精确计算)。

## 参考答案

第 8 题 （10 分）

8-1 放热反应 （1 分）； 熵减反应 （1 分）。

8-2
设平衡时 $\cdot$ 的分压为 $\cdot$ ， 则： $\cdot$ ； $-$ ；$-$ （1 分）
解得： $\cdot$ bar （1 分）
$p ( \mathrm { H } _{ 2 } ) = 3 p ( \mathrm { N } _{ 2 } ) = 3.325$ bar （1 分）
$p ( \mathrm { NH } _{ 3 } ) = p _{ \mathrm { total } } - p ( \mathrm { N } _{ 2 } ) - p ( \mathrm { H } _{ 2 } ) = 0.108 ~ \mathrm { ban }$ （1 分）
由氮的总量恒定： $n ( \mathrm { NH _{ 3 } } ) / 2 + n ( \mathrm { N _{ 2 } } ) = 1.00 ~ \mathrm { mol }$ 再由： $-$ 解得： $\cdot$ ； $n ( \mathrm { NH _{ 3 } } ) = 0.10 \mathrm { mol }$ ； 进而 $n ( \mathrm { H } _{ 2 } ) = 3 n ( \mathrm { N } _{ 2 } ) = 2.85 ~ \mathrm { mol }$ ；$-$ （2 分）
共6 分， 通过其他计算方法得到结果也可得分。

8-3 通入 $\mathrm { H } _{ 2 }$ ， $K _{ p }$ 不变， 氢气分压 $p ( \mathrm { H } _{ 2 } )$ 增大 $\cdot$ 减小； 由于容器体积膨胀， 氮气和氨气分压减小相同倍数， 故 $\cdot$ 减小； 因此 $Q _{ p }$ 整体减小， 平衡向右移动。 （2 分）
