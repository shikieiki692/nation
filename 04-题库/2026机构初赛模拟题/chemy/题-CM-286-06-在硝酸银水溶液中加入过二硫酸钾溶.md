# 题-CM-286-06-在硝酸银水溶液中加入过二硫酸钾溶

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-16-6`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（7 分）

在硝酸银水溶液中加入过二硫酸钾溶液，煮沸反应，析出抗磁性黑色氧化物。该氧化物中，每个氧原子均与 3 个银原子配位；银为 dsp<sup>2</sup>杂化和 sp 杂化，其数目比为 1 : 1。

**6-1** 写出该氧化物的化学式以及制备该氧化物的化学反应方程式。

**6-2** 将该氧化物投入硝酸中完全溶解，发生氧化还原反应，得到顺磁性溶液，无气体放出。写出化学反应方程式。

**6-3** 该氧化物溶于硝酸所得到的溶液不稳定，室温下会缓慢放出气体。写出化学反应方程式。

## 参考答案

**6-1** Ag<sup>I</sup>Ag<sup>III</sup>O<sub>2</sub>（或答 AgO）（1 分）

K<sub>2</sub>S<sub>2</sub>O<sub>8</sub> + 2AgNO<sub>3</sub> + 2H<sub>2</sub>O = 2AgO + 2HNO<sub>3</sub> + 2KHSO<sub>4</sub>（2 分）

或：K<sub>2</sub>S<sub>2</sub>O<sub>8</sub> + 2AgNO<sub>3</sub> + 2H<sub>2</sub>O = 2AgO + K<sub>2</sub>SO<sub>4</sub> +2HNO<sub>3</sub> + H<sub>2</sub>SO<sub>4</sub>

或：S<sub>2</sub>O<sub>8</sub><sup>2-</sup> + 2Ag<sup>+</sup> + 2H<sub>2</sub>O = 2AgO + 4H<sup>+</sup> + 2SO<sub>4</sub><sup>2-</sup>

**6-2** AgO + 2HNO<sub>3</sub> = Ag(NO<sub>3</sub>)<sub>2</sub> + H<sub>2</sub>O（2 分）

或：AgO + 2H<sup>+</sup> = Ag<sup>2+</sup> + H<sub>2</sub>O

**6-3** 4Ag(NO<sub>3</sub>)<sub>2</sub> + 2H<sub>2</sub>O = 4AgNO<sub>3</sub> + 4HNO<sub>3</sub> + O<sub>2</sub>（2 分）

或：4Ag<sup>2+</sup> + 2H<sub>2</sub>O = 4Ag<sup>+</sup> + 4H<sup>+</sup><sub> </sub>+ O<sub>2</sub>
