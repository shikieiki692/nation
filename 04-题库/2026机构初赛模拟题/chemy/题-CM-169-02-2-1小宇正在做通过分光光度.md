# 题-CM-169-02-2-1小宇正在做通过分光光度

## 题目

### 第 2 题

第 2 题 （26 分， 占 $13 \%$ ） 分光光度法的应用分光光度法是一种灵敏的分析方法，可以测定较低的化合物浓度。这种方法基于分子对特定波长光的吸收，而这种吸收与特定的电子跃迁有关。Lambert-Beer 定律描述了吸光度与化合物浓度之间的关系： $\begin{array} { r } { A = \lg \frac { I _{ 0 } } { I } = \varepsilon l c = \sum _{ i } \varepsilon _{ i } c _{ i } l } \end{array}$ ， 其中 $\mathcal { A }$ 为吸光度，I 和 $\overline { { I _{ 0 } } }$ 分别是透射光和入射光的强度， $\varepsilon$ 为摩尔消光系数，l 为光通过的路径长， $\boldsymbol { \mathbf { \mathit { c } } }$ 为溶液浓度。

## 2-2-2-1 b) (2 分)

## 2-2-2-2 共 11 分，本问不要求有效数字。

由 Lambert-Beer 定律和表格，对溶液 2 有：

$$
\begin{array}{l} A _{2} (260 \mathrm{nm}) = (\varepsilon_{260} (\mathrm{NADH}) \cdot c (\mathrm{NADH}) + \varepsilon_{260} (\mathrm{NAD} ^{+}) \cdot c (\mathrm{NAD} ^{+})) \cdot l \\ A _{2} (340 \mathrm{nm}) = (\varepsilon_{340} (\mathrm{NADH}) \cdot c (\mathrm{NADH}) + \varepsilon_{340} (\mathrm{NAD} ^{+}) \cdot c (\mathrm{NAD} ^{+})) \cdot l \end{array}
$$

对溶液 3 有:

$$
A _{3} (260 \mathrm{nm}) = \varepsilon_{260} (\mathrm{NADH}) \cdot c (\mathrm{NADH}) \cdot l
A _{3} (340 \mathrm{nm}) = \varepsilon_{340} (\mathrm{NADH}) \cdot c (\mathrm{NADH}) \cdot l (\text {正确写出以上四个方程得} 2 \text {分})
$$

由 $NAD^{+}$ 与 NADH 的紫外-可见吸收光谱可知:

$$
\begin{array}{r l} & \varepsilon_{340} (\mathrm{NAD} ^{+}) = 0 (1 \text {分}) \\ & \varepsilon_{260} (\mathrm{NADH}) = \varepsilon_{260} (\mathrm{NAD} ^{+}) (1 \text {分}) \end{array}
$$

由物料守恒：

$$
c (\mathrm{NADH}) + c \left(\mathrm{NAD} ^{+}\right) = c (\text {溶液} 2) = c (\text {溶液} 1) \cdot 5.0 / 1000 = 1.25 \cdot 10^{- 4} \mathrm{M} (1 \text {分})
$$

则有

$$
\begin{array}{r l} \varepsilon_{260} (\mathrm{NADH}) & = \varepsilon_{260} (\mathrm{NAD} ^{+}) = A _{2} (260 \mathrm{nm}) / [ (c (\mathrm{NADH}) + c (\mathrm{NAD} ^{+})) \cdot l ] = 15700 \mathrm{M} ^{- 1} \cdot \mathrm{cm} ^{- 1} \\ \varepsilon_{340} (\mathrm{NADH}) & = A _{3} (260 \mathrm{nm}) \cdot \varepsilon_{340} (\mathrm{NADH}) / A _{3} (340 \mathrm{nm}) = 6500 \mathrm{M} ^{- 1} \cdot \mathrm{cm} ^{- 1} (1 \text {分}) \end{array}
$$

因此

$$
\begin{array}{r l} & c (\mathrm{NADH}) = A _{2} (340 \mathrm{nm}) / (\varepsilon_{340} (\mathrm{NADH}) \cdot l) = 10^{- 4} \mathrm{M} \\ & c (\mathrm{NAD} ^{+}) = 1.25 \cdot 10^{- 4} \mathrm{M} - 10^{- 4} \mathrm{M} = 0.25 \cdot 10^{- 4} \mathrm{M} \end{array}
$$

则在溶液 1 中有:

$$
c \left(\mathrm{NAD} ^{+}\right) = 5.0 \mathrm{mM} (1 \text {分}), c (\mathrm{NADH}) = 20.0 \mathrm{mM} (1 \text {分})
$$

对溶液 3 有:

$$
c (\mathrm{NADH}) = A _{3} (260 \mathrm{nm}) / \left(\varepsilon_{260} (\mathrm{NADH}) \cdot l\right) = 0.133 \mathrm{mM} (1 \text {分})
$$

因此稀释倍数为:

$$
k = c _{0} (\mathrm{NADH}) / c (\mathrm{NADH}) = 4.0 / 0.133 = 30 (1 \text {分})
$$

若采用其他计算方法，过程合理且结果正确也可得满分。

2-2-2-3 共 3 分，本问不要求有效数字。

由 $A = \lg \frac{I_0}{I}$ 和 $T = \frac{I}{I_0}$ 可知 $A = -\lg T$ ，则 $A_{min} = 4.36 \cdot 10^{-3}$ （1分）

由 $NAD^{+}$ 与 NADH 的紫外-可见吸收光谱可知 $\varepsilon_{max} = 15700 M^{-1} \cdot cm^{-1}$ （1 分）

则有 $c(\mathrm{NAD})_{\min}=A_{\min}/\varepsilon_{\max}\cdot l=5.6\cdot10^{-7}\mathrm{M}$ （1分）
