# 题-CM-241-04-钒的salen配合物能体现出丰富

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-5-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（19 分）

钒的 salen 配合物能体现出丰富的氧化还原化学。

**4-1** 将等摩尔的乙酰丙酮钒(III)和 H<sub>2</sub>salen（结构如下所示）的甲醇溶液混合，在开放容器中搅拌过夜，洗涤后可以高于 95%的产率得到绿色晶体 A。将 A 溶于乙腈，溶液中置入一张洁净的铂纱网，用 Ar 吹扫 20 min 后缓慢加入等当量 CF<sub>3</sub>SO<sub>3</sub>H，再通入 H<sub>2</sub>直到反应完成。除去溶液后得到含结晶溶剂的 B，元素分析指出其含 V 量为 9.29%，含 S 量为 5.846%，含N 量为 10.22%。画出 A 的结构，计算给出 B 的化学式。

![](images/224cb66f875bfc1d2b922223e430072c92eb79b801c43f19637e15e67586ad8d.jpg)![](images/d6911b5053c406cfafef2a6f760f2a6d6ea2bb0056222ad332966d49793fc5d6.jpg)

组氧化还原电对，电对的电极电势为上升曲线的中点所对应的电势。以(1)为例，该台阶对应A 被氧化的半反应：

A → [A]<sup>+</sup> + e<sup>-</sup>

**4-2-1** 已知在(2)(3)(4)曲线对应体系检测到水，写出 A 歧化的反应方程式。

**4-2-2** 测得曲线(2)中两个台阶电对的电极电势分别为 0.65 V 和 0.90 V，尝试计算该条件下无外加电压时体系平衡状态下所有物种的浓度。

**4-3** 向含有足量氧气的乙腈溶液中加入含[V(salen)]<sup>+</sup>的溶液发生反应，研究提出了如下机理：

[V(salen)]<sup>+</sup> + O<sub>2</sub> = [O<sub>2</sub>V(salen)]<sup>+</sup> k<sub>1</sub>, k<sub>-1</sub>

[O<sub>2</sub>V(salen)]<sup>+</sup> + [V(salen)]<sup>+</sup> = [(salen)VOOV(salen)]<sup>2+</sup> k<sub>2</sub>

[(salen)VOOV(salen)]<sup>2+</sup> = 2[VO(salen)]<sup>+</sup> fast

**4-3-1** 使用稳态近似推导产物的生成速率。

**4-3-2** 实验测定发现该反应对[V(salen)]<sup>+</sup>为一级，提出假设以修正 4-3-1 得出的速率方程式。

## 参考答案

![](images/1c4f9cba075ebc5f0b2fbdc8dfa46e7267cecdfcd3a59e7793fe88fb74d1da7e.jpg)

**4-2-1** 2VO(salen) + 2H<sup>+</sup> → [VO(salen)]<sup>+</sup> + [V(salen)]<sup>+</sup> + H<sub>2</sub>O（3 分）

**4-2-2** 歧化反应电动势为 E = Δφ = 0.90 – 0.65 = 0.25 (V)，由 ΔG = -zEF = -RTlnK，可得K° = exp(zEF / RT) = exp[1 × 0.25 × 96485 / (8.314 × 298.15)] = 1.7 × 10<sup>4</sup> （2 分）由于溶剂为乙腈，需要计算反应生成的水的浓度。设平衡时[VO(salen)<sup>+</sup>] = [V(salen)<sup>+</sup>] = [H<sub>2</sub>O] = x mmol/L K° = [VO(salen)<sup>+</sup>][V(salen)<sup>+</sup>][H<sub>2</sub>O]c° / [VO(salen)]<sup>2</sup>[H<sup>+</sup>]<sup>2</sup> = 1000x<sup>3</sup> / (1 – 2x)<sup>4</sup>解得 x = 0.38（2 分）则平衡时有[VO(salen)CF<sub>3</sub>SO<sub>3</sub>] = [V(salen)CF<sub>3</sub>SO<sub>3</sub>] = [H<sub>2</sub>O] = 0.38 mmol/L，[VO(salen)] = [CF<sub>3</sub>SO<sub>3</sub>H] = 0.24 mmol/L（2 分）

**4-3-1** 设氧复合物 O<sub>2</sub>V(salen)<sup>+</sup>处于稳态，则d[O<sub>2</sub>V(salen)<sup>+</sup>]/dt = k<sub>1</sub>[V(salen)<sup>+</sup>]p(O<sub>2</sub>) – k<sub>-1</sub>[O<sub>2</sub>V(salen)<sup>+</sup>] – k<sub>2</sub>[O<sub>2</sub>V(salen)<sup>+</sup>][V(salen)<sup>+</sup>] = 0 [O<sub>2</sub>V(salen)<sup>+</sup>] = k<sub>1</sub>[V(salen)<sup>+</sup>]p(O<sub>2</sub>) / (k<sub>-1</sub> + k<sub>2</sub>[V(salen)<sup>+</sup>])由于最后一步转化为 fast，则有 d[VO(salen)<sup>+</sup>]/dt = 2d[(salen)VOOV(salen)<sup>2+</sup>]/dt故 d[VO(salen)<sup>+</sup>]/dt = 2k<sub>2</sub>[O<sub>2</sub>V(salen)<sup>+</sup>][V(salen)<sup>+</sup>] = 2k<sub>1</sub>k<sub>2</sub>[V(salen)<sup>+</sup>]<sup>2</sup>p(O<sub>2</sub>) / (k<sub>-1</sub> + k<sub>2</sub>[V(salen)<sup>+</sup>])（4 分）

**4-3-2** 当 k<sub>2</sub>[V(salen)<sup>+</sup>] >> k<sub>-1</sub>时，有d[VO(salen)<sup>+</sup>]/dt = 2k<sub>1</sub>k<sub>2</sub>[V(salen)<sup>+</sup>]<sup>2</sup>p(O<sub>2</sub>) / k<sub>2</sub>[V(salen)<sup>+</sup>] = 2k<sub>1</sub>[V(salen)<sup>+</sup>]p(O<sub>2</sub>)（2 分）
