# 题-CM-66-01-含金属M的不溶于水的黑色粉末

## 题目

### 第 1 题（9 分）

含金属 M 的不溶于水的黑色粉末状氧化物 A， 溶于浓硫酸后可得到溶液 B， 并伴随有无色气体 C 溢出。在无氧条件下向 B 的水溶液中加入强碱，生成白色沉淀 D， 该沉淀不稳定，易被空气氧化生成棕色沉淀 E。若将 A 与 KOH 和 $\mathrm { KClO } _{ 3 }$ 混合加热熔融可得到一深绿色物质F。F 溶于水后， 向溶液中通入 $\mathrm { CO } _{ 2 }$ ， 则溶液变为紫色，其主要溶质为G，同时析出黑色沉淀A。

1-1 写出 $\Delta \sim G$ 所代表物质的化学式。

1-2 在 CO 氛围中， $\mathbf { Mg }$ 与 $\boldsymbol { \mathsf { M } } _{ 2 }$ 反应， 得到了一种金黄色晶体 H， 实验测得其为反磁性。 画出H 的结构。
