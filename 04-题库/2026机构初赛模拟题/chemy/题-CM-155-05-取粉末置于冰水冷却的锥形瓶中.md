# 题-CM-155-05-取粉末置于冰水冷却的锥形瓶中

## 题目

### 第 5 题 14 分， 占比 $9 \%$

取 $2.5 \mathrm { g } \mathrm { KClO } _{ 3 }$ 粉末置于冰水冷却的锥形瓶中，加入 $5.0 \ \mathrm { g }$ 研细的 $\mathrm { I } _{ 2 }$ ，再注入 $3 \mathrm { cm } ^{ 3 }$ 水，在 45分钟内不断振荡，分批加入 $9 \sim 10 \mathrm { cm } ^{ 3 }$ 浓盐酸，直到 $\mathrm { I } _{ 2 }$ 完全消失为止（整个反应过程保持在$40^{ \circ } \mathrm { C }$ 以下）。将锥形瓶置于冰水中冷却，得到橙黄色的晶体 A。 $\pmb { \mathsf { A } }$ 与三氯化铝化合可得到红色晶体B，B 为 1 : 1 型盐，其阳离子遇水会发生水解(反应 1)。晶体 $\pmb { \mathsf { A } }$ 在熔融状态下即会离解为二元化合物 C 和单质 D。C 与 KCl 在水溶液中反应可得到盐 E， $D$ 与 E 充分反应后干燥可制得盐 F(反应 2)； $\pmb { \mathsf { A } }$ 与PCl5 反应则会得到盐 $\pmb { 6 }$ (反应 3)，F 与 $\pmb { 6 }$ 的阴离子相同。
盐G(反应3)，F 与G 的阴离子相同。5-1

5-1 写出 A、B、E 的化学式， 并分别指出碘中心的构型及杂化方式。

5-2 写出反应 $1 \sim$ 反应 3 反应方程式(需表示出F 和 $\pmb { 6 }$ 的具体组成)。

## 参考答案

## 第 5 题（14 分，占比 9%）

5-1 共 9 分，化学式各 1 分，各物种的构型、杂化方式各 1 分。

A $I_{2}Cl_{6}$ 构型：平面四边形 杂化方式： $sp^{3}d^{2}$ 杂化

B $[ICl_{2}][AlCl_{4}]$ 构型：V 字型 杂化方式： $sp^{3}$ 杂化

E KICl₂ 构型：直线型 杂化方式：sp³d 杂化

5-2 反应 1: $5 \mathrm{ICl}_{2}^{+} + 9 \mathrm{H}_{2} \mathrm{O} = \mathrm{I}_{2} + 3 \mathrm{IO}_{3}^{-} + 18 \mathrm{H}^{+} + 10 \mathrm{Cl}^{-}$ (2 分)

反应 2: $KICl_{2} + Cl_{2} = KICl_{4}$ (1 分)

反应 3: $2PCl_{5} + I_{2}Cl_{6} = 2[PCl_{4}][ICl_{4}]$ (2 分)
