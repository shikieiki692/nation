# 题-CM-292-04-有人设计了一种利用固体以期改变效

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-22-4`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（13 分）

有人设计了一种利用固体以期改变效率的新型热机(如下左图)。该热机工作于高温热源 T<sub>H</sub> = 373.15 K 和低温 T<sub>L</sub> = 298.15 K 间；A 为位置可变的导热活塞，B 为位置固定的导热隔板；A、B 间装有 n = 10.00 mol N<sub>2 </sub>(视为理想气体)；B 以下为固体物质 S(以及真空)，S 与导热隔板接触。初始状态时，体系温度(包括 N<sub>2</sub>和 S)T<sub>1</sub> = T<sub>L</sub> = 298.15 K；N<sub>2</sub>分压 p<sub>1</sub> = 101.3 kPa。热机经历以下三步骤进行工作(如下右图)：(1)在绝热条件下进行可逆压缩，体系温度升至 T<sub>2</sub> = T<sub>H</sub> = 373.15 K；N<sub>2</sub>分压升至 p<sub>2</sub> = 300.0 kPa；(2)使体系与高温热源 T<sub>2</sub>接触并进行等温可逆膨胀；(3)取出 S；在绝热条件下进行可逆膨胀，使 N<sub>2</sub>回到 298.15 K, 101.3 kPa 的状态。

![](images/86f1ae81625b1b35a0760df37fd5ee5186194e99d74de0cd3c3194249ba67211.jpg)![](images/91fc9d47c8c5f739d720ae3e457a039caf95280f9d5233203c4d2cc6dd4423f9.jpg)

**4-1** 分别计算步骤(1) ~ (3)的功 W<sub>1</sub>、W<sub>2</sub>、W<sub>3</sub>；计算 S 的热容 C<sub>S</sub>及体系从外界吸收的热量 Q。

**4-2** 定义 η<sub>1</sub> = –(W<sub>1</sub> + W<sub>2</sub> + W<sub>3</sub>) / Q，计算 η<sub>1</sub>；计算在 T<sub>H</sub> = 373.15 K 和 T<sub>L</sub> = 298.15 K 之间运作的卡诺热机的效率 η<sub>2</sub>。

**4-3** 判断体系经历完整的三步骤(1)、(2)、(3)的可逆性并说明理由。

**4-4** 奥托循环是由绝热可逆压缩→恒容可逆升温→绝热可逆膨胀→恒容可逆降温四步构建的循环；对于一定量理想气体 N<sub>2</sub>，设压缩前后体积分别为 V<sub>1</sub>和 V<sub>2</sub>，推出奥托热机的效率 η<sub>3</sub>。

## 参考答案

**4-1** 步骤(1)对体系而言是绝热过程，δQ = 0；根据热力学第一定律 dU = δW + δQ，有：

dU<sub>N2</sub> + dU<sub>S</sub> = δW

nC<sub>V,m</sub>dT + C<sub>S</sub>dT = –pdV

![](images/dfba8219d436fef4e92ea26f1c95ff32ba011bee92b80097e0a0861a2f4e1dc9.jpg)

积分，得：

![](images/ba2850ecb22938576b3fc1002e8fed381e5c2536ce2d1b365a24d13e8514150f.jpg)

T·V<sup>α–1</sup> =<sub> </sub>常数联系理想气体状态方程 pV = nRT，又有：

p·V<sup>α</sup> =<sub> </sub>常数（1 分）

p<sup>1–α</sup>·T<sup>α</sup> =<sub> </sub>常数

(101.3 kPa)<sup>1–α</sup> × (298.15 K)<sup>α</sup> = (300.0 kPa)<sup>1–α</sup> × (373.15 K)<sup>α</sup>其合理解为：

α = 1.2606

![](images/6f79331f48cefc8ee59319033e1a022de4afc8a570cd58383ceba942f4679454.jpg)

C<sub>S</sub> = 111.2 J/K（1 分）绝热步骤(1)的 Q<sub>1</sub> = 0，做功 W<sub>1</sub>完全转化为 N<sub>2</sub>和 S 的内能，因此：

W<sub>1</sub> = ΔU<sub>1</sub> – Q<sub>1</sub> = ΔU<sub>1</sub> = (nC<sub>V,m</sub> + C<sub>S</sub>)(T<sub>H</sub> – T<sub>L</sub>)

![](images/be28f95b77fb3a62bf83ecf671d0baa1bc3ce0c99690624d4fcb5f181b3407c2.jpg)

= 23.93 kJ（1 分）步骤(2)为等温膨胀，N<sub>2 </sub>末压可由步骤(3)的方程确定。(3)为绝热可逆膨胀，其状态方程为：

p<sup>1–γ</sup>·T<sup>γ</sup> =<sub> </sub>常数

p<sub>3</sub><sup>–2/5</sup> × (373.15 K)<sup>7/5</sup> = (101.3 kPa)<sup>–2/5</sup> × (298.15 K)<sup>7/5</sup>解得：

p<sub>3</sub> = 222.9 kPa（1 分）W<sub>2</sub>的值为：

![](images/d672fd6ad32b20efac7b7e7b19b5b36df7375210a04c9638b0c1d9b6f8343f3a.jpg)

= – 9.216 kJ（1 分）步骤(1)和(3)为绝热过程，Q<sub>1</sub> = Q<sub>3</sub> = 0；步骤(2)中 N<sub>2</sub>和 S 的温度均不变，故 ΔU<sub>2</sub> = 0，因此：Q = Q<sub>1 </sub>+ Q<sub>2</sub> + Q<sub>3</sub> = Q<sub>2</sub> = ΔU<sub>2</sub> – W<sub>2</sub> = –W<sub>2</sub> = 9.216 kJ（1 分）步骤(3)为绝热过程，Q<sub>3</sub> = 0；故 W<sub>3</sub>的值为：W<sub>3</sub> = ΔU<sub>3</sub> – Q<sub>3</sub> = ΔU<sub>3</sub> = nC<sub>V,m</sub>(T<sub>L</sub> – T<sub>H</sub>)

![](images/20304fa3d194675c852c4bcfde700264d5ae145272597f4c0bf36829cda91e46.jpg)

= –15.58 kJ（1 分）

**4-2** η<sub>1</sub> = –(W<sub>1</sub> + W<sub>2</sub> + W<sub>3</sub>) / Q = –(23.93 kJ – 9.216 kJ –15.58 kJ) / 9.216 kJ = 9.40%（1 分）η<sub>2</sub> = (T<sub>H</sub> – T<sub>L</sub>) / T<sub>H</sub> = 20.10%（1 分）若使用自己求出的错误的 W<sub>1</sub> ~ W<sub>3</sub>数值进行计算 η<sub>1</sub>，结果在 0 ~ 20.10%之间，也得分。

**4-3** 是可逆的，因为步骤(1)、(2)、(3)均是可逆过程。（1 分）不能用 η<sub>1</sub> < η<sub>2</sub>判定该过程是不可逆过程。因为经历步骤(1)、(2)、(3)前后，固体 S 的温度不同，亦即实际上(1)、(2)、(3)并非一个完整的循环，不能直接与完整循环的卡诺热机对比。

**4-4** 奥托循环中在高温和低温热源的热量变化分别为：

Q<sub>1</sub> = C<sub>V</sub>(T<sub>3</sub> – T<sub>2</sub>) （0.5 分）Q<sub>2</sub> = C<sub>V</sub>(T<sub>4</sub> – T<sub>1</sub>) （0.5 分）因此奥托循环效率为：
