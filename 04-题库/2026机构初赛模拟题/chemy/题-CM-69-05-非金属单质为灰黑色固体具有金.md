# 题-CM-69-05-非金属单质为灰黑色固体具有金

## 题目

### 第 5 题（12 分）

非金属单质 $\pmb { \mathsf { A } }$ 为灰黑色固体，具有金属光泽。 $\pmb { \mathsf { A } }$ 与黄绿色气体 B 加热反应， 得到白色固体C，C 在固态为四聚体，具有立方体结构，但在气态为单体；将C 与 $\pmb { \mathsf { A } }$ 在无水乙醚中混合反应，可制得黑色固体D，D 不稳定，受热易歧化；C 与过量 $\mathrm { CH } _{ 3 } \mathrm { Li }$ 在乙醚中反应，得到橙黄色液体 E；E 与 $\mathrm { XeF } _{ 2 }$ 在惰性气氛中反应得到 F，F 与等量 $Z \mathrm { n } ( \mathrm { CH } _{ 3 } ) _{ 2 }$ 反应得到 $\pmb { 6 }$ ， $\pmb { 6 }$ 为白色固体，易分解。将 $0.2495 { \textbf { g } } \mathbf { G }$ 用过量的溴单质处理， 产生H 和 $\mathrm { CH } _{ 3 } \mathrm { Br }$ ； 将产生的H 溶于过量硝酸并加热反应， 得到 $0.1825 \mathrm { g }$ 氧化物 I。
量Zn(CH3)2 反应得到G，G 为白色固体，易分解。将0.2495 g G 用过量

5-1 写出 $\mathsf { \pmb { A } } \sim \mathsf { \pmb { I } }$ 的化学式。
5-2 写出D 受热歧化的化学反应方程式。
5-3 分别画出C 的四聚体和单体的结构示意图。
5-4 室温下E 的 $^ 1 \mathrm { H }$ -NMR 谱显示，E 中的氢原子只有一种化学环境，这与VSEPR 理论的预
测结果不符。 请给出合理的解释。
