# 题-CM-60-19-在某溶剂中亲核取代反应可能以

## 题目

### 第 19 题 一道基础的实验设计题，用于掌握对 $S_{N}1$ 和 $S_{N}2$ 基础知识的了解。（6 分）

在某溶剂中，亲核取代反应 $\mathrm{PhCH_2Cl + OH^- \rightarrow PhCH_2OH + Cl^-}$ 可能以 $\mathrm{S_N1}$ 或 $\mathrm{S_N2}$ 的机理进行。请至少设计三种不同的实验，以确定该反应实际采取哪种机理。简要写出实验方案、预期结果和所得结论(不考虑两种机理同时进行的情形)。

## 参考答案

本题为开放性试题，只要方案合理均可得分。以下几种方案供参考：方案一：增大氢氧根离子的浓度，测定反应速率的变化。若反应速率明显增加，则该反应可能为 $\cdot$ 机理；若反应速率基本不变，则该反应可能为SN2 机理。方案二：将底物亚甲基上的一个氢换成D，使用光学活性的底物进行实验，测定产物的旋光性。若产物有旋光性，则该反应可能为 SN2 机理；若产物无旋光性，则该反应可能为$\cdot$ 机理。（注：不建议换成甲基或其他基团，因为这可能导致反应机理发生变化。）方案三：用弱的吸电子基（给电子基）取代底物中氯甲基间或对位的氢进行实验，测定反应速率的变化。若反应速率明显降低（升高），则该反应可能为 $\cdot$ 机理；否则，该反应可能为 $\mathrm { S } _{ \mathrm { N } } 2$ 机理。（注：改变苯环上的取代基可能导致反应机理发生变化， 因此， 可以分别用不同的基团取代，进行多组实验，这样得出的结论更为严谨。）（共6 分）
