# 题-CM-167-06-蛋白质是一类最重要的生物大分

## 题目

### 第 6 题

# 第 6 题 （27 分， $14 \%$ ） 生命化学中的核心物质

蛋白质是一类最重要的生物大分子，英文名为 protein，源自希腊文προτο， 它是“最原初的”，“第一重要的”意思。蛋白质在生物体内占有特殊的地位。
蛋白质的基本结构的氨基酸，多个氨基酸通过肽键结合成蛋白质。

6-1 普通的氨基酸形成的肽键为 Z 式构型， 而脯氨酸（四氢吡咯-2-羧酸） 并不具有此类优势。 解释原因。

6-2 蛋白质主链的构型与构象决定了它的折叠方式。蛋白质主链具有极性的 $\scriptstyle { \mathrm { C = O } }$ 与 N-H 基团，为亲水结构，而氨基酸侧链多具有疏水结构，因此，它难以像嵌段共聚物与磷脂一样形成简单的聚合结构。

6-2-1 据此， 指出蛋白质折叠过程中的主要作用力， 指出相比于磷脂，蛋白质维持主链构象稳定性的关键作用。

6-2-2 分别指出形成氢键与生物体中形成盐键、疏水作用时 $\Delta \mathrm { H } , \ \Delta \mathrm { S }$ 的情况 （ ${ \mathrm { > } } 0$ ， ${ < } 0$ 或不能判断）。
