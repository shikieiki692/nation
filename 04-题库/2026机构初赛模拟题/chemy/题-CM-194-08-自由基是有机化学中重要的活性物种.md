# 题-CM-194-08-自由基是有机化学中重要的活性物种

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-3-8`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 8 题（21 分，占 15%）

自由基是有机化学中重要的活性物种，可以参与多样的反应。其中，氮自由基和氧自由基由于其高电负性具有很高的活性，相比碳自由基寿命更短，反应模式也更多样。

**8-1** 康奈尔大学的 Lin Song 团队发现，两个大位阻的自由基会因为空间位阻的排斥而无法复合，而会形成受阻自由基对，通过自由基途径发生后续反应。根据这个思路，他们设计了一种新型的 sp<sup>3</sup>碳原子上 C-H 键活化的策略。

![](images/8f1fff6b35bd1d3c5d36250d66a14219a14f6fc5f5eb77cd6f1b678dc58df37c.jpg)

**8-1-1** 写出体系中生成的受阻自由基对的结构，并通过方程式分别表示它们的作用

**8-1-2** 写出 A 生成产物的关键中间体和过渡态。

**8-2** Stahl 等人利用类似的思路，使用二叔丁基过氧化物并借助镍的自由基分选实现了 sp<sup>3 </sup>C- H 键的活化与甲基化。提示：二叔丁基过氧化物在光敏剂的作用下发生均裂。

![](images/95ae9dfc1950df9cbcf033dd86a54a25fe169d5ad6f97187eeb24aea3d1b29b8.jpg)

**8-2-1** 产物的核磁氢谱：7.78 (dd, J = 5.4, 3.1 Hz, 2H), 7.68 (dd, J =5.4, 3.0 Hz, 2H), 7.25–7.19 (m, 4H), 7.10 (tt, J = 7.5, 1.6 Hz, 1H), 3.68–3.56 (m, 2H), 2.78 (dp, J = 8.9, 6.9 Hz, 1H), 2.09 (dtd, J = 13.6, 8.6, 6.9 Hz, 1H), 1.92 (ddt, J = 14.1, 8.3, 5.9 Hz, 1H), 1.29 (d, J = 7.0 Hz, 3H) 画出产物的结构。

**8-2-2** 写出各基元反应的方程式（标明结构）以说明产物是如何生成的

**8-3** 利用类似的思路，Lin Song 课题组开发了三级醇的氧化官能团化方法，可以合成多样的化学骨架。（加料顺序：KHMDS 与二苯酮溶于三氟甲苯，滴加入三级醇与 TEMPO<sup>+</sup>的三氟甲苯溶液；先将 KHMDS/二苯酮与三级醇混合再加入 TEMPO<sup>+</sup>也可以得到相同的结果）

![](images/395c3d3e219aa5e4819280c327ecec8825dceca60810da3ed4172d79c0f0f155.jpg)

**8-3-1** 写出 X 的结构与涉及的关键中间体。提示：产物的核磁共振氢谱：7.97 (d, J = 7.7 Hz, 2H), 7.55 (t, J = 7.4 Hz, 1H), 7.46 (t, J = 7.7 Hz, 2H), 3.74 (t, J = 6.5 Hz, 2H), 2.98 (t, J = 7.4 Hz, 2H), 1.77 (p, J = 7.5 Hz, 2H), 1.57 (dt, J = 8.6, 6.4 Hz, 3H), 1.52–1.39 (m, 6H), 1.35–1.28 (m, 1H), 1.14 (s, 6H), 1.08 (s, 6H).
