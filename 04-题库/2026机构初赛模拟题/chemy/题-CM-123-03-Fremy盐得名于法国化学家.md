# 题-CM-123-03-Fremy盐得名于法国化学家

## 题目

### 第 3 题（10 分）

Fremy 盐得名于法国化学家 E. Frémy，其化学式为 $\mathrm{K}_{2}[\mathrm{NO}(\mathrm{SO}_{3})_{2}]$ ，是一种较为稳定的自由基负离子盐，可溶于水。为合成 Fremy 盐，在冰浴冷却下，向 $KNO_{2}$ 和 $KHCO_{3}$ 的混合溶液中通入稍过量的 $SO_{2}$ ，充分反应，制得 2:1 型钾盐 A 的水溶液(反应 1)。A 经过单电子转移反应即得 Fremy 盐：一种方法是，将 A 置于 NaOH 水溶液中进行电解，此时一电极产生该盐阴离子(反应 2)，另一电极放出气体(反应 3)；另一种方法是，向 A 的氨-氯化铵溶液(pH ≈ 10.0)中滴加 $KMnO_{4}$ 溶液(反应 4)，然后浓缩析晶。Fremy 盐是一种重要的氧化剂，例如，它在 NaOH 水溶液中可与苯酚反应得到苯醌(反应 5)。以上所有反应均不能在酸性溶液中进行，因为 Fremy 盐在酸性条件下迅速分解，得到 A 和笑气(反应 6)。

3-1 写出 A 的化学式。

3-2 写出反应 1、4、5、6 的离子反应方程式；写出反应 2、3 的电极反应方程式。

## 参考答案

3-1 写出 A 的化学式。

3-1 $\mathrm{K}_2[\mathrm{N(OH)(SO_3)_2}]$ （2分）
3-2 反应1：$\mathrm{NO}_2^- + \mathrm{HCO}_3^- + 2\mathrm{SO}_2 = [\mathrm{N(OH)(SO_3)_2}]^{2-} + \mathrm{CO}_2$ （1.5分）
反应4：$3[\mathrm{N(OH)(SO_3)_2}]^{2-} + \mathrm{MnO}_4^- + \mathrm{NH}_4^+ = 3[\mathrm{NO(SO_3)_2}]^{2-} + \mathrm{MnO}_2 + \mathrm{NH}_3 + 2\mathrm{H}_2\mathrm{O}$ （1.5分）
反应5：$\mathrm{C_6H_5OH} + 4[\mathrm{NO(SO_3)_2}]^{2-} + \mathrm{H}_2\mathrm{O} = \mathrm{C_6H_4O_2} + 4[\mathrm{N(OH)(SO_3)_2}]^{2-}$ （1.5分）
写作 $\mathrm{C_6H_5OH} + 2[\mathrm{NO(SO_3)_2}]^{2-} = \mathrm{C_6H_4O_2} + [\mathrm{N(OH)(SO_3)_2}]^{2-} + [\mathrm{HN(SO_3)_2}]^{2-}$ 也得1.5分。
产物写作去质子形态也得分。
反应6：$4[\mathrm{NO(SO_3)_2}]^{2-} + 3\mathrm{H}_2\mathrm{O} = \mathrm{N}_2\mathrm{O} + 2[\mathrm{N(OH)(SO_3)_2}]^{2-} + 4\mathrm{HSO}_4^-$ （1.5分）
反应2：$[\mathrm{N(OH)(SO_3)_2}]^{2-} + \mathrm{OH}^- - \mathrm{e}^- = [\mathrm{NO(SO_3)_2}]^{2-} + \mathrm{H}_2\mathrm{O}$ （1分）
反应3：$2\mathrm{H}_2\mathrm{O} + 2\mathrm{e}^- = \mathrm{H}_2 + 2\mathrm{OH}^-$ （1分）
