# 题-CM-142-03-3-1X是一种含有整数个结晶

## 题目

### 第 3 题（13 分）

3-1 X 是一种含有整数个结晶水的盐，化学式为 $\mathsf{M}_{x}(\mathrm{SO}_{4})_{x}(\mathrm{C}_{4}\mathrm{O}_{4})\cdot y\mathrm{H}_{2}\mathrm{O}$ ，其在空气中的热重分析曲线如下图所示。X 首先在 $125^{\circ}\mathrm{C}\sim290^{\circ}\mathrm{C}$ 区间内失重 11.0% 得到 A，对应全部结晶水；随后 A 在 $505^{\circ}\mathrm{C}$ 附近失重 26.9%，得到 B 的同时放出一种混合气体；最终，B 在 $860^{\circ}\mathrm{C}$ 附近失重 12.3%，得到氧化物 C。提示：整个失重过程中 M 价态未发生改变。

![](images/15e45da26bf235c1f91302c23fa1429426d6d1e394781a76500ab6d43358fb6c.jpg)

通过计算给出 X、A、B、C 的化学式。

3-2 Y 是一种含结晶水的 1:1 型方酸盐，与 X 相比其热分解略有不同。在氧气氛中加热 Y，首先在 $114^{\circ}$ C 下失重 16.82%，随后在 $228^{\circ}$ C 下失重 5.60%，最后在 $523^{\circ}$ C 下失重 16.19%。剩余固体对热较稳定，在 $1300^{\circ}$ C 及以上才会受热分解。通过计算推断 Y 的化学式，并写出每步分解反应的方程式。

## 参考答案

![](images/180c0431b3b314713bb26dbf16b8451998e97461d1011bcb008c606d99ddc4f7.jpg)

3-2 M 的价态为： $(2x+2)/x=2+2/x$ （1分）
当 x=1 时，M 价态为 +4，则 C 为 $MO_{2}$ 。所以由 X 分解为 C 共失去 $C_{4}SO_{6}+yH_{2}O$ 因此： $[(12.01\times4+32.066+16\times6+18.016y)\div(11.0\%+26.9\%+12.3\%)]\times11.0\%=18.016y$ 解出 y=2.74，不为整数，故舍去 x=1 的情况（1分）
当 x=2 时，M 价态为 +3，则 C 为 $M_{2}O_{3}$ ，所以由 X 分解为 C 共失去 $C_{4}S_{2}O_{9}+yH_{2}O$ 因此： $[(12.01\times4+32.066\times2+16\times9+18.016y)\div(11.0\%+26.9\%+12.3\%)]\times11.0\%=18.016y$ 解出 y=3.99，约为整数 4，符合题意（1分）
据此求出 M = 139.1 (g/mol)，对应元素为 La
因此 X 为 $\mathrm{La}_{2}(\mathrm{SO}_{4})_{2}(\mathrm{C}_{4}\mathrm{O}_{4})\cdot4\mathrm{H}_{2}\mathrm{O}$ （1 分）
据此可以得到：A 为 $\mathrm{La}_{2}(\mathrm{SO}_{4})_{2}(\mathrm{C}_{4}\mathrm{O}_{4})$ （1 分），C 为 $La_{2}O_{3}$ （1 分）
由于 B 到 C 失重 M = 80.4 (g/mol)，恰为 1 个 $SO_{3}$ 的质量，因此 B 为 $La_{2}O_{2}SO_{4}$ （1 分）

3-2 由题知 114℃下失重的应为结晶水，设失去了 x 个水分子
因此： $M(Y)=18.016x/16.82\%$ 。据此知 228℃下失重： $(18.016x/16.82\%)\times5.60\%$ 打表，发现 x=1 时 228℃下失重 6.005 (g/mol)，当 x=3 时恰为 1 个水分子
故两步均失去结晶水，X 中含有 4 个结晶水（1 分）
结合题目 Y 为 1:1 型方酸盐
中心金属 $M=(3\times18.016)\div16.82\%-4\times18.016-12.01\times4-16\times4=137.23\ (\text{g/mol})$ 查表知 M 为 Ba，所以 Y 为 $BaC_{4}O_{4}\cdot4H_{2}O$ （2 分）
对应在 523℃失重后 $M=(137.33+12.01\times4+16\times4+18.016\times4)\times(1-16.82\%-5.60\%-16.19\%)=197.33\ (\text{g/mol})$ 减去一个 Ba 后 M = 60.00 (g/mol)，恰为一个碳酸根的相对分子质量
因此最终分解产物为 $BaCO_{3}$ （1 分） $BaC_{4}O_{4}\cdot4H_{2}O=BaC_{4}O_{4}\cdot H_{2}O+3H_{2}O$ （0.5 分） $BaC_{4}O_{4}\cdot H_{2}O=BaC_{4}O_{4}+H_{2}O$ （0.5 分） $2BaC_{4}O_{4}+5O_{2}=2BaCO_{3}+6CO_{2}$ （1 分）
如写出 $BaCO_{3}=BaO+CO_{2}$ 不得分也不扣分。
