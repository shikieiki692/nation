# 题-CM-98-01-1-1用热的溶液处理含硼废渣

## 题目

### 第 1 题（10 分）

1-1 用热的 $Na_{2}CO_{3}$ 溶液处理含硼废渣(活性成分为 $Mg_{2}B_{2}O_{5}$ )，同时通入 $CO_{2}$ 气体，得到硼砂水溶液；镁均转化为 $MgCO_{3}$ 沉淀。

1-2 $\mathrm{UO}_2$ 是动力反应堆中广泛使用的燃料，可由 $(\mathrm{NH}_4)_4[\mathrm{UO}_2(\mathrm{CO}_3)_3]$ 在 $800^{\circ}\mathrm{C}$ 热分解制备。

1-3 室温下混合氯化铜溶液和硫脲溶液，析出化合物 $\mathrm{Cu(CS(NH_{2})_{2})Cl\cdot0.5H_{2}O}$ 。

1-4 在乙腈中， $NaBH_{4}$ 与 $CO_{2}$ 按摩尔比 1:3 反应，产物仅为一种盐；其中有两种化学环境的氢，数目比为 1:3。

1-5 90°C 下，盐酸介质中，用次磷酸还原 $W_{3}Se_{7}Br_{4}$ 粉末，可制得离子 $[W_{3}Se_{4}(H_{2}O)_{9}]^{4+}$ ；产物中有两种二元弱酸。

## 参考答案

**1-1** 用热的 $Na_{2}CO_{3}$ 溶液处理含硼废渣(活性成分为 $Mg_{2}B_{2}O_{5}$ ),同时通入 $CO_{2}$ 气体,得到硼砂水溶液;镁均转化为 $MgCO_{3}$ 沉淀。

**1-1** $2Mg_{2}B_{2}O_{5} + Na_{2}CO_{3} + 3CO_{2} + 2H_{2}O = Na_{2}B_{4}O_{5}(OH)_{4} + 4MgCO_{3}$ (2分)

**1-2** $UO_{2}$ 是动力反应堆中广泛使用的燃料,可由 $(NH_{4})_{4}[UO_{2}(CO_{3})_{3}]$ 在800°C热分解制备。

**1-2** $3(NH_{4})_{4}[UO_{2}(CO_{3})_{3}] = 3UO_{2} + 10NH_{3} + 9CO_{2} + N_{2} + 9H_{2}O$ (2分)

**1-3** 室温下混合氯化铜溶液和硫脲溶液,析出化合物 $Cu(CS(NH_{2})_{2})Cl \cdot 0.5H_{2}O$ 。

**1-3** $2CuCl_{2} + 4CS(NH_{2})_{2} + H_{2}O = 2[Cu(CS(NH_{2})_{2})Cl \cdot 0.5H_{2}O] + [(NH_{2})_{2}CSSC(NH_{2})_{2}]Cl_{2}$ (2分)

**1-4** 在乙腈中, $NaBH_{4}$ 与 $CO_{2}$ 按摩尔比1:3反应,产物仅为一种盐;其中有两种化学环境的氢,数目比为1:3。

**1-4** $NaBH_{4} + 3CO_{2} = Na[HB(OOCH)_{3}]$ (2分)

**1-5** 90°C下,盐酸介质中,用次磷酸还原 $W_{3}Se_{7}Br_{4}$ 粉末,可制得离子 $[W_{3}Se_{4}(H_{2}O)_{9}]^{4+}$ ;产物中有两种二元弱酸。

**1-5** $W_{3}Se_{7}Br_{4} + 3H_{3}PO_{2} + 12H_{2}O = W_{3}Se_{4}(H_{2}O)_{9}^{4+} + 3H_{2}Se + 3H_{3}PO_{3} + 4Br^{-}$ (2分)或: $W_{3}Se_{7}Br_{4} + 3H_{3}PO_{2} + 3H_{2}O = W_{3}Se_{4}^{4+} + 3H_{2}Se + 3H_{3}PO_{3} + 4Br^{-}$
