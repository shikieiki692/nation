# 题-CM-84-07-可视为硝酸的酸酐气态时加热可

## 题目

### 第 7 题（11 分）

$N_{2}O_{5}$ 可视为硝酸的酸酐，气态时加热可完全分解成 $NO_{2}$ 和 $O_{2}$ ，相关科研人员通过实验结果，经过合理的推断得出其可能的分解机理如下：

$$
\mathrm{N} _{2} \mathrm{O} _{5} \underset {k _{- 1}} {\overset {k _{1}} {\rightleftharpoons}} \mathrm{NO} _{2} + \mathrm{NO} _{3}
\mathrm{NO} _{2} + \mathrm{NO} _{3} \xrightarrow {k _{2}} \mathrm{NO} _{2} + \mathrm{O} _{2} + \mathrm{NO}
\mathrm{NO} + \mathrm{NO} _{3} \xrightarrow {k _{3}} 2 \mathrm{NO} _{2}
$$

7-1 推导出 $N_{2}O_{5}$ 分解的速率方程。

7-2-1 计算初始加入 $N_{2}O_{5}$ 的物质的量。

## 参考答案

7-1 对 NO 使用稳态近似： $k_{2}[NO_{2}][NO_{3}] - k_{3}[NO][NO_{3}] = 0 \cdots (1)$

由(1)可以解出： $[NO] = k_{2}[NO_{2}] / k_{3} \cdots (2)$ （1分）

对  $NO_{3}$  使用稳态近似： $k_{1}[N_{2}O_{5}] - k_{-1}[NO_{2}][NO_{3}] - k_{2}[NO_{2}][NO_{3}] - k_{3}[NO][NO_{3}] = 0 \cdots (3)$

将(2)带入(3)可得  $[NO_{3}] = k_{1}[N_{2}O_{5}] / (k_{-1} + 2k_{2})[NO_{2}] \cdots (4)$ （1分）

而反应速率  $r = -d[N_{2}O_{5}] / dt = k_{1}[N_{2}O_{5}] - k_{-1}[NO_{2}][NO_{3}] \cdots (5)$

将(4)带入(5)可知  $r = 2k_{1}k_{2}[N_{2}O_{5}] / (k_{-1} + 2k_{2}) = k[N_{2}O_{5}]$ ，其中  $k = 2k_{1}k_{2} / (k_{-1} + 2k_{2})$ （1分）

7-2-1 设反应完时  $O_{2}$  的分压为  $x p^{\ominus}$ ， $NO_{2}$  的分压为  $y p^{\ominus}$
则  $N_{2}O_{4}$  的分压为  $(0.8906 - x - y)p^{\ominus}$ （1 分）
根据物料守恒有  $2(0.8906 - x - y) + y = 4x$
根据反应平衡有 $(0.8906 - x - y)/y^{2} = 1.79$
则可以解出 x = 0.2321, y = 0.3884 (1 分)
故  $p(\mathrm{N}_{2}\mathrm{O}_{5})_{0} = 2x = 0.4643p^{\ominus}$
则  $n(\mathrm{N}_{2}\mathrm{O}_{5})_{0} = p(\mathrm{N}_{2}\mathrm{O}_{5})_{0}V/RT = 0.1756\ \mathrm{mol}$ （1 分）

7-2-2 设 $NO_{2}$ 的分压为 $x p^{\ominus}$ ，则 $N_{2}O_{4}$ 的分压为 $1.79 x^{2} p^{\ominus}$ ， $O_{2}$ 的分压为 $0.25(x + 3.58 x^{2}) p^{\ominus}$ ， $N_{2}O_{5}$ 的分压为 $[0.4643 - 0.5(x + 3.58 x^{2})] p^{\ominus}$ 而总压 $p = x + 1.79 x^{2} + 0.25(x + 3.58 x^{2}) + [0.4643 - 0.5(x + 3.58 x^{2})]$ （1 分）
将上表数据代入上述方程可知
当 t = 20 min 时，x = 0.2361， $N_{2}O_{5}$ 的分压为 $0.2464 p^{\ominus}$ （0.5 分）
当 t = 70 min 时，x = 0.3567， $N_{2}O_{5}$ 的分压为 $0.0582 p^{\ominus}$ （0.5 分）
而 $N_{2}O_{5}$ 的分解是一个一级反应，则有 $\ln(p_{20}/p_{70}) = kt$ 则代入数据可求得 $k_{45}=0.02886\ min^{-1}$ （1 分）

7-2-3 可知 $k_{45}=0.2886\ min^{-1}=4.810\times10^{-4}\ s^{-1}$ （1分）
由 Arrhenius 公式可知 $k = A \exp(-E_{a}/RT)$ 则 $E_{a}=\ln(k_{55}/k_{45})RT_{45}T_{55}/(T_{55}-T_{45})=38.52\ kJ\cdot mol^{-1}$ （1分）
