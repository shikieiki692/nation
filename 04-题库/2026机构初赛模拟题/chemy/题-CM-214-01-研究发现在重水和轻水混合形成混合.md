# 题-CM-214-01-研究发现在重水和轻水混合形成混合

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-1-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（7 分）

研究发现，在重水和轻水混合形成混合物时，体系的体积变化微小到可忽略不计(< 0.001%)。25°C 时，轻水 <sup>1</sup>H<sub>2</sub>O 的密度 D<sub>1</sub> = 0.99703 g/cm<sup>3</sup>，分子量 M<sub>1</sub> = 18.014924；重水 <sup>2</sup>H<sub>2</sub>O 的密度为 D<sub>2</sub> = 1.10447 g/cm<sup>3</sup>，分子量 M<sub>2</sub> = 20.027478。

**1-1** 计算密度为 D = 1.00500 g/cm<sup>3</sup>的轻重水混合物在混合前，轻水与重水的摩尔比。

**1-2** 忽略热力学同位素效应，写出反应 <sup>1</sup>H<sub>2</sub>O + <sup>2</sup>H<sub>2</sub>O = 2<sup>1</sup>H<sup>2</sup>HO 的平衡常数。

**1-3** 在 1-2 的前提下，计算 1-1 中轻重水平衡混合物中各组分的摩尔分数。

## 参考答案

**1-1** 设摩尔比为 x : 1，则：

(xM<sub>1</sub> + M<sub>2</sub>) : D = xM<sub>1</sub> / D<sub>1</sub> + M<sub>2</sub> / D<sub>2</sub>（2 分）

x = 12.53（1 分）不要求有效数字。

**1-2** 平衡常数为 4（1 分）

**1-3** 设摩尔分数分别为 n<sub>1</sub>、n<sub>2</sub>、n<sub>3</sub>，则：

n<sub>1</sub> + n<sub>2</sub> + n<sub>3</sub> = 1（0.5 分）

n<sub>3</sub><sup>2</sup> / (n<sub>1</sub>n<sub>2</sub>) = 4（0.5 分）

(n<sub>1</sub> + n<sub>3 </sub>/ 2) : (n<sub>2</sub> + n<sub>3 </sub>/ 2) = 12.53（0.5 分）

n<sub>1</sub> = 0.857（0.5 分） n<sub>2</sub> = 0.005（0.5 分） n<sub>3</sub> = 0.1379（0.5 分）
