# 题-CM-279-01-写出下列反应的方程式11乙硼烷与

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-9-1`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（12 分）

写出下列反应的方程式：

**1-1** 乙硼烷与三甲胺反应。

**1-2** 用高锰酸钾与甘油反应，测定甘油的含量。

**1-3** 高溴酸镁受热完全分解。

**1-4** 向 KIO<sub>3</sub>-KI 溶液滴入少量 TlNO<sub>3</sub>溶液后，用硫酸酸化。

**1-5** 连二亚硫酸钠溶液在 pH = 8 的条件下与铬酸钾溶液反应可除去水溶液中的 Cr(VI)。

**1-6** Sn(II)水解产生一种具有特殊结构的水合氧化物。该氧化物晶体中存在具有高对称性的结构单元，其中含有 Sn<sub>6</sub>八面体。每个结构单元周围存在八个最近的 Sn<sub>6</sub>单元。

## 参考答案

**1-1** 2Me<sub>3</sub>N + B<sub>2</sub>H<sub>6</sub> = 2Me<sub>3</sub>N<sup>+</sup>-<sup>-</sup>BH<sub>3</sub>（2 分）<sup> </sup>

**1-2** 14MnO<sub>4</sub><sup>- </sup>+ C<sub>3</sub>H<sub>8</sub>O<sub>3</sub> + 20OH<sup>-</sup> = 14MnO<sub>4</sub><sup>2-</sup> + 3CO<sub>3</sub><sup>2-</sup><sub> </sub>+14H<sub>2</sub>O（2 分）<sup> </sup>

**1-3** 2Mg(BrO<sub>4</sub>)<sub>2</sub> = 2MgO + 2Br<sub>2</sub> + 7O<sub>2</sub>（2 分）<sup> </sup>

**1-4** Tl<sup>+</sup> + I<sup>-</sup> = TlI（1 分）

3TlI + IO<sub>3</sub><sup>-</sup> + 8I<sup>-</sup> + 6H<sup>+</sup>= 3TlI<sub>4</sub><sup>-</sup> + 3H<sub>2</sub>O （1 分）

合并写总反应也得分。

**1-5** 3S<sub>2</sub>O<sub>4</sub><sup>2-</sup> + 2CrO<sub>4</sub><sup>2-</sup> + 4H<sub>2</sub>O = 2Cr(OH)<sub>3</sub> + 4SO<sub>3</sub><sup>2-</sup> + 2HSO<sub>3</sub><sup>-</sup>（2 分）<sup> </sup>

**1-6** 6Sn<sup>2+</sup> + 8H<sub>2</sub>O = Sn<sub>6</sub>O<sub>4</sub>(OH)<sub>4</sub> + 12H<sup>+</sup>（2 分）<sup> </sup>
