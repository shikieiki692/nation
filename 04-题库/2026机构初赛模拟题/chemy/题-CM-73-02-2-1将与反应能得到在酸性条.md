# 题-CM-73-02-2-1将与反应能得到在酸性条

## 题目

### 第 2 题（13 分）

2-1 将 $\mathrm { { NaB } ( CN ) _{ 4 } }$ 与 $\mathrm { ClF } _{ 3 }$ 反应能得到 $\pmb { \mathsf { A } }$ ， $\pmb { \mathsf { A } }$ 在酸性条件下水解得到一种电中性的分子 B，B中含有一根 $C _{ 3 }$ 轴且其中含有1 个氧原子和9 个氟原子，B 的结构与 $\mathrm { BF } _{ 3 }$ -CO 有相似之处。2-1-1 请给出A、B 的化学式并写出生成A 的化学反应方程式。

2-1-2 比较 $\mathrm { BF } _{ 3 }$ -CO、 $\mathrm { BH } _{ 3 }$ -CO 哪一个更容易分解并解释原因。
2-2 在 2 bar CO 分压下，B 可以与 $\mathrm { Co } _{ 2 } \mathrm { ( CO ) } _{ 8 }$ 在液态HF 中反应得到一种阴阳离子均具有 $C _{ 3 }$ 轴的 1 : 1 型离子化合物，其中C-O 伸缩振动频率相对常见的过渡金属羰基配合物更高，且其中 Co 满足 EAN 规则。
2-2-1 请给出该反应的方程式并画出其中阳离子的结构。
2-2-2 解释为什么其中C-O 伸缩振动频率比常见过渡金属羰基配合物更高。
2-2-3 画出该阳离子中Co 的 $d$ 轨道能级分裂情况。

## 参考答案

## 第2题（13分）

$$
2 - 1 - 1 \mathrm{A} \mathrm{NaB} (\mathrm{CF} _ {3}) _ {4}
\mathrm{B} (\mathrm{CF} _ {3}) _ {3} \mathrm{CO}
\mathrm{NaB} (\mathrm{CN}) _ {4} + 4 \mathrm{ClF} _ {3} \rightarrow \mathrm{NaB} (\mathrm{CF} _ {3}) _ {4} + 2 \mathrm{Cl} _ {2} + 2 \mathrm{N} _ {2} (2 \text {分})
$$

<table><tr><td>2-1-2  $BF_{3}-CO$ 更容易分解(1分)在 $BH_{3}-CO$ 中B-H键可以与CO的 $\pi^{*}$ 存在到超共轭效应,因此B-C结合较为紧密;而在 $BF_{3}-CO$ 中,由于F的电负性过大,B-F成键电子更多的偏向于F,因此不易与CO的反键轨道进行超共轭,且分解后可以形成有大 $\pi$ 键的较为稳定的 $BF_{3}$ ,因此 $BF_{3}-CO$ 较 $BH_{3}-CO$ 更容易分解(1分)用“软硬酸碱”等理论解释合理也可得分。</td></tr></table>

$$
2 - 2 - 1 \mathrm{Co} _ {2} (\mathrm{CO}) _ {8} + 2 \mathrm{B} \left(\mathrm{CF} _ {3}\right) _ {3} \mathrm{CO} + 2 \mathrm{HF} \rightarrow 2 \left[ \mathrm{Co} (\mathrm{CO}) _ {5} \right] ^ {+} \left[ \mathrm{BF} \left(\mathrm{CF} _ {3}\right) _ {3} \right] ^ {-} + \mathrm{H} _ {2}
\left[ \begin{array}{c} \mathrm{CO} \\ \mathrm{OC} - \mathrm{Co} - \mathrm{CO} \\ \mathrm{OC} - \mathrm{CO} \end{array} \right] ^ {+}
$$
