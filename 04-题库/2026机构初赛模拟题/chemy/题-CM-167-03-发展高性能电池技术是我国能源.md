# 题-CM-167-03-发展高性能电池技术是我国能源

## 题目

### 第 3 题

# 第 3 题（10 分， $7 \%$ ） 钠离子电池

发展高性能电池技术是我国能源结构转型升级、发展低碳清洁经济、实现“碳中和，碳达峰”目标的重大战略需求。锂离子电池是当前应用最广泛的高效电池体系之一，但锂元素在地壳中丰度很低，且我国锂储量仅占全球 $7 \%$ ，近七成碳酸锂依赖进口，未来难以满足储能与动力电池领域的巨大需求。因此，开发原料来源广泛的钠离子电池是防止美帝国主义卡脖子的重大战略需求。

普鲁士蓝类化合物是一种备受关注的钠离子电池正极材料。

3-1 指出普鲁士蓝类化合物作为电极材料的两点优势。

3-2 普鲁士蓝中过多的结晶水会降低钠离子电池的性能，指出两点问题。

一种钠离子电池使用 $\mathrm { Na _{ 1.91 } Fe _{ 2 } ( CN ) _{ 6 } { \cdot } 3.2 H _{ 2 } O }$ 为正极材料， 硬碳（可记为 $\mathrm { Na } _{ \mathrm { x } } \mathrm { C }$ ） 为负极材料，高氯酸钠的有机聚合物溶液为电解质。

3-3 写出放电时的电极反应方程式。

3-4 该正极材料的制备方法为：水相中 $24 \mathrm { mmol } \mathrm { FeSO } _{ 4 } { \cdot } 7 \mathrm { H } _{ 2 } \mathrm { O }$ 、 26 mmol ${ \mathrm { Na } } _{ 4 } { \mathrm { Fe } } ( \mathrm { CN } ) _{ 6 }$ ， 在柠檬酸钠存在下， 搅拌反应，得到沉淀 （结晶水可记为 5 个）。 （反应一） $270^{ \circ } \mathrm { C }$ 下焙烧沉淀得到最终产物 （反应二）。 写出相应的化学方程式。

## 参考答案

3-1 多孔，有利于离子导电。（1 分）骨架稳定。（1 分）

3-2 释放出结晶水进入有机相，降低电池性能。结晶水过多干扰骨架内离子迁移，降低导电性。结晶水直接参与放电，产生气体。（任答两点即得 2 分）

3-3 $Na_{x}C - xe^{-} = C + xNa^{+}$ (1 分)

$$
\mathrm{Na} _{1.91} \mathrm{Fe} _{2} (\mathrm{CN}) _{6} \cdot 3.2 \mathrm{H} _{2} \mathrm{O} + \mathrm{xe} ^{-} + \mathrm{xNa} ^{+} = \mathrm{Na} _{1.91 + \mathrm{x}} \mathrm{Fe} _{2} (\mathrm{CN}) _{6} \cdot 3.2 \mathrm{H} _{2} \mathrm{O} (1 \text {分})
3 - 4 \mathrm{FeSO} _{4} \cdot 7 \mathrm{H} _{2} \mathrm{O} + \mathrm{Na} _{4} \mathrm{Fe(CN)} _{6} = \mathrm{Na} _{2} \mathrm{Fe} _{2} (\mathrm{CN}) _{6} \cdot 5 \mathrm{H} _{2} \mathrm{O} + 2 \mathrm{H} _{2} \mathrm{O} + \mathrm{Na} _{2} \mathrm{SO} _{4} (2 \text {分})
\mathrm{Na} _{2} \mathrm{Fe} _{2} (\mathrm{CN}) _{6} \cdot 5 \mathrm{H} _{2} \mathrm{O} + 0.0225 \mathrm{O} _{2} = \mathrm{Na} _{1.91} \mathrm{Fe} _{2} (\mathrm{CN}) _{6} \cdot 3.2 \mathrm{H} _{2} \mathrm{O} + 0.09 \mathrm{NaOH} + 1.755 \mathrm{H} _{2} \mathrm{O} (2 \text {分})
$$
