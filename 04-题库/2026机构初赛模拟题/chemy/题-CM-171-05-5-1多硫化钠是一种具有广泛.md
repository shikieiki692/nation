# 题-CM-171-05-5-1多硫化钠是一种具有广泛

## 题目

### 第 5 题 多硫化物 （32 分， 占 $16 \%$

5-1 多硫化钠 $\left( \mathrm { Na } _{ 2 } \mathrm { S } _{ x } \right)$ 是一种具有广泛用途的无机化合物；它可用作聚合终止剂、脱毛剂、杀虫剂、石油炼制助剂；也可用于电池。现有含硫代硫酸钠 $\mathrm { ( Na _{ 2 } S _{ 2 } O _{ 3 } ) }$ )杂质的多硫化钠 $\mathrm { Na } _{ 2 } \mathrm { S } _{ x }$ 溶液样品； 为测定 $x$ 的值，采取了以下方案：

实验1：取 $5.00 \mathrm { mL }$ 样品溶液， 以淀粉作指示剂， 用 0.01004 mol/L 的碘标准溶液滴定至终点（反应 1、反应 2）， 消耗 $6.73 \mathrm { \ mL }$ 。

实验 2： 取 ${ 5.00 } ~ \mathrm { mL }$ 样品溶液于离心试管中， 加入足量 ${ \mathrm { Na } } _{ 2 } { \mathrm { SO } } _{ 3 }$ 溶液使 ${ \mathrm { S } } _{ x } ^{ 2 }$ -完全转化为 $\mathrm { S } ^{ 2 \cdot }$ -和$\mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 - }$ （反应 3）；再加入过量 $\mathrm { SrCl } _{ 2 }$ 溶液充分反应 （反应4），离心分离除去沉淀并洗涤沉淀5\~6 次，合并洗液至清液中；然后在清液中加入过量洗净的 $Z \mathrm { n } ( \mathrm { OH } ) _{ 2 }$ 悬浊液（反应 5），充分反应后，过滤，洗涤沉淀5\~6 次，合并洗液至滤液中；滤液以淀粉作指示剂，用 $0.01004 \mathrm { mol / L }$ 的碘标准溶液滴定至终点， 消耗 $13.39 \mathrm { mL }$ 。

将反应 5 生成的沉淀转移到碘量瓶中， 滴加 $1 { + } 1 \mathrm { HCl }$ 使沉淀完全溶解 （反应6）， 加入 10.00$\mathrm { mL 0.01004 mol / L }$ 碘标准溶液 （反应 7）， 用淀粉作指示剂， 用 $0.01630 \mathrm { mol / L }$ 硫代硫酸钠标准溶液返滴定剩余的碘， 消耗 $4.34 ~ \mathrm { mL }$ 。

5-1-1 写出反应 $1 \sim$ 反应 7 的离子反应方程式。

5-1-2 计算原溶液中 ${ \mathrm { S } } _{ x } ^{ 2 \cdot }$ -的总摩尔浓度。

5-1-3 计算原溶液中杂质离子 $\mathrm { S } _{ 2 } \mathrm { O } _{ 3 } { } ^{ 2 }$ -的总摩尔浓度。

5-1-4 计算 $x$ （结果保留 2 位小数）。

5-1-5 在实验过程中， 需要维持体系的 $\mathrm { pH } > 10$ ， 简述理由。

5-2 利用氰化物提金一直是常用的提炼金单质的方法之一，但氰化物有剧毒；有人提出利用多硫化物溶液替代有毒的氰化物， 将金单质以 AuS-等形式溶出， 以达到浸金的效果。

反应 1、反应 2： $2S_{2}O_{3}^{2-} + I_{2} \rightarrow S_{4}O_{6}^{2-} + 2I^{-}$ （1 分） $S_{x}^{2-} + I_{2} \rightarrow xS + 2I^{-}$ （1 分）

反应 3: $(x-1)\mathrm{SO}_{3}^{2-}+\mathrm{S}_{x}^{2-}\rightarrow\mathrm{S}^{2-}+(x-1)\mathrm{S}_{2}\mathrm{O}_{3}^{2-}$ （1 分）

反应 4: $Sr^{2+} + SO_{3}^{2-} \rightarrow SrSO_{3}$ (1 分)

反应 5: $\mathrm{Zn(OH)_{2} + S^{2-} \rightarrow ZnS + 2OH^{-}}$ (1 分)

反应 6: ZnS + 2H $^{+}$ → Zn $^{2+}$ + H $_{2}$ S (1 分)

反应 7: $H_{2}S + I_{2} \rightarrow 2H^{+} + 2I^{-} + S$ (1 分)

以上方程式中， $S^{2-}$ 写成 $HS^{-}$ ， $I_{2}$ 写成 $I_{3}^{-}$ ，配平，均可得分。

5-1-2 原溶液中的摩尔数为:

$$
n \left(\mathrm{S} _{x} ^{2 -}\right) = 10.00 \mathrm{mL} \times 0.01004 \mathrm{mol} / \mathrm{L} - \frac {1}{2} \times 0.01630 \mathrm{mol} / \mathrm{L} \times 4.34 \mathrm{mL} = 6.503 \times 10^{- 5} \mathrm{mol} (2 \text {分})
$$

对应至浓度： $c(\mathrm{S}_{x}^{2-})=6.503\times10^{-5}\mathrm{mol}\div5.00\mathrm{mL}=0.01300\mathrm{mol/L}$ （2分）

5-1-3 由实验 1:

$$
c \left(\mathrm{S} _{x} ^{2 -}\right) + \frac {1}{2} c \left(\mathrm{S} _{2} \mathrm{O} _{3} ^{2 -}\right) = 6.73 \mathrm{mL} \times 0.01004 \mathrm{mol/L} \div 5.00 \mathrm{mL} = 0.01351 \mathrm{mol/L} (2 \text {分})
c \left(\mathrm{S} _{2} \mathrm{O} _{3} ^{2 -}\right) = 2 \times (0.01351 \mathrm{mol} / \mathrm{L} - 0.01300 \mathrm{mol} / \mathrm{L}) = 0.0010 \mathrm{mol} / \mathrm{L} (2 \text {分})
$$

5-1-4 由实验 2:

$$
\frac {1}{2} (x - 1) c \left(\mathrm{S} _{\mathrm{x}} ^{2 -}\right) + \frac {1}{2} c \left(\mathrm{S} _{2} \mathrm{O} _{3} ^{2 -}\right) = 13.39 \mathrm{mL} \times 0.01004 \mathrm{mol} / \mathrm{L} \div 5.00 \mathrm{mL} = 0.02689 \mathrm{mol} / \mathrm{L} (3 \text {分})
x = \left[ 2 \times 0.02689 \mathrm{mol} / \mathrm{L} - 0.0010 \mathrm{mol} / \mathrm{L} \right] \div 0.01300 \mathrm{mol} / \mathrm{L} + 1 = 5.06 (\text {2分})
$$

5-1-5 若 pH 过低，多硫化物离子易分解为 S 和 $S^{2-}$ （2 分）。


$$
5 - 2 E = E ^{\ominus} - R T / n F \ln ([ S ^{2 -} ] / c ^{\ominus}) = - 0.476 \mathrm{V} + \frac {0.0591 \mathrm{V}}{2} \lg (K _{\mathrm{a}, 1} K _{\mathrm{a}, 2}) = 0.149 \mathrm{V} (3 \text {分})
$$

$$
5 \mathrm{S} (\mathrm{s}) + 2 \mathrm{e} ^{-} \rightarrow \mathrm{S} _{5} ^{2 -} (\mathrm{aq}) \quad E ^{\mathrm{e}} = - 0.290 \mathrm{V} \quad \Delta_{\mathrm{r}} G _{\mathrm{m}, 1} ^{\mathrm{e}} = 56.0 \mathrm{kJ/mol(1分)}

\mathrm{AuS} ^{-} (\mathrm{aq}) + \mathrm{e} ^{-} \rightarrow \mathrm{Au} (\mathrm{s}) + \mathrm{S} ^{2 -} (\mathrm{aq}) \quad E ^{\ominus} = - 0.460 \mathrm{V} \quad \Delta_{\mathrm{r}} G _{\mathrm{m}, 3} ^{\ominus} = 44.4 \mathrm{kJ/mol(1分)}

$$
\Delta_{\mathrm{r}} G _{\mathrm{m}} ^{\ominus} = 5 \times 91.8 - 56.0 - 8 \times 44.4 = 47.8 (\mathrm{kJ/mol}) (2 \text {分})
K = \exp (- \Delta_{\mathrm{r}} G _{\mathrm{m}} ^{\ominus} / \mathrm{RT}) = 4 \times 10^{- 9} (2 \text {分})
