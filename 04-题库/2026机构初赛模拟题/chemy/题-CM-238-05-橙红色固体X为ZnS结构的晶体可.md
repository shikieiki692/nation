# 题-CM-238-05-橙红色固体X为ZnS结构的晶体可

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-19-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（23 分，占 10.0%）

橙红色固体 X 为 ZnS 结构的晶体，可用作半导体材料。通过水溶液反应可合成 X：将氧化

物 A(含氧 25.6%)与具有四面体分子结构的单质 B 于稀 NaOH 水溶液中混合加热反应，A 溶

解得到 C(反应 1)，B 歧化得到 D(反应的转化率为 25%)(反应 2)；而后 C 与 D 反应可得到

X(反应 3)。向体系中加入适量碘可提高反应的速率和 X 的产率，原因可能是由于：B 与碘

单质按摩尔比 1:2 在稀 NaOH 水溶液中发生了新的反应，生成 D、E 等产物(产物的摩尔比

为 1:1) (反应 4)。此外还可通过传统方法高温下合成 X。令 A 与 D 于 950°C 的 H<sub>2</sub>气氛下反

应(反应 5)，或令 B 与低价氯化物 F 于 1050°C 的真空中反应(反应 6)，均可得到 X；F 在高

温下为气相分子，迅速冷却至 77 K 转化为红色固体；继续升温至 0°C 以上，F 发生歧化分

解。

**5-1** 写出 X、A ~ F 的化学式。

**5-2** 写出反应 1～反应 6 的化学反应方程式。

**5-3** 若 X 为闪锌矿结构，键长 d = 236.0 pm，写出 X 的点阵形式；并计算 X 的密度。

## 参考答案

**5-1** X GaP A Ga<sub>2</sub>O<sub>3</sub> B P<sub>4</sub> C NaGa(OH)<sub>4</sub> D PH<sub>3</sub>

E NaH<sub>2</sub>PO<sub>4</sub>（或：Na<sub>2</sub>HPO<sub>4</sub>或 Na<sub>3</sub>PO<sub>4</sub>或 H<sub>3</sub>PO<sub>4</sub>） F GaCl（各 1 分） （共 7 分）

**5-2** 反应 1：Ga<sub>2</sub>O<sub>3</sub> + 2NaOH + 3H<sub>2</sub>O → 2NaGa(OH)<sub>4</sub>

反应 2：P<sub>4</sub> + 3NaOH + 3H<sub>2</sub>O → PH<sub>3</sub> + 3NaH<sub>2</sub>PO<sub>2</sub>

反应 3：NaGa(OH)<sub>4</sub> + PH<sub>3</sub> → GaP + NaOH + 3H<sub>2</sub>O

反应 4：P<sub>4</sub> + 2I<sub>2</sub> + 4H<sub>2</sub>O + 4NaOH → 2PH<sub>3</sub> + 2H<sub>3</sub>PO<sub>4</sub> + 4NaI

或：P<sub>4</sub> + 2I<sub>2</sub> + 2H<sub>2</sub>O + 6NaOH → 2PH<sub>3</sub> + 2NaH<sub>2</sub>PO<sub>4</sub> + 4NaI

或：P<sub>4</sub> + 2I<sub>2</sub> + 8NaOH → 2PH<sub>3</sub> + 2Na<sub>2</sub>HPO<sub>4</sub> + 4NaI

或：P<sub>4</sub> + 2I<sub>2</sub> + 10NaOH → 2PH<sub>3</sub> + 2Na<sub>3</sub>PO<sub>4</sub> + 4NaI + 2H<sub>2</sub>O

反应 5：Ga<sub>2</sub>O<sub>3</sub> + 2PH<sub>3</sub> → 2GaP + 3H<sub>2</sub>O

反应 6：6GaCl + P<sub>4</sub> → 4GaP + 2GaCl<sub>3</sub>（各 2 分） （共 12 分）

**5-3** 点阵形式为面心立方（1 分）；

![](images/623fa0b62314bd64295144e8efd0c19bb15d7466128cecdbfcd390d39f03fd0a.jpg)

D = ZM/N<sub>A</sub>V = 4 × 100.7 g mol<sup>-1</sup> / (6.022 × 10<sup>23</sup> mol<sup>-1</sup> × (545.0pm)<sup>3</sup>)

= 4.132 g/cm<sup>3</sup>（2 分） （共 4 分）
