# 题-CM-93-08-化合物A与B在氯仿溶液中可发

## 题目

### 第 8 题（8 分）

化合物 A 与 B 在氯仿溶液中可发生自组装生成 AB 和 $AB_{2}$ 两种超分子化合物:

$$
\begin{array}{c c}\mathrm{A} + \mathrm{B} \rightleftharpoons \mathrm{AB}&K _{\mathrm{f}, 1}\\\mathrm{AB} + \mathrm{B} \rightleftharpoons \mathrm{AB} _{2}&K _{\mathrm{f}, 2}\end{array}
$$

为测定 AB 以及 $AB_{2}$ 的形成常数 $K_{f,1}$ 和 $K_{f,2}$ ，在 1.00 $\mu$ mol/L 的 $AB_{2}$ 的氯仿溶液中加入大量的化合物 C，使 $AB_{2}$ 发生分解(加入 C 前后溶液体积不变):

$$
\begin{array}{l l}\mathrm{AB} _{2} + 3 \mathrm{C} \rightleftharpoons \mathrm{ABC} _{3} + \mathrm{B}&K _{3}\\\mathrm{ABC} _{3} + 3 \mathrm{C} \rightleftharpoons \mathrm{AC} _{6} + \mathrm{B}&K _{4}\end{array}
$$

测得:

$[\mathrm{C}] = 0.037 \, \mathrm{mol/L}$ 时，溶液中 $[\mathrm{AB}_2] = [\mathrm{ABC}_3]$ ;

$[\mathrm{C}] = 0.190 \, \mathrm{mol/L}$ 时，溶液中 $[\mathrm{ABC}_3] = [\mathrm{AC}_6]$ ;

又已知：

$$
\begin{array}{r l}\mathrm{AB} + 3 \mathrm{C}&\rightleftharpoons \mathrm{ABC} _{3}\\\mathrm{A} + 6 \mathrm{C}&\rightleftharpoons \mathrm{AC} _{6}\end{array}\quad K _{5} = 5.9 \times 10^{11} K _{6} = 3.5 \times 10^{23}
$$

8-1 计算 $K_{f,1}$ 和 $K_{f,2}$ (平衡常数默认除以标准浓度)。

8-2 计算 1.00 μmol/L 的 AB₂ 的氯仿溶液中各物种的平衡浓度[A]、[B]、[AB]。

## 参考答案

第8题（8分）



测得:

又已知：


8-1 当[C] = 0.037 mol/L 时，溶液中[B] = 0.50 μmol/L（0.5 分）
此时  $K_{3} = [B] / [C]^{3} = 9.9 \times 10^{-3}$ （1 分）
故  $K_{f,2} = K_{5} / K_{3} = 6.0 \times 10^{13}$ （1 分）
当[C] = 0.190 mol/L 时，溶液中[B] = 1.50 μmol/L（0.5 分）
此时  $K_{4} = [B] / [C]^{3} = 2.2 \times 10^{-4}$ （1 分）
故  $K_{f,1} = K_{6} / K_{4}K_{5} = 2.7 \times 10^{15}$ （1 分）

8-2 在该 AB₂ 溶液中，近似有： $[AB_{2}] = 1.00 \mu mol/L$ ， $[AB] = [B]$ ;
由： $K_{f,2} = [AB_{2}] / [AB][B] = 6.0 \times 10^{13}$ （0.5 分）
得： $[AB] = [B] \approx [1.00 \times 10^{-6} / (6.0 \times 10^{13})]^{1/2} = 1.3 \times 10^{-10} (\text{mol/L})$ （1 分）
又由： $K_{f,1} = [AB] / [A][B] = 2.7 \times 10^{15}$ （0.5 分）
得： $[A] = [1 / (2.7 \times 10^{15})] = 3.7 \times 10^{-16} (\text{mol/L})$ （1 分）
由于[A] &lt;&lt; [AB] &lt;&lt; [AB₂]，故以上近似成立。
