# 题-CM-90-05-由Cs和O组成的二元化合物属

## 题目

### 第 5 题（10 分）

由 Cs 和 O 组成的二元化合物 $Cs_{x}O_{y}$ 属于六方晶系，其沿着 c 和 $2a + b$ 方向的投影如下所示，其中大球为 Cs 原子，小球为 O 原子。

![](images/5fa7882213837b1055dc926d78a79030801998e29fea8a8866a2f2a00e9b10e2.jpg)

5-1 写出 $Cs_{x}O_{y}$ 的化学式。

5-2 分别写出 $Cs_{x}O_{y}$ 中 Cs 和 O 的化学环境和空间环境有多少种。

5-3 该化合物可以看作 $\left[\mathrm{Cs}_{m} \mathrm{O}_{n}\right]$ 簇和 Cs 原子组成的晶体。

5-3-1 画出 $\left[\mathrm{Cs}_{m} \mathrm{O}_{n}\right]$ 簇的结构。

5-3-2 已知在 $[Cs_{m}O_{n}]$ 簇中 Cs-O 的距离接近 $Cs^{+}$ 和 $O^{2-}$ 的离子半径的加和值，而在 $Cs_{x}O_{y}$ 中 $[Cs_{m}O_{n}]$ 簇间的 Cs-Cs 距离接近单质 Cs 中的 Cs-Cs 距离。根据上述条件，表示出 $[Cs_{m}O_{n}]$ 簇的真实存在形式。
示出 [CsmOn] 簇的真实存在形式。5-3 已知CsxOy

5-3 已知 $Cs_{x}O_{y}$ 正当晶胞的晶胞参数：a = 1624.4 pm, c = 914.5 pm，计算 $Cs_{x}O_{y}$ 的密度。
