# 题-CM-223-03-将N2通入RuNH35H2O2记

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-13-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（10 分）

将 N<sub>2</sub>通入[Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup>（记作 A）的水溶液可得到[Ru(NH<sub>3</sub>)<sub>5</sub>(N<sub>2</sub>)]<sup>2+</sup>（记作 B）。酸性条件下，向 A 与 Cr<sup>2+</sup>的混合溶液中通入 N<sub>2</sub>O 气体，充分反应也可得到 B。

**3-1** 写出得到 B 的两个反应方程式。

**3-2** 科研人员通过间接测量反应热的方法估算出了反应(a)和反应(b)的反应焓变。(a) [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup> + N<sub>2</sub> = [Ru(NH<sub>3</sub>)<sub>5</sub>(N<sub>2</sub>)]<sup>2+</sup> + H<sub>2</sub>O (b) [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup> + CO = [Ru(NH<sub>3</sub>)<sub>5</sub>(CO)]<sup>2+</sup> + H<sub>2</sub>O

**3-2-1** 写出 N<sub>2</sub>和 CO 的价层分子轨道排布式，并分析它们与 Ru 中心的成键情况。

**3-2-2** 结合给出的数据，估算反应(a)和反应(b)的反应焓变。[Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup>(aq) + Ce<sup>4+</sup>(aq) = [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>3+</sup>(aq) + Ce<sup>3+</sup>(aq) ΔH<sub>1</sub> = -124.0 kJ·mol<sup>-1</sup> [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>3+</sup>(aq) + Ce<sup>3+</sup>(aq) + N<sub>2</sub>(g) = [Ru(NH<sub>3</sub>)<sub>5</sub>(N<sub>2</sub>)]<sup>2+</sup>(aq) + Ce<sup>4+</sup>(aq) + H<sub>2</sub>O(aq) ΔH<sub>2</sub> = 47.7 kJ·mol<sup>-1</sup> [Ru(NH<sub>3</sub>)<sub>5</sub>(CO)]<sup>2+</sup>(aq) + 3Ce<sup>4+</sup>(aq) + 2H<sub>2</sub>O(aq) = [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>3+</sup>(aq) + 3Ce<sup>3+</sup>(aq) + CO<sub>2</sub>(g) + 2H<sup>+</sup>(aq)ΔH<sub>3</sub> = -353.7 kJ·mol<sup>-1</sup> Fe(CN)<sub>6</sub><sup>3-</sup>(aq) + Ce<sup>3+</sup>(aq) = Fe(CN)<sub>6</sub><sup>4-</sup>(aq) + Ce<sup>4+</sup>(aq) ΔH<sub>4</sub> = 76.6 kJ·mol<sup>-1</sup> 2Fe(CN)<sub>6</sub><sup>3-</sup>(aq) + H<sub>2</sub>(g) = 2Fe(CN)<sub>6</sub><sup>4-</sup>(aq) + 2H<sup>+</sup>(aq) ΔH<sub>5</sub> = -223.5 kJ·mol<sup>-1</sup> CO<sub>2</sub>(g) + H<sub>2</sub>(g) = CO(g) + H<sub>2</sub>O(aq) ΔH<sub>6</sub> = 2.9 kJ·mol<sup>-1</sup>

## 参考答案

**3-1** N<sub>2</sub> + [Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup> = [Ru(NH<sub>3</sub>)<sub>5</sub>(N<sub>2</sub>)]<sup>2+</sup> + H<sub>2</sub>O（1 分）[Ru(NH<sub>3</sub>)<sub>5</sub>(H<sub>2</sub>O)]<sup>2+</sup> + 2Cr<sup>2+</sup> + 2H<sup>+</sup> + N<sub>2</sub>O = [Ru(NH<sub>3</sub>)<sub>5</sub>(N<sub>2</sub>)]<sup>2+</sup> + 2Cr<sup>3+</sup> + 2H<sub>2</sub>O（2 分）

**3-2-1** N<sub>2</sub>的价层分子轨道排布式：(1σ<sub>g</sub>)<sup>2</sup>(1σ<sub>u</sub>)<sup>2</sup>(1π<sub>u</sub>)<sup>4</sup>(2σ<sub>g</sub>)<sup>2</sup>（1 分）CO 的价层分子轨道排布式：(1σ)<sup>2</sup>(2σ)<sup>2</sup>(1π)<sup>4</sup>(3σ)<sup>2</sup>（1 分）成键情况：N<sub>2</sub>和 CO 的 σ 电子与 Ru 中心的空 d 轨道形成 σ 配键，Ru 中心填充电子的 d 轨道与 N<sub>2</sub>和 CO 的 π 反键轨道形成反馈 π 键。（2 分）

**3-2-2** (a) ΔH = ΔH<sub>1</sub> + ΔH<sub>2</sub> = -76.3 kJ·mol<sup>-1</sup>（1 分）(b)ΔH = ΔH<sub>1</sub> - ΔH<sub>3</sub> - 2ΔH<sub>4</sub> + ΔH<sub>5</sub> – ΔH<sub>6</sub> = -149.9 kJ·mol<sup>-1</sup>（2 分）
