# 题-CM-283-02-在硝酸盐MNO33的溶液中加入稍

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-13-2`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（13 分）

在硝酸盐 M(NO<sub>3</sub>)<sub>3 </sub>的溶液中加入稍过量的草酸浓溶液，将析出的沉淀用乙醇-水混合溶剂洗涤，得到白色结晶 A [M<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·nH<sub>2</sub>O]。在不同的气氛下，A 的分解产物不完全相同。A 在氩气气氛中的热重分析显示，从 90°C 加热至 300°C，失重 20.9%，对应于失去 n 个结晶水；继续加热至 500°C，再失重 23.5%；继续加热至 800°C，再失重 4.1%，残留固体为黑色粉末，其成分为氧化物 B (MO<sub>2</sub>)与另一种物质的混合物。A 在空气中加热至 450°C 失重 49.7%，唯一残留固体为氧化物 B。

**2-1** 通过计算确定 n 的数值，指出 M 是何种金属。

**2-2** 写出 A 在空气中分解的化学反应方程式。

**2-3** 通过计算确定 A 在氩气中从 500°C 加热至 800°C 时所失去的组分。

**2-4** 写出 A 在氩气中加热至 800°C 所残留的黑色粉末的定性组成？

**2-5** 写出 A 在氩气中从 300°C 加热至 500°C 时发生的化学反应的方程式。

## 参考答案

**2-1** 由(M<sub>M</sub> + 32.0) / (M<sub>M</sub> + 264.1 + 18.0n) = 1 − 0.497

和 18.0n / (M<sub>M</sub> + 264.1 + 18.0n) = 0.209（2 分）

解得：n = 8.07 ≈ 8（1 分）

M 的摩尔质量为 M<sub>M</sub> = 143.6 g/mol，为 Ce（2 分）

A 为 Ce<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·8H<sub>2</sub>O

根据结晶颜色和氧化物价态可判断元素为 Ce；若答出 La，该小问得 0 分；若答 Pr、Nd

等元素，该小问只得 1 分。但后续问题中若无其他错误仍可得分。

**2-2** Ce<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub>·8H<sub>2</sub>O + 2O<sub>2</sub> = 2CeO<sub>2</sub> + 6CO<sub>2</sub> + 8H<sub>2</sub>O（2 分）

**2-3** M<sub>r</sub> = 676.2 g/mol × 4.1% = 27.7 g/mol（1 分）

为一分子 CO（1 分）

**2-4** 为 CeO<sub>2</sub>和 C 的混合物（2 分，全部答出才可得分）

**2-5** Ce<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub> = Ce<sub>2</sub>O<sub>2</sub>(CO<sub>3</sub>) + 3CO + 2CO<sub>2</sub> 2CO = C + CO<sub>2</sub>

或：2Ce<sub>2</sub>(C<sub>2</sub>O<sub>4</sub>)<sub>3</sub> = 2Ce<sub>2</sub>O<sub>2</sub>(CO<sub>3</sub>) + 3C + 7CO<sub>2</sub> C + CO<sub>2</sub> = 2CO

（共 2 分，写出一个方程式可得 1 分，写出 2 个即可得满分。）
