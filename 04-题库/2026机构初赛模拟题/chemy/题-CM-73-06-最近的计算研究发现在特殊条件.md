# 题-CM-73-06-最近的计算研究发现在特殊条件

## 题目

### 第 6 题（11 分）

最近的计算研究发现在特殊条件下 $\mathrm { NH } _{ 3 }$ 与 $\mathrm { H } _{ 2 }$ 会结合成一种富氢化合物， 其晶胞投影图如下图所示：

![](images/faf5d56db4186b54a27868b342bb565735370cf815896df9eada9b201874b9b3.jpg)

6-1 请给出符合该化合物结构特点的化学式。
6-2 请指出将该物质应用为储氢材料存在有哪些困难。
6-3 给出其中H-的配位数，假设不考虑 $\mathrm { H } _{ 2 }$ 与 $\mathrm { \Delta H }$ -之间的配位作用。
6-4 已知 $\mathrm { N } _{ 2 } \mathrm { H } _{ 7 } { } ^{ + }$ 中端基氢(下简称为端基氢)与 $\mathrm { \Delta H }$ -之间的距离为 $149.8 \mathrm { pm } ( d _{ 1 } )$ ， 端基氢与中心氮原子之间距离为 $101.8 ~ \mathrm { pm } ( d _{ 2 } )$ ， 中心氮原子与桥连氢之间距离为 $122.8 ~ \mathrm { pm } ( d _{ 3 } )$ ， 假设相邻的$\mathrm { N } _{ 2 } \mathrm { H } _{ 7 } { } ^{ + }$ 的端基氢在同一个平面，所有的H-N-H 键角为 $109^{ \circ } 28^{ \circ }$ ，估算该物质的密度。6-5 请估算该物质的储氢密度， 若无法利用 5-4 的条件求得该物质的密度， 请用 $5.00 ~ \mathrm { g } / \mathrm { cm } ^{ 3 }$ 代替。
