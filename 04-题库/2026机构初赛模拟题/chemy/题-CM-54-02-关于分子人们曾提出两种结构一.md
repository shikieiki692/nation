# 题-CM-54-02-关于分子人们曾提出两种结构一

## 题目

### 第 2 题（9 分）

关于 $\mathrm{O_4}$ 分子，人们曾提出两种结构：一种结构为 $D_{2\mathrm{d}}$ 对称性的环状结构 $\mathbf{X}$ ，另一种为 $D_{3\mathrm{h}}$ 对称性的“三氧化氧”型结构 $\mathbf{Y}$ 。通过计算化学的方法，科学家们得出， $\mathbf{Y}(\mathrm{g})$ 的标准摩尔生成焓为 $480.0\mathrm{kJ / mol}$ 。 $\mathbf{X}(\mathrm{g})$ 分解为 $2\mathrm{O}_2(\mathrm{g})$ 的反应活化能为 $48.7\mathrm{kJ / mol}$ ，反应 $\mathbf{X}(\mathrm{g}) \rightarrow \mathbf{Y}(\mathrm{g})$ 的焓变为 $89.3\mathrm{kJ / mol}$ 。

科学家们还通过 NR-MS 技术研究了 $O_{4}$ 分子可能的结构。在该技术中，人们设法制得 $O_{2}^{+}$ 离子，并使之与 $O_{2}$ 碰撞，产生稍微更稳定的 $O_{4}^{+}$ 离子，然后再设法 $O_{4}^{+}$ 离子与电子的碰撞，使用电磁场除去混合物中的带电离子，留下中性 $O_{4}$ 分子流，并使用质谱检测。以纯净的 ${}^{16}O_{2}$ 和 ${}^{18}O_{2}$ 为原料进行实验，所得的质谱图如下所示：

![](images/3c47362f97c867e6c5c439521d94fd2ebb4257395823698ce69f0c40ad989419.jpg)

2-1 分别画出 X 和 Y 满足八隅律的 Lewis 结构式，若有共振式请一并画出。

2-2 计算反应 $2\mathrm{O}_{2}(\mathrm{~g}) \rightarrow \mathbf{X}(\mathrm{~g})$ 的活化能。

2-3 A、B、C 各代表什么粒子？

2-4 根据 NR-MS 技术的实验结果，判断 X、Y 是否可能是 $O_{4}$ 的结构？简述判断理由。

可能是O4 的结构？简述判断理由。2-4 X、Y 都不可能是O4 的结构

$2 { \cdot } 4 \times$ 、Y 都不可能是 $\cdot$ 的结构。（1 分）

因为质谱图中几乎没有 $\cdot$ 的峰， 说明 $\cdot$ 和 $^{ 18 } \mathrm { O } _{ 2 }$ 之间未通过形成 $\mathrm { O } _{ 4 }$ 而交换氧原子。A中四个氧原子化学环境相同，B 中有三个氧原子化学环境相同，故 $\cdot$ 之间化合为A 或B 之后再分解必然引起氧原子的交换。（2 分， 意思对即可）
