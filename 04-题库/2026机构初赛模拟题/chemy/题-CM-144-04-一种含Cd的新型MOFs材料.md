# 题-CM-144-04-一种含Cd的新型MOFs材料

## 题目

### 第 4 题（9 分）

一种含 Cd 的新型 MOFs 材料能够高效吸附 C2-烃类化合物（如乙烯、乙炔等），在甲烷等气体的工业制备中拥有着巨大的潜力。其合成方法如下：将 $\mathrm{Cd(NO_{3})_{2}\cdot4H_{2}O}$ 和 $H_{3}L$ (分子式为 $C_{39}H_{25}NO_{6}$ ，结构如下图所示) 置于玻璃瓶中，向其中加入 N,N-二甲基乙酰胺(分子式为 $C_{4}H_{9}NO$ ，简写为 DMA)、微量的 6 mol/L HCl 以及一定量的 $H_{2}O$ ，之后在 373 K 下密闭反应 96 h，趁热过滤，DMA 洗涤，最终以 45% 的产率得到黄色晶体 X。对 X 的 TGA 和 EA 等数据分析表明，X 中含有 3 个含氮一价阳离子 $Y^{+}$ 和 1 个阴离子簇 $(\mathrm{Cd}_{x}\mathrm{L}_{y})^{3-}$ ，除此之外均为中性分子，其中 $Y^{+}$ 是由体系中的 DMA 在酸性条件下原位分解得到的。对 X 的元素分析表明：C 60.50；H 5.58；N 6.72；Cd 12.44 (均为质量分数，%)。

![](images/aba300dcfaa64e99b1f32fac099ae1af2d3eabedb382c041de99b8b4947200ba.jpg)

4-1 写出 $Y^{+}$ 的化学式。

4-2 通过计算与推理，推出 X 的化学式(必须表明配体种类以及个数，配体可用简写表示)。4-3 在阴离子簇 $\left(\mathrm{Cd}_{x}\mathrm{L}_{y}\right)^{3-}$ 中，每个 Cd 均为 6 配位， $L^{3-}$ 中羧酸根阴离子有两种配位方式，分别对应于结合 2 个 Cd(记为 $C_{1}$ )和结合 3 个 Cd(记为 $C_{2}$ )，氨基不参与配位。通过计算写出 $C_{1}$ 和 $C_{2}$ 的个数比(最简整数比)，并用结构示意图分别表示出 $C_{1}$ 和 $C_{2}$ 的配位方式。

## 参考答案

![](images/91a0f8d97c4c791ddb9cb25481edacc1dbe58813ff4695fac7bab1ace85eb3ac.jpg)

4-1 写出 $Y^{+}$ 的化学式。

4-1  $(\mathrm{CH}_{3})_{2}\mathrm{NH}_{2}^{+}$ （1分）

4-2 在该反应体系中并没有能够作为氧化剂/还原剂的物种，因此 X 中 Cd 应为 +2 价。故根据阴离子簇的电荷可知：3y - 2x = 3，且 x 和 y 均为整数。经验证，x = 3, y = 3 时，不符合题目质量分数的要求，则 y : x = 5 : 6（1 分）不妨令 y = 5, x = 6，则阴离子簇的化学式为  $(\mathrm{Cd}_{6}\mathrm{C}_{195}\mathrm{H}_{110}\mathrm{N}_{5}\mathrm{O}_{30})^{3-}$ 。根据质量分数，并结合 Cd 的个数为 6，可得：

 $n(\mathrm{C}): n(\mathrm{Cd}) = (112.4 / 0.1244) / (12.01 / 0.6050) = 45.52 = 273 : 6$ $n(\mathrm{N}): n(\mathrm{Cd}) = (112.4 / 0.1244) / (14.01 / 0.0672) = 4.33 = 26 : 6$

体系中含 N 的分子/离子有  $(\mathrm{CH}_{3})_{2}\mathrm{NH}_{2}^{+}$ 、 $L^{3-}$  和 DMA，因此扣除 3 个  $(\mathrm{CH}_{3})_{2}\mathrm{NH}_{2}^{+}$  和 5 个  $L^{3-}$  中的 N，还剩 18 个 N，对应于 18 个 DMA（1 分）。接下来验证 C 的数目，发现 3 个  $(\mathrm{CH}_{3})_{2}\mathrm{NH}_{2}^{+}$ 、5 个  $L^{3-}$  和 18 个 DMA 恰好对应 273 个 C。故剩余分子量  $Mr = 6 \times 112.4 / 0.1244 - 6 \times 112.4 - 18 \times 87.1 - 5 \times 600.6 - 3 \times 46.1 = 37.7$

由中性分子可知，剩余分子量应对应于 2 个  $H_{2}O$ （1 分）

故 X 的化学式为  $[(\mathrm{CH}_{3})_{2}\mathrm{NH}_{2}]_{3}[\mathrm{Cd}_{6}\mathrm{L}_{5}](\mathrm{DMA})_{18}(\mathrm{H}_{2}\mathrm{O})_{2}$ （1 分）

C1 和C2 的配位方式。4-3 假设C1 和C2 的

4-3 假设  $C_{1}$  和  $C_{2}$  的个数分别为 x 和 y，运用均摊法可得：

 $x + y = 15, 2x + 4y = 36$ （1 分）

解得 x = 12, y = 3，故  $C_{1}$  和  $C_{2}$  的个数比为 4:1（1 分）
