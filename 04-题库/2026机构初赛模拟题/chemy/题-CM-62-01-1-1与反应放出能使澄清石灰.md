# 题-CM-62-01-1-1与反应放出能使澄清石灰

## 题目

### 第 1 题（10 分）

1-1 $\mathrm { Pb } ( \mathrm { CH } _{ 3 } \mathrm { COO } ) _{ 2 }$ 与 $\mathrm { I } _{ 2 }$ 反应放出能使澄清石灰水变浑浊的气体， 并生成一种有香味的物质。
1-2 在络合滴定中用 HCHO 解蔽 $Z \mathrm { n } ( \mathrm { CN } ) _{ 4 } { } ^{ 2 \cdot }$ 。
1-3 在 $250^{ \circ } \mathrm { C }$ ， $350 \mathrm { atm }$ 下， ${ \mathrm { Re } } _{ 2 } { \mathrm { O } } _{ 7 }$ 与CO 发生反应。
1-4 稀、冷的弱碱性 $\mathrm { KMnO _{ 4 } }$ 水溶液将烯烃 $R _{ 2 } { \bf C } { = } { \bf C } { \bf R } _{ 2 } )$ 氧化。
1-5 $- 70^{ \circ } \mathrm { C }$ 时 $\mathrm { CoF } _{ 3 }$ 与 ${ \bf N } _{ 2 } { \bf O } _{ 5 }$ 反应， 生成一种挥发性的绿色晶体。
