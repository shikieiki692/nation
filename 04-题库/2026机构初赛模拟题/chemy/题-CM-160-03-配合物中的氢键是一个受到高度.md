# 题-CM-160-03-配合物中的氢键是一个受到高度

## 题目

### 第 3 题

第 3 题 （12 分， 占 $10 \%$ ） $\mathbf { R } \mathbf { u }$ 配合物的结构

配合物中的氢键是一个受到高度关注的研究领域，在生物化学中不少的金属酶都是以氢键的方式在温和的条件下实现其生理功能。 Kuwata 等人合成了 Ru 中心的该类化合物。

![](images/228957cda7191b8235c4ec906955208f34e5c87dee6b2cb99372281284c91ebd.jpg)

3-1 Kuwata 等人用上述方法合成了配合物的关键配体 $\mathrm { LH } _{ 3 }$ 。 给出其结构。

3-2 上述配体与 $\mathrm { [ Ru ( C _{ 6 } H _{ 6 } ) Cl _{ 2 } ] _{ 2 } } 2 : 1$ 反应， 可以得到一种 1 : 1 型盐， 其阳离子是一个双核配合物，两个 $\mathtt { R u }$ 的配位环境相同。阴离子为一种简单阴离子。其中反应中只产生了一种小分子。 画出 $\mathrm { [ Ru ( C _{ 6 } H _{ 6 } ) Cl _{ 2 } ] _{ 2 } }$ 的结构以及反应产物的结构。

3-3 将 3-2 的产物用 $\mathrm { PPh } _{ 3 }$ 解离， 同样得到了 $1 : 1$ 型离子化合物。其中阴离子与阳离子存在特殊的作用力。 画出该化合物的结构， 表示出阴离子与阳离子的作用。

3-4 有趣的是，3-2 中的离子化合物可以与 PhNH-NHPh 以1:2 发生反应，理论上可以得到1种小分子副产物以及一种离子化合物。在该离子化合物中同样存在阴阳离子的特殊作用力。写出小分子副产物的化学式， 并给出离子化合物的结构。
