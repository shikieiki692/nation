# 题-CM-101-05-通过以下方法制备了一种钌的单

## 题目

### 第 5 题（12 分）

通过以下方法制备了一种钌的单核八面体配合物晶体。

在水溶液中，用过量银盐处理 $trans-[RuCl_{2}(NH_{2}CH_{2}CH_{2}NH_{2})_{2}]Cl$ ，反应后过滤；向滤液中加入 $NaN_{3}$ ，静置数小时后，加入 $NaPF_{6}$ 饱和溶液，便能得到该配合物的晶体。X-射线衍射表明，该晶体配离子仍为 $trans$ 构型；晶体中仅含一种阳离子和一种阴离子，其数目比为 1:1。晶体中 Ru 的质量分数为 23.17%。

5-1 通过计算，推出该配合物晶体的化学式。

5-2 写出在水溶液中用过量银盐处理 trans- $\left[\mathrm{RuCl}_{2}\left(\mathrm{NH}_{2}\mathrm{CH}_{2}\mathrm{CH}_{2}\mathrm{NH}_{2}\right)_{2}\right]$ Cl 的离子反应方程式 (产生六配位单核络离子)。

5-3 写出滤液与 $NaN_{3}$ 和 $NaPF_{6}$ 反应生成配合物晶体的离子反应方程式(反应放出气体)。

5-4 画出该配合物晶体中配离子的结构，注意体现立体结构。

5-5 该配合物晶体中存在两种氢键，分别写出其表达式(X-H…Y)。

## 参考答案

## 第5题（12分）

5-1 晶体的摩尔质量为： $M = 101.07 \, g/mol \div 23.17\% = 436.21 \, g/mol$ （1分）

阴离子为 $PF_{6}^{-}$ ，摩尔质量为 144.97 g/mol；阳离子的配体中应有两个乙二胺配体，其摩尔质量共为：120.19 g/mol；

其余配体的摩尔质量为：436.21 g/mol - 144.97 g/mol - 120.19 g/mol = 69.98 g/mol（1 分）故其余配体中共含 5 个 N 原子；由于 Ru 为八面体六配位，故 5 个 N 原子共形成 2 个配体；根据电荷平衡，只有 1 个配体带 1 个负电，因此为 1 个 $N_{3}$ -和 1 个 $N_{2}$ （1 分）

化学式为 trans- $[Ru(N_{3})(N_{2})(NH_{2}CH_{2}CH_{2}NH_{2})_{2}]$ (PF $_{6}$ )（1分）

$$
5 - 2 \text { trans } - [ \mathrm{RuCl} _{2} (\mathrm{NH} _{2} \mathrm{CH} _{2} \mathrm{CH} _{2} \mathrm{NH} _{2}) _{2} ] ^{+} + \mathrm{Cl} ^{-} + 3 \mathrm{Ag} ^{+} + 2 \mathrm{H} _{2} \mathrm{O} =
\text { trans } - \left[ \mathrm{Ru} (\mathrm{H} _{2} \mathrm{O}) _{2} \left(\mathrm{NH} _{2} \mathrm{CH} _{2} \mathrm{CH} _{2} \mathrm{NH} _{2}\right) _{2} \right] ^{3 +} + 3 \mathrm{AgCl} (2 \text { 分 })
5 - 32 \text { trans } - [ \mathrm{Ru} (\mathrm{H} _{2} \mathrm{O}) _{2} (\mathrm{NH} _{2} \mathrm{CH} _{2} \mathrm{CH} _{2} \mathrm{NH} _{2}) _{2} ] ^{3 +} + 4 \mathrm{N} _{3} ^{-} + 2 \mathrm{PF} _{6} ^{-}
= 2 \text { trans } - [ \mathrm{Ru} (\mathrm{N} _{3}) (\mathrm{N} _{2}) (\mathrm{NH} _{2} \mathrm{CH} _{2} \mathrm{CH} _{2} \mathrm{NH} _{2}) _{2} ] (\mathrm{PF} _{6}) + \mathrm{N} _{2} (2 \text { 分 })
$$
