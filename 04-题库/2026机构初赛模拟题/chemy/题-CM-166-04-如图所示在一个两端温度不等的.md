# 题-CM-166-04-如图所示在一个两端温度不等的

## 题目

### 第 4 题 HgS 与 HCl 的反应 （21 分，占 $10 \%$

如图所示， 在一个两端温度不等 $\langle \overset { \triangledown } { T _{ 1 } } \ne T _{ 2 } \rangle$ 的高温反应容器中，充入HCl 气体，并在 $\left| T _{ 1 } \right|$ 一端放置反应物 $\mathrm { HgS }$ 固体。一段时间后，在区域 2 沉积出化合物 $\pmb { x }$ 。

合物X。结构测定表明，X 有多

结构测定表明， $\pmb { x }$ 有多种晶型；其中一种为立方晶体，晶胞参数 $a = 1.792 \mathrm { nm }$ ； 晶体中仅含有 2 种粒子：一种为 $\mathrm { [ Hg } _{ x } \mathrm { S } _{ y } ] ^{ 8 + }$ 团簇，其中1 个团簇中心的坐标为 $( 0 , \frac { 1 } { 2 } , \frac { 1 } { 4 } )$ ；另一种为Cl-，它近似做简单立方堆积；晶体中最近的 Cl…Cl 间距约为 $0.44 \mathrm { nm }$ 。 晶体中存在沿4 条对角线方向的三次旋转轴， 且均穿过晶胞的中心。 晶体密度 $D = 6.80 \mathrm { g } / \mathrm { cm } ^{ 3 }$ 。

![](images/cb88824786cfb375765b68ca6ff8469e73cac95f173af2b49412f929e4379a14.jpg)

4-1 在硫化汞 $\mathrm { HgS }$ 晶体中存在一维链状结构。画出该结构的示意图。
4-2 指出反应生成 $\pmb { x }$ 的动力；写出在区域1 沉积的化合物的化学式。
4-3 通过计算和推理，确定 $x$ 、 $y$ 的数值；并写出其他所有团簇中心的坐标参数。
4-4 画出团簇 $\mathrm { [ Hg } _{ x } \mathrm { S } _{ y } ] ^{ 8 + }$ 的结构示意图。
4-5 在该晶体中，每个 $\mathrm { Hg }$ 周围有多少个Cl-？指出Cl-的最大配位数；说明这样的 Cl-在晶胞
里有多少个。
4-6 写出该晶体的点阵形式和结构基元。

## 参考答案

![](images/c1f3dfb96194a1000d5e31db5f467b7ad574dc14ecb22f7c533d56b7bfb3d066.jpg)

![](images/149eb31059f4ba84e3bc583466e635beaa5f3bb27fc757735f5675d6fbdd05f7.jpg)

4-2 在高温区，发生反应 $HgS + 2HCl \rightarrow HgCl_{2} + H_{2}S$ ， $HgCl_{2}$ 为气态，推动反应进行。在低温区， $3HgCl_{2}(g) + 2H_{2}S \rightarrow X + 4HCl$ ，反应放热生成稳定固体，推动反应进行。（2 分）
区域 1 沉积的是 HgS（1 分）

4-3 每个晶胞参数的距离对应的氯离子的数目为： $1.792 / 0.44 = 4.1 \approx 4$

由于氯离子为简单立方堆积，所以晶胞中氯离子个数为 $4^{3} = 64$ （1分）

晶胞摩尔质量 $M = DN_{A}V = 6.80 \, g/cm^{3} \times 6.022 \times 10^{23}/mol \times (1.792 \, nm)^{3} = 23565 \, g/mol$ （2分）

根据电荷守恒，晶胞中有8个阳离子。

根据摩尔质量： $8 \times (200.6x + 32.06y) + 64 \times 35.45 = 23565$ ；根据氧化态： $2x - 2y = 8$

解得： $x = 12$ （1分） $y = 8$ （1分）

团簇坐标： $(0,0,0)$ ; $(1/2,1/2,1/2)$ （1分）

$(0, \frac{1}{2}, \frac{3}{4})$ ; $(\frac{1}{2}, \frac{1}{4}, 0)$ ; $(\frac{1}{2}, \frac{3}{4}, 0)$ ; $(\frac{1}{4}, 0, \frac{1}{2})$ ; $(\frac{3}{4}, 0, \frac{1}{2})$ （2分）

前 2 个坐标全部写对，得 1 分。

后 5 个坐标，写对 3 个以上得 1 分，写对 5 个得 2 分；有错误不得分。
