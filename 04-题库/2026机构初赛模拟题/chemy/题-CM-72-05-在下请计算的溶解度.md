# 题-CM-72-05-在下请计算的溶解度

## 题目

### 第 5 题（10 分）

在 $298.15 \mathrm { K }$ 下， $\Delta _{ \mathrm { f } } G _{ \mathrm { m } } { \mathrm { ^{ e } } } ( \mathrm { Ca ( OH ) } _{ 2 } , \mathrm { s } ) = - 895.7 \mathrm { kJ / mol }$ ， $\Delta _{ \mathrm { f } } G _{ \mathrm { m } } { } ^{ \mathrm { e } } ( \mathrm { H } _{ 2 } \mathrm { O } , \mathrm { l } ) { = } { - } 237.1 \mathrm { kJ / mol }$ ， $E ^{ \circ } ( \mathrm { Ca } ^{ 2 + } / \mathrm { Ca } )$ $= - 2.868 \mathrm { V }$ ， $K _{ \mathrm { w } } = 1.00 \times 10^{ - 14 }$ ， 请计算 $\mathrm { Ca ( OH ) } _{ 2 }$ 的溶解度 $( \mathbf { g } / \mathrm { L } )$ 。

## 第5题（10分）


$= -2.868\mathrm{V},\mathrm{K}_{\mathrm{w}} = 1.00\times 10^{-47}$ ，请计算 $\mathrm{Ca(OH)_2}$ 的溶解度(g/L)。
对于反应 $\mathrm{Ca(s)} + 2\mathrm{H}_2\mathrm{O(l)} = \mathrm{Ca(OH)_2(s)} + \mathrm{H}_2(\mathrm{g})$ $\Delta_{\mathrm{f}}G_{\mathrm{m}}^{\ominus} = -895.7\mathrm{kJ / mol} + 2\times 237.1\mathrm{kJ / mol} = -421.5\mathrm{kJ / mol}$ （1分）
$K_{1} = \exp (-\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus} / RT) = 7.042\times 10^{73}$ （1分）
对于反应 $\mathrm{Ca(s)} + 2\mathrm{H}_2\mathrm{O(l)} = \mathrm{Ca}^{2 + }(\mathrm{aq}) + 2\mathrm{OH}^{-}(\mathrm{aq}) + \mathrm{H}_2(\mathrm{g})$ $E(\mathrm{Ca}^{2 + } / \mathrm{Ca}) = E^{\ominus}(\mathrm{Ca}^{2 + } / \mathrm{Ca}) = -2.868\mathrm{V}$ （1分）
$E(\mathrm{H}^{+} / \mathrm{H}_{2}) = E^{\ominus}(\mathrm{H}^{+} / \mathrm{H}_{2}) + (0.0591 / n)\lg ([\mathrm{H}^{+}]^{2} / c^{\ominus 2})$ $= 0\mathrm{V} + (0.0591\mathrm{V} / 2)\lg ((1.00\times 10^{-14})^{2})$ $= -0.827\mathrm{V}$ （1分）
$E = E(\mathrm{H}^{+} / \mathrm{H}_{2}) - E(\mathrm{Ca}^{2 + } / \mathrm{Ca}) = 2.041\mathrm{V}$ （1分）
$K_{2} = \exp (nFE / RT) = 1.008\times 10^{69}$ （1分）
因此对于 $\mathrm{Ca(OH)_2(s)} = \mathrm{Ca}^{2 + }(\mathrm{aq}) + 2\mathrm{OH}^{-}(\mathrm{aq})$ ，有：
$K = K_{2} / K_{1} = 1.432\times 10^{-5}$ （1分）
设饱和溶液的浓度为 $c$ ，则：
$K = c\cdot (2c)^2$ （1分）
解得 $c = 1.530\times 10^{-2}\mathrm{mol / L}$ （1分）
$m = Mc = 74.10\mathrm{g / mol}\times 1.530\times 10^{-2}\mathrm{mol / L} = 1.13\mathrm{g / L}$ （1分）
不要求有效数字；采取其他合理方法，得出相近结果的，也可得分。
