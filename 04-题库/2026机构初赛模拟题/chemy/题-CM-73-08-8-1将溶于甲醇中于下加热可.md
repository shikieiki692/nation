第1题（17分）

1-1 VA 族元素可以形成一些结构特殊的原子簇。

1-1-1 将 $BiCl_{3}$ 及 $AlCl_{3}$ 与化学计量的 Bi 在熔融 $NaAlCl_{4}$ 中反应，改变投料比，可以分别制得离子化合物 A 和 B，若要生成相同物质的量的 A 和 B，则制备时分别投入的 Bi 的比例为 6:11。已知 A 中 Bi 的质量分数为 67.4%，且 A 中所有原子均满足八隅律。

1-1-1-1 通过计算，确定离子化合物 A 的化学式。

1-1-1-1 由题意可设 A 的化学式为  $\mathrm{Bi}_{m}(\mathrm{AlCl}_{4})_{n}$
则根据 Bi 的质量分数可知  $mM(\mathrm{Bi}) = 0.674 [mM(\mathrm{Bi}) + nM(\mathrm{AlCl}_{4})]$ （1 分）
解上述不定方程，求得唯一符合题目条件的解
即 m = 5, n = 3，则 A 的化学式为  $\mathrm{Bi}_{5}(\mathrm{AlCl}_{4})_{3}$ （1 分）

1-1-1-2 离子化合物 B 中阳离子为 +2 价，阴离子与 A 相同，通过计算确定 B 的化学式。

1-1-1-2 由题意可设 B 的化学式为  $\mathrm{Bi}_{m}(\mathrm{AlCl}_{4})_{2}$
由于生成相同物质的量的 A 和 B，需分别投入的 Bi 的比例为 6:11
而  $Bi_{5}^{3+}$  可看做  $Bi^{3+} + 4Bi$ ，则  $Bi_{m}^{2+}$  则可看做  $2/3Bi^{3+} + (3m - 2)/3Bi$ （1 分）
故可知 m = 4，则 B 的化学式为  $\mathrm{Bi}_{8}(\mathrm{AlCl}_{4})_{2}$ （1 分）

1-1-2 除了 A 和 B 中的阳离子外，Bi 还可以形成一种与  $BF_{3}$  对称性相同的正离子，其最早被发现于 Bi 的黑色次氯化物 C 中。已知 C 中存在着比例为 3:1 的两种价态（其中一种为 +3 价）的 Bi，和三种比例为 2:4:1 的含 Bi 离子，阴离子中 Bi 均为四方锥配位，C 中 Bi 的质量分数为 83.48%。

1-1-2-1 通过计算和推导，写出能表示 C 的具体组成的化学式。

1-1-2-1 由题意可知 C 只由 Bi 和 Cl 构成
则 C 中  $n(\mathrm{Bi}):n(\mathrm{Cl})=\omega(\mathrm{Bi})M(\mathrm{Cl})/\omega(\mathrm{Cl})M(\mathrm{Bi})=6:7$  （1 分）
由价态可知 C 应为  $Bi_{24}Cl_{28}$ ，且其中由 6 个 Bi 为 +3 价，其他 18 个 Bi 一共呈现 +10 首先可以推断这 18 个 Bi 应是 Bi 形成的正离子
其次存在两种可能 2:4:1 中的 “1” 为该正离子  $Bi_{18}^{10+}$ ，“2” 为该正离子  $Bi_{9}^{5+}$ （1 分）
而由阴离子中 Bi 均为四方锥配位可知符合条件的是  $Bi_{9}^{5+}$
且剩下的 “4” 对应着  $BiCl_{5}^{2-}$ ，“1” 对应着  $Bi_{2}Cl_{8}^{2-}$ （1 分）
则 C 的化学式为  $(\mathrm{Bi}_{9}^{5+})_{2}(\mathrm{BiCl}_{5}^{2-})_{4}(\mathrm{Bi}_{2}\mathrm{Cl}_{8}^{2-})$ （1 分）
