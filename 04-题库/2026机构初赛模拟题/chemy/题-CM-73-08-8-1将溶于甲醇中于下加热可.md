# 题-CM-73-08-8-1将溶于甲醇中于下加热可

## 题目

### 第 8 题（9 分）

8-1 将 $262 \mathrm { mg } \mathrm { Cr ( acac ) _{ 3 } \cdot 143 \mathrm { mg } NiCl _{ 2 } \cdot 6 H _{ 2 } O \cdot 243 \mathrm { mg } H _{ 2 } L \cdot 101 \mathrm { mg } NEt _{ 3 } }$ 溶于甲醇中，于 $120^{ \circ } \mathrm { C }$ 下加热 $12 \mathrm { h }$ ， 可以得到一种七核配合物。若不考虑溶剂共同结晶，其中 $\mathrm { Cr }$ 的含量为 $1.52 \%$ ，Ni 含量为 $10.30 \%$ ， 请推导出该配合物的化学式。 配体 $\mathrm { H } _{ 2 } \mathrm { L }$ 可简化表示， 其结构如下图：

![](images/64c401685250408319ac9a9a753c90270060178fa9dacc7bb42a16b8a336d15a.jpg)

8-2 请给出其中 NEt3 的作用。

8-3 在阳离子中Cr 和Ni 均为6 配位，其中含有六次反轴。其中 HL-的配位方式有1 : 1 两种配位方式， 如下图所示。 请给出该阳离子的结构， 配体简化为用配位原子表示。

![](images/8e04d496a5e961a1d755f73743524edfcb124777ffc413f4c4af301de01750b0.jpg)

## 参考答案

## 第8题（9分）

![](images/6ec956e5375beeaf6b5c66969a96c17c4c37f0808a4200f8ea9be16b29180817.jpg)

8-1 $n(\mathrm{Cr}):n(\mathrm{Ni})=(1.52\%/52.00)/(10.30\%/58.69)=1:6$ （1分）
由下问可知金属离子位于阳离子中，在该体系中平衡电荷的阴离子有极大的可能为 Cl，
因此不妨假设该物质的化学式为 $\mathrm{CrNi_{6}(HL)_{x}Cl_{y}}$ （1分）
经尝试得，当 x=12, y=3 时有合理解，因此该配合物得化学式为 $\mathrm{CrNi_{6}(HL)_{12}Cl_{3}}$ （1分）

8-2 缚酸剂（1 分）

![](images/42fdb1b501e335c7d42f80ebb337d4d5cee552300109cca0fb538c9dd0ccef2d.jpg)

8-3 金属均为六配位因此需要有配位原子 42 次配位，第一种配位方式可以对金属原子配位 4 次，第二种可以配位 3 次因此不需要 Cl 对金属进行配位，可以得知阳离子为 $\mathrm{CrNi_{6}(HL)_{12}^{3+}}$

![](images/2673458d6337e30a06fd3e97947e9dbfbe37570a333ac69e9d129e54413be136.jpg)

外围的 Ni 仍有一个 N 一个 O 的配位没有示出（5 分，画出该结构即可得满分）
