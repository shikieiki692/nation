## 题目

### 第 16 题 末端炔烃的制备

16-1 一种高效合成化合物 ${ \mathsf { B } } ( { \mathrm { C } } _{ 10 } \mathrm { H } _{ 10 } { \mathrm { O } } )$ 及其衍生物的反应如下所示， 其中 benzaldehyde 是苯甲醛。

NaH, THF, $0^{ \circ } \mathsf { C }$ ; 1) Tf2O, NEt3 O n-BuLi; CH2Cl2, -78°C Me OMe benzaldehyde A 2) MeMgBr (2 eq) B 2M NaOH toluene, $\mathsf { - } 78^{ \circ } \mathsf { C }$ to r.t.

16-1-1 画出化合物A 的结构式，并解释生成A 的区域选择性。
16-1-2 画出生成B 的中间产物和B 的结构式。
