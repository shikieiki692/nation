# 题-CM-61-02-回答以下问题

## 题目

### 第 2 题（17 分）

回答以下问题：

2-1 在固态，锑华 $\mathrm { ( Sb } _{ 2 } \mathrm { O } _{ 3 } \mathrm { ) }$ 的一种晶型呈现出由锑、氧原子交错构成的无限双链结构，而砒霜$\left( \mathrm { As } _{ 2 } \mathrm { O } _{ 3 } \right)$ 则是由十二元环构成的单层平面结构。试画出这两种结构的示意图，每种结构至少要示出一个环。
2-2 在离子 $\mathrm { [ Fe _{ 5 } O ( CH _{ 3 } COO ) _{ 12 } ] ^{ + } }$ 中，铁具有两种配位数和两种化学环境，其数目比为2:3，醋酸根离子为桥联配体或单齿配体。画出其结构。
2-3 丁二酸和戊二酸的四个 $\mathsf { p } K _{ \mathrm { a } }$ 为 4.21、4.34、5.41 和 5.64，指出这些常数分别是哪个酸的几级酸常数。
2-4 锇与一氧化碳能形成一种具有4 个三重轴的阴离子 $[ \mathrm { Os } _{ 20 } ( \mathrm { CO } ) _{ 40 } ] ^{ 2 \cdot }$ -。此阴离子的结构可看做由 20 个 Os 原子做最密堆积，堆成一个正四面体结构；所有的 Os 均被 CO 配位；其中，与不同化学环境的 Os 配位的 CO 的数目不同。该离子中 Os 有几种化学环境？分别是哪几种？这几种化学环境的Os 分别被几个CO 配位？
2-5 某种含氮 $35.00 \%$ 的盐受热分解，失水得到气体A。在 $1000 \mathrm { K }$ 附近，A 会发生分解，产物为两种短周期元素的单质，这两种元素在周期表中相邻。若有痕量氯气存在并光照，A 的分解反应会进行得更快， 反应过程主要包括自由基的产生，转移和湮灭三步，写出得到气体A 的化学反应方程式， 并分步写出氯气存在下A 分解的反应机理。

2-3 4.21, 4.34, 5.41 和 5.64 分别为丁二酸的 $K_{\mathrm{a} 1}$, 戊二酸的 $K_{\mathrm{a} 1}$, 戊二酸的 $K_{\mathrm{a} 2}$, 丁二酸的 $K_{\mathrm{a} 2}$ (2 分)。这可以解释为电子效应的影响强度随共价键数目的变多而减弱。—COOH 具有吸电子诱导效应, 因此碳链越短, 酸性越强, $K_{\mathrm{a} 1}$ 越小; 而—COO-具有给电子诱导效应, 因此碳链越短, 酸性越弱, $K_{\mathrm{a} 2}$ 越大。

```txt
2-4 共 3 种化学环境（1 分）
一种位于正四面体的顶点（0.5 分），每个被 3 个 CO 配位（0.5 分）
一种位于正四面体的棱上（0.5 分），被 2 个 CO 配位（0.5 分）
一种位于正四面体的面上（0.5 分），被 1 个 CO 配位（0.5 分）
```
