# 题-CM-72-09-右图是的结构Ln表示稀土原子

## 题目

### 第 9 题（12 分）

![](images/2cd34204fc6c29f4abc5fea4d618706476d3393bc929b042443d7df0955138bf.jpg)

右图是 $\mathrm { Ba } _{ 3 } \mathrm { Ln } _{ 2 } \mathrm { O } _{ 5 } \mathrm { Cl } _{ 2 }$ 的结构(Ln 表示稀土原子)：

9-1 指出该晶体所属晶系。
9-2 指出其中位于晶胞(0.5, 0.5, 0)和(0, 0, 0)位置的分别是什么元素。9-3 氯原子的化学环境和空间环境有几种？每个氯被几个Ba 配位？9-4 指出晶胞的最高次旋转轴及其位置。
9-5 指出Ln-O 形成的四方锥之间的连接方式。
9-6 当 $\mathrm { Ln } = \mathrm { Gd }$ 时，晶胞参数 $a = 4.454 \mathrm{mathring A}$ ， $c = 24.84 \mathrm{mathring A}$ ， 计算其密度(Gd的原子量为 157.25)。
(注：右图中每个 仅代表一个原子，因无法找到更好的晶体图片，故只能使用此图代替。)

## 参考答案

## 第9题（12分）

![](images/8876ea5e57ecaf2a36b77e1b54a17f4db821d78a1c916f643ceeeb9ec6a43219.jpg)


9-6 $D = ZM / VN_{\mathrm{A}}$ $= 2 \times (137.3 \times 3 + 114.8 \times 2 + 16 \times 5 + 35.45 \times 2) / 4.454^{2} \times 24.84 \times 10^{-24} \times 6.022 \times 10^{23}$ $= 5.34\mathrm{g/cm^3}$ （3分）
