# 题-CM-72-07-7-1暗红色固体是众所周知的

## 题目

### 第 7 题（8 分）

7-1 暗红色固体 $\mathrm { PtF } _{ 6 }$ 是众所周知的超强氧化剂，其特殊的性质也决定了它不同寻常的反应特性。在无水氟化氢溶剂中， $\mathrm { PtF } _{ 6 }$ 和CO 反应，得到离子化合物A(含铂 $63.25 \%$ 和一种可作氟化剂的剧毒物质；而在 ${ \mathrm { SbF } } _{ 5 }$ 的存在下， ${ \mathrm { PtF } } _{ 6 }$ 和 CO 反应， 则得到离子化合物 B。 $\pmb { \mathsf { A } }$ 和 B 的阳离子相同，其中心原子的周围电子数为 16； $\pmb { \mathsf { A } }$ 的阴离子为单核配离子， $B$ 的阴离子为双核配离子。请分别写出生成 $\pmb { \mathsf { A } }$ 和B 的反应方程式。

7-2 强氧化剂 $\mathrm { KrF } _{ 2 }$ 的氧化性远高于 ${ \mathrm { PtF } } _{ 6 }$ ， 如 $\mathrm { KrF } _{ 2 }$ 能在 ${ \mathrm { SbF } } _{ 5 }$ 的存在下将 $\mathrm { XeOF } _{ 4 }$ 氧化成 C；C中 Xe 为 $^{ + 6 }$ 氧化态， C 与B 阴离子相同。 写出生成C 的反应方程式。

7-3 许多铂系金属氟化物也可以和 $\mathrm { KrF } _{ 2 }$ 发生反应。例如，在 $\mathrm { O } _{ 2 }$ 氛围中， $\mathrm { PdF } _{ 4 }$ 与 $\mathrm { KrF } _{ 2 }$ 反应，得到离子化合物 D。D 为 1:1 型盐，其阳离子为双核阳离子， 键级为 2.5； 阴离子为八面体配离子。写出生成D 的反应方程式。

## 参考答案

第7题（8分）

7-1  $3PtF_{6} + 7CO = [Pt(CO)_{4}][PtF_{6}]_{2} + 3COF_{2}$  （2分）
 $PtF_{6} + 4SbF_{5} + 6CO = [Pt(CO)_{4}][Sb_{2}F_{11}]_{2} + 2COF_{2}$  （2分）

7-2  $4XeOF_{4} + 5KrF_{2} + 12SbF_{5} = 4[XeF_{5}][Sb_{2}F_{11}] + 2O_{2}[Sb_{2}F_{11}] + 5Kr$  （2分）
氧化产物写  $OF_{2}$  或  $O_{2}$  也可得分。

7-3  $PdF_{4} + KrF_{2} + O_{2} = O_{2}PdF_{6} + Kr$  (2 分)
