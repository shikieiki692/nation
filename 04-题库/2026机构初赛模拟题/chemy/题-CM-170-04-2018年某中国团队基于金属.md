4-1-1 圈出在 $\pmb { M } _{ 4 } \pmb { L } _{ 4 } ^{ 8 + }$ 中所有参与配位的原子。
4-1-2 在这一四面体分子笼中， $\pmb { \mathsf { M } } ( \mathbf { II } )$ 展现出了一种稍显特殊的配位数， 写出其配位数。

4-1-5 写出该阳离子的所有对称元素。
在 $[ \pmb { \mathsf { M } } _{ 4 } \pmb { \mathrm { L } } _{ 4 } ] \pmb { \times } _{ 8 }$ 的质谱中发现了如下几个峰： $m / z = 610.6775$ , 711.6234, 846.8852, 1036.2516,1320.3012。理论而言还有三个更大质荷比的峰， 但超出质量检测范围而未能发现。

## 参考答案

第4题（23分， $18\%$ ）


4-1-2 配位数为 9（1 分）每个配体有 9 个配位原子，M 和 L 个数相等，因此 M 为 9 配位。

4-1-3 三帽三棱柱（2 分）

常见的配位方式是三帽三棱柱和加帽四方反棱柱，但前者更符合四面体分子笼的对称性。

4-1-4

![](images/55d9a4ed3f75b8c10bec445e19207fb70f0667d44ddb1db67a0c136a4811ec4b.jpg)
(3 分)

其中表示出 “加帽的三个原子是 N” 得 1 分，表示出 “O-N-O 应该横跨一个三棱柱的侧面矩形，两个 O 是其对角顶点，N 是该面上的加帽” 再得 2 分。不画出 M 与九个配位原子之间的键连关系不影响此题得分。

4-1-5 有 4 个 $C_{3}$ （1 分）和 3 个 $C_{2}$ （1 分）

该分子笼为 T 点群。之所以没有镜面，从 M 的配位结构不存在镜面就可以看出。

4-2-1 观察到 $610.6775 \times 8$ 、 $711.6234 \times 7$ 、 $846.8852 \times 6$ 、 $1036.2516 \times 5$ 、 $1320.3012 \times 4$ 近似相等，进一步计算可知它们几乎成公差为 100 的等差数列，从而可以分析出它们依次对应 $[M_{4}L_{4}]^{8+}$ 、 $[M_{4}L_{4}]X^{7+}$ 、 $[M_{4}L_{4}]X_{2}^{6+}$ 、 $[M_{4}L_{4}]X_{3}^{5+}$ 、 $[M_{4}L_{4}]X_{4}^{4+}$ （5 分）

$$
\left[ \mathrm{M} _{4} \mathrm{L} _{4} \right] \mathrm{X} _{\mathrm{n}} ^{(8 - \mathrm{n}) ^{+}} (n = 5, 6,
$$

4-2-2 $610.6775 \times 8$ 、 $711.6234 \times 7$ 、 $846.8852 \times 6$ 、 $1036.2516 \times 5$ 、 $1320.3012 \times 4$ 分别为 4885.42、4981.3638、5081.3112、5181.258、5281.2048。通过计算可知 X 的相对质量也即上述数列的公差，为 99.9468。鉴于 X 是一种简单阴离子，可以推出最接近该值的离子为 $ClO_{4}^{-}$ （2 分）接着，在此基础上，我们可以计算出由各个数据算出的 M 的相对质量，分别是 113.085、112.19595、112.3078、112.4195、112.5312，因此 M 为 Cd（2 分）
