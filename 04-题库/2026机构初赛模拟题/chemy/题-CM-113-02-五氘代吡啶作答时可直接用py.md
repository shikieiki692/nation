2-3-1 (6 分)

Path I: (2.5 分)

反应的速率方程可表示为： $r = k_{1}[B]$

而由物料守恒： $C_{\mathrm{V(V)}} = [\mathbf{B}] + [\mathbf{A}]$ ，又有 $K_{eq} = [\mathbf{B}] / [\mathbf{A}]$ [py]，故有：

$$
[ \mathbf {B} ] = K _{\mathrm{eq}} [ \mathrm{py} ] C _{\mathrm{V(V)}} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1)
r = k _{1} K _{\mathrm{eq}} [ \mathrm{py} ] C _{\mathrm{V(V)}} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1)
$$

Path II: (1.5 分)

反应的速率方程可表示为： $r = k_{1}[\mathrm{py}][\mathbf{B}]$

而由物料守恒与 Path I 相同，故有：

$$
r = k _{1} K _{\mathrm{eq}} [ \mathrm{py} ] ^{2} C _{\mathrm{V(V)}} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1)
$$

Path III: (2 分)

反应的速率方程可表示为： $r = k_{1}[\mathrm{py}][\mathbf{B}] + k_{2}[\mathrm{py}][\mathbf{A}]$

由 A 的物料守恒以及 $K_{eq}$ 的关系式可得:

$$
[ \mathbf {B} ] = K _{\mathrm{eq}} [ \mathrm{py} ] C _{\mathrm{V} (\mathrm{v})} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1); [ \mathbf {A} ] = C _{\mathrm{V} (\mathrm{v})} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1)
r = k _{1} K _{\mathrm{eq}} [ \mathrm{py} ] ^{2} C _{\mathrm{V(V)}} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1) + k _{2} [ \mathrm{py} ] C _{\mathrm{V(V)}} / (K _{\mathrm{eq}} [ \mathrm{py} ] + 1)
$$

![](images/940fc74549d2c0bae6cea82cc08f20e06b7a5bd56f66c3f779df357e0d2dd999.jpg)

2-3-2 三种途径的 $k_{\mathrm{obs}}$ 如下：（1分）
Path I: $k_{\mathrm{obs}} = k_1K_{\mathrm{eq}}[\mathrm{py}] / (K_{\mathrm{eq}}[\mathrm{py}] + 1)$
Path II: $k_{\mathrm{obs}} = k_1K_{\mathrm{eq}}[\mathrm{py}]^2 / (K_{\mathrm{eq}}[\mathrm{py}] + 1)$
Path III: $k_{\mathrm{obs}} = (k_1K_{\mathrm{eq}}[\mathrm{py}] + k_2)[\mathrm{py}] / (K_{\mathrm{eq}}[\mathrm{py}] + 1)$
而[py] &gt;&gt; $1 / K_{\mathrm{eq}}$ 时有：（1分）
Path I: $k_{\mathrm{obs}} = k_1$
Path II: $k_{\mathrm{obs}} = k_1[\mathrm{py}]$
Path III: $k_{\mathrm{obs}} = k_1[\mathrm{py}] + k_2 / K_{\mathrm{eq}}$
显然高浓度 py-$d_5$ 条件下作 $k_{\mathrm{obs}}$ 的切线会发现 $k_{\mathrm{obs}}$ 具有纵轴截距且会发现 $k_{\mathrm{obs}}$ 与[py]正相关（近似为直线）（1分）故：Path III 为最合理的反应历程。（1分）
