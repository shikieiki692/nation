## 题目

### 第 11 题 羰基化合物的反应（19 分，占 9.5%）

11-1 $\alpha$ 杂原子取代羰基化合物在天然产物和药物分子的合成中具有重要用途。 酰胺化合物A在三氟甲磺酸酐 (Tf2O) 和2-碘吡啶（2-I-py） 存在下，与手性亚磺酰胺试剂反应， 生成 $\alpha$ 氨基酰胺化合物H. 反应过程如下：

U n Bu Tf2O 3 2-1-Py G / T1O[C17H16N]OTf C17H17NO NR2 2-1-py [2.3]o重排 2-1-pyH+ R2N \`Ph HN. Ph C34H37N2OS\* C34H36N2OS

11-1-1 画出中间体B、 C、F和G的结构。

11-1-2 中间体 $\mathbf { \delta } _{ \mathbf { { p } } }$ 和E哪个形成更快? 说明原因。

11-1-3 画出 G到H的过渡态结构。

11-2 如下过程可用于 $\alpha$ 羟基酮的制备。 该反应的关键在于中间体 L 的形成以及 L 中羰基在光激发下形成双自由基M.

11-2-4 画出化合物S经硼氢化钠处理后得到的最终产物结构。
