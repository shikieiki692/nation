# 题-CM-172-05-为测定某水样中的微量的含量采

## 题目

### 第 5 题 水样中微量锰的测定 （12 分， 占 $6 \%$

为测定某水样中的微量的 $\mathrm { Mn } ^{ 2 + }$ 含量，采取以下方法： 取 $100.00 ~ \mathrm { mL }$ 水样， 用缓冲溶液调节$\mathsf { pH } = 3.0$ ， 加入足量 $\mathrm { H } _{ 5 } \mathrm { IO } _{ 6 }$ 充分反应， 使所有 Mn(II)转化为 $\mathbf { Mn } ( \mathrm { VII } )$ ； 体系中过量的 ${ \mathrm { H } } _{ 5 } { \mathrm { IO } } _{ 6 }$ 用钼酸盐掩蔽后， 加入足量KI 充分反应，然后用浓度为 $0.02025 \mathrm { mol } / \mathrm { LNa } _{ 2 } \mathrm { S } _{ 2 } \mathrm { O } _{ 3 }$ 溶液滴定，消耗 $23.03 ~ \mathrm { mL }$ 。 写出下划线处发生的所有离子反应方程式； 计算水样 ${ \mathrm { Mn } } ^{ 2 + }$ 含量 $\left( { \mathrm { mg / L } } \right)$ 。

## 参考答案

$$
2 \mathrm{Mn} ^{2 +} + 5 \mathrm{H} _{5} \mathrm{IO} _{6} \rightarrow 2 \mathrm{MnO} _{4} ^{-} + 5 \mathrm{IO} _{3} ^{-} + 11 \mathrm{H} ^{+} + 7 \mathrm{H} _{2} \mathrm{O} (2 \text {分})
\mathrm{IO} _{3} ^{-} + 5 \mathrm{I} ^{-} + 6 \mathrm{H} ^{+} \rightarrow 3 \mathrm{I} _{2} + 3 \mathrm{H} _{2} \mathrm{O} (2 \text {分})
2 \mathrm{MnO} _{4} ^{-} + 10 \mathrm{I} ^{-} + 16 \mathrm{H} ^{+} \rightarrow 2 \mathrm{Mn} ^{2 +} + 5 \mathrm{I} _{2} + 8 \mathrm{H} _{2} \mathrm{O} (2 \text {分})
$$

由于： $2Mn^{2+}\sim2MnO_{4}^{-}+5IO_{3}^{-}$ ； $2MnO_{4}^{-}\sim5I_{2}\sim10S_{2}O_{3}^{2-}$ ； $5IO_{3}^{-}\sim15I_{2}\sim30S_{2}O_{3}^{2-}$

所以： $Mn^{2+}\sim20S_{2}O_{3}^{2-}$ （2分）

$$
n \left(\mathrm{Mn} ^{2 +}\right) = 0.02025 \mathrm{mol} / \mathrm{L} \times 23.03 \mathrm{mL} \div 20 = 2.330 \times 10^{- 5} \mathrm{mol} (2 \text {分})
$$

转化为质量含量为： $2.330 \times 10^{-5} \, mol \times 54.94 \, g/mol \div 100.00 \, mL = 12.80 \, mg/L$ （2分）
