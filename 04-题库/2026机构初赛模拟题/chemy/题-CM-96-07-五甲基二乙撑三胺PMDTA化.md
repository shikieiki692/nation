# 题-CM-96-07-五甲基二乙撑三胺PMDTA化

## 题目

### 第 7 题（8 分）

五甲基二乙撑三胺[PMDTA，化学式为 $\mathrm{(CH_3)_2NCH_2CH_2N(CH_3)CH_2CH_2N(CH_3)_2}$ ]、NO与铁形成了化合物A[Fe(NO) $_2$ (PMDTA)];在-80°C时，A在四氢呋喃溶液中与O $_2$ 作用，得到化合物B[Fe(NO)(ONOO)(PMDTA)];B升至室温得到化合物C[Fe(NO $_2$ ) $_2$ (PMDTA)];C的甲醇溶液与大量NO气体作用，然后用KC $_8$ 还原又得回A。A、B、C都是单核配合物，铁的周围电子数均为18。

7-1 在 A 中铁为四面体配位，画出 A 的结构，预测其磁属性以及铁的氧化态。(若有多种合理的异构体，画出其中一种即可，下同)

7-2 在 B 中铁为四方锥配位，过氧亚硝酸根配体用 N 和 O 配位，画出 B 的结构，指出铁的氧化态。

7-3 实验测得化合物 B 的有效磁矩 $\mu_{eff}=1.052\mu_{B}$ ，据此判断，化合物 B:

a) 为高自旋    b) 为低自旋    c) 高低自旋同时存在

7-4 在 C 中铁为八面体配位，配位原子为 3 个 N 原子和 3 个 O 原子。画出 C 的结构，指出铁的氧化态。
