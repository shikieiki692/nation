# 题-CM-166-08-8-1在四氯化碳溶液中336

## 题目

### 第 8 题 环己二烯体系的重排（15 分， 占 $8 \%$

8-1 在四氯化碳溶液中， 3,3,6,6-四苯基-1,4-环己二烯与 Br2 于室温反应 $26 \mathrm { h }$ ， 以 $98 \%$ 的产率得到化合物 $\pmb { \mathsf { A } } ( \mathbf { C } _{ 30 } \mathrm { H } _{ 22 } )$ 。

8-1-1 画出A 的结构简式以及生成A 的所有关键中间体。

8-1-2 若将反应物换为3,3,6,6-四(4-甲氧基苯基)-1,4-环己二烯，所得产物为 ${ \mathsf { \pmb { \mathsf { B } } } } ( \mathrm { C } _{ 34 } \mathrm { H } _{ 26 } \mathrm { Br } _{ 4 } \mathrm { O } _{ 4 } ) .$ 。
画出 B 的结构简式。

8-2 用酸处理以下化合物 $\pmb { x }$ 和Y，均能脱除甲醇分子并得到三取代产物。 $\pmb { x }$ 用酸处理， 仅得到了产物C；Y 用酸处理，所得产物为D1 和D2，其比例受反应温度影响： 反应所得D1 和D2 的比例随温度的关系如下图所示。

![](images/6064170f5a3bf953be4f64f10900f7053349c0f5f35e44c337b352df90f2dc2c.jpg)

8-2-1 分别画出C、 D1、 D2 的结构简式。

8-2-2 说明Y 用酸处理能得到两种产物， 而 $\pmb { x }$ 却只能得到一种产物的原因。
