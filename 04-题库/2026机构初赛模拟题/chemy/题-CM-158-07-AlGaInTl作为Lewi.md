# 题-CM-158-07-AlGaInTl作为Lewi

## 题目

### 第 7 题 11 分， $5 \%$

$\operatorname { E } ( \operatorname { C } _{ 6 } \operatorname { F } _{ 5 } ) _{ 3 } ( \operatorname { E } = \mathbf { B }$ 、Al、Ga、In、Tl)作为 Lewis 酸广泛应用于各种反应中，其酸性的测定显得尤为重要。研究其与一些电子给体形成加合物的稳定性，是一种测定酸性的方式。
7- `\mathrm { \bf ~ 1 ~ B } ( \mathrm { C } _{ 6 } \mathrm { F } _{ 5 } ) _{ 3 } .` py 升华熵为 $150 \mathrm { J \cdot mol ^{ - 1 } \cdot K ^{ - 1 } }$ ，其于 $160^{ \circ } \mathrm { C }$ 开始升华，此时饱和蒸气压为 $10^{ - 3 } \mathrm { mmHg }$ 。忽略焓变于熵变随温度的变化，计算 ${ \mathrm { B } } ( { \mathrm { C } } _{ 6 } { \mathrm { F } } _{ 5 } ) _{ 3 } { \cdot } { \mathrm { py } }$ 升华焓。
$7 { \cdot } 2 \ \mathrm { B } ( \mathrm { C } _{ 6 } \mathrm { F } _{ 5 } ) _{ 3 } .$ py(s)的一种可能分解途径为生成 $\mathrm { py ( g ) }$ 与 $\mathrm { B } ( \mathrm { C } _{ 6 } \mathrm { F } _{ 5 } ) _{ 3 } ( \mathrm { s } )$ ，该过程的熵变为 $121 { \mathrm { J } } { \cdot } { \mathrm { mol } } ^{ }$ $\mathrm { ^{ 1 } \cdot K ^{ - 1 } }$ 。已知 $\mathrm { B } ( \mathrm { C } _{ 6 } \mathrm { F } _{ 5 } ) _{ 3 } { \cdot } \mathrm { py } ( \mathrm { g } )$ 的解离焓为 $126.2 \mathrm { kJ } { \cdot } \mathrm { mol } ^{ - 1 }$ ， ${ \mathrm { B } } ( { \mathrm { C } } _{ 6 } { \mathrm { F } } _{ 5 } ) _{ 3 }$ 的升华焓为 $103.8 \mathrm { kJ } \cdot \mathrm { mol } ^{ - 1 }$ 。计算 $\mathrm { B } ( \mathrm { C } _{ 6 } \mathrm { F } _{ 5 } ) _{ 3 } { \cdot } \mathrm { py } ( \mathrm { s } )$ 通过该途径开始分解(py 蒸气压为 $\mathrm { 1 \ mmHg }$ )的温度。
`{ \bf 7 - 3 \ E ( C _{ 6 } F _{ 5 } ) _{ 3 } }` 与乙腈1 : 1 加合物的解离焓 $\mathrm { Al } > \mathrm { Ga } > \mathrm { In } > \mathrm { B } > \mathrm { Tl }$ ， 其随E 的周期数增加并非单调变化， 简述原因。

## 参考答案

## 第7题（11分，5%）

7-1 饱和蒸汽压达到大气压时，温度为 $\Delta H/\Delta S$

根据克拉伯龙方程带入两组数据

$$
\ln \frac {p _{1}}{101.325 k P} = \frac {\Delta H}{R} \left(\frac {\Delta H}{\Delta S} ^{- 1} - \frac {1}{(273.15 + 160) K}\right) (2 \text {分})
$$

解得 $\Delta H = 114 \, kJ \cdot mol^{-1}$ （1 分）

$$
\Delta \mathrm{H} = (126.2 + 114 - 103.8) \mathrm{kJ} \cdot \mathrm{mol} ^{- 1} = 136 \mathrm{kJ} \cdot \mathrm{mol} ^{- 1} (1
- R T \ln \left(\frac {1 m m H g}{750 m m H g}\right) = 136 k J m o l ^{- 1} - T \times 121 J m o l ^{- 1} K (1 \text {分})
$$

解得 $T = 773 \, K$ （1 分）

7-3 随周期数增大，原子半径变大，由三配位变为四配位的空间拥挤程度下降，位阻降低，配位能力增强（1 分）

同时随周期数增大，轨道能量变高，与轨道能量较低的 N 能量差变大，键能下降，配位能力下降（1 分）

由于两个趋势相反的因素影响，总体呈现非单调的变化趋势（1 分）
