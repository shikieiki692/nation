# 题-CM-205-06-1906年安德烈马尔可夫分析了普

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-14-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（26 分，占 13%）

1906 年，安德烈·马尔可夫分析了普希金的长诗《叶甫盖尼·奥涅金》，统计了其中元音字母和辅音字母的交替规律，从中得到启发提出了马尔可夫链(Markov Chain)。马尔科夫链是一种具有马尔可夫性（无记忆性）的随机过程，其核心思想是系统在时刻 t<sub>n+1</sub>的状态 X<sub>n+1</sub>只与时刻 t<sub>n</sub>的状态 X<sub>n</sub>有关，与 t<sub>n</sub>前的状态无关，用数学语言可表示为：

P(X<sub>n+1</sub> = s<sub>n+1</sub> | X<sub>n</sub> = s<sub>n</sub>, X<sub>n-1</sub> = s<sub>n-1</sub>, … , X<sub>0</sub> = s<sub>0</sub>) = P(X<sub>n+1</sub> = s<sub>n+1</sub> | X<sub>n</sub> = s<sub>n</sub>)

注：P 表示概率马尔可夫链堪称机器学习与人工智能的基石，在强化学习、股价波动、天气预测、语音识别、物种迁徙等领域都有着极其广泛的应用。有趣的是，1997 年的一项晶体工程研究中同样使用了马尔可夫链模型。

**6-1** 该研究使用一定浓度的(±)-PHTP 与 NPP 在 2-丁酮溶液中结晶形成了一种极性包合物，其具有二次谐波生成、电光效应、热释电效应等有趣的性质。研究表明，热释电位移电流在晶体的中部改变方向，说明极性在中部发生反转，宏观上晶体是由两个极性轴反向平行的极性畴形成的孪晶（下文中的“极性包合物”指的是孪晶被孪晶面分割所得的一半部分）。

![](images/0d43696d9298f3a8a2253c4b3093e669298c56109a0fe26570c3fb62884ad89a.jpg)

包合物中同种手性的 PHTP 堆积形成链，沿堆积方向观察，PHTP 彼此重叠。链排布成形似蜂巢的通道结构骨架，其中两种手性的 PHTP 形成的链无序分布。NPP 填入其中的通道形成NPP 链。

**6-1-1** 判断(±)-PHTP 所属的点群，并指出其是否具有极性。

**6-1-2** 研究表明，在 PHTP 链中沿堆积方向两分子 PHTP 的距离为 4.73 Å，NPP 分子中二级胺氮原子与硝基 N 原子的距离为 8.33 Å。包合物的化学式可用[(±)-PHTP]<sub>n</sub>[NPP]表示，其中n 为整数。通过估算和推理，直接写出 n 的值。

**6-2** (±)-PHTP 形成的骨架显然不具有极性，包合物整体的极性应由 NPP 的填入导致。

**6-2-1** 定义 NPP 的二级胺一端为 A 端，硝基一端为 B 端，通道中相邻的两个 NPP 可能以三种方式接触，即 A-A、A-B、B-B。将这三种方式按有利程度从大到小排列。

**6-2-2** Cosimo 认为，NPP 始终通过最有利的一种方式接触，形成极性的 NPP 链，从而形成极性的包合物。假设 NPP 确实始终通过最有利的一种方式接触，判断 Cosimo 的结论是否正确并解释原因。

**6-3** 事实上，以上假设并不正确。受(±)-PHTP 骨架通道的尺寸限制，NPP 在通道中无法翻转。而在晶体生长时，尽管大部分 NPP 之间确实以最有利的方式接触，但仍会出现少量“缺陷”，即以相对不利的两种方式接触。在此情境下，运用马尔科夫链模型即可解释包合物中存在的极性与所观察到的孪晶现象。

**6-3-1** 已知结晶过程在常温(298.15K)下进行，用 ΔG<sub>m</sub>(X-X)表示晶体生长过程中 X 与 X 发生接触的摩尔吉布斯自由能变。通过 ΔG<sub>m</sub>(A-A)、ΔG<sub>m</sub>(A-B)、ΔG<sub>m</sub>(B-B)分别表示出当上一分子NPP 末端为 A 时形成 A-A 接触的概率 P<sub>A</sub>(A-A)与当上一分子 NPP 末端为 B 时形成 B-B 接触的概率 P<sub>B</sub>(B-B)。

**6-3-2** 假设 P<sub>A</sub>(A-A) = 0.1，P<sub>B</sub>(B-B) = 0.005，思考晶体生长过程，计算给出极性包合物中两种取向的 NPP 分别所占的百分比。

**6-3-3** 根据以上模型，解释形成极性反转的孪晶的原因。若在晶体生长的溶液中加入少量 TP，判断所得包合物极性增大还是减小。

## 参考答案

**6-1-1** D<sub>3</sub>（2 分）不具有（1 分）

**6-1-2** 5（3 分）答 4 或 6 可得 1 分；其他答案不得分

**6-2-1** A-B > A-A > B-B（3 分）

**6-2-2** 错误（1 分）。NPP 链被(±)-PHTP 骨架隔开，链间几乎无作用（1 分），链的取向无序

（1 分）

**6-3-1**（共 4 分）P(A-A) = exp[-ΔG<sub>m</sub>(A-A) / (R·298.15K)] / {exp[-ΔG<sub>m</sub>(A-A) / (R·298.15K)] + exp[-ΔG<sub>m</sub>(A-B) / (R·298.15K)]}（2 分；写成其他合理的代数变形形式也可得分）P(B-B) = exp[-ΔG<sub>m</sub>(B-B) / (R·298.15K)] / {exp[-ΔG<sub>m</sub>(B-B) / (R·298.15K)] + exp[-ΔG<sub>m</sub>(A-B) / (R·298.15K)]}（2 分；写成其他合理的代数变形形式也可得分）

**6-3-2**（共 6 分）注意到 NPP 层间满足如下关系 P<sub>n+1</sub>(A) = P<sub>n</sub>(A)P<sub>A</sub>(A-B) + P<sub>n</sub>(B)P<sub>B</sub>(B-B)，即 P<sub>n+1</sub>(A) = P<sub>n</sub>(A)(1 - P<sub>A</sub>(A-A)) + (1 - P<sub>n</sub>(A))P<sub>B</sub>(B-B)；（1 分）代入数据得 P<sub>n+1</sub>(A) = 0.9P<sub>n</sub>(A) + 0.005(1 - P<sub>n</sub>(A)) = 0.895P<sub>n</sub>(A) + 0.005；（1 分）将其转化为 P<sub>n+1</sub>(A) - 1/21 = 0.895P<sub>n</sub>(A) - 179/4200 = 0.895(P<sub>n</sub>(A) - 1/21)，故该数列通项公式为 P<sub>n</sub>(A) = 0.895<sup>n-1</sup>(P<sub>0</sub>(A) - 1/21) + 1/21；（1 分）由于晶体的 n 极大，故第一项对晶体整体可忽略，得晶体中 P(A) = 1/21；（1 分）故极性包合物中两种取向的 NPP 所占百分比分别为 4.76 %与 95.24 %。（2 分）

**6-3-3** 原因：晶体沿±c 方向生长速率相同，生长方向相反使 NPP 主要取向相反。（2 分）减小（2 分）
