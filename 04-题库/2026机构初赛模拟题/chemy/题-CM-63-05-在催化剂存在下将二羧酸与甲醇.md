# 题-CM-63-05-在催化剂存在下将二羧酸与甲醇

## 题目

### 第 5 题（10 分）

在催化剂存在下将二羧酸与甲醇以摩尔比例 $1 : x$ 混合， 发生酯化反应并达到平衡。将羧酸与醇生成单酯、单酯与醇生成二酯的平衡常数分别记为 $K _{ 1 }$ 和 $K _{ 2 }$ ：

$$
\mathrm { R ( CO _{ 2 } H ) _{ 2 } + MeOH = R ( CO _{ 2 } H ) ( CO _{ 2 } Me ) + H _{ 2 } O }
\mathrm { R } ( \mathrm { CO _{ 2 } H } ) ( \mathrm { CO _{ 2 } Me } ) + \mathrm { MeOH } = \mathrm { R } ( \mathrm { CO _{ 2 } Me } ) _{ 2 } + \mathrm { H _{ 2 } O }
$$

5-1 将平衡常数 $K _{ 3 }$ 用 $K _{ 1 }$ 、 $K _{ 2 }$ 表示。

$$
\mathrm { R } ( \mathrm { CO _{ 2 } Me } ) _{ 2 } + \mathrm { R } ( \mathrm { CO _{ 2 } H } ) _{ 2 } = 2 \mathrm { R } ( \mathrm { CO _{ 2 } H } ) ( \mathrm { CO _{ 2 } Me } )
$$

5-2 通过计算和推演给出用 $K _{ 1 }$ 和 $K _{ 2 }$ 表示二羧酸转化为羧酸单酯的最大平衡收率

5-3 设 $K _{ 1 } = K _{ 2 } = 20$ ， 计算此时单酯的最大收率， 并推出此时 $x$ 的值。

5-4 在5-3 中的平衡体系中加入少量的水， 则反应平衡后单酯的产率是更大、更小、完全不变还是无法判断？

## 参考答案


$$
K _ {3}
$$

5-1 $K_{3} = K_{1} / K_{2}$ (2分)

5-2 方法一：设 $(\mathrm{CO}_{2}\mathrm{H})_{2}$、$(\mathrm{CO}_{2}\mathrm{H})(\mathrm{CO}_{2}\mathrm{Me})$、$(\mathrm{CO}_{2}\mathrm{Me})_{2}$ 的摩尔百分数为 $a: m:b$ 则有：$m^{2}/ab = K_{3}$ (2分)
又 $a + b + m = 1$，故 $m$ 达到最大值时，$a + b$ 必达到最小值；$ab$ 必达到该前提下的最大值，此时必然有 $a = b = (1 - m)/2$ (1分)
故 $m^{2}/[(1 - m)/2]^{2} = K_{1}/K_{2}$
解得最大收率 $m = 1/(1 + 2\sqrt{K_{2}/K_{1}})$ (1分)
方法二：设 $(\mathrm{CO}_{2}\mathrm{H})_{2}$、$(\mathrm{CO}_{2}\mathrm{H})(\mathrm{CO}_{2}\mathrm{Me})$、$(\mathrm{CO}_{2}\mathrm{Me})_{2}$ 的摩尔分数为 $1 - m - n:m:n$ 则有：$m(m + 2n)/(1 - m - n)(x - m - 2n) = K_{1}$ (1分)
$n(m + 2n)/m(x - m - 2n) = K_{2}$ (1分)
化简等式可知 $[n^{2} + (m - 1)n]K_{1} + m^{2}K_{2} = 0$ (1分)
为使得上式有解，$[K_{1}(m - 1)]^{2} - 4m^{2}K_{1}K_{2} \leq 0$，则 $m \leq 1/(1 + 2\sqrt{K_{2}/K_{1}})$
故最大平衡收率为 $1/(1 + 2\sqrt{K_{2}/K_{1}})$ (1分)
（共4分，用其他合理方法得出正确结论也可得分）
本题的本质其实与“在二元弱酸 $\mathrm{H}_{2}\mathrm{A}$ 的溶液中，在 $\mathrm{pH}$ 为多少时 HA-离子所占百分比最大”是相同的，都是分布分数的最大值的问题。

5-3 将 $K_{1} = K_{2} = 20$ 代入上述表达式，求得：$\eta_{max} = 33.3\%$ (1分)
设 $(\mathrm{CO}_{2}\mathrm{H})_{2}$、$(\mathrm{CO}_{2}\mathrm{H})(\mathrm{CO}_{2}\mathrm{Me})$、$(\mathrm{CO}_{2}\mathrm{Me})_{2}$ 的量均为 1，则水的量为 $2 \times 1 + 1 = 3$，根据平衡常数求得平衡时甲醇的量为 0.15 (1分)
故 $x = (0.15 + 2 \times 1 + 1)/3 = 1.05$ (1分)

5-4 变小 (1分)
利用 $2R(\mathrm{CO}_{2}\mathrm{H})(\mathrm{CO}_{2}\mathrm{Me}) = R(\mathrm{CO}_{2}\mathrm{Me})_{2} + R(\mathrm{CO}_{2}\mathrm{H})_{2}$ 的反应式前后均没有水参与来直接得到

单酯的产率不变显然是错误的，具体原因请读者自行思考。
