# 题-CM-271-02-有一个经验规则可以用于估算基元反

## 题目

### 第 2 题（8 分）

有一个经验规则可以用于估算基元反应的活化能，遵循下列情况时，可分别通过对应下表中的计算方法计算活化能：①反应中没有键的断裂的反应；②自由基与分子的放热反应；③反应中键不完全断裂(如协

![](images/9db5e26f9587531198b3afd13394c9bbc9952aa78d6e712584eae687d2a10c85.jpg)

根据上述经验规则及下面所提供的键能信息，估算氢气与氯气反应中各步基元反应的活化能，并与下列所给出的实验值比较。

Cl<sub>2</sub> = 2Cl· E<sub>a1</sub> = 242.8 kJ·mol<sup>-1</sup>

Cl· + H<sub>2</sub> = HCl + H· E<sub>a2</sub> = 25.1 kJ·mol<sup>-1</sup>

H· + Cl<sub>2</sub> = HCl + Cl· E<sub>a3</sub> = 12.6 kJ·mol<sup>-1</sup>

BE(Cl-Cl) = 243 kJ·mol<sup>-1</sup>；BE(H-H) = 436 kJ·mol<sup>-1</sup>；BE(H-Cl) = 431 kJ·mol<sup>-1</sup><sub> </sub>

## 参考答案

反应 1：Cl<sub>2</sub> = 2Cl·

直接使用经验公式 E<sub>a1</sub> = BE(Cl-Cl) = 243 kJ·mol<sup>-1</sup>（2 分）

反应 2：Cl· + H<sub>2</sub> = HCl + H· ΔH = BE(H-H) - BE(H-Cl) = 5 kJ·mol<sup>-1</sup> > 0（1 分）

不能直接使用经验公式 E<sub>a2</sub> = 0.05·BE(H-H) = 21.8 kJ·mol<sup>-1</sup>

应用正反应活化能 - 逆反应活化能 = ΔH 间接求算：

E<sub>a2</sub> = E<sub>a2,逆</sub> + ΔH = 0.05·BE(H-Cl) + 5 kJ·mol<sup>-1</sup> = 26.5 kJ·mol<sup>-1</sup>（2 分）

反应 3：H· + Cl<sub>2</sub> = HCl + Cl· ΔH = BE(Cl-Cl) - BE(H-Cl) = -188 kJ·mol<sup>-1</sup> < 0

直接使用经验公式 E<sub>a2</sub> = 0.05·BE(Cl-Cl) = 12.2 kJ·mol<sup>-1</sup>（2 分）

结果与实验值很好的符合（1 分）
