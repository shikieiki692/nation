# 题-CM-126-06-小心控制乙硼烷的气相热解反应

## 题目

### 第 6 题（9 分）

小心控制乙硼烷 $B_{2}H_{6}$ 的气相热解反应可以制备各种高级硼烷。有人提出，通过 $B_{2}H_{6}$ 热裂产生 $B_{4}H_{10}$ 的机理如下所示：

$$
\mathrm{B} _{2} \mathrm{H} _{6} \rightleftharpoons 2 \mathrm{BH} _{3}
\mathrm{B} _{2} \mathrm{H} _{6} + \mathrm{BH} _{3} \stackrel {k} {\rightarrow} \mathrm{B} _{3} \mathrm{H} _{7} + \mathrm{H} _{2}
\mathrm{B} _{3} \mathrm{H} _{7} + \mathrm{B} _{2} \mathrm{H} _{6} \stackrel {\text { fast }} {\rightarrow} \mathrm{B} _{4} \mathrm{H} _{10} + \mathrm{BH} _{3}
$$

设反应 1 为快平衡，平衡常数为 $K_{i}$ ，正逆反应活化能分别为 $E_{a,1}$ 和 $E_{a,-1}$ ；反应 2 为决速步，其速率常数为 k，活化能为 $E_{a,2}$ ；反应 3 为快速步骤，活化能为 $E_{a,3}$ 。回答以下问题：

6-1 写出由 $B_{2}H_{6}$ 生成 $B_{4}H_{10}$ 的总反应方程式。

6-2 推出 $B_{2}H_{6}$ 的消耗速率以 $[B_{2}H_{6}]$ 为自变量的表达式。

6-3 推算反应的表观活化能 $E_{a}$ 与各步反应活化能的关系式。

6-4 研究人员在 $147^{\circ}C$ 下向 $1.00\ dm^{3}$ 的玻璃泡中充入初始分压为 $3.50\ mmHg$ ( $1\ atm = 760\ mmHg$ ) 的 $B_{2}H_{6}$ ，测得反应的表观速率常数 $k_{obs} = 4.55 \times 10^{-4}\ mol^{-\frac{1}{2}} \cdot m^{\frac{3}{2}} \cdot s^{-1}$ 。求出该实验中 $B_{2}H_{6}$ 的半衰期。

## 参考答案

6-1 2 B₂H₆ = B₄H₁₀ + H₂ (1 分)
其他答案不得分。

6-2 对 [B₃H₇] 稳态近似，
    d[B₃H₇] / dt = r₂ - r₃ = 0
于是 r₂ = r₃，进而有
    d[B₄H₁₀] / dt = r₃ = r₂ = k[BH₃][B₂H₆] (1 分)
由平衡态假设，
    Kᵢ = [BH₃]² / [B₂H₆]
    [BH₃] = √Kᵢ[B₂H₆] (1 分)
因此：
    d[B₄H₁₀] / dt = r₃ = r₂ = k√Kᵢ[B₂H₆]³/²
因为 B₄H₁₀ 生成速率与 B₂H₆ 消耗速率之比为 1:2，故：
    d[B₂H₆] / dt = r₃ = r₂ = 2k√Kᵢ[B₂H₆]³/² (1 分)

6-3 根据阿伦尼乌斯公式：
kₒbs = k√Kᵢ
= A₂exp(-Eₐ,₂/RT) [A₁exp(-Eₐ,₁/RT) / A₋₁exp(-Eₐ,-₁/RT)]¹/²
= [A₁¹/²A₂/A₋₁] exp[(-½Eₐ,₁ - Eₐ,₂ + ½Eₐ,-₁)/RT]
= Aexp(-Eₐ/RT) (1 分)
故：
Eₐ = ½Eₐ,₁ + Eₐ,₂ - ½Eₐ,-₁ (1 分)

6-4 乙硼烷初始浓度为:

$$
[ \mathrm{B} _{2} \mathrm{H} _{6} ] _{0} = \frac {p _{0}}{R T} = \frac {3.5 \times 133.3}{8.314 \times 420.15} = 0.134 (\mathrm{mol} \cdot \mathrm{m} ^{- 3}) (1 \text {分})
$$

对于 1.5 级反应，有：

$$
\frac {\mathrm{d} \left[ \mathrm{B} _{2} \mathrm{H} _{6} \right]}{\mathrm{d} t} = - k _{\mathrm{obs}} \left[ \mathrm{B} _{2} \mathrm{H} _{6} \right] ^{\frac {3}{2}}
\frac {1}{\sqrt {[ \mathrm{B} _{2} \mathrm{H} _{6} ] _{\mathrm{t}}}} - \frac {1}{\sqrt {[ \mathrm{B} _{2} \mathrm{H} _{6} ] _{0}}} = \frac {1}{2} k _{\mathrm{obs}} t (1 \text {分})
$$

将 $[\mathrm{B}_2\mathrm{H}_6]_{\mathrm{t}} = \frac{1}{2} [\mathrm{B}_2\mathrm{H}_6]_0$ 带入求得：

$$
t _{\frac {1}{2}} = \frac {2 \sqrt {2} - 2}{k _{\mathrm{obs}} \sqrt {[ \mathrm{B} _{2} \mathrm{H} _{6} ] _{0}}} = 4974 \mathrm{s} ^{- 1} (1 \text {分})
$$

结果在 $4874 \sim 5074 \mathrm{~s}$ 间均可得分。

若认为 B2H6 消耗速率为 $0.5k_{obs}[B_{2}H_{6}]^{\frac{3}{2}}$ 求出响应结果也得分。

6-5 电子总数 $g = 4\times 3 + 10\times 1 = 22 = 4\times 4 + 6$ ，故丁硼烷属于蛛网式硼烷。
