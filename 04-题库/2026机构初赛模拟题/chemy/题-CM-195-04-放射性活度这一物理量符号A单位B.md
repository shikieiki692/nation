# 题-CM-195-04-放射性活度这一物理量符号A单位B

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-4-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（20 分，占 17%）

放射性活度这一物理量(符号：A，单位：Bq)可用于定量描述核素的放射性衰变，其含义是放射性同位素每秒衰变的原子个数。在经历足够长时间后，若某一衰变链中的亲代核素和子代同位素的放射性活度之比不随时间变化，就可以称这些核素达到了放射性平衡，由于各步衰变反应的相对快慢不同放射性平衡可分为长期平衡(secular equilibrium)和暂时平衡(transient equilibrium)。

**4-1** 长期平衡的探究：当亲代放射性核素的半衰期远远大于子代放射性同位素的半衰期时，才可能建立长期平衡存在，<sup>238</sup>U 便是一个典型的亲代放射性核素，而 <sup>234</sup>Th、<sup>234m</sup>Pa、<sup>234</sup>U 等则为对应的子代放射性同位素。

![](images/7d4d31cf4a7d1abb471e527fbee16423ddccd4727872121b06b227e6256bd4eb.jpg)![](images/b5f99ec8faa05f2a347bf72f76a0f67ae9b964cc05994fba9d088a822263960d.jpg)![](images/21315ee3474d6c93b92340f4d3c755acf1df0890d0a415a6a60d26284570fea9.jpg)

**4-1-1** 若仅考虑如下的衰变过程，在达到足够长时间后，求出 A(<sup>234</sup>Th)/A(<sup>238</sup>U)的数值。(注：

<sup>234m</sup>Pa 的质量数为 234，m 表示其中一种处于激发态的核素)

![](images/53bb8e0adfb10b73830047d6cbb5aa558f9bc4b26da6718541c0a0eff5dbd93a.jpg)

**4-1-2** 若考虑整个 <sup>238</sup>U 衰变链，认为样品中的所有放射性同位素均来自于上述衰变链而没有其他来源，且没有其他衰变路径，则在达到长期平衡后，测得样品的总放射性活度为 A<sub>0</sub>，求出此时 <sup>238</sup>U 的物质的量的表达式，其中速率常数用 ki（i = 1, 2, 3, …）表示，给出推导过程。阿伏伽德罗常数的值用 N<sub>A</sub>表示。

**4-2** 暂时平衡的探究：当子代放射性同位素的半衰期与亲代相比不可忽略时，不可能达到长期平衡，但在经历足够长时间后，可以达到暂时平衡。

**4-2-1** <sup>99</sup>Mo 可以通过 β 衰变并进一步发生 γ 衰变生成 <sup>99</sup>Tc，该述路径在足够长时间后能够达到暂时平衡。写出两个衰变的方程式。

![](images/8f7c619e1a1ce9d4a923c78432d57d738cf956fe1b35b6a524f989c6ef40f5a9.jpg)

**4-2-2** 暂时平衡可使用连续反应动力学模型展开讨论。

![](images/a2009288ba26bc2d2a4d90ce7150c2df20c24eb3112cbf11f680631e4f8211f5.jpg)

假设对于上图所示连续反应满足 k<sub>2</sub> > k<sub>1</sub>，A 的初始浓度记为[A]<sub>0</sub>，B、C 的初始浓度均为 0。给出 t 时刻 B 物种的速率方程(生成为正)，其中可包含本题涉及的速率常数及[A]<sub>0</sub>、[B]、t。

**4-2-3** 经过进一步数学计算后可得[B] = k<sub>1</sub>[A]<sub>0</sub>[exp(-k<sub>1</sub>t) – exp(-k<sub>2</sub>t)] / (k<sub>2</sub> – k<sub>1</sub>)，做适当简化，推导经历足够长时间后达到暂时平衡时 B 与 A 的放射性强度之比。

**4-2-4** 在上述体系中，若 A 的量足够多(不会被消耗完)，B 的浓度在何时会达到最大值？推导出该时刻 t<sub>m</sub>的表达式，表达式中仅可出现 k<sub>1</sub>，k<sub>2</sub>。

## 参考答案

**4-1-1** （共 3 分，使用稳态近似分析也得分）在足够长时间后，可以达到长期平衡。此时，<sup>234</sup>Th 的生成速率和衰变速率相等（1 分），因此有[<sup>234</sup>Th] / [<sup>238</sup>U] = k<sub>1</sub> / k<sub>2</sub>（1 分）。

**4-1-2** （共 5 分）在达到长期平衡时，所有子代放射性核素的衰变速率与亲代放射性核素衰变速率相等。即使在衰变链中并不满足 k<sub>i</sub> << k<sub>i+1</sub>（i≥2），第 i 代的衰变速率已经被亲代(第 1 代)核素控制，故所有中间产物均能满足“稳态近似”，即所有中间产物的生成速率均等于衰变速率。考虑过程 a → b → c → d → …d[b] / dt = k<sub>1</sub>[a] – k<sub>2</sub>[b] = 0，d[c] / dt = k<sub>2</sub>[b] – k<sub>3</sub>[c] = 0（2 分）因此类似 4-1-1 可得 A(c) / A(b) = 1，即在达到长期平衡时，亲代放射性核素和子代放射性核素的放射性活度相同。（1 分）故在此情况下，A<sub>0</sub> = 14A<sub>0</sub> = 14k<sub>1</sub>n(<sup>238</sup>U)N<sub>A</sub>（1 分），n(<sup>238</sup>U) = A<sub>0</sub> / 14k<sub>1</sub>N<sub>A</sub>（1 分）。

**4-2-1** 各 1 分，共 2 分。

<sup>99</sup><sub>42</sub>Mo → <sup>99m</sup><sub>43</sub>Tc + <sup>0</sup><sub>-1</sub>e <sup>99m</sup><sub>43</sub>Tc → <sup>99</sup><sub>43</sub>Tc + γ

**4-2-2** 对于 A 而言，-d[A] / dt = k<sub>1</sub>t，积分可得[A] = [A]<sub>0</sub> exp(-k<sub>1</sub>t)，因此 B 的生成速率表达式为：d[B] / dt = k<sub>1</sub>[A]<sub>0</sub> exp(-k<sub>1</sub>t) – k<sub>2</sub>[B]（2 分）

**4-2-3** [B] = k<sub>1</sub>[A]<sub>0</sub>[exp(-k<sub>1</sub>t) – exp(-k<sub>2</sub>t)] / (k<sub>2</sub> – k<sub>1</sub>) = k<sub>1</sub>[A][1 - exp(-k<sub>2</sub>t + k<sub>1</sub>t)] / (k<sub>2</sub> – k<sub>1</sub>)（1 分）因此可得[B] / [A] = k<sub>1</sub>[1 - exp(-k<sub>2</sub>t + k<sub>1</sub>t)] / (k<sub>2</sub> – k<sub>1</sub>)在时间足够长时间后，可以认为(k<sub>1</sub> – k<sub>2</sub>)t << 0，因此 exp(-k<sub>2</sub>t + k<sub>1</sub>t) ≈ 0（1 分），故达到暂时平衡时[B] / [A] = k<sub>1</sub> / (k<sub>2</sub> – k<sub>1</sub>)，放射性强度之比为 k<sub>2</sub> / (k<sub>2</sub> – k<sub>1</sub>)（2 分）。

**4-2-4**（4 分）方法一：直接对[B]关于时间 t 求导，求出[B]的极大值，此情景下，极大值就是最大值。d[B] / dt = k<sub>1</sub>[A]<sub>0</sub> exp(-k<sub>1</sub>t)[–k<sub>1</sub> + k<sub>2</sub> exp(k<sub>1</sub>t - k<sub>2</sub>t)]（2 分）此时 k<sub>2</sub> – k<sub>1</sub> > 0，故极大值点对应–k<sub>1</sub> + k<sub>2</sub> exp(k<sub>1</sub>t - k<sub>2</sub>t) = 0，即 t = (lnk<sub>1</sub> – lnk<sub>2</sub>) / (k<sub>1</sub> – k<sub>2</sub>)（2 分）方法二：简单分析知道，生成 B 的速率随着时间的增加逐渐减小。而消耗 B 的速率随着 B浓度的增加而增大。所以，当生成 B 的速率等于消耗 B 的速率时达到一个临界条件 k<sub>1</sub>[A] = k<sub>2</sub>[B]（2 分），此时的 t 即为 t<sub>m</sub>，代入可得相同结果（2 分）。
