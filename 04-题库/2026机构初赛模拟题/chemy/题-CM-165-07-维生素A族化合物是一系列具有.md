# 题-CM-165-07-维生素A族化合物是一系列具有

## 题目

### 第 7 题

第 7 题（16 分， 占比 $10 \%$ ）维生素A 的故事

维生素A 族化合物是一系列具有相同骨架结构的化合物，包括视黄醇、视黄醛、视黄酸等，在生命活动中发挥着至关重要的作用。早在 1000 多年前，中国唐代医学家孙思邈在《千金方》中就记载了使用动物肝脏治疗夜盲症。1912 年，科学家在鳕鱼肝脏中首次提取了维生素A 族化合物， 而关于它们的结构与功能的研究至今仍被人们所重视。

7-1 视黄醇和视黄醛是形成视觉的两个关键化合物，而视黄醛和 11-cis-视黄醛的相互转化则是将外界光信号转化为生物信号的重要一步。下图给出了视黄醛与 11-cis-视黄醛的结构。

![](images/a40ee2dde93904edb892c6017aba46ec7d482eb138499c64920072402fd595a5.jpg)

在生物体中，X(上述两种化合物中的一种)可以与视蛋白上的氨基残基缩合形成 A(蛋白部分可以用 R 替代)，A 可以吸收光发生顺反异构化得到 B，而此时由于结合口袋中的分子发生了结构的改变，导致视蛋白的构象发生了改变，从而产生了视觉神经冲动，并水解 B 释放了Y(上述两种化合物中的另一种)。 $\pmb { \ Y }$ 首先被还原为C，此后C 在酶的催化下消耗 ATP 经过两步反应得到 D，此后 D 被氧化再生得到 $\pmb { x }$ 。给出 $\blacktriangle \sim \pmb { \mathsf { D } }$ 的结构。提示： ATP 可以作为生命活动中吸能反应的能量来源。

7-2 人类需要补充维生素 A 还可以摄入 $\beta \mathrm { . }$ -胡萝 $\boldsymbol { \mathsf { h } }$ 素， 而 $\beta$ -胡萝卜素可以在小肠粘膜上被氧化产生两分子的维生素A。

7-2-1 请判断 $\beta \mathrm { . }$ -胡萝卜素是否属于萜类化合物。 若属于，写出其含有的异戊二烯单元数量。
7-2-2 已知 $\beta \mathrm { . }$ -胡萝 卜素只含 C，H 元素， 尝试给出其可能的结构。

7-3 由于维生素 A 缺乏会导致视觉以及上皮功能异常等一系列问题，不少人需要通过服用维生素 A 片剂补充维生素 A。工业上的维生素 A 一般是由化学合成得到的。下面展示了一条合成维生素A 醋酸酯的路线，请给出E \~ I 的结构。并给出E 生成 F 经历的关键中间体。

![](images/1b19524e2ef7175d4f10f61f2b022d5c39938e1f5e54daa8d16567a50faedfd4.jpg)

7-4 异维 A 酸是视黄酸的13-(Z)异构体，具有缩小皮脂腺组织、抑制皮脂腺活性的功能，常用于治疗痤疮。此外，异维 A 酸有时还被用于癌症治疗中。工业上合成异维 A 酸的路线与维生素 A 醋酸酯的路线高度重合，只需将上述路线中的 I 更换为 J。据此， 请给出 J 的结构。
