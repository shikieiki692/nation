# 题-CM-70-08-在有机化学中对底物的结构或者

## 题目

### 第 8 题（13 分）

在有机化学中，对底物的结构或者反应的条件进行一定的改动，会得到让人意想不到的结果。

以下是有关异腈的多组分反应， 当 R 基为 Bn 和 H 时， 会得到结构不同的产物。

![](images/5c051bd71fcbd60dcbb9f14d8507398ed2fecb5bbad83b359bbfd4e89c35e264.jpg)

异腈A、累积二烯衍生物B、吲哚酮C 在甲苯回流的条件下进行三组分反应生成了产物D(R$\mathbf { \Sigma } = \mathbf { \Sigma }$ Bn 时)和 E( $\mathrm { R } = \mathrm { H }$ 时)。

具体反应历程如上图所示：A 和 B 反应生成中间体 D， $D$ 和 C 反应生成了中间体 G 和 H，$\pmb { 6 }$ 和 H 进一步反应分别得到了含有六个环的产物 D 和含有五个环的产物 E，已知反应并未生成其他小分子。

8-1 画出中间体F 的结构式， 并写出其中存在的大 $\pi$ 键的种类。

8-2 画出中间体G 和H 的结构式， 并解释为何当R 基发生变化时， 反应历程会有所改变。

8-3 画出产物D 和E 的结构简式。
