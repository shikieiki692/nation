# 题-CM-58-07-MAPO-20是一种立方晶系

## 题目

### 第 7 题（6 分）

MAPO-20 是一种立方晶系的沸石, 其与天然矿物 sodalite 具有相同的骨架结构, 如右图所示。该结构由 $\beta$ 笼共面连接组成, 图中每一个顶点均代表一个 T 原子(X 为 Mg、Al 或 P), 其中 Mg、Al 符合统计分布; 而每一条边均代表一个氧原子; NMe $_{4}^{+}$ 占据所有的 $\beta$ 笼中心。

7-1 分别指出 T 和 O 的配位数。

![](images/12e3c27c6912de6f48ca27433914079ef0252b0db4bc11beafcb4e6d7239e932.jpg)

7-2 根据描述写出 MAPO-20 的化学式。

7-3 该晶体的最小重复单位是什么？

## 参考答案

第 7 题（6 分）

![](images/a54a57470b0bbcf6c72a789dbf85bff381f86052cc7fd87887ac0b907fc197a0.jpg)

7-1 4 和 2。（各 1 分）

7-2 (NMe4)MgAl2P3O12 （2 分）写成 $\_$ ， 得1 分。

7-3 $\mathrm { ( NMe _{ 4 } ) _{ 2 } Mg _{ 2 } Al _{ 4 } P _{ 6 } O _{ 24 } }$ （2 分）
