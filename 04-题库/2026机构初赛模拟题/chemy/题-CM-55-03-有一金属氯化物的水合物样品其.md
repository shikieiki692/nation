# 题-CM-55-03-有一金属氯化物的水合物样品其

## 题目

### 第 3 题（9 分）

有一金属氯化物的水合物样品，其化学式为 $MCl_{x}\cdot nH_{2}O$ ，通过以下方法分析其组成：取少量该样品溶于水，使用 I=1.86 A 的电流进行电解，电解时间 1572 s，析出金属单质 0.525 g；另取 3.000 g 该样品溶于水，稀释至 250 mL；移取 25.00 mL 该溶液于锥形瓶中，滴入几滴 $Na_{2}CrO_{4}$ 溶液，立即用 0.1000 mol/L $AgNO_{3}$ 溶液滴定到终点，消耗 11.24 mL；另取 3.245 g 该样品，在氮气气氛下小心加热到 600℃，剩余固体残渣的质量为 1.929 g。请通过计算确定金属 M 的元素符号以及能反应该样品实际组成的化学式。

## 参考答案

第 3 题（9 分）

电解转移电子的物质的量为： $n(\mathrm{e}) = 1.86 \ \mathrm { A } \times 1572 \ \mathrm { s } / 96485 \ \mathrm { C \ mol } ^ { - 1 } = 0.03030 \ \mathrm { mol }$ （1 分）金属的摩尔质量为： $M = m x / n(\mathrm{e}) = 17.32 x \ \mathrm { g/mol }$ （1 分）依次将 $x = 1$ ，2，3， 4……代入知， 当 $x = 3$ 时 （1 分）， $M = 51.97 \mathrm { g / mol }$ ， 为 Cr（1 分）

由： $(52.00 + 35.45 \times 3 + 18.02 \times n) / (52.00 + 35.45 \times 3) = 3.245 / 1.929$ （1 分）
解得 $n = 5.99 \approx 6$ （1 分）
3.000 g 该样品的摩尔数为：
$n _{ 0 } = [ 3.000 / ( 52.00 + 35.45 \times 3 + 18.02 \times 6 ) ]$ mol= 0.01125 mol （1 分）
配合物外界Cl-的摩尔数为： $n _{ \mathrm { Cl } } = 0.1000 \ \mathrm { mol } \ \mathrm { L } ^{ - 1 } \times 11.24 \ \mathrm { mL } = 0.01124 \ \mathrm { mol }$ （1 分）
$n _{ 0 } / n _{ \mathrm { Cl } } \approx 1$ ，即3 个氯中有1 个处于外界， 2 个处于内界
因此该化合物的化学式为 $[ \mathrm { CrCl } _{ 2 } ( \mathrm { H } _{ 2 } \mathrm { O } ) _{ 4 } ] \mathrm { Cl } \cdot 2 \mathrm { H } _{ 2 } \mathrm { O }$ （1 分）
