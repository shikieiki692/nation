# 题-CM-110-03-在传统认知中元素X的化学性质

## 题目

### 第 3 题（6 分）

在传统认知中，元素 X 的化学性质非常不活泼，实际上，有许多含 X 的化合物被合成、分离、表征。1975 年，英国化学家 J. Turner 在 4K 的固态基质中光解 Cr(CO) $_{6}$ ，在光谱中发现了配合物 A 的吸收，A 含有四种元素，Cr 的理论质量分数为 24.50%。在 X 的单质中对 N $_{2}$ 加超高压，得到了二元固体化合物 B。经测定 B 为六方晶系，晶胞参数为 a = 7.936 Å, c = 9.360 Å，密度 $\rho = 2.136 \, g \cdot cm^{-3}$ ，晶体结构如右所示。

![](images/85bbf907d42609e371ddc4d15ae38b7c986ec927c56fd2474bdcd079aaf5e655.jpg)

2020 年，德国化学家 J. Warneke 制备出了含 X 阴离子 C-。C-包含 B $_{12}$ 单元，仅含 B、C、N、X 四种元素，且碳质量分数为 30.3%，氮质量分数为 35.3%。请写出 A-C-的化学式。

提示：图中晶胞顶点和(0,0,1/2)基团是三种不同取向的叠加，如下图所示，实际上可以看作仅有两个球。且这些小球与图中最大的球是同一种元素。
