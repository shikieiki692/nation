# 题-CM-57-03-环氧值是指100g环氧树脂中

## 题目

### 第 3 题（7 分）

环氧值是指 100 g 环氧树脂中所含环氧基团的摩尔数。精确称取 1.1382 g 环氧树脂试样，装入 250 mL 密闭烧瓶中，用吸量管加 $0.2 \, mol \cdot L^{-1}$ 的盐酸-丙酮溶液 25 mL，充分摇匀，使试样完全溶解，在室温下放置 15 min 后，加人中性乙醇 25 mL，然后以甲酚红指示剂，用 0.1018 $mol \cdot L^{-1}$ 氢氧化钠标准溶液滴定至终点，消耗 17.17 mL。同时做空白试验，消耗 46.85 mL。

3-1 环氧氯丙烷是合成某些环氧树脂的重要原料之一，写出环氧氯丙烷溶于 $0.2 \, mol \cdot L^{-1}$ 盐酸-丙酮溶液的反应方程式。

3-2 计算此环氧树脂试样的环氧值。

## 参考答案

第 3 题（7 分）

3-1

![](images/f98dd34bbb67f60f80898e1e2dea96a7fc0e63ca11490becc5526539b6cf04f5.jpg)

3-2 环氧基团的摩尔数为：
$n = 0.1018 ~ \mathrm { mol / L } \times ( 46.85 - 17.17 ) ~ \mathrm { mL } = 3.021 \times 10^{ - 3 } ~ \mathrm { mol }$ （2 分）
环氧值为：
$N = 3.021 \times 10^{ - 3 } \mathrm { mol } \times 100 \mathrm { g } / 1.1382 \mathrm { g } = 0.2655 \mathrm { mol }$ （3 分）（或答成 $0.2655 \mathrm { mol / 100 g }$ 也可得分）
