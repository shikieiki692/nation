# 题-CM-293-02-长余辉发光材料是一类可吸收能量并

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-23-2`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（5 分）

长余辉发光材料是一类可吸收能量并在激发停止后仍可继续发出光的物质，其以稀土离子为激活剂，以复合氧化物为基质。一种基质的快速合成方法是用硝酸锶-硝酸铝-尿素混合料通过燃烧法(Combustion Synthesis, CS)合成；反应在马弗炉中进行，引发温度为 600℃，充分反应后，凝聚态产物仅有制备所得的基质。该基质由三种元素组成，含氧量为 31.13%。

**2-1** 通过计算，推出该基质的化学组成(要求组成的系数比为最简整数比)。

**2-2** 氮元素在反应后的产物中仅以唯一的形式存在，写出制备基质的反应方程式(要求系数比为最简整数比)。

## 参考答案

**2-1** 由题意，设基质为 aSrO·bAl<sub>2</sub>O<sub>3</sub>，故有:

![](images/dbd4252e78c206ca5375cb66fb51cb41db0e43c1042188eea586ae30a2d9daf3.jpg)

ω(O) = 31.13%；M(O) = 16g·mol<sup>-1</sup>；M(SrO) = 103.62g·mol<sup>-1</sup>；M(Al<sub>2</sub>O<sub>3</sub>) = 101.96g·mol<sup>-1</sup>

![](images/9da44fcf11b852f296ecb48e2bf283437b6646e05a227c7fa162bfa51e72119e.jpg)

令 a = b = 1，则基质为 SrO·Al<sub>2</sub>O<sub>3</sub>，或写作 SrAl<sub>2</sub>O<sub>4</sub>。（3 分）

**2-2** 6Al(NO<sub>3</sub>)<sub>3</sub> + 3Sr(NO<sub>3</sub>)<sub>2</sub> + 20CO(NH<sub>2</sub>)<sub>2</sub> == 3SrAl<sub>2</sub>O<sub>4</sub> + 40H<sub>2</sub>O + 32N<sub>2</sub> + 20CO<sub>2</sub> （2 分）
