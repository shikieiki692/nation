# 题-CM-73-14-P4的一些转化由于P4的

## 题目

### 第 14 题 $\mathbf { \dot { P } } _{ 4 }$ 的一些转化

P4 的一些转化）由于P4 的

由于 ${ \bf P } _{ 4 }$ 的特殊分子结构， 导致其化学性质十分活泼。 在光照下， ${ \bf P } _{ 4 }$ 会解离成能量较高的 ${ \bf P } _{ 2 }$ 分子； 已知 ${ \bf P } _{ 4 }$ 发生水解反应的中间体为 $\mathrm { P } _{ 3 } ( \mathrm { OH } ) _{ 3 }$ 。

14-1 ${ \bf P } _{ 4 }$ 和 2,3-二甲基-1,3-丁二烯在光照下于正己烷中反应， 生成了化合物 A。将 2,3-二甲基-1,3-丁二烯换成蒽，相同条件下生成了结构类似的化合物B。将B 和 $\pmb { MN } _{ 3 } ( \pmb { M }$ 为大的抗衡一价阳离子)置于 THF 溶剂中加热反应，生成了一种具有芳香性的阴离子 C(副产物为蒽)。画出 $\pmb { \mathsf { A } }$ 和C 的结构，并判断C 的点群(或者写出其中含有的所有对称元素)。

14-2 ${ \bf P } _{ 4 }$ 和三当量的 MesLi(Mes 为 2,4,6-三甲基苯基)在室温下于甲苯中按摩尔比 1:3 反应，唯一产物为化合物D。 已知 $D$ 中有根 $C _{ 3 }$ 轴， 画出化合物D 的结构。

14-3 将 ${ \bf P } _{ 4 }$ 和双锂试剂 1,4-(双三甲基硅基)-2,3-二甲基-1,4 二锂丁二烯置于 THF 溶剂中，室温下反应，得到化合物E，其中P 的质量分数为 $7.617 \%$ ， $\mathrm { ~ C ~ }$ 的质量分数为 $53.17 \%$ 。E 中有三个五元环， 画出化合物E 的结构。

14-4 已知G 中有两个三元环和 个四元环，H 中有两个五元环，画出化合物 $\boldsymbol { \mathsf { F } } \sim \boldsymbol { \mathsf { H } }$ 的结构。
