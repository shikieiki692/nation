# 题-CM-88-03-已知部分物种热力学数据如下设

## 题目

### 第 3 题（12 分）

已知部分物种热力学数据如下(设其不随温度变化而变化)，不考虑未提到的其他物种存在。

<table><tr><td>物种</td><td> $\Delta_{\text{f}}H_{\text{m}}^{\ominus}/\text{kJ}\cdot\text{mol}^{-1}$ </td><td> $S_{\text{m}}^{\ominus}/\text{J}\cdot\text{K}^{-1}\cdot\text{mol}^{-1}$ </td></tr><tr><td> $\text{MgCl}_2\cdot6\text{H}_2\text{O(s)}$ </td><td>-2499.0</td><td>315.1</td></tr><tr><td> $\text{MgCl}_2(\text{s})$ </td><td>-641.3</td><td>89.6</td></tr><tr><td> $\text{MgO(s)}$ </td><td>-601.6</td><td>27.0</td></tr><tr><td> $\text{NH}_4\text{Cl(s)}$ </td><td>-314.5</td><td>94.6</td></tr><tr><td> $\text{HCl(g)}$ </td><td>-92.3</td><td>186.9</td></tr><tr><td> $\text{NH}_3(\text{g})$ </td><td>-45.9</td><td>192.8</td></tr><tr><td> $\text{H}_2\text{O(g)}$ </td><td>-241.8</td><td>188.8</td></tr></table>

3-1 结合相律回答：500.0 K 下，将一定量 $MgCl_{2}\cdot6H_{2}O(s)$ 、 $MgCl_{2}(s)$ 、 $MgO(s)$ 投入预先抽真空的恒容容器中，它们能否共存？简述判断理由。若能，计算与混合物达到平衡后气相各组分分压；若不能，计算它们可以共存的温度。

3-2 在上问的三种固体共存平衡后，向体系内投入足量 $NH_{4}Cl(s)$ ，指出再次平衡时的固相成分与气相各组分分压。

3-3 若 $MgCl_{2}\cdot6H_{2}O(s)$ 和 $NH_{4}Cl(s)$ 相对另两种固体大过量，如下哪（几）种操作可能可以仅使体系中 $MgO(s)$ 相消失？

$$
\mathrm{a)} \text {   增大容器体积   } \quad \mathrm{b)} \text {   减小容器体积   }
$$

c) 投入 $\mathrm{MgCl}_2$ d) 恒容抽出 $\mathrm{NH}_3$ e) 恒容抽出 $\mathrm{H}_2\mathrm{O}$

## 参考答案

## 第3题（12分）

3-1 可以共存。（1分，理由错误，即使判断正确，也不得分。）
$\mathrm{MgCl_2\cdot 6H_2O(s)}$、$\mathrm{MgCl_2(s)}$、$\mathrm{MgO(s)}$、$\mathrm{HCl(g)}$、$\mathrm{H_2O(g)}$共存时
根据相律 $s + 2 = \Phi + f$，可求得独立组分数 $s = 3$，相数 $\Phi = 1 + 3 = 4$，自由度 $f = s + 2 - \Phi = 1$，即温度和总压二者可以改变其一而推知另一者。（1分，写 $f^* = 0$ 也可得分）
$\mathrm{MgCl_2\cdot 6H_2O(s)} = \mathrm{MgCl_2(s)} + 6\mathrm{H_2O(g)}$ $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 406.9 \mathrm{~kJ}\cdot \mathrm{mol}^{-1}$（0.5分）
$\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 907.3 \mathrm{~J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$（0.5分）
$K_{1}^{\ominus} = \exp[-(\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} - T\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus}) / RT) = 7.66\times 10^{4}$ $p(\mathrm{H_2O}) = p^{\ominus}(K_{1}^{\ominus})^{1/6} = 6.62 \mathrm{bar}$（1分）
$\mathrm{MgCl_2(s)} + \mathrm{H_2O(g)} = \mathrm{MgO(s)} + 2\mathrm{HCl(g)}$ $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 96.9 \mathrm{~kJ}\cdot \mathrm{mol}^{-1}$（0.5分）
$\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 122.4 \mathrm{~J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$（0.5分）
$K_{2}^{\ominus} = \exp[-(\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} - T\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus}) / RT) = 1.86\times 10^{-4}$ $p(\mathrm{HCl}) = [K_2^{\ominus}\cdot p(\mathrm{H_2O})\cdot p^{\ominus}]^{1/2} = 0.0351 \mathrm{bar}$（1分）

$$
\mathrm{NH} _{4} \mathrm{Cl} (\mathrm{s})
$$

3-2 固相：$\mathrm{MgCl_2\cdot 6H_2O(s)}$、$\mathrm{MgCl_2(s)}$、$\mathrm{MgO(s)}$、$\mathrm{NH_4Cl(s)}$均存在（1分）
气相：$\mathrm{NH_4Cl(s)} = \mathrm{HCl(g)} + \mathrm{NH_3(g)}$ $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 176.3 \mathrm{~kJ} \cdot \mathrm{mol}^{-1}$（0.5分）
$\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus} = \Sigma v_{i}\Delta_{\mathrm{f}}H_{\mathrm{m}}{}_{i}^{\ominus} = 285.1 \mathrm{~J} \cdot \mathrm{K}^{-1} \cdot \mathrm{mol}^{-1}$（0.5分）
$K_{3}^{\ominus} = \exp[-(\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} - T\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus}) / RT) = 2.98 \times 10^{-4}$ $p(\mathrm{NH}_{3}) = (p^{\ominus})^{2} \cdot K_{3}^{\ominus} / p(\mathrm{HCl}) = 8.49 \times 10^{-3} \mathrm{bar}$（1分）
其余气体分压与上问所得相同。（1分）

3-3 b) d)（2分；多选/少选每个选项扣1分，扣完为止）
b) 气体分压一定，减小体积等价于使部分气体进入固相。
气相分压  $H_{2}O \gg HCl &gt; NH_{3}$ ，压缩时发生反应  $HCl + NH_{3} = NH_{4}Cl$ 、
 $12HCl + 6MgO = 5MgCl_{2} + MgCl_{2} \cdot 6H_{2}O$ 、 $6H_{2}O + MgCl_{2} = MgCl_{2} \cdot 6H_{2}O$
必定可以减少 MgO 量。
d) 同理，此时发生反应  $12NH_{4}Cl + 6MgO = 5MgCl_{2} + MgCl_{2} \cdot 6H_{2}O + 12NH_{3}$ 。
e) 此时只可减少  $MgCl_{2}$  量，MgO 不受影响。
