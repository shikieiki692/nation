# 题-CM-291-02-21在185C和低于133Pa的

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-21-2`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（10 分）

**2-1** 在 185<sup> </sup>°C 和低于 133 Pa 的压力下，将 BF<sub>3</sub>蒸气通过晶体硼，制得一种硼的氟化物气体；其分子中含有 2 根 B-B 单键，无多中心键和氟桥键。

**2-2** 在 pH = 5.0 时，用高铁酸钾溶液处理含有甲醇的废液，可将甲醇彻底氧化。

**2-3** 向含 Co<sup>2+</sup>的溶液中加入碳酸氢钠溶液和 30%过氧化氢溶液，析出苹果绿色固体，该固体为三钠盐沉淀，带 3 个结晶水。

**2-4** 将砒霜、萤石和浓硫酸混合加热，可蒸馏出无色气体。

**2-5** 在氢氧化钠溶液中，AgO 与碘酸钠反应，生成 Na<sub>7</sub>[Ag(IO<sub>6</sub>)<sub>2</sub>]和棕黑色固体。

## 参考答案

**2-1** 5BF<sub>3</sub> + 4B = 3B<sub>3</sub>F<sub>5</sub>（2 分）

**2-2** 2FeO<sub>4</sub><sup>2-</sup> + CH<sub>3</sub>OH + 4H<sup>+</sup> = 2Fe(OH)<sub>3</sub> + CO<sub>2</sub> + H<sub>2</sub>O（2 分）Fe(OH)<sub>3</sub>写成 Fe<sub>2</sub>O<sub>3</sub>·xH<sub>2</sub>O，配平，也可得分。

**2-3** 2Co<sup>2+</sup> + 10HCO<sub>3</sub><sup>-</sup> + H<sub>2</sub>O<sub>2</sub> + 6Na<sup>+</sup><sub> </sub>= 2Na<sub>3</sub>[Co(CO<sub>3</sub>)<sub>3</sub>]·3H<sub>2</sub>O + 4CO<sub>2</sub>（2 分）

**2-4** As<sub>2</sub>O<sub>3</sub> + 3CaF<sub>2</sub> + 3H<sub>2</sub>SO<sub>4</sub> = 2AsF<sub>3</sub> + 3CaSO<sub>4</sub> + 3H<sub>2</sub>O（2 分）产物写成硫酸氢钙，不扣分。

**2-5** 4IO<sub>3</sub><sup>-</sup> + 12AgO + 10OH<sup>-</sup> → 2[Ag(IO<sub>6</sub>)<sub>2</sub>]<sup>7-</sup> + 5Ag<sub>2</sub>O + 5H<sub>2</sub>O（2 分）
