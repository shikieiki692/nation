# 题-CM-258-03-将三氯化钌的稀盐酸溶液与L结构见

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy35-16-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（12 分）

将三氯化钌的稀盐酸溶液与 L(结构见下)的乙醇溶液混合，在 75 °C 下温和加热 3 h，析出砖红色粉末；该粉末经丙酮-水混合溶剂重结晶，析出橙红色晶体 A。对 A 有如下表征结果：

(1)<sup> </sup>磁矩测定实验表明，A 在 20°C 下的磁矩为 μ = 1.9 μ<sub>B</sub>。

(2)<sup> </sup>元素分析表明，A 中各元素的含量(质量分数)为：C, 29.52%; H, 3.86%; N, 24.58%。

(3)<sup> </sup>X-射线衍射表明，A 的晶体中存在两种分子：一种是钌的单核八面体配合物分子，分子中存在 4 根氢键，L 用标*的氮原子配位；另一种是溶剂分子。

(4) A 的丙酮溶液的核磁共振氢谱表明，配体 L 仅有一种化学环境。

![](images/dfdeca2ce076ac9e0d13777e6ed774feb4606a92c2a3237cd9113b5da12cf9d8.jpg)

**3-1** 写出 A 中 Ru 的自旋态(高或低)以及 Ru 在八面体场中的价电子排布。

**3-2** 通过计算和推理，写出 A 的化学式，注意体现配合物的内界和外界。

**3-3** 画出 A 晶体中单核八面体配合物分子的结构，示出其中的氢键。

## 参考答案

**3-1** 低自旋（1 分）；价电子排布为 t<sub>2g</sub><sup>5</sup>e<sub>g</sub><sup>0</sup>（1 分）

**3-2** A 中 C、H、N 数目比为：(29.52 / 12.01) : (3.86 / 1.008) : (24.58 / 14.01) ≈ 7 : 11 : 5（1 分）L 中的 C : N = 7 : 5，乙醇和丙酮中含碳而不含氮，因此 A 中无丙酮或乙醇（1 分），溶剂分子应为水；因此 A 中含有 Ru、L、H<sub>2</sub>O，可能含有 Cl 和 OH 配体；设 A 的化学式中有 n 个配体 L，则 A 的摩尔质量为：M(A) = 12.01 g·mol<sup>-1</sup> × 7n / 29.52% = 284.8n g·mol<sup>-1</sup>（1 分）当 n = 1 时，1 个配体 L 和 1 个 Ru 的摩尔质量就已达到 264.3 g·mol<sup>-1</sup>，不合理；（1 分）当 n = 2 时，摩尔质量 M = 569.6 g·mol<sup>-1</sup>；由于 Ru 为+3 氧化态，因此 OH 配体和 Cl 配体共有 3 个；又因为 Ru 为 6 配位，L 为单齿配体，因此配合物内界应有 1 个水分子，故 A 的化学式可写为：RuL<sub>2</sub>Cl<sub>3-x</sub>(OH)<sub>x</sub>(H<sub>2</sub>O)<sub>n</sub> L 中的 C : H = 7 : 11，得 x + 2n = 4；依次将 x = 2，n = 1 和 x = 0，n = 2 代入化学式中，计算摩尔质量得：x = 0，n = 2（1 分）时摩尔质量为 569.8 g·mol<sup>-1</sup>，符合题意，即 A 为 RuL<sub>2</sub>Cl<sub>3</sub>(H<sub>2</sub>O)<sub>2</sub>；实际结构应为[RuL<sub>2</sub>Cl<sub>3</sub>(H<sub>2</sub>O)]·H<sub>2</sub>O（1 分）用其他方法推出合理结果的，也可得满分。

**3-3**
