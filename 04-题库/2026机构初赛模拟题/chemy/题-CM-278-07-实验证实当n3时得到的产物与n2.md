实验证实，当 n = 3 时得到的产物与 n = 2,4,5 时得到的产物均不含溴，但其结构有明显的差异。分别画出 n = 3 和 n = 4 时得到产物的结构简式，解释产生这种差异的原因。

烯醇负离子碳端亲核性强于氧端（1 分），因此正常情况下得到碳端两次进攻的产物；但

六元环比四元环更易形成（1 分），因此 n = 3 时不利于碳端第二次进攻，而是得到氧进攻

的六元环产物。
