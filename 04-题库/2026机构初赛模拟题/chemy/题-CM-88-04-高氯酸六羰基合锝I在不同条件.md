# 题-CM-88-04-高氯酸六羰基合锝I在不同条件

## 题目

### 第 4 题（10 分）

高氯酸六羰基合锝(I)在不同条件下水解可得到不同的产物: 在己烷相存在下, 向高氯酸六羰基合锝(I)的水溶液中滴入过量氢氧化钠溶液, 搅拌反应 $40 \mathrm{~min}$ , 产物为配合物 A, 生成于己烷相; 若无己烷相存在, 向高氯酸六羰基合锝(I)的水溶液中滴入氢氧化钠溶液至 $\mathrm{pH} = 12$ , 剧烈搅拌下反应, 析出黄色沉淀 B。

通过红外光谱与 X-射线衍射确定了配合物 A 和 B 的结构。实验表明，A 为单核八面体配合物，配体仅为羰基和氢；B 为三核配合物，化学式为 $\mathrm{Tc}_{3}\mathrm{H}(\mathrm{CO})_{14}$ ，其中羰基均为端基配体，氢为桥连配体，每分子 $\mathrm{Tc}_{3}\mathrm{H}(\mathrm{CO})_{14}$ 含 1 根 Tc-Tc 键。

4-1 写出高氯酸六羰基合锝(I)中锝在八面体场中的电子组态，指出高氯酸六羰基合锝(I)的磁属性(顺磁性/抗磁性)。

4-2 分别写出生成配合物 A 和 B 的化学反应方程式。

4-3 画出配合物 B 的结构。

4-4 B 在 $100^{\circ}$ C 以上分解，得到 $[TcH(CO)_{4}]_{3}$ 和一种双核配合物 C。

4-4-1 写出化学反应方程式。

4-4-2 在 $\left[\mathrm{TcH}(\mathrm{CO})_{4}\right]_{3}$ 中，羰基仍均为端基配体，氢仍均为桥连配体。画出 $\left[\mathrm{TcH}(\mathrm{CO})_{4}\right]_{3}$ 的结构。

4-4-3 指出双核配合物 C 分子中存在的最高次对称轴的种类及位置。

## 参考答案

第4题（10分）

4-1  $t_{2g}^{6}e_{g}^{0}$  (0.5分)；抗磁性（0.5分）

4-2  $[Tc(CO)_{6}]ClO_{4} + 3NaOH = TcH(CO)_{5} + NaClO_{4} + Na_{2}CO_{3} + H_{2}O$  (1.5分)

3  $[Tc(CO)_{6}]ClO_{4} + 7NaOH = Tc_{3}H(CO)_{14} + 3NaClO_{4} + 2CO + 2Na_{2}CO_{3} + H_{2}O$  (1.5分)

(2分，不要求画出立体结构)

4-4-1  $3Tc_{3}H(CO)_{14} = [TcH(CO)_{4}]_{3} + 3Tc_{2}(CO)_{10}$  (1分)
