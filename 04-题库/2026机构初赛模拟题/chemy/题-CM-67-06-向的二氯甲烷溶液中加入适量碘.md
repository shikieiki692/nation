# 题-CM-67-06-向的二氯甲烷溶液中加入适量碘

## 题目

### 第 6 题（10 分）

向 $c i s { \mathrm { - Ru ( Et _{ 2 } Ndtc ) _{ 2 } ( DMSO ) _{ 2 } } }$ 的二氯甲烷溶液中加入适量碘单质， 室温搅拌过夜， 蒸发结晶， 析出一种暗红色晶体。X-射线衍射实验表明，该晶体的化学式为$\mathrm{[Ru_{3}(Et_{2}Ndtc)_{6}(DMSO)_{2}](I_{3})_{2}}$ ，其阳离子中三个钌原子在同一直线上，其核间距 $d ( \mathrm { Ru } _{ a } \mathrm { - Ru } _{ b } ) =$ $330 \mathrm { pm }$ ， $d ( \mathrm { Ru } _{ b } \mathbf { - } \mathbf { R } \mathbf { u } _{ c } ) = 283 ~ \mathrm { pm }$ ； 每个钌原子均与六个硫原子形成八面体配位； DMSO 为端基配体， 仅用硫原子进行配位。 配体 $\mathrm { Et } _{ 2 } \mathrm { Ndtc }$ 和 DMSO 的结构如下所示：

N S H3C OS CH3 Et2Ndtc DMSO

6-1 化合物 cis- $\mathbf { \bar { \tau } } _{ \mathrm { Ru ( Et _{ 2 } Ndtc ) _{ 2 } ( DMSO ) _{ 2 } } }$ 显抗磁性， 指出钌的价电子在八面体场中的排布。

6-2 写出生成该化合物的化学反应方程式(配体可用简写代替)。

6-3 画出该三核阳离子的结构示意图， 并标出其中每个钌原子的氧化态。

6-4 磁性测试结果表明， 该晶体呈现抗磁性， 请解释原因。

6-5 若将底物换成 $c i s – \mathbf { Ru ( Et _{ 2 } Ndtc ) _{ 2 } ( CO ) _{ 2 } }$ ， 在相同条件下反应， 并未得到类似的三核配合物， 而只得到了 cis- $\mathrm { \cdot Ru ( Et _{ 2 } Ndtc ) _{ 2 } ( CO ) _{ 2 } { \cdot } 0.5 I _{ 2 } }$ 。 请解释二者反应产物不同的原因。

**6-4** 形成了 Ru-Ru 单键使单电子成对(1 分)

**6-5** 若将底物换成  $cis-Ru(Et_2Ndtc)_2(CO)_2$ ,在相同条件下反应,并未得到类似的三核配合物,而只得到了  $cis-Ru(Et_2Ndtc)_2(CO)_2 \cdot 0.5I_2$ 。请解释二者反应产物不同的原因。

**6-5** CO 是比 DMSO 更强的强场配体,能使晶体场分裂能更大,使得  $t_{2g}$  轨道的电子能量更低,更不易失去,因此未被碘氧化。(2 分)
