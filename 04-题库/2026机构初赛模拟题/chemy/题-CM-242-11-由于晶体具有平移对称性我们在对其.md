# 题-CM-242-11-由于晶体具有平移对称性我们在对其

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-6-11`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 11 题（14 分）

由于晶体具有平移对称性，我们在对其进行研究时可以使用一些手段简化研究，而其中最常用的手段就是选取一个晶胞。

**11-1** 由于人们希望在一个晶胞中尽可能地体现出晶体的对称性，因而我们通常选取的都是正当晶胞。但实际上我们也可以在部分晶体中选取出包含点阵点数目更少的素晶胞。

**11-1-1** 在 R 心六方点阵中，我们通常选取何种晶胞作为素晶胞？写出其名称，并描述其轴a, b, c 和夹角 α, β, γ 之间的关系。

**11-1-2** 在下图中涂黑其素晶胞所在的顶点，框出其素晶胞，并计算其晶胞轴之间的夹角。

![](images/f3ea8479849f7ada634f503061f97401b7c8916c7550092811ba7f75e18119cd.jpg)

**11-2** 上述思想其实在另一种晶体的物理模型——Wigner–Seitz 原胞（下称 W-S 原胞）中同样有所体现。但不同的是，W-S 原胞的定义为取两个点阵点连线的中点，并过该点作垂直于该线的平面，用这样的平面围成的一个图形即为一个 W-S 原胞。例如：简单六方点阵的 W- S 原胞即为一个六棱柱。

**11-2-1** 请问一个W-S 原胞中含几个点阵点？为什么一般来说 W-S 原胞不可以作为一个晶胞（即为何大部分的 W-S 原胞不符合晶胞的定义？）

**11-2-2** 根据上述定义，画出面心立方点阵中的一个 W-S 原胞。

**11-2-3** 假设该晶胞边长为 a，直接写出该 W-S 原胞的体积表达式。

## 参考答案

**11-1-1** 菱面体（1 分） 其中 a = b = c（1 分），α = β = γ（1 分）

**11-1-2**

![](images/a343370978ecaebde39491b496abf72944a617175ece84c982230aad4f418768.jpg)

α = arccos ( (a<sup>2</sup> + b<sup>2</sup> - c<sup>2</sup> ) / 2ab ) = arccos( ( 2 × 0.75 – 2 ) / 2 × 0.75 ) = 109.5°（2 分）

**11-2-1** 一个 W-S 原胞中仅有一个点阵点。（1 分）在三维空间中从晶胞要求必须是平行六面体，而绝大部分的 W-S 原胞不属于平行六面体，故不能作为晶胞（或者说明晶胞中应有尽可能多的直角出现亦可，但只说 W-S 原胞对称性不够高的不得分）（2 分）
