# 题-CM-170-01-金属的单质是高密度低熔点且柔

## 题目

### 第 1 题 9 分， $6 \%$

金属 $M$ 的单质是高密度，低熔点且柔软的。我国很早便发现、生产、应用了 M。早在公元前2000 年，我们的祖先就已经用 M 来铸造货币。M 可以与钠在液氨中反应，先生成白色沉淀，后转化为绿色化合物A，A 与氯乙烷反应可以得到无色、具有粘性的液体B，此化合物常用于汽车汽油的添加剂，以提高辛烷值。将 M 的粉末置于管中，在充满氧气的情况下加热反应，可以得到氧化物 C，将C 与醋酸反应，可以得到有甜味的D。D 既可以与砷酸反应得到沉淀E， 亦可以与黄血盐反应得到沉淀 F，已知E 和 F 中 $\pmb { M }$ 的质量分数分别为 $61.28 \%$ 和 $66.16 \%$ 。 $\bigcirc$
中M 的质量分数分别为61.28%和66.16%。

1-1 给出各字母代表物质的化学式。

1-2 B 可以参与下面的反应， 完成下面反应的方程式。

$$
\pmb { \mathsf { B } } + \mathbf { P } \mathbf { C } \mathbf { l } _{ 5 } = \pmb { \mathsf { G } } + \pmb { \mathsf { H } } + \mathbf { l }
\mathbf { B } + \mathbf { C } \mathbf { H } _{ 3 } \mathbf { C } \mathbf { O } \mathbf { C } \mathbf { l } = \mathbf { G } + \mathbf { J }
$$

## 参考答案

第1题（9分，6%）

1-1 M Pb A Na₄Pb₉ B Pb(C₂H₅)₄ C PbO D Pb(CH₃COO)₂ E Pb₂As₂O₇ F Pb₂[Fe(CN)₆] (每个 1 分)

$$
\mathbf {B} + \mathrm{PCl} _{5} = \mathbf {G} + \mathbf {H} + \mathbf {I}
\mathbf {B} + \mathrm{CH} _{3} \mathrm{COCl} = \mathbf {G} + \mathbf {J}
$$

1-2 $\mathrm{Pb}(\mathrm{C}_{2}\mathrm{H}_{5})_{4}+\mathrm{PCl}_{5}=\mathrm{Pb}(\mathrm{C}_{2}\mathrm{H}_{5})_{3}\mathrm{Cl}+\mathrm{PCl}_{3}+\mathrm{C}_{2}\mathrm{H}_{5}\mathrm{Cl}$ （1分）

$\mathrm{Pb(C_{2}H_{5})_{4} + CH_{3}COCl = Pb(C_{2}H_{5})_{3}Cl + CH_{3}COCH_{2}CH_{3}}$ （1分）
