# 题-CM-111-05-5-1某羧酸衍生物HR在甲苯

## 题目

### 第 5 题（11 分）

5-1 某羧酸衍生物 HR 在甲苯(tol)中可发生如下二聚反应:

$$
2 \mathrm{HR} (\mathrm{o}) \rightleftharpoons \mathrm{H} _{2} \mathrm{R} _{2} (\mathrm{o}) \quad K _{\mathrm{d}} ^{\ominus}
$$

为测定其平衡常数，在 298 K 下，向 50.0 mL 甲苯中加入 0.0200 mol HR，测得此时甲苯的饱和蒸汽压 $p_{tol} = 3.672 \, kPa$ ；此温度下纯甲苯的饱和蒸气压为 $p_{0,tol} = 3.749 \, kPa$ 。设甲苯的饱和蒸气压满足拉乌尔定律，甲苯密度 $\rho_{tol} = 9.355 \times 10^{2} \, kg/m^{3}$ (298 K)，加入 HR 前后溶液体积近似不变，计算 $K_{d}^{\ominus}$ 。

5-2 羧酸衍生物 HR 的甲苯溶液可用于从水溶液中萃取含钯物种。有一含 Pd(II) 和氯离子的酸性溶液，其中钯的分析浓度为 $c_{0}(Pd) = 2.0 \times 10^{-4} \, \text{mol/L}$ ， $[Cl^{-}] = 0.020 \, \text{mol/L}$ ，pH = 1.00；现加入等体积的分析浓度 $c(\text{HR}) = 0.200 \, \text{mol/L}$ 的甲苯溶液，以萃取水相中的 Pd。萃取过程中发生如下反应：

$$
\mathrm{H} _{2} \mathrm{R} _{2} (\mathrm{o}) + \mathrm{PdCl} _{4} ^{2 -} (\mathrm{aq}) \rightleftharpoons \mathrm{PdR} _{2} (\mathrm{o}) + 2 \mathrm{H} ^{+} (\mathrm{aq}) + 4 \mathrm{Cl} ^{-} (\mathrm{aq}) \quad K _{1} ^{\ominus} = 0.11
$$

同时 HR 在水相与有机相间达成平衡:

$$
\mathrm{HR} (\mathrm{aq}) \rightleftharpoons \mathrm{HR} (\mathrm{o}) \quad \text {分配系数} P = \frac {[ \mathrm{HR} ] (\mathrm{o})}{[ \mathrm{HR} ] (\mathrm{aq})} = 10.0
$$

由于水相显酸性，可忽略 HR 在水相中的电离。各络合物的累积稳定常数为：

<table><tr><td></td><td> $\log\beta_1$ </td><td> $\log\beta_2$ </td><td> $\log\beta_3$ </td><td> $\log\beta_4$ </td></tr><tr><td>Pd(II)</td><td>6.1</td><td>10.7</td><td>13.1</td><td>15.4</td></tr></table>

5-2-1 计算水相中 HR 的平衡浓度以及有机相中 HR、 $H_{2}R_{2}$ 的平衡浓度。

5-2-2 计算经过一次萃取后，水相中 Pd 的分析浓度 $c(\mathrm{Pd})$ 。

(若在 5-1 中未求出 $K_{d}^{\ominus}$ ，则 5-2 可按 $K_{d}^{\ominus}=2.0\times10^{2}$ 进行计算)

## 参考答案

## 第5题（11分）

$$
2 \mathrm{HR} (\mathrm{o}) \rightleftharpoons \mathrm{H} _{2} \mathrm{R} _{2} (\mathrm{o}) \quad K _{\mathrm{d}} ^{\ominus}
$$

5-1

甲苯的摩尔数为： $n_{tol}=\rho_{tol}V/M_{tol}=0.5077\ mol$

甲苯和溶质质点分子的总摩尔数为： $n_{0}=n_{tol}p_{0,tol}/p_{tol}=0.5184\ mol$ （1分）

联立：

$$
[ \mathrm{HR} ] + [ \mathrm{H} _{2} \mathrm{R} _{2} ] = (0.5184 \mathrm{mol} - 0.5077 \mathrm{mol}) / 50.0 \mathrm{mL} = 0.214 \mathrm{mol} / \mathrm{L}
\left[ \mathrm{HR} \right] + 2 \left[ \mathrm{H} _{2} \mathrm{R} _{2} \right] = 0.0200 \mathrm{mol} / 50.0 \mathrm{mL} = 0.400 \mathrm{mol} / \mathrm{L} (1 \text {分})
$$

解得:

$$
[ \mathrm{HR} ] = 0.028 \mathrm{mol} / \mathrm{L}; [ \mathrm{H} _{2} \mathrm{R} _{2} ] = 0.186 \mathrm{mol} / \mathrm{L} (1 \text {分})
$$

平衡常数 $K_{d}^{\ominus} = [H_{2}R_{2}]c^{\ominus}/[HR]^{2} = 2.4 \times 10^{2}$ （1 分）

答案算出在 $230 \sim 330$ 均可得分


$$
\mathrm{HR} (\mathrm{aq}) \rightleftharpoons \mathrm{HR} (\mathrm{o})
$$

5-2-1 联立:

$$
[ \mathrm{HR} (\mathrm{aq}) ] + [ \mathrm{HR} (\mathrm{o}) ] + 2 [ \mathrm{H} _{2} \mathrm{R} _{2} (\mathrm{o}) ] = 0.200 \mathrm{mol} / \mathrm{L}
10.0 \times [ \mathrm{HR} (\mathrm{aq}) ] = [ \mathrm{HR} (\mathrm{o}) ]
\left[ \mathrm{H} _{2} \mathrm{R} _{2} (\mathrm{o}) \right] c ^{\ominus} / [ \mathrm{HR} (\mathrm{o}) ] ^{2} = 2.4 \times 10^{2} = K _{\mathrm{d}} ^{\ominus}
$$

解得:

$$
[ \mathrm{HR(w)} ] = 1.93 \times 10^{- 3} \mathrm{mol/L(1分)}
[ \mathrm{HR(o)} ] = 1.93 \times 10^{- 2} \mathrm{mol/L(1分)}
\mathrm {[ H _{2} R _{2} (o)] = 8.94\times10^{- 2} mol / L(1分)}
$$

其他合理解法均可得分。

5-2-2 由于 $[Cl^{-}]$ 、 $[H^{+}]$ 、 $[H_{2}R_{2}(o)]>>c(Pd)$ ，所以可认为萃取前后 $[Cl^{-}]$ 、 $[H^{+}]$ 、 $[H_{2}R_{2}(o)]$ 近似不变（0.5分）；

水相的氢离子浓度为： $\left[H^{+}\right]=10^{-1.00}\ mol/L=0.10\ mol/L$ （0.5分）；

总 Pd 含量与水相中 $PdCl_{4}^{2-}$ 的比例为:

$$
\alpha \left(\mathrm{PdCl} _{4} ^{2 -}\right) = \left(1 + \beta_{1} [ \mathrm{Cl} ^{-} ] ^{4} + \beta_{2} [ \mathrm{Cl} ^{-} ] ^{2} + \beta_{3} [ \mathrm{Cl} ^{-} ] ^{3} + \beta_{4} [ \mathrm{Cl} ^{-} ] ^{4}\right) / \beta_{4} [ \mathrm{Cl} ^{-} ] ^{4} = 0.77 (1 \text {分})
$$

粗略估计得知，Pd 几乎被萃取完全，即 $[PdR_{2}(o)]=2.0\times10^{-4}\ mol/L$ ；则：

$$
\left[ \mathrm{PdCl} _{4} ^{2 -} \right] = 2.0 \times 10^{- 4} \mathrm{mol} / \mathrm{L} \times (0.10 \mathrm{mol} / \mathrm{L}) ^{2} \times (0.020 \mathrm{mol} / \mathrm{L}) ^{4} / (8.94 \times 10^{- 2} \mathrm{mol} / \mathrm{L} \times 0.11)
c (\mathrm{Pd}) = \left[ \mathrm{PdCl} _{4} ^{2 -} \right] / \alpha \left(\mathrm{PdCl} _{4} ^{2 -}\right) = 3.3 \times 10^{- 11} \mathrm{mol} / \mathrm{L} / 0.77 = 4.2 \times 10^{- 11} \mathrm{mol} / \mathrm{L} (1 \text {分})
$$
