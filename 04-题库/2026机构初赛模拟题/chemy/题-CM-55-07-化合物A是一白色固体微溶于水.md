# 题-CM-55-07-化合物A是一白色固体微溶于水

## 题目

### 第 7 题（8 分）

化合物 A 是一白色固体，微溶于水，加热能升华。A 的水溶液可发生以下反应：

(1) 向 $\mathbf{A}$ 的溶液中滴入 NaOH 溶液, 产生黄色沉淀 $\mathbf{B}$ , $\mathbf{B}$ 不溶于碱, 可溶于 $\mathrm{HNO}_{3}$ ;

（2）向 A 的溶液中滴入 $H_{2}S$ 溶液，产生黑色沉淀 C，C 不溶于浓 $HNO_{3}$ ，但可溶于饱和硫化钠溶液得到溶液 D；

(3) 向 $\mathbf{A}$ 的溶液中滴入 $\mathrm{AgNO}_3$ 溶液, 产生白色沉淀 $\mathbf{E}$ , $\mathbf{E}$ 不溶于 $\mathrm{HNO}_3$ , 但可溶于氨水得到溶液 $\mathbf{F}$ ;

（4）向 A 溶液中滴入 $SnCl_{2}$ 溶液至过量，先产生白色沉淀 G，最后得黑色沉淀 H。请写出 A\~H 的化学式。

## 参考答案

第 7 题（8 分）

（1）向A 的溶液中滴入NaOH 溶液， 产生黄色沉淀 B， B 不溶于碱， 可溶于 ${ \mathrm { HNO } } _{ 3 }$ ；（2）向 A 的溶液中滴入 $\mathrm { H } _{ 2 } \mathrm { S }$ 溶液， 产生黑色沉淀C，C 不溶于浓 ${ \mathrm { HNO } } _{ 3 }$ ， 但可溶于饱和硫化钠溶液得到溶液D；

A HgCl2 B HgO C HgS D Na2[HgS2] E AgCl F [Ag(NH3)2]Cl G Hg2Cl2 H Hg（每个1 分）
