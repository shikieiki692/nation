# 题-CM-67-02-2-1将与硫单质按计量系数比

## 题目

### 第 2 题（10 分）

2-1 将 $\mathrm { P } _{ 2 } \mathrm { S } _{ 5 }$ 与硫单质按计量系数比混合加热至 $290^{ \circ } \mathrm { C }$ 以上， 可得到分子式为 $\mathrm { P } _{ 4 } \mathrm { S } _{ 16 }$ 的硫化物。 $^{ 31 } \mathrm { P }$ -NMR 谱显示其中磷原子只有一种化学环境。画出其结构示意图。 $\mathrm { P } _{ 4 } \mathrm { S } _{ 16 }$ 具有出良好的循环性能，可作为锂离子电池的电极材料。 $\mathrm { P } _{ 4 } \mathrm { S } _{ 16 }$ 为锂离子电池的哪一极？请写出放电时该电极的电极反应方程式。

2-2 在惰性气氛中将红磷与硫混合加热至 $180^{ \circ } \mathrm { C }$ ， 得到分子式为 $\mathrm { P } _{ 4 } \mathrm { S } _{ 3 }$ 的化合物， 其含有一根 $C _{ 3 }$ 轴； 室温下， $\mathbf { P } _{ 4 } \mathbf { S } _{ 3 }$ 与等摩尔的碘在苯溶剂中反应，生成 $\beta { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ ； $\beta { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ 在 $\mathrm { CS } _{ 2 }$ 溶剂中与 $[ ( \mathrm { CH } _{ 3 } ) _{ 3 } \mathrm { Sn } ] _{ 2 } \mathrm { S }$ 反应，得到 $\beta { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 4 }$ ， 光谱数据表明其没有 $\scriptstyle \mathrm { P = S }$ 基团； 将 $\beta { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ 加热至$122^{ \circ } \mathrm { C }$ 并再次冷却， 异构化为 $| a { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ ； $\mathrm { \ a - P _{ 4 } S _{ 3 } I _{ 2 } }$ 在 $\mathrm { CS } _{ 2 }$ 溶剂中与 $[ ( \mathrm { CH } _{ 3 } ) _{ 3 } \mathrm { Sn } ] _{ 2 } \mathrm { S }$ 反应， 得到 $\scriptstyle a .$ -$\mathrm { P } _{ 4 } \mathrm { S } _{ 4 }$ ， 其P-S 键长只有一种。 画出 $\mathrm { P } _{ 4 } \mathrm { S } _{ 3 }$ ， $| a { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ ， $\beta { \mathrm { - } } \mathrm { P } _{ 4 } \mathrm { S } _{ 3 } \mathrm { I } _{ 2 }$ ， $\mathrm { \Gamma } _{ a - \mathrm { P _{ 4 } S _{ 4 } } }$ 和 $\beta { \mathrm { - P } } _{ 4 } \mathrm { S } _{ 4 }$ 的结构。
热至180°C，得到分子式为P4S3

2-3 否。(1 分)
二酸和二酸根离子左右对称，熵相对更小；因此第一步电离熵变相对于一般的羧酸更有利，而第二步电离熵变相对与一般的羧酸更不利。(1 分) 因此，无论 n 如何增大， $pK_{a,1}$  和  $pK_{a,2}$  总会有一个差值。
或答：二酸有两个羧基，因此比一般的单羧酸更容易电离（1 分），酸性更大；而二酸根有两个羧酸负离子基团，因此比一般的羧酸根离子更容易水解，因此二酸一氢根酸性更小。
本题的原型为一道较古老的竞赛模拟题：证明当  $n \to \infty$  时，的  $pK_{a,1} = 4 pK_{a,2}$ 。有兴趣的同学可以考虑自行证明。
