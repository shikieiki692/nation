# 题-CM-158-02-元素M的单质是柔软且带有白色

## 题目

### 第 2 题 16 分， 6%

元素 M 的单质是柔软且带有白色光泽的过渡金属。M 不与稀盐酸或者稀硫酸反应，但其能与硝酸反应生成A 而溶解，人们将 A 溶于海藻酸盐中，用于防止伤口的感染。向 A 的溶液中加入盐酸，便有白色沉淀 B 析出，B 一般不溶于无机酸，但因能生成 C 而溶于氨水。将A 的固体和 KCl 和 $\mathrm { F } _{ 2 }$ 共同反应，可以得到有强氧化性的D，D 中 M 的质量分数为 $48.38 \%$ 。2-1 写出 $\mathsf { \pmb { A } } \sim \mathsf { \pmb { D } }$ 代表物质的化学式，并写出生成D 的方程式。
2-2 C 可以与汞单质作用，写出反应方程式。
$2 - 3 A$ 与尿素反应可以得到沉淀E。E 用溴单质处理，除得到一种浅黄色固体和一种气体外，还得到了一种熔点为 $52^{ \circ } \mathrm { C }$ 的有剧毒的白色挥发性晶体，写出涉及的两个反应的方程式。2-4 当 $\pmb { \mathsf { A } }$ 的酸性溶液与乙醇接触时，F 会在无意间被制备出来，它是极具爆炸性的。E 和F互为同分异构体，画出F 的阴离子的最稳定共振式。
2-5 E 与溴单质在合适条件下作用数天后可以得到盐 G。G 的化学式仅比 E 多了一个溴原子。 $\sigma$ 与水反应，产物中含有两种气体和三聚氰酸。写出该反应方程式，并写出能体现G 的结构特点的化学式。

## 参考答案

## 第2题（15分，6%）

2-1 写出 A～D 代表物质的化学式，并写出生成 D 的方程式。

2-1 $\mathrm{AgNO_3}$ AgCl $\mathrm{Ag(NH_3)_2Cl}$ $\mathrm{KAgF_4}$ （每个1分） $\mathrm{AgNO_3 + 2KCl + 2F_2 = KAgF_4 + KNO_3 + Cl_2}$ （1分）

2-2 $2\mathrm{Ag}(\mathrm{NH}_{3})_{2}\mathrm{Cl} + \mathrm{Hg} = \mathrm{Hg}(\mathrm{NH}_{2})\mathrm{Cl} + \mathrm{NH}_{4}\mathrm{Cl} + 2\mathrm{NH}_{3} + 2\mathrm{Ag}$ (2 分)

2-3 $\mathrm{AgNO_3 + CO(NH_2)_2 = AgOCN + NH_4NO_3}$ (2分)

$2AgOCN + 2Br_{2} = 2AgBr + O_{2} + 2BrCN$ （2分）

2-4 $\cdot C\equiv N^{+}-O^{-}$ (2 分)

$$
2 - 518 \mathrm{AgOCNBr} + 6 \mathrm{H} _{2} \mathrm{O} = 18 \mathrm{AgBr} + 4 \mathrm{H} _{3} \mathrm{C} _{3} \mathrm{O} _{3} \mathrm{N} _{3} + 6 \mathrm{CO} _{2} + 3 \mathrm{N} _{2} (2 \text {分})
$$
