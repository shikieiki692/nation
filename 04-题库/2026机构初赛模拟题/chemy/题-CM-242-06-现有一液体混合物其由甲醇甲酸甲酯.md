# 题-CM-242-06-现有一液体混合物其由甲醇甲酸甲酯

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-6-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（11 分）

现有一液体混合物，其由甲醇、甲酸甲酯和甘油组成（不含杂质）。准确称取 0.2002 g 样品于烧瓶中，并加入 10.00 mL 的 3.000 mol L<sup>−1</sup> KOH 溶液，在 N<sub>2</sub>气氛下回流 3h。将反应后的溶液完全转入250 mL容量瓶中并定容。移取25.00 mL于锥形瓶中，并在酚酞指示下用0.1017 mol L<sup>−1</sup>的 H<sub>2</sub>SO<sub>4</sub>溶液滴定，消耗体积为 14.26 mL。移取 25.00 mL 于锥形瓶，加入 25 mL 的4 mol L<sup>−1</sup> KOH 溶液，准确移取 50.00 mL 的 0.01782 mol L<sup>−1</sup> KMnO<sub>4</sub>溶液于锥形瓶中，水浴加热后加入 H<sub>2</sub>SO<sub>4</sub>至强酸性，然后加入 25.00 mL 的 0.09006 mol L<sup>−1</sup> FeSO<sub>4</sub>溶液，充分反应后用 0.01673 mol L<sup>−1</sup> KMnO<sub>4</sub>滴定至终点，用了 11.32 mL。计算样品中各物质的含量（以质量分数计算）。

## 参考答案

n(甲酸甲酯) = c(KOH)V(KOH) – 20c(H<sub>2</sub>SO<sub>4</sub>)V(H<sub>2</sub>SO<sub>4</sub>) = 9.9516×10<sup>−4</sup> mol（1 分）6n(甲醇) + 14n(甘油) = 50c(KMnO<sub>4</sub>)<sub>1</sub>V(KMnO<sub>4</sub>)<sub>1</sub> + 50c(KMnO<sub>4</sub>)<sub>2</sub>V(KMnO<sub>4</sub>)<sub>2</sub>− 10c(Fe<sup>2+</sup>)V(Fe<sup>2+</sup>)− 8n(甲酸甲酯) = 0.023543 mol（1 分）32.042n(甲醇) + 92.094n(甘油) = 0.2002 – 60.052n(甲酸甲酯) = 0.14044 mol（1 分）解得 n(甲醇) = 1.943×10<sup>−3</sup> mol（1 分），n(甘油) = 8.490×10<sup>−4</sup> mol（1 分）则ꞷ(甲醇) = 31.10%（2 分），ꞷ(甲酸甲酯) = 29.85%（2 分），ꞷ(甘油) = 39.05%（2 分）
