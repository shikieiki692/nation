# 题-CM-65-06-6-1化学式为的化合物中含有

## 题目

### 第 6 题（14 分）

6-1 化学式为 $( \mathrm { C _{ 5 } H _{ 5 } NH ) _{ 2 } ( H _{ 3 } O ) _{ 2 } [ CuMo _{ 6 } O _{ 24 } ( As _{ 3 } O _{ 3 } ) _{ 2 } ] }$ 的化合物中含有具有 Anderson 结构的 $D _{ 3 \mathrm { d } }$ 群多核配离子 $\mathrm { [ CuMo _{ 6 } O _{ 24 } ( As _{ 3 } O _{ 3 } ) _{ 2 } ] ^{ 4 - } }$ 。该阴离子的结构可看作由具有 Anderson 结构的$\begin{array} { r } { [ \mathrm { CuMo } _{ 6 } \mathrm { O } _{ 24 } ] ^{ 10 \cdot } } \end{array}$ -与和两个 $[ \mathrm { As } _{ 3 } \mathrm { O } _{ 6 } ] ^{ 3 }$ -基团之间通过共用氧原子相连而形成的； $\mathrm { Cu }$ 和 Mo 均形成$\mathrm { [ MO _{ 6 } ] }$ 八面体，且它们之间共棱连接；Cu、Mo 和As 均只有一种化学环境。将化合物在氮气气氛中加热至 $321^{ \circ } \mathrm { C }$ ， 失重 $11.17 \%$ ； 继续加热至 $515^{ \circ } \mathrm { C }$ ， 又失重 $35.50 \%$ ， 残余固体为两种氧化物的混合物。

热至321°C，失重11.17%；继续加热至515°C，又失重35.50

6-1-1 分别指出上述化合物中 $\mathrm { Cu }$ 、 Mo 和 As 的氧化态。

6-1-2 请分别画出 $\mathrm { [ CuMo _{ 6 } O _{ 24 } ] ^{ 10 } }$ -和 $[ \mathrm { As } _{ 3 } \mathrm { O } _{ 6 } ] ^{ 3 }$ -的结构示意图。

6-1-3 通过计算说明， 将化合物在氮气气氛中加热至 $321^{ \circ } \mathrm { C }$ 失去的组分是什么。

6-1-4 通过计算确定加热至 $515^{ \circ } \mathrm { C }$ 后残余固体的成分。

6-2 富瓦烯(简记为Fv， 结构如右图)能与过渡金属形成多种多样的配合物。例如，富瓦烯与钌能形成化学式为 ${ \mathrm { Ru _{ 2 } Fv ( CO ) } } _{ 4 }$ 的双核配合物A，A 含有Ru-Ru 键。在光照下，A 中的碳碳键发生断裂，转化为其同分异构体B；B 不含 $\mathrm { Ru - Ru }$ 键，在温热条件下即又转化回A。A、B 均满足 18 电子规则。 请画出A、 B 的结构示意图。
