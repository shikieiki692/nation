# 题-CM-176-03-锂硫电池

## 题目

### 第 03 题 锂硫电池（15 分）

硫（S8）是下一代电池技术中最有希望的正极材料。它具有极高的理论容量， 而且成本极低。 锂硫电池的简单构造如图1 所示，其中硫为正极材料，金属锂为负极材料， 完全放电的产物为不溶的 Li2S。

3-1 写出锂硫电池完全放电的电极反应方程式。

3-2 计算硫电极的理论容量 （用 $\mathrm { \ mAh / g }$ 表示）。

3-3 目前市面上旗舰手机锂离子电池的平均电压为 $3.85 \mathrm { ~ V ~ }$ ，电池容量 $6100 ~ \mathrm { { mAh } }$ 。 锂硫电池的平均电压为$2.15 \mathrm { V }$ ，假设硫电极含有 $32.07 \mathrm { g }$ 活性正极材料。分别计算两种电池可以输出的最大电功 （用kW 表示），锂硫电池可以输出的电功是锂离子电池多少倍。

3-4 锂硫电池实际在充放电工作时会生成一系列可以溶于电解液的中间产物 $\mathrm { Li } _{ 2 } \mathrm { S } _{ \mathrm { n } } ( 3 { \leq } \mathrm { n } { \leq } 8 )$ （图2）， 这些多硫化物可以发生穿梭效应， 迁移到负极， 生成不溶物， 造成容量损失。 写出反应方程式。
