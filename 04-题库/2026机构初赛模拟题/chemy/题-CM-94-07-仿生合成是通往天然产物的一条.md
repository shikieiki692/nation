# 题-CM-94-07-仿生合成是通往天然产物的一条

## 题目

### 第 7 题（16 分）

仿生合成是通往天然产物的一条捷径。2017年，某研究小组利用仿生合成的方法，仅用7步便完成了复杂天然产物(±)-Homodimericin A的全合成。Homodimericin A的结构如下所示：

![](images/1cdb26cb6813e0229d656fda7898ba38152d552de77faa3056bc5b02a43b8efe.jpg)

7-1 Homodimericin A 是由两个完全相同的片段 X 在聚合后经过一系列反应得到的(详见第 3 小问)。已知从 X 到 Homodimericin A 的反应过程中没有发生任何碳骨架的重排，试在 Homodimericin A 的结构中用星号标出一个 X 片段的碳骨架，并将新形成的碳-碳 $\sigma$ 键切断。题干已标出其中一个 X 片段中的部分碳原子和一条新形成的碳-碳 $\sigma$ 键，你只需要将新形成的碳-碳 $\sigma$ 键和该片段剩余的骨架碳原子标出即可。

7-2 科学家们用下面的方法合成了 X 的前体 Y:

![](images/2f32e95fa4c0205be30959e5a8d07a2223a8c688a734feee3d083acdf6dfc8fa.jpg)
7-2-1 选用常见的无机或有机试剂，完成 A 到 B 的转化(要求在 3 步或以内)。

7-2-2 画出 Y 的结构。

7-3 Y 到 Homodimericin A 的转化只有一步之遥。在 pH = 8 的缓冲体系中，Y 被 Fremy 盐 ( $K_{2}[ON(SO_{3})_{2}]$ ) 氧化，一锅生成了 (±)-Homodimericin A，其机理如下所示：

![](images/b99b156df45a1b7e553f1dc5bf5f017ac155b888cfde1fcd174b8245583703c1.jpg)

7-3-1 画出 Fremy 盐阴离子的 Lewis 结构式。

7-3-2 已知在上面的流程中 Fremy 盐仅仅是对芳环进行了氧化，X 和 $M_{1} \sim M_{6}$ 均为电中性的闭壳层物种。画出 X 和 $M_{1} \sim M_{6}$ 的结构，不要求立体化学。
