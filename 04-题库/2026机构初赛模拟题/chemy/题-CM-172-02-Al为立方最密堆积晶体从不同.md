# 题-CM-172-02-Al为立方最密堆积晶体从不同

## 题目

### 第 2 题 铝-钛合金及其结构（22 分，占 $10 \%$

Al 为立方最密堆积晶体。从不同温度和组成的 Al-Ti 熔体中能析出多种Al-Ti 合金(如 $\mathbf { L } 1 _{ 0 }$ 结构、Al5Ti3、h-Al2Ti3 等)，在这些结构中，Al 和Ti 原子仍然共同做立方最密堆积。
2-1 在Al 单质中，Al 的原子半径为 $143.0 \mathrm { pm }$ 。计算晶胞参数 $a$ 和Al 的金属密度。2-2 最简单的 Al-Ti 合金为 $\mathrm { L } 1 _{ 0 }$ 结构；它可看作是由 Al 原子和 Ti 原子分别形成具有四重轴对称性的单层(分别记为A 层和B 层)；单层沿 $\scriptstyle { \boldsymbol { c } }$ 方向按照…ABABAB…的方式进行堆积。2-2-1 写出 L10 结构的化学式。
2-2-2 设 Al-Al 最短间距为 $284.0 ~ \mathrm { pm }$ ， Al-Ti 最短间距为 $286.0 \ \mathrm { pm }$ ，求 $\mathrm { L } 1 _{ 0 }$ 结构的晶胞参数。2-3 结构较为复杂的 Al-Ti 合金有 $\mathrm { Al } _{ 5 } \mathrm { Ti } _{ 3 }$ 、 $\mathrm { \ h - Al _{ 2 } Ti }$ 等。在这2 种合金中，单层 A 和单层B 仍沿 $\scriptstyle { \mathbf { \alpha } } _{ c }$ 方向按照…ABABAB…的方式进行堆积；A 层均仍为仅由Al 原子形成的层。合金 Al5Ti3为四方晶体，晶胞参数 $a = 1592 ~ \mathrm { pm }$ ， $c = 402 ~ \mathrm { pm }$ 。合金 $\mathrm { \ h - Al _{ 2 } Ti }$ 为正交晶体，晶胞参数 $a =$ $396 \mathrm { pm }$ ， $b = 1209 \mathrm { pm }$ ， $c = 403 ~ \mathrm { pm }$ ； 所有Ti 原子的化学环境相同。
2-3-1 分别写出 $\mathrm { \ Al _{ 5 } Ti _{ 3 } }$ 和 $\mathrm { \ h - Al _{ 2 } Ti }$ 的晶胞中含有的化学式的数目。
2-3-2 分别写出 $\mathrm { Al } _{ 5 } \mathrm { Ti } _{ 3 }$ 和 $\mathrm { \ h - Al _{ 2 } Ti }$ 的B 层的化学组成。

2-3-3 写出 $\mathrm { \ h { - } Al _{ 2 } Ti }$ 的点阵类型； 画出 B 层的结构示意图。

## 参考答案

2-1 (共5分)

$a = 143.0 \, pm \times 2 \times \sqrt{2} = 404.5 \, pm$ （2分）

$$
D = Z M / N _{\mathrm{A}} V = 4 \times 26.98 \mathrm{g} / \mathrm{mol} \div (6.022 \times 10^{23} / \mathrm{mol} \times (404.5 \mathrm{pm}) ^{3}) = 2.707 \mathrm{g} / \mathrm{cm} ^{3} (3 \text {分})
$$

2-2-2 设 Al-Al 最短间距为 284.0 pm，Al-Ti 最短间距为 286.0 pm，求 L1₀ 结构的晶胞参数。
2-2（共8分）

2-2-1 化学式：AlTi（1 分）

2-2-2 晶胞参数 a = 284.0 pm; b = 284.0 pm (2 分)

设层间距为 h，则： $h^{2}+(284.0\ \text{pm}\div\sqrt{2})^{2}=(286\ \text{pm})^{2}$ （1 分）

h = 203.6 pm (1 分)

$$
c = 2 h = 407.2 \mathrm{pm} (2 \text {分})
\alpha = \beta = \gamma = 90^{\circ} (1 \text {分})
$$


2-3（共9分）

2-3-1 分别为 8（1 分）和 4（1 分）。

2-3-2 分别为 $AlTi_{3}$ （1 分）和 $AlTi_{2}$ （1 分）比例正确即可。
