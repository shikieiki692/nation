# 题-CM-244-01-11在冷暗的环境中用BaOH2处

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-9-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（10 分）

**1-1** 在冷、暗的环境中，用 Ba(OH)<sub>2</sub>处理 Fe(CO)<sub>5</sub>，反应得到橙色化合物 Ba[Fe(CO)<sub>4</sub>]和白色沉淀 BaCO<sub>3</sub>。

**1-2** 碳酸钠、硫单质和氯化钴(Ⅱ)以摩尔比 1 : 2 : 1 反应，得到 Co<sub>2</sub>S<sub>3</sub>。

**1-3** 二苯基汞与过量四氯化钛发生氧化还原反应，得到苯基氯化汞、一种氯化物和一种烃。

**1-4** 过量的汞单质可在硫酸水溶液将 V<sub>2</sub>O<sub>5</sub>还原为四价钒。

**1-5** Cr(NCS)<sub>6</sub><sup>3-</sup>在酸性条件下被 MnO<sub>4</sub><sup>-</sup>彻底氧化。

## 参考答案

**1-1** Fe(CO)<sub>5</sub> + 2Ba(OH)<sub>2</sub> = Ba[Fe(CO)<sub>4</sub>] + BaCO<sub>3</sub> + 2H<sub>2</sub>O（2 分）

**1-2** 2Na<sub>2</sub>CO<sub>3</sub> + 4S + 2CoCl<sub>2</sub> = Co<sub>2</sub>S<sub>3</sub> + 4NaCl + 2CO<sub>2</sub> + SO<sub>2</sub>（2 分）

**1-3** 2(C<sub>6</sub>H<sub>5</sub>)<sub>2</sub>Hg + 2TiCl<sub>4</sub> = 2(C<sub>6</sub>H<sub>5</sub>)HgCl + 2TiCl<sub>3</sub> + C<sub>6</sub>H<sub>5</sub>-C<sub>6</sub>H<sub>5</sub>（2 分）

**1-4** V<sub>2</sub>O<sub>5</sub> + 2Hg + 3H<sub>2</sub>SO<sub>4</sub> = 2VOSO<sub>4</sub> + Hg<sub>2</sub>SO<sub>4</sub> + 3H<sub>2</sub>O（2 分）

**1-5** 10Cr(NCS)<sub>6</sub><sup>3-</sup> + 198MnO<sub>4</sub><sup>-</sup> + 434H<sup>+</sup> = 60NO<sub>3</sub><sup>-</sup> + 60SO<sub>4</sub><sup>2-</sup> + 5Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> + 198Mn<sup>2+</sup> + 217H<sub>2</sub>O

（2 分）
