# 题-CM-91-06-已知热力学数据如下不考虑没有

## 题目

### 第 6 题（9 分）

已知热力学数据如下，不考虑没有提到的物种，假设所有反应均能达到热力学平衡；温度取298.2 K。

<table><tr><td>物种</td><td> $\Delta_{\text{f}}H_{\text{m}}^{\ominus}/\text{kJ}\cdot\text{mol}^{-1}$ </td><td> $S_{\text{m}}^{\ominus}/\text{J}\cdot\text{K}^{-1}\cdot\text{mol}^{-1}$ </td></tr><tr><td>Ag(s)</td><td></td><td>42.6</td></tr><tr><td> $AgNO_{3}(s)$ </td><td>-124.4</td><td>140.9</td></tr><tr><td> $AgNO_{2}(s)$ </td><td>-45.9</td><td>128.2</td></tr><tr><td> $Ag_{2}O(s)$ </td><td>-31.1</td><td>121.3</td></tr><tr><td>NO(g)</td><td>91.3</td><td>210.8</td></tr><tr><td> $NO_{2}(g)$ </td><td>33.1</td><td>240.1</td></tr></table>

6-1 含少量 $\mathrm{O}_{2}(\mathrm{~g})$ 的 $\mathrm{NO}_{2}(\mathrm{~g})$ 被过量 $\mathrm{Ag}(\mathrm{s})$ 吸收，生成 $\mathrm{AgNO}_{2}(\mathrm{s})$ 和另一种固体，无常量气体剩余。结合计算说明生成的另一种固体是 $\mathrm{AgNO}_{3}(\mathrm{s})$ 还是 $\mathrm{Ag}_{2}\mathrm{O}(\mathrm{s})$ ?

6-2 恒容 0.500 L 的容器内初有 0.1000 mol Ag(s)，向其中通入 6.902 g NO $_{2}$ (g)，计算达到平衡时的气相组成(用摩尔分数表示)。已知 2NO $_{2}$ (g) = N $_{2}$ O $_{4}$ (g) 的 K $^{\ominus}$ = 2.9。提示: Ag(s) 与 Ag $_{2}$ O(s) 均不存在。

## 参考答案

## 第6题（9分）

6-1 必定发生的反应为：$\mathrm{Ag(s) + NO_2(g) = AgNO_2(s)}$（1分）
涉及 $\mathrm{O}_2$ 的反应可能为：（1分）
(1) $4\mathrm{Ag(s) + O_2(g) = 2Ag_2O(s)}$ (2) $2\mathrm{AgNO_2(s) + O_2(g) = 2AgNO_3(s)}$
考虑两个产物之间的转化：
$2\mathrm{Ag(s) + AgNO_3(s) = Ag_2O(s) + AgNO_2(s)}$ $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} = (-45.9\mathrm{kJ}\cdot \mathrm{mol}^{-1}) + (-31.1\mathrm{kJ}\cdot \mathrm{mol}^{-1}) - (-124.4\mathrm{kJ}\cdot \mathrm{mol}^{-1})$ $= 47.4\mathrm{kJ}\cdot \mathrm{mol}^{-1}$（0.5分）
$\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus} = 128.2\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} + 121.3\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} - 140.9\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} - 2\times 42.6\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$ $= 23.4\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$（0.5分）
$\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus} = 47.4\mathrm{kJ}\cdot \mathrm{mol}^{-1} - 298.2\mathrm{K}\times 23.4\times 10^{-3}\mathrm{kJ}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} = 40.4\mathrm{kJ}\cdot \mathrm{mol}^{-1}$（0.5分）
逆反应自发，故不可能生成 $\mathrm{Ag_2O}$（0.5分）
综上，生成的固体为 $\mathrm{AgNO_2}$ 与 $\mathrm{AgNO_3}$（1分）
固体为AgNO2 与AgNO3（1 分）若额外答出，在O2(g)浓度极

若额外答出，在 $\mathrm{O}_2(\mathrm{g})$ 浓度极低时，有可能只生成 $\mathrm{AgNO_2}$，不得分也不扣分。

$$
2 \mathrm{NO} _{2} (\mathrm{g}) = \mathrm{N} _{2} \mathrm{O} _{4} (\mathrm{g})
K ^{\ominus} = 2.9
\mathrm{NO} _{2} (\mathrm{g})
\mathrm{示}: \mathrm{Ag} (\mathrm{s})
\mathrm{Ag} _{2} \mathrm{O} (\mathrm{s})
$$

6-2 $\mathrm{NO}_2(\mathrm{g}) + \mathrm{AgNO}_2(\mathrm{s}) = \mathrm{NO}(\mathrm{g}) + \mathrm{AgNO}_3(\mathrm{s})$ $\Delta_{\mathrm{r}}H_{\mathrm{m}}^{\ominus} = 91.3\mathrm{kJ}\cdot \mathrm{mol}^{-1} + (-124.4\mathrm{kJ}\cdot \mathrm{mol}^{-1}) - 33.1\mathrm{kJ}\cdot \mathrm{mol}^{-1} - (-45.9\mathrm{kJ}\cdot \mathrm{mol}^{-1})$ $= -20.3\mathrm{kJ}\cdot \mathrm{mol}^{-1}$ （0.5分）
$\Delta_{\mathrm{r}}S_{\mathrm{m}}^{\ominus} = 210.8\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} + 140.9\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} - 128.2\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} - 240.1\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$ $= -16.6\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}$ （0.5分）
$\Delta_{\mathrm{r}}G_{\mathrm{m}}^{\ominus} = -20.3\mathrm{kJ}\cdot \mathrm{mol}^{-1} + 298.2\mathrm{K}\times 16.6\times 10^{-3}\mathrm{kJ}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1} = -15.3\mathrm{kJ}\cdot \mathrm{mol}^{-1}$ （0.5分）
$K^{\ominus} = \exp [15.3\times 10^{3}\mathrm{J}\cdot \mathrm{mol}^{-1}/(8.314\mathrm{J}\cdot \mathrm{K}^{-1}\cdot \mathrm{mol}^{-1}\times 298.2\mathrm{K})] = 479$ （0.5分）
$n_0(\mathrm{NO}_2) = 6.902\mathrm{g}/46.01\mathrm{g}\cdot \mathrm{mol}^{-1} = 0.1500\mathrm{mol}$
设气象 $p(\mathrm{NO}_2) = x$ bar，故 $p(\mathrm{N}_2\mathrm{O}_4) = 2.9x^2$ bar， $p(\mathrm{NO}) = 479x$ bar
显然所有 Ag 被转化为 $\mathrm{AgNO_2}$ 或 $\mathrm{AgNO_3}$，故固相有 $0.1000\mathrm{molN}$，气相有 $0.0500\mathrm{molN}$ 物料守恒： $[p(\mathrm{NO}_2) + p(\mathrm{NO}) + 2p(\mathrm{N}_2\mathrm{O}_4)]V / RT = 0.0500\mathrm{mol}$ （1分）
即： $(x + 479x + 2\cdot 2.9x^2)\cdot (100\times 0.500) / (8.314\times 298.2) = 0.0500$
解得 $x = 5.16\times 10^{-3}$
故 $p(\mathrm{NO}_2) = 5.16\times 10^{-3}$ bar， $p(\mathrm{N}_2\mathrm{O}_4) = 7.7\times 10^{-5}$ bar， $p(\mathrm{NO}) = 2.47$ bar（2分）
$x(\mathrm{NO}_2) = 2.08\times 10^{-3}, x(\mathrm{N}_2\mathrm{O}_4) = 3.1\times 10^{-5}, x(\mathrm{NO}) = 0.998$ （1分）
