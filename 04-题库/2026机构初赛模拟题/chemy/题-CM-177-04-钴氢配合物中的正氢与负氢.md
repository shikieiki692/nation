### 第 04 题 钴氢配合物中的正氢与负氢（24 分）

钴氢配合物是许多重要催化转化反应的催化剂， 包括氢甲酰化、 制氢和 $\mathrm { CO } _{ 2 }$ 加氢。

`\mathbf { 4 { - } 1 { - } 2 \thinspace CO } _{ 2 }` 加氢反应催化循环的第一步通常是金属氢配合物对 $\mathrm { CO } _{ 2 }$ 的还原。 能否还原 $\mathrm { CO } _{ 2 }$ 的一个简单判据是金属氢配合物和 HCOO-之间氢化度 $\Delta { \mathrm { G } } _{ \mathrm { H } } ^{ \theta } .$ -的差异。 HCOO-的氢化度 $\Delta \mathrm { G } _{ \mathrm { { H } } } ^{ \theta }$ -为 $+ 44 \mathrm { kcal / mol }$ 。
