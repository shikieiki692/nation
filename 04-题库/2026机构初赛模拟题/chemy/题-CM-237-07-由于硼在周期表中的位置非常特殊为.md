# 题-CM-237-07-由于硼在周期表中的位置非常特殊为

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-18-7`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 7 题（18 分，占 10.0%）

由于硼在周期表中的位置非常特殊，为了缓解硼原子中心的缺电子性，许多硼化物中都广泛

地存在着多中心键，例如在各种硼“单质”中几乎都存在着三角二十面体单元。根据“对角

线规则”，硅与硼具有相似的性质，硼硅化物 X 中也大量存在三角二十面体单元。

**7-1** X 的晶体结构可简化为如下描述：若将原子簇[B<sub>n</sub>Si<sub>12-n</sub>]看作单一原子 A，则 A 按照立方

最密堆积方式堆积，其位于晶胞顶点的位置；Si<sub>2</sub>单元填入由 A 构成的所有八面体空隙，Si<sub>2</sub>

所在直线与 A 的堆积方向平行。X 的部分晶胞参数为：a = b = 631.9 pm，c = 1271.3 pm。

**7-1-1** 指出 X 晶体所属的晶系及其特征对称元素。

**7-1-2** 已知 X 中一个 Si 原子的坐标为(0, 0, 0.4030)，计算与之化学环境相同的 Si 原子之间最

近和次近的两种距离。

**7-1-3** 若将 X 晶体中的 Si<sub>2</sub>单元均移走，剩余的原子会形成一种典型的晶体结构，写出其点

阵型式。

**7-2** 若考虑 A 的结构和朝向，则三角二十面体单元的两个相对的三角面应垂直于 c 轴，而不

属于这两个三角面的六个原子应分别对齐原子簇周围的六个 Si 原子。

**7-2-1** 判断所有原子簇的取向是否完全相同。

**7-2-2** 考虑到原子簇之间也会形成共价键，假设除原子簇内部的键外，所有共价键均为正常

的二中心二电子键，为了达到稳定的结构，指出合适的 n 的值 (提示：尝试运用等电子体)，

并计算其晶体密度。

![](images/749eb6efb4b2784586a0ab83cb0fe13fae5347cf72a9dcfdf58446cf19e3eac2.jpg)

## 参考答案

**7-1-1**

晶系：三方晶系（2 分）；特征对称元素：I<sub>3</sub>（2 分，C<sub>3</sub>，3<sub>1</sub>螺旋轴均可得分）

**7-1-2**（共 6 分，过程 2 分，结果 4 分）

有三个备选的距离，分别为：平行于 c 轴方向的 Si-Si 距离、垂直于 c 轴方向的 Si-Si 距离以

及斜方向的 Si-Si 距离。

对于上述三种距离，可以选定题干中 Si 原子附近的三个 Si 原子进行计算，它们的坐标分别

为(0, 0, 0.5970)、(0, 1, 0.4030)和(0.3333, 0.6667, 0.2637)。

![](images/3d1ffed992e6346556fa3899eaedaf44f7f7342d99bf2a4ae797e274c51cbecd.jpg)

垂直距离 d<sub>2</sub> = a = 631.9 pm

![](images/2c9e6cc07f0366ce5e72d7c938a417cf07cf08aa1b93e6579e9a02c98af2d3ca.jpg)

因此最短和次短的距离分别为 246.6 pm 和 405.5 pm（各 2 分）

**7-1-3** 点阵型式：面心立方点阵(cF)（2 分）

**7-2-1** 完全相同（2 分）

**7-2-2** n = 10（2 分），对应化学式为 B<sub>30</sub>Si<sub>12</sub>，则密度

![](images/76a3e5553b1e41cfe513f8fb89cc1ac2b56787e984fb9294b01017c743614f86.jpg)

pm<sup>3</sup>] = 2.498 g/cm<sup>3</sup>（2 分）
