# 题-CM-66-07-向的溶液中加入反应生成等量的

## 题目

### 第 7 题（10 分）

向 $\mathrm { B } _{ 2 } \mathrm { H } _{ 4 } [ \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ] _{ 2 }$ 的 $\mathrm { CH } _{ 2 } \mathrm { Cl } _{ 2 }$ 溶液中加入 $\mathrm { [ C ( C _{ 6 } H _{ 5 } ) _{ 3 } ] [ BF _{ 4 } ] }$ 反应， 生成等量的 $\mathrm { BH } _{ 3 } [ \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ]$ 和$[ \mathrm { B } _{ 3 } \mathrm { H } _{ 4 } ( \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ) _{ 3 } ] [ \mathrm { BF } _{ 4 } ]$ ； $- 40^{ \circ } \mathrm { C }$ 的 $^{ 31 } \mathrm { P }$ -NMR 谱显示， $\mathrm { B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 3 } } ^{ + }$ 中磷原子有两种化学环境； 而 $0^{ \circ } \mathrm { C }$ 的 31P-NMR 谱显示， $\mathrm { B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 3 } ^{ + } }$ 中磷原子只有一种环境。用干燥的甲苯洗涤$\mathrm{[B_{3}H_{4}(P(CH_{3})_{3})_{3}][BF_{4}]}$ 以除去其中的 $\mathrm { BH } _{ 3 } ( \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } )$ ， 发现部分 $\mathrm { [ B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 3 } ] [ BF _{ 4 } ] }$ 转化为了$\mathrm { [ B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 4 } ] [ BF _{ 4 } ] _{ \circ } }$ 。

7-1 写出 $\mathrm { B } _{ 2 } \mathrm { H } _{ 4 } [ \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ] _{ 2 }$ 与 $\mathrm{[C(C_{6}H_{5})_{3}][BF_{4}]}$ 反应的化学反应方程式。

7-2 画出 $\mathrm { B } _{ 2 } \mathrm { H } _{ 4 } [ \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ] _{ 2 }$ 、 $\mathrm { BH } _{ 3 } [ \mathrm { P } ( \mathrm { CH } _{ 3 } ) _{ 3 } ]$ 、 $\mathrm { [ B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 3 } ] ^{ + } }$ 和 $\mathrm { [ B _{ 3 } H _{ 4 } ( P ( CH _{ 3 } ) _{ 3 } ) _{ 4 } ] ^{ + } }$ 的结构简式。

7-3 解释 $\mathrm { B _{ 3 } H _{ 4 } } [ \mathrm { P } ( \mathrm { CH _{ 3 } } ) _{ 3 } ] _{ 3 } +$ 的 $^{ 31 } \mathrm { P }$ -NMR 谱随温度变化的原因。
