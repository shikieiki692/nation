# 题-CM-167-01-1-1磷是生命生产与生活中的

## 题目

### 第 1 题

# 第 1 题 （27 分， $16 \%$ ） 磷簇化学

1-1 磷是生命、生产与生活中的常见元素。工业上用氟磷灰石 $( \mathrm { Ca } _{ 5 } ( \mathrm { PO } _{ 4 } ) _{ 3 } \mathrm { F } )$ 在 $\mathrm { SiO } _{ 2 }$ 的存在下与焦炭反应制备最常见的磷簇。写出化学方程式。1-2 上述磷簇虽然满足八电子结构，但并不十分稳定。在 ${ \mathbf { A } } { \mathbf { g } } ^{ + }$ 的作用下，它可以与 NOCl、$\mathrm { PBr } _{ 3 }$ 分别发生反应得到具有 2 个对称面与 1 根 $C _{ 2 }$ 轴的离子，分别画出其结构。1-3 在室温下，虽然该磷簇很不稳定，容易自燃，但其仍然不会形成双原子分子。解释原因。1-4 为了制得室温下稳定的双磷结构，需要采用特殊的手段。经典的制备方法是由 $\mathrm { PCl } _{ 3 }$ 出发， 先经如下配体Ln 处理， 随后与过量 $\mathrm { KC } _{ 8 }$ 反应， 生成双核配合物 $\blacktriangle _{ \mathfrak { n } }$ 。

![](images/bdba5ca7890631b981045588ab75e3f6935344e5bcfc3ea338c249c022c875ab.jpg)

1-4-1 画出 $\pmb { A } _{ \pmb { \mathrm { n } } }$ 的结构通式。

1-4-2 当配位为 $\mathbf { L } _{ 1 }$ ： $\mathrm { R } = 2 , 6 \cdot$ -二异丙基苯基(dipp)时， $\pmb { A } _{ 1 }$ 为 $\mathrm { C } _{ 2 \mathrm { h } }$ 点群，而配位为L2： $\boldsymbol { \mathrm { R } } = \boldsymbol { \mathrm { H } }$ 时，$\blacktriangle _{ 2 }$ 为 $\mathbf { C } _{ 2 }$ 点群， 解释差异。

1-4-3 解释此时 $\blacktriangle _{ \mathfrak { n } }$ 的稳定性。

1-5 2021 年，科学家制备了具有 D2d 对称性的磷簇结构 C，其合成路线如下：以 Pt(PNP)(PCO)$\mathrm { ( PNP = ( t { - } Bu _{ 2 } PCH { = } CH ) _{ 2 } N ^{ - } ) }$ 为原料，在 $\mathrm { C _{ 6 } D _{ 6 } ^{ - } }$ 中，456nm 光照射下得到了双核配合物B，B 在`\mathrm { \sf Ag [ BAr ^{ F } _{ 4 } ] }` 的作用下生成 C。

1-5-1 画出 $B , C$ 的结构。 除 C 外， PNP 配体可以缩写为 PNP。 C 中 PNP 配体可以缩写为P—N—P， 需要示出立体结构。

1-5-2 比较 B 与 C 中 $\mathrm { Pt - N }$ 键长哪个更长。

1-5-3 比较 B 与 C 中 Pt-P(in `{ \bf P } _{ 2 } )` 的键长哪个更长。

C 在配体作用下可以发生有趣的配体交换反应。

1-5-4 写出 C 与过量 t-BuNC 发生反应的化学方程式。

1-5-5 C 在t-BuNC 或CO 与1,3-环己二烯的共同作用下，可以得到单核配合物 ${ \pmb { \mathsf { D } } } _{ 1 } ( \mathrm { CO } )$ 或 $\sqsupseteq _{ 2 }$ (t-BuNC)与单核配合物 E 的混合物，且满足 $n ( \pmb { \mathsf { D } } _{ 1 } ) : n ( \pmb { \mathsf { E } } ) = n ( \pmb { \mathsf { D } } _{ 2 } ) : n ( \pmb { \mathsf { E } } ) = 1 : 1$ 。 画出 $\mathsf { D } _{ 1 }$ 与 E的结构。

1-5-6 但是，若先用 CO 处理 C， 同样可以生成两种配合物 $\overline { \mathsf { D } } _{ 1 }$ 与 F， 其摩尔比为 2:1， 此时再用1,3-环己二烯处理 F 并不能得到 E。若F 具有 $\mathrm { C } _{ 2 \mathrm { v } }$ 对称性， 画出 F 的结构。
