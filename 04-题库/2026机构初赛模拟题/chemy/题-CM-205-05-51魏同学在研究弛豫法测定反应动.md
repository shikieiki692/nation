# 题-CM-205-05-51魏同学在研究弛豫法测定反应动

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-14-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（22 分，占 13%）

**5-1** 魏同学在研究弛豫法测定反应动力学时发现，铬酸根离子与重铬酸根的转换的机理可分为两步：

反应 1 H<sup>+</sup> + CrO<sub>4</sub><sup>2-</sup> ⇌ HCrO<sub>4</sub><sup>- </sup>K<sub>1</sub> = 1.3×10<sup>6 </sup>

反应 2 2HCrO<sub>4</sub><sup>-</sup> ⇌ Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> + H<sub>2</sub>O K<sub>2</sub> = 50通过计算分别说明在碱性条件（pH = 12）和酸性条件（pH = 2）下 0.05 mol·L<sup>-1</sup> K<sub>2</sub>CrO<sub>4</sub>水溶液中 Cr (VI)的主要存在形态。

**5-2** 魏同学闲来无事，搜集了一些数据想计算难溶盐 ZnS 的溶解度。他找到 ZnS 的 pK<sub>sp</sub> = 21.60，H<sub>2</sub>S 的 pK<sub>a1</sub> = 6.89，pK<sub>a2</sub> = 14.15。据此他提出了以下算法：

1) 假设 ZnS 溶于水后所有 S<sup>2-</sup>均水解，即 ZnS + H<sub>2</sub>O ⇌ Zn<sup>2+</sup> + HS<sup>-</sup> + OH<sup>-</sup>；

2) 因此，K = [Zn<sup>2+</sup>][HS<sup>-</sup>][OH<sup>-</sup>] = K<sub>sp</sub>K<sub>w</sub> / K<sub>a2</sub> = 1.8 × 10<sup>-22</sup>；

3) 由于体系中不存在其他反应，则[OH<sup>-</sup>] = K<sup>1/3</sup> = 5.6 × 10<sup>-8</sup> mol·L<sup>-1</sup>；

4) 求得 pH = 6.75。他基于朴素的化学直觉意识到，在忽略 Zn<sup>2+</sup>水解的情况下，弱酸阴离子水解却使得溶液呈酸性是很荒谬的。请指出他算法中哪一步出现了错误，并帮助他计算出正确的 pH 值和此时溶液中 Zn<sup>2+</sup>的浓度。

**5-3** 一天，魏同学按某个实验条件生成了 Cu<sub>2</sub>S 并探索了它的一些性质。实验结束后清理仪器时，由于贪图省事，他直接将硝酸注入底部附着有 Cu<sub>2</sub>S 固体的敞口试管并将其丢进水浴锅中便开始等待固体溶解。偶然路过的教练嗅到了刺激性气味的气体，赶忙进来打断了他的操作。写出 Cu<sub>2</sub>S 固体与硝酸反应的离子方程式，计算其标准平衡常数。可能用到的数据：φ°(Cu<sup>2+</sup>/Cu) = 0.342 V，φ°(Cu<sup>+</sup>/Cu) = 0.521 V，φ°(S/H<sub>2</sub>S) = 0.142 V，φ°(S/S<sup>2-</sup>) = -0.476 V，φ°(NO<sub>3</sub><sup>-</sup>/NO) = 0.942 V，K<sub>sp</sub>(Cu<sub>2</sub>S) = 2.5 × 10<sup>-48</sup>。

## 参考答案

**5-1**（共 6 分）K<sub>1</sub> = [HCrO<sub>4</sub><sup>-</sup>] / [H<sup>+</sup>][CrO<sub>4</sub><sup>2-</sup>]，K<sub>2</sub> = [Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>] / [HCrO<sub>4</sub><sup>-</sup>]<sup>2</sup> C = [CrO<sub>4</sub><sup>2-</sup>] + [HCrO<sub>4</sub><sup>-</sup>] + 2[Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>] = [HCrO<sub>4</sub><sup>-</sup>] / K<sub>1</sub>[H<sup>+</sup>] + [HCrO<sub>4</sub><sup>-</sup>] + 2K<sub>2</sub>[HCrO<sub>4</sub><sup>-</sup>]<sup>2</sup> pH = 12：[HCrO<sub>4</sub><sup>-</sup>] = 6.5 × 10<sup>-8</sup> mol·L<sup>-1</sup>，[Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>] = 2.11 × 10<sup>-13</sup> mol·L<sup>-1</sup>，[CrO<sub>4</sub><sup>2-</sup>] = 0.05 mol·L<sup>-1</sup>，主要存在形态为 CrO<sub>4</sub><sup>2-</sup>（3 分）pH = 2：[HCrO<sub>4</sub><sup>-</sup>] = 0.018 mol·L<sup>-1</sup>，[Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>] = 0.0162 mol·L<sup>-1</sup>，[CrO<sub>4</sub><sup>2-</sup>] = 1.4 × 10<sup>-6</sup> mol·L<sup>-1</sup>，主要存在形态为 HCrO<sub>4</sub><sup>-</sup>和 Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>共存（3 分）

**5-2**（共 8 分）不妨设 pH = 7，此时[HS<sup>-</sup>] / [H<sub>2</sub>S] = K<sub>a1</sub> / [H<sup>+</sup>] = 1.29，因此，3)中忽略了 H<sub>2</sub>S 显然是不合理的（2 分）；同时，由于体系 pH 应在 7 附近，水自身的电离也应该纳入考虑。K = [Zn<sup>2+</sup>][HS<sup>-</sup>][OH<sup>-</sup>] = [Zn<sup>2+</sup>]<sup>2</sup> K<sub>a1</sub>K<sub>w</sub>/([H<sup>+</sup>]<sup>2</sup> + K<sub>a1</sub>[H<sup>+</sup>]) = K<sub>sp</sub>K<sub>w</sub> / K<sub>a2</sub> [Zn<sup>2+</sup>] = {K<sub>sp</sub>([H<sup>+</sup>]<sup>2</sup> + K<sub>a1</sub>[H<sup>+</sup>]) / K<sub>a1</sub>K<sub>a2</sub>}<sup>1/2</sup>（2 分）CBE：[H<sup>+</sup>] + 2[Zn<sup>2+</sup>] = [OH<sup>-</sup>] + [HS<sup>-</sup>] {K<sub>sp</sub>([H<sup>+</sup>]<sup>2</sup> + K<sub>a1</sub>[H<sup>+</sup>]) / K<sub>a1</sub>K<sub>a2</sub>}<sup>1/2</sup>(2 – K<sub>a1</sub>/([H<sup>+</sup>] + K<sub>a1</sub>) +[H<sup>+</sup>] – K<sub>w</sub> / [H<sup>+</sup>] = 0解得[H<sup>+</sup>] = 6.7 × 10<sup>-8</sup> mol·L<sup>-1</sup>，pH = 7.17（2 分）[Zn<sup>2+</sup>] = {K<sub>sp</sub>([H<sup>+</sup>]<sup>2</sup> + K<sub>a1</sub>[H<sup>+</sup>]) / K<sub>a1</sub>K<sub>a2</sub>}<sup>1/2</sup> = 8.1 × 10<sup>-8</sup> mol·L<sup>-1</sup>（2 分）判断错误部分占 2 分，需要正确判断并给出合理的理由才可得分；计算部分占 6 分。

**5-3**（共 8 分）离子方程式：3Cu<sub>2</sub>S + 4NO<sub>3</sub><sup>-</sup> + 16H<sup>+</sup> = 6Cu<sup>2+</sup> + 3S + 4NO + 8H<sub>2</sub>O（2 分）可以将其拆分成两个部分进行计算：① 3S<sup>2-</sup> + 2NO<sub>3</sub><sup>-</sup> + 8H<sup>+</sup> = 3S + 2NO + 4H<sub>2</sub>O E<sub>1</sub> = φ°(NO<sub>3</sub><sup>-</sup>/NO) – φ°(S/S<sup>2-</sup>) = 1.418 V（2 分）

K<sub>1</sub> = exp(zE<sub>1</sub>F / RT)② 6Cu<sup>+</sup> + 2NO<sub>3</sub><sup>-</sup> + 8H<sup>+</sup> = 6Cu<sup>2+</sup> + 2NO + 4H<sub>2</sub>Oφ°(Cu<sup>2+</sup>/Cu<sup>+</sup>) = 2φ°(Cu<sup>2+</sup>/Cu) – φ°(Cu<sup>+</sup>/Cu) = 0.163 V E<sub>2</sub> = φ°(NO<sub>3</sub><sup>-</sup>/NO) – φ°(Cu<sup>2+</sup>/Cu<sup>+</sup>) = 0.779 V（2 分）K<sub>2</sub> = exp(zE<sub>2</sub>F / RT) K = K<sub>1</sub>K<sub>2</sub>K<sub>sp</sub><sup>3</sup> = 10<sup>80.02</sup> = 1.1 × 10<sup>80</sup>（2 分）
