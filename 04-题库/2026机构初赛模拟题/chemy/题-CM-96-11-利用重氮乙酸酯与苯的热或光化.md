# 题-CM-96-11-利用重氮乙酸酯与苯的热或光化

## 题目

### 第 11 题（7 分）

利用重氮乙酸酯与苯的热或光化学反应，可得到各种异构环庚三烯的混合物，这一反应被称为 Buchner 扩环反应。这是一种已知上百年的反应。

11-1 画出中间体 A、B 的结构简式，并画出环庚三烯衍生物 C 的任意一种结构。

![](images/81bac1dd41df3294bbb39f03387bd773086fd00d731531a16116cb85ef36f213.jpg)

11-2 随着金属催化剂的出现，产品混合物的复杂性被降低或消除，20世纪80年代早期出现的 $Rh_{2}(OAc)_{4}$ 及其类似物均成为了该反应的首选催化剂。在 $Rh_{2}(OAc)_{4}$ 催化下，重氮丙二酸二甲酯在苯溶液中回流，除得到与上述反应类似的产物外，还得到了产物 D 和 E:

$$
\text {   } + \text {   } \mathrm{N} _{2} \xrightarrow [ \text {   CO } _{2} \mathrm{Me} ]{\text {   CO } _{2} \mathrm{Me}} \xrightarrow [ \text {   reflux   } ]{\text {   Rh } _{2} (\mathrm{OAc}) _{4}} \text {   D   } + \text {   E   }
$$

D 的化学式为 $C_{11}H_{12}O_{4}$ ，其 ${}^{1}H-NMR$ 谱为：δ 7.37 (m, 5H), 4.65 (s, 1H), 3.75 (s, 6H);

E 的化学式为 $C_{16}H_{18}O_{8}$ ，其 ${}^{1}H-NMR$ 谱为：δ 5.71 (m, 2H), 3.75 (s, 6H), 3.74 (s, 6H), 2.50 (d, 2H), 2.02 (dd, 2H);

画出 D 和 E 的结构简式，注意立体化学。
