# 题-CM-72-02-2-1生理盐水是指的氯化钠水

## 题目

### 第 2 题（8 分）

2-1 生理盐水是指 $0.9 \%$ 的氯化钠水溶液，请计算体温 $( 37^{ \circ } \mathrm { C } )$ 下生理盐水与纯水的渗透压相差多少。

2-2 在 $298 \mathrm { K }$ 下， 碳酸的 $K _{ \mathrm { a , 1 } } = 4.5 \times 10^{ - 7 }$ ， 空气中二氧化碳的体积分数为 $0.030 \%$ ， 被空气中二氧化碳饱和了的水的 $\mathrm { pH } = 5.6$ 。

2-2-1 根据亨利定律 $p ( \mathrm { CO } _{ 2 } ) = k _{ x } ( \mathrm { CO } _{ 2 } ) x ( \mathrm { CO } _{ 2 } )$ ， 计算二氧化碳的亨利常数 $k _{ x } ( \mathrm { CO } _{ 2 } )$ 。

2-2-2 为什么碳酸的电离常数 $K _{ \mathrm { a , 1 } }$ 比乙酸 $( K _{ \mathrm { a } } = 1.80 \times 10^{ - 5 } )$ 小？

## 参考答案

第2题（8分）

2-1  $c = 1000 \times 0.9 \times 2 / 58.5 = 0.308 \, (\text{mol/L})$  （1 分）
 $\pi = cRT = 0.308 \times 8.314 \times 310.15 = 7.9 \times 10^{2} \, (\text{kPa})$  （1 分）
纯水渗透压可认为为零，故相差  $7.9 \times 10^{2} \, kPa$ 。
不要求有效数字。

2-2-1 $p(\mathrm{CO}_{2}) = p_{0}x = 101.3 \, \mathrm{kPa} \times 0.030\% = 3.0 \times 10^{-2} \, \mathrm{kPa}$ (1 分)

碳酸饱和溶液中，可认为 $[\mathrm{HCO}_{3}^{-}] = [\mathrm{H}^{+}]$，则有：

$[CO_{2}] = [HCO_{3}^{-}][H^{+}] / K_{a,1} = 1.4 \times 10^{-5} \, \mathrm{mol/L}$ (1 分)

$x(\mathrm{CO}_{2}) = 1.41 \times 10^{-5} / (1.41 \times 10^{-5} + 1000 / 18) = 2.5 \times 10^{-7}$ (1 分)

$k_{x}(\mathrm{CO}_{2}) = p(\mathrm{CO}_{2}) / x(\mathrm{CO}_{2}) = 1 \times 10^{5} \, \mathrm{kPa}$ (1 分)

保留两位有效数字也可。

## 2-2-2 答出碳酸的电离常数中 $\left[\mathrm{H}_{2} \mathrm{CO}_{3}\right]$ 是以 $\mathrm{CO}_{2}$ 和 $\mathrm{H}_{2} \mathrm{CO}_{3}$ 的总浓度计算即可。（2分）
