# 题-CM-202-03-BiI3是一种棕黑色晶体可用作分

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-11-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（32 分，占 16%）

BiI<sub>3</sub>是一种棕黑色晶体，可用作分析试剂。

**3-1** BiI<sub>3 </sub>的晶体结构可视作碘做六方最密堆积，铋填入单层内 2/3 的八面体空隙，填一层空一层。晶体为 R 心六方点阵，a=b=7.498 Å，c=20.676 Å，γ=120°。

**3-1-1** 晶体学数据表明，以 Bi 为顶点，晶胞中(1/3,1/3,0.0880)处存在一个 I。据此，求出晶胞中所有的 I-Bi-I 键角。

**3-1-2** 某同学认为，上述[BiI<sub>6</sub>]中 Bi 的立体构型可以利用 VSEPR 模型判断。根据这一说法，预测 BiI<sub>3</sub>晶体中 Bi 的 VSEPR 空间构型。

**3-1-3** 很明显，VSEPR 模型的预测与实际并不相符。尝试提出一个合理的解释。

**3-2** BiI<sub>3</sub>可以与 DMF 和 DMSO 等有机溶剂形成复合物。将 0.5g Bil<sub>3</sub>置于小瓶中，向其中逐滴滴加 DMF 直至形成饱和溶液。将溶剂蒸发后，得到复合物晶体 A；将 DMF 换为 DMSO，则可以得到复合物晶体 B；A 和 B 分别含 Bi 26.64%和 28.02%。B 可以用于制备 BiI<sub>3</sub>薄膜。

**3-2-1** 推出 A 和 B 的最简式。

**3-2-2** 事实上，A 和 B 均为 1：1 型离子化合物，且 DMF 和 DMSO 均全部参与配位。A 和B 的阳离子极为相似，其中 Bi 的配位多面体在不考虑畸变的理想情况下均属于 D<sub>4d</sub>点群；阴离子中 Bi 均为（畸变的）八面体配位。给出 A 和 B 中阳离子的配位多面体的名称和示意图，及 A 和 B 中阴离子的结构。

**3-3** 利用电沉积法可以制备高纯 BiI<sub>3</sub>薄膜。以石墨电极为阴极，316 不锈钢电极为阳极（惰性电极），AgCl 电极为参比电极，在 pH=0.2 下电解含 15mM I<sub>2</sub>，2mM Bi<sup>3+</sup>，50mM NO<sub>3</sub><sup>-</sup>的30%乙二醇-水混合溶液，可以在某一电极 X 上沉积出 BiI<sub>3</sub>薄膜。

**3-3-1** 判断“某一电极 X”是阳极还是阴极，并写出该电极的电极反应方程式。

**3-3-2** 近似认为体系中各电对电极电势与水溶液中相同，电极 X 超电势为 401 mV，另一电极的电极电势为 φ’，给出能够使 BiI<sub>3</sub>开始析出的最小外加电压 E 的表达式（仅含 φ’为未知数）。需要用到的热力学数据如下：K<sub>sp</sub>(BiI<sub>3</sub>)=7.71×10<sup>-19</sup> φ<sup>Θ</sup>(I<sub>2</sub>/I<sup>-</sup>)=0.5355 V

**3-3-3** 在 pH=2 下，Bi<sup>3+</sup>发生水解，得到具有高对称性的 Bi<sub>6</sub>(OH)<sub>12</sub><sup>6+</sup>，给出其结构。此时进行电解反应则会得到另一种含 I 的薄膜材料 C，C 为三元化合物。请给出生成 C 的电极反应方程式。

**3-3-4** 研究人员测得 BiI<sub>3</sub>和 C 的带隙分别为 1.72 eV 和 1.98 eV，通过计算判断这两种薄膜是否可用于吸收可见光的光伏或光催化？
