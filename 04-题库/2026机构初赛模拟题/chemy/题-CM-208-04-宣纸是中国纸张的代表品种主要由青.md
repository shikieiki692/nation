# 题-CM-208-04-宣纸是中国纸张的代表品种主要由青

## 题目

### 第 4 题（24 分，占 12%）

宣纸是中国纸张的代表品种，主要由青檀树皮纤维和沙田稻草纤维混合制备而成，被广泛用于传统书画创作及书画装裱修裱，素有“纸寿千年”的美誉，是世界文化遗产中的瑰宝。然而，这也使人们不禁要问：宣纸是否真的能拥有一千年的寿命呢？

**4-1** 纸张的主要成分是由 β-1,4-葡萄糖苷键连接而成的纤维素，画出纤维素的结构。

**4-2** 纸张的力学性能与纸张中纤维素的平均聚合度 DP 密切相关，一般认为，当 DP 降至 200 ~ 300 时，纸张就几乎完全失去了力学性能。据此，可以推导出计算纸张纤维素降解速率的方法，得到 DP 与降解时间 t 的关系式。

**4-2-1** 记 N 为单体总数(包含已聚合和未聚合的单体)，x 为糖苷键总数，直接写出 x 关于 N与 DP 的表达式。

**4-2-2** 近似认为所有键等同，降解反应(其速率表示为–dx/dt)对糖苷键的级数为 1。结合合理近似，证明降解后的聚合度 DP<sub>t</sub>、初始聚合度 DP<sub>0</sub>、降解速率常数 k、降解时间 t 之间满足以下关系式（提示：当 n 非常小时，ln(1 + n) ≈ n）：

![](images/aa2bd4643e4b8daea7895550d28ed70e480ce8ab540253b44442e9c7c2951a58.jpg)

**4-3** 理论上，在得到 4-2-2 的关系式后，只要通过实验测定 DP<sub>0</sub>与给定时间后的 DP<sub>t</sub>便可以推得纸张寿命。使用粘度法测定 DP 时，需要选择合适的溶剂。

**4-3-1** 指出哪一种分子间相互作用力主要导致了纤维素一般情况下不易溶于普通溶剂。

**4-3-2** 文献指出，用铜乙二胺溶液可以溶解纤维素。说明原因。

**4-4** 研究表明，纸张的降解反应满足 Arrhenius 公式。通过升高温度可提升纸张降解反应速

**4-5** 植物纤维的主要成分是纤维素，但其中还有一定量木质素的存在，木质素很可能会影响宣纸溶液的粘度，使用粘度法测定纤维素的 DP 时，需排除木质素的干扰。将木质素含量不

ln k 对 1/T 线性回归，得到

ln k = –1.011×10<sup>4</sup> 1/T + 15.63（1 分）

故 20 °C 下，特净皮宣纸 k = 6.446×10<sup>-9</sup> d<sup>-1</sup>（1 分）<sup> </sup>

特净皮宣纸寿命为：

(1/300 – 1/1530) / (6.446 × 10<sup>-9</sup>) = 4.157×10<sup>6</sup> d ≈ 1139 a（1 分）

对特净皮宣纸，常温下“纸寿千年”属实。（1 分）

**4-5**（共 6 分）

该纤维素 DP = (0.75 × 561.1)<sup>1/0.905</sup> = 793.5（2 分）

相对误差达到-1.5%时，DP = 793.5 × (1 – 0.015) = 781.6（1 分）

对应的[η] = 781.6<sup>0.905</sup>/0.75 = 553.5 mL/g（1 分）

观察数据，可以猜测[η]与木质素含量呈线性关系。

[η](mL/g)对木质素含量(%)线性回归，得

[η](mL/g) = -1.037·木质素含量(%) + 561.0

r = -0.9997 线性关系良好，猜测合理。

代入线性回归得到的关系式，得木质素含量(%)为(553.5 – 561.0) / (–1.037) = 7.3

即木质素含量为 7.3%（2 分）

采取其他合理方法，估测出木质素含量在 7.1% ~ 7.5%之间的，均可得分。
