# 题-CM-235-08-复杂桥环化合物的构筑是许多有机合

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-13-8`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 8 题（25 分，占 14.0%）

复杂桥环化合物的构筑是许多有机合成工作者致力研究的一个难题。相比于逐步连接环系，

利用串联反应一步构建多环具有更高的原子经济性。2022 年，中国化学家想利用以下反应

一步合成出桥环化合物 1，却发现没有得到目标产物，而是得到了化合物 A。

![](images/ec316e1cc54a992a4ba5415eedd47cfb06cc2d0b2750a72bed03603517ff0774.jpg)

**8-1** 研究人员认为 A 是由 1 通过一步周环反应脱去一个小分子得到的，A 的核磁氢谱数据

如下：<sup>1</sup>H NMR (500 MHz, CDCl<sub>3</sub>) δ 9.00 (s, 1H), 7.68 (d, J = 8.0 Hz, 2H), 7.31 (d, J = 7.9 Hz,

3H), 7.23 (d, J = 6.5 Hz, 2H), 7.16 (d, J = 7.9 Hz, 1H), 3.71 (t, J = 8.4 Hz, 2H), 3.60 (s, 2H), 2.52

(t, J = 8.4 Hz, 2H), 2.42 (s, 3H). 画出 A 的结构，写出小分子的化学式与这步周环反应的名称。

**8-2** 经研究发现 1 是通过如下机理生成的：底物首先在加热条件下转化为中间体 B，B 含有

六并五环系与电荷分离的结构，随后 B 发生两步周环反应即得到 1。画出 B 的结构，依次

写出两步周环反应的名称。

**8-3** 通过进一步修改底物结构，研究人员成功合成出了与 1 含有相同骨架的 C。

![](images/a371911110a63f2ccbd828b6814623a5ab511650c57b616d9e0eb43ed2d37476.jpg)

**8-3-1** 画出 C 的结构。

**8-3-2** 比较 1 与 C 在环大小上的差别，解释为什么 1 会脱去小分子转化为 A 而 C 能够稳定

存在。

**8-4** C 可以发生如下转化：

![](images/147f424d2a3350af92e445cfc20d9c1e1dc39a7186fd13cda3773267ab93bd1b.jpg)

**8-4-1** D 含有六螺五环系，画出 D 的结构。

**8-4-2** 画出 D 在酸作用下转化为 E 的所有关键中间体。

## 参考答案

**8-1** 5 分，结构 3 分，小分子与反应名称各 1 分。

![](images/5bcfd1d9b7b6266407f696029449ec405425920d32d2f9dc9472c49e21b4fa17.jpg)

小分子：CO（1 分） 周环反应：逆[4 + 1]反应（1 分）

**8-2** 7 分，结构 3 分，周环反应名称各 2 分（顺序错误不得分）。

![](images/e31159d0640aa8efc3ca6318d8f7f1d1b52b5f600b6048e6e7b193a31fe5c2c7.jpg)

**8-3-1** 3 分

![](images/907cab0b388fefbeea3bff56db2b2a31676f5615c653e9cf502a245ae062f5f3.jpg)

**8-3-2** 1 的环更小，桥环张力更大（1 分），脱羰能够缓解环张力（1 分），因此容易转化为 A；

而 C 环较大，桥环张力小，此时脱羰在能量上不利（1 分），因此 C 能够稳定存在。

**8-4-1** 3 分

![](images/c31ee4e402d5952670dfd8ca78af71265643eecbebf74e1e22eacd54121c02f7.jpg)

**8-4-2** 4 分，各 2 分。第二个中间体画为以下蓝色中间体也得分。

![](images/27214ccff43a367f7233b05005f258ba6a1650cdb265e92fc150d72e82806b9a.jpg)![](images/a60f06823d0e6fa14bb5a7f64563ed15dfbd91da7e1f4ba2ccab0c300426f38b.jpg)
