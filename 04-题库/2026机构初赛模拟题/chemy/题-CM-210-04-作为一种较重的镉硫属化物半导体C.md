# 题-CM-210-04-作为一种较重的镉硫属化物半导体C

## 题目

### 第 4 题（16 分，占 None%）

作为一种较重的镉硫属化物半导体，CdTe 具有较小的带隙和优异的光电性能，在薄膜太阳能电池、红外探测器、生物成像、光催化等领域有着广泛的应用。2025 年，研究人员实现了一种原子级精度 CdTe 纳米团簇的简易合成，并对其性质进行了探索。

**4-1** 在甲醇中混合Cd(OAc)<sub>2</sub>·2H<sub>2</sub>O、TBBT-H(4-叔丁基苯硫酚，在本题中用R-SH表示)与NEt<sub>3</sub>，常温下反应 30 min 后得到白色沉淀[HNEt<sub>3</sub>][Cd<sub>4</sub>(SR)<sub>9</sub>]，其阴离子为无限长链结构，可认为由[Cd<sub>4</sub>(SR)<sub>10</sub>]<sup>2-</sup>共用配体连接形成。在理想情况下，[Cd<sub>4</sub>(SR)<sub>10</sub>]<sup>2-</sup>中 Cd 与 S 形成一种高对称性结构，可视作一种常见晶体的结构片段。

**4-1-1** 指出在理想情况下[Cd<sub>4</sub>(SR)<sub>10</sub>]<sup>2-</sup>中 Cd 与 S 形成的结构的所有对称元素，并从以下选项中选出该结构可被视作哪种常见晶体的结构片段：( )。(a) 萤石； (b) 闪锌矿； (c) 纤锌矿； (d) 岩盐； (e) 金红石； (f) 氯化铯。

**4-1-2** 画出[HNEt<sub>3</sub>][Cd<sub>4</sub>(SR)<sub>9</sub>]中阴离子的结构。

**4-2** 将一定量的[HNEt<sub>3</sub>][Cd<sub>4</sub>(SR)<sub>9</sub>]、TePBu<sub>3</sub>、PPh<sub>3</sub>在十八烯中混合，在 150 °C 下反应 10 min后，反应混合物的紫外-可见光谱在377 nm处出现了尖锐的吸收峰，表明形成了一种团簇A。A 的结构通过单晶 X 射线衍射得到，可用以下方式描述：团簇的核心为 Cd<sub>4</sub>Te<sub>10</sub>，其结构与[Cd<sub>4</sub>(SR)<sub>10</sub>]<sup>2-</sup>中 Cd 与 S 形成的结构相同；在团簇核心的周围，四个 Cd<sub>6</sub>Te(SR)<sub>9 </sub>片层与团簇

![](images/e4939be336bd1104afcba0f614c3631bc828bef6e7b3360fe4dcc2e4f19c9c1a.jpg)

和胶体纳米晶体之间的过渡阶段。4-2 中采用了配合物的角度描述 A 的结构，我们也可以采用晶体的角度描述该团簇。

**4-3-1** 以团簇的其中一根 C<sub>3</sub>轴为堆积的方向，忽略不处在该 C<sub>3</sub>轴上的 Cd-PPh<sub>3</sub>结构片段，只观察团簇中的其他原子。将 P、Te、S 视为堆积原子，用 A、B、C 表示；将 Cd 视为填隙原子，用 a、b、c 表示。给出团簇 A 中原子的堆积方式。

**4-3-2** 从堆积方式可以看出，团簇的结构可以看作由两种常见晶体结构组合而成，从以下选项中选出这两种常见晶体：( )。(a) 萤石； (b) 闪锌矿； (c) 纤锌矿； (d) 岩盐； (e) 金红石； (f) 氯化铯。

**4-4** 团簇 A 的单晶属于正交晶系，其晶胞与立方晶胞非常相似(a = 31.7718 Å, b = 31.7987 Å, c = 31.8026 Å, α = β = γ = 90°)，其中团簇 A 的堆积方式为体心立方密堆积。但即使将团簇单晶近似视为立方晶胞，其点阵类型也并非体心立方，而是简单立方。仔细思考团簇 A 的结构特征，解释其原因。
