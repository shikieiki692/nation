# 题-CM-244-07-通过如下反应可以制备含Si的特殊

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-9-7`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 7 题（11 分）

通过如下反应可以制备含 Si 的特殊配合物。向 Na[Tp’Mo(CO)<sub>2</sub>(PMe<sub>3</sub>)] (记为 A)的氟苯溶液中加入 0.5 当量的 SiBr<sub>2</sub>(Sldipp)<sub>2</sub> (记为 B)反应得到了 C；向 C 的氯苯溶液中通入 2-丁炔并油浴加热，观察到溶液颜色从棕红色变为橙色，这是由于它们发生了摩尔比为 1 : 1 的加成反应，从而得到了目标配合物 D。本题涉及的配体的简写如下所示：

![](images/32449b693a900a0b1af6884c481cee990f61b3e278feef1680d3beef3f1ec8e1.jpg)![](images/d0abe533993c5c846fb61daed3f55727e6d54fdbf3da2a9ea258f18c5d38f5be.jpg)

**7-1-1** 元素分析实验表明，C 中元素质量分数为 C 44.33%，H 5.33%，N 16.77%，D 中含 N 17.10%，且不含 P 元素。C 和 D 的元素分析结果与理论值符合得都很好。通过计算推出 C和 D 的化学式(要求：给出简写符号的配体必须用简写符号表示)。

**7-1-2** 对 C 和 D 的结构分析表明，C 和 D 中 Mo 原子均满足 EAN 规则；D 分子的理想点群为 C<sub>2v</sub>，原先丁炔中的三键键长变为 136.8pm，接近 C=C 双键的键长，且所有 Mo 原子均为7 配位。画出 C 和 D 的结构(提示：可以适当简化配体，但必须注明，下同)。

**7-2** 化合物 C 在二甘醇二甲醚中用 2 当量的 KC<sub>8 </sub>还原得到了 E。E 中阴离子的理想点群为C<sub>2h</sub>，阴离子中各元素质量分数为 C 44.08%，H 4.79%，N 18.15%。画出 E 中阴离子的结构，并通过计算说明其中的 Mo 是否符合 EAN 规则。

## 参考答案

**7-1-1**（共 4 分，过程 2 分，化学式各 1 分）

先考虑 A 与 B 2:1 反应得到 Si(Sldipp)<sub>2</sub>[MoTp’(CO)<sub>2</sub>(PMe<sub>3</sub>)]<sub>2</sub>，此时分子中有 16 个 N。

C 中 n(C) : n(N) = (44.33% / 12.01) : (16.77% / 14.01) = 3.083，若 C 中有 16 个 N，则 C 的

个数偏离整数较多，因此考虑某些含 N 配体解离了，最有可能是 Sldipp 配体发生解离。

分别假设 Sldipp 解离 1 或 2 个，代入发现，当解离 2 个 Sldipp，即 N 为 12 个时，C 的个

数恰为整数 37，除去 Tp’的 C 仍剩余 7 个 C，只有可能对应(CO)<sub>4</sub>(PMe<sub>3</sub>)或(CO)(PMe<sub>3</sub>)<sub>2</sub>。

![](images/2dce9c189c210b3b890b25a02f9efc9cbc6ba6596d896518d51b7b3f53df02d1.jpg)

(CO)<sub>4</sub>(PMe<sub>3</sub>)，因此 C 的化学式为 SiMo<sub>2</sub>Tp’<sub>2</sub>(CO)<sub>4</sub>(PMe<sub>3</sub>)。

由题意知 D 中膦配体已经解离，先假设 D 的化学式为 SiMo<sub>2</sub>Tp’<sub>2</sub>(CO)<sub>4</sub>(C<sub>4</sub>H<sub>6</sub>)，则 D 中有

![](images/c43b6ad22e62f2dfa01de6f2fde7c20edd59f3c9873a0054fbe7a505886e91d5.jpg)

SiMo<sub>2</sub>Tp’<sub>2</sub>(CO)<sub>4</sub>(C<sub>4</sub>H<sub>6</sub>)
