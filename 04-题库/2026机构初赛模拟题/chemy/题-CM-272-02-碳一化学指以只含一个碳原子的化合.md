# 题-CM-272-02-碳一化学指以只含一个碳原子的化合

## 题目

### 第 2 题（11 分）

碳一化学指以只含一个碳原子的化合物(如 CO、CH<sub>4 </sub>等)为原料来合成一系列化工原料和燃料的化学。其中甲烷是碳一化学中的重要组成部分，甲醇则作为碳一化学的核心产品。用甲烷生产甲醇有蒸汽转化、催化部分氧化、非催化部分氧化等方法。其中蒸汽转化法包括以下四个反应：

（1）CH<sub>4</sub>(g) + H<sub>2</sub>O(g) = CO(g) + 3H<sub>2</sub>(g)

（2）CO(g) + H<sub>2</sub>O(g) = CO<sub>2</sub>(g) + H<sub>2</sub>(g)

（3）CO(g) + 2H<sub>2</sub>(g) = CH<sub>3</sub>OH(g)

（4）CO<sub>2</sub>(g) + 3H<sub>2</sub>(g) = CH<sub>3</sub>OH(g) + H<sub>2</sub>O(g)

**2-4** 列举三条可以提高反应(1)中甲烷转化率的措施，这些措施对甲醇的产量分别有怎样的影响？(至少有一条措施有利)

## 参考答案

**2-4** 降低压力，对甲醇的产量无影响

提高温度，对甲醇的产量不利

提高水碳比(H<sub>2</sub>O/CH<sub>4</sub>)，对甲醇的产量有利(增加反应物浓度)

加入 CO<sub>2</sub>，对甲醇的产量有利(利用多余的 1 mol H<sub>2</sub>)（任意答出三点即可得 3 分，每点 1
