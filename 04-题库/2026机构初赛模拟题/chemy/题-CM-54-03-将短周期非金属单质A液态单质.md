# 题-CM-54-03-将短周期非金属单质A液态单质

## 题目

### 第 3 题（11 分）

将短周期非金属单质 A，液态单质 B 和氟化钾混合，在 $-86^{\circ}C$ 直接反应，得到一种二元化合物 C(108.1 g/mol)，C 常温下为无色腐蚀性气体。C 能与 $NH_{3}$ 反应，得到三原子无色气体 D。D 被 $AgF_{2}$ 氧化生成一种沸点为 300 K 的无色化合物 E，E 具有 $C_{3}$ 轴。E 能与 ClF 反应，其产物与反应物比例有关：在 $-78^{\circ}C$ 下，若将 E 与少量 ClF 混合反应，则得到化合物 F，F 是加成产物的二聚体，具有 1 个镜面和垂直于这一镜面的 $C_{2}$ 轴；若将 E 与过量 ClF 混合反应，则主产物为加成产物 G，同时检测到副产物 $N_{2}$ 生成。

3-1 写出 A\~G 的化学式。

3-2 写出由 E 与 ClF 反应生成副产物的化学反应方程式。

3-3 画出 F 二聚体的结构示意图。

## 参考答案

第 3 题（11 分）

3-1 写出 $\mathsf { \pmb { A } } { \sim } \mathsf { \pmb { G } }$ 的化学式。

3-1 A S B $\cdot$ C $\cdot$ D NSF E ${ \mathrm { NSF } } _{ 3 }$ F $( \mathrm { ClNSF } _{ 4 } ) _{ 2 }$ $\mathsf { \Omega } \mathsf { G } \mathrm { F } _{ 5 } \mathrm { SNCl } _{ 2 }$ （每个1 分）

$-$ （2 分）写成 $\cdot$ 配平也可得分， 但产物写 $\cdot$ 不得分。
