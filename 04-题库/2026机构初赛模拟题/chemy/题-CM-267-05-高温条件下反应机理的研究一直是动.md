# 题-CM-267-05-高温条件下反应机理的研究一直是动

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy33-18-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题

高温条件下反应机理的研究一直是动力学的基本课题，1956 年诺贝尔化学奖获得者在该领域作出杰出的贡献。科研人员研究了高温下乙烷的热分解反应并提出如下反应历程：

C<sub>2</sub>H<sub>6</sub> → 2CH<sub>3</sub>· k<sub>1 </sub>E<sub>1</sub> = 351.5 kJ mol<sup>−1</sup>

CH<sub>3</sub>· + C<sub>2</sub>H<sub>6</sub> → CH<sub>4</sub> + C<sub>2</sub>H<sub>5</sub>· k<sub>2 </sub>E<sub>2</sub> = 33.5 kJ mol<sup>−1</sup>

C<sub>2</sub>H<sub>5</sub>· → C<sub>2</sub>H<sub>4</sub> + H· k<sub>3 </sub>E<sub>3</sub> = 167 kJ mol<sup>−1</sup>

H· + C<sub>2</sub>H<sub>6</sub> → H<sub>2</sub> + C<sub>2</sub>H<sub>5</sub>· k<sub>4 </sub>E<sub>4</sub> = 29.3 kJ mol<sup>−1</sup>

H· + C<sub>2</sub>H<sub>5</sub>· → C<sub>2</sub>H<sub>6</sub> k<sub>5 </sub>E<sub>5</sub> = 0 kJ mol<sup>−1</sup>

**5-1** 以上反应历程是根据两个平行反应提出的，分别写出反应方程式。

**5-2** 已知反应对 C<sub>2</sub>H<sub>6</sub>近似为一级反应，推导反应速率方程(以乙烷消耗的速率表示)。

**5-3** 根据 5-2 中的结果计算其表观活化能(要求写出公式推导)。

## 参考答案

**5-1** C<sub>2</sub>H<sub>6</sub> = C<sub>2</sub>H<sub>4</sub> + H<sub>2</sub>（1 分）

2 C<sub>2</sub>H<sub>6</sub> = 2 CH<sub>4</sub> + C<sub>2</sub>H<sub>4</sub>（1 分）<sub> </sub>

**5-2** 根据上述机理可知 r = k<sub>1</sub>[C<sub>2</sub>H<sub>6</sub>] + k<sub>2</sub>[CH<sub>3</sub>·][C<sub>2</sub>H<sub>6</sub>] + k<sub>4</sub>[C<sub>2</sub>H<sub>6</sub>][H·] – k<sub>5</sub>[H·][C<sub>2</sub>H<sub>5</sub>·] ···(1)

（0.5 分）

对各活泼不稳定自由基进行稳态近似处理

对 CH<sub>3</sub>·有 2k<sub>1</sub>[C<sub>2</sub>H<sub>6</sub>] − k<sub>2</sub>[CH<sub>3</sub>·][C<sub>2</sub>H<sub>6</sub>] = 0 ···(2)（0.5 分）

对 C<sub>2</sub>H<sub>5</sub>·有 k<sub>2</sub>[CH<sub>3</sub>·][C<sub>2</sub>H<sub>6</sub>] − k<sub>3</sub>[C<sub>2</sub>H<sub>5</sub>·] + k<sub>4</sub>[C<sub>2</sub>H<sub>6</sub>][H·] − k<sub>5</sub>[H·][C<sub>2</sub>H<sub>5</sub>·] = 0 ···(3)（0.5 分）

对 H·有 k<sub>3</sub>[C<sub>2</sub>H<sub>5</sub>·] − k<sub>4</sub>[C<sub>2</sub>H<sub>6</sub>][H·] − k<sub>5</sub>[H·][C<sub>2</sub>H<sub>5</sub>·] = 0 ···(4)（0.5 分）

由(2)可知[CH<sub>3</sub>·] = 2k<sub>1</sub>/k<sub>2</sub> ···(5) （0.5 分）

而由(2)+(3)+(4)可知[H·] = k<sub>1</sub>[C<sub>2</sub>H<sub>6</sub>]/k<sub>5</sub>[C<sub>2</sub>H<sub>5</sub>·] ···(6) （0.5 分）

将(6)代入(4)中可得[C<sub>2</sub>H<sub>5</sub>·]<sup>2</sup> – {k<sub>1</sub>[C<sub>2</sub>H<sub>6</sub>]/k<sub>3</sub>}[C<sub>2</sub>H<sub>5</sub>·] – k<sub>1</sub>k<sub>4</sub>[C<sub>2</sub>H<sub>6</sub>]<sup>2</sup>/k<sub>3</sub>k<sub>5</sub> = 0（0.5 分）

![](images/e9ee817785aacff219bc17d661544dd2f9416b5aef754bd731b91ebd85917030.jpg)

由于 k<sub>1</sub>较小，且负值不合理，则可知[C<sub>2</sub>H<sub>5</sub>·] = (k<sub>1</sub>k<sub>4</sub>/k<sub>3</sub>k<sub>5</sub>)<sup>0.5</sup>[C<sub>2</sub>H<sub>6</sub>] ···(7)（0.5 分）

将(7)代入(6)可知[H·] = (k<sub>1</sub>k<sub>3</sub>/k<sub>4</sub>k<sub>5</sub>)<sup>0.5</sup> ···(8)（0.5 分）

将(5)(7)(8)代入(1)可知 r = [2k<sub>1</sub> + (k<sub>1</sub>k<sub>3</sub>k<sub>4</sub>/k<sub>5</sub>)]<sup>0.5</sup>[C<sub>2</sub>H<sub>6</sub>]（1 分）

由于 k<sub>1</sub>相较而言较小，故简化得 r = (k<sub>1</sub>k<sub>3</sub>k<sub>4</sub>/k<sub>5</sub>)<sup>0.5</sup>[C<sub>2</sub>H<sub>6</sub>]（1 分）

**5-3** 由 Arrhenius 公式可知 k = Aexp(−E<sub>a</sub>/RT) = (A<sub>1</sub>A<sub>3</sub>A<sub>4</sub>/A<sub>5</sub>)<sup>0.5</sup>exp[−0.5(E<sub>1</sub>+E<sub>3</sub>+E<sub>4</sub>−E<sub>5</sub>)/RT]（1

分）

故有 E<sub>a</sub> = 0.5(E<sub>1</sub>+E<sub>3</sub>+E<sub>4</sub>−E<sub>5</sub>) = 274 kJ·mol<sup>−1</sup>（2 分）
