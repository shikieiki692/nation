# 题-CM-52-05-可采取如下方法测定某硅酸盐样

## 题目

### 第 5 题（8 分）

可采取如下方法测定某硅酸盐样品中钠元素的含量:称取纯铋4.0131 g,用10 mL硝酸溶解,煮沸并冷却后,稀释至1 L,配成硝酸铋溶液。将1.1012 g硅酸盐矿石样品溶于10 mL氢氟酸和5 mL硫酸,加热蒸发至冒白烟,冷却;加入50 mL水,并用氨水调节至弱酸性;加入pH=5的缓冲液、 $FeCl_{3}$ 溶液、 $NH_{4}HF_{2}$ 溶液和15 mL乙醇,使所有的钠均转化为 $\mathrm{Na(NH_{4})_{2}FeF_{6}}$ 沉淀。将沉淀过滤,用硝酸溶解,调溶液pH至1.5,加入50.00 mL EDTA溶液,以二甲酚橙为指示剂,用上述硝酸铋溶液滴定至终点。消耗硝酸铋溶液29.83 mL。在相同条件下使用上述硝酸铋溶液直接滴定50.00 mL上述EDTA溶液,消耗49.01 mL。

请计算样品中钠的含量(以 $\omega(\mathrm{Na}_{2}\mathrm{O})$ 计)。

## 参考答案

# 第 5 题（8 分）

耗硝酸铋溶液 $49.01 ~ \mathrm { mL }$ 。
c(EDTA) = 0.01920 × 49.01 / 50.00 mol·L-1 = 0.01882 mol·L-1 （3 分）
$\omega ( \mathrm { Na _{ 2 } O } ) = ( 0.01882 \times 50.00 - 0.01920 \times 29.83 ) \times 1 / 2 \times 61.98 + 1.1012 \times 100^{ 9 } \mathrm { { 0 } } = 1.049 \mathrm { { 0 } } \times 20^{ 8 } { \mathrm { { 0 } } }$ （3 分）列总反应式进行计算得到结果也可得分。 用 $\omega ( \mathrm { Na } )$ 表示， 扣1 分。
