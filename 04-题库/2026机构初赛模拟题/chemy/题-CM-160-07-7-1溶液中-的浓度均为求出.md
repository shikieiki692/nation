# 题-CM-160-07-7-1溶液中-的浓度均为求出

## 题目

### 第 7 题

第 7 题（12 分， 占 $12 \%$ ） 离子共存已知： $298 \mathrm { K }$ 下的酸性电位： $\varphi _{ F e ^{ 3 + } / F e ^{ 2 + } } ^{ 0 } = 0.771 \mathrm { V } ; \varphi _{ N O _{ 3 } ^{ - } / N O } ^{ 0 } = 0.80 \mathrm { V }$

7-1 溶液中 $\mathrm { Fe } ^{ 2 + }$ 、 $\mathrm { Fe } ^{ 3 + }$ 、 $\mathsf { NO } _{ 3 }$ -的浓度均为 $1.0 \mathrm { mol / L }$ ， 求出能发生氧化反应的最高 $\mathsf { pH }$ 值.小明同学认为， 如果在 7-1 的基础上升高 $\mathsf { pH }$ ， 可以让 $\mathrm { Fe } ^{ 3 + }$ 产生沉淀从而促进氧化反应的发生。已知 $K _{ s p } ( \mathrm { Fe ( OH ) } _{ 3 } ) { = } 4.0 { \times } 10^{ - 38 }$ 。
7-2 请计算在 $\mathsf { pH }$ 大于 7-1 的情况下， $\mathrm { Fe } ^{ 2 + }$ 可被 $\mathsf { NO } _{ 3 }$ -氧化的最低 $\mathsf { pH }$ 值。假定硝酸根与亚铁离子的浓度均为 $1.0 \mathrm { mol / L }$ 。
7-3 计算 $1.0 \ \mathrm { mol / L }$ 的 $\mathrm { Fe } ( \mathsf { NO } _{ 3 } ) _{ 2 }$ 溶液发生自氧化还原反应的终点。给出体系的 $\mathsf { pH }$ 值和亚铁离子的转化率。 说明为什么我们认为硝酸根与亚铁离子可以共存， 不计 $\mathrm { Fe ( II ) }$ 的酸效应。

## 参考答案

7-1 $NO_{3}^{-} + 4H^{+} + 3e^{-} = NO + 2H_{2}O$ 得到 $[H^{+}] = 0.4289 \, mol/L$ ，pH = 0.37（2 分）
7-2 $0.771 - \frac{RT}{F} \ln \frac{Kw^{3}}{K_{sp} \times [H^{+}]^{3}} \leq 0.80 - \frac{RT}{F} \ln \frac{1}{[H^{+}]^{4}}$ （1 分）

解得： $\left[H^{+}\right]=3.411\times10^{-3}\ mol/L,\ pH=2.47\ (2\ 分)$

7-3 先假定反应不额外产生新的氢离子： $9Fe^{2+} + 3NO_{3}^{-} + 6H_{2}O = 4Fe(OH)_{3} + 5Fe^{3+} + 3NO$ 假定最后 $Fe^{2+}$ 浓度为 $(1-3x)\ \text{mol/L}$ 则含有 $Fe^{3+}\ 5x/3\ mol/L$ ，在此基础上， $Fe^{3+}$ 进一步发生水解，假定产生氢离子浓度为 3y mol/L

$$
\frac {K w ^{3}}{K _{s p}} = \frac {27 y ^{3}}{\frac {5}{3} x - y} (2 \text {分})
0.771 - \frac {\mathrm{RT}}{\mathrm{F}} \ln \frac {1 - 3 \mathrm{x}}{\frac {5}{3} \mathrm{x} - \mathrm{y}} \leq 0.80 - \frac {\mathrm{RT}}{3 \mathrm{F}} \ln \frac {1}{(3 \mathrm{y}) ^{4} \times (2 - \mathrm{x})} (2 \text {分})
$$

解得 $y = 1.3 \times 10^{-3} \, mol/L$ ，pH = 2.40，消耗 $Fe^{2+}$ $6.6 \times 10^{-3} \, mol/L$ （2 分）

故反应进度极小，基本可共存（1 分）
