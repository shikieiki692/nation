# 题-CM-48-05-向含有少量酚酞指示剂的水溶液

## 题目

### 第 5 题 甲醛时钟（13 分，占 7%）

向含有少量酚酞指示剂的水溶液中加入亚硫酸钠 ( $\mathbf { \ Na } _{ 2 } \mathbf { SO } _{ 3 } )$ )、 亚硫酸氢钠 - $\mathrm{NaHSO_3^-}$ ) 和甲醛(HCHO)。 经过一段时间后， 溶液由无色突变为紫红色。 发生该颜色突变所需的时间由上述三种试剂的初始浓度决定， 因此， 该体系被称为 “甲醛时钟”。

注： 本题中温度为 $298.15 \mathrm { ~ K ~ }$ . 溶液充分混匀， 不考虑甲醛的水合反应。 解题时可采取的近似原则为： 如果 $x > 50 y$ . 则 $x + y$ 可近似为 $_ x$ 。

5-1 在中性水溶液中， 甲醛可以与亚硫酸氢根 (HSOj) 或亚硫酸根 ( $\mathrm{SO_3^{2-}}$ ） 发生反应， 生成一种酸性和碱性都很弱的一价负离子。 分别写出甲醛与亚硫酸氢根反应、 甲醛与亚硫酸根反应生成该一价负离子的离子方程式。

5-2 亚硫酸的第一级酸电离反应平衡常数 $K_a(\mathrm{H_2SO_3})=1.2\times10^{-2}\ \mathrm{mol\cdot dm^{-3}}$。为了计算亚硫酸的第二级酸电离反应平衡常数 $K_2(\mathrm{HSO_3^-})$，将 $1.0\times10^{-3}\ \mathrm{mol}\ \mathrm{NaHSO_3}$ 和 $1.0\times10^{-3}\ \mathrm{mol}\ \mathrm{Na_2SO_3}$ 溶于水并定容至 $1.0\ \mathrm{dm^3}$，测得该溶液 pH 值为 5.36。

5-2-1 列出上述溶液的物料平衡方程式 （亚硫酸的各形态） 与电荷平衡方程式。

5-2-2 计算上述溶液的亚硫酸根平衡浓度[SO门与亚硫酸氢根平衡浓度[HSO]。
5-2-3 计算 $K_2(\mathrm{HSO_3^-})$ e

5-3 甲醛与亚硫酸氢根反应的速率常数 $k(\mathrm{HSO_3^-})=4.5\times10^{-3}\ \mathrm{dm^3\cdot mol^{-1}\cdot s^{-1}}$，甲醛与亚硫酸根反应的速率常数 $k(\mathrm{SO_3^{2-}})=54\ \mathrm{dm^3\cdot mol^{-1}\cdot s^{-1}}$。酸碱电离和酸碱中和反应的速率很大，可认为是瞬时反应。某个甲醛时钟体系的各组分初始浓度分别为：甲醛 $0.10\ \mathrm{mol\cdot dm^{-3}}$、亚硫酸氢钠 $a=0.10\ \mathrm{mol\cdot dm^{-3}}$、亚硫酸钠 $c(\mathrm{Na_2SO_3})=0.010\ \mathrm{mol\cdot dm^{-3}}$。

5-3-1 该甲醛时钟初期阶段 （溶液 $\mathrm{pH} \leq 8.20$ ) 的甲醛消耗速率 $\nu ( { \mathrm { HCHO } } )$ 与甲醛平衡浓度[HCHO]近似成正比， 即经过合理近似后， $\nu ( { \mathrm { HCHO } } ) = a [ { \mathrm { HCHO } } ]$ . 其中 $a$ 为常量。 列出 $a$ 的计算式并算出 $a$ 的数值。

5-3-2 该甲醛时钟初期阶段的 $\mathrm{pH}$ 值随时间 $^{ \prime }$ 近似线性增加， 即经过合理近似后， $\mathrm{dpH}/\mathrm{d}t=b$ . 其中 $b$ 为常量。 列出 $b$ 的计算式并算出 $b$ 的数值。

微分公式 （其中 $m$ 为常数， $^ c \Theta$ 为标准浓度 $1.0 ~ \mathrm { mol } \cdot \mathrm { d } \mathrm { m } ^{ - 3 }$ ):

$$
\frac{\mathrm{d}\left(m[\mathrm{H^+}]\right)}{\mathrm{d}t}=\frac{m\,\mathrm{d}[\mathrm{H^+}]}{\mathrm{d}t}
$$

$$
\frac{\mathrm{d}\mathrm{pH}}{\mathrm{d}t}=\frac{\mathrm{d}\left[-\lg\left([\mathrm{H^+}]/c^\ominus\right)\right]}{\mathrm{d}t}=-\frac{1}{\ln 10\cdot[\mathrm{H^+}]}\frac{\mathrm{d}[\mathrm{H^+}]}{\mathrm{d}t}
$$

5-3-3 已知存在下列平衡 （其中 $\mathrm{A^-}$ 为甲醛与亚硫酸氢根或亚硫酸根的反应产物）：

$$
\begin{array}{r} \mathrm{A^-(aq)} \rightleftharpoons \mathrm{HCHO(aq)} + \mathrm{HSO_3^-(aq)} \end{array}
$$

该反应的经验平衡常数 $K(\mathrm{A^-})=1.2\times10^{-7}\ \mathrm{mol\cdot dm^{-3}}$。该甲醛时钟达到颜色突变点时，溶液计算此时的 [HCHO]。
