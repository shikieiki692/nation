# 题-CM-75-08-8-1将萘和硫酸混合加热至C

## 题目

### 第 8 题（14 分）

8-1 将萘和硫酸混合加热至 $60^{\circ}$ C 发生反应，以 96% 的产率得到单取代产物 A；若将体系加热至 $160^{\circ}$ C，则主产物为 B，其产率为 85%。

8-1-1 画出 A 和 B 的结构简式。

8-1-2 画出生成 A 的过程中形成的碳正离子含苯环的共振式。

8-1-3 解释在 $60^{\circ}$ C 时主产物为 A，而加热至 $160^{\circ}$ C 却大部分转化为 B 的原因。

8-2 在浓硫酸存在下，将苯酚与草酸混合并加热，产物为深红色化合物 $\mathbf{C}(\mathrm{C}_{19}\mathrm{H}_{14}\mathrm{O}_3)$ ；在冰水浴冷却下， $\mathbf{C}$ 与氟化氢反应，得到深绿色离子型化合物 $\mathbf{D}(\mathrm{C}_{19}\mathrm{H}_{15}\mathrm{O}_3\mathrm{F})$ 。画出 $\mathbf{C}$ 和 $\mathbf{D}$ 的结构简式。

8-3 化合物 $\mathsf{E}(\mathrm{C}_{6}\mathrm{H}_{2}\mathrm{ClN}_{3}\mathrm{O}_{6})$ 在室温下即可与水发生反应，产物 F 是一种烈性炸药。指出该反应的具体反应类型，并画出 E 的结构简式。F 具有较强的酸性 $(pK_{a}=0.3)$ ，解释原因。

8-4 以下反应得到的主产物为 $\mathbf{G}(\mathrm{C}_{12}\mathrm{H}_8\mathrm{N}_2\mathrm{O}_2)$ ，实验表明 $\mathbf{G}$ 存在分子内氢键。画出 $\mathbf{G}$ 的结构简式。

8-1-3生成A的中间体能画出更多含苯环的稳定共振式,该中间体能量更低,生成A的活化能更小,反应更快,因此低温下主产物为A;而磺化反应是可逆反应,由于A中磺基与异环的α-H处于平行位置,空阻较大,相对于B更不稳定;升高温度提供了β位磺化反应所需的活化能,使得A转化为更加稳定的化合物B。(2分)
