# 题-CM-50-02-2-1迄今为止已知最短的氮氯

## 题目

### 第 2 题（14 分）

2-1 迄今为止已知最短的氮氯键存在于化合物 $VNCl_{4}$ 中，其键长仅有 160 pm；请画出 $VNCl_{4}$ 的结构，解释为何其氮氯键如此之短。

2-2 沸石是一大类天然及人工合成的晶态硅铝酸盐，大多数沸石具有由铝氧四面体和硅氧四面体组成的笼共面连接而成的三维结构。现有一种沸石笼呈现与甲烷有相同的对称性，具有 $x$ 个八元环、 $y$ 个十二元环和 $y$ 个二十四元环，请根据欧拉定理，通过计算和推演，给出满足条件的最小的沸石笼的组成(求出 $x$ 和 $y$ 的数值)，并写出该笼多面体的表达记号(如立方体笼为 $[4^6]$ )。

2-3 我们可以将反应 $HA = A^{-} + H^{+}$ 的 $\Delta H^{\ominus}$ 定义为气相酸度，进而描述气相条件下某些物质的酸性。已知甲烷均裂的键解离能为 $439.3 \, kJ \cdot mol^{-1}$ ，H 的电离能为 $1312.0 \, kJ \cdot mol^{-1}$ ， $\cdot CH_{3}$ 结合电子放热 $8.2 \, kJ \cdot mol^{-1}$ ，计算甲烷分子的气相酸度。

2-4 磷是构成生命的必要元素之一，在生命体发挥着重要的作用。磷在高等生物体内有各种形式，包括无机的可溶和不溶性的磷酸盐，如羟基磷酸钙；还有一系列有机磷酸酐和磷酸酯类化合物，如携带遗传信息的 DNA、RNA 以及作为“能量通货”的 ATP 等。在人类生产的大宗化学品中，有机磷化合物如各种有机磷农药也占据着重要的地位。

2-4-1 亚磷酸三乙酯和亚磷酸二乙酯是制造有机磷农药的前体，请分别画出其结构简式。

2-4-2 实验发现，磷酸三甲酯的水解速率是磷酸二甲酯的 $10^{9}$ 倍，是磷酸单甲酯的 $10^{12}$ 倍，请解释产生这种差异的原因。

2-4-3 在生物体内，激酶能催化有机磷酸酐类化合物(如 ATP)上的磷酸基团向其他亲核性物种转移的反应，例如己糖激酶可催化 ATP 与葡萄糖反应，产生葡糖-6-磷酸。这些酶往往需要在 $Mg^{2+}$ 或 $Mn^{2+}$ 存在才能正常发挥作用，请解释原因。

2-4-4 在生物体内，3-磷酸-D-甘油酸激酶能识别并结合 3-磷酸-D-甘油酸(甘油酸即 2,3-二羟基丙酸)，从而催化其转化反应。请推测为了识别和结合底物，该酶的活性中心应具有何种类型的氨基酸残基？

2-4-2 因为磷酸三甲酯分子不带电，而磷酸二甲酯和磷酸单甲酯在水中会分别电离为一价和二价阴离子，阻止了带有负电荷的亲核试剂进攻，因此水解速率较磷酸三甲酯显著降低。（1 分）

2-4-3 因为亲核物种的亲核位点往往是电荷密度较高的区域，而生理条件下ATP 中的磷酸基团都是高度电离的，因此需要 $\mathrm { Mg ^{ 2 + } }$ 或 ${ \mathrm { Mn } } ^{ 2 + } .$ 来与磷酸酐部分结合以中和电荷，促进磷酸基团的转移，稳定反应的过渡态。（1 分）
答出类似“分散电荷”、“作为Lewis 酸”的关键词即可得分。

2-4-4 应具有侧链带有正电荷的氨基酸残基（1 分），如赖氨酸(Lys)和精氨酸(Arg)。答“侧链带有氨基的氨基酸残基”也可得分。
生理条件下磷酸基团会电离为阴离子，带负电，所以需要生理条件下侧链带有正电荷的氨基酸残基通过离子键和氢键相互作用识别和结合底物， 而生理条件下侧链带有正电的常见氨基酸即为赖氨酸和精氨酸。
