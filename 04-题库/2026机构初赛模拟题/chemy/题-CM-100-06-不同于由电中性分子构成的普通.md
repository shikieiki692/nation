# 题-CM-100-06-不同于由电中性分子构成的普通

## 题目

### 第 6 题（11 分）

不同于由电中性分子构成的普通液体，离子液体具有许多独特的性质。

6-1 离子液体之所以在室温下为液态，是因为阴阳离子之间的相互作用相对正常离子化合物来说较弱。其熔点通常受阴离子体积和对称性的影响，请指出阴离子体积和对称性的变化会对离子液体熔点造成什么影响，并指出原因。

$[Me_{2}NH_{2}]^{+}[Me_{2}NCO_{2}]^{-}$ 是一种新型的“可蒸馏”离子液体。

6-2-1 该离子液体中的阴阳离子间可以通过氢键形成离子对，请画出离子对的立体结构。

6-2-2 蒸馏是指通过蒸发和冷凝操作的联合，分离提纯某一液体组分的方法。通常待蒸馏组分都是沸点较低的分子化合物，但该离子液体却具有“可蒸馏”的性质，试解释之。

6-2-3 电解含有少量水的 $\left[Me_{2}NH_{2}\right]^{+}\left[Me_{2}NCO_{2}\right]^{-}$ 离子液体，阴极析氢反应，阳极生成了 $\left[MeNHCO_{2}\right]^{-}$ 和一种常见刺激性气体。请写出电解反应的电极反应式。

6-3 正丙胺乙酸盐 $\left[^{n}\mathrm{C}_{3}\mathrm{H}_{7}\mathrm{NH}_{3}\right]^{+}[OAc]^{-}$ 是一种常见的质子离子液体，其中存在如下的平衡：

$$
{ } ^{ n } \mathrm{C} _{ 3 } \mathrm{H} _{ 7 } \mathrm{NH} _{ 2 } ( 1 ) + \mathrm{HOAc} ( 1 ) \rightleftharpoons { } ^{ n } \mathrm{C} _{ 3 } \mathrm{H} _{ 7 } \mathrm{NH} _{ 3 } ^{ + } ( 1 ) + \mathrm{OAc} ^{ - } ( 1 )
$$

故离子液体的电离度 $\alpha = x_{\mathrm{X}^{-}} = x_{\mathrm{RNH_3}^{+}}$ 便成为了衡量离子液体性能的一个重要标准。

实验人员发现，通过测定特定波数下乙酸根与乙酸的红外吸收峰面积之比 $S_{OAc^{-}}/S_{HOAc}$ 并与标准曲线比对，便可计算出电离度 $\alpha$ 。

标准曲线的数据如下表所示:

<table><tr><td> $[OAc^{-}]/[HOAc]$ </td><td>0.84</td><td>1.43</td><td>2.07</td><td>3.28</td><td>7.86</td><td>17.6</td></tr><tr><td> $S_{OAc^{-}}/S_{HOAc}$ </td><td>1.37</td><td>3.47</td><td>5.63</td><td>9.35</td><td>20.56</td><td>44.43</td></tr></table>

6-3-1 已知 $\left[\mathrm{OAc}^{-}\right] / \left[\mathrm{HOAc}\right]$ 与 $S_{\mathrm{OAc}} - / S_{\mathrm{HOAc}}$ 满足一次函数关系：

$$
\left[ \mathrm{OAc} ^{-} \right] / \left[ \mathrm{HOAc} \right] = a + b S _{\mathrm{OAc} ^{-}} / S _{\mathrm{HOAc}}
$$

试求出 $a$ 与 $b$ 的值，结果保留三位有效数字。

提示: 在回归方程中 $a$ 为直线的截距, $b$ 为直线的斜率, 它们可按下式求解:

$$
b = \frac {\sum_{i = 1} ^{n} \left(x _{i} - \bar {x}\right) \left(y _{i} - \bar {y}\right)}{\sum_{i = 1} ^{n} \left(x _{i} - \bar {x}\right) ^{2}}, a = \bar {y} - b \bar {x}
$$

6-3-2 测定的 IR 得到其 $S_{OAc}^{-}/S_{HOAc} = 35.30$ ，试求出 $[^{n}C_{3}H_{7}NH_{3}]^{+}[OAc]^{-}$ 离子液体的电离度 $\alpha$ 。

$$
2 \left[ \mathrm{Me} _{2} \mathrm{NH} _{2} \right] ^{+} + 2 \mathrm{e} ^{-} = 2 \mathrm{Me} _{2} \mathrm{NH} + \mathrm{H} _{2}
\left[ \mathrm{Me} _{2} \mathrm{NCO} _{2} \right] ^{-} + \mathrm{H} _{2} \mathrm{O} = \left[ \mathrm{MeNHCO} _{2} \right] ^{-} + \mathrm{HCHO} + 2 \mathrm{H} ^{+} + 2 \mathrm{e} ^{-}
\begin{array}{l} \hline \text {6 - 3 - 1} \\ b = \frac {\Sigma_{i = 1} ^{n} (x _{i} - \overline {{x}}) (y _{i} - \overline {{y}})}{\Sigma_{i = 1} ^{n} (x _{i} - \overline {{x}}) ^{2}} = 0.394 (\text {1分}) \\ a = \overline {{y}} - b \overline {{x}} = - 0.0560 (\text {1分}) \end{array}
\begin{array}{l} \text {6 - 3 - 2 由6 - 3 - 1可知:} \\ [ \mathrm{OAc} ^{-} ] / [ \mathrm{HOAc} ] = - 0.0560 + 0.394 \times S _{\mathrm{OAc}} / S _{\mathrm{HOAc}} = - 0.0560 + 0.394 \times 35.30 = 13.9 (\text {1分}) \\ \text {故} \alpha = [ \mathrm{OAc} ^{-} ] / ([ \mathrm{HOAc} ] + [ \mathrm{OAc} ^{-} ]) = 13.9 / (1 + 13.9) = 93.3 \% (\text {1分}) \end{array}
$$
