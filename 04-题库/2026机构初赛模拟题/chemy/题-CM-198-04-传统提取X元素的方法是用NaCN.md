# 题-CM-198-04-传统提取X元素的方法是用NaCN

## 题目

### 第 4 题（32 分，占 15%）

传统提取 X 元素的方法是用 NaCN 溶液处理含 X 的矿石，在通入空气后 X 会进入到溶液相(反应 1)，分出残渣后再向溶液中加入 Zn 可得到 X 单质(反应 2)。但该方法要用到剧毒的氰化物，因此研究人员一直致力于发展新的回收 X 的方法。一种思路是在氧化剂(本题中用FeCl<sub>3 </sub>代表)的存在下用硫脲溶解矿石中的 X(反应 3)，该过程中部分硫脲先被氧化为了一种带 2 个正电荷的阳离子(反应 4)。另一种思路则是从电子废料出发，40 台手机中的 X 含量与1 吨矿物相同，关键是如何高选择性、高效率地实现提取。要实现选择性吸附，就要构造能与 X 特征结合的位点；要提高吸附容量、加快吸附速率，就需要加大材料的比表面积，共价有机框架(COF)便能较好地符合上述要求。

**4-2-3** pH 过高 AuCl<sub>4</sub><sup>-</sup>可能发生水解，难以吸附在材料表面（1 分）；在低 pH 下，部分亚胺会被质子化，其与带负电荷的 AuCl<sub>4</sub><sup>-</sup>之间有吸引作用，有利于吸附，在高 pH 下，部分酚羟基会被去质子，所带负电荷会与 AuCl<sub>4</sub><sup>-</sup>之间相互排斥，导致吸附量下降（1 分）。

**4-2-4** (a)(c)（2 分，全部选对才得分）

**4-2-5** SC(NH<sub>2</sub>)<sub>2</sub>（2 分）

**4-3-1** 假设表面 Y*物种覆盖度为 θ，则空位点所占分数为(1 – θ)，代入平衡常数表达式有：

K<sub>L</sub> = θ / (1 – θ)c（1 分）解得 θ = K<sub>L</sub>c / (1 + K<sub>L</sub>c)（1 分）因此吸附量 q<sub>e</sub> = q<sub>m</sub>θ = q<sub>m</sub>K<sub>L</sub>c / (1 + K<sub>L</sub>c)（1 分）

**4-3-2** 首先讨论 Langmuir 模型，对吸附等温式进行整理可得：

1 / q<sub>e</sub> = 1 / (q<sub>m</sub>K<sub>L</sub>c) + 1 / q<sub>m</sub>（2 分）因此以 1 / c 为自变量，1 / q<sub>e</sub>为因变量进行线性拟合可得：

1 / q<sub>e</sub> = 0.0078(1 / c) + 0.1068（R<sup>2</sup> = 0.99751）（1 分）再讨论 Freundlich 模型，对吸附等温式进行整理可得：

lnq<sub>e</sub> = lnK<sub>f</sub> + (1 / n)lnc（2 分）以 lnc 为自变量、lnq<sub>e</sub>为因变量进行线性拟合可得：

lnq<sub>e</sub> = 0.12lnc + 2.04（R<sup>2</sup> = 0.83743）（1 分）因此相比之下，Y 的吸附更符合 Langmuir 模型，即吸附的 Au 物种形成单分子层、无显著的相互作用，对应的饱和吸附量可由截距计算：

q<sub>m</sub> = 1 / 0.1068 = 9.363 mmol X /g = 1845 mg X /g（2 分）
