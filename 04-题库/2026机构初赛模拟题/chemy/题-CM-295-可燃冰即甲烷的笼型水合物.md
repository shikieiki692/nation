# 题-CM-295-可燃冰即甲烷的笼型水合物

## 题目

### 第 6 题（17 分）

本题是关于可燃冰的题目，涉及到可燃冰的组成、骨架、多面体结构、晶体结构、对称性等多方面的知识，解答本题需要一定的数学技巧，同时能使得读者对可燃冰的结构有所了解。

可燃冰被认为是 21 世纪最重要的能源，目前大部分仍处于探索性试采阶段，虽然中国在这方面起步较晚，但已成为该领域的领跑者。

6-1 可燃冰即甲烷的笼型水合物。由甲烷分子填入两种多面体中心形成。两种多面体如下图所示，分别表示为 $5^{12}$ 和 $6^{2}5^{12}$ 。

![](images/2eab77870e5cfc6d1916fa51d820606d7024c66dbdefc943671b6fba101d7955.jpg)
五角十二面体十四面体

6-1-1 我们常用二维图来表示多面体，比如立方体可以表示为下图。试将这两种多面体表示为二维图。作图时， $5^{12}$ 多面体以五边形为中心， $6^{2}5^{12}$ 以六边形为中心。

![](images/3dba480855cea0fe263d85f1b5a71d5385cf39a1fd15579dc464fa706e338ffd.jpg)

6-1-2 写出 $6^{2}5^{12}$ 多面体中的所有对称元素及数目。

6-1-3 可燃冰中，每个水笼中心都有一个甲烷分子（认为是球形），整个晶体结构为立方晶系，晶胞中心为对称中心，其中两个甲烷的坐标为(0,0,0)和(1/2,0,1/4)，已知这两个甲烷分子位于不同种类的多面体笼中心，坐标为(0,0,0)的甲烷分子位于五角十二面体中心，试写出其中所有甲烷的分数坐标。

6-1-4 已知可燃冰中，每个水都通过 O 和两个 H 形成氢键，每个 H 都连接着两个水，且只有两种多面体，每个多面体中心都有一个甲烷分子。试推求出可燃冰的化学式。

6-1-5 假设可燃冰的晶胞参数为 $1.20 \, nm$ ，求 $1 \, m^{3}$ 的可燃冰能够分解出多少体积的标准状况下的水和甲烷。

6-2 除了可燃冰外，气体水合物还有很多种，结构大体类似，都是由气体分子 A 填入某种多面体空隙，这些多面体通过共面连接在一起，但是水仍是氢键形成的三维骨架。

6-2-1 丙烷、异丁烷水合物的晶胞可以看做由 16 个 $5^{12}$ 多面体和 8 个 $6^{4}5^{12}$ 多面体组成，试计算一个晶胞中水分子的个数。

6-2-2 甲烷和环己烷共同形成的水合物的晶胞可以看做由3个 $5^{12}$ 多面体、1个 $6^{8}5^{12}$ 多面体和 $6^{3}5^{6}4^{3}$ 多面体组成，计算一个晶胞中水分子的个数。

6-1-3 可燃冰中，每个水笼中心都有一个甲烷分子（认为是球形），整个晶体结构为立方晶系，晶胞中心为对称中心，其中两个甲烷的坐标为(0,0,0)和(1/2,0,1/4)，已知这两个甲烷分子位于不同种类的多面体笼中心，坐标为(0,0,0)的甲烷分子位于五角十二面体中心，试写出其中所有甲烷的分数坐标。

6-1-4 一个晶胞中有8 个甲烷分子，2 个位于五角十二面体， 6 个位于十四面体（1 分）
则水分子数目为： $( 2 \times 20 + 6 \times 24 ) / 4 = 46$ 个（1 分）
所以晶体的化学式为 $8 \mathrm { CH } _{ 4 } \cdot 46 \mathrm { H } _{ 2 } \mathrm { O }$ （1 分）

6-1-5 假设可燃冰的晶胞参数为 $1.20 \mathrm { nm }$ ， 求 $1 ~ \mathrm { m } ^{ 3 }$ 的可燃冰能够分解出多少体积的标准状况下的水和甲烷。

6-1-5 晶体密度 $D = ZM/N_AV = 0.918 \ \mathrm { g } \cdot \mathrm { cm } ^ { - 3 }$ （1 分）

则 $1 \ \mathrm { m } ^{ 3 }$ 的可燃冰重 918 kg ， 其中， 甲烷质量 123 g ， 水质量 $795 \mathrm { g }$ （1 分）
则甲烷的体积为： $172 \ \mathrm { m } ^{ 3 }$ （1 分）
水的体积为 $0.795 \mathrm { m } ^{ 3 }$ （1 分）

6-2-1 $( 16 \times 20 + 8 \times 28 ) / 4 = 136$ 个水 （1 分）
