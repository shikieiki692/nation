# 题-CM-166-01-1-1碳化铝与氯化汞的盐酸溶

## 题目

### 第 1 题 写出以下化学反应的方程式。 （12 分， 占 $8 \%$

1-1 碳化铝与氯化汞的盐酸溶液反应， 产生一种剧毒的化合物。
1-2 在无氧条件下，含 ${ \mathrm { Cu } } ^{ 2 + }$ 的溶液可作为氧化剂与黄铁矿反应， 产物中硫有 2 种氧化态：-2和 $+ 6$ ；铁的氧化态保持不变。
1-3 将磷酸铁、碳酸锂以及二水合草酸混合研磨后高温煅烧制备 LiFePO4。
1-4 在弱酸性条件下，用过氧化氢水溶液与LiFePO4 反应，能使得锂全部进入水溶液中，而铁和磷仍留在固相。
1-5 将汞单质、明矾和NaCl 在空气中混合加热，挥发出含+1 氧化态汞的化合物。
1-6 在酸性水溶液中， 用过量的 $\mathrm { { \mathcal { I } } } _{ 2 }$ 氧化六硫氰酸根合铬(III)酸钾， 碳和氮只转化为 ICN；反应无单质产生。

$$
