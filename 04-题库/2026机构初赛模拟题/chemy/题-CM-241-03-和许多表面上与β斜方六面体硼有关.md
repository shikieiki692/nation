# 题-CM-241-03-和许多表面上与β斜方六面体硼有关

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-5-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（9 分）

和许多表面上与 β-斜方六面体硼有关的复杂结构相反，ScB<sub>12</sub>的结构相当简单，但其中的 B<sub>12</sub>单元不是正二十面体，而是一种特殊的“截角立方体”。

![](images/805def4fea72a72b05414698e6619f651c0853fc1eccd441d706d5e2193d164e.jpg)

B<sub>12</sub>截角立方体示意图 菱面体晶胞向六方晶胞的转化参考图

**3-1** 在 ScB<sub>12</sub>以 Sc 为顶点的菱面体晶胞中，B<sub>12</sub>单元中心的坐标为(1/2, 1/2, 1/2)。结合参考图，给出以 Sc 为顶点的六方晶胞中所有 B<sub>12</sub>单元中心坐标。

**3-2** 现测得菱面体晶胞的参数为 a = 5.241 Å，α = 60°。结合参考图，计算该晶体密度。

**3-3** 在以 Sc 为顶点的六方晶胞中沿 c 轴观察得到的 B<sub>12</sub>投影图与示意图相同。结合参考图，推导 Sc 原子周围最近 B 原子的数量。

## 参考答案

**3-1** (0, 0, 1/2)，(2/3, 1/3, 5/6)，(1/3, 2/3, 1/6)或(0, 0, 1/2)，(2/3, 1/3, 1/6)，(1/3, 2/3, 5/6)（3 分）

**3-2**
