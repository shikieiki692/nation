# 题-CM-252-06-相较于无机碱或有机金属盐碱有机超

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-25-6`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 6 题（24 分，占 13.0%）

相较于无机碱或有机金属盐碱，有机超碱在维持相似碱性的同时还具有更低的亲核性和更好的溶解性。一般而言，碱性比质子海绵（pK<sub>a</sub>H<sup>+</sup> = 18.6 in CH<sub>3</sub>CN）强的有机碱即可称为超碱。

**6-1** 质子海绵的结构如下所示，解释它具有强碱性的原因。

![](images/34e4fc095992a108340ac1022c8e4dd18c068051aaf6818c6e148094efb62ea4.jpg)

**6-2** 考虑超碱 DBU 参与的如下消除反应，若初始底物和碱的浓度均为 a，假设其为二级反应，对应速率常数为k<sub>1</sub>，计算t时刻产物的浓度并给出底物半衰期公式。

![](images/fc51fd2cb3bfe8f4ecd45d01c1711fd167a4b8b319f6bd84b55066f59e42ecf4.jpg)

**6-3** 在实际反应中一般不会控制碱和底物等量加入。若将碱的初始浓度改为 b(a ≠ b)，其他条件不变，计算t时刻产物的浓度并给出底物半衰期公式。提示：1 / (a – x)(b – x) = [1 / (a – x) – 1 / (b – x)] / (b – a)；∫[f(x) ± g(x)]dx = ∫f(x)dx ±∫g(x)dx

**6-4** 虽然有机超碱的亲核性比其他碱弱，但仍难以避免副反应的发生。假设亲核取代反应也为二级反应，对应速率常数为k<sub>2</sub>，初始底物和碱的浓度分别为a和b，计算t时刻两种产物的浓度。

**6-5** 若b = 7 μmol，a = 1.4b，t = 168 h，消除与取代产物比例为 87: 13，碱的总转化率为17%，尝试计算k<sub>1</sub>和k<sub>2</sub>。

**6-6** 若将 DBU 更换为如下物质，可在维持碱性差距不大的情况下将消除与取代产物比例提升到 99: 1 以上，解释其碱性来源和提升产物消除比例的原因。

## 参考答案

**6-1** 结合氢离子能缓解两个 N 原子上甲基的排斥。（2 分）

![](images/e1c2e1013b8b1cbc12ab9579340d5a58c01bd9618f71105f6917a6c219a810d0.jpg)

**6-2** 记底物、DBU 和产物分别为 A、B 和 P<sub>1</sub>，有

A + B → P<sub>1</sub> + …

t = 0 a a

t = t a – x a – x x由二级反应动力学方程有 dx / dt = k<sub>1</sub>(a – x)<sup>2</sup>，（1 分）移项并从 0 积分到t可得 1 / (a – x) – 1 / a = k<sub>1</sub>t，整理得x = a<sub>2</sub>k<sub>1</sub>t / (1 + ak<sub>1</sub>t)。（2 分）令a – x = a / 2，代入方程可得t<sub>1/2</sub> = 1 / k<sub>1</sub>a。（2 分）

**6-3** 与 6-2 同理，有

A + B → P<sub>1</sub> + …

t = 0 a b

t = t a – x b – x x由二级反应动力学方程有 dx / dt = k<sub>1</sub>(a – x)(b – x)（1 分），移项并从 0 积分到t可得k<sub>1</sub>t – k<sub>1</sub>t<sub>0</sub> = ∫dx / (a – x)(b – x) = [∫dx / (a – x) – ∫dx / (b – x)] / (b – a)

= ln[b(a – x) / a(b – x)] / (a – b)（2 分），整理得：x = ab{1 – exp[(a – b)k<sub>1</sub>t]} / {b – aexp[(a – b)k<sub>1</sub>t]}（2 分）。

**6-4** 与 6-3 同理，分别设t时刻 P<sub>1</sub>和 P<sub>2</sub>浓度为x<sub>1</sub>和x<sub>2</sub>，令x = x<sub>1</sub> + x<sub>2</sub>。由二级反应动力学方程有 dx<sub>1</sub> / dt = k<sub>1</sub>(a – x)(b – x)，dx<sub>2</sub> / dt = k<sub>2</sub>(a – x)(b – x)；dx<sub>1</sub> / dt + dx<sub>2</sub> / dt = d(x<sub>1</sub> + x<sub>2</sub>) / dt = dx / dt = (k<sub>1</sub> + k<sub>2</sub>)(a – x)(b – x)（2 分）由 6-3 可知x = ab{1 – exp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]} / {b – aexp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]} = x<sub>1</sub> + x<sub>2 </sub>而(dx<sub>1</sub> / dt) / (dx<sub>2</sub> / dt) = k<sub>1</sub> / k<sub>2</sub>，有x<sub>1</sub> / x<sub>2</sub> = k<sub>1</sub> / k<sub>2</sub>（2 分），联立两式解得：x<sub>1</sub> = k<sub>1</sub>ab{1 – exp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]} / (k<sub>1</sub> + k<sub>2</sub>){b – aexp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]}（1 分），x<sub>2</sub> = k<sub>2</sub>ab{1 – exp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]} / (k<sub>1</sub> + k<sub>2</sub>){b – aexp[(a – b)(k<sub>1</sub> + k<sub>2</sub>)t]}（1 分）。

**6-5** 由 6-3 可知(k<sub>1</sub> + k<sub>2</sub>)t = ln[b(a – x) / a(b – x)] / (a – b)，代入数据求得(k<sub>1</sub> + k<sub>2</sub>) = 121 L·mol<sup>-1</sup>·h<sup>-1</sup>（1 分）由 6-4 可知k<sub>1</sub> / k<sub>2</sub> = x<sub>1</sub> / x<sub>2</sub> = 87 / 13（1 分），故k<sub>1</sub> = 105 L·mol<sup>-1</sup>·h<sup>-1</sup>，k<sub>2</sub> = 16 L·mol<sup>-1</sup>·h<sup>-1</sup>（2分）。

**6-6** 碱性：结合氢离子后铵能与 24-crown-8 形成强氢键（1 分）；弱亲核性：24-crown-8对底物有很强的范德华排斥（1 分）。若将该物质辨认为 18-crown-6 等错误名称，不得分。
