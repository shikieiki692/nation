# 题-CM-288-05-将Th和ThI4按比例混合加热至

## 题目

### 第 5 题（14 分）

将 Th 和 ThI<sub>4</sub>按比例混合加热至 700 ~ 850°C，得到了 Th 的低价碘化物晶体。该碘化物的晶体由 I-Th-I 的层状结构重复堆叠而成。根据配位多面体的不同，I-Th-I 的层状结构又可分为三棱柱层和八面体层。以下按照沿 c 轴从上往下的顺序，示出了每层 Th 的配位多面体沿 c轴的投影图；其中小球表示 Th 原子，大球表示 I 原子：

![](images/b5bb74edb7470fbe8875eaf44ab44946b16d5435a35d2d31f61ab11e6f9a2769.jpg)

**5-1** 图 1~4 中，哪些为三棱柱层，哪些为八面体层？

**5-2** 用 A, B, C 表示 I 原子层，用 a, b, c 表示 Th 原子层，用□表示空层，写出该晶体的堆积方式(图 1 和图 3 的配位多面体取向不同)。

**5-3** 该晶体属于七大晶系中的哪一种？简述判断理由。

**5-4** 该晶体中，Th-I 的平均键长为 322.8 pm，层间最短的 I-I 距离为 544.8 pm，层内最近的Th 间距为 397.0 pm。计算晶胞参数 a 和 c 以及理论密度 D。

**5-5** 该晶体中，多面体层间的距离相对而言较大；对此，研究人员认为，空层中可能存在游离的电子对。写出能体现该晶体结构特点的化学式，注意 Th 的稳定氧化态。

**5-6** 化合物 MoC 也存在着与该晶体相同的两种配位多面体层，但区别在于：(1) MoC 中 Mo的配位多面体层之间通过（且只通过）共棱的方式相互连接；(2) MoC 的晶胞中共有 6 层 Mo的配位多面体层，其中包括 2 层三棱柱层和 4 层八面体层；同种配位多面体层的化学环境相同。据此回答：

**5-6-1** 分别指出由 C 原子堆积形成的八面体空隙以及三棱柱空隙被 Mo 占据的比例。

**5-6-2** 用 A, B, C 表示 C 原子层，用 a, b, c 表示 Mo 原子层，写出该晶体的堆积方式。

**5-6-3** 晶体中有多少种不同空间环境的 C 原子？

**5-6-4** 晶体中有多少种不同长度的 Mo-C 键？
