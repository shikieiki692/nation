# 题-CM-242-01-11镍与稀硝酸反应生成一种不溶于

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-6-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（12 分）

**1-1** 镍与稀硝酸反应，生成一种不溶于水的气体。

**1-2** SnS 与某种单质在 100℃的环境下反应，生成一种最终是黄色的产物。

**1-3** 某种密度小于水的金属与氮气在一定条件下反应，生成一种稳定的红色固体。

**1-4** 二茂镍和 CPh<sub>3</sub>PF<sub>6</sub>按 2:1 的比例反应得到了两种离子化合物。

**1-5** 在二甘醚中 Et<sub>3</sub>NBH<sub>3</sub>与 B<sub>2</sub>H<sub>6</sub>反应，得到了三角正二十面体形状的阴离子。

**1-6** 二氯化二硫和 NSCl 反应，生成含氮 14.36%的三元化合物和分子形状为 V 形的红色发烟液体。

**1-7** 利用二氧化锆和氟化铵在 500°C 下混合加热，得到 Zr<sub>7</sub>O<sub>9</sub>F<sub>10</sub>。

**1-8** 将五氯化磷与氯化铵在有机溶剂中混合回流，生成含有六元环的化合物。

## 参考答案

**1-1** 3Ni + 2NO<sub>3</sub><sup>- </sup>+ 8H<sup>+</sup> = 3Ni<sup>2+ </sup>+ 2NO + 4H<sub>2</sub>O（1.5 分）

**1-2** SnS + S = SnS<sub>2</sub>（1.5 分）或：8SnS + S<sub>8</sub> = 8SnS<sub>2</sub>

**1-3** 6Li + N<sub>2</sub> = 2Li<sub>3</sub>N（1.5 分）写成 6Na+N<sub>2</sub> = 2Na<sub>3</sub>N 给 1 分

**1-4** 2Ni(C<sub>5</sub>H<sub>5</sub>)<sub>2</sub> + CPh<sub>3</sub>PF<sub>6</sub> = Ni<sub>2</sub>(C<sub>5</sub>H<sub>5</sub>)<sub>3</sub>PF<sub>6</sub> + C<sub>5</sub>H<sub>5</sub>CPh<sub>3</sub>（1.5 分）

**1-5** 2Et<sub>3</sub>NBH<sub>3</sub> + 5B<sub>2</sub>H<sub>6</sub> = [Et<sub>3</sub>NH]<sub>2</sub>B<sub>12</sub>H<sub>12</sub> + 11H<sub>2</sub>（1.5 分）

**1-6** S<sub>2</sub>Cl<sub>2</sub> + 2 NSCl = S<sub>3</sub>N<sub>2</sub>Cl<sub>2</sub> + SCl<sub>2</sub>（1.5 分）

**1-7** 7ZrO<sub>2</sub> + 10NH<sub>4</sub>F = Zr<sub>7</sub>O<sub>9</sub>F<sub>10</sub> + 10NH<sub>3</sub> + 5H<sub>2</sub>O（1.5 分）
