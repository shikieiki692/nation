# 题-CM-227-03-将一种常见的无机盐A置于分压为0

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-24-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（14 分）

将一种常见的无机盐 A 置于分压为 0.1 atm 的气体 X 气氛下进行热重分析，加热至 610 K时，失重 8.24%，放出气体 X 并得到碱式盐 B；继续加热至 650 K 左右，失重 2.75%，放出气体 X 并得到碱式盐 C；继续加热至 700 K，又放出气体 X，剩余固体为 D，质量为原质量的 83.5%。取剩余残渣 D，冷却后用稀硝酸溶解。然后加入过量的 Na<sub>2</sub>S，得到黑色沉淀 E，然后用 30% H<sub>2</sub>O<sub>2</sub>处理沉淀，发现沉淀颜色逐渐变白。

**3-1** 写出 A~E、X 的化学式。

**3-2** 当体系中 X 分压变小时，开始分解的温度是变高、变低还是不变？

## 参考答案

**3-1** 根据题意可知样品的中心元素为 Pb，所以最后剩余的残渣有很大概率为稳定氧化物 PbO。

且根据失重温度来看，原样品中不太可能存在 H<sub>2</sub>O。

所以假设原样品中阴离子的摩尔质量为 x，可写出方程：( 207.2 + 16 ) / ( 207.2 + x ) = 83.5%

解得 x = 60.1 (g/mol)，所以阴离子为 CO<sub>3</sub><sup>2-</sup>。

X CO<sub>2</sub> A PbCO<sub>3</sub> B Pb<sub>2</sub>O(CO<sub>3</sub>) C Pb<sub>3</sub>O<sub>2</sub>(CO<sub>3</sub>) D PbO E PbS （每个 2 分）

**3-2** 变低 （2 分）
