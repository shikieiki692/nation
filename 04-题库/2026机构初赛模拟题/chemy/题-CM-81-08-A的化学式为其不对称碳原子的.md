# 题-CM-81-08-A的化学式为其不对称碳原子的

## 题目

### 第 8 题（11 分）

A 的化学式为 $C_{3}H_{6}O_{3}$ ，其不对称碳原子的构型为 R。A 与 HCN 作用，得到一对异构体 B 和 C。将 B 用 $\mathrm{Ba(OH)_{2}}$ 处理后酸化，然后用钠汞齐还原，得到 D-赤藓糖，D-赤藓糖经 $NaBH_{4}$ 还原可得到无光学活性的赤藓醇；而 C 在相同条件下则得到 D-苏糖，D-苏糖经 $NaBH_{4}$ 还原可得到 D-苏糖醇。

8-1 画出 A 的 Fischer 投影式。

8-2 化合物 B 和 C 属于哪种异构体?
a) 对映异构体    b) 非对映体    c) 差向异构体    d) 构象异构体

8-3 二硫苏糖醇是 D-苏糖醇的 1,4 位羟基被巯基取代后的衍生物，常在生化实验中被用于蛋白质中二硫键的还原，是一种很有用的生化试剂。画出二硫苏糖醇的 Fischer 投影式，标出其中不对称碳原子的构型(R/S)。

8-4 二硫苏糖醇与蛋白质反应后，转化为化合物 D。画出 D 最稳定的构象式。

8-5 是否能用 1,4-丁二硫醇代替二硫苏糖醇在磷酸缓冲液中还原蛋白质的二硫键？简述原因。

8-5 不能（1 分），因为 1,4-丁二硫醇的水溶性不好（1 分），反应速率太慢，而引入了两个羟基的 DTT 的水溶性好得多，更适合于水溶液中对蛋白质二硫键的还原。
