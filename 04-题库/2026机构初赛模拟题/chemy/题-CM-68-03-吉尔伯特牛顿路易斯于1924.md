# 题-CM-68-03-吉尔伯特牛顿路易斯于1924

## 题目

### 第 3 题（8 分）

吉尔伯特·牛顿·路易斯于 1924 年预测了四聚氧的存在， 2000 年美国 《科学》 杂志报道了这种分子被成功的合成出来。

3-1 理论计算表明可能以亚稳态存在的 $\mathrm { O } _{ 4 }$ 分子有三种不同的结构。第一种具有 $S _{ 4 }$ 轴，第二种兼具 $S _{ 4 }$ 轴与四条 $C _{ 3 }$ 轴，第三种为平面型结构，其中含有一条 $C _{ 3 }$ 轴和三条垂直于 $C _{ 3 }$ 轴的$C _{ 2 }$ 轴。画出这三种 $\mathrm { O } _{ 4 }$ 分子的可能结构。在理论计算预测的条件下，第一种结构最稳定，请给出合理的解释。

C3 轴和三条垂直于C3 轴的C2 轴。画出这三种O4 分

3-2 在常温常压下， $\mathrm { O } _{ 4 }$ 和 $\mathrm { O } _{ 2 }$ 何者更稳定？ 解释原因。

3-3 在常温常压下， $\mathrm { O } _{ 4 }$ 和 $\mathrm { O } _{ 2 }$ 何者氧化性更强？

**3-2** 在常温常压下, $O_{4}$ 和 $O_{2}$ 何者更稳定?解释原因。

**3-2** $O_{2}$ 更稳定。从单键和双键的键能角度考虑, $4BE(O-O)>2BE(O=O)$ ;从环张力考虑, $O_{4}$ 四元环键角较小,分子的张力较大;从熵的角度考虑, $O_{4}$ 分解为 $O_{2}$ 为熵增反应。因此 $O_{2}$ 更稳定。(判断1分,原因2分,3条中答出2条即可得满分)

**3-3** 在常温常压下, $O_{4}$ 和 $O_{2}$ 何者氧化性更强?

**3-3** $O_{4}$ 氧化性更强。(1分)
