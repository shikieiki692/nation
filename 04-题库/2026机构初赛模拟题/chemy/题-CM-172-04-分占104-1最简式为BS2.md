# 题-CM-172-04-分占104-1最简式为BS2

## 题目

### 第 4 题 含硼和硫的阴离子（22 分，占 $10 \%$

分，占10%）4-1 最简式为BS2-的硼硫

4-1 最简式为 $\mathrm { \overline { { BS } } } _{ 2 }$ -的硼硫阴离子在不同的化合物中结构不同。在 $\mathrm { CsBS } _{ 2 }$ 中， ${ \mathrm { BS } } _{ 2 } { \mathrm { \cdot } }$ -为二聚体；在 $\mathrm { NaBS } _{ 2 }$ 中， $\mathrm { BS } _{ 2 }$ -为三聚体；在 $\mathrm { BaB } _{ 2 } \mathrm { S } _{ 4 }$ 中， ${ \mathrm { BS } } _{ 2 } { \mathrm { \cdot } }$ -具有由 $\mathrm { [ B _{ 3 } S _{ 3 } ] }$ 六元环通过共用 B 原子连接形成的一维无限长链结构。 画出这三种 $\mathrm { BS } _{ 2 }$ 的结构示意图。

4-2 将 $\mathrm { K } _{ 2 } \mathrm { S }$ 、S 和 `{ \bf B } _{ 2 } { \bf S } _{ 3 }` 混合加热制得化合物 $\mathrm { K } _{ 2 } \mathrm { B } _{ 2 } \mathrm { S } _{ 7 }$ ；其阴离子 `{ \bf B } _{ 2 } { \bf S } _{ 7 } { } ^{ 2 }` -为一维无限长链结构；

B 原子和S 原子形成 5 元环和 6 元环， B 均为四面体配位。 画出 $\mathrm { B } _{ 2 } \mathrm { S } _{ 7 } { } ^{ 2 }$ -的结构示意图。

4-3 在六氟异丙醇中， $0.0300 { \mathrm { molNaBH } } _{ 4 }$ 和 $0.100 \mathrm { mol } \mathrm { s }$ 充分反应，得到 $748 \mathrm { mL }$ 气体 $\mathrm { H } _{ 2 } ( 25^{ \circ } \mathrm { C } ,$ $100 \ \mathrm { kPa } )$ ； 反应的另一产物是一种活性更高的还原剂 A。研究发现，S 的用量达到化学计量前， $\mathrm { H } _{ 2 }$ 释放体积和 S 用量成线性关系，达到计量后不再释放 $\mathrm { H } _{ 2 \circ } \mathbf { A }$ 阴离子的一种可能结构具有八元环，S 有 2 种化学环境。

4-3-1 计算生成 $\mathrm { H } _{ 2 }$ 的摩尔数。

4-3-2 写出反应方程式， 画出含有八元环结构的阴离子的结构示意图。

4-3-3 以 S 与 $\mathrm { NaBH _{ 4 } }$ 的物质的量比为横坐标， 生成 $\mathrm { H } _{ 2 }$ 与 $\mathrm { \Delta NaBH _{ 4 } }$ 的物质的量比为纵坐标， 画出实验结果曲线图。
