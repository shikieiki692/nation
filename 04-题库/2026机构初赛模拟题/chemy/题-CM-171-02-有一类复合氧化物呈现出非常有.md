# 题-CM-171-02-有一类复合氧化物呈现出非常有

## 题目

### 第 2 题 复合氧化物的结构 （23 分， 占 $12 \%$

有一类复合氧化物呈现出非常有趣的结构。在该复合氧化物的晶体中有 A 原子、A’ 原子、$\mathbf { B }$ 原子和氧原子，其中 $\mathbf { A }$ 通常为碱金属或碱土金属， $\mathbf { A } ^{ \prime }$ 和 B 通常为过渡金属。A’原子与 6个氧原子形成三棱柱配位(tp)，B 原子与6 个氧原子形成八面体配位(o)；这两种配位多面体通过共面连接形成平行于 $\scriptstyle { \mathbf { \alpha } } _{ c }$ 轴的无限单链；链间存在 A 原子以平衡电荷，每个三棱柱中心对应 2 个 A 原子，每个八面体中心对应 1 个 A 原子。设单链中八面体中心与三棱柱中心的数目比为 $x { : } 1$ (其中 $x$ 为整数)。

2-1 写出该晶体的化学式。

2-2 简要说明晶体中 A’原子和B 原子位于无限单链内(而不是链间)的原因。

2-3 将晶体中的八面体视为正八面体；设三棱柱和八面体中 $\mathbf { A } ^{ \prime }$ -O和B-O 键长均为 $200.0 \mathrm { pm }$ ，计算：

(1)单层八面体的高度 $h _{ 1 }$ 和单层三棱柱的高度 $h _{ 2 }$ ；
h1 和单层三棱柱的高度h2；(2)为使

(2)为使晶体满足平移对称性的要求， 符合要求的最小晶胞参数 $\boldsymbol { c }$ ；

2-4 由 Sr、 Co、 O 三种原子形成的该类型复合氧化物晶体，所有原子均有序分布，六方晶胞体积 $V = 0.85606 \mathrm { nm } ^{ 3 }$ ， 晶体密度 $D { = } 5.548 ~ \mathrm { g / cm ^{ 3 } }$ 。 晶体中所有 Sr 原子化学环境相同。

2-4-1 通过计算， 推出该晶体的化学式， 推出晶胞中有多少根无限单链穿过。

2-4-2 若以 $\scriptstyle \left| { \mathrm { Co } } \right.$ 原子为晶胞顶点，画出晶胞沿 $\boldsymbol { \mathscr { c } }$ 轴的投影示意图 （氧原子可不画出）； 写出晶体点阵类型。

2-5 若晶体中只有 $\mathbf { B }$ 原子而无 A’原子， 但配位多面体之间的连接方式不变， 画出晶胞示意图。

## 参考答案

2-1 化学式为 $A_{x+2}A'B_{x}O_{3x+3}$ （3 分）

2-2 因为 A' 和 B 常为过渡金属，d 电子数目多，极化能力强，配位数(相对)更低（2 分）(相对于碱金属或碱土金属)，易形成八面体或三棱柱配位。

2-3 单层八面体的高度 $h_{1}=2\times\sqrt{3}\times200.0\ pm/3=230.9\ pm$ （1分）

根据几何图形的相似性： $h_{2}=230.9\ pm$ （1分）

当 $x$ 为奇数时，一个周期含2个三棱柱和 $2x$ 个八面体，此时：

$$
c = 2 x \times 230.9 \mathrm{pm} + 2 \times 231.0 \mathrm{pm} = 461.8 (x + 1) (\mathrm{pm}) (1 \text {分})
$$

当 $x$ 为偶数时，一个周期含1个三棱柱和 $x$ 个八面体，此时：

$$
c = 230.9 (x + 1) (\mathrm{pm}) \text {(1分)}
$$

2-4-1 （共6分）该晶体的化学式为 $Sr_{x+2}Co_{x+1}O_{3x+3}$ ；摩尔质量为：

$$
M = 87.62 (x + 2) + 58.93 (x + 1) + 16.00 (3 x + 3) = 194.55 x + 282.17 (\mathrm{g/mol}) \text {(1分)}
$$

居 $ZM = DN_{\mathrm{A}}V$ ： $(194.55x + 282.17)Z = 5.548\times 6.022\times 10^{23}\times 0.85606\times (10^{-7})^{3}$ （1分）

当 x=1 时，Z=6，刚好为合理解（2 分）

当 x > 1 时，Z < 6;

将 $Z = 1,2,3,4,5\dots$ 带入上式，分别求得： $x = 13.25,5.90,3.45,2.24,1.49$ 均非合理解因此，晶体的化学式为 $\mathrm{Sr}_3\mathrm{Co}_2\mathrm{O}_6$ （1分）

根据上题结论，该链每2个化学式为一个周期，晶胞中的无限单链数目为： $6 \div 2 = 3$ （1分）
