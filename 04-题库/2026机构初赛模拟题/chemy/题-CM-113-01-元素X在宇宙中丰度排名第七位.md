# 题-CM-113-01-元素X在宇宙中丰度排名第七位

## 题目

### 第 1 题（23 分）

元素 X 在宇宙中丰度排名第七位，而在宇宙化学中，含 X 的高活性四原子分子 A 十分富有研究意义。A 可以通过 X 的氢化物 $XH_{n}$ 与 $(\mathrm{CN})_{2}$ 反应或 X 原子与 HCN 反应得到。将 $1gXH_{n}$ 通入充满 $10dm^{3}$ 空气容器(顶盖为理想活塞)中完全燃烧，得到氧化物 $XO_{n/2}$ 和水，恢复至室温后容器体积减少至 $8.477dm^{3}$ (忽略生成固体和液体的体积)；每克 A 含有 $2.787 \times 10^{-4}g$ 电子。

1-1 非 X 原子均为闭壳层的 A 一共有 6 种异构体，推导 X 代表的元素，并画出 A 所有无环异构体的 Lewis 结构式。

1-2 2021 年，A. Filippou 小组合成了化合物 B，其与 A 的某种异构体的核心键连方式相同。合成从 $XBr_{2}(SIdipp)$ 出发，其与 $\mathrm{NaB(Ar^{F})_{4}}$ 和 $Ar^{Mes}N\equiv C$ 反应，得到含 X 的 1:1 型盐 C。C 与 $KC_{8}$ 反应，得到电中性的 B，B 和 C 均具有两种立体异构体。

![](images/8e70d6775a3675c9613618947d590eafea188a188fc8f3e60334003e3663b9db.jpg)

1-2-1 利用 VSEPR 理论，判断 $\mathbf{XBr}_2(\mathrm{SIdipp})$ 中 $\mathbf{X}$ 的立体构型。

1-2-2 指出 $\mathrm{NaB(Ar^{F})_{4}}$ 的作用。

1-2-3 画出 B 和 C 的结构式。

1-2-4 研究人员发现，如果 $XBr_{2}(SIdipp)$ 过量，则无法得到 C。他们认为可能是由于过量的 $XBr_{2}(SIdipp)$ 会导致双核 X 配离子 D 的形成，D 同样为 1:1 型盐，不含 $[Ar^{Mes}N\equiv C]$ 基团。若 C 中的 N≡C 键长为 1.15Å， $Ar^{Mes}N\equiv C$ 中 N≡C 键长为 1.16Å，由此推测 C 中 X 原子和 $Ar^{Mes}N\equiv C$ 片段间的主导稳定化作用，并比较 $XBr_{2}(SIdipp)$ 和 $Ar^{Mes}N\equiv C$ 的 σ 给体能力。

$$
\mathbf {X} \mathrm{Br} _{2} (\text { SIdipp }) + \mathbf {C} = \mathbf {D}
$$

求出在室温下该反应的 $\varDelta_r G_m^o$ 、 $\varDelta_r H_m^o$ 和 $\varDelta_r S_m^o$ 。

1-2-6 正如化学家们推测，B 有很强的亲核性。B 与 Ge(Ar $^{Mes}$ )Cl 反应可以得到 E，其中的 X 与 3 个原子相连，Ge 只与 2 个原子相连，请给出 E 的结构式。

1-3 2020 年，A. Filippou 小组合成了含有 “反 Van't Hoff/Le Bel 规则” 的 X 的化合物 F。Na[Mo(Tp')(CO) $_{2}$ (PMe $_{3}$ )] 和 XBr $_{2}$ (SIdipp) 以 2:1 的摩尔比反应，得到不对称的化合物 G。G 中一条 X-Mo 长 228.7 pm，另一条则长 243.8 pm，且两个 Mo 均符合 EAN 规则。G 和丁炔发生取代反应，得到 C $_{2v}$ 对称性的 F。F 不含磷元素。（Tp'：HB[cyclo-C $_{3}$ N $_{2}$ (H)(CH $_{3}$ ) $_{2}$ ] $_{3}$ ）

提示：Van't Hoff/Le Bel 规则认为，四价碳原子采取四面体构型，可能存在不对称碳原子的情况。

1-3-1 给出 F 和 G 的结构式。

1-3-2 从规则前提角度考虑，解释称 F 是 “反 Van't Hoff/Le Bel 规则” 的原因。

## 参考答案

## 第1题（23分）

1-1 设 X 的原子量为 $Ar(x)$ ; 由 pV = nRT，得出消耗氧气的物质的量为： $7.254 \times 10^{-3} \times 1.013 \times 10^{5} / (8.314 \times 298.15) \times 0.21 = 6.225 \times 10^{-2} \, mol$ $XH_{n} + n/2 O_{2} = n/2H_{2}O + XO_{n/2}$ ，从 n = 1 开始逐渐代入，有：

n = 1, $n(xH_{n}) = 0.1245 \, \text{mol}$ , $Ar(x) = 7.024$ ，不合理；

n = 2, $n(xH_{n}) = 6.225 \times 10^{-2} \, \text{mol}$ , $Ar(x) = 14.05$ ，为 N，不合理；

n = 3, $n(xH_{n}) = 4.150 \times 10^{-2} \, \text{mol}$ , $Ar(x) = 21.07$ ，不合理；

n = 4, $n(xH_{n}) = 3.113 \times 10^{-2} \, \text{mol}$ , $Ar(x) = 28.09$ ，为 Si, $SiH_{4}$ 合理；

n = 5, $n(xH_{n}) = 2.490 \times 10^{-2} \, \text{mol}$ , $Ar(x) = 35.12$ ，为 Cl，不合理…

## 因此 $\mathbf{X}$ 是硅。（2分）

电子物质的量为 $2.787 \times 10^{-4} \mathrm{~g} / [(9.109 \times 10^{-31} \times 10^{3}) \mathrm{~g} \times 6.022 \times 10^{23} \mathrm{~mol}^{-1}] = 0.5080 \mathrm{~mol}$ ，由于 $\mathbf{X}$ 是硅， $\mathbf{A}$ 中含有 $1 + 6 + 7 + 14 = 28$ 个电子，故 $n_{(\mathbf{A})} = 1.814 \times 10^{-2} \mathrm{~mol}$ 每克 $\mathbf{A}$ 的物质的量为 $1 / M_{(\mathbf{A})}$ ，代入得 $M_{(\mathbf{A})} = 55.11$ ，结合四原子分子以及制备方式，可知 $\mathbf{A}$ 为HCNSi。（1分）
