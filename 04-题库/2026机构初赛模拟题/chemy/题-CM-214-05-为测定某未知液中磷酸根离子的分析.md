# 题-CM-214-05-为测定某未知液中磷酸根离子的分析

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-1-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（8 分）

为测定某未知液中磷酸根离子的分析浓度，向体积为 V<sub>0</sub> (mL)的未知液中加入浓度 c<sub>1</sub>(mol/L)、

![](images/ec487d2112321b50b11cb57e8729f56cfadcf29924d0f6592a55c8165fa9d10c.jpg)

水磷酸镁铵的摩尔质量为 M (g/mol)。可忽略 <sup>32</sup>P 对六水磷酸镁铵摩尔质量产生的影响。

**5-1** 设未知液体系 pH = 10.0，写出反应 1 的离子反应方程式。

**5-2** 写出反应 2 和反应 3 的离子反应方程式。

**5-3** 写出 <sup>32</sup>P 衰变的核反应方程式(标明各粒子质量数和电荷数)。

**5-4** 写出未知液中磷酸根离子的分析浓度 c (mol/L)的计算式。

## 参考答案

**5-1** Mg<sup>2+</sup> + NH<sub>3</sub> + HPO<sub>4</sub><sup>2-</sup> + 6H<sub>2</sub>O = NH<sub>4</sub>MgPO<sub>4</sub>·6H<sub>2</sub>O（1 分）

**5-2** NH<sub>4</sub>MgPO<sub>4</sub>·6H<sub>2</sub>O + H<sub>2</sub>EDTA<sup>2-</sup> = MgEDTA<sup>2-</sup> + NH<sub>4</sub><sup>+</sup> + H<sub>2</sub>PO<sub>4</sub><sup>-</sup> + 6H<sub>2</sub>O（1 分）NH<sub>4</sub>MgPO<sub>4</sub>·6H<sub>2</sub>O + 3H<sup>+</sup> = Mg<sup>2+</sup> + NH<sub>4</sub><sup>+</sup> + H<sub>3</sub>PO<sub>4</sub> + 6H<sub>2</sub>O（1 分）磷酸写成磷酸一氢根，可不扣分。

**5-3** <sup>32</sup><sub>15</sub>P → <sup>32</sup><sub>16</sub>S + <sup>0</sup><sub>-1</sub>e（1 分）

**5-4** c = 1000yA<sub>0</sub>/AMV<sub>0</sub> – c<sub>1</sub>V<sub>1</sub>/V<sub>0</sub>（4 分）
