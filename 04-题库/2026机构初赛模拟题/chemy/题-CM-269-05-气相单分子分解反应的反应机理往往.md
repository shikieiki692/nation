# 第 5 题 （12 分）

气相单分子分解反应的反应机理往往按照下图所示机理进行：

$$
\mathsf { A } + \mathsf { A } \frac { k _{ 1 } } { \mathsf { k } _{ - 1 } } \mathsf { A } ^{ \star } + \mathsf { A }
$$

5-1 依据上述描述， 直接写出气相单分子分解反应的反应速率方程。

5-1

$$
- \frac { d [ \mathrm { A } ] } { d t } = \frac { k _{ 1 } k _{ 2 } [ \mathrm { A } ] ^{ 2 } } { k _{ - 1 } [ \mathrm { A } ] + k _{ 2 } }
$$

（1 分）

5-2 分别写出气相单分子分解反应在低压和高压下两种极限情况下反应速率方程的近似式。

5-2

At high pressures, the number of A molecules per unit volume is large, and deactivation of $\mathsf { A } ^{ * }$ can occur by frequent collisions with other molecules ofA. Under these conditions, we will consider the rate of deactivation

of $\mathbf { A } ^{ * }$ to be large compared to the rate of decomposition. Therefore, $k _{ - 1 } [ \mathrm { A } ] > > k _{ 2 }$ and

$$
- { \frac { d [ \boldsymbol { \mathsf { A } } ] } { d t } } = { \frac { k _{ 1 } k _{ 2 } [ \boldsymbol { \mathsf { A } } ] ^{ 2 } } { k _{ - 1 } [ \boldsymbol { \mathsf { A } } ] + k _{ 2 } } } \approx { \frac { k _{ 1 } k _{ 2 } [ \boldsymbol { \mathsf { A } } ] ^{ 2 } } { k _{ - 1 } [ \boldsymbol { \mathsf { A } } ] } } = k [ \boldsymbol { \mathsf { A } } ]
$$

where $k = k _{ 1 } k _{ 2 } / k _{ - 1 }$ Therefore, at relatively high pressure where [A] is high, the reaction appears to be unimolecular (first-order) in [A].

Atlow pressures ofA, the rate of decomposition ofA\* is greater than the rate ofits deactivation by collision with A because there are fewer molecules ofA available Under these conditions, the increase in vibrational energy can cause bond rupture and decomposition. Therefore, in this case, $k _{ 2 } > > k _{ - 1 } [ \mathrm { A } ]$ and

$$
- \frac { d [ \boldsymbol { \mathrm { A } } ] } { d t } = \frac { k _{ 1 } k _{ 2 } [ \boldsymbol { \mathrm { A } } ] ^{ 2 } } { k _{ 2 } } = k _{ 1 } [ \boldsymbol { \mathrm { A } } ] ^{ 2 }
$$

（每个式子1 分，共2 分）
