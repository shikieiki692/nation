# 题-CM-66-05-氢是元素周期表中半径最小的元

## 题目

### 第 5 题（12 分）

氢是元素周期表中半径最小的元素， 同时也是仅利用 $s$ 轨道成键的元素， 因此在成键方面具有许多有趣的性质。

5-1 氢在与高电负性的原子成键时， 可以和另一高电负性的原子形成氢键。

5-1-1 现已知的最强氢键存在于 $\mathrm { HF } _{ 2 } \mathrm { \cdot }$ -离子中，其键能高达 $161.5 \mathrm { kJ / mol }$ 。 $\mathrm { HF } _{ 2 }$ -的分子轨道可以用 $3 c { - } 4 e$ 键来描述， 请画出其中的轨道重叠情况， 并给出其定性分子轨道能级图。
在于HF2-离子中，其键能高达161.5 kJ/mol。HF2-的分子轨道可以用3c-4e 键来描

5-1-2 请解释如下图所示的物质有强碱性的原因。

${ \ } 5 { - } 2 \ \mathrm { H } _{ 2 }$ 分子有较大的键解离能， 只有在 $2000 \mathrm { K }$ 以上才能明显的解离成H 原子。 下表列出了不同温度下 $\mathrm { H } _{ 2 }$ 的解离百分比， 体系总压均为 $1 \ \mathrm { bar } = 100 \ \mathrm { kPa }$ ：

5-2-1 根据范特霍夫方程， 计算 $\mathrm { H } _{ 2 }$ 解离的反应焓变。

求得  $\Delta H=460\ kJ/mol$ （1 分）
