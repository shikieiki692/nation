# 题-CM-239-05-51Zn的配合物一种Zn元素的配

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-1-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（12 分）

**5-1** Zn 的配合物 一种 Zn 元素的配合物(记为 X)制备方法如下：向 3 mL 配体 L(结构如下图所示)的甲醇溶液中加入 Zn(ClO<sub>4</sub>)<sub>2</sub>·6H<sub>2</sub>O，将得到的混合物搅拌 15 min，之后加入 N-甲基甲酰胺(C<sub>2</sub>H<sub>5</sub>NO，简写为 NMF)，并继续搅拌 20 min。向透明溶液中加入约 40 mL 乙醚，再经后处理即得到 X。已知 X 的化学式为 ZnL<sub>x</sub>(NMF)<sub>y</sub>(ClO<sub>4</sub>)<sub>z</sub> (x、y、z 均为整数)，对 X 元素分析可知：C 28.56；H 4.48；N 9.44 (均为质量分数，%)。

![](images/dba6f8f63cd218fe0342e9a114e05fe8682ecb8517f82af57aafd602a605aee6.jpg)

**5-1-1** 指出上述制备实验中加入 40 mL 乙醚的目的。

**5-1-2** 通过计算与推理，推出 X 的化学式。

**5-1-3** 已知 X 中存在一组六元环氢键，且 X 中 Zn 为 5 配位，画出 X 的结构。

**5-2** pH 对 Zn 配合物结构的影响 配合物 A<sub>1</sub>存在如下电离平衡：

![](images/4b52bed83d8b7e457c06fb212b6071099b35c0ab3aa4b95c2d91b04fe0d3ed0b.jpg)

A<sub>1</sub>电离出一个质子后将会形成配合物 A<sub>2</sub>。对二者分别进行红外光谱测定，发现 A<sub>1</sub>中 C=O的吸收峰为 1663 cm<sup>-1</sup>， A<sub>2</sub>中 C=O 的吸收峰为 1572 cm<sup>-1</sup>。

**5-2-1** 画出 A<sub>2</sub>的结构。

**5-2-2** 可以通过分光光度法测定 A<sub>1</sub>的电离平衡常数 K<sub>a</sub>。在 325 nm 的波长，液层厚度 b = 1 cm 下，测定不同 pH 下分析浓度为 1.00 × 10<sup>-4</sup> mol/L 的 A<sub>1</sub>溶液的吸光度 A，得到下表所示

![](images/6abe02b72f58e76cdfe147c154845246ffde65d03cf72e24fe37b0985c6f6178.jpg)

忽略配体的解离，计算 A<sub>1</sub>的电离平衡常数 K<sub>a</sub>。(提示：朗伯-比尔方程 A = εbc，A 吸光度；ε 摩尔吸光系数；b 光通过溶液的路径长；c 溶液浓度)。

## 参考答案

**5-1-1** 使溶液中的固体析出（1 分），使得后处理得以正常进行。

**5-1-2**（共 4 分）

配体 L 的分子式为 C<sub>12</sub>H<sub>21</sub>N<sub>3</sub>S<sub>2</sub>，NMF 的分子式为 C<sub>2</sub>H<sub>5</sub>NO

由于 L 和 NMF 均为中性配体，且 Zn 为+2 氧化态，故 z = 2（1 分）

故 X 的分子式为 ZnC<sub>(12x + 2y)</sub>H<sub>(21x + 5y)</sub>N<sub>(3x + y)</sub>O<sub>(y + 8)</sub>S<sub>2x</sub>Cl<sub>2</sub>（1 分）

X 的相对质量 M = 65.38 + 12.01 × (12x + 2y) + 1.01 × (21x + 5y) + 14.01 × (3x + y) + 16.00 ×

(y + 4) + 32.07 × 2x + 35.45

由元素分析数据可得以下三式：

0.2856 = 12.01 × (12x + 2y) / M

0.0944 = 14.01 × (3x + y) / M

0.0448 = 1.01 × (21x + 5y) / M

（1 分）

综合以上三式，解得整数解 x = 1，y = 1，故 X 的化学式为 ZnL(NMF)(ClO<sub>4</sub>)<sub>2</sub>（1 分）

**5-2-2**（共 3 分）

在 pH = 7.8 下，A<sub>1</sub>和 A<sub>2</sub>两种物种均存在，设二者摩尔吸光系数分别为 ε<sub>1</sub>和 ε<sub>2</sub>，则有：

A = ε<sub>1</sub>b[A<sub>1</sub>] + ε<sub>2</sub>b[A<sub>2</sub>] = ε<sub>1</sub>bc<sub>0</sub>[H<sup>+</sup>] / (K<sub>a</sub> + [H<sup>+</sup>]) + ε<sub>2</sub>bc<sub>0</sub>K<sub>a</sub> / (K<sub>a</sub> + [H<sup>+</sup>])（1 分）

设 pH = 6.2 和 pH = 11.0 下溶液吸光度分别为 A<sub>1</sub>和 A<sub>2</sub>，则有：

pK<sub>a</sub> = -lg[(A<sub>1</sub> - A) / (A – A<sub>2</sub>)] + pH（1 分）

带入数据得 pK<sub>a</sub> = 7.06，则 K<sub>a</sub> = 8.7 × 10<sup>-8</sup>（1 分）
