# 题-CM-60-22-将金属镧与第三周期非金属单质

## 题目

### 第 22 题 本题前几个问题难度不大，但 5-4 一问却饱受争议。根据题目所给信息，通过猜测得出 5-4 的正确答案难度并不大（这也是与实验事实符合的），但是若要判断是否能够通过严格的逻辑推理和论证得出 5-4 的答案，则可能需要读者对等效点系、化学环境、空间群等概念具有一定的了解，并且需要较大的思考量。在本题答案中，笔者给出了自己对这一问题的鄙陋、浅薄的分析。笔者认为，这一问题的思考与解答已经远远远远超过竞赛对晶体结构的要求，因此对该问题没有太大兴趣的读者大可不必在这一问题上过分消耗精力。（8 分）

将金属镧与第三周期非金属单质 X 混合加热至 $1080^{\circ}$ C 以上，得到一种含镧 69.16% 的抗磁性粉末 A。实验表明，A 中阳离子仅为 $La^{3+}$ ，而阴离子有两种，两种阴离子数目相同，且均为由奇数个原子连接而成的无支链的链状阴离子。

22-1 写出能体现 A 结构特点的化学式。

22-3 已知 A 为单斜晶系的晶体，其晶胞参数 $a = 888.3 \, pm$ ， $b = 1394.2 \, pm$ ， $c = 882.5 \, pm$ ， $\beta = 90.15^{\circ}$ ，密度 $\rho = 4.86 \, g \cdot cm^{-3}$ 。计算一个晶胞中 $La^{3+}$ 的数目。

22-4 已知在 A 的晶体中，La 有 4 种化学环境，X 有 8 种化学环境，据此判断：A 中的 La-X 键共有几种键长？简述判断理由。

晶体结构中，能通过对称要素的变换作用相互重复而联系在一起的一组几何点叫做等效点系。例如，现有一单斜晶体，其对称元素只有一沿着 b 方向的 $C _{ 2 }$ 轴，那么点 $( \mathbf { x } , \mathbf { y } , z )$ 绕 $C _{ 2 }$ 轴旋转后坐标为点 $( 1 \mathrm { - x } , \mathrm { y } , 1 \mathrm { - z } )$ ，它们就是一组化学环境完全相同的点，也即它们构成等效点系。因此，若想完整描述该晶体的结构，并不需要得知整个晶胞的结构；而是只需得知 1/2个晶胞的内容和该晶体中所有的对称元素，即可通过对称操作得知整个晶体的结构。这 1/2个晶胞就被称为这个晶体的“不对称单位”。

由上述分析可知，“化学环境”的概念， 其实是和“等效点系”、“不对称单位”联系在一起的。我们以前曾经听过这样一种描述：

返回到上面只有 $C _{ 2 }$ 轴的晶胞。设这个晶胞中， 点 $( \mathrm { x } , \mathrm { y } , \mathrm { z } )$ 有一原子，则点(1-x, y, 1-z)处必有一原子，也就是说，原子的数目是与等效点的数目相等的。但是很明显也有例外：如果这个原子恰好被镜面、旋转轴或对称中心所穿过，那么这种原子的数目就会少于等效点的数目。如本晶胞 $( 1 / 2 , 1 / 2 , 1 / 2 )$ 这一点，这些被穿过的位置被称为“特殊位置”。

在搞清楚上述有关化学环境、 等效点系的概念之后， 我们反观本题： 若想解决同一个

La 所连接的 9 个 P 的化学环境是否相同的问题，只需考虑是否有某种对称元素能将这 9 个P 原子相联系即可。若考察 $\mathrm { LaP } _{ 2 }$ 一个晶胞，则 16 个 La 共有 4 种环境，32 个P 共有8 种环境，因此可推得每种环境的每种原子都有 4 个。根据以上知识可知，该晶体的对称性仅有可能有以下两种情况：

（a） 该晶胞中一般等效点数目为 4，所有的原子均位于一般等效点的位置；如果这一假设成立，那么必然没有对称元素穿过La 原子，进而同一La 原子形成的9 根La-P 键化学环境不同，La 共4 种环境，故La-P 键有36 种键长。（b）该晶胞中一般等效点数目为 8，所有的原子均位于特殊等效点的位置。这要求这一晶体中所有的原子都被对称元素穿过，显然不太可能。为进一步说明上述（b）假设的不合理性，笔者查阅了单斜晶系晶体的所有可能的空间群，发现即使对称性最高的单斜晶体，其晶胞中一般等效点的数目也是4，亦即单斜晶体的晶胞中一般等效点的数目不会大于 4。

综上， La-P 键共有36 种键长。

但是在此，笔者想提出另外一个问题：是否化学环境不相同的共价键，其键长不可能完全相同，而是或多或少有一点的差别（化学环境不同，键长是否一定不同）？笔．者．认．为．，在分子型化合物和大多数晶体中，化学环境不同，键长一定不同（这有点类似于，在数轴的某个区间上任取两点，这两点重合的概率为零）；但是在少数晶体中也会出现特殊情况：例如，有一种金属氮化物的化学式为 $\mathrm { M } _{ 3 } \mathrm { N } _{ 4 }$ ，其晶胞结构可看做由 NaCl 结构移走顶点的Na 原子而得到。显然，在该晶体中，M-N 键有两种环境，一种是由面心的 M 与体心六配位的N 连接而成，另一种是由面心的 M 与棱心四配位的 $\mathrm { ~  ~ N ~ }$ 连接而成。不难求出，这两种 M-N 键长均为 $\scriptstyle a / 2$ ，是等长的。此处笔者仍对该结论的合理性保持质疑态度，希望能起到抛砖引玉的作用，若读者对该问题有更好的看法， 欢迎读者讨论纠正
