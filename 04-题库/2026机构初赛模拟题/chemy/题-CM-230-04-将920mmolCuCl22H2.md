# 题-CM-230-04-将920mmolCuCl22H2

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-4-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（17 分）

将 9.20 mmol CuCl<sub>2</sub>·2H<sub>2</sub>O、9.20 mmol 吡唑(结构如下图左所示)、9.20 mmol NaOH 和 3.06

mmol PPNCl(结构如下图右所示)混合，在四氢呋喃中室温搅拌 16 h，溶液从最初的深绿色逐

渐变成深蓝色。待反应结束后，滤掉体系的不溶物，向滤液中加入一定量的乙醚，3 天后溶

液中析出蓝色晶体，经真空干燥即可得到三核铜配合物 X，产率为 57 %。已知 X 中 Cu 只

有一种化学环境；元素分析表明，X 中含 C 51.29，N 9.31，Cl 10.10 (%，均为质量分数)。

![](images/0cadda36d0e5224576cae48cc68704b11cfacb60caefbde0fb13bfab5a0481f7.jpg)

**4-1** 写出反应结束后滤掉的不溶物的主要成分(写出最主要的一种)。

**4-2** 通过计算与推理，推出 X 的化学式，写出 X 的制备反应方程式。

**4-3** 画出 X 阴离子的结构。

**4-4** 向 X 的四氢呋喃溶液中滴加少量的 PPNCl，溶液中有沉淀析出，对应于化合物 Y；若向

X 的四氢呋喃溶液中加入过量的 PPNCl，则不会有沉淀析出，得到的是另一种化合物 Z。Y

和 Z 均为与 X 结构类似的三核铜配合物，它们对应的阴离子具有相同的电荷数，但与 X 均

不同。写出 Y 和 Z 的化学式(需要体现其结构特点)。

## 参考答案

**4-1** NaCl（2 分）次主要的为 CuCl<sub>2</sub>

**4-2**（共 8 分）

由反应物加料比可知：n(Cu) : n(吡唑) : n(PPN) = 3 : 3 : 1（1 分）

因此可初步推断 X 的化学式为[C<sub>36</sub>H<sub>30</sub>P<sub>2</sub>N]<sup>+</sup>[Cu<sub>3</sub>(C<sub>3</sub>H<sub>3</sub>N<sub>2</sub>)<sub>3</sub>M]<sup>-</sup>（1 分）

由元素分析可知：

n(C) : n(N) = (14.01 / 0.0931) / (12.01 / 0.5129) = 45 : 7（1 分）

n(C) : n(Cl) = (35.45 / 0.1011) / (12.01 / 0.5129) = 45 : 3（1 分）

因此 X 中含 3 个 Cl，剩余相对质量 M = 16.9 g/mol，结合 Cu 的氧化态为+2，综合判断可知

对应于一个 OH<sup>-</sup>（1 分）

故 X 的化学式为[C<sub>36</sub>H<sub>30</sub>P<sub>2</sub>N][Cu<sub>3</sub>(C<sub>3</sub>H<sub>3</sub>N<sub>2</sub>)<sub>3</sub>Cl<sub>3</sub>(OH)]（1 分）

制备方程式为：3CuCl<sub>2</sub>·2H<sub>2</sub>O + 3C<sub>3</sub>H<sub>4</sub>N<sub>2</sub> + 3NaOH + PPNCl → [PPN][Cu<sub>3</sub>(C<sub>3</sub>H<sub>3</sub>N<sub>2</sub>)<sub>3</sub>Cl<sub>3</sub>(OH)] +

2NaCl + 4H<sub>2</sub>O + HCl（2 分）NaOH 为定量加入，因此方程式右边出现生成的 HCl。

（3 分）

不要求画出 Cu 的立体构型

**4-4** Y：[PPN]<sub>2</sub>[Cu<sub>3</sub>(μ<sub>3</sub>-O)(C<sub>3</sub>H<sub>3</sub>N<sub>2</sub>)<sub>3</sub>Cl<sub>3</sub>]（2 分）；Z：[PPN]<sub>2</sub>[Cu<sub>3</sub>(μ<sub>3</sub>-Cl)<sub>2</sub>(C<sub>3</sub>H<sub>3</sub>N<sub>2</sub>)<sub>3</sub>Cl<sub>3</sub>]（2 分）

不要求表示出配体种类（例如 μ<sub>3</sub>-O），但不能合并写（例如 Z 写成“Cl<sub>5</sub>”则不得分）
