### 第 8 题 高价碘试剂 （30 分， 占 $19 \%$

PIDA(碘苯二乙酸， ${ \mathrm { PhI } } ( \mathrm { OAc } ) _{ 2 }$ 及其衍生物是常见的相对温和的氧化剂； 它们较为常见的用途是将一级醇氧化为对应的醛或酮。 以下是与 PIDA 相关的两个转换反应， 在思考其反应机理的基础上，完成下列问题。

有兴趣的选手可以思考以下问题：

8-4-3 思考 2-氨基吡啶和 2-氨基喹啉的结构差异，并根据实验结果尝试解释反应以不同路径进行的原因。

8-4-3 在反应条件下，2-氨基吡啶的还原性强于对二甲苯，而 2-氨基喹啉的还原性弱于对二甲苯，因此 2-氨基吡啶首先和 PIDA 反应，而后发生芳香亲电取代反应。而在 2-氨基喹啉作为亲核试剂的体系中，对二甲苯先被氧化成苄基正离子进行后续反应。
