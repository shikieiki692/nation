# 题-CM-215-01-11在低温下的乙二醇二甲醚中叠氮

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-4-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（10 分）

**1-1** 在低温下的乙二醇二甲醚中，叠氮化钠与三氯化氮作用，仅得到 2 种产物。

**1-2** 在有机溶剂中，四溴化硒与氨作用，生成 Se<sub>4</sub>N<sub>4</sub>和 Se(摩尔比 1:2)。

**1-3** 八羰基合二钴与一氧化氮反应，生成单核四面体配合物。

**1-4** 化合物 NH<sub>4</sub>CuSO<sub>3</sub>在稀硫酸中发生分解，生成铜粉并得到蓝色溶液。

**1-5** 钍的难溶盐 KTh<sub>4</sub>(IO<sub>3</sub>)<sub>17</sub>与含有过量 KI 的酸性溶液反应，生成 Th<sup>4+</sup>等产物。

## 参考答案

3NaN<sub>3</sub> + NCl<sub>3</sub> = 5N<sub>2</sub> + 3NaCl（2 分）

6SeBr<sub>4</sub> + 32NH<sub>3</sub> = Se<sub>4</sub>N<sub>4</sub> + 2Se + 24NH<sub>4</sub>Br + 2N<sub>2</sub>（2 分）

如果产物写成 Se<sub>8</sub>，对应的化学方程式书写正确，不扣分

Co<sub>2</sub>(CO)<sub>8</sub> + 2NO = 2Co(CO)<sub>3</sub>NO + 2CO（2 分）

2NH<sub>4</sub>CuSO<sub>3</sub> + 2H<sub>2</sub>SO<sub>4 </sub>= CuSO<sub>4</sub> + Cu + 2SO<sub>2</sub> + (NH<sub>4</sub>)<sub>2</sub>SO<sub>4 </sub>+ 2H<sub>2</sub>O（2 分）

KTh<sub>4</sub>(IO<sub>3</sub>)<sub>17</sub> + 85I<sup>-</sup> + 102H<sup>+</sup> = 4Th<sup>4+</sup> + 51I<sub>2</sub> + 51H<sub>2</sub>O（2 分）

写成化学方程式并配平，也可得分。

若写离子方程式但写成 KTh<sub>4</sub>(IO<sub>3</sub>)<sub>17</sub>离子形式，不得分。
