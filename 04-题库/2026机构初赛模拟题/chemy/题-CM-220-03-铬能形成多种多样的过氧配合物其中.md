# 题-CM-220-03-铬能形成多种多样的过氧配合物其中

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-10-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（12 分）

铬能形成多种多样的过氧配合物。其中最为人所熟知的是将 Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup>-H<sup>+</sup>-H<sub>2</sub>O<sub>2 </sub>在水溶液中混合且用乙醚进行萃取<sub> </sub>(反应 1)而得到的化合物 A，A 呈抗磁性，Cr 的配位原子数为 6，具有1 个乙醚配体。若用弱酸性的重铬酸钾溶液与 H<sub>2</sub>O<sub>2</sub>反应，生成蓝紫色晶体 B<sup> </sup>(反应 2)；它是1:1 型盐，呈抗磁性；阴离子为铬的单核配离子，铬的配位原子数为 6。B 不稳定，易爆炸性分解，固体产物为 KCrO<sub>2 </sub>(反应 3)。若用重铬酸铵代替重铬酸钾，也能得到类似于 B 的 1:1型盐；但该盐热分解，产物为 Cr<sub>2</sub>O<sub>3</sub>和 N<sub>2</sub>等<sub> </sub>(反应 4)。若用碱性的铬酸铵溶液与 30%H<sub>2</sub>O<sub>2</sub>溶液在室温下作用，生成红棕色晶体 C<sup> </sup>(反应 5)；它是 3:1 型盐，磁矩为 1.7 μ<sub>B</sub>；其阴离子为铬的单核配离子，铬的配位原子数为 8。若制备 C 时的反应温度为 60°C，反应毕冷却，则不能得到 C 而是得到棕色晶体 D<sup> </sup>(反应 6)；它是电中性单核配合物，磁矩为 2.8 μ<sub>B</sub>，铬的配位原子数为 7，配体仅有 2 种(配位原子分别为 N 和 O)。D 在水溶液中与 KCN 反应，生成3:1 型盐 E<sup> </sup>(反应 7)；E 阴离子的磁矩和铬的配位原子数均与 D 的相同。

**3-1** 写出 A~E 的化学式。

**3-2** 写出反应 1<sub> </sub>~<sub> </sub>反应 7 的方程式(要求系数为最简整数比)。

## 参考答案

**3-1** A CrO(O<sub>2</sub>)<sub>2</sub>·(CH<sub>3</sub>CH<sub>2</sub>)<sub>2</sub>O B K[CrO(O<sub>2</sub>)<sub>2</sub>(OH)] C (NH<sub>4</sub>)<sub>3</sub>[Cr(O<sub>2</sub>)<sub>4</sub>]

D Cr(O<sub>2</sub>)<sub>2</sub>(NH<sub>3</sub>)<sub>3</sub> E K<sub>3</sub>[Cr(O<sub>2</sub>)<sub>2</sub>(CN)<sub>3</sub>]（各 1 分）

**3-2**

反应 1：Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> + 2H<sup>+</sup> + 4H<sub>2</sub>O<sub>2</sub> + 2(CH<sub>3</sub>CH<sub>2</sub>)<sub>2</sub>O = 2CrO<sub>5</sub>·(CH<sub>3</sub>CH<sub>2</sub>)<sub>2</sub>O + 5H<sub>2</sub>O

反应 2：Cr<sub>2</sub>O<sub>7</sub><sup>2-</sup> + 2K<sup>+</sup> + 4H<sub>2</sub>O<sub>2</sub> = 2K[CrO(O<sub>2</sub>)<sub>2</sub>(OH)] + 3H<sub>2</sub>O

反应 3：4K[CrO(O<sub>2</sub>)<sub>2</sub>(OH)] = 4KCrO<sub>2</sub> + 2H<sub>2</sub>O + 7O<sub>2</sub>

反应 4：2NH<sub>4</sub>[CrO(O<sub>2</sub>)<sub>2</sub>(OH)] = Cr<sub>2</sub>O<sub>3</sub> + N<sub>2</sub> + 2O<sub>2</sub> + 5H<sub>2</sub>O

反应 5：6NH<sub>4</sub><sup>+</sup> + 2OH<sup>-</sup> + 2CrO<sub>4</sub><sup>2-</sup> + 9H<sub>2</sub>O<sub>2</sub> = 2(NH<sub>4</sub>)<sub>3</sub>Cr(O<sub>2</sub>)<sub>4</sub> + O<sub>2</sub> + 10H<sub>2</sub>O

反应 6：3NH<sub>4</sub><sup>+</sup> + CrO<sub>4</sub><sup>2-</sup> + 3H<sub>2</sub>O<sub>2</sub> + OH<sup>-</sup> = Cr(O<sub>2</sub>)<sub>2</sub>(NH<sub>3</sub>)<sub>3</sub> + O<sub>2</sub> + 5H<sub>2</sub>O

反应 7：Cr(O<sub>2</sub>)<sub>2</sub>(NH<sub>3</sub>)<sub>3</sub> + 3KCN = K<sub>3</sub>[Cr(O<sub>2</sub>)<sub>2</sub>(CN)<sub>3</sub>] + 3NH<sub>3</sub>（各 1 分）

反应 5 和反应 6 中，反应物写 NH<sub>3</sub>，配平，也可得分。

将 E 写成 K<sub>3</sub>[Cr(CN)<sub>7</sub>]，不得分。
