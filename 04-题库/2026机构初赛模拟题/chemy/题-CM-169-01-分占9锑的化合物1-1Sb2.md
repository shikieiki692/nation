# 第 1 题（16 分， 占 $9 \%$ ） 锑的化合物
分，占9 %）锑的化合物1-1 Sb2S3 用

$\mathbf { 1 - 1 } \mathsf { Sb } _{ 2 } \mathsf { S } _{ 3 }$ 用途广泛， 可被用作玻璃橡胶的添加剂、 防潮剂等。一种较方便制备 $\mathrm { Sb } _{ 2 } \mathrm { S } _{ 3 }$ 的方法是加热 $\mathrm { \ SbCl { 3 } }$ 和硫代硫酸钠溶液， 二者计量比为1：3， 反应仅产生一种含氧酸盐。 写出该反应的化学方程式。

`{ \bf 1 } { \cdot } 2 \ \mathrm { SbF } _{ 3 }` 与碱金属的氟化物反应可以得到各式各样的含氟配离子。 譬如， ${ \mathrm { SbF } } _{ 3 }$ 和 KF 反应可以得到盐 $\mathsf { \pmb { A } } ( w ( \mathrm { F } ) = 32.08 \ \% )$ ， 盐 $\pmb { \mathsf { A } }$ 的阴离子中含有一个八元环状结构； SbF3 和 CsF 反应可以得到盐 $\mathsf { B } ( w ( \mathrm { F } ) = 26.10 \ \% )$ ， 盐 $B$ 的阴离子中 Sb 的化学环境相同。 画出盐A、盐 B 阴离子的结构。 $\bigcirc$

1-3 主族金属元素间形成的多重键是当前研究的热点。 2022 年， 德国科学家合成了一系列含有 Sb-Sb 双键的化合物： 他们将 $\mathrm { [ \mathbf { L } ( Cl ) Ga ] _{ 2 } SbCl }$ 和 MeNHCMe （结构如下图所示）在一定条件下按计量比2：1 反应，得到计量比为1：2 的含有Sb-Sb 双键的化合物C 与Ga 的单核配合物D，C 中有一个Sb 不满足八隅律。C 中的Sb-Sb 双键可在一分子 $M e _{ N H C } = M e$ 的作用下发生裂解， 该反应仅生成一种化合物E。 画出 C、 D 和E 的结构。
