# 题-CM-64-03-3-1一定条件下低氧化态过渡

## 题目

### 第 3 题（11 分）

3-1 一定条件下，低氧化态过渡金属配合物与卤代烯烃发生亲核取代反应， 可以得到烯丙基络合物。例如 $\mathrm { { Na } [ \mathrm { { Mn } ( \mathrm { { CO } ) _{ 5 } ] } } }$ 与烯丙基氯反应，先生成中间体A，A 脱除一分子一氧化碳得到最终产物B。 请画出 $\pmb { \mathsf { A } }$ 和B 的结构示意图。

3-2 间三氮三硼烷(6)， 又称“无机苯”， 化学式 $\mathrm { B } _{ 3 } \mathrm { N } _{ 3 } \mathrm { H } _{ 6 }$ ， 是苯的等电子体。间三氮三硼烷(6)在酸性条件下可被质子化，得到 $\mathrm { B } _{ 3 } \mathrm { N } _{ 3 } \mathrm { H } _{ 7 } { } ^{ + }$ ； 也可在碱性条件下被拔除质子，得到 $\mathrm { B } _{ 3 } \mathrm { N } _{ 3 } \mathrm { H } _{ 5 } \mathrm { \bar { \Omega } }$ 。请分别画出这两种离子的结构。

3-3 丁腈橡胶(NBR)是一种合成橡胶， 其高弹性的特点使之成为制造一次性实验手套的原料。一般而言，聚合物中氰基含量越高，其抗腐蚀性就越强，同时弹性就越差。制备丁腈橡胶时，单体浓度和反应条件的不同，会使产生的丁腈橡胶呈现不同的结构。最终所得的聚合物种类也会随之变化，造成所得的聚合物种类纷繁复杂，最终的产物中不具有简单的重复单元。也正因如此， 丁腈橡胶作为一个笼统的聚合物， 并没有IUPAC 命名法系统命名。

3-3-1 以下哪种是丁腈橡胶？

(a)丁二烯与乙腈的共聚物 (b)丁二烯与2-丙烯腈的共聚物(c)2-丁烯腈的均聚物 (d)2-丙烯腈和乙烯的共聚物

3-3-2 以下哪种(些)溶剂可以穿透丁腈手套？

(a)石油醚 (b)乙醇 (c)二氯甲烷 (d)乙酸乙酯；

3-3-3 丁腈橡胶手套不慎沾上浓硝酸会变色， 试解释原因。

-3-4 除了橡胶外， 塑料也是三大合成材料之一。 以下哪种塑料燃烧会释放剧毒的二噁英？

(a)聚酯纤维 (b)双酚 A (c)聚丙烯 (d)聚氯乙烯
