# 题-CM-253-01-11IF3在过量水中水解12碱性

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-26-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（11 分）

**1-1** IF<sub>3</sub>在过量水中水解。

**1-2** 碱性条件下，用臭氧处理含有氰根的废水以消毒。

**1-3** 工业上将尿素和纯碱共热，制备一种 1:1 型离子化合物。将其隔绝空气加热至 700℃，得到纯碱和一种剧毒的钠盐，仅释放出两种相对分子质量很接近的常见气体。

**1-4** 用 Na<sub>2</sub>CO<sub>3</sub>溶液吸收有污染的 SiF<sub>4</sub>气体，F 元素未留在溶液中。

**1-5** 古埃及人用高岭土(Al<sub>2</sub>Si<sub>2</sub>O<sub>5</sub>(OH)<sub>4</sub>)与硫磺、纯碱按一定比例混合共热，得到蓝色颜料Na<sub>8</sub>[Al<sub>6</sub>Si<sub>6</sub>O<sub>24</sub>](S<sub>3</sub>)<sub>2</sub>，图坦卡门面具上的蓝色即使用了这种颜料。

## 参考答案

**1-1** 5IF<sub>3</sub> + 9H<sub>2</sub>O = I<sub>2</sub> + 3HIO<sub>3</sub> + 15HF（2 分）

**1-2** 2CN<sup>-</sup> + 5O<sub>3</sub> + H<sub>2</sub>O = 2HCO<sub>3</sub><sup>-</sup> + N<sub>2</sub> + 5O<sub>2</sub>（2 分）

**1-3** 2CO(NH<sub>2</sub>)<sub>2</sub> + Na<sub>2</sub>CO<sub>3</sub> = 2NaOCN + H<sub>2</sub>O + 2NH<sub>3</sub> + CO<sub>2</sub>（1 分）

**1-4** 4Na<sub>2</sub>CO<sub>3</sub> + 3SiF<sub>4</sub> + 3H<sub>2</sub>O = 2Na<sub>2</sub>SiF<sub>6</sub> + H<sub>2</sub>SiO<sub>3</sub> + 4NaHCO<sub>3</sub>（2 分）

**1-5** 6Al<sub>2</sub>Si<sub>2</sub>O<sub>5</sub>(OH)<sub>4</sub> + 13S + 8Na<sub>2</sub>CO<sub>3</sub> = 2Na<sub>8</sub>[Al<sub>6</sub>Si<sub>6</sub>O<sub>24</sub>](S<sub>3</sub>)<sub>2</sub> + SO<sub>2</sub> + 8CO<sub>2</sub> + 12H<sub>2</sub>O（2 分）
