# 题-CM-79-01-1-1将NO通入四羰基合钴酸

## 题目

### 第 1 题（10 分）

1-1 将 NO 通入四羰基合钴酸钠的中性溶液中，反应后溶液呈碱性。

1-2 往氯化亚铜浊液中加入硼砂水溶液，浊液颜色变红。

1-3 用过量的热氰化钠溶液溶解固体 $Au_{2}S_{3}$ ，反应没有气体生成。

1-4 过量的 $PCl_{5}$ 与 $NH_{3}$ 反应得到了两种离子化合物，两者阳离子中心原子均呈四面体构型，而阴离子均为单原子离子，且两者的比例为 1:12。若将 $PCl_{5}$ 换为 $PF_{5}$ ，则会得到另外两种截然不同的产物，其中一种产物中 P 的质量分数为 25.80%，而另一种产物为铵盐。

## 参考答案

1-1 $2\mathrm{NaCo}(\mathrm{CO})_{4} + 2\mathrm{NO} + 2\mathrm{H}_{2}\mathrm{O} = 2\mathrm{Co}(\mathrm{NO})(\mathrm{CO})_{3} + 2\mathrm{NaOH} + \mathrm{H}_{2} + 2\mathrm{CO}$ （2分）

1-2 $2\mathrm{CuCl} + \mathrm{Na}_{2}\mathrm{B}_{4}\mathrm{O}_{5}(\mathrm{OH})_{4} + \mathrm{H}_{2}\mathrm{O} = \mathrm{Cu}_{2}\mathrm{O} + 4\mathrm{B}(\mathrm{OH})_{3} + 2\mathrm{NaCl}$ （2分）

1-3 $\mathrm{Au}_2\mathrm{S}_3 + 10\mathrm{CN}^- = 2\mathrm{Au}(\mathrm{CN})_4^{3 - } + \mathrm{S}^{2 - } + 2\mathrm{SCN}^-$ （2分，写成 $\mathrm{Au}(\mathrm{CN})_2^-$ 也给分）

$$
1 - 45 \mathrm{PCl} _{5} + 16 \mathrm{NH} _{3} = [ \mathrm{P} (\mathrm{NPCl} _{3}) _{4} ] \mathrm{Cl} + 12 \mathrm{NH} _{4} \mathrm{Cl} (2 \text {分})
3 \mathrm{PF} _{5} + 4 \mathrm{NH} _{3} = \mathrm{PF} _{3} (\mathrm{NH} _{2}) _{2} + 2 \mathrm{NH} _{4} \mathrm{PF} _{6} (2 \text {分})
$$
