# 题-CM-69-01-1-1在液氨中被还原为单质

## 题目

### 第 1 题（8 分）

1-1 $\mathrm { PoCl } _{ 4 }$ 在液氨中被还原为单质。
1-2 铬铁矿 $[ \mathrm { Fe } ( \mathrm { CrO } _{ 2 } ) _{ 2 } ]$ 在空气中与纯碱煅烧， 反应中铬和铁均被氧化。
1-3 硬硼钙石 $\mathrm { \Gamma [ CaB _{ 3 } O _{ 4 } ( OH ) _{ 3 } \cdot H _{ 2 } O ] }$ 与硫酸加热反应，产生可滤出的石膏 $\mathrm { ( CaSO _{ 4 } { \cdot } 2 H _{ 2 } O ) }$ 沉淀。
1-4 联膦与铯(摩尔比3:5)在低温下反应得到一种铯盐，其阴离子为芳香性四核阴离子；同时
生成 $\mathrm { Cs } \mathrm { PH } _{ 2 }$ 和一种单质气体。
