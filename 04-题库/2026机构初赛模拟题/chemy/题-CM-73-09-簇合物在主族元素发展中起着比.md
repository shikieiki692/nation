# 题-CM-73-09-簇合物在主族元素发展中起着比

## 题目

### 第 9 题（15 分）

簇合物在主族元素发展中起着比较重要的作用，而且它们的结构往往都较为有趣。
9-1 有无配位溶剂的存在会影响簇合物的结构，如 $\{ \mathrm { Li } _{ 2 } [ \mathrm { C ( Nt - Bu ) } _{ 3 } ] \} _{ 2 }$ 。它在无配位溶剂存在时$\mathrm { ~ N ~ }$ 呈八面体分布，所有Li 化学环境相同。而在6 分子THF 存在下分解为阶梯状的结构，其中存在有三个四元环，其中有两种化学环境的 Li，配位数分别为3 和 4。
9-1-1 画出 $\mathrm { C ( Nt - Bu ) } _{ 3 } \mathrm{\Delta}^{2}$ -的结构式。
9-1-2 请给出二者的结构。
9-1-3 事实上 THF 对圆柱状结构的分解是逐步进行的，2 分子 THF 会在不破坏骨架的情况下对 Li 进行配位，请给出该中间体可能形成的几何异构体的数目并画出会继续进行分解形成最终产物的异构体的结构。
9-1-4 在6 个THF 溶剂合的结构中存在有3 配位的Li 和 3 配位的N，试解释为什么该N 和Li 没有结合而在4 个THF 溶剂合的中间产物中该 $\mathrm { \Delta N }$ 和 Li 进行了配位。
9-2 将足量的 $\mathfrak { n }$ -BuLi加入到 $\mathrm { P } _{ 2 } \mathrm { N } _{ 4 } \mathrm { H } _{ 2 } ( \mathrm { tBu } ) _{ 4 }$ 中可以得到一种分子量不低于700的笼状化合物。9-2-1 已知 $\mathrm { P } _{ 2 } \mathrm { N } _{ 4 } \mathrm { H } _{ 2 } ( \mathrm { tBu } ) _{ 4 }$ 中 $\mathrm { \Delta N }$ 和 $\mathrm{P}$ 均满足八隅律，且分子中含有四元环，并且在不考虑N 连接的端基取代基时存在有两个对称面，画出其结构。
9-2-2 产物笼状分子中仅含有6 个四边形和4 个六边形，并且只存在有一条四重反轴，请给出其结构。
