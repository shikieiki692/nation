# 题-CM-218-01-11MoS2是一种重要的润滑剂材

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-8-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（8 分）

**1-1** MoS<sub>2 </sub>是一种重要的润滑剂材料，常用 MoO<sub>3 </sub>与硫脲水热反应制备，反应有三种气体产生。

**1-2** 定量分析 Zn<sup>2+</sup>有许多化学方法，以下给出两个例子(本题中含 Zn<sup>2+</sup>溶液以 ZnSO<sub>4</sub>溶液为例)。

**1-2-1** 用亚铁氰化钾溶液滴定含 Zn<sup>2+</sup>溶液，生成 w(K) = 11.20%的氰亚铁酸锌钾沉淀。

**1-2-2** 微量法测定锌常使用间接滴定法，含 Zn<sup>2+</sup>溶液需要先与铁氰化钾和碘化钾反应。

**1-3** 在金属铅的生产过程中，可以通过碱性精炼法除去其中混杂的砷单质：在 425℃下，将熔融的粗铅通过 NaCl-NaOH 混合熔体，并不断加入 NaNO<sub>3</sub>作为氧化剂反应。已知每除去一当量的砷，理论需要消耗等当量的 NaNO<sub>3</sub>。

## 参考答案

**1-1** 3MoO<sub>3</sub> + 7SC(NH<sub>2</sub>)<sub>2</sub> + 7H<sub>2</sub>O → 3MoS<sub>2</sub> + 7CO<sub>2</sub> + 14NH<sub>3</sub> + SO<sub>2</sub>（2 分）

**1-2-1** 3ZnSO<sub>4</sub> + 2K<sub>4</sub>Fe(CN)<sub>6</sub> → K<sub>2</sub>Zn<sub>3</sub>[Fe(CN)<sub>6</sub>]<sub>2</sub> + 3K<sub>2</sub>SO<sub>4</sub>（2 分）

**1-2-2** 3ZnSO<sub>4</sub> + 2K<sub>3</sub>Fe(CN)<sub>6</sub> + 2KI → K<sub>2</sub>Zn<sub>3</sub>[Fe(CN)<sub>6</sub>]<sub>2</sub> + 3K<sub>2</sub>SO<sub>4</sub> + I<sub>2</sub>（2 分）

**1-3** 2As + 4NaOH + 2NaNO<sub>3</sub> → 2Na<sub>3</sub>AsO<sub>4</sub> + 2H<sub>2</sub>O + N<sub>2</sub>（2 分）
