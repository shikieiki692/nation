# 题-CM-81-07-在甲醇中铑的双核配合物与膦配

## 题目

### 第 7 题（9 分）

在甲醇中，铑的双核配合物 $Rh_{2}(CO)_{4}Cl_{2}$ 与膦配体 $Ph_{2}PCH_{2}CH_{2}OCH_{2}CH_{2}PPh_{2}$ (记为 $L^{1}$ ) 反应，可析出化学式为 $RhL^{1}(CO)Cl$ 的配合物。将 $RhL^{1}(CO)Cl$ 溶于氯仿，加入 $AgPF_{6}$ 充分反应，用甲醇析晶，得到化学式为 $[RhL^{1}(CO)]PF_{6}$ 的配合物。相同条件下，若换用膦配体 $Ph_{2}PCH_{2}CH_{2}(OCH_{2}CH_{2})_{3}PPh_{2}$ (记为 $L^{2}$ ) 进行实验，最终产物为配合物 $[RhL^{2}(CO)(H_{2}O)]PF_{6}$ ，X-射线衍射表明，其阳离子内存在氢键。

以上所有含铑的物种中，铑的配位构型均为平面四方，磷的化学环境均只有一种。

7-1 画出 $\mathrm{Rh}_{2}(\mathrm{CO})_{4} \mathrm{Cl}_{2}$ 的结构, 指出其中铑的价电子组态和杂化方式。

7-2 推出 $\mathrm{Rh}_{2}(\mathrm{CO})_{4}\mathrm{Cl}_{2}$ 中铑原子是否满足18电子规则。

7-3 画出 RhL $^{1}$ (CO)Cl 的结构。

7-4 画出 $[\mathrm{RhL}^{1}(\mathrm{CO})]^{+}$ 和 $[\mathrm{RhL}^{2}(\mathrm{CO})(\mathrm{H}_{2}\mathrm{O})]^{+}$ 的结构。
