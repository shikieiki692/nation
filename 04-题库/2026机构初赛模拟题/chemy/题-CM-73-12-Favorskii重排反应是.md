# 题-CM-73-12-Favorskii重排反应是

## 题目

### 第 12 题 《有机人名反应》 上的一个奇怪机理的实例

Favorskii 重排反应是最为经典的几个人名反应之一，该反应简单明了易懂，但是在特殊的条件下，其反应性又显得扑朔迷离。

Me O Me Br2, ${ \mathsf { CH } } _{ 3 } { \mathsf { CO } } _{ 2 } { \mathsf { H } }$ KOH, DMSO B Me Me 50°C, 1h $100^{ \circ } \mathsf { C }$ , 1h C11H20O2 Me Me

12-1 为了解释产物 B 的生成， 科研人员提出了电荷分离的中间体进行 $2 \pi$ 电环化的机理，已知 B 中没有Br， 画出化合物A 和 B 的结构式，并解释生成B 的选择性。

12-2 以下反应(生成化合物D)看似难以理解，实际上其也经历了一个电荷分离的中间体，并且正电荷高烯丙基正离子发生了重排反应。

![](images/1f026c0029ef855f95fa1b6fc93cfe77782471b60d93187c9361a39ac1bdda78.jpg)

C 和 D 未经分离， 同时进行下一步反应， C 发生重排得到了 E，D 未发生变化；E 和 D 未经分离， 同时进行下一步反应，均得到了化合物F。
12-2-1 画出化合物C、E 和F 的结构式(D 除外)。
12-2-2 画出生成D 的过程中经历的三个中间体的结构式。
12-2-3 画出由C 转化为E 的过程中经历的三个中间体的结构式。
