# 题-CM-106-03-将还原铁粉和沉降硫混合后用镁

## 题目

### 第 3 题（8 分）

将还原铁粉和沉降硫混合后用镁带引燃，制得了黑色块状的硫化亚铁。用此方法制得的硫化亚铁纯度较低，通常含有铁、硫以及惰性杂质。通过如下的实验方法（装置如右图）对制得的硫化亚铁的成分进行分析。

称取硫化亚铁样品 0.1749 g，移入装有 2.0 g NaHCO $_{3}$ 并装有恒压滴液漏斗和冷凝管的蒸馏瓶中。将冷凝管末端浸于含 1 g 乙酸镉的 70 mL 氨水中。

通过恒压滴液漏斗向烧瓶中加入 $50 \, mL \, 1 + 4 \, H_{2}SO_{4}$ ，加热蒸出 $35 \, mL$ 溶液；向吸收液中加入 $50 \, mL \, 1:1$ 盐酸和 $50.00 \, mL \, 0.1 \, mol/L$ 标准碘溶液，放置 $30 \, min$ ，以淀粉为指示剂，用 $0.1197 \, mol/L \, Na_{2}S_{2}O_{3}$ 溶液滴定至终点，消耗 $25.10 \, mL$ 。同时做空白实验，消耗 $Na_{2}S_{2}O_{3}$ 溶液 $45.37 \, mL$ 。

![](images/6ce370245608e96645366e7d1c5867cb8ae46844f75ebbe39843ac903a1becdb.jpg)

用砂芯漏斗过滤烧瓶中的混合物并洗涤。滤渣干燥并称量为 0.0109 g；用二硫化碳反复洗涤滤渣，干燥后再次称量为 0.0023 g。将滤液及洗涤液转移至锥形瓶中，加入 10 mL $1+1\ H_{2}SO_{4}$ 和 3 mL $H_{3}PO_{4}$ ，用 0.01058 mol/L $KMnO_{4}$ 溶液滴定至终点，消耗 39.45 mL。

分别计算硫化亚铁样品中铁、硫、硫化亚铁的含量(以质量分数计)。

## 参考答案

## 第3题（8分）

![](images/cb28d7701f87fcbb58abb533638616bb130377aa289dcedd26e07c982b37b807.jpg)

$\omega (\mathrm{S}) = (0.0109\mathrm{g} - 0.0023\mathrm{g}) / 0.1749\mathrm{g} = 4.9\%$ （2分） $\mathrm{FeS}\sim \mathrm{H}_2\mathrm{S}\sim \mathrm{I}_2\sim 2\mathrm{Na}_2\mathrm{S}_2\mathrm{O}_3$ $n(\mathrm{FeS}) = 0.1197\mathrm{mol / L}\times (45.37\mathrm{mL} - 25.10\mathrm{mL}) / 2 = 1.213\times 10^{-3}\mathrm{mol}$ （2分） $\omega (\mathrm{FeS}) = 1.213\times 10^{-3}\mathrm{mol}\times (55.85 + 32.07)\mathrm{g / mol / 0.1749g} = 60.98\%$ （1分） $n(\mathrm{Fe}^{2 + }) = 5\times 0.01058\mathrm{mol / L}\times 39.45\mathrm{mL} = 2.087\times 10^{-3}\mathrm{mol}$ （1分） $n(\mathrm{Fe}) = 2.087\times 10^{-3}\mathrm{mol} - 1.213\times 10^{-3}\mathrm{mol} = 8.74\times 10^{-4}\mathrm{mol}$ （1分） $\omega (\mathrm{Fe}) = 8.74\times 10^{-4}\mathrm{mol}\times 55.85\mathrm{g / mol / 0.1749g} = 27.90\%$ （1分）
