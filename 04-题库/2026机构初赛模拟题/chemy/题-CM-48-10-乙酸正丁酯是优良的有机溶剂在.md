## 题目

### 第 10 题 乙酸正丁酯的合成（8 分，占 4%）

乙酸正丁酯是优良的有机溶剂， 在石油加工、制药工程等领域均有广泛应用。在实验室中，乙酸正丁酯可通过正丁醇和冰醋酸在强酸催化及加热条件下合成，实验装置如右图所示。反应中生成的水可以与正丁醇或乙酸正丁酯形成共沸混合物被蒸出。使用分水器可在反应进行的同时分离出生成的水， 并使有机相流回反应瓶中。实验步骤如下：

(1) 如右图所示装配仪器。

(2) 关闭分水器旋塞并在分水器带旋塞一侧预先加入适量的 $\textcircled{1}$ 再向反应瓶中加入 $\mathsf { \Omega } 5.0 \mathsf { mL }$ ( $55 \mathrm { { mmol } }$ ) 正丁醇、 $\textcircled{2}$ _和 $\textcircled{3}$ ，加入1粒沸石。

![](images/7a3de654791ac696b0af0354f461b19f804d584d009328273506e7255028763f.jpg)

(3) 将反应液温度控制在 $\textcircled{4}$ _并保持 15分钟，然后升温至回流状态进行分水。当反应不再有水生成时，停止加热。合并烧瓶和分水器中的液体， 用分液漏斗将水层分出。 依次用 $5 \mathrm { \ mL \ 10 \% }$ 碳酸钠水溶液及5mL水洗涤有机层。

(4) 有机层用无水硫酸镁干燥。 常压蒸馏， 收集 $124 - 126^{ \circ } C$ 的馏分。
