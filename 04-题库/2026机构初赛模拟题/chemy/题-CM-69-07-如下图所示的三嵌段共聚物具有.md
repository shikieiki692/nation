# 题-CM-69-07-如下图所示的三嵌段共聚物具有

## 题目

### 第 7 题（7 分）

如下图所示的三嵌段共聚物具有优良的抗菌性能， 在生物医用材料领域具有广泛的应用前景。该三嵌段共聚物的合成方法如下：将一定量的单体 $\pmb { \mathsf { A } }$ 溶于 $\mathrm { CH } _{ 2 } \mathrm { Cl } _{ 2 }$ 中，在氮气气氛下，冰水浴搅拌预冷 $30 \mathrm { min }$ ， 然后加入烯丙基溴 $/ \mathrm { AgClO _{ 4 } }$ 引发聚合反应；反应进行 $3.5 \mathrm { h }$ ，得到具有活泼末端的活性链；然后将高分子化合物B 加入到上述溶液中，反应 $3 \mathrm { h }$ ， 然后在无水乙醇中沉析， 即可得到产物。

![](images/4e2c44aa5935f89e861fb37ea9a7a58daf58457bef2ca254f71ac4258d00f0d4.jpg)

7-1 请写出单体A 和高分子化合物B 的结构简式。

7-2 红外光谱显示，三嵌段共聚物在 $3300 { \sim } 3540 \mathrm { cm } ^{ - 1 }$ 处出现较宽的吸收谱带。将此共聚物升温至 $130^{ \circ } \mathrm { C }$ ， 发现该谱带的吸收强度逐渐减弱， 最终几乎完全消失。请解释这一现象。7-3 该三嵌段共聚物表现出良好的抗菌性能， 可能的原因是什么？

## 参考答案

## 第7题（7分）

![](images/3a1a9940a1ce1eaa0f864733d80a3ce146f95681c140171ec8faf12eb354e234.jpg)

![](images/5158bc03d00db302913737ea5ca54fb1b1154e47e5b1ffdded0a3c8d3f5dae98.jpg)

7-2 在  $3300 \sim 3540 \, cm^{-1}$  处出现较宽的吸收谱带为氢键（1 分）的吸收谱带。随着温度升高，分子链间氢键逐渐发生解离，因此该谱带吸收强度逐渐减弱；当温度升至  $130^{\circ}C$  时，氢键几乎全部解离，因此最终完全消失。（1 分）
