# 题-CM-253-03-在101325kPa时使干燥空气

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-26-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（6 分）

在 101.325kPa 时，使干燥空气依下列次序缓慢地通过一系列温度均为 20℃的容器，它包括：稀尿素水溶液(A)、纯水(B)、浓硫酸(C)。若干时间以后，C 已增重 2.0361 g，而 B 减少了0.087 g，不考虑大气从 C 端倒吸的干扰。已知该温度下纯水的饱和蒸汽压是 2.33 kPa。提示：气体缓慢通过液体时前后总压力保持不变。

**3-1** 求 A 中尿素的浓度（g/100g 水）。

**3-2** 实际A中溶液是13.333g尿素溶于100.00g水中得到的。计算相对误差并分析可能原因。

## 参考答案

**3-1** 4 分，其他做法答案正确也得分。考虑空气的量守恒，有：n(通过 C 中的空气) = [Δm<sub>c</sub>/M(H<sub>2</sub>O)]×[(p <sub>大气</sub> – p <sub>水</sub><sup>*</sup>)/ p <sub>水</sub><sup>*</sup>] = 4.8017 (mol) = n(通过 A 中的空气). n(A 中失去的水) = (Δm<sub>c</sub> – Δm<sub>B</sub>)/ M(H<sub>2</sub>O) = 0.10819 (mol).（1 分）p <sub>水</sub> = p <sub>大气 </sub>× [n <sub>水</sub>/( n <sub>水 </sub>+ n <sub>空气</sub>)] = 2.2326 (kPa).（1 分）由 p <sub>水</sub> = p <sub>水</sub><sup>*</sup>× x <sub>水</sub> 得：x <sub>水</sub> = 95.82%（1 分），解出：尿素浓度= 14.539 (g/100g 水).（1 分）

**3-2** 相对误差为：E<sub>r</sub> = [(14.88 – 13.333) ÷ 13.333] × 100% = 9.042%.（1 分）可能原因为：仪器中气压降低，实际小于一个大气压；实验过程中 A 中水分被不断带走导致浓度变化；A 中溶液偏离理想溶液。（1 分，答出任意一点即可得分）
