# 题-CM-123-04-利用偶氮二异丁腈AIBN结构

## 题目

### 第 4 题（7 分）

利用偶氮二异丁腈(AIBN, 结构如下)可引发苯乙烯聚合为聚苯乙烯(PS)的自由基聚合反应:

![](images/5d377fdec8d926b2a7a9f730af02e5b0c4cb3f851c53110839f3fd1b1ebfc07b.jpg)

用 ${}^{14}$ C 标记的 AIBN 引发聚合得到(数均)分子量为 $1.30 \times 10^{6}$ 的 PS。闪烁计数器测定表明，AIBN 放射活性为 $1.919 \times 10^{8}$ counts min $^{-1}$ mol $^{-1}$ ; 5.80 g PS 放射活性为 858 counts min $^{-1}$ 。4-1 写出聚合反应的链引发的反应式(2 个)。

4-2 通过计算和推导确定链终止的方式，画出所得聚合物的结构。

## 参考答案

![](images/df4fc65863e45c52e4b5efca0e630f81bde66fced07fbbb23bf895b938b97950.jpg)

```txt
5-1-1 Mo: 三棱柱（0.5分）Si: 四面体（0.5分）
5-1-2 MoSi₂N₄（2分）

5-2 将钼酸锂 Li₂MoO₄ 置于氨气流中加热至 450℃，反应生成黑色粉末。X-射线衍射表明，该黑色粉末是 2 种物质 A 和 B 的混合物。A 为面心立方晶体，阴离子做立方最密堆积，阳离子填入所有的四面体空隙中。
B 为具有特殊导电性质的三元氮化物，它的晶体结构如右图所示。每一层氮原子都是密堆积层，锂和钼相间填充在两层氮之间，钼填充在一半的三棱柱空隙中，锂填充在所有的八面体空隙中。
5-2-1 写出 A 和 B 的化学式。
5-2-2 写出生成该黑色粉末的化学反应方程式。
5-2-3 分别用 A、B、C 表示氮原子，a、b、c 表示锂，a'、b'、c'表示钼的堆积位置，写出晶体 B 沿 c 轴方向原子的堆积方式。
5-2-4 若以锂为 B 的六方晶胞顶点，写出所有锂原子的坐标以及所有钼原子的坐标。

5-2-1 Li₂O（1分，写作 Li₂NH 也得分）LiMoN₂（1分）
5-2-2 6Li₂MoO₄ + 14NH₃ = 6LiMoN₂ + 3Li₂O + N₂ + 21H₂O（2分，产物写 Li₂NH 也得分）
5-2-3 …[Ac’AcBa’BaCb’Cb]Ac’AcBa’BaCb’Cb…（2分）
答案不唯一，只要位置正确，能体现出 R 心六方对称性和堆积方式，即可得分。
5-2-4 Li: (0,0,0) (1/3,2/3,1/3) (2/3,1/3,2/3)（1分）
Mo: (0,0,1/6) (1/3,2/3,1/2) (2/3,1/3,5/6)（1分）

5-2-5 结构测定表明，B 的密堆积层内的氮原子间距为 286.7 pm；层间氮原子间距为 256.1 pm 和 317.2 pm。计算晶胞参数 a 和 c 以及晶体密度 D。

5-2-5 晶胞参数 a 等于层内氮原子间距，即 a = 286.7 pm（0.5分）
投影位置错开的两层氮原子的层间距满足：d² + (286.7 pm /√3)² = (317.2 pm)² d = 270.3 pm（0.5分）
c = (256.1 pm + 270.3 pm) × 3 = 1579 pm（1分）
因此可求出晶体密度为：
D = ZM/NₐV
= ZM/Nₐa²csin120°（1分）
= 5.792 g/cm³（1分）
```
