# 题-CM-222-07-A为过渡金属的氧化物含氧368在

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-12-7`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 7 题（10 分）

A 为过渡金属的氧化物，含氧 36.8%。在-63°C 的无水乙醇中，A 与 HCl 发生氧化还原反应，加入四氯化碳析晶，得到黑色氯化物 B；B 遇水反应放出气体，溶液经浓缩析晶得浅红色结晶 C，C 为(单核)八面体配合物分子。此外，若将 A 与 KOH 混合共熔并通入氧气，可得 X；X 经电解氧化可制得 1:1 型钾盐 D。在醋酸钠存在下，向 C 的水溶液中加入 2,4-戊二酮(简写为 Hacac)，并缓慢加入 D 的水溶液；加热反应、冷却，析出黑色沉淀；将该黑色沉淀真空干燥可制得黑色晶体 E。晶体衍射表明，E 中金属原子为八面体配位，金属原子形成的键仅有 1 种键长；磁性测定表明，E 的磁矩为 5.13 B.M.。

**7-1** 通过计算，推出 A 的化学式。

**7-2** 写出 B、C、D、E 的化学式(2,4-戊二酮配体用简写符号表示)。

**7-3** 写出由 C 和 D 生成 E 的化学反应方程式。

**7-4** 分别写出 C 和 E 中，M 在(正)八面体场中的价电子组态。

## 参考答案

**7-1** 设过渡金属的原子量为 M，则：M / (M + 16.0 x) = 36.8%（1 分）

将 x = 1, 2, 3……分别代入，得当 x = 2 时，M = 54.9

因此 A 为 MnO<sub>2</sub>（1 分）

采用其他计算方式，公式合理，分析合乎逻辑，结果正确，亦得满分

**7-2** B MnCl<sub>3</sub>（1 分） C MnCl<sub>2</sub>·4H<sub>2</sub>O（1 分） D KMnO<sub>4</sub>（1 分） E Mn(acac)<sub>3</sub>（1 分）<sub> </sub>

C 写成 MnCl<sub>2</sub>(H<sub>2</sub>O)<sub>4</sub>或 Mn(H<sub>2</sub>O)<sub>4</sub>Cl<sub>2</sub>，也得分。

其他答案不得分。

**7-3** 4Mn<sup>2+</sup> + MnO<sub>4</sub><sup>-</sup> + 15Hacac + 7CH<sub>3</sub>COO<sup>-</sup> → 5Mn(acac)<sub>3</sub> + 7CH<sub>3</sub>COOH + 8H<sub>2</sub>O（2 分）

将 Mn<sup>2+</sup>写成[MnCl<sub>2</sub>(H<sub>2</sub>O)<sub>4</sub>]，配平，不扣分。

写成化学反应方程式并配平，也可得分。

**7-4** C (t<sub>2g</sub>)<sup>3</sup>(e<sub>g</sub>)<sup>2</sup>（1 分） E (t<sub>2g</sub>)<sup>3</sup>(e<sub>g</sub>)<sup>1</sup>（1 分）

用 dε 和 dγ 表示正确的，也可得分。

若采用画图示出，答案正确的，也可得分。
