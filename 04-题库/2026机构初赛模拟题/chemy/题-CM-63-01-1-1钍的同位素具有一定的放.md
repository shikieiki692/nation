# 题-CM-63-01-1-1钍的同位素具有一定的放

## 题目

### 第 1 题（10 分）

1-1 钍的同位素具有一定的放射性， $232 _{ \mathrm { { 90 Th } } }$ 经过一系列的 $\boldsymbol { a }$ 衰变和 $\beta$ 衰变得到了 $^{ 208 } \mathrm { { 81 Tl } }$ 。
1-2 水合三氯乙醛与氢氧化钠水溶液反应， 反应体系分为两相。
1-3 铍的提取方式之一是将绿柱石粉末 $\left( \mathrm { Be } _{ 3 } \mathrm { Al } _{ 2 } \mathrm { Si } _{ 6 } \mathrm { O } _{ 18 } \right)$ 与过量六氟合铁(III)酸钠混合，在
$750^{ \circ } \mathrm { C }$ 烧结。将产物用水浸取，可使得 $\mathrm { Be ( II ) }$ 与铝、硅分离。
可使得Be(II)与铝、硅分离。1-4 在N2 高度稀释下，NH3 和Cl2 按摩尔比2 : 1 反

1-4 在 $\Nu _{ 2 }$ 高度稀释下， $\mathrm { NH } _{ 3 }$ 和 $\mathrm { Cl } _{ 2 }$ 按摩尔比 $2 : 1$ 反应，产生一种白色固体和一种无色气体。
1-5 氯酸铊(I)加热受热分解，生成两种固态二元化合物并放出黄绿色氧化物气体。

## 参考答案



**1-1** 钍的同位素具有一定的放射性, $^{232}_{90}Th$ 经过一系列的 $\alpha$ 衰变和 $\beta$ 衰变得到了 $^{208}_{81}Tl$ 。

**1-1** $^{232}_{90}Th = ^{208}_{81}Tl + 6^{4}_{2}He + 3^{0}_{-1}e$ (2分)

**1-2** 水合三氯乙醛与氢氧化钠水溶液反应,反应体系分为两相。

**1-2** $Cl_{3}CCH(OH)_{2} + NaOH \rightarrow HCCl_{3} + HCOONa + H_{2}O$ (2分)

**1-3** 铍的提取方式之一是将绿柱石粉末( $Be_{3}Al_{2}Si_{6}O_{18}$ )与过量六氟合铁(III)酸钠混合,在750°C烧结。将产物用水浸取,可使得Be(II)与铝、硅分离。

**1-3** $Be_{3}Al_{2}Si_{6}O_{18} + 2Na_{3}FeF_{6} \rightarrow 3Na_{2}BeF_{4} + Fe_{2}O_{3} + Al_{2}O_{3} + 6SiO_{2}$ (2分)

**1-4** 在 $N_{2}$ 高度稀释下, $NH_{3}$ 和 $Cl_{2}$ 按摩尔比2:1反应,产生一种白色固体和一种无色气体。

**1-4** $2NH_{3} + Cl_{2} \rightarrow NH_{2}Cl + NH_{4}Cl$ (2分)

**1-5** 氯酸铊(I)加热受热分解,生成两种固态二元化合物并放出黄绿色氧化物气体。

**1-5** $7TlClO_{3} = TlCl + 3Tl_{2}O_{3} + 6ClO_{2}$ (2分)产物写为 $Tl_{2}O$ 也可得分。
