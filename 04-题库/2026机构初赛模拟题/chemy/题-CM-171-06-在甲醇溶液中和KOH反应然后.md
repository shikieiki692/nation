# 题-CM-171-06-在甲醇溶液中和KOH反应然后

## 题目

### 第 6 题 铬和铅的配合物 （19 分， 占 $10 \%$

在甲醇溶液中， $\mathrm { Cr ( CO ) } _{ 6 }$ 、 $\mathrm { Pb } { \mathrm { Cl } } _{ 2 }$ 和KOH 反应，然后加入溴化四乙基铵 $\left( { \mathrm { Et } } _{ 4 } { \mathrm { NBr } } \right)$ ， 可沉淀出化合物A。X 射线衍射表明 $\pmb { \mathsf { A } }$ 为2:1 型盐，其阴离子是含铅和铬的多核配离子，铅和铬分别为四面体和八面体配位；对 A 的元素分析结果表明，其中各元素的质量分数 $( \% )$ 为： C, 29.19;H, 2.81; N, 1.87。核磁共振氢谱表明 A 的阴离子具有2 个羟基；红外光谱表明A 中的CO 配体全部为端基配位。

在二氯甲烷中， A 与 $\mathrm { CO } _{ 2 } ^{ - }$ 反应，产物为 B；反应产生的 B 的摩尔数是消耗的 A 的 2 倍。B加热至 $35^{ \circ } \mathrm { C }$ 生成C。结构测定表明，B、C 均是 2:1 型盐，铅和铬仍分别保持四面体和八面体配位；B 的阴离子具有 1 个四元环；C 的阴离子具有 2 个四元环； B、C 均能在 KOH 的甲醇溶液中均能转化回A。

6-1 通过计算和推导， 求出 A 的化学式。(提示：元素分析测定的结果往往有一定的误差)

6-2 画出 $\Delta - C$ 的阴离子的结构简式(Cr 的配位多面体的立体结构可不示出)。

6-3 分别写出B 和C 在氢氧化钾的甲醇溶液中转化回 A 的反应方程式。

6-4 对于化合物 A 的生成机制，人们提出，反应的第一步为 Cr(CO)6 转化为 $\mathrm { K [ HCr ( CO ) _{ 5 } ] }$ ；然后 $\mathrm { K [ HCr ( CO ) _{ 5 } ] }$ 经历之后的转化生成最终产物。写出第一步转化的反应方程式；指出$\mathrm { K [ HCr ( CO ) _{ 5 } ] }$ 的阴离子在八面体场中的 d 电子排布。

## 参考答案

6-1 A 中各元素的原子数目比 n(C): n(H): n(N) 为:

A 中有 2 个阳离子 $\left[\mathrm{NEt}_{4}\right]^{+}$ ，则 A 的摩尔质量为： $14.01 \times 2 / 0.0187 = 1498 (\mathrm{~g/mol})$ （1 分）A 的 1 个阳离子中含 20 个 H、1 个 N 和 8 个 C；阴离子中剩余 20 个 C 和 2 个 H。若阴离子中碳均为 CO 配体，氢均为 OH 配体，则剩余部分的摩尔质量为：

4 个 Cr 和 2 个 Pb 的摩尔质量总和为 $52.00 \times 4 + 207.2 \times 2 = 622.4 \, (\text{g/mol})$ 与之接近（1 分）因此 A 的化学式为 $[NEt_{4}]_{2}[Pb_{2}(OH)_{2}(Cr(CO)_{5})_{4}]$ （2 分）

6-2 参考图形如下:
