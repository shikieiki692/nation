# 题-CM-231-06-五氧化二钒磷酸一氢铵及碳共热可制

## 题目

### 第 6 题（15 分，占 8.0%）

五氧化二钒、磷酸一氢铵及碳共热可制得磷酸钒晶体。该晶体属于正交晶系，晶胞参数 a

=523.2 pm，b = 777.4 pm，c = 628.5 pm。其沿 a 轴和 c 轴的投影图如下（左图为沿 a 轴投影

![](images/a62b2b8be103d38e0235aeeccb2309c6560bd6ef6cf0e41857f203ef73c773fc.jpg)

**6-1** 指出该晶体中钒的价电子组态，写出制备磷酸钒晶体的化学反应方程式

**6-2** 写出该晶体所属的空间点阵型式。

**6-3** 该晶体中有几种化学环境和空间环境的氧原子？结合配位数，指出不同化学环境氧原子

的配位数及比例。

**6-4** 计算该晶体的密度。

**6-5** 磷酸钒晶体与氟化钠固体以一定比例混合反应可生成晶体 X，X 可视作由磷酸钒的多面

体骨架发生重组后插入钠离子、氟离子得到。X 中钒的配位数与磷酸钒中相同，但配位原子

不完全相同（两种配位原子的比例为 1 : 2），每 2 个钒的配位多面体通过氟桥共顶点连接形

成[V<sub>2</sub>]结构单元，单元之间不共用配位原子。根据上述结构描述给出 X 的化学式。

## 参考答案

![](images/7dd2253b465c6e47d9327ae96e30b9b6a108b88e0bff277ca10183c1b6697699.jpg)

**6-1**

钒的价电子组态：3d<sup>2</sup>（1 分）

化学反应方程式：V<sub>2</sub>O<sub>5</sub> + 2(NH<sub>4</sub>)<sub>2</sub>HPO<sub>4</sub> + 2C = 2VPO<sub>4</sub> + 4NH<sub>3</sub> + 3H<sub>2</sub>O + 2CO（2 分）

写作 V<sub>2</sub>O<sub>5</sub> + 2(NH<sub>4</sub>)<sub>2</sub>HPO<sub>4</sub> + C = 2VPO<sub>4</sub> + 4NH<sub>3</sub> + 3H<sub>2</sub>O + CO<sub>2</sub>也得 2 分。

**6-2** 底心正交点阵（2 分）

**6-3** 有 2 种化学环境的氧原子，8 种空间环境的氧原子。（各 1 分，共 2 分）

不同化学环境氧原子的配位数：3（1P + 2V），2（1P + 1V），比例为 1 : 1。（2 分）

**6-4** 根据投影图可知，该晶体 Z = 4。（1 分）

故 ρ = ZM/N<sub>A</sub>abc = 3.791 g·cm<sup>-3</sup>（2 分）
