### 第 6 题 白磷及其活化 （27 分， 占 $14 \%$

磷元素是生命体重要的元素之 广 ；如何将白磷转化为各种含磷化合物，是科学家们一直在研究的问题之一。

6-1 自然界中磷元素常以磷酸盐的形式存在于矿石中。工业上多用焦炭和 $\mathrm { SiO } _{ 2 }$ 与 $\mathrm { Ca } _{ 3 } ( \mathrm { PO } _{ 4 } ) _{ 2 }$ 在电炉中 $1400^{ \circ } \mathrm { C }$ 反应制备白磷(反应 1)。在酸或碱存在下利用白磷的歧化可以得到 $\mathrm { PH } _{ 3 }$ ： 如在酸催化下白磷与水蒸气在 $280^{ \circ } \mathrm { C }$ 反应， 氧化产物为磷酸(反应 2)；白磷在碱性水溶液中受热歧化，氧化产物中磷为 $+ 1$ 氧化态(反应 3)或 $+ 3$ 氧化态(反应 4)。分别写出反应 $1 \sim$ 反应 4 的反应方程式。

6-2 利用白磷可得到多种以配体形式存在的多磷负离子， $\mathbf { \Delta } \operatorname { P } _{ 6 } ^{ x }$ -就是其中之一。其中 $x = 2 , 4 , 6$ 的离子均具有六元单环结构。此外， $x = 4$ 的 ${ \mathrm { P } } _{ 6 } ^{ 4 }$ -还存在另外 3 种满足八隅律的结构： 结构(a)的环仅有三元环；结构(b)的环有三元环和五元环；结构(c)的环有四元环和五元环； 以上三种结构中磷均为 2 和3 配位且均不存在磷-磷多重键。

6-2-1 若孤立的 $\mathrm { P } _{ 6 } ^{ x - }$ 为六元单环离子， 利用休克尔规则判断 $x = 2 , 4 , 6$ 的哪些具有芳香性。

6-2-2 分别画出结构(a)、 (b)、 (c)的示意图。

6-2-3 分别指出结构(b)和结构(c)中存在的对称元素。

## 第 6 题（13 分，占 8%）二茂铁片段的力响应

在聚合物链段中引入二茂铁片段后，可体现出有趣的力响应性质。

6-1 在外力作用下，二茂铁片段会发生解离，进而发生聚合物的降解。二茂铁的解离主要有两种机制：其中一种为剪切过程，即 $Fe^{2+}$ 上下的茂环向相反的方向位移；另一种为剥离过程，即增大两个茂环平面的二面角。研究表明，下图所示两种二茂铁片段受力解离的机制不同，指出两种片段受力解离的主要机制(波浪线省略部分表示聚合物链)。

![](images/15b7df2924ba67e71fdf70308c43688f7f333c9268dca4e7b3b2cdf724926097.jpg)
FC

![](images/976f8fe7d4a824b2f88207ea71f8df75b220dc55efbc85b9b88c54a8712e43ec.jpg)

6-1 FC：剪切过程；cis-3-FCP：剥离过程（各2分）

6-2 不同的解离机制使上述二茂铁片段具有不同的力响应性能，cis-3-FCP 片段发生解离所需外力显著小于 FC。完成如下问题：

6-2-1 向硅弹性体链段中引入二茂铁片段，而后引入邻二氮菲，可制得一种机械力诱导变色高分子，在外力作用下，硅弹性体会变为红色。

6-2-1-1 写出显红色对应的配合物分子(或离子)。

6-2-1-1 Fe(phen) $_{3}^{2+}$ （2分）

6-2-1-2 在施加外力相同的前提下，引入 cis-3-FCP 片段的硅弹性体与引入 FC 片段的硅弹性体相比何者受外力作用后显示出的红色更深？

6-2-1-2 引入 cis-3-FCP 片段的硅弹性体（2 分）

6-2-2 通常双官能度的单体只可形成链状聚合物、而无法形成交联网络，但向链状聚合物中插入 cis-3-FCP 片段便可在外力作用下实现交联。

6-2-2-1 说明实现交联的原理。(提示：未参与配位的茂基配体在溶液中会发生质子化反应)
6-2-2-1 发生质子化反应后的茂基配体间可发生 Diels-Alder 反应，进而实现链间交联（2分）

![](images/f6df9fe5cdec37d8c59eafa8e3ffa63e468298742dec05030260ac049cd77da5.jpg)

6-2-2-2 然而，若将插入 cis-3-FCP 片段的聚合物溶于含 X 分子的溶液后再施加外力，将得到澄清溶液，无交联网络生成，解释原因。

![](images/6b97775866130e17ee5c3a8abf73fcddec3693ce8c891b719564627add86f649.jpg)

6-2-2-2 由于羰基的吸电子诱导及吸电子效应，X 具有相较于环戊二烯基更低的 LUMO，是更好的亲双烯体（2 分），因此会优先与二茂铁解离后释放出的环戊二烯发生 Diels-Alder 反应（1 分），故 X 体现出类似“封端”的作用、抑制了交联。
