# 题-CM-85-05-主族元素N在古代常被误认为是

## 题目

### 第 5 题（12 分）

主族元素 N 在古代常被误认为是铅或锡，其化合物常被用作化妆品。单质 N 不溶于熔融碱，但可溶于王水生成 A，A 水解得到沉淀 B。与 A 阴离子相同的一离子化合物 C 可以通过氯化物 D、氯化物 E 与氯气反应制得 C、D、E 的含氯量分别为 64.31%、58.67%、59.27%。E 与氢化铝锂在乙醚中反应可以得到三角锥型的 F。

5-1 写出 A\~F 的化学式。

5-2 将 N 在温和条件下加热可以得到含氧量 16.46% 的氧化物 E，E 在气相中以二聚体形式存在；而在 $600^{\circ}$ C 以上的固相，E 以双链结构存在，N 和 O 形成八元环，画出气相和固相下 E 的两种结构。

5-3 N 的一种二甲基取代的卤化物中 N 的含量为 47.17%，其单体和水分子对称性相同，画出其单体的结构，并画出其 $D_{2h}$ 群二聚体结构。

## 参考答案

## 第5题（12分）

5-1 写出 A\~F 的化学式。



**5-1** A HSbCl6 B Sb2O5·nH2O C [AsCl4+] [SbCl6-] D AsCl3 E SbCl5 F SbH3(每个1分)
