# 题-CM-237-03-元素X含量稀少常伴生于锌矿中将单

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-18-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（17 分，占 10.0%）

元素 X 含量稀少，常伴生于锌矿中。将单质 X 溶于浓硝酸中，得到含氧 51.86%的四水合

物 A (反应 1)。令单质 X 与热浓盐酸作用，在 HCl 气氛中蒸馏，在 N<sub>2</sub>下干燥最终制得 B

(反应 2)。将 X 熔于 B 中得到暗红色熔体，加入 AlCl<sub>3</sub>能析出抗磁性黄色化合物 C (反应

3)。C 遇水即分解得到单质 X。D 为 X 的碘化物，bipy(结构如下图所示)/KI/FeSO<sub>4</sub>可用来

![](images/49af49c13d2d82ad1b61dd60b37d1911667938591a1849080bed2aff59618e4c.jpg)

与 X 的配位阴离子结合产生配合物 E (反应 4)。混合 diars(o-苯基双二甲胂，结构如下图所

示) 与 D 的溶液生成配合物 F (反应 5)，F 含有与 E 相同的阴离子。

![](images/b6659ca28d70cf560f418b59cf0b31bdcd5c2b53f918005d51d39da5b22b91b8.jpg)

**3-1** 写出反应 1 ~ 反应 5 的化学方程式。

**3-2** 蒸干配合物 F 的水溶液，其会分解为配合物 G，G 中 X 的配位数与 F 保持一致，写出

G 的化学式。

## 参考答案

**3-1** 反应 1：Cd + 4HNO<sub>3</sub> + 2H<sub>2</sub>O → Cd(NO<sub>3</sub>)<sub>2</sub>·4H<sub>2</sub>O + 2NO<sub>2</sub>（3 分）

反应 2：Cd + 2HCl → CdCl<sub>2</sub> + H<sub>2</sub>（3 分）

反应 3：Cd + CdCl<sub>2</sub> + 2AlCl<sub>3</sub> → Cd<sub>2</sub>[AlCl<sub>4</sub>]<sub>2</sub>（3 分）

反应 4：FeSO<sub>4</sub> + 2KI + 3bipy + CdI<sub>2</sub> → [Fe(bipy)<sub>3</sub>][CdI<sub>4</sub>] + K<sub>2</sub>SO<sub>4</sub>（3 分）

反应 5：2CdI<sub>2</sub> + 2diars → [Cd(diars)<sub>2</sub>][CdI<sub>4</sub>]（3 分）

**3-2** G 的化学式为 Cd(diars)I<sub>2</sub>（2 分）
