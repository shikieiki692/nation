# 题-CM-239-01-11将氢氧化铝和纯碱一同溶于氢氟

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-1-1`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 1 题（10 分）

**1-1** 将氢氧化铝和纯碱一同溶于氢氟酸当中，能够制备常作为助熔剂的冰晶石。

**1-2** 将(NH<sub>4</sub>)<sub>6</sub>Mo<sub>7</sub>O<sub>24 </sub>溶于盐酸中，并加入过量 Sn 单质，产物中 Mo 的存在形式为 MoCl<sub>6</sub><sup>2-</sup> (本问以离子方程式的形式作答)。

**1-3** 六价铬的化合物有较大毒性，但其在化学实验和工业生产中都发挥着重要的作用。

**1-3-1** 工业生产六价铬的化合物主要是通过铬铁矿(Fe(CrO<sub>2</sub>)<sub>2</sub>)与苏打混合，并在空气中煅烧得到。

**1-3-2** 将重铬酸钾与氯化钾在浓硫酸加热，可制备一种深红色易挥发液体。

**1-4** Se 和 S 作为同族元素，其化学性质有许多相似之处。在醋酸水溶液中，SeO<sub>2</sub>和 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>反应得到两种含硫阴离子 A 和 B。A 和 B 中的硫原子数目相同，且 B 中 S 元素的质量分数为 42.30%。

## 参考答案

**1-1** 2Al(OH)<sub>3</sub> + 3Na<sub>2</sub>CO<sub>3</sub> + 12HF = 2Na<sub>3</sub>AlF<sub>6</sub> + 3CO<sub>2</sub> + 9H<sub>2</sub>O（2 分）

**1-2** (NH<sub>4</sub>)<sub>6</sub>Mo<sub>7</sub>O<sub>24</sub> + 48H<sup>+</sup> + 42Cl<sup>-</sup> + 7Sn = 24H<sub>2</sub>O + 7Sn<sup>2+</sup> + 7MoCl<sub>6</sub><sup>2-</sup> + 6NH<sub>4</sub><sup>+</sup>（2 分）

写成(NH<sub>4</sub>)<sub>6</sub>Mo<sub>7</sub>O<sub>24</sub> + 48H<sup>+</sup> + 63Cl<sup>-</sup> + 7Sn = 24H<sub>2</sub>O + 7SnCl<sub>3</sub><sup>-</sup> + 7MoCl<sub>6</sub><sup>2-</sup> + 6NH<sub>4</sub><sup>+ </sup>

或(NH<sub>4</sub>)<sub>6</sub>Mo<sub>7</sub>O<sub>24</sub> + 48H<sup>+</sup> + 84Cl<sup>-</sup> + 7Sn = 24H<sub>2</sub>O + 7SnCl<sub>4</sub><sup>2-</sup> + 7MoCl<sub>6</sub><sup>2-</sup> + 6NH<sub>4</sub><sup>+</sup>亦可

**1-3-1** 4Fe(CrO<sub>2</sub>)<sub>2</sub> + 7O<sub>2</sub> + 8Na<sub>2</sub>CO<sub>3</sub> = 2Fe<sub>2</sub>O<sub>3</sub> + 8Na<sub>2</sub>CrO<sub>4</sub> + 8CO<sub>2</sub>（2 分）

写成 3Fe(CrO<sub>2</sub>)<sub>2</sub> + 5O<sub>2</sub> + 6Na<sub>2</sub>CO<sub>3</sub> = Fe<sub>3</sub>O<sub>4</sub> + 6Na<sub>2</sub>CrO<sub>4</sub> + 6CO<sub>2</sub>亦可

**1-3-2** K<sub>2</sub>Cr<sub>2</sub>O<sub>7</sub> + 4KCl + 3H<sub>2</sub>SO<sub>4</sub> = 2CrO<sub>2</sub>Cl<sub>2</sub> + 3K<sub>2</sub>SO<sub>4</sub> + 3H<sub>2</sub>O（2 分）

写成 K<sub>2</sub>Cr<sub>2</sub>O<sub>7</sub> + 4KCl + 6H<sub>2</sub>SO<sub>4</sub> = 2CrO<sub>2</sub>Cl<sub>2</sub> + 6KHSO<sub>4</sub> + 3H<sub>2</sub>O 亦可

**1-4** SeO<sub>2</sub> + 4S<sub>2</sub>O<sub>3</sub><sup>2-</sup> + 4CH<sub>3</sub>COOH = S<sub>4</sub>O<sub>6</sub><sup>2-</sup> + S<sub>4</sub>SeO<sub>6</sub><sup>2-</sup> + 4CH<sub>3</sub>COO<sup>-</sup> + 2H<sub>2</sub>O（2 分）
