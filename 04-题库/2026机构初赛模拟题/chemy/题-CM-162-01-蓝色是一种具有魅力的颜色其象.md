# 题-CM-162-01-蓝色是一种具有魅力的颜色其象

## 题目

### 第 1 题

# 第 1 题（25 分， 占 $15 \%$ ） Un certain bleu pénètre votre âme

蓝色是一种具有魅力的颜色，其象征着和平，平静和寒冷，内涵丰富而又富有意境。在古代蓝色常用作艺术和装饰，从最古老的由蓝草提取的靛蓝，文艺复兴时期绘画所使用的群青到现在克莱因蓝，丰富了艺术的表达。

1-1 在摄影技术发明三年后便发明了蓝晒工艺(Cyanotype)， 这是第一种古典的非银盐摄影工艺。 蓝晒的制备流程如下：

$1$ 取 $40 \mathrm { g }$ 柠檬酸铁铵 `\mathrm { \small { [ FeC _{ 6 } H _{ 5 } O _{ 7 } ] } } _{ x } \mathrm { [ ( NH _{ 4 } ) _{ 3 } C _{ 6 } H _{ 5 } O _{ 7 } ] } _{ y }` （柠檬酸：3-羧基-3-羟基戊二酸）溶于 200$\mathrm { ml }$ 水，得深棕色溶液。取 $16 \mathrm { g }$ 铁氰化钾 $\mathrm { K } _{ 3 } \mathrm { Fe } ( \mathrm { CN } ) _{ 6 }$ 溶于 $200 \mathrm { ml }$ 水，得黄色溶液。取适量的两种溶液等体积混合，得到由化合物 A 和柠檬酸盐组成的深黄绿色感光剂混合液。将感光剂均匀涂抹在载体上并干燥。

$2$ 将负片或物体放在载体上并用玻璃板覆盖，从而固定物体，在阳光下进行曝光处理。紫外线作用下，未被物体覆盖的载体表面产生少量二氧化碳，并逐渐形成蓝色影像（产生化合物B，吸附在载体纤维上）。若曝光时间过长则蓝色影像会发生褪色而变浅（产生化合物 C），停止曝光后又会缓慢恢复至蓝色。

$3$ 用水冲洗载体五到十分钟，若冲洗时间短则画面局部呈现黄色，若冲洗时间长则会褪色。适当酸洗可进一步脱去感光剂，显影过程中水洗和酸洗后最初显天蓝色，静置或用低浓度双氧水处理可得深蓝色的影像。

部分无机颜料的说明如下，普鲁士白，普鲁士黄和普鲁士蓝[2]的晶体骨架结构相同，只有柏林绿是混合物，其他均为化合物：

1-1-1 根据无机化学知识和蓝晒工艺过程补全上表中物质相应的化学式和对应工艺中出现化合物的符号，若工艺中未涉及该化合物则符号处写“无”。

1-1-2 写出曝光过程中发生的主反应的离子方程式（有机反应和产物用结构简式表示）。

1-1-3 柏林绿实际上是其他两种颜料的混合物， 指出其组成。

1-1-4 指出为何使用双氧水进行处理。若用沾满汗液 （含大量无机盐） 的手接触蓝晒产品会导致其变质， 形成深色斑点， 试说明原因。

1-2 群青(Ultramarine)是一种昂贵的颜料，早期从青金石中分离得到， 1828 年首次合成了人造群青。群青化学式可视为 $\mathrm { Na _{ 8 - 10 } Al _{ 6 } Si _{ 6 } O _{ 24 } S _{ 2 \sim 4 } } .$ 。

1-2-1 将高岭土(主要成分为 $\mathrm { Al _{ 2 } Si _{ 2 } O _{ 7 } } { \cdot } 2 \mathrm { H } _{ 2 } \mathrm { O } )$ ，无水碳酸钠，石英，木炭和硫磺在坩埚中以特定的比例共同加热得到蓝色群青( 记作$\mathrm { Na _{ 6.8 } Al _{ 5.6 } Si _{ 6.4 } O _{ 24 } S _{ 2.4 } } )$ ， 写出反应方程式。

![](images/b32609091fe00bc3e28e75cff41af7904faf0467128593f5797e5bcfbce8df60.jpg)

1-2-2 群青的晶体结构可用右图简要概括，其顶点和体心为流变的 $\mathrm { S } _{ x } ^{ y _{ - } }$ 离子，深色原子为Si/Al。 其吸收 $600 \mathrm { nm }$ 左右的绿-黄-橙区域宽能带。$\mathbf { S } _{ x } ^{ \phantom { \dagger } }$ -一般为 `{ \bf S } _{ 3 } { \bf \dot { \Delta } }` -和 $\mathbf { S } _{ 2 } \mathbf { \bar { \Sigma } }$ ，据此推测群青的显色机制。
