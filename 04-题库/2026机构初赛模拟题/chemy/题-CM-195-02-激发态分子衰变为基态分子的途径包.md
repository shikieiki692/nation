# 题-CM-195-02-激发态分子衰变为基态分子的途径包

## 题目

### 第 2 题（8 分，占 5%）

激发态分子衰变为基态分子的途径包括荧光发射、系间跨越、内转化等过程。下面考虑如下过程(S 表示基态，S<sup>*</sup>表示单线态激发态，T<sup>*</sup>表示三线态激发态，Q 表示猝灭剂，h 为普朗克常数，v<sub>i</sub>和 v<sub>f</sub>分别为激发光频率和发射光频率，I<sub>abs</sub>为激发步骤的速率，k<sub>f</sub>，k<sub>IC</sub>，k<sub>ISC</sub>，k<sub>Q</sub>分别为各步骤的速率常数)：

激发：S + hv<sub>i</sub> → S<sup>*</sup> ，r<sub>abs</sub>=I<sub>abs </sub>

荧光发射：S<sup>*</sup> → S + hv<sub>f</sub> ，k<sub>f </sub>

内转化：S<sup>*</sup> → S ，k<sub>IC </sub>

系间跨越：S<sup>*</sup> → T<sup>*</sup> ，k<sub>ISC</sub>

淬灭：S<sup>*</sup> + Q → S + Q ，k<sub>Q</sub>荧光寿命 τ 可用于描述荧光分子在激发态上停留时间的长短，一般将其定义为停止光照后达到[S<sup>*</sup>] / [S<sup>*</sup>]<sub>0</sub> = 1 / e([S<sup>*</sup>]<sub>0</sub>指刚停止光照时单线态激发态的浓度)所经历的时间。根据定义可知，若向体系中加入能与处于激发态分子作用的猝灭剂，荧光寿命可能发生改变。有研究人员探究了 O<sub>2</sub>对色氨酸水溶液的荧光猝灭过程，实验测得数据示于下表。根据前述基本模型，推导不加猝灭剂时的荧光寿命 τ<sub>0</sub>以及猝灭剂浓度为[Q]时荧光寿命 τ 的表达式，并根据实验数

## 参考答案

由于[Q]大大过量，因此停止激发后，对[S*]为准一级反应。-d[S*] / dt = k<sub>f</sub>[S*] + k<sub>IC</sub>[S*] + k<sub>ISC</sub>[S*] + k<sub>Q</sub>[Q][S*]因此积分后可得 ln([S*]<sub>0</sub> / [S*]) = (k<sub>f</sub> + k<sub>IC</sub> + k<sub>ISC</sub> + k<sub>Q</sub>[Q])t（1 分）当[S<sup>*</sup>] / [S<sup>*</sup>]<sub>0</sub> = 1 / e 时，t = τ = 1 / (k<sub>f</sub> + k<sub>IC</sub> + k<sub>ISC</sub> + k<sub>Q</sub>[Q])（1 分）在没有猝灭剂时，τ<sub>0</sub> = 1 / (k<sub>f</sub> + k<sub>IC</sub> + k<sub>ISC</sub>)（1 分），即 τ = 1 / (1 / τ<sub>0</sub> + k<sub>Q</sub>[Q])（1 分）因此有 1 / τ = 1 / τ<sub>0</sub> + k<sub>Q</sub>[Q]（2 分）代入数据线性回归可得 k<sub>Q</sub> = 1.3 × 10<sup>10</sup> M<sup>-1</sup>·s<sup>-1</sup>（2 分）
