# 题-CM-285-08-100mol理想气体经历一个如右

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-15-8`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 8 题（11 分）

![](images/40c6d1efa4ac8fe4f4015e43238a83aba77a0e8306c4a77d53c29f0c91558763.jpg)

1.00 mol 理想气体经历一个如右图所示的循环过程，从状态 A(p<sub>A</sub> = 125 kPa, V<sub>A</sub> = 10.0 L)开始，经等温可逆膨胀过程到达状态 B(V<sub>B</sub> = 20.0 L)，再经 pV<sup>n</sup> = C<sub>1</sub>的绝热可逆膨胀过程到达状态 C(p<sub>C</sub> = 20.0 kPa, V<sub>C</sub> = 39.6 L)，再经等温可逆压缩过程到达状态 D，最后经pV<sup>n</sup> = C<sub>2</sub>的绝热可逆压缩过程又回到状态 A。C<sub>1</sub>、C<sub>2</sub>均为常数。

**8-1** 计算状态 B 的压力 p<sub>B</sub>。

**8-2** 计算 n。

**8-3** 计算状态 D 的温度 T<sub>D</sub>、压力 p<sub>D</sub>和体积 V<sub>D</sub>。

**8-4** 计算整个循环过程的热变化 Q 和功变化 W。

**8-5** 以温度 T 为纵坐标，以熵 S 为横坐标，画出该循环过程的示意图(标出对应的状态)。

## 参考答案

**8-1** p<sub>B</sub> = p<sub>A</sub>V<sub>A</sub>/V<sub>B</sub> = 62.5 kPa（1 分）

**8-2** 由 p<sub>B</sub>V<sub>B</sub><sup>n</sup>=p<sub>C</sub>V<sub>C</sub><sup>n</sup>；解得 n = 1.67（1 分，或答 n = 5/3）

**8-3** T<sub>D</sub> = T<sub>C</sub> = p<sub>C</sub>V<sub>C</sub>/nR = 95.3 K（1 分）

由 p<sub>D</sub>V<sub>D</sub> = p<sub>C</sub>V<sub>C</sub>；p<sub>D</sub>V<sub>D</sub><sup>n</sup>=p<sub>A</sub>V<sub>A</sub><sup>n</sup>

解得 p<sub>D</sub> = 40.0 kPa（1 分）V<sub>D</sub> = 19.8 kPa（1 分）

**8-4** Q = Q<sub>AB</sub> + Q<sub>CD</sub> = - W<sub>AB</sub> - W<sub>CD</sub> = nRT<sub>A</sub>lnV<sub>B</sub>/V<sub>A</sub> + nRT<sub>C</sub> ln V<sub>D</sub>/V<sub>C</sub> = 317 J（2 分）

W = -Q = -317 J（2 分）
