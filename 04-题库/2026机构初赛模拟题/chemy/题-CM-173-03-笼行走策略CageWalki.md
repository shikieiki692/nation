# 题-CM-173-03-笼行走策略CageWalki

## 题目

### 第 3 题

# 第 3 题 （13 分， 占比 $10 \%$ ） 有趣的 “笼行走”

“笼行走” 策略(“Cage Walking” Strategy)是一种应用于碳硼烷的金属催化官能团化策略。“笼行走”现象最早由 Hawthorne 于 1971 年在 nido- $\mathrm { \cdot C _{ 2 } B } { \mathrm { qH } } _{ 12 }$ 体系中观察到，其含义是碳硼烷笼上的金属单元发生 1,2-迁移。 （本题中， 碳硼烷骨架上的H 可省略不写）

3-1 碳硼烷笼上 C 原子或 B 原子上的电荷密度是控制金属原子迁移的重要因素之一。o-$\mathrm { C } _{ 2 } \mathrm { B } _{ 10 } \mathrm { H } _{ 12 }$ 和 $\mathrm { m { \mathrm { - } C _{ 2 } B _{ 10 } H _{ 12 } } }$ 的骨架原子编号已展示于下图中，分别将两个碳硼烷中所有 B 原子按电荷密度从高到低排序。

3-2 近年有课题组应用“笼行走”策略实现了 Pd 催化的区域选择性 B-H 键官能团化。

![](images/142b134d59efbded31925328d5e1f61a5887db11752c63c9b4d5de56f0db252d.jpg)

3-2-1 补全上图中含Pd 阳离子中间体 $\pmb { \Delta } ^{ + } { \sim } \pmb { \mathbb { C } } ^{ + }$ 的结构。 （提示： A+中 Pd 为 2 配位）
3-2-2 指出 $\pmb { \Delta } ^{ + } { \sim } \pmb { \mathbb { C } } ^{ + }$ 中Pd 中心的氧化态。
3-2-3 解释其中 1 到 $\pmb { \mathsf { A } } ^{ + }$ 一步和“笼行走”一步的区域选择性。

## 参考答案

![](images/47ebf038f1b6fc1ccb94037cc6dadc14cc8bd182552f52b8a1b65dcdc10f5f3b.jpg)

3-1 o-C₂B₁₀H₁₂: B(9,12) > B(8,10) > B(4,5,7,11) > B(3,6) (1 分);

$m-C_{2}B_{10}H_{12}$ : $B(9,10)>B(5,12)>B(4,6,8,11)>B(2,3)$ （1分）。

C 电负性比 B 大，主要考虑 C 的诱导吸电子效应，可类比卤代烃的电荷分布。

![](images/b21373464d1f2111e6c6f8a051c189e29a14c727025f313e2c8ef49d5bc2e960.jpg)

3-2-1 各 2 分，共 6 分。

![](images/b43c67cf0928d35c02ed5f7962b52e9cec26b129887b07411091d15155f81999.jpg)

3-2-2 +2, +4, +4（各1分，共3分）

3-2-3 1 到 A⁺: Pd(II)较富电子，在酰胺基的配位作用下活化相对缺电子的 B-H 键。(1 分)
“笼行走”: B(8)电荷密度高于 B(4)，更能稳定缺电子的 Pd(IV)。(1 分)
