# 题-CM-205-04-1817年德国格丁根大学的一名教

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy39-14-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（19 分，占 11%）

1817 年，德国格丁根大学的一名教授在一种名为 Calamine 的碳酸盐矿石中发现了元素 X。Calamine 又名菱锌矿，主要成分为 ZnCO<sub>3</sub>。将灼烧 Calamine 得到的混合物溶于硫酸，向溶液中通入硫化氢气体，得到混合物沉淀，其中包含橙黄色沉淀 A。A 中含有元素 X，曾经被用作颜料，因其具有的毒性导致使用范围受到限制。该混合物沉淀经多次洗涤后溶于浓盐酸，A 转化为可溶性化合物 B。除去过量盐酸后中加入足量碳酸铵溶液，B 转化为沉淀 C (反应

1)。将沉淀 C 过滤、清洗、灼烧得到褐色固体 D。D 经过足量的碳还原得到了有光泽的蓝灰色金属单质 X (反应 2)。研究表明，X 单质是一种优良的电极材料和半导体材料。

**4-1** 写出 X 的元素符号。

**4-2** 写出 A ~ D 的化学式。

**4-3** 写出反应 1 ~ 反应 2 的化学方程式。

**4-4** 向 X<sup>2+</sup>的溶液中按一定比例加入 KCN，能够得到一种高对称性晶体 M。M 为立方晶系，其中所有的 K<sup>+</sup>与所有的 CN<sup>-</sup>中的 N 原子通过配位的形式形成[K<sub>4</sub>N<sub>4</sub>]立方体骨架，立方体骨架之间通过共用所有的 K<sup>+</sup>，形成无限的三维框架结构。X<sup>2+</sup>则填入所有由 C 原子形成的空隙中。单独看晶体中所有 X<sup>2+</sup>的位置，发现其具有与金刚石晶体相同的排布方式。

**4-4-1** 写出晶体的化学式。

**4-4-2** 分别指出 K<sup>+</sup>和 X<sup>2+</sup>为中心的配位多面体的形状。

**4-4-3** 分别指出 K<sup>+</sup>和 X<sup>2+</sup>具有的化学环境的数目。

**4-4-4** 若晶体中距离最近的两个 X<sup>2+</sup>间的距离为 555.99 pm，据此计算晶体的密度(若未能推出 X 的元素种类，可用 Mr(X) = 100 g/mol 代替计算)。

## 参考答案

**4-1** Cd（1 分）

**4-2** A CdS B CdCl<sub>2</sub> C CdCO<sub>3</sub> D CdO（各 1 分）

**4-3**反应 1：CdCl<sub>2</sub> + (NH<sub>4</sub>)<sub>2</sub>CO<sub>3</sub> → CdCO<sub>3</sub> + 2NH<sub>4</sub>Cl（2 分）反应 2：CdO + C → Cd + CO（2 分）

**4-4-1** K<sub>2</sub>Cd(CN)<sub>4</sub>（2 分）

**4-4-2** K<sup>+</sup>：八面体（1 分）Cd<sup>2+</sup>：四面体（1 分）

**4-4-3** K<sup>+</sup>：1 种（1 分）Cd<sup>2+</sup>：1 种（1 分）
