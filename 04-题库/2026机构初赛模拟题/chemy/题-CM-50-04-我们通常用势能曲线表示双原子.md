# 题-CM-50-04-我们通常用势能曲线表示双原子

## 题目

### 第 4 题（5 分）

我们通常用势能曲线表示双原子分子的势能与核间距的关系。如右图所示，为氟气单质 $F_{2}$ 和阴离子 $F_{2}^{-}$ 的势能曲线。请根据右图和所学知识，回答以下问题：

4-1 $F_{2}$ 和 $F_{2}^{-}$ 的键级分别为 \_\_\_\_ 和 \_\_\_\_ 。

4-2 $F_{2}$ 和 $F_{2}^{-}$ 的键长分别为 \_\_\_\_ Å 和 \_\_\_\_ Å。

4-3 $F_{2}$ 和 $F_{2}^{-}$ 的键解离能分别为 \_\_\_\_ eV 和 \_\_\_\_ eV。

4-4 $F_{2}$ 和 $F_{2}^{-}$ 的磁属性分别为 \_\_\_\_ 和 \_\_\_\_。

4-5 $F_{2}$ 和 F 的电子亲和能分别为 \_\_\_\_ eV 和 \_\_\_\_ eV。

## 参考答案

第 4 题 （5 分）

4-1 $\mathrm { F } _{ 2 }$ 和 $\mathrm { F } _{ 2 } \mathrm { \cdot }$ 的键级分别为 和$ { 4 - 2 }  { \mathrm { ~ F } _{ 2 } }$ 和 $\mathrm { F } _{ 2 }$ -的键长分别为 Å 和      Å。

$\mathbf { 4 } { \cdot } 4 \mathrm { ~ F } _{ 2 }$ 和 $\mathrm { F } _{ 2 } \mathrm { \cdot }$ 的磁属性分别为 和$\mathbf { 4 } { \cdot } \mathbf { 5 } \ \mathrm { ~ F } _{ 2 }$ 和 F 的电子亲和能分别为 eV 和 eV。
