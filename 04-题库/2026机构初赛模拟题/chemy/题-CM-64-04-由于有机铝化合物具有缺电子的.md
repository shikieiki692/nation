# 题-CM-64-04-由于有机铝化合物具有缺电子的

## 题目

### 第 4 题（8 分）

由于有机铝化合物具有缺电子的特性，因此， 在溶液中，有机铝化合物常被溶剂配位或形成多聚体。例如，在苯溶液中，叠氮二异丁基铝(DBAA)就以单体和三聚体这两种形式存在并达成以下解离平衡：

$$
[ ( i \mathrm { - C _{ 4 } H _{ 9 } } ) _{ 2 } \mathrm { AlN _{ 3 } } ] _{ 3 }  3 ( i \mathrm { - C _{ 4 } H _{ 9 } } ) _{ 2 } \mathrm { AlN _{ 3 } }
$$

为测定上述反应的平衡常数 $K _{ \mathrm { d } }$ ， 在氮气保护下，将 $0.3586 \mathrm { g } \mathrm { DBAA }$ 溶于 $26.9234 \mathrm { g }$ 苯中，测得溶液的凝固点下降 $\Delta T _{ \mathrm { f } } { = } 0.176 \mathrm { K }$ 。已知苯的凝固点下降常数 $K _{ \mathrm { f } } { = } 5.12 \mathrm { K } { \cdot } \mathrm { kg } { \cdot } \mathrm { mol } ^{ - 1 }$ ， 该溶液的体积为 $V = 31.7 \mathrm { mL }$ ， 请据此计算该解离反应的平衡常数 $K _{ \mathrm { d } }$ 和三聚体的解离度 $\scriptstyle a$ 。

## 参考答案

## 第4题（8分）


DBAA 单体和三聚体的摩尔质量为:
 $M_{mono} = 183.2 \, g/mol$ ,  $M_{tri} = 549.7 \, g/mol$
由凝固点下降公式，DBAA 及其多聚体的平均摩尔质量为：
 $M = m_{B} K_{f} / m_{A} \Delta T_{f}$

= 0.3586g × 5.12 K·kg·mol $^{-1}$ / (26.9234 g × 0.176K)（1分）
= 387.5 g/mol（1分）
由： $M=\frac{(1-\alpha)\times3M_{\mathrm{mono}}+(3\alpha)\times M_{\mathrm{mono}}}{1+\alpha}$ （2分）
解得  $\alpha=0.209$ （1分）
三聚体初始浓度为：
 $c=0.3568\mathrm{g}/(549.7\mathrm{g}/\mathrm{mol}\times31.7\mathrm{mL})=2.06\times10^{-2}\mathrm{mol/L}$ （1分）
故平衡常数为：
 $K_{d}=\frac{(3ac)^{3}}{(1-a)c}$ （1分）
 $=1.32\times10^{-4}\ L^{2}/mol^{2}$ （1分）
