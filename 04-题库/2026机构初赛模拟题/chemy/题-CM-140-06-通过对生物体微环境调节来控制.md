# 题-CM-140-06-通过对生物体微环境调节来控制

## 题目

### 第 6 题（8 分）

通过对生物体微环境调节来控制细胞的凋亡已然成为了研究治疗肿瘤的一大方向，其中模拟生物酶而设计出的人工纳米酶具有显著的应用前景。模仿生物酶LOX而设计出的纳米钴氮化物 $\mathrm{Co}_x\mathrm{N}_y / \mathrm{C}$ 便能够靶向控制癌细胞死亡，进而实现对肿瘤的治疗。该纳米材料的合成如下：首先通过Co-MOF(一种含Co元素的金属有机框架)在热条件下分解得到 $\mathrm{Co}_3\mathrm{O}_4 / \mathrm{C}$ ，而后通入 $\mathrm{NH}_3$ 在高温下反应得到纳米钴氮化物 $\mathrm{Co}_x\mathrm{N}_y / \mathrm{C}$ 。随反应温度的不同能够分别得到Co/N比例不同的产物。当温度为 $360^{\circ}\mathrm{C}$ 时得到X，其晶胞参数 $a = 2.80\mathrm{mathring A}$ ， $b = 4.20\mathrm{mathring A}$ ， $c = 4.56\mathrm{mathring A}$ ， $\alpha = \beta = \gamma = 90^{\circ}$ ，可视作畸变的金红石结构，其中N原子为6配位。当温度为 $460^{\circ}\mathrm{C}$ 时得到Y，其晶胞参数 $a = b = 4.54\mathrm{mathring A}$ ， $c = 4.28\mathrm{mathring A}$ ， $\alpha = \beta = 90^{\circ}$ ， $\gamma = 120^{\circ}$ ，可视作Co原子作六方最密堆积，N原子有序填入1/3的八面体空隙，且具有平行于 $c$ 轴且不穿过N的 $6_3$ 螺旋轴。当温度在 $500^{\circ}\mathrm{C}$ 以上时得到Z，其晶胞参数 $a = b = c = 3.71\mathrm{mathring A}$ ， $\alpha = \beta = \gamma = 90^{\circ}$ ，可视作Co原子作立方最密堆积，N原子有序填入1/4的八面体空隙。
c 轴且不穿过N 的63 螺旋轴。当温度在500°C 以上时

6-1 写出 X\~Z 的化学式及 Co 原子周围的 N 原子数。

6-2 以 A、B、C 表示 Co 原子密堆积层的排布，a、b、c 表示 N 原子密堆积层的排布，用口表示空位层，分别写出 Y 和 Z 的堆积方式。(要求 N 原子的在堆积层中的占有率用下标表示，并以上标区分沿 c 轴投影不重合的 N 原子)

示例： $\cdots\mathrm{Ac}_{1/2}\mathrm{Bc}^{\prime}_{1/2}\mathrm{Ab}_{1/2}\mathrm{Cb}^{\prime}_{1/2}\mathrm{Ac}_{1/2}\mathrm{Bc}^{\prime}_{1/2}\mathrm{Ab}_{1/2}\mathrm{Cb}^{\prime}_{1/2}\cdots$

## 参考答案

6-1 X 的化学式为 $Co_{2}N$ （0.5 分），Co 周围有 3 个 N 原子。（0.5 分）

Y 的化学式为 $Co_{3}N$ （0.5 分），Co 周围有 2 个 N 原子。（0.5 分）

Z 的化学式为 $Co_{4}N$ （1 分），Co 周围有 0 或 2 个 N 原子。（1 分）

6-2 Y 的堆积方式为…Ac $_{1/3}$ Bc' $_{1/3}$ Ac $_{1/3}$ Bc' $_{1/3}$ …（2 分）
Z 的堆积方式为…Ac $_{1/4}$ Ba $_{1/4}$ Cb $_{1/4}$ Ac $_{1/4}$ Ba $_{1/4}$ Cb $_{1/4}$ …（2 分）
思考题:

6-3 研究表明，癌细胞在大量消耗葡萄糖的同时产生了大量乳酸，进而使得细胞外 pH 显著下降，导致免疫系统酸中毒而受到抑制。如下图所示，该钴氮化物便能催化乳酸氧化为丙酮酸，而后氧化产物丙酮酸将很快被代谢掉。

![](images/fd01369b6096ad213ddde7c61dd7ed67fcbeddce836a15321ae12cee1af6a9c9.jpg)

研究人员将制得的人工纳米酶注射入小鼠肿瘤部位，14 天后，发现小鼠体内的肿瘤重量相比于实验对照组显著降低。简述该纳米人工酶是如何控制癌细胞死亡的。

6-4 若 3 转化为 4 一步为反应的决速步，则三种钴氮化物中，哪一种更适合作为治疗肿瘤的纳米酶？
