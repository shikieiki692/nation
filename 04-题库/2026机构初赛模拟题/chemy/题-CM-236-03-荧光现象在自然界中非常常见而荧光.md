# 题-CM-236-03-荧光现象在自然界中非常常见而荧光

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy38-14-3`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（23 分，占 14.0%）

荧光现象在自然界中非常常见，而荧光现象在科学技术领域有非常广泛的应用，包括 DNA

测序、成像标记和蛋白质组学研究。光子与分子发生相互作用后在 10<sup>-15 </sup>s 内发生吸收，使得

分子被激发到电子的激发态上。此后，激发态分子可以通过荧光、内转换和系间窜跃等方式

回到基态，而激发态分子的寿命一般在 10<sup>-8 </sup>s。

一般而言，分子接受光子的激发都是单光子激发，一个光子所具有的能量与分子的电子能级

跃迁所需能量相匹配。在入射光的功率足够大时，一个分子可以吸收多个光子的能量发生跃

迁，这样的过程被称为多光子吸收。1931 年，Maria Goeppert-Mayer 在她的博士论文中最先

对多光子吸收过程进行了讨论，但是由于多光子吸收对光强度的高要求，直到 1960 年激光

发明之后多光子吸收才被逐渐证实。1990 年，康奈尔大学的 Denk 课题组首次实现了对猪肝

细胞中染色体的多光子成像，相关工作发表在 Science 上。

**3-1-1** 已知黄色荧光蛋白可以吸收 514 nm 的可见光，发射 527 nm 的荧光，请计算黄色荧光

蛋白第一电子激发态与基态的能量差。

**3-1-2** 如果黄色荧光蛋白通过双光子吸收实现激发，试写出激发光波长的可能值。

**3-2** Lambert-Beer 定律：一般而言我们认为，单光子吸收过程符合 Lambert-Beer 定律，是因

为单个分子对光的吸收与入射光的光强 I、吸收截面 σ 以及单位体积分子个数 n 成正比，即：

![](images/2e95f5f067e0eb260aeb2a34ddac5026e3b302827e44bbd304c4a0cb86cb425a.jpg)

而对于多光子吸收过程（吸收光子数为 n）而言，单个分子对光的吸收强度与光强的 n 次幂

成正比。以双光子吸收为例，推导透光率 T 与光程 b，分子浓度 c 的关系。双光子吸收还符

合 Lambert-Beer 定律吗？

**3-3** 激发光功率：由于在进行双光子激发时，要求第一个光子在被分子吸收的过程中，第二

个光子就要开始与分子进行相互作用。所以双光子激发对光源的功率要求非常苛刻。假定有

一光源可以将光束聚焦在 1μm×1μm 的正方形内；分子对光子的吸收截面为 10<sup>-20 </sup>m<sup>2</sup>，每一

个吸收截面中同一时刻只有一个光子通过（提示：可以用来估算聚焦光束中某一截面中的光

子数）。

**3-3-1** 现用波长为 1000 nm 的光对荧光团进行多光子激发，试估算要实现多光子激发所需光

源的最小功率。

**3-3-2** 上述的功率非常的大，导致大多数的光源无法长时间以如此大的功率运行。同时，过

高的入射光功率会导致样品受到严重的热损坏。为此，常用的多光子激发光源常使用飞秒脉

冲激光，两束持续 100 fs 的脉冲激光之间间隔 12.5 ns。计算脉冲激光的平均功率。

![](images/fdf090906146411fc08cbe75cfe995dac0947dc59db8479144b06204af670875.jpg)

**3-5** 利用多光子技术，使用下面两种探针都可以实现对 Ca<sup>2+</sup>的成像。但是两种探针中只有

indo-1 探针能有效地实现细胞质内的 Ca<sup>2+</sup>成像，而另一种不能。说明 indo-1 探针是如何实现

细胞质内钙离子成像的。

## 参考答案

**3-1-1** ΔE = hc / λ = 3.77 × 10<sup>-19</sup> J（2 分）

**3-1-2** ΔE = 2hc / λ，故激发光波长的可能值为 1028 nm。（2 分）

**3-2** -dI / db = nσI<sup>2</sup>（1 分），故(1 – T) / TI<sub>0</sub> = σbc（2 分），不符合 Lambert-Beer 定律（1 分）。

**3-3-1** P = nhc / λ = 20 kW（4 分，公式 2 分，代入数据 2 分）

**3-3-2** P = 100 fs × 20 kW / 12.5 ns = 0.16 W（2 分）

**3-4** 假设激发过程吸收了 n 个光子，则有 lnI = nlnP（1 分），对数据进行整理得：

![](images/d42b50cd9555a188c72b8ecb12097eacc89c726118b42b1e2bb2a0101e3daf75.jpg)

回归得到斜率 k=2.95（2 分），因此是三光子吸收（1 分）。

**3-5** Indo-1 可以实现胞内钙离子成像（1 分）。Indo-1 的 COOR 基团可以在细胞质内的弱酸

性条件下水解形成羧基（1 分），而在此之前分子是以中性的形式存在，因而可以通过细胞

膜（1 分）。水解后 Ca<sup>2+</sup>与 EDTA 的类似结构络合（1 分），而吲哚基团则可以接受多光子

激发实现成像。（1 分）
