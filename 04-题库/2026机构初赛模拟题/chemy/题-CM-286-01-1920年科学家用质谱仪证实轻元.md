# 题-CM-286-01-1920年科学家用质谱仪证实轻元

## 题目

### 第 1 题（9 分）

1920 年，科学家用质谱仪证实，轻元素的非放射性同位素可以稳定存在。氘是氢的核素之一，其原子质量为 2.014102 u，无放射性。氘原子由质子、中子和电子组成，它们的质量分别为 1.007277 u，1.008665 u 和 0.000549 u。

**1-1** 解释为什么氘原子的质量小于质子、中子和电子的质量之和。

**1-2** 某烃的部分氢原子被氘原子取代，2.00 g 该烃在空气中完全燃烧，生成 5.73 g 二氧化碳和 3.21 g 水。通过计算求出该烃的化学式。该烃具有旋光性，画出其结构简式。

## 参考答案

**1-1** 质子和中子结合形成氘原子时会放出巨大的能量，按照质能方程 ΔE = Δmc<sup>2</sup>转化为质

量亏损（2 分）

**1-2** 设烃的化学式为 C<sub>x</sub>H<sub>y</sub>D<sub>z</sub>，则：

(12x + y + 2z) / (44x) = 2.00 / 5.73（1 分）

(12x + y + 2z) / (9y + 10z) = 2.00 / 3.21（1 分）

解得：x : y : z = 3 : 6 : 2

因此为二氘代烃 C<sub>3</sub><sup>1</sup>H<sub>6</sub><sup>2</sup>H<sub>2</sub>（1 分），结构为：

![](images/74d04b749ace57ec607d7e7a9d2b82b47a73434160c6d01b0ec89b988fc90688.jpg)

标外消旋符号的，不得分。

通过其他合理方法得到正确答案的，也可得分。如以下解法也可供参考：

n(O<sub>2</sub>) = (5.73 + 3.21 - 2.00) / 32.00) = 0.217 (mol)

n(CO<sub>2</sub>) = 5.73 / 44.01 = 0.130 (mol)

n(H) = (0.217 × 2 - 0.130 × 2) × 2 = 0.348 (mol)

n(H) / n(CO<sub>2</sub>) = 2.68 ≈ 8 / 3，为 C<sub>3</sub>H<sub>8 </sub>

摩尔质量 M = 2.00 × 3 / 0.130 = 46.2 (g/mol)

因此为二氘代烃 C<sub>3</sub><sup>1</sup>H<sub>6</sub><sup>2</sup>H<sub>2</sub>
