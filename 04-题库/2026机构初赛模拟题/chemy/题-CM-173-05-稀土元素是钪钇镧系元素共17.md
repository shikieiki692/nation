# 题-CM-173-05-稀土元素是钪钇镧系元素共17

## 题目

### 第 5 题

第 5 题 （7 分， $7 \%$ ）稀土氧化物的晶体结构

稀土元素是钪、钇、镧系元素共 17 种元素的统称，是重要的国家战略资源。 如图所示，某稀土元素 $\boldsymbol { \mathsf { M } }$ 的氧化物 ${ \pmb M } _{ 2 } \mathrm { O } _{ 3 }$ 的一种晶体结构可以被描述成： $M$ 采取 ccp 堆积，O 原子填所有四面体空隙构成小立方体，除去处于体对角线上的两个O 原子以保持化学计量比， 该结构可以看作萤石结构的变体。 图中所示立方体晶胞边长为 $529 \mathrm { pm }$ 。

![](images/66903e2e1eea7695e55524548e331be4ae090079afb2d60eaec806a0d02feaf5.jpg)

5-1 该 `{ \bf M } _{ 2 } { \bf O } _{ 3 }` 晶体属于哪种晶系， 哪种点阵形式？

5-2 图中示出的晶胞是否是正当晶胞？如果是， 指出晶胞中包含的特征对称元素及位置；
如果不是，计算其正当晶胞的晶胞参数。

5-3 该 `{ \bf M } _{ 2 } { \bf O } _{ 3 }` 晶体的密度为 $5.06 \mathrm { g } \mathrm { cm } ^{ - 3 }$ ， 推断 $M$ 为何种元素。

## 参考答案

![](images/936f71c2e903b9e5869aaa582c06ee1c0f48fad68601057e260b624e29310ede.jpg)

5-1 立方晶系（1 分）；简单立方点阵（1 分）。

5-2 是。（1 分）特征对称元素及位置：4 条 $C_{3}$ ；体对角线方向，经过 M 构成的四面体空隙中心。（2 分，全答对才得分；位置答“体对角线”不得分，其他正确答案的等价表述也得分，只答出“是”不得分）

5-3 氧化物分子量:

$$
M = \frac {\rho V N _{\mathrm{A}}}{Z} = \frac {5.06 \times 529^{3} \times 10^{- 30} \times 6.02 \times 10^{23}}{2} = 226 \mathrm{g} \mathrm{mol} ^{- 1} (1 \text {分})
$$

稀土元素 M 分子量:

$$
M _{\mathbf {M}} = \frac {225.5 - 16.00 \times 3}{2} = 88.8 \mathrm{g} \mathrm{mol} ^{- 1}
$$

M 为 Y 元素（1 分）
