# 题-CM-170-03-笼型硼烷与笼型碳硼烷的结构极

## 题目

### 第 3 题 12 分， $5 \%$

笼型硼烷与笼型碳硼烷的结构极具研究价值。某实验室欲通过如下反应制备一种经典碳硼烷C，硫-碳键在反应过程中始终未发生变化，方程式均未配平。

```text
\mathrm { \bf B } _{ 10 } \mathrm { \bf H } _{ 14 } + \mathrm { \bf S } \mathrm { Et } _{ 2 } \to \mathrm { \bf ~ A } + \mathrm { \bf B }
\bf { A } + \mathrm { C } _{ 2 } \mathrm { H } _{ 2 }  \bf { C } + \mathrm { SEt } _{ 2 } + \bf { B }
```

3-1 写出 A、 B、 C 的化学式。

3-2 运用韦德规则解释C 的结构类型， 并列出其 $s , \ t , \ y , \ x$ 数码方程组。

## 参考答案

## 第3题（12分，5%）


$$
\mathbf {A} + \mathrm{C} _{2} \mathrm{H} _{2} \rightarrow \mathbf {C} + \mathrm{SEt} _{2} + \mathbf {B}
$$

3-1 $\mathbf{A}\mathrm{B}_{10}\mathrm{H}_{12}(\mathrm{SEt}_2)_2$ $\mathbf{B}\mathrm{H}_2$ $\mathbf{C}(\mathrm{CH})_2(\mathrm{BH})_{10}$ （每个2分）

3-2 $(\mathrm{CH})_{2}(\mathrm{BH})_{10}$ 的等电子体为 $[(\mathrm{BH}_{12})]^{2-}$ （1 分）

$$
b = n + 0.5 d = 12 + 1 = 13 = 12 + 1 \text {(1分)}
$$

从结构来说，为 $n+1$ 型硼烷，即闭式硼烷（1 分）

通过氢原子守恒可得 $s + x = 0$ （1 分）

通过 B 价轨道守恒可得 $2s + 3t + 2y + x = 36$ （1 分）

通过 B 价电子守恒可得 $2s + 2t + 2y + 2x = 26$ （1 分）
