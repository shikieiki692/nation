# 题-CM-290-03-在HgCl2催化下金属M与一元醇

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy0-20-3`；联赛系列，源＝`Chemy化学奥林匹克竞赛联赛试题合集(1~24).pdf`（本地未存）。版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 3 题（9 分）

在 HgCl<sub>2</sub>催化下，金属 M 与一元醇 ROH 加热反应，经减压蒸馏、提纯，可制得白色晶体 X。

**3-1** 一元醇 ROH 含碳 60.0%，氢有 3 种环境。推出 ROH 的结构简式(ROH 仅含碳、氢、氧)。

**3-2** 1.002 g X 在空气气氛中充分氧化，残余固体 0.250 g，其成分为金属 M 的氧化物，该过程中 M 的氧化态未发生变化。通过计算，确定 M 的元素符号和 X 的化学式。

**3-3** 写出制备该白色晶体的化学反应方程式(要求系数为最简整数比)。

**3-4** 1.3505 g X 溶解于 21.70 g 苯，测得熔点下降 0.39°C。计算苯溶液中 X 的分子量(苯的熔点下降常数为 5.12 K·kg·mol<sup>-1</sup>)；指出在苯溶液中，X 为几聚体。

**3-5** 苯溶液中 X 的多聚体具有三重旋转轴，画出其结构简式。

## 参考答案

**3-1** 设醇 A 分子中有 n 个碳原子，则醇 A 的摩尔质量为：

M<sub>A</sub> = 12.0 × n / 60.0% = 20.0 n (g/mol) (n = 1, 2, 3, ...)（0.5 分）

当 n = 1 时，M<sub>A</sub> = 20.0 g/mol，无合理解；

当 n = 2 时，M<sub>A</sub> = 40.0 g/mol, 无合理解；

当 n = 3 时，M<sub>A</sub> = 60.0 g/mol，符合条件的有 C<sub>3</sub>H<sub>8</sub>O；（0.5 分）

当 n ≥ 4 时，一元醇的含碳量必然大于 60.0%，无合理解。

C<sub>3</sub>H<sub>8</sub>O 为正丙醇或异丙醇；氢有 3 种化学环境，则符合条件的为异丙醇(CH<sub>3</sub>)<sub>2</sub>CHOH（1

分）

**3-2** 设 M 的摩尔质量为 M<sub>M</sub>；X 的化学式为 M(OCH(CH<sub>3</sub>)<sub>2</sub>)<sub>m</sub>，分解后得到 MO<sub>m/2</sub>，则：

(M<sub>M</sub> + 59.1m g/mol) / (M<sub>M</sub> + 8.0m g/mol) = 1.002 g / 0.250 g（0.5 分）

将 m = 1, 2, 3, ...依次代入上式，得当 m = 3（0.5 分）时，M<sub>M</sub> = 27.0 g/mol，为 Al（0.5 分）；

X 为异丙醇铝 2Al(OCH(CH<sub>3</sub>)<sub>2</sub>)<sub>3</sub>（0.5 分）

**3-3** 2Al + 6(CH<sub>3</sub>)<sub>2</sub>CHOH = 2Al(OCH(CH<sub>3</sub>)<sub>2</sub>)<sub>3</sub> + 3H<sub>2</sub>（1 分）

**3-4** (1.3505 g × 5.12 K·kg·mol<sup>-1</sup>) / (0.39 K × 21.70 g) = 0.817 kg·mol<sup>-1</sup>

所以苯溶液中 X 的分子量为 817（1 分），X 为四聚体（1 分）
