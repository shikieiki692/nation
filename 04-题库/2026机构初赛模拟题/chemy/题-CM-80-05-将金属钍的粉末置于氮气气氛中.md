# 题-CM-80-05-将金属钍的粉末置于氮气气氛中

## 题目

### 第 5 题（11 分）

将金属钍的粉末置于氮气气氛中加热至 $500^{\circ}$ C 以上，生成一种红褐色粉末。该红褐色粉末为钍的氮化物，其呈现出较好的抗磁性和电绝缘性。该氮化物晶体中，Th 原子和 N 原子均有两种化学环境。Th 原子作最密堆积，其堆积方式

为…ABABCBCACABABCBCAC…；相邻两密堆积层之间的所有四面体空隙或所有八面体空隙被 N 原子占据；这两种 N 原子的数目比为 1:1。晶胞参数为 $a = b = 387 \mathrm{pm}$ ; $c = 2739 \mathrm{pm}$ ; $\alpha = \beta = 90^{\circ}$ ; $\gamma = 120^{\circ}$ 。

5-1 推出一个晶胞的原子组成以及该晶体的化学式。

5-2 分别指出晶体中两种钍原子的配位数以及这两种钍原子在一个晶胞中的数目。

5-3 写出该晶体作平移周期性重复的最小单位。

5-4 计算该晶体的密度(钍的原子量为 232.0)。

## 参考答案

5-2 一种钍原子配位数为6（1 分），在晶胞中有3 个（1 分）另一种钍原子配位数为7（1 分），在晶胞中有6 个（1

$$
5 - 4 \rho = \frac {Z M}{N _{\mathrm{A}} V} = \frac {3 \times (232.0 \times 3 + 14.01 \times 4)}{6.022 \times 10^{23} \times 387^{2} \times 2739 \times \sin 120^{\circ} \times 10^{- 30}} = 10.55 (\mathrm{g} / \mathrm{cm} ^{3}) (2 \text {分})
