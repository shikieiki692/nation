# 题-CM-72-10-X-射线衍射表明化合物是一种

## 题目

### 第 10 题（8 分）

X-射线衍射表明，化合物 $[ \mathrm { Ti } _{ 7 } \mathrm { O } _{ 4 } ( \mathrm { OC } _{ 2 } \mathrm { H } _{ 5 } ) _{ 20 } ]$ 是一种具有紧密相连的三层结构的簇合物。该簇合物具有与水分子具有相同的对称性；钛均为六配位；乙氧根离子有单配和桥连两种配位形式；四个“独立氧”中，有两个“独立氧”配位数为 3，另外两个“独立氧”配位数为 4。该簇合物的 7 个钛原子中，有一个钛原子处于簇的中心位置，与该钛原子配位的氧配体(或含氧配体)均为桥连配体。

10-1 请通过计算和推演， 给出 $[ \mathrm { Ti } _{ 7 } \mathrm { O } _{ 4 } ( \mathrm { OC } _{ 2 } \mathrm { H } _{ 5 } ) _{ 20 } ]$ 中单配和桥连乙氧基的数目之比。

10-2 请画出 $[ \mathrm { Ti } _{ 7 } \mathrm { O } _{ 4 } ( \mathrm { OC } _{ 2 } \mathrm { H } _{ 5 } ) _{ 20 } ]$ 的结构示意图(乙氧基与“独立氧” 均可用 “O” 表示)。

## 参考答案

## 第10题（8分）

10-1 由 $7 \times 6 = 2 \times 3 + 2 \times 4 + x + 2(20 - x)$

得 $x = 12$ ，故桥连乙氧基数目为 $20 - x = 8$

3:2（3分，过程2分，结果1分）
