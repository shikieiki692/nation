# 题-CM-122-05-5-1化合物A可发生二聚形成

## 题目

### 第 5 题（14 分）

5-1 化合物 A 可发生二聚形成 $A_{2}$ ，该二聚反应构成如下平衡：

$$
2 \mathbf {A} \rightleftarrows \mathbf {A} _{2} \quad K _{c} ^{\theta}
$$

反应的平衡常数可通过偏振法测得，其原理是测定溶液中反应达到平衡时的比旋光度 $[\alpha]_{\mathrm{D}}$ 以此计算得到反应平衡常数 $K_{c}^{\theta}$ 。已知反应达到平衡时 $[\alpha]_{\mathrm{D}}$ 满足如下关系式：
衡常数Kcθ。已知反应达到平衡时[α]D 满足如下关系式：[α]D = x12[α]1 + x22[α]2其中x1 和x2 为对

$$
[ \alpha ] _{\mathrm{D}} = x _{1} ^{2} [ \alpha ] _{1} + x _{2} ^{2} [ \alpha ] _{2}
$$

其中 $x_{1}$ 和 $x_{2}$ 为对应物种的摩尔分数， $[\alpha]_{1}$ 和 $[\alpha]_{2}$ 为对应物种单独存在时的比旋光度。

5-1-1 化合物 $\mathbf{A}$ 的结构如右图所示, 画出其二聚体 $\mathbf{A}_{2}$ 的结构。

5-1-2 在室温下，总浓度为 8.0 mmol/L 的化合物 A 在 CCl₄ 溶剂中达到平衡，测得体系的比旋光度 [α]D = -6 deg dm⁻¹ g⁻¹ mL。化合物 A 和二聚体 A₂ 单独存在时的比旋光度分别为 [α]₁ = -1 deg dm⁻¹ g⁻¹ mL, [α]₂ = -203 deg dm⁻¹ g⁻¹ mL，忽略体系中可能存在的其他物种，计算该二聚反应的平衡常数 Kc θ。

5-2 在室温下将 0.15 g 化合物 $H_{3}L$ (结构如下图所示) 溶解于无水乙醇中，加入 1 mL 吡啶溶液和 0.09 g 乙酸镍，将混合物在 50°C 下搅拌 30 min，得到深黑色溶液。在空气中缓慢蒸发，以 48% 的产率得到了块状黑色单晶 X。对 X 元素分析可知：C 52.94；H 3.33；N 12.87；O 14.69 (均为质量分数，%)。

5-2-2 对化合物 $H_{3}L$ 以及所得的配合物 X 分别进行红外光谱测定，得到如下所示的结果。主要的 IR 吸收峰(KBr, cm $^{-1}$ ): $H_{3}L$ : 1692; 1590; 1543; 1520; X: 1602; 1563; 1518。

解释二者 IR 光谱的区别的来源，并画出 L 配位时的结构。

5-2-3 对配合物 X 的晶体结构进行表征，发现其为单斜晶系， $a = 2492.7 \, pm, b = 1614.0 \, pm, c = 1218.1 \, pm, \beta = 94.59^\circ$ 。已知 Z = 4，计算该晶体的密度。

5-1-2（共3分）

设 $\mathbf{A}$ 和 $\mathbf{A}_2$ 的摩尔分数分别为 $x_{1}$ 和 $x_{2}$ ，其中 $x_{1} + x_{2} = 1$ 将已知的比旋光度数据带入 $[a]_{\mathrm{D}} = x_{1}^{2}[a]_{1} + x_{2}^{2}[a]_{2}$ 得： $-x_{1}^{2} - 203x_{2}^{2} = -6$ 联立上述二式，解得 $x_{1} = 0.838$ ， $x_{2} = 0.161$ （1分）
又 $c(\mathbf{A}) + 2c(\mathbf{A}_2) = 0.0080 \, \mathrm{mol/L}$ ，联立解得 $c(\mathbf{A}) = 5.78 \times 10^{-3} \, \mathrm{mol/L}$ ， $c(\mathbf{A}_2) = 1.12 \times 10^{-3} \, \mathrm{mol/L}$ 故 $K_{c}^{\theta} = c(\mathbf{A}_2) \times c^{\theta} / [c(\mathbf{A})]^2 = (1.12 \times 10^{-3}) / (5.78 \times 10^{-3})^2 = 33.5$ （2分）

![](images/fd3f41770be99fff6c4bdc275371b163aeebf988846a81188545cf9ceb8fb0e5.jpg)

## 5-2-1（共5分）

由元素分析结果可得 $n(\mathrm{C}):n(\mathrm{O})=4.80,\quad n(\mathrm{C}):n(\mathrm{H})=1.33,\quad n(\mathrm{N}):n(\mathrm{O})=1.00$ （1分）
X 中含氮配体只可能为 L 和吡啶，化学式分别为 $C_{14}H_{8}N_{3}O_{5}$ 和 $C_{5}H_{5}N$ 由 $n(\mathrm{N}):n(\mathrm{O})=1.00$ 可知，L 和吡啶的个数比为 1:2（1 分）
假设 X 中 L 为 1 个，吡啶为 2 个，则 C 的个数为 24，N 和 O 的个数均为 5，H 的个数为 18，恰好符合上述元素分析所得的比例，故 X 中只含有 L 和吡啶两种配体（1 分）
设 X 中 L 的个数为 x，则吡啶的个数为 2x
中心金属显然为 Ni，故当 x=2 时，剩余 M=176.1 g/mol，对应于 3 个 Ni（1 分）
故 X 的化学式为 $\mathrm{Ni}_{3}\mathrm{L}_{2}(\mathrm{C}_{5}\mathrm{H}_{5}\mathrm{N})_{4}$ （1 分）
