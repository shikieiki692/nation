# 题-CM-58-04-在C下加热金单质气体A单质气

## 题目

### 第 4 题（11 分）

在 $370^{\circ}$ C 下，加热金、单质气体 A、单质气体 B 的混合物可得到一种 1:1 型盐 X。实验表明，X 呈现顺磁性，其阳离子为双核阳离子，键级为 2.5，而阴离子为八面体型离子。将 X 在无 A 和 B 存在下加热到 $180^{\circ}$ C，X 会分解生成 A、B 和 C。C 为双核配合物，其中金的氧化态与 X 中相同。

4-1 已知 A 和 B 的元素在周期表中相邻，写出 A、B、C、X 的化学式。

4-2 事实上 X 的顺磁性仅与阳离子有关，而 X 的阴离子呈现抗磁性。

4-2-1 根据配合物的杂化轨道理论，指出 X 阴离子中心原子的杂化方式。

4-2-2 根据配合物的晶体场理论，指出 X 阴离子中心原子在八面体场中的价电子排布。若分裂能为 $\Delta_{0}$ ，成对能为 P，写出晶体场稳定化能 CFSE 的表达式。

4-2-3 X 阴离子的磁属性与按照光谱化学序列的预测结果不符，解释原因。
