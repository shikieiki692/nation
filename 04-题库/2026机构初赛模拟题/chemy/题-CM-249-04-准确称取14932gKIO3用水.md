# 题-CM-249-04-准确称取14932gKIO3用水

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-17-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（9 分）

准确称取 1.4932 g KIO<sub>3</sub>，用水溶解，定容至 250 mL，配成 KIO<sub>3</sub>标准溶液。准确移取 25.00 mL KIO<sub>3 </sub>标准溶液于碘量瓶中，加入一定量的 KI 溶液和硫酸(反应 1)，用水密封后置于暗处，10 min 后用 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>标准溶液滴定(反应 2)，快到终点时加入淀粉溶液后继续滴定，消耗 27.63 mL。准确称取 0.2587 g 铜块，用浓硝酸溶解(反应 4)，冷却后用水稀释，然后加入一定量的 KI 溶液(反应 4)，用水密封后置于暗处，10 min 后用 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>标准溶液滴定，快到终点时加入淀粉溶液后继续滴定，共消耗 26.53 mL。

**4-1** 写出反应 1~反应 4 的离子反应方程式；计算铜块中 Cu 的含量(质量分数)。

**4-2** 淀粉溶液必须在快到终点时加入，而不能提前加入，说明理由。

## 参考答案

**4-1** 反应 1：IO<sub>3</sub><sup>- </sup>+ 5I<sup>-</sup> + 6H<sup>+</sup> → 3I<sub>2</sub> + 3H<sub>2</sub>O（1 分）

反应 2：I<sub>2</sub> + 2S<sub>2</sub>O<sub>3</sub><sup>2-</sup> → 2I<sup>-</sup> + S<sub>4</sub>O<sub>6</sub><sup>2-</sup>（1 分）

反应 3：Cu + 4H<sup>+</sup> + 2NO<sub>3</sub><sup>-</sup> → Cu<sup>2+</sup> + 2H<sub>2</sub>O + 2NO<sub>2</sub>（1 分）

反应 4：2Cu<sup>2+</sup> + 4I<sup>-</sup> → 2CuI + I<sub>2</sub>（1 分）

I<sub>2</sub>写成 I<sub>3</sub><sup>-</sup>配平，也可以

KIO<sub>3</sub>标准溶液浓度 c<sub>1</sub> = m<sub>1</sub>/M<sub>1</sub>V = 0.02791 mol L<sup>−1</sup>（1 分）

则 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>标准溶液浓度 c<sub>2</sub> = 6c<sub>1</sub>V/V<sub>1</sub> = 0.1515 mol L<sup>−1</sup>（1 分）

故 0.2587 g 铜块中 n(Cu) = c<sub>2</sub>V<sub>2</sub> = 4.019×10<sup>−3</sup> mol

因此含量为 98.73%（1 分）

**4-2** 提前加入淀粉溶液，淀粉会吸附一些 I<sub>2</sub>而无法释放，给滴定带来误差（2 分）

有兴趣的选手可思考以下问题：

**4-3** 移取 25.00 mL 的碘标准溶液于锥形瓶中，用上述的 Na<sub>2</sub>S<sub>2</sub>O<sub>3 </sub>标准溶液标定，快到终点时加入淀粉溶液后继续滴定，共消耗 13.32 mL。

**4-3-1** 计算碘标准溶液的浓度。

**4-3-2** 假设碘标准溶液中的碘元素全以 I<sub>2</sub>存在（初始时为 I<sub>2</sub>的悬浊液），已知 I<sub>2</sub>在水中的最大溶解度为 0.001332 mol L<sup>−1</sup>，而反应 I<sub>2</sub>(aq) + I<sup>-</sup>(aq) = I<sub>3</sub><sup>-</sup>(aq)的平衡常数 K = 708。计算在上述滴定过程中，固体 I<sub>2</sub>刚好溶解时加入的 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>溶液的体积。

**4-3-1** 碘标准溶液 c = c<sub>2</sub>V<sub>3</sub>/2V = 0.04036 mol L<sup>−1</sup>

**4-3-2** 设加入 Na<sub>2</sub>S<sub>2</sub>O<sub>3</sub>溶液的体积为 V mL 时固体 I<sub>2</sub>刚好溶解，此时溶液体积为(25<sub> </sub>+<sub> </sub>V) mL由物料守恒可知([I<sup>−</sup>]<sub> </sub>+<sub> </sub>3[I<sub>3</sub><sup>−</sup>]<sub> </sub>+<sub> </sub>2×0.001332)(25<sub> </sub>+<sub> </sub>V) = 2×25c由电子守恒可知([I<sup>−</sup>]<sub> </sub>+<sub> </sub>[I<sub>3</sub><sup>−</sup>])(25<sub> </sub>+<sub> </sub>V) = c<sub>2</sub>V由反应平衡可知<sub> </sub>[I<sub>3</sub><sup>−</sup>] = 708×0.001332[I<sup>−</sup>]则可解得 V = 6.32 mL
