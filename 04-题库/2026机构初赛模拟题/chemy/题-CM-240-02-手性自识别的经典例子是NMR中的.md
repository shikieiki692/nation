# 题-CM-240-02-手性自识别的经典例子是NMR中的

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-3-2`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 2 题（14 分）

手性自识别的经典例子是 NMR 中的自诱导非对映异构效应（SIDA，也称为对映异构的自诱导识别），这一效应意指某些手性非外消旋分子在溶液中自发聚集，形成非对映的同手性聚合物或异手性聚合物，体现出不同的 NMR 信号。e.r.为对映体比例，e.e.为对映体过量值，e.e. = (c<sub>R</sub> – c<sub>S</sub>) / (c<sub>S</sub> + c<sub>R</sub>) × 100 %。

**2-1** 分子 A 91:9 e.r.的 CDCl<sub>3</sub>溶液具有 SIDA，指出手性碳的绝对构型，画出它在溶液中二聚的结构，不考虑立体化学。

![](images/6057dda4489907e0d65a70bd059cbbd9b30c53c4c6bd5a03997c97eb63d93d8d.jpg)

A以 A 为例，SIDA 可以简单表述如下：依照手性碳的构型分别记两种分子为 S 和 R，则溶液中存在如下平衡。

S + S = SS K<sub>SS </sub>

R + R = RR K<sub>RR </sub>

S + R = SR（与 RS 相同） K<sub>SR </sub>在 NMR 时间尺度下该平衡非常快，因此能观察到的化学位移是各个物种的加权平均：

δ<sup>obs</sup><sub>R</sub> = x<sub>R</sub>δ<sub>R</sub> + 2x<sub>RR</sub>δ<sub>RR</sub> + x<sup>R</sup><sub>SR</sub>δ<sub>SR </sub>

δ<sup>obs</sup><sub>S</sub> = x<sub>S</sub>δ<sub>S</sub> + 2x<sub>SS</sub>δ<sub>SS</sub> + x<sup>S</sup><sub>SR</sub>δ<sub>SR </sub> x<sub>i</sub>表示各个物种分别在总 R 或总 S 中的摩尔分数，即 x<sub>R</sub> + 2x<sub>RR</sub> + x<sup>R</sup><sub>SR</sub> = 1。当 δ<sup>obs</sup><sub>R</sub> ≠ δ<sup>obs</sup><sub>S</sub>时，在 NMR 上能观察到两组峰。显然有 K<sub>SS</sub> = K<sub>RR</sub>，δ<sub>R</sub> = δ<sub>S</sub>，δ<sub>RR</sub> = δ<sub>SS</sub>。

**2-2** 若将溶剂更换为 DMSO-d<sub>6</sub>、MeOD-d<sub>4</sub>或者 DMF-d<sub>7</sub>，NMR 谱中 SIDA 的特征峰将消失，解释原因。

**2-3** 以光学纯的 A 为例，推导出用 δ<sup>obs</sup>、初始浓度 C 和化学位移表示的二聚平衡常数。

**2-4** 假设 K<sub>SR</sub> = 2K<sub>SS</sub>，化合物浓度足够高，可以忽略平衡时溶液中的 S 和 R 单体，推导 Δδ<sup>obs</sup>（以 δ<sup>obs</sup><sub>R</sub> – δ<sup>obs</sup><sub>S</sub>记）和 e.e.值的关系。

## 参考答案

**2-1** 绝对构型为 S（1 分）

![](images/e24919418e168c34d8f509659faa45a3168d2fb998b438a75680901a95fd1d55.jpg)

**2-2** 这些为高极性溶剂，破坏了 A 之间的氢键使二聚体无法形成（2 分）

**2-3** 由于 A 是光学纯的，因此溶液中仅有 S 和 SSδ<sup>obs</sup> = x<sub>S</sub>δ<sub>S</sub> + 2x<sub>SS</sub>δ<sub>SS</sub> = δ<sub>S</sub> + 2x<sub>SS</sub>(δ<sub>SS</sub> – δ<sub>S</sub>) = δ<sub>S</sub> + 2[SS](δ<sub>SS</sub> – δ<sub>S</sub>)/C（1 分）则[SS] = C · (δ<sup>obs</sup> – δ<sub>S</sub>) / 2(δ<sub>SS</sub> – δ<sub>S</sub>)（1 分）[S] = C – 2[SS] = C[1 – (δ<sup>obs</sup> – δ<sub>S</sub>)/(δ<sub>SS</sub> – δ<sub>S</sub>)] = C · (δ<sub>SS</sub> – δ<sup>obs</sup>) / (δ<sub>SS</sub> – δ<sub>S</sub>)（1 分）K = [SS]/[S]<sup>2</sup> = (δ<sub>SS</sub> – δ<sub>S</sub>)(δ<sup>obs</sup> – δ<sub>S</sub>) / 2(δ<sub>SS</sub> – δ<sup>obs</sup>)<sup>2</sup>C（1 分，共 4 分）

**2-4** 忽略 S 和 R 后，SR 由下述反应产生：

SS + RR = 2SR K = [SR]<sup>2</sup> / [SS][RR] = K<sub>SR</sub><sup>2</sup> / K<sub>SS</sub>K<sub>RR</sub> = 4δ<sup>obs</sup><sub>R</sub> = 2x<sub>RR</sub>δ<sub>RR</sub> + x<sup>R</sup><sub>SR</sub>δ<sub>SR</sub> = δ<sub>RR</sub> + x<sup>R</sup><sub>SR</sub>(δ<sub>SR</sub> – δ<sub>RR</sub>)δ<sup>obs</sup><sub>S</sub> = 2x<sub>SS</sub>δ<sub>SS</sub> + x<sup>S</sup><sub>SR</sub>δ<sub>SR</sub> = δ<sub>SS</sub> + x<sup>S</sup><sub>SR</sub>(δ<sub>SR</sub> – δ<sub>SS</sub>)Δδ<sup>obs</sup> = δ<sup>obs</sup><sub>R</sub> – δ<sup>obs</sup><sub>S</sub> = (x<sup>R</sup><sub>SR</sub> – x<sup>S</sup><sub>SR</sub>)(δ<sub>SR</sub> – δ<sub>SS</sub>) x<sup>R</sup><sub>SR</sub> – x<sup>S</sup><sub>SR</sub> = [SR] / c<sub>R</sub> – [SR] / c<sub>S</sub> = [SR](c<sub>S</sub> – c<sub>R</sub>) / c<sub>S</sub>c<sub>R </sub>

= [SR](c<sub>S</sub> – c<sub>R</sub>) / (2[SS] + [SR])(2[RR] + [SR])

= [SR](c<sub>S</sub> – c<sub>R</sub>) / [4[SS][RR] + 2[SR]([SS] + [RR]) + [SR]<sup>2</sup>]

= (c<sub>S</sub> – c<sub>R</sub>) / 2([SS] + [RR] + [SR]) = (c<sub>S</sub> – c<sub>R</sub>) / (c<sub>S</sub> + c<sub>R</sub>)

= -e.e.故 Δδ<sup>obs</sup> = -e.e.(δ<sub>SR</sub> – δ<sub>SS</sub>)（4 分，写 δ<sub>RR</sub>也可）
