在 $4000 \mathrm { K }$ 下， 向某恒压容器中充入 $0.100 \mathrm { mol } \mathrm { XY } _{ 2 } ( \mathrm { g } )$ 和 $0.100 \mathrm { mol } \mathrm { Y } _{ 2 } ( \mathrm { g } )$ 并达平衡， 此时容器的体积为 $20.0 \mathrm { L }$ 。 请计算：
为20.0 L。请计算：5-1 体系中X(s)的

5-1 体系中 $\mathrm { X ( s ) }$ 的物质的量。

5-2 体系中 $\mathrm { \ X ( g ) }$ 、 $\Upsilon _{ 2 } ( \mathbf { g } )$ 、 $\Upsilon ( \mathfrak { g } )$ 、 $\mathrm { XY } _{ 2 } ( \mathrm { g } )$ 、 $\mathrm { XY ( g ) }$ 各自的分压(设 $p ^{ \ominus } { = } 1.00 \times 10^{ 5 } \mathrm { Pa } )$ 。(对该体系， 反应的标准摩尔吉布斯自由能变和平衡常数满足： $\Delta _{ \mathrm { r } } G ^{ \ominus } = - R T \mathrm { ln } K ^{ \ominus }$ )

## 参考答案

第5题（12分）

<table><tr><td>物质</td><td> $\Delta_{\text{f}}G^{\ominus}(4000\ \text{K})/(kJ/mol)$ </td></tr><tr><td>X(s)</td><td>0</td></tr><tr><td>X(g)</td><td>92.427</td></tr><tr><td>$Y_{2}(g)$</td><td>0</td></tr><tr><td>Y(g)</td><td>-15.541</td></tr><tr><td>XY2(g)</td><td>353.687</td></tr><tr><td>XY(g)</td><td>194.335</td></tr></table>



**5-1** 根据标准摩尔吉布斯生成自由能,该体系中X(s)的量远大于其他含X物种,故有: $n(X(s)) = n_0(XY_2) = 0.100 \text{ mol}$ (2分)考虑到X(s)有一部分分解为X(g),本题更准确的结果应为0.096 mol。严格来讲,本题应该得出0.096 mol的结果才可以得分。



$$
\mathrm{X} (\mathrm{g}) \text {、} \mathrm{Y} _ {2} (\mathrm{g}) \text {、} \mathrm{Y} (\mathrm{g}) \text {、} \mathrm{XY} _ {2} (\mathrm{g}) \text {、} \mathrm{XY} (\mathrm{g})
p ^ {\ominus} = 1. 0 0 \times 1 0 ^ {5} \mathrm{Pa})
$$

(对该体系，反应的标准摩尔吉布斯自由能变和平衡常数满足： $\Delta_{r}G^{\ominus}=-RT\ln K^{\ominus}$ )

5-2 对于可逆反应 X(s) = X(g)，其  $\Delta_{\mathrm{r}}G_{1}^{\ominus} = \Delta_{\mathrm{f}}G^{\ominus}(X(\mathrm{g})) = 92.427 \, \mathrm{kJ/mol}$ $K_{1}^{\ominus} = \exp(-\Delta_{\mathrm{r}}G_{1}^{\ominus}/RT) = \exp[-92.427 \times 10^{3} / (8.314 \times 4000)] = 0.0621$

故  $p(X(\mathrm{g})) = 0.0621p^{\ominus}$  （2分）

对于可逆反应  $Y_{2}(g) = 2Y(g)$ ，其  $\Delta_{\mathrm{r}}G_{2}^{\ominus} = 2\Delta_{\mathrm{f}}G^{\ominus}(Y(g)) - \Delta_{\mathrm{f}}G^{\ominus}(Y2(g)) = -31.082 \, \mathrm{kJ/mol}$ $K_{2}^{\ominus} = \exp(-\Delta_{\mathrm{r}}G_{2}^{\ominus}/RT) = \exp[31.082 \times 10^{3} / (8.314 \times 4000)] = 2.546$

该体系中 Y(g) 和 Y₂(g) 的量远大于其他含 Y 物种，故由 Y 原子数守恒，有：
 [  p(\mathrm{Y}(\mathrm{g})) / 2 + p(\mathrm{Y}_{2}(\mathrm{g})) ] V = [n_{0}(\mathrm{XY}_{2}) + n_{0}(\mathrm{Y}_{2}) ] R T  ]

 $p^{2}(\mathrm{Y}(\mathrm{g})) / p(\mathrm{Y}_{2}(\mathrm{g})) = K_{2} = 2.546$

联立以上方程，解得：

 $p(\mathrm{Y}(\mathrm{g})) = 2.34p^{\ominus} \text{(2 分)}$ $p(\mathrm{Y}_{2}(\mathrm{g})) = 2.16p^{\ominus} \text{(2 分)}$

对于可逆反应 X(s) + Y₂(g) = XY₂(g)，其  $\Delta_{\mathrm{r}}G_{3}^{\ominus} = \Delta_{\mathrm{f}}G^{\ominus}(\mathrm{XY}_{2}(\mathrm{g})) = 353.687 \, \mathrm{kJ/mol}$ $K_{3}^{\ominus} = \exp(-\Delta_{\mathrm{r}}G_{3}^{\ominus}/RT) = \exp[-353.687 \times 10^{3}/(8.314 \times 4000)] = 2.40 \times 10^{-5}$ $p(\mathrm{XY}_{2}(\mathrm{g})) = p(\mathrm{Y}_{2}(\mathrm{g}))K_{3}^{\ominus} = 5.20 \times 10^{-5}p^{\ominus} \text{(2 分)}$

对于可逆反应  $2\mathrm{X}(\mathrm{s}) + \mathrm{Y}_{2}(\mathrm{g}) = 2\mathrm{XY}(\mathrm{g})$ ，其  $\Delta_{\mathrm{r}}G_{4}^{\ominus} = 2\Delta_{\mathrm{f}}G^{\ominus}(\mathrm{XY}(\mathrm{g})) = 388.670 \, \mathrm{kJ/mol}$ $K_{4}^{\ominus} = \exp(-\Delta_{\mathrm{r}}G_{4}^{\ominus}/RT) = \exp[-388.670 \times 10^{3}/(8.314 \times 4000)] = 8.40 \times 10^{-6}$ $p(\mathrm{XY}(\mathrm{g})) = [p(\mathrm{Y}_{2}(\mathrm{g}))K_{4}^{\ominus}]^{1/2} = 4.26 \times 10^{-3}p^{\ominus} \text{(2 分)}$

单位使用 kPa 且计算正确，也可得分。
