# 题-CM-148-05-三磷酸腺苷ATP是人体内能量

## 题目

### 第 5 题（9 分）

三磷酸腺苷(ATP)是人体内能量的直接来源；在生理 pH 的条件下对三磷酸腺苷进行选择性识别具有重要的意义。人们发现环蕃类物种 X 可在 pH=7.40 的生理条件下与三磷酸腺苷发生选择性的响应，可逆地形成复合物(ATP-X complex):

![](images/0e534babac29fea62fc4665784736d7037068efc1ba699c19ebf048ea2cdc8c0.jpg)

在 pH=7.40 的磷酸盐缓冲溶液中，加入 ATP 和 X；当体系达到平衡后，测定体系在 400 nm 处的吸光度 A。维持 X 的初始浓度为 $c_{X,0}=1.1\times10^{-5}$ mol/L，测定 ATP 在不同初始浓度 $c_{ATP,0}$ 时体系的吸光度为 A，发现当 ATP 大过量（即 $c_{ATP,0}\gg c_{X,0}$ ）时， $c_{ATP,0}$ (mol/L) 与吸光度 A 满足如下关系： $\frac{1}{0.120-A}=\frac{6.11\times10^{-3}}{c_{ATP,0}}+25.7$ 。（实验波长下，ATP 对光的吸收可忽略不计；体系吸光度 A、X 的浓度 $c_{X}$ ，复合物浓度 $c_{ATP-X}$ 满足： $A=\varepsilon_{X}bc_{X}+\varepsilon_{ATP-X}bc_{ATP-X}$ 。式中，摩尔消光系数 $\varepsilon_{X}$ 、 $\varepsilon_{ATP-X}$ 和吸收池厚度 b 均为常数）

5-1 在 ATP-X 复合物中具有 1 个 X；它可能包含 1 个或多个 ATP。通过计算和推演求出：

(1)在 ATP-X 复合物中，1 个 X 与多少个 ATP 结合时，能满足题设 $c_{ATP,0}$ (mol/L) 与吸光度 A 关系式；(2)形成 ATP-X 复合物的平衡常数。

5-2 说明 X 能选择性响应 ATP，并形成复合物的原因。

## 参考答案

![](images/5a49e8764aa364ac97d9e37cb460711c8168e62ecd1faa0e515742f88020e306.jpg)

5-1 设转化率为 0 时体系吸光度为 $A_{0}$ ，转化率为 100% 时体系吸光度为 $A_{\infty}$ ，则：

$$
A _{0} = \varepsilon_{\mathbf {X}} b c _{\mathbf {X}, 0}; A _{\infty} = \varepsilon_{\mathrm{ATP-X}} b c _{\mathbf {X}, 0}
$$

实际吸光度应为:

$$
A = \varepsilon_{\mathbf {X}} b c _{\mathbf {X}} + \varepsilon_{\mathrm{ATP-X}} b c _{\mathrm{ATP-X}} = \varepsilon_{\mathbf {X}} b c _{\mathbf {X}, 0} \frac {c _{\mathbf {X}}}{c _{\mathbf {X}} + c _{\mathrm{ATP-X}}} + \varepsilon_{\mathrm{ATP-X}} b c _{\mathbf {X}, 0} \frac {c _{\mathrm{ATP-X}}}{c _{\mathbf {X}} + c _{\mathrm{ATP-X}}}
$$

联立上式可得:

$$
A = A _{0} \frac {c _{\mathbf {X}}}{c _{\mathbf {X}} + c _{\mathrm{ATP-X}}} + A _{\infty} \frac {c _{\mathrm{ATP-X}}}{c _{\mathbf {X}} + c _{\mathrm{ATP-X}}}
$$

整理得:

$$
\frac {A _{0} - A}{A _{0} - A _{\infty}} = \frac {c _{\mathrm{ATP-X}}}{c _{\mathbf {X}} + c _{\mathrm{ATP-X}}}
$$

设每个 X 与 n 个 ATP 结合即 $X + nATP \rightarrow ATP_{n}X$ ，则：

$$
K = \frac {c _{\mathrm{ATP-X}}}{c _{\mathrm{X}} c _{\mathrm{ATP}} ^{n}} (1 \text {分})
c _{\mathrm{ATP-X}}: c _{\mathbf {X}} = K c _{\mathrm{ATP}} ^{n}: 1
$$

所以：

$$
\frac {A _{0} - A}{A _{0} - A _{\infty}} = \frac {K c _{\mathrm{ATP}} ^{n}}{1 + K c _{\mathrm{ATP}} ^{n}}
$$

整理得:

$$
\frac {1}{A _{0} - A} = \frac {1}{A _{0} - A _{\infty}} \frac {1}{K c _{\mathrm{ATP}} ^{n}} + \frac {1}{A _{0} - A _{\infty}}
$$

对应题干的关系式 $\frac{1}{0.120-A}=\frac{6.11\times10^{-3}}{c_{ATP,0}}+25.7$ ，得：

$$
A _{0} = 0.120
\frac {1}{A _{0} - A _{\infty}} = 25.7
\frac {1}{A _{0} - A _{\infty}} \frac {1}{K} = 6.11 \times 10^{- 3}
n = 1 (1 \text {分})
$$

所以，每个 X 与 1 个 ATP 结合（1 分），平衡常数为：

$$
K = 25.7 \div (6.11 \times 10^{- 3}) = 4.21 \times 10^{3} (1 \text {分})
$$

若选手采取其他合理方法（如在线性关系上选两点并求出平衡常数）得出正确结果的，可按以下标准评分：(1)共2分，推出每个X与1个ATP结合，可得2分；若写出每个X与1个ATP结合，但无严格推导和证明，只得1分；(2)共5分，正确写出平衡常数表达式，得1分；方法合理、步骤正确，得3分；结果正确，得1分。利用斜率和截距求得平衡常数K，但无相关推导和说明的，只得2分（平衡常数表达式分和结果分），不给步骤分。

5-2 因为 X 具有含大共轭体系的蒽环，能与 ATP 中含大共轭体系的嘌呤基团产生 $\pi-\pi$ 堆叠作用（1 分）；同时，ATP 中含有带 4 个负电的三磷酸基团，能与 X 中带正电的吡啶环产生较强的静电作用（1 分）。此外，嘌呤基团填入两个蒽环之间时，可能会挤出蒽环间的少量水分子，该过程熵增，推动反应发生。
