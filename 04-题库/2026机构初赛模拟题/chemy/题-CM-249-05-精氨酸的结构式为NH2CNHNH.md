# 题-CM-249-05-精氨酸的结构式为NH2CNHNH

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy37-17-5`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 5 题（8 分）

精氨酸的结构式为 NH<sub>2</sub>C(NH)NH(CH<sub>2</sub>)<sub>3</sub>CHNH<sub>2</sub>CO<sub>2</sub>H，它的各级解离常数为: pK<sub>a1</sub> = 2.17, pK<sub>a2</sub> = 9.04, pK<sub>a3</sub> = 12.48。

**5-1** 计算精氨酸的等电点 pI。(pI 为氨基酸阴阳离子浓度相等时的 pH)

**5-2** 现有 0.10 mol/L 的精氨酸溶液 100 mL，计算该溶液的 pH，取 pK<sub>w</sub> = 14.00。

**5-3** 计算为使该溶液达到等电点，需向其中加入 5.0 × 10<sup>-3</sup> mol/L 的盐酸或 5.0 × 10<sup>-3</sup> mol/L 的氢氧化钠溶液的体积(仅选择一种；假设溶液体积具有加和性)。

## 参考答案

**5-1** 用 HA 代表精氨酸：H<sub>3</sub>A<sup>2+</sup> == H<sub>2</sub>A<sup>+</sup> + H<sup>+</sup> == HA + 2H<sup>+</sup> == A<sup>-</sup> + 3H<sup>+</sup>

![](images/c43ebc1a516f9a6f3a0adbf182aac6dec74bbe7d239dc3ec2e9eb420ab544c15.jpg)

——————————————————或——————————————————

处于等电点时有：[H<sub>3</sub>A<sup>2+</sup>] + [H<sub>2</sub>A<sup>+</sup>] = [A<sup>-</sup>]

套用分布分数公式，代入结果为：[H<sup>+</sup>]<sup>3</sup> + [H<sup>+</sup>]<sup>2+</sup>K<sub>a1</sub> – K<sub>a1</sub>K<sub>a2</sub>K<sub>a3</sub> = 0

代入数据解得：[H<sup>+</sup>] = 1.7×10<sup>-11</sup>mol/L → pI = 10.76 (2.5 分)

**5-2** 有质子守恒如下：[H<sup>+</sup>] + 2[H<sub>3</sub>A<sup>2+</sup>] + [H<sub>2</sub>A<sup>+</sup>] = [OH<sup>-</sup>] + [A<sup>-</sup>]

![](images/69e90b0c6d0bb973f15d4ff922a4bb6b932c8b947ec4885b1376aa04f831629d.jpg)

代入数据解得：[H<sup>+</sup>] = 2.0×10<sup>-11</sup>mol/L → pI = 10.70 (2.5 分)

**5-3** 应加入 5.0×10<sup>-3</sup> mol/L 的氢氧化钠溶液。(0.5 分)

质子守恒修正为：[Na<sup>+</sup>] + [H<sup>+</sup>] + 2[H<sub>3</sub>A<sup>2+</sup>] + [H<sub>2</sub>A<sup>+</sup>] = [OH<sup>-</sup>] + [A<sup>-</sup>]

![](images/5d3750d0d7c783f6c3b3bb56bbe36189893303ca347318d87ffd30a20464f4c1.jpg)

代入数据解得：V = 13mL。(2.5 分)

若采用其他计算方法，过程合理且结果正确也可得满分。
