# 题-CM-214-04-41少量甲烷还原三氧化二锰生成四

> 来源：Chemy- 项目（brucejllpku.github.io/Chemy-）`chemy36-1-4`；版权归 Chemy 化学奥林匹克团队原命题组，仅供内部备课、禁商用、不删原水印。

## 题目

### 第 4 题（12 分）

**4-1** 少量甲烷还原三氧化二锰，生成四氧化三锰。

**4-2** 将硝基乙烷投入含水硫酸中，加热反应，生成一种一元酸以及一种氮为-1 价态的化合物。

**4-3** 铁投入到熔融的氢氧化钠中，生成 2 种单质，铁均转化为尖晶石结构的固体。

**4-4** 将苯肼和 AtI 溶于 KI-I<sub>2</sub>溶液中反应，制得砹苯。

**4-5** 向黑色 Cu(SCN)<sub>2</sub>的悬浊液中通入二氧化硫，体系转变为白色悬浊液。

**4-6** 砷硫铅铁矿PbFe<sub>3</sub>(AsO<sub>4</sub>)(SO<sub>4</sub>)(OH)<sub>6</sub>与矿井水中溶解的碳酸氢钙反应，转化为四种矿物：臭葱石(FeAsO<sub>4</sub>·2H<sub>2</sub>O)，针铁矿(FeOOH)，白铅矿和生石膏。

## 参考答案

**4-1** 12Mn<sub>2</sub>O<sub>3</sub> + CH<sub>4</sub> = 8Mn<sub>3</sub>O<sub>4</sub> + CO<sub>2</sub> + 2H<sub>2</sub>O（2 分）

**4-2** CH<sub>3</sub>CH<sub>2</sub>NO<sub>2</sub> + H<sub>2</sub>SO<sub>4</sub> + H<sub>2</sub>O = CH<sub>3</sub>COOH + [NH<sub>3</sub>OH][HSO<sub>4</sub>] （2 分）

**4-3** 3Fe + 4NaOH = Fe<sub>3</sub>O<sub>4</sub> + 4Na + 2H<sub>2</sub>（2 分）

**4-4** C<sub>6</sub>H<sub>5</sub>NHNH<sub>2</sub> + AtI + I<sub>2</sub> = C<sub>6</sub>H<sub>5</sub>At + 3HI + N<sub>2</sub>（2 分）

**4-5** 2Cu(SCN)<sub>2</sub> + SO<sub>2</sub> + 2H<sub>2</sub>O = 2CuSCN + 2HSCN + H<sub>2</sub>SO<sub>4</sub>（2 分）

**4-6** PbFe<sub>3</sub>(AsO<sub>4</sub>)(SO<sub>4</sub>)(OH)<sub>6</sub> + Ca(HCO<sub>3</sub>)<sub>2</sub> + H<sub>2</sub>O = FeAsO<sub>4</sub>·2H<sub>2</sub>O + 2FeOOH + PbCO<sub>3</sub> + CaSO<sub>4</sub>·2H<sub>2</sub>O + CO<sub>2</sub>（2 分）
