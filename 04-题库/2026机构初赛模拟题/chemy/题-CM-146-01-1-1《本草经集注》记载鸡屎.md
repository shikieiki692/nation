# 题-CM-146-01-1-1《本草经集注》记载鸡屎

## 题目

### 第 1 题（8 分）

1-1《本草经集注》记载：“鸡屎矾不入药用，惟堪镀作，以合熟铜；投苦酒(醋)中，涂铁皆作铜色，外虽铜色，内置不变。”其中鸡屎矾的主要成分之一为 $\mathrm{Cu_{2}(OH)_{2}CO_{3}}$ ，写出其“投苦酒中”的化学方程式。

1-2 硝酸银水溶液与硫代硫酸钠反应，析出白色沉淀 (反应 1)，随后白色沉淀逐渐转变为黑色 (反应 2)，过程中没有气体产生。写出反应 1 和反应 2 的化学方程式。

1-3 硫单质和 $Na_{2}CO_{3}$ 、 $CoCl_{2}$ 混合加热，反应得到 $Co_{2}S_{3}$ ，并伴随两种气体的生成。

1-4 $K_{3}NiF_{6}$ 可以与稀硫酸反应，有气体生成。

## 参考答案

1-1  $\mathrm{Cu_{2}(OH)_{2}CO_{3} + 4CH_{3}COOH = 2Cu(CH_{3}COO)_{2} + 3H_{2}O + CO_{2}}$  （2分）
1-2  $2AgNO_{3} + Na_{2}S_{2}O_{3} = Ag_{2}S_{2}O_{3} + 2NaNO_{3}$  （1分）
 $Ag_{2}S_{2}O_{3} + H_{2}O = Ag_{2}S + H_{2}SO_{4}$  （1分）
1-3  $2CoCl_{2} + 2Na_{2}CO_{3} + 4S = Co_{2}S_{3} + 4NaCl + 2CO_{2} + SO_{2}$  （2分）
1-4  $4K_{3}NiF_{6} + 10H_{2}SO_{4} + 2H_{2}O = 4NiSO_{4} + O_{2} + 24HF + 6K_{2}SO_{4}$  （2分）
