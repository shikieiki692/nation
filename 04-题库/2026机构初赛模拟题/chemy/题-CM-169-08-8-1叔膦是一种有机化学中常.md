# 题-CM-169-08-8-1叔膦是一种有机化学中常

## 题目

### 第 8 题

第 8 题（19 分，占 $9 \%$ ） 叔膦催化剂的应用

8-1 叔膦是一种有机化学中常见的催化剂， 常被用于羰基化合物的极性反转的反应。
8-1-1 画出下列反应的关键中间体。

CO2Et OH PPh3 (20 mol %) benzene, reflux, 12h

8-1-2 A 在 $\mathrm { PhNEt } _{ 2 }$ 中回流2 天，得到了具有内酯结构的B。 画出B 的结构简式。

![](images/85c55ed053fd9f4bfbc64b3e18c66fe722f89a8c0855e938490510e6bd429c8d.jpg)

8-2 叔膦催化剂还可用于催化极化环丙烷的开环反应。 在开环后的反应中， 反应底物取代基的改变会极大地影响产物的结构。

8-2-1 画出下列反应的产物 C 的结构简式。已知C 为底物的同分异构体，C 的 $\mathrm { ^{ 1 } H }$ NMR (400MHz, CDCl3) $\delta 7.46 \ – 7.32$ (m, 3H), 7.30–7.17 (m, 7H), 6.86 (d, $J { = } 16.2 \mathrm { Hz } ,$ , 1H), 6.77 (d, $J = 16.2$ Hz, 1H), 2.24 (s, 3H), 2.10 (s, 3H)。

PBu3 (20 mol %) Ph PhMe DCE, reflux, 24h

8-2-2 观察如下两个反应， 和 8-2-1 中的反应进行比较：

![](images/ad838ff6f3bc145fb4d77c6d08cf154448003a7b4e204eb405b4f4aa4b838c4b.jpg)

8-2-2-1 解释当环丙烷上的苯基换为- $\mathrm { \cdot } \mathrm { CO } _{ 2 } \mathrm { Et }$ 时， 反应不产生 C 而产生D 的原因。
8-2-2-2 解释在产生E 的反应中，E 为主产物而 F 为副产物的原因。

![](images/af3986da0f8d59f0fcde515d063ff21b0d49d131fec49793544f44c53fe3cc1b.jpg)
