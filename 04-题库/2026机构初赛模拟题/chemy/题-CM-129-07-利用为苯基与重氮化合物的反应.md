# 题-CM-129-07-利用为苯基与重氮化合物的反应

## 题目

### 第 7 题（12 分）

利用 $\mathrm{RuCl}_2(\mathrm{PPh}_3)_3(\mathrm{Ph}$ 为苯基)与重氮化合物的反应可得到烯烃复分解反应催化剂的前体 A: $\mathrm{RuCl}_2(\mathrm{PPh}_3)_3 + \mathrm{CH}_3\mathrm{CHN}_2 \xrightarrow[-\mathrm{PPh}_3, -\mathrm{N}_2]{\mathrm{CH}_2\mathrm{Cl}_2, -78^\circ\mathrm{C}} \mathbf{A}$

7-1 写出 $CH_{3}CHN_{2}$ 的 Lewis 结构式并标出形式电荷，有共振结构需一并画出。

7-2 在 A 中，Ru 为三角双锥配位，三苯基膦配体位于轴向，画出 A 的结构。

7-3 人们发现，若利用 $\mathrm{OsCl}_2(\mathrm{PPh}_3)_3$ 代替 $\mathrm{RuCl}_2(\mathrm{PPh}_3)_3$ 进行反应，则产物的结构随重氮化合物的不同而不同。利用不同的底物进行实验，如下所示：

$$
\mathrm{OsCl} _{2} \left(\mathrm{PPh} _{3}\right) _{3} + \underset {\mathrm{R}} {\overset {\mathrm{N} _{2}} {\longrightarrow}} \underset {\mathrm{R} ^{\prime}} {\overset {\mathrm{CH} _{2} \mathrm{Cl} _{2}, \text {r.t.}} {\longrightarrow}}
$$

7-3-1 当 R 为对甲苯基，R'为氢时，产物为 B。研究表明 B 为 Os 的八面体配合物，不含氮；B 含有 Os-H 键；且 B 的 Os-C 间距明显比 A 的 Ru-C 间距更短。画出 B 的结构。

7-3-2 当 R 和 R'均为苯甲酰基时，产物为 C。研究表明 C 也是 Os 的八面体配合物；在 C 中，重氮化合物被还原，并利用 N 原子和 O 原子与 Os 络合形成六元环。画出 C 的结构。7-3-3 当 R 和 R'均为苯基时，产物为 D。研究表明 D 是 Os 的双核配合物，2 个 Os 均为八面体配位，八面体间通过共面连接。D 的配体仅有 3 种：氯、三苯基膦和氮气。其中，氮气配体仅有 1 个且作为端基配体。画出 D 的结构。该反应还产生一种副产物 $\mathsf{E}(\mathrm{C}_{26}\mathrm{H}_{20}\mathrm{N}_{2})$ ，画出 E 的结构。
