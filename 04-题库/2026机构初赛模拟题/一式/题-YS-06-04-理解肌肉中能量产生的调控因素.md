# 题-YS-06-04-理解肌肉中能量产生的调控因素

## 题目

### 第 4 题（17分，占 $10\%$ ）给肌肉快充

理解肌肉中能量产生的调控因素，对于认识身体对运动的反应，以及确定心脏和肌肉疾病的生理影响都具有重要意义。细胞以三磷酸腺苷（ATP）作为分子层面的能量通货；ATP水解为二磷酸腺苷（ADP）的过程常常与其他化学反应相偶联。在无脊椎动物中，这一高能磷酸键的转移通常与精氨酸（arginine）相结合，形成磷酸精氨酸（phosphoarginine）作为能量储备；而在脊椎动物中，则与肌酸（creatine）相结合，生成磷酸肌酸（phosphocreatine）。在肌肉活动初期，当 ATP 消耗速率超过线粒体氧化磷酸化的供给能力时，这些高能磷酸化合物能够通过相应的激酶反应，迅速将磷酸基团转移至 ADP，从而再生 ATP，维持短时高强度的能量需求。健身爱好者通过食用肌酸追求更好的肌肉表现力。

ATP 水解为 ADP 和无机磷是肌肉收缩的直接能量来源:

$$
\mathrm{ATP} + \mathrm{H} _ {2} \mathrm{O} \rightleftharpoons \mathrm{ADP} + \mathrm{Pi} + \mathrm{H} ^ {+}
$$

在生物化学中，为简化 pH 影响，定义 pH = 7.0 时表观标准自由能变 $\Delta G^{\circ}$ 及相应平衡常数 $K'$ 。37℃下，该反应 $K' = 1.38 \times 10^{5}$ 4-1 在 37℃下，pH = 7.0 的缓冲溶液中 ATP 的初始浓度为 $c_{0} = 10 \, mmol/L$ 。计算达到平衡时，ATP、ADP 和 Pi 的浓度。

## 4-2 计算 $37^{\circ}$ C 下反应的 $\Delta G$

在生物体中，ATP和Pi的浓度可通过 $^{31}$ P NMR测量。然而，ADP的浓度过低，无法用 $^{31}$ P NMR直接检测。因此，ADP的浓度必须通过 $^{31}$ P NMR测得的磷酸肌酸浓度以及肌酸激酶（creatine kinase）所催化肌酸与ATP的反应K"值来间接确定。肌酸激酶催化以下反应：

$$
\text { creatine } + \mathrm{ATP} \rightleftharpoons \mathrm{ADP} + \text { phosphocreatine } + \mathrm{H} ^ {+}
$$

$$

## 4-3（本小问共8分）

根据平衡常数的定义和物料守恒，有

$$
\frac {[ \mathrm{AD} ] [ \text { phosphocreatine } ]}{[ \mathrm{ATP} ] [ \text { creatine } ]} = 6 \times 10 ^ {- 3}
$$

故

$$
c = [ \text { creatine } ] + [ \text { phophocreatine } ] = 42.5 \times 10 ^ {- 3} \mathrm{mol/L}
$$

$$
[ \mathrm{ADP} ] = K ^ {\prime \prime} [ \mathrm{ATP} ] \frac {c - [ \mathrm{phosphocreatine} ]}{[ \mathrm{phosphocreatine} ]} (1 \text {分})
$$

解得静息时 $[\mathrm{ADP}] = 5.54\times 10^{-6}\mathrm{mol / L}$ （1分）轻微运动时 $[\mathrm{ADP}] = 5.74\times 10^{-5}\mathrm{mol / L}$ （1分）剧烈运动时 $[\mathrm{ADP}] = 1.50\times 10^{-4}\mathrm{mol / L}$ （1分）

$$
\Delta G ^ {\prime} = \Delta G ^ {o 1} + R T \ln \frac {[ \mathrm{ADP} ] [ \mathrm{Pi} ]}{[ \mathrm{ATP} ]} (1 \text {分})
$$

故静息时 $\Delta G' = -63.6 \, kJ/mol$ （1分）轻微运动时 $\Delta G' = -53.2 \, kJ/mol$ （1分）剧烈运动时 $\Delta G = -49.3 \, kJ/mol$ （1分）
