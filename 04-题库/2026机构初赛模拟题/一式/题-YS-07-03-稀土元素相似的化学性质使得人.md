# 题-YS-07-03-稀土元素相似的化学性质使得人

## 题目

### 第 3 题（16分，占 $9\%$ ） 双子的迷失

稀土元素相似的化学性质使得人们在很长一段时间无法正确地认识它们。19 世纪初 Berzelius 发现了 “ceria” 并认为其为一种新的金属元素的氧化物，将此元素命名为 Ce。19 世纪中叶 Mosander 又先后从 ceria 拆分出两种金属氧化物，将两种元素分别命名为 La 和 Di。La 意为 “隐藏”，因 La 与 Ce 一起出现，而 Di 意为 “孪生”，因 Di 与 La 一同发现。然而直到 19 世纪末 Di 才被 Welsbach 成功拆分，被证实为两种元素即 Pr 和 Nd 的混合物。

在常规价态+3 之外，Pr 和 Nd 的性质差异得以体现。例如室温下 Pr 最稳定的氧化物不是 $Pr_{2}O_{3}$ ，而是 A。在空气中加热 $\mathrm{Pr}_{2}(\mathrm{CO})_{3}\cdot\mathrm{H}_{2}\mathrm{O}$ ，在 $95^{\circ}C$ 、 $435^{\circ}C$ 和 $518^{\circ}C$ 三次吸热事件分别失重 23.76%、14.52% 和 5.52%。第一次失重脱去所有结晶水，第二次失重后 Pr 仍为 +3 价，第三次失重得到的固体残留为 A。

3-1 推断整数 $x$ 的值和三次失重的反应过程

3-1-2 给出三次失重的反应方程式。

## 参考答案

稀释元素相似的化学性质使得人们在很长一段时间无法正确地认识它们。19世纪初Berzehus发现了“ceria”并认为其为一种新的金属元素的氧化物，将此元素命名为Ce。19世纪中叶Mosander又先后从ceria拆分出两种金属氧化物，将两种元素分别命名为La和Di。La总为“隐藏”，因La与Ce一起出现；而Di意为“孪生”，因Di与La一同发现。然而回到19世纪末Di才被Welsbach成功拆分，被证实为两种元素即Pr和Nd的混合物。

![](images/770ee896923427c7a0c76c48aa0da24b881dfa69aab23ebfd37f6f47d6949d61.jpg)

在常规价态+3 之外，Pr 和 Nd 的性质差异得以体现。例如室温下 Pr 最稳定的氧化物不是 $Pr_{2}O_{3}$ ，而是 A。在空气中加热 $\mathrm{Pr}_{2}(\mathrm{CO}_{3})_{3}:x\mathrm{H}_{2}\mathrm{O}$ ，在 $95^{\circ}C$ 、 $435^{\circ}C$ 和 $518^{\circ}C$ 三次吸热事件分别失重 23.76%、14.52% 和 5.52%。第一次失重脱去所有结晶水，第二次失重后 Pr，仍为 +3 价，第三次失重得到的固体残留为 A。

## 3-1 推断整数 $x$ 的值和三次失重的反应过程。

![](images/396b9e0f5c647f4a7434e3b68d4c55d91c02f098e39d4a4f4cb4cf5eff0cce13.jpg)

```txt
3-1（本小问共 10 分）
Pr₂(CO₃)₃ 的分子量为 461.85 g mol⁻¹，水的分子量为 18.02 g mol⁻¹
第一次失重有 18.02x / (467.85 + 18.02x) = 23.76%（1 分）
解得 x = 8（2 分）
第二次失重 14.52% × (467.85 + 18.02 × 8) = 88（1 分）
即失去 2 个 CO₂，得产物 Pr₂O₂(CO₃)（2 分）
第三次失重 5.52% × (467.85 + 18.02 × 8) = 33.45（1 分）
产物已是氧化物，说明 CO₂ 全部脱去，质量差应是 Pr 被氧化至更高加每 2 个 Pr 原子增加的 O 原子个数(44.01 - 33.45) ÷ 16.00 = 0.66（1 分）
即 A 是 Pr₆O₁₁（1 分）
```

## 3-1-2 给出三次失重的反应方程式。
