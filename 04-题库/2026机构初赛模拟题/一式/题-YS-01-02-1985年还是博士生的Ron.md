### 第 2 题（11分，占9%）驱动蛋白——细胞中的纳米“火车”

1985年，还是博士生的Ronald Vale在研光乌贼神经元运输时发现：在一份只含有微管、ATP和细胞提取物混合物的对照样品中，微管竟然自己动了起来。经过半年纯化，他发现了一种全新的马达蛋白，命名为驱动蛋白(Kinesin)。驱动蛋白是一类体积微小但功能强大的ATP酶。它像一列忙碌的“火车”，在细胞内由微管蛋白组成的“轨道”——微管(Microtubule)上穿行，将各种营养物质运输到细胞的各个角落。驱动蛋白功能异常会导致遗传性痉挛性截瘫、渐冻症等疾病，也成为抗癌药物的靶点。因此，理解驱动蛋白如何结合微管、如何运动，不仅有理论意义，也有重要的医学价值。

2-1 结合平衡。驱动蛋白（P）与微管上的结合位点（Site）形成可逆结合：

$$
\mathrm{P} _ {\text { bound }} \rightleftharpoons \mathrm{P} _ {\text { free }} + \text { Site }
$$

单个驱动蛋白分子与相应位点的结合过程符合质量作用定律：

$$
K _ {d} = \frac {[ \mathrm{P} _ {\text { free }} ] [ \text { Site } ]}{[ \mathrm{P} _ {\text { bound }} ]}
$$

其中，[Site]为未结合的结合位点浓度， $\left[\mathrm{P}_{\mathrm{free}}\right]$ 为自由的驱动蛋白浓度， $\left[\mathrm{P}_{\mathrm{bound}}\right]$ 为已结合的驱动蛋白浓度， $K_{d}$ 为解离平衡常数。已知 $K_{d} = 5.00 \times 10^{-7} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ ， $\left[\mathrm{P}_{\mathrm{free}}\right] = 1.00 \times 10^{-7} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ ，微管上结合位点的总浓度 $\left[\mathrm{Site}\right]_{\mathrm{total}} = 1.00 \times 10^{-5} \, \mathrm{mol} \cdot \mathrm{L}^{-1}$ 。
