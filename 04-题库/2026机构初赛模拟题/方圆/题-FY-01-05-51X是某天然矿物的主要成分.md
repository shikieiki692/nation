# 题-FY-01-05-51X是某天然矿物的主要成分

## 题目

### 第 5 题 晶体推断（24分， $11\%$ ）

5.1 X 是某天然矿物的主要成分，含 A 量达 20.77%，是炼 A 的重要矿物原料之一，在地表易氧化，常与红镍矿等共生。由于 A 在电池、航空航天、磁性材料等领域不可或缺，X 作为 A 的载体矿物具有重要战略价值。X 由两种第四周期元素组成，其晶体结构具有较高对称性，晶胞透视图如下。图中深色球代表 A，浅色球代表 B。

![](images/ea65b04bf450d400661d7589510b8f4b935ad27d27b4253dfd8000fdf370ff3e.jpg)

5-1-1 写出 X 的点阵形式。

5-1-2 根据 X 的晶胞透视图，写出 X 的化学式（用 A 和 B 表示）。

5-1-3 分别写出晶体 X 中 A, B 化学环境数及配位数。(提示: 晶体 X 中存在 $B_{4}$ 单元)

5-1-4 写出晶体 X 中 A 的配位多面体及其连接方式。

5-1-5 写出晶体 X 中 A 的特征对称元素并描述其所处位置。

5-1-6 晶胞中有一 B 原子坐标为(0, 0.3500, 0.8500)，其与最近 A 原子的距离为 d=235.2pm，晶体密度 $\rho=6.86\ g/cm^{3}$ ，通过计算及推导给出 X 的化学式。

5.2 现还有另一种由 A 和 B 组成的晶体 Y，其是一种重要的无机化合物，在材料科学和固体物理领域具有研究价值。Y 的晶胞沿 a、b、c 方向的投影图及透视图如下。图中深色球代表 A，浅色球代表 B。提示：为示出原子间键连关系，晶胞图中并非所有原子均处于晶胞内。

![](images/9795e9474d6d68857dd07dd78afab49f0f2791be6ff0239c9205b39810eac501.jpg)
5-2-1 写出 Y 的化学式（若 5-1-6 未求出结果，可使用 A，B 代替具体元素）
5-2-2 给出 Y 的点阵形式及特征对称元素。

5-2-3 分别写出晶体 Y 中 A 和 B 的空间环境数。

5-2-4 晶胞中某一 A 原子坐标为（0.2723, 0.0031, 0.2832），根据晶胞图写出其余 A 原子坐标。（提示：晶体 Y 在 b 方向上存在 c 滑移面）
