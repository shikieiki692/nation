## 题目

### 第 7 题（26 分，占 12%）“逆配合物”

逆配合物（inverse coordination complex，又称反配位配合物），是相对于经典配合物定义的一类特殊配位化合物，其核心特征是中心原子为非金属元素，而金属元素作为“配体”分布在其周围。

提示：本卷第2题的物质H便是一种典型的逆配合物。

7-1 逆配合物的形成常常需要额外的稳定化因素。

7-1-1 金形成的多核阳离子 $\left[\mathrm{Au}_{3}\mathrm{O}(\mathrm{PMe}_{3})_{3}\right]^{+}$ 和 $\left[\mathrm{Au}_{4}\mathrm{S}(\mathrm{PMe}_{3})_{4}\right]^{2+}$ 。已知前者的对称元素为一根三重旋转轴和三个镜面，后者则具有一根四重旋转轴和四个镜面，请分别画出两种阳离子的结构。

7-1-2 指出上述两种多核阳离子中存在的弱相互作用，并预测欲破坏一对该相互作用，大约需要多大的能量（选填 a/b/c/d）。

(a) 0\~10 kJ/mol (b) 10\~100 kJ/mol (c) 100\~200 kJ/mol (d) 200\~300 kJ/mol

7-2 N 也可作为逆配合物的中心，将 Mg 粉、 $t-BuNH_{2}$ 与 $\mathrm{Mg(NHt-Bu)_{2}}$ 混合后，在高压釜中于 $200^{\circ}C$ 下搅拌 60h，得到了一种 N 的逆配合物 A，同时放出物质的量相同的两种气体。对 A 进行元素分析，得出其分子式为 $C_{36}H_{90}Mg_{6}N_{10}$ 。已知理想情况下，A 属于 $D_{3h}$ 点群，写出制备 A 的方程式，并画出 A 的结构。提示：N 有三种化学环境。

7-3 卤素原子同样也可作为中心原子形成逆配合物。

7-3-1 一定条件下， $[\mathrm{Cu}(\mathrm{NCMe})_{4}]^{+}$ 与 dtbpm 在丙酮中可以 1:1 反应得到双核阳离子 B，向体系中引入 $PF_{6}^{-}$ 后，B 可转化为含有 3 个 Cu 的阳离子 C，C 是一种氟的逆配位离子。其中 Me 为甲基，dtbpm 的结构如下图所示：

![](images/231dd8cde9669454aada03974ac54f73015fbb05d5ec7a02889925e60416f201.jpg)

已知 B 中的 Cu 均近似呈直线型配位，C 中的 Cu 均近似呈平面三角型配位。分别画出 B 和 C 的结构。

7-3-2 研究者将 dtbpm 中的叔丁基换成了甲基，结果未能得到任何类似 B 和 C 的产物，尝试解释原因。

7-3-3 D 是一种仅含 Cu 和 Br 的逆配位离子（ $M \approx 1100 \mathrm{~g} / \mathrm{mol}$ ），带有三个单位的负电荷，其中 Cu 和 Br 的数目比为 2:3。若不考虑中心 Br 原子，D 中含有一个八元环与两个六元环。D 中的 Cu 原子有两种配位数，数目比为 2:1，且不存在端基 Br。推出 D 的化学式，并画出其结构。
