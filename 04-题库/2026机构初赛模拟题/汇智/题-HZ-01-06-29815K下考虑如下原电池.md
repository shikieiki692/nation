6-1 计算左侧半电池链接的缓冲溶液浴中的 $[H^{+}]$ , $[OH^{-}]$ 与 pH.

令  $h=[H^{+}]$ . 由乙酸的物料守恒和解离平衡可得

[ [Ac^{-}]=C[T]K a/(Ka+h),\quad[HAc]=C[T]h/(Ka+h). ]

CBE 方程为

 $h+0.200=(1.00\times10^{-14})/h+(0.300\times1.75\times10^{-5})/(1.75\times10^{-5}+h).$  (3')

解得

[ [H^{+}]=8.7489\times10^{-6}mol\cdot L^{-1},(1') ]

[ [OH^{-}]=1.1430\times10^{-9}mol\cdot L^{-1},(1') ]

由于左侧存在 $\mathrm{Fe(OH)_3(s)}$ ，有$\mathrm{Ksp(Fe(OH)_3) = [Fe^{3 + }][OH^- ]^3}$ $[\mathrm{Fe}^{3 + }] = (2.79\times 10^{-39}) / (1.1430\times 10^{-9})^3 = 1.868\times 10^{-12}\mathrm{mol}\cdot \mathrm{L}^{-1}$ .(2') 铁电极对应还原半反应为 $\mathrm{Fe}^{3 + } + \mathrm{e}^{-}\rightleftharpoons \mathrm{Fe}^{2 + }$ .Nernst方程为$\varphi [\mathrm{Fe}] = \varphi^{\circ}(\mathrm{Fe}^{3 + } / \mathrm{Fe}^{2 + }) + (\mathrm{RT / F})\ln ([\mathrm{Fe}^{3 + }] / [\mathrm{Fe}^{2 + }] = 0.195\mathrm{V}$ .(2') $Q = [\mathrm{Fe}^{2 + }][\mathrm{OH}^{-}]^{2} = 0.0100\times (1.1430\times 10^{-9})^{2} = 1.31\times 10^{-20}$ .(2') 因为 $Q &lt;   Ksp(Fe(OH)_2) = 4.87\times 10^{-17}$ ，故 $\mathrm{Fe(OH)_2(s)}$ 不析出.(2')

铜电极对应还原半反应为  $Cu^{2+} + 2e^{-} \rightleftharpoons Cu(s)$ ，故

 $\varphi[\mathrm{Cu}] = \varphi^{\circ}(\mathrm{Cu}^{2+}/\mathrm{Cu}) + (\mathrm{RT}/2\mathrm{F}) \ln[\mathrm{Cu}^{2+}] = 0.299 \mathrm{~V}. (2')$

由于  $\varphi[\mathrm{Cu}] &gt; \varphi[\mathrm{Fe}]$ ，故右侧铜电极为正极，左侧铁电极为负极。(2')

负极实际氧化过程可写作

 $Fe^{2+} + 3H_{2}O \rightarrow Fe(OH)_{3}(s) + 3H^{+} + e^{-}.$

正极过程为

 $Cu^{2+} + 2e^{-} \rightarrow Cu(s).$

配平得总反应：

 $2Fe^{2+} + 6H_{2}O + Cu^{2+} + 6Ac^{-} \rightarrow 2Fe(OH)_{3}(s) + 6HAc + Cu(s). (3')$

电池电动势为

 $E = \varphi[\mathrm{Cu}] - \varphi[\mathrm{Fe}] = 0.299 - 0.195 = 0.103 \mathrm{~V}. (2')$

该总反应转移电子数为 z=2，故

 $\Delta rG = -zFE = -2 \times 96485 \times 0.103 = -1.99 \times 10^{4} \mathrm{~J} \cdot \mathrm{mol}^{-1} = -19.9 \mathrm{~kJ} \cdot \mathrm{mol}^{-1}. (2')$

6-5 向 1.00 L 初始左侧缓冲溶液浴中加入强酸 $HClO_{4}$ ，并忽略体积变化。计算需加入多少 mol $HClO_{4}$ ，才能达到 6-4 中的 pH。

加入强酸后，设加入  $HClO_{4}$  的分析浓度为 c[a]. 由于  $ClO_{4}^{-}$  不参与酸碱平衡，但参与电荷守恒，有

 $h + C[Na] = [OH^{-}] + [Ac^{-}] + c[a]. (2')$

故

 $c[a] = h + C[Na] - Kw/h - C[T]Ka/(Ka+h).$

将  $h = 3.331 \times 10^{-5}$  代入：

$\mathrm{Fe(OH)_2(s)}$ 开始析出时满足 $[\mathrm{Fe}^{2+}][\mathrm{OH}^{-}]^2 = \mathrm{Ksp}(\mathrm{Fe(OH)}_2)$. 故 $[\mathrm{OH}^{-}] = ((4.87\times 10^{-17}) / 0.0100)^{1 / 2} = 6.98\times 10^{-8}\mathrm{mol}\cdot \mathrm{L}^{-1}.
