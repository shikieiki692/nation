# 题-HZ-07-01-非金属元素X的一种氟化物A在

## 题目

### 第 1 题（18分，占 $16\%$ ）

非金属元素 X 的一种氟化物 A 在低温下与足量水发生非氧化还原水解，得到无色晶体氧化物 B。B 是强氧化剂，受热或受震动时可能发生爆炸性分解。B 溶于浓碱后发生歧化，加入 $\mathrm{Ba(OH)_{2}}$ 溶液可得到难溶盐 C。C 与冷浓硫酸小心反应，生成另一种更高价氧化物 D。称取 0.3906 g D，使其完全分解，得到 97.84 mLO $_{2}$ 和 48.92 mL X 单质蒸气，气体体积均在 25℃、1 atm 下测得，可取该条件下气体摩尔体积为 24.46 L·mol $^{-1}$ 。

1-1 通过计算确定 X 和 D 的化学式。

1-2 写出 B 的化学式，并说明 B 与 D 中 X 的氧化态。

1-3 C 中氧元素质量分数为 19.12%，推断 C 的化学式。

1-4 若 B 的晶胞为正交晶系，a = 616.3 pm, b = 811.5 pm, c = 523.4 pm，密度为 $4.55 \, g \cdot cm^{-3}$ ，计算一个晶胞中含有多少个 B 分子。

1-5 写出 B 氧化甲酸生成 X 单质、 $CO_{2}$ 和水的化学方程式。

## 参考答案

非金属元素 X 的一种氟化物 A 在低温下与足量水发生非氧化还原水解，得到无色晶体氧化物 B。B 是强氧化剂，受热或受震动时可能发生爆炸性分解。B 溶于浓碱后发生歧化，加入 $\mathrm{Ba(OH)_2}$ 溶液可得到难溶盐 C。C 与冷浓硫酸小心反应，生成另一种更高价氧化物 D。称取 0.3906 g D，使其完全分解，得到 97.84 mL O₂ 和 48.92 mL X 单质蒸气，气体体积均在 25℃、1 atm 下测得，可取该条件下气体摩尔体积为 24.46 L·mol⁻¹。

由25℃气体摩尔体积24.46L·mol-1得
n(O₂)=97.84/24460=4.00 mmol
n(X单质)=48.92/24460=2.00 mmol
设D=XOy/2，分解为X单质和O₂。若X单质为单原子气体，则y=8；
代入质量可得
Ar(X)≈131.3，故X=Xe，D=XeO₄。
6分

1-2 写出B的化学式，并说明B与D中X的氧化态。

B为XeO₃
Xe为+VI，XeO₄中Xe为+VIII
4分，阿拉伯数字亦可

1-3 C中氧元素质量分数为19.12%，推断C的化学式。

C为高氙酸钡Ba₂XeO₆
按Ba₂XeO₆计算氧质量分数为96/(2×137.33+131.29+96)≈19.12%。
3分

1-4 若B的晶胞为正交晶系，a=616.3pm, b=811.5pm, c=523.4pm，密度为4.55g·cm⁻³，计算一个晶胞中含有多少个B分子。

晶胞体积V=abc；用ZM=ρN∧V，代入XeO₃式量和晶胞参数得Z≈43分

1-5 写出B氧化甲酸生成X单质、CO₂和水的化学方程式。

XeO₃+3HCOOH=Xc+3CO₂+3H₂O
