# 题-HZ-01-03-31X的某些化合物是熟知的半

## 题目

### 第 3 题（25分，占 $12\%$ ）

3-1 X 的某些化合物是熟知的半导体材料，它还可以应用于玻璃、陶瓷和染料工业等消费领域。X 的定性检测最常用的方法就是将含 X 的化合物还原为单质以鉴别他们的存在，例如可以用羟胺与 X 的 +4 价含氧酸 A 混合，析出红色的 X 单质，产物中还有一种氮氧化物气体产生(反应 1)：在氰化钠浸取金的过程中，X 呈相应的盐 B 进入溶液，B 为硫氰化钠的等电子体，滤出的溶液用 $H_{2}SO_{4}$ 酸化又能得到 X 单质(反应 2)。

3-1-1 写出反应 1\~2 的方程式。

3-1-2 X 单质和它的氧化物 7: 1 与浓硫酸混合可得到 C(反应 3), C 中阳离子具有芳香性,且 C 中 X 的质量分数为 61.93%；同样地，用 X 与 $S_{2}O_{6}F_{2}$ 混合依然可以得到具有相同阳离子的物质 D(反应 4)。写出反应 3 的方程式，并指出 D 的化学式。
