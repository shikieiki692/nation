# 题-HZ-11-06-糖类化合物在水溶液中有开链和

## 题目

### 第 6 题 光度动力学法测定开链醛糖的含量（18 分，占 8%）

糖类化合物在水溶液中有开链和环状两种存在形式，一般情况下环状结构更稳定，占所有存在形式的绝大多数。测定溶液中开链醛糖含量的常规方法是同位素核磁检测，其工作量较大且需要复杂的核磁共振仪器。2021年，研究人员采用2-氨基苯甲脒肟(ABAO)动力学紫外光度法，快速、简便地测得了各类醛糖的微量开链含量，实验结果与公认标准高度一致。6-1该方法可行的基础在于开链醛糖与ABAO的定量反应。

6-2-1 设时间趋于无穷时溶液的吸光度为 $A_{max}$ ，推导吸光度随时间变化的表达式(式中只能含有 $A_{max}$ 、ABAO 的浓度[ABAO]、时间 t 和各反应的速率常数及平衡常数，可进行适当近似)。

∵[ABAO]大过量，∴可假设[ABAO]不随时间变化
d[P]/dt = k₂[ABAO][O]，[O] = K[C]；[C]₀ = [P] + [C] + [O]
∵环状结构占所有存在形式的绝大多数，可忽略[O]，∴[C]₀ = [P] + [C]
∴d[P]/dt = k₂K[C][ABAO] = k₂K([C]₀ - [P])[ABAO]
解得：ln([C]₀ - [P]) = -k₂K[ABAO]t + C
∵t = 0时，[P] = 0，∴C = ln([C]₀)
∴[P] = [C]₀ - exp(-k₂K[ABAO]t + ln([C]₀)) = [C]₀(1 - exp(-k₂K[ABAO]t))
A = εb[P] = εb[C]₀(1 - exp(-k₂K[ABAO]t))
∵t趋于无穷时，[P] = [C]₀，∴A_max = εb[C]₀
∴A = A_max(1 - exp(-k₂K[ABAO]t))（过程2分，结果1分，过程合理结果不对可给一半）
6-2-2 实验数据回归计算结果表明，葡萄糖-ABAO混合溶液的吸光度随时间变化的表达式为A = 0.01274 + 0.6609(1 - e^{-0.000882(t/min)})。已知初始加入的ABAO浓度为40 mmol/L，据此计算葡萄糖溶液中开链醛糖的占比(OCC)。
0.01274为本底吸光度，A_max = 0.6609，k₂K[ABAO] = 8.82 × 10⁻⁴ min⁻¹ = 1.47 × 10⁻⁵ s⁻¹ (1分)
[ABAO] = 0.04 mol/L；D-葡萄糖为苏型，k₂ = 3.76 L/(mol·s)
∴K = 9.77 × 10⁻⁵
OCC = 1/(1 + K) = 0.00977 % (2分)
