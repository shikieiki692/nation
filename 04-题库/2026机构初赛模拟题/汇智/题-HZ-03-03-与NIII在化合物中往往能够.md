# 题-HZ-03-03-与NIII在化合物中往往能够

## 题目

### 第 3 题 二配位 P(III)化学(20 分，占 10%)

与 N(III)在化合物中往往能够形成二配位的 N=X 双键不同，在 P(III)中一般是以三配位结构存在，而低配位数的 P 往往作为 P 卡宾，具有十分活泼的性质。

3- 亚磷酸 $\mathrm{H}_{3} \mathrm{PO}_{3}$ 作为常见的 $\mathrm{P(III)}$ 物种, 在水相中体现出二元酸的性质, 但在偶极溶剂中存在部分三元酸的性质。试画出 $\mathrm{H}_{3} \mathrm{PO}_{3}$ 的在水相和偶极溶剂中的主要存在形式。

3-2-1 通过在低温下光照 P 的两种 P(V)与 P(III)的同分异构体， $\mathrm{MeP(O)(N_3)_2}$ 和 $\mathrm{MeOP(N_3)_2}$ ，可以分别得到两种低配位的 P 的化合物 A 和 B，其互为同分异构体，画出 A 和 B 的 Lewis 结构式，并标注出中心原子的杂化形式，提示：杂化形式不同，配位数不同，且均不含 N。3-2-2 比较 A 和 B 中的 P-O 键的键长。

3-3 然而低配位的 P 化合物只能作为中间体在 3-15K 短暂存在，在 2024 年，一种新的稳定的二配位 P(III)氮氧化物被合成出来，能够在常温无水条件下存在。

3-3-1 在冠醚 18-crown-6 的存在下, 通过 ArNPCl 与 KOTMS 反应, 可得含有 P(III)阴离子的盐 C。且产物中不含 Si-Cl 键, 试给出 C 阴离子的 Lewis 的共振式与生成 C 的反应方程式。(Ar 为大位阻芳环, 在反应式中保留)

3-3-2 C 的性质非常有趣, 体现出特有的亲核性, 与不同的试剂反应会体现不同的反应性质。给出分别与 $\mathrm{H}_{2} \mathrm{O}, \mathrm{BnBr}, \mathrm{iPr}_{3} \mathrm{SiOTf}$ 的反应产物的结构式, 提示: 后两个产物的 $\mathrm{P}$ 未与新原子成键, 且 $\mathrm{P} = \mathrm{X}$ 双键不同, 一个 $\mathrm{X}$ 为 $\mathrm{N}$ , 另一个为 $\mathrm{O}$ 。
