# 题-HZ-09-01-西直门位于北京内城西垣北侧旧

## 题目

### 第 1 题 西直门与泉水（14 分，占 11%）

西直门位于北京内城西垣北侧。旧时，皇城所用之水大多来自西郊的玉泉山，并由西直门进城。因此，西直门也被称为“水门”。瓮城门洞顶上刻有水波纹，以此标志走水车之用。

其中, 水波纹石刻的材质为汉白玉。汉白玉的主要成分是 $\mathrm{CaCO}_{3}$ 和 $\mathrm{CaMg(CO}_{3})_{2}$ 。1-1 $\mathrm{MgCO}_{3}$ 的 $\mathrm{K}_{\mathrm{sp}}$ 比 $\mathrm{CaCO}_{3}$ 更大, 请你解释原因。

玉泉山泉水以富含 $H_{2}SiO_{3}$ 和微量元素 Sr 闻名。Sr 是人体必需的微量元素，其化学性质与钙相似，但原子序数更大。 $H_{2}SiO_{3}$ 则赋予泉水特有的甘甜口感，其含量是评价矿泉水品质的重要指标。

1-2 请你比较 $\mathrm{SrCO}_{3}$ 与 $\mathrm{CaCO}_{3}$ 的热分解温度，并解释原因。

Sr 的常见难溶盐有 SrSO $_{4}$ 和 SrCO $_{3}$ 等。已知 25°C时，K $_{sp}$ (SrSO $_{4}$ ) = 3.2×10 $^{-7}$ ，K $_{sp}$ (SrCO $_{3}$ ) = 1.1×10 $^{-10}$ 。若泉水中 c(Sr $^{2+}$ ) = 0.50 mg/L，c(SO $_{4}^{2-}$ ) = 12 mg/L，c(CO $_{3}^{2-}$ ) 由空气中 CO $_{2}$ 溶解平衡决定（pH = 7.0，[H $_{2}$ CO $_{3}$ ] = 1.2×10 $^{-3}$ mol/L，H $_{2}$ CO $_{3}$ 的 K $_{a1}$ = 4.3×10 $^{-7}$ ，K $_{a2}$ = 5.6×10 $^{-11}$ ）。

1-3 试通过计算判断该泉水是否会生成沉淀。

为测定泉水中偏硅酸的准确含量，可采用硅钼蓝光度法。其原理为：在酸性条件下，正硅酸与 $(\mathrm{NH}_{4})_{2}\mathrm{MoO}_{4}$ 反应生成黄色的硅钼杂多酸 $\left(\mathrm{H}_{4}\mathrm{SiMo}_{12}\mathrm{O}_{40}\right)$ ，然后还原为硅钼蓝，在810 nm处测定吸光度。

1-4-1 写出生成硅钼杂多酸的化学反应方程式。

1-4-2 请你说明为何必须在 $\mathrm{pH} = 1.2$ 的条件下显色，而不能在强碱性条件下进行。

1-4-2 请你说明为何必须在 pH = 1.2 的条件下显色，而不能在强碱性条件下进行。

1-4-2（2分）
强碱性条件下，杂多酸会被水解为单体，不能稳定存在。
或答：碱性环境下，硅酸根和钼酸根均带负电荷，很难发生有效碰撞形成杂多酸。
类似于 $CrO_{4}^{2-}$ 与 $Cr_{2}O_{7}^{2-}$ 的平衡，不论同多酸或是杂多酸，都是在酸性条件下更加稳定。
