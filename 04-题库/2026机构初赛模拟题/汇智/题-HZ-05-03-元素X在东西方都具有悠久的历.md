# 题-HZ-05-03-元素X在东西方都具有悠久的历~2

## 题目

### 第 3 题 Mad as a hatter（23分，占 $9\%$ ）

元素 X 在东西方都具有悠久的历史，其在自然界中主要以硫化物 A 的形式存在，将 A 在空气中煅烧即可得到单质 X，含 X 的化合物大多具有神经毒性，然而以前欧洲制帽工业中用到的毛毡的生产需要使用到 X 盐，导致制帽匠神经紊乱，因此有 Mad as a hatter（像制帽匠一样疯狂）的说法。

X 只有一种常见氧化物 B，可以由 X 在氧气中加热制备，与之对应的是，X 有两种常见的易升华的氯化物 C 与 D。C 可以由 D 与 X 混合制备，将 D、X 与 $AlCl_{3}$ 混合后可以得到离子化合物 E（含 X 64.06%），阳离子只含有 X，所有原子共线。

3-1 试给出 A\~E 的化学式

3-2 元素 X 具有很有意思的配位化学性质（下面问题中若没有推出 X，可以用字母代替）

3-2-1 将 B 溶解在酸里，可以得到含 X 的简单阳离子，通过其极易形成硫化物可以看出，它应该相对较软，比如其与过量碘离子反应可以得到配离子，该配离子可以在碱性环境下检测铵根（反应 1），此外该简单阳离子也可以与铜试剂（ $Et_{2}NCS_{2}^{-}$ ）反应，产生双核配合物，其中 X 的配位数为 5，给出反应 1 的方程式与双核配合物的结构。
