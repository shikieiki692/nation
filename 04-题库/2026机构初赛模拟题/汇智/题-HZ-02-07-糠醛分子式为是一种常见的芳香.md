# 题-HZ-02-07-糠醛分子式为是一种常见的芳香

## 题目

### 第 7 题（32 分，占 16%）Cannizzaro 反应的实际应用

糠醛，分子式为 $C_{5}H_{4}O_{2}$ ，是一种常见的芳香醛，在室温下为无色透明的液体。糠醛在工业上的制备方法是使用甘蔗渣、麦秆等农林废弃物中的半纤维素酸解得到戊糖，再用戊糖脱水环化而得到。作为芳香醛，糠醛在强碱（例如浓 NaOH 溶液）体系的作用下可以发生 Cannizzaro 反应而歧化，生成糠醇 $\left(\mathrm{C}_{5}\mathrm{H}_{6}\mathrm{O}_{2}\right)$ 和糠酸钠 $\left(\mathrm{C}_{5}\mathrm{H}_{3}\mathrm{O}_{3}\mathrm{Na}\right)$ ，经过浓盐酸酸化后可以得到糠酸 $\left(\mathrm{C}_{5}\mathrm{H}_{4}\mathrm{O}_{3}\right)$ ，由此可以制备两种化合物。具体实验过程如下：

量取 4.1 mL 的糠醛(密度为 $1.16 \, g \, mL^{-1}$ )于 100 mL 烧杯中，在不断搅拌下加入 3 mL 40% NaOH 溶液，溶液变为棕褐色。维持体系温度在 $8 \sim 12^{\circ}C$ ，搅拌反应 20 min，此时体系逐渐转变为土黄色浆状物。在搅拌下加入 5 mL 水使沉淀溶解，用乙酸乙酯对反应体系萃取并分液三次（每次 3.5 mL），合并三次分液所得的有机相与水相。

向水相中加入少量浓盐酸至体系 pH 约为 3，此时体系析出大量固体。减压抽滤，用少量水洗涤固体，干燥后称量得到 0.50 g 物质 A。

向有机相中加入少量干燥剂，静置少许后将干燥剂过滤，对过滤后的液体进行常压蒸馏，蒸气温度在 $64^{\circ}$ C 附近时蒸出物质 B，蒸气温度在 $156^{\circ}$ C 附近时蒸出物质 C，其中称得物质 C 质量为 1.06 g。
