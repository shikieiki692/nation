# 题-YS-09-03-索伦石是1961年在我国内蒙

## 题目

### 第 3 题（18分，占 $9\%$ ）失落之石

索伦石 $\left(\mathrm{CaO}\cdot\mathrm{SiO}_{2}\cdot\mathrm{H}_{2}\mathrm{O}\right)$ 是1961年在我国内蒙古首次发现的矿物，亦是含水硅酸盐矿物中 $CaO:SiO_{2}:H_{2}O=1:1:1$ 的唯一一种矿物。加热可使得索伦石完全脱水为硅灰石，两次失重的温度区间为440\~610℃和810\~880℃，分别失重11.2%和2.3%。

3-1 写出索伦石加热脱水失重两个阶段的化学方程式。

索伦石中硅酸根具有平行 $c$ 轴的 $C_2$ 轴，硅酸根在正当晶胞的位置如下图所示：

![](images/85af9fa7994d3efa39fd747da971f6ac6cf8cd9825f25f01f4855c8017e2eb32.jpg)

索伦石属于正交晶系，晶胞参数：a=1102 pm, b=1974 pm, c=608 pm。

3-2 计算索伦石的理论密度。

索伦卡中硅酸根更准确形式为 $H_{2}Si_{2}O_{7}^{4-}(Si-Si'$ 距离 $d_{1}=326\ pm$ ，有一对 $Si-O^{-}(Si-O_{2}$ 键长 $d_{2}\approx0.5d_{1})$ 与同个水分子的两个氢原子分别成氢键，而剩下的 Si-OH 和 $Si-O^{-}$ 则与其相邻的 $H_{2}Si_{2}O_{7}^{4-}$ 形成近平行于 ab 平面的分子间氢键。水中氧原子 $O_{5}$ 和双四面体共用氧原子 $O_{1}$ 距离 $d_{3}=0.5c$ ，而 $O_{2}-O_{5}$ 距离 $d_{4}$ 与 $O_{1}-O_{2}$ 距离 $d_{5}$ 相等。

3-3 假定氢键 $\mathrm{O}_2\cdots \mathrm{H}-\mathrm{O}_5$ 各原子严格共线，根据以上几何信息计算晶胞中水分子的键角。

![](images/90788b7e14cb9845b07a49f769959c58602d460a6e985e33ac05a976b86b0b0e.jpg)

氢原子的位置实际来源于其他原子位置和红外测量的推算。红外光谱可以提供一些氢键信息，如 Nakamoto 等人认为氢键红外吸收光谱带频率 v 是氢键 O…H-O 中 O-O 距离 d 的函数。在相当大范围内该函数呈线性，其公式为 $v(\mathrm{cm}^{-1}) = 41.635 \times d(\mathrm{pm}) - 8344.8$ 。3-4 估算硅酸根与水分子形成氢键的红外吸收频率 v。

3-2（本小问共12分）
设 $[H_{3}O^{-}] = x \, mol \, kg^{-1}$ ， $[H_{3}SO_{4}^{+}] = y \, mol \, kg^{-1}$ ，则由化学平衡有：
 $[HS_{2}O_{7}^{-}] = K_{1}/x \, mol \, kg^{-1}$ （0.5分） $[HSO_{4}^{-}] = K_{2}/y \, mol \, kg^{-1}$ （0.5分）
 $[H_{2}S_{2}O_{7}] = K_{1}y / K_{3}x \, mol \, kg^{-1}$ （0.5分） $[H_{2}O] = K_{2}x / K_{4}y \, mol \, kg^{-1}$ （0.5分）
另有物料平衡：
①： $[H_{3}O^{+}] + [H_{2}O] = [HS_{2}O^{-}] + [H_{2}S_{2}O_{7}]$ （1分）
②： $[HSO_{4}^{-}] + [H_{2}O] = [H_{3}SO_{4}^{-}] + [H_{2}S_{2}O_{7}]$ （1分）
两者相减就是电荷平衡：
③： $[H_{3}O^{+}] + [H_{3}SO_{4}^{+}] = [HSO_{4}^{-}] + [HS_{2}O_{7}^{-}]$ （1分）
解①得： $x = \sqrt{\frac{K_{1}K_{2}(K_{3} + y)y}{K_{2}(K_{4}y + K_{2})}}$ （2分）
带回① $\frac{K_{2}}{y} + \frac{K_{2}}{K_{4}}\frac{x}{y} = y + \frac{K_{1}}{K_{3}}\frac{y}{x} \Rightarrow K_{4}(K_{3}x + K_{1})y^{2} = K_{2}K_{3}(K_{4} + x)x$
即得： $y = 414 \times 10^{-2}$ （0.5分） $x = 1.003 \times 10^{-2}$ （0.5分）
