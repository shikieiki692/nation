# 题-GChO-46-06-氟硼烯BF为CO的等电子体在

## 题目

### 第 6 题 (14分)

氟硼烯 BF 为 CO 的等电子体，在其比 CO 能量更高的 HOMO 和能量更低的 LUMO 使得其理论上是一种比 CO 更好的 $\pi$ -acceptor 配体。

今年，同济大学某课题组利用 BF 和 $N_{2}$ 在极低温度下的反应，制备了三种不同的 BF- $N_{2}$ 化合物 A, B, C.（分子量均不超过 100）

A 和 B 中，N 元素的质量分数为 31.97%，而 C 中 N 的质量分数为 48.45%。

其中 A 与 C 都是具有 $C_{2v}$ 对称性的环状结构，计算表明 C 具有芳香性，A 中不存在定域的 N-N 键的作用， $\pi$ 电子也是离域的。而 B 则具有 $D_{\infty h}$ 的对称性。
6-1 写出 A\~C 的化学式。

6-2 给出 A 和 C 的立体结构，需要标明孤对电子。写出 A 和 C 环状体系中离域 $\pi$ 键的符号 ( $\pi_{m}^{n}$ )。

6-3 给出 B 的结构式，注意正确的表示出形式电荷。实验测得其中 N-N 键长明显小于经典 N-N 单键的键长，这一结论可以用经典的价键理论很好的解释。请给出 B 中 B 和 N 原子的杂化方式，以及形成的离域 $\pi$ 键的符号和数目。

6-4 试从 C 的结构出发，简要分析 BF 是如何 “活化” 惰性的 $N_{2}$ 分子，并与之成环的。可以画出轨道作用的示意图，也可以直接描述轨道作用的方式。
