# 题-GChO-83-04-MXene是由MAX相处理得

## 题目

### 第 4 题 MXene 与锂硫电池(32 分，占 12%)

MXene 是由 MAX 相处理得到的类石墨烯结构，MAX 相的具体化学式为 $M_{n+1}AX_{n}$ (n = 1\~4)，其中 M 指过渡金属，如 Ti 或 Nb；A 指主族元素，如 Al、Ga 和 Si 等；X 指 C 或/和 N。通过刻蚀作用可将结合力较弱的 A 从 MAX 相中移除，得到 2D 结构的 MXene。MXene 具有 $M_{n+1}X_{n}T_{x}$ (n = 1\~4, $x \leqslant 2$ ) 的通式，其中 T 表示表面的端基，如 -OH、-F 等。自 2011 年 Naguib 等人首次在室温下使用氢氟酸选择性蚀刻 $Ti_{3}AlC_{2}$ 制备 $Ti_{3}C_{2}F_{2}$ 以来，越来越多的研究者致力于寻找更多的方法来制备 MXene。

4-1 写出 HF 刻蚀 $Ti_{3}AlC_{2}$ 制备 MXene ( $Ti_{3}C_{2}F_{2}$ ) 的化学方程式。

4-2 将 $Ti_{n+1}SiC_{n}$ 置于 750 °C 的 $CuCl_{2}/NaCl/KCl$ 熔融盐中刻蚀，得到 Cl 含量为 29.72% 的 MXene 材料 A。写出 MXene A 的化学式，以及制备 A 的化学方程式，并指出刻蚀结束后如何分离 A 与过量的 $CuCl_{2}$ 、NaCl、KCl。

4-3 某 MAX 相材料含有 Ti、Al、C 三种原子，Ti 原子的堆积方式为…ABBAABBA…，其中 A、B 都是密置单层。C 原子占据所有的正八面体空隙，而 Al 原子则占据一半的三棱柱空隙，且沿着晶胞 c 轴方向，Al 和 C 原子的投影重合。

4-3-1 直接写出该 MAX 相经 HF 刻蚀后得到的 MXene 材料 B 的化学式(F 尽可能多)。

4-3-2 已知该 MAX 相属六方晶系，Ti、C 原子之间的平均键长为 0.216 nm，Ti、Al 原子之间的平均键长为 0.278 nm，请计算该 MAX 材料的理论密度。

与锂离子电池相比，锂硫电池的理论比容量和能量密度有很大的优势。锂硫电池的放电过程为单质硫 $(\mathrm{S}_8)$ 参与还原反应，先与锂生成液态多硫化物中间体 $(\mathrm{Li}_2\mathrm{S}_x, 2 < x \leq 8)$ 最终还原成硫化锂 $(\mathrm{Li}_2\mathrm{S})$ 。锂硫电池的放电过程有两个电压平台，上电压平台对应 $\mathbf{S}_8$ 向液态长链多硫化物 $\mathrm{Li}_2\mathrm{S}_x (2 < x \leq 8)$ 的转化和溶解，低电压平台对应于多硫化物 $\mathrm{Li}_2\mathrm{S}_x (2 < x \leq 8)$ 进一步还原为不溶性短链多硫化物 $\mathrm{Li}_2\mathrm{S}_2 / \mathrm{Li}_2\mathrm{S}$ 并沉淀到正极上。

4-4 写出锂硫电池放电的总反应方程式，以及对应的正极和负极反应。(均只写出一个方程式即可)

4-5 写出锂硫电池的电池符号。

4-6 基于正极材料质量，计算锂硫电池的理论比容量，以 mAh/g 为单位。

4-7 已知锂硫电池的理论放电电压为 2.287 V，试计算锂硫电池的理论储能密度(基于正负极的总质量，结果以 Wh/kg 表示)。

MXene 材料在锂硫电池的应用中具有诸多优势。单质 $S_{8}$ 和放电产物 $Li_{2}S$ 的导电性能较差，降低了电子迁移速率和反应动力学，而 MXene 作为载硫体时，其表面基团(-OH)可以与多硫化锂形成硫代硫酸盐基团，且亚稳态 Ti 原子可以与多硫离子成 Ti-S 键，从而固定多硫化物，减少穿梭效应带来的活性物质损失，提高电池循环寿命。

4-8 以 $I = 400 \mathrm{~mA}$ 的电流通电 $1.02 \mathrm{~h}$ (理论值，假设法拉第效率为 $100\%$ )，可以使得 $0.115 \mathrm{~g} \mathrm{MXene}$ 材料达到硫饱和负载，计算该 MXene 材料的载硫率(以质量分数计)。
