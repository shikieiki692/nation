# 题-GChO-45-06-近二十年来人们制备了许多含二

## 题目

### 第 6 题 (13分)

近二十年来，人们制备了许多含二膦甲基负离子的金属配合物。作为配体，无论是过渡金属还是主族金属，二膦甲基负离子都可以与之配位。但是二膦甲基负离子的反应性我们却知之甚少。接下来我们将研究一类二膦甲基负离子与亲电非金属进行的反应。这类反应是有趣的，因为它可以使双膦中心碳原子官能团化，从而开启金属辅助合成更复杂的双膦甲基配体的大门。

6-1 用 $\mathrm{Br}_2$ 处理 $(\mathrm{Ph}_2\mathrm{P})_2\mathrm{CH}^-$ ，得到了 $(\mathrm{Ph}_2\mathrm{P})_2\mathrm{CH}_2$ 、 $(\mathrm{Ph}_2\mathrm{P})_2\mathrm{CBr}_2$ 、 $(\mathrm{Ph}_2\mathrm{P})_2\mathrm{CHBr}$ 、 $(\mathrm{Ph}_2\mathrm{P})_2\mathrm{CBr}^-$ 这四种产物，写出得到这四种产物的方程式。（可以写多个方程式）

6-2 用某非金属单质分子 X 处理化合物 A，仅得到了两种产物 B 和 C。B 是中性化合物分子，而 C 是离子化合物。已知化合物 A 的分子式为 $[(OC)_{4}MCH(Ph_{2}P)_{2}]$ ，且 X 的生成焓为 0。
6-2-1 画出化合物 A 的立体结构（中心金属原子用 M 表示）

6-2-2 中心金属元素在化合物 A、B、C 中的含量为 9.42%、8.51%、9.98%（数据是打乱的，并不知道哪个数据对应哪个化合物），另外，方程式的计量比为 $4A + X = B + C$ ，画出 B 和 C 的结构，指出 M 代表的金属原子以及 X 的分子式（写出推理步骤）。
