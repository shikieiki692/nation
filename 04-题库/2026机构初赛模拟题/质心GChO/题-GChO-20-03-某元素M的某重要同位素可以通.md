# 题-GChO-20-03-某元素M的某重要同位素可以通

## 题目

### 第 3 题 (13分)

某元素 M 的某重要同位素可以通过 ${}^{238}$ U 通过 $(n, \gamma)$ 反应（中子捕获反应）以及连续两次的 $\beta$ -衰变得到，另外一种重要同位素则可以通过 ${}^{241}$ Am 通过 $(n, \gamma)$ 反应以及 $\beta$ -衰变， $\alpha$ -衰变制备。将 M 的单质置于 $O_{2}$ 中高温加热，得到 M 的稳定氧化物 A。在氧气气氛中，A 与 HF 在 $500^{\circ}C$ 左右下反应生成 B，B 与过量的 $F_{2}$ 在 $700^{\circ}C$ 左右发生反应得到 C，C 是一种强氧化剂，可以将 $BrF_{3}$ 氧化为 $BrF_{5}$ 。若将 B 与 $NH_{4}F$ 在 $100^{\circ}C$ 左右反应，则生成 $M_{4}N$ 型离子化合物 D，D 的阴离子配位数为 8。D 受热的分解过程较为复杂，最终分解产物为 B。将 D 加热到 $160^{\circ}C$ 左右，分解生成化合物 E，该过程中失重为 15.82%（M 的质量数按照质子数 +150 计算），在真空中加热到 $250^{\circ}C$ 以上时，E 进一步分解，失重（占 E 质量）9.40%，得到化合物 F，F 进一步加热则分解为 B。

3-1 分别写出题目中所述的 2 种制备 M 不同质量数的同位素的方法的过程，并写出 M 的核外电子排布式。只需要写出核素和对应的过程即可，一种示例如下：（但答题时需要一并写出核素的质子数

和质量数）

$$
{ } ^ { 232 } \mathrm{Th} \xrightarrow { \alpha \text {   衰变   } } { } ^ { 228 } \mathrm{Ra} \quad \xrightarrow { \beta \text {   衰变   } } { } ^ { 228 } \mathrm{Ac} \xrightarrow { \beta \text {   衰变   } } { } ^ { 228 } \mathrm{Th}
$$

3-2 分别写出 A, B, C 以及 D 的化学式。

3-3 通过计算给出 E，F 的化学式。

3-4 已知 B 在 700 K\~1200 K 下, 蒸汽压随温度变化的函数关系为: $\log p(\text{torr}) = 5.580 - 10040 / T(\text{K})$ , 据此计算 B 在该温度范围内的 $\Delta_{sub}H_{m}^{\ominus}$ 。(1 torr = 1 mm Hg 柱产生的压力)
