# 题-GChO-35-05-如下是配合物B和D的合成路线

## 题目

### 第 5 题 (11分)

如下是配合物 B 和 D 的合成路线，这两个配合物被认为有望用于催化氮气还原为氨气的反应。

$$
\begin{array}{c} \text { ReCl } _ {3} (\text { PPh } _ {3}) _ {2} (\text { MeCN }) + \\ 1 \quad \text { 1.0 eq. } \end{array} \xrightarrow [ \text { THF } ]{\text { THF }} \begin{array}{c} \text { A } \quad \frac {\text { N } _ {2} (1 \text { atm })}{\text { KHBEt } _ {3} (2.0 \text { eq. })} \\ \text { THF,   rt,   8   h } \end{array} \xrightarrow [ \text { THF,   rt,   8   h } ]{\text { B }}
$$

$$
\begin{array}{c} \mathrm {MoCl_ {3} (thf) _ {3}} \\ 3 \end{array} + \begin{array}{c} \mathrm {P ^ {t} B u _ {2}} \\ \mathrm{N} \\ \mathrm {P ^ {t} B u _ {2}} \end{array} \xrightarrow [ 50 ^ {\circ} \mathrm{C} , 18 \mathrm{h} ]{\text {THF}} \quad \mathrm{C} \xrightarrow [ \text {THF,rt,12h} ]{\mathrm {N _ {2} (1 atm)}} \quad \mathrm{D}
$$

在红外光谱 $1500 \sim 2500 \, cm^{-1}$ 的特征吸收波段，配合物 B 有两个吸收峰，分别是 $1892, 1956 \, cm^{-1}$ (THF 溶液)，还有一个 Raman 光谱吸收峰， $1890 \, cm^{-1}$ (THF 溶液)。配合物 D 只有一个红外吸收峰， $1944 \, cm^{-1}$ (THF 溶液)，一个 Raman 吸收峰为 $1890 \, cm^{-1}$ (THF 溶液)。（不需要特别在意这些数据）

配合物 B 和 D 都被预测可能是存在对称面或者对称中心的高对称性结构，但通过 X 射线单晶衍射测得的晶体结构显示，配合物 B 没有对称面和对称中心，只有一个 $C_{2}$ 轴，配合物 D 有两个互相垂直的对称面和两个互相垂直的 $C_{2}$ 轴，但是没有对称中心。

元素分析结构显示配合物 B 中氮元素的质量分数为 8.50%，配合物 D 中氮元素的质量分数为 14.97%，
