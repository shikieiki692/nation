# 题-GChO-52-05-电解盐A的水溶液可以得到漂白

## 题目

### 第 5 题 (11分)

电解盐 A 的水溶液可以得到漂白粉(反应 1)。盐 B 的焰色呈黄色，向含有甲基橙的盐 B 的水溶液中不断加入硝酸至甲基橙刚变色，再加入硝酸银溶液，可以产生黄色沉淀。

在剧烈搅拌下，向 B 的溶液中逐滴加入 12.1 mL 40% 的 A 溶液(密度为 $1.396 \, g/cm^{3}$ )，析出白色沉淀 C，C 中金属元素的质量分数(金属元素来自盐 A)为 38.03%。过滤并洗涤沉淀，得到 C 的质量为 17.45 g。C 有三种阴离子，在较低的温度下煅烧 C(反应 2)，失重 1.90%。

如果没有迅速过滤出 C，则在上述溶液中会形成 D(反应 3)，D 是人类身体的重要组成部分。5-1 写出 A\~D 的化学式，其中 C 的结果需要有详细的推导和讨论过程。

5-2 写出反应 1\~反应 3 的化学方程式。

## 推导过程:

Ca 的质量分数为 38.03%，一个 Ca 对应 40.08/38.03% = 105.3 的分子量
C 在较低温度下煅烧，很可能是失水，假设失去 1 分子水，则 C 的分子量约为 18.016/1.90% = 948948 恰好是 105.3 的 9 倍，几乎可以说明 C 中有 9 个 Ca。1 分 $CaCl_{2}$ 和 $Na_{3}PO_{4}$ 的反应体系里面的阴离子以 $PO_{4}^{3-}, HPO_{4}^{2-}, OH^{-}, Cl^{-}$ 为主
如果 C 中的水是结晶水，因为有且只有一个，此时阴离子只可能是 $PO_{4}^{3-}$ 和 $Cl^{-}$ ，找不出第三种阴离子，故 C 中不是结晶水，阴离子的组合应该是 $PO_{4}^{3-}HPO_{4}^{2-}Cl^{-}; PO_{4}^{3-}OH^{-}Cl^{-}; PO_{4}^{3-}, HPO_{4}^{2-}, OH^{-}0.5$ 分除开 Ca，剩余部分的分子量是 9×105.3×(1−38.03%) = 5820.5 分
Case 1: $Ca_{9}(PO_{4})_{x}(HPO_{4})_{2}Cl_{y}$ 有 3x + y = 1694.97x + 95.98×2 + 35.45y = 582 此时的解甚至不是正数 0.5 分
Case 2: $Ca_{9}(PO_{4})_{x}(OH)_{2}Cl_{y}$ 有 3x + y = 1694.97x + 17.01×2 + 35.45y = 582 解得 x=1.68 y=10.93，并不是整数 0.5 分
Case 3: $Ca_{9}(PO_{4})_{x}(HPO_{4})_{y}(OH)_{z}$ 此时有 3x + 2y + z = 18 y+z = 294.97x + 95.98y + 17.01z = 582
解得 x = 5 y = z = 1，是合理的整数解 1 分
故 C 的化学式为 $Ca_{9}(PO_{4})_{5}(HPO_{4})(OH)$ 化学式每个 1 分，共 4 分，推导过程共 4 分。如果完全没有讨论 Cl−可能存在，只是直接讨论了 $Ca_{9}(PO_{4})_{x}(HPO_{4})_{y}(OH)_{z}$ 的情况，计算过程合理且明确，共扣 1 分。
