## 参考答案

4-1 A 是含有金属 M 的简单盐类(即阴阳离子分别只有一种)。将 0.595 g 的 A 完全溶解于过量的盐酸中，释放出 0 °C, 101.325 kPa 下的 0.112 L 气体 X，密度为 1.964 g/L。试仅利用目前的信息，尽量全面地考虑，通过计算和推理，导出 A 可能的 3 种化学式。(如果需要用到镧系和锕系元素的原子量，请翻阅自己的资料)

```txt
M(X) = 29×1.964/1.29 = 44.1(g/mol) 0.5 分
故 X 是 CO₂
且 n(X) = 0.112/22.4 = 0.00500(mol) 0.5 分
因为是“简单盐类”，所以 A 要么是碳酸盐，要么是碳酸氢盐 0.5 分
①假设 A 是 M(CO₃)₀.₅x (x 为整数)
则 Mᵣ(A) = Mᵣ(M) + 0.5x × 60.0 = 0.595/(0.00500/0.5x) 0.5 分
整理可得 Mᵣ(M) = 29.5 x 0.5 分
当 x=2 时，Mᵣ(M)有合理取值 59，为 Co 或者 Ni，此时 A 是 CoCO₃ 或 NiCO₃ 0.5 分
②假设 A 是 M(HCO₃)ᵧ (y 是整数) 0.5 分
则 Mᵣ(A) = Mᵣ(M) + 61.0y = 0.595y/0.50000
整理得 Mᵣ(M) = 58.0 y 0.5 分
当 y=4 时，Mᵣ(M)有合理取值 232.0，为 Th，此时 A 是 Th(HCO₃)₄ 0.5 分
故 A 可能为 CoCO₃, NiCO₃, Th(HCO₃)₄ 0.5 分
没讨论碳酸氢盐的情况，只写出了 Co 和 Ni(有些同学可能还写出了 Y)，共扣 2 分。4-1 共 5 分

4-2 将上述溶液小心地浓缩，可以析出沉淀 B，B 在 140 ℃ 下长时间干燥可以得到蓝色晶体 C。B 和 C 中 M 的质量分数分别为 24.77% 和 45.39%。
```

4-2-1 不通过计算，最终确定 A 是什么化合物，为什么？

$CoCO_{3}$ ，因为 C 是蓝色。0.5 分，没写理由不得分。

各 1.5 分，Z1 如果没有写出正离子或者电荷未标/标错，扣 1 分。

4-4-2 写出反应 1\~反应 3 的化学方程式

反应 1:  $CoCO_{3} + C_{10}H_{16}N_{2}O_{8} \rightarrow H_{2}CoC_{10}H_{12}N_{2}O_{8} + CO_{2} + H_{2}O$

反应 2:  $2H_{2}[Co(C_{10}H_{12}N_{2}O_{8})] + H_{2}O_{2} \rightarrow 2HCoC_{10}H_{12}N_{2}O_{8} + 2H_{2}O$

每个 1 分，共 3 分，化学式合并写也可以。
