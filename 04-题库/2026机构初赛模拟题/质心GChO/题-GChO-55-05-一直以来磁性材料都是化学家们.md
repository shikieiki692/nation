# 题-GChO-55-05-一直以来磁性材料都是化学家们

## 题目

### 第 5 题 (14分)

一直以来，磁性材料都是化学家们研究的一个热点，然而涉及到磁性的材料往往离不开铁系元素和稀土元素。近日，某团队合成了一中新型的不含铁系元素和稀土元素的磁性材料，其在 $28^{\circ}$ C 这个相当舒适的温度下就可以发生由铁磁性到顺磁性的转变。其正当晶胞结构如右图所示，请观察并回答下列问题。

5-1 该晶体由 Mn、As、Pt 三种元素构成，存在两种最近的 Mn-Pt 距离，但可以近似认为其相等，都为 278.5 pm，最近的 As-Pt 距离为 251 pm。

5-1-1 写出晶胞的化学式和其所属的点阵型式。

5-1-2 计算该晶胞的晶胞参数。

5-1-3 写出所有 Pt 原子的坐标。

5-2 进一步的研究表明，晶体中的 Mn 可以全部替换为 Mg，同时晶体在 ab 方向上有少许拉伸。然而进行原子替换后得到的材料却不能发生铁磁性向顺磁性的转变，试解释原因。

5-3 通过对晶体结构的观察，科学家发现本晶体与另一种由 Pu、Ga、Co 组成的非传统超导体有着一致的结构。在超导体的晶体结构中，仅存在一种空间环境的 Pu 和 Co。写出 Pu 和 Co 的配位数、配位多面体以及 Co 与 Co，Co 与 Pu，Pu 与 Pu 的配位多面体之间连接方式。
