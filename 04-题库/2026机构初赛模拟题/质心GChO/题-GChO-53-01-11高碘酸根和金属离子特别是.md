# 题-GChO-53-01-11高碘酸根和金属离子特别是

## 题目

### 第 1 题 (13分)

1-1 高碘酸根和金属离子, 特别是高价金属离子有良好的“相性”(比如容易形成沉淀、络合物等等)。Ni(II)盐在碱性条件下与过二硫酸钾以及高碘酸钾一起煮沸, 冷却后可以析出一种含 Ni 17.80% 的结晶水合物(已知化合物中的 Ni:I=1:1), 请写出该反应的离子方程式。

1-2 $\left[\mathrm{C}_n\mathrm{O}_n\right]^{2-}$ 是一系列结构很有特点的阴离子，比如 $n = 4$ 时代表的方酸阴离子已经在国初里考过两次了。向氯化锶溶液中加入某种属于这个系列的阴离子A，会得到特殊的红色沉淀，其中锶的质量分数为 $34.3\%$ ，写出该沉淀的化学式，画出A的结构简式。

1-3 偏钒酸铵是一种白色粉末状固体，在水中的溶解度不高。将偏钒酸铵溶于盐酸(反应 1)，加入 Zn 单质，溶液先变为紫色(反应 2)，而后很快变为绿色(反应 3)，写出三个反应的离子方程式。

1-4 我们知道， $\mathrm{H}_2\mathrm{SeO}_4$ 是唯一可以溶解黄金的单一酸，但研究表明溶解后得到的“硒酸金”并非简单的 $\mathrm{Au}_2(\mathrm{SeO}_4)_3$ ，实际的产物中 Se 体现多种氧化态。为了探究其具体成分，现取 $10.018\mathrm{g}$ 产物与盐酸充分反应，将得到的气体先后通过饱和食盐水和浓硫酸，最后收集到 $0.314\mathrm{L}$ 气体（ $100\mathrm{kPa}, 25^{\circ}\mathrm{C}$ ），请通过写出“硒酸金”的化学式(需要有简单的推理过程)，并写出金溶解在 $\mathrm{H}_2\mathrm{SeO}_4$ 中的反应方程式。

1-5 砒霜可以用来检验少量的醋酸根，该反应得到的含 As 化合物据说是 As 的第一例被发现的有机化合物，含 O 7.08%, 含 C 21.24%，同时还产生了 CO₂ 气体。请写出反应的方程式。

1-3 偏钒酸铵是一种白色粉末状固体，在水中的溶解度不高。将偏钒酸铵溶于盐酸(反应 1)，加入 Zn 单质，溶液先变为紫色(反应 2)，而后很快变为绿色(反应 3)，写出三个反应的离子方程式。

反应 1:  $(\mathrm{NH}_{4})\mathrm{VO}_{3} + 2\mathrm{H}^{+} \rightarrow \mathrm{VO}_{2}^{+} + \mathrm{NH}_{4}^{+} + \mathrm{H}_{2}\mathrm{O}$  1 分
反应 2:  $2\mathrm{VO}_{2}^{+} + 3\mathrm{Zn} + 8\mathrm{H}^{+} \rightarrow 2\mathrm{V}^{2+} + 3\mathrm{Zn}^{2+} + 4\mathrm{H}_{2}\mathrm{O}$  1 分
反应 3:  $4\mathrm{V}^{2+} + \mathrm{O}_{2} + 4\mathrm{H}^{+} \rightarrow 4\mathrm{V}^{3+} + 2\mathrm{H}_{2}\mathrm{O}$  1 分
不写离子方程式不得分。反应 1 偏钒酸铵不得拆开。反应 2 和 3 产生的两种钒离子也可以写六水合钒离子，配平即可。

1-4 我们知道， $\mathrm{H}_2\mathrm{SeO}_4$ 是唯一可以溶解黄金的单一酸，但研究表明溶解后得到的“硒酸金”并非简单的 $\mathrm{Au}_2(\mathrm{SeO}_4)_3$ ，实际的产物中 Se 体现多种氧化态。为了探究其具体成分，现取 $10.018\mathrm{g}$ 产物与盐酸充分反应，将得到的气体先后通过饱和食盐水和浓硫酸，最后收集到 $0.314\mathrm{L}$ 气体（ $100\mathrm{kPa}, 25^{\circ}\mathrm{C}$ ），请通过写出“硒酸金”的化学式(需要有简单的推理过程)，并写出金溶解在 $\mathrm{H}_2\mathrm{SeO}_4$ 中的反应方程式。

Se(VI)可以1:1氧化HCl得到 $\mathrm{Cl}_2$ 0.5分$n(\mathrm{Cl}_2) = pV / RT = (0.314\times 100) / (8.314\times 298) = 0.127(\mathrm{mol})$ 0.5分题干中描述Se有多种氧化态，最可能的就是 $+6$ 和 $+4$ ，假设有1个6价Se，可将“硒酸金”的化学式假设为 $\mathrm{Au}_x(\mathrm{SeO}_4)(\mathrm{SeO}_3)_y$ 0.5分则“硒酸金”的摩尔质量 $M = m / n(\mathrm{Cl}_2) = 790.5\mathrm{g mol^{-1}} = (197.0x + 142.96 + 126.96y)\mathrm{g mol^{-1}}$ 0.5分又根据电荷守恒， $3x = 2 + 2y$ ，直接可解得 $x = y = 2$ 0.5分故“硒酸金”的化学式为 $\mathrm{Au}_2(\mathrm{SeO}_4)(\mathrm{SeO}_3)_2$ 0.5分溶解方程式： $2\mathrm{Au} + 4\mathrm{H}_2\mathrm{SeO}_4 = \mathrm{Au}_2(\mathrm{SeO}_3)_2(\mathrm{SeO}_4) + \mathrm{H}_2\mathrm{SeO}_3 + 3\mathrm{H}_2\mathrm{O}$ 1分有别的假设方式，比如把化学式设为 $xAu_{2}O_{3}\cdot SeO_{3}\cdot ySeO_{2}$ 等，得到正确结果，也可得分。没有计算和推理过程直接写答案的，不得分。

1-5 砒霜可以用来检验少量的醋酸根，该反应得到的含 As 化合物据说是 As 的第一例被发现的有机化合物，含 O 7.08%, 含 C 21.24%，同时还产生了 $CO_{2}$ 气体。请写出反应的方程式。

$$
