# 题-GChO-40-05-如图此为某CsO化合物沿着c

## 题目

### 第 5 题(16 分)

![](images/59f350b287634bb44d522397e13438ca2f94446e43704785843d54dd6e480847.jpg)

![](images/f8eb051c6441931326cb4777fb68857426371a8b28b1197fafd9d2108bddc9df.jpg)

![](images/799acf2a2dde1bcf67b1c14c4abdc5524615b864ebac329409cbbea1b0b8bcd9.jpg)

如图，此为某 Cs-O 化合物沿着 c 轴和 $(\boldsymbol{b}-\boldsymbol{a})$ 方向的投影图。红色为 O，紫色为 Cs(如果看不清，到时候会把彩图发群里)。已知其部分正当晶胞参数 $a = 882.0 \, pm, c = 752.6 \, pm$ 5-1 写出该化合物的化学式。

5-2 写出所有 Cs 的坐标。其中一个是(0,1/4,1/4)，晶体中较近的 Cs-O 距离有几种？计算此距离。

5-3 计算最近的两种 Cs-Cs 距离。我们知道，在很多 Cs 的低氧化物中，由于 Cs-Cs 距离很近故存在 Cs-Cs 的作用，并使得这些低氧化物具有金属 Cs 的性质。如果 $r(\mathrm{O}^{2-})=121\ \mathrm{pm}$ ，根据你计算的距离，判断此化合物是否具有 Cs-Cs 的作用。

5-4 该结构可以视为(链状/层状/三维网格)中的哪种类型？O 原子的配位数为几？

5-5 该结构是否具有与主轴垂直的对称面？据此其属于什么晶系？写出一个结构基元包含的内容。
5-6 计算该晶体的理论密度。
