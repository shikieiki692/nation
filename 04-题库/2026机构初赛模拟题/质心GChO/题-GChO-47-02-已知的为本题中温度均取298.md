# 题-GChO-47-02-已知的为本题中温度均取298

## 题目

### 第 2 题 (13分)

已知 $\mathrm{Zn(OH)_{2}}$ 的 $K_{sp}$ 为 $1.80 \times 10^{-17}$ ，本题中温度均取 298.15 K。

2-1 计算 $\mathrm{Zn(OH)_{2}}$ 在纯水中的溶解度 s(mol/L) 和饱和溶液的 pH 值。

2-2 已知 $\varphi^{\circ}[Zn(OH)_{4}^{2-}/Zn]=-1.285\ V$ $\varphi^{\circ}(Zn^{2+}/Zn)=-0.762\ V$ ，计算 $Zn(OH)_{4}^{2-}$ 的稳定常数 $\beta_{4}$ .

2-3 以下问题均考虑溶液中存在的 Zn(II)物种只有 $Zn^{2+}$ 和 $\mathrm{Zn(OH)}_{4}^{2-}$ 。

2-3-1 分别导出 $[Zn^{2+}]$ 与 $[OH^{-}]$ ， $[Zn(OH)_{4}^{2-}]$ 与 $[OH^{-}]$ 的关系式。

2-3-2 计算 $\mathrm{Zn(OH)_{2}}$ 在 pH = 9.80 的缓冲溶液中的溶解度 $s(\mathrm{mol/L})$ 。

2-3-3 要使 $\mathrm{Zn(OH)_{2}}$ 的溶解度达到 0.010 mol/L 以上，计算缓冲溶液的 pH 应满足什么样的条件？

2-3-4 计算 pH 为多少时， $\mathrm{Zn(OH)_2}$ 的溶解度最低？并求出此时的溶解度。

## 参考答案

已知 $\mathrm{Zn(OH)_{2}}$ 的 $K_{sp}$ 为 $1.80 \times 10^{-17}$ ，本题中温度均取 298.15 K。

2-1 计算 $\mathrm{Zn(OH)_{2}}$ 在纯水中的溶解度 $s(\mathrm{mol/L})$ 和饱和溶液的 pH 值。

$s(2s)^{2}=K_{\mathrm{sp}}$  解得
 $s=1.65\times10^{-6}\ mol/L$  (1 分)
 $[OH^{-}]=2s=3.30\times10^{-6}\ mol/L\quad pH=8.519\ (1\ 分)$
有效数字位数不对，本题共扣0.5分。

2-2 已知 $\varphi^{\circ}[Zn(OH)_{4}^{2-}/Zn]=-1.285\ V\quad\varphi^{\circ}(Zn^{2+}/Zn)=-0.762\ V$，计算 $Zn(OH)_{4}^{2-}$ 的稳定常数 $\beta_{4}$.

用 Nernst 方程或者多重平衡法均可，此处给出多重平衡的方法(过程 1 分，结果 1 分)

$Zn(OH)_{4}^{2-}+2e^{-}\rightarrow Zn+4OH^{-}$ $Zn^{2+}+2e^{-}\rightarrow Zn$

式②-式①即得 $Zn^{2+}+4OH^{-}\rightarrow Zn(OH)_{4}^{2-}$ $\Delta rG_m^{\circ}=-zF\varphi^{\circ}(Zn^{2+}/Zn)-(-zF\varphi^{\circ}[Zn(OH)_{4}^{2-}/Zn])=-100.9\ kJ/mol=-RTln\beta_{4}$

解得 $\beta_{4}=4.81\times10^{17}$

2-3 以下问题均考虑溶液中存在的 $Zn(II)$ 物种只有 $Zn^{2+}$ 和 $Zn(OH)_{4}^{2-}$。

2-3-1 分别导出 $[Zn^{2+}]$ 与 $[OH^{-}]$，$[Zn(OH)_{4}^{2-}]$ 与 $[OH^{-}]$ 的关系式。

联立 $K_{sp}$ 和 $\beta_{4}$ 的式子可知 $[Zn(OH)_{4}^{2-}] = K_{sp}\beta_{4}[OH^{-}]^{2}=8.66[OH^{-}]^{2}\ (1\ \text{分})$ $[Zn^{2+}] = K_{sp}/[OH^{-}]^{2}=1.80\times10^{-17}/[OH^{-}]^{2}\ (1\ \text{分})$

2-3-2 计算 $Zn(OH)_{2}$ 在 pH=9.80 的缓冲溶液中的溶解度 s(mol/L)。

根据 2-3-1 的结果，此时 $[Zn^{2+}] = 4.5\times10^{-9}\ mol/L$ $[Zn(OH)_{4}^{2-}] = 3.4\times10^{-8}\ mol/L$ 故 s=3.9×10⁻⁸ mol/L (1 分)

2-3-3 要使 $Zn(OH)_{2}$ 的溶解度达到 0.010 mol/L 以上，计算缓冲溶液的 pH 应满足什么样的条件？

要使得溶解度达到 0.010 mol/L，要么是 $[Zn^{2+}] = 0.01\ mol/L$，此时 $[Zn(OH)_{4}^{2-}]$ 可以忽略不计，要么是 $[Zn(OH)_{4}^{2-}] = 0.010\ M,\ [Zn^{2+}]$ 忽略不计。两种条件下的 $[OH^{-}]$ 分别为 4.2×10⁻⁸ mol/L 和 0.034 mol/L，故需要满足的条件是 pH≤6.63 (1 分) 或者 pH≥12.53 (1 分)

酸性条件下，$[Zn(OH)_{4}^{2-}] = 1.6\times10^{-14}\ mol/L$

碱性条件下，$[Zn^{2+}] = 1.6\times10^{-14}\ mol/L$ 忽略是合理的 (1 分)

本题也可以直接根据 2-3-1 的结果，令 s=0.010 mol/L 解方程，得到正确的结果，也得满分。

2-3-4 计算 pH 为多少时，$Zn(OH)_{2}$ 的溶解度最低？并求出此时的溶解度。

有 s=1.80×10⁻¹⁷/$[OH^{-}]^{2} + 8.658[OH^{-}]^{2}$

由均值不等式的性质，当 1.80×10⁻¹⁷/$[OH^{-}]^{2} = 8.658[OH^{-}]^{2}$ 时，(1 分)

即 $[OH^{-}] = 3.8\times10^{-5}\ mol/L, pH=9.58$ 时 (1 分)

$s_{min}=2(1.80\times10^{-17}\times8.658)^{1/2}=2.5\times10^{-8}\ (mol/L)\ (1\ \text{分})$
