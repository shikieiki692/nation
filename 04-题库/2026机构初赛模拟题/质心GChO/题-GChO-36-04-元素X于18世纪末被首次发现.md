# 题-GChO-36-04-元素X于18世纪末被首次发现

## 题目

### 第 4 题 (17分)

元素 X 于 18 世纪末被首次发现，其他的背景咱就不介绍了。X 单质可以与氧气在加热的条件下化合得到 A，A 也可以由 B 加热至 $140^{\circ}$ C 得到。X 单质、A 和 B 都可以溶于氢氧化钠溶液得到盐 C。X 单质与氯气的化合需要在 $700^{\circ}$ C 下进行，得到 D，D 与少量的 NaOH 溶液作用得到 B，与适量 $Na_{2}CO_{3}$ 溶液作用得到沉淀 E，E 可以溶于浓的碳酸铵溶液得到 F。D 还可以在 $120^{\circ}$ C 与 $LiBH_{4}$ 发生形式上的复分解反应得到 G，G 与 $PPh_{3}$ 作用则得到固体为一维链状结构的二元化合物 H。

X 单质还可以直接溶于浓的 $NH_{4}F$ 溶液得到 I，灼烧 I 的固体得到 J，在 $1300^{\circ}C$ 下，Mg 可以把 J 还原成 X 单质。

已知 B→A 的转化失重 41.86%，E 为碱式盐。

将 B 于冰醋酸中煮沸，可以得到 $T_{d}$ 对称性的配合物 K，其中 X 元素的质量分数为 8.87%。

4-1 写出物质 A\~K 的化学式。

4-2 写出 G 与 PPh₃ 作用得到 H，B 于冰醋酸中煮沸得到 K 的化学方程式。

4-3 画出 G 和 H 的立体结构，如果有多中心键，请用文字辅助说明。
