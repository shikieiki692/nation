# 题-GChO-66-02-下面的反应都是能够生成PP键

## 题目

### 第 2 题 (12 分) 磷磷键的合成

下面的反应都是能够生成 P-P 键的反应:

2-1 写出下列反应的化学方程式:

2-1-1 $Ph_{2}PF_{3}$ 与 $Ph_{2}PSiMe_{3}$ 在 $150^{\circ}C$ 下反应 4 h，得到两种产物。

2-1-2 $\mathrm{PhPF}_2$ 与 $\mathrm{Ph}_2\mathrm{PSiMe}_3$ 在 $100^{\circ}\mathrm{C}$ 下按1:2的比例反应，产物中有两种含P的物质，其中一种与-1-1中相同，另一种含有一个带有5重轴的五元环。

2-2 t-BuPCl₂ 与(Me₃Si)₂PLi 在 -40 °C 的戊烷中反应，可以得到多种产物。(M(t-Bu) = 57, M(Me₃Si) = 73)

2-2-1 当 t-BuPCl₂ 与 (Me₃Si)₂PLi 按 1:2 反应时，会得到含 P 的产物 X，X 在室温下转化为含有四元环的产物 A 和化合物 B。其中 A 含 P 质量分数为 32.3%，B 含 P 质量分数为 12.4%。写出从 X 到 A 和 B 的化学反应方程式，其中 A 用其结构表示。

2-2-2 X 在 $130^{\circ}$ C 下还会生成含 P 量分别高达 56% 和 62% 的笼状分子 $W_{1}$ 和 $W_{2}$ 。该 $W_{1}$ 和 $W_{2}$ 中不含 Si， $W_{1}$ 分子属 $C_{3}$ 点群， $W_{2}$ 分子属 $C_{3h}$ 点群。画出 $W_{1}$ 和 $W_{2}$ 的结构。

2-2-3 当 t-BuPCl₂ 与(Me₃Si)₂PLi 按 1:1 反应时，会得到含 P 的产物 Y，Y 在室温下转化为 A、B、C、D、E、F（不是一个独立的反应所得）。其中 C 和 A 有着相同的骨架，且为同分异构体；D、E 中不含 Cl，且各存在一个三元环；F 中不含 P。画出 C 的结构。写出从 Y 生成 D 的化学反应方程式。
