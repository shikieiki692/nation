# 题-GChO-61-03-硫化物A具有层形结构可用作锂

## 题目

### 第 3 题 (9 分) 新型锂电池的阴极材料

硫化物 A 具有层形结构，可用作锂电池的阴极材料。将 A 隔绝空气加热至 $1000^{\circ}$ C 得到 B。将 B 与浓盐酸发生非氧化还原反应可得含氯化物 C 的紫色溶液。隔绝空气的条件下将 C 加热至 $500^{\circ}$ C 可以得到 D 和一种重要的化工原料 E，E 曾被用作烟雾剂。将 E 与纯氧反应，得到一种常见的白色颜料 F。C 在一定条件下与氯化铯化合得到 G，G 中氯元素的质量分数为 52.05%。A\~G 中均含有同一种元素 H。

3-1 写出 A\~G 的化学式。

3-2 A 的晶体结构中，S 作六方最密堆积，H 原子填入硫原子形成的八面体空隙，且并非每两层相邻的硫原子密置层之间都有 H 原子。

3-2-1 写出 A 的点阵型式以及硫原子形成的八面体空隙的填隙率。

3-2-2 简要解释为什么 A 可以作为锂电池的阴极材料。(提示: 此种电池阳极为金属锂, 载流子为锂离子)

## 参考答案

硫化物 A 具有层形结构，可用作锂电池的阴极材料。将 A 隔绝空气加热至 $1000^{\circ}$ C 得到 B。将 B 与浓盐酸发生非氧化还原反应可得含氯化物 C 的紫色溶液。隔绝空气的条件下将 C 加热至 $500^{\circ}$ C 可以得到 D 和一种重要的化工原料 E，E 曾被用作烟雾剂。将 E 与纯氧反应，得到一种常见的白色颜料 F。C 在一定条件下与氯化铯化合得到 G，G 中氯元素的质量分数为 52.05%。A\~G 中均含有同一种元素 H。

点阵型式：hP 或者六方 P 或者简单六方 0.5 分
