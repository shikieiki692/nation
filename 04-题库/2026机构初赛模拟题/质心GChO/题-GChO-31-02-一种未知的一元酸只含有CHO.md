# 题-GChO-31-02-一种未知的一元酸只含有CHO

## 题目

### 第 2 题(9分)

一种未知的一元酸只含有 C, H, O 三种元素。燃烧分析表明该物质含有 40.0% 的 C 和 6.7% 的 H。将 0.4283 g 该化合物样品溶于 50 mL 水中，以酚酞为指示剂，用 0.1782 mol/L NaOH 溶液滴定，加入 26.68 mL 碱液后观察到终点。(实验均在室温下进行)

2-1 通过计算推导出该酸的分子式。(形如 $C_{x}H_{y}O_{z}$ 即可)

2-2 在加入 10.00 mL 的 NaOH 溶液时，测得滴定混合物的 pH 为 3.64，计算该酸的 $pK_{a}$ 。

2-3 如果一共加入 30.00 mL NaOH 溶液并测得溶液 pH 值为 x，是否能通过 x 计算出该酸的 $pK_{a}$ ？如果可以，导出 $pK_{a}$ 与 x 的关系；如果不行，计算 x 的值为多少。

2-4 实验测得偏振光通过该酸的溶液时发生了偏转，试画出该酸所有可能的结构。

## 参考答案

一种未知的一元酸只含有 C, H, O 三种元素。燃烧分析表明该物质含有 40.0% 的 C 和 6.7% 的 H。将 0.4283 g 该化合物样品溶于 50 mL 水中，以酚酞为指示剂，用 0.1782 mol/L NaOH 溶液滴定，加入 26.68 mL 碱液后观察到终点。

2-1 通过计算推导出该酸的分子式。(形如 $C_{x}H_{y}O_{z}$ 即可)

2-2 在加入 10.00 mL 的 NaOH 溶液时，测得滴定混合物的 pH 为 3.64，计算该酸的 $pK_{a}$ 。

2-3 如果一共加入 30.00 mL NaOH 溶液并测得溶液 pH 值为 x，是否能通过 x 计算出该酸的 $pK_{a}$ ？如果可以，导出 $pK_{a}$ 与 x 的关系；如果不行，计算 x 的值为多少。

2-4 实验测得偏振光通过该酸的溶液时发生了偏转，试画出该酸所有可能的结构。

$$
2 - 1 M = m / n = m / c (\mathrm{NaOH}) V (\mathrm{NaOH}) = 0.4283 / (0.1782 \times 26.68 \times 10 ^ {- 3}) = 90.09 (\mathrm{g} / \mathrm{mol})
$$

通过元素分析实验知

$$
N (\mathrm{C}): N (\mathrm{H}): N (\mathrm{O}) = 40.0 \% / 12.01: 6.7 \% / 1.008: 53.3 \% / 16.00 = 1: 2: 1 \quad 1 \text {分}
$$

根据摩尔质量，易知分子式为 $C_{3}H_{6}O_{3}$ 1 分

2-2 此时相当于是 10.00 mL 体积碱对应的 NaA 和 16.68 mL 体积碱对应的 HA，1 分

故有 $\mathrm{pH} = \mathrm{pK}_a + \lg \frac{10.00}{16.68}$ 解得 $\mathrm{pK}_a = 3.86$ 1分

2-3 加入 30.00 mL NaOH 时，已远远超过了滴定的化学计量点，此时溶液的 pH 应只由过量的 NaOH 来决定。（在 NaOH 滴定不同强度的酸的时候，滴定突跃的上界和之后的滴定曲线都是相同的），故不能通过 x 计算出酸的 $pK_{a}$ （意思对即可，1 分）

此时 $[OH^{-}] = V_{\text{过量}}(\text{NaOH})c(\text{NaOH})/V_{\text{total}} = (30.00 - 26.68) \times 0.1782 / (50 + 30.00) = 7.4 \times 10^{-3} (\text{mol/L})$ $x = \text{pH} = 14.00 + \lg(7.4 \times 10^{-3}) = 11.87$ 2 分

本小问有效数字 1 位或 2 位均可
