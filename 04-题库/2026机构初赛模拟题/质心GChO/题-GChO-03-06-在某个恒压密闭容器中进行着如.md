# 题-GChO-03-06-在某个恒压密闭容器中进行着如

## 题目

### 第 6 题（10分）

在某个恒压密闭容器中，进行着如下可逆反应：

$$
\mathrm{A} (\mathrm{g}) + \mathrm{B} (\mathrm{g}) \leftrightarrows \mathrm{C} (\mathrm{g})
$$

6-1 已知反应的标准平衡常数 $K^{\ominus}$ 和反应商 Q，如何判断反应进行的方向？(1.5')

6-2 当体系的压力为 1atm 时，向容器中充入 3.0mol A(g)与 2.0mol B(g)，达到平衡时，C 的物质的量为 0.7mol，计算该反应的标准平衡常数 K $^{\ominus}$ 。(3')

6-3 向容器中充入 x mol A(g) 与 x mol B(g)，反应达到平衡时，各组分的物质的量分别为 n(A) = a mol, n(B) = b mol, n(C) = c mol，向完全相同的另一容器中通入一定物质的量的 C，若欲使平衡时与上容器内各组分的物质的量相同，则应通入多少的 C? (1.5')

6-4 若体系的压力变为 2atm，向容器中充入 3.0mol A(g) 与 5.0mol B(g)，计算反应后各组分的物质的量以及此时容器体积与 6-2 中容器体积的比值。(4')

## 参考答案

在某个恒压密闭容器中，进行着如下可逆反应：

 $A(g) + B(g) \rightleftharpoons C(g)$

6-1 已知反应的标准平衡常数  $K^{\ominus}$  和反应商 Q，如何判断反应进行的方向？(1.5')

当标准压力平衡常数大于标准压力反应商，即  $K_{p}^{\ominus} &gt; Q_{p}^{\ominus}$  时，反应正向进行。(0.5')
当标准压力平衡常数等于标准压力反应商，即  $K_{p}^{\ominus} = Q_{p}^{\ominus}$  时，反应达到平衡。(0.5')
当标准压力平衡常数小于标准压力反应商，即  $K_{p}^{\ominus} &lt; Q_{p}^{\ominus}$  时，反应逆向进行。(0.5')

6-2 当体系的压力为 1atm 时，向容器中充入 3.0mol A(g)与 2.0mol B(g)，达到平衡时，C 的物质的量为 0.7mol，计算该反应的标准平衡常数  $K^{\ominus}$ 。(3')

根据反应关系，终态时：
 $n_{A} = 3.0 - 0.7 = 2.3(mol)$ $n_{B} = 2.0 - 0.7 = 1.3(mol)$ $n_{C} = 0.7mol$
n = 4.3mol

故  $p_{A} = p \cdot n_{A}/n = 54.2kPa$ $p_{B} = p \cdot n_{B}/n = 30.6kPa$ $p_{C} = p \cdot n_{C}/n = 16.5kPa$  (1.5')

 $K^{\ominus} = \frac{\left(\frac{p_{C}}{p^{\ominus}}\right)}{\left(\frac{p_{A}}{p^{\ominus}}\right)\left(\frac{p_{B}}{p^{\ominus}}\right)} = \frac{\left(\frac{16.5}{100}\right)}{\left(\frac{54.2}{100}\right) \times \left(\frac{30.6}{100}\right)} = 1.0$  (1.5')

误将总压 p 认为是  $p^{\ominus}$  的，或者将  $p^{\ominus}$  认为是 1atm 的，总共扣 1'。

6-3 向容器中充入 x mol A(g)与 x mol B(g)，反应达到平衡时，各组分的物质的量分别为 n(A) = a mol, n(B) = b mol, n(C) = c mol，向完全相同的另一容器中通入一定物质的量的 C，若欲使平衡时与上容器内各组分的物质的量相同，则应通入多少的 C? (1.5')

应通入 x mol 的 C (1.5')

6-4 若体系的压力变为 2atm，向容器中充入 3.0mol A(g)与 5.0mol B(g)，计算反应后各组分的物质的量以及此时容器体积与 6-2 中容器体积的比值。(4')

假设生成了 x mol 的 C，则
 $n_{A} = (3.0 - x) \, \text{mol}$ $n_{B} = (5.0 - x) \, \text{mol}$ $n_{C} = x \, \text{mol}$ $n = (8.0 - x) \, \text{mol}$
故  $p_{A} = p \cdot n_{A}/n = \frac{3.0 - x}{8.0 - x} \times 2 \times 101.325 \, \text{kPa}$ $p_{B} = p \cdot n_{B}/n = \frac{5.0 - x}{8.0 - x} \times 2 \times 101.325 \, \text{kPa}$ $p_{C} = p \cdot n_{C}/n = \frac{x}{8.0 - x} \times 2 \times 101.325 \, \text{kPa} (0.5')$
又
 $K^{\Theta} = \frac{\left(\frac{p_{C}}{p^{\Theta}}\right)}{\left(\frac{p_{A}}{p^{\Theta}}\right)\left(\frac{p_{B}}{p^{\Theta}}\right)} = \frac{\frac{\frac{x}{8.0 - x} \times 2 \times 101.325}{100}}{\left(\frac{\frac{3.0 - x}{8.0 - x} \times 2 \times 101.325}{100}\right) \times \left(\frac{\frac{5.0 - x}{8.0 - x} \times 2 \times 101.325}{100}\right)} = 1.0 (1')$
解得 x = 1.56 (1')
故由
 $\frac{V_{2}}{V_{1}} = \frac{n_{2}/p_{2}}{n_{1}/p_{1}} (1')$ $= \frac{\frac{8.0 - 1.56}{2}}{4.3} = 0.75 (0.5')$
误将总压 p 认为是  $2p^{\Theta}$  的，或者将  $p^{\Theta}$  认为是 1atm 的，总共扣 1'。
