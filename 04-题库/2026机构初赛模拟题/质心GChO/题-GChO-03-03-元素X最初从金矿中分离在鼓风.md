# 题-GChO-03-03-元素X最初从金矿中分离在鼓风

## 题目

### 第 3 题 (15分)

元素 X 最初从金矿中分离。在鼓风熔炼铅产生的烟尘中，富集了一部分 X 元素。将烟尘在 110-140℃ 进行硫酸化焙烧后用水浸取，浸取液用 ZnO 中和至 pH=4，析出了含 X 元素的沉淀 A, A 用 NaOH 溶液处理后用锌粉还原后，可以得到更为富集的含 X 单质 6\~20% 的精矿。用过量的多硫化钠溶液浸取此矿，可以使 X 元素转化为 B 而溶解，再向溶液中加入过量的亚硫酸钠溶液，又可以析出 X 单质。用甘汞在 550℃ 下处理 X 单质得到白色化合物 C, C 在凝聚态时为离子型化合物，这使得 C 可以和 TiCl₄、SO₃ 等 Lewis 酸发生加合反应得到离子型加合物 D 和 E。C 与 A 中 X 的氧化态相同，1 摩尔 C 可以和 11 摩尔 A 化合得到 2 摩尔的复杂的化合物 F，该化合物中 X 元素的质量分数为 75.6%。
