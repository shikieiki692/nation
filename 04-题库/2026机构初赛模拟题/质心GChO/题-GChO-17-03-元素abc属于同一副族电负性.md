# 题-GChO-17-03-元素abc属于同一副族电负性

## 题目

### 第 3 题 (12分)

元素 a, b, c 属于同一副族，电负性 a < b < c。已知 a 的某常见氧化物是容量分析的常见基准试剂之一，向 a 的氯化物溶液中通入 $H_{2}S$ ，生成沉淀 A，但 a 的氯化物溶液与 $Na_{2}S_{2}O_{3}$ 按 1:2 反应可以得到沉淀 B 与连硫酸盐。

3-1 写出 a, b, c 的元素符号，并写出 A, B 的化学式。

3-2 元素 b 的检出常用联吡啶-碘化亚铁法，将少量溶液滴在点滴板上，加一滴 bipy（联二吡啶），KI 与 $FeSO_{4}$ 的混合溶液，若存在 b 的离子，则出现红色斑点 C，C 实际上为一种 NaCl 型离子化合物，阴阳离子均为配离子。乙基格式试剂与 b 的氯化物反应得到化合物 D，D 在常温下稳定，但在光照下会部分分解，D 可以与苯甲酰氯反应而生成 E。同时，b 的乙酸盐可以与 $\mathrm{Fe(CO)}_{4}$ 发生有趣的反应。在低温下， $\mathrm{Fe(CO)}_{5}$ 与 $NH_{3}$ ，b 的乙酸盐反应，生成某配合物 F，F 中存在 2 个 $NH_{3}$ 配体，将 F 在真空中加热至 $60^{\circ}C$ ，则生成 $\mathrm{bFe(CO)}_{4}$ ，已知 $\mathrm{bFe(CO)}_{4}$ 存在多种多聚体，一个典型的多聚体为四聚体，存在八元环。

3-2-1 分别写出 C, D, E 的化学式，以及生成 F 的反应方程式。

3-2-2 画出 bFe(CO) $_{4}$ 四聚体的结构简式。

3-3 c 的硫化物在水中的溶解度非常差，请举出两例能够溶解其硫化物的体系。
