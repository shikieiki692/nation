# 题-GChO-64-03-X是一种常见的金属元素虽然其

## 题目

### 第 3 题 (11分)

X 是一种常见的金属元素，虽然其在地壳中的储量比较丰富，但由于其熔炼需要在真空或惰性气体保护下进行，所以 X 元素的制品价格通常比较昂贵。元素 X 在自然界中的最主要存在形式是其一系列非整比氧化物，其中 X 的质量分数为 58.44%\~60.98%。将元素 X 的粉末单质 A 在空气中加热，会发生燃烧并最终得到黄色粉末，其中含有一种化合物 B，纯化后的 B 是一种暗金色粉末，可以用于在切削工具表面形成耐磨镀层。

![](images/62cd18bc014cd6f5806f01b9ade25e34d3026ba575a5f4025a1bc19b5787d25a.jpg)

3-1 写出 B 的化学式，以及元素 X 的最常见整比氧化物 C 的化学式及其两种常见晶型。

3-2 人们最早希望通过高温下用焦炭还原 C 来制备 A，但最终失败了，请用反应方程式来解释这种方法失败的原因。如果利用 $CaH_{2}$ 替代焦炭作为还原剂，则可以很好的获得 A 单质，写出该反应的化学方程式。

3-3 元素 X 的一种氯化物 D 是无色发烟液体，工业上获取 A 的一种方式是用镁来还原 D 并进一步加工，写出该反应的方程式，并说明为何不采用直接电解 D 的方式来获取 A。

3-4 研究人员通过下述方式合成了含有元素 X 的中心对称配合物 E，元素分析表明其中 X 的质量分数为 10.34%，请推断 E 的化学式并画出 E 的结构，已知配合物中 X 的配位数为 6，多齿配体可以尝试简化表示。
