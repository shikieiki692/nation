# 题-GChO-06-03-无机酸A酸性和醋酸相当和醋酸

## 题目

### 第 3 题 (12分)

无机酸 A 酸性和醋酸相当，和醋酸不同的是，A 在溶解金属 Zn 时得到的不是氢气，而是气体 B 和 C。B 和 C 都可以作为配体和金属配位，且提供配位的原子 X 相同。已知通常情况下，常见的过渡金属 M 与 B 形成的配合物中的 M-X 长度要大于与 C 形成的配合物中 M-X 的长度。酸 A 的阴离子 D 也是常见配体，现有一 Co(III) 的配合物，阳离子部分为 E，其中 Co 的质量分数为 31.66%，与 Co 配位的配体只有 B 和 D。E 具有一定的还原性，和亚硝酸以 1:1 的摩尔比反应的产物之一是 C，若将 E 的弱酸性溶液用 253.7nm 的光照射，则发生内部的氧化-还原反应得到 C，同时得到全水合的 Co 物种。

## 3- 1 请写出 A、B、C、E 的化学式

3-2 解释为什么过渡金属 M 与 B 形成的配合物中的 M-X 长度要大于金属与 C 形成的配合物中 M-X 的长度。

3-3 写出 A 与 Zn 反应、E 被亚硝酸氧化、E 被光照三个反应的方程式。
