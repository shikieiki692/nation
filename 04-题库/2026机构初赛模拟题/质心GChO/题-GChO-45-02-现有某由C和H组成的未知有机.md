# 题-GChO-45-02-现有某由C和H组成的未知有机

## 题目

### 第 2 题 (11分)

现有某由 C 和 H 组成的未知有机化合物 X，为了确定 X 的结构，进行如下实验：

(1) 取 $10.8 \, g \, X$ ，在 $O_{2}$ 中充分燃烧，产物通过 CaO 充分吸收，测得 CaO 增重 $46.0 \, g$ 。

(2) 通过旋光仪测得 X 具有手性。

(3) 将 X 加入 $Br_{2}$ 的 $CCl_{4}$ 溶液，溶液褪色。

(4) X 用 $\mathrm{Na} / \mathrm{NH}_{3}(1)$ 还原, 的到化合物 A, A 没有手性。

(5) X 用 Pd/PbO, $CaCO_{3}$ 催化和 $H_{2}$ 反应, 得到化合物 B, B 具有手性。

(6) X 用 Pt 催化和足量 $H_{2}$ 反应，得到化合物 C，C 没有手性。

(7) A 和 B 分别用 Pt 催化和足量 $H_{2}$ 反应，都得到 C。

(8) 10.8 g X 用 Pt 催化和足量 $H_{2}$ 反应后，所得的 C(假定产率为 100%) 在 $O_{2}$ 中完全燃烧，产生的气体通过 CaO 充分吸收，测得 CaO 增重 51.4 g。

2-1 写出过程(1)中 CaO 参与的化学反应方程式。

2-2 在用 Pt 进行催化加氢时，发现换用 $PtO_{2}$ 也能顺利反应。请解释为什么 $PtO_{2}$ 也能使催化加氢正常进行。

2-3 分别计算 X 和 C 的化学式，注意分别明确表示计算过程。如果能确定分子式，则表示分子式，不能确定写出最简式即可。

2-4 写出 X 和 A \~ C 的结构，如果有双键，注意标明顺反。
