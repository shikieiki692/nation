# 题-GChO-65-02-21由复分解反应制备过渡金属

## 题目

### 第 2 题 (10分) 溶液中的离子平衡

2-1 由复分解反应制备过渡金属难溶盐时，时常因金属离子的水解而导致得不到预期的产物。在无氧条件下，向 $0.10\mathrm{mol / LNaHCO_3}$ 溶液中滴入少量硫酸锰溶液，生成白色沉淀。已知 $25^{\circ}\mathrm{C}$ 时碳酸的 $K_{\mathrm{a1}} = 4.2\times 10^{-7}$ ， $K_{\mathrm{a2}} = 5.6\times 10^{-11}$ ，假设沉淀可以互相转化，通过计算说明，最终的沉淀为碳酸锰 $(K_{\mathrm{sp}} = 8.8\times 10^{-11})$ 还是氢氧化锰 $(K_{\mathrm{sp}} = 4.0\times 10^{-14})$ 。

2-2 EDTA 是一种广谱的配体，常用于各种金属离子浓度的定量分析。根据不同金属离子与 EDTA 配位能力的不同，有时可以实现在同一溶液中连续滴定多种不同的金属离子。现有一含有 $Bi^{3+}$ 与 $Pb^{2+}$ 的混合溶液 25.00 mL，其中 $Bi^{3+}$ 与 $Pb^{2+}$ 的浓度均为 0.02000 mol/L。向溶液中加入 25.00 mL 0.02000 mol/L EDTA 二钠盐溶液，反应达到平衡时，假设溶液 pH 值为 1.0，忽略金属离子的水解，计算溶液中 PbY 的平衡浓度。（EDTA 为一种六元酸，其与金属离子发生配位的形体为其六个氢全部电离的形式，用 Y 表示。已知 EDTA 的 $pK_{a1}$ 至 $pK_{a6}$ 分别为 0.9, 1.6, 2.0, 2.67, 6.16 和 10.26，两离子与 EDTA 形成的配合物的稳定常数分别为 $K_{BiY} = 10^{27.94}$ ， $K_{PbY} = 10^{18.04}$ ）
