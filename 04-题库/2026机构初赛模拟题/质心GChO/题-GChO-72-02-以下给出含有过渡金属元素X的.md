# 题-GChO-72-02-以下给出含有过渡金属元素X的

## 题目

### 第 2 题（22分，占 $11\%$ ）过渡金属元素 $\mathbf{X}$ 的化合物推断

以下给出含有过渡金属元素 X 的若干化合物的合成方法。

(I)在冰水浴的条件下，将研磨成粉的 2 g A 和 3.5 g 研磨成粉状的七水亚硫酸钠放入装有 50 mL 28% 的氢氧化钠溶液的锥形瓶中搅拌(反应 1)。大约十分钟后，得到一种浅蓝色结晶的浆状物。将生成物在 0 ℃ 下置于冷却的玻璃过滤器中，用 28% 的氢氧化钠溶液充分洗涤。把得到的湿产品迅速在新鲜的粘土上摊开成薄层，然后放在处于 0 ℃ 的真空干燥器中。这样处理是为了避免硅酸盐和铝酸盐的污染。得到的产物 B 是天蓝色棒状结晶，在 0 ℃ 以及没有水和二氧化碳的环境下保持稳定。将 B 溶于 50% 的氢氧化钠溶液中，加热或稀释该溶液都将变成草绿色，同时生成 C(反应 2)。

(II)纯净物盐 D 是 B 的主要成分，可以由以下过程制备：将氢氧化钠固体置于银坩埚，在 $400^{\circ}$ C 下完全脱水后，按照 $n(\mathrm{Na}):n(\mathbf{X})=3:1$ 的比例与 C 混合。混合物置于银坩埚中在氧气流下加热到 $800^{\circ}$ C，并保持 5 h(反应 3)。将得到的产物 D 迅速冷却到室温。盐 D 是深绿色化合物且不与二氧化碳反应。

(III)将 30 g 氢氧化钾溶于 50 mL 水中配成溶液，与 10 g A 一同放在 250 mL 敞口锥形瓶中煮沸，直至得到纯绿色的溶液(反应 4)。蒸发溶液的水，然后在冰水浴中冷却，析出墨绿色略带紫色的晶体。将其放在硼硅玻璃过滤器上，先用 $1 \, mol \cdot L^{-1}$ 的氢氧化钾溶液洗涤，再用五氧化二磷干燥。得到的产物 E 可以在稀的氢氧化钾溶液中重结晶，还可以在真空中升华。

2-1 利用下列信息确定元素 X 和 A-E 的化学式。

(a) 钠元素在 B 中的质量分数为 18.1%。

(b) 元素 X 在 A、B、C、D、E 中的质量分数依次为 34.8%、13.3%、63.2%、29.3%、27.9%。

2-2 写出反应 1\~反应 4。
