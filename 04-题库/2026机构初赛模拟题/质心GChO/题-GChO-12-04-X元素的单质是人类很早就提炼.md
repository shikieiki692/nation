# 题-GChO-12-04-X元素的单质是人类很早就提炼

## 题目

### 第 4 题（13分）

X 元素的单质是人类很早就提炼出来的一种金属。下列的 A\~K 均为含 X 的化合物。

X 的单质与适量 $F_{2}$ 反应可以得到化合物 A， $F_{2}$ 过量则会得到化合物 B。A 与 $P_{2}S_{5}$ 在约 $170^{\circ}C$ 作用反应可以得到化合物 C，C 是 X 最重要的产出矿石的主要成分。B 与浓硫酸反应，可以得到氧化性极强的黄色晶体 D，将 D 的浓硫酸溶液加热至 $100^{\circ}C$ ，可分解得到稳定的 E，E 是常见的蓄电池电极材料。

X 的单质与不同量的 $Cl_{2}$ 反应均只能得到化合物 F，F 微溶于水。将 F 的饱和溶液与 $Na_{2}CO_{3}$ 反应得到沉淀 G，G 中 X 的质量分数为 76.0%。在 0 ℃ 下将 $Cl_{2}$ 通入 F 于浓盐酸的悬浮液中，并加入 $NH_{4}Cl$ 固体，可以得到黄色晶体 H，H 可与浓硫酸在 0 ℃ 反应可以得到黄色油状液体 I，I 在室温时即可分解成 F 和 $Cl_{2}$ 。将 I 溶于 $CCl_{4}$ ，并通入 $Cl_{2}O$ ，可以得到 J，J 遇水则会得到 K，K 是一种强氧化剂。
