# 题-GChO-33-03-2012年有科学家合成了一种

## 题目

### 第 3 题 (17分)

2012 年，有科学家合成了一种化学式为 $XYO_{4}$ 的单晶，有望用于检测无中微子产生的 $\beta$ 衰变。现将 192 mg 的金属 Y 在加热的条件下与 30% 的 $HNO_{3}$ 作用，得到 Y 的水合氧化物 $YO_{x}\cdot H_{2}O$ ，并释放出 89.6 mL 的无色气体 (0 °C, 1 atm)。将 $YO_{x}\cdot H_{2}O$ 干燥至恒重，得到 0.288 g 固体，在 650 °C 时用氢气还原所得的 $YO_{x}$ ，得到 0.256 g 的氧化物 A。

3-1 通过计算和讨论，推测 Y 的元素符号和 Y 原子的基态核外电子排布。

3-2 写出氧化物 A 的化学式。

3-3 现将 $\alpha,\beta,\gamma$ 三种射线沿纸面方向通过垂直于纸面方向的匀强磁场，观察到结果如下：

![](images/acf8214d4677c1fcafcb1b06e2770208c71981b511b18ab63da27dbc09a675d0.jpg)

请指认 1,2,3 分别代表什么射线，并指出匀强磁场的方向是垂直于纸面向外还是向里。3-4 X 单质是一种较软的金属，可以溶于酸、碱和浓氨水。已知 $1 \, mol \, XYO_{4}$ 晶体中含有 $6.26 \times 10^{25}$ 个电子，给出 X 的元素符号，并写出其溶于浓氨水的方程式。

## 第1页/共5页

3-5 以下是一些金属 Y 相关的转化:

$$
\begin{array}{c} \text { B } \xleftarrow [ 750 ^ {\circ} \mathrm{C} ]{\mathrm{COCl} _ {2}} \text { Y } \xrightarrow [ \text { C } ]{\mathrm{Cl} _ {2} , 100 ^ {\circ} \mathrm{C}} \text { C } \xrightarrow [ 500 ^ {\circ} \mathrm{C} ]{\mathrm{H} _ {2} \mathrm{S}} \text { D } \xrightarrow [ 400 \sim 600 ^ {\circ} \mathrm{C} ]{\mathrm{O} _ {2}} \text { YO} _ {\mathrm{x}} \xrightarrow [ \text { E } ]{\text { NaOH }} \\ \Bigg \downarrow \text { CO,   Al,   100 } ^ {\circ} \text { C,   pressure } \\ \text { F } \xrightarrow [ \text { I } _ {2} ]{} \text { G } \end{array}
$$

除 E 和 F 外都是二元化合物。其中，B 中 Y 的氧化态为 +2，其中的阳离子是含有 Y 八面体骨架的 cluster，属于 $O_{h}$ 点群。C 为两个八面体共棱连接的双核物质。D 的触感油腻，与其层状结构有关。G 中 Y 的质量分数为 20.13%

3-5-1 试给出 B\~G 的化学式。B 的正负离子需分开写。

3-5-2 写出 $C \rightarrow D$ ， $C \rightarrow F$ 的化学方程式。
