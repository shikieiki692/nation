# 题-GChO-48-01-11硫与在液态中反应可以得到

## 题目

### 第 1 题 (12分)

1-1 硫与 $AsF_{5}$ 在液态 $SO_{2}$ 中反应，可以得到阴阳离子为 2:1 的配合物。

1-2 $\mathrm{SeCl}_2$ 与 $\mathrm{Ph}_3\mathrm{PSe}$ 反应则能得到与正交硫结构相同的分子。

1-3 Br₂ 与臭氧反应得到橙色的溴的氧化物，进一步反应则颜色消失。

1-4 高压下可将 $N_{2}$ 压入 Sr 固体中，得到 SrN，但此时的 N 有两种形态，其中一种为 $O_{2}$ 的等电子体。写出 SrN 的离子形式。

1-5 Cs 可以与 $P_{2}H_{4}$ 反应得到物质的量比为 1:8 的具有芳香性的阴离子和另一种盐，并产生无色无味的气体。

1-6 $\mathrm{SbCl}_3$ 可在 $\mathrm{GaCl}_3$ 的苯溶液中被 $\mathrm{GaCl}_2$ 还原，产物为阴阳离子2:1的盐，且阳离子中具有四方反棱柱的结构。化学方程式中需正确写出 $\mathrm{GaCl}_2$ 的形式。

## 参考答案



**1-1** 硫与 AsF5 在液态 SO2 中反应,可以得到阴阳离子为 2:1 的配合物。

2 分 S8 + 3AsF5 → [S8][AsF6]2 + AsF3

**1-2** SeCl2 与 Ph3PSe 反应则能得到与正交硫结构相同的分子。

2 分 4SeCl2 + 4Ph3PSe → Se8 + 4Ph3PCl2

**1-3** Br2 与臭氧反应得到橙色的溴的氧化物,进一步反应则颜色消失。

1 分 2Br2 + 3O3 → 2Br2O3 + 2O2 写成 BrO2 也行 Br2 + 4O3 → 2BrO2 + 4O21 分 Br2O3 + 2O3 → Br2O5 + 2O22BrO2 + O3 → Br2O5 + O2

**1-4** 高压下可将 N2 压入 Sr 固体中,得到 SrN,但此时的 N 有两种形态,其中一种为 O2 的等电子体。写出 SrN 的离子形式。

2 分 (Sr2+)4(N3-)2(N22-)

**1-5** Cs 可以与 P2H4 反应得到物质的量比为 1:8 的具有芳香性的阴离子和另一种盐,并产生无色无味的气体。

2 分 6P2H4 + 10Cs → Cs2P4 + 8CsPH2 + 4H2

**1-6** SbCl3 可在 GaCl3 的苯溶液中被 GaCl2 还原,产物为阴阳离子 2:1 的盐,且阳离子中具有四方反棱柱的结构。化学方程式中需正确写出 GaCl2 的形式。

2 分 8SbCl3 + 11Ga+GaCl4 → Sb82+[GaCl4-]2 + 20GaCl3
