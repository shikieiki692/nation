# 题-GChO-27-05-元素X是生命必要的非金属元素

## 题目

### 第 5 题 (11 分)

元素 X 是生命必要的非金属元素之一。其单质 A 与 $Cl_{2}$ 按 2:1 反应得到结构类似于 $H_{2}O_{2}$ 的化合物 B，B 会水解歧化分解为 A 与 C，B 与 $O_{3}$ 反应则可以得到 C 和 D。单质 A 与 CIF 作用可得到 E，C、D、E 中 X 的氧化态都相同，都是二元化合物，且 C 在化学反应中主要体现氧化性。E 与 X 的最高价氧化物 F 1:1 地作用可以 1:1 地得到 G 和 H，G 和 H 都是三元化合物，其中 G 也可以通过 F 的水化物 I 与氟磺酸作用而来，I 是强酸。

5-1 写出 B\~I 的化学式。

5-2 完善下列反应方程式:

(1) $\mathbf{B} + \mathrm{O}_3\rightarrow \mathbf{C} + \mathbf{D}$

(2) $B + BCl_{3}$ 在低温下作用。

(3) $\mathbf{I}\rightarrow \mathbf{G}$
