# 题-GChO-29-05-X是一种贵金属元素其单质A与

## 题目

### 第 5 题 (13分)

X 是一种贵金属元素. 其单质 A 与 $Cl_{2}$ 在高温下化合得到化合物 B, B 与 CO 按 1:2 的化学计量比在 $120^{\circ}C$ 下反应可以得到等比例的 C 与另一种气体 D. C 又能受热分解, 得到含有 X 的 E 和 CO, E 易被水分解为 A 和 B. 将 B 用液氨处理, 得到的沉淀溶于 KCN 得到 F, F 中存在反磁性的直线型阴离子.

## 第2页/共6页

5-1 写出 C\~F 的化学式

5-2 B 的实际存在形式是它的二聚体, 画出其立体结构.

5-3 将 B 在盐酸中转化为 G, G 与 $Na_{2}CO_{3}$ 作用, 得到气体和褐色沉淀, 写出此反应的化学方程式.

5-4 B 与 $PH_{3}$ 在无水乙醚中反应可以得到褐色沉淀 H, 写出 H 在空气中完全燃烧的化学方程式.

5-5 B 与格氏试剂 $C_{2}H_{5}MgCl$ 反应可以得到 I, I 与 AgCN 进一步作用得到 J. I 和 J 分别含有 2 个和 4 个 X 原子. 画出 I 和 J 的立体结构.
