## 题目

### 第 9 题 (8分)

α,β-不饱和羰基化合物是有机化学中非常重要的官能团，具有丰富的化学反应性。通常 α,β-不饱和羰基化合物都是以 β 位作为亲电试剂参与反应，但在一些条件下，其 α 位也可以和亲电或者亲核试剂才参与反应。

α,β-不饱和羰基化合物 1 可以在醋酸碘苯和对甲苯磺酸吡啶盐的作用下反应产生中间产物 B，然后 B 在三乙胺存在下可以得到最终产物 C。

$$
\mathrm{Me} \xrightarrow {\text {   1   }} \frac {\mathrm{PhI} (\mathrm{OAc}) _ {2} (3.0 \text { eq. })}{\mathrm{TsO} ^ {-} \mathrm{pyH} ^ {+} (3.5 \text { eq. })} \xrightarrow [ \mathrm{MeCN} , \mathrm{rt} , 14 \mathrm{h} ]{\text {   PhI } (\mathrm{OAc}) _ {2} (3.0 \text { eq. })} \left[ \begin{array}{c} \mathrm{B} \\ \end{array} \right] \xrightarrow [ \mathrm{rt} , 2 \mathrm{h} ]{\mathrm{Et} _ {3} \mathrm{N} (4.5 \text { eq. })} \mathrm{C}
$$

化合物 C 的核磁共振数据如下：

$^{1}$ H NMR (400 MHz, CDCl $_{3}$ ) δ 7.73 (2H), 7.61 (2H), 7.25 (2H), 7.19 (2H), 5.77 (1H), 5.74 (1H), 3.39 (3H), 3.38 (3H);

$^{13}$ C NMR (101 MHz, CDCl $_{3}$ ) δ 188.3, 149.9, 145.7, 144.3, 133.1, 132.7, 129.9, 129.8, 129.3, 128.7, 117.5, 21.87, 21.86;

9-1 请画出 B 和 C 的结构。

9-2 请画出产生 B 的过程中的重要的反应中间体。
