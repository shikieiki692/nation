## 题目

### 第 4 题 具有特殊光学性质的三元晶体(占 10%)

具有特殊光学性质的晶体一直是无机材料领域研究的热门话题。近日，某研究小组通过真空封管法合成出了一种具有独特性质的三元晶体 X。

4-1 晶体 X 的合成方法如下：按照化学计量比精确称量单质 A，B，C，均匀混合后封入真空石英管，将密封好的石英管放入马弗炉中进行升温，体系在 $450^{\circ}$ C 下进行保温一段时间，随后继续升温至 $800 \sim 1000^{\circ}$ C 使反应进行完全，此时已形成均匀的晶相，最终通过缓慢冷却降温，即可从熔体中得到较大的块状单晶。（补充说明：单质 A 在常温下不挥发，但其沸点在所有元素单质中较低。）4-1-1 在本反应中，真空石英封管的作用是什么，请答出两点。

4-1-2 为何合成时先进行保温然后再进行升温？

4-2 该晶体的晶胞结构如下，我们可以通过将晶胞分成 3 部分来逐步了解该晶体的结构，即： $AC_{6}$ 八面体， $BA_{3}$ 三角锥以及由 C 组成的多面体三维框架。但需要注意的是，组成八面体的 C 原子为统计分布，其占据率为 2/3。

4-2-1 写出以 A, B, C 表示的该晶体的化学式。

4-2-2 判断该晶体的点阵形式，结构基元。

4-2-3 指出该晶体的特征对称元素以及最高次轴。

4-3 该科研团队对合成晶体的机理进行了合理推测，可以认为该晶体是由较小的分子碎片不断加和成簇，最终整齐排列并掺入 C 原子形成的，请在以下机理中画出每个方块所对应的物质，如有结构也需示出，方括号内仅写出化学式即可。（补充说明：本小问中无需考虑 C 原子的统计分布）

![](images/acf8f5db3eb0e96439e306761ef1b445a5f7f3016ad0a80de772a32befaaeb3a.jpg)

4-4 该晶体的独特之处即在于不对称的 $\mathsf{BA}_3^{2-}$ 三角锥结构存在一对能量较高、空间分布较为弥散的孤对电子，当受到外界光电场作用时，该孤对电子的电子云更容易被扰动和发生畸变，从而产生强大的微观非线性光学响应。此外，产生二阶非线性光学效应（如倍频效应）的前提要求晶体结构必须非中心对称，如果对 $\mathsf{BA}_3^{2-}$ 三角锥结构进行如下调整后（所处位置不变），以下哪种晶体仍然有可能产生二阶非线性光学效应？

a. $\mathsf{BA}_4$ 正四面体 b. $\mathsf{BA}_6$ 三方反棱柱 c. $\mathsf{BA}_3$ 平面正三角形 d. $\mathsf{BA}_6$ 四角双锥

4-5 已知 A 和 B 处于同主族但不相邻，在合成反应中，B 与 C 的质量比接近 4:5，写出晶体 X 的化学式，判断每个元素的化合价。
