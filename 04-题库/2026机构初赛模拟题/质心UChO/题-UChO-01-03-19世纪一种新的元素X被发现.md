# 题-UChO-01-03-19世纪一种新的元素X被发现

## 题目

### 第 3 题 (11分)

19 世纪一种新的元素 X 被发现。将草酸钠加入 X 的氯化物溶液，形成不溶性物质 A。在低于 $100^{\circ}$ C 的时候，A 热分解生成 B，质量亏损大约为 20%。在加热到 $400^{\circ}$ C 以上，得到了白色不溶性氧化物 C。C 和 NaF 在浓盐酸中反应会生成沉淀 D，D 与 Ca 反应可以得到纯的单质 X。沉淀 D 与过量的 NaF 可以生成络合物 E。X 可以与卤素形成各种各样的簇合物。在 F，G，H，I 中，X 的比例依次增加。F 可以通过将 X 的氯化物与 X 的单质按 4:3 的比例反应制得。持续加热 F 可以生成 I，质量损失为 23.95%。F 和 H 共混可以反应生成 G。从 F 到 G 的变化中 X 的氧化态改变了 6.67%，从 H 到 G 的变化中 X 的氧化态改变了 12%。F 和 H 中的金属原子数是相同的。

3-1 请写出 A-I 的化学式。

3-2 F 近似属于 $O_{h}$ 点群，请画出 F 的结构。
