# 题-UChO-02-01-在一定配位环境下的金属离子可

## 题目

### 第 1 题 (14分)

在一定配位环境下的金属离子可以通过“质子耦合电子转移”的方式来促进金属离子的氧化还原，而质子和电子的转移既可以是协同的，也可以是分步的。以下图中的化学物质（A）作为原料（配体为TAML， $M = 370\mathrm{g / mol}$ ，题中画结构时可以只写出配位原子和连接线），使其在甲醇溶液中与 $\mathrm{NH_4Cl}$ 和 $\mathrm{NaClO}$ 反应，将得到的固体重新溶解，加入 $\mathrm{PPh_4Cl}$ ，并用 $\mathrm{CH}_3\mathrm{CN}/$ 二乙醚重结晶，可以得到橙色晶体B。

![](images/c2de87a137e385639cc753127409a989e60e71f21aa1bc3bd3b7b69a6ea95ba0.jpg)

1-1 橙色晶体 B 为阴阳离子 1:2 的离子型配合物，质谱显示有两个明显的 m/z 分别为 219.7 和 778.7 的峰。

1-1-1 画出 B 的结构，标出 Mn 的价态。

1-1-2 写出 m/z 为 219.7 和 778.7 的峰各对应的物质的化学式。

1-1-3 画出 B 中 Mn 的晶体场轨道及其电子排布（以配体平面为 xy 平面，标注各 d 轨道名称）。

1-2 将 B 溶于 $CH_{2}Cl_{2}$ ，加入等物质的量的 $[Cp_{2}Fe][BAr^{F}_{4}]$ ，得到深棕色溶液，加入乙醚析出棕色针状晶体 C。C 的质谱峰为 439.5，在对 B 测试质谱时也有少量出现。画出 C 的结构，标出 Mn 的价态。

1-3 C 可与 $PPh_{3}$ 发生反应，生成中间产物 D，D 则发生质子耦合电子转移过程得到 A。画出 D 和另一个最终产物的结构，标出 Mn 的价态。

1-4 C 可以与苯乙烯发生反应，生产中间产物 E，E 具有三元环的结构。

1-4-1 E 在发生质子耦合电子转移过程时有氧气参与进来，得到了与 C 结构类似的 F。画出 E、F 和另一个最终产物的结构，标出 Mn 的价态。

1-4-2 若苯乙烯的 4 号 C 上存在电子效应明显的取代基时，则会得到链状中间体，而不是三元环。且吸电子取代基（以 X 表示）和给电子取代基（以 Y 表示）将会得到不同的中间体。画出这两种中间体的结构，标出 Mn 的价态（C 只需画出配位中心与反应相关的原子）。
