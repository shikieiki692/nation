# 题-光度-04：最佳吸光度范围选择

## 题目

某有色溶液在 $\lambda = 520\ \text{nm}$、$1.0\ \text{cm}$ 比色皿中测得透光度 $T = 50.0\%$。

(1) 求吸光度 $A$；
(2) 该透光度是否处于最佳测量范围（$A = 0.2\sim0.8$）内？
(3) 若要使测量相对误差最小，应把溶液浓度（或比色皿厚度）调节到什么程度？此时 $T$ 约为多少？（已知透光度读数误差最小点 $A = 0.434$）

## 参考答案

**(1)** $A = -\lg T = -\lg 0.500 = 0.301$

**(2)** $A = 0.301 \in [0.2, 0.8]$，处于最佳测量范围内。对应 $T$ 范围：$A=0.2 \Rightarrow T=63.1\%$，$A=0.8 \Rightarrow T=15.8\%$，即 $T$ 落在 $16\%\sim63\%$ 之间为宜。

**(3)** 最小相对误差点 $A = 0.434$，此时：

$$T = 10^{-0.434} = 0.368 = 36.8\%$$

可通过稀释、改变取样量或调整比色皿厚度，使透光度落在 $36.8\%$ 附近（即 $A$ 约 $0.4\sim0.5$）。

**答案**：(1) $0.301$；(2) 在范围内；(3) $A = 0.434$，$T \approx 36.8\%$。

## 知识点映射

- 核心考点：$A$-$T$ 对数换算、最佳测量范围、最小读数误差点
- 关键公式：$A = -\lg T$，$T = 10^{-A}$
- 易错点：$A$ 与 $T$ 非反比；最小误差点 $A = 0.434$（$T = 36.8\%$）而非 $A = 0.5$
