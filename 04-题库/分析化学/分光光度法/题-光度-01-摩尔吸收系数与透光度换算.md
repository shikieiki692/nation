# 题-光度-01：摩尔吸收系数与透光度换算

## 题目

某有色配合物溶液浓度为 $2.5\times10^{-5}$ mol/L，在 1 cm 吸收池中于 $\lambda_{\max}$ 处测得吸光度 $A = 0.750$，已知该物质摩尔吸收系数 $\varepsilon = 3.0\times10^{4}$ L·mol⁻¹·cm⁻¹。计算：

(1) 透光度 $T$（以百分数表示）；
(2) 改用 2 cm 吸收池测定时，吸光度与透光度各为多少？此时是否在最佳测量范围（$A = 0.2\sim0.8$）内？
(3) 该物质的桑德尔灵敏度 $S$（$M = 55.85$ g/mol）。

## 参考答案

**(1)** 由 $A = -\lg T$：

$$T = 10^{-A} = 10^{-0.750} = 0.178 = 17.8\%$$

**(2)** $b = 2$ cm 时：

$$A = \varepsilon b c = 3.0\times10^{4} \times 2 \times 2.5\times10^{-5} = 1.50$$

$$T = 10^{-1.50} = 0.0316 = 3.16\%$$

$A = 1.50 > 0.8$，已超出最佳测量范围。此时透射光太弱、仪器噪声占比大、相对读数误差增大，应稀释后重新测定。

**(3)** 桑德尔灵敏度：

$$S = \frac{M}{\varepsilon} = \frac{55.85}{3.0\times10^{4}} = 1.9\times10^{-3}\ \mu\mathrm{g}\cdot\mathrm{cm}^{-2}$$

**答案**：(1) 17.8%；(2) $A = 1.50$，$T = 3.16\%$，超出最佳范围；(3) $S \approx 1.9\times10^{-3}\ \mu\mathrm{g}\cdot\mathrm{cm}^{-2}$。

## 知识点映射

- 核心考点：Lambert-Beer 定律、$A$-$T$ 对数换算、桑德尔灵敏度
- 关键公式：$A = \varepsilon b c$，$T = 10^{-A}$，$S = M/\varepsilon$
- 易错点：$A$ 与 $T$ 是对数关系（非反比）；$b$ 加倍则 $A$ 加倍、$T$ 变为平方；最佳测量范围 $A = 0.2\sim0.8$，最小误差点 $A = 0.434$
