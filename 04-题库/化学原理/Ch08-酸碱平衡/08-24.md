# 8.24 缓冲溶液抗酸能力计算

## 题目

醋酸-醋酸钠缓冲体系（$pK_a = 4.76$），初始时 $[HAc] = [Ac^-] = 1.0\ M$。

向该缓冲溶液中加入0.1 mol HCl后，计算pH变化量。

（缓冲溶液pH计算公式：$pH = pK_a + \log \frac{[A^-]}{[HA]}$）

## 参考答案

初始状态：$[HAc] = [Ac^-] = 1.0\ M$，$pH = pK_a + \log(1.0/1.0) = 4.76$

加入0.1 mol HCl后，HCl与Ac⁻反应生成HAc：
$[HAc] = 1.0 + 0.1 = 1.1\ M$，$[Ac^-] = 1.0 - 0.1 = 0.9\ M$

新pH：$pH = 4.76 + \log(0.9/1.1) = 4.76 + (-0.087) = 4.67$

pH变化量：$\Delta pH = 4.76 - 4.67 \approx 0.09$单位。

证明高浓度缓冲体系具有良好的缓冲能力，加入强酸后pH变化很小。
