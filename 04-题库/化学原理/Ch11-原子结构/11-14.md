# 11.14 元素电子构型推断

| (1)Na | 11 | $1s^22s^22p^63s^1$ |
| (2)- | - | $1s^22s^22p^63s^23p^3$ |
| (3)Zr | 40 | [Kr]4d( )5s2 |
| (4)- | - | [Kr]4d( )5s25p4 |
| (5)- | - | [Kr]4d( )5s( )5p5 |
