# 11.27 第一电离能比较

## 题目

下列第一电离能比较正确的是：
A. N $2s^22p^3$ > O $2s^22p^4$
B. C $2s^22p^2$ < N $2s^22p^3$
C. B $2s^22p^1$ < C $2s^22p^2$
D. B $2s^22p^1$ < Be $2s^2$

## 参考答案

A。判断规律：半满/全满构型电离能较高（如氮>氧）；$p^1$ 构型电离能较低（易失去电子形成$p^0$全空）；$s^2$ 构型电离能高于 $s^2p^1$（如铍>硼）。实例分析：氮 $(2s^22p^3)$ > 氧 $(2s^22p^4)$；硼 $(2s^22p^1)$ < 铍 $(2s^2)$；碳 $(2s^22p^2)$ < 氮 $(2s^22p^3)$。
