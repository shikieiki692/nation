# 6.27 H₂+O₂反应kp≠kc判断

## 题目

对于反应 $2H_2(g) + O_2(g) = 2H_2O(l)$，判断以下说法是否正确：
"$k_p^{\circ} = k_c^{\circ}$"

## 参考答案

错误。该反应中 $\Delta n = 0 - (2+1) = -3 \neq 0$。当 $\Delta n \neq 0$ 时，$k_p \neq k_c$。由公式 $k_p = k_c(RT)^{\Delta n}$，此时 $k_p^{\circ} = k_c^{\circ}(RT)^{-3}$，两者不相等。
