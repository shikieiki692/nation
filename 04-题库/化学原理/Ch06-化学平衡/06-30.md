# 6.30 NH₄HS固体分解平衡常数及分压

## 题目

$NH_4HS(s)$ 在真空容器中分解：$NH_4HS(s) \rightleftharpoons NH_3(g) + H_2S(g)$，平衡时总压为68.0 kPa。（$P^\theta = 100$ kPa）

(1) 计算标准平衡常数 $K^\theta$。
(2) 保持温度不变，向体系中加入 $NH_3$ 使 $P_{NH_3} = 93.0$ kPa，求 $P_{H_2S}$ 与总压。

## 参考答案

(1) 由于反应方程式系数比为1:1，故 $P_{H_2S} = P_{NH_3} = 34.0$ kPa。

标准平衡常数：
$$K^\theta = \frac{P_{H_2S}}{P^\theta} \times \frac{P_{NH_3}}{P^\theta} = (0.340)^2 = 0.116$$

(2) 温度不变则 $K^\theta$ 不变，利用 $K^\theta = \frac{P_{H_2S}}{P^\theta} \times \frac{P_{NH_3}}{P^\theta} = 0.116$：
$$\frac{P_{H_2S}}{P^\theta} = \frac{0.116}{0.930} = 0.125$$
$$P_{H_2S} = 12.5 \, \text{kPa}$$
总压 $P_{总} = P_{H_2S} + P_{NH_3} = 12.5 + 93.0 = 105.5 \, \text{kPa}$
