# 6.26 C+O₂反应kp=kc判断

## 题目

对于反应 $C(s) + O_2(g) = CO_2(g)$，判断以下说法是否正确：
"$k_p^{\circ} = k_c^{\circ}$"

## 参考答案

正确。该反应中 $\Delta n = 1 - 1 = 0$（C为固体不计入气体摩尔数）。当 $\Delta n = 0$ 时，$k_p = k_c$ 成立。因为 $k_p^{\circ} = \frac{p_{CO_2}}{p_{O_2}}$，$k_c^{\circ} = \frac{c_{CO_2}}{c_{O_2}}$，由 $C = p/(RT)$ 可得两式相等。
