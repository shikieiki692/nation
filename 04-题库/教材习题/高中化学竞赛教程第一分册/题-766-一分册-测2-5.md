# 题-766-一分册-测2-5

> **来源**：高中化学竞赛教程第一分册 · 测试题二 · 选择第5题（题面 `_200-328.md` L1736~1740；答案 L4028）

## 题目

5. 原子的核电荷数小于 18 的某元素 X，其原子的电子层数为 n，最外层电子数为 $2n+1$，原子核内质子数是 $2n^2-1$。下列有关 X 的说法中，错误的是（ ）。

A. X 原子的价电子数和核电荷数肯定为奇数

B. X 能形成的酸都具有强氧化性

C. X 一定能形成化学式为 KXO₃ 的含氧酸钾盐

D. X 与短周期金属元素形成的化合物都是离子晶体

### 答案

### 解析（原书答案区 L4028）

原子的核电荷数小于 18 的元素，最多有三个电子层。若 $n=1$，则最外层电子数 $2n+1=3$，不可能；若 $n=2$，则最外层电子数 $2n+1=5$，核电荷数=核内质子数=7，即 $2n^2-1=2\times2^2-1=7$，满足题意，X 可能是 N 元素；若 $n=3$，则最外层电子数为 $2n+1=7$，核电荷数=核内质子数=2+8+7=17，而原子核内质子数是 $2n^2-1=2\times3^2-1=17$，符合题意，可能是 Cl 元素。因此 X 可能是 N 或 Cl 元素。再根据 N 或 Cl 相关知识即可作答：B 错（HCl、$HNO_2$ 等无强氧化性），D 错（如 $AlCl_3$ 为共价化合物，属分子晶体）。
