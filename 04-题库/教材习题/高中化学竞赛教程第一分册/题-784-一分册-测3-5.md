# 题-784-一分册-测3-5

> **来源**：高中化学竞赛教程第一分册 · 测试题三 · 选择第5题（题面 `_200-328.md` L1927~1934；答案 L4186~4188）

## 题目

5. 室温下，将 $1.000\,\mathrm{mol\cdot L^{-1}}$ 盐酸滴入 $20.00\,\mathrm{mL}\,1.000\,\mathrm{mol\cdot L^{-1}}$ 氨水中，溶液 pH 和温度随加入盐酸体积变化曲线如右图所示。下列有关说法正确的是（ ）。

A. a 点由水电离出的 $c(\mathrm{H}^{+}) = 1.0\times10^{-14}\,\mathrm{mol\cdot L^{-1}}$

B. b 点：$c(\mathrm{NH}_{4}^{+}) + c(\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O}) = c(\mathrm{Cl}^{-})$

C. c 点：$c(\mathrm{Cl}^{-}) = c(\mathrm{NH}_{4}^{+})$

D. d 点后，溶液温度略下降的主要原因是 $\mathrm{NH_3\cdot H_2O}$

![[500d3f3f42abee1072b3fc009a3eb067286415df42f9b9c1a3aa0b97db1011d1.jpg]]

> **校勘注**：题面 D 选项原书 OCR 断裂（"主要原因是 NH₃"后接图片化残句 $\mathrm{NH_3\cdot H_2O}$），按答案区"再加盐酸温度降低只能是加入盐酸的温度低于溶液温度"补全语义为"加入的盐酸温度低于溶液温度（且稀释散热）"，照录存疑。

### 答案

C

### 解析（原书答案区 L4186~4188）

本题综合考查水溶液中的电离平衡以及酸碱中和滴定的相关知识。a 点 $7 < pH < 14$，由于 $[H^{+}][OH^{-}] = 10^{-14}$，因此由水电离出的 $c(H^{+}) > 1.0\times10^{-14}\,\mathrm{mol\cdot L^{-1}}$，A 错；b 点时盐酸和氨水反应，氨水过量，等式 $c(\mathrm{NH}_{4}^{+}) + c(\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O}) = c(\mathrm{Cl}^{-})$ 不成立，B 错；c 点溶液呈中性，根据电荷守恒，有等式 $c(\mathrm{OH}^{-}) + c(\mathrm{Cl}^{-}) = c(\mathrm{NH}_{4}^{+}) + c(\mathrm{H}^{+})$，又由于 pH = 7，即 $c(\mathrm{H}^{+}) = c(\mathrm{OH}^{-})$，因此等式 $c(\mathrm{Cl}^{-}) = c(\mathrm{NH}_{4}^{+})$ 成立，C 正确。d 点时盐酸和氨水恰好完全反应，放热最多，再加盐酸温度降低只能是加入盐酸的温度低于溶液温度，这才是温度下降的原因，因此 D 错误。
