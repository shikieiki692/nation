# 题-764-一分册-测2-3

> **来源**：高中化学竞赛教程第一分册 · 测试题二 · 选择第3题（题面 `_200-328.md` L1714~1718；答案 L4024）

## 题目

3. 在恒温、恒容条件下，反应 $2\mathrm{A(g)} + \mathrm{B(g)} \rightleftharpoons 2\mathrm{C(g)}$ 从两条途径分别建立平衡：(Ⅰ) A、B 的起始浓度分别为 $2\,\mathrm{mol\cdot L^{-1}}$ 和 $1\,\mathrm{mol\cdot L^{-1}}$；(Ⅱ) C 的起始浓度为 $4\,\mathrm{mol\cdot L^{-1}}$。以下关于平衡时的叙述正确的是（ ）。

A. 途径 Ⅰ 和途径 Ⅱ 所得混合气体的百分组成相同

B. 途径 Ⅰ 所得 C 物质的浓度为途径 Ⅱ 所得 C 物质浓度的一半

C. 途径 Ⅰ 的反应速率 $v(A)$ 与途径 Ⅱ 的反应速率 $v(C)$ 相等

D. 途径 Ⅰ 所得混合气体的密度为途径 Ⅱ 所得混合气体的密度的一半

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

D

### 解析（原书答案区 L4024）

本题要弄清楚同一化学平衡和等效平衡问题。Ⅰ 和 Ⅱ 不是同一化学平衡。若将 Ⅱ 中 C 的起始浓度变为 $2\,\mathrm{mol\cdot L^{-1}}$，则为同一化学平衡，Ⅰ 和 Ⅱ 的生成物量的关系是 2 倍关系。因此选项 A、B、C 均错误。

> **整理者解析**：Ⅱ（C=4）折算为 A、B 投料相当于 2× 途径 Ⅰ，但反应 2A+B⇌2C 是气体分子数减小的反应——投料加倍即压强加倍，平衡右移使转化率略增，故两途径的百分组成、浓度倍数、速率均非严格 2 倍关系，A/B/C 皆不成立；而 D 中密度=气体总质量/恒容体积，质量守恒使 Ⅱ 的气体总质量恒为 Ⅰ 的 2 倍，密度严格为一半，D 正确。

</details>
