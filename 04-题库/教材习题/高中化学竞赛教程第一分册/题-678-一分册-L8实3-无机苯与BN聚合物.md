# 无机苯与BN聚合物

> **来源**：高中化学竞赛教程第一分册 · 第8讲 共价键理论 · 实战演练 3

## 题目

硼、氮、氢三种元素在一定条件下可以形成类似苯的化合物，俗称无机苯。它是无色液体，也有类似于苯环的芳香性。

(1) 写出无机苯的分子式，画出它的结构式并标出形式电荷。

(2) 写出无机苯与 HCl 发生加成反应的化学方程式。

(3) 硼和氮的化合物可形成二元固体聚合物，分析该种聚合物的可能结构，并说明它是否会具有导电性。

**原书答案（答案区 L3272~3278）**

(1) $B_3N_3H_6$：

![[a40be35f4ed9a86d8287b5dd6ec324591a861f013c185cbb5e5b193ab3cfce68.jpg]]

（六元环 B、N 交替，B=N 交替双键，两个共振式：一式 B 带 ⊕、N 带 ⊙/⊖，另一式相反；环内以离域 $\Pi_6^6$ 表达芳香性。）

(2) 因为电负性的差异，B 原子带正电荷，N 原子带负电荷，所以 Cl 原子加成在 B 原子上。

![[c10f500ed61ee6f579cdc31c9938f5bdd6b818ba392dc6d1e0d26c82185971d8.jpg]]

（$B_3N_3H_6 + 3HCl \longrightarrow$ 环上 3 个 B 各加 1 个 Cl、3 个 N 各加 1 个 H 的加成产物。）

(3) 因为 (BN) 与 $C_2$ 互为等电子体关系，由 $C_n$ 可以有金刚石型和石墨型，可以得出 $(BN)_x$ 也可以具有金刚石型或石墨型。在金刚石型的 $(BN)_x$ 中，B 原子、N 原子均采取 $sp^3$ 杂化，没有自由电子存在，所以不导电；在石墨型中虽然 B 原子、N 原子都采取 $sp^2$ 杂化，形成层状结构，由于 B 和 N 元素电负性差异比较大，未参与杂化的 N 原子 2p 轨道上孤电子对与 B 原子未参与杂化的空 2p 轨道，成为定域 $\pi$ 键，所以也不导电。

**整理者解析**

(2) 极性键加成取向遵循"正电部分加负电原子、负电部分加正电原子"：H⁺ 加到带负电的 N 上、Cl⁻ 加到带正电的 B 上。这与无机苯的"极性芳香环"性质一致，也是 BN 系与苯最大的差别（苯与 HCl 不加成）。

</details>
