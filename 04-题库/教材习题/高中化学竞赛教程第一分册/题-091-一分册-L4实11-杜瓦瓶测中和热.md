# 杜瓦瓶测中和热

> **来源**：高中化学竞赛教程第一分册 · 第4讲 化学反应中的能量变化 · 实战演练 11
> **同题异版**：[[题-054-上海中学-化学热力学基础-习题5]]（上海中学版同题，储液管体积作 35 mL，答案口径 −56.0/2.0）

## 题目

通常中和热、溶解热等测定是在一种恒压绝热的量热计(又叫杜瓦瓶)中进行。已知 $\Delta H_{\mathrm{f}}^{\ominus}(\mathrm{H}_{2}\mathrm{O}(\mathrm{l})) = -286~\mathrm{kJ}\cdot\mathrm{mol}^{-1}$，$\Delta H_{\mathrm{f}}^{\ominus}(\mathrm{OH}^{-}(\mathrm{aq})) = -230~\mathrm{kJ}\cdot\mathrm{mol}^{-1}$。欲测弱酸与强碱反应的中和热，进行下列实验：

第一步：量热计热容量的测定。先在杜瓦瓶中装入 $350~\mathrm{mL}~0.2~\mathrm{mol\cdot L^{-1}}$ HCl 溶液，在另一带活塞的小储液管中装入 $350~\mathrm{mL}~0.2~\mathrm{mol\cdot L^{-1}}$ NaOH 溶液，并将储液管放入杜瓦瓶酸液中，测定反应前温度 $23.20^{\circ}\mathrm{C}$，然后快速吹去活塞，使碱液与酸混合并搅拌，测得反应后最高温度为 $28.33^{\circ}\mathrm{C}$。

第二步：以 $350~\mathrm{mL}~0.2~\mathrm{mol\cdot L^{-1}}$ HAc 标准溶液代替盐酸，重复上述操作，测得反应前后温度分别为 $23.33^{\circ}\mathrm{C}$ 和 $27.64^{\circ}\mathrm{C}$。

(1) 求 HAc 与 NaOH 的中和热 $(\mathrm{kJ}\cdot\mathrm{mol}^{-1})$；

(2) 求 HAc 的电离热 $(\mathrm{kJ}\cdot\mathrm{mol}^{-1})$。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

(1) $\Delta H = -47.05~\mathrm{kJ}\cdot\mathrm{mol}^{-1}$

(2) $\Delta H = 8.95~\mathrm{kJ}\cdot\mathrm{mol}^{-1}$

**解析（补建）**：强酸强碱中和热 = ΔHf⊖(H₂O,l) − ΔHf⊖(OH⁻,aq) = −286−(−230) = −56 kJ/mol。第一步 n(HCl)=n(NaOH)=0.350×0.2=0.070 mol，放热 Q₁ = 0.070×56 = 3.92 kJ，温升 5.13℃ → 量热计总热容 C = 3.92/5.13 = 0.764 kJ/℃。第二步温升 4.31℃，放热 Q₂ = 0.764×4.31 = 3.294 kJ → 摩尔中和热 = 3.294/0.070 = 47.05 kJ/mol（放热记 −47.05）。电离热 = 56 − 47.05 = 8.95 kJ/mol（弱酸电离吸热）。

</details>
