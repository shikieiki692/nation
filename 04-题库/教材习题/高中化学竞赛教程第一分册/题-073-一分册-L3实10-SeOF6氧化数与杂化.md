# SeOF₆ 的氧化数、杂化与碱反应

> **来源**：高中化学竞赛教程第一分册·第3讲 离子反应【实战演练·10】

## 题目

在 $SeOF_{6}$ 化合物中, Se 和 O 的实际氧化数分别为 \_\_\_\_、\_\_\_\_; Se 原子采用 \_\_\_\_ 杂化方式, 其几何构型名称是 \_\_\_\_ 。该化合物与苛性碱反应, 其离子方程式为 \_\_\_\_ , 它 \_\_\_\_ (填是或不是) 氧化还原反应。

## 参考答案

<details><summary>📖 查看答案与解析</summary>

**参考解答**（书末答案区照录＋解析补建）

+6 0 $\mathrm{sp}^3\mathrm{d}^2$ 正八面体(或变形八面体)

$$
2\mathrm{SeOF}_{6} + 16\mathrm{OH}^{-}\longrightarrow 2\mathrm{SeO}_{4}^{2 - } + \mathrm{O}_{2} + 12\mathrm{F}^{-} + 8\mathrm{H}_{2}\mathrm{O} \quad \text{不是}
$$

**解析补注**（原书未给说明，录入时补建）①氧化数：SeOF₆ 中 F 电负性最强，6F 记 −6；O 与 Se 之间因 F 的强拉电子作用，成键电子对不划给 O，O 记 0 价；由电中性 Se = +6。②杂化与构型：中心 Se 价层电子对 = 7（6 个 Se—F 键 + 1 个 Se=O 键），无孤对 → sp³d² 杂化、八面体骨架；因一个配位体为 O 与 F 不同，实际为变形八面体（答案两写均收）。③碱反应验算：Se 2=2、F 12=12 ✓；O 左 2+16=18，右 8+2+8=18 ✓；H 16=16 ✓；电荷 −16=−4−12 ✓。氧化数视角：Se(+6) 与 F(−1) 均未变价；O 则由 SeOF₆ 中的 0 价落入 $\mathrm{SeO_4^{2-}}$/H₂O 的 −2 价（各 2 个，共得 4e），同时 2 个 $\mathrm{OH^{-}}$ 的 O(−2) 升为 $\mathrm{O_{2}}$ 的 0 价（失 4e）——若严格按 O 的氧化数 0↔−2 转换，应属氧化还原反应；原书答案给「不是」（仅考察 Se/F 主元素价态不变），照录存疑。

**同源小问互链**：本题「SeOF₆ 在碱性溶液中分解」与 [[04-题库/教材习题/化学竞赛初赛讲义/题-139-初赛讲义-反应方程式-习题1.56]]（初赛讲义 1.56 第 2 小问）同源——该题仅要求写碱性分解方程式，本题进一步问氧化数/杂化/构型，两题保留互链。
