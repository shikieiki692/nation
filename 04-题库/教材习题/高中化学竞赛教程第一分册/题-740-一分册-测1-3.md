# 题-740-一分册-测1-3

> **来源**：高中化学竞赛教程第一分册 · 测试题一 · 选择第3题（题面 `_200-328.md` L1502~1505；答案 L3886）

## 题目

3. 已知 A、B 两种气体在一定条件下可发生反应：$2\mathrm{A} + \mathrm{B} \longrightarrow \mathrm{C} + 3\mathrm{D} + 4\mathrm{E}$。现将 $m\,\mathrm{g}$ 相对分子质量为 $M$ 的 A 气体与适量的 B 气体充入一密闭容器中，恰好完全反应且有少量液滴生成。在相同温度下测得反应前后容器内的压强为 $6.06\times10^{6}\,\mathrm{Pa}$ 和 $1.01\times10^{7}\,\mathrm{Pa}$，且测得反应共放出热量 $Q\,\mathrm{kJ}$。则该反应的热化学方程式为（ ）。

A. $2\mathrm{A(g)} + \mathrm{B(g)} \longrightarrow \mathrm{C(g)} + 3\mathrm{D(g)} + 4\mathrm{E(g)} \quad \Delta H = -MQ/m\,\mathrm{kJ\cdot mol^{-1}}$

B. $2\mathrm{A(g)} + \mathrm{B(g)} \longrightarrow \mathrm{C(l)} + 3\mathrm{D(g)} + 4\mathrm{E(g)} \quad \Delta H = -2MQ/m\,\mathrm{kJ\cdot mol^{-1}}$

C. $2\mathrm{A(g)} + \mathrm{B(g)} \longrightarrow \mathrm{C(g)} + 3\mathrm{D(g)} + 4\mathrm{E(l)} \quad \Delta H = -MQ/m\,\mathrm{kJ\cdot mol^{-1}}$

D. $2\mathrm{A(g)} + \mathrm{B(g)} \longrightarrow \mathrm{C(g)} + 3\mathrm{D(l)} + 4\mathrm{E(g)} \quad \Delta H = -2MQ/m\,\mathrm{kJ\cdot mol^{-1}}$

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

D

### 解析（原书答案区 L3886）

根据克拉珀龙方程知：反应前后气体压强之比等于其体积比，等于方程式中气态物质的计量系数比。因此设气态生成物的系数为 x，则 $(2+1)/x = 6.06\times10^{6}/1.01\times10^{7} = 6/10 = 3/5$，x = 5。因此生成物中气态物质的系数为 5，满足题意的选项为 A 或 D。再根据题意：$m/M : Q = 2 : y$，$y = 2MQ/m\,\mathrm{kJ\cdot mol^{-1}}$。由于反应放热，因此选项 D 正确。

> **整理者解析**：气体分子数由 3 变为 5（比值 3/5 与压强比吻合），故液滴为 3D(l)；$m$ g A 为 $m/M$ mol，对应反应热 $Q$，则每摩尔反应（消耗 2 mol A）放热 $2MQ/m$ kJ，$\Delta H=-2MQ/m$。
