# NₓHᵧ 燃烧推算

> **来源**：高中化学竞赛教程第一分册·第1讲 物质的量【实战演练】7

## 题目

4 mL O₂ 和 3 mL NₓHᵧ（y > x）混合气体在 120 ℃、1.01×10⁵ Pa 下点燃完全反应后，恢复到原温度和压强时，测得反应后 N₂、O₂、H₂O（气）混合气体密度减小 3/10。

(1) 反应的化学方程式为 \_\_\_\_；
(2) 推算 NₓHᵧ 的分子式：

计算的根据是（用文字叙述）\_\_\_\_，即（用含 x、y 的代数式表示）\_\_\_\_，解此方程得 \_\_\_\_ 时符合题意，所以 NₓHᵧ 的分子式为 \_\_\_\_。

## 参考答案

<details><summary>📖 查看答案与解析</summary>

(1) 密度减小 3/10 ⇒ ρ_后 = 7/10·ρ_前；反应前后气体总质量守恒，同温同压下 ρ 与体积成反比，故 V_后 = 7/(7/10) = **10 mL**。设反应后剩余 O₂ a mL、生成 N₂ b mL、H₂O(g) c mL，则 a + b + c = 10。

原子守恒：O：2a + c = 2×4 = 8；H：2c = 3y；N：2b = 3x。代入得 20 − 3x − 1.5y = 8，即 **2x + y = 8**。

在 y > x 的正整数约束下解 2x + y = 8：x = 2、y = 4 符合题意（x = 1、y = 6 无稳定氮氢物；x ≥ 3 时 y ≤ 2 违背 y > x）。

(2) 故 NₓHᵧ 的分子式为 **N₂H₄（肼）**。反应的化学方程式：

**N₂H₄ + O₂ → N₂ + 2H₂O**

（3 mL N₂H₄ 耗 3 mL O₂ 生成 3 mL N₂ 与 6 mL H₂O，余 1 mL O₂，总体积 3+6+1 = 10 mL ✓）

</details>
