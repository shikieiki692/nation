# 镁碳化物与复杂盐推断

> **来源**：高中化学竞赛教程第一分册·第1讲 物质的量【竞赛对接】例2（2015 年捷克化学竞赛试题）

## 题目

硫、氮、碳、铁、铜等常见元素在化合物中常表现出多种价态，如硫有 -2、-1、+2、+4、+6 等价态。这些元素在化工生产中有着重要应用。

(1) 31.2 g 镁与碳粉的混合物在一定条件下恰好完全反应，再加入足量水，得到 40.6 g 白色沉淀，同时产生密度为 1.4107 g/L（标准状况）的丙二烯（C₃H₄）和不饱和烃 X 的混合气体。
① 镁与碳粉的反应产物的化学式为 \_\_\_\_。
② 原混合物中碳粉的物质的量分数为 \_\_\_\_（用小数表示，保留 2 位小数）。

(2) 某复杂盐由三种元素组成，含两种阳离子和两种阴离子。取 21.76 g 该复杂盐，平均分为两份。将第一份溶于足量盐酸酸化的 BaCl₂ 溶液，所得沉淀中含 9.32 g BaSO₄。将第二份溶于足量热浓硝酸，再滴加足量 Ba(NO₃)₂ 溶液，得 13.98 g 白色沉淀，过滤后向蓝色滤液中加足量烧碱溶液，过滤、洗涤、灼烧，得 8.00 g 黑色固体。
① 该复杂盐的化学式为 \_\_\_\_。
② 该复杂盐中两种阳离子的质量比为 \_\_\_\_。

## 参考答案

<details><summary>📖 查看答案与解析</summary>

(1) 因为 m[Mg(OH)₂] = 40.6 g，所以 n[Mg(OH)₂] = 40.6/58 = 0.7 mol，m(Mg) = 0.7 × 24 = 16.8 g，所以 m(C) = 31.2 − 16.8 = 14.4 g，即 n(C) = 1.2 mol。不饱和烃平均摩尔质量 M = 1.4107 × 22.4 = 31.6 g/mol，而 M(C₃H₄) = 40 g/mol，所以另一种不饱和烃 X 的摩尔质量小于 31.6，可能是乙烯或乙炔。

- 若为 C₂H₂ 与 C₃H₄ 混合物：设 x、y mol，则 (26x+40y)/(x+y) = 31.6 ⇒ x:y = 3:2；对应 MgC₂ 与 Mg₂C₃，由镁守恒 x + 2y = 0.7 ⇒ x = 0.3、y = 0.2，碳守恒验证成立。
- 若为 C₂H₄ 与 C₃H₄ 混合物：得 a:b = 7:3，由镁守恒 a = 49/200、b = 21/200 mol，代入碳元素守恒不相等，排除。

① 镁与碳粉反应产物为 **MgC₂ 和 Mg₂C₃**；② 原混合物中碳粉的物质的量分数 = 1.2/(1.2+0.7) × 100% ≈ **0.63**。

(2) 每份样品 10.88 g。第一份盐酸酸化的 BaCl₂ 只沉淀 SO₄²⁻：n₁(SO₄²⁻) = 9.32/233 = 0.04 mol；第二份热浓硝酸把 S²⁻ 氧化成 SO₄²⁻，n₂(BaSO₄) = 13.98/233 = 0.06 mol ⇒ n(S²⁻) = 0.02 mol；蓝色滤液加碱灼烧得 CuO：n(CuO) = 8.00/80 = 0.1 mol。

另一份 0.02 mol 含硫离子质量 m = 10.88 − 3.84 − 6.4 = 0.64 g ⇒ 为 S²⁻（0.02 mol S 恰 0.64 g）。故 n(Cu) : n(SO₄²⁻) : n(S²⁻) = 0.1 : 0.04 : 0.02 = 5 : 2 : 1。

① 复杂盐化学式为 **Cu₅S(SO₄)₂**。
② 含两种阳离子 Cu⁺ 与 Cu²⁺：设 Cu₅S(SO₄)₂ 中 Cu⁺ 为 x、Cu²⁺ 为 y，由铜守恒与化合价代数和为零：x + y = 5，x + 2y = 2 + 2×2 ⇒ x = 4、y = 1，两阳离子质量比 = 4×64 : 1×64 = **4 : 1**。

</details>
