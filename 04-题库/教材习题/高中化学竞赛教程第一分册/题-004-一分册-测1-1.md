# 题-004-一分册-测1-1

## 题目

1. 下列离子方程式正确的是（ ）。

A. 硫酸亚铁在空气中氧化：$4\mathrm{Fe^{2+}} + 3\mathrm{O_2} + 6\mathrm{H_2O} \longrightarrow 4\mathrm{Fe(OH)_3}$

B. 向硝酸银溶液中加入过量氨水：$\mathrm{Ag^+} + \mathrm{NH_3\cdot H_2O} \longrightarrow \mathrm{AgOH}\downarrow + \mathrm{NH_4^+}$

C. 向硫酸铝铵矾溶液中滴加过量的氢氧化钡溶液：$\mathrm{NH_4^+} + \mathrm{Al^{3+}} + 2\mathrm{SO_4^{2-}} + 2\mathrm{Ba^{2+}} + 5\mathrm{OH^-} \longrightarrow \mathrm{AlO_2^-} + 2\mathrm{BaSO_4}\downarrow + \mathrm{NH_3\cdot H_2O} + 2\mathrm{H_2O}$

D. 向次氯酸钠溶液中通入足量 $\mathrm{SO_2}$ 气体：$\mathrm{ClO^-} + \mathrm{SO_2} + \mathrm{H_2O} \longrightarrow \mathrm{HClO} + \mathrm{HSO_3^-}$

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

C

### 解析

选项 A 电荷不守恒；$\mathrm{Ag^+}$ 与过量氨水反应生成 $[\mathrm{Ag(NH_3)_2}]^+$，因此选项 B 错误；$\mathrm{ClO^-}$ 能将 $\mathrm{SO_2}$ 氧化为 $\mathrm{SO_4^{2-}}$，故选项 D 错误。

</details>
