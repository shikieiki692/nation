# 题-759-一分册-测1-22

> **来源**：高中化学竞赛教程第一分册 · 测试题一 · 非选择第22题（题面 `_200-328.md` L1661~1669；答案 L3990~3996）

## 题目

22. 我国东方Ⅱ号宇宙火箭的燃料是 $\mathrm{N}_2\mathrm{H}_2(\mathrm{CH}_3)_2$，助燃剂为 $N_2O_4$，两者发生完全燃烧时产生了巨大推力，让火箭携带卫星上天。

(1) $\mathrm{N}_2\mathrm{H}_2(\mathrm{CH}_3)_2$ 中 N 的氧化数为____，$N_2O_4$ 中 N 的氧化数为____。

(2) 完全燃烧反应的化学方程式为____。

(3) 试写出 $N_2O_4$ 中 N、N 连接的一种 Lewis 结构式并标出形式电荷____。

(4) $N_2H_4$ 与 $N_2O_4$ 比较，____的 N—N 键长较长，其理由是____。

### 答案（原书答案区 L3990~3996）

(1) −2；+4。

(2) $\mathrm{N}_2\mathrm{H}_2(\mathrm{CH}_3)_2 + 2\mathrm{N}_2\mathrm{O}_4 \longrightarrow 3\mathrm{N}_2 + 2\mathrm{CO}_2 + 4\mathrm{H}_2\mathrm{O}$

(3) （见下图，N—N 相连，每个 N 以 N=O 双键与 N—O 单键连接，两个单键 O 带形式电荷 −、两个 N 带形式电荷 +）

![[d4a96deb6105a92710dc8e2c64540b656067023a8726a9988f44822e0a2194f1.jpg]]

(4) $N_2O_4$。因为 $N_2O_4$ 中的两个 N 原子带同号形式电荷，N、N 原子之间存在排斥力，所以 $N_2O_4$ 的 N—N 键长比 $N_2H_4$ 中的 N—N 键长要长。

</details>
