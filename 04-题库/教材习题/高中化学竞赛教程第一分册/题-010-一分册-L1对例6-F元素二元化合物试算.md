# F 元素二元化合物试算

> **来源**：高中化学竞赛教程第一分册·第1讲 物质的量【竞赛对接】例6（第 23 届国际竞赛预备题）

## 题目

元素 X 能分别和 B、N 及 O 形成二元化合物。在二元化合物中 B 占 16.2%，N 占 19.7%，O 占 29.7%。其摩尔质量分别为 54、68、71 g·mol⁻¹（未按顺序）。在各未知物具体摩尔质量下能否知道 X 为何种元素？若能，请确定 X 并给出各物的分子式。

## 参考答案

<details><summary>📖 查看答案与解析</summary>

本题无妨用试算的方法：

先设 X 与 B 的化合物摩尔质量分别为 54、68、71 g·mol⁻¹，分别计算 B 原子数目：
54×0.162/11 = 0.79（不是整数，不符合）；68×0.162/11 = 1.001（很接近整数，符合）；71×0.162/11 = 1.05（接近整数但已可排除）。

X 与 N 的化合物：54×0.197/14 = 0.76（不符合）；68×0.197/14 = 0.96（不符合）；71×0.197/14 = 1.00（符合）。

X 与 O 的化合物：54×0.297/16 = 1.002（符合）；68×0.297/16 = 1.26（不符合）；71×0.297/16 = 1.32（不符合）。

综合试算结果：B、N、O 与 X 的化合物的摩尔质量应分别为 68、71、54 g·mol⁻¹。1 mol 化合物中 X 的质量分别为：68−11 = 57、71−14 = 57、54−16 = 38 g。57、57、38 应为 X 元素摩尔质量的整数倍，很容易得出 X 的摩尔质量为 19 g·mol⁻¹。

所以 X 元素为 **F**，二元化合物的分子式为 **BF₃、NF₃、OF₂**。

</details>
