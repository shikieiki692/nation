# 题-060-1：含碘废液回收离子方程式

**1.** 实验室含碘废液可回收利用。写出上述过程涉及的离子反应方程式。

---

## 答案

SO₃²⁻ + I₂ + H₂O = SO₄²⁻ + 2I⁻ + 2H⁺；2Cu²⁺ + 2I⁻ + SO₃²⁻ + H₂O = 2CuI↓ + SO₄²⁻ + 2H⁺；3CuI + 8H⁺ + 2NO₃⁻ = 3Cu²⁺ + 3I⁻ + 2NO↑ + 4H₂O
