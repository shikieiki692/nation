# 题-054-3：HI生成焓计算

1/2I₂(g) = I(g) ΔᵣHₘθ = 75.7 kJ·mol⁻¹
I₂(s) = I₂(g) ΔᵣHₘθ = 62.3 kJ·mol⁻¹
计算反应 H(g) + I(g) = HI(g) 的焓变 ΔᵣHₘθ
