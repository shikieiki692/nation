# 第一讲 卤族元素 — 答案与提示

## 习题1

(1) $2\mathrm{Ag}^{+} + \mathrm{CrO}_{4}^{2-} = \mathrm{Ag}_{2}\mathrm{CrO}_{4}$

(2) 0.000 530 mol/L

(3) $\left[\mathrm{Ag}^{+}\right] = 7.1\times 10^{-6}\mathrm{mol / L}$　$\left[\mathrm{Cl}^{-}\right] = 2.5\times 10^{-5}\mathrm{mol / L}$

(4) $2\mathrm{CrO}_4^{2-} + 2\mathrm{H}^+ = \mathrm{Cr}_2\mathrm{O}_7^{2-} + \mathrm{H}_2\mathrm{O}$

## 习题2

分析: 首先考虑到 $\mathrm{F}_{2}$ 的强氧化性, 应可将 $\mathrm{ClO}_{3}^{-}$ 氧化到 $\mathrm{Cl(VII)}$, 另外 $\mathrm{ClO}_{3}^{-}$ 是三角锥形分子, 要形成四面体分子还需额外有个配位原子。联系 (5) 中该四面体分子是温和的氟化剂, 可以确定是 $\mathrm{FClO}_{3}$。(3) 中与 $\mathrm{NH}_{3}$ 反应主要是对 $\mathrm{Cl(VII)}$ 酸根的处理, 在非氧化还原的前提下, F 的位置只能被 $\mathrm{NH}_{2}^{-}$ 亲核取代后生成酸根 $\mathrm{HNClO}_{3}^{-}$。(4) 中根据题目信息显然需要 $2 \mathrm{~mol} \mathrm{NaOH}$ 参与, 在只有 1 个铵根的情况下, 应该是中和酸根中的 $\mathrm{H}^{+}$。

答案：

(1) $\mathrm{KClO}_{3} + \mathrm{F}_{2} = \mathrm{KF} + \mathrm{FClO}_{3}$

(2) $\mathrm{FClO}_{3} + 2\mathrm{NaOH} = \mathrm{NaClO}_{4} + \mathrm{NaF} + \mathrm{H}_{2}\mathrm{O}$

(3) $\mathrm{FClO}_{3} + 3\mathrm{NH}_{3} = [\mathrm{NH}_{4}][\mathrm{HNClO}_{3}] + \mathrm{NH}_{4}\mathrm{F}$

(4) $[\mathrm{NH}_{4}][\mathrm{HNClO}_{3}] + 2\mathrm{NaOH} = \mathrm{Na}_{2}\mathrm{NClO}_{3} + \mathrm{NH}_{3}\uparrow + 2\mathrm{H}_{2}\mathrm{O}$

(5) $\mathrm{FClO}_{3} + \mathrm{PhLi} = \mathrm{PhClO}_{3} + \mathrm{LiF}$

## 习题3

解析: 假设有 F 元素, AgF 易溶, $\mathrm{BaF}_{2}$ 微溶, 第二次的 15 g 沉淀就是另一种卤化银, 以 Cl 来说 15 g AgCl, Cl 元素有 3.71 g, 以 Br 来说就已经超了 5.2 g 了, 所以只可能是 Cl 和 F。但是 5.2 g $\mathrm{ClF}_{n}$ 里, 就算 n=1, Cl 的质量也到不了 3.71 g, 所以这个假设不成立, 因此不含氟元素。

(2) 15.0 - 5.20 = 9.8, 约含 X = 9.8/108 = 0.09 mol, M = 5.20/0.09 = 57.8 g/mol。设 X 为 Br, Y 为 Cl, 则 $(79 + 35.5 \times 3)/4 = 185.5/4 = 46.4$, 所以不是 $\mathrm{BrCl}_{3}$, 同理不是 $\mathrm{BrF}_{3}$。设 X 为 I, Y 为 Cl, 则 $(127 + 35.5 \times 3)/4 = 58.4$, 与 57.8 误差 1%, 考虑到实验操作误差, 所以可能是 $\mathrm{ICl}_{3}$。

## 习题4

(1) $4\mathrm{Au} + 8\mathrm{CN}^{-} + 2\mathrm{H}_{2}\mathrm{O} + \mathrm{O}_{2} = 4\mathrm{Au}(\mathrm{CN})_{2}^{-} + 4\mathrm{OH}^{-}$

$K = [\mathrm{Au}(\mathrm{CN})_{2}^{-}]^{4} \times [\mathrm{OH}^{-}]^{4}/([\mathrm{CN}^{-}]^{8} \times p[\mathrm{O}_{2}]) = [\mathrm{Au}(\mathrm{CN})_{2}^{-}]^{4} \times [\mathrm{Au}^{+}]^{4} \times [\mathrm{OH}^{-}]^{4}/([\mathrm{Au}^{+}]^{4} \times [\mathrm{CN}^{-}]^{8} \times p[\mathrm{O}_{2}]) = (K_{\text{稳}}\mathrm{Au}(\mathrm{CN})_{2}^{-})^{4} \times K'$, 其中 $\lg K' = n\varepsilon^{\ominus}/0.059$, $\varepsilon^{\ominus} = \varphi^{\ominus}(\mathrm{O}_{2}/\mathrm{OH}^{-}) - \varphi^{\ominus}(\mathrm{Au}^{+}/\mathrm{Au}) = 0.401 - 1.68 = -1.279 \mathrm{~V}$。将 $n = 4, K' = 1.94 \times 10^{-87}$ 代入求得: $K = (2.0 \times 10^{38})^{4} \times 1.94 \times 10^{-87} = 3.10 \times 10^{66}$。

$2\mathrm{Au}(\mathrm{CN})_{2}^{-} + \mathrm{Zn} = 2\mathrm{Au} + \mathrm{Zn}(\mathrm{CN})_{4}^{2-}$

$$K = [\mathrm{Zn}(\mathrm{CN})_{4}^{2-}]/[\mathrm{Au}(\mathrm{CN})_{2}^{-}]^{2} = K_{\text{稳}}(\mathrm{Zn}(\mathrm{CN})_{4}^{2-}) \times K_{\text{稳}}(\mathrm{Au}(\mathrm{CN})_{2}^{-})^{-2} \times [\mathrm{Zn}^{2+}]/[\mathrm{Au}^{+}]^{2}$$

设 $K' = [\mathrm{Zn}^{2+}]/[\mathrm{Au}^{+}]^{2}$, 为对应于以下反应的平衡常数 $2\mathrm{Au}^{+} + \mathrm{Zn} = 2\mathrm{Au} + \mathrm{Zn}^{2+}$, $\varepsilon^{\ominus} = \varphi^{\ominus}(\mathrm{Au}^{+}/\mathrm{Au}) - \varphi^{\ominus}(\mathrm{Zn}^{2+}/\mathrm{Zn})$, n = 2, $\lg K' = n\varphi^{\ominus}/0.059$, $K' = 1.12 \times 10^{83}$, 解得 $K = 2.8 \times 10^{22}$。

(2) ① $\mathrm{CN}^{-} + \mathrm{ClO}^{-} = \mathrm{CNO}^{-} + \mathrm{Cl}^{-}$, $2\mathrm{CNO}^{-} + 3\mathrm{ClO}^{-} + 2\mathrm{H}^{+} = \mathrm{N}_{2}\uparrow + 2\mathrm{CO}_{2}\uparrow + \mathrm{H}_{2}\mathrm{O} + 3\mathrm{Cl}^{-}$

② A; 除去混合气体中 $\mathrm{Cl}_{2}$, 防止对 $\mathrm{CO}_{2}$ 测定量的影响

## 习题5

分析: 第(1)问可根据氧化出的 $\mathrm{I}_{2}$ 和硫代硫酸根的反应系数比可知 A 应为 $\mathrm{BrO}_{2}$(Br 被还原为负一价)。第(2)问可设产物化学式为 $\mathrm{BrO}_{2}\mathrm{F}_{x}$, 根据 Br 的百分含量可知分子式为 $\mathrm{BrO}_{2}\mathrm{F}$, 由电子守恒和原子守恒可推出(3)的分子式为 $\mathrm{BrF}_{3}$。第(6)问可根据 VSEPR 理论推出相关杂化类型和空间构型。

答案:

(1) A 是 $\mathrm{BrO}_{2}$; $6\mathrm{BrO}_{2} + 6\mathrm{NaOH} = \mathrm{NaBr} + 5\mathrm{NaBrO}_{3} + 3\mathrm{H}_{2}\mathrm{O}$

(2) B 是 $\mathrm{BrO}_{2}\mathrm{F}$

(3) C 是 $\mathrm{BrF}_{3}$

(4) $3\mathrm{BrF}_{3} + 5\mathrm{H}_{2}\mathrm{O} = \mathrm{HBrO}_{3} + \mathrm{Br}_{2} + 9\mathrm{HF}\uparrow + \mathrm{O}_{2}\uparrow$; 0.2 mol

(5) $2\mathrm{BrF}_{3} = \mathrm{BrF}_{2}^{+} + \mathrm{BrF}_{4}^{-}$

(6) B: $sp^{3}$, 三角锥; C: $sp^{3}d$, 正三角形

## 习题6

分析: 通过计算离子化合物 C 中 Xe 的质量分数可知 A 和 B 生成离子化合物 C 是一个化合反应, 再根据题目信息: 该离子化合物的负离子为四氟硼酸根, 可以得出正离子是 $\mathrm{C}_{6}\mathrm{F}_{5}\mathrm{XeF}_{2}^{+}$, 且 Xe 与苯环的 C 原子连接。另外, 与碘的氧化还原反应方程可根据题目信息 Xe 的价态完成, $\mathrm{IF}_{5}$ 分子构型则可用 VSEPR 理论推出 I 采取 $sp^{3}d^{2}$ 杂化的 $\mathrm{AX}_{5}\mathrm{E}$ 型的四方锥构型。

答案：

(1) $\mathrm{C}_{6}\mathrm{F}_{5}\mathrm{XeF}_{2}^{+}\mathrm{BF}_{4}^{-}$

(2) 分子中有 C—Xe 键

(3) $\mathrm{XeF}_{4} + \mathrm{C}_{6}\mathrm{F}_{5}\mathrm{BF}_{2} = \mathrm{C}_{6}\mathrm{F}_{5}\mathrm{XeF}_{2}^{+}\mathrm{BF}_{4}^{-}$

(4) $5\mathrm{C}_{6}\mathrm{F}_{5}\mathrm{XeF}_{2}^{+}5\mathrm{BF}_{4}^{-} + 2\mathrm{I}_{2} = 4\mathrm{IF}_{5} + 5\mathrm{Xe}\uparrow + 5\mathrm{C}_{6}\mathrm{F}_{5}\mathrm{BF}_{2}$

(5) 五氟化碘 $\mathrm{IF}_{5}$: I 采取 $sp^{3}d^{2}$ 杂化, AX5E 型, 四方锥构型

## 习题7

(1) $E_{\mathrm{Cl}_{2}^{+}} = 407 \mathrm{~kJ \cdot mol^{-1}}$

分析：根据热力学第一定律, 利用本题所给数据, 设计循环即可求得 $\mathrm{Cl}_{2}^{+}$ 的键能。

(2) ① 1.63 和 0.40

理由：酸性条件下发生归中反应, 碱性条件发生歧化反应, $E_{(+)} > E_{(-)}$ 反应自发

② 酸性介质中, 反应 $\mathrm{Cl}_{2} + \mathrm{H}_{2}\mathrm{O} = \mathrm{HClO} + \mathrm{Cl}^{-} + \mathrm{H}^{+}$ 的 $\lg K = nFE/2.30RT = -4.57$, $K = 2.69 \times 10^{-5}$; 忽略 HClO 的电离, $c(\mathrm{H}^{+}) = \sqrt[3]{K} = 0.0299$, $\mathrm{pH} = 1.52$
