# 题-060-6：铬酸铅沉淀与黄血盐（2015年初赛）

**6.**（2015年全国初赛）写出下列各化学反应的方程式:
(1) 碱式铬酸铅沉淀的生成；(2) 制备黄血盐；(3) 黄血盐被 KMnO₄ 氧化；(4) Ag₂SO₄ 与单质 S 作用。

---

## 参考答案
(1) 2Pb²⁺ + 2CrO₄²⁻ + H₂O = Pb₂(OH)₂CrO₄↓ + H₂O (2) Fe + 6HCN + K₂CO₃ = K₄[Fe(CN)₆] + H₂O + CO₂ (3) 5[Fe(CN)₆]⁴⁻ + 61MnO₄⁻ + 188H⁺ = 5Fe³⁺ + 30CO₂ + 5NO₃⁻ + 61Mn²⁺ + 94H₂O (4) Ag₂SO₄ + S = Ag₂S + SO₃
