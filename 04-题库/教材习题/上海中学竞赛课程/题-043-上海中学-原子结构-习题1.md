# 题-043：原子结构与核反应综合（7题）

> **来源**：上海中学竞赛课程·化学·第1分册·第二讲 习题
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

**1.** 假定在下列电子的各组量子数中 n 正确，请指出哪几种不能存在，为什么？
(1) n = 1, l = 1, m = 1, ms = -1
(2) n = 3, l = 1, m = 2, ms = +1/2
(3) n = 3, l = 2, m = 1, ms = -1/2
(4) n = 2, l = 0, m = 0, ms = 0
(5) n = 2, l = -1, m = 1, ms = +1/2
(6) n = 4, l = 3, m = 2, ms = 2

**2.**（2006年全国初赛试题）2006年3月有人预言，未知超重元素第126号元素有可能与氟形成稳定的化合物。按元素周期系的已知规律，该元素应位于第____周期，它未填满电子的能级应是____，在该能级上有____个电子，而这个能级总共可填充____个电子。

**3.**（2002年全国初赛试题）最近有人用高能 ${}^{26}\mathrm{Mg}$ 核轰击 ${}^{248}_{96}\mathrm{Cm}$ 核，发生核合成反应，得到新元素 X。研究者将 X 与氧气一起加热，检出了气态分子 $\mathrm{XO}_{4}$，使 X 成为了研究化学性质的最重元素。

| 质量数 | 半衰期 | 衰变方式 |
|--------|--------|----------|
| 263 | 1s | 释放 α 粒子 |
| 264 | 0.00008 s | 释放 α 粒子；或自发裂变 |
| 265 | 0.0018 s | 释放 α 粒子；或自发裂变 |
| 269 | 9.3s | 释放 α 粒子 |
(1) X 的元素符号是____。
(2) 写出合成 X 的核反应方程式。

**4.**（2004年全国初赛试题）2004年2月2日，俄国杜布纳实验室宣布用核反应得到了两种新元素 X 和 Y。X 是用高能 ${}^{48}\mathrm{Ca}$ 撞击 ${}^{243}_{95}\mathrm{Am}$ 靶得到的。经过100微秒，X 发生 α 衰变，得到 Y。然后 Y 连续发生4次 α 衰变，转变为质量数为268的第105号元素 Db 的同位素。写出上述合成新元素 X 和 Y 的核反应方程式。

**5.** 1984年，联邦德国达姆施塔特重离子研究机构用 ${}^{58}\mathrm{Fe}$ 离子轰击 ${}^{208}\mathrm{Pb}$ 靶时发现了 ${}^{265}\mathrm{X}$。
(1) X 的元素符号是____，X 最高价氧化物的化学式是____。
(2) 写出合成 X 的核反应方程式。
(3) 最近有人用高能 ${}^{26}\mathrm{Mg}$ 核轰击 ${}^{248}\mathrm{Cm}$ 核，发生核合成反应，得到 X 的另一种同位素；然后释放出 α 粒子，得到质量数为265的另一种核素。分别写出核反应方程式。

**6.** 据《科学时报》报道俄罗斯科学家最近合成了质量数为 381 的第 166 号化学元素。
(1) 该元素在周期表中的位置，它是金属还是非金属？
(2) 写出该元素的最高氧化态及电子排布式。
(3) 写出合成该元素的核反应方程式。
(4) 该元素变成稳定的 ${}^{209}_{83}\mathrm{Bi}$ 的过程中发生了多少次 α 和 β 衰变？

**7.**（1992年全国冬令营试题）假定某个星球上的元素服从下面的量子数限制：n = 1,2,3,...；l = 0,1,2,...,n-1；ml = ±l；ms = +1/2。则在此星球上，前4个惰性元素的原子序数各是多少？

---

## 参考答案
**1.** (1)、(2)、(4)、(5)、(6)组不能存在。因为：(1) n=1 时，l 只能为 0；(2) n=3，l=1 时，m 只能为 0 或 ±1；(4) ms 只能为 +1/2 或 -1/2；(5) n=2，l 只能为 0 或 1；(6) ms 只能为 +1/2 或 -1/2。

**2.** 八；5g；6；18

**3.** (1) Hs；(2) $\ce{^{26}_{12}Mg + ^{248}_{96}Cm -> ^{269}_{108}Hs + 5n}$

**4.** $\ce{^{48}_{20}Ca + ^{243}_{95}Am -> ^{288}115 + 3n}$；$\ce{^{288}115 -> ^{284}113 + ^{4}_{2}He}$

**5.** (1) Hs；$\mathrm{HsO}_{4}$ (2) $\ce{^{58}_{26}Fe + ^{208}_{82}Pb -> ^{265}_{108}Hs + n}$ (3) $\ce{^{26}_{12}Mg + ^{248}_{96}Cm -> ^{269}_{108}Hs + 5n}$；$\ce{^{269}_{108}Hs -> ^{265}_{106}Sg + ^{4}_{2}He}$

**6.** (1) 第八周期，第ⅥA族；金属 (2) +6；$[118]5g^{18}6f^{14}7d^{10}8s^{2}8p^{4}$ (3) $\ce{_{21}^{44}Sc + _{82}^{207}Pb -> ^{381}166 + 2n}$ (4) 3次 α 衰变，4次 β 衰变

**7.** 前4个惰性元素的原子序数为 1、4、9、16。
