# 题-058-1：I₃⁻平衡常数与CCl₄萃取（2006年初赛）

**1.**（2006年全国初赛）配制 (0.100 mol·L⁻¹) KI-I₂ 的水溶液，用 0.100 mol·L⁻¹ Na₂S₂O₃ 标准溶液测得 c(I₂) = 4.85×10⁻³ mol·L⁻¹。量取 50.0 mL KI-I₂ 溶液和 50.0 mL CCl₄ 置于分液漏斗中振荡达平衡，分液后测知 CCl₄ 相中 c(I₂) = 2.60×10⁻³ mol·L⁻¹。已知实验温度下 CCl₄ 从水溶液中萃取 I₂ 的分配比为 85:1。求水溶液中 I₂ + I⁻ ⇌ I₃⁻ 的平衡常数。
