## 题目

**1.**（1997年江苏化学竞赛试题）0.3 mol 的气态高能燃料乙硼烷 (B₂H₆) 在氧气中燃烧，生成固态三氧化二硼和液态水，放出 649.5 kJ 热量，其热化学方程式为____。又已知 H₂O(l) = H₂O(g)；ΔH = 44 kJ·mol⁻¹，则 11.2 L（标准状况）乙硼烷完全燃烧生成气态水时，放出的热量是____kJ。

**2.** 在燃烧 2.24 L(标准状况)CO 与 O₂ 的混和气体时，放出 11.32 kJ 的热量。所得产物的密度为原来气体密度的 1.2525 倍。燃烧同样体积(标准状况)的 N₂O 和 CO 的混合物时，放出 13.225 kJ 热量，而原来的混合物的密度是产物密度的 1.25 倍，试确定：
(1) 在 O₂ 中燃烧的 CO 的热效应（每摩尔 CO 完全燃烧时放出的热量）；
(2) N₂O 与CO所组成的混合物中各气体的体积百分组成；
(3) 由单质生成 N₂O 时的热效应。

**3.**（1997年全国初赛试题）NH₄NO₃ 热分解及和燃料油 [(CH₂)ₙ] 反应的方程式及反应热分别为：
① NH₄NO₃ = N₂O + 2H₂O + 0.53 kJ·g⁻¹ NH₄NO₃
② NH₄NO₃ = N₂ + 1/2O₂ + 2H₂O + 1.47 kJ·g⁻¹ NH₄NO₃
③ 3nNH₄NO₃ + (CH₂)ₙ = 3nN₂ + 7nH₂O + nCO₂ + 7.23n kJ·g⁻¹ NH₄NO₃
试问：由以上三个热化学方程式可得出哪些新的热化学方程式？

**4.** B₂H₆(g) 的燃烧反应如下：B₂H₆(g) + 3O₂(g) = B₂O₃(s) + 3H₂O(g)。在 298.15 K 标准状态下每燃烧 1 mol B₂H₆(g) 放热 2020 kJ，同样条件下 2 mol 硼燃烧生成 1 mol B₂O₃(s) 时放热 1264 kJ。求 298.15 K 下 B₂H₆(g) 的标准摩尔生成焓。

**5.** 298.15 K 下，测得 CH₃COOH(l) + C₂H₅OH(l) = CH₃COOC₂H₅(l) + H₂O(l) 反应的标准摩尔反应焓 ΔᵣHₘ⊖ = -9.20 kJ·mol⁻¹。查表得 ΔcHₘ⊖(C₂H₅OH, l, 298.15K) = -1366.8 kJ·mol⁻¹，ΔfHₘ⊖(H₂O, l) = -285.83 kJ·mol⁻¹，ΔcHₘ⊖(CH₃COOH, l, 298.15K) = -874.54 kJ·mol⁻¹，ΔfHₘ⊖(CO₂, g) = -393.51 kJ·mol⁻¹。求 ΔfHₘ⊖(CH₃COOC₂H₅, l, 298.15K)。

**6.** 已知 25°C 时的下列数据：反应 4C₂H₅Cl(g) + 13O₂(g) = 2Cl₂(g) + 8CO₂(g) + 10H₂O(g) 的 ΔᵣHₘ⊖ = -5144.60 kJ·mol⁻¹，反应 C₂H₆(g) + 7/2O₂(g) = 2CO₂(g) + 3H₂O(g) 的 ΔᵣHₘ⊖ = -1515.79 kJ·mol⁻¹，ΔfHₘ⊖(H₂O, g) = -241.82 kJ·mol⁻¹，ΔfHₘ⊖(HCl, g) = -92.307 kJ·mol⁻¹。求反应 C₂H₆(g) + Cl₂(g) = C₂H₅Cl(g) + HCl(g) 在 25°C 下的 ΔᵣHₘ⊖。

**7.**（第28届中国化学奥林匹克初赛试题）合成氨原料气由天然气在高温下与水和空气反应而得。涉及的主要反应如下：
① CH₄(g) + H₂O(g) = CO(g) + 3H₂(g)
② 2CH₄(g) + O₂(g) = 2CO(g) + 4H₂(g)
③ CO(g) + H₂O(g) = H₂(g) + CO₂(g)
假设反应产生的 CO 全部转化为 CO₂，CO₂ 被碱液完全吸收，剩余的 H₂O 通过冷凝干燥除去。进入合成氨反应塔的原料气为纯净的 N₂ 和 H₂。
(1) 为使原料气中 N₂ 和 H₂ 的体积比为 1:3，推出起始气体中 CH₄ 和空气的比例。设空气中 O₂ 和 N₂ 的体积比为 1:4，所有气体均按理想气体处理。
(2) 计算反应②的反应热。已知：④ C(s) + 2H₂(g) = CH₄(g), ΔH₄ = -74.8 kJ·mol⁻¹ ⑤ C(s) + 1/2O₂(g) = CO(g), ΔH₅ = -110.5 kJ·mol⁻¹

---

## 答案

**1.** B₂H₆(g) + 3O₂(g) = B₂O₃(s) + 3H₂O(l), ΔH = -2165 kJ·mol⁻¹；放出的热量是 1016.5 kJ

**2.** (1) CO 的热效应：-283 kJ·mol⁻¹ (2) N₂O 为 75%，CO 为 25% (3) ΔH = 82 kJ·mol⁻¹

**3.** ②-①可得：N₂O = N₂ + 1/2O₂ + 75.2 kJ·mol⁻¹（N₂O 分解热）；③-②×3n可得：(CH₂)ₙ + 3n/2O₂ = nCO₂ + nH₂O + ...（(CH₂)ₙ 的燃烧热）

**4.** ΔfHₘ⊖(B₂H₆, g) = 30.54 kJ·mol⁻¹

**5.** ΔfHₘ⊖(CH₃COOC₂H₅, l) = -485.22 kJ·mol⁻¹

**6.** ΔᵣHₘ⊖ = -201.037 kJ·mol⁻¹

**7.** (1) 起始气体中 CH₄ 和空气的体积比为 7:10 (2) 反应②的反应热：ΔH₂ = -71.4 kJ·mol⁻¹
