## 题目

**1.** 实验室含碘废液可回收利用。写出上述过程涉及的离子反应方程式。

**2.** 氯化亚砜 (SOCl₂) 的相关反应:
(1) 写出氯化亚砜与水完全反应的方程式，并设计简单的实验装置来验证产物；(2) 写出氯化亚砜与乙醇、乙酸反应的方程式；(3) 比较(1)、(2)中化学反应的共同之处；(4) 用方程式表示除去水合氯化物中结晶水的反应；(5) 写出亚硫酸钙和五氯化磷共热制备氯化亚砜的方程式; (6) 写出在液态 SO₂ 中, 用 Cs₂SO₃ 滴定 SOCl₂ 反应的方程式。

**3.** (1) 铁细菌将 Fe²⁺ 转变为 Fe₂O₃ 的反应方程式。(2) 金矿与磁铁矿共生的化学方程式。

**4.**（2015年全国初赛改编）
(1) 选择试剂分离各组固体混合物。(2) 在酸化的 KI 溶液中通入 SO₂ 的反应。

**5.** 菠菜成分探究实验:
(1) 根据数据说明沉淀 A 与沉淀 B 分别是什么物质? (2) 检验菠菜中是否含有铁的方法是否正确? (3) 菠菜与豆腐同食是否形成结石?

**6.**（2015年全国初赛）写出下列各化学反应的方程式:
(1) 碱式铬酸铅沉淀的生成；(2) 制备黄血盐；(3) 黄血盐被 KMnO₄ 氧化；(4) Ag₂SO₄ 与单质 S 作用。

**7.** 从含银、铜、金和铂的金属废料中提取 Au、Ag、Pt 的工艺:
(1) 电解时，金属废料应与电源的哪一极相连? (2) 写出王水处理阳极泥的反应方程式; (3) 写出用 N₂H₄ 处理制得 Ag 的方程式；(4) 写出工艺④所示步骤的反应方程式; (5) 写出工艺⑤所示步骤的反应方程式。

**8.**（2015年全国初赛）新型可逆电池:
(1) 写出电池放电时的反应方程式; (2) 写出甲烷热解反应的方程式; (3) 写出除去镍的反应方程式; (4) 写出电解质制备的反应方程式。

## 答案

**1.** SO₃²⁻ + I₂ + H₂O = SO₄²⁻ + 2I⁻ + 2H⁺；2Cu²⁺ + 2I⁻ + SO₃²⁻ + H₂O = 2CuI↓ + SO₄²⁻ + 2H⁺；3CuI + 8H⁺ + 2NO₃⁻ = 3Cu²⁺ + 3I⁻ + 2NO↑ + 4H₂O

**2.** (1) SOCl₂ + H₂O = SO₂↑ + 2HCl↑ (2) SOCl₂ + C₂H₅OH = C₂H₅Cl + SO₂ + HCl (3) 都是亲核取代反应 (4) MClₙ·xH₂O + xSOCl₂ = MClₙ + xSO₂ + 2xHCl (5) CaSO₃ + PCl₅ →[Δ] SOCl₂ + CaCl₂ + POCl₃ (6) SOCl₂ + Cs₂SO₃ = 2CsCl + 2SO₂

**3.** (1) 4Fe²⁺ + CO₂ + 5H₂O →[酶] 2Fe₂O₃ + HCHO + 8H⁺ (2) 8[AuS]⁻ + 8Fe²⁺ + 4H₂O = Fe₃O₄ + 8Au + 8HS⁻ + 4H⁺

**4.** (1) ①氨水溶解CaC₂O₄；②NaOH溶解BaCrO₄；③氨水溶解Zn(OH)₂；④氨水溶解AgCl；⑤王水溶解HgS (2) SO₂ + 2KI + 2H⁺ = I₂ + SO₂ + 2K⁺ + H₂O；I₂ + SO₂ + 2H₂O = 2HI + H₂SO₄

**5.** (1) 沉淀A为CaCO₃，沉淀B为CaC₂O₄ (2) 不正确，铁可能以Fe²⁺形式存在 (3) 可能形成草酸钙结石

**6.** (1) 2Pb²⁺ + 2CrO₄²⁻ + H₂O = Pb₂(OH)₂CrO₄↓ + H₂O (2) Fe + 6HCN + K₂CO₃ = K₄[Fe(CN)₆] + H₂O + CO₂ (3) 5[Fe(CN)₆]⁴⁻ + 61MnO₄⁻ + 188H⁺ = 5Fe³⁺ + 30CO₂ + 5NO₃⁻ + 61Mn²⁺ + 94H₂O (4) Ag₂SO₄ + S = Ag₂S + SO₃

**7.** (1) 阳极 (2) HNO₃ + 3HCl = NOCl + Cl₂ + 2H₂O；3Pt + 4HNO₃ + 18HCl = 3H₂PtCl₆ + 4NO + 8H₂O；Au + HNO₃ + 4HCl = HAuCl₄ + NO + 2H₂O (3) 4[Ag(NH₃)₂]⁺ + N₂H₄ + 4OH⁻ = 4Ag↓ + N₂↑ + 8NH₃ + 4H₂O (4) 2HAuCl₄ + 3SO₂ + 6H₂O = 2Au↓ + 3H₂SO₄ + 8HCl (5) (NH₄)₂PtCl₆ →[Δ] Pt + 2NH₄Cl + 2Cl₂↑

**8.** (1) 负极：Al - 3e⁻ = Al³⁺；正极：Cₙ[AlCl₄] + e⁻ = Cₙ + AlCl₄⁻ (2) CH₄ →[H₂] C + 2H₂；泡沫镍提供大比表面积 (3) Ni + 2HCl = NiCl₂ + H₂↑ (4) AlCl₃ + RCl = R⁺[AlCl₄]⁻
