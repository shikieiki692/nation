# 题-060-3：铁细菌与金矿共生反应

**3.** (1) 铁细菌将 Fe²⁺ 转变为 Fe₂O₃ 的反应方程式。(2) 金矿与磁铁矿共生的化学方程式。

---

## 参考答案
(1) 4Fe²⁺ + CO₂ + 5H₂O →[酶] 2Fe₂O₃ + HCHO + 8H⁺ (2) 8[AuS]⁻ + 8Fe²⁺ + 4H₂O = Fe₃O₄ + 8Au + 8HS⁻ + 4H⁺
