# 题-054-3：HI生成焓计算

**3.** 已知下列反应的焓变为:
1/2H₂(g) + 1/2I₂(s) = HI(g) ΔᵣHₘθ = 25.9 kJ·mol⁻¹
1/2H₂(g) = H(g) ΔᵣHₘθ = 218 kJ·mol⁻¹
1/2I₂(g) = I(g) ΔᵣHₘθ = 75.7 kJ·mol⁻¹
I₂(s) = I₂(g) ΔᵣHₘθ = 62.3 kJ·mol⁻¹
计算反应 H(g) + I(g) = HI(g) 的焓变 ΔᵣHₘθ

---

## 答案

-201.4 kJ·mol⁻¹
