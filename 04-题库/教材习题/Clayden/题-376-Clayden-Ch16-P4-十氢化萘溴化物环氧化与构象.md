# 题-376: 十氢化萘溴化物环氧化与构象

## 题目

Which of these two compounds would form an epoxide on treatment with base?

**原文题目**：下列两个化合物中，哪一个在碱处理下会形成环氧化物？

## 参考答案

**Answer (English)**: The mechanism is easy (intramolecular SN2) and the conformation of a trans decalin is fixed so we can start with the conformational drawings. The first compound can get the necessary 'attack from the back' angle of 180° between the nucleophile (O⁻) and the leaving group (Br) for the intramolecular reaction. But this is impossible for the second compound.

**中文解析**：

本题考察构象分析在反应性判断中的应用——构象决定了SN2反应能否发生。

关键要点：
1. **SN2机理要求**：分子内SN2反应要求亲核试剂（O⁻）从离去基团（Br）的背面进攻，即两者需呈180°反式共线（anti-periplanar）关系
2. **反式十氢化萘的构象锁定**：反式十氢化萘的两个环都是椅式，且构象被锁定，不能翻转
3. **第一个化合物**：O⁻和Br处于anti-periplanar关系（均为轴向，且在环的异侧），满足SN2的背面进攻要求，可以形成环氧化物
4. **第二个化合物**：O⁻和Br的空间排列使得背面进攻角度达不到180°，因此无法发生分子内SN2反应

> **核心概念**：环氧化物的形成（分子内SN2）不仅需要正确的立体化学关系，还需要满足构象上的几何约束。

## 解题思路

1. **读题定位**：题目要求判断哪个化合物在碱处理下能形成环氧化物——本质是判断哪个能发生分子内SN2
2. **🔑 关键转换**：画出两个化合物的椅式构象→检查O⁻与Br的二面角→反式十氢化萘构象锁定→一个满足180° anti-periplanar，另一个不满足
3. **验证**：检查构象图中O⁻和Br是否确实处于轴向-轴向的anti关系
