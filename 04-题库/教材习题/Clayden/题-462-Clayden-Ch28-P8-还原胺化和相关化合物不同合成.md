# 题-462: 还原胺化和相关化合物不同合成

## 题目

How would you make these compounds?

**中文解析**：

四种看似相关的化合物，需要完全不同的合成方法：

**仲胺**：
- 最佳方法：还原胺化（醛/酮 + 胺 + 还原剂）
- 亚胺中间体通常不分离→一锅法

**仲醇**：
- Grignard化学：环己基Grignard + 甲醛当量
- 选择：乙酸甲酯（两次加成→对称醇）或环己烷甲醛（一次加成）

**羧酸**：
- 丙二酸酯双烷基化→水解→脱羧
- 需要两次烷基化引入两个取代基

**伯胺**：
- 选择1：仲醇氧化为酮→还原胺化→伯胺
- 选择2：仲醇→甲磺酸酯→叠氮化物→还原→伯胺

## 解题思路

1. 读题定位：四个含氮/氧官能团的化合物，需要分别设计合成
2. 关键转换：
   - 仲胺→还原胺化
   - 仲醇→Grignard + 甲醛当量
   - 羧酸→丙二酸酯双烷基化
   - 伯胺→仲醇氧化+还原胺化 或 叠氮化物还原
3. 验证：每个化合物的方法是否最优
