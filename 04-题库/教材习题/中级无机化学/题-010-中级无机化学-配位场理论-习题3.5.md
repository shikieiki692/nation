# 题-010：基谱项的书写 习题3.5

> **来源**：项斯芬 姚光庆《中级无机化学》第3章 习题3.5
> **难度**：⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

写出下列电子组态的基谱项：

(1) $2p^1$ (2) $2p^2$ (3) $3d^1$ (4) $3d^3$ (5) $3d^5$ (6) $3d^9$

---

## 参考答案

### 方法：Hund 规则三步法

1. **S 最大**：自旋多重度 2S+1 最大的谱项能量最低。
2. **L 最大**：在 S 相同者中，L 最大者能量最低。
3. **J 确定**：电子数 ≤ 半满取 $J = |L-S|$；≥ 半满取 $J = L+S$（本题基谱项只写到 $^{2S+1}L$ 级，不写 J）。

### 解答

| 组态 | 电子排布要点 | 基谱项 |
|:---|:---|:---:|
| (1) $2p^1$ | 1 个电子，$S=1/2$，$L=1$ | $^2P$ |
| (2) $2p^2$ | 两电子自旋平行占据不同 m_l：$S=1$（三重态），$M_L=+1+0=1$ → $L=1$ | $^3P$ |
| (3) $3d^1$ | 1 个电子，$S=1/2$，$L=2$ | $^2D$ |
| (4) $3d^3$ | 3 电子自旋平行（半满前）：$S=3/2$，$M_L=2+1+0=3$ → $L=3$ | $^4F$ |
| (5) $3d^5$ | 半满：5 电子全部自旋平行，$S=5/2$，$L=0$ | $^6S$ |
| (6) $3d^9$ | 相当于 $d^1$ 的一个空穴（电子-空穴互补）：$S=1/2$，$L=2$ | $^2D$ |

### 考点提示

- **半满组态 d⁵ → ⁶S**：$L=0$、$S=5/2$，是唯一六重态基谱项，也是 Mn²⁺/Fe³⁺ 高自旋"无色"的根源。
- **电子-空穴互补**：$d^9$ 与 $d^1$、$p^5$ 与 $p^1$ 基谱项相同（$^2D$、$^2P$）——等价电子组态 $d^n$ 与 $d^{10-n}$ 光谱项相同。
- 若需写 $J$：$d^3$（≤半满）取 $J=|3-3/2|=3/2$ → $^4F_{3/2}$；$d^9$（≥半满）取 $J=2+1/2=5/2$ → $^2D_{5/2}$。
