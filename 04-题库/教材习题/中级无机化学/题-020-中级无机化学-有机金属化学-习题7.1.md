# 题-020：含烯烃/卡宾/茂配体的价电子数计算 习题7.1

> **来源**：项斯芬 姚光庆《中级无机化学》第7章 习题7.1
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛深化

---

## 题目

计算下列化合物的价电子数，指出哪些符合十八电子规则：

(1) CpTa(CO)₄ (2) Cp₂Ru₂(CO)₄ (3) [PtCl₃(C₂H₄)]⁻ (4) [CpFe(CO)₂(C₂H₄)]⁺
(5) Pt(PPh₃)₂(C₂Ph₂) (6) (η⁴-C₇H₈)Fe(CO)₃ (7) (CO)₅W=CMe(OMe) (8) Cp₂(Me)Ta=CH₂

---

## 参考答案

用**中性配体法**（金属按族序数出价电子，Cp 记 5e，CO/PR₃/烯烃 2e，卡宾 2e）：

| 化合物 | 计算 | 总价电子 | 18e? |
|--------|------|:---:|:---:|
| (1) CpTa(CO)₄ | Ta(5)+Cp(5)+4×2=8 | **18** | ✓ |
| (2) Cp₂Ru₂(CO)₄ | 2Ru(16)+2Cp(10)+4CO(8)=34；含 Ru—Ru 键 +2 | **36**（每 Ru 18） | ✓ |
| (3) [PtCl₃(C₂H₄)]⁻ | Pt²⁺(8)+3Cl(3)+C₂H₄(2)+1=…（离子法）→ | **16** | ✗（d⁸ 平面四方 16e 稳定） |
| (4) [CpFe(CO)₂(C₂H₄)]⁺ | Fe(8)+Cp(5)+2CO(4)+C₂H₄(2)−1 | **18** | ✓ |
| (5) Pt(PPh₃)₂(C₂Ph₂) | Pt(10)+2PPh₃(4)+C₂Ph₂(2) | **16** | ✗（d¹⁰ 16e） |
| (6) (η⁴-C₇H₈)Fe(CO)₃ | Fe(8)+η⁴-C₇H₈(4)+3CO(6) | **18** | ✓ |
| (7) (CO)₅W=CMe(OMe) | W(6)+5CO(10)+卡宾(2) | **18** | ✓ |
| (8) Cp₂(Me)Ta=CH₂ | Ta(5)+2Cp(10)+Me(1)+卡宾 CH₂(2) | **18** | ✓ |

**符合 18e：(1)(2)(4)(6)(7)(8)**；(3)(5) 为 16e 例外。

### 关键点

- **(2) 双核**：34e 不含 M—M 键，每个 Ru 仅 17e；需 Ru—Ru 键（每金属 +1e）才达 18e——与 Mn₂(CO)₁₀ 同理。
- **(3) Zeise 盐**：[PtCl₃(C₂H₄)]⁻ 是 16e 的 d⁸ 平面四方稳定物种，不追求 18e。
- **(7)(8) 卡宾**：中性法一律记卡宾碳给 2e，两种卡宾（Fischer/Schrock）在此计数下相同；Schrock 型若按 CR₂²⁻ 记 4e 则为 20e，故竞赛用中性法更稳。
- **(6) η⁴ 环多烯**：η⁴-C₇H₈（降冰片烯）提供 4e，按"配位双键数"计。

### 易错点

- 中性法统一"金属按族序数、配体按中性记"；离子法需先定氧化态，两类卡宾的氧化态分配易错。
- 双核/多核必须考虑 M—M 键贡献。
- 16e 的 d⁸ 平面四方（Pt²⁺/Pd²⁺）不是"错"，而是 16e 规则体系。
