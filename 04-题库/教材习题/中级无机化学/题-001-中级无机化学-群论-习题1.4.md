# 题-001：点群判断 习题1.4

> **来源**：项斯芬 姚光庆《中级无机化学》第1章 习题1.4
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

指出下列分子或离子所属的点群：
(1) H₂O₂ (2) S₂O₃²⁻ (3) N₂O (4) Hg₂Cl₂ (5) UO₂F₆ (6) BF₄⁻ (7) SClF₅ (8) 反-Pt(NH₃)₂Cl₂

---

## 参考答案

| 物质 | 结构特征 | 点群 |
|:---|:---|:---|
| (1) H₂O₂ | 非平面交错构型，绕 O—O 轴仅一根 C₂ | **C₂** |
| (2) S₂O₃²⁻ | S 连 3 个 O + 1 个 S 的变形四面体，仅 C₃ 轴 + 3σᵥ | **C₃ᵥ** |
| (3) N₂O | 直线形 N—N—O，无对称中心 | **C_∞ᵥ** |
| (4) Hg₂Cl₂ | 直线形 Cl—Hg—Hg—Cl，有对称中心 | **D_∞ₕ** |
| (5) UO₂F₆ | 八面体，2 个反式 O + 4 个 F，有 C₄ 轴 + σₕ + 4 根垂直 C₂ | **D₄ₕ** |
| (6) BF₄⁻ | 正四面体 | **$T_d$** |
| (7) SClF₅ | 八面体，5 F + 1 Cl，沿 C₄ 轴方向一种配体不同 | **C₄ᵥ** |
| (8) 反-Pt(NH₃)₂Cl₂ | 平面四方反式，中心 + 3 根互相垂直 C₂ + i + 3σ | **D₂ₕ** |

### 考点提示
- **直线分子二分**：先看有无对称中心 → 有：D_∞ₕ；无：C_∞ᵥ（N₂O 与 CO₂ 的区别正在于此）。
- **八面体配体替换降对称**：$O_h$ → 一个配体被替换 → C₄ᵥ；对位两个被替换 → D₄ₕ；反式替换 → D₂ₕ。
- H₂O₂ 的气相平衡构型是**非平面**的（二面角约 94°），只有 C₂，这是易错点。
