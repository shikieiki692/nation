# 题-030：B₁₀ 系硼烷阴离子结构类型判断 习题5.4

> **来源**：项斯芬 姚光庆《中级无机化学》第5章 习题5.4
> **难度**：⭐⭐⭐
> **教学层级**：竞赛深化

---

## 题目

$B_{10}H_{10}^{2-}$、$B_{10}H_{12}^{2-}$ 和 $B_{10}H_{14}^{2-}$ 各是哪种类型的硼烷结构？

---

## 参考答案

三个阴离子共享同一个 10 顶点基础多面体——**双帽四方反棱柱（$D_{4d}$）**，差别在于缺顶程度：

### 1. $B_{10}H_{10}^{2-}$ → **closo（闭式）**

- 骨架电子 = $10\times2 + 2 = 22$ 个 = **11 对**
- $n = 10$，11 = n + 1 → 完整 10 顶点闭式多面体

### 2. $B_{10}H_{12}^{2-}$ → **nido（开式）**

- 骨架电子 = $10\times2 + 2\times1（额外2H） + 2（负电荷）= 24$ 个 = **12 对**
- 12 = n + 2 → 闭式多面体缺 1 顶（巢形）

### 3. $B_{10}H_{14}^{2-}$ → **arachno（网式）**

- 骨架电子 = $10\times2 + 4\times1（额外4H） + 2 = 26$ 个 = **13 对**
- 13 = n + 3 → 开式再缺 1 相邻顶（蛛网形）

### 规律总结

同一基础多面体（顶点数 n 固定）下，**每多一对骨架电子，结构就多缺一个顶点**：

$$B_{10}H_{10}^{2-} \xrightarrow{+1对骨架电子} B_{10}H_{12}^{2-} \xrightarrow{+1对} B_{10}H_{14}^{2-}$$
$$\text{closo} \rightarrow \text{nido} \rightarrow \text{arachno}$$

这也是把 nido 看成"闭式加一对电子"、arachno 看成"再加一对电子"的来源——多出的电子必须由更开放的结构容纳。

### 易错点

- 不要只数 H 数判断类型：$B_{10}H_{12}^{2-}$ 与 $B_{10}H_{14}$（中性癸硼烷，也是 nido）H 数不同但都要看电子对判据。
- 缺顶点规则（Williams）：去掉相邻硼原子数最多的顶点最稳定。
