# 题-028：CO/H₂ 合成乙酸的全部反应与 Monsanto 催化循环 习题8.7

> **来源**：项斯芬 姚光庆《中级无机化学》第8章 习题8.7
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

写出以 CO 和 H₂ 为原料合成乙酸的全部反应，并绘出由甲醇制备乙酸的催化循环反应过程。

---

## 参考答案

### 一、以 CO 和 H₂ 为原料合成乙酸的全部反应

**第一步（合成气制甲醇）**：
$$\ce{CO + 2H2 -> CH3OH}$$

**第二步（甲醇羰基化，Monsanto 主反应）**：
$$\ce{CH3OH + CO -> CH3COOH}$$

**总反应**：
$$\ce{2CO + 2H2 -> CH3COOH}$$

> 工业实际走"甲醇中间体"路线：先由合成气（CO/H₂）制甲醇，再经铑催化羰基化得乙酸。

### 二、甲醇制备乙酸的催化循环（Monsanto 过程）

催化剂：**RhI₂(CO)₂⁻**（铑负离子，I⁻ 促进）；循环的关键中间体由红外光谱证实为 **cis-[Rh(CO)₂I₂]⁻**。

```
① CH₃I 氧化加成（决速步）
   [Rh(CO)₂I₂]⁻ + CH₃I → [Rh(CO)₂I₃(CH₃)]⁻      Rh(I) → Rh(III)

② CO 迁移插入
   [Rh(CO)₂I₃(CH₃)]⁻ → [Rh(CO)(COCH₃)I₃]⁻        甲基迁移到顺位 CO → 酰基

③ CO 配位补充空位
   [Rh(CO)(COCH₃)I₃]⁻ + CO → [Rh(CO)₂(COCH₃)I₃]⁻

④ 还原消除
   [Rh(CO)₂(COCH₃)I₃]⁻ → CH₃COI + [Rh(CO)₂I₂]⁻    Rh(III) → Rh(I)（催化剂再生）

⑤ 乙酰碘水解
   CH₃COI + H₂O → CH₃COOH + HI

⑥ 碘甲烷再生（HI 与甲醇反应）
   CH₃OH + HI → CH₃I + H₂O

（①②③④构成铑循环；⑤⑥构成碘/甲醇的辅助循环）
```

### 三、动力学与光谱证据（判断决速步）

| 证据 | 结论 |
|------|------|
| 对 Rh 催化剂为一级 | 决速步含一个 Rh 中心 |
| 对 CH₃I 为一级 | CH₃I 参与决速步 |
| 与 CO 压力无关（>3×10⁵ Pa） | CO 配位为快速可逆平衡，非决速步 |
| 速率方程 r = k[Rh][CH₃I] | **决速步 = ① CH₃I 氧化加成** |
| IR 证实 cis-[Rh(CO)₂I₂]⁻ | 循环中铑物种真实存在 |

### 易错点

- 决速步是**CH₃I 氧化加成**，不是 CO 插入——速率方程与 CO 无关是"CO 快速平衡"的证据，不是 CO 不参与。
- 循环中铑氧化态只在 ①（+2）与 ④（−2）两步改变，②③不变——氧化态"升降"只在 OA/RE 步。
- CH₃I 来自 CH₃OH + HI，I⁻ 是**助催化剂**（碘循环），不是消耗品。
