# HChO方-11 亚硝酰正离子的 Lewis 酸性与无水硝酸铁制备（3 分）

## 题目

亚硝酰正离子 NO⁺ 在反应中体现很强的 Lewis 酸性，写出下列反应的方程式。

**1-5-1** 二氧化氮溶于浓硫酸中，可生成亚硝酰正离子。

**1-5-2** 三氯化铁溶于液态四氧化二氮，可制备无水硝酸铁。

## 解答

**1-5-1**（1.5 分）

2NO₂ + 3H₂SO₄ = NO⁺ + NO₂⁺ + 3HSO₄⁻ + H₃O⁺

> 写作 2NO₂ + 2H₂SO₄ = NO⁺ + NO₂⁺ + 2HSO₄⁻ + H₂O 者不得分。

**1-5-2**（1.5 分）

FeCl₃ + 3N₂O₄ = Fe(NO₃)₃ + 3NOCl

> 写作 FeCl₃ + 3N₂O₄ = Fe(NO₃)₃ + 3NO⁺ + 3Cl⁻ 者不得分。

## 解析要点

- 1-5-1 的破题点是「NO⁺ 是 Lewis 酸」这一提示：它要被浓硫酸中的**质子（H₃O⁺ 的来源）**而非水分子所满足，故 NO₂ 通过自身歧化（NO₂ 既作 Lewis 碱给出 O、又作 Lewis 酸接受 O）产生 NO⁺ 与 NO₂⁺ 一对离子。写 H₂O 为产物的版本之所以不得分，是因为体系是**浓硫酸**，没有自由水，须以 H₃O⁺ + HSO₄⁻ 的离子形态表达。
- 1-5-2 的破题点是「Cl⁻ 不能游离于液态 N₂O₄ 中」：FeCl₃ 是强 Lewis 酸，N₂O₄ 解离为 NO⁺ 与 NO₃⁻，Fe³⁺ 取 NO₃⁻、NO⁺ 取 Cl⁻，故产物是 Fe(NO₃)₃ + NOCl，而非把 Cl⁻ 单独写出来。
- 两小问共享同一判据：**产物的存在形式必须与反应介质匹配**（这是本讲义第 1 章「体系与存在形式」的核心论点）。
