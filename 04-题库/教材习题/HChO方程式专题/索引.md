## 校勘注汇总

- **方-08**（第6届专题卷 05-02）：源文配平式 `2Na₂S₂O₃ + 6SnCl₂ + 9H₂O = SnS₂ + 5H₂SnO₃ + 2S + 8HCl` 中 Na（左 4／右 0）、Cl（左 12／右 8）不平；卡内据守恒补 `+ 4NaCl` 并附校勘注。
- **方-09**（第22届 3-2）：题面作「偏亚锡酸**钠**」，而解答与熔盐体系均为钾盐 K₂SnO₂；题面照录并附校勘注说明疑为「钾」之误。
- **方-14**（第11届 2-1）：源文 `HOI + 2Cl⁻ = ICl₂⁻ + H₂O` 电荷与氢均不守恒，按介质补全为 `HOI + 2Cl⁻ + H⁺ = ICl₂⁻ + H₂O`，附校勘注。
- **方-21**（第9届 1-1）：源文 `S₂O₃²⁻ + HCN + 2H⁺ = SO₂ + SCN⁻ + H₂O` 氢与电荷不守恒，按守恒径正为 `S₂O₃²⁻ + HCN + H⁺ = SO₂ + SCN⁻ + H₂O`，附校勘注。
