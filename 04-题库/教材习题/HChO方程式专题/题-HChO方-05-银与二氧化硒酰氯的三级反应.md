# HChO方-05 银与二氧化硒酰氯的三级反应（4 分）

> 来源：HChO 第17届培训班综合卷 第1题1-2；bdwp《01方程式书写》练习 2

## 题目

**1-2** Se 的低价化合物中，以 Se₂Cl₂ 最稳定。将一定量的 Ag 谨慎地加至冷的 SeOCl₂ 中，恰好完全反应，前者将迅速地变为 AgCl；当 Ag 过量 33%、过量 100% 时，可观察到不同的反应。写出以上三个方程式。

## 解答

4SeOCl₂ + 6Ag = 6AgCl + 2SeO₂ + Se₂Cl₂（2 分）

2SeOCl₂ + 4Ag = 4AgCl + SeO₂ + Se（1 分）

2SeOCl₂ + 6Ag = 4AgCl + SeO₂ + Ag₂Se（1 分）

> 评分细则：但凡生成 Ag₂O、Cl₂、O₂、SeO、Ag₂SeO₄ 等，均不得分。

## 解析要点

- 三档 Ag 用量对应硒的三种**还原深度**：SeOCl₂ 中 Se 为 +4，恰好反应时降到 Se₂Cl₂（+1），过量 33% 时降到 Se(0)，过量 100% 时降到 Ag₂Se（−2）。三个方程式中 SeO₂ 与 AgCl 都保留，说明它们不是被继续还原的对象。
- 判据是"**Ag 只夺氯、不夺氧**"：所有被排除的答案（Ag₂O、O₂、SeO 等）都违背了这一点；Ag₂SeO₄ 则错误地把 Se 保留在 +6。
