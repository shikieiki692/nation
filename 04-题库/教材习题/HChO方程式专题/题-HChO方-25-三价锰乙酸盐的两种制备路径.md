# HChO方-25 三价锰乙酸盐的两种制备路径（4 分）

## 题目

KMnO₄ 在冰乙酸中将 Mn(OCOCH₃)₂ 氧化、脱水，可得以棕色粉末；而 Mn(NO₃)₂·6H₂O 与乙酸酐反应则有两种棕色物质生成，且溶液中不再有五价氮。以上两个反应的共同产物的水溶液加热至沸，可转化为 Mn₂O₃。写出前两个反应的方程式。

## 解答

**反应一**（KMnO₄ 溶于冰乙酸氧化 Mn(II)）：

KMnO₄ + 4Mn(OCOCH₃)₂ + 8CH₃COOH = 5Mn(OCOCH₃)₃ + CH₃COOK + 4H₂O

**反应二**（Mn(NO₃)₂·6H₂O 与乙酸酐）：

4Mn(NO₃)₂·6H₂O + 30(CH₃CO)₂O = 4Mn(OCOCH₃)₃ + 8NO₂ + O₂ + 48CH₃COOH

（4 分）

## 解析要点

- 「共同产物」是解题的锚点：两个反应的共同产物就是那个棕色粉末，其水溶液加热可转为 Mn₂O₃ ⇒ 该产物必为 **Mn(III) 的乙酸盐 Mn(OCOCH₃)₃**（三价锰的羧酸盐是典型的棕色可溶物种）。
- 反应一的关键在氧化剂的选择与计量：Mn(VII) 与 Mn(II) 发生**归中**，由 1 个 MnO₄⁻（+7）与 4 个 Mn²⁺ 归中为 5 个 Mn³⁺（电子账：1×4 降 = 4×1 升）。钾以 CH₃COOK 形式留下，氧以 H₂O 补足。
- 反应二的关键是「溶液中不再有五价氮」：硝酸根中的 N(+5) 必须彻底消除或还原，唯一的解释是 N 以 **NO₂(+4)** 形式逸出（配平需 8 个 N），同时体系内发生**分子内氧化**放出 O₂ 以平衡氧与电子的账目。乙酸酐在此既作溶剂又作酰化试剂，把 Mn(II) 氧化为 Mn(III)。
- 两个反应都是「方程式书写」训练中的高阶题型：一个考归中、一个考非标准氧化剂的电子账分配，且都需要靠物料守恒（而非机械配平）确定产物。
- 配平核对：反应一 Mn 5/5、K 1/1、O 36/36、H 56/56、C 32/32；反应二 Mn 4/4、N 8/8、O 138/138、H 228/228、C 120/120。
