# HChO方-02 硼酸与乙酸酐在浓硫酸中的转化（5 分）

> 来源：HChO 第16届培训班综合卷 第3题3-3、3-4；bdwp《01方程式书写》练习 1

## 题目

**3-3** 硼酸在浓硫酸中将转化为一种阴离子。写出涉及的反应方程式。

**3-4** 乙酸酐溶于浓硫酸，唯一有机产物为乙酸正离子。写出涉及的反应方程式。

## 解答

**3-3**（2.5 分）

B(OH)₃ + 6H₂SO₄ = 3H₃O⁺ + B(OSO₃H)₄⁻ + 2HSO₄⁻

> 评分细则：写成 B(HSO₄)₄⁻ 也得分，但不推荐；写成 B(OSO₃H)(OH)₃⁻、B(OH)₄⁻ 等碱性物种均不得分。原书注：若单纯制备 H₃SO₄⁺B(OSO₃H)₄⁻，则在发烟硫酸中加入硼酸，或在浓硫酸中加入三氧化二硼即可。

**3-4**（2.5 分）

Ac₂O + 3H₂SO₄ = 2AcOH₂⁺ + HS₂O₇⁻ + HSO₄⁻

> 评分细则：最初写成 Ac₂O + 4H₂SO₄ = 2AcOH₂⁺ + SO₃H⁺ + 3HSO₄⁻，但 SO₃H⁺ 与 HSO₄⁻ 不能共存——生成 H₂S₂O₇ 后还会进一步解离（焦酸酸性更强，有常量浓度 HSO₄⁻ 作溶剂碱时一定会解离）。故 Ac₂O + 4H₂SO₄ = 2AcOH₂⁺ + SO₃H⁺ + 3HSO₄⁻ 得 0.5 分；Ac₂O + 4H₂SO₄ = 2AcOH₂⁺ + 2HSO₄⁻ + H₂S₂O₇ 得 1 分。Ref: J. Chem. Soc. 1956 607

## 解析要点

- 浓硫酸在本题中既是溶剂又是强酸介质：硼酸被硫酸酯化到 B(OSO₃H)₄⁻（硼由 sp² 平面转为 sp³ 四面体，是四配位硼的常见动机），乙酸酐则被质子化为乙酸正离子 AcOH₂⁺。
- 关键判据是**物种共存性**，不是配平：写出的产物必须在同一介质中彼此共存（SO₃H⁺ 会被 HSO₄⁻ 夺走质子生成 H₂S₂O₇）。这是浓硫酸/超酸体系特有的评分点，也是本题较国初同型题更难的原因。
