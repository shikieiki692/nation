# HChO方-21 硫代硫酸钠解除氰化物中毒的离子方程式（2 分）

## 题目

硫代硫酸钠可做解毒剂，可用于抢救氰化物中毒，写出硫代硫酸钠和氰化物 1:1 反应的离子方程式。

## 解答

S₂O₃²⁻ + HCN + H⁺ = SO₂ + SCN⁻ + H₂O

（1 分）

> 产物无论写何种形式（H₂SO₃、HSO₃⁻、HSCN、SCN⁻）均可，但反应物不得写 CN⁻。
>
> **校勘注**：源文作 S₂O₃²⁻ + HCN + 2H⁺ = SO₂ + SCN⁻ + H₂O，左端 H 为 3、右端为 2，电荷亦不守恒（左 0、右 −1）；按守恒应为 S₂O₃²⁻ + HCN + H⁺ = SO₂ + SCN⁻ + H₂O。此处按守恒径正。

## 解析要点

- 「解毒」的化学本质是**把游离氰转化为低毒的硫氰根**：S₂O₃²⁻ 中的一个 S 转移到 CN⁻ 上生成 SCN⁻，另一个 S 被氧化到 +4（SO₂/H₂SO₃/HSO₃⁻），硫自身完成一次歧化。
- 「反应物不得写 CN⁻」是这道题最狠的一处判分点：题面说的是「氰化物中毒」，而中毒现场的相关物种是**氢氰酸 HCN**（pKa 9.2，人体 pH 下以 HCN 为主）。写成 CN⁻ 就等于忽视了解毒环境的真实存在形式——这正是本讲义反复强调的「体系与存在形式」。
- 「1:1」的比例约束排除了 S₂O₃²⁻ 被进一步氧化到 SO₄²⁻ 的写法。
- 配平核对：S 2/2、O 3/3、C 1/1、N 1/1、H 2/2；电荷左 −2+1 = −1、右 −1。
