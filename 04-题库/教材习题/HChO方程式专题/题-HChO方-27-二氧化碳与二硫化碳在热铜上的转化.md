# HChO方-27 二氧化碳与二硫化碳在热铜上的转化（1.5 分）

## 题目

二氧化碳和二硫化碳蒸汽通至热的铜上，转化为 Cu₂S，写出反应方程式。

## 解答

CO₂ + CS₂ + 4Cu = 2Cu₂S + 2CO

（1.5 分）

## 解析要点

- 第一步要判明**谁被氧化、谁被还原**：Cu(0) → Cu(+1)；CS₂ 中的 S(−2) → Cu₂S 中的 S(−2)（未被氧化）；CO₂ 与 CS₂ 中的 C 分工不同——CO₂ 的 C(+4) → CO 的 C(+2)（被还原），CS₂ 的 C(+4) 进入另一个 CO（同样被还原到 +2）。
- 于是本题是一个**双碳源、单铜源**的配平题：CO₂ 与 CS₂ 各提供一个 C，共同生成 2 个 CO；而 S 全部来自 CS₂，与 4 个 Cu 结合为 2Cu₂S。
- 「通至热的铜上」意味着 Cu 过量（可视为无限供给），因此反应式按**气态反应物的定比**书写，而非受铜的计量限制。这是气体与固体反应配平的常见约定。
- 配平核对：Cu 4/4、S 2/2、C 2/2、O 2/2。
