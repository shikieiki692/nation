# HChO方-17 偏亚砷酸氢钾与焦亚砷酸汞的生成（4 分）

## 题目

**1-3** 在教科书中，偏亚砷酸氢钾的化学式可表示为 KH(AsO₂)₂，而实际上其为一可在水溶液中存在的离子化合物，可由亚砷酸 As(OH)₃ 的浓溶液加入 KOH 蒸发而得。该化合物中某元素的质量分数为 29.42%，画出其阴离子的实际结构，并以此结构作为其真实存在形式，写出生成偏亚砷酸氢钾的化学反应方程式。

**1-4** 氯化汞的稀溶液与过量偏亚砷酸氢钾发生非氧化还原反应，生成淡黄白色的焦亚砷酸汞。其中汞元素与砷元素的物质的量之比为 1:1，写出该反应的化学方程式。

## 解答

**1-3**（1 分）

阴离子的实际结构为 **As₂(OH)₃O₂⁻**（两个 As 各以四面体配位连接，其中两个 O 分别以 OH 形式端接，另有两个 O 桥连，还有一个端氧）：

![[00ea81e83f443adf1aca8d8d7b4b86493b5c8486164efab77b195cbd6f49384a.jpg]]

2As(OH)₃ + KOH = KAs₂(OH)₃O₂ + 2H₂O

> 亦可写作 2K[AsO(OH)₂] = KAs₂(OH)₃O₂ + KOH（说明 K[AsO(OH)₂] 并非真实存在形式，而是歧化为双核偏亚砷酸根）。

**1-4**（2 分）

4KAs₂(OH)₃O₂ + 2HgCl₂ + 3H₂O = Hg₂As₂O₅ + 4KCl + 6As(OH)₃

> 答 KAs₂(OH)₃O₂ + 2HgCl₂ = Hg₂As₂O₅ + KCl + 3HCl 者不得分；生成 As₂O(OH)₄ 者得 1 分。

## 解析要点

- 1-3 的突破口是那个 **29.42% 的质量分数**：由「教科书写法 KH(AsO₂)₂」出发逐一试算各元素的质量分数，只有按 As₂(OH)₃O₂⁻ 组成的阴离子才能与 29.42% 吻合——这是典型的「用定量数据反推真实物种」的命题手法。
- 反推结果同时给出了**结构信息**：As 为第三周期元素，可扩张配位层，故两个 As 通过氧桥连成双核、每个 As 呈四面体配位，这正是「教科书的 KH(AsO₂)₂ 形式并不真实」的物理原因。
- 1-4 的关键约束是「Hg:As = 1:1」与「非氧化还原」。既然没有价态变化，Hg(II) 只能以**氧桥**与砷氧骨架结合，得到焦亚砷酸汞 Hg₂As₂O₅；过量偏亚砷酸氢钾则被释放出的碱重新转化为 As(OH)₃。
- 配平核对：1-3 式 As 2/2、K 1/1、O 7/7、H 7/7；1-4 式 K 4/4、As 8/8、Hg 2/2、Cl 4/4、O 23/23、H 18/18。
