# HChO方-16 氟铍酸铵结晶的生成（2 分）

## 题目

向 HF 水溶液中加入理论量的 NH₄HCO₃ 与 BeO，浓缩并冷却至 0 °C，得到一结晶。

## 解答

2NH₄HCO₃ + BeO + 4HF = (NH₄)₂BeF₄ + 2CO₂ + 3H₂O

（2 分）

> 写成 (NH₄)₆Be₄OF₁₂、(NH₄)₆Be₄O(CO₃)₆ 等答案者均不得分。

## 解析要点

- 「理论量」三字是配平的唯一入口：三种反应物按恰好完全反应的整数比加入，且**浓缩冷却后得单一结晶**，故产物必须是组成固定的单一复盐。
- 铍与铝不同，Be²⁺ 半径极小、电荷密度高，在含 F⁻ 的酸性介质中倾向形成**四配位氟铍配阴离子** [BeF₄]²⁻，再由 NH₄⁺ 平衡电荷，得到 (NH₄)₂BeF₄。写成含氧桥的多核物种（如 (NH₄)₆Be₄OF₁₂）虽然形式上「更高聚合」，但破坏了「理论量」所要求的定比组成。
- 反应的副产物 CO₂ 来自 HCO₃⁻ 与 HF 的复分解；H₂O 由 HCO₃⁻ 中的 H 与 O 结转。H 的全部去向是 H₂O 与 NH₄⁺。
- 配平核对：N 2/2、C 2/2、O 7/7、F 4/4、Be 1/1、H 14/14。
