# HChO方-06 锂硅合金水解与硅烷的燃烧（4 分）

> 来源：HChO 第20届培训班综合卷 第1题1-3；bdwp《01方程式书写》练习 2

## 题目

**1-3** Li₆Si₂ 遇水迅速水解①，产物进一步生成的氢气②被引燃③。得到的澄清溶液呈强碱性。写出发生的三个反应的方程式。

## 解答

① Li₆Si₂ + 6H₂O = 6LiOH + Si₂H₆（1 分）

② Si₂H₆ + 2LiOH + H₂O = SiH₄ + 3H₂ + Li₂SiO₃（1.5 分）

③ SiH₄ + 3H₂ + 3.5O₂ + 2LiOH = Li₂SiO₃ + 6H₂O（1.5 分）

> 评分细则：第二个方程式写成 Si₂H₆ + 4H₂O = Si(OH)₄ + SiH₄ + 3H₂ 或 Si₂H₆ + 3H₂O = H₂SiO₃ + SiH₄ + 3H₂、对应第三个方程式写成 SiH₄ + 3H₂ + 3.5O₂ = Si(OH)₄ + 3H₂O 或 SiH₄ + 3H₂ + 3.5O₂ = H₂SiO₃ + 4H₂O 也得分。

## 解析要点

- 三步是一条**串联链**：锂硅合金水解先生成乙硅烷 Si₂H₆（与硅化镁水解制硅烷同型）；碱性介质中 Si₂H₆ 继续被 LiOH 切断 Si–Si 键放出 H₂（"产物进一步生成的氢气"就指这一步）；引燃的是 SiH₄ 与 H₂ 的混合气。
- ⚠️ 第三个方程式的**系数 3.5O₂ 是本题的评分点**：氧要同时氧化 SiH₄ 与并存的 3H₂，总量按守恒凑出即可，不必写成整数——这是竞赛允许的分数系数写法。
- 澄清溶液呈强碱性 ⇒ 硅最终以可溶的 Li₂SiO₃（而非 H₂SiO₃ 沉淀）形式存在，这正是 LiOH 参与后两式的原因。
