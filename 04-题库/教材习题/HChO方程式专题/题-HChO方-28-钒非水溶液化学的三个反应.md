# HChO方-28 钒非水溶液化学的三个反应（6 分）

## 题目

与钒的水溶液化学一样，钒的非水溶液化学同样丰富多彩。

**2-1-1** 可通过 V₂O₅ 与 S₂Cl₂ 的反应制备 VCl₃，已知反应后硫的平均氧化态为 +5/3，写出反应方程式。

**2-1-2** 而 V₂O₅ 与等量的 VOCl₃，以及一定比例的 VCl₃ 在一根密闭钢管中施加特殊的反应条件，则可制得一绿色晶体，产物的物质的量是反应物的总物质的量的 6/5。写出反应方程式。

**2-1-3** 五氟化钒不可保存在石英容器或铁质容器中，而只能保存在铂管内，说明其原因。

## 解答

**2-1-1**（2 分）

2V₂O₅ + 6S₂Cl₂ = 4VCl₃ + 5SO₂ + 7S

**2-1-2**（2 分）

V₂O₅ + VOCl₃ + 3VCl₃ = 6VOCl₂

**2-1-3**（2 分）

4VF₅ + 5SiO₂ = 2V₂O₅ + 5SiF₄

（1 分；写成 2VF₅ + SiO₂ = 2VOF₃ + SiF₄ 也得分）

3VF₅ + Fe = 3VF₄ + FeF₃

（1 分；写成 2VF₅ + 3Fe = 2VF₃ + 3FeF₃ 者不得分）

## 解析要点

- **2-1-1** 的题眼是「硫的平均氧化态为 +5/3」：S₂Cl₂ 中 S 为 +1，若产物同时含 SO₂（+4）与 S（0），设 SO₂ 为 a、S 为 b，则 (4a + 0·b)/(a+b) = 5/3 ⇒ a:b = 5:7，正好对应配平式中的 5SO₂ + 7S。这是「用平均氧化态反推产物分配」的典型手法。
- **2-1-2** 的题眼是「产物的物质的量是反应物的总物质的量的 6/5」：反应物为 V₂O₅ + VOCl₃ + 3VCl₃ 共 5 份，产物 6 份 ⇒ 产物是 6VOCl₂。绿色的 VOCl₂ 是钒(IV) 的氧氯化物，其 V 的氧化数 (+4) 恰好是 V₂O₅(+5) 与 VCl₃(+3) 的**归中结果**——V₂O₅ 降 1、3VCl₃ 共升 3，电子账闭合。
- **2-1-3** 要从「材料与试剂的反应性」出发分别解释两种容器：对**石英**，VF₅ 是强氟化剂，能把 SiO₂ 中的 Si 拉出来成 SiF₄、V 被还原；对**铁**，VF₅ 有氧化性，把 Fe 氧化为 FeF₃ 的同时自身还原为 VF₄。铂对氟化物惰性，故只能用铂。
- 判分细则中「2VF₅ + 3Fe = 2VF₃ + 3FeF₃ 不得分」值得注意：这里 Fe 被氧化到 **+3** 是唯一被接受的终态，V 相应只降一级到 +4；写成 VF₃ 意味着 Fe 只到 +2，与 FeF₃ 的稳定性不符。
- 配平核对：2-1-1 V 4/4、O 8+2 = 10/10、S 12/12、Cl 12/12；2-1-2 V 6/6、O 6/6、Cl 12/12；2-1-3 石英式 V 4/4、F 20/20、Si 5/5、O 10/10，铁式 V 3/3、F 15/15、Fe 3/3。
