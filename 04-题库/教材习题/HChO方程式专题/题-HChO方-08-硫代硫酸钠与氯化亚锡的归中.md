# HChO方-08 硫代硫酸钠与氯化亚锡的归中（3 分）

> 来源：HChO 第6届培训班专题卷（化学方程式）05-02；bdwp《01方程式书写》练习 2

## 题目

**05-02** 将 Na₂S₂O₃ 溶液滴入盐酸酸化的 SnCl₂ 溶液中，至反应完全并稍过量，Sn 部分沉淀。最终 Sn 全部为 +4 价，S 的最高价态为 0 价，写出反应的方程式。

## 解答

2Na₂S₂O₃ + 6SnCl₂ + 9H₂O = SnS₂↓ + 5H₂SnO₃↓ + 2S↓ + 8HCl + 4NaCl（3 分）

> **校勘注**：源文作「2Na₂S₂O₃ + 6SnCl₂ + 9H₂O = SnS₂ + 5H₂SnO₃ + 2S + 8HCl」（3 分），Na 与 Cl 两项未配平（左 4 Na／12 Cl，右 0 Na／8 Cl）。此处据原子与电荷守恒补齐 4NaCl；等价写法为以 2S₂O₃²⁻ 起式、末项记 4Cl⁻。

## 解析要点

- 题面给了三条约束：Sn 全部 +4、S 最高价态为 0、Sn 部分沉淀 —— 三者联立才能定出产物组合（SnS₂ 中 S 为 −2，故还有单质 S(0)；H₂SnO₃ 是 Sn(IV) 的水解沉淀形态）。
- 电子守恒可自证：6 个 Sn(+2→+4) 失 12 e⁻；4 个 S 中 2 个降为 −2（得 8 e⁻）、2 个降为 0（得 4 e⁻），合计 12 e⁻ ✓。
- 陷阱是**把 S 一路写成 SO₄²⁻**：题面已限定"S 的最高价态为 0 价"，即硫只作氧化剂、不发生深度氧化。
