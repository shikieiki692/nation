# HChO方-14 次碘酸在硫酸与盐酸中的歧化差异（3 分）

## 题目

在 pH = 0 的稀硫酸中 HOI 可发生歧化反应，但在 pH = 0 的稀盐酸中 HOI 并不歧化。写出涉及的反应方程式。

## 解答

稀硫酸中：

5HOI = HIO₃ + 2I₂ + 2H₂O

3HOI = 2HI + HIO₃

稀盐酸中：

HOI + HCl = ICl + H₂O

HOI + 2Cl⁻ = ICl₂⁻ + H₂O

> **校勘注**：源文第四式作 HOI + 2Cl⁻ = ICl₂⁻ + H₂O，左端电荷 −2、右端 −1，氢亦不守恒；按介质应为 HOI + 2Cl⁻ + H⁺ = ICl₂⁻ + H₂O（等价分子式写法 HOI + 2HCl = ICl₂⁻ + H₂O + H⁺）。此处按守恒补全。

## 解析要点

- 题目的对照组设计在于**酸根阴离子的反应性差异**：SO₄²⁻ 是「旁观者」，Cl⁻ 却是**强配位性还原剂**。在硫酸中 HOI 只发生自身的氧化还原歧化（I 的 +1 价同时向 +5 与 −1/0 两个方向分岔）；在盐酸中 Cl⁻ 抢先与 I(+1) 结合为 ICl，把 HOI 从歧化通道上「拉走」。
- 稀硫酸中的两个式子分别对应「歧化到 I₂」与「歧化到 I⁻」两条支路：5HOI 式得 HIO₃ 与 I₂；3HOI 式得 HI 与 HIO₃。两条支路并存，说明歧化产物分布不是唯一的。
- 稀盐酸中的两个式子只是 ICl 的**分子式写法**与**离子式写法**之别，其价值在于提示：一旦生成 ICl，碘的氧化数就被锁定在 +1，无法再升到 +5，歧化随之关闭。
- 配平核对：5HOI 式 I 5/5、O 5/5、H 5/5；3HOI 式 I 3/3、O 3/3、H 3/3。
