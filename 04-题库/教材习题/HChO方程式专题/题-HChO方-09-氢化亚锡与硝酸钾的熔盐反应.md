# HChO方-09 氢化亚锡与硝酸钾的熔盐反应（3 分）

> 来源：HChO 第22届培训班综合卷 第3题3-2；bdwp《01方程式书写》练习 2

## 题目

**3-2** Sn₂H₂ 与熔融的 KNO₃ 反应，生成偏亚锡酸钠的同时，放出 NO₂。写出反应的方程式。

## 解答

Sn₂H₂ + 5KNO₃ = 2K₂SnO₂ + KNO₂ + 4NO₂ + H₂O（3 分）

> 评分细则：写成 Sn₂H₂ + 6KNO₃ = 2K₂SnO₂ + 6NO₂ + 2KOH 得 1 分。
> **校勘注**：题面作「偏亚锡酸钠」，而解答与体系均为钾盐 K₂SnO₂，疑源文"钠"为"钾"之误，题面照录。

## 解析要点

- 第一步是**确定偏亚锡酸盐的化学式**：应为 K₂SnO₂，而不是 K₄SnO₃ 或 K₂Sn(OH)₄。判据是熔盐体系不水合、且非氧化物体系不会出现 SnO₃⁴⁻（即使题面只写"氧化至 +2 价"也足以定下）。
- 第二步是"**先写最简式、再加合副反应**"：先得 Sn₂H₂ + 6KNO₃ = 2K₂SnO₂ + 6NO₂ + 2KOH；再把 2NO₂ + 2KOH = KNO₂ + KNO₃ + H₂O 叠加，消去 KOH，得到最终式。这也是 1 分与 3 分的分界。
- 隐含条件是 NO₂ 在碱性熔盐中**会回头歧化**（生成 KNO₂ 与 KNO₃），故产物中不能保留 KOH。
