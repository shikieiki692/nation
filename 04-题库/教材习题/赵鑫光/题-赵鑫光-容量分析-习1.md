# 题-赵鑫光-容量分析-习1：Cl₂歧化反应配平

## 题目

Cl₂ 歧化反应中，若 ClO⁻ 和 ClO₃⁻ 的物质的量之比为 1:2，计算歧化反应中 Cl₂ 与 NaOH 反应的总化学方程式中 Cl₂、NaOH、NaCl、NaClO、NaClO₃ 的计量系数。

---

## 参考答案

设 ClO⁻ 为 1 mol，ClO₃⁻ 为 2 mol。

Cl₂ → ClO⁻：Cl 从 0 价升至 +1 价，失去 1e⁻
Cl₂ → ClO₃⁻：Cl 从 0 价升至 +5 价，失去 5e⁻
Cl₂ → Cl⁻：Cl 从 0 价降至 -1 价，得到 1e⁻

氧化半反应失去电子总数：1×1 + 2×5 = 11 mol e⁻

还原半反应需得到 11 mol e⁻，即生成 11 mol Cl⁻。

Cl 原子守恒：ClO⁻(1) + ClO₃⁻(2) + Cl⁻(11) = 14 个 Cl 原子 = 7 mol Cl₂

Na 原子守恒：NaOH = NaCl(11) + NaClO(1) + NaClO₃(2) = 14 mol

H 原子守恒：H₂O = 14/2 = 7 mol

**配平方程式：**

$$5\text{Cl}_2 + 12\text{NaOH} = 8\text{NaCl} + \text{NaClO} + 2\text{NaClO}_3 + 6\text{H}_2\text{O}$$

**答案**：Cl₂ = 5, NaOH = 12, NaCl = 8, NaClO = 1, NaClO₃ = 2

---

## 知识点映射

- 核心考点：歧化反应的配平
- 关键步骤：根据产物比例确定电子转移数，利用得失电子守恒配平
- 注意事项：歧化反应中同一元素既被氧化又被还原
