# 赵鑫光·配位化合物·例16 K₃[Fe(C₂O₄)₃]制备

## 题目

实验中以FeSO₄·7H₂O和K₂C₂O₄为原料制备K₃[Fe(C₂O₄)₃]·3H₂O。

**(1)** 写出反应方程式。
**(2)** 说明H₂O₂的作用。
**(3)** 为什么产物呈绿色？

## 解答

**(1)** 制备反应分两步：

第一步：FeSO₄ + K₂C₂O₄ → FeC₂O₄↓ + K₂SO₄

第二步：2FeC₂O₄ + H₂O₂ + 3K₂C₂O₄ → 2K₃[Fe(C₂O₄)₃] + 2KOH

或总反应：
2FeSO₄ + H₂O₂ + 6K₂C₂O₄ + H₂SO₄ → 2K₃[Fe(C₂O₄)₃] + 2K₂SO₄ + 2H₂O

**(2)** H₂O₂的作用是**氧化剂**，将Fe²⁺氧化为Fe³⁺：

$$\text{Fe}^{2+} + \text{H}_2\text{O}_2 + 2\text{H}^+ \rightarrow \text{Fe}^{3+} + 2\text{H}_2\text{O}$$

**(3)** [Fe(C₂O₄)₃]³⁻中Fe³⁺为d⁵低自旋构型（C₂O₄²⁻为中强场配体）：
- t₂g⁵eg⁰ → 有一个d-d跃迁在可见光区
- 草酸根到Fe³⁺的电荷转移（LMCT）也对颜色有贡献
- 绿色是由于**吸收红光和蓝光，透过绿光**
