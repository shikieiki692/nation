# 赵鑫光·热力学·例3 Li+冰→LiOH

## 题目

将10g金属锂置于100g 0℃的冰块上，确定100℃时由溶液中沉淀的氢氧化锂一水合物的质量。

反应：$2\text{Li}(s) + 2\text{H}_2\text{O}(l) = 2\text{LiOH}(s) + \text{H}_2(g)$，$\Delta H = -398.2$ kJ/mol

已知：冰的熔化热330 kJ/kg，水的比热4.200 kJ/(kg·K)，水的汽化热2300 kJ/kg，LiOH的比热49.58 J/(mol·K)，100℃时一水合LiOH溶解度19.1g

## 解答

反应放热：$Q = 10/7/2 \times 398.2 = 284.43$ kJ

消耗水：$m_1 = 10/7 \times 18 = 25.71$ g

生成LiOH：$m_2 = 10/7 \times 24 = 34.28$ g（$n_2 = 1.43$ mol）

热量分配：熔冰33 kJ；水升温31.20 kJ；LiOH升温7.09 kJ

剩余热量：$Q_4 = 284.43 - 33 - 31.2 - 7.09 = 213.14$ kJ

可蒸发水量：$213.14/2300 \times 1000 = 92.7$ g，而所剩水量仅74.29 g

**结论**：产物中为氢氧化锂固体而无一水合物。
