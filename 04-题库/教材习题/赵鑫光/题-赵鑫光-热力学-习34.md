# 赵鑫光·热力学·习34 NH₃质子亲和焓Born-Haber

## 题目

已知：$\Delta_f H_m^{\ominus}(\text{NH}_3,g) = -46.04$ kJ/mol，$\Delta_f H_m^{\ominus}(\text{NH}_4\text{Cl},s) = -314.4$ kJ/mol，NH₄Cl晶格能663 kJ/mol，H₂键焓436 kJ/mol，Cl₂键焓243 kJ/mol，H电离能1312 kJ/mol，Cl电子亲和能348.7 kJ/mol。计算气态氨的质子亲和焓。

## 解答

设计Born-Haber循环：

$\Delta_f H_m^{\ominus}(\text{NH}_4\text{Cl}) = \Delta_f H_m^{\ominus}(\text{NH}_3) + \Delta_{PA}H + \Delta_{IE}H(\text{H}) + \Delta_{sub}H(\text{Cl}) + \Delta_{EA}H(\text{Cl}) - U$

其中$\Delta_{sub}H(\text{Cl}) = \frac{1}{2} \times 243 = 121.5$ kJ/mol

$-314.4 = -46.04 + \Delta_{PA}H + 1312 + 121.5 + (-348.7) - 663$

$\Delta_{PA}H = -890.2$ kJ/mol
