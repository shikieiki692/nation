# 赵鑫光·热力学·习28 C-H和C-C键焓计算

## 题目

已知：$\Delta_f H_m^{\ominus}(\text{CH}_4) = -74.8$ kJ/mol，$\Delta_f H_m^{\ominus}(\text{C}_2\text{H}_6) = -84.7$ kJ/mol，C(石墨)升华热716.7 kJ/mol，H₂键焓436 kJ/mol。计算C—H和C—C键的键焓。

## 解答

C—H键焓：$(716.7 - (-74.8) + 2 \times 436)/4 = 1664/4 = 416$ kJ/mol

C—C键焓：$(2 \times 716.7 - (-84.7) + 3 \times 436) - 6 \times 416 = 330$ kJ/mol
