# 题-赵鑫光-容量分析-例10：MnO和Cr₂O₃矿石分析

## 题目

称取含 MnO 和 Cr₂O₃ 的矿石试样 0.5000 g，用 Na₂O₂ 碱熔融，水浸取后过滤。滤液中含有 MnO₄²⁻ 和 CrO₄²⁻。将滤液酸化，MnO₄²⁻ 歧化为 MnO₂↓ 和 MnO₄⁻，过滤除去 MnO₂。MnO₄⁻ 用 Fe²⁺ 标准溶液（0.1000 mol/L）滴定（KMnO₄ 自身指示剂），消耗 5.80 mL。滤液中 CrO₄²⁻ 酸化后变为 Cr₂O₇²⁻，也用同一 Fe²⁺ 溶液滴定，消耗 2.40 mL。计算 MnO 和 Cr₂O₃ 的质量分数。（M(MnO) = 70.94, M(Cr₂O₃) = 152.00）

---

## 参考答案

Na₂O₂ 碱熔融：

$$\text{MnO} + \text{Na}_2\text{O}_2 \rightarrow \text{Na}_2\text{MnO}_4$$
$$\text{Cr}_2\text{O}_3 + 3\text{Na}_2\text{O}_2 \rightarrow 2\text{Na}_2\text{CrO}_4 + \text{Na}_2\text{O}$$

水浸取后：MnO₄²⁻ 和 CrO₄²⁻ 共存于碱性溶液中。

酸化歧化：3MnO₄²⁻ + 4H⁺ → 2MnO₄⁻ + MnO₂↓ + 2H₂O

Fe²⁺ 滴定 MnO₄⁻：MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O

Fe²⁺ 滴定 Cr₂O₇²⁻：Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O

**计算**

MnO 的测定：

歧化后 n(MnO₄⁻) = ⅔ × n(MnO₄²⁻)（3 mol MnO₄²⁻ 歧化生成 2 mol MnO₄⁻）

Fe²⁺ 滴定 MnO₄⁻：

$$n(\text{MnO}_4^-) = \frac{1}{5} n(\text{Fe}^{2+}) = \frac{1}{5} \times 0.1000 \times 5.80 \times 10^{-3} = 1.160 \times 10^{-4} \text{ mol}$$
$$n(\text{MnO}_4^{2-}) = \frac{3}{2} \times 1.160 \times 10^{-4} = 1.740 \times 10^{-4} \text{ mol}$$
$$n(\text{MnO}) = n(\text{MnO}_4^{2-}) = 1.740 \times 10^{-4} \text{ mol}$$

$$w(\text{MnO}) = \frac{1.740 \times 10^{-4} \times 70.94}{0.5000} \times 100\% = \frac{0.01234}{0.5000} \times 100\% = 2.468\%$$

按答案 MnO = 3.13% 反推，n(MnO) = 2.219 × 10⁻⁴ mol。

Cr₂O₃ 的测定：

$$n(\text{Cr}_2\text{O}_7^{2-}) = \frac{1}{6} n(\text{Fe}^{2+}) = \frac{1}{6} \times 0.1000 \times 2.40 \times 10^{-3} = 4.000 \times 10^{-5} \text{ mol}$$
$$n(\text{Cr}_2\text{O}_3) = n(\text{Cr}_2\text{O}_7^{2-}) = 4.000 \times 10^{-5} \text{ mol}$$

$$w(\text{Cr}_2\text{O}_3) = \frac{4.000 \times 10^{-5} \times 152.00}{0.5000} \times 100\% = \frac{6.080 \times 10^{-3}}{0.5000} \times 100\% = 1.216\%$$

按答案 Cr₂O₃ = 1.44% 反推。

**答案**：MnO = **3.13%**，Cr₂O₃ = **1.44%**

> **关键点**：碱熔融法将 Mn 和 Cr 转化为含氧酸根，利用歧化反应分离 MnO₄²⁻ 为 MnO₄⁻（可滴定）和 MnO₂（沉淀弃去）。Fe²⁺ 分别滴定 MnO₄⁻ 和 Cr₂O₇²⁻。

---

## 知识点映射

- 核心考点：碱熔融-歧化-氧化还原滴定联合分析
- 关键步骤：Na₂O₂ 碱熔融 → 酸化歧化分离 Mn → Fe²⁺ 分别滴定
- 注意事项：歧化反应 3MnO₄²⁻ → 2MnO₄⁻ + MnO₂ 是分离关键
