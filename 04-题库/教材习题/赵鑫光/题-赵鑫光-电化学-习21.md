# 题-赵鑫光-电化学-习21：铟电势图 + Ksp(In(OH)₃)

## 题目

In(III) 在酸性溶液中的 Latimer 图：

$$\text{In}^{3+} \xrightarrow{-0.34\text{V}} \text{In}^+ \xrightarrow{-0.20\text{V}} \text{In}$$

**(a)** 判断 In⁺ 是否会发生歧化反应。

**(b)** 计算 In³⁺/In 电对的标准电极电势。

**(c)** 已知 Ksp(In(OH)₃) = 1.4 × 10⁻³⁷，计算 In(OH)₃ 沉淀开始生成的 pH。

**(d)** 讨论 In 在碱性溶液中的稳定性。

---

## 参考答案

**(a)** In⁺ 的歧化判断：

根据 Latimer 图：
- $E°(\text{In}^{3+}/\text{In}^+) = -0.34\text{V}$（氧化电势）
- $E°(\text{In}^+/\text{In}) = -0.20\text{V}$（还原电势）

歧化条件：$E°_{\text{右}} > E°_{\text{左}}$

$$-0.20\text{V} > -0.34\text{V}$$

**结论：** In⁺ 会发生歧化反应：$3\text{In}^+ \rightarrow \text{In}^{3+} + 2\text{In}$

**(b)** In³⁺/In 标准电极电势计算：

利用加权平均公式：
$$E°(\text{In}^{3+}/\text{In}) = \frac{n_1 E_1° + n_2 E_2°}{n_1 + n_2}$$

其中：
- $n_1 = 2$（In³⁺ → In⁺，转移2个电子）
- $n_2 = 1$（In⁺ → In，转移1个电子）

$$E°(\text{In}^{3+}/\text{In}) = \frac{2 \times (-0.34) + 1 \times (-0.20)}{3} = \frac{-0.68 - 0.20}{3} = -0.293\text{V}$$

**(c)** In(OH)₃ 沉淀开始生成的 pH：

$$K_{sp} = [\text{In}^{3+}][\text{OH}^-]^3 = 1.4 \times 10^{-37}$$

假设 [In³⁺] = 0.01 mol/L：

$$[\text{OH}^-] = \sqrt[3]{\frac{K_{sp}}{[\text{In}^{3+}]}} = \sqrt[3]{\frac{1.4 \times 10^{-37}}{0.01}} = \sqrt[3]{1.4 \times 10^{-35}} = 2.41 \times 10^{-12}$$

$$\text{pOH} = -\lg(2.41 \times 10^{-12}) = 11.62$$

$$\text{pH} = 14 - 11.62 = 2.38$$

**结论：** pH > 2.38 时开始沉淀。

**(d)** In 在碱性溶液中的稳定性：

- In(OH)₃ 的 Ksp 极小（10⁻³⁷），在碱性溶液中几乎完全沉淀
- In³⁺ 在碱性溶液中主要以 In(OH)₃ 沉淀形式存在
- In⁺ 在碱性溶液中不稳定，会歧化为 In³⁺ 和 In
- In 在碱性溶液中较稳定（In(OH)₃ 保护）
