# 赵鑫光·配位化合物·综12 磁矩解释

## 题目

解释为什么[Fe(CN)₆]⁴⁻的磁矩为0 BM，而[Fe(H₂O)₆]²⁺的磁矩为4.90 BM。

## 解答

**[Fe(CN)₆]⁴⁻：**
- Fe²⁺为d⁶，CN⁻为强场配体（△o > P）
- 低自旋排布：t₂g⁶eg⁰
- 所有6个电子成对 → 未成对电子数 = 0
- μ = √(0×2) = 0 BM（抗磁性）

**[Fe(H₂O)₆]²⁺：**
- Fe²⁺为d⁶，H₂O为弱场配体（△o < P）
- 高自旋排布：t₂g⁴eg²
- 有4个未成对电子
- μ = √(4×(4+2)) = √24 ≈ 4.90 BM（顺磁性）
