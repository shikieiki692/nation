【例 4】写出下列各电池的正、负极电极反应式和电池反应方程式

(1) $\mathrm{Pt}, \mathrm{H}_{2} \mid \mathrm{HCl} \mid \mathrm{KCl} \mid \mathrm{Hg}_{2} \mathrm{Cl}_{2}(\mathrm{s}), \mathrm{Hg}$ ; (2) $\mathrm{Cu} \mid \mathrm{Cu}^{2+} \mid \mid \mathrm{I}^{-} \mid \mathrm{CuI}(\mathrm{s}), \mathrm{Cu}$ ;

(3) $\mathrm{Pt}, \mathrm{CuI(s)}|\mathrm{Cu}^{2+}||\mathrm{I}^{-}|\mathrm{CuI(s)}, \mathrm{Cu}$ ; (4) $\mathrm{Fe}, \mathrm{Fe(OH)}_2|\mathrm{OH}^-||\mathrm{Fe}^{2+}|\mathrm{Fe}$ ;

(5) $\mathrm{Li(s)}\mid \mathrm{Li}^{+} - \mathrm{Li}_{2}\mathrm{Mn}_{2}\mathrm{O}_{4}\mid \mathrm{LiMn}_{2}\mathrm{O}_{4}(\mathrm{s})$ (6) $\mathrm{Pt,C_3H_8|Y_2O_3 / ZrO_2|O_2(p^{\ominus}),Pt;}$

(7) $\mathrm{Pt}, \mathrm{CH}_3\mathrm{OH} \mid \mathrm{Na}_2\mathrm{CO}_3 \mid \mathrm{CO}_2 \mid \mathrm{O}_2, \mathrm{Pt}$ ; (8) $\mathrm{Pt}, \mathrm{H}_2 \mid \mathrm{KOH} \mid \mathrm{NiO(OH)}, \mathrm{Ni(OH)}_2 \mid \mathrm{Ni}$ .

## 参考答案（提炼版，供参考）

## 参考答案

### (1) Pt, H₂ | HCl | KCl | Hg₂Cl₂, Hg（甘汞电极）

$$\text{负极：} \text{H}_2 - 2e^- \rightarrow 2\text{H}^+$$
$$\text{正极：} \text{Hg}_2\text{Cl}_2 + 2e^- \rightarrow 2\text{Hg} + 2\text{Cl}^-$$

### (2) Cu | Cu²⁺ || I⁻ | CuI, Cu

$$\text{负极：} \text{Cu} - e^- \rightarrow \text{Cu}^+$$
$$\text{正极：} \text{Cu}^{2+} + e^- + \text{I}^- \rightarrow \text{CuI} \downarrow$$

### (3) CuI 电极

利用 CuI/Cu 电对的电极电势，结合 Ksp(CuI) 计算实际电势：

$$E = Eθ + \frac{0.0592}{n}\lg\frac{1}{K_{sp}}$$

### (4) Fe 浓差电池

两极均为 Fe 电极，分别浸于不同浓度的 Fe²⁺ 溶液中：

$$E = Eθ + \frac{RT}{nF}\ln\frac{c_1(\text{Fe}^{2+})}{c_2(\text{Fe}^{2+})}$$

对于浓差电池，$Eθ = 0$，因此：

$$E = \frac{0.0592}{2}\lg\frac{c_1}{c_2}$$

### (5) 锂离子电池

$$\text{负极：} \text{LiC}_6 - e^- \rightarrow \text{Li}^+ + \text{C}_6$$
$$\text{正极：} \text{Li}_{1-x}\text{CoO}_2 + x\text{Li}^+ + xe^- \rightarrow \text{LiCoO}_2$$

### (6) 固体氧化物燃料电池（丙烷）

$$\text{阳极：} \text{C}_3\text{H}_8 + 10\text{O}^{2-} - 20e^- \rightarrow 3\text{CO}_2 + 4\text{H}_2\text{O}$$
$$\text{阴极：} 5\text{O}_2 + 20e^- \rightarrow 10\text{O}^{2-}$$

### (7) 熔融碳酸盐燃料电池（甲醇）

$$\text{阳极：} \text{CH}_3\text{OH} + 3\text{CO}_3^{2-} - 6e^- \rightarrow 4\text{CO}_2 + 2\text{H}_2\text{O}$$
$$\text{阴极：} \frac{3}{2}\text{O}_2 + 6e^- + 3\text{CO}_2 \rightarrow 3\text{CO}_3^{2-}$$

### (8) Ni-MH 电池

$$\text{负极：} \text{MH} + \text{OH}^- - e^- \rightarrow \text{M} + \text{H}_2\text{O}$$
$$\text{正极：} \text{NiOOH} + \text{H}_2\text{O} + e^- \rightarrow \text{Ni(OH)}_2 + \text{OH}^-$$

## 知识点映射

- 核心考点：各类原电池的电极反应书写
- 电池类型：甘汞电极、浓差电池、锂离子电池、燃料电池、Ni-MH电池
- 关键技能：根据电池符号判断正负极，正确书写电极反应
