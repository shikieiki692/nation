# 赵鑫光·晶体结构·习33 分子点群分类

## 分子点群分类 `[决赛]`

**题目**：将以下分子归入正确的点群：菲、$\mathrm{P_4O_5}$、碘仿、环己烷、$\mathrm{B_2H_6}$、乙烷、$\mathrm{C_{60}}$ 等。

---

### 解答

| 分子 | 点群 |
|:---|:---|
| 菲 (phenanthrene) | $C_{2v}$ |
| 碘仿 ($\mathrm{CHI_3}$) | $C_{3v}$ |
| 环己烷（椅式） | $D_{3d}$ |
| $\mathrm{B_2H_6}$（乙硼烷） | $D_{2h}$ |
| 乙烷（交叉式） | $D_{3d}$ |
| $\mathrm{C_{60}}$ | $I_h$ |

**点群判断方法**：
1. 找最高次旋转轴（主轴）
2. 判断是否有垂直于主轴的 $C_2$ 轴（D 群）或无（C 群）
3. 判断是否有水平镜面 $\sigma_h$ 或对角镜面 $\sigma_d$
4. 判断是否有反演中心 $i$
