对于连续反应 $\text{A} \xrightarrow{k_1} \text{B} \xrightarrow{k_2} \text{C}$，其中 $k_1 = 0.10$ min⁻¹，$k_2 = 0.05$ min⁻¹，$[\text{A}]_0 = 1.0$ mol/L，$[\text{B}]_0 = [\text{C}]_0 = 0$。

(1) 写出中间体B的浓度随时间变化的表达式。

(2) 计算B达到最大浓度的时间和最大浓度值。

## 答案

**(1)** A的一级衰减：

$$[\text{A}] = [\text{A}]_0 e^{-k_1 t}$$

B的浓度方程（B由A生成、自身衰减）：

$$[\text{B}] = \frac{k_1 [\text{A}]_0}{k_2 - k_1}(e^{-k_1 t} - e^{-k_2 t})$$

代入数值（$k_1 = 0.10$，$k_2 = 0.05$，$k_2 < k_1$）：

$$[\text{B}] = \frac{0.10 \times 1.0}{0.05 - 0.10}(e^{-0.10t} - e^{-0.05t}) = -2.0(e^{-0.10t} - e^{-0.05t})$$

$$[\text{B}] = 2.0(e^{-0.05t} - e^{-0.10t})$$

**(2)** B最大浓度时 $d[\text{B}]/dt = 0$：

$$k_1 e^{-k_1 t_{\max}} = k_2 e^{-k_2 t_{\max}}$$

$$\frac{k_1}{k_2} = e^{(k_1 - k_2)t_{\max}}$$

$$t_{\max} = \frac{\ln(k_1/k_2)}{k_1 - k_2} = \frac{\ln(0.10/0.05)}{0.10 - 0.05} = \frac{0.6931}{0.05} = 13.86 \text{ min}$$

$$[\text{B}]_{\max} = 2.0(e^{-0.05 \times 13.86} - e^{-0.10 \times 13.86}) = 2.0(e^{-0.693} - e^{-1.386}) = 2.0(0.500 - 0.250) = 0.50 \text{ mol/L}$$
