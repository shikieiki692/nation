7. 铅一酸电池是广泛使用在汽车和作为动力的便携式电池。目前在动力汽车的电池发展中，最有前途的是轻便型可充电锂离子电池。

一个铅一酸电池表示如下： $\mathrm{Pb(s)}|\mathrm{PbSO}_4(\mathrm{s})|\mathrm{H}_2\mathrm{SO}_4(\mathrm{aq})|\mathrm{PbSO}_4(\mathrm{s})|\mathrm{PbO}_2|\mathrm{Pb(s)}$ 。一个锂电池表示如下： $\mathrm{Li(s)}|\mathrm{Li}^+$ 一导电固体电解质(s)| $\mathrm{LiMn_2O_4(s)}$ 。

在放电过程中，形成了嵌入物 $\mathrm{Li}_2\mathrm{Mn}_2\mathrm{O}_4$ ，在充电过程中，转变成 $\mathrm{Li(s)}$ 和 $\mathrm{LiMn_2O_4}$

(1) 写出在铅一酸电池放电过程中电极上的反应式。

负极：\_\_\_\_正极：\_\_\_\_

(2) 写出在锂离子电池放电过程中电极上的电化学反应式。

负极：\_\_\_\_正极：\_\_\_\_

(3) 写出在 $Li_{2}Mn_{2}O_{4}$ 尖晶石型结构中锂离子和锰离子的配位数。

## 参考答案（提炼版，供参考）

## 参考答案

**(a)** 铅酸蓄电池放电反应：

负极：$\text{Pb} + \text{SO}_4^{2-} - 2e^- \rightarrow \text{PbSO}_4$

正极：$\text{PbO}_2 + 4\text{H}^+ + \text{SO}_4^{2-} + 2e^- \rightarrow \text{PbSO}_4 + 2\text{H}_2\text{O}$

总反应：$\text{Pb} + \text{PbO}_2 + 2\text{H}_2\text{SO}_4 \rightarrow 2\text{PbSO}_4 + 2\text{H}_2\text{O}$

**(b)** 锂离子电池放电反应：

负极：$\text{LiC}_6 - e^- \rightarrow \text{Li}^+ + \text{C}_6$

正极：$\text{Li}_{1-x}\text{CoO}_2 + x\text{Li}^+ + xe^- \rightarrow \text{LiCoO}_2$

总反应：$\text{LiC}_6 + \text{CoO}_2 \rightarrow \text{C}_6 + \text{LiCoO}_2$

**(c)** 电池性能比较：

| 参数 | 铅酸电池 | 锂离子电池 |
|------|----------|------------|
| 电压 | 2.0V | 3.6-3.7V |
| 能量密度 | 30-40 Wh/kg | 150-250 Wh/kg |
| 循环寿命 | 200-500次 | 500-1000次 |
| 自放电 | 5%/月 | 1-2%/月 |

**(d)** 铅酸电池理论比能量：

总反应：$\text{Pb} + \text{PbO}_2 + 2\text{H}_2\text{SO}_4 \rightarrow 2\text{PbSO}_4 + 2\text{H}_2\text{O}$

- $Eθ = 2.04\text{V}$
- $n = 2$
- 总质量：$M = 207 + 239 + 2\times98 = 642\text{ g/mol}$

$$W = \frac{nFEθ}{M} = \frac{2 \times 96485 \times 2.04}{642} = 613\text{ Wh/kg}$$

实际比能量约为理论值的 30-40%，即 180-250 Wh/kg。
