# 题-赵鑫光-电化学-习7：铅酸电池与锂电池

## 题目

**(a)** 写出铅酸蓄电池放电时的电极反应和总反应。

**(b)** 写出锂离子电池（LiCoO₂/C₆ 体系）放电时的电极反应。

**(c)** 比较两种电池的能量密度、电压和循环寿命。

**(d)** 计算铅酸电池的理论比能量（Wh/kg）。

---

## 参考答案

**(a)** 铅酸蓄电池放电反应：

负极：$\text{Pb} + \text{SO}_4^{2-} - 2e^- \rightarrow \text{PbSO}_4$

正极：$\text{PbO}_2 + 4\text{H}^+ + \text{SO}_4^{2-} + 2e^- \rightarrow \text{PbSO}_4 + 2\text{H}_2\text{O}$

总反应：$\text{Pb} + \text{PbO}_2 + 2\text{H}_2\text{SO}_4 \rightarrow 2\text{PbSO}_4 + 2\text{H}_2\text{O}$

**(b)** 锂离子电池放电反应：

负极：$\text{LiC}_6 - e^- \rightarrow \text{Li}^+ + \text{C}_6$

正极：$\text{Li}_{1-x}\text{CoO}_2 + x\text{Li}^+ + xe^- \rightarrow \text{LiCoO}_2$

总反应：$\text{LiC}_6 + \text{CoO}_2 \rightarrow \text{C}_6 + \text{LiCoO}_2$

**(c)** 电池性能比较：

| 参数 | 铅酸电池 | 锂离子电池 |
|------|----------|------------|
| 电压 | 2.0V | 3.6-3.7V |
| 能量密度 | 30-40 Wh/kg | 150-250 Wh/kg |
| 循环寿命 | 200-500次 | 500-1000次 |
| 自放电 | 5%/月 | 1-2%/月 |

**(d)** 铅酸电池理论比能量：

总反应：$\text{Pb} + \text{PbO}_2 + 2\text{H}_2\text{SO}_4 \rightarrow 2\text{PbSO}_4 + 2\text{H}_2\text{O}$

- $E° = 2.04\text{V}$
- $n = 2$
- 总质量：$M = 207 + 239 + 2\times98 = 642\text{ g/mol}$

$$W = \frac{nFE°}{M} = \frac{2 \times 96485 \times 2.04}{642} = 613\text{ Wh/kg}$$

实际比能量约为理论值的 30-40%，即 180-250 Wh/kg。
