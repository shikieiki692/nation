# 赵鑫光·配位化合物·综8 MA₂B₂八面体异构体

## 题目

画出八面体配合物MA₂B₂（A≠B）的所有几何异构体，并标记哪些有旋光异构。

## 解答

MA₂B₂型八面体配合物有**2种几何异构体**：

**(1) 顺式（cis-）：**
```
    A       A
     \     /
      M
     /     \
    B       B
```
- A和A相邻，夹角90°
- 无旋光异构（有对称面）

**(2) 反式（trans-）：**
```
    A       B
     \     /
      M
     /     \
    B       A
```
- A和A对位，夹角180°
- 无旋光异构（有对称中心）

**注意：** MA₂B₂型无旋光异构。旋光异构需要无对称面、无对称中心的结构，如[Co(en)₃]³⁺。
