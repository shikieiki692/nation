# 赵鑫光·热力学·习29 丙烯燃烧焓与生成焓

## 题目

丙烯加氢生成丙烷$\Delta_r H_m^{\ominus} = -123.9$ kJ/mol，丙烷恒容燃烧热$Q_v = -2213.0$ kJ/mol。

已知$\Delta_f H_m^{\ominus}(\text{CO}_2) = -393.5$ kJ/mol，$\Delta_f H_m^{\ominus}(\text{H}_2\text{O},l) = -286.0$ kJ/mol

(1)求丙烯标准摩尔燃烧焓；(2)求丙烯标准摩尔生成焓。

## 解答

(1) $\Delta_r H_{m2}^{\ominus} = -2213.0 + (-3) \times 8.314 \times 10^{-3} \times 298 = -2220.4$ kJ/mol

丙烯燃烧：①+②-③

$\Delta_c H_m^{\ominus} = -123.9 + (-2220.4) - (-286.0) = -2058.3$ kJ/mol

(2) $\Delta_f H_m^{\ominus}(\text{C}_3\text{H}_6) = 3 \times (-286.0) + 3 \times (-393.5) - (-2058.3) = 19.8$ kJ/mol
