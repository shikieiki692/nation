## 参考答案

**(1)** $4\text{FeS}_2 + 11\text{O}_2 = 2\text{Fe}_2\text{O}_3 + 8\text{SO}_2$

**(2)** $3\text{Cu}_2\text{S} + 16\text{HNO}_3 = 6\text{Cu(NO}_3)_2 + 4\text{NO} + 3\text{S} + 8\text{H}_2\text{O}$

**(3)** $\text{P}_4 + 3\text{NaOH} + 3\text{H}_2\text{O} = 3\text{NaH}_2\text{PO}_2 + \text{PH}_3$

**(4)** $3\text{As}_2\text{S}_3 + 28\text{HNO}_3 + 4\text{H}_2\text{O} = 6\text{H}_3\text{AsO}_4 + 9\text{H}_2\text{SO}_4 + 28\text{NO}$

**(5)** $2\text{KMnO}_4 + 16\text{HCl} = 2\text{KCl} + 2\text{MnCl}_2 + 5\text{Cl}_2 + 8\text{H}_2\text{O}$

**(6)** $\text{K}_2\text{Cr}_2\text{O}_7 + 3\text{H}_2\text{S} + 4\text{H}_2\text{SO}_4 = \text{Cr}_2(\text{SO}_4)_3 + 3\text{S} + \text{K}_2\text{SO}_4 + 7\text{H}_2\text{O}$

**(7)** $2\text{Na}_2\text{S}_2\text{O}_3 + \text{I}_2 = \text{Na}_2\text{S}_4\text{O}_6 + 2\text{NaI}$

**(8)** $2\text{KClO}_3 + 4\text{HCl} = 2\text{KCl} + 2\text{ClO}_2 + \text{Cl}_2 + 2\text{H}_2\text{O}$

## 知识点映射

- 核心考点：氧化数法配平氧化还原反应
- 关键步骤：标出氧化数变化，使升降总数相等
- 常见类型：歧化反应、归中反应、一般氧化还原反应
