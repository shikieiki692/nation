# 题-赵鑫光-电化学-习25：Cu²⁺ + Cu + 2Cl⁻ = 2CuCl 平衡

## 题目

$$\text{Cu}^{2+} + \text{Cu} + 2\text{Cl}^- \rightleftharpoons 2\text{CuCl} \downarrow$$

**(a)** 利用以下数据计算该反应的平衡常数 K：

- E°(Cu²⁺/Cu⁺) = 0.153V
- E°(Cu⁺/Cu) = 0.521V
- Ksp(CuCl) = 1.7 × 10⁻⁷

**(b)** 当 [Cl⁻] = 1M 时，计算 Cu²⁺ 完全转化为 CuCl 所需的最低 [Cl⁻]。

**(c)** 讨论该反应在铜的湿法冶金中的应用。

**(d)** 从电极电势角度解释为什么 CuCl 沉淀能推动反应正向进行。

---

## 参考答案

**(a)** 平衡常数 K 计算：

反应可分解为：
1. $\text{Cu}^{2+} + e^- \rightarrow \text{Cu}^+$（E° = 0.153V）
2. $\text{Cu}^+ + e^- \rightarrow \text{Cu}$（E° = 0.521V）
3. $\text{Cu}^+ + \text{Cl}^- \rightarrow \text{CuCl}$（K = 1/Ksp）

总反应：$\text{Cu}^{2+} + \text{Cu} + 2\text{Cl}^- \rightarrow 2\text{CuCl}$

$$E°_{\text{cell}} = E°(\text{Cu}^{2+}/\text{Cu}^+) - E°(\text{Cu}^+/\text{Cu}) = 0.153 - 0.521 = -0.368\text{V}$$

$$\lg K = \frac{nE°_{\text{cell}}}{0.0592} + 2\lg\frac{1}{K_{sp}}$$

$$\lg K = \frac{2 \times (-0.368)}{0.0592} + 2\lg\frac{1}{1.7 \times 10^{-7}}$$

$$\lg K = -12.43 + 2 \times 6.77 = -12.43 + 13.54 = 1.11$$

$$K = 10^{1.11} = 12.9$$

**(b)** 最低 [Cl⁻] 计算：

当 [Cu²⁺] = 0.01 mol/L 时：

$$K = \frac{[\text{CuCl}]^2}{[\text{Cu}^{2+}][\text{Cu}][\text{Cl}^-]^2}$$

假设 [CuCl] ≈ 1（沉淀），[Cu] = 1（固体）：

$$12.9 = \frac{1}{0.01 \times [\text{Cl}^-]^2}$$

$$[\text{Cl}^-]^2 = \frac{1}{12.9 \times 0.01} = 7.75$$

$$[\text{Cl}^-] = 2.78\text{ M}$$

**(c)** 湿法冶金应用：

- **铜的精炼**：利用 CuCl 沉淀纯化粗铜
- **铜的提取**：从矿石中浸出铜后，用 Cl⁻ 沉淀 CuCl
- **铜的回收**：从废液中回收铜
- **优势**：CuCl 沉淀易于过滤和分离

**(d)** CuCl 沉淀推动反应的解释：

- **热力学角度**：CuCl 沉淀的形成降低了 Cu⁺ 的浓度
- **电极电势变化**：根据 Nernst 方程，[Cu⁺] 降低使 Cu²⁺/Cu⁺ 电势升高
- **平衡移动**：沉淀的形成推动反应正向进行
- **协同效应**：Cu²⁺ 氧化 Cu，Cu⁺ 与 Cl⁻ 沉淀，两者协同

## 知识点映射

- 核心考点：溶度积与电极电势的关系
- 关键公式：$\lg K = \frac{nE°}{0.0592} + \lg\frac{1}{K_{sp}}$
- 铜化学：Cu(I) 与 Cu(II) 的相互转化
