# 赵鑫光·热力学·习4 PbS氧化反应Qp与Qv

## 题目

已知$2\text{PbS}(s) + 3\text{O}_2(g) = 2\text{PbO}(s) + 2\text{SO}_2(g)$，$\Delta_r H_m^{\ominus} = -843.4$ kJ/mol，则该反应的$Q_v$值是

A. 840.9　　B. 845.9　　C. -845.9　　D. -840.9

## 答案

D

## 解析

$Q_p = \Delta H = -843.4$ kJ/mol

$\Delta n = 2 - 3 = -1$ mol

$Q_v = Q_p - \Delta nRT = -843.4 - (-1) \times 8.314 \times 10^{-3} \times 298 = -843.4 + 2.5 = -840.9$ kJ/mol
