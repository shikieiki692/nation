# 赵鑫光·配位化合物·选19 光谱化学序列

## 题目

在光谱化学序列中，下列配体场强由弱到强的顺序正确的是：
A. I⁻ < Br⁻ < Cl⁻ < F⁻ < OH⁻ < H₂O < NH₃ < en < CN⁻ < CO
B. F⁻ < Cl⁻ < Br⁻ < I⁻ < H₂O < NH₃ < CN⁻ < CO
C. I⁻ < Br⁻ < Cl⁻ < F⁻ < OH⁻ < CN⁻ < NH₃ < CO
D. F⁻ < OH⁻ < H₂O < NH₃ < en < CN⁻ < CO

## 解答

**答案：A**

> 光谱化学序列（场强由弱到强）：I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < NO₃⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < NH₃ < en < bipy < phen < NO₂⁻ < PPh₃ < CN⁻ < CO
