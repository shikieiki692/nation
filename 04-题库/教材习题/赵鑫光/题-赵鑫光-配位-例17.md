# 赵鑫光·配位化合物·例17 [Ni(en)(NO₂)₂]结构推断

## 题目

配合物[Ni(en)(NO₂)₂]（en = 乙二胺）已知为顺磁性，μ ≈ 3.2 BM。

**(1)** 推断其几何构型。
**(2)** 指出可能的异构体。
**(3)** NO₂⁻的配位方式有哪些？

## 解答

**(1)** Ni²⁺为d⁸构型。
- μ = 3.2 BM → 有未成对电子
- 若为平面四方形d⁸：抗磁性（μ = 0），不符合
- 若为八面体d⁸高自旋：t₂g⁶eg²，2个未成对电子，μ ≈ 2.83 BM

en为双齿配体，2个NO₂⁻（若各占1个配位点）→ 配位数 = 2 + 2 = 4
若NO₂⁻以双齿方式配位 → 配位数 = 2 + 4 = 6 → 八面体

**结论：八面体构型**，两个en提供4个配位点（双齿×2），两个NO₂⁻各以双齿方式配位。
但更合理的解释是：两个en和两个NO₂⁻（单齿N配位）形成扭曲八面体，μ = 3.2 BM暗示有2个未成对电子。

**(2)** 八面体MA₂B₂型有2种异构体：
- **顺式（cis-）**
- **反式（trans-）**

**(3)** NO₂⁻的配位方式：
- **硝基配位（nitro，-NO₂）**：通过N原子配位 → 强场
- **亚硝酸根配位（nitrito，-ONO）**：通过O原子配位 → 弱场
