# 赵鑫光·热力学·例5 Al₂O₃碳还原

## 题目

计算以下两个反应的$\Delta H^{\ominus}$、$\Delta G_{298}^{\ominus}$和$\Delta S^{\ominus}$，讨论焦炭还原炼制铝的可能性。

$$2\text{Al}_2\text{O}_3(s) + 3\text{C}(s) = 4\text{Al}(s) + 3\text{CO}_2(g)$$

$$\text{Al}_2\text{O}_3(s) + 3\text{CO}(g) = 2\text{Al}(s) + 3\text{CO}_2(g)$$

## 解答

反应①：$\Delta H^{\ominus} = 2171.47$ kJ/mol，$\Delta S^{\ominus} = 635.06$ J/(mol·K)，$\Delta G^{\ominus} = 1982.13$ kJ/mol

反应②：$\Delta H^{\ominus} = 827.03$ kJ/mol，$\Delta S^{\ominus} = 53.86$ J/(mol·K)，$\Delta G^{\ominus} = 810.97$ kJ/mol

**结论**：焦炭还原Al₂O₃的转换温度 $T = 2171.47/0.63506 = 3419$ K，工业上很难实现。
