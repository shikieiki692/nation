# 机理例10 乙醛热分解链式反应稳态法推导

## 题目

已知乙醛的热分解反应 $\mathrm{CH}_{3}\mathrm{CHO} \longrightarrow \mathrm{CH}_{4}+\mathrm{CO}$ 是链式反应：

- 链引发：$\mathrm{CH}_{3}\mathrm{CHO} \xrightarrow{k_{1}} \mathrm{CH}_{3}\cdot+\mathrm{CHO}\cdot$
- 链传递：$\mathrm{CH}_{3}\cdot+\mathrm{CH}_{3}\mathrm{CHO} \xrightarrow{k_{2}} \mathrm{CH}_{4}+\mathrm{CH}_{3}\mathrm{CO}\cdot$
- $\mathrm{CH}_{3}\mathrm{CO}\cdot \xrightarrow{k_{3}} \mathrm{CH}_{3}\cdot+\mathrm{CO}$
- 链终止：$\mathrm{CH}_{3}\cdot+\mathrm{CH}_{3}\cdot \xrightarrow{k_{4}} \mathrm{CH}_{3}\mathrm{CH}_{3}$

试用稳态法推导出 $\mathrm{CH}_{4}$ 生成速率。

## 解

$\mathrm{CH}_{4}$ 的生成速率：

$$\frac{\mathrm{d}[\mathrm{CH}_{4}]}{\mathrm{dt}} = k_{2}[\mathrm{CH}_{3}\cdot][\mathrm{CH}_{3}\mathrm{CHO}] \quad \text{①}$$

对 $\mathrm{CH}_{3}\cdot$ 应用稳态近似：

$$\frac{\mathrm{d}[\mathrm{CH}_{3}\cdot]}{\mathrm{dt}} = k_{1}[\mathrm{CH}_{3}\mathrm{CHO}] - k_{2}[\mathrm{CH}_{3}\cdot][\mathrm{CH}_{3}\mathrm{CHO}] + k_{3}[\mathrm{CH}_{3}\mathrm{CO}\cdot] - 2k_{4}[\mathrm{CH}_{3}\cdot]^{2} = 0 \quad \text{②}$$

对 $\mathrm{CH}_{3}\mathrm{CO}\cdot$ 应用稳态近似：

$$\frac{\mathrm{d}[\mathrm{CH}_{3}\mathrm{CO}\cdot]}{\mathrm{dt}} = k_{2}[\mathrm{CH}_{3}\cdot][\mathrm{CH}_{3}\mathrm{CHO}] - k_{3}[\mathrm{CH}_{3}\mathrm{CO}\cdot] = 0 \quad \text{③}$$

将② + ③得：

$$k_{1}[\mathrm{CH}_{3}\mathrm{CHO}] = 2k_{4}[\mathrm{CH}_{3}\cdot]^{2}$$

解得：

$$[\mathrm{CH}_{3}\cdot] = \left(\frac{k_{1}}{2k_{4}}[\mathrm{CH}_{3}\mathrm{CHO}]\right)^{1/2}$$

代入①得：

$$\frac{\mathrm{d}[\mathrm{CH}_{4}]}{\mathrm{dt}} = k_{2}\left(\frac{k_{1}}{2k_{4}}\right)^{1/2}[\mathrm{CH}_{3}\mathrm{CHO}]^{3/2} = k[\mathrm{CH}_{3}\mathrm{CHO}]^{3/2}$$

其中 $k = k_{2}\left(\frac{k_{1}}{2k_{4}}\right)^{1/2}$。
