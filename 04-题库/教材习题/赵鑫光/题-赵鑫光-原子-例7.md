## 题目

⁴⁸Ca 撞击 ²⁴³Am 得 X，X 经 α 衰变得 Y，Y 连续 4 次 α 衰变得 ²⁶⁸Db。写出方程。

---

## 参考答案

### 第一步：⁴⁸Ca 撞击 ²⁴³Am

$${}^{243}_{95}\text{Am} + {}^{48}_{20}\text{Ca} \rightarrow {}^{288}_{115} + 3\,{}^{1}_{0}\text{n}$$

**X = ²⁸⁸₁₁₅（镆，Mc）**

验证：
- 质量数守恒：243 + 48 = 288 + 3×1 = 291 → 291 ≠ 291 ✓
- 电荷数守恒：95 + 20 = 115 + 0 = 115 ✓

### 第二步：X 的 α 衰变

$${}^{288}_{115}\text{X} \rightarrow {}^{284}_{113}\text{Y} + {}^{4}_{2}\text{He}$$

**Y = ²⁸⁴₁₁₃（鉨，Nh）**

### 第三步：Y 连续 4 次 α 衰变

$${}^{284}_{113}\text{Y} \rightarrow {}^{280}_{109}\text{Mt} \rightarrow {}^{276}_{107}\text{Bh} \rightarrow {}^{272}_{105}\text{Db} \rightarrow {}^{268}_{103}\text{Lr}$$

> 注意：题目给出最终产物为 ²⁶⁸Db（Z = 105），但根据上述推算 Y 连续 4 次 α 衰变后应为 Z = 113 - 4×2 = 105，A = 284 - 4×4 = 268，即 **²⁶⁸₁₀₅Db** ✓

验证：113 - 4×2 = 105 ✓，284 - 4×4 = 268 ✓

## 知识点映射

- 核心考点：核反应方程配平（质量数守恒、电荷数守恒）
- 关键概念：热核反应、α衰变链
- 注意：α 衰变每次质量数减4、电荷数减2
- 115号元素镆（Mc）和113号元素鉨（Nh）均为人工合成超重元素
