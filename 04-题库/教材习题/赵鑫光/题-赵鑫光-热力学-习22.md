# 赵鑫光·热力学·习22 Ca还原ThO₂最高温度

## 题目

反应$2\text{Ca}(l) + \text{ThO}_2(s) = 2\text{CaO}(s) + \text{Th}(s)$

T = 1373K时，$\Delta_r G_m^{\ominus} = -10.46$ kJ/mol；T = 1473K时，$\Delta_r G_m^{\ominus} = -8.37$ kJ/mol

近似计算Ca(l)能还原ThO₂(s)的最高温度。

## 解答

联立方程：$\Delta_r H_m^{\ominus} - 1373\Delta_r S_m^{\ominus} = -10460$

$\Delta_r H_m^{\ominus} - 1473\Delta_r S_m^{\ominus} = -8370$

解得：$\Delta_r H_m^{\ominus} = -39156$ J/mol，$\Delta_r S_m^{\ominus} = -20.90$ J/(mol·K)

转换温度：$T_{转} = -39156/(-20.90) = 1873.5$ K
