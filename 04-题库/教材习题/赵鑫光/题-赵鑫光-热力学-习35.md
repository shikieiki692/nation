# 赵鑫光·热力学·习35 N₂O₄分解平衡常数

## 题目

45℃向0.5L真空容器注入0.003mol N₂O₄(g)，平衡时压力26.345kPa。

$\text{N}_2\text{O}_4(g) = 2\text{NO}_2(g)$

(1)求分解百分率和$K^{\ominus}$；

(2)若$\Delta_r H_m^{\ominus} = +4.16$ kJ/mol，求298K时$K^{\ominus}$；

(3)求$\Delta_r S_m^{\ominus}$和$\Delta_r G_m^{\ominus}$随温度变化的关系式。

## 解答

(1) $n_{总} = pV/RT = 26.345 \times 0.5/(8.314 \times 318) = 0.00497$ mol

分解量$\Delta n = 0.00497 - 0.003 = 0.00197$ mol

分解百分率：$0.00197/0.003 \times 100\% = 65.7\%$

$K^{\ominus} = \frac{(2 \times 0.00197/0.5)^2}{(0.003-0.00197)/0.5} = 0.300$

(2) $\lg K^{\ominus}(298) = \lg K^{\ominus}(318) + \frac{\Delta_r H_m^{\ominus}}{2.303R}(\frac{1}{318}-\frac{1}{298})$

解得$K^{\ominus}(298) \approx 0.142$

(3) $\Delta_r G_m^{\ominus} = -RT\ln K^{\ominus}$
