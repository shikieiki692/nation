# 赵鑫光·热力学·习31 甲苯弹式量热计燃烧

## 题目

弹式量热计中燃烧0.20mol H₂(g)使温度升高0.88K，燃烧0.010mol甲苯使温度升高0.615K。已知$\Delta_f H_m^{\ominus}(\text{H}_2\text{O},l) = -285.8$ kJ/mol。

甲苯燃烧反应：$\text{C}_7\text{H}_8(l) + 9\text{O}_2(g) = 7\text{CO}_2(g) + 4\text{H}_2\text{O}(l)$

求该反应的$\Delta_r H_m^{\ominus}$。

## 解答

$\Delta_r U_m^{\ominus}(\text{H}_2) = -285.8 - (-1.5) \times 8.314 \times 10^{-3} \times 298 = -282.1$ kJ/mol

量热计热容：$0.2 \times 282.1/0.88 = 64.11$ kJ/K

甲苯放热：$-64.11 \times 0.615 = -39.43$ kJ

$\Delta_r U_m^{\ominus} = -39.43/0.01 = -3943$ kJ/mol

$\Delta n = -2$，$\Delta_r H_m^{\ominus} = -3943 + (-2) \times 8.314 \times 10^{-3} \times 298 = -3948$ kJ/mol
