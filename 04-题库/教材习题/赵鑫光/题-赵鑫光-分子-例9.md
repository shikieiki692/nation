# 题目

羟胺NH₂OH与H¹⁵NO₂(¹⁵N标记的亚硝酸)反应生成N₂O。若改用¹⁵NH₂OH与HNO₂反应，产物N₂O中¹⁵N的位置有何不同？请通过Lewis结构推导反应机理。

---

# 解析

- **反应**: NH₂OH + HNO₂ → N₂O + 2H₂O
- **N₂O的Lewis结构**: N≡N-O ↔ N=N=O（共振结构），中心N为sp杂化，端基N也为sp杂化。

**同位素标记分析**:
- NH₂OH + H¹⁵NO₂ → NH₂-¹⁵N=O → N=¹⁵N=O → 产物中¹⁵N在中间位置
- ¹⁵NH₂OH + HNO₂ → ¹⁵NH₂-N=O → ¹⁵N=N=O → 产物中¹⁵N在端基位置

反应机理：NH₂OH中的N（亲核）进攻HNO₂中的N（亲电），经脱水形成N-N键。

---

# 关键结论

同位素标记是推断反应机理和原子连接顺序的重要手段。
