# 赵鑫光·配位化合物·例20 Ag(NH₃)₂⁺配位平衡计算

## 题目

已知：
- Ag⁺ + 2NH₃ ⇌ [Ag(NH₃)₂]⁺，Kf = 1.7 × 10⁷
- AgCl的Ksp = 1.8 × 10⁻¹⁰

**(1)** 计算AgCl在6.0 mol/L NH₃中的溶解度。
**(2)** 若向上述溶液中加入HCl使pH = 7，是否会有AgCl沉淀？

## 解答

**(1)** 溶解平衡：

$$\text{AgCl} + 2\text{NH}_3 \rightleftharpoons [\text{Ag(NH}_3)_2]^+ + \text{Cl}^-$$

$$K = K_{sp} \times K_f = 1.8 \times 10^{-10} \times 1.7 \times 10^7 = 3.06 \times 10^{-3}$$

设溶解度为s mol/L：
$$K = \frac{s^2}{(6.0 - 2s)^2} \approx \frac{s^2}{36}$$

$$s^2 = 3.06 \times 10^{-3} \times 36 = 0.11$$

$$s \approx 0.33 \text{ mol/L}$$

**(2)** pH = 7时，NH₃转化为NH₄⁺（pKa = 9.25）：
- [NH₃] / [NH₄⁺] = 10^(pH-pKa) = 10^(7-9.25) = 10^(-2.25) ≈ 0.0056
- 自由NH₃浓度大大降低

此时游离Ag⁺浓度升高，Q = [Ag⁺][Cl⁻] 可能超过Ksp，**会有AgCl沉淀生成**。
