# 赵鑫光·配位化合物·综9 CFSE计算与比较

## 题目

计算[Fe(H₂O)₆]²⁺和[Fe(CN)₆]⁴⁻的CFSE，比较大小并解释。

**已知：** Fe²⁺为d⁶，P = 15000 cm⁻¹
- [Fe(H₂O)₆]²⁺：△o = 10400 cm⁻¹
- [Fe(CN)₆]⁴⁻：△o = 33000 cm⁻¹

## 解答

**(1) [Fe(H₂O)₆]²⁺（高自旋）：**
- 电子排布：t₂g⁴eg²
- CFSE = 4×(-0.4×10400) + 2×(+0.6×10400) = -16640 + 12480 = **-4160 cm⁻¹**

**(2) [Fe(CN)₆]⁴⁻（低自旋）：**
- 电子排布：t₂g⁶eg⁰
- CFSE = 6×(-0.4×33000) + 3P = -79200 + 45000 = **-34200 cm⁻¹**
- 不考虑成对能修正：CFSE = -79200 cm⁻¹

**比较：** [Fe(CN)₆]⁴⁻的CFSE远大于[Fe(H₂O)₆]²⁺，因为CN⁻是强场配体，产生大分裂能，且低自旋态充分利用了t₂g轨道的稳定化。
