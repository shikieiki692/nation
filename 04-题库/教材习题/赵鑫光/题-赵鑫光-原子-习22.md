22. 在一个多电子原子中, 具有下列各套量子数 $(n, l, m, m_{s})$ 的电子, 能量最大的电子具有的量子数是 ( )
A. $3, 2, +1, +\frac{1}{2}$ B. $2, 1, +1, -\frac{1}{2}$ C. $3, 1, 0, -\frac{1}{2}$ D. $3, 1, -1, +\frac{1}{2}$

## 参考答案（提炼版，供参考）

## 参考答案

**答案：A（$3, 2, +1, +\frac{1}{2}$）**

**解析：**

在多电子原子中，电子的能量由 $n$ 和 $l$ 共同决定（构造原理/能级图）。

对于同一 $n$ 值，$l$ 越大能量越高：
$$E(ns) < E(np) < E(nd) < E(nf)$$

各选项的能级：
- **A**：$(3, 2, \ldots)$ → **3d** 轨道
- **B**：$(3, 1, \ldots)$ → **3p** 轨道
- **C**：$(3, 0, \ldots)$ → **3s** 轨道
- **D**：$(2, 1, \ldots)$ → **2p** 轨道

能级高低排序：$2p < 3s < 3p < 3d$

因此 **3d** 电子能量最高，选 **A**。

注意：$m_l$ 和 $m_s$ 不影响电子能量（在无外场情况下简并），能量仅由 $n$ 和 $l$ 决定。
