已知 $A + B \rightarrow C + H_{2}O$ 。 $t^{\circ}C$ 、A、B、C 三种物质的溶解度分别为 $S_{1}$ 、 $S_{2}$ 、 $S_{3}g$ 。现取 $t^{\circ}C$ 时 A 的饱和溶液 Mg，B 的饱和溶液 Ng，混合后恰好完全反应生成 C 物质 Pg。

(1)求反应中生成水多少 g?

(2)通过计算推断：在此反应中 C 物质沉淀的条件是什么?


---

## 参考答案

溶解度 $S$ 表示 t ℃ 时 100 g 水中最多溶解溶质 $S$ g。

**(1) 生成水的质量**

恰好完全反应，由质量守恒：反应物总质量 = 生成物总质量，即

$$M + N = P + m(\mathrm{H_2O})$$

故生成水的质量为：

$$m(\mathrm{H_2O}) = (M + N - P)\ \mathrm{g}$$

**(2) C 沉淀的条件**

反应后体系中水的总质量 = 两份饱和溶液带入的水 + 反应生成的水：

$$m_{\mathrm{水}} = \frac{100M}{100 + S_1} + \frac{100N}{100 + S_2} + (M + N - P)$$

这些水在 t ℃ 时最多能溶解 C 的质量为 $\dfrac{S_3}{100} \cdot m_{\mathrm{水}}$。因此 C 物质沉淀（溶液对 C 过饱和）的条件为：

$$P > \frac{S_3}{100}\left[\frac{100M}{100 + S_1} + \frac{100N}{100 + S_2} + (M + N - P)\right]$$

即生成的 C 的质量超过反应后体系中水所能溶解的 C 的最大质量时，C 才会析出沉淀。
