# 习22：溶解度综合

> **来源**：赵鑫光《高中化学竞赛基本理论学习笔记》第1章 习题22
> **难度**：⭐⭐⭐⭐
> **教学层级**：拓展

---

## 题目

A + B → C + H₂O，t℃时A、B、C溶解度分别为S₁、S₂、S₃ g。取A饱和溶液Mg，B饱和溶液Ng，混合恰好完全反应生成C物质Pg。

(1) 生成水多少g？

(2) C物质沉淀的条件？

---

## 答案

(1) 生成水 = $\dfrac{MS_1}{100+S_1} + \dfrac{NS_2}{100+S_2} - P$

(2) $P > \dfrac{(M+N-P)S_3}{100}$

---

## 解析

**(1) 生成水的计算**

A饱和溶液Mg中：
- 溶质A的质量：$m_A = \dfrac{MS_1}{100+S_1}$
- 溶剂水的质量：$m_{w1} = M - m_A = \dfrac{100M}{100+S_1}$

B饱和溶液Ng中：
- 溶质B的质量：$m_B = \dfrac{NS_2}{100+S_2}$
- 溶剂水的质量：$m_{w2} = N - m_B = \dfrac{100N}{100+S_2}$

反应生成的水来自两部分：
1. 反应本身生成的水
2. 原溶液中已有的水

由质量守恒：反应前总质量 = 反应后总质量

$$M + N = P + m_{\text{水总}}$$

$$m_{\text{水总}} = M + N - P$$

但这是反应后所有水（包括原有的和生成的）。题目问的是**生成**的水，即反应产物中的水。

由反应方程式，溶质A和B反应生成C和水。溶质A和B的质量之和减去生成C的质量，就是生成水的质量：

$$m_{\text{生成水}} = m_A + m_B - P = \frac{MS_1}{100+S_1} + \frac{NS_2}{100+S_2} - P$$

**(2) C物质沉淀的条件**

C沉淀的条件是：生成的C质量超过溶液对C的溶解能力。

反应后溶液总质量：$M + N - P$（扣除沉淀的C）

溶液中最多能溶解的C质量：$\dfrac{(M+N-P) \cdot S_3}{100}$

沉淀条件：

$$P > \frac{(M+N-P) \cdot S_3}{100}$$
