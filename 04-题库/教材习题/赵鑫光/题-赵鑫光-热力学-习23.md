# 赵鑫光·热力学·习23 Ag₂O最低分解温度

## 题目

利用热力学数据计算反应$\text{Ag}_2\text{O}(s) = 2\text{Ag}(s) + \frac{1}{2}\text{O}_2(g)$中Ag₂O(s)的最低分解温度。

298K数据：$\Delta_f H_m^{\ominus}(\text{Ag}_2\text{O}) = -31.1$ kJ/mol，$S_m^{\ominus}(\text{Ag}_2\text{O}) = 121$ J/(mol·K)，$S_m^{\ominus}(\text{Ag}) = 42.55$ J/(mol·K)，$S_m^{\ominus}(\text{O}_2) = 205.03$ J/(mol·K)

## 解答

$\Delta_r H_m^{\ominus} = 31.1$ kJ/mol，$\Delta_r S_m^{\ominus} = 66.62$ J/(mol·K)

$T \geq 31.1 \times 10^3/66.62 = 467$ K

最低分解温度为467K。
