# 赵鑫光·热力学·习3 状态函数与途径函数

## 题目

一个体系从一个特定的开始状态到终止状态总是有

A. Q 途径1 = Q 途径2

B. W 途径1 = W 途径2

C. (Q + W) 途径1 = (Q + W) 途径2

D. $\Delta U = 0$，与途径无关

## 答案

C

## 解析

热力学第一定律：$\Delta U = Q + W$。内能是状态函数，与途径无关，所以$Q + W$在不同途径中相等。Q和W各自是途径函数，不同途径中可以不同。
