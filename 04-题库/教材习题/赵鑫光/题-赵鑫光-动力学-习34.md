对峙反应 $\text{A} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \text{B}$，$k_1 = 0.040$ min⁻¹，$k_{-1} = 0.010$ min⁻¹。若 $[\text{A}]_0 = 1.0$ mol/L，$[\text{B}]_0 = 0$：

(1) 求平衡常数 $K$。

(2) 求A和B的平衡浓度。

(3) 求 $[\text{B}]$ 达到平衡浓度一半所需的时间。

## 答案

**(1)**

$$K = k_1/k_{-1} = 0.040/0.010 = 4.0$$

**(2)** 设平衡时A转化了 $x$：

$$K = [\text{B}]_{eq}/[\text{A}]_{eq} = x/(1.0 - x) = 4.0$$

$$x = 4.0 - 4.0x \implies 5.0x = 4.0 \implies x = 0.80$$

$[\text{A}]_{eq} = 0.20$ mol/L，$[\text{B}]_{eq} = 0.80$ mol/L

**(3)** 净速率方程：

$$\frac{dx}{dt} = k_1(1-x) - k_{-1}x = k_1 - (k_1 + k_{-1})x$$

积分（起始 $x=0$）：

$$x(t) = \frac{k_1}{k_1 + k_{-1}}(1 - e^{-(k_1+k_{-1})t}) = 0.80(1 - e^{-0.050t})$$

当 $[\text{B}] = 0.40$（平衡浓度一半），$x = 0.40$：

$$0.40 = 0.80(1 - e^{-0.050t})$$

$$e^{-0.050t} = 0.50$$

$$t = \frac{\ln 2}{0.050} = \frac{0.6931}{0.050} = 13.86 \text{ min}$$
