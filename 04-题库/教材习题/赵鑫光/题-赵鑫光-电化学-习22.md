22. 电解镍盐溶液, 其中 $\mathrm{Ni}^{2+}$ 离子浓度为 $0.10 \mathrm{~mol} / \mathrm{L}$ 。如果在阴极上恰好镍析出, 而不析出氢气, 此时溶液的最小 $\mathrm{pH}$ 值为 0.95 。镍的标准电极电势为 $E^{\ominus}(\mathrm{Ni}^{2+} / \mathrm{Ni}) = -0.2363 \mathrm{~V}$ 。计算氢在镍上的超电势为多少? (设 $p(\mathrm{H}_{2}) = p^{\ominus}$ 。)

## 参考答案（提炼版，供参考）

## 参考答案

**(a)** 电极反应：

阴极（还原）：$\text{Ni}^{2+} + 2e^- \rightarrow \text{Ni}$

阳极（氧化）：$2\text{H}_2\text{O} - 4e^- \rightarrow \text{O}_2 + 4\text{H}^+$

总反应：$2\text{NiSO}_4 + 2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{Ni} + \text{O}_2 + 2\text{H}_2\text{SO}_4$

**(b)** 理论分解电压：

$$E_{\text{理论}} = Eθ(\text{O}_2/\text{H}_2\text{O}) - Eθ(\text{Ni}^{2+}/\text{Ni}) = 1.23 - (-0.25) = 1.48\text{V}$$

**(c)** 实际所需电压：

$$E_{\text{实际}} = E_{\text{理论}} + \eta_{\text{阴}} + \eta_{\text{阳}}$$

假设阳极超电势忽略（≈0）：

$$E_{\text{实际}} = 1.48 + 0.2 + 0 = 1.68\text{V}$$

**(d)** 超电势来源：

- **活化极化**：电极反应的活化能垒导致的过电位
  - 与电极材料、表面状态有关
  - Ni 在阴极沉积时存在较高的活化能

- **浓差极化**：电极表面与溶液本体浓度差异导致的过电位
  - Ni²⁺ 在阴极表面被还原，浓度降低
  - 扩散速率不足导致浓差极化

- **电阻极化**：溶液电阻、电极膜电阻等导致的电压降
  - 与溶液电导率、电极间距有关
  - NiSO₄ 溶液浓度影响电阻极化
