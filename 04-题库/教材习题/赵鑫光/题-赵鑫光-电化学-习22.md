# 题-赵鑫光-电化学-习22：电解镍盐超电势

## 题目

电解 NiSO₄ 水溶液时，阴极上 Ni²⁺ 的还原存在超电势。

**(a)** 写出阴极和阳极的电极反应。

**(b)** 已知 E°(Ni²⁺/Ni) = -0.25V，E°(O₂/H₂O) = 1.23V，计算理论分解电压。

**(c)** 若 Ni 的超电势为 0.2V，实际所需电压为多少？

**(d)** 讨论超电势的来源（活化极化、浓差极化、电阻极化）。

---

## 参考答案

**(a)** 电极反应：

阴极（还原）：$\text{Ni}^{2+} + 2e^- \rightarrow \text{Ni}$

阳极（氧化）：$2\text{H}_2\text{O} - 4e^- \rightarrow \text{O}_2 + 4\text{H}^+$

总反应：$2\text{NiSO}_4 + 2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{Ni} + \text{O}_2 + 2\text{H}_2\text{SO}_4$

**(b)** 理论分解电压：

$$E_{\text{理论}} = E°(\text{O}_2/\text{H}_2\text{O}) - E°(\text{Ni}^{2+}/\text{Ni}) = 1.23 - (-0.25) = 1.48\text{V}$$

**(c)** 实际所需电压：

$$E_{\text{实际}} = E_{\text{理论}} + \eta_{\text{阴}} + \eta_{\text{阳}}$$

假设阳极超电势忽略（≈0）：

$$E_{\text{实际}} = 1.48 + 0.2 + 0 = 1.68\text{V}$$

**(d)** 超电势来源：

- **活化极化**：电极反应的活化能垒导致的过电位
  - 与电极材料、表面状态有关
  - Ni 在阴极沉积时存在较高的活化能

- **浓差极化**：电极表面与溶液本体浓度差异导致的过电位
  - Ni²⁺ 在阴极表面被还原，浓度降低
  - 扩散速率不足导致浓差极化

- **电阻极化**：溶液电阻、电极膜电阻等导致的电压降
  - 与溶液电导率、电极间距有关
  - NiSO₄ 溶液浓度影响电阻极化
