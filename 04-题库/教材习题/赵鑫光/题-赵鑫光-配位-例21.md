# 赵鑫光·配位化合物·例21 Wilkinson催化剂[RhCl(PPh₃)₃]

## 题目

Wilkinson催化剂[RhCl(PPh₃)₃]（Rh = 铑，PPh₃ = 三苯基膦）是有机合成中重要的均相催化剂。

**(1)** 写出Rh的氧化态和d电子数。
**(2)** 画出该配合物的结构。
**(3)** 该催化剂用于什么反应？简述其催化机理。

## 解答

**(1)** PPh₃为中性配体，Cl⁻带-1电荷。
总电荷 = 0 → Rh的氧化态为 **Rh(I)**
Rh为第45号元素，[Kr]4d⁸5s¹，Rh⁺为 **4d⁸**

**(2)** 结构为**平面四方形**（dsp²杂化）：

```
    PPh₃     Cl
      \     /
       Rh
      /     \
    PPh₃   PPh₃
```

- 3个PPh₃和1个Cl⁻围绕Rh(I)形成平面四方形
- PPh₃体积大，限制了配位数

**(3)** 用于**烯烃加氢反应（催化加氢）**：

催化循环：
1. **氧化加成**：H₂ + Rh(I) → Rh(III)H₂
2. **配位**：烯烃配位到Rh(III)
3. **迁移插入**：H转移到烯烃上
4. **还原消除**：产物烷烃离去，Rh(I)再生

总反应：RCH=CH₂ + H₂ → RCH₂CH₃
