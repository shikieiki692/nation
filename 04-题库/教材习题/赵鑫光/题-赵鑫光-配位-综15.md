# 赵鑫光·配位化合物·综15 AgCl溶解度计算

## 题目

计算在pH = 10.0的缓冲溶液中，AgCl在0.10 mol/L NH₃中的溶解度。

**已知：** Ksp(AgCl) = 1.8×10⁻¹⁰，Kf([Ag(NH₃)₂]⁺) = 1.7×10⁷，NH₃的Kb = 1.8×10⁻⁵

## 解答

pH = 10.0时，[H⁺] = 10⁻¹⁰，[OH⁻] = 10⁻⁴

NH₃ + H₂O ⇌ NH₄⁺ + OH⁻，Kb = 1.8×10⁻⁵

设[NH₃] = 0.10 - x ≈ 0.10（近似），则[NH₄⁺] ≈ [OH⁻] = 10⁻⁴

实际[NH₃] ≈ 0.10 mol/L（pH = 10接近pKa = 9.25，NH₃占主导）

溶解反应：
AgCl + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻

K = Ksp × Kf = 1.8×10⁻¹⁰ × 1.7×10⁷ = 3.06×10⁻³

设溶解度为s：
K = s² / (0.10 - 2s)² ≈ s² / 0.01

s² = 3.06×10⁻³ × 0.01 = 3.06×10⁻⁵

s ≈ 5.5×10⁻³ mol/L
