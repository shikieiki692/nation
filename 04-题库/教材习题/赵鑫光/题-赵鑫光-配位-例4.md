# 赵鑫光·配位化合物·例4 Pt配合物元素分析

## 题目

某Pt配合物A（分子量≈500）进行元素分析：Pt 40.1%, Cl 23.5%, N 12.3%, H 4.2%。将A溶于水后加入过量AgNO₃，生成白色沉淀B，经称量B中Ag占50.3%。

**(1)** 确定A的化学式。
**(2)** 写出B的化学式。
**(3)** 将A溶于王水，经处理得到产物C，C再经还原得到D，D可被氧化为K₂[PtCl₆]。写出C、D的化学式。

## 解答

**(1)** 设分子式为PtₐClₓN_yH_z，由元素分析：
- n(Pt) = 40.1/195.1 ≈ 0.2056 mol → 取a = 1
- n(Cl) = 23.5/35.5 ≈ 0.6620 mol → x ≈ 3.2 → 取3或4
- n(N) = 12.3/14.0 ≈ 0.8786 mol → y ≈ 4.3 → 取4
- n(H) = 4.2/1.0 ≈ 4.2 mol → z ≈ 20

综合推算：化学式为 **[PtCl₂(NH₃)₄]Cl₂** → 分子量 ≈ 500

验证：[PtCl₂(NH₃)₄]Cl₂ 中，外界有2个Cl⁻可被AgNO₃沉淀。

**(2)** B = **2AgCl**

**(3)** A溶于王水，Pt被氧化为Pt⁴⁺：
- C = **H₂[PtCl₆]**（六氯合铂(IV)酸）
- 还原D = **H₂[PtCl₄]**（四氯合铂(II)酸）
- 氧化：H₂[PtCl₄] → K₂[PtCl₆]
