# 题目

OsO₄为四面体结构。与OsO₄互为等电子体的[OsO₃N]⁻也具有四面体结构，且与KMnO₄类质同晶。试解释其合理性。

---

# 解析

- **等电子原理**: 原子数相同、价电子总数相同的物种具有相似的结构。
- OsO₄: 5个原子，Os的6个价电子 + 4×6(O) = 30个价电子
- [OsO₃N]⁻: 5个原子，Os的6个价电子 + 3×6(O) + 5(N) + 1(电荷) = 30个价电子

OsO₄与[OsO₃N]⁻：将一个O²⁻替换为N³⁻（电荷增加1），原子数不变，价电子总数不变。因此两者互为等电子体，结构相似（四面体）。

[OsO₃N]⁻与MnO₄⁻：Os(VIII)的d⁰构型与Mn(VII)的d⁰构型类似，两者都是四面体含氧酸根/氧化物，因此类质同晶。

---

# 关键结论

等电子体具有相似的几何构型和成键方式，这是推测未知化合物结构的重要方法。
