# 赵鑫光·热力学·习27 CO₂+H₂平衡最大转化率

## 题目

在500K、101.325kPa下，等摩尔CO₂与H₂反应：

$\text{CO}_2(g) + \text{H}_2(g) = \text{CO}(g) + \text{H}_2\text{O}(g)$

计算最大转化率。已知298K热力学数据：

| 物质 | $\Delta_f H_m^{\ominus}$ (kJ/mol) | $S_m^{\ominus}$ [J/(mol·K)] |
|:---|:---:|:---:|
| CO₂(g) | -393.5 | 218.6 |
| H₂(g) | 0 | 130.6 |
| CO(g) | -110.5 | 197.9 |
| H₂O(g) | -241.8 | 188.7 |

## 解答

$\Delta_r H_m^{\ominus} = 41.2$ kJ/mol，$\Delta_r S_m^{\ominus} = 37.4$ J/(mol·K)

500K时：$\Delta_r G_m^{\ominus} = 41.2 - 500 \times 0.0374 = 22.5$ kJ/mol

$K^{\ominus} = 4.47 \times 10^{-3}$

设转化率$\alpha$：$K^{\ominus} = \frac{(\alpha/2)^2}{((1-\alpha)/2)^2}$，解得$\alpha = 6.3\%$
