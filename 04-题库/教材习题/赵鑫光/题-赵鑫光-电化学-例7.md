# 题-赵鑫光-电化学-例7：金的氰化提炼

## 题目

$$4\text{Au} + \text{O}_2 + 8\text{CN}^- + 2\text{H}_2\text{O} = 4[\text{Au(CN)}_2]^- + 4\text{OH}^-$$

$$\Delta G° = -405.62\text{ kJ}$$

**热力学驱动力分析：**

- Au³⁺/Au 标准电势 +1.50V，Au 极难被氧化
- 形成 [Au(CN)₂]⁻ 配合物后，Au⁺ 浓度极低
- 电极电势降低为 $E°(\text{Au}^+/\text{Au}) = 0.68\text{V}$（配合后）
- O₂ 作为氧化剂提供足够驱动力

$$E°_{\text{cell}} = E°(\text{O}_2/\text{OH}^-) - E°([\text{Au(CN)}_2]^-/\text{Au}) > 0$$

**问题：**
1. 计算该反应的标准电动势
2. 解释为什么氰化物能溶解金
3. 计算 [Au(CN)₂]⁻ 的稳定常数

---

## 参考答案

**1. 标准电动势计算：**

已知 $\Delta G° = -nFE°$，对于反应：
- 转移电子数 $n = 4$（4个Au原子各失去1个电子）
- $F = 96485\text{ C/mol}$

$$E° = \frac{-\Delta G°}{nF} = \frac{405620}{4 \times 96485} = 1.05\text{V}$$

**2. 氰化物溶解金的原理：**

- 金的标准电极电势很高（+1.50V），普通氧化剂无法氧化
- CN⁻ 与 Au⁺ 形成稳定的 [Au(CN)₂]⁻ 配合物（β₂ ≈ 10³⁸）
- 配位使 Au⁺ 浓度极低，根据 Nernst 方程，Au⁺/Au 电对电势大幅降低
- 降低后的电势（0.68V）低于 O₂/OH⁻ 电对电势（0.40V），反应自发

**3. [Au(CN)₂]⁻ 的稳定常数：**

利用电极电势关系：
$$E°(\text{Au}^+/\text{Au}) = E°(\text{Au}^{2+}/\text{Au}) + 0.0592\lg\frac{1}{\beta_2}$$

$$0.68 = 1.50 + 0.0592\lg\frac{1}{\beta_2}$$

$$\lg\beta_2 = \frac{1.50 - 0.68}{0.0592} = \frac{0.82}{0.0592} = 13.85$$

$$\beta_2 = 7.1 \times 10^{13}$$

（注：文献值约为 10³⁸，此处计算基于题目给定数据）

- 核心考点：配位反应对电极电势的影响
- 关键概念：稳定常数与电势的关系
- 工业应用：氰化法提金的热力学原理
