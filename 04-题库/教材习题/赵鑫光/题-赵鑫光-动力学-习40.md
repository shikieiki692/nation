在800 K时，反应 $\text{CO(g)} + \text{H}_2\text{O(g)} \rightleftharpoons \text{CO}_2\text{(g)} + \text{H}_2\text{(g)}$ 的 $K_c = 1.0$。将2.0 mol CO和3.0 mol H₂O置于10.0 L容器中加热至800 K。

(1) 计算平衡时各组分浓度。

(2) 若在平衡体系中再加入1.0 mol H₂O，重新计算平衡移动后各组分浓度。

(3) 说明H₂O的加入对CO转化率的影响。

## 答案

**(1)** 初始浓度：$[\text{CO}]_0 = 0.20$ mol/L，$[\text{H}_2\text{O}]_0 = 0.30$ mol/L

设平衡时CO转化了 $x$ mol/L：

$$K_c = \frac{x^2}{(0.20-x)(0.30-x)} = 1.0$$

$$x^2 = (0.20-x)(0.30-x) = 0.06 - 0.50x + x^2$$

$$0.50x = 0.06 \implies x = 0.12 \text{ mol/L}$$

平衡浓度：$[\text{CO}] = 0.08$，$[\text{H}_2\text{O}] = 0.18$，$[\text{CO}_2] = 0.12$，$[\text{H}_2] = 0.12$ mol/L

CO转化率：$\alpha_1 = 0.12/0.20 = 60\%$

**(2)** 加入1.0 mol H₂O后，$[\text{H}_2\text{O}]_{\text{新初}} = 0.18 + 1.0/10.0 = 0.28$ mol/L

设新增转化量为 $y$：

$$\frac{(0.12+y)^2}{(0.08-y)(0.28-y)} = 1.0$$

$$(0.12+y)^2 = (0.08-y)(0.28-y)$$

$$0.0144 + 0.24y + y^2 = 0.0224 - 0.36y + y^2$$

$$0.60y = 0.008 \implies y = 0.0133 \text{ mol/L}$$

新平衡：$[\text{CO}] = 0.0667$，$[\text{H}_2\text{O}] = 0.267$，$[\text{CO}_2] = 0.133$，$[\text{H}_2] = 0.133$ mol/L

CO转化率：$\alpha_2 = (0.12 + 0.0133)/0.20 = 66.7\%$

**(3)** 增加H₂O使平衡正向移动，CO转化率从60%提高到66.7%。这体现了Le Chatelier原理——增加反应物浓度使平衡向产物方向移动。
