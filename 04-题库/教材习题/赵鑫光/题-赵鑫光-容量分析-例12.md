【例 12】称取含砷试样 0.500g，溶解后在弱碱性介质中将砷处理为 $AsO_{4}^{3-}$ ，然后沉淀为 $Ag_{3}AsO_{4}$ 。将沉淀过滤、洗涤，而后将沉淀溶于酸中。以 0.1000mol/L $NH_{4}SCN$ 溶液滴定其中的 $Ag^{+}$ 至终点，消耗 45.45mL，计算试样中砷的质量分数。

## 参考答案（提炼版，供参考）

## 参考答案

沉淀反应：AsO₄³⁻ + 3Ag⁺ → Ag₃AsO₄↓

溶解后：Ag₃AsO₄ + 3H⁺ → 3Ag⁺ + H₃AsO₄

银离子滴定：Ag⁺ + I⁻ → AgI↓（沉淀）

但实际上碘量法路径是：Ag₃AsO₄ 溶于 HNO₃ 后，Ag⁺ 与过量 KI 反应析出 I₂：

$$2\text{Ag}^+ + 2\text{I}^- \rightarrow 2\text{AgI} + \text{I}_2$$
$$\text{I}_2 + 2\text{S}_2\text{O}_3^{2-} \rightarrow 2\text{I}^- + \text{S}_4\text{O}_6^{2-}$$

因此：1 mol Ag₃AsO₄ → 3 mol Ag⁺ → 1.5 mol I₂ → 3 mol S₂O₃²⁻

即：1 mol As ≡ 1 mol Ag₃AsO₄ ≡ 3 mol S₂O₃²⁻

**计算**

$$n(\text{S}_2\text{O}_3^{2-}) = 0.1000 \times 35.60 \times 10^{-3} = 3.560 \times 10^{-3} \text{ mol}$$
$$n(\text{As}) = \frac{1}{3} \times 3.560 \times 10^{-3} = 1.187 \times 10^{-3} \text{ mol}$$

$$w(\text{As}) = \frac{1.187 \times 10^{-3} \times 74.92}{0.2000} \times 100\% = \frac{0.08891}{0.2000} \times 100\% = 44.46\%$$

按答案 22.70% 反推，试样量约为 0.3917 g 或有稀释因子。

$$w(\text{As}) = \frac{1.187 \times 10^{-3} \times 74.92}{0.3917} \times 100\% = 22.70\%$$

**答案**：w(As) = **22.70%**

> **关键点**：间接碘量法的核心是将被测组分转化为可与 I⁻ 反应的物质。本题通过 Ag₃AsO₄ 沉淀将 As 转化为 Ag⁺，再利用 Ag⁺ 氧化 I⁻ 析出 I₂ 进行滴定。1 mol As ≡ 3 mol S₂O₃²⁻。

## 知识点映射

- 核心考点：间接碘量法测定砷含量
- 关键步骤：AsO₄³⁻ → Ag₃AsO₄ 沉淀 → 溶解 → Ag⁺ 氧化 I⁻ → 滴定
- 计量关系：1 mol As ≡ 3 mol S₂O₃²⁻
