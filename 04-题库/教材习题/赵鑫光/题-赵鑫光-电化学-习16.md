# 题-赵鑫光-电化学-习16：Co³⁺ 氧化水

## 题目

已知：

$$E°(\text{Co}^{3+}/\text{Co}^{2+}) = 1.92\text{V}$$
$$E°(\text{O}_2/\text{H}_2\text{O}) = 1.23\text{V}$$

**(a)** 从热力学角度分析 Co³⁺ 能否氧化水。

**(b)** 实际实验中，[Co(NH₃)₆]³⁺ 能稳定存在于水中，解释原因。

**(c)** 若 Co³⁺/Co²⁺ 电对的有效电势为 0.82V（考虑配位效应），分析其稳定性。

---

## 参考答案

**(a)** 热力学分析：

Co³⁺ 氧化水的反应：
$$4\text{Co}^{3+} + 2\text{H}_2\text{O} \rightarrow 4\text{Co}^{2+} + \text{O}_2 + 4\text{H}^+$$

$$E°_{\text{cell}} = E°(\text{Co}^{3+}/\text{Co}^{2+}) - E°(\text{O}_2/\text{H}_2\text{O}) = 1.92 - 1.23 = 0.69\text{V}$$

由于 $E°_{\text{cell}} > 0$，反应自发进行。

**结论：** 从热力学角度看，Co³⁺ 能够氧化水。

**(b)** [Co(NH₃)₆]³⁺ 稳定的原因：

- **配位效应**：NH₃ 与 Co³⁺ 形成稳定配合物，降低了 Co³⁺ 的有效浓度
- **电极电势降低**：配合物的形成使 Co³⁺/Co²⁺ 电对电势大幅降低
- **动力学惰性**：Co(III) 配合物是惰性配合物，反应速率很慢
- **实际电势**：[Co(NH₃)₆]³⁺/Co²⁺ 电对电势约为 +0.1V，低于水的氧化电势

**(c)** 配位效应分析：

当有效电势为 0.82V 时：
- $E°_{\text{cell}} = 0.82 - 1.23 = -0.41\text{V}$
- $E°_{\text{cell}} < 0$，反应不自发
- **结论：** 配位效应使 Co³⁺ 失去氧化水的能力

## 知识点映射

- 核心考点：电极电势与反应自发性
- 关键概念：配位效应对电极电势的影响
- 配位化学：配合物的热力学稳定性
