## 题目

化学反应 $\mathrm{H}_{2}(\mathrm{g})+\mathrm{Cl}_{2}(\mathrm{g}) \longrightarrow 2\mathrm{HCl}(\mathrm{g})$ 经历的反应过程为：

$\mathrm{Cl}_{2}+\mathrm{M} \longrightarrow 2\mathrm{Cl}\cdot+\mathrm{M}$（链引发）

$\mathrm{Cl}\cdot+\mathrm{H}_{2} \longrightarrow \mathrm{HCl}+\mathrm{H}\cdot$（链传递）

$\mathrm{H}\cdot+\mathrm{Cl}_{2} \longrightarrow \mathrm{HCl}+\mathrm{Cl}\cdot$（链传递）

$2\mathrm{Cl}\cdot+\mathrm{M} \longrightarrow \mathrm{Cl}_{2}+\mathrm{M}$（链终止）

试用稳态处理法导出该反应的速率方程式。

## 解答

由给出的反应机理，可写出 HCl 的生成速率：

$$\frac{\mathrm{d}[\mathrm{HCl}]}{\mathrm{dt}} = k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] + k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] \tag{①}$$

由于自由基都很活泼，寿命很短，当反应达到稳定状态后，假定 $\frac{\mathrm{d}[\mathrm{Cl}\cdot]}{\mathrm{dt}}=0$，$\frac{\mathrm{d}[\mathrm{H}\cdot]}{\mathrm{dt}}=0$。

$$\frac{\mathrm{d}[\mathrm{Cl}\cdot]}{\mathrm{dt}} = 2k_{1}[\mathrm{Cl}_{2}][\mathrm{M}] - k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] + k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] - 2k_{-1}[\mathrm{Cl}\cdot]^{2}[\mathrm{M}] = 0 \tag{②}$$

$$\frac{\mathrm{d}[\mathrm{H}\cdot]}{\mathrm{dt}} = k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] - k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}] = 0 \tag{③}$$

比较式②和式③，由式③得 $k_{2}[\mathrm{Cl}\cdot][\mathrm{H}_{2}] = k_{3}[\mathrm{H}\cdot][\mathrm{Cl}_{2}]$，代入式②：

$$2k_{1}[\mathrm{Cl}_{2}][\mathrm{M}] - 2k_{-1}[\mathrm{Cl}\cdot]^{2}[\mathrm{M}] = 0$$

$$[\mathrm{Cl}\cdot]=\left(\frac{k_{1}}{k_{-1}}[\mathrm{Cl}_{2}]\right)^{1/2} \tag{④}$$

将③和④式代入①式得：

$$\frac{\mathrm{d}[\mathrm{HCl}]}{\mathrm{dt}} = 2k_{2}\left(\frac{k_{1}}{k_{-1}}\right)^{1/2}\cdot[\mathrm{Cl}_{2}]^{1/2}\cdot[\mathrm{H}_{2}] = k[\mathrm{Cl}_{2}]^{1/2}\cdot[\mathrm{H}_{2}]$$

其中 $k=2k_{2}\left(\frac{k_{1}}{k_{-1}}\right)^{1/2}$。
