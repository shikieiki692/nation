# 赵鑫光·配位化合物·例12 CFT计算（CFSE/磁矩/高低自旋）

## 题目

计算以下配合物的晶体场稳定化能（CFSE）、未成对电子数和磁矩（μ）：

(1) [Fe(H₂O)₆]²⁺
(2) [Fe(CN)₆]⁴⁻
(3) [Co(NH₃)₆]³⁺
(4) [CoF₆]³⁻

已知：△o（弱场）≈ 10000 cm⁻¹，△o（强场）≈ 20000 cm⁻¹
电子成对能P ≈ 15000 cm⁻¹

## 解答

**(1) [Fe(H₂O)₆]²⁺：** Fe²⁺为d⁶，H₂O为弱场 → **高自旋**
- 电子排布：t₂g⁴eg²
- CFSE = 4×(-0.4△o) + 2×(+0.6△o) = -0.4△o = **-4000 cm⁻¹**
- 未成对电子数 = **4**
- μ = √(4×6) = **4.90 BM**

**(2) [Fe(CN)₆]⁴⁻：** Fe²⁺为d⁶，CN⁻为强场 → **低自旋**
- 电子排布：t₂g⁶eg⁰
- CFSE = 6×(-0.4△o) + 3P = -2.4△o + 3P = **-48000 + 45000 = -3000 cm⁻¹**（考虑成对能后）
- 未成对电子数 = **0**
- μ = **0 BM**（抗磁性）

**(3) [Co(NH₃)₆]³⁺：** Co³⁺为d⁶，NH₃为强场 → **低自旋**
- 电子排布：t₂g⁶eg⁰
- CFSE = 6×(-0.4△o) + 3P = **-48000 + 45000 = -3000 cm⁻¹**
- 未成对电子数 = **0**
- μ = **0 BM**

**(4) [CoF₆]³⁻：** Co³⁺为d⁶，F⁻为弱场 → **高自旋**
- 电子排布：t₂g⁴eg²
- CFSE = 4×(-0.4△o) + 2×(+0.6△o) = -0.4△o = **-4000 cm⁻¹**
- 未成对电子数 = **4**
- μ = **4.90 BM**
