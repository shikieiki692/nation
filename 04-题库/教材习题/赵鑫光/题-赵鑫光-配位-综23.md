# 赵鑫光·配位化合物·综23 光谱化学序列本质

## 题目

解释以下配合物的光谱化学序列现象：为什么I⁻是弱场配体，而CN⁻是强场配体？

## 解答

**I⁻（弱场）：**
- 碘离子半径大，电荷密度低
- 主要通过σ键与金属结合
- 有充满的p轨道，可以向金属的d轨道提供电子（π给体）
- π给体作用**减小**了d轨道分裂能（Δo）
- 因此I⁻为弱场配体

**CN⁻（强场）：**
- 碳原子有空的π*反键轨道
- 金属的dπ电子可以反馈到CN⁻的π*轨道（反馈π键）
- 反馈π键**增大**了d轨道分裂能（Δo）
- CN⁻既是σ给体，又是π接受体
- 因此CN⁻为强场配体

**总结：**
- 弱场配体（如I⁻）：σ给体 + π给体 → 小Δo
- 强场配体（如CN⁻）：σ给体 + π接受体 → 大Δo
- 这就是光谱化学序列的本质：π给体 < 纯σ给体 < π接受体
