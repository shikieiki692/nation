# 题-赵鑫光-电化学-例9：MnO₄⁻ + Fe²⁺ 原电池

## 题目

$$\text{MnO}_4^- + 5\text{Fe}^{2+} + 8\text{H}^+ \rightarrow \text{Mn}^{2+} + 5\text{Fe}^{3+} + 4\text{H}_2\text{O}$$

**(1) 标准电动势**

$$E° = E°(\text{MnO}_4^-/\text{Mn}^{2+}) - E°(\text{Fe}^{3+}/\text{Fe}^{2+}) = 1.51 - 0.77 = 0.74\text{V}$$

**(2) 标准平衡常数**

$$\lg K° = \frac{nE°}{0.0592} = \frac{5 \times 0.74}{0.0592} = 62.5$$

$$K° = 3.98 \times 10^{62}$$

**(3) pH = 2 时的实际电势**

$$E = E° + \frac{0.0592}{5}\lg\frac{[\text{MnO}_4^-][\text{H}^+]^8}{[\text{Mn}^{2+}]}$$

$$E = 1.51 + \frac{0.0592}{5}\lg(10^{-2})^8 = 1.51 - 0.189 = 1.32\text{V}$$

实际电池电动势 $E = 1.32 - 0.77 = 0.55\text{V}$

**问题：**
1. 验证标准电动势的计算
2. 解释为什么平衡常数如此之大
3. 分析pH对电池电动势的影响

---

## 参考答案

**1. 标准电动势验证：**

- $E°(\text{MnO}_4^-/\text{Mn}^{2+}) = 1.51\text{V}$（酸性条件）
- $E°(\text{Fe}^{3+}/\text{Fe}^{2+}) = 0.77\text{V}$
- $E°_{\text{cell}} = 1.51 - 0.77 = 0.74\text{V}$ ✓

**2. 平衡常数极大的原因：**

- $E°_{\text{cell}} = 0.74\text{V}$，正值较大
- $\lg K = \frac{nE°}{0.0592} = \frac{5 \times 0.74}{0.0592} = 62.5$
- $K = 10^{62.5} \approx 3.98 \times 10^{62}$
- 如此大的K值说明反应几乎完全进行，MnO₄⁻ 是强氧化剂

**3. pH对电动势的影响：**

MnO₄⁻ 还原反应消耗8个H⁺，根据Nernst方程：
- [H⁺] 降低（pH升高）→ 电势降低
- 每升高1个pH单位，电势降低约 $8 \times 0.0592/5 \approx 0.095\text{V}$
- pH = 2时，电势降低约 $0.189\text{V}$（从1.51V降至1.32V）

**结论：** 酸性越强，MnO₄⁻ 的氧化性越强。

## 知识点映射

- 核心考点：原电池电动势计算与pH影响
- 关键公式：$\lg K = \frac{nE°}{0.0592}$，Nernst方程
- 应用：KMnO₄ 滴定需在强酸性条件下进行
