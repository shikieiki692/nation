# 赵鑫光·热力学·习10 绝热箱中蓄电池

## 题目

在绝热箱中装有水，水中绕有电阻丝，由蓄电池供给电流。通电后电阻丝和水的温度皆有升高。若以电池为体系，以水和电阻丝为环境，则

A. $Q = 0, W > 0, \Delta U < 0$

B. $Q < 0, W < 0, \Delta U > 0$

C. $Q > 0, W = 0, \Delta U > 0$

D. $Q = 0, W < 0, \Delta U < 0$

## 答案

D

## 解析

以电池为体系：绝热箱中电池对外做电功（$W < 0$），无热量交换（$Q = 0$），由$\Delta U = Q + W < 0$，电池内能减少。
