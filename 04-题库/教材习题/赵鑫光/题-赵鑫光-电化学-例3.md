# 题-赵鑫光-电化学-例3：硫铁矿氧化

## 题目

黄铁矿（FeS₂）在酸性溶液中被溶解氧氧化的5步反应：

$$\text{FeS}_2 \xrightarrow{O_2} \text{Fe}^{2+} + \text{S}_2\text{O}_3^{2-} \rightarrow \text{SO}_4^{2-} \rightarrow \cdots$$

最终产物为 Fe³⁺ 和 SO₄²⁻。

**Fe₂(SO₄)₃ 循环使用原理：**

- Fe³⁺ 作为氧化剂将 FeS₂ 氧化，自身被还原为 Fe²⁺
- Fe²⁺ 再被 O₂ 氧化再生为 Fe³⁺
- 总反应：$4\text{FeS}_2 + 15\text{O}_2 + 2\text{H}_2\text{O} = 2\text{Fe}_2(\text{SO}_4)_3 + 2\text{H}_2\text{SO}_4$

Fe₂(SO₄)₃ 起催化剂作用，构成自催化循环。

**问题：**
1. 写出各步反应方程式
2. 解释为什么 Fe₂(SO₄)₃ 能循环使用
3. 分析该反应的热力学驱动力

---

## 参考答案

**1. 各步反应方程式：**

- 第1步：$\text{FeS}_2 + 2\text{Fe}^{3+} \rightarrow 3\text{Fe}^{2+} + 2\text{S}$
- 第2步：$2\text{S} + 3\text{O}_2 + 2\text{H}_2\text{O} \rightarrow 2\text{H}_2\text{SO}_4$
- 第3步：$4\text{Fe}^{2+} + \text{O}_2 + 4\text{H}^+ \rightarrow 4\text{Fe}^{3+} + 2\text{H}_2\text{O}$
- 总反应：$4\text{FeS}_2 + 15\text{O}_2 + 2\text{H}_2\text{O} = 2\text{Fe}_2(\text{SO}_4)_3 + 2\text{H}_2\text{SO}_4$

**2. Fe₂(SO₄)₃ 的循环原理：**

Fe³⁺ 作为中间氧化剂参与反应：
- 在第1步中，Fe³⁺ 氧化 FeS₂，自身被还原为 Fe²⁺
- 在第3步中，Fe²⁺ 被 O₂ 重新氧化为 Fe³⁺
- 因此 Fe³⁺ 在整个过程中不被消耗，起到催化作用

**3. 热力学驱动力：**

- FeS₂ 中 S₂²⁻ 具有强还原性（S的氧化态为-1）
- O₂ 是强氧化剂
- 反应生成稳定的 SO₄²⁻ 和 Fe³⁺，ΔG° < 0
- 该反应是典型的放热反应，热力学上高度自发

## 知识点映射

- 核心考点：氧化还原反应的分步书写与催化循环
- 关键概念：Fe³⁺/Fe²⁺ 电对作为电子穿梭体
- 工业应用：细菌浸矿（bioleaching）原理
