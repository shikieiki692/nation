【例 1】（1）核磁共振(NMR)技术已广泛应用于复杂分子结构的测定和医学诊断等高科技领域。已知只有质子数或中子数为奇数的原子核有 NMR 现象。试判断下列哪组原子均可产生 NMR 现象
A. $^{18}$ O³¹ P¹¹⁹ Sn
B. $^{27}$ Al¹⁹ F¹² C
C. 元素周期表中ⅢA族所有元素的原子
D. 元素周期表中第三周期所有元素的原子

(2)假定在下列电子的各组量子数中 n 正确,请指出哪个能存在?
A. n=1, l=1, m=1, $m_{s}=-1$ B. $n=3, l=1, m=2, m_{s}=+1/2$ C. $n=3, l=2, m=1, m_{s}=-1/2$ D. n=2, l=0, m=0, $m_{s}=0$ E. $n=2, l=-1, m=1, m_{s}=+1/2$ F. $n=4, l=3, m=2, m_{s}=2$

## 参考答案（提炼版，供参考）

## 参考答案

### (1) 答案：C

**分析：**

- **A**: ¹⁸O 质子数8(偶)、中子数10(偶) → 无NMR；³¹P 质子数15(奇) → 有NMR；¹¹⁹Sn 质子数50(偶)、中子数69(奇) → 有NMR。¹⁸O无NMR，排除。
- **B**: ²⁷Al 质子数13(奇) → 有NMR；¹⁹F 质子数9(奇) → 有NMR；¹²C 质子数6(偶)、中子数6(偶) → 无NMR。¹²C无NMR，排除。
- **C**: ⅢA族元素（B、Al、Ga、In、Tl），质子数分别为5、13、31、49、81，均为奇数 → 均有NMR。**正确。**
- **D**: 第三周期含 ²⁸Si（质子数14偶、中子数14偶）无NMR，排除。

### (2) 答案：C

**分析：**

量子数取值规则：n ≥ 1（正整数），0 ≤ l ≤ n-1，-l ≤ m ≤ l，m_s = ±1/2。

| 选项 | 判断 | 原因 |
|:---:|:---:|:---|
| A | 不合法 | l = 1，但 n = 1 时 l 最大为 0 |
| B | 不合法 | l = 1 时 m 最大为 1，m = 2 超出范围 |
| **C** | **合法** | **n=3, l=2, m=1，均在允许范围内** |
| D | 不合法 | m_s 只能取 ±1/2，不能为 0 |
| E | 不合法 | l 不能为负值 |
| F | 不合法 | m_s 只能取 ±1/2，不能为 2 |

## 知识点映射

- 核心考点：NMR活性判断（质子数或中子数为奇数）、量子数合法性判断
- 关键规则：n ≥ 1；0 ≤ l ≤ n-1；-l ≤ m ≤ l；m_s = ±1/2
- NMR条件：原子核自旋量子数 I ≠ 0，即质子数或中子数为奇数
