# 赵鑫光·配位化合物·综18 顺铂合成路线

## 题目

合成路线：从K₂PtCl₄出发，设计合成顺铂（cis-[Pt(NH₃)₂Cl₂]）。

## 解答

**合成路线（Dhara法）：**

第一步：K₂PtCl₄ + 2KI → K₂[PtI₄] + 2KCl

第二步：K₂[PtI₄] + 2NH₃ → cis-[Pt(NH₃)₂I₂] + 2KI
- 由于I⁻的反位效应强于NH₃，两个NH₃倾向于占据相邻位置（顺式）

第三步：cis-[Pt(NH₃)₂I₂] + 2AgNO₃ → cis-[Pt(NH₃)₂(H₂O)₂]²⁺ + 2AgI↓
- AgI沉淀，I⁻被H₂O取代

第四步：cis-[Pt(NH₃)₂(H₂O)₂]²⁺ + 2KCl → cis-[Pt(NH₃)₂Cl₂] + 2H₂O
- Cl⁻取代H₂O

**关键：** 利用I⁻的强反位效应控制立体化学，确保两个NH₃处于顺式位置。
