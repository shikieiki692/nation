## 题目

求 300mL 0.50mol/L $H_{3}PO_{4}$ 和 500mL 0.50mol/L NaOH 的混合溶液的 pH。已知磷酸的 $K_{\mathrm{a2}}=6.3\times10^{-8}$ 。


## 参考答案

0.150mol $H_{3}PO_{4}$ 和 0.250mol NaOH 反应：

第一步完全中和：$\mathrm{H_3PO_4 + OH^- \to H_2PO_4^- + H_2O}$，生成 0.150mol $\mathrm{NaH_2PO_4}$，剩余 0.100mol NaOH；
第二步继续反应：$\mathrm{H_2PO_4^- + OH^- \to HPO_4^{2-} + H_2O}$，生成 0.100mol $\mathrm{Na_2HPO_4}$，剩余 0.050mol $\mathrm{NaH_2PO_4}$。

得到 $\mathrm{H_2PO_4^- \sim HPO_4^{2-}}$ 缓冲溶液：

$$\mathrm{H_2PO_4^-(aq) + H_2O(l) \rightleftharpoons HPO_4^{2-}(aq) + H_3O^+(aq)}$$

$$\mathrm{pH} = \mathrm{p}K_{\mathrm{a2}} + \lg \frac{[\mathrm{HPO_4^{2-}}]}{[\mathrm{H_2PO_4^-}]} = -\lg(6.3 \times 10^{-8}) + \lg \frac{0.100}{0.0500} = 7.20 + 0.30 = 7.50$$
