## 习20 化学平衡-气相平衡计算

在1000 K时，反应 $\text{CO(g)} + \text{H}_2\text{O(g)} \rightleftharpoons \text{CO}_2\text{(g)} + \text{H}_2\text{(g)}$ 的 $K_p = 1.0$。将1.0 mol CO和3.0 mol H₂O置于5.0 L容器中，计算平衡时各组分的物质的量。（$K_c = K_p$，因 $\Delta n = 0$）

---

**答案：**

$K_c = K_p = 1.0$

设平衡时CO转化了 $x$ mol，浓度 = 物质的量/5.0 L：

$$K_c = \frac{(x/5)(x/5)}{((1-x)/5)((3-x)/5)} = \frac{x^2}{(1-x)(3-x)} = 1.0$$

$$x^2 = (1-x)(3-x) = 3 - 4x + x^2$$

$$0 = 3 - 4x \implies x = 0.75 \text{ mol}$$

平衡时各组分的物质的量：

- $n(\text{CO}) = 1.0 - 0.75 = 0.25$ mol
- $n(\text{H}_2\text{O}) = 3.0 - 0.75 = 2.25$ mol
- $n(\text{CO}_2) = 0.75$ mol
- $n(\text{H}_2) = 0.75$ mol
