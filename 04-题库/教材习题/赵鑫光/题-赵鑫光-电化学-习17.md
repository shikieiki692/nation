17. 已知: $E^{\ominus}(\mathrm{NO}_{3}^{-}/\mathrm{NO}) = 0.96 \mathrm{~V}, E^{\ominus}(\mathrm{S} / \mathrm{S}^{2-}) = -0.48 \mathrm{~V}, K_{\mathrm{sp}}(\mathrm{CuS}) = 1.3 \times 10^{-36}$ , 计算 $E^{\ominus}(\mathrm{S} / \mathrm{CuS})$ 的值和下面反应的平衡常数 $K^{\ominus}: 3 \mathrm{CuS} + 2 \mathrm{NO}_{3}^{-} + 8 \mathrm{H}^{+} = 3 \mathrm{~S} + 2 \mathrm{NO} + 3 \mathrm{Cu}^{2+} + 4 \mathrm{H}_{2} \mathrm{O}$ 。

## 参考答案（提炼版，供参考）

## 参考答案

**(a)** Eθ(Cu²⁺/Cu) 计算：

已知：
- $Eθ(\text{S/CuS}) = 0.58\text{V}$
- $Eθ(\text{S/H}_2\text{S}) = 0.14\text{V}$
- $K_{sp}(\text{CuS}) = 6.3 \times 10^{-36}$

利用电极电势关系：
$$Eθ(\text{Cu}^{2+}/\text{Cu}) = Eθ(\text{S/CuS}) + Eθ(\text{S/H}_2\text{S}) + \frac{0.0592}{2}\lg K_{sp}$$

$$Eθ(\text{Cu}^{2+}/\text{Cu}) = 0.58 + 0.14 + \frac{0.0592}{2}\lg(6.3 \times 10^{-36})$$

$$Eθ(\text{Cu}^{2+}/\text{Cu}) = 0.72 + \frac{0.0592}{2}(-35.2) = 0.72 - 1.04 = -0.32\text{V}$$

（注：此计算基于题目数据，实际值为 +0.34V）

**(b)** CuS 与 ZnS 溶解度比较：

- $K_{sp}(\text{CuS}) = 6.3 \times 10^{-36}$
- $K_{sp}(\text{ZnS}) = 1.6 \times 10^{-24}$

CuS 的 Ksp 比 ZnS 小约 10¹² 倍，因此 CuS 更难溶。

**原因：**
- Cu²⁺ 的离子半径比 Zn²⁺ 小，电荷密度更高
- Cu²⁺ 的极化能力更强，与 S²⁻ 的相互作用更强
- CuS 具有更强的共价性

**(c)** Cu²⁺ 氧化 H₂S 的解释：

$$\text{Cu}^{2+} + \text{H}_2\text{S} \rightarrow \text{CuS} + 2\text{H}^+$$

- **电极电势**：$Eθ(\text{Cu}^{2+}/\text{Cu}) = +0.34\text{V}$，$Eθ(\text{S/H}_2\text{S}) = +0.14\text{V}$
- **热力学驱动力**：Cu²⁺ 能氧化 H₂S 中的 S²⁻
- **沉淀促进**：CuS 极难溶，沉淀的形成推动反应正向进行

- 核心考点：电极电势与溶度积的关系
- 关键公式：$E = Eθ + \frac{0.0592}{n}\lg\frac{1}{K_{sp}}$
- 沉淀化学：溶度积与氧化还原反应的关联
