# 题-赵鑫光-电化学-习2：离子电子法配平（15题）

## 题目

用离子电子法配平下列半反应和完整反应：

**(1)** $\text{MnO}_4^- \rightarrow \text{MnO}_4^{2-}$（碱性）

**(2)** $\text{CrO}_4^{2-} \rightarrow \text{Cr(OH)}_3$（碱性）

**(3)** $\text{IO}_3^- \rightarrow \text{I}_2$（酸性）

**(4)** $\text{AsO}_4^{3-} \rightarrow \text{AsO}_2^-$（碱性）

**(5)** $\text{S}_2\text{O}_3^{2-} \rightarrow \text{SO}_4^{2-}$（碱性）

**(6)** $\text{MnO}_4^- + \text{SO}_3^{2-} \rightarrow \text{MnO}_2 + \text{SO}_4^{2-}$（碱性）

**(7)** $\text{Cr}_2\text{O}_7^{2-} + \text{Fe}^{2+} \rightarrow \text{Cr}^{3+} + \text{Fe}^{3+}$（酸性）

**(8)** $\text{ClO}^- + \text{NH}_3 \rightarrow \text{Cl}^- + \text{N}_2$（碱性）

**(9)** $\text{NO}_3^- + \text{I}^- \rightarrow \text{NO}_2^- + \text{I}_2$（碱性）

**(10)** $\text{MnO}_4^- + \text{Br}^- \rightarrow \text{MnO}_2 + \text{BrO}_3^-$（碱性）

**(11)** $\text{Co}^{3+} + \text{Co}^{2+} \rightarrow \text{Co}_3\text{O}_4$（碱性）

**(12)** $\text{Cu}^{2+} + \text{CN}^- \rightarrow \text{CuCN} + (\text{CN})_2$（酸性）

**(13)** $\text{FeO}_4^{2-} + \text{Cl}^- \rightarrow \text{Fe(OH)}_3 + \text{Cl}_2$（碱性）

**(14)** $\text{S}_4\text{O}_6^{2-} + \text{OH}^- \rightarrow \text{SO}_3^{2-} + \text{SO}_4^{2-}$（碱性）

**(15)** $\text{MnO}_4^- + \text{H}_2\text{O}_2 \rightarrow \text{MnO}_2 + \text{O}_2$（碱性）

---

## 参考答案

**(1)** $\text{MnO}_4^- + e^- \rightarrow \text{MnO}_4^{2-}$

**(2)** $\text{CrO}_4^{2-} + 4\text{H}_2\text{O} + 3e^- \rightarrow \text{Cr(OH)}_3 + 5\text{OH}^-$

**(3)** $2\text{IO}_3^- + 12\text{H}^+ + 10e^- \rightarrow \text{I}_2 + 6\text{H}_2\text{O}$

**(4)** $\text{AsO}_4^{3-} + 2\text{H}_2\text{O} + 2e^- \rightarrow \text{AsO}_2^- + 4\text{OH}^-$

**(5)** $\text{S}_2\text{O}_3^{2-} + 10\text{OH}^- - 8e^- \rightarrow 2\text{SO}_4^{2-} + 5\text{H}_2\text{O}$

**(6)** $2\text{MnO}_4^- + 3\text{SO}_3^{2-} + \text{H}_2\text{O} \rightarrow 2\text{MnO}_2 + 3\text{SO}_4^{2-} + 2\text{OH}^-$

**(7)** $\text{Cr}_2\text{O}_7^{2-} + 6\text{Fe}^{2+} + 14\text{H}^+ \rightarrow 2\text{Cr}^{3+} + 6\text{Fe}^{3+} + 7\text{H}_2\text{O}$

**(8)** $3\text{ClO}^- + 2\text{NH}_3 \rightarrow 3\text{Cl}^- + \text{N}_2 + 3\text{H}_2\text{O}$

**(9)** $2\text{NO}_3^- + 2\text{I}^- + \text{H}_2\text{O} \rightarrow 2\text{NO}_2^- + \text{I}_2 + 2\text{OH}^-$

**(10)** $2\text{MnO}_4^- + \text{Br}^- + \text{H}_2\text{O} \rightarrow 2\text{MnO}_2 + \text{BrO}_3^- + 2\text{OH}^-$

**(11)** $4\text{Co}^{3+} + 2\text{Co}^{2+} + 12\text{OH}^- \rightarrow 2\text{Co}_3\text{O}_4 + 6\text{H}_2\text{O}$

**(12)** $2\text{Cu}^{2+} + 4\text{CN}^- \rightarrow 2\text{CuCN} + (\text{CN})_2$

**(13)** $2\text{FeO}_4^{2-} + 6\text{Cl}^- + 8\text{H}_2\text{O} \rightarrow 2\text{Fe(OH)}_3 + 3\text{Cl}_2 + 10\text{OH}^-$

**(14)** $\text{S}_4\text{O}_6^{2-} + 2\text{OH}^- \rightarrow \text{SO}_3^{2-} + \text{SO}_4^{2-} + \text{H}_2\text{O} + \text{S}_2\text{O}_3^{2-}$

**(15)** $2\text{MnO}_4^- + 3\text{H}_2\text{O}_2 \rightarrow 2\text{MnO}_2 + 3\text{O}_2 + 2\text{OH}^- + 2\text{H}_2\text{O}$

## 知识点映射

- 核心考点：离子电子法配平半反应和完整反应
- 关键步骤：酸性条件用 H⁺/H₂O 配平，碱性条件用 OH⁻/H₂O 配平
- 常见错误：忘记配平电荷或原子数
