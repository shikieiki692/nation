27. 下列各组量子数中, 相应于氢原子薛定谔方程的合理解的一组是 ( )
A. 3 0 +1 - $\frac{1}{2}$ B. 2 2 0 + $\frac{1}{2}$ C. 4 1 -1 - $\frac{1}{2}$ D. 4 -2 0 + $\frac{1}{2}$

## 参考答案（提炼版，供参考）

## 参考答案

**答案：C（$4, 1, -1, -\frac{1}{2}$）**

**解析：**

量子数的取值规则：
- $n$（主量子数）：正整数 $1, 2, 3, \ldots$
- $l$（角量子数）：$0, 1, 2, \ldots, n-1$（即 $l < n$）
- $m_l$（磁量子数）：$-l, -l+1, \ldots, 0, \ldots, l-1, l$（即 $|m_l| \leq l$）
- $m_s$（自旋量子数）：$+\frac{1}{2}$ 或 $-\frac{1}{2}$

逐项检验：

**A.** $(3, 2, 3, +\frac{1}{2})$
- $n=3, l=2$：$l < n$，合法。
- $m_l = 3$：但 $|m_l| \leq l = 2$，$m_l$ 最大只能为 $+2$，**$m_l = 3$ 不合法**。

**B.** $(2, 2, -1, -\frac{1}{2})$
- $n=2, l=2$：$l$ 必须小于 $n$，即 $l \leq 1$，**$l = 2$ 不合法**。

**C.** $(4, 1, -1, -\frac{1}{2})$
- $n=4, l=1$：$l < n$，合法。
- $m_l = -1$：$|m_l| \leq l = 1$，合法。
- $m_s = -\frac{1}{2}$，合法。**全部合法。**

**D.** $(5, 3, 4, +\frac{1}{2})$
- $n=5, l=3$：$l < n$，合法。
- $m_l = 4$：$|m_l| \leq l = 3$，$m_l$ 最大只能为 $+3$，**$m_l = 4$ 不合法**。

因此选 **C**。
