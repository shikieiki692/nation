# 题目

四氮化四硫S₄N₄是一种重要的无机化合物，具有独特的笼状结构。

(1) S₄N₄的结构特征是什么？画出其笼状结构示意图。

(2) 计算S₄N₄中的12π电子离域体系。

(3) S和N的氧化数分别为多少？

(4) 解释S₄N₄显橙红色的原因。

(5) 写出S₄N₄的一种合成方法。

---

# 答案要点

(1) **笼状结构**: S₄N₄中4个N原子占据近似四面体的4个顶点，4个S原子占据近似正方形的4个顶点（穿插在N四面体中）。S-N-S桥键连接N原子，形成笼状。S-S跨环距离约2.58 Å（接近S-S单键2.05 Å，有弱相互作用）。

(2) 12π电子体系：每个N原子贡献1个p轨道和2个电子（孤对电子参与共轭），每个S原子贡献1个p轨道和1个电子。12个原子的p轨道形成离域π键，总计12个π电子。

(3) 氧化数：
- N的电负性(3.0) > S的电负性(2.5)
- N为**-3**，S为**+3**
- 验证：4×(+3) + 4×(-3) = 0 ✓

(4) **显色原因**: S₄N₄的12π电子离域体系形成大的共轭体系，HOMO-LUMO能隙较小，可吸收可见光（蓝紫光区域），因此呈现互补色**橙红色**。

(5) 合成方法：
$$2\text{SCl}_2 + 2\text{NH}_3 \rightarrow \text{S}_4\text{N}_4 + 6\text{HCl} + 2\text{S}$$
或更经典的方法：
$$6\text{S}_2\text{Cl}_2 + 16\text{NH}_3 \rightarrow \text{S}_4\text{N}_4 + 12\text{NH}_4\text{Cl} + 8\text{S}$$
