8.电解它们的熔融氯化物，阴极放电反应最可能正确的是 （）A. $\mathrm{Q}^{2 + } + 2\mathrm{e}^{-}\rightarrow \mathrm{Q}$ B. $\mathbb{R}^{2 + } + 2\mathrm{e}^{-}\rightarrow \mathbb{R}$ C. $\mathrm{S}^{3 + } + 3\mathrm{e}^{-}\rightarrow \mathrm{S}$ D. $\mathrm{T}^{3 + } + 3\mathrm{e}^{-}\rightarrow \mathrm{T}$ E. $\mathrm{U}^{2 + } + 2\mathrm{e}^{-}\rightarrow \mathrm{U}$

## 参考答案（提炼版，供参考）

## 参考答案

**答案：D（T³⁺ + 3e⁻ → T）**

**解题思路：**

阴极放电的难易程度与金属的电极电势有关：**电极电势越正（或越不负），越容易在阴极被还原放电。**

判断依据：
- 电离能越高，说明原子对电子的束缚力越强，其离子越难被还原
- 电离能越低，说明原子容易失去电子，其离子也容易在阴极获得电子放电

但这里需要注意是**多价离子的总能量**。T³⁺ + 3e⁻ → T 的过程需要考虑T的I₁ + I₂ + I₃的逆过程。如果T的前几级电离能都较低，说明T³⁺ 容易结合3个电子回到基态。

此外，从电极电势角度看，某些过渡金属或主族金属的高价离子（如 T³⁺）由于水合能较大，其标准电极电势可能较正，因此更容易在阴极放电。
