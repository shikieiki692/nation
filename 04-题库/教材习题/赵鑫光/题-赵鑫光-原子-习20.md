20. 下列各套量子数中, 可描述元素 Sc 的 $3d^{1}4s^{2}$ 次外层的一个电子的是 ( )
A. $3,1,1,+\frac{1}{2}$ B. $3,2,0,+\frac{1}{2}$ C. $3,0,1,-\frac{1}{2}$ D. $3,0,2,+\frac{1}{2}$

## 参考答案（提炼版，供参考）

## 参考答案

**答案：AB（$3, 2, 0, +\frac{1}{2}$ 和 $3, 1, 1, +\frac{1}{2}$）**

**解析：**

Sc 的基态电子排布为 $1s^2 2s^2 2p^6 3s^2 3p^6 3d^1 4s^2$。

**次外层**为第三层（$n=3$），包含以下电子：
- $3s^2$：$n=3, l=0$
- $3p^6$：$n=3, l=1$
- $3d^1$：$n=3, l=2$

分析各选项：
- **A**：$(3, 2, 0, +\frac{1}{2})$ — 这是 $3d$ 电子的量子数，$l=2$ 对应 d 轨道，$m_l=0$ 合法，**正确**。
- **B**：$(3, 1, 1, +\frac{1}{2})$ — 这是 $3p$ 电子的量子数，$l=1$ 对应 p 轨道，$m_l=1$ 合法，**正确**。
- **C**：$(4, 0, 0, +\frac{1}{2})$ — 这是 $4s$ 电子，属于**最外层**（$n=4$），不是次外层，**错误**。
- **D**：$(3, 2, -1, -\frac{1}{2})$ — 虽然量子数本身合法，但 Sc 的 $3d$ 层只有 1 个电子，按构造原理自旋应取 $+\frac{1}{2}$，且题目问的是"可能"的量子数。$m_l = -1$ 对应另一个 d 轨道，而 $3d^1$ 只占一个轨道，此选项虽量子数合法但不是该电子的实际量子数。

综合分析选 **AB**。
