## 按卷分组

```dataview
TABLE WITHOUT ID
    key AS 卷,
    rows.file.link AS 题目,
    length(rows.file.link) AS 题数
FROM "04-题库/教材习题/北斗学友"
WHERE type = "题目"
FLATTEN split(string(file.name), "-")[3] AS key
GROUP BY key
SORT key ASC
```
