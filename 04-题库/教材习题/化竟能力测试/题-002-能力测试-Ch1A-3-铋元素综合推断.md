# 题-002-能力测试-Ch1A-3-铋元素综合推断

## 题目

某元素 X 在自然界中储量较低，其存在形态有游离态和化合态（主要为 $\mathrm{X_2O_3}$ 和 $\mathrm{X_2S_3}$）两种。X 是较弱的导体，其电导随温度的升高而降低，但熔融后迅速增加。X 的熔点是 545 K，熔融后体积缩小。X 的沸点为 $1883\ \mathrm{K}(p=1.01\times10^{5}\ \mathrm{Pa})$。该温度下的蒸汽密度为 $3.011\ \mathrm{g\cdot dm^{-3}}$，而在 2280 K 和 2770 K 时蒸汽密度则分别为 $1.122\ \mathrm{g\cdot dm^{-3}}$ 和 $0.919\ \mathrm{g\cdot dm^{-3}}$。

X 不与无氧化性的稀酸反应，但可被浓硫酸或王水氧化转化为硫酸盐或氯化物（X 的氧化态为Ⅲ）。X(Ⅲ)的盐可与碱金属卤化物或硫酸盐作用形成配合物（如 $\mathrm{XCl_4^-}$、$\mathrm{XCl_5^{2-}}$ 和 $\mathrm{X(SO_4)_2^-}$ 等）。X 也形成 XN 和 $\mathrm{XH_3}$ 等化合物，在这些化合物中，X 的氧化态为-Ⅲ。X 还可生成 $\mathrm{X_2O_3}$，其中 X 的氧化态为Ⅲ。X(Ⅲ)卤化物也可由 X 和卤素直接反应生成。X(Ⅲ)的许多盐可溶解在乙醚和丙酮中。这些盐在强酸性介质中是稳定的，在中性介质中则生成含氧酸盐（羟基盐沉淀），并逐渐转化成如 $\mathrm{XONO_3}$ 型体。X(Ⅲ)的盐在碱性介质中可被强氧化剂氧化成 X(V)的化合物，在酸性介质中 X(V)的化合物能将 $\mathrm{Mn^{2+}}$ 氧化为 $\mathrm{MnO_4^-}$。

<!-- 校勘: 前句「X 还可生成 X₂O₃，其中 X 的氧化态为Ⅳ」依 X₂O₃ 化学式改氧化态为Ⅲ（中高置信），详见 L1 校勘记 -->

X 的化合物有毒。在治消化道溃疡药及杀菌药中含少量 X 化合物。在碱性介质中，用亚锡酸盐可将 X 的化合物还原为游离态的 X，这可用于 X 的定性分析。

请回答下列问题：

3-1 写出 X 的名称、元素符号及原子的电子构型。

<!-- 缺小问: 3-2 小问题面文本 OCR 缺失（解答侧存在 3-2：沸点蒸汽密度与分子型体推断），不代拟 -->

3-3 写出 X 与浓硫酸、稀硝酸反应的方程式。

3-4 写出 $\mathrm{X^{3+}}$ 与卤化物、碱金属硫酸盐配位的方程式，画出 $\mathrm{XCl_6^-}$ 的几何构型，说明 X 用什么轨道成键？

3-5 写出 X(Ⅲ)盐水解的反应方程式。

3-6 写出在酸性介质中五价 X 化合物与 $\mathrm{Mn^{2+}}$ 反应的离子方程式。

3-7 写出 X(Ⅲ)化合物与亚锡酸盐发生还原反应的方程式，为什么该反应必须在较低温度下进行?

3-8 确定下列原电池的正负极：Pt, H₂ | HCl | XCl₃, X。

### 答案

- 3-1 铋 Bi，电子构型 $[Xe]4f^{14}5d^{10}6s^{2}6p^{3}$
- 3-2 沸点 1883 K 时以 $\mathrm{Bi_2(g)}$ 型体存在；沸点以上以 $\mathrm{Bi(g)}$ 状态存在
- 3-3 $2\mathrm{Bi} + 6\mathrm{H_2SO_4} \xrightarrow{\Delta} \mathrm{Bi_2(SO_4)_3} + 3\mathrm{SO_2}\uparrow + 6\mathrm{H_2O}$；$\mathrm{Bi} + 4\mathrm{HNO_3} \longrightarrow \mathrm{Bi(NO_3)_3} + \mathrm{NO}\uparrow + 2\mathrm{H_2O}$
- 3-4 $\mathrm{KBiCl_4}$、$\mathrm{K_2BiCl_5}$、$\mathrm{KBi(SO_4)_2}$；正八面体，Bi 以 $\mathrm{sp^3d^2}$ 杂化轨道成键
- 3-5 $\mathrm{Bi(NO_3)_3} + \mathrm{H_2O} \longrightarrow \mathrm{BiONO_3}\downarrow + 2\mathrm{HNO_3}$；$\mathrm{BiCl_3} + \mathrm{H_2O} \longrightarrow \mathrm{BiOCl}\downarrow + 2\mathrm{HCl}$
- 3-6 $5\mathrm{NaBiO_3} + 2\mathrm{Mn^{2+}} + 14\mathrm{H^+} \longrightarrow 2\mathrm{MnO_4^-} + 5\mathrm{Bi^{3+}} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$
- 3-7 $2\mathrm{Bi^{3+}} + 3\mathrm{HSnO_2^-} + 6\mathrm{OH^-} \longrightarrow 2\mathrm{Bi} + 3\mathrm{HSnO_3^-} + 3\mathrm{H_2O}$；温度高时 $\mathrm{HSnO_2^-}$ 发生自氧化还原析出黑色 Sn，故需较低温度
- 3-8 (−) $\mathrm{Pt, H_2 \mid HCl \mid BiCl_3, Bi}$ (+)

### 解析

3-1 X 为铋 Bi，其电子构型为 $[Xe]4f^{14}5d^{10}6s^{2}6p^{3}$。

3-2 根据理想气体状态方程 $pV = nRT = \dfrac{m}{M}RT$ 得：$M = \dfrac{\rho RT}{p}$。

当 $T = 1883\ \mathrm{K}$ 时，$M = \dfrac{3.011 \times 8.314 \times 1883}{1.014 \times 10^{5} \times 10^{-3}} = 464.9\ (\mathrm{g\cdot mol^{-1}})$

Bi 的原子量为 208.98。在沸点 1883 K 时以 $\mathrm{Bi_2(g)}$ 型体存在。

$T = 2280\ \mathrm{K}$ 时，$M = \dfrac{1.122 \times 8.314 \times 2280}{1.014 \times 10^{5} \times 10^{-3}} = 209.75\ (\mathrm{g\cdot mol^{-1}})$

$T = 2770\ \mathrm{K}$ 时，$M = \dfrac{0.919 \times 8.314 \times 2770}{1.014 \times 10^{5} \times 10^{-3}} = 208.7\ (\mathrm{g\cdot mol^{-1}})$

故在沸点以上以 $\mathrm{Bi(g)}$ 状态存在。

由低温到高温时，$\mathrm{Bi_2(g)} \rightleftharpoons 2\mathrm{Bi(g)}$（正向平衡常数为 $K_p$，逆向为 $K_p'$）

$$K_p = \frac{p_{\mathrm{Bi}}^2}{p_{\mathrm{Bi_2}}},\qquad K_{p'} = (K_p)^{-1} = \frac{p_{\mathrm{Bi_2}}}{p_{\mathrm{Bi}}^2}$$

3-3 $2\mathrm{Bi} + 6\mathrm{H_2SO_4} \xrightarrow{\Delta} \mathrm{Bi_2(SO_4)_3} + 3\mathrm{SO_2}\uparrow + 6\mathrm{H_2O}$；$\mathrm{Bi} + 4\mathrm{HNO_3} \longrightarrow \mathrm{Bi(NO_3)_3} + \mathrm{NO}\uparrow + 2\mathrm{H_2O}$

3-4 $\mathrm{BiCl_3} + \mathrm{KCl} \longrightarrow \mathrm{KBiCl_4}$；$\mathrm{BiCl_3} + 2\mathrm{KCl} \longrightarrow \mathrm{K_2BiCl_5}$

$\mathrm{Bi_2(SO_4)_3} + \mathrm{K_2SO_4} \longrightarrow 2\mathrm{KBi(SO_4)_2}$

正八面体；Bi 以 $\mathrm{sp^3d^2}$ 杂化轨道成键。

3-5 $\mathrm{Bi(NO_3)_3} + \mathrm{H_2O} \longrightarrow \mathrm{BiONO_3}\downarrow + 2\mathrm{HNO_3}$

$\mathrm{BiCl_3} + \mathrm{H_2O} \longrightarrow \mathrm{BiOCl}\downarrow + 2\mathrm{HCl}$
