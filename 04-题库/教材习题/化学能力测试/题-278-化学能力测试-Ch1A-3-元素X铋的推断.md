# 元素 X（铋）的推断

> **来源**：化学竞赛能力测试·第1章 化学反应方程式与核化学反应方程式·A卷第3题（10 分）

## 题目

某元素 X 在自然界中储量较低，其存在形态有游离态和化合态（主要为 $\mathrm{X_2O_3}$ 和 $\mathrm{X_2S_3}$）两种。X 是较弱的导体，其电导随温度的升高而降低，但熔融后迅速增加。X 的熔点是 545 K，熔融后体积缩小。X 的沸点为 1883 K（p = 1.01×10⁵ Pa）。该温度下的蒸汽密度为 3.011 g·dm⁻³，而在 2280 K 和 2770 K 时蒸汽密度则分别为 1.122 g·dm⁻³ 和 0.919 g·dm⁻³。

X 不与无氧化性的稀酸反应，但可被浓硫酸或王水氧化转化为硫酸盐或氯化物（X 的氧化态为 Ⅲ）。X(Ⅲ) 的盐可与碱金属卤化物或硫酸盐作用形成配合物（如 $\mathrm{XCl_4^-}$、$\mathrm{XCl_5^{2-}}$ 和 $\mathrm{X(SO_4)_2^-}$ 等）。X 也形成 XN 和 $\mathrm{XH_3}$ 等化合物，在这些化合物中，X 的氧化态为 −Ⅲ。X 还可生成 $\mathrm{X_2O_3}$，其中 X 的氧化态为 IV（原文如此，系 X₂O₄/XO₂ 型氧化物之误写）。X(Ⅲ) 卤化物也可由 X 和卤素直接反应生成。X(Ⅲ) 的许多盐可溶解在乙醚和丙酮中。这些盐在强酸性介质中是稳定的，在中性介质中则生成含氧酸盐（羟基盐沉淀），并逐渐转化成如 XONO₃ 型体。X(Ⅲ) 的盐在碱性介质中可被强氧化剂氧化成 X(V) 的化合物，在酸性介质中 X(V) 的化合物能将 $\mathrm{Mn^{2+}}$ 氧化为 $\mathrm{MnO_4^-}$。

X 的化合物有毒。在治消化道溃疡药及杀菌药中含少量 X 化合物。在碱性介质中，用亚锡酸盐可将 X 的化合物还原为游离态的 X，这可用于 X 的定性分析。

请回答下列问题：

3-1 写出 X 的名称、元素符号及原子的电子构型。

3-2 （题面 OCR 缺失，按答案反推为）计算各温度下蒸气的摩尔质量，确定 X 蒸气在沸点 1883 K 及 2280 K、2770 K 时以何种分子型体存在，并写出低温（沸点）型体与高温型体之间的平衡关系。

3-3 写出 X 与浓硫酸、稀硝酸反应的方程式。

3-4 写出 $\mathrm{X^{3+}}$ 与卤化物、碱金属硫酸盐配位的方程式，画出 $\mathrm{XCl_6^-}$ 的几何构型，说明 X 用什么轨道成键？

3-5 写出 X(Ⅲ) 盐水解的反应方程式。

3-6 写出在酸性介质中五价 X 化合物与 $\mathrm{Mn^{2+}}$ 反应的离子方程式。

3-7 写出 X(Ⅲ) 化合物与亚锡酸盐发生还原反应的方程式，为什么该反应必须在较低温度下进行？

3-8 确定下列原电池的正负极：Pt, H₂ | HCl | XCl₃, X。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**3-1** X 为铋 Bi，电子构型为 $[\mathrm{Xe}]4f^{14}5d^{10}6s^2 6p^3$。

（判据：熔点 545 K 与 Bi 273.3℃ 熔融体积缩小相符；Bi 蒸气可双原子化；Bi(III) 水解 BiONO₃/BiOCl；Bi(V) NaBiO₃ 氧化 Mn²⁺；铋盐用于消化道溃疡药如枸橼酸铋钾。）

**3-2** 由理想气体状态方程 $pV = nRT = \dfrac{m}{M}RT$ 得 $M = \dfrac{\rho RT}{p}$。

- T = 1883 K（沸点）：$M = \dfrac{3.011 \times 8.314 \times 1883}{1.014 \times 10^5 \times 10^{-3}} = 464.9\ \mathrm{g/mol}$，为 Bi 原子量 208.98 的 ~2.2 倍 → 以 $\mathrm{Bi_2(g)}$ 型体存在（约双聚）
- T = 2280 K：$M = \dfrac{1.122 \times 8.314 \times 2280}{1.014 \times 10^5 \times 10^{-3}} = 209.75\ \mathrm{g/mol}$ → 以 $\mathrm{Bi(g)}$ 单原子存在
- T = 2770 K：$M = \dfrac{0.919 \times 8.314 \times 2770}{1.014 \times 10^5 \times 10^{-3}} = 208.7\ \mathrm{g/mol}$ → 单原子 Bi(g)

平衡关系：由低温到高温，$\mathrm{Bi_2(g)} \rightleftharpoons[K_{p'}]{K_p} 2\mathrm{Bi(g)}$

$K_p = \dfrac{p_\mathrm{Bi}^2}{p_{\mathrm{Bi_2}}}$，$K_{p'} = (K_p)^{-1} = \dfrac{p_{\mathrm{Bi_2}}}{p_\mathrm{Bi}^2}$

**3-3** $2\mathrm{Bi + 6H_2SO_4(浓) \xrightarrow{\Delta} Bi_2(SO_4)_3 + 3SO_2\uparrow + 6H_2O}$

$\mathrm{Bi + 4HNO_3 \longrightarrow Bi(NO_3)_3 + NO\uparrow + 2H_2O}$（稀硝酸产物为 NO）

**3-4** 配位反应：

$\mathrm{BiCl_3 + KCl \longrightarrow KBiCl_4}$（即 $\mathrm{[BiCl_4]^-}$）

$\mathrm{BiCl_3 + 2KCl \longrightarrow K_2BiCl_5}$（即 $\mathrm{[BiCl_5]^{2-}}$）

$\mathrm{Bi_2(SO_4)_3 + K_2SO_4 \longrightarrow 2KBi(SO_4)_2}$

$\mathrm{[BiCl_6]^{3-}}$ 为正八面体构型，Bi 采用 $\mathrm{sp^3d^2}$ 杂化轨道成键。

**3-5** 水解反应：

$\mathrm{Bi(NO_3)_3 + H_2O \longrightarrow BiONO_3\downarrow + 2HNO_3}$

$\mathrm{BiCl_3 + H_2O \longrightarrow BiOCl\downarrow + 2HCl}$

**3-6** $5\mathrm{NaBiO_3 + 2Mn^{2+} + 14H^+ \longrightarrow 2MnO_4^- + 5Bi^{3+} + 5Na^+ + 7H_2O}$

（Bi(V) 强氧化性将 Mn²⁺ 氧化为 MnO₄⁻；电子守恒：Mn+2→+7 失 5e×2=10e，Bi+5→+3 得 2e×5=10e ✓）

**3-7** $2\mathrm{Bi^{3+} + 3HSnO_2^- + 6OH^- \longrightarrow 2Bi\downarrow + 3HSnO_3^- + 3H_2O}$

必须在较低温度下进行：温度高时 $\mathrm{HSnO_2^-}$ 发生自氧化还原，析出黑色 Sn，干扰 Bi 的还原检验。

**3-8** 原电池 $(-)\ \mathrm{Pt, H_2 | HCl | BiCl_3, Bi}\ (+)$

（H₂/H⁺ 为负极，BiCl₃/Bi 为正极；电子由 H₂ 极经外电路流向 Bi 极）
