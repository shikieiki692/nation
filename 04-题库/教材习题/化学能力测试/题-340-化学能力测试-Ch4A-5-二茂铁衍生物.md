# 二茂铁及其衍生物合成

> **来源**：化学竞赛能力测试·第4章·A卷第5题（10 分）

在有机溶剂（如四氢呋喃）中环戊二烯被钠还原为 C₅H₅⁻ 阴离子，它和阳离子，如 Fe²⁺、Co²⁺、Ni²⁺、Mn²⁺、V²⁺……形成有色配合物。其中铁配合物中含 30.05% Fe、64.57% C 及 5.38% H。该铁配合物具有芳香性、氧化还原活性、稳定性和低毒性等特殊性质，可作功能材料、超导材料等，具有很广泛的应用。

**5-1** 给出铁配合物及所有上述配合物的名称。画出 Fe(Ⅱ) 配合物的结构。

**5-2** 以 F 表示上述配合物，下面的一个合成路线为合成该配合物的多种衍生物。试确定 A~C 结构式。写出相关反应：

F →(DMF/POCl₃) A →(Ph₃P=CHCl, n-BuLi) B →(t-BuOK) C

**5-3** 请提出另一条制备 C 的合成路线。

**5-4** 合成 2-甲酰-1-氯乙烯基 F 的过程中，反应必须在惰性气氛中进行。所用的原料是 F、磷酸、醋酸酐、H—CO—N(CH₃)₂、POCl₃。试提出制备上述物质的反应机理。

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 由元素质量分数可以得到铁配合物的化学式：C:H = 64.57/12 : 5.38/1 = 5.38:5.38 = 1:1；Fe 30.05/55.85 = 0.538 → Fe:C:H = 1:10:10，即 FeC₁₀H₁₀。该铁配合物为二茂铁（双环戊二烯基铁(Ⅱ)，夹心配合物），名称：二茂铁/ferrocene。

配合物名称：二茂铁 Fe(C₅H₅)₂、钴茂 Co(C₅H₅)₂、镍茂 Ni(C₅H₅)₂、锰茂 Mn(C₅H₅)₂、钒茂 V(C₅H₅)₂ 等（metallocenes）。

Fe(Ⅱ) 配合物结构（夹心：两个 η⁵-C₅H₅⁻ 平面夹 Fe²⁺，D₅d 交错式）：

$$\mathrm{Fe}(\eta^5\text{-}\mathrm{C_5H_5})_2$$

**5-2** 合成路线（F = 二茂铁）：

- A = 甲酰基二茂铁（FcCHO，Vilsmeier 甲酰化：DMF/POCl₃）
- B = 氯乙烯基二茂铁（Wittig：Ph₃P=CHCl 与醛生成 β-氯乙烯基）
- C = 乙炔基二茂铁（Fc—C≡CH，t-BuOK 消除 HCl）

$$(\eta^5\mathrm{C_5H_5})_2\mathrm{Fe} \xrightarrow{\mathrm{DMF/POCl_3}} (\eta^5\mathrm{C_5H_5})\mathrm{Fe}(\eta^5\mathrm{C_5H_4CHO})$$

$$(\eta^5\mathrm{C_5H_5})\mathrm{Fe}(\eta^5\mathrm{C_5H_4CHO}) + \mathrm{Ph_3P{=}CHCl} \longrightarrow (\eta^5\mathrm{C_5H_5})\mathrm{Fe}(\eta^5\mathrm{C_5H_4CH{=}CHCl}) + \mathrm{Ph_3PO}$$

$$(\eta^5\mathrm{C_5H_5})\mathrm{Fe}(\eta^5\mathrm{C_5H_4CH{=}CHCl}) \xrightarrow{t\text{-}\mathrm{BuOK}} (\eta^5\mathrm{C_5H_5})\mathrm{Fe}(\eta^5\mathrm{C_5H_4C{\equiv}CH})$$

**5-3** 另一条制备 C（乙炔基二茂铁）路线：FcCHO + CCl₄/Ph₃P（Corey-Fuchs）→ FcCCl₂? 或 FcCHO → FcCH=CH₂（Wittig CH₂）→ 溴化/脱 HBr → FcC≡CH；或 FcCOCH₃ 氯化…

（Corey-Fuchs 法：FcCHO + PPh₃/CBr₄ → FcCBr=CHBr → n-BuLi → FcC≡CH；照答案区图 1830 行给出的是 Hg 汞化/I 代/Sonogashira 偶联路线：FcH → FcHgCl → FcI → Fc—C≡CH（Me₃Si—C≡CH + Pd 催化）。）

**5-4** 机理（Vilsmeier-Haack 甲酰化）：

POCl₃ 与 DMF(HCO—N(CH₃)₂) 生成 Vilsmeier 试剂 [(CH₃)₂N=CHCl]⁺Cl⁻ → 对二茂铁环发生亲电芳香取代（Fc 环富电子）→ 亚胺中间体水解 → 甲酰基二茂铁。
