# 氢化锂/重氢化锂混合物

> **来源**：化学竞赛能力测试·第8章·A卷第9题（10 分）

8.40 g 固体试样与 235 mL 蒸馏水反应完全溶解，得：① 溶液（1.00 mL 恰用 50.0 mL 0.0460 M H₂SO₄ 滴定；密度 1.107 g/cm³；单一金属阳离子；溶质约 10%）；② 非放射性气体（相对 H₂ 密度 1.25）。电解同固体熔融物释放非放射性气体，摩尔质量≈2.95。

**9-1** 固体含什么物质？定量组成？写反应。

**9-2** 解释电解结果（摩尔质量保留一位小数）。

<details>
<summary>📖 查看答案与解析</summary>

**9-1** 气体密度 1.25 → 平均 M≈2.5：H₂+HD 混合物 → 固体含 MH 与 MD（IA 族氢化物）。水解强碱 → IA 族（IIA 氢氧化物不溶排除）。滴定算 M：碱浓度 $M_{\mathrm{al}}$×1.00=2×0.0460×50 → $M_{\mathrm{al}}$=4.60 mol/L：

M 溶质量分数与体积联立 → M≈7 → **Li**。混合气体 M：y mol LiH + (1−y) mol LiD → H₂ 与 HD 等 mol 平均 (2y+3(1−y))=2.5 → y=0.5：

**固体 = 0.5 mol LiH + 0.5 mol LiD**（8.4 g：0.5×8+0.5×9=8.5≈8.4 ✓）

$$\mathrm{LiH + H_2O \longrightarrow LiOH + H_2\uparrow}$$

$$\mathrm{LiD + H_2O \longrightarrow LiOH + HD\uparrow}$$

**9-2** 熔融电解 H⁻/D⁻ 阳极放电速率不同（H⁻ 快 k 倍）：H₂:HD:D₂ = k²:2k:1（二项式 (km+m)² 系数）。混合气体平均 M=2.95：

$$M = \frac{2k^2 + 3\times 2k + 4}{k^2 + 2k + 1} = 2.95$$

解一元二次方程 → **k=1.7**（H⁻ 阳极放电比 D⁻ 快 1.7 倍——与电解重水富集 D 同理）。

</details>
