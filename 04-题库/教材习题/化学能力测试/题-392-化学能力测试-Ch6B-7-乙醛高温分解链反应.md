# 乙醛高温分解链反应

> **来源**：化学竞赛能力测试·第6章·B卷第7题（10 分）

Hinshelwood（1956 诺贝尔化学奖）高温反应机理研究。乙醛高温分解：

| 反应 | 速率常数 | Eₐ/kJ·mol⁻¹ |
|---|---|---|
| CH₃CHO → CH₃· + HCO· | k₁ | 358 |
| CH₃· + CH₃CHO → CH₄ + CH₃CO· | k₂ | 8 |
| CH₃CO· → CH₃· + CO | k₃ | 59 |
| HCO· → H· + CO | k₄ | 65 |
| H· + CH₃CHO → H₂ + CH₃CO· | k₅ | 15 |
| 2CH₃· → C₂H₆ | k₆ | 0 |

**7-1** 按链引发、链传递、链终止分类。

**7-2** 稳态近似求 HCO·、H·、CH₃·、CH₃CO· 稳态浓度。

**7-3** 写出乙醛消耗速率方程和甲烷、乙烷、氢气、CO 生成速率。

**7-4** 乙醛分解两种途径——写配平方程式并分别给乙醛反应级数和活化能。

<details>
<summary>📖 查看答案与解析</summary>

**7-1** 反应 1 = 链引发；反应 6 = 链终止；反应 2~5 = 链传递。

**7-2** 稳态（AcH = CH₃CHO）：

① [HCO·]：d[HCO·]/dt = k₁[AcH] − k₄[HCO·] = 0 → **[HCO·] = k₁/k₄[AcH]**

② [H·]：d[H·]/dt = k₄[HCO·] − k₅[H·][AcH] = 0 → **[H·] = k₄[HCO·]/(k₅[AcH]) = k₁/k₅**

③ [CH₃·]：d/dt = k₁[AcH] − k₂[CH₃·][AcH] + k₃[CH₃CO·] − 2k₆[CH₃·]² = 0

④ [CH₃CO·]：d/dt = k₂[CH₃·][AcH] − k₃[CH₃CO·] + k₅[H·][AcH] = 0

③+④（代入②①）：

$$0 = 2k_1[\mathrm{AcH}] - 2k_6[\mathrm{CH_3\cdot}]^2 \Rightarrow [\mathrm{CH_3\cdot}] = \sqrt{\frac{k_1}{k_6}}[\mathrm{AcH}]^{1/2}$$

$$[\mathrm{CH_3CO\cdot}] = \frac{k_2}{k_3}\sqrt{\frac{k_1}{k_6}}[\mathrm{AcH}]^{3/2} + \frac{k_1}{k_3}[\mathrm{AcH}]$$

**7-3**

$$-\frac{\mathrm d[\mathrm{AcH}]}{\mathrm dt} = k_1[\mathrm{AcH}] + k_2[\mathrm{CH_3\cdot}][\mathrm{AcH}] + k_5[\mathrm H\cdot][\mathrm{AcH}] = 2k_1[\mathrm{AcH}] + k_2\sqrt{\frac{k_1}{k_6}}[\mathrm{AcH}]^{3/2}$$

$$\frac{\mathrm d[\mathrm{CH_4}]}{\mathrm dt} = k_2\sqrt{k_1/k_6}[\mathrm{AcH}]^{3/2}$$

$$\frac{\mathrm d[\mathrm{C_2H_6}]}{\mathrm dt} = k_1[\mathrm{AcH}]$$

$$\frac{\mathrm d[\mathrm{H_2}]}{\mathrm dt} = k_1[\mathrm{AcH}]$$

$$\frac{\mathrm d[\mathrm{CO}]}{\mathrm dt} = k_3[\mathrm{CH_3CO\cdot}] + k_4[\mathrm{HCO\cdot}] = 2k_1[\mathrm{AcH}] + k_2\sqrt{k_1/k_6}[\mathrm{AcH}]^{3/2}$$

**7-4** 两途径：

**途径甲**：CH₃CHO → CH₄ + CO，**3/2 级**（甲烷生成主导），Eₐ = 187 kJ/mol（源答案：=E₁/2+E₂−E₆/2≈358/2+8≈187）

**途径乙**：2CH₃CHO → C₂H₆ + H₂ + 2CO，**1 级**（乙烷+氢气主导），Eₐ = 358 kJ/mol

两种途径均产 CO（前者 1 mol CO/1 mol 乙醛，后者 1 mol CO/1 mol 乙醛）。

</details>
