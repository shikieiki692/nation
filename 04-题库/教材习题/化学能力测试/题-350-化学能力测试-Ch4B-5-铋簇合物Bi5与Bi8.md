# 铋簇合物 Bi₅ 与 Bi₈

> **来源**：化学竞赛能力测试·第4章·B卷第5题（10 分）

铋的化合物丰富多彩。1978 年，化学家 R. C. Burns 在液态 $\mathrm{SO_2}$ 中，用 $\mathrm{AsF_5}$ 氧化金属铋制备了化合物 A。经分析，A 为离子化合物，且阴离子结构高度对称。已知 A 中铋元素的质量分数为 64.84%，Bi 元素的平均氧化数为 +0.6。

**5-1** 试确定 A 的结构简式，阐述并画出阳离子的结构；写出生成 A 的化学反应方程式。

金属铋与适量的 $\mathrm{BiCl_3}$、$\mathrm{AlCl_3}$ 在熔融的 $\mathrm{NaAlCl_4}$ 中反应也能制备含 A 的阳离子的化合物 B。B 也为离子化合物，且阴离子也高度对称。B 中铋元素质量分数为 67.33%。在制备 B 的过程中，若金属铋过量，则会生成化合物 C。C 中 Bi 元素质量分数为 83.18%。

**5-2** (1) 试通过计算确定 B 的分子式，写出制备 B 的化学反应。

(2) C 中的阳离子为全铋阳离子。试通过计算确定 C 的分子式，写出制备 C 的化学反应。

(3) 化合物 B 是顺磁性还是抗磁性？为什么？

(4) 化合物 C 的阳离子可看作是封闭的多面体中削去对称的两个顶点得到的立体构型。问该阳离子是什么构型？Bi 元素平均氧化数是多少？

**5-3** 有一种与 C 相似的阳离子 D 与阴离子 E 为等电子体，但两者却有不同结构。试画出 D 和 E 的结构，指出其点群。

<details>
<summary>📖 查看答案与解析</summary>

**5-1** Bi 正常化合价为 +3 和 +5 价，现在平均氧化数为 +0.6，说明是原子簇合离子 $\mathrm{Bi}_n^{m+}$。根据氧化数列方程：$0.6n = m$。可能是 $n=5, m=3$，所以 A 的阳离子为 $\mathrm{Bi}_5^{3+}$。

结构对称才最稳定，因此该阳离子可能是全铋三角双锥（$D_{3h}$）：

![[a5a628139870cbe1596f57340d2bfb6b9715e7dd835338a5b8a09fa9665e610b.jpg]]

去一个电子后所有 Bi 原子周围均为 8e⁻（满足 18e 经验）。阴离子结构高度对称，根据 As 的结构特点，猜测应为 $\mathrm{AsF_6^-}$，因此 A 的分子式为 $\mathrm{Bi_5(AsF_6)_3}$。铋元素质量分数验算：

$$w(\mathrm{Bi}) = \frac{5\times 209}{5\times 209 + 3\times 190} = \frac{1045}{1615} = 64.71\% \approx 64.84\%\ \checkmark$$

化学反应：

$$\mathrm{10Bi + 9AsF_5 \longrightarrow 2Bi_5(AsF_6)_3 + 3AsF_3}$$

**5-2** (1) B 的阴离子高度对称，根据质量守恒，阴离子应为 Al 的配离子 $\mathrm{AlCl_4^-}$，因此 B 的分子式为 $\mathrm{Bi_5(AlCl_4)_3}$。铋质量分数验算：

$$w(\mathrm{Bi}) = \frac{5\times 209}{5\times 209 + 3\times 169} = \frac{1045}{1552} = 67.33\%\ \checkmark$$

制备反应：

$$\mathrm{4Bi + BiCl_3 + 3AlCl_3 \longrightarrow Bi_5(AlCl_4)_3}$$

(2) 设 C 分子式为 $\mathrm{Bi}_n(\mathrm{AlCl_4})_m$，则 $\dfrac{209n}{209n + 169m} = 83.18\%$，即 $\dfrac{209n}{169m} = \dfrac{83.18}{16.82}$，得 $n/m = 4$。由于化合物 C 的阳离子可看作封闭多面体中削去对称的两个顶点，排除 $\mathrm{Bi}_4^{+}$（若是平面四边形）。$n/m = 4$ 的公比应为 2，即 $n=8, m=2$，C 的阳离子为 $\mathrm{Bi_8^{2+}}$，C 的分子式为 $\mathrm{Bi_8(AlCl_4)_2}$。

制备 C 的反应：

$$\mathrm{22Bi + 2BiCl_3 + 6AlCl_3 \longrightarrow 3Bi_8(AlCl_4)_2}$$

(3) $\mathrm{Bi_5(AlCl_4)_3}$ 为抗磁性物质，无未成对电子。

(4) 封闭多面体为 $\mathrm{Bi_9^{5+}}$（三角双锥加腰三角形）削去对称两个顶点 → Bi₈²⁺ 为**四方反棱柱**形：

![[66d12586e420af0f4a6d672450fc78821952156409ee4ffbca94c2754cd6df8c.jpg]]

$\mathrm{Bi_8^{2+}}$：$8x = 2$，$x = +0.25$。

**5-3** 与 $\mathrm{Bi_8^{2+}}$ 等电子体的阳离子应为簇离子 $\mathrm{Bi_9^{5+}}$，阴离子为 $\mathrm{Pb_9^{4-}}$ 或 $\mathrm{Sn_9^{4-}}$。结构式：

![[1ef121b9880c4b9ba029cd1cec54eaa07cf422b874da3c177fe111a416cb1d86.jpg]]

（$D_{3h}$ 点群，三角双锥）

![[596441c383798d524f6a181ec8e694f7a8636a3f483751e65982071edccfbcfb.jpg]]

（$\mathrm{Pb_9^{4-}}$ 或 $\mathrm{Sn_9^{4-}}$，$C_{4v}$ 点群）

</details>
