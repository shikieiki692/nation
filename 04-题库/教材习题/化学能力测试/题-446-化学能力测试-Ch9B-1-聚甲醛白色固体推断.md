# 聚甲醛白色固体推断

> **来源**：化学竞赛能力测试·第9章·B卷第1题（10 分）

## 题目

白色固体 A 是一种常用的有机试剂，具有下列性质：

① 有碱存在时加热，A 与 Cu(OH)₂ 反应，生成红色沉淀。
② 可以进行银镜反应。
③ 在 HCl 存在时，与过量的甲醇反应，生成光学惰性的挥发性化合物 B（不是外消旋体）为唯一产物。
④ 60 mg A 在过量的氧中燃烧，生成 44.8 mL 气体 C（在 0 ℃、760 mmHg 下测定，分子量为 44）和 0.036 mL 的液体 D。液体 D 与 B 反应生成气体 E，E 极易溶于水得到一溶液，该溶液广泛用于应用化学品、医药、生物学等方面，是廉价的且作用力很强的杀菌剂和防腐剂。另外，0.036 g D 与 60 mg A 含有相同量的氧。

1-1. 写出化合物 A、C 和 D 的实验式。
1-2. 写出 A 与氢氧化铜反应生成的红色沉淀的化学式。
1-3. 写出 A、B 和 E 的结构。
1-4. 写出所涉及的化学反应，包括 E 转化为 A 的反应。
1-5. 可以认为 A 和 B 属于同一种类的有机化合物吗？

## 参考答案

<details><summary>📖 查看答案与解析</summary>

由气体 C 的密度可推断 C 是 CO₂；D 一定是水（0.036 mL）。A 中 C、H 含量：n(C) = n(CO₂) = 44.8/22400 = 0.002 mol，n(H) = 2n(H₂O) = 2 × (0.036×16/18)/(16/18×…)=按氧含量法：0.036 g 水含氧 0.032 g，与 60 mg A 含氧相同，A 中 m(C)=0.002×12=0.024 g、m(O)=0.032 g、m(H)=0.060−0.024−0.032=0.004 g ⇒ 实验式 **CH₂O**。

**1-1** A：CH₂O（实验式）；C：CO₂；D：H₂O。

A 不是普通碳水化合物（其衍生物普遍旋光），而是甲醛的线性聚合物——**多聚甲醛 (CH₂O)ₙ**。

**1-2** Cu₂O（红色沉淀）。

**1-3** A：(CH₂O)ₙ（多聚甲醛）；B：CH₂(OCH₃)₂（甲醛二甲缩醛/二甲氧基甲烷）；E：CH₂O（甲醛）。

**1-4** 各反应：

(CH₂O)ₙ + 4nCu(OH)₂ + 2nNaOH → 2nCu₂O + nNa₂CO₃ + 6nH₂O

(CH₂O)ₙ + 4n[Ag(NH₃)₂]OH → 4nAg + n(NH₄)₂CO₃ + 2nH₂O + 6nNH₃

(CH₂O)ₙ + 2nCH₃OH ―[HCl]→ nCH₂(OCH₃)₂ + nH₂O

(CH₂O)ₙ + nO₂ → nCO₂ + nH₂O

H₂O + CH₂(OCH₃)₂ → CH₂O + 2CH₃OH（B 水解生 E）

nCH₂O → (CH₂O)ₙ（E 转化为 A，聚合）

**1-5** 是。形式上说二者都是缩醛（或更确切地说是醚类）。

</details>
