# 锂钴复合氧化物电极材料

> **来源**：化学竞赛能力测试·第3章·B卷第3题（10 分）

目前商品化的锂离子电池正极几乎都是锂钴复合氧化物，其理想结构如图所示：

![[bfd06cb6af8ec92631039aa6884e22d2438340c14a36619ae840fffb8d5d7b0d.jpg]]

**3-1** 用粗线框出这种理想结构的锂钴复合氧化物晶体的一个晶胞。

**3-2** 这种晶体的一个晶胞里有几个锂原子、几个钴原子和几个氧原子？

**3-3** 给出这种理想结构的锂钴复合氧化物的化学式（最简式）。

**3-4** 锂离子电池必须先长时间充电后才能使用。写出上述锂钴氧化物作为正极放电时的电极反应。

**3-5** 锂锰复合氧化物是另一种锂离子电池正极材料。它的理想晶体中有两种多面体：LiO₄ 四面体和 MnO₆ 八面体，个数比 1:2，LiO₄ 四面体相互分离，MnO₆ 八面体的所有氧原子全部取自 LiO₄ 四面体。写出这种晶体的化学式。

**3-6** 从右图获取信息，说明为什么锂锰氧化物正极材料在充电和放电时晶体中的锂离子可在晶体中移动，而且个数可变。并说明晶体中锂离子的增减对锰的氧化态有何影响。

<details>
<summary>📖 查看答案与解析</summary>

锂电池是当今很普遍的电池。本题以锂电池为载体，考查晶体结构。

**3-1** 画晶胞时要注意画出平行六面体：

![[42d34317d318a0132a21da52cf701fa06540e97170ce00b877824b7b10aca185.jpg]]

**3-2** 晶胞里有 3 个锂原子、3 个钴原子和 6 个氧原子。

**3-3** 根据原子在顶点、面心、棱心的贡献率，很容易得化学式为 LiCoO₂。

**3-4** 电极反应方程式（正极放电，Li⁺ 嵌入）：

$$\mathrm{Li_{1-x}CoO_2} + x\mathrm{Li^+} + x\mathrm{e^-} \xrightarrow{\text{放电}} \mathrm{LiCoO_2}\ (\text{理想})$$

（充电则为逆过程：LiCoO₂ − xe⁻ → Li₁₋ₓCoO₂ + xLi⁺，Co 氧化态升高。）

**3-5** 化学式：LiMn₂O₄。（LiO₄ 四面体 : MnO₆ 八面体 = 1:2，即 Li : Mn = 1:2；由电荷守恒 Li⁺Mn³⁺Mn⁴⁺O₄ 或 LiMn(III,IV)₂O₄。）

**3-6** 相邻 Li⁺ 之间有多个未填 Li⁺ 的八面体及四面体空隙，在电场作用下形成"离子通道"。充电时，锂锰氧化物中部分 Li⁺ 沿着"离子通道"移出晶体，晶体中锂离子的个数减少，Mn 的氧化态升高；放电时 Li⁺ 沿通道从电解质流回晶体，锂离子个数增加，Mn 的氧化态降低。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| 层状氧化物 | LiCoO₂ 晶胞 3Li+3Co+6O |
| 电极反应 | Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ → LiCoO₂ |
| 尖晶石结构 | LiMn₂O₄（LiO₄:MnO₆ = 1:2）|
| 嵌入化学 | 充放电 Li⁺ 脱嵌、Mn 氧化态随 x 变 |
