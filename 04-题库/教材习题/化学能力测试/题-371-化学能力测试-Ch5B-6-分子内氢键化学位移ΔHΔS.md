# 分子内氢键化学位移 ΔH/ΔS

> **来源**：化学竞赛能力测试·第5章·B卷第6题（10 分）

测定氢键强度。

![[18ec2c19874a22efaa1b08b27ab4980fe2ac52b32f1c42a0ab3545cf748a4c2b.jpg]]

不同温度下测定了胺质子的化学位移 δ_obs：

| T/K | δ_obs/ppm | T/K | δ_obs/ppm |
|---|---|---|---|
| 220 | 6.67 | 280 | 6.27 |
| 240 | 6.50 | 300 | 6.19 |
| 260 | 6.37 | | |

δ_obs 是 N—H 完全氢键化（δ_h）和自由态（δ_f）的加权平均。

**6-1** 写一个表示 δ_obs 的表达式。

**6-2** 写一个用 δ_obs、δ_h、δ_f 表示反应 A⇌B 平衡常数 K 的表达式。

**6-3** 已知 δ_h=8.4 ppm，δ_f=5.7 ppm，计算各温度下的 K。

**6-4** 通过画适当函数图像，计算 300 K 下 A→B 的标准焓变和熵变。

**6-5** 讨论第 2 问的重要意义。

<details>
<summary>📖 查看答案与解析</summary>

**6-1**

$$\delta_\mathrm{obs} = x_\mathrm{h}\delta_\mathrm{h} + x_\mathrm{f}\delta_\mathrm{f},\quad x_\mathrm{h} + x_\mathrm{f} = 1$$

**6-2**

$$\delta_\mathrm{obs} = x_\mathrm{h}\delta_\mathrm{h} + (1-x_\mathrm{h})\delta_\mathrm{f} \Rightarrow x_\mathrm{h}(\delta_\mathrm{h}-\delta_\mathrm{f}) = \delta_\mathrm{obs}-\delta_\mathrm{f}$$

$$K = \frac{x_\mathrm{h}}{x_\mathrm{f}} = \frac{\delta_\mathrm{obs}-\delta_\mathrm{f}}{\delta_\mathrm{h}-\delta_\mathrm{obs}}$$

**6-3**

| T/K | δ_obs | K=(δ_obs−5.7)/(8.4−δ_obs) |
|---|---|---|
| 220 | 6.67 | (6.67−5.7)/(8.4−6.67)=0.97/1.73=0.5607 |
| 240 | 6.50 | 0.80/1.90=0.4211 |
| 260 | 6.37 | 0.67/2.03=0.3300 |
| 280 | 6.27 | 0.57/2.13=0.2676 |
| 300 | 6.19 | 0.49/2.21=0.2217 |

**6-4** ln K 对 1/T 直线斜率 = −ΔrH^θ/R = 764.1 K：

$$\Delta_\mathrm{r}H^\theta = -764.1\times 8.3145 = -6.35\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta_\mathrm{r}S^\theta(300\ \mathrm K) = (\Delta_\mathrm{r}H^\theta - \Delta_\mathrm{r}G^\theta(300))/300 = (-6.4 - (-10.2))/300 = -34\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

（ΔrG^θ(300)=−RT ln K = −8.314×300×ln(0.2217)≈+10.2 kJ/mol）

**6-5** 第 2 问重要性：通过 NMR 化学位移可定量监测分子内氢键平衡，无需分离纯化即可获 K 与 ΔH^θ/ΔS^θ；为生物大分子构象分析提供原位手段。

</details>
