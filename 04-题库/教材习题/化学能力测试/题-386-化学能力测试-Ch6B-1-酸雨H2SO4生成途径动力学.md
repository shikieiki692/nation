# 酸雨 H₂SO₄ 生成途径动力学

> **来源**：化学竞赛能力测试·第6章·B卷第1题（10 分）

Molina 教授（1995 诺贝尔化学奖）研究大气酸雨 H₂SO₄ 生成过程，提出两个可能反应：

- 途径 A：H₂O(g) + SO₃(g) → H₂SO₄(g)
- 途径 B：2H₂O(g) + SO₃(g) → H₂SO₄(g) + H₂O(g)

**1-1** 简单碰撞理论下 A、B 的反应级数应为多少？

途径 B 分两步：SO₃ + 2H₂O ⇌ SO₃·2H₂O（k₁/k₋₁，快）、SO₃·2H₂O → H₂SO₄ + H₂O（k₂，慢）。

**1-2** 稳态法推导途径 B 的速率方程及反应级数。

**1-3** 量子化学活化能：途径 A 的 $E_A$=+80 kJ/mol；途径 B 的 $E_B$=−20 kJ/mol。给出 A、B 的 Arrhenius 方程并预测 $k \sim T$ 函数。

**1-4** H₂SO₄ 在高空（175 K）形成比地表（300 K）快。A、B 哪种途径在高空是主要机理？

<details>
<summary>📖 查看答案与解析</summary>

**1-1** 途径 A 若为基元反应：d[H₂SO₄]/dt = k[H₂O][SO₃]，**二级**。

途径 B 由 2 个 H₂O + 1 个 SO₃ 一次碰撞：d[H₂SO₄]/dt = k[H₂O]²[SO₃]，**三级**。

**1-2** 稳态法（SO₃·2H₂O）：

$$\frac{\mathrm d[\mathrm{SO_3\cdot 2H_2O}]}{\mathrm dt} = k_1[\mathrm{SO_3}][\mathrm{H_2O}]^2 - k_{-1}[\mathrm{SO_3\cdot 2H_2O}] - k_2[\mathrm{SO_3\cdot 2H_2O}] = 0$$

$$[\mathrm{SO_3\cdot 2H_2O}] = \frac{k_1[\mathrm{SO_3}][\mathrm{H_2O}]^2}{k_2 + k_{-1}}$$

$$\frac{\mathrm d[\mathrm{H_2SO_4}]}{\mathrm dt} = k_2[\mathrm{SO_3\cdot 2H_2O}] = \frac{k_1k_2}{k_2+k_{-1}}[\mathrm{SO_3}][\mathrm{H_2O}]^2$$

k₂≪k₋₁ → d[H₂SO₄]/dt = k[SO₃][H₂O]²（k = k₁k₂/k₋₁），**三级反应**，与碰撞预测一致。

**1-3** Arrhenius：k_A = A_A·exp(−80×10³/RT)（k 随 T 升高增大）；k_B = A_B·exp(+20×10³/RT)（**k 随 T 升高减小**——负活化能）。

**1-4** 高空 175 K 低温下，exp(+20/RT) 项较大（指数中负号少）→ **途径 B 占优**。从碰撞几率看途径 A 合理，但其较大正活化能使之在高空不可行。

</details>

<!-- 校勘注: ①途径 B 的"负活化能"（E_B=−20 kJ/mol）源于氢键预配合物 SO₃·2H₂O 稳定中间体使表观活化能为负——预平衡 K=k₁/k₋₁ 放热，E_app=E₂+ΔH_pre 可为负；②高空稀薄水蒸气+低温，三分子途径 B 因碰撞频率低而受限，但低活化能占主导——源答案文字「A、B 指前因子可比」按活化能指数判 B。 -->
