# 碳化钙 CaC₂ 四方晶胞

> **来源**：化学竞赛能力测试·第3章·A卷第9题（10 分）

一个 Ca 和 C 的二元化合物具有四方晶胞：a = b = 3.87 Å、c = 6.37 Å（α = β = γ = 90°），晶胞如下图所示，图中钙原子用较大的黑圆圈表示，碳原子用空心圆圈表示。在位于原点的钙原子上面的碳原子的坐标为 x = 0、y = 0、z = 0.406（1 Å = 10⁻⁸ cm）。

![[51ca2080914cc737e5d57e14a6839c0b3a0d93bc9ce4b0f85e8f4f033573e69d.jpg]]

**9-1** 导出这个化合物的化学式为 ______。

**9-2** 一个晶胞中所含的化学式单位的数目为 ______。

**9-3** C₂ 基团中 C—C 键长为 ______ Å。

**9-4** 最短的 Ca—C 距离为 ______ Å。

**9-5** 最短的两个非键 C……C 间距离为 ______ Å、______ Å。

**9-6** 这一结构与 ______ 型离子化合物的结构密切相关。

<details>
<summary>📖 查看答案与解析</summary>

**9-1** 根据顶点、面心、棱心的贡献率，可得到碳化钙的化学式为 CaC₂（每个 Ca 周围有两个 C₂ 哑铃，Ca²⁺ 与 [C₂]²⁻）。

**9-2** 4（晶胞含 4 个 CaC₂ 化学式单位）。

**9-3** C₂ 基团中 C—C 键长（C 位于 z = 0.406 与其上方等价位置 z' 之间，沿 c 轴）：

$$d_{\mathrm{C-C}} = c - 2\times 0.406c = 0.188c = 0.188\times 6.37 = 1.20\ \mathrm{Å}$$

**9-4** 最短的 Ca—C 距离：

$$d = \sqrt{\left(\frac{a}{2}\right)^2 + \left(\frac{d_{\mathrm{C-C}}}{2}\right)^2} = \frac{1}{2}\sqrt{(3.87)^2 + (1.20)^2} = 2.03\ \mathrm{Å}$$

**9-5** 最短的 C…C 非键距离：

$$d_1 = \sqrt{\left(\frac{a}{2}\right)^2 + \left(\frac{b}{2}\right)^2} = \frac{\sqrt{2}}{2}a = 2.74\ \mathrm{Å}$$

$$d_2 = \sqrt{\left(\frac{c}{2} - d_{\mathrm{C-C}}\right)^2 + \left(\frac{a}{2}\right)^2} = \sqrt{\left(\frac{6.37}{2} - 1.20\right)^2 + \left(\frac{3.87}{2}\right)^2} = 2.77\ \mathrm{Å}$$

**9-6** 与 NaCl 型离子化合物的结构密切相关（CaC₂ 是 Ca²⁺ 与 C₂²⁻ 哑铃组成的 NaCl 畸变结构）。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| 四方晶胞 | a=b≠c、C₂ 沿 c 轴取向 |
| 化学式 | Ca²⁺/C₂²⁻ 摩尔比 1:1 |
| 键长 | C—C = c(1−2×0.406)；距离几何 |
| NaCl 畸变 | CaC₂ 类 NaCl 但 C₂ 拉长 |
