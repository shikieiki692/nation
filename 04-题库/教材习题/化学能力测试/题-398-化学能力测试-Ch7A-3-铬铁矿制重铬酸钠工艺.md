# 铬铁矿制重铬酸钠工艺

> **来源**：化学竞赛能力测试·第7章·A卷第3题（10 分）

由铬铁矿(FeO·Cr₂O₃)生产重铬酸钠工艺流程图：

![[a2b095bf09961030aac52d65cf52ccae2e42979acc2faf139de285f932c594c1.jpg]]

**3-1** (2) 步通 CO₂ 用水浸取比单纯水浸取的优点（用方程式说明）？

**3-2** (5)(8) 步过滤滤渣中相同成分？能否再利用？

**3-3** (4)(7) 步为预碳化及碳化。碳化率 X={1−[CrO₄²⁻]}/c₀（c₀ 浸取液中 Cr 总浓度）。证明 X = 1/[1+K₂b/(K₁kp)]（p 为 CO₂ 分压，[HCO₃⁻]=kp=b，K₁ 为 H₂CO₃ 一级电离，K₂ 为 HCrO₄⁻ 电离，H₂CrO₄ 强酸）。

**3-4** (2) 步与 (7) 步通 CO₂ 分压区别？

**3-5** (4)(7) 步溶液温度控制？

<details>
<summary>📖 查看答案与解析</summary>

**3-1** 单纯水浸取：4CaO·Al₂O₃·Fe₂O₃ + Na₂CrO₄ + 4H₂O → 3CaO·Al₂O₃·CaCrO₄ + 2Fe(OH)₃ + 2NaOH（CaCrO₄ 难溶 → 铬随渣流失）。

通 CO₂：CO₂ + 2OH⁻ → CO₃²⁻ + H₂O；CaCrO₄ + CO₃²⁻ → CrO₄²⁻ + CaCO₃↓

——难溶 CaCrO₄ 转化成更难溶 CaCO₃ 使 CrO₄²⁻ 不流失。

**3-2** 滤渣成分 NaHCO₃。可再利用：2NaHCO₃ → Na₂CO₃ + CO₂ + H₂O（CO₂ 供 (2)(7) 通入，Na₂CO₃ 作焙烧原料）。

**3-3** 由各平衡：

$$\frac{[\mathrm{HCO_3^-}]}{[\mathrm{H_2CO_3}]K_1} = \frac{1}{[\mathrm H^+]} = \frac{[\mathrm{CrO_4^{2-}}]}{K_2(c_0 - [\mathrm{CrO_4^{2-}}])} = \frac{1}{K_2}\cdot\frac{[\mathrm{CrO_4^{2-}}]/c_0}{1 - [\mathrm{CrO_4^{2-}}]/c_0}$$

X = 1 − [CrO₄²⁻]/c₀ 代入：

$$\frac{b}{K_1 kp} = \frac{1}{K_2}\cdot\frac{1-X}{X} \Rightarrow X = \frac{K_1kp}{K_1kp + K_2b} = \frac{1}{1 + K_2b/(K_1kp)}$$

**3-4** (2) 步需**低压 CO₂**（预碳化去除杂质）；(7) 步需**高压 CO₂**（充分碳化得 CrO₄²⁻）。

**3-5** 室温附近较好：温度低 H₂CO₃ 电离小、b 小 → X 大；低温也有利 CO₂ 吸收。

</details>
