# CdFe(CO)₄ 羰基簇

> **来源**：化学竞赛能力测试·第4章·A卷第7题（10 分）

已知 Fe(CO)₅ 可与乙酸钠发生如下反应：

Fe(CO)₅ + Cd(Ac)₂ + NH₃ + H₂O → CdFe(CO)₄(NH₃)₂ + CO₂ + HAc。反应产物 CdFe(CO)₄(NH₃)₂ 又可在真空中 60°C 条件下生成 A。元素分析表明：A 中含四种元素且含 Cd 40%、Fe 20%。

物质 A 单体不稳定，易形成多种聚合物。例如：在 2,2-联吡啶中，A 以 A₃ 形式存在，A₃ 又与溶剂形成配合物 B，X 射线衍射表明 B 中存在平面六元环，且存在金属—金属键及一种金属—碳键，同时还知道，B 中 Fe 以高度变形的八面体几何构型存在，而 Cd 则以四面体构型存在。

根据以上信息回答下列问题（原子量 Cd 112、Fe 56、C 12、O 16）：

**7-1** 配平反应方程式并写出 A 的分子式。

**7-2** 写出配合物 B 的结构式。

**7-3** A 还可聚合为 A₄，A₄ 中有平面八元环，且只有一种金属—碳键，试写出 A₄ 的结构。

<details>
<summary>📖 查看答案与解析</summary>

**7-1** 配平反应：Cd 与 Fe 均为 +2/0? 源答案：Fe(CO)₅ + Cd(Ac)₂ + 2NH₃ + H₂O → CdFe(CO)₄(NH₃)₂ + CO₂ + 2HAc? 验算配平：

$$\mathrm{Fe(CO)_5} + \mathrm{Cd(Ac)_2} + 2\mathrm{NH_3} + \mathrm{H_2O} \longrightarrow \mathrm{CdFe(CO)_4(NH_3)_2} + \mathrm{CO_2} + 2\mathrm{HAc}$$

（等号两边 C：5+4=9? 左 Fe(CO)₅ 5C + Ac 4C = 9C；右 4C+1C(CO₂)+Ac 4C = 9C ✓）

真空加热 60°C（NH₃ 离去比 CO 大，因 Fe/Cd 与 CO 结合远比与 NH₃ 牢固）：

$$\mathrm{CdFe(CO)_4(NH_3)_2} \xrightarrow{60^{\circ}\mathrm{C}/\text{真空}} \mathrm{CdFe(CO)_4} + 2\mathrm{NH_3}$$

A 的分子式为 CdFe(CO)₄。

验算：M = 112+56+4×28 = 280；Cd% = 112/280 = 40% ✓、Fe% = 56/280 = 20% ✓。

**7-2** 配合物 B：三聚体 A₃（Cd₃Fe₃(CO)₁₂）与 2,2'-联吡啶配位。B 中存在平面六元环（Fe₃Cd₃ 或交替环）、金属—金属键（Fe—Cd）及金属—碳键（Fe—CO）。Fe 八面体（配位 6：CO×4 + 2 个 Cd? 变形）、Cd 四面体（配位 4：Fe 键 + 联吡啶 N? 或 CO）。

**7-3** A₄（Cd₄Fe₄(CO)₁₆ 类）有平面八元环且只有一种金属—碳键（Fe—C 键，来自 CO 的 Fe—CO σ 配键），Cd 无 Cd—C 键只有 Fe—Cd 键：

A₄ 为四元环交替骨架（平面八元环 Cd—Fe—Cd—Fe…各 4 个），CO 全部端接 Fe 原子，Cd 由 Fe—Cd 金属键连接（可能 Cd 桥接 CO? 但题意只有 Fe—C 键）——结构：八元环 Cd₂Fe₂? 按题意 A₄ 平面八元环 = 4 Cd + 4 Fe 交替环。
