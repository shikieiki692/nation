# 保险粉 Na₂S₂O₄

> **来源**：化学竞赛能力测试·第1章 化学反应方程式与核化学反应方程式·A卷第5题（10 分）

## 题目

保险粉是 $\mathrm{Na_2S_2O_4}$ 的工业俗名。它的年产量高达 30 万吨，是产量最大的人造无机盐之一，大量用于漂白纸张、纸浆和陶土以及印染。生产保险粉的方法之一是：先把甲酸（HCOOH）和溶于甲醇和水的混合溶剂的 NaOH 混合，再通入 $\mathrm{SO_2}$ 气体，就得到保险粉。

![[0c172a14a33e071838e386eb3668c1be6b4a22eba8266a1c1d94a194d0433720.jpg]]

5-1 写出甲酸法生产保险粉的配平的化学方程式。你认为此法中甲醇的作用是什么？为什么？

5-2 保险粉的重要工业应用之一是瓮染。瓮染的染料必须先在烧碱溶液里与保险粉反应，所得的产物才会和棉纤维结合，然后织物经漂洗后再把反应产物回复到原来的染料。下面是一种瓮染法的蓝色染料的结构式：

![[4bf3495392dadd1239855f3167df35240715688f0c740ddcd896f4115b81e265.jpg]]

(1) 写出该蓝色染料和保险粉反应得到的产物的可能结构式。说明理由。

(2) 为什么必须令染料跟保险粉反应才能使染料和织物结合？扼要地描述结合的机理。

(3) 为什么最后还要把反应产物回复到染料原来的形态？怎样回复？

5-3 保险粉的用途之一是除去废水里的 $\mathrm{CrO_4^{2-}}$。据说这是迄今除去中性或碱性废水里的 $\mathrm{CrO_4^{2-}}$ 的最有效的方法。往废水里通 $\mathrm{SO_2}$ 不能达此目的。试写出配平的离子方程式。

5-4 研究人员已经使用和正在研究用其他工业原料和 $\mathrm{SO_2}$ 反应来制取保险粉，例如，使用 $\mathrm{NaBH_4}$ 已经达到工业生产的规模（pH = 5~6）。你能写出该反应的离子方程式吗？

5-5 根据你所学的化学知识还能想到其他生产保险粉的更廉价的原料吗？

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 甲酸法：

$\mathrm{HCOONa + 2SO_2 + NaOH \longrightarrow Na_2S_2O_4 + CO_2\uparrow + H_2O}$

甲醇的作用：(1) **溶剂**——反应物和产物均可溶于水和甲醇的混合溶剂；(2) **降低目标产物保险粉在水中的溶解度**——水中加入甲醇会降低溶剂的极性，而保险粉是离子性很强的盐类（水合能力强），可从溶剂里析出，便于从反应体系中分离。

**5-2** (1) 产物的可能结构式（染料中 C=O 被还原为 C—O⁻ 钠盐）：

![[e17cff1db33d4ab02933ff7cd132fb66787d97449c47802983d3332e032dede7.jpg]]

理由：还原产物不应改变染料的基本碳架，否则难以回复原结构；还原产物应是水溶性的——因此还原反应是把原结构的羰基还原成羟基（烯醇式/酚氧负离子），并因反应在碱性溶液里进行而呈阴离子（钠盐），故有水溶性。

(2) 结合机理：染料是电中性的有机分子，难溶于水；而其还原产物是钠盐，易溶于水。还原产物分子容易通过水分子的运动均匀地分布到织物纤维表面，排开织物表面的水分子，并通过氢键和范德华力与棉纤维素分子结合（纤维里本来存在大量氢键），同时高极性的亲水基团 C—O⁻ 朝向水相，而不溶的染料原形分子不能均匀地分散到织物表面。

(3) 必须回复原因：还原产物可溶于水，若不回复到难溶的染料原形，织物经水洗涤就容易褪色；更重要的是还原产物从结构看已无原染料的共轭结构（醌式/醌亚胺共轭被还原断链），是无色的或接近无色，而染料原形的结构里有很大的共轭结构，呈蓝色。回复办法：织物经漂洗后在（弱）酸性溶液里使用氧化剂（如空气/过氧化物）即可回复到原染料。

**5-3** $2\mathrm{CrO_4^{2-} + 3S_2O_4^{2-} + 4H_2O \longrightarrow 2Cr(OH)_3\downarrow + 4SO_3^{2-} + 2HSO_3^-}$

（S₂O₄²⁻ 中 S(+3) 歧化/还原 Cr(+6)；中性或碱性介质 Cr 以 Cr(OH)₃ 沉淀析出除尽。SO₂ 通入会使溶液酸化，不能在中性/碱性介质有效沉淀 Cr(OH)₃ 且引入 SO₄²⁻ 等杂质。）

**5-4** $\mathrm{BH_4^- + 8HSO_3^- + 5H^+ \longrightarrow 4HS_2O_4^- + H_3BO_3 + 5H_2O}$

或 $\mathrm{BH_4^- + 3HSO_3^- + 5H_2SO_3 \longrightarrow 4HS_2O_4^- + H_3BO_3 + 5H_2O}$

或 $\mathrm{BH_4^- + 8HSO_3^- + H^+ \longrightarrow 4S_2O_4^{2-} + H_3BO_3 + 5H_2O}$

或 $\mathrm{BH_4^- + 7HSO_3^- + H_2SO_3 \longrightarrow 4S_2O_4^{2-} + H_3BO_3 + 5H_2O}$

（BH₄⁻ 负氢还原 HSO₃⁻（S+4→+3）为连二亚硫酸根；pH=5~6 时以 HSO₃⁻ 与 H⁺ 形式供氢）

**5-5** 更廉价原料：用 Na（钠汞齐）、CO、H₂ 等还原 SO₂。

$\mathrm{2Na + 2SO_2 \longrightarrow Na_2S_2O_4}$（钠汞齐还原）

$\mathrm{2CO + 2SO_2 + 2NaOH \longrightarrow Na_2S_2O_4 + 2CO_2}$（CO 还原，类甲酸法）

$\mathrm{H_2 + 2SO_2 + 2NaOH \longrightarrow Na_2S_2O_4 + 2H_2O}$（H₂ 还原）
