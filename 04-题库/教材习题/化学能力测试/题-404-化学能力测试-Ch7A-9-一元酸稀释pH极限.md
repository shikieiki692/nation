# 一元酸稀释 pH 极限

> **来源**：化学竞赛能力测试·第7章·A卷第9题（10 分）

0.226% 的一元酸水溶液 pH=2.536，两倍稀释后 pH 升至 2.692。

**9-1** 计算该酸的离解常数。

**9-2** 计算初始溶液摩尔浓度。

**9-3** 已知初始溶液密度 1 g/cm³，确定酸的摩尔质量和化学式。

**9-4** 推导一元酸水溶液 n 次体积加倍稀释后 pH 变化上下限（忽略水的电离）。

<details>
<summary>📖 查看答案与解析</summary>

**9-1** 由一元弱酸 c = a²/K + a（a=[H⁺]=10⁻²·⁵³⁶）；稀释 2 倍：c/2 = b²/K + b（b=10⁻²·⁶⁹²）：

$$K = \frac{a^2 - b^2n}{bn - a},\quad n=2$$

$$K = \frac{(10^{-2.536})^2 - 2(10^{-2.692})^2}{2\times 10^{-2.692} - 10^{-2.536}} = 1.83\times 10^{-4}$$

**9-2** c = a²/K + a = (8.5×10⁻⁴)²/1.83×10⁻⁴ + 3.9×10⁻³ ≈ **0.0492 mol/L**

**9-3** 1 L 溶液质量 1 kg，酸 2.26 g：

$$M = \frac{2.26}{0.0492} = 46\ \mathrm{g/mol}$$

**唯一 M=46 的一元酸是甲酸 HCOOH**。

**9-4** K=(a²−b²n)/(bn−a)>0 → 分母 bn−a>0（b>a/n）、分子 a²−b²n<0（b<a/√n）：

$$n^{1/2} < a/b < n \Rightarrow \tfrac{1}{2}\lg n < \Delta\mathrm{pH} = \lg(a/b) < \lg n$$

**稀释 n 次 pH 升高下限 ½lg n、上限 lg n**。

</details>
