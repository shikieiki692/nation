# BP 闪锌矿结构与反应速率

> **来源**：化学竞赛能力测试·第3章·A卷第3题（10 分）

BP（硼磷化合物）是一种高价值的耐磨涂布剂，其生产方式可经由三溴化硼与三溴化磷在氢气的条件下于高温（>750°C）反应而成。这种陶瓷材料可应用于当作金属表面的保护膜。BP 是以立方最密堆积，且其原子周围是以四角锥方式堆积。

**3-1** 写出生成 BP 的化学反应方程式。

**3-2** 画出三溴化硼与三溴化磷的路易斯结构式。

**3-3** 画出 BP 的晶体结构。

**3-4** 写出与 BP 结构相同的晶胞的所有组成。

**3-5** 当晶胞的边长为 4.78 Å 时，计算 BP 的密度（以 $\mathrm{kg\cdot m^{-3}}$ 为单位）。

**3-6** 计算 BP 中硼原子与磷原子之间的距离。

可用 Born-Lande 方程式计算晶格能：$U_{\text{lattice}} = -f\frac{Z_+Z_-Ae^2}{r_+ + r_-}\left(1-\frac{1}{n}\right)$

当离子半径 $r_+$ 和 $r_-$ 是以 Å 为单位时，$fe^2$ 这项等于 1390。马德龙（Madelung）常数为 1.638。波恩（Born）指数 n 为 7。离子之电荷 $Z_+$ 和 $Z_-$ 为整数。

**3-7** 计算 BP 晶格能。

BP 的生成速率与反应物的浓度有关，如表所示：

| 温度/°C | [BBr₃] | [PBr₃] | [H₂] | r/mol·s⁻¹ |
|---|---|---|---|---|
| 800 | 2.25e-6 | 9.00e-6 | 0.070 | 4.60e-8 |
| 800 | 4.50e-6 | 9.00e-6 | 0.070 | 9.20e-8 |
| 800 | 9.00e-6 | 9.00e-6 | 0.070 | 18.4e-8 |
| 800 | 2.25e-6 | 2.25e-6 | 0.070 | 1.15e-8 |
| 800 | 2.25e-6 | 4.50e-6 | 0.070 | 2.30e-8 |
| 800 | 2.25e-6 | 9.00e-6 | 0.035 | 4.60e-8 |
| 880 | 2.25e-6 | 9.00e-6 | 0.070 | 19.6e-8 |

**3-8** 确定形成 BP 反应的级数，并且写出反应式。

**3-9** 计算在 800°C 和 880°C 速率常数。

**3-10** 计算生成 BP 的活化能。

**3-1**

$$\mathrm{BBr_3} + \mathrm{PBr_3} + 3\mathrm{H_2} \longrightarrow \mathrm{BP} + 6\mathrm{HBr}$$

**3-2** 三溴化硼为平面正三角形（B sp²），三溴化磷为三角锥形（P 有一孤对电子，sp³ 不等性杂化）：

![[89da4f97a0476565b13c429fe0e5defe5256ef47ddc72f25dae5025d0c4f1ca1.jpg]]

![[cd9798c0692f27085b9a42bf663e0193ef35d4b566c7b3a5122d008cc4a55915.jpg]]

**3-3** BP 晶胞与金刚石/闪锌矿结构相似（Zinc blende structure，B 为 fcc，P 填其 4 个四面体空隙之一半）：

![[37bfe955eaa47b284b0e52f9d46f92cebf0d6518745478fb8838fffce3bf7718.jpg]]

**3-4** B 原子为 fcc：顶点 $8\times 1/8 = 1$，面心 $6\times 1/2 = 3$，共 4 个；P 原子 4 个位于四面体空隙（填 8 个四面体空隙的一半）。晶胞组成 = 4 BP。

**3-5** 硼和磷的相对原子质量分别为 11 和 31：

$$\rho = \frac{m}{V} = \frac{nM_{\mathrm{BP}}}{N_A a^3} = \frac{4\times 42}{6.022\times 10^{23}\times (4.78\times 10^{-10})^3} = 2554\ \mathrm{kg\cdot m^{-3}}$$

**3-6** B—P 之间的距离 $d = \frac{\sqrt{3}}{4}a = \frac{\sqrt{3}}{4}\times 4.78 = 2.069\ \mathrm{Å}$。

**3-7** BP 晶格能：

$$U = -\frac{1390\times 3\times 3\times 1.638}{2.069}\times\frac{6}{7} = -8489\ \mathrm{kJ\cdot mol^{-1}}$$

（B 与 P 均为 +3/−3 假想离子模型；Born-Lande 以 r₊+r₋ = d(B—P) 代入。）

**3-8** 根据质量作用定律：$r = k[\mathrm{BBr_3}]^m[\mathrm{PBr_3}]^n$。代入数据可求出 m = n = 1。因此反应级数为 2，速率方程 $r = k[\mathrm{BBr_3}][\mathrm{PBr_3}]$（H₂ 浓度改变不影响速率 → H₂ 级数为 0）。

**3-9**

$$k_{800} = \frac{4.60\times 10^{-8}}{2.25\times 10^{-6}\times 9\times 10^{-6}} = 2272\ \mathrm{L^2\cdot mol^{-1}\cdot s^{-1}}$$

$$k_{880} = \frac{19.6\times 10^{-8}}{2.25\times 10^{-6}\times 9\times 10^{-6}} = 9679\ \mathrm{L^2\cdot mol^{-1}\cdot s^{-1}}$$

**3-10** 用阿伦尼乌斯方程（T₁ = 1073 K，T₂ = 1153 K）：

$$E_a = -R\ln(k_2/k_1)\times\left(\frac{1}{T_2} - \frac{1}{T_1}\right)^{-1} = -8.314\times\ln(9679/2272)\times\left(\frac{1}{1153}-\frac{1}{1073}\right)^{-1} = 186\ \mathrm{kJ\cdot mol^{-1}}$$
