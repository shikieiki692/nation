# 马来酸分布分数与滴定

> **来源**：化学竞赛能力测试·第7章·A卷第8题（10 分）

马来酸（H₂A）二元弱酸。总浓度 C：α₀=[H₂A]/C、α₁=[HA⁻]/C、α₂=[A²⁻]/C。pH=1.92 时 α₀=α₁；pH=6.22 时 α₁=α₂。

**8-1** 求 K₁ 和 K₂。

**8-2** 求 pH=1.92 与 6.22 时的 α₀、α₁、α₂。

**8-3** 求 α₁ 极大时的 pH 与极大值。

**8-4** 0.1 mol/L NaOH 滴定 0.1 mol/L 马来酸——一元酸与二元酸时分别用哪些指示剂？

<details>
<summary>📖 查看答案与解析</summary>

**8-1** α₀=α₁ 时 pH=pKa₁ → K₁=[H⁺]=10⁻¹·⁹²=**1.20×10⁻²**；α₁=α₂ → K₂=10⁻⁶·²²=**6.02×10⁻⁷**

**8-2** pH=1.92（[H⁺]=1.20×10⁻²、F=2.88×10⁻⁴）：

α₀=α₁=[H⁺]²/F=0.50；α₂=K₁K₂/F=2.51×10⁻⁵

pH=6.22（[H⁺]=6.02×10⁻⁷、F=1.445×10⁻⁸）：

α₀=K₁K₂/F=2.51×10⁻⁵；α₁=α₂=0.500

**8-3** α₁ 极大条件：α₀=α₂ → [H⁺]²=K₁K₂ → [H⁺]=√(1.20×10⁻²×6.02×10⁻⁷)=8.5×10⁻⁵ M，**pH=4.07**

$$\alpha_{1,\max} = \frac{K_1[\mathrm H^+]}{[\mathrm H^+]^2 + K_1[\mathrm H^+] + K_1K_2} = 0.986$$

**8-4** 一元当点 pH=4.07（HA⁻ 两性）：**溴酚蓝/刚果红**。二元当点：A²⁻ 水解 pH=9.37：**百里酚蓝/酚酞**。

</details>
