# 绿矾综合利用工艺

> **来源**：化学竞赛能力测试·第8章·A卷第3题（10 分）

绿矾（FeSO₄·7H₂O）为硫酸法钛白粉副产物（每吨钛白粉副产 4.5~5.0 吨），综合利用流程：

![[14eee0f79701cf9881249fecdc83ef0ee6eb16348acf5a6cb1f84d1032f5fd63.jpg]]

B 是氯化物、C 不含氯优质钾肥、D 是氮肥、E 是红色颜料；A-E 均是盐、E/F 常见化合物。

**3-1** 写出 A~F 化学式。

**3-2** 写反应 (1)(2)(3) 方程式。

**3-3** 指出反应 (3) 加 DFA（有机溶剂）的理由。

**3-4** 判断 DFA 是否溶于水。

<details>
<summary>📖 查看答案与解析</summary>

**3-1** A=**NH₄HCO₃**（或 (NH₄)₂CO₃）、B=**KCl**、C=**K₂SO₄**、D=**NH₄Cl**、E=**Fe₂O₃**、F=**CO₂**

推断链：FeSO₄ 与 A（碳酸铵盐）复分解得碱式碳酸亚铁↓+CO₂↑（F），碱式盐在空气/水氧化为 Fe(OH)₃ 再煅烧得 E=Fe₂O₃；滤液 (NH₄)₂SO₄ 与 B=KCl 在 DFA 中交换得 K₂SO₄↓（C）+NH₄Cl（D）。

**3-2**

(1) (m+n)FeSO₄ + 2(m+n)NH₄HCO₃ = Fe_m+n(OH)₂ₙ(CO₃)_m↓ + (m+n)(NH₄)₂SO₄ + (2n+m)CO₂↑ + mH₂O

(2) 2Fe_m+n(OH)₂ₙ(CO₃)_m + (m+n)/2 O₂ + 3(m+n)H₂O = 2(m+n)Fe(OH)₃↓ + 2mCO₂↑

(3) (NH₄)₂SO₄ + 2KCl →(DFA) K₂SO₄↓ + 2NH₄Cl

**3-3** DFA 降低 K₂SO₄ 溶解度使之结晶析出，促使复分解平衡右移（反应完全）。

**3-4** **溶于水**（滤液蒸发水分后得 D=NH₄Cl，说明 DFA 与水互溶均相；否则沉降分层即可分离）。

</details>

<!-- 校勘注: ①反应(1) 通式 Fe_m+n(OH)₂ₙ(CO₃)_m 中 m:n 不定（碱式碳酸亚铁组成可变为 Fe₂(OH)₂CO₃ 等），源答案多式等价；②B=KCl（K⁺ 入 C=K₂SO₄、Cl⁻ 入 D=NH₄Cl）推理关键：A 提供 NH₄⁺、B 提供 K⁺/Cl⁻。 -->
