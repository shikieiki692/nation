# 草酸多核 CuZn 配合物

> **来源**：化学竞赛能力测试·第4章·B卷第2题（10 分）

现已发现金属桥联多核结构广泛存在于生物体的金属蛋白及金属酶中，因此对多核金属配合物的研究具有十分重要的意义。

1991 年有人用草酸与乙醇反应得到化合物 A，A 与丙二胺（$\mathrm{H_2N-CH_2-CH_2-CH_2-NH_2}$）反应得化合物 B，B 与新配制的 $\mathrm{Cu(OH)_2}$ 在 pH=10 的条件下反应生成化合物 C。根据电导测定，化合物 C 为非电解质，再用 C 与 $\mathrm{Zn(ClO_4)_2}$ 及菲咯啉（

![[20aaec1aeb391467d0de8d705145c59c7389e9b40a2a1a677d60a110d4d448d7.jpg]]

）反应得 D。D 为 1:2 型电解质，其分子式为：$\mathrm{C_{32}H_{36}Cl_2N_8O_{12}CuZn}$。

**2-1** 试写出并配平各步反应式。

**2-2** 写出化合物 D 中配离子的结构简式。

<details>
<summary>📖 查看答案与解析</summary>

**2-1** 草酸与乙醇发生酯化反应：

$$\mathrm{(COOH)_2 + 2C_2H_5OH \xrightarrow[浓H_2SO_4]{\triangle} CH_3CH_2OOC-COOCH_2CH_3 + 2H_2O}$$

因此 A 为草酸二乙酯 $\mathrm{CH_3CH_2OOC-COOCH_2CH_3}$。

酯进行氨解（丙二胺亲核取代乙氧基），得 B：

![[b933388df92d9b485949dc79c5fba60139a855056504bdfcaecc6beee7867862.jpg]]

$$\mathrm{(COOC_2H_5)_2 + 2H_2N-(CH_2)_3-NH_2 \longrightarrow O=C-NH-(CH_2)_3-NH_2 \ (双端) + 2C_2H_5OH}$$

即 B 为草酰二（丙二胺酰胺）：两侧均为 O=C—NH—CH₂CH₂CH₂—NH₂。

由于 B 与新配制的 $\mathrm{Cu(OH)_2}$ 在 pH=10 条件下反应生成化合物 C，电导测定 C 为非电解质，说明 C 为内配化合物：—NH₂ 端是给质子基团，解离出 H⁺ 与 $\mathrm{Cu(OH)_2}$ 中的 OH⁻ 中和；Cu²⁺ 一般为四配位，C 中每个草酰胺单元的 2 个去质子酰胺 N 与 2 个端 NH₂ 中一个配位 Cu²⁺，另一 NH₂ 悬垂。生成 C 的反应：

![[792893d71d1333612a62d19aa4269e2419608f64de3a84a9900436348209d37b.jpg]]

![[830dbec8c659e5352dabba55291b3492cfb4715b3c1b4075f9950f8aee814574.jpg]]

C 再与 $\mathrm{Zn(ClO_4)_2}$ 及两分子菲咯啉反应得 D（1:2 电解质，含 2 个 ClO₄⁻）：

![[08640f4187edd86a38ff73267f636d01263ba25c0c09b98484c66b449e0698f0.jpg]]

**2-2** Cu 为四配位、Zn 为六配位，故 D 中配离子为 [Cu(草酰胺)₂Zn(phen)₂]²⁺ 型双核结构——两个草酰胺桥把 Cu(II) 与 Zn(II) 相连，Zn 上再各配一个菲咯啉：

![[8399e22b6a8aa00fc809fd6ea63dc0f929215b9f881458f6991fa69f0dab201c.jpg]]

（图中以菲咯啉简写为 N^N 双齿配体。）

</details>
