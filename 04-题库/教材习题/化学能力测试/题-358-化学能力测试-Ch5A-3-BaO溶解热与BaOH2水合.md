# BaO 溶解热与 Ba(OH)₂·8H₂O 水合

> **来源**：化学竞赛能力测试·第5章·A卷第3题（10 分）

已知：

| 反应 | ΔrH^θₘ / kJ·mol⁻¹ |
|---|---|
| BaO(s) + H₂O(l) → Ba(OH)₂(s) ① | −103 |
| Ba(OH)₂(s) + aq → Ba²⁺(aq) + 2OH⁻(aq) ② | −52 |
| Ba(OH)₂·8H₂O(s) + aq → Ba²⁺(aq) + 2OH⁻(aq) ③ | +64 |

请回答下列问题。若能，给出答案；若不能，简述原因。

**3-1** 能求得 BaO(s) 的溶解热吗？

**3-2** 能求得 Ba(OH)₂(s) 转变成 Ba(OH)₂·8H₂O 能量变化吗？

**3-3** 能求得 "O²⁻"(s) + H₂O(l) → 2OH⁻(s) 的能量变化吗？

**3-4** 能求得 "O²⁻"(s) + aq → 2OH⁻(aq) 的能量变化吗？

<details>
<summary>📖 查看答案与解析</summary>

**3-1** 能。① + ② 得：

$$\mathrm{BaO(s) + aq \longrightarrow Ba^{2+}(aq) + 2OH^-(aq)}$$

$$\Delta_\mathrm{r}H^\theta_\mathrm{m} = -103 + (-52) = -155\ \mathrm{kJ\cdot mol^{-1}}$$

**3-2** 能。② − ③ 得：

$$\mathrm{Ba(OH)_2(s) + 8H_2O(l) \longrightarrow Ba(OH)_2\cdot 8H_2O(s)}$$

$$\Delta_\mathrm{r}H^\theta_\mathrm{m} = -52 - 64 = -116\ \mathrm{kJ\cdot mol^{-1}}$$

**3-3** 不能。因反应是拆散 BaO 晶格吸能、Ba²⁺ 水合释能、O²⁻ 与水反应成 OH⁻ 释能以及水合释能的代数和（其中 BaO 晶格能与 O²⁻ 水合能不能由题给 ΔfH^θ 单独得到）。

**3-4** 不能。同第 3-3 问，缺 BaO 晶格能。

</details>
