# 二茂铁双齿膦 Pd 配合物

> **来源**：化学竞赛能力测试·第4章·B卷第6题（10 分）

配合物 $\mathrm{PdL(C_7H_7)NAr_2}$ 在 L 存在下受热分解，能得到有机化合物 A 和一种四面体配合物 B。已知：L 为一种常见的金属有机化合物（记为 C）的衍生物，是一种膦的双齿配体，其中金属 M 和磷元素质量分数分别为 10.07% 和 11.17%。Ar 表示芳香族化合物。

![[fc937ba090d294c4ec4e2d4a130e130f59d45d18b2e9897ad6fb25ea0f53dbc3.jpg]]

**6-1** 使用林德催化剂彻底还原 L 后，可得配体 L₁ 和金属 M。L₁ 相对分子质量是 L 的 48.06%。请推测并给出 L 的最合理结构，画出 L₁ 结构。

**6-2** 请确定 A 和 B 的结构。说明：在画出配合物结构式时，可对配体 L 进行简化，但需进行相关标记。

**6-3** C 可类比于乙烷碳碳键的旋转。请画出 C 的两种极限构象，分别给出其所属点群。

**6-4** C 在 $\mathrm{AlCl_3}$ 催化下可以与乙酰氯发生傅克反应。反应过程中金属 M 原子先结合亲电试剂形成中间体 D，随后发生重排得到中间体 E，E 失去质子得到产物。请画出 D 和 E 的结构，判断其是否满足 EAN 规则。

**6-5** 有一种配合物 F 仅有两种配体，一种配体是 C 中的配体，另一种配体是一种常见无机顺磁性小分子。F 中也含有金属 M，且质量分数为 37.00%。F 分子含有一个 C₂ 轴和一个垂直于 C₂ 的对称轴。试通过计算推导出 F 的结构式；并通过计算解释为何中心金属 M 原子满足 EAN 规则，在计算式中表明电子的来源，指出中心原子的价态。

<details>
<summary>📖 查看答案与解析</summary>

**6-1** 膦是双齿配体。设 L 含 2 个 P 原子，则：

$$M(L) = \frac{2\times 30.97}{11.17\%} = 554.5$$

$$M(M) = 554.5\times 10.07\% = 55.84 \implies M = \mathrm{Fe}$$

L 是含铁的常见金属有机化合物 C 的衍生物。C 为二茂铁 $\mathrm{Fe(C_5H_5)_2}$，$M(C) = 184.0$，则余下式量：

$$554.5 - 30.97\times 2 - 184.0 = 308.36$$

L 加氢分解得 L₁，L₁ 为双键全部被破坏的产物：

$$M(L_1) = 554.5\times 48.06\% = 266.5$$

由 $n(\mathrm{H}) = (266.5\times 2 + 55.84 - 554.5)/1.008 = 34$，1 当量 L 需 17 当量 $\mathrm{H_2}$ 彻底还原。环戊二烯相差 5 个 H，余下 12 个 H 原子可猜为两个苯环（一个苯加 3H₂），则 L 中应含有 4 个苯基，相对分子质量 $77.11\times 4 = 308.44$ 与前述一致。

参考三苯基膦结构，L 结构为两个 $\mathrm{PPh_2}$ 双齿接在二茂铁的两个 Cp 环上（1,1′-二(二苯膦)二茂铁 dppf）：

![[a51583dfcaee8118453e3c67d1a0a2696ded267538a0f4641f496d749d3758be.jpg]]

L₁ 结构为林德加氢破坏 Cp 与 Ph 中全部 C=C 后的饱和产物（环戊烷基+环己基膦桥联二茂铁骨架）：

![[a60f64243074c3a584789d3e573b5ede42f5d723e9fd5e070f7ed0f821594ca8.jpg]]

**6-2** A 的结构为：

![[e1d8a96f6c675c88b639023451015e77a0a64601e13478a6fb6b07c97ea422ad.jpg]]

即 $C_6H_5CH_2NAr_2$（重排产物，Pd 离去后的有机胺）。

B 的结构为：

![[d8f34e05b8551b17e9edd0988faf816dcd0232ca884aefaea1c2b7ed860141e9.jpg]]

即 $\mathrm{Pd(L')_4}$ 四面体配位（Pd 与 4 个简化配体 L′ 配位——实际可能是 $\mathrm{Pd(dppf)}$ 或含 N 的 的 类似四面体排布）。

**6-3** C = 二茂铁的两种极限构象：

- 交错（staggered）型：$D_{5d}$ 点群
- 重叠（eclipsed）型：$D_{5h}$ 点群

**6-4** 乙酰氯在 $\mathrm{AlCl_3}$ 催化下产生亲电试剂乙酰碳正离子 $\mathrm{CH_3CO^+}$，进攻二茂铁 Cp 环产生中间体 D：

![[58f1ea3364b27fdb6bd65ba00e030abb51126d1b5497e82e0b7e7c411f28304b.jpg]]

D 满足 EAN 规则；D 再发生重排得到中间体 E：

![[31a0be83a0771386c9808c95820131a100e75ad076847b3cf0bc48dea3c85b23.jpg]]

E 不满足 EAN 规则（酰基-亚键位过渡态，形式上电子数不达 18）。

**6-5** C 中的配体是环戊二烯阴离子 $\mathrm{C_5H_5^-}$；常见无机顺磁性小分子最可能是 NO（$\mathrm{O_2}$ 作为配体不常见可排除）。

设 F 分子式为 $\mathrm{Fe}_m(\mathrm{NO})_n(\mathrm{C_5H_5})_p$：

$$\frac{55.85m}{55.85m + 30.01n + 65.08p} = 37.00\%$$

解不定方程：当 $m=2, n=2, p=2$ 时符合：

$$w(\mathrm{Fe}) = \frac{111.7}{111.7 + 60.02 + 130.16} = \frac{111.7}{301.88} = 37.00\%\ \checkmark$$

因此 F 分子式为 $\mathrm{Fe_2(NO)_2(C_5H_5)_2}$。由于 F 分子含有一个 $C_2$ 轴和一个垂直于 $C_2$ 的对称轴，对称性良好。结构式：

![[b966a5c5dc86adb487b73439e41eaa8c5cb97e8340dfb8fd062983f60d6c34a4.jpg]]

![[eea5a1a696b8ef3994807874ff74124f66507e8d67febc042466be782238070f.jpg]]

EAN 规则计算：

- Fe：8 个价电子（d⁶ 高自旋 Fe(II) d⁶ 或 Fe(0) d⁸）
- $\mathrm{C_5H_5^-}$：6 个 π 电子（阴离子给 6e⁻）
- NO：作为 $\mathrm{NO^+}$（亚硝酰阳离子，按 $\mathrm{NO^+}$ 强场电子计数）提供 2e；或作为 $\mathrm{NO^-}$ 提供 2e

只有 Fe 为 +2 价才符合 EAN 规则（Fe²⁺ d⁶ + Cp⁻ 6e + 2 NO 4e + Fe—Fe 键 1e + 其他桥连贡献……源答案定性说明）。
