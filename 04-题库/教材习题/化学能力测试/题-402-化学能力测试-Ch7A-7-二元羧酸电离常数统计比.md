# 二元羧酸电离常数统计比

> **来源**：化学竞赛能力测试·第7章·A卷第7题（10 分）

弱酸电离 HA ⇌ H⁺+A⁻：v正=β[HA]，v逆=α[H⁺][A⁻]。

二元酸 HOOC—(CH₂)ₓ—COOH（简记 A），一级解离常数 K₁、二级 K₂。x 足够大以至两羧基间分子内相互作用可忽略。

**7-1** 推导 K₁、K₂ 间简单代数关系。

**7-2** 找出溶液中 H⁺ 浓度与羧酸浓度依赖关系。

**7-3** 定性阐明 x=1 与 x=0 时 K₁/K₂ 变化及理由。

**7-4** x=1 时，A 在 P₂O₅ 存在下加热得 B 和 H₂O，B 为线型分子。(1) 写 B 结构简式。(2) B 与 NH₃、HCl、ROH 反应，写 B+NH₃→C。(3) 光照下 B 分解为 D 和 E，D 与 CH₂=CH₂ 反应生成 F 和 E（各物质量均相等），写方程式。

<details>
<summary>📖 查看答案与解析</summary>

**7-1** 一级电离 H₂A ⇌ H⁺ + HA⁻：v正 = 2β[H₂A]（两个羧基）、v逆 = α[HA⁻][H⁺]（HA⁻ 一个可质子位）：

$$K_1 = \frac{[\mathrm H^+][\mathrm{HA^-}]}{[\mathrm{H_2A}]} = \frac{2\beta}{\alpha}$$

二级 HA⁻ ⇌ H⁺ + A²⁻：v正 = β[HA⁻]、v逆 = 2α[A²⁻][H⁺]：

$$K_2 = \frac{[\mathrm H^+][\mathrm{A^{2-}}]}{[\mathrm{HA^-}]} = \frac{\beta}{2\alpha}$$

**K₁ = 4K₂**（统计因子：两相同羧基，一级概率因子 2、二级 1/2）。

**7-2** 设 c 总浓度、x=[HA⁻]、y=[A²⁻]：K₁=[H⁺]x/(c−x−y)、K₂=[H⁺]y/x=K₁/4。电荷平衡 [HA⁻]+2[A²⁻]=[H⁺]：

$$[\mathrm H^+] = -\frac{K_1}{4} + \sqrt{\left(\frac{K_1}{4}\right)^2 + K_1c}$$

**7-3** x=1 丙二酸 / x=0 草酸：羧基相距近，双阴离子电荷排斥使第二步去质子化更难 → **K₁/K₂ ≫ 4**。且 H₂A⁻ 可分子内氢键增稳。

**7-4**

(1) B = **O=C=C=C=O**（二氧化三碳 C₃O₂，线型）

(2) O=C=C=C=O + 2NH₃ → H₂N−C(O)−CH₂−C(O)−NH₂（丙二酰胺 C）

(3) C₃O₂ →(hv) C₂O + CO；C₂O + CH₂=CH₂ → CH₂=C=CH₂ + CO

</details>
