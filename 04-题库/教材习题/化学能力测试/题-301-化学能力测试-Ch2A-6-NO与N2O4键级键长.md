# NO 与 N₂O₄ 键级键长

> **来源**：化学竞赛能力测试·第2章·A卷第6题（10 分）

**6-1** 填满下表，要使 NO、NO⁺、N₂O、NH₃OH⁺ 和 NO₃⁻ 等分子与表中最后一栏所列的对应 N—O 键长相匹配：

| 分子或离子 | N—O 键级 | N—O 键长(埃) |
|---|---|---|
| | | 1.062 |
| | | 1.154 |
| | | 1.188 |
| | | 1.256 |
| | | 1.42 |

**6-2** $\mathrm{N_2O_4}$ 和 $\mathrm{N_2O_3^{2-}}$（存在于晶体 $\mathrm{Na_2N_2O_3\cdot H_2O}$ 中）都是平面型的，画出这两种物质的价键结构，并根据(1)的结果计算 $\mathrm{N-O}$ 键长。

**6-3** 定性说明 $\mathrm{N_2O_4}$、$\mathrm{N_2O_3^{2-}}$ 和 $\mathrm{N_2H_4}$ 中 $\mathrm{N-N}$ 键的键长。

<details>
<summary>📖 查看答案与解析</summary>

本题的综合性很强，涉及到等电子体、路易斯结构理论、写共振式等。

$\mathrm{NO^+}$ 与 $\mathrm{N_2}$ 是等电子体，所以 $\mathrm{NO^+}$ 的键级为 3；NO 比 $\mathrm{NO^+}$ 多一个电子，该电子排在 $\pi^*$ 反键轨道上，所以键级 $= \frac{6-1}{2} = 2.5$。$\mathrm{N_2O}$ 有两种共振结构：$N\equiv N^-O^{\oplus} \leftrightarrow N^-=N^+=O$，所以 N—O 的键级 $= \frac{1+2}{2} = 1.5$。$\mathrm{NO_3^-}$ 中 N—O 键级为 $\frac{2+1+1}{3} = 1\frac{1}{3}$；$\mathrm{NH_3OH^+}$ 的 Lewis 结构式为 $H_2N^+-OH$，N—O 键级为 1。

**6-1** 完整表格：

| 分子或离子 | N—O 键级 | N—O 键长(埃) |
|---|---|---|
| NO⁺ | 3 | 1.062 |
| NO | 2.5 | 1.154 |
| N₂O | 1.5 | 1.188 |
| NO₃⁻ | $1\frac{1}{3}$ | 1.256 |
| NH₃OH⁺ | 1 | 1.42 |

**6-2** $\mathrm{N_2O_4}$ 的结构为 $O=N-N=O$（两边各有一个 N=O 与两个 N—O），N—O 键 $= \frac{1+2}{2} = 1.5$，从上表比较，N—O 键长应为 1.188 埃。由于 $\mathrm{N_2O_3^{2-}}$ 的结构式为 $O^- - N = N^+ - O^-$，因此 N、N 都采取 $\mathrm{sp^2}$ 杂化，存在 $\pi_5^6 \leftrightarrow \pi_5^8$ 离域，所以 N—O 键级在 $1\sim 1\frac{1}{3}$ 之间，即 N—O 键长在 1.42~1.256 埃之间。

**6-3** 由于 $\mathrm{N_2O_3^{2-}}$ 的共振结构 (I) $H>N-N<H$、(II) $O\equiv N-N\leqslant O$、(III) $(O-N=N<O)^{2-}$，所以在 $\mathrm{N_2O_3^{2-}}$ 中，N—N 之间有一定的双键性质，它的 N—N 键长最短；在 (I)、(II) 中，虽然 N—N 之间都是单键，但 $\mathrm{N_2O_4}$ 中的形式电荷都为 $\oplus$：$O\leqslant N^+-N^+\leqslant O^-$，N—N 之间发生相互排斥，因此 $\mathrm{N_2H_4}$ 的键长短于 $\mathrm{N_2O_4}$ 的键长，即 N—N 键长的顺序为：$\mathrm{N_2O_3^{2-}}$ 最短，其次是 $\mathrm{N_2H_4}$，最长为 $\mathrm{N_2O_4}$。
