# 铁测定分析化学

> **来源**：化学竞赛能力测试·第7章·B卷第9题（10 分）

缺铁性贫血用二价铁治疗。分别测 Fe²⁺/Fe³⁺/总铁是制药质检关键步骤。

**9-1** 用下表标准还原电势判断哪些氧化剂能在标准条件将 Fe²⁺ 氧化（I₂ 0.54/HNO₃ 0.96/H₂O₂ 1.77/Br₂ 1.09），写离子方程式。

**9-2** 总铁重量法（Fe(OH)₃→Fe₂O₃ 称重）：(1) 估计 0.01 M FeCl₃ 溶液 pH（Fe(OH₂)₆³⁺ 一元酸 Ka=6.3×10⁻³）(2) Fe(OH)₃ 开始沉淀 pH（Ksp=6.3×10⁻³⁸）(3) 沉淀完全 pH（剩<0.2 mg/100 mL）。

**9-3** 酸性条件 KMnO₄ 滴定 Fe²⁺。As₂O₃ 标定 KMnO₄（0.2483 g/100 mL，10.00 mL 耗 12.79 mL KMnO₄）；滴定 15.00 mL 铁溶液用 11.80 mL KMnO₄（总铁 2.505 g/L）。计算 Fe²⁺ 摩尔分数。

**9-4** 加酒石酸+氨+过量 KCN 后铂电极电势 +0.132 V（饱和甘汞参比）。(1) 所有铁为 Fe(CN)₆ⁿ⁻，计算 Fe²⁺ 摩尔分数（E^θ(Fe(CN)₆³⁻/⁴⁻)=0.364、甘汞 +0.241 V）。(2) 酒石酸和氨避免什么反应？

<details>
<summary>📖 查看答案与解析</summary>

**9-1** E^θ(氧化剂)>0.77 均可（I₂ 0.54 除外）：

$$3\mathrm{Fe^{2+}} + \mathrm{NO_3^-} + 4\mathrm H^+ \longrightarrow 3\mathrm{Fe^{3+}} + \mathrm{NO} + 2\mathrm{H_2O}$$

$$2\mathrm{Fe^{2+}} + \mathrm{H_2O_2} + 2\mathrm H^+ \longrightarrow 2\mathrm{Fe^{3+}} + 2\mathrm{H_2O}$$

$$2\mathrm{Fe^{2+}} + \mathrm{Br_2} \longrightarrow 2\mathrm{Fe^{3+}} + 2\mathrm{Br^-}$$

**9-2** (1) Fe³⁺ 水解：Ka=x²/(0.01−x)=6.3×10⁻³ → x=5.4×10⁻³ → **pH=2.3**

(2) Ksp=[Fe³⁺][OH⁻]³ 迭代（考虑 Fe(OH)²⁺ 分布）：y=[OH⁻] → **开始沉淀 pH=2.27**

(3) c(Fe)=1×10⁻⁶ M（剩余<0.2 mg）四次迭代：**完全沉淀 pH=4.3**

**9-3** c(As₂O₃)=0.01255 M；5As₂O₃+4MnO₄⁻+12H⁺+9H₂O→10H₃AsO₄+4Mn²⁺：

$$c(\mathrm{KMnO_4}) = 0.01255\times 4/(5\times 10.00/12.79\times...) = 7.850\times 10^{-3}\ \mathrm M$$

5Fe²⁺+MnO₄⁻+8H⁺→5Fe³⁺+Mn²⁺+4H₂O：

$$c(\mathrm{Fe^{2+}}) = 7.850\times 10^{-3}\times 11.80/15.00\times 5\times 55.85 = 1.724\ \mathrm{g/L}$$

$$\omega(\mathrm{Fe^{2+}}) = 1.724/2.505 = 68.8\%$$

**9-4** (1) E=E^θ+(0.059/1)lg([Fe³⁺]/[Fe²⁺]) 体系 vs SHE：E=0.132+0.241=0.373 V：

$$\lg\frac{[\mathrm{Fe(CN)_6^{3-}}]}{[\mathrm{Fe(CN)_6^{4-}}]} = \frac{0.373-0.364}{0.059} = 0.153 \Rightarrow \text{比值}=1.42$$

$$\omega(\mathrm{Fe^{2+}}) = 1/(1+1.42) = 41.3\%$$

(2) 氨防酸性 HCN 生成（CN⁻+H⁺→HCN）；酒石酸配位防 Fe(OH)₃、Fe(OH)₂ 沉淀与普鲁士蓝 KFe(II)Fe(III)(CN)₆ 生成。

</details>
