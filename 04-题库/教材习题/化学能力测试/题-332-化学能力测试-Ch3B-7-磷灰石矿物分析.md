# 磷灰石矿物分析

> **来源**：化学竞赛能力测试·第3章·B卷第7题（10 分）

某磷酸盐矿化学式是 A₅(PO₄)₃B（记为 N），具有熔融后重新结晶的性质。该磷酸盐矿结晶属于六方晶系，晶胞参数：a = b = 0.999 nm、c = 0.733 nm、α = γ = 90°、β = 120°、Z = 2。其密度 ρ = 7.111 g·cm⁻³。

将 1.000 g N 完全溶解于浓硝酸后，以 KOH 中和溶液至 pH≈5，加入 1.224 g KI，生成 1.700 g 沉淀。

**7-1** 确定该磷酸盐矿 N 的化学式。

**7-2** 写出当不足量的 KI 加入时可能发生的反应。

在某些情况下，相当一部分 A 会被杂质 C 取代。A 的相对原子质量是 C 的 3.98 倍。为确定杂质含量，将 1.00 g 矿物 N 溶于硝酸。向溶液中加入 Na₂SO₄ 后生成白色沉淀。滤除沉淀后向滤液中加入氨水，分离出生成的 C(OH)ₙ 并将其溶于硫酸。为了滴定 C(+n 价)，首先需被预氧化至 C(+m 价)。为此，在 Ag₂S₂O₈ 存在下（Ag⁺ 作催化剂），加热 C(+n 价)的硫酸溶液。该溶液转移入 100 mL 容量瓶并以蒸馏水定容。移取 10.0 mL 溶液至烧瓶，再加入 10.0 mL 1.00 mol·L⁻¹ 酸化的 (NH₄)₂Fe(SO₄)₂ 溶液。混合液最后以 15.0 mL 9.44×10⁻³ mol·L⁻¹ 的 KMnO₄ 溶液滴定至终点。

**7-3** 确定杂质 C。写出所有题目中提到的方程式。

**7-4** 计算该磷酸盐矿中 C 的质量分数（w%）。

<details>
<summary>📖 查看答案与解析</summary>

**7-1** 确定磷酸盐矿化学式，首先计算其摩尔质量：

$$\rho = \frac{m}{V} = \frac{m}{abc\sin\beta},\quad m = \frac{MZ}{N_A}$$

$$M = \frac{\rho N_A abc\sin\beta}{Z} = \frac{7.111\times 6.02\times 10^{23}\times 9.99\times 7.33\times 10^{-22}\times 0.866}{2} = 1356\ \mathrm{g/mol}$$

阳离子 A 可从与 KI 的反应鉴定：1.000 g 固体中 N 的摩尔数 = 1/1356 = 7.375×10⁻⁴ mol；KI 1.224/166 = 7.37×10⁻³ mol。两种试剂比值：5×7.375×10⁻⁴/7.37×10⁻³ = 0.500，即 A²⁺ + 2I⁻ = AI₂（每 5 个 A 需 10 I⁻，实际 5 个 A 中 5/2? 按每 N 含 5 个 A：7.375e-4×5 = 3.688e-3 mol A，需 7.37e-3 mol I⁻ 恰为 2 倍 ✓）。

沉淀摩尔质量 = 1.700/3.688×10⁻³ = 461 g/mol，故 A 的摩尔质量 M(A) = 461 − 2×127 = 207 g/mol → A 为 Pb。

确定 B：M(B) = 1356 − 5×207 − 3×95 = 36 g/mol（PO₄³⁻ = 95）→ B 为 Cl。因此 N 的化学式为 Pb₅(PO₄)₃Cl（磷氯铅矿/羟基磷灰石类似物）。

**7-2** 不足量 KI 时可能发生的反应：

$$\mathrm{Pb^{2+}} + 2\mathrm{I^-} \longrightarrow \mathrm{PbI_2}\downarrow$$

$$\mathrm{PbI_2} + 2\mathrm{I^-} \longrightarrow [\mathrm{PbI_4}]^{2-}\quad\text{（KI 过量时 PbI₂ 溶解）}$$

**7-3** 杂质 C：M(C) = 207/3.98 = 52 g/mol → C 为 Cr。

所有方程式：

$$\mathrm{Pb^{2+}} + \mathrm{SO_4^{2-}} \longrightarrow \mathrm{PbSO_4}\downarrow$$

$$\mathrm{Cr^{3+}} + 3\mathrm{NH_3} + 3\mathrm{H_2O} \longrightarrow \mathrm{Cr(OH)_3}\downarrow + 3\mathrm{NH_4^+}$$

$$\mathrm{Cr(OH)_3} + 3\mathrm{H^+} \longrightarrow \mathrm{Cr^{3+}} + 3\mathrm{H_2O}$$

预氧化（Ag⁺ 催化）：

$$2\mathrm{Cr^{3+}} + 3\mathrm{S_2O_8^{2-}} + 7\mathrm{H_2O} \longrightarrow \mathrm{Cr_2O_7^{2-}} + 6\mathrm{SO_4^{2-}} + 14\mathrm{H^+}$$

Cr₂O₇²⁻ 与 Fe²⁺ 反应（返滴定）：

$$\mathrm{Cr_2O_7^{2-}} + 6\mathrm{Fe^{2+}} + 14\mathrm{H^+} \longrightarrow 2\mathrm{Cr^{3+}} + 6\mathrm{Fe^{3+}} + 7\mathrm{H_2O}$$

过量的 Fe²⁺ 用 KMnO₄ 滴定：

$$5\mathrm{Fe^{2+}} + \mathrm{MnO_4^-} + 8\mathrm{H^+} \longrightarrow \mathrm{Mn^{2+}} + 5\mathrm{Fe^{3+}} + 4\mathrm{H_2O}$$

**7-4** 反滴定法计算：用 KMnO₄ 滴定的过量 Fe²⁺：

$$n_{\text{过量}}(\mathrm{Fe^{2+}}) = 5\times c(\mathrm{MnO_4^-})\times V = 5\times 9.44\times 10^{-3}\times 15.0\times 10^{-3} = 7.08\times 10^{-4}\ \mathrm{mol}$$

在 10.0 mL 等分试样中与 Cr₂O₇²⁻ 反应的 Fe²⁺ = 10.0×10⁻³×1.00 − 7.08×10⁻⁴ = 2.92×10⁻⁴ mol：

$$m_\mathrm{al}(\mathrm{Cr}) = \frac{2.92\times 10^{-4}\times 2\times M(\mathrm{Cr})}{6} = 5.1\ \mathrm{mg}$$

对于 1.00 g 矿物：m(Cr) = 5.1×10 = 51 mg → 铬的质量分数 = 0.051/1.00 = 5.1%。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| 化学式推断 | 密度 → M=1356 → Pb₅(PO₄)₃Cl |
| 沉淀鉴定 | Pb²⁺ + 2I⁻ → PbI₂（M 461）|
| 返滴定 | Fe²⁺ 过量 + KMnO₄ 回滴 |
| 氧化还原 | Cr³⁺→Cr₂O₇²⁻（S₂O₈²⁻/Ag⁺）|
| 指示剂 | Mn²⁺ 氧化成 MnO₄⁻ 显粉红 |
