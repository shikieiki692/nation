# Co 氰配合物氧化还原机理

> **来源**：化学竞赛能力测试·第4章·A卷第1题（10 分）

将 CoCl₂·6H₂O 在 N₂ 气氛下与 KCN 作用，欲得到顺磁性的产物 A，结果却得到红色抗磁性的固体 B，反应方程式为 CoCl₂·6H₂O + KCN（水溶液）→(N₂气氛) 绿色溶液 →(E+OH⁻) 固体 B，但将 B 溶于水形成溶液 B 又转化为顺磁性的 C。已知 C 可以发生如下反应 C →(Cl₂) 溶液 →(E+OH⁻) D，D 是一种不含结晶水的钾盐，其含钾质量分数为 34.3%。

**1-1** 写出 A、B、C、D 的化学式及 B 的阴离子的空间结构。

**1-2** 由 C → D 的反应历程类似于有机反应中的自由基反应，试写出 C → D 的反应机理。

**1-3** D 也可以用另一种方法合成：E + CN⁻（过量）→ F↑ + D。F 是一种常见的在工农业生产中有重要用途的气体。E 是一种含两种配体的 Co(Ⅲ) 配合物，F 是其中一种配体。

(1) 写出 E、F 的化学式。

(2) CN⁻ 是一种很强的配体，而它只取代 E 中的 F 配体，不取代另一种配体，这是因为：溶液中的微量的 Co²⁺ 是此反应的催化剂，写出此反应的机理，并解释机理的合理性（提示：[Co(CN)₅]³⁻ 是一种强还原剂）。

<details>
<summary>📖 查看答案与解析</summary>

Co(Ⅱ)和 Co(Ⅲ)配合物是经常考查的内容，一般为六配位。但需注意：在特殊情况下，Co 不遵循六配位。

**1-1** A：K₄[Co(CN)₆]（Co²⁺，顺磁）；B：K₆[(CN)₅Co—Co(CN)₅]（Co—Co 金属键，抗磁）；C：K₃[Co(CN)₅]（Co²⁺ 五配位，顺磁）；D：K₃[Co(CN)₅Cl]。

B 的阴离子结构 [(NC)₅Co—Co(CN)₅]⁶⁻：两个 Co 通过 Co—Co 键相连，每个 Co 为八面体配位（5 个 CN⁻ + 1 个 Co）：

![[9086862f3ca61532225549b56fd99d14b396d60068294bff13568fd5f4845f6e.jpg]]

（Co(Ⅱ)-Co(Ⅱ) 二聚：Co 3d⁷，成 Co—Co 键后 d 电子配对 → 抗磁。）

**1-2** C → D 的自由基机理（Cl₂ 引发）：

$$[\mathrm{Co(CN)_5}]^{3-} + \mathrm{Cl-Cl} \longrightarrow [\mathrm{Co(CN)_5Cl}]^{3-} + \mathrm{Cl\cdot}\ (\text{氯原子})$$

$$\mathrm{Cl\cdot} + [\mathrm{Co(CN)_5}]^{3-} \longrightarrow [\mathrm{Co(CN)_5Cl}]^{3-}$$

（[Co(CN)₅]³⁻ 为强还原剂/自由基捕捉剂，两个 [Co(CN)₅]³⁻ 与 Cl₂ 发生氧化加成类似自由基链。）

**1-3** (1) E：[Co(NH₃)₅Cl]²⁺（或 [Co(NH₃)₅X]²⁺，F 为 NH₃——CN⁻ 只取代 NH₃ 配体；但按题意 F 是气体，答案 F：NH₃ 与卤化氢？F 应为 NH₃——源答案 E:[Co(NH₃)₅X]²⁺、F:NH₃，照录）。

(2) 机理：

$$\mathrm{Co^{2+}} + 5\mathrm{CN^-} \longrightarrow [\mathrm{Co(CN)_5}]^{3-}$$

$$[\mathrm{Co(CN)_5}]^{3-} + [\mathrm{Co(NH_3)_5X}]^{2+} \longrightarrow [(\mathrm{NH_3})_5\mathrm{Co}\cdots\mathrm{X}\cdots\mathrm{Co(CN)_5}] \longrightarrow [\mathrm{Co(CN)_5X}]^{3-} + \mathrm{Co^{2+}} + 5\mathrm{NH_3}\uparrow$$

解释：[Co(Ⅱ)(CN)₅]³⁻ 是强还原剂，CN⁻ 比 NH₃ 结合得牢，电子容易从 Co(Ⅱ) 转移到 Co(Ⅲ)，[Co(NH₃)₅X]²⁺ 是容易取代的物种，因此得到 Co²⁺(aq)，然后它又重新与 CN⁻ 结合生成 [Co(CN)₅]³⁻，起到催化作用（催化循环）。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| Co 配合物价态 | Co²⁺(d⁷) 顺磁 vs Co³⁺(d⁶) 抗磁 |
| 金属-金属键 | [(CN)₅Co-Co(CN)₅]⁶⁻ 二聚体 |
| 自由基机理 | Cl₂ 均裂 + [Co(CN)₅]³⁻ 捕获 |
| 催化循环 | Co²⁺ 再生催化 CN⁻ 取代 |
| 五配位 Co | [Co(CN)₅]³⁻ 特殊配位 |
