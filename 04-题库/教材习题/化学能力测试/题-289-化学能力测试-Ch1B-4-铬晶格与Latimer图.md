# 铬的晶格与 Latimer 图

> **来源**：化学竞赛能力测试·第1章·B卷第4题（10 分）

铬的金属半径约为 126 pm。铬的密度是 $7.14\,\mathrm{g\cdot cm^{-3}}$。固体铬属于规则的立方晶系。

**4-1** 仅用以上确定铬的晶格类型。

曾有如下的用来检测来氯离子存在的方法：将未知材料与重铬酸钾的干燥混合物与与质 $\mathrm{H_2SO_4}$ 一起加热。生成的气体通入 NaOH 溶液，若出现黄色说明有氯存在。

**4-2** 此反应中生成的挥发性铬化合物是什么？画出其结构。注意 Cr 和 Cl 在反应中氧化态均未改变。

**4-3** 铬酸钾溶液的酸化会生成橙色的重铬酸根离子，然后是较深红色的三和四铬酸根离子。用与硫酸我们可以得到一种不含钾的红色沉淀。反应方程式并画出离子的结构。你可以推出这种沉淀的结构吗？

**4-5** Cr(V) 和 Cr(IV) 在歧化反应中稳定吗？说明基于 Latimer 图的一种判断标准。$\mathrm{Cr^{2+}}$ 的歧化反应的平衡的常数是多少？

**4-6** 计算氢氧化铬(Ⅲ)的溶度积常数和四羟基铬(Ⅲ)阴离子的总稳定常数。

**4-7** 下图给出了一系列的与氧相关的物种在酸性（pH=0）和碱性（pH=14）介质中的 Latimer 图：

**4-1** 在立方晶系中，可以是简单立方、面心立方（fcc）和体心立方（bcc）晶格。这些晶胞分别包含 1、4 或 2 个原子。我们可以利用原子在每个晶格中相互接触的事实来确定晶格常数取决于金属半径。我们得到简单立方 $a = 2R$；对于 fcc: $a = 2R\sqrt{2}$；对于 bcc: $a = 4R/\sqrt{3}$。

- 简单立方：$V = M(\mathrm{Cr})/(\rho N_A) = 1.209\times10^7\ \mathrm{pm^3}$，$a = 229.5\ \mathrm{pm}$，与 $a=2R=252\ \mathrm{pm}$ 不符。
- fcc：$V = 4M/(\rho N_A) = 4.838\times10^7\ \mathrm{pm^3}$，$a = 364.4\ \mathrm{pm}$，与 $a=2R\sqrt{2}=356\ \mathrm{pm}$ 不一致。
- bcc：$V = 2M/(\rho N_A) = 2.419\times10^7\ \mathrm{pm^3}$，$a = 289.2\ \mathrm{pm}$，与 $a=4R/\sqrt{3}=291\ \mathrm{pm}$ 相当接近。

因此铬的晶格是体心立方（bcc）。

**4-3** 离子方程式为：

$$2\mathrm{CrO_4^{2-}} + 2\mathrm{H^+} = \mathrm{Cr_2O_7^{2-}} + \mathrm{H_2O}$$

$$3\mathrm{CrO_4^{2-}} + 4\mathrm{H^+} = \mathrm{Cr_3O_{10}^{2-}} + 2\mathrm{H_2O}$$

$$4\mathrm{CrO_4^{2-}} + 6\mathrm{H^+} = \mathrm{Cr_4O_{13}^{2-}} + 3\mathrm{H_2O}$$

这些离子的结构为：

$\mathrm{CrO_3}$ 是衍生自多铬酸根离子的聚合物链。

**4-4** 使用公式 $E^\theta = (n_1 E_1^\theta + n_2 E_2^\theta)/(n_1+n_2)$ 计算：

由此可知，$E^\theta(\mathrm{Cr(V)/Cr(IV)}) = 1.35\ \mathrm{V}$，$E^\theta(\mathrm{Cr_2O_7^{2-}/Cr^{3+}}) = 1.33\ \mathrm{V}$，$E^\theta(\mathrm{Cr^{2}^+/Cr}) = 0.90\ \mathrm{V}$。

**4-5** 歧化的标准是：$E_{ox} < E_{red}$，其中 $E_{ox}$ 是氧化电势，而 $E_{red}$ 是还原电势。如果 Latimer 图上右侧的数值大于左侧的数值，则该物种倾向歧化反应。由此可见，Cr(V) 和 Cr(IV) 会发生歧化反应，都是不稳定的。

对于 $3\mathrm{Cr^{2+}} = 2\mathrm{Cr^{3+}} + \mathrm{Cr}$ 反应，可以从标准氧化还原电势值计算平衡常数：

$$\Delta_r G^\theta = -2\times F\times(-0.90\ \mathrm{V} - (-0.42\ \mathrm{V})) = 93\ \mathrm{kJ\cdot mol^{-1}}$$

由 $\Delta_r G^\theta$ 使用公式 $K = \exp(-\Delta_r G^\theta/RT)$，可以计算化学平衡常数 $K = \exp(-93000/(8.314\times298)) = 5.91\times10^{-17}$。

**4-6** $\mathrm{Cr(OH)_3}$ 溶度积常数，可以从 pH=14 的 Latimer 图进行计算。比较 pH=0 和 pH=14 时 $\mathrm{Cr(III)}\longrightarrow\mathrm{Cr(0)}$ 过程的标准电势（V）可以写为：

$$-1.33 = -0.74 + \frac{0.059}{3}\lg(K_{sp}/[\mathrm{OH^-}]^3)$$

解得 $\mathrm{p}K_{sp} = 30$。

同样，对于四羟合铬(Ⅲ)酸根阴离子的总稳定常数可以写为：

$$-1.33 = -0.74 + \frac{0.059}{3}\lg\left(\frac{[\mathrm{Cr(OH)_4^-}]}{K[\mathrm{OH^-}]^4}\right)$$

$[\mathrm{Cr(OH)_4^-}]$ 和 $[\mathrm{OH^-}]$ 浓度均为 $1.0\ \mathrm{mol\cdot L^{-1}}$，可以得到：$\mathrm{p}K = -30$（即 $K = 10^{30}$）。

**4-7** 在酸性条件下，属于这些物种的最高标准电池电势为 $1.33\ \mathrm{V} - 0.695\ \mathrm{V} = 0.635\ \mathrm{V}$。因此，在酸性溶液中，过氧化氢被氧化为 $\O_2$，Cr(VI) 被还原为 Cr(III)。反应方程式为：

$$\mathrmCr_2O_7^{2-} + 3\mathrm{H_2O_2} + 8\mathrm{H^+} = 2\mathrm{Cr^{3+}} + 3\mathrm{O_2} + 7\mathrm{H_2O}$$

在碱性溶液中，$\mathrm{OH^-}$ 的形成和电势差 $E^\theta[\mathrm{Cr(VI)}/\mathrm{Cr(III)}] = 0.87\ \mathrm{V} - (-0.72\ \mathrm{V}) = 1.59\ \mathrm{V}$。反应方程式为：

$$2[\mathrm{Cr(OH)_4}]^- + 3\mathrm{HO_2^-} = 2\mathrm{CrO_4^{2-}} + 5\mathrm{H_2O} + \mathrm{OH^-}$$

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| 晶格类型判定 | 密度法 + 金属半径 → bcc |
| 多酸盐结构 | Cr₂O₇²⁻/Cr₃O₁₀²⁻/Cr₄O₁₃²⁻/CrO₃ 链 |
| Latimer 图 | Cr、O 物种酸碱电势 |
| 溶度积与配位稳定常数 | Ksp / K（pK）= 30 |
| 歧化稳定判据 | E_ox < E_red |
| 过氧化氢的两性 | 酸中作还原剂，碱中作氧化剂 |
