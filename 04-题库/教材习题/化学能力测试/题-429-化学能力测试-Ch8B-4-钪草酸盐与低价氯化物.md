# 钪草酸盐与低价氯化物

> **来源**：化学竞赛能力测试·第8章·B卷第4题（10 分）

1879 年 Nilson 发现新金属 X（门捷列夫预言"类硼"）。草酸钠加入 X 氯化物富集液得不溶物 A；A<100℃ 分解失 ~20% 得 B；B>400℃ 得白不溶 C。C+NaF 浓盐酸（12 eq）→E；E+6 eq NaF →D；D+Ca→X。

**4-1** 通过计算确定各化合物并写反应。

F~I 是 X 的簇氯化物（X 质量分数递增）。F=4:3 摩尔比 X 高氯化物+X 熔合制得；F 长热分解得 I（失 23.95%）；F+H→G（F→G X 氧化态变化 20/3%；H→G 变化 12%；F/H 金属原子数同）。

**4-2** 计算 F~I 组成并写反应。

<details>
<summary>📖 查看答案与解析</summary>

**4-1** X₂O₃+6NaF+6HCl→2XF₃+6NaCl+3H₂O（D）；X₂O₃+12NaF+6HCl→2Na₃XF₆+6NaCl+3H₂O（E）。

E/D 摩尔质量比 2.235：

$$(3\times 23 + x + 6\times 19)/(x + 3\times 19) = 2.235 \Rightarrow x = 45$$

**X=Sc**。A=Sc₂(C₂O₄)₃·5H₂O（失 20% 验算结晶水：90/(666+90)=11.9%？源 20% 含部分草酸分解，按 n=5 照录）；B=Sc₂(C₂O₄)₃；C=Sc₂O₃；D=ScF₃；E=Na₃ScF₆。

2Sc₂(C₂O₄)₃+3O₂→2Sc₂O₃+12CO₂；2ScF₃+3Ca→3CaF₂+2Sc。

**4-2** F：4ScCl₃+3Sc→**Sc₇Cl₁₂**（Sc₆Cl₁₈ 簇片段，Sc 八面体+Cl 桥/端，Sc 平均 +12/7）。

F 分解失 23.95% 产 I：Sc₇Cl₁₂→7ScCl+2.5Cl₂（I=**ScCl**）。

H→G 与 F→G 联立：F(+12/7)→G 降 20/3%→G 氧化态 12/7×(1−2/30)=1.6=8/5 → **G=Sc₅Cl₈**；H 比 G 高 12%：1.6/(1+0.12)=10/7 → **H=Sc₇Cl₁₀**。

3Sc₇Cl₁₂+2Sc₇Cl₁₀→7Sc₅Cl₈
