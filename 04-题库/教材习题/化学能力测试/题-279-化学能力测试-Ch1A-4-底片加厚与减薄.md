# 底片加厚与减薄

> **来源**：化学竞赛能力测试·第1章 化学反应方程式与核化学反应方程式·A卷第4题（10 分）

## 题目

照相时若曝光不足，则已显影和定影的黑白底片图像淡薄，需要对其进行加厚处理；若曝光过度，则需对图像进行减薄。

4-1 加厚的一种方法是：把底片放入由硝酸铅、赤血盐溶于水配成的溶液，取出，洗净，再用硫化钠溶液处理。写出底片图像加厚的反应方程式。

4-2 减薄的一种方法是：按一定比例混合硫代硫酸钠溶液和赤血盐溶液，把要减薄的底片用水充分湿润后浸入，适当减薄后，取出冲洗干净。写出底片图像减薄的反应方程式。

4-3 如底片经过加厚处理后，图像仍不明显，能否再次用以上方法继续加厚？又经减薄后的底片，能否再次用以上方法减薄？说明理由。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** 加厚（赤血盐将影像中银氧化为银氰配合物盐，再经铅盐置换与硫化处理增黑）：

$\mathrm{4Ag + 4K_3[Fe(CN)_6] \longrightarrow Ag_4[Fe(CN)_6] + 3K_4[Fe(CN)_6]}$

（Ag 失电子被氧化为 Ag⁺ 与 [Fe(CN)₆]⁴⁻ 结合成难溶 Ag₄[Fe(CN)₆]；K₄[Fe(CN)₆] 随后与硝酸铅作用）

$\mathrm{K_4[Fe(CN)_6] + 2Pb(NO_3)_2 \longrightarrow Pb_2[Fe(CN)_6] + 4KNO_3}$

用 Na₂S 处理：

$\mathrm{Ag_4[Fe(CN)_6] + 2Na_2S \longrightarrow 2Ag_2S\downarrow + Na_4[Fe(CN)_6]}$

$\mathrm{Pb_2[Fe(CN)_6] + 2Na_2S \longrightarrow 2PbS\downarrow + Na_4[Fe(CN)_6]}$

（Ag₂S 与 PbS 均比 Ag 黑，起到影像加厚增黑作用）

**4-2** 减薄（赤血盐把银氧化为 Ag₄[Fe(CN)₆]，再用硫代硫酸钠把 Ag⁺ 配合溶解移走）：

$\mathrm{4Ag + 4K_3[Fe(CN)_6] \longrightarrow Ag_4[Fe(CN)_6] + 3K_4[Fe(CN)_6]}$

$\mathrm{Ag_4[Fe(CN)_6] + 8Na_2S_2O_3 \longrightarrow 4Na_3[Ag(S_2O_3)_2] + Na_4[Fe(CN)_6]}$

（银以 $\mathrm{[Ag(S_2O_3)_2]^{3-}}$ 配离子形式溶解，从底片除去，影像减薄）

**4-3** 加厚处理后的底片**不能**再次用上述方法继续加厚：因为加厚后影像已转化为 Ag₂S 和 PbS，而 $\mathrm{K_3[Fe(CN)_6]}$ 氧化不了 Ag₂S 和 PbS（S²⁻ 电子云与 Ag⁺ 结合紧密），无法进一步氧化增厚。

减薄后的底片**能**再次用上述方法减薄：因为 $\mathrm{K_3[Fe(CN)_6]}$ 能继续氧化剩余的 Ag（只要还有金属 Ag 存在），$\mathrm{Na_2S_2O_3}$ 也能继续溶解新生成的 Ag₄[Fe(CN)₆]。

</details>
