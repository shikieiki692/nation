# Pd 催化 H₂O₂ 合成与 CS₂ 催化裂解

> **来源**：化学竞赛能力测试·第4章·B卷第10题（10 分）

过氧化氢是一种绿色氧化剂，主要应用于造纸工业，在环境保护方面也有广阔的应用前景。近年来过氧化氢的制备方法和生产工艺不断改进，逐渐淘汰了生产方式陈旧能量消耗高的氧阴极法和存在安全问题的异丙醇法，而蒽醌法经过不断研究改进已经成为目前 $\mathrm{H_2O_2}$ 生产的主要方法。但是蒽醌法工艺流程复杂，生产成本较高，限制了 $\mathrm{H_2O_2}$ 的应用，同时人们正在进行氢氧直接化合法的研究，这是一种符合原子经济的绿色的 $\mathrm{H_2O_2}$ 生产方法，工业化前景乐观，但它仍需解决生产安全、$\mathrm{H_2O_2}$ 收率等问题。作为氢氧直接化合法的一种可替代方法，$\mathrm{O_2/CO}$ 与 $\mathrm{H_2O}$ 反应发现在三苯膦钯配合物（氯化物）的存在下制备 $\mathrm{H_2O_2}$，可在很大程度上降低反应的危险性，$\mathrm{O_2}$ 和 CO 在操作条件下（没有明火）形成比较安全的混合气体。

**10-1** 请写出总反应方程式。

**10-2** 反应机理如下，请分步写出反应式：

(1) Pd(Ⅱ) 配合物被 CO 还原成 Pd(0) 配合物同时产生 $\mathrm{CO_2}$。

(2) Pd(0) 配合物被 $\mathrm{O_2}$ 氧化生成过氧化 Pd(Ⅱ) 配合物。

(3) 过氧化 Pd(Ⅱ) 配合物与酸 $\mathrm{HX}$（$\mathrm{X^-}$ 是一种结合力较弱的配位离子如 $\mathrm{CF_3COO^-}$、$\mathrm{AcO^-}$ 等，称 HX 为酸助催化剂）反应，产生 $\mathrm{H_2O_2}$ 和原始的 Pd(Ⅱ) 配合物。

**10-3** 氯代有机物 (RCl) 在过氧化氢的合成上有很好的促进效果，但却导致催化剂很快失活，生成的 $\mathrm{H_2O_2}$ 大量减少，且发现产物中有烃类、氯化氢、二氧化碳。原因是可能存在副反应，试用化学方程式解释有上述几种副产品的原因。

**10-4** 本方法除了催化剂转化率低这个缺点，还有个实际生产中所要考虑的问题是什么？

由于 Pd 的价电子排布为 $4d^{10}$，因此 Pd(0) 二配位；而 Pd(Ⅱ) 价电子排布为 $4d^8$，因此一般为四配位，且一般是平面四边形。这一点是解题的关键。

**10-1** 总反应方程式：

$$\mathrm{O_2 + CO + H_2O \longrightarrow H_2O_2 + CO_2}$$

**10-2** 机理分步：

(1) Pd(Ⅱ) 配合物被 CO 还原：

$$\mathrm{(PPh_3)_2Pd(Ⅱ)X_2 + CO + H_2O \longrightarrow (PPh_3)_2Pd(0) + CO_2 + 2HX}$$

(2) Pd(0) 配合物被 $\mathrm{O_2}$ 氧化：

$$\mathrm{(PPh_3)_2Pd(0) + O_2 \longrightarrow (PPh_3)_2Pd(Ⅱ)(\eta^2-O_2)}$$

中间体结构（侧基 $\mathrm{O_2}$）：

![[87c2408c0ac6ff9806289b41c6dc588070a457943e1d035f6e7a7174b3407d64.jpg]]

(3) 过氧化 Pd(Ⅱ) 与酸反应再生：

$$\mathrm{(PPh_3)_2Pd(Ⅱ)O_2 + 2HX \longrightarrow H_2O_2 + (PPh_3)_2Pd(Ⅱ)X_2}$$

**10-3** 副反应：

$$\mathrm{RCl + CO + H_2O \longrightarrow RH + HCl + CO_2}$$

RCl 在 Pd 催化下与 CO/H₂O 反应消耗 CO、生成 RH + HCl + CO₂ 副产物，导致催化剂 Pd(II) 被 Cl⁻ 不可逆配位失活（Pd(II) 对 Cl⁻ 亲和力远强于 CF₃COO⁻、AcO⁻）。

**10-4** 实际生产问题：贵金属钯催化剂的回收与再生比较困难，不可避免造成贵金属催化剂的浪费；催化剂与配体的回收还涉及分离萃取等单元操作使工艺复杂，增加操作费用。

**10-5** 化合物 A 化学式推导：

含氮双齿配体含碳、氢、氮三种元素，设为 $\mathrm{C_mH_nN_2}$。根据氮质量分数：

$$M(\text{配体}) = \frac{28}{17.94\%} = 156\ \mathrm{g\cdot mol^{-1}}$$

即 $12m + n + 28 = 156$。当 $m=10, n=8$ 时符合，配体为**联吡啶** $\mathrm{C_{10}H_8N_2}$（bpy），与 Pd 形成五元螯环：

![[5e45961860c76086c141ef1cfb45bdf3b218d6b5e5da5f0c1bbb11a28b04a653.jpg]]

同理根据「A 中氮元素质量分数为 14.50%」，可推导 A 分子式为 $\mathrm{Pd(C_{10}H_8N_2)(NO_3)_2}$：

$$w(\mathrm{N}) = \frac{2\times 14}{156 + 2\times 62} = \frac{28}{280} = 10\%$$

源答案用 14.50%（按 14×2/Pd(106.42)+28×10+...) 验算得 Pd=106.42、bpy=156、2 NO₃=124，总 M=386，$w(\N) = 28/386 = 7.25\%$ 与 14.50% 不符；源答案以「N 14.50% 推 A」应包含更多 N 元素（或 Pd=53.21 取二聚计算）。照录源答案结论 $\mathrm{Pd(bpy)(NO_3)_2}$。

配体结构简式：

![[785c7b2d456f034d638ef9f548fa4dde785a47331eebcef4abd24703a101e4a5.jpg]]

**10-6** 由 6A → 3B，B 分子式为 $\mathrm{Pd_2(C_{10}H_8N_2)_2(NO_3)_4}$。B 中阳离子 +2 价，4 个 $\mathrm{NO_3^-}$ 中 2 个在外、2 个在内（双齿），故 B 阳离子结构式：

![[823683e5dcfc8dede7e486e67ff9846d50a11665ad6c4005b060a022eb5474b3.jpg]]

化合物 C 中 Pd 满足 EAN 规则。C 中阳离子 +2 价，$n(\mathrm{Pd}):n(\mathrm{S}) = \dfrac{106.42/32.71\%}{32.06/6.57\%} = \dfrac{325.4}{488.1} = 1:1.5$，即 $n(\mathrm{Pd}):n(\mathrm{S}) = 2:3$，进一步调整为 $3:2$（与 bpy 数对应），$M(C) = 106.42\times 3/32.71\% = 976$。设 $C$ 化学式为 $\mathrm{[Pd_3S_2(C_{10}H_8N_2)_m](NO_3)_n}$：

$$106.42\times 3 + 32.06\times 2 + 156m + 62n = 976$$

解不定方程：$m=3, n=2$。故 C 化学式 $\mathrm{[Pd_3S_2(C_{10}H_8N_2)_3](NO_3)_2}$，阳离子 $\mathrm{[Pd_3S_2(bpy)_3]^{2+}}$，C 结构：

![[6c823aeae71365c1a4974b6d1cfb6f6b40af855beb2d0fc6e42b9d4ec45973f8.jpg]]

Pd 在 B 中杂化为 $dsp^2$，在 C 中杂化为 $d^2sp^3$（Pd 八面体配位）。

**10-7** 总反应方程式：

$$\mathrm{CS_2 + 12HNO_3 = CO_2 + 2SO_2 + 12NO_2 + 6H_2O}$$

守恒验算：C 1=1 ✓、S 1=2 ✗——题面总反应式按源答案 N 守恒（1 N NO₃ = 1 N NO₂ 但 N 总 12）而 S 不平衡（1 vs 2），源答案反应式应改为 $\mathrm{2CS_2 + ...}$ 或系数调整，照录原式并注。
