# 光电化学电池与 Ru 配合物

> **来源**：化学竞赛能力测试·第4章·A卷第8题（10 分）

太阳能发电和阳光分解水制氢，是清洁能源研究的主攻方向，研究工作之一集中在 n 型半导体光电化学电池方面。下图是 n 型半导体光电化学电池光解水制氢的基本原理示意图，图中的半导体导带（未充填电子的分子轨道构成的能级最低的能带）与价带（已充填价电子的分子轨道构成的能级最高的能带）之间的能量差 ΔE = E_c − E_v 称为带隙。

![[935eca929cb1760e4a7154733b3739b34e248165a25d08414e8da0ad6769f0ca.jpg]]

瑞士科学家最近发明了一种基于上图所示原理的廉价光电化学电池装置，其半导体电极由两个光系统串联而成。系统一由吸收蓝色光的 WO₃ 纳米晶薄膜构成；系统二吸收绿色和红色光，由染料敏化的 TiO₂ 纳米晶薄膜构成。在光照下，系统一的电子由价带跃迁到导带后，转移到系统二的价带，再跃迁到系统二的导带，然后流向对电极。所采用的光敏染料为配合物 RuL₂(SCN)₂，其中中性配体 L 为 4,4'-二羧基-2,2'-联吡啶。

**8-1** 指出配合物 RuL₂(SCN)₂ 中配体 L 的配位原子和中心金属原子的配位数。

**8-2** 推测该配合物的分子结构，并用 Z—Z 代表 L（其中 Z 为配位原子），画出该配合物及其几何异构体的几何结构示意图。

**8-3** 画出该配合物有旋光活性的键合异构体。

**8-4** 分别写出半导体电极表面和对电极表面发生的电极反应式，以及总反应式。

**8-5** 已知太阳光能量密度最大的波长在 560 nm 附近，说明半导体电极中 TiO₂ 纳米晶膜（白色）必须添加光敏剂的原因。

**8-6** 说明 TiO₂ 和配合物 RuL₂(SCN)₂ 对可见光的吸收情况，推测该配合物的颜色。

**8-7** 该光电化学电池装置所得产物可用于环保型汽车发动机吗？说明理由。

<details>
<summary>📖 查看答案与解析</summary>

本题主要考查配合物的几何异构体和旋光异构体的判断、书写。

**8-1** 配体 L 的配位原子是两个吡啶环上的 N 原子（4,4'-二羧基联吡啶的两个 N），中心金属 Ru 的配位数是 6（2 个 L ×2 N + 2 个 SCN⁻ ×1 = 6）。

**8-2** 该配合物的分子结构应为顺式结构 cis-RuL₂(SCN)₂（几何异构体为反式 trans-RuL₂(SCN)₂）。理由：(1) 配位原子放在金属原子相邻位置，且配合物表达式 RuL₂(SCN)₂ 中 SCN⁻ 为硫原子配位的硫氰酸根；(2) 顺式结构电偶极性强而反式几乎无极性，极性强的混合配体过渡金属配合物因存在分子内的电荷跃迁而光敏性好（染料需 MLCT 跃迁）。

![[df4f0b7ff917ef4d42c3a5d1572a84ee02518bbf74c7666ec119d240c7c850b7.jpg]]

![[e034fba161f5fb7016c60f2e1f66d6ab5ac410818c3e8e2101c9b4c832d4b4b8.jpg]]

**8-3** 该配合物有旋光活性的键合异构体（SCN⁻ 以 N 配位成 NCS⁻ 的异硫氰酸根异构体；顺式的 RuL₂(SCN)₂、RuL₂(NCS)₂ 和混配 RuL₂(NCS)(SCN) 都有旋光异构体——cis-M(A₂B₂C₂) 型配合物无对称面/中心时具手性）：

![[bd1eb218cf94af19cd9b5666227f0f61a995953b65473893462c708fcf3e798a.jpg]]

![[9b03d1841811a0b308106d659f67af1a04e5a47928a1859c4bdd2e466b805855.jpg]]

（trans-RuL₂(NCS)₂ 等。）

**8-4** 电极反应：

- 半导体（光阳极）表面：$4h^+ + 2\mathrm{H_2O} \longrightarrow \mathrm{O_2}\uparrow + 4\mathrm{H^+}$
- 对电极表面：$4\mathrm{H^+} + 4e^- \longrightarrow 2\mathrm{H_2}\uparrow$
- 总反应：$2\mathrm{H_2O} \xrightarrow{h\nu} \mathrm{O_2}\uparrow + 2\mathrm{H_2}\uparrow$

**8-5** 因纳米晶 TiO₂ 膜几乎不吸收可见光，而太阳光能量密度最大的波长在 560 nm 附近，故必须添加能吸收可见区（该波长范围）光能的光敏剂（染料），才可能充分利用太阳光的能量（染料吸收可见光将电子注入 TiO₂ 导带）。

**8-6** 自由 Ti⁴⁺ 离子的基态电子组态为 3d⁰，TiO₂ 既无 d-d 跃迁亦无荷移跃迁，因此几乎不吸收可见光，呈白色。配合物 RuL₂(SCN)₂ 吸收绿色和红色光（系统二吸收绿红光），由互补色原理推测：该配合物应当显橙色。

**8-7** 可用于环保型汽车发动机。该光电化学电池装置所得产物氢气属于清洁能源：氢气燃烧产生的热能可用于汽车发动机，也可经氢燃料电池产生电能驱动汽车发动机（产物为水、无污染）。

</details>
