# SbF₅-HF 超酸质子化

> **来源**：化学竞赛能力测试·第2章·B卷第7题（10 分）

酸性强于纯硫酸的酸称为超酸。超酸是很强的质子给予体，甚至能够质子化较弱的 Lewis 碱，例如 Xe、H₂、Cl₂、Br₂ 和 CO₂。人们在超酸溶液中观察到了很难存在于其他介质中的阳离子。George Olah 利用超酸发现了反应中碳正离子的生成，获得 1994 年诺贝尔化学奖。超酸的酸性较强是由于形成了溶剂化质子。最常见的一种超酸可以通过混合 SbF₅ 和 HF 得到。当液态 SbF₅ 溶解在液态 HF 中（要求 SbF₅/HF 的摩尔比大于 0.5）时，生成 SbF₆⁻ 与 Sb₂F₁₁⁻ 阴离子，释放出的质子被 HF 溶剂化。

**7-1** 写出 HF 与 SbF₅ 混合发生反应的化学方程式。

**7-2** 画出 $\mathrm{SbF_6^-}$ 与 $\mathrm{Sb_2F_{11}^-}$ 的结构（在两种阴离子中，中心离子的配位数均为 6，$\mathrm{Sb_2F_{11}^-}$ 中存在一根氟桥键）。

**7-3** 写出 $\mathrm{H_2}$ 和 $\mathrm{CO_2}$ 在 $\mathrm{HF/SbF_5}$ 超酸溶液中发生质子化的化学反应方程式。

**7-4** 画出 $\mathrm{HCO_2^+}$ 的 Lewis 结构式，要求写出共振结构并估计每个共振结构中 H—O—C 的键角。

<details>
<summary>📖 查看答案与解析</summary>

**7-1** HF—SbF₅ 为超酸体系，可视为 Lewis 酸碱反应（SbF₅ 接受 F⁻）：

$$2\mathrm{HF} + \mathrm{SbF_5} \longrightarrow \mathrm{H_2F^+} + \mathrm{SbF_6^-}$$

$$2\mathrm{HF} + 2\mathrm{SbF_5} \longrightarrow \mathrm{H_2F^+} + \mathrm{Sb_2F_{11}^-}\quad\text{（或）}$$

$$4\mathrm{HF} + 3\mathrm{SbF_5} \longrightarrow 2\mathrm{H_2F^+} + \mathrm{SbF_6^-} + \mathrm{Sb_2F_{11}^-}$$

（SbF₅/HF > 0.5 时主要生成 Sb₂F₁₁⁻。）

**7-2** 离子结构：

![[cff0d1aa24c21a7fbbfebb5af54f64f37ebc891e8f83ceeca08c03e374f96011.jpg]]

- SbF₆⁻：正八面体（Sb 配位数 6）
- Sb₂F₁₁⁻：两个 SbF₆ 八面体共用一个 F（氟桥键 F—Sb 桥），即 [F₅Sb—F—SbF₅]⁻

**7-3** $\mathrm{H_2F^+}$ 为超酸，给出质子的能力很强：

$$\mathrm{H_2F^+} + \mathrm{H_2} \longrightarrow \mathrm{HF} + \mathrm{H_3^+}$$

$$\mathrm{H_2F^+} + \mathrm{CO_2} \longrightarrow \mathrm{HF} + \mathrm{CO_2H^+}\ (\mathrm{or}\ \mathrm{HCO_2^+})$$

**7-4** HCO₂⁺（质子化 CO₂，即 HOCO⁺）的共振结构：

$$\ddot{\mathrm{O}} = \mathrm{C} = \mathrm{O^+} - \mathrm{H} \longleftrightarrow \overset{\oplus}{:}\mathrm{O} \equiv \mathrm{C} - \ddot{\mathrm{O}} - \mathrm{H} \longleftrightarrow \overset{\ominus}{:}\ddot{\mathrm{O}} - \mathrm{C} \equiv \overset{\oplus 2}{\mathrm{O}} - \mathrm{H}$$

每个共振结构中 H—O—C 键角估计为约 120°（O 为 sp² 或接近 sp² 杂化，答案区标 120°）。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| 超酸 | H₀ ≤ −12；溶剂化质子 H₂F⁺ |
| Lewis 酸碱 | SbF₅ 接受 F⁻ 成 SbF₆⁻/Sb₂F₁₁⁻ |
| 质子化 | H₂/CO₂ 被 H₂F⁺ 质子化 |
| 共振结构 | HCO₂⁺ 三种共振式 |
