# 叠氮化物反应

> **来源**：化学竞赛能力测试·第2章·B卷第5题（10 分）

叠氮化合物具有许多特殊性质，广泛应用于军事、化工等方面。

**5-1** 分别画出 $\mathrm{N_3^-}$ 和 $\mathrm{HN_3}$ 的共振结构式。

**5-2** 将 $\mathrm{N_2O}$ 通入 $\mathrm{NaNH_2}$ 的液氨溶液，或亚硝酸正丁酯与肼和 NaOH 在乙醇中加热回流，均可得到 $\mathrm{NaN_3}$。写出这两个反应的化学方程式。

**5-3** $\mathrm{HN_3}$ 是一种极不稳定的液体，会遇水缓慢水解，产物之一是羟氨。纯的 $\mathrm{HN_3}$ 本身也会分解。写出这两个反应的化学方程式。

**5-4** 三氯乙腈和过量 $\mathrm{NaN_3}$ 反应得到了一种含氮量 93.3% 的易爆炸的化合物 A。试写出制备 A 以及 A 爆炸的反应方程式。

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 共轭结构式中要将大 π 键标出。$\mathrm{N_3^-}$ 和 $\mathrm{CO_2}$ 为等电子体，都是两个三中心四电子的大 π 键（直线型）。而在 $\mathrm{HN_3}$ 中具有一个正常的 π 键（端基 N=N 双键）加一个三中心离域体系，注意把其他的电子标出。

答案为：$\mathrm{HN_3}$：$H-N-N\equiv N$ 及其共轭形式；$\mathrm{N_3^-}$：$[:N-N-N:]^-$（两个等价 π₃⁴ 离域）。

（本题难度较小但正答率不高，主要是很多人把共轭结构式画成共振式——应画带离域大 π 键的共轭结构而非离散共振式。）

**5-2**

$$\mathrm{N_2O} + 2\mathrm{NaNH_2} \longrightarrow \mathrm{NaN_3} + \mathrm{NaOH} + \mathrm{NH_3}$$

$$n\text{-}\mathrm{BuONO} + \mathrm{N_2H_4} + \mathrm{NaOH} \longrightarrow \mathrm{NaN_3} + n\text{-}\mathrm{BuOH} + 2\mathrm{H_2O}$$

**5-3** 氮气是比较稳定的气体，反应产物一般写氮气。类似地 $\mathrm{NaN_3}$ 的分解，产物是 Na 和 $\mathrm{N_2}$ 而不是 $\mathrm{Na_3N}$，原因与 $\mathrm{Na_3N}$ 的不稳定性有关。

$$\mathrm{HN_3} + \mathrm{H_2O} \longrightarrow \mathrm{NH_2OH} + \mathrm{N_2}$$

$$2\mathrm{HN_3} \longrightarrow \mathrm{H_2} + 3\mathrm{N_2}$$

**5-4** 该反应为叠氮负离子取代氯和氰基的反应，故产物的结构应该是 C 与四个叠氮基团相连。类比 $\mathrm{HN_3}$ 的结构可以得出 C—N—N 键角为折线型。本题难度适中，但 $\mathrm{CN_{12}}$ 的结构需要注意细节。

答案为：

$$\mathrm{CCl_3CN} + 4\mathrm{NaN_3} \longrightarrow 3\mathrm{NaCl} + \mathrm{NaCN} + \mathrm{CN_{12}}$$

（A 为 $\mathrm{CN_{12}}$，四叠氮取代氰基碳上的 3 个 Cl 与... 含 N 93.3% 验算：$12\times14/(12+12\times14) = 168/180 = 93.3\%$ ✓）

![[b564bab2a97bafdfce1203960f3b8da833e2a6e9b9ea9e4b879e78f1ef87fb7e.jpg]]

A 爆炸分解：

$$\mathrm{CN_{12}} \longrightarrow \mathrm{C} + 6\mathrm{N_2}$$
