# 氚与碳化铝

> **来源**：化学竞赛能力测试·第1章·B卷第10题（10 分）

已知放射性气体 A 与氧化铜在 $500^{\circ}\mathrm{C}$ 时反应。该反应的产物之一 B 在相同温度下与化合物 M（含质量百分含量为 75% Al）反应，生成气体 C 和固体 N，C 的分子量为 24，化合物 B 含有质量百分含量为 53% 的 Al。气体 C 的原子中某原子的放射性衰变导致其分解，得到一些带电荷的粒子 D，以及氦原子 ${}_{2}^{3}$He，D 的分子量是 21。气体 C 与水蒸气接触得醇类分子 E 以及水合质子，E 的分子量是 38。

根据这些数据回答下列问题：

**10-1** A、B、C、D、E、M、N 各代表什么化合物？

**10-2** 气体 C 与苯蒸气的混合物中，慢慢生成分子量等于 98 的化合物 F，F 代表什么物质？

**10-3** 估算苯蒸气与化合物 C 的混合的反应反应，1 周后所生成化合物 F 的放射性。你可能需要下列数据：①气体 C 具有放射性 $4.0\times 10^8\ \mathrm{Bq}$；②C 分解生成 D，其中有 70% 的 D 粒子进一步与苯反应生成化合物 F；③放射性核素的半衰期是 12.43 年。

**10-4** 写出所有过程的化学方程式。

<details>
<summary>📖 查看答案与解析</summary>

**10-1** A: $\mathrm{T_2}$（氚，$ {}_{1}^{3}\mathrm{H}$）；B: $\mathrm{T_2O}$；C: $\mathrm{CT_4}$；D: $\mathrm{CT_3^+}$；E: $\mathrm{CT_3OH}$；M: $\mathrm{Al_4C_3}$；N: $\mathrm{Al_2O_3}$。

**10-2** F: $\mathrm{C_6H_5CT_3}$。

**10-3** $C_6H_5CT_3$ 的活度是 $0.9\times 10^6\ \mathrm{Bq}$。

**10-4** 

① $\mathrm{T_2} + \mathrm{CuO} \xrightarrow{500^{\circ}\mathrm{C}} \mathrm{T_2O} + \mathrm{Cu}$

② $6\mathrm{T_2O} + \mathrm{Al_4C_3} \xrightarrow{500^{\circ}\mathrm{C}} 3\mathrm{CT_4} + 2\mathrm{Al_2O_3}$

③ $\mathrm{T} \to {}_{2}^{3}\mathrm{He} + \beta$

④ $\mathrm{CT_4} \to \mathrm{CT_3^+} + {}_{2}^{3}\mathrm{He} + \beta$

⑤ $\mathrm{CT_3^+} + 2\mathrm{H_2O} \to \mathrm{CT_3OH} + \mathrm{H_3O^+}$

⑥ $\mathrm{CT_3^+} + \mathrm{C_6H_6} \to \mathrm{C_6H_5CT_3} + \mathrm{H^+}$

**活度计算链**（数据：$T_{1/2}=12.43$ 年，$\lambda = 1.79\times 10^{-9}\ \mathrm{s^{-1}}$）：

$$A' \longrightarrow N(\mathrm{CT_3^+})/t \longrightarrow N(\mathrm{CT_3^+}) \longrightarrow A'' \longrightarrow A'''$$

$$4\times 10^8\ \mathrm{Bq}\quad 4\times 10^8\ \mathrm{s^{-1}}\quad 2.4\times 10^{14}\quad 1.3\times 10^6\ \mathrm{Bq}\quad 0.9\times 10^6\ \mathrm{Bq}$$

1 周内 $\mathrm{CT_3^+}$ 形成数 $ = 4\times 10^8\times 604800 = 2.42\times 10^{14}$（每 $\mathrm{CT_4}$ 中 4 个 T，每个 T 衰变产生一个 $\mathrm{CT_3^+}$），$\mathrm{CT_3^+}$ 活度 $A'' = 3\lambda N(\mathrm{CT_3^+}) = 3\times 1.79\times 10^{-9}\times 2.42\times 10^{14} = 1.30\times 10^6\ \mathrm{Bq}$；70% 与苯反应 → $A''' = 0.7\times 1.30\times 10^6 = 0.91\times 10^6 \approx 0.9\times 10^6\ \mathrm{Bq}$ ✓。

</details>
