# 联吡啶氮氧化物配体 L 的配合物

> **来源**：化学竞赛能力测试·第4章·A卷第4题（10 分）

配体 L 能够与许多过渡金属生成配合物。L 是将 2,2-联吡啶、冰醋酸和过氧化氢的混合物在 70—80°C 加热 3 小时合成的。它以细小的针状晶体析出，分子量为 188。

![[e998c09a3f82826195af0b2834662041073294cba48489764c28224a7f544468.jpg]]

![[a544525200ed4d7f2cb73c4b6fb5cb099ce6b93ba75620e98ab0f55e49e3b25f.jpg]]

![[42220aa35f408d03aa73bcec5dec0e1238a02ad773ac2e67c75d093f9007e3ab.jpg]]

配体 L 与 Fe 和 Cr 的配合物的分子式为 FeLₘ(ClO₄)ₙ·3H₂O(A) 和 CrLₓClᵧ(ClO₄)z·H₂O(B)。其元素分析结果如下表所示：

| 化合物 | 元素分析 (wt.%) |
|---|---|
| A | Fe 5.740; C 37.030; H 3.090; Cl 10.940; N 8.640 |
| B | Cr 8.440; C 38.930; H 2.920; Cl 17.250; N 9.080 |

**4-1** 写出 L 的分子式。如果 L 是双齿螯合配体，请画出 L 的结构。

**4-2** 配体 L 有无电荷（净电荷）？画出一个 L 分子与一个金属离子配位的结构。

**4-3** 根据上表的数据确定 A 的经验式。确定 FeLₘ(ClO₄)ₙ·3H₂O 中的 m 和 n 的数值，用惯用 IUPAC 符号写出 A 的完整的分子式。

**4-4** Fe 在 A 中的氧化数为多少？配合物中的 Fe 离子有多少个 d 电子？

**4-5** 化合物 B 是 1:1 型电解质。试确定 B 的经验式和 CrLₓClᵧ(ClO₄)z·H₂O 中的 x、y、z 的数值。

<details>
<summary>📖 查看答案与解析</summary>

**4-1** L 的分子式可以根据吡啶的氧化反应类比而成。吡啶氧化后得 C₅H₅NO，故 2,2-联吡啶氧化后得到的 L 的分子式为 C₁₀H₈N₂O₂（双 N-氧化物），摩尔质量为 12×10+8+2×14+2×16 = 188 g/mol ✓。

![[4df5b06c7ef2dcf101a676827c2300d2de30fc06de61765935287e18e361e9d3.jpg]]

![[46ad8fdf799a6a26ea6d77130bd013ebac10614d9a87ff55f98a0b3cb07c38e5.jpg]]

![[92c35b3afc6070f8b5606a68a0a633a768e4e75ae118f8218435033735be283d.jpg]]

![[7cd77886245b5c00c462cbc7649394e76a8cd6d8e1b37bb42e1a1048bfaf56fa.jpg]]

（两个吡啶环的 N 各自连 O，形成 N→O 配位基团。）

**4-2** 由于氮原子和氧原子之间是配位键（N→O），N 和 O 原子均为 8 电子构型，因此配体 L 无电荷（净电荷为零）。它与金属离子的键合方式（双齿、两个 N→O 的 O 配位）：

![[9bfce883ffdd4a2db7dbb133ad7f4001fb07560ca01fc468f0d07192344dd02c.jpg]]

**4-3** A 中 Fe:C:H:Cl:N:O（O 由差减 = 100−5.74−37.03−3.09−10.94−8.64 = 34.56）：

$$\frac{5.740}{55.8}:\frac{37.030}{12}:\frac{3.090}{1}:\frac{10.940}{35.45}:\frac{8.640}{14}:\frac{34.560}{16} = 1:30:30:3:6:21$$

故 A 的经验式为 FeC₃₀H₃₀Cl₃N₆O₂₁。与 FeLₘ(ClO₄)ₙ·3H₂O 及 L=C₁₀H₈N₂O₂ 比较得 m=3、n=3。A 的完整分子式：[FeL₃](ClO₄)₃·3H₂O。

**4-4** Fe 在 A 中的氧化数为 +3（3 个 ClO₄⁻ 平衡 3+ 电荷），Fe³⁺ 的 d 电子数为 5，即 3d⁵。

**4-5** B 中 Cr:C:H:Cl:N:O（O 差减 = 100−8.44−38.93−2.92−17.25−9.08 = 23.38）：

$$\frac{8.440}{52}:\frac{38.930}{12}:\frac{2.920}{1}:\frac{17.250}{35.45}:\frac{9.080}{14}:\frac{23.380}{16} = 1:20:18:3:4:9$$

B 的经验式 CrC₂₀H₁₈N₄Cl₃O₉。因 L=C₁₀H₈N₂O₂，故 x=2。B 是 1:1 电解质且 Cr³⁺ 六配位：[CrL₂Cl₂]ClO₄ → z=1（外界 1 个 ClO₄⁻）、y=2（内界 2 个 Cl⁻）。B = [CrL₂Cl₂]ClO₄·H₂O。

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| N-氧化物配体 | 联吡啶 → 双 N→O（中性双齿）|
| 元素分析 | 摩尔比 → 经验式 |
| 经验式配合 | m/n 试配 |
| 1:1 电解质 | [CrL₂Cl₂]ClO₄ |
| d 电子数 | Fe³⁺ 3d⁵ |
