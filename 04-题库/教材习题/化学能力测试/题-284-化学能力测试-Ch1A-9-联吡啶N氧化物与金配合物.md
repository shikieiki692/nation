# 联吡啶 N-氧化物与金配合物

> **来源**：化学竞赛能力测试·第1章 化学反应方程式与核化学反应方程式·A卷第9题（10 分）

## 题目

![[5611a789ee665723bfab5608b564912da64d5e4f239e3adf2d7d096f42e44d44.jpg]]

现已发现许多含金的化合物可以治疗风湿症等疾病，引起科学家的广泛兴趣。在吡啶（$\ce{C6H5N}$）的衍生物 2,2-联吡啶 $\ce{C6H5N}$（代号 A）中加入冰醋酸与 30% $\mathrm{H_2O_2}$ 的混合溶液，

![[d0354be3a92161a1b4db7d17352d0a354f86ce8250e4b4e18faf605219a1477b.jpg]]

反应完成后加入数倍体积的丙酮，析出白色针状晶体 B（化学式 $\mathrm{C_{10}H_8N_2O_2}$）。B 的红外光谱显示它有一种 A 没有的化学键。B 分成两份，一份与 $\mathrm{HAuCl_4}$ 在温热的甲醇中反应得到深黄色沉淀 C。另一份在热水中与 $\mathrm{NaAuCl_4}$ 反应，得到亮黄色粉末 D。用银量法测得 C 不含游离氯而 D 含游离氯 7.18%。C 的紫外光谱在 211 nm 处有吸收峰，与 B 的 213 nm 特征吸收峰相近，而 D 则没有这一吸收。C 和 D 中金的配位数都是 4。

9-1 画出 B、C、D 的结构式。

9-2 写出生成 B、C 和 D 的化学反应方程式，并指出 C、D 分子中 Au 原子的杂化形态。

9-3 制备 B 的过程中加入丙酮起什么作用？

9-4 给出用游离氯测定值得出 D 的化学式的推理和计算的过程。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

A（$\ce{C6H5N}$）的化学式为 $\mathrm{C_{10}H_8N_2}$。B 的化学式为 $\mathrm{C_{10}H_8N_2O_2}$。B 与 A 相比多了两个 O 原子，且只多了一种化学键，由此知 B 的结构为 2,2'-联吡啶二 N-氧化物（每个 N 与 O 形成 1 个 N→O 配位键）：

![[87adbd27c88cfa181f3f98890ca9e7809045d48fe5a83e1c6eb315eaaa560e30.jpg]]

![[c40ff1c6a4fdc8dce084d632051bd3f70623e590ff0941088d3429f01db5c668.jpg]]

因为其他结构（如 N-O 直接与吡啶环成环氧化等）与 A 相比均多了两种化学键，不合题意。在 B 的结构中 N—O 之间形成的是一种配位键，电子对由 N 提供。

**9-1** B 的结构：

![[87adbd27c88cfa181f3f98890ca9e7809045d48fe5a83e1c6eb315eaaa560e30.jpg]]

C 的确定要联系到 D：C 和 D 分别是 B 与 HAuCl₄ 和 NaAuCl₄ 反应得到的产物，这两种配合物中 Au 的配位数都是 4。C 不含游离氯而 D 含有游离氯 7.18%，表明 C 中的氯全部在配合物内界（配离子为 [AuCl₄]⁻），外界无氯；D 配合物的外界有氯。

C 的紫外光谱 211 nm 吸收峰与 B 的 213 nm 相近 → C 中含有与 B 类似的部分。C 中含 B 的部分应带正电荷——只能通过 B 结合 HAuCl₄ 解离出的 H⁺ 实现：

![[74096873ba629736da9b456fdddf802aa4fef15af71495ed538710548bbabfe7.jpg]]

∴ C 结构为 [AuCl₄]⁻ 与 [B·H]⁺（质子化联吡啶二 N-氧化物）结合的离子化合物：

![[7259233387d0cbf001f61044e3984bea25b56bda36b8efcb5575f2e9fad510d9.jpg]]

D 的结构：B 是双齿中性配体（两个 N→O 的 O 各提供孤对电子配位），若 D 中含一个 B 则配离子为 [Au(B)Cl₂]⁺ 型；D 中 B 与 Au 配位，Au 配位数 4（2 个 N→O 氧配位 + 2 个 Cl）：

![[82d09043c67b4719eaaeae40e8b62c6a6f5a3cc16afae3240d5790f8fc62ccd5.jpg]]

由游离氯含量确定 D 的具体化学式（见 9-4）。

**9-2** 反应方程式：

B 的生成（A 被 H₂O₂ 氧化为 N-氧化物）：

$\mathrm{C_{10}H_8N_2 + 2H_2O_2 \xrightarrow{CH_3COOH} C_{10}H_8N_2O_2 + 2H_2O}$

C 的生成：$\mathrm{C_{10}H_8N_2O_2 + HAuCl_4 \longrightarrow [BH]^+[AuCl_4]^-}$

（B 的 N→O 氧接受 H⁺ 成 [B·H]⁺，AuCl₄⁻ 为外界无游离氯）

D 的生成：$\mathrm{C_{10}H_8N_2O_2 + NaAuCl_4 \longrightarrow [Au(B)Cl_2]Cl + NaCl}$

（B 作双齿配体取代 2 个 Cl，Au 配位数 4 = 2 O + 2 Cl；外界保留 1 个 Cl⁻）

C、D 分子中 Au 原子为 **dsp² 杂化**（配位数 4、平面正方形）。

**9-3** 丙酮的作用是降低 B 在水中的溶解度（加入数倍体积丙酮使产物 B 从水溶液中析出为针状晶体）。

**9-4** D 的相对分子质量 = 491.5。设 n 为 D 中游离氯离子数，x 为游离氯质量分数，则 $35.5n / 491.5 = x$：

尝试法：n = 1 时，x = 35.5/491.5 = 7.22%，与实验值 7.18% 相近，表明 D 的外界有 1 个游离氯离子（n = 1）。

∴ D 的化学式：$\mathrm{[Au(C_{10}H_8N_2O_2)Cl_2]Cl}$（即外界 1 Cl⁻ + 配离子 [Au(B)Cl₂]⁺）。

（若含两个 B 则 M 更大、游离氯含量不符——D 只含 1 个 B）

</details>
