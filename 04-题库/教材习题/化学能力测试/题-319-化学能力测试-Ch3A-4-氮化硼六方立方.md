# 氮化硼（六方/立方）晶胞与密度

> **来源**：化学竞赛能力测试·第3章·A卷第4题（10 分）

最简单的二元硼氮化合物可以通过下列反应合成：

$$\mathrm{B_2O_3(l)} + 2\mathrm{NH_3(g)} \xrightarrow{1200^{\circ}\mathrm{C}} 2\mathrm{BN(s)} + 3\mathrm{H_2O(g)}$$

反应产生的氮化硼的结构与石墨结构相似，但上下层平行，B、N 原子相互交替（见图）。层内 B—N 核间距为 145 pm，面间距为 333 pm。请回答下列问题：

**4-1** 试画出层状六方氮化硼的晶胞。

**4-2** 写出晶胞中各原子的原子坐标。

**4-3** 试计算层状六方氮化硼晶体的密度。

![[4e3f65ab4469a4e76a19d57cdbf54149375eccc90f6d3a8111988e5fa57a0b6b.jpg]]

**4-4** 在高压（60 kbar）、高温（2000°C）下层状六方氮化硼晶体可以转化成立方氮化硼。它与金刚石有类似结构。若立方氮化硼晶胞的边长为 361.5 pm，试计算立方氮化硼晶体中 B—N 键的键长。

**4-5** 氮化硼能与单质氟气发生反应，其中的一种产物具有平面三角形结构，另一种产物是稳定的单质。试写出化学反应方程式。

**4-6** 氮化硼也能与 HF 化合，生成物中阴阳离子均为正四面体结构。该反应能定量测定 BN。试写出该化学反应方程式。

<details>
<summary>📖 查看答案与解析</summary>

本题的突破口是画出层状六方 BN 的晶胞。六方 BN 的每一面最小重复单元为菱形（虚线），B/N 交替，晶胞取六方（含 2 个 BN）或斜方（1 个 BN）单元。计算晶体密度时抓公式 $N_A = ZM/(VD)$。

![[3aaa2eb91995a2017f9c2fbe7d213306dd8514beac2ecc4c3577c0dca2c80db4.jpg]]

![[f7e4f968f64a666f0123cb8f1f9b2e27e8b7dc85ef35053c2d35c83abe70f2cd.jpg]]

**4-1/4-2** 六方晶胞中 B、N 分数坐标：

- B 原子：(0,0,0)、(1/3,2/3,1/2) 或 (2/3,1/3,1/2)
- N 原子：(0,0,1/2)、(1/3,2/3,0) 或 (2/3,1/3,0)

（每层平面内 B—N 键长 145 pm、层间距 333 pm；晶胞含 2 B + 2 N。）

**4-3** 密度：

$$D = \frac{2\times(10.81+14.01)}{6.022\times 10^{23}\times(\sqrt{3}\times145)^2\times\frac{\sqrt{3}}{2}\times 2\times 333\times 10^{-30}\ \mathrm{cm^3}} = 2.26\ (\text{或 }2.27)\ \mathrm{g\cdot cm^{-3}}$$

**4-4** 立方 BN（金刚石型，B/N 各占一套 fcc 并交错）：

$$d_{\mathrm{B-N}} = \frac{\sqrt{3}}{4}a = \frac{\sqrt{3}}{4}\times 361.5 = 156.5\ \mathrm{pm}$$

**4-5** 平面三角形的分子只有 $\mathrm{BF_3}$，最稳定的单质只有 $\mathrm{N_2}$（$\mathrm{N\equiv N}$ 键能约 946 kJ/mol）：

$$2\mathrm{BN} + 3\mathrm{F_2} \longrightarrow 2\mathrm{BF_3} + \mathrm{N_2}$$

**4-6** 阴阳离子均为正四面体结构，只有 $\mathrm{NH_4^+}$ 和 $\mathrm{BF_4^-}$ 满足：

$$\mathrm{BN} + 4\mathrm{HF} \longrightarrow \mathrm{NH_4BF_4}$$
