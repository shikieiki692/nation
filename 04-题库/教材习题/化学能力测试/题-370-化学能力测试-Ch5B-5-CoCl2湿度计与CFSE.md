# CoCl₂ 湿度计与 CFSE/HSAB

> **来源**：化学竞赛能力测试·第5章·B卷第5题（10 分）

Co(Ⅱ)盐用于制备隐显墨水（淡粉红色，蜡烛火焰加热变蓝色）；硅胶干燥指示（蓝色→粉红色即吸收水分）；CoCl₂·6H₂O（粉红）与 CoCl₂·4H₂O（蓝）相互转换可作湿度计。

**5-1** 利用热力学数据（CoCl₂·6H₂O/CoCl₂·4H₂O/H₂O(l)/H₂O(g) 的 ΔfH^θₘ、S^θₘ），确定湿度计对空气湿度 (%) 响应的临界值。

**5-2** 配合物 [Cr(H₂O)₆]³⁺ vs [Cr(H₂O)₄]³⁺、[Co(H₂O)₆]²⁺ vs [Co(H₂O)₄]²⁺ 的 d 轨道能级与电子排布，计算 CFSE。

**5-3** 反应 [Co(H₂O)₆]²⁺ + 4X⁻ ⇌ [CoX₄]²⁻ + 6H₂O，X=Cl⁻/Br⁻/I⁻/SCN⁻：
(1) 预测 ΔrH^θ 和 ΔrS^θ 符号。
(2) 温度对平衡的影响。
(3) 同样摩尔浓度下 KCN vs KSCN 谁更右移？HSAB 解释。

**5-4** [CoX₂L₄] ⇌ [CoX₂L₂] + 2L：
(1) L=py 时，X=Cl⁻ vs I⁻ 谁更右移？HSAB 解释。
(2) L=PH₃ 时呢？
(3) [CoX₂L₂] X=Cl, L=py 紫色对应八面体，画结构片段。

**5-5** 0℃冰浴 CoCl₂ + NaOH → 蓝色沉淀；25℃ 放置变粉红色；加过量碱沉淀溶解为蓝色溶液。写方程式。

**5-1** 反应：

$$\mathrm{CoCl_2\cdot 6H_2O(s) = CoCl_2\cdot 4H_2O(s) + 2H_2O(g)}$$

$$\Delta_\mathrm{r}H^\theta = 2\times(-241.8) - 1538.6 - (-2113) = 90.8\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta_\mathrm{r}S^\theta = 2\times 188.7 + 211.4 - 346 = 242.8\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

$$\Delta_\mathrm{r}G^\theta(298) = 90.8 - 298\times 242.8\times 10^{-3} = 18.45\ \mathrm{kJ\cdot mol^{-1}}$$

$$-RT\ln K_\mathrm{p}^\theta = \Delta_\mathrm{r}G^\theta,\quad K_\mathrm{p}^\theta = p(\mathrm{H_2O})^2$$

$$\lg p(\mathrm{H_2O}) = -\Delta_\mathrm{r}G^\theta/(2\times 2.303\times 298\times R) = -18450/(2.303\times 2\times 298\times 8.314) = -1.62$$

$$p(\mathrm{H_2O}) = 0.024\ \mathrm{atm}$$

水蒸发 25℃ 饱和蒸汽压：$\Delta_\mathrm{r}H^\theta = 44.0\ \mathrm{kJ/mol}$，$\Delta_\mathrm{r}S^\theta = 118.6\ \mathrm{J/(K\cdot mol)}$，$p^\theta_{\mathrm{H_2O}} = 0.030\ \mathrm{atm}$

相对湿度临界值 = 0.024/0.030 = **0.80 = 80%**

**5-2** 八面体场 d 轨道分裂 $e_g$（高）— t₂g（低），Δ₀；四面体场 t₂（高）— e（低），Δt≈4/9 Δ₀。

![[26aa8b138ed5897cca76cd90e37aff2f1efbd6dfad2c210fc8b37e6ce1bb9c3c.jpg]]

(1) [Cr(H₂O)₆]³⁺ d³ 高高自旋：t₂g³，CFSE=−3×4Dq=−1.2Δ₀；四面体 [Cr(H₂O)₄]³⁺ t₂³，CFSE=−3×4Dq_t=−12Dq_t=−16/45Δ₀≈−0.36Δ₀

(2) [Co(H₂O)₆]²⁺ d⁷ 高高自旋：t₂g⁵$e_g$²，CFSE=−(5×4−2×6)Dq=−8Dq=−0.8Δ₀；四面体 d⁷：e⁴t₂³，CFSE=−(6×4−3×6)Dq_t=−24Dq_t=−0.53Δ₀

Co²⁺（接近软酸/交界酸）四面体 CFSE 差值（八面体减四面体）相对较小，且 HSAB 中 Co²⁺ 与大可极化配体（Cl⁻/Br⁻/I⁻）形成共价键稳定四面体。

**5-3**

(1) ΔrH^θ>0、ΔrS^θ>0（物种数增多 → ΔrS^θ>0；HSAB 中弱键断裂 + 较强共价键形成）。

(2) 加热平衡右移（ΔrH^θ>0，升温有利吸热方向）→ 粉红变深蓝。

(3) Co²⁺ 交界酸，SCN⁻ 是软碱；KSCN 提供 SCN⁻ 使平衡右移更多（HSAB「软亲软」）。

**5-4**

(1) L=py：X=I⁻ 更使平衡右移。py 硬碱，Co²⁺ 交界酸，I⁻ 软碱 → Co²⁺ 倾向结合软 I⁻ 而非硬 py，使 [CoX₂L₄] → [CoI₂(py)₂] + 2py 右移多。

(2) L=PH₃ 软碱：Co²⁺ 同样以软 PH₃ 稳定四面体；X=I⁻/Cl⁻ 差异变小，可能通过 Cl 桥形成聚合结构。

(3) [CoCl₂(py)₂] 紫色对应八面体配位，py 双齿桥联成聚合物 [Co(μ-Cl)₂(py)₂]ₙ 或 [Co(py)₂Cl₂] 反式八面体结构（py 在轴向，Cl 在赤道）：

![[aa9a8e1a0e56d241df2927f792ad633699f81d7783152cb6e31e9365d01e2709.jpg]]

**5-5** Co²⁺（冰浴）：CoCl₂ + 2NaOH → [Co(H₂O)₂(OH)₂]（蓝色四面体 CN=4）↓

25℃ 转化为 [Co(H₂O)₄(OH)₂]（粉红八面体 CN=6）。

加过量碱：Na₂[Co(OH)₄]（蓝色四面体配位 [Co(OH)₄]²⁻）溶液。
