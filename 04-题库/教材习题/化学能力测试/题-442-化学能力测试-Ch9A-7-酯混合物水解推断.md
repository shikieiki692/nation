# 酯混合物水解推断

> **来源**：化学竞赛能力测试·第9章·A卷第7题（10 分）

## 题目

两种一元羧酸酯的混合物重 0.74 g，这种混合物完全进行碱性水解需要 7.0 g 8% 的 KOH（aq）；与 80% 硫酸一起加热，最初这种酯的混合物有气体放出，使之冷却，收集并称重；而后，该气体缓慢通入过量的溴的水溶液，气体的重量减少三分之一，而气体的密度几乎保持不变（假定所有反应过程都是定量进行）。

7-1. 计算混合酯的表观分子量。
7-2. 确定冷却的气体混合物的组成，计算其质量。
7-3. 确定原始酯混合物的组成，计算混合物中两种酯的含量。
7-4. 写出一种酯与氧化银（I）的氨溶液的化学方程式。

## 参考答案

<details><summary>📖 查看答案与解析</summary>

从酯的水解方程式 RCOOR′ + KOH → RCOOK + R′OH 可知，酯的总量等于氢氧化钾的量：

n(酯) = n(KOH) = 7.0 × 0.08 / 56 = 0.01 mol

**7-1** 酯混合物的平均摩尔质量：M_av = 0.74 / 0.01 = **74 g·mol⁻¹**。

在硫酸存在下甲酸受热分解成 CO（M = 28）；除 CO 外，气体混合物中还含有由酯的醇部分消去产生的烯烃。经溴处理后烯烃定量转成二溴化物而从气体中除去。因通过溴溶液后气体密度不变，第二种气体须与 CO 具有相同摩尔质量（28 g·mol⁻¹），故为**乙烯**——其中一种酯为乙醇的衍生物。

设混合物含甲酸甲酯 x mol（HCOOCH₃ → CO + CH₃OH）与某乙酯 RCOOC₂H₅ y mol（RCOOC₂H₅ → RCOOH + C₂H₄）。气体混合物含 x mol CO 与 y mol C₂H₄，CO 重量为 C₂H₄ 的 2 倍 ⇒ x = 2y；x + y = 0.01，故 x = 0.02/3，y = 0.01/3。

**7-2** 气体组成：**CO 与 C₂H₄**；质量 = 28x + 28y = 28 × 0.01 = **0.28 g**。

**7-3** 酯总量关系：0.02/3 × 60 + 0.01/3 × (R + 73) = 0.74，解得 **R = 29**（—C₂H₅），即丙酸乙酯。故原始混合物为：

- **甲酸甲酯 HCOOCH₃**：W = 0.02/3 × 60 / 0.74 = 4/7.4 = **54.1%**
- **丙酸乙酯 C₂H₅COOC₂H₅**：W = 0.01/3 × 102 / 0.74 = 3.4/7.4 = **45.9%**

**7-4** HCOOCH₃ + 2[Ag(NH₃)₂]OH → 2Ag↓ + CH₃OH + (NH₄)₂CO₃ + 2NH₃

</details>
