# C₃N₁₂ 光解与 g-C₃N₄

> **来源**：化学竞赛能力测试·第2章·B卷第10题（10 分）

现已合成出一种碳、氮两种元素组成的共价化合物 A，A 中氮元素质量分数为 0.8235。该分子是平面型分子，碳原子处于相同环境中，有一个三次旋转轴。20.415 g A 光解，生成 B 并放出 7.340 L 气体（标准状态），继续光解 B，生成 C，C 有两种同分异构体。C 再光解，生成 D 并放出气体。D 中含氮元素质量分数为 0.6087。D 是石墨型结构 E 的单体。

**10-1** 试画出 A 的结构式，标出结构式中非零 $Q_F$。

**10-2** 试画出 B 的 Lewis 结构式。

**10-3** 试画出 C 的两种异构体的共振结构式，标出式中非零 $Q_F$。

**10-4** 写出生成 D 的反应方程式，并画出 D 的结构式，指出结构式中原子的杂化类型（端基原子除外）以及化学键型。

**10-5** 试写出一种合成 E 方法的化学反应方程式，并画出 E 的一种结构式。

**10-1** A 由碳氮两种元素组成，由质量分数可计算出 $n(\mathrm{C}):n(\mathrm{N}) = 1:4$。因此 A 的分子式为 $(\mathrm{CN_4})_n$。因 N 原子较多，猜测可能存在叠氮 $\mathrm{N_3}$ 基团。最简式中还存在 CN。又因为 A 为平面分子且存在 C₃ 轴（旋转 120° 能完全重合）。因此可以考虑 n=3 的情况，$\mathrm{C_3N_{12}}$ 为类似于苯环的平面六元环（三嗪环）在间位有三个叠氮基团 $\mathrm{N_3}$，符合题意。因此 A 的结构式为三叠氮基三嗪（C₃N₃(N₃)₃）：

![[b8afb35a32c1aec7cb7e69fac2c1da8de11f3877c533b83d2b9930c1e97a758a.jpg]]

（三嗪环 C₃N₃ 上每个 C 各连一个 N₃ 叠氮基；Q_F（形式电荷）非零处在叠氮基端基 N。）

**10-2** 由于存在叠氮基团 $\mathrm{N_3}$，受热时能够分解产生 $\mathrm{N_2}$。A 光解放出 N₂ 后生成 B（三嗪环保留 + C=N? 骨架），B 的 Lewis 结构式为：

![[175d57f81a32617f6091f2b4a98723053e89772c6d6bf2526d431647abfbe240.jpg]]

**10-3** 继续光解 B，实际上是破坏了环的三聚，即三聚解离变成 $\mathrm{CN_2}$。C 有两种同分异构体（异氰/腈基氮烯等）。根据路易斯电子理论：

$$N \equiv C - \dot{N} \longleftrightarrow \dot{N} - C \equiv N:$$

根据形式电荷 $Q_F$ 的计算方法，可以写为：

$$\overset{\ominus}{:}\mathrm{C} \equiv \overset{\oplus}{\mathrm{N}} - \ddot{\mathrm{N}} \longleftrightarrow \overset{\ominus}{\ddot{\mathrm{C}}} - \overset{\oplus}{\mathrm{N}} \equiv \mathrm{N}: \longleftrightarrow :\mathrm{C} = \overset{\oplus}{\mathrm{N}} = \dot{\mathrm{N}}^{\ominus}$$

**10-4** C 为 $\mathrm{CN_2}$，继续受热分解，产生的气体只能是 $\mathrm{N_2}$，再结合 D 中含氮元素质量分数为 0.6087，可知 D 中含有碳氮两种元素，根据质量分数计算得 D 为 $\mathrm{C_3N_4}$：

$$3\mathrm{CN_2} = \mathrm{C_3N_4} + \mathrm{N_2}\quad\text{或}\quad 3[\mathrm{NCN}] = \mathrm{C_3N_4} + \mathrm{N_2}$$

![[3f2fd7d908423061ed98f1a587741fd284f96f8c7c1bffcb070ec371d72f9dbf.jpg]]

根据路易斯电子理论，D 的结构式为 NCN—NCN 型链（注意大致键角）。所有 C 原子为 sp 杂化；2 个端基 N 原子为 sp 杂化（或孤对），中间 2 个 N 原子 sp² 杂化。化学键有原子之间的 6 个 σ 键、端基 N 原子与连接 C 原子之间的 π 键和 2 个四中心四电子大 π 键。

**10-5** D 是石墨型结构 E 的单体。合成 E 的方法（热缩聚）：

$$3\mathrm{CN_2} \longrightarrow \mathrm{g}\text{-}\mathrm{C_3N_4}\quad(\text{或含 NH 前体热解})$$

（例：三聚氰胺/双氰胺高温缩聚 → g-C₃N₄ + NH₃；或 2NC—NCO → CO₂ + C₃N₄ 等。）
