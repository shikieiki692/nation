# I₂ 解离平衡与键能量子产率

> **来源**：化学竞赛能力测试·第5章·B卷第8题（10 分）

碘是生命中必不可少的微量元素，是生物通常所需的最重的元素。高温下 I₂(g) 和 I(g) 之间达到平衡。

| T/K | 1073 | 1173 |
|---|---|---|
| p(I₂) 初始 (atm) | 0.0631 | 0.0684 |
| p_total (atm) | 0.0750 | 0.0918 |

**8-1** 计算 1100 K 下的 ΔH^θ、ΔG^θ、ΔS^θ（假设 ΔH^θ、ΔS^θ 不随温度变）。

**8-2** 当 Kₚ = 总压一半时，计算平衡混合物中 I(g) 的摩尔分数。

**8-3** 假设 I₂(g) 和 I(g) 均为理想气体，计算 298 K 下 I₂ 的键能。

**8-4** 计算 298 K 下解离 I₂(g) 必须使用的辐射波长。

**8-5** λ=825.8 nm 激光 20.0 J/s 照射 10.0 s 产生 1.0×10⁻³ mol I(g)。计算量子产率。

<details>
<summary>📖 查看答案与解析</summary>

**8-1**

$$\mathrm{I_2(g) \rightleftharpoons 2I(g)},\quad p(\mathrm{I_2})_\mathrm{eq} = p(\mathrm{I_2})_0 - x,\quad p_\mathrm{total} = p(\mathrm{I_2})_0 + x$$

1073 K：x = 0.0750 − 0.0631 = 0.0119 atm；p(I) = 0.0238；p(I₂) = 0.0512

$$K_1 = 0.0238^2/0.0512 = 0.0111$$

1173 K：x = 0.0918 − 0.0684 = 0.0234 atm；p(I) = 0.0468；p(I₂) = 0.0450

$$K_2 = 0.0468^2/0.0450 = 0.0487$$

Van't Hoff：

$$\ln(K_2/K_1) = 1.4817 = \frac{\Delta H^\theta}{R}\left(\frac{1}{1073}-\frac{1}{1173}\right) = \frac{\Delta H^\theta}{8.314}\times 7.945\times 10^{-5}$$

$$\Delta H^\theta = 1.4817\times 8.314/(7.945\times 10^{-5}) = 155\ \mathrm{kJ\cdot mol^{-1}}$$

1100 K Kₚ：

$$\ln(K_{1100}/0.0111) = \frac{155052}{8.314}\left(\frac{1}{1073}-\frac{1}{1100}\right)$$

$$K_{1100} = 0.0169 \approx 0.017$$

$$\Delta G^\theta(1100) = -RT\ln K = -8.314\times 1100\times \ln 0.017 = +37.25\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta S^\theta(1100) = (\Delta H^\theta - \Delta G^\theta)/T = (155052-37249)/1100 = 107.1\ \mathrm{J\cdot K^{-1}\cdot mol^{-1}}$$

**8-2** Kₚ = p_total/2：

$$\frac{4x^2}{p(\mathrm{I_2})_0 - x} = \frac{1}{2}(p(\mathrm{I_2})_0 + x)$$

整理得 $p_\mathrm{total} = 4x$，$p(\mathrm{I_2})_\mathrm{eq} = 2x$，$x(\mathrm{I}) = 2x/4x = 0.50$，$x(\mathrm{I_2}) = 0.50$

**8-3** Cp,I(g)=5R/2；Cp,I₂(g)=7R/2；ΔCp = −R：

$$\Delta H^\theta(298) = \Delta H^\theta(1100) + \Delta C_p\Delta T = 155052 + (-R)\times (298-1100) = 155052 + 802\times 8.314 = 145050\ \mathrm{J\cdot mol^{-1}}$$

$$E(\mathrm{I-I}) = 145\ \mathrm{kJ\cdot mol^{-1}}$$

**8-4**

$$\lambda = N_A h c/E = (6.022\times 10^{23}\times 6.63\times 10^{-34}\times 3\times 10^8)/145050 = 8.258\times 10^{-7}\ \mathrm{m} = 825.8\ \mathrm{nm}$$

**8-5**

$$E_\text{光子} = hc/\lambda = (6.63\times 10^{-34}\times 3\times 10^8)/(825.8\times 10^{-9}) = 2.409\times 10^{-19}\ \mathrm{J}$$

$$N_\text{光子} = Pt/E = (20.0\times 10.0)/2.409\times 10^{-19} = 8.30\times 10^{20}$$

$$n_\text{光子} = N/N_A = 8.30\times 10^{20}/6.022\times 10^{23} = 1.38\times 10^{-3}\ \mathrm{mol}$$

$$n(\mathrm{I_2}) = \tfrac{1}{2}n(\mathrm{I}) = 0.5\times 10^{-3}\ \mathrm{mol}$$

$$\text{量子产率} = n(\mathrm{I_2})/n_\text{光子} = 5\times 10^{-4}/1.38\times 10^{-3} = 0.36$$

</details>
