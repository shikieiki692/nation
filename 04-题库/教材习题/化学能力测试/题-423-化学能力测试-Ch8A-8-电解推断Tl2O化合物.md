# 电解推断 Tl₂O 化合物

> **来源**：化学竞赛能力测试·第8章·A卷第8题（10 分）

化合物 X 溶于水惰性电极电解，无气体放出。两电极都增重：阴极增重=阳极 1.79 倍，两电极增重总量=X 起初重量。阳极沉积 Y 定量溶于稀硫酸再电解：阳极区放氧，阴极沉积同 X 电解产物（重量减半）。

**8-1** 推测 X、Y 与两次电解阴极产物。**8-2** 写所有反应。

<details>
<summary>📖 查看答案与解析</summary>

**8-1** 阴极沉积金属；阳极生成氧化物/氢氧化物。设 X 中金属价态 a、Y 中 b：每 1/a mol 金属阴极沉积对应 1/(b−a)... 电极计量导出 (b−a)/a=2 → **b/a=3**（金属变 3 倍价）。

氧化物中金属质量分数 0.895 → 当量 E：0.895/0.105=E/8 → E=68.2？源答 E=204.6/3=68.2 → **M=204.6（Tl，+3 最高价）**；X 中 Tl 为 +1：

**X=Tl₂O、Y=Tl₂O₃、阴极产物=Tl**

**8-2**

$$\mathrm{Tl_2O + H_2O = 2TlOH}$$

$$6\mathrm{TlOH} = 4\mathrm{Tl(阴)} + \mathrm{Tl_2O_3(阳)} + 3\mathrm{H_2O}$$

$$\mathrm{Tl_2O_3 + 3H_2SO_4 = Tl_2(SO_4)_3 + 3H_2O}$$

$$2\mathrm{Tl_2(SO_4)_3 + 6H_2O} = 4\mathrm{Tl(阴)} + 6\mathrm{H_2SO_4(阳)} + 3\mathrm{O_2(阳)}$$

阴极:阳极金属比 = 4:1（第二次半量因 Tl 回收率）；Tl(III) 氧化物碱液不溶（第一次可见）、酸中强氧化性。

</details>
