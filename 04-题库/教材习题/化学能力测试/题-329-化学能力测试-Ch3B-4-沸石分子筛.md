# 沸石分子筛与方石英

> **来源**：化学竞赛能力测试·第3章·B卷第4题（10 分）

沸石分子筛是重要的石油化工催化材料。下图是一种沸石晶体结构的一部分，其中多面体的每一个顶点均代表一个 T 原子（T 可为 Si 或 Al），每一条边代表一个氧桥（即连接两个 T 原子的氧原子）。该结构可以看成是由 6 个正方形和 8 个正六边形围成的凸多面体（称为 β 笼），通过六方柱笼与相邻的四个 β 笼相连形成的三维立体结构。

![[59598755199ffb11c4f05243d9080e027afc64ba6730a33e2cbd9df2599a9c8c.jpg]]

![[9950b0b38e91a87e1592292d942481856dbe728000d6d1dcf7f505b93209fdd7.jpg]]

**4-1** (1) 若将每个 β 笼看作一个原子，六方柱笼看作原子之间的化学键，上图可以简化成什么结构？

(2) 该沸石属于十四种布拉维点阵类型中的哪一种？指出其晶胞内有几个 β 笼。

(3) 假设该沸石骨架仅含有 Si 和 O 两种元素，写出其晶胞内每种元素的原子数。

(4) 已知该沸石的晶胞参数 a = 2.34 nm，试求该沸石的晶体密度。（相对原子质量：Si 28.0、O 16.0）

**4-2** 方石英和上述假设的全硅沸石都由硅氧四面体构成。右图为方石英的晶胞示意图。

(1) 求方石英的晶体密度。

(2) 比较沸石和方石英的晶体密度来说明沸石晶体的结构特征。

**4-3** 一般沸石由负电性骨架和骨架外阳离子构成，利用骨架外阳离子的可交换性，沸石可以作为阳离子交换剂或质子酸催化剂使用。图为沸石的负电性骨架示意图：

**4-4** 以甲醇为甲基化试剂的甲苯甲基化反应是制备对二甲苯的重要方法之一，常用沸石分子筛为固体酸催化剂。该过程包含如下反应网络：

(2) 若反应起始时体系中只有 1 mol 甲醇和 1 mol 甲苯，平衡时体系内对、间、邻二甲苯的含量分别为 x、y、z mol，请写出反应 1 的平衡常数 K₁ 的表达式（以 x、y、z 表示）。

(3) 各物种在 298.15 K 时的标准生成焓和熵列于下表，根据表中的热力学数据（假设数据不随温度变化），计算 500 K 下反应 1 的平衡常数。

**4-5** 若使用有效孔径为 0.65 nm 的沸石分子筛作为上述反应的催化剂，主要产物是什么？简述理由。（苯最小和最大直径分别 0.59 nm 和 0.68 nm；甲苯 0.59 nm 和 0.78 nm。图为该沸石分子筛孔道结构示意图。）

![[5e563d8f9bb1a58a4e13d29694ba8f34ddb6b88eb6ab0b18c35f5e0cafdf1155.jpg]]

<details>
<summary>📖 查看答案与解析</summary>

**4-1** (1) 是金刚石结构（每个 β 笼通过六方柱连接 4 个相邻 β 笼，四面体构型，等价于金刚石中 C—C 键）：

![[8291edc5206df211a485e10e5653190389eeb235592eabd56f62a21c9c028353.jpg]]

(2) 该沸石所属点阵类型为立方面心（fcc）；晶胞内含 8 个 β 笼（金刚石型 fcc 含 8 个点）。

(3) 因为每个晶胞含 8 个 β 笼，每个 β 笼有 24 个 Si 原子和 48 个 O 原子：Si 192、O 384。

(4) 晶体密度：

$$\rho = \frac{m}{V} = \frac{28.0\times 192 + 16.0\times 384}{6.02\times 10^{23}\times (2.34\times 10^{-9})^3} = 1.49\times 10^{3}\ \mathrm{kg\cdot m^{-3}}$$

**4-2** (1) 此晶胞 SiO₂ 数：Si 为 $8\times\frac{1}{8} + 6\times\frac{1}{2} + 4 = 8$；O 为 8×2 = 16（每 Si 配 4 个桥 O，每 O 为 2 个 Si 共有）。晶胞质量 $m = \frac{(28.0+32.0)\times 8}{6.02\times 10^{23}\times 10^3} = 7.97\times 10^{-25}\ \mathrm{kg}$；体积 $V = (2.31\times 1.62\times 10^{-10}\times 2)^3 = 4.19\times 10^{-28}\ \mathrm{m^3}$（AB = 4AE/√3，AE = 2×Si—O 键长 0.162 nm）。

$$\rho = \frac{7.97\times 10^{-25}}{4.19\times 10^{-28}} = 1.90\times 10^{3}\ \mathrm{kg\cdot m^{-3}} = 1.90\ \mathrm{kg\cdot dm^{-3}}$$

(2) 沸石晶体的密度（1.49×10³ kg/m³）明显小于方石英（1.90×10³ kg/m³），说明沸石晶体具有多孔（空旷骨架）的结构特征。

**4-4** (1) 反应网络中有 3 个热力学上相互独立的化学反应（对/间/邻二甲苯异构化 3 个独立反应，甲基化可归并）。

(2) 反应 1（甲苯 + 甲醇 → 对二甲苯 + 水）：

$$K_1 = \frac{x(x+y+z)}{[1-(x+y+z)]^2}$$

(3) 计算（反应 1：甲苯 + 甲醇 → 对二甲苯 + 水）：

$$\Delta_r H^{\theta} = (17.95 - 241.82) - (50.00 - 201.17) = -72.70\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta_r S^{\theta} = (352.42 + 188.72) - (237.70 + 319.74) = -16.30\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$$

$$\Delta_r G^{\theta}(500\ \mathrm{K}) = -72.70\times 10^3 - 500\times(-16.30) = -64.55\ \mathrm{kJ\cdot mol^{-1}}$$

$$\ln K^{\theta} = -\Delta G^{\theta}/RT = 64.55\times 10^3/(8.314\times 500) = 15.528\quad\Rightarrow\quad K^{\theta} = 5.54\times 10^{6}$$

**4-5** 反应的主要产物是对二甲苯。因为只有对二甲苯最小直径（0.59 nm）小于沸石孔径（0.65 nm），可从沸石孔道中脱出；间、邻二甲苯的最小直径（0.68 nm）大于沸石孔径，扩散困难，将留在沸石笼中继续发生异构化反应转变为对二甲苯。随着反应进行，二甲苯异构化平衡一直向生成对二甲苯方向移动。

（估算三种二甲苯直径：对二甲苯 0.59/0.88 nm、邻二甲苯 0.68/0.68 nm、间二甲苯 0.68/0.76 nm。）

</details>

## 知识点映射

| 知识点 | 体现 |
|--------|------|
| β 笼拓扑 | 截角八面体 → 金刚石型连接（fcc、8 笼）|
| 密度计算 | 沸石 1.49×10³ vs 方石英 1.90×10³ kg/m³ |
| 电子式 | 骨架 O 桥与负电荷标记 |
| 平衡常数 | 500 K K₁ = 5.54×10⁶ |
| 择形催化 | 对二甲苯优先脱出 |
