# 氮氧化物平衡与 FNO₂

> **来源**：化学竞赛能力测试·第2章·A卷第8题（10 分）

氮氧化物是大气化学的主要研究对象之一。内燃机中的高温促使空气中的氮气与氧气发生的化合反应以及工厂排放的光化学烟雾，是大气中氮氧化物的两大来源。在平流层，氮氧化物对于维持能够吸收紫外线的臭氧浓度稳定的光化学分解臭氧的反应有推动作用。下文将描述氮氧化物的一些化学性质。

氮氧化物 A 是无色顺磁性气体，能和过量氧气反应。将反应后的混合物通入 $-120^{\circ}\mathrm{C}$ 容器中，气体凝华为无色固体 B。将 2.00 g B 放入 1.00 L 真空容器中，可生成红棕色气体。反应体系在不同温度下达到平衡时的压强如下：

| 温度/°C | 压强/atm |
|---|---|
| 25.0 | 0.653 |
| 50.0 | 0.838 |

**8-1** 写出化合物 A 和 B 的化学式。

**8-2** 写出第二步 B 生成红棕色气体的反应方程式。计算该反应在热力学标况下的焓变和熵变。假设温度和压强对反应的焓变、熵变影响可以忽略不计。

化合物 B，与氟气反应可生成一无色气体 C，C 与三氟化硼反应可生成无色固体 D。将 1.000 g D 溶于水，以酚酞作为指示剂，用 $0.5000\ \mathrm{mol\cdot L^{-1}}$ NaOH 滴定至终点，耗 NaOH 溶液 30.12 mL。

**8-3** 写出 C 和 D 的路易斯结构式，以及 D 与 NaOH 中和滴定得到的最终产物的化学式。

**8-4** 写出 A 与 $\mathrm{ClO_2}$ 反应方程式。

**8-5** D 与过量硝基苯反应主要生成有机产物 E，写出 E 的结构式。

<summary>📖 查看答案与解析</summary>

引起光化学烟雾的是 $NO_x$，氮氧化物 A 是无色顺磁性气体，因此 A 是 NO。因为 A 是双头游离基，是顺磁性物质。NO 与 $O_2$ 反应生成红棕色 $NO_2$，$NO_2$ 中 N 有成单电子，又是游离基，因此 $NO_2$ 能二聚成 $N_2O_4$。故 B 为 $N_2O_4$。

**8-1** A: NO；B: $N_2O_4$

**8-2** $N_2O_4 \rightleftharpoons 2NO_2$。平衡计算：

- $T_1=298\ \mathrm{K}$：$K_p(298\ \mathrm{K}) = 0.140$
- $T_2=323\ \mathrm{K}$：$K_p(323\ \mathrm{K}) = 0.848$

由范特霍夫方程 $\ln(K) = -\Delta H^{\theta}/RT + \Delta S^{\theta}/R$：

$$\Delta H^{\theta} = +57.7\ \mathrm{kJ\cdot mol^{-1}},\quad \Delta S^{\theta} = +177\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$$

（验算：$\ln\frac{0.848}{0.140} = 1.80 = \frac{\Delta H}{R}\cdot\frac{T_2-T_1}{T_1T_2} = \frac{\Delta H}{8.314}\times\frac{25}{298\times323}$ → $\Delta H = 57.6\ \mathrm{kJ/mol}$；再由 $\ln K_1 = -\Delta H/RT_1 + \Delta S/R$ → $\Delta S = 177\ \mathrm{J/(mol\cdot K)}$。）

**8-3** $N_2O_4$ 受热可以生成 $NO_2$，实际为游离基 $\cdot NO_2$，而 $F_2$ 受热也会产生 F·游离基。因此产生的两种游离基可以耦合成 $FNO_2$，其化学反应为：$N_2O_4 + F_2 \longrightarrow 2FNO_2$。因此 C 为 $FNO_2$。

由于 $FNO_2$ 可以是 Lewis 碱（提供 F⁻），而 $BF_3$ 是强 Lewis 酸，发生路易斯酸碱反应：

$$BF_3 + FNO_2 \longrightarrow [NO_2][BF_4]$$

因此 D 为 $[NO_2][BF_4]$。其路易斯结构式为：

$$[\ddot{O}=N^{\oplus}=\ddot{O}]\ [\ddot{F}-\underset{\ddot{F}}{\overset{\ddot{F}}{\mathrm{B}}}-\ddot{F}]^-$$

经计算 $[NO_2][BF_4]$ 与 NaOH 反应的物质的量之比为 1:2，因此化学反应为：

$$[NO_2][BF_4] + 2\mathrm{NaOH} \longrightarrow \mathrm{NaNO_3} + \mathrm{NaBF_4} + \mathrm{H_2O}$$

**8-4** NO 有成单电子，$ClO_2$ 也有成单电子，能发生耦合。因此化学反应为：

$$\mathrm{NO} + \mathrm{ClO_2} \longrightarrow \mathrm{ON-ClO_2}$$

**8-5** $[NO_2][BF_4]$ 能产生强的亲电试剂 $NO_2^+$。$NO_2^+$ 与苯发生亲电取代（硝化）：

| 知识点 | 体现 |
|--------|------|
| 化学平衡 | Kp 随 T 变化（范特霍夫）|
| 热力学量 | ΔH^θ/ΔS^θ 由 K(T) 求 |
| 分子结构 | NO 顺磁自由基、N₂O₄ 二聚 |
| 路易斯酸碱 | FNO₂+BF₃→[NO₂][BF₄] |
| 亲电取代 | NO₂⁺+C₆H₆→C₆H₅NO₂+H⁺ |
