# AgBr 溶解与定影原理

> **来源**：化学竞赛能力测试·第7章·A卷第6题（10 分）

照相废物含银可回收。溴化银（pKL=12.3）感光材料，定影时生成配离子。银配离子配位数=2：

| 配体 | pK(稳定常数) | 配体 | pK |
|---|---|---|---|
| NH₃ | −7.14 | CN⁻ | −21.0 |
| S₂O₃²⁻ | −13.6 | | |

**6-1** 写 AgBr 与各配体反应的方程式。

**6-2** 计算 AgBr 在水中与配体平衡浓度 0.1 mol/L 溶液里的溶解度。说明为什么用硫代硫酸钠作定影剂？

**6-3** 每升定影液含 240 g Na₂S₂O₃。25 L 定影液中定影剂消耗 80%，回收损失 3.5%。计算回收银量。

<details>
<summary>📖 查看答案与解析</summary>

**6-1**

$$\mathrm{AgBr + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+ + Br^-}$$

$$\mathrm{AgBr + 2S_2O_3^{2-} \rightleftharpoons [Ag(S_2O_3)_2]^{3-} + Br^-}$$

$$\mathrm{AgBr + 2CN^- \rightleftharpoons [Ag(CN)_2]^- + Br^-}$$

**6-2** 水：Ksp=[Ag⁺][Br⁻]=S² → S=√(10⁻¹²·³)=7.08×10⁻⁷ mol/L

配体 L 浓度 0.1 M：K = K稳·Ksp = [AgL₂][Br⁻]/[L]² = S²/0.1²

- NH₃：S=√(10⁷·¹⁴×10⁻¹²·³×0.01)=7.08×10⁻⁵ mol/L（溶解太少）
- S₂O₃²⁻：S=√(10¹³·⁶×10⁻¹²·³×0.01)=**2.2×10⁻⁴ mol/L**
- CN⁻：S=√(10²¹×10⁻¹²·³×0.01)=0.22 mol/L

**NH₃ 溶解不足；CN⁻ 溶解强但剧毒 → 选硫代硫酸钠作定影剂**（方程式②）。

**6-3** AgBr + 2Na₂S₂O₃ → Na₃[Ag(S₂O₃)₂] + NaBr

n(Na₂S₂O₃) = (240/158)×25×80% = 30.4 mol → n(Ag)=30.4/2×(1 全转化)= 取 x 由 K 平衡近似，x≈13.66 mol 源答：

$$m(\mathrm{Ag}) = 13.66\times 108\times(1-3.5\%) = 1423\ \mathrm g \approx 1.4\ \mathrm{kg}$$

</details>
