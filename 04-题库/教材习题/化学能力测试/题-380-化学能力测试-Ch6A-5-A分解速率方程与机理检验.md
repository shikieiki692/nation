# A(l) 分解速率方程与机理检验

> **来源**：化学竞赛能力测试·第6章·A卷第5题（10 分）

缓冲介质水溶液中，300 K 研究无机物 A 的分解：A(l) → B(g) + H₂O(l)。气态产物 B 不溶于水。

实验事实：

① 固定 A 液上部体积，不同 t 测 B 分压 p，得 ln[p∞/(p∞−p)] = k't（p∞ 为 A 完全分解时 B 的分压）。

② 改变 pH 作 lg(t₁/₂)~pH 图，斜率 −1，截距 lg(0.693/k)。

**5-1** 求实验速率方程。

**5-2** 机理：A + OH⁻ ⇌ I + H₂O（k₁/k₋₁），I → B + OH⁻（k₂）。该机理与实验事实是否相符？

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 设 v = k[A]ᵅ[H⁺]ᵝ。缓冲液中 [H⁺] 恒定 → v = k'[A]ᵅ。

事实①：ln[A]₀/[A] = ln[p∞/(p∞−p)] = k't（[A]∝p∞−p）→ **对 A 一级（α=1）**。

准一级 t₁/₂ = 0.693/k' = 0.693/(k[H⁺]ᵝ)：

$$\lg t_{1/2} = \lg(0.693/k) - \beta\lg[\mathrm{H^+}] = \lg(0.693/k) + \beta\,\mathrm{pH}$$

斜率 −1 → β = −1。

**实验速率方程：v = k[A][H⁺]⁻¹**（即对 A 一级、对 H⁺ 负一级，碱催化）。

**5-2** 机理检验（稳态近似 I）：

$$v = k_2[\mathrm I],\quad \frac{\mathrm d[\mathrm I]}{\mathrm dt} = k_1[\mathrm A][\mathrm{OH^-}] - k_{-1}[\mathrm{H_2O}][\mathrm I] - k_2[\mathrm I] = 0$$

$$[\mathrm I] = \frac{k_1[\mathrm A][\mathrm{OH^-}]}{k_2 + k_{-1}[\mathrm{H_2O}]}$$

$$v = \frac{k_1k_2[\mathrm A][\mathrm{OH^-}]}{k_2 + k_{-1}[\mathrm{H_2O}]}$$

当 k₋₁[H₂O]≫k₂：

$$v = \frac{k_1k_2}{k_{-1}}\cdot\frac{[\mathrm A][\mathrm{OH^-}]}{[\mathrm{H_2O}]}$$

水的离子积 K = [H⁺][OH⁻]/[H₂O] → [OH⁻]/[H₂O] = K/[H⁺]：

$$v = \frac{Kk_1k_2}{k_{-1}}\cdot\frac{[\mathrm A]}{[\mathrm H^+]} = k[\mathrm A][\mathrm H^+]^{-1},\quad k = \frac{Kk_1k_2}{k_{-1}}$$

与实验速率方程相符（对 A 一级、对 H⁺ 负一级），机理成立。

</details>
