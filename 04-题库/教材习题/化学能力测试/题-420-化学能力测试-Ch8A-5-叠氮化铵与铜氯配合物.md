# 叠氮化铵与铜氯配合物

> **来源**：化学竞赛能力测试·第8章·A卷第5题（10 分）

无色晶状 A（含 6.67% H）隔绝空气爆炸仅得 B、C（气态，含氮肥料原料）。A 溶于浓盐酸加入金属 D（实验室除痕量氧），D 溶解释放 B。加过量热无水乙醇得红色针状 E（Cl 47.33%），空气中变蓝粉 F（D 37.28%、Cl 41.6%）。

**5-1** 判断 A~F 并写反应。**5-2** E、F 中 D 的配位数？画结构。**5-3** 从 NH₃+HNO₃ 出发制备 A（最少试剂）。**5-4** F 水解方程式；算溶于 1 L 水得 pH=3 的 F 量（K=0.127）。**5-5** 真空中加热 F 得盐 G 和液体 H（IR 3600/1680 cm⁻¹）——G-H 体系算复盐吗？

<details>
<summary>📖 查看答案与解析</summary>

**5-1** A=**NH₄N₃**（M=60，H 4/60=6.67% ✓）。D=**Cu**（除氧常用金属）。

NH₄N₃ → 2N₂ + 2H₂（B=N₂、C=H₂）

Cu + NH₄N₃ + 5HCl + 3H₂O → **HCuCl₃·3H₂O**（E，Cl 106.5/225=47.3% ✓）+ N₂ + 2NH₄Cl

HCuCl₃·3H₂O（空气中）→ **CuCl₂·2H₂O**（F，Cu 37.28%/Cl 41.6% ✓）+ HCl↑ + H₂O

**5-2** E、F 配位数均 6；Cu²⁺ d⁹ 八面体 **Jahn-Teller 变形**（拉长八面体）。

**5-3** NH₃+HNO₃→NH₄NO₃；2Na+2NH₃→2NaNH₂+H₂；NaNH₂+N₂O→NaN₃+H₂O；2NaN₃+H₂SO₄→Na₂SO₄+2HN₃；HN₃+NH₃→NH₄N₃。

**5-4** Cu²⁺+H₂O→CuOH⁺+H⁺ K=0.127；[H⁺]=10⁻³：

K=[CuOH⁺][H⁺]/[Cu²⁺]=0.127 → [CuOH⁺]≈10⁻³、[Cu²⁺]=10⁻⁶/(0.127×...)=7.87×10⁻⁶：

$$c(\mathrm{Cu}) = 10^{-3} + 7.87\times 10^{-6}/0.127 = 1.01\times 10^{-3}\ \mathrm{mol/L}$$

$$m(\mathrm{CuCl_2\cdot 2H_2O}) = 1.01\times 10^{-3}\times 170.5 = 0.172\ \mathrm g$$

**5-5** F 真空加热：CuCl₂·2H₂O → CuCl₂ + 2H₂O 升华（G=CuCl₂ 盐、H=水）；CuCl₂-H₂O 低温可能有 CuCl₂·4H₂O 等中间水合物但非独立稳定相。

</details>
