# S₄N₄ 合成 Born-Haber 与配位化学

> **来源**：化学竞赛能力测试·第5章·B卷第7题（10 分）

把 NH₃ 气体通入 SCl₂ 溶液，产生红色爆炸性固体 S₄N₄。结构：

![[88cab453b4fb8fd906dd951af7d74c6bc2e47e71e248ea210f099afff6ecaa17.jpg]]

**7-1** 写出 NH₃ 和 SCl₂ 合成 S₄N₄ 的配平方程式。

**7-2** 建立 S₄N₄ 生成的 Born-Haber 循环并计算其生成焓。

**7-3** 用更多数据计算 NH₃ 与 SCl₂ 反应的焓变。

> E(S−S)=226、E(S−N)=273、E(S=N)=328、E(N≡N)=946 kJ·mol⁻¹；ΔvapH(S₈)=77、ΔvapH(S₄N₄)=88 kJ·mol⁻¹；ΔfH(NH₃)=−45.9、ΔfH(HCl)=−92.3、ΔfH(SCl₂)=−50.0 kJ·mol⁻¹

**7-4** S₄N₄ + 过量 AsF₅ → [S₄N₄][AsF₆]₂ + AsF₃；S₄N₄ + 过量 SnCl₂·2H₂O（甲醇） → S₄N₄H₄ + SnCl₂(MeO)₂。写方程式。

**7-5** 画出 [S₄N₄]²⁺ 和 S₄N₄H₄ 结构。

**7-6** 画出 S₄N₄ 路易斯结构式。

**7-7** NaN₃ + S₄N₄ → 唯一钠盐 A，Na 质量分数 10.41%。求 A 分子式，画阴离子结构。

<details>
<summary>📖 查看答案与解析</summary>

**7-1**

$$\mathrm{4NH_3 + 6SCl_2 \longrightarrow S_4N_4 + 12HCl + \tfrac{1}{4}S_8}$$

或 HCl 进一步与过量 NH₃ 反应：

$$\mathrm{16NH_3 + 6SCl_2 \longrightarrow S_4N_4 + 12NH_4Cl + \tfrac{1}{4}S_8}$$

**7-2** Born-Haber 循环：从单质生成 1 mol S₄N₄ 需断 4 S—S 键（来自 ½S₈）、2 N≡N 键（来自 1 N₂），形成 4 S=N 双键和 4 S−N 单键：

$$\Delta_\mathrm{f}H^\theta(\mathrm{S_4N_4}) = 4\times 226 + 2\times 946 - 4\times 328 - 4\times 273 = 392\ \mathrm{kJ\cdot mol^{-1}}$$

**7-3**

$$\Delta_\mathrm{r}H^\theta(1) = 392 + 12\times(-92.3) - 4\times(-45.9) - 6\times(-50.0) = -232\ \mathrm{kJ\cdot mol^{-1}}$$

**7-4**

$$\mathrm{S_4N_4 + 3AsF_5 \longrightarrow [S_4N_4]^{2+}(AsF_6^-)_2 + AsF_3}$$

或 $\mathrm{S_4N_4 + 4AsF_5 \longrightarrow (S_4N_4)(AsF_6)(As_3F_{14})}$

$$\mathrm{S_4N_4 + 2SnCl_2 + 4MeOH \longrightarrow S_4N_4H_4 + 2SnCl_2(MeO)_2}$$

**7-5** [S₄N₄]²⁺：10 π 电子满足 4n+2（n=2）休克尔规则，八元环平面：

![[15e9dd32335b65eab32ee2cc04c26c62605382405e066c016c6ea4ae77d3e439.jpg]]

S₄N₄H₄ = S₄(NH)₄ = S₈ 等电子体，皇冠型结构（与 S₈ 同）：

![[03337987a6b8785b6086ae85a571872d04f94f570f8c74f64cf5341beb90a145.jpg]]

**8-6** S₄N₄ 路易斯结构式：

![[a0188974911cc806795f0250c0a3d237a3575cf79a12e45c16c721d704712698.jpg]] ![[3038ed430a509f1a96bdcac66b501c62f7aa4ddc52395f2ce1e0380dd6a7bcd1.jpg]]

**8-7** M(A) = 23n/10.41% = 221n，n=1 时 M=221−23=198 = 32×4+14×5 → S₄N₅，A=Na[S₄N₅]。阴离子 [S₄N₅]⁻：π 电子 2×4+1×5+1=14=4×3+2 满足休克尔 → 九元环平面：

![[b0bd1f02187327a7c15e7709c81317121d5b364015548a8135aa675b95177de5.jpg]]

反应：$\mathrm{6NaN_3 + 8S_4N_4 \longrightarrow 6Na[S_4N_5] + S_8 + 10N_2}$
