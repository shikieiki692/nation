# 含氮化合物与铜盐

> **来源**：化学竞赛能力测试·第1章·B卷第5题（10 分）

含氮化合物广泛用于工业，如肥料和炸药。无色晶状化合物 A（含 6.67% 的氢）在隔绝空气条件下爆炸，分解仅得到 B 和 C。在通常状态下 B 和 C 是气态，是用于合成含氢肥料的最重要的试剂。晶体 A 溶于浓盐酸后，该溶液中加入金属 D（通常用于实验室中从多种气体中除去痕量氧）,

金属 D 易溶解在此溶液中并释放出气体 B。将制备的混合物加入过量的热无水乙醇，最终缓慢生成一种红色针状状沉淀 E（含 47.33% Cl）。将其在空气中放置使之转化成蓝色晶状粉末 F（含 37.28% D 和 41.6% Cl）。

**5-1** 判断 A\~F 所代表的化合物，并写出所涉及的反应。

**5-2** 在化合物 E 和 F 中，金属 D 的配位数是多少？绘出这些化合物的结构。

**5-3** 提出一种制备 A 的方法，要求从 $\mathrm{NH_3}$ 和 $\mathrm{HNO_3}$ 的浓溶液出发，并使用最少种类的参与反应的试剂。

**5-4** 写出 F 的水解方程式，计算溶于 1 L 水得到 pH=3 的溶液的 F 的量（该水解反应的平衡常数为 0.127）。

**5-5** 真空中缓慢加热 F，得到盐 G 和液体 H 的蒸气（它在 $\mathrm{CCl_4}$ 的极稀溶液中的 IR 光谱，在 $3600\ \mathrm{cm^{-1}$ 和 $1680\ \mathrm{cm^{-1}$ 处有两个强吸收带）。可以认为 G—H 体系为是复盐吗？除 F 外，该体系是否存在其他化合物？与 F 相比，它们的热稳定性如何？

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 本题的突破口是用于除去痕量的氧并生成带蓝色盐的金属 D，这一定是铜，F 的组成可由元素分析数据来确定：$37.28/63.54 : 41.60/35.45 = 1:2$，这意味着 F 是质子化的 $\mathrm{CuCl_2}$。溶剂化合物的摩尔质量是：$63.54/0.3728 = 170.4 = M(\mathrm{CuCl_2}) + 36$，对应于 $\mathrm{CuCl_2\cdot 2H_2O}$。

化合物 E 含有的氯比 F 多，可以假设它可能是水合的配位酸，下列以下式：①分子式单元中多一个 Cl，其分子量：$M = 35.45\times 3/0.4733 = M(\mathrm{CuCl_2}) + 54$，即 $E = \mathrm{HCuCl_3\cdot 3H_2O}$；或者是②多两个氯原子。由计算得组成为 $\mathrm{H_2CuCl_4\cdot 5H_2O}$。由于它的水和 HCl 含量都很高，即使它确实存在的话，也是非常不稳定的。

通过 A 的组成计算可知 A 为某酸的盐，它不含有氧。B 和 C 在常温下均为气体，化合物中所包含的阳离子明显含有氮。所以，其可能的阳离子为 $\mathrm{NH_4^+}$ 和 $\mathrm{N_2H_5^+}$，可能的阴离子只能是 $\mathrm{N_3^-}$，对铵盐摩尔量的的计算可得：$4/0.0667 = 60.60 - 4 = 56$，这与 $\mathrm{NH_4N_3}$ 相符。

$$\mathrm{NH_4N_3} \xrightarrow{\triangle} 2\mathrm{N_2} + 2\mathrm{H_2}$$

$$\mathrm{Cu} + \mathrm{NH_4N_3} + 5\mathrm{HCl} + 3\mathrm{H_2O} \longrightarrow \mathrm{HCuCl_3\cdot 3H_2O} + \mathrm{N_2} + 2\mathrm{NH_4Cl}$$

电离反应：$\mathrm{N_3^-} + 4\mathrm{H^+} + 2\mathrm{e} \longrightarrow \mathrm{NH_4^+} + \mathrm{N_2}\uparrow$；$\mathrm{Cu} - 2\mathrm{e} \longrightarrow \mathrm{Cu^{2+}}$。

$$\mathrm{HCuCl_3\cdot 3H_2O} \xrightarrow{\text{空气中}} \mathrm{CuCl_2\cdot 2H_2O} + \mathrm{HCl}\uparrow + \mathrm{H_2O}\uparrow$$

$$\mathrm{CuCl_2\cdot 2H_2O} \xrightarrow{\triangle} \mathrm{CuCl_2} + 2\mathrm{H_2O}\uparrow$$

**5-2** E 和 F 的配位数都为 6，根据 $d^9$ 电子组态的八面体配位的姜-泰勒效应，铜原子几何形状为变形的八面体。

**5-3** 从 $\mathrm{NH_3}$ 和 $\mathrm{HNO_3}$ 制备 $\mathrm{NH_4N_3}$ 的反应方程式为：

$$\mathrm{NH_3} + \mathrm{HNO_3} \longrightarrow \mathrm{NH_4NO_3}$$

$$2\mathrm{Na} + 2\mathrm{NH_3} \longrightarrow 2\mathrm{NaNH_2} + \mathrm{H_2}$$

$$\mathrm{NaNH_2} + \mathrm{N_2O} \longrightarrow \mathrm{NaN_3} + \mathrm{H_2O}$$

$$2\mathrm{NaN_3} + \mathrm{H_2SO_4} \longrightarrow \mathrm{Na_2SO_4} + 2\mathrm{HN_3}$$

$$\mathrm{HN_3} + \mathrm{NH_3} \longrightarrow \mathrm{NH_4N_3}$$

**5-4** F 的水解：$\mathrm{Cu^{2+}} + \mathrm{H_2O} \longrightarrow \mathrm{Cu(OH)^+} + \mathrm{H^+}$。

设 $K = [\mathrm{Cu(OH)^+}][\mathrm{H^+}]/[\mathrm{Cu^{2+}}] = 0.127$。

① $\quad c(\mathrm{Cu}) = [\mathrm{Cu(OH)^+}] + [\mathrm{Cu^{2+}}]$
② $\quad K = [\mathrm{Cu(OH)^+}]/[\mathrm{Cu^{2+}}] \times [\mathrm{H^+}] = 0.127$
③ $\quad [\mathrm{Cu(OH)^+}] + [\mathrm{H^+}] + 2[\mathrm{Cu^{2+}}] = [\mathrm{Cl^-}] + [\mathrm{OH^-}] = 0$（电荷平衡）

$[\mathrm{H^+}] = 10^{-3}\ \mathrm{mol/L}$，代入②：$[\mathrm{Cu(OH)^+}] = 0.127[\mathrm{Cu^{2+}}]/10^{-3} = 127[\mathrm{Cu^{2+}}]$。

代入③：$127[\mathrm{Cu^{2+}}] + 10^{-3} + 2[\mathrm{Cu^{2+}}] = 0$ →$[\mathrm{Cu^{2+}}]$ 实应重新推导。答案原文：

$$\text{由 ③：}\ [\mathrm{Cu(OH)^+}] + 10^{-3} + 2[\mathrm{Cu^{2+}}] = 2[\mathrm{Cl^-}] = 2[\mathrm{Cu^{2+}}]$$

即 $[\mathrm{Cu(OH)^+}] + 10^{-3} = 0$ 在电荷平衡方程化为 $187[\mathrm{Cu^{2+}}] = 10^{-6}$（由 $[\mathrm{Cu(OH)^+}] = 187[\mathrm{Cu^{2+}}]$ 联立电荷平衡）。所以 $[\mathrm{Cu^{2+}}] = 7.87\times10^{-6}\ \mathrm{mol/L}$。

$c(\mathrm{Cu}) = 1.01\times10^{-3}\ \mathrm{mol/L}$（近似 = $[\mathrm{H^+}]$）。

$m(\mathrm{CuCl_2\cdot 2H_2O}) = c(\mathrm{Cu})\times M = 1.01\times10^{-3}\times170.4 = 0.172\ \mathrm{g}$。

**5-5** 只因我们忽略水解（只对很高浓度的溶液才可这样做），$\mathrm{CuCl_2-H_2O}$ 体系可被认为是准二组分体系。我们可假设低温下（由于水含量高，稳定性差）其他水合物可能存在，例如 $\mathrm{CuCl_2\cdot 4H_2O}$，但这样的水合物不能作为独立的化合物。

## 知识点映射

| 知识点 | 体现 |
|--------|------|
