# 星际氨合成离子分子链

> **来源**：化学竞赛能力测试·第6章·B卷第5题（10 分）

星际气云合成 NH₃ 的粒子-分子反应机理：

| 反应 | 常数 |
|---|---|
| N⁺ + H₂ → NH⁺ + H | k₁ |
| NH⁺ + H₂ → NH₂⁺ + H | k₂ |
| NH₂⁺ + H₂ → NH₃⁺ + H | k₃ |
| NH₃⁺ + H₂ → NH₄⁺ + H | k₄ |
| NH₄⁺ + e⁻ → NH₃ + H | k₅ |
| NH₄⁺ + e⁻ → NH₂ + 2H | k₆ |

**5-1** 稳态近似推导中间体 NH⁺、NH₂⁺、NH₃⁺、NH₄⁺ 浓度（电子与其他反应物同样处理）。

**5-2** 产生 NH₃ 速率 d[NH₃]/dt = k₂ₙₐₜ[N⁺][H₂]，用 k₁~k₆ 表示 k₂ₙₐₜ。

**5-3** 化学反应活化能的来源是什么？

**5-4** 很多离子-分子反应速率与温度无关。对活化能意味着什么？

**5-5** 这与反应发生在星际介质中有何联系？

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 稳态近似（SSA）用于各级中间体：

d[NH⁺]/dt = 0 = k₁[N⁺][H₂] − k₂[NH⁺][H₂] → **[NH⁺] = k₁[N⁺]/k₂**

d[NH₂⁺]/dt = 0 = k₂[NH⁺][H₂] − k₃[NH₂⁺][H₂] → **[NH₂⁺] = k₂/k₃×k₁[N⁺]/k₂ = k₁[N⁺]/k₃**

d[NH₃⁺]/dt = 0 = k₃[NH₂⁺][H₂] − k₄[NH₃⁺][H₂] → **[NH₃⁺] = k₁[N⁺]/k₄**

d[NH₄⁺]/dt = 0 = k₄[NH₃⁺][H₂] − (k₅+k₆)[NH₄⁺][e⁻] → **[NH₄⁺] = k₁[N⁺][H₂]/[(k₅+k₆)[e⁻]]**

**5-2**

$$\frac{\mathrm d[\mathrm{NH_3}]}{\mathrm dt} = k_5[\mathrm{NH_4^+}][\mathrm e^-] = \frac{k_1k_5}{k_5+k_6}[\mathrm{N^+}][\mathrm{H_2}]$$

$$k_\text{2nd} = k_1k_5/(k_5+k_6)$$

**5-3** 化学反应涉及键断裂与形成。活化能与破坏初始键或提供反应物几何构型充分重排引发反应所需的能量有关。

**5-4** k(T) = A·exp(−Eₐ/RT) 几乎没有温度依赖性 → **Eₐ≈0**（离子-分子反应无势垒）。

**5-5** 星际介质温度极低——只有活化能非常低的反应才能发生，离子-分子反应（Eₐ≈0）正是星际化学主要机制。

</details>
