# 高中化学必修一 · 教材习题精选> 从人教版必修一各章"练习与应用"和"复习与提高"中精选的代表性题目。> 每题附解答，适合课后巩固和竞赛前基础训练。---## 第一章 物质及其变化### §1-1 物质的分类及转化**题1**（教材原题改编）：从Zn、BaCl₂、NaOH、KClO₃、CuCl₂、Na₂SO₄、Na₂O、H₂O、H₂SO₄等物质中，选出适当物质，按要求写出化学方程式：（1）化合反应（2）分解反应（3）置换反应（4）复分解反应<details><summary>参考答案</summary>（1）Na₂O + H₂O = 2NaOH（2）2KClO₃ =(MnO₂,△)= 2KCl + 3O₂↑（3）Zn + CuCl₂ = ZnCl₂ + Cu（4）BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl</details>**题2**（教材原题）：当光束通过下列物质时，不会出现丁达尔效应的是：①Fe(OH)₃胶体 ②水 ③蔗糖溶液 ④FeCl₃溶液 ⑤云、雾A.②④⑤ B.③④⑤ C.②③④ D.①③④<details><summary>参考答案</summary>**C**。丁达尔效应是胶体的特性。①Fe(OH)₃胶体和⑤云、雾是胶体，有丁达尔效应。②水是纯液体，③蔗糖溶液和④FeCl₃溶液是溶液（粒子直径<1nm），无丁达尔效应。</details>### §1-2 离子反应**题3**（教材原题）：下列离子方程式中，正确的是：A. 稀硫酸滴在铜片上：Cu + 2H⁺ = Cu²⁺ + H₂↑B. 氧化镁与稀盐酸混合：MgO + 2H⁺ = Mg²⁺ + H₂OC. 铜片插入硝酸银溶液中：Cu + Ag⁺ = Cu²⁺ + AgD. 稀盐酸滴在石灰石上：CaCO₃ + 2H⁺ = Ca²⁺ + H₂CO₃<details><summary>参考答案</summary>**B**。A错：Cu不与稀硫酸反应（Cu在H之后）。C错：电荷不守恒，应为Cu + 2Ag⁺ = Cu²⁺ + 2Ag。D错：H₂CO₃应分解为H₂O + CO₂↑，应写为CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑。</details>**题4**（教材原题）：向一定体积的Ba(OH)₂溶液中逐滴加入稀硫酸，测得混合溶液的导电能力随时间变化的曲线如图。（1）写出反应的离子方程式。（2）B处导电能力约为0，说明什么？<details><summary>参考答案</summary>（1）Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO₄↓ + 2H₂O（2）B处导电能力约为0，说明溶液中几乎没有自由移动的离子——Ba(OH)₂与H₂SO₄恰好完全反应，生成难溶的BaSO₄和极弱电解质H₂O。</details>### §1-3 氧化还原反应**题5**：判断下列反应中的氧化剂和还原剂：2FeCl₃ + Cu = 2FeCl₂ + CuCl₂<details><summary>参考答案</summary>Fe从+3降到+2（得电子），FeCl₃是**氧化剂**。Cu从0升到+2（失电子），Cu是**还原剂**。</details>**题6**：用双线桥法标出下列反应中电子的转移方向和数目，并指出氧化剂和还原剂：MnO₂ + 4HCl(浓) =(△)= MnCl₂ + Cl₂↑ + 2H₂O<details><summary>参考答案</summary>Mn从+4降到+2，得2e⁻，MnO₂是氧化剂。Cl从-1升到0（2个Cl），失2e⁻，HCl是还原剂。注意：4个HCl中只有2个被氧化，另外2个起酸的作用（提供Cl⁻形成MnCl₂）。</details>## 第二章 海水中的重要元素——钠和氯### §2-1 4OH⁻ + O₂↑</details>### §2-3 物质的量**题8**（教材例题）：250 mL 2 mol/L 的硫酸与足量铁屑完全反应。计算：（1）参加反应的铁屑的物质的量（2）生成H₂的体积（标准状况）<details><summary>参考答案</summary>n(H₂SO₄) = 0.25L × 2mol/L = 0.50molFe + H₂SO₄ = FeSO₄ + H₂↑（1）n(Fe) = 0.50mol（2）V(H₂) = 0.50mol × 22.4L/mol = 11.2L</details>## 第三章 铁 金属材料### §3-2 金属材料**题9**（教材原题）：相同质量的两份铝，分别放入足量的盐酸和NaOH溶液中，放出H₂在同温同压下体积之比为：A. 1:1 B. 1:6 C. 2:3 D. 3:2<details><summary>参考答案</summary>**A**。两个反应中Al均从0价→+3价，每mol Al均转移3mol电子。相同质量→相同物质的量→转移电子数相同→生成H₂相同。</details>**题10**（教材原题）：向铝质易拉罐中充满CO₂，注入足量浓NaOH溶液，封严罐口。（1）易拉罐变瘪的原因和离子方程式（2）易拉罐又鼓起来的原因和离子方程式<details><summary>参考答案</summary>（1）CO₂被NaOH吸收，罐内气压降低，大气压将罐压瘪。CO₂ + 2OH⁻ = CO₃²⁻ + H₂O（2）Al₂O₃膜先与NaOH反应，然后Al与NaOH反应放出H₂，罐内气压回升使罐鼓起。2Al + 2OH⁻ + 2H₂O = 2AlO₂⁻ + 3H₂↑</details>### 第三章 Cu剩余固体可被磁铁吸引→含Fe（铁粉过量或Fe生成）。溶液中较多的阳离子是 **Fe²⁺**（Fe³⁺和Cu²⁺已被完全还原）。</details>## 第四章 物质结构 元素周期律### §4-1
