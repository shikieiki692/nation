## 题目

Lewis 结构式的书写思想虽然简单, 但在现代化学中仍然有发挥着重要作用。请根据 Lewis 结构式的分析后填写下表。

**9-1** 将这些微粒与最后一列中相应的 N—O 键长相匹配: 甲醛肟 $\mathrm{(CH_2NOH)}$、亚硝酰离子 $\mathrm{(NO^+)}$、硝酰离子 $\mathrm{(NO_2^+)}$、亚硝酸根离子 $\mathrm{(NO_2^-)}$ 和硝酸根离子 $\mathrm{(NO_3^-)}$ 。

| 分子/离子 | N—O 键级 | N—O 键长(Å) |
|---|---|---|
|  |  | 1.062 |
|  |  | 1.15 |
|  |  | 1.236 |
|  |  | 1.25 |
|  |  | 1.47 |

**9-2** 完成下表, 使所列分子与最后一列中相应的 C—O 键长相匹配: $\mathrm{CO}$、$\mathrm{CO_2}$、$\mathrm{CO_3^{2-}}$、$\mathrm{H_3COCH_3}$(二甲醚) 和 $\mathrm{H_3CCOO^-}$(醋酸根离子)。

## 参考答案

**9-1** N—O 键级与键长关系(键级越大键长越短, 单调递减):

| 分子/离子 | N—O 键级 | N—O 键长(Å) |
|---|---|---|
| $\mathrm{NO^+}$: $:\mathrm{N \equiv O:}$ | 3 | 1.062 |
| $\mathrm{NO_2^+}$: $\mathrm{O{=}N^+{=}O}$ | 2 | 1.15 |
| $\mathrm{NO_2^-}$: $\mathrm{O{-}N(O^-){=}O}$(共振) | 1.5 | 1.236 |
| $\mathrm{NO_3^-}$: $\mathrm{O{-}N(O^-){=}O{-}N(O^-){=}O}$(3 个等价 N—O 共振) | 1⅓ | 1.25 |
| $\mathrm{CH_2NOH}$(甲醛肟): $\mathrm{H_2C{=}N{-}OH}$ | 1 | 1.47 |

**9-2** C—O 键级与键长关系:

| 分子/离子 | C—O 键级 | C—O 键长(Å) |
|---|---|---|
| $\mathrm{CO}$: $:\mathrm{C \equiv O:}$ | 3 | 1.128 |
| $\mathrm{CO_2}$: $\mathrm{O{=}C{=}O}$ | 2 | 1.163 |
| $\mathrm{CH_3COO^-}$(醋酸根): 两个等价 C—O 共振 | 1.5 | 1.250 |
| $\mathrm{CO_3^{2-}}$(碳酸根): 3 个等价 C—O 共振 | 1⅓ | 1.290 |
| $\mathrm{H_3COCH_3}$(二甲醚): $\mathrm{H_3C{-}O{-}CH_3}$ | 1 | 1.416 |
