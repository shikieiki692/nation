# 氦碳化合物 CHe₃³⁺/CHe₄⁴⁺

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第10章 氢、稀有气体和卤族元素·A卷第7题
> **分值**：9 分
> **教学层级**：竞赛

## 题目

1962 年英国青年化学家巴特列第一次制得了 $\mathrm{XePtF_6}$ 化合物，突破了"惰性元素"的禁区。此后人们相继合成了氙的系列化合物，以及原子序数较大的稀有气体氪、氡的化合物。对于原子序数较小的氦、氖尚未制得化合物。有人从理论上预言了它们的化合物是可以制得的。不久澳洲国立大学的拉多姆宣布了化学上一奇闻，氦能够与碳结合形成分子。像 $\mathrm{CHe}_x^{x+}$ 不仅存在，而且能够用实验手段观察到，并借助计算机算出了 $\mathrm{CHe_3^{3+}}$、$\mathrm{CHe_4^{4+}}$ 的键长分别为：0.1209 nm，0.1212 nm。

**7-1** 相对于 Xe，Ne、He 的化合物难以合成的主要原因是什么？

**7-2** 如果 $\mathrm{CHe_3^{3+}}$、$\mathrm{CHe_4^{4+}}$ 果真存在的话，请写出它们的立体结构式。

**7-3** 为什么 $\mathrm{CHe_3^{3+}}$ 的键长比 $\mathrm{CHe_4^{4+}}$ 短？

**7-4** 写出与 $\mathrm{CHe_3^{3+}}$、$\mathrm{CHe_4^{4+}}$ 互为等电子体的物质（或原子团）的名称。

**7-5** 并完成下列化学方程式：

$$\mathrm{CHe_4^{4+}} + \mathrm{H_2O} \longrightarrow$$

$$\mathrm{CHe_4^{4+}} + \mathrm{HCl} \longrightarrow$$

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**7-1** 原子半径小，原子核对外层电子引力大。

**7-2** $\mathrm{CHe_3^{3+}}$（正三角形）；$\mathrm{CHe_4^{4+}}$（正四面体）。

![[4b4cbf59dfc6dc64f17ba320df84556d4c96d068e22b8bccda21f399c130294d.jpg]]

（CHe₃³⁺ 正三角形结构答图）

![[df5faa20ced3a1ab4ccb026f729b8eeebacfe6590ce9704448bea3d25d2a3f1a.jpg]]

（CHe₄⁴⁺ 正四面体结构答图）

**7-3** $\mathrm{CHe_3^{3+}}$ 中 C 原子 $\mathrm{sp^2}$ 杂化，$\mathrm{CHe_4^{4+}}$ 中 C 原子 $\mathrm{sp^3}$ 杂化，后者 p 轨道成分多，相同条件下成键长。

**7-4** 甲基；甲烷。

**7-5** 

$$\mathrm{CHe_4^{4+}} + 2\mathrm{H_2O} = \mathrm{CO_2} + 4\mathrm{He} + 4\mathrm{H^+}$$

$$\mathrm{CHe_4^{4+}} + 4\mathrm{HCl} = \mathrm{CCl_4} + 4\mathrm{He} + 4\mathrm{H^+}$$

</details>

<!-- 校勘注: ①7-3 答案原文「后者 p 轨道成分多，相同条件下成键长」——按通常杂化轨道理论应为 sp² 杂化 s 成分（33%）多于 sp³（25%），s 成分多使键更短，故 CHe₃³⁺（sp²）键短于 CHe₄⁴⁺（sp³）的解释合理，但表述「p 成分多成键长」似指 sp³ p 成分多键长——与「s 成分多键短」的常用规则相符但表述可改进；照录原文存疑；②7-5 两个方程式电荷/原子数守恒自洽（CHe₄⁴⁺ + 2H₂O = CO₂ + 4He + 4H⁺：C/He/O/H/电荷全守恒；CHe₄⁴⁺ + 4HCl = CCl₄ + 4He + 4H⁺ 同理）；③7-4 等电子体按价电子总数：CHe₃³⁺ 4+6-3=7 价电子 ↔ CH₃⁺ 4+3-1=6（不等），与中性 CH₃ 自由基（7 价电子）等电子；CHe₄⁴⁺ 4+8-4=8 ↔ CH₄ 4+4=8 等电子。答案「甲基/甲烷」按原子团名称作答。 -->
