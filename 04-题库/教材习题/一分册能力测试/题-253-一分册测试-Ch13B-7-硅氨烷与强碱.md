# 硅氨烷与强碱

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·B卷第7题（12 分）

## 题目

试剂 A 是一种无色液体，是有机合成和金属有机化学中一类重要碱试剂的中间体。A 可由三甲基氯硅烷与氨气反应合成，有两种化学环境不同的氢，个数之比为 18:1。

7-1 给出合成 A 的化学方程式。

7-2 A 与丁基锂反应生成一种"非亲核性强碱" B，B 在有机合成中有重要的用途，写出这种强碱的 B 的结构简式。为什么 B 是一种"非亲核性强碱"？

7-3 B 可以形成二聚体，给出二聚体的结构。

7-4 B 可以用来制备一些低配位数的配合物，如三配位的 Fe(Ⅲ) 的配合物，分析原因。

7-5 三甲基氯硅烷与 B 反应，可以得到一种分子 C，C 的结构特征是具有平面正三角形的配位形式，给出 C 的结构简式，并通过其成键形式解释其结构特征。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**7-1** A = $\mathrm{[(CH_3)_3Si]_2NH}$（六甲基二硅氮烷，HMDS）

$\mathrm{2(CH_3)_3SiCl + 3NH_3 \longrightarrow [(CH_3)_3Si]_2NH + 2NH_4Cl}$

H 个数比 18:1（18 个 CH₃ 氢 + 1 个 NH 氢），符合题面两种 H 环境。

**7-2** B = $\mathrm{[(CH_3)_3Si]_2NLi}$（LiHMDS，双三甲硅基胺基锂）

$\mathrm{[(CH_3)_3Si]_2NH + BuLi \longrightarrow [(CH_3)_3Si]_2NLi + BuH}$

非亲核性强碱原因：两个大位阻三甲硅基（Si(CH₃)₃）屏蔽了 N 中心的孤对电子，N 中心虽能夺取质子（强碱性），但因位阻大无法接近其他亲电中心（如 C=O 碳），即强碱但弱亲核性。

**7-3** 二聚体：两个 $\mathrm{[(CH_3)_3Si]_2NLi}$ 单元通过 N—Li—N 桥联（每个 Li 配位 2 N 原子形成四元环 Li₂N₂）：

![[c84c8d44e17b5494b0307035aecf26b7b6295c6792b861cd4c34e7dd646bb468.jpg]]

**7-4** 三配位 Fe(III) 形成原因：B 的空间位阻很大，不利于形成高配位（四配位或六配位）的化合物。Fe(III) 与 B 反应时只能容纳 3 个 B 配体（每个 B 提供 1 个 N 孤对电子与 Fe 配位），形成三角平面三配位 Fe(III) 配合物。

**7-5** C = $\mathrm{[(CH_3)_3Si]_3N}$（三（三甲硅基）胺）

结构特征：N 中心 sp² 杂化，三个 Si 位于平面正三角形顶点，N 位于中心。

成键形式：

- N 与 3 个 Si 形成 3 个 N—Si σ 键
- N 上一对孤对电子与 3 个 Si 的 3d 空轨道形成离域 π 键（类似硼酸盐中 B—O π 配键）

sp² 杂化 + 离域 π 键使 N 中心呈平面三角形配位，无孤对电子位于平面外（避免立体化学活性），整个分子因此具有平面特征。

</details>
