# O₂ 系列离子键级键能键长(分子轨道理论)

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第8章 共价键与分子结构·B卷第10题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

已知含 $\mathrm{O_2^{2-}}$、$\mathrm{O_2^-}$、$\mathrm{O_3^-}$ 和 $\mathrm{O_2^+}$ 的化合物都是存在的。

**10-1** 写出上述四个离子对应的化合物的化学式。

**10-2** 上述四个离子中是否存在反磁性的?若有请指出来。

**10-3** 已知下表中各个微粒的 O—O 原子间距离为 112、121、132 和 ~149 pm, 有三种物种的键能约为 200, 490 和 625 kJ·mol⁻¹, 另一种未给出数据, 试把这些数据填在下表中的合适位置, 并确定每一种微粒的键级。

| 微粒 | 原子间距离 | 键能 | 键级 |
|---|---|---|---|
| $\mathrm{O_2}$ |  |  |  |
| $\mathrm{O_2^+}$ |  |  |  |
| $\mathrm{O_2^-}$ |  |  |  |
| $\mathrm{O_2^{2-}}$ |  |  |  |

**10-4** 有没有可能从 $\mathrm{F_2}$ 出发, 制备出含 $\mathrm{F_2^{2-}}$ 离子的化合物, 理由是什么?

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**10-1** $\mathrm{O_2^{2-}}$: $\mathrm{Na_2O_2}$(过氧化钠); $\mathrm{O_2^-}$: $\mathrm{KO_2}$(超氧化钾); $\mathrm{O_3^-}$: $\mathrm{KO_3}$(臭氧化钾); $\mathrm{O_2^+}$: $\mathrm{O_2[PtF_6]}$(Dioxygenyl hexafluoroplatinate)。

**10-2** **$\mathrm{O_2^{2-}}$ 是反磁性的**。$\mathrm{O_2}$ 分子轨道排布为 $\mathrm{KK}(\sigma_{2s})^2(\sigma^*_{2s})^2(\sigma_{2p})^2(\pi_{2p})^4(\pi^*_{2p})^2$, 键级 = 2, 含 2 个未成对电子(顺磁)。$\mathrm{O_2^{2-}}$ 是在 $\mathrm{O_2}$ 的 $\pi^*_{2p}$ 轨道上再增加 2 个电子, 4 个 $\pi^*_{2p}$ 电子全部成对, 无单电子, 故反磁。$\mathrm{O_2^-}$、$\mathrm{O_2^+}$ 各有 1 个未成对电子(顺磁);$\mathrm{O_3^-}$ 有 1 个未成对电子(顺磁)。

**10-3** 按分子轨道理论, $\mathrm{O_2}$ 键级 = 2, $\mathrm{O_2^+}$ 键级 = 2.5, $\mathrm{O_2^-}$ 键级 = 1.5, $\mathrm{O_2^{2-}}$ 键级 = 1。键级-键长-键能单调关系: 键级↑ → 键长↓, 键能↑。

| 微粒 | 原子间距离 (pm) | 键能 (kJ·mol⁻¹) | 键级 |
|---|---|---|---|
| $\mathrm{O_2}$ | 121 | 490 | 2 |
| $\mathrm{O_2^+}$ | 112 | 625 | 2.5 |
| $\mathrm{O_2^-}$ | 132 | — | 1.5 |
| $\mathrm{O_2^{2-}}$ | 149 | 200 | 1 |

**10-4** **不可能**。按分子轨道理论, $\mathrm{F_2}$ 得到的两个电子要填充在反键轨道($\sigma^*_{2p}$ 或 $\pi^*_{2p}$) 上去, 此时键级变为零, 不可能稳定存在, 故从 $\mathrm{F_2}$ 出发不能制备出含 $\mathrm{F_2^{2-}}$ 离子的稳定化合物。
