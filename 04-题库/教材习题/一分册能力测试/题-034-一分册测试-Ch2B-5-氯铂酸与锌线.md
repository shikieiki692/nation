# 题-034-一分册测试-Ch2B-5-氯铂酸与锌线

## 题目

某酸（A）由三种元素组成。把一种金属线放入盛有 75.0 g、16.4% 的酸（A）的锥形瓶中，会放出 0.672 dm³ 的氢气（体积已换算成 0℃ 与 1 atm），并生成盐溶液。当过量的硝酸银加入上述盐溶液中，得到 25.81 g 白色沉淀。该沉淀含有 75.26%（质量分数）的银。在分析过程中，反应前后的金属线质量没有发生变化。

5-1 通过计算，试确定白色沉淀的组成。

5-2 通过计算，试确定（A）的化学式。

5-3 通过计算，说明金属线是什么金属元素？

5-4 写出上述实验中所发生的全部的反应方程式。

5-5 试写出制备酸（A）的化学方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

5-1 设白色沉淀为 $\mathrm{Ag}_n\mathrm{X}$：

$$\frac{n\times M_{\mathrm{Ag}}}{n\times M_{\mathrm{Ag}} + M_{\mathrm{X}^{n-}}} = 0.7526$$

$$\frac{n\times107.87}{n\times107.87 + M_{\mathrm{X}^{n-}}} = 0.7526$$

$$M_{\mathrm{X}^{n-}} = \frac{0.2427 n\times107.87}{0.7526} = 35.46n$$

当 n=1 时，$M_{\mathrm{X}^{-}}=35.46$，X 应为氯元素，∴白色沉淀为 AgCl。

5-2 (A) 酸应由 H、Cl 和另一种元素 Y 组成。

$$n_{\mathrm{Cl}} = n_{\mathrm{AgCl}} = \frac{25.81}{107.87+35.45} = 0.180\ (\mathrm{mol}),\quad n_{\mathrm{H}} = 2n_{\mathrm{H}_2} = \frac{2\times0.672}{22.4} = 0.060\ (\mathrm{mol})$$

$$\therefore n_{\mathrm{H}}:n_{\mathrm{Cl}} = 0.060:0.180 = 1:3$$

∴(A) 酸的化学式可以记作 $H_{a}Y_{b}Cl_{3a}$。

设金属线元素为 M，M 与 (A) 酸的反应方程式为：

$$m\mathrm{H}_a\mathrm{Y}_b\mathrm{Cl}_{3a} + 3a\mathrm{M} = \frac{ma}{2}\mathrm{H}_2 + mb\mathrm{Y} + 3a\mathrm{MCl}_m$$

(A) 酸的摩尔质量 $=\dfrac{75.0\times0.164\times a}{0.060}=205a\ (\mathrm{g\cdot mol^{-1}})$。

当 a=1，则 $1.008+bM_{(\mathrm{Y})}+3\times35.45=205\times1$，$bM_{(\mathrm{Y})}=97.642$：b=1 时 Y 为 Tc（98）；b=2 时 Y 为 Ti（49）。此两种金属都不符合题意。

当 a=2，则 $1.008\times2+bM_{(\mathrm{Y})}+6\times35.45=205\times2$，$bM_{(\mathrm{Y})}=195.28$：b=1 时 Y 为 Pt（195.08）。金属铂符合题意，∴(A) 酸为 $H_{2}PtCl_{6}$。

5-3 $\quad k\mathrm{H}_2[\mathrm{PtCl}_6] + 6\mathrm{M} = 6\mathrm{MCl}_k + k\mathrm{H}_2\uparrow + k\mathrm{Pt}$

由于反应前后金属线的质量不变，$\therefore m_{(\mathrm{M})}=m_{(\mathrm{Pt})}$。

而 Pt 的质量 $=\frac{1}{2}\times0.060\times195.08=5.8524\ (\mathrm{g})$。

∴金属线的金属元素摩尔质量 $=\dfrac{5.8524}{\frac{6}{k}\times0.03}=32.51k\ (\mathrm{g\cdot mol^{-1}})$。

k=1 时，不合题意；k=2 时，$32.51\times2=65.02$，应为金属 Zn。

5-4 $\quad 3\mathrm{Zn} + \mathrm{H}_2[\mathrm{PtCl}_6] = 3\mathrm{ZnCl}_2 + \mathrm{H}_2\uparrow + \mathrm{Pt}$

$$\mathrm{ZnCl}_2 + 2\mathrm{AgNO}_3 = \mathrm{Zn}(\mathrm{NO}_3)_2 + 2\mathrm{AgCl}\downarrow$$

5-5 $\quad 3\mathrm{Pt} + 4\mathrm{HNO}_3 + 18\mathrm{HCl} = 3\mathrm{H}_2\mathrm{PtCl}_6 + 4\mathrm{NO}\uparrow + 8\mathrm{H}_2\mathrm{O}$

</details>
