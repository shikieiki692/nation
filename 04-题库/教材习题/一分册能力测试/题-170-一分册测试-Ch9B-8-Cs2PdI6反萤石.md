# Cs₂PdI₆ 反萤石结构

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第9章 金属键和金属晶体·B卷第8题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

由于 Pd(IV) 具有比较强的氧化性，其碘化物的晶体不太容易得到。2000 年，有文献报道通过对 Pd(II) 的碘化物 $\mathrm{Cs_2PdI_4}$ 与 $\mathrm{I_2}$ 共同生成的晶体直接施加高压，可以得到 Pd(IV) 的 $\mathrm{Cs_2PdI_6}$ 晶体。$\mathrm{Cs_2PdI_6}$ 的晶体属于立方晶系，具有反萤石型结构，晶体密度为 $5.174\ \mathrm{g\cdot cm^{-3}}$。$\mathrm{Cs_2PdI_4}$ 与 $\mathrm{I_2}$ 共同生成的晶体属于四方晶系，晶胞参数 $a = 899\ \mathrm{pm}$，$c = 924\ \mathrm{pm}$。

**8-1** 请指出 $\mathrm{Cs_2PdI_6}$ 中阴离子的空间构型并求算 $\mathrm{Cs_2PdI_6}$ 的晶胞参数。

**8-2** 求算 $\mathrm{Cs_2PdI_4}$ 与 $\mathrm{I_2}$ 共同生成晶体的晶体密度。

**8-3** 如图所示为 $\mathrm{Cs_2PdI_4}$ 与 $\mathrm{I_2}$ 共同生成晶体的晶胞，请给出 $\mathrm{Cs^+}$ 离子的分数坐标。

![[a172cbc619e9a5656451532c2881b975afe23596f0e385f56ee66f2d2b0f6865.jpg]]

（Cs₂PdI₄ 与 I₂ 共晶的晶胞，第8题图）

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**8-1** 正八面体；

萤石结构 $Z = 4$，$\rho = m/V = m/a^3 = 5.174\ \mathrm{g\cdot cm^{-3}}$，$m = 4\times(132.9\times 2 + 106.4 + 126.9\times 6)/(6.022\times 10^{23}) = 7.528\times 10^{-21}\ \mathrm{g}$。故晶胞参数 $a = 1133\ \mathrm{pm}$。

**8-2** 晶体密度 

$$\rho = \frac{m}{V} = \frac{2\times(132.9\times 2 + 106.4 + 126.9\times 6)}{899\times 899\times 924\times (10^{-10})^{3}\times 6.022\times 10^{23}} = 5.04\ \mathrm{g\cdot cm^{-3}}$$

**8-3** $(0, 1/2, 1/4)$；$(0, 1/2, 3/4)$；$(1/2, 0, 1/4)$；$(1/2, 0, 3/4)$。

</details>
