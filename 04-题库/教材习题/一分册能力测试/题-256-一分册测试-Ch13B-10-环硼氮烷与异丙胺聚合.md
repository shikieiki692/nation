# 环硼氮烷与异丙胺聚合

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·B卷第10题（10 分）

## 题目

将一定量的 $\mathrm{NH_4Cl}$ 在甲苯中剧烈搅拌，加热到 110 ℃ 后缓慢通入 $\mathrm{BCl_3}$ 气体，在出口端冷凝回流 15 小时，减压蒸馏溶剂得到无色针状晶体 X，X 具有三重轴，在水中容易水解得到弱酸性的溶液。元素分析结果表明 X 中含 B: 17.6%，N: 22.9%，H: 1.64%，所有原子都只有一种化学环境。−20 ℃ ~ −10 ℃ 下，在含 0.050 mol 的 X 的甲苯溶液中缓慢加入 0.150 mol 的异丙胺，反应 5 h 后再升至室温下反应 15 h，减压蒸馏溶剂得到物质 Y，加热 Y，Y 的状态由液态转化为难熔的固体 Z，Z 具有多环结构，进一步加热到高温得到只含两种元素的材料 W。

10-1 给出 X 的化学式及其结构。

10-2 写出 X 水解的方程式。

10-3 画出 Y 的结构式。

10-4 Y 在加热的状态下生成 Z 的反应类型。

10-5 给出 W 的化学式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**10-1** X = $\mathrm{B_3N_3H_3Cl_3}$（环硼氮烷，B-N 交替六元环）

验算：$M = 3 \times 10.81 + 3 \times 14.01 + 3 \times 1.008 + 3 \times 35.45 = 183.83$

$w(\mathrm{B}) = 32.43/183.83 = 17.6\%$ ✓
$w(\mathrm{N}) = 42.03/183.83 = 22.9\%$ ✓
$w(\mathrm{H}) = 3.024/183.83 = 1.64\%$ ✓

所有原子一种化学环境：B 上接 1 H + 1 Cl，N 上接 1 H（环上 N-H）；B-N 交替六元环具有三重轴 C₃。

![[e826447de3c85e83b6e07866d6ef34df2c3a053f8d3e0adec46662e0fddfa90f.jpg]]

**10-2** $\mathrm{B_3N_3H_3Cl_3 + 9H_2O = 3H_3BO_3 + 3NH_4Cl}$

水解产物硼酸（H₃BO₃，弱酸）与 NH₄Cl，水溶液呈弱酸性。

**10-3** Y = $\mathrm{(ClBNH\text{-}iPr)_3}$（环上 3 个 B-Cl 都被 iPrNH 取代，保留 B-N 环骨架，N 上挂 iPr 异丙基）

![[bc45d60e26cef288cd7c5382e414de7b23102c5000cd7011d21d32bbea425733.jpg]]

（结构式中 R = (CH₃)₂CH—）

反应：$\mathrm{B_3N_3H_3Cl_3 + 3iPrNH_2 = (ClBNH\text{-}iPr)_3 + 3HCl}$

**10-4** 反应类型：**缩聚反应**（Y 加热脱去 iPrNH₂ 分子，B-Cl 与相邻 N-H 缩合形成 B-N 桥联多环结构 Z）

**10-5** W = $\mathrm{BN}$（氮化硼）

进一步高温缩聚脱去所有 iPrNH₂ 与 HCl，最终产物为无机陶瓷材料氮化硼 BN（石墨型结构）。

</details>
