# 题-022-一分册测试-Ch2A-3-碘硫代硫酸盐推断

## 题目

钾盐 A 可用作感光乳化剂、食品添加剂等；B 微溶于水，加入 A 后 B 的溶解度增大，成棕色溶液 C；D 溶液遇酸有淡黄色沉淀生成，将黄绿色气体 E 通入溶液 D，在所得溶液中加入 $BaCl_{2}$ 溶液有难溶于 $HNO_{3}$ 溶液白色沉淀生成；物质 C 与 D 反应，常用于化学反应的定量分析。各物质之间的部分转化关系如下：

![[b5ba82d028e3355173a3b7136676b0b78ddb47c6125cd6b6080b7973cc89253a.jpg]]

回答下列问题：

3-1 化合物 A 和 D 的化学式分别是 A：____；D：____。

3-2 写出过量 E 通入溶液 D 的离子反应方程式：____。

3-3 写出上述流程中 C 与 E 反应的离子方程式：____。

3-4 从分子结构分析，B 微溶于水，加入 A 后 B 的溶解度增大的原因。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

3-1 「B 微溶于水，加入 A 后 B 的溶解度增大，成棕色溶液 C」是本题突破口。说明 B 为 $I_{2}$，A 为 KI，生成 $KI_{3}$，增大了 $I_{2}$ 的溶解度。气体容易确定。因此 A 为 KI，D 为 $Na_{2}S_{2}O_{3}$。

3-2 $\quad S_2O_3^{2-} + 4Cl_2 + 5H_2O = 2SO_4^{2-} + 8Cl^- + 10H^+$

3-3 $\quad \mathrm{I}_3^- + 8\mathrm{Cl}_2 + 9\mathrm{H}_2\mathrm{O} = 3\mathrm{IO}_3^- + 16\mathrm{Cl}^- + 18\mathrm{H}^+$

3-4 碘分子是非极性分子，$I_{2}$ 遇 $I^{-}$ 溶液生成了 $I_{3}^{-}$（也可从 Lewis 酸碱角度考虑：$I_{2}$ 为 Lewis 酸，$I^{-}$ 为 Lewis 碱，发生 Lewis 酸碱反应）。

</details>
