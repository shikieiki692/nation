# AuCu₃ 与 Cs₁₁O₃

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第9章 金属键和金属晶体·B卷第4题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

某化合物 X 由 A、B 两种元素组成，X 晶体中存在一根 $\mathrm{C_3}$ 轴，晶体沿此轴的投影图如图所示。

![[a104ff6bf56c5f8e9a24bcd20b76d4e7a0cedfb03782a5798f5a69ccb9808e0a.jpg]]

（X 晶体沿 C₃ 轴的投影图）

晶体中 A 元素与 B 元素的质量之比为 1:0.968，A 和 C 组成某种离子化合物 M，其中阴阳离子的比值为 1:1，而且 A 的质量分数为 59.71%。C 存在多种低价氧化物，有一种含 C 的低价氧化物 N 中 C 的质量分数为 0.968，该氧化物有一根 $\mathrm{C_3}$ 轴，并且有 3 个八面体两两共面组成，由 C 组成八面体的框架，O 在八面体的中心。

**4-1** 写出 A、B、C、M、N、X 的化学式。

![[c82d5a3bf2c464b367005e79932bdcab07b8ef7e8f047e5d520483f7d4ef2e4e.jpg]]

（第4题图）

**4-2** 画出 X 的晶胞。

**4-3** 画出 N 的结构。

**4-4** 试分析 N 存在的原因。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** N 是 $\mathrm{C_{11}O_3} \Rightarrow \frac{11M(C)}{11M(C)+16\times3} = 0.968 \Rightarrow M(C) = 132 \Rightarrow C$ 是 Cs，N 是 $\mathrm{Cs_{11}O_3}$ $\Rightarrow \frac{M(A)}{M(A)+M(C)} = 59.71\% \Rightarrow M(A) = 196.96 \Rightarrow A$ 是 Au，M 是 CsAu。

因此 A：Au；B：Cu；C：Cs；M：CsAu；N：$\mathrm{Cs_{11}O_3}$；X：$\mathrm{Cu_3Au}$。

**4-4** 由于相对论效应和屏蔽效应使 6s 轨道收缩，能级降低，6s 和 5d 轨道一起形成最外层的价轨道，此时 Au 具有类似卤素的电子组态，差一个电子即成为闭壳层，因此 Au 具有稳定的 −1 价。
