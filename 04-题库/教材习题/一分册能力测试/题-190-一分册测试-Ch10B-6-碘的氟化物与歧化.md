# 碘的氟化物与歧化

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第10章 氢、稀有气体和卤族元素·B卷第6题
> **分值**：12 分
> **教学层级**：竞赛

## 题目

碘能形成多种氟化物，具有许多有趣的性质。

**6-1** 画出 $\mathrm{IF_3}$、$\mathrm{IF_5}$、$\mathrm{IF_7}$ 的立体结构。

**6-2** 在非水溶剂中，$\mathrm{IF_7}$ 与 $\mathrm{AsF_5}$ 反应得到一种离子化合物 A，$\mathrm{IF_7}$ 与 $\mathrm{SbF_5}$ 以摩尔比 $1:2$ 反应得到离子化合物 B，A、B 中阳离子结构相同，给出 A、B 的结构简式，画出 B 中阴离子的立体结构。

**6-3** $\mathrm{IF_5}$ 和 $\mathrm{SO_3}$ 以摩尔比 $1:1$ 反应得到一种离子化合物 C，给出 C 的结构简式，画出 C 中阳离子的结构。

**6-4** IF、$\mathrm{IF_3}$、$\mathrm{IF_5}$ 均可能发生歧化反应，生成碘单质和碘元素价态升高二价的氟化物。写出歧化反应的方程式，并计算反应热。事实上 IF，$\mathrm{IF_3}$，$\mathrm{IF_5}$ 只有一个不能发生歧化，指出是何种物质。已知某些物质的标准生成热如下：

| | IF | $\mathrm{IF_3}$ | $\mathrm{IF_5}$ | $\mathrm{IF_7}$ |
|---|---|---|---|---|
| $\Delta_{\mathrm{f}}H^{\ominus}/\mathrm{kJ\cdot mol^{-1}}$ | −95.4 | −486 | −843 | −962.5 |

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**6-1** 立体结构图略。$\mathrm{IF_3}$ T 型，$\mathrm{IF_5}$ 四方锥型，$\mathrm{IF_7}$ 五角双锥形。

**6-2** A $[\mathrm{IF_6^+}][\mathrm{AsF_6^-}]$，B $[\mathrm{IF_6^+}][\mathrm{Sb_2F_{11}^-}]$；$\mathrm{Sb_2F_{11}^-}$ 立体结构图略；两个 $\mathrm{SbF_6}$ 正八面体以氟桥键相连。

**6-3** C $[\mathrm{IF_4^+}][\mathrm{SO_3F^-}]$；$\mathrm{IF_4^+}$ 为变形四面体形（跷跷板形），立体结构图略。

**6-4** 

$3\mathrm{IF} \longrightarrow \mathrm{I_2} + \mathrm{IF_3}$

$\Delta_{\mathrm{r}}H^{\ominus} = -3\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF}) + \Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_3}) = (286.2 - 486)\ \mathrm{kJ\cdot mol^{-1}} = -199.8\ \mathrm{kJ\cdot mol^{-1}}$

$5\mathrm{IF_3} \longrightarrow \mathrm{I_2} + 3\mathrm{IF_5}$

$\Delta_{\mathrm{r}}H^{\ominus} = -5\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_3}) + 3\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_5}) = (2430 - 2529)\ \mathrm{kJ\cdot mol^{-1}} = -99\ \mathrm{kJ\cdot mol^{-1}}$

$7\mathrm{IF_5} \longrightarrow \mathrm{I_2} + 5\mathrm{IF_7}$

$\Delta_{\mathrm{r}}H^{\ominus} = -7\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_5}) + 5\Delta_{\mathrm{f}}H^{\ominus}(\mathrm{IF_7}) = (5901 - 4812.5)\ \mathrm{kJ\cdot mol^{-1}} = +1088.5\ \mathrm{kJ\cdot mol^{-1}}$

结论：$\mathrm{IF_5}$ 不歧化。

</details>
