# 纯硫酸溶剂化学

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第11章 氧族元素·B卷第4题
> **分值**：8 分
> **教学层级**：竞赛

## 题目

纯硫酸是无色透明的液体，是一种重要的非水溶剂，试回答下列问题。

**4-1** 纯硫酸的粘度非常大，为什么纯硫酸中 $\mathrm{H_3SO_4^+}$ 和 $\mathrm{HSO_4^-}$ 离子的迁移速度可以与水中的 $\mathrm{H_3O^+}$ 和 $\mathrm{OH^-}$ 离子的迁移速度相提并论。

**4-2** 写出下列在 $100\%\ \mathrm{H_2SO_4}$ 中化学反应方程式：

① $\mathrm{HNO_3}(1\ \mathrm{mol}) + \mathrm{H_2SO_4}(2\ \mathrm{mol})$　$v^* = 4$

② $\mathrm{H_3BO_3}(1\ \mathrm{mol}) + \mathrm{H_2SO_4}(6\ \mathrm{mol})$　$v^* = 6$

③ $\mathrm{I_2}(7\ \mathrm{mol}) + \mathrm{HIO_3}(1\ \mathrm{mol}) + \mathrm{H_2SO_4}(8\ \mathrm{mol})$　$v^* = 16$

$v^*$ 表示反应方程式右边的离子数（以 mol 计，可由冰点测定仪确定）

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** $\mathrm{H_3SO_4^+}$ 与 $\mathrm{H_2SO_4(l)}$ 之间、$\mathrm{HSO_4^-}$ 与 $\mathrm{H_2SO_4(l)}$ 之间依靠氢键形成了 $\mathrm{H_3SO_4^+}$ 和 $\mathrm{HSO_4^-}$ 离子团的通道，所以这两种离子在 $\mathrm{H_2SO_4(l)}$ 中迁移速度快（质子跳跃/结构扩散机制，类比水中 $\mathrm{H_3O^+}$/$\mathrm{OH^-}$ 的 Grotthuss 机理）。

**4-2** ① $\mathrm{HNO_3} + 2\mathrm{H_2SO_4} = \mathrm{NO_2^+} + \mathrm{H_3O^+} + 2\mathrm{HSO_4^-}$

② $\mathrm{H_3BO_3} + 6\mathrm{H_2SO_4} = \mathrm{B(HSO_4)_4^-} + 2\mathrm{HSO_4^-} + 3\mathrm{H_3O^+}$

③ $7\mathrm{I_2} + \mathrm{HIO_3} + 8\mathrm{H_2SO_4} = 5\mathrm{I_3^+} + 8\mathrm{HSO_4^-} + 3\mathrm{H_3O^+}$

</details>
