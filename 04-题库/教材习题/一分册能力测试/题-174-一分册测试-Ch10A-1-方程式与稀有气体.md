# 方程式与稀有气体化合物

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第10章 氢、稀有气体和卤族元素·A卷第1题
> **分值**：12 分
> **教学层级**：竞赛

## 题目

写出下列反应的方程式：

**1-1** 将湿润的 $\mathrm{KClO_3}$ 和草酸（固体）混合加热到 $60^{\circ}\mathrm{C}$ 即得二氧化氯。

**1-2** 将 $\mathrm{F_2}$ 通入碱性的 $\mathrm{NaBrO_3}$ 溶液制备 $\mathrm{NaBrO_4}$。

**1-3** 氯气与 HgO 以摩尔比 1:1 反应制备 $\mathrm{Cl_2O}$。

**1-4** $\mathrm{XeF_4}$ 与 $\mathrm{SF_4}$ 得到两种化学惰性的分子。

**1-5** $\mathrm{XeF_2}$ 与 $\mathrm{SbF_5}$ 以 $2:1$ 反应得到一个离子化合物，指出阴、阳离子的立体构型。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**1-1** $2\mathrm{KClO_3} + \mathrm{H_2C_2O_4} = \mathrm{K_2CO_3} + 2\mathrm{ClO_2} + \mathrm{CO_2}\uparrow + \mathrm{H_2O}$

**1-2** $\mathrm{BrO_3^-} + \mathrm{F_2} + 2\mathrm{OH^-} = \mathrm{BrO_4^-} + 2\mathrm{F^-} + \mathrm{H_2O}$

**1-3** $2\mathrm{HgO} + 2\mathrm{Cl_2} = \mathrm{HgCl_2\cdot HgO} + \mathrm{Cl_2O}$

**1-4** $\mathrm{XeF_4} + 2\mathrm{SF_4} = 2\mathrm{SF_6} + \mathrm{Xe}$

**1-5** $2\mathrm{XeF_2} + \mathrm{SbF_5} = \mathrm{Xe_2F_3^+} + \mathrm{SbF_6^-}$；阳离子：V 型，阴离子：正八面体。

</details>
