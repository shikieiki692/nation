# 硅与同族水解比较

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·B卷第2题（12 分）

## 题目

2-1 解释硅没有类似于石墨的同素异形体。

2-2 $\mathrm{SiCl_4}$ 和 $\mathrm{SiF_4}$ 都能水解，但两者水解不完全相同，前者能比后者产生更多的 $\mathrm{H_2SiO_3}$，说明理由，请分别写出它们水解的化学方程式。

2-3 碳与硅为同族元素，$\mathrm{SiCl_4}$ 和 $\mathrm{CCl_4}$ 结构相似，且根据：

$\mathrm{CCl_4(l) + 2H_2O(l) = CO_2(g) + 4HCl(g)} \quad \Delta_r G_m^\ominus = -377\ \mathrm{kJ \cdot mol^{-1}}$

$\mathrm{SiCl_4(l) + 2H_2O(l) = SiO_2(s) + 4HCl(g)} \quad \Delta_r G_m^\ominus = -282\ \mathrm{kJ \cdot mol^{-1}}$

$\mathrm{CCl_4(l)}$ 的水解比 $\mathrm{SiCl_4(l)}$ 的水解在热力学上趋势更大。然而，在实际上，$\mathrm{SiCl_4}$ 能激烈水解，而 $\mathrm{CCl_4}$ 不发生水解，请说明理由。

2-4 实验室配制 $\mathrm{SnCl_2}$ 溶液时要采取哪些措施？说明原因（写出有关的方程式）。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**2-1** Si 的原子半径大于 C，如形成类似石墨结构中的 p-p π 键，3p 轨道重叠程度小于 2p 轨道，π 键键能和稳定性小于石墨中的 π 键，故不能形成类似石墨的同素异形体（Si 倾向于 sp³ 形成金刚石型三维网状结构而非 sp² 平面层状）。

**2-2** Si 是亲氟元素，$\mathrm{SiF_4}$ 水解生成的 HF 能与 $\mathrm{SiF_4}$ 继续作用生成 $\mathrm{H_2SiF_6}$，故 $\mathrm{SiF_4}$ 水解不完全，产生的 $\mathrm{H_2SiO_3}$ 较少。

水解方程式：

$\mathrm{SiCl_4 + 3H_2O = H_2SiO_3 + 4HCl}$

$\mathrm{3SiF_4 + 3H_2O = 2H_2SiF_6 + H_2SiO_3}$

**2-3** 动力学因素决定。

C 为第二周期元素，只有 2s、2p 轨道可以成键，最大配位数为 4。$\mathrm{CCl_4}$ 中 C 已达最高配位数（4 个 Cl 配位），无空轨道可以接受水分子的进攻配位，因此不易水解。

Si 为第三周期元素，Si 可以利用 3s、3p、3d 轨道成键，最大配位数大于 4。$\mathrm{SiCl_4}$ 可以利用 3d 空轨道接受水分子的进攻配位，形成 5 配位中间体 $\mathrm{[SiCl_4(OH_2)]}$，再经 OH 取代 Cl、连续脱 HCl 完成水解。

**2-4** 配制 $\mathrm{SnCl_2}$ 溶液的措施：

①加入 Sn 粒（锡粒），防止 $\mathrm{Sn^{2+}}$ 被空气中 $\mathrm{O_2}$ 氧化为 $\mathrm{Sn^{4+}}$ 或 $\mathrm{SnCl_6^{2-}}$；

②加入盐酸（HCl），防止 $\mathrm{Sn^{2+}}$ 水解生成 $\mathrm{Sn(OH)Cl}$：

$\mathrm{Sn^{2+} + H_2O + Cl^- \rightleftharpoons Sn(OH)Cl + H^+}$

加 HCl 增大 $\mathrm{H^+}$ 浓度使平衡左移，抑制水解。

</details>
