# 题-004-一分册测试-Ch1A-5-超导非整比化合物

## 题目

固体材料的制备中，常遇到缺陷和非整比（非化学计量）的化合物，$Na_{1-x+y}Ca_{x/2}LaTiO_{4}$ 就是非整比化合物，也是一类新的高温超导体。

它的制备方法如下：用 $\mathrm{NaLaTiO_{4}(I)}$ 作为母体化合物，和无水 $\mathrm{Ca(NO_{3})_{2}}$ 混合，封闭在耐热玻管中，加热到 $350^{\circ}\mathrm{C}$，维持3天，然后打开，取出样品，用水冲洗，直到没有杂质（用X射线衍射证实），得到 $Ca^{2+}$ 交换产物，记为 $Na_{1-x}Ca_{x/2}LaTiO_{4}(II)$，光谱实验证明，上述过程中(I)有86%的 $Na^{+}$ 被交换，所以产生离子空位（即部分原本 $Na^{+}$ 的位置空置了）。

将样品(II)放入 $300^{\circ}\mathrm{C}$ 下的钠蒸气中，经历数天，该物质由白色渐变为黑色，这是 $Na^{+}$ 插入空位所致，光谱实验证明，有 88% 的离子空位被 $Na^{+}$ 插入了，生成目标化合物 $\mathrm{Na}_{1-x+y}\mathrm{Ca}_{x/2}\mathrm{LaTiO}_{4}(\mathrm{III})$。试回答：

5-1 制备时，为何选用 $\mathrm{Ca(NO_{3})_{2}}$ 而不用其他钙盐？

5-2 产物(III)中 $x$ 和 $y$ 分别是多少？

5-3 当化合物(II)中的离子空位被 $\mathrm{Na}^{+}$ 插入时，为保持晶体的电中性，部分 Ti 的化合价发生了改变，求化合物(III)中高、低价态钛离子的个数比为何？

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

5-1 硝酸盐易分解完全，易彻底用水洗去。

5-2 $x = 0.86$；$y = 0.38$。

5-3 高、低价态钛离子（$\mathrm{Ti}^{4+}:\mathrm{Ti}^{3+}$）个数比 $= 0.62 : 0.38 = 31 : 19$。

### 解析

5-1 硝酸盐易分解完全，易彻底用水洗去（不引入杂质阴离子残留）。

5-2 交换产生空位：86% 的 $Na^{+}$ 被 $Ca^{2+}$ 交换，$x = 0.86$；按化学式 $Na_{1-x}Ca_{x/2}$，$Ca^{2+}$ 占据 $1/2 \times 0.86 = 0.43$；(II) 中空位分数为 $x/2 = 0.43$；钠蒸气插入其中 88%：$y = 0.88 \times 0.43 = 0.38$。

<!-- 校勘注: 原书 5-2 解答 OCR 碎块化为 x=0.86 / 1/2×0.86=0.43 / y=0.88×0.43=0.38 三个孤立式，上按数学自洽重排，未增删数据 -->

5-3 (III) 中每个化学式单元：$Na$ 为 $1-x+y = 0.14+0.38 = 0.52$，$Ca$ 为 $0.43$，$La$ 为 $1$。设 $n\ \mathrm{mol}\ Ti^{4+}$、$m\ \mathrm{mol}\ Ti^{3+}$（$n+m=1$），由电中性：

$$0.52 \times 1 + 0.43 \times 2 + 3 \times 1 + 4n + 3m = 8$$

解得 $n = 0.62$，$m = 0.38$，即高价（$\mathrm{Ti}^{4+}$）与低价（$\mathrm{Ti}^{3+}$）钛离子个数比为 $0.62:0.38 = 31:19$。
