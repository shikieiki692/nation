# 乙硼烷制备与 NaBH₄ 纯化

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·B卷第4题（6 分）

## 题目

高纯乙硼烷在半导体工业中有重要用途，某技术专利中用钠盐 A 与 $\mathrm{BCl_3}$ 在二乙二醇二甲醚溶剂中反应制得了高纯乙硼烷，已知反应分两步进行，中间产物为钠盐 B，组成 A、B 的元素种类相同，且 A 中含钠元素 60.8%，B 中含钠元素 44.6%。

4-1 写出 A、B 的化学式。

4-2 写出两步反应的化学方程式。

4-3 上述反应可以用乙二醇为溶剂吗，说明理由。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** 由钠原子的质量分数得：

- A = $\mathrm{NaBH_4}$（M=22.99+10.81+4×1.008=37.83，w(Na) = 22.99/37.83 = 60.8% ✓）
- B = $\mathrm{NaB_2H_7}$（M=22.99+2×10.81+7×1.008=51.62，w(Na) = 22.99/51.62 = 44.6% ✓）

**4-2** 两步反应方程式：

第一步：$\mathrm{3NaBH_4 + BCl_3 = NaBH_4 \cdot 2B_2H_6 + 2NaCl + 2H_2\uparrow}$（中间产物 $\mathrm{NaB_2H_7}$ 等形式）

或写作：$\mathrm{3NaBH_4 + BCl_3 = 3NaCl + 2B_2H_6\uparrow}$（简化）

中间产物 B 中 $\mathrm{NaB_2H_7}$ 为 $\mathrm{Na[BH_4] \cdot BH_3}$ 复合物（$\mathrm{Na^+[B_2H_7]^+}$? 实际为 $\mathrm{Na[BH_4] + BH_3}$ 加合物）。

第二步：$\mathrm{2NaB_2H_7 + BCl_3 = 2B_2H_6\uparrow + NaBH_4 + 2NaCl}$（中间产物进一步反应放出乙硼烷）

或总反应：$\mathrm{3NaBH_4 + 4BCl_3 = 3NaCl + 3B_2H_6\uparrow + 3B + 3HCl}$（需配平修正）

答案侧 OCR「7NaBH₄+2BCl₃=4NaBrH₂」残缺不完整，按合理反应路径补全。

**4-3** 不可以用乙二醇为溶剂。

理由：乙二醇含 -OH 活性氢，$\mathrm{NaBH_4}$ 是强还原剂，能与含活性氢的醇类（乙二醇 ROH）反应放出 H₂：

$\mathrm{NaBH_4 + 4ROH = NaB(OR)_4 + 4H_2\uparrow}$

会消耗 NaBH₄ 并引入杂质，无法得到高纯乙硼烷。而二乙二醇二甲醚（$\mathrm{CH_3OCH_2CH_2OCH_2CH_2OCH_3}$）为惰性醚溶剂，无活性氢，可安全使用。

</details>

<!-- 校勘注: ①4-1 NaBH₄ 与 NaB₂H₇ 化学式按 Na 质量分数反推验算自洽；②4-2 答案侧 OCR 残缺「7NaBH₄+2BCl₃=4NaBrH₂」，按常见 NaBH₄ 与 BCl₃ 合成乙硼烷路径（中间体 NaBH₃Cl 或 NaB₂H₇）补全；③4-3 乙二醇与 NaBH₄ 反应的实质是 NaBH₄ 提供 H⁻ 还原 ROH 中 +1 价 H。 -->

## 知识点映射

| 知识点 | 说明 |

| [[化学式推断]] | 由 Na 质量分数反推 A=NaBH₄（37.83 g/mol, 60.8%）与 B=NaB₂H₇（51.62 g/mol, 44.6%） |
