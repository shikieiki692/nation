# 题-120-一分册测试-Ch7A-4-保险粉Na2S2O4推断

## 题目

某物质 A 由三种常见的元素组成，某兴趣小组进行了如下实验：

![[6b8bafadfe6b446d60f64a2a2752963e3b6a2aad570ce764a44b615ba74e92df.jpg]]

（第 4 题图：3.48 g A 隔绝空气加热① → 气体 B 0.224 L（标准状况）＋盐 C＋盐 D；盐 C＋盐 D 加足量盐酸② → 溶液＋气体 B 0.448 L（标准状况）＋淡黄色沉淀 0.32 g）

又知，A 的焰色反应为黄色，盐 C 和盐 D 的组成元素和 A 相同，①和②处气体体积均在充分加热挥发后经干燥测定。

4-1 试确定 A 的化学式。

4-2 写出②中产生黄色沉淀反应的离子方程式。

4-3 A 的溶液还可以作分析化学中的吸氧剂，假设其溶液与少量氧气反应产生等物质的量的两种酸式盐，试写出该反应的化学方程式。

4-4 A 可用来除去废水（$\mathrm{pH}\sim8$）中的 $\mathrm{Cr(VI)}$，所得产物中含 A 某元素的价态以 (IV) 存在。写出反应的离子方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

4-1 ∵ A 焰色反应为黄色 ∴ A 是钠盐

∵ 标况下 B 0.224 L ∴ $n(\mathrm{B})=0.01\ \mathrm{mol}$

∵ A 可作吸氧剂 ∴ A 有还原性

∵ C 与 D 酸化后产生黄色沉淀 ∴ 有 S 元素，即 A 是钠的硫的含氧酸盐

$2\mathrm{Na}_{2}\mathrm{S}_{2}\mathrm{O}_{4} \longrightarrow 2\mathrm{Na}_{2}\mathrm{S}_{2}\mathrm{O}_{3} + \mathrm{O}_{2}\uparrow$，$m(\mathrm{Na}_{2}\mathrm{S}_{2}\mathrm{O}_{4}) = 0.01\times2\times(23\times2+32\times2+16\times4) = 3.48\ \mathrm{g}$。

【答案】

4-1 $\mathrm{Na}_2\mathrm{S}_2\mathrm{O}_4$

4-2 $\mathrm{S}_2\mathrm{O}_3^{2-} + 2\mathrm{H}^+ = \mathrm{S}\downarrow +\mathrm{SO}_2\uparrow +\mathrm{H}_2\mathrm{O}$。

4-3 $\mathrm{Na}_{2}\mathrm{S}_{2}\mathrm{O}_{4} + \mathrm{O}_{2} + \mathrm{H}_{2}\mathrm{O} = \mathrm{NaHSO}_{4} + \mathrm{NaHSO}_{3}$。

4-4 $2\mathrm{CrO}_{4}^{2-} + 3\mathrm{S}_{2}\mathrm{O}_{4}^{2-} + 4\mathrm{H}_{2}\mathrm{O} = 2\mathrm{Cr(OH)}_{3}\downarrow + 4\mathrm{SO}_{3}^{2-} + 2\mathrm{HSO}_{3}^{-}$

</details>
