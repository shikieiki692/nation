# C(CN)₃⁻ 阴离子结构推断

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·A卷第3题（10 分）

## 题目

实验室已经制出了 $\mathrm{C(CN)_3^-}$ 阴离子，关于该离子的结构有人提出了两种假设（i）三角锥形，（ii）平面三角形。

3-1 写出假设（i），假设（ii）的路易斯结构式，如存在共振结构，请一起写出。

3-2 如需要证实两种假设的正确性，可以测量一些什么数据，说明理由？

3-3 比较 $\mathrm{C(CN)_3^-}$ 与 $\mathrm{CH_3^-}$ 碱性，分析原因。

3-4 某离子化合物中碳元素含量为 44.4%，N 元素含量为 51.9%，求其可能的化学式。

假设（ii）平面三角形（sp² 杂化，C 孤对电子参与 p-π 共轭）：

![[caf771d462b2a36dcfc79b89d6c8cd621daa4f9ab09495dac39416a64ba5b343.jpg]]

**3-2** 测量 C-C-C 键角：若实测为 120°，则支持假设（ii）平面三角形（sp² 杂化）；若接近 109.5°，则支持假设（i）三角锥形（sp³ 杂化）。

也可通过测定离子是否具有永久偶极矩（平面 sp² 中心 C 上有孤对参与 p-π 离域，无孤对 → 偶极矩 0）或 ¹³C NMR 中心碳化学位移判断。

**3-3** $\mathrm{CH_3^-}$ 的碱性比较强，$\mathrm{C(CN)_3^-}$ 碱性较弱。原因：CN 为强吸电基（sp 杂化 N 上有孤对电子且电负性高），三个 CN 强烈分散中心 C 上的负电荷，使 $\mathrm{C(CN)_3^-}$ 稳定性增加、碱性减弱。

**3-4** 化学式 $\mathrm{NH_4C(CN)_3}$（即 $\mathrm{NH_4^+[C(CN)_3]^-}$）

验算：$M = 4 \times 14 + 4 \times 12 + 4 \times 1 = 56 + 48 + 4 = 108$

$w(\mathrm{C}) = 48/108 = 44.4\%$ ✓

$w(\mathrm{N}) = 56/108 = 51.85\%$ ✓

$w(\mathrm{H}) = 4/108 = 3.70\%$（剩余）

</details>
