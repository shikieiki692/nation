# 液氨溶剂与金属液氨溶液

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·B卷第4题（10 分）

## 题目

液氨是一种无色液体，沸点为 239.6 K，是研究最多的非水溶剂。

4-1 $\mathrm{PH_3}$ 的沸点为 185.3 K，为什么液氨的沸点比 $\mathrm{PH_3}$ 高？

4-2 某些金属可以溶解在液氨中，并显示一定的颜色，可用方程式为 $M + (x+y)\mathrm{NH_3}(l) \rightarrow M(\mathrm{NH_3})_x^+ + e(\mathrm{NH_3})_y^-$ 表示，金属液氨溶液可以用来制备一些物质，如①由 $\mathrm{O_2}$ 制备 $\mathrm{O_2^-}$，②由 $\mathrm{C_6H_5I}$ 制备联苯，请写出反应的方程式。

4-3 液氨中能发生许多有趣的反应，如① $\mathrm{ZnCl_2}$ 与 $\mathrm{NaNH_2}$ 反应可生成沉淀，$\mathrm{NaNH_2}$ 过量时沉淀将溶解；② $\mathrm{AgCl}$ 与 $\mathrm{Ba(NO_3)_2}$ 的液氨溶液混合可得到白色沉淀 $\mathrm{BaCl_2}$，写出反应的方程式并指出上述反应为什么能够发生。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** 氨分子之间存在氢键（$\mathrm{N—H\cdots N}$）而 $\mathrm{PH_3}$ 不存在氢键，故液氨沸点高于 $\mathrm{PH_3}$。

**4-2** ① $\mathrm{O_2 + e(NH_3)_y^- \longrightarrow O_2^- + yNH_3}$

② $2\mathrm{C_6H_5I + 2e(NH_3)_y^- \longrightarrow C_6H_5—C_6H_5 + 2I^- + 2yNH_3}$

**4-3** ① $\mathrm{ZnCl_2 + 2NaNH_2 = 2NaCl + Zn(NH_2)_2\downarrow}$（生成 $\mathrm{Zn(NH_2)_2}$ 沉淀）

$\mathrm{Zn(NH_2)_2 + 2NaNH_2 = Na_2[Zn(NH_2)_4]}$（NaNH₂ 过量，$\mathrm{Zn(NH_2)_2}$ 溶解形成四氨合锌酸钠配离子）

② $2\mathrm{AgCl + Ba(NO_3)_2 = BaCl_2\downarrow + 2AgNO_3}$

原因：$\mathrm{BaCl_2}$ 在液氨中的溶解度小于 $\mathrm{AgCl}$ 与 $\mathrm{Ba(NO_3)_2}$ 在液氨中的溶解度，故复分解反应能向生成 $\mathrm{BaCl_2}$ 沉淀方向进行。

</details>

<!-- 校勘注: ①4-2② 答案 OCR 残留「2Γ」应为「$2\mathrm{I^-}$」单字符识别错误，已径改；②4-3① 第二步答案 $\mathrm{Na_2Zn(NH_2)_4}$ 配位式按「中心 Zn²⁺ 配 4 个 NH₂⁻」理解；③4-3②「AgCl+Ba(NO₃)₂ 液氨反应」对比水中反应方向相反——水溶液中 BaCl₂ 微溶、AgCl 难溶，液氨中 AgCl 溶解度大（氨合 Ag⁺）、BaCl₂ 几乎不溶，复分解方向由溶解度差决定。 -->

## 知识点映射

| 知识点 | 说明 |
|---|---|
| [[氢键]] | NH₃ 分子间 N—H…N 氢键是液氨沸点（239.6 K）远高于 PH₃（185.3 K）的主因 |
| [[分子极性]] | NH₃ 极性分子且 N—H 键为强氢键供体，PH₃ 极性弱且 P—H 不形成强氢键 |
| [[氧化还原反应基础]] | 金属液氨溶液中溶剂化电子 e(NH₃)y⁻ 是强还原剂，还原 O₂ 得 O₂⁻、还原 C₆H₅I 得联苯 |
