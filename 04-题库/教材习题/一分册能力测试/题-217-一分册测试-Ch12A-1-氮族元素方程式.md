# 氮族元素方程式

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·A卷第1题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

**1-1** 肼与酸性高锰酸钾作用，得到无色无味的气体，写出反应的方程式。

**1-2** 将 $\mathrm{AsH_3}$ 通入 $\mathrm{HF-SbF_5}$ 体系中，可以得到一高对称性的阴离子和阳离子，写出反应方程式。

**1-3** 亚硝酸能氧化尿素，并释放出无污染的气体，写出反应的方程式。

**1-4** 银氨溶液久置常分解析出黑色沉淀（此过程中无电子转移），写出这一反应的化学方程式，并说明"久置"为什么会析出沉淀。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**1-1** $5\mathrm{N_2H_4} + 4\mathrm{MnO_4^-} + 12\mathrm{H^+} = 5\mathrm{N_2} + 4\mathrm{Mn^{2+}} + 16\mathrm{H_2O}$

**1-2** $\mathrm{AsH_3} + \mathrm{HF} + \mathrm{SbF_5} \longrightarrow [\mathrm{AsH_4^+}][\mathrm{SbF_6^-}]$

**1-3** $2\mathrm{HNO_2} + \mathrm{CO(NH_2)_2} \longrightarrow 2\mathrm{N_2} + \mathrm{CO_2} + 3\mathrm{H_2O}$

**1-4** $3[\mathrm{Ag(NH_3)_2}]\mathrm{OH} = \mathrm{Ag_3N}\downarrow + 5\mathrm{NH_3} + 3\mathrm{H_2O}$（或 $3[\mathrm{Ag(NH_3)_2}]\mathrm{OH} + 2\mathrm{H_2O} = \mathrm{Ag_3N}\downarrow + 5\mathrm{NH_3\cdot H_2O}$）

由于 $\mathrm{NH_3}$ 的挥发，久置后上述平衡向右移动，促使 $\mathrm{Ag_3N}$ 的生成并形成沉淀。

</details>
