# 碱金属碱土金属反应方程式

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第14章 碱金属、碱土金属·B卷第1题（10 分）
> （题号丢失：「（10 分） <<<」前无「第 1 题」标记，按位置重建大题号「第 1 题」）

## 题目

写出下列反应的方程式：

1-1 氢化锂与氮气一起加热生成两种二元化合物。

1-2 400 ℃ 下，足量氢化钠与钛的最高价氯化物作用得到钛单质。

1-3 500 ℃ 下，加热橙黄色的 $\mathrm{CsICl_2}$ 晶体。

1-4 氧化钾溶于液氨中。

1-5 叠氮化钠与亚硝酸钠作用制备氧化钠。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**1-1** $\mathrm{3LiH + N_2 \longrightarrow Li_3N + NH_3\uparrow}$

LiH 中 H⁻ 还原 N₂（N≡N → 部分变 N³⁻、部分变 H-N-H）：N 一部分结合 3 Li⁺ 得 Li₃N，一部分结合 3 H 得 NH₃。

**1-2** $\mathrm{4NaH + TiCl_4 \longrightarrow Ti + 4NaCl + 2H_2\uparrow}$

NaH 中 H⁻ 还原 Ti⁴⁺ → Ti⁰，H⁻ → H₂（自身氧化）。

**1-3** $\mathrm{CsICl_2 \xrightarrow{500\,℃} CsCl + ICl\uparrow}$

500 ℃ 热歧化：CsICl₂ = Cs⁺[ICl₂]⁻ = Cs⁺ + ICl₂⁻；ICl₂⁻ 热分解为 ICl + Cl⁻？实际按答案为 CsCl + ICl。

**1-4** $\mathrm{K_2O + NH_3 \longrightarrow KOH + KNH_2}$

液氨中 $\mathrm{K_2O}$ 与 $\mathrm{NH_3}$ 类比 $\mathrm{K_2O + H_2O = 2KOH}$ 反应：$\mathrm{O^{2-} + 2NH_3 = 2NH_2^- + H_2O}$ 后续形成 KOH+KNH₂。

**1-5** $\mathrm{3NaN_3 + NaNO_2 \longrightarrow 2Na_2O + 5N_2\uparrow}$

$\mathrm{N_3^-}$（N 0 价，不稳定）还原 $\mathrm{NO_2^-}$（N+3）为 $\mathrm{N_2}$（N 0），自身也被氧化为 $\mathrm{N_2}$：3×2 N (N₃⁻) + 1 N (NO₂⁻) = 7 N → 5 N₂ + 2 Na₂O。

</details>
