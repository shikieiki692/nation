# POCl₃ 水解与磷酸焦磷酸

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·B卷第8题（12 分）

## 题目

A 为重要的无机化工原料，广泛用于医药、燃料合成、半导体等行业。A 分子结构为四面体构型，具有两种不同的化学键长，分子量不超过 200。A 极易水解，在潮湿的空气中易发烟，生成两种常见的酸 B 和 C，若等摩尔的 B 和 C 分别用等浓度氢氧化钠溶液滴定，消耗氢氧化钠溶液的体积比为 3:1，形成正盐时溶液分别为碱性和中性。常温下 A 为无色易挥发性液体，电导率为 $1.6 \times 10^{-6}\ \Omega^{-1}\ \mathrm{cm^{-1}}$，约为纯水的 30 倍。酸 B 与 A 共热，可得到另一种酸 D，过量的硝酸银溶液滴入 D 的溶液中，可得到一种白色沉淀 E，元素分析表明，E 中银元素质量分数为 71.3%。

8-1 给出 A 的结构简式。

8-2 给出 A 在潮湿的空气中发烟的方程式。

8-3 解释 A 具有弱电导率的原因，并用方程式表示。

8-4 在药物合成中 A 可以与胺、醇、酚、酸等多类物质作用，写出 A 与足量乙醇反应的化学方程式，并给出所得有机产物的名称。

8-5 给出 D 和 E 的化学式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**8-1** A = $\mathrm{POCl_3}$（结构式 $\mathrm{O{=}P(—Cl)_3}$，P 采取 sp³ 杂化，P=O 与 3 个 P—Cl 两种键长）

**8-2** $\mathrm{POCl_3 + 3H_2O = H_3PO_4 + 3HCl\uparrow}$（水解生成两种酸 B=H₃PO₄ 与 C=HCl，HCl 在空气中发烟）

**8-3** 弱电导原因：和纯水一样，POCl₃ 存在弱的自偶电离：

$\mathrm{2POCl_3 \rightleftharpoons POCl_2^+ + POCl_4^-}$

电导率约为纯水 30 倍，说明自偶电离程度高于 H₂O。

**8-4** $\mathrm{POCl_3 + 3C_2H_5OH \longrightarrow (C_2H_5O)_3PO + 3HCl}$

有机产物名称：磷酸三乙酯（triethyl phosphate，TEP）

**8-5** D = $\mathrm{H_4P_2O_7}$（焦磷酸）；E = $\mathrm{Ag_4P_2O_7}$（焦磷酸银，白色沉淀）

E 验算：$M(\mathrm{Ag_4P_2O_7}) = 4 \times 108 + 2 \times 31 + 7 \times 16 = 432 + 62 + 112 = 606$；$w(\mathrm{Ag}) = 432/606 = 71.3\%$ ✓

D 与 A 共热生成反应：$\mathrm{2H_3PO_4 + POCl_3 = H_4P_2O_7 + 3HCl}$（POCl₃ 充当脱水剂/吸酸剂）

</details>

## 知识点映射

| 知识点 | 说明 |
|---|---|
| [[元素推断]] | 综合「四面体、两种键长、M≤200、水解得 B/C 用 NaOH 3:1、Ag 71.3%」多信息反推 A=POCl₃、D=H₄P₂O₇、E=Ag₄P₂O₇ |
| [[Lewis酸碱理论]] | POCl₃ 自偶电离 POCl₂⁺/POCl₄⁻（路易斯酸碱对）；POCl₃ 与 AlCl₃ 类似可作路易斯酸 |
| [[氧化还原反应基础]] | POCl₃ 水解非氧化还原，但 POCl₃+ROH 类亲核取代是磷酸酯合成的核心反应 |
