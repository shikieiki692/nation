# 溶剂理论与酸碱反应

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·B卷第3题（8 分）
> （题号丢失：B 卷第3题无「## 第3题」标记，按位置重建「第3题」）

## 题目

1905 年美国化学家富兰克林提出了酸碱的溶剂理论，人们发现许多溶剂能发生自电离过程，生成特征阳离子和特征阴离子，如 $2\mathrm{H_2O} \rightleftharpoons \mathrm{H_3O^+ + OH^-}$，$2\mathrm{NH_3} \rightleftharpoons \mathrm{NH_4^+ + NH_2^-}$，溶剂理论认为凡在溶剂中能产生（包括化学反应生成）特征阳离子的物质为溶剂酸，反之为溶剂碱。

3-1 试定义溶剂理论中的中和反应。

3-2 $\mathrm{NH_4Cl}$ 和 NaH 在液氨体系中的是酸还是碱，并用方程式来表示。

3-3 $\mathrm{SbF_5}$ 在 $\mathrm{BrF_3}$ 溶液中为酸，并画出电离所得阴离子的结构。

3-4 尿素在液氨中为弱酸，试写出电离方程式。液氨中尿素与氨基钠反应得到尿素盐试写出方程式。为什么该反应不能在水中进行。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**3-1** 特征阴阳离子反应生成溶剂分子。

**3-2** $\mathrm{NH_4Cl = NH_4^+ + Cl^-}$（在液氨中为酸，提供特征阳离子 $\mathrm{NH_4^+}$）

$\mathrm{NaH + NH_3 = H_2\uparrow + NH_2^- + Na^+}$（NaH 在液氨中为碱，生成特征阴离子 $\mathrm{NH_2^-}$）

**3-3** $\mathrm{SbF_5 + BrF_3 = BrF_2^+ + SbF_6^-}$

阴离子 $\mathrm{[SbF_6]^-}$：Sb 采取 sp³d² 杂化，F 位于正八面体六个顶点（VSEPR 6 对电子对，AX₆ 几何）。

**3-4** 弱酸电离：$\mathrm{CO(NH_2)_2 + NH_3 \rightleftharpoons NH_4^+ + NH_2CONH^-}$

与氨基钠反应：$\mathrm{NaNH_2 + NH_2CONH_2 = NH_2CONHNa + NH_3}$

不能在水中进行：氨基钠遇水分解（$\mathrm{NaNH_2 + H_2O = NaOH + NH_3}$），生成的 $\mathrm{OH^-}$ 会与尿素反应，无法得到尿素钠盐。

</details>
