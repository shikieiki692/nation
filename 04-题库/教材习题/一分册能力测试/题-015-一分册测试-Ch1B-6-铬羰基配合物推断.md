# 题-015-一分册测试-Ch1B-6-铬羰基配合物推断

## 题目

$CrCl_{3}$、金属铝和 CO 可在 $AlCl_{3}$ 的苯溶液中发生化学反应生成一种无色物质 A，A 又可和 $\mathrm{P(CH_{3})_{3}}$ 反应，生成物质 B，A 还可和钠汞齐反应生成物质 C，已知 A、B、C 的元素分析结果如下：

| 元素质量分数/% | Cr | P | C | 元素质量分数/% | Cr | P | C |
|---|---|---|---|---|---|---|---|
| A | 23.63 | | 32.75 | C | 21.84 | | 25.23 |
| B | 19.39 | 11.55 | 35.83 | | | | |

试写出：

6-1 结构简式 A \_\_\_\_；B \_\_\_\_；C \_\_\_\_。

6-2 将 A 中 Cr 原子换为 Mo 原子得物质 D，D 可与 PPh₃ 反应（Ph 为苯基），试写出反应的化学方程式 \_\_\_\_。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

6-1 A：$\mathrm{Cr(CO)_6}$；B：$\mathrm{Cr(CO)_5P(CH_3)_3}$；C：$\mathrm{Na_2[Cr(CO)_5]}$。

6-2 $\mathrm{Mo(CO)_6} + \mathrm{PPh_3} = \mathrm{Mo(CO)_5PPh_3} + \mathrm{CO}$

### 解析

在 A 中，碳元素质量分数为 32.75%，因 $n(\mathrm{C}):n(\mathrm{O}) = 1:1$，因此 $(32.75\%/12):(\omega(\mathrm{O})/16) = 1:1$，因此可以得到 $\omega(\mathrm{O}) = 43.67\%$。因为 $43.67\% + 23.63\% + 32.75\% = 100.05\%$。考虑到实验误差，因此 A 为 Cr、C 和 O 三种元素组成。根据质量分数可求得 $\mathrm{Cr}:\mathrm{C}:\mathrm{O} = (23.63\%/52):(32.75\%/12):(43.67\%/16) = 1:6:6$。因此 A 为 $\mathrm{Cr(CO)_6}$。

B 的考虑要复杂一点。由于 A 又可和 $\mathrm{P(CH_{3})_{3}}$ 反应，生成物质 B。根据质量守恒定律可知：B 可能有 Cr、C、O、P 和 H 元素，而且在考虑 B 时，C 元素应该有 CO 和 CH₃ 两部分。碰到这种情况，要通过假设法：若假设 B 中只有一种 P 原子，因此根据磷元素质量分数求出 B 的摩尔质量，再减去 Cr、P 元素摩尔质量，即可求出 C、O、H 的残基总量，最后用 CO 和 CH₃ 组合，得出 B 为 $\mathrm{Cr(CO)_{5}P(CH_{3})_{3}}$，满足 EAN 规则。

也可以这样计算：

因 B 中磷元素质量分数 11.55%，铬元素质量分数 19.39%，因此 $n(\mathrm{Cr}):n(\mathrm{P}) = (19.39\%/52):(11.55\%/31) = 1:1$，得到 $M(\mathrm{B}) = 31\ \mathrm{g\cdot mol^{-1}} \div 11.55\% = 268\ \mathrm{g\cdot mol^{-1}}$，因此 B 为 $\mathrm{Cr(CO)_{5}P(CH_{3})_{3}}$，满足 EAN 规则。

<!-- 校勘注: 原书此处残留孤立碎块「A: n(Cr):n(C) = (23.63%/52):」，属 6-1 A 推断的重复残片，与上文重复，已剔除 -->

A 为 $\mathrm{Cr(CO)_{6}}$ 满足 EAN 规则。设 C 为 $\mathrm{Na_{2x}[Cr(CO)_{6-x}]}$。根据 Cr 元素质量分数 $\omega(\mathrm{Cr})\% = 52/[23 \times 2x + 52 + 28 \times (6-x)] \times 100\% = 21.84\%$。解得 x = 1，即 C 为 $\mathrm{Na_{2}[Cr(CO)_{5}]}$。

<!-- 校勘注: 原书括号内作「28×(6-2x)」，按 x=1 回代得 24.8%≠21.84%，按 (6-x) 回代得 21.85% 吻合，判为 OCR 误植，已修正 -->

Mo 与 Cr 同一副族，因此 D 为 $\mathrm{Mo(CO)_{6}}$，符合 EAN 规则。D 与 $PPh_{3}$ 反应，生成物类似于 B，其反应为配体交换反应，生成 $\mathrm{Mo(CO)_{5}PPh_{3}}$。

<!-- 校勘注: 原书此处作「生成 Mo(CO)₅P(CH₃)₃」，与 6-2 问（PPh₃）及下方方程式矛盾，判为 OCR 串行，已修正为 PPh₃ -->

因此答案为：

$$6-1 \quad A: \mathrm{Cr(CO)_6};\ B: \mathrm{Cr(CO)_5P(CH_3)_3};\ C: \mathrm{Na_2[Cr(CO)_5]}$$

$$6-2 \quad \mathrm{Mo(CO)_6} + \mathrm{PPh_3} = \mathrm{Mo(CO)_5PPh_3} + \mathrm{CO}$$
