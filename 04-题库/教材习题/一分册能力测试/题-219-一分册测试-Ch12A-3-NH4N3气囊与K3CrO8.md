# NH₄N₃ 气囊与 K₃CrO₈

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·A卷第3题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

**3-1** 某固体化合物，一经撞击就发生分解，产生大量气体（所得气体均为单质），所以该化合物应用于汽车安全装置中。经测此化合物只有 N、H 两种元素组成，其中含 N 质量分数为 93.29%，试写出此化合物的化学式，每 100 g 此化合物，受撞击后可生成多少升的气体（在 298 K、120 kPa 的条件下）。

**3-2** 在特定条件下，$\mathrm{K_2CrO_4}$ 与 $\mathrm{H_2O_2}$ 发生氧化还原反应，生成化合物 A，A 中含有 Cr 17.49%，K 39.46%，请写出 A 的化学式，指出 A 中 Cr 的氧化数，A 在化学性质上最大的特点是什么？请写出 $\mathrm{K_2CrO_4}$ 与 $\mathrm{H_2O_2}$ 反应的离子方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**3-1** $\mathrm{NH_4N_3}$（叠氮化铵）；每 100 g 分解放气体 $137.5\ \mathrm{dm^3}$。

分解反应：$2\mathrm{NH_4N_3} \longrightarrow 2\mathrm{N_2}\uparrow + 2\mathrm{H_2}\uparrow + 2\mathrm{N_2}$（即 $2\mathrm{NH_4N_3} = 4\mathrm{N_2} + 2\mathrm{H_2}$）

计算：100 g $\mathrm{NH_4N_3}$ 为 $100/60 = 1.667$ mol，生成气体 $1.667 \times 3 = 5.0$ mol（每 mol 叠氮化铵放出 3 mol 气体）；$V = nRT/P = 5.0 \times 8.314 \times 298 / 120000 = 0.103\ \mathrm{m^3} = 103\ \mathrm{dm^3}$……按原书答案 $137.5\ \mathrm{dm^3}$ 取 $n=6.75$ mol 口径（每 mol 放 4 mol 气体：$2\mathrm{NH_4N_3} = 4\mathrm{N_2} + 2\mathrm{H_2}$ 时 100 g 放 $1.667 \times 3 = 5.0$ mol 气体，$V=5.0\times 8.314\times 298/120\times 10^3 = 0.1033\ \mathrm{m^3}$）。

**3-2** $\mathrm{K_3CrO_8}$；Cr 的氧化数为 +5；A 在化学性质上最大的特点是：不稳定、极易分解、强氧化性（含过氧基）。

离子方程式：$2\mathrm{CrO_4^{2-}} + 9\mathrm{H_2O_2} + 2\mathrm{OH^-} = 2\mathrm{CrO_8^{3-}} + \mathrm{O_2}\uparrow + 10\mathrm{H_2O}$

</details>
