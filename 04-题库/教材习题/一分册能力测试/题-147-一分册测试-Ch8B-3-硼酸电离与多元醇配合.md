# 硼酸电离与甘油螯合增酸

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第8章 共价键与分子结构·B卷第3题
> **分值**：8 分
> **教学层级**：竞赛
> **校勘**：原书 B-3 题号丢失(「## (8 分) <<<」前无「第3题」), 重建为「第3题」。

## 题目

硼酸的化学式为 $\mathrm{H_3BO_3}$,但它并非三元酸,而是一种一元弱酸。

**3-1** 写出硼酸电离的化学方程式,并指出反应前后硼原子的杂化形式。

**3-2** 在硼酸中加入乙二醇或甘油等邻二羟基多元醇后,酸性显著增强,请用化学方程式和简要的文字解释说明。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**3-1** 硼酸是一元弱酸, B 是缺电子原子(价层 3 对电子, 有空 2p 轨道), 在水中会结合水分子的孤对电子形成配位键, 由 sp² 平面三角形杂化转为 sp³ 四面体杂化, 电离出 H⁺:

$$\mathrm{H_3BO_3 + H_2O \rightleftharpoons B(OH)_4^- + H^+}$$

**反应前 B 原子: sp² 杂化;反应后 B 原子: sp³ 杂化。**

> 参考配位键示意(原答案侧图实际为 B-6 BrN₃ Lewis 结构, B-3 配位图位置错乱, 此处以文字描述代替): B 由平面三角形(sp²) 转为四面体(sp³)。

**3-2** 硼酸是路易斯酸, 多元醇(乙二醇/甘油) 是路易斯碱, 多元醇的邻二羟基同时与 B 原子配位形成稳定的五元或六元环螯合物, 释放出更多 H⁺。

以甘油(丙三醇) 为例:

$$\mathrm{H_3BO_3 + 2\,HOCH_2CH(OH)CH_2OH \rightarrow [B(OCH_2CH(O^-)CH_2O)_2] + 3H_2O + H^+}$$

> 参考反应图(原答案侧 b948fccb 显示 H₃BO₃ + 2 甘油 → [B(O-丙二醇-O)₂]⁻ + 3H₂O + H⁺):![[b948fccbbbd40cc9bbc4d94fac080d41b72aa8539ba72f70b6528c90c3bebf2e.jpg]]

由于形成了稳定的螯合物, 平衡向右移动, c(H⁺) 增大, 酸性显著增强。
