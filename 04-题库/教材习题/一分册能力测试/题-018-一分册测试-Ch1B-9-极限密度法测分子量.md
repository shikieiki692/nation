# 题-018-一分册测试-Ch1B-9-极限密度法测分子量

## 题目

实际气体在温度越高、压强越低时越接近理想气体，现在 273 K 时测得 1 g 某实际气体在不同压强下的体积如下表，请用作图法对得到的数据加以处理，求出该气体的分子量。

| $p/10^{5}$ Pa | 1.013 | 0.6755 | 0.5066 | 0.3378 | 0.2533 |
|---|---|---|---|---|---|
| $V/10^{-3}\ \mathrm{m^3}$ | 0.4334 | 0.6552 | 0.8771 | 1.321 | 1.765 |
| | | | | | |
| | | | | | |

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

该气体的分子量 $M \approx 50.5\ \mathrm{g\cdot mol^{-1}}$（作图外推法）。

### 解析

解法一：

应用极限密度法，由 $pV=mRT/M$

$$M=\left(\rho/p\right)_{p\to 0}RT\quad(\rho\ \text{代表密度})$$

作 $\rho/p \sim p$ 图，得 $p = 0$ 时的 $\rho/p$，代入上式即得 $M$。

| $p/10^{5}\ \mathrm{Pa}$ | 1.013 | 0.6755 | 0.5066 | 0.3378 | 0.2533 |
|---|---|---|---|---|---|
| $V/10^{-3}\ \mathrm{m^3}$ | 0.4334 | 0.6552 | 0.8771 | 1.321 | 1.765 |
| $\rho/10^{3}\ \mathrm{g\cdot m^{-3}}$ | 2.307 | 1.526 | 1.140 | 0.7570 | 0.5666 |
| $(\rho/p)/10^{-2}\ \mathrm{g\cdot m^{-3}\cdot Pa^{-1}}$ | 2.277 | 2.259 | 2.251 | 2.241 | 2.237 |

![[c934fb94c98b60ba79699b5ab886dfca6cc84c7780623a611d3f4ef0a2454024.jpg]]

第9题答图

由图得 p=0 时，$\rho/p=2.223\times10^{-2}\ \mathrm{g\cdot m^{-3}\cdot Pa^{-1}}$。故 $M=2.223\times10^{-2}\ \mathrm{g\cdot m^{-3}\cdot Pa^{-1}}\times8.314\ \mathrm{Pa\cdot m^{3}\cdot mol^{-1}\cdot K^{-1}}\times273\ \mathrm{K}=50.46\ \mathrm{g\cdot mol^{-1}}$

解法二：

| $pV/10^{2}\ \mathrm{Pa\cdot m^{3}}$ | 0.4390 | 0.4426 | 0.4443 | 0.4462 | 0.4471 |
|---|---|---|---|---|---|
| $p/10^{5}\ \mathrm{Pa}$ | 1.013 | 0.6755 | 0.5066 | 0.3378 | 0.2533 |

当 $p \to 0$ 时，用作图外推法得：$pV / 10^{2}\ \mathrm{Pa\cdot m^{3}} = 0.4500$

因为 $n=pV/(RT)=45.00/(8.314\times273)=0.0198\ (\mathrm{mol})$

$nM=\omega$，所以 $M=50.5\ (\mathrm{g\cdot mol^{-1}})$。
