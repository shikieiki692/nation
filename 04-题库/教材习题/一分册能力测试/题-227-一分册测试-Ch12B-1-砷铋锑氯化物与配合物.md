# 砷铋锑氯化物与配合物

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·B卷第1题
> （题号重建：B 卷大题后无「## (分值) >>>」分值标记，按位置重建「第1题」并省略分值行；B 卷首分值标在第2题 (6分) 处）

## 题目

完成下列反应方程式。

液态 AsCl₃ 中加入氯化铁发现导电性增强。

1-1 液态盐酸中，H₃AsO₃ 与 SnCl₂ 作用生成黑色的砷单质。

1-2 浓盐酸 Bi(NO₃)₃ 水解得到白色沉淀。

1-3 三苯基铋在浓盐酸中分解。

1-4 三本基硫 [题面残缺，OCR 截断；据上下文疑为「三苯基硫醚/胂/膦」等三苯基衍生物酸解，答案无对应条目]

1-5 液态二氧化硫中，AsF₅ 与 Bi 作用生成 Bi₅³⁺ 阳离子的配合物。

## 参考答案

<summary>📖 查看答案与解析</summary>

**（引言）** $\mathrm{AsCl_3 + FeCl_3 \longrightarrow [AsCl_2]^+ + [FeCl_4]^-}$

（说明：原文 OCR 记为 $\mathrm{AsCl_2^-}$，据电荷守恒与液态 AsCl₃ 加入路易斯酸 FeCl₃ 增强导电性的离子化机理，$\mathrm{AsCl_2}$ 应为阳离子形式，径改为 $\mathrm{[AsCl_2]^+[FeCl_4]^-}$）

**1-1** $3\mathrm{SnCl_2 + 12Cl^- + 2H_3AsO_3 + 6H^+ \longrightarrow 2As + 3[SnCl_6]^{2-} + 6H_2O}$

**1-2** $\mathrm{Bi(NO_3)_3 + H_2O \longrightarrow BiONO_3\downarrow + 2HNO_3}$

**1-3** $\mathrm{(C_6H_5)_3Bi + 3HCl \longrightarrow BiCl_3 + 3C_6H_6}$

**1-4** [题面残缺，答案无对应条目]

**1-5** $10\mathrm{Bi + 9AsF_5 \longrightarrow 2[Bi_5(AsF_6)_3] + 3AsF_3}$
