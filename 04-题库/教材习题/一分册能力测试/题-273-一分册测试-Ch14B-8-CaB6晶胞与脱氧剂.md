# CaB₆ 晶胞与脱氧剂

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第14章 碱金属、碱土金属·B卷第8题（9 分）

## 题目

B 与 Ca 在 900 ℃ 下反应得到晶体 X，X 的晶胞为立方晶系，Ca 占据八个顶点，硼原子在立方体内，晶胞边长为 415 pm，密度为 2.44 g·cm⁻³。X 在工业上有广泛的用途，例如，可以作为高纯铜生产的脱氧剂。

8-1 计算 X 的化学式。

8-2 写出一种 X 在脱氧过程中可能转化为的物质（盐类）。这些物质如何和反应成 $\mathrm{CaCl_2}$ 与 $\mathrm{NaBH_4}$ 在 500 ℃ 时反应。写出两个方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**8-1** 设 X 化学式为 $\mathrm{CaB_x}$。Ca 位于立方晶胞顶点，1 个晶胞中含 1 个 $\mathrm{CaB_x}$ 单位（Z=1）。

晶胞质量 = $Z \times M = \rho \times N_A \times a^3$

$1 \times (40.08 + 10.81x) = 2.44 \times 6.02 \times 10^{23} \times (415 \times 10^{-10})^3$

$40.08 + 10.81x = 2.44 \times 6.02 \times 10^{23} \times 7.148 \times 10^{-23} = 104.96$

$10.81x = 64.88$

$x = 6$

∴ **X = $\mathrm{CaB_6}$**

**8-2** 脱氧产物：$\mathrm{Ca(BO_2)_2}$ 或 $\mathrm{CaB_4O_7}$

CaB₆ 与 O₂ 反应（脱氧）：

$\mathrm{CaB_6 + 4O_2 = Ca(BO_2)_2 + 2B_2O_3}$

或简化为 $\mathrm{2CaB_6 + 7O_2 = 2CaB_4O_7}$（CaB₄O₇ 形式）

分离原因：$\mathrm{Ca(BO_2)_2}$ 密度小（~2.5 g/cm³）小于铜水（8.96 g/cm³），浮在表面便于分离。

反应方程式（用 CaO/B₂O₃/Mg 合成 CaB₆，或用 CaCl₂/NaBH₄ 合成）：

合成法 1（Mg 热还原）：$\mathrm{CaO + 3B_2O_3 + 10Mg = CaB_6 + 10MgO}$

合成法 2（NaBH₄ 还原）：$\mathrm{CaCl_2 + 6NaBH_4 = CaB_6 + 2NaCl + 4NaH + 10H_2\uparrow}$

</details>
