# 硫代硫酸钠制备与解毒

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第11章 氧族元素·A卷第5题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

硫代硫酸钠是一种重要的化工产品，用途十分广泛。

制备硫代硫酸钠的方法之一是把二氧化硫通入硫化钠和碳酸钠（摩尔比 2:1）的混合溶液。在反应过程中，先生成黄色的固体，其量先逐渐增多，然后又逐渐减少，溶液的 pH 值降到 7 左右时，溶液近于无色，反应已经完成。如果继续通入二氧化硫，溶液的 pH 值降到 5，又会有固体物质出现。

硫代硫酸钠在药剂中常用作解毒剂，可解卤素单质（如 $\mathrm{Cl_2}$）、重金属离子（如 $\mathrm{Hg^{2+}}$）及氰化物（如 KCN）中毒。

**5-1** 写出制备硫代硫酸钠的总反应以及和以上现象有关的化学方程式。

**5-2** $\mathrm{S_2O_3^{2-}}$ 为何种几何构型，与重金属离子形成配位键时配位原子是什么？

**5-3** 写出其中三个解毒有关的反应方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**5-1** 总反应：$2\mathrm{Na_2S} + 4\mathrm{SO_2} + \mathrm{Na_2CO_3} = 3\mathrm{Na_2S_2O_3} + \mathrm{CO_2}$

固态物质逐渐增多是因为 $\mathrm{SO_2} + \mathrm{Na_2S} + \mathrm{H_2O} = \mathrm{Na_2SO_3} + \mathrm{H_2S}$，$2\mathrm{H_2S} + \mathrm{SO_2} = 3\mathrm{S} + 2\mathrm{H_2O}$

固态物质减少是因为 $\mathrm{S} + \mathrm{SO_3^{2-}} = \mathrm{S_2O_3^{2-}}$

pH 在 5 左右又产生固态物质是因为 $\mathrm{S_2O_3^{2-}} + \mathrm{SO_2} + \mathrm{H_2O} = 2\mathrm{HSO_3^-} + \mathrm{S}$

**5-2** $\mathrm{S_2O_3^{2-}}$ 为四面体构型；S。

**5-3** $\mathrm{S_2O_3^{2-}} + 4\mathrm{Cl_2} + 5\mathrm{H_2O} = 2\mathrm{SO_4^{2-}} + 8\mathrm{Cl^-} + 10\mathrm{H^+}$

$2\mathrm{S_2O_3^{2-}} + \mathrm{Hg^{2+}} = \mathrm{Hg(S_2O_3)_2^{2-}}$

$\mathrm{S_2O_3^{2-}} + \mathrm{CN^-} = \mathrm{SCN^-} + \mathrm{SO_3^{2-}}$

</details>
