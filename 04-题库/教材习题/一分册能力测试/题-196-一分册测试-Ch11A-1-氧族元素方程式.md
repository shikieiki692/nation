# 氧族元素方程式

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第11章 氧族元素·A卷第1题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

完成下列反应式：

**1-1** 盐酸酸化多硫化铵 $\left(\mathrm{NH_4}\right)_2\mathrm{S_x}$ 溶液。

**1-2** 多硫化物 $S_5^{2-}$ 在碱性溶液中与 $BrO_3^-$ 反应。

**1-3** 硒与氢氧化钾溶液共热。

**1-4** 将 $SeO_2$ 溶于水，然后通 $SO_2$ 气体。

**1-5** $S_4N_4$ 与氯化亚锡(Ⅱ)乙醇溶液反应生成 $H_4S_4N_4$。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**1-1** $2\mathrm{HCl} + (\mathrm{NH_4})_2\mathrm{S_x} = \mathrm{H_2S}\uparrow + (x-1)\mathrm{S}\downarrow + 2\mathrm{NH_4Cl}$

**1-2** $3\mathrm{S_5^{2-}} + 16\mathrm{BrO_3^-} + 24\mathrm{OH^-} = 15\mathrm{SO_4^{2-}} + 16\mathrm{Br^-} + 12\mathrm{H_2O}$

**1-3** $3\mathrm{Se} + 6\mathrm{KOH} \xrightarrow{\triangle} \mathrm{K_2SeO_3} + 2\mathrm{K_2Se} + 3\mathrm{H_2O}$

**1-4** $2\mathrm{SO_2} + \mathrm{H_2SeO_3} + \mathrm{H_2O} = 2\mathrm{H_2SO_4} + \mathrm{Se}\downarrow$ 或 $\mathrm{SeO_2} + 2\mathrm{H_2O} + 2\mathrm{SO_2} = \mathrm{Se}\downarrow + 2\mathrm{H_2SO_4}$

**1-5** $\mathrm{S_4N_4} + 2\mathrm{SnCl_2} + 4\mathrm{C_2H_5OH} = \mathrm{H_4S_4N_4} + 2\mathrm{SnCl_2(OC_2H_5)_2}$

</details>
