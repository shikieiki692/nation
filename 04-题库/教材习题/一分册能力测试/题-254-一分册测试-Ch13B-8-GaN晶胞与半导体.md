# GaN 晶胞与半导体

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第13章 碳族元素和硼族元素·B卷第8题（12 分）

## 题目

某金属 A 的最高价氧化物与氨气在高温下反应作用得到一种重要的二元无机材料 X（氮元素的质量分数为 16.7%），晶体中氮原子作六方最密堆积，金属原子占据氮原子形成的同种空隙，空隙利用率为 50%，一层氮，一层 A 分层排布，且两种原子在 c 轴上投影相同。晶胞参数为 a = 0.3186 nm, c = 0.5186 nm。

8-1 推测 X 的化学式，写出合成 X 的方程式。

8-2 画出 X 的一个晶胞，写出晶胞内各原子的坐标。

8-3 计算 X 的密度。

8-4 预测 X 的一个用途。

8-5 X 也可以由含 A 60.7%（质量分数）的化合物 Y 与 $\mathrm{NH_3}$ 在高温下反应制备，Y 常温下为液态。写出反应的方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**8-1** 设 A_xN_y，N 16.7%：

$\dfrac{x M(\mathrm{A})}{y \times 14.01} = \dfrac{83.3\%}{16.7\%}$

当 x = 1, y = 1 时，$M(\mathrm{A}) = 14.01 \times 83.3/16.7 = 69.8$，合理元素为 Ga（69.72 g/mol）

∴ **X = GaN**

合成方程式：$\mathrm{Ga_2O_3 + 2NH_3 \xrightarrow{高温} 2GaN + 3H_2O}$

**8-2** 晶胞（N 六方最密堆积，Ga 占四面体空隙 50%）：

![[bb9ad4a6c7a147bb5328bcfc69d43554ec51c3c71fb035f93e1f18004149dc58.jpg]]

原子坐标（沿 c 轴投影，N 在 z=0, 1/2；Ga 在 z=1/8, 7/8）：

- N 顶点与内部：(0, 0, 0)、(2/3, 1/3, 1/2)
- Ga：(0, 0, 7/8)、(2/3, 1/3, 1/8)

**8-3** 密度计算：

六方晶胞体积：$V = \dfrac{\sqrt{3}}{2} a^2 c = \dfrac{\sqrt{3}}{2} \times (0.3186 \times 10^{-7})^2 \times 0.5186 \times 10^{-7}$

$V = 0.866 \times 1.015 \times 10^{-16} \times 0.5186 \times 10^{-7} = 4.56 \times 10^{-23}\ \mathrm{cm^3}$

晶胞含 2 个 GaN（Z=2）：

$\rho = \dfrac{Z M}{N_A V} = \dfrac{2 \times 83.73}{6.02 \times 10^{23} \times 4.56 \times 10^{-23}} = \dfrac{167.46}{27.45} = 6.10\ \mathrm{g/cm^3}$

（与答案 6.15 g/cm³ 接近，差由 V 计算精度）

**8-4** 用途：半导体材料、光电材料（GaN 与 Si 为等电子体，禁带宽度 3.4 eV，UV/蓝光 LED、激光器、高频高功率器件）

**8-5** Y = $\mathrm{Ga(CH_3)_3}$（三甲基镓）

验算 Ga 质量分数：$\dfrac{69.72}{69.72 + 3 \times 15.04} = \dfrac{69.72}{114.84} = 60.7\%$ ✓

反应方程式：$\mathrm{Ga(CH_3)_3 + NH_3 \longrightarrow GaN + 3CH_4}$

</details>
