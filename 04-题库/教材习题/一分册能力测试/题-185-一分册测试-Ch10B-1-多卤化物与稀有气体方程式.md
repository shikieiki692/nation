# 多卤化物与稀有气体方程式

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第10章 氢、稀有气体和卤族元素·B卷第1题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

写出下列反应的方程式：

**1-1** 多卤化物 $\mathrm{CsICl_2}$ 受热分解。

**1-2** 液态 $\mathrm{BrF_3}$ 中，$\mathrm{KBrF_4}$ 与 $\mathrm{SnBr_2F_{10}}$ 反应。

**1-3** $\mathrm{XeF_6}$ 与 $\mathrm{NH_3}$ 反应得到两种单质和一种铵盐。

**1-4** $\mathrm{Hg(CN)_2}$ 和 $\mathrm{HgCl_2}$ 为原料制备一种拟卤素。

**1-5** 电解 KI 制备 $\mathrm{KIO_3}$ 的电极反应。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**1-1** $\mathrm{CsICl_2} = \mathrm{CsCl} + \mathrm{ICl}$。

**1-2** $2\mathrm{K^+} + 2\mathrm{BrF_4^-} + [\mathrm{BrF_2^+}]_2[\mathrm{SnF_6}]^{2-} \longrightarrow \mathrm{K_2SnF_6} + 4\mathrm{BrF_3}$。

**1-3** $\mathrm{XeF_6} + 8\mathrm{NH_3} = \mathrm{Xe} + \mathrm{N_2} + 6\mathrm{NH_4F}$（按题给「两种单质和一种铵盐」补全）。

**1-4** $\mathrm{Hg(CN)_2 + HgCl_2 = Hg_2Cl_2 + (CN)_2}$。

**1-5** 阴极：$2\mathrm{H^+} + 2e^- = \mathrm{H_2}\uparrow$；阳极：$\mathrm{I^-} + 3\mathrm{H_2O} = \mathrm{IO_3^-} + 6\mathrm{H^+} + 6e^-$。

</details>
