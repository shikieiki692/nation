# 题-007-一分册测试-Ch1A-8-食品添加剂推断

## 题目

当今世界，食品生产几乎都离不开食品添加剂。部分欧盟许可的食品添加剂信息如下表。已知 X、Y 为不同的金属元素。

| 食品添加剂 | 元素成分 | 用途 | 生成过程 |
|---|---|---|---|
| N | 39.34% X | 保持口味 | |
| E171 | 59.94% Y | 食品颜色白色 | 见下方流程图 |
| E450(I) | 20.72% X | 烘焙面粉的成分 | $NaH_{2}PO_{4} \xrightarrow{170^{\circ}C} E450(I)$ |
| E500(II) | 27.37% X | 烘焙面粉的成分 | $N \xrightarrow{NH_{3} + CO_{2} + H_{2}O} E500(II)$ |

8-1 利用给出的晶胞参数，列式计算 E171 中最小重复单元的化学式的摩尔质量。

8-2 确定 B、D 的化学式，以及 E500(II)、E171 和 N 的化学式。注：标准状态下 D 是一种液体。

8-3 写出 $\mathrm{NaH_2PO_4}\xrightarrow{170^{\circ}\mathrm{C}}$ E450(I) 转化的反应方程式。

8-4 E450(I)、E500(II)和面粉的混合物就是发酵粉，广泛用于糕点生产中的无酵母面坯。请写出上述混合物能够使面坯疏松的反应方程式。

### 答案

8-1 $M = \dfrac{\rho V N_{\mathrm{A}}}{Z} = \dfrac{4.59^{2} \times 2.96 \times 10^{-24} \times 4.25 \times 6.02 \times 10^{23}}{2} = 79.8\ (\mathrm{g\cdot mol^{-1}})$。

8-2 B：$\mathrm{TiOSO_4}$；D：$\mathrm{TiCl_4}$；E500(II)：$\mathrm{NaHCO_3}$；E171：$\mathrm{TiO_2}$；N：$\mathrm{NaCl}$。

8-3 $2 \mathrm{NaH_2PO_4} \xrightarrow{170^{\circ}\mathrm{C}} \mathrm{Na_2H_2P_2O_7} + \mathrm{H_2O}$

8-4 $\mathrm{NaHCO_3} + \mathrm{Na_2H_2P_2O_7} = \mathrm{CO_2} + \mathrm{Na_3HP_2O_7} + \mathrm{H_2O}$

### 解析

8-1 $M = \frac{\rho V N_{\mathrm{A}}}{Z} = \frac{4.59^{2} \times 2.96 \times 10^{-24} \times 4.25 \times 6.02 \times 10^{23}}{2} = 79.8\ (\mathrm{g\cdot mol^{-1}})$

8-2 因 X 和 Y 是金属，E450(I) 由 $\mathrm{NaH_2PO_4}$ 制得，其中有 X 元素，故 X 只能是 Na 元素。物质 N 的摩尔质量 $M(N) = 23\ \mathrm{g\cdot mol^{-1}} \div 39.34\% = 58.5\ \mathrm{g\cdot mol^{-1}}$，再减去 Na 元素摩尔质量 $23\ \mathrm{g\cdot mol^{-1}}$，得到 $35.5\ \mathrm{g\cdot mol^{-1}}$，这是氯元素摩尔质量，因此 N 是 NaCl；$M(\mathrm{E450}) = 23\ \mathrm{g\cdot mol^{-1}} \div 20.72\% = 111\ \mathrm{g\cdot mol^{-1}}$，因此 E450 为 $\mathrm{Na_2H_2P_2O_7}$。

由质量守恒可知：E171 应为氧化物，$M(\mathrm{E171}) = 15x/(1-59.94\%)$。

<!-- 校勘注: 该式 OCR 不可读（原书作「15x/(1-59.94%)」），按 8-1 结果与 59.94% 数据自洽复原其义为 M(E171)=M(Y)/59.94%，即 M(Y)=0.5994×79.9≈47.9，得 Y=Ti -->

讨论：当 x=2 时，E171 为 $TiO_2$，是白色染料，因此 D 为 $TiCl_4$，B 为 $TiOSO_4$，以此满足标准状态下 D 是一种液体（流程图中 B 含 Y 29.93%，$47.9/159.9 = 29.96\%$；D 含 Y 25.24%，$47.9/189.9 = 25.22\%$，均吻合）。

因此答案为：

$$\mathrm{B}: \mathrm{TiOSO_4};\ \mathrm{D}: \mathrm{TiCl_4};\ \mathrm{E500(II)}: \mathrm{NaHCO_3};\ \mathrm{E171}: \mathrm{TiO_2};\ \mathrm{N}: \mathrm{NaCl}。$$

8-3 $\mathrm{NaH_2PO_4}$ 中存在—OH，加热时分子间脱水，因此化学反应方程式为：

$$2 \mathrm{NaH_2PO_4} \xrightarrow{170^{\circ}\mathrm{C}} \mathrm{Na_2H_2P_2O_7} + \mathrm{H_2O}$$

8-4 $\mathrm{Na_2H_2P_2O_7}$ 与 $\mathrm{NaHCO_3}$ 混合，能够使面坯疏松，说明产生了 $\mathrm{CO_2}$。从广义上讲，$\mathrm{Na_2H_2P_2O_7}$ 可视为酸，与 $\mathrm{NaHCO_3}$ 反应产生 $\mathrm{CO_2}$ 气体，因此其化学反应为：

$$\mathrm{NaHCO_3} + \mathrm{Na_2H_2P_2O_7} = \mathrm{CO_2} + \mathrm{Na_3HP_2O_7} + \mathrm{H_2O}$$
