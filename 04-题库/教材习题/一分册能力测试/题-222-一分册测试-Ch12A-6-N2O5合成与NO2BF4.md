# N₂O₅ 合成与硝鎓盐

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·A卷第6题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

A、B 为同主族短周期元素，A 最高价含氧酸根为平面构型，B 最高价含氧酸根为正四面体构型。将 A 的最高价含氧酸冷冻后与 B 的最高价氧化物混合，升温融化，维持温度 40℃，剧烈反应生成气体 C，氟化硼可与 C 以摩尔比 1:1 反应，生成 D，将 D 溶于硝基甲烷中，通入干燥的氟化氢气体可得到沉淀 E，E 的阳离子与 $\mathrm{CO_2}$ 为等电子体，阴离子为四面体构型。将 E 与氟化钠在 240℃反应得到产物 F，F 与固态 C 中的阴离子为等电子体。

**6-1** 写出 A 和 B 生成 C 的方程式。

**6-2** 给出 D、E、F 的结构简式。

**6-3** F 可苯剧烈反应，写出反应的方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**6-1** $2\mathrm{HNO_3} + \mathrm{P_2O_5}$（或 $\frac{1}{2}\mathrm{P_4O_{10}}$）$= \mathrm{N_2O_5} + 2\mathrm{HPO_3}$（A 为 N，B 为 P）

**6-2** D：$(\mathrm{NO_2})_2\mathrm{O}\cdot\mathrm{BF_3}$（即 N₂O₅ 与 BF₃ 的 1:1 加合物，写作 $\mathrm{NO_2^+[BF_3ONO_2]^-}$ 或按原书 $(\mathrm{NO_2})_2\mathrm{O}\rightarrow\mathrm{BF_3}$）；E：$\mathrm{NO_2^+[BF_4]^-}$；F：$\mathrm{NO_2F}$。

**6-3** $\mathrm{C_6H_6} + \mathrm{NO_2F} = \mathrm{C_6H_5NO_2} + \mathrm{HF}$

</details>
