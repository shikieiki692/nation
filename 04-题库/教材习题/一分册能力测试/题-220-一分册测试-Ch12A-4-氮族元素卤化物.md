# 氮族元素卤化物

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·A卷第4题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

氮族元素能形成多种卤化物。

**4-1** $\mathrm{NH_3}$ 和 $\mathrm{F_2}$ 在铜做催化剂下可直接得到一种三角锥结构的分子 A，另外一种产物是离子化合物 B，阳离子为正四面体构型。往 A 分子中通入 $\mathrm{F_2}$，在 $\mathrm{SbF_3}$ 中反应可得 C，阳离子也具有正四面体构型。请写出 A、B、C 的结构简式和 C 的阴离子空间构型。

**4-2** $\mathrm{F_2}$ 与 $\mathrm{SbF_3}$ 反应制得 D，在常温下是粘稠液体。结构测定是一种环状四聚体，通过 F 原子桥相缔合，请画出其结构；用 $^{19}\mathrm{F}$ 的核磁共振可以确定 D 中有几种化学环境不同的 F 原子。

**4-3** $\mathrm{PCl_5}$ 在加压下于 $148^{\circ}\mathrm{C}$ 液化，形成一种能导电的熔体，此时测得 P—Cl 键键长为 198 pm 和 206 pm，试分析其原因，并画出有关微粒的结构。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**4-1** A：$\mathrm{NF_3}$；B：$\mathrm{NH_4F}$；C：$[\mathrm{NF_4^+}][\mathrm{SbF_6^-}]$；C 的阴离子为**正八面体**构型。

**4-2** D 为 $(\mathrm{SbF_5})_4$：4 个 SbF₅ 单元通过 F 桥联成环状四聚体（Sb—F—Sb 桥键），每个 Sb 六配位。

![[aeac0d929dc72a63168d4c052b7dcd5aa25f7a2df60fee9b75d80a99d462c2df.jpg]]

（NF₃ 相关结构答图）

$^{19}\mathrm{F}$ NMR 可确定 D 中 F 原子环境数：桥氟与端氟共 **2 种**化学环境（高对称环中同种氟等价）。

**4-3** $\mathrm{PCl_5}$ 熔体发生自偶电离：$2\mathrm{PCl_5}(l) \rightleftharpoons \mathrm{PCl_4^+} + \mathrm{PCl_6^-}$，故能导电且出现两种 P—Cl 键长：$\mathrm{PCl_4^+}$ 中 P—Cl 键较短（正四面体，sp³），$\mathrm{PCl_6^-}$ 中 P—Cl 键较长（正八面体，sp³d²）。

![[05fd6ffb52fe0f690ff3b81f7439b1c4b8a216420c0bd6fc383068c155ae0994.jpg]]

（PCl₄⁺ 与 PCl₆⁻ 结构答图）
