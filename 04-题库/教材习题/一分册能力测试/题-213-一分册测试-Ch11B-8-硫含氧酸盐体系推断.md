# 硫含氧酸盐体系推断

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第11章 氧族元素·B卷第8题
> **分值**：12 分
> **教学层级**：竞赛

## 题目

某元素 X，在空气中燃烧，生成 $\mathrm{XO_2}$，$\mathrm{XO_2}$ 与 $\mathrm{PCl_5}$ 反应，生成 $\mathrm{XOCl_2}$。在室温下 $\mathrm{XO_2}$ 与 $\mathrm{O_2}$ 反应生成 $\mathrm{XO_3}$ 很难，但是在有催化剂存在下，此反应进行得很快。$\mathrm{XO_2}$ 溶解在碱性溶液中，得到 $\mathrm{XO_3^{2-}}$，在有过量的 $\mathrm{XO_2}$ 存在下的 $\mathrm{XO_3^{2-}}$ 溶液可用锌还原到 $\mathrm{X_2O_4^{2-}}$，但 $\mathrm{X_2O_4^{2-}}$ 静止后就分解成 $\mathrm{X_2O_3^{2-}}$ 和 $\mathrm{HXO_3^-}$。当 $0.1741\ \mathrm{g}\ \mathrm{X_2O_4^{2-}}$ 的钠盐与过量的硝酸银的氨溶液反应，得到 $0.2158\ \mathrm{g}$ 银的沉淀。

**8-1** 通过计算确定 X 是何种元素。

**8-2** 写出上述各反应的方程式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**8-1** 生成的银的物质的量为：$0.2158 \div 107.9 = 2.000 \times 10^{-3}\ \mathrm{mol}$。$0.1741\ \mathrm{g}\ \mathrm{X_2O_4^{2-}}$ 失去的电子数为 $2.000 \times 10^{-3}\ \mathrm{mol}$，即 $\frac{0.1741}{22.99 \times 2 + 2M(\mathrm{X}) + 4 \times 16.00} \times n = 2.000 \times 10^{-3}$。$n = 2$ 时，$M(\mathrm{X}) = 32$ 为合理解，X 为硫。

**8-2** $\mathrm{S} + \mathrm{O_2} = \mathrm{SO_2}$；$\mathrm{SO_2} + \mathrm{PCl_5} = \mathrm{SOCl_2} + \mathrm{POCl_3}$；$2\mathrm{SO_2} + \mathrm{O_2} \xrightarrow{\text{催化剂}} 2\mathrm{SO_3}$；$\mathrm{SO_2} + 2\mathrm{OH^-} = \mathrm{SO_3^{2-}} + \mathrm{H_2O}$；$\mathrm{SO_2} + \mathrm{SO_3^{2-}} + \mathrm{Zn} + 2\mathrm{H^+} = \mathrm{Zn^{2+}} + \mathrm{H_2O} + \mathrm{S_2O_4^{2-}}$；$2\mathrm{S_2O_4^{2-}} + \mathrm{H_2O} = \mathrm{S_2O_3^{2-}} + 2\mathrm{HSO_3^-}$；$\mathrm{S_2O_4^{2-}} + 2\mathrm{Ag(NH_3)_2^+} + 4\mathrm{OH^-} = 2\mathrm{SO_3^{2-}} + 2\mathrm{Ag} + 4\mathrm{NH_3} + 2\mathrm{H_2O}$。

</details>
