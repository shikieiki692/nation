# 液氨非水溶剂体系

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第12章 氮族元素·A卷第2题
> **分值**：10 分
> **教学层级**：竞赛

## 题目

液氨是研究较多的非水溶剂之一，液氨体系与水溶液体系有很多相似的性质。

**2-1** 写出液氨自偶电离的方程式。

**2-2** 已知在液氨中能发生下列两个反应：

$$\mathrm{NH_4Cl} + \mathrm{KNH_2} = \mathrm{KCl} + 2\mathrm{NH_3}$$

$$2\mathrm{NH_4I} + \mathrm{Pb(NH_2)_2} = \mathrm{PbI_2} + 3\mathrm{NH_3}$$

请写出能在水溶液中发生的与上两个反应相当的反应方程式。

**2-3** 试完成并配平下列反应方程式（反应①②中 M 为碱金属）：

① $M + NH_3 \xrightarrow{NH_3(l)}$

② $M + NH_4Cl \xrightarrow{NH_3(l)}$

③ $\mathrm{M(NH_2)_2} \xrightarrow{\triangle}$

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**2-1** $2\mathrm{NH_3} \rightleftharpoons \mathrm{NH_4^+} + \mathrm{NH_2^-}$

**2-2** $\mathrm{HCl} + \mathrm{KOH} = \mathrm{KCl} + \mathrm{H_2O}$（对应 $\mathrm{NH_4Cl}$ + $\mathrm{KNH_2}$ = $\mathrm{KCl}$ + 2$\mathrm{NH_3}$：$\mathrm{NH_4^+}$ 相当于 $\mathrm{H_3O^+}$、$\mathrm{NH_2^-}$ 相当于 $\mathrm{OH^-}$、$\mathrm{NH_3}$ 相当于 $\mathrm{H_2O}$）

$2\mathrm{HI} + \mathrm{Pb(OH)_2} = \mathrm{PbI_2} + 2\mathrm{H_2O}$（对应 $2\mathrm{NH_4I}$ + $\mathrm{Pb(NH_2)_2}$ = $\mathrm{PbI_2}$ + 3$\mathrm{NH_3}$）

**2-3** ① $2\mathrm{M} + 2\mathrm{NH_3} = 2\mathrm{MNH_2} + \mathrm{H_2}$

② $2\mathrm{M} + 2\mathrm{NH_4Cl} = 2\mathrm{MCl} + \mathrm{H_2} + 2\mathrm{NH_3}$

③ $\mathrm{M(NH_2)_2} \xrightarrow{\triangle} \mathrm{MNH} + \mathrm{NH_3}$（M 为碱土金属，如 Ca(NH₂)₂ → CaNH + NH₃）

</details>
