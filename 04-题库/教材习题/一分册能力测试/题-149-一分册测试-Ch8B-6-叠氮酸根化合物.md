# 叠氮酸根 NaN₃ 与 Br₂/NOCl 反应

> **来源**：高中化学竞赛教程第一分册·配套能力测试 第8章 共价键与分子结构·B卷第6题
> **分值**：8 分
> **教学层级**：竞赛
> **校勘**：原书 6-1 答案侧配图 113243b9 实为 BrN₃ Lewis 结构(标题「第 6 题 6-1」), 与 3-1 配位图位置错乱无碍。

## 题目

叠氮酸根作为一种纯多氮阴离子,能形成许多有趣的化合物。

**6-1** $\mathrm{NaN_3}$ 与 $\mathrm{Br_2}$ 反应生成橙色液体 $\mathrm{BrN_3}$, 写出反应的化学方程式和 $\mathrm{BrN_3}$ 的 Lewis 结构式。

**6-2** $\mathrm{NaN_3}$ 与 NOCl 反应生成淡黄色固体 $\mathrm{N_4O}$, 写出反应的化学方程式和 $\mathrm{N_4O}$ 的 Lewis 结构式。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**6-1** $\mathrm{BrN_3}$ 的结构可以参考 $\mathrm{HN_3}$ 的成键情况(N—N—N 直线骨架,端基 N 与 Br 以单键相连, N=N 双键与 N—N 单键的共振):

$$\mathrm{NaN_3 + Br_2 \longrightarrow BrN_3 + NaBr}$$

**$\mathrm{BrN_3}$ 的 Lewis 结构式**(主共振式, Br 端基 N 上有正形式电荷):

```
  ··
:N=N⁺=N:                ··  ··
  |        ↔              :N⁻—N⁺≡N:
 ·· ··                  
 :Br:                       |
                          ··  ··
                          :Br:
```

> 参考答图:![[113243b9a4957543e979ef5681c21efabc91721d4fedc9fc4804881e9aaf3315.jpg]] (该图实际归属本小问, 答案原书位置错乱附于 B-3 后)

**6-2** $\mathrm{NaN_3}$ 与 NOCl 反应可看作复分解反应:

$$\mathrm{NaN_3 + NOCl \longrightarrow N_4O + NaCl}$$

产物 $\mathrm{N_4O}$ 可认为是 $\mathrm{N_3^-}$ 离子和 $\mathrm{NO^+}$ 离子结合形成的共价化合物。Lewis 结构式(含 3 个等价共振式):

$$
:\mathrm{N{=}N^+{-}N^-/\dot{N}{=}\ddot{O}:}
\leftrightarrow
:\mathrm{N{=}N^+{-}N^-/\dot{N}{=}\ddot{O}:}
\leftrightarrow
:\mathrm{N^-{=}N^+{=}N^-/\dot{N}{=}\ddot{O}:}
$$

N₃⁻ 端通过 N 与 NO⁺ 的 N 之间形成 N—N 单键(或 N=N 双键) 桥连, 整体保持直线或近直线型。
