# 题-0407-2 磁铁矿 CO 还原的热力学与气体平衡（24 分）

## 题目

高温下 CO 还原磁铁矿：

Fe₃O₄(s) + 4 CO(g) ⇌ 3 Fe(s) + 4 CO₂(g)

298 K 热力学数据：

| 物质 | Fe(s) | Fe₃O₄(s) | CO(g) | CO₂(g) |
|---|---|---|---|---|
| ΔfH_m°/kJ·mol⁻¹ | 0 | −1118.4 | −110.5 | −393.5 |
| S_m°/J·mol⁻¹·K⁻¹ | 27.3 | 145.3 | 197.7 | 213.8 |

气体视为理想气体，固体活度为 1，p° = 1 bar，近似认为 ΔfH_m° 和 S_m° 不随温度变化。

2-1 计算 1000 K 下反应的 ΔrH_m°、ΔrS_m°、ΔrG_m° 和平衡常数 K°。（8 分）

2-2 1000 K、总压 1.00 bar，管式炉中放有过量 Fe₃O₄，通入 p_CO,in = 0.100 bar（其余为 Ar，不含 CO₂）的混合气体，求出口气体达平衡时的 p_CO 和 p_CO₂。（5 分）

2-3 入口改为 p_CO,in = 0.100 bar、p_CO₂,in = 0.0200 bar（其余 Ar，总压 1.00 bar），判断反应方向，求平衡出口 p_CO、p_CO₂；若每次通过 1.000 mol 入口混合气体，求生成 Fe 的质量。（5 分）

2-4 仍用 2-2 的入口气体，但管中只有 2.00 g Fe₃O₄，每次通过 1.000 mol 入口混合气体。判断 Fe₃O₄ 是否足以使气体达到 2-2 的平衡组成，并求实际出口 p_CO、p_CO₂ 及生成 Fe 的质量。（6 分）

## 解答

**2-1** ΔrH_m° = 4(−393.5) − [−1118.4 + 4(−110.5)] = −13.6 kJ·mol⁻¹
ΔrS_m° = 3(27.3) + 4(213.8) − [145.3 + 4(197.7)] = 1.0 J·mol⁻¹·K⁻¹
ΔrG_m° = ΔrH_m° − TΔrS_m° = −13.6 − 1000×1.0×10⁻³ = −14.6 kJ·mol⁻¹
ln K° = 14.6×10³/(8.314×1000) = 1.756，K° = 5.79

**2-2** K° = (p_CO₂/p°)⁴/(p_CO/p°)⁴，故 p_CO₂/p_CO = 5.79^(1/4) = 1.551
反应前后气体总物质的量不变，Ar 不参与：p_CO + p_CO₂ = 0.100 bar
解得 p_CO = 0.0392 bar，p_CO₂ = 0.0608 bar

**2-3** 入口 p_CO₂/p_CO = 0.0200/0.100 = 0.200 < 1.551，反应向右进行。
p_CO + p_CO₂ = 0.120 bar，联立比例式：p_CO = 0.0470 bar，p_CO₂ = 0.0730 bar。
每通过 1.000 mol 入口气体（总物质的量不变，分压数值=物质的量分数）：Δn(CO₂) = 0.0730 − 0.0200 = 0.0530 mol
n(Fe) = (3/4)Δn(CO₂) = 0.0398 mol，m(Fe) = 0.0398 × 55.85 ≈ 2.22 g

**2-4** 若达 2-2 平衡组成，每通过 1.000 mol 入口气体需消耗 Fe₃O₄：n = (1/4)×0.0608 = 0.0152 mol，m = 0.0152 × 231.55 = 3.52 g > 2.00 g，Fe₃O₄ 不足，气体不能达平衡组成。
实际：n(Fe₃O₄) = 2.00/231.55 = 8.64×10⁻³ mol，消耗 CO 4n = 0.0346 mol，生成 CO₂ 0.0346 mol。
出口：n_CO = 0.100 − 0.0346 = 0.0654 mol，n_CO₂ = 0.0346 mol → p_CO = 0.0654 bar，p_CO₂ = 0.0346 bar。
n(Fe) = 3n(Fe₃O₄) = 0.0259 mol，m(Fe) = 1.45 g。
检验：p_CO₂/p_CO = 0.529 < 1.551，若还有 Fe₃O₄ 反应仍会继续，故出口组成由固体限量决定。

## 解析要点

- 2-2~2-4 构成"平衡态—固体足量/不足量"的完整梯度训练；反应前后气体计量数相等（Δν=0）使分压比直接等于浓度比，是简化关键；
- 2-4 的"检验"步骤值得讲：用平衡常数反推固体是否耗尽。
