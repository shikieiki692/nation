# 0407-9 TiO₂ 碳氯化的气–固耦合多重平衡（21 分）

## 题目

TiO₂(s) 的碳氯化在 1200 K、体积 1.00 L 的容器中进行，初始通入 n₀(Cl₂) = 2.81×10⁻² mol，加入足量 TiO₂(s) 与碳。平衡时测得总压为 3.30 bar。已知该温度下：

① TiO₂(s) + 2Cl₂(g) ⇌ TiCl₄(g) + O₂(g)，Kp₁
② TiO₂(s) + C(s) + 2Cl₂(g) ⇌ TiCl₄(g) + CO₂(g)，Kp₂ = 25.0
③ C(s) + CO₂(g) ⇌ 2CO(g)，Kp₃ = 4.00

R = 0.08314 L·bar·mol⁻¹·K⁻¹，p° = 1 bar。设平衡分压 Cl₂ = x，O₂ = y，CO₂ = a，CO = c，TiCl₄ = b（bar）。

**9-1** 写出初始压力 x₀ = n₀RT/V 的值；用 x、y、a、b、c 写出 Kp₁、Kp₂、Kp₃ 的表达式（固体活度取 1）。

**9-2** 由元素守恒与平衡常数联立，求 x、y、a、b、c。

**9-3** 计算 Kp₁ 与 Cl₂ 的平衡转化率 α(Cl₂)。

**9-4** 若容器中加入的碳只有 0.0100 mol，判断体系能否达到 9-2 的平衡；若不能，计算此时 O₂ 与 TiCl₄ 分压的比值 p(O₂)/p(TiCl₄)，并求它与 9-2 平衡值的比。

## 解答

**9-1**

x₀ = n₀RT/V = 2.81×10⁻² × 0.08314 × 1200 / 1.00 = **2.80 bar**

Kp₁ = (b·y)/x²，Kp₂ = b/a = 25.0，Kp₃ = c²/b = 4.00（均以 p° = 1 bar 为基准的分压数值代入）。

**9-2**

守恒方程组（Cl 守恒、O 守恒、总压）：
- Cl：2x + 4b = 2x₀ → x + 2b = 2.80
- O 与 C 合并：x + 2y = 2.80；2y = 2a + 2b + c
- 总压：x + y + a + b + c = 3.30
- 由 Kp₂：b = 25a；由 Kp₃：c² = 4b

代入解得：**c = 1.00，b = 0.250，a = 0.0100，y = 0.760，x = 1.28 bar**（若 9-1 取 x₀ = 2.803 bar，则 x = 1.298，y = 0.7529，a = 9.861×10⁻³，b = 0.2465，c = 0.9930，两组结果均给分）。

**9-3**

Kp₁ = b·y/x² = 0.250×0.760/1.28² = **4.64×10⁻³**

由 Cl 守恒，消耗 Cl₂ 分压 = 2b = 2.80 − x = 2.80 − 1.28 = 1.52 bar，故 α(Cl₂) = 1.52/2.80 = **54.3%**

**9-4**

9-2 平衡中碳以 CO₂ + CO 形式存在：p_C = a + c = 1.25 bar，n(C) = 1.25 × 1.00/(0.08314 × 1200) = 0.0125 mol > 0.0100 mol，碳量不足，**不能**达到 9-2 平衡。

无碳（反应②③无法进行）时仅反应①进行：Kp₁ = s²/(2.80 − 2s)² = 4.64×10⁻³，s/(2.80 − 2s) = 0.0681，s = 0.168 bar，即 p(O₂) = p(TiCl₄) = 0.168 bar，比值 p(O₂)/p(TiCl₄) = 1。

与 9-2 平衡值之比：0.760/0.168 = **4.52**。

## 解析要点

- 本题是竞赛物化的"多重平衡 + 元素守恒"压轴模型：三个反应共享物种，独立变量数 = 物种数 − 独立反应数，列守恒方程比设反应进度更稳。
- 9-2 的关键观察：Kp₂ = 25 与 Kp₃ = 4 把 b、a、c 串成一条链（b = 25a，c = 2√b），守恒方程立刻降维；先解 c、b、a，再回代 y、x。
- 9-4 的"碳不足"判断用碳原子守恒反算需求（0.0125 mol > 0.0100 mol），是典型的"守恒判据"考法；无碳时只剩反应①，且由反应①的化学计量 p(O₂)/p(TiCl₄) ≡ 1，比值退化为 Kp₁ 开方的函数。
- 易错点：守恒方程漏掉 CO 中的碳；转化率分母用总压而非初始 Cl₂ 分压。
