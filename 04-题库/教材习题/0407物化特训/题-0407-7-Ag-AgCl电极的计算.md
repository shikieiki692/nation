# 0407-7 Ag/AgCl 电极与银氨配位溶解度的计算（14 分）

## 题目

已知 φ°(Ag⁺/Ag) = 0.7996 V，φ°(AgCl/Ag) = 0.22234 V，β₂[Ag(NH₃)₂⁺] = 1.6×10⁷，T = 298.15 K，F = 96485 C·mol⁻¹。

**7-1（6 分）** 计算 AgCl 的溶度积 Ksp；计算 Ag/AgCl 电极在 0.1000 mol·L⁻¹ KCl 溶液中的电极电势。

**7-2（8 分）** 向 0.1000 mol·L⁻¹ 氨水中加入过量 AgCl 固体，充分搅拌至平衡。求 AgCl 在该溶液中的溶解度 S（以 mol·L⁻¹ 表示，并换算为 g·L⁻¹）。

## 解答

**7-1**

由 Ag⁺ + e⁻ ⇌ Ag 与 AgCl(s) + e⁻ ⇌ Ag + Cl⁻ 两电对的电势相等关系：

Ksp = exp[(F/RT)(φ°(AgCl/Ag) − φ°(Ag⁺/Ag))]
= exp[96485/(8.314×298.15) × (0.22234 − 0.7996)]
= **1.75×10⁻¹⁰**

在 0.1000 mol·L⁻¹ KCl 中，[Cl⁻] = 0.1000 mol·L⁻¹：

φ = φ°(AgCl/Ag) − (RT/F)ln[Cl⁻]
= 0.22234 − (8.314×298.15/96485)·ln 0.1000
= 0.22234 + 0.05916 = **0.2815 V**

**7-2**

溶解度 S = [Ag⁺] + [Ag(NH₃)₂⁺]；溶解的 Ag⁺ 全部以 Cl⁻ 等摩尔出现，故 [Cl⁻] = S。

由 Ksp：[Ag⁺] = Ksp/S；由 β₂：[Ag(NH₃)₂⁺] = β₂[Ag⁺][NH₃]²。

游离氨浓度：[NH₃] = 0.1000 − 2(S − Ksp/S)（每溶解 1 mol AgCl 以配离子形态存在时消耗 2 mol NH₃）。

代入：

S = Ksp/S + β₂·(Ksp/S)·(0.1000 − 2S + 2Ksp/S)²

因 Ksp ≪ S，近似 [NH₃] ≈ 0.1000 − 2S，且 Ksp/S 项可略：

S ≈ β₂·(Ksp/S)·(0.1000 − 2S)²
S² = 1.6×10⁷ × 1.75×10⁻¹⁰ × (0.1000 − 2S)² = 2.80×10⁻³(0.1000 − 2S)²

开方：S = 0.0529(0.1000 − 2S)，解得 **S = 4.78×10⁻³ mol·L⁻¹**

换算：S = 4.78×10⁻³ × 143.3 = **0.685 g·L⁻¹**

## 解析要点

- 7-1 的核心关系：同一金属的难溶盐电极与简单离子电极的标准电势之差由 Ksp 联系，Δφ° = (RT/F)ln Ksp，符号方向要由电极反应写法推定，不要死记。
- Nernst 方程中 Ag/AgCl 电极对 Cl⁻ 是还原型，故 φ = φ° − (RT/F)ln[Cl⁻]，[Cl⁻] 越大 φ 越低。
- 7-2 是"配位溶解"经典题型：溶解度 S 同时满足物料守恒（[Cl⁻] = S）、配位平衡（β₂）与氨的消耗关系三个约束；因 Ksp 很小，可对 [NH₃] 作合理近似，但 S 与游离氨同数量级时近似必须迭代检验。
- 易错点：把 [Ag(NH₃)₂⁺] 当 S 而丢掉游离 [Ag⁺]；或氨消耗按 1:1 配（实为 2:1）。
