# 0407-8 铜的碘量法与沉淀诱导的氧化还原（13 分）

## 题目

已知 φ°(Cu²⁺/Cu⁺) = 0.159 V，φ°(I₂/I⁻) = 0.5355 V，Ksp(CuI) = 1.27×10⁻¹²，β(I₃⁻) = 698。向 0.1000 mol·L⁻¹ Cu(NO₃)₂ 溶液中加入初始浓度为 c 的 KI，反应：

2Cu²⁺ + 4I⁻ → 2CuI↓ + I₂

平衡时测得 [Cu²⁺] = 0.0200 mol·L⁻¹，且体系中仍有 CuI(s) 存在。

**8-1（3 分）** 标准态下 Cu²⁺ 的氧化性弱于 I₂，为什么不能直接氧化 I⁻？说明本反应能够进行的两个原因。

**8-2（10 分）** 求初始 KI 浓度 c。

## 解答

**8-1**

① 反应生成的 Cu⁺ 被 I⁻ 沉淀为 Ksp 极小的 CuI，[Cu⁺] 被压至极低，由 Nernst 方程 φ(Cu²⁺/Cu⁺) = φ° + 0.0592 lg([Cu²⁺]/[Cu⁺])，[Cu⁺] 降低使该电对电势大幅升高，超过 I₂/I⁻；② 生成的 I₂ 与过量 I⁻ 结合为 I₃⁻，游离 I₂ 浓度降低，φ(I₂/I⁻) 相应下降，两者共同使反应正向进行。

**8-2**

设平衡时 [I⁻] = y，[Cu⁺] = Ksp/y。

Cu²⁺/Cu⁺ 与 I₂/I⁻ 两电对平衡时电势相等：

0.159 + 0.0592 lg(0.0200/(Ksp/y)) = 0.5355 + (0.0592/2) lg([I₂]/y²)

由 Ksp = 1.27×10⁻¹²，代入化简可得 [I₂] = 4.64×10⁷ y⁴。

又 [I₃⁻] = β[I₂][I⁻] = 698 × 4.64×10⁷ y⁵。

Cu²⁺ 消耗量 = 0.1000 − 0.0200 = 0.0800 mol·L⁻¹，故

[I₂] + [I₃⁻] = ½ × 0.0800 = 0.0400（I₂ 与 I₃⁻ 中的碘来自 I⁻ 的 2 电子氧化，每氧化 2 个 I⁻ 得 1 个 I 原子进入 I₂/I₃⁻）

代入：4.64×10⁷y⁴(1 + 698y) = 0.0400，解得 **y = [I⁻] = 3.90×10⁻³ mol·L⁻¹**

于是 [I₂] = 4.64×10⁷×(3.90×10⁻³)⁴ = **1.07×10⁻² mol·L⁻¹**，[I₃⁻] = 698 × 1.07×10⁻² × 3.90×10⁻³ = **2.93×10⁻² mol·L⁻¹**。

碘元素守恒（初始 c = 游离 I⁻ + I₂ 中 2 倍 + I₃⁻ 中 3 倍 + 进入 CuI 的碘）：

c = [I⁻] + 2[I₂] + 3[I₃⁻] + 0.0800
= 3.90×10⁻³ + 2(1.07×10⁻²) + 3(2.93×10⁻²) + 0.0800
= **0.193 mol·L⁻¹**

## 解析要点

- 8-1 是碘量法测铜的原理题："条件电势"思想——沉淀（CuI）与配位（I₃⁻）两个副反应同时改变两个电对的实际电势，使表观上 φ° 小的电对也能驱动反应。答题必须点出两条原因，各占分。
- 8-2 的计算骨架是"双电势相等 + 元素守恒"：先由 φ_Cu = φ_I 建立 [I₂] 与 [I⁻] 的关系，再由碘的氧化量守恒建立第二个方程，联立解出游离碘浓度，最后做全碘守恒。
- 易错点：I₂ + I₃⁻ 的总量按 ½(Cu²⁺消耗) 而不是按 1:1；CuI 沉淀消耗的 I⁻ 是 0.0800 mol·L⁻¹，守恒中不可遗漏。
