# 题-0407-4 氨气吸收与缓冲液计算（12 分）

## 题目

298.15 K 下氨气在水中的亨利定律：p(NH₃) = k·[NH₃(aq)]，k = 1.60×10⁻² atm·L·mol⁻¹；pK_a(NH₄⁺) = 9.25。

4-1 空气中氨气分压 p(NH₃) = 1.00×10⁻⁴ atm，与纯水充分接触达平衡，估算水溶液的 pH。（4 分）

4-2 设总氨浓度 C_N = [NH₃(aq)] + [NH₄⁺]，用 [H⁺] 和 K_a 写出未质子化氨的分布系数 δ(NH₃) = [NH₃(aq)]/C_N。（2 分）

4-3 现有 1.00 L、0.100 mol·L⁻¹ NH₄Cl 溶液，与 p(NH₃) 恒定为 2.00×10⁻³ atm 的气体充分接触，忽略体积变化，求最终溶液 pH 和氨气吸收量。（6 分）

## 解答

**4-1** [NH₃(aq)] = p/k = 1.00×10⁻⁴/(1.60×10⁻²) = 6.25×10⁻³ mol·L⁻¹
K_a = 10⁻⁹·²⁵ = 5.62×10⁻¹⁰，K_b = K_w/K_a = 1.78×10⁻⁵
p(NH₃) 恒定（开放体系），未质子化 NH₃ 浓度由亨利定律锁定，故 [NH₄⁺] ≈ [OH⁻]：
[OH⁻]² = K_b·[NH₃(aq)] = 1.78×10⁻⁵×6.25×10⁻³，[OH⁻] = 3.33×10⁻⁴ mol·L⁻¹
pH = 14.000 − pOH = 10.52

**4-2** 由 [NH₄⁺] = [NH₃][H⁺]/K_a：
δ(NH₃) = 1/(1 + [H⁺]/K_a) = K_a/(K_a + [H⁺]) = 1/(1 + 10^(pK_a−pH))

**4-3** [NH₃(aq)] = p/k = 2.00×10⁻³/(1.60×10⁻²) = 0.125 mol·L⁻¹（恒定）
[NH₄⁺] = [NH₃][H⁺]/K_a，[Cl⁻] = 0.100 mol·L⁻¹
电荷守恒：[NH₄⁺] + [H⁺] = [Cl⁻] + [OH⁻]，即 0.125h/K_a + h = 0.100 + K_w/h
解得 [H⁺] = 4.50×10⁻¹⁰ mol·L⁻¹，pH = 9.35
平衡 [NH₄⁺] = 0.125×4.50×10⁻¹⁰/(5.62×10⁻¹⁰) = 0.10002 mol·L⁻¹
C_N = 0.125 + 0.10002 = 0.225 mol·L⁻¹，气相吸收 ΔC_N = 0.225 − 0.100 = 0.125 mol·L⁻¹
溶液体积 1.00 L，吸收氨 0.125 mol。

## 解析要点

- 4-1 的关键洞察是"开放体系"：NH₃(aq) 浓度被亨利定律固定，不能用普通弱碱公式自洽求解，必须走 [OH⁻]² = K_b·c 的简化；
- 4-3 是"固定气相分压 + 电荷守恒"型多重平衡，解法具有通用地位（可迁移到 H₂S 吸收、CO₂ 固定分压等题）。
