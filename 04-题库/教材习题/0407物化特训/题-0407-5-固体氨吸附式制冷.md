# 题-0407-5 固体氨吸附式制冷与热化学储能（28 分）

## 题目

低温余热驱动的固体吸附式制冷装置由盐床、冷凝器和蒸发器组成，盐床中：

SrCl₂·8NH₃(s) ⇌ SrCl₂·NH₃(s) + 7 NH₃(g)

加热盐床时氨解吸并在冷凝器中液化；冷却后液氨在蒸发器中蒸发并重新被吸收，产生制冷。测得 ΔrG°(330.0 K) = −30.20 kJ·mol⁻¹，ΔrG°(360.0 K) = −58.40 kJ·mol⁻¹。液氨沸点 T_b = 239.82 K（饱和蒸气压 100.0 kPa），题设温度范围内 Δ_vapH_m = 23.30 kJ·mol⁻¹ 视为常数。

5-1 求该反应的 ΔrH_m° 和 ΔrS_m°。（4 分）

5-2 在 360.0 K 下：
5-2-1 计算氨平衡压力 p_eq。（4 分）
5-2-2 若盐床中氨实际压力为 1.20 MPa，计算此时 ΔrG 并判断反应方向。（4 分）

5-3：
5-3-1 计算液氨 298.15 K 下的饱和蒸气压；判断盐床 360.0 K、冷凝器 298.15 K 时，解吸出的氨能否在冷凝器中自发液化。（4 分）
5-3-2 为使解吸出的氨恰好能在 298.15 K 冷凝器中液化，盐床至少加热至多少温度？（4 分）

5-4 制冷阶段蒸发器维持 263.15 K，盐床降至 300.0 K：
5-4-1 分别计算蒸发器中液氨饱和蒸气压和盐床 300.0 K 下的氨平衡压力，判断氨能否从蒸发器蒸发并被盐床自发吸收。（4 分）
5-4-2 忽略显热、散热及传质阻力，认为逆向进行 1 mol 反应时有 7 mol 液氨在蒸发器中完全汽化，计算理想制冷循环 COP = 蒸发器吸热/盐床再生需热，并指出实际装置 COP 通常低于此值的两个原因。（4 分）

## 解答

**5-1** 由 ΔrG°/T 对 1/T 的直线关系（ΔrG° = ΔrH° − TΔrS°，联立两温度）：
ΔrH° = [−58.40/360.0 − (−30.20/330.0)] / (1/360.0 − 1/330.0) = 280.0 kJ·mol⁻¹
ΔrS° = (280.0 − (−30.20))/330.0 = 0.9400 kJ·mol⁻¹·K⁻¹ = 940.0 J·mol⁻¹·K⁻¹

**5-2-1** K_p° = (p_NH₃/p°)⁷；360.0 K 时 K_p° = exp(58.40×10³/(8.314×360.0)) = 2.98×10⁸
p_eq = p°·(K_p°)^(1/7) = 100.0×(2.98×10⁸)^(1/7) = 1.624×10³ kPa

**5-2-2** Q_p = (1.20/0.1000)⁷ = 12.0⁷
ΔrG = ΔrG° + RT ln Q_p = −58.40 + (8.314×360.0/1000)·ln(12.0⁷) = −6.34 kJ·mol⁻¹ < 0
正反应自发，氨合物解吸。

**5-3-1** ln(p₂/p₁) = −(Δ_vapH_m/R)(1/T₂ − 1/T₁)：
ln(p_sat/100.0) = −(23.30×10³/8.314)(1/298.15 − 1/239.82)，p_sat(298.15 K) = 983.8 kPa
p_eq(360.0 K) = 1.624 MPa > p_sat(298.15 K) = 0.9838 MPa，故氨能在冷凝器中液化。

**5-3-2** 令 p_eq = 983.8 kPa，由 0 = ΔrH° − TΔrS° + 7RT ln(p/p°)：
T_min = 280.0×10³ / (940.0 − 7×8.314×ln(983.8/100.0)) = 347.0 K

**5-4-1** p_sat(263.15 K) = 281.8 kPa（同法克-克方程）
ΔrG°(300.0 K) = 280.0 − 300.0×0.9400 = −2.00 kJ·mol⁻¹
p_eq = p°·exp(−ΔrG°/(7RT)) = 100.0·exp(2.00×10³/(7×8.314×300.0)) = 112.1 kPa
281.8 kPa > 112.1 kPa，氨能从蒸发器蒸发并被盐床自发吸收。

**5-4-2** Q_cold = 7×Δ_vapH_m = 7×23.30 = 163.1 kJ；Q_regen = ΔrH° = 280.0 kJ
COP = 163.1/280.0 = 0.5825
实际 COP 偏低的原因：盐床与装置升温需显热；装置存在散热、传热温差和传质阻力。

## 解析要点

- 5-1 用两组 (T, ΔrG°) 联立解 ΔrH°/ΔrS°，避开基尔霍夫积分，是竞赛标准做法；
- 反应气体计量数 7 使 K_p 与 p_eq 成 7 次方关系，开 7 次方是核心运算；
- "能否液化/能否蒸发"统一翻译为 p_eq 与 p_sat 的比较，本题为相变方向判断的完整样板。
