# 题-0407-3 偶氮甲烷热分解动力学（20 分）

## 题目

偶氮甲烷气相分解（一级基元反应，不考虑逆反应）：

CH₃N=NCH₃(g) → C₂H₆(g) + N₂(g)

记偶氮甲烷为 A。150 ℃ 时 k = 2.00×10⁻⁴ s⁻¹；初始分压 p_A,0 = 60.0 kPa，p_Ar,0 = 40.0 kPa，Ar 不参与反应，气体均视为理想气体。

3-1 计算 150 ℃ 下反应的半衰期。（2 分）

3-2 150 ℃ 下反应多长时间后，A 的分压降为 15.0 kPa？（3 分）

3-3 150 ℃ 下反应 5.00×10³ s 后，求 p(A)、p(C₂H₆)、p(N₂) 及体系总压。（7 分）

3-4 另在 120 ℃ 下配制相同初始分压的气体，反应 1.00×10⁴ s 后测得体系总压 127.3 kPa。求 120 ℃ 下的 k′ 及反应的活化能 E_a。（8 分）

## 解答

**3-1** t₁/₂ = ln2/k = 0.693/(2.00×10⁻⁴) = 3.47×10³ s

**3-2** 恒容恒温下 p_A/p_A,0 = c_A/c_A,0，一级积分式 ln(p_A/p_A,0) = −kt
p_A/p_A,0 = 15.0/60.0 = 1/4，t = ln4/(2.00×10⁻⁴) = 6.93×10³ s

**3-3** kt = 2.00×10⁻⁴×5.00×10³ = 1.00，p_A = 60.0e⁻¹ = 22.1 kPa
Δp_A = 60.0 − 22.1 = 37.9 kPa，故 p(C₂H₆) = p(N₂) = 37.9 kPa，p_Ar = 40.0 kPa
p_tot = 22.1 + 37.9 + 37.9 + 40.0 = 137.9 kPa

**3-4** 设 120 ℃ 下消耗的分压量为 x：p_tot = (60.0−x) + x + x + 40.0 = 100.0 + x = 127.3 kPa，x = 27.3 kPa
p_A = 32.7 kPa，p_A/p_A,0 = 0.545
k′ = −(1/t)·ln(p_A/p_A,0) = −(1/1.00×10⁴)·ln 0.545 = 6.07×10⁻⁵ s⁻¹
Arrhenius 方程（T = 423.15 K，T′ = 393.15 K）：
ln(k′/k) = −(E_a/R)(1/T′ − 1/T)
E_a = 5.50×10⁴ J·mol⁻¹ = 55.0 kJ·mol⁻¹

## 解析要点

- 恒容气相一级反应中分压可直接替代浓度（p ∝ n ∝ c），这是竞赛常用简化；
- 3-4 由总压变化反推转化率是经典套路：注意每消耗 1 mol A 总压增加 1 mol。
