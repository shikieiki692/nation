# 题-0407-6 铝-空气电池与铝资源循环（25 分）

## 题目

铝-空气电池理论能量密度高。25 ℃、1 bar 下标准电动势 2.71 V，负极由 Al(s) 与产物 Al₂O₃(s) 组成。

从废弃电池中回收 Al(OH)₃，其溶解平衡涉及：
- Al(OH)₃(s) ⇌ Al(OH)₃(aq)，K_s = 1.00×10⁻⁶；K_sp[Al(OH)₃] = 3.00×10⁻³⁴
- Al(OH)₃(s) + OH⁻(aq) ⇌ Al(OH)₄⁻(aq)，K_c = 1.00×10⁻²

6-1 25 ℃、1 bar 下电池以 50.0 mA 放电 12.0 h，写出电池总反应式，计算负极的质量变化。（3 分）

6-2 电池在海拔 5000 m 处使用，当地 −20 ℃，空气中 O₂ 摩尔分数 21.0%。已知 −20 ℃、1 bar 下电池反应 ΔrG_m° = −3140 kJ·mol⁻¹，大气压与温度、海拔关系近似为 p/bar = 1.013(1 − 0.0065·h[m]/(T[K] + 0.0065·h[m]))^5.257。计算此时电池的电动势。（2 分）

6-3 保持 p(H₂) = 1.00 bar，使 Al₂O₃(s) + 3 H₂(g) → 2 Al(s) + 3 H₂O(g) 在 1000 ℃ 下热力学自发，求水蒸气分压上限。已知 1000 ℃、1 bar 下 ΔfG_m°(Al₂O₃,s) = −1360 kJ·mol⁻¹，ΔfG_m°(H₂O,g) = −192 kJ·mol⁻¹。（3 分）

6-4 忽略 Al(III) 其他水解平衡：
6-4-1 计算 25 ℃ 下 Al(OH)₃(s) 在稀酸或稀碱溶液中溶解度的最小值及对应 pH。（6 分）
6-4-2 确定 Al(OH)₃(aq) 是溶液中 Al(III) 浓度最高存在形式时的 pH 范围。（3 分）

6-5 用 pH = 4.50 的稀盐酸配制 Al(OH)₃(s) 饱和溶液，25 ℃ 过滤。取滤液一份用缓冲液调至 pH = 7.00（忽略体积变化），求沉淀出的铝占原滤液总溶解铝的摩尔百分比。（5 分）

6-6 25 ℃、1 bar 下，E°(Al³⁺/Al) = −1.66 V，E°(O₂/H₂O) = 1.23 V，又知铝-空气电池反应标准电动势 2.71 V。计算反应 Al(OH)₃(s) → ½Al₂O₃(s) + 3/2 H₂O(l) 的标准吉布斯自由能变。（3 分）

## 解答

**6-1** 总反应 4Al + 3O₂ → 2Al₂O₃；1 mol O₂ ~ 4 mol e⁻。
Q = It = 0.0500×12.0×3600 = 2160 C；n(O₂) = 2160/(4×96485) = 5.60×10⁻³ mol
Δm = 5.60×10⁻³×32.00 = +0.179 g（负极增重；若按消耗铝计 0.2013 g 也给满分，取决于生成的 Al₂O₃ 是否留在电极上）

**6-2** T = 253.15 K：p = 1.013×(1 − 0.0065×5000/(253.15 + 0.0065×5000))^5.257 = 0.537 bar
p(O₂) = 0.210×0.537 = 0.1128 bar
Q = 1/(p_O₂/p°)³，ΔrG_m = ΔrG_m° − 3RT ln(p_O₂/p°) = −3140×10³ − 3×8.314×253.15×ln 0.1128 = −3.126×10⁶ J·mol⁻¹
n = 12，E = 3.126×10⁶/(12×96485) = 2.70 V

**6-3** ΔrG_m° = 3(−192) − (−1360) = 784 kJ·mol⁻¹；Q = (p_H₂O/p°)³（p_H₂ = 1.00 bar）
自发条件：0 > ΔrG_m° + 3RT ln(p_H₂O/p°)
p(H₂O) = exp(−784000/(3×8.314×1273.15)) = 1.90×10⁻¹¹ bar，即 p(H₂O) < 1.90×10⁻¹¹ bar。上限极低 → 氢气直接还原氧化铝热力学上极其困难。

**6-4-1** 总溶解铝 S = [Al³⁺] + [Al(OH)₃(aq)] + [Al(OH)₄⁻] = (K_sp/K_w³)[H⁺]³ + K_s + K_w·K_c/[H⁺]
取最小值：dS/d[H⁺] = 0 → [H⁺]₀ = (K_c·K_w⁴/(3K_sp))^(1/4) = 5.77×10⁻⁷ mol·L⁻¹，pH₀ = 6.24
此时 [Al³⁺] = 5.77×10⁻¹¹、[Al(OH)₄⁻] = 1.73×10⁻¹⁰、[Al(OH)₃(aq)] = 1.00×10⁻⁶ mol·L⁻¹
S_min ≈ 1.00×10⁻⁶ mol·L⁻¹

**6-4-2** Al(OH)₃(aq) 占主导要求两侧均小于它：
[Al³⁺] < K_s：边界 [H⁺]₁ = (K_w³·K_s/K_sp)^(1/3) = 1.49×10⁻⁵，即 pH > 4.83
[Al(OH)₄⁻] < K_s：边界 [H⁺]₂ = K_c·K_w/K_s = 1.00×10⁻¹⁰，即 pH < 10.00
故 **4.83 < pH < 10.00**

**6-5** pH = 4.50：[H⁺] = 3.16×10⁻⁵
[Al³⁺] = K_sp[H⁺]³/K_w³ = 9.49×10⁻⁶；[Al(OH)₃] = 1.00×10⁻⁶；[Al(OH)₄⁻] = K_c·K_w/[H⁺] = 3.16×10⁻¹²
S₄.₅₀ = 1.05×10⁻⁵ mol·L⁻¹
pH = 7.00：[Al³⁺] = 3.00×10⁻¹³；[Al(OH)₃] = 1.00×10⁻⁶；[Al(OH)₄⁻] = 1.00×10⁻⁹
S₇.₀₀ = 1.001×10⁻⁶ mol·L⁻¹
沉淀摩尔百分比 Ω = 1 − S₇.₀₀/S₄.₅₀ = 1 − 1.001×10⁻⁶/1.049×10⁻⁵ = 90.5%

**6-6** 由 E°(Al³⁺/Al) = −1.66 V、E°(O₂/H₂O) = 1.23 V：
4Al + 3O₂ + 12H⁺ → 4Al³⁺ + 6H₂O　ΔG₁° = −12F×2.89
4Al + 3O₂ → 2Al₂O₃　ΔG₂° = −12F×2.71
两式相减：4Al³⁺ + 6H₂O → 2Al₂O₃ + 12H⁺　ΔG₃° = 12F×0.18
叠加 Al(OH)₃ ⇌ Al³⁺ + 3OH⁻（ΔG₄° = −RT ln K_sp）与 H⁺ + OH⁻ → H₂O（3×，3RT ln K_w）：
ΔG_m° = 3F×0.18 − RT ln K_sp + 3RT ln K_w = 3×96485×0.18 − 8.314×298.15×ln(3.00×10⁻³⁴) + 3×8.314×298.15×ln(1.00×10⁻¹⁴)
= 5.21×10⁴ + 1.91×10⁵ − 2.40×10⁵ = 3.71×10³ J·mol⁻¹ = **3.71 kJ·mol⁻¹**

## 解析要点

- 6-4 的"溶解度最小值"模型（S = a[H⁺]³ + K_s + b/[H⁺]）是竞赛分析化学经典框架，对应题型总纲第 6 条水溶液计算；
- 6-6 用电对电势差 ΔE = 0.18 V 搭桥，把电极电势、K_sp、K_w 三线合一，是"平衡 K、热力学函数、电对电势三者相互转化"的典型考题（对应题型总纲第 3 条）。
