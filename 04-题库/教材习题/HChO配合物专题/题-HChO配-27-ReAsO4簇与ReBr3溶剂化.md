# HChO配-27 Re–As 簇合物 X 的推断（15 分）

> 来源：HChO 第9届培训班专题卷 第6题；讲义题型二练习

## 题目

Re 的一种络合物 X 具有 Be₄O(OAc)₆ 般令人治愈的结构。向 ReBr₃ 的红色的丙酮溶液中加入 Ag₃AsO₄ 并剧烈震荡，得到红色的固体。此固体溶解于少量 DMSO（二甲亚砜）中，得到深红色溶液，此溶液倒入大量 THF 中，析出玫瑰红色的固体。真空加热至 100 ℃ 使溶剂挥发，同时采用 P₂O₅ 干燥少量的水后即可得到 X。生成 X 的过程是非氧化还原的，X 中 As 的质量分数为 11.43%。

6-1 写出 P₂O₅ 干燥的反应式；Ag₃AsO₄ 是什么颜色的？

6-2 通过计算写出 X 的化学式。红外光谱表明 X 中仅有 1 种 Re 和 1 种 As，X 中存在 Re-Re 键，画出其结构。

6-3 溶解于 DMSO 的红色固体是一种银盐，其最可能的化学式是什么？

6-4 由此观之，本应有极性的 ReBr₃ 为何可溶于丙酮？

## 解答

6-1 **P₂O₅ + H₂O = 2 HPO₃**；Ag₃AsO₄ 是**深红色**的（2 分）。

6-2 假设 X 中仅有一个 As 原子：M(X) = 74.96 g·mol⁻¹/11.43% = 655.8 g·mol⁻¹。Ag₃AsO₄ 提供 AsO₄³⁻，AgBr 很可能中途剥离 Re 络合物，故此物质的化学式可写为 (ReAsO₄)·(ReBr₃)ₓ 或 (ReAsO₄)·(溶剂)ₓ 或 (ReAsO₄)·(ReBr₃)ₓ·(溶剂)ᵧ，其中溶剂最可能是 DMSO。逐一验算：[M(X) − M(ReAsO₄)]/M(ReBr₃) = 0.776，舍去；[M(X) − M(ReAsO₄)]/M(DMSO) = 4.23，舍去；另两溶剂（丙酮、THF）的解分别为 5.69 和 4.59，舍去（3 分）。

故 X 中至少有两个 As 原子：M(X) = 2×74.96 g·mol⁻¹/11.43% = 1312 g·mol⁻¹。对 (ReAsO₄)₂·(ReBr₃)ₓ、(ReAsO₄)₂·(溶剂)ₓ、(ReAsO₄)₂·(ReBr₃)ₓ·(溶剂)ᵧ 逐一验算，仅 [M(X) − 2M(ReAsO₄)] = x·M(ReBr₃) + y·M(DMSO) 有整数解 x = 1，y = 3（4 分）。验算 (ReAsO₄)₂·ReBr₃·(DMSO)₃ 中 As 的质量分数为 11.43%，符合题意。

故 X 的化学式为 **(ReAsO₄)₂·ReBr₃·(DMSO)₃**，即 [Re₃Br₃(AsO₄)₂(DMSO)₃]。结构（3 分，Re₃ 三角形骨架，AsO₄ 与 DMSO 配位，含 Re–Re 键）：

6-3 最可能的化学式为 **Ag₃[Re₃Br₆(AsO₄)₂]**（1 分）。

6-4 ReBr₃ 会发生三聚，结合丙酮形成疏水的非极性结构，故可溶于丙酮（2 分）：

## 解析要点

- 6-2 是本题核心：先按 1 个 As 计算并枚举所有可能的溶剂组合，全部舍去后再升到 2 个 As；解多元一次不定方程时逐一枚举溶剂种类；
- 6-4 指向经典结论：金属卤化物在配位性溶剂中通过溶剂化/齐聚改变极性而"反常"溶解；三聚 Re₃Br₆ 型结构与 Re₃Cl₉ 类似。
