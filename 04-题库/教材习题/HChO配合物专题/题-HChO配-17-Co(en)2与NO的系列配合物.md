# HChO配-17 Co(en)₂ 与 NO 反应体系的化学式推断（11 分）

> 来源：HChO 第5届培训班综合卷 第6题；讲义题型二练习

## 题目

将 CoCl₂·6H₂O 与乙二胺（en）以 1:2 溶于有机溶剂中，通入一倍当量的 NO，可得含钴 21.04% 的巧克力色晶体 A；继续通入两倍当量的 NO，可得含钴 19.90% 的暗红色晶体 B 与气态化合物 C；而若将 CoCl₂·6H₂O 与乙二胺以 1:3 溶于盐酸酸化的甲醇中，通入 NO 则可生成橙黄色晶体 D，钴的质量分数为 17.05%。写出 A~D 的化学式，配合物有内外界的，表示出内外界。

## 解答

| 物种 | 化学式 | 备注 |
|------|--------|------|
| A（巧克力色） | [Co(en)₂(NO)Cl]Cl | NO 以 NO⁺（亚硝酰阳离子）配位，Co 为 +1 价（EAN 18e） |
| B（暗红色） | [Co(en)₂(NO₂)Cl]Cl | NO 过量时被氧化为 NO₂⁻（亚硝酸根）配位；答亚硝酸根络合物也得分 |
| C（气体） | N₂O | 2 NO → N₂O 的歧化脱氧 |
| D（橙黄色） | [Co(en)₃]Cl₃ | en 过量时形成三螯合经典配合物 |

评分：A、B、D 每个 3 分，C 2 分；B 答 [Co(en)₂(NO)(O)]Cl₂ 得 0.5 分。

## 解析要点

- 抓手是"NO 的两种配位形态"：NO⁺（线性亚硝酰，Co(I) d⁸ 18e 平面四方/八面体畸变）与 NO₂⁻（ bent 亚硝酸根）；
- 质量分数验证：用 A 中 Co% = 58.69 / (58.69 + 2×116.2 + 30.01 + 35.45 + 35.45) ≈ 21.0% 可复核；
- C 的判断来自氧化数守恒：A → B 的转化是 NO 歧化（2NO → N₂O + O 进入配位层）。
