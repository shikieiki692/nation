# HChO配-31 硼、铍的乙酸盐络合物推断（13 分）

> 来源：HChO 第21届培训班专题卷 第5题；讲义题型二练习

## 题目

本题的 A、B 和 C 均为常见物质，X 和 Y 均为无机化学中的经典结构。

含有不同核心元素的酸 A 与酸酐 C 发生反应，可生成电中性络合物 X 和酸 C′。生成 X 时失重（相较于反应物，下同）56.82%，X 中含氧量为 52.59%，核心元素含量 7.90%；含有另一种核心元素的盐 B 加热分解，可生成电中性络合物 Y 和酸酐 C。生成 Y 时失重 20.08%，Y 中含氧量为 51.19%，核心元素含量 8.87%。已知 A、B 和 C 的核心元素在元素周期表中相邻。

5-1 X 中氧原子的个数与生成 C′ 的个数的比例为 1.5:1，通过计算确定 C 和 C′ 的化学式。

5-2 已知电中性络合物 X 和酸 C′ 物质的量比为 1:6，通过计算与推断确定 A 与 X、B 与 Y 的化学式。

5-3 分别画出 X 和 Y 的结构。

## 解答

5-1 设 C′ 的分子量为 M（有 x 个），则氧原子的个数 y 为：

y = [(x × M/56.82% − x × M) × 52.59%]/(16.00 g·mol⁻¹)

由于 y = 1.5x，故 M = 60.05 g·mol⁻¹，为 CH₃COOH。（2.5 分）

故 C 和 C′ 分别为 (CH₃CO)₂O 和 CH₃COOH。（0.5 分）

5-2 1.5 × 6 = 9

M(X) = 16.00 g·mol⁻¹ × 9/52.59% = 273.8 g·mol⁻¹

X 中核心元素的总摩尔质量为 273.8 g·mol⁻¹ × 7.90% = 21.6 g·mol⁻¹，为 2 个硼原子。故 A 为 B(OH)₃；又有 C 和 C′ 分别为 (CH₃CO)₂O 和 CH₃COOH，故生成 X 的反应方程式可写为：

2B(OH)₃ + a(CH₃CO)₂O = B₂O₉C(4a−12)H(3a+6) + 6CH₃COOH

又有 6 + 3a = 9 + 12，故 a = 5，X 的化学式为 B₂O₉C₈H₁₂，即 B₂O(OCOCH₃)₄。（4 分）

由于 A、B 和 C 的核心元素在元素周期表中相邻，故 B 中的核心元素为铍或氮。后者没有合适的乙酸盐，故选择 B 为 Be(OCOCH₃)₂。生成 Y 的反应方程式可写为：

dBe(OCOCH₃)₂ = Y + e(CH₃CO)₂O

由失重率可求得 d = 4、e = 1，Y 的化学式为 Be₄O(OCOCH₃)₆，Be 的质量分数为 8.87%，得证。（2.5 分）

故四者的化学式：A: B(OH)₃；X: B₂O(OCOCH₃)₄；B: Be(OCOCH₃)₂；Y: Be₄O(OCOCH₃)₆。（0.5 分）

## 解析要点

- 两个"失重率 + 含氧量 + 核心元素含量"是同一套联立：先由 y = 1.5x 反解出 C′ = CH₃COOH（M = 60.05），再由 X 的含氧量 52.59% 反解 M(X) = 273.8，核心元素 7.90% → 21.6 → 2 个 B。
- "核心元素在周期表中相邻"是收口的最后一把钥匙：B 相邻的只能是 Be 或 C，而"盐 B 加热分解得失重 20.08%"只有乙酸盐 Be(OCOCH₃)₂ 走得通，碳没有合适的乙酸盐。
- 校勘：原书解答此处写"Y 的化学式为 4Be(OCOCH₃)₂"，但按失重率（d = 4、e = 1）应为 Be₄O(OCOCH₃)₆；本卡按后者的化学式记录，并在 5-2 的方程式中保留原书系数 d = 4、e = 1。
