# HChO配-47 硼取代茂基铁羰基配合物（8 分）

> 来源：HChO 第10届培训班专题卷 第10题；讲义题型三练习

## 题目

含硼的无色的晶体 X 具有 [(CH₃)₅C₅B][M(CO)ₓ] 的化学式。经测定，X 中碳元素的质量分数为 53.56%。

10-1 通过计算写出 X 的化学式。

10-2 X 中共有 1:3 的两种氧原子，画出 X 的结构示意图。

10-3 X 中几种碳原子？

10-4 M 原子外围依然为 18 电子，推测 M 和 B 之间最可能形成几重键。

## 解答

10-1 当 x = 1 时，M(M) = 72.61，为 Ge，但并没有合理结构；

当 x = 2 时，M(M) = 67.03，没有合理解；当 x = 3 时，M(M) = 61.44，没有合理解；当 x = 4 时，M(M) = 55.86，为 Fe，有合理结构；当 x = 5 时，M(M) = 50.27，没有合理解；当 x = 6 时，M(M) = 44.69，没有合理解；当 x = 7 时，M(M) = 39.10，为 K，但并没有合理结构；当 x > 7 时，M(M) 过小，没有合理解。

故 X 的化学式为 (CH₃)₅C₅BFe(CO)₄。（2 分 + 1 分）

10-3 4 种（1 分）

10-4 最可能形成双键（1 分）

## 解析要点

- 10-1 是"枚举 x 逐一试解"的典型：碳质量分数 53.56% 只给出一个方程，必须对 x = 1~7 逐个验算摩尔质量，只有 x = 4 给出 55.86（Fe）且结构合理；x = 1 得 Ge、x = 7 得 K 虽然数值对得上，但都无合理结构，故被排除。
- "1:3 的两种氧原子"与"18 电子"是收口的两把钥匙：前者约束 CO 的排布方式，后者要求 M 与硼代茂基之间额外成键，才能把 Fe 的电子数补足。
- M-B 之间的多重键是本题的化学内核：硼代茂基（硼杂环戊二烯基）作为缺电子配体，需要与 Fe 形成额外键来满足 18 电子规则，故最可能是双键。
