# HChO配-25 (PCl)₂(NBu-t)₂ 与 NaMn(CO)₅ 的反应产物（10 分）

> 来源：HChO 第9届培训班专题卷 第2题；讲义题型二练习

## 题目

含有 PNPN 四元环的化合物 (PCl)₂(NBu-t)₂ 具有十分丰富的配位化学，其与过量的 NaMn(CO)₅ 在 THF 中反应，得到绿色的电中性化合物 X。定量放出 CO 的同时，还定量生成了一种 Mn 的稳定化合物。元素分析证实，X 中 Mn 的质量分数为 14.80%。

2-1 通过计算写出 X 的最简式。

2-2 红外光谱表明，X 中有两种 Mn-P 键。已知 X 不是多核络合物，推断 X 的化学式，画出其结构（用"N"表示"NBu-t"基团）。

2-3 写出 X 中 Mn 的氧化态，采用 EAN 规则判断 X 中 Mn 的周围电子数。

2-4 写出生成 X 的方程式。

2-5 判断 X 中哪种 Mn-P 键键能更大。

## 解答

2-1 (PCl)₂(NBu-t)₂ 中更不可能反应的是 NBu-t 基团；X 不含 Na。若 X 为单核络合物，则 M(X) = 54.94/14.80% = **371.2 g·mol⁻¹**，M(X) − M(Mn) − M(CO)×5 = 176.2 g·mol⁻¹；(PCl)₂(NBu-t)₂、P(PCl)(NBu-t)₂、P₂(NBu-t)₂ 的式量分别为 275.1、239.7 和 204.2 g·mol⁻¹，故 X 中 Mn:CO 不能为 5；M(X) − M(Mn) − M(CO)×4 = 204.2 g·mol⁻¹，故 X 的最简式为 **Mn(CO)₄P₂(NBu-t)₂**（3 分）。

2-2 单核络合物不可能产生两种 Mn-P 键，因此 X 为双核或多核络合物。双核的 X 有合理结构（两个 Mn(CO)₄ 单元通过 P–P 键与 Mn–P 键相连，形成 Mn₂P₂ 核心）：

2-3 X 中 Mn 的氧化态为 **+1**，EAN 电子计数：6 + 2×4 + 2 + 2 = **18 e**（1 分）。

2-4 生成 X 的方程式：

![[74c50b529a07cd518258f8960da5a65b946a09b350655afacdc217cf9fda1062.jpg]]。（1.5 分）

2-5 **未形成 P-P 键的 P 原子与 Mn 成的键键能更大**（1.5 分）。

## 解析要点

- 2-1 先按单核假设计算剩余式量，与候选配体式量对比逐次排除 Mn(CO)₅ 与 Mn(CO)₄ 两种情形；
- 2-2 "两种 Mn-P 键"是推翻单核假设的直接证据；双核 Mn₂P₂ 核心中一个 P 以 P–P 键、另一个 P 以孤对电子与 Mn 成键，故出现两种 Mn–P 键；
- 2-5 中形成 P–P 键的 P 孤对电子已用于成键，与 Mn 的给电子能力弱，Mn–P 键键能较小。
