# HChO配-18 [AuL₄]Cl·xH₂O 的配体滴定推断（12 分）

> 来源：HChO 第13届培训班综合卷 第5题；讲义题型二练习

## 题目

实验室里现有一白色的纯品金络合物，其化学式可写作 [AuL₄]Cl·xH₂O。L 中所有的氮原子都是 −3 价的氮原子。为了确定 L，某同学做了如下实验：

**实验一**：称取 0.6027 g 样品，定容于 100 mL 容量瓶后，量取 25.00 mL。酸化使其完全分解后，加碱、蒸馏。采用 50.00 mL 0.05398 mol·L⁻¹ 的标准 HCl 溶液吸收生成的气体后，用甲基橙为指示剂，以 0.05675 mol·L⁻¹ 的标准 NaOH 溶液滴定，消耗 14.68 mL；

**实验二**：称取 0.6191 g 样品，定容于 100 mL 容量瓶后，量取 25.00 mL。酸化使其完全分解后，样品中所有的碳原子均从 —CH₂—（亚甲基）转化为 HCHO。调 pH 至碱性后，加入适量 K₂Zn(CN)₄ 溶液，完全反应后酸化，以 K₄[Fe(CN)₆] 滴定至终点，测得生成的 K₂Zn₃[Fe(CN)₆]₂ 沉淀的质量为 0.2230 g；

**最后**：将一定量的样品转化为 [AuL₄]PF₆·yH₂O，测得磷元素的质量分数为 15.66%。

**5-1** 通过计算写出 L 的化学式。

**5-2** 计算 x 与 y 的值。

**5-3** 在采用亚铁氰化氧铀为外指示剂、以 K₄[Fe(CN)₆] 滴定至白色浑浊中产生棕色的过程中，往往需要加入少量的 NH₄Cl 以达到更好的效果。指出这样做的原因。此次实验中为何没有这样做？

## 解答

**5-1** 实验一测氮：n(NH₃) = (50.00 mL×0.05398 mol·L⁻¹ − 14.68 mL×0.05675 mol·L⁻¹)×4 = 7.464×10⁻³ mol，即 0.6027 g 样品含 7.464×10⁻³ mol N（2 分）。

实验二测亚甲基：反应 4HCHO + [Zn(CN)₄]²⁻ + 4H₂O = 4NCCH₂OH + [Zn(OH)₄]²⁻；[Zn(OH)₄]²⁻ + 4H⁺ = Zn²⁺ + 4H₂O；2K⁺ + 3Zn²⁺ + 2[Fe(CN)₆]⁴⁻ = K₂Zn₃[Fe(CN)₆]₂↓。0.2230 g 沉淀 = 3.193×10⁻⁴ mol，对应 n(CH₂) = 3.193×10⁻⁴×48 = 1.533×10⁻² mol；折合 0.6027 g 样品为 1.492×10⁻² mol。N : CH₂ = 7.464×10⁻³ : 1.492×10⁻² ≈ **1:2**（共 3 分）。

由 P% = 15.66%：若每分子仅 1 个 P（PF₆⁻），总摩尔质量 197.77 只够 Au，故 L 中必含 P；设每分子共 5 个 P，则 M = 988.83，减 Au、PF₆、4P 后剩 522.98，由 a×42.06 + b×18.02 = 522.98（a、b 正整数），解 a=3,b=22；a=6,b=15；a=9,b=8；a=12,b=1；a 为 4 的倍数 → 唯一解 a=12, b=1，对应 **L = PN₃(CH₂)₆**（按讲义解答；3 分）。

**5-2** y = b = **1**；0.6027 g 样品含 L 2.49×10⁻³ mol、AuCl 6.22×10⁻⁴ mol，M([AuL₄]Cl·xH₂O) = 969 g·mol⁻¹，减 AuCl 与 4L 后剩 108 g·mol⁻¹ = 6H₂O，故 **x = 6**（2 分）。

**5-3** 加 NH₄Cl 是为使 K₂Zn₃[Fe(CN)₆]₂ 发生聚沉（胶体凝聚，便于观察终点）；本实验中样品酸化分解后溶液中已含 NH₄Cl，故无需另加（1 分）。

## 解析要点

- 本题是"配体推断 + 容量分析"综合：凯氏定氮（返滴定）+ 亚甲基甲醛化锌量法两条分析线并行；
- 5-1 的难点在把沉淀计量关系转成 CH₂ 数（×48 来自 4×4×3 的计量链），计算繁琐但每步都有分；
- L 的化学式以讲义解答原文为准（PN₃(CH₂)₆），实际文献中该配体体系可能对应其他组成，使用前建议与原件图片核对。
