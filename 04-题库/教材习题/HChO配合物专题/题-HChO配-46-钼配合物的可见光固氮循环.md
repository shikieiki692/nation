# HChO配-46 钼配合物的可见光固氮循环（13 分）

> 来源：HChO 第10届培训班专题卷 第4题；讲义题型三练习

## 题目

不断开发更高效的化学法合成氨对人类的持续发展具有重大的意义。2015 年，荷兰科学家首次报道了可见光推动的金属催化光化学法合成氨的反应：采用 L₃Mo（A）接受 N₂ 的配位生成 B，B 经历光化学裂解生成 2 个 C，C 后处理得到 NH₃。

4-1 画出 C 的结构式。

4-2 B 还可以被氧化生成 B′²⁺，但后者的裂解将得到多种结构不明的复杂产物因而不具应用价值。画出 B′²⁺ 的结构式，并判断 B 和 B′²⁺ 何者中的氮氮键更弱。

4-3 C 后处理得到 NH₃ 的过程如下，其中 lut 为 2,6-二甲基吡啶（2,6-lutidine）的缩写。指出两种试剂分别的作用。

C —（过量 Co(C₅H₅)₂／过量 [lutH][BArF₄]）→ NH₃ + L₃Mo(A)

4-4 令作者都感到惊讶的是，仅用 [lutH][BArF₄] 处理 C，将发生：4C → B′²⁺ + 2D 的歧化反应。画出 D 的结构式，写出 A、B、B′²⁺、C 和 D 中 Mo 的氧化态（提示：C 被氧化为 C′ 后与 1,4 环己二烯反应，也可得到 D）。

## 解答

4-1 C 的结构式：

L₃Mo≡N

4-2 B′²⁺ 的结构式与氮氮键强弱判断：原书解答区未给出对应文字与图形，此处留白（可参照题给的氧化产物为 N≡N 桥连双 Mo 的推断方向）。

## 解析要点

- 4-1 的 C = L₃Mo≡N 是整条循环的产物单元：N₂ 在 Mo 上被彻底切断为端基氮宾/氮化物，"生成 2 个 C"正对应一次 4 电子还原的 N≡N 断裂。
- 4-3 的两种试剂分工明确：Co(C₅H₅)₂ 是 19 电子的强还原剂（供电子），[lutH][BArF₄] 提供质子，二者合起来完成"还原 + 质子化"得到 NH₃。
- 4-4 的歧化反应是本题的难点，原书对 Mo 氧化态未给文字答案，使用本卡时须对照配体电荷与整体电荷自行核算（本卡按原书原样保留该缺口，未代为补写）。
