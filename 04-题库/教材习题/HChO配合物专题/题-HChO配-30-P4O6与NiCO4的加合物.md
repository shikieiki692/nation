# HChO配-30 P₄O₆ 与 Ni(CO)₄ 的加合物推断（13 分）

> 来源：HChO 第21届培训班专题卷 第1题；讲义题型二练习

## 题目

1965 年，化学家发现两种在无机化学中常见的液态化合物 A 和 B 在室温下混合，在 B 过量的前提下，将得到新的白色粉末 C 和常见气体 D。C 中氧元素的质量分数为 36.42%，D 中氧元素的质量分数为 57.12%。已知 A、B 和 C 具有完全相同的对称性，三种分子中分别存在 1 种、2 种和 4 种化学键。

1-1 通过计算与推断写出 A、B、C 和 D 的化学式。

1-2 画出 C 的结构。

## 解答

1-1 易发现，质量分数为 56.94% 的常见气体为 CO。则液态化合物 A 和 B 首先考虑 Ni(CO)₄ 或 Fe(CO)₅。但 Fe(CO)₅ 中存在 3 种化学键，因此很可能 B 是 Ni(CO)₄。（2 分）

而只有一种化学键的化合物 A 则可以认为只有两种元素，可能是 XₐO_b，也可能是 XₐY_b。XₐO_b 为更简单的情况，先考虑 XₐO_b。此时 X 的化学式可以写作 XₐO_b·c[Ni(CO)₄]。依据氧元素的质量分数有：

16.00 g·mol⁻¹ × (b + cd) = M(XₐO_b·c[Ni(CO)₄]) × 36.42%（2 分）

其中 d = 0、1、2 或 3。由于 A、B 和 C 具有完全相同的对称性，故最可能的情况有二：

可能一：c = 4、d = 3

16.00 g·mol⁻¹ × (b + 12) = M(XₐO_b·4[Ni(CO)₃]) × 36.42%

M(Xₐ) = [16.00 g·mol⁻¹ × (b + 12)]/36.42% − 16.00 g·mol⁻¹ × (b + 12) − 378.88 g·mol⁻¹

仅当 b = 6 时，Xₐ 有合理解，为 P₄。故 C 可能是 P₄O₆[Ni(CO)₃]₄。

可能二：c = 1、d = 0 且 a、b 均为 4 的倍数

16.00 g·mol⁻¹ × b = M(XₐO_b·Ni) × 36.42%

M(Xₐ) = 16.00 g·mol⁻¹ × b/36.42% − 16.00 g·mol⁻¹ × b − 58.69 g·mol⁻¹，Xₐ 无合理解。

综上：A、B、C 和 D 的化学式分别为 P₄O₆、Ni(CO)₄、P₄O₆[Ni(CO)₃]₄ 和 CO。（6 分）

## 解析要点

- 三条约束同时成立才唯一："A、B、C 对称性完全相同"＋"A 只有 1 种化学键"＋"B 有 2 种化学键"——只有 Td 的 P₄O₆ 与 Td 的 Ni(CO)₄ 能彼此匹配；Fe(CO)₅ 有 3 种键（轴向/平伏 CO 不等价）被排除。
- 计算的关键是把氧质量分数写成 16.00×(b + cd) 与 M(XₐO_b·c[Ni(CO)₄]) 的关系，再用 c = 4、d = 3（4 个 Ni(CO)₃ 顶点）试解，b = 6 时 Xₐ 恰为 P₄。
- 校勘：题干给 D 的氧质量分数为 57.12%，而解答正文写"质量分数为 56.94% 的常见气体为 CO"。CO 的氧质量分数实为 16.00/28.01 = 57.14%，与题干自洽；解答正文 56.94% 系笔误，此处照录原文并加注。
