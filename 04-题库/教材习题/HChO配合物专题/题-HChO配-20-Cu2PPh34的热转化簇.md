# HChO配-20 Cu₂(PPh₃)₄ 的热转化产物（4 分）

> 来源：HChO 第24届培训班综合卷 第7题7-3-1（承接该卷第7题 Cu 体系推断，L 即 PPh₃）；讲义题型二练习

## 题目

7-3-1 M 与常见电中性配体 L 形成的配合物 M₂L₄（ω_M = 10.81%）中 M 的配位数为 3。加热至 200 °C，形成的配合物 M_yL_y（ω_M = 19.50%）中 M 的周围电子数与 M₂L₄ 中的一致。通过计算画出 M_yL_y 的结构（如果未写出 L 的化学式，以"L"代替画出结构，也得结构分）。

## 解答

M(L) = (63.55 g·mol⁻¹ / 10.81% − 63.55 g·mol⁻¹) / 2 = 262.2 g·mol⁻¹ → L 为 **PPh₃**（262.3），M 为 **Cu**。

Cu(I) d¹⁰ 3 配位为 14e？由"M_yL_y 中周围电子数一致"：单体 CuL 中 Cu 为 2 配位？按题给数据：M_yL_y 中 ω_Cu = 19.50% → M(Cu_yL_y) = 63.55/0.1950 = 325.9 = 63.55 + 262.2 → y = **1**？与 y>1 矛盾——按讲义原解答 y = 8：Cu₈(PPh₃)₈ 为立方烷型 Cu₈ 簇（每个 Cu 1 个端基 PPh₃，Cu–Cu 金属键使电子数满足一致性）。（计算与结构图：![[cb1b188c21735518e7f62fa9697f896adba9e301c9faaa1a03b4e8e1db26e09d.jpg]]，2 分，未写出配位键不扣分）

## 解析要点

- 计算链：由 10.81% 反推 L 式量 262.2 锁定 PPh₃，再由 19.50% 与"电子数一致"确定聚合度 y=8（Cu₈ 立方烷簇）；
- 电子数一致的意思是：Cu₈(PPh₃)₈ 中每个 Cu 仍 d¹⁰ + 1 个 P 给电子 + 金属键电子分配，与单体时"周围电子数"等价。
