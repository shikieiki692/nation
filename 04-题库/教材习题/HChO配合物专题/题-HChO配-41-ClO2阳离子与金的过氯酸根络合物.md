# HChO配-41 ClO₂⁺ 阳离子与金的过氯酸根络合物（5 分）

> 来源：HChO 第24届培训班综合卷 第2题2-2；讲义题型三练习

## 题目

2-2 在很特殊的条件下，使用 AuCl₃ 与 Cl₂O₆ 反应，得到的络合物可写作 ClO₂⁺[X]⁻ 的形式。阴离子中三种元素的原子个数呈等比数列。

2-2-1 指出阳离子的 VSEPR 构型与杂化方式。

2-2-2 写出 X⁻ 的化学式。

2-2-3 指出金原子的杂化方式

2-2-4 NO 与 Cl₂O₆ 的反应与此反应稍有不同，发生了氧化还原反应。写出反应方程式。

## 解答

2-2-1 平面三角形（0.5 分）；sp² 杂化（0.5 分）。

2-2-2 [Au(ClO₄)₄]⁻（1 分）；写成 [AuCl₄O₁₆]⁻ 也得分；写成 [AuCl₂O₄]⁻ 或 [AuCl(ClO₂)]⁻ 不得分。

2-2-3 dsp²（1 分）；若 2-2-2 写成 [AuCl₂O₄]⁻ 或 [AuCl(ClO₂)]⁻，写 sp 本问得分。

2-2-4 NO + Cl₂O₆ = NOClO₄ + ClO₂（2 分）；写成 NO + ClO₄⁻ 也得分；写成 NO₂ + ClO₂ 不得分。

## 解析要点

- "阴离子中三种元素原子个数成等比数列"是解开 X⁻ 的唯一线索：Au、Cl、O 的个数须成等比，[Au(ClO₄)₄]⁻ 恰为 1:4:16，比值 4。
- ClO₂⁺ 用价层电子对数法判断：中心 Cl 无孤对电子、三条 σ 键 → 平面三角形 / sp²；与弯曲的 ClO₂（带单电子）形成对照。
- 2-2-4 的关键是"NO 被氧化为 NO⁺、部分 Cl(VI) 被还原为 ClO₂ 中的 Cl(IV)"，写成 NO₂ 就错在把 N 氧化到了 +4。
