# HChO配-21 Fe₂(CO)₈²⁻ 与 AuPPh₃ 加合物（10 分）

> 来源：HChO 第25届培训班综合卷 第6题；讲义题型二练习

## 题目

金属羰基化合物 [N(C₂H₅)₄]₂[Mₓ(CO)ᵧ] 中 M 的质量分数为 18.73%。四氢呋喃中它与等量的 AuClPPh₃ 反应，有如下的方程式：

[N(C₂H₅)₄]₂[Mₓ(CO)ᵧ] + AuClPPh₃ = X + [N(C₂H₅)₄]Cl

实验测得生成物 X 中 M 的质量分数为 12.07%。

6-1 通过计算写出 [N(C₂H₅)₄]₂[Mₓ(CO)ᵧ] 与 X 的化学式。

6-2 [N(C₂H₅)₄]₂[Mₓ(CO)ᵧ] 与 X 的阴离子中，包括金属-金属键在内 M 分别为 5 配位和 7 配位。分别画出两个阴离子的结构（注意，M-M 金属-金属键显著长于一般的共价键、配位键）。

## 解答

6-1 X 的化学式可写为 [N(C₂H₅)₄][Mₓ(CO)ᵧ(AuPPh₃)]。设 x 个 M 的摩尔质量为 M₁，将 Mₓ(CO)ᵧ 看作一个整体，其摩尔质量设为 M₂，有：

M₁/(M₂ + 2×130.25 g·mol⁻¹) = 18.73%；M₁/(M₂ + 130.25 g·mol⁻¹ + 459.27 g·mol⁻¹) = 12.07%

解得 M₁ = 111.7 g·mol⁻¹；M₂ = 335.8 g·mol⁻¹。由 M₁ = 111.7 g·mol⁻¹ 可知 M 为 Fe，x = 2；由 M₂ = 335.8 g·mol⁻¹ 可知 y = 8。

故二者的化学式分别为 **[N(C₂H₅)₄]₂[Fe₂(CO)₈]** 和 **[N(C₂H₅)₄][Fe₂(CO)₈(AuPPh₃)]**。

6-2 结构图（[Fe₂(CO)₈]²⁻ 与 [Fe₂(CO)₈(AuPPh₃)]⁻，Fe(CO)₄ 单元以 Fe–Fe 键相连；AuPPh₃ 加合后 Fe 为 7 配位）：

## 解析要点

- 把 Mₓ(CO)ᵧ 设为整体未知数 M₂、x 个 M 总质量设为 M₁，两次质量分数联立即可同时解出金属种类与 CO 数目；
- "包括金属-金属键在内"的配位数表述提示结构中含 Fe–Fe 键，且 M–M 键显著长于共价/配位键是画结构时的重要几何约束。
