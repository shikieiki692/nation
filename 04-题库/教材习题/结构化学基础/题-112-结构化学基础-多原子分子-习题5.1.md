# 题-112：多原子分子 习题5.1

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第5章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

利用价电子对互斥理论，说明 $\mathrm{XeF_4}$，$\mathrm{XeO_4}$，$\mathrm{XeO_3}$，$\mathrm{XeF_2}$，$\mathrm{XeOF_4}$ 等分子的形状。

---

## 参考答案

Xe 的价电子数为 8，每个 F 提供 1 个电子参与成键，每个 O 提供 2 个电子参与成键。

**（1）$\mathrm{XeF_4}$**

- m（成键电子对）= 4（4 个 Xe—F 键）
- n（孤对电子）= (8 − 4×1)/2 = 2 对
- m + n = 6，电子对空间排布为**八面体**
- 2 对孤对电子处于对位（夹角 180°），4 个 F 原子处于赤道面
- 分子几何构型：**正方形（平面正方形）**

**（2）$\mathrm{XeO_4}$**

- m = 4（4 个 Xe=O 键）
- n = (8 − 4×2)/2 = 0 对
- m + n = 4，电子对空间排布为**四面体**
- 0 对孤对电子
- 分子几何构型：**正四面体**

**（3）$\mathrm{XeO_3}$**

- m = 3（3 个 Xe=O 键）
- n = (8 − 3×2)/2 = 1 对
- m + n = 4，电子对空间排布为**四面体**
- 1 对孤对电子占据四面体一个顶点
- 分子几何构型：**三角锥形**

**（4）$\mathrm{XeF_2}$**

- m = 2（2 个 Xe—F 键）
- n = (8 − 2×1)/2 = 3 对
- m + n = 5，电子对空间排布为**三角双锥**
- 3 对孤对电子处于赤道面（彼此夹角 120°），2 个 F 原子处于轴向
- 分子几何构型：**直线形**

**（5）$\mathrm{XeOF_4}$**

- m = 5（1 个 Xe=O 键 + 4 个 Xe—F 键）
- n = (8 − 1×2 − 4×1)/2 = 1 对
- m + n = 6，电子对空间排布为**八面体**
- 1 对孤对电子占据八面体一个顶点
- 分子几何构型：**四方锥形**
