# 题-019：量子力学 习题1.19

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第1章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

在边长为 $a$ 和 $b$ 的长方形二维势箱中存在质量为 $m$ 的自由粒子，写出它的两个方向的 Schrödinger 方程、存在能级的能量值，以及总波函数和总能量。

---

## 参考答案

二维势箱中势能函数为：

$$V(x,y) = \begin{cases} 0, & 0 < x < a,\ 0 < y < b \\ \infty, & \text{其他} \end{cases}$$

**$x$ 方向的 Schrödinger 方程**（箱内）：

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi_x}{\mathrm{d}x^2} = E_x\psi_x$$

边界条件：$\psi_x(0) = \psi_x(a) = 0$

**$y$ 方向的 Schrödinger 方程**（箱内）：

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi_y}{\mathrm{d}y^2} = E_y\psi_y$$

边界条件：$\psi_y(0) = \psi_y(b) = 0$

**分离变量解**：

$$\psi_x(x) = \sqrt{\frac{2}{a}}\sin\frac{n_x\pi x}{a}, \quad n_x = 1,2,3,\ldots$$

$$\psi_y(y) = \sqrt{\frac{2}{b}}\sin\frac{n_y\pi y}{b}, \quad n_y = 1,2,3,\ldots$$

**总波函数**：

$$\psi(x,y) = \psi_x(x)\psi_y(y) = \frac{2}{\sqrt{ab}}\sin\frac{n_x\pi x}{a}\sin\frac{n_y\pi y}{b}$$

**总能量**：

$$E = E_x + E_y = \frac{h^2}{8m}\left(\frac{n_x^2}{a^2}+\frac{n_y^2}{b^2}\right)$$

其中 $n_x, n_y = 1, 2, 3, \ldots$
