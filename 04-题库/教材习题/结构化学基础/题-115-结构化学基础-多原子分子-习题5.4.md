# 题-115：多原子分子 习题5.4

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第5章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

椅式环己烷具有 $D_{3d}$ 点群对称性，若将 C 原子按正四面体方向成键：

(1) 画出分子结构图并编号；

(2) 画出沿三重反轴（$\bar{3}$ 轴）的投影图；

(3) 画出 4 个 C 原子沿中间 C 原子连接的 H 和 C 原子的投影图；

(4) 写出扭角和二面角。

---

## 参考答案

**（1）分子结构图及编号**

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/1a65ce09c38a9dba05a99c7d1e3c3549f99fe29d6f76ab4de330faff65e50645.jpg]]

椅式环己烷有 6 个 C 原子，编号为 C₁—C₆。其中 C₁、C₃、C₅ 处于"上方"（三个 H 朝上），C₂、C₄、C₆ 处于"下方"（三个 H 朝下）。六个 C 原子构成椅式构象的环，C—C—C 键角接近正四面体角 109.5°。

分子结构示意：C₁ 通过 C₂—C₃ 与 C₄ 相连，C₄ 通过 C₅—C₆ 与 C₁ 相连，形成六元环。C₁ 和 C₄ 处于对位（上下各一个），其余 C 原子形成环的"椅面"。

**（2）沿三重反轴（$\bar{3}$ 轴）的投影图**

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/85676c9db875a85078da462e3ef37997476ccf9c2738a217e93516b862b75030.jpg]]

$D_{3d}$ 点群包含一个 $\bar{3}$ 轴（$S_6$ 轴），通过 C₁—C₄ 连线的中点。沿此轴观察：

- C₁ 和 C₄ 投影重合于中心
- C₂、C₄、C₆ 投影成等边三角形（上层）
- C₁、C₃、C₅ 投影成等边三角形（下层，旋转 60°）
- 各 H 原子投影在外围

**（3）4 个 C 原子的 Newman 投影**

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/e734ece298d2bab8b3ddd9a2605638714242a4edf31d9bdb253467fda91527a0.jpg]]

沿某一 C—C 键（如 C₁—C₂）观察，用 Newman 投影法表示：

- 前方 C（C₁）上的 H 和 C₆ 呈三脚架排列
- 后方 C（C₂）上的 H 和 C₃ 呈三脚架排列
- 前后两组三脚架相互交错，呈交叉式构象

在椅式环己烷中，所有相邻 C—C 键均呈**交叉式构象**，这是椅式构象稳定的结构原因。

**（4）扭角和二面角**

在椅式环己烷中：

- **扭角**（dihedral angle / torsion angle）：$\omega = 60°$

  即相邻两个 C—C 键上的 C—H 键之间的扭转角为 60°（交叉式构象）。

- **二面角**（dihedral angle）：$\phi = 180° - 60° = 120°$

  二面角 $\phi$ 定义为包含公共键的两个平面之间的夹角。在椅式环己烷中，相邻 C—C—C 三个原子确定的两个平面之间的二面角为 120°。

  也可直接用定义：沿 C₂—C₃ 键观察，C₁—C₂ 键与 C₃—C₄ 键的二面角为 120°。

**总结**：椅式环己烷中所有相邻 C—C 键均呈交叉式构象（$\omega = 60°$，$\phi = 120°$），无扭转张力，这是其构象能量最低的原因。
