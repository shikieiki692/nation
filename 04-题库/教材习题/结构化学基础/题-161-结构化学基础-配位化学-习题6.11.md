# 题-161：配位化合物 习题6.11

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第6章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目
利用配位场理论推断下列配位离子的结构及不成对电子数。

(1) $\mathrm{MnO}_4^{3-}$ ; (2) $\mathrm{Pd(CN)}_4^{2-}$ ; (3) $\mathrm{NiI}_4^{2-}$ ; (4) $\mathrm{Ru(NH_3)}_6^{3+}$ ;

(5) $\mathrm{MoCl}_6^{3-}$ ; (6) $\mathrm{IrCl}_6^{2-}$ ; (7) $\mathrm{AuCl}_4^-$ 。

---

## 参考答案

| 离子 | d电子数 | 形状 | d电子排布 | 不成对电子数 |
|------|--------|------|----------|------------|
| $\mathrm{MnO}_{4}^{3-}$ | $d^{2}$ | 四面体 | | 2 |
| $\mathrm{Pd(CN)}_{4}^{2-}$ | $d^{8}$ | 正方形 | | 0 |
| $\mathrm{NiI}_{4}^{2-}$ | $d^{8}$ | 四面体 | | 2 |
| $\mathrm{Ru(NH_{3})}_{6}^{3+}$ | $d^{5}$ | 八面体 | | 1 |
| $\mathrm{MoCl}_{6}^{3-}$ | $d^{3}$ | 八面体 | | 3 |
| $\mathrm{IrCl}_{6}^{2-}$ | $d^{5}$ | 八面体 | | 1 |
| $\mathrm{AuCl}_{4}^{-}$ | $d^{8}$ | 正方形 | | 0 |

**讨论**：一个配位离子究竟采取何种几何构型，主要取决于它在能量上和几何上是否有利。对于六配位的离子，比较容易判断。但对于四配位的离子，因素复杂些。

$\mathrm{MnO}_{4}^{3-}$ 离子中，尽管正方形 LFSE 更大，但 $\mathrm{Mn(V)}$ 半径较小，正方形构型配体间排斥力大，故采取四面体构型。

$\mathrm{NiI}_{4}^{2-}$ 中，$\mathrm{I}^{-}$ 半径大且电负性大，正方形构型斥力太大，故采取四面体构型。

同是 $d^{8}$ 构型的 $\mathrm{Pd}^{2+}$ 和 $\mathrm{Au}^{3+}$ 属第二、三长周期，半径较大，配位场稳定化能是决定因素，故采取平面四方形。
