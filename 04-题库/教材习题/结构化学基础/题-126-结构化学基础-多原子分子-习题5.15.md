# 题-126：多原子分子 习题5.15

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第5章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

说明 $\mathrm{N}_3^-$ 的几何构型和成键情况；用 HMO 法求离域 $\pi$ 键的波函数及离域能。

---

## 参考答案

叠氮离子 $\mathrm{N}_3^-$ 是 $\mathrm{CO}_2$ 的等电子体，呈直线构型，属 $D_{\infty h}$ 点群。中间 N 原子以 sp 杂化轨道与两端 N 原子形成 2 个 $\sigma$ 键。3 个 N 原子的 $p_x$ 轨道形成 $\pi_{x3}^4$，$p_y$ 轨道形成 $\pi_{y3}^4$。

对一个 $\pi_3^4$：$\psi_1 = \frac{1}{2}(\phi_1 + \sqrt{2}\phi_2 + \phi_3)$，$E_1 = \alpha + \sqrt{2}\beta$；$\psi_2 = \frac{1}{\sqrt{2}}(\phi_1 - \phi_3)$，$E_2 = \alpha$；$\psi_3 = \frac{1}{2}(\phi_1 - \sqrt{2}\phi_2 + \phi_3)$，$E_3 = \alpha - \sqrt{2}\beta$。

离域能为 $4(\sqrt{2}-1)\beta = 1.656\beta$。
