# 题-114：多原子分子 习题5.3

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第5章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

画出下列分子中孤对电子和键对电子在空间的排布图：

(1) $\mathrm{ICl_2^+}$, $\mathrm{N_2O}$

(2) $\mathrm{H_3O^+}$, $\mathrm{BrF_3}$, $\mathrm{NF_3}$

(3) $\mathrm{ICl_4^-}$, $\mathrm{IF_4^+}$, $\mathrm{SbF_4^-}$, $\mathrm{XeO_2F_2}$

(4) $\mathrm{IF_5}$，$\mathrm{XeF_5^+}$

---

## 参考答案

各分子的 VSEPR 分析及电子对空间排布如下：

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/1b16fcfee291802f34e359a67c06368e95ce3f866f2d09f8b7a11d072bb1fefb.jpg]]

**（1）**

- **$\mathrm{ICl_2^+}$**：I 价电子数 7，减去正电荷 1 个电子后为 6。m = 2（2 个 I—Cl 键），n = (6 − 2×1)/2 = 2 对。m + n = 4，四面体排布。2 对孤对 + 2 个键对，分子构型为**角形（V 形）**，键角小于 109.5°。

- **$\mathrm{N_2O}$**：结构为 N≡N—O，中心 N 用 sp 杂化。m = 2，n = 0。电子对排布为**直线形**。

**（2）**

- **$\mathrm{H_3O^+}$**：O 价电子数 6，减去正电荷 1 个电子后为 5。m = 3（3 个 O—H 键），n = (5 − 3×1)/2 = 1 对。m + n = 4，四面体排布。1 对孤对 + 3 个键对，离子构型为**三角锥形**。

- **$\mathrm{BrF_3}$**：Br 价电子数 7，m = 3（3 个 Br—F 键），n = (7 − 3×1)/2 = 2 对。m + n = 5，三角双锥排布。2 对孤对处于赤道面，分子构型为**T 形**。

- **$\mathrm{NF_3}$**：N 价电子数 5，m = 3（3 个 N—F 键），n = (5 − 3×1)/2 = 1 对。m + n = 4，四面体排布。1 对孤对 + 3 个键对，分子构型为**三角锥形**。

**（3）**

- **$\mathrm{ICl_4^-}$**：I 价电子数 7，加上负电荷 1 个电子后为 8。m = 4（4 个 I—Cl 键），n = (8 − 4×1)/2 = 2 对。m + n = 6，八面体排布。2 对孤对处于对位，分子构型为**平面正方形**。

- **$\mathrm{IF_4^+}$**：I 价电子数 7，减去正电荷 1 个电子后为 6。m = 4（4 个 I—F 键），n = (6 − 4×1)/2 = 1 对。m + n = 5，三角双锥排布。1 对孤对处于赤道面，分子构型为**变形四面体（翘翘板形）**。

- **$\mathrm{SbF_4^-}$**：Sb 价电子数 5，加上负电荷 1 个电子后为 6。m = 4（4 个 Sb—F 键），n = (6 − 4×1)/2 = 1 对。m + n = 5，三角双锥排布。1 对孤对处于赤道面，离子构型为**变形四面体（翘翘板形）**。

- **$\mathrm{XeO_2F_2}$**：Xe 价电子数 8。m = 4（2 个 Xe=O 键 + 2 个 Xe—F 键），O 提供 2 个电子，F 提供 1 个电子。n = (8 − 2×2 − 2×1)/2 = 1 对。m + n = 5，三角双锥排布。1 对孤对处于赤道面，O 原子占据赤道面位置（与孤对相邻时排斥较小），F 原子占据轴向位置。分子构型为**变形四面体**。

**（4）**

- **$\mathrm{IF_5}$**：I 价电子数 7，m = 5（5 个 I—F 键），n = (7 − 5×1)/2 = 1 对。m + n = 6，八面体排布。1 对孤对 + 5 个键对，分子构型为**四方锥形**。

- **$\mathrm{XeF_5^+}$**：Xe 价电子数 8，减去正电荷 1 个电子后为 7。m = 5（5 个 Xe—F 键），n = (7 − 5×1)/2 = 1 对。m + n = 6，八面体排布。1 对孤对 + 5 个键对，离子构型为**四方锥形**。
