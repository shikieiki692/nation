# 题-300：综合题 习题C.15

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》综合部分
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目
在晶体的衍射中，系统消光指的是什么现象？举三例说明系统消光和结构中对称元素及点阵型式的联系。证明体心立方点阵晶体的系统消光为:"在hkl型衍射数据中, $h+k+l=$ 奇数"。

---

## 参考答案
系统消光是指晶体的衍射数据中，有许多衍射的强度系统地、有规律地为零，即不出现衍射。例如:

（1）晶体结构属体心立方点阵型式，在它的 $hkl$ 型衍射中，$h+k+l=$ 奇数的衍射点一律不出现。

(2) 垂直于 b 轴有 n 滑移面时，在 h0l 型衍射中，$h+l=$ 奇数的衍射点一律不出现。

（3）平行于 c 轴有 $2_{1}$ 螺旋轴时，在 00l 型衍射中，l 为奇数的衍射点一律不出现。

对体心立方点阵晶体，根据结构因子公式:

$$
F_{hkl} = \sum_{j=1}^{N} f_{j} \exp[\mathrm{i}2\pi(hx_{j} + ky_{j} + lz_{j})]
$$

当 $h + k + l =$ 偶数，$F_{hkl} = 2f_{\mathrm{Na}}$ ；当 $h + k + l =$ 奇数，$F_{hkl} = 0$ 。

结构因子为 0, 衍射强度为 0, 即不出现衍射。
