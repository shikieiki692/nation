# 题-304：综合题 习题C.19

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》综合部分
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目
金属元素铒(Er)和镧(La)的晶体结构分别为六方最密堆积ABAB...(A3型)和双六方最密堆积ABACABAC...(A3'型)。这两种晶体结构的空间群都属于 $D_{6h}^{4}-P6_{3}/mmc$ 。

Er: $a = 355.9\mathrm{pm}, c = 558.7\mathrm{pm}, Z = 2$

La: $a = 377.0\mathrm{pm}, c = 1215.9\mathrm{pm}, Z = 4$

(1) 画出晶胞沿 c 轴的结构投影图, 写出两种结构中原子的坐标参数。

Er: $(0,0,0),(1/3,2/3,1/2)$ ；La：$(0,0,0),(0,0,1/2),(1/3,2/3,3/4),(2/3,1/3,1/4)$

(3) 计算两种结构中原子半径。

La 的原子半径: $a/2 = 188.5\mathrm{pm}$

Er 的原子半径：$a/2=177.5\mathrm{pm}$

（4）Er 的密度 $D = 9.064\mathrm{g}\mathrm{cm}^{-3}$，La 的密度 $D = 6.615\mathrm{g}\mathrm{cm}^{-3}$

Er 的密度比 La 高得多, 主要归因于镧系收缩效应和相对原子质量随着原子序数的增加而加大这两个因素的作用。
