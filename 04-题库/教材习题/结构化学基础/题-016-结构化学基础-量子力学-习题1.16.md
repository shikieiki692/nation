# 题-016：量子力学 习题1.16

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第1章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

设粒子处在 $0\sim a$ 范围内的一维无限深势阱中运动，其状态可用波函数 $\psi(x) = (4/\sqrt{a})\sin(\pi x/a)\cos^2(\pi x/a)$ 表示，试估算：

(1) 该粒子能量的可能测量值及相应的概率；

(2) 能量平均值。

---

## 参考答案

**(1) 将 $\psi(x)$ 展开为本征函数的线性组合**

利用三角恒等式：

$$\sin\theta\cos^2\theta = \sin\theta\cdot\frac{1+\cos 2\theta}{2} = \frac{1}{2}\sin\theta + \frac{1}{2}\sin\theta\cos 2\theta$$

$$= \frac{1}{2}\sin\theta + \frac{1}{4}[\sin(3\theta) - \sin(\theta)]$$

等一下，更直接地用：

$$\sin\theta\cos^2\theta = \sin\theta - \sin^3\theta$$

或者利用积化和差：

$$\sin\theta\cos^2\theta = \frac{1}{2}\sin\theta(1+\cos 2\theta) = \frac{1}{2}\sin\theta + \frac{1}{4}(\sin 3\theta + \sin(-\theta)) = \frac{1}{4}\sin\theta + \frac{1}{4}\sin 3\theta$$

所以：

$$\psi(x) = \frac{4}{\sqrt{a}}\sin\frac{\pi x}{a}\cos^2\frac{\pi x}{a} = \frac{4}{\sqrt{a}}\left(\frac{1}{4}\sin\frac{\pi x}{a} + \frac{1}{4}\sin\frac{3\pi x}{a}\right) = \frac{1}{\sqrt{2}}\psi_1 + \frac{1}{\sqrt{2}}\psi_3$$

其中 $\psi_n = \sqrt{2/a}\sin(n\pi x/a)$ 是归一化的本征函数。

因此能量的可能测量值为：

- $E_1 = h^2/(8ma^2)$，概率 $= |1/\sqrt{2}|^2 = 1/2$
- $E_3 = 9h^2/(8ma^2)$，概率 $= |1/\sqrt{2}|^2 = 1/2$

**(2) 能量平均值**

$$\langle E \rangle = \frac{1}{2}E_1 + \frac{1}{2}E_3 = \frac{1}{2}\cdot\frac{h^2}{8ma^2} + \frac{1}{2}\cdot\frac{9h^2}{8ma^2} = \frac{5h^2}{8ma^2}$$
