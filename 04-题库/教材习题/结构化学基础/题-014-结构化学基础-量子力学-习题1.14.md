# 题-014：量子力学 习题1.14

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第1章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

已知一维势箱中粒子的归一化波函数为 $\psi_n(x) = \sqrt{2/l}\sin(n\pi x/l)$，$n=1,2,3,\ldots$。求：

(1) 粒子的能量

(2) 粒子的坐标

(3) 动量的平均值

---

## 参考答案

**(1) 粒子的能量**

利用薛定谔方程 $\hat{H}\psi_n = E_n\psi_n$，其中 $\hat{H} = -\frac{\hbar^2}{2m}\frac{\mathrm{d}^2}{\mathrm{d}x^2}$（势箱内 $V=0$）：

$$\hat{H}\psi_n = -\frac{\hbar^2}{2m}\frac{\mathrm{d}^2}{\mathrm{d}x^2}\sqrt{\frac{2}{l}}\sin\frac{n\pi x}{l} = -\frac{\hbar^2}{2m}\cdot\left(-\frac{n^2\pi^2}{l^2}\right)\sqrt{\frac{2}{l}}\sin\frac{n\pi x}{l} = \frac{n^2\pi^2\hbar^2}{2ml^2}\psi_n$$

$$E_n = \frac{n^2\pi^2\hbar^2}{2ml^2} = \frac{n^2h^2}{8ml^2}$$

**(2) 粒子的坐标平均值**

$$\langle x \rangle = \int_0^l \psi_n^2 x\,\mathrm{d}x = \frac{2}{l}\int_0^l x\sin^2\frac{n\pi x}{l}\mathrm{d}x$$

利用 $\sin^2\theta = \frac{1-\cos 2\theta}{2}$，并注意到势箱关于 $x=l/2$ 的对称性：

$$\langle x \rangle = \frac{l}{2}$$

**(3) 动量的平均值**

$$\langle p_x \rangle = \int_0^l \psi_n\left(-\mathrm{i}\hbar\frac{\mathrm{d}}{\mathrm{d}x}\right)\psi_n\mathrm{d}x = -\mathrm{i}\hbar\frac{2}{l}\int_0^l \sin\frac{n\pi x}{l}\cdot\frac{n\pi}{l}\cos\frac{n\pi x}{l}\mathrm{d}x$$

$$= -\mathrm{i}\hbar\frac{n\pi}{l^2}\int_0^l \sin\frac{n\pi x}{l}\cos\frac{n\pi x}{l}\mathrm{d}x = -\mathrm{i}\hbar\frac{n\pi}{2l^2}\int_0^l \sin\frac{2n\pi x}{l}\mathrm{d}x = 0$$

$$\langle p_x \rangle = 0$$

这与势箱中粒子驻波的物理图像一致：粒子向左和向右运动的概率相等。
