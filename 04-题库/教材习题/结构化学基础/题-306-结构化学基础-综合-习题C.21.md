# 题-306：综合题 习题C.21

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》综合部分
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目
金刚石结构是一种基本的、重要的结构型式，晶体结构所属的空间群为 $O_{h}^{7}-F\\frac{4_{1}}{d}\\overline{3}\\frac{2}{m}$ 。

(1) 写出两套分别由面心立方点阵联系的 C 原子坐标参数。

(2) 指出四重对称轴的名称和记号。

（3）通过晶胞中心点的点对称元素组成 $T_{d}$ 点群。

(4) 金刚石晶体结构有对称中心，位置在 $\\left(\\frac{1}{8},\\frac{1}{8},\\frac{1}{8}\\right)$ ，即C—C键的中心点。

(5) 由对称中心联系的两个 C 原子的成键构象为交叉型。

（6）平行于 $yz$ 平面的金刚石滑移面处在 $x$ 值为 $\\frac{1}{8}, \\frac{3}{8}, \\frac{5}{8}, \\frac{7}{8}$ 等处。

(7) 将图 C.21.1 中去掉一套由面心立方点阵联系的 C 原子，它属 $O_h$ 点群，不存在金刚石滑移面 (d)。

(8) 将图 C.21.1 中的一套 C 原子换成 Si 原子得 SiC 结构, 它属 $T_{d}$ 点群, 为立方硫化锌型结构。Si—C 键长为 188.3 pm。SiC 俗称金刚砂，硬度为 9，仅次于金刚石。

（9）将 Si 原子换成 Ca 原子，C 换成 F 原子，再加上体心和棱心位置的 F 原子，得 $CaF_{2}$ 结构，点群为 $O_{h}$ ，俗称反萤石型结构。

(10) 将原点移至 Ca 原子上, F 原子周围有 4 个 Ca 原子, 呈四面体形配位, Ca 原子周围有 8 个 F 原子, 呈立方体形配位。

（11）将 C 原子换成 Si 原子，再在 Si 原子的连线中心点放 O 原子，其结构为 $\\beta-$方石英。

(12) $\\beta$-方石英的密度 $D = 2.08\\mathrm{g}\\mathrm{cm}^{-3}$，Si—O 键长 $d = 158.0\\mathrm{pm}$

（13）将图 C.21.5(a) 的 $A_{2}B$ 型结构中加上 B 原子，得 NaTl 的结构。将 A 原子用黑线相连，B 原子用双线相连，得到两套金刚石型结构。

(14) NaTl 的结构中，Tl---Tl 间距离为 324.2 pm。Tl 原子按正四面体形成键。

（15）NaTl 结构同时含有共价键、金属键和离子键。这类化合物具有明显的金属性。
