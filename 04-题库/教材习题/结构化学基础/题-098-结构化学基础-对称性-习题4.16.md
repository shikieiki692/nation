> **原书解答（2026-08-25 逐字转录）**

解 兹将各分子的序号、点群、旋光性和偶极矩等情况列表如下：

| 序号 | 点群 | 旋光性 | 偶极性 |
| --- | --- | --- | --- |
| (1)* | $C_{2v}$ | 无 | 有 |
| (2)* | $C_s$ | 无 | 有 |
| (3) | $C_{4v}$ | 无 | 有 |
| (4) | $D_{4d}$ | 无 | 无 |
| (5) | $C_{2h}$ | 无 | 无 |
| (6) | $C_s$ | 无 | 有 |
| (7) | $C_1$ | 有 | 有 |

\* 在判断分子的点群时，除特别注明外，总是将—CH₃看作圆球对称性的基团。
