# 题-018：量子力学 习题1.18

## 题目

一个粒子处在 $a=b=c$ 的三维势箱中，试求能级最低的前 5 个能量值 [单位为 $h^2/(8ma^2)$]，计算每个能级的简并度。

## 参考答案

三维势箱的能量公式为：

$$E = \frac{h^2}{8ma^2}(n_x^2 + n_y^2 + n_z^2)$$

其中 $n_x, n_y, n_z = 1, 2, 3, \ldots$

令 $N = n_x^2 + n_y^2 + n_z^2$，列出所有可能的 $(n_x, n_y, n_z)$ 组合，按 $N$ 从小到大排列：

| 能级 | $N = n_x^2+n_y^2+n_z^2$ | 能量值 $[h^2/(8ma^2)]$ | 组合 | 简并度 |
|---|---|---|---|---|
| $E_{111}$ | $1+1+1=3$ | **3** | (1,1,1) | **1** |
| $E_{112}$ | $1+1+4=6$ | **6** | (1,1,2), (1,2,1), (2,1,1) | **3** |
| $E_{122}$ | $1+4+4=9$ | **9** | (1,2,2), (2,1,2), (2,2,1) | **3** |
| $E_{113}$ | $1+1+9=11$ | **11** | (1,1,3), (1,3,1), (3,1,1) | **3** |
| $E_{222}$ | $4+4+4=12$ | **12** | (2,2,2) | **1** |

**前5个能级**：

1. $E = 3\,h^2/(8ma^2)$，简并度 = 1
2. $E = 6\,h^2/(8ma^2)$，简并度 = 3
3. $E = 9\,h^2/(8ma^2)$，简并度 = 3
4. $E = 11\,h^2/(8ma^2)$，简并度 = 3
5. $E = 12\,h^2/(8ma^2)$，简并度 = 1
