# 题-127-结构化学基础-多原子分子-习题5.16

## 题目

已知三次甲基甲烷 $[\mathrm{C}(\mathrm{CH}_2)_3]$ 为平面形分子，形成 $\pi_4^4$ 键。试用HMO法处理，证明中心碳原子和周围3个碳原子间的 $\pi$ 键键级之和为 $\sqrt{3}$。

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/29cbe6dfdedecb5f03d7cc336c9a07b88f5f86ed154093796801792d85ded2d5.jpg]]

## 答案

利用分子对称性化简久期方程，求得4个分子轨道及能级：$E_1 = \alpha + \sqrt{3}\beta$，$E_2 = E_3 = \alpha$，$E_4 = \alpha - \sqrt{3}\beta$。4个 $\pi$ 电子排布在 $\psi_1, \psi_2, \psi_3$ 上。

![[结构化学习题与解析/结构化学基础（第5版）习题解析周公度z-library.sk,1lib.sk,z-lib.sk_1-150_images/936798d22e5cd43da3fd8388256001c8b0aca1e5f9a4f680b8b0c2113547e2c5.jpg]]

$\pi$ 键键级 $P_{12} = P_{13} = P_{14} = 1/\sqrt{3}$，中间C原子和周围3个C原子间 $\pi$ 键键级之和为 $3/\sqrt{3} = \sqrt{3}$。加上3个 $\sigma$ 键，中心C原子的总成键度为 $N = 3 + \sqrt{3} = 4.732$，这是C原子理论上的最高成键度。
