# 题-124：多原子分子 习题5.13

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第5章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目

用 HMO 法解环丙烯正离子 $(\mathrm{C}_3\mathrm{H}_3)^+$ 的离域 $\pi$ 键分子轨道波函数，并计算 $\pi$ 键键级和 C 原子的自由价。

---

## 参考答案

(1) 分子轨道为：$\psi_1 = \frac{1}{\sqrt{3}}(\phi_1 + \phi_2 + \phi_3)$，$E_1 = \alpha + 2\beta$；$\psi_2 = \frac{1}{\sqrt{6}}(\phi_1 - 2\phi_2 + \phi_3)$，$E_2 = \alpha - \beta$；$\psi_3 = \frac{1}{\sqrt{2}}(\phi_1 - \phi_3)$，$E_3 = \alpha - \beta$。

(2) 2个 $\pi$ 电子在 $\psi_1$ 上，$\pi$ 键键级 $P_{12} = P_{23} = P_{31} = 2/3$。

(3) 自由价 $F_1 = F_2 = F_3 = 4.732 - 3 - 2\times(2/3) = 0.40$。
