# 题-275：超分子化学 习题10.11

> **来源**：周公度 段连运《结构化学基础（第5版）习题解析》第10章
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛拔高

---

## 题目
根据 $SbF_{3}$ 晶体结构测定数据，Sb—F 间除 3 个较短的强键呈三角锥形分布外，还有 3 个弱键和 3 个非常弱的键。它们的键长（以 pm 为单位）如下：195,195,206;250,256,256;375,378,378。

试计算各键的键价及 Sb 原子的键价和。

## 参考答案

> **原书解答（2026-08-25 逐字转录）**

解 按《结构化学基础》(第5版)(10.1.4)式和表10.1.1查得计算键价的 $R_{0}$ 和N值， $\mathrm{Sb}(3)\cdots\mathrm{F}(-1)$ 的 $R_{0}$ 值为177.2pm,N为3.7,计算所得各键键价及键价和如下：

| 键长/pm | 键价 |
| --- | --- |
| 195 | 0.70 |
| 195 | 0.70 |
| 206 | 0.58 |
| 250 | 0.28 |
| 256 | 0.26 |
| 256 | 0.26 |
| 375 | 0.06 |
| 378 | 0.06 |
| 378 | 0.06 |

Sb 的键价和为 2.96, 它接近于 $SbF_{3}$ 中 Sb 的原子价。
