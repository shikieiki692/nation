# HChO晶-01 K₂Sn₂O₃ 的晶胞、配位与密度（11 分）

> 来源：HChO 第22届培训班综合卷 第5题；讲义晶体练习

## 题目

二价锡的各种水合氧化物 SnO·xH₂O 的结构在很早之前就已经被透彻研究过，但其钾盐却因为很强的还原性与不稳定性未能得到研究。1978 年，科学家在氩气保护下首次得到了在六方的 K₂Sn₂O₃，其晶胞如右所示。

![[03b3fd02b9b0f6191e97463d7d803e76d77c979176f86a527d29dbf67bd2015b.jpg]]。

5-1 晶胞 (0, 0, 0)、(0, 0, 0.25)、(0.5, 0.5, 0.5) 处分别为哪种原子？

5-2 晶胞中共有几种化学环境、几种空间环境的钾原子？

5-3 对氧原子对钾原子的配位方式、钾原子对氧原子的配位方式进行描述。

5-4 晶体中 Sn-O-Sn 层的层高为 2.674 Å；层间距离为 2.101 Å；层内 K 原子的距离为 6.001 Å。计算该晶体的密度。

## 解答

5-1 (0, 0, 0)：**钾原子**（0.5 分）；(0, 0, 0.25)：**没有原子**（1 分）；(0.5, 0.5, 0.5)：**氧原子**（0.5 分）。

5-2 **2 种化学环境；2 种空间环境**（2 分）。

5-3 氧原子对钾原子有**两种**配位方式：① 以**拉长八面体**进行六配位；② 以**平面（正）六边形**进行六配位（1.5 分）。钾原子对氧原子有**一种**配位方式：以**平面四方型**进行四配位（1.5 分）——平面，但不是平面正方，层内 K–O 为 3.000 Å，层间为 2.950 Å。

参考图形：![[57202d07014454451d841f6da88b039d53e1ace8e38867ea5987c9e01154099b.jpg]]。

5-4 晶胞的高 c 为 3 倍 Sn-O 层的层间平均距离，即 14.327 Å；底边边长 a 则等于层内 K 原子的距离，为 6.001 Å（1 分）。

D = zM/VN_A = zM/a²c(sin 120°)N_A = 3×363.6 g·mol⁻¹/[(6.001 Å)²×14.327 Å×sin 120°×10⁻²⁴ cm³·Å⁻³×6.022×10²³] = **4.054 g·cm⁻³**（3 分）

## 解析要点

- 六方晶胞体积 V = a²c·sin 120°；本题 z = 3（每个晶胞含 3 个 K₂Sn₂O₃ 式量），M(K₂Sn₂O₃) = 363.6 g·mol⁻¹。
- c 由"3 倍层间距"给出（2.674 Å 是 Sn-O-Sn 层本身的高度、2.101 Å 是层间距离），需要按题目给的两段数据拼出 c = 3×14.327 Å 的关系，不能直接把 2.674 Å 当层间距。
- "空间环境"与"化学环境"是两个不同判据：前者按平移等价性（空间位置）划分，后者按化学键合环境划分，本题两者数值相同但不能混答。
