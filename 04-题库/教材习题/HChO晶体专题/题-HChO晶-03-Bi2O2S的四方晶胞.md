# HChO晶-03 Bi₂O₂S 的四方晶胞与密度（10 分）

> 来源：HChO 第6届联考 第4题；讲义晶体练习

## 题目

1984 年，首个铋的氧硫化物 Bi₂O₂S 被制备出来。X-射线衍射测得此晶体为四方晶系，边长 a = 385.6 pm；c = 1191.6 pm，这一结构与 UOS 的经典结构颇为类似。晶胞中，全部 S 的原子坐标为 (0, 0, 0)；(0.5, 0.5, 0.5)；一个 Bi 的原子坐标为 (0, 0, 0.3568)；所有 O 的高度均为 0.25 或 0.75。

4-1 已知氧原子均为四面体配位，画出四方 Bi₂O₂S 的晶胞。

4-2 晶体中共有几种空间环境的 Bi？

4-3 指出 Bi 的配位情况；Bi 与 O、S 何种原子之间的距离更近？

4-4 计算此晶体的密度。

## 解答

4-1 晶胞图：

![[8cc6a446595307e73f7b284b659c313b85c36b5dbe7fd0e0b874af526656c5b2.jpg]]（3 分，三种原子各自占 1 分）。

4-2 **0**（原书解答仅给出数值"0"）。

4-3 原书解答未给出（讲义 OCR 未收录该小题的解答文字）。

4-4 D = zM/VN_A = zM/(a²c·N_A) = 2×514.1 g·mol⁻¹/[(385.6 pm)²×1191.6 pm×10⁻³⁰ cm³·pm⁻³×6.022×10²³ mol⁻¹] = **9.036 g·cm⁻³**

> **校勘注记**：解答式中质量项印作 514.1 g·mol⁻¹，而 Bi₂O₂S 的摩尔质量应为 482.1 g·mol⁻¹（2×209.0 + 2×16.00 + 32.07）。由所给答案 9.036 g·cm⁻³ 反推恰对应 M ≈ 482.1 g·mol⁻¹，故 514.1 疑为笔误（照录原文并加注，未擅改）。

## 解析要点

- 四方晶胞 V = a²c；z = 2（S 占 (0,0,0) 与 (0.5,0.5,0.5) 两个位置，各计 1 个）。
- Bi 只占 (0,0,0.3568) 一个坐标，配合四方晶胞的对称操作繁衍，全部 Bi 处于同一空间环境，故 4-2 答"0"（指无第二种）。
- 本题与 UOS 型结构同族，氧为四面体配位是画图的关键约束：由 O 的位置反推 Bi 的排布。
