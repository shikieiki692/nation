# HChO晶-15 Na₃OBH₄ 的通道半径与 Na⁺ 传导（9 分）

> 来源：HChO 第29届培训班综合卷 第4题；讲义晶体练习

## 题目

近日，中国科学家发现等量 Na₂O 与 NaBH₄ 可发生固态反应，可得到一种混盐 X。X 因为具有极好的传导 Na⁺ 的能力而受到关注。X-射线衍射表明，它具有立方晶胞，a = 463 pm。如果以 O²⁻ 为晶胞顶点，则 BH₄⁻ 在晶胞体心。

4-1 写出 X 的化学式。

4-2 猜测 Na⁺ 的位置。

4-3 Na⁺ 在晶体中的传导将会通过怎样的通道？假设 O²⁻ 的半径 r₁ 为 140 pm；BH₄⁻ 的半径 r₂ 为 203 pm。计算此通道的半径，并猜测 Na⁺ 半径大于通道半径，但依然可以迁移的一个可能原因。

4-4 计算这个晶体的密度。

## 解答

4-1 **Na₃OBH₄**（1 分）

4-2 **Na⁺**（原书解答仅给出"Na⁺"一行）。由"O²⁻ 在晶胞顶点（8×1/8 = 1）、BH₄⁻ 在体心（1）"的立方晶胞与化学式 Na₃OBH₄ 可推得：**Na⁺ 占据面心位置**，每个晶胞 3 个。

4-3 穿过由 1 个 O²⁻ 和 2 个 BH₄⁻ 组成的**三角形通道**（1 分）。通道平面图如右：

![[8fbc7bf31313c27817b00b5a9196037ee79328112681296102b0902958fe7e2a.jpg]]。

设通道的中心与氧原子的原子核的距离为 x，则有：

(√2/2·a − x)² + (a/2)² = (r₂ + x − r₁)²

解得 **x = 201 pm**。

Na⁺ 半径大于通道半径却仍可迁移，可能的原因有二：① 阴阳离子都具有一定的变形性；② BH₄⁻ 实际上并不是球体，它旋转至合适的角度时，有效半径会显著下降，利于迁移（1 分，答出任意一种即可得分）。

> 原书参考：Na⁺ 的半径为 95 pm；如果认为 Na⁺ 占据晶胞的面心，则需要穿过半径为 91.5 pm 的平行四边形通道，但这是不对的。

4-4 D = zM/VN_A = zM/a³N_A = 1×99.81 g·mol⁻¹/[(463 pm)³×10⁻³⁰ cm³·pm⁻³×6.022×10²³ mol⁻¹] = **1.67 g·cm⁻³**（3 分）

## 解析要点

- 4-2 与 4-3 需要联读：只有先定出 Na⁺ 的位置（面心），才能画出由 1 个 O²⁻ 与 2 个 BH₄⁻ 围成的三角形通道，进而列出几何方程。
- 4-3 的方程由**通道中心到三个离子表面的距离相切**导出：(√2/2·a − x)² + (a/2)² = (r₂ + x − r₁)²，属"圆心到两球心距离分别等于两球半径之和"的标准几何关系。
- 4-4 中 z = 1（立方晶胞恰含 1 个 Na₃OBH₄），M = 99.81 g·mol⁻¹。
