# HChO晶-06 KMgF₃ 与 Cs₂Au₂Cl₆ 的结构与价态（15 分）

> 来源：HChO 第2届培训班专题卷 第1题；讲义晶体练习

## 题目

**1-1** 化学式为 K_xMg_yF_z 的化合物的晶体结构示意图如下左图所示：

![[764b894a617638f3884a68ab9c74d89ee3339b143439d2039eee90bd32161f76.jpg]]。

1-1-1 指出图中深色大球、浅色大球和浅色小球分别对应何种离子，写出该化合物的化学式。

1-1-2 氟离子对钾离子的配位数不是 4，指出其正确的配位数（只有一种 K—F 键长）。

1-1-3 在图中勾出该化合物的晶胞。

1-1-4 该晶体的密度为 3.148 g·cm⁻³，计算上一问中勾出的晶胞的晶胞参数（长度以埃为单位）。

**1-2** 与之相似的结构在化学式为 Cs_xAu_yCl_z 的化合物中被发现（如上右图），该四方晶胞的晶胞参数为 a = 0.749 nm，c = 1.087 nm。

![[022d8cc44b48071c4b4a0649d43ea97500bd6ce8836ebdd5c35cc901287b1ff0.jpg]]。

1-2-1 在常见离子化合物中，除硫化铅、硫化汞等盐类，深色的晶体并不常见，可以举出的例子有普鲁士蓝、四氧化三铁等。而该化合物却呈现十分独特的亮黑色（jet black）。

1-2-1-1 硫化铅、硫化汞因何种效应而显较深的颜色？

1-2-1-2 由此写出能够表现该化合物价态特点的化学式（暂不要求写出配离子）。

1-2-2 已知该晶胞中，其中两个浅色大球的原子坐标分别为 (0, 0, 0.288) 和 (0.228, 0.228, 0)，由此写出能够表现该化合物价态特点的化学式。

1-2-3 写出深色大球的原子坐标。

## 解答

1-1-1 深色大球、浅色大球和浅色小球分别对应**钾离子、氟离子和镁离子**（1.5 分）；化学式为 **KMgF₃**（1.5 分，其他答案不得分）。

1-1-2 配位数为 **12**（2 分，其他答案不得分）。

1-1-3 勾出的晶胞：

![[0918969f902f43f141bd4e731d482c10a25bb64b80a574562ef275d3f5b86987.jpg]]（1 分）。

1-1-4 该晶胞为立方晶胞，故只需求出棱长 a（0.5 分）：

a³ = V = zM/DN_A = 1×120.41 g·mol⁻¹/(3.148 g·cm⁻³×6.022×10²³ mol⁻¹) = 6.352×10⁻²³ cm³

a = (6.352×10⁻²³ cm³)^(1/3) = 3.990×10⁻⁸ cm，即 **3.990 Å**（2 分）

故其晶胞参数为：a = b = c = **3.990 Å**；α = β = γ = 90°（0.5 分）。其他计算过程合理、答案正确，亦得满分。

1-2-1-1 **离子极化效应**（1 分，其他答案不得分）。

1-2-1-2 **Cs₂Au⁽ᴵ⁾Au⁽ᴵᴵᴵ⁾Cl₆**（1 分，其他答案不得分）。

1-2-2 该晶体中共有两种化学环境的金：顶点和体心为**三价金**，侧棱棱心和顶底面面心为**一价金**。而侧棱上的氯原子距离一价金与三价金的比例为 0.212 : 0.288，更贴近一价金，故化学式应为：

**Cs₂[Au⁽ᴵ⁾Cl₂][Au⁽ᴵᴵᴵ⁾Cl₄]**（2 分；叙述合理即可得分，但不叙述仅得 1 分结论分）

1-2-3 深色大球的原子坐标：(0, 0.5, 0.25)；(0.5, 0, 0.25)；(0, 0.5, 0.75)；(0.5, 0, 0.75)（2 分）。

> 若写 (0,0.5,0.25)；(0.5,0,0.25)；(0,0.5,0.75)；(0.5,0,0.75)；(1,0.5,0.25)；(0.5,1,0.25)；(1,0.5,0.75)；(0.5,1,0.75) 这 8 个，只得 1 分；但只写后 4 个不得分；只要写出不属于以上 8 个中任意一个的，不得分。

![[21f35d9453c2f0a35679a5598b4fa4d20e0cba4a14b8f2de0d8cfa6c8c87d57a.jpg]]
![[a1ad1e1a85274b3229309aa296cc08ed076305434adb97ed87b52bf0274f6bfb.jpg]]

## 解析要点

- 1-1 是典型钙钛矿型（ABX₃）结构：Mg 占面心/小立方体中心、K 占顶点、F 占棱心。因顶点—棱心的几何关系，K 被 12 个 F 包围，故 1-1-2 的配位数是 **12** 而不是"4"。
- 1-1-4 中注意 **z = 1**（该晶胞恰含 1 个 KMgF₃ 式量），M = 120.41 g·mol⁻¹，两者共同决定 a³。
- 1-2 的难点在**混合价态**：同一元素在两组不同晶格位点上价态不同（Au⁽ᴵ⁾/Au⁽ᴵᴵᴵ⁾），判据是 Au—Cl 键长把侧棱 Cl 归属到哪一价；"亮黑色"提示电荷转移（离子极化）吸收，是价态混合的外在表现。
