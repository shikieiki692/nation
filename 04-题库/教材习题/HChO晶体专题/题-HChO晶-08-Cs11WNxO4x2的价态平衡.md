# HChO晶-08 Cs₁₁[WNₓO₄₋ₓ]₂(X)₂ 的化学式与价态平衡（3 分）

> 来源：HChO 第20届培训班综合卷 第2题 2-3；讲义晶体练习

## 题目

（由 4 种元素组成的）晶体的化学式可写作 **Cs₁₁[WN_xO_{4−x}]₂(X)₂**。

2-3-1 X 是整数价态的阴离子，钨四面体中 W、N、O 则分别为 +6、−3、−2 价。指出统计离子中 x 可能的取值。

2-3-2 观察此物质的晶胞（Cs 原子已省略），写出此物质的化学式。

`bdwp资源/06晶体总结_images/5f5aa66135462f060986e0befd198aa7727582f5795b07b78a8c772dce1f54fe.jpg`，待媒体仓库入库后补链。

## 解答

2-3-1 原书解答未单列该小题（讲义 OCR 未收录对应文字）。由价态平衡推算：

钨四面体部分电荷 = 2×[(+6) + x(−3) + (4−x)(−2)] = −4 − 2x；Cs 提供 +11；设阴离子 X 的电荷为 −v，则

11 − 4 − 2x − 2v = 0 ⇒ **v = (7 − 2x)/2**

要求 v 为正整数，得 **x = 0.5、1.5、2.5**（分别对应 v = 3、2、1）。再由 2-3-2 的晶胞可确定实际取值 x = 2.5、X = N₃⁻。

2-3-2 **Cs₁₁[WN₂.₅O₁.₅]₂(N₃)₂**（2 分）

## 解析要点

- 该题的核心是**电荷守恒 + 整数价约束**：令 x 自由，用 v 必须为整数这一条把 x 离散化，再借晶胞信息唯一确定。
- "统计离子"意味着钨四面体中 N、O 的占位是**无序统计**的，故 x 允许取非整数值（2.5 表示两种四面体各占一半的统计结果）。
- 抗磁性（原书解答区题面提到）与 N₃⁻、全部电子成对相容，可作为化学式合理性的辅助判据。
