# HChO晶-17 LiCu₂Si 与 Li₂CuP 的结构与配位（11 分）

> 来源：HChO 第33届培训班综合卷 第3题；讲义晶体练习

## 题目

化学式为 Li_xCu_{3−x}X（X = Si、P）的晶体具有并不类似的结构。

3-1 在 LiCu₂Si 中，硅做面心立方堆积，指出锂与铜的位置。

3-2 在 Li₂CuP 的六方晶胞如下所示，其中 a = 404.5 pm；c = 772.4 pm：

`bdwp资源/06晶体总结_images/fd91ad6f6d64b236579ef8940ec6e3c5d3ec9dc7321dac8472d99348485fb83f.jpg`，待媒体仓库入库后补链。

3-2-1 指出浅色小球、深色小球、深色大球各自是哪种原子？

3-2-2 晶胞中有几种化学环境、几种空间环境的锂原子？

3-2-3 指出铜原子、磷原子的配位环境。

3-2-4 计算此晶体的密度。

## 解答

3-1 锂在**全部的棱心和体心**（八面体空隙中心），铜在**全部的四面体空隙中心**（2 分）。

3-2-1 浅色小球、深色小球、深色大球各自是**铜原子、锂原子、磷原子**（1.5 分）。

3-2-2 原书解答未给出（讲义 OCR 未收录该小题的解答文字）。

3-2-3 原书解答未给出（讲义 OCR 未收录该小题的解答文字）。

3-2-4 D = zM/VN_A = zM/a²c·sin 120°·N_A = 2×108.40 g·mol⁻¹/[(404.5 pm)²×772.4 pm×sin 120°×10⁻³⁰ cm³·pm⁻³×6.022×10²³ mol⁻¹] = **3.289 g·cm⁻³**（3 分）

## 解析要点

- 3-1 是**空隙填充**的标准题型：先由"Si 做面心立方堆积"确定四面体空隙（8 个/晶胞）与八面体空隙（4 个/晶胞）的数目，再用化学式 LiCu₂Si 的比例（1:2:1）定出占据方式——Li 填八面体空隙、Cu 填四面体空隙。
- 3-2-4 中 M(Li₂CuP) = 2×6.941 + 63.55 + 30.97 = 108.40 g·mol⁻¹，z = 2；六方晶胞 V = a²c·sin 120°。
- 同系列 LiCu₂Si（面心立方堆积型）与 Li₂CuP（六方）"结构并不类似"，说明填充型合金相的结构强烈依赖阳离子半径比与电子计数，不能由化学式相似外推。
