# HChO晶-21 [N(C₂H₅)₄]₂(TiOCl₄) 的晶胞与键长（10 分）

> 来源：HChO 第18届培训班综合卷 第8题；讲义晶体练习

## 题目

在 CH₃CN 中采用 [N(C₂H₅)₄]Cl 与 Ti₂OCl₆ 反应，可制得离子化合物 X 的单晶。X 的化学式可写作 [N(C₂H₅)₄]x(Y) 的形式。对 X 的单晶进行 X-射线衍射后，科研人员于 1968 年得到了其晶体结构。已知 X 的四方晶胞的空间群为 P4₂nm，晶胞参数 a = 9.90 Å；c = 12.34 Å。部分位置所填入的原子如下（所有 Ti 原子已给出）：

| 坐标 | 原子 |
|---|---|
| (0.000, 0.000, 0.000) | Ti |
| (0.500, 0.500, 0.500) | Ti |
| (0.337, 0.337, 0.462) | Cl |
| (0.163, 0.163, 0.962) | Cl |
| (0.500, 0.500, 0.645) | O |
| (0.500, 0.000, 0.245) | N |

8-1 计算 Ti-Cl 键长。

8-2 画出晶胞。

8-3 写出 X 的化学式。

8-4 计算此晶体的密度。

## 解答

8-1 以体心的 Ti 以及 (0.337, 0.337, 0.462) 的 Cl 为例：

d = {[(0.500−0.337)×9.90 Å]² + [(0.500−0.337)×9.90 Å]² + [(0.500−0.462)×12.34 Å]²}^(1/2) = **2.33 Å**

在正常键长范围之内，故 Ti-Cl 键长为 **2.33 Å**（2 分）。

8-2 补全后的晶胞：

![[70178de98e6824cb964290cb95f7801e68c5057d3c35152663e416d7b8a1918f.jpg]]（4 分）。

原书另附**错误结构**（对应简单四方）：![[df819618858e88a0b120d8981c80d3a6a84a8f3fb3150cce8e0e9c81fece844c.jpg]]——答成此结构得 2 分。

8-3 X 的化学式：**[N(C₂H₅)₄]₂(TiOCl₄)**（1 分）

8-4 D = ZM/a²c×N_A = 2×466.18 g·mol⁻¹/[(9.90 Å)²×12.34 Å×10⁻²⁴ cm³·Å⁻³×6.022×10²³ mol⁻¹] = **1.28 g·cm⁻³**（3 分）

## 解析要点

- 8-1 用**分数坐标差 → 乘晶胞参数 → 平方和开根**的标准流程，注意 a ≠ c，x、y 方向乘 9.90 Å、z 方向乘 12.34 Å。
- 8-2 的关键是区分 **P4₂ 螺旋轴 vs 简单四方的镜像**：Ti 只占 (0,0,0) 与 (1/2,1/2,1/2) 两个位置，但 Cl 的 z 高度（0.462 vs 0.962）显示上下两个 Ti 的配位**旋转了 90°/发生螺旋平移**，据此画出 P4₂nm 而非简单四方。
- 8-3 的化学式由电荷与配位共同定出：Ti 为 +4（TiOCl₄²⁻ 阴离子）、N(C₂H₅)₄⁺ 为 +1，故需 2 个阳离子配 1 个阴离子。
- 8-4 中 M = 2×130.25 + 205.67 = 466.18 g·mol⁻¹，z = 2。
