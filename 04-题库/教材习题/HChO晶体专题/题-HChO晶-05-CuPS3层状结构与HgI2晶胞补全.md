# HChO晶-05 CuPS₃ 的层状结构与 HgI₂ 晶胞补全（11 分）

> 来源：HChO 第2届联考 第6题；讲义晶体练习

## 题目

**6-1** 在某四方晶系的复合硫化物中，硫原子做 ABCABC 型堆积，铜原子和磷原子共计占据三分之一的四面体空隙，从而形成了独特的平面层结构，其晶胞示意图如右所示。图中铜原子位于晶胞的面上，磷原子则位于棱上和晶胞内。所有四面体均近似为正四面体。

![[cb63f1c267dd1bdbbb2bb69f64ef30768c0b20a8ee229680fb23454808310637.jpg]]。

6-1-1 该晶体的磁矩为 0，写出其中存在的孤立阴离子的化学式。

6-1-2 写出该硫化物的化学式以及全部铜原子的原子坐标。

6-1-3 已知该晶体的密度 D = 2.91 g·cm⁻³，求其晶胞参数 a 和 c 的近似值（以 pm 为单位）。

**6-2** 在答题纸中给出了二碘化汞的晶胞示意图（只有所有碘原子被标出），晶胞中只有一种化学环境的碘原子。所有汞原子则都在晶胞的侧面上，它们均填入四面体空隙中。补全该结构示意图。

![[d5342bc021a7ffabbd10cd414c9b93d23602de4fb73dab35ea895d189d573d4c.jpg]]、![[90511ae44cbd143caf225eccc262dd3caa8e08b725c2e6094e715c4db39ce5fe.jpg]]、![[66892d05f04e10bdac48629326643ce1f0b34c4362b00ba82b0605cfc4c3768c.jpg]]。

## 解答

6-1-1 孤立阴离子的化学式：**P₂S₆²⁻**（1 分）

6-1-2 该硫化物的化学式：**CuPS₃**（1 分，写 Cu₂P₂S₆ 也得分）。

铜原子的原子坐标：(0, 0.5, 0.25)；(0.5, 0, 0.25)；(0, 0.5, 0.75)；(0.5, 0, 0.75)（2 分）。

> 若写 (0,0.5,0.25)；(0.5,0,0.25)；(0,0.5,0.75)；(0.5,0,0.75)；(1,0.5,0.25)；(0.5,1,0.25)；(1,0.5,0.75)；(0.5,1,0.75) 这 8 个，只得 1 分；但只写后 4 个不得分；只要写出不属于以上 8 个中任意一个的，不得分。

6-1-3 因为晶胞中所有四面体均为近似正四面体，故 Cu-S 四面体和 P-S 四面体的大小近似相等，四面体的棱长为 a/√2。则沿 z 轴方向四面体的高度为 (a/√2)/√2 = a/2（1 分），则 c = 6×a/2 = 3a（1 分）。

a²c = 3a³ = V = [zM/DN_A = 4×190.73 g·mol⁻¹/(2.91 g·cm⁻³×6.022×10²³ mol⁻¹)]×10³⁰ pm³·cm⁻³，3a³ = 4.35×10⁸ pm³，**a = 525 pm，c = 3a = 1576 pm**（3 分）

> 得出 c = 3a 的结论时，叙述合理即可得 2 分，但不叙述仅得 1 分结论分。本问不要求有效数字；a 在 520~530 pm、c 在 1560~1590 pm 之间均可得分。

## 解析要点

- 6-1-1 的"磁矩为 0"提示无单电子，硫以二聚 S₂²⁻（即 P₂S₆²⁻ 中的 S₆ 环）形式存在；孤立阴离子取 P₂S₆²⁻ 而非 P⁵⁺ 与 S²⁻ 的简单组合。
- 6-1-3 的关键是**用几何关系定出 c 与 a 的比例**（正四面体高 = 棱长的 1/√2 倍，六层四面体叠成 c = 3a），再用密度公式只解一个未知量 a。
- 坐标题要区分"晶胞内独立坐标"与"由平移重复出来的等价坐标"：把 (1, 0.5, 0.25) 一类晶胞外平移点一并列出会扣分。
