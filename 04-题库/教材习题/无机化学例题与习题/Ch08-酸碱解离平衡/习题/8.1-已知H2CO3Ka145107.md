# 8.1 已知H2CO3Ka1^=4.510^-7

## 题目

已知 $\mathrm{H_2CO_3}$ $K_{a_1}^{\ominus} = 4.5\times10^{-7}$，$K_{a_2}^{\ominus} = 4.7\times10^{-11}$；$\mathrm{H_2S}$ $K_{a_1}^{\ominus} = 1.1\times10^{-7}$，$K_{a_2}^{\ominus} = 1.3\times10^{-13}$。将相同浓度的 $\mathrm{H_2S}$ 和 $\mathrm{H_2CO_3}$ 溶液等体积混合后，下列对离子浓度相对大小表达正确的是

(A) $c(\mathrm{CO_3^{2-}}) < c(\mathrm{S^{2-}})$

(B) $c(\mathrm{CO_3^{2-}}) > c(\mathrm{S^{2-}})$

(C) $c(\mathrm{HCO_3^-}) < c(\mathrm{S^{2-}})$

(D) $c(\mathrm{HS^-}) < c(\mathrm{CO_3^{2-}})$

## 参考答案

(B)**

**解析：** $\mathrm{H_2CO_3}$ 的 $K_{a_2}^{\ominus} = 4.7\times10^{-11}$ 远大于 $\mathrm{H_2S}$ 的 $K_{a_2}^{\ominus} = 1.3\times10^{-13}$，说明 $\mathrm{HCO_3^-}$ 的解离能力强于 $\mathrm{HS^-}$，故混合后 $c(\mathrm{CO_3^{2-}}) > c(\mathrm{S^{2-}})$。
