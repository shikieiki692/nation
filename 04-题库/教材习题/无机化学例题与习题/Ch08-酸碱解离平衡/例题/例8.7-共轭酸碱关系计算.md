# 例8.7

指出下列各反应式中的所有共轭酸碱关系，从相关参考书中查出酸（或碱）的 $K_a^{\ominus}$（或 $K_b^{\ominus}$），再计算出其共轭碱（或酸）的 $K_b^{\ominus}$（或 $K_a^{\ominus}$）：

(1) $\mathrm{HSO_4^- + OH^- = SO_4^{2-} + H_2O}$

(2) $\mathrm{PO_4^{3-} + H_2O = HPO_4^{2-} + OH^-}$

(3) $\mathrm{CO_3^{2-} + H_2O = HCO_3^- + OH^-}$

(4) $\mathrm{NH_3 + H_2S = NH_4^+ + HS^-}$

## 解

|  | 共轭酸 | 共轭碱 | 查出的 $K_a^{\ominus}(K_b^{\ominus})$ | 计算出的 $K_b^{\ominus}(K_a^{\ominus})$ |
|---|---|---|---|---|
| (1) | $\mathrm{HSO_4^-}$、$\mathrm{H_2O}$ | $\mathrm{SO_4^{2-}}$、$\mathrm{OH^-}$ | $K_a^{\ominus}(\mathrm{HSO_4^-}) = 1.0\times10^{-2}$ | $K_b^{\ominus}(\mathrm{SO_4^{2-}}) = 1.0\times10^{-12}$ |
| (2) | $\mathrm{HPO_4^{2-}}$、$\mathrm{H_2O}$ | $\mathrm{PO_4^{3-}}$、$\mathrm{OH^-}$ | $K_a^{\ominus}(\mathrm{HPO_4^{2-}}) = 4.8\times10^{-13}$ | $K_b^{\ominus}(\mathrm{PO_4^{3-}}) = 2.1\times10^{-2}$ |
| (3) | $\mathrm{HCO_3^-}$、$\mathrm{H_2O}$ | $\mathrm{CO_3^{2-}}$、$\mathrm{OH^-}$ | $K_a^{\ominus}(\mathrm{HCO_3^-}) = 4.7\times10^{-11}$ | $K_b^{\ominus}(\mathrm{CO_3^{2-}}) = 2.1\times10^{-4}$ |
| (4) | $\mathrm{H_2S}$、$\mathrm{NH_4^+}$ | $\mathrm{HS^-}$、$\mathrm{NH_3}$ | $K_a^{\ominus}(\mathrm{H_2S}) = 1.1\times10^{-7}$，$K_b^{\ominus}(\mathrm{NH_3}) = 1.8\times10^{-5}$ | $K_b^{\ominus}(\mathrm{HS^-}) = 9.1\times10^{-8}$，$K_a^{\ominus}(\mathrm{NH_4^+}) = 5.6\times10^{-10}$ |

从 $K_a^{\ominus}(K_b^{\ominus})$ 计算其共轭碱的 $K_b^{\ominus}$（共轭酸的 $K_a^{\ominus}$）的公式是 $K_a^{\ominus} \cdot K_b^{\ominus} = K_w^{\ominus}$。
