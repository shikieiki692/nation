# 22.13 给出下列物质的化学式

## 题目

给出下列物质的化学式

| 序号 | 名称 | 化学式 |
|------|------|--------|
| (1) | 赤铁矿 | $\mathrm{Fe}_{2}\mathrm{O}_{3}$ |
| (2) | 磁铁矿 | $\mathrm{Fe}_{3}\mathrm{O}_{4}$ |
| (3) | 褐铁矿 | $2\mathrm{Fe}_{2}\mathrm{O}_{3}\cdot3\mathrm{H}_{2}\mathrm{O}$ |
| (4) | 菱铁矿 | $\mathrm{FeCO}_{3}$ |
| (5) | 砷钴矿 | $\mathrm{CoAs}_{2}$ |
| (6) | 辉钴矿 | CoAsS |
| (7) | 硫钴矿 | $\mathrm{Co}_{2}\mathrm{S}_{4}$ |
| (8) | 赤血盐 | $\mathrm{K}_{3}[\mathrm{Fe}(\mathrm{CN})_{6}]$ |
| (9) | 黄血盐 | $\mathrm{K}_{4}[\mathrm{Fe}(\mathrm{CN})_{6}]\cdot3\mathrm{H}_{2}\mathrm{O}$ |
| (10) | 绿矾 | $\mathrm{FeSO}_{4}\cdot7\mathrm{H}_{2}\mathrm{O}$ |
| (11) | 莫尔盐 | $(\mathrm{NH}_{4})_{2}\mathrm{SO}_{4}\cdot\mathrm{FeSO}_{4}\cdot6\mathrm{H}_{2}\mathrm{O}$ |
| (12) | 铁铵矾 | $\mathrm{NH}_{4}\mathrm{Fe}(\mathrm{SO}_{4})_{2}\cdot12\mathrm{H}_{2}\mathrm{O}$ |
| (13) | 二茂铁 | $\mathrm{Fe}(\mathrm{C}_{5}\mathrm{H}_{5})_{2}$ |
| (14) | 蔡斯盐 | $\mathrm{K}[\mathrm{Pt}(\mathrm{C}_{2}\mathrm{H}_{4})\mathrm{Cl}_{3}]$ |
| (15) | 顺铂 | $cis\text{-}\mathrm{Pt}(\mathrm{NH}_{3})_{2}\mathrm{Cl}_{2}$ |
