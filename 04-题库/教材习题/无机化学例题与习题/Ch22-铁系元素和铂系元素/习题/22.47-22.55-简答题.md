# 习题 简答题（22.47-22.55）

## 题目与答案

### 22.47 分别向 FeSO4、CoSO4、NiSO4 溶液中缓慢滴加氨水，生成的产物和实验现象是什么？

## 参考答案

**向FeSO4溶液中缓慢滴加氨水**：先有白色沉淀生成，后迅速变成灰绿色，最终变成红棕色的沉淀：

$$\mathrm{Fe}^{2+} + 2\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = \mathrm{Fe(OH)}_{2}\downarrow\text{（白色）} + 2\mathrm{NH}_{4}^{+}$$

$$4\mathrm{Fe(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{Fe(OH)}_{3}\text{（红棕色）}$$

**在CoSO4溶液中滴加氨水**：先析出蓝绿色沉淀，氨水过量时沉淀溶解，生成棕黄色溶液，在空气中放置，溶液逐渐变成棕褐色：

$$2\mathrm{CoSO}_{4} + 2\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = \mathrm{Co(OH)}_{2}\cdot\mathrm{CoSO}_{4}\downarrow + (\mathrm{NH}_{4})_{2}\mathrm{SO}_{4}$$

$$\mathrm{Co(OH)}_{2}\cdot\mathrm{CoSO}_{4} + 12\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = 2[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{OH}^{-} + \mathrm{SO}_{4}^{2-} + 12\mathrm{H}_{2}\mathrm{O}$$

$$4[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{2+} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{3+} + 4\mathrm{OH}^{-}$$

**向NiSO4溶液中缓慢滴加氨水**：先有绿色沉淀生成：

$$\mathrm{Ni}^{2+} + 2\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = \mathrm{Ni(OH)}_{2}\downarrow + 2\mathrm{NH}_{4}^{+}$$

氨水过量则绿色沉淀溶解，生成蓝色 $\left[\mathrm{Ni}(\mathrm{NH}_{3})_{6}\right]^{2+}$ 溶液：

$$\mathrm{Ni(OH)}_{2} + 6\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = [\mathrm{Ni}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{OH}^{-} + 6\mathrm{H}_{2}\mathrm{O}$$

### 22.48 为什么铝板氧化层用极稀的 Co(NO3)2 溶液处理后灼烧，即显蓝色？

**答案**：

铝板氧化层用极稀的 $\mathrm{Co(NO_{3})_{2}}$ 溶液处理后灼烧，加热条件下 $\mathrm{Co(NO_{3})_{2}}$ 分解生成 CoO：

$$2\mathrm{Co}(\mathrm{NO}_{3})_{2}\stackrel{\triangle}{=}2\mathrm{CoO} + 4\mathrm{NO}_{2}\uparrow + \mathrm{O}_{2}\uparrow$$

CoO 与铝板氧化层的 $\mathrm{Al}_{2}\mathrm{O}_{3}$ 作用生成蓝色的偏铝酸钴：

$$\mathrm{CoO} + \mathrm{Al}_{2}\mathrm{O}_{3} = \mathrm{Co}(\mathrm{AlO}_{2})_{2}$$

因而显蓝色。

### 22.49 利用 NH4SCN 试剂鉴定 Co2+ 时，为什么要用浓的 NH4SCN 溶液，并加丙酮萃取？溶液中存在什么常见离子时会发生干扰？如何消除这些干扰？

**答案**：

$\mathrm{Co}^{2+}$ 与 $\mathrm{SCN}^{-}$ 结合形成蓝色的 $[\mathrm{Co}(\mathrm{SCN})_{4}]^{2-}$，常用于 $\mathrm{Co}^{2+}$ 的鉴定。但该配离子稳定常数较小，在水溶液中有时不易观察到蓝色。用水稀释时也易变成粉红色的 $[\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+}$。所以在实际操作时，使用浓的 $\mathrm{NH}_{4}\mathrm{SCN}$ 溶液，并加入丙酮（或戊醇）进行萃取，以抑制 $[\mathrm{Co}(\mathrm{SCN})_{4}]^{2-}$ 的解离，确保观察到该离子显示的蓝色。

溶液中若有 $\mathrm{Fe}^{3+}$ 存在，它将与 $\mathrm{SCN}^{-}$ 结合形成血红色配离子，干扰 $\mathrm{Co}^{2+}$ 的鉴定。通常加入 $\mathrm{F}^{-}$ 与 $\mathrm{Fe}^{3+}$ 形成更稳定的 $[\mathrm{FeF}_{6}]^{3-}$ 无色配离子以消除干扰。

### 22.50 在用稀硫酸清洗被 Co(OH)3 和 MnO(OH)2 污染的玻璃器皿时，为什么要加入一些过氧化氢溶液？

**答案**：

由于 $\mathrm{Co(OH)}_{3}$ 和 $\mathrm{MnO(OH)}_{2}$ 都是难溶物，它们附着在被污染的玻璃器皿壁上难以完全去除，在酸性条件下，加入一些过氧化氢溶液作为还原剂，把 $\mathrm{Co(III)}$ 和 $\mathrm{Mn(IV)}$ 还原为易溶物而除去：

$$2\mathrm{Co(OH)}_{3} + \mathrm{H}_{2}\mathrm{O}_{2} + 4\mathrm{H}^{+} = 2\mathrm{Co}^{2+} + \mathrm{O}_{2}\uparrow + 6\mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{MnO(OH)}_{2} + \mathrm{H}_{2}\mathrm{O}_{2} + 2\mathrm{H}^{+} = \mathrm{Mn}^{2+} + \mathrm{O}_{2}\uparrow + 3\mathrm{H}_{2}\mathrm{O}$$

### 22.51 [Ni(CO)4] 和 [Ni(CN)4]2- 都是逆磁性的，两者在结构上是否相同？试用配位化合物的价键理论给予说明。

**答案**：

$\left[\mathrm{Ni}(\mathrm{CO})_{4}\right]$ 中 Ni 的电子构型为 $3\mathrm{d}^{10}$，Ni 采取 $\mathrm{sp}^{3}$ 杂化，$\left[\mathrm{Ni}(\mathrm{CO})_{4}\right]$ 的空间构型为四面体形，Ni 原子中无成单电子，所以配位化合物为逆磁性。

$\left[\mathrm{Ni}(\mathrm{CN})_{4}\right]^{2-}$ 中 $\mathrm{Ni}^{2+}$ 的电子构型为 $3\mathrm{d}^{8}$，$\mathrm{Ni}^{2+}$ 采取 $\mathrm{dsp}^{2}$ 杂化，$\left[\mathrm{Ni}(\mathrm{CN})_{4}\right]^{2-}$ 的空间构型为平面四边形，$\mathrm{Ni}^{2+}$ 中也无成单电子，所以配位化合物也为逆磁性。

两者结构不同：前者为四面体形（sp3杂化），后者为平面四边形（dsp2杂化）。

### 22.52 写出与下述实验现象有关的化学反应方程式

向含有 $\mathrm{Fe}^{2+}$ 的溶液中加入 NaOH 溶液后生成灰绿色沉淀，空气中放置沉淀逐渐变为棕色。过滤后，用盐酸溶解棕色沉淀得黄色溶液。向黄色溶液中加几滴 KSCN 溶液则溶液立即变红，再通入 $\mathrm{SO}_{2}$ 气体则红色消失。向溶液中再滴入 $\mathrm{KMnO}_{4}$ 溶液，则 $\mathrm{KMnO}_{4}$ 紫色褪去。最后加入黄血盐溶液时，生成蓝色沉淀。

**答案**：

$$\mathrm{Fe}^{2+} + 2\mathrm{OH}^{-} = \mathrm{Fe(OH)}_{2}\downarrow\text{（白色→灰绿色→棕色）}$$

$$4\mathrm{Fe(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{Fe(OH)}_{3}\text{（棕色）}$$

$$\mathrm{Fe(OH)}_{3} + 3\mathrm{HCl} = \mathrm{FeCl}_{3} + 3\mathrm{H}_{2}\mathrm{O}\text{（黄色）}$$

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n}\text{（血红色）}$$

$$2[\mathrm{Fe(SCN)}_{n}]^{3-n} + \mathrm{SO}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 2\mathrm{Fe}^{2+} + \mathrm{SO}_{4}^{2-} + 4\mathrm{H}^{+} + 2n\mathrm{SCN}^{-}\text{（红色消失）}$$

$$\mathrm{MnO}_{4}^{-} + 5\mathrm{Fe}^{2+} + 8\mathrm{H}^{+} = \mathrm{Mn}^{2+} + 5\mathrm{Fe}^{3+} + 4\mathrm{H}_{2}\mathrm{O}\text{（紫色褪去）}$$

$$\mathrm{Fe}^{3+} + [\mathrm{Fe}(\mathrm{CN})_{6}]^{4-} + \mathrm{K}^{+} = \mathrm{K}[\mathrm{FeFe}(\mathrm{CN})_{6}]\downarrow\text{（蓝色）}$$

### 22.53 给出下列实验的现象和化学反应方程式

**(1) 向含有CCl4的黄血盐溶液中滴加碘水**

$\mathrm{I}_{2}$ 的颜色消失：

$$2[\mathrm{Fe}(\mathrm{CN})_{6}]^{4-} + \mathrm{I}_{2} = 2[\mathrm{Fe}(\mathrm{CN})_{6}]^{3-} + 2\mathrm{I}^{-}$$

**(2) 将3 mol·dm-3 CoCl2溶液加热，再滴加AgNO3溶液**

加热后溶液由粉红色变蓝色：

$$[\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + 4\mathrm{Cl}^{-} = [\mathrm{CoCl}_{4}]^{2-} + 6\mathrm{H}_{2}\mathrm{O}$$

再加入 $\mathrm{AgNO}_{3}$ 溶液，溶液由蓝色变粉红色，并有白色沉淀生成：

$$[\mathrm{CoCl}_{4}]^{2-} + 4\mathrm{Ag}^{+} + 6\mathrm{H}_{2}\mathrm{O} = [\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + 4\mathrm{AgCl}\downarrow$$

**(3) 将[Ni(NH3)6]SO4溶液水浴加热一段时间再加氨水**

水浴加热后，有绿色沉淀生成：

$$[\mathrm{Ni}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{H}_{2}\mathrm{O}\stackrel{\triangle}{=}\mathrm{Ni}(\mathrm{OH})_{2}\downarrow + 2\mathrm{NH}_{4}^{+} + 4\mathrm{NH}_{3}\uparrow$$

再加入氨水，沉淀又溶解，得蓝色溶液：

$$\mathrm{Ni(OH)}_{2} + 6\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = [\mathrm{Ni}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{OH}^{-} + 6\mathrm{H}_{2}\mathrm{O}$$

**(4) 用浓盐酸处理Fe(OH)3、Co(OH)3、Ni(OH)3**

- Fe(OH)3：棕色Fe(OH)3溶解，得黄色溶液

$$\mathrm{Fe(OH)}_{3} + 3\mathrm{HCl} = \mathrm{FeCl}_{3} + 3\mathrm{H}_{2}\mathrm{O}$$

- Co(OH)3：棕褐色Co(OH)3溶解，得粉红色溶液，并有氯气放出

$$2\mathrm{Co(OH)}_{3} + 2\mathrm{Cl}^{-} + 6\mathrm{H}^{+} + 6\mathrm{H}_{2}\mathrm{O} = 2[\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + \mathrm{Cl}_{2}\uparrow$$

浓盐酸过量时，溶液变蓝：

$$[\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + 4\mathrm{Cl}^{-} = [\mathrm{CoCl}_{4}]^{2-} + 6\mathrm{H}_{2}\mathrm{O}$$

- Ni(OH)3：黑色Ni(OH)3溶解，得绿色溶液并有氯气放出

$$2\mathrm{Ni}(\mathrm{OH})_{3} + 2\mathrm{Cl}^{-} + 6\mathrm{H}^{+} + 6\mathrm{H}_{2}\mathrm{O} = 2[\mathrm{Ni}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + \mathrm{Cl}_{2}\uparrow$$

### 22.54 解释实验现象

**(1) FeCl3溶液加KSCN变红，加铁粉后红色消失**

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n}\text{（n=1～6，血红色）}$$

加入铁粉后，铁粉将 $\left[\mathrm{Fe}(\mathrm{SCN})_{n}\right]^{3-n}$ 还原，生成的 $\mathrm{Fe}^{2+}$ 不与 $\mathrm{SCN}^{-}$ 生成有色配位化合物，因而血红色消失：

$$2[\mathrm{Fe(SCN)}_{n}]^{3-n} + \mathrm{Fe} = 3\mathrm{Fe}^{2+} + n\mathrm{SCN}^{-}$$

**(2) FeCl3加(NH4)2C2O4后加KSCN不变红，加盐酸后变红**

$\mathrm{FeCl}_{3}$ 遇 $(\mathrm{NH}_{4})_{2}\mathrm{C}_{2}\mathrm{O}_{4}$ 生成稳定的 $[\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]^{3-}$，其稳定性比 $[\mathrm{Fe}(\mathrm{SCN})]^{2+}$ 高，因而加入少量 KSCN 溶液时不变红：

$$\mathrm{Fe}^{3+} + 3\mathrm{C}_{2}\mathrm{O}_{4}^{2-} = [\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]^{3-}$$

再加入盐酸时，$\mathrm{C}_{2}\mathrm{O}_{4}^{2-}$ 转化为 $\mathrm{HC}_{2}\mathrm{O}_{4}^{-}$ 弱酸或 $\mathrm{H}_{2}\mathrm{C}_{2}\mathrm{O}_{4}$ 中强酸，而使 $\left[\mathrm{Fe}\left(\mathrm{C}_{2}\mathrm{O}_{4}\right)_{3}\right]^{3-}$ 破坏，再由 $\mathrm{Fe}^{3+}$ 与 $\mathrm{SCN}^{-}$ 结合使溶液变红：

$$[\mathrm{Fe}(\mathrm{C}_{2}\mathrm{O}_{4})_{3}]^{3-} + 3\mathrm{H}^{+} = \mathrm{Fe}^{3+} + 3\mathrm{HC}_{2}\mathrm{O}_{4}^{-}$$

$$\mathrm{Fe}^{3+} + \mathrm{SCN}^{-} = [\mathrm{Fe}(\mathrm{SCN})]^{2+}$$

**(3) 蓝色变色硅胶吸水后变粉红色**

变色硅胶中含有吸湿指示剂 $\left(\mathrm{CoCl}_{2}\right)$，随所含结晶水的数目不同，颜色不同：

$$\mathrm{CoCl}_{2}\cdot6\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}\cdot2\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}\cdot\mathrm{H}_{2}\mathrm{O}\rightleftharpoons\mathrm{CoCl}_{2}$$

所以，无水 $\mathrm{CoCl}_{2}$ 显蓝色，$\mathrm{CoCl}_{2}$ 结晶水较多时显粉红色。

**(4) [Co(NH3)6]SO4加稀盐酸先沉淀后溶解**

向 $\left[\mathrm{Co}\left(\mathrm{NH}_{3}\right)_{6}\right]^{2+}$ 溶液中缓慢滴加稀盐酸，先有蓝绿色沉淀生成：

$$[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{2+} + \mathrm{HCl} + \mathrm{H}_{2}\mathrm{O} = \mathrm{Co(OH)Cl}\downarrow + 4\mathrm{NH}_{3} + 2\mathrm{NH}_{4}^{+}$$

盐酸过量则蓝绿色沉淀溶解，生成粉红色 $\left[\mathrm{Co}\left(\mathrm{H}_{2}\mathrm{O}\right)_{6}\right]^{2+}$ 溶液：

$$\mathrm{Co(OH)Cl} + \mathrm{HCl} + 5\mathrm{H}_{2}\mathrm{O} = [\mathrm{Co}(\mathrm{H}_{2}\mathrm{O})_{6}]^{2+} + 2\mathrm{Cl}^{-}$$

**(5) FeCl3溶液通入H2S无硫化物沉淀**

酸性条件下，$\mathrm{FeCl}_{3}$ 可以将 $\mathrm{H}_{2}\mathrm{S}$ 氧化，生成单质硫：

$$2\mathrm{FeCl}_{3} + \mathrm{H}_{2}\mathrm{S} = 2\mathrm{FeCl}_{2} + \mathrm{S}\downarrow + 2\mathrm{HCl}$$

$\mathrm{FeCl}_{3}$ 溶液的酸性较强，上述反应过程中又生成 HCl，而 FeS 在酸中的溶解度较大，不能沉淀。所以向 $\mathrm{FeCl}_{3}$ 溶液中通入 $\mathrm{H}_{2}\mathrm{S}$ 气体不会有硫化物沉淀生成。

### 22.55 推断题（紫红色混合溶液）

混合溶液(A)为紫红色。向(A)中加入浓盐酸并微热得蓝色溶液(B)和气体(C)。(A)中加入NaOH溶液则得棕黑色沉淀(D)和绿色溶液(E)。向(A)中通入过量 $\mathrm{SO}_{2}$ 气体则溶液最后变为粉红色溶液(F)。向(F)中加入过量氨水得白色沉淀(G)和棕黄色溶液(H)。(G)在空气中缓慢转变为棕黑色。将(D)与(G)混合后加入硫酸又得溶液(A)。

**答案**：

(A) — $\mathrm{MnO}_{4}^{-} + \mathrm{Co}^{2+}$
(B) — $\left[\mathrm{CoCl}_{4}\right]^{2-} + \mathrm{Mn}^{2+}$
(C) — $\mathrm{Cl}_{2}$
(D) — $\mathrm{Co(OH)}_{3}$
(E) — $\mathrm{MnO}_{4}^{2-}$
(F) — $\mathrm{Mn}^{2+} + \mathrm{Co}^{2+}$
(G) — $\mathrm{Mn(OH)}_{2}$
(H) — $[\mathrm{Co}(\mathrm{NH}_{3})_{6}]^{2+}$
