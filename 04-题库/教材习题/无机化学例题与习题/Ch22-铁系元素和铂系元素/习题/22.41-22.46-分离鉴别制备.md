# 习题 分离、鉴别与制备（22.41-22.46）

## 题目与答案

### 22.41 以粗镍为原料制备高纯镍

## 参考答案

在 50～100 ℃ 条件下，使粗 Ni 粉末与 CO 反应生成液态的 $\left[\mathrm{Ni}(\mathrm{CO})\right]_{4}$，分离后将 $\left[\mathrm{Ni}(\mathrm{CO})\right]_{4}$ 在 200 ℃ 加热分解，即得到高纯 Ni：

$$\mathrm{Ni(s)} + 4\mathrm{CO(g)}\xlongequal{50\sim100^{\circ}\mathrm{C}}[\mathrm{Ni}(\mathrm{CO})]_{4}(\mathrm{l})$$

$$[\mathrm{Ni}(\mathrm{CO})]_{4}(\mathrm{l})\xlongequal{200^{\circ}\mathrm{C}}\mathrm{Ni(s)} + 4\mathrm{CO(g)}$$

### 22.42 如何鉴别分别含有 Fe3+、Co2+ 和 Ni2+ 的溶液？

**答案**：

**Fe3+ 的鉴别：**

(1) 与 KSCN 作用产生血红色：

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n}\text{（血红色）}$$

(2) 与黄血盐 $\mathrm{K}_{4}[\mathrm{Fe}(\mathrm{CN})_{6}]$ 作用产生蓝色沉淀：

$$\mathrm{K}^{+} + \mathrm{Fe}^{3+} + [\mathrm{Fe}(\mathrm{CN})_{6}]^{4-} = \mathrm{K}[\mathrm{FeFe}(\mathrm{CN})_{6}]\downarrow\text{（蓝色）}$$

**Co2+ 的鉴别：**

加入饱和 KSCN 溶液及丙酮（或乙醚），在丙酮（或乙醚）层中产生蓝色：

$$\mathrm{Co}^{2+} + 4\mathrm{SCN}^{-} = [\mathrm{Co}(\mathrm{SCN})_{4}]^{2-}$$

若防止 $\mathrm{Fe}^{3+}$ 干扰 $\mathrm{Co}^{2+}$ 的鉴别，可加入 NaF 或 $\mathrm{NH}_{4}\mathrm{F}$ 掩蔽 $\mathrm{Fe}^{3+}$。

**Ni2+ 的鉴别：**

向溶液中滴加丁二酮肟，生成鲜红色沉淀，表示有 $\mathrm{Ni}^{2+}$ 存在。

若溶液中含有 $\mathrm{Fe}^{3+}$ 及 $\mathrm{Co}^{2+}$，则可用氨水调至碱性，有 $\mathrm{Fe(OH)}_{3}$ 析出，$\mathrm{Co}^{2+}$ 和 $\mathrm{Ni}^{2+}$ 在氨水过量时生成 $\left[\mathrm{Co}(\mathrm{NH}_{3})_{6}\right]^{2+}$ 和 $\left[\mathrm{Ni}(\mathrm{NH}_{3})_{6}\right]^{2+}$，离心分离除去沉淀；$\mathrm{Co}^{2+}$ 不与丁二酮肟反应，对实验无影响。

### 22.43 鉴别下列各组物质

**(1) NiSO4 和 FeSO4**

将样品溶于水，向两种溶液中滴加 NaOH 溶液，生成灰绿色沉淀并逐渐变成红棕色的是 $\mathrm{FeSO}_{4}$：

$$\mathrm{Fe}^{2+} + 2\mathrm{OH}^{-} = \mathrm{Fe(OH)}_{2}\downarrow$$

$$4\mathrm{Fe(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{Fe(OH)}_{3}$$

生成绿色沉淀，且不变色的为 $\mathrm{NiSO}_{4}$，进一步确认可加入氨水，该沉淀溶于氨水：

$$\mathrm{Ni}^{2+} + 2\mathrm{OH}^{-} = \mathrm{Ni(OH)}_{2}\downarrow$$

$$\mathrm{Ni(OH)}_{2} + 6\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = [\mathrm{Ni}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{OH}^{-} + 6\mathrm{H}_{2}\mathrm{O}$$

**(2) Fe2O3 和 CuO**

将样品溶于稀盐酸，后向其中滴加氨水，先生成浅蓝色沉淀，后沉淀溶解生成蓝色溶液的是 $\mathrm{CuO}$：

$$\mathrm{CuO} + 2\mathrm{HCl} = \mathrm{CuCl}_{2} + \mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{CuCl}_{2} + 2\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = \mathrm{Cu(OH)}_{2}\downarrow + 2\mathrm{NH}_{4}\mathrm{Cl}$$

$$\mathrm{Cu(OH)}_{2} + 4\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = [\mathrm{Cu}(\mathrm{NH}_{3})_{4}]^{2+} + 2\mathrm{OH}^{-} + 4\mathrm{H}_{2}\mathrm{O}$$

加入氨水，生成红棕色沉淀的是 $\mathrm{Fe}_{2}\mathrm{O}_{3}$，且该沉淀不溶于过量氨水：

$$\mathrm{Fe}^{3+} + 3\mathrm{OH}^{-} = \mathrm{Fe(OH)}_{3}\downarrow$$

### 22.44 设计方案分离共存于溶液中的下列离子

**(1) Al3+、Cr3+、Fe3+、Ni2+**

分离方案：
1. 加过量 NaOH：Fe3+→Fe(OH)3↓，Ni2+→Ni(OH)2↓，Al3+→[Al(OH)4]-，Cr3+→[Cr(OH)4]-
2. 过滤，沉淀为Fe(OH)3和Ni(OH)2；滤液含Al和Cr的羟基配合物
3. 滤液通CO2：Al(OH)3↓和Cr(OH)3↓
4. 沉淀加过量NaOH：Al(OH)3溶解，Cr(OH)3也溶解，需进一步用NH4Cl调pH分离
5. Fe(OH)3和Ni(OH)2加过量氨水：Ni2+溶解为[Ni(NH3)6]2+，Fe(OH)3不溶

**(2) Fe2+、Co2+、Zn2+、Cu2+**

分离方案：
1. 加过量NaOH：Fe(OH)2↓，Co(OH)2↓，Cu(OH)2↓，[Zn(OH)4]2-溶解
2. 过滤，滤液含Zn：加酸得Zn(OH)2↓
3. 沉淀加过量氨水：Cu→[Cu(NH3)4]2+溶解，Co→[Co(NH3)6]2+溶解，Fe(OH)2不溶
4. 分别处理Cu和Co的氨溶液

### 22.45 如何在不引入杂质的情况下，将粗ZnSO4溶液中含有的Fe3+、Fe2+、Cu2+杂质除去？

**答案**：

首先，向溶液中加入 Zn 粉，将 $\mathrm{Cu}^{2+}$ 还原为 Cu 过滤除去：

$$\mathrm{Zn} + \mathrm{Cu}^{2+} = \mathrm{Zn}^{2+} + \mathrm{Cu}$$

然后，向滤液中加入 $\mathrm{H}_{2}\mathrm{O}_{2}$，将溶液中的 $\mathrm{Fe}^{2+}$ 氧化为 $\mathrm{Fe}^{3+}$：

$$2\mathrm{Fe}^{2+} + \mathrm{H}_{2}\mathrm{O}_{2} + 2\mathrm{H}^{+} = 2\mathrm{Fe}^{3+} + 2\mathrm{H}_{2}\mathrm{O}$$

加入 ZnO 调节溶液的 pH=4～5，使 $\mathrm{Fe(OH)}_{3}$ 沉淀完全，过滤除去。

最后，将滤液加热，将多余的 $\mathrm{H}_{2}\mathrm{O}_{2}$ 分解除去。

### 22.46 完成下列过程的化学反应方程式（Pt化合物系列转化）

**答案**：

① 将单质 Pt 溶于王水中，滤液经蒸发、浓缩后，冷却得到红棕色的 $\mathrm{H}_{2}[\mathrm{PtCl}_{6}]$ 晶体：

$$3\mathrm{Pt} + 4\mathrm{HNO}_{3} + 18\mathrm{HCl} = 3\mathrm{H}_{2}[\mathrm{PtCl}_{6}] + 4\mathrm{NO}\uparrow + 8\mathrm{H}_{2}\mathrm{O}$$

② 将 $\mathrm{H}_{2}[\mathrm{PtCl}_{6}]$ 晶体在 300℃ 下加热分解，得到 $\mathrm{PtCl}_{4}$：

$$\mathrm{H}_{2}[\mathrm{PtCl}_{6}]\stackrel{\triangle}{=}\mathrm{PtCl}_{4} + 2\mathrm{HCl}\uparrow$$

③ 继续升高加热温度至 528℃，$\mathrm{PtCl}_{4}$ 分解得到橄榄绿色的 $\mathrm{PtCl}_{2}$：

$$\mathrm{PtCl}_{4} = \mathrm{PtCl}_{2} + \mathrm{Cl}_{2}\uparrow$$

④ 单质 Pt 加热至 250℃ 与 $\mathrm{Cl}_{2}$ 作用，可以得到橄榄绿色的 $\mathrm{PtCl}_{2}$：

$$\mathrm{Pt} + \mathrm{Cl}_{2}\stackrel{\triangle}{=}\mathrm{PtCl}_{2}$$

⑤ 向 $\mathrm{H}_{2}[\mathrm{PtCl}_{6}]$ 溶液中加入 KCl 固体，析出难溶的 $\mathrm{K}_{2}[\mathrm{PtCl}_{6}]$ 黄色晶体：

$$\mathrm{H}_{2}[\mathrm{PtCl}_{6}] + 2\mathrm{KCl} = \mathrm{K}_{2}[\mathrm{PtCl}_{6}]\downarrow + 2\mathrm{HCl}$$

⑥ 使用 $\mathrm{SO}_{2}$ 还原 $\mathrm{K}_{2}[\mathrm{PtCl}_{6}]$ 的水溶液，可以得到暗红色的 $\mathrm{K}_{2}[\mathrm{PtCl}_{4}]$：

$$\mathrm{K}_{2}[\mathrm{PtCl}_{6}] + \mathrm{SO}_{2} + 2\mathrm{H}_{2}\mathrm{O} = \mathrm{K}_{2}[\mathrm{PtCl}_{4}] + \mathrm{H}_{2}\mathrm{SO}_{4} + 2\mathrm{HCl}$$

⑦ 使 $\mathrm{PtCl}_{4}$ 在碱性条件下水解，得到红棕色的 $\mathrm{PtO}_{2}\cdot x\mathrm{H}_{2}\mathrm{O}$：

$$\mathrm{PtCl}_{4} + (x+2)\mathrm{H}_{2}\mathrm{O} = \mathrm{PtO}_{2}\cdot x\mathrm{H}_{2}\mathrm{O} + 4\mathrm{HCl}$$

⑧ 向 $\mathrm{PtCl}_{2}$ 中加入过量盐酸，得到 $\mathrm{H}_{2}[\mathrm{PtCl}_{4}]$ 的深红色溶液：

$$\mathrm{PtCl}_{2} + 2\mathrm{HCl} = \mathrm{H}_{2}[\mathrm{PtCl}_{4}]$$

⑨ 向 $\mathrm{H}_{2}[\mathrm{PtCl}_{4}]$ 溶液中加入 KCl，析出难溶的 $\mathrm{K}_{2}[\mathrm{PtCl}_{4}]$：

$$\mathrm{H}_{2}[\mathrm{PtCl}_{4}] + 2\mathrm{KCl} = \mathrm{K}_{2}[\mathrm{PtCl}_{4}]\downarrow + 2\mathrm{HCl}$$

⑩ 使 $\mathrm{K}_{2}[\mathrm{PtCl}_{4}]$ 在碱性条件下水解，析出难溶的黑色 $\mathrm{Pt(OH)}_{2}$：

$$\mathrm{K}_{2}[\mathrm{PtCl}_{4}] + 2\mathrm{OH}^{-} = \mathrm{Pt(OH)}_{2} + 2\mathrm{K}^{+} + 4\mathrm{Cl}^{-}$$
