# 例22.5 解释实验现象

## 题目

(1) 向 $\mathrm{FeSO}_{4}$ 溶液中加入碘水，碘水不褪色，再加入 $\mathrm{NaHCO}_{3}$ 后，碘水褪色。

(2) 向 $\mathrm{FeCl}_{3}$ 溶液中加入 KSCN 溶液，溶液立即变红，加入适量 $\mathrm{SnCl}_{2}$ 后溶液变成无色。

(3) $\mathrm{CoCl}_{2}$ 与 $\mathrm{NaOH}$ 作用所得的沉淀久置后用盐酸酸化时，有刺激性气味气体产生。

## 解答

### (1) FeSO4与碘水反应

酸性条件下，电对 $\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ 的标准电极电势为 0.77 V，碘水不能将 $\mathrm{Fe(II)}$ 氧化，因为电对 $\mathrm{I}_{2}/\mathrm{I}^{-}$ 的标准电极电势为 0.54 V，故向 $\mathrm{FeSO}_{4}$ 溶液中加入碘水，碘水不褪色。

体系中加入 $\mathrm{NaHCO}_{3}$ 后，涉及的电对变成了 $\mathrm{Fe(OH)}_{3}/\mathrm{Fe(OH)}_{2}$，由于 $\mathrm{Fe(OH)}_{3}$ 的溶度积远小于 $\mathrm{Fe(OH)}_{2}$，电极电势变得很低，为 -0.52 V。因此碘水很容易将 $\mathrm{Fe(II)}$ 氧化为 $\mathrm{Fe(III)}$，故碘水褪色。反应式为：

$$2\mathrm{Fe(OH)}_{2} + \mathrm{I}_{2} + 2\mathrm{OH}^{-} = 2\mathrm{Fe(OH)}_{3} + 2\mathrm{I}^{-}$$

### (2) FeCl3与KSCN、SnCl2反应

向 $\mathrm{FeCl}_{3}$ 溶液中加入 KSCN 溶液，生成红色的 $\left[\mathrm{Fe}(\mathrm{SCN})_{n}\right]^{3-n}$：

$$\mathrm{Fe}^{3+} + n\mathrm{SCN}^{-} = [\mathrm{Fe(SCN)}_{n}]^{3-n} \quad (n=1\sim6)$$

加入 $\mathrm{SnCl}_{2}$ 使 $\left[\mathrm{Fe}(\mathrm{SCN})_{n}\right]^{3-n}$ 中 $\mathrm{Fe}^{3+}$ 还原为 $\mathrm{Fe}^{2+}$，故红色消失，因为较稀的 $\mathrm{Fe}^{2+}$ 溶液近于无色：

$$2\left[\mathrm{Fe(SCN)}_{n}\right]^{3-n} + \mathrm{Sn}^{2+} = 2\mathrm{Fe}^{2+} + \mathrm{Sn}^{4+} + 2n\mathrm{SCN}^{-}$$

### (3) CoCl2与NaOH反应产物久置

$$\mathrm{CoCl}_{2} + 2\mathrm{NaOH} = \mathrm{Co(OH)}_{2}\downarrow + 2\mathrm{NaCl}$$

$\mathrm{Co(OH)}_{2}$ 久置后有部分被空气氧化：

$$4\mathrm{Co(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} = 4\mathrm{Co(OH)}_{3}$$

Co(Ⅲ)在酸性条件下有强氧化性，可以氧化 $\mathrm{Cl}^{-}$ 而产生有刺激性气味的 $\mathrm{Cl}_{2}$：

$$2\mathrm{Co}(\mathrm{OH})_{3} + 2\mathrm{Cl}^{-} + 6\mathrm{H}^{+} = 2\mathrm{Co}^{2+} + \mathrm{Cl}_{2}\uparrow + 6\mathrm{H}_{2}\mathrm{O}$$
