# 例22.8 推断题

## 题目

某金属(A)缓慢地溶于稀盐酸生成绿色溶液，从中可以结晶出绿色物质(B)。向绿色溶液中加入 NaOH 得绿色沉淀(C)，(C)不溶于过量 NaOH 溶液，但在大量 $\mathrm{NH}_{4}^{+}$ 存在时可溶于氨水生成蓝色溶液(D)。用气体(E)处理刚生成的沉淀(C)，沉淀颜色逐渐加深，最后转化为黑棕色的(F)。(F)与盐酸作用得绿色溶液并放出气体(E)。气体(E)与金属(A)共热生成黄色固体物质(G)。

试给出(A)、(B)、(C)、(D)、(E)、(F)和(G)所代表的物质的化学式，并用化学反应方程式表示各过程。

## 解答

(A) — Ni
(B) — $\mathrm{NiCl}_{2}\cdot6\mathrm{H}_{2}\mathrm{O}$
(C) — $\mathrm{Ni(OH)}_{2}$
(D) — $\left[\mathrm{Ni}(\mathrm{NH}_{3})_{6}\right]^{2+}$
(E) — $\mathrm{Cl}_{2}$
(F) — $\mathrm{Ni(OH)}_{3}$
(G) — $\mathrm{NiCl}_{2}$

各过程的化学反应方程式如下：

$$\mathrm{Ni}^{2+} + 2\mathrm{OH}^{-} = \mathrm{Ni(OH)}_{2}\downarrow$$

$$\mathrm{Ni(OH)}_{2} + 12\mathrm{NH}_{3}\cdot\mathrm{H}_{2}\mathrm{O} = 2[\mathrm{Ni}(\mathrm{NH}_{3})_{6}]^{2+} + 2\mathrm{OH}^{-} + 12\mathrm{H}_{2}\mathrm{O}$$

$$2\mathrm{Ni(OH)}_{2} + \mathrm{Cl}_{2} + 2\mathrm{OH}^{-} = 2\mathrm{Ni(OH)}_{3} + 2\mathrm{Cl}^{-}$$

$$2\mathrm{Ni(OH)}_{3} + 6\mathrm{HCl} = 2\mathrm{NiCl}_{2} + \mathrm{Cl}_{2}\uparrow + 6\mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{Ni} + \mathrm{Cl}_{2} = \mathrm{NiCl}_{2}$$
