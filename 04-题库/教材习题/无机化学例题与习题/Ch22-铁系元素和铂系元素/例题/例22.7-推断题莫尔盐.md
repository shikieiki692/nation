# 例22.7 推断题

## 题目

某淡蓝绿色晶体(A)可溶于水，在无氧条件下，将 NaOH 溶液加入(A)溶液中，即有使红色石蕊试纸变蓝的气体(B)放出，同时溶液中有白色沉淀(C)析出。(C)在空气中迅速变为灰绿色、黑色，最后变为红棕色沉淀(D)。(D)溶于稀盐酸中生成棕黄色溶液(E)。在(E)溶液中滴加 KI 溶液，溶液由棕黄色逐渐变为红棕色，说明有(F)和(G)生成。若在滴加 KI 溶液之前先加入过量 KF 溶液，则无此现象。在(D)的浓 KOH 悬浮液中通入氯气，可得到紫红色溶液(H)。在(A)溶液和(H)溶液中分别滴加 $\mathrm{BaCl}_{2}$，均可析出沉淀，但前者是白色沉淀(I)，后者是紫红色沉淀(J)。(I)不溶于 $\mathrm{HNO}_{3}$，但(J)遇 $\mathrm{HNO}_{3}$ 即分解并放出气体(K)。

试给出(A)、(B)、(C)、(D)、(E)、(F)、(G)、(H)、(I)、(J)和(K)所代表的物质的化学式，并用化学反应方程式表示各过程。

## 解答

(A) — $(\mathrm{NH}_{4})_{2}\mathrm{SO}_{4}\cdot\mathrm{FeSO}_{4}\cdot6\mathrm{H}_{2}\mathrm{O}$（莫尔盐）
(B) — $\mathrm{NH}_{3}$
(C) — $\mathrm{Fe(OH)}_{2}$
(D) — $\mathrm{Fe(OH)}_{3}$
(E) — $\mathrm{FeCl}_{3}$
(F) — $\mathrm{I}_{2}$
(G) — $\mathrm{KI}_{3}$
(H) — $\mathrm{FeO}_{4}^{2-}$
(I) — $\mathrm{BaSO}_{4}$
(J) — $\mathrm{BaFeO}_{4}$
(K) — $\mathrm{O}_{2}$

各过程的化学反应方程式如下：

$$\mathrm{NH}_{4}^{+} + \mathrm{OH}^{-} \xlongequal{} \mathrm{NH}_{3}\uparrow + \mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{Fe}^{2+} + 2\mathrm{OH}^{-} \xlongequal{} \mathrm{Fe(OH)}_{2}\downarrow$$

$$4\mathrm{Fe(OH)}_{2} + \mathrm{O}_{2} + 2\mathrm{H}_{2}\mathrm{O} \xlongequal{} 4\mathrm{Fe(OH)}_{3}$$

$$\mathrm{Fe(OH)}_{3} + 3\mathrm{HCl} \xlongequal{} \mathrm{FeCl}_{3} + 3\mathrm{H}_{2}\mathrm{O}$$

$$2\mathrm{Fe}^{3+} + 2\mathrm{I}^{-} \xlongequal{} 2\mathrm{Fe}^{2+} + \mathrm{I}_{2}$$

$$\mathrm{KI} + \mathrm{I}_{2} \xlongequal{} \mathrm{KI}_{3}$$

$$2\mathrm{Fe(OH)}_{3} + 3\mathrm{Cl}_{2} + 10\mathrm{KOH} \xlongequal{} 2\mathrm{K}_{2}\mathrm{FeO}_{4} + 6\mathrm{KCl} + 8\mathrm{H}_{2}\mathrm{O}$$

$$\mathrm{Ba}^{2+} + \mathrm{SO}_{4}^{2-} \xlongequal{} \mathrm{BaSO}_{4}\text{（白色）}\downarrow$$

$$\mathrm{Ba}^{2+} + \mathrm{FeO}_{4}^{2-} \xlongequal{} \mathrm{BaFeO}_{4}\text{（紫红色）}\downarrow$$

$$4\mathrm{BaFeO}_{4} + 20\mathrm{H}^{+} \xlongequal{} 4\mathrm{Fe}^{3+} + 3\mathrm{O}_{2}\uparrow + 10\mathrm{H}_{2}\mathrm{O} + 4\mathrm{Ba}^{2+}$$
