# 第10章 离子-电子法配平方程式

## 10.23 用离子电子法配平下列反应方程式（酸性介质）

### (1) $\mathrm{MnO}_{4}^{-} + \mathrm{Cl}^{-} \longrightarrow \mathrm{Mn}^{2+} + \mathrm{Cl}_{2}$

**答案**：

$$
2\mathrm{MnO}_{4}^{-} + 10\mathrm{Cl}^{-} + 16\mathrm{H}^{+} = 2\mathrm{Mn}^{2+} + 5\mathrm{Cl}_{2} + 8\mathrm{H}_{2}\mathrm{O}
$$

### (2) $\mathrm{Mn}^{2+} + \mathrm{NaBiO}_{3} \longrightarrow \mathrm{MnO}_{4}^{-} + \mathrm{Bi}^{3+}$

**答案**：

$$
2\mathrm{Mn}^{2+} + 5\mathrm{NaBiO}_{3} + 14\mathrm{H}^{+} = 2\mathrm{MnO}_{4}^{-} + 5\mathrm{Bi}^{3+} + 5\mathrm{Na}^{+} + 7\mathrm{H}_{2}\mathrm{O}
$$

### (3) $\mathrm{Cr}^{3+} + \mathrm{PbO}_{2} \longrightarrow \mathrm{Cr}_{2}\mathrm{O}_{7}^{2-} + \mathrm{Pb}^{2+}$

**答案**：

$$
2\mathrm{Cr}^{3+} + 3\mathrm{PbO}_{2} + \mathrm{H}_{2}\mathrm{O} = \mathrm{Cr}_{2}\mathrm{O}_{7}^{2-} + 3\mathrm{Pb}^{2+} + 2\mathrm{H}^{+}
$$

### (4) $\mathrm{C}_{3}\mathrm{H}_{8}\mathrm{O} + \mathrm{MnO}_{4}^{-} \longrightarrow \mathrm{C}_{3}\mathrm{H}_{6}\mathrm{O}_{2} + \mathrm{Mn}^{2+}$

**答案**：

$$
5\mathrm{C}_{3}\mathrm{H}_{8}\mathrm{O} + 4\mathrm{MnO}_{4}^{-} + 12\mathrm{H}^{+} = 5\mathrm{C}_{3}\mathrm{H}_{6}\mathrm{O}_{2} + 4\mathrm{Mn}^{2+} + 11\mathrm{H}_{2}\mathrm{O}
$$

### (5) $\mathrm{HClO}_{3} + \mathrm{P}_{4} \longrightarrow \mathrm{Cl}^{-} + \mathrm{H}_{3}\mathrm{PO}_{4}$

**答案**：

$$
10\mathrm{HClO}_{3} + 3\mathrm{P}_{4} + 18\mathrm{H}_{2}\mathrm{O} = 10\mathrm{Cl}^{-} + 12\mathrm{H}_{3}\mathrm{PO}_{4} + 10\mathrm{H}^{+}
$$

## 10.24 用离子电子法配平下列反应方程式（碱性介质）

### (1) $\mathrm{CrO}_{4}^{2-} + \mathrm{HSnO}_{2}^{-} \longrightarrow \mathrm{CrO}_{2}^{-} + \mathrm{HSnO}_{3}^{-}$

**答案**：

$$
2\mathrm{CrO}_{4}^{2-} + 3\mathrm{HSnO}_{2}^{-} + \mathrm{H}_{2}\mathrm{O} = 2\mathrm{CrO}_{2}^{-} + 3\mathrm{HSnO}_{3}^{-} + 2\mathrm{OH}^{-}
$$

### (2) $\mathrm{H}_{2}\mathrm{O}_{2} + \mathrm{CrO}_{2}^{-} \longrightarrow \mathrm{CrO}_{4}^{2-}$

**答案**：

$$
3\mathrm{H}_{2}\mathrm{O}_{2} + 2\mathrm{CrO}_{2}^{-} + 2\mathrm{OH}^{-} = 2\mathrm{CrO}_{4}^{2-} + 4\mathrm{H}_{2}\mathrm{O}
$$

### (3) $\mathrm{CuS} + \mathrm{CN}^{-} \longrightarrow [\mathrm{Cu(CN)}_{4}]^{3-} + \mathrm{S}^{2-} + \mathrm{NCO}^{-}$

**答案**：

$$
2\mathrm{CuS} + 9\mathrm{CN}^{-} + 2\mathrm{OH}^{-} = 2[\mathrm{Cu(CN)}_{4}]^{3-} + 2\mathrm{S}^{2-} + \mathrm{NCO}^{-} + \mathrm{H}_{2}\mathrm{O}
$$

### (4) $\mathrm{CN}^{-} + \mathrm{O}_{2} \longrightarrow \mathrm{CO}_{3}^{2-} + \mathrm{NH}_{3}$

**答案**：

$$
2\mathrm{CN}^{-} + \mathrm{O}_{2} + 2\mathrm{OH}^{-} + 2\mathrm{H}_{2}\mathrm{O} = 2\mathrm{CO}_{3}^{2-} + 2\mathrm{NH}_{3}
$$

### (5) $\mathrm{Al} + \mathrm{NO}_{2}^{-} \longrightarrow [\mathrm{Al(OH)}_{4}]^{-} + \mathrm{NH}_{3}$

**答案**：

$$
2\mathrm{Al} + \mathrm{NO}_{2}^{-} + \mathrm{OH}^{-} + 5\mathrm{H}_{2}\mathrm{O} = 2[\mathrm{Al(OH)}_{4}]^{-} + \mathrm{NH}_{3}
$$
