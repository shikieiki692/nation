# 21.1-21.12 选择题

## 题目

**21.1** 下列金属中,硬度最高的是

(A) Cr; (B) Mo; (C) W; (D) Mn。

**21.2** 下列金属中,熔点最高的是

(A) Cr; (B) Mo; (C) W; (D) Mn。

**21.3** 下列各对元素的性质最相似的是

(A) Cr 和 Mo; (B) Mo 和 W; (C) Mn 和 Re; (D) Cr 和 Mn。

**21.4** 与其他化合物颜色明显不同的是

(A) $\mathrm{Cu(OH)_2\cdot CuCO_3}$ ; (B) $NaCrO_2$ ; (C) $K_2MnO_4$ ; (D) $K_2CrO_4$ 。

**21.5** 下列微溶化合物中,既溶于 $HNO_{3}$ 溶液又溶于 NaOH 溶液的是

(A) $PbCrO_{4}$ ; (B) $BaCrO_{4}$ ; (C) $Ag_{2}CrO_{4}$ ; (D) $BaSO_{4}$ 。

**21.6** 下列物质中,强氧化性与惰性电子对效应无关的是

(A) $PbO_{2}$ ; (B) $NaBiO_{3}$ ; (C) $K_{2}Cr_{2}O_{7}$ ; (D) $TlCl_{3}$ 。

**21.7** 下列化合物中,不是黄颜色的是

(A) $BaCrO_{4}$ ; (B) $Ag_{2}CrO_{4}$ ; (C) $PbCrO_{4}$ ; (D) $PbI_{2}$ 。

**21.8** 欲分离溶液中 $Cr^{3+}$ 和 $Zn^{2+}$ ，应加入的试剂为

(A) NaOH; (B) $NH_{3}\cdot H_{2}O$ ; (C) $H_{2}S$ ; (D) $Na_{2}CO_{3}$

**21.9** 在酸性介质中, 不能将 $\mathrm{Mn}^{2+}$ 氧化为 $\mathrm{MnO}_{4}^{-}$ 的是

(A) $(\mathrm{NH}_{4})_{2} \mathrm{S}_{2} \mathrm{O}_{8}$ ; (B) $\mathrm{NaBiO}_{3}$ ; (C) $\mathrm{K}_{2} \mathrm{Cr}_{2} \mathrm{O}_{7}$ ; (D) $\mathrm{PbO}_{2}$ 。

**21.10** 下列金属氧化物中,熔点最低的是

(A) $Na_{2}O$ ; (B) HgO; (C) $V_{2}O_{5}$ ; (D) $Mn_{2}O_{7}$ 。

**21.11** 在酸性介质中, 可使 $Cr^{3+}$ 转化为 $Cr_{2}O_{7}^{2-}$ 的试剂是

(A) $H_{2}O_{2}$ ; (B) $MnO_{2}$ ; (C) $KMnO_{4}$ ; (D) $HNO_{3}$ 。

**21.12** 在酸性介质中, 发生歧化反应的离子是

(A) $Mn^{2+}$ ; (B) $Mn^{3+}$ ; (C) $Cr^{3+}$ ; (D) $Ti^{3+}$ 。

## 答案

21.1 A  21.2 C  21.3 B  21.4 D  21.5 A  21.6 C  21.7 B  21.8 B  21.9 C  21.10 D  21.11 C  21.12 B

## 解析

**21.1** Cr是硬度最高的金属之一（莫氏硬度8.5）。

**21.2** W（钨）是熔点最高的金属（3422℃）。

**21.3** Mo和W是同族元素，化学性质最相似。

**21.4** K₂CrO₄为黄色，NaCrO₂为绿色，K₂MnO₄为绿色，Cu(OH)₂·CuCO₃为绿色，只有K₂CrO₄是黄色。

**21.5** PbCrO₄具有两性，既溶于酸又溶于碱；BaCrO₄只溶于酸；Ag₂CrO₄只溶于酸；BaSO₄既不溶于酸也不溶于碱。

**21.6** K₂Cr₂O₇的强氧化性与惰性电子对效应无关，是因为Cr(VI)的高氧化态稳定性。

**21.7** Ag₂CrO₄是砖红色，不是黄色。

**21.8** NH₃·H₂O可与Cr³⁺形成[Cr(OH)₄]⁻溶解，而Zn²⁺形成Zn(OH)₂沉淀（但过量氨水会溶解）。

**21.9** K₂Cr₂O₇的氧化性不足以氧化Mn²⁺为MnO₄⁻。

**21.10** Mn₂O₇是共价化合物，常温下为油状液体，熔点最低（-6℃）。

**21.11** KMnO₄是强氧化剂，可将Cr³⁺氧化为Cr₂O₇²⁻。

**21.12** Mn³⁺在酸性介质中会发生歧化反应：2Mn³⁺ + 2H₂O = Mn²⁺ + MnO₂ + 4H⁺
