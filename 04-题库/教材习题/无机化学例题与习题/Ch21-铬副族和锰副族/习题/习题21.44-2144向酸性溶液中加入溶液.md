# 习题21.44 2144向酸性溶液中加入溶液

21.44 向酸性 $\mathrm{K}_2\mathrm{Cr}_2\mathrm{O}_7$ 溶液中加入 $\mathrm{H}_2\mathrm{O}_2$ 溶液。

> **答案**：$\mathrm{Cr_2O_7^{2 - } + 3H_2O_2 + 8H^+ = 2Cr^{3 + } + 3O_2\uparrow + 7H_2O}$
