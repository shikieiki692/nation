# 习题19.67 1967填写汞的硝酸盐与某些

19.67 填写汞的硝酸盐与某些试剂反应的主要产物，并说明实验现象。

<table><tr><td></td><td> ${\mathrm{{Hg}}}_{2}{\left( {\mathrm{{NO}}}_{3}\right) }_{2}$ </td><td> $\mathrm{{Hg}}{\left( {\mathrm{{NO}}}_{3}\right) }_{2}$ </td></tr><tr><td>KOH</td><td></td><td></td></tr><tr><td> ${\mathrm{{NH}}}_{3} \cdot {\mathrm{H}}_{2}\mathrm{O}$ </td><td></td><td></td></tr><tr><td> ${\mathrm{H}}_{2}\mathrm{\;S}$ </td><td></td><td></td></tr><tr><td> ${\mathrm{{SnCl}}}_{2}$ </td><td></td><td></td></tr><tr><td>KI</td><td></td><td></td></tr></table>

> **答案：**

| 试剂 | $\mathrm{Hg_2(NO_3)_2}$ | $\mathrm{Hg(NO_3)_2}$ |
|---|---|---|
| $\mathrm{KOH}$ | $\mathrm{Hg_2^{2+} + 2OH^- = HgO\downarrow(黄) + Hg\downarrow(黑) + H_2O}$<br>生成黄黑混合沉淀 | $\mathrm{Hg^{2+} + 2OH^- = HgO\downarrow(黄) + H_2O}$<br>生成黄色沉淀 |
| $\mathrm{NH_3\cdot H_2O}$ | 发生歧化，生成黑色 $\mathrm{Hg(NH_2)NO_3}$ 与 $\mathrm{Hg}$ 的混合物 | $\mathrm{Hg^{2+} + NH_3\cdot H_2O = Hg(NH_2)NO_3\downarrow(白) + H_2O}$<br>生成白色沉淀 |
| $\mathrm{H_2S}$ | $\mathrm{Hg_2^{2+} + H_2S = HgS\downarrow(黑) + Hg\downarrow(黑) + 2H^+}$ | $\mathrm{Hg^{2+} + H_2S = HgS\downarrow(黑) + 2H^+}$ |
| $\mathrm{SnCl_2}$ | 先生成白色 $\mathrm{Hg_2Cl_2}$，随后被还原为灰黑色 $\mathrm{Hg}$ | 先生成白色 $\mathrm{Hg_2Cl_2}$，过量 $\mathrm{Sn^{2+}}$ 将其还原为灰黑色 $\mathrm{Hg}$ |
| $\mathrm{KI}$ | 生成黄绿色 $\mathrm{Hg_2I_2}$ 沉淀；过量 KI 歧化为 $\mathrm{[HgI_4]^{2-}}$ 与 $\mathrm{Hg}$ | 生成红色 $\mathrm{HgI_2}$ 沉淀；过量 KI 溶解为无色 $\mathrm{[HgI_4]^{2-}}$ |
