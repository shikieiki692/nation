# 习题19.66 1966用化学反应方程式表示

19.66 用化学反应方程式表示下列与 Zn 有关的转化过程。

![[05bf1a9241628c35fdc0f91312074f2703c87c8d29e16b0d71b24a5ae0ed7633.jpg]]

> **答案：**

各步转化对应的化学反应方程式如下：

- $\mathrm{Zn + \frac{1}{2}O_2 \xrightarrow{\triangle} ZnO}$
- $\mathrm{ZnO + H_2SO_4 = ZnSO_4 + H_2O}$
- $\mathrm{ZnSO_4 + H_2S = ZnS\downarrow + H_2SO_4}$
- $\mathrm{ZnS + 2HCl = ZnCl_2 + H_2S\uparrow}$
- $\mathrm{Zn + 2HCl = ZnCl_2 + H_2\uparrow}$
- $\mathrm{ZnCl_2 + 2NaOH = Zn(OH)_2\downarrow + 2NaCl}$
- $\mathrm{Zn(OH)_2 + 2NaOH = Na_2[Zn(OH)_4]}$
- $\mathrm{Zn(OH)_2 + 4NH_3\cdot H_2O = [Zn(NH_3)_4](OH)_2 + 4H_2O}$
