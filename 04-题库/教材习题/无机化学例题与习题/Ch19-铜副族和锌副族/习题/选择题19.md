# 一、选择题

## 19.1 既易溶于稀氢氧化钠溶液,又易溶于氨水的是

(A) $\mathrm{Cu(OH)_2}$ ; (B) $Ag_2O$ ; (C) $\mathrm{Zn(OH)_2}$ ; (D) $\mathrm{Cd(OH)_2}$ 。

**答案：C**

**解析：** $\mathrm{Zn(OH)_2}$ 是两性氢氧化物，既溶于强碱（生成 $[\mathrm{Zn(OH)_4}]^{2-}$），又溶于氨水（生成 $[\mathrm{Zn(NH_3)_4}]^{2+}$）。$\mathrm{Cu(OH)_2}$ 只溶于氨水，$Ag_2O$ 只溶于氨水，$\mathrm{Cd(OH)_2}$ 溶解性较差。

---

## 19.2 下列化合物中，在 NaOH 溶液中溶解度最小的是

(A) $\mathrm{Sn(OH)_2}$ ; (B) $\mathrm{Pb(OH)_2}$ ; (C) $\mathrm{Cu(OH)_2}$ ; (D) $\mathrm{Zn(OH)_2}$ 。

**答案：C**

**解析：** $\mathrm{Cu(OH)_2}$ 是碱性氢氧化物，不具有两性，难溶于 NaOH 溶液。而 $\mathrm{Sn(OH)_2}$、$\mathrm{Pb(OH)_2}$、$\mathrm{Zn(OH)_2}$ 都具有两性，可溶于 NaOH 溶液。

---

## 19.3 和稀硫酸作用有金属单质生成的是

(A) $Ag_{2}O$ ; (B) $Cu_{2}O$ ; (C) ZnO; (D) HgO。

**答案：B**

**解析：** $\mathrm{Cu_2O}$ 与稀硫酸发生歧化反应：$\mathrm{Cu_2O + H_2SO_4 = CuSO_4 + Cu + H_2O}$，生成金属铜单质。其他氧化物与稀硫酸反应只生成相应的盐和水。

---

## 19.4 为除去铜粉中的少量氧化铜,应采取的操作是

(A) 浓盐酸洗; (B) KCN 溶液洗; (C) 稀硝酸洗; (D) 稀硫酸洗。

**答案：D**

**解析：** 稀硫酸能溶解 $\mathrm{CuO}$ 生成 $\mathrm{CuSO_4}$ 而除去，同时铜不与稀硫酸反应。浓盐酸会溶解铜，KCN 和稀硝酸都会与铜反应。

---

## 19.5 欲除去 $\mathrm{Cu(NO_{3})_{2}}$ 溶液中的少量 $AgNO_{3}$ ，最好加入

(A) 铜粉；(B) NaOH；(C) $Na_{2}S$ ；(D) $NaHCO_{3}$ 。

**答案：A**

**解析：** 加入铜粉可发生反应：$\mathrm{Cu + 2Ag^+ = Cu^{2+} + 2Ag}$，将 $\mathrm{Ag^+}$ 还原为 $\mathrm{Ag}$ 沉淀除去，同时不引入新杂质。其他选项会引入新杂质或使 $\mathrm{Cu^{2+}}$ 沉淀。

---

## 19.6 下列化合物中,其浓溶液可以溶解铁锈的是

(A) $FeCl_{2}$ ; (B) $CoCl_{2}$ ; (C) $ZnCl_{2}$ ; (D) $CuCl_{2}$ 。

**答案：C**

**解析：** $\mathrm{ZnCl_2}$ 浓溶液因水解呈酸性，可以溶解铁锈（主要成分为 $\mathrm{Fe_2O_3}$）。$\mathrm{ZnCl_2}$ 还可用作焊接时的助焊剂。

---

## 19.7 向 $\mathrm{Hg}_{2}(\mathrm{NO}_{3})_{2}$ 溶液中加入 NaOH 溶液，生成的沉淀是

(A) $Hg_{2}O$ ; (B) HgOH; (C) $HgO+Hg$ ; (D) $\mathrm{Hg(OH)}_{2}+\mathrm{Hg}$ .

**答案：C**

**解析：** $\mathrm{Hg_2^{2+}}$ 遇 $\mathrm{OH^-}$ 先生成不稳定的 $\mathrm{Hg_2(OH)_2}$，立即歧化分解为 $\mathrm{HgO}$（黄色）和 $\mathrm{Hg}$（黑色）：$\mathrm{Hg_2^{2+} + 2OH^- = HgO\downarrow + Hg\downarrow + H_2O}$

---

## 19.8 下列化合物中,在硝酸和氨水中都能溶解的是

(A) AgCl; (B) $Ag_{2}CrO_{4}$ ; (C) $HgCl_{2}$ ; (D) CuS。

**答案：B**

**解析：** $Ag_2CrO_4$ 既能溶于硝酸（生成可溶性银盐），又能溶于氨水（形成 $[\mathrm{Ag(NH_3)_2}]^+$ 配离子）。AgCl 只溶于氨水，CuS 难溶于两者。

---

## 19.9 在分析气体时,可用于吸收 CO 的试剂为

(A) $PdCl_{2}$ ; (B) CuCl; (C) AgCl; (D) $Hg_{2}Cl_{2}$ 。

**答案：B**

**解析：** CuCl 的盐酸溶液可吸收 CO，生成 $[\mathrm{Cu(CO)Cl\cdot H_2O}]$。这是分析化学中常用的 CO 吸收剂。

---

## 19.10 下列化合物中,颜色最深的是

(A) CuO; (B) ZnO; (C) HgO; (D) PbO。

**答案：A**

**解析：** CuO 为棕黑色，颜色最深。ZnO 为白色，HgO 为黄色或红色，PbO 为黄色。

---

## 19.11 下列化合物中,在氨水、盐酸、氢氧化钠溶液中均不溶解的是

(A) $ZnCl_{2}$ ; (B) $CuCl_{2}$ ; (C) $Hg_{2}Cl_{2}$ ; (D) AgCl。

**答案：C**

**解析：** $Hg_2Cl_2$（甘汞）在氨水中转化为 $\mathrm{Hg(NH_2)Cl + Hg}$，在盐酸和 NaOH 中均不溶解。$ZnCl_2$、$CuCl_2$ 都易溶于水，AgCl 可溶于氨水。

---

## 19.12 下列试剂中, 可将 $Hg_{2}Cl_{2}$ , CuCl, AgCl 鉴别开的是

(A) $Na_{2}S$ ; (B) $NH_{3}\cdot H_{2}O$ ; (C) $Na_{2}SO_{4}$ ; (D) $KNO_{3}$

**答案：B**

**解析：** 用氨水处理：
- $Hg_2Cl_2$：生成灰黑色沉淀（$\mathrm{Hg(NH_2)Cl + Hg}$）
- CuCl：先溶解成无色溶液，后被氧化变蓝色（$[\mathrm{Cu(NH_3)_4}]^{2+}$）
- AgCl：溶解成无色溶液（$[\mathrm{Ag(NH_3)_2}]^+$）

## 解题思路

### 19.1 既溶于 NaOH 又溶于氨水

**考点**：两性氢氧化物的性质。

- Zn(OH)₂ 是典型的两性氢氧化物：酸性方向溶于 NaOH 生成 $[\mathrm{Zn(OH)_4}]^{2-}$，碱性方向溶于氨水生成 $[\mathrm{Zn(NH_3)_4}]^{2+}$。
- Cu(OH)₂ 只溶于氨水（形成 $[\mathrm{Cu(NH_3)_4}]^{2+}$），不溶于 NaOH。
- Cd(OH)₂ 碱性较弱，溶解性差。
- Ag₂O 只溶于氨水。

### 19.2 NaOH 中溶解度最小

**考点**：氢氧化物的两性。

Cu(OH)₂ 是碱性氢氧化物，不具有两性，不溶于 NaOH。而 Sn(OH)₂、Pb(OH)₂、Zn(OH)₂ 都有两性，可溶于过量 NaOH。

### 19.3 与稀硫酸作用有金属单质生成

**考点**：Cu(I) 的歧化反应。

Cu₂O 中 Cu 为 +1 价（不稳定氧化态），遇酸发生歧化：$\mathrm{Cu_2O + H_2SO_4 = CuSO_4 + Cu + H_2O}$。生成的金属 Cu 是单质产物。其他氧化物与酸反应只生成盐和水。

### 19.4 除去铜粉中的 CuO

**考点**：选择性溶解。

稀硫酸能溶解 CuO（$\mathrm{CuO + H_2SO_4 = CuSO_4 + H_2O}$），而 Cu 不与稀硫酸反应（Cu 在 H 之后）。浓盐酸、KCN 和稀硝酸都会与 Cu 反应，不能使用。

### 19.5 除去 Cu(NO₃)₂ 中的 AgNO₃

**考点**：金属置换反应。

铜的金属活泼性大于银：$\mathrm{Cu + 2Ag^+ = Cu^{2+} + 2Ag}$。加入铜粉可将 Ag⁺ 还原为 Ag 沉淀过滤除去，同时生成 Cu²⁺（正是需要的离子），不引入新杂质。

### 19.6 浓溶液能溶解铁锈

**考点**：盐的水解。

ZnCl₂ 浓溶液因水解呈较强酸性：$\mathrm{Zn^{2+} + 2H_2O \rightleftharpoons Zn(OH)_2 + 2H^+}$。酸性溶液能溶解铁锈（Fe₂O₃）。这也是 ZnCl₂ 用作焊接助焊剂（"熟接水"）的原因。

### 19.7 Hg₂(NO₃)₂ + NaOH

**考点**：Hg₂²⁺ 的不稳定性。

Hg₂²⁺（亚汞离子）遇 OH⁻ 先生成不稳定的 Hg₂(OH)₂，立即歧化分解：$\mathrm{Hg_2^{2+} + 2OH^- = HgO\downarrow(黄) + Hg\downarrow(黑) + H_2O}$。产物是 HgO + Hg，不是 Hg₂O 或 Hg(OH)₂。

### 19.8 在硝酸和氨水中都能溶解

**考点**：溶解性的综合判断。

Ag₂CrO₄ 既能溶于硝酸（Ag⁺ 与 NO₃⁻ 不形成沉淀），又能溶于氨水（形成 $[\mathrm{Ag(NH_3)_2}]^+$ 配离子）。AgCl 只溶于氨水不溶于硝酸；CuS 难溶于两者。

### 19.9 吸收 CO 的试剂

**考点**：配位化合物的应用。

CuCl 的盐酸溶液（氨性氯化亚铜溶液）能吸收 CO：$\mathrm{CuCl + CO + H_2O = [Cu(CO)Cl\cdot H_2O]}$。这是分析化学中经典的 CO 测定方法。

### 19.10 颜色最深的化合物

**考点**：化合物颜色与电子跃迁。

CuO 为棕黑色（颜色最深），因为 Cu²⁺ 的 d-d 跃迁和电荷迁移跃迁吸收范围广。ZnO 为白色（d¹⁰ 无 d-d 跃迁），HgO 为黄色/红色，PbO 为黄色。

### 19.11 在 NH₃、HCl、NaOH 中均不溶

**考点**：Hg₂Cl₂ 的特殊性质。

Hg₂Cl₂（甘汞）在氨水中发生歧化反应生成 Hg(NH₂)Cl + Hg（不溶物），在 HCl 和 NaOH 中均不溶解。而 ZnCl₂、CuCl₂ 易溶于水，AgCl 可溶于氨水。

### 19.12 鉴别 Hg₂Cl₂、CuCl、AgCl

**考点**：氨水对三种白色氯化物的不同作用。

- Hg₂Cl₂ + NH₃ → 灰黑色沉淀（Hg(NH₂)Cl 白 + Hg 黑）
- CuCl + NH₃ → 先溶解为无色 [Cu(NH₃)₂]⁺，遇空气氧化变蓝色 $[\mathrm{Cu(NH_3)_4}]^{2+}$
- AgCl + NH₃ → 溶解为无色 $[\mathrm{Ag(NH_3)_2}]^+$

三种物质与氨水作用现象截然不同，可一次鉴别。
