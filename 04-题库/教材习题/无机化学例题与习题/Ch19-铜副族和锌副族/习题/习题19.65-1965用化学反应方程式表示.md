# 习题19.65 1965用化学反应方程式表示

19.65 用化学反应方程式表示下列与 Cu 有关的转化过程。

![[f5bc8158547e020e3524ceff5cfda8514269bcbd0b5316c6746302a2a4fce75e.jpg]]

> **答案：**

各步转化对应的化学反应方程式如下：

- $\mathrm{Cu + \frac{1}{2}O_2 \xrightarrow{\triangle} CuO}$
- $\mathrm{CuO + H_2SO_4 = CuSO_4 + H_2O}$；$\mathrm{CuSO_4 + 5H_2O = CuSO_4\cdot5H_2O}$
- $\mathrm{CuSO_4\cdot5H_2O + 4NH_3\cdot H_2O = [Cu(NH_3)_4]SO_4 + 4H_2O}$
- $\mathrm{Cu + Cl_2 = CuCl_2}$
- $\mathrm{CuCl_2 + H_2S = CuS\downarrow + 2HCl}$
- $\mathrm{2CuCl_2 + 4KI = 2CuI\downarrow + I_2 + 4KCl}$
- $\mathrm{2CuCl_2 + 10KF + F_2 = 2K_3[CuF_6] + 4KCl}$
- $\mathrm{Cu + S \xrightarrow{\triangle} Cu_2S}$
- $\mathrm{Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O}$
- $\mathrm{Cu(NO_3)_2 + H_2S = CuS\downarrow + 2HNO_3}$
- $\mathrm{Cu_2O + 6HNO_3(浓) = 2Cu(NO_3)_2 + 2NO_2\uparrow + 3H_2O}$
