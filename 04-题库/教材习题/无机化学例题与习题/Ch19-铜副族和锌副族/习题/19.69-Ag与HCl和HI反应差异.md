# 19.69 Ag与HCl和HI反应差异

HCl 和 HI 溶液都是强酸，但 Ag 不能从 HCl 溶液中置换出 $\mathrm{H}_{2}$，却能从 HI 溶液中置换出 $\mathrm{H}_{2}$，试说明原因。

**答案：**

若 Ag 与 HX 反应，生成 AgX 沉淀和 $\mathrm{H_2}$:

$$
\mathrm {Ag} + \mathrm {HX} = \mathrm {AgX} \downarrow + \mathrm {H} _ {2} \uparrow
$$

AgI 的溶度积很小 $(8.52 \times 10^{-17})$，使得 $E^{\ominus}(\mathrm{AgI/Ag}) < E^{\ominus}(\mathrm{H^+/H_2})$，故 Ag 能从 HI 溶液中置换出 $\mathrm{H_2}$。但 AgCl 的溶度积不是很小 $(1.77 \times 10^{-10})$，使 $E^{\ominus}(\mathrm{AgCl/Ag}) > E^{\ominus}(\mathrm{H^+/H_2})$，故 Ag 不能从 HCl 溶液中置换出 $\mathrm{H_2}$。

---

---

## 解题思路

**关键**：比较 $E^\ominus(\mathrm{AgX/Ag})$ 与 $E^\ominus(\mathrm{H^+/H_2}) = 0$ V。

利用能斯特方程：$E^\ominus(\mathrm{AgX/Ag}) = E^\ominus(\mathrm{Ag^+/Ag}) + 0.0592\lg K_{sp}(\mathrm{AgX})$

- AgCl：$E^\ominus = 0.799 + 0.0592\lg(1.77\times10^{-10}) = 0.222$ V > 0 → 不反应
- AgI：$E^\ominus = 0.799 + 0.0592\lg(8.52\times10^{-17}) = -0.152$ V < 0 → 可反应

Ksp 越小，AgX/Ag 电对的电极电势越低，越容易被还原。
