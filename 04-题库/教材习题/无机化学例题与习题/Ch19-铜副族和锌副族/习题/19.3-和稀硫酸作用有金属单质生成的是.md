# 19.3 和稀硫酸作用有金属单质生成的是

## 题目

和稀硫酸作用有金属单质生成的是

(A) $Ag_{2}O$ ; (B) $Cu_{2}O$ ; (C) ZnO; (D) HgO。

## 参考答案

**答案：B**
B**

**解析：** $\mathrm{Cu_2O}$ 与稀硫酸发生歧化反应：$\mathrm{Cu_2O + H_2SO_4 = CuSO_4 + Cu + H_2O}$，生成金属铜单质。其他氧化物与稀硫酸反应只生成相应的盐和水。

---

与稀硫酸作用有金属单质生成

**考点**：Cu(I) 的歧化反应。

Cu₂O 中 Cu 为 +1 价（不稳定氧化态），遇酸发生歧化：$\mathrm{Cu_2O + H_2SO_4 = CuSO_4 + Cu + H_2O}$。生成的金属 Cu 是单质产物。其他氧化物与酸反应只生成盐和水。
