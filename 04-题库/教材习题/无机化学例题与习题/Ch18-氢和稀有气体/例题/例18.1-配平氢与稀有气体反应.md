# 例18.1 配平氢与稀有气体相关反应

## 题目

完成并配平下列化学反应方程式：

## 解答

| 编号 | 反应方程式 |
|:---:|:---|
| (1) | $\mathrm{H_2 + 2Na \xlongequal{\triangle} 2NaH}$ |
| (2) | $\mathrm{WO_3 + 3H_2 \xrightarrow{\triangle} W + 3H_2O}$ |
| (3) | $\mathrm{2LiH + B_2H_6 \xrightarrow{乙醚} 2LiBH_4}$ |
| (4) | $\mathrm{4NaH + TiCl_4 \xrightarrow{\triangle} Ti + 4NaCl + 2H_2\uparrow}$ |
| (5) | $\mathrm{LiAlH_4 + 4H_2O = Al(OH)_3\downarrow + LiOH + 4H_2\uparrow}$ |
| (6) | $\mathrm{KH + H_2O = KOH + H_2\uparrow}$ |
| (7) | $\mathrm{XeF_2(aq) + H_2 = Xe + 2HF}$ |
| (8) | $\mathrm{XeF_2(aq) + 2I^- = Xe\uparrow + I_2 + 2F^-}$ |
| (9) | $\mathrm{XeF_4 + Pt \xrightarrow{液态HF} Xe\uparrow + PtF_4}$ |
| (10) | $\mathrm{XeF_2 + H_2O_2 = Xe\uparrow + 2HF + O_2\uparrow}$ |
