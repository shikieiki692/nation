# 例20.5 钒化合物的推断与反应

## 题目

浅黄色晶体(A)受热分解生成棕黄色粉末(B)和无色气体(C)。(B)不溶于水,与浓盐酸作用放出强刺激性气体(D)。将气体(C)通入 $CuSO_{4}$ 溶液有淡蓝色沉淀(E)生成,(C)过量则沉淀溶解得到深蓝色溶液(F)。(B)溶于稀硫酸后,加入适量草酸,经充分反应得到蓝色溶液(G)。向溶液(G)中放入足量金属 Zn,最终生成紫色溶液(H)。

试给出(A)、(B)、(C)、(D)、(E)、(F)、(G)和(H)所代表的物质的化学式,并用化学反应方程式表示各过程。

## 解答

$(A)-NH_{4}VO_{3}$ ; $(B)-V_{2}O_{5}$ ; $(C)-NH_{3}$ ; $(D)-Cl_{2}$ ; $(E)-Cu(OH)_{2}$ ; $(F)-\left[Cu(NH_{3})_{4}\right]^{2+}$ ; $(G)-VO^{2+}$ ; $(H)-V^{2+}$ 。

各过程的化学反应方程式如下：

$2NH_{4}VO_{3}\xrightarrow{\triangle}V_{2}O_{5}+2NH_{3}\uparrow+H_{2}O$

$V_{2}O_{5}+6HCl(浓)=2VOCl_{2}+Cl_{2}\uparrow+3H_{2}O$

$2NH_{3}+CuSO_{4}+2H_{2}O=Cu(OH)_{2}\downarrow+(NH_{4})_{2}SO_{4}$

$Cu(OH)_{2}+4NH_{3}=\left[Cu(NH_{3})_{4}\right]^{2+}+2OH^{-}$

$V_{2}O_{5}+H_{2}SO_{4}=(VO_{2})_{2}SO_{4}+H_{2}O$

$2VO_{2}^{+} + H_{2}C_{2}O_{4} + 2H^{+} = 2VO^{2+} + 2CO_{2}\uparrow + 2H_{2}O$

$VO^{2+} + Zn + 2H^{+} = V^{2+} + Zn^{2+} + H_{2}O$

## 解析

本题是典型的无机推断题。根据物质的颜色和反应特征进行推断：NH₄VO₃为浅黄色晶体，受热分解生成V₂O₅（棕黄色粉末）和NH₃（无色气体）。V₂O₅与浓盐酸反应放出Cl₂。NH₃通入CuSO₄溶液生成Cu(OH)₂沉淀，过量NH₃使其溶解生成铜氨配离子。V₂O₅溶于硫酸生成VO₂⁺，被草酸还原为VO²⁺（蓝色），再被Zn还原为V²⁺（紫色）。
