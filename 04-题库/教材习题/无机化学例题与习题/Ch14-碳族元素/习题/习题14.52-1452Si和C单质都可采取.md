# 习题14.52 1452Si和C单质都可采取

14.52 Si 和 C 单质都可采取 $sp^{3}$ 杂化形成金刚石型结构, 但 Si 的半径比 C 大得多, 因此 Si—Si 键较弱, 键能低, 使单质硅的熔点、硬度比金刚石低得多。
