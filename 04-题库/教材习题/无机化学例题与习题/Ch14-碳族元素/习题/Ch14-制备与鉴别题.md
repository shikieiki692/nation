# 第14章 碳族元素 — 分离、鉴别与制备

**14.42** 以方铅矿(PbS)为原料，制备氧化铅、二氧化铅和铅单质。

**答案：** 先在空气中灼烧方铅矿粉：

$$2 \mathrm{PbS} + 3 \mathrm{O}_{2} = 2 \mathrm{PbO} + 2 \mathrm{SO}_{2}$$

用过量的 NaOH 处理 PbO：

$$\mathrm{PbO} + 2 \mathrm{NaOH} = \mathrm{Na}_{2}\mathrm{PbO}_{2} + \mathrm{H}_{2}\mathrm{O}$$

用 NaClO 氧化 $\mathrm{Na_{2}PbO_{2}}$ 得到 $\mathrm{PbO_{2}}$：

$$\mathrm{Na}_{2}\mathrm{PbO}_{2} + \mathrm{NaClO} + \mathrm{H}_{2}\mathrm{O} = \mathrm{PbO}_{2} \downarrow + \mathrm{NaCl} + 2 \mathrm{NaOH}$$

高温下用碳还原 PbO，可得金属铅：

$$\mathrm{PbO+C=Pb+CO\uparrow}$$

**14.43** 如何用锡直接氯化的方法制取 $\mathrm{SnCl}_4$？需要采取哪些防止产物水解的措施？

**答案：** 反应方程式：$\mathrm{Sn} + 2 \mathrm{Cl}_{2}(\mathrm{g}) = \mathrm{SnCl}_{4}(\mathrm{l})$

防止水解措施：
- 反应之前，将干燥的 $\mathrm{CO_{2}}$ 气体通过反应气路，赶尽装置中的潮湿空气
- $\mathrm{Cl}_{2}$ 要经过盛有浓硫酸的洗气瓶严格除水
- 生成的气态 $\mathrm{SnCl}_{4}$ 经冷凝后收集在插有干燥管的广口瓶中，防止外界水汽进入

**14.44** 简述 CO 和 $\mathrm{CO}_{2}$ 的实验室制法。

**答案：**

CO 的制法：将甲酸滴加到热浓硫酸中（利用 $\mathrm{H_2SO_4}$ 的脱水作用）：

$$\mathrm{HCOOH} = \mathrm{CO} \uparrow + \mathrm{H}_{2}\mathrm{O}$$

或将草酸晶体与浓硫酸共热，使生成的混合气体通过固体 NaOH 吸收 $\mathrm{CO_2}$：

$$\mathrm{H}_{2}\mathrm{C}_{2}\mathrm{O}_{4} = \mathrm{CO}_{2} \uparrow + \mathrm{CO} \uparrow + \mathrm{H}_{2}\mathrm{O}$$

$\mathrm{CO_{2}}$ 的制法：用碳酸盐（如 $\mathrm{CaCO_3}$）和盐酸作用：

$$\mathrm{CaCO}_{3} + 2 \mathrm{HCl} = \mathrm{CaCl}_{2} + \mathrm{CO}_{2} \uparrow + \mathrm{H}_{2}\mathrm{O}$$

经常使用启普发生器来完成上述反应。

**14.45** 用四种方法鉴别 $\mathrm{SnCl}_4$ 和 $\mathrm{SnCl}_2$ 溶液。

**答案：**

(1) 酸性条件下加入少量 $\mathrm{FeCl_3}$ 溶液，充分反应后加入 KSCN 溶液，变红的为 $\mathrm{SnCl_4}$（$\mathrm{Sn^{2+}}$ 还原 $\mathrm{Fe^{3+}}$ 后无 $\mathrm{Fe^{3+}}$ 剩余，不变红），另一种为 $\mathrm{SnCl_2}$。

(2) 将少量溶液加入 $\mathrm{HgCl_2}$ 溶液中，产生白色沉淀（$\mathrm{Hg_2Cl_2}$）的为 $\mathrm{SnCl_2}$，不产生沉淀的为 $\mathrm{SnCl_4}$。

(3) 与 $\mathrm{Na_2S}$ 溶液作用，产生黄色沉淀（$\mathrm{SnS_2}$）的为 $\mathrm{SnCl_4}$，产生棕色沉淀（$\mathrm{SnS}$）的为 $\mathrm{SnCl_2}$。

(4) 加入过量 NaOH 溶液至沉淀全部溶解，再加入 $\mathrm{BiCl_3}$ 溶液，有黑色沉淀（Bi）生成的为 $\mathrm{SnCl_2}$（亚锡酸还原 $\mathrm{Bi^{3+}}$），另一种为 $\mathrm{SnCl_4}$。

**14.46** 设计实验鉴别下列各组物质。

(1) $\mathrm{Sb_{2}O_{5}}$ 与 SnO；(2) $\mathrm{As_{2}S_{3}}$ 与 $\mathrm{SnS_{2}}$；
(3) $\mathrm{Pb(NO_{3})_{2}}$ 与 $\mathrm{Bi(NO_{3})_{3}}$；(4) $\mathrm{PbCl_{2}}$ 和 $\mathrm{SnCl_{2}}$。

**答案：**

(1) 分别溶于盐酸，滴加淀粉-碘化钾试液，有 $\mathrm{I_2}$ 生成使体系变蓝的是 $\mathrm{Sb_2O_5}$（Sb(V) 氧化 $\mathrm{I^-}$）。

(2) 将等质量的两种物质分别置于 $6\ \mathrm{mol\cdot dm^{-3}}$ 盐酸中，溶解的是 $\mathrm{SnS_2}$，基本不溶解的是 $\mathrm{As_2S_3}$。

(3) 溶于过量 NaOH 溶液的是 $\mathrm{Pb(NO_3)_2}$（两性），不溶于过量 NaOH 溶液的是 $\mathrm{Bi(NO_3)_3}$。

(4) 分别通入 $\mathrm{H_2S}$ 气体，生成棕褐色沉淀的是 $\mathrm{SnCl_2}$（生成 SnS），生成黑色沉淀的是 $\mathrm{PbCl_2}$（生成 PbS）。SnS 可溶于 $\mathrm{Na_2S_2}$，而 PbS 不溶。

**14.47** 提纯除去气体中的少量杂质。

(1) 除去氢气中少量的一氧化碳；
(2) 工业上生产的 $\mathrm{CO_2}$ 气体中常含有 CO、$\mathrm{O_2}$、$\mathrm{N_2}$、水蒸气和微量的 $\mathrm{H_2S}$、$\mathrm{SO_2}$，如何纯化二氧化碳？

**答案：**

(1) 将含有少量 CO 的氢气通入 $\mathrm{CuCl}$ 的盐酸溶液，少量 CO 被定量吸收：

$$\mathrm{CO} + \mathrm{CuCl} + 2 \mathrm{H}_{2}\mathrm{O} = \mathrm{Cu(CO)Cl} \cdot 2 \mathrm{H}_{2}\mathrm{O}$$

(2) 将气体通过冷的浓碳酸钾溶液吸收 $\mathrm{CO_2}$（$\mathrm{CO}$、$\mathrm{O_2}$、$\mathrm{N_2}$ 不被吸收），然后加热放出 $\mathrm{CO_2}$ 干燥后即可应用。微量的 $\mathrm{H_2S}$、$\mathrm{SO_2}$ 被吸收后再加热并不逸出。

**14.48** 分离离子：$\mathrm{Pb}^{2+}$、$\mathrm{Mg}^{2+}$ 和 $\mathrm{Ag}^{+}$。

**答案：** 先加稀盐酸使 $\mathrm{Ag}^{+}$ 沉淀为 $\mathrm{AgCl}$，过滤分离。滤液中加入稀 $\mathrm{H_2SO_4}$ 使 $\mathrm{Pb}^{2+}$ 沉淀为 $\mathrm{PbSO_4}$，过滤分离。滤液中含 $\mathrm{Mg}^{2+}$，加入 NaOH 生成 $\mathrm{Mg(OH)_2}$ 沉淀。

**14.49** 有一白色粉末是 $\mathrm{Na_2SO_3}$、$\mathrm{Na_2CO_3}$、$\mathrm{NaClO_3}$、$\mathrm{Na_2SO_4}$ 中的一种，设计实验加以鉴别。

**答案：**

加稀盐酸，有刺激性气体（使品红褪色）生成的为 $\mathrm{Na_2SO_3}$。

加稀盐酸，有气体（使澄清石灰水浑浊，不使品红褪色）生成的为 $\mathrm{Na_2CO_3}$。

加稀盐酸无明显变化的为 $\mathrm{NaClO_3}$ 和 $\mathrm{Na_2SO_4}$。再加浓盐酸，溶液变黄（产生 $\mathrm{Cl_2}$）的为 $\mathrm{NaClO_3}$，无现象的为 $\mathrm{Na_2SO_4}$。

**14.50** 如何配制 $\mathrm{SnCl}_2$ 溶液？

**答案：** 将 $\mathrm{SnCl_2}$ 加入一定量水中充分搅拌后，再边搅拌边滴加稀盐酸至沉淀消失后并稍过量。再加少许锡粒。

加入过量的盐酸是为抑制 $\mathrm{SnCl_2}$ 的水解：

$$\mathrm{Sn(OH)Cl+HCl} \rightleftharpoons \mathrm{SnCl_{2} + H_{2}O}$$

加少量 Sn 粒以防止 $\mathrm{SnCl_2}$ 被氧化：

$$\mathrm{Sn}^{4+} + \mathrm{Sn} = 2\mathrm{Sn}^{2+}$$
