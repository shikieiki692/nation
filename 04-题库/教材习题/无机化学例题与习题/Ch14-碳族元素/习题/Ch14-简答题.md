# 第14章 碳族元素 — 简答题

**14.51** CO 和 $\mathrm{N}_{2}$ 是等电子体，为什么 CO 的配位能力远强于 $\mathrm{N}_{2}$？

**答案：** CO 和 $\mathrm{N}_{2}$ 虽是等电子体，但 CO 的 HOMO 能级较 $\mathrm{N}_{2}$ 高，易于给出电子形成 $\sigma$ 配键；同时 CO 的 LUMO 能级较 $\mathrm{N}_{2}$ 低，接受中心原子反馈电子的能力较强，形成 $\mathrm{d}\rightarrow\pi^{*}$ 反馈 $\pi$ 键，使金属-碳键加强。而 $\mathrm{N}_{2}$ 的 HOMO 能级低、LUMO 能级高，配位能力较弱。

**14.52** 试解释下列现象：

(1) 烧水的锅炉中长期使用后会形成锅垢；

(2) 蛤蜊、牡蛎等贝壳的主要成分为 $\mathrm{CaCO}_{3}$，但它们能在 $\mathrm{CO}_{2}$ 含量较高的海水中生长。

**答案：**

(1) 天然水中含有 $\mathrm{Ca(HCO_3)_2}$，加热时分解：

$$\mathrm{Ca(HCO_3)_2\xrightarrow{\triangle}CaCO_3\downarrow + CO_2\uparrow + H_2O}$$

生成的 $\mathrm{CaCO_3}$ 附着在锅炉内壁形成锅垢。若水中含有 $\mathrm{Mg(HCO_3)_2}$，加热后先生成 $\mathrm{MgCO_3}$，进一步水解生成更难溶的 $\mathrm{Mg(OH)_2}$ 沉淀：

$$\mathrm{MgCO_3 + H_2O\xrightarrow{\triangle}Mg(OH)_2\downarrow + CO_2\uparrow}$$

(2) 海水中 $\mathrm{CO_2}$ 含量较高时，$\mathrm{CaCO_3}$ 与 $\mathrm{CO_2}$、$\mathrm{H_2O}$ 反应生成可溶性的 $\mathrm{Ca(HCO_3)_2}$：

$$\mathrm{CaCO_3 + CO_2 + H_2O = Ca(HCO_3)_2}$$

这样 $\mathrm{Ca^{2+}}$ 以 $\mathrm{Ca(HCO_3)_2}$ 形式存在于海水中，贝类生物可以从海水中摄取 $\mathrm{Ca^{2+}}$ 和 $\mathrm{CO_3^{2-}}$（或 $\mathrm{HCO_3^-}$）来构建贝壳。

**14.53** 硅酸盐的基本结构单元是什么？画出单个硅氧四面体的结构示意图。硅氧四面体通过共用顶点可以组成哪些类型的硅酸盐阴离子？举例说明。

**答案：**

硅酸盐的基本结构单元是硅氧四面体 $\mathrm{[SiO_4]^{4-}}$，其中 Si 原子位于四面体中心，4 个 O 原子位于四面体的四个顶点。

硅氧四面体通过共用顶点（即共用 O 原子）可以组成以下类型的硅酸盐阴离子：

1. **单个四面体**（岛状）：硅氧比 1:4，如 $\mathrm{[SiO_4]^{4-}}$（橄榄石 $\mathrm{Mg_2SiO_4}$）。

2. **双四面体**：两个四面体共用一个顶点，硅氧比 2:7，如 $\mathrm{[Si_2O_7]^{6-}}$（钪硅石 $\mathrm{Sc_2Si_2O_7}$）。

3. **环状**：多个四面体形成闭合环，硅氧比 1:3，如三元环 $\mathrm{[Si_3O_9]^{6-}}$、六元环 $\mathrm{[Si_6O_{18}]^{12-}}$（绿柱石 $\mathrm{Be_3Al_2Si_6O_{18}}$）。

4. **链状（单链）**：每个四面体共用 2 个顶点形成无限长链，硅氧比 1:3，如 $\mathrm{[SiO_3]_n^{2n-}}$（辉石类，如 $\mathrm{MgSiO_3}$）。

5. **双链**：由两条单链通过共用顶点交联，硅氧比 4:11，如 $\mathrm{[Si_4O_{11}]_n^{6n-}}$（角闪石类）。

6. **层状**：每个四面体共用 3 个顶点形成无限二维层，硅氧比 2:5，如 $\mathrm{[Si_2O_5]_n^{2n-}}$（云母、滑石）。

7. **三维骨架**：每个四面体共用全部 4 个顶点，硅氧比 1:2，如 $\mathrm{SiO_2}$（石英）、长石类。

**14.54** 解释下列事实：

(1) 碳与硅同属第 IVA 族，但 $\mathrm{CO_2}$ 是气体而 $\mathrm{SiO_2}$ 是原子晶体；

(2) $\mathrm{CO}$ 有毒而 $\mathrm{CO_2}$ 无毒。

**答案：**

(1) C 原子半径小，$\mathrm{CO_2}$ 分子中 C=O 键短而强，形成独立的直线形小分子，分子间仅存在较弱的范德华力，因此 $\mathrm{CO_2}$ 在常温常压下为气体。Si 原子半径较大，Si=O 双键不稳定（Si 的 3p 轨道与 O 的 2p 轨道匹配差），倾向于形成单键。每个 Si 原子与 4 个 O 原子以单键相连，每个 O 原子桥连 2 个 Si 原子，形成三维骨架的原子晶体 $\mathrm{SiO_2}$，熔点很高。

(2) CO 中 C 原子有一对孤对电子，能与血红蛋白中 $\mathrm{Fe^{2+}}$ 形成很强的配位键（形成稳定的碳氧血红蛋白 $\mathrm{HbCO}$），使血红蛋白失去输氧能力，因此 CO 有剧毒。$\mathrm{CO_2}$ 分子呈直线形，C 原子无孤对电子，不能与血红蛋白中的 $\mathrm{Fe^{2+}}$ 有效配位，故无毒性。但高浓度 $\mathrm{CO_2}$ 会因窒息作用导致危险。

**14.55** 已知下列热力学数据，通过计算判断常温下锡在空气中氧化的可能性（提示：考虑锡表面 $\mathrm{SnO}$ 膜的保护作用）。

**答案：** 锡在空气中氧化的反应为：

$$\mathrm{Sn(s) + O_2(g) = SnO_2(s)}$$

$\Delta_rG^\theta = -519.7\ \mathrm{kJ\cdot mol^{-1}}$，远小于零，从热力学角度看反应可以自发进行。

但实际常温下锡表面会迅速形成一层致密的 $\mathrm{SnO_2}$ 薄膜，阻止内部金属继续与氧气接触，因此锡在常温下具有一定的抗腐蚀性（钝化现象）。加热后氧化膜保护作用减弱，锡在空气中加热会被氧化为 $\mathrm{SnO_2}$。

**14.56** 比较 $\mathrm{Na_2CO_3}$ 和 $\mathrm{NaHCO_3}$ 的热稳定性、水溶液的酸碱性，并加以解释。

**答案：**

(1) **热稳定性**：$\mathrm{Na_2CO_3 > NaHCO_3}$。$\mathrm{Na_2CO_3}$ 加热至 $851^{\circ}\mathrm{C}$ 才熔化而不分解；$\mathrm{NaHCO_3}$ 在约 $100^{\circ}\mathrm{C}$ 即分解：

$$2\mathrm{NaHCO_3\xrightarrow{\triangle}Na_2CO_3 + CO_2\uparrow + H_2O}$$

这是因为 $\mathrm{HCO_3^-}$ 中 H 与 $\mathrm{CO_3^{2-}}$ 的结合远不如 $\mathrm{Na^+}$ 与 $\mathrm{CO_3^{2-}}$ 的结合牢固。

(2) **水溶液酸碱性**：$\mathrm{Na_2CO_3}$ 溶液 pH $\approx$ 11.6（碱性较强），$\mathrm{NaHCO_3}$ 溶液 pH $\approx$ 8.3（碱性较弱）。

$\mathrm{CO_3^{2-}}$ 的水解：$\mathrm{CO_3^{2-} + H_2O \rightleftharpoons HCO_3^- + OH^-}$（$K_{h1} = K_w/K_{a2} \approx 2.1\times10^{-4}$），水解程度较大。

$\mathrm{HCO_3^-}$ 既水解（$\mathrm{HCO_3^- + H_2O \rightleftharpoons H_2CO_3 + OH^-}$，$K_{h2} = K_w/K_{a1} \approx 2.3\times10^{-8}$）又电离（$\mathrm{HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}}$，$K_{a2} \approx 4.7\times10^{-11}$），水解大于电离，溶液呈弱碱性，但碱性弱于 $\mathrm{Na_2CO_3}$。

**14.57** 为什么 $\mathrm{PbCl_2}$ 能溶于冷水，而 $\mathrm{PbI_2}$ 却难溶于冷水？试从热力学角度加以解释。

**答案：** $\mathrm{PbCl_2}$ 和 $\mathrm{PbI_2}$ 都是难溶电解质，溶解度的差异可通过溶度积和溶解热力学来理解。

$\mathrm{PbCl_2}$ 的 $K_{sp} \approx 1.7\times10^{-5}$，$\mathrm{PbI_2}$ 的 $K_{sp} \approx 1.4\times10^{-8}$。$\mathrm{PbI_2}$ 的 $K_{sp}$ 远小于 $\mathrm{PbCl_2}$。

从离子极化角度解释：$\mathrm{I^-}$ 半径大（206 pm），可极化性强，$\mathrm{Pb^{2+}}$ 半径大且有 18+2 电子构型，极化力强。$\mathrm{Pb^{2+}}$ 与 $\mathrm{I^-}$ 之间的相互极化作用显著，使 $\mathrm{PbI_2}$ 的离子键中增加了共价成分，晶格能增大，溶解度降低。而 $\mathrm{Cl^-}$ 半径小（181 pm），极化性较弱，$\mathrm{PbCl_2}$ 的共价成分较少，溶解度相对较大。

因此 $\mathrm{PbCl_2}$ 可溶于冷水（溶解度约 9.9 g/100 g 水，20°C），而 $\mathrm{PbI_2}$ 难溶于冷水（溶解度约 0.063 g/100 g 水，20°C），但 $\mathrm{PbI_2}$ 可溶于热水（溶解度显著增大）。

**14.58** 试解释 $\mathrm{SnCl_4}$ 比 $\mathrm{SnCl_2}$ 更易水解的原因。

**答案：** $\mathrm{SnCl_4}$ 中 Sn 为 +4 价，离子电荷高、半径较小，极化力强。$\mathrm{Sn^{4+}}$ 有空的 5d 轨道，可与水分子中 O 的孤对电子配位，形成 $\mathrm{sp^3d}$ 杂化过渡态，有利于水解进行。且 $\mathrm{SnCl_4}$ 为共价化合物（分子晶体），水解后生成稳定的 $\mathrm{H_4SiO_4}$ 型含氧酸，反应热力学有利：

$$\mathrm{SnCl_4 + 4H_2O = H_4SnO_4\downarrow + 4HCl}$$

而 $\mathrm{SnCl_2}$ 中 Sn 为 +2 价，极化力较弱，水解倾向较小：

$$\mathrm{SnCl_2 + H_2O \rightleftharpoons Sn(OH)Cl + HCl}$$

Sn(II) 的水解产物为碱式盐，可逆性较强，且 Sn(II) 保留有一对孤对电子（$5s^2$），该孤对电子对水解无促进作用。因此 $\mathrm{SnCl_4}$ 的水解程度远大于 $\mathrm{SnCl_2}$。

**14.59** 从原子结构的角度解释为什么碳能形成很长的碳链和各种环状结构（有机化合物），而硅却不能。

**答案：**

(1) C 原子半径小（77 pm），C-C 键长短（154 pm），键能大（346 kJ/mol），碳链稳定性高，可以形成很长的碳链而不易断裂。Si 原子半径大（117 pm），Si-Si 键长长（235 pm），键能较小（226 kJ/mol），长硅链不稳定，倾向于断裂。

(2) C 原子能形成稳定的 p-p $\pi$ 键（2p-2p 重叠好），因此碳可以形成 C=C、C=O 等双键，构成各种不饱和环状结构。Si 的 3p 轨道较大，3p-3p 重叠差，Si=Si 双键极不稳定（只能在特殊条件下短暂存在），因此硅不能形成类似碳的环状不饱和结构。

(3) C-C 键与 C-O、C-N 等杂原子键的键能相近，使得有机分子中的碳骨架可以稳定存在并连接各种官能团，形成极其丰富的有机化学世界。而 Si-O 键能（452 kJ/mol）远大于 Si-Si 键能（226 kJ/mol），硅化合物倾向于形成 Si-O 骨架（硅酸盐矿物），而非 Si-Si 链。

**14.60** 解释为什么 $\mathrm{CCl_4}$ 不水解，而 $\mathrm{SiCl_4}$ 和 $\mathrm{PCl_5}$ 水解完全。

**答案：**

(1) **$\mathrm{CCl_4}$ 不水解**：C 原子处于第二周期，外层只有 2s 和 2p 轨道，没有可利用的空 d 轨道。水解的第一步需要水分子中 O 的孤对电子进攻中心原子，但由于 C 的 2s、2p 轨道已被填满，无法接受 O 的电子对形成配位中间体。此外 C-Cl 键较强（328 kJ/mol），不易断裂。因此 $\mathrm{CCl_4}$ 不水解。

(2) **$\mathrm{SiCl_4}$ 水解完全**：Si 原子处于第三周期，有空的 3d 轨道。水分子中 O 的孤对电子可以进入 Si 的空 3d 轨道，形成 $\mathrm{sp^3d}$ 杂化的五配位中间体，然后 C-Cl 键断裂，O-Si 键形成，最终水解完全：

$$\mathrm{SiCl_4 + 4H_2O = H_4SiO_4\downarrow + 4HCl}$$

(3) **$\mathrm{PCl_5}$ 水解完全**：P 原子同样有空的 3d 轨道，且 P 原子半径较小，$\mathrm{PCl_5}$ 中 P-Cl 键长较短，键能较低，易被水分子进攻。$\mathrm{PCl_5}$ 水解分步进行，最终产物为磷酸和盐酸：

$$\mathrm{PCl_5 + 4H_2O = H_3PO_4 + 5HCl}$$

**14.61** 试从热力学角度分析：为什么在水溶液中 $\mathrm{Sn^{2+}}$ 既能作为氧化剂又能作为还原剂？

**答案：**

$\mathrm{Sn^{2+}}$ 在水溶液中既可以被氧化为 $\mathrm{Sn^{4+}}$，也可以被还原为 Sn，相关电极电势为：

$$\mathrm{Sn^{4+} + 2e^- = Sn^{2+}}\quad E^\theta = +0.151\ \mathrm{V}$$

$$\mathrm{Sn^{2+} + 2e^- = Sn}\quad E^\theta = -0.137\ \mathrm{V}$$

(1) **作为还原剂**：当 $\mathrm{Sn^{2+}}$ 与氧化剂（如 $\mathrm{Fe^{3+}}$、$\mathrm{HgCl_2}$ 等）反应时，$\mathrm{Sn^{2+}}$ 被氧化为 $\mathrm{Sn^{4+}}$：

$$\mathrm{Sn^{2+} \to Sn^{4+} + 2e^-}$$

因为 $E^\theta(\mathrm{Sn^{4+}/Sn^{2+}}) = 0.151\ \mathrm{V}$ 较低，$\mathrm{Sn^{2+}}$ 是中等强度的还原剂。

(2) **作为氧化剂**：当 $\mathrm{Sn^{2+}}$ 与强还原剂（如 Mg、Zn 等）反应时，$\mathrm{Sn^{2+}}$ 被还原为 Sn：

$$\mathrm{Sn^{2+} + 2e^- \to Sn}$$

$E^\theta(\mathrm{Sn^{2+}/Sn}) = -0.137\ \mathrm{V}$，表明 $\mathrm{Sn^{2+}}$ 有一定的氧化性。

由于 $\mathrm{Sn^{4+}/Sn^{2+}}$ 和 $\mathrm{Sn^{2+}/Sn}$ 的电势都接近于零，$\mathrm{Sn^{2+}}$ 处于中间氧化态，既能升高又能降低，因此 $\mathrm{Sn^{2+}}$ 既可以作氧化剂也可以作还原剂，这体现了 Sn(II) 的两重性。

**14.62** 为什么 $\mathrm{PbO_2}$ 能在酸性溶液中将 $\mathrm{Mn^{2+}}$ 氧化为 $\mathrm{MnO_4^-}$，而 $\mathrm{MnO_2}$ 却不能？

**答案：**

相关电极电势为：

$$\mathrm{PbO_2 + 4H^+ + 2e^- = Pb^{2+} + 2H_2O}\quad E^\theta = +1.455\ \mathrm{V}$$

$$\mathrm{MnO_4^- + 8H^+ + 5e^- = Mn^{2+} + 4H_2O}\quad E^\theta = +1.507\ \mathrm{V}$$

$$\mathrm{MnO_2 + 4H^+ + 2e^- = Mn^{2+} + 2H_2O}\quad E^\theta = +1.224\ \mathrm{V}$$

在酸性溶液中：

- $\mathrm{PbO_2}$ 作为氧化剂，可将 $\mathrm{Mn^{2+}}$ 氧化为 $\mathrm{MnO_4^-}$：

$$E_{cell} = E(\mathrm{PbO_2/Pb^{2+}}) - E(\mathrm{MnO_4^-/Mn^{2+}}) = 1.455 - 1.507 = -0.052\ \mathrm{V}$$

虽然标准电极电势之差略为负值，但由于 $\mathrm{PbO_2}$ 在反应中大量消耗 $\mathrm{H^+}$，使 $\mathrm{MnO_4^-/Mn^{2+}}$ 电对的电势降低（能斯特方程），实际反应可以进行。此外，$\mathrm{MnO_4^-}$ 生成后其浓度极低，也有利于反应正向进行。

- $\mathrm{MnO_2}$ 作为氧化剂：

$$E_{cell} = E(\mathrm{MnO_2/Mn^{2+}}) - E(\mathrm{MnO_4^-/Mn^{2+}}) = 1.224 - 1.507 = -0.283\ \mathrm{V}$$

差值太大，即使考虑浓度变化也无法逆转，所以 $\mathrm{MnO_2}$ 不能将 $\mathrm{Mn^{2+}}$ 氧化为 $\mathrm{MnO_4^-}$。

本质上是 $\mathrm{PbO_2}$ 的氧化性（+1.455 V）远强于 $\mathrm{MnO_2}$（+1.224 V），Pb(IV) 由于惰性电子对效应而具有异常强的氧化性。

**14.63** 用化学方法区分下列各组物质：(1) 锡粉与铅粉；(2) $\mathrm{SnCl_2}$ 和 $\mathrm{SnCl_4}$；(3) $\mathrm{Pb(NO_3)_2}$ 和 $\mathrm{Bi(NO_3)_3}$。

**答案：**

**(1) 锡粉与铅粉：** 分别加入稀盐酸，有气泡（$\mathrm{H_2}$）产生的是锡粉（Sn 可与稀盐酸反应）：

$$\mathrm{Sn + 2HCl = SnCl_2 + H_2\uparrow}$$

无明显现象的是铅粉（Pb 与稀盐酸反应极慢，表面生成难溶的 $\mathrm{PbCl_2}$ 阻止反应继续）。

**(2) $\mathrm{SnCl_2}$ 和 $\mathrm{SnCl_4}$：** 取少量试液，加入 $\mathrm{HgCl_2}$ 溶液。产生白色沉淀（$\mathrm{Hg_2Cl_2}$）的是 $\mathrm{SnCl_2}$：

$$2\mathrm{HgCl_2 + SnCl_2 = Hg_2Cl_2\downarrow + SnCl_4}$$

不产生沉淀的是 $\mathrm{SnCl_4}$。也可以加入 $\mathrm{FeCl_3}$ 和 KSCN：能使 $\mathrm{Fe^{3+}}$ 还原（加 KSCN 不变红）的是 $\mathrm{SnCl_2}$。

**(3) $\mathrm{Pb(NO_3)_2}$ 和 $\mathrm{Bi(NO_3)_3}$：** 加入过量 NaOH 溶液，沉淀溶解的是 $\mathrm{Pb(NO_3)_2}$（两性，生成 $\mathrm{[Pb(OH)_4]^{2-}}$）：

$$\mathrm{Pb(OH)_2 + 2OH^- = [Pb(OH)_4]^{2-}}$$

沉淀不溶解的是 $\mathrm{Bi(NO_3)_3}$（$\mathrm{Bi(OH)_3}$ 不溶于过量碱）。

**14.64** 从 $\mathrm{SiO_2}$ 出发，合成以下化合物：(1) 硅酸钠；(2) 原硅酸；(3) 变色硅胶；(4) SiC。

**答案：**

**(1) 硅酸钠**：将 $\mathrm{SiO_2}$ 与纯碱（$\mathrm{Na_2CO_3}$）共熔：

$$\mathrm{SiO_2 + Na_2CO_3\xrightarrow{\text{共熔}}Na_2SiO_3 + CO_2\uparrow}$$

溶于水得硅酸钠溶液（水玻璃）。

**(2) 原硅酸**：向硅酸钠溶液中加入适量盐酸：

$$\mathrm{Na_2SiO_3 + 2HCl = H_4SiO_4\downarrow + 2NaCl}$$

也可写为：$\mathrm{Na_2SiO_3 + 2HCl = H_2SiO_3\downarrow + 2NaCl}$（硅酸）。

**(3) 变色硅胶**：先制得硅酸钠溶液（水玻璃），加入盐酸使 pH 至 7~8，析出硅酸凝胶。洗涤后用 $\mathrm{CoCl_2}$ 溶液浸泡，100°C 以下干燥，300°C 活化，即得多孔性变色硅胶。含水时呈粉红色（$\mathrm{CoCl_2\cdot 6H_2O}$），干燥后变蓝色（$\mathrm{CoCl_2}$）。

**(4) SiC（金刚砂）**：将 $\mathrm{SiO_2}$ 与过量焦炭在电炉中高温反应：

$$\mathrm{SiO_2 + 3C\xrightarrow{2000^{\circ}\mathrm{C}}SiC + 2CO\uparrow}$$

**14.65** 试解释下列事实：

(1) 为什么 $\mathrm{PbCl_4}$ 在常温下即分解，而 $\mathrm{SnCl_4}$ 可以稳定存在？

(2) 为什么 $\mathrm{SnS}$ 可溶于 $\mathrm{(NH_4)_2S_2}$（多硫化铵）溶液，而 PbS 不溶？

(3) 为什么 $\mathrm{PbI_2}$ 在水中的溶解度随温度升高而增大，但在 KI 溶液中的溶解度先减小后增大？

**答案：**

**(1)** Pb 和 Sn 同属第 IVA 族，但 Pb 位于第六周期，由于"惰性电子对效应"（或称"惰性电子对效应"），6s 电子受 4f、5d 电子的屏蔽不完全，使得 Pb(IV) 具有极强的氧化性，$\mathrm{PbCl_4}$ 不稳定，在常温下即分解：

$$\mathrm{PbCl_4 = PbCl_2 + Cl_2\uparrow}$$

Sn 位于第五周期，惰性电子对效应较弱，Sn(IV) 的氧化性远弱于 Pb(IV)，$\mathrm{SnCl_4}$ 可以稳定存在。

**(2)** $\mathrm{SnS}$ 中的 Sn(II) 可被多硫化物中的 $\mathrm{S_2^{2-}}$ 氧化为 Sn(IV)，生成可溶性的硫代锡酸盐：

$$\mathrm{SnS + (NH_4)_2S_2 = (NH_4)_2SnS_3}$$

或：$\mathrm{SnS + S^{2-} = SnS_2^{2-}}$（硫代锡酸根），$\mathrm{SnS_2}$ 可溶于 $\mathrm{(NH_4)_2S}$。

而 PbS 中的 Pb(II) 不被 $\mathrm{S_2^{2-}}$ 氧化（Pb 的 +4 价极不稳定，不易被氧化到 +4），且 $\mathrm{PbS}$ 的 $K_{sp}$ 极小（约 $10^{-28}$），故 PbS 不溶于多硫化铵溶液。

**(3)** $\mathrm{PbI_2}$ 在水中的溶解过程为吸热过程（$\Delta H > 0$），根据勒夏特列原理，升温有利于溶解，溶解度增大。

在 KI 溶液中，存在同离子效应。初始阶段随着 $\mathrm{I^-}$ 浓度增大，$\mathrm{PbI_2}$ 的溶解平衡：

$$\mathrm{PbI_2(s) \rightleftharpoons Pb^{2+}(aq) + 2I^-(aq)}$$

平衡左移，溶解度减小（同离子效应主导）。当 KI 浓度继续增大时，$\mathrm{I^-}$ 与 $\mathrm{Pb^{2+}}$ 形成配离子 $\mathrm{[PbI_3]^-}$、$\mathrm{[PbI_4]^{2-}}$：

$$\mathrm{PbI_2 + I^- = [PbI_3]^-}$$

配位作用使溶解平衡右移，溶解度又增大。因此溶解度先减小后增大。
