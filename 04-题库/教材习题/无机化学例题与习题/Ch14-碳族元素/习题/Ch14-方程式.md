# 第14章 碳族元素 — 完成并配平化学反应方程式

**14.19** 将甲酸滴加到热浓硫酸中。

**答案：** $\mathrm{HCOOH} \xlongequal{\text{浓} \mathrm{H}_{2}\mathrm{SO}_{4}} \mathrm{CO}\uparrow + \mathrm{H}_{2}\mathrm{O}$

---

**14.20** 向+3价铁离子的溶液中加入碳酸钠溶液。

**答案：** $2\mathrm{Fe}^{3+} + 3\mathrm{CO}_3^{2-} + 3\mathrm{H}_2\mathrm{O} = 2\mathrm{Fe(OH)}_3\downarrow + 3\mathrm{CO}_2\uparrow$

---

**14.21** 向浓氨水中通入过量 $\mathrm{CO}_{2}$。

**答案：** $\mathrm{NH_3\cdot H_2O + CO_2 = NH_4HCO_3}$

---

**14.22** 向 $\mathrm{Na}_{2}\mathrm{SiO}_{3}$ 溶液中加入饱和 $\mathrm{NH}_{4}\mathrm{Cl}$ 溶液。

**答案：** $\mathrm{SiO}_3^{2-} + 2\mathrm{NH}_4^+ = \mathrm{H}_2\mathrm{SiO}_3\downarrow + 2\mathrm{NH}_3$

---

**14.23** 石英与熔融状态的纯碱作用。

**答案：** $\mathrm{SiO_2 + Na_2CO_3\xrightarrow{\text{共熔}}Na_2SiO_3 + CO_2\uparrow}$

---

**14.24** 二氧化硅溶于过量的氢氟酸中。

**答案：** $\mathrm{SiO_2 + 6HF = H_2[SiF_6] + 2H_2O}$

---

**14.25** 甲硅烷受热分解。

**答案：** $\mathrm{SiH_4\xrightarrow{500°C}Si + 2H_2\uparrow}$

---

**14.26** 在乙醚中用氢化铝锂还原四氯化硅。

**答案：** $\mathrm{SiCl_4 + LiAlH_4\xrightarrow{\text{乙醚}} SiH_4\uparrow + LiCl + AlCl_3}$

---

**14.27** 四氟化硅水解。

**答案：** $\mathrm{SiF_4 + 4H_2O = H_4SiO_4\downarrow + 4HF}$

$$\mathrm{SiF}_{4} + 2 \mathrm{HF} = 2 \mathrm{H}^{+} + [\mathrm{SiF}_{6}]^{2-}$$

---

**14.28** 甲硅烷在空气中自燃。

**答案：** $\mathrm{SiH_4 + 2O_2\xrightarrow{\text{自燃}} SiO_2 + 2H_2O}$

---

**14.29** 用锌粉还原 $\mathrm{SiCl}_4$。

**答案：** $\mathrm{SiCl_4 + 2Zn = Si + 2ZnCl_2}$

---

**14.30** 金属锗溶于浓硝酸中。

**答案：** $\mathrm{Ge} + 4\mathrm{HNO}_3(\text{浓}) = \mathrm{GeO_2\cdot H_2O\downarrow + 4NO_2\uparrow + H_2O}$

---

**14.31** 金属锡与浓硝酸反应。

**答案：** $\mathrm{Sn} + 4\mathrm{HNO}_3(\text{浓}) = \mathrm{H}_2\mathrm{SnO}_3(\beta)\downarrow + 4\mathrm{NO}_2\uparrow + \mathrm{H}_2\mathrm{O}$

---

**14.32** 金属锡与热的浓盐酸反应。

**答案：** $\mathrm{Sn} + 2\mathrm{HCl}(\text{浓}) \xrightarrow{\triangle}\mathrm{SnCl}_2 + \mathrm{H}_2\uparrow$

---

**14.33** 二硫化锡与氢氧化钠溶液作用。

**答案：** $3\mathrm{SnS}_2 + 6\mathrm{NaOH(aq)} = \mathrm{Na}_2\mathrm{SnO}_3 + 2\mathrm{Na}_2\mathrm{SnS}_3 + 3\mathrm{H}_2\mathrm{O}$

---

**14.34** 碱性条件下，用亚锡酸还原硝酸铋。

**答案：** $3[\mathrm{Sn(OH)}_3]^- + 2\mathrm{Bi}^{3+} + 9\mathrm{OH}^- = 3[\mathrm{Sn(OH)}_6]^{2-} + 2\mathrm{Bi}\downarrow$

---

**14.35** 锡与氢氧化钠溶液反应。

**答案：** $\mathrm{Sn} + 2\mathrm{OH}^{-} + 2\mathrm{H}_{2}\mathrm{O} = [\mathrm{Sn(OH)}_{4}]^{2-} + \mathrm{H}_{2}\uparrow$

---

**14.36** 硅溶解在硝酸和氢氟酸的混合溶液中。

**答案：** $3\mathrm{Si} + 4\mathrm{HNO}_3 + 18\mathrm{HF(aq)} = 3\mathrm{H}_2\mathrm{SiF}_6 + 4\mathrm{NO}\uparrow + 8\mathrm{H}_2\mathrm{O}$

---

**14.37** 向 $\mathrm{Na}_{2}[\mathrm{Sn}(\mathrm{OH})_{6}]$ 溶液中通入 $\mathrm{CO}_{2}$。

**答案：** $[\mathrm{Sn(OH)}_6]^{2-} + 2\mathrm{CO}_2 = \mathrm{Sn(OH)}_4\downarrow + 2\mathrm{HCO}_3^-$

---

**14.38** $\mathrm{PbCrO_4}$ 溶于 $\mathrm{NaOH}$ 溶液。

**答案：** $\mathrm{PbCrO_4 + 4NaOH(aq) = Na_2[Pb(OH)_4] + Na_2CrO_4}$

---

**14.39** 金属铅溶于浓硝酸。

**答案：** $\mathrm{Pb + 4HNO_3(浓)} = \mathrm{Pb(NO_3)_2 + 2NO_2\uparrow + 2H_2O}$

---

**14.40** 二氧化铅与盐酸反应。

**答案：** $\mathrm{PbO_2 + 4HCl = PbCl_2 + Cl_2\uparrow + 2H_2O}$

---

**14.41** 将二氧化铅加入+2价锰离子的酸性溶液中并微热。

**答案：** $5\mathrm{PbO_2 + 2Mn^{2+} + 4H^+ \xlongequal{\text{微热}} 5Pb^{2+} + 2MnO_4^- + 2H_2O}$
