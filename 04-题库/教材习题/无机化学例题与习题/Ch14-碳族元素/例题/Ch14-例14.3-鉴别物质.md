# 例14.3 鉴别下列各组物质。

(1) $\mathrm{Sn(OH)_2}$ 和 $\mathrm{Pb(OH)_2}$；(2) $\mathrm{PbCrO}_4$ 和 $\mathrm{BaCrO}_4$。

---

## 答案

**(1)** 溶于 NaOH 溶液后加入次氯酸钠溶液，有棕黑色沉淀生成的是 $\mathrm{Pb(OH)}_{2}$（$\mathrm{Pb(II)}$ 被氧化为 $\mathrm{PbO}_{2}$）。

**(2)** 方法一：取少量固体样品，滴加稀盐酸，若黄色沉淀消失且不生成白色沉淀，则样品为 $\mathrm{BaCrO}_{4}$：

$$2 \mathrm{BaCrO}_{4} + 2 \mathrm{H}^{+} = \mathrm{Cr}_{2}\mathrm{O}_{7}^{2-} + 2 \mathrm{Ba}^{2+} + \mathrm{H}_{2}\mathrm{O}$$

若黄色沉淀在加稀盐酸时逐渐转变成白色沉淀（$\mathrm{PbCl}_2$），当盐酸过量时白色沉淀又消失（生成 $\mathrm{H_2[PbCl_4]}$），则样品为 $\mathrm{PbCrO}_{4}$。

方法二：取少量固体样品，滴加浓 NaOH 溶液，黄色沉淀逐渐消失的是 $\mathrm{PbCrO}_{4}$，无明显现象的是 $\mathrm{BaCrO}_{4}$：

$$\mathrm{PbCrO}_{4} + 3 \mathrm{OH}^{-} = \mathrm{CrO}_{4}^{2-} + [\mathrm{Pb(OH)}_{3}]^{-}$$
