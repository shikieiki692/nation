# 15.59 提纯下列物质。

## 题目

提纯下列物质。

(1) 除去 $\mathrm{N_2}$ 中的少量 $\mathrm{O_2}$ 和 $\mathrm{H_2O}$：将 $\mathrm{N_2}$ 气通过赤热的铜粉除去 $\mathrm{O_2}$（$\mathrm{O_2 + 2Cu = 2CuO}$），再用 $\mathrm{P_2O_5}$ 干燥 $\mathrm{N_2}$ 除去 $\mathrm{H_2O}$。

(2) 除去 NO 中的少量 $\mathrm{NO_2}$：将气体通过水或 $\mathrm{NaOH}$ 溶液除去 $\mathrm{NO_2}$，再用 $\mathrm{P_2O_5}$ 干燥：
$$3\mathrm{NO_2} + \mathrm{H_2O} = 2\mathrm{HNO_3} + \mathrm{NO}$$
$$2\mathrm{NO_2} + 2\mathrm{NaOH} = \mathrm{NaNO_3} + \mathrm{NaNO_2} + \mathrm{H_2O}$$

(3) 除去 $\mathrm{NaNO_3}$ 溶液中的少量 $\mathrm{NaNO_2}$：向溶液中加入少量 $\mathrm{HNO_3}$ 溶液后加热：
$$2\mathrm{NO_2^-} + 2\mathrm{H^+} = \mathrm{NO_2}\uparrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$$

或向溶液中加入少量 $\mathrm{NH_4NO_3}$ 溶液后加热：
$$\mathrm{NH_4^+} + \mathrm{NO_2^-} = \mathrm{N_2}\uparrow + 2\mathrm{H_2O}$$
