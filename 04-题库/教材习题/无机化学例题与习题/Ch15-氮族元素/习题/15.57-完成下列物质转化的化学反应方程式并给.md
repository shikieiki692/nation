# 15.57 完成下列物质转化的化学反应方程式并给出反

## 题目

完成下列物质转化的化学反应方程式并给出反应条件。

白磷在不足量的空气中燃烧生成 $\mathrm{P_4O_6}$：
$$\mathrm{P_4} + 3\mathrm{O_2} = \mathrm{P_4O_6}$$

白磷在有 HI 时与水反应生成 $\mathrm{H_3PO_3}$ 和 $\mathrm{PH_3}$：
$$\mathrm{P_4} + 6\mathrm{H_2O} \stackrel{\mathrm{HI}}{=} 2\mathrm{H_3PO_3} + 2\mathrm{PH_3}\uparrow$$

白磷与不足量的干燥氯气反应生成 $\mathrm{PCl_3}$：
$$\mathrm{P_4} + 6\mathrm{Cl_2} = 4\mathrm{PCl_3}$$

白磷在碱中歧化生成 $\mathrm{PH_3}$：
$$\mathrm{P_4} + 3\mathrm{NaOH} + 3\mathrm{H_2O} = \mathrm{PH_3}\uparrow + 3\mathrm{NaH_2PO_2}$$

$\mathrm{PH_3}$ 与不足量的干燥氯气反应生成 $\mathrm{PCl_3}$：
$$\mathrm{PH_3} + 3\mathrm{Cl_2} = \mathrm{PCl_3} + 3\mathrm{HCl}$$

$\mathrm{P_4O_6}$ 与过量氧作用生成 $\mathrm{P_4O_{10}}$：
$$\mathrm{P_4O_6} + 2\mathrm{O_2} = \mathrm{P_4O_{10}}$$

$\mathrm{P_4O_6}$ 缓慢溶于冷水生成 $\mathrm{H_3PO_3}$：
$$\mathrm{P_4O_6} + 6\mathrm{H_2O(冷)} = 4\mathrm{H_3PO_3}$$

$\mathrm{PCl_3}$ 水解生成 $\mathrm{H_3PO_3}$：
$$\mathrm{PCl_3} + 3\mathrm{H_2O} = \mathrm{H_3PO_3} + 3\mathrm{HCl}$$

$\mathrm{PCl_3}$ 与过量干燥 $\mathrm{Cl_2}$ 作用生成 $\mathrm{PCl_5}$：
$$\mathrm{PCl_3} + \mathrm{Cl_2} = \mathrm{PCl_5}$$

将 $\mathrm{H_3PO_3}$ 氧化生成 $\mathrm{H_3PO_4}$：
$$\mathrm{H_3PO_3} + \mathrm{H_2O_2} = \mathrm{H_3PO_4} + \mathrm{H_2O}$$

$\mathrm{P_4O_{10}}$ 与过量水作用最终生成 $\mathrm{H_3PO_4}$：
$$\mathrm{P_4O_{10}} + 6\mathrm{H_2O} = 4\mathrm{H_3PO_4}$$

$\mathrm{PCl_5}$ 彻底水解生成 $\mathrm{H_3PO_4}$：
$$\mathrm{PCl_5} + 4\mathrm{H_2O} = \mathrm{H_3PO_4} + 5\mathrm{HCl}$$
