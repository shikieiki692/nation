# 分离、鉴别与制备（15.55-15.61）

## 题目与答案

**15.55** 由辉锑矿生产单质 Sb。

高温下焙烧 $\mathrm{Sb_2S_3}$ 生成 $\mathrm{Sb_2O_3}$：
$$2\mathrm{Sb_2S_3} + 9\mathrm{O_2} \xlongequal{\triangle} 2\mathrm{Sb_2O_3} + 6\mathrm{SO_2}$$

高温下用 C 还原 $\mathrm{Sb_2O_3}$，即得金属锑单质：
$$\mathrm{Sb_2O_3} + 3\mathrm{C} \xlongequal{\triangle} 2\mathrm{Sb(g)} + 3\mathrm{CO(g)}$$

---

**15.56** 由 $\mathrm{Bi_2S_3}$ 制备 $\mathrm{NaBiO_3}$。

高温下焙烧 $\mathrm{Bi_2S_3}$ 生成 $\mathrm{Bi_2O_3}$：
$$2\mathrm{Bi_2S_3} + 9\mathrm{O_2} \xlongequal{\triangle} 2\mathrm{Bi_2O_3} + 6\mathrm{SO_2}$$

盐酸与 $\mathrm{Bi_2O_3}$ 反应得 $\mathrm{BiCl_3}$：
$$\mathrm{Bi_2O_3} + 6\mathrm{HCl} = 2\mathrm{BiCl_3} + 3\mathrm{H_2O}$$

在碱性介质中，强氧化剂 $\mathrm{Cl_2}$ 可氧化 Bi(III) 到 Bi(V)：
$$\mathrm{BiCl_3} + \mathrm{Cl_2} + 6\mathrm{NaOH(aq)} = \mathrm{NaBiO_3}\downarrow + 5\mathrm{NaCl} + 3\mathrm{H_2O}$$

---

**15.57** 完成下列物质转化的化学反应方程式并给出反应条件。

白磷在不足量的空气中燃烧生成 $\mathrm{P_4O_6}$：
$$\mathrm{P_4} + 3\mathrm{O_2} = \mathrm{P_4O_6}$$

白磷在有 HI 时与水反应生成 $\mathrm{H_3PO_3}$ 和 $\mathrm{PH_3}$：
$$\mathrm{P_4} + 6\mathrm{H_2O} \stackrel{\mathrm{HI}}{=} 2\mathrm{H_3PO_3} + 2\mathrm{PH_3}\uparrow$$

白磷与不足量的干燥氯气反应生成 $\mathrm{PCl_3}$：
$$\mathrm{P_4} + 6\mathrm{Cl_2} = 4\mathrm{PCl_3}$$

白磷在碱中歧化生成 $\mathrm{PH_3}$：
$$\mathrm{P_4} + 3\mathrm{NaOH} + 3\mathrm{H_2O} = \mathrm{PH_3}\uparrow + 3\mathrm{NaH_2PO_2}$$

$\mathrm{PH_3}$ 与不足量的干燥氯气反应生成 $\mathrm{PCl_3}$：
$$\mathrm{PH_3} + 3\mathrm{Cl_2} = \mathrm{PCl_3} + 3\mathrm{HCl}$$

$\mathrm{P_4O_6}$ 与过量氧作用生成 $\mathrm{P_4O_{10}}$：
$$\mathrm{P_4O_6} + 2\mathrm{O_2} = \mathrm{P_4O_{10}}$$

$\mathrm{P_4O_6}$ 缓慢溶于冷水生成 $\mathrm{H_3PO_3}$：
$$\mathrm{P_4O_6} + 6\mathrm{H_2O(冷)} = 4\mathrm{H_3PO_3}$$

$\mathrm{PCl_3}$ 水解生成 $\mathrm{H_3PO_3}$：
$$\mathrm{PCl_3} + 3\mathrm{H_2O} = \mathrm{H_3PO_3} + 3\mathrm{HCl}$$

$\mathrm{PCl_3}$ 与过量干燥 $\mathrm{Cl_2}$ 作用生成 $\mathrm{PCl_5}$：
$$\mathrm{PCl_3} + \mathrm{Cl_2} = \mathrm{PCl_5}$$

将 $\mathrm{H_3PO_3}$ 氧化生成 $\mathrm{H_3PO_4}$：
$$\mathrm{H_3PO_3} + \mathrm{H_2O_2} = \mathrm{H_3PO_4} + \mathrm{H_2O}$$

$\mathrm{P_4O_{10}}$ 与过量水作用最终生成 $\mathrm{H_3PO_4}$：
$$\mathrm{P_4O_{10}} + 6\mathrm{H_2O} = 4\mathrm{H_3PO_4}$$

$\mathrm{PCl_5}$ 彻底水解生成 $\mathrm{H_3PO_4}$：
$$\mathrm{PCl_5} + 4\mathrm{H_2O} = \mathrm{H_3PO_4} + 5\mathrm{HCl}$$

**15.58** 分离下列各组离子。

(1) $\mathrm{Sb^{3+}}$ 和 $\mathrm{Bi^{3+}}$：向溶液中加入过量 $\mathrm{NaOH}$ 溶液，$\mathrm{Sb^{3+}}$ 生成可溶性的 $\mathrm{SbO_3^{3-}}$ 而 $\mathrm{Bi^{3+}}$ 生成 $\mathrm{Bi(OH)_3}$ 沉淀：
$$\mathrm{Sb^{3+}} + 6\mathrm{OH^-} = \mathrm{SbO_3^{3-}} + 3\mathrm{H_2O}$$
$$\mathrm{Bi^{3+}} + 3\mathrm{OH^-} = \mathrm{Bi(OH)_3}\downarrow$$

(2) $\mathrm{PO_4^{3-}}$ 和 $\mathrm{NO_3^-}$：向溶液中加入 $\mathrm{AgNO_3}$ 溶液，$\mathrm{PO_4^{3-}}$ 与 $\mathrm{Ag^+}$ 生成 $\mathrm{Ag_3PO_4}$ 沉淀而 $\mathrm{NO_3^-}$ 留在溶液中。

(3) $\mathrm{PO_4^{3-}}$ 和 $\mathrm{SO_4^{2-}}$：将溶液用硝酸酸化后加入 $\mathrm{BaCl_2}$ 溶液，$\mathrm{SO_4^{2-}}$ 转化为 $\mathrm{BaSO_4}$ 沉淀而 $\mathrm{PO_4^{3-}}$ 转化为 $\mathrm{H_2PO_4^-}$ 留在溶液中。

(4) $\mathrm{PO_4^{3-}}$ 和 $\mathrm{Cl^-}$：将溶液用硝酸酸化后加入 $\mathrm{AgNO_3}$ 溶液，$\mathrm{Cl^-}$ 转化为 $\mathrm{AgCl}$ 沉淀而 $\mathrm{PO_4^{3-}}$ 转化为 $\mathrm{H_2PO_4^-}$ 留在溶液中。

---

**15.59** 提纯下列物质。

(1) 除去 $\mathrm{N_2}$ 中的少量 $\mathrm{O_2}$ 和 $\mathrm{H_2O}$：将 $\mathrm{N_2}$ 气通过赤热的铜粉除去 $\mathrm{O_2}$（$\mathrm{O_2 + 2Cu = 2CuO}$），再用 $\mathrm{P_2O_5}$ 干燥 $\mathrm{N_2}$ 除去 $\mathrm{H_2O}$。

(2) 除去 NO 中的少量 $\mathrm{NO_2}$：将气体通过水或 $\mathrm{NaOH}$ 溶液除去 $\mathrm{NO_2}$，再用 $\mathrm{P_2O_5}$ 干燥：
$$3\mathrm{NO_2} + \mathrm{H_2O} = 2\mathrm{HNO_3} + \mathrm{NO}$$
$$2\mathrm{NO_2} + 2\mathrm{NaOH} = \mathrm{NaNO_3} + \mathrm{NaNO_2} + \mathrm{H_2O}$$

(3) 除去 $\mathrm{NaNO_3}$ 溶液中的少量 $\mathrm{NaNO_2}$：向溶液中加入少量 $\mathrm{HNO_3}$ 溶液后加热：
$$2\mathrm{NO_2^-} + 2\mathrm{H^+} = \mathrm{NO_2}\uparrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$$

或向溶液中加入少量 $\mathrm{NH_4NO_3}$ 溶液后加热：
$$\mathrm{NH_4^+} + \mathrm{NO_2^-} = \mathrm{N_2}\uparrow + 2\mathrm{H_2O}$$

**15.60** 分别用三种方法鉴别下列各组物质。

(1) $\mathrm{Na_3PO_4}$ 和 $\mathrm{Na_2SO_4}$：

**方法一**：向两种盐的溶液中加入 $\mathrm{AgNO_3}$ 溶液，有黄色沉淀生成的是 $\mathrm{Na_3PO_4}$，有白色沉淀生成的是 $\mathrm{Na_2SO_4}$：
$$3\mathrm{Ag^+} + \mathrm{PO_4^{3-}} = \mathrm{Ag_3PO_4}\downarrow(\text{黄色})$$
$$2\mathrm{Ag^+} + \mathrm{SO_4^{2-}} = \mathrm{Ag_2SO_4}\downarrow(\text{白色})$$

**方法二**：向两种盐的溶液中加入 $\mathrm{BaCl_2}$ 溶液，生成的白色沉淀不溶于硝酸的是 $\mathrm{Na_2SO_4}$，生成的白色沉淀溶于硝酸的是 $\mathrm{Na_3PO_4}$。

**方法三**：向两种盐的溶液中加入碘水，能使碘水褪色的是 $\mathrm{Na_3PO_4}$（碱性较强，碘水发生歧化反应），不能使碘水褪色的是 $\mathrm{Na_2SO_4}$。

(2) $\mathrm{KNO_3}$ 和 $\mathrm{KIO_3}$：

**方法一**：将两种盐的溶液酸化后滴加 $\mathrm{Na_2SO_3}$ 溶液，颜色变黄有 $\mathrm{I_2}$ 生成的是 $\mathrm{KIO_3}$，另一种是 $\mathrm{KNO_3}$。

**方法二**：将两种盐分别与 $\mathrm{NaNO_2}$ 晶体混合后滴加浓硫酸，有 $\mathrm{NO_2}$ 气体放出的是 $\mathrm{KNO_3}$，另一种是 $\mathrm{KIO_3}$。

**方法三**：向两种盐的溶液中分别加入 $\mathrm{BaCl_2}$ 溶液，生成白色沉淀的为 $\mathrm{KIO_3}$，另一种为 $\mathrm{KNO_3}$。

---

**15.61** 试用 6 种方法鉴别 $\mathrm{KNO_3}$ 和 $\mathrm{KNO_2}$。

**方法一**：向两种盐的溶液中分别加入酸性 $\mathrm{KMnO_4}$ 溶液，使 $\mathrm{KMnO_4}$ 溶液褪色的是 $\mathrm{KNO_2}$，另一种是 $\mathrm{KNO_3}$。

**方法二**：将两种盐的溶液分别用 HAc 酸化，再加入 KI 溶液，颜色变黄（有 $\mathrm{I_2}$ 生成）的是 $\mathrm{KNO_2}$，另一种是 $\mathrm{KNO_3}$。

**方法三**：向两种盐的溶液中分别加入 $\mathrm{AgNO_3}$ 溶液，有黄色沉淀生成的是 $\mathrm{KNO_2}$，另一种是 $\mathrm{KNO_3}$。

**方法四**：向盛有两种盐的溶液的大试管中分别加入 $\mathrm{FeSO_4}$ 溶液，斜持试管并沿试管壁缓慢倒入浓硫酸，在硫酸与溶液的界面生成棕色环的是 $\mathrm{KNO_3}$，生成棕色溶液的是 $\mathrm{KNO_2}$。

**方法五**：向两种盐的溶液中加入 HAc 和 $\mathrm{CoCl_2}$ 溶液，水浴加热后冷却，有黄色沉淀析出的是 $\mathrm{KNO_2}$，另一种是 $\mathrm{KNO_3}$。

**方法六**：向盛有两种盐晶体的试管中分别加入浓硝酸，有棕色气体生成的是 $\mathrm{KNO_2}$，另一种是 $\mathrm{KNO_3}$。
