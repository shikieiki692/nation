# 简答题（15.62-15.77）

## 题目与答案

**15.62** 除去下列物质中的杂质，给出相关化学反应方程式。

(1) $\mathrm{KNO_2}$ 晶体中的少量 $\mathrm{KNO_3}$ 晶体：晶体在煤气灯上加热，$\mathrm{KNO_3}$ 转化为 $\mathrm{KNO_2}$：
$$2\mathrm{KNO_3} \xlongequal{\triangle} 2\mathrm{KNO_2} + \mathrm{O_2}\uparrow$$

(2) $\mathrm{N_2O}$ 气体中混有的少量 NO：使气体通过 $\mathrm{FeSO_4}$ 溶液除去 NO：
$$\mathrm{NO} + \mathrm{FeSO_4} = \mathrm{Fe(NO)SO_4}$$

(3) $\mathrm{Na_2SO_4}$ 溶液中的少量 $\mathrm{(NH_4)_2SO_4}$：向溶液中加少量 $\mathrm{NaNO_2}$ 后加热可除去 $\mathrm{NH_4^+}$：
$$\mathrm{NH_4^+} + \mathrm{NO_2^-} \xlongequal{\triangle} \mathrm{N_2}\uparrow + 2\mathrm{H_2O}$$

**15.63** $\mathrm{H_4P_2O_7}$ 的解离平衡常数 $K_{\mathrm{a_1}}^{\ominus} = 1.2\times10^{-1}$，$K_{\mathrm{a_2}}^{\ominus} = 7.9\times10^{-3}$，$K_{\mathrm{a_3}}^{\ominus} = 2.0\times10^{-7}$，$K_{\mathrm{a_4}}^{\ominus} = 4.5\times10^{-10}$，为什么 $K_{\mathrm{a_1}}^{\ominus}$ 与 $K_{\mathrm{a_2}}^{\ominus}$ 相近，$K_{\mathrm{a_3}}^{\ominus}$ 与 $K_{\mathrm{a_4}}^{\ominus}$ 相近，但 $K_{\mathrm{a_2}}^{\ominus}$ 与 $K_{\mathrm{a_3}}^{\ominus}$ 相差较大？

解离出第一个 $\mathrm{H^+}$ 和第二个 $\mathrm{H^+}$ 是从两个不同的磷氧四面体失去 $\mathrm{H^+}$，二者解离时相互影响不大，因此 $K_{\mathrm{a_1}}^{\ominus}$ 与 $K_{\mathrm{a_2}}^{\ominus}$ 相差不大。但解离出第三个 $\mathrm{H^+}$ 时，是从失去一个 $\mathrm{H^+}$ 并带负电的四面体上再解离出第二个 $\mathrm{H^+}$，显然困难得多，因而 $K_{\mathrm{a_2}}^{\ominus}$ 与 $K_{\mathrm{a_3}}^{\ominus}$ 相差较大。同理，$K_{\mathrm{a_3}}^{\ominus}$ 与 $K_{\mathrm{a_4}}^{\ominus}$ 相近。

**15.64** 在酸性溶液中，按氧化能力由大到小排列这些离子，并简要说明：$\mathrm{NO_3^-}$、$\mathrm{PO_4^{3-}}$、$\mathrm{AsO_4^{3-}}$、$\mathrm{SbO_4^{3-}}$、$\mathrm{BiO_3^-}$。

氧化能力：$\mathrm{BiO_3^- > NO_3^- > SbO_4^{3-} > AsO_4^{3-} > PO_4^{3-}}$

在氮族的五价化合物中，随周期数增加，元素 R 的半径增大，R—O 键强度减弱，则氧化能力增强。由于 Bi(V) 的惰性电子对效应，其氧化性最强且有一个突跃。而 N(V) 由于无空的价层 d 轨道，N—O 间不存在 d-pπ 配键使键强度变弱，N—O 键易断而有明显的氧化性。

**15.65** 解释实验现象。

(1) 向含有 $\mathrm{Bi^{3+}}$ 和 $\mathrm{Sn^{2+}}$ 的澄清溶液中加入 $\mathrm{NaOH}$ 溶液会有黑色沉淀生成：在碱性条件下 $\mathrm{Sn^{2+}}$ 将 $\mathrm{Bi^{3+}}$ 还原为单质 Bi，生成的粉末产物为黑色：
$$3\mathrm{Sn^{2+}} + 2\mathrm{Bi^{3+}} + 18\mathrm{OH^-} = 2\mathrm{Bi}\downarrow + 3[\mathrm{Sn(OH)_6}]^{2-}$$

(2) 向 $\mathrm{FeCl_3}$ 溶液中滴加 $\mathrm{Na_3PO_4}$ 溶液，先有黄色沉淀生成；继续滴加时沉淀减少，最后消失得无色溶液：黄色沉淀为 $\mathrm{FePO_4}$。因磷酸具有配位性，当磷酸过量时，生成可溶性配位化合物 $[\mathrm{Fe(PO_4)_2}]^{3-}$：
$$\mathrm{Fe^{3+}} + \mathrm{PO_4^{3-}} = \mathrm{FePO_4}\downarrow$$
$$\mathrm{FePO_4} + \mathrm{PO_4^{3-}} = [\mathrm{Fe(PO_4)_2}]^{3-}$$

(3) $\mathrm{AsH_3}$ 通入一玻璃管并在入口处加热，管壁出现有金属光泽的黑色物质：$\mathrm{AsH_3}$ 受热分解，在玻璃管壁生成了黑亮的单质 As：
$$2\mathrm{AsH_3} \xlongequal{\triangle} 2\mathrm{As} + 3\mathrm{H_2}$$

(4) 向 $\mathrm{NaNO_2}$ 溶液中加 $\mathrm{AgNO_3}$ 溶液有黄色沉淀生成：$\mathrm{AgNO_2}$ 为微溶盐：
$$\mathrm{Ag^+} + \mathrm{NO_2^-} = \mathrm{AgNO_2}\downarrow$$

(5) 将 $\mathrm{NaOH}$ 溶液与 $\mathrm{BiCl_3}$ 溶液充分混合有白色沉淀生成，再向其中通入 $\mathrm{Cl_2}$ 时有黄棕色沉淀生成：白色沉淀为 $\mathrm{Bi(OH)_3}$，呈碱性，不溶于过量的 $\mathrm{NaOH}$：
$$\mathrm{Bi^{3+}} + 3\mathrm{OH^-} = \mathrm{Bi(OH)_3}\downarrow$$

在碱性介质中，强氧化剂 $\mathrm{Cl_2}$ 可氧化 $\mathrm{Bi(OH)_3}$ 得到土黄色沉淀物 $\mathrm{NaBiO_3}$：
$$\mathrm{BiCl_3} + \mathrm{Cl_2} + 6\mathrm{NaOH(aq)} = \mathrm{NaBiO_3}\downarrow + 5\mathrm{NaCl} + 3\mathrm{H_2O}$$

**15.66** 给出下列硝酸盐受热分解的反应方程式，总结硝酸盐热分解反应规律。

$\mathrm{KNO_3}$、$\mathrm{LiNO_3}$、$\mathrm{Pb(NO_3)_2}$、$\mathrm{Bi(NO_3)_3}$、$\mathrm{AgNO_3}$、$\mathrm{Fe(NO_3)_2}$

$$2\mathrm{KNO_3} \xlongequal{\triangle} 2\mathrm{KNO_2} + \mathrm{O_2}\uparrow$$

$$4\mathrm{LiNO_3} \xlongequal{\triangle} 2\mathrm{Li_2O} + 4\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$2\mathrm{Pb(NO_3)_2} \xlongequal{\triangle} 2\mathrm{PbO} + 4\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$4\mathrm{Bi(NO_3)_3} \xlongequal{\triangle} 2\mathrm{Bi_2O_3} + 12\mathrm{NO_2}\uparrow + 3\mathrm{O_2}\uparrow$$

$$2\mathrm{AgNO_3} \xlongequal{\triangle} 2\mathrm{Ag} + 2\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$4\mathrm{Fe(NO_3)_2} \xlongequal{\triangle} 2\mathrm{Fe_2O_3} + 8\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

**规律**：硝酸盐受热分解的产物与阳离子的极化能力有关，按照阳离子的极化能力由弱至强，分别生成亚硝酸盐和氧气，金属氧化物、二氧化氮和氧气，金属单质、二氧化氮和氧气；若阳离子有还原性，则阳离子可被生成的氧气所氧化。

**15.67** 为什么 $\mathrm{NH_3}$ 溶液显碱性而 $\mathrm{HN_3}$ 溶液显酸性？

$\mathrm{NH_3}$ 是一种稳定的分子，在水中解离出 $\mathrm{H^+}$ 的能力很弱。而 $\mathrm{NH_3}$ 中 N 的孤电子对有较强的配位能力，可以与 $\mathrm{H_2O}$ 解离出的 $\mathrm{H^+}$ 结合，使溶液中的 $\mathrm{OH^-}$ 过剩，故 $\mathrm{NH_3}$ 溶液显碱性：
$$\mathrm{NH_3} + \mathrm{H_2O} \rightleftharpoons \mathrm{NH_4^+} + \mathrm{OH^-} \quad K_{\mathrm{b}}^{\ominus} = 1.8\times10^{-5}$$

$\mathrm{HN_3}$ 分子解离出 $\mathrm{H^+}$ 后生成的 $\mathrm{N_3^-}$ 由于离域 $\pi$ 键存在使其较稳定，同时 $\mathrm{HN_3}$ 端原子 N 的电子对配位能力极弱。所以，$\mathrm{HN_3}$ 给出质子能力远比配位能力强而显酸性：
$$\mathrm{HN_3} \rightleftharpoons \mathrm{N_3^-} + \mathrm{H^+} \quad K_{\mathrm{a}}^{\ominus} = 2.5\times10^{-5}$$

**15.68** 如何配制 $\mathrm{SbCl_3}$ 溶液和 $\mathrm{Bi(NO_3)_3}$ 溶液？

$\mathrm{SbCl_3}$ 和 $\mathrm{Bi(NO_3)_3}$ 都易水解生成沉淀：
$$\mathrm{SbCl_3} + \mathrm{H_2O} \rightleftharpoons \mathrm{SbOCl}\downarrow + 2\mathrm{HCl}$$
$$\mathrm{Bi(NO_3)_3} + \mathrm{H_2O} \rightleftharpoons \mathrm{BiONO_3}\downarrow + 2\mathrm{HNO_3}$$

加酸可抑制盐的水解。为避免水解，在配制溶液时先将一定量的盐溶于相应的酸中，再稀释到所需体积即可。配制 $\mathrm{SbCl_3}$ 溶液时，先将 $\mathrm{SbCl_3}$ 溶于 1:1 盐酸中；配制 $\mathrm{Bi(NO_3)_3}$ 溶液时，先将 $\mathrm{Bi(NO_3)_3}$ 溶于 1:1 硝酸中。

**15.69** 有人提出由 $\mathrm{NO_2}$ 的磁性测定数据可分析 $\mathrm{NO_2}$ 分子中的离域 $\pi$ 键是 $\Pi_3^4$ 还是 $\Pi_3^3$。你认为是否可行？为什么？

这种方法是不可行的。

测定 $\mathrm{NO_2}$ 的磁性应是 $\mathrm{NO_2}$ 处在液态或固态下，而随着温度的降低，$\mathrm{NO_2}$ 发生聚合反应：
$$2\mathrm{NO_2} \rightleftharpoons \mathrm{N_2O_4}$$

实验结果表明，在 $\mathrm{N_2O_4}$ 沸点温度时，液体中含有 1% 的 $\mathrm{NO_2}$，气体中含有 15.9% 的 $\mathrm{NO_2}$；在 $\mathrm{N_2O_4}$ 熔点温度的液体中只含有 0.01% 的 $\mathrm{NO_2}$，在低于 $\mathrm{N_2O_4}$ 的熔点温度时，固体中全部是 $\mathrm{N_2O_4}$。

可见，液态或固态时 $\mathrm{NO_2}$ 几乎全部转化为 $\mathrm{N_2O_4}$，无法测定液态或固态时 $\mathrm{NO_2}$ 的磁性。

**15.70** 比较磷的含氧酸的酸性强弱：$\mathrm{H_3PO_2}$、$\mathrm{H_3PO_3}$、$\mathrm{H_3PO_4}$、$\mathrm{H_4P_2O_7}$。

由酸的解离平衡常数判断，酸性 $\mathrm{H_4P_2O_7 > H_3PO_2 > H_3PO_3 > H_3PO_4}$

$$\begin{aligned}
\mathrm{H_3PO_2} & \quad K_{\mathrm{a}}^{\ominus} = 5.9\times10^{-2} \\
\mathrm{H_3PO_3} & \quad K_{\mathrm{a_1}}^{\ominus} = 3.7\times10^{-2} \\
\mathrm{H_3PO_4} & \quad K_{\mathrm{a_1}}^{\ominus} = 7.1\times10^{-3} \\
\mathrm{H_4P_2O_7} & \quad K_{\mathrm{a_1}}^{\ominus} = 1.2\times10^{-1}
\end{aligned}$$

**15.71** 为什么与过渡金属的配位能力 $\mathrm{NH_3 < PH_3}$，$\mathrm{NF_3 < PF_3}$；而与 $\mathrm{H^+}$ 的配位能力 $\mathrm{NH_3 > PH_3}$？

$\mathrm{NH_3}$ 和 $\mathrm{NF_3}$ 利用 N 的孤电子对向过渡金属配位形成配位键；而 $\mathrm{PH_3}$ 和 $\mathrm{PF_3}$ 的中心原子 P 除利用 P 的孤电子对向过渡金属配位形成配位键外，P 原子空的 d 轨道接受过渡金属 d 轨道电子的配位，形成 d-dπ 配键，使 $\mathrm{PH_3}$ 和 $\mathrm{PF_3}$ 与过渡金属生成的配位化合物更稳定，即与过渡金属的配位能力 $\mathrm{NH_3 < PH_3}$，$\mathrm{NF_3 < PF_3}$。

由于 H 不存在价层 d 轨道，在与 $\mathrm{H^+}$ 配位时，$\mathrm{NH_3}$ 和 $\mathrm{PH_3}$ 只能以孤电子对向 $\mathrm{H^+}$ 的 1s 空轨道配位。$\mathrm{H^+}$ 的半径很小，与半径小的 N 形成的配位键较强，而与半径较大的 P 形成的配位键较弱。因此，与 $\mathrm{H^+}$ 的配位能力 $\mathrm{NH_3 > PH_3}$。
