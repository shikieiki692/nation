# 完成并配平化学反应方程式（15.30-15.54）

## 题目与答案

**15.30** 氯化铵与亚硝酸钠溶液混合后加热。

$$\mathrm{NH_4^+ + NO_2^- \xrightarrow{\triangle} N_2\uparrow + 2H_2O}$$

**15.31** 亚硝酸钠晶体与浓硝酸混合。

$$\mathrm{NaNO_2(s) + 2HNO_3(浓)} = 2\mathrm{NO_2}\uparrow + \mathrm{NaNO_3} + \mathrm{H_2O}$$

**15.32** 二氧化氮通入氢氧化钠溶液。

$$2\mathrm{NO_2} + 2\mathrm{NaOH} = \mathrm{NaNO_2} + \mathrm{NaNO_3} + \mathrm{H_2O}$$

**15.33** 亚硝酸钠晶体受热分解。

$$2\mathrm{NaNO_2} \xrightarrow{\triangle} \mathrm{Na_2O} + \mathrm{NO_2}\uparrow + \mathrm{NO}\uparrow$$

**15.34** 氨气通过热的氧化铜。

$$2\mathrm{NH_3} + 3\mathrm{CuO} \xrightarrow{\triangle} \mathrm{N_2} + 3\mathrm{Cu} + 3\mathrm{H_2O}$$

**15.35** 用羟胺处理 $\mathrm{AgBr}$。

$$2\mathrm{NH_2OH} + 2\mathrm{AgBr} = \mathrm{N_2}\uparrow + 2\mathrm{Ag}\downarrow + 2\mathrm{HBr} + 2\mathrm{H_2O}$$

**15.36** 叠氨酸铅受热分解。

$$\mathrm{Pb(N_3)_2} \xrightarrow{\triangle} \mathrm{Pb} + 3\mathrm{N_2}\uparrow$$

**15.37** 金溶于王水。

$$\mathrm{Au} + \mathrm{HNO_3} + 4\mathrm{HCl} = \mathrm{HAuCl_4} + \mathrm{NO}\uparrow + 2\mathrm{H_2O}$$

**15.38** 铂溶于王水。

$$3\mathrm{Pt} + 4\mathrm{HNO_3} + 18\mathrm{HCl} = 3\mathrm{H_2PtCl_6} + 4\mathrm{NO}\uparrow + 8\mathrm{H_2O}$$

**15.39** 向红磷与水的混合物中滴加溴。

$$3\mathrm{Br_2} + 2\mathrm{P} + 6\mathrm{H_2O} = 6\mathrm{HBr} + 2\mathrm{H_3PO_3}$$

**15.40** 白磷溶于硝酸溶液。

$$3\mathrm{P_4} + 20\mathrm{HNO_3} + 8\mathrm{H_2O} = 12\mathrm{H_3PO_4} + 20\mathrm{NO}\uparrow$$

**15.41** 向次磷酸溶液中滴加硝酸银溶液。

$$\mathrm{H_3PO_2} + 4\mathrm{AgNO_3} + 2\mathrm{H_2O} = 4\mathrm{Ag}\downarrow + \mathrm{H_3PO_4} + 4\mathrm{HNO_3}$$

**15.42** 三氯化磷与氧气反应。

$$2\mathrm{PCl_3} + \mathrm{O_2} = 2\mathrm{POCl_3}$$

**15.43** 次磷酸溶液中加入过量氢氧化钠溶液。

$$\mathrm{H_3PO_2} + \mathrm{NaOH} = \mathrm{NaH_2PO_2} + \mathrm{H_2O}$$

**15.44** 亚磷酸溶液中加入过量氢氧化钠溶液。

$$\mathrm{H_3PO_3} + 2\mathrm{NaOH} = \mathrm{Na_2HPO_3} + 2\mathrm{H_2O}$$

**15.45** 用次氯酸钠溶液洗掉玻璃管壁上的"砷镜"。

$$5\mathrm{NaClO} + 2\mathrm{As} + 3\mathrm{H_2O} = 2\mathrm{H_3AsO_4} + 5\mathrm{NaCl}$$

**15.46** 砷化氢通入硝酸银溶液。

$$2\mathrm{AsH_3} + 12\mathrm{AgNO_3} + 3\mathrm{H_2O} = \mathrm{As_2O_3} + 12\mathrm{Ag}\downarrow + 12\mathrm{HNO_3}$$

**15.47** 三硫化二砷溶于氢氧化钠溶液。

$$\mathrm{As_2S_3} + 6\mathrm{NaOH} = \mathrm{Na_3AsO_3} + \mathrm{Na_3AsS_3} + 3\mathrm{H_2O}$$

**15.48** 三硫化二砷溶于硫化钠溶液。

$$\mathrm{As_2S_3} + 3\mathrm{Na_2S} = 2\mathrm{Na_3AsS_3}$$

**15.49** 向硫代砷酸钠溶液中加盐酸。

$$2\mathrm{Na_3AsS_4} + 6\mathrm{HCl} = \mathrm{As_2S_5}\downarrow + 3\mathrm{H_2S}\uparrow + 6\mathrm{NaCl}$$

**15.50** 五硫化二锑溶于氢氧化钠溶液。

$$4\mathrm{Sb_2S_5} + 24\mathrm{NaOH} = 3\mathrm{Na_3SbO_4} + 5\mathrm{Na_3SbS_4} + 12\mathrm{H_2O}$$

**15.51** 三氧化二锑溶于浓硝酸。

$$\mathrm{Sb_2O_3} + 4\mathrm{HNO_3(浓)} + \mathrm{H_2O} = 2\mathrm{H_3SbO_4} + 4\mathrm{NO_2}\uparrow$$

**15.52** 三氯化铋水解。

$$\mathrm{BiCl_3} + \mathrm{H_2O} = \mathrm{BiOCl}\downarrow + 2\mathrm{HCl}$$

**15.53** 氢氧化铋与氯气在氢氧化钠溶液中反应。

$$\mathrm{Bi(OH)_3} + \mathrm{Cl_2} + 3\mathrm{NaOH(aq)} = \mathrm{NaBiO_3}\downarrow + 2\mathrm{NaCl} + 3\mathrm{H_2O}$$

**15.54** 将铋酸钠与少许酸化的硫酸锰溶液混合。

$$5\mathrm{NaBiO_3} + 2\mathrm{Mn^{2+}} + 14\mathrm{H^+} = 5\mathrm{Bi^{3+}} + 2\mathrm{MnO_4^-} + 5\mathrm{Na^+} + 7\mathrm{H_2O}$$
