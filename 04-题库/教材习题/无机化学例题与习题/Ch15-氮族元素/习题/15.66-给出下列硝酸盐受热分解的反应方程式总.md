# 15.66 给出下列硝酸盐受热分解的反应方程式，总结

## 题目

给出下列硝酸盐受热分解的反应方程式，总结硝酸盐热分解反应规律。

$\mathrm{KNO_3}$、$\mathrm{LiNO_3}$、$\mathrm{Pb(NO_3)_2}$、$\mathrm{Bi(NO_3)_3}$、$\mathrm{AgNO_3}$、$\mathrm{Fe(NO_3)_2}$

$$2\mathrm{KNO_3} \xlongequal{\triangle} 2\mathrm{KNO_2} + \mathrm{O_2}\uparrow$$

$$4\mathrm{LiNO_3} \xlongequal{\triangle} 2\mathrm{Li_2O} + 4\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$2\mathrm{Pb(NO_3)_2} \xlongequal{\triangle} 2\mathrm{PbO} + 4\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$4\mathrm{Bi(NO_3)_3} \xlongequal{\triangle} 2\mathrm{Bi_2O_3} + 12\mathrm{NO_2}\uparrow + 3\mathrm{O_2}\uparrow$$

$$2\mathrm{AgNO_3} \xlongequal{\triangle} 2\mathrm{Ag} + 2\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

$$4\mathrm{Fe(NO_3)_2} \xlongequal{\triangle} 2\mathrm{Fe_2O_3} + 8\mathrm{NO_2}\uparrow + \mathrm{O_2}\uparrow$$

**规律**：硝酸盐受热分解的产物与阳离子的极化能力有关，按照阳离子的极化能力由弱至强，分别生成亚硝酸盐和氧气，金属氧化物、二氧化氮和氧气，金属单质、二氧化氮和氧气；若阳离子有还原性，则阳离子可被生成的氧气所氧化。
