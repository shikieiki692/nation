# 15.67 为什么NH3溶液显碱性而HN3溶液显酸性

## 题目

为什么 $\mathrm{NH_3}$ 溶液显碱性而 $\mathrm{HN_3}$ 溶液显酸性？

$\mathrm{NH_3}$ 是一种稳定的分子，在水中解离出 $\mathrm{H^+}$ 的能力很弱。而 $\mathrm{NH_3}$ 中 N 的孤电子对有较强的配位能力，可以与 $\mathrm{H_2O}$ 解离出的 $\mathrm{H^+}$ 结合，使溶液中的 $\mathrm{OH^-}$ 过剩，故 $\mathrm{NH_3}$ 溶液显碱性：
$$\mathrm{NH_3} + \mathrm{H_2O} \rightleftharpoons \mathrm{NH_4^+} + \mathrm{OH^-} \quad K_{\mathrm{b}}^{\ominus} = 1.8\times10^{-5}$$

$\mathrm{HN_3}$ 分子解离出 $\mathrm{H^+}$ 后生成的 $\mathrm{N_3^-}$ 由于离域 $\pi$ 键存在使其较稳定，同时 $\mathrm{HN_3}$ 端原子 N 的电子对配位能力极弱。所以，$\mathrm{HN_3}$ 给出质子能力远比配位能力强而显酸性：
$$\mathrm{HN_3} \rightleftharpoons \mathrm{N_3^-} + \mathrm{H^+} \quad K_{\mathrm{a}}^{\ominus} = 2.5\times10^{-5}$$
