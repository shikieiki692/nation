# 例15.2 用化学反应方程式表示制备与生产过程

## 题目

(1) 以 $\mathrm{N_2}$ 和 $\mathrm{H_2}$ 为主要原料制备 $\mathrm{NH_4NO_3}$

(2) 由 $\mathrm{NH_3}$ 制备 $\mathrm{N_2H_4}$ 和 $\mathrm{HN_3}$

(3) 由 $\mathrm{NaNO_3}$ 制备 $\mathrm{N_2O_5}$

(4) 以磷酸钙矿为主要原料生产 $\mathrm{P_2O_5}$ 和单质 $\mathrm{P}$

(5) 以 $\mathrm{As_2S_3}$ 为主要原料制备 $\mathrm{As_2O_3}$ 和 $\mathrm{H_3AsO_4}$

## 解答

**(1)** 合成氨：
$$3\mathrm{H_2} + \mathrm{N_2} \xrightarrow[T,p]{\text{催化剂}} 2\mathrm{NH_3}$$

生成的 $\mathrm{NH_3}$ 通入硝酸中生成 $\mathrm{NH_4NO_3}$：
$$\mathrm{NH_3} + \mathrm{HNO_3} = \mathrm{NH_4NO_3}$$

**(2)** 用 NaClO 氧化过量氨水得到 $\mathrm{N_2H_4}$：
$$2\mathrm{NH_3} + \mathrm{NaClO} = \mathrm{N_2H_4} + \mathrm{NaCl} + \mathrm{H_2O}$$

联氨被亚硝酸氧化生成叠氮酸：
$$\mathrm{N_2H_4} + \mathrm{HNO_2} = \mathrm{HN_3} + 2\mathrm{H_2O}$$

**(3)** 将 $\mathrm{NaNO_3}$ 酸化，并用 $\mathrm{P_2O_5}$ 使硝酸脱水：
$$6\mathrm{HNO_3} + \mathrm{P_2O_5} = 3\mathrm{N_2O_5} + 2\mathrm{H_3PO_4}$$

**(4)** 在电炉中反应：
$$\mathrm{Ca_3(PO_4)_2(s)} + 3\mathrm{SiO_2(s)} = 3\mathrm{CaSiO_3(l)} + \mathrm{P_2O_5(g)}$$
$$\mathrm{P_2O_5(g)} + 5\mathrm{C(s)} = 2\mathrm{P(g)} + 5\mathrm{CO(g)}$$

将 P 蒸气通入水中冷凝得单质 P。

**(5)** 高温下焙烧 $\mathrm{As_2S_3}$ 得到 $\mathrm{As_2O_3}$：
$$2\mathrm{As_2S_3} + 9\mathrm{O_2} \xlongequal{\triangle} 2\mathrm{As_2O_3} + 6\mathrm{SO_2}$$

酸性条件下用 $\mathrm{H_2O_2}$ 氧化 $\mathrm{As_2O_3}$ 可得 $\mathrm{H_3AsO_4}$：
$$\mathrm{As_2O_3} + 2\mathrm{H_2O_2} + \mathrm{H_2O} \xlongequal{\triangle} 2\mathrm{H_3AsO_4}$$
