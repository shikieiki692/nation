# 例15.10 推断物质化学式（二）

## 题目

化合物(A)溶于稀盐酸得无色溶液，再加入 $\mathrm{NaOH}$ 溶液得到白色沉淀(B)。(B)溶于过量 $\mathrm{NaOH}$ 溶液得到无色溶液(C)。将(B)溶于盐酸后蒸发、浓缩后又析出(A)。向(A)的稀盐酸溶液加入 $\mathrm{H_2S}$ 溶液生成橙色沉淀(D)。(D)与 $\mathrm{Na_2S_2}$ 可以发生氧化还原反应，反应产物之间作用得到无色溶液(E)。将(A)投于水中生成白色沉淀(F)。

试给出(A)、(B)、(C)、(D)、(E)和(F)所代表的物质的化学式，并用化学反应方程式表示各过程。

## 解答

- **(A)** — $\mathrm{SbCl_3}$
- **(B)** — $\mathrm{Sb(OH)_3}$
- **(C)** — $\mathrm{Na_3SbO_3}$
- **(D)** — $\mathrm{Sb_2S_3}$
- **(E)** — $\mathrm{Na_3SbS_4}$
- **(F)** — $\mathrm{SbOCl}$

各过程的化学反应方程式如下：

$$\mathrm{SbCl_3} + 3\mathrm{NaOH} = \mathrm{Sb(OH)_3}\downarrow + 3\mathrm{NaCl}$$

$$\mathrm{Sb(OH)_3} + 3\mathrm{NaOH} = \mathrm{Na_3SbO_3} + 3\mathrm{H_2O}$$

$$\mathrm{Sb(OH)_3} + 3\mathrm{HCl} = \mathrm{SbCl_3} + 3\mathrm{H_2O}$$

$$2\mathrm{SbCl_3} + 3\mathrm{H_2S} = \mathrm{Sb_2S_3}\downarrow + 6\mathrm{HCl}$$

$$\mathrm{Sb_2S_3} + 2\mathrm{Na_2S_2} = \mathrm{Sb_2S_5} + 2\mathrm{Na_2S}$$

$$\mathrm{Sb_2S_5} + 3\mathrm{Na_2S} = 2\mathrm{Na_3SbS_4}$$

$$\mathrm{SbCl_3} + \mathrm{H_2O} = \mathrm{SbOCl}\downarrow + 2\mathrm{HCl}$$
