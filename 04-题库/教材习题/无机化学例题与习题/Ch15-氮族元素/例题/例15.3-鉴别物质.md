# 例15.3 分别用三种方法鉴别下列各组物质

## 题目

(1) $\mathrm{NH_4NO_3}$ 和 $\mathrm{NH_4Cl}$

(2) $\mathrm{SbCl_3}$ 和 $\mathrm{BiCl_3}$

(3) $\mathrm{NaNO_3}$ 和 $\mathrm{NaPO_3}$

## 解答

**(1) $\mathrm{NH_4NO_3}$ 和 $\mathrm{NH_4Cl}$ 的鉴别**

**方法一**：向两种盐的溶液中加入 $\mathrm{AgNO_3}$ 溶液，有白色沉淀生成的是 $\mathrm{NH_4Cl}$，另一种是 $\mathrm{NH_4NO_3}$：
$$\mathrm{Ag^+} + \mathrm{Cl^-} = \mathrm{AgCl}\downarrow$$

**方法二**：向两种盐的溶液中分别加入酸性 $\mathrm{KMnO_4}$ 溶液，能使其褪色的是 $\mathrm{NH_4Cl}$，另一种是 $\mathrm{NH_4NO_3}$：
$$10\mathrm{Cl^-} + 2\mathrm{MnO_4^-} + 16\mathrm{H^+} = 2\mathrm{Mn^{2+}} + 5\mathrm{Cl_2}\uparrow + 8\mathrm{H_2O}$$

**方法三**：取少量两种盐的晶体分别装入两支试管中，加入 $\mathrm{FeSO_4}$，加水溶解后沿着试管壁加浓硫酸，在浓硫酸与上层溶液的界面处有棕色环生成的是 $\mathrm{NH_4NO_3}$，另一种是 $\mathrm{NH_4Cl}$：
$$\mathrm{NO_3^-} + 3\mathrm{Fe^{2+}} + 4\mathrm{H^+} = \mathrm{NO}\uparrow + 3\mathrm{Fe^{3+}} + 2\mathrm{H_2O}$$
$$\mathrm{NO} + \mathrm{Fe^{2+}} = \mathrm{Fe(NO)^{2+}}(\text{棕色})$$

**(2) $\mathrm{SbCl_3}$ 和 $\mathrm{BiCl_3}$ 的鉴别**

**方法一**：将两种盐溶于水，分别滴加 $\mathrm{NaOH}$ 溶液至过量，先有白色沉淀生成而后沉淀又溶解的是 $\mathrm{SbCl_3}$，生成的白色沉淀不溶于过量 $\mathrm{NaOH}$ 溶液的是 $\mathrm{BiCl_3}$：
$$\mathrm{Sb^{3+}} + 3\mathrm{OH^-} = \mathrm{Sb(OH)_3}\downarrow$$
$$\mathrm{Sb(OH)_3} + 3\mathrm{OH^-} = \mathrm{SbO_3^{3-}} + 3\mathrm{H_2O}$$
$$\mathrm{Bi^{3+}} + 3\mathrm{OH^-} = \mathrm{Bi(OH)_3}\downarrow$$

**方法二**：将两种盐溶于稀盐酸，分别加入溴水，能使溴水褪色的是 $\mathrm{SbCl_3}$，另一种是 $\mathrm{BiCl_3}$：
$$\mathrm{Sb^{3+}} + \mathrm{Br_2} = \mathrm{Sb^{5+}} + 2\mathrm{Br^-}$$

**方法三**：向两种盐的溶液中加入 $\mathrm{NaOH}$ 和 $\mathrm{NaClO}$ 溶液，微热，有土黄色沉淀生成的是 $\mathrm{BiCl_3}$，另一种是 $\mathrm{SbCl_3}$：
$$\mathrm{Bi^{3+}} + \mathrm{ClO^-} + 4\mathrm{OH^-} + \mathrm{Na^+} = \mathrm{NaBiO_3}\downarrow + 2\mathrm{H_2O} + \mathrm{Cl^-}$$

**(3) $\mathrm{NaNO_3}$ 和 $\mathrm{NaPO_3}$ 的鉴别**

**方法一**：向两种盐的溶液中加入 $\mathrm{AgNO_3}$ 溶液，有白色沉淀生成的是 $\mathrm{NaPO_3}$，另一种是 $\mathrm{NaNO_3}$：
$$\mathrm{Ag^+} + \mathrm{PO_3^-} = \mathrm{AgPO_3}\downarrow$$

**方法二**：分别将两种盐酸化后煮沸，偏磷酸盐 $\mathrm{PO_3^-}$ 转化为正磷酸盐 $\mathrm{PO_4^{3-}}$。再分别加入过量的 $(\mathrm{NH_4})_2\mathrm{MoO_4}$，有特征黄色沉淀磷钼酸铵生成的是 $\mathrm{NaPO_3}$，无此现象的是 $\mathrm{NaNO_3}$：
$$\mathrm{PO_4^{3-}} + 12\mathrm{MoO_4^{2-}} + 24\mathrm{H^+} + 3\mathrm{NH_4^+} = (\mathrm{NH_4})_3\mathrm{PMo_{12}O_{40}\cdot6H_2O}\downarrow + 6\mathrm{H_2O}$$

**方法三**：分别将两种盐的晶体加热，充分反应后加入浓硝酸，有棕色 $\mathrm{NO_2}$ 气体生成的是 $\mathrm{NaNO_3}$，另一种是 $\mathrm{NaPO_3}$：
$$\mathrm{NO_3^-} + \mathrm{NO_2^-} + 2\mathrm{H^+} = 2\mathrm{NO_2}\uparrow + \mathrm{H_2O}$$
