# 例15.9 推断物质化学式（一）

## 题目

无色钠盐晶体(A)溶于水后加入 $\mathrm{AgNO_3}$ 有浅黄色沉淀(B)生成。用 $\mathrm{NaOH}$ 溶液处理(B)，得到棕黑色沉淀(C)。(B)溶于硝酸并放出棕色气体(D)。(D)通入 $\mathrm{NaOH}$ 溶液后经蒸发、浓缩析出晶体(E)。(E)受热分解得无色气体(F)和(A)的粉末。

试给出(A)、(B)、(C)、(D)、(E)和(F)所代表的物质的化学式，并用化学反应方程式表示各过程。

## 解答

- **(A)** — $\mathrm{NaNO_2}$
- **(B)** — $\mathrm{AgNO_2}$
- **(C)** — $\mathrm{Ag_2O}$
- **(D)** — $\mathrm{NO_2}$
- **(E)** — $\mathrm{NaNO_2 + NaNO_3}$
- **(F)** — $\mathrm{O_2}$

各过程的化学反应方程式如下：

$$\mathrm{NaNO_2} + \mathrm{AgNO_3} = \mathrm{AgNO_2}\downarrow + \mathrm{NaNO_3}$$

$$2\mathrm{AgNO_2} + 2\mathrm{NaOH} = \mathrm{Ag_2O}\downarrow + 2\mathrm{NaNO_2} + \mathrm{H_2O}$$

$$2\mathrm{AgNO_2} + 2\mathrm{HNO_3} = 2\mathrm{AgNO_3} + \mathrm{NO_2}\uparrow + \mathrm{NO}\uparrow + \mathrm{H_2O}$$

$$2\mathrm{NO_2} + 2\mathrm{NaOH} = \mathrm{NaNO_3} + \mathrm{NaNO_2} + \mathrm{H_2O}$$

$$2\mathrm{NaNO_3} \xlongequal{\triangle} 2\mathrm{NaNO_2} + \mathrm{O_2}\uparrow$$
