# 例15.1 完成并配平下列化学反应方程式

## 题目

(1) $\mathrm{NH_3 + Mg\xlongequal{\triangle}}$

(2) $\mathrm{Mg_3N_2 + H_2O =}$

(3) $\mathrm{NH_3 + HgCl_2 =}$

(4) $\mathrm{MnO_4^- + HNO_2 + H^+ =}$

(5) $\mathrm{N_2H_4(aq) + HNO_2 =}$

(6) $\mathrm{As_2O_3 + Zn + HCl(aq) =}$

(7) $\mathrm{Cu_2SO_4 + PH_3 =}$

(8) $\mathrm{NCl_3 + H_2O =}$

(9) $\mathrm{P_4 + NaOH(热、浓) + H_2O =}$

## 解答

**(1)** $2\mathrm{NH_3} + 3\mathrm{Mg} \xlongequal{\triangle} \mathrm{Mg_3N_2} + 3\mathrm{H_2}$

**(2)** $\mathrm{Mg_3N_2} + 6\mathrm{H_2O} = 3\mathrm{Mg(OH)_2} + 2\mathrm{NH_3}\uparrow$

**(3)** $2\mathrm{NH_3} + \mathrm{HgCl_2} = \mathrm{Hg(NH_2)Cl}\downarrow + \mathrm{NH_4Cl}$

**(4)** $2\mathrm{MnO_4^-} + 5\mathrm{HNO_2} + \mathrm{H^+} = 5\mathrm{NO_3^-} + 2\mathrm{Mn^{2+}} + 3\mathrm{H_2O}$

**(5)** $\mathrm{N_2H_4(aq)} + \mathrm{HNO_2} = \mathrm{HN_3} + 2\mathrm{H_2O}$

**(6)** $\mathrm{As_2O_3} + 6\mathrm{Zn} + 12\mathrm{HCl(aq)} = 2\mathrm{AsH_3}\uparrow + 6\mathrm{ZnCl_2} + 3\mathrm{H_2O}$

**(7)** $3\mathrm{Cu_2SO_4} + 2\mathrm{PH_3} = 3\mathrm{H_2SO_4} + 2\mathrm{Cu_3P}\downarrow$

**(8)** $\mathrm{NCl_3} + 3\mathrm{H_2O} = \mathrm{NH_3} + 3\mathrm{HClO}$

**(9)** $\mathrm{P_4} + 3\mathrm{NaOH(热、浓)} + 3\mathrm{H_2O} = 3\mathrm{NaH_2PO_2} + \mathrm{PH_3}\uparrow$
