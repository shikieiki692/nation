# 例15.4 现有下列六种磷的含氧酸盐固体，试加以鉴别

## 题目

$\mathrm{Na_4P_2O_7}$、$\mathrm{NaPO_3}$、$\mathrm{Na_2HPO_4}$、$\mathrm{NaH_2PO_4}$、$\mathrm{NaH_2PO_2}$、$\mathrm{NaH_2PO_3}$

## 解答

向六种盐的水溶液中分别加入 $\mathrm{AgNO_3}$ 溶液：

**生成白色沉淀**的是 $\mathrm{Na_4P_2O_7}$ 和 $\mathrm{NaPO_3}$：
$$\mathrm{P_2O_7^{4-}} + 4\mathrm{Ag^+} = \mathrm{Ag_4P_2O_7}\downarrow(\text{白色})$$
$$\mathrm{PO_3^-} + \mathrm{Ag^+} = \mathrm{AgPO_3}\downarrow(\text{白色})$$

**生成黄色沉淀**的是 $\mathrm{Na_2HPO_4}$ 和 $\mathrm{NaH_2PO_4}$：
$$\mathrm{HPO_4^{2-}} + 3\mathrm{Ag^+} = \mathrm{Ag_3PO_4}\downarrow(\text{黄色}) + \mathrm{H^+}$$
$$\mathrm{H_2PO_4^-} + 3\mathrm{Ag^+} = \mathrm{Ag_3PO_4}\downarrow(\text{黄色}) + 2\mathrm{H^+}$$

**生成黑色沉淀**的是 $\mathrm{NaH_2PO_2}$ 和 $\mathrm{NaH_2PO_3}$：
$$\mathrm{H_2PO_2^-} + 4\mathrm{Ag^+} + 2\mathrm{H_2O} = 4\mathrm{Ag}\downarrow(\text{黑色}) + \mathrm{H_3PO_4} + 3\mathrm{H^+}$$
$$\mathrm{H_2PO_3^-} + 2\mathrm{Ag^+} + \mathrm{H_2O} = 2\mathrm{Ag}\downarrow(\text{黑色}) + \mathrm{H_3PO_4} + \mathrm{H^+}$$

进一步区分：

- $\mathrm{NaPO_3}$ 能使蛋白质溶液凝聚而 $\mathrm{Na_4P_2O_7}$ 不能，可将二者区分开。
- $\mathrm{Na_2HPO_4}$ 溶液为弱碱性而 $\mathrm{NaH_2PO_4}$ 溶液为弱酸性，可将二者区分开。
- $\mathrm{NaH_2PO_3}$ 为酸式盐，其溶液有缓冲作用，加入少量强酸或强碱但溶液 pH 基本不变；$\mathrm{NaH_2PO_2}$ 不是酸式盐，其溶液没有缓冲作用。由此可将二者区分开。
