# 例15.7 氮族元素氯化物的水解反应

## 题目

给出下列物质的水解反应方程式，并说明 $\mathrm{NCl_3}$ 水解产物与其他化合物的水解产物有何本质的区别，为什么？

$\mathrm{NCl_3}$、$\mathrm{PCl_3}$、$\mathrm{AsCl_3}$、$\mathrm{SbCl_3}$、$\mathrm{BiCl_3}$、$\mathrm{POCl_3}$

## 解答

$$\mathrm{NCl_3} + 3\mathrm{H_2O} = \mathrm{NH_3} + 3\mathrm{HClO}$$

$$\mathrm{PCl_3} + 3\mathrm{H_2O} = \mathrm{H_3PO_3} + 3\mathrm{HCl}$$

$$\mathrm{AsCl_3} + 3\mathrm{H_2O} = \mathrm{H_3AsO_3} + 3\mathrm{HCl}$$

$$\mathrm{SbCl_3} + \mathrm{H_2O} = \mathrm{SbOCl}\downarrow + 2\mathrm{HCl}$$

$$\mathrm{BiCl_3} + \mathrm{H_2O} = \mathrm{BiOCl}\downarrow + 2\mathrm{HCl}$$

$$\mathrm{POCl_3} + 3\mathrm{H_2O} = \mathrm{H_3PO_4} + 3\mathrm{HCl}$$

**本质区别**：$\mathrm{NCl_3}$ 水解产物既有酸（$\mathrm{HClO}$），又有碱（$\mathrm{NH_3}$）；$\mathrm{PCl_3}$ 和 $\mathrm{AsCl_3}$ 彻底水解产物为两种酸；$\mathrm{SbCl_3}$ 和 $\mathrm{BiCl_3}$ 水解产物为酸和碱式盐（$\mathrm{MOCl}$）。

**原因**：$\mathrm{NCl_3}$ 中 N 的孤电子对向 $\mathrm{H_2O}$ 中的 H 配位后释放出 $\mathrm{Cl^-}$，最终生成 $\mathrm{NH_3}$，释放出的 $\mathrm{Cl^-}$ 与 $\mathrm{H_2O}$ 中解离出的 $\mathrm{OH^-}$ 结合生成 $\mathrm{HClO}$。

$\mathrm{AsCl_3}$ 和 $\mathrm{PCl_3}$ 解离出的 $\mathrm{Cl^-}$ 与 $\mathrm{H_2O}$ 解离出的 $\mathrm{H^+}$ 结合生成 $\mathrm{HCl}$，$\mathrm{AsCl_3}$ 和 $\mathrm{PCl_3}$ 的中心与 $\mathrm{H_2O}$ 解离出的 $\mathrm{OH^-}$ 结合生成 $\mathrm{M(OH)_3}$（或写成 $\mathrm{H_3MO_3}$）。

$\mathrm{SbCl_3}$ 和 $\mathrm{BiCl_3}$ 水解与 $\mathrm{AsCl_3}$ 和 $\mathrm{PCl_3}$ 相似，但前两者水解不完全而生成碱式盐和 $\mathrm{HCl}$。
