# 13.49 用反应方程式表示下列转化过程。

## 题目

用反应方程式表示下列转化过程。

$$\mathrm{B} \rightarrow \mathrm{B(OH)}_3 \rightarrow \mathrm{B}_2\mathrm{O}_3 \rightarrow \mathrm{BF}_3 \rightarrow \mathrm{NaBF}_4 \rightarrow \mathrm{B(OH)}_3$$

## 参考答案
$$\mathrm{B} + 3\mathrm{HNO}_3(\text{浓}) \stackrel{\triangle}{=} \mathrm{B(OH)}_3 + 3\mathrm{NO}_2\uparrow$$

$$2\mathrm{B(OH)}_3 \stackrel{\triangle}{=} \mathrm{B}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{O}$$

$$\mathrm{B}_2\mathrm{O}_3 + 3\mathrm{CaF}_2 + 3\mathrm{H}_2\mathrm{SO}_4 = 2\mathrm{BF}_3\uparrow + 3\mathrm{CaSO}_4 + 3\mathrm{H}_2\mathrm{O}$$

$$\mathrm{BF}_3 + 4\mathrm{NaF} = \mathrm{NaBF}_4 + 3\mathrm{NaF}$$

即 $\mathrm{BF}_3 + \mathrm{NaF} = \mathrm{NaBF}_4$

$$\mathrm{NaBF}_4 + \mathrm{H}_2\mathrm{SO}_4(\text{浓}) + 5\mathrm{H}_2\mathrm{O} = \mathrm{NaHSO}_4 + \mathrm{B(OH)}_3 + 4\mathrm{HF}$$
