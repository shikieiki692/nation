# 第13章 硼族元素 — 完成并配平化学反应方程式

**13.21** 高温下单质硼与氮气反应。

**答案：** $2\mathrm{B} + \mathrm{N}_{2}\stackrel{\text{高温}}{=}2\mathrm{BN}$

---

**13.22** 无定形硼与热的浓硫酸反应。

**答案：** $2\mathrm{B} + 3\mathrm{H}_2\mathrm{SO}_4(\text{浓}) \xrightarrow{\triangle} 2\mathrm{B(OH)}_3 + 3\mathrm{SO}_2 \uparrow$

---

**13.23** 三碘化硼在灼热的金属钽丝上分解。

**答案：** $2\mathrm{BI}_3\xrightarrow[\mathrm{Ta}]{1000\mathrm{K}} 2\mathrm{B} + 3\mathrm{I}_2$

---

**13.24** 乙硼烷在空气中自燃。

**答案：** $\mathrm{B_2H_6 + 3O_2\xrightarrow{\text{自燃}} B_2O_3 + 3H_2O}$

---

**13.25** 硼氢化锂与水作用。

**答案：** $\mathrm{LiBH_4 + 2H_2O = LiBO_2 + 4H_2\uparrow}$

---

**13.26** 三氧化二硼遇到热的水蒸气。

**答案：** $3\mathrm{B}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{O}(\mathrm{g}) = 2\mathrm{B}_3\mathrm{O}_3(\mathrm{OH})_3(\mathrm{g})$

---

**13.27** 三氟化硼水解。

**答案：** $\mathrm{BF}_3 + 3\mathrm{H}_2\mathrm{O} = \mathrm{B(OH)}_3 + 3\mathrm{HF}$

$$\mathrm{BF}_{3} + \mathrm{HF} = \mathrm{H}[\mathrm{BF}_{4}]$$

---

**13.28** 赤热下无定形硼与水蒸气作用。

**答案：** $2\mathrm{B} + 6\mathrm{H}_2\mathrm{O(g)} = 2\mathrm{B(OH)}_3 + 3\mathrm{H}_2(\mathrm{g})$

---

**13.29** 三氧化二硼和氟化钙的混合物中加入浓硫酸。

**答案：** $3\mathrm{CaF}_2 + \mathrm{B}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{SO}_4(\text{浓}) \triangleq 2\mathrm{BF}_3\uparrow +3\mathrm{CaSO}_4 + 3\mathrm{H}_2\mathrm{O}$

---

**13.30** 向硼砂溶液中加稀硫酸。

**答案：** $\mathrm{Na_2B_4O_7 + H_2SO_4 + 5H_2O = 4B(OH)_3 + Na_2SO_4}$

---

**13.31** 将 $\mathrm{Na}_{2}\mathrm{CO}_{3}$ 和 $\mathrm{Al}_{2}\mathrm{O}_{3}$ 一起熔烧，然后将熔块打碎并投入水中。

**答案：** $\mathrm{Na_2CO_3 + Al_2O_3\xrightarrow{\triangle} 2NaAlO_2 + CO_2\uparrow}$

$$\mathrm{NaAlO}_{2} + 2 \mathrm{H}_{2}\mathrm{O} = \mathrm{Al(OH)}_{3} \downarrow + \mathrm{NaOH}$$

---

**13.32** 铝溶于热的 NaOH 溶液中。

**答案：** $2\mathrm{Al} + 2\mathrm{NaOH} + 2\mathrm{H}_2\mathrm{O}\stackrel{\triangle}{=} 2\mathrm{NaAlO}_2 + 3\mathrm{H}_2\uparrow$

---

**13.33** 向 $\mathrm{NaAlO_2}$ 溶液中加 $\mathrm{NH_4Cl}$。

**答案：** $\mathrm{NaAlO_2 + NH_4Cl + 2H_2O = Al(OH)_3\downarrow + NH_3\cdot H_2O + NaCl}$

---

**13.34** 金属镓与稀硫酸反应。

**答案：** $2\mathrm{Ga} + 3\mathrm{H}_2\mathrm{SO}_4(\text{稀}) = \mathrm{Ga_2(SO_4)_3 + 3H_2\uparrow}$

---

**13.35** 金属镓与浓硝酸反应。

**答案：** $\mathrm{Ga} + 6\mathrm{HNO}_3(\text{浓}) = \mathrm{Ga(NO_3)_3 + 3NO_2\uparrow + 3H_2O}$

---

**13.36** 向 TlOH 溶液中加 NaCl 溶液。

**答案：** $\mathrm{TlOH + NaCl = TlCl + NaOH}$

---

**13.37** 向 KI 溶液中加入 $\mathrm{TlCl}_3$。

**答案：** $\mathrm{TlCl}_3 + 3\mathrm{KI} = \mathrm{TlI} + \mathrm{I}_2 + 3\mathrm{KCl}$
