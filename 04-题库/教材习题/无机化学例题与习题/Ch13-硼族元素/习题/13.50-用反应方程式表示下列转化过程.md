# 13.50 用反应方程式表示下列转化过程。

## 题目

用反应方程式表示下列转化过程。

$$\mathrm{Al} \rightarrow \mathrm{Al}_2\mathrm{O}_3 \rightarrow \mathrm{NaAlO}_2 \rightarrow \mathrm{Al(OH)}_3 \rightarrow \mathrm{AlCl}_3 \rightarrow \mathrm{NaAlO}_2$$

## 参考答案

**

$$4\mathrm{Al} + 3\mathrm{O}_2 = 2\mathrm{Al}_2\mathrm{O}_3$$

$$\mathrm{Al}_2\mathrm{O}_3 + 2\mathrm{NaOH} \xlongequal{\triangle} 2\mathrm{NaAlO}_2 + \mathrm{H}_2\mathrm{O}$$

$$\mathrm{NaAlO}_2 + \mathrm{CO}_2 + 2\mathrm{H}_2\mathrm{O} = \mathrm{Al(OH)}_3\downarrow + \mathrm{NaHCO}_3$$

$$2\mathrm{Al(OH)}_3 + 3\mathrm{Cl}_2\mathrm{O} \xlongequal{\triangle} 2\mathrm{AlCl}_3 + 3\mathrm{H}_2\mathrm{O}$$

或：$2\mathrm{Al} + 3\mathrm{Cl}_2 \xlongequal{\triangle} 2\mathrm{AlCl}_3$

$$\mathrm{AlCl}_3 + 3\mathrm{NaOH}(\text{过量}) = \mathrm{NaAlO}_2 + 2\mathrm{H}_2\mathrm{O} + 3\mathrm{NaCl}$$
