# 第13章 硼族元素 — 简答与计算题

**13.44** 试用化学键理论解释下列事实。

(1) 三卤化硼的稳定性从 $\mathrm{BF}_3$ 到 $\mathrm{BI}_3$ 依次降低；

(2) 三卤化铝的稳定性从 $\mathrm{AlF}_3$ 到 $\mathrm{AlI}_3$ 依次降低；

(3) $\mathrm{BF}_3$ 为平面三角形结构，而 $\mathrm{NF}_3$ 为三角锥形结构。

**答案：**

(1) 三卤化硼的 B—X 键由 $\sigma$ 键和大 $\pi$ 键组成。从 $\mathrm{BF}_3$ 到 $\mathrm{BI}_3$，B 的 2p 轨道与卤素的 np 轨道能量差越来越大，轨道重叠效率越来越低，$\sigma$ 键和大 $\pi$ 键的强度都依次降低，故稳定性依次降低。

(2) 三卤化铝中 $\mathrm{AlF}_3$ 为离子晶体，Al³⁺ 与 F⁻ 之间以离子键结合，键能较大；从 $\mathrm{AlCl}_3$ 到 $\mathrm{AlI}_3$ 为分子晶体，Al 与卤素之间以共价键结合。从 Cl 到 I，原子半径增大，轨道重叠效率降低，共价键强度降低，故稳定性依次降低。

(3) $\mathrm{BF}_3$ 中 B 原子有 3 个价电子，与 3 个 F 原子形成 3 个 $\sigma$ 键，无孤电子对，B 为 sp² 杂化，分子为平面三角形。$\mathrm{NF}_3$ 中 N 原子有 5 个价电子，与 3 个 F 原子形成 3 个 $\sigma$ 键后还有 1 对孤电子对，N 为 sp³ 杂化，分子为三角锥形。

**13.45** 从 $\mathrm{BF}_3$ 的性质出发，解释为什么 $\mathrm{BF}_3$ 不与 $\mathrm{NH}_3$ 发生取代反应而生成 $\mathrm{BN}$，而是形成加合物 $\mathrm{F}_3\mathrm{B}\leftarrow\mathrm{NH}_3$。

**答案：** $\mathrm{BF}_3$ 中 B 原子为 sp² 杂化，有空的 2p 轨道，是典型的路易斯酸。$\mathrm{NH}_3$ 中 N 原子有一对孤电子对，是路易斯碱。两者通过配位键形成加合物 $\mathrm{F}_3\mathrm{B}\leftarrow\mathrm{NH}_3$，此时 B 变为 sp³ 杂化。

要发生取代反应生成 BN 需要断裂 B—F 键和 N—H 键，这需要很高的活化能，在通常条件下难以实现。形成加合物仅需孤电子对填入空轨道，反应容易进行。

**13.46** 解释下列事实。

(1) $\mathrm{B}_2\mathrm{H}_6$ 为缺电子化合物，但 $\mathrm{B}_2\mathrm{H}_6$ 中 B 的配位数为 4；

(2) $\mathrm{Al}_2\mathrm{Cl}_6$ 中 Al 的配位数为 4，而 $\mathrm{BCl}_3$ 不形成二聚体。

**答案：**

(1) $\mathrm{B}_2\mathrm{H}_6$ 是缺电子化合物，B 原子只有 3 个价电子。两个 B 原子各与两个端基 H 原子形成正常的 B—H $\sigma$ 键（共 4 个 B—H 键），剩余的 2 个电子和 2 个 B 原子的空轨道形成两个三中心两电子键（3c-2e 键），即 B—H—B 桥键。因此每个 B 原子周围有 4 个 H，配位数为 4。

(2) $\mathrm{Al}_2\mathrm{Cl}_6$ 中 Al 原子为 sp³ 杂化，通过两个 Cl 桥键形成四面体配位结构，使每个 Al 原子达到八电子稳定结构。$\mathrm{BCl}_3$ 中 B 原子半径小，3 个 Cl 原子之间的空间位阻使得桥键难以形成；同时 $\mathrm{BCl}_3$ 中 B 的 p 轨道与 Cl 的 p 轨道形成大 $\pi$ 键，平面结构已经是稳定构型，没有形成二聚体的驱动力。

**13.47** 解释下列事实。

(1) $\mathrm{B(OH)}_{3}$ 在水中的电离方式与一般酸不同；

(2) 加入甘油后可使硼酸的酸性增强；

(3) 硼砂溶液具有缓冲作用。

**答案：**

(1) 硼酸 B(OH)₃ 是典型的路易斯酸。它不是通过 O—H 键异裂电离给出 H⁺，而是 B 原子的空轨道接受水中 OH⁻ 的孤电子对，形成 [B(OH)₄]⁻，同时释放出 H⁺：

$$\mathrm{B(OH)}_3 + \mathrm{H}_2\mathrm{O} \rightleftharpoons [\mathrm{B(OH)}_4]^- + \mathrm{H}^+$$

(2) 加入甘油后，甘油中的多个 —OH 与 [B(OH)₄]⁻ 反应生成很稳定的硼酸酯（螯合效应），使平衡强烈右移，释放出更多的 H⁺，故酸性增强。

(3) 硼砂水解生成等物质的量的 H₃BO₃ 和 [B(OH)₄]⁻：

$$[\mathrm{B}_4\mathrm{O}_5(\mathrm{OH})_4]^{2-} + 5\mathrm{H}_2\mathrm{O} = 2\mathrm{B(OH)}_3 + 2[\mathrm{B(OH)}_4]^-$$

弱酸和其共轭碱浓度相近，构成缓冲体系，pH ≈ 9.24，稀释时 pH 变化不大。

**13.48** 比较下列各对化合物的热稳定性，并说明理由。

(1) $\mathrm{AlCl}_3$ 和 $\mathrm{TlCl}_3$；

(2) $\mathrm{Al(OH)}_3$ 和 $\mathrm{Tl(OH)}_3$；

(3) $\mathrm{Al}_2\mathrm{O}_3$ 和 $\mathrm{Tl}_2\mathrm{O}_3$。

**答案：**

(1) $\mathrm{AlCl}_3$ 热稳定性 > $\mathrm{TlCl}_3$。AlCl₃ 在 180°C 升华而不分解；TlCl₃ 在约 155°C 就分解为 TlCl 和 Cl₂。因为 Tl 位于第六周期，惰性电子对效应使 Tl(III) 不稳定，倾向于获得 2 个电子变为更稳定的 Tl(I)。

(2) $\mathrm{Al(OH)}_3$ 热稳定性 > $\mathrm{Tl(OH)}_3$。Al(OH)₃ 加热脱水变为 Al₂O₃；Tl(OH)₃ 在较低温度即分解。同样是惰性电子对效应使 Tl(III) 易被还原。

(3) $\mathrm{Al}_2\mathrm{O}_3$ 热稳定性 > $\mathrm{Tl}_2\mathrm{O}_3$。Al₂O₃ 非常稳定，熔点很高（2072°C）；Tl₂O₃ 加热分解为 Tl₂O 和 O₂。惰性电子对效应使 Tl(III) 的化合物热稳定性差。

**13.49** 用反应方程式表示下列转化过程。

$$\mathrm{B} \rightarrow \mathrm{B(OH)}_3 \rightarrow \mathrm{B}_2\mathrm{O}_3 \rightarrow \mathrm{BF}_3 \rightarrow \mathrm{NaBF}_4 \rightarrow \mathrm{B(OH)}_3$$

**答案：**

$$\mathrm{B} + 3\mathrm{HNO}_3(\text{浓}) \stackrel{\triangle}{=} \mathrm{B(OH)}_3 + 3\mathrm{NO}_2\uparrow$$

$$2\mathrm{B(OH)}_3 \stackrel{\triangle}{=} \mathrm{B}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{O}$$

$$\mathrm{B}_2\mathrm{O}_3 + 3\mathrm{CaF}_2 + 3\mathrm{H}_2\mathrm{SO}_4 = 2\mathrm{BF}_3\uparrow + 3\mathrm{CaSO}_4 + 3\mathrm{H}_2\mathrm{O}$$

$$\mathrm{BF}_3 + 4\mathrm{NaF} = \mathrm{NaBF}_4 + 3\mathrm{NaF}$$

即 $\mathrm{BF}_3 + \mathrm{NaF} = \mathrm{NaBF}_4$

$$\mathrm{NaBF}_4 + \mathrm{H}_2\mathrm{SO}_4(\text{浓}) + 5\mathrm{H}_2\mathrm{O} = \mathrm{NaHSO}_4 + \mathrm{B(OH)}_3 + 4\mathrm{HF}$$

**13.50** 用反应方程式表示下列转化过程。

$$\mathrm{Al} \rightarrow \mathrm{Al}_2\mathrm{O}_3 \rightarrow \mathrm{NaAlO}_2 \rightarrow \mathrm{Al(OH)}_3 \rightarrow \mathrm{AlCl}_3 \rightarrow \mathrm{NaAlO}_2$$

**答案：**

$$4\mathrm{Al} + 3\mathrm{O}_2 = 2\mathrm{Al}_2\mathrm{O}_3$$

$$\mathrm{Al}_2\mathrm{O}_3 + 2\mathrm{NaOH} \xlongequal{\triangle} 2\mathrm{NaAlO}_2 + \mathrm{H}_2\mathrm{O}$$

$$\mathrm{NaAlO}_2 + \mathrm{CO}_2 + 2\mathrm{H}_2\mathrm{O} = \mathrm{Al(OH)}_3\downarrow + \mathrm{NaHCO}_3$$

$$2\mathrm{Al(OH)}_3 + 3\mathrm{Cl}_2\mathrm{O} \xlongequal{\triangle} 2\mathrm{AlCl}_3 + 3\mathrm{H}_2\mathrm{O}$$

或：$2\mathrm{Al} + 3\mathrm{Cl}_2 \xlongequal{\triangle} 2\mathrm{AlCl}_3$

$$\mathrm{AlCl}_3 + 3\mathrm{NaOH}(\text{过量}) = \mathrm{NaAlO}_2 + 2\mathrm{H}_2\mathrm{O} + 3\mathrm{NaCl}$$

**13.51** $\mathrm{GaCl}_2$ 是逆磁性物质，试解释之。写出其结构式。

**答案：** $\mathrm{GaCl}_2$ 是逆磁性物质，说明其中没有未成对电子。Ga 的价电子构型为 4s²4p¹，若 $\mathrm{GaCl}_2$ 中 Ga 为 +2 价，应有 1 个未成对电子，显顺磁性。

实际上 $\mathrm{GaCl}_2$ 是 Ga(I) 和 Ga(III) 的混合价态化合物，结构式应写为 $\mathrm{Ga}^{\mathrm{I}}[\mathrm{Ga}^{\mathrm{III}}\mathrm{Cl}_4]$。其中 Ga(I) 的价电子构型为 4s²，无未成对电子；Ga(III) 的价电子构型为 3d¹⁰，也无未成对电子。两者均无未成对电子，故为逆磁性物质。

**13.52** 试比较硼酸与磷酸的酸性强弱，并从结构上解释。

**答案：** $\mathrm{H}_3\mathrm{BO}_3$ 的 $K_a^\ominus = 5.81 \times 10^{-10}$，$\mathrm{H}_3\mathrm{PO}_4$ 的 $K_{a1}^\ominus = 7.11 \times 10^{-3}$。磷酸的酸性远强于硼酸。

从结构上解释：$\mathrm{H}_3\mathrm{PO}_4$ 中 P 与 4 个 O 原子形成四面体结构（sp³ 杂化），有一个 P=O 双键。P=O 双键的强吸电子效应使 O—H 键极性增强，易于异裂电离给出 H⁺。

$\mathrm{H}_3\mathrm{BO}_3$ 中 B 为 sp² 杂化，形成平面三角形结构。B—O—H 中 O 的电负性大于 B，但由于 B 与 O 电负性相差不太大（2.0 vs 3.5），O—H 键的极化程度不高，不易发生 O—H 键异裂。硼酸的弱酸性来源于路易斯酸机制（接受 OH⁻），而非质子酸机制。

**13.53** 从 $\mathrm{In}$ 和 $\mathrm{Tl}$ 在化合物中的常见氧化态，解释惰性电子对效应。

**答案：** In 和 Tl 同属第 13 族。In 的常见氧化态为 +3，化合物如 $\mathrm{In}_2\mathrm{O}_3$、$\mathrm{InCl}_3$ 稳定。Tl 除了有 +3 氧化态外，+1 氧化态更稳定，化合物如 $\mathrm{Tl}_2\mathrm{O}$、$\mathrm{TlCl}$ 稳定，而 Tl(III) 化合物有较强氧化性。

这是因为 Tl 位于第六周期，其 6s² 电子受到相对论效应和较强的核吸引力影响，不易参与成键，称为"惰性电子对效应"。Tl 失去 2 个 6p 电子形成 Tl(III) 后，剩下的 6s² 电子对稳定性很高，倾向于保留，因此 Tl(III) 具有强氧化性，容易被还原为 Tl(I)。相比之下，In 位于第五周期，5s² 电子的惰性电子对效应较弱，+3 氧化态更稳定。

**13.54** 写出下列反应的方程式。

(1) 甲硼烷 $\mathrm{BH}_3$（假设存在）与过量水反应；

(2) 硼氮三甲 $\mathrm{(CH_3)_3N}$ 与 $\mathrm{BCl}_3$ 反应。

**答案：**

(1) $\mathrm{BH}_3 + 3\mathrm{H}_2\mathrm{O} = \mathrm{B(OH)}_3 + 3\mathrm{H}_2\uparrow$

实际上 $\mathrm{BH}_3$ 不存在游离态，以二聚体 $\mathrm{B}_2\mathrm{H}_6$ 形式存在：

$\mathrm{B}_2\mathrm{H}_6 + 6\mathrm{H}_2\mathrm{O} = 2\mathrm{B(OH)}_3 + 6\mathrm{H}_2\uparrow$

(2) $\mathrm{(CH_3)_3N + BCl_3 = (CH_3)_3N \rightarrow BCl_3$

两者通过 N 的孤电子对与 B 的空轨道形成配位键，生成 1:1 加合物。

**13.55** 完成并配平下列反应方程式。

(1) $\mathrm{In} + \mathrm{HCl}(\text{浓}) \rightarrow$

(2) $\mathrm{Tl}_2\mathrm{SO}_4 + \mathrm{BaCl}_2 \rightarrow$

(3) $\mathrm{Tl(OH)}_3 \xrightarrow{\triangle}$

(4) $\mathrm{Tl}_2\mathrm{O}_3 + \mathrm{HI} \rightarrow$

(5) $\mathrm{NaAlO}_2 + \mathrm{HCl}(\text{过量}) \rightarrow$

(6) $\mathrm{Ga(OH)}_3 + \mathrm{NaOH}(\text{过量}) \rightarrow$

**答案：**

(1) $2\mathrm{In} + 6\mathrm{HCl}(\text{浓}) = 2\mathrm{InCl}_3 + 3\mathrm{H}_2\uparrow$

(2) $\mathrm{Tl}_2\mathrm{SO}_4 + \mathrm{BaCl}_2 = 2\mathrm{TlCl}\downarrow + \mathrm{BaSO}_4\downarrow$

注意：TlCl 溶度积很小，会沉淀析出。

(3) $2\mathrm{Tl(OH)}_3 \xrightarrow{\triangle} \mathrm{Tl}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{O}$

(4) $\mathrm{Tl}_2\mathrm{O}_3 + 6\mathrm{HI} = 2\mathrm{TlI}\downarrow + \mathrm{I}_2 + 3\mathrm{H}_2\mathrm{O}$

Tl(III) 将 I⁻ 氧化为 I₂，自身被还原为 Tl(I)。

(5) $\mathrm{NaAlO}_2 + 4\mathrm{HCl}(\text{过量}) = \mathrm{AlCl}_3 + \mathrm{NaCl} + 2\mathrm{H}_2\mathrm{O}$

HCl 过量时，Al(OH)₃ 沉淀溶解生成 AlCl₃。

(6) $\mathrm{Ga(OH)}_3 + \mathrm{NaOH}(\text{过量}) = \mathrm{Na[Ga(OH)}_4]$

镓的氢氧化物具有两性，可溶于过量强碱生成四羟基合镓(III)酸盐。
