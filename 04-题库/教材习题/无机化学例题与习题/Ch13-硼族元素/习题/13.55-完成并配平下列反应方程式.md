# 13.55 完成并配平下列反应方程式。

## 题目

完成并配平下列反应方程式。

(1) $\mathrm{In} + \mathrm{HCl}(\text{浓}) \rightarrow$

(2) $\mathrm{Tl}_2\mathrm{SO}_4 + \mathrm{BaCl}_2 \rightarrow$

(3) $\mathrm{Tl(OH)}_3 \xrightarrow{\triangle}$

(4) $\mathrm{Tl}_2\mathrm{O}_3 + \mathrm{HI} \rightarrow$

(5) $\mathrm{NaAlO}_2 + \mathrm{HCl}(\text{过量}) \rightarrow$

(6) $\mathrm{Ga(OH)}_3 + \mathrm{NaOH}(\text{过量}) \rightarrow$

## 参考答案
(1) $2\mathrm{In} + 6\mathrm{HCl}(\text{浓}) = 2\mathrm{InCl}_3 + 3\mathrm{H}_2\uparrow$

(2) $\mathrm{Tl}_2\mathrm{SO}_4 + \mathrm{BaCl}_2 = 2\mathrm{TlCl}\downarrow + \mathrm{BaSO}_4\downarrow$

注意：TlCl 溶度积很小，会沉淀析出。

(3) $2\mathrm{Tl(OH)}_3 \xrightarrow{\triangle} \mathrm{Tl}_2\mathrm{O}_3 + 3\mathrm{H}_2\mathrm{O}$

(4) $\mathrm{Tl}_2\mathrm{O}_3 + 6\mathrm{HI} = 2\mathrm{TlI}\downarrow + \mathrm{I}_2 + 3\mathrm{H}_2\mathrm{O}$

Tl(III) 将 I⁻ 氧化为 I₂，自身被还原为 Tl(I)。

(5) $\mathrm{NaAlO}_2 + 4\mathrm{HCl}(\text{过量}) = \mathrm{AlCl}_3 + \mathrm{NaCl} + 2\mathrm{H}_2\mathrm{O}$

HCl 过量时，Al(OH)₃ 沉淀溶解生成 AlCl₃。

(6) $\mathrm{Ga(OH)}_3 + \mathrm{NaOH}(\text{过量}) = \mathrm{Na[Ga(OH)}_4]$

镓的氢氧化物具有两性，可溶于过量强碱生成四羟基合镓(III)酸盐。
