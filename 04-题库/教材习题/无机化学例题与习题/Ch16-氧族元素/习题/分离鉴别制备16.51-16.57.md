# 分离、鉴别与制备（16.51-16.57）

## 题目与答案

**16.51** 按如下要求，制备 $\mathrm{H_2S}$、$\mathrm{SO_2}$ 和 $\mathrm{SO_3}$，写出相关反应方程式。

**(1) S 氧化数不变的反应**

$\mathrm{H_2S}$ 用金属硫化物与非氧化性的稀酸反应，例如：
$$\mathrm{FeS} + 2\mathrm{HCl(稀)} = \mathrm{FeCl_2} + \mathrm{H_2S}\uparrow$$

$\mathrm{SO_2}$ 用 $\mathrm{Na_2SO_3}$ 与稀盐酸反应：
$$\mathrm{Na_2SO_3} + 2\mathrm{HCl} = 2\mathrm{NaCl} + \mathrm{SO_2}\uparrow + \mathrm{H_2O}$$

$\mathrm{SO_3}$ 用加热分解硫酸盐的方法：
$$\mathrm{CaSO_4} \xlongequal{\triangle} \mathrm{CaO} + \mathrm{SO_3}\uparrow$$

**(2) S 氧化数变化的反应**

$\mathrm{H_2S}$ 用 NaI 与浓硫酸反应：
$$8\mathrm{NaI} + 9\mathrm{H_2SO_4(浓)} = 4\mathrm{I_2} + 8\mathrm{NaHSO_4} + \mathrm{H_2S}\uparrow + 4\mathrm{H_2O}$$

$\mathrm{SO_2}$ ①金属单质与浓硫酸反应：
$$\mathrm{Zn} + 2\mathrm{H_2SO_4(浓)} = \mathrm{ZnSO_4} + \mathrm{SO_2}\uparrow + 2\mathrm{H_2O}$$

② 单质 S 或硫化物矿在空气中燃烧：
$$\mathrm{S} + \mathrm{O_2} \xlongequal{\text{燃烧}} \mathrm{SO_2}$$
$$4\mathrm{FeS_2} + 11\mathrm{O_2} \xlongequal{\text{燃烧}} 2\mathrm{Fe_2O_3} + 8\mathrm{SO_2}$$

$\mathrm{SO_3}$ 以 $\mathrm{V_2O_5}$ 为催化剂，用 $\mathrm{SO_2}$ 与 $\mathrm{O_2}$ 反应：
$$2\mathrm{SO_2} + \mathrm{O_2} \xlongequal[\triangle]{\mathrm{V_2O_5}} 2\mathrm{SO_3}$$

---

**16.52** 工业上以硫化钠、碳酸钠和二氧化硫为原料生产硫代硫酸钠，写出相关反应方程式。

将 $\mathrm{Na_2S}$ 和 $\mathrm{Na_2CO_3}$ 以 2:1 的物质的量比配成溶液，然后通入 $\mathrm{SO_2}$ 气体：
$$2\mathrm{Na_2S} + \mathrm{Na_2CO_3} + 4\mathrm{SO_2} = 3\mathrm{Na_2S_2O_3} + \mathrm{CO_2}$$

---

**16.53** 将硫黄粉、石灰与水混合，经煮沸、摇匀制得石硫合剂。试解释石硫合剂呈橙色至樱桃红色的原因，并写出相应的反应方程式。

将硫黄粉、石灰及水混合，煮沸制石硫合剂过程中发生如下反应：
$$\mathrm{CaO} + \mathrm{H_2O} = \mathrm{Ca(OH)_2}$$
$$3\mathrm{S} + 3\mathrm{Ca(OH)_2} = 2\mathrm{CaS} + \mathrm{CaSO_3} + 3\mathrm{H_2O}$$

过量的 S 与 CaS 进一步反应，生成多硫化物：
$$(x-1)\mathrm{S} + \mathrm{CaS} = \mathrm{CaS_x}(\text{橙色})$$

$\mathrm{CaS_x}$ 为橙色，并随 x 值升高显樱桃红色。

此外，过程中还发生以下反应：
$$\mathrm{S} + \mathrm{CaSO_3} = \mathrm{CaS_2O_3}$$

---

**16.54** $\mathrm{CS_2}$ 在过量 $\mathrm{O_2}$ 中燃烧，得到混合气体，设计方案分离出其中的 $\mathrm{SO_2}$。

燃烧反应为：
$$\mathrm{CS_2} + 3\mathrm{O_2} \xlongequal{\text{煅烧}} \mathrm{CO_2} + 2\mathrm{SO_2}$$

因为 $\mathrm{O_2}$ 过量，故得到的混合气体为 $\mathrm{SO_2}$、$\mathrm{CO_2}$ 和 $\mathrm{O_2}$。将混合气体用液氨冷却，$\mathrm{SO_2}$ 的沸点较高，先液化为液态，故可与 $\mathrm{CO_2}$ 和 $\mathrm{O_2}$ 分离。

或将反应后的混合气体通过 $\mathrm{NaHCO_3}$ 溶液，由于 $\mathrm{SO_2}$ 酸性比 $\mathrm{CO_2}$ 强，$\mathrm{SO_2}$ 可与 $\mathrm{NaHCO_3}$ 作用而除去：
$$2\mathrm{NaHCO_3} + \mathrm{SO_2} = \mathrm{Na_2SO_3} + 2\mathrm{CO_2} + \mathrm{H_2O}$$

---

**16.55** 用化学反应方程式表示物质的转化。

$$4\mathrm{FeS_2} + 11\mathrm{O_2} \xlongequal{\text{燃烧}} 2\mathrm{Fe_2O_3} + 8\mathrm{SO_2}$$

$$2\mathrm{SO_2(g)} + \mathrm{O_2(g)} \xrightarrow[\triangle]{\mathrm{V_2O_5}} 2\mathrm{SO_3}$$

$$\mathrm{SO_3} + 2\mathrm{KOH} = \mathrm{K_2SO_4} + \mathrm{H_2O}$$

$$\mathrm{K_2SO_4} + \mathrm{H_2SO_4} = 2\mathrm{KHSO_4}$$

$$2\mathrm{KHSO_4} \xlongequal{\text{电解}} \mathrm{K_2S_2O_8} + \mathrm{H_2}\uparrow$$

$$\mathrm{K_2S_2O_8} + 2\mathrm{H_2O} \xlongequal{\mathrm{H_2SO_4}} 2\mathrm{KHSO_4} + \mathrm{H_2O_2}$$

$$2\mathrm{SO_2(过量)} + \mathrm{Na_2CO_3} + \mathrm{H_2O} = 2\mathrm{NaHSO_3} + \mathrm{CO_2}$$

$$2\mathrm{NaHSO_3} + \mathrm{Zn} + \mathrm{H_2SO_3} = \mathrm{Na_2S_2O_4} + \mathrm{ZnSO_3} + 2\mathrm{H_2O}$$

$$\mathrm{NaHSO_3} + \mathrm{NaOH} = \mathrm{Na_2SO_3} + \mathrm{H_2O}$$

$$\mathrm{Na_2SO_3} + \mathrm{S} = \mathrm{Na_2S_2O_3}$$

**16.56** 某溶液中可能含 $\mathrm{Cl^-}$、$\mathrm{S^{2-}}$、$\mathrm{SO_3^{2-}}$、$\mathrm{S_2O_3^{2-}}$、$\mathrm{SO_4^{2-}}$，进行下列实验并产生如下的实验现象：

(1) 向一份未知液中加入过量 $\mathrm{AgNO_3}$ 溶液产生白色沉淀；

(2) 向另一份未知液中加入 $\mathrm{BaCl_2}$ 溶液也产生白色沉淀；

(3) 取第三份未知液，用 $\mathrm{H_2SO_4}$ 酸化后加入溴水，溴水不褪色。

判断哪几种离子存在？哪几种离子不存在？哪几种离子可能存在？

由实验(1)可知：溶液中不含 $\mathrm{S^{2-}}$、$\mathrm{S_2O_3^{2-}}$，因为 $\mathrm{Ag_2S}$ 为黑色沉淀，$\mathrm{Ag_2S_2O_3}$ 虽为白色沉淀，但其不稳定会分解，由白色转变为黑色的 $\mathrm{Ag_2S}$。

由实验(2)可知：溶液中应含有 $\mathrm{SO_4^{2-}}$。

由实验(3)酸化的溴水不褪色，说明溶液中不含 $\mathrm{S^{2-}}$、$\mathrm{S_2O_3^{2-}}$ 及 $\mathrm{SO_3^{2-}}$ 具有还原性的离子。

由此可得出结论：$\mathrm{SO_4^{2-}}$ 肯定存在，$\mathrm{S^{2-}}$、$\mathrm{S_2O_3^{2-}}$、$\mathrm{SO_3^{2-}}$ 肯定不存在，$\mathrm{Cl^-}$ 可能存在。

**16.57** 试设计方案分离下列各组离子（分离过程须用到硫的化合物）。

(1) $\mathrm{Ag^+, Ba^{2+}, Fe^{2+}}$

(2) $\mathrm{Al^{3+}, Zn^{2+}, Fe^{3+}, Cu^{2+}}$

（具体分离方案需结合流程图，此处给出关键反应）

(1) 向混合溶液中加入 $\mathrm{HCl}$，$\mathrm{Ag^+}$ 生成 $\mathrm{AgCl}$ 沉淀分离；再通入 $\mathrm{H_2S}$，$\mathrm{Fe^{2+}}$ 生成 $\mathrm{FeS}$ 沉淀分离；$\mathrm{Ba^{2+}}$ 留在溶液中。

(2) 向混合溶液中加入过量 $\mathrm{NaOH}$，$\mathrm{Al^{3+}}$ 生成 $\mathrm{AlO_2^-}$，$\mathrm{Zn^{2+}}$ 生成 $\mathrm{ZnO_2^{2-}}$，$\mathrm{Fe^{3+}}$ 生成 $\mathrm{Fe(OH)_3}$ 沉淀，$\mathrm{Cu^{2+}}$ 生成 $\mathrm{Cu(OH)_2}$ 沉淀。过滤分离后，向滤液中通入 $\mathrm{CO_2}$ 可分别沉淀 $\mathrm{Al(OH)_3}$ 和 $\mathrm{Zn(OH)_2}$。向沉淀中加入 $\mathrm{H_2S}$，$\mathrm{Cu(OH)_2}$ 转化为 $\mathrm{CuS}$ 沉淀，$\mathrm{Fe(OH)_3}$ 不反应，可分离。
