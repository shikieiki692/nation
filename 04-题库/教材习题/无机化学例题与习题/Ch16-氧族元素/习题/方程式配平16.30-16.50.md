# 完成并配平化学反应方程式（16.30-16.50）

## 题目与答案

**16.30** 过氧化钠与冷的稀硫酸作用。

$$\mathrm{Na_2O_2 + H_2SO_4 + 10H_2O = Na_2SO_4\cdot10H_2O + H_2O_2}$$

**16.31** 过氧化氢与氢碘酸反应。

$$\mathrm{H_2O_2 + 2I^- + 2H^+ = I_2 + 2H_2O}$$

**16.32** 电解硫酸氢铵溶液。

$$2\mathrm{NH_4HSO_4} \xrightarrow{\text{电解}} (\mathrm{NH_4)_2S_2O_8} + \mathrm{H_2}\uparrow$$

**16.33** 高温下三氧化硫与碘化钾反应。

$$\mathrm{SO_3} + 2\mathrm{KI} \xrightarrow{\text{高温}} \mathrm{K_2SO_3} + \mathrm{I_2}$$

**16.34** 亚硫酸与硫化氢作用。

$$\mathrm{H_2SO_3 + 2H_2S = 3S\downarrow + 3H_2O}$$

**16.35** 三氧化二铝与焦硫酸钾共熔。

$$\mathrm{Al_2O_3 + 3K_2S_2O_7 \xrightarrow{\text{共熔}} Al_2(SO_4)_3 + 3K_2SO_4}$$

**16.36** 无氧条件下锌粉还原亚硫酸氢钠和亚硫酸的混合溶液。

$$2\mathrm{NaHSO_3} + \mathrm{H_2SO_3} + \mathrm{Zn} = \mathrm{Na_2S_2O_4} + \mathrm{ZnSO_3} + 2\mathrm{H_2O}$$

**16.37** 硫化汞溶于硫化钠溶液。

$$\mathrm{HgS + Na_2S = Na_2[HgS_2]}$$

**16.38** 硫酸亚铁受热分解。

$$2\mathrm{FeSO_4} \xrightarrow{\triangle} \mathrm{Fe_2O_3} + \mathrm{SO_3}\uparrow + \mathrm{SO_2}\uparrow$$

**16.39** 氧化铁与焦硫酸钾共熔。

$$\mathrm{Fe_2O_3 + 3K_2S_2O_7 \xrightarrow{\text{共熔}} Fe_2(SO_4)_3 + 3K_2SO_4}$$

**16.40** 氯化亚铜溶解在硫代硫酸钠溶液中。

$$\mathrm{CuCl + 2Na_2S_2O_3 = Na_3[Cu(S_2O_3)_2] + NaCl}$$

**16.41** 过二硫酸钾加热分解。

$$2\mathrm{K_2S_2O_8} \xrightarrow{\triangle} 2\mathrm{K_2SO_4} + 2\mathrm{SO_3}\uparrow + \mathrm{O_2}\uparrow$$

**16.42** 亚硫酰氯水解。

$$\mathrm{SOCl_2 + H_2O = 2HCl + SO_2}\uparrow$$

**16.43** 过量的干燥氯化氢气体与三氧化硫反应。

$$\mathrm{SO_3 + HCl = HSO_3Cl}$$

**16.44** 将二氧化硒溶于水，然后通入二氧化硫气体。

$$\mathrm{SeO_2 + H_2O = H_2SeO_3}$$
$$\mathrm{H_2SeO_3 + 2SO_2 + H_2O = Se\downarrow + 2H_2SO_4}$$

**16.45** 中等浓度的硒酸与盐酸作用。

$$\mathrm{H_2SeO_4 + 2HCl = H_2SeO_3 + Cl_2}\uparrow + \mathrm{H_2O}$$

**16.46** 向 $\mathrm{Na_2S}$ 和 $\mathrm{Na_2SO_3}$ 混合溶液中加入稀酸。

$$2\mathrm{S^{2-}} + \mathrm{SO_3^{2-}} + 6\mathrm{H^+} = 3\mathrm{S}\downarrow + 3\mathrm{H_2O}$$

**16.47** 向 $\mathrm{Na_2S_2O_3}$ 溶液中加入碘水。

$$2\mathrm{Na_2S_2O_3} + \mathrm{I_2} = \mathrm{Na_2S_4O_6} + 2\mathrm{NaI}$$

**16.48** 硫代硫酸钠溶液加入氯水中。

$$\mathrm{S_2O_3^{2-}} + 4\mathrm{Cl_2} + 5\mathrm{H_2O} = 2\mathrm{SO_4^{2-}} + 8\mathrm{Cl^-} + 10\mathrm{H^+}$$

**16.49** 向 $\mathrm{Na_2S_2}$ 溶液中滴加盐酸。

$$\mathrm{Na_2S_2 + 2HCl = 2NaCl + S\downarrow + H_2S}$$

**16.50** 向 $[\mathrm{Ag(S_2O_3)_2}]^{3-}$ 的弱酸性溶液中通入硫化氢气体。

$$2[\mathrm{Ag(S_2O_3)_2}]^{3-} + \mathrm{H_2S} + 6\mathrm{H^+} = \mathrm{Ag_2S}\downarrow + 4\mathrm{S}\downarrow + 4\mathrm{SO_2} + 4\mathrm{H_2O}$$
