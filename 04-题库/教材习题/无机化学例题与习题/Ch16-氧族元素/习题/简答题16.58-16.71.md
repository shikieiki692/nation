# 简答题（16.58-16.71）

## 题目与答案

**16.58** 解释实验现象。

(1) 少量 $\mathrm{Na_2S_2O_3}$ 溶液和 $\mathrm{AgNO_3}$ 溶液反应生成白色沉淀，沉淀逐渐变黄至棕色，最后变成黑色。白色沉淀溶于过量 $\mathrm{Na_2S_2O_3}$ 溶液，而黑色沉淀不溶于过量 $\mathrm{Na_2S_2O_3}$ 溶液。

少量 $\mathrm{Na_2S_2O_3}$ 溶液和 $\mathrm{AgNO_3}$ 溶液反应生成白色的难溶盐 $\mathrm{Ag_2S_2O_3}$：
$$2\mathrm{Ag^+} + \mathrm{S_2O_3^{2-}} = \mathrm{Ag_2S_2O_3}\downarrow$$

$\mathrm{Ag_2S_2O_3}$ 不稳定，逐渐分解，转化为黑色的 $\mathrm{Ag_2S}$ 沉淀：
$$\mathrm{Ag_2S_2O_3} + \mathrm{H_2O} = \mathrm{Ag_2S} + \mathrm{H_2SO_4}$$

$\mathrm{Ag_2S_2O_3}$ 溶于过量 $\mathrm{Na_2S_2O_3}$ 溶液生成无色的配位化合物，但 $\mathrm{Ag_2S}$ 溶度积常数很小，不溶于过量 $\mathrm{Na_2S_2O_3}$ 溶液：
$$\mathrm{Ag_2S_2O_3} + 3\mathrm{S_2O_3^{2-}} = 2[\mathrm{Ag(S_2O_3)_2}]^{3-}$$

(2) 将 $\mathrm{H_2S}$ 气体通入 $\mathrm{MnSO_4}$ 溶液中不产生 $\mathrm{MnS}$ 沉淀，若 $\mathrm{MnSO_4}$ 溶液中含有一定量的氨水，再通入 $\mathrm{H_2S}$ 气体时即有 $\mathrm{MnS}$ 沉淀产生。

由于 MnS 的溶度积常数较大，$\mathrm{H_2S}$ 是很弱的二元酸，在水中解离出的 $\mathrm{S^{2-}}$ 浓度很小；同时沉淀过程有 $\mathrm{H^+}$ 生成，$\mathrm{H^+}$ 的存在更降低了 $\mathrm{H_2S}$ 的解离度，使得溶液中 $c(\mathrm{Mn^{2+}}) \cdot c(\mathrm{S^{2-}}) < K_{\mathrm{sp}}^{\ominus}(\mathrm{MnS})$，所以不会析出 MnS 沉淀。当溶液中含有一定量的氨水时，$\mathrm{NH_3}$ 与 $\mathrm{H^+}$ 结合，$c(\mathrm{H^+})$ 减小，$\mathrm{H_2S}$ 的解离度增大，使 $c(\mathrm{Mn^{2+}}) \cdot c(\mathrm{S^{2-}}) > K_{\mathrm{sp}}^{\ominus}(\mathrm{MnS})$，故会有 MnS 沉淀析出。

(3) 向稀盐酸和 $\mathrm{Na_2SO_3}$ 混合溶液中通入 $\mathrm{H_2S}$ 气体，溶液变浑浊；向稀盐酸和 $\mathrm{Na_2SO_4}$ 混合溶液中通入 $\mathrm{H_2S}$ 气体，溶液无变化。

稀盐酸和 $\mathrm{Na_2SO_3}$ 混合溶液相当于 $\mathrm{H_2SO_3}$ 稀溶液。$\mathrm{H_2SO_3}$ 有一定的氧化性，通入 $\mathrm{H_2S}$ 气体时发生氧化还原反应生成单质 S 沉淀，故溶液变浑浊：
$$\mathrm{H_2SO_3} + 2\mathrm{H_2S} = 3\mathrm{S}\downarrow + 3\mathrm{H_2O}$$

稀盐酸和 $\mathrm{Na_2SO_4}$ 混合溶液相当于 $\mathrm{H_2SO_4}$ 稀溶液。$\mathrm{H_2SO_4}$ 稀溶液氧化性不如 $\mathrm{H_2SO_3}$，不能将 $\mathrm{H_2S}$ 氧化，因此通入 $\mathrm{H_2S}$ 气体溶液无变化。

(4) 将少量酸性 $\mathrm{MnSO_4}$ 溶液与 $\mathrm{(NH_4)_2S_2O_8}$ 溶液混合后水浴加热，很快生成棕黑色沉淀；但在加热前加入几滴 $\mathrm{AgNO_3}$ 溶液，混合溶液逐渐变红。

$\mathrm{MnSO_4}$ 与 $\mathrm{(NH_4)_2S_2O_8}$ 反应生成难溶的 $\mathrm{MnO_2}$，由 $\mathrm{MnO_2}$ 生成 $\mathrm{MnO_4^-}$ 的速率较慢，因而只看到 $\mathrm{MnO_2}$ 生成。向反应体系中加入几滴 $\mathrm{AgNO_3}$ 溶液，由于 $\mathrm{Ag^+}$ 对 $\mathrm{MnSO_4}$ 与 $\mathrm{(NH_4)_2S_2O_8}$ 反应生成 $\mathrm{MnO_4^-}$ 有催化作用，则很快有 $\mathrm{MnO_4^-}$ 生成，溶液变红。

**16.59** 已知 $\mathrm{O_2F_2}$ 结构与 $\mathrm{H_2O_2}$ 相似，但 $\mathrm{O_2F_2}$ 中 O—O 键长 121 pm，$\mathrm{H_2O_2}$ 中 O—O 键长 148 pm，请给出 $\mathrm{O_2F_2}$ 的结构，并解释两个化合物中 O—O 键长不同的原因。

$\mathrm{O_2F_2}$ 分子结构为 F—O—O—F（与 $\mathrm{H_2O_2}$ 相似的锯齿形结构）。

由于 F 的电负性大于 O，则 O 周围的电子密度降低使 O 有一定的正电性，两个 O 原子对共用电子对的引力变大，因而 $\mathrm{O_2F_2}$ 中 O—O 键变短。

**16.60** 溶于水的 $\mathrm{O_2}$ 以氢键形式与水形成一水合物和二水合物，为什么 $\mathrm{O_2}$ 能与水形成氢键但溶解度却非常小？

氧的电负性大，$\mathrm{O_2}$ 分子中的两个氧原子互为强吸电子基团，因此氧的孤电子对给出电子能力很差，$\mathrm{O_2}$ 分子中的原子没有明显的负电荷。所以，$\mathrm{O_2}$ 分子的原子与水分子的氢静电引力很小，$\mathrm{O_2}$ 与水形成的氢键弱，使其在水中溶解度很小。

**16.61** 为什么 $\mathrm{SOCl_2}$ 既可作路易斯酸又可作路易斯碱？

$\mathrm{SOCl_2}$ 分子中的中心原子 S 有孤电子对，能给出电子，故可作路易斯碱。

分子的中心原子 S 有空的价层 d 轨道，又可以接受电子对，因此 $\mathrm{SOCl_2}$ 又可作电子接受体，为路易斯酸。

**16.62** 给出 $\mathrm{SOF_2}$、$\mathrm{SOCl_2}$、$\mathrm{SOBr_2}$ 分子中 S—O 键强度的变化规律，并解释原因。

分子中 S—O 键强度：$\mathrm{SOF_2 > SOCl_2 > SOBr_2}$

三个化合物的结构均为三角锥形，S 为中心原子，中心原子上有一孤电子对。

① X 电负性越大，吸引电子能力越强，则 S 原子周围的电子密度越低，硫的正电性越高，S 对 O 的极化作用越强，S—O 键共价成分越大，键越短，故 S—O 键越强。

② S—O 间存在 d-p 反馈 π 键，S 周围电子密度小，吸引氧的反馈电子能力越强，S—O 键越强。

**16.63** 为什么 $\mathrm{SF_6}$ 稳定、不易水解，而 $\mathrm{SF_4}$ 不稳定、又易水解？

$\mathrm{SF_6}$ 分子为正八面体结构，中心原子电子对全部用于成键，不易受到水分子的进攻。故对称性高、无孤电子对的 $\mathrm{SF_6}$ 分子非常稳定，也难以水解。

$\mathrm{SF_4}$ 分子为变形四面体结构，中心原子有一对孤电子对，易与水分子作用而水解；同时，对称性低的 $\mathrm{SF_4}$ 分子稳定性差，易分解。$\mathrm{SF_4}$ 歧化为 $\mathrm{SF_6}$ 和 S 是自发进行的（放热反应）。

**16.64** 试用价层电子对互斥理论判断 $\mathrm{SOF_2}$ 和 $\mathrm{SOCl_2}$ 的空间构型。说明在 O 原子和 S 原子之间的 d-pπ 配键是怎样形成的。试比较两者的 d-pπ 配键的强弱。

按照价层电子对互斥理论，$\mathrm{SOF_2}$ 和 $\mathrm{SOCl_2}$ 的中心价层电子对数均为 4，电子对空间构型为四面体，配体数为 3，故分子的空间构型为三角锥形。$\mathrm{SOF_2}$ 和 $\mathrm{SOCl_2}$ 分子中，中心 S 采取 $\mathrm{sp^3}$ 不等性杂化。

其中含有单电子的杂化轨道分别与两个卤素原子形成 σ 键。中心原子 S 有一个电子对向端基原子 O 空的 2p 轨道（经过重排形成的）配位，形成 σ 配键；同时中心原子 S 有空的 3d 轨道，可以接受端基原子 O 的 2p 轨道中的孤电子，形成反馈 π 键。这个反馈键，就对称性而言属于 π 键，且是 d 轨道与 p 轨道的重叠，就电子对的来源属于配位键，故称为 d-pπ 配键。

在 $\mathrm{SOX_2}$ 分子中，卤素 X 的电负性越大，吸引电子能力越强，使中心原子 S 更易接受端基原子 O 中孤电子的配入，故 $\mathrm{SOF_2}$ 分子中的 d-pπ 配键比 $\mathrm{SOCl_2}$ 分子中的强。

**16.65** 为什么不宜采用高温浓缩的办法制备 $\mathrm{NaHSO_3}$ 晶体？

$\mathrm{NaHSO_3}$ 受热易缩水，不宜采用高温浓缩的办法制备 $\mathrm{NaHSO_3}$：
$$2\mathrm{NaHSO_3} = \mathrm{Na_2S_2O_5} + \mathrm{H_2O}$$

**16.66** 某学生实验时发现 SnS 能溶于 $\mathrm{Na_2S}$ 溶液。你认为出现这种反常现象的原因是什么？如何证明你的判断是正确的？

可能是 $\mathrm{Na_2S}$ 溶液暴露在空气中时间过长，被氧化而有过硫化钠生成，过硫化钠能够将 SnS 氧化而溶解：
$$2\mathrm{Na_2S} + \mathrm{O_2} + 2\mathrm{H_2O} = 2\mathrm{S}\downarrow + 4\mathrm{NaOH}$$
$$\mathrm{Na_2S} + \mathrm{S} = \mathrm{Na_2S_2}$$
$$\mathrm{SnS} + \mathrm{Na_2S_2} = \mathrm{Na_2SnS_3}$$

将溶解 SnS 的溶液进行酸化，若溶液变浑浊且放出臭鸡蛋气味的 $\mathrm{H_2S}$ 气体，则说明判断是正确的：
$$\mathrm{Na_2SnS_3} + 2\mathrm{HCl} = \mathrm{SnS_2}\downarrow + \mathrm{H_2S}\uparrow + 2\mathrm{NaCl}$$
