# 例16.5 解释实验现象

## 题目

(1) 向 $\mathrm{Pb(NO_3)_2}$ 溶液中通入 $\mathrm{H_2S}$ 气体，有黑色沉淀生成，用 $\mathrm{H_2O_2}$ 处理该黑色沉淀，沉淀逐渐转变为白色。

(2) 室温下稀 $\mathrm{H_2O_2}$ 溶液分解较慢，但加入少量 KI 后分解速率加快。

(3) 向硫代硫酸钠溶液中滴加少量硝酸银溶液，生成少许白色沉淀又马上消失，向此溶液中加入少许盐酸，则产生黑色沉淀。

## 解答

**(1)** $\mathrm{Pb(NO_3)_2}$ 与 $\mathrm{H_2S}$ 反应生成黑色的 $\mathrm{PbS}$ 沉淀：
$$\mathrm{Pb(NO_3)_2} + \mathrm{H_2S} = \mathrm{PbS}\downarrow + 2\mathrm{HNO_3}$$

$\mathrm{H_2O_2}$ 具有较强的氧化性，可以将 PbS 氧化为白色的 $\mathrm{PbSO_4}$，故沉淀变白：
$$\mathrm{PbS} + 4\mathrm{H_2O_2} = \mathrm{PbSO_4} + 4\mathrm{H_2O}$$

**(2)** $\mathrm{H_2O_2}$ 分解速率与温度有关，温度越高，分解速率越快，故常温下分解较慢。

加入 KI 后，$\mathrm{H_2O_2}$ 首先将 $\mathrm{I^-}$ 氧化为 $\mathrm{I_2}$，后进一步氧化为 $\mathrm{IO_3^-}$，$E^{\ominus}(\mathrm{IO_3^-/I_2}) = 1.12\ \mathrm{V}$，介于 $\mathrm{H_2O_2}$ 作氧化型和还原型的 1.776～0.695 V 之间，可以催化 $\mathrm{H_2O_2}$ 的分解，具体反应如下：

$$\mathrm{H_2O_2} + 2\mathrm{I^-} + 2\mathrm{H^+} = \mathrm{I_2} + 2\mathrm{H_2O}$$

$$5\mathrm{H_2O_2} + \mathrm{I_2} = 2\mathrm{IO_3^-} + 2\mathrm{H^+} + 4\mathrm{H_2O}$$

$$5\mathrm{H_2O_2} + 2\mathrm{IO_3^-} + 2\mathrm{H^+} = \mathrm{I_2} + 5\mathrm{O_2}\uparrow + 6\mathrm{H_2O}$$

反应②和③循环进行，总的结果是 $\mathrm{H_2O_2}$ 分解：
$$2\mathrm{H_2O_2} = \mathrm{O_2}\uparrow + 2\mathrm{H_2O}$$

**(3)** 少量的硝酸银加入硫代硫酸钠溶液中先发生反应：
$$2\mathrm{Ag^+} + \mathrm{S_2O_3^{2-}} = \mathrm{Ag_2S_2O_3}\downarrow$$

生成白色沉淀 $\mathrm{Ag_2S_2O_3}$，溶于过量的硫代硫酸钠生成稳定的配离子，白色沉淀迅速溶解为无色溶液：
$$\mathrm{Ag_2S_2O_3} + 3\mathrm{S_2O_3^{2-}} = 2[\mathrm{Ag(S_2O_3)_2}]^{3-}$$

加入盐酸后，$[\mathrm{Ag(S_2O_3)_2}]^{3-}$ 遇酸分解，生成黑色的 $\mathrm{Ag_2S}$：
$$2[\mathrm{Ag(S_2O_3)_2}]^{3-} + 4\mathrm{H^+} = \mathrm{Ag_2S}\downarrow + \mathrm{SO_4^{2-}} + 3\mathrm{S}\downarrow + 3\mathrm{SO_2} + 2\mathrm{H_2O}$$
