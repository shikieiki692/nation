# 例16.1 完成并配平下列化学反应方程式

## 题目

(1) $\mathrm{O_3 + KI(aq) + H_2O =}$

(2) $\mathrm{HO_2^- + [Cr(OH)_4]^- =}$

(3) $\mathrm{H_2O_2 + Ag_2O =}$

(4) $\mathrm{PbS + O_3 =}$

(5) $\mathrm{MnO_4^- + H_2O_2 + H^+ =}$

(6) $\mathrm{HO_2^- + Mn(OH)_2}$

(7) $\mathrm{S + NaOH(aq) \stackrel{\triangle}{=}}$

(8) $\mathrm{S + H_2SO_4(浓)}$

(9) $\mathrm{H_2S(aq) + I_2 + H_2O =}$

## 解答

**(1)** $\mathrm{O_3 + 2KI(aq) + H_2O = I_2 + O_2 + 2KOH}$

**(2)** $3\mathrm{HO_2^-} + 2[\mathrm{Cr(OH)_4}]^- = 2\mathrm{CrO_4^{2-}} + \mathrm{OH^-} + 5\mathrm{H_2O}$

**(3)** $\mathrm{H_2O_2 + Ag_2O = 2Ag + O_2\uparrow + H_2O}$

**(4)** $\mathrm{PbS + 4O_3 = PbSO_4 + 4O_2}$

**(5)** $2\mathrm{MnO_4^-} + 5\mathrm{H_2O_2} + 6\mathrm{H^+} = 2\mathrm{Mn^{2+}} + 5\mathrm{O_2}\uparrow + 8\mathrm{H_2O}$

**(6)** $\mathrm{HO_2^- + Mn(OH)_2 = MnO_2 + OH^- + H_2O}$

**(7)** $3\mathrm{S} + 6\mathrm{NaOH(aq)} \xrightarrow{\triangle} 2\mathrm{Na_2S} + \mathrm{Na_2SO_3} + 3\mathrm{H_2O}$

**(8)** $\mathrm{S} + 2\mathrm{H_2SO_4(浓)} \xlongequal{\triangle} 3\mathrm{SO_2}\uparrow + 2\mathrm{H_2O}$

**(9)** $\mathrm{H_2S(aq)} + 4\mathrm{I_2} + 4\mathrm{H_2O} = \mathrm{H_2SO_4} + 8\mathrm{HI}$
