# 例16.8 推断白色固体化学式

## 题目

有一种能溶于水的白色固体，其水溶液进行下列实验而产生如下的实验现象：

(1) 用铂丝蘸少量液体在火焰上灼烧，产生黄色火焰。

(2) 它使酸化的 $\mathrm{KMnO_4}$ 溶液褪色而产生无色溶液，该溶液与 $\mathrm{BaCl_2}$ 溶液作用生成不溶于稀 $\mathrm{HNO_3}$ 的白色沉淀。

(3) 加入硫粉，并加热，硫溶解生成无色溶液，此溶液用盐酸酸化时产生乳白色或浅黄色沉淀；此溶液也能使 $\mathrm{KI_3}$ 溶液褪色，也能溶解 $\mathrm{AgCl}$ 或 $\mathrm{AgBr}$ 沉淀。

写出这一白色固体的化学式，并完成各步化学反应方程式。

## 解答

该白色固体的化学式为 **$\mathrm{Na_2SO_3}$**。

各步化学反应方程式如下：

$$5\mathrm{SO_3^{2-}} + 2\mathrm{MnO_4^-} + 6\mathrm{H^+} = 5\mathrm{SO_4^{2-}} + 2\mathrm{Mn^{2+}} + 3\mathrm{H_2O}$$

$$\mathrm{SO_4^{2-}} + \mathrm{Ba^{2+}} = \mathrm{BaSO_4}\downarrow$$

$$\mathrm{Na_2SO_3} + \mathrm{S} = \mathrm{Na_2S_2O_3}$$

$$\mathrm{Na_2S_2O_3} + 2\mathrm{HCl} = 2\mathrm{NaCl} + \mathrm{S}\downarrow + \mathrm{SO_2}\uparrow + \mathrm{H_2O}$$

$$2\mathrm{Na_2S_2O_3} + \mathrm{I_2} = \mathrm{Na_2S_4O_6} + 2\mathrm{NaI}$$

$$\mathrm{AgBr} + 2\mathrm{Na_2S_2O_3} = \mathrm{Na_3[Ag(S_2O_3)_2]} + \mathrm{NaBr}$$
