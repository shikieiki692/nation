# 例16.3 鉴别四种含硫溶液

## 题目

现有 4 瓶失落标签的无色溶液，分别为 $\mathrm{Na_2S}$、$\mathrm{Na_2SO_3}$、$\mathrm{Na_2S_2O_3}$ 和 $\mathrm{Na_2SO_4}$，试加以鉴别。

## 解答

用试管分别取少许 4 种无色溶液，向其中加入少许盐酸。

**有臭鸡蛋气味气体放出并能使醋酸铅试纸变黑**的是 $\mathrm{Na_2S}$ 溶液：
$$\mathrm{S^{2-}} + 2\mathrm{H^+} = \mathrm{H_2S}\uparrow$$
$$\mathrm{Pb(Ac)_2} + \mathrm{H_2S} = \mathrm{PbS}\downarrow(\text{黑色}) + 2\mathrm{HAc}$$

**有刺激性气体放出并有乳白色（或浅黄色）沉淀析出**的是 $\mathrm{Na_2S_2O_3}$ 溶液；气体可使湿润的品红试纸褪色可进一步确证生成气体为 $\mathrm{SO_2}$：
$$\mathrm{S_2O_3^{2-}} + 2\mathrm{H^+} = \mathrm{SO_2}\uparrow + \mathrm{S}\downarrow + \mathrm{H_2O}$$

**放出刺激性且能使 $\mathrm{KMnO_4}$ 溶液褪色（或使蓝色石蕊试纸变红）的气体，且无沉淀或浑浊现象**的是 $\mathrm{Na_2SO_3}$ 溶液：
$$\mathrm{SO_3^{2-}} + 2\mathrm{H^+} = \mathrm{SO_2}\uparrow + \mathrm{H_2O}$$
$$5\mathrm{SO_2} + 2\mathrm{MnO_4^-} + 2\mathrm{H_2O} = 5\mathrm{SO_4^{2-}} + 2\mathrm{Mn^{2+}} + 4\mathrm{H^+}$$

**无反应现象**的是 $\mathrm{Na_2SO_4}$ 溶液，再加入 $\mathrm{BaCl_2}$ 溶液有不溶于硝酸的白色沉淀析出则可确证：
$$\mathrm{Ba^{2+}} + \mathrm{SO_4^{2-}} = \mathrm{BaSO_4}\downarrow(\text{白色})$$
