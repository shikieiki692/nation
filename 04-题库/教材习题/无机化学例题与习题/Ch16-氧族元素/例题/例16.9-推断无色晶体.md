# 例16.9 推断无色晶体化学式

## 题目

无色晶体(A)易溶于水。(A)的溶液与酸性 KI 溶液作用溶液变黄，说明有(B)生成。(A)的溶液煮沸一段时间后加入 $\mathrm{BaCl_2}$ 溶液有白色沉淀(C)生成，(C)不溶于强酸。(A)的溶液与 $\mathrm{MnSO_4}$ 混合后加稀硝酸和几滴 $\mathrm{AgNO_3}$ 溶液，加热，溶液变红，说明有(D)生成。(A)溶液与 KOH 混合后加热，有气体(E)放出。气体(E)通入 $\mathrm{AgNO_3}$ 溶液则有棕黑色沉淀(F)生成，(E)通入过量则沉淀溶解为无色溶液。

试给出(A)、(B)、(C)、(D)、(E)和(F)所代表的物质的化学式，并用化学反应方程式表示各过程。

## 解答

- **(A)** — $\mathrm{(NH_4)_2S_2O_8}$
- **(B)** — $\mathrm{I_2}$ 或 $\mathrm{I_3^-}$
- **(C)** — $\mathrm{BaSO_4}$
- **(D)** — $\mathrm{MnO_4^-}$
- **(E)** — $\mathrm{NH_3}$
- **(F)** — $\mathrm{Ag_2O}$

各过程的化学反应方程式如下：

$$\mathrm{(NH_4)_2S_2O_8} + 2\mathrm{KI} = \mathrm{(NH_4)_2SO_4} + \mathrm{K_2SO_4} + \mathrm{I_2}$$

$$2\mathrm{(NH_4)_2S_2O_8} + 2\mathrm{H_2O} \stackrel{\triangle}{=} 4\mathrm{NH_4HSO_4} + \mathrm{O_2}\uparrow$$

$$\mathrm{NH_4HSO_4} + \mathrm{BaCl_2} = \mathrm{BaSO_4}\downarrow + \mathrm{NH_4Cl} + \mathrm{HCl}$$

$$5\mathrm{S_2O_8^{2-}} + 2\mathrm{Mn^{2+}} + 8\mathrm{H_2O} \xlongequal[\triangle]{\mathrm{Ag^+}} 2\mathrm{MnO_4^-} + 10\mathrm{HSO_4^-} + 6\mathrm{H^+}$$

$$\mathrm{(NH_4)_2S_2O_8} + 2\mathrm{KOH} = 2\mathrm{NH_3}\uparrow + \mathrm{K_2S_2O_8} + 2\mathrm{H_2O}$$

$$2\mathrm{NH_3} + 2\mathrm{Ag^+} + \mathrm{H_2O} = \mathrm{Ag_2O}\downarrow + 2\mathrm{NH_4^+}$$

$$\mathrm{Ag_2O} + 2\mathrm{NH_3} + 2\mathrm{NH_4^+} = 2[\mathrm{Ag(NH_3)_2}]^+ + \mathrm{H_2O}$$
