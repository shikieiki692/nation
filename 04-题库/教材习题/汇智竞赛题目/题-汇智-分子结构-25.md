# 题-汇智-分子结构-25

> [!info] 2026-08-25 忠实重录：本题干与答案逐字转录自汇智教师版题库（此前为同考点自编替换题，已替换；教师版原版式将小问置于解析区内，现归位为题目）。

## 题目

氮氧化物是大气化学的主要研究对象之一。内燃机中的高温促使空气中的氮气与氧气发生的化合反应以及工厂排放的光化学烟雾，是大气中氮氧化物的两大来源。在平流层，氮氧化物对于维持能够吸收紫外线的臭氧浓度稳定的光化学分解臭氧的反应有推动作用。下文将描述氮氧化物的一些化学性质。

氮氧化物 A 是无色顺磁性气体，能和过量氧气反应。将反应后的混合物通入 -120℃ 容器中，气体凝华为无色固体 B。将 2.00g B 放入 1.00L 真空容器中，可生成红棕色气体。反应体系在不同温度下达到平衡时的压强如下：25.0℃，压强 0.653 atm、50.0℃，压强 0.838 atm。

25-1 写出化合物 A 和 B 的化学式。

25-2 写出第二步 B 生成红棕色气体的反应方程式。计算该反应在热力学标况下的焓变和熵变。假设温度和压强对反应的焓变、熵变影响可以忽略不计。

化合物 B，与氟气反应可生成一无色气体 C，C 与三氟化硼反应可生成无色固体 D。将 1.000g D 溶于水，以酚酞作为指示剂，用 $0.5000\ \mathrm{mol\cdot L^{-1}}$ NaOH 滴定至终点，耗 NaOH 溶液 30.12 mL。

25-3 写出 C 和 D 的路易斯结构式，以及 D 与 NaOH 中和滴定得到的最终产物的化学式。

25-4 写出 A 与 $\mathrm{ClO_2}$ 反应方程式。

25-5 D 与过量硝基苯反应主要生成有机产物 E，写出 E 的结构式。

## 参考答案

25-1 氮氧化物 A 是无色顺磁性气体，所以 A 是 NO；NO 与 $\mathrm{O_2}$ 反应生成 $\mathrm{NO_2}$，$\mathrm{NO_2}$ 能二聚成 $\mathrm{N_2O_4}$，所以 B 是 $\mathrm{N_2O_4}$。

$$\Delta \mathrm{S}^{0} = +177\ \mathrm{J\cdot mol^{-1}}$$

$$\ln(K) = -\left(\Delta H^{0}/RT\right) + \left(\Delta S^{0}/R\right)$$

25-3 $\mathrm{N_2O_4}$ 受热生成 $\mathrm{NO_2}$，$\mathrm{F_2}$ 受热产生 $\mathrm{F}$；二者耦合成 $\mathrm{FNO_2}$，所以 C 是 $\mathrm{FNO_2}$；$\mathrm{FNO_2}$ 与 $\mathrm{BF_3}$ 发生路易斯酸碱反应生成 $[\mathrm{NO_2}][\mathrm{BF_4}]$，所以 D 是 $[\mathrm{NO_2}][\mathrm{BF_4}]$。路易斯结构式如下：

$$\left[ \begin{array}{c} \ddot{\mathrm{O}} = \stackrel{\oplus}{\mathrm{N}} = \ddot{\mathrm{O}} \\ \ddots \end{array} \right] \left[ \begin{array}{c} \vdots \stackrel{\ddots}{\mathrm{F}}: \\ \vdots \stackrel{\ddots}{\mathrm{F}} \stackrel{\ominus}{\mathrm{B}}: \\ \vdots \stackrel{\ddots}{\mathrm{F}}: \end{array} \stackrel{\ddots}{\mathrm{F}}: \right]$$

$[\mathrm{NO_2}][\mathrm{BF_4}]$ 与 NaOH 反应：$[\mathrm{NO_2}][\mathrm{BF_4}] + 2\mathrm{NaOH} = \mathrm{NaNO_3} + \mathrm{NaBF_4} + \mathrm{H_2O}$

25-4 NO 和 $\mathrm{ClO_2}$ 都有成单电子，反应 $\mathrm{NO + ClO_2 = ON\!-\!ClO_2}$。
