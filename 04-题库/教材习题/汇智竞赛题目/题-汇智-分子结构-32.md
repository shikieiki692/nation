# 题-汇智-分子结构-32


> [!info] 2026-08-25 忠实重录：本题干与答案逐字转录自汇智教师版题库（此前为同考点自编替换题，已替换）。

## 题目

现已合成出一种碳、氮两种元素组成的共价化合物 A，A 中氮元素质量分数为 0.8235。该分子是平面型分子，碳原子处于相同环境中，有一个三次旋转轴。20.415 g A 光解，生成 B 并放出 7.340 L 气体（标准状态），继续光解 B，生成 C，C 有两种同分异构体。C 再光解，生成 D 并放出气体。D 中含氮元素质量分数为 0.6087。D 是石墨型结构 E 的单体。

32-1 试画出 A 的结构式，标出结构式中非零 $Q_F$。

32-2 试画出 B 的 Lewis 结构式。

32-3 试画出 C 的两种异构体的共振结构式，标出式中非零 $Q_F$。

32-4 写出生成 D 的反应方程式，并画出 D 的结构式，指出结构式中原子的杂化类型（端基原子除外）以及化学键型。

32-5 试写出一种合成 E 方法的化学反应方程式，并画出 E 的一种结构式。

## 参考答案

32-1 A 由碳、氮两种元素组成，由质量分数可以计算出 $n(\mathrm{C}):n(\mathrm{N}) = 1:4$。因此 A 的分子式为 $(\mathrm{CN_4})_n$。因 N 原子较多，推测可能存在叠氮 $-\mathrm{N_3}$ 基团。最简式中还存在 $\mathrm{CN}$。又因为 A 为平面分子，且存在 $C_3$ 轴，即旋转 $120^\circ$ 能完全重合。因此在 $n=3$ 的情况下，$\mathrm{C_3N_{12}}$ 类似于均三嗪环（或苯环），在平面六元环的三个碳原子上各连一个叠氮基团 $-\mathrm{N_3}$，符合题意。

32-2 由于存在叠氮基团 $-\mathrm{N_3}$，受热或光解时能够分解产生 $\mathrm{N_2}$。结合题中 A 光解产生 B 的相关数据证实了这一点。A 的结构式与 B 的路易斯结构式如下：

![[18d38aaabf92886a4f3e6cbe71119b7e24e51e770210abd6151c17d77d2d2839.jpg]]

32-3 继续光解 B，实际上是破坏了均三嗪环的三聚，即三聚解离，变成了 $\mathrm{CN_2}$。根据路易斯电子理论可得：$:\mathrm{N \equiv C - \ddot{N} - \ddot{N} - C \equiv N:}$。根据形式电荷 $Q_F$ 的计算方法，可以写为：
$$^{⊖}:\mathrm{C \equiv N - \overset{\oplus}{N} - \ddot{N} - \overset{\oplus}{N} - N \equiv N:} \longleftrightarrow \overset{⊖}{:\mathrm{C=N=N^-}}$$

32-4 C 为 $\mathrm{CN_2}$，继续受热分解产生的气体只能是 $\mathrm{N_2}$，再结合 D 中含氮元素质量分数为 0.6087，计算得 D 为 $\mathrm{C_3N_4}$。因此生成 D 的化学方程式为：
$$3\mathrm{CN_2} = \mathrm{C_3N_4} + \mathrm{N_2} \quad \text{或} \quad 3[\mathrm{NCN}] = \mathrm{C_3N_4} + \mathrm{N_2}$$

所有 C 原子为 $\mathrm{sp}$ 杂化，2 个端基 N 原子为 $\mathrm{sp}$ 杂化，中间 2 个 N 原子为 $\mathrm{sp}$ 杂化。化学键有原子之间的 6 个 $\sigma$ 键，端基 N 原子与连接 C 原子之间的 $\pi$ 键和 2 个四中心四电子大 $\Pi_4^4$ 键。成键情况表示如下：
