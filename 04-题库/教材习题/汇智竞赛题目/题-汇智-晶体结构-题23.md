# 题-汇智-晶体结构·题23

X射线衍射实验表明，合金Cr-Al晶体（有序）属四方晶系，呈层型结构，堆积方式为…AbaBabAbaBabA…。

- 23-1 确定该合金的化学式。
- 23-2 画出该有序合金的四方晶胞；写出晶胞中原子的分数坐标。
- 23-3 写出该合金的密度表达式。
- 23-4 如果升高温度使Al、Cr原子无序排列，则所得晶胞与下面哪种晶体的晶胞相似？（NaCl、CsCl、闪锌矿、萤石、金刚石、石墨、干冰、金红石、钙钛矿、钾、镁、铜）

---

## 参考答案
23-1 Cr与Al的原子个数比为2:1，化学式：Cr₂Al。

23-2 分数坐标: ①Al (0, 0, 0)、(1/2, 1/2, 1/2) Cr(0, 0, 1/3)、(0, 0, 2/3)、(1/2, 1/2, 1/6)、(1/2, 1/2, 5/6)

23-3 $\rho=(4M_{Cr}+2M_{Al})/N_Aa^2c$

23-4 钾（体心立方）
