**4.4-1** 解释为什么以上三个催化剂中只有 A 能够催化反应。

**4.4-2** 进一步研究发现，exo-降冰片醇和 2,4-二硝基苯甲酸在该催化反应条件下所形成的产物仍为 exo 构型（如左图）。画出该反应历程关键中间体的结构简式，并解释产物构型保持的原因。

![[db9d688a7d5dd9b23c7ce1c5e6d4d7eb89b1b6b810a04b47079b51bec85fae21.jpg]]

**4.4-3** 研究人员报道了下列反应：

![[58a8ade2a2e6b556aed71492ec6990458c29111399d1786310abc10241325f3b.jpg]]

为了探究该反应的历程，研究人员进行了如下实验：

1. 在 1h 停止上述反应（其余条件相同），分离得到产物 A（分子式 ${ \sf C } _ { 1 1 } { \sf H } _ { 1 0 } 0 )$ ）与产物 B（分子式 $\mathsf { C } _ { 2 1 } \mathsf { H } _ { 2 5 } \mathsf { N } _ { 2 } \mathsf { O } _ { 8 } \mathsf { P } \mathsf { S } )$ ）；
2. 产物 A 与 1.5 倍量的化合物 2 进行上述反应（不加入原料 1，其余条件相同），15h 后得到产物 3；而 B 在相同条件下不能转化为 3；
3. 化合物 2 与 5 倍量的碱在室温下反应（以未经干燥处理的二氯甲烷为溶剂），5min 后生成一不稳定化合物 C（分子量为 244.22）。C 继续在室温下反应，30min 后完全分解。减压浓缩后，只检测到一种化合物 D，其分子量为 202.18。
4. 在 2 中加入水和碱，得到两分子甲醛。

依据以上实验结果，回答以下问题：

**4.4-3-1** 画出化合物 A、B、C 以及 D 的结构简式。
**4.4-3-2** 除了 D 以外，C 的分解产物还有什么？
**4.4-3-3** 解释在实验二中 B 为什么不能转化成 3。

## 参考答案

（自原书 OCR 提取）

**4.4-1** 看书。（原书此处未展开文字解析）

**4.4-2** 经历非经典碳正离子——降冰片正离子（结构见原书图），因此产物构型保持。

**4.4-3** 重要提示：底物 2 在碱作用下发生分子内亲核取代之后，会发生逆 2+2 环加成形成甲醛和亚胺，亚胺也会水解形成甲醛，所以 2 就是一个甲醛前体。

**4.4-3-1** 化合物 A-D 的结构简式见原书图。
**4.4-3-2** 甲醛。
**4.4-3-3** 氨甲基取代的磷酸酯 B 无法通过四元环消除形成 α,β-不饱和酮 A。
