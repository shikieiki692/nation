# 题-206-北斗40-2017BST7押题二-06-聚氨酯分子量测定

> 来源：北斗学友40套全真模拟 · 2017年 BST7/押题营（二）第6题（7分）｜难度：4｜教学层级：竞赛

## 题目

高分子由于分子量不均及分子量较大，因此其分子量难以准确测定。目前常用的测定高分子分子量的方法包括凝胶渗透色谱、核磁、端基滴定等。某次合成得到了一个结构如图的高分子化合物，该分子可以分成三个部分，两边是 PEG 链，中间是聚氨酯。

![[7b489114ab4e3e772f1f0d918d32dadf728499e2fb202c42c18d12b02132e228.jpg]]

**6-1**（4分）请给出中间聚氨酯的合成单体，要求合成效率最大化。

**6-2**（3分）已知 PEG 链上的亚甲基 H 化学位移是 3.66，聚氨酯中氧邻位 H 化学位移是 4.15，这两个 H 的峰面积比为 6:5，而 m＝60，请计算分子量。

### 答案

**6-1**

单体为 2,4-甲苯二异氰酸酯（TDI，OCN—C₆H₃(CH₃)—NCO）与 1,5-戊二醇（HO—(CH₂)₅—OH），加成聚合无小分子副产物、原子利用率 100%：

![[d59e64d006ac7384b71bdd38aa5a42f583edda27433060020945741ffa66d7a4.jpg]]

**6-2**

聚氨酯重复单元中二醇的 —OCH₂—（δ 4.15，4n 个 H）与 TDI 环上甲基（或其他定量 H），PEG 的 —CH₂CH₂O—（δ 3.66，4m 个 H）。按原书口径：

$$\frac{4m\times2}{4n} = \frac{6}{5} \quad\Rightarrow\quad n = 100$$（1分）

$$M = 100\times278 + 44\times60\times2 + 176 + 17\times2 = 33290$$（2分）

（278 为 TDI＋戊二醇重复单元量，44 为 EO 单元量。）
