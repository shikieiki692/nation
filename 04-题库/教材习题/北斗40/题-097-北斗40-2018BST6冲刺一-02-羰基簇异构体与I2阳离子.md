# 题-097-北斗40-2018BST6冲刺一-02-羰基簇异构体与I2阳离子

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（一）第2题（10分）｜难度：4｜教学层级：竞赛

## 题目

**2-1** 研究发现，Co₂(CO)₈ 加热后可以得到两种同分异构体 A 和 B。其中 A 为四面体结构，B 的结构与氮气分子有类似性。请给出 A 和 B 的结构。（4分）

**2-2** 利用不同的金属簇合物可以形成一系列结构多样的 MOF 材料。请给出以下簇合物单体的结构，注意 C 中配体甲基在邻位、羧基在对位：（4分）

C：CuCl₂(NC₆H₆CO₂)₂²⁻　　D：CoCl₂(p-NC₅H₄CO₂)₄⁴⁻

**2-3** 研究发现，如果将碘溶于发烟硫酸中，可以得到一种蓝色的溶液，请分析产生颜色的原因。（2分）

### 答案

**2-1**

A（T_d，四面体 Co₄ 核，12 个端式 CO、无桥羰基）：

![[0b322b12c45ded3721c2ac585ca07cce171794769c9427a3e71fa8095529fd74.jpg]]

B（C₃v，四面体 Co₄ 核、3 个 μ₂ 桥 CO——类 N₂ 的 D∞h 对称性对应其 3 桥 CO 排布）：

![[98b136d341cbbac33942468704a51bf34f5717f988832ec0d2a4f3b626123499.jpg]]

（即 Co₄(CO)₁₂ 的两种经典异构体；原书答案行首「D」「c」为选项编号残留。）

**2-2**

C：CuCl₂(2-甲基烟酸根)₂²⁻（甲基邻位、羧基对位）：

![[eba1e183b9cf7bc0a8da5040a496ef54dbf67f2fe3545d365ca3a6c4be65511d.jpg]]

D：CoCl₂(异烟酸根)₄⁴⁻（4 个对位羧基吡啶配体，轴向 2 个 Cl）：

![[1faa135265459c6ddfcb15319b3f787d68f8850b2f5cd0f55eb214ca327db50f.jpg]]

**2-3**

I₂ 在发烟硫酸中被氧化为**碘阳离子 I₂⁺**（实际以 I₄²⁺ 形式存在），呈蓝色：

$$\mathrm{H_2SO_4} + 2\mathrm{SO_3} + 2\mathrm{I_2} = \mathrm{I_4^{2+}} + 2\mathrm{HSO_4^-} + \mathrm{SO_2}$$

（电子守恒：2I₂→I₄²⁺ 失 2e，S(+6→+4) 得 2e ✓。蓝色源于 I₂⁺ 的 d–π 跃迁吸收。）
