# 题-076-北斗40-2018BST4强化一-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（一）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

写出下列反应的化学（离子）方程式：

**1-1**（2分）氯化铁和亚硝酰氯在含氯的非水溶剂中反应。

**1-2**（2分）在 350 °C 时，K₂NiF₆ 发生真空分解。

**1-3**（2分）酸性条件下，重铬酸根氧化亚碲酸。

**1-4**（2分）二氧化钛与四氯化碳在 500 °C 下反应。

**1-5**（2分）氮化银与氰根在水溶液中反应。

### 答案

**1-1**

$$\mathrm{FeCl_3 + NOCl = NO[FeCl_4]}$$

（NO⁺ 与 FeCl₄⁻ 结合成亚硝酰鎓四氯合铁(III)酸盐。）

**1-2**

$$3\mathrm{K_2NiF_6} \xlongequal{350\ ^\circ\mathrm{C}} 2\mathrm{K_3NiF_6} + \mathrm{NiF_2} + 2\mathrm{F_2}\uparrow$$

Ni(IV) 歧化为 Ni(III) 与 Ni(II)，并释放氟气。电子守恒核验：2 个 Ni(IV)→2 Ni(III)（得 2e）＋1 个 Ni(IV)→Ni(II)（得 2e），共得 4e；4F⁻→2F₂ 失 4e ✓。

> **校勘注**：原书答案 F₂ 系数写作 1，则电子得失不守恒（得 4e 失 2e）；按系数 2F₂ 配平方守恒，已径改。

**1-3**

$$3\mathrm{H_2TeO_3} + \mathrm{Cr_2O_7^{2-}} + 8\mathrm{H^+} = 3\mathrm{H_2TeO_4} + 2\mathrm{Cr^{3+}} + 4\mathrm{H_2O}$$

（Te(+4)→Te(+6)，Cr₂O₇²⁻→Cr³⁺。）

> **校勘注**：原书 8H⁺ 误排为 8H\*，已改。

**1-4**

$$\mathrm{TiO_2 + CCl_4} \xlongequal{500\ ^\circ\mathrm{C}} \mathrm{TiCl_4} + \mathrm{CO_2}$$

**1-5**

$$\mathrm{Ag_3N + 6CN^- + 3H_2O = 3Ag(CN)_2^- + NH_3\uparrow + 3OH^-}$$

（Ag₃N 极不稳定，被 CN⁻ 配位溶解。）

> **校勘注**：原书产物写作 NH₄⁺，则电荷（左 −6 / 右 −3）与氢（左 6 / 右 7）均不守恒；改为 NH₃ 后电荷 −6＝−3−3、H 6＝3＋3 平衡，已径改。
