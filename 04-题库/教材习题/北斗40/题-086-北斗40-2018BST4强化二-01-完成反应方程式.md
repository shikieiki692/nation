# 题-086-北斗40-2018BST4强化二-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（二）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

写出下列反应的化学（离子）方程式：

**1-1**（2分）过硫化铜被浓硝酸氧化。

**1-2**（2分）高氯酸鏻（PH₄ClO₄）分解生成五氧化二磷、氯化氢和水。

**1-3**（2分）将 AsH₃ 通入硝酸银溶液。

**1-4**（2分）用硫代硫酸钠解氰化物的毒性。

**1-5**（2分）用 VO₂⁺ 氧化草酸。

### 答案

**1-1**

$$\mathrm{CuS_2 + 16HNO_3(浓) = Cu(NO_3)_2 + 2H_2SO_4 + 14NO_2\uparrow + 6H_2O}$$

（CuS₂ 中 S 为 −1 价（类似黄铁矿），2 个 S(−1→+6) 共失 14e，14 个 N(+5→+4) 得 14e ✓。）

**1-2**

$$2\mathrm{PH_4ClO_4} \xlongequal{\Delta} \mathrm{P_2O_5} + 2\mathrm{HCl}\uparrow + 3\mathrm{H_2O}$$

电子守恒核验：2 个 P(−3→+5) 失 16e，2 个 Cl(+7→−1) 得 16e ✓；O 8＝5＋3 ✓。

> **校勘注**：①原书题面此处排印为「五氯化磷」，但若产物含 PCl₅ 则电子得失（失 8a e / 得 2a e）无法守恒，P₂O₅＋HCl＋H₂O 是唯一可配平的三产物组合，故应为「氯化氢」；②原书答案行排为「5PH₄ClO₄ = 2P₂O₃ + PCl₃ + 10H₂O」，P、Cl、O 计数全不守恒，系排印失真，已按守恒解径改。

**1-3**

$$2\mathrm{AsH_3} + 12\mathrm{Ag^+} + 3\mathrm{H_2O} = \mathrm{As_2O_3} + 12\mathrm{Ag}\downarrow + 12\mathrm{H^+}$$

（古蔡氏试砷法：2 个 As(−3→+3) 失 12e，12 个 Ag⁺ 得 12e ✓。）

> **校勘注**：原书答案 6Ag⁺／Ag／6H⁺ 电子得失 6e≠12e，且 O、H 计数不平，已径改。

**1-4**

$$\mathrm{S_2O_3^{2-} + CN^- = SCN^- + SO_3^{2-}}$$

（CN⁻ 被转化为低毒的 SCN⁻。）

**1-5**

$$2\mathrm{VO_2^+} + \mathrm{H_2C_2O_4} + 2\mathrm{H^+} = 2\mathrm{VO^{2+}} + 2\mathrm{CO_2}\uparrow + 2\mathrm{H_2O}$$

（V(+5→+4) 得 2e，C₂O₄²⁻（+3）→2CO₂（+4）失 2e ✓。）

> **校勘注**：原书答案漏写 H⁺ 与 H₂O（O 计数 8≠6），已径改。
