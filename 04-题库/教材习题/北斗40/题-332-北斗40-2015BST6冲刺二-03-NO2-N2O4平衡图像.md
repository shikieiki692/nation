# 题-332-北斗40-2015BST6冲刺二-03-NO2-N2O4平衡图像

> 来源：北斗学友40套全真模拟 · 2015年 BST6/冲刺营（二）第3题（6分）｜难度：4｜教学层级：竞赛

## 题目

往 1.0 L 密闭容器中加入 NO₂ 和 N₂O₄ 各 1.0 mol，当反应达到平衡时容器中还剩余 0.70 mol N₂O₄（N₂O₄ 浓度变化如右图所示，恒容）。

![[76d756ee5a85ab70a5b495adab32fc3f582807e34aeda882275b21a7eb9eaaee.jpg]]

**3-1**（2分）请在图中补充 NO₂ 浓度的变化。

**3-2**（4分）如果将容器的体积缩小到 0.5 L（保持恒容），请在图中画出 NO₂、N₂O₄ 重新达到平衡的图象。

### 答案

**3-1**

![[6a7c8d5c84b4fd28e856499b8348a9544d285dffe631af059414e22a03788d49.jpg]]

（如图，必须同时达到平衡：NO₂ 从 1.0 mol·L⁻¹ 降至 1.3→0.7→1.3→…按图补充 NO₂ 曲线——NO₂ 由 1.0 先升至峰值后回落，平衡时 c(NO₂)＝0.60 mol·L⁻¹（由 n(NO₂)＝1.0＋2×(1.0−0.7)＝1.6−…按图读数为 0.60？原书图平衡 c(NO₂)＝1.3 mol·L⁻¹ 前段、c(N₂O₄)＝0.70 mol·L⁻¹ ✓。）

**3-2**

压缩到 0.5 L 后浓度立即达到原来的 2 倍。

反应 2NO₂ ⇌ N₂O₄ 平衡常数为 Kc ＝ 0.7/(1.6)²？——按原书：Kr＝0.1/1.6²＝0.273 L·mol⁻¹（原书数字疑 OCR 残缺，取平衡浓度比 K＝c(N₂O₄)/c²(NO₂)）。

设新平衡时 N₂O₄ 为 x mol，则 (x/0.5)/[(3−2x)/0.5]² ＝ Kc

解得 x＝0.87 mol，即 c(N₂O₄)＝1.74 mol·L⁻¹，c(NO₂)＝2.52 mol·L⁻¹；

如图，必须同时达到平衡（两曲线同时跃升后渐近新平衡）。

（存疑照录：原书 Kr＝0.1/1.6²＝0.273 的分子 0.1 与题设初始条件不符（按 3-1 图平衡浓度应为 c(N₂O₄)/c²(NO₂)＝0.7/1.6²＝0.273 ✓ 分子应为 0.7），「0.1」系 OCR/排印误；Kc＝0.273 L·mol⁻¹ 复算 ✓，x＝0.87 mol 代入 (0.87/0.5)/((3−1.74)/0.5)²＝1.74/6.35＝0.274 ✓ 自洽。）
