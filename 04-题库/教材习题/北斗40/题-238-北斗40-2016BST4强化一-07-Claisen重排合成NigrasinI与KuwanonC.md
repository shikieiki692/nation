# 题-238-北斗40-2016BST4强化一-07-Claisen重排合成NigrasinI与KuwanonC

> 来源：北斗学友40套全真模拟 · 2016年 BST4/强化营（一）第7题（10分）｜难度：5｜教学层级：竞赛

## 题目

在天然产物的全合成中，Claisen 重排很多时候有着重要的应用。例如，两种天然产物 Nigrasin I 和 Kuwanon C 都是经由此反应合成的。这两种天然产物互为同分异构体。

![[6a1a45abdc3ffa5e758b1f61701408562dbaa603b6ee92d1d092d3850b41831d.jpg]]

（A：5,7-二羟基-2-(4-羟-3,5-二苄氧基苯基)黄酮并带异戊烯侧链 → ① prenyl bromide/K₂CO₃ 得酚醚 M → Ac₂O/AcONa 微波 180 ℃ → Nigrasin I；② cat. Pd(PPh₃)₄/THF ＋ 烯丙基碳酸叔丁酯得 N → 微波 170 ℃ → Kuwanon C。）

**7-1**（3分）在上图中给出 Nigrasin I 和 Kuwanon C 的结构。

**7-2**（2分）事实上，这两个反应非常相似，然而我们却使用了完全不同的反应来把 A 转化为其对应的酚醚。请解释这样做的原因。

**7-3**（2分）—Bz 是苯甲酰基，常用于羟基的保护。在此反应中，我们为何要保护这两个酚羟基？在 M/N 中，还有第三个酚羟基，我们是否也需要保护？为什么？

**7-4**（3分）给出反应 A→N 的所有产物。

### 答案

**7-1**

![[55ad33a7766e824fd19aab02b1e0cac4ee5066c235b9fa514d90cd9ed0c2753d.jpg]]

Nigrasin I

![[4b82c8d38a26259df08b804699bf90365156b044f9be3c7e2102da9aba793d2b.jpg]]

Kuwanon C

（各 1.5 分。）

**7-2**

从 A→M，反应所需另一原料是一级卤代烃，非常适合 SN2 反应，故通常的取代反应条件即可满足。然而，从 A→N，反应需要三级卤代烃，相比取代，在碱性条件下更易于发生消去反应。因此我们必须采取另外的反应路径。否则，也可能用另一个苯环的酚羟基发生取代，经 Claisen 重排后得到另一个苯环上被取代的产物。

**7-3**

不需要保护。因为即使在这个酚羟基上发生取代，经 Claisen 重排后，仍是我们所需要的产物。

（两个 BzO 保护基用于防止碱/加热条件下酚羟基的副反应；第三个酚羟基位置在重排后回归所需位点，无须保护。）

**7-4**

![[91dce0ee22eaf53bf2fd3ec5a0f49c2129bffed7d85973eea6e0bf0059151eaa.jpg]]

（A→N 的烯丙基碳酸叔丁酯经 Pd 催化脱羧释放异丁烯与 CO₂，得 O-烯丙基酚醚 N 的伴生产物：叔丁醇与二氧化碳。）
