# 题-031-北斗40-2019BST6冲刺二-01-完成反应方程式

> **来源**：北斗学友·2019 年 BST6/冲刺营全真模拟（二） 第1题（12分）
> **难度**：⭐⭐⭐⭐
> **教学层级**：竞赛

---

## 题目

写出并配平下列化学反应的方程式。

1-1 碘酸酐检验一氧化碳。

1-2 二氧化钛溶于浓硫酸的反应产物和铝单质的反应。

1-3 重铬酸根与过氧化氢在乙醚中反应，生成蓝色的溶剂合物。

1-4 氯化镍溶液中加入保险粉，在烧杯内壁形成一层镍镜（不考虑保险粉还原水）。

1-5 氨基钠和一氧化二氮反应，生成物中的化合物或离子与反应物中的离子与化合物成两对等电子体。

1-6 在氟离子环境中，高锰酸根与锰离子发生归中反应。

### 答案

1-1（2分）

$$\mathrm{I}_{2}\mathrm{O}_{5} + 5\mathrm{CO} = \mathrm{I}_{2} + 5\mathrm{CO}_{2}$$

1-2（2分）硫酸氧钛与铝：

$$3\mathrm{TiO}^{2+} + \mathrm{Al} + 6\mathrm{H}^{+} = 3\mathrm{Ti}^{3+} + \mathrm{Al}^{3+} + 3\mathrm{H}_{2}\mathrm{O}$$

1-3（2分）蓝色过氧化铬的生成：

$$\mathrm{Cr}_{2}\mathrm{O}_{7}^{2-} + 4\mathrm{H}_{2}\mathrm{O}_{2} + 2\mathrm{Et}_{2}\mathrm{O} + 2\mathrm{H}^{+} = 2\mathrm{CrO(O_{2})_{2}}\cdot\mathrm{Et}_{2}\mathrm{O} + 5\mathrm{H}_{2}\mathrm{O}$$

1-4（2分）保险粉（连二亚硫酸钠）还原沉积镍镜：

$$\mathrm{Ni}^{2+} + \mathrm{S}_{2}\mathrm{O}_{4}^{2-} = \mathrm{Ni} + 2\mathrm{SO}_{2}$$

（生成亚硫酸或亚硫酸氢根也给分）

1-5（2分）

$$2\mathrm{NaNH}_{2} + \mathrm{N}_{2}\mathrm{O} = \mathrm{NaOH} + \mathrm{NH}_{3} + \mathrm{NaN}_{3}$$

（$N_2O$ 与 $N_3^-$ 等电子、$NH_3$ 与 $OH^-$ 等电子——两对等电子体 ✓）

1-6（2分）

$$2\mathrm{MnO}_{4}^{-} + 3\mathrm{Mn}^{2+} + 30\mathrm{F}^{-} + 8\mathrm{H}_{2}\mathrm{O} = 5\mathrm{MnF}_{6}^{2-} + 16\mathrm{OH}^{-}$$

**要点提示**：1-3 的蓝色 $CrO(O_2)_2\cdot Et_2O$ 在乙醚层中稳定存在（水相中迅速分解），是检验过氧化物的经典反应；1-6 中 $F^-$ 的引入使 Mn(Ⅳ) 以稳定配离子 $MnF_6^{2-}$ 形式"捕获"归中产物。
