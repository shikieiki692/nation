# 题-109-北斗40-2018BST6冲刺二-04-镍系列化合物推断

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第4题（13分）｜难度：5｜教学层级：竞赛

## 题目

单质 A 为银白色金属。将 A 与 CO 在 50 °C 进行反应得到 X，其中 A 的质量分数为 34.38%。将 A 溶于盐酸得到 B，向溶液中加入过量的 NaOH 得到 C，后加入溴水，使其充分反应，得到含氧量为 34.89% 的 D。将 C 溶于 HBr 中，加入过量的氨水，得到紫色沉淀 E。将 B 在氨水介质中与分子式为 C₄H₆O₂ 的有机物及 F 反应，得到著名的红色沉淀 G。

**4-1**（6分）写出 A、B、C、D、E、F 的化学式。

**4-2**（4分）画出 G 的结构，写出生成 G 的反应方程式。

**4-3**（3分）画出 X 中 A 和 CO 形成的多中心 π 键的原子轨道示意图。

### 答案

**4-1**

| 物种 | 化学式 | 依据 |
|:--|:--|:--|
| A | Ni | 银白色金属；X 中 Ni 质量分数 58.69/170.7 = 34.4% ✓ |
| X | Ni(CO)₄ | 50 °C 与 CO 反应（Mond 法） |
| B | NiCl₂ | A 溶于盐酸 |
| C | Ni(OH)₂ | 加过量 NaOH |
| D | NiO(OH) | 溴水氧化（含氧量 3×16/91.7 = 34.9% ✓） |
| E | Ni(NH₃)₆Br₂ | C 溶于 HBr 再加氨水，紫色沉淀 |
| F | NH₂OH | 与丁二酮肟共同沉淀 Ni²⁺ |

**4-2**

G 为丁二酮肟合镍 Ni(DMG)₂（鲜红色沉淀，平面四方形，两个分子内 O—H···O 氢键）：

![[6d1b1434d0bd33add30fc84a078cd79b618a9cde88406b5bd3275944d6988a87.jpg]]

方程式：

$$\mathrm{NiCl_2} + 2\mathrm{NH_3} + 2\mathrm{C_4H_6O_2} + 2\mathrm{NH_2OH} = 4\mathrm{H_2O} + 2\mathrm{NH_4Cl} + \mathrm{Ni(C_4H_7O_2N_2)_2}\downarrow$$

（C₄H₆O₂ ＋ NH₂OH 原位缩合生成丁二酮肟。）

**4-3**
