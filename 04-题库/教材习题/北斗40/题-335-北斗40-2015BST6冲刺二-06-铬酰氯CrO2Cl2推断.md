# 题-335-北斗40-2015BST6冲刺二-06-铬酰氯CrO2Cl2推断

> 来源：北斗学友40套全真模拟 · 2015年 BST6/冲刺营（二）第6题（8分）｜难度：4｜教学层级：竞赛

## 题目

称取液体 A 464.7 mg，使之溶于水中，溶液具有明显的酸性。需要 6.000 mmol 的 Ba(OH)₂ 才能中和它，同时溶液中产生沉淀 B 760.0 mg。过滤出沉淀并洗涤后用稀 H₂SO₄ 处理，沉淀 B 转化为一溶液 C，与此同时又产生一新沉淀 D 700.2 mg。B、D 类质同晶。溶液 C 中加入过量的 KI 后，用 S₂O₃²⁻ 滴定，耗去 0.3000 mol·L⁻¹ 的 Na₂S₂O₃ 溶液 30.00 mL。

**6-1**（2分）试确认各符号所代表的化合物。

**6-2**（2分）写出 A 与 Ba(OH)₂ 反应的总方程式。

**6-3**（2分）写出 C 与过量 KI 反应的离子方程式。

**6-4**（2分）A 的蒸气可以用中性亚硫酸钠溶液吸收，写出反应方程式。

### 答案

**6-1**

A：CrO₂Cl₂（铬酰氯）

（复算：n(A)＝6.000/2＝3.000 mmol → M(A)＝464.7/3.000＝154.9 ≈ M(CrO₂Cl₂)＝154.9 ✓；中和需 2 mol Ba(OH)₂/mol A（生成 HCl 与 H₂CrO₄ 各 2 H⁺ 当量）✓。）

B：BaCrO₄（760.0 mg/233.3＝3.257 mmol ≈ 3.000 mmol，微差为共沉淀 BaCl₂）

D：BaSO₄（700.2 mg/233.4＝3.000 mmol ✓，与 B 类质同晶 ✓）

C：H₂Cr₂O₇（B 溶于稀硫酸后铬转化为重铬酸）

**6-2**

CrO₂Cl₂ + 2Ba(OH)₂ ═ BaCrO₄ + BaCl₂ + 2H₂O

**6-3**

Cr₂O₇²⁻ + 6I⁻ + 14H⁺ ═ 2Cr³⁺ + 3I₂ + 7H₂O

（复算：滴定 I₂ 耗 9.000 mmol S₂O₃²⁻ → n(I₂)＝4.500 mmol → n(Cr₂O₇²⁻)＝1.500 mmol → n(Cr)＝3.000 mmol ✓ 与 A 量吻合，全链自洽。）

**6-4**

2CrO₂Cl₂ + 3SO₃²⁻ + H₂O ═ 2Cr(OH)²⁺?（原书作 2Cr(OH)²⁺…）＋4Cl⁻ + 3SO₄²⁻

（原书方程：2CrO₂Cl₂ + 3SO₃²⁻ + H₂O ═ 2Cr(OH)²⁺? + 4Cl⁻ + 3SO₄²⁻——照录；电子账 Cr(VI)→Cr(III) 得 6e⁻、3 个 S(IV)→S(VI) 失 6e⁻ ✓；电荷左侧 −3 对右侧 ＋2−4−6＝−8？——原书方程电荷/物种书写存在 OCR 残缺（Cr(OH)²⁺ 应为 Cr³⁺ 或羟合配离子形式），按电子账照录存疑待回源。）
