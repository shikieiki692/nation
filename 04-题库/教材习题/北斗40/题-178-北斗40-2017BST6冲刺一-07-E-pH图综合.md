# 题-178-北斗40-2017BST6冲刺一-07-E-pH图综合

> 来源：北斗学友40套全真模拟 · 2017年 BST6/冲刺营（一）第7题（12分）｜难度：5｜教学层级：竞赛

## 题目

现有 E–pH 图如下所示：

![[cc88a6daeb0aa355532c775321c4ed9386aa170f280a49cd7ac47b7a23a404ea.jpg]]

A、B、C 三条线分别代表电对 IO₃⁻/I₂、I₂/I⁻、Cu²⁺/Cu。

**7-1**（1.5分）分别写出三个电对所代表的半反应式。

**7-2**（1.5分）说明线 C 是折线的原因。

![[f56000be473bb1f0e29861c40502c0f8c14285bc9d58ce8ec6f744e59dcaed68.jpg]]

**7-3**（8分）计算 pH＝0 时由电对 IO₃⁻/I₂ 和 I₂/I⁻ 构成的反应的 K° 和 ΔG°(298 K)。

**7-4**（3分）求 b 和 pH＝b 时的 K°。

**7-5**（3分）求 Cu(OH)₂ 的 Ksp。

### 答案

**7-1**

$$2IO_3^- + 12H^+ + 10e^- \longrightarrow I_2 + 6H_2O \quad (E^\circ = 1.20\ V)$$

$$I_2 + 2e^- \longrightarrow 2I^- \quad (E^\circ = 0.54\ V)$$

$$Cu^{2+} + 2e^- \longrightarrow Cu \quad (E^\circ = 0.34\ V)$$

**7-2**

pH 增大、开始生成 Cu(OH)₂ 沉淀，Cu²⁺/Cu 电对的电势与 pH 有关，故 C 线在 a 点（pH≈4.7）后变为斜线（折线）。

**7-3**

总反应 IO₃⁻ ＋ 5I⁻ ＋ 6H⁺ ＝ 3I₂ ＋ 3H₂O，E°cell＝1.20−0.54＝0.66 V：

$$\lg K^\circ = \frac{nE^\circ}{0.05916} = \frac{5\times0.66}{0.05916} = 55.8$$

$$K^\circ = 6.0\times10^{55}, \qquad \Delta G^\circ = -nE^\circ F = -318\ \mathrm{kJ\cdot mol^{-1}}$$

**7-4**

A、B 两线交点（b 点）满足：

$$E(IO_3^-/I_2) = E^\circ(IO_3^-/I_2) - \frac{0.05916\times6}{5}\,pH$$

$$0.54 = 1.20 - \frac{0.05916\times6}{5}\,b \quad\Rightarrow\quad b = 9.30$$

pH＝b 时 K° 仍为该反应的平衡常数：K°＝6.0×10⁵⁵。

**7-5**

C 线水平段终点 a 后变为斜线，与 0.068 V 虚线交点满足：

$$E(Cu^{2+}/Cu) = 0.34 - 0.05916\,\Delta pH \quad\Rightarrow\quad \Delta pH = \frac{0.34-0.068}{0.05916} = 4.60,\quad a = 4.70$$

a 点开始生成 Cu(OH)₂（设 [Cu²⁺]＝1 mol·L⁻¹ 的标准态）：

$$[OH^-] = 10^{-(14-4.70)} = 5.0\times10^{-10}\ \mathrm{mol\cdot L^{-1}}$$

$$K_{sp} = [Cu^{2+}][OH^-]^2 = (5.0\times10^{-10})^2 = 2.5\times10^{-19}$$
