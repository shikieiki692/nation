# 题-280-北斗40-2016BST7押题二-04-Epton法测定阴离子表面活性剂

> 来源：北斗学友40套全真模拟 · 2016年 BST7/押题营（二）第4题（13分）｜难度：5｜教学层级：竞赛

## 题目

Epton 法是一种用于测定溶液中阴离子表面活性剂浓度的方法。反应在两相中进行，通常是水和氯仿两相。反应以阳离子表面活性剂为滴定剂，以亚甲基蓝为指示剂。亚甲基蓝的结构式如图所示，记作 MB⁺Cl⁻。

![[dbca1e6e262a49161bdb1ea4a092f56da16301e50e33c54bd228ee1b4c3495aa.jpg]]

（亚甲基蓝：噻嗪鎓染料，两个二甲氨基取代。（图下部含页码「354」水印，系原书扫描装饰。））

**4-1**（2分）除本题已提到的物种之外，给出阴离子表面活性剂和阳离子表面活性剂各一例。表面活性剂具有什么样的结构特点？

**4-2**（2分）假如我们简记阳离子表面活性剂为 Rₘ⁺，阴离子表面活性剂为 Rₛ⁻，试判断以下物种在水和氯仿两相中的溶解度：MB⁺Cl⁻、MB⁺Rₛ⁻、Rₘ⁺Cl⁻、Rₘ⁺Rₛ⁻。

市售的洗涤剂中通常含有一定量的阴离子表面活性剂，其含量测量可以利用 Epton 法进行测量，一个典型的实验如下。

取 4.8382 g 洗涤剂，用水溶解，定容至 1000 mL 备用。在 100 mL 锥形瓶中加入 20.00 mL 上述洗涤剂溶液，加入 25 mL 亚甲基蓝指示剂及 15 mL 氯仿，充分振荡混匀。用 5.920 mmol·L⁻¹ 的阳离子表面活性剂溶液进行滴定，当两相呈相同颜色时达到终点，消耗 10.38 mL。

**4-3**（1分）滴定开始时体系是什么颜色？

**4-4**（2分）试简述 Epton 法的原理。

**4-5**（1.5分）计算该洗涤剂中阴离子表面活性剂的含量。

**4-6**（2.5分）实际实验中，阳离子表面活性剂滴定剂通常采用烷基吡啶盐酸盐，这是因为它能与重铬酸根离子反应生成烷基吡啶重铬酸盐沉淀，因而可以被方便地标定。以重铬酸钾为基准物质，设计一种标定烷基吡啶盐酸盐溶液的方案。给出需要测量的数据，并列出计算公式。

**4-7**（2分）近来，有科学家改进了 Epton 法，先加入过量的阳离子表面活性剂，然后以阴离子表面活性剂进行返滴定，这种方法有什么好处？

### 答案

**4-1**

阴离子表面活性剂：十二烷基苯磺酸钠、硬脂酸钠等。

阳离子表面活性剂：溴化四正丁基铵、溴化三甲基十六烷基铵等。

结构特点：具有亲水的阳（阴）离子和亲油的阴（阳）离子，后者常有较长的烷基链。

**4-2**

MB⁺Cl⁻：在水中溶解度较大，在氯仿中也有一定的溶解度。

MB⁺Rₛ⁻：在水中溶解度较小（几乎不溶），在氯仿中溶解度较大。

Rₘ⁺Cl⁻：在水中和氯仿中均有一定的溶解度。

Rₘ⁺Rₛ⁻：在水中溶解度较小（几乎不溶），在氯仿中溶解度较大。

**4-3**

氯仿层呈蓝色，而水层几乎无色。（阴离子表面活性剂与 MB⁺ 形成 MB⁺Rₛ⁻ 进入氯仿相。）

**4-4**

滴定开始时，体系中主要为 MB⁺Rₛ⁻，位于氯仿相中。随着滴定的进行，Rₘ⁺ 与 Rₛ⁻ 反应生成 Rₘ⁺Rₛ⁻，释放出 MB⁺，与 Cl⁻ 结合为 MB⁺Cl⁻。后者在水和氯仿两相中均有一定的溶解度，因此可以自由分配于两相之间，使两相均显蓝色。滴定达终点时，所有 Rₛ⁻ 均被结合为 Rₘ⁺Rₛ⁻，没有 MB⁺Rₛ⁻ 存在，从而两相的颜色应当大致相同。

**4-5**

终点时 n(Rₛ⁻) ＝ n(Rₘ⁺) ＝ 5.920 mmol·L⁻¹ × 10.38×10⁻³ L ＝ 6.145×10⁻² mmol（20.00 mL 试液中）

折算至 1000 mL 贮备液：6.145×10⁻² × (1000/20.00) ＝ 3.073 mmol

含量 ＝ 3.073 mmol / 4.8382 g ＝ 0.635 mmol·g⁻¹

（校勘注：原书 4-5 答案为严重 OCR 乱码，仅可辨「r＝5.920 mmol·L⁻¹」与残留数字「0.6150 mmol·g⁻¹」；按题面数据复算应为 0.635 mmol·g⁻¹，两者不符且 0.6150 无法由题面数据复现。本卡按题面数据重建计算，标注非原书转录，待回源核对。）

**4-6**

（原书答案为严重 OCR 乱码，以下方案按乱码残留骨架「重铬酸盐沉淀—过滤—KI—硫代硫酸钠滴定」与残留公式因子 (r₁V₁ − r₂V₂/6)×2 重建，标注非原书转录。）

方案：准确移取 V₁ mL 烷基吡啶盐酸盐（浓度 c，待标定）溶液于碘量瓶中，加入准确量取的过量 K₂Cr₂O₇ 标准溶液（浓度 c₁、体积 V₁′），生成重铬酸二烷基吡啶沉淀：

2Rₘ⁺ + Cr₂O₇²⁻ → (Rₘ)₂Cr₂O₇↓

过滤（洗涤沉淀，滤液与洗涤液合并），向滤液中加入过量 KI 与适量硫酸，暗处放置充分反应（剩余 Cr₂O₇²⁻ 氧化 I⁻ 析出 I₂）：

Cr₂O₇²⁻ + 14H⁺ + 6I⁻ ═ 2Cr³⁺ + 3I₂ + 7H₂O

以淀粉为指示剂，用 Na₂S₂O₃ 标准溶液（浓度 c₂）滴定至蓝色消失为终点，消耗 V₂ mL：

I₂ + 2S₂O₃²⁻ ═ 2I⁻ + S₄O₆²⁻

计算公式（计量关系：2Rₘ⁺ ～ 1 Cr₂O₇²⁻；1 Cr₂O₇²⁻ ～ 3 I₂ ～ 6 S₂O₃²⁻）：

c(Rₘ⁺) ＝ 2×[c₁V₁′ − c₂V₂/6]/V样 ＝ (2c₁V₁′ − c₂V₂/3)/V样

需测量的数据：K₂Cr₂O₇ 标液的 c₁ 与加入体积 V₁′、Na₂S₂O₃ 标液的 c₂ 与滴定消耗体积 V₂、烷基吡啶盐酸盐溶液的取样体积 V样。

**4-7**

（1）终点由两相相同的蓝色更改为水相无色、氯仿相蓝色，更加明确。

（2）若体系中有其他阴离子可以与 MB⁺ 形成化合物，加入阳离子表面活性剂可以与这部分阴离子预先反应，除去它们带来的干扰。
