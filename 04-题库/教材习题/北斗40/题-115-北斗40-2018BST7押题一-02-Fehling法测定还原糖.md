# 题-115-北斗40-2018BST7押题一-02-Fehling法测定还原糖

> 来源：北斗学友40套全真模拟 · 2018年 BST7/押题营 全真模拟（一）第2题（14分）｜难度：5｜教学层级：竞赛

## 题目

Fehling's 试剂经常被用来测定食品中不同还原糖的含量。现将 20.00 mL 的橙汁样品（认为其中只含有葡萄糖和果糖）转移到 100 mL 容量瓶中并定容。第一份用移液管移取 25 mL 溶液至锥形瓶中，加入 Fehling's 试剂。试剂由 25.00 mL 0.05000 mol·L⁻¹ 硫酸铜溶液、酒石酸钾钠和氢氧化钠组成，加热后得到的溶液生成了红色沉淀，之后向锥形瓶中加入 15 mL 5% 的碘化钾溶液与适量 3 mol·L⁻¹ 硫酸，混合物用表面皿盖住并在暗处放置 5 min，用 0.05132 mol·L⁻¹ 的硫代硫酸钠溶液滴定，终点时消耗了 10.86 mL 滴定剂。另用移液管移取 25.00 mL 溶液，加入 10.00 mL 0.01541 mol·L⁻¹ 的碘酸钾溶液、适量 3 mol·L⁻¹ 硫酸和 20 mL 10% 碘化钾溶液。混合物变成棕色后加入过量氢氧化钠溶液。容器用表面皿盖住，于暗处放置。随后酸化，用 0.01107 mol·L⁻¹ 的硫代硫酸钠溶液滴定，滴定体积为 25.93 mL。

**2-1**（3分）写出第一份溶液滴定过程的操作（包括添加试剂、指示剂与颜色变化）。

**2-2**（2分）指出第二份实验操作中的瑕疵。

**2-3**（4分）写出第二份测定过程中的方程式。

**2-4**（5分）计算橙汁中两种糖的含量（g·L⁻¹）。

### 答案

**2-1**

先用硫代硫酸钠滴定至浅黄色，再用淀粉作指示剂，滴定至溶液近乎白色后加入 KSCN 再滴定至终点，终点应为白色或者带有淡淡的粉色。

**2-2**

需要重复实验操作 2 至 3 次。

**2-3**

$$\mathrm{IO_3^-} + 5\mathrm{I^-} + 6\mathrm{H^+} = 3\mathrm{I_2} + 3\mathrm{H_2O}$$

$$\mathrm{I_2} + 2\mathrm{S_2O_3^{2-}} = 2\mathrm{I^-} + \mathrm{S_4O_6^{2-}}$$

![[b5d28f677b6afbfb9c5576fef91fde37d80cb299c5325a7dd4928beef8f1b863.jpg]]

（上图：葡萄糖被 I₂/NaOH 定量氧化为葡萄糖酸钠的方程式。）

**2-4**

第一份滴定了葡萄糖和果糖（Cu²⁺ 氧化两种还原糖后余 Cu²⁺ 与 I⁻ 反应析碘回滴）：

$$n_总 = 0.5\times(0.05000\times25.00 - 0.05132\times10.86)\times10^{-3} = 3.463\times10^{-4}\ \mathrm{mol}$$

第二份（KIO₃ 定量出碘、NaOH 介质中选择性氧化葡萄糖，回滴余碘）：

$$n_{葡} = 0.5\times(0.01541\times10.00\times6 - 0.01107\times25.93)\times10^{-3} = 3.188\times10^{-4}\ \mathrm{mol}$$

$$m_{葡} = 3.188\times10^{-4}\times180.15\times1000\div20.00\times100\div25.00 = 11.49\ \mathrm{g\cdot L^{-1}}$$

$$m_{果} = (3.463-3.188)\times10^{-4}\times180.15\times1000\div20.00\times100\div25.00 = 0.9928\ \mathrm{g\cdot L^{-1}}$$

（果糖 = 总还原糖 − 葡萄糖。）
