# 题-187-北斗40-2017BST6冲刺二-06-合成氨化学平衡

> 来源：北斗学友40套全真模拟 · 2017年 BST6/冲刺营（二）第6题（15分）｜难度：4｜教学层级：竞赛

## 题目

合成氨反应 N₂ ＋ 3H₂ ⟶ 2NH₃ 是对人类意义十分重大的一个化学反应，同时也是讨论化学平衡问题的常用体系。已知该反应在 298 K 温度下的标准反应吉布斯自由能 ΔrG 为 −32.8 kJ·mol⁻¹。将一定量的氮气和氢气的混合气体（N₂:H₂＝1:3）充入一个带活塞的装有催化剂的反应容器中，在反应过程中通过活塞的移动可使容器内部保持 100 kPa 的恒压状态。

**6-1**（4分）计算 298 K 下合成氨反应的平衡常数和体系达到平衡时各组分的分压。

**6-2**（3分）已知 N₂、H₂ 和 NH₃ 的标准摩尔熵分别为 191.6、130.7 和 192.8 J·mol⁻¹·K⁻¹。将上述体系温度升至 473 K，计算反应的平衡常数和体系达到平衡时各组分的分压。

**6-3**（2分）上述体系在恒外压的条件下，温度从 298 K 降到 200 K，下列说法正确的是：
(a) 平衡左移；(b) 平衡右移；(c) 密度增大；(d) 反应速率提高；(e) 单位体积粒子数减少。

**6-4**（2分）上述体系在 473 K 恒温、100 kPa 恒压的条件下达到平衡后，往体系中加入少量惰性气体，下列说法正确的是：
(a) 平衡左移；(b) 平衡右移；(c) 平衡不移动；(d) 三者都有可能

**6-5**（4分）假设在该带有活塞的反应容器中填充着由 3 mol N₂、1 mol H₂ 和 1 mol NH₃ 组成的混合气体，并且已经达到平衡状态。此时，往反应体系中加入 0.1 mol N₂，下列说法正确的是（简述理由）：
(a) 平衡左移；(b) 平衡右移；(c) 平衡不移动；(d) 三者都有可能

### 答案

**6-1**

$$\Delta_r G = -32.8\ \mathrm{kJ\cdot mol^{-1}} = -RT\ln K_p \quad\Rightarrow\quad K_p = 5.62\times10^{5}$$

设转化率 x（N₂＋3H₂→2NH₃，初始 1:3）：

$$\frac{\left(\dfrac{2x}{4-2x}\right)^2}{\left(\dfrac{1-x}{4-2x}\right)\left(\dfrac{3-3x}{4-2x}\right)^3} = K_p = 5.62\times10^{5} \quad\Rightarrow\quad x = 0.958$$

$$p_{N_2} = 2.02\ \mathrm{kPa},\quad p_{H_2} = 6.06\ \mathrm{kPa},\quad p_{NH_3} = 91.9\ \mathrm{kPa}$$

**6-2**

$$\Delta_r S = 2\times192.8 - 130.7\times3 - 191.6 = -198.1\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$$

$$\Delta_r H = \Delta_r G + T\Delta_r S = -32800 - 198.1\times298 = -9.18\times10^{4}\ \mathrm{J\cdot mol^{-1}}$$

473 K 下（设 ΔH、ΔS 不变）：

$$\Delta_r G(473) = -9.18\times10^4 + 473\times198.1 = 1.87\times10^{3}\ \mathrm{J\cdot mol^{-1}},\quad K_p = 0.622$$

计算步骤与 6-1 相同：x＝0.207，

$$p_{N_2} = 22.1\ \mathrm{kPa},\quad p_{H_2} = 66.3\ \mathrm{kPa},\quad p_{NH_3} = 11.6\ \mathrm{kPa}$$

**6-3**

(b)、(c)。p＝cRT，p 不变、T 减小，c 增大，故 (e) 错误；降温平衡放热方向右移，(a) 错误；(d) 降温速率降低。

**6-4**

(a)。恒温恒压增加惰性物质的摩尔数，相当于降低各反应气体的分压，平衡向摩尔数增大的方向（左）移动。

**6-5**

(a)。以摩尔分数计的 Kx（此时 Q 用摩尔分数表达，恒温恒压下 Kx 不随体积变化）：

$$K_x = \frac{(1/5)^2}{(3/5)(1/5)^3} = 8.33$$

加入 0.1 mol N₂ 后：

$$Q_x = \frac{(1/5.1)^2}{(3.1/5.1)(1/5.1)^3} = 8.39 > K_x$$

因此平衡左移。

要注意的是，6-4 和 6-5 是不能用勒夏特列原理判断的。因为勒夏特列原理只适用于封闭体系，对于开放体系是不成立的。
