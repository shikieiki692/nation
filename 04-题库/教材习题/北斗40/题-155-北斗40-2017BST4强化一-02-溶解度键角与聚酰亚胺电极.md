## 题目

**2-4**（5分）锂离子电池由于其高的能量密度和优异的循环性能得到了广泛的研究和应用。聚酰亚胺由于含有稳定的单体骨架和高电化学活性的官能团而被认为是极具前景的有机电极材料。一种近十年被不断研究的聚酰亚胺可由 1,2,4,5-苯四甲酸二酐（PMDA）或 1,4,5,8-萘四甲酸二酐（NDA）与二胺反应得到。

**2-4-1**（2分）分别写出 PMDA 与乙二胺、NDA 与对苯二胺反应得到的聚酰亚胺 A 和 B 的结构式。

**2-4-2**（3分）在放电过程中，A 与 B 中每个结构单元都能通过两步电化学过程，每步得到两个电子被还原。请写出 B 放电时经历的部分还原形态 C 和最终形成的还原形态 D，并指出 A 和 B 是作为电池的哪个电极。

> 题面 OCR 注：原文「λ 与 B」系「A 与 B」之误。

### 答案

**2-1**

PbCl₂ 不受酸度影响（Cl⁻ 不水解）：

$$S = \sqrt[3]{\frac{K_{sp}}{4}} = \sqrt[3]{\frac{1.70\times10^{-5}}{4}} = 0.0162\ \mathrm{mol\cdot L^{-1}}$$

PbF₂ 在 pH＝1 时 F⁻ 质子化，分布分数：

$$\alpha = \frac{K_a}{K_a + [H^+]} = \frac{6.30\times10^{-4}}{6.30\times10^{-4}+0.100} = 6.26\times10^{-3}$$

由 Ksp＝[Pb²⁺][F⁻]²＝S·(2Sα)²＝4S³α²：

$$S = \sqrt[3]{\frac{3.30\times10^{-8}}{4\times(6.26\times10^{-3})^2}} = 0.0594\ \mathrm{mol\cdot L^{-1}}$$

PbF₂ 的溶解度大于 PbCl₂。

> **校勘注**：原书算式把立方根漏写（S＝3.30×10⁻⁸×(1.00/6.30×10⁻⁴)²＝0.0831，量纲不符）。按 S³α² 正确复算为 0.0594 mol·L⁻¹，溶解度大小结论不变。

**2-2**

N(CF₃)₃ 具有下图所示的共振结构式（N→CF₃ 的 p-π 反馈，N 带正电荷、一个 C 带负电荷），在该结构中 N 原子和三个 C 原子共平面，∠C−N−C 趋近 120°、C−N 键缩短；而 N(CH₃)₃ 不存在这样的共振结构式，保持 sp³ 棱锥体。
