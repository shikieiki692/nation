# 题-175-北斗40-2017BST6冲刺一-04-Winkler碘量法测溶解氧

> 来源：北斗学友40套全真模拟 · 2017年 BST6/冲刺营（一）第4题（10分）｜难度：5｜教学层级：竞赛

## 题目

氧含量测定是分析化学中的重要内容。

水质分析中的溶解氧的测定，国际标准指定了两种方法：碘量法（ISO 5813—1983）和电化学探头法（ISO 5814—1984）。两者相比碘量法简单、准确，但易受到干扰。水中溶解氧的测定对于水质监测、环境评价、水产品养殖等都有重要意义。

水样预处理：将水样注入 250 mL 水样瓶并使水溢流，迅速盖上瓶塞，然后打开塞子加入 1.0 mL 2.0 mol/L 的 MnSO₄ 溶液和 2.0 mL KI-NaOH 溶液，立即盖好。颠倒摇动 10 次，放置 5 分钟，再颠倒 10 次。平行处理 3 份水样。

当水样中的沉淀物下降到瓶口以下 1/3 距离时，缓缓加入 1.7 mL (1＋1) 硫酸，盖好，颠倒摇匀使沉淀物溶解完全，并分布均匀。取出 100.0 mL 至锥形瓶中，用 0.010 12 mol·L⁻¹ 的 Na₂S₂O₃ 溶液滴定至浅黄色，加 3 mL 淀粉溶液，继续滴定至蓝色消失，平均消耗 5.60 mL。

**4-1** 试写出分析过程中所有的反应方程式。

**4-2** 在分析过程中，哪些加入的溶液的体积是需要准确测量的？并计算水样的含氧量。

**4-3** 实际上，在用碘量法测定水样含氧量时，若水样存在其他氧化性干扰物质，需对结果进行校正：另取 200 mL 水样置于锥形瓶中，加入 1.7 mL (1＋1) 硫酸，然后加入 2.0 mL KI-NaOH 溶液和 1.0 mL MnSO₄ 溶液，混匀后放置 5 分钟，用 Na₂S₂O₃ 溶液滴定至终点，结果从之前的滴定结果中扣除。试说明如此操作为何能校正氧化性杂质带来的干扰。

### 答案

**4-1**（Winkler 法四步；第 1 式为原书文本，第 2 式原书写作 2Mn(OH)₂·O₂→2MnO₄(OH)₂ 的缩写形式，第 3 式原书「4OH⁻」系「4H⁺」之 OCR 误、电荷不平，径改）

$$Mn^{2+} + 2OH^- = Mn(OH)_2$$

$$2Mn(OH)_2 + O_2 = 2H_2MnO_3$$

$$H_2MnO_3 + 4H^+ + 2I^- = Mn^{2+} + I_2 + 3H_2O$$

$$I_2 + 2S_2O_3^{2-} = 2I^- + S_4O_6^{2-}$$

**4-2**

需要准确测量的体积：水样瓶体积（250 mL）、MnSO₄ 1.0 mL、KI-NaOH 2.0 mL、(1＋1) 硫酸 1.7 mL（它们决定体积校正因子）、以及滴定剂消耗 5.60 mL。

$$n(S_2O_3^{2-}) = 0.01012\times\frac{5.60}{1000} = 5.667\times10^{-5}\ \mathrm{mol}$$

由 O₂ : S₂O₃²⁻ ＝ 1 : 4，100.0 mL 滴定液中：

$$n(O_2) = \frac{5.667\times10^{-5}}{4} = 1.417\times10^{-5}\ \mathrm{mol}$$

体积校正（加试剂后总体积 254.7 mL，取出的 100.0 mL 中水样占 100.0×250.0/254.7）：

$$c(O_2) = \frac{1.417\times10^{-5}}{0.1000}\times\frac{250.0}{254.7} = 1.39\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$$

$$溶解氧 = 1.39\times10^{-4}\times32\ \mathrm{g\cdot mol^{-1}} = 4.45\ \mathrm{mg\cdot L^{-1}}$$

> **非原书转录**：原书本小题数值部分 OCR 严重乱码（「11.20 mL／2.887×10⁻¹／0.24 mg/L」均不可读），以上按题面数据（平均消耗 5.60 mL）重算并标注。

**4-3**

只有在碱性条件下溶解氧才能氧化 Mn(II)。若先加入足量的硫酸使溶液保持酸性，则溶解氧不会发生反应，而只有氧化性干扰物质会转化为 I₂ 被滴定；因此可以通过调整试剂的加入顺序来消除氧化性杂质带来的干扰（本次滴定值即干扰本底，从正式滴定值中扣除）。
