# 题-157-北斗40-2017BST4强化一-04-高碘酸高锰酸钾双法测定

> 来源：北斗学友40套全真模拟 · 2017年 BST4/强化营（一）第4题（10分）｜难度：5｜教学层级：竞赛

## 题目

移取 20.00 mL HCOOH 和乙二醇的混合溶液，用 50.00 mL 高碘酸钾溶液处理。待反应完全后，将混合液调至 pH＝8.0，加入过量 KI，释放出的 I₂ 以 0.050 00 mol·L⁻¹ 亚砷酸钠溶液滴定至终点，消耗 14.30 mL。而 50.00 mL 该高碘酸钾的空白溶液在 pH＝8.0 时，加入过量 KI，释放出的 I₂ 所消耗的等浓度的亚砷酸钠溶液为 40.10 mL。另取 20.00 mL 上述混合溶液，准确加入 0.100 0 mol·L⁻¹ KMnO₄ 强碱性溶液 50.00 mL，使其完全反应后，调节至酸性，加入 0.200 0 mol·L⁻¹ Fe²⁺ 标准溶液 25.00 mL，反应后剩余的 Fe²⁺ 用上述 KMnO₄ 标准溶液滴定，消耗 10.90 mL。

**4-1**（2分）写出乙二醇与高碘酸钾反应生成碘酸钾的离子反应方程式；写出高碘酸钾与 KI 的离子反应方程式。

**4-2**（2分）写出强碱性介质中 HCOOH（甲酸盐）及乙二醇与 KMnO₄ 反应的离子方程式。

**4-3**（6分）计算试液中 HCOOH 和乙二醇的浓度各为多少。

### 答案

**4-1**

$$CH_2OHCH_2OH + IO_4^- \longrightarrow 2HCHO + IO_3^- + H_2O$$

$$IO_4^- + 2I^- + H_2O \longrightarrow IO_3^- + I_2 + 2OH^-$$

**4-2**

$$HCOO^- + 2MnO_4^- + 3OH^- \longrightarrow CO_3^{2-} + 2MnO_4^{2-} + 2H_2O$$

$$CH_2OHCH_2OH + 10MnO_4^- + 14OH^- \longrightarrow 2CO_3^{2-} + 10MnO_4^{2-} + 10H_2O$$

（电荷、H、O 均已核验守恒；碱性介质中 Mn +7→+6，每 mol KMnO₄ 得 1 e。）

**4-3**

第一步（高碘酸法）：CH₂OHCH₂OH ∼ IO₄⁻ ∼ I₂ ∼ AsO₃³⁻，20.00 mL 混合液中乙二醇：

$$n = \frac{40.10-14.30}{1000}\times0.05000 = 1.290\times10^{-3}\ \mathrm{mol}$$

浓度为 **0.06450 mol·L⁻¹**。

第二步（高锰酸钾法，电子守恒总账）：酸化后所有锰最终均被还原至 Mn²⁺，每 mol Mn 相当于 5 e。

- 首次加入 KMnO₄：5.000 mmol × 5 ＝ 25.00 mmol e；
- 返滴定消耗 KMnO₄：1.090 mmol × 5 ＝ 5.450 mmol e；
- Fe²⁺ 提供：5.000 mmol e。

有机物耗氧量 ＝ 25.00＋5.450−5.000 ＝ 25.45 mmol e。其中乙二醇 1.290 mmol × 10 e ＝ 12.90 mmol e，故 HCOOH：

$$n = \frac{25.45-12.90}{2} = 6.275\times10^{-3}\ \mathrm{mol}$$

浓度为 **0.3138 mol·L⁻¹**。

> **校勘注**：原书把返滴定体积换算重复乘以浓度（写成 0.100 0×0.001 090×5＝0.000 545；实际 10.90 mL×0.100 0 mol·L⁻¹ 已等于 1.090×10⁻³ mol），致总电子量误为 0.025 54、HCOOH 浓度误为 0.191 0 mol·L⁻¹。按电子守恒复算正确值为 0.313 8 mol·L⁻¹；乙二醇 0.064 50 mol·L⁻¹ 与原书一致。
