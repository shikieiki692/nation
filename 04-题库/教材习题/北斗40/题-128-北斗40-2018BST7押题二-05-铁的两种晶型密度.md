# 题-128-北斗40-2018BST7押题二-05-铁的两种晶型密度

> 来源：北斗学友40套全真模拟 · 2018年 BST7/押题营 全真模拟（二）第5题（8分）｜难度：4｜教学层级：竞赛

## 题目

铁有三种不同的晶型，改变温度可以相互转化。其中 α-铁为体心立方，γ-铁为立方最密堆积。画出这两种晶胞，确定每个晶胞中铁原子的数量 Z，并计算密度。已知铁半径为 126 pm。

### 答案

α-铁：体心立方（bcc），Z = 2：

![[88065bcbcb76a432013b0cfaa37af90615e246a2ca263bfda3d30813175db229.jpg]]

对于体心立方，√3a = 4r，Z = 2，则 a = 2.91×10⁻⁸ cm：

$$\rho = \frac{2\times55.85}{6.02\times10^{23}\times(2.91\times10^{-8})^3} = 7.53\ \mathrm{g\cdot cm^{-3}}$$

γ-铁：立方最密堆积（fcc），Z = 4：

![[6216fcc072778a00dc16be1eba4ab5e54d036dfc7a05e97cfb57df23a3794931.jpg]]

对于立方最密堆积，√2a = 4r，Z = 4，则 a = 3.56×10⁻⁸ cm：

$$\rho = \frac{4\times55.85}{6.02\times10^{23}\times(3.56\times10^{-8})^3} = 8.20\ \mathrm{g\cdot cm^{-3}}$$

（复算：bcc a = 4×126/√3 = 291 pm ✓；fcc a = 4×126/√2 = 356 pm ✓。）
