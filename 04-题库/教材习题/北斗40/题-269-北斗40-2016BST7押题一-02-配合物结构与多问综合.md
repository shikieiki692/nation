# 题-269-北斗40-2016BST7押题一-02-配合物结构与多问综合

> 来源：北斗学友40套全真模拟 · 2016年 BST7/押题营（一）第2题（19分）｜难度：5｜教学层级：竞赛

## 题目

**2-1**（3分）四氯化钛与三氯化磷可以形成八面体配合物，试画出其结构。

**2-2**（6分）生物正交反应由于其对生物体系的兼容性，目前已经成为重要的化学生物学研究手段。在相关领域的研究中，对蛋白质的修饰始终是研究的重点。2015 年，Bertozzi 等人报道了一种用硼试剂对氮氧键进行切断的反应，反应的二级速率常数达到 2.3×10³ L·mol⁻¹·s⁻¹，假设反应物浓度为 1 mol·L⁻¹，试计算反应完成 99% 所需时间。

**2-3**（2分）由于多糖结构的复杂性，糖类的合成一直是有机合成中极富挑战性的工作。2015 年，Kajihara 教授报道了一种由二触角糖（biantennary oligosaccharide）合成三触角糖（triantennary oligosaccharide）的思路。在一步选择性保护反应中，将化合物 3 用 PhCH(OMe)₂ 处理后，完成了化合物 3 中 8 个羟基的选择性保护工作，生成化合物 4。试分析选择性保护发生的原因。

![[e029183d1bd73f3bb4af2c8bb7d3d3bfc841205b800f1df0f33e963f16293a8f.jpg]]

（化合物 3：Asn 连接二触角复杂型寡糖；化合物 4：苯亚甲基缩醛选择性保护后的产物。）

**2-4**（4分）过去，科学家合成多肽多使用液相合成，即所有合成工作都在溶液中进行，合成工作十分烦琐复杂。1963 年，Merrifield 提出了多肽固相合成法，即将肽链的 C 端连在树脂上，进行不断的保护与脱保护，完成整个肽链的构筑。试分析多肽固相合成法相对于液相合成法的优势。同时，由于固相合成过程中需要使用强酸对保护基进行切断，加上固相合成本身的限制，导致了固相合成法不适合合成长肽链。试具体分析原因。

**2-5**（4分）锂硫电池因其超高的能量密度，成为未来极具前景的储能体系。硫/金属氧化物复合材料是目前的研究方向之一。这种电池有一个较大的问题，即充电过程中硫的体积会发生膨胀。为此，Seh 等人设计了一种蛋黄—蛋壳（yolk–shell）结构，在硫外覆盖了一层二氧化钛，有效解决了体积膨胀问题，电池寿命得到显著提高。试分析这种包覆结构的工作原理。

![[75d6c6cf75e1ed372908e7c116f3821fb381c3eaa3f18922cb7fc2ee41fe2d94.jpg]]

（硫颗粒 → TiO₂ 包覆 → 部分硫溶解后形成蛋黄—蛋壳空腔结构。）

### 答案

**2-1**

![[3d4601ce8cf89029063d26881e8768e2847d30d91d66b32e0274e3a5efa3421b.jpg]]

（原书答案图为双核结构：两个 Ti 各为八面体配位，彼此通过两对氯桥相连，每个 Ti 另以 OPCl₃ 以 O 端配位——即 [(TiCl₄)₂(μ-Cl)₂(OPCl₃)₂] 型骨架。）

（存疑照录：题面写「三氯化磷」，而原书答案图中配体明确含 P＝O（POCl₃）。PCl₃ 与 TiCl₄ 直接加合应为 P 端配位、无氧；答案图与之矛盾，可能原题为 POCl₃ 或 PCl₃ 在体系中已被氧化，待回源核对。）

**2-2**

对二级反应 A＋B → 产物（等浓度），速率方程 −dc/dt = k·c²，k＝2.3×10³ L·mol⁻¹·s⁻¹：

∫₁^0.01 −dc/c² = k∫₀^t dt

1/c₀ − 1/c = −kt，即 t = (1/0.01 − 1/1)/k = 99/(2.3×10³) ≈ 0.043 s

（校勘注：按积分式复算 t＝99/2300＝0.0430 s；原书答案 0.0433 s 在末位与自列积分式不符，疑笔误，径改为 0.043 s。）

**2-3**

可以生成稳定的六元环构象，产物热力学稳定（苯亚甲基缩醛以稳定的六元环锁住相应二醇，从而实现 8 个羟基的选择性保护）。

**2-4**

固相合成法相对液相合成法的优势：反应效率高，不需要复杂的分离纯化步骤（每步仅需过滤洗涤即可除去过量试剂与副产物）。

固相合成法缺点：使用强酸可能造成氨基酸消旋，且无法将两个固定在树脂上的肽链进行连接（或无法进行汇聚式合成），因此链越长累积损失越大，不适合合成长肽链。

**2-5**

S 内核与 TiO₂ 外壳中间有空隙，可以容纳硫的体积膨胀；TiO₂ 外壳的孔状结构可以限制多硫化物溶解；亲水性的 Ti—O 键可以与硫化物产生吸附作用进一步抑制扩散。（一点 2 分，答出两点即可得满分）
