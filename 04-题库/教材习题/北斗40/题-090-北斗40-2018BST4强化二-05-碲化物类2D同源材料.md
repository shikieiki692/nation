# 题-090-北斗40-2018BST4强化二-05-碲化物类2D同源材料

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（二）第5题（9分）｜难度：5｜教学层级：竞赛

## 题目

近期，科研人员合成了两种氧族元素的同源 2D 材料。两种材料由 Cs、Ag、Bi、Q（Q = Se 或 S）四种元素组成，其结构如下图所示。

![[b051959675c5365bd0108aa7ef4c7b20e5dea7fc8b1e2b51d622781ce9a3ba0e.jpg]]

![[b72c9b734709bc1bf0e3f356614ae03e5a9b711f047786d00ac44c9df9321cb0.jpg]]

**5-1**（4分）请在上图中标出两种结构的结构基元。

**5-2**（2分）请用 A(a)B(b)C(c) 等标注 Cs₁.₂Ag₀.₆Bi₃.₄S₆ 的堆积方式。

**5-3**（3分）已知 Cs₁.₂Ag₀.₆Bi₃.₄S₆ 为六方晶胞，a = 4.03 Å，c = 24.2 Å，Z = 1，请计算晶体密度。

### 答案

**5-1**

结构基元标注（黑色多边形簇为 [BiQ₄] 单元，晶胞框内为重复单元）：

![[247e347755d23583563e3d47ed2e6a2f4a7683940dee7579a80df8c976616ffd.jpg]]

![[534e6ad5168b43f8279b2593af8e3255e9dbe06360b9ede2a9f4322f78c29779.jpg]]

**5-2**

堆积方式：**A B a C a B A b a c a b A**（沿 c 轴的密堆积层序，大小写区分不同层内原子位置）。

**5-3**

$$\rho = \frac{1\times 1130.08}{(4.03\times10^{-8})^2\times 24.2\times10^{-8}\times 6.02\times10^{23}\times \sin 60°} = 5.52\ \mathrm{g\cdot cm^{-3}}$$

> **存疑说明（无法解释，照录原书）**：原书计算所用式量 1130.08 与题面化学式 Cs₁.₂Ag₀.₆Bi₃.₄S₆ 按相对原子质量加和（≈1100.8）不符；且题面化学式在 OCR 源中多处失真（如 Csₐ₆Agₐ₅Bi₂₂S₄、C₁=Ag₀.₆Bi₂S₄ 等），无法从现有信息裁定真实组成。密度值 5.52 g·cm⁻³ 照录原书答案，不作改数。
