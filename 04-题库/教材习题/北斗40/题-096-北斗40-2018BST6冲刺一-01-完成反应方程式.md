# 题-096-北斗40-2018BST6冲刺一-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（一）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

写出下列反应的化学（离子）方程式：

**1-1**（2分）亚硫酸银在沸水中分解。

**1-2**（2分）氟化硝酰与等物质的量的锌反应。

**1-3**（2分）在 175 °C 下，将粉末状的硝酸钠加入氨基化钠中，得到叠氮化钠。

**1-4**（2分）锰酸根在酸性条件下发生快速分解。

**1-5**（2分）四氯化锡、四氢铝锂和 Me₃SiCH₂SnCl₃ 反应得到 Sn₁₄Cl₆(CH₂SiMe₃)₁₂，产物无气体。

### 答案

**1-1**

$$2\mathrm{Ag_2SO_3} = \mathrm{Ag_2SO_4} + 2\mathrm{Ag}\downarrow + \mathrm{SO_2}\uparrow$$

（歧化：S(+4→+6) 失 2e，2Ag(+1→0) 得 2e ✓；Ag/S/O 计数全守恒。）

> **校勘注**：原书答案首式 OCR 排为「2Ag₂SO₄＝…」，按题面（亚硫酸银分解）应为 Ag₂SO₃；原书评分注「此处给出硫酸银沉淀扣 1 分」照录。

**1-2**

$$2\mathrm{NO_2F} + 2\mathrm{Zn} = \mathrm{ZnF_2} + \mathrm{ZnO} + \mathrm{N_2O}$$

> **存疑说明（无法解释，照录原书）**：原书答案 N 计数不平（左 2 右 1）；在「NO₂F 与锌等物质的量」约束下，逐一试遍 N₂O／N₂／N₂O₃ 与 ZnF₂-ZnO 分配组合，均无法同时满足元素守恒与电子守恒（N(+4→+1) 得 3e/个 与 Zn 失 2e/个 不匹配），无法给出自洽配平。存疑照录，待回源核对。

**1-3**

$$3\mathrm{NaNH_2} + \mathrm{NaNO_3} \xlongequal{175\ ^\circ\mathrm{C}} \mathrm{NaN_3} + 3\mathrm{NaOH} + \mathrm{NH_3}\uparrow$$

（实验室制叠氮化钠经典法。）

**1-4**

$$3\mathrm{MnO_4^{2-}} + 4\mathrm{H^+} = \mathrm{MnO_2}\downarrow + 2\mathrm{MnO_4^-} + 2\mathrm{H_2O}$$

（Mn(VI) 歧化：1 个 Mn(+6→+4) 得 2e，2 个 Mn(+6→+7) 失 2e ✓。）

> **校勘注**：原书 4H•（圆点）为 4H⁺ 之 OCR 误，已改。

**1-5**

$$48\mathrm{Me_3SiCH_2SnCl_3} + 8\mathrm{SnCl_4} + 19\mathrm{LiAlH_4} = 4\mathrm{Sn_{14}Cl_6(CH_2SiMe_3)_{12}} + 19\mathrm{LiCl} + 19\mathrm{AlCl_3} + 76\mathrm{HCl}$$

（自洽核验：Sn 56＝56 ✓；Cl 176＝24＋19＋57＋76＝176 ✓；C/Si 各 48 ✓；H 432＋96＋76＝604＝528＋76 ✓；Li/Al 各 19 ✓。）

> **校勘注**：题面「四氢钼锂」为「四氢铝锂（LiAlH₄）」之 OCR 误，已改。
