# 题-106-北斗40-2018BST6冲刺二-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

根据条件书写化学反应方程式：

**1-1**（2分）将 N₂O 通入 Na 的 NH₃（液氨）溶液中，得到比例为 3 : 2 的一种沉淀和一种气体，此外还得到一种易溶于液氨的化工产品。

**1-2**（2分）氯铂酸钾溶液与 SO₂ 作用，颜色由黄色转变为红色。

**1-3**（2分）重氮甲烷 H₂CN₂ 与 MnH(CO)₅ 反应生成一种羰基锰衍生物以及一种常见的气体。

**1-4**（2分）在 pH = 9.5 的 NH₃/NH₄⁺ 缓冲溶液中，以 Na₂H₂Y 溶液滴定其中的锌离子（H₆Y²⁺ 的 pKa1~6：0.9, 1.6, 2.0, 2.67, 6.16, 10.26）。

**1-5**（2分）PH₃ 在液氨中形成的溶液能导电，电解时在阳极析出白磷，写出电解反应方程式。

### 答案

**1-1**

$$3\mathrm{N_2O} + 4\mathrm{Na} + \mathrm{NH_3} = \mathrm{NaN_3} + 3\mathrm{NaOH}\downarrow + 2\mathrm{N_2}\uparrow$$

（守恒自核：Na 4、O 3、H 3、N 7 两侧全平；氧化数总账 Na 失 4e＝N 得 4e ✓。沉淀 NaOH : 气体 N₂ = 3 : 2 ✓；易溶于液氨的化工产品为叠氮化钠 NaN₃。）

**1-2**

$$\mathrm{K_2PtCl_6} + \mathrm{SO_2} + 2\mathrm{H_2O} = \mathrm{K_2PtCl_4} + \mathrm{H_2SO_4} + 2\mathrm{HCl}$$

（Pt(+4→+2) 得 2e，S(+4→+6) 失 2e ✓；红色物种为 K₂PtCl₄。）

**1-3**

$$\mathrm{H_2CN_2} + \mathrm{MnH(CO)_5} = \mathrm{N_2}\uparrow + \mathrm{Mn(CO)_5(CH_3)}$$

（重氮甲烷作甲基化试剂，HMn(CO)₅ 的 H 转移到卡宾碳。）

**1-4**

$$\mathrm{Zn(NH_3)_4^{2+}} + \mathrm{HY^{3-}} = \mathrm{ZnY^{2-}} + 3\mathrm{NH_3} + \mathrm{NH_4^+}$$

（pH 9.5 时 EDTA 主要以 HY³⁻ 形式存在；ZnY²⁻ 稳定，释放的 1 个质子由氨承接。）

**1-5**

$$4\mathrm{NH_4PH_2} \xlongequal{\text{电解}} \mathrm{P_4}\downarrow + 4\mathrm{NH_3} + 4\mathrm{H_2}\uparrow$$

阴极：4NH₄⁺ + 4e⁻ = 4NH₃ + 2H₂↑
阳极：4PH₂⁻ − 4e⁻ = P₄ + 2H₂↑

> **校勘注**：原书总式写作 4NH₄PH₂ = P₄ + 3H₂↑ + 4NH₃，H 计数不平（左 20 右 18）；按元素守恒总式应为 4H₂（两极半反应相加恰为上式），已径改。
