# 题-172-北斗40-2017BST6冲刺一-01-完成反应与终点电位

> 来源：北斗学友40套全真模拟 · 2017年 BST6/冲刺营（一）第1题（9分）｜难度：4｜教学层级：竞赛

## 题目

**1-1**（3分）向 [Cu(NH₃)₄]SO₄ 的水溶液中通入 SO₂ 至溶液呈微酸性，生成白色沉淀 Q，Q 中存在两种不同构型的原子团。试写出生成 Q 的离子方程式以及 Q 和硫酸混合加热的反应方程式。

**1-2**（2分）可以用已知浓度的 Ce⁴⁺ 溶液测定 Fe²⁺ 的含量。已知 φ°(Fe³⁺/Fe²⁺)＝0.77 V，φ°(Ce⁴⁺/Ce³⁺)＝1.45 V，试求滴定终点的溶液电位。

**1-3**（4分）含有 Cd(CN)₄²⁻ 的电镀废水和实验室含有 CN⁻ 的废液可以用漂白粉在碱性条件下进行无害化处理，试写出反应方程式，并说明在碱性条件下反应的原因。

### 答案

**1-1**

Q 为 Cu(NH₄)SO₃（白色沉淀，含 NH₄⁺ 与 SO₃²⁻ 两种原子团）：

$$2Cu(NH_3)_4^{2+} + 3SO_2 + 4H_2O = 2(NH_4)CuSO_3 + SO_4^{2-} + 6NH_4^+$$

$$2(NH_4)CuSO_3 + 4H^+ = Cu + Cu^{2+} + 2SO_2 + 2NH_4^+ + 2H_2O$$

（歧化：Cu(I) 一半被 SO₂ 还原为 Cu、一半氧化为 Cu²⁺。）

**1-2**

化学计量点时两电对电位相等，且 n₁＝n₂＝1：

$$\varphi_{sp} = \frac{\varphi^\circ(Fe^{3+}/Fe^{2+}) + \varphi^\circ(Ce^{4+}/Ce^{3+})}{2} = \frac{0.77+1.45}{2} = 1.11\ V$$

**1-3**

$$Cd(CN)_4^{2-} + 5Ca(ClO)_2 + 6OH^- = 4CaCO_3 + Cd(OH)_2 + Ca^{2+} + 2N_2 + 10Cl^- + 2H_2O$$

$$4CN^- + 5Ca(ClO)_2 + 4OH^- = 4CaCO_3 + Ca^{2+} + 2N_2 + 10Cl^- + 2H_2O$$

（两式电荷、Ca/C/N/Cl/O/H 均已核验守恒。）

碱性条件下反应的原因：酸性条件下 CN⁻ 会转化为剧毒气体 HCN 挥发逸出，污染空气且处理不完全；碱性条件保证氰以 CN⁻ 形式被彻底氧化为无毒的 N₂ 与 CO₃²⁻。
