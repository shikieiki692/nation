# 题-297-北斗40-2016BAT4二模-03-SnCl2水解与检验

> 来源：北斗学友40套全真模拟 · 2016年 BAT4/二模 大联考（四）第3题（12分）｜难度：4｜教学层级：竞赛

## 题目

化合物 A 是生产上和化学实验中广泛使用的还原剂，在水溶液中易水解成 B，A 和 C 常用来相互检验各自的存在，检验过程中先后生成两种沉淀。

**3-1**（3分）写出 A 的水解方程式和 C 及两种沉淀的化学式。

**3-2**（3分）A 的水解常常是不完全的，试说明原因。

**3-3**（3分）写出 A 的水溶液的配置步骤和常额外加入的固体物质。

**3-4**（3分）在碱性介质中，可用另一种物质检验 A 的阳离子，生成一黑色沉淀，试写出化学方程式。

### 答案

**3-1**

A 为 SnCl₂。水解方程式：

SnCl₂ + 2H₂O ═ Sn(OH)₂ + 2HCl（或 SnCl₂ + H₂O ═ Sn(OH)Cl + HCl）

C 为 HgCl₂（与 SnCl₂ 相互检验）；两种沉淀先后为 Hg₂Cl₂（白色）与 Hg（黑色/灰黑色）。

**3-2**

部分水解生成 Sn(OH)Cl 沉淀。

**3-3**

将 SnCl₂ 溶于浓盐酸后稀释；加入 Sn 粒（防止 Sn²⁺ 被空气氧化）。

**3-4**

2Bi³⁺ + 3Sn²⁺ ═ 2Bi + 3Sn⁴⁺

（铋酸钠法检验 Sn²⁺，生成的黑色沉淀为金属铋。）
