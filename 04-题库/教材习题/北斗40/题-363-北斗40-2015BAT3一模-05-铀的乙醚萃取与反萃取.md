# 题-363-北斗40-2015BAT3一模-05-铀的乙醚萃取与反萃取

> 来源：北斗学友40套全真模拟 · 2015年 BAT3/一模（三）第5题（10分）｜难度：5｜教学层级：竞赛

## 题目

铀的提取在原子能工业中具有重要意义，目前从溶液中提取铀主要用溶剂萃取法。铀的化合物中硝酸铀酰最早被发现可以用乙醚萃取，在酸度不太高时，铀主要以中性的硝酸铀酰分子进入醚中。请根据所给信息，回答下列问题。

**5-1** 已知：

UO₂²⁺ + NO₃⁻ ⟶ UO₂(NO₃)⁺　K₁ ＝ 2.93

UO₂(NO₃)⁺ + NO₃⁻ ⟶ UO₂(NO₃)₂　K₂ ＝ 0.0100

UO₂²⁺(aq) + 2NO₃⁻(aq) ⟶ UO₂(NO₃)₂(o)　K ＝ 0.115

其中，o 表示在有机相中。现有 0.100 mol·L⁻¹ 的 UO₂Cl₂ 溶液，其中有 0.100 mol·L⁻¹ HNO₃ 以维持其酸度，加入 NaNO₃ 固体使硝酸根浓度达到 1.00 mol·L⁻¹。现用乙醚萃取水相中的铀（体积比 1:1），请运用适当的近似，计算在这一条件下醚层中铀的浓度以及分配比（乙醚∶水）。

**5-2** 已知在高浓度的 NO₃⁻ 存在下，UO₂²⁺ 也可以形成 UO₂(NO₃)₃⁻。请解释为什么在高浓度 NO₃⁻ 存在下，铀元素的萃取效率下降。已经观察到若在高浓度 NO₃⁻ 的环境同时提高酸度，铀的分配比会有所提高，请给出解释。

**5-3** 在乙醚中的铀随后可被高浓度的硫酸钠溶液反萃取回水相，从而得到铀在水中的溶液，便于进行后续处理。已知：

UO₂²⁺ + SO₄²⁻ ⟶ UO₂(SO₄)　K₁ ＝ 50.0

UO₂(SO₄) + SO₄²⁻ ⟶ UO₂(SO₄)₂²⁻　K₂ ＝ 7.00

UO₂(SO₄)₂²⁻ + SO₄²⁻ ⟶ UO₂(SO₄)₃⁴⁻　K₃ ＝ 7.20

若第一问中的乙醚溶液经过洗涤之后，铀物种的浓度未变，现用 1:1 体积的 1.00 mol·L⁻¹ 的 Na₂SO₄ 溶液处理，请计算醚层中剩余的铀物种浓度。

> **校勘注（题面）**：5-2 原书（题面与答案均）写作「UO₂(NO₃)⁻」，电荷不平衡（UO₂²⁺＋NO₃⁻ 应为 +1）；按其化学语境（高浓度 NO₃⁻ 下 UO₂²⁺ 继续配位生成阴离子）径正为 **UO₂(NO₃)₃⁻**（UO₂²⁺＋3NO₃⁻＝−1，与答案「硝酸根与乙醚竞争 UO₂(NO₃)₂ 生成…」相符）。5-3 三式原书 OCR 产物写作「UO₂(SO₄)₂ / UO₂(SO₄)₂ / UO₂(SO₄)₂²⁻」，按电荷守恒径正为 UO₂(SO₄)（中性，一硫酸根）、UO₂(SO₄)₂²⁻（二硫酸根）、UO₂(SO₄)₃⁴⁻（三硫酸根）。

### 答案

**5-1**（5分）

UO₂²⁺ + 2NO₃⁻ ⟶ UO₂(NO₃)₂；β₂ ＝ K₁K₂ ＝ 2.93×0.0100 ＝ 0.0293

由于 β₂ 太小，即使按不发生其他配位反应计算，UO₂(NO₃)₂ 浓度也仅有 c(UO₂²⁺)·c(NO₃⁻)β₂ ＝ 0.00293 (mol·L⁻¹)，因此这一物种可以忽略不计。

设平衡时有机相中 UO₂(NO₃)₂ 浓度为 c mol·L⁻¹，列出物料平衡式：

[UO₂²⁺] + [UO₂(NO₃)⁺] ＝ 0.1 − c　；　[UO₂(NO₃)⁺] + [NO₃⁻] ＝ 1 − 2c

由于 UO₂²⁺(aq) + 2NO₃⁻(aq) ⟶ UO₂(NO₃)₂(o) 的 K 太小，即使仅考虑初始情况，有机相中 UO₂(NO₃)₂ 浓度也仅为 K·c(UO₂²⁺)·c(NO₃⁻) ＝ 0.0115 (mol·L⁻¹)，对硝酸根浓度的影响可以忽略。

因此硝酸根的物料平衡式可以改写为：[UO₂(NO₃)⁺] + [NO₃⁻] ＝ 1

利用铀的分布系数求解这一方程：δ_[UO₂(NO₃)₂]·c(U) + [NO₃⁻] ＝ 1；K₁[NO₃⁻]/(1+[NO₃⁻])·(0.1−c) + [NO₃⁻] ＝ 1

整理得：c ＝ (K₁[NO₃⁻]² + (1−0.9K₁)[NO₃⁻] − 1) / (K₁[NO₃⁻])

由 K ＝ [UO₂(NO₃)₂(o)] / ([UO₂²⁺][NO₃⁻]²) ＝ c / ((0.1−c)δ_(UO₂²⁺)[NO₃⁻]²) ＝ 1 / ((0.1/c − 1)δ_(UO₂²⁺)[NO₃⁻]²)

**5-2**（2分）

> 原书 OCR 此处误标为「第4题（9分）」，实为第 5 题之续（5-2）。

整理得：(1 − [NO₃⁻])[NO₃⁻]² / (K₁[NO₃⁻]² + (1 − 0.9K₁)[NO₃⁻] − 1) ＝ 1/K

解得：[NO₃⁻] ＝ 0.9288 mol·L⁻¹（可用迭代法解，以二次项做迭代）

c ＝ (K₁[NO₃⁻]² + (1−0.9K₁)[NO₃⁻] − 1) / (K₁[NO₃⁻]) ＝ (2.93×0.9288² + (1−0.9×2.93)×0.9288 − 1) / (2.93×0.9288) ＝ 2.64×10⁻³ (mol·L⁻¹)

D ＝ c/(0.1−c) ＝ 2.64×10⁻³ / (0.100 − 2.64×10⁻³) ＝ 0.0271

（结果每个 1 分，有适当近似 1 分，计算过程 2 分）

也可采用忽略萃取对水相铀浓度影响的方法，计算出水相的有关离子浓度，最后验证近似的合理性。此时 [NO₃⁻] ＝ 0.9269 mol·L⁻¹，c ＝ 2.59×10⁻³ mol·L⁻¹，D ＝ 0.0266，差别不大，得分参考上述过程。

由于高浓度硝酸根存在时，硝酸根与乙醚竞争水相中的 UO₂(NO₃)₂ 生成 UO₂(NO₃)₃⁻，导致与有机相平衡的 UO₂(NO₃)₂ 浓度降低，使铀元素的萃取效率下降。（1 分）

酸度非常高时，乙醚可以形成氧鎓盐，与高浓度硝酸根中的 UO₂(NO₃)₃⁻ 结合，将其带入有机相中，使萃取的分配比提高。（1 分）

**5-3**（3分）

由于已知三个反应的平衡常数都很大，且硫酸根大大过量，故可以近似为所有铀都已进入水相。

由于硫酸根远大于 c(U) 三倍，故水相可近似认为只有二硫酸根和三硫酸根两种配合物存在，一硫酸根配合物与游离铀酰离子浓度可忽略。

列出物料平衡等式：2[UO₂(SO₄)₂²⁻] + 3[UO₂(SO₄)₃⁴⁻] + [SO₄²⁻] ＝ 1.00

用分布系数改写：c(U)·(2β₂[SO₄²⁻]² + 3β₃[SO₄²⁻]³)/(1 + β₂[SO₄²⁻]² + β₃[SO₄²⁻]³) + [SO₄²⁻] ＝ 1.00

由于水相与有机相体积比 1:1，因此 c(U) ＝ [UO₂(NO₃)₂(o)] ＝ 2.64×10⁻³ mol·L⁻¹

由于 β₂[SO₄²⁻]² ≫ 1、β₃[SO₄²⁻]³ ≫ 1，故分母中的 1 可以忽略。

2.64×10⁻³ · (2β₂ + 3β₃[SO₄²⁻])/(β₂ + β₃[SO₄²⁻]) + [SO₄²⁻] ＝ 1.00

化简，得：2.64×10⁻³ · (3 − 1/(1 + K₃[SO₄²⁻])) + [SO₄²⁻] ＝ 1.00

解得：[SO₄²⁻] ＝ 0.9924 mol·L⁻¹

δ_[UO₂(SO₄)] ＝ β₁[SO₄²⁻] / (1 + β₁[SO₄²⁻] + β₂[SO₄²⁻]² + β₃[SO₄²⁻]³) ＝ 0.0174

因为 [UO₂(SO₄)₂²⁻] 比例很小，因此近似是合理的。

δ_(UO₂²⁺) ＝ 1 / (1 + β₁[SO₄²⁻] + β₂[SO₄²⁻]² + β₃[SO₄²⁻]³) ＝ 3.50×10⁻⁴

[UO₂²⁺] ＝ δ_(UO₂²⁺)·c(U) ＝ 3.50×10⁻⁴ × 2.64×10⁻³ ＝ 9.24×10⁻⁷ mol·L⁻¹

因为 UO₂²⁺ 浓度很小，且硝酸根配合物的稳定常数很小，故硝酸根的配位可忽略。

[NO₃⁻] ＝ 2[UO₂(NO₃)₂(o)] ＝ 2 × 2.64×10⁻³ ＝ 5.28×10⁻³ mol·L⁻¹

[UO₂(NO₃)₂(o)]₂ ＝ K[UO₂²⁺][NO₃⁻]² ＝ 0.115 × 9.24×10⁻⁷ × (5.28×10⁻³)² ＝ 2.96×10⁻¹² mol·L⁻¹

（结果 1 分、过程 2 分）

若第一问结果为 c ＝ 2.59×10⁻³ mol·L⁻¹，则对应的 [SO₄²⁻] ＝ 0.9925 mol·L⁻¹，δ_(UO₂²⁺) ＝ 3.50×10⁻⁴，[UO₂²⁺] ＝ 9.06×10⁻⁷ mol·L⁻¹，[UO₂(NO₃)₂(o)]₂ ＝ 2.80×10⁻¹² mol·L⁻¹。（评分标准同上）

> **校勘注（答案）**：
> ① 末式原书 OCR 作「(5.28×10⁻¹)²」，按上文 [NO₃⁻]＝5.28×10⁻³ 径正为 (5.28×10⁻³)²，复算 0.115×9.24×10⁻⁷×(5.28×10⁻³)²＝2.96×10⁻¹² ✓；
> ② 全链复算：β₂＝K₁K₂＝0.0293 ✓；[NO₃⁻]＝0.9288 代入得 c＝2.64×10⁻³、D＝c/(0.1−c)＝0.0271 ✓；5-3 [SO₄²⁻]＝0.9924 回代 2.64×10⁻³·(3−1/(1+7.20×0.9924))＋0.9924＝1.000 ✓；δ 两值与 [UO₂²⁺] 复算全部吻合 ✓。
