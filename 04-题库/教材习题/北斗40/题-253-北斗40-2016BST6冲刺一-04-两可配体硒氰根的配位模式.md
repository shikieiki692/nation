# 题-253-北斗40-2016BST6冲刺一-04-两可配体硒氰根的配位模式

> 来源：北斗学友40套全真模拟 · 2016年 BST6/冲刺营（一）第4题（6分）｜难度：5｜教学层级：竞赛

## 题目

拥有两个配位原子的单齿配体称为两可配体，例如硫氰根。与硫氰根类似，硒氰根也是一种两可配体，根据配位化学的知识回答下列问题。

**4-1**（2分）请画出 Pd²⁺、dien（二乙三胺）、硒氰根形成的络合物离子的结构，并解释原因。

**4-2**（4分）当将 dien 换成 Et₄dien（1,1,7,7-四乙基二乙三胺）后，形成的络合物离子 [Pd(Et₄dien)(SeCN)]⁺ 在 DMF 溶液中刚开始只有一个代表硒氰根的 C—N 伸缩振动峰，位于 2125 cm⁻¹ 处，一段时间过后在 2089 cm⁻¹ 处出现了一个新的峰，并且在 2125 cm⁻¹ 处的峰高度下降，请解释该现象说明了什么，以及该现象出现的原因。

### 答案

**4-1**

[Pd(dien)(SeCN)]⁺ 结构（dien 三齿 N 配位，硒氰根以 Se 原子弯曲型配位）：

![[4e3282c39df2a77cf660b64d2484cbb7418c298bd5a5e324f1df60c9563faf38.jpg]]

（硒氰根配位若没有画成弯曲型，得 1 分。）

Pd²⁺ 为软酸，硒氰根以 Se 原子配位时为软碱，以 N 原子配位时为硬碱，根据软硬酸碱理论的「软亲软，硬亲硬」原理，硒氰根以 Se 原子与 Pd²⁺ 配位在能量上更加有利。（1 分，提到「软亲软，硬亲硬」即得 0.5 分。）

**4-2**

产生了新的 C—N 伸缩振动峰，说明出现了另一种配位形式的硒氰根，也即 [Pd(Et₄dien)(NCSe)]⁺ 的生成，硒氰根中的 N 原子与 Pd²⁺ 进行配位。（1 分）

因为 Et₄dien 的位阻远大于 dien，（0.5 分）不利于硒氰根用 Se 原子进行弯曲型配位，而直线型的 N 原子配位模式由于位阻较小更具有优势，（1 分）因此硒氰根逐渐从 Se 原子配位转变为 N 原子配位，形成了一种新的络合物离子。硒氰根使用 N 原子进行配位，使得 C 和 N 之间的键被削弱，导致波数降低。（0.5 分。）
