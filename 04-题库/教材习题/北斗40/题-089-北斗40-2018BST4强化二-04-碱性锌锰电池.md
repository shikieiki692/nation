# 题-089-北斗40-2018BST4强化二-04-碱性锌锰电池

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（二）第4题（8分）｜难度：4｜教学层级：竞赛

## 题目

**4-1**（3分）众所周知，电池分为一次性电池与可充电电池。有一种典型的一次性电池为碱性锌锰电池，其负极为锌，正极为二氧化锰，电解质为氢氧化钾，请给出其电极反应和电池反应。

**4-2**（5分）已知 φθ(Zn²⁺/Zn) = −0.76 V，Ksp[Zn(OH)₂] = 1.2×10⁻¹⁷，φθ(MnO₂/MnOOH) = 0.24 V，φθ(O₂/H₂O) = 1.23 V，假定 pH = 14，请分析充电时的电极反应，并解释为何碱性锌锰电池不能充电。

### 答案

**4-1**

负极：Zn − 2e⁻ + 2OH⁻ = Zn(OH)₂

正极：MnO₂ + e⁻ + H₂O = MnOOH + OH⁻

电池反应：Zn + 2MnO₂ + 2H₂O = Zn(OH)₂ + 2MnOOH

**4-2**

由数据可以计算（pH = 14，即 c(OH⁻) = 1 mol·L⁻¹）：

$$\varphi(\mathrm{H^+/H_2}) = 0 - 0.0592\times 14 = -0.83\ \mathrm{V}$$

$$\varphi^\theta[\mathrm{Zn(OH)_2/Zn}] = -0.76 + \frac{0.0592}{2}\lg(1.2\times10^{-17}) = -1.26\ \mathrm{V}$$

$$\varphi(\mathrm{O_2/OH^-}) = 1.23 - 0.0592\times 14 = 0.40\ \mathrm{V}$$

充电时：

- 阳极（原正极）：由于 φ(MnO₂/MnOOH) = 0.24 V < φ(O₂/OH⁻) = 0.40 V，氧化 MnOOH 之前 OH⁻ 已优先被氧化析出 O₂（且析氧过电位下实际更早），阳极主要发生析氧副反应，无法有效再生 MnO₂；
- 阴极（原负极）：由于 φ(H₂/H₂O) = −0.83 V > φ[Zn(OH)₂/Zn] = −1.26 V，沉积 Zn 之前 H₂O 已优先被还原，**阴极生成氢气**，这会产生爆炸危险。

因此碱性锌锰电池充电时两极均为副反应主导（析氧/析氢），无法实现有效的充放电循环，故为一次性电池。
