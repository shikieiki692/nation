# 题-107-北斗40-2018BST6冲刺二-02-亚硝酰茂铁二聚体推断

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第2题（8分）｜难度：5｜教学层级：竞赛

## 题目

某金属有机配合物分子含有 1 个 C₂ 轴和一个垂直于 C₂ 的对称面。该配合物由五种元素构成，分子中有且仅有 2 种配体，其中之一为一种常见的有机配体（其中 C : H 的比例为 1 : 1），另一种为常见无机顺磁性小分子配体，而金属元素在该配合物中的质量分数为 37.00%，其金属元素是棕色环实验的主角，而且是人类最早使用的 7 种金属元素之一。

**2-1**（2分）通过计算及推理得到配合物的配体、中心金属元素。

**2-2**（3分）试通过该配合物的对称性，画出该配合物的结构。

**2-3**（3分）试通过计算解释为何中心金属原子满足 18 电子，在算式中表明电子的来源，并指出中心原子的价态。

### 答案

**2-1**

方法1：从题目中给出的 C : H 的比例为 1 : 1，而且又是常见的有机配体，可以确定有机配体不是环戊二烯负离子就是苯。而常见的无机顺磁性小分子，最常见的是 NO、O₂，而且 O₂ 作为配体很少见，故排除。而从金属元素是棕色环实验的主角可以确定金属元素是铁。然后根据算式讨论：

$$\frac{55.85}{55.85 + 30.01\times n + (12.01+1.008)\times x} = 0.3700$$

当 n = 1 时，x 恰好等于 5，得出答案：金属元素为 **Fe**，无机配体为 **NO**，有机配体为 **C₅H₅⁻（环戊二烯负离子）**。

方法2：由于分子含有 1 个 C₂ 轴和一个垂直于 C₂ 的对称面，所以分子对称性好。1 个 Fe 对应 1 个 NO 的话，直接推出余下 95 的式量，根据碳氢比可知为环戊二烯负离子。

**2-2**

[(η⁵-C₅H₅)Fe(NO)]₂：两个 Cp 环反向（非交叉式），Fe—Fe 键相连，2 个 NO 桥式配位（C₂ 对称）：

![[4bbda6ab290889a581f6b387f7f43f2b0691e0130fc4048dc597c83cfd0f86a3.jpg]]

（注：两个环戊二烯基不画成交叉式不给分；Fe 与 Fe 间化学键是否画出不影响得分。）

**2-3**

中心铁为 **+1 价**（NO⁺ 为 3e 给体时）或按 +2 价计（NO 作 2e 给体）的两种 18e 计算均成立：

![[cc82ade85ded849c1856c1b09cc6813848cd83bc6509c21373c519df1c512370.jpg]]

![[b7ab075ac138cb70e14139e1e3b2ea2948a76fd7347f61760930ecc256b20fe8.jpg]]

算法一（Fe 自身 6e＋环戊二烯负离子 6e＋2NO 各 2e＋Fe—Fe 键 2×2e = 18）；算法二（Fe 自身 8e＋Cp 6e＋2NO 2e＋Fe—Fe 2×2e = 18）。按算法二中心铁为 **+2 价**。
