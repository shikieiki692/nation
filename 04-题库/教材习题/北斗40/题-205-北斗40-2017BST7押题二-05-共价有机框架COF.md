# 题-205-北斗40-2017BST7押题二-05-共价有机框架COF

> 来源：北斗学友40套全真模拟 · 2017年 BST7/押题营（二）第5题（11分）｜难度：5｜教学层级：竞赛

## 题目

自 2005 年被发现以来，共价有机框架（COF）材料已经成为重要的研究领域，由于大量孔道的存在，这种材料被广泛应用在气体存储、物质分离、催化等领域。

**5-1**（1分）请写出 COF 的英文全称。

**5-2** 2016 年，来自中科院上海有机所的研究人员报道了一种合成具有大小孔道的 COF 材料的策略。文章中总共涉及了四种有机小分子，分别为 X(ETTA)、TPA、BDPA、TPDA。X 的化学式为 C₂₆H₂₄N₄。产物 COF 的结构可以用下图简单表示，其中三角形 A 和 B 的边长由于选用小分子底物的差异，可能会不同，但是三个 A、B 的边长是一致的。实验中使用的三种小分子底物的结构也一并给出。

TPA OHC-CHO；BPDA OHC-C₆H₄-CHO；TPDA OHC-C₆H₄-C₆H₄-CHO

![[e6e469fe7450f23b763f4e03c05ac669cce7815875af7facf7e5928afa73ebe3.jpg]]

**5-2-1**（2分）请给出 X 的结构。

**5-2-2**（2分）请在答题框中给出的 COF 结构中画出其结构单元。

![[ed42217ce17a47ff02cc82b8b469ee3f5dbab1950707708f7e7008a507a90a5a.jpg]]

**5-2-3**（2分）在文献中，研究人员合成了四种 COF 材料，其反应原料和结构单元的边长总结如下，请推测 SIOC-COF-1 与 SIOC-COF-2 的结构单元边长。

**5-2-4**（2分）请指出 COF-BPDA 属于什么点群。

**5-2-5**（2分）请判断，合成 SIOC-COF-1 时，三种原料的投料比。

### 答案

**5-1**

Covalent Organic Framework。

**5-2-1**

X(ETTA) 为四(4-氨基苯基)乙烯：

![[d8b4517383bf48b9f19e8c4fb60c852ca9de84422ebddedc8d60ff850682b184.jpg]]

**5-2-2**

结构单元（一个 ETTA 节点与三个醛配体构成的菱形重复单元，其他合理答案也可以给分）：

![[ba9522cf1c1a443adb1fda637782d568403e5a5261cc88d76bb410ca220f4b4c.jpg]]

**5-2-3**

SIOC-COF-1：(46.83＋55.29)/2＋46.83−46.83 → 按原书口径 SIOC-COF-1 边长＝(46.83−55.29)/2＋46.83＝42.60 Å；SIOC-COF-2：(46.83＋55.29)/2＝51.06 Å。

**5-2-4**

COF-BPDA 为 D₂h 点群。

**5-2-5**

ETTA:TPA:BPDA＝1:1:1（每个 ETTA 节点连 3 个醛单元，三角形 A、B 交替，按节点：顶点化学计量 1:1:1）。
