# 题-314-北斗40-2015BST4强化二-03-Bi9O7.5S6层状晶体结构

> 来源：北斗学友40套全真模拟 · 2015年 BST4/强化营（二）第3题（14分）｜难度：5｜教学层级：竞赛

## 题目

Bi₉O₇.₅S₆ 的晶体结构很有特点，可以看作是由 [Bi₂O₂] 和 [BiS₂] 的层状结构沿 c 轴交替堆叠而成。晶体属三方晶系，a＝4.068 Å，c＝31.03 Å。

![[c206f2d836c3d70687e885323bd3db0ddca92784ccf08e405fd06924e2b81c2c.jpg]]

**3-1**（2分）在 [BiS₂] 层中，Bi 与 S 以 BiS₆ 八面体形式存在，则 Bi 的配位数为多少？BiS₆ 八面体之间如何连接？每个 S 原子由几个八面体共用？

**3-2**（3分）画出 [BiS₂] 层沿 c 轴的投影图，注意区分不同的层。

**3-3**（4分）[Bi₂O₂] 层的情况要复杂一些，其框架如右图所示，其中有两种化学环境的 O 原子，记为 O1、O2。其中，O1 与 Bi₂ 一同构成了畸变的六方棱柱骨架，O2 居于其中心。现在，试求 O2 占据这样的六方棱柱中心的占有率，并说明 Bi₂ 的配位情况。

![[0a461a67697ccb95a0ae74cac01a81575a5586581762643ba72e91f3e1b16e8c.jpg]]

**3-4**（3分）已知 Bi₂—O1 的间距为 2.399 Å，假设每个 O1 周围均为正四面体，试求 Bi₂—O2 的间距。

**3-5** 计算此晶体的密度。

### 答案

**3-1**

Bi 配位数为 6，共棱 3 个。（每个 S 原子由 3 个八面体共用。）

**3-2**

![[32811d7267224a6b3c15997a9712c033e127702e37bb58aabe9cd6f8ebd0f757.jpg]]

（[BiS₂] 层沿 c 轴投影：BiS₆ 八面体共棱成层，图中区分上下不同层。）

**3-3**

![[e3ddaf72e6140a8ffb1164a83001fa4c329df09a93d04eb23c7bd76304697831.jpg]]

每个六方棱柱边缘的原子形成该层的 [Bi₂O₂] 骨架，而仅共用周围一圈的面形成二维结构，顶面和底面不共用。如若向周围扩展，可以发现每个顶点原子被三个这样的六方棱柱共用。故每个六方棱柱的化学式即为 [Bi₂O₂]。读图，整个晶胞由三层 [BiS₂] 与三层 [Bi₂O₂]，应有化学式 Bi₉O₆S₆，而实际化学式为 Bi₉O₇.₅S₆，多出来的 1.5 个 O 正是 [Bi₂O₂] 层的填隙原子 O2，平均到每层的化学式为 [Bi₂O₂.₅]，多 0.5 个 O。而每个 [Bi₂O₂] 六方棱柱有一个空隙，所以六方棱柱中心的占有率为 0.5/1＝50%。

每个 Bi₂ 与 4 个 O1 和 3 个 50% 概率的 O2（或 1.5 个 O2）配位。

**3-4**

其实就是对顶点两 Bi 原子间距的一半。灵活利用 O1 原子在周围四个 Bi 原子的四面体中心，以及底面或顶面的三个 Bi 原子构成一个正三角形，其边长正是 BiO1 四面体的边长。可算得间距＝2.770 Å。

**3-5**

ρ ＝ ZM/(NA·V) ＝ 8.190 g·cm⁻³

（复算：三方晶胞 V＝a²c·sin120°＝4.068²×31.03×0.866＝444.8 Å³；M(Bi₉O₇.₅S₆)＝9×209＋7.5×16＋6×32.07＝2193.4；Z＝1 时 ρ＝2193.4/(6.022×10²³×4.448×10⁻²²)＝8.19 g·cm⁻³ ✓。）
