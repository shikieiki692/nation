# 题-234-北斗40-2016BST4强化一-03-钙钛矿偏离结构与卤钠石

> 来源：北斗学友40套全真模拟 · 2016年 BST4/强化营（一）第3题（16分）｜难度：5｜教学层级：竞赛

## 题目

钙钛矿型结构作为 ABX₃ 化合物经常采取的晶体结构，在许多常见物种中都有所体现。

**3-1**（2分）通常地，我们用 A 指代大阳离子，B 指代小阳离子，X 指代阴离子。试用堆积-填隙模型描述钙钛矿的晶体结构。

**3-2**（3分）1990 年，我国首次在内蒙古巴彦诺尔盐湖发现矿物卤钠石（$[\mathrm{FClNa_6}](\mathrm{SO_4})_2$），其结构可以用下图来描述。试说明其与钙钛矿结构的联系，并给出其一个正当晶胞的组成。

![[99f4e01a07299554994d505d04c647beb9cead395f99d76d9f69650c49ebe9a4.jpg]]

**3-3**（2分）对于钙钛矿结构，可以定义容忍因子

$$
t = \frac{r_A + r_X}{\sqrt{2}\,(r_B + r_X)}
$$

试通过计算说明，对于理想的钙钛矿型结构，容忍因子 t 应为多少？

**3-4**（4分）容忍因子 t 太小或太大均会导致钙钛矿型结构发生对于理想结构的偏离。常见的偏离情况有以下两种。试描述它们与钙钛矿型结构的关联，并给出所属晶系。

![[01328d8f328380bd08a8cf029afe3fffdac8318e11fc2b481067490df3a624e9.jpg]]

**3-5**（2分）判断容忍因子 t 的大小分别对应上述两图的哪一种结构偏离。

**3-6**（3分）计算 SrTiO₃ 和 GdFeO₃ 所属结构。（离子半径：Sr²⁺ 144 pm，Ti⁴⁺ 61 pm，Gd³⁺ 111 pm，Fe³⁺ 78 pm，O²⁻ 140 pm）

### 答案

**3-1**

大阳离子 A 与阴离子 X 一同做 ccp 密堆积。（1 分）

小阳离子 B 则在仅由阴离子 X 构成的八面体空隙中（占据所有八面体空隙的 1/4）。（1 分）

**3-2**

$\mathrm{Na^+}$（作 A 位，与 $\mathrm{SO_4^{2-}}$ 一同密堆积）、$\mathrm{SO_4^{2-}}$（作 X）、$[\mathrm{ClNa_6}]$ 八面体单元（Cl⁻ 居中、Na⁺ 占八面体空隙——相当于「双重钙钛矿」）：

$$
[\mathrm{FClNa_6}](\mathrm{SO_4})_2
$$

（正当晶胞组成即一个化学式单元：$\mathrm{Na_6FCl(SO_4)_2}$。）

**3-3**

理想结构、A 与 X 相切，B 与 X 相切：

$$
r_A + r_X = \frac{a\sqrt{2}}{2},\qquad r_B + r_X = \frac{a}{2}
$$

代入定义式：$t = \dfrac{a\sqrt{2}/2}{\sqrt{2}\,(a/2)} = 1$。

**3-4**

左图：沿 c 轴方向，$[\mathrm{BX_6}]$ 八面体发生有序倾斜——四方晶系（2 分）。

右图：A 与 X 一同做 hcp 堆积（钙钛矿结构是 ccp），B 仍填在 X 的八面体空隙当中——六方晶系（2 分）。

**3-5**

容忍因子 t 大，可以理解为 A 位阳离子较大，从而需要周围有更多的空间，对应右图的结构偏离情况；t 小，A 位阳离子较小，周围空间也更小，对应左图的偏离情况。（可以计算得到 $[\mathrm{AX_{12}}]$ 配位多面体在八面体发生倾斜后体积减小；只要求结论，各 1 分。）

**3-6**

$\mathrm{SrTiO_3}$：$t = \dfrac{144+140}{\sqrt{2}\,(61+140)} = \dfrac{284}{284.3} = 1.00$，理想的钙钛矿型结构。

$\mathrm{GdFeO_3}$：$t = \dfrac{111+140}{\sqrt{2}\,(78+140)} = \dfrac{251}{308.3} = 0.81$，t 太小的偏离结构，如试题左图。

（计算 1 分，结论 0.5 分，各 1.5 分。）
