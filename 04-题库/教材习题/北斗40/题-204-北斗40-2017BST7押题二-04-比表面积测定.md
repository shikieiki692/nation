# 题-204-北斗40-2017BST7押题二-04-比表面积测定

> 来源：北斗学友40套全真模拟 · 2017年 BST7/押题营（二）第4题（11分）｜难度：5｜教学层级：竞赛

## 题目

为了测定活性炭粉末的比表面积，实验人员设计了如下实验过程：

(1) 准确称量 5.1132 g 邻苯二甲酸氢钾，溶于去离子水，用 250 mL 容量瓶定容。

(2) 配置 0.1 mol·L⁻¹ 的 NaOH 溶液，用移液管移取 25.00 mL 邻苯二甲酸氢钾溶液于锥形瓶，加入去离子水与两滴酚酞，用 NaOH 溶液滴定，平行三次，分别消耗 23.08 mL、23.09 mL、23.07 mL。

(3) 完成对 NaOH 溶液的标定后，用移液管移取 25.00 mL 乙酸溶液于锥形瓶，加入去离子水与两滴酚酞，用 NaOH 溶液标定，平行三次，分别消耗 21.11 mL、21.13 mL、21.22 mL。

(4) 用移液管量取 25.00 mL 乙酸溶液于小烧杯，加入 1.0788 g 活性炭吸附，之后取 10.00 mL 溶液至锥形瓶，加入少量去离子水稀释，用 NaOH 溶液滴定，消耗 5.77 mL。

**4-1**（6分）请计算活性炭粉末比表面积 S，已知乙酸分子表面积为 2.43×10⁻¹⁹ m²。（单位 m²/g）

**4-2**（1分）如果邻苯二甲酸氢钾在实验前没有烘干，那么对于测定的比表面积会____。
A. 偏大　　B. 不变　　C. 偏小

**4-3**（2分）请判断该体系是否适合氧化铝的比表面积测定，并说明理由。

**4-4**（2分）该体系中乙酸的浓度不可以太高或太低，不然实验可能存在较为明显的系统误差，请分析误差来源。

### 答案

**4-1**

$$c(KHP) = \frac{5.1132}{204.22\times0.2500} = 0.1002\ \mathrm{mol\cdot L^{-1}}$$（1分）

$$c(NaOH) = \frac{0.1002\times25.00\times10^{-3}}{\frac{23.08+23.09+23.07}{3}\times10^{-3}} = 0.1085\ \mathrm{mol\cdot L^{-1}}$$（1分）

$$c(HAc) = \frac{0.1085\times25.00\times10^{-3}}{\frac{21.11+21.13+21.22}{3}\times10^{-3}} = 0.1284\ \mathrm{mol\cdot L^{-1}}$$（1分）

吸附后残液（10.00 mL 计）：

$$c'(HAc) = \frac{0.1085\times5.77\times10^{-3}}{10.00\times10^{-3}} = 0.0626\ \mathrm{mol\cdot L^{-1}}$$（1分）

$$\Delta c = 0.1284-0.0626 = 0.0658\ \mathrm{mol\cdot L^{-1}},\quad n = 0.0658\times25.00\times10^{-3} = 1.645\times10^{-3}\ \mathrm{mol}$$（1分）

$$S = \frac{1.645\times10^{-3}\times6.022\times10^{23}\times2.43\times10^{-19}}{1.0788} = 223\ \mathrm{m^2\cdot g^{-1}}$$（1分）

**4-2**

**C（偏小）**。未烘干的 KHP 实际称样量偏少，标出的 c(NaOH) 偏大，从而算得的吸附前后乙酸浓度差偏小，S 偏小。

**4-3**

不适合。乙酸会和氧化铝发生反应（酸碱作用/表面溶解），不是单纯的物理吸附。

**4-4**

本实验的一个基本要求是乙酸必须是单层吸附：如果乙酸浓度过高，可能会出现多层吸附；如果浓度太低，可能无法覆盖整个表面，从而产生系统误差。
