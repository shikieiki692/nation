# 题-154-北斗40-2017BST4强化一-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2017年 BST4/强化营（一）第1题（8分）｜难度：4｜教学层级：竞赛

## 题目

写出下列各化学反应的方程式。

**1-1**（2分）将黄铁矿石和焦炭混合，置于炼硫炉中，使混合物在有限的空气中燃烧，便可从中分离出硫来。写出该过程的化学反应方程式。

**1-2**（2分）在含有甲酸盐的溶液中，亚硫酸盐能被还原为硫代硫酸盐，而甲酸盐则被氧化成草酸盐。

**1-3**（2分）在旋转式管状反应器中，Cl₂ 和潮湿的 Na₂CO₃ 能发生反应，产生 NaHCO₃ 和 Cl₂O。

**1-4**（2分）硼砂与 NH₄Cl 共热，可得到 B₂O₃ 和白色固体 BN。

### 答案

**1-1**

$$3FeS_2 + 12C + 8O_2 \longrightarrow 6S + Fe_3O_4 + 12CO$$

（Fe、S、C、O 守恒：O 左 16 ＝ 右 4＋12。）

**1-2**

$$2SO_3^{2-} + 4HCOO^- \longrightarrow S_2O_3^{2-} + 2C_2O_4^{2-} + 2OH^- + H_2O$$

> **校勘注**：原书硫代硫酸根写为 S₂O₃⁻（左电荷 −8、右 −7 不守恒），径改为 S₂O₃²⁻。电子守恒核验：2×S(+4→+2) 得 4e，4×C(+2→+3) 失 4e。

**1-3**

$$2Cl_2 + 2Na_2CO_3 + H_2O \longrightarrow 2NaHCO_3 + 2NaCl + Cl_2O$$

**1-4**

$$Na_2B_4O_7 + 2NH_4Cl \longrightarrow 2NaCl + B_2O_3 + 2BN + 4H_2O$$
