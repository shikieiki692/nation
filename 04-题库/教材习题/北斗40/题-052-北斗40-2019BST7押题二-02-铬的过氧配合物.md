# 题-052-北斗40-2019BST7押题二-02-铬的过氧配合物

> **来源**：北斗学友·2019 年 BST7/押题营全真模拟（二） 第2题（17分）
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛

---

## 题目

已知元素 X 位于第四周期 VIB 族，元素 Y 位于第五周期 VIB 族。

2-1 写出基态 X 原子的电子排布式。

2-2 写出 Y 的原子序数。

2-3 某种 X 的含氧酸的钾盐 A，经过元素分析，组成如下：钾元素 39.4552%，X 元素 17.4903%，氧元素 43.0545%，通过计算写出 A 的化学式。

2-4 A 的阴离子中氧氧键长为 1.466 Å，已知一般的过氧配体中氧氧键长约为 1.5 Å，一般的超氧配体中氧氧键长约为 1.3 Å。写出 A 中 X 元素的氧化态。

2-5 A 在稀硫酸中完全分解，最终产生一种深绿色溶液和一种无色无味气体 B。将混有惰性杂质的 A 的样品 24.2500 g 置于 2 mol·L⁻¹ 的稀硫酸中进行一段时间的分解，之后微热以赶出溶液中溶解的微量 B，这样总共收集到了 STP 条件下为 3779 mL 的 B。写出 A 在稀硫酸中完全分解的离子方程式。

2-6 计算出该样品中 A 的质量分数。

2-7 X 元素的某含有过氧配体和吡啶的配合物 C，元素分析结果如下：氢元素 2.3874%，碳元素 28.4488%，氮元素 6.6353%，氧元素 37.8966%，X 元素 24.6318%。已知 C 的基本结构是单分子，X 元素的配位环境为五角锥，X 和氧之间的键合有两种，吡啶占据了赤道的位置，如果将吡啶抽象成一个"大原子"，那么 C 分子将具有一个镜面。但是实际上吡啶环是倾斜放置的。写出 C 的化学式。

2-8 画出 C 的立体结构。

2-9 C 分子真正具有镜面吗？

### 答案

2-1（1分）

$$[\mathrm{Ar}]\,3\mathrm{d}^{5}4\mathrm{s}^{1}$$

（X = Cr。）

2-2（1分）Y = Mo，原子序数 **42**。

2-3（3分）

$$\mathrm{K}_{3}\mathrm{CrO}_{8}$$

（K:Cr:O = 39.4552/39.10 : 17.4903/52.00 : 43.0545/16.00 = 1.009 : 0.3364 : 2.691 = 3 : 1 : 8 ✓）

2-4（2分）

$[CrO_8]^{3-}$ 含 4 个过氧配体（O–O 键长 1.466 Å 介于过氧 1.5 Å 与超氧 1.3 Å 之间、偏过氧）：4×O₂²⁻ 共 −8，配阴离子 −3，故 Cr 为 **+5** 氧化态。

2-5（3分）分解的离子方程式：

$$2 \mathrm{CrO}_{8}^{3-} + 12 \mathrm{H}^{+} = 2 \mathrm{Cr}^{3+} + 6 \mathrm{H}_{2}\mathrm{O} + 5 \mathrm{O}_{2}$$

（深绿色溶液为 Cr³⁺，气体 B = O₂。）

2-6（3分）

n(O₂) = 3.779/22.4 = 0.16871 mol → n(A) = 2/5 × n(O₂) = 0.067482 mol

$$w(\mathrm{A}) = \frac{0.067482\times(3\times39.10+52.00+8\times16.00)}{24.2500} = \frac{0.067482\times297.3}{24.2500} = 82.70\%\ (\pm 0.05\%)$$

2-7（2分）

$$\mathrm{CrC}_{5}\mathrm{H}_{5}\mathrm{NO}_{5}$$

（即 Cr(O₂)₂(py)O 型：Cr 中心 + 2 个过氧 + 1 个吡啶 + 1 个端氧；按元素分析百分数验证各元素吻合。）

2-9（1分）

没有。（吡啶环实际倾斜放置，破坏了抽象化后的镜面对称。）

**要点提示**：K₃CrO₈ 中 Cr(+5) 被 4 个过氧"锁定"——过氧把 Cr 的高氧化态势能通过 π* 反馈稳定；2-5 的"惰性杂质"设置考察由气体量反推纯度的定量能力。
