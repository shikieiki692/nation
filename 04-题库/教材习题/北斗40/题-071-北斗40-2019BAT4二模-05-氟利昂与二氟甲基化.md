# 题-071-北斗40-2019BAT4二模-05-氟利昂与二氟甲基化

## 题目

氟利昂是一类氟氯代烷烃的统称。氟利昂曾经广泛用作制冷剂，由于其对臭氧层的强烈破坏，目前已经禁止使用。一种氟利昂 $CHF_{2}Cl$ 的商品名称为 R-22，本题将以它为例进行计算。

已知在 $CHF_{2}Cl$ 中，C—H 键键能为 421.3 kJ·mol⁻¹，C—F 键键能为 462.3 kJ·mol⁻¹，C—Cl 键键能为 364.0 kJ·mol⁻¹。

5-1 氟利昂的作用机理是在高空下受紫外线照射分解出自由基。根据键能数据，说明至少需要多大能量的紫外线？相应的波长是多少？

（备注：$E = h\nu$，$c = \lambda\nu$。）

5-2 已知 O=O 键能为 498.36 kJ·mol⁻¹，$O_{3}$ 的生成焓为 142.67 kJ·mol⁻¹，写出表示相应意义的热化学方程式。

5-3 氯自由基是破坏臭氧层的罪魁祸首。反应的第一步为 $Cl\cdot + O_{3} = ClO + O_{2}$。计算该反应的能量变化。（Cl—O 键能为 269.1 kJ·mol⁻¹）

5-4 反应的第二步为 $ClO + O_{3} = Cl\cdot + 2O_{2}$，写出总反应的化学方程式。Cl· 发挥了什么作用？

5-5 若将 $CHF_{2}Cl$ 和丙烷在一起用紫外线照射，可能生成哪些产物？（列举 4 种即可）

5-6 如果要计算 $CHF_{2}Cl$ 的生成焓，你还需要哪些数据？

5-7 近日，$CHF_{2}Cl$ 被用于卤代芳烃的 $-CF_{2}H$ 官能团化，反应的基本信息在如下反应式中给出。其中 $NiCl_{2}$ 是催化剂，4,4'-二氨基-2,2'-联吡啶是常用的配体，DMAP 即 4-二甲氨基吡啶，是一种常用的碱，DMA 即二甲基乙酰胺，是反应的溶剂。

### 答案

5-1（2分）最弱键为 C—Cl（364.0 kJ·mol⁻¹），即至少需要 364.0 kJ·mol⁻¹，等价于每个光子

$$E = \frac{3.64\times10^{5}}{6.022\times10^{23}} = 6.045\times10^{-19}\ \mathrm{J}$$

$$\lambda = \frac{hc}{E} = 329\ \mathrm{nm}$$

5-2（1分）

$$\mathrm{O}_{2}(g) = 2\mathrm{O}(g)\qquad \Delta H = 498.36\ \mathrm{kJ\cdot mol^{-1}}$$

$$\frac{3}{2}\mathrm{O}_{2}(g) = \mathrm{O}_{3}(g)\qquad \Delta H = 142.67\ \mathrm{kJ\cdot mol^{-1}}$$

（各 0.5 分，不建议调换反应物生成物顺序或改变系数。）

5-3（1.5分）由 Hess 定律组合（O₂ 解离一半 + O + O₃ → ClO + O₂，ClO 解离逆写）：

$$\Delta H = \frac{1}{2}\Delta H(O_{2}) - \Delta H(O_{3}) - \Delta H(ClO) = \frac{498.36}{2} - 142.67 - 269.1 = -162.6\ \mathrm{kJ\cdot mol^{-1}}$$

5-4（1分）

总反应：$2O_{3} = 3O_{2}$。Cl· 发挥了**催化作用**（消耗后又再生）。

5-5（2分）自由基交叉偶联，例如：

$$\mathrm{CH_{3}CH_{2}CH_{2}CHF_{2}}\quad \mathrm{CH_{3}CH(CHF_{2})CH_{3}}\quad \mathrm{CH_{2}ClCH_{2}CH_{3}}\quad \mathrm{CH_{3}CHClCH_{3}}$$

（正丙基/异丙基与 CF₂H/Cl 的交叉组合，任写 4 种。）

5-6（1.5分）

还需要 $Cl_{2}$ 的键能、$F_{2}$ 的键能，以及 C（石墨）的升华焓。

5-7-1（4分）

循环空缺依次为：(1) Zn；(2) $CHF_{2}Cl$；(3) Cl（配体）；(4) $[ArNi^{I}LCF_{2}H]$；(5) Zn。

（两处 Zn 每处 0.5 分，其余每处 1 分。）

机理循环（Ni⁰→Niᴵᴵ 氧化加成 ArCl→单电子转移得 Niᴵᴵᴵ-Ar→捕获 ·CF₂H→还原消除 ArCF₂H）：

![[a67edd9420377cec93c8d9cecdb44e591737cb4f3011df3d9e75419f3a694f6a.jpg]]

5-7-2（1分）

Zn：作还原剂；$[Ni^{0}L]$ 是由配体 L 与 $NiCl_{2}$ 在 Zn 存在下原位还原生成的。

5-7-3（3分）$[ArNi^{II}LCl]$（Ni 与 Ar–C、Cl、联吡啶双 N 四配位）：

![[2bbfec62bff6d67423d753151bab4e9c24bba4988b8ef34b397d89a6c2527a6b.jpg]]

杂化方式：$dsp^{2}$，磁矩：0。（结构 2 分，后两者各 0.5 分。）

**要点提示**：本题为"环境化学＋现代有机金属"双主题——前半以键能/Hess 定律量化氟利昂破坏臭氧的链式催化（329 nm 光解阈值、−162.6 kJ·mol⁻¹ 放热步）；后半是 2020 年代前沿的镍催化二氟甲基化（Ni⁰/Niᴵᴵ/Niᴵᴵᴵ 循环 + Zn 还原剂 + 联吡啶配体），要求标出 Ni 价态并画出四方平面 $dsp^{2}$ 抗磁性配合物。
