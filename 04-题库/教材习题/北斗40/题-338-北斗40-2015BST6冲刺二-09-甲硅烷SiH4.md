# 题-338-北斗40-2015BST6冲刺二-09-甲硅烷SiH4

> 来源：北斗学友40套全真模拟 · 2015年 BST6/冲刺营（二）第9题（18分）｜难度：4｜教学层级：竞赛

## 题目

甲硅烷是一种无色气体，遇到空气能发生爆炸性自燃，易分解，可用于制备高纯度硅。

**9-1**（3分）写出甲硅烷自燃反应方程式。

**9-2**（3分）甲硅烷可与 AgNO₃ 反应，有沉淀生成，但无气体释放。写出反应方程式。

**9-3**（3分）甲硅烷可以在溶液中使（酸性）高锰酸钾褪色（无气体释放），写出反应方程式。

**9-4**（3分）以 SiO₂ 为硅源、在非水溶剂（液氨、乙醚）中制取 SiH₄，其他反应物有 Li[AlH₄]、NH₄Br 及其他常见无机物。现用两种方法进行制备，写出分步反应方程式。

**9-5**（3分）提出由粗硅制得纯硅的一种物理方法和一种化学方法。

**9-6**（3分）SiH₄ 为原料也可以用来制备 Si₃N₄ 纳米材料，该制备方法中最可能存在的杂质是什么？请解释该结论。

### 答案

**9-1**

SiH₄ + 2O₂ ═ SiO₂ + 2H₂O

**9-2**

SiH₄ + 8AgNO₃ + 2H₂O ═ Ag↓ + SiO₂↓ + 8HNO₃

**9-3**

5SiH₄ + 8KMnO₄ + 12H₂SO₄ ═ 8MnSO₄ + 5H₂SiO₃ + 4K₂SO₄ + 17H₂O

**9-4**

方法①：SiO₂ + 4Mg ═ Mg₂Si + 2MgO

Mg₂Si + 4NH₄Br ═ SiH₄ + MgBr₂ + 4NH₃（在液氨中）

方法②：SiO₂ + 2Cl₂ + 2C ═ SiCl₄ + 2CO

SiCl₄ + Li[AlH₄] ═ LiCl + SiH₄ + AlCl₃（在乙醚中）

**9-5**

物理：区域熔炼法或由熔融体拉成单晶（实际上，炼制芯片级纯硅是先用化学法沉降出高纯硅，再用区域熔炼法制得的。相关试题参见 38th IChOPP）。

化学：Si + Cl₂ ═ SiCl₄；SiCl₄ + 2H₂ ═ Si + 4HCl

**9-6**

SiO₂；因为 SiH₄ 水解、氧化所得产物都是 SiO₂（微量水汽/氧的存在使产物中夹杂 SiO₂）。
