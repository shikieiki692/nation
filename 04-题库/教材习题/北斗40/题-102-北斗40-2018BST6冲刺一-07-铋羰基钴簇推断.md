# 题-102-北斗40-2018BST6冲刺一-07-铋羰基钴簇推断

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（一）第7题（10分）｜难度：5｜教学层级：竞赛

## 题目

金属 B 能够与气体 X（分子量 28）形成多种化合物。1908 年，人们制得橙色固体 C。A 为氧化物。C 用 Na 处理后得到 D，之后加入 ZCl₃ 后得到化合物 E。化合物 E 加热后可以得到具有 C₃ 轴的化合物 F。A 到 F 中，金属 B 的质量分数已给出。

$$\mathrm{A} \xrightarrow{\mathrm{H_2}} \mathrm{B} \xrightarrow{\mathrm{X}} \mathrm{C} \xrightarrow{\mathrm{Na}} \mathrm{D} \xrightarrow{\mathrm{ZCl_3}} \mathrm{E} \xrightarrow{\text{heat}} \mathrm{F}$$

**7-1**（8分）请给出 A～F、X 和 ZCl₃ 的化学式。

**7-2**（2分）请给出 F 的结构。

### 答案

> **补录说明（非原书转录）**：原书 7-1 答案缺失，以下由题面线索（X 分子量 28→CO；C 为橙色固体→Co₂(CO)₈）与 7-2 原书结构图（F）反推补全，全链条自洽；A 的具体氧化物因原书质量分数数据表被 OCR 吞失而无法唯一确定。

**7-1**

| 物种 | 化学式 | 依据 |
|:--|:--|:--|
| X | CO（28） | 与过渡金属成多种羰基化合物 |
| B | Co | 羰基化学经典金属 |
| A | CoO（或 Co₃O₄） | 氧化物，H₂ 还原得 Co |
| C | Co₂(CO)₈ | 橙色固体，1908 年前后的经典羰基化合物 |
| D | Na[Co(CO)₄] | Co₂(CO)₈ + 2Na = 2Na[Co(CO)₄] |
| ZCl₃ | BiCl₃ | 见下 |
| E | Bi[Co(CO)₄]₃ | 3Na[Co(CO)₄] + BiCl₃ = Bi[Co(CO)₄]₃ + 3NaCl |
| F | BiCo₃(CO)₉ | E 受热脱去 3 CO |

**7-2**

F 为 Bi 顶点与 3 个 Co(CO)₃ 片构成的 C₃v 四面体簇（Bi—Co 三角锥，C₃ 轴沿 Bi—Co₃ 面法线）：
