# 题-144-北斗40-2018BAT4二模-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BAT4/二模 大联考（四）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

写出下列反应方程式：

**1-1**（2分）Ag(NH₃)₂Cl 与 Hg 作用，可得到 2 种沉淀。

**1-2**（2分）将 HAuCl₄ 的稀溶液与少量甲醛在 KOH 存在的情况下混合可制得一种溶胶，加酸后无气体产生。

**1-3**（2分）在低温下用 O₂F₂ 处理 BF₃。

**1-4**（2分）S₄N₄ 与过量的氢碘酸溶液反应，产生沉淀，溶液变为深色。

**1-5**（2分）(NH₄)₄[UO₂(CO₃)₃] 加热到 800 °C 可以制备 UO₂。

### 答案

**1-1**

$$2\mathrm{Ag(NH_3)_2Cl} + \mathrm{Hg} = 2\mathrm{Ag}\downarrow + \mathrm{Hg(NH_2)Cl}\downarrow + 2\mathrm{NH_3} + \mathrm{NH_4Cl}$$

（两种沉淀：Ag 与氨基氯化汞。）

**1-2**

$$2\mathrm{HAuCl_4} + 3\mathrm{HCHO} + 11\mathrm{KOH} = 2\mathrm{Au}\downarrow + 3\mathrm{HCOOK} + 8\mathrm{KCl} + 8\mathrm{H_2O}$$

> **存疑说明（照录原书）**：该式 O 计数（左 14 / 右 11）与 H 计数（左 16 / 右 19）均不平，按 HAuCl₄–HCHO–KOH 体系多次尝试无法配平（甲酸钾与 KOH 的系数约束冲突），存疑照录待回源核对。

**1-3**

$$2\mathrm{O_2F_2} + 2\mathrm{BF_3} = 2\mathrm{O_2BF} + \mathrm{F_2}$$

（O₂F₂ 为强氟化-氧化剂，生成二氧氟硼酰 O₂BF。）

**1-4**

$$\mathrm{S_4N_4} + 16\mathrm{HI} = 4\mathrm{S}\downarrow + 4\mathrm{NH_4I} + 6\mathrm{I_2}$$

（守恒自核：S 4、N 4、H 16=16、I 16=4+12 ✓；电子 N(+3→−3) 得 6e×4=24e？细账：S(+2→0) 失 2e×4=8e；N(+3→−3) 得 6e×4=24e；I(−1→0) 失 2e×12=24e；S 失 8e+I 失 24e=32e？重账：得电子 N 24e；失电子 S 8e+I 24e=32e ✗。再核 I₂：12 个 I(−1→0) 失 12e（不是 24）。失 8+12=20 ✗。嗯——按题面条件照录原书式；元素计数 N 4=4、S 4=4、H 16=16、I 16=4+12 ✓ 全平；氧化数细账因 S₄N₄ 中 S/N 形式价态特殊（S +2/N −2 更常见：S(+2→0) 失 2e×4=8e；N(−2→−3) 得 1e×4=4e；I(−1→0) 失 2e×12=24e；得 4e 失 32e 仍不守恒）。**氧化数无法严格闭合，元素计数平，存疑照录。**）

**1-5**

$$3(\mathrm{NH_4})_4[\mathrm{UO_2(CO_3)_3}] \xlongequal{800\ ^\circ\mathrm{C}} 3\mathrm{UO_2} + 10\mathrm{NH_3}\uparrow + 9\mathrm{CO_2}\uparrow + 9\mathrm{H_2O} + \mathrm{N_2}\uparrow$$

（守恒自核：U 3、N 12=10+2、H 48=30+18、C 9、O 27=6+18+3 ✓。）
