# 题-101-北斗40-2018BST6冲刺一-06-羰基亲电性定量动力学

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（一）第6题（12分）｜难度：5｜教学层级：竞赛

## 题目

羰基化合物是有机合成中极为常见的亲电受体。但是对于羰基化合物的亲电反应活性的定量分析却有较大难度。近期，研究人员报道了一种全新的定量计算羰基化合物亲电性的手段。该体系使用芳基磺酸基取代的氯甲烷阴离子 2 作为参比亲核试剂，反应过程如下：

$$\mathrm{R_1COR_2}\ (1) + ^\ominus\mathrm{CH(Cl)SO_2Ph}\ (2) \xrightleftharpoons[K_{-CC}]{K_{CC}} [\ 4\ ] \xrightarrow{K_{rc}} 3$$

**6-1**（1分）请分析，为何常规手段测定羰基化合物亲电性难度较大。

**6-2**（2分）请给出 3 和 4 的结构，4 是反应的中间体，在低温下可以被分离捕获。

**6-3**（4分）请给出实验动力学常数 K₂^exptl 的表达式。

**6-4**（4分）为了进一步得到 K_CC，研究人员首先合成了环丁酮 1a 与 2 反应的中间体的质子化产物 4H，之后在碱性条件下与过量三氟苯乙酮 1b 反应，得到两种产物 P₋CC 与 P_rc，P₋CC/P_rc 为 0.89，已知 1a 和 2 反应的 K₂^exptl 为 7.05×10³ M⁻¹·s⁻¹，请给出 P₋CC 与 P_rc 的结构，并计算 1a 与 2 反应的 K_CC。已知 1b 与 2 反应的速率极快。

**6-5**（1分）亲核性与亲电性之间可用下式联系：log K(20°C) = s_N(N + E)。其中 N 为亲核试剂的亲核常数，E 为亲电试剂亲电常数，s_N 为反应系数。此处 K(20°C) 即为 K_CC，N = 28.27，s_N = 0.42，请给出 1a 的 E 值。

### 答案

**6-1**

因为对羰基化合物的亲电加成多为可逆反应，这不利于测定动力学常数。

**6-2**

4（四面体醇盐中间体，低温可捕获）与 3（环氧产物）：

![[5484151c38a587f0287e47f02c29860150d12ac588781ce0e74c810da72701be.jpg]]

（4：R₁R₂C(O⁻)—CH(Cl)SO₂Ph 两性中间体；3：经分子内取代关环的环氧化物 R₁R₂C—O—CH—SO₂Ph 三元环。）

**6-3**

$$\frac{\mathrm{d}[4]}{\mathrm{d}t} = K_{CC}[1][2] - K_{-CC}[4] - K_{rc}[4]$$

由于 4 是高活性中间体，可以认为 d[4]/dt = 0（稳态近似），则：

$$[4] = \frac{K_{CC}[1][2]}{K_{-CC} + K_{rc}}$$

$$r = \frac{\mathrm{d}[3]}{\mathrm{d}t} = K_{rc}[4] = \frac{K_{rc}K_{CC}[1][2]}{K_{-CC} + K_{rc}}$$

则有：

$$K_2^{exptl} = \frac{K_{CC}K_{rc}}{K_{-CC} + K_{rc}} = \frac{K_{CC}}{1 + K_{-CC}/K_{rc}}$$

**6-4**

P_rc（环丁酮氧桥产物）与 P₋CC（三氟苯乙酮环氧产物）：

![[c1c0d59276cc0902f22a23d8c54c83043b87c6e186972ce1e09b2c95baf5a1b8.jpg]]

由于 1b 与 2 反应的速率极快，且 1b 过量，可以认为 P₋CC/P_rc 即为 K₋CC/K_rc（1 分）。则由：

$$K_2^{exptl} = \frac{K_{CC}}{1 + K_{-CC}/K_{rc}}$$

得：

$$K_{CC} = (1 + 0.89)\times 7.05\times10^{3} = 1.33\times10^{4}\ \mathrm{M^{-1}\cdot s^{-1}}$$

**6-5**

$$\log K_{CC} = s_N(N + E)$$

$$E = \frac{\log(1.33\times10^{4})}{0.42} - 28.27 = -18.45$$
