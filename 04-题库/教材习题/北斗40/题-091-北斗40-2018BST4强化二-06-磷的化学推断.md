# 题-091-北斗40-2018BST4强化二-06-磷的化学推断

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（二）第6题（12分）｜难度：4｜教学层级：竞赛

## 题目

金属 X 与非金属 Y 是两种常见的元素。X 单质与浓硫酸反应后稀释可以得到蓝色溶液 A，A 可以与 Y 的一种单质 B 反应得到沉淀 C。B 与氢氧化钠溶液反应可以得到剧毒气体 D 与 Y 的含氧酸盐 E，该种气体具有较强的还原性，能够还原 A 得到 X 单质与 C。与此同时，D 可以和氧气反应得到 F。

**6-1**（8分）指出 A～F 和 X、Y。

**6-2**（2分）写出 A 与 B 反应的方程式。

**6-3**（2分）写出 B 与氢氧化钠溶液反应的方程式。

### 答案

**6-1**

> **说明**：原书答案本小题空白，以下由题面线索与 6-2/6-3 原书答案反推补全（非原书转录）。

| 物种 | 化学式/名称 | 依据 |
|:--|:--|:--|
| X | Cu | 与浓硫酸反应得蓝色溶液 |
| A | CuSO₄ | 蓝色溶液 |
| Y | P | 非金属；其碱液歧化产物剧毒、强还原性 |
| B | P₄（白磷） | 与 NaOH 歧化得 PH₃ |
| C | Cu₃P | A 与 B 反应沉淀 |
| D | PH₃（膦） | 剧毒、强还原性气体，可还原 Cu²⁺ |
| E | NaH₂PO₂（次磷酸钠） | 白磷碱液歧化的含氧酸盐 |
| F | H₃PO₄ | PH₃ 被氧气氧化产物 |

**6-2**

$$11\mathrm{P_4} + 60\mathrm{Cu^{2+}} + 96\mathrm{H_2O} = 20\mathrm{Cu_3P}\downarrow + 24\mathrm{PO_4^{3-}} + 192\mathrm{H^+}$$

（守恒核验：Cu 60＝60；P 44＝20＋24；O 96＝96；H 192＝192；电荷 +120＝+120；电子：得 60×1e＋20×3e＝120e＝失 24×5e ✓。）

**6-3**

$$\mathrm{P_4} + 3\mathrm{OH^-} + 3\mathrm{H_2O} = 3\mathrm{H_2PO_2^-} + \mathrm{PH_3}\uparrow$$

（白磷在碱液中歧化：1 个 P(0→−3) 得 3e，3 个 P(0→+1) 失 3e ✓。）

（另：D 与 O₂ 的反应：PH₃ + 2O₂ = H₃PO₄。）
