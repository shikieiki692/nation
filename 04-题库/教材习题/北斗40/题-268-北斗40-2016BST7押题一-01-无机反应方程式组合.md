# 题-268-北斗40-2016BST7押题一-01-无机反应方程式组合

> 来源：北斗学友40套全真模拟 · 2016年 BST7/押题营（一）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

**1-1**（2分）铅白与炭火加热生成铅。

**1-2**（2分）苯进行 Birch 还原（体系为苯、液氨、钠与乙醇）。

**1-3**（2分）六氧化四砷、氟化钙与浓硫酸制备三氟化砷。

**1-4**（2分）硫与氢氧化钠溶液反应。

**1-5**（2分）四氯化钽受热升华发生歧化反应。

（注：题面「四氧化六砷」按化学式 As₄O₆ 应读作六氧化四砷，系 OCR 语序问题。）

### 答案

**1-1**

铅白即碱式碳酸铅 2PbCO₃·Pb(OH)₂，受热先分解为铅黄（PbO），再被炭还原：

2PbCO₃·Pb(OH)₂ ─Δ→ 3PbO + H₂O↑ + 2CO₂↑

2PbO + C ─Δ→ 2Pb + CO₂↑

（校勘注：原书第一式写作「Pb₂(OH)₃CO₃＝PbO＋H₂O＋CO₂」、第二式写作「2PbO＋C＝Pb＋CO₂」，两式原子均不守恒——第一式 Pb 2 对 1、O 左 6 对右 4；第二式 Pb 2 对 1。按铅白组成与守恒原理径改如上，待回源核对。）

**1-2**

Birch 还原分两步：钠在液氨中溶剂化，苯得溶剂化电子后被乙醇质子化，净结果生成 1,4-环己二烯：

Na → Na⁺ + e⁻(NH₃)（溶剂化电子）

C₆H₆ + 2C₂H₅OH + 2e⁻(NH₃) → C₆H₈（1,4-环己二烯） + 2C₂H₅O⁻ + 2NH₃

（校勘注：原书等式左侧误作 C₆H₈，与右侧产物同式——苯为 C₆H₆，径改。）

**1-3**

As₄O₆ + 6CaF₂ + 6H₂SO₄ ═ 4AsF₃ + 6H₂O + 6CaSO₄

（配平验证：As 4、F 12、Ca 6、S 6、H 12、O 左 6+24＝30 对右 6+24＝30，全平。）

**1-4**

3S + 6NaOH ═ Na₂SO₃ + 2Na₂S + 3H₂O

（硫在热碱中歧化为 −2 与 +4 价，电子账：0→−2 得 2e⁻×2，0→+4 失 4e⁻×1，全平。校勘注：原书答案漏写 3H₂O，O 左 6 对右 3 不平，径改补上。）

**1-5**

2TaCl₄ ═ TaCl₃ + TaCl₅

（Ta 平均 +4 价歧化为 +3 与 +5 价，受热促进歧化，与升华操作配合使平衡右移。）
