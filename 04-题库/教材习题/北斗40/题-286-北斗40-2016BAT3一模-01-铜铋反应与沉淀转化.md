# 题-286-北斗40-2016BAT3一模-01-铜铋反应与沉淀转化

> 来源：北斗学友40套全真模拟 · 2016年 BAT3/一模 大联考（三）第1题（13分）｜难度：5｜教学层级：竞赛

## 题目

**1-1** 写出下列反应的方程式。

**1-1-1**（1分）向 Bi(NO₃)₃·5H₂O 固体中加入少量水溶解。

**1-1-2**（3分）向 Zn 与 NaOH 反应的体系中放入 Cu 片，稍加热，Cu 片上即可镀上 Zn。这是一个原电池，写出电极反应。

**1-2** 解释下列现象：

**1-2-1**（1.5分）在液氨中，Be 可以取代 KNH₂ 中的 K。

**1-2-2**（1.5分）向 6 mol·L⁻¹ HCl、1 mol·L⁻¹ CuCl₂ 及大量 NaCl 的混合溶液中加入 Cu 制备 CuCl，溶液变为棕黑色，反应一段时间后褪去。

**1-3** 推断下列实验现象，并解释。

**1-3-1**（3分）向 CuCl₂ 溶于 KCl 的清液中加入乙二胺。［φ⁰(Cu²⁺/Cu⁺)＝0.159 V，φ⁰(Cu⁺/Cu)＝0.520 V；K稳(CuCl₃²⁻)＝5.0×10⁵，K稳[Cu(en)₂²⁺]＝1.0×10²⁰，K稳[Cu(en)₂⁺]＝6.3×10¹⁰］

**1-3-2**（3分）在 0.5 mL 0.1 mol·L⁻¹ KCl 和 0.5 mL 0.1 mol·L⁻¹ K₂CrO₄ 混合后的溶液中逐滴加入 0.1 mol·L⁻¹ AgNO₃。［Ksp(AgCl)＝1.56×10⁻¹⁰，Ksp(Ag₂CrO₄)＝1.12×10⁻¹²］

### 答案

**1-1-1**

Bi(NO₃)₃ + 2H₂O ═ BiONO₃↓ + 2HNO₃

**1-1-2**

Zn 为负极：Zn + 4OH⁻ − 2e⁻ ═ Zn(OH)₄²⁻

Cu 为正极：2H₂O + 2e⁻ ═ H₂↑ + 2OH⁻

Zn(OH)₄²⁻ + 2e⁻ ═ Zn + 4OH⁻

**1-2-1**

产物 Be(NH₂)₂ 的溶解度比 KNH₂ 低，可以从溶液中析出。

（反应产生的 K 可以继续与液氨反应生成 KNH₂，并与 Be(NH₂)₂ 反应生成 K[Be(NH₂)₃]，这步反应速率不快，但进一步促进了反应的进行。回答只需达到第一点即可。）

**1-2-2**

这一步骤的反应为 3Cl⁻ + Cu + Cu²⁺ ═ CuCl₃²⁻，反应中的棕黑色物种为 Cu(I) 和 Cu(II) 的多核配离子。它们之间的电荷转移产生了较深的颜色。（电荷转移的深色在普鲁士蓝中是一个很好的例子。）

**1-3-1**

en 与 Cu²⁺ 的配位显然强于 Cu⁺，因此可能可以促进 Cu⁺ 的歧化。由题目所给数据，可以计算得到反应

2CuCl₃²⁻ + 2en ═ Cu(en)₂²⁺ + 6Cl⁻ + Cu

的平衡常数 K＝5.0×10¹⁴（＝K稳[Cu(en)₂²⁺]×K歧化/[K稳(CuCl₃²⁻)]²，其中 K歧化＝10^((0.520−0.159)/0.0591)≈1.3×10⁶，1.0×10²⁰×1.3×10⁶/(5.0×10⁵)²≈5.2×10¹⁴ ✓）。

因此，反应现象为：生成红色沉淀（Cu），溶液颜色变为紫色（Cu(en)₂²⁺ 的颜色，回答蓝色亦给分）。

**1-3-2**

考虑反应 2AgCl + CrO₄²⁻ ═ 2Cl⁻ + Ag₂CrO₄，可以计算得 K＝2.17×10⁻⁸（＝Ksp(Ag₂CrO₄)/Ksp(AgCl)²，复算 1.12×10⁻¹²/(1.56×10⁻¹⁰)²＝2.17×10⁻⁸ ✓），而起始时 c(Cl⁻)＝c(CrO₄²⁻)＝0.05 mol·L⁻¹，Q＝0.05²/0.05＝0.05＞K，反应向左进行，即 Ag₂CrO₄ 沉淀将转化为 AgCl 沉淀。（或者可以从与 Ag⁺ 平衡所需的离子浓度考虑，均可以判断出 AgCl 先沉淀。）

因此，反应现象为：先出现白色沉淀（AgCl），再出现砖红色沉淀（Ag₂CrO₄）。
