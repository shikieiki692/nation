# 题-078-北斗40-2018BST4强化一-03-联吡啶衍生物与钌水氧化催化剂

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（一）第3题（13分）｜难度：5｜教学层级：竞赛

## 题目

**3-1**（5分）联吡啶（bpy）是一种重要的有机配体，但是在实际工作中，该配体常会被进行修饰。现科研人员得到了三种 bpy 的衍生物，其化学式分别为 C₁₂H₈O₄N₂（A）、C₁₁H₉O₅N₂P（B）和 C₁₀H₁₀O₆N₂P₂（C）。请给出 bpy 和 A、B、C 三种物质的结构，已知三种物质都是四齿配体。

**3-2**（3分）某种金属 M 的配合物被发现可以催化水的分解。在所有被研究的配合物中，一种配合物的化学式可以用 [M(V)L₂OB] 表示，该物质不带电荷，M 为五角双锥配位，L 为 N 配位单齿配体，其 H-NMR 显示在 7.18 和 8.44 处有双峰，在 2.32 处有单峰，请给出 L 的结构，并指认峰的归属。

**3-3**（5分）报道中，另一种被研究的化合物 [M(V)L₂OA]ⁿ⁺ 的分子量为 545.5，请通过计算指出 M 是何种元素，画出其结构并标注出电荷。已知 [M(V)L₂OA]ⁿ⁺ 有对称面，A 可以用下图简化。

![[c096e3958ec83a07fa21b606a8bd3de7df921f09e151f5dee74544246a2a560c.jpg]]

### 答案

**3-1**

bpy 为 2,2'-联吡啶；A、B、C 分别为 6、6' 位酰胺/膦酰胺逐步氧代同系物（均以两个 N 及酰胺/膦酰氧配位成四齿）：

![[642729b4a5a2ae219c6ada99599b8145fa7b402fe64d29e9ce75f4ee8be2d8b2.jpg]]

A（C₁₂H₈O₄N₂，2,2'-联吡啶-6,6'-二甲酰胺）：

![[070fdc82cdc25a8fbdd8a4e55b84d8a277e8eb383a6a6406c1b899ad8dbeb12b.jpg]]

B（C₁₁H₉O₅N₂P，一侧甲酰胺、一侧膦二酰胺）：

![[45bbcc13015e2f4616271b72e03c2f73d96062f0764dee654d31915c7fab235c.jpg]]

C（C₁₀H₁₀O₆N₂P₂，双膦二酰胺）：

![[f1d133d94626ddc6cd59c66d9e4917f8c79ceec6d2fa2975d3c520b920ae7918.jpg]]

**3-2**

L 为 **2-甲基吡啶**（N 配位单齿）：

![[93fa7a781b0d51665a1f687033e696b4cd64904616f682d70e14afc1823ce5e1.jpg]]

峰归属：2 位 —CH₃ 为 2.32 处单峰（s）；吡啶环上 6-H 与 4-H 分别在 7.18 与 8.44 处呈双峰（d）。

**3-3**

由 [M(V)L₂OA]ⁿ⁺ 分子量 545.5 反推：

$$M = 545.5 - 16(\mathrm{O}) - 93.06\times2(\mathrm{L_2}) - 244.18(\mathrm{A}) + 2\times1.008 = 101.21$$

与 **Ru**（101.07）符合，由此 M 应为 Ru。

配合物结构（五角双锥：赤道面为四齿 A 配体＋桥氧，轴向两个 2-甲基吡啶）：

![[ab929ab809a229f6a49582ad25d5cb7d989e8846ca9021b6e9b4f8939c62025f.jpg]]

（原书此处另有一张标注图因褪色不可辨，弃用。）

**校勘注**：本小题按题面数据（545.5、L=C₆H₇N、A=C₁₂H₈O₄N₂、O）独立验算：545.5−16−186.1−244.2+2.0≈101.2，与 Ru 一致；配合物有对称面，A 与 2 个 L 均为中性配体，O 为 O²⁻，故 n = +5−2 = **+3**，即 [Ru(V)L₂OA]³⁺。
