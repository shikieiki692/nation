# 题-114-北斗40-2018BST7押题一-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST7/押题营 全真模拟（一）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

写出下列反应的化学（离子）方程式：

**1-1**（2分）高锰酸钾在酸性条件下与 FeCl₂ 反应。

**1-2**（2分）亚硝酸钾在高温下的热解。

**1-3**（2分）白磷在温热的氢氧化钾溶液中溶解。

**1-4**（2分）K₃[Fe(C₂O₄)₃] 在光照下逐渐分解。

**1-5**（2分）向硫酸钛溶液中加入羟胺。

### 答案

**1-1**

$$3\mathrm{MnO_4^-} + 5\mathrm{Fe^{2+}} + 10\mathrm{Cl^-} + 24\mathrm{H^+} = 3\mathrm{Mn^{2+}} + 5\mathrm{Fe^{3+}} + 5\mathrm{Cl_2}\uparrow + 12\mathrm{H_2O}$$

（酸性 FeCl₂ 体系中被氧化的既有 Fe²⁺ 又有 Cl⁻：Mn(+7→+2) 得 15e，Fe(+2→+3) 失 5e、Cl(−1→0) 失 10e ✓。）

**1-2**

$$4\mathrm{KNO_2} \xlongequal{\Delta} 2\mathrm{K_2O} + 4\mathrm{NO}\uparrow + \mathrm{O_2}\uparrow$$

（N(+3→+2) 得 4e，O(−2→0) 失 4e ✓。）

**1-3**

$$\mathrm{P_4} + 3\mathrm{KOH} + 3\mathrm{H_2O} = \mathrm{PH_3}\uparrow + 3\mathrm{KH_2PO_2}$$

（白磷歧化：1 个 P(0→−3) 得 3e，3 个 P(0→+1) 失 3e ✓。）

**1-4**

$$2\mathrm{K_3[Fe(C_2O_4)_3]} \xlongequal{h\nu} 2\mathrm{K_2[Fe(C_2O_4)_2]} + \mathrm{K_2CO_3} + \mathrm{CO}\uparrow + 2\mathrm{CO_2}\uparrow$$

（光致电子转移：2 个 Fe(+3→+2) 得 2e，生成 CO₂ 的 2 个 C(+3→+4) 失 2e ✓。）

**1-5**

$$2\mathrm{NH_2OH} + 2\mathrm{Ti(SO_4)_2} + 2\mathrm{H_2O} = (\mathrm{NH_4})_2\mathrm{SO_4} + 2\mathrm{TiOSO_4} + \mathrm{H_2SO_4}$$

> **存疑说明（照录原书）**：原书该式 H 计数（左 10 / 右 12）与 O 计数（左 18 / 右 16）均不平，且在题给物种范围内多次尝试无法配平（N(−1→−3) 得电子无对应氧化过程），存疑照录，待回源核对原书反应条件与物种。
