# 题-290-北斗40-2016BAT3一模-05-全铋阳离子原子簇

> 来源：北斗学友40套全真模拟 · 2016年 BAT3/一模 大联考（三）第5题（13分）｜难度：5｜教学层级：竞赛

## 题目

铋的化合物丰富多彩。1978 年，化学家 R.C.Burns 在液态 SO₂ 中，用 AsF₅ 氧化金属铋制备了化合物 A。经分析，A 为离子化合物，且阴离子结构高度对称。已知 A 中铋元素的质量分数为 64.84%，Bi 元素的平均氧化数为 +0.6。

**5-1**（4分）试确定 A 的结构简式，阐述并画出阳离子的结构；写出生成 A 的化学反应方程式。

**5-2** 将金属铋与适量的 BiCl₃、AlCl₃ 在熔融的 NaAlCl₄ 中反应也能制备含 A 的阳离子的化合物 B。B 也为离子化合物，且阴离子也高度对称。B 中铋元素质量分数为 67.33%。在制备 B 的过程中，若金属铋过量，则会生成化合物 C。C 中 Bi 元素质量分数为 83.18%。

**5-2-1**（2分）试通过计算确定 B 的分子式，写出生成 B 的化学反应。

**5-2-2**（2分）C 中的阳离子为全铋阳离子。试通过计算确定 C 的分子式，写出生成 C 的化学反应。

**5-2-3**（2分）化合物 B 是顺磁性还是抗磁性？为什么？

**5-2-4**（3分）化合物 C 的阳离子可看作是封闭的多面体中削去对称的两个顶点得到的立体构型。问该阳离子是什么构型？Bi 元素平均氧化数是多少？

### 答案

**5-1**

Bi 正常化合价为 +3 和 +5 价，现在平均氧化数为 +0.6，说明是原子簇合离子，即 Biₙ^m⁺。

根据氧化数列方程：0.6n＝m，可能是 n＝5，m＝3，所以 A 的阳离子为 Bi₅³⁺。结构对称才最稳定，因此该阳离子为三角双锥形：

![[fd7dfaaa85c6f9df138d30c5efcd680a82acffa6c57fda2e820cfd8b839b63d6.jpg]]

（Bi₅³⁺ 三角双锥结构，赤道 3 个 Bi 与轴向 2 个 Bi。）

离子结构高度对称，根据 As 的结构特点，猜测应为 AsF₆⁻，因此 A 的分子式为 Bi₅(AsF₆)₃，然后将 Bi 元素质量分数进行验证即可得证（5×209/(5×209＋3×130.9)＝64.8% ✓）。

化学反应为：10Bi + 9AsF₅ ═ 2Bi₅(AsF₆)₃ + 3AsF₃

**5-2-1**

B 的阴离子高度对称，根据质量守恒，阴离子应为 Al 的配离子，应为 AlCl₄⁻，因此 B 的分子式为 Bi₅(AlCl₄)₃。将铋元素质量分数代入验证即可（5×209/(5×209＋3×169.8)＝67.1% ≈ 67.33%）。化学方程式为：

4Bi + BiCl₃ + 3AlCl₃ ═ Bi₅(AlCl₄)₃

**5-2-2**

C 的分子式不妨设为 Biₙ(AlCl₄)ₘ。

则 209n/(209n＋169m)＝83.18%，即 209n/169m＝83.18/16.82，n/m＝4。由于化合物 C 的阳离子可看作是封闭的多面体中削去对称的两个顶点得到的立体构型，排除了 Bi₄⁺（若是，应为八面体扣除对称的两个顶点，应为平面四边形）。

因此 n/m＝4 的公比应为 2，即 n＝8，m＝2，即 C 的阳离子为 Bi₈²⁺，C 的分子式为 Bi₈(AlCl₄)₂。

制备 C 的化学方程式为：22Bi + 2BiCl₃ + 6AlCl₃ ═ 3Bi₈(AlCl₄)₂

**5-2-3**

Bi₅(AlCl₄)₃ 为抗磁性物质，无未成对电子。

**5-2-4**

（Bi₈²⁺：8 顶点四方反棱柱，可看作二十面体削去对称两个顶点。）
