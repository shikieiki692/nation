# 题-112-北斗40-2018BST6冲刺二-07-氨氧化制硝酸热力学

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第7题（8分）｜难度：5｜教学层级：竞赛

## 题目

从 NH₃(g) 制备 HNO₃ 的一种工业方法，是将 NH₃(g) 与空气的混合物通过高温下的金属 Pt 催化剂，主要反应为

$$4\mathrm{NH_3(g)} + 5\mathrm{O_2(g)} = 4\mathrm{NO(g)} + 6\mathrm{H_2O(g)}$$

相关的热力学常数（由题目数据表，按生成焓/生成自由能计）：

- Δ_fH：H₂O(g) −241.818、NO +90.25、NH₃ −46.11（kJ·mol⁻¹）
- Δ_fG：H₂O(g) −228.572、NO +86.55、NH₃ −16.45（kJ·mol⁻¹）

在 1773 K 下，将 2.018 g 的 NH₃ 充入恒压为 101325 Pa 的容器中（即 NH₃ 分压为 101325 Pa），后通入空气，空气中氧气的含量近似为 0.21，剩余成分不参加反应。问：当 NH₃ 的分压为 10⁻⁶ Pa 时，通入的空气的物质的量。假设 ΔfH 不随温度而变化。（提示：若已知一个反应在一个温度下的 K、ΔH，则可以根据 ln(K₁/K₂) = −(ΔH/R)×(1/T₁ − 1/T₂) 计算出另一温度下的平衡常数）

### 答案

$$\Delta_r H = 6\times(-241.818) + 90.25\times4 + 46.11\times4 = -905.468\ \mathrm{kJ\cdot mol^{-1}}$$

$$\Delta_r G = 6\times(-228.572) + 86.55\times4 + 16.45\times4 = -959.432\ \mathrm{kJ\cdot mol^{-1}}$$

$$\ln K^\theta_{(298\,\mathrm{K})} = -\frac{\Delta_r G}{RT} = 387.2$$

由 van't Hoff 方程：

$$\ln\frac{K(298\,\mathrm{K})}{K(1773\,\mathrm{K})} = \frac{-\Delta_r H}{R}\times\left(\frac{1}{T(298\,\mathrm{K})} - \frac{1}{T(1773\,\mathrm{K})}\right)$$

得到 $K_{(1773\,\mathrm{K})} = 1.307\times10^{36}$。

由于 NH₃ 的分压过小，可以认为 NH₃ 进行了完全转化，即生成了

$$n(\mathrm{NO}) = \frac{2.018}{14.01+1.008\times3} = 0.1185\ \mathrm{mol},\qquad n(\mathrm{H_2O}) = 0.1185\times1.5 = 0.1777\ \mathrm{mol}$$

根据总压一定可以得到（NH₃ 分压很小，忽略）：

$$p_{O_2}+p_{N_2}+p_{H_2O}+p_{NO}+p_{NH_3} = 101325\ \mathrm{Pa}$$

$$p_{H_2O}+p_{NO} = \frac{(0.1185+0.1777)\times 8.314\times1773}{V}$$

$$p_{N_2} = \left(p_{O_2}+\frac{p_{H_2O}+p_{NO}}{2}\right)\times\frac{79}{21}$$

$$K = \frac{p_{H_2O}^6\times p_{NO}^4}{p_{O_2}^5\times p_{NH_3}^4\times (p^\theta)^{1}} = 1.307\times10^{36}$$

联立上述方程得到：

$$V = 0.3648\ \mathrm{m^3}$$

故需要的空气摩尔数为：

$$n(\text{空气}) = \frac{0.3648\times101325}{8.314\times1773} - 0.1481 = 2.359\ \mathrm{mol}$$
