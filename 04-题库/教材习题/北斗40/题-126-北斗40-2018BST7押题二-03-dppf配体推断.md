# 题-126-北斗40-2018BST7押题二-03-dppf配体推断

> 来源：北斗学友40套全真模拟 · 2018年 BST7/押题营 全真模拟（二）第3题（11分）｜难度：5｜教学层级：竞赛

## 题目

某种配合物可以用 PdL(C₇H₇)NAr₂ 表示，该配合物在 L 的存在下加热分解，能得到有机化合物 A 和一种四面体配合物 B。

**3-1**（7分）已知 L 是一种常见金属有机化合物的衍生物，且是一种膦二齿配体，其中含有金属 10.07%，含有磷 11.17%。使用 Pd-C 做催化剂彻底还原 L 后，可以得到配体 L1 和某种金属 M，L1 的分子量是 L 的 48.06%。请推测并给出 L 的最合理结构，并给出 L1 的结构。

**3-2**（4分）请给出 A 和 B 的结构，必要情况下可以对 L 的结构进行简化，但是需进行相关标示。

### 答案

**3-1**

由于是膦二齿配体，不妨假设化合物含有两个 P，那么分子量为 554.3 g·mol⁻¹。对应可以算出，金属原子量为 55.80 g·mol⁻¹，与铁符合。考查铁的常见金属有机化合物，不妨假设为二茂铁。

二茂铁分子量为 184.00，则余下分子量为：554.3 − 30.97×2 − 184.00 = 308.36 g·mol⁻¹。

已知 L 加氢分解可以得到 L1，且 L1 为双键全部被破坏产物。有 L1 分子量为：554.3×0.4806 = 266.4 g·mol⁻¹。由 (266.4×2 + 55.85 − 554.3)/1.008 = 34 可见，1 当量 L 需要 17 当量氢气分子才可彻底还原。环戊二烯相差 5 个 H、余下 12 个 H，猜测为两个苯环，则 L 中应含有 4 个苯基，分子量为 77.11×4 = 308.44 g·mol⁻¹，这与前面计算所得一致。

参考三苯基膦的结构，可以得出 L 和 L1 的结构为——**L = dppf（1,1'-双(二苯基膦)二茂铁）**、**L1 = o-双(二苯基膦)苯**：

![[53ae061cac11ba8711775b7eff13752afd86585856aaa68f1a13ceb3224b0bc4.jpg]]

（dppf：Fe 夹两个 Cp 环、各带一个 PPh₂。）

![[fda6bf4e3ebc6893d6112e629d429668d0aaca12e0f6d5732ebbc1137e02b74f.jpg]]

（L1：邻苯撑双(二苯基膦)，苯环取代两个 Cp 环。）

（注：L 的结构 3 分、L1 的结构 1 分；金属质量分数自核：55.85/554.3 = 10.08% ≈ 10.07% ✓、2P 61.94/554.3 = 11.17% ✓。）

**3-2**

A：PhCH₂NAr₂（苄基胺，来自 C₇H₇–NAr₂ 片段加氢/热解）；B：Pd 与两分子简化 L 形成的四面体配合物：

![[e4196533ebb3903c640e06b157fa3e53eb6a1e93934a4b400101192cfe8cda41.jpg]]

![[ac1249a03100edc9e82109a2687338521e0ee87e24a917200d7592e0319e774f.jpg]]

（B：Pd(PPh₂–桥)₂ 四面体构型；L 可简化为 PPh₂ 双齿标注。）
