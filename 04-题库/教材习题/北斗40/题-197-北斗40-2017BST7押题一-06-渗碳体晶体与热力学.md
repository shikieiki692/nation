# 题-197-北斗40-2017BST7押题一-06-渗碳体晶体与热力学

> 来源：北斗学友40套全真模拟 · 2017年 BST7/押题营（一）第6题（13分）｜难度：5｜教学层级：竞赛

## 题目

铁碳系统在工业上有着重要的应用。在铁中加入碳形成合金，可以增强铁的硬度和脆性。在铁碳系统中存在一种被称作渗碳体的化合物，渗碳体的晶胞参数为 a＝451.5 pm、b＝507.7 pm、c＝672.0 pm，α＝β＝γ＝90°。其晶体结构如下图所示（小黑球为碳，大白球为铁）：

![[a55bdec4b0957ced254d14da293bbe864ae3d9092505464b0ea739e84350055b.jpg]]

**6-1**（2分）铁和碳可以形成 FeC、FeC₂ 等化合物，工业的铁碳系统相图中却没有给出，为什么？

**6-2**（7分）写出渗碳体的化学式，给出它的点阵类型并计算密度。

**6-3**（2分）含有较多渗碳体的铁被称为白口铁，过于脆而硬。战国早期人们就发明了通过加热对白口铁进行柔化处理，白口铁中的渗碳体在加热下会分解成单质，其中碳以石墨的形式和铁形成固溶体存在。用化学术语解释白口铁柔化的原理。

**6-4**（4分）下表是几种物质的热力学函数，计算有利于渗碳体生成的最低温度并简要说明渗碳体低温下稳定的原因。

### 答案

**6-1**

FeC、FeC₂ 等在铁碳平衡相图涉及的温度与成分范围内热力学上不稳定（不能与 Fe、C 平衡共存），属于介稳化合物，故平衡相图不给出。

**6-2**

渗碳体为 **Fe₃C**（1分）；简单正交点阵（1分）；由图可知晶胞中 Z＝4（1分）：

$$\rho = \frac{4\times(3\times55.85+12.01)}{6.022\times10^{23}\times4.515\times5.077\times6.720\times10^{-24}} = 7.743\ \mathrm{g\cdot cm^{-3}}$$（2分）

**6-3**

$$Fe_3C = 3Fe + C(\text{石墨})$$

加热使渗碳体分解为铁与石墨碳，碳溶于铁形成固溶体（退火/柔化），消除了硬脆的 Fe₃C 相，塑性提高。

**6-4**

$$Fe_3C(s) = 3Fe(s) + C(s)$$（1分）

$$\Delta_r H^\circ = -25.1\ \mathrm{kJ\cdot mol^{-1}},\quad \Delta_r S^\circ = -17.0\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}},\quad T = \frac{\Delta H}{\Delta S} \approx 1.48\times10^{3}\ K$$（1分）

因此在 1480 K 以上、从热力学的角度来看有利于渗碳体分解（题目口径：有利于渗碳体生成的最低温度即该转折温度）（1分）。

低温条件下，渗碳体分解反应虽然热力学有利，然而动力学禁阻（C 的扩散极慢），渗碳体处于亚稳态（1分）。

（因为形成固溶体，所以方程式中 Fe 以固态存在，以 Fe(g) 计算得 1920 K 是错误的。）
