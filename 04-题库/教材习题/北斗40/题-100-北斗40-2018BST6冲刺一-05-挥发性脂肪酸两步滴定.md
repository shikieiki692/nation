# 题-100-北斗40-2018BST6冲刺一-05-挥发性脂肪酸两步滴定

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（一）第5题（12分）｜难度：5｜教学层级：竞赛

## 题目

无氧消化（anaerobic digestion）技术被广泛应用于有机废物的处理中。在无氧体系中，挥发性脂肪酸 VFA 由于可能影响体系 pH，因此其浓度需要被准确控制。近期，研究人员报道了一种两步滴定测定 VFA 浓度的策略，过程如下：

（1）用浓度为 c 的盐酸调节样品至 pH 为 4.70，此时样品体积为 V₀。
（2）继续加入盐酸，调节样品 pH 为 4.20，此时加入盐酸 V_a，总体积为 V₁。此处假定体系为理想溶液。

请根据提示回答下列问题。

**5-1**（2分）已知体系中少量杂质离子可以用 Mⁿ⁺ 和 xᵐ⁻ 表示，VFA 阴离子可以用 VFA⁻ 表示。请分别给出在 pH 为 4.70 和 4.20 时体系的电荷守恒式。

**5-2**（3分）研究发现，体系中主要的杂质离子为碳酸氢根。已知碳酸的 pKa1、pKa2 分别为 6.35 和 10.33。请计算分析，pH 从 4.70 到 4.20 是否会对杂质离子的组成产生明显变化。

**5-3**（6分）研究发现，在加入盐酸的过程中，体系不会出现明显的沉淀。请基于以上分析，给出样品中 VFA 的总浓度 c₀ 的表达式。离子的浓度只需要给出符号，不需给出具体数据。VFA 的解离常数用 Ka 表示。

**5-4**（1分）研究发现，滴定时若剧烈搅拌，会产生较大的误差。请分析误差的来源。

### 答案

**5-1**

pH 为 4.70 时：

$$[\mathrm{H^+}]_0 + n[\mathrm{M^{n+}}]_0 = [\mathrm{VFA^-}]_0 + [\mathrm{OH^-}]_0 + m[\mathrm{x^{m-}}]_0$$

pH 为 4.20 时：

$$[\mathrm{H^+}]_1 + n[\mathrm{M^{n+}}]_1 = [\mathrm{VFA^-}]_1 + [\mathrm{OH^-}]_1 + m[\mathrm{x^{m-}}]_1$$

**5-2**

首先计算碳酸氢根离子浓度变化。由于酸性增加且酸度较大，可以忽略碳酸根的影响（pKa2 = 10.33 远高于体系 pH）。

$$[\mathrm{H^+}]_0 = 10^{-4.70} = 2.0\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$$

$$\delta_0 = \frac{10^{-6.35}\times 2.0\times10^{-5}}{10^{-6.35}\times 2.0\times10^{-5} + (2.0\times10^{-5})^2} = 0.022$$

$$[\mathrm{H^+}]_1 = 10^{-4.20} = 6.3\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$$

$$\delta_1 = \frac{10^{-6.35}\times 6.3\times10^{-5}}{10^{-6.35}\times 6.3\times10^{-5} + (6.3\times10^{-5})^2} = 0.0070$$

可见虽然碳酸氢根离子浓度相对变化较大，但由于绝大多数以碳酸（分子）形式存在，因此不会对杂质离子组成产生较大影响。

（注：此处并没有讨论碳酸氢根与 VFA 的相对浓度关系。为简化计算，在 5-1 中指出为少量杂质离子，但实际分析时能否忽略，还需进一步分析。）

**5-3**

由于滴定过程中没有引入杂质阳离子，且没有生成明显沉淀，可认为 Mⁿ⁺ 总量保持一致（1 分，需有表意一致的文字说明）。则应有：

$$n[\mathrm{M^{n+}}]_0 V_0 = n[\mathrm{M^{n+}}]_1 V_1$$

由于杂质阴离子浓度变化不大，可以认为：

$$n[\mathrm{M^{n+}}]_1 V_1 - n[\mathrm{M^{n+}}]_0 V_0 = cV_a$$

由 (2)×V₁ − (1)×V₀，可得（1 分）：

$$[\mathrm{H^+}]_1 V_1 - [\mathrm{H^+}]_0 V_0 = [\mathrm{VFA^-}]_1 V_1 - [\mathrm{VFA^-}]_0 V_0 + [\mathrm{OH^-}]_1 V_1 - [\mathrm{OH^-}]_0 V_0 + cV_a$$

其中（1 分）：

$$[\mathrm{VFA^-}]_1 V_1 = C_0V_0\frac{K_a}{[\mathrm{H^+}]_1 + K_a},\qquad [\mathrm{VFA^-}]_0 V_0 = C_0V_0\frac{K_a}{[\mathrm{H^+}]_0 + K_a}$$

则转化为（1 分）：

$$C_0V_0K_a\frac{[\mathrm{H^+}]_0 - [\mathrm{H^+}]_1}{([\mathrm{H^+}]_1 + K_a)([\mathrm{H^+}]_0 + K_a)} = ([\mathrm{H^+}]_1 - [\mathrm{OH^-}]_1)V_1 - ([\mathrm{H^+}]_0 - [\mathrm{OH^-}]_0)V_0 - cV_a$$

解出（1 分）：

$$C_0 = \frac{\{([\mathrm{H^+}]_1 - [\mathrm{OH^-}]_1)V_1 - ([\mathrm{H^+}]_0 - [\mathrm{OH^-}]_0)V_0 - cV_a\}([\mathrm{H^+}]_1 + K_a)([\mathrm{H^+}]_0 + K_a)}{V_0K_a([\mathrm{H^+}]_0 - [\mathrm{H^+}]_1)}$$

**5-4**

可能是由于搅拌导致碳酸分解成二氧化碳，这会导致体系 pH 上升。（若写 VFA 挥发，虽然与原文献不一致，但亦可说通，也可给分。）
