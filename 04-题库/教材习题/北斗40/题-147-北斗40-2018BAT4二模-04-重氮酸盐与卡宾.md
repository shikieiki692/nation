# 题-147-北斗40-2018BAT4二模-04-重氮酸盐与卡宾

> 来源：北斗学友40套全真模拟 · 2018年 BAT4/二模 大联考（四）第4题（13分）｜难度：5｜教学层级：竞赛

## 题目

重氮酸盐是一种反应过程中的活性中间体，在中性或酸性条件下会通过重氮盐分解。

**4-1** 2012 年发现单杂卡宾 A 与 N₂O 反应可以生成稳定的重氮酸盐化合物。

**4-1-1**（2分）请画出生成物的结构式。

**4-1-2**（4分）卡宾既有给电子的能力又有接受电子的能力，请比较卡宾 B 与 A 在给出和接受电子能力上的差别。

![[94d04816b4196bfd3b4a949988822ddda677583c89cf71169592a47ac517a874.jpg]]

（A：N-芳基咪唑-2-亚基卡宾。）

![[cfdd14fa6e0e74e4ed0e28cf48034d68621c30b8ff4baaa4111b322e904690b7.jpg]]

（B：CAP 类环烷基氨基卡宾。）

**4-1-3**（2分）由上一问的结论判断 A 与 B 谁能与 CO 反应，并画出反应的产物。

**4-2** 近期有人报道合成了一种重氮酸根做配体的配合物。PdCl₂(MeCN)₂：

![[6e02e1311b8483f7a5835df0a958c6e68f88bf3b225c4ccc598e1da56897a63a.jpg]]

**4-2-1**（2分）请画出配合物的结构式，配体以最稳定的构型配位。

**4-2-2**（3分）此配合物在固体中是以分子线形式存在，请画出分子线的示意图，并说明金属间相互作用的轨道。

### 答案

**4-1-1**

卡宾碳加成到 N₂O 的 N 端得重氮酸盐（卡宾-C(−)＝N⁺＝O 型，即 N-亚硝基偶氮酸盐两性离子）：

![[38c2a489f5d8ab6e5c5338f39737ecc12ed51ca81e484405d661ab057e7d86f9.jpg]]

**4-1-2**

B 给电子的能力比 A 强，因为 N 具有吸电子诱导效应，N 越多给电子能力越弱。

B 接受电子的能力比 A 强（原书如此——按推理应为「弱」，因为 N 的孤对电子与 C 的空轨道共轭，N 越多 C 的缺电子性越弱，接受电子的能力越弱）。

> **校勘注**：原书 4-1-2 第二句首排为「B 接受电子的能力比 A 强」，但理由句（「N 越多……接受电子的能力越弱」）指向 B 弱于 A，两处矛盾；按化学逻辑应为「B 接受电子的能力比 A 弱」，理由句照录。

**4-1-3**

B 可以与 CO 反应（B 给电子能力强，可向 CO 反馈/加合）：

![[cc0a92ab90fa726e265f3723f1e7f26b922c3fb097280caff3ce9f8bd3e6ad75.jpg]]

（产物：卡宾碳与 CO 加合的烯酮式结构 Ar–N–C(=C=O)–CAP 环。）

**4-2-1**

Pd 与两分子芳基重氮酸盐配体（N,O-螯合，最稳定构型）：

![[557ec78ef80eb5c2d4bb93a76213b63389d1ae4d5ae80c6ba64d7e84bcdc25d1.jpg]]

（Pd 中心：两个 N=N(O⁻) 邻苯二基型配体螯合。）

**4-2-2**

分子线示意（Pd…Pd 沿一维堆叠）：
