# 题-110-北斗40-2018BST6冲刺二-05-碲化铋热电材料晶体学

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第5题（14分）｜难度：5｜教学层级：竞赛

## 题目

热电材料是一种能将热能和电能相互转换的功能材料。M₂X₃ 为一代热电材料研究方向，其晶体结构可以看作 X 的每一层都为密堆积，而 M 选择性地填充其中八面体空隙。晶体中检测到有 X-X 层相邻，两层相邻的 M（即两层 M 中无空层）沿 c 轴投影不重合，且已知 M 沿 c 轴的排列方式为 …aabbcc…，M 为主族金属，且 M 的质量分数为 52.20%，已知六方晶胞参数 a = 380 pm，c = 3050 pm。

**5-1**（2分）通过尝试性的计算，得出 M₂X₃ 的化学式。

**5-2**（2分）写出 M₂X₃ 晶体的排列方式（如 NaCl 晶体排列方式为 …AeBaCbA…）。

**5-3**（3分）将 M 看作填隙原子，不计 X-X 层之间距离的差异，写出晶体中 M 的分数坐标。

**5-4**（2分）计算晶体的密度。

**5-5**（5分）判断晶体属于三方晶系还是六方晶系。若判断为三方晶系，则计算出对应的菱面体晶胞的晶胞参数。若判断为六方晶系，则画出其六方晶胞，找出晶胞中所有的对称元素，并说明对称元素的位置。

### 答案

**5-1**

可以先从常见价态为 +3 价的金属开始尝试，而常见的价态为 +3 价的金属离子有：In³⁺、Sb³⁺、Bi³⁺（加上 Al³⁺、Ga³⁺）。然后带入公式：

$$\frac{2\times M}{2\times M + 3\times X} = 0.5220$$

最后得到当 M 为 Bi 时，X 为 Te。故 M₂X₃ 为 **Bi₂Te₃**。

**5-2**

排列方式：**…BaCBaCbACbAcBAcB…**（沿 c 轴，大小写区分 Bi 层与 Te 层）

![[d875ee98ddb1ac7b11ff215dec61b3721f1d034189ee95e3beda139e86a626ea.jpg]]

![[222dc5d57d86d45b40e4d05b1405d2ae013c76c8e453abf24a435341d63b63f1.jpg]]

**5-3**

M（Bi）的分数坐标：

$$\left(\tfrac{2}{3},\tfrac{1}{3},\tfrac{1}{18}\right)\ \left(\tfrac{2}{3},\tfrac{1}{3},\tfrac{5}{18}\right)\ \left(\tfrac{1}{3},\tfrac{2}{3},\tfrac{13}{18}\right)\ \left(\tfrac{1}{3},\tfrac{2}{3},\tfrac{17}{18}\right)\ \left(0,0,\tfrac{7}{18}\right)\ \left(0,0,\tfrac{11}{18}\right)$$

**5-4**

$$\rho = \frac{n\times M_r}{N_A\times V} = \frac{6\times 209.0 + 127.6\times 9}{380\times 380\times 3050\times 6.022\times10^{23}\times10^{-30}\times \sin 120°} = 10.5\ \mathrm{g\cdot cm^{-3}}$$

（六方晶胞含 Bi₆Te₉，Z = 3；式量 2402.4。）

**5-5**

三方晶系（R 心，因 aabbcc 层序中 cc 与 aa 相邻有 X-X 层接触、破坏六方 6₃ 轴）。

方法1：联立方程

$$a_b = 2\times a_r\times\sin\frac{\theta}{2}$$

$$C_h = 3\times\sqrt{\left(a_r\times\cos\frac{\theta}{2}\right)^2 - \left(0.5\times a_H\times\tan 30°\right)^2}$$

得到 a_r = 1040 pm，θ = 21.05°。

方法2：根据点阵点位置做题。R 心六方晶胞中两个点阵点（顶点和 1/3,2/3,1/3 或 2/3,1/3,2/3 处）距离就是菱面体晶胞的 a′，可求得：

$$a' = \sqrt{\left(\frac{\sqrt{3}a}{3}\right)^2 + \left(\frac{c}{3}\right)^2} = 1040\ \mathrm{pm}$$

再根据 sinθ 或 tanθ 求得角度。
