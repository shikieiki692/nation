# 题-302-北斗40-2016BAT4二模-08-Trioxacarcins全合成

> 来源：北斗学友40套全真模拟 · 2016年 BAT4/二模 大联考（四）第8题（24分）｜难度：5｜教学层级：竞赛

## 题目

Trioxacarcins 是一类具有极强细胞毒性的生物分子，最初是在波卓链霉菌的发酵液中发现的。在对其的后续研究中发现，这类分子能够定向地与 DNA 结合，具有在生物体内运载药物和靶向治疗癌症的潜力。2016 年，著名化学家 K. C. Nicolaou 发表了这类化合物的最新全合成方法。

Trioxacarins 部分合成路线如下：

![[85b65c37807ad29b511233fbd5bd39eb57635b3cbfd00c3db07f50e31ecca3ea.jpg]]

（Hauser-Kraus 反应：氰基茚满酮（A）＋ OTBS/OPMB 取代环己烯酮（B）─1. t-BuOLi  2. Me₂SO₄→ 蒽酮产物（C）；─Si 化→ D。）

![[62478d7a5dc274b1f1a72bcc7f2cf0ae6ebd04f63f51a5614b8f3c759012e655.jpg]]

（D ─HOCH₂CH＝CHSnBu₃, Ph(PPh₃)₄, CuTC→ E（Stille 偶联）；E ─Sharpless 环氧化→ F。）

![[b59754cffa5c4fa52162763863fb3cb219725a8f486e4ac51493a80e49557f76.jpg]]

（F ＋ CH₂＝CH—CH(OMe)₂ 型烯酮 ─DABCO→ Baylis-Hillman 加成产物 ─→ Trioxacarcins。）

CuTC：一价铜盐，在该反应中可加速反应，提高产率。DABCO：三级胺。

**8-1** 生成 C 的反应是 Hauser-Kraus 反应，通过两步碳负缩合得到。

**8-1-1**（4分）试写出反应机理（不必写甲基化）。

**8-1-2**（2分）该 Hauser-Kraus 反应得到产物有两个酚羟基，而在后续的甲基化反应中，这两个酚羟基具有选择性，试猜测原因。

**8-2** 生成 E 的反应是 Stille 偶联反应。

**8-2-1**（4分）对于 Pd 催化的有机反应中，一般来说，有催化活性的是 0 价 Pd，但在实际实验中，由于 0 价 Pd 比较昂贵又不易保存，常使用 +2 价 Pd 来代替，再通过还原剂还原成 0 价 Pd。而通常采用的还原剂为同时具有配位作用的三乙胺和三苯基膦，试猜测两者的还原产物。

**8-2-2**（2分）有机金属催化反应的反应机理通常由氧化加成、还原消去等几类反应组成，试写出该 Stille 反应的两个重要中间体。

**8-3** F 生成 G 的反应是经典的 Baylis-Hillman 反应。

**8-3-1**（4分）该反应的一个重要中间体如图所示：

![[2cbe59eaeb56c9fab15b654b0dea4d0c8dfc99c29d184baa41c9e2dd6cb88d4e.jpg]]

试写出该反应的反应机理。

**8-3-2**（2分）试指出 DABCO 的作用。

**8-4** 天然的 Trioxacarcin C 的结构式如图所示：

![[ed1a64de21491b5b8228a2371dd8ce806532bfc90219bb2274ba4ea131f4ebdd.jpg]]

但是在 Nicolaou 之前，人们并不清楚天然的 Trioxacarcin C 中，标有「*」处碳的手性。Nicolaou 通过分别合成一对 Trioxacarcin C 的手性异构体，并与天然的 Trioxacarcin C 进行比较来确定天然 Trioxacarcin C 的准确结构。

**8-4-1**（2分）Nicolaou 合成的这对手性异构体是一对____。
A. 非对映体　　B. 差向异构体　　C. 外消旋体　　D. 对映体

**8-4-2**（4分）Nicolaou 在合成这对手性异构体中最重要的一步是通过酮的还原反应来达成的。

![[acdd5d53e87336127c6b3097d4a9bd6cb6d39f2fed9095e497a326cfb7d10c39.jpg]]

![[ca115499ad2cccdddd2a0cede1adaabb5d3af5c76fa3a2b98b5b5e09c8ce0694.jpg]]

试分别画出这两个反应的重要中间体，并猜测产生差异的原因。

### 答案

**8-1-1**

Hauser-Kraus 机理（锂代茚腈负离子对环己烯酮 Michael 加成 → 分子内环化 → CN 消除得蒽酮 → 互变异构为芳烃酚式 → Me₂SO₄ 甲基化）：

![[f111bd21cc6f462697bdd553f54ff2aae896e0099357cf09e8f7773f334aded0.jpg]]

（① NC、Li 同碳的茚满酮锂盐负离子进攻环己烯酮 β-碳；② 烯醇负离子分子内进攻酯羰基、经 O—Li 螯合中间体消除 CN⁻ 闭环；③ 得三环蒽醌负离子，互变异构为双酚式；④ Me₂SO₄ 甲基化。）

**8-1-2**

上方羟基与右侧羰基形成氢键。

（形成分子内氢键的酚羟基酸性降低、反应性下降，从而实现选择性甲基化；原书答案区另附结构互变示意：）

![[6f15c19514e355afb7eb02456ccffafb0634b84619fc8c2ba7a8d21de2ac67e9.jpg]]

**8-2-1**

二乙基（乙烯基）胺和三苯氧膦。

（三乙胺经 β-消除被氧化为乙烯基铵/烯胺类物种、自身还原 Pd；PPh₃ 被氧化为 O＝PPh₃，同时还原 Pd(II)→Pd(0)。）

**8-2-2**

R¹—Pd—I 与 R¹—Pd—R²（氧化加成后与金属转移化后的两个有机钯中间体）。

**8-3-1**

Baylis-Hillman 机理（DABCO 对烯酮 Michael 加成 → 烯醇负离子进攻醛 → 质子转移经六元环过渡态 → E1cb 消除释放 DABCO）：

![[e3f227ae6be59f20933014aad2ca5cfd653c541549421e7653d1417a63723ab2.jpg]]

（DABCO 加成于 α,β-不饱和酯生成两性离子烯醇负离子 → 进攻 R—CHO 得烷氧负离子 → 经 DABCO⁺—N 与羟基氢的质子转移六元环过渡态 → 消除再生 DABCO，得 α-亚甲基-β-羟基产物。）

**8-3-2**

做亲核试剂；提供碱性。

**8-4-1**

D. 对映体。

**8-4-2**

两条路线的还原条件不同、中间体的螯合方式不同，导致 H⁻ 进攻面不同：

路线一（NaBH₄、CeCl₃，Luche 型）：Ce³⁺ 与羰基氧和邻位乙酰氧基螯合，H⁻ 从 Me 一侧进攻：

![[814288de1a94d593c409e383842d99f13c31ec07e607bded4cd46b0c87f31a0d.jpg]]

路线二（1. K₂CO₃ 脱乙酰基 2. LiAlH(t-BuO)₃）：裸羟基与羰基氧被 Li⁺ 螯合成五元环，H⁻ 从 OH 一侧的相反面进攻：

![[021836a38bb34867dde607385500f4a8399ba6a3d58aecd8aa93277e0a1d91f4.jpg]]

![[426a2b4ec10471cee005b46e927a67bddeb72525216548c241abc144115aa142.jpg]]

（Ce 离子半径大，Li 离子半径小——螯合环几何不同决定了氢负离子进攻的方向，从而分别给出两个对映异构体。）
