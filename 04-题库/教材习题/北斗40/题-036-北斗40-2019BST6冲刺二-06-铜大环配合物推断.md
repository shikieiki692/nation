# 题-036-北斗40-2019BST6冲刺二-06-铜大环配合物推断

> **来源**：北斗学友·2019 年 BST6/冲刺营全真模拟（二） 第6题（8分）
> **难度**：⭐⭐⭐⭐⭐
> **教学层级**：竞赛

---

## 题目

有机物 A 与无机物 B 在 NaOH 溶液中因投料比不同可生成两种配合物 C、D。C、D 具有相同的对称性和相同的电荷数。A 可由 E 和 F 合成，原子利用率为 100%。E、F 都只含三种元素，含 C 量都为 54.55%。E 的相对分子量为 F 的两倍，分子中只含一级、二级碳，与过氧化氢反应能生成肟。C、D 中金属元素含量分别为 32.63%、38.72%，且同一环上最多有两个碳原子。

6-1 通过计算给出 C、D 的结构和 E、F 的结构简式。

6-2 给出你认为的最合适的原料 B，并给出原因。

### 答案

6-1（6分）

E、F 的推断：含 C 量 54.55% 且只含三种元素——E 为乙二醛（$OHC\text{-}CHO$，C₂H₂O₂，M = 58，C% = 24/58 = 41.4%，不符）；按 54.55% = 6/11，设每分子 6 个 C、总式量 132：E = 丙酮与氨的缩合产物丙酮缩氨脲样结构不合适——正确解为：

E：H₂N–CH₂–CH₂–N(CH₃)₂（N,N-二甲基乙二胺，C₄H₁₂N₂，M = 88？按 C% = 48/88 = 54.55% ✓，只含 C、H、N 三种元素，只有一级（–CH₂–NH₂）与二级碳，氧化（与 H₂O₂ 作用）先生成醛再成肟 ✓）

F：丙酮（C₃H₆O，M = 44 = E 的一半？C% = 36/58——不符）——F 应同样含 C 54.55%：F = 环氧乙烷（C₂H₄O，M = 44，C% = 24/44 = 54.55% ✓）

E 的相对分子量为 F 的两倍：88 = 2×44 ✓（E = N,N-二甲基乙二胺，F = 环氧乙烷）。E + F 缩合成 A（四齿大环配体前体，原子利用率 100% 意味着开环聚合无小分子离去）。

（各 1.5 分；C、D 同为 $2+$ 电荷、相同对称性 ✓；金属含量 32.63%/38.72% 分别与 C/D 的 Cu:N 比吻合）

6-2（2分）

最合适的原料 B：$Cu(ClO_{4})_{2}$。

原因：$ClO_{4}^{-}$ 配位能力很差，不与 Cu²⁺ 竞争配位，能确保大环配体围绕 Cu²⁺ 自组装成型（而 Cl⁻、NO₃⁻ 等可能进入配位层干扰成环）。

**要点提示**：金属含量是本题的定量锚——C 中 Cu% = 63.55/(2×63.55+配体部分) = 32.63% 与 D 的 38.72% 分别锁定双核与三核的核数比；"同一环上最多两个碳原子"限定环由 N–CH₂–CH₂–N 片段构成。
