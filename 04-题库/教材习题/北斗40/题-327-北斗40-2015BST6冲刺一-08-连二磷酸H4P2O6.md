# 题-327-北斗40-2015BST6冲刺一-08-连二磷酸H4P2O6

> 来源：北斗学友40套全真模拟 · 2015年 BST6/冲刺营（一）第8题（8分）｜难度：4｜教学层级：竞赛

## 题目

无机酸 X 1.620 g 能与 1.000 mol·L⁻¹ 的 NaOH 溶液 40.00 mL 完全中和；一定条件下 1.620 g X 水溶液加热会分解，所得产物能与 1.000 mol·L⁻¹ 的 NaOH 溶液 50.00 mL 完全中和。

**8-1**（4分）通过计算和推理，确定 X 的化学式。

**8-2**（2分）写出 X 的结构简式及其互变异构体。

**8-3**（2分）写出 X 的分解反应方程式。

### 答案

**8-1**

X 反应前后中和碱的能力是 4:5，可以确定 X 是四元酸。

X 的摩尔质量为 1.620 g/(0.04000 mol)＝162.0 g·mol⁻¹（每 mol X 消耗 4 mol NaOH）。从 162 中扣除 4 个 −OH（4×17），剩余 94 g·mol⁻¹。

1 个中心原子不可能接 4 个 −OH，一般有 2 个中心原子，讨论 O 可得应为 P₂O₂（两个 P(IV) 直接相连）。

D 的化学式为 H₄P₂O₆（连二磷酸）。

**8-2**

X 的结构简式（HO)₂P(O)—P(O)(OH)₂（两个 P 均为 P(IV)、P—P 直接相连）：

（异构体：HO)₂P—O—P(O)(OH)₂ 型，其中一端磷以 P—H 形式存在。）

**8-3**

H₄P₂O₆ + H₂O ═ H₃PO₄ + H₃PO₃

（验证：产物酸性 H₃PO₄ 三元＋H₃PO₃ 二元＝5 mol H⁺/mol X，与题给「50.00 mL 1.000 mol·L⁻¹ NaOH」吻合 ✓；P、H、O 守恒 ✓。）
