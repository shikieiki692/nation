# 题-088-北斗40-2018BST4强化二-03-质谱推断联吡啶与Mo羰基配合物

> 来源：北斗学友40套全真模拟 · 2018年 BST4/强化营 全真模拟（二）第3题（11分）｜难度：5｜教学层级：竞赛

## 题目

实验发现，某中性单中心配合物 A 可以用于二氧化碳的还原。该配合物满足 EAN 规则，含有两种配体 L 和 CO，已知 L 为常见配体。元素分析显示，除了 C、H、O、N 外，该配合物只含有一种金属元素 M。

**3-1**（5分）已知 L 由 C、H、N 三种元素组成，质谱分析显示，L 的 M 与 M+1 的峰高比例为 100 : 10.8。已知 C 的同位素丰度为 ¹²C 占 98.89%，¹³C 占 1.11%，H 占 L 分子量的 5.16%，请给出 L 的分子式与结构。

**3-2**（6分）该配合物变热可逐步脱除 CO，脱除两个 CO 时，分子量下降 15.38%，且一个配合物分子中只含有一个 L 配体。请根据给出的信息，推断该化合物分子式，并给出结构。

### 答案

**3-1**

根据质谱信息与同位素丰度，不妨假设有 n 个 C 原子，则：

$$\frac{0.9889^{\,n}}{n\times 0.9889^{\,n-1}\times 0.0111} = \frac{100}{10.8}$$

解得 n = 9.62。考虑到 N 和 H 同位素的影响，应向上取整，即有 **10 个 C 原子**。

由于有至少一个 N 原子，那么分子量就将大于 134.1。不妨假设有 m 个 H 原子：

- m = 7 时，M = 136.74，不合理；
- m = 8 时，M = 156.28，对应为 C₁₀H₈N₂，即**联吡啶（bpy）**，满足题意（H 占 8/156.28 = 5.12% ≈ 5.16% ✓）。

**3-2**

脱除两个 CO，分子量下降 15.38%，那么总分子量为 2×28.01/0.1538 = 364.24。

根据题目已知信息，不妨假设分子式为 M(bpy)(CO)ᵧ，其中 y ≥ 2。考虑到该配合物满足 EAN 规则，可以进行如下推断：

- 若 y = 3，那么 M 的价层电子数为 8（=18−4−2×3−4），M 原子量为 124.02，不符合 Fe、Ru、Os 三种元素，不成立；
- 若 y = 4，那么 M 的价层电子数为 6，M 原子量为 96.01，可见 **Mo** 满足。

综上：该配合物分子式为 **Mo(bpy)(CO)₄**（95.95＋156.18＋4×28.01＝364.2 ✓；EAN：6＋4＋8＝18 ✓），结构如下：
