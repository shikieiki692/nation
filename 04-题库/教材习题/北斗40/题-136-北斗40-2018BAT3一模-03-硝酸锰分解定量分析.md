# 题-136-北斗40-2018BAT3一模-03-硝酸锰分解定量分析

> 来源：北斗学友40套全真模拟 · 2018年 BAT3/一模 大联考（三）第3题（7分）｜难度：5｜教学层级：竞赛

## 题目

下面的反应方程式常用来描述硝酸锰的分解：

$$\mathrm{Mn(NO_3)_2} = \mathrm{MnO_2} + 2\mathrm{NO_2}$$

但实际上，对形成的锰氧化物进行定量分析，其原子比 n(O) : n(Mn) < 2。

在一次实验中，1 mmol 硝酸锰在 100 mL 密闭容器中加热后，质量减少了 52.04%。

**3-1**（2分）请指出所有可能生成的气体。

**3-2**（5分）当容器内部气压稳定后，请计算内部所有生成气体的分压。已知该条件下反应 2NO₂ ⇌ N₂O₄ 的 Kp 为 0.28，体系温度为 308 K。

### 答案

**3-1**

$$\mathrm{Mn(NO_3)_2} = \mathrm{MnO_x}$$

$$x = \frac{178.96\times(1-0.5204) - 54.94}{16.00} = 1.93$$

由此可见，体系中应有 N₂O₅。由于 N₂O₅ 会分解，以及 NO₂ 存在平衡，因此可能存在 **N₂O₅、NO₂、N₂O₄、O₂**。

**3-2**

不妨设反应方程式为 Mn(NO₃)₂ = MnO₁.₉₃ + xNO₂ + yN₂O₅，则 x + 2y = 2，2x + 5y = 4.07，得 x = 1.86、y = 0.07。

初始状态生成 1.86 mmol NO₂ 和 0.07 mmol N₂O₅。由于 N₂O₅ 会分解为 O₂ 和 NO₂，初始态体系中有：

$$n(\mathrm{NO_2}) = 1.86 + 0.07\times2 = 2\ \mathrm{mmol},\qquad n(\mathrm{O_2}) = 0.035\ \mathrm{mmol}$$

对应初始分压：p(NO₂) = 0.51 atm，p(O₂) = 8.9×10⁻³ atm。

对 2NO₂ ⇌ N₂O₄ 平衡（Kp = 0.28）求解后（原书中间式排印失真），最终各分压满足总压守恒（0.41 + 2×0.048 + 0.0089 ≈ 0.51 atm ✓）：

$$p(\mathrm{NO_2}) = 0.41\ \mathrm{atm},\quad p(\mathrm{N_2O_4}) = 0.048\ \mathrm{atm},\quad p(\mathrm{O_2}) = 8.9\times10^{-3}\ \mathrm{atm}$$

> **校勘注**：原书 3-2 的中间平衡式「(0.51−a)² = 0.28」与「a = 0.003」互相矛盾（√0.28 > 0.51），系排印失真；本题卡以最终分压结果（总压自洽）照录，中间求解过程按 Kp = p(N₂O₄)/p(NO₂)² = 0.28 重解可得 p(NO₂) = 0.41 atm 附近的自洽解。
