# 题-124-北斗40-2018BST7押题二-01-完成反应方程式

> 来源：北斗学友40套全真模拟 · 2018年 BST7/押题营 全真模拟（二）第1题（10分）｜难度：4｜教学层级：竞赛

## 题目

请给出下述反应的方程式：

**1-1**（2分）一氧化二氯与氨气混合爆炸。

**1-2**（2分）用硫粉覆盖打碎的水银温度计。

**1-3**（2分）三硫化砷溶解于氢氧化钠溶液，得到两种 1 : 1 的含砷盐。

**1-4**（2分）用氰化钠溶液浸取游离状态下的银。

**1-5**（2分）六氟化铀水解得到氟化铀酰。

### 答案

**1-1**

$$3\mathrm{Cl_2O} + 10\mathrm{NH_3} = 2\mathrm{N_2}\uparrow + 6\mathrm{NH_4Cl} + 3\mathrm{H_2O}$$

（Cl(+1→−1) 得 2e×6=12e；NH₃ 中 4 个 N(−3→0) 失 3e×4=12e ✓。）

**1-2**

$$\mathrm{Hg} + \mathrm{S} = \mathrm{HgS}$$

（消除汞蒸气毒性的经典操作。）

**1-3**

$$\mathrm{As_2S_3} + 6\mathrm{NaOH} = \mathrm{Na_3AsS_3} + \mathrm{Na_3AsO_3} + 3\mathrm{H_2O}$$

（硫代亚砷酸钠与亚砷酸钠两种 1 : 1 含砷盐。）

**1-4**

$$4\mathrm{Ag} + 8\mathrm{NaCN} + 2\mathrm{H_2O} + \mathrm{O_2} = 4\mathrm{Na[Ag(CN)_2]} + 4\mathrm{NaOH}$$

（氰化提银：Ag(0→+1) 失 4e，O₂(0→−2) 得 4e ✓。）

**1-5**

$$\mathrm{UF_6} + 2\mathrm{H_2O} = \mathrm{UO_2F_2} + 4\mathrm{HF}$$

（UF₆ 剧烈水解，得氟化铀酰。）
