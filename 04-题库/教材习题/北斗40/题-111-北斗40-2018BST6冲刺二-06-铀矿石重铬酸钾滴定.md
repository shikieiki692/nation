# 题-111-北斗40-2018BST6冲刺二-06-铀矿石重铬酸钾滴定

> 来源：北斗学友40套全真模拟 · 2018年 BST6/冲刺营 全真模拟（二）第6题（9分）｜难度：5｜教学层级：竞赛

## 题目

铀矿石中铀含量的测定可以通过间接氧化还原进行滴定测量。先将矿石溶解在 12 mol·L⁻¹ 的硫酸中，然后以钼蓝为指示剂加入 Walden 还原剂进行还原，之后加入过量 FeCl₃，后以二苯胺磺酸钠为指示剂，以 K₂Cr₂O₇ 标准溶液进行滴定。

准确称取 0.7193 g 的 K₂Cr₂O₇ 置于盛有 100 mL 水的烧杯中，后稀释并转移至 250 mL 的容量瓶中，摇匀。将 0.315 g 的含铀矿石按照上述方法处理后，以 K₂Cr₂O₇ 标准溶液进行滴定，消耗 K₂Cr₂O₇ 标准溶液 11.33 mL，同时做空白实验得到空白值为 0.81 mL；同上述方法，处理质量为 0.479 g 的含铀矿石时，消耗 K₂Cr₂O₇ 标准溶液 17.28 mL（除矿石质量不同外其余条件相同）；处理质量为 0.578 g 的含铀矿石时，消耗 K₂Cr₂O₇ 标准溶液 21.50 mL。（U 的相对分子质量用 238）下图为 U 在酸性下的部分电极电势图。

![[7a872a9cc69fdfc61cafbe8b33a71b70c30f112fcbe8cc79d2c171b9f4561e43.jpg]]

**6-1**（2分）写出以 K₂Cr₂O₇ 滴定还原态 U 的反应方程式。

**6-2**（2分）以方程式表示 Fe³⁺ 的作用。

**6-3**（5分）计算 U 的平均含量，试解释为何 3 次平行实验测得的结果相差较大。

### 答案

**6-1**

$$\mathrm{Cr_2O_7^{2-}} + 3\mathrm{U^{4+}} + 2\mathrm{H^+} = 3\mathrm{UO_2^{2+}} + 2\mathrm{Cr^{3+}} + \mathrm{H_2O}$$

（守恒自核：O 7＝6＋1、H 2＝2、电荷 −2＋12＋2＝＋6＋6 ✓；电子 U(+4→+6)×3＝Cr(+6→+3)×2 ✓。）

**6-2**

$$2\mathrm{Fe^{3+}} + \mathrm{U^{4+}} + 2\mathrm{H_2O} = \mathrm{UO_2^{2+}} + 4\mathrm{H^+} + 2\mathrm{Fe^{2+}}$$

$$6\mathrm{Fe^{2+}} + \mathrm{Cr_2O_7^{2-}} + 14\mathrm{H^+} = 6\mathrm{Fe^{3+}} + 2\mathrm{Cr^{3+}} + 7\mathrm{H_2O}$$

（Fe³⁺ 将 U(IV) 定量氧化为 U(VI)，自身被还原的 Fe²⁺ 再由 Cr₂O₇²⁻ 滴定并再生 Fe³⁺。）

**6-3**

$$C_{K_2Cr_2O_7} = \frac{0.7193}{(39.10\times2 + 52.00\times2 + 16.00\times7)}\times\frac{1000}{250} = 0.009780\ \mathrm{mol\cdot L^{-1}}$$

1 mol K₂Cr₂O₇ ∼ 3 mol U⁴⁺：

$$\omega_{U1} = \frac{0.009780\times(11.33-0.81)\times 3\times 238\times10^{-3}}{0.315}\times 100\% = 23.3\%$$

$$\omega_{U2} = \frac{0.009780\times(17.28-0.81)\times 3\times 238\times10^{-3}}{0.479}\times 100\% = 24.0\%$$

$$\omega_{U3} = \frac{0.009780\times(21.50-0.81)\times 3\times 238\times10^{-3}}{0.578}\times 100\% = 25.0\%$$

平均含量：

$$\omega_U = \frac{0.233 + 0.240 + 0.250}{3} = 24.1\%$$

原因：用 K₂Cr₂O₇ 滴定 Fe²⁺ 时，随着 Fe²⁺ 含量的增大，指示剂（二苯胺磺酸钠）空白值也增大，因此用第一次试验的空白值去处理后面第二、三组实验的数据会导致空白值不能完全消除，所以测得的含量不准。

> **校勘注**：原书「K₁Cr₂O₃」为 K₂Cr₂O₇ 之 OCR 误、「随意测得」为「所以测得」之误，已改。
