# 题-894-二分册-L4对例3-2003全国初赛钠硫蓄电池

> **来源**：高中化学竞赛教程第二分册 · 第4讲 竞赛对接 例3（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L2927~2955，答案 inline）

## 题目

【例3】（2003 年全国初赛）下图是一种正在投入生产的大型蓄电系统。左右两侧为电解质储罐，中央为电池，电解质通过泵不断在储罐和电池间循环；电池中的左右两侧为电极，中间为离子选择性膜，在电池放电和充电时该膜可允许钠离子通过；放电前，被隔开的电解质为 $\mathrm{Na_2S_2}$ 和 $\mathrm{NaBr_3}$，放电后，分别为 $\mathrm{Na_2S_4}$ 和 $\mathrm{NaBr}$。

![[4560329f3df5e72a1a951ebb61560c1d7fbde6228395ebc48f076c60f259a376.jpg]]

(1) 左、右储罐中的电解质分别是____。

(2) 写出电池充电时，阳极和阴极的电极反应。

(3) 写出电池充、放电的反应方程式。

(4) 指出在充电过程中钠离子通过膜的流向。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**过程探究**（原书 L2939~2945）

(1) 可根据发生反应的类型来判断。电池放电时，$\mathrm{Na_2S_2} \longrightarrow \mathrm{Na_2S_4}$（S 平均氧化数 −1→−1/2，化合价升高，发生氧化反应，是电池负极），因此右边储罐中的电解质是 $Na_2S_2$ 和 $Na_2S_4$，那么左边储罐中应存放 $NaBr_3$ 和 $NaBr$。

(2) 充电与放电是相反的过程。充电时 $NaBr \longrightarrow NaBr_3$、$Na_2S_4 \longrightarrow Na_2S_2$：阳极反应为 $3NaBr - 2e^{-} \longrightarrow NaBr_3 + 2Na^{+}$，阴极反应为 $Na_2S_4 + 2Na^{+} + 2e^{-} \longrightarrow 2Na_2S_2$。

(3) 原电池充放电的方程式是电极反应的总和：$2Na_2S_2 + NaBr_3 \xrightarrow[\text{充电}]{\text{放电}} Na_2S_4 + 3NaBr$。注意充电与放电的方程式相反，但不是化学平衡中的可逆反应，因为充电要外接电源，与放电时反应的条件不同。

(4) 充电时，阳极（左边）反应生成较多游离的 $Na^{+}$，而阴极（右边）反应消耗 $Na^{+}$，因此 $Na^{+}$ 流动方向由左到右。

**参考解答**（1）左：$NaBr_3/NaBr$；右：$Na_2S_2/Na_2S_4$。（2）阳极：$3NaBr - 2e^{-} \longrightarrow NaBr_3 + 2Na^{+}$；阴极：$Na_2S_4 + 2Na^{+} + 2e^{-} \longrightarrow 2Na_2S_2$。（3）$2Na_2S_2 + NaBr_3 \xrightarrow[\text{充电}]{\text{放电}} Na_2S_4 + 3NaBr$。（4）$Na^{+}$ 的流向为从左到右。
