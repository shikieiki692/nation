# 题-853-二分册-L2实3-重水pD四判断

> **来源**：高中化学竞赛教程第二分册 · 第2讲 实战演练3（`化学竞赛教程2/..._1-199.md` L1604~1608，答案 L1724~1726）

## 题目

3 重水 $\left(\mathrm{D}_2\mathrm{O}\right)$ 的离子积为 $1.6\times10^{-15}$，可以用类似定义 pH 的方法规定 $\mathrm{pD}=-\lg\left[c(D^{+})\right]$，以下关于 pD 的叙述正确的是（ ）。

A. 中性溶液的 pD = 7.0

B. 含 0.01 mol NaOD 的 D₂O 溶液 1 L，其 pD = 12.0

C. 溶解 0.01 mol DCl 的 D₂O 溶液 1 L，其 pD = 2.0

D. 在 100 mL 0.25 mol·L⁻¹ DCl 的 D₂O 溶液中，加入 50 mL 0.2 mol·L⁻¹ NaOD 的重水溶液，其 pD = 1.0

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

CD

### 解析（原书答案 L1724~1726）

$K_{\text{重水}} = c(D^{+})\cdot c(OD^{-}) = 1.6\times10^{-15}$，中性时 $c(D^{+}) = c(OD^{-}) = 4.0\times10^{-8}\,\mathrm{mol\cdot L^{-1}}$，所以 pD = pOD = 7.40，A 错。含 0.01 mol NaOD 的 1 L D₂O 溶液，$c(OD^{-}) = 10^{-2}$，pOD = 2.0，pD = 14.8 − 2.0 = 12.8，B 错。0.01 mol DCl 的 1 L 溶液 pD = 2.0，C 对。100 mL 0.25 mol·L⁻¹ DCl 中加入 50 mL 0.2 mol·L⁻¹ NaOD：剩余 $c(D^{+}) = (0.1\times0.25 - 0.05\times0.2)/0.15$……按原书算法 $c(D^{+}) = 0.1\times0.25 - 0.05\times0.2 = 0.015$ mol/总体积后 $\mathrm{pD} = 1.0$，D 对。答案：CD。

> **校勘注**：原书解析 D 项的浓度计算未显式除以总体积（0.015 mol / 0.15 L = 0.1 mol·L⁻¹ → pD = 1.0 ✓），数值自洽；照录。
