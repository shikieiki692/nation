# 题-933-二分册-L6例1-配合物命名表格与CrNH3Cl推断

> **来源**：高中化学竞赛教程第二分册 · 第6讲 例1（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L4001~4022，答案 inline）

## 题目

## 【例1】

(1) 填写下表空白处。

| 序号 | 配合物的化学式 | 配合物的名称 | 形成体 | 配位体 | 配位数 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | [Cu(H₂O)₄]SO₄ | 硫酸四水合铜(II) | Cu(II) | H₂O | 4 |
| 2 | | 二氯化四氨合锌(II) | | | |
| 3 | [CoClNO₂(NH₃)₄]Cl | | | | |
| 4 | K₃[Fe(CN)₆] | | | | |
| 5 | | 五氯·一氨合铂(IV)酸钾 | | | |

(2) 在一个配位体分子中若有二个配位原子，同时与一个中心离子（或原子）成键时，即可形成环状化合物。乙二胺四乙酸是一种常用的含有多个配位原子的试剂，请写出乙二胺四乙酸分子的结构简式。其中的配位原子最多可以有几个？最多可形成几个五元环？

(3) 某配合物的摩尔质量为 $260.6\,\mathrm{g\cdot mol^{-1}}$，按质量百分比计，其中 Cr 占 20.0%，$NH_3$ 占 39.2%，Cl 占 40.8%；取 25.0 mL 浓度为 $0.052\,\mathrm{mol\cdot L^{-1}}$ 的该配合物的水溶液用 $0.121\,\mathrm{mol\cdot L^{-1}}$ 的 $AgNO_3$ 滴定，达到终点时耗去 $AgNO_3$ 32.5 mL；滴加 NaOH 使该化合物的溶液呈强碱性，未检出 $NH_3$ 的逸出。试确定该配合物组成。

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**过程探究**（(3)，原书 L4011）

由 Cr、$NH_3$、Cl 的百分比之和为 100% 知该物不含其他元素；由百分比可得它们的物质的量比为 Cr:$NH_3$:Cl = 1:6:3。由滴定消耗的 $Ag^{+}$ 的量可算出被 $Ag^{+}$ 沉淀的 $Cl^{-}$ 是全部所含的 $Cl^{-}$。由使该化合物溶液呈强碱性不能释放出氨可见 $NH_3$ 被 $Cr^{3+}$ 牢牢结合住。

$$
Cr:NH_3:Cl = \frac{0.20\times260.6}{52}:\frac{0.392\times260.6}{17}:\frac{0.408\times260.6}{35.5} = 1:6:3
$$

每摩尔配合物里所含的氯 $= \dfrac{32.5\times0.121}{25.0\times0.052}\approx3\,\mathrm{mol}$。

**参考解答**（原书 L4015~4022）

(1)

| 序号 | 配合物的化学式 | 配合物的名称 | 形成体 | 配位体 | 配位数 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 2 | [Zn(NH₃)₄]Cl₂ | 二氯化四氨合锌(II) | Zn(II) | NH₃ | 4 |
| 3 | [CoClNO₂(NH₃)₄]Cl | 氯化一氯·一硝基·四氨合钴(III) | Co(III) | Cl⁻、NO₂⁻、NH₃ | 6 |
| 4 | K₃[Fe(CN)₆] | 六氰合铁(III)酸钾 | Fe(III) | CN⁻ | 6 |
| 5 | K[PtCl₅NH₃] | 五氯·一氨合铂(IV)酸钾 | Pt(IV) | Cl⁻、NH₃ | 6 |

(2) 乙二胺四乙酸（EDTA）结构中含 2 个 N 与 4 个羧基 O，配位原子最多 6 个；最多可形成 5 个五元环（结构图见原书 c96fcbc9）。

(3) 该配合物为 $\left[\mathrm{Cr(NH_3)_6}\right]\mathrm{Cl_3}$。
