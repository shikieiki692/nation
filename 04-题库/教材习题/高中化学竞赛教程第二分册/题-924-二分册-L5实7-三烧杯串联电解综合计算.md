# 题-924-二分册-L5实7-三烧杯串联电解综合计算

> **来源**：高中化学竞赛教程第二分册 · 第5讲 实战演练7（`化学竞赛教程2/..._1-199.md` L3671~3693，答案 L3809~3823）

## 题目

7 下图所示装置中，甲、乙、丙三个烧杯分别盛放 100 g 5.00% 的 NaOH 溶液、足量的 $CuSO_4$ 溶液和 100 g 10.00% 的 $K_2SO_4$ 溶液，电极均为石墨电极。

![[0dc0074c18ac2c215e973f722ff78d21771ce76d960ce9502d4df9ebaef56652.jpg]]

（甲、乙、丙）

(1) 接通电源，经过一段时间后，测得丙中 $K_2SO_4$ 浓度为 10.47%，乙中 c 电极质量增加。据此回答问题：

① 电源的 N 端为____极。

② 电极 b 上发生的电极反应为____。

③ 电极 b 上生成的气体在标准状况下的体积为____。

④ 电极 c 的质量变化是____ g。

⑤ 电解前后各溶液的酸、碱性大小是否发生变化？简述其原因：甲溶液____；乙溶液____；丙溶液____。

(2) 如果电解过程中铜全部析出，此时电解能否继续进行？为什么？

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案（原书答案 L3809~3823）

(1) ① 电源的 N 端为正极。

② 电极 b：$4OH^{-} - 4e^{-} \longrightarrow 2H_2O + O_2\uparrow$。

③ 根据丙中 $K_2SO_4$ 质量分数由 10.00% 上升为 10.47%，设电解水的质量为 x g：$100\times10.00\% = (100-x)\times10.47\%$，得 x = 4.49 g。再由 $2H_2O \xrightarrow{\text{电解}} 2H_2\uparrow + O_2\uparrow$，算出 b、d、f 极上均产生相同体积的氧气 2.79 L。

④ 根据 $2Cu \sim O_2$ 关系，电极 c 上析出铜 16.0 g（质量增加 16.0 g）。

⑤ 甲增大——相当于电解水；乙减小——$OH^{-}$ 放电、$H^{+}$ 增多；丙不变——相当于电解水。

(2) 可以继续。因为 $CuSO_4$ 溶液已转变为 $H_2SO_4$ 溶液，继续电解实质是电解水。

</details>
