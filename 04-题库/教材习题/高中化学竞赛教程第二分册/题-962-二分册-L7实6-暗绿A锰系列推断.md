# 题-962-二分册-L7实6-暗绿A锰系列推断

> **来源**：高中化学竞赛教程第二分册 · 第7讲 实战演练⑥（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L5084，答案 L5170~5172。原书题号标记「⑥」被 OCR 丢失，按答案区顺序回填）

## 题目

⑥ 化合物 A 是一不溶于水的暗绿色固体，但它能溶于硝酸生成浅粉色溶液 B，将 B 与浓 HNO₃ 和 KClO₃ 共煮，便可生成棕色沉淀 C，将该沉淀 C 与 NaOH 和 Na₂O₂ 共熔，它就转化为绿色化合物 D，D 可溶于盐酸溶液中，生成紫色溶液 E 及少量沉淀 C。将 C 加入酸性 H₂O₂ 溶液中，便有气体 F 生成，在溶液中加入少量的 NaOH 溶液，生成白色沉淀 G，G 迅速变成褐色沉淀 H。请确认每个字母所代表的物质，并写出 C 在酸性条件下与 H₂O₂ 反应和 C 在碱性条件下与 Na₂O₂ 反应的方程式。

## 参考答案

<summary>📖 查看答案与解析</summary>

### 答案

A：MnO　B：$Mn(NO_{3})_{2}$　C：$MnO_{2}$　D：$Na_{2}MnO_{4}$　E：$NaMnO_{4}$　F：$O_{2}$　G：$Mn(OH)_{2}$　H：$MnO(OH)_{2}$

$$
\mathrm {MnO_ {2} + H_ {2} O_ {2} + 2 H^ {+} \longrightarrow Mn^ {2 + } + O_ {2} \uparrow + 2 H_ {2} O}
$$

$$
\mathrm {MnO_ {2} + Na_ {2} O_ {2} \xrightarrow{\triangle} Na_ {2} MnO_ {4}\ (碱性条件下)}
$$
