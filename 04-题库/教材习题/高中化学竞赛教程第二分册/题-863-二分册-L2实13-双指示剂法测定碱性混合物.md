# 题-863-二分册-L2实13-双指示剂法测定碱性混合物

> **来源**：高中化学竞赛教程第二分册 · 第2讲 实战演练13（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L1690~1696，答案 L1790~1836）
> **互链**：[[题-容量-02-混合碱双指示剂法]]（同方法不同题）。

## 题目

13 双指示剂可用来测定 NaOH、$NaHCO_3$、$Na_2CO_3$ 中的一种或两种物质组成混合物时各成分的质量分数。具体做法是：先向待测溶液中加入酚酞，用标准盐酸滴定，当 NaOH 或 $Na_2CO_3$ 被转化为 NaCl 或 $NaHCO_3$ 时，酚酞由红色褪为无色，消耗 $V_1$ mL 盐酸；然后滴加甲基橙，继续用标准盐酸滴定，当 $NaHCO_3$ 转化为 NaCl 时，溶液由黄色变为橙色，消耗 $V_2$ mL 盐酸。

(1) 试根据下表给出的 $V_1$、$V_2$ 数值的范围，判断原混合物的成分（用化学式表示）。

| $V_1$ 和 $V_2$ | $V_1\neq0$, $V_2=0$ | $V_1=0$, $V_2\neq0$ | $V_1=V_2\neq0$ | $V_1>V_2>0$ | $V_2>V_1>0$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 试样成分 | | | | | |

(2) 若称取 1.200 g 含杂质的试样（杂质不与盐酸反应），配制成 100.00 mL 溶液，取出 20.00 mL 溶液，用 0.100 mol·L⁻¹ 的标准盐酸滴定，测得 $V_1 = 35.00$ mL，$V_2 = 5.00$ mL。求试样的成分及质量分数。

### 答案（原书答案 L1790~1836）

(1) 利用双指示剂法分析碱性混合物的组成是容量分析中有实际意义的分析方法，常用以测定烧碱中 NaOH 的质量分数（因吸收空气中 $CO_2$ 而混有 $Na_2CO_3$ 杂质）。

① $V_1\neq0$、$V_2=0$：只含 NaOH；② $V_2\neq0$、$V_1=0$：只含 $NaHCO_3$（终点为 $CO_2$ 饱和溶液，pH 3.1~4.4 在甲基橙变色范围；若有 NaOH 或 $Na_2CO_3$ 则 $V_1\neq0$）；③ $V_1=V_2\neq0$：只含 $Na_2CO_3$（两步耗盐酸相等）；④ $V_1>V_2>0$：含 NaOH 和 $Na_2CO_3$（$n(NaOH) = c_{\text{酸}}(V_1-V_2)$）；⑤ $V_2>V_1>0$：$Na_2CO_3$ 和 $NaHCO_3$ 的混合物（$n(NaHCO_3) = c_{\text{酸}}(V_2-V_1)$）。

(2) $V_1 > V_2 > 0$，混合物含 NaOH 和 $Na_2CO_3$：

$$
n(NaOH) = 0.100\times(35.00-5.00)\times10^{-3} = 3.00\times10^{-3}\,\mathrm{mol},\quad \mathrm{NaOH}\% = \frac{3.00\times10^{-3}\times\frac{100.00}{20.00}\times40}{1.200}\times100\% = 50.0\%
$$

$$
n(Na_2CO_3) = 0.100\times5.00\times10^{-3} = 5.00\times10^{-4}\,\mathrm{mol},\quad \mathrm{Na_2CO_3}\% = \frac{5.00\times10^{-4}\times\frac{100.00}{20.00}\times106}{1.200}\times100\% = 22.1\%
$$
