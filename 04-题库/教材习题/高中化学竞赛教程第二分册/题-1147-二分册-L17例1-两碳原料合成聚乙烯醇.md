# 题-1147-二分册-L17例1-两碳原料合成聚乙烯醇

> **来源**：高中化学竞赛教程第二分册·第17讲 合成高分子·例1

**【例1】** 用不大于两个碳的化合物合成聚乙烯醇。

<details>
<summary>📖 查看答案与解析</summary>

**过程探究** $\left[\mathrm{CH_{2}CH}\right]_{n}$ 为聚乙烯醇，但该聚合物无 $\mathrm{CH_{2}=CH{-}OH}$ 单体（乙烯醇不稳定，立即异构化为乙醛），因此只能通过大分子的反应得到，即先合成聚醋酸乙烯酯，再醇解。

**参考解答**

$$\mathrm{CH}\equiv\mathrm{CH} + \mathrm{CH_{3}COOH} \longrightarrow \mathrm{CH_{2}=CH{-}OOCCH_{3}}$$

$$n\,\mathrm{CH_{2}=CH{-}OOCCH_{3}} \xrightarrow[\ \Delta\ ]{\text{引发剂}} \left[\mathrm{CH_{2}-CH}\right]_{n}$$
$$\qquad\qquad\qquad\qquad\qquad\qquad\ \big\vert$$
$$\qquad\qquad\qquad\qquad\qquad\quad\ \mathrm{OOCCH_{3}}$$

$$\left[\mathrm{CH_{2}-CH}\right]_{n} + n\,\mathrm{HOCH_{3}} \xrightarrow{\ \mathrm{NaOH}\ } \left[\mathrm{CH_{2}-CH}\right]_{n} + n\,\mathrm{CH_{3}COOCH_{3}}$$
$$\qquad\ \ \big\vert\qquad\qquad\qquad\qquad\qquad\ \ \big\vert$$
$$\quad\ \mathrm{OOCCH_{3}}\qquad\qquad\qquad\qquad\quad\ \mathrm{OH}$$

</details>
