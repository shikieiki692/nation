# 题-900-二分册-L4实5-高铁电池充放电判断

> **来源**：高中化学竞赛教程第二分册 · 第4讲 实战演练5（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L3016~3018，答案 L3122~3124）

## 题目

5 高铁电池是一种新型可充电电池，与普通高能电池相比，该电池能长时间保持稳定的放电电压。高铁电池的总反应为 $3Zn + 2K_2FeO_4 + 8H_2O \xrightarrow[\text{充电}]{\text{放电}} 3Zn(OH)_2 + 2Fe(OH)_3 + 4KOH$。下列叙述不正确的是（ ）。

A. 放电时负极反应为 $Zn - 2e^{-} + 2OH^{-} \longrightarrow Zn(OH)_2$

B. 充电时阳极反应为 $Fe(OH)_3 - 3e^{-} + 5OH^{-} \longrightarrow FeO_4^{2-} + 4H_2O$

C. 放电时每转移 3 mol 电子，正极有 1 mol $K_2FeO_4$ 被还原

D. 放电时正极附近溶液的 pH 不变

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

### 答案

D

### 解析（原书答案 L3122~3124）

根据题中电池总反应式可知，放电时负极反应为 $Zn - 2e^{-} + 2OH^{-} \longrightarrow Zn(OH)_2$，选项 A 正确；充电时阳极反应为 $Fe(OH)_3 - 3e^{-} + 5OH^{-} \longrightarrow FeO_4^{2-} + 4H_2O$，选项 B 正确；1 mol $K_2FeO_4$ 被还原成 $Fe(OH)_3$ 得 3 mol 电子，所以选项 C 正确；正极反应 $FeO_4^{2-} + 4H_2O + 3e^{-} \longrightarrow Fe(OH)_3 + 5OH^{-}$ 生成 $OH^{-}$，正极附近溶液的 pH 变大，选项 D 错误。

答案：D。
