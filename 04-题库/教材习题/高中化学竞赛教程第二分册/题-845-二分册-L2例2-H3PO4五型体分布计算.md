# 题-845-二分册-L2例2-H3PO4五型体分布计算

> **来源**：高中化学竞赛教程第二分册 · 第2讲 例2（`06-外部资料导入/OCR/竞赛教程第二分册OCR源/..._1-199.md` L1170~1204，答案 inline）

## 题目

【例2】计算 $0.10\,\mathrm{mol\cdot L^{-1}}\,\mathrm{H_3PO_4}$ 溶液中 $[\mathrm{H}^{+}]$、$[\mathrm{H_2PO_4^{-}}]$、$[\mathrm{HPO_4^{2-}}]$、$[\mathrm{PO_4^{3-}}]$ 和 $[\mathrm{H_3PO_4}]$。

（已知：$\mathrm{H_3PO_4}$　$K_{a_1} = 7.5\times10^{-3}$，$K_{a_2} = 6.2\times10^{-8}$，$K_{a_3} = 2.2\times10^{-13}$）

## 参考答案

<details>
<summary>📖 查看答案与解析</summary>

**过程探究**（原书 L1176）

$H_3PO_4$ 是三元弱酸，但由于 $K_{a_1}\gg K_{a_2}\gg K_{a_3}$，所以计算 $[H^{+}]$ 时可当一元弱酸处理，并且 $[H_2PO_4^{-}]$ 近似等于 $[H^{+}]$。

**参考解答**（原书 L1178~1204）因 $\dfrac{c}{K_{a_1}} = \dfrac{0.10}{7.5\times10^{-3}} = 13 < 500$，需解一元二次方程（不能用电离度近似）：

$$
[\mathrm{H}^{+}] = \frac{-7.5\times10^{-3} + \sqrt{(7.5\times10^{-3})^{2} + 4\times7.5\times10^{-3}\times0.10}}{2} = 2.4\times10^{-2}\,\mathrm{mol\cdot L^{-1}}
$$

$[\mathrm{H_2PO_4^{-}}] = [\mathrm{H}^{+}] = 2.4\times10^{-2}\,\mathrm{mol\cdot L^{-1}}$。

由第二级离解平衡：$[\mathrm{HPO_4^{2-}}] = K_{a_2}\dfrac{[\mathrm{H_2PO_4^{-}}]}{[\mathrm{H}^{+}]} = K_{a_2} = 6.2\times10^{-8}\,\mathrm{mol\cdot L^{-1}}$。

由第三级离解平衡：$[\mathrm{PO_4^{3-}}] = K_{a_3}\dfrac{[\mathrm{HPO_4^{2-}}]}{[\mathrm{H}^{+}]} = \dfrac{2.2\times10^{-13}\times6.2\times10^{-8}}{2.4\times10^{-2}} = 5.7\times10^{-19}\,\mathrm{mol\cdot L^{-1}}$。

$[\mathrm{H_3PO_4}] = 0.10 - (2.4\times10^{-2} + 6.2\times10^{-8} + 5.7\times10^{-19}) = 7.6\times10^{-2}\,\mathrm{mol\cdot L^{-1}}$。

注意：本题中 $K_{a_2} = [HPO_4^{2-}]$，但不能因此认为 $[PO_4^{3-}] = K_{a_3}$。
