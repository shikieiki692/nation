# TiO2制造方法评述

> **来源**：无机化学第6版（Weller等著，中文版）Ch19 辅导性作业19.3
> **难度**：⭐⭐⭐⭐

## 题目

$\mathrm{TiO_{2}}$ 可由氯化物法和硫酸盐法制造，从使用的原材料、生产出来的颜料的性质、生产过程对环境的影响等三个方面简要评述两种方法的优缺点。

## 参考答案

### 1. 原材料

- 氯化物法：以高品位金红石或富钛渣为原料，与焦炭一起在高温下氯化，生成可精馏提纯的 $\mathrm{TiCl_4}$，再用 $\mathrm{O_2}$ 氧化为颜料级 $\mathrm{TiO_2}$ 并回收氯气：

$$\mathrm{TiO_2 + 2C + 2Cl_2 \longrightarrow TiCl_4 + 2CO}$$

$$\mathrm{TiCl_4 + O_2 \longrightarrow TiO_2 + 2Cl_2}$$

- 硫酸盐法：以钛铁矿（$\mathrm{FeTiO_3}$）或钛渣等廉价易得原料为起点，用浓硫酸酸解后浸取，再经水解、洗涤、煅烧得到 $\mathrm{TiO_2}$。核心流程可概括为：

$$\mathrm{FeTiO_3 + 2H_2SO_4 \longrightarrow TiOSO_4 + FeSO_4 + 2H_2O}$$

$$\mathrm{TiOSO_4 + 2H_2O \longrightarrow TiO(OH)_2\downarrow + H_2SO_4}$$

$$\mathrm{TiO(OH)_2 \xrightarrow{\Delta} TiO_2 + H_2O}$$

### 2. 颜料性质

- 氯化物法产物纯度高，Fe 等着色杂质少，白度、遮盖力和消色力好，粒径与晶型（以金红石型为主）更易控制，适合高档涂料、塑料和造纸用钛白。
- 硫酸盐法通过调节水解和煅烧条件既可制锐钛矿型也可制金红石型，但杂质含量通常偏高，粒度和消色力略逊，常需表面包膜处理；经良好控制也能达到较高颜料质量，综合性能总体略低于氯化法高端产品。

### 3. 环境影响

- 氯化物法需要氯气密闭循环、高温氯化设备和严格的尾气与泄漏控制，设备腐蚀和安全防护成本高；但流程短、废水量少，副产物氯气可回收，若原料品位高，整体环保负荷相对较小。
- 硫酸盐法硫酸消耗量大，产生大量稀硫酸、硫酸亚铁和酸性废水等副产物，需中和、浓缩或综合利用；铁杂质进入废渣后增加环保负担，废物处理是该方法的主要短板。

### 4. 综合评价

- 氯化物法更适合大规模生产高纯度金红石型颜料，产品质量与环境闭环更优，但对原料品位、氯气管理和高温设备要求高；硫酸盐法原料廉价且适合处理钛铁矿，但产品质量上限较低、废酸和含铁废料多。
- 两种方法各有适用场景，现代高端钛白生产总体向氯化物法集中；工厂选址还需结合原料供应、氯碱配套、废酸处置和当地环保成本综合决策。
