# 初赛讲义 第1讲 反应方程式 习题1.64

**题目**：
根据所给条件按照要求书写化学反应方程式(要求系数为最简整数比)。

1. 二氧化硫的水溶液与铝反应得到澄清的溶液，生成的气体具有毒性。
2. 新制 $\mathrm{Fe(OH)_2}$ 可在碳酸氢钠中将 1/12 当量的 $\mathrm{NaNO_3}$ 还原为 $\mathrm{NH_3}$。
3. 在氧化镁存在下，羟胺可用碘滴定，羟胺的物质的量等于消耗的碘的物质的量。
4. 在 50% 硫酸中，硫酸肼被 3% 过氧化氢溶液缓慢氧化得到叠氮酸。
5. 氯仿被臭氧氧化，产生两种常见强酸性气体。

## 答案

提示：第 1 小题需要注意酸式盐和正盐的溶解性关系。

1. $2\mathrm{Al} + 4\mathrm{H_2O} + 7\mathrm{SO_2} \rightarrow 2\mathrm{Al(HSO_3)_3} + \mathrm{H_2S}$
2. $12\mathrm{Fe(OH)_2} + \mathrm{NaNO_3} + \mathrm{NaHCO_3} \rightarrow 4\mathrm{Fe_3O_4} + 11\mathrm{H_2O} + \mathrm{NH_3} + \mathrm{Na_2CO_3}$
3. $2\mathrm{NH_2OH} + 2\mathrm{I_2} + 2\mathrm{MgO} \rightarrow \mathrm{N_2O} + 3\mathrm{H_2O} + 2\mathrm{MgI_2}$
4. $3\mathrm{N_2H_6^{2+}} + 2\mathrm{H_2O_2} \rightarrow 2\mathrm{HN_3} + 6\mathrm{H^+} + 10\mathrm{H_2O}$
5. $\mathrm{CHCl_3} + \mathrm{O_3} \rightarrow \mathrm{COCl_2} + \mathrm{HCl} + \mathrm{O_2}$
