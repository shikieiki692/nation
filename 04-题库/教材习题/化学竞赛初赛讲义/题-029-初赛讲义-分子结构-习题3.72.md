# 初赛讲义 第3讲 分子结构 习题3.72

**题目**：
【习题 3.72】六亚基四胺 $\left(\mathrm{CH}_{2}\right)_{6}\mathrm{N}_{4}$ 中存在 C—H...N 氢键。

1. 在六亚甲基四胺中, 每摩尔该分子有几摩尔氢键?

2. 为何电负性较小的 C 也能参与形成氢键?

**来源**：化学竞赛初赛讲义 第3讲 习题

## 参考答案
1. 2mol, 注意氢键给体 N 相比于受体 CH 不足。



2. C周围有4个N,因为较强的吸电子效应导致亚甲基上的氢缺电子。
