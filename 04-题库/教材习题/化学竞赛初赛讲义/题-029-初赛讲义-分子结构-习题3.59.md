# 初赛讲义 第3讲 分子结构 习题3.59

**题目**：
1. 用分子轨道理论解释下列物质的 O—O 键级、磁性（顺磁性、逆磁性）。
   - A. $O_{2}^{+}$
   - B. $O_{2}$
   - C. $O_{2}^{-}$
   - D. $O_{2}^{2-}$
2. 试判断 $O_{3}$ 中 O—O 间距与以上何者最接近。
3. 比较 $SOF_{2}$、$SOCl_{2}$、$SOBr_{2}$ 中硫氧键强度，并简要说明理由。

**来源**：化学竞赛初赛讲义 第3讲 习题

## 答案

1. 依次为:2.5,顺磁性;2,顺磁性;1.5,顺磁性;1,逆磁性。



2. 和 C 最接近。



3. $\mathrm{SOF}_2$ 最强, $\mathrm{SOBr}_2$ 最弱。第一, 根据 Bent 规则, 随着卤素 X 电负性增加, SO 键的杂化中 s 的成分增加, 因此成键变强; 第二, 由于 F 无 3d 轨道且吸电子能力强, 故 S 中心缺电子, 可与 O 更好地成 d—pπ 键, 因此成键变强。
