# 初赛讲义 第4讲 配合物 习题4.49

**题目**：
以下是制备一些新发现的 Cr 的配合物时的步骤。

- 新制备的 $\mathrm{CrBr}_2$ 和 $2,2'$ -联吡啶在稀盐酸中反应，得到黑色结晶沉淀A。  
- A与5%的HClO $_{4}$ 溶液混合在空气中摇动,得到了黄色晶状沉淀B。  
- 将 A 溶解在无空气的含有过量 $NH_{4}ClO_{4}$ 的蒸馏水中，在惰性气氛中与 Mg 反应，生成深蓝色化合物 C。

关于这些化合物的化学分析结果如下表所示：

| 物种 | N/% | Br/% | Cl/% | Cr/% | ClO₄/% | μ/(B.M.) |
|------|-----|------|------|------|--------|----------|
| A | 11.0 | 21.0 | | 6.9 | | 3.27 |
| B | 10.26 | | 13.01 | 6.4 | | 3.76 |
| C | 13.56 | | | 8.39 | 16.6 | 2.05 |

1. 写出 A、B、C 的化学式。  
2. 写出 A、B、C 的电子构型。
