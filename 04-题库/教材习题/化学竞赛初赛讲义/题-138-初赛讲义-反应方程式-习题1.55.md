# 初赛讲义 第1讲 反应方程式 习题1.55

**题目**：
根据所给条件按照要求书写化学反应方程式(要求系数为最简整数比)。

1. 由于 Zn 中含有少量的 $\mathrm{As_2O_3}$，所以吸入 Zn 与酸反应生成的 $\mathrm{H_2}$ 有很大的危险性。
2. KOH 可以与 $\mathrm{O_3}$ 反应生成臭氧化钾，反应气体分子数与生成气体分子数之比为 4:1。指出 KOH 的作用。
3. $\mathrm{Ce(NO_3)_3}$ 在碱性介质中被高锰酸钾氧化为 $\mathrm{CeO_2}$，Mn 元素被沉淀出来。
4. $\mathrm{CaH_2}$ 与纯碱溶液反应。
5. $\mathrm{Fe_2(SO_4)_3}$ 水溶液溶解煤中的 $\mathrm{FeS_2}$，用过的溶液经处理可循环使用。

## 答案

> [!warning] 原书答案区 OCR 错行严重（各小题方程式相互穿插），以下为忠实转录，引用前务必核对纸版。

1. $3\mathrm{Zn} + \mathrm{As_2O_3} + \cdots$（Zn 作还原剂；KOH 起还原剂并吸水作用）
2. $6\mathrm{KOH} + 4\mathrm{O_3} = \cdots$
3. $3\mathrm{Ce^{3+}} + 8\mathrm{OH^-} + \cdots$；$\mathrm{MnO_4^-}\rightarrow \mathrm{MnO_2} + 3\mathrm{CeO_2}$
4. $\mathrm{CaH_2 + CO_3^{2-} + 2H_2O \rightarrow CaCO_3\downarrow + 2H_2\uparrow + 2OH^-}$
5. $14\mathrm{Fe^{3+}} + \mathrm{FeS_2} + 8\mathrm{H_2O} \rightarrow 15\mathrm{Fe^{2+}} + 2\mathrm{SO_4^{2-}} + 16\mathrm{H^+}$
