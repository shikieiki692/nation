# 题-043：欲制备 $\mathrm{CaCl}$ 晶体，现通过热力学计算对其可行性进行判断。

## 题目

欲制备 $\mathrm{CaCl}$ 晶体，现通过热力学计算对其可行性进行判断。

1. 理论计算表明离子半径 $r(\mathrm{Ca}^{+})=120\mathrm{pm}, r(\mathrm{Cl}^{-})=167\mathrm{pm}$ ，下表列出了 MX 型化合物的有关情况。试推测 CaCl 的晶体结构。

| 配位方式 | $CaCl$  晶格能  $U_1/(kJ·mol^{-1})$ |
| --- | --- |
| 四面体配位 | -751.9 |
| 八面体配位 | -758.4 |
| 立方体配位 | -704.8 |

其他有关数据如下表所示：

| Ca熔化热 $\Delta_{\text{fus}} H_{\text{m}}^{\ominus}$ | 9.30kJ·mol⁻¹ |
| --- | --- |
| Ca第一电离能 $I_1$ | 589.7kJ·mol⁻¹ |
| Ca第二电离能 $I_2$ | 1145.0kJ·mol⁻¹ |
| Ca汽化热L | 150.0kJ·mol⁻¹ |
| Cl₂ 键解离能 | 240.0kJ·mol⁻¹ |
| CaCl₂ 晶格能 $U_2$ | -2232kJ·mol⁻¹ |
| Cl电子亲和能E | 349.0kJ·mol⁻¹ |

2. 求 CaCl 的标准摩尔生成焓。

3. 从热力学角度考虑, CaCl 可能合成吗? 计算说明。

---

## 参考答案
1. 立方体配位。其他配位型式都无法合并。



3. 不能，由于 $\mathrm{CaCl}_{2}$ 的标准摩尔生成焓为 $100\mathrm{kJ/mol}$，考虑到分子数基本不变, 因此反应在热力学上趋势很大, 所以很难制备。+Ca的焓变为 $-426\mathrm{kJ/mol}$，考虑到分子数基本不变, 因此反应在热力学上趋势很大, 所以很难制备。
