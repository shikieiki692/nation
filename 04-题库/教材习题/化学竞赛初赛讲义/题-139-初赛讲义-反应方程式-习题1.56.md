# 初赛讲义 第1讲 反应方程式 习题1.56

**题目**：
根据所给条件按照要求书写化学反应方程式(要求系数为最简整数比)。

1. 加热环乙亚砜可以得到一种特殊的化合物 A。A 非常不稳定，以至于遇水便歧化；它与烧碱溶液反应生成一种盐。（只需写出最后一个反应的方程式）
2. $\mathrm{SeOF_6}$ 在碱性溶液中分解，底物用结构简式表示。
3. 浓硫酸与尿素发生非氧化还原反应得到一种一元酸，它又与 HCl、$\mathrm{NaNO_2}$ 反应生成一种二元强酸。（只需写出后一个反应）
4. 近中性溶液中，1 mol 高碘酸与过量碘化物反应产生 1 mol 碘，将所得溶液酸化，又产生 3 mol 碘。（两个反应）
5. $(\mathrm{NH_4})_2\mathrm{SeO_3}$ 受热分解。

## 答案

> [!warning] 原书答案区 OCR 错行严重，以下为忠实转录，引用前务必核对纸版。

1. $2\mathrm{SO} + 2\mathrm{NaOH} \rightarrow \cdots$
2. $\mathrm{SeOF_6}$ 在碱性溶液中：$\rightarrow \mathrm{SeO_4^{2-}} + \mathrm{F^-} + \cdots$（系数待核）
3. $\mathrm{NH_3SO_3 + NaNO_2 + HCl \rightarrow N_2\uparrow + H_2SO_4 + NaCl + H_2O}$
4. $\mathrm{H_5IO_6 + 2I^- \rightarrow IO_3^- + I_2 + OH^- + 2H_2O}$；$\mathrm{IO_3^- + 5I^- + 6H^+ \rightarrow 3I_2 + 3H_2O}$
5. $3(\mathrm{NH_4})_2\mathrm{SeO_3} \rightarrow 2\mathrm{N_2}\uparrow + 3\mathrm{Se}\downarrow + 2\mathrm{NH_3}\uparrow + \cdots$
