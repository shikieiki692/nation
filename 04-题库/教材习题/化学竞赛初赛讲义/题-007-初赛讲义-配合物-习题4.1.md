# 初赛讲义 第4讲 配合物 习题4.1

**题目**：
用Bent规则解释诱导效应的来源。

**来源**：化学竞赛初赛讲义 第4讲 §4.1.1.1 习题

## 答案

设 C 与基团 R 相连, 根据 Bent 规则, 随着 R 的电负性升高, C—R 键的 p 成分会增加, 而 C 与其他基团连接的键的 s 成分相应增加, 造成 C 也显现出吸电子效应。
