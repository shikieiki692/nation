# 初赛讲义 第3讲 分子结构 习题3.28

**题目**：
1. 只考虑电子效应，分别比较 $NH_{3}$、$NF_{3}$、$NCl_{3}$ 和 $H_{2}O$、$H_{2}S$、$H_{2}Se$ 两组物质的键角大小关系。
2. 已知键角 $\mathrm{N}(\mathrm{CH}_{3})_{3}<\mathrm{N}(\mathrm{CF}_{3})_{3}$，对比以上结论你有什么发现？

**来源**：化学竞赛初赛讲义 第3讲 习题

## 答案

1. $\mathrm{NCl}_3 < \mathrm{NF}_3 < \mathrm{NH}_3$；$\mathrm{H}_2\mathrm{Se} < \mathrm{H}_2\mathrm{S} < \mathrm{H}_2\mathrm{O}$。
2. 结论与简单按照电子效应的结果相反，因此键角实际上是由电子效应与空间效应共同决定的。
