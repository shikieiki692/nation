# 高分子-06 电极区自由基离子浓度与稳态近似

> 来源：bdwp《10高分子化学加动力学》开篇手写区习题 **5-2-1**（承接 5-1-1 的电极区电引发聚合体系）

## 题目

**5-2-1** 假设 5-1-1 中电极区的溶液体积为 V，电流大小为 I，法拉第常数大小为 F，自由基离子二聚速率常数为 k_d，结合**稳态近似**，给出自由基离子的浓度。

## 解答

① **电子转移引发**：e⁻ + A → A⁻（单体自由基阴离子）

单位时间单位体积的生成量按法拉第定律算：

V_e⁻ = ΔC/Δt = Δn/(VΔt) = I/(FV)　（由 Q = nF 得）

② **二聚终止**：2A⁻ →(k_d) 二聚体

v_x = 2k_d[X]² ，稳态时与生成速率相等：

2k_d[X]² = I/(FV)　⟹　**[X] = √( I / (2FV k_d) )**

③ **链增长**：[P] + [M] →(k_p) 增长链，R_p = k_p[P][M]；

稳态下链自由基浓度 [P] = I / (F V k_t[Z])。

## 解析要点

- **核心是「电流 → 浓度」的换算**：电引发聚合中自由基离子由电极反应**定量产生**，生成速率即 I/(FV)（法拉第定律），无需另设引发剂。
- **稳态近似**：活泼中间体（此处为自由基离子）净生成速率为零 ⇒ 生成速率 = 消耗速率 ⇒ 解出 [X] ∝ I^(1/2)。这与自由基聚合中 R_i = R_t 解 [M·] 是**同一套方法**。
- 对照萘钠引发：两者皆由「引发速率」决定活性种浓度；区别是电引发用**电流**控制、化学引发用**引发剂用量**控制——都是实现「化学计量聚合」（窄分布）的途径。
