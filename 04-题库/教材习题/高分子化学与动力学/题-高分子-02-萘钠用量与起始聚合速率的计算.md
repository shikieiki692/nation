# 高分子-02 萘钠用量与起始聚合速率的计算

> 来源：bdwp《10高分子化学加动力学》第五章【例题 2（2015 期末 B）】第 3 题（8 分）

## 题目

**3.** 采用萘钠作引发剂，苯乙烯进行阴离子聚合，试求：

（1）合成分子量为 300000 的聚苯乙烯，当苯乙烯用量为 1 kg 时，需要多少克金属钠？

（2）若苯乙烯的浓度为 1.5 mol·L⁻¹，萘钠的浓度为 3.2×10⁻⁵ mol·L⁻¹，当表观反应速率常数 K_p = 550 L·mol⁻¹·s⁻¹ 时，起始聚合速率是多少？转化率 100% 时的聚合度是多少？（8 分）

## 解答

（1）萘钠作引发剂时 n = 2。假设所有的单体都消耗完全，则有 X̄ₙ = n([M]₀ − [M]) / [C] = 2[M]₀ / [C]；而分子量应为聚合度（即单体的个数）乘以单体相对分子质量，即 M = X̄ₙ · M_r。在一定体积时，易有

n_C = 2 n_苯乙烯 / X̄ₙ = 2 (m_苯乙烯 / M_r) ÷ (M / M_r) = 2 m_苯乙烯 / M = 2 × 1000 / 300000 = 1/150

所需金属钠的量即为萘钠的量，即

m_钠 = n_C × M_钠 = 23 / 150 ≈ **0.153 g**

（2）直接代入 R_p = k_P[M]₀[C]、X̄ₙ = 2[M]₀ / [C]，得

R_p = 550 × 1.5 × 3.2×10⁻⁵ = **0.0264 mol/(L·s)**

X̄ₙ = 2 × 1.5 ÷ (3.2×10⁻⁵) = **9.4×10⁴**

## 解析要点

- **两问共用同一个判据**：转化率 100% 时 [M] → 0，聚合度公式退化为 X̄ₙ = n[M]₀/[C]（n = 2），于是「分子量 → 聚合度 → 引发剂用量」是一条链。
- **易错点**：把 n 忘记（按 n = 1 算），结果钠用量会**翻倍**。萘钠（钠/萘络合物）是电子间接转移引发剂，一个引发剂分子给出**两个**活性端。
- 第（2）问把「起始速率」与「最终聚合度」并置，恰好体现阴离子聚合的**矛盾性**——提高引发剂浓度可提速，但聚合度反比下降；这正是它宜做「化学计量聚合」（窄分布标样）的原因。
