# 题-元推-03：陌生物质综合推断（液态金属）

## 题目

元素 X 的单质在常温下为银白色液体。X 的氯化物在水中微弱电离，其一价化合物以双核离子形式存在，X 的硝酸盐受热分解可回收 X。推断 X 并写出相应反应的方程式。

## 参考答案

**信号链**：
- 常温液态金属 → **Hg**（唯一常温液态金属）
- 一价双核离子 → $\mathrm{Hg_2^{2+}}$（Cl—Hg—Hg—Cl）
- 氯化物微弱电离 → HgCl₂ 为弱电解质（共价性、难电离）
- 硝酸盐热分解回收 Hg → $\mathrm{Hg(NO_3)_2 \xrightarrow{\Delta} Hg + 2NO_2\uparrow + O_2\uparrow}$

**答案**：X = Hg；依据：常温液态、Hg₂²⁺ 双核、HgCl₂ 弱电离、硝酸盐热分解得金属。

> **核心辨析**：综合推断用"最强信号先定位，再交叉验证"——常温液态金属是 P1 唯一性信号，直接锁定 Hg，后续特征（双核、弱电离、热分解）全部吻合。
