# 题-元推-01：颜色/溶解信号推断

## 题目

某白色固体 A 溶于水得无色溶液 B。向 B 中加 NaOH 生成白色沉淀 C，继续加过量 NaOH，沉淀溶解得无色溶液 D。另取 B 加氨水，先产生白色沉淀、加过量氨水又溶解。推断 A、C 的可能组成，并写出相关反应。

## 参考答案

**关键信号**：白色沉淀 C **既溶于过量强碱又溶于过量氨水** → 只有 **Zn(OH)₂** 符合（Al(OH)₃ 溶于强碱但不溶于氨水）。

- $\mathrm{A = ZnCl_2\ (ZnSO_4\ 等锌盐)}$，$\mathrm{C = Zn(OH)_2}$
- 与强碱：$\mathrm{Zn(OH)_2 + 2OH^- \rightarrow [Zn(OH)_4]^{2-}}$（D）
- 与氨水：$\mathrm{Zn(OH)_2 + 4NH_3 \rightarrow [Zn(NH_3)_4]^{2+} + 2OH^-}$

**答案**：A 为锌盐，C 为 Zn(OH)₂；溶于强碱得 [Zn(OH)₄]²⁻、溶于氨水得 [Zn(NH₃)₄]²⁺。

> **核心辨析**："两性 + 氨溶"双特征 = Zn 的指纹；Al(OH)₃ 只碱溶不氨溶是区分点。沉淀溶解行为矩阵是元素推断最强信号。
