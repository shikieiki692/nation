# 题-元氧-03：硝酸还原产物与白磷结构

## 题目

(1) 分别写出 Cu 与浓硝酸、稀硝酸反应的方程式，说明硝酸浓度如何影响还原产物。(2) 从结构角度解释白磷为何易自燃。

## 参考答案

**(1) 硝酸还原产物**：

$$\mathrm{Cu + 4HNO_3(\text{浓}) \rightarrow Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O}\quad(\text{N: } +5 \to +4)$$

$$3\mathrm{Cu + 8HNO_3(\text{稀}) \rightarrow 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O}\quad(\text{N: } +5 \to +2)$$

**规律**：硝酸越稀、还原产物价态越低：$\mathrm{NO_2 \to NO \to N_2O \to N_2 \to NH_4^+}$（极稀+活泼金属直接到 NH₄⁺）。

**(2) 白磷自燃**：P₄ 为正四面体，P—P—P 键角 60°，远小于正常共价键角（约 109.5°），**环张力极大**、键能低 → 化学性质极活泼，常温在空气中自发氧化燃烧。

**答案**：浓→NO₂、稀→NO；白磷因键角 60° 环张力大而自燃。

> **核心辨析**：硝酸的氧化性产物随浓度"滑尺"递变是推断题高频；P₄ 的小键角是白磷活泼性的结构根源（红磷为链状，稳定）。
