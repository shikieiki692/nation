# 题-元s-03：对角线规则（Li—Mg、Be—Al）

## 题目

(1) 各举两个实例说明 Li 与 Mg、Be 与 Al 的性质相似性。(2) 从离子势 $\phi = Z/r$ 角度解释对角线规则的本质。

## 参考答案

**(1) Li 与 Mg 相似**：
- 两者在 N₂ 中燃烧均生成氮化物 Li₃N、Mg₃N₂（Na、K 不生成）；
- Li₂CO₃ 与 MgCO₃ 均热不稳定，受热分解为氧化物（其余碱金属碳酸盐稳定）。

**Be 与 Al 相似**：
- Be(OH)₂ 与 Al(OH)₃ 均为两性氢氧化物；
- BeCl₂ 与 AlCl₃ 均为共价型、易升华，AlCl₃ 双聚为 Al₂Cl₆（BeCl₂ 聚合为链状）。

**(2) 离子势解释**：对角线规则的本质是**离子势相近**。从左上方到右下方，电荷 Z 增加但半径 r 减小，$\phi = Z/r$ 变化不大。Li⁺（Z=1, r≈76pm）与 Mg²⁺（Z=2, r≈72pm）的 $\phi$ 相近 → 极化能力相近 → 性质相似；Be²⁺ 与 Al³⁺ 同理。

**答案**：见上述实例；本质是离子势相近导致极化能力相近。

> **核心辨析**：对角线规则是"次级周期性"的典型体现——同一周期从左到右半径减小，同一族向下半径增大，沿对角线两个效应抵消。

## 知识点映射

- [[对角线规则]] · [[碱金属]] · [[离子极化]]
- 易错点：对角线规则是**相邻元素间**的相似性（Li-Mg、Be-Al、B-Si），不是所有对角元素都相似
