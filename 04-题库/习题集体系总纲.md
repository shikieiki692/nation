## 一、三层架构

```
第①层 章节练习包（2,654 题）         ← 随堂/章末，消耗品
    关键词：difficulty ≤ 3 的教材习题
    用完可补充，题目可重复出

第②层 模块习题集（1,685 题）         ← 阶段测试，核心资产
    关键词：difficulty ≥ 4 的教材习题 + 全部初赛真题
    每模块一份精选卷，题目只用一次

第③层 综合模拟卷（214 题）           ← 模考，选拔层
    关键词：决赛真题 + 高档综合题
    每套 25 题，跨模块混编

预赛专项（260 题）                  ← 初赛前热身
    关键词：省预赛真题
```

> **习题书成书（2026-09-01 质量整备后终态）**：第②层已固化为四篇 **31 章 / 1,283 题**正式习题书（化学原理 128 / 结构化学 564 / 有机化学 363 / 元素与分析 228）。教师版含折叠答案、学生版无答案，由 `11-模板/scripts/build_module_book.py` 一键重建（大题合并与严格过滤默认开启、章内 fidelity 优先排序）。硬规则：① 同一道大题的全部小问合并为一节，不再拆散；② 题面只标注真题来源（如"第38届初赛"），其余来源/难度等元信息不进正文。书末附**全书来源索引**（按"模块 · 章"专题排序），需外部资料的缺口题不入书。结构化学第 8 章（旧批次孤儿）已归档 `_归档/孤儿章-结构推断与综合-2026-08-31/`；构建防漂移三件套（README 自动回写 + 目录一致性校验 + 溯源映射）已落地。下文"九、利用率快照"为 2026-08-26 历史口径，数字以本节为准。
> **质量优先维护（2026-09-01）**：本书以质量优先于数量——分类审计（`audit_book_classification.py`）、质量四维排查（`audit_book_quality.py`：难度过低/考纲无关/篇幅过短/缺乏解析）、覆盖率核查（`audit_book_coverage.py`）为常规自检工具；不达标**降级不删除**（降级登记 `07-资料提炼/习题书剔除清单.json`，2026-09-01 首批降级 12 题）；择优补入 3 题。详见 [[04-题库/README]]「质量优先维护原则」。

### 五种载体形式分工（2026-09-01 定稿）

> 上面"三层架构"是**题库内部按 pack 分层**（题目存放在 04-题库，一题一包）；下面是**成品的载体形式分工**——同一道题可以以不同形态出现在不同载体中，这不是重复收录，而是服务场景不同。

| 载体 | 位置 | 定位 | 组织方式 | 答案形态 | 校验机制 |
|:--|:--|:--|:--|:--|:--|
| **仓储层** | `04-题库/` | 题目的唯一权威存放地（一题一文件） | 按来源/章节目录 | 随文件自带 | `validate_kb.py` |
| **随堂层·习题集** | `04-课件/习题集/第一轮*-习题集.md` | 配套讲义的随堂/章末练习（第一轮教学） | 手编，按难度三层（⭐基础巩固→竞赛提升→真题挑战）分级 | 题答同卷 | 无自动校验（人工维护） |
| **成书层·习题书** | `04-课件/习题集/习题书-{学生版,教师版}/` | 独立成书的模块精选（覆盖四个模块） | `build_module_book.py` 管线生成：大题合并不拆散 + fidelity 优先排序 | 师生双版本分离 | 三件套防漂移（溯源映射 + validate + README 回写） |
| **评测层·阶段测试卷** | `04-课件/习题集/化学原理阶段测试卷.md` | 限时计分考试（100 分 / 150 分钟） | 真题小问拼卷 | 独立答案卷（含易错分析） | 无自动校验（人工维护） |
| **真题策略层** | `05-真题库/` | 真题按题型重组 + 讲评加工 | 按题型文件 | 讲评级 | 与 04-题库/真题（按届次）互补 |

**区分要点**（以 33 届初赛第 3 题为例）：习题书收**整大题**（3-1~3-5 不拆，入热力学章）；习题集可取**单个小问**改写后按知识点入卷（3-1 气体分压入气体卷）；阶段测试卷按**小问拼卷**计分。题源必然重叠，形态互补。

**真题标注规范**（习题集适用，2026-09-01 起统一）：`[真题·第N届初赛/决赛·题号(或题号-小问)]`，如 `[真题·第33届初赛·第3题]`。届次+题号已由 `11-模板/scripts/trace_zhenti_labels.py` 自动溯源补全 20 处；深度改写无法可靠溯源的保留届次级标注。`[真题库]` 指 05-真题库精选，不适用此规范。

## 三、知识点覆盖矩阵

> 确保核心考点无盲区。每个知识点至少在模块习题集层有 ≥3 题。

```dataviewjs
const pages = dv.pages('"04-题库"').where(p => p.type === "题目" && p.knowledge_points);
const kpCount = {};
for (const p of pages) {
  for (const kp of (p.knowledge_points || [])) {
    const k = kp.replace(/\[\[|\]\]/g, "").trim();
    if (k) kpCount[k] = (kpCount[k] || 0) + 1;
  }
}
const sorted = Object.entries(kpCount).sort((a,b) => b[1]-a[1]).slice(0, 30);
dv.table(["知识点", "题量"], sorted.map(([k,v]) => [k, v]));
```

## 六、出卷流程

### 章节练习包（随堂）
1. 在 [[04-题库/组卷工作台]] 设参数：`pack = 章节练习` + `subject_module = 目标模块` + `difficulty = 2-3`
2. 从结果中选 10-15 题 → 复制到试卷文件
3. 检查 `depends_on`——承接式题目连同前驱一起出

### 模块习题集（阶段测试）
1. 参数：`pack = 模块习题集` + `subject_module = 目标模块` + `difficulty = 3-5`
2. 选 50-70 题，按子模块分组排列
3. 答案区单独一节置底
4. 出完的题在 frontmatter 加 `used_in: "[[卷名]]"` 标记已用

### 综合模拟卷（模考）
1. 参数：`pack = 综合模拟卷` + `difficulty = 3-5`
2. 选 25 题，跨模块混编，难度梯度 2:5:3
3. 真题占比 ≥60%
4. 同样标记 `used_in`

### 已用题追踪
- 出卷后在题目文件加 `used_in` 字段指向试卷页
- 选题时 Dataview 加过滤 `WHERE !p.used_in` 排除已用
