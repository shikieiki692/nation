# 题库唯一 ID 迁移表

> 本表只登记迁移风险和建议，不在本轮批量改名、批量 `kb_move` 或批量改 `qid`。当前唯一键仍以完整文件路径为准。

## 1. 迁移原则

1. 文件完整路径是当前稳定唯一键；
2. `qid`、`aliases`、basename、题号都不能单独承担唯一性；
3. 迁移前必须检查 `used_in`、`cross_references`、`aliases`、`knowledge_points`、试卷选题清单和反向引用；
4. 任何改名都必须保留旧链接兼容层，先登记、再改写、最后清理；
5. `qid` 建议采用“来源域 + 稳定序号/题号”，不要只写裸章节号；
6. 同号文件不能直接合并，必须先证明内容完全相同且消费记录可合并。

## 3. 建议的稳定 qid 形态

```text
上海中学-共价键理论-习题01
上海中学-共价键理论-习题02
ABOC-659-Ch1-T5
ABOC-673-Ch1-T8
ABOC-676-Ch1-T5
ABOC-680-Ch1-T3
```

命名中必须保留来源域，解决不同书籍都使用 `T1`、`T5`、`题-045` 的冲突。

## 4. 迁移前检查清单

- [ ] 用完整路径建立目标唯一性；
- [ ] 收集所有 `used_in`、`cross_references`、`aliases`、试卷链接；
- [ ] 检查同号文件是否真重复，而非不同小问或不同来源；
- [ ] 生成旧 ID → 新 ID 映射表；
- [ ] 先改引用，后改文件名；
- [ ] 用 `kb_index action=rebuild` 重建反向引用；
- [ ] 迁移后复核断链、重复题号和组卷隔离状态。

## 5. 本轮处理边界

- 只登记风险，不批量改名；
- 不对 ABOC deprecated 题卡臆造替代关系；
- 不把 basename 或 `qid` 作为去重主键；
- 不迁移 `04-课件/学生讲义/` 和讲义语言规范化试点文件。
