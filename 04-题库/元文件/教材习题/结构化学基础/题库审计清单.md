## 自动修复规则

以下问题**直接修复**，无需用户确认：

| 问题 | 修复方式 |
|------|----------|
| 缺少updated | 填入今天日期 |
| 缺少tags | 填入`[化竞, 结构化学基础, {主题}]` |
| 图片格式错误 | `![](xxx.jpg)` → `![[xxx.jpg]]` |
| 路径错误（周度→周公度） | 批量替换 |
| 缺少分隔线 | 在`## 参考答案`前后添加`---` |
| exam_stage不一致 | 批量修正为“初赛” |

以下问题**报告但不修复**：

| 问题 | 处理 |
|------|------|
| 答案截断 | 报告，建议用户确认后补充 |
| knowledge_points不准确 | 报告，建议修正 |
| 公式错误 | 报告，需人工核实 |

## 批量审计流程

1. **Glob定位**：`04-题库/教材习题/结构化学基础/题-*.md`
2. **kb_read批量读取**：每次读10个文件的frontmatter（limit=20）
3. **分类检查**：
   - 按章节分组（题号前缀）
   - 检查frontmatter完整性
   - 检查答案长度（>100字为合格）
4. **生成报告**：按P0/P1/P2分级输出
5. **自动修复**：低风险问题直接Edit
