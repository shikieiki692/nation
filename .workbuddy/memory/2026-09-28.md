## ★★ 头号发现：git 临时索引堆积 1.00 GB
`.workbuddy/tmp/index_*` 70 个 × 16.7 MB = **1.00 GB**。
**定性**：魔数 `DIRC` = git 索引文件（`.git/index` 同格式）。
**成因**：项目铁律每次 commit 建隔离索引 `export GIT_INDEX_FILE=.workbuddy/tmp/index_*.$$` + `git read-tree HEAD`，**用完从不清理**。

> 🔴 **教训：分档统计要给「<3天」这一档，否则会高估可清理量。**
> 🔴 **后续：应把「commit 后删除临时索引」写进铁律**，否则还会继续堆积（每会话 16.7 MB）。
