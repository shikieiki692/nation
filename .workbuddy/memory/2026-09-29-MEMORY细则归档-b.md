## ★ P0/P1 执行铁律（2026-09-29 新踩）

- 🔴 **bash 双引号内的 `python -c "…"` 含反引号 ⇒ 被 shell 当命令替换执行**。含反引号/非 ASCII 的脚本一律 Write 成 `.py`。

- 🔴 **docx 构建必须前台跑**；后台任务受沙箱限制会**静默假失败**。

- **js-yaml4 遇重复键/非法转义 THROW ⇒ 文件在 Obsidian 消失（P0）**：值含裸 `: `、以 `*`/`[`/`{` 开头 ⇒ 加引号；FM 内 wikilink 用 `/`；禁反斜杠 LaTeX。

- 🔴 **正则处理 `$$…$$` 会定界符配对错位** ⇒ 先暂存 `$$` 块，再处理行内 `$…$`，最后还原。
- **写盘铁律**：`open(p,"w").write(...)` 先截断 ⇒ 一律**先算后写 + 断言长度/内容**。
