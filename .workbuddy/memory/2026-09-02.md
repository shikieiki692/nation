### 本批踩坑（重要，跨批次通用）

- **bash heredoc 里 `:\` 会被吃掉**：`teaching_level:\s*` 变成 `teaching_level:/s*`，正则静默失效。但 `\s` 前面是中文/括号/行首时没事（`求\s`、`（\s{2,}`、`^\s*[ABCD]` 均正常）。→ **含冒号+反斜杠的正则一律用 Write 写成 .py 文件，不要走 heredoc**。
- **本库 `.gitattributes` 有 `*.md text eol=lf`，git diff 会做 CRLF 归一化** → 之前用「`git diff --stat` vs `--ignore-cr-at-eol --stat`」检测行尾污染**在本库是无效手段**。改为与 zip 快照逐行比对（`verify_b2a.py`）。
- **本库是混合行尾**：4,189 个待改文件里有 134,919 个 CRLF。用 `split("\n")` 后 CRLF 行的 `\r` 留在行尾——原地改值不受影响（`\r` 落在正则 `\s*$` 里），但**插入新行会丢 `\r`**，必须按邻居行尾风格补（487 次插入，241 次落在 CRLF 上下文）。
- `Path.read_text()` 不接受 `newline=`；且默认 `newline=None` 会折叠 CRLF→LF，**检测行尾时正好毁掉要测的东西**，必须用 `open(..., newline="")`。
- **git add 会刷出 ~150KB CRLF 警告**（`.gitattributes` 归一化所致），不 `2>/dev/null` 会被 SIGTERM 打断并留下 `.git/index.lock`（0 字节残留），后续 git 全报 exit=128，需 PowerShell `Remove-Item` 清锁。
- **改完文档要重跑校验再提交**：B1 在 题库架构总览.md 写了 `[[wikilink]]` 示例被当真实链接，Warning 209→210，本批才发现并改全角修回。这正是 SOP §7 明令禁止的反模式。
- git status 报 `M` 但 `git diff` 为空 = stat 缓存过期（内容字节相同），无害；`git update-index --refresh` 有时清不掉，提交时按显式 pathspec 暂存即可。
