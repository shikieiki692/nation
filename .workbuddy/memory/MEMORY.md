## 二、铁律（格式）

- **js-yaml4 遇重复键/非法转义 THROW ⇒ 文件在 Obsidian 消失（P0）**：值含裸 `: `、以 `*`/`[`/`{` 开头 ⇒ 加引号；FM 内 wikilink 用 `/`；禁反斜杠 LaTeX。
- **texmath 三条硬边界**：① `\frac` 3 层嵌套必炸；② array 单元格 `\text{}` 不可含 `_`/`^`；③ 单元格行首 `[` 触发 `\\[` 解析 ⇒ 写 `\mathrm{[…]}`。另 `\]`／`\atop`／`\cdotK` 不支持。
- **`$$` 三坑**：后换行以 `:` 开头 ⇒ pandoc 判非数学；被空行切断同理；块内嵌行内 `$` 须去。**行内数学 `$` 后不可紧跟空格**。
- 🔴 **正则处理 `$$…$$` 会定界符配对错位** ⇒ 先暂存 `$$` 块，再处理行内 `$…$`，最后还原。
- **写盘铁律**：先算后写 + 断言长度/内容。含 `|`/`*`/`[` 串禁 `grep -E`；锚点未命中先 `repr()`。⛔ 禁 `os.removedirs()`／`git rm -r`／统一转 LF；自写校验先自证（**扫 0 ＝ 可能是静默失效**）。
