## ★ 工具链铁律

- 🔴 Python `open(…,'w')` 在 Windows 写 CRLF ⇒ `xargs`/`git add` 把 `\r` 当路径一部分 ⇒ `sed -i 's/\r$//'` 后再喂 git。
- 🔴 **长任务（docx 构建）必须前台跑**：后台任务受沙箱限制会**静默假失败**。
- 🔴 **docx 导出会留 tmp 残留**（Word COM 报 WinError 5「目标被占用」时）：判据＝`_` 开头 + `.数字-数字.tmp.`（本轮在 `06-学生侧材料/讲义` 清出 171 个/15.6 MB）。处置 `.workbuddy/tmp/clean_tmp_residue.py`（先备份再删）；`.gitignore` 已加 `_*.tmp.md`/`_*.tmp.docx`。
