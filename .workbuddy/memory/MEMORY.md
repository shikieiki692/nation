## ★ 判据坑（2026-10-01 新增两条）

- 🔴 **图注编号检查必须「单元格级」**：只取表格中**以「图 N-M」开头**的单元格（`| > 图 N-M：… |` 或 `| 图 N-M 标签 |`）。
