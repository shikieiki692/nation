## 二、铁律（坑）

- **js-yaml4 遇重复键/非法转义 THROW→文件在 Obsidian 消失(P0)**：值含裸 `: `、以 `*`/`[`/`{` 开头→加引号；FM 内 wikilink 用 `/`；禁反斜杠 LaTeX。
- 🔴 **公式渲染三条硬边界（texmath）**：①`\frac` **3 层嵌套必炸**（2 层 OK）；②数组单元格 `\text{…}` **不可含 `_`/`^`**（2 行 array 中必炸、单行不炸）；③单元格**行首 `[`** 触发 `\\[` 可选参数解析 → 须写 `\mathrm{[…]}`。另：`\]`、`\atop`（→`\substack`）、`\stackup`、`\cdotK`/`\cdotLi`（粘连）、`{\right]}` 均不支持。
- 🔴 **`$$` 后换行以 `:` 开头 ⇒ pandoc 判为非数学**（产物留字面 `$`）；**`$$…$$` 被空行切断**同理。修法：内容与 `$$` 同行 / 合并对内空行。
- 🔴 **OCR 转义 `\$` 会渲染成字面 `$`** → 须还原为 `$`；`$$` 块内嵌行内 `$` → 去内层 `$`；`$$` 包裹 markdown 图 → 脱 `$$`。
- 🔴 **行内数学 `$` 后不可紧跟空格**（`$ a > 0.5 $` 会被 pandoc `tex_math_dollars` 判为非数学 ⇒ 字面 `$`）→ 写 `$a > 0.5$`。
- 🔴 **`render_gate --regression` 只比「是否变差」，⛔ 不能代替 full**：修完渲染必须再跑 `--manifest/--domain` 的 full 模式收口（2026-09-28 实测：两张只跑回归的卡残留字面 `$`）。
- 🔴 **pre-commit 用 `--regression`（与 HEAD 比 oMath 数/字面 `$` 数）**：`\(…\)`、`\[…\]` 与 `$…$` **同为数学定界符**，修渲染时**只可换定界符＋修内部语法，不可降级为纯文本**（否则 A 栏绿、回归红）。描述性文字（索引/报告）里 ⛔ 不写裸 LaTeX 命令（如 `\AA`）。
- 含正则/反斜杠/非ASCII脚本**必须 Write 成 .py**；同文件多 Edit 禁并行→原子 .py＋锚点 `count==1` 预检＋回读。批量替换先 dry-run；锚点未命中先 `repr()`（正文普遍直引号）。含 `|`/`*`/`[` 串禁 `grep -E`→`grep -F`。
- 自写校验先自证（扫 0＝静默失效）；「通过」前看扫了多少。⛔ 禁 `os.removedirs()`/`git rm -r`/统一转 LF。机检数字异常先怀疑判据本身。
- 🔴 **临时索引提交后主索引缺条目→`D ` 伪信号**：提交后把本会话全部产物重新 `git add`，核 `D`=0。
