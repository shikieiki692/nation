### 1 字体统一（用户指示：所有数字和符号 → Times New Roman，特殊中文符号除外）
- **根因**：pandoc 对「以汉字开头的 run」写 `<w:rFonts w:hint="eastAsia"/>`（卷I 373 处）⇒ 该 run 内的**数字与符号也走宋体**，
  同一页里「第 1 题」的 1 与 `700 °C` 的 700 字体不一致。
- **修法**：把每一处 `w:rFonts` 规范化成 `ascii/hAnsi/cs=Times New Roman + eastAsia=SimSun` 并**删掉 hint**；
  Word 随后按 Unicode 区段分派 —— ASCII/西文符号 → TNR，汉字与全角标点 → 宋体。覆盖 document/styles/numbering/footnotes/comments/footer/header 全部部件。
- **数学域再补两层**：`settings.xml` 写 `m:mathPr/m:mathFont=Times New Roman`；每个 `<m:r>` 内插 `<w:rPr><w:rFonts…/></w:rPr>`（**必须排在 `<m:t>` 之前**，CT_R 顺序＝m:rPr→w:rPr→内容）。
- **核验**：对渲染 PDF 做 span 级字体归类（pymupdf）——答题卡「宋体承载西文/数字」= **0**；学生版/答案版仅剩 `→ ∞` 落到宋体，
  其余 `，。（）、：；""【】④／` 是应保留的**全角中文标点**。
- 🔴 **实测渲染器限制**：LibreOffice 的 OMML 导入**既不认 `m:mathFont` 也不认 run 级 `w:rFonts`/`m:sty`**
  （数学一律用 LiberationSerif/OpenSymbol 代排，且一律斜体）——做了严格对照实验（把注入的 567 处 w:rPr 全部删除后重渲染，**像素级一致**）
  ⇒ 预览 PDF 里公式仍是斜体数学字体，属渲染器行为；Word/WPS 按规范应用。**汇报必须写明这一点，否则用户会以为没改**。
