## 六、Word（pandoc/texmath）
- 不支持 `\ce{}`（须预处理）；math 内禁 `\textbf`；`$$` 块内禁空行；闭合 `$` 禁后跟数字；不支持 `\displaylines`。标准态 `^\theta`；但 `^{\circ}\mathrm{C}` 必须保留。
- **texmath 拒绝两类**：① 字体开关 `\bf/\sf/\rm/\it/\sl/\sc/\tt`（含 `\boldsymbol{\rm …}`）→换等义命令、保留外层花括号；② `\text{}` 内反斜杠命令→换 Unicode。**诊断：`pandoc -t native` 会骗人，必须 `pandoc -t docx` 抓 `Could not convert TeX math`。**
- 等宽段 / 合并单元格 / `<br>` 被静默吞 / 闭合 `**` 遇全角 `）` / 教师向泄漏 precheck → 见 skill `docx-math-leak-qa`、`md-tables-to-docx-merged`、`md-codeblock-to-list`。

## 七、讲义 / 教案 / OCR
- ⛔ **禁止 `python -c "..."` 内联写长文本（2026-09-18 实测事故）**：正文含**反引号**时会被 bash 优先做**命令替换**——本次写日志时反引号内的 `` `11-模板/scripts/audit_question_bank.py` `` 等片段**被当命令真的执行了**，后果：① 目标写入失败（`F02A` 私有区字符 + `**` 被吃掉）② **误跑并行会话的审计脚本**、重新生成了 `09-审计报告/2026-09-18-题库全面审计.md` ③ 造出乱码垃圾文件（`\uf02a\uf02a范围\uf02a\uf02a：04-题库`，0 字节）。→ **一切含反引号／双引号／非 ASCII 的文本写入，必须 Write 成 `.py` 再跑**（本库既有铁律，此次为实证）。乱码文件因含 U+F02A，`os.path.exists(字面量)` 会判 False → 须 `os.listdir` 遍历 + 判 `0xE000<=ord(c)<=0xF8FF` 才能删。

## 十、OCR 表格公式格式治理（2026-09-19，A/B/C/D 四类）

### 四类缺陷定义
- **A**：math 内裸单位未包 `\mathrm{}`（`mol`/`kJ`/`dm`…）
- **B**：真空双花括号 `\mathrm{{X}}` → `\mathrm{X}`（**会字面输出到 Word 的硬伤**）
- **C**：孤立左 `$`（无配对，破坏整行数学渲染）
- **D**：单位裸露在 math **之外** + 负下标写法错（`mol·s-1` → `mol·s⁻¹`）

### 口径（用户 2026-09-19 拍板）
- **修 A+B+C；D 只出清单不自动修**。理由（抽样实证）：机械替换会掩盖真错——
  OCR 上标丢失（`10-2` 实为 `10⁻²`）、表格结构断裂（单位与数值对应关系需人工读表）。
- **跳过** `04-题库/`、`05-真题库/`、`_归档/`（红线区 + 并行会话）。

### ⚠️ 三大必守纪律
1. **A 类判据必须带上下文**（白名单法必误伤）：
   - **排除**相态 `(g)/(s)/(l)`、元素符号 `H/O/C/N`、变量 `K`/`T`/`J`（偶合常数）
   - **单字母单位**（`J/K/L/s`）仅在「与已识别多字母单位由 `·`/`\cdot` 串联」时才处理
   - 斜杠后单字母（`mol/L`）需门控：同段内出现多字母单位才处理
2. **占位符法（Protect-Restore）必用**：`\mathrm{mol\cdot dm^{-3}}` 含**嵌套花括号**，
   用 `[^{}]*` 无法匹配 → 会被重复包裹成 `\mathrm{\mathrm{mol}...}`（P0）。

### ⭐ 单位分隔符 `·` vs `\cdot`（2026-09-19 新增，长效判据）

**缺陷形态**：`\mathrm{X}·\mathrm{Y}` —— 单位已包裹但分隔符误用 Unicode 中圆点
`·`(U+00B7)，而非数学算子 `\cdot`。**是「半修复残留」，不是已修好**。
- `·` 无二元运算符间距语义；pandoc→docx 落入普通文本 run，乘号不成比例
- 库内普查：`\cdot` 形态 **322 文件/1380 处**（主流）｜`·` 形态 **48 文件/206 处**
- **38 个文件内两种写法混用** → 历史遗留不一致的铁证

**规则（保守，零误伤）**：正则 `(\\mathrm\{[^}$\n{}]{1,24}\})·(\\mathrm\{[^}$\n{}]{1,24}\})`
→ `\1\cdot\2`。**只动两个 `\mathrm{}` 之间的 `·`**。
- **不动**：化学式/水合物（`KOH·2H₂O`、`CuSO₄·5H₂O`、`TMA·H₂O`）、
  `\text{J/(mol·K)}` 内文字乘号、裸单位（`mol·L-1` 未被 `\mathrm` 包，属另一类未修）
- **⚠️ 必须迭替代换至稳定**：首次非重叠 `sub` 会漏掉
  `\mathrm{K}\cdot\mathrm{kg}·\mathrm{mol}^{-1}` 类混合形态（前一个已是 `\cdot`，
  第二个 `·` 被跳过 → 本次漏 4 处，二次迭代修复）

**四口径验证**（独立于被验对象）：① 残留形态=0；② 行数/行尾守恒；
③ **逐处位点守恒**（迭代替换备份后应与现文完全相等）；④ 字符级 diff 全为 `·`→`\cdot`。

**⚠️ 证伪纪律**：validate_kb 报的 error/warning 若含断链，**先查该断链在改动前
备份中是否存在**（本次 8/8 命中 → 证明是既有问题，非本次引入）。
