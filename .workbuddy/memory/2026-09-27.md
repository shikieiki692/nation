### 方法沉淀（新判据，全部实测）
- **`$$` 后换行以 `:` 开头 ⇒ pandoc 判为非数学**，产物残留字面 `$$`。修法：内容与 `$$` 同行（`$$ : x $$`）；6 张属此类（YJ-02-04 / HZ-07-01 / QBY-04-03 / QBY-17-05 / GChO-45-03 / GChO-65-04）。**旧检查器查不出**，因为 pandoc 不报错、只写字面 `$`。
- **texmath 三条硬边界**：①`\frac` **3 层嵌套必炸**（2 层 OK）；②array 单元格 `\text{…}` **不可含 `_`/`^`**（2 行 array 中必炸，单行不炸）；③单元格**行首 `[`** 触发 `\\[` 可选参数解析 → 须写 `\mathrm{[…]}`。

- 🔴 **`\ce{…}` 内不得含 `<`/`"`**：`_preprocess_ce_in_math` 之外，我自写的「`\ce{}` 去空格」规则会把 `<img src="…"/>` 压成 `<imgsrc="…"/>` **破坏标签** → 规则须跳过含 `<`/`"` 的 `\ce{}`。
