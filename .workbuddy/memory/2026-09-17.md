### 本轮踩到并排除的 3 个自写检测假信号（重要教训）
1. **`grep -c $'\r'` 报 82/82 行 CRLF —— 假**：Git Bash 下 `$'\r'` 被当空串，每行都命中。改用 Python 字节级 `b.count(b'\r')` → 实为 **纯 LF**。
2. **`cut -c1-170` 截断造成「文件乱码」假象 —— 假**：多字节字符被截断后终端显示成 GBK 乱码，文件本身 UTF-8 完好（用 Python 断言 `含[根据画出]: True`）。
3. **`TAG_RE = <[^>]+>` 跨行吞噬造成「文字不守恒 1388 字符」—— 假**：正文数学式里的裸 `<`（如 `n < 5`）会让 `[^>]` 一路吞到下一个 `>`；摊平插入行后吞噬范围改变。**必须写成 `<[^<>\n]*>`（禁跨行）**。

> 结论：报告「❌」前先怀疑脚本 —— 本会话 3 次全是脚本的问题，不是内容的问题。

### 坐标法要点（可复用）
- 依赖仅 **PyMuPDF**（装于 `~/binaries/python/envs/default`，1.28.2）；**全部真题 PDF 均为 Word 原生版**（`Creator: Word`），矢量结构式可用区域渲染，不失真。
- 题号定位：`get_text("words")` 中 `^\d{1,3}[.．]$` 且 `x0<=110`。
- **图形块必须保留零宽/零高线段**：结构式由大量 `3.6x0`、`0x49.3` 的细线段拼成，过滤 `width<2 or height<2` 会把图拆散（曾致 Q11/Q12 漏裁）。正确过滤 = 只剔除「完全退化为点」与「width>500 且 height<3 的页面分隔线」。

- 江苏/福建另用 **PDF 自带「图N」图注**定位（题库描述里的「图1~图5」与 PDF 图注编号一致，命中 5/5），无图注时退回「第N题」题号区间。

### ⚠️ 四个新踩的坑
1. **题号撞车**：首页「考生须知」的 `1./2./3./4.` 与正式题号同时被 `\d+.` 正则命中 → 字典 `setdefault` 只留第一个（考生须知），Q3/Q4 定位到页眉。**必须取最后一次出现**（`flat[q]=…` 覆盖）。
2. **「同页优先」是双刃剑**：浙江实测 2 处（2021-Q77、2022-Q60）描述写「第N页下图」，图确实排到了**次页顶部**——同页优先反而会选到正文块。**看描述中「下图」二字即可判定**，勿盲目同页优先。
3. **文件级预过滤写错会静默漏整批**：`if "省预赛" not in text and "_p0" not in text: continue` —— 短链形态不含「省预赛」、单页号 `_p10/_p16` 不含 `_p0` → **7 处学生版整体被跳过且报「未匹配 0」**。预过滤应写 `re.search(r"_p\d+\.png", text)`。
4. **「未匹配 0」≠ 全覆盖**：它只说明「扫到的都匹配上了」，不代表「该扫的都扫到了」。必须反向核对**残留数**（替换后 grep 旧模式），两者同时为 0 才算干净。
